NOM

YAML::PP::Schema::Perl - Schéma pour la sérialisation d'objets Perl et de types spéciaux

SYNOPIS

use YAML::PP;
# Ceci peut être dangereux lors du chargement de YAML non fiable !
my $yp = YAML::PP->new( schema => [qw/ + Perl /] );
# ou
my $yp = YAML::PP->new( schema => [qw/ Core Perl /] );
my $yaml = $yp->dump_string(sub { return 23 });
# chargement de références de code
# Ceci est très dangereux lors du chargement de YAML non fiable !!
my $yp = YAML::PP->new( schema => [qw/ + Perl +loadcode /] );
my $code = $yp->load_string(<<'EOM');
--- !perl/code |
    {
        use 5.010;
        my ($name) = @_;
        say "Hello $name!";
    }
EOM
$code->("Ingy");

DESCRIPTION

Ce schéma permet de charger et de sauvegarder des objets Perl et des types spéciaux.

Veuillez noter que le chargement d'objets de classes arbitraires peut être dangereux en Perl. Vous devez charger vous-même les modules, mais si un module exploitable est chargé et qu'un objet est créé, sa méthode "DESTROY" sera appelée lorsque l'objet sortira de portée. File::Temp est un exemple qui peut être exploitable et supprimer des fichiers arbitraires.

La sauvegarde des références de code est activée par défaut, mais pas leur chargement (car cela est facilement exploitable car il utilise l'évaluation de chaînes de caractères "eval").

Styles de balises

Vous pouvez définir le style des balises que vous souhaitez prendre en charge :

my $yp_perl_two_one = YAML::PP->new(
    schema => [qw/ + Perl tags=!!perl+!perl /],
);
"!perl" (par défaut)
Seules les balises "!perl/type" sont supportées.
"!!perl"
Seules les balises "!!perl/type" sont supportées.
"!perl+!!perl"
Les balises "!perl/type" et "!!perl/tag" sont supportées lors du chargement. Lors de la sauvegarde, "!perl/type" est utilisée.
"!!perl+!perl"
Les balises "!perl/type" et "!!perl/tag" sont supportées lors du chargement. Lors de la sauvegarde, "!!perl/type" est utilisée.

YAML.pm, YAML::Syck et YAML::XS utilisent "!!perl/type" lors de la sauvegarde.

YAML.pm et YAML::Syck supportent à la fois "!perl/type" et "!!perl/type" lors du chargement. YAML::XS ne prend en charge actuellement que ce dernier.

Autoriser uniquement certaines classes

Depuis la v0.017

Le blessing d'objets arbitraires peut être dangereux. Peut-être souhaitez-vous autoriser le blessing uniquement de classes spécifiques et ignorer les autres. Pour cela, vous devez instancier un objet Perl Schema au préalable et utiliser l'option "classes".

Actuellement, elle n'autorise qu'une liste de chaînes de caractères :

my $perl = YAML::PP::Schema::Perl->new(
    classes => ['Foo', 'Bar'],
);
my $yp = YAML::PP::Perl->new(
    schema => [qw/ + /, $perl],
);

Les classes autorisées seront chargées et sauvegardées comme d'habitude. Les autres seront ignorées.

Si vous souhaitez n'autoriser aucun objet, passez un tableau vide.

EXEMPLES

Voici une liste des types actuellement supportés et comment ils sont sauvegardés en YAML :

tableau
# Code
[
    qw/ un deux trois quatre /
]
# YAML
---
- un
- deux
- trois
- quatre
tableau_blessed
# Code
bless [
    qw/ un deux trois quatre /
], "Juste::Un::Arrayref"
# YAML
--- !perl/array:Juste::Un::Arrayref
- un
- deux
- trois
- quatre
circulaire
# Code
my $cercle = bless [ 1, 2 ], 'Cercle';
push @$cercle, $cercle;
$cercle;
# YAML
--- &1 !perl/array:Cercle
- 1
- 2
- *1
reference_code
# Code
sub {
    my (%args) = @_;
    return $args{x} + $args{y};
}
# YAML
--- !perl/code |-
  {
      use warnings;
      use strict;
      (my(%args) = @_);
      (return ($args{'x'} + $args{'y'}));
  }
reference_code_blessed
# Code
bless sub {
    my (%args) = @_;
    return $args{x} - $args{y};
}, "Je::Suis::Code"
# YAML
--- !perl/code:Je::Suis::Code |-
  {
      use warnings;
      use strict;
      (my(%args) = @_);
      (return ($args{'x'} - $args{'y'}));
  }
hash
# Code
{
    U => 2,
    B => 52,
}
# YAML
---
B: 52
U: 2
hash_blessed
# Code
bless {
    U => 2,
    B => 52,
}, 'Une::Classe::Très::Exclusive'
# YAML
--- !perl/hash:Une::Classe::Très::Exclusive
B: 52
U: 2
reference_de_reference
# Code
my $ref = { a => 'hash' };
my $refref = \$ref;
$refref;
# YAML
--- !perl/ref
=:
  a: hash
reference_de_reference_blessed
# Code
my $ref = { a => 'hash' };
my $refref = bless \$ref, 'Foo';
$refref;
# YAML
--- !perl/ref:Foo
=:
  a: hash
expression_reguliere
# Code
my $string = 'non_blessed';
qr{$string}
# YAML
--- !perl/regexp non_blessed
expression_reguliere_blessed
# Code
my $string = 'blessed';
bless qr{$string}, "Foo"
# YAML
--- !perl/regexp:Foo blessed
reference_scalaire
# Code
my $scalar = "une chaine";
my $scalarref = \$scalar;
$scalarref;
# YAML
--- !perl/scalar
=: une chaine
reference_scalaire_blessed
# Code
my $scalar = "une autre chaine";
my $scalarref = bless \$scalar, 'Foo';
$scalarref;
# YAML
--- !perl/scalar:Foo
=: une autre chaine

MÉTHODES

new
my $perl = YAML::PP::Schema::Perl->new(
    tags => "!perl",
    classes => ['MyClass'],
    loadcode => 1,
    dumpcode => 1,
);

Le constructeur reconnaît les options suivantes :

tags
Défaut : '"!perl"'

Voir "Styles de balises"

classes
Défaut : "undef"

Depuis : v0.017

Accepte un tableau de noms de classes

loadcode
Défaut : 0
dumpcode
Défaut : 1 
my $yp = YAML::PP->new( schema => [qw/ + Perl -dumpcode /] );
register
Une méthode de classe appelée par YAML::PP::Schema
construct_ref, represent_ref
Les variables Perl de type "REF" sont représentées en yaml comme suit : 
--- !perl/ref
=:
  a: 1

"construct_ref" retourne les données Perl :

my $data = YAML::PP::Schema::Perl->construct_ref([ '=', { some => 'data' } ]);
my $data = \{ a => 1 };

"represent_ref" transforme une variable "REF" en un mappage YAML :

my $data = YAML::PP::Schema::Perl->represent_ref(\{ a => 1 });
my $data = { '=' => { a => 1 } };
construct_scalar, represent_scalar
Les références scalaires sont représentées en yaml comme suit : 
--- !perl/scalar
=: une chaine

"construct_scalar" retourne les données Perl :

my $data = YAML::PP::Schema::Perl->construct_scalar([ '=', 'une chaine' ]);
my $data = \{ a => 1 };

"represent_scalar" transforme une référence scalaire en un mappage YAML :

my $data = YAML::PP::Schema::Perl->represent_scalar(\"une chaine\");
my $data = { '=' => \"une chaine\" };
construct_array, represent_array
Les tableaux sont représentés comme des listes YAML : 
---
- un
- deux

"construct_array" retourne les données Perl :

my $data = YAML::PP::Schema::Perl->construct_array([ '=', [ 'un', 'deux' ] ]);
my $data = [ 'un', 'deux' ];

"represent_array" transforme un tableau Perl en une liste YAML :

my $data = YAML::PP::Schema::Perl->represent_array([ 'un', 'deux' ]);
my $data = [ 'un', 'deux' ];
construct_hash, represent_hash
Les hachages sont représentés comme des mappages YAML : 
---
a: 1
b: 2

"construct_hash" retourne les données Perl :

my $data = YAML::PP::Schema::Perl->construct_hash([ '=', { a => 1, b => 2 } ]);
my $data = { a => 1, b => 2 };

"represent_hash" transforme un hachage Perl en un mappage YAML :

my $data = YAML::PP::Schema::Perl->represent_hash({ a => 1, b => 2 });
my $data = { a => 1, b => 2 };
construct_code, represent_code
Les références de code sont représentées en yaml comme suit : 
--- !perl/code |-
  {
      use warnings;
      use strict;
      (my(%args) = @_);
      (return ($args{'x'} - $args{'y'}));
  }

"construct_code" retourne les données Perl :

my $data = YAML::PP::Schema::Perl->construct_code([ '=', $code_string ]);
my $code = eval $code_string;

"represent_code" transforme une référence de code en une chaîne YAML :

my $data = YAML::PP::Schema::Perl->represent_code(sub { ... });
my $yaml_string = "!perl/code |-\n  ...\n";
construct_regexp, represent_regexp
Les expressions régulières sont représentées en yaml comme suit : 
--- !perl/regexp nomatch

"construct_regexp" retourne les données Perl :

my $data = YAML::PP::Schema::Perl->construct_regexp([ '=', 'nomatch' ]);
my $regex = qr/nomatch/;

"represent_regexp" transforme une expression régulière Perl en une chaîne YAML :

my $data = YAML::PP::Schema::Perl->represent_regexp(qr/nomatch/);
my $yaml_string = \"!perl/regexp nomatch\";
construct_object, represent_object
Les objets sont représentés en yaml comme suit : 
--- !perl/object:MyClass
data:
  ...

"construct_object" retourne les données Perl :

my $data = YAML::PP::Schema::Perl->construct_object([ '=', 'MyClass', { data => '...' } ]);
my $obj = MyClass->new( ... );

"represent_object" transforme un objet Perl en un mappage YAML :

my $data = YAML::PP::Schema::Perl->represent_object($obj);
my $yaml_string = \"!perl/object:MyClass\n...\";

VOIR AUSSI

YAML::PP, YAML::PP::Schema

t_scalar,">construct_scalar, represent_scalar
Les variables Perl du type "SCALAR" sont représentées en YAML comme suit : 
--- !perl/scalar
=: string

"construct_scalar" retourne les données perl :

my $data = YAML::PP::Schema::Perl->construct_ref([ '=', 'string' );
my $data = \'string';

"represent_scalar" transforme une variable "SCALAR" en un mapping YAML :

my $data = YAML::PP::Schema::Perl->represent_scalar(\'string');
my $data = { '=' => 'string' };
construct_regex, represent_regex
"construct_regex" retourne un objet "qr{}" à partir de la chaîne YAML : 
my $qr = YAML::PP::Schema::Perl->construct_regex('foo.*');

"represent_regex" retourne une chaîne représentant l'objet regex :

my $string = YAML::PP::Schema::Perl->represent_regex(qr{...});
evaluate_code, represent_code
"evaluate_code" retourne une référence de code à partir d'une chaîne. La chaîne doit commencer par un "{" et se terminer par un "}". 
my $code = YAML::PP::Schema::Perl->evaluate_code('{ return 23 }');

"represent_code" retourne une représentation chaîne de la référence de code à l'aide de B::Deparse :

my $string = YAML::PP::Schema::Perl->represent_code(sub { return 23 });
construct_glob, represent_glob
"construct_glob" retourne un glob à partir d'un hash. 
my $glob = YAML::PP::Schema::Perl->construct_glob($hash);

"represent_glob" retourne une représentation hash du glob.

my $hash = YAML::PP::Schema::Perl->represent_glob($glob);
object
Fait la même chose que "bless" : 
my $object = YAML::PP::Schema::Perl->object($data, $class);
