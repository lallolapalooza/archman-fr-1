YAML__Any(3pm)

Paquet: perl-yaml

Licences: GPL, PerlArtistic

YAML::Any(3) Documentation Perl fournie par les contributeurs YAML::Any(3)

NOM

YAML::Any - Choisit une implémentation YAML et l'utilise.

STATUT

AVERTISSEMENT : Ce module sera bientôt déprécié. Le plan est que YAML.pm lui-même agira comme un module Any.

SYNTAXE

use YAML::Any;
$YAML::Indent = 3;
my $yaml = Dump(@objects);

DESCRIPTION

Il existe plusieurs implémentations YAML qui prennent en charge l'API Dump/Load. Ce module sélectionne la meilleure disponible et l'utilise.

ORDRE

Actuellement, YAML::Any choisira la première de ces implémentations YAML qui est installée sur votre système :

  • YAML::XS
  • YAML::Syck
  • YAML::Old
  • YAML
  • YAML::Tiny

OPTIONS

Si vous spécifiez une option comme :

$YAML::Indent = 4;

Et si YAML::Any utilise YAML::XS, il utilisera la variable appropriée : $YAML::XS::Indent.

SOUS-PROGRAMMES

Comme tous les modules YAML que YAML::Any utilise, les sous-programmes suivants sont exportés par défaut :

  • Dump
  • Load

et les sous-programmes suivants peuvent être exportés sur demande :

  • DumpFile
  • LoadFile

MÉTHODES

YAML::Any fournit les méthodes de classe suivantes.

"YAML::Any->order"
Cette méthode renvoie une liste des implémentations possibles que YAML::Any recherchera.
"YAML::Any->implementation"
Cette méthode renvoie l'implémentation que YAML::Any utilisera. Ce résultat est obtenu en trouvant le premier membre de YAML::Any->order qui est soit déjà chargé dans %INC, soit qui peut être chargé en utilisant "require". Si aucune implémentation n'est trouvée, une erreur sera générée.

EXEMPLES

DumpFile et LoadFile

Voici un exemple pour "DumpFile" :

#!/usr/bin/perl
use strict;
use warnings;
use YAML::Any qw(DumpFile);
my $ds =
{
    array => [5,6,100],
    string => "Hello",
};
DumpFile("hello.yml", $ds);

Lors de son exécution, cela crée un fichier appelé "hello.yml" dans le répertoire de travail actuel, avec le contenu suivant.

---
array:
- 5
- 6
- 100
string: Hello

En retour, l'exemple "LoadFile" suivant charge le contenu à partir de là et y accède :

#!/usr/bin/perl
use strict;
use warnings;
use YAML::Any qw(LoadFile);
my ($ds) = LoadFile("hello.yml");
print "String == '", $ds->{string}, "'\n";

En supposant que "hello.yml" existe et est tel que créé par l'exemple "DumpFile", cela affiche :

$ perl load.pl
String == 'Hello'
$
