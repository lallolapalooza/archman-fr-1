NOM

YAML::PP::Schema::Binary - Schéma pour le chargement et les données binaires

SYNOPSIS

use YAML::PP;
my $yp = YAML::PP->new( schema => [qw/ + Binary /] );
# ou
my ($binary, $same_binary) = $yp->load_string(<<'EOM');
--- !!binary "\
  R0lGODlhDAAMAIQAAP//9/X17unp5WZmZgAAAOfn515eXvPz7Y6OjuDg4J+fn5\
  OTk6enp56enmlpaWNjY6Ojo4SEhP/++f/++f/++f/++f/++f/++f/++f/++f/+\
  +f/++f/++f/++f/++f/++SH+Dk1hZGUgd2l0aCBHSU1QACwAAAAADAAMAAAFLC\
  AgjoEwnuNAFOhpEMTRiggcz4BNJHrv/zCFcLiwMWYNG84BwwEeECcgggoBADs="
--- !!binary |
  R0lGODlhDAAMAIQAAP//9/X17unp5WZmZgAAAOfn515eXvPz7Y6OjuDg4J+fn5
  OTk6enp56enmlpaWNjY6Ojo4SEhP/++f/++f/++f/++f/++f/++f/++f/++f/+
  +f/++f/++f/++f/++f/++SH+Dk1hZGUgd2l0aCBHSU1QACwAAAAADAAMAAAFLC
  AgjoEwnuNAFOhpEMTRiggcz4BNJHrv/zCFcLiwMWYNG84BwwEeECcgggoBADs=
# La valeur binaire ci-dessus est une petite flèche encodée en tant qu'image gif.
EOM

DESCRIPTION

Voir https://yaml.org/type/binary.html

En préfixant une chaîne binaire encodée en base64 avec le marqueur "!!binary", elle peut être automatiquement décodée lors du chargement.

Notez que la logique de vidage est probablement cassée, voir https://github.com/perlpunk/YAML-PP-p5/issues/28.

Suggestions bienvenues.
