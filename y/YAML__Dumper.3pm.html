NOM

YAML::Dumper - Classe YAML pour la sérialisation d'objets Perl en YAML

SYNOPSIS

use YAML::Dumper;
my $dumper = YAML::Dumper->new;
$dumper->indent_width(4);
print $dumper->dump({foo => 'bar'});

DESCRIPTION

YAML::Dumper est le module que YAML.pm utilisait pour sérialiser les objets Perl en YAML. Il est entièrement orienté objet et peut être utilisé de manière autonome.
