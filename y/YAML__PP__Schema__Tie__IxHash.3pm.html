NOM

YAML::PP::Schema::Tie::IxHash - (Obsolète) Schéma pour la sérialisation de hachages ordonnés

SYNOPSIS

use YAML::PP;
use Tie::IxHash;
my $yp = YAML::PP->new( schema => [qw/ + Tie::IxHash /] );
tie(my %ordered, 'Tie::IxHash');
%ordered = (
    U => 2,
    B => 52,
);
my $yaml = $yp->dump_string(\%ordered);
# Sortie :
---
U: 2
B: 52

DESCRIPTION

Ceci est obsolète. Voir la nouvelle option "preserve" dans YAML::PP.

Ce schéma vous permet de sauvegarder des hachages ordonnés qui sont liés à Tie::IxHash.

Ce code est assez nouveau et expérimental.

Il n'est pas encore implémenté pour le chargement, donc pour l'instant vous devez lier vous-même les hachages.

Exemples :

ordre
# Code
tie(my %order, 'Tie::IxHash');
%order = (
    U => 2,
    B => 52,
    c => 64,
    19 => 84,
    Disco => 2000,
    Year => 2525,
    days_on_earth => 20_000,
);
\%order;
# YAML
---
U: 2
B: 52
c: 64
19: 84
Disco: 2000
Year: 2525
days_on_earth: 20000
ordre_blessé
# Code
tie(my %order, 'Tie::IxHash');
%order = (
    U => 2,
    B => 52,
    c => 64,
    19 => 84,
    Disco => 2000,
    Year => 2525,
    days_on_earth => 20_000,

bless \%order, 'Order';

--- !perl/hash:Order

Disco: 2000

days_on_earth: 20000
