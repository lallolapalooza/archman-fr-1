NOM

YAML::Types - Marshall des types de données internes Perl vers/depuis YAML

SYNOPSIS

$::foo = 42;
print YAML::Dump(*::foo);
print YAML::Dump(qr{match me});

DESCRIPTION

Ce module contient les classes d'aide pour transférer des objets, des sous-routines, des références, des globs, des expressions régulières et des fichiers vers et depuis YAML.
