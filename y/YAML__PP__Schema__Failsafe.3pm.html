NOM

YAML::PP::Schema::Failsafe - Schéma Failsafe de YAML 1.2

SYNOPSIS

my $yp = YAML::PP->new( schema => ['Failsafe'] );

DESCRIPTION

Avec ce schéma, tout sera traité comme une chaîne de caractères. Il n'y a pas de booléens, d'entiers, de nombres flottants ou de valeurs indéfinies.

Vous pouvez voir ici tous les schémas et exemples implémentés par YAML::PP : https://perlpunk.github.io/YAML-PP-p5/schemas.html

Schéma officiel : https://yaml.org/spec/1.2/spec.html#id2802346
