YAML::PP::Emitter(3) Documentation Perl fournie par l'utilisateur YAML::PP::Emitter(3)

NOM

YAML::PP::Emitter - Émission d'événements

SYNTAXE

my $emitter = YAML::PP::Emitter->new(
    indent => 4,
);
$emitter->init;
$emitter->stream_start_event;
$emitter->document_start_event({ implicit => 1 });
$emitter->sequence_start_event;
$emitter->scalar_event({ value => $input, style => $style });
$emitter->sequence_end_event;
$emitter->document_end_event({ implicit => 1 });
$emitter->stream_end_event;
my $yaml = $emitter->writer->output;
$emitter->finish;

DESCRIPTION

L'émetteur émet des événements vers YAML. Il fournit des méthodes pour chaque type d'événement. Les arguments sont en grande partie les mêmes que ceux des événements de YAML::PP::Parser.

MÉTHODES

new
my $emitter = YAML::PP::Emitter->new(
    indent => 4,
);

Constructeur. Accepte actuellement les options suivantes :

indent
writer
stream_start_event, stream_end_event, document_start_event, document_end_event, sequence_start_event, sequence_end_event, mapping_start_event, mapping_end_event, scalar_event, alias_event
indent, set_indent
Accesseur/mutateur pour le nombre d'espaces d'indentation.

TODO : Actuellement, les séquences sont toujours indentées à zéro.

writer, set_writer
Accesseur/mutateur pour l'objet rédacteur. Par défaut YAML::PP::Writer. Vous pouvez passer votre propre rédacteur si vous souhaitez produire le YAML résultant vous-même.
init
Initialiser
finish
