YAML::PP::Schema::JSON(3) Documentation Perl Contribuée par l'Utilisateur YAML::PP::Schema::JSON(3)

NOM

YAML::PP::Schema::JSON - Schéma JSON YAML 1.2

SYNOPSIS

my $yp = YAML::PP->new( schema => ['JSON'] );
my $yp = YAML::PP->new( schema => [qw/ JSON empty=str /] );
my $yp = YAML::PP->new( schema => [qw/ JSON empty=null /] );

DESCRIPTION

Avec ce schéma, la résolution des valeurs simples fonctionnera comme en JSON. Tout ce qui correspond à une valeur spéciale sera chargé comme telle, les autres scalaires simples seront chargés comme des chaînes de caractères.

Notez que c'est différent du schéma JSON officiel YAML 1.2, où toutes les chaînes de caractères doivent être entre guillemets.

Vous pouvez trouver ici tous les schémas et exemples implémentés par YAML::PP : https://perlpunk.github.io/YAML-PP-p5/schemas.html

Schéma officiel : https://yaml.org/spec/1.2/spec.html#id2803231

CONFIGURATION

Le schéma JSON officiel YAML 1.2 exige que toutes les chaînes de caractères soient entre guillemets. YAML::PP ne l'exige actuellement pas (cela pourrait être une option à l'avenir).

Cela signifie qu'aucun nœud vide n'est autorisé dans le schéma officiel. Exemple :

---
key:

Le comportement par défaut de YAML::PP::Schema::JSON est de renvoyer une chaîne de caractères vide, donc ce serait équivalent à :

---
key: ''

Vous pouvez le configurer pour résoudre cela comme "undef" :

my $yp = YAML::PP->new( schema => [qw/ JSON empty=null /] );

De cette façon, c'est équivalent à :

---
key: null

La valeur par défaut est :

my $yp = YAML::PP->new( schema => [qw/ JSON empty=str /] );
