NOM

YAML::PP::Writer - Écrire la sortie YAML

SYNTAXE

my $writer = YAML::PP::Writer->new;

DESCRIPTION

Le YAML::PP::Emitter envoie sa sortie vers l'écrivain.

Vous pouvez utiliser votre propre écrivain si vous souhaitez envoyer la sortie YAML ailleurs. Voir t/44.writer.t pour un exemple.

MÉTHODES

new
my $writer = YAML::PP::Writer->new;

Constructeur.

write
$writer->write('- ');
init
$writer->init;

Initialiser

finish
$writer->finish;

Est appelé lorsque la sortie se termine.

output, set_output
