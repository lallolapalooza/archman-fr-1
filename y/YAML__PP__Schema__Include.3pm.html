NOM

YAML::PP::Schema::Include - Inclure des fichiers YAML

SYNTAXE

# /chemin/vers/fichier.yaml
# ---
# inclus: !include include/fichier2.yaml
# /chemin/vers/include/fichier2.yaml
# ---
# a: b
my $include = YAML::PP::Schema::Include->new;
my $yp = YAML::PP->new( schema => ['+', $include] );
# nous avons besoin de l'objet YAML::PP original pour obtenir le nom de fichier actuel
# et pour charger un autre fichier
$include->yp($yp);
my ($data) = $yp->load_file("/chemin/vers/fichier.yaml");
# Le résultat sera :
$data = {
    inclus => { a => 'b' }
};

Autoriser les noms de fichiers absolus et la remontée '..' :

my $include = YAML::PP::Schema::Include->new(
    allow_absolute => 1, # défaut : 0
);

Spécifier les chemins de recherche des inclusions :

my @chemins_inclusion = ("/chemin/vers/include/yaml/1", "/chemin/vers/include/yaml/2");
my $include = YAML::PP::Schema::Include->new(
    paths => \@chemins_inclusion,
);
my $yp = YAML::PP->new( schema => ['+', $include] );
$include->yp($yp);
# /chemin/vers/include/yaml/1/fichier1.yaml
# ---
# a: b
my $yaml = <<'EOM';
- inclus: !include fichier1.yaml
EOM
my ($data) = $yp->load_string($yaml);

DESCRIPTION

Ce plugin vous permet de diviser un gros fichier YAML en plus petits. Vous pouvez ensuite inclure ces fichiers avec le tag "!include".

Il recherchera le nom de fichier spécifié relativement au nom de fichier actuellement traité.

Vous pouvez également spécifier les chemins où chercher les fichiers à inclure. Il itère sur les chemins et retourne le premier nom de fichier qui existe.

Par défaut, seuls les chemins relatifs sont autorisés. Toute occurrence de "../" dans le chemin sera supprimée. Vous pouvez modifier ce comportement en réglant l'option "allow_absolute" sur vrai.

Si le fichier inclus contient plusieurs documents, seul le premier sera inclus.

Je vais probablement ajouter une possibilité de retourner tous les documents sous forme de tableau.

Le fichier YAML inclus sera chargé en créant un nouvel objet YAML::PP avec le schéma de l'objet existant. De cette façon, vous pouvez inclure des fichiers de manière récursive.

Vous pouvez même réutiliser la même inclusion via un alias :

---
facture:
    adresse de livraison: &adresse !include adresse.yaml
    adresse de facturation: *adresse

Les inclusions circulaires seront détectées et seront fatales.

Il est possible de spécifier quoi faire du fichier inclus :

my $include = YAML::PP::Schema::Include->new(
    loader => sub {
        my ($yp, $filename);
        if ($filename =~ m/\.txt$/) {
            # ouvrir le fichier et simplement retourner le texte
        }
        else {
            # comportement par défaut
            return $yp->load_file($filename);
        }
    },
);

Par exemple, RAML définit un tag "!include" qui dépend du contenu du fichier. S'il contient une directive RAML spéciale, il sera chargé comme YAML, sinon le contenu du fichier sera inclus sous forme de chaîne.

Ainsi, avec ce plugin, vous êtes capable de lire des spécifications RAML.
