NOM

YAML::PP::Schema::Core - Schéma Core de YAML 1.2

SYNOPSIS

my $yp = YAML::PP->new( schema => ['Core'] );

DESCRIPTION

Ce schéma est le schéma Core officiel recommandé pour YAML 1.2. Il charge des valeurs supplémentaires au schéma JSON en tant que types spéciaux, par exemple "TRUE" et "True" en plus de "true".

Schéma officiel : https://yaml.org/spec/1.2/spec.html#id2804923

Vous pouvez trouver ici tous les schémas et exemples implémentés par YAML::PP : https://perlpunk.github.io/YAML-PP-p5/schemas.html
