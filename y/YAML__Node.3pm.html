NOM

YAML::Node - Un nœud de données générique qui encapsule les informations YAML

SYNOPIS

use YAML;
use YAML::Node;
my $ynode = YAML::Node->new({}, 'ingerson.com/fruit');
%$ynode = qw(orange orange apple red grape green);
print Dump $ynode;

génère :

--- !ingerson.com/fruit
orange: orange
apple: red
grape: green

DESCRIPTION

Un nœud YAML générique est similaire à un nœud de hachage, de tableau ou scalaire simple en Perl, sauf qu'il doit également conserver une trace de son type. Le type est une URI appelée balise de type YAML.

YAML::Node est une classe pour générer et manipuler ces conteneurs. Un nœud YAML (ou ynode) est un hachage, un tableau ou un scalaire lié. Dans la plupart des cas, il se comporte comme la chose ordinaire. Mais vous pouvez lui attribuer et récupérer une URI de balise de type YAML. Pour la saveur de hachage, vous pouvez également attribuer l'ordre dans lequel les clés seront récupérées. Par défaut, un ynode proposera ses clés dans le même ordre qu'elles ont été attribuées.

YAML::Node a un appel de méthode de classe new() qui retournera un ynode. Vous lui passez un nœud régulier et une balise de type facultative. Après cela, vous pouvez l'utiliser comme un nœud Perl normal, mais lorsque vous l'utiliserez avec YAML::Dump, les propriétés magiques seront respectées.

C'est ainsi que vous pouvez contrôler l'ordre de tri des clés de hachage lors d'une sérialisation YAML. Par défaut, YAML trie les clés par ordre alphabétique. Mais remarquez dans l'exemple ci-dessus que les clés ont été Dumped dans le même ordre qu'elles ont été attribuées.

YAML::Node exporte une fonction appelée ynode(). Cette fonction retourne l'objet lié afin que vous puissiez appeler des méthodes spéciales dessus comme ->keys().

keys() fonctionne comme suit :

use YAML;
use YAML::Node;
%$node = qw(orange orange apple red grape green);
$ynode = YAML::Node->new($node);
ynode($ynode)->keys(['grape', 'apple']);
print Dump $ynode;

produit :

---
grape: green
apple: red

Il indique au ynode quelles clés et dans quel ordre utiliser.

Les ynodes joueront un rôle très important dans la façon dont les programmes utilisent YAML. Ils sont le fondement de la manière dont une classe Perl peut organiser le chargement et le déchargement de ses objets.

Les prochaines versions de YAML.pm contiendront beaucoup plus d'informations à ce sujet.
