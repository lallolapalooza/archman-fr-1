NOM

emptty - Gestionnaire d'affichage CLI simple comme bonjour sur TTY

SYNTAXE

emptty [-v] [--version] [-d] [--daemon] [-c CHEMIN] [--config CHEMIN] [-i] [--ignore-config] [-t TTY] [--tty TTY] [-u utilisateurParDéfaut] [--default-user utilisateurParDéfaut] [-a [session]] [--autologin [session]]

DESCRIPTION

emptty est un gestionnaire d'affichage CLI simple, qui permet de sélectionner un environnement de bureau/gestionnaire de fenêtres après la connexion, d'utiliser une configuration prédéfinie ou d'autoriser la connexion automatique si l'utilisateur sélectionné fait partie du groupe nopasswdlogin.

OPTIONS

-v, --version
Affiche la version du programme.
-d, --daemon
Lance emptty en tant que démon, ce qui ne nécessite pas agetty.
-c, --config CHEMIN
Charge la configuration à partir du chemin spécifié.
-C, --print-config
Imprime uniquement la configuration chargée et quitte.
-i, --ignore-config
Ignore le chargement de la configuration depuis le fichier, charge uniquement la configuration des arguments.
-t, --tty TTY
Remplace la configuration chargée en définissant le TTY spécifié. Peut être spécifié comme un nombre (par exemple, « 7 ») ou un nom de TTY (par exemple, « tty7 »).
-u, --default-user utilisateurParDéfaut
Remplace la configuration chargée en définissant l'utilisateur par défaut spécifié.
-a, --autologin [session]
Remplace la configuration chargée en activant la connexion automatique. Si une session est définie, elle remplace la session de connexion automatique.

Environnement optionnel de la session de bureau présélectionnée, si l'utilisateur n'utilise pas le fichier `emptty`. Les valeurs possibles sont « xorg » et « wayland ».

Active la connexion automatique si DEFAULT_USER est défini. Les valeurs possibles sont « true » ou « false ». Valeur par défaut : false.

AUTOLOGIN_SESSION
La session par défaut utilisée si la connexion automatique est activée. Si la session n'est pas trouvée dans la liste des sessions, la sélection manuelle est poursuivie.
AUTOLOGIN_SESSION_ENV
Environnement optionnel de la session de bureau en connexion automatique. Les valeurs possibles sont « xorg » et « wayland ».
AUTOLOGIN_MAX_RETRY
Si une session ne démarre pas correctement dans une période donnée, le nombre de tentatives dans une courte période est conservé pour éventuellement arrêter la boucle infinie de redémarrages. -1 signifie des tentatives infinies, 0 signifie aucune tentative. Valeur par défaut : 2.
AUTOLOGIN_RETRY_PERIOD
Période de temps en secondes, utilisée pour vérifier les tentatives de connexion de session. Valeur par défaut : 2.
LANG
définit la locale pour tous les utilisateurs. Valeur par défaut : « en_US.UTF-8 »
DBUS_LAUNCH
Démarre « dbus-launch » avant la commande d'affichage. Après la fin de la session, « dbus-daemon » est interrompu. Valeur par défaut : vrai. Si la configuration utilisateur est traitée comme un script (ne contient pas l'option Exec), cette configuration est remplacée par false.
ALWAYS_DBUS_LAUNCH
Démarre « dbus-launch » avant la commande d'affichage dans tous les cas, la valeur de DBUS_LAUNCH est ignorée. Il démarre également si XINITRC_LAUNCH est défini sur `true`. Après la fin de la session, « dbus-daemon » est interrompu. Valeur par défaut : false.
XINITRC_LAUNCH
Démarre le bureau Xorg en appelant le script ~/.xinitrc avec la session exec en argument. Si vrai, le fichier existe et le WM/DE sélectionné est une session Xorg, cela remplace DBUS_LAUNCH. Si la configuration utilisateur est traitée comme un script (ne contient pas l'option Exec), cette configuration est remplacée par false.
VERTICAL_SELECTION
Affiche chaque environnement de bureau/gestionnaire de fenêtres disponible sur une nouvelle ligne au lieu de les afficher sur une seule ligne.
INDENT_SELECTION
Décalage horizontal pour la sélection verticale, utile pour centrer le menu à l'écran.
LOGGING

COMMAND

S

Si les commandes sont autorisées et qu'aucun utilisateur par défaut n'est défini, il est possible d'utiliser des commandes dans la saisie de connexion. Toutes ces commandes doivent commencer par deux-points ":". Les caractères d'échappement sont ignorés pour éviter les problèmes liés à la mémoire musculaire de VI.
- :help, :? - affiche les commandes disponibles
- :poweroff, :shutdown - traite la commande d'arrêt
- :reboot - traite la commande de redémarrage
