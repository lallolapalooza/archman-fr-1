EMACSCLIENT(1) GNU EMACSCLIENT(1)

NOM

emacsclient - demande à un Emacs en cours d'exécution d'ouvrir un fichier

SYNTAXE

emacsclient [options] fichiers ...

DESCRIPTION

Cette page de manuel documente brièvement la commande emacsclient. La documentation complète est disponible au format GNU Info ; voir ci-dessous.

emacsclient fonctionne en conjonction avec le serveur intégré d'Emacs.

Vous pouvez soit appeler emacsclient directement, soit laisser d'autres programmes l'appeler pour vous lorsque c'est nécessaire. Sur les systèmes GNU et Unix, de nombreux programmes consultent la variable d'environnement EDITOR (parfois aussi VISUAL) pour obtenir la commande utilisée pour l'édition. Ainsi, définir cette variable d'environnement sur 'emacsclient' permettra à ces programmes d'utiliser un Emacs déjà en cours d'exécution pour l'édition. D'autres systèmes d'exploitation peuvent avoir leurs propres méthodes pour définir l'éditeur par défaut.

Pour que emacsclient fonctionne, vous avez besoin d'un Emacs déjà en cours d'exécution avec un serveur. Dans Emacs, appelez les fonctions « server-start » ou « server-mode ». (Votre fichier « .emacs » peut le faire automatiquement si vous y ajoutez soit « (server-start) » soit « (server-mode 1) ».)

Lorsque vous avez terminé l'édition du tampon, tapez « C-x # » (« server-edit »). Cela enregistre le fichier et renvoie un message au programme emacsclient lui indiquant de se terminer. Les programmes qui utilisent EDITOR attendent que l'« éditeur » (en fait, emacsclient) se termine. « C-x # » vérifie également d'autres demandes externes en attente d'édition de divers fichiers, et sélectionne le fichier suivant.

Si vous définissez la variable « server-window » sur une fenêtre ou un cadre, « C-x # » affiche le tampon du serveur dans cette fenêtre ou dans ce cadre.

OPTIONS

La plupart des options suivent la syntaxe habituelle de ligne de commande GNU, avec des options longues commençant par deux tirets (« - »).

+ligne[:colonne]
Accéder à la ligne et colonne spécifiées. Une colonne manquante est traitée comme la colonne 1. Cette option ne s'applique qu'au fichier spécifié suivant.
-a, --alternate-editor=COMMANDE
Si le serveur Emacs ne fonctionne pas, exécutez la commande shell spécifiée à la place. Si la chaîne vide est spécifiée, exécutez « emacs --daemon » pour démarrer Emacs en mode démon, et essayez de vous y connecter.

Voir aussi la variable d'environnement ALTERNATE_EDITOR, sur laquelle cette option a priorité.

-c, --create-frame
Créer un nouveau cadre au lieu d'essayer d'utiliser le cadre Emacs actuel.
-r --reuse-frame
Réutiliser un cadre existant s'il y en a un, sinon en créer un nouveau.
-F, --frame-parameters=ALISTE
Définir les paramètres d'un cadre nouvellement créé.
-d, --display=AFFICHAGE
Demander au serveur d'afficher les fichiers sur l'affichage donné.
-e, --eval
Ne pas ouvrir de fichiers mais évaluer les arguments comme des expressions Emacs Lisp.
-f, --server-file=FICHIER
Utiliser le fichier de configuration TCP FICHIER pour la communication. Les noms de fichiers relatifs sont relatifs à « ~/.emacs.d/server/ » ou « $XDG_CONFIG_HOME/emacs/server/ », et le défaut est « server ».

Voir aussi la variable d'environnement EMACS_SERVER_FILE, sur laquelle cette option a priorité.

-n, --no-wait
Retourner immédiatement sans attendre que vous « terminiez » le tampon dans Emacs. Si combinée avec --eval, cette option est ignorée.
-w, --timeout=N
Durée d'attente, en secondes, avant d'abandonner si Emacs ne répond pas. La valeur par défaut est 0, ce qui signifie attendre indéfiniment.
--parent-id=ID
Ouvrir un cadre emacsclient comme cadre client dans la fenêtre X parente avec l'ID ID.
-q, --quiet
Ne pas laisser emacsclient afficher de messages concernant l'attente d'Emacs ou la connexion à des sockets de serveur distants.
-u, --suppress-output
Ne pas laisser emacsclient afficher les résultats renvoyés par le serveur. Principalement utile en combinaison avec --eval lorsque l'évaluation effectuée est pour un effet de bord plutôt que pour un résultat.
-s, --socket-name=FICHIER
Utiliser le socket nommé FICHIER pour la communication. Les noms de fichiers relatifs sont relatifs à « $XDG_RUNTIME_DIR/emacs/ » ou « $TMPDIR/ ».

Voir aussi la variable d'environnement EMACS_SOCKET_NAME, sur laquelle cette option a priorité.

-nw, -t, --tty, --no-window-system
Ouvrir un nouveau cadre Emacs sur le terminal actuel.
-T, --tramp=PREFIXE
Définir PREFIXE à ajouter aux noms de fichiers pour qu'Emacs localise les fichiers sur des machines distantes en utilisant TRAMP. Ceci est principalement utile en combinaison avec l'utilisation du serveur Emacs sur un hôte distant (soit en utilisant TCP avec --server-file, soit un socket transféré via SSH).

Voir aussi la variable d'environnement EMACSCLIENT_TRAMP, sur laquelle cette option a priorité.

-V, --version
Afficher les informations de version et quitter.
-H, --help
Afficher ce message d'aide et quitter.

STATUT DE SORTIE

Normalement, le statut de sortie est 0. Si emacsclient se termine en raison d'une erreur signalée par Emacs, le statut de sortie est 1.

ENVIRONNEMENT

ALTERNATE_EDITOR
Si le serveur Emacs ne fonctionne pas, exécutez la commande shell contenue dans cette variable d'environnement à la place. Si elle est définie sur la chaîne vide, exécutez « emacs --daemon » pour démarrer Emacs en mode démon et essayer de vous y connecter. Sera remplacée par l'option --alternate-editor, si elle est présente.
EMACSCLIENT_TRAMP
Un préfixe à ajouter aux noms de fichiers, destiné à permettre à Emacs de localiser des fichiers sur des machines distantes en utilisant TRAMP. Sera remplacée par l'option --tramp, si elle est présente.
EMACS_SERVER_FILE
Rechercher dans ce fichier pour découvrir où trouver un serveur Emacs TCP. Les noms de fichiers relatifs sont relatifs à « ~/.emacs.d/server/ » ou « $XDG_CONFIG_HOME/emacs/server/ », et le défaut est « server ». Sera remplacée par l'option --server-file, si elle est présente.
EMACS_SOCKET_NAME
Le nom du fichier socket à utiliser pour la communication avec le serveur Emacs. Les noms de fichiers relatifs sont relatifs à « $XDG_RUNTIME_DIR/emacs/ » ou « $TMPDIR/ ». Sera remplacée par l'option --socket-name, si elle est présente.

VOIR AUSSI

Le programme est entièrement documenté dans Using Emacs as a Server disponible via le système Info.

Les variables d'environnement XDG sont décrites en détail dans la Spécification des répertoires de base XDG.
