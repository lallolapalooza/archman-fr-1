NOM

Email::Abstract::MIMEEntity - Wrapper Email::Abstract pour MIME::Entity

VERSION

version 3.010

DESCRIPTION

Ce module encapsule la bibliothèque de gestion des e-mails MIME::Entity avec une interface abstraite, à utiliser avec Email::Abstract.

VERSION PERL

Cette bibliothèque devrait fonctionner sur des versions Perl même très anciennes. Elle devrait fonctionner sur n'importe quelle version de Perl publiée au cours des cinq dernières années.

Bien qu'elle puisse fonctionner sur des versions plus anciennes de Perl, aucune garantie n'est faite quant à l'augmentation de la version minimum requise. La version peut être augmentée pour quelque raison que ce soit, et il n'y a aucune promesse que des correctifs seront acceptés pour abaisser la version minimale requise de Perl.

VOIR AUSSI
