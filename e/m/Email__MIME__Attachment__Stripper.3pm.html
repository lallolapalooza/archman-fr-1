NOM

Email::MIME::Attachment::Stripper - supprimer les pièces jointes d'un courriel

VERSION

version 1.317

SYNTAXE

my $stripper = Email::MIME::Attachment::Stripper->new($mail);
my $msg = $stripper->message;
my @attachments = $stripper->attachments;

DESCRIPTION

Étant donné un objet Email::MIME, détache toutes les pièces jointes du message et les rend disponibles séparément.

Le message restant peut toujours être multipart, mais il ne devrait être que multipart/alternative ou multipart/related.

Étant donné ce message :

+ multipart/mixed
  - text/plain
  - application/pdf; disposition=attachment

Le PDF sera supprimé. On ne garantit pas si le message retourné sera une unique partie text/plain ou un message multipart/mixed avec seulement la partie text/plain restante.

MÉTHODES

new

my $stripper = Email::MIME::Attachment::Stripper->new($email, %args);

Le constructeur peut recevoir un objet Email::MIME, une référence vers une chaîne de caractères, ou toute autre valeur que Email::Abstract (si disponible) peut convertir en un objet Email::MIME.

Les arguments valides incluent :

force_filename - essaie plus fort d'obtenir un nom de fichier, en en créant un si nécessaire

message

my $email_mime = $stripper->message;

Ceci retourne le message avec toutes les pièces jointes détachées. Cela modifiera le corps et l'en-tête du message.

attachments

my @attachments = $stripper->attachments;

Ceci retourne une liste de toutes les pièces jointes trouvées dans le message, sous forme de hachage de { filename, content_type, payload }.

Ceci peut contenir des parties qui ne seraient pas normalement considérées comme des pièces jointes, comme text/html ou multipart/alternative.
