NOM

Email::Sender::Role::CommonSending - les tâches d'envoi communes que la plupart des classes Email::Sender auront besoin

VERSION

version 2.601

DESCRIPTION

Email::Sender::Role::CommonSending fournit un certain nombre de fonctionnalités qui devraient faciliter l'écriture de nouvelles classes qui implémentent le rôle Email::Sender. Au lieu d'écrire une méthode "send", les implémenteurs devront écrire une méthode plus petite "send_email", qui recevra un objet Email::Abstract et une enveloppe contenant des entrées "from" et "to". L'entrée "to" sera garantie d'être un tableau.

Une méthode "success" sera également fournie comme raccourci pour appeler :

Email::Sender::Success->new(...);

Quelques autres petits détails sont gérés par CommonSending ; pour plus d'informations, consultez la source.

Les méthodes documentées ici peuvent être redéfinies pour modifier le comportement du rôle CommonSending.

VERSION PERL

Cette bibliothèque devrait fonctionner sur des versions de Perl sorties même il y a longtemps. Elle devrait fonctionner sur n'importe quelle version de Perl sortie au cours des cinq dernières années.

Bien qu'elle puisse fonctionner sur des versions plus anciennes de Perl, aucune garantie n'est faite que la version minimale requise n'augmentera pas. La version peut être augmentée pour quelque raison que ce soit, et rien ne garantit que des correctifs seront acceptés pour abaisser la version minimale requise de Perl.

MÉTHODES

prepare_email

Cette méthode reçoit un scalaire et est censée renvoyer un objet Email::Abstract. Vous ne devriez probablement pas la redéfinir dans la plupart des cas.

prepare_envelope

Cette méthode reçoit un hashref et renvoie un nouveau hashref qui doit être utilisé comme enveloppe passée à la méthode "send_email". Cette méthode est responsable de s'assurer que l'entrée *to* est un tableau.

success

...
return $self->success;

Cette méthode renvoie un nouvel objet Email::Sender::Success. Les arguments passés à cette méthode sont transmis au constructeur de Success. Ceci est fourni pour faciliter le retour de succès à partir des méthodes "send_email" des sous-classes.
