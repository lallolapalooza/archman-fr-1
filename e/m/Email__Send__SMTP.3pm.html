NOM

Email::Send::SMTP - Envoyer des messages en utilisant SMTP

SYNTAXE

use Email::Send;
my $mailer = Email::Send->new({mailer => 'SMTP'});
$mailer->mailer_args([Host => 'smtp.example.com:465', ssl => 1])
  if $USE_SSL;
$mailer->send($message);

DESCRIPTION

Ce module d'envoi pour "Email::Send" utilise "Net::SMTP" pour envoyer un message avec un serveur SMTP. La première invocation de "send" nécessite des arguments pour le serveur SMTP. Les appels suivants mémoriseront le premier réglage jusqu'à ce qu'il soit réinitialisé.

Tous les arguments passés à "send" seront passés à "Net::SMTP->new()", avec quelques exceptions. "username" et "password", s'ils sont passés, sont utilisés pour invoquer "Net::SMTP->auth()" pour le support d'authentification SASL. "ssl", s'il est défini comme vrai, active le support SSL en utilisant "Net::SMTP::SSL".

SMTP peut échouer pour un certain nombre de raisons. Toutes les valeurs de retour de ce paquet sont vraies ou fausses. Si c'est faux, l'envoi a échoué. Si c'est vrai, l'envoi a réussi. Les valeurs de retour sont des objets "Return::Value", cependant, et contiennent plus d'informations sur ce qui s'est mal passé.

Voici un exemple de gestion de l'échec.

my $return = send SMTP => $message, 'localhost';
die "$return" if ! $return;

La version chaînée de la valeur de retour contiendra le texte de l'erreur. Dans une condition, un échec sera évalué comme faux.

Voici un exemple de gestion du succès. Il arrive que certaines adresses e-mail ne réussissent pas mais que d'autres y parviennent. Dans ce cas, la propriété "bad" de la valeur de retour est définie sur une liste d'adresses incorrectes.

my $return = send SMTP => $message, 'localhost';
if ( $return ) {
    my @bad = @{ $return->prop('bad') };
    warn "Failed to send to: " . join ', ', @bad
      if @bad;
}

Pour plus d'informations sur ces valeurs de retour, voir Return::Value.

GÉNÉRATION_DE_L'ENVELOPPE

L'expéditeur et les destinataires de l'enveloppe sont, par défaut, générés en examinant les en-têtes From, To, Cc et Bcc. Ce comportement peut être modifié en remplaçant les méthodes "get_env_sender" et "get_env_recipients", qui reçoivent toutes deux l'objet Email::Simple et leur seul paramètre, et retournent des adresses e-mail.
