NOM

Email::Date::Format - produire des chaînes de date RFC 2822

VERSION

version 1.008

SYNOPSIS

use Email::Date::Format qw(email_date);
my $header = email_date($date->epoch);
Email::Simple->create(
  header => [
    Date => $header,
  ],
  body => '...',
);

DESCRIPTION

Ce module fournit un moyen simple de générer une chaîne de date et heure conforme à la RFC 2822. (Au cas où cela vous intéresserait, ce ne sont pas des dates RFC 822, car elles utilisent une année à quatre chiffres, ce qui n'est pas autorisé dans la RFC 822.)

VERSION PERL

Cette bibliothèque devrait fonctionner sur des versions de Perl publiées même il y a longtemps. Elle devrait fonctionner sur toute version de Perl publiée au cours des cinq dernières années.

Bien qu'elle puisse fonctionner sur des versions plus anciennes de Perl, aucune garantie n'est faite que la version minimale requise ne sera pas augmentée. La version peut être augmentée pour quelque raison que ce soit, et il n'y a aucune promesse que des correctifs seront acceptés pour abaisser la version minimale de Perl requise.

FONCTIONS

email_date

my $date = email_date; # maintenant
my $date = email_date( time - 60*60 ); # il y a une heure

"email_date" accepte une valeur d'époque, telle que celle retournée par "time". Elle renvoie une chaîne représentant la date et l'heure de l'entrée, comme spécifié dans la RFC 2822. Si aucune valeur d'entrée n'est fournie, la valeur actuelle de "time" est utilisée.

"email_date" n'est exportée que si elle est demandée.

email_gmdate

my $date = email_gmdate;

"email_gmdate" est identique à "email_date", mais elle renverra une chaîne indiquant l'heure en Temps Universel Coordonné (UTC), plutôt qu'en heure locale.

"email_gmdate" n'est exportée que si elle est demandée.
