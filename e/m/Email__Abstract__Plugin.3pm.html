NOM

Email::Abstract::Plugin - une classe de base pour les plugins Email::Abstract

VERSION

version 3.010

VERSION PERL

Cette bibliothèque devrait fonctionner sur des Perl publiés même il y a longtemps. Elle devrait fonctionner sur n'importe quelle version de perl publiée au cours des cinq dernières années.

Bien qu'elle puisse fonctionner sur des versions plus anciennes de perl, aucune garantie n'est donnée que la version minimale requise ne sera pas augmentée. La version peut être augmentée pour quelque raison que ce soit, et il n'est pas promis que des correctifs seront acceptés pour abaisser la version minimale requise de perl.

METHODES

est_disponible

Cette méthode renvoie vrai si le plugin doit être considéré comme disponible pour l'enregistrement. Les plugins qui renvoient faux de cette méthode ne seront pas enregistrés lors du chargement de Email::Abstract.
