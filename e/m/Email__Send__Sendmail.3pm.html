NOM

Email::Send::Sendmail - Envoyer des messages en utilisant sendmail

SYNOPSIS

use Email::Send;
Email::Send->new({mailer => 'Sendmail'})->send($message);

DESCRIPTION

Ce gestionnaire de courrier pour "Email::Send" utilise "sendmail" pour envoyer un message. Il n'essaie pas activement de trouver l'exécutable. Il appelle simplement "sendmail" et s'attend à ce qu'il soit dans votre chemin. Si ce n'est pas le cas, ou si vous souhaitez définir explicitement l'emplacement de votre exécutable, modifiez la variable de package $Email::Send::Sendmail::SENDMAIL.

$Email::Send::Sendmail::SENDMAIL = '/usr/sbin/sendmail';
