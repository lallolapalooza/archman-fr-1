package Email::Send::Example;
sub is_available {
    eval { use Net::Example }

Écrire de nouveaux agents est très simple. Si vous voulez utiliser un nom court lors de l'appel de « send », nommez votre agent sous l'espace de noms « Email::Send ». Si vous ne le faites pas, le nom complet devra être utilisé. Un agent n'a besoin que d'implémenter une seule fonction, « send ». Elle sera appelée depuis « Email::Send » exactement comme

ceci. 
Your::Sending::Package->send($message, @args)
;

$message est un objet Email::Simple, @args sont les arguments supplémentaires passés à « Email::Send::send »

.

Voici un exemple d'agent qui envoie des courriels vers une

URL. 
package Email::Send::HTTP::Post;
use strict;
use vars qw[$AGENT $URL $FIELD];
use Return::Value;
sub is_available {
    eval { use LWP::UserAgent }
}
sub send {
    my ($class, $message, @args);
    require LWP::UserAgent;
    if ( @args ) {
        my ($URL, $FIELD) = @args;
        $AGENT = LWP::UserAgent->new;
    }
    return failure "Can't send to URL if no URL and field are named"
        unless $URL && $FIELD;
    $AGENT->post($URL => { $FIELD => $message->as_string });
    return success;
}
1;

Cet exemple conservera un singleton UserAgent sauf si de nouveaux arguments sont passés à « send ». Il est utilisé en appelant « Email::Send::send »
