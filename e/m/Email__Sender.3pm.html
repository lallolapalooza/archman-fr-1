NOM

Email::Sender - une bibliothèque pour envoyer des e-mails

VERSION

version 2.601

SYNOPIS

my $message = Email::MIME->create( ... );
# produit un objet message compatible Email::Abstract,
# par exemple produit par Email::Simple, Email::MIME, Email::Stuff
use Email::Sender::Simple qw(sendmail);
use Email::Sender::Transport::SMTP qw();
use Try::Tiny;
try {
  sendmail(
    $message,
    {
      from => $SMTP_ENVELOPE_FROM_ADDRESS,
      transport => Email::Sender::Transport::SMTP->new({
          host => $SMTP_HOSTNAME,
          port => $SMTP_PORT,
      })
    }
  );
} catch {
    warn "envoi échoué : $_";
};

APERÇU

Email::Sender remplace l'ancienne bibliothèque Email::Send, parfois problématique, qui faisait un travail décent pour des tâches d'envoi d'e-mails très simples, mais n'était pas adaptée à un usage sérieux, pour diverses raisons.

La plupart des utilisateurs pourront utiliser Email::Sender::Simple pour envoyer des courriels. Les utilisateurs ayant des besoins plus spécifiques devraient consulter les classes Email::Sender::Transport disponibles.

La documentation se trouve dans Email::Sender::Manual, et les nouveaux utilisateurs devraient commencer par Email::Sender::Manual::QuickStart.

VERSION PERL

Cette bibliothèque devrait fonctionner sur des versions de Perl sorties il y a longtemps. Elle devrait fonctionner sur toute version de Perl sortie au cours des cinq dernières années.

Bien qu'elle puisse fonctionner sur des versions plus anciennes de Perl, aucune garantie n'est donnée quant à l'augmentation éventuelle de la version minimale requise. La version peut être augmentée pour quelque raison que ce soit, et il n'y a aucune promesse que des correctifs seront acceptés pour abaisser la version minimale requise de Perl.

IMPLÉMENTATION

Email::Sender lui-même est un rôle Moo. Toute classe qui implémente Email::Sender est tenue de fournir une méthode nommée "send". Cette méthode doit accepter toute entrée compréhensible par Email::Abstract, suivie d'un hashref contenant les arguments "to" et "from" à utiliser comme enveloppe. La méthode doit retourner un objet Email::Sender::Success en cas de succès ou lancer une exception Email::Sender::Failure en cas d'échec.
