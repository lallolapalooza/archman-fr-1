Email::MessageID(3) Documentation Perl fournie par l'utilisateur Email::MessageID(3)

NOM

Email::MessageID - Générer des identifiants de message uniques au monde.

VERSION

version 1.408

SYNOPSIS

use Email::MessageID;
my $mid = Email::MessageID->new->in_brackets;
print "Message-ID: $mid\x0D\x0A";

DESCRIPTION

Les identifiants de message sont des en-têtes optionnels, mais fortement recommandés, qui identifient un message de manière unique. Ce logiciel génère un identifiant de message unique.

VERSION PERL

Cette bibliothèque devrait fonctionner sur des versions de Perl publiées même il y a longtemps. Elle devrait fonctionner sur toute version de Perl publiée au cours des cinq dernières années.

Bien qu'elle puisse fonctionner sur des versions plus anciennes de Perl, aucune garantie n'est faite que la version minimale requise ne sera pas augmentée. La version peut être augmentée pour quelque raison que ce soit, et il n'y a aucune promesse que des correctifs seront acceptés pour abaisser la version minimale requise de Perl.

MÉTHODES

new

my $mid = Email::MessageID->new;
my $new_mid = Email::MessageID->new( host => $myhost );

Cette méthode de classe construit un objet Email::MessageID contenant un identifiant de message unique. Vous pouvez spécifier des paramètres personnalisés "host" et "user".

Par défaut, l'"host" est généré à partir de "Sys::Hostname::hostname".

Par défaut, l'"user" est généré en utilisant "Time::HiRes"'s "gettimeofday" et l'identifiant du processus.

En utilisant ces valeurs, nous avons la capacité d'assurer l'unicité mondiale jusqu'à un processus spécifique s'exécutant sur un hôte spécifique, et l'heure exacte jusqu'à six chiffres de précision de microseconde.

create_host

my $domain_part = Email::MessageID->create_host;

Cette méthode renvoie la partie domaine de l'identifiant de message.

create_user

my $local_part = Email::MessageID->create_user;

Cette méthode renvoie une partie locale unique pour l'identifiant de message. Elle inclut des données aléatoires et des données prévisibles.

in_brackets

Lors de l'utilisation directe d'Email::MessageID pour remplir le champ "Message-ID", assurez-vous d'utiliser "in_brackets" pour obtenir la chaîne à l'intérieur des chevrons :

header => [
  ...
  'Message-Id' => Email::MessageID->new->in_brackets,
],

Ne faites pas cette erreur courante :

header => [
  ...
  'Message-Id' => Email::MessageID->new->as_string, # FAUX !
],
