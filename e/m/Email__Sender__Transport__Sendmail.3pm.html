NOM

Email::Sender::Transport::Sendmail - envoi de courrier via sendmail(1)

VERSION

version 2.601

VERSION PERL

Cette bibliothèque devrait fonctionner sur des versions de Perl sorties il y a longtemps. Elle devrait fonctionner sur toute version de Perl sortie au cours des cinq dernières années.

Bien qu'elle puisse fonctionner sur des versions plus anciennes de Perl, aucune garantie n'est faite quant à l'augmentation de la version minimale requise. La version peut être augmentée pour n'importe quelle raison, et il n'y a aucune promesse que des correctifs seront acceptés pour abaisser la version minimale requise de Perl.

DESCRIPTION

Ce transport envoie du courrier en le redirigeant vers la commande sendmail. Si l'emplacement de la commande sendmail n'est pas fourni dans le constructeur (voir ci-dessous), la bibliothèque recherchera un fichier exécutable nommé sendmail dans le PATH.

Pour spécifier l'emplacement de sendmail :

my $sender = Email::Sender::Transport::Sendmail->new({ sendmail => $path });
