NOM

Email::Abstract::EmailSimple - Wrapper Email::Abstract pour Email::Simple

VERSION

version 3.010

DESCRIPTION

Ce module encapsule la bibliothèque de gestion d'e-mails Email::Simple avec une interface abstraite, à utiliser avec Email::Abstract.

VERSION PERL

Cette bibliothèque devrait fonctionner sur des versions de Perl même anciennes. Elle devrait fonctionner sur toute version de Perl sortie au cours des cinq dernières années.

Bien qu'elle puisse fonctionner sur des versions plus anciennes de Perl, aucune garantie n'est faite que la version minimale requise ne sera pas augmentée. La version peut être augmentée pour quelque raison que ce soit, et rien ne garantit que des correctifs seront acceptés pour abaisser la version minimale requise de Perl.

VOIR AUSSI
