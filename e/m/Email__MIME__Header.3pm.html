NOM

Email::MIME::Header - l'en-tête d'un message MIME

VERSION

version 1.954

DESCRIPTION

Cet objet se comporte comme un en-tête Email::Simple standard, avec les modifications suivantes :

  • la méthode "header" décode automatiquement les en-têtes encodés si possible
  • la méthode "header_as_obj" renvoie une représentation objet de la valeur de l'en-tête
  • la méthode "header_raw" renvoie l'en-tête brut ; (lecture seule pour le moment)
  • la stringification utilise "header_raw" plutôt que "header"

Notez que "header_set" ne fait pas l'encodage pour vous, et s'attend à un en-tête encodé. Ainsi, "header_set" fonctionne en aller-retour avec "header_raw", pas avec "header" ! Assurez-vous d'encoder correctement vos en-têtes avec "Encode::encode('MIME-Header', $value)" avant de les passer à "header_set". Et assurez-vous d'utiliser une version minimale de 2.83 du module Encode en raison de bugs dans MIME-Header.

Alternativement, si vous avez des chaînes Unicode (caractères) à définir dans les en-têtes, utilisez la méthode "header_str_set".
