NOM

Email::Sender::Transport::SMTP - envoyer des e-mails via SMTP

VERSION

version 2.601

DESCRIPTION

Ce transport est utilisé pour envoyer des e-mails via SMTP, avec ou sans sockets sécurisés (SSL/TLS). C'est l'un des transports les plus complexes disponibles, capable de succès partiels.

Pour une version potentiellement plus efficace de ce transport, voir Email::Sender::Transport::SMTP::Persistent.

VERSION PERL

Cette bibliothèque devrait fonctionner sur des versions de Perl même anciennes. Elle devrait fonctionner sur toute version de Perl publiée au cours des cinq dernières années.

Bien qu'elle puisse fonctionner sur des versions plus anciennes de Perl, rien ne garantit que la version minimale requise ne sera pas augmentée. La version peut être augmentée pour quelque raison que ce soit, et rien ne garantit que des correctifs seront acceptés pour abaisser la version minimale requise de Perl.

ATTRIBUTS

Les attributs suivants peuvent être passés au constructeur :

"hosts" : un tableau d'hôtes à essayer, dans l'ordre ; par défaut, un tableau contenant un seul élément "localhost"
L'attribut "host" peut être donné, à la place, et contient un seul nom d'hôte.
"ssl" : si 'starttls', utiliser STARTTLS ; si 'ssl' (ou 1), se connecter de manière sécurisée ; si 'maybestarttls', utiliser STARTTLS si disponible ; sinon, pas de sécurité
"ssl_options" : passé au constructeur Net::SMTP pour les connexions 'ssl' ou à starttls pour les connexions 'starttls' ou 'maybestarttls' ; doit contenir des options supplémentaires pour IO::Socket::SSL
"port" : port de connexion ; par défaut 25 pour non-SSL, 465 pour 'ssl', 587 pour 'starttls'
"timeout" : temps maximum en secondes d'attente du serveur ; par défaut 120
"sasl_username" : le nom d'utilisateur à utiliser pour l'authentification ; optionnel
"sasl_password" : le mot de passe à utiliser pour l'authentification ; requis si "sasl_username" est fourni
"sasl_authenticator" : une instance de "Authen::SASL" à utiliser pour l'authentification ; optionnel
Les attributs "sasl_authenticator" et "sasl_username" s'excluent mutuellement.
"allow_partial_success" : si vrai, enverra les données même si certains destinataires ont été rejetés ; par défaut faux
"helo" : ce qu'il faut dire en disant HELO ; pas de défaut
"localaddr" : adresse locale à partir de laquelle se connecter
"localport" : port local à partir duquel se connecter
"debug" : si vrai, met l'objet Net::SMTP en mode débogage

SUCCÈS PARTIEL

Si "allow_partial_success" a été défini lors de la création du transport, le transport peut retourner des objets Email::Sender::Success::Partial. Consulter la documentation de ce module.
