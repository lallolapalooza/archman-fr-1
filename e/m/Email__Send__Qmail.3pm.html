NOM

Email::Send::Qmail - Envoyer des messages en utilisant qmail-inject

SYNOPIS

use Email::Send;
Email::Send->new({mailer => 'Qmail'})->send($message);

DESCRIPTION

Ce gestionnaire de courrier pour "Email::Send" utilise "qmail-inject" pour placer un message dans la file d'attente de Qmail. Il n'essaie pas activement de trouver l'exécutable. Il appelle simplement "qmail-inject" et s'attend à ce qu'il soit dans votre PATH. Si ce n'est pas le cas, ou si vous souhaitez définir explicitement l'emplacement de votre exécutable, modifiez la variable du paquet $Email::Send::Qmail::QMAIL.

$Email::Send::Qmail::QMAIL = '/usr/sbin/qmail-inject';
