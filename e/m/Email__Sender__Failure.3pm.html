NOM

Email::Sender::Failure - un rapport d'échec d'un transport d'envoi d'e-mails

VERSION

version 2.601

VERSION PERL

Cette bibliothèque devrait fonctionner sur des versions de Perl même anciennes. Elle devrait fonctionner sur toute version de Perl publiée au cours des cinq dernières années.

Bien qu'elle puisse fonctionner sur des versions plus anciennes de Perl, aucune garantie n'est faite que la version minimale requise ne sera pas augmentée. La version peut être augmentée pour n'importe quelle raison, et rien ne garantit que des correctifs seront acceptés pour abaisser la version minimale requise de Perl.

ATTRIBUTS

message

Cette méthode renvoie le message d'échec, qui devrait décrire l'échec. Les échecs sont convertis en chaînes de caractères par ce message.

code

Ceci renvoie le code numérique de l'échec, le cas échéant. Ceci est principalement utile pour les transports de protocoles réseau comme SMTP. Ceci peut être indéfini.

destinataires

Ceci renvoie une liste d'adresses auxquelles l'e-mail n'a pas pu être envoyé.

MÉTHODES

lancer

Cette méthode peut être utilisée pour instancier et lancer un objet Email::Sender::Failure en une seule fois.

Email::Sender::Failure->throw(\%arg);

Au lieu d'un hachage d'arguments, vous pouvez passer un seul argument de chaîne qui sera utilisé comme "message" du nouvel échec.
