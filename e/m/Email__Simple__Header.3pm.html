NOM

Email::Simple::Header - l'en-tête d'un message Email::Simple

VERSION

version 2.218

SYNOPSIS

my $email = Email::Simple->new($text);
my $header = $email->header_obj;
print $header->as_string;

DESCRIPTION

Cette méthode implémente les en-têtes d'un objet Email::Simple. C'est une interface très minimale, et principalement destinée à un usage interne pour le moment.

VERSION PERL

Cette bibliothèque devrait fonctionner sur des versions de Perl remontant à longtemps. Elle devrait fonctionner sur toute version de perl publiée au cours des cinq dernières années.

Bien qu'elle puisse fonctionner sur des versions plus anciennes de perl, aucune garantie n'est donnée sur le fait que la version minimale requise ne sera pas augmentée. La version peut être augmentée pour n'importe quelle raison, et il n'y a aucune promesse que des correctifs seront acceptés pour abaisser la version minimale de perl requise.

MÉTHODES

new

my $header = Email::Simple::Header->new($head, \%arg);

$head est une chaîne contenant un en-tête d'e-mail valide, ou une référence à une telle chaîne. Si une référence est passée, ne comptez pas sur le fait qu'elle ne sera pas modifiée.

Les arguments valides sont :

crlf - le caractère de nouvelle ligne de l'en-tête ; par défaut CRLF

as_string

my $string = $header->as_string(\%arg);

Cela renvoie une version sous forme de chaîne de l'en-tête.

header_names

Cette méthode renvoie une liste des noms d'en-tête uniques trouvés dans cet en-tête, dans un ordre quelconque.

header_raw_pairs

my @pairs = $header->header_raw_pairs;
my $first_name  = $pairs[0];
my $first_value = $pairs[1];

Cette méthode renvoie une liste de toutes les paires champ/valeur dans l' en-tête, dans l'ordre où elles apparaissent dans l'en-tête. (Rappelez-vous : n'essayez pas d'assigner cela à un hash. Certains champs peuvent apparaître plus d'une fois !)

header_pairs

header_pairs est un autre nom pour header_raw_pairs, qui était le nom original de la méthode et que vous verrez le plus souvent. En général, cependant, il vaut mieux être explicite et utiliser header_raw_pairs. (Dans Email::MIME, header_str_pairs existe pour laisser la bibliothèque faire le décodage de l'en-tête pour vous.)

header_raw

my $first_value = $header->header_raw($field);
my $nth_value   = $header->header_raw($field, $index);
my @all_values  = $header->header_raw($field);

Cette méthode renvoie la valeur ou les valeurs du champ d'en-tête donné. Si le champ nommé n'apparaît pas dans l'en-tête, cette méthode renvoie faux.

header

Cette méthode appelle simplement "header_raw". C'est l'ancien nom pour "header_raw", mais cela peut poser problème car Email::MIME, une sous-classe de Email::Simple, fait "header" renvoyer la valeur décodée de l'en-tête.

header_raw_set

$header->header_raw_set($field => @values);

Cette méthode met à jour la valeur de l'en-tête donné. Les en-têtes existants ont leurs valeurs définies à leur emplacement. Les en-têtes supplémentaires sont ajoutés à la fin. Si aucune valeur n'est donnée à définir, l'en-tête sera complètement supprimé du message.

header_set

header_set est un autre nom pour header_raw_set, qui était le nom original de la méthode et que vous verrez le plus souvent. En général, cependant, il vaut mieux être explicite et utiliser header_raw_set. (Dans Email::MIME, header_str_set existe pour laisser la bibliothèque faire l'encodage de l'en-tête pour vous.)

header_raw_prepend

$header->header_raw_prepend($field => $value);

Cette méthode ajoute une nouvelle instance du champ nommé en tant que premier champ dans l'en-tête.

header_rename

$header->header_rename($field, $new_name, $nth);

Cela renomme le champ nommé avec le nouveau nom. Si $nth est donné, seule la nièmeinstance du champ sera renommée. C'est fatal de renommer une instance qui n'existe pas. La première instance d'un en-tête est la 0ème.

Si $nth est omis, toutes les instances de l' en-tête sont renommées.

Lors du choix des en-têtes à renommer, $field est comparé sans tenir compte de la casse. Ainsi, étant donné cet en-tête :

happythoughts: yes
HappyThoughts: so many
hapPyThouGhts: forever

Puis ce code...

$header->rename_header('happythoughts', 'Delights');

...donnera ceci :

Delights: yes
Delights: so many
Delights: forever

Les en-têtes peuvent être réorganisés à la suite d'un renommage.

crlf

Cette méthode renvoie la chaîne de nouvelle ligne utilisée dans l'en-tête.
