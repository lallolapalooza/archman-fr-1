NOM

Email::Sender::Transport - un rôle pour les transports d'e-mails

VERSION

version 2.601

DESCRIPTION

Email::Sender::Transport est un rôle Moo pour aider à écrire des classes utilisées pour envoyer des e-mails. Dans la plupart des cas, son comportement provient entièrement du rôle Email::Sender::Role::CommonSending, qu'il inclut. La différence importante est que les Transports sont souvent destinés à être utilisés par Email::Sender::Simple, et ils fournissent deux méthodes liées à cet objectif.

VERSION PERL

Cette bibliothèque devrait fonctionner sur des versions de Perl publiées même il y a longtemps. Elle devrait fonctionner sur n'importe quelle version de Perl publiée au cours des cinq dernières années.

Bien qu'elle puisse fonctionner sur des versions plus anciennes de Perl, aucune garantie n'est faite que la version minimale requise ne sera pas augmentée. La version peut être augmentée pour quelque raison que ce soit, et il n'y a aucune promesse que des correctifs seront acceptés pour abaisser la version minimale requise de Perl.

Premièrement, ils fournissent une méthode "allow_partial_success" qui renvoie vrai ou faux pour indiquer si le transport signalera jamais un succès partiel.

Deuxièmement, ils fournissent une méthode "is_simple", qui renvoie vrai si le transport convient pour une utilisation avec Email::Sender::Simple. Par défaut, cette méthode renvoie l'inverse de "allow_partial_success".

Il est impératif que ces méthodes soient exactes pour empêcher les utilisateurs de Email::Sender::Simple d'envoyer des transmissions partiellement réussies. Le succès partiel est un cas complexe que presque tous les utilisateurs souhaiteront éviter à tout moment.
