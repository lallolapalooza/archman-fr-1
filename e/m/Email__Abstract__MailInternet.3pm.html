NOM

Email::Abstract::MailInternet - Wrapper Email::Abstract pour Mail::Internet

VERSION

version 3.010

DESCRIPTION

Ce module encapsule la bibliothèque de gestion d'e-mails Mail::Internet avec une interface abstraite, à utiliser avec Email::Abstract.

VERSION PERL

Cette bibliothèque devrait fonctionner sur des versions de Perl publiées même il y a longtemps. Elle devrait fonctionner sur toute version de perl publiée au cours des cinq dernières années.

Bien qu'elle puisse fonctionner sur des versions plus anciennes de perl, aucune garantie n'est faite que la version minimale requise ne sera pas augmentée. La version peut être augmentée pour quelque raison que ce soit, et il n'y a aucune promesse que des correctifs seront acceptés pour abaisser la version minimale de perl requise.

VOIR AUSSI
