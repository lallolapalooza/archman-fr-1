NOM

emacs - un éditeur de texte extensible et auto-documenté

SYNTAXE

emacs [ emacs options ] [ fichiers... ]

DESCRIPTION

Emacs est un éditeur de texte sophistiqué qui s'exécute dans un environnement interactif et est hautement personnalisable.

Emacs est plus qu'un simple éditeur de texte. C'est un environnement de travail complet qui peut être utilisé pour lire et écrire du courrier électronique, naviguer sur le Web, lire des articles de groupe, programmer, déboguer et bien plus encore. Il est écrit en Emacs Lisp, un dialecte du langage Lisp, ce qui permet une personnalisation et une extension poussées.

MANUELS

Vous pouvez commander des copies imprimées du manuel GNU Emacs auprès de la Free Software Foundation, qui développe des logiciels GNU. Voir la boutique en ligne à l'adresse https://shop.fsf.org/.

Votre administrateur local peut également avoir des copies disponibles. Comme pour tous les logiciels et publications de la FSF, tout le monde est autorisé à faire et distribuer des copies du manuel Emacs. La source Texinfo du manuel est également incluse dans la distribution source d'Emacs.

FICHIERS

/usr/local/share/info — fichiers pour le navigateur de documentation Info. Le texte complet du manuel de référence Emacs est inclus sous une forme pratique structurée en arbre. Cela inclut le manuel de référence Emacs Lisp, utile à quiconque souhaite écrire des programmes dans le langage d'extension Emacs Lisp, et l'introduction à la programmation en Emacs Lisp.

/usr/local/share/emacs/$VERSION/lisp — fichiers source Lisp et fichiers compilés qui définissent la plupart des commandes d'édition. Certains sont préchargés ; d'autres sont chargés automatiquement à partir de ce répertoire lorsqu'ils sont utilisés.

/usr/local/libexec/emacs/$VERSION/$ARCH — divers programmes utilisés avec GNU Emacs.

/usr/local/share/emacs/$VERSION/etc — divers fichiers d'information.

/usr/local/share/emacs/$VERSION/etc/DOC.* — contient les chaînes de documentation pour les primitives Lisp et les fonctions Lisp préchargées de GNU Emacs. Elles sont stockées ici pour réduire la taille d'Emacs proprement dit.

BOGUES

Il existe une liste de diffusion, bug-gnu-emacs@gnu.org, pour signaler les bogues et les corrections d'Emacs. Mais avant de signaler quelque chose comme un bogue, essayez de vous assurer qu'il s'agit bien d'un bogue, pas d'un malentendu ou d'une fonctionnalité délibérée. Nous vous demandons de lire la section "Reporting Bugs" du manuel Emacs pour des indices sur comment et quand signaler les bogues. De plus, incluez le numéro de version d'Emacs que vous utilisez dans chaque rapport de bogue que vous envoyez. Les bogues ont tendance à être corrigés s'ils peuvent être isolés, il est donc dans votre intérêt de les signaler de manière à ce qu'ils puissent être facilement reproduits.

Ne vous attendez pas à une réponse personnelle à un rapport de bogue. Le but de signaler les bogues est de les faire corriger pour tout le monde dans la prochaine version, si possible. Pour une assistance personnelle, consultez le répertoire des services à l'adresse https://www.fsf.org/resources/service/ pour une liste de personnes qui en offrent.

Veuillez ne rien envoyer d'autre que des rapports de bogues à cette liste de diffusion. Pour d'autres listes Emacs, voir https://savannah.gnu.org/mail/?group=emacs.
