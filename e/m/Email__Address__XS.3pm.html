DESCRIPTIO

N

Ce module implémente l'analyseur et le formateur d'adresses e-mail et de groupes selon RFC 5322 https://tools.ietf.org/html/rfc5322. Il analyse une chaîne d'entrée à partir d'en-têtes e-mail qui contiennent une liste d'adresses e-mail ou un groupe d'adresses e-mail (comme From, To, Cc, Bcc, Reply-To, Sender, ...). Il peut également générer une valeur de chaîne pour ces en-têtes à partir d'une liste d'objets d'adresses e-mail. Le module est rétrocompatible avec RFC 2822 https://tools.ietf.org/html/rfc2822 et RFC 822 https://tools.ietf.org/html/rfc822

.

La fonctionnalité d'analyse et de formatage est implémentée en XS et utilise du code partagé du serveur IMAP

Dovecot.

C'est un remplacement direct pour le module Email::Address qui présente plusieurs problèmes de sécurité. Par exemple, le problème CVE-2015-7686 (vulnérabilité de complexité algorithmique) https://cve.mitre.org/cgi-bin/cvename.cgi?name=CVE-2015-7686, qui permet à des attaquants distants de provoquer un déni de service, est toujours présent dans Email::Address version 1.

908.

Le module Email::Address::XS a été créé pour finalement corriger

CVE-2015-7686.

Les applications existantes qui utilisent le module Email::Address pourraient facilement passer au module Email::Address::XS. Dans la plupart des cas, il suffit de changer "use Email::Address" en "use Email::Address::XS" et de remplacer chaque "Email::Address" par "Email::Address::

XS".

Ainsi, contrairement à Email::Address, ce module n'utilise pas d'expressions régulières pour l'analyse mais une implémentation XS native analyse la chaîne d'entrée séquentiellement selon la grammaire RFC

5322.

De plus, il prend également en charge les groupes nommés et peut donc être utilisé à la place du module Email::Address::

List.

Si vous cherchez le module qui fournit une représentation objet pour une liste d'adresses e-mail adaptée aux en-têtes e-mail MIME, consultez Email::MIME::Header::

AddressList.

Construit et renvoie un nouvel objet "Email::Address::XS". Prend une liste d'arguments nommés : phrase, address, user, host, comment et copy. L'argument address a la priorité sur user et

host.

Lorsque l'argument copy est spécifié, un objet Email::Address::XS est attendu et une copie clonée de cet objet est renvoyée. Tous les autres paramètres sont

ignorés.

L'ancienne syntaxe du module Email::Address est également prise en charge. Prend

un à quatre arguments positionnels : phrase, address, comment et chaîne originale
. Passer un argument original est obsolète, ignoré et déclenche un avertissement.
