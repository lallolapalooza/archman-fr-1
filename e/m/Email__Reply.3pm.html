Ce logiciel simplifie la g

my $reply   = reply to       => $message,
                    from     => '"Casey West" <casey@geeknest.com>',
                    all      => 1;
                    self     => 0,
                    attach   => 1,
                    quote    => 1,
                    top_post => 0,
                    keep_sig => 1,
                    prefix   => ': ',
                    attrib   => sprintf("From %s, typer of many words:",
                                        $from->name),
                    body     => <<__RESPONSE__;
Thanks for the message, I'll be glad to explain the picture...
__RESPONSE__

Cette fonction accepte un certain nombre de paramètres nommés et renvoie un objet message de courriel de type "Email::MIME" ou "Email::Simple", selon les paramètres transmis. Passons en revue ces paramètres

maintenant.
"t
o"
Ce paramètre requis est le message de courriel auquel vous répondez. Il peut représenter plusieurs types d'objets, ou une chaîne contenant le message. Cette valeur est transmise directement à "Email::Abstract" sans passer par la case départ ni collecter $200, alors veuillez lire la documentation de ses greffons disponibles pour savoir ce qui est autorisé
ici.
"fro
m"
Ce paramètre facultatif spécifie une adresse courriel à utiliser pour indiquer l'expéditeur du message de réponse. Il peut s'agir d'une chaîne ou d'un objet "Email::Address". En l'absence de ce paramètre, la première adresse trouvée dans l'en-tête "To" du message original est utilisée. Cela ne correspond pas toujours à ce que vous souhaitez, ce paramètre est donc fortement
recommandé.
"al
l"
Ce paramètre facultatif indique si vous souhaitez ou non « Répondre à tous ». S'il est vrai, l'en-tête "Cc" de la réponse sera rempli avec toutes les adresses présentes dans les en-têtes "To" et "Cc" du message original. Par défaut, le paramètre est faux, indiquant « Répondre à l'expéditeur
».
"sel
f"
Ce paramètre facultatif détermine si une adresse correspondant à l'adresse "from" sera incluse dans la liste des adresses "all". S'il est vrai, votre adresse sera conservée dans cette liste si elle y est trouvée. S'il est faux, comme c'est le cas par défaut, votre adresse sera retirée de la liste. Comme vous pouvez vous en douter, ce paramètre n'est utile que si "all" est
vrai.
"attac
h"
Ce paramètre facultatif permet d'encapsuler le message original, dans son intégralité, dans une partie MIME de type "message/rfc822". S'il est vrai, l'objet renvoyé par "reply" sera un objet "Email::MIME" dont la deuxième partie est le message encapsulé. S'il est faux, rien de tout cela ne se produit. Par défaut, rien de tout cela ne se
produit.
"quot
e"
Ce paramètre facultatif, qui est vrai par défaut, mettra le message original en citation pour votre réponse. Si le message original est un message MIME, la première partie de type "text/plain" sera citée. S'il s'agit d'un message Simple, le corps sera cité. Mais cela ne se produit que si vous laissez le paramètre vrai. Sinon, rien de tout cela ne se
produit.
"top_pos
t"
Ce paramètre facultatif, dont l'usage est généralement déconseillé, permettra le « top posting » lorsqu'il est vrai. Il définira implicitement "quote" à vrai, et placera votre "body" avant le texte cité. Il est faux par défaut, et vous devriez faire de votre mieux pour le laisser tel
quel.
"keep_si
g"
Ce paramètre facultatif active ou désactive le mécanisme de suppression de signature. Vrai par défaut, la signature sera retirée du corps cité original. Lorsqu'il est faux, la signature est laissée intacte et sera citée en conséquence. Cela n'est utile que lorsque "quote" est
vrai.
"prefi
x"
Ce paramètre facultatif spécifie le préfixe de citation. Par défaut, c'est ">", mais vous pouvez le changer en définissant ce paramètre. Encore une fois, utile seulement lorsque "quote" est
vrai.
"attri
b"
Ce paramètre facultatif spécifie la ligne d'attribution à ajouter au début du texte cité. Par défaut, le nom ou l'adresse courriel de l'expéditeur original est utilisé pour remplacer %s dans la chaîne "%s wrote:". Vous pouvez changer cela avec ce paramètre. Aucun format spécial, sprintf() ou autre, n'est fourni pour votre commodité. Désolé, vous devrez vous débrouiller. Comme "prefix" et "keep_sig", cela n'est bon que lorsque "quote" est
vrai.
"bod
y"
Ce paramètre requis cont
ient votre prose, votre
manifeste, votre ré
ponse. N'oubliez pas de
vérifier l'orthographe !
