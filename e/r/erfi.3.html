NOM

cerfi, erfi - fonction d'erreur imaginaire

SYNTAXE

#include <cerf.h>

double _Complex cerfi ( double _Complex z );

double erfi ( double x );

DESCRIPTION

La fonction cerfi retourne une fonction d'erreur tournée dans le plan complexe, erfi(z) = -i erf(iz).

La fonction erfi prend un argument réel et retourne un résultat réel.

VOIR AUSSI

L'implémentation de cerfi et erfi est trivialement basée sur les fonctions cerf(3) et im_w_of_x(3).

Autres fonctions d'erreur complexes dans libcerf : dawson(3), erfcx(3), voigt(3), w_of_z(3).

La fonction d'erreur réelle est fournie avec les versions récentes de glibc, comme demandé par la norme C99 : erf(3).
