ERR_GET_LIB(3ssl) OpenSSL ERR_GET_LIB(3ssl)

NOM

ERR_GET_LIB, ERR_GET_REASON, ERR_FATAL_ERROR - obtenir des informations à partir des codes d'erreur

SYNTAXE

#include <openssl/err.h>
int ERR_GET_LIB(unsigned long e);
int ERR_GET_REASON(unsigned long e);
int ERR_FATAL_ERROR(unsigned long e);

DESCRIPTION

Le code d'erreur renvoyé par ERR_get_error() est composé d'un numéro de bibliothèque et d'un code de raison. ERR_GET_LIB() et ERR_GET_REASON() peuvent être utilisés pour les extraire.

ERR_FATAL_ERROR() indique si un code d'erreur donné est une erreur fatale.

Le numéro de bibliothèque décrit où l'erreur s'est produite, le code de raison est l'information concernant ce qui s'est mal passé.

Chaque sous-bibliothèque d'OpenSSL a un numéro de bibliothèque unique; le code de raison est unique au sein de chaque sous-bibliothèque. Notez que des bibliothèques différentes peuvent utiliser la même valeur pour signaler des raisons différentes.

Les codes de raison ERR_R_... tels que ERR_R_MALLOC_FAILURE sont globalement uniques. Cependant, lors de la vérification des codes de raison spécifiques aux sous-bibliothèques, assurez-vous de comparer également le numéro de bibliothèque.

ERR_GET_LIB(), ERR_GET_REASON() et ERR_FATAL_ERROR() sont des macros.

VALEURS DE RETOUR

Le numéro de bibliothèque, le code de raison et si l'erreur est fatale, respectivement. À partir d'OpenSSL 3.0.0, le code de fonction est toujours défini sur zéro.

NOTES

Les applications ne doivent pas baser les décisions de flux de contrôle sur des codes d'erreur spécifiques. Les codes d'erreur sont susceptibles de changer à tout moment (même dans les versions patch d'OpenSSL). Un code d'erreur particulier ne peut être considéré comme significatif pour les décisions de flux de contrôle que s'il est explicitement documenté comme tel. De nouveaux codes d'échec peuvent apparaître à tout moment.

VOIR AUSSI

ERR_get_error(3)

HISTORIQUE

ERR_GET_LIB() et ERR_GET_REASON() sont disponibles dans toutes les versions d'OpenSSL.

ERR_GET_FUNC() a été supprimé dans OpenSSL 3.0.
