NOM

Error::TypeTiny::Compilation - exception pour Eval::TypeTiny

STATUT

Ce module est couvert par la politique de stabilité de Type-Tiny.

DESCRIPTION

Lancé lorsque la compilation d'une fermeture échoue. Les causes courantes sont des problèmes avec les contraintes de type incorporées et les erreurs de syntaxe lorsque les coercitions sont fournies sous forme de chaînes de code Perl.

Ce package hérite de Error::TypeTiny ; consultez celui-ci pour la plupart de la documentation. Les principales différences sont listées ci-dessous :

Attributs

"code"
Le code source Perl en cours de compilation.
"environment"
Hashref des variables qui sont fermées.
"errstr"
Message d'erreur du compilateur Perl.
