ERR_set_mark(3ssl)

Paquet: openssl

Licences: Apache-2.0

ERR_SET_MARK(3ssl) OpenSSL ERR_SET_MARK(3ssl)

NOM

ERR_set_mark, ERR_clear_last_mark, ERR_pop_to_mark, ERR_count_to_mark, ERR_pop - définir une marque, effacer une marque, retirer les erreurs jusqu'à la marque et retirer la dernière erreur

SYNTAXE

#include <openssl/err.h>
int ERR_set_mark(void);
int ERR_pop_to_mark(void);
int ERR_clear_last_mark(void);
int ERR_count_to_mark(void);
int ERR_pop(void);

DESCRIPTION

ERR_set_mark() définit une marque sur l'enregistrement d'erreur actuel le plus en haut s'il y en a un.

ERR_pop_to_mark() retirera le haut de la pile d'erreurs jusqu'à ce qu'une marque soit trouvée. La marque est ensuite supprimée. S'il n'y a pas de marque, toute la pile est retirée.

ERR_clear_last_mark() supprime la dernière marque ajoutée s'il y en a une.

ERR_count_to_mark() renvoie le nombre d'entrées dans la pile d'erreurs au-dessus de l'entrée marquée la plus récente, sans inclure cette entrée. S'il n'y a pas de marque dans la pile d'erreurs, le nombre total d'entrées dans la pile d'erreurs est renvoyé.

ERR_pop() retire inconditionnellement une seule entrée d'erreur du haut de la pile d'erreurs (qui est l'entrée accessible via ERR_peek_last_error(3)).

VALEURS DE RETOUR

ERR_set_mark() renvoie 0 si la pile d'erreurs est vide, sinon 1.

ERR_clear_last_mark() et ERR_pop_to_mark() renvoient 0 s'il n'y avait pas de marque dans la pile d'erreurs, ce qui implique que la pile est devenue vide, sinon 1.

ERR_count_to_mark() renvoie le nombre d'entrées de la pile d'erreurs situées au-dessus de la marque la plus récente, le cas échéant, ou le nombre total d'entrées de la pile d'erreurs.

ERR_pop() renvoie 1 si une erreur a été retirée ou 0 si la pile d'erreurs était vide.

HISTORIQUE

ERR_count_to_mark() a été ajouté dans OpenSSL 3.2. ERR_pop() a été ajouté dans OpenSSL 3.3.
