ERR_get_error(3ssl)

NOM

ERR_get_error, ERR_peek_error, ERR_peek_last_error, ERR_get_error_line, ERR_peek_error_line, ERR_peek_last_error_line, ERR_peek_error_func, ERR_peek_last_error_func, ERR_peek_error_data, ERR_peek_last_error_data, ERR_get_error_all, ERR_peek_error_all, ERR_peek_last_error_all, ERR_get_error_line_data, ERR_peek_error_line_data, ERR_peek_last_error_line_data - obtenir le code d'erreur et les données

#include <openssl/err.h>
unsigned long ERR_get_error(void);
unsigned long ERR_peek_error(void);
unsigned long ERR_peek_last_error(void);
unsigned long ERR_peek_error_line(const char **file, int *line);
unsigned long ERR_peek_last_error_line(const char **file, int *line);
unsigned long ERR_peek_error_func(const char **func);
unsigned long ERR_peek_last_error_func(const char **func);
unsigned long ERR_peek_error_data(const char **data, int *flags);
unsigned long ERR_peek_last_error_data(const char **data, int *flags);
unsigned long ERR_get_error_all(const char **file, int *line,
                                const char **func,
                                const char **data, int *flags);
unsigned long ERR_peek_error_all(const char **file, int *line,
                                 const char **func,
                                 const char **data, int *flags);
unsigned long ERR_peek_last_error_all(const char **file, int *line,
                                      const char *func,
                                      const char **data, int *flags);

Les fonctions suivantes sont obsolètes depuis OpenSSL 3.0, et peuvent être entièrement masquées en définissant OPENSSL_API_COMPAT avec une valeur de version appropriée, voir openssl_user_macros(7):

unsigned long ERR_get_error_line(const char **file, int *line);

DESCRIPTION

ERR_get_error() renvoie le code d'erreur le plus ancien de la file d'erreurs du thread et supprime l'entrée. Cette fonction peut être appelée de manière répétée jusqu'à ce qu'il n'y ait plus de codes d'erreur à renvoyer.

ERR_peek_error() renvoie le code d'erreur le plus ancien de la file d'erreurs du thread sans la modifier.

ERR_peek_last_error() renvoie le code d'erreur le plus récent de la file d'erreurs du thread sans la modifier.

Voir ERR_GET_LIB(3) pour obtenir des informations plus spécifiques telles que la raison de l'erreur, et ERR_error_string(3) pour des messages d'erreur lisibles par l'humain.

ERR_get_error_all() est identique à ERR_get_error(), mais en cas de succès, il stocke en plus le nom de fichier, le numéro de ligne et la fonction où l'erreur s'est produite dans *file, *line et *func, et également le texte supplémentaire et les indicateurs dans *data, *flags. Si l'un de ces paramètres est NULL, il ne sera pas modifié. Un nom de fichier non défini est indiqué par "", c'est-à-dire une chaîne vide. Un numéro de ligne non défini est indiqué par 0. Un nom de fonction non défini est indiqué par "", c'est-à-dire une chaîne vide.

Un pointeur renvoyé de cette manière par ces fonctions et les suivantes est valide jusqu'à ce que l'entrée respective soit écrasée dans la file d'erreurs.

ERR_peek_error_line() et ERR_peek_last_error_line() sont identiques à ERR_peek_error() et ERR_peek_last_error(), mais en cas de succès, ils stockent en plus le nom de fichier et le numéro de ligne où l'erreur s'est produite dans *file et *line, tant qu'ils ne sont pas NULL. Un nom de fichier non défini est indiqué par "", c'est-à-dire une chaîne vide. Un numéro de ligne non défini est indiqué par 0.

ERR_peek_error_func() et ERR_peek_last_error_func() sont identiques à ERR_peek_error() et ERR_peek_last_error(), mais en cas de succès, ils stockent en plus le nom de la fonction où l'erreur s'est produite dans *func, à moins qu'il ne soit NULL. Un nom de fonction non défini est indiqué par "".

ERR_peek_error_data() et ERR_peek_last_error_data() sont identiques à ERR_peek_error() et ERR_peek_last_error(), mais en cas de succès, ils stockent en plus les données et les indicateurs supplémentaires associés au code d'erreur dans *data et *flags, tant qu'ils ne sont pas NULL. Des données non définies sont indiquées par "". Dans ce cas, la valeur donnée pour l'indicateur est sans importance (et vaut 0). *data contient une chaîne si *flags&ERR_TXT_STRING est vrai.

ERR_peek_error_all() et ERR_peek_last_error_all() sont des combinaisons de tout ce qui précède.

ERR_get_error_line(), ERR_get_error_line_data(), ERR_peek_error_line_data() et ERR_peek_last_error_line_data() sont des variantes plus anciennes de ERR_get_error_all(), ERR_peek_error_all() et ERR_peek_last_error_all(), et peuvent donner des résultats confus. Elles ne devraient plus être utilisées et sont donc obsolètes.

Une application NE DOIT PAS libérer le pointeur *data (ou tout autre pointeur renvoyé par ces fonctions) avec OPENSSL_free() car la libération est gérée automatiquement par la bibliothèque d'erreurs.

VALEURS RENVOYÉES

Le code d'erreur, ou 0 s'il n'y a pas d'erreur dans la file.

VOIR AUSSI

ERR_error_string(3), ERR_GET_LIB(3)

HISTORIQUE

ERR_peek_error_func(), ERR_peek_last_error_func(), ERR_peek_error_data(), ERR_peek_last_error_data(), ERR_peek_error_all() et ERR_peek_last_error_all() ont été ajoutées dans OpenSSL 3.0.

ERR_get_error_line(), ERR_get_error_line_data(), ERR_peek_error_line_data() et ERR_peek_last_error_line_data() sont devenues obsolètes dans OpenSSL 3.0.
