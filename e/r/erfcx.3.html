NOM

cerfcx, erfcx - fonction complémentaire de l'erreur compensée par sous-dépassement

SYNTAXE

#include <cerf.h>

double _Complex cerfcx ( double _Complex z );

double erfcx ( double x );

DESCRIPTION

La fonction cerfcx est une variante compensée par sous-dépassement de la fonction d'erreur complexe : erfcx(z) = exp(z^2) erfc(z).

La fonction erfcx prend un argument réel et retourne un résultat réel.

RÉFÉRENCES

L'implémentation de cerfcx est un simple wrapper autour de la fonction de Faddeeva w_of_z.

L'implémentation de erfcx est autonome. Elle a été entièrement réécrite pour libcerf-2.5, et garantit désormais une précision relative de 2.34e-16 pour x < 12.

L'approximation polynomiale par morceaux pour les valeurs intermédiaires de |x| est expliquée dans Wuttke et Kleinknecht, "Code generation for piecewise Chebyshev approximation" (soumis ; prépublication disponible auprès des auteurs).

VOIR AUSSI

Fonctions d'erreur complexes apparentées dans liberfc : w_of_z(3), dawson(3), voigt(3), cerf(3), erfi(3).

La fonction d'erreur réelle est fournie avec les versions récentes de glibc, comme demandé par la norme C99 : erf(3)
