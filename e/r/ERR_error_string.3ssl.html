ERR_ERROR_STRING(3ssl) OpenSSL ERR_ERROR_STRING(3ssl)

NOM

ERR_error_string, ERR_error_string_n, ERR_lib_error_string, ERR_func_error_string, ERR_reason_error_string — obtenir un message d'erreur lisible par l'homme

SYNTAXE

#include <openssl/err.h>
char *ERR_error_string(unsigned long e, char *buf);
void ERR_error_string_n(unsigned long e, char *buf, size_t len);
const char *ERR_lib_error_string(unsigned long e);
const char *ERR_reason_error_string(unsigned long e);

Obsolète dans OpenSSL 3.0 :

const char *ERR_func_error_string(unsigned long e);

DESCRIPTION

ERR_error_string() génère une chaîne de caractères lisible par l'homme représentant le code d'erreur e et la place dans buf. buf doit avoir une taille d'au moins 256 octets. Si buf est NULL, la chaîne d'erreur est placée dans un tampon statique. Notez que cette fonction n'est pas thread-safe et ne vérifie pas la taille du tampon ; utilisez plutôt ERR_error_string_n().

ERR_error_string_n() est une variante de ERR_error_string() qui écrit au maximum len caractères (y compris le terminateur 0) et tronque la chaîne si nécessaire. Pour ERR_error_string_n(), buf NE DOIT PAS être NULL.

La chaîne aura le format suivant :

error:[code d'erreur]:[nom de la bibliothèque]::[chaîne de raison]

code d'erreur est un nombre hexadécimal à 8 chiffres, nom de la bibliothèque et chaîne de raison sont du texte ASCII.

ERR_lib_error_string() et ERR_reason_error_string() renvoient respectivement le nom de la bibliothèque et la chaîne de raison.

S'il n'y a pas de chaîne de texte enregistrée pour le code d'erreur donné, la chaîne d'erreur contiendra le code numérique.

ERR_print_errors(3) peut être utilisé pour imprimer tous les codes d'erreur actuellement dans la file d'attente.

VALEURS DE RETOUR

ERR_error_string() renvoie un pointeur vers un tampon statique contenant la chaîne si buf == NULL, sinon buf.

ERR_lib_error_string() et ERR_reason_error_string() renvoient les chaînes, et NULL si aucune n'est enregistrée pour le code d'erreur.

ERR_func_error_string() renvoie NULL.

VOIR AUSSI

ERR_get_error(3), ERR_print_errors(3)

HISTORIQUE

ERR_func_error_string() est devenu obsolète dans OpenSSL 3.0.
