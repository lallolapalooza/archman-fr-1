erff(3) Manuel des fonctions de bibliothèque erff(3)

NOM

erf, erff, erfl - fonction d'erreur

BIBLIOTHÈQUE

Bibliothèque mathématique (libm, -lm)

SYNTAXE

#include <math.h>
double erf(double x);
float erff(float x);
long double erfl(long double x);
Exigences de macro de test de fonctionnalités pour glibc (voir feature_test_macros(7)) :

erf() :

    _ISOC99_SOURCE || _POSIX_C_SOURCE >= 200112L || _XOPEN_SOURCE
        || /* Depuis glibc 2.19 : */ _DEFAULT_SOURCE
        || /* glibc <= 2.19 : */ _BSD_SOURCE || _SVID_SOURCE

erff(), erfl() :

    _ISOC99_SOURCE || _POSIX_C_SOURCE >= 200112L
        || /* Depuis glibc 2.19 : */ _DEFAULT_SOURCE
        || /* glibc <= 2.19 : */ _BSD_SOURCE || _SVID_SOURCE

DESCRIPTION

Ces fonctions retournent la fonction d'erreur de x, définie comme


erf(x) = 2/sqrt(pi) * integrale de 0 à x de exp(-t*t) dt

VALEUR DE RETOUR

En cas de succès, ces fonctions retournent la valeur de la fonction d'erreur de x, une valeur comprise dans l'intervalle [-1, 1].

Si x est un NaN, un NaN est retourné.

Si x est +0 (-0), +0 (-0) est retourné.

Si x est l'infini positif (infini négatif), +1 (-1) est retourné.

Si x est subnormal, une erreur de plage se produit et la valeur de retour est 2*x/sqrt(pi).

ERREURS

Voir math_error(7) pour savoir comment déterminer si une erreur s'est produite lors de l'appel de ces fonctions.

Les erreurs suivantes peuvent survenir :

Erreur de plage : sous-dépassement de résultat (x est subnormal)
Une exception de virgule flottante de sous-dépassement (FE_UNDERFLOW) est levée.

Ces fonctions ne définissent pas errno.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
erf (), erff (), erfl () Sécurité des threads MT-Safe

NORMES

C11, POSIX.1-2008.

HISTORIQUE

C99, POSIX.1-2001.

La variante retournant double est également conforme à SVr4, 4.3BSD.

VOIR AUSSI

cerf(3), erfc(3), exp(3)
