error(3) Manuel des fonctions de bibliothèque error(3)

NOM

error, error_at_line, error_message_count, error_one_per_line, error_print_progname - fonctions de rapport d'erreurs glibc

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <error.h>
void error(int status, int errnum, const char *format, ...);
void error_at_line(int status, int errnum, const char *file,
                   unsigned int line, const char *format, ...);
extern unsigned int error_message_count;
extern int error_one_per_line;
extern typeof(void (void))  *error_print_progname;

DESCRIPTION

error() est une fonction générale de rapport d'erreurs. Elle vide stdout, puis écrit sur stderr le nom du programme, deux-points et un espace, le message spécifié par la chaîne de caractères de format de type printf(3) format, et, si errnum est non nul, deux-points et un espace suivis de la chaîne donnée par strerror(errnum). Tous les arguments requis pour format devraient suivre format dans la liste d'arguments. La sortie est terminée par un caractère de nouvelle ligne.

Le nom du programme affiché par error() est la valeur de la variable globale program_invocation_name(3). program_invocation_name a initialement la même valeur que le argv[0] de main(). La valeur de cette variable peut être modifiée pour changer la sortie de error().

Si status a une valeur non nulle, alors error() appelle exit(3) pour terminer le programme en utilisant la valeur donnée comme statut de sortie ; sinon, elle retourne après avoir affiché le message d'erreur.

La fonction error_at_line() est exactement la même que error(), à l'exception de l'ajout des arguments file et line. La sortie produite est la même que pour error(), sauf qu'après le nom du programme sont écrits : deux-points, la valeur de file, deux-points, et la valeur de line. Les valeurs du préprocesseur __LINE__ et __FILE__ peuvent être utiles lors de l'appel à error_at_line(), mais d'autres valeurs peuvent également être utilisées. Par exemple, ces arguments pourraient se référer à un emplacement dans un fichier d'entrée.

Si la variable globale error_one_per_line est définie à une valeur non nulle, une séquence d'appels à error_at_line() avec la même valeur de file et line ne produira qu'un seul message (le premier) ; sortira.

La variable globale error_message_count compte le nombre de messages qui ont été générés par error() et error_at_line().

Si la variable globale error_print_progname est assignée à l'adresse d'une fonction (c'est-à-dire n'est pas NULL), alors cette fonction est appelée au lieu de préfixer le message avec le nom du programme et les deux-points. La fonction devrait écrire une chaîne appropriée sur stderr.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
error () Sécurité des threads MT-Safe locale
error_at_line () Sécurité des threads MT-Unsafe race: error_at_line/error_one_per_line locale

La variable interne error_one_per_line est accédée (sans aucune forme de synchronisation, mais comme c'est un int utilisé une seule fois, cela devrait être suffisamment sûr), et si error_one_per_line est définie à une valeur non nulle, les variables statiques internes (non exposées aux utilisateurs) utilisées pour stocker le dernier nom de fichier et numéro de ligne imprimés sont accédées et modifiées sans synchronisation ; la mise à jour n'est pas atomique et se produit avant la désactivation de l'annulation, elle peut donc être interrompue seulement après la modification de l'une des deux variables. Après cela, error_at_line() est très similaire à error().
