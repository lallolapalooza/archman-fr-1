NOM

erofsfuse - Client de système de fichiers FUSE pour le système de fichiers erofs

SYNTAXE

erofsfuse [OPTIONS] PÉRIPHÉRIQUE POINT_DE_MONTAGE

DESCRIPTION

erofsfuse est un client de système de fichiers FUSE qui permet la lecture à partir de périphériques ou de fichiers image contenant un système de fichiers erofs.

OPTIONS

options générales :

-o opt,[opt...]
options de montage
-h --help
afficher l'aide et quitter

options erofsfuse :

--dbglevel=#
Spécifier le niveau des messages de débogage. La valeur par défaut est 2, qui affiche les messages d'avertissement de base.
--device=chemin
Spécifier un périphérique supplémentaire à utiliser conjointement. Vous pouvez donner plusieurs options `--device' dans le bon ordre.
--offset=#
Spécifier `--offset' octets à ignorer lors de la lecture du fichier image. La valeur par défaut est 0.

options FUSE :

-d -o debug
activer la sortie de débogage (implique -f)
-f
opération en premier plan
-s
désactiver l'opération multithread

Pour d'autres options FUSE, veuillez consulter mount.fuse(8) ou consulter la sortie de erofsfuse --help

DISPONIBILITÉ

erofsfuse fait partie du paquet erofs-utils et est disponible depuis git://git.kernel.org/pub/scm/linux/kernel/git/xiang/erofs-utils.git.
