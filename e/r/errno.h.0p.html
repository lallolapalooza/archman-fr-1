DESCRIPTIO

N

Certaines des fonctionnalités décrites sur cette page de référence étendent la norme ISO C. Tout conflit entre les exigences décrites ici et la norme ISO C est involontaire. Ce volume de POSIX.1‐2017 se conforme à la norme ISO

C.

La norme ISO C exige uniquement que les symboles [EDOM], [EILSEQ] et [ERANGE] soient

définis.

L'en-tête <errno.h> doit fournir une déclaration ou une définition pour errno. Le symbole errno doit s'étendre à une lvalue modifiable de type int. Il n'est pas spécifié si errno est une macro ou un identifiant déclaré avec une liaison externe. Si une définition de macro est supprimée afin d'accéder à un objet réel, ou si un programme définit un identifiant avec le nom errno, le comportement est

indéfini.

L'en-tête <errno.h> doit définir les macros suivantes qui doivent s'étendre à des expressions constantes entières de type int, à valeurs positives distinctes (sauf comme indiqué ci-dessous), et qui doivent être adaptées à une utilisation dans les directives de prétraitement #if
