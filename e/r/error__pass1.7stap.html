NOM

error::pass1 - erreurs de passe 1 (analyse) de systemtap

DESCRIPTION

Les erreurs qui se produisent pendant la passe 1 (analyse) signifient généralement une erreur de syntaxe de base dans le script systemtap. Plusieurs classes de problèmes sont possibles :

erreur de syntaxe simple
L'analyseur de script systemtap détecte une grande variété d'erreurs, telles que des opérandes manquants, une mauvaise ponctuation. Il essaie d'indiquer quels types de jetons il s'attendait à voir, et montrera la région du code source problématique. Veuillez consulter la page man de stap(1) et/ou le tutoriel pour corriger la syntaxe du script.
ambiguïtés grammaticales
Il existe au moins une ambiguïté connue dans la grammaire de systemtap. Elle concerne le caractère optionnel des séparateurs ; (point-virgule) entre les instructions, et les opérateurs d'incrémentation/décrémentation ++ et --. Si l'analyseur signale une erreur, envisagez d'ajouter des séparateurs ; explicites entre les instructions voisines et réessayez.
arguments manquants en ligne de commande
Un script systemtap qui utilise les constructions $N et @N pour substituer des options de ligne de commande peut échouer si suffisamment d'options n'ont pas été fournies sur la ligne de commande de stap.
changements de compatibilité
Certaines versions de systemtap ont modifié le langage de manière incompatible, par exemple en ajoutant les mots-clés try/catch pour la gestion des exceptions. Dans de tels cas, relancez systemtap avec l'option --compatibility=VERSION, en substituant la dernière version de systemtap où votre script était connu pour fonctionner. Vous pouvez également consulter le fichier NEWS de l'historique des versions pour les changements de compatibilité.

RASSEMBLER PLUS D'INFORMATIONS

Augmenter la verbosité de la passe 1 avec une option telle que --vp 1 peut aider à identifier le problème.
