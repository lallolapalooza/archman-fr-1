erfc(3) Manuel des fonctions de bibliothèque erfc(3)

NOM

erfc, erfcf, erfcl - fonction d'erreur complémentaire

BIBLIOTHÈQUE

Bibliothèque mathématique (libm, -lm)

SYNTAXE

#include <math.h>
double erfc(double x);
float erfcf(float x);
long double erfcl(long double x);
Exigences de Macro de Test de Fonctionnalité pour glibc (voir feature_test_macros(7)) :

erfc() :

    _ISOC99_SOURCE || _POSIX_C_SOURCE >= 200112L || _XOPEN_SOURCE
        || /* Depuis glibc 2.19 : */ _DEFAULT_SOURCE
        || /* glibc <= 2.19 : */ _BSD_SOURCE || _SVID_SOURCE

erfcf(), erfcl() :

    _ISOC99_SOURCE || _POSIX_C_SOURCE >= 200112L
        || /* Depuis glibc 2.19 : */ _DEFAULT_SOURCE
        || /* glibc <= 2.19 : */ _BSD_SOURCE || _SVID_SOURCE

DESCRIPTION

Ces fonctions retournent la fonction d'erreur complémentaire de x, c'est-à-dire 1.0 - erf(x).

VALEUR DE RETOUR

En cas de succès, ces fonctions retournent la fonction d'erreur complémentaire de x, une valeur dans l'intervalle [0,2].

Si x est un NaN, un NaN est retourné.

Si x est +0 ou -0, 1 est retourné.

Si x est l'infini positif, +0 est retourné.

Si x est l'infini négatif, +2 est retourné.

Si le résultat de la fonction sous-dépasse et produit une valeur non représentable, la valeur de retour est 0.0.

Si le résultat de la fonction sous-dépasse mais produit une valeur représentable (c'est-à-dire sous-normale), cette valeur est retournée et une erreur de plage se produit.

ERREURS

Voir math_error(7) pour des informations sur la façon de déterminer si une erreur s'est produite lors de l'appel de ces fonctions.

Les erreurs suivantes peuvent survenir :

Erreur de plage : sous-dépassement du résultat (résultat sous-normal)
Une exception de virgule flottante de sous-dépassement (FE_UNDERFLOW) est levée.

Ces fonctions ne définissent pas errno.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
erfc (), erfcf (), erfcl () Sécurité des threads MT-Safe

NORMES

C11, POSIX.1-2008.

HISTORIQUE

C99, POSIX.1-2001.

La variante retournant double est également conforme à SVr4, 4.3BSD.

NOTES

Les fonctions erfc(), erfcf() et erfcl() sont fournies pour éviter la perte de précision qui se produirait pour le calcul 1-erf(x) pour des valeurs importantes de x (pour lesquelles la valeur de erf(x) approche 1).

VOIR AUSSI

cerf(3), erf(3), exp(3)
