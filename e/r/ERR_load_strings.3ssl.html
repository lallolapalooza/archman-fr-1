ERR_load_strings(3ssl)

Paquet: openssl

Licences: Apache-2.0

ERR_LOAD_STRINGS(3ssl) OpenSSL ERR_LOAD_STRINGS(3ssl)

NOM

ERR_load_strings, ERR_PACK, ERR_get_next_error_library - charger des chaînes d'erreurs arbitraires

SYNTAXE

#include <openssl/err.h>
int ERR_load_strings(int lib, ERR_STRING_DATA *str);
int ERR_get_next_error_library(void);
unsigned long ERR_PACK(int lib, int func, int reason);

DESCRIPTION

ERR_load_strings() enregistre les chaînes d'erreurs pour la bibliothèque numéro lib.

str est un tableau de données de chaînes d'erreurs :

typedef struct ERR_string_data_st
{
    unsigned long error;
    char *string;
} ERR_STRING_DATA;

Le code d'erreur est généré à partir du numéro de bibliothèque et d'un code de fonction et de raison : error = ERR_PACK(lib, func, reason). ERR_PACK() est une macro.

La dernière entrée du tableau est {0,0}.

ERR_get_next_error_library() peut être utilisée pour attribuer des numéros de bibliothèque aux bibliothèques utilisateur à l'exécution.

VALEURS DE RETOUR

ERR_load_strings() retourne 1 en cas de succès et 0 en cas d'échec. ERR_PACK() retourne le code d'erreur. ERR_get_next_error_library() retourne zéro en cas d'échec, sinon un nouveau numéro de bibliothèque.
