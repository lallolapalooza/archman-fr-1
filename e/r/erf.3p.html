ERF(3P) Manuel du programmeur POSIX ERF(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

erf, erff, erfl — fonctions d'erreur

SYNTAXE

#include <math.h>
double erf(double x);
float erff(float x);
long double erfl(long double x);

DESCRIPTION

La fonctionnalité décrite sur cette page de référence est alignée avec la norme ISO C. Tout conflit entre les exigences décrites ici et la norme ISO C est involontaire. Ce volume de POSIX.1-2017 renvoie à la norme ISO C.

Ces fonctions calculent la fonction d'erreur de leur argument x, définie comme suit :

2π∫0xe-t2dt

Une application souhaitant vérifier les situations d'erreur doit initialiser errno à zéro et appeler feclearexcept(FE_ALL_EXCEPT) avant d'appeler ces fonctions. Au retour, si errno est différent de zéro ou si fetestexcept(FE_INVALID | FE_DIVBYZERO | FE_OVERFLOW | FE_UNDERFLOW) est différent de zéro, une erreur s'est produite.

VALEUR RENVOYÉE

En cas de succès, ces fonctions renvoient la valeur de la fonction d'erreur.

Si x est NaN, un NaN est renvoyé.

Si x est ±0, ±0 est renvoyé.

Si x est ±Inf, ±1 est renvoyé.

Si la valeur correcte entraînerait un sous-dépassement, une erreur de plage peut se produire, et erf(), erff() et erfl() renvoient une valeur indéfinie par l'implémentation, dont la magnitude n'est pas supérieure à DBL_MIN, FLT_MIN et LDBL_MIN, respectivement.

Si l'option à virgule flottante IEC 60559 est prise en charge, 2 * x/sqrt(π) doit être retourné.

ERREURS

Ces fonctions peuvent échouer si :

Erreur de plage
Le résultat sous-dépasse.

Si l'expression entière (math_errhandling & MATH_ERRNO) est différente de zéro, alors errno est défini sur [ERANGE]. Si l'expression entière (math_errhandling & MATH_ERREXCEPT) est différente de zéro, alors l'exception à virgule flottante de sous-dépassement est levée.

Les sections suivantes sont informatives.

EXEMPLES

Calcul de la probabilité pour une variable normale

Cet exemple montre comment utiliser erf() pour calculer la probabilité qu'une variable normale prenne une valeur dans l'intervalle [x1,x2] avec x1≤x2.

Cet exemple utilise la constante M_SQRT1_2 qui fait partie de l'option XSI.

#include <math.h>
double
Phi(const double x1, const double x2)
{
    return ( erf(x2*M_SQRT1_2) - erf(x1*M_SQRT1_2) ) / 2;
}

UTILISATION PAR L'APPLICATION

Le sous-dépassement se produit lorsque |x| < DBL_MIN * (sqrt(π)/2).

En cas d'erreur, les expressions (math_errhandling & MATH_ERRNO) et (math_errhandling & MATH_ERREXCEPT) sont indépendantes l'une de l'autre, mais au moins une d'entre elles doit être différente de zéro.

RATIONALE

Aucune.

ORIENTATIONS FUTURES

Aucune.

VOIR AUSSI
