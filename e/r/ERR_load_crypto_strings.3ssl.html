ERR_load_crypto_strings(3ssl)

Paquet: openssl

Licences: Apache-2.0

ERR_LOAD_CRYPTO_STRINGS(3ssl) OpenSSL ERR_LOAD_CRYPTO_STRINGS(3ssl)

NOM

ERR_load_crypto_strings, SSL_load_error_strings, ERR_free_strings - charger et libérer les chaînes d'erreurs

SYNTAXE

Les fonctions suivantes ont été dépréciées depuis OpenSSL 1.1.0, et peuvent être entièrement masquées en définissant OPENSSL_API_COMPAT avec une valeur de version appropriée, voir openssl_user_macros(7) :

#include <openssl/err.h>
void ERR_load_crypto_strings(void);
void ERR_free_strings(void);
#include <openssl/ssl.h>
void SSL_load_error_strings(void);

DESCRIPTION

ERR_load_crypto_strings() enregistre les chaînes d'erreurs pour toutes les fonctions de libcrypto. SSL_load_error_strings() fait de même, mais enregistre également les chaînes d'erreurs de libssl.

Dans les versions antérieures à OpenSSL 1.1.0, ERR_free_strings() libère toutes les ressources créées par les fonctions ci-dessus.

VALEURS DE RETOUR

ERR_load_crypto_strings(), SSL_load_error_strings() et ERR_free_strings() ne retournent aucune valeur.

VOIR AUSSI

ERR_error_string(3)

HISTORIQUE

Les fonctions ERR_load_crypto_strings(), SSL_load_error_strings() et ERR_free_strings() ont été dépréciées dans OpenSSL 1.1.0 par OPENSSL_init_crypto() et OPENSSL_init_ssl() et ne devraient pas être utilisées.
