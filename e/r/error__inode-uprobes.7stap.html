NOM

error::inode-uprobes - limitations de inode-uprobes

DESCRIPTION

La facilité de sondage du noyau uprobes introduite dans Linux 3.5 vise à supplanter le patch utrace externe précédent pour permettre le sondage de l'espace utilisateur. Il y a eu quelques limitations fonctionnelles dans inode-uprobes qui excluent certains constructs systemtap. Avec le temps, nous espérons que ces régressions seront corrigées.

sondes function.return
Les sondes process.function().return nécessitent une fonctionnalité de "return-probes" ou "uretprobes", qui n'a été implémentée dans les inode-uprobes intégrées qu'à partir du noyau 3.10. Si vous ne pouvez pas mettre à jour votre noyau, envisagez d'utiliser les sondes process.statement() placées sur les numéros de ligne source aux instructions de retour de la fonction.
sondes function.statement.absolute
Dans les noyaux équipés d'utrace, systemtap permettait de s'adresser aux sondes par des adresses littérales dans l'espace d'adressage mémoire virtuel du processus. Le nouvel inode-uprobes n'a pas cette capacité.
