Errno(3perl) Guide du programmeur Perl Errno(3perl)

NOM

Errno - Constantes d'erreur système errno

SYNOPSIS

use Errno qw(EINTR EIO :POSIX);

DESCRIPTION

"Errno" définit et exporte conditionnellement toutes les constantes d'erreur définies dans le fichier d'inclusion errno.h de votre système. Il possède une seule étiquette d'exportation, ":POSIX", qui exportera tous les numéros d'erreur définis par POSIX.

Sous Windows, "Errno" définit et exporte également conditionnellement toutes les constantes d'erreur Winsock définies dans le fichier d'inclusion WinError.h de votre système. Celles-ci sont incluses dans une deuxième étiquette d'exportation, ":WINSOCK".

"Errno" rend également la variable magique "%!" telle que chaque élément de "%!" a une valeur non nulle uniquement si $! est défini à cette valeur. Par exemple :

my $fh;
unless (open($fh, "<", "/fangorn/spouse")) {
    if ($!{ENOENT}) {
        warn "Trouve une épouse !\n";
    } else {
        warn "Ce chemin est bloqué : $!";
    }
}

Si une constante spécifiée "EFOO" n'existe pas sur le système, $!{EFOO} retourne "". Vous pouvez utiliser "exists $!{EFOO}" pour vérifier si la constante est disponible sur le système.

Perl charge automatiquement "Errno" dès la première utilisation de "%!", vous n'avez donc pas besoin d'un "use" explicite.

PRÉCAUTIONS

L'importation d'une constante particulière peut ne pas être très portable, car l'importation échouera sur les plateformes qui ne disposent pas de cette constante. Une méthode plus portable pour définir $! à une valeur valide consiste à utiliser :

if (exists &Errno::EFOO) {
    $! = &Errno::EFOO;
}
