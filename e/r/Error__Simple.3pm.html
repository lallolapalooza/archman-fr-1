Error::Simple(3) Documentation Perl fournie par l'utilisateur Error::Simple(3)

NOM

Error::Simple - la sous-classe d'erreur simple de Error

VERSION

version 0.17030

SYNTAXE

use base 'Error::Simple';

DESCRIPTION

Le seul but de ce module est de permettre à quelqu'un de dire :

use base 'Error::Simple';

et la seule chose qu'il fait est d'"utiliser" Error.pm. Reportez-vous à la documentation de Error pour plus d'informations sur Error::Simple.

MÉTHODES

Error::Simple->new($texte [, $valeur])

Construit un Error::Simple avec le texte $texte et la valeur optionnelle $valeur.

$err->stringify()

Error::Simple surcharge cette méthode.
