ERR_remove_state(3ssl)

Paquet: openssl

Licences: Apache-2.0

ERR_REMOVE_STATE(3ssl) OpenSSL ERR_REMOVE_STATE(3ssl)

NOM

ERR_remove_thread_state, ERR_remove_state - OBSOLÈTE

SYNTAXE

La fonction suivante a été obsolète depuis OpenSSL 1.0.0, et peut être complètement masquée en définissant OPENSSL_API_COMPAT avec une valeur de version appropriée, voir openssl_user_macros(7) :

void ERR_remove_state(unsigned long tid);

La fonction suivante a été obsolète depuis OpenSSL 1.1.0, et peut être complètement masquée en définissant OPENSSL_API_COMPAT avec une valeur de version appropriée, voir openssl_user_macros(7) :

void ERR_remove_thread_state(void *tid);

DESCRIPTION

ERR_remove_state() libère la file d'attente d'erreurs associée au thread spécifié, identifié par tid. ERR_remove_thread_state() fait la même chose, sauf que l'identifiant est un pointeur opaque.

VALEURS DE RETOUR

ERR_remove_state() et ERR_remove_thread_state() ne retournent aucune valeur.

VOIR AUSSI

LOPENSSL_init_crypto(3)

HISTORIQUE

ERR_remove_state() a été obsolète dans OpenSSL 1.0.0 et ERR_remove_thread_state() a été obsolète dans OpenSSL 1.1.0 ; ces fonctions ne doivent pas être utilisées.
