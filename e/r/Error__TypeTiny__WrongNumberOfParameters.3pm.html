NOM

Error::TypeTiny::WrongNumberOfParameters - exception pour Type::Params

STATUT

Ce module est couvert par la politique de stabilité de Type-Tiny.

DESCRIPTION

Lancée lorsqu'une vérification compilée de Type::Params est appelée avec le mauvais nombre de paramètres.

Également lancée par diverses contraintes de type paramétrables dans des circonstances similaires. Par exemple, "HashRef[Int]" a du sens, mais "HashRef[Int, {}]" n'en a pas.

Ce paquet hérite de Error::TypeTiny ; consultez ce dernier pour la plupart de la documentation. Les différences majeures sont listées ci-dessous :

Attributs

"minimum"
Le nombre minimum attendu de paramètres.
"maximum"
Le nombre maximum attendu de paramètres.
"got"
Le nombre de paramètres réellement passés à la vérification compilée.
"target"
Une courte chaîne décrivant pour quoi le nombre de paramètres était incorrect.

Méthodes

"has_minimum", "has_maximum", "has_target"
Méthodes prédicats.
