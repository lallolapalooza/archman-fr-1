NOM

errno - rechercher les noms et descriptions d'errno

SYNOPIS


errno
{nom-ou-code}

errno
[-ls] [--list]

errno
[-s] [--search] {mot}

errno
[-S] [--search-all-locales] {mot}

DESCRIPTION

errno recherche les noms de macros errno, les codes errno et les descriptions correspondantes. Par exemple, si on lui donne ENOENT sur un système Linux, il affichera le code 2 et la description "No such file or directory". Si on lui donne le code 2, il affichera ENOENT et la même description.

OPTIONS

-l, --list
Lister toutes les valeurs errno.
-s, --search
Rechercher les erreurs dont la description contient tous les mots donnés (insensible à la casse).
-S, --search-all-locales
Comme --search, mais recherche dans toutes les locales installées.
