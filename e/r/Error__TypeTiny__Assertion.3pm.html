NOM

Error::TypeTiny::Assertion - exception lorsqu'une valeur échoue à une contrainte de type

STATUT

Ce module est couvert par la politique de stabilité de Type-Tiny.

DESCRIPTION

Cette exception est lancée lorsqu'une valeur échoue à une assertion de contrainte de type.

Ce paquet hérite de Error::TypeTiny ; voir ce dernier pour la plupart des documentations. Les différences majeures sont listées ci-dessous :

Attributs

"type"
La contrainte de type qui a été vérifiée. Des liens affaiblis sont impliqués, donc cela peut finir par être "undef".
"value"
La valeur qui a été testée.
"varname"
Le nom de la variable qui a été vérifiée, si connu. Par défaut, c'est '$_'.
"attribute_name"
Si cette exception a été lancée à la suite d'une vérification isa ou d'une coercition échouée pour un attribut Moo, ceci indiquera quel attribut (si votre Moo est suffisamment récent).

(Espérons qu'un jour cela supportera d'autres frameworks OO.)

"attribute_step"
Si cette exception a été lancée à la suite d'une vérification isa ou d'une coercition échouée pour un attribut Moo, ceci contiendra soit "isa check", soit "coercion" pour indiquer ce qui a mal tourné (si votre Moo est suffisamment récent).

(Espérons qu'un jour cela supportera d'autres frameworks OO.)

Méthodes

"has_type", "has_attribute_name", "has_attribute_step"
Méthodes prédicats.
"message"
Surchargée pour ajouter "varname" au message s'il est défini.
"explain"
Tente d'expliquer pourquoi la valeur n'a pas satisfait la contrainte de type. Retourne un arrayref de chaînes fournissant un raisonnement étape par étape ; ou retourne undef si aucune explication n'est possible.
