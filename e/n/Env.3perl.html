Env(3perl) Guide du programmeur Perl Env(3perl)

NOM

Env - module Perl qui importe les variables d'environnement comme scalaires ou tableaux

SYNTAXE

use Env;
use Env qw(PATH HOME TERM);
use Env qw($SHELL @LD_LIBRARY_PATH);

DESCRIPTION

Perl maintient les variables d'environnement dans une table de hachage spéciale nommée %ENV. Pour les cas où cette méthode d'accès est peu pratique, le module Perl "Env" permet de traiter les variables d'environnement comme des variables scalaires ou de tableau.

La fonction Env::import() lie les variables d'environnement ayant des noms appropriés à des variables globales Perl portant les mêmes noms. Par défaut, elle lie toutes les variables d'environnement existantes ("keys %ENV") à des scalaires. Si la fonction "import" reçoit des arguments, elle les considère comme une liste de variables à lier ; il est acceptable qu'elles n'existent pas encore. Le préfixe de type scalaire '$' est inféré pour tout élément de cette liste non préfixé par '$' ou '@'. Les tableaux sont implémentés en utilisant "split" et "join", en utilisant $Config::Config{path_sep} comme délimiteur.

Après qu'une variable d'environnement a été liée, il suffit de l'utiliser comme une variable normale. Vous pouvez accéder à sa valeur

@path = split(/:/, $PATH);
print join("\n", @LD_LIBRARY_PATH), "\n";

ou la modifier

$PATH .= ":/any/path";
push @LD_LIBRARY_PATH, $dir;

comme bon vous semble. Gardez cependant à l'esprit que chaque accès à une variable de tableau liée nécessite de diviser à nouveau la chaîne de la variable d'environnement.

Le code :

use Env qw(@PATH);
push @PATH, '/any/path';

est presque équivalent à :

use Env qw(PATH);
$PATH .= ":/any/path";

sauf que si $ENV{PATH} était vide au départ, la deuxième approche le laisse avec la valeur (étrange) "":/any/path", mais la première approche le laisse avec ""/any/path".

Pour supprimer une variable d'environnement liée de l'environnement, affectez-lui la valeur indéfinie

undef $PATH;
undef @LD_LIBRARY_PATH;

LIMITATIONS

Sur les systèmes VMS, les tableaux liés aux variables d'environnement sont en lecture seule. Toute tentative de modification entraînera un avertissement.
