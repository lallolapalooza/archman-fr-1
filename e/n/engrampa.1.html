ENGRAMPA(1) Manuel des commandes générales ENGRAMPA(1)

NOM

Engrampa - Gestionnaire d'archives pour MATE

SYNTAXE

engrampa [OPTIONS...] [FICHIERS...]

DESCRIPTION

Engrampa est le gestionnaire d'archives officiel de l'environnement de bureau MATE. C'est une interface graphique pour les utilitaires d'archivage tels que tar et zip. C'est un fork de File Roller.

Engrampa prend en charge la plupart des opérations courantes telles que la création, la modification et l'extraction de fichiers à partir d'une archive. Vous pouvez également afficher le contenu d'une archive et ouvrir les fichiers contenus dans l'archive.
Ce manuel documente brièvement la commande engrampa.

OPTIONS

nom-du-fichier(s)...
Spécifie le fichier archive à ouvrir au démarrage de engrampa. Si ceci n'est pas spécifié, engrampa démarrera avec une fenêtre vide et vous pourrez ouvrir une archive depuis le menu ou en utilisant le raccourci CTRL+O.
-a, --ajouter-à=ARCHIVE
Ajouter des fichiers à l'archive spécifiée et quitter le programme.
-d, --ajouter FICHIER
Ajouter des fichiers en demandant le nom de l'archive et quitter le programme.
-e, --extraire-vers=DOSSIER
Extraire les archives dans le dossier spécifié et quitter le programme.
-f, --extraire
Extraire les archives en demandant le dossier de destination et quitter le programme.
-h, --extraire-ici
Extraire les archives en utilisant le nom de l'archive comme dossier de destination et quitter le programme.
--dossier-par-défaut=DOSSIER
Dossier par défaut à utiliser pour les commandes '--ajouter' et '--extraire'.
--forcer
Créer le dossier de destination sans demander de confirmation.
--display=DISPLAY
Affichage X à utiliser.
-?, --aide
Afficher les options de ligne de commande standard.
--aide-tous
Afficher toutes les options de ligne de commande.
--version
Afficher la version de l'application.

Ce programme accepte également les options GTK standard.

EXEMPLES

engrampa -h matelivecd.iso

Extrait matelivecd.iso dans ./matelivecd dans le répertoire de travail courant.

engrampa ./matelivecd/* -a matelivecd.tar.gz

Crée une nouvelle archive tar compressée gzip nommée matelivecd.tar.gz, contenant tous les fichiers situés dans le répertoire ./matelivecd.

engrampa matelivecd.tar.gz

Ouvre matelivecd.tar.gz pour visualiser et manipuler son contenu.
