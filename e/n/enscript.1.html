NOM

enscript - convertir des fichiers texte en PostScript, HTML, RTF, ANSI et surimpressions

SYNTAXE

enscript [-123456789BcgGhjkKlmOqrRvVzZ] [-# copies] [-a pages] [-A alignement] [-b en-tête] [-C[ligne_début]] [-d imprimante] [-D clé[:valeur]] [-e[car]] [-E[lang]] [-f police] [-F police_en-tête] [-H[num]] [-i indentation] [-I filtre] [-J titre] [-L lignes_par_page] [-M média] [-n copies] [-N nouvelle_ligne] [-o fichier_sortie] [-o -] [-p fichier_sortie] [-p -] [-P imprimante] [-s interligne] [-S clé[:valeur]] [-t titre] [-T taille_tabulation] [-u[texte]] [-U num] [-w langage] [-X encodage] [fichier ...]

DESCRIPTION

Enscript convertit des fichiers texte en PostScript ou en d'autres langages de sortie. Enscript peut envoyer directement la sortie générée à une imprimante spécifiée ou la laisser dans un fichier. Si aucun fichier d'entrée n'est donné, enscript traite l'entrée standard stdin. Enscript peut être étendu pour gérer différents supports de sortie et possède de nombreuses options qui peuvent être utilisées pour personnaliser les impressions.

OPTIONS

-# num
Imprime num copies de chaque page.
-1, -2, -3, -4, -5, -6, -7, -8, -9, --colonnes=num
Spécifie le nombre de colonnes par page. Avec l'option longue --colonnes=num vous pouvez spécifier plus de 9 colonnes par page.
-a pages, --pages=pages
Spécifie quelles pages sont imprimées. La spécification des pages pages peut être donnée dans les formats suivants :
debut-fin
imprime les pages de debut à fin
-fin
imprime les pages de 0 à fin
debut-
imprime les pages de debut à la fin
page
imprime la page page
impair
imprime les pages impaires
pair
imprime les pages paires
-A alignement, --alignement-fichier=alignement
Aligne les fichiers d'entrée séparés pour avoir un nombre pair de pages alignement. Cette option est utile pour l'impression recto-verso et 2 par page (--alignement-fichier=2).
-b en-tête, --en-tête=en-tête
Utilise le texte en-tête comme en-tête de page. L'en-tête de page par défaut est construit à partir du nom du fichier et de sa dernière heure de modification.

La chaîne d'en-tête en-tête peut contenir les mêmes échappements de formatage qui peuvent être spécifiés pour les directives %Format dans les en-têtes fantaisistes définis par l'utilisateur. Par exemple, l'option suivante imprime le nom du fichier, la date actuelle et les numéros de page :

enscript --en-tête='$n %W Page $% sur $=' *.c

La chaîne d'en-tête peut également contenir des champs alignés à gauche, au centre et à droite. Les champs sont séparés par le caractère '|' :

enscript --en-tête='$n|%W|Page $% sur $=' *.c

Maintenant, le nom du fichier est imprimé aligné à gauche, la date est centrée dans l'en-tête et les numéros de page sont imprimés alignés à droite.

-B, --pas-d-en-tete
Ne pas imprimer les en-têtes de page.
-c, --tronquer-lignes
Coupe les lignes trop longues pour la page. Par défaut, enscript renvoie les lignes longues à la ligne suivante afin qu'aucune information ne soit perdue.

Vous pouvez également utiliser l'option --trancher qui découpe les lignes longues sur des pages séparées.

-C[ligne_debut], --numeros-lignes[=ligne_debut]
Précède chaque ligne de son numéro de ligne. L'argument optionnel ligne_debut spécifie le numéro de la première ligne de l'entrée. Le numéro de la première ligne est par défaut 1.
-d nom
Envoie la sortie à l'imprimante nom.
-D clé[:valeur], --definir-peripherique-page=clé[:valeur]
Transmet une définition de périphérique de page à la sortie PostScript générée. Si aucune valeur n'est donnée, la clé clé est supprimée des définitions.

Par exemple, la commande

enscript -DDuplex:true foo.txt

imprime le fichier foo.txt en mode duplex (recto-verso).

Les opérateurs de périphérique de page dépendent de l'implémentation mais ils sont standardisés. Voir la section OPTIONS DE PÉRIPHÉRIQUE DE PAGE pour les détails.

-e[car], --echappements[=car]
Active l'interprétation des échappements spéciaux (voir la section ÉCHAPPEMENTS SPÉCIAUX). Si l'argument car est donné, il change le caractère d'échappement en car. Le caractère d'échappement par défaut est 0.
-E[lang], --surligner[=lang]
Surligne le code source en créant un filtre d'entrée spécial avec le programme states. L'argument optionnel lang spécifie le langage à surligner. Par défaut, states fait une supposition éclairée.

Vous pouvez imprimer une courte description des langages de surlignage et des formats de fichiers pris en charge avec la commande :

enscript --aide-surlignage

Les règles de surlignage sont définies dans les fichiers `/usr/share/enscript/hl/*.st' qui peuvent être modifiés pour créer des définitions de surlignage pour de nouveaux langages.

Note ! Vous ne pouvez pas utiliser vos propres filtres d'entrée avec cette option.

-f nom, --police=nom
Sélectionne une police utilisée pour le texte du corps. La police de corps par défaut est Courier10, sauf si le mode d'impression paysage multicolonne est sélectionné, auquel cas la police par défaut est Courier7.

La spécification de police nom contient deux parties : le nom de la police et sa taille en points PostScript. Par exemple, "Times-Roman12" sélectionne la police "Times-Roman" avec une taille de 12pt.

La spécification de police nom peut également être donnée au format `nom@taille_pt', où le nom de la police et sa taille en points sont séparés par un caractère `@'. Ceci permet à enscript d'utiliser des polices dont les noms contiennent des chiffres.

La taille de police en points peut également être donnée au format largeur/hauteur où la largeur et la hauteur spécifient la taille de la police dans les directions x et y. Par exemple, "Times-Roman@10/12" sélectionne une police "Times-Roman" de 10 points de large et 12 points de haut.

Vous pouvez également donner les tailles de police sous forme de nombres décimaux. Par exemple, "Times-Roman10.2" sélectionne une police "Times-Roman" de 10,2pt.

-F nom, --police-en-tete=nom
Sélectionne une police pour les textes d'en-tête.
-g, --imprimer-quand-meme
Imprime un fichier même s'il contient des données binaires. L'option n'est implémentée qu'à des fins de compatibilité. Enscript imprime de toute façon les fichiers binaires, quelle que soit l'option.
-G, --en-tete-fantaisie[=nom]
Imprime un en-tête de page fantaisie nom en haut de chaque page. L'option -G spécifie l'en-tête fantaisie par défaut. Voir la section FICHIERS DE CONFIGURATION pour voir comment l'en-tête fantaisie par défaut peut être modifié.
-h, --pas-d-en-tete-job
Supprime l'impression de la page d'en-tête du travail.
-H[num]
>, --hauteur-barres[=nombre]
Spécifiez la hauteur des barres de surbrillance en lignes. Si le nombre n'est pas donné, la valeur par défaut 2 est utilisée. Par défaut, aucune barre de surbrillance n'est imprimée.
-i nombre, --indent=nombre
Indente chaque ligne de nombre caractères. L'indentation peut également être spécifiée dans d'autres unités en ajoutant un spécificateur d'unité après le nombre. Les spécificateurs d'unité possibles et les unités correspondantes sont :
c
centimètres
i
pouces
l
caractères (par défaut)
p
points PostScript
-I filtre, --filter=filtre
Lit tous les fichiers d'entrée via un filtre d'entrée filtre. Le filtre d'entrée peut être une commande unique ou un pipeline de commandes. Le filtre peut faire référence au nom du fichier d'entrée avec l'échappement `%s'. Le nom de l'entrée standard peut être modifié avec l'option `--filter-stdin'.

Par exemple, la commande suivante imprime le fichier `foo.c' en utilisant uniquement des caractères majuscules :

enscript --filter="cat %s | tr 'a-z' 'A-Z'" foo.c

La commande suivante met en évidence les modifications apportées aux fichiers depuis le dernier enregistrement :

enscript --filter="rcsdiff %s | diffpp %s" -e *.c

Pour inclure la chaîne "%s" dans la commande de filtre, vous devez l'écrire sous la forme "%%s".

-J titre

-k, --page-prefeed

-l, --lineprinter
Émule une imprimante ligne par ligne. Cette option est un raccourci pour les options --lines-per-page=66 et --no-header.
-L nombre, --lines-per-page=nombre
Imprime seulement nombre lignes par page. Par défaut, le nombre de lignes par page est calculé à partir de la hauteur de la page et de la taille de la police.
-m, --mail
Envoie une notification par e-mail à l'utilisateur une fois le travail d'impression terminé.
-M nom, --media=nom
Sélectionne un média de sortie nom. Le média de sortie par défaut d'Enscript est A4.
-n nombre, --copies=nombre
Imprime nombre copies de chaque page.
-N nl, --newline=nl
Sélectionne le caractère de nouvelle ligne. Les valeurs possibles pour nl sont : n (nouvelle ligne Unix, 0xa hex) et r (nouvelle ligne Mac, 0xd hex).
-o fichier
Un alias pour l'option -p, --output.
-O, --missing-characters
Imprime une liste des codes de caractères qui n'ont pas pu être imprimés.
-p fichier, --output=fichier
Laisse la sortie dans le fichier fichier. Si le fichier est `-', enscript envoie la sortie à la sortie standard stdout.
-P nom, --printer=nom
Envoie la sortie à l'imprimante nom.
-q, --quiet, --silent
Rend enscript vraiment silencieux. Seuls les messages d'erreur fatals sont imprimés sur stderr.
-r, --landscape
Imprime en mode paysage ; tourne la page de 90 degrés.
-R, --portrait
Imprime en mode portrait (par défaut).
-s nombre, --baselineskip=nombre
Spécifie l'espacement de ligne de base en points PostScript. Le nombre nombre peut être donné sous forme de nombre décimal. Lorsque enscript passe d'une ligne à l'autre, la coordonnée y du point courant est déplacée de (taille de point de police + espacement de ligne de base) points vers le bas. L'espacement de ligne de base par défaut est de 1.
-S clé[:valeur], --statusdict=clé[:valeur]
Passe une définition de dictionnaire d'état à la sortie PostScript générée. Si aucune valeur n'est donnée, la clé clé est retirée des définitions.

Les opérateurs du dictionnaire d'état dépendent de l'implémentation ; consultez la documentation de l'imprimante pour plus de détails.

Par exemple, la commande

enscript -Ssetpapertray:1 foo.txt

imprime le fichier foo.txt en utilisant le papier du bac à papier 1 (en supposant que l'imprimante prend en charge la sélection du bac à papier).

-t titre, --title=titre
Définit le titre du travail de la page de garde à titre. L'option définit également le nom du fichier d'entrée stdin.
-T nombre, --tabsize=nombre
Définit la taille de la tabulation à nombre caractères. La valeur par défaut est 8.
-u[texte], --underlay[=texte]
Imprime la chaîne texte sous chaque page. Les propriétés du texte peuvent être modifiées avec les options --ul-angle, --ul-font, --ul-gray, --ul-position et --ul-style.

Si aucun texte n'est donné, le fond de page n'est pas imprimé. Ceci peut être utilisé pour supprimer un texte de fond spécifié avec l'option `Underlay' du fichier de configuration.

-U nombre, --nup=nombre
Imprime nombre pages logiques sur chaque page de sortie (impression N-up). La valeur nombre doit être une puissance de 2.
-v, --verbose[=niveau]
Indique ce que fait enscript.
-V, --version

CONFIGURATION

Enscript lit les informations de configuration des sources suivantes (dans cet ordre) : options de la ligne de commande, variable d'environnement ENSCRIPT, fichier de configuration personnel de l'utilisateur ($HOME/.enscriptrc), fichier de configuration du site (/etc/enscript/enscriptsite.cfg) et fichier de configuration global du système (/etc/enscript/enscript.cfg)

.

commentaires.

FANCY

Les utilisateurs peuvent créer leurs propres en-têtes personnalisés en créant un fichier de description d'en-tête et en le plaçant dans un répertoire qui se trouve dans le chemin de bibliothèque d'enscript. OPTIONS DE PÉRIPHÉRIQUE DE PAGE

Le périphérique de page est une fonctionnalité de PostScript niveau 2 qui offre une interface uniforme pour contrôler le périphérique de sortie de l'imprimante. Enscript protège toutes les options du périphérique de page à l'intérieur d'un bloc `if`, de sorte qu'elles n'ont aucun effet dans les interpréteurs de niveau 1. Bien que tous les interpréteurs de niveau 2 prennent en charge le périphérique de page, ils ne sont pas obligés de prendre en charge toutes les options du périphérique de page. Par exemple, certaines imprimantes peuvent imprimer en mode recto-verso et d'autres non. Reportez-vous à la documentation de votre imprimante pour connaître les options prises en charge.

Voici quelques options utilisables pour le périphérique de page qui peuvent être sélectionnées avec l'option -D, --setpagedevice. Pour une liste complète, voir le *PostScript Language Reference Manual* : section 4.11 Device Setup.

Collate booléen
organisation de la sortie lors de l'impression de plusieurs copies
Duplex booléen
impression recto-verso
ManualFeed booléen
bac papier à alimentation manuelle
OutputFaceUp booléen
impression de la sortie `face dessus' ou `face dessous'

positionnement des côtés opposés en impression recto-verso

EXEMPLES D'IMPRESSION

Les exemples d'impression suivants supposent qu'enscript utilise la configuration par défaut. Si les actions par défaut ont été modifiées dans les fichiers de configuration, certains exemples se comporteront différemment.

enscript foo.txt
Imprime le fichier foo.txt sur l'imprimante par défaut.
enscript -Possu foo.txt
Imprime le fichier foo.txt sur l'imprimante ossu.
enscript -pfoo.ps foo.txt
Imprime le fichier foo.txt, mais laisse la sortie PostScript dans le fichier foo.ps.
enscript -2 foo.txt
Imprime le fichier foo.txt en deux colonnes.
enscript -2r foo.txt
Imprime le fichier en deux colonnes et fait pivoter la sortie de 90 degrés (paysage).
enscript -DDuplex:true foo.txt
Imprime le fichier en mode recto-verso (dépendant de l'imprimante).
enscript -G2rE -U2 foo.c
Ma commande par défaut pour l'impression de code : en-tête voyant, deux colonnes, paysage, coloration syntaxique, impression 2-up.
enscript -E --color -whtml --toc -pfoo.html *.h *.c
Un joli rapport HTML des fichiers sources C de votre projet.

VARIABLES D'ENVIRONNEMENT

La variable d'environnement ENSCRIPT peut être utilisée pour transmettre des options par défaut à enscript. Par exemple, pour sélectionner la police de corps par défaut comme Times-Roman 7pt, définissez la valeur suivante pour la variable d'environnement ENSCRIPT :

-fTimes-Roman7

La valeur de la variable ENSCRIPT est traitée avant les options de ligne de commande, de sorte que les options de ligne de commande peuvent être utilisées pour remplacer ces valeurs par défaut.

La variable ENSCRIPT_LIBRARY spécifie le répertoire de la bibliothèque d'enscript. Elle peut être utilisée pour remplacer la valeur par défaut intégrée `/usr/share/enscript'.

VALEUR DE RETOUR

Enscript renvoie la valeur 1 au shell si des erreurs ont été rencontrées, ou 0 sinon. Si l'option --extended-return-values a été spécifiée, la valeur de retour est construite à partir des indicateurs suivants :

0
aucune erreur ou avertissement
2
certaines lignes ont été tronquées ou renvoyées à la ligne
4
certains caractères étaient manquants dans les polices utilisées
8
certains caractères étaient non imprimables
