NOM

envy24control - Outil de contrôle graphique pour cartes son basées sur Envy24 (ice1712), sous ALSA.

SYNTAXE

envy24control [-c numéro-carte] [-D nom-contrôle] [-o 0-num DACs max 8] [-i 0-num ADCs max 8] [-p 0-8] [-s 0-2] [-f <nom_fichier_profils>] [-v] [<numéro_profil>|<nom_profil>] [-m canal_midi] [-M] [-w largeur_fenêtre] [-t 0-9]

DESCRIPTION

envy24control permet de contrôler le mélangeur numérique, les gains des canaux et d'autres réglages matériels pour les cartes son basées sur le chipset ice1712 (série Midiman Delta, série Terratec EWS et EWX). Il affiche également un indicateur de niveau pour chaque canal d'entrée et de sortie.

UTILISATION

envy24control [-c numéro-carte] [-D nom-contrôle] [-o 0-num DACs max 8] [-i 0-num ADCs max 8] [-p 0-8] [-s 0-2] [-f <nom_fichier_profils>] [-v] [<numéro_profil>|<nom_profil>] [-m canal_midi] [-M] [-w largeur_fenêtre] [-t 0-9]

Si aucun nom-contrôle n'est donné, alors la première carte son est utilisée.

Options

-c numéro-carte
Utiliser la carte spécifiée par numéro-carte au lieu de la première carte. Ceci est équivalent à l'option -Dhw:n où n est le numéro de la carte.
-D nom-contrôle
Utiliser la carte spécifiée par nom-contrôle au lieu de la première carte, normalement ce sera sous la forme hw:n où n est le numéro de la carte son (commençant à zéro). Ceci n'est nécessaire que si vous avez plus d'une carte basée sur Envy24 ou si votre carte Envy24 n'est pas configurée comme première carte dans votre configuration de pilote ALSA.
-o sorties
Limiter le nombre de sorties analogiques à afficher. Par défaut, c'est le nombre de DACs spécifié par le pilote. Maximum 8. Le nombre de lignes de sortie analogiques ne peut être réduit par rapport au nombre disponible de lignes de sortie.
-i entrées
Limiter le nombre d'entrées analogiques à afficher. Par défaut, c'est le nombre d'ADCs spécifié par le pilote. Maximum 8. Le nombre de lignes d'entrée analogiques ne peut être réduit par rapport au nombre disponible de lignes d'entrée.
-p sorties pcm
Limiter le nombre de sorties PCM à afficher. Par défaut 8.
-s entrées/sorties spdif
Limiter le nombre d'entrées/sorties SPDIF à afficher. Par défaut 2.
-f nom et chemin du fichier de profils
Depuis/vers ce fichier, envy24control lira/écrira les paramètres alsactl. Si non spécifié, DEFAULT_PROFILERC ou, pour la restauration si DEFAULT_PROFILERC n'existe pas, SYS_PROFILERC sera utilisé.
-v afficher les canaux de lecture spdif dans le mélangeur.
Il n'est pas possible de gérer quelque chose (mute, niveaux sonores). C'est uniquement pour visualiser les indicateurs de niveau. Par défaut, pas d'affichage des canaux de lecture spdif dans le mélangeur.
-m canal_midi
Utiliser les valeurs des contrôleurs MIDI pour contrôler les faders dans la vue du mélangeur. L'application réagira aux contrôleurs sur le canal canal_midi et enverra des contrôleurs sur ce canal lorsque l'utilisateur déplace les curseurs de l'interface graphique.
-M
Utiliser un mappage amélioré des valeurs des contrôleurs MIDI aux curseurs dB.
-w largeur_fenêtre
Spécifier la largeur initiale de la fenêtre envy24control. Utiliser largeur_fenêtre dans la plage 0-20 spécifie approximativement le nombre de canaux du mélangeur visibles. Les valeurs supérieures à 20 sont interprétées comme des pixels d'écran.
-t hauteurs de mélangeur égales
Utiliser -t 1 agrandit les mélangeurs de canaux à la même hauteur que le mélangeur numérique. Avec des valeurs supérieures à 1, la hauteur de tous les mélangeurs est augmentée par étapes. -t 0 est la valeur par défaut, définie pour une hauteur de fenêtre minimale.
