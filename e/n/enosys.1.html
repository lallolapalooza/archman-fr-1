ENOSYS(1) Commandes utilisateur ENOSYS(1)

NOM

enosys - utilitaire pour faire échouer les appels système avec ENOSYS

SYNOPIS

enosys [--syscall|-s appel_sys] commande

DESCRIPTION

enosys est une commande simple pour exécuter un processus fils pour lequel certains appels système échouent avec errno ENOSYS.

Il peut être utilisé pour tester le comportement des applications face à des appels système manquants, comme cela se produirait lors de l'exécution sur de vieux noyaux.

OPTIONS

-s, --syscall

Appel système à bloquer avec ENOSYS. Peut être spécifié plusieurs fois. Un numéro ou un nom d'erreur alternatif peut être spécifié avec un deux-points.

-i, --ioctl

Ioctl à bloquer avec ENOTTY. Peut être spécifié plusieurs fois. Un numéro ou un nom d'erreur alternatif peut être spécifié avec un deux-points.

-l, --list

Lister les appels système connus de enosys.

-m, --list-ioctl

Lister les ioctls connus de enosys.

-d, --dump[=fichier]

Exporter le filtre bytecode seccomp vers la sortie standard.

L'exportation peut par exemple être utilisée par setpriv --seccomp-filter.

-h, --help

Afficher le texte d'aide et quitter.

-V, --version

Afficher la version et quitter.

EXEMPLES

# faire échouer l'appel système "fallocate" avec ENOSYS
enosys -s fallocate ...
# faire échouer l'appel système "fallocate" avec ENOMEM
enosys -s fallocate:ENOMEM ...
# faire échouer l'appel système "fallocate" avec la valeur 12/ENOMEM
enosys -s fallocate:12 ...
# faire échouer l'ioctl FIOCLEX avec ENOTTY
enosys -i FIOCLEX ...
# faire échouer l'ioctl FIOCLEX avec ENOMEM
enosys -i FIOCLEX:ENOMEM ...
# faire échouer l'ioctl FIOCLEX avec la valeur 12/ENOMEM
enosys -i FIOCLEX:12 ...

STATUT DE SORTIE

enosys se termine avec le code de statut du processus exécuté. Les valeurs suivantes ont une signification spéciale :

1

erreur interne

2

le système ne fournit pas les fonctionnalités nécessaires
