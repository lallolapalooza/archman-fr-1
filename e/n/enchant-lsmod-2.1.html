ENCHANT-LSMOD-2(1) Manuel des commandes générales ENCHANT-LSMOD-2(1)

NOM

enchant-lsmod - lister les informations sur les fournisseurs et les dictionnaires

SYNTAXE

enchant-lsmod-2 [[-lang|-word-chars] [tag_langue]|-list-dicts|-help|-version]

DESCRIPTION

enchant-lsmod-2 fournit des informations sur les fournisseurs de correcteurs orthographiques d'Enchant et les dictionnaires proposés par chacun. Voir enchant(5) pour les détails sur la manière dont les fournisseurs et les dictionnaires sont localisés. Si aucune option de ligne de commande n'est donnée, les fournisseurs disponibles sont listés.

OPTIONS

-lang
Affiche le fournisseur et le dictionnaire qui seront utilisés pour la langue donnée, ou toutes les langues si aucune n'est fournie.
-word-chars
Affiche les caractères de mots supplémentaires pour la langue donnée, si disponibles. Ceci présente peu d'intérêt pour la plupart des utilisateurs.
-list-dicts
Liste le fournisseur et le dictionnaire pour toutes les langues disponibles.
-help
Affiche une aide brève.
-version
Imprime la version du programme.
