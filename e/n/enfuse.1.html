ENFUSE(1) Commandes utilisateur ENFUSE(1)

NOM

enfuse - page manuelle pour enfuse 4.2.1-0bcfaaf743e7

SYNOPSIS

enfuse [options] [--output=IMAGE] INPUT...

DESCRIPTION

Fusionne les images INPUT en une seule IMAGE.

INPUT... sont des noms de fichiers d'images ou des noms de fichiers de réponse. Les noms de fichiers de réponse commencent par le caractère "@".

OPTIONS

Options courantes :

-l, --levels=LEVELS
limiter le nombre de niveaux de fusion (LEVELS) à utiliser (1 à 29) ; un nombre négatif de LEVELS diminue le maximum ; "auto" restaure la maximisation automatique par défaut
-o, --output=FILE
écrire la sortie dans FILE ; par défaut : "a.tif"
-v, --verbose[=LEVEL]
rapporter la progression de manière verbeuse ; répéter pour augmenter le niveau de verbosité ou définir directement à LEVEL
--compression=COMPRESSION
définir la compression de l'image de sortie à COMPRESSION, où COMPRESSION est : "deflate", "jpeg", "lzw", "none", "packbits" pour les fichiers TIFF et 0 à 100, ou "jpeg", "jpeg-arith" pour les fichiers JPEG, où "jpeg" et "jpeg-arith" acceptent un niveau de compression

Options avancées :

--blend-colorspace=COLORSPACE
forcer COLORSPACE pour les opérations de fusion ; Enfuse utilise "CIELUV" pour les images avec profil ICC et "IDENTITY" pour celles sans, ainsi que pour toutes les images en virgule flottante ; les autres espaces colorimétriques de fusion disponibles sont "CIELAB" et "CIECAM"
-c, --ciecam
utiliser CIECAM02 pour fusionner les couleurs ; désactiver avec "--no-ciecam" ; noter que cette option sera retirée au profit de "--blend-colorspace"
-d, --depth=DEPTH
définir le nombre de bits par canal de l'image de sortie, où DEPTH est "8", "16", "32", "r32" ou "r64"
-f WIDTHxHEIGHT[+xXOFFSET+yYOFFSET]
définir manuellement la taille et la position de l'image de sortie ; utile pour les images TIFF d'entrée recadrées et décalées, comme celles produites par Nona
-g
hack alpha associé pour Gimp (avant la version 2) et Cinepaint
-w, --wrap[=MODE]
effectuer un enroulement aux bords de l'image, où MODE est "none", "horizontal", "vertical" ou "both" ; par défaut : none ; sans argument, l'option sélectionne l'enroulement horizontal

Options de fusion :

--exposure-weight=WEIGHT
poids donné aux pixels bien exposés (0 <= WEIGHT <= 1) ; par défaut : 1
--saturation-weight=WEIGHT
poids donné aux pixels hautement saturés (0 <= WEIGHT <= 1) ; par défaut : 0.2
--contrast-weight=WEIGHT
poids donné aux pixels dans des voisinages à fort contraste (0 <= WEIGHT <= 1) ; par défaut : 0
--entropy-weight=WEIGHT
poids donné aux pixels dans des voisinages à forte entropie (0 <= WEIGHT <= 1) ; par défaut : 0
--exposure-optimum=OPTIMUM
valeur d'exposition optimale, généralement le maximum de la fonction de pondération (0 <= OPTIMUM <= 1) ; par défaut : 0.5
--exposure-width=WIDTH
largeur caractéristique de la fonction de pondération (WIDTH > 0) ; par défaut : 0.2
--soft-mask
moyenne sur tous les masques ; c'est le comportement par défaut
--hard-mask
forcer des masques de fusion durs et aucun lissage à la plus fine échelle ; c'est particulièrement utile pour les piles de mise au point avec des caractéristiques fines et à fort contraste, mais entraîne une augmentation du bruit

Options d'expert :

--save-masks[=SOFT-TEMPLATE[:HARD-TEMPLATE]]
enregistrer les masques de pondération dans SOFT-TEMPLATE et HARD-TEMPLATE ; caractères de conversion : "%i" : index du masque, "%n" : numéro du masque, "%p" : chemin complet, "%d" : nom du répertoire, "%b" : nom de base, "%f" : nom de fichier, "%e" : extension ; les caractères en minuscules se réfèrent aux images d'entrée, en majuscules à l'image de sortie ; par défaut : "softmask-%n.tif":"hardmask-%n.tif"
--load-masks[=SOFT-TEMPLATE[:HARD-TEMPLATE]]
ignorer le calcul des cartes de pondération et utiliser celles des fichiers correspondant aux modèles à la place. Celles-ci peuvent être des masques durs ou souples. Pour la syntaxe des modèles, voir "--save-masks" ; par défaut : "softmask-%n.tif":"hardmask-%n.tif"
--fallback-profile=PROFILE-FILE
utiliser le profil ICC de PROFILE-FILE au lieu de sRGB
--layer-selector=ALGORITHM
définir l'ALGORITHM de sélection des couches ; par défaut : "all-layers" ; les algorithmes disponibles sont : "all-layers" : sélectionner toutes les couches de n'importe quelle image ; "first-layer" : sélectionner uniquement la première couche de chaque image (multi-)couche ; "last-layer" : sélectionner uniquement la dernière couche de chaque image (multi-)couche ; "largest-layer" : sélectionner la plus grande couche de chaque image (multi-)couche ; "no-layer" : ne sélectionner aucune couche de n'importe quelle image ;
--parameter=KEY1[=VALUE1][:KEY2[=VALUE2][:...]]
définir une ou plusieurs paires KEY-VALUE

Options de fusion d'expert :

--exposure-weight-function=WEIGHT-FUNCTION
(1ère forme) sélectionner l'une des WEIGHT-FUNCTIONs d'exposition intégrées : "gaussian", "lorentzian", "half-sine", "full-sine" ou "bi-square" ; par défaut : "gaussian"
--exposure-weight-function=SHARED-OBJECT:SYMBOL[:ARGUMENT[:...]]
(2ème forme) charger la fonction de pondération d'exposition définie par l'utilisateur SYMBOL depuis SHARED-OBJECT et éventuellement passer des ARGUMENTs
--exposure-cutoff=LOWERCUTOFF[:UPPERCUTOFF[:LOWERPROJECTOR[:UPPERPROJECTOR]]]
LOWERCUTOFF et UPPERCUTOFF sont les valeurs en dessous ou au-dessus desquelles les pixels sont pondérés avec un poids de zéro dans la pondération d'exposition ; ajouter des signes "%" pour des valeurs relatives ; par défaut : 0%:100%:anti-value:value
--contrast-window-size=SIZE
définir la taille de la fenêtre SIZE pour l'analyse du contraste local (SIZE >= 3) ; par défaut : 5
--contrast-edge-scale=EDGESCALE[:LCESCALE[:LCEFACTOR]]
définir l'échelle à laquelle rechercher les contours ; un LCESCALE positif active l'amélioration du contraste local par LCEFACTOR (EDGESCALE, LCESCALE, LCEFACTOR >= 0) ; ajouter "%" à LCESCALE pour des valeurs relatives à EDGESCALE ; ajouter "%" à LCEFACTOR pour une valeur relative ; par défaut : 0:0:0
--contrast-min-curvature=CURVATURE
courbure CURVATURE minimale pour qu'un contour soit qualifié ; ajouter "%" pour des valeurs relatives ; par défaut : 0

NAME

enfuse — fuse images by aligning and blending them

SYNOPSIS

enfuse [-o output.tif] [--blend-colorspace=colorspace] [--exposure-weight-mask=mask.tif] [--saturation-weight-mask=mask.tif] [--contrast-weight-mask=mask.tif] [--hard-mask] [--no-hard-mask] [--overlap=overlap] [--output-format=format] [--save-masks] [--shadow-compensation=shadows] [--shadow-multi-percentile] [--shadow-multi-contrast] [--shadow-no-multi-percentile] [--shadow-no-multi-contrast] [--contrast-edge-width=width] [--gray-projector=PROJECTOR] [--entropy-window-size=SIZE] [--entropy-cutoff=LOWERCUTOFF[:UPPERCUTOFF]] [-v|--verbose] [-q|--quiet] [-f|--force] [-h|--help] [-V|--version] [--show-globbing-algorithms] [--show-image-formats] [--show-signature] [--show-software-components] [input.tif ...]

DESCRIPTION

Enfuse is a command-line tool that takes a set of input images and produces a single output image that is properly exposed, sharp and without ghosts.

Enfuse is especially useful for merging bracketed exposures, but it can also be used for aligning and blending arbitrary sets of images. Enfuse works by calculating weights for each pixel of each input image and then blending the input images according to these weights.

Weights can be calculated based on:

  • Exposure: Pixels from images with a more appropriate exposure are given higher weights.
  • Saturation: Pixels from images with higher saturation are given higher weights.
  • Contrast: Pixels from images with higher contrast are given higher weights.
  • Entropy: Pixels from images with higher local entropy are given higher weights.

Enfuse can also:

  • align the input images if they are not perfectly aligned.
  • compensate for shadows.
  • save the calculated weight masks for inspection.

The weight calculation can be customized using several options.

OPTIONS

Enfuse accepts arguments to any option in uppercase as well as in lowercase letters.

Output options:

-o output.tif
write output image to output.tif; if not specified output goes to stdout
--output-format=format
use format for output image; default is determined from output filename extension (usually TIFF)

Blending options:

--blend-colorspace=colorspace
use colorspace for blending; allowed colorspaces are "rgb" and "hsv"; default: "rgb"
--overlap=overlap
set the width of the feathered overlap region in pixels; default: 16

Alignment options:

--hard-mask
use a hard mask between images instead of a feathered mask
--no-hard-mask
use a feathered mask between images (default)

Weighting options:

--exposure-weight-mask=mask.tif
use mask.tif as exposure weight mask
--saturation-weight-mask=mask.tif
use mask.tif as saturation weight mask
--contrast-weight-mask=mask.tif
use mask.tif as contrast weight mask
--save-masks
save the calculated weight masks (prefix: mask)
--shadow-compensation=shadows
compensate shadows by the factor shadows; default: 0
--shadow-multi-percentile
use multi-percentile for shadow compensation
--shadow-multi-contrast
use multi-contrast for shadow compensation
--shadow-no-multi-percentile
do not use multi-percentile for shadow compensation
--shadow-no-multi-contrast
do not use multi-contrast for shadow compensation
--contrast-edge-width=width
set contrast edge width to width; default: 3
--gray-projector=PROJECTOR
apply gray-scale PROJECTOR in exposure or contrast weighing, where PROJECTOR is one of "anti-value", "average", "l-star", "lightness", "luminance", "pl-star", "value", or "channel-mixer:RED-WEIGHT:GREEN-WEIGHT:BLUE-WEIGHT"; default: "average"
--entropy-window-size=SIZE
set window SIZE for local entropy analysis (SIZE >= 3); default: 3
--entropy-cutoff=LOWERCUTOFF[:UPPERCUTOFF]
LOWERCUTOFF is the value below of which pixels are treated as black and UPPERCUTOFF is the value above of which pixels are treated as white in the entropy weighting; append "%" signs for relative values; default: 0%:100%

Information options:

-h, --help
print this help message and exit
-V, --version
output version information and exit
--show-globbing-algorithms
show all globbing algorithms
--show-image-formats
show all recognized image formats and their filename extensions
--show-signature
show who compiled the binary when and on which machine
--show-software-components
show the software components with which Enfuse was compiled

Enfuse accepts arguments to any option in uppercase as well as in lowercase letters.

ENVIRONMENT

OMP_NUM_THREADS
The OMP_NUM_THREADS environment variable sets the number of threads to use in OpenMP parallel regions. If unset Enfuse uses as many threads as there are CPUs.
OMP_DYNAMIC
The OMP_DYNAMIC environment variable controls dynamic adjustment of the number of threads to use in executing OpenMP parallel regions.
