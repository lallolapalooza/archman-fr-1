ENDPWENT(3P) Manuel du programmeur POSIX ENDPWENT(3P)

PROLOGUE

Cette page manuelle fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page manuelle Linux correspondante pour les détails du comportement de Linux), ou l'interface peut ne pas être implémentée sur Linux.

NOM

endpwent, getpwent, setpwent — fonctions de la base de données des utilisateurs

SYNOPSIS

#include <pwd.h>
void endpwent(void);
struct passwd *getpwent(void);
void setpwent(void);

DESCRIPTION

Ces fonctions récupèrent des informations sur les utilisateurs.

La getpwent() fonction retourne un pointeur vers une structure contenant les champs décomposés d'une entrée dans la base de données des utilisateurs. Chaque entrée dans la base de données des utilisateurs contient une passwd structure. Si la base de données des utilisateurs n'est pas déjà ouverte, getpwent() l'ouvre et retourne un pointeur vers une passwd structure contenant la première entrée dans la base de données. Ensuite, elle retourne un pointeur vers une passwd structure contenant l'entrée suivante dans la base de données des utilisateurs. Des appels successifs peuvent être utilisés pour parcourir toute la base de données des utilisateurs.

Si une fin de fichier ou une erreur est rencontrée lors de la lecture, getpwent() retourne un pointeur nul.

Une implémentation qui fournit des contrôles de sécurité étendus peut imposer des restrictions supplémentaires définies par l'implémentation sur l'accès à la base de données des utilisateurs. En particulier, le système peut refuser l'existence de certaines ou de toutes les entrées de la base de données des utilisateurs associées à des utilisateurs autres que l'appelant.

La setpwent() fonction rembobine la base de données des utilisateurs de sorte que le prochain getpwent() appel retourne la première entrée, permettant des recherches répétées.

La endpwent() fonction ferme la base de données des utilisateurs.

Les setpwent() et endpwent() fonctions ne changent pas le réglage de errno si elles réussissent.

En cas d'erreur, setpwent() et endpwent() fonctions définissent errno pour indiquer l'erreur.

Puisqu'aucune valeur n'est retournée par les setpwent() et endpwent() fonctions, une application souhaitant vérifier les situations d'erreur devrait définir errno à 0, puis appeler la fonction, puis vérifier errno.

Ces fonctions n'ont pas besoin d'être sûres pour les threads.

VALEUR RENVOYÉE

Lors de l'achèvement réussi, getpwent() retourne un pointeur vers une passwd structure. À la fin de fichier, getpwent() retourne un pointeur nul et ne change pas le réglage de errno. En cas d'erreur, getpwent() retourne un pointeur nul et errno est défini pour indiquer l'erreur.

L'application ne doit pas modifier la structure vers laquelle pointe la valeur retournée, ni aucune zone de stockage pointée par des pointeurs à l'intérieur de la structure. Le pointeur retourné, et les pointeurs à l'intérieur de la structure, peuvent être invalidés ou la structure ou les zones de stockage peuvent être écrasées par un appel ultérieur à getpwuid(), getpwnam(), ou getpwent(). Le pointeur retourné, et les pointeurs à l'intérieur de la structure, peuvent aussi être invalidés si le thread appelant est terminé.

ERREURS

Ces fonctions peuvent échouer si :

EINTR
Un signal a été capturé pendant l'opération.
EIO
Une erreur d'entrée/sortie s'est produite.

De plus, getpwent() et setpwent() peuvent échouer si :

EMFILE
Tous les descripteurs de fichiers disponibles pour le processus sont actuellement ouverts.
ENFILE
Le nombre maximum de fichiers autorisés est actuellement ouvert dans le système.

EXEMPLES

Recherche dans la base de données des utilisateurs

L'exemple suivant utilise la getpwent() fonction pour obtenir des entrées successives dans la base de données des utilisateurs, retournant un pointeur vers une passwd structure contenant des informations sur chaque utilisateur. L'appel à endpwent() ferme la base de données des utilisateurs et nettoie.

#include <pwd.h>
#include <stdio.h>
void printname(uid_t uid)
{
    struct passwd *pwd;
    setpwent();
    while((pwd = getpwent()) != NULL) {
        if (pwd->pw_uid == uid) {
            printf("name=%s\n",pwd->pw_name);
            break;
        }
    }
    endpwent();
}

UTILISATION PAR LES APPLICATIONS

Ces fonctions sont fournies en raison de leur utilisation historique. Les applications devraient éviter les dépendances aux champs de la base de données des mots de passe, que la base de données soit un fichier unique, ou l'endroit dans l'espace de noms du système de fichiers où la base de données réside. Les applications devraient utiliser getpwuid() chaque fois que possible car cela évite ces dépendances.
