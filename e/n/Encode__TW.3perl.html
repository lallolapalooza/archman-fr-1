NOM

Encode::TW - Jeux de caractères chinois basés à Taiwan

SYNTAXE

use Encode qw/encode decode/; 
$big5 = encode("big5", $utf8); # charge Encode::TW implicitement
$utf8 = decode("big5", $big5); # idem

DESCRIPTION

Ce module implémente les jeux de caractères chinois traditionnels tels qu'utilisés à Taiwan et à Hong Kong. Les encodages pris en charge sont les suivants.

Canonique   Alias             Description
--------------------------------------------------------------------
big5-eten   /\bbig-?5$/i      Encodage Big5 (avec extensions ETen)
        /\bbig5-?et(en)?$/i
        /\btca-?big5$/i
big5-hkscs  /\bbig5-?hk(scs)?$/i
            /\bhk(scs)?-?big5$/i
                              Big5 + caractères cantonnais à Hong Kong
MacChineseTrad                Big5 + mappages du fournisseur Apple
cp950                         Code Page 950 
                              = Big5 + mappages du fournisseur Microsoft
--------------------------------------------------------------------

Pour savoir comment utiliser ce module en détail, consultez Encode.

NOTES

En raison de préoccupations liées à la taille, "EUC-TW" (Extended Unix Character), "CCCII" (Chinese Character Code for Information Interchange), "BIG5PLUS" (Big5+ de CMEX) et "BIG5EXT" (Big5e de CMEX) sont distribués séparément sur CPAN, sous le nom Encode::HanExtra. Ce module contient également des encodages supplémentaires basés sur la Chine.

BOGUES

Étant donné que l'encodage "big5" original (1984) n'est pris en charge nulle part (glibc et les systèmes basés sur DOS utilisent "big5" pour signifier "big5-eten" ; Microsoft utilise "big5" pour signifier "cp950"), une décision consciente a été prise d'aliasser "big5" à "big5-eten", qui est le sur-ensemble de fait du big5 original.

Les fichiers d'encodage "CNS11643" ne sont pas complets. Pour la manipulation courante de "CNS11643", veuillez utiliser "EUC-TW" dans Encode::HanExtra, qui contient les plans 1 à 7.

La région ASCII (0x00-0x7f) est préservée pour tous les encodages, même si cela entre en conflit avec les mappages du Unicode Consortium.
