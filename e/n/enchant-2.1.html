ENCHANT-2(1) Manuel des commandes générales ENCHANT-2(1)

NOM

Enchant - un correcteur orthographique

SYNTAXE

enchant-2 -a|-l|-h|-v [-L] [-d DICIONNAIRE] [FICHIER]

DESCRIPTION

Enchant est un correcteur orthographique compatible avec Ispell. Notez que, contrairement à Ispell, il n'a pas de mode interactif ; il est conçu pour être utilisé par d'autres programmes.

-d DICIONNAIRE
utilise le dictionnaire donné
-p LISTE_DE_MOTS
utilise la liste de mots personnels donnée
-a
liste les suggestions au format du mode pipe d'Ispell
-l
liste uniquement les fautes d'orthographe
-L
affiche les numéros de ligne
-h
affiche l'aide et quitte
-v
affiche les informations de version et quitte

FICHIERS ET RÉPERTOIRES

Voir enchant(5) pour les détails sur les fichiers de configuration et les listes de mots personnels.

VOIR AUSSI

enchant-2(5), aspell(1), enchant-lsmod-2(1)
