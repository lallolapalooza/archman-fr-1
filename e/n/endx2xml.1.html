NOM

endx2xml - Convertisseur d'index de man vers XML

SYNOPSIS

endx2xml [OPTIONS] FICHIER...

DESCRIPTION

La commande endx2xml est un utilitaire pour convertir des pages de manuel au format texte (tel que celui généré par la commande man) en un format XML basé sur le DTD Document Style Semantics and Specification Language (DSSSL).

Ce format XML est conçu pour représenter la structure et le contenu des pages de manuel, y compris les sections, les énumérations, les listes, le texte en gras, italique, etc.

CONVERSION VERS MODS

Pour convertir une page de manuel au format texte en XML, vous pouvez exécuter la commande comme suit :

endx2xml page_de_manuel.man > page_de_manuel.xml

CONVERSION DEPUIS MODS

La commande endx2xml ne prend pas en charge la conversion inverse du format XML vers le format texte des pages de manuel.

EXEMPLES

Pour convertir la page de manuel ls.1 en XML :

man -l ls.1 | endx2xml > ls.xml

Pour convertir plusieurs fichiers de manuel en XML :

endx2xml file1.man file2.man > output.xml
