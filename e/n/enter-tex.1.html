ENTER-TEX(1) Commandes utilisateur ENTER-TEX(1)

NOM

enter-tex - éditeur de texte TeX/LaTeX

SYNTAXE

enter-tex [OPTIONS] [FICHIERS]

enter-tex {-h | --help | --help-all | --help-gtk}

DESCRIPTION

Cette page de manuel documente brièvement la commande enter-tex.

Enter TeX est un éditeur de texte TeX/LaTeX.

OPTIONS

Le programme suit la syntaxe habituelle des lignes de commande GNU, avec les options longues commençant par deux tirets. Un résumé des options est inclus ci-dessous. Pour une description complète des options, veuillez utiliser enter-tex --help.

-n, --new-document

Crée un nouveau document.

--new-window

Crée une nouvelle fenêtre de niveau supérieur dans une instance existante d'Enter TeX.

--display=DISPLAY

Affichage X à utiliser.

-h, --help

Affiche un résumé des options courantes.

--help-all

Affiche un résumé de toutes les options.

--help-gtk

Affiche un résumé des options GTK+.

-V, --version

Affiche les informations de version.

NOTES

Par défaut, lors du démarrage d'Enter TeX, il rouvre les fichiers qui étaient ouverts lors de la dernière utilisation. Ce comportement peut être désactivé dans les préférences du programme.
