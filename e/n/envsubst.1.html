ENVSUBST(1) Commandes utilisateur ENVSUBST(1)

NOM

envsubst - substitue les variables d'environnement dans des chaînes au format shell

SYNTAXE

envsubst [OPTION] [FORMAT-SHELL]

DESCRIPTION

Substitue les valeurs des variables d'environnement.

Mode de fonctionnement :

-v, --variables
affiche les variables apparaissant dans FORMAT-SHELL

Sortie informative :

-h, --help
affiche cette aide et quitte
-V, --version
affiche les informations de version et quitte

En mode de fonctionnement normal, l'entrée standard est copiée vers la sortie standard, avec les références aux variables d'environnement de la forme $VARIABLE ou ${VARIABLE} remplacées par les valeurs correspondantes. Si un FORMAT-SHELL est donné, seules les variables d'environnement référencées dans FORMAT-SHELL sont substituées ; autrement, toutes les références aux variables d'environnement apparaissant dans l'entrée standard sont substituées.

Lorsque --variables est utilisé, l'entrée standard est ignorée, et la sortie consiste en les variables d'environnement référencées dans FORMAT-SHELL, une par ligne.
