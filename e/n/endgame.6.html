NOM

endgame - économiseur d'écran d'échecs final

SYNTAXE

endgame [--display hôte:écran] [--window] [--root] [--window-id numéro] [--install] [--visual visuel] [--delay microsecondes] [--wireframe] [--fps]

DESCRIPTION

endgame rejoue une brillante finale d'échecs

OPTIONS

endgame accepte les options suivantes :

--window
Dessine dans une fenêtre nouvellement créée. C'est le comportement par défaut.
--root
Dessine sur la fenêtre racine.
--window-id numéro
Dessine sur la fenêtre spécifiée.
--install
Installe une palette de couleurs privée pour la fenêtre.
--shadows
Projette les pièces sur l'échiquier avec un mélange sombre.
--reflections
Reflète les pièces sur les cases claires de l'échiquier.
--classic
Utilise les modèles de pièces originaux à faible nombre de polygones.
--visual visuel
Spécifie quel visuel utiliser. Les valeurs valides sont le nom d'une classe de visuel, ou l'identifiant numérique (décimal ou hexadécimal) d'un visuel spécifique.
--wireframe
Rendu en fil de fer au lieu de plein. --fps Affiche le taux de rafraîchissement actuel, la charge CPU et le nombre de polygones.

ENVIRONNEMENT

DISPLAY
pour obtenir l'hôte et le numéro d'écran par défaut.
XENVIRONMENT
pour obtenir le nom d'un fichier de ressources qui surcharge les ressources globales stockées dans la propriété RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
L'identifiant de fenêtre à utiliser avec --root.

BOGUES

Il n'est pas rare que ce programme et d'autres hacks OpenGL échouent sous accélération matérielle (UtahGLX) et emportent le serveur X avec eux. Les images de texture doivent être de 16x16, 32x32 ou 64x64, etc.
