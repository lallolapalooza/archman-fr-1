Encode::Unicode::UTF7(3perl) Guide du programmeur Perl Encode::Unicode::UTF7(3perl)

NOM

Encode::Unicode::UTF7 -- encodage UTF-7

SYNOPSIS

use Encode qw/encode decode/; 
$utf7 = encode("UTF-7", $utf8);
$utf8 = decode("UTF-7", $ucs2);

RÉSUMÉ

Ce module implémente l'encodage UTF-7 documenté dans la RFC 2152. UTF-7, comme son nom l'indique, est une version ré-encodée en 7 bits de UTF-16BE. Il est conçu pour être sûr pour les MTA (Mail Transfer Agent) et devrait être un moyen standard d'échanger des e-mails Unicode via le courrier électronique. Mais avec l'avènement d'UTF-8 et des MTA compatibles 8 bits, UTF-7 est rarement utilisé.

UTF-7 n'était pas supporté par Encode avant la version 1.95 pour cette raison. Mais Unicode::String, un module de Gisle Aas qui ajoute le support Unicode à Perl non compatible UTF-8, supportait UTF-7, le support UTF-7 a été ajouté afin que Encode puisse remplacer complètement Unicode::String.

En pratique

Lorsque vous souhaitez encoder Unicode pour les e-mails et les pages Web, n'utilisez cependant pas UTF-7, sauf si vous êtes sûr que vos destinataires et lecteurs peuvent le gérer. Très peu de MUA (Mail User Agent) et de navigateurs WWW le supportent de nos jours (seul Mozilla semble en supporter une variante). Dans les cas généraux, utilisez UTF-8 pour le corps des messages et MIME-Header pour l'en-tête à la place.
