envz_add(3) Manuel des fonctions de bibliothèque envz_add(3)

NOM

envz_add, envz_entry, envz_get, envz_merge, envz_remove, envz_strip - support des chaînes d'environnement

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <envz.h>
error_t envz_add(char **restrict envz, size_t *restrict envz_len,
               const char *restrict name, const char *restrict value);
char *envz_entry(const char *restrict envz, size_t envz_len,
               const char *restrict name);
char *envz_get(const char *restrict envz, size_t envz_len,
               const char *restrict name);
error_t envz_merge(char **restrict envz, size_t *restrict envz_len,
               const char *restrict envz2, size_t envz2_len,
               int override);
void envz_remove(char **restrict envz, size_t *restrict envz_len,
               const char *restrict name);
void envz_strip(char **restrict envz, size_t *restrict envz_len);

DESCRIPTION

Ces fonctions sont spécifiques à glibc.

Un vecteur argz est un pointeur vers un tampon de caractères ainsi qu'une longueur, voir argz_add(3). Un vecteur envz est un vecteur argz spécial, à savoir un où les chaînes ont la forme "nom=valeur". Tout ce qui suit le premier '=' est considéré comme la valeur. S'il n'y a pas de '=', la valeur est considérée comme NULL. (Alors que la valeur dans le cas d'un '=' final est la chaîne vide "".)

Ces fonctions servent à gérer les vecteurs envz.

envz_add() ajoute la chaîne "name=value" (si value n'est pas NULL) ou "name" (si value est NULL) au vecteur envz (*envz, *envz_len) et met à jour *envz et *envz_len. Si une entrée avec le même name existait, elle est supprimée.

envz_entry() recherche name dans le vecteur envz (envz, envz_len) et retourne l'entrée si trouvée, ou NULL sinon.

envz_get() recherche name dans le vecteur envz (envz, envz_len) et retourne la valeur si trouvée, ou NULL sinon. (Notez que la valeur peut aussi être NULL, notamment lorsqu'il y a une entrée pour name sans signe '='.)

envz_merge() ajoute chaque entrée de envz2 à *envz, comme avec envz_add(). Si override est vrai, alors les valeurs dans envz2 remplaceront celles avec le même nom dans *envz, sinon non.

envz_remove() supprime l'entrée pour name de (*envz, *envz_len) s'il y en avait une.

envz_strip() supprime toutes les entrées avec une valeur NULL.

VALEUR DE RETOUR

Toutes les fonctions envz qui effectuent une allocation mémoire ont un type de retour error_t (un type entier), et retournent 0 en cas de succès, et ENOMEM en cas d'erreur d'allocation.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

NORMES

GNU.

EXEMPLES

#include <envz.h>
#include <stdio.h>
#include <stdlib.h>
int
main(int argc, char *argv[], char *envp[])
{
    char    *str;
    size_t  e_len = 0;
    for (size_t i = 0; envp[i] != NULL; i++)
        e_len += strlen(envp[i]) + 1;
    str = envz_entry(*envp, e_len, "HOME");
    printf("%s\n", str);
    str = envz_get(*envp, e_len, "HOME");
    printf("%s\n", str);
    exit(EXIT_SUCCESS);
}
