Encode::JP(3perl) Guide de référence des programmeurs Perl Encode::JP(3perl)

NOM

Encode::JP - Encodages japonais

SYNTAXE

use Encode qw/encode decode/; 
$euc_jp = encode("euc-jp", $utf8);   # charge Encode::JP implicitement
$utf8   = decode("euc-jp", $euc_jp); # de même

RÉSUMÉ

Ce module implémente les jeux de caractères japonais. Les encodages supportés sont les suivants.

Canonique       Alias             Description
--------------------------------------------------------------------
euc-jp          /\beuc.*jp$/i     EUC (Extended Unix Character)
                /\bjp.*euc/i   
            /\bujis$/i
shiftjis        /\bshift.*jis$/i  Shift JIS (alias MS Kanji)
                /\bsjis$/i
7bit-jis        /\bjis$/i         7 bits JIS
iso-2022-jp                       ISO-2022-JP                  [RFC1468]
                  = 7 bits JIS avec tous les Kana demi-chasse 
                    convertis en pleine chasse
iso-2022-jp-1                     ISO-2022-JP-1                [RFC2237]
                                  = ISO-2022-JP avec le support 
                                    de JIS X 0212-1990. Voir ci-dessous
MacJapanese                       Mappages vendeurs Apple + Shift JIS
cp932           /\bwindows-31j$/i Code Page 932
                                  = Mappages vendeurs MS/IBM + Shift JIS
jis0201-raw                       JIS0201, format brut
jis0208-raw                       JIS0208, format brut
jis0212-raw                       JIS0212, format brut
--------------------------------------------------------------------

DESCRIPTION

Pour savoir comment utiliser ce module en détail, voir Encode.

Note sur ISO-2022-JP(-1)?

ISO-2022-JP-1 (RFC2237) est un sur-ensemble de ISO-2022-JP (RFC1468) qui ajoute le support de JIS X 0212-1990. Cela signifie que vous pouvez utiliser le même code pour décoder vers utf8, mais pas l'inverse.

$utf8 = decode('iso-2022-jp-1', $stream);

et

$utf8 = decode('iso-2022-jp',   $stream);

donnent le même résultat, mais

$with_0212 = encode('iso-2022-jp-1', $utf8);

est maintenant différent de

$without_0212 = encode('iso-2022-jp', $utf8 );

Dans ce dernier cas, les caractères qui correspondent à 0212 sont d'abord convertis en U+3013 (0xA2AE en EUC-JP ; un carré blanc aussi connu sous le nom de 'Tofu' ou 'marque geta') puis transmis au moteur de décodage. U+FFFD n'est pas utilisé, afin de préserver la mise en page du texte autant que possible.

BOGUES

La région ASCII (0x00-0x7f) est préservée pour tous les encodages, bien que cela entre en conflit avec les mappages du Unicode Consortium.
