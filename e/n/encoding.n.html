encoding(n) Commandes intégrées Tcl encoding(n)

NOM

encoding - Manipuler les encodages

SYNOPIS

encoding option ?arg arg ...?

INTRODUCTION

Les chaînes en Tcl sont logiquement une séquence de caractères Unicode de 16 bits. Ces chaînes sont représentées en mémoire comme une séquence d'octets qui peuvent être dans l'un de plusieurs encodages : UTF-8 modifié (qui utilise 1 à 3 octets par caractère), “Unicode” de 16 bits (qui utilise 2 octets par caractère, avec une endianness qui dépend de l'architecture hôte), et binaire (qui utilise un seul octet par caractère mais ne gère qu'une plage restreinte de caractères). Tcl ne garantit pas d'utiliser toujours le même encodage pour la même chaîne.

Différentes interfaces de système d'exploitation ou applications peuvent générer des chaînes dans d'autres encodages tels que Shift-JIS. La commande encoding aide à établir le lien entre Unicode et ces autres formats.

DESCRIPTION

Exécute une ou plusieurs opérations liées à l'encodage, en fonction de option. Les options légales sont :

encoding convertfrom ?encoding? data
Convertit data en Unicode à partir de l'encoding spécifié. Les caractères dans data sont traités comme des données binaires où les 8 bits inférieurs de chaque caractère sont pris comme un seul octet. La séquence résultante d'octets est traitée comme une chaîne dans l'encoding spécifié. Si encoding n'est pas spécifié, l'encodage système actuel est utilisé.
encoding convertto ?encoding? string
Convertit string d'Unicode vers l'encoding spécifié. Le résultat est une séquence d'octets représentant la chaîne convertie. Chaque octet est stocké dans les 8 bits inférieurs d'un caractère Unicode (en fait, la chaîne résultante est une chaîne binaire pour Tcl, du moins au début). Si encoding n'est pas spécifié, l'encodage système actuel est utilisé.
encoding dirs ?directoryList?
Tcl peut charger des fichiers de données d'encodage à partir du système de fichiers qui décrivent des encodages supplémentaires avec lesquels il peut travailler. Cette commande définit le chemin de recherche des fichiers de données d'encodage *.enc à la liste de répertoires directoryList. Si directoryList est omis, la commande renvoie la liste actuelle des répertoires qui constituent le chemin de recherche. C'est une erreur si directoryList n'est pas une liste valide. Si, lors d'une recherche de fichier de données d'encodage, un élément dans directoryList ne fait pas référence à un répertoire lisible et consultable, cet élément est ignoré.
encoding names
Renvoie une liste contenant les noms de tous les encodages actuellement disponibles. Les encodages “utf-8” et “iso8859-1” sont garantis d'être présents dans la liste.
encoding system ?encoding?
Définit l'encodage système à encoding. Si encoding est omis, la commande renvoie l'encodage système actuel. L'encodage système est utilisé chaque fois que Tcl transmet des chaînes aux appels système.

EXEMPLE

L'exemple suivant convertit une séquence d'octets en encodage japonais euc-jp en une chaîne TCL :

set s [encoding convertfrom euc-jp "\xA4\xCF"]

Le résultat est le point de code unicode : “\u306F”, qui est la lettre Hiragana HA.
