NOM

engine - dessine un moteur quatre temps en 3D.

SYNTAXE

engine [--display hôte:écran.numéro] [--visual visuel] [--window] [--root] [--window-id numéro] [--engine nom] [--delay numéro] [--no-move] [--no-spin] [--no-title] [--fps]

DESCRIPTION

Dessine un moteur quatre temps simple qui flotte à l'écran.

OPTIONS

--visual visuel
Spécifie quel visuel utiliser. Les valeurs valides sont le nom d'une classe visuelle ou l'identifiant (décimal ou hexadécimal) d'un visuel spécifique.
--window
Dessine dans une nouvelle fenêtre créée. C'est le comportement par défaut.
--root
Dessine sur la fenêtre racine.
--window-id numéro
Dessine sur la fenêtre spécifiée.
--engine nom
Quel type de moteur dessiner. Par défaut : aléatoire. Les modèles connus sont : "Honda Insight" (3), "BMW M3" (4), "VW Beetle" (plat 4), "Audi Quattro" (5), "BMW M5" (6), "Subaru XT" (V6), "Porsche 911" (plat 6), "Corvette Z06" (V8), "Dodge Viper" (V10), et "Jaguar XKE" (V12).
--delay numéro
Délai par image, en microsecondes. Par défaut : 10000 (0.01 secondes.).
--move | --no-move
Indique si l'objet doit se déplacer à l'écran.
--spin | --no-spin
Indique si l'objet doit tourner.
--fps
Affiche le taux d'images par seconde actuel, la charge CPU et le nombre de polygones.
--title | --no-title
Indique s'il faut afficher le nom du moteur en cours de rendu.

ENVIRONNEMENT

DISPLAY
pour obtenir le nom d'hôte et le numéro d'écran par défaut.
XENVIRONMENT
pour obtenir le nom d'un fichier de ressources qui remplace les ressources globales stockées dans la propriété RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
L'identifiant de fenêtre à utiliser avec --root.

VOIR AUSSI

X(1), xscreensaver(1)
