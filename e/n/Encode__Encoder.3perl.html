Encode::Encoder(3perl) Guide du programmeur Perl Encode::Encoder(3perl)

NOM

Encode::Encoder -- Encodeur orienté objet

SYNTAXE

use Encode::Encoder;
# Encode::encode("ISO-8859-1", $data); 
Encode::Encoder->new($data)->iso_8859_1; # Façon OO
# Raccourci
use Encode::Encoder qw(encoder);
encoder($data)->iso_8859_1;
# vous pouvez les chaîner!
encoder($data)->iso_8859_1->base64;  # à condition que base64() soit défini
# vous pouvez l'utiliser aussi comme décodeur
encoder($base64)->bytes('base64')->latin1;
# sous forme de chaîne
print encoder($data)->utf8->latin1;  # affiche la chaîne en latin1
# sous forme numérique
encoder("\x{abcd}\x{ef}g")->utf8 == 6; # vrai. bytes::length($data)

ABSTRAIT

Encode::Encoder vous permet d'utiliser Encode dans un style orienté objet. Ce n'est pas seulement plus intuitif qu'une approche fonctionnelle, mais aussi plus pratique lorsque vous souhaitez chaîner des encodages. Supposons que vous vouliez convertir votre chaîne UTF-8 en Latin1 puis en Base64 : vous pouvez simplement dire

my $base64 = encoder($utf8)->latin1->base64;

au lieu de

my $latin1 = encode("latin1", $utf8);
my $base64 = encode_base64($utf8);

ou le plus paresseux et plus compliqué

my $base64 = encode_base64(encode("latin1", $utf8));

Description

Voici comment utiliser ce module.

  • Il y a au moins deux variables d'instance stockées dans une référence de hash, {data} et {encoding}.
  • Lorsqu'il n'y a pas de méthode, il prend le nom de la méthode comme nom de l'encodage et encode les données de l'instance avec l'encodage. En cas de succès, l'encodage de l'instance est défini en conséquence.
  • Vous pouvez récupérer le résultat via ->data mais généralement vous n'avez pas à le faire car l'opérateur de conversion en chaîne ("") est surchargé pour faire exactement cela.

Méthodes prédéfinies

Ce module prédéfinit les méthodes ci-dessous :

$e = Encode::Encoder->new([$data, $encoding]);
retourne un objet encodeur. Ses données sont initialisées avec $data si présent, et son encodage est défini sur $encoding si présent.

Lorsque $encoding est omis, il prend par défaut utf8 si $data est déjà en utf8 ou "" (chaîne vide) sinon.

encoder()
est un alias de Encode::Encoder->new(). Celui-ci est exporté à la demande.
$e->data([$data])
Lorsque $data est présent, définit les données de l'instance sur $data et retourne l'objet lui-même. Sinon, les données actuelles de l'instance sont retournées.
$e->encoding([$encoding])
Lorsque $encoding est présent, définit l'encodage de l'instance sur $encoding et retourne l'objet lui-même. Sinon, l'encodage actuel de l'instance est retourné.
$e->bytes([$encoding])
décode les données de l'instance à partir de $encoding, ou de l'encodage de l'instance si omis. Si la conversion réussit, l'encodage de l'instance sera défini sur "".

Le nom bytes a été délibérément choisi pour éviter la contamination de l'espace de noms – ce module peut être utilisé comme classe de base afin d'éviter les noms de méthodes qui apparaissent dans Encode::Encoding.

Exemple : transcodeur base64

Ce module est conçu pour fonctionner avec Encode::Encoding. Pour que l'exemple de transcodeur Base64 ci-dessus fonctionne réellement, vous pourriez écrire un module comme celui-ci :

package Encode::Base64;
use parent 'Encode::Encoding';
__PACKAGE__->Define('base64');
use MIME::Base64;
sub encode{ 
    my ($obj, $data) = @_; 
    return encode_base64($data);
}
sub decode{
    my ($obj, $data) = @_; 
    return decode_base64($data);
}
1;
__END__

Et votre module appelant ressemblerait à ceci :

use Encode::Encoder;
use Encode::Base64;
# maintenant vous pouvez vraiment faire ceci
encoder($data)->iso_8859_1->base64;
encoder($base64)->bytes('base64')->latin1;

Surcharge d'opérateur

Ce module surcharge deux opérateurs, la conversion en chaîne ("") et la conversion numérique (0+).

La conversion en chaîne affiche les données à l'intérieur de l'objet.

La conversion numérique retourne le nombre d'octets dans les données de l'instance.

Ils sont utiles lorsque vous souhaitez afficher ou trouver la taille des données.
