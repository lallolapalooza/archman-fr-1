ENCFSCTL(1) Système de fichiers chiffré ENCFSCTL(1)

NOM

encfsctl - outil administratif pour travailler avec les systèmes de fichiers EncFS

SYNTAXE

encfsctl [commande args_commande]

encfsctl [info] répertoiredurable

encfsctl passwd répertoiredurable

encfsctl showcruft répertoiredurable

encfsctl decode [--extpass=prog] répertoiredurable [nom_chiffré ...]

encfsctl encode [--extpass=prog] répertoiredurable [nom_en_clair ...]

encfsctl cat [--extpass=prog] [--reverse] répertoiredurable <(chiffré|clair) nom_fichier>

DESCRIPTION

encfsctl est un outil administratif pour travailler avec les systèmes de fichiers EncFS. Il est capable de changer le mot de passe fourni par l'utilisateur, d'afficher des informations de base sur un volume chiffré, et d'autres opérations connexes.

COMMANDES

info
Affiche les informations de base sur le système de fichiers. Prend un seul argument, répertoiredurable, qui est le répertoire racine du système de fichiers chiffré. Le système de fichiers n'a pas besoin d'être monté. Info est également la commande par défaut si seul un répertoire racine est fourni sur la ligne de commande.
passwd
Permet de changer le mot de passe du système de fichiers chiffré. L'utilisateur sera invité à saisir le mot de passe actuel et le nouveau mot de passe.
showcruft
Parcourt récursivement tout le volume et affiche tous les fichiers qui ne peuvent pas être décodés (ne vérifie que le chiffrement du nom de fichier, pas les en-têtes MAC des blocs). Ceci peut être utile pour le nettoyage au cas où vous auriez utilisé des fonctionnalités qui créent des fichiers qui ne sont pas décodables sous la clé principale.
decode
Vous permet de spécifier un nom chiffré sur la ligne de commande et affiche sa version décodée. Ceci est principalement utile pour le débogage, car les messages de débogage affichent toujours les noms de fichiers chiffrés (pour éviter de fuir des données sensibles via les canaux de débogage). Cette commande fournit donc un moyen de décoder les noms de fichiers.

L'option --extpass peut être utilisée pour spécifier le programme qui renvoie le mot de passe - tout comme avec encfs.

Si aucun nom n'est spécifié sur la ligne de commande, alors une liste de noms de fichiers sera lue depuis l'entrée standard et décodée.

encode
Vous permet de spécifier un nom de fichier sur la ligne de commande et affiche sa version chiffrée. Ceci est utile si, par exemple, vous faites une sauvegarde d'un répertoire chiffré et souhaitez exclure certains fichiers.

L'option --extpass peut être utilisée pour spécifier le programme qui renvoie le mot de passe - tout comme avec encfs.

Si aucun nom n'est spécifié sur la ligne de commande, alors une liste de noms de fichiers sera lue depuis l'entrée standard et chiffrée.

cat
Décode et affiche le contenu d'un fichier chiffré avec cat. Le nom de fichier peut être donné sous forme claire ou chiffrée. Avec --reverse, le contenu du fichier sera chiffré à la place.

EXEMPLES

Afficher les informations sur un système de fichiers chiffré :

% encfsctl info ~/.crypt
Version 5 configuration; created by EncFS 1.1 (revision 20040504)
Filesystem cipher: "ssl/aes" , version 2:1:1
Filename encoding: "nameio/block" , version 3:0:1
Key Size: 192 bits
Block Size: 512 bytes
Each file contains 8 byte header with unique IV data.
Filesname encoded using IV chaining mode.
