entry(n) Commandes intégrées Tk entry(n)

NOM

entry - Créer et manipuler des widgets de saisie de texte sur une ligne 'entry'

SYNTAXE

entry cheminNom ?options?

OPTIONS STANDARD

-background	-highlightthickness	-selectbackground
-borderwidth	-insertbackground	-selectborderwidth
-cursor	-insertborderwidth	-selectforeground
-exportselection	-insertofftime	-takefocus
-font	-insertontime	-textvariable
-foreground	-insertwidth	-xscrollcommand
-highlightbackground	-justify
-highlightcolor	-relief

Voir la page de manuel options pour plus de détails sur les options standard.

DESCRIPTION

La commande entry crée une nouvelle fenêtre (donnée par l'argument cheminNom) et en fait un widget d'entrée. Des options supplémentaires, décrites ci-dessus, peuvent être spécifiées sur la ligne de commande ou dans la base de données d'options pour configurer des aspects de l'entrée tels que ses couleurs, sa police et son relief. La commande entry retourne son argument cheminNom. Au moment où cette commande est invoquée, il ne doit pas exister de fenêtre nommée cheminNom, mais le parent de cheminNom doit exister.

Une entrée est un widget qui affiche une chaîne de texte sur une seule ligne et permet de modifier cette chaîne à l'aide des commandes de widget décrites ci-dessous, qui sont généralement liées à des frappes de touches et à des actions de souris. Lors de sa création, la chaîne d'une entrée est vide. Une partie de l'entrée peut être sélectionnée comme décrit ci-dessous. Si une entrée exporte sa sélection (voir l'option -exportselection), elle observera les protocoles X11 standard pour la gestion de la sélection ; les sélections d'entrée sont disponibles sous le type STRING. Les entrées observent également les règles Tk standard pour la gestion du focus d'entrée. Lorsqu'une entrée a le focus d'entrée, elle affiche un curseur d'insertion pour indiquer où les nouveaux caractères seront insérés.

Les entrées sont capables d'afficher des chaînes trop longues pour tenir entièrement dans la fenêtre du widget. Dans ce cas, seule une partie de la chaîne sera affichée ; les commandes décrites ci-dessous peuvent être utilisées pour modifier la vue dans la fenêtre. Les entrées utilisent le mécanisme standard -xscrollcommand pour interagir avec les barres de défilement (voir la description de l'option -xscrollcommand pour plus de détails). Elles prennent également en charge l'analyse, comme décrit ci-dessous.

VALIDATION

La validation fonctionne en définissant l'option -validatecommand sur un script (validateCommand) qui sera évalué selon l'option -validate comme suit :

none
Par défaut. Cela signifie qu'aucune validation ne se produira.
focus
validateCommand sera appelé lorsque l'entrée reçoit ou perd le focus.
focusin
validateCommand sera appelé lorsque l'entrée reçoit le focus.
focusout
validateCommand sera appelé lorsque l'entrée perd le focus.
key
validateCommand sera appelé lorsque l'entrée est modifiée.
all
validateCommand sera appelé pour toutes les conditions ci-dessus.

Il est possible d'effectuer des substitutions de pourcentage sur la valeur des options -validatecommand et -invalidcommand, tout comme vous le feriez dans un script bind. Les substitutions suivantes sont reconnues :

%d
Type d'action : 1 pour insertion, 0 pour suppression, ou -1 pour validation par focus, forcée ou textvariable.
%i
Indice du caractère à insérer/supprimer, le cas échéant, sinon -1.
%P
La valeur de l'entrée si l'édition est autorisée. Si vous configurez le widget d'entrée pour avoir une nouvelle textvariable, ce sera la valeur de cette textvariable.
%s
La valeur actuelle de l'entrée avant modification.
%S
La chaîne de caractères en cours d'insertion/suppression, le cas échéant, sinon {}.
%v
Le type de validation actuellement défini.
%V
Le type de validation qui a déclenché le rappel (key, focusin, focusout, forced).
%W

Le nom du widget d'entrée.

En général, les options -textvariable et -validatecommand peuvent être dangereuses à mélanger. Tous les problèmes ont été surmontés afin que l'utilisation de -validatecommand n'interfère pas avec le comportement traditionnel du widget d'entrée. L'utilisation de -textvariable à des fins de lecture seule ne causera jamais de problèmes. Le danger survient lorsque vous essayez de définir -textvariable sur quelque chose que -validatecommand n'accepterait pas, ce qui amène -validate à devenir none (la commande -invalidcommand ne sera pas déclenchée). Il en va de même lorsqu'une erreur survient lors de l'évaluation de la commande -validatecommand.

Principalement, une erreur se produira lorsque la commande -validatecommand ou -invalidcommand rencontrera une erreur dans son script lors de l'évaluation, ou lorsque -validatecommand ne retournera pas une valeur booléenne Tcl valide. L'option -validate se réglera également sur none lorsque vous modifierez le widget d'entrée à partir de la commande -validatecommand ou -invalidcommand. De telles modifications remplaceront celle qui était en cours de validation. Si vous souhaitez modifier le widget d'entrée (par exemple, le définir sur {}) pendant la validation et que l'option -validate reste active, vous devez inclure la commande

after idle {%W config -validate %v}
dans la commande -validatecommand ou -invalidcommand (selon celle à partir de laquelle vous modifiiez le widget d'entrée). Il est également recommandé de ne pas définir une commande -textvariable associée pendant la validation, car cela pourrait désynchroniser le widget d'entrée avec la commande -textvariable.

COMMANDE DU WIDGET

La commande entry crée une nouvelle commande Tcl dont le nom est pathName. Cette commande peut être utilisée pour invoquer diverses opérations sur le widget. Elle a la forme générale suivante :

pathName sous-commande ?arg arg ...?
La sous-commande et les args déterminent le comportement exact de la commande.

INDICES

De nombreuses commandes de widget pour les entrées prennent un ou plusieurs indices comme arguments. Un indice spécifie un caractère particulier dans la chaîne de l'entrée, de l'une des manières suivantes :

nombre
Spécifie le caractère comme un indice numérique, où 0 correspond au premier caractère de la chaîne.
anchor
Indique le point d'ancrage de la sélection, qui est défini avec les commandes de widget select from et select adjust.
end
Indique le caractère juste après le dernier caractère de la chaîne de l'entrée. Ceci est équivalent à spécifier un indice numérique égal à la longueur de la chaîne de l'entrée.
insert
Indique le caractère adjacent et immédiatement suivant le curseur d'insertion.
sel.first
Indique le premier caractère de la sélection. C'est une erreur d'utiliser cette forme si la sélection n'est pas dans la fenêtre d'entrée.
sel.last
Indique le caractère juste après le dernier caractère de la sélection. C'est une erreur d'utiliser cette forme si la sélection n'est pas dans la fenêtre d'entrée.
@nombre
Dans cette forme, nombre est traité comme une coordonnée x dans la fenêtre d'entrée ; le caractère qui traverse cette coordonnée x est utilisé. Par exemple, “@0” indique le caractère le plus à gauche de la fenêtre.

Des abréviations peuvent être utilisées pour toutes les formes ci-dessus, par exemple “e” ou “sel.f”. En général, les indices hors limites sont automatiquement arrondis à la valeur légale la plus proche.

SOUS-COMMANDES

Les commandes suivantes sont possibles pour les widgets d'entrée :

pathName bbox index
Retourne une liste de quatre nombres décrivant la boîte englobante du caractère donné par index. Les deux premiers éléments de la liste donnent les coordonnées x et y du coin supérieur gauche de la zone d'écran couverte par le caractère (en pixels par rapport au widget) et les deux derniers éléments donnent la largeur et la hauteur du caractère, en pixels. La boîte englobante peut faire référence à une zone en dehors de la zone visible de la fenêtre.
pathName cget option
Retourne la valeur actuelle de l'option de configuration donnée par option. Option peut avoir l'une des valeurs acceptées par la commande entry.
pathName configure ?option? ?valeur option valeur ...?
Interroge ou modifie les options de configuration du widget. Si aucune option n'est spécifiée, retourne une liste décrivant toutes les options disponibles pour pathName (voir Tk_ConfigureInfo pour des informations sur le format de cette liste). Si option est spécifiée sans valeur, la commande retourne une liste décrivant l'option nommée (cette liste sera identique à la sous-liste correspondante de la valeur retournée si aucune option n'est spécifiée). Si une ou plusieurs paires option-valeur sont spécifiées, la commande modifie les options de widget données pour leur attribuer les valeurs données ; dans ce cas, la commande retourne une chaîne vide. Option peut avoir l'une des valeurs acceptées par la commande entry.
pathName delete first ?last?
Supprime un ou plusieurs éléments de l'entrée. First est l'indice du premier caractère à supprimer, et last est l'indice du caractère juste après le dernier à supprimer. Si last n'est pas spécifié, il prend par défaut la valeur first+1, c'est-à-dire qu'un seul caractère est supprimé. Cette commande retourne une chaîne vide.
pathName get
Retourne la chaîne de l'entrée.
pathName icursor index
Dispose le curseur d'insertion juste avant le caractère donné par index. Retourne une chaîne vide.
pathName index index
Retourne l'indice numérique correspondant à index.
pathName insert index string
Insère les caractères de string juste avant le caractère indiqué par index. Retourne une chaîne vide.
pathName scan option args
Cette commande est utilisée pour implémenter le balayage sur les entrées. Elle a deux formes, selon option :
pathName scan mark x
Enregistre x et la vue actuelle dans la fenêtre d'entrée ; utilisé en conjonction avec les commandes scan dragto ultérieures. Généralement, cette commande est associée à un clic de bouton de souris dans le widget. Elle retourne une chaîne vide.
pathName scan dragto x
Cette commande calcule la différence entre son argument x et l'argument x de la dernière commande scan mark pour le widget. Elle ajuste ensuite la vue vers la gauche ou la droite de 10 fois la différence des coordonnées x. Cette commande est généralement associée aux événements de mouvement de la souris dans le widget, pour produire l'effet de faire glisser l'entrée à grande vitesse à travers la fenêtre. La valeur de retour est une chaîne vide.
pathName selection option arg
Cette commande est utilisée pour ajuster la sélection dans une entrée. Elle a plusieurs formes, selon option :
pathName selection adjust index
Localise l'extrémité de la sélection la plus proche du caractère donné par index, et ajuste cette extrémité de la sélection à index (c'est-à-dire en incluant mais sans dépasser index). L'autre extrémité de la sélection devient le point d'ancrage pour les futures commandes select to. Si la sélection n'est pas actuellement dans l'entrée, une nouvelle sélection est créée pour inclure les caractères entre index et le point d'ancrage de sélection le plus récent, inclusivement. Retourne une chaîne vide.
pathName selection clear
Efface la sélection si elle est actuellement dans ce widget. Si la sélection n'est pas dans ce widget, la commande n'a aucun effet. Retourne une chaîne vide.
pathName selection from index
Définit le point d'ancrage de la sélection juste avant le caractère donné par index. Ne modifie pas la sélection. Retourne une chaîne vide.
pathName selection present
Retourne 1 s'il y a des caractères sélectionnés dans l'entrée, 0 sinon.
pathName selection range start end
Définit la sélection pour inclure les caractères commençant par celui indexé par start et se terminant par celui juste avant end. Si end fait référence au même caractère que start ou à un caractère antérieur, la sélection de l'entrée est effacée.
pathName selection to index
Si index est avant le point d'ancrage, définit la sélection sur les caractères de index jusqu'au point d'ancrage, mais sans l'inclure. Si index est identique au point d'ancrage, ne fait rien. Si index est après le point d'ancrage, définit la sélection sur les caractères du point d'ancrage jusqu'à index, mais sans l'inclure. Le point d'ancrage est déterminé par la commande select from ou select adjust la plus récente dans ce widget. Si la sélection n'est pas dans ce widget, une nouvelle sélection est créée en utilisant le point d'ancrage le plus récent spécifié pour le widget. R
renvoie une chaîne vide.
