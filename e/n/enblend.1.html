ENBLEND(1) Commandes utilisateur ENBLEND(1)

NOM

enblend - page de manuel pour enblend 4.2.1-0bcfaaf743e7

SYNTAXE

enblend [options] [--output=IMAGE] ENTREE...

DESCRIPTION

Fusionne les images d'ENTRÉE en une seule IMAGE.

Les ENTREE... sont des noms de fichiers image ou des noms de fichiers de réponse. Les noms de fichiers de réponse commencent par le caractère "@".

OPTIONS

Options communes :

-l, --levels=NIVEAUX
limite le nombre de NIVEAUX de fusion à utiliser (de 1 à 29) ; un nombre négatif de NIVEAUX diminue le maximum ; "auto" rétablit la maximisation automatique par défaut.
-o, --output=FICHIER
écrit la sortie dans FICHIER ; par défaut : "a.tif"
-v, --verbose[=NIVEAU]
rapporte la progression de manière détaillée ; répéter pour augmenter la verbosité ou définir directement le NIVEAU.
--compression=COMPRESSION
définit la COMPRESSION de l'image de sortie, où COMPRESSION est : "deflate", "jpeg", "lzw", "none", "packbits", pour les fichiers TIFF et 0 à 100, ou "jpeg", "jpeg-arith" pour les fichiers JPEG, où "jpeg" et "jpeg-arith" acceptent un niveau de compression.

Options avancées :

--blend-colorspace=ESPACEDECOULEUR
force l'ESPACEDECOULEUR pour les opérations de fusion ; Enblend utilise "CIELUV" pour les images avec profil ICC et "IDENTITY" pour celles sans, ainsi que pour toutes les images à virgule flottante ; les autres espaces de fusion disponibles sont "CIELAB" et "CIECAM".
-c, --ciecam
utilise CIECAM02 pour fusionner les couleurs ; désactiver avec "--no-ciecam" ; notez que cette option sera retirée au profit de "--blend-colorspace".
-d, --depth=PROFONDEUR
définit le nombre de bits par canal de l'image de sortie, où PROFONDEUR est "8", "16", "32", "r32", ou "r64".
-f LARGEURxHAUTEUR[+xOFFSETx+yOFFSETy]
définit manuellement la taille et la position de l'image de sortie ; utile pour les images TIFF recadrées et décalées, telles que celles produites par Nona.
-g
hack alpha associé pour Gimp (avant la version 2) et Cinepaint.
-w, --wrap[=MODE]
enroule le bord de l'image, où MODE est "none" (aucun), "horizontal", "vertical", ou "both" (les deux) ; par défaut : aucun ; sans argument, l'option sélectionne l'enroulement horizontal.

Options de génération de masque :

--coarse-mask[=FACTEUR] réduit les régions de chevauchement par FACTEUR pour accélérer la génération de masque
de masque ; c'est la valeur par défaut ; si omis, FACTEUR vaut 8.
--fine-mask
génère le masque à la pleine résolution de l'image ; à utiliser par exemple si les régions de chevauchement sont très étroites.
--optimize
active l'optimisation du masque ; c'est la valeur par défaut ; désactiver avec "--no-optimize".
--save-masks[=MODÈLE]
sauvegarde les masques générés dans MODÈLE ; par défaut : "mask-%n.tif" ; caractères de conversion : "%i" : index du masque, "%n" : numéro du masque, "%p" : chemin complet, "%d" : nom du répertoire, "%b" : nom de base, "%f" : nom du fichier, "%e" : extension ; les caractères minuscules se réfèrent aux images d'entrée, les majuscules à l'image de sortie.
--load-masks[=MODÈLE]
utilise les masques existants dans MODÈLE au lieu de les générer ; mêmes caractères de modèle que "--save-masks" ; par défaut : "mask-%n.tif".
--visualize[=MODÈLE] sauvegarde les résultats de l'optimiseur dans MODÈLE ; mêmes caractères de modèle
que "--save-masks" ; par défaut : "vis-%n.tif".

Options expertes :

-a, --pre-assemble
pré-assemble les images non chevauchantes ; annuler avec "--no-pre-assemble".
-x
sauvegarde les résultats partiels.
--fallback-profile=PROFIL-FICHIER
utilise le profil ICC de PROFIL-FICHIER au lieu de sRGB.
--layer-selector=ALGORITHME
définit l'ALGORITHME de sélection de calque ; par défaut : "all-layers" ; les algorithmes disponibles sont : "all-layers" : sélectionne tous les calques de n'importe quelle image ; "first-layer" : sélectionne uniquement le premier calque de chaque image (multi-)calque ; "last-layer" : sélectionne uniquement le dernier calque de chaque image (multi-)calque ; "largest-layer" : sélectionne le calque le plus grand de chaque image (multi-)calque ; "no-layer" : ne sélectionne aucun calque d'aucune image ;
--parameter=CLE1[=VALEUR1][:CLE2[=VALEUR2][:...]]
définit une ou plusieurs paires CLÉ-VALEUR.

Options expertes de génération de masque :

--primary-seam-generator=ALGORITHME
utilise l'ALGORITHME principal de recherche de jointures, où ALGORITHME est "nearest-feature-transform" ou "graph-cut" ; par défaut : "graph-cut".
--image-difference=ALGORITHME[:POIDS-LUMINANCE[:POIDS-CHROMINANCE]]
utilise l'ALGORITHME pour le calcul de l'image de différence, où ALGORITHME est "max-hue-luminance" ou "delta-e" ; POIDS-LUMINANCE et POIDS-CHROMINANCE définissent les poids de la clarté et de la couleur ; par défaut : delta-e:1:1.
--optimizer-weights=POIDS-DISTANCE[:POIDS-INADÉQUATION]
définit les poids de l'optimiseur pour la distance et l'inadéquation ; par défaut : 8:1.
--mask-vectorize=LONGUEUR
définit la LONGUEUR d'un segment de jointure unique ; ajoutez "%" pour une valeur relative ; par défaut : 4 pour les masques grossiers et 20 pour les masques fins.
--anneal=TAU[:DELTAE-MAX[:DELTAE-MIN[:K-MAX]]]
définit les paramètres d'adoucissement de la stratégie d'optimiseur 1 ; par défaut : 0.75:7000:5:32.
--dijkstra=RAYON
définit le RAYON de recherche de la stratégie d'optimiseur 2 ; par défaut : 25 pixels.

Options d'information :

-h, --help
affiche ce message d'aide et quitte.
-V, --version
affiche les informations de version et quitte.
--show-globbing-algorithms
affiche tous les algorithmes de globbing.
--show-image-formats
affiche tous les formats d'image reconnus et leurs extensions de fichier.
--show-signature
affiche qui a compilé le binaire, quand et sur quelle machine.
--show-software-components
affiche les composants logiciels avec lesquels Enblend a été compilé.
