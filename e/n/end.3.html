NOM

etext, edata, end - fin des segments de programme

SYNTAXE

extern etext;
extern edata;
extern end;

DESCRIPTION

Les adresses de ces symboles indiquent la fin de divers segments de programme :

etext
Ceci est la première adresse après la fin du segment de texte (le code du programme).
edata
Ceci est la première adresse après la fin du segment de données initialisé.
end
Ceci est la première adresse après la fin du segment de données non initialisé (également appelé segment BSS).

NORMES

Aucune.

HISTORIQUE

Bien que ces symboles soient fournis depuis longtemps sur la plupart des systèmes UNIX, ils ne sont pas standardisés ; utilisez-les avec prudence.

NOTES

Le programme doit déclarer explicitement ces symboles ; ils ne sont définis dans aucun fichier d'en-tête.

Sur certains systèmes, les noms de ces symboles sont précédés de tirets bas, ainsi : _etext, _edata et _end. Ces symboles sont également définis pour les programmes compilés sur Linux.

Au début de l'exécution du programme, le point de rupture (program break) se situera quelque part près de &end (peut-être au début de la page suivante). Cependant, le point de rupture changera lors de l'allocation de mémoire via brk(2) ou malloc(3). Utilisez sbrk(2) avec un argument de zéro pour trouver la valeur actuelle du point de rupture du programme.

EXEMPLES

Lors de son exécution, le programme ci-dessous produit une sortie telle que la suivante :


$ ./a.out
Première adresse après :
    texte du programme (etext)   0x8048568
    données initialisées (edata) 0x804a01c
    données non initialisées (end) 0x804a024

Source du programme

#include <stdio.h>
#include <stdlib.h>
extern char etext, edata, end;  /* Les symboles doivent avoir un type,
                                   sinon "gcc -Wall" se plaint */
int
main(void)
{
    printf("Première adresse après :\n");
    printf("    texte du programme (etext)      %10p\n", &etext);
    printf("    données initialisées (edata)  %10p\n", &edata);
    printf("    données non initialisées (end)  %10p\n", &end);
    exit(EXIT_SUCCESS);
}
