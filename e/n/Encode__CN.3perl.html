NOM

Encode::CN - Encodages chinois basés en Chine

SYNTAXE

use Encode qw/encode decode/; 
$euc_cn = encode("euc-cn", $utf8);   # charge Encode::CN implicitement
$utf8   = decode("euc-cn", $euc_cn); # id.

DESCRIPTION

Ce module implémente les jeux de caractères chinois basés en Chine. Les encodages pris en charge sont les suivants.

Canonique   Alias             Description
--------------------------------------------------------------------
euc-cn      /\beuc.*cn$/i     EUC (Extended Unix Character)
        /\bcn.*euc$/i
            /\bGB[-_ ]?2312(?:\D.*$|$)/i (voir ci-dessous)
gb2312-raw                    La carte de caractères GB2312 brute (bas-bit)
gb12345-raw                   L'équivalent chinois traditionnel de
              GB2312 (brut)
iso-ir-165                    GB2312 + GB6345 + GB8565 + additions
MacChineseSimp                GB2312 + Ajouts Apple
cp936                         Code Page 936, également connu sous le nom de GBK
              (Extended GuoBiao)
hz                            Encodage GB2312 échappé sur 7 bits
--------------------------------------------------------------------

Pour savoir comment utiliser ce module en détail, voir Encode.

NOTES

Pour des raisons de taille, "GB 18030" (une extension de "GBK") est distribué séparément sur CPAN, sous le nom Encode::HanExtra. Ce module contient également des encodages supplémentaires basés à Taiwan.

BOGUES

Lorsque vous voyez "charset=gb2312" sur des e-mails et des pages web, cela signifie en réalité des encodages "euc-cn". Pour corriger cela, "gb2312" est aliasé à "euc-cn". Utilisez "gb2312-raw" lorsque vous le pensez vraiment.

La région ASCII (0x00-0x7f) est préservée pour tous les encodages, même si cela entre en conflit avec les mappages du Unicode Consortium.
