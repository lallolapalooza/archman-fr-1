English(3perl) Guide de référence pour programmeurs Perl English(3perl)

NOM

English - utilise des noms anglais (ou awk) compréhensibles pour les variables laides à base de ponctuation

SYNTAXE

use English;
use English qw( -no_match_vars ) ;  # Évite la pénalité de performance des
                                    # expressions régulières en perl 5.18
                                    # et versions antérieures
...
if ($ERRNO =~ /denied/) { ... }

DESCRIPTION

Ce module fournit des alias pour les variables intégrées dont les noms sont apparemment peu appréciés. Les variables ayant des effets secondaires déclenchés simplement par leur accès (comme $0) seront toujours affectées.

Pour les variables qui ont une version awk, des alternatives anglaises courtes et longues sont fournies. Par exemple, la variable $/ peut être référencée soit comme $RS, soit comme $INPUT_RECORD_SEPARATOR si vous utilisez le module English.

Voir perlvar pour une liste complète.

PERFORMANCE

NOTE : Ceci a été corrigé dans perl 5.20. L'évocation de ces trois variables n'entraîne plus de différence de vitesse. Cette section s'applique toujours si votre code doit s'exécuter sur perl 5.18 ou une version antérieure.

Ce module peut provoquer d'importantes inefficacités pour les expressions régulières, en raison de détails d'implémentation malheureux. Si la performance est importante pour votre application et que vous n'avez pas besoin de $PREMATCH, $MATCH ou $POSTMATCH, essayez de faire

use English qw( -no_match_vars ) ;

. Il est particulièrement important de le faire dans les modules pour éviter de pénaliser toutes les applications qui les utilisent.
