NOM

Encode::Alias - définitions d'alias pour les encodages

SYNTAXE

use Encode;
use Encode::Alias;
define_alias( "nouveauNom" => ENCODAGE);
define_alias( qr/.../ => ENCODAGE);
define_alias( sub { return ENCODAGE if ...; } );

DESCRIPTION

Permet d'utiliser nouveauNom comme un alias pour ENCODAGE. ENCODAGE peut être soit le nom d'un encodage, soit un objet d'encodage (tel que décrit dans Encode).

Actuellement, le premier argument de define_alias() peut être spécifié de la manière suivante :

Comme une simple chaîne de caractères.
Comme une expression régulière compilée qr//, par exemple :
define_alias( qr/^iso8859-(\d+)$/i => '"iso-8859-$1"' );

Dans ce cas, si ENCODAGE n'est pas une référence, il est "eval"-ué afin de permettre la substitution de $1, etc. L'exemple est une façon d'associer des noms tels qu'utilisés dans les polices X11 aux noms MIME pour la famille iso-8859-*. Notez les guillemets doubles à l'intérieur des guillemets simples.

(ou, vous n'avez pas à le faire vous-même car cet exemple est prédéfini)

Si vous utilisez une expression régulière ici, vous devez utiliser les guillemets comme indiqué, sinon cela ne fonctionnera pas. Notez également que la gestion des expressions régulières est délicate, même pour les personnes expérimentées. Utilisez cette fonctionnalité avec précaution.

Comme une référence de code, par exemple :
define_alias( sub {shift =~ /^iso8859-(\d+)$/i ? "iso-8859-$1" : undef } );

Même effet que l'exemple ci-dessus, mais d'une autre manière. La référence de code prend le nom de l'alias comme argument et retourne un nom canonique en cas de succès ou undef sinon. Notez que le deuxième argument est ignoré s'il est fourni. Utilisez ceci avec encore plus de prudence que la version avec expression régulière.

Changements dans l'aliasing par référence de code

Depuis Encode 1.87, l'ancienne forme

define_alias( sub { return  /^iso8859-(\d+)$/i ? "iso-8859-$1" : undef } );

ne fonctionne plus.

Encode jusqu'à la version 1.86 utilisait en interne "local $_" pour implémenter cette ancienne forme. Mais considérez le code ci-dessous ;

use Encode;
$_ = "eeeee" ;
while (/(e)/g) {
  my $utf = decode('aliased-encoding-name', $1);
  print "position:",pos,"\n";
}

Avant Encode 1.86, cela échoue à cause de "local $_".

Surcharge d'alias

Vous pouvez remplacer les alias prédéfinis en appliquant simplement define_alias(). Le nouvel alias est toujours évalué en premier, et si nécessaire, define_alias() vide le cache interne pour rendre la nouvelle définition disponible.

# redirige SHIFT_JIS vers MS/IBM Code Page 932, qui est un
# sur-ensemble de SHIFT_JIS
define_alias( qr/shift.*jis$/i  => '"cp932"' );
define_alias( qr/sjis$/i        => '"cp932"' );

Si vous souhaitez supprimer tous les alias prédéfinis, vous pouvez utiliser

Encode::Alias->undef_aliases;

pour ce faire. Et

Encode::Alias->init_aliases;

restaure les paramètres d'usine.

Notez que define_alias() ne pourra pas remplacer le nom canonique des encodages. Les encodages sont d'abord recherchés par nom canonique avant que les alias potentiels ne soient essayés.
