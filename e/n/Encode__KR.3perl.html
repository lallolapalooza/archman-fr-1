NOM

Encode::KR - Encodages coréens

SYNOPIS

use Encode qw/encode decode/; 
$euc_kr = encode("euc-kr", $utf8);   # charge Encode::KR implicitement
$utf8   = decode("euc-kr", $euc_kr); # idem

DESCRIPTION

Ce module implémente les jeux de caractères coréens. Les encodages pris en charge sont les suivants.

Canonique   Alias             Description
--------------------------------------------------------------------
euc-kr      /\beuc.*kr$/i     EUC (Extended Unix Character)
        /\bkr.*euc$/i
ksc5601-raw                   Jeu de codes standard coréen (tel quel)
cp949       /(?:x-)?uhc$/i
            /(?:x-)?windows-949$/i
            /\bks_c_5601-1987$/i
                              Code Page 949 (EUC-KR + 8 822
                              syllabes Hangul supplémentaires)
MacKorean                     EUC-KR + Mappages du vendeur Apple
johab       JOHAB             Un encodage supplémentaire défini dans
                                           l'Annexe 3 de KS X 1001:1998
iso-2022-kr                   iso-2022-kr                  [RFC1557]
--------------------------------------------------------------------

Pour savoir comment utiliser ce module en détail, voir Encode.

BOGUES

Lorsque vous voyez "charset=ks_c_5601-1987" dans les courriels et les pages Web, ils signifient en réalité les encodages "cp949". Pour corriger cela, les alias suivants sont définis ;

qr/(?:x-)?uhc$/i         => '"cp949"'
qr/(?:x-)?windows-949$/i => '"cp949"'
qr/ks_c_5601-1987$/i     => '"cp949"'

La région ASCII (0x00-0x7f) est préservée pour tous les encodages, bien que cela soit en conflit avec les mappages du Consortium Unicode.
