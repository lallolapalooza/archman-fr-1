ENCGUESS(1perl) Guide de référence des programmeurs Perl ENCGUESS(1perl)

NOM

encguess - deviner les encodages de caractères des fichiers

VERSION

$Id: encguess,v 0.4 2023/11/10 01:10:50 dankogai Exp $

SYNTAXE

encguess [options] nom_de_fichier...

OPTIONS

-h
affiche ce message et quitte.
-s
spécifie une liste de « types d'encodage suspects » à tester, séparés par  ":"  ou  "," 
-S
affiche une liste de tous les types d'encodage acceptables qui peuvent être utilisés avec le paramètre -s
-u
supprime l'affichage des types non identifiés

EXEMPLES :

  • Deviner l'encodage d'un fichier nommé "test.txt", en utilisant uniquement les types suspects par défaut. 
    encguess test.txt
  • Deviner le type d'encodage d'un fichier nommé "test.txt", en utilisant les types suspects "euc-jp,shiftjis,7bit-jis". 
    encguess -s euc-jp,shiftjis,7bit-jis test.txt
encguess -s euc-jp:shiftjis:7bit-jis test.txt
  • Deviner le type d'encodage de plusieurs fichiers, ne pas afficher les résultats pour les fichiers non identifiés. 
    encguess -us euc-jp,shiftjis,7bit-jis test*.txt

DESCRIPTION

L'identification de l'encodage se fait en vérifiant un type d'encodage à la fois jusqu'à ce que tous sauf le bon type soient éliminés. L'ensemble des types d'encodage à essayer est défini par le paramètre -s et par défaut, il s'agit de ascii, utf8 et UTF-16/32 avec BOM. Ceci peut être écrasé en passant un ou plusieurs types d'encodage via le paramètre -s. Si vous devez passer plusieurs types d'encodage suspects, utilisez une chaîne entre guillemets avec un espace séparant chaque valeur.

VOIR AUSSI

Encode::Guess, Encode::Detect
