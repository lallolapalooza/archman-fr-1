DESCRIPTIO

N

Ces routines sont utilisées pour accéder au fichier de description des systèmes de fichiers /etc/fstab et au fichier de description des systèmes de fichiers montés /etc/mtab

.

La fonction setmntent() ouvre le fichier de description des systèmes de fichiers path et renvoie un pointeur de fichier qui peut être utilisé par getmntent(). L'argument type est le type d'accès requis et peut prendre les mêmes valeurs que l'argument mode de fopen(3). Le flux renvoyé devrait être fermé avec endmntent() plutôt qu'avec fclose(

3).

La fonction getmntent() lit la ligne suivante du fichier de description des systèmes de fichiers depuis stream et renvoie un pointeur vers une structure contenant les champs extraits d'une ligne du fichier. Le pointeur pointe vers une zone statique de mémoire qui est écrasée par les appels suivants à getmnten

t().

La fonction addmntent() ajoute la structure mntent mnt à la fin du stream ou

vert.

La fonction endmntent() ferme le stream associé au fichier de description des systèmes de

fichiers.

La fonction hasmntopt() parcourt le champ mnt_opts (voir ci-dessous) de la structure mntent mnt à la recherche d'une sous-chaîne qui correspond à opt. Voir <mntent.h> et mount(8) pour les options de montage

valides.

La fonction getmntent_r() ré-entrant est similaire à getmntent(), mais stocke la structure mntent dans le *mntbuf fourni, et stocke les chaînes pointées par les entrées de cette structure dans le tableau fourni buf de taille size

.

La structure mntent est définie dans <mntent.h> comme suit

: 


struct mntent {
    char *mnt_fsname;   /* nom du système de fichiers monté */
    char *mnt_dir;      /* préfixe de chemin du système de fichiers */
    char *mnt_type;     /* type de montage (voir mntent.h) */
    char *mnt_opts;     /* options de montage (voir mntent.h) */
    int   mnt_freq;     /* fréquence de sauvegarde en jours */
    int   mnt_passno;   /* numéro de passage lors d'un fsck parallèle */
}
;

Puisque les champs des fichiers mtab et fstab sont séparés par des espaces, des échappements octaux sont utilisés pour représenter les caractères espace (\040), tabulation (\011), nouvelle ligne (\012) et antislash (\\) dans ces fichiers lorsqu'ils apparaissent dans l'une des quatre chaînes d'une structure mntent. Les routines addmntent() et getmntent() convertiront de la représentation en chaîne vers la représentation échappée et inversement. Lors d

e la conversion depuis la représentation échappée, la
séquence \134 est également convertie en un antislash.

VALEUR

RENVOYÉE

Les fonctions getmntent() et getmntent_r() renvoient un pointeur vers la structure mntent ou NULL en cas

d'échec.

La fonction addmntent() renvoie 0 en cas de succès et 1 en cas

d'échec.

La fonction endmntent() renvoie toujours

1.

La fonction hasmntopt() renvoie l'adresse de la sous-

chaîne si une correspondance
est trouvée et NULL sinon.

HISTORIQU

E

Les fonctions non ré-entrantes proviennent de SunOS 4.1.3. Une routine getmntent_r() a été introduite dans HP-UX 10, mais elle renvoie un int. Le prototype montré ci-dessus est exclusif à

glibc.

System V a également une fonction getmntent() mais la séquence d'appel diffère, et la structure renvoyée est différente. Sous System V /etc/mnttab est utilisé. 4.4BSD et Digital UNIX ont une routine getmntinfo(), un enveloppement autour de l'appel système getfss

tat
().
