NOM

eolang - Éditeur automatique de fichiers TeX utilisant le package "eolang"

SYNTAXE

eolang [<options>] <chemin du fichier source .tex> <chemin du fichier cible .tex>

DESCRIPTION

L'outil eolang est un script Perl permettant de modifier automatiquement les fichiers TeX qui utilisent le package "eolang", afin de les aider à passer les vérifications de post-traitement dans les éditeurs ACM, arXiv, IEEE, et autres.

OPTIONS

Diverses options s'appliquent :

--version
Affiche la version de l'outil.
--help
Affiche l'écran d'introduction.
--verbose
Affiche également les informations de débogage.
