EOF(3const) EOF(3const)

NOM

EOF - indicateur de fin de fichier ou d'erreur

BIBLIOTHÈQUE

Bibliothèque C standard (libc)

SYNTAXE

#include <stdio.h>
#define EOF  /* ... */

DESCRIPTION

EOF représente la fin d'un fichier d'entrée, ou une indication d'erreur. C'est une valeur négative, de type int.

EOF n'est pas un caractère (il ne peut pas être représenté par unsigned char). C'est plutôt une valeur sentinelle en dehors de la plage valide pour les caractères valides.

NORMES

C11, POSIX.1-2024.

HISTORIQUE

C89, POSIX.1-2001.

ATTENTION

Les programmes ne peuvent pas passer cette valeur à une fonction de sortie pour "écrire" la fin d'un fichier. Cela entraînerait probablement un comportement indéfini. Au lieu de cela, fermer le flux d'écriture ou le descripteur de fichier qui fait référence à un tel fichier est la façon de signaler la fin de ce fichier.

VOIR AUSSI

feof(3), fgetc(3)
