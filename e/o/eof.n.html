NOM

eof - Vérifier la condition de fin de fichier sur un canal

SYNOPSIS

eof channelId

DESCRIPTION

Retourne 1 si une condition de fin de fichier s'est produite lors de la dernière opération d'entrée sur channelId (telle que gets), 0 sinon.

ChannelId doit être un identifiant pour un canal ouvert tel qu'un canal standard Tcl (stdin, stdout, ou stderr), la valeur de retour d'une invocation de open ou socket, ou le résultat d'une commande de création de canal fournie par une extension Tcl.

EXEMPLES

Lire et afficher le contenu d'un fichier ligne par ligne :

set f [open somefile.txt]
while {1} {
    set line [gets $f]
    if {[eof $f]} {
        close $f
        break
    }
    puts "Ligne lue : $line"
}

Lire et afficher le contenu d'un fichier par enregistrements de taille fixe :

set f [open somefile.dat]
fconfigure $f -translation binary
set recordSize 40
while {1} {
    set record [read $f $recordSize]
    if {[eof $f]} {
        close $f
        break
    }
    puts "Enregistrement lu : $record"
}
