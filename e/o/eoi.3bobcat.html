FBB::Eoi(3bobcat) Classe de base End-Of-Information FBB::Eoi(3bobcat)

NOM

FBB::Eoi - classe std::streambuf offrant un manipulateur eoi

SYNOPSISSE

#include <bobcat/eoi>
Option de liaison : -lbobcat

DESCRIPTION

La classe Eoi hérite de std::streambuf et peut donc être utilisée comme classe de base de classes spécialisant std::streambuf. Elle est particulièrement utile pour les classes implémentant des opérations de sortie, car elle peut être utilisée pour spécifier la « vraie fin » de la sortie générée. Par exemple, un objet std::istream in peut insérer son contenu dans un objet std::ostream out en utilisant l'expression familière out << in.rdbuf() , mais cela ne permet pas à out de conclure qu'il a reçu toutes ses informations. Parfois, des actions supplémentaires sont nécessaires pour compléter la sortie (cela se produit avec, par exemple, les objets EncryptBuf (cf.encryptbuf (3bobcat)) où après le chiffrement de toutes les entrées, des caractères de remplissage peuvent devoir être ajoutés au document chiffré. Si out est initialisé avec l'adresse d'un std::streambuf EncryptBuf , la vraie fin de l'entrée peut être indiquée en insérant le manipulateur eoi . L'expression résultante devient std::cout << in.rdbuf() << eoi, et le manipulateur s'assure que le remplissage correct est géré.

ESPACE DE NOMS

FBB
Tous les constructeurs, membres, opérateurs et manipulateurs mentionnés dans cette page manuel sont définis dans l'espace de noms FBB.

HÉRITE DE

std::streambuf

CONSTRUCTEUR PROTÉGÉ

o
Eoi():
De manière analogue à std::streambuf , seul un constructeur protégé par défaut est disponible.

Les constructeurs de copie et de déplacement (et les opérateurs d'affectation) ne sont pas disponibles.

FONCTIONS MEMBRES

Tous les membres de std:streambuf sont disponibles, car FBB::Eoi hérite de ces classes.

FONCTION MEMBRE VIRTUELLE

o
virtual void eoi_():
La fonction membre virtuelle eoi_ est un membre privé qui peut être redéfini par les classes dérivées. Par défaut, elle n'effectue aucune action.

MANIPULATEUR

o
std::ostream &FBB::eoi(std::ostream &out):
Le manipulateur eoi peut être inséré dans le ostream utilisant un streambuf hérité de FBB::EoiBuf pour arrêter les insertions ultérieures dans le ostream. S'il est inséré dans un std::ostream simple, rien ne se passe.
eoi peut également être appelé en tant que fonction, recevant le flux qui utilise un FBB::EoiBuf comme son streambuf. Par défaut, le manipulateur eoi n'effectue aucune action. Pour utiliser le manipulateur dans une classe dérivée de EoiBuf , l'approche suivante peut être utilisée : 
    1. définir un membre de données tt(bool d_eoi), initialisé à tt(false) ;
    2. définir un membre tt(void eoi_() override) ;
    3. tt(eoi_) retourne si tt(d_eoi == true), sinon :
    4. il définit tt(d_eoi) à tt(true) et effectue les actions normalement effectuées par le destructeur de la classe ;
    5. le destructeur de la classe appelle tt(eoi_()).
