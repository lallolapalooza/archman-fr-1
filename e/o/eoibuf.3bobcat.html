DESCRIPTIO

N

La classe EoiBuf hérite de Eoi et peut donc être utilisée comme classe de base de classes spécialisant std::streambuf. Elle fournit également un tampon de caractères configurable pour stocker les caractères reçus de leurs périphériques. Souvent, lors de la dérivation de classes à partir de std::streambuf, les classes dérivées doivent implémenter le stockage dans et la récupération à partir d'un tampon de caractères. En héritant de EoiBuf, la gestion du tampon est automatiquement fournie : elle contient un tampon de caractères (redimensionnable) et offre un membre setp ainsi qu'un membre setg qui peut être utilisé pour spécifier la plage d'index du tampon à partir de laquelle les extractions reçoivent les caractères. De plus, en redéfinissant le membre eoi_ de sa classe de base, elle peut être utilisée pour signaler la fin des données d'entrée insérées dans les classes std::ostream utilisant des objets EoiBuf comme objets std:

:stre
ambuf.

EXEMPL

E

Les deux fonctions suivantes sont définies dans la classe (utilisée uniquement en interne) FBB::OSymCryptBase, qui est la classe de base de osymcryptstreambuf(

3bobcat).
o
evpUpdate met à jour le chiffrement ou le déchiffrement en cours, par exemple en utilisant la fonction openssl EVP_EncryptUpdate, en utilisant ucharPtr pour accéder aux caractères actuellement dans le tampon de EoiBuf
: 
#include "osymcryptbase.ih"
void OSymCryptBase::evpUpdate()
{
    size_t inBufRead = pptr() - pbase();    // # read chars
    checkOutBufSize(inBufRead);
    int nOutputChars;
    if (not ((*d_evpUpdate)(                // en/decrypt the bytes in d_inBuf
            ctx(),
            uOutBuf(), &nOutputChars,
            ucharPtr(), inBufRead
        ))
    )
        throw Exception{} << "EVP_{En,De}cryptUpdate failed";
    d_outStream.write(outBuf(), nOutputChars);      // write the processed
                                                    // chars to d_outSteam
setp()
; }
o
eoi_ redéfinit la fonction FBB::Eoi::eoi_(), empêchant de nouvelles informations d'être insérées dans l'objet FBB::OSymCryptBase (et donc d'être insérées dans sa classe dérivée FBB::OSymCryptStreambuf)
: 
#include "osymcryptbase.ih"
void OSymCryptBase::eoi_()
{
if (d_eoi) return; evpUpdate();
// process available chars in the input d_eoi = true;
resize(0); // clear the input buffer
evpUpdate(); // update an empty buffer }
