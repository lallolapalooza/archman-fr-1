NOM

eeprog - lit et écrit les EEPROMs 24Cxx connectées au bus série I2C

SYNOPSIS

eeprog [-fqxdh] [-16|-8] [-r addr[:count]|-w addr] <périphérique> <addr-i2c>

DESCRIPTION

eeprog utilise le protocole SMBus utilisé par la plupart des chipsets récents.

NOTE

N'oubliez pas de charger vos pilotes de chipset i2c et i2c-dev.

Les variables d'environnement suivantes peuvent être définies à la place des arguments de la ligne de commande :


EEPROG_DEV périphérique
EEPROG_I2C_ADDR addr-i2c

PARAMETRES

Modes d'adresse

-8
Utilise le mode d'adressage 8 bits pour les 24c0x...24C16 [par défaut]
-16
Utilise le mode d'adressage 16 bits pour les 24c32...24C256
Actions
-r addr[:count]
Lit count (1 si omis) octets à partir de addr et les affiche sur la sortie standard.
-w addr
Écrit l'entrée (stdin) à l'adresse addr de l'EEPROM.
-h
Affiche cette aide.
Options
-x
Active le mode de sortie hexadécimale.
-d
Mode factice, affiche ce qui aurait été fait.
-f
Désactive les avertissements et ne demande pas de confirmation.
-q
Mode silencieux.
Bus
périphérique
Fichier périphérique représentant le bus I2C (par exemple, /dev/i2c-0).
addr-i2c
Adresse du bus I2C de l'EEPROM (par exemple, 0x3A).

EXEMPLES

Lire 64 octets depuis l'EEPROM à l'adresse 0x54 sur le bus 0 en commençant à l'adresse 123 (décimal).

eeprog /dev/i2c-0 0x54 -r 123:64

Afficher les codes hexadécimaux des 32 premiers octets lus depuis le bus 1 à l'adresse 0x22.

eeprog /dev/i2c-1 0x51 -x -r 0x22:0x20

Écrire l'horodatage actuel à l'adresse 0x200 de l'EEPROM sur le bus 0 à l'adresse 0x33.


date | eeprog -f /dev/i2c-0 0x33 -w 0x200
