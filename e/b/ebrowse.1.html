NOM

ebrowse - créer une base de données de hiérarchie de classes

SYNTAXE

ebrowse [options] [FICHIERS...]

DESCRIPTION

Cette page de manuel documente brièvement la commande ebrowse. La documentation complète est disponible au format GNU Info.

ebrowse est utilisé pour créer la base de données utilisée par le navigateur de classes dans Emacs.

OPTIONS

Le programme suit la syntaxe habituelle des lignes de commande GNU, avec les options longues commençant par deux tirets ("-").

-a, --append
ajouter la sortie au fichier existant
-f, --files=FICHIERS
lire les noms de fichiers d'entrée depuis FICHIER
-I, --search-path=LISTE
définir le chemin de recherche des fichiers d'entrée
-m, --min-regexp-length=N
définir la longueur minimale des expressions régulières à N
-M, --max-regexp-length=N
définir la longueur maximale des expressions régulières à N
-n, --no-nested-classes
exclure les classes imbriquées
-o, --output-file=FICHIER
définir le nom du fichier de sortie à FICHIER
-p, --position-info
afficher des informations sur la position dans le fichier
-s, --no-structs-or-unions
ne pas enregistrer les structures ou unions
-v, --verbose
être verbeux
-V, --very-verbose
être très verbeux
-x, --no-regexps
ne pas enregistrer les expressions régulières
--help
afficher cette aide
--version
afficher les informations sur la version

VOIR AUSSI

emacs(1), etags(1), et la documentation complète de ebrowse qui est maintenue sous forme de manuel Texinfo. Si les programmes info et ebrowse sont correctement installés sur votre site, la commande

info ebrowse

devrait vous donner accès au manuel complet.
