NOM

extractbb, ebb - extraire les informations de boîte englobante des fichiers graphiques

SYNTAXE

extractbb [-v|-q] [-O] [-m|-x] fichier...

DESCRIPTION

Pour chaque fichier JPEG, PNG ou PDF donné sur la ligne de commande, extractbb extrait les informations de boîte englobante et les écrit dans un fichier avec l'extension .xbb, ainsi que des informations d'en-tête. Ces fichiers peuvent ensuite être utilisés par dvipdfmx ou d'autres programmes. Pour les fichiers PDF, le nombre de pages et le numéro de version du PDF sont également rapportés. L'extension du nom de fichier d'entrée peut être en majuscules ou en minuscules.

Si appelé sous le nom ebb, la sortie est écrite au format ``bb'' (et avec l'extension .bb) tel qu'utilisé par dvipdfm. Xbb peut être défini comme un synonyme pour extractbb sur votre système.

OPTIONS

-v
Être verbeux.
-q
Être silencieux.
-O
Écrire la sortie sur la sortie standard.
-m
Écrire la sortie au format ``bb'' de dvipdfm.
-x
Écrire la sortie au format ``xbb'' de dvipdfmx (par défaut), qui est le même que celui utilisé par pdfTeX.

FORMATS DE SORTIE

Voici plus de détails sur les formats bb et xbb :

L'original ebb (de dvipdfm) ignorait les informations de densité dans les images bitmap, et générait des boîtes englobantes avec 100px = 72bp = 1in. Malheureusement, les captures d'écran (surtout) ont tendance à mal rendre avec cette approche.

Ainsi, extractbb (de dvipdfmx) utilise les informations de densité si elles sont présentes. Sinon, il génère une boîte englobante avec 100px = 100bp. C'est ce que fait pdfTeX.

BOGUES

Il n'y a actuellement aucun moyen de spécifier quelle boîte englobante est prise pour les fichiers PDF. Ce sera toujours la première de la liste suivante : ArtBox, TrimBox, BleedBox, MediaBox. (Souvent, seule la MediaBox est définie.) De plus, la boîte englobante rapportée fait toujours référence à la première page d'un fichier PDF.
