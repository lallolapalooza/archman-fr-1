DESCRIPTIO

N

Le programme ircII/EPIC est un agent utilisateur ('client') orienté caractères basé sur unix pour Internet Relay Chat. C'est un client ircII entièrement

fonctionnel avec de nombreuses extensions utiles. Cette version fonctionne
avec toutes les classes modernes de serveurs irc en date du début de 1999.

OPTION

S
-
a
Ajoute la liste de description de serveurs à la liste de serveurs par défaut. Le comportement par défaut est que la liste de description de serveurs remplace la liste de serveurs par
défaut.
-
b
Fonctionne en ce qu'on appelle le « mode bot ». Cela implique l'option [-d]. EPIC va fork(2) immédiatement et le processus parent va se terminer, vous ramenant à votre shell. Certains administrateurs système n'apprécient pas que leurs utilisateurs exécutent des bots, et ils ont désactivé cette option. Même si votre administrateur ne l'a pas désactivée, vous ne devriez pas supposer que cela vous donne automatiquement la permission d'exécuter un bot. Si vous exécutez effectivement un bot sans permission, votre administrateur peut se mettre très en colère contre vous, et éventuellement révoquer votre compte. De plus, la plupart des opérateurs IRC sur les réseaux irc publics ont très peu de tolérance envers les personnes qui exécutent des bots. Alors juste un mot de prudence, assurez-vous que votre administrateur système et votre administrateur irc vous ont donné la permission avant d'exécuter un
bot.
-
B
Force le fichier de démarrage à être chargé immédiatement plutôt que d'attendre jusqu'à ce qu'une connexion à un serveur soit
établie.
-c ch
an
Rejoint le canal spécifié la première fois que vous vous connectez avec succès à un
serveur.
-
d
Fonctionne en « mode bête ». Le client n'affichera pas un écran complet, et lira depuis l'entrée standard et écrira vers la sortie standard. C'est utile si la sortie a normalement un aspect horrible (parce que vous utilisez un paramètre TERM incorrect, ou votre description de terminal est spectaculairement cassée), ou si vous ne voulez tout simplement pas utiliser l'interface jolie. Cette option sera activée automatiquement si votre paramètre TERM actuel n'est pas capable d'afficher un écran
complet.
-
f
Force l'utilisation du contrôle de flux matériel. Avec cette option, les touches control-S et control-Q ne sont probablement pas disponibles pour être liées à autre
chose.
-
F
Désactive l'utilisation du contrôle de flux matériel. Avec cette option, les touches control-S et control-Q sont disponibles pour être liées à autre chose. Cependant, vous n'aurez pas de contrôle de flux
matériel.
-
h
Affiche un message d'aide modérément concis et se termine
immédiatement.
-H hostna
me
Utilise l'adresse IP du hostname spécifié comme votre adresse IP par défaut. Cela peut être utilisé si vous avez plusieurs adresses IP sur la même machine et que vous voulez utiliser une adresse autre que l'adresse par défaut. Vous pourriez avoir besoin d'utiliser cette option quand gethostname(3) ne retourne pas un hostname (dans certains environnements NIS mal configurés). L'utilisation de plusieurs adresses IP sur une seule machine est couramment appelée « hébergement virtuel » (virtual hosting), et chaque adresse IP est un « hôte virtuel ». Veuillez comprendre qu'un client irc peut ne pas dire au serveur irc quel devrait être votre hostname : le serveur seul le détermine. Les serveurs utilisent typiquement le hostname canonique d'une adresse IP comme votre hostname. À cause de cela, cette option ne vous permettra pas d'utiliser un CNAME (hostname secondaire pour une adresse IP), parce que le serveur utilisera le hostname canonique à la place. Cette option remplace la variable d'environnement IRCHOST
.
-l filename,
[filename]
Utilise le ou les fichiers spécifiés comme fichier de démarrage. Le fichier de démarrage est chargé la première fois que vous vous connectez avec succès à un serveur, sauf si vous spécifiez l'option [-B]. Cela remplace la variable d'environnement IRCRC. Si cette option n'est pas spécifiée, et que la variable d'environnement IRCRC n'est pas définie, alors ~/.ircrc est le fichier de démarrage par
défaut.
-n nickna
me
Utilise le surnom spécifié comme surnom par défaut chaque fois que vous vous connectez à un serveur irc. Cette option remplace la variable d'environnement IRCNICK. Cette option peut être remplacée si vous spécifiez l'argument nickname sur la ligne de commande (voir ci-dessous)
.
-
o
Force l'utilisation des caractères termios IEXTEN. Les systèmes POSIX sont autorisés à réserver des caractères de contrôle supplémentaires pour effectuer des actions spéciales quand IEXTEN est activé. Sur 4.4BSD, les touches control-V et control-O sont utilisées par IEXTEN et ne peuvent donc pas être utilisées dans des liaisons de touches au sein d'EPIC puisque le terminal ne les envoie jamais à
EPIC.
-
O
Désactive l'utilisation des caractères termios IEXTEN. Cela rend toutes les touches réservées par l'option termios IEXTEN de votre système disponibles pour être utilisées dans des liaisons de touches. Sur 4.4BSD, ce drapeau est nécessaire si vous voulez utiliser control-V et control-O dans vos liaisons de
touches.
-p po
rt
Utilise le port spécifié comme port par défaut pour les nouvelles connexions au serveur. Le port par défaut est généralement 6667. Assurez-vous que les serveurs auxquels vous voulez vous connecter écoutent sur ce port avant d'essayer de vous y
connecter.
-
q
Supprime le chargement de tout fichier lorsque vous établissez premièrement une connexion à un serveur
irc.
-
v
Affiche les informations d'identification de version (VID) et se
termine.
-
x
Cette fonctionnalité non documentée active tous les drapeaux XDEBUG. Consultez les fichiers d'aide pour XDEBUG si vous voulez savoir ce qui se passe si vous utilisez
cela.
-z userna
me
Utilise le nom d'utilisateur spécifié lors de la négociation d'une connexion à un nouveau serveur irc. Cela remplace la variable d'environnement IRCUSER. Si cette option n'est pas spécifiée, alors le nom d'utilisateur spécifié dans /etc/passwd pour votre utilisateur est utilisé. Cette fonctionnalité était autrefois non documentée, mais avec la montée en popularité et l'utilisation de identd(8), cette option est bien moins utile qu'elle ne l'était. Les demandes pour avoir cette option supprimée seront probablement ignorées. Si vous ne voulez pas que vos utilisateurs usurpent leurs noms d'utilisateurs, installez identd, et rendez service à tout le monde sur
IRC.
nickna
me
Le premier mot seul trouvé est pris comme surnom par défaut à utiliser. Cela remplace toutes les autres options, y compris l'option -n et la variable d'environnement IRCNICK. Si tout le reste échoue, alors le client utilise votre nom de connexion comme surnom par
défaut.

DÉTAILLÉE

L'écran

:

L'écran est divisé en deux parties, séparées par une ligne d'état en vidéo inversée (si prise en charge). La partie supérieure (plus grande) de l'écran affiche les réponses du serveur ircd(8). La partie inférieure de l'écran (une seule ligne) accepte la saisie du

clavier.

Certains terminaux ne prennent pas en charge certaines fonctionnalités requises par epic , auquel cas vous recevez un message indiquant cela. Si cela se produit, essayez de changer le type de terminal ou exécutez epic avec l

'opti
on -d.

Commandes IRC

:

Toute ligne commençant par le caractère « / » est considérée comme une commande epic (le caractère de commande peut être changé). Toute ligne ne commençant pas par ce caractère est traitée comme un message à envoyer au canal actuel. Le client possède un sys

tème d'aide intégré. Installez les fichiers d'aide (ils devraient être disponibles au même e
ndroit où vous avez obtenu le client) puis tapez « /help » pour ouvrir le système d'aide.

Le fichier .ircrc

:

Quand epic est exécuté, il vérifie le répertoire personnel de l'utilisateur pour un fichier ~/.ircrc, exécutant les commandes du fichier. Les commandes dans ce fichier n

'ont pas besoin d'avoir un caractère slas
h « / » en début. Cela permet la prédéfiniti
on des alias et d'autres fonctionnalités.

D'AIDE

Démarrer le client est la partie facile. Une fois connecté, vous trouverez probablement que vous n'avez aucune idée de ce que vous faites. C'est là que les fichiers d'aide entrent en jeu. Si la personne qui maintient irc sur votre site n'a pas inst

allé les fichiers d'aide, harcelez-les jusqu'à ce qu'ils le fassent. Une fois les fichiers d'aide disponibles, utilisez la commande « /help » pour commencer. Il y a une tonne de commandes et une multitude de nuances qui prendront quelques mois pour
être maîtrisées. Mais une fois que vous le ferez, vous serez tellement fermement accro à irc que votre femme vous quittera, vos enfants vous abandonneront, votre chien s'enfira, et vous raterez toutes vos classes, et serez laissé à chanter les blues.

Tout logiciel non trivial a des bogues. ircII/EPIC ne fait pas exception. Vous pouvez consulter le fichier KNOWNBUGS qui est distribué avec le code source du client pour une liste des problèmes qui sont connus pour exister et qui peuvent ou non être corrigés un jour.
