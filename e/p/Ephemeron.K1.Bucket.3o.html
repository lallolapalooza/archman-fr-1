Module Bucket
: sig end

type ('k, 'd) t

Un bucket est une "liste" mutable d'éphémères.

val make : unit -> ('k, 'd) t

Crée un nouveau bucket.

val add : ('k, 'd) t -> 'k -> 'd -> unit

Ajoute un éphémère au bucket.

val remove : ('k, 'd) t -> 'k -> unit

remove b k supprime du bucket b l'éphémère le plus récemment ajouté avec la clé k , ou ne fait rien s'il n'y a pas d'éphémère correspondant.

val find : ('k, 'd) t -> 'k -> 'd option

Retourne la donnée de l'éphémère le plus récemment ajouté avec la clé donnée, ou None s'il n'y a pas d'éphémère correspondant.

val length : ('k, 'd) t -> int

Retourne une borne supérieure sur la longueur du bucket.

val clear : ('k, 'd) t -> unit

Supprime tous les éphémères du bucket.
