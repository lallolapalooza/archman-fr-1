EPLAIN(1) Manuel des commandes générales EPLAIN(1)

NOM

eplain - TeX brut étendu

SYNTAXE

eplain [ première-ligne ]

DESCRIPTION

eplain est une extension du TeX brut décrite initialement dans le livre TeX for nroff for the Impatient. Elle ajoute les fonctionnalités suivantes (entre autres) au TeX brut :

•
affichages justifiés à gauche
•
sortie sur deux colonnes
•
tables des matières
•
\hrule et \vrule avec une valeur par défaut différente de 0.4pt
•
heure de la journée
•
listage verbatim de fichier
•
notes de bas de page généralisées
•
boîtes blanches et noires
•
citations utilisant BibTeX

FICHIERS

eplain/doc/eplain.texi
Documentation TeXable des macros etex au format texinfo.
eplain.info*
Fichiers d'information GNU Emacs en ligne (info) produits à partir de eplain.texi.
