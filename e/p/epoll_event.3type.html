epoll_event(3type) epoll_event(3type)

NOM

epoll_event, epoll_data, epoll_data_t - événement epoll

BIBLIOTHÈQUE

Bibliothèque C standard (libc)

SYNTAXE

#include <sys/epoll.h>
struct epoll_event {
    uint32_t      events;  /* Événements Epoll */
    epoll_data_t  data;    /* Variable de données utilisateur */
};
union epoll_data {
    void     *ptr;
    int       fd;
    uint32_t  u32;
    uint64_t  u64;
};
typedef union epoll_data  epoll_data_t;

DESCRIPTION

La structure epoll_event spécifie les données que le noyau doit sauvegarder et retourner lorsque le descripteur de fichier correspondant devient prêt.

VERSIONS

Différences bibliothèque C/noyau

Les en-têtes du noyau Linux fournissent également ce type, avec une définition légèrement différente :


#include <linux/eventpoll.h>
struct epoll_event {
    __poll_t  events;
    __u64     data;
};

NORMES

Linux.

VOIR AUSSI

epoll_wait(2), epoll_ctl(2)
