epiphany(1) Manuel des commandes générales epiphany(1)

Nom

epiphany - Une vue simple, propre et belle du web

Syntaxe

epiphany [OPTION...] [URL...]

Description

epiphany est le nom de code de GNOME Web, le navigateur web conçu pour le bureau GNOME. Il offre une intégration GNOME de première classe, utilisant WebKitGTK pour le rendu web.

Options

--new-window

Ouvre une nouvelle fenêtre de navigateur au lieu d'un nouvel onglet

-l, --load-session=FICHIER

Charge le fichier d'état de session donné

-i, --incognito-mode

Démarre une instance avec des données utilisateur en lecture seule, pour naviguer sans enregistrer l'historique sur votre ordinateur

-p, --private-instance

Démarre une instance temporaire sans aucune donnée utilisateur, pour les tests

-a, --application-mode=NOMBASE

Démarre une instance privée en mode application web (nécessite de passer soit le nom de base du fichier de bureau, soit --profile)

--automation-mode

Démarre une instance privée pour le contrôle WebDriver

--profile=FICHIER

Démarre en utilisant un répertoire de profil personnalisé pour les données utilisateur

--search=TERME

Lance une recherche avec le terme de recherche donné

-?, --help

Affiche les options d'aide

--version

Affiche la version

Epiphany dispose d'un système d'aide complet. Lancez le navigateur et sélectionnez Aide dans le menu.
