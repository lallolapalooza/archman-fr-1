Éphémères avec une seule clé.

type ('k, 'd) t

un éphémère avec une seule clé

val make : 'k -> 'd -> ('k, 'd) t

Ephemeron.K1.make k d crée un éphémère avec la clé k et les données d.

val query : ('k, 'd) t -> 'k -> 'd option

Ephemeron.K1.query eph key retourne Some x (où x sont les données de l'éphémère) si key est physiquement égal à la clé de eph, et None si eph est vide ou si key n'est pas égal à la clé de eph.
