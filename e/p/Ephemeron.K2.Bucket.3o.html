Module Bucket
: sig fin

type ('k1, 'k2, 'd) t

Un seau est une « liste » mutable d'éphémères.

val make : unit -> ('k1, 'k2, 'd) t

Crée un nouveau seau.

val add : ('k1, 'k2, 'd) t -> 'k1 -> 'k2 -> 'd -> unit

Ajoute un éphémère au seau.

val remove : ('k1, 'k2, 'd) t -> 'k1 -> 'k2 -> unit

remove b k1 k2 supprime de b l'éphémère ajouté le plus récemment avec les clés k1 et k2 , ou ne fait rien s'il n'y a pas d'éphémère de ce type.

val find : ('k1, 'k2, 'd) t -> 'k1 -> 'k2 -> 'd option

Retourne les données de l'éphémère ajouté le plus récemment avec les clés données, ou None s'il n'y a pas d'éphémère de ce type.

val length : ('k1, 'k2, 'd) t -> int

Retourne une borne supérieure sur la longueur du seau.

val clear : ('k1, 'k2, 'd) t -> unit

Supprime tous les éphémères du seau.
