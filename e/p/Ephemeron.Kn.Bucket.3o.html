Module Bucket
: sig end

type ('k, 'd) t

Un seau est une « liste » mutable d'éphémères.

val make : unit -> ('k, 'd) t

Crée un nouveau seau.

val add : ('k, 'd) t -> 'k array -> 'd -> unit

Ajoute un éphémère au seau.

val remove : ('k, 'd) t -> 'k array -> unit

remove b k supprime de b l'éphémère ajouté le plus récemment avec les clés k, ou ne fait rien s'il n'y a pas d'éphémère de ce type.

val find : ('k, 'd) t -> 'k array -> 'd option

Retourne les données de l'éphémère ajouté le plus récemment avec les clés données, ou None s'il n'y a pas d'éphémère de ce type.

val length : ('k, 'd) t -> int

Retourne une borne supérieure sur la longueur du seau.

val clear : ('k, 'd) t -> unit

Supprime tous les éphémères du seau.
