EU-ELFCLASSIFY(1) Manuel des commandes générales EU-ELFCLASSIFY(1)

NOM

eu-elfclassify - Détermine le type d'un fichier ELF.

SYNTAXE

eu-elfclassify [--core]
[--debug-only]
[--elf]
[--elf-archive]
[--elf-file]
[--executable]
[--library]
[--linux-kernel-module]
[--loadable]
[--program]
[--shared]
[--unstripped]
[-f| --file]
[--no-stdin]
[--stdin]
[--stdin0]
[-z| --compressed]
[--matching]
[--no-print]
[--not-matching]
[--print]
[--print0]
[-q| --quiet]
[-v| --verbose]
[-?| --help]
[--usage]
[-V| --version] fichier_elf...

DESCRIPTION

eu-elfclassify identifie le but principal d'un type particulier de
fichier ELF ou de fichiers.

OPTIONS

Les formes longues et courtes des options, présentées ici comme alternatives, sont équivalentes. Toutes les options de classification doivent s'appliquer en même temps à un fichier particulier. Les options de classification peuvent être niées à l'aide d'un préfixe --not-.

Options de classification

--core
Le fichier est un fichier de vidage noyau ELF.
--debug-only
Le fichier est un fichier ELF uniquement pour le débogage (fichiers multiples .debug, .dwo ou dwz séparés).
--elf
Le fichier ressemble à un objet ELF ou à une archive/bibliothèque statique (par défaut).
--elf-archive
Le fichier est une archive ELF ou une bibliothèque statique.
--elf-file
Le fichier est un objet ELF régulier (pas une archive/bibliothèque statique).
--executable
Le fichier est (principalement) un exécutable de programme ELF (pas principalement un DS.O)
--library
Le fichier est un objet partagé ELF (DSO) (peut aussi être un exécutable).
--linux-kernel-module
Le fichier est un module du noyau Linux.
--loadable
Le fichier est un objet ELF chargeable (programme ou objet partagé).
--program
Le fichier est un exécutable de programme ELF (peut aussi être un DSO).
--shared
Le fichier est (principalement) un objet partagé ELF (DSO) (pas principalement un exécutable).
--unstripped
Le fichier est un fichier ELF avec une table de symboles ou des sections .debug_* et peut être dépouillé davantage.

Indicateurs d'entrée

-f
--file
Ne classifie que les fichiers réguliers (pas les liens symboliques ni les périphériques spéciaux).
--no-stdin
Ne lit pas les fichiers depuis l'entrée standard (par défaut).
--stdin
Lit également les noms de fichiers à traiter depuis l'entrée standard, séparés par des sauts de ligne.
--stdin0
Lit également les noms de fichiers à traiter depuis l'entrée standard, séparés par des octets NUL ASCII.
-z
--compressed
Essaie d'ouvrir des fichiers compressés ou des images ELF intégrées (noyau).

Indicateurs de sortie

--matching
Si des noms de fichiers sont imprimés, imprime les fichiers correspondants (par défaut).
--no-print
Ne produit pas de noms de fichiers.
--not-matching
Si des noms de fichiers sont imprimés, imprime les fichiers qui ne correspondent pas.
--print
Affiche les noms des fichiers, séparés par un saut de ligne.
--print0
Affiche les noms des fichiers, séparés par un NUL ASCII.

Indicateurs supplémentaires

-q
--quiet
Supprime certaines sorties d'erreur (l'inverse de --verbose).
-v
--verbose
Affiche des informations supplémentaires (peut être spécifié plusieurs fois).
-?
--help
Donne cette liste d'aide.
--usage
Donne un court message d'utilisation.
-V
--version
Affiche la version du programme.
