NOM

eutp - transfert de fichiers EuroBraille

SYNTAXE

eutp

DESCRIPTION

eutp vous permet d'échanger des fichiers avec un terminal Clio de EuroBraille.

OPTIONS DE LIGNE DE COMMANDE

Aucune pour le moment

VALEUR DE RETOUR

1 erreur

EXPANSIONS DE SHELL

Attention aux caractères spéciaux : * et . sont souvent développés par votre shell, donc sending files * fera probablement ce que vous attendez, en plaçant chaque fichier existant dans le répertoire courant sur le terminal, mais receiving files * pourrait ne pas faire ce que vous attendez : il ne récupérera que chaque fichier qui existe déjà dans le répertoire courant, en sautant ceux que vous venez de créer sur votre terminal ! Si vous voulez récupérer tous les fichiers qui existent dans le terminal, vous devriez utiliser '*' ou quelque chose de similaire (veuillez lire le manuel de votre shell).

Le même avertissement s'applique aux autres caractères spéciaux, tels que $, ~, &,... qui devraient être protégés en entourant les arguments de guillemets (') ou en utilisant des backslashes simples (\) juste avant eux (veuillez lire le manuel de votre shell).
