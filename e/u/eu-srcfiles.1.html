NOM

eu-srcfiles - Liste les fichiers source d'un fichier DWARF/ELF.

SYNTAXE

eu-srcfiles [-0|--null] [-c|--cu-only] [-v|--verbose] [-z|--zip] FICHIER_ENTRANT

DESCRIPTION

eu-srcfiles liste tous les fichiers source d'un fichier DWARF/ELF donné. Cette liste est basée sur une recherche des informations de débogage DWARF, qui peuvent être automatiquement récupérées par debuginfod si applicable. Le fichier cible peut être un exécutable, un vidage mémoire (coredump), un processus, ou même le noyau en cours d'exécution. L'entrée par défaut est le fichier 'a.out'. Les noms des fichiers source sont rendus uniques en leur préfixant le nom du chemin complet, puis imprimés sur la sortie standard. Les fichiers source peuvent être placés dans un fichier zip envoyé sur stdout.

Notez que toutes les occurrences de '/./' et '/../' dans le nom du chemin sont canonisées.

OPTIONS D'ENTRÉE

Les formes longues et courtes des options, présentées ici comme alternatives, sont équivalentes.

--core=FICHIER_VIDAGE
Trouve les adresses à partir des signatures trouvées dans FICHIER_VIDAGE.
--debuginfo-path=CHEMIN
Chemin de recherche pour les fichiers de débogage séparés.
-e FICHIER, --executable=FICHIER
Trouve les adresses dans FICHIER.
-k, --kernel
Trouve les adresses dans le noyau en cours d'exécution.
-K, --offline-kernel[=VERSION]
Noyau avec tous les modules.
-M FICHIER, --linux-process-map=FICHIER
Trouve les adresses dans les fichiers mappés lus depuis FICHIER au format Linux /proc/PID/maps.
-p PID, --pid=PID
Trouve les adresses dans les fichiers mappés dans le processus PID.
-?, --help
Donne cette liste d'aide.
--usage
Donne un court message d'utilisation.
-V, --version
Affiche la version du programme.

OPTIONS DE SORTIE

-0, --null
Sépare les éléments par un caractère nul au lieu d'un saut de ligne.
-b, --no-backup
Désactive la recherche locale de fichiers source lorsque debuginfod ne parvient pas à récupérer les fichiers. Cette option n'est applicable que lors de la récupération et de la compression des fichiers.
-c, --cu-only
Liste uniquement les noms des CU (unités de compilation).
-v, --verbose
Augmente la verbosité des messages de journalisation.
-z, --zip
Compresse tous les fichiers source et les envoie sur stdout. Par défaut, les fichiers seront automatiquement récupérés par debuginfod (si applicable) ou localement en secours. Aucun fichier source non trouvé ne sera archivé.

EXEMPLES

Lister tous les fichiers source d'un binaire. 


eu-srcfiles -e /bin/ls

Lister tous les noms d'unités de compilation (CU) pour un processus donné (y compris les bibliothèques partagées). 


eu-srcfiles -c -p $$

Lister les fichiers source d'un binaire basé sur son buildid, en utilisant debuginfod. 


binary=`debuginfod-find executable 9c22d8d9e42bd051ffdc1064fdfd456ba781c629`
eu-srcfiles -c -e $binary

Afficher le code source de la première CU d'une bibliothèque partagée. 


binary=/usr/lib64/libc.so.6
srcfile=`eu-srcfiles -c -e $binary | head -1`
cat `debuginfod-find source $binary $srcfile`

Lister les fichiers source d'une image noyau. 


eu-srcfiles -e /boot/vmlinuz-`uname -r`

Compresser tous les fichiers source d'un binaire. 


eu-srcfiles -z -e /bin/ls > ls.zip
