Description détaillée

Fonction ESAPI pour invoquer la commande TPM2_EvictControl soit en appel unique, soit de manière asynchrone.

Documentation des fonctions

TSS2_RC Esys_EvictControl (ESYS_CONTEXT * esysContext, ESYS_TR auth, ESYS_TR objectHandle, ESYS_TR shandle1, ESYS_TR shandle2, ESYS_TR shandle3, TPMI_DH_PERSISTENT persistentHandle, ESYS_TR * newObjectHandle)

Fonction à appel unique pour TPM2_EvictControl

Cette fonction invoque la commande TPM2_EvictControl dans une variante à appel unique. Cela signifie que la fonction se bloquera jusqu'à ce que la réponse du TPM soit disponible. Tous les paramètres d'entrée sont const. La mémoire pour les paramètres de sortie non simples est allouée par l'implémentation de la fonction.

Paramètres

esysContext Le ESYS_CONTEXT.
auth TPM2_RH_OWNER ou TPM2_RH_PLATFORM+{PP}.
objectHandle Le handle d'un objet chargé.
shandle1 Handle de session pour l'autorisation de auth
shandle2 Deuxième handle de session.
shandle3 Troisième handle de session.
persistentHandle Si objectHandle est un handle d'objet transitoire, alors ceci est le handle persistant de l'objet.
newObjectHandle Handle ESYS_TR de la ressource ESYS pour TPM2_HANDLE.

Valeurs de retour

TSS2_RC_SUCCESS si l'appel de fonction a réussi.
TSS2_ESYS_RC_BAD_REFERENCE si esysContext ou les pointeurs d'entrée requis ou les références de handle de sortie requis sont NULL.
TSS2_ESYS_RC_BAD_CONTEXT si une corruption d'esysContext est détectée.
TSS2_ESYS_RC_MEMORY si l'ESAPI ne peut pas allouer assez de mémoire pour les opérations internes ou les paramètres de retour.
TSS2_ESYS_RC_BAD_SEQUENCE si le contexte a déjà une opération asynchrone en attente.
TSS2_ESYS_RC_INSUFFICIENT_RESPONSE si la réponse du TPM ne contient pas au moins le tag, la longueur de la réponse et le code de réponse.
TSS2_ESYS_RC_MALFORMED_RESPONSE si la réponse du TPM est corrompue.
TSS2_ESYS_RC_RSP_AUTH_FAILED si le HMAC de réponse du TPM n'a pas pu être vérifié.
TSS2_ESYS_RC_MULTIPLE_DECRYPT_SESSIONS si plus d'une session a le bit d'attribut 'decrypt' défini.
TSS2_ESYS_RC_MULTIPLE_ENCRYPT_SESSIONS si plus d'une session a le bit d'attribut 'encrypt' défini.
TSS2_ESYS_RC_BAD_TR si l'un des objets ESYS_TR est inconnu du ESYS_CONTEXT ou est du mauvais type ou si les objets ESYS_TR requis sont ESYS_TR_NONE.
TSS2_ESYS_RC_NO_DECRYPT_PARAM si l'une des sessions a l'attribut 'decrypt' défini et que la commande ne supporte pas le chiffrement du premier paramètre de commande.
TSS2_ESYS_RC_NO_ENCRYPT_PARAM si l'une des sessions a l'attribut 'encrypt' défini et que la commande ne supporte pas le chiffrement du premier paramètre de réponse.
Les TSS2_RC produits par les couches inférieures de la pile logicielle peuvent être retournés à l'appelant inchangés, sauf s'ils sont traités en interne.

TSS2_RC Esys_EvictControl_Async (ESYS_CONTEXT * esysContext, ESYS_TR auth, ESYS_TR objectHandle, ESYS_TR shandle1, ESYS_TR shandle2, ESYS_TR shandle3, TPMI_DH_PERSISTENT persistentHandle)

Fonction asynchrone pour TPM2_EvictControl

Cette fonction invoque la commande TPM2_EvictControl dans une variante asynchrone. Cela signifie que la fonction retournera dès que la commande a été envoyée vers le bas dans la pile jusqu'au TPM. Tous les paramètres d'entrée sont const. Afin de récupérer la réponse du TPM, appelez Esys_EvictControl_Finish.

Paramètres

esysContext Le ESYS_CONTEXT.
auth TPM2_RH_OWNER ou TPM2_RH_PLATFORM+{PP}.
objectHandle Le handle d'un objet chargé.
shandle1 Handle de session pour l'autorisation de auth
shandle2 Deuxième handle de session.
shandle3 Troisième handle de session.
persistentHandle Si objectHandle est un handle d'objet transitoire, alors ceci est le handle persistant de l'objet.

Valeurs de retour

ESYS_RC_SUCCESS si l'appel de fonction a réussi.
TSS2_ESYS_RC_BAD_REFERENCE si esysContext ou les pointeurs d'entrée requis ou les références de handle de sortie requis sont NULL.
TSS2_ESYS_RC_BAD_CONTEXT si une corruption d'esysContext est détectée.
TSS2_ESYS_RC_MEMORY si l'ESAPI ne peut pas allouer assez de mémoire pour les opérations internes ou les paramètres de retour.
Les TSS2_RC produits par les couches inférieures de la pile logicielle peuvent être retournés à l'appelant inchangés, sauf s'ils sont traités en interne.
TSS2_ESYS_RC_MULTIPLE_DECRYPT_SESSIONS si plus d'une session a le bit d'attribut 'decrypt' défini.
TSS2_ESYS_RC_MULTIPLE_ENCRYPT_SESSIONS si plus d'une session a le bit d'attribut 'encrypt' défini.
TSS2_ESYS_RC_BAD_TR si l'un des objets ESYS_TR est inconnu du ESYS_CONTEXT ou est du mauvais type ou si les objets ESYS_TR requis sont ESYS_TR_NONE.
TSS2_ESYS_RC_NO_DECRYPT_PARAM si l'une des sessions a l'attribut 'decrypt' défini et que la commande ne supporte pas le chiffrement du premier paramètre de commande.
TSS2_ESYS_RC_NO_ENCRYPT_PARAM si l'une des sessions a l'attribut 'encrypt' défini et que la commande ne supporte pas le chiffrement du premier paramètre de réponse.

TSS2_RC Esys_EvictControl_Finish (ESYS_CONTEXT * esysContext, ESYS_TR * newObjectHandle)

Fonction de fin asynchrone pour TPM2_EvictControl

Cette fonction retourne les résultats d'une commande TPM2_EvictControl invoquée via Esys_EvictControl_Finish. Tous les paramètres de sortie non simples sont alloués par l'implémentation de la fonction. NULL peut être passé pour chaque paramètre de sortie si la valeur n'est pas requise.

Paramètres

esysContext Le ESYS_CONTEXT.
newObjectHandle Handle ESYS_TR de la ressource ESYS pour TPM2_HANDLE.

Valeurs de retour

TSS2_RC_SUCCESS en cas de succès
ESYS_RC_SUCCESS si l'appel de fonction a réussi.
TSS2_ESYS_RC_BAD_REFERENCE si esysContext ou les pointeurs d'entrée requis ou les références de handle de sortie requis sont NULL.
TSS2_ESYS_RC_BAD_CONTEXT si une corruption d'esysContextune corruption de texte est détectée.
TSS2_ESYS_RC_MEMORY si l'ESAPI ne peut pas allouer suffisamment de mémoire pour les opérations internes ou les paramètres de retour.
TSS2_ESYS_RC_BAD_SEQUENCE si le contexte a déjà une opération asynchrone en attente.
TSS2_ESYS_RC_TRY_AGAIN si le compteur de délai expire avant que la réponse du TPM soit reçue.
TSS2_ESYS_RC_INSUFFICIENT_RESPONSE si la réponse du TPM ne contient pas au moins la balise, la longueur de la réponse et le code de réponse.
TSS2_ESYS_RC_RSP_AUTH_FAILED si le HMAC de réponse du TPM n'a pas pu être vérifié.
TSS2_ESYS_RC_MALFORMED_RESPONSE si la réponse du TPM est corrompue.
TSS2_RCs produits par les couches inférieures de la pile logicielle peuvent être renvoyés à l'appelant sans modification, sauf s'ils sont traités en interne.
