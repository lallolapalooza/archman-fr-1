Fonction à appel unique pour TPM2_GetCommandAuditDiges

t

Cette fonction invoque la commande TPM2_GetCommandAuditDigest dans une variante à appel unique. Cela signifie que la fonction se bloquera jusqu'à ce que la réponse du TPM soit disponible. Tous les paramètres d'entrée sont const. La mémoire pour les paramètres de sortie non simples est allouée par l'implémentation de la

fonction.

Paramètre

s
esysContext Le ESYS_CONTEXT.
privacyHandle TPM2_Handle de l'administrateur de confidentialité (TPM2_RH_ENDORSEMENT).
signHandle Le handle de la clé de signature.
shandle1 Handle de session pour l'autorisation de privacyHandle
shandle2 Handle de session pour l'autorisation de signHandle
shandle3 Troisième handle de session.
qualifyingData Autres données à associer à ce résumé d'audit.
inScheme Schéma de signature TPM2_Signing à utiliser si le schéma pour signHandle est TPM2_ALG_NULL.
auditInfo Les auditInfo qui ont été signés. (alloué par l'appelant)
signature La signature sur auditInfo. (alloué par
l'appelant)

Valeurs de

retour
TSS2_RC_SUCCESS si l'appel de fonction a été un succès.
TSS2_ESYS_RC_BAD_REFERENCE si esysContext ou les pointeurs d'entrée requis ou les références de handle de sortie requis sont NULL.
TSS2_ESYS_RC_BAD_CONTEXT si une corruption de esysContext est détectée.
TSS2_ESYS_RC_MEMORY si l'ESAPI ne peut pas allouer suffisamment de mémoire pour les opérations internes ou les paramètres de retour.
TSS2_ESYS_RC_BAD_SEQUENCE si le contexte a déjà une opération asynchrone en attente.
TSS2_ESYS_RC_INSUFFICIENT_RESPONSE si la réponse du TPM ne contient pas au moins la balise, la longueur de la réponse et le code de réponse.
TSS2_ESYS_RC_MALFORMED_RESPONSE si la réponse du TPM est corrompue.
TSS2_ESYS_RC_RSP_AUTH_FAILED si le HMAC de réponse du TPM n'a pas pu être vérifié.
TSS2_ESYS_RC_MULTIPLE_DECRYPT_SESSIONS si plus d'une session a le bit d'attribut 'decrypt' défini.
TSS2_ESYS_RC_MULTIPLE_ENCRYPT_SESSIONS si plus d'une session a le bit d'attribut 'encrypt' défini.
TSS2_ESYS_RC_BAD_TR si l'un des objets ESYS_TR est inconnu de l'ESYS_CONTEXT ou est du mauvais type ou si les objets ESYS_TR requis sont ESYS_TR_NONE.
