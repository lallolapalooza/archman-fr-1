Fonction en appel unique pour

TPM2_StirRandom

Cette fonction invoque la commande TPM2_StirRandom dans une variante à appel unique. Cela signifie que la fonction se bloquera jusqu'à ce que la réponse du TPM soit disponible. Tous les paramètres d'entrée sont const. La mémoire pour les paramètres de sortie non simples est allouée par l'implémentation de la

fonction.

esysContext Le ESYS_CONTEXT.
shandle1 Premier handle de session.
shandle2 Deuxième handle de session.
shandle3 Troisième handle de session.
inData Informations supplémentaires

retour
TSS2_RC_SUCCESS si l'appel de fonction a été un succès.
TSS2_ESYS_RC_BAD_REFERENCE si esysContext ou les pointeurs d'entrée requis ou les références de handle de sortie requises sont NULL.
TSS2_ESYS_RC_BAD_CONTEXT si une corruption d'esysContext est détectée.
TSS2_ESYS_RC_MEMORY si l'ESAPI ne peut pas allouer assez de mémoire pour les opérations internes ou les paramètres de retour.
TSS2_ESYS_RC_BAD_SEQUENCE si le contexte a déjà une opération asynchrone en attente.

TSS2_ESYS_RC_MALFORMED_RESPONSE si la réponse du TPM est corrompue.
TSS2_ESYS_RC_RSP_AUTH_FAILED si le HMAC de réponse du TPM n'a pas pu être vérifié.

Fonction asynchrone pour

TPM2_StirRandom

Cette fonction invoque la commande TPM2_StirRandom dans une variante asynchrone. Cela signifie que la fonction retournera dès que la commande a été envoyée vers le bas dans la pile jusqu'au TPM. Tous les paramètres d'entrée sont const. Afin de récupérer la réponse du TPM, appelez Esys_StirRandom_Finish
