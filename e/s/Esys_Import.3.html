Description détaillée

Fonction ESAPI pour invoquer la commande TPM2_Import soit en appel unique, soit de manière asynchrone.

Documentation des fonctions

TSS2_RC Esys_Import (ESYS_CONTEXT * esysContext, ESYS_TR parentHandle, ESYS_TR shandle1, ESYS_TR shandle2, ESYS_TR shandle3, const TPM2B_DATA * encryptionKey, const TPM2B_PUBLIC * objectPublic, const TPM2B_PRIVATE * duplicate, const TPM2B_ENCRYPTED_SECRET * inSymSeed, const TPMT_SYM_DEF_OBJECT * symmetricAlg, TPM2B_PRIVATE ** outPrivate)

Fonction à appel unique pour TPM2_Import

Cette fonction invoque la commande TPM2_Import dans une variante à appel unique. Cela signifie que la fonction se bloquera jusqu'à ce que la réponse du TPM soit disponible. Tous les paramètres d'entrée sont const. La mémoire pour les paramètres de sortie non simples est allouée par l'implémentation de la fonction.

Paramètres

esysContext Le ESYS_CONTEXT.
parentHandle Le handle du nouveau parent pour l'objet.
shandle1 Handle de session pour l'autorisation de parentHandle
shandle2 Deuxième handle de session.
shandle3 Troisième handle de session.
encryptionKey La clé de chiffrement symétrique optionnelle utilisée comme enveloppe interne pour duplicate.
objectPublic La zone publique de l'objet à importer.
duplicate L'objet dupliqué chiffré symétriquement qui peut contenir une enveloppe symétrique interne.
inSymSeed La graine pour la clé symétrique et la clé HMAC.
symmetricAlg Définition de l'algorithme symétrique à utiliser pour l'enveloppe interne.
outPrivate La zone sensible chiffrée avec la clé symétrique de parentHandle. (allouée par l'appelant)

Valeurs de retour

TSS2_RC_SUCCESS si l'appel de fonction a été un succès.
TSS2_ESYS_RC_BAD_REFERENCE si esysContext ou les pointeurs d'entrée requis ou les références de handle de sortie requises sont NULL.
TSS2_ESYS_RC_BAD_CONTEXT si une corruption de esysContext est détectée.
TSS2_ESYS_RC_MEMORY si l'ESAPI ne peut pas allouer assez de mémoire pour les opérations internes ou les paramètres de retour.
TSS2_ESYS_RC_BAD_SEQUENCE si le contexte a déjà une opération asynchrone en attente.
TSS2_ESYS_RC_INSUFFICIENT_RESPONSE si la réponse du TPM ne contient pas au moins la balise, la longueur de la réponse et le code de réponse.
TSS2_ESYS_RC_MALFORMED_RESPONSE si la réponse du TPM est corrompue.
TSS2_ESYS_RC_RSP_AUTH_FAILED si le HMAC de réponse du TPM n'a pas pu être vérifié.
TSS2_ESYS_RC_MULTIPLE_DECRYPT_SESSIONS si plus d'une session a le bit d'attribut 'decrypt' défini.
TSS2_ESYS_RC_MULTIPLE_ENCRYPT_SESSIONS si plus d'une session a le bit d'attribut 'encrypt' défini.
TSS2_ESYS_RC_BAD_TR si l'un des objets ESYS_TR est inconnu du ESYS_CONTEXT ou est du mauvais type ou si les objets ESYS_TR requis sont ESYS_TR_NONE.
Les TSS2_RC produits par les couches inférieures de la pile logicielle peuvent être retournés à l'appelant inchangés, sauf s'ils sont gérés en interne.

TSS2_RC Esys_Import_Async (ESYS_CONTEXT * esysContext, ESYS_TR parentHandle, ESYS_TR shandle1, ESYS_TR shandle2, ESYS_TR shandle3, const TPM2B_DATA * encryptionKey, const TPM2B_PUBLIC * objectPublic, const TPM2B_PRIVATE * duplicate, const TPM2B_ENCRYPTED_SECRET * inSymSeed, const TPMT_SYM_DEF_OBJECT * symmetricAlg)

Fonction asynchrone pour TPM2_Import

Cette fonction invoque la commande TPM2_Import dans une variante asynchrone. Cela signifie que la fonction retournera dès que la commande a été envoyée vers le bas dans la pile jusqu'au TPM. Tous les paramètres d'entrée sont const. Afin de récupérer la réponse du TPM, appelez Esys_Import_Finish.

Paramètres

esysContext Le ESYS_CONTEXT.
parentHandle Le handle du nouveau parent pour l'objet.
shandle1 Handle de session pour l'autorisation de parentHandle
shandle2 Deuxième handle de session.
shandle3 Troisième handle de session.
encryptionKey La clé de chiffrement symétrique optionnelle utilisée comme enveloppe interne pour duplicate.
objectPublic La zone publique de l'objet à importer.
duplicate L'objet dupliqué chiffré symétriquement qui peut contenir une enveloppe symétrique interne.
inSymSeed La graine pour la clé symétrique et la clé HMAC.
symmetricAlg Définition de l'algorithme symétrique à utiliser pour l'enveloppe interne.

Valeurs de retour

ESYS_RC_SUCCESS si l'appel de fonction a été un succès.
TSS2_ESYS_RC_BAD_REFERENCE si esysContext ou les pointeurs d'entrée requis ou les références de handle de sortie requises sont NULL.
TSS2_ESYS_RC_BAD_CONTEXT si une corruption de esysContext est détectée.
TSS2_ESYS_RC_MEMORY si l'ESAPI ne peut pas allouer assez de mémoire pour les opérations internes ou les paramètres de retour.
Les TSS2_RC produits par les couches inférieures de la pile logicielle peuvent être retournés à l'appelant inchangés, sauf s'ils sont gérés en interne.
TSS2_ESYS_RC_MULTIPLE_DECRYPT_SESSIONS si plus d'une session a le bit d'attribut 'decrypt' défini.
TSS2_ESYS_RC_MULTIPLE_ENCRYPT_SESSIONS si plus d'une session a le bit d'attribut 'encrypt' défini.
TSS2_ESYS_RC_BAD_TR si l'un des objets ESYS_TR est inconnu du ESYS_CONTEXT ou est du mauvais type ou si les objets ESYS_TR requis sont ESYS_TR_NONE.

TSS2_RC Esys_Import_Finish (ESYS_CONTEXT * esysContext, TPM2B_PRIVATE ** outPrivate)

Fonction de fin asynchrone pour TPM2_Import

Cette fonction retourne les résultats d'une commande TPM2_Import invoquée via Esys_Import_Finish. Tous les paramètres de sortie non simples sont alloués par la fonction's implementation. NULL can be passed for every output parameter if the value is not required.

Paramètres

esysContext Le ESYS_CONTEXT.
outPrivate La zone sensible chiffrée avec la clé symétrique de parentHandle. (allouée par l'appelé)

Valeurs de retour

TSS2_RC_SUCCESS en cas de succès
ESYS_RC_SUCCESS si l'appel de fonction a réussi.
TSS2_ESYS_RC_BAD_REFERENCE si esysContext ou les pointeurs d'entrée requis ou les références de gestionnaire de sortie requises sont NULL.
TSS2_ESYS_RC_BAD_CONTEXT si une corruption d'esysContext est détectée.
TSS2_ESYS_RC_MEMORY si l'ESAPI ne peut pas allouer suffisamment de mémoire pour les opérations internes ou les paramètres de retour.
TSS2_ESYS_RC_BAD_SEQUENCE si le contexte a déjà une opération asynchrone en attente.
TSS2_ESYS_RC_TRY_AGAIN si le compteur de délai d'attente expire avant que la réponse du TPM ne soit reçue.
TSS2_ESYS_RC_INSUFFICIENT_RESPONSE si la réponse du TPM ne contient pas au moins le tag, la longueur de la réponse et le code de réponse.
TSS2_ESYS_RC_RSP_AUTH_FAILED si le HMAC de réponse du TPM n'a pas pu être vérifié.
TSS2_ESYS_RC_MALFORMED_RESPONSE si la réponse du TPM est corrompue.
TSS2_RCs produites par les couches inférieures de la pile logicielle peuvent être renvoyées à l'appelant sans modification, sauf si elles sont traitées en interne.
