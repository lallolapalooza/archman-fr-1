Fonction ESAPI pour invoquer la commande TPM2_GetTime soit en un seul appel, soit de manière asynchrone.

Documentation de la fonction

TSS2_RC Esys_GetTime (ESYS_CONTEXT * esysContext, ESYS_TR privacyAdminHandle, ESYS_TR signHandle, ESYS_TR shandle1, ESYS_TR shandle2, ESYS_TR shandle3, const TPM2B_DATA * qualifyingData, const TPMT_SIG_SCHEME * inScheme, TPM2B_ATTEST ** timeInfo, TPMT_SIGNATURE ** signature)

Fonction en un seul appel pour TPM2_GetTime

Cette fonction invoque la commande TPM2_GetTime dans une variante en un seul appel. Cela signifie que la fonction se bloquera jusqu'à ce que la réponse du TPM soit disponible. Tous les paramètres d'entrée sont const. La mémoire pour les paramètres de sortie non simples est allouée par l'implémentation de la fonction.

Paramètres

esysContext Le ESYS_CONTEXT.
privacyAdminHandle TPM2_Handle de l'administrateur de confidentialité (TPM2_RH_ENDORSEMENT).
signHandle L'identifiant keyHandle d'une clé chargée capable d'effectuer des signatures numériques.
shandle1 Poignée de session pour l'autorisation de privacyAdminHandle
shandle2 Poignée de session pour l'autorisation de signHandle
shandle3 Troisième poignée de session.
qualifyingData Données à horodater.
inScheme Schéma de signature TPM2 à utiliser si le schéma pour signHandle est TPM2_ALG_NULL.
timeInfo Bloc d'attestation standard généré par le TPM. (alloué par l'appelé)
signature La signature sur timeInfo . (alloué par l'appelé)

Valeurs de retour

TSS2_RC_SUCCESS si l'appel de fonction a réussi.
TSS2_ESYS_RC_BAD_REFERENCE si esysContext ou les pointeurs d'entrée requis ou les références de poignée de sortie requises sont NULL.
TSS2_ESYS_RC_BAD_CONTEXT si une corruption de esysContext est détectée.
TSS2_ESYS_RC_MEMORY si l'ESAPI ne peut pas allouer assez de mémoire pour les opérations internes ou les paramètres de retour.
TSS2_ESYS_RC_BAD_SEQUENCE si le contexte a déjà une opération asynchrone en attente.
TSS2_ESYS_RC_INSUFFICIENT_RESPONSE si la réponse du TPM ne contient pas au moins la balise, la longueur de la réponse et le code de réponse.
TSS2_ESYS_RC_MALFORMED_RESPONSE si la réponse du TPM est corrompue.
TSS2_ESYS_RC_RSP_AUTH_FAILED si le HMAC de réponse du TPM n'a pas pu être vérifié.
TSS2_ESYS_RC_MULTIPLE_DECRYPT_SESSIONS si plus d'une session a le bit d'attribut 'decrypt' défini.
TSS2_ESYS_RC_MULTIPLE_ENCRYPT_SESSIONS si plus d'une session a le bit d'attribut 'encrypt' défini.
TSS2_ESYS_RC_BAD_TR si l'un des objets ESYS_TR est inconnu du ESYS_CONTEXT ou est du mauvais type ou si les objets ESYS_TR requis sont ESYS_TR_NONE.
Les TSS2_RC produits par les couches inférieures de la pile logicielle peuvent être retournés à l'appelant inchangés, sauf s'ils sont gérés en interne.

Fonction asynchrone pour TPM2_GetTime

Cette fonction invoque la commande TPM2_GetTime dans une variante asynchrone. Cela signifie que la fonction retournera dès que la commande a été envoyée vers le bas dans la pile jusqu'au TPM. Tous les paramètres d'entrée sont const. Afin de récupérer la réponse du TPM, appelez Esys_GetTime_Finish.

Paramètres

esysContext Le ESYS_CONTEXT.
privacyAdminHandle TPM2_Handle de l'administrateur de confidentialité (TPM2_RH_ENDORSEMENT).
signHandle L'identifiant keyHandle d'une clé chargée capable d'effectuer des signatures numériques.
shandle1 Poignée de session pour l'autorisation de privacyAdminHandle
shandle2 Poignée de session pour l'autorisation de signHandle
shandle3 Troisième poignée de session.
qualifyingData Données à horodater.
inScheme Schéma de signature TPM2 à utiliser si le schéma pour signHandle est TPM2_ALG_NULL.

Valeurs de retour

ESYS_RC_SUCCESS si l'appel de fonction a réussi.
TSS2_ESYS_RC_BAD_REFERENCE si esysContext ou les pointeurs d'entrée requis ou les références de poignée de sortie requises sont NULL.
TSS2_ESYS_RC_BAD_CONTEXT si une corruption de esysContext est détectée.
TSS2_ESYS_RC_MEMORY si l'ESAPI ne peut pas allouer assez de mémoire pour les opérations internes ou les paramètres de retour.
Les TSS2_RC produits par les couches inférieures de la pile logicielle peuvent être retournés à l'appelant inchangés, sauf s'ils sont gérés en interne.
TSS2_ESYS_RC_MULTIPLE_DECRYPT_SESSIONS si plus d'une session a le bit d'attribut 'decrypt' défini.
TSS2_ESYS_RC_MULTIPLE_ENCRYPT_SESSIONS si plus d'une session a le bit d'attribut 'encrypt' défini.
TSS2_ESYS_RC_BAD_TR si l'un des objets ESYS_TR est inconnu du ESYS_CONTEXT ou est du mauvais type ou si les objets ESYS_TR requis sont ESYS_TR_NONE.

TSS2_RC Esys_GetTime_Finish (ESYS_CONTEXT * esysContext, TPM2B_ATTEST ** timeInfo, TPMT_SIGNATURE ** signature)

Fonction de finition asynchrone pour TPM2_GetTime

Cette fonction retourne les résultats d'une commande TPM2_GetTime invoquée via Esys_GetTime_Finish. Tous les paramètres de sortie non simples sont alloués par l'implémentation de la fonction. NULL peut être passé pour chaque paramètre de sortie si la valeur n'est pas requise.

Paramètres

esysContext Le ESYS_CONTEXT.
timeInfo Bloc d'attestation standard généré par le TPM. (alloué par l'appelé)
signature La signature sur timeInfo . (alloué par l'appelé)

Valeurs de retour

TSS2_RC_SUCCESS en cas de succès
ESYS_RC_SUCCESS si l'appel de fonction a réussi.
TSS2_ESYS_RC_BAD_REFERENCE si esysContext ou les pointeurs d'entrée requis ou les références de poignée de sortie requises sont NULL.
TSS2_ESYS_RC_BAD_CONTEXT si une corruption de esysContext est détectée.
TSS2_ESYS_RC_MEMORY si l'ESAPI ne peut pas allouer suffisamment de mémoire pour les opérations internes ou les paramètres de retour.
TSS2_ESYS_RC_BAD_SEQUENCE si le contexte a déjà une opération asynchrone en attente.
TSS2_ESYS_RC_TRY_AGAIN si le compteur de délai d'attente expire avant la réception de la réponse du TPM.
TSS2_ESYS_RC_INSUFFICIENT_RESPONSE si la réponse du TPM ne contient pas au moins la balise, la longueur de la réponse et le code de réponse.
TSS2_ESYS_RC_RSP_AUTH_FAILED si le HMAC de réponse du TPM n'a pas pu être vérifié.
TSS2_ESYS_RC_MALFORMED_RESPONSE si la réponse du TPM est corrompue.
TSS2_RCs produits par les couches inférieures de la pile logicielle peuvent être renvoyés à l'appelant sans modification, sauf s'ils sont traités en interne.
