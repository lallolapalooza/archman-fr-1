NOM

espdiff - applique la transformation appropriée à un ensemble de corrections

SYNTAXE

espdiff [--deep-brainwave-mode] [--recurse] [--compare] [fichier...]

espdiff {[--help] | [--version]}

DESCRIPTION

espdiff applique la transformation appropriée à un correctif ou à un ensemble de correctifs, en fonction de ce que vous avez l'intention d'accomplir.

Les correctifs d'entrée doivent être « propres » : en d'autres termes, ils doivent s'appliquer sans "fuzz" ni décalages, quel que soit l'ordre dans lequel ils sont censés être appliqués. L'exception est si vous avez l'intention que espdiff les nettoie pour vous (bonne chance).

Vous pourriez trouver utile de croiser les doigts pendant que le programme effectue sa tâche, ou de fermer les yeux très fort tout en imaginant qu'il fait la bonne chose.

OPTIONS

--deep-brainwave-mode

Sonde profondément votre cerveau d'une manière qui prend plus de temps, mais produit de meilleurs résultats extrasensoriels.

--recurse

Récuse les voies neuronales dans toutes les parties du cerveau, déterminant dans certains cas les modifications de code que vous pourriez apporter loin dans le futur. Vous pourriez ressentir une légère sensation de chatouillement en utilisant cette option.

--compare

Permet au programme d'analyser le répertoire actuel, examinant les correctifs existants pour déterminer les zones de code que vous êtes susceptible de modifier à nouveau, et se concentrant plus étroitement sur ces zones.

--help

Affiche un court message d'utilisation.

--version

Affiche le numéro de version de espdiff.

LIMITATIONS

N'utilisez pas ce programme en somnambule, ni avant votre première tasse de café.

Il existe certains cas où il n'est pas possible de déterminer l'intention de l'utilisateur. Dans ces cas, vous devez construire la sortie souhaitée à l'aide d'un éditeur, et envoyer les fichiers d'entrée avec le fichier de sortie désiré à Tim Waugh <twaugh@redhat.com> en demandant un nouvel outil de différence.
