Description détaillée

Fonction ESAPI pour invoquer la commande TPM2_PolicySecret soit en appel unique, soit de manière asynchrone.

Documentation des fonctions

TSS2_RC Esys_PolicySecret (ESYS_CONTEXT * esysContext, ESYS_TR authHandle, ESYS_TR policySession, ESYS_TR shandle1, ESYS_TR shandle2, ESYS_TR shandle3, const TPM2B_NONCE * nonceTPM, const TPM2B_DIGEST * cpHashA, const TPM2B_NONCE * policyRef, INT32 expiration, TPM2B_TIMEOUT ** timeout, TPMT_TK_AUTH ** policyTicket)

Fonction à appel unique pour TPM2_PolicySecret

Cette fonction invoque la commande TPM2_PolicySecret dans une variante à appel unique. Cela signifie que la fonction se bloquera jusqu'à ce que la réponse du TPM soit disponible. Tous les paramètres d'entrée sont const. La mémoire pour les paramètres de sortie non simples est allouée par l'implémentation de la fonction.

Paramètres

esysContext Le ESYS_CONTEXT.
authHandle Descripteur d'une entité fournissant l'autorisation.
policySession Descripteur de la session de politique étant étendue.
shandle1 Descripteur de session pour l'autorisation de authHandle
shandle2 Deuxième descripteur de session.
shandle3 Troisième descripteur de session.
nonceTPM Le nonce de politique pour la session.
cpHashA Empreinte des paramètres de commande auxquels cette autorisation est limitée.
policyRef Une référence à une politique relative à l'autorisation
•
peut être le Tampon Vide.

expiration Moment où l'autorisation expirera, mesuré en secondes à partir du moment où nonceTPM a été généré.
timeout Valeur de temps spécifique à l'implémentation utilisée pour indiquer au TPM quand le ticket expire ; ce ticket utilisera la structure tag TPMT_ST_AUTH_SECRET. (alloué par l'appelant)
policyTicket Produit si la commande réussit et si expiration dans la commande était non nul (Voir 23.2.5). (alloué par l'appelant)

Valeurs de retour

TSS2_RC_SUCCESS si l'appel de fonction a réussi.
TSS2_ESYS_RC_BAD_REFERENCE si esysContext ou les pointeurs d'entrée requis ou les références de descripteur de sortie requises sont NULL.
TSS2_ESYS_RC_BAD_CONTEXT si une corruption de esysContext est détectée.
TSS2_ESYS_RC_MEMORY si l'ESAPI ne peut pas allouer assez de mémoire pour les opérations internes ou les paramètres de retour.
TSS2_ESYS_RC_BAD_SEQUENCE si le contexte a déjà une opération asynchrone en attente.
TSS2_ESYS_RC_INSUFFICIENT_RESPONSE si la réponse du TPM ne contient pas au moins le tag, la longueur de la réponse et le code de réponse.
TSS2_ESYS_RC_MALFORMED_RESPONSE si la réponse du TPM est corrompue.
TSS2_ESYS_RC_RSP_AUTH_FAILED si le HMAC de réponse du TPM n'a pas pu être vérifié.
TSS2_ESYS_RC_MULTIPLE_DECRYPT_SESSIONS si plus d'une session a le bit d'attribut 'decrypt' défini.
TSS2_ESYS_RC_MULTIPLE_ENCRYPT_SESSIONS si plus d'une session a le bit d'attribut 'encrypt' défini.
TSS2_ESYS_RC_BAD_TR si l'un des objets ESYS_TR est inconnu du ESYS_CONTEXT ou est du mauvais type ou si les objets ESYS_TR requis sont ESYS_TR_NONE.
Les TSS2_RC produits par les couches inférieures de la pile logicielle peuvent être retournés à l'appelant sans modification, sauf s'ils sont gérés en interne.

Fonction asynchrone pour TPM2_PolicySecret

Cette fonction invoque la commande TPM2_PolicySecret dans une variante asynchrone. Cela signifie que la fonction retournera dès que la commande a été envoyée vers le bas dans la pile jusqu'au TPM. Tous les paramètres d'entrée sont const. Afin de récupérer la réponse du TPM, appelez Esys_PolicySecret_Finish.

shandle3 Troisième descripteur de session.
nonceTPM Le nonce de politique pour la session.
cpHashA Empreinte des paramètres de commande auxquels cette autorisation est limitée.
policyRef Une référence à une politique relative à l'autorisation
•
peut être le Tampon Vide.

expiration Moment où l'autorisation expirera, mesuré en secondes à partir du moment où nonceTPM a été généré.

Valeurs de retour

ESYS_RC_SUCCESS si l'appel de fonction a réussi.
TSS2_ESYS_RC_BAD_REFERENCE si esysContext ou les pointeurs d'entrée requis ou les références de descripteur de sortie requises sont NULL.
TSS2_ESYS_RC_BAD_CONTEXT si une corruption de esysContext est détectée.
TSS2_ESYS_RC_MEMORY si l'ESAPI ne peut pas allouer assez de mémoire pour les opérations internes ou les paramètres de retour.

Fonction de fin asynchrone pour TPM2_PolicySecret

Cette fonction retourne les résultats d'une commande TPM2_PolicySecret invoquée via Esys_PolicySecret_Finish. Tous les paramètres de sortie non simples sont alloués par l'implémentation de la fonction. NULL peut être passé pour chaque paramètre de sortie si la valeur n'est pas requise.

Paramètres

esysContext Le ESYS_CONTEXT.
timeout Valeur de temps spécifique à l'implémentation utilisée pour indiquer au TPM quand le ticket expire ; ce ticket utilisera la structure tag TPMT_ST_AUTH_SECRET. (alloué par l'appelant)
policyTicket Produit si la commande réussit et si l'expiration dans la commande était non nulle (voir 23.2.5). (alloué par l'appelant)

Valeurs de retour

TSS2_RC_SUCCESS en cas de succès
ESYS_RC_SUCCESS si l'appel de fonction a réussi.
TSS2_ESYS_RC_BAD_REFERENCE si esysContext ou les pointeurs d'entrée requis ou les références de gestion de sortie requises sont NULL.
TSS2_ESYS_RC_BAD_CONTEXT si une corruption de esysContext est détectée.
TSS2_ESYS_RC_MEMORY si l'ESAPI ne peut pas allouer assez de mémoire pour les opérations internes ou les paramètres de retour.
TSS2_ESYS_RC_BAD_SEQUENCE si le contexte a déjà une opération asynchrone en attente.
TSS2_ESYS_RC_TRY_AGAIN si le compteur d'expiration expire avant que la réponse du TPM soit reçue.
TSS2_ESYS_RC_INSUFFICIENT_RESPONSE si la réponse du TPM ne contient pas au moins le tag, la longueur de la réponse et le code de réponse.
TSS2_ESYS_RC_RSP_AUTH_FAILED si le HMAC de réponse du TPM n'a pas pu être vérifié.
TSS2_ESYS_RC_MALFORMED_RESPONSE si la réponse du TPM est corrompue.
TSS2_RCs produites par les couches inférieures de la pile logicielle peuvent être retournées à l'appelant sans modification, sauf si elles sont traitées en interne.
