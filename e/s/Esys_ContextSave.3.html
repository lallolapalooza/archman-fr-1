NOM

Esys_ContextSave - La fonction ESAPI pour la commande TPM2_ContextSave.

SYNOPSIS

Fonctions


TSS2_RC Esys_ContextSave_Async (ESYS_CONTEXT *esysContext, ESYS_TR saveHandle)

Description détaillée

Fonction ESAPI pour appeler la commande TPM2_ContextSave soit en un seul appel, soit de manière asynchrone.

Documentation des fonctions

TSS2_RC Esys_ContextSave (ESYS_CONTEXT * esysContext, ESYS_TR saveHandle, TPMS_CONTEXT ** context)

Fonction à appel unique pour TPM2_ContextSave

Cette fonction appelle la commande TPM2_ContextSave dans une variante à appel unique. Cela signifie que la fonction se bloquera jusqu'à ce que la réponse du TPM soit disponible. Tous les paramètres d'entrée sont const. La mémoire pour les paramètres de sortie non simples est allouée par l'implémentation de la fonction.

Paramètres

esysContext Le ESYS_CONTEXT.
saveHandle Descripteur de la ressource à sauvegarder.
context . (alloué par l'appelant)

Valeurs de retour

TSS2_RC_SUCCESS si l'appel de fonction a réussi.
TSS2_ESYS_RC_BAD_REFERENCE si esysContext ou les pointeurs d'entrée requis ou les références de descripteur de sortie requises sont NULL.
TSS2_ESYS_RC_BAD_CONTEXT si une corruption d'esysContext est détectée.
TSS2_ESYS_RC_MEMORY si l'ESAPI ne peut pas allouer suffisamment de mémoire pour les opérations internes ou les paramètres de retour.
TSS2_ESYS_RC_BAD_SEQUENCE si le contexte a déjà une opération asynchrone en attente.
TSS2_ESYS_RC_INSUFFICIENT_RESPONSE si la réponse du TPM ne contient pas au moins la balise, la longueur de la réponse et le code de réponse.
TSS2_ESYS_RC_MALFORMED_RESPONSE si la réponse du TPM est corrompue.
TSS2_ESYS_RC_RSP_AUTH_FAILED si le HMAC de réponse du TPM n'a pas pu être vérifié.
TSS2_ESYS_RC_BAD_TR si l'un des objets ESYS_TR est inconnu du ESYS_CONTEXT ou est du mauvais type, ou si les objets ESYS_TR requis sont ESYS_TR_NONE.
Les TSS2_RC produits par les couches inférieures de la pile logicielle peuvent être renvoyés à l'appelant sans modification, sauf s'ils sont traités en interne.

TSS2_RC Esys_ContextSave_Async (ESYS_CONTEXT * esysContext, ESYS_TR saveHandle)

Fonction asynchrone pour TPM2_ContextSave

Cette fonction appelle la commande TPM2_ContextSave dans une variante asynchrone. Cela signifie que la fonction retournera dès que la commande a été envoyée vers le bas dans la pile jusqu'au TPM. Tous les paramètres d'entrée sont const. Afin de récupérer la réponse du TPM, appelez Esys_ContextSave_Finish.

Paramètres

esysContext Le ESYS_CONTEXT.
saveHandle Descripteur de la ressource à sauvegarder.

Valeurs de retour

ESYS_RC_SUCCESS si l'appel de fonction a réussi.
TSS2_ESYS_RC_BAD_REFERENCE si esysContext ou les pointeurs d'entrée requis ou les références de descripteur de sortie requises sont NULL.
TSS2_ESYS_RC_BAD_CONTEXT si une corruption d'esysContext est détectée.
TSS2_ESYS_RC_MEMORY si l'ESAPI ne peut pas allouer suffisamment de mémoire pour les opérations internes ou les paramètres de retour.
Les TSS2_RC produits par les couches inférieures de la pile logicielle peuvent être renvoyés à l'appelant sans modification, sauf s'ils sont traités en interne.
TSS2_ESYS_RC_BAD_TR si l'un des objets ESYS_TR est inconnu du ESYS_CONTEXT ou est du mauvais type, ou si les objets ESYS_TR requis sont ESYS_TR_NONE.

TSS2_RC Esys_ContextSave_Finish (ESYS_CONTEXT * esysContext, TPMS_CONTEXT ** context)

Fonction de finition asynchrone pour TPM2_ContextSave

Cette fonction retourne les résultats d'une commande TPM2_ContextSave invoquée via Esys_ContextSave_Finish. Tous les paramètres de sortie non simples sont alloués par l'implémentation de la fonction. NULL peut être passé pour chaque paramètre de sortie si la valeur n'est pas requise.

Paramètres

esysContext Le ESYS_CONTEXT.
context . (alloué par l'appelant)

Valeurs de retour

TSS2_RC_SUCCESS en cas de succès
ESYS_RC_SUCCESS si l'appel de fonction a réussi.
TSS2_ESYS_RC_BAD_REFERENCE si esysContext ou les pointeurs d'entrée requis ou les références de descripteur de sortie requises sont NULL.
TSS2_ESYS_RC_BAD_CONTEXT si une corruption d'esysContext est détectée.
TSS2_ESYS_RC_MEMORY si l'ESAPI ne peut pas allouer suffisamment de mémoire pour les opérations internes ou les paramètres de retour.
TSS2_ESYS_RC_BAD_SEQUENCE si le contexte a déjà une opération asynchrone en attente.
TSS2_ESYS_RC_TRY_AGAIN si le compteur d'expiration dépasse le délai avant que la réponse du TPM ne soit reçue.
TSS2_ESYS_RC_INSUFFICIENT_RESPONSE si la réponse du TPM ne contient pas au moins la balise, la longueur de la réponse et le code de réponse.
TSS2_ESYS_RC_RSP_AUTH_FAILED si le HMAC de réponse du TPM n'a pas pu être vérifié.
TSS2_ESYS_RC_MALFORMED_RESPONSE si la réponse du TPM est corrompue.
Les TSS2_RC produits par les couches inférieures de la pile logicielle peuvent être renvoyés à l'appelant sans modification, sauf s'ils sont traités en interne.
