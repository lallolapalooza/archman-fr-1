Fonction d'appel unique pour

TPM2_Rewrap

Cette fonction invoque la commande TPM2_Rewrap dans une variante à appel unique. Cela signifie que la fonction se bloquera jusqu'à ce que la réponse du TPM soit disponible. Tous les paramètres d'entrée sont const. La mémoire pour les paramètres de sortie non simples est allouée par l'implémentation de la

fonction.

Paramètre

s
esysContext Le ESYS_CONTEXT.
oldParent Parent de l'objet.
newParent Nouveau parent de l'objet.
shandle1 Poignée de session pour l'autorisation de oldParent
shandle2 Deuxième poignée de session.
shandle3 Troisième poignée de session.
inDuplicate Un objet chiffré à l'aide d'une clé symétrique dérivée de inSymSeed.
name Le nom de l'objet qui est ré-encrypté.
inSymSeed La graine pour la clé symétrique et la clé HMAC.
outDuplicate Un objet chiffré à l'aide d'une clé symétrique dérivée de outSymSeed. (alloué par l'appelé)
outSymSeed Graine pour une clé symétrique protégée par la clé asymétrique newParent. (alloué par
l'appelé)

Valeurs de

retour
TSS2_RC_SUCCESS si l'appel de fonction a été un succès.
TSS2_ESYS_RC_BAD_REFERENCE si esysContext ou les pointeurs d'entrée requis ou les références de poignée de sortie requises sont NULL.
TSS2_ESYS_RC_BAD_CONTEXT si une corruption de esysContext est détectée.
TSS2_ESYS_RC_MEMORY si l'ESAPI ne peut pas allouer assez de mémoire pour les opérations internes ou les paramètres de retour.
TSS2_ESYS_RC_BAD_SEQUENCE si le contexte a déjà une opération asynchrone en attente.
TSS2_ESYS_RC_INSUFFICIENT_RESPONSE si la réponse du TPM ne contient pas au moins la balise, la longueur de la réponse et le code de réponse.
TSS2_ESYS_RC_MALFORMED_RESPONSE si la réponse du TPM est corrompue.
TSS2_ESYS_RC_RSP_AUTH_FAILED si le HMAC de réponse du TPM n'a pas pu être vérifié.
TSS2_ESYS_RC_MULTIPLE_DECRYPT_SESSIONS si plus d'une session a le bit d'attribut 'decrypt' défini.
TSS2_ESYS_RC_MULTIPLE_ENCRYPT_SESSIONS si plus d'une session a le bit d'attribut 'encrypt' défini.
TSS2_ESYS_RC_BAD_TR si l'un des objets ESYS_TR est inconnu de ESYS_CONTEXT ou est du mauvais type ou si les objets ESYS_TR requis sont ESYS_TR_NONE.

Fonction de finition asynchrone pour

Cette fonction retourne les résultats d'une commande TPM2_Rewrap invoquée via Esys_Rewrap_Finish. Tous les paramètres de sortie non simples sont alloués par l'implémentation de la fonction. NULL peut être passé pour chaque paramètre de sortie si la valeur n'est pas
