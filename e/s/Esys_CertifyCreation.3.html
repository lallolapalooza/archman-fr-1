Fonction ESAPI pour invoquer la commande TPM2_CertifyCreation soit en appel unique, soit de manière asynchrone.

Documentation des fonctions

Fonction en appel unique pour TPM2_CertifyCreation

Cette fonction invoque la commande TPM2_CertifyCreation dans une variante en appel unique. Cela signifie que la fonction se bloquera jusqu'à ce que la réponse du TPM soit disponible. Tous les paramètres d'entrée sont const. La mémoire pour les paramètres de sortie non simples est allouée par l'implémentation de la fonction.

Paramètres

esysContext Le ESYS_CONTEXT.
signHandle Poignée de la clé qui signera le bloc d'attestation.
objectHandle L'objet associé aux données de création.
shandle1 Poignée de session pour l'autorisation de signHandle
shandle2 Deuxième poignée de session.
shandle3 Troisième poignée de session.
qualifyingData Données de qualification fournies par l'utilisateur.
creationHash Empreinte des données de création produites par TPM2_Create() ou TPM2_CreatePrimary().
inScheme Schéma de signature TPM2_Signing à utiliser si le schéma pour signHandle est TPM2_ALG_NULL.
creationTicket Ticket produit par TPM2_Create() ou TPM2_CreatePrimary().
certifyInfo La structure qui a été signée. (allouée par l'appelant)
signature La signature sur certifyInfo . (allouée par l'appelant)

Valeurs de retour

TSS2_RC_SUCCESS si l'appel de fonction a été un succès.
TSS2_ESYS_RC_BAD_REFERENCE si esysContext ou les pointeurs d'entrée requis ou les références de poignée de sortie requises sont NULL.
TSS2_ESYS_RC_BAD_CONTEXT si une corruption de esysContext est détectée.
TSS2_ESYS_RC_MEMORY si l'ESAPI ne peut pas allouer assez de mémoire pour les opérations internes ou les paramètres de retour.
TSS2_ESYS_RC_BAD_SEQUENCE si le contexte a déjà une opération asynchrone en attente.
TSS2_ESYS_RC_INSUFFICIENT_RESPONSE si la réponse du TPM ne contient pas au moins la balise, la longueur de la réponse et le code de réponse.
TSS2_ESYS_RC_MALFORMED_RESPONSE si la réponse du TPM est corrompue.
TSS2_ESYS_RC_RSP_AUTH_FAILED si le HMAC de réponse du TPM n'a pas pu être vérifié.
TSS2_ESYS_RC_MULTIPLE_DECRYPT_SESSIONS si plus d'une session a le bit d'attribut 'decrypt' défini.
TSS2_ESYS_RC_MULTIPLE_ENCRYPT_SESSIONS si plus d'une session a le bit d'attribut 'encrypt' défini.
TSS2_ESYS_RC_BAD_TR si l'un des objets ESYS_TR est inconnu du ESYS_CONTEXT ou est du mauvais type ou si des objets ESYS_TR requis sont ESYS_TR_NONE.
Les TSS2_RC produits par les couches inférieures de la pile logicielle peuvent être retournés à l'appelant inchangés, sauf s'ils sont gérés en interne.

Fonction asynchrone pour TPM2_CertifyCreation

Cette fonction invoque la commande TPM2_CertifyCreation dans une variante asynchrone. Cela signifie que la fonction retournera dès que la commande a été envoyée vers le bas dans la pile jusqu'au TPM. Tous les paramètres d'entrée sont const. Afin de récupérer la réponse du TPM, appelez Esys_CertifyCreation_Finish.

inScheme Schéma de signature TPM2_Signing à utiliser si le schéma pour signHandle est TPM2_ALG_NULL.
creationTicket Ticket produit par TPM2_Create() ou TPM2_CreatePrimary().

Valeurs de retour

ESYS_RC_SUCCESS si l'appel de fonction a été un succès.
TSS2_ESYS_RC_BAD_REFERENCE si esysContext ou les pointeurs d'entrée requis ou les références de poignée de sortie requises sont NULL.
TSS2_ESYS_RC_BAD_CONTEXT si une corruption de esysContext est détectée.
TSS2_ESYS_RC_MEMORY si l'ESAPI ne peut pas allouer assez de mémoire pour les opérations internes ou les paramètres de retour.

TSS2_RC Esys_CertifyCreation_Finish (ESYS_CONTEXT * esysContext, TPM2B_ATTEST ** certifyInfo, TPMT_SIGNATURE ** signature)

Fonction de fin asynchrone pour TPM2_CertifyCreation

Cette fonction retourne les résultats d'une commande TPM2_CertifyCreation invoquée via Esys_CertifyCreation_Finish. Tous les paramètres de sortie non simples sont alloués par l'implémentation de la fonction. NULL peut être passé pour chaque paramètre de sortie si la valeur n'est pas requise.

Paramètres

esysContext Le ESYS_CONTEXT.
certifyInfo La structure qui a été signée. (alloué par l'appelant)
signature La signature sur certifyInfo . (alloué par l'appelant)

Valeurs de retour

TSS2_RC_SUCCESS en cas de succès
ESYS_RC_SUCCESS si l'appel de fonction a réussi.
TSS2_ESYS_RC_BAD_REFERENCE si esysContext ou les pointeurs d'entrée requis ou les références de gestionnaire de sortie requises sont NULL.
TSS2_ESYS_RC_BAD_CONTEXT si une corruption de esysContext est détectée.
TSS2_ESYS_RC_MEMORY si l'ESAPI ne peut pas allouer suffisamment de mémoire pour les opérations internes ou les paramètres de retour.
TSS2_ESYS_RC_BAD_SEQUENCE si le contexte a déjà une opération asynchrone en attente.
TSS2_ESYS_RC_TRY_AGAIN si le compteur d'expiration expire avant que la réponse du TPM ne soit reçue.
TSS2_ESYS_RC_INSUFFICIENT_RESPONSE si la réponse du TPM ne contient pas au moins la balise, la longueur de la réponse et le code de réponse.
TSS2_ESYS_RC_RSP_AUTH_FAILED si le HMAC de réponse du TPM n'a pas pu être vérifié.
TSS2_ESYS_RC_MALFORMED_RESPONSE si la réponse du TPM est corrompue.
TSS2_RCs produites par les couches inférieures de la pile logicielle peuvent être retournées à l'appelant sans modification, sauf si elles sont traitées en interne.
