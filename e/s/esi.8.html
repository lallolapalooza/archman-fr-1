ESI(8) Commandes de maintenance ESI(8)

NOM

esi - obtenir ou définir l'identifiant de système terminal (ESI)

SYNTAXE

esi [itf]
esi [-f] esi [itf]
esi -V

DESCRIPTION

esi est utilisé pour afficher ou définir l'identifiant de système terminal (ESI, un numéro unique de six octets correspondant à l'adresse MAC des technologies LAN comme Ethernet) d'une interface ATM. Si le numéro d'interface itf est omis, l'interface 0 est utilisée par défaut. L'argument esi est une chaîne de douze chiffres hexadécimaux.

Seul l'ESI stocké dans le noyau est accédé ; esi ne modifie pas l'ESI stocké sur la carte réseau. Si un ESI non nul est déjà défini sur une interface, l'option -f doit être utilisée pour le remplacer.

Notez que les changements d'ESI ne sont pas automatiquement propagés dans tout le système, par exemple à ilmid. esi devrait donc être utilisé tôt lors de l'initialisation du système.

OPTIONS

-f
forcer le remplacement d'un ESI existant.
-V
afficher le numéro de version de esi sur la sortie standard et quitter.
