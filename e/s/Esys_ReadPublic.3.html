Esys_ReadPublic - La fonction ESAPI pour la commande TPM2_ReadPublic.

SYNOPSIS

Description détaillée

Fonction ESAPI pour invoquer la commande TPM2_ReadPublic soit en un seul appel, soit de manière asynchrone.

Documentation des fonctions

TSS2_RC Esys_ReadPublic (ESYS_CONTEXT * esysContext, ESYS_TR objectHandle, ESYS_TR shandle1, ESYS_TR shandle2, ESYS_TR shandle3, TPM2B_PUBLIC ** outPublic, TPM2B_NAME ** name, TPM2B_NAME ** qualifiedName)

Fonction en un seul appel pour TPM2_ReadPublic

Cette fonction invoque la commande TPM2_ReadPublic dans une variante en un seul appel. Cela signifie que la fonction se bloquera jusqu'à ce que la réponse du TPM soit disponible. Tous les paramètres d'entrée sont const. La mémoire pour les paramètres de sortie non simples est allouée par l'implémentation de la fonction.

Paramètres

esysContext Le ESYS_CONTEXT.
objectHandle Poignée TPM d'un objet.
shandle1 Première poignée de session.
shandle2 Deuxième poignée de session.
shandle3 Troisième poignée de session.
outPublic Structure contenant la zone publique d'un objet. (allouée par l'appelant)
name Nom de l'objet. (allouée par l'appelant)
qualifiedName Le Qualified Name de l'objet. (allouée par l'appelant)

Valeurs de retour

TSS2_RC_SUCCESS si l'appel de fonction a réussi.
TSS2_ESYS_RC_BAD_REFERENCE si esysContext ou les pointeurs d'entrée requis ou les références de poignées de sortie requises sont NULL.
TSS2_ESYS_RC_BAD_CONTEXT si une corruption d'esysContext est détectée.
TSS2_ESYS_RC_MEMORY si l'ESAPI ne peut pas allouer assez de mémoire pour les opérations internes ou les paramètres de retour.
TSS2_ESYS_RC_BAD_SEQUENCE si le contexte a déjà une opération asynchrone en attente.
TSS2_ESYS_RC_INSUFFICIENT_RESPONSE si la réponse du TPM ne contient pas au moins le tag, la longueur de la réponse et le code de réponse.
TSS2_ESYS_RC_MALFORMED_RESPONSE si la réponse du TPM est corrompue.
TSS2_ESYS_RC_RSP_AUTH_FAILED si le HMAC de réponse du TPM n'a pas pu être vérifié.
TSS2_ESYS_RC_MULTIPLE_DECRYPT_SESSIONS si plus d'une session a le bit d'attribut 'decrypt' défini.
TSS2_ESYS_RC_MULTIPLE_ENCRYPT_SESSIONS si plus d'une session a le bit d'attribut 'encrypt' défini.
TSS2_ESYS_RC_BAD_TR si l'un des objets ESYS_TR est inconnu du ESYS_CONTEXT ou est du mauvais type ou si les objets ESYS_TR requis sont ESYS_TR_NONE.
TSS2_ESYS_RC_NO_DECRYPT_PARAM si l'une des sessions a l'attribut 'decrypt' défini et que la commande ne supporte pas le chiffrement du premier paramètre de commande.
Les TSS2_RC produits par les couches inférieures de la pile logicielle peuvent être retournés à l'appelant sans modification, sauf s'ils sont traités en interne.

TSS2_RC Esys_ReadPublic_Async (ESYS_CONTEXT * esysContext, ESYS_TR objectHandle, ESYS_TR shandle1, ESYS_TR shandle2, ESYS_TR shandle3)

Fonction asynchrone pour TPM2_ReadPublic

Cette fonction invoque la commande TPM2_ReadPublic dans une variante asynchrone. Cela signifie que la fonction retournera dès que la commande a été envoyée vers le bas dans la pile jusqu'au TPM. Tous les paramètres d'entrée sont const. Afin de récupérer la réponse du TPM, appelez Esys_ReadPublic_Finish.

Paramètres

esysContext Le ESYS_CONTEXT.
objectHandle Poignée TPM d'un objet.
shandle1 Première poignée de session.
shandle2 Deuxième poignée de session.
shandle3 Troisième poignée de session.

Valeurs de retour

ESYS_RC_SUCCESS si l'appel de fonction a réussi.
TSS2_ESYS_RC_BAD_REFERENCE si esysContext ou les pointeurs d'entrée requis ou les références de poignées de sortie requises sont NULL.
TSS2_ESYS_RC_BAD_CONTEXT si une corruption d'esysContext est détectée.
TSS2_ESYS_RC_MEMORY si l'ESAPI ne peut pas allouer assez de mémoire pour les opérations internes ou les paramètres de retour.
Les TSS2_RC produits par les couches inférieures de la pile logicielle peuvent être retournés à l'appelant sans modification, sauf s'ils sont traités en interne.
TSS2_ESYS_RC_MULTIPLE_DECRYPT_SESSIONS si plus d'une session a le bit d'attribut 'decrypt' défini.
TSS2_ESYS_RC_MULTIPLE_ENCRYPT_SESSIONS si plus d'une session a le bit d'attribut 'encrypt' défini.
TSS2_ESYS_RC_BAD_TR si l'un des objets ESYS_TR est inconnu du ESYS_CONTEXT ou est du mauvais type ou si les objets ESYS_TR requis sont ESYS_TR_NONE.
TSS2_ESYS_RC_NO_DECRYPT_PARAM si l'une des sessions a l'attribut 'decrypt' défini et que la commande ne supporte pas le chiffrement du premier paramètre de commande.

TSS2_RC Esys_ReadPublic_Finish (ESYS_CONTEXT * esysContext, TPM2B_PUBLIC ** outPublic, TPM2B_NAME ** name, TPM2B_NAME ** qualifiedName)

Fonction de fin asynchrone pour TPM2_ReadPublic

Cette fonction retourne les résultats d'une commande TPM2_ReadPublic invoquée via Esys_ReadPublic_Finish. Tous les paramètres de sortie non simples sont alloués par l'implémentation de la fonction. NULL peut être passé pour chaque paramètre de sortie si la valeur n'est pas requise.

Paramètres

esysContext Le ESYS_CONTEXT.
outPublic Structure contenant la zone publique d'un objet. (allouée par l'appelant)
name Nom de l'objet. (allouée par l'appelant)
qualifiedName Le Qualified Name de l'objet. (allouée par l'appelant)

Valeurs de retour

TSS2_RC_SUCCESS en cas de succès
ESYS_RC_SUCCESS si l'appel de fonction a réussi.
TSS2_ESYS_RC_BAD_REFERENCE si esysContext ou les pointeurs d'entrée requis ou les références de poignées de sortie requises sont NULL.
TSS2_ESYS_RC_BAD_CONTEXT si une corruption d'esysContext est détectée.
TSS2_ESYS_RC_MEMORY si l'ESAPI ne peut pas allouer assez de mémoire pour les opérations internes ou les paramètres de retour.
TSS2_ESYS_RC_BAD_SEQUENCE si le contexte a déjà une opération asynchrone en attente.
TSS2_ESYS_RC_TRY_AGAIN si le compteur d'expiration du délai d'attente expire avant que la réponse du TPM ne soit reçue.
TSS2_ESYS_RC_INSUFFICIENT_RESPONSE si la réponse du TPM ne contient pas au moins le tag, la longueur de la réponse et le code de réponse.
TSS2_ESYS_RC_RSP_AUTH_FAILED si le HMAC de réponse du TPM n'a pas pu être vérifié.
TSS2_ESYS_RC_MALFORMED_RESPONSE si la réponse du TPM est corrompue.
Les TSS2_RC produits par les couches inférieures de la pile logicielleay be returned to the caller unaltered unless handled internally.
