ES256_PK_NEW(3) Manuel des fonctions de bibliothèque ES256_PK_NEW(3)

NOM

es256_pk_new, es256_pk_free, es256_pk_from_EC_KEY, es256_pk_from_EVP_PKEY, es256_pk_from_ptr, es256_pk_to_EVP_PKEY — API FIDO2 COSE ES256

SYNOPSIS

#include <openssl/ec.h>
#include <fido/es256.h>

es256_pk_t *
es256_pk_new(void);

void
es256_pk_free(es256_pk_t **pkp);

int
es256_pk_from_EC_KEY(es256_pk_t *pk, const EC_KEY *ec);

int
es256_pk_from_EVP_PKEY(es256_pk_t *pk, const EVP_PKEY *pkey);

int
es256_pk_from_ptr(es256_pk_t *pk, const void *ptr, size_t len);

EVP_PKEY *
es256_pk_to_EVP_PKEY(const es256_pk_t *pk);

DESCRIPTION

ES256 est le nom donné dans la RFC CBOR Object Signing and Encryption (COSE) pour ECDSA sur P-256 avec SHA-256. L'API COSE ES256 de libfido2 est une API auxiliaire avec des routines pour convertir entre les différents types de clés publiques ECDSA utilisés dans libfido2 et OpenSSL.

Dans libfido2, les clés publiques ES256 sont abstraites par le type es256_pk_t.

La fonction es256_pk_new() retourne un pointeur vers un type es256_pk_t nouvellement alloué et vide. Si la mémoire ne peut pas être allouée, NULL est retourné.

La fonction es256_pk_free() libère la mémoire sous-jacente de *pkp, où *pkp doit avoir été précédemment alloué par es256_pk_new(). Au retour, *pkp est défini à NULL. Soit pkp, soit *pkp peut être NULL, auquel cas es256_pk_free() est une opération nulle (NOP).

La fonction es256_pk_from_EC_KEY() remplit pk avec le contenu de ec. Aucune référence à ec n'est conservée.

La fonction es256_pk_from_EVP_PKEY() remplit pk avec le contenu de pkey. Aucune référence à pkey n'est conservée.

La fonction es256_pk_from_ptr() remplit pk avec le contenu de ptr, où ptr pointe vers len octets. Le pointeur ptr peut pointer vers un point non compressé, ou vers la concaténation des coordonnées x et y. Aucune référence à ptr n'est conservée.

La fonction es256_pk_to_EVP_PKEY() convertit pk en un type EVP_PKEY nouvellement alloué avec un compteur de références de 1. Aucune référence interne au pointeur retourné n'est conservée. En cas d'erreur, es256_pk_to_EVP_PKEY() retourne NULL.

VALEURS DE RETOUR

Les fonctions es256_pk_from_EC_KEY(), es256_pk_from_EVP_PKEY(), et es256_pk_from_ptr() retournent FIDO_OK en cas de succès. En cas d'erreur, un code d'erreur différent défini dans <fido/err.h> est retourné.
