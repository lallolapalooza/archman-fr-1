Fonction d'appel unique pour TPM2_CreatePrimar

y

Cette fonction invoque la commande TPM2_CreatePrimary dans une variante à appel unique. Cela signifie que la fonction se bloquera jusqu'à ce que la réponse du TPM soit disponible. Tous les paramètres d'entrée sont const. La mémoire pour les paramètres de sortie non simples est allouée par l'implémentation de la

fonction.

Paramètre

s
esysContext Le ESYS_CONTEXT.
primaryHandle TPM2_RH_ENDORSEMENT, TPM2_RH_OWNER, TPM2_RH_PLATFORM+{PP}, ou TPM2_RH_NULL.
shandle1 Poignée de session pour l'autorisation de primaryHandle
shandle2 Deuxième poignée de session.
shandle3 Troisième poignée de session.
inSensitive Les données sensibles, voir TPM 2.0 Part 1 Sensitive Values.
inPublic Le modèle public.
outsideInfo Données qui seront incluses dans les données de création pour cet objet afin de fournir une liaison permanente et vérifiable entre cet objet et certaines données du propriétaire de l'objet.
creationPCR Les PCR qui seront utilisés dans les données de création.
outPublic La partie publique de l'objet créé. (alloué par l'appelant)
creationData Contient un TPMT_CREATION_DATA. (alloué par l'appelant)
creationHash Empreinte de creationData utilisant nameAlg de outPublic. (alloué par l'appelant)
creationTicket Ticket utilisé par TPM2_CertifyCreation() pour valider que les données de création ont été produites par le TPM. (alloué par l'appelant)
objectHandle Poignée ESYS_TR de la ressource ESYS pour
TPM2_HANDLE.

Valeurs de

retour
TSS2_RC_SUCCESS si l'appel de fonction a été un succès.
TSS2_ESYS_RC_BAD_REFERENCE si esysContext ou les pointeurs d'entrée requis ou les références de poignée de sortie requises sont NULL.
TSS2_ESYS_RC_BAD_CONTEXT si une corruption de esysContext est détectée.
TSS2_ESYS_RC_MEMORY si l'ESAPI ne peut pas allouer assez de mémoire pour les opérations internes ou les paramètres de retour.
TSS2_ESYS_RC_BAD_SEQUENCE si le contexte a déjà une opération asynchrone en attente.
TSS2_ESYS_RC_INSUFFICIENT_RESPONSE si la réponse du TPM ne contient pas au moins la balise, la longueur de la réponse et le code de réponse.
TSS2_ESYS_RC_MALFORMED_RESPONSE si la réponse du TPM est corrompue.
TSS2_ESYS_RC_RSP_AUTH_FAILED si le HMAC de réponse du TPM n'a pas pu être vérifié.
TSS2_ESYS_RC_MULTIPLE_DECRYPT_SESSIONS si plus d'une session a le bit d'attribut 'decrypt' défini.
TSS2_ESYS_RC_MULTIPLE_ENCRYPT_SESSIONS si plus d'une session a le bit d'attribut 'encrypt' défini.
TSS2_ESYS_RC_BAD_TR si l'un des objets ESYS_TR est inconnu du ESYS_CONTEXT ou est du mauvais type ou si les objets ESYS_TR requis sont ESYS_TR_NONE.
Les TSS2_RC produits par les couches inférieures de la pile logicielle peuvent ê
tre retournés à l'appelant sans modifica
tion, sauf s'ils sont gérés en interne.

Fonction asynchrone pour TPM2_CreatePrimar

y

Cette fonction invoque la commande TPM2_CreatePrimary dans une variante asynchrone. Cela signifie que la fonction retournera dès que la commande a été envoyée vers le bas dans la pile jusqu'au TPM. Tous les paramètres d'entrée sont const. Afin de récupérer la réponse du TPM, appelez Esys_CreatePrimary_Finish

.

création.

Fonction d'achèvement asynchrone pour TPM2_CreatePrimar

y

Cette fonction retourne les résultats d'une commande TPM2_CreatePrimary invoquée via Esys_CreatePrimary_Finish. Tous les paramètres de sortie non simples sont alloués par l'implémentation de la fonction. NULL peut être passé pour chaque paramètre de sortie si la valeur n'est pas

requise.

Paramètre

s
esysContext Le ESYS_CONTEXT.
outPublic La partie publique de l'objet créé. (alloué par l'appelé)
creationData Contient un TPMT_CREATION_DATA. (alloué par l'appelé)
creationHash Digest de creationData en utilisant nameAlg de outPublic. (alloué par l'appelé)
creationTicket Ticket utilisé par TPM2_CertifyCreation() pour valider que les données de création ont été produites par le TPM. (alloué par l'appelé)
objectHandle Poignée ESYS_TR de la ressource ESYS pour
TPM2_HANDLE.

Valeurs de

retour
TSS2_RC_SUCCESS en cas de succès
ESYS_RC_SUCCESS si l'appel de fonction a réussi.
TSS2_ESYS_RC_BAD_REFERENCE si esysContext ou les pointeurs d'entrée requis ou les références de poignée de sortie requises sont NULL.
TSS2_ESYS_RC_BAD_CONTEXT si une corruption de esysContext est détectée.
TSS2_ESYS_RC_MEMORY si l'ESAPI ne peut pas allouer suffisamment de mémoire pour les opérations internes ou les paramètres de retour.
TSS2_ESYS_RC_BAD_SEQUENCE si le contexte a déjà une opération asynchrone en attente.
TSS2_ESYS_RC_TRY_AGAIN si le compteur d'expiration expire avant que la réponse du TPM ne soit reçue.
TSS2_ESYS_RC_INSUFFICIENT_RESPONSE si la réponse du TPM ne contient pas au moins la balise, la longueur de la réponse et le code de réponse.
TSS2_ESYS_RC_RSP_AUTH_FAILED si le HMAC de réponse du TPM n'a pas pu être vérifié.
TSS2_ESYS_RC_MALFORMED_RESPONSE si la réponse du TPM est corrompue.

ielle peuvent être retournés à
