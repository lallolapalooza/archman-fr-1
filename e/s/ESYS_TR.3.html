Description

détaillée

Objets virtuels avec métadonnées pour les ressources TPM. Les ressources TPM Esys sont les objets virtuels à l'intérieur de l'ESYSCONTEXT qui contiennent les métadonnées des ressources TPM correspondantes

.

Il existe un ensemble d'objets ESYS_TR globaux tels que E

SYS_TR_NON ou pour les diverses hiérarchies et PCR. ESYS_T
R_MIN_OBJECT désigne le premier objet ESYS_TR non global.

TSS2_RC Esys_TR_FromTPMPublic (ESYS_CONTEXT * esys_context, TPM2_HANDLE tpm_handle, ESYS_TR shandle1, ESYS_TR shandle2, ESYS_TR shandle3, ESYS_TR *

object)

Création d'un objet ESYS_TR à partir de métadonnées

TPM.

Cette fonction peut être utilisée pour créer un objet ESYS_TR pour des ressources TPM qui ne sont pas créées ou chargées (par exemple à l'aide de ESys_CreatePrimary ou ESys_Load) mais qui préexistent à l'intérieur du TPM. Des exemples sont les indices NV ou les objets

persistants.

Remarque : Pour les PCR et les hiérarchies, veuillez utiliser les identifiants ESYS_TR globaux. Remarque : Si une session est fournie, le TPM est interrogé pour les métadonnées deux fois. D'abord sans session pour récupérer certaines métadonnées, puis avec la session où ces métadonnées sont utilisées dans le calcul du HMAC de la session et ainsi

vérifiées.

Étant donné que les attaques de type « homme du milieu » doivent être évitées autant que possible, il est recommandé de passer une

session.

Paramètre

s
esys_context [in,out] Le ESYS_CONTEXT
tpm_handle [in] Le handle de l'objet TPM à représenter comme ESYS_TR.
shandle1 [in,out] Une session pour sécuriser la commande TPM (facultative).
shandle2 [in,out] Une session pour sécuriser la commande TPM (facultative).
shandle3 [in,out] Une session pour sécuriser la commande TPM (facultative).
object [out] Le nouvel objet de métadonnées ESYS_TR
créé.

Valeurs de

retour
TSS2_RC_SUCCESS en cas de succès
ESYS_RC_SUCCESS si l'appel de fonction a réussi.
TSS2_ESYS_RC_BAD_REFERENCE si esysContext ou les pointeurs d'entrée requis ou les références de handle de sortie requis sont NULL.
TSS2_ESYS_RC_BAD_CONTEXT si une corruption de esysContext est détectée.
TSS2_ESYS_RC_MEMORY si l'ESAPI ne peut pas allouer suffisamment de mémoire pour les opérations internes ou les paramètres de retour.
TSS2_ESYS_RC_BAD_SEQUENCE si le contexte a déjà une opération asynchrone en attente.
TSS2_ESYS_RC_INSUFFICIENT_RESPONSE si la réponse du TPM ne contient pas au moins la balise, la longueur de la réponse et le code de réponse.
TSS2_ESYS_RC_MALFORMED_RESPONSE si la réponse du TPM est corrompue.
TSS2_ESYS_RC_MULTIPLE_DECRYPT_SESSIONS si plus d'une session a le bit d'attribut 'decrypt' défini.
TSS2_ESYS_RC_MULTIPLE_ENCRYPT_SESSIONS si plus d'une session a le bit d'attribut 'encrypt' défini.
TSS2_ESYS_RC_NO_DECRYPT_PARAM si l'une des sessions a l'attribut 'decrypt' défini et que la commande ne prend pas en charge le chiffrement du premier paramètre de commande.
