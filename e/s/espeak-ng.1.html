--sep=<caractè

Le caractère pour séparer les phonèmes de la sortie -x et
--ipa.
--voices[=<code de langue>
]
Liste les voix disponibles. Si =<code de langue> est présent, alors seules les voix adaptées à cette langue sont listées. Si le code de langue xx-yy est passé, alors les voix avec yy de variantes de langue xx sont affichées avec une priorité plus élevée que simplement xx. Si variante est passé, alors toutes les variantes de voix sont affichées. Si mb ou mbrola est passé, alors toutes les voix utilisant le synthétiseur de voix MBROLA sont affichées. Si all est passé, alors toutes les voix eSpeak NG, les variantes de voix et les voix MBROLA sont
affichées.
