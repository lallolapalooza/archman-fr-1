Documentation des fonctions TSS2_RC Esys_NV_Extend

(

ESYS_CONTEXT * esysContext, ESYS_TR authHandle, ESYS_TRnvIndex, ESYS_TR shandle1, ESYS_TR shandle2, ESYS_TR shandle3, const TPM2B_MAX_NV_BUFFER * data) Fonction à appel unique pour TPM2_NV_Extend
Cette fonction invoque la commande TPM2_NV_Extend dans une variante à appel unique. Cela signifie que la fonction se bloquera jusqu'à ce que la réponse du TPM soit disponible. Tous les paramètres d'entrée sont const. La mémoire pour les paramètres de sortie non simples est allouée par l'implémentation de la fonction. Paramètres esysContext Le ESYS_CONTEXT . authHandle Poignée indiquant la source de la valeur d'autorisation. nvIndex L'index NV à étendre.shandle1 Poignée de session pour l'autorisation de authHandle shandle2 Deuxième poignée de session. shandle3 Troisième poignée de session. data Les données à étendre. Valeurs de retour TSS2_RC_SUCCESS si l'appel de fonction a réussi. TSS2_ESYS_RC_BAD_REFERENCE si esysContext ou les pointeurs d'entrée requis ou les références de poignées de sortie requises sont NULL.
TSS2_ESYS_RC_BAD_CONTEXT si une corruption de esysContext est détectée. TSS2_ESYS_RC_MEMORY si l'ESAPI ne peut pas allouer assez de mémoire pour les opérations internes ou les paramètres de retour. TSS2_ESYS_RC_BAD_SEQUENCE si le contexte a déjà une opération asynchrone en attente. TSS2_ESYS_RC_INSUFFICIENT_RESPONSE si la réponse du TPM ne contient pas au moins la balise, la longueur de la réponse et le code de réponse. TSS2_ESYS_RC_MALFORMED_RESPONSEsi la réponse du TPM est corrompue.

Fonction asynchrone pour TPM2_NV_Extend Cette fonction invoque la commande TPM2_NV_Extend dans une variante asynchrone. Cela signifie que la fonction retournera dès que la commande a été envoyée vers le bas dans la pile jusqu'au TPM. Tous les paramètres d'entrée sont const. Afin de récupérer la réponse du TPM, appelez Esys_NV_Extend_Finish.
