Fonction en un seul appel pour

TPM2_Duplicate

Cette fonction invoque la commande TPM2_Duplicate dans une variante en un seul appel. Cela signifie que la fonction se bloquera jusqu'à ce que la réponse du TPM soit disponible. Tous les paramètres d'entrée sont const. La mémoire pour les paramètres de sortie non simples est allouée par l'implémentation de la

fonction.

Paramètre

s
esysContext Le ESYS_CONTEXT.
objectHandle Objet chargé à dupliquer.
newParentHandle Doit référencer la zone publique d'une clé asymétrique.
shandle1 Poignée de session pour l'autorisation de objectHandle
shandle2 Deuxième poignée de session.
shandle3 Troisième poignée de session.
encryptionKeyIn Clé de chiffrement symétrique facultative.
symmetricAlg Définition de l'algorithme symétrique à utiliser pour l'enveloppe interne.
encryptionKeyOut TPM2_Si l'appelant a fourni une clé de chiffrement ou si symmetricAlg était TPM2_ALG_NULL, alors ce sera le TPM2_Empty TPM2_Buffer ; sinon, il doit contenir la clé de chiffrement symétrique TPM2_générée par le TPM pour l'enveloppe interne.. (alloué par l'appelé)
duplicate Zone privée qui peut être chiffrée par encryptionKeyIn ; et peut être doublement chiffrée. (alloué par l'appelé)
outSymSeed Graine protégée par les algorithmes asymétriques du nouveau parent (NP). (alloué par
l'appelé)

Valeurs de

retour
TSS2_RC_SUCCESS si l'appel de fonction a réussi.

TSS2_ESYS_RC_BAD_CONTEXT si une corruption de esysContext est détectée.
TSS2_ESYS_RC_MEMORY si l'ESAPI ne peut pas allouer assez de mémoire pour les opérations internes ou les paramètres de retour.
TSS2_ESYS_RC_BAD_SEQUENCE si le contexte a déjà une opération asynchrone en attente.
TSS2_ESYS_RC_INSUFFICIENT_RESPONSE si la réponse du TPM ne contient pas au moins la balise, la longueur de la réponse et le code de réponse.
TSS2_ESYS_RC_MALFORMED_RESPONSE si la réponse du TPM est corrompue.
TSS2_ESYS_RC_RSP_AUTH_FAILED si le HMAC de réponse du TPM n'a pas pu être vérifié.
TSS2_ESYS_RC_MULTIPLE_DECRYPT_SESSIONS si plus d'une session a le bit d'attribut 'decrypt' défini.
TSS2_ESYS_RC_MULTIPLE_ENCRYPT_SESSIONS si plus d'une session a le bit d'attribut 'encrypt' défini.

Fonction de finition asynchrone pour

TPM2_Duplicate

Cette fonction retourne les résultats d'une commande TPM2_Duplicate invoquée via Esys_Duplicate_Finish. Tous les paramètres de sortie non simples sont tousocated by the function's implementation. NULL can be passed for every output parameter if the value is not

required.

Paramètre

s
esysContext The ESYS_CONTEXT.
encryptionKeyOut TPM2_If the caller provided an encryption key or if symmetricAlg was TPM2_ALG_NULL, then this will be the TPM2_Empty TPM2_Buffer; otherwise, it shall contain the TPM2_TPM-generated, symmetric encryption key for the inner wrapper.. (callee-allocated)
duplicate Private area that may be encrypted by encryptionKeyIn; and may be doubly encrypted. (callee-allocated)
outSymSeed Seed protected by the asymmetric algorithms of new parent (NP). (callee-allocated
)

retour
