NOM

ESingular - page de manuel pour ESingular 4.0.0

DESCRIPTION

ESingular: Un programme qui lance Singular dans emacs, pour la version 4.0.0 de Singular -- un SGC pour les calculs polynomiaux. Utilisation :

ESingular [options] [fichier]

OPTIONS

- --emacs=EMACS
Utilise EMACS comme programme emacs pour lancer Singular
- --emacs-dir=DIR
Utilise DIR comme répertoire pour rechercher les fichiers emacs lisp
- --emacs-load=FILE
Charge FILE au démarrage d'emacs, au lieu du fichier par défaut
- --singular=PROG
Lance PROG comme programme Singular dans emacs
- --no-call
Ne lance pas le programme. Affiche l'appel sur la sortie standard
Toutes les autres options sont passées à Singular.

Pour plus d'informations, tapez `help;' depuis Singular ou visitez https://www.singular.uni-kl.de ou consultez le manuel de Singular (disponible sous forme d'info en ligne ou de manuel html).

VOIR AUSSI

La documentation complète de Singular est maintenue sous forme de manuel Texinfo. Si les programmes info et Singular sont correctement installés sur votre site, la commande

info Singular

devrait vous donner accès au manuel complet.

Janvier 2014 ESingular 4.0.0
