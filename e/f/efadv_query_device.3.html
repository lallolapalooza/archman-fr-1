EFADV_QUERY_DEVICE(3) Manuel des verbes EFA Direct EFADV_QUERY_DEVICE(3)

NOM

efadv_query_device - Interroger les capacités du périphérique

SYNTAXE

#include <infiniband/efadv.h>
int efadv_query_device(struct ibv_context *ibvctx,
               struct efadv_device_attr *attr,
               uint32_t inlen);

DESCRIPTION

efadv_query_device() interroge les attributs spécifiques au périphérique EFA.

La compatibilité est gérée à l'aide des champs comp_mask et inlen.

struct efadv_device_attr {
    uint64_t comp_mask;
    uint32_t max_sq_wr;
    uint32_t max_rq_wr;
    uint16_t max_sq_sge;
    uint16_t max_rq_sge;
    uint16_t inline_buf_size;
    uint8_t reserved[2];
    uint32_t device_caps;
    uint32_t max_rdma_size;
};
inlen
Entrée : Taille de la structure efadv_device_attr.
comp_mask
Masque de compatibilité.
max_sq_wr
Nombre maximum de requêtes de travail (WRs) pour la file d'attente d'envoi (SQ).
max_rq_wr
Nombre maximum de requêtes de travail (WRs) pour la file d'attente de réception (RQ).
max_sq_sge
Nombre maximum d'éléments scatter/gather (SGEs) pour la file d'attente d'envoi (SQ).
max_rq_sge
Nombre maximum d'éléments scatter/gather (SGEs) pour la file d'attente de réception (RQ).
inline_buf_size
Taille maximale du tampon en ligne.
device_caps
Masque de bits des capacités du périphérique :

EFADV_DEVICE_ATTR_CAPS_RDMA_READ : RDMA read est pris en charge.

EFADV_DEVICE_ATTR_CAPS_RNR_RETRY : La retransmission RNR est prise en charge pour les QPs SRD.

EFADV_DEVICE_ATTR_CAPS_CQ_WITH_SGID : La lecture de l'adresse source (SGID) à partir des descripteurs de complétion de réception est prise en charge. Valide uniquement pour les AH inconnus.

EFADV_DEVICE_ATTR_CAPS_RDMA_WRITE : RDMA write est pris en charge.

EFADV_DEVICE_ATTR_CAPS_UNSOLICITED_WRITE_RECV : Indique que le périphérique prend en charge la création de QPs capables de recevoir des RDMA write avec immédiat non sollicités. Les RQ avec cette fonctionnalité activée ne consommeront aucune requête de travail pour recevoir des RDMA write avec immédiat, et un WC généré pour une telle réception sera marqué comme non sollicité.

EFADV_DEVICE_ATTR_CAPS_CQ_WITH_EXT_MEM_DMABUF : Indique que la création de CQs avec des tampons mémoire externes en passant un dmabuf est prise en charge.

max_rdma_size
Taille maximale du transfert RDMA en octets.

VALEUR DE RETOUR

efadv_query_device() renvoie 0 en cas de succès, ou la valeur d'errno en cas d'échec (qui indique la raison de l'échec).

VOIR AUSSI

efadv(7)

NOTES

•
Le masque de compatibilité (comp_mask) est un champ de sortie et n'a actuellement aucune valeur.
