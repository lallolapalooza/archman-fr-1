type ('a, 'b) continuation

('a,'b) continuation est une continuation délimitée qui attend une valeur de type 'a et retourne une valeur de type 'b.

val fiber : ('a -> 'b) -> ('a, 'b) continuation

fiber f construit une continuation qui exécute le calcul f.

type ('a, 'b) handler = {
retc : 'a -> 'b ;
exnc : exn -> 'b ;
effc : 'c. 'c Effect.t -> (('c, 'a) continuation -> 'b) option ;
}

('a,'b) handler est un enregistrement de gestionnaire avec trois champs -- retc est le gestionnaire de valeur, exnc gère les exceptions, et effc gère les effets effectués par le calcul enfermé par le gestionnaire.

val continue_with : ('c, 'a) continuation -> 'c -> ('a, 'b) handler -> 'b

continue_with k v h reprend la continuation k avec la valeur v et le gestionnaire h.

Lève Continuation_already_resumed si la continuation a déjà été reprise.

val discontinue_with : ('c, 'a) continuation -> exn -> ('a, 'b) handler -> 'b

discontinue_with k e h reprend la continuation k en levant l'exception e avec le gestionnaire h.

Lève Continuation_already_resumed si la continuation a déjà été reprise.

val discontinue_with_backtrace : ('a, 'b) continuation -> exn -> Printexc.raw_backtrace -> ('b, 'c) handler -> 'c

discontinue_with k e bt h reprend la continuation k en levant l'exception e avec le gestionnaire h en utilisant la trace brute bt comme origine de l'exception.

Lève Continuation_already_resumed si la continuation a déjà été reprise.

val get_callstack : ('a, 'b) continuation -> int -> Printexc.raw_backtrace

get_callstack c n renvoie une description du sommet de la pile d'appels sur la continuation c, avec au plus n entrées.
