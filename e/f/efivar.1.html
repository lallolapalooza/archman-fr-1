EFIVAR(1) Commandes utilisateur EFIVAR(1)

NOM

efivar - Outil pour manipuler les variables UEFI

SYNTAXE

efivar [OPTION...]

DESCRIPTION

-A, --attributes=<attributs>
attributs à utiliser lors de l'ajout
-l, --list
lister les variables actuelles
-p, --print
afficher la variable spécifiée par --name
-D, --dmpstore
utiliser le format DMPSTORE lors de l'exportation
-d, --print-decimal
afficher la variable en valeurs décimales spécifiées par --name
-n, --name=<guid-nom>
variable à manipuler, sous la forme 8be4df61-93ca-11d2-aa0d-00e098032b8c-Boot0000
-a, --append
ajouter à la variable spécifiée par --name
-f, --datafile=<fichier>
charger ou sauvegarder le contenu de la variable depuis/vers <fichier>
-e, --export=<fichier>
exporter la variable vers <fichier>
-i, --import=<fichier>
importer la variable depuis <fichier>
-L, --list-guids
afficher la liste des GUIDs internes
-w, --write
écrire dans la variable spécifiée par --name

Options d'aide :

-?, --help
Afficher ce message d'aide
--usage
Afficher un bref message d'utilisation
