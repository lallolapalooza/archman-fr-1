NOM

efadv_create_driver_qp - Créer une paire de files d'attente spécifique à EFA # SYNTAXE

#include <infiniband/efadv.h>
struct ibv_qp *efadv_create_driver_qp(struct ibv_pd *ibvpd,
                                      struct ibv_qp_init_attr *attr,
                                      uint32_t driver_qp_type);

DESCRIPTION

efadv_create_driver_qp() Crée des paires de files d'attente spécifiques au périphérique.

Le transport Scalable Reliable Datagram (SRD) fournit une livraison fiable hors-séquence, utilisant de manière transparente plusieurs chemins réseau pour réduire la latence des queues réseau. Son interface est similaire à UD, en particulier elle prend en charge des tailles de messages allant jusqu'à MTU, avec une gestion des erreurs étendue pour supporter la communication fiable.

driver_qp_type
Le type de QP à créer :

EFADV_QP_DRIVER_TYPE_SRD: Crée un QP SRD.

VALEUR DE RETOUR

efadv_create_driver_qp() renvoie un pointeur vers le QP créé, ou NULL si la demande échoue.

VOIR AUSSI
