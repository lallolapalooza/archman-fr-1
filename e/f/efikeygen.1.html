DESCRIPTIO

N

efikeygen est un outil en ligne de commande pour générer des clés et des certificats à utiliser avec pesign. Ce sont des certificats X.509 standard, et ils peuvent potentiellement être générés avec n'importe quel outil de création de certificats. efikeygen génère des certificats avec des options appropriées définies

pour une clé destinée à la signature
d'images PE pour UEFI Secure Boot.

NAME


pesign - a tool for signing EFI binaries with PKCS#11






SYNOPSIS


pesign [OPTION...]






DESCRIPTION


This utility can be used to sign EFI binaries and verify signatures
    on EFI binaries. It uses PKCS#11 to interface with cryptographic hardware tokens
    like Smart Cards or YubiKeys. It can generate keys and certificates, store them
    on a token, and use them to sign binaries.


PESign requires a smart card reader and a smart card with PKCS#11
    support, or a YubiKey with PIV support.


To use PESign, you will need to prepare your smart card or YubiKey
    with appropriate keys and certificates. This usually involves using tools like
    pkcs15-init, efikeygen, and
    pk12util.


See the EXAMPLES section below for a step-by-step guide on how to
    prepare a smart card for signing and then use it to sign an EFI binary.






OPTIONS


PESign supports the following options:




-s


Sign an EFI binary. This requires the following additional options:


-t TOKEN


The PKCS#11 token to use for signing. This can be a label or a slot number.
    For example, "OpenSC Card (myorg-sb-ca)" or "2".


-c CERTIFICATE


The certificate to use for signing. This can be a label or a URI. For example,
    "OpenSC Card (myorg-sb-ca):/CN=My Org's SB Signer".


-i INPUT


The input EFI binary to sign.


-o OUTPUT


The output file for the signed EFI binary.


-l


List signatures on an EFI binary. This requires the following additional
    option:


-i INPUT


The input EFI binary to inspect.








EXAMPLES


This section provides a detailed example of how to prepare a smart
    card for signing EFI binaries using PESign.


1. Initialize the Smart Card


First, you need to initialize the smart card with security officer
    (SO) PIN and PUK codes, and then with user PIN and PUK codes. Replace
    $PIN, $PUK, $SOPIN,
    and $SOPUK with your desired values.




# Initialize the card's PKCS15 data, set the Security Officer PIN and unlock
# code.
host:~$ pkcs15-init -CT --so-pin $SOPIN --so-puk $SOPUK
Using reader with a card: Generic Smart Card Reader Interface [Smart Card Reader Interface] (20070818000000000) 00 00

# Initialize the user PIN and unlock code, and label the token
host:~$ pkcs15-init -P -a 1 --pin $PIN --puk $PUK \
        --so-pin $SOPIN --so-puk $SOPUK \
        --label "myorg-sb-ca"
Using reader with a card: Generic Smart Card Reader Interface [Smart Card Reader Interface] (20070818000000000) 00 00




2. Generate Keys and Certificates


Next, generate the necessary keys and certificates. In this example,
    we generate a Certificate Authority (CA) key and certificate, and a kernel
    signing key and certificate.




# Create a new CA key and certificate
host:~$ efikeygen -C -n my-ca -S \
        -c "CN=My Org's Secure Boot CA,OU=My Org's CA,O=My Org" \
        -u https://myorg.example.com/ca/

# Create a kernel signing key and cert
host:~$ efikeygen -n my-signer --signer my-ca -k \
        -c "CN=My Org's SB Signer,OU=My Org's CA,O=My Org"\
        -u https://myorg.example.com/ca/




3. Store Keys and Certificates on the Smart Card


Export the CA key and certificate to a PKCS-12 bundle and then
    import it onto the smart card. You will be prompted to enter a password for
    the PKCS-12 file.




# Save the CA key and certificate in a PKCS-12 bundle
host:~$ pk12util -d /etc/pki/pesign -o my-ca.p12 -n my-ca
Enter password for PKCS12 file: <enter a password here>
Re-enter password: <type it again here>
pk12util: PKCS12 EXPORT SUCCESSFUL

# Import the PKCS-12 bundle onto the card
host:~$ pkcs15-init --store-private-key my-ca.p12 \
        --format pkcs12 --auth-id 01 \
        --pin $PIN --so-pin $SOPIN --so-puk $SOPUK
Using reader with a card: Generic Smart Card Reader Interface [Smart Card Reader Interface] (20070818000000000) 00 00
Importing 1 certificates:
   0: /CN=My Org's Secure Boot CA

host:~$ pkcs11-tool --module opensc-pkcs11.so -l --pin $PIN -O

Repeat the key/certificate generation and import process for the
    signer key and certificate. Remember to switch cards if you are using
    different smart cards for CA and signer keys.


4. Sign an EFI Binary


Once the keys and certificates are on the smart card, you can use
    PESign to sign an EFI binary. You will be prompted to enter the PIN for the
    smart card multiple times.




# Sign the binary.  On each of these prompts, you have to enter
# the PIN for the Smart Card.  This and the strange choice of
# names are because PKCS-11 is horrible.  I'm sorry.
host:~$ pesign -s -t "OpenSC Card(myorg-sb-signer)" \
        -c "OpenSC Card (myorg-sb-signer):/CN=My Org's SB Signer"\
        -i shimx64.efi -o shimx64.signed.efi
Enter Password or Pin for "My Org's SB Signer": <type the PIN here>
