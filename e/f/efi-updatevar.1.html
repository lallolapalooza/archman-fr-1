EFI-UPDATEVAR(1) Commandes utilisateur EFI-UPDATEVAR(1)

NOM

efi-updatevar - outil pour la mise à jour des variables sécurisées

SYNTAXE

efi-updatevar: [-a] [-e] [-d <liste>[-<entrée>]] [-k <clé>] [-g <guid>] [-b <fichier>|-f <fichier>|-c fichier] <var>

DESCRIPTION

Prend une variété de fichiers d'entrée et les ajoute à l'une des bases de données de clés ou de signatures de démarrage sécurisé UEFI.

Notez que le système de fichiers efivarfs doit être monté quelque part sur la machine et efi-updatevars doit avoir la permission d'écrire sur les fichiers (cela signifie généralement qu'il doit être exécuté en tant que root).

Manipule la base de données des clés UEFI via le système de fichiers efivarfs.

OPTIONS

-a
ajoute une valeur à la variable au lieu de la remplacer
-e
utilise la liste de signatures EFI (EFI Signature List) au lieu d'une mise à jour signée (ne fonctionne qu'en mode Setup
-b <fichier_binaire>
Ajoute le hash de <fichier_binaire> à la liste de signatures
-f <fichier>
Ajoute ou remplace le fichier de clé (.esl ou .auth) dans <var>
-c <fichier>
Ajoute ou remplace le certificat x509 dans <var> (avec <guid> si fourni)
-g <guid>
Optionnel <guid> pour le certificat X509
-k <clé>
Fichier de clé secrète pour autoriser les mises à jour en mode utilisateur
-d <liste>[-<entrée>]
Supprime la liste de signatures <liste> (ou juste une seule <entrée> dans la liste)
--engine <moteur>
Utilise le moteur <moteur> pour la clé privée

EXEMPLES

En supposant que vous possédez votre propre clé de plateforme et que vous avez les fichiers PK.auth et noPK.auth qui vont avec, vous pouvez programmer le système pour sortir du mode utilisateur en faisant :

efi-updatevar -f noPK.auth PK

et le remettre en place avec :

efi-updatevar -f PK.auth PK

Pour ajouter le hash d'un binaire EFI bin.efi à db en mode Setup, faites :

efi-updatevar -b bin.efi db

Et pour ajouter une liste de signatures EFI append.esl à db en mode Setup, faites :

efi-updatevar -a -e append.esl db

Pour ajouter votre clé (KEK.crt) à la clé d'échange de clés (Key Exchange Key) en mode utilisateur, en supposant que la partie privée de la clé de plateforme se trouve dans PK.key, faites :

efi-updatevar -a -c KEK.crt -k PK.key KEK

Pour ajouter le certificat DB.crt à db en mode utilisateur, en supposant que la partie privée de la clé d'échange de clés (KEK) se trouve dans KEK.key, faites :

efi-updatevar -a -c DB.crt -k KEK.key db

Pour remplacer l'ancienne clé de plateforme (PK) par une nouvelle dans newPK.crt en mode utilisateur, en supposant que la partie privée de l'ancienne clé de plateforme se trouve dans PK.key, faites :

efi-updatevar -c newPK.crt -k PK.key db

Pour supprimer la clé privée, faisant passer la plateforme du mode utilisateur au mode de configuration (Setup Mode), faites :

efi-updatevar -d 0 -k PK.key PK

Et pour remettre la clé privée (en mode de configuration), faites :

efi-updatevar -c PK.crt -k PK.key PK
