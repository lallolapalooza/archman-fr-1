NOM

efibootdump - afficher les entrées de démarrage à partir d'une variable ou d'un fichier

SYNTAXE

efibootdump [-?|--help] [--usage]
[-f <fichier1> [... -f <fichierN>]]
[[-g {guid}] <nom0> [... [<nomN>]]]

DESCRIPTION

efibootdump est une application en espace utilisateur utilisée pour afficher des options de démarrage UEFI individuelles, à partir d'un fichier ou d'une variable UEFI. Cela permet par exemple d'afficher les fichiers sauvegardés d'efivarfs, ainsi que les variables de la machine en cours d'exécution.

OPTIONS

Voici une liste des options acceptées par efibootmgr :

-g | --guid {guid}
Toutes les variables spécifiées par nom ont le GUID spécifié.
-f | --file <fichier>
Lire une seule variable de démarrage à partir du fichier spécifié.
<nomN>
Afficher la variable spécifiée sur la machine locale. Si aucun GUID n'est spécifié, la variable globale EFI est utilisée par défaut.

BOGUES

Veuillez adresser tout bogue, demande de fonctionnalité, correctif, etc. à l'équipe de gestion du chargeur de démarrage de Red Hat à l'adresse https://github.com/rhboot/efibootmgr .
