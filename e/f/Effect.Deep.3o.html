Gestionnaires profonds

type ('a, 'b) continuation = ('a, 'b) continuation

('a,'b) continuation est une continuation délimitée qui attend une valeur de type 'a et retourne une valeur de type 'b.

val continue : ('a, 'b) continuation -> 'a -> 'b

continue k x reprend la continuation k en lui passant x.

Lève Continuation_already_resumed si la continuation a déjà été reprise.

val discontinue : ('a, 'b) continuation -> exn -> 'b

discontinue k e reprend la continuation k en lui levant l'exception e.

Lève Continuation_already_resumed si la continuation a déjà été reprise.

val discontinue_with_backtrace : ('a, 'b) continuation -> exn -> Printexc.raw_backtrace -> 'b

discontinue_with_backtrace k e bt reprend la continuation k en lui levant l'exception e en utilisant bt comme origine de l'exception.

Lève Continuation_already_resumed si la continuation a déjà été reprise.

type ('a, 'b) handler = {
retc : 'a -> 'b ;
exnc : exn -> 'b ;
effc : 'c. 'c Effect.t -> (('c, 'b) continuation -> 'b) option ;
}

('a,'b) handler est un enregistrement de gestionnaire avec trois champs : retc est le gestionnaire de valeur, exnc gère les exceptions, et effc gère les effets produits par le calcul encapsulé par le gestionnaire.

val match_with : ('c -> 'a) -> 'c -> ('a, 'b) handler -> 'b

match_with f v h exécute le calcul f v dans le gestionnaire h.

type 'a effect_handler = {
effc : 'b. 'b Effect.t -> (('b, 'a) continuation -> 'a) option ;
}

'a effect_handler est un gestionnaire profond avec un gestionnaire de valeur identité fun x -> x et un gestionnaire d'exception qui lève toute exception fun e -> raise e.

val try_with : ('b -> 'a) -> 'b -> 'a effect_handler -> 'a

try_with f v h exécute le calcul f v sous le gestionnaire h.

val get_callstack : ('a, 'b) continuation -> int -> Printexc.raw_backtrace

get_callstack c n retourne une description du sommet de la pile d'appels de la continuation c, avec au plus n entrées.
