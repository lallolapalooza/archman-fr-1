EFADV_CREATE_QP_EX(3) Manuel des Verbes EFA Direct EFADV_CREATE_QP_EX(3)

NOM

efadv_create_qp_ex - Créer une paire de files d'attente étendue spécifique à EFA

SYNTAXE

#include <infiniband/efadv.h>
struct ibv_qp *efadv_create_qp_ex(struct ibv_context *ibvctx,
                  struct ibv_qp_init_attr_ex *attr_ex,
                  struct efadv_qp_init_attr *efa_attr,
                  uint32_t inlen);

DESCRIPTION

efadv_create_qp_ex() crée une paire de files d'attente étendue spécifique au périphérique.

L'argument attr_ex est une structure ibv_qp_init_attr_ex, telle que définie dans <infiniband/verbs.h>.

Utilisez ibv_qp_to_qp_ex() pour obtenir le ibv_qp_ex permettant d'accéder à l'interface d'itérateur d'opérations d'envoi, lorsque l'attribut de création de QP IBV_QP_INIT_ATTR_SEND_OPS_FLAGS est utilisé.

Scalable Reliable Datagram (SRD) transport fournit une livraison fiable hors ordre, utilisant de manière transparente plusieurs chemins réseau pour réduire la latence réseau de queue. Son interface est similaire à UD, en particulier, il prend en charge une taille de message jusqu'à MTU, avec une gestion des erreurs étendue pour prendre en charge la communication fiable.

La compatibilité est gérée à l'aide des champs comp_mask et inlen.

struct efadv_qp_init_attr {
    uint64_t comp_mask;
    uint32_t driver_qp_type;
    uint16_t flags;
    uint8_t sl;
    uint8_t reserved[1];
};
inlen
Entrée : Taille de la structure efadv_qp_init_attr.
comp_mask
Masque de compatibilité.
driver_qp_type
Le type de QP à créer :

EFADV_QP_DRIVER_TYPE_SRD : Créer un QP SRD.

flags
Un OU logique des valeurs décrites ci-dessous.

EFADV_QP_FLAGS_UNSOLICITED_WRITE_RECV : Les WR de réception ne seront pas consommés pour les écritures RDMA avec imm.

sl
Niveau de service - la valeur 0 implique le niveau par défaut.

VALEUR DE RETOUR

efadv_create_qp_ex() retourne un pointeur vers le QP créé, ou NULL si la requête échoue.

VOIR AUSSI

efadv(7), ibv_create_qp_ex(3)
