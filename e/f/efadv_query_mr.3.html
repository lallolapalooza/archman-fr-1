EFADV_QUERY_MR(3) Manuel des verbes directs EFA EFADV_QUERY_MR(3)

NOM

efadv_query_mr - Interroger les attributs spécifiques EFA de la région mémoire

SYNTAXE

#include <infiniband/efadv.h>
int efadv_query_mr(struct ibv_mr *ibvmr, struct efadv_mr_attr *attr, uint32_t inlen);

DESCRIPTION

efadv_query_mr() interroge les attributs spécifiques au périphérique de la région mémoire.

La compatibilité est gérée à l'aide des champs comp_mask et inlen.

struct efadv_mr_attr {
    uint64_t comp_mask;
    uint16_t ic_id_validity;
    uint16_t recv_ic_id;
    uint16_t rdma_read_ic_id;
    uint16_t rdma_recv_ic_id;
};
inlen
Entrée : Taille de la structure efadv_mr_attr.
comp_mask
Masque de compatibilité.
ic_id_validity
Masque de validité des champs d'identifiant d'interconnexion :

EFADV_MR_ATTR_VALIDITY_RECV_IC_ID : recv_ic_id contient une valeur valide.

EFADV_MR_ATTR_VALIDITY_RDMA_READ_IC_ID : rdma_read_ic_id contient une valeur valide.

EFADV_MR_ATTR_VALIDITY_RDMA_RECV_IC_ID : rdma_recv_ic_id contient une valeur valide.

recv_ic_id
Interconnexion physique utilisée par le périphérique pour atteindre la MR pour l'opération de réception.
rdma_read_ic_id
Interconnexion physique utilisée par le périphérique pour atteindre la MR pour l'opération de lecture RDMA.
rdma_recv_ic_id
Interconnexion physique utilisée par le périphérique pour atteindre la MR pour la réception d'écriture RDMA.

VALEUR DE RETOUR

efadv_query_mr() renvoie 0 en cas de succès, ou la valeur d'errno en cas d'échec (qui indique la raison de l'échec).

VOIR AUSSI

efadv(7)

NOTES

•
Le masque de compatibilité (comp_mask) est un champ de sortie et n'a actuellement aucune valeur.
