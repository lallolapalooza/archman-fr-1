DESCRIPTIO

N

efi_variable_t est un type de données opaque utilisé pour stocker des variables en mémoire pour utilisation avec cette

API.

efi_variable_import() est utilisé pour importer des données brutes lues depuis un fichier. Cette fonction renvoie la quantité de données consommées avec cette variable, et peut être utilisée successivement, en utilisant son code de retour comme décalage, pour analyser une liste de variables. Notez que les valeurs internes guid, nom et données sont allouées séparément, et doivent être libérées soit individuellement soit en utilisant le paramètre free_data de efi_variable_free(). Les accesseurs _get() pour ces valeurs renvoient des données adaptées pour être libérées individuellement, sauf dans les cas où un accesseur _set() a été passé un objet déjà inadapté à

cela.

efi_variable_export() est utilisé pour sérialiser des objets efi_variable_t en données linéaires qui peuvent être écrites dans un fichier. Si les paramètres data ou size ne sont pas fournis, cette fonction renverra combien de stockage un appelant doit allouer. Sinon, efi_variable_export() utilisera le stockage désigné comme son tampon ; si size est inférieur à la quantité de stockage nécessaire, le tampon ne sera pas modifié, et la différence entre l'espace nécessaire et size sera

renvoyée.

efi_variable_alloc() est utilisé pour allouer un objet efi_variable_t non rempli adapté pour être utilisé tout au long de cette API. efi_variable_free() est utilisé pour libérer un objet efi_variable_t, et si free_data est non nul, pour libérer ses données

constitutives.

Chaque paire d' accesseurs _set() et _get() a essentiellement les mêmes sémantiques. Aucune opération n'effectue de gestion de mémoire, y compris la libération des valeurs précédemment définies ou des valeurs définies par efi_variable_import(), et donc dans certains cas il peut être nécessaire d' utiliser un accesseur _get() pour récupérer un objet à libérer. Dans les cas où aucune valeur n'a été définie, les accesseurs _get() définiront errno à ENOENT et renverront une valeur négative ou

NULL.

efi_variable_set_name() et efi_variable_get_name() sont utilisés pour définir et récupérer le nom de la variable désignée par l' objet efi_vari

able_t.

efi_variable_set_guid() et efi_variable_get_guid() sont utilisés pour définir et récupérer la valeur Vendor GUID de la variable désignée par l' objet efi_vari

able_t.

efi_variable_set_data() et efi_variable_get_data() sont utilisés pour définir et récupérer les données de variable d'un objet

efi_variable_t.

efi_variable_set_attributes() et efi_variable_get_attributes sont utilisés pour définir et récupérer les attributs d'un objet efi_variable_t. Tous les bits sauf EFI_VARIABLE_HAS_AUTH_HEADER et EFI_VARIABLE_HAS_SIGNATURE sont définis dans la spécification UEFI et devraient être utilisés en conséquence. EFI_VARIABLE_HAS_AUTH_HEADER devrait être utilisé par les applications pour suivre si le contenu des données de la variable inclut un en-tête d'authentification. EFI_VARIABLE_HAS_SIGNATURE devrait être utilisé par les applications pour suivre si le contenu des données de la variable inclut une signature, et ne devrait pas être défini sauf si EFI_VARIABLE_HAS_AUTH_HEADER est également défini. Ces attributs sont utilisés pour suivre si une variable exportée est dans un état de construction partielle, par exemple si une variable authentifiée a été créée mais est destinée à être signée à une date

ultérieure.

efi_variable_realize() est une fonction de commodité pour définir ou ajouter une variable UEFI sur le système en cours d'exécution à partir d'un objet efi_variable_t. ses codes de retour sont les mêmes que efi_append_variable(3) si EFI_VARIABLE_APPEND_WRITE est défini, et efi_set_variable() si ce bit n'est pas défini. De plus, dans le cas où l'un des bits d'authentification est défini, efi_variable_realize() renverra une erreur et définira errno à EPERM sauf si les deux bits d'attribut EFI_VARIABLE_HAS_AUTH_HEADER et EFI_VARIABLE_HAS_SIG

NATURE son
t définis.

VALEUR DE

RETOUR

efi_variable_import() renvoie 0 en cas de succès, et -1 en cas d'échec. Dans les cas où il ne peut pas analyser les données, errno sera défini à EINVAL. Dans les cas où la mémoire est épuisée, errno sera défini à ENOMEM

.

efi_variable_export() renvoie la taille du tampon data en cas de succès, ou une valeur négative en cas d'erreur. Si les paramètres data ou size ne sont pas fournis, cette fonction renverra combien de stockage un appelant doit allouer. Sinon, cette fonction utilisera le stockage fourni dans data ; si size est inférieur à l'espace nécessaire, le tampon ne sera pas modifié, et la valeur de retour sera le déficit de

taille.

efi_variable_alloc() renvoie un objet efi_variable_t nouvellement alloué, mais n'effectue aucune allocation pour le nom de cet objet, name, guid, ou data. Dans le cas où la mémoire est épuisée, NULL sera renvoyé, et errno sera défini à ENOMEM

.

efi_variable_get_name() renvoie un pointeur vers la chaîne terminée par NUL contenant les informations de nom de l'objet efi_variable_t

.

efi_variable_set_name(), efi_variable_set_guid(), efi_variable_get_guid(), efi_variable_set_data(), efi_variable_get_data(), efi_variable_set_attributes(), efi_variable_get_attributes(), et efi_variable_realize() renvoient 0

en cas de succès et
-1 en cas d'erreur.
