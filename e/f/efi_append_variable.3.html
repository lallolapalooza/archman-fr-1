efi_append_variable(3)

Paquet: efivar

Licences: LGPL-2.1-or-later

EFI_GET_VARIABLE(3) Manuel des fonctions de bibliothèque EFI_GET_VARIABLE(3)

NOM

efi_variables_supported, efi_del_variable, efi_get_variable, efi_get_variable_attributes, efi_get_variable_size, efi_set_variable - manipuler les variables UEFI

SYNTAXE

#include <efivar.h>

int efi_variables_supported(void);
int efi_del_variable(efi_guid_t guid, const char *name);
int efi_get_variable(efi_guid_t guid, const char *name,
				 void **data, ssize_t *data_size,
				 uint32_t *attributes);
int efi_get_variable_attributes(efi_guid_t guid, const char *name,
						  uint32_t *attributes);
int efi_get_variable_exists(efi_guid_t guid, const char *name);
int efi_get_variable_size(efi_guid_t guid, const char *name,
					 size_t *size);
int efi_append_variable(efi_guid_t guid, const char *name,
				 void *data, size_t data_size,
				 uint32_t attributes);
int efi_set_variable(efi_guid_t guid, const char *name,
				 void *data, size_t data_size,
				 uint32_t attributes, mode_t mode);
int efi_get_next_variable_name(efi_guid_t **guid, char **name);
int efi_str_to_guid(const char *s, efi_guid_t *guid);
int efi_guid_to_str(const efi_guid_t *guid, char **sp);
int efi_name_to_guid(const char *name, efi_guid_t *guid);
int efi_id_guid_to_guid(const char *id_guid, efi_guid_t *guid);
int efi_guid_to_name(efi_guid_t *guid, char **name);
int efi_guid_to_id_guid(efi_guid_t *guid, char **id_guid);
int efi_guid_to_symbol(efi_guid_t *guid, char **symbol);
int efi_symbol_to_guid(const char *symbol, efi_guid_t *guid);

DESCRIPTION

efi_variables_supported() teste si la fonctionnalité de variables UEFI est supportée sur la machine actuelle.

efi_del_variable() supprime la variable spécifiée par guid et name.

efi_get_variable() récupère la variable spécifiée par guid et name. La valeur est stockée dans data, sa taille dans data_size, et ses attributs sont stockés dans attributes.

efi_get_variable_attributes() récupère les attributs de la variable spécifiée par guid et name.

efi_get_variable_exists() indique si la variable spécifiée par guid et name existe.

efi_get_variable_size() récupère la taille des données pour la variable spécifiée par guid et name.

efi_append_variable() ajoute data de taille size à la variable spécifiée par guid et name.

efi_set_variable() définit la variable spécifiée par guid et name, et définit le mode fichier à mode, soumis à umask. Notez que le mode ne persistera pas après un redémarrage, et que les permissions ne s'appliquent que sur les systèmes utilisant efivarfs.

efi_get_next_variable_name() itère sur les variables actuellement existantes, retournant un guid et un nom.

efi_str_to_guid() analyse un GUID UEFI de forme chaîne vers un efi_guid_t fourni par l'appelant.

efi_guid_to_str() Crée une représentation chaîne d'un GUID UEFI. Si sp est NULL, il renvoie la taille que la chaîne aurait. Si sp n'est pas NULL mais que *sp est NULL, il alloue une chaîne et la renvoie. Il est de la responsabilité de l'appelant de libérer cette chaîne. Si sp n'est pas NULL et *sp n'est pas NULL, efi_guid_to_str() suppose qu'il y a une allocation de taille appropriée et l'utilise.

efi_name_to_guid() traduit un nom bien connu en un efi_guid_t fourni par l'appelant.

efi_guid_to_name() traduit un efi_guid_t en un nom bien connu. Si le GUID fourni n'a pas de nom bien connu, cette fonction est équivalente à efi_guid_to_str().

efi_guid_to_id_guid() traduit un efi_guid_t en un {ID GUID}. Si le GUID fourni a un nom bien connu, le {ID GUID} sera de la forme "{nom_ici}". Sinon, il sera de la forme "{66b2af1c-6211-4082-95cb-9f73a4795a7e}".

efi_id_guid_to_guid() traduit un {ID GUID} en un efi_guid_t fourni par l'appelant.

efi_guid_to_symbol() traduit un efi_guid_t en un nom de symbole C unique (dans libefivar). Ces noms de symboles sont utiles pour l'affichage comme identifiant unique et facilement analysable, et sont également fournis par la bibliothèque et ses fichiers d'en-tête.

efi_symbol_to_guid() traduit un nom de symbole efi_guid_$FOO de libefivar en un efi_guid_t fourni par l'appelant.

VALEUR DE RETOUR

efi_variables_supported() renvoie vrai si les variables sont supportées sur le matériel en cours d'exécution, et faux si elles ne le sont pas.

efi_get_next_variable_name() renvoie 0 lorsque l'itération est terminée, 1 lorsque l'itération n'est pas terminée, et -1 en cas d'erreur. En cas d'erreur, errno(3) est définie de manière appropriée.

efi_del_variable(), efi_get_variable(), efi_get_variable_attributes(), efi_get_variable_exists(), efi_get_variable_size(), efi_append_variable(), efi_set_variable(), efi_str_to_guid(), efi_guid_to_str(), efi_name_to_guid(), et efi_guid_to_name() renvoient une valeur négative en cas d'erreur et zéro en cas de succès.
