EFI-READVAR(1) Commandes utilisateur EFI-READVAR(1)

NOM

efi-readvar - outil pour afficher les variables sécurisées

SYNTAXE

efi-readvar: [-v <var>] [-s <liste>[-<entrée>]] [-o <fichier>]

DESCRIPTION

sans arguments, imprime toute la base de données des variables sécurisées et développe le contenu des hachages et des certificats X509. Peut être restreint à des variables spécifiques et des signatures spécifiques dans les variables. Notez que les listes de signatures EFI sont numérotées à partir de zéro et peuvent contenir une ou plusieurs entrées (également numérotées à partir de zéro), donc 0-0 représente la première entrée de la liste de signatures zéro.

Liste le contenu des bases de données de signatures UEFI

OPTIONS

-v <var>
liste uniquement le contenu de <var>
-s <liste>[-<entrée>]
liste uniquement une liste de signatures donnée (et éventuellement
uniquement une entrée donnée dans cette liste
-o <fichier>
sort les listes de signatures demandées dans <fichier>

EXEMPLES

Pour voir toutes les variables, tapez

efi-readvars

Pour voir la deuxième entrée de la liste de signatures 1 pour la variable db, faites

efi-readvars -v db -s 1-1

Pour voir toutes les entrées de la liste de signatures 0 pour la KEK

efi-readvars -v KEK -s 0
