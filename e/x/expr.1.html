EXPR(1) Commandes utilisateur EXPR(1)

NOM

expr - évaluer des expressions

SYNOPIS

expr EXPRESSION
expr OPTION

DESCRIPTION

--help
afficher cette aide et quitter
--version
afficher les informations sur la version et quitter

Imprime la valeur de EXPRESSION sur la sortie standard. Une ligne vide ci-dessous sépare les groupes de précédence croissants. EXPRESSION peut être :

ARG1 | ARG2
ARG1 s'il n'est ni vide ni 0, sinon ARG2
ARG1 & ARG2
ARG1 si aucun des arguments n'est vide ou 0, sinon 0
ARG1 < ARG2
ARG1 est inférieur à ARG2
ARG1 <= ARG2
ARG1 est inférieur ou égal à ARG2
ARG1 = ARG2
ARG1 est égal à ARG2
ARG1 != ARG2
ARG1 est différent de ARG2
ARG1 >= ARG2
ARG1 est supérieur ou égal à ARG2
ARG1 > ARG2
ARG1 est supérieur à ARG2
ARG1 + ARG2
somme arithmétique de ARG1 et ARG2
ARG1 - ARG2
différence arithmétique de ARG1 et ARG2
ARG1 * ARG2
produit arithmétique de ARG1 et ARG2
ARG1 / ARG2
quotient arithmétique de ARG1 divisé par ARG2
ARG1 % ARG2
reste arithmétique de ARG1 divisé par ARG2
CHAINE : REGEXP
correspondance d'ancrage de REGEXP dans CHAINE
match CHAINE REGEXP
identique à CHAINE : REGEXP
substr CHAINE POS LONGUEUR
sous-chaîne de CHAINE, POS compté à partir de 1
index CHAINE CARACTERES
index dans CHAINE où n'importe lequel des CARACTERES est trouvé, ou 0
length CHAINE
longueur de CHAINE
+ JETON
interpréter JETON comme une chaîne, même s'il s'agit d'un mot-clé comme 'match' ou d'un opérateur comme '/'
( EXPRESSION )
valeur de EXPRESSION

Attention, de nombreux opérateurs doivent être échappés ou mis entre guillemets pour les shells. Les comparaisons sont arithmétiques si les deux ARG sont des nombres, sinon lexicographiques. Les correspondances de motifs retournent la chaîne correspondante entre \( et \) ou une chaîne vide ; si \( et \) ne sont pas utilisés, ils retournent le nombre de caractères correspondants ou 0.

Le statut de sortie est 0 si EXPRESSION n'est ni vide ni 0, 1 si EXPRESSION est vide ou 0, 2 si EXPRESSION est syntaxiquement invalide, et 3 si une erreur s'est produite.
