Paquet: perl-extutils-helpers

Licences: PerlArtistic, GPL

ExtUtils::Helpers(3) Documentation Perl contribuée par l'utilisateur ExtUtils::Helpers(3)

NOM

ExtUtils::Helpers - Divers utilitaires de portabilité pour les constructeurs de modules

VERSION

version 0.028

SYNOPSIS

use ExtUtils::Helpers qw/make_executable split_like_shell/;
unshift @ARGV, split_like_shell($ENV{PROGRAM_OPTS});
write_script_to('Build');
make_executable('Build');

DESCRIPTION

Ce module fournit diverses fonctions utilitaires portables pour les modules de construction de modules.

FONCTIONS

make_executable($filename)

Ceci rend un script perl exécutable.

split_like_shell($string)

Cette fonction divise une chaîne de la même manière que le fait la plateforme locale.

detildefy($path)

Cette fonction remplace un tilde au début d'un chemin par le répertoire personnel de l'utilisateur de manière appropriée.

man1_pagename($filename, $ext = $Config{man1ext})

Retourne le nom de fichier de la page de manuel pour un script.

man3_pagename($filename, $basedir = 'lib', $ext = $Config{man3ext})

Retourne le nom de fichier de la page de manuel pour une bibliothèque Perl.

REMERCIEMENTS

Olivier Mengué et Christian Walde ont fait fonctionner "make_executable" sous Windows.
