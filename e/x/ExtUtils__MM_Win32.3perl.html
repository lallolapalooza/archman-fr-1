ExtUtils::MM_Win32(3perl) Guide du programmeur Perl ExtUtils::MM_Win32(3perl)

NOM

ExtUtils::MM_Win32 - méthodes pour remplacer le comportement UN*X dans ExtUtils::MakeMaker

SYNOPIS

use ExtUtils::MM_Win32; # Fait en interne par ExtUtils::MakeMaker si nécessaire

DESCRIPTION

Voir ExtUtils::MM_Unix pour une documentation des méthodes fournies. Ce paquet remplace l'implémentation de ces méthodes, pas la sémantique.

Méthodes remplacées

dlsyms
xs_dlsyms_ext
Sur Win32, est ".def".
replace_manpage_separator
Remplace le séparateur de chemin avec .
maybe_command
Comme Windows n'a rien d'aussi simple qu'un bit exécutable, nous vérifions l'extension de fichier.

La variable d'environnement PATHEXT sera utilisée pour obtenir une liste d'extensions qui pourraient indiquer une commande, sinon .com, .exe, .bat et .cmd seront utilisés par défaut.

init_DIRFILESEP
Utilise \ pour Windows, sauf pour "gmake" où c'est /.
init_tools
Remplace certaines commandes lentes et portables par des commandes spécifiques à Windows.
init_others
Remplace les outils de liaison et de compilation par défaut.

La valeur par défaut de LDLOADLIBS est modifiée en $Config{libs}.

Des ajustements sont faits pour les bizarreries de Borland qui nécessitent que -L vienne en premier.

init_platform
Ajoute MM_Win32_VERSION.
platform_constants
specify_shell
Définit SHELL à $ENV{COMSPEC} uniquement si make est de type 'gmake'.
constants
Ajoute MAXLINELENGTH pour dmake avant que toutes les constantes ne soient affichées.
dep_constants
Crée des dépendances qui fonctionnent pour nmake.
special_targets
Ajoute la cible .USESHELL pour dmake.
static_lib_pure_cmd
Définit comment exécuter l'utilitaire d'archivage
dynamic_lib
Les méthodes sont remplacées ici : pas dynamic_lib lui-même, mais les méthodes utilitaires qui font le travail spécifique au système d'exploitation.
extra_clean_files
Nettoie certains fichiers dll.{base,exp} supplémentaires qui pourraient être générés par gcc. Sinon, supprime tous les fichiers *.pdb.
init_linker
perl_script
Vérifie le programme perl sous plusieurs extensions perl courantes.
quote_dep
xs_obj_opt
Remplacé pour corriger les options -o pour MSVC.
pasthru
Tout ce que nous envoyons est -nologo à nmake pour l'empêcher d'afficher sa fichue bannière.
arch_check (remplacé)
Normalise tous les arguments pour la cohérence de la comparaison.
oneliner
Ceux-ci sont basés sur ce que fait command.com sous Win98. Ils peuvent être erronés pour d'autres shells Windows, je ne sais pas.
cd
dmake peut gérer le cd de style Unix, mais nmake (au moins 1.5) ne peut pas. Il veut : 
cd dir1\dir2
command
another_command
cd ..\..
max_exec_len
nmake 1.50 limite la longueur des commandes à 2048 caractères.
os_flavor
Windows est Win32.
dbgoutflag
Retourne un indicateur CC qui indique au CC de générer un fichier de symboles de débogage séparé lors de la compilation d'un fichier objet.
cflags
Définit le symbole PERLDLL si nous sommes configurés pour une compilation statique car tout le code destiné à la dll perl5xx doit être compilé avec le symbole PERLDLL défini.
make_type
Retourne une chaîne de caractères appropriée décrivant le type de Makefile écrit.
