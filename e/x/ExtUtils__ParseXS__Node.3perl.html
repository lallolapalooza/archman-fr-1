XXX Sept 2024 : ceci est un travail en cours. Cette API est actuellement privée et sujette à modification. La plupart de ParseXS n'utilise pas d'AST, et maintient plutôt juste assez d'état pour générer du code lors de l'analyse. Ce module représente le début d'un effort pour qu'il utilise un AST à la place.

Une classe "ExtUtils::ParseXS::Node", et ses différentes sous-classes, contiennent l'état des nœuds d'un arbre de syntaxe abstraite (AST), qui représente l'état analysé d'un fichier XS.

Chaque nœud est essentiellement une table de hachage de champs. Les noms de champs autorisés varient selon le type de nœud. Les clés et les valeurs de la table de hachage sont accessibles directement : il n'y a pas de méthodes getter/setter.
