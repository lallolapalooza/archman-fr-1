ExtUtils::Typemaps::InputMap(3perl) Guide du programmeur Perl ExtUtils::Typemaps::InputMap(3perl)

NOM

ExtUtils::Typemaps::InputMap - Entrée dans la section INPUT d'une typemap

SYNOPIS

use ExtUtils::Typemaps;
...
my $input = $typemap->get_input_map('T_NV');
my $code = $input->code();
$input->code("...");

DESCRIPTION

Se référer à ExtUtils::Typemaps pour les détails.

MÉTHODES

new

Requiert les paramètres "xstype" et "code".

code

Retourne ou définit le code de mappage INPUT pour cette entrée.

xstype

Retourne le nom du type XS de la carte INPUT.

cleaned_code

Retourne une copie nettoyée du code sur laquelle certaines transformations ont été appliquées pour le rendre plus conforme à l'ANSI.
