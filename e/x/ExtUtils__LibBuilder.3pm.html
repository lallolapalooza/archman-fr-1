ExtUtils__LibBuilder(3pm)

ExtUtils::LibBuilder(3pm) Documentation Perl fournie par l'utilisateur ExtUtils::LibBuilder(3pm)

NOM

ExtUtils::LibBuilder - Un outil pour construire des bibliothèques C.

SYNOPIS

use ExtUtils::LibBuilder;
my $libbuilder = ExtUtils::LibBuilder->new( %options );

MÉTHODES

Prend en charge toutes les méthodes de ExtUtils::CBuilder. Les trois méthodes suivantes ont été adaptées pour être utilisées dans des bibliothèques C autonomes.

new

Cette méthode crée un nouvel objet ExtUtils::LibBuilder. Bien qu'elle prenne en charge toutes les méthodes de "ExtUtils::CBuilder", certaines peuvent fonctionner légèrement différemment (notamment les deux ci-dessous).

Vous pouvez fournir au constructeur toute option reconnue par le constructeur de "ExtUtils::CBuilder". Aucune d'entre elles ne sera utilisée par "LibBuilder".

link

$libbuilder -> link( objects     => [ "foo.o", "bar.o" ],
                     module_name => "foobar",
                     lib_file    => "libfoobar$libbuilder->{libext}");

Les options pour la méthode link sont les mêmes que celles de son homologue "CBuilder". Notez que le résultat est une bibliothèque C autonome et non un paquet à charger par Perl.

Notez également que vous pouvez utiliser la clé "libext" pour récupérer depuis l'objet l'extension de bibliothèque courante sur le système en cours d'exécution (y compris le point).

link_executable

$libbuilder->link_executable( objects => ["main.o"],
                              extra_linker_flags => "-L. -lfoobar",
                              exe_file => "foobarcmd$libbuilder->{exeext}");

La méthode "link_executable" a besoin, en tant qu'options "extra_linker_flags", du nom de la bibliothèque et du chemin de recherche. Les futures versions pourraient inclure une meilleure gestion des fichiers de bibliothèque.

Notez également que vous pouvez utiliser la clé "exeext" pour récupérer depuis l'objet l'extension d'exécutable courante sur le système en cours d'exécution (y compris le point).
