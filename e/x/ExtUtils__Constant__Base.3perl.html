DESCRIPTIO

N

ExtUtils::Constant::Base fournit une implémentation de base de méthodes pour générer du code C permettant une recherche rapide de valeurs constantes par chaîne nommée. Actuellement, elle est principalement utilisée par ExtUtils::Constant::XS, qui génère le code de recherche pour le sous-programme constant() que l'on t

rouve dans de nomb
reux modules XS.

Dans le hashref d'arguments, package est le nom du paquet, et n'est utilisé que dans les commentaires à l'intérieur du code C généré. subname vaut "constant" si

default_type est le type renvoyé par les "ITEM"s qui ne spécifient pas leur type. Il vaut par défaut la valeur de default_type(). types doit être donné soit comme une liste de types séparés par des virgules que la sous-routine C subname générera, soit comme une référence vers un hash. default_type sera ajouté à la liste s'il n'est pas présent, de même que tout type donné dans la liste des ITEMs. La liste résultante doit être la même liste de types que celle donnée à "XS_constant". [Sinon "XS_constant" et "C_constant" peuvent différer dans le nombre de paramètres de la fonction constante. indent est actuellement inutilisé et ignoré. À l'avenir, il pourra être utilisé pour transmettre des informations permettant de modifier le style d'indentation C utilisé.] La meilleure façon de maintenir la cohérence est de passer une référence vers un hash et de laisser cette fonction la mettre à

jour.

breakout contrôle quand les fonctions enfants de subname sont générées. S'il y a breakout ou plus ITEMs avec la même longueur de nom, alors le code pour basculer entre eux est placé dans une fonction nommée subname_len, par exemple "constant_5" pour les noms de 5 caractères de long.
