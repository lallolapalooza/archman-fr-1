NOM

ExtUtils::XSBuilder::ParseSource - analyse les fichiers source C

DESCRIPTION

Pour plus d'informations, voir ExtUtils::XSBuilder

parser_extent (o)

Permet à l'utilisateur d'appeler la méthode Extent ou Replace du parser pour ajouter de nouvelles règles de syntaxe. Ceci est principalement utile pour inclure des expansions de macros du préprocesseur.

pré-traiter (o)

Permet à l'utilisateur de pré-traiter la source avant qu'elle ne soit fournie au parser. Vous pouvez modifier la source, qui est donnée en premier argument, en place.

dossiers_inclusion (o)

Renvoie une référence à la liste des répertoires qui doivent être recherchés pour les fichiers d'inclusion contenant les fonctions, structures, etc. à extraire.

Défaut : '.'

chemins_inclusion (o)

Renvoie une référence à une liste de répertoires qui sont fournis en tant que répertoires d'inclusion au compilateur C. Ceci est principalement utilisé pour supprimer ces répertoires des noms de fichiers afin de convertir les chemins absolus en chemins relatifs.

Défaut : liste vide ("[]")

inclusions_indésirables (o)

Renvoie une référence à une liste de fichiers d'inclusion qui ne doivent pas être traités.

Défaut : liste vide ("[]")

trier_inclusions (o, liste_inclusions)

Reçoit une référence d'array de fichiers d'inclusion, cela permet à l'utilisateur de définir l'ordre de tri, de sorte que les inclusions soient traitées correctement.

Défaut : renvoie la référence d'array passée.

trouver_inclusions (o)

Renvoie une liste de fichiers d'inclusion à traiter.

Défaut : recherche dans les répertoires donnés par "include_dirs" pour tous les fichiers et construit une liste de fichiers d'inclusion. Tous les fichiers commençant par un mot correspondant à "unwanted_includes" ne sont pas inclus dans la liste.

gérer_définir (o)

Reçoit une référence de hash avec la définition d'une directive #define, peut la modifier. Renvoie false pour la supprimer, renvoie true pour la conserver.

Défaut : 1

gérer_énumérer (o)

Reçoit une référence de hash avec la définition d'une valeur enum, peut la modifier. Renvoie false pour la supprimer, renvoie true pour la conserver.

Défaut : 1

gérer_structure (o)

Reçoit une référence de hash avec la définition d'une structure, peut la modifier. Renvoie false pour la supprimer, renvoie true pour la conserver.

Défaut : 1

gérer_fonction (o)

Reçoit une référence de hash avec la définition d'une fonction, peut la modifier. Renvoie false pour la supprimer, renvoie true pour la conserver.

Défaut : 1

gérer_rappel (o)

Reçoit une référence de hash avec la définition d'un callback, peut la modifier. Renvoie false pour la supprimer, renvoie true pour la conserver.

Défaut : 1

paquet (o)

Renvoie le nom du paquet pour les tables.

Défaut : 'MY'

répertoire_cible (o)

Renvoie le nom du répertoire cible où écrire les tables.

Défaut : './xsbuilder/tables'

exécuter

Appelez cette méthode de classe pour analyser votre source. Avant de pouvoir le faire, vous devez fournir une classe qui remplace les défauts de ExtUtils::XSBuilder::ParseSource. Après cela, vous analysez les fichiers source avec

MaClasse -> run ;
