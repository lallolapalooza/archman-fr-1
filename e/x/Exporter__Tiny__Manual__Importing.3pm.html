Beaucoup de ces astuces peuvent sembler familières depuis Sub::Exporter. C'est intentionnel. Exporter::Tiny n'essaie pas de fournir toutes les fonctionnalités de Sub::Exporter, mais là où il le fait,

Importa

de base

Il est facile d'importer une seule fonction depuis un

module :

use MyUtils "frobnicate"; Ou une liste de fonctions : use MyUtils "red", "green"; Le raccourci de Perl qw() pour une liste de mots est assez utile : use MyUtils qw( red green ); Si le module définit des tags, vous pouvez les importer comme ceci : use MyUtils qw( :colours ); Ou avec un tiret au lieu d'un deux-points : use MyUtils qw( -colours ); Les tirets sont pratiques car Perl mettra automatiquement entre guillemets un mot brut qui les suit : use MyUtils -c

olours;

Et il est possible de mélanger des noms de fonctions et des tags dans la même liste

:

use MyUtils qw( frobnicate :colours

);

Désimportatio
n

Vous pouvez désimporter les fonctions que MyUtils a ajoutées à votre espace de noms

Ou seulement des fonctions spécifiques

;

Si vous avez renommé une fonction lorsque vous l'avez importée, vous devriez la désimporter sous le nouveau nom

DIAGNOSTIC
S


  
Remplacement de la sous-routine existante '%s::%s' par la sous-routine '%s' exportée par %
s
  
Un avertissement émis si Exporter::Tiny est demandé d'exporter un symbole qui entraînerait l'écrasement d'une sous-routine existante. Cet avertissement peut être supprimé en utilisant l'une des options suivantes :
        
use MyUtils { replace => 1 }, "frobnicate";
use MyUtils "frobnicate" => { -replace =>
 1 };
    
Ou peut être transformé en erreur 
fatale :
        
use MyUtils { replace => "die" }, "frobnicate";
use MyUtils "frobnicate" => { -replace => 
"die" 
};
  
Refus de remplacer la sous-routine existante '%s::%s' par la sous-routine '%s' exportée par
    %
s
  
La version fatale de l'avertissement 
ci-dessus.
  
Impossible de trouver la sous-routine '%s' exportée par %
s
  
Vous avez demandé d'importer une sous-routine que le le paquet ne fournit pas.

  
Impossible de fournir une option -as
    pour les tags

  
Étant donné qu'un tag peut fournir plus d'une fonction, il n'a pas de sens
      de demander un seul nom pour lui. Utilisez plutôt
      "-prefix" ou
      "-suffix".

  
Passer des options à
    unimport '%s' n'a pas de sens

  
Lorsque vous importez un sub, il arrive qu'il soit judicieux de lui passer
      certaines options. Cependant, lors de la désimportation, les options n'ont
      aucun effet ; cet avertissement est donc émis.
