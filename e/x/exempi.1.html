exempi(1) Manuel des commandes générales exempi(1)

NOM

exempi - outil en ligne de commande pour manipuler les métadonnées XMP

SYNTAXE

exempi { -h | [ -R ] [ -X ] [ -x [ -p ] ] [ { -w | -o <fichier> } ] [ { -g <nom_prop> | -s <nom_prop> -v <valeur> } ] } <fichiers>

OPTIONS

-h : afficher cette aide
-R : ne pas réconcilier
-x : afficher le XML
-p : encapsuler le paquet XML. Seulement pour -x.
-X : le(s) fichier(s) est (sont) XMP
-w : écrire sur place. Seulement pour -s. Non compatible avec -o.
-o <fichier> : fichier où écrire la sortie.
-n <ns> <préfix> : définir le préfixe pour un espace de noms.
-g <nom_prop> : récupérer la valeur avec nom_prop.
-s <nom_prop> -v <valeur> : récupérer ou définir la valeur.
<fichiers> les fichiers à lire.

SÉCURITÉ

Le code source n'a pas été audité pour la sécurité. L'outil en ligne de commande ne dispose pas d'une vérification d'entrée robuste plus facile.

Faites attention à ne pas exécuter l'outil en tant que super-utilisateur. Soyez prudent si vous décidez de l'utiliser dans une application en ligne (web).

Les correctifs et suggestions sont les bienvenus.
