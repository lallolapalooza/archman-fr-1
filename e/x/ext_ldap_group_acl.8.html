NOM

ext_ldap_group_acl - Assistant externe ACL de groupe LDAP pour Squid

Version 2.18

SYNTAXE

ext_ldap_group_acl -b base-DN -f filtre [ options ] [ serveur [ ':' port ] | URI ] ...

DESCRIPTION

ext_ldap_group_acl permet à Squid de se connecter à un annuaire LDAP pour autoriser les utilisateurs via des groupes LDAP. Les options LDAP sont spécifiées en tant que paramètres sur la ligne de commande, tandis que le(s) nom(s) d'utilisateur et le(s) groupe(s) à vérifier par rapport à l'annuaire LDAP sont spécifiés sur des lignes d'entrée ultérieures pour l'assistant, une paire nom d'utilisateur/groupe par ligne, séparée par un espace.

Comme attendu par la construction external_acl_type de Squid, après avoir spécifié un nom d'utilisateur et un groupe suivis d'une nouvelle ligne, cet assistant produira soit OK soit ERR sur la ligne suivante pour indiquer si l'utilisateur est membre du groupe spécifié.

Le programme fonctionne en effectuant une recherche avec un filtre de recherche basé sur le nom d'utilisateur et le groupe demandé, et si une correspondance est trouvée, il est déterminé que l'utilisateur appartient au groupe.

OPTIONS

-a jamais|toujours|recherche|trouver
Quand déréférencer les alias. Par défaut 'jamais'
jamais déréférencer les alias (par défaut), toujours déréférencer les alias, uniquement lors d'une recherche ou uniquement pour trouver l'objet de base
-b basedn
REQUIS. Spécifie le DN de base sous lequel les groupes sont situés.
-B basedn
Spécifie le DN de base sous lequel les utilisateurs sont situés (si différent)
-c timeoutconnexion
Spécifie le timeout utilisé lors de la connexion aux serveurs LDAP (nécessite les bibliothèques d'API LDAP Netscape)
-d
Mode débogage où chaque étape sera signalée en détail. Utile pour comprendre ce qui ne va pas si le résultat n'est pas celui attendu.
-D binddn -w motdepasse
Le DN et le mot de passe pour se lier lors de l'exécution des recherches. Requis si l'annuaire LDAP n'autorise pas les recherches anonymes.
Comme le mot de passe doit être imprimé en texte clair dans votre configuration Squid et sera envoyé sur la ligne de commande à l'assistant, il est fortement recommandé d'utiliser un compte avec des privilèges minimaux associés. Ceci afin de limiter les dégâts si quelqu'un parvenait à obtenir une copie de votre fichier de configuration Squid ou à extraire le mot de passe utilisé à partir d'une liste de processus.
-D binddn -W fichiersecret
Le DN et le nom d'un fichier contenant le mot de passe pour se lier lors de l'exécution des recherches.
Version moins insécurisée des deux paires de paramètres précédentes avec deux avantages : Le mot de passe n'apparaît pas dans la liste des processus, et le mot de passe n'est pas compromis si quelqu'un obtient le fichier de configuration de Squid sans obtenir le fichier secret.
-E chemincertificat
Activer LDAP sur SSL (nécessite les bibliothèques d'API LDAP Netscape)
-f filtre
Filtre de recherche LDAP utilisé pour rechercher dans l'annuaire LDAP toute adhésion à un groupe correspondante. Dans le filtre, %u sera remplacé par le nom d'utilisateur (ou le DN si les options -F ou -u sont utilisées) et %g par le nom du groupe demandé.
-F filtre
Filtre de recherche LDAP utilisé pour rechercher dans l'annuaire LDAP tout utilisateur correspondant. Dans le filtre, %s sera remplacé par le nom d'utilisateur. Si % doit être inclus littéralement dans le filtre, utilisez %%
-g
Spécifie que le premier argument de requête envoyé à l'assistant par Squid est une extension du basedn et sera temporairement ajouté devant le basedn global pour cette requête.
-h serveurldap
Spécifie le serveur LDAP à contacter
-H urildap
Spécifie le serveur LDAP à contacter via une URI LDAP (nécessite les bibliothèques OpenLDAP)
-K
Supprime le composant de royaume Kerberos des noms d'utilisateur (séparés par @)
-p portldap
Spécifie un port TCP alternatif où le serveur LDAP écoute si différent du port LDAP par défaut 389.
-P
Utiliser une connexion LDAP persistante. Normalement, la connexion LDAP n'est ouverte que lors de la vérification de l'appartenance d'un utilisateur à un groupe pour préserver les ressources du serveur LDAP. Cette option maintient la connexion LDAP ouverte, permettant sa réutilisation pour d'autres validations d'utilisateurs. Recommandé pour les installations plus importantes.
-R
Ne pas suivre les références
-s base|un|sous
Portée de la recherche. Par défaut sous
objet base uniquement,
un niveau en dessous de l'objet de base ou
arbre sous en dessous de l'objet de base
-S
Supprime le composant de nom de domaine NT des noms d'utilisateur (séparés par / ou \)
-t timeoutrecherche
Spécifie la limite de temps pour les opérations de recherche LDAP
-u attr
Attribut LDAP utilisé pour construire le DN de l'utilisateur à partir du nom d'utilisateur et du DN de base sans avoir à rechercher l'utilisateur. Un maximum de 16 occurrences de %s sont supportées.
-v 2|3
Version du protocole LDAP. Par défaut 3 si non spécifié.
-Z
Utiliser le chiffrement TLS

CONFIGURATION

Cet assistant est destiné à être utilisé comme assistant external_acl_type dans squid.conf.

external_acl_type ldap_group %LOGIN /chemin/vers/ext_ldap_group_acl ...
acl group1 external ldap_group Groupe1
acl group2 external ldap_group Groupe2

NOTE : Lors de la construction des filtres de recherche, il est recommandé de tester d'abord le filtre en utilisant ldapsearch pour vérifier que le filtre correspond à ce que vous attendez avant de tenter d'utiliser ext_ldap_group_acl
