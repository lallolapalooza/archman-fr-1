EXIT_SUCCESS(3const) EXIT_SUCCESS(3const)

NOM

EXIT_SUCCESS, EXIT_FAILURE — constantes d'état de terminaison

BIBLIOTHÈQUE

Bibliothèque C standard (libc)

SYNTAXE

#include <stdlib.h>
#define EXIT_SUCCESS  0
#define EXIT_FAILURE  /* non nul */

DESCRIPTION

EXIT_SUCCESS et EXIT_FAILURE représentent respectivement un statut de sortie réussi et non réussi, et peuvent être utilisés comme arguments de la fonction exit(3).

NORMES

C11, POSIX.1-2024.

HISTORIQUE

C89, POSIX.1-2001.

EXEMPLES

#include <stdio.h>
#include <stdlib.h>
int
main(int argc, char *argv[])
{
    FILE *fp;
    if (argc != 2) {
        fprintf(stderr, "Usage: %s <fichier>\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    fp = fopen(argv[1], "r");
    if (fp == NULL) {
        perror(argv[1]);
        exit(EXIT_FAILURE);
    }
    /* Autre code omis */
    fclose(fp);
    exit(EXIT_SUCCESS);
}

VOIR AUSSI

exit(3), sysexits.h(3head)
