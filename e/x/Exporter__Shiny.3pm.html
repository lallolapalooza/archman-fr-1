NOM

Exporter::Shiny - raccourci pour Exporter::Tiny

SYNOPIS

use Exporter::Shiny qw( foo bar );

Est un raccourci pour :

use base "Exporter::Tiny";
push our(@EXPORT_OK), qw( foo bar );

Pour la compatibilité avec Sub::Exporter, la syntaxe plus longue suivante est également prise en charge :

use Exporter::Shiny -setup => {
   exports => [qw( foo bar )],
};

DESCRIPTION

Ceci est un petit wrapper pour simplifier l'utilisation d'Exporter::Tiny.

Il fait les choses suivantes :

  • Marque votre paquet comme chargé dans %INC ;
  • Pousse tous les noms de fonctions dans la liste d'importation vers votre @EXPORT_OK ; et
  • Pousse "Exporter::Tiny" vers votre @ISA.

Il ne configure pas %EXPORT_TAGS ou @EXPORT, mais rien ne vous empêche de le faire vous-même.
