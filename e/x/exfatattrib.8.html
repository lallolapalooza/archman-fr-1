NOM

exfatattrib - Définir ou afficher les attributs de fichiers exFAT

SYNTAXE

exfatattrib [ -r | -R | -i | -I | -s | -S | -a | -A ] -d périphérique fichier

DESCRIPTION

exfatattrib définit ou affiche les attributs d'un fichier sur un système de fichiers exFAT.

périphérique est le chemin d'accès à une partition de disque non montée ou à un fichier image disque contenant un système de fichiers exFAT.

fichier est le chemin d'accès à un fichier dans ce système de fichiers.

S'il est exécuté sans options en ligne de commande, les attributs actuels du fichier sont affichés ; sinon, les attributs spécifiés sont définis ou effacés. Il est erroné de définir et d'effacer le même drapeau.

OPTIONS DE LIGNE DE COMMANDE

Options de ligne de commande disponibles :

-d périphérique
Le chemin d'accès à une partition de disque non montée ou à un fichier image disque contenant un système de fichiers exFAT. Cette option est requise.
-r
Définir le drapeau lecture seule
-R
Effacer le drapeau lecture seule
-i
Définir le drapeau caché (mnémonique : invisible)
-I
Effacer le drapeau caché
-s
Définir le drapeau système
-S
Effacer le drapeau système
-a
Définir le drapeau archive
-A
Effacer le drapeau archive
-h
Afficher ce message d'aide
-V
Afficher la version et le copyright.

CODES DE SORTIE

Zéro est retourné si aucune erreur n'est trouvée. Tout autre code signifie une erreur.
