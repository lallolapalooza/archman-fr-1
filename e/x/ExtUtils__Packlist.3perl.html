ExtUtils::Packlist(3perl) Guide du programmeur Perl ExtUtils::Packlist(3perl)

NOM

ExtUtils::Packlist - gérer les fichiers .packlist

SYNOPSIS

use ExtUtils::Packlist;
my ($pl) = ExtUtils::Packlist->new('.packlist');
$pl->read('/an/old/.packlist');
my @missing_files = $pl->validate();
$pl->write('/a/new/.packlist');
$pl->{'/some/file/name'}++;
   ou
$pl->{'/some/file/name'} = { type => 'file',
                                   from => '/some/file' };

DESCRIPTION

ExtUtils::Packlist fournit une manière standard de gérer les fichiers .packlist. Des fonctions sont fournies pour lire et écrire les fichiers .packlist. Le format original .packlist est une simple liste de noms de chemin absolus, un par ligne. En outre, ce paquet supporte un format étendu, où en plus d'un nom de fichier, chaque ligne peut contenir une liste d'attributs sous la forme d'une liste séparée par des espaces de paires clé=valeur. Ceci est utilisé par le script installperl pour différencier entre les fichiers et les liens, par exemple.

UTILISATION

La référence de hachage retournée par la fonction new() peut être utilisée pour examiner et modifier le contenu du .packlist. Des éléments peuvent être ajoutés/supprimés du .packlist en modifiant le hachage. Si la valeur associée à une clé de hachage est un scalaire, l'entrée écrite dans le .packlist par une éventuelle future fonction write() sera un simple nom de fichier. Si la valeur est un hachage, l'entrée écrite sera le nom de fichier suivi des paires clé=valeur du hachage. La lecture du .packlist recréera les entrées originales.

FONCTIONS

new()
Ceci prend un paramètre optionnel, le nom d'un .packlist. Si le fichier existe, il sera ouvert et le contenu du fichier sera lu. La méthode new() retourne une référence vers un hachage. Ce hachage contient une entrée pour chaque ligne du .packlist. Dans le cas des .packlists de style ancien, la valeur associée à chaque clé est indéfinie. Dans le cas des .packlists de style nouveau, la valeur associée à chaque clé est un hachage contenant les paires clé=valeur suivant le nom de fichier dans le .packlist.
read()
Ceci prend un paramètre optionnel, le nom du .packlist à lire. Si aucun fichier n'est spécifié, le .packlist spécifié à new() sera lu. Si le .packlist n'existe pas, Carp::croak sera appelé.
write()
Ceci prend un paramètre optionnel, le nom du .packlist à écrire. Si aucun fichier n'est spécifié, le .packlist spécifié à new() sera écrasé.
validate()
Ceci vérifie que chaque fichier listé dans le .packlist existe réellement. Si un argument qui s'évalue à vrai est donné, les fichiers manquants seront supprimés du hachage interne. La valeur de retour est une liste des fichiers manquants, qui sera vide s'ils existent tous.
packlist_file()
Ceci retourne le nom du fichier .packlist associé.

EXEMPLE

Voici "modrm", un petit utilitaire pour supprimer proprement un module installé.

#!/usr/local/bin/perl -w
use strict;
use IO::Dir;
use ExtUtils::Packlist;
use ExtUtils::Installed;
sub emptydir($) {
    my ($dir) = @_;
    my $dh = IO::Dir->new($dir) || return(0);
    my @count = $dh->read();
    $dh->close();
    return(@count == 2 ? 1 : 0);
}
# Trouver tous les paquets installés
print("Finding all installed modules...\n");
my $installed = ExtUtils::Installed->new();
foreach my $module (grep(!/^Perl$/, $installed->modules())) {
   my $version = $installed->version($module) || "???";
   print("Found module $module Version $version\n");
   print("Do you want to delete $module? [n] ");
   my $r = <STDIN>; chomp($r);
   if ($r && $r =~ /^y/i) {
      # Supprimer tous les fichiers
      foreach my $file (sort($installed->files($module))) {
         print("rm $file\n");
         unlink($file);
      }
      my $pf = $installed->packlist($module)->packlist_file();
      print("rm $pf\n");
      unlink($pf);
      foreach my $dir (sort($installed->directory_tree($module))) {
         if (emptydir($dir)) {
            print("rmdir $dir\n");
            rmdir($dir);
         }
      }
   }
}
