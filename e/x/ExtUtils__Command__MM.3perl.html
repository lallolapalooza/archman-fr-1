ExtUtils::Command::MM(3perl) Guide du programmeur Perl ExtUtils::Command::MM(3perl)

NOM

ExtUtils::Command::MM - Commandes pour que les MM les utilisent dans les Makefiles

SYNOPSIS

perl "-MExtUtils::Command::MM" -e "fonction" "--" arguments...

DESCRIPTION

POUR USAGE INTERNE SEULEMENT ! L'interface n'est pas stable.

ExtUtils::Command::MM encapsule du code qui devrait autrement être fait avec de grands "one liners".

Tout $(FOO) utilisé dans les exemples sont des variables make, pas Perl.

test_harness
test_harness($verbose, @test_libs);

Exécute les tests sur @ARGV via Test::Harness en passant le flag $verbose. Tout @test_libs sera décalé au début du @INC des tests.

@test_libs sont exécutés par ordre alphabétique.

pod2man
pod2man( '--option=valeur',
         $podfile1 => $manpage1,
         $podfile2 => $manpage2,
         ...
       );
# ou arguments sur @ARGV

pod2man() est une fonction effectuant la plupart des tâches du programme pod2man. Ses arguments sont exactement les mêmes que pod2man à partir de la version 5.8.0, avec l'ajout de :

--perm_rw   permission octale à attribuer à la page de manuel résultante

Et la suppression de :

--verbose/-v
--help/-h

Si aucun argument n'est donné à pod2man, il lira depuis @ARGV.

Si Pod::Man n'est pas disponible, cette fonction avertira et retournera undef.

warn_if_old_packlist
perl "-MExtUtils::Command::MM" -e warn_if_old_packlist <nomfichier>

Affiche un avertissement qu'un ancien fichier packlist a été trouvé. Lit le nom du fichier depuis @ARGV.

perllocal_install
perl "-MExtUtils::Command::MM" -e perllocal_install
    <type> <nom module> <clé> <valeur> ...
# VMS seulement, paires clé|valeur viennent sur STDIN
perl "-MExtUtils::Command::MM" -e perllocal_install
    <type> <nom module> < <clé>|<valeur> ...

Imprime un fragment de POD adapté pour être ajouté à perllocal.pod. Les arguments sont lus depuis @ARGV.

'type' est le type de ce que vous installez. Généralement 'Module'.

'nom module' est simplement le nom de votre module. (Foo::Bar)

Les paires clé/valeur sont des informations supplémentaires sur le module. Les champs incluent :

installed into      dans quel répertoire votre module a été installé
LINKTYPE            lien dynamique ou statique
VERSION             numéro de version du module
EXE_FILES           tous les exécutables installés dans une liste
                    séparée par des espaces
uninstall
perl "-MExtUtils::Command::MM" -e uninstall <packlist>

Un wrapper autour de ExtUtils::Install::uninstall(). Avertit que la désinstallation est dépréciée et n'effectue pas réellement la désinstallation.

test_s
perl "-MExtUtils::Command::MM" -e test_s <fichier>

Teste si un fichier existe et n'est pas vide (taille > 0). *Sort* avec 0 s'il existe, 1 sinon.

cp_nonempty
perl "-MExtUtils::Command::MM" -e cp_nonempty <srcfile> <dstfile> <perm>

Teste si le fichier source existe et n'est pas vide (taille > 0). S'il n'est pas vide, il le copie vers la destination donnée avec les permissions données.
