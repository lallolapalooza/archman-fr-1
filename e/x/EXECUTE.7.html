NOM

EXECUTE - exécuter une instruction préparée

SYNTAXE

EXECUTE nom [ ( paramètre [, ...] ) ]

DESCRIPTION

EXECUTE est utilisé pour exécuter une instruction préparée précédemment. Étant donné que les instructions préparées n'existent que pendant la durée d'une session, l'instruction préparée doit avoir été créée par une instruction PREPARE exécutée plus tôt dans la session actuelle.

Si l'instruction PREPARE qui a créé l'instruction spécifiait des paramètres, un ensemble compatible de paramètres doit être passé à l'instruction EXECUTE, sinon une erreur est levée. Notez que (contrairement aux fonctions) les instructions préparées ne sont pas surchargées en fonction du type ou du nombre de leurs paramètres ; le nom d'une instruction préparée doit être unique au sein d'une session de base de données.

Pour plus d'informations sur la création et l'utilisation des instructions préparées, voir PREPARE(7).

PARAMETRES

nom

Le nom de l'instruction préparée à exécuter.

paramètre

La valeur réelle d'un paramètre pour l'instruction préparée. Cela doit être une expression produisant une valeur compatible avec le type de données de ce paramètre, tel que déterminé lors de la création de l'instruction préparée.

SORTIES

La balise de commande renvoyée par EXECUTE est celle de l'instruction préparée, et non EXECUTE.

EXEMPLES

Les exemples se trouvent dans les Exemples de la documentation PREPARE(7).

COMPATIBILITE

La norme SQL inclut une instruction EXECUTE, mais elle est uniquement destinée à être utilisée dans le SQL embarqué. Cette version de l'instruction EXECUTE utilise également une syntaxe quelque peu différente.

VOIR AUSSI
