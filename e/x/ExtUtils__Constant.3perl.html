DESCRIPTIO

N

ExtUtils::Constant facilite la génération de code wrapper C et XS pour permettre aux modules perl de faire AUTOLOAD de constantes définies dans des fichiers d'en-tête de bibliothèque C. Il est principalement utilisé par l'utilitaire "h2xs", sur lequel ce code est basé. Il ne contient pas les routines

pour scanner les fichiers d'en-
tête afin d'extraire ces constantes.
