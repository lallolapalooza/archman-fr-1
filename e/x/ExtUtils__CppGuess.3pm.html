DESCRIPTIO

N

"ExtUtils::CppGuess" tente de deviner le compilateur C++ du système qui est compatible avec le compilateur C avec lequel votre perl a été

construit.

Il peut générer les options nécessaires pour le constructeur de Module::Build ou pour la fonction "WriteMakefile" d'E

xtUtils::
MakeMaker.

ENVIRONNEMEN

T

Depuis la version 0.24, la variable d'environnement "CXX" définit la valeur évidente, et sera utilisée au lieu de toute

détection. Les arguments fournis à "n
ew" auront toujours la priorité.

MÉTHODE

S

ne

w

Crée un nouvel objet "ExtUtils::CppGuess". Prend le chemin vers le compilateur C comme argument "cc", mais utilise la valeur de $Config{cc} en cas d'échec, ce qui devrait être ce que vous voulez de toute

façon.

Vous pouvez spécifier "extra_compiler_flags" et "extra_linker_flags" (sous forme de chaînes) qui seront fusionnés avec ceux détectés

automatiquement
.

module_build_option

s

Retourne les options correctes pour le constructeur de "Module::Build". Ce sont

: 
extra_compiler_flags
extra_linker_flags
config => { cc => ... }, # depuis 0.
15

Veuillez noter que ce qui précède peut poser des problèmes

sur Perl <= 5.8 avec ExtUtils::CBuilder <= 0.280230 en
raison d'un problème avec les expressions régulières Perl.

makemaker_option

s

Retourne les options correctes pour la fonction "WriteMakefile" de "ExtUtils::MakeMaker". Ce sont

: 
CCFLAGS
dynamic_lib => { OTHERLDFLAGS => ... }
CC # depuis 0.
15

Si vous spécifiez les options de compilateur ou de liaison supplémentaires dans le constructeur, elles seront fusionnées dans "CCFLAGS" ou "OTHERLDFLAGS"

respect
ivement.

iostream_fnam

e

Retourne le nom de fichier à "#include" pour obtenir la fonctionnalité

iostream.

Cela peut être utilisé de manière un peu créative pour assurer la portabilité dans vos fichiers XS, comme les tests de ce module en ont besoin

# dans Makefile.PL :
$guess->add_extra_compiler_flags(
  '-DINCLUDE_DOT=' .
  ($guess->iostream_fname =~ /\./ ? 1 : 0)
);
// dans votre fichier .xs :
#if INCLUDE_DOT
#include <string.h>
#else
#include <string>
#endif

cpp_flavor_def

s

Retourne le texte pour un en-tête qui "#define" "__INLINE_CPP_STANDARD_HEADERS" et "__INLINE_CPP_NAMESPACE_STD" si les en-têtes standard et l'espace de noms sont disponibles. Cela est déterminé en essayant de compiler du C++ avec "#define <iostream>" - si cela réussit, les symboles seront définis, sinon

commentés.
