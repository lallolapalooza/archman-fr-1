NOM

ExtUtils::Config - Un wrapper pour la configuration de perl

VERSION

version 0.010

SYNOPSIS

my $config = ExtUtils::Config->new();
$config->get('installsitelib');

DESCRIPTION

ExtUtils::Config est une abstraction autour du hachage %Config. En soi, ce n'est pas un module particulièrement intéressant, mais il relie une famille de modules d'outils modernes.

MÉTHODES

new(\%config)

Crée un nouvel objet ExtUtils::Config. Les valeurs de "\%config" sont utilisées pour initialiser l'objet.

get($key)

Obtient la valeur de $key. Si elle n'est pas remplacée, elle renverra la valeur dans %Config.

exists($key)

Teste l'existence de $key.

but(\%keys)

Crée un nouvel objet "ExtUtils::Config" basé sur l'objet actuel, mais avec les valeurs de %keys remplaçant les valeurs actuelles. Une valeur indéfinie signifie qu'elle sera supprimée de l'ensemble remplacé.

values_set()

Obtient un hashref de toutes les valeurs remplacées.

all_config()

Obtient un hashref de la configuration complète, y compris les remplacements.

serialize()

Cette méthode sérialise l'objet dans une sorte de chaîne. Cela peut être utile à diverses fins de mise en cache.
