ExtUtils::MM_NW5(3perl) Guide du programmeur Perl ExtUtils::MM_NW5(3perl)

NOM

ExtUtils::MM_NW5 - méthodes pour remplacer le comportement UN*X dans ExtUtils::MakeMaker

SYNOPSIS

use ExtUtils::MM_NW5; # Fait en interne par ExtUtils::MakeMaker si nécessaire

DESCRIPTION

Voir ExtUtils::MM_Unix pour la documentation des méthodes fournies là-bas. Ce paquet remplace l'implémentation de ces méthodes, pas la sémantique.

os_flavor
Nous sommes Netware en plus d'être Windows.
init_platform
Ajouter les macros Netware.

LIBPTH, BASE_IMPORT, NLM_VERSION, MPKTOOL, TOOLPATH, BOOT_SYMBOL, NLM_SHORT_NAME, INCLUDE, PATH, MM_NW5_REVISION

platform_constants
Ajouter les macros Netware initialisées ci-dessus au Makefile.
static_lib_pure_cmd
Définit comment exécuter l'utilitaire d'archivage
xs_static_lib_is_xs
dynamic_lib
Remplacement des méthodes utilitaires pour le travail spécifique à l'OS.
