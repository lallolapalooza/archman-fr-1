FBB::Exec(3bobcat) Exécution de processus enfants FBB::Exec(3bobcat)

NOM

FBB::Exec - Exécute des programmes externes

SYNOPSIS

#include <bobcat/exec>
Option de liaison : -lbobcat

DESCRIPTION

La classe FBB::Exec offre une interface de base pour appeler des programmes externes (les soi-disant processus enfants). Les flux standard des processus enfants ne sont pas gérés par les objets Exec : le processus enfant utilise les flux standard du parent. La variable d'environnement PATH n'est pas utilisée lors de l'appel des processus enfants : les programmes des processus enfants doivent être spécifiés à l'aide de chemins.

Les objets Exec peuvent être utilisés à plusieurs reprises pour exécuter le même ou différents processus enfants. Avant de démarrer le processus enfant suivant, le processus enfant courant doit avoir terminé.

Les arguments passés aux processus enfants peuvent être entourés de guillemets doubles ou simples. Les arguments entourés de guillemets doubles ont leurs guillemets doubles supprimés, tout en interprétant les séquences d'échappement qui ont pu être utilisées à l'intérieur. Les arguments entourés de guillemets simples ont leurs guillemets simples supprimés, tout en acceptant leur contenu tel quel. De plus, des séquences d'échappement non quotées peuvent être spécifiées : ces séquences d'échappement sont évaluées et remplacées par les caractères qu'elles représentent (par exemple, \100 est converti en @).

ESPACE DE NOMS

FBB
Tous les constructeurs, membres, opérateurs et manipulateurs mentionnés dans cette page manuel sont définis dans l'espace de noms FBB.

HÉRITE DE

FBB::Fork

CONSTRUCTEUR

Seul le constructeur par défaut est pris en charge.

MEMBRES

o
bool execute(std::string const &cmd):
L'argument spécifie la commande à exécuter : la commande elle-même doit être spécifiée sous forme de chemin (la variable d'environnement PATH n'est pas utilisée). Le membre retourne true si la valeur de sortie du processus enfant est égale à 0. Sinon, false est retourné. Une fois que execute a retourné, il peut être rappelé, soit avec la même soit avec une autre commande. La classe Exec n'offre pas de mécanisme pour terminer de force les processus enfants : les processus parents sont suspendus jusqu'à ce que les processus enfants aient terminé. Les arguments passés au programme à exécuter en tant que processus enfant peuvent éventuellement être spécifiés à l'aide de guillemets simples ou doubles, comme décrit dans la section DESCRIPTION de cette page manuel.
o
int ret() const:
Une fois que execute a retourné, ce membre fournit le code de sortie réel du processus enfant. Sa valeur est égale à -1 avant le premier appel à execute .

EXEMPLE

#include <iostream>
#include <bobcat/execfork>
using namespace std;
using namespace FBB;
int main()
{
    ExecFork ef;
    if (ef.execute("/bin/cp driver.cc /tmp"))
        cout << "driver.cc now copied to /tmp\n";
    else
        cout << "could not copy driver.cc to /tmp\n";
    cout << "Again:\n";
    if (ef.execute("/bin/cp driver.cc /tmp"))
        cout << "driver.cc now copied to /tmp\n";
    else
        cout << "could not copy driver.cc to /tmp\n";
}
