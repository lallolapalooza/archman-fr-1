NOM

ext_kerberos_sid_group_acl - aide ACL externe pour Squid afin de vérifier l'appartenance aux groupes du domaine AD à l'aide de sid.

SYNTAXE

ext_kerberos_sid_group_acl [-d] [-h] -p Nom Principal -D Contrôleur de Domaine -b DN de base -G Groupe1:Groupe2

DESCRIPTION

ext_kerberos_sid_group_acl est un script exécutable installé. Il utilise ldapsearch d'OpenLDAP pour rechercher le nom d'un SID de groupe AD.

Cette aide doit être utilisée avec l'aide negotiate_kerberos_auth dans un environnement Microsoft AD ou Samba.

Il lit depuis l'entrée standard le nom d'utilisateur du domaine et une liste de SIDs de groupe et essaie de faire correspondre les SIDs de groupe aux SIDs de groupe AD.

OPTIONS

-d
Écrit les informations de débogage dans stderr.
-h
Affiche l'aide.
-p nom principal
Nom principal dans le fichier keytab de Squid à utiliser pour l'authentification LDAP auprès d'AD
-D contrôleur de domaine
Contrôleur de domaine à contacter pour rechercher le SID du groupe
-b DN de base
DN de base pour la recherche LDAP
-G nom du groupe AD
Nom du groupe AD à utiliser pour la recherche de SID. Liste séparée par un deux-points (:)

CONFIGURATION

auth_param negotiate program /chemin/vers/negotiate_wrapper_auth -d \
     --ntlm /chemin/vers/ntlm_auth --helper-protocol=squid-2.5-ntlmssp --domain exemple.com \
     --kerberos /chemin/vers/negotiate_kerberos_auth -d -s GSS_C_NO_NAME -k /chemin/vers/squid.keytab -t none
external_acl_type sid_check %LOGIN %note{group} /chemin/vers/kerberos_sid_group_acl -p principal -D dc1.exemple.com -b "DC=exemple,DC=com" -G Groupe1:Groupe2
acl squid_allow external sid_check
acl allowed_group external sid_check
http_access allow allowed_group

Si l'interpréteur Perl local se trouve dans un emplacement inhabituel, il peut être nécessaire de l'ajouter :

external_acl_type sid_check %LOGIN %note{group} /chemin/vers/perl /chemin/vers/kerberos_sid_group_acl -p principal -D dc1.exemple.com -b "DC=exemple,DC=com" -G Groupe1:Groupe2
