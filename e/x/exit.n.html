NOM

exit - Terminer l'application

SYNOPSIS

exit ?code_retour?

DESCRIPTION

Termine le processus, retournant code_retour au système en tant que statut de sortie. Si code_retour n'est pas spécifié, il est par défaut à 0.

EXEMPLE

Étant donné que les codes de sortie non nuls sont généralement interprétés comme des cas d'erreur par le processus appelant, la commande exit est une partie importante pour signaler qu'un problème fatal s'est produit. Ce fragment de code est utile dans les scripts pour servir de piège général aux problèmes :

proc main {} {
    # ... mettre le vrai code principal ici ...
}
if {[catch {main} msg options]} {
    puts stderr "erreur de script inattendue : $msg"
    if {[info exists env(DEBUG)]} {
        puts stderr "---- DÉBUT DE LA TRACE ----"
        puts stderr [dict get $options -errorinfo]
        puts stderr "---- FIN DE LA TRACE ----"
    }
    # Réserver le code 1 pour les sorties d'erreur "attendues"...
    exit 2
}
