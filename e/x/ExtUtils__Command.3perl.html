ExtUtils::Command(3perl) Guide du programmeur Perl ExtUtils::Command(3perl)

NOM

ExtUtils::Command - utilitaires pour remplacer les commandes UNIX courantes dans les Makefiles, etc.

SYNTAXE

perl -MExtUtils::Command -e cat fichiers... > destination
perl -MExtUtils::Command -e mv source... destination
perl -MExtUtils::Command -e cp source... destination
perl -MExtUtils::Command -e touch fichiers...
perl -MExtUtils::Command -e rm_f fichiers...
perl -MExtUtils::Command -e rm_rf répertoires...
perl -MExtUtils::Command -e mkpath répertoires...
perl -MExtUtils::Command -e eqtime source destination
perl -MExtUtils::Command -e test_f fichier
perl -MExtUtils::Command -e test_d répertoire
perl -MExtUtils::Command -e chmod mode fichiers...
...

DESCRIPTION

Ce module est utilisé pour remplacer les commandes UNIX courantes. Dans tous les cas, les fonctions travaillent à partir de @ARGV plutôt que de prendre des arguments. Cela les rend plus faciles à gérer dans les Makefiles. Appelez-les comme suit :

perl -MExtUtils::Command -e une_commande des fichiers à traiter

Et *PAS* comme ceci :

perl -MExtUtils::Command -e 'une_commande qw(des fichiers à traiter)'

Pour cela, utilisez Shell::Command.

Les noms de fichiers contenant * et ? seront développés par glob.

FONCTIONS

cat
cat fichier ...

Concatène tous les fichiers mentionnés sur la ligne de commande vers STDOUT.

eqtime
eqtime source destination

Définit l'heure de modification de la destination à celle de la source.

rm_rf
rm_rf fichiers ou répertoires ...

Supprime les fichiers et les répertoires - récursivement (même s'ils sont en lecture seule).

rm_f
rm_f fichier ...

Supprime les fichiers (même s'ils sont en lecture seule).

touch
touch fichier ...

Fait exister les fichiers, avec le timestamp actuel.

mv
mv fichier_source fichier_destination
mv fichier_source fichier_source répertoire_destination

Déplace la source vers la destination. Plusieurs sources sont autorisées si la destination est un répertoire existant.

Retourne vrai si tous les déplacements ont réussi, faux sinon.

cp
cp fichier_source fichier_destination
cp fichier_source fichier_source répertoire_destination

Copie les sources vers la destination. Plusieurs sources sont autorisées si la destination est un répertoire existant.

Retourne vrai si toutes les copies ont réussi, faux sinon.

chmod
chmod mode fichiers ...

Définit les permissions de type UNIX 'mode' sur tous les fichiers. par ex. 0666.

mkpath
mkpath répertoire ...

Crée les répertoires, y compris les répertoires parents.

test_f
test_f fichier

Teste si un fichier existe. *Sort* avec 0 s'il existe, 1 s'il n'existe pas (c'est-à-dire l'idée de vrai et faux du shell).

test_d
test_d répertoire

Teste si un répertoire existe. *Sort* avec 0 s'il existe, 1 s'il n'existe pas (c'est-à-dire l'idée de vrai et faux du shell).

dos2unix
dos2unix fichiers ou répertoires ...

Convertit les fins de ligne DOS et OS/2 en style Unix, récursivement.

VOIR AUSSI

Shell::Command, qui contient les mêmes fonctions mais qui prennent les arguments normalement.
