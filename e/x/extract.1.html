EXTRACT(1) Manuel des commandes générales EXTRACT(1)

NOM

extract - déterminer les métadonnées d'un fichier

SYNTAXE

extract [ -bgihLmnvV ] [ -l bibliothèque ] [ -p type ] [ -x type ] fichier ...

DESCRIPTION

Cette page de manuel documente la version 1.0.0 de la commande extract.

extract teste chaque fichier spécifié dans la liste des arguments pour tenter d'en déduire les métadonnées. Chaque fichier est soumis aux bibliothèques d'extraction de métadonnées de libextractor.

libextractor classe les métadonnées (également appelées mots-clés) en types. Une liste de tous les types peut être obtenue avec l'option -L.

OPTIONS

-b
Afficher la sortie au format BiBTeX.
-g
Utiliser une sortie compatible grep (tous les mots-clés sur une seule ligne pour chaque fichier). Utiliser l'option verbeuse pour imprimer d'abord le nom du fichier, suivi des mots-clés. Utiliser l'option verbeuse deux fois pour afficher également les types de mots-clés. Cette option n'imprimera pas les types de mots-clés ni les métadonnées non textuelles.
-h
Afficher un bref résumé des options.
-i
Exécuter les plugins dans le processus principal (pour le débogage). Par défaut, chaque plugin est exécuté dans son propre processus.
-l bibliothèques
Utiliser les bibliothèques spécifiées pour extraire les mots-clés. Le format général des bibliothèques est .I [[-]NOMBIBLIOTHEQUE[:[-]NOMBIBLIOTHEQUE]*] où NOMBIBLIOTHEQUE est une bibliothèque compatible libextractor et a généralement la forme .Inom_de_fichier_jpeg. Le signe moins avant le nom de la bibliothèque indique que cette bibliothèque doit être retirée de la liste existante. Pour n'exécuter que quelques extracteurs sélectionnés, utiliser -l en combinaison avec -n.
-L
Afficher une liste de tous les types de mots-clés connus.
-m
Charger le fichier en mémoire et effectuer l'extraction depuis la mémoire (pour le débogage).
-n
Ne pas utiliser l'ensemble par défaut des extracteurs (typiquement tous les extracteurs standards, actuellement mp3, ogg, jpg, gif, png, tiff, real, html, pdf et types MIME), utiliser uniquement les extracteurs spécifiés avec l'option .B -l.
-p type
N'afficher que les mots-clés correspondant au type spécifié. Par défaut, tous les mots-clés trouvés et non supprimés comme doublons sont affichés.
-v
Afficher le numéro de version et quitter.
-V
Être verbeux. Cette option peut être spécifiée plusieurs fois pour augmenter la verbosité.
-x type
Exclure les mots-clés du type spécifié de la sortie. Par défaut, tous les mots-clés trouvés et non supprimés comme doublons sont affichés.

VOIR AUSSI

libextractor(3) - description de la bibliothèque libextractor

EXEMPLES

$ extract test/test.jpg
comment - (C) 2001 par Christian Grothoff, utilisant gimp 1.2 1
mimetype - image/jpeg
$ extract -V -x comment test/test.jpg
Keywords for file test/test.jpg:
mimetype - image/jpeg
$ extract -p comment test/test.jpg
comment - (C) 2001 par Christian Grothoff, utilisant gimp 1.2 1
$ extract -nV -l png.so -p comment test/test.jpg test/test.png
Keywords for file test/test.jpg:
Keywords for file test/test.png:
comment - Testing keyword extraction
