NOM

ext_unix_group_acl - Assistant ACL de groupe UNIX pour Squid

SYNTAXE

ext_unix_group_acl [-d] [-g groupe ] [-g groupe ...] [-p] [-s]

DESCRIPTION

ext_unix_group_acl permet à Squid de baser les contrôles d'accès sur l'appartenance des utilisateurs aux groupes UNIX.

OPTIONS

-d
Écrit des informations de débogage sur stderr. -g groupe Spécifie un nom de groupe à faire correspondre.
-p
Fait également correspondre le groupe primaire de l'utilisateur depuis /etc/passwd.
-s
Supprime le composant de nom de domaine NT des noms d'utilisateur (séparés par / ou \).

CONFIGURATION

Cet exemple de squid.conf définit deux ACL Squid. usergroup1 correspond aux utilisateurs du group1, et usergroup2 correspond aux utilisateurs du group2 ou group3.

external_acl_type unix_group %LOGIN /usr/local/squid/libexec/ext_unix_group_acl -p
acl usergroup1 external unix_group group1
acl usergroup2 external unix_group group2 group3

Par défaut, jusqu'à 11 groupes peuvent être mis en correspondance dans une seule ACL (y compris les groupes spécifiés en ligne de commande). Cette limite est définie par MAX_GROUPS dans le code source.

PROBLÈMES CONNUS

Ne comprend pas les groupes alias GID parfois utilisés pour contourner les limitations de taille des groupes. Si vous utilisez des groupes alias GID, vous devez spécifier chaque alias par son nom.
