EXIT(3P) Manuel du programmeur POSIX EXIT(3P)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation de cette interface sous Linux peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

exit — terminer un processus

SYNTAXE

#include <stdlib.h>
void exit(int status);

DESCRIPTION

La fonctionnalité décrite sur cette page de référence est alignée sur la norme ISO C. Tout conflit entre les exigences décrites ici et la norme ISO C est involontaire. Ce volume de POSIX.1‐2017 s'en remet à la norme ISO C.

La valeur de status peut être 0, EXIT_SUCCESS, EXIT_FAILURE, ou toute autre valeur, bien que seuls les 8 bits les moins significatifs (c'est-à-dire status & 0377) soient disponibles à partir de wait() et waitpid(); la valeur complète sera disponible à partir de waitid() et dans le siginfo_t passé à un gestionnaire de signaux pour SIGCHLD.

La fonction exit() appelle d'abord toutes les fonctions enregistrées par atexit(), dans l'ordre inverse de leur enregistrement, sauf qu'une fonction est appelée après toute fonction enregistrée précédemment qui avait déjà été appelée au moment de son enregistrement. Chaque fonction est appelée autant de fois qu'elle a été enregistrée. Si, lors de l'appel à l'une de ces fonctions, un appel à la fonction longjmp() est effectué qui mettrait fin à l'appel à la fonction enregistrée, le comportement est indéfini.

Si une fonction enregistrée par un appel à atexit() ne parvient pas à retourner, les fonctions enregistrées restantes ne seront pas appelées et le reste du traitement de exit() ne sera pas complété. Si exit() est appelée plus d'une fois, le comportement est indéfini.

La fonction exit() vide ensuite tous les flux ouverts avec des données tamponnées non écrites et ferme tous les flux ouverts. Finalement, le processus est terminé avec les mêmes conséquences que celles décrites dans Conséquences de la terminaison d'un processus.

VALEUR DE RETOUR

La fonction exit() ne retourne pas.

ERREURS

Aucune erreur n'est définie.
