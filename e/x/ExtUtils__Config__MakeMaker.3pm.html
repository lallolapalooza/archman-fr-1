NOM

ExtUtils::Config::MakeMaker - Un wrapper compatible ExtUtils::Config pour la configuration d'ExtUtils::MakeMaker.

VERSION

version 0.010

SYNOPSIS

my $config = ExtUtils::Config::MakeMaker->new($makemaker);

DESCRIPTION

Cet objet encapsule l'idée de configuration d'ExtUtils::MakeMaker dans une interface compatible ExtUtils::Config. Cela signifie que si vous passez un argument de configuration à ou dans Makefile.PL (par exemple, "OPTIMIZE=-O3"), il apparaîtra dans l'objet de configuration (par exemple, "$config-"get('optimize')>).

MÉTHODES

new($makemaker)

Ceci crée un nouvel objet "ExtUtils::Config::MakeMaker" à partir d'un objet MakeMaker.

get($key)

Obtient la valeur de $key. Si elle n'est pas remplacée, elle renverra la valeur dans %Config.

exists($key)

Teste l'existence de $key.

values_set()

Obtient un hashref de toutes les valeurs remplacées.

all_config()

Obtient un hashref de la configuration complète, y compris les remplacements.

serialize()

Cette méthode sérialise l'objet dans une sorte de chaîne. Cela peut être utile à diverses fins de mise en cache.

materialize()

Cela transforme cet objet en un objet "ExtUtils::Config" réel.

but(%config)

Ceci renvoie un objet "ExtUtils::Config" basé sur celui-ci mais avec les entrées données remplacées. Si une valeur est "undef", elle reviendra à la valeur officielle %Config à la place.
