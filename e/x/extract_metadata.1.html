EXTRACT_METADATA(1) Manuel des commandes générales EXTRACT_METADATA(1)

NOM

extract_metadata - lire les métadonnées de colonnes à partir de fichiers binaires SPSS et Stata, et les formater en JSON

SYNTAXE

extract_metadata fichier-entrée fichier-sortie

DESCRIPTION

extract_metadata lit les métadonnées de colonnes à partir de fichiers de données binaires existants, afin que readstat puisse produire de nouveaux fichiers binaires compatibles avec les colonnes à partir de fichiers d'entrée CSV. Les deux programmes utilisent JSON comme format d'échange de métadonnées.

Le fichier-entrée doit être un fichier avec l'une des extensions suivantes :

dta
Fichier binaire Stata, version 104 ou plus récente
sav
Fichier binaire non compressé SPSS
zsav
Fichier binaire compressé SPSS

Dans tous les cas, fichier-sortie doit se terminer par .json.

EXEMPLE

Supposons que vous ayez un fichier Stata avec les données de l'enquête de l'année dernière, et que vous souhaitiez produire un fichier Stata compatible contenant les données de l'enquête de cette année. Tout d'abord, extrayez les métadonnées :

extract_metadata last-year.dta survey-metadata.json

Appliquez maintenant ces métadonnées aux données de cette année, qui sont stockées dans un fichier CSV :

readstat this-year.csv metadata.json this-year.dta

La première ligne du fichier CSV doit contenir des noms de colonnes qui correspondent aux noms de colonnes dans last-year.dta. Si tout s'est bien passé, votre nouvel ensemble de données binaire est maintenant stocké dans this-year.dta.

OPTIONS

Aucune.
