NOM

exfatlabel - obtenir ou définir une étiquette de système de fichiers exFAT

SYNTAXE

exfatlabel [ -V ] périphérique [ étiquette ]

DESCRIPTION

exfatlabel lit ou modifie une étiquette de système de fichiers exFAT (nom de volume).

Si l'argument étiquette est présent, exfatlabel définit le nouveau nom de volume. Une étiquette vide ('') supprime le nom de volume. L'étiquette peut comporter jusqu'à 15 caractères. Cette limite est plus courte si des caractères au-delà du BMP Unicode sont utilisés car l'étiquette est stockée en interne en UTF-16.

Si l'argument étiquette est omis, exfatlabel affiche simplement le nom de volume actuel.

OPTIONS DE LIGNE DE COMMANDE

Options de ligne de commande disponibles :

-V
Affiche la version et le copyright.

CODES DE SORTIE

Zéro est retourné en cas de succès. Tout autre code signifie une erreur.
