NOM

ExtUtils::Mkbootstrap - créer un fichier bootstrap pour une utilisation par DynaLoader

SYNTAXE

Mkbootstrap

DESCRIPTION

Mkbootstrap est généralement appelé à partir d'un Makefile d'extension.

Il n'y a pas de fichier "*.bs" fourni avec l'extension. Au lieu de cela, il peut y avoir un fichier *_BS qui contient du code pour les cas spéciaux, comme posix pour la base de données berkeley sur le NeXT.

Ce fichier sera analysé et produira un tableau @DynaLoader::dl_resolve_using potentiellement vide pour l'architecture courante. Celui-ci sera étendu par $BSLOADLIBS, qui a été calculé par ExtUtils::Liblist::ext(). Si ce tableau est toujours vide, nous ne faisons rien, sinon nous écrivons un fichier .bs avec un tableau @DynaLoader::dl_resolve_using.

Le fichier *_BS peut insérer du code dans le fichier "*.bs" généré en le plaçant dans $bscode. Ceci est un mécanisme d'échappement pratique qui peut s'avérer utile dans des situations complexes.

Si @DynaLoader::dl_resolve_using contient des entrées "-L*" ou "-l*", alors Mkbootstrap ajoutera automatiquement un appel à dl_findfile() dans le fichier "*.bs" généré.
