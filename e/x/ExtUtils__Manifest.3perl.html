NOM

ExtUtils::Manifest - Utilitaires pour écrire et vérifier un fichier MANIFEST

VERSION

version 1.75

manicopy($read,$target);

FONCTIONS

ExtUtils::Manifest n'exporte aucune fonction par défaut. Les suivantes sont exportées sur demande :

mkmanifest

mkmanifest();

Écrit tous les fichiers du répertoire courant et de ses sous-répertoires dans votre MANIFEST. Cela fonctionne de manière similaire au résultat de la commande Unix

find . > MANIFEST

Tous les fichiers correspondant à une expression régulière dans un fichier MANIFEST.SKIP (s'il existe) sont ignorés.

Tout fichier MANIFEST existant sera sauvegardé sous le nom MANIFEST.bak.

manifind

my $found = manifind();

renvoie une référence de hachage. Les clés de la hachage sont les fichiers trouvés sous le répertoire courant.

manicheck

my @missing_files = manicheck();

vérifie si tous les fichiers listés dans un "MANIFEST" dans le répertoire courant existent réellement. Si le "MANIFEST" et l'arborescence sous le répertoire courant sont synchronisés, elle renvoie silencieusement une liste vide. Sinon, elle renvoie une liste de fichiers qui sont listés dans le "MANIFEST" mais manquants du répertoire, et par défaut, elle affiche également ces noms sur STDERR.

filecheck

my @extra_files = filecheck();

trouve les fichiers sous le répertoire courant qui ne sont pas mentionnés dans le "MANIFEST" . Un fichier optionnel "MANIFEST.SKIP" sera consulté. Tout fichier correspondant à une expression régulière dans un tel fichier ne sera pas signalé comme manquant dans le "MANIFEST" . La liste de tous les fichiers superflus trouvés est renvoyée, et par défaut, elle est également signalée sur STDERR.

fullcheck

my($missing, $extra) = fullcheck();

fait à la fois un manicheck() et un filecheck(), en renvoyant alors les deux sous forme de deux références de tableau.

skipcheck

my @skipped = skipcheck();

liste tous les fichiers qui sont ignorés en raison de votre fichier "MANIFEST.SKIP" .

maniread

my $manifest = maniread();
my $manifest = maniread($manifest_file);

lit un fichier "MANIFEST" nommé (par défaut "MANIFEST" dans le répertoire courant) et renvoie une référence de HACHAGE avec les fichiers comme clés et les commentaires comme valeurs de la HACHAGE. Les lignes vides et les lignes commençant par "#" dans le fichier "MANIFEST" sont ignorées.

maniskip

my $skipchk = maniskip();
my $skipchk = maniskip($manifest_skip_file);
if ($skipchk->($file)) { .. }

lit un fichier "MANIFEST.SKIP" nommé (par défaut "MANIFEST.SKIP" dans le répertoire courant) et renvoie une référence de CODE qui teste si un nom de fichier donné doit être ignoré.

manicopy

manicopy(\%src, $dest_dir);
manicopy(\%src, $dest_dir, $how);

Copie les fichiers qui sont les clés dans %src vers le $dest_dir. %src est typiquement renvoyé par la fonction maniread() .

manicopy( maniread(), $dest_dir );

Cette fonction est utile pour produire une arborescence de répertoires identique à l'arborescence de distribution prévue.

$how peut être utilisé pour spécifier une méthode différente de « copie ». Les valeurs valides sont "cp", qui copie réellement les fichiers, "ln" qui crée des liens physiques, et "best" qui lie principalement les fichiers mais copie tout lien symbolique pour créer une arborescence sans aucun lien symbolique. "cp" est la valeur par défaut.

maniadd

maniadd({ $file => $comment, ...});

Ajoute une entrée à un MANIFEST existant, à moins qu'elle n'y soit déjà.

$file sera normalisé (c'est-à-dire unixifié). NON IMPLÉMENTÉ

MANIFEST

Une liste de fichiers dans la distribution, un fichier par ligne. Le MANIFEST utilise toujours les conventions de chemin de fichier Unix même si vous n'êtes pas sur Unix. Cela signifie le style foo/bar et non foo\bar.

Tout ce qui se trouve entre une espace et une fin de ligne dans un fichier "MANIFEST" est considéré comme un commentaire. Toute ligne commençant par # est également un commentaire. À partir d'ExtUtils::Manifest 1.52, un nom de fichier peut contenir des caractères d'espacement s'il est entouré de guillemets simples ; les guillemets simples ou les barres obliques inverses dans ce nom de fichier doivent être échappés par une barre oblique inverse.

# this a comment
some/file
some/other/file            comment about some/file
'some/third file'          comment

MANIFEST.SKIP

Le fichier MANIFEST.SKIP peut contenir des expressions régulières de fichiers qui doivent être ignorés par mkmanifest() et filecheck(). Les expressions régulières doivent apparaître une par ligne. Les lignes vides et les lignes commençant par "#" sont ignorées. Utilisez "\#" si vous avez besoin qu'une expression régulière commence par un "#".

Par exemple :

# Version control files and dirs.
\bRCS\b
\bCVS\b
,v$
\B\.svn\b
# Makemaker generated files and dirs.
^MANIFEST\.
^Makefile$
^blib/
^MakeMaker-\d
# Temp, old and emacs backup files.
~$
\.old$
^#.*#$
^\.#

Si aucun fichier MANIFEST.SKIP n'est trouvé, un ensemble d'ignorances par défaut sera utilisé, similaire à l'exemple ci-dessus. Si vous ne voulez rien ignorer, créez simplement un fichier MANIFEST.SKIP vide.

Dans son propre fichier MANIFEST.SKIP, certaines directives peuvent être utilisées pour inclure le contenu d'autres fichiers MANIFEST.SKIP. Actuellement, deux telles directives sont reconnues.

#!include_default
Cela indique à ExtUtils::Manifest de lire le fichier MANIFEST.SKIP par défaut et d'ignorer les fichiers en conséquence, mais pas de l'inclure dans le MANIFEST.SKIPlocal. Cela est destiné à ignorer les fichiers selon un défaut système, qui peut changer au fil du temps sans nécessiter d'autres modifications du MANIFEST.SKIPde la distribution.
#!include /Path/to/another/manifest.skip
Cela insère le contenu du fichier externe spécifié dans le MANIFEST.SKIPlocal. Cela est destiné aux auteurs qui ont un MANIFEST.SKIP central et qui l'incluent avec leurs différentes distributions.

Le contenu inclus sera inséré dans le fichier MANIFEST.SKIP entre les marqueurs #!start included /path/to/manifest.skip et #!end included /path/to/manifest.skip . Le MANIFEST.SKIP original est sauvegardé sous le nom MANIFEST.SKIP.bak.

EXPORT_OK

&mkmanifest, &manicheck, &filecheck, &fullcheck, &maniread, et &manicopy sont exportables.

VARIABLES GLOBALES

$ExtUtils::Manifest::MANIFEST vaut par défaut "MANIFEST". Le modifier entraîne à la fois un fichier "MANIFEST" différent et un fichier "MANIFEST.SKIP" différent. C'est utile si vous voulez maintenir des distributions différentes pour différents publics (disons une version utilisateur et une version développeur incluant RCS).

$ExtUtils::Manifest::Quiet vaut 0 par défaut. S'il est défini à une valeur vraie, toutes les fonctions agissent silencieusement.

$ExtUtils::Manifest::Debug vaut 0 par défaut. S'il est défini à une valeur vraie, ou si PERL_MM_MANIFEST_DEBUG est vrai, une sortie de débogage sera produite.

DIAGNOSTICS

Toute la sortie de diagnostic est envoyée vers "STDERR".

"Not in MANIFEST:" fichier
est rapporté si un fichier est trouvé qui n'est pas dans "MANIFEST".
"Skipping" fichier
est rapporté si un fichier est ignoré en raison d'une entrée dans "MANIFEST.SKIP".
"No such file:" fichier
est rapporté si un fichier mentionné dans un fichier "MANIFEST" n'existe pas.
"MANIFEST:" $!
est rapporté si "MANIFEST" n'a pas pu être ouvert.
"Added to MANIFEST:" fichier
est rapporté par mkmanifest() si $Verbose est défini et qu'un fichier est ajouté à MANIFEST. $Verbose est défini à 1 par défaut.

ENVIRONNEMENT

PERL_MM_MANIFEST_DEBUG
Active le débogage
