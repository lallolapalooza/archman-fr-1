NOM

ext_file_userip_acl - Restreindre les utilisateurs à certaines adresses IP, en utilisant un fichier texte comme backend.

Version 1.0

SYNTAXE

ext_file_userip_acl [-dh] [-f nom du fichier ]

DESCRIPTION

ext_file_userip_acl est un binaire installé. Un assistant externe pour le schéma d'ACL externe de Squid.

Il fonctionne en lisant une paire composée d'une adresse IP et d'un nom d'utilisateur sur STDIN et en la comparant à un fichier de configuration.

OPTIONS

-d
Écrit les informations de débogage sur stderr.
-f fichier
Le fichier de configuration à charger.
-h
Affiche l'aide du binaire et les informations sur la syntaxe de la ligne de commande sur stderr.

CONFIGURATION

La configuration de squid.conf pour l'ACL externe devrait être :

external_acl_type type-name %SRC %LOGIN /chemin/vers/ext_file_userip_acl -f /chemin/vers/config.file

Si le programme assistant trouve un nom d'utilisateur/IP correspondant dans le fichier de configuration, il retourne OK , sinon il retourne ERR .

Le format du fichier de configuration est le suivant :

ip_addr[/masque] username|@groupe|ALL|NONE

Où ip_addr est une adresse IP au format décimal pointé, le masque doit également être au format décimal pointé.

Lorsque le deuxième paramètre est précédé d'un @ , le programme recherchera l'entrée du fichier /etc/group pour le nom d'utilisateur spécifié.

Il existe deux autres directives, ALL et NONE , qui signifient "tout utilisateur sur cette adresse IP peut s'authentifier" ou "aucun utilisateur sur cette adresse IP ne peut s'authentifier".
