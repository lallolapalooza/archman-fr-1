NOM

ExtUtils::PkgConfig - interface simpliste vers pkg-config

SYNOPIS

use ExtUtils::PkgConfig;
$package = 'gtk+-2.0';
%pkg_info = ExtUtils::PkgConfig->find ($package);
print "modversion:  $pkg_info{modversion}\n";
print "cflags:      $pkg_info{cflags}\n";
print "libs:        $pkg_info{libs}\n";
$exists = ExtUtils::PkgConfig->exists($package);
$modversion = ExtUtils::PkgConfig->modversion($package);
$libs = ExtUtils::PkgConfig->libs($package);
$cflags = ExtUtils::PkgConfig->cflags($package);
$cflags_only_I = ExtUtils::PkgConfig->cflags_only_I($package);
$cflags_only_other = ExtUtils::PkgConfig->cflags_only_other($package);
$libs_only_L = ExtUtils::PkgConfig->libs_only_L($package);
$libs_only_l = ExtUtils::PkgConfig->libs_only_l($package);
$libs_only_other = ExtUtils::PkgConfig->libs_only_other($package);
$static_libs = ExtUtils::PkgConfig->static_libs($package);
$var_value = ExtUtils::PkgConfig->variable($package, $var);
if (ExtUtils::PkgConfig->atleast_version($package,$version)) {
   ...
}
if (ExtUtils::PkgConfig->exact_version($package,$version)) {
   ...
}
if (ExtUtils::PkgConfig->max_version($package,$version)) {
   ...
}

DESCRIPTION

Le programme pkg-config récupère des informations sur les bibliothèques installées, généralement dans le but de les compiler et de les lier.

ExtUtils::PkgConfig est une interface très simpliste à cet utilitaire, destinée à être utilisée dans le Makefile.PL des extensions Perl qui lient des bibliothèques que pkg-config connaît. C'est vraiment juste du code répétitif que vous auriez écrit vous-même.

UTILISATION

HASH = ExtUtils::PkgConfig->find (CHAINE, [CHAINE, ...])
Appelle pkg-config sur la bibliothèque spécifiée par CHAINE (vous devrez savoir quoi utiliser ici). Le HASH retourné contient les valeurs modversion, cflags et libs sous des clés portant ces noms. Si plusieurs CHAINES sont passées, elles sont tentées dans l'ordre où elles sont données jusqu'à ce qu'un paquet fonctionnel soit trouvé.

Si pkg-config ne parvient pas à trouver une CHAINE fonctionnelle, cette fonction échoue avec un message destiné à aider celui qui tente de compiler votre paquet.

Par exemple:

*** can not find package bad1
*** check that it is properly installed and available
*** in PKG_CONFIG_PATH

ou

*** can't find cflags for gtk+-2.0
*** is it properly installed and available in PKG_CONFIG_PATH?
CHAINE = ExtUtils::PkgConfig->create_version_macros (PAQUET, TIGE)
Crée un ensemble de macros de version avec le préfixe TIGE pour la bibliothèque spécifiée par PAQUET. Le résultat est retourné.

Un exemple d'entrée serait "gtk+-2.0" pour PAQUET et "GTK" pour TIGE.

ExtUtils::PkgConfig->write_version_macros (FICHIER, PAQUET, TIGE, [PAQUET, TIGE, ...])
Crée un ou plusieurs ensembles de macros de version pour les bibliothèques et les préfixes spécifiés par les paires PAQUET et TIGE et les écrit dans le fichier FICHIER. S'il n'existe pas, FICHIER sera créé. S'il existe, il sera écrasé.
