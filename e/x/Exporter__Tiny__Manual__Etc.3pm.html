Fonctions utilitaires

Exporter::Tiny est lui-même un exportateur !

Ces fonctions sont réellement destinées à un usage interne, mais peuvent être exportées si vous en avez besoin :

mkopt(\@array)
Similaire à "mkopt" de Data::OptList. Il ne prend pas en charge toutes les options sophistiquées que Data::OptList prend en charge ("moniker", "require_unique", "must_be" et "name_test") mais il est environ 50% plus rapide.
mkopt_hash(\@array)
Similaire à "mkopt_hash" de Data::OptList. Voir aussi "mkopt".

Historique

Type::Library avait un ensemble de code d'exportation personnalisé qui insérait des coderefs dans le stash de son appelant. Il avait besoin de quelque chose de plus puissant que la plupart des exportateurs afin de pouvoir basculer entre l'exportation d'objets compatibles Moose, Mouse et Moo sur demande. Sub::Exporter aurait été capable, mais avait trop de dépendances pour le projet Type::Tiny.

Pendant ce temps, Type::Utils, Types::TypeTiny et Test::TypeTiny utilisaient le vénérable Exporter.pm. Cependant, cela signifiait qu'ils n'étaient pas en mesure d'utiliser les fonctionnalités comme le renommage de fonctions de style Sub::Exporter que j'avais intégrées dans Type::Library :

## importe "Str" mais renommez-la en "String".
use Types::Standard "Str" => { -as => "String" };

Et donc j'ai décidé de factoriser le code qui pouvait être partagé par tous les exportateurs de Type-Tiny en un seul endroit : Exporter::TypeTiny.

À partir de la version 0.026, Exporter::TypeTiny a également été rendu disponible sous le nom d'Exporter::Tiny, distribué indépendamment sur CPAN. CHOCOLATEBOY m'avait convaincu qu'il était assez mature pour vivre sa propre vie.

À partir de la version 0.030, Type-Tiny dépend d'Exporter::Tiny et Exporter::TypeTiny est en cours d'abandon.

Comparaison obligatoire des exportateurs

L'exportation n'est probablement pas le goulot d'étranglement des performances de votre application, mais néanmoins, voici quelques comparaisons.

Tailles comparatives selon Devel::SizeMe :

Exporter                     217.1Kb
Sub::Exporter::Progressive   263.2Kb
Exporter::Tiny               267.7Kb
Exporter + Exporter::Heavy   281.5Kb
Exporter::Renaming           406.2Kb
Sub::Exporter                701.0Kb

Performances d'exportation d'une seule sous-routine :

              Rate     SubExp    ExpTiny SubExpProg      ExpPM
SubExp      2489/s         --       -56%       -85%       -88%
ExpTiny     5635/s       126%         --       -67%       -72%
SubExpProg 16905/s       579%       200%         --       -16%
ExpPM      20097/s       707%       257%        19%         --

(Exporter::Renaming modifie globalement le comportement d'Exporter.pm, il n'a donc pas pu être inclus dans les mêmes benchmarks.)

Dépendances (hors cœur) :

Exporter                    -1
Exporter::Renaming           0
Exporter::Tiny               0
Sub::Exporter::Progressive   0
Sub::Exporter                3
