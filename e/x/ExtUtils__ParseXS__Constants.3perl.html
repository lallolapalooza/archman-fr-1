NOM

ExtUtils::ParseXS::Constants - Valeurs d'initialisation pour certains globaux

SYNTAXE

use ExtUtils::ParseXS::Constants ();
$PrototypeRegexp = $ExtUtils::ParseXS::Constants::PrototypeRegexp;

DESCRIPTION

L'initialisation de certaines variables autres que des sous-routines dans ExtUtils::ParseXS et certains de ses paquets de support a été déplacée dans ce paquet afin que ces valeurs puissent être définies exactement une fois puis réutilisées dans n'importe quel paquet.

Rien n'est exporté. Utilisez des noms de variables entièrement qualifiés.
