NOM

delayer - Assistant ACL externe pour Squid ajoutant un délai artificiel aux requêtes

SYNTAXE

delayer [--help] [--debug] [--log fichier] [--wait msec]

DESCRIPTION

Assistant ACL externe pour Squid ; provoque un délai de réponse aux requêtes HTTP par Squid.

En configurant soigneusement les ACL de Squid, il est possible de retarder sélectivement les requêtes reçues par un proxy. Après le délai configuré, il retournera toujours « vrai ».

OPTIONS

--help ou -h
Affiche le message d'aide sur la sortie standard
--debug ou -d
Émet des messages de débogage sur la sortie d'erreur standard et finalement dans cache.log
--log /chemin/vers/fichier ou -l /chemin/vers/fichier
Émet des messages de débogage dans le fichier spécifié au lieu de la sortie d'erreur standard. Active également le débogage.
--wait msec ou -w msec
Retarde chaque requête du nombre spécifié de millisecondes (msec). Sauf si cette option est spécifiée, chaque requête soumise sera retardée d'une demi-seconde (500 msec) par défaut.

CONFIGURATION

Pour l'utiliser, ce fragment de modèle de configuration peut être utilisé dans squid.conf :

external_acl_type delayer concurrency=100000 children-max=2 children-startup=1 children-idle=1 cache=10 %URI /chemin/vers/delayer -w 200
acl delay external delayer
http_access allow acl1 acl2 acl3 delay !all

Il est important que l'ACL faisant référence au délai soit l'avant-dernière clause de la ligne http_access. Elle provoquera un retard pour toutes les requêtes qui correspondent à toutes les ACL précédentes de la ligne. La clause !all à la fin de la ligne garantira qu'aucun trafic n'est autorisé par cette ACL, seul le délai pour évaluer la clause de délai sera inséré avant d'évaluer les lignes http_access suivantes. Il est également important de placer la ligne http_access avec soin dans la séquence de toutes les lignes http_access ; elle devrait être près du début, mais attention à ne pas insérer des ACL lentes indésirables (en particulier proxy_auth).

Il est possible de personnaliser la façon dont le délai est calculé pour chaque requête en modifiant la fonction PERL « calc_delay » dans le script, la documentation à ce sujet est intégrée dans les commentaires du code source.
