NOM

exfatfsck - vérifie un système de fichiers exFAT

SYNTAXE

exfatfsck [ -a | -n | -p | -y ] périphérique
exfatfsck [ -V ]

DESCRIPTION

exfatfsck vérifie un système de fichiers exFAT à la recherche d'erreurs. Il peut en réparer certaines.

OPTIONS DE LIGNE DE COMMANDE

Options de ligne de commande disponibles :

-a
Répare automatiquement le système de fichiers. Aucune intervention de l'utilisateur n'est requise.
-n
Mode sans opération : vérifie les erreurs de manière non interactive, mais n'écrit rien sur le système de fichiers.
-p
Identique à -a pour la compatibilité avec d'autres *fsck.
-V
Affiche la version et le copyright.
-y
Identique à -a pour la compatibilité avec d'autres *fsck.

CODES DE RETOUR

Zéro est retourné si aucune erreur n'est trouvée. Tout autre code signifie une erreur.
