ExtUtils__XSBuilder__WrapXS(3pm)

Paquet: perl-extutils-xsbuilder

Licences: GPL, PerlArtistic

XSBuilder::WrapXS(3) Documentation Perl Contribuée par les Utilisateurs XSBuilder::WrapXS(3)

NOM

ExtUtils::XSBuilder::WrapXS - créer des wrappers XS perl pour les fonctions C

DESCRIPTION

Pour plus d'informations, voir ExtUtils::XSBuilder

new_parsesource (o)

Retourne une référence d'un tableau d'objets ParseSource pour tous les fichiers sources qui devraient être utilisés pour générer des fichiers XS

new_typemap (o)

Retourne un nouvel objet typemap

new_podtemplate (o)

Retourne un nouvel objet podtemplate

xs_includes (o)

Retourne une liste de fichiers d'inclusion XS.

Par défaut : utilise tous les fichiers d'inclusion que "ParseSource::find_includes" retourne, mais supprime les informations de chemin

xs_glue_dirs (o)

Retourne une liste de répertoires de colle XS supplémentaires à rechercher pour les maps.

xs_base_dir (o)

Retourne un répertoire qui sert de base pour d'autres répertoires.

Par défaut : '.'

xs_map_dir (o)

Retourne le répertoire où rechercher les fichiers de map

Par défaut : "<xs_base_dir"/xsbuilder/maps>

xs_incsrc_dir (o)

Retourne le répertoire où rechercher les fichiers à inclure dans la source. Par exemple, "<xs_incsrc_dir"/Apache/DAV/Resource/Resource_pm> sera inclus dans le module "Apache::DAV::Resource".

Par défaut : "<xs_base_dir"/xsbuilder>

xs_include_dir (o)

Retourne un répertoire où rechercher les fichiers d'inclusion pour pm et XS

Par défaut : "<xs_base_dir"/xsinclude>

xs_target_dir (o)

Retourne le répertoire où écrire les fichiers XS et header générés

Par défaut : "<xs_base_dir"/xs>

makefilepl_text (o)

Retourne le texte pour Makefile.PL

h_filename_prefix (o)

Définit un préfixe pour les fichiers header générés

Par défaut : 'xs_'

my_xs_prefix (o)

Définit un préfixe utilisé pour toutes les fonctions XS

Par défaut : 'xs_'

my_cnv_prefix (o)

Définit un préfixe utilisé pour toutes les fonctions/macros de conversion.

Par défaut : "my_xs_prefix"

needs_prefix (o, name)

Retourne vrai si le nom passé doit être préfixé

pm_text (o, module, isa, code)

Retourne le texte d'un fichier ".pm", ou undef si aucun fichier ".pm" ne devrait être écrit.

Par défaut : Crée un fichier ".pm" qui amorce le code XS

mapline_elem (o, elem)

Appelé pour chaque élément de structure qui est écrit dans le fichier map par checkmaps. Permet à l'utilisateur de modifier le nom de l'élément, par exemple en ajoutant un nom perl différent.

Par défaut : retourne l'élément inchangé

mapline_func (o)

Appelé pour chaque fonction qui est écrite dans le fichier map par checkmaps. Permet à l'utilisateur de modifier le nom de la fonction, par exemple en ajoutant un nom perl différent.

Par défaut : retourne l'élément inchangé
