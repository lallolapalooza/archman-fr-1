EXCH(1) Commandes utilisateur EXCH(1)

NOM

exch - échange de chemins atomique entre deux fichiers

SYNTAXE

exch chemin_ancien chemin_nouveau

DESCRIPTION

exch échange atomiquement chemin_ancien et chemin_nouveau. exch est une simple commande encapsulant l'appel système RENAME_EXCHANGE de renameat2.

OPTIONS

-h, --help

Affiche le texte d'aide et quitte.

-V, --version

Affiche la version et quitte.

STATUT DE RAPPEL

exch a les valeurs de statut de sortie suivantes :

0

succès

1

échec non spécifié

AUTEURS

Masatake YAMATO <yamato@redhat.com>

VOIR AUSSI

renameat2(2)

RAPPORTER LES BOGUES

Pour les rapports de bogues, utilisez le suivi des problèmes https://github.com/util-linux/util-linux/issues.

DISPONIBILITÉ

La commande exch fait partie du paquet util-linux qui peut être téléchargé depuis le Linux Kernel Archive https://www.kernel.org/pub/linux/utils/util-linux/.
