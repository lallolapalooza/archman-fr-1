ExtUtils::Typemaps::Type(3perl) Guide du programmeur Perl ExtUtils::Typemaps::Type(3perl)

NOM

ExtUtils::Typemaps::Type - Entrée dans la section TYPEMAP d'une carte de types

SYNTAXE

use ExtUtils::Typemaps;
...
my $type = $typemap->get_type_map('char*');
my $input = $typemap->get_input_map($type->xstype);

DESCRIPTION

Se référer à ExtUtils::Typemaps pour plus de détails. L'objet associe le "ctype" (type C) au "xstype" (type XS), qui est l'indice des tables de mappage d'entrée et de sortie.

MÉTHODES

new

Reçoit les paramètres "xstype" et "ctype".

Accepte optionnellement le paramètre "prototype". Notez cependant que la méthode pour obtenir/définir la valeur s'appelle "proto" plutôt que <prototype>.

proto

Retourne ou définit le prototype.

xstype

Retourne le nom du type XS auquel ce type C est associé.

ctype

Retourne le nom du type C tel qu'il a été défini lors de la construction.

tidy_ctype

Retourne le nom canonisé du type C.

VOIR AUSSI

ExtUtils::Typemaps
