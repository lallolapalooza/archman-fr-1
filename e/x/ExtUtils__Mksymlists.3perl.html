ExtUtils::Mksymlists(3perl) Guide du programmeur Perl ExtUtils::Mksymlists(3perl)

NOM

ExtUtils::Mksymlists - écrire des fichiers d'options de l'éditeur de liens pour l'extension dynamique

SYNOPIS

use ExtUtils::Mksymlists;
Mksymlists(  NAME     => $nom ,
             DL_VARS  => [ $var1, $var2, $var3 ],
             DL_FUNCS => { $pkg1 => [ $func1, $func2 ],
                           $pkg2 => [ $func3 ] });

DESCRIPTION

"ExtUtils::Mksymlists" produit des fichiers utilisés par l'éditeur de liens sous certains systèmes d'exploitation lors de la création de bibliothèques partagées pour les extensions dynamiques. Il est normalement appelé depuis un Makefile généré par MakeMaker lorsque l'extension est construite. Le fichier d'options de l'éditeur de liens est généré en appelant la fonction "Mksymlists", qui est exportée par défaut par "ExtUtils::Mksymlists". Elle prend un argument, une liste de paires clé-valeur, dans lesquelles les clés suivantes sont reconnues :

DLBASE
Cet élément spécifie le nom par lequel l'éditeur de liens connaît l'extension, qui peut être différent du nom de l'extension elle-même (par exemple, certains éditeurs de liens ajoutent un '_' au nom de l'extension). S'il n'est pas spécifié, il est dérivé de l'attribut NAME. Il est actuellement utilisé uniquement par OS2 et Win32.
DL_FUNCS
Ceci est identique à l'attribut DL_FUNCS disponible via MakeMaker, d'où il est généralement pris. Sa valeur est une référence vers un tableau associatif, dans lequel chaque clé est le nom d'un paquet, et chaque valeur est une référence vers un tableau de noms de fonctions qui devraient être exportés par l'extension. Par exemple, on pourrait dire "DL_FUNCS => { Homer::Iliad => [ qw(trojans greeks) ], Homer::Odyssey => [ qw(travellers family suitors) ] }". Les noms de fonctions doivent être identiques à ceux du code XSUB ; "Mksymlists" modifiera les noms écrits dans le fichier d'options de l'éditeur de liens pour correspondre aux changements effectués par xsubpp. De plus, si aucune des fonctions d'une liste ne commence par la chaîne boot_, "Mksymlists" ajoutera une fonction de bootstrap pour ce paquet, tout comme le fait xsubpp. (Si une fonction boot_<pkg> est présente dans la liste, elle est transmise telle quelle.) Si DL_FUNCS n'est pas spécifié, il utilise par défaut la fonction de bootstrap pour l'extension spécifiée dans NAME.
DL_VARS
Ceci est identique à l'attribut DL_VARS disponible via MakeMaker, et, comme DL_FUNCS, il est généralement spécifié via MakeMaker. Sa valeur est une référence vers un tableau de noms de variables qui devraient être exportés par l'extension.
FILE
Cette clé peut être utilisée pour spécifier le nom du fichier d'options de l'éditeur de liens (moins l'extension spécifique au système d'exploitation), si pour une raison quelconque vous ne souhaitez pas utiliser la valeur par défaut, qui est le dernier mot de l'attribut NAME (par exemple, pour "Tk::Canvas", FILE vaut par défaut "Canvas").
FUNCLIST
Ceci fournit un moyen alternatif de spécifier les noms de fonctions à exporter de l'extension. Sa valeur est une référence vers un tableau de noms de fonctions à exporter par l'extension. Ces noms sont transmis tels quels au fichier d'options de l'éditeur de liens. La spécification d'une valeur pour l'attribut FUNCLIST supprime la génération automatique de la fonction de bootstrap pour le paquet. Pour créer quand même le nom de bootstrap, vous devez spécifier le nom du paquet dans la table associative DL_FUNCS : 
Mksymlists(  NAME     => $nom ,
             FUNCLIST => [ $func1, $func2 ],
             DL_FUNCS => { $pkg => [] } );
IMPORTS
Cet attribut est utilisé pour spécifier les noms à importer dans l'extension. Il est actuellement utilisé uniquement par OS/2 et Win32.
NAME
Ceci donne le nom de l'extension (par exemple, "Tk::Canvas") pour laquelle le fichier d'options de l'éditeur de liens sera produit.

Lors de l'appel de "Mksymlists", il faut toujours spécifier l'attribut NAME. Dans la plupart des cas, c'est tout ce qui est nécessaire. Cependant, dans le cas d'extensions inhabituelles, les autres attributs peuvent être utilisés pour fournir des informations supplémentaires à l'éditeur de liens.
