NOM

expac - utilitaire d'extraction de données alpm

SYNTAXE

Usage: expac [options] <format> cibles...

DESCRIPTION

expac est un outil d'extraction de données pour les bases de données alpm. Il offre une flexibilité similaire à printf et vise à être utilisé comme un outil simple pour d'autres utilitaires basés sur pacman qui ne sont pas liés à la bibliothèque. Il utilise pacman.conf comme fichier de configuration pour localiser et charger vos bases de données locales et synchronisées.

L'invocation d'expac consiste à fournir une chaîne de formatage, qui est généralement décrite par un ou plusieurs jetons de formatage (voir la section FORMATAGE), toutes options pertinentes et zéro ou plusieurs cibles. La chaîne de formatage doit être le premier argument autre qu'une option. Les cibles peuvent être un simple nom de paquet, une chaîne de requête (dans le cas d'une recherche), ou dans la syntaxe dépôt/paquet lorsque l'option -sync est fournie.

OPTIONS

-Q, --query
Recherche dans la base de données locale les cibles fournies. C'est le comportement par défaut.
-S, --sync
Recherche dans les bases de données de synchronisation les cibles fournies.
-s, --search
Recherche les paquets correspondant aux chaînes spécifiées par les cibles. Il s'agit d'une requête ET booléen et les expressions régulières sont autorisées.
-g, --group
Retourne les paquets correspondant aux cibles spécifiées en tant que groupes de paquets.
--config <fichier>
Lit depuis fichier pour l'initialisation alpm au lieu de /etc/pacman.conf.
-H, --humansize <taille>
Formate les tailles de paquets en unités SI selon taille. Les options valides sont : 
B, K, M, G, T, P, E, Z, Y
-1, --readone
Arrête la recherche après le premier résultat. Ceci n'a d'effet que sur les opérations -S sans -s.
-d, --delim <chaîne>
Sépare chaque paquet avec la chaîne spécifiée. La valeur par défaut est un caractère de nouvelle ligne.
-l, --listdelim <chaîne>
Sépare chaque élément de liste avec la chaîne spécifiée. Les listes sont toute séquence interprétée spécifiée avec une lettre majuscule. La valeur par défaut est deux espaces.
-p, --file
Interprète les cibles comme des chemins vers des fichiers locaux.
-t, --timefmt <format>
Affiche l'heure décrite par le format spécifié. Cette chaîne est passée directement à strftime(3). Le format par défaut est %c.
-v, --verbose
Affiche plus d'informations. Les erreurs de type `Paquet introuvable' seront affichées, et les valeurs de champs vides seront affichées comme 'None'.
-V, --version
Affiche les informations de version et quitte.
-h, --help
Affiche le message d'aide et quitte.

FORMATAGE

L'argument de format permet les séquences interprétées suivantes :

%a    architecture
%B    fichiers de sauvegarde
%b    date de construction
%C    conflits avec (pas de chaînes de version)
%D    dépend de
%d    description
%E    dépend de (pas de chaînes de version)
%e    base du paquet
%f    nom du fichier (uniquement avec -S)
%F    fichiers (uniquement avec -Q)
%g    signature PGP encodée en base64 (uniquement avec -S)
%G    groupes
%H    conflits avec
%h    sha256sum
%i    possède un scriptlet d'installation (uniquement avec -Q)
%k    taille de téléchargement (uniquement avec -S)
%l    date d'installation (uniquement avec -Q)
%L    licences
%m    taille d'installation
%M    fichiers de sauvegarde modifiés (uniquement avec -Q)
%n    nom du paquet
%N    requis par
%O    dépendances optionnelles
%o    dépendances optionnelles (sans descriptions)
%p    nom du packager
%P    fournit
%R    remplace (pas de chaînes de version)
%r    dépôt
%s    md5sum
%S    fournit (pas de chaînes de version)
%T    remplace
%u    URL du projet
%V    méthode de validation du paquet
%v    version
%w    raison d'installation (uniquement avec -Q)
%!    numéro de résultat (compteur auto-incrémenté, commence à 0)
%%    % littéral

Notez que pour les jetons en minuscules autres que %m et %k, le support printf complet est autorisé, par exemple %-20n. Cela ne s'applique pas aux sorties basées sur des listes, des dates ou des nombres.

Les séquences d'échappement standard avec antislash sont prises en charge, conformément à printf(1).

EXEMPLES

Émuler la fonction de recherche de pacman :

$ expac -Ss '%r/%n %v\n    %d' <termes de recherche>

Lister les 10 paquets installés les plus anciens (par date de construction) :

$ expac --timefmt=%s '%b\t%n' | sort -n | head -10
