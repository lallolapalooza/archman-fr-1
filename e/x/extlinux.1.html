extlinux(1) Manuel des commandes générales extlinux(1)

NOM

extlinux - installer le chargeur de démarrage SYSLINUX sur un système de fichiers ext2/ext3/ext4/btrfs/xfs

SYNTAXE

extlinux [options] répertoire

DESCRIPTION

EXTLINUX est un nouveau dérivé de syslinux, qui démarre à partir d'un système de fichiers Linux ext2/ext3/ext4/btrfs ou xfs. Il fonctionne de la même manière que SYSLINUX, avec quelques légères modifications. Il est destiné à simplifier la première installation de Linux, et pour la création de disques de secours et autres disques de démarrage spéciaux.

L'installateur est conçu pour être exécuté sur un répertoire monté. Par exemple, si vous avez une clé usb ext2, ext3, ext4, ou btrfs montée sur /mnt, vous pouvez exécuter la commande suivante:

extlinux --install /mnt

OPTIONS

-H, --heads=#
Forcer le nombre de têtes.
-i, --install
Installer par-dessus le secteur d'amorçage actuel.
-O, --clear-once
Effacer la commande de démarrage unique.
-o, --once=commande
Exécuter une commande une fois au démarrage.
-M, --menu-save=étiquette
Définir l'étiquette à sélectionner comme défaut au prochain démarrage
-r, --raid
Revenire au périphérique suivant en cas d'échec de démarrage.
--reset-adv
Réinitialiser les données auxiliaires.
-S, --sectors=#
Forcer le nombre de secteurs par piste.
-U, --update
Met à jour une installation précédente d'EXTLINUX.
-z, --zip
Forcer la géométrie du lecteur zip (-H 64 -S 32).
--device=nom_périphérique
Ignorer la détection automatique des noms de périphériques. Cette option est destinée aux environnements spéciaux uniquement et ne doit pas être utilisée par les utilisateurs normaux. Une mauvaise utilisation de cette option peut entraîner une corruption du disque et une perte de données.

FICHIERS

Le fichier de configuration extlinux doit être nommé syslinux.cfg ou extlinux.conf et doit être stocké dans le répertoire d'installation d'extlinux. Pour plus d'informations sur le contenu de extlinux.conf, consultez la page de manuel de syslinux(1), section fichiers.

LIMITATIONS

Le démarrage à partir de XFS ne fonctionne que lorsque une table de partitions MBR est utilisée (pas sur les tables de partitions GPT).

BOGUES

J'apprécierais d'être informé de tout problème que vous pourriez rencontrer avec SYSLINUX. J'aimerais également avoir de vos nouvelles si vous avez utilisé SYSLINUX avec succès, surtout si vous l'utilisez pour une distribution.

Si vous signalez des problèmes, veuillez inclure toutes les informations possibles sur votre système et votre BIOS ; la grande majorité de tous les problèmes signalés s'avèrent être des bogues du BIOS ou du matériel, et j'ai besoin d'autant d'informations que possible pour diagnostiquer les problèmes.

Il existe une liste de diffusion pour la discussion entre les utilisateurs de SYSLINUX et pour les annonces de nouvelles versions et de versions de test. Vous pouvez vous abonner à cette liste de diffusion.
