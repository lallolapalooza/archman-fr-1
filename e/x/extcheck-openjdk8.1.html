extcheck(1) Outils de base extcheck(1)

NOM

extcheck - Détecte les conflits de version entre un fichier Archive Java (JAR) cible et les fichiers JAR d'extension actuellement installés.

SYNTAXE

extcheck [options] fichiercible.jar
options
Les options de ligne de commande. Voir Options.
fichiercible.jar
Le fichier JAR cible par rapport auquel les fichiers JAR d'extension actuellement installés sont comparés pour détecter les conflits de version.

DESCRIPTION

La commande extcheck vérifie un fichier JAR spécifié pour les conflits de titre et de version avec toutes les extensions installées dans le SDK Java SE. Avant d'installer une extension, vous pouvez utiliser cet utilitaire pour voir si une version identique ou plus récente de l'extension est déjà installée.

La commande extcheck compare les en-têtes Specification-title et Specification-version du manifeste du fichier fichiercible.jar avec les en-têtes correspondants de tous les fichiers JAR actuellement installés dans le répertoire des extensions. Par défaut, le répertoire des extensions est jre/lib/ext sur Oracle Solaris et \jre\lib\ext sous Windows. La commande extcheck compare les numéros de version de la même manière que la méthode java.lang.Package.isCompatibleWith.

Si aucun conflit n'est détecté, le code de retour est 0.

Si le manifeste de l'un des fichiers JAR du répertoire des extensions a le même Specification-title et le même numéro de Specification-version ou un numéro plus récent, un code d'erreur non nul est retourné. Un code d'erreur non nul est également retourné lorsque fichiercible.jar n'a pas les attributs Specification-title ou Specification-version dans son fichier manifeste.

OPTIONS

-verbose

Liste les fichiers JAR dans le répertoire des extensions au fur et à mesure de leur vérification. De plus, les attributs du manifeste du fichier JAR cible et de tout fichier JAR en conflit sont également rapportés.
-Joption

Passe option à la Machine Virtuelle Java (JVM), où option est l'une des options décrites sur la page de référence du lanceur Java. Par exemple, -J-Xms48m définit la mémoire de démarrage à 48 Mo. Voir java(1).
