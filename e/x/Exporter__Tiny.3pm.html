NOM

Exporter::Tiny - un exportateur avec les fonctionnalités de Sub::Exporter mais avec uniquement des dépendances essentielles

SYNTAXE

package MyUtils;
use base "Exporter::Tiny";
our @EXPORT = qw(frobnicate);
sub frobnicate { ... }
1;
package MyScript;
use MyUtils "frobnicate" => { -as => "frob" };
print frob(42);
exit;

DESCRIPTION

Exporter::Tiny prend en charge bon nombre des fonctionnalités externes de Sub::Exporter, y compris le renommage des fonctions importées avec les options "-as", "-prefix" et "-suffix" ; les destinations explicites avec l'option "into" ; et les installateurs alternatifs avec l'option "installer". Mais il est écrit avec environ 40% de lignes de code en moins et sans aucune dépendance non essentielle.

Son interface interne est plus proche de celle de Exporter.pm, avec une configuration effectuée via les variables de paquet @EXPORT, @EXPORT_OK et %EXPORT_TAGS.

Si vous essayez d'écrire un module qui hérite d'Exporter::Tiny, consultez :

  • Exporter::Tiny::Manual::QuickStart
  • Exporter::Tiny::Manual::Exporting

Si vous essayez d'utiliser un module qui hérite d'Exporter::Tiny, consultez :

•
Exporter::Tiny::Manual::Importing
