NOM

exa - nouvelle architecture d'accélération 2D pour X.Org

DESCRIPTION

EXA fournit une API simple pour que les pilotes vidéo implémentent l'accélération 2D. C'est un module chargé par les pilotes, et il n'est pas prévu de le charger seul. Consultez la page de manuel de votre pilote pour savoir comment activer EXA.

L'architecture EXA est conçue pour rendre l'accélération de l'extension Render simple et efficace, et entraîne divers compromis de performance par rapport à XAA. Certaines options de xorg.conf sont disponibles pour le débogage des problèmes de performance ou des problèmes de rendu des pilotes. Elles ne sont pas destinées à une utilisation générale.

Option "EXANoComposite" "booléen"
Désactive l'accélération de l'opération Composite, qui est au cœur de l'extension Render. Sans rapport avec l'extension Composite. Par défaut : Non.
Option "EXANoUploadToScreen" "booléen"
Désactive l'accélération du téléchargement de données pixmap dans la trame d'images. Par défaut : Non.
Option "EXANoDownloadFromScreen" "booléen"
Désactive l'accélération du téléchargement de données pixmap à partir de la trame d'images. NOTE : Ne peut pas être utilisé avec les pilotes qui dépendent du succès de DownloadFromScreen. Par défaut : Non.
Option "MigrationHeuristic" "anystr"
Choisit une heuristique de migration de pixmap alternative, à des fins de débogage. Le réglage par défaut est censé être le plus performant pour une utilisation générale, bien que d'autres puissent aider dans des cas d'utilisation spécifiques. Les options disponibles incluent "always", "greedy" et "smart". Par défaut : always.
