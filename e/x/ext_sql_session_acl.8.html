NOM

ext_sql_session_acl - Aide à la recherche de session de base de données SQL pour Squid

SYNOPSIS

ext_sql_session_acl [options]

DESCRIPTION

Valide l'autorisation d'accès d'une requête HTTP avec une base de données de session.

En prenant un jeton d'identité à valider (tel que déterminé par le format external_acl_type), il renvoie un nom d'utilisateur ou une étiquette associé au jeton d'identité passé.

Les formes courantes d'identifiants sont l'adresse IP, l'adresse EUI (MAC), les mots de passe ou les jetons UUID.

Ce programme utilise le support de concurrence de Squid.

OPTIONS

--dsn
DSN de la base de données. Par défaut "DBI:mysql:database=squid"
--user
Utilisateur de la base de données
--password
Mot de passe de la base de données
--table
Table de la base de données. Par défaut "passwd".
--uidcol
Colonne d'identifiant de session unique. Par défaut "id".
--usercol
Colonne de résultat user= pour ACL externe.
--tagcol
Colonne de résultat tag= pour ACL externe.
--cond
Condition, par défaut enabled=1. Spécifier 1 ou "" pour aucune condition
--persist
Garder une connexion de base de données persistante ouverte entre les requêtes.
--debug
Écrire des informations de débogage sur stderr.
