expand_number(3bsd)

Paquet: libbsd

Licences: custom

expand_number(3bsd) 3bsd expand_number(3bsd)

NOM

expand_number — formater un nombre à partir d'une forme lisible par l'homme

BIBLIOTHQUE

bibliothèque « libbsd »

SYNTAXE

#include <libutil.h> (Voir libbsd(7) pour l'utilisation de l'inclusion.)
int
expand_number(const char *buf, uint64_t *num);

DESCRIPTION

La fonction expand_number() défait le formatage de la chaîne buf et stocke une quantité non signée de 64 bits à l'adresse pointée par l'argument num.

La fonction expand_number() suit la convention de puissance de deux du SI.

Les préfixes sont :

Préfixe Description Multiplicateur
k kilo 1024
M méga 1048576
G giga 1073741824
T téra 1099511627776
P péta 1125899906842624
E exra 1152921504606846976

VALEUR DE RETOUR

En cas de succès, la valeur 0 est retournée ; sinon, la valeur -1 est retournée et la variable globale errno est définie pour indiquer l'erreur.

ERREURS

La fonction expand_number() échouera si :

[EINVAL]
La chaîne donnée ne contient aucun chiffre.
[EINVAL]
Un préfixe non reconnu a été donné.
[ERANGE]
Le résultat ne rentre pas dans 64 bits.

VOIR AUSSI

HISTORIQUE
