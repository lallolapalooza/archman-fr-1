NOM

ExtUtils::MM_OS2 - méthodes pour remplacer le comportement UN*X dans ExtUtils::MakeMaker

SYNTAXE

use ExtUtils::MM_OS2; # Fait en interne par ExtUtils::MakeMaker si nécessaire

DESCRIPTION

Voir ExtUtils::MM_Unix pour une documentation des méthodes fournies là-bas. Ce paquet remplace l'implémentation de ces méthodes, pas les sémantiques.

MÉTHODES

init_dist
Définit TO_UNIX pour convertir les fins de ligne OS2 en style Unix.
init_linker
os_flavor
OS/2 est OS/2
