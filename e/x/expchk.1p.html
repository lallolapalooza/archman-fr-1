NOM

expchk - Vérifier un fichier keyrec pour des zones expirées

SYNTAXE

expchk -all -expired -valid -warn numjours -zone nomzone -count -help fichiers_keyrec

DESCRIPTION

expchk vérifie un ensemble de fichiers keyrec pour déterminer si les enregistrements de zone keyrec sont valides ou expirés. Le type de zones affiché dépend des options choisies ; si aucune option n'est donnée, les zones expirées seront listées.

OPTIONS

-all
Affiche les informations d'expiration sur toutes les zones, expirées ou valides, dans les fichiers keyrec spécifiés.
-expired
Affiche les informations d'expiration sur les zones expirées dans les fichiers keyrec spécifiés. C'est l'action par défaut.
-valid
Affiche les informations d'expiration sur les zones valides dans les fichiers keyrec spécifiés.
-warn numjours
Un avertissement sera donné pour chaque zone valide qui expirera dans numjours jours. Cette option n'a aucun effet sur les zones expirées.
-zone nomzone
Affiche les informations d'expiration sur la zone spécifiée dans nomzone.
-count
Seul le compte des zones correspondantes (valides ou expirées) sera donné. Si les deux types de zones sont sélectionnés, alors le compte sera le nombre de zones dans les fichiers keyrec spécifiés.
-help
Affiche un message d'utilisation.
-Version
Affiche les informations de version pour expchk et le paquet DNSSEC-Tools.
