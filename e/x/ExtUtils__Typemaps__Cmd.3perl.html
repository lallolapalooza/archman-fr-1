ExtUtils::Typemaps::Cmd(3perl) Guide du programmeur Perl ExtUtils::Typemaps::Cmd(3perl)

NOM

ExtUtils::Typemaps::Cmd - Commandes rapides pour la gestion des typemaps

SYNTAXE

Depuis XS :

INCLUDE_COMMAND: $^X -MExtUtils::Typemaps::Cmd \
                 -e "print embeddable_typemap(q{Excommunicated})"

Charge "ExtUtils::Typemaps::Excommunicated", instancie un objet et le déverse sous forme de typemap intégrable pour une utilisation directe dans votre fichier XS.

DESCRIPTION

Ceci est un module d'aide pour ExtUtils::Typemaps pour des lignes de commande rapides, spécifiquement pour l'inclusion de typemaps partagés qui résident sur CPAN dans un fichier XS (voir SYNTAXE).

Pour cette raison, les fonctions suivantes sont exportées par défaut :

FONCTIONS EXPORTÉES

embeddable_typemap

Étant donné une liste d'identifiants, "embeddable_typemap" essaie de charger des typemaps à partir d'un fichier du ou des noms donnés, ou à partir d'un module qui est une sous-classe de "ExtUtils::Typemaps".

Retourne une représentation sous forme de chaîne des typemaps fusionnés qui peut être incluse verbatim dans XS. Exemple :

print embeddable_typemap(
  "Excommunicated", "ExtUtils::Typemaps::Basic", "./typemap"
);

Ceci essaiera de charger un module "ExtUtils::Typemaps::Excommunicated" et de l'utiliser comme sous-classe de "ExtUtils::Typemaps". Si cela échoue, il essaiera de charger "Excommunicated" comme module, si cela échoue, il essaiera de lire un fichier appelé Excommunicated. Il fonctionnera de manière similaire pour le deuxième argument, mais le troisième sera chargé en premier comme un fichier.

Après avoir chargé tous les fichiers ou modules de typemap, il les fusionnera dans l'ordre spécifié et déversera le résultat en tant que typemap intégrable.
