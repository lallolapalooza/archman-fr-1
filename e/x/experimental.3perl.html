experimental(3perl) Guide de référence pour les programmeurs Perl experimental(3perl)

NOM

experimental - Fonctionnalités expérimentales facilitées

VERSION

version 0.035

SYNOPSIS

use experimental 'lexical_subs', 'signatures';
my sub plus_one($value) { $value + 1 }

DESCRIPTION

Ce pragma offre un moyen facile et pratique d'activer ou de désactiver des fonctionnalités expérimentales.

Chaque version de perl contient un certain nombre de fonctionnalités présentes mais considérées comme « expérimentales ». Pendant une grande partie de la vie de Perl 5, il ne s'agissait que d'une désignation trouvée dans la documentation. À partir de Perl v5.10.0, et plus agressivement en v5.18.0, les fonctionnalités expérimentales ont été placées derrière des pragmas utilisés pour activer la fonctionnalité et désactiver les avertissements associés.

Le pragma "experimental" existe pour combiner les incantations nécessaires en une seule interface stable à travers les versions de perl. Pour chaque fonctionnalité expérimentale, cela devrait activer la fonctionnalité et supprimer les avertissements pour la portée lexicale englobante :

use experimental 'feature-name';

Pour désactiver la fonctionnalité et, le cas échéant, réactiver les avertissements, utilisez :

no experimental 'feature-name';

Les fonctionnalités prises en charge, documentées plus loin, sont :

  • "args_array_with_signatures" - autorise l'utilisation de @_ dans les sous-fonctions signées.

    Ceci est pris en charge à partir de perl 5.20.0, mais sera probablement supprimé à l'avenir.

  • "array_base" - autorise l'utilisation de $[ pour changer l'index de départ de @array.

    Ceci a été supprimé dans perl 5.30.0.

  • "autoderef" - autorise push, each, keys, et d'autres fonctions intégrées sur des références.

    Ceci a été ajouté dans perl 5.14.0 et supprimé dans perl 5.24.0.

  • "bitwise" - autorise les nouveaux opérateurs bit à bit au niveau des chaînes.

    Ceci a été ajouté dans perl 5.22.0.

  • "builtin" - autorise l'utilisation des fonctions de l'espace de noms builtin::

    Ceci a été ajouté dans perl 5.36.0

  • "const_attr" - autorise l'attribut :const sur les sous-fonctions.

    Ceci a été ajouté dans perl 5.22.0.

  • "declared_refs" - active l'aliasing via l'assignation à des références.

    Ceci a été ajouté dans perl 5.26.0.

  • "defer" - active l'utilisation des blocs defer.

    Ceci a été ajouté dans perl 5.36.0

  • "extra_paired_delimiters" - active l'utilisation de délimiteurs de chaînes supplémentaires par rapport aux quatre traditionnels, "<  >", "( )", "{ }", et "[ ]".

    Ceci a été ajouté dans perl 5.36.

  • "for_list" - autorise l'itération sur plusieurs valeurs à la fois avec "for".

    Ceci a été ajouté dans perl 5.36.0

  • "isa" - autorise l'utilisation de l'opérateur infix "isa".

    Ceci a été ajouté dans perl 5.32.0.

  • "lexical_topic" - autorise l'utilisation du $_ lexical via "my $_".

    Ceci a été ajouté dans perl 5.10.0 et supprimé dans perl 5.24.0.

  • "lexical_subs" - autorise l'utilisation de sous-routines lexicales.

    Ceci a été ajouté en 5.18.0, et est devenu non expérimental (et toujours activé) en 5.26.0.

  • "postderef" - autorise l'utilisation d'expressions de déréférencement postfixées.

    Ceci a été ajouté dans perl 5.20.0, et est devenu non expérimental (et toujours activé) en 5.24.0.

  • "postderef_qq" - autorise l'utilisation d'expressions de déréférencement postfixées à l'intérieur de chaînes d'interpolation.

    Ceci a été ajouté dans perl 5.20.0, et est devenu non expérimental (et toujours activé) en 5.24.0.

  • "re_strict" - active le mode strict dans les expressions régulières.

    Ceci a été ajouté dans perl 5.22.0.

  • "refaliasing" - autorise l'aliasing via "\$x = \$y".

    Ceci a été ajouté dans perl 5.22.0.

  • "regex_sets" - autorise les classes de caractères étendues entre crochets dans les expressions régulières.

    Ceci a été ajouté dans perl 5.18.0, et est devenu non expérimental (et toujours activé) en 5.36.0.

    Ceci est documenté dans "Extended Bracketed Character Classes" dans perlrecharclass.

  • "signatures" - autorise les signatures de sous-routines (pour les arguments nommés).

    Ceci a été ajouté dans perl 5.20.0.

  • "smartmatch" - autorise l'utilisation de "~~".

    Ceci a été ajouté dans perl 5.10.0, mais il convient de noter qu'il existe des incompatibilités importantes entre 5.10.0 et 5.10.1.

    La fonctionnalité a été dépréciée dans perl 5.38.0 et non dépréciée dans 5.42.0.

  • "switch" - autorise l'utilisation de "~~", given, et when.

    Ceci a été ajouté dans perl 5.10.0.

    La fonctionnalité a été dépréciée dans perl 5.38.0 et non dépréciée dans 5.42.0.

  • "try" - autorise l'utilisation de "try" et "catch".

    Ceci a été ajouté dans perl 5.34.0

  • "win32_perlio" - autorise l'utilisation de la couche IO :win32.

    Ceci a été ajouté dans perl 5.22.0.

L'ordre est important

Utiliser ce pragma pour « activer une fonctionnalité expérimentale » est une autre façon de dire que ce pragma désactivera les avertissements qui résulteraient de l'utilisation de cette fonctionnalité. Par conséquent, l'ordre dans lequel les pragmas sont appliqués est important. En particulier, vous voudrez probablement activer les fonctionnalités expérimentales *après* avoir activé les avertissements :

use warnings;
use experimental 'smartmatch';

Vous devez également faire attention avec les modules qui activent les avertissements pour vous. Un exemple courant est Moose. Dans cet exemple, les avertissements pour la fonctionnalité 'smartmatch' sont d'abord activés par le pragma warnings, désactivés par le pragma experimental, et réactivés par le module Moose (la solution consiste à inverser les deux dernières lignes) :

use warnings;
use experimental 'smartmatch';
use Moose;

Avertissement

En raison de la nature des fonctionnalités qu'il active, la compatibilité ascendante ne peut être garantie d'aucune manière.
