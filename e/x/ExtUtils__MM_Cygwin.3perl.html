ExtUtils::MM_Cygwin(3perl) Guide de référence du programmeur Perl ExtUtils::MM_Cygwin(3perl)

NOM

ExtUtils::MM_Cygwin - méthodes pour outrepasser le comportement UN*X dans ExtUtils::MakeMaker

SYNTAXE

use ExtUtils::MM_Cygwin; # Fait en interne par ExtUtils::MakeMaker si nécessaire

DESCRIPTION

Voir ExtUtils::MM_Unix pour une documentation des méthodes fournies là-bas.

os_flavor
Nous sommes Unix et Cygwin.
cflags
Si configuré pour le chargement dynamique, déclenche #define EXT dans EXTERN.h
replace_manpage_separator
remplace les chaînes '::' par '.' dans les noms de pages de manuel MAN*POD
init_linker
pointe vers libperl.a
maybe_command
Détermine si un fichier est natif de Cygwin en vérifiant s'il réside à l'intérieur de l'installation Cygwin (en utilisant des chemins Windows). Si c'est le cas, utilise ExtUtils::MM_Unix pour déterminer s'il peut s'agir d'une commande. Sinon, utilise les tests d'ExtUtils::MM_Win32.
dynamic_lib
Utilise la valeur par défaut pour produire les *.dll. Mais pour les nouvelles dlls archdir, utilise la même adresse de rebasage si l'ancienne existe.
install
Rebase les dlls avec la base de données de rebasage globale après l'installation.
