E4CRYPT(8) Manuel du gestionnaire système E4CRYPT(8)

NOM

e4crypt - utilitaire de chiffrement de système de fichiers ext4

SYNOPIS

e4crypt add_key -S [ -k keyring ] [-v] [-q] [ -p pad ] [ chemin ... ]
e4crypt new_session
e4crypt get_policy chemin ...
e4crypt set_policy [ -p pad ] politique chemin ...

DESCRIPTION

e4crypt gère le chiffrement pour les systèmes de fichiers ext4.

COMMANDES

e4crypt add_key [-vq] [-S sel ] [-k keyring ] [ -p pad ] [ chemin ... ]
Demande à l'utilisateur un mot de passe et l'insère dans le keyring spécifié. Si aucun keyring n'est spécifié, e4crypt utilisera le keyring de session s'il existe ou le keyring de session utilisateur s'il n'existe pas.
L'argument sel est interprété de différentes manières, en fonction de sa valeur préfixée. Si les deux premiers caractères sont "s:", le reste de l'argument sera utilisé comme une chaîne de texte et servira de valeur de sel. Si les deux premiers caractères sont "0x", le reste de l'argument sera analysé comme une chaîne hexadécimale et utilisé comme sel. Si les premiers caractères sont "f:", le reste de l'argument sera interprété comme un nom de fichier à partir duquel la valeur du sel sera lue. Si la chaîne commence par un caractère '/', elle sera également traitée comme un nom de fichier. Enfin, si l'argument sel peut être analysé comme un UUID valide, alors la valeur de l'UUID sera utilisée comme valeur de sel.
L'argument keyring spécifie le keyring auquel la clé doit être ajoutée.
La valeur pad spécifie le nombre d'octets de remplissage qui seront ajoutés aux noms de répertoires à des fins d'obfuscation. Les valeurs valides pour pad sont 4, 8, 16 et 32.
Si un ou plusieurs chemins de répertoires sont spécifiés, e4crypt essaiera de définir la politique de ces répertoires pour utiliser la clé qui vient d'être ajoutée par la commande add_key. Si un sel a été explicitement spécifié, il sera utilisé pour dériver la clé de chiffrement de ces répertoires. Sinon, un sel par défaut spécifique au répertoire sera utilisé.
e4crypt get_policy chemin ...
Affiche la politique des répertoires spécifiés sur la ligne de commande.
e4crypt new_session
Donne au processus appelant (généralement un shell) un nouveau keyring de session, en rejetant son ancien keyring de session.
e4crypt set_policy [ -p pad ] politique chemin ...
Définit la politique pour les répertoires spécifiés sur la ligne de commande. Tous les répertoires doivent être vides pour définir la politique ; si le répertoire a déjà une politique établie, e4crypt vérifiera que la politique correspond à celle qui a été spécifiée. Une politique est un identifiant de clé de chiffrement constitué de 16 caractères hexadécimaux.
