NOM

eqn — référence du langage eqn pour mandoc

DESCRIPTION

Le langage eqn est un langage de mise en forme d'équations. Il est utilisé dans les pages de manuel mdoc(7) et man(7). Il décrit la structure d'une équation, pas sa signification mathématique. Ce manuel décrit le langage eqn accepté par l'utilitaire mandoc(1), qui correspond à la spécification eqn de la Deuxième Édition (voir VOIR AUSSI pour les références).

Une équation commence par une ligne d'entrée contenant exactement les caractères « .EQ », peut contenir plusieurs lignes d'entrée et se termine par une ligne d'entrée contenant exactement les caractères « .EN ». Alternativement, une équation peut être donnée au milieu d'une seule ligne de texte d'entrée en l'entourant des délimiteurs d'équation définis avec l'instruction delim.

La grammaire de l'équation est la suivante, où les chaînes de caractères entre guillemets sont des littéraux sensibles à la casse dans l'entrée :

eqn     : box | eqn box
box     : text
        | "{" eqn "}"
        | "define" text text
        | "ndefine" text text
        | "tdefine" text text
        | "gfont" text
        | "gsize" text
        | "set" text text
        | "undef" text
        | "sqrt" box
        | box pos box
        | box mark
        | "matrix" "{" [col "{" list "}" ]* "}"
        | pile "{" list "}"
        | font box
        | "size" text box
        | "left" text eqn ["right" text]
col     : "lcol" | "rcol" | "ccol" | "col"
text    : [^espace"]+ | ".*"
pile    : "lpile" | "cpile" | "rpile" | "pile"
pos     : "over" | "sup" | "sub" | "to" | "from"
mark    : "dot" | "dotdot" | "hat" | "tilde" | "vec"
        | "dyad" | "bar" | "under"
font    : "roman" | "italic" | "bold" | "fat"
list    : eqn
        | list "above" eqn
espace  : [^~ \t]

Les espaces blancs sont constitués des caractères espace, tabulation, circonflexe et tilde. Ils sont requis pour délimiter les jetons constitués de caractères alphabétiques et ils sont ignorés ailleurs. Les accolades et les guillemets délimitent également les jetons. S'ils sont dans une chaîne entre guillemets, ces caractères d'espacement sont conservés. Les chaînes entre guillemets ne sont pas analysées pour les mots-clés, les noms de glyphes et l'expansion des définitions. Pour afficher un caractère guillemet littéral, il peut être précédé d'une barre oblique inverse ou exprimé avec la séquence d'échappement \(dq.

Les sous-équations peuvent être entourées d'accolades pour les passer en arguments aux mots-clés d'opération, remplaçant ainsi la priorité standard des opérations. Les accolades peuvent être imbriquées. Pour définir une accolade verbatim, elle doit être entourée de guillemets.

Les termes textuels suivants sont traduits en un glyphe rendu, s'il est disponible : alpha, beta, chi, delta, epsilon, eta, gamma, iota, kappa, lambda, mu, nu, omega, omicron, phi, pi, psi, rho, sigma, tau, theta, upsilon, xi, zeta, DELTA, GAMMA, LAMBDA, OMEGA, PHI, PI, PSI, SIGMA, THETA, UPSILON, XI, inter (intersection), union (union), prod (produit), int (intégrale), sum (somme), grad (gradient), del (différentielle vectorielle), times (multiplication), cdot (point centré), nothing (espace de largeur nulle), approx (égal approximativement), prime (prime), half (un demi), partial (dérivée partielle), inf (infini), >> (beaucoup plus grand), << (beaucoup plus petit), <- (flèche gauche), -> (flèche droite), +- (plus-moins), != (non égal), == (équivalence), <= (inférieur ou égal), et >= (supérieur ou égal). Les séquences d'échappement de caractères documentées dans mandoc_char(7) peuvent également être utilisées.

Les instructions de contrôle suivantes sont disponibles :

define
Remplace toutes les occurrences d'une clé par une valeur. Sa syntaxe est la suivante :
define clé cvaleurc

Le premier caractère de la chaîne de valeur, c, est utilisé comme délimiteur pour la valeur valeur. Cela permet une clôture arbitraire des termes (pas seulement des guillemets), comme

define foo 'bar baz'
define foo cbar bazc

C'est une erreur d'avoir une clé ou une valeur vide. Notez qu'une clé entre guillemets provoque des erreurs dans certaines implémentations de eqn et ne doit pas être considérée comme portable. Elle n'est pas expansée pour les remplacements. Les définitions peuvent faire référence à d'autres définitions ; celles-ci sont évaluées récursivement lors du remplacement de texte et non lors de la création de la définition.

Les définitions peuvent créer des chaînes arbitraires, par exemple, la construction suivante est légale.

define foo 'define'
foo bar 'baz'

Les définitions auto-référentielles lèveront une erreur. L'instruction ndefine est synonyme de define, tandis que tdefine est ignorée.

delim
Cette instruction prend un argument de chaîne composé de deux octets, à utiliser comme délimiteurs d'ouverture et de fermeture pour les équations au milieu des lignes de texte. Conventionnellement, le signe dollar est utilisé pour les deux délimiteurs, comme suit : 
.EQ
delim $$
.EN
Une équation comme $sin pi = 0$ peut maintenant être saisie
au milieu d'une ligne de texte.

L'instruction spéciale delim off désactive temporairement les délimiteurs précédemment déclarés et delim on les réactive.

gfont
Définit la police par défaut de la sortie ultérieure. Sa syntaxe est la suivante :
gfont police

Dans mandoc, cette valeur est ignorée.

gsize
Définit la taille par défaut de la sortie ultérieure. Sa syntaxe est la suivante :
gsize [+|-]taille

La valeur de taille doit être un entier. Si elle est précédée d'un signe, la taille de la police est modifiée par rapport à la taille actuelle.

set
Définit un mode d'équation. Dans mandoc, les deux arguments sont ignorés. Sa syntaxe est la suivante :
set clé valeur

La clé et la valeur ne sont pas expansées pour les remplacements. Cette instruction est une extension GNU.

undef
Annule une clé précédemment définie. Sa syntaxe est la suivante :
define clé

Une fois invoquée, la définition de clé est ignorée. La clé n'est pas expansée pour les remplacements. Cette instruction est une extension GNU.

COMPATIBILIT

É

Cette section documente la compatibilité de eqn de mandoc et de l'implémentation eqn de troff (y compris GNU troff)

.
  • La chaîne de texte ‘\"’ est interprétée comme une citation littérale dans troff. Dans mandoc, ceci est interprété comme un
    • commentaire.
  • Dans troff, les symboles d'espacement blanc circonflexe et tilde correspondent à des espaces de largeur fixe. Dans mandoc, ces caractères sont des synonymes du caractère
    • espace.
  • L'implémentation de eqn dans troff permet l'alignement d'équations avec les jetons mark et lineup. mandoc rejette ces jetons. Les commandes back n, fwd n, up n, et down n sont égalem
    • ent
ign
orées.

HISTORIQU

E

L'utilitaire eqn, un préprocesseur pour troff, a été écrit à l'origine par Brian W. Kernighan et Lorinda L. Cherry en 1975. La réimplémentation GNU de eqn, partie du paquet GNU troff, a été publiée en 1989 par James Clark. Le composant eqn de mandoc(1) a été

ajouté
en 2011.
