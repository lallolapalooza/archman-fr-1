NOM

elf_hash, elf_gnu_hash - Calculer le hachage ELF standard ou le hachage GNU d'une chaîne.

SYNTAXE

#include <libelf.h>
unsigned long int elf_hash(const char *string);
unsigned long int elf_gnu_hash(const char *string);

DESCRIPTION

La fonction elf_hash calcule la valeur de hachage ELF standard pour une chaîne terminée par un caractère nul. Les valeurs de hachage sont généralement utilisées dans les fichiers objets ELF pour le hachage de la table des symboles. La fonction de hachage est utilisée dans les sections SHT_HASH car elle évite de générer des valeurs dépendantes de l'architecture et convient à une utilisation sur différentes architectures.

La fonction elf_gnu_hash calcule la valeur de hachage de style GNU d'une chaîne terminée par un caractère nul, utilisée dans la section SHT_GNU_HASH.

PARAMETRES

string
Chaîne terminée par un caractère nul à hacher.

VALEUR DE RETOUR

Ces fonctions retournent une valeur de hachage pour string. Seuls les 32 bits de poids faible de la valeur de retour sont utilisés.

VOIR AUSSI

libelf(3), elf(5)

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
elf_hash (), elf_gnu_hash () Sécurité des threads MT-Safe

SIGNALEMENT DE BOGUES

Signalez les bogues à <elfutils-devel@sourceware.org> ou https://sourceware.org/bugzilla/.

HISTORIQUE

elf_gnu_hash est apparu pour la première fois dans elfutils 0.122. Cette fonction est une extension de libelf d'elfutils et peut ne pas être disponible dans d'autres implémentations de libelf.
