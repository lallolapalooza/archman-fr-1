ELF32_NEWPHDR(3) Manuel du programmeur Libelf ELF32_NEWPHDR(3)

NOM

elf32_newphdr, elf64_newphdr - créer une nouvelle table d'en-têtes de programme pour un fichier objet ELF 32 bits ou 64 bits

SYNTAXE

#include <libelf.h>
Elf32_Phdr *elf32_newphdr(Elf *elf, size_t count);
Elf64_Phdr *elf64_newphdr(Elf *elf, size_t count);

DESCRIPTION

Crée une nouvelle table d'en-têtes de programme pour le fichier objet ELF référencé par elf. Le nombre d'entrées dans la nouvelle table d'en-têtes de programme est spécifié par count. Un count de zéro supprime la table d'en-têtes de programme existante.

La fonction alloue un nouveau tableau de Elf32_Phdr et en fait la table d'en-têtes de programme pour elf. Le contenu de la nouvelle table d'en-têtes de programme est mis à zéro et toute table d'en-têtes de programme précédente est rejetée. Un en-tête ELF doit exister avant de créer une table d'en-têtes de programme.

PARAMÈTRES

elf
Pointeur vers l'objet ELF pour lequel une nouvelle table d'en-têtes de programme doit être créée.
count
Le nombre d'entrées dans la nouvelle table d'en-têtes de programme. Un compte de zéro supprime la table d'en-têtes de programme existante.

VALEUR DE RETOUR

En cas de succès, retourne un pointeur vers le premier Elf32_Phdr de la table d'en-têtes de programme nouvellement créée. Si elf est NULL, retourne NULL. Si une erreur survient, retourne NULL et définit un code d'erreur libelf.
