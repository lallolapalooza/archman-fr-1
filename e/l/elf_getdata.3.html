NOM

elf_getdata - Obtenir les données lavées d'une section

SYNOPSIS

#include <libelf.h>

Elf_Data * elf_getdata (Elf_Scn *scn, Elf_Data *data);

DESCRIPTION

La fonction elf_getdata() permet à l'utilisateur de récupérer les tampons de données de la section scn
. Il peut y avoir plus d'un tampon si l'utilisateur en a explicitement ajouté. Lorsqu'un fichier est lu, la bibliothèque libelf crée exactement un tampon de données.

Le premier tampon de la liste peut être obtenu en passant un pointeur nul dans le paramètre data. Pour obtenir le tampon de données suivant, la valeur précédemment retournée doit être passée dans le paramètre data. S'il n'y a plus de tampon dans la liste, un pointeur nul est retourné.

Si le paramètre data n'est pas un pointeur nul, il doit s'agir d'un descripteur pour un tampon associé à la section scn . Si ce n'est pas le cas, un pointeur nul est retourné. Pour faciliter la gestion des erreurs, elf_getdata retourne également un pointeur nul si le paramètre scn est un pointeur nul.
