ELF32_XLATETOM(3) Manuel du programmeur Libelf ELF32_XLATETOM(3)

NOM

elf32_xlatetom, elf64_xlatetom - traduit les données ELF 32 bits ou 64 bits de la représentation fichier vers la représentation mémoire
elf32_xlatetof, elf64_xlatetof - traduit les données ELF 32 bits ou 64 bits de la représentation mémoire vers la représentation fichier

SYNTAXE

#include <libelf.h>
int elf32_xlatetom(Elf_Data *dst, const Elf_Data *src, unsigned int encoding);
int elf64_xlatetom(Elf_Data *dst, const Elf_Data *src, unsigned int encoding);
int elf32_xlatetof(Elf_Data *dst, const Elf_Data *src, unsigned int encoding);
int elf64_xlatetof(Elf_Data *dst, const Elf_Data *src, unsigned int encoding);

DESCRIPTION

Traduit les données ELF de la représentation fichier vers la représentation mémoire ou inversement. Les représentations fichier et mémoire des données ELF peuvent différer en termes d'endianness. Les données en représentation fichier proviennent normalement de elf_rawdata, tandis que les données en représentation mémoire proviennent normalement de elf_getdata. Lorsqu'il n'y a pas de différence entre les représentations fichier et mémoire, ces fonctions copient simplement les données ELF de src vers dst. Sinon, l'encodage alternera entre ELFDATA2LSB (complément à deux en little-endian) et ELFDATA2MSB (complément à deux en big-endian). L'encodage d'un fichier ELF est spécifié dans le membre Elf32_Ehdr ou Elf64_Ehdr e_ident[EI_DATA]. Pour connaître l'encodage mémoire d'un programme, vous pouvez faire un #include <endian.h> et vérifier BYTE_ORDER == LITTLE_ENDIAN (correspondant à ELFDATA2LSB) ou BYTE_ORDER == BIG_ENDIAN (correspondant à ELFDATA2MSB).

PARAMÈTRES

dst
Destination où seront stockées les données traduites. Le champ d_size de dst doit être au moins aussi grand que le champ d_size de src.
src
Données source. Pour les fonctions xlatetom, les données source doivent être en représentation fichier. Pour les fonctions xlatetof, les données source doivent être en représentation mémoire.
encoding
Spécifie un encodage. Peut être soit ELFDATA2LSB (complément à deux en little-endian), soit ELFDATA2MSB (complément à deux en big-endian). Pour les fonctions xlatetom, ceci spécifie l'encodage de src. Pour les fonctions xlatetof, ceci spécifie l'encodage de dst.

VALEUR DE RETOUR

En cas de succès, renvoie dst, qui contiendra les données traduites. S'il n'y a pas de différence entre les représentations fichier et mémoire, dst contiendra une copie des données source. Les champs d_type et d_size de dst seront définis à ceux de src.


En cas d'erreur, renvoie NULL et définit un code d'erreur libelf.
