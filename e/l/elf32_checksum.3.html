ELF32_CHECKSUM(3) Manuel du programmeur Libelf ELF32_CHECKSUM(3)

NOM

elf32_checksum, elf64_checksum - calculer la somme de contrôle pour un fichier objet ELF 32 bits ou 64 bits

SYNTAXE

#include <libelf.h>
long int elf32_checksum(Elf *elf);
long int elf64_checksum(Elf *elf);

DESCRIPTION

Calcule une somme de contrôle pour le fichier objet ELF désigné par elf. La somme de contrôle est calculée à partir des parties permanentes du fichier ELF et le résultat est reproductible. Pour être reproductible, les sections supprimables ne sont pas incluses dans le calcul de la somme de contrôle. Les sections SHT_NOBITS ne sont pas non plus incluses lors du calcul de la somme de contrôle. La somme de contrôle peut être utilisée comme valeur pour DT_CHECKSUM.

PARAMETRES

elf
Le fichier objet ELF pour lequel la somme de contrôle doit être calculée.

VALEUR DE RETOUR

En cas de succès, retourne la somme de contrôle calculée. Si une erreur se produit, retourne -1 et définit un code d'erreur libelf. La somme de contrôle est toujours calculée comme une valeur de 4 octets. Si long int est plus grand que 4 octets, alors la somme de contrôle sera étendue par un remplissage de zéros.

VOIR AUSSI

elf_errno(3), libelf(3), elf(5)

ATTRIBUTS
