NOM

elf_getbase - Récupérer l'offset de base pour un fichier objet ELF.

SYNOPSIS

#include <libelf.h>

int64_t elf_getbase(Elf *elf);

DESCRIPTION

elf_getbase renvoie l'offset dans le fichier du premier octet du descripteur ELF elf. Si elf est un membre d'une archive et a le type ELF ELF_K_AR, l'offset de base est l'offset de l'objet ELF dans l'archive. Pour les autres types d'objets ELF, l'offset de base est 0.

PARAMÈTRES

elf
Le descripteur ELF.

VALEUR DE RETOUR

Renvoie l'offset de base de elf si son type ELF est ELF_K_AR, sinon renvoie 0. Si elf est NULL, renvoie -1.

VOIR AUSSI

elf_getaroff(3), elf_rawelf(3), libelf(3), elf(5)
