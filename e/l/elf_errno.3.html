NOM

elf_errno - récupérer le code d'erreur du dernier appel de fonction libelf échoué.

SYNTAXE

#include <libelf.h>

int elf_errno(void);

DESCRIPTION

La fonction elf_errno récupère le code d'erreur de la dernière fonction de la bibliothèque libelf ayant échoué. Ce code d'erreur indique le type d'erreur qui s'est produit lors de l'appel de fonction échoué. Chaque thread maintient son propre code d'erreur distinct.

PARAMETRES

Cette fonction ne prend aucun paramètre.

VALEUR DE RETOUR

La fonction elf_errno retourne un entier représentant le code d'erreur le plus récent pour le thread courant. Si aucune erreur ne s'est produite, elle retourne 0. Si une erreur s'est produite, la fonction retourne un code d'erreur non nul qui correspond à l'erreur spécifique. Les codes d'erreur peuvent être passés à elf_errmsg afin de créer une chaîne décrivant l'erreur.

VOIR AUSSI

elf_errmsg(3)
