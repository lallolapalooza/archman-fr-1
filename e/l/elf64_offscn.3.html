NOM

elf64_offscn - récupérer un descripteur de section par décalage de fichier pour un fichier ELF 64 bits

SYNTAXE

#include <libelf.h>

Elf_Scn *elf64_offscn(Elf *elf, off_t offset);

DESCRIPTION

La fonction elf64_offscn récupère le descripteur de section pour la section non vide au décalage de fichier spécifié dans l'objet ELF64 référencé par elf.

PARAMETRES

elf
Un pointeur Elf vers l'objet ELF dont le descripteur de section doit être récupéré.
offset
Une valeur off_t représentant le décalage de fichier de la section dont le descripteur doit être récupéré.

VALEUR DE RETOUR

La fonction elf64_offscn renvoie un pointeur vers le Elf_Scn de la section non vide dont le sh_offset correspond à offset. En cas d'erreur, elle renvoie NULL et définit un code d'erreur libelf approprié.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
elf64_offscn () Sécurité des threads MT-Safe

VOIR AUSSI

elf32_offscn(3), libelf(3), elf(5),

SIGNALER DES BOGUES

Signaler les bogues à <elfutils-devel@sourceware.org> ou https://sourceware.org/bugzilla/.

HISTORIQUE

elf64_offscn est apparu pour la première fois dans elfutils 0.112. Cette fonction libelf d'elfutils peut ne pas se trouver dans d'autres implémentations de libelf.
