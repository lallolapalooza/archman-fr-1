ELF32_GETCHDR(3) Manuel du programmeur Libelf ELF32_GETCHDR(3)

NOM

elf32_getchdr, elf64_getchdr - récupérer l'en-tête de compression d'une section à partir d'un fichier objet ELF 32 bits ou 64 bits.

SYNTAXE

#include <libelf.h>
Elf32_Chdr *elf32_getchdr(Elf_Scn *scn);
Elf64_Chdr *elf64_getchdr(Elf_Scn *scn);

DESCRIPTION

Récupère l'en-tête de compression pour une section contenant des données compressées. Les sections avec des données compressées sont indiquées par le drapeau SHF_COMPRESSED. Voir libelf(3) pour plus d'informations sur l'en-tête de compression.

PARAMÈTRES

scn
Section dont l'en-tête de compression sera récupéré. Le drapeau SHF_COMPRESSED de la section doit être défini.

VALEUR DE RETOUR

En cas de succès, retourne un pointeur vers l'en-tête de compression. En cas d'échec, retourne NULL et définit un code d'erreur libelf.

VOIR AUSSI

elf_compress(3), elf_errno(3), libelf(3), elf(5)

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
elf32_getchdr (), elf64_getchdr () Sécurité des threads Sûr pour les threads (MT-Safe)

SIGNALEMENT DE BOGUES

Signaler les bogues à <elfutils-devel@sourceware.org> ou https://sourceware.org/bugzilla/.

HISTORIQUE

elf32_getchdr est apparu pour la première fois dans elfutils 0.165.
