ELF_NEXTSCN(3) Manuel du programmeur Libelf ELF_NEXTSCN(3)

NOM

elf_nextscn - Retourne la section suivante dans un descripteur ELF.

SYNTAXE

#include <libelf.h>
Elf_Scn *elf_nextscn(Elf *elf, Elf_Scn *scn);

DESCRIPTION

La fonction elf_nextscn() retourne un handle vers la section suivante dans le descripteur d'objet ELF elf. Si scn est NULL, la première section (avec l'index 1) est retournée. L'index de section 0 est réservé et ignoré.

Si scn n'est pas NULL, la section qui le suit immédiatement est retournée. S'il n'y a plus de sections, NULL est retourné.

PARAMETRES

elf
Un pointeur vers un descripteur ELF.
scn
Un handle de section retourné par elf_getscn(3), ou NULL pour commencer l'itération.

VALEUR DE RETOUR

Retourne un pointeur vers la structure Elf_Scn suivante dans la liste des sections, ou NULL s'il n'y a plus de sections ou si elf est NULL.

VOIR AUSSI

elf_getscn(3), elf_newscn(3), libelf(3), elf(5)

ATTRIBUTS

Interface Attribut Valeur
elf_nextscn () Sécurité thread MT-Safe
