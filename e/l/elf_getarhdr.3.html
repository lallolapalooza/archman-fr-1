ELF_GETARHDR(3) Manuel du programmeur Libelf ELF_GETARHDR(3)

NOM

elf_getarhdr - récupérer les informations d'en-tête d'un membre d'archive

SYNTAXE

#include <libelf.h>
Elf_Arhdr *elf_getarhdr(Elf *elf);

DESCRIPTION

Retourne un pointeur Elf_Arhdr * décrivant l'en-tête d'archive du membre d'archive actuellement référencé par un descripteur ELF.

La structure Elf_Arhdr est définie comme suit :

typedef struct {
  char *ar_name;                /* Nom du membre d'archive.  */
  time_t ar_date;               /* Date du fichier.  */
  uid_t ar_uid;                 /* ID utilisateur.  */
  gid_t ar_gid;                 /* ID groupe.  */
  mode_t ar_mode;               /* Mode du fichier.  */
  int64_t ar_size;              /* Taille du fichier.  */
  char *ar_rawname;             /* Nom original du membre d'archive.  */
} Elf_Arhdr;

PARAMETRES

elf
Un descripteur ELF faisant référence à un membre d'un fichier archive.

VALEUR DE RETOUR

Si elf fait référence à un membre d'archive, elf_getarhdr() retourne un pointeur vers son en-tête d'archive. Ce pointeur est valide jusqu'à ce que elf ou le descripteur Elf d'archive parent soient fermés à l'aide de elf_end(). Si elf ne fait pas référence à un membre d'archive ou si l'en-tête ne peut pas être acquis, NULL est retourné.

VOIR AUSSI

elf_begin(3), elf_getaroff(3), elf_next(3), elf_rand(3), libelf(3), elf(5)

ATTRIBUTS
