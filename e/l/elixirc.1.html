NOM

elixirc — Le compilateur Elixir

SYNTAXE

elixirc [OPTIONS] fichier ...

DESCRIPTION

Le compilateur est destiné à compiler un ou plusieurs fichiers contenant le code source Elixir. Les fichiers doivent avoir l'extension .ex.

OPTIONS

-o répertoire
Place le fichier de sortie dans le répertoire spécifié. Si le répertoire n'est pas spécifié via l'option, le répertoire de travail actuel sera utilisé.
--erl paramètres
Sert le même objectif que ELIXIR_ERL_OPTIONS (voir la section ENVIRONNEMENT).
--ignore-module-conflict
Désactive les avertissements lorsqu'un module a déjà été défini.
--no-debug-info
Désactive la génération d'informations de débogage.
--no-docs
Désactive la génération de la documentation.
--warnings-as-errors
Transforme tous les avertissements en erreurs.
--verbose
Active le mode verbeux.
--
Sépare les options passées au compilateur des options passées au code exécuté.

ENVIRONNEMENT

ELIXIR_ERL_OPTIONS
Permet de passer des paramètres au runtime Erlang.
ERL_COMPILER_OPTIONS
Permet de passer des paramètres au compilateur Erlang (voir erlc(1)).
