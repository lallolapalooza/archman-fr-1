NOM

elf_version - définit la version ELF pour libelf.

SYNTAXE

#include <libelf.h>

unsigned int elf_version(unsigned int version);

DESCRIPTION

La fonction elf_version définit la version ELF de libelf à la valeur spécifiée. Cette fonction doit être appelée avant toute autre fonction libelf.

PARAMÈTRES

version
Une valeur de type unsigned int spécifiant la version ELF souhaitée pour la bibliothèque. Elle doit être définie à EV_CURRENT pour indiquer la version ELF actuelle. À ce stade, la seule version ELF prise en charge est EV_CURRENT.

VALEUR DE RETOUR

La fonction elf_version retourne EV_CURRENT si version est supportée et définit la version ELF de la bibliothèque à cette valeur. Si la valeur donnée version est EV_NONE, alors cette fonction retourne EV_CURRENT et ne définit pas la version ELF de la bibliothèque. Si la version spécifiée n'est pas supportée, cette fonction retourne EV_NONE.

SIGNALEMENT DE BOGUES

Signalez les bogues à <elfutils-devel@sourceware.org> ou à https://sourceware.org/bugzilla/.
