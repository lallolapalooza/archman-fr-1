NOM

elf_end - Libérer les ressources associées à un descripteur ELF.

SYNTAXE

#include <libelf.h>
int elf_end(Elf *elf);

DESCRIPTION

La fonction elf_end libère les ressources associées à un descripteur ELF précédemment retourné par elf_begin. Elle décrémente le compteur de références interne du descripteur ELF de un. Lorsque ce compteur atteint zéro, les ressources associées au descripteur sont libérées et le descripteur est invalidé. Si elf n'est pas un membre d'archive avec un type ELF de ELF_K_AR, le compteur de références interne est augmenté de un chaque fois que elf est passé à elf_begin en tant qu'argument ref.

Un descripteur ELF dont le compteur de références atteint zéro est invalidé. Les opérations ultérieures sur le descripteur entraîneront un comportement indéfini.

PARAMÈTRES

elf
Le descripteur ELF (peut être NULL).

VALEUR DE RETOUR

Retourne le compteur de références interne actuel du descripteur ELF après décrémentation. Une valeur de retour de zéro indique que le descripteur ELF est maintenant invalidé. Si elf est NULL, alors elf_end retourne également 0.
