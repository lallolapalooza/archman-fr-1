NOM

elf_next - fait avancer un descripteur ELF vers le membre d'archive suivant

SYNOPSIS

#include <libelf.h>
Elf_Cmd elf_next(Elf *elf);

DESCRIPTION

Fait avancer un descripteur ELF associé à un fichier archive vers le membre d'archive suivant disponible.

Les descripteurs ELF initialisés à partir d'un fichier archive peuvent être utilisés pour récupérer les descripteurs ELF des membres d'archive un par un en utilisant elf_begin(3). elf_next(3) met à jour le descripteur d'archive de telle sorte que elf_begin(3) retourne le descripteur ELF du membre suivant de l'archive. Voir la section EXEMPLES ci-dessous.

VALEUR DE RETOUR

Si elf fait référence à un membre d'archive, met à jour l'état du descripteur ELF de l'archive parente associé à elf afin que le membre d'archive suivant puisse être récupéré avec elf_begin(3). Retourne la valeur Elf_Cmd qui a été utilisée avec elf_begin(3) pour initialiser elf.

Si elf n'a pas été initialisé à partir d'un fichier archive ou s'il n'y a plus de membres d'archive, elf_next(3) retourne ELF_C_NULL.

EXEMPLES

  /* Ouvre l'archive.  */
  fd = open (archive_name, O_RDONLY);
  if (fd == -1)
    {
      printf ("impossible d'ouvrir le fichier archive `%s'", fname);
      exit (1);
    }
  /* Définit la version ELF.  */
  elf_version (EV_CURRENT);
  /* Crée un descripteur ELF pour l'archive.  */
  cmd = ELF_C_READ;
  elf = elf_begin (fd, cmd, NULL);
  if (elf == NULL)
    {
      printf ("impossible de créer le descripteur ELF : %s\n", elf_errmsg (-1));
      exit (1);
    }
  /* Vérifie qu'il s'agit d'un descripteur d'archive.  */
  if (elf_kind (elf) != ELF_K_AR)
    {
      printf ("`%s' n'est pas une archive\n", fname);
      exit (1);
    }
  /* Récupère les membres de l'archive un par un.  */
  while ((subelf = elf_begin (fd, cmd, elf)) != NULL)
    {
      /* Traite subelf ici */
      [...]
      /* elf_next met à jour elf, l'archive parente, de sorte que le prochain appel
         à elf_begin retourne le membre d'archive suivant.  */
      cmd = elf_next (subelf);
      if (elf_end (subelf) != 0)
        {
          printf ("erreur lors de la libération du descripteur sous-ELF : %s\n",
                  elf_errmsg (-1));
          exit (1);
        }
    }
  elf_end (elf);
  close (fd);
