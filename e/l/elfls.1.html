SORTIE DU

PROGRAMME

La sortie du programme, pour chaque fichier ELF donné sur la ligne de commande, est la suivante

:

nom du fichier
dépendances
fichiers source
table des en-têtes de programme
table des en-têtes de

section

La première ligne de la sortie affiche le nom du fichier et l'architecture pour laquelle il a été créé. Le nom du fichier sera suffixé d'un astérisque * si le fichier est un exécutable binaire, d'un esperluette & si le fichier est une bibliothèque partagée, ou d'un signe dollar $ si le fichier est un fichier core. Sinon, le fichier est un fichier objet. (C'est la seule ligne dont la sortie est garantie. Les autres informations ne sont pas affichées si les données ne sont pas applicables, absentes du fichier, ou supprimées via les options de ligne de commande.

)

Après le nom du fichier, la liste des bibliothèques d'objets partagés avec lesquelles le fichier est lié dynamiquement est affichée, le cas

échéant.

Ensuite, la liste des fichiers source utilisés pour construire le fichier est affichée, en supposant que cette information soit

disponible.

La liste des entrées de la table des en-têtes de programme apparaît ensuite. Voir ci-dessous pour une description détaillée de la sortie. Les exécutables binaires et les bibliothèques partagées contiennent toujours une table des en-têtes de

programme.

Enfin, les entrées de la table des en-têtes de section sont affichées. Voir ci-dessous pour

une description détaillée de la sortie. Les fichiers ELF contiennent presque toujours une t
able des en-têtes de section, bien qu'elles ne soient requises que pour les fichiers objet.

TABLE DES EN-TÊTES DE

PROGRAMME

Les entrées de la table des en-têtes de programme sont affichées dans le format suivant

:

ind T rwx pos size

address
in
d
Le numéro d'index de l'entrée dans la table des en-têtes de
programme.
T
Une lettre indiquant le type de l'entrée. Les types possibles sont
:
B
Données binaires : instructions en langage machine ou données utilisées par le programme
lui-même.
P
La table des en-têtes de
programme.
D
La section d'informations de liaison
dynamique.
I
La spécification de l'interpréteur. Généralement, il s'agira du chemin du lienur
dynamique.
N
Une section de note, dont les détails ne sont pas
spécifiés.
U
Données de pile de trame d'exception, utilisées par le code pour dérouler les
piles.
rw
x
Drapeaux indiquant les permissions mémoire pour le contenu de cette entrée. r indique que le contenu doit être chargé dans une mémoire lisible, w indique que la mémoire doit être inscriptible, et x indique que la mémoire doit être exécutable. Un s peut également apparaître en dernière position, ce qui indique en plus que cette section contient le point de départ du
programme.
po
s
Un nombre hexadécimal indiquant la position dans le fichier du contenu de cette
entrée.
si
ze
Un nombre hexadécimal indiquant la taille du contenu de
l'entrée.
addre
ss
Un nombre hexadécimal indiquant l'
adresse mémoire à laquelle charger
le contenu de cette entrée.

Un nombre hexadécimal à la fin de l'entrée préfixé par un + indique de combien la taille de cette entrée doit être plus grande en mémoire qu'elle ne l'est dans le fichier (avec les octets supplémentaires à la fin devant être initialisés à zéro)

.

Notez que, sauf si --nostr est spécifié, les entrées d'interpréteur et de note dans la table des en-tête

s de programme sont simplement affichées sous
forme de chaîne indiquant leur contenu.

TABLE DES EN-TÊTES DE

SECTION

Les entrées de la table des en-têtes de section sont affichées dans le format suivant

:

ind T rwx pos size

name
in
d
Le numéro d'index de l'entrée dans la table des en-têtes de
section.
T
Une lettre indiquant le type de l'entrée. Les types possibles sont
:
B
Données du programme : instructions en langage machine ou données qui font partie du programme
lui-même.
0
Données du programme initialisées à zéro : la mémoire doit être allouée comme d'habitude pour cette entrée, mais aucune donnée n'est présente dans le fichier. La mémoire est plutôt initialisée à tous les bits à
zéro.
S
Une table des symboles utilisés dans le
fichier.
$
Une table de
chaînes.
H
Une table de hachage des symboles utilisée pour la liaison
dynamique.
D
La section d'informations de liaison
dynamique.
P
Une table de liaison de
procédures.
O
La table des décalages
globaux.
I
La spécification de l'interpréteur. Généralement, il s'agira du chemin du lienur
dynamique.
R
Une liste d'enregistrements de
relocalation.
V
Une section spécifiant les dépendances de version pour le
programme.
G
Une section fournissant des informations de
débogage.
U
Une section de données d'en-tête d'exception, utilisée lors du déroulement de la
pile.
N
Une section de note, dont le contenu n'est pas
spécifié.
C
Une section de commentaire : informations auxiliaires, généralement insérées par le programme qui a créé le
fichier.
rw
x
Drapeaux indiquant l'utilisation mémoire et la permission pour cette entrée. r indique que le contenu doit être chargé en mémoire lors de l'exécution du processus, w indique que le contenu doit être inscriptible lors de l'exécution du processus, et x indique que le contenu contient des instructions exécutables par la
machine.
po
s
Un nombre hexadécimal indiquant la position dans le fichier du contenu de cette
entrée.
si
ze
Un nombre hexadécimal indiquant la taille du contenu de
l'entrée.
na
me
Le nom de cette section. Si la section est une liste d'entrées de relocalationes, puis le nom sera suffixé par deux points et un numéro, le numéro indiquant l'indice de la section à laquelle s'appliquent les informations de relocalisation. De plus, plusieurs types de sections contiennent des informations qui font référence à des chaînes de caractères et/ou des symboles, lesquels sont contenus dans une section de table de chaînes et/ou une section de table de hachage de symboles. Ces sections auront un numéro entre crochets après le nom, indiquant l'indice de cette section. Un S entre crochets apparaissant après le nom d'une section de table de chaînes indique la table de chaînes qui contient les noms des sections.

Notez que, sauf si --nostr est spécifié, les entrées d'interpréteur, de commentaire et de note dans la table des en-têtes du programme sont simplement affichées comme une chaîne de caractères indiquant leur contenu.
