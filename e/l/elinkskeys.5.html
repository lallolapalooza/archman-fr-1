NOM

elinkskeys - raccourcis clavier pour ELinks

SYNOPSIS

Informations sur la façon de configurer les raccourcis clavier et aperçu des raccourcis clavier par défaut.

DESCRIPTION

Les raccourcis clavier pour elinks doivent être placés dans le fichier ~/.config/elinks/elinks.conf. Notez que toute information concernant leur format/structure peut ne pas être à jour. Si vous découvrez cela, veuillez nous envoyer un patch.

Les instructions de raccourcis clavier sont de la forme :

bind <keymap> <keystroke> = <action>

où :

<keymap>

est main, edit, ou menu. La keymap principale est utilisée pour la navigation générale. La keymap d'édition est utilisée pour modifier les champs de texte. La keymap de menu est utilisée pour naviguer dans les menus.

<keystroke>

est une touche sensible à la casse, que vous pouvez précéder de Ctrl-, Alt-, ou les deux. Ctrl- doit être suivi d'une touche majuscule. Voir ci-dessous pour une liste des touches valides.

<action>

est ce que la touche doit faire. Les actions disponibles dépendent de la keymap et sont listées séparément ci-dessous.

Tous les mots/chaînes peuvent être mis entre guillemets "comme ceci". Les barres obliques inverses sont des caractères d'échappement, même si elles ne sont pas entre guillemets. Les lignes commençant par un caractère dièse (#) sont des commentaires.

Les touches peuvent être désactivées simplement en les associant à l'action spéciale none. Cela peut être utile si vous tapez accidentellement une touche souvent.

EXEMPLE DE LIAISONS

Quelques exemples de raccourcis clavier :

bind "main" "v" = "view-image"
bind "main" "l" = "jump-to-link"
bind "main" "L" = "link-menu"
bind "main" "F10" = "file-menu"
bind "main" "F9" = "menu"
bind "main" "Escape" = "menu"
bind "edit" "Ctrl-R" = "auto-complete-unambiguous"
bind "edit" "Ctrl-W" = "auto-complete"
bind "edit" "Ctrl-K" = "kill-to-eol"
bind "menu" "Ctrl-B" = "page-up"
bind "menu" "PageUp" = "page-up"
bind "menu" "Ctrl-F" = "page-down"
bind "menu" "PageDown" = "page-down"
# ELinks avec support Lua
bind "main" "," = "lua-console"

TOUCHES

Les touches valides sont : caractères alphanumériques, ponctuation, Enter, Backspace, Tab, Escape, Left, Right, Up, Down, Insert, Delete, Home, End, PageUp, PageDown, F1 à F12.

Certaines touches devront être mises entre guillemets ou échappées. Par exemple, l'espace peut être écrit comme " " (guillemet espace guillemet), et le guillemet lui-même comme \" (barre oblique inverse guillemet). La barre oblique inverse peut être écrite comme \\ (double barre oblique inverse).
