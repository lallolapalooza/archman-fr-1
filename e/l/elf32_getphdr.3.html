ELF32_GETPHDR(3) Manuel du programmeur Libelf ELF32_GETPHDR(3)

NOM

elf32_getphdr, elf64_getphdr - récupérer la table des en-têtes de programme pour un fichier objet ELF 32 bits ou 64 bits

SYNTAXE

#include <libelf.h>
Elf32_Phdr *elf32_getphdr(Elf *elf);
Elf64_Phdr *elf64_getphdr(Elf *elf);

DESCRIPTION

Récupère la table des en-têtes de programme pour le descripteur ELF donné elf. Le nombre d'éléments dans la table des en-têtes de programme peut être récupéré avec elf32_getphdrnum et elf64_getphdrnum. elf32_newphdr et elf64_newphdr modifient la taille de la table des en-têtes de programme ou la suppriment. Si vous modifiez un élément de la table des en-têtes de programme, vous devez appeler elf_flagphdr avec ELF_C_SET et ELF_F_DIRTY afin d'écrire les nouvelles données sur le disque.

PARAMÈTRES

elf
Descripteur ELF à partir duquel récupérer la table des en-têtes de programme.

VALEUR DE RETOUR

En cas de succès, retourne un pointeur vers la table des en-têtes de programme. Retourne NULL s'il n'y a pas d'en-tête de programme. En cas d'échec, retourne NULL et définit un code d'erreur libelf.

VOIR AUSSI

elf32_newphdr(3), elf_errno(3), elf_getphdrnum(3), libelf(3), elf(5)

ATTRIBUTS

Interface Attribut Valeur
