ELF32_GETSHDR(3) Manuel du programmeur Libelf ELF32_GETSHDR(3)

NOM

elf32_getshdr, elf64_getshdr - récupérer l'en-tête de section pour une section dans un fichier objet ELF 32 bits ou 64 bits

SYNTAXE

#include <libelf.h>
Elf32_Shdr *elf32_getshdr(Elf_Scn *scn);
Elf64_Shdr *elf64_getshdr(Elf_Scn *scn);

DESCRIPTION

Récupère l'en-tête de section pour la section référencée par scn. Si l'en-tête de section récupéré est modifié, elf_flagshdr doit être appelé avec ELF_C_SET et ELF_F_DIRTY afin d'écrire l'en-tête de section modifié sur le disque.

PARAMETRES

scn
Le descripteur de section dont l'en-tête de section doit être récupéré.

VALEUR DE RETOUR

En cas de succès, renvoie un pointeur vers l'en-tête de section. Si scn est NULL alors NULL sera renvoyé. En cas d'erreur, renvoie NULL et définit un code d'erreur libelf.

VOIR AUSSI

elf_errno(3), elf_flagshdr(3), libelf(3), elf(5)

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
elf32_getshdr (), elf64_getshdr () Sécurité des threads MT-Safe

SIGNALER LES BOGUES
