ELFTOC(1) Manuel des commandes générales ELFTOC(1)

NOM

elftoc - traduire un fichier ELF en une structure C

SYNTAXE

elftoc [OPTIONS] FICHIER

DESCRIPTION

elftoc prend en entrée un fichier ELF et traduit son contenu en un fichier source C décrivant une structure avec une valeur initialisée correspondant à l'image mémoire du fichier ELF. Lorsque c'est possible, les valeurs littérales sont remplacées par des symboles du préprocesseur et des calculs basés sur sizeof.

OPTIONS

-e, --force-end
Forcer l'inclusion d'un champ _end final dans la structure C. Par défaut, un champ _end n'est inclus que si le remplissage rend la structure plus grande que le fichier ELF d'origine. Avec cette option, une structure sans remplissage supplémentaire fournira un champ _end défini comme un tableau de longueur nulle.
-E, --exclude-end
Ne pas inclure de champ _end final, même si un remplissage est présent à la fin de la structure C.
-w, --width=N
Définir la largeur de ligne maximale en sortie à N. La largeur de ligne maximale par défaut est 80.
-i, --indent=N
Définir le nombre d'espaces pour l'indentation à N. L'indentation par défaut est de 2.
-s, --structname=NOM
Définir le nom de la structure C dans le code source généré à NOM. Par défaut, le nom de la structure est « elf ».
-v, --varname=NOM
Définir le nom de la variable dans le code source généré à NOM. Par défaut, le nom de la variable est « foo ».
-m, --allow-misaligned
Une section mal alignée dans le fichier ELF provoquerait l'insertion d'octets de remplissage dans la structure C. Pour éviter cela, elftoc représente les sections mal alignées comme des tableaux d'octets non interprétés, quel que soit leur type d'origine. Cette option supprime ce comportement, de sorte que les sections mal alignées conservent leur type réel, même si cela crée une image incorrecte dans la structure C.
-q, --quiet
Supprimer les messages d'avertissement concernant les valeurs invalides et contradictoires dans le fichier ELF.
-o, --output=NOMFICHIER
Écrire le code source C dans NOMFICHIER au lieu de la sortie standard.
--help
Afficher l'aide et quitter.
--version
Afficher les informations de version et quitter.
