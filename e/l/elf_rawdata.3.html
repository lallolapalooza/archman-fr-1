ELF_RAWDATA(3) Manuel du programmeur Libelf ELF_RAWDATA(3)

NOM

elf_rawdata - Récupère les données brutes d'une section ELF.

SYNTAXE

#include <libelf.h>
Elf_Data *elf_rawdata(Elf_Scn *scn, Elf_Data *data);

DESCRIPTION

La fonction elf_rawdata() retourne un pointeur vers une structure Elf_Data contenant le contenu non traité (brut) de la section identifiée par scn. Cette vue brute reflète la disposition binaire exacte sur disque du fichier ELF, sans aucune modification pour l'endianness ou l'alignement mémoire. Utilisez elf_getdata(3) pour obtenir une vue des données traduites au format mémoire.

Si data est NULL, les données brutes de la section sont retournées. Si data n'est pas NULL et que les données brutes n'ont pas été initialisées, l'appel échoue.

Pour les sections compressées (c'est-à-dire avec le drapeau SHF_COMPRESSED), l'Elf_Data retournée contient la forme compressée, et son d_type est ELF_T_CHDR.

Pour les sections de type SHT_NOBITS, le pointeur d_buf est NULL.

Le pointeur Elf_Data * retourné par cette fonction et son champ d_buf appartiennent à libelf et ne doivent pas être libérés. Ils ne sont valides que jusqu'à ce que elf_end(3) soit appelé sur le descripteur Elf associé à scn.

PARAMETRES

scn
Un descripteur de section retourné par elf_getscn(3) ou elf_nextscn(3). Si NULL, cette fonction retourne NULL.
data
Doit être NULL lors de l'appel initial. Toute autre utilisation n'est pas prise en charge.

VALEUR DE RETOUR

Retourne un pointeur vers un descripteur Elf_Data décrivant le contenu brut de la section. En cas d'échec, NULL est retourné et elf_errno est défini.

VOIR AUSSI

elf_getdata(3), elf_getscn(3), elf_compress(3), libelf(3), elf(5)
