ELF_GETARSYM(3) Manuel du programmeur Libelf ELF_GETARSYM(3)

NOM

elf_getarsym - récupérer la table des symboles d'archive

SYNTAXE

#include <libelf.h>
Elf_Arsym *elf_getarsym(Elf *elf, size_t *narsyms);

DESCRIPTION

Récupère la table des symboles d'archive du fichier d'archive associé à elf.

Si l'archive contient une table des symboles, elf_getarsym() renvoie un pointeur vers un tableau de structures Elf_Arsym décrivant chaque symbole. Stocke également le nombre de symboles dans ce tableau dans narsyms si ce dernier n'est pas NULL.

Elf_Arsym a la structure suivante :

typedef struct {
  char   *as_name;   /* Nom du symbole (terminé par un caractère nul). */
  int64_t as_off;    /* Décalage dans le fichier du membre d'archive définissant le symbole. */
  uint64_t as_hash;  /* Valeur de hachage du nom du symbole. */
} Elf_Arsym;

La dernière entrée dans la table des symboles d'archive est l'entrée spéciale { NULL, 0, ~0L }. Ceci peut être utilisé pour trouver la fin de la table si narsyms est NULL.

PARAMETRES

elf
Un descripteur ELF faisant référence à un fichier d'archive, obtenu en appelant elf_begin(3) sur une archive.
narsyms
Un pointeur vers un size_t dans lequel le nombre d'entrées dans la table des symboles sera stocké si ce pointeur n'est pas NULL.

VALEUR DE RETOUR

Si l'archive contient une table des symboles, renvoie un pointeur vers un tableau de structures Elf_Arsym, y compris l'entrée NULL spéciale indiquant la fin de la table. Définit *narsyms au nombre d'entrées dans le tableau (si narsyms n'est pas NULL). Ces pointeurs sont gérés par libelf et ne doivent pas être libérés par l'appelant de elf_getarsym.

Si l'archive ne contient pas de table des symboles ou si elf n'est pas un descripteur d'archive valide, elf_getarsym renvoie NULL.

VOIR AUSSI
