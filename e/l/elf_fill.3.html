NOM

elf_fill - Définit l'octet de remplissage utilisé lors de la construction ou de la modification de fichiers objets ELF.

SYNTAXE

#include <libelf.h>
void elf_fill(int fill);

DESCRIPTION

La fonction elf_fill définit l'octet de remplissage utilisé par libelf pour combler les nouveaux espaces entre les sections ELF ou les éléments de données lorsqu'un fichier objet ELF est redimensionné ou réaligné à l'aide de elf_update. L'octet de remplissage par défaut utilisé par libelf est zéro.

PARAMÈTRES

fill
La valeur utilisée pour remplir les espaces dans les écritures futures vers les objets ELF. Cette valeur doit être comprise entre 0 et 255 (inclus). Seuls les 8 bits les moins significatifs sont utilisés.

VALEUR DE RETOUR

elf_fill ne retourne aucune valeur.

VOIR AUSSI

elf_update(3), libelf(3), elf(5)
