NOM

elographics - pilote d'entrée Elographics

SYNOPSIS

Section "InputDevice"
Identifier "nom_periph"
Driver "elographics"
Option "Device" "chemin_dev"
  ...
EndSection

DESCRIPTION

elographics est un pilote d'entrée Xorg pour les appareils à écran tactile Elographics.

Le pilote elographics fonctionne comme un périphérique d'entrée pointeur, et peut être utilisé comme pointeur principal du serveur X.

MATÉRIEL PRIS EN CHARGE

Les appareils E271-2210 et E271-2200 sont pris en charge. Les appareils E281-2310 et compatibles sont pris en charge avec certaines fonctionnalités indisponibles.

DÉTAILS DE CONFIGURATION

Veuillez vous référer à xorg.conf(5) pour les détails généraux de configuration et pour les options qui peuvent être utilisées avec tous les pilotes d'entrée. Cette section couvre uniquement les détails de configuration spécifiques à ce pilote.

Les options de pilote suivantes sont prises en charge :

Option "Device" "chaîne"
Le périphérique connecté à l'interface de l'écran tactile. Par défaut, "/dev/ttyS1".
Option "MinX" "entier"
Définit la valeur minimale pour l'axe X de l'écran tactile. Par défaut, 600.
Option "MaxX" "entier"
Définit la valeur maximale pour l'axe X de l'écran tactile. Par défaut, 3000.
Option "MinY" "entier"
Définit la valeur minimale pour l'axe Y de l'écran tactile. Par défaut, 600.
Option "MaxY" "entier"
Définit la valeur maximale pour l'axe Y de l'écran tactile. Par défaut, 3000.
Option "ScreenNo" "entier"
L'écran auquel attacher l'écran tactile lors de l'exécution avec plusieurs écrans. Par défaut, écran 0.
Option "PortraitMode" "chaîne"
Définit l'orientation des axes X/Y. Par défaut, "Landscape", mais vous pouvez faire pivoter dans le sens des aiguilles d'une montre ("Portrait") ou dans le sens inverse ("PortraitCCW").
Option "SwapXY" "booléen"
Inverse les axes X et Y de l'affichage. Par défaut, false.
Option "UntouchDelay" "entier"
La période pendant laquelle le doigt doit être retiré pour qu'un événement de non-toucher se produise. Par défaut : 5 (50 ms).
Option "ReportDelay" "entier"
Délai entre les paquets de rapport. Par défaut : 1 (10 ms).
Option "Model" "chaîne"
Le modèle de l'écran tactile. Par défaut : non défini. Modèles pris en charge : "Sunit dSeries".

VOIR AUSSI

Xorg(1), xorg.conf(5), Xserver(1), X(7).
