ELF_ERRMSG(3) Manuel du programmeur Libelf ELF_ERRMSG(3)

NOM

elf_errmsg - renvoie la chaîne de message d'erreur pour un code d'erreur libelf donné.

SYNTAXE

#include <libelf.h>

const char *elf_errmsg(int err);

DESCRIPTION

La fonction elf_errmsg récupère une chaîne lisible par l'homme correspondant au code d'erreur le plus récent défini par une fonction de la bibliothèque libelf. Si err est 0, la fonction renvoie le message d'erreur pour le code d'erreur le plus récent. Si err est différent de zéro, la fonction renvoie le message d'erreur pour le code d'erreur spécifié.

PARAMETRES

err
Une valeur de type int spécifiant le code d'erreur. Si cette valeur est 0, la fonction renvoie le message d'erreur pour l'erreur la plus récente ou NULL si aucune ne s'est produite. Si cette valeur est -1, le comportement est similaire au cas précédent, sauf qu'une chaîne valide sera renvoyée à la place de NULL.

VALEUR DE RETOUR

La fonction elf_errmsg renvoie une chaîne contenant le message d'erreur. S'il n'y a pas de message d'erreur correspondant, elle renvoie NULL.

VOIR AUSSI

elf_errno(3)

SIGNALEMENT DE BOGUES
