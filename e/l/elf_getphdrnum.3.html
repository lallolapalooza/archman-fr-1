ELF_GETPHDRNUM(3) Manuel du programmeur Libelf ELF_GETPHDRNUM(3)

NOM

elf_getphdrnum - récupérer le nombre d'en-têtes de programme dans un fichier ELF

SYNTAXE

#include <libelf.h>
int elf_getphdrnum(Elf *elf, size_t *dst );

DESCRIPTION

La fonction elf_getphdrnum() stocke le nombre d'en-têtes de programme associés au descripteur ELF elf dans la variable pointée par dst.

Si le nombre d'en-têtes de programme dépasse la plage représentable du champ e_phnum dans l'en-tête ELF, la spécification ELF autorise l'encodage du vrai compte dans le champ sh_info de l'en-tête de section 0, et définit e_phnum à la valeur réservée PN_XNUM (toujours 0xFFFF). Cette fonction gère de manière transparente ce cas.

La fonction assure également que le nombre d'en-têtes de programme renvoyé ne dépasse pas le nombre qui peut être effectivement adressé dans la table des en-têtes de programme. Ceci est important lors de l'indexation dans le tableau renvoyé par elf32_getphdr() ou elf64_getphdr().

PARAMETRES

elf
Un pointeur vers un descripteur Elf. Le descripteur doit représenter un binaire ELF avec Elf_Kind ELF_K_ELF.
dst
En cas de succès, le nombre d'en-têtes de programme dans elf est écrit ici. Ne doit pas être NULL.

VALEUR DE RETOUR

Renvoie 0 en cas de succès et stocke le résultat dans dst. Renvoie -1 en cas d'échec et définit elf_errno. Renvoie -1 sans définir errno si elf est NULL.

VOIR AUSSI

elf32_getphdr(3), elf64_getphdr(3), libelf(3), elf(5)

ATTRIBUTS
