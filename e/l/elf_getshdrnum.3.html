elf_getshdrnum(3)

ELF_GETSHDRNUM(3) Manuel du programmeur Libelf ELF_GETSHDRNUM(3)

NOM

elf_getshdrnum, elf_getshnum - récupérer le nombre d'en-têtes de section dans un fichier ELF

SYNOPSIS

#include <libelf.h>
int elf_getshdrnum("Elf *elf", size_t *dst );
int elf_getshnum("Elf *elf", size_t *dst ); (obsolète)

DESCRIPTION

La fonction elf_getshdrnum() stocke le nombre d'en-têtes de section (sections) associés au descripteur ELF elf dans la variable pointée par dst.

Elle gère de manière transparente les comptes d'en-têtes de section standards et étendus. Si le nombre d'en-têtes de section dépasse la plage représentable du champ e_shnum dans l'en-tête ELF, la spécification ELF permet d'encoder le vrai compte dans le champ sh_size de l'en-tête de section 0, et de mettre e_shnum à 0. Cette fonction gère cela de manière transparente.

La fonction elf_getshnum() est un alias obsolète pour elf_getshdrnum() et ne doit pas être utilisée dans le nouveau code (voir HISTORIQUE).

PARAMETRES

elf
Un pointeur vers un descripteur Elf ouvert avec elf_begin(3). Le descripteur doit représenter un fichier de type ELF_K_ELF . Si NULL, la fonction retourne -1 sans définir elf_errno.
dst
Pointeur vers une variable de type size_t. En cas de succès, le nombre d'en-têtes de section est écrit ici. Ne doit pas être NULL.

VALEUR DE RETOUR

Retourne 0 en cas de succès et stocke le résultat dans dst. Retourne -1 en cas d'échec.

VOIR AUSSI

elf32_getshdr(3), elf64_getshdr(3), libelf(3), elf(5)

ATTRIBUTS

Interface Attribut Valeur
elf_getshdrnum (), elf_getshnum() Sécurité des threads MT-Safe

SIGNALEMENT DE BOGUES

Signaler les bogues à <elfutils-devel@sourceware.org> ou https://sourceware.org/bugzilla/.

HISTORIQUE

elf_getshdrnum est apparu pour la première fois dans elfutils 0.142. Cette fonction a été ajoutée en raison des incohérences de valeurs de retour d'elf_getshnum entre différentes implémentations de libelf. elf_getshdrnum a été introduite pour garantir que 0 est retourné en cas de succès dans toutes les implémentations de libelf.
