ELF32_FSIZE(3) Manuel du programmeur Libelf ELF32_FSIZE(3)

NOM

elf32_fsize, elf64_fsize - calculer la taille de fichier d'une structure de données ELF

SYNTAXE

#include <libelf.h>
size_t elf32_fsize(Elf_Type type, size_t count, unsigned int version);
size_t elf64_fsize(Elf_Type type, size_t count, unsigned int version);

DESCRIPTION

Étant donné une représentation Elf_Type d'une structure ELF centrale ainsi que le nombre d'éléments, renvoie le nombre d'octets nécessaires pour la représentation sur disque dans un fichier ELF 32 bits ou 64 bits. Les représentations sur disque et en mémoire de Elf_Type sont supposées être identiques. Voir libelf(3) pour plus d'informations concernant Elf_Type.

PARAMETRES

type
Le type de structure de données ELF pour lequel la taille de fichier doit être calculée.
count
Le nombre d'éléments du type spécifié.
version
La version ELF. Elle doit être définie à EV_CURRENT, qui est la seule valeur valide.

VALEUR DE RETOUR

La taille en octets du nombre et du type de structure de données spécifiés. Si la version n'est pas définie à EV_CURRENT ou si type n'est pas un Elf_Type valide, renvoie 0 et définit un code d'erreur libelf. Un débordement d'entier peut se produire si la taille de type multipliée par count est supérieure à SIZE_MAX.

VOIR AUSSI

elf_errno(3), libelf(3), elf(5)

ATTRIBUTS
