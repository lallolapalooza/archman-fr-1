ELF_FLAGELF(3) Manuel du programmeur Libelf ELF_FLAGELF(3)

NOM

elf_flagelf, elf_flagdata, elf_flagehdr, elf_flagphdr, elf_flagscn, elf_flagshdr - définir ou effacer des drapeaux sur des descripteurs et composants ELF

SYNTAXE

#include <libelf.h>
unsigned int elf_flagelf(Elf * elf, Elf_Cmd cmd, unsigned int flags);
unsigned int elf_flagehdr(Elf * elf, Elf_Cmd cmd, unsigned int flags);
unsigned int elf_flagphdr(Elf * elf, Elf_Cmd cmd, unsigned int flags);
unsigned int elf_flagscn(Elf_Scn * scn, Elf_Cmd cmd, unsigned int flags);
unsigned int elf_flagshdr(Elf_Scn * scn, Elf_Cmd cmd, unsigned int flags);
unsigned int elf_flagdata(Elf_Data * data, Elf_Cmd cmd, unsigned int flags);

DESCRIPTION

Ces fonctions permettent à l'appelant de définir ou d'effacer des drapeaux sur divers composants ELF gérés par libelf . Elles sont typiquement utilisées pour indiquer qu'un composant a été modifié (salie), ou pour contrôler le comportement de la disposition lors de la sortie.

elf_flagelf() modifie les drapeaux sur le descripteur Elf de plus haut niveau.

elf_flagdata() modifie les drapeaux sur un descripteur Elf_Data, typiquement récupéré à l'aide de elf_getdata(3) ou créé avec elf_newdata(3).

elf_flagehdr() modifie les drapeaux sur l'en-tête ELF d'un descripteur ELF (par exemple, le résultat de gelf_getehdr(3)).

elf_flagphdr() modifie les drapeaux sur la table des en-têtes de programme d'un descripteur ELF.

elf_flagscn() modifie les drapeaux sur un descripteur Elf_Scn (section).

elf_flagshdr() modifie les drapeaux sur l'en-tête de section d'un descripteur Elf_Scn donné.

L'argument cmd détermine si les drapeaux donnés doivent être définis ( ELF_C_SET ) ou effacés ( ELF_C_CLR ).

Les valeurs de drapeaux suivantes peuvent être passées via le paramètre flags :

ELF_F_DIRTY
Marque l'objet comme modifié. Ceci garantit que les modifications apportées au composant seront écrites lors de elf_update(3).
ELF_F_LAYOUT
Indique que la disposition du composant ELF est gérée manuellement. Les décalages et les tailles seront préservés tels que fournis. Ce drapeau est uniquement utilisé avec elf_flagelf() et est ignoré lorsqu'il est utilisé avec d'autres fonctions. Si ce drapeau est défini, l'utilisateur doit définir les champs e_phoff, e_shoff de Ehdr, ainsi que les champs d_off de Elf_Data et sh_offset de Shdr. Si ce n'est pas défini, ces décalages seront recalculés lors de l'appel à elf_update. Si ELF_F_LAYOUT est défini, les modifications des décalages de phdr empêcheront elf_update d'ajuster automatiquement les décalages de shdr.
ELF_F_PERMISSIVE
Active une validation souple de la structure de l'objet. Ce drapeau autorise des dispositions non standard sans vérifications strictes. Plus précisément, il supprime une vérification dans elf_update() selon laquelle la taille de la section sh_size est un multiple de la taille de l'élément de section sh_entsize (si différent de zéro). Ce drapeau est uniquement utilisé avec elf_flagelf() et est ignoré lorsqu'il est utilisé avec d'autres fonctions. ELF_F_PERMISSIVE est une extension elfutils libelf et peut ne pas être disponible dans d'autres implémentations de libelf.

PARAMETRES

obj
L'objet à modifier : Pour elf_flagelf, elf_flagehdr, elf_flagphdr, il s'agit d'un descripteur Elf *. Pour elf_flagscn et elf_flagshdr, il s'agit d'un descripteur Elf_Scn *. Pour le tampon elf_flagdata, il s'agit d'un tampon Elf_Data *.
cmd
Doit être soit : ELF_C_SET pour définir les drapeaux donnés, soit ELF_C_CLR pour les effacer.
flags
Masque de bits des drapeaux à modifier. Peut inclure toute combinaison de ELF_F_DIRTY , ELF_F_LAYOUT , et ELF_F_PERMISSIVE .

Notez que ELF_F_LAYOUT et ELF_F_PERMISSIVE ne sont utilisés qu'avec elf_flagelf() et sont ignorés pour les autres fonctions.

VALEUR DE RETOUR

Renvoie la nouvelle valeur des drapeaux après l'opération de définition/effacement.

Renvoie 0 en cas d'erreur, et définit un code d'erreur récupérable via elf_errmsg(3). Si le premier argument est NULL, alors 0 est renvoyé et aucun code d'erreur n'est défini.

Si le dernier drapeau est effacé, 0 sera renvoyé comme nouvelle valeur de drapeau. Dans ce cas, 0 n'est pas un indicateur d'erreur et aucun code d'erreur n'est défini.
