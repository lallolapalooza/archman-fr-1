ELF_GETAROFF(3) Manuel du programmeur Libelf ELF_GETAROFF(3)

NOM

elf_getaroff - récupérer le décalage d'un en-tête de membre d'archive

SYNTAXE

#include <libelf.h>
int64_t elf_getaroff(Elf *elf);

DESCRIPTION

Retourne le décalage de fichier, en octets, de l'en-tête du membre d'archive auquel fait référence un descripteur ELF. C'est le décalage de l'en-tête du membre dans le fichier d'archive parent. Ce décalage peut être utilisé avec elf_rand.

PARAMETRES

elf
Descripteur Elf faisant référence à un membre d'un en-tête de fichier d'archive.

VALEUR DE RETOUR

Retourne le décalage de fichier, en octets, de l'en-tête du membre d'archive auquel fait référence elf. Si elf est NULL ou n'est pas un membre d'une archive, retourne -1.

VOIR AUSSI

elf_begin(3), elf_next(3), elf_rand(3), libelf(3), elf(5)

ATTRIBUTS

Interface Attribut Valeur
elf_getaroff () Sécurité des threads MT-Safe

SIGNALER LES BOGUES

Signalez les bogues à <elfutils-devel@sourceware.org> ou https://sourceware.org/bugzilla/.

HISTORIQUE

elf_getaroff est apparu pour la première fois dans elfutils 0.114. Cette fonction libelf d'elfutils peut ne pas se trouver dans d'autres implémentations de libelf.
