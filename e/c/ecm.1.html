DESCRIPTIO

N

ecm est un programme de factorisation d'entiers utilisant la méthode de

s courbes elliptiques (ECM), la méthode P-1 ou la méthode P+1. Les secti
ons suivantes décrivent les paramètres pertinents pour ces algorithmes.

PARAMÈTRES DE BORNES DE L'ÉTAPE 1 ET DE L'ÉTAPE

2

B

1
B1 est la borne de l'étape 1. C'est un paramètre obligatoire. Il peut être donné soit au format entier (par exemple 3000000) soit au format flottant (3000000.0 ou 3e6). La plus grande valeur possible de B1 est 9007199254740996 pour P-1, et ULONG_MAX ou 9007199254740996 (selon la plus petite des deux) pour ECM et P+1. Tous les nombres premiers 2 <= p <= B1 sont traités à l'étape
1.

B

2
B2 est la borne de l'étape 2. Elle est optionnelle : si elle est omise, une valeur par défaut est calculée à partir de B1, ce qui devrait être proche de l'optimal. Comme B1, elle peut être donnée soit au format entier soit au format flottant. La plus grande valeur possible de B2 est approximativement 9e23, mais dépend du nombre de blocs k si vous spécifiez l'option -k. Tous les nombres premiers B1 <= p <= B2 sont traités à l'étape 2. Si B2 < B1, aucune étape 2 n'est
effectuée.

B2min-B2ma

x
alternativement, on peut utiliser la forme B2min-B2max , ce qui signifie que tous les nombres premiers B2min <= p <= B2max devraient être traités. Ainsi, spécifier seulement B2 correspond à B1-B2. Les valeurs de B2min et B2max peuvent être arbitrairement grandes, mais leur différence ne doit pas dépasser environ 9e23, sous réserve du nombre de blocs k
.

PARAMÈTRES DE GROUPE ET DE POINT

INITIAL

-x0

x
[ECM, P-1, P+1] Utiliser x (entier ou rationnel à précision arbitraire) comme point initial. Par exemple, -x0 1/3 est valide. Si non donné, x est généré à partir de la valeur sigma pour ECM, ou au hasard pour P-1 et

s
[ECM] Utiliser s (entier à précision arbitraire) comme générateur de courbe. Si omis, s est généré au
hasard.

a
[ECM] Utiliser a (entier à précision arbitraire) comme paramètre de courbe. Si omis, il est généré à partir de la valeur
sigma.

-go va

l

PARAMÈTRES DE L'ÉTAPE

2

-k

k
[ECM, P-1, P+1] Effectuer k blocs à l'étape 2. Pour une valeur B2 donnée, augmenter k diminue l'utilisation de la mémoire de l'étape 2, au prix d'un temps CPU plus
important.

-treefile fil

e
Stocke certaines tables de données dans des fichiers sur disque pour réduire la quantité de mémoire occupée à l'étape 2, au prix des entrées/sorties disque. Les données seront écrites dans les fichiers file.1, file.2 etc. Ne fonctionne pas avec le stage 2 rapide pour P+1 et
P-1.

-power

n
[ECM] Utiliser x^n pour l'extension de Brent-Suyama (-power 1 désactive l'extension de Brent-Suyama). Le polynôme par défaut est choisi en fonction de la méthode et de
B2.

-dickson

n
[ECM] Utiliser le polynôme de Dickson de degrén pour l'extension de
Brent-Suyama.

-maxmem

n
Utiliser au plus n mégaoctets de mémoire dans le stage
2.

-ntt, -no-nt

t
Activer ou désactiver le code de la transformation arithmétique théorique des nombres (NTT) pour l'arithmétique des polynômes dans le stage 2. Avec NTT, dF est choisi comme une puissance
de 2, et est limité par le nombre de nombres premiers convenables qui tiennent dans un mot machine (ce qui n'est une limitation que sur les systèmes 32 bits). La variante -no-ntt utilise p
lus de mémoire, mais est plus rapide que NTT avec de grands nombres d'entrée. Par défaut, NTT est utilisé pour P-1, P+1 et pour ECM sur des nombres d'une taille d'au plus 30 mots machine.

OPTIONS D'ARITHMÉTIQUE

MODULAIRE

Plusieurs algorithmes sont disponibles pour la multiplication modulaire. Le programme essaie de trouver le meilleur pour chaque entrée ; on peut forcer une méthode donnée avec les options

suivantes.

-mpzmo

d
Utiliser la fonction mpz_mod de GMP (sous-quadratique pour les grandes entrées, mais introduit un certain surcoût pour les petites)
.

-modmul

n
Utiliser la multiplication de Montgomery (version quadratique). Généralement la meilleure méthode pour les petites
entrées.

-red

c
Utiliser la multiplication de Montgomery (version sous-quadratique). Théoriquement optimal pour les grandes
entrées.

-nobase

2
Désactiver le code spécial base-2 (qui est utilisé lorsque le nombre d'entrée est un grand facteur de 2^n+1 ou 2^n-1, voir -v)
.

-base2

n
Forcer l'utilisation du code spécial base-2, le nombre d'entrée doit diviser 2^n+1 si n > 0, ou 2^|n|-1 si n <
0.

E/S DE

FICHIERS

Les options suivantes permettent d'effectuer l'étape 1 et l'étape 2 séparément, soit sur différentes machines, à différents moments, ou en utilisant différents logiciels (en particulier, le programme Prime95/mprime de George Woltman peut produire une sortie d'étape 1 adaptée pour la reprise avec GMP-ECM). Il peut aussi être utile de diviser l'étape 2 en plusieurs exécutions, en utilisant l'option B2min-B2max

.

-inp fil

e
Prendre l'entrée depuis le fichier file au lieu de l'entrée
standard.

-save fil

e
Enregistrer le résultat de l'étape 1 dans file. Si file existe, une erreur est levée. Exemple : pour effectuer seulement l'étape 1 avec B1=1000000 sur le nombre composé dans le fichier "c155" et enregistrer son résultat dans le fichier "foo", utiliser 
ecm -s
ave foo
1e6 1
< c155

-savea fil

e
Comme -save, mais ajoute aux fichiers
existants.

-resume fil

e
Reprendre les résidus depuis file, lit depuis l'entrée standard si file est "-". Exemple : pour effectuer l'étape 2 à la suite du calcul d'étape 1 ci-dessus, utiliser 
ecm -
resum
e fo
o 1e6

e
Écrire périodiquement le résidu courant du stage 1 dans file. En cas de panne de courant, etc., le calcul peut être poursuivi avec l'option -resume.

MODE BOUCLE

Le « mode boucle » (option -c n) permet d'exécuter plusieurs courbes sur chaque nombre d'entrée. Les options suivantes contrôlent son comportement.

-c n

Exécute n passes sur chaque nombre d'entrée (par défaut, une seule). Cette option est principalement utile pour P+1 (par exemple avec n=3) ou pour ECM, où n pourrait être défini comme le nombre attendu de courbes pour trouver un facteur de d chiffres avec une limite de pas 1 donnée. Cette option est incompatible avec -resume, -sigma, -x0. Donner -c 0 produit une boucle infinie jusqu'à ce qu'un facteur soit trouvé.

-one

En mode boucle, arrêtez-vous lorsqu'un facteur est trouvé ; par défaut, le programme continue jusqu'à ce que le cofacteur soit premier ou que le nombre spécifié de passes soit terminé.

-b

Traitement en largeur d'abord : en mode boucle, exécutez une courbe pour chaque nombre d'entrée, puis une deuxième courbe pour chacun, et ainsi de suite. C'est le mode par défaut avec -inp.

-d

Traitement en profondeur d'abord : en mode boucle, exécutez n courbes pour le premier nombre, puis n courbes pour le second, et ainsi de suite. C'est le mode par défaut avec l'entrée standard.

-ve n

En mode boucle, lors des deuxièmes et suivantes passes, n'affichez que les expressions ayant au plus n caractères. Par défaut est -ve 0.

-i n

En mode boucle, incrémentez B1 de n après chaque courbe.

-I n

En mode boucle, multipliez B1 par un facteur dépendant de n après chaque courbe. Par défaut, c'est un, ce qui devrait être optimal sur une seule machine, tandis que -I 10 pourrait être utilisé pour factoriser le même nombre simultanément sur 10 machines identiques.

EXÉCUTION DE COMMANDES SHELL

Ces options permettent d'exécuter des commandes shell pour compléter les fonctionnalités de GMP-ECM.

-prpcmd cmd

Exécute la commande cmd pour tester la primalité des facteurs et cofacteurs au lieu des fonctions propres à GMP-ECM. Le nombre à tester est passé via stdin. Un code de sortie de 0 est interprété comme « probablement premier », un code de sortie non nul comme « composé ».

-faccmd cmd

Exécute la commande cmd chaque fois qu'un facteur est trouvé par P-1, P+1 ou ECM. Le nombre d'entrée, le facteur et le cofacteur sont passés via stdin, chacun sur une ligne. Cela pourrait être utilisé, par exemple, pour envoyer automatiquement les nouveaux facteurs par e-mail : 
ecm -faccmd 'mail -s “$HOSTNAME a trouvé un facteur”
                me@myaddress.com' 11e6 < cunningham.in

-idlecmd cmd

Exécute la commande cmd avant que chaque tentative de courbe ECM, P-1 ou P+1 sur un nombre ne soit démarrée. Si le statut de sortie de cmd est non nul, GMP-ECM se termine immédiatement, sinon il continue normalement. GMP-ECM est arrêté pendant l'exécution de cmd, offrant un moyen de laisser GMP-ECM dormir par exemple pendant que le système est autrement occupé.

DIVERS

-n

Exécute le programme en mode « nice » (priorité inférieure à la normale).

-nn

Exécute le programme en mode « très nice » (priorité inoccupée).

-B2scale f

Multiplie la limite par défaut du pas 2, B2, par la valeur à virgule flottante f. Exemple : -B2scale 0.5 divise le B2 par défaut par 2.

-stage1time n

Ajoute n secondes au temps du pas 1. Ceci est utile pour obtenir le temps attendu correct avec -v si une partie du pas 1 a été effectuée lors d'une autre passe.

-cofdec

Force la sortie du cofacteur en décimal (même si des expressions sont utilisées).

-h, --help

Affiche une courte description de l'utilisation, des paramètres et des options de ligne de commande d'ecm.

-printconfig

Affiche les paramètres de configuration utilisés pour la compilation et se termine.

SYNTAXE D'ENTRÉE

Les nombres d'entrée peuvent avoir plusieurs formes :

Nombres décimaux bruts comme 123456789.

Les commentaires peuvent être placés dans le fichier : tout ce qui suit « // » est ignoré, jusqu'à la fin de la ligne.

Rallongement de ligne. Si une ligne se termine par un caractère backslash « \ », elle est considérée comme continuant sur la ligne suivante.

Des expressions arithmétiques courantes peuvent être utilisées. Exemple : 3*5+(2+7)^10.

Factorielle : exemple 53!.

Multi-factorielle : exemple 15!3 signifie 15*12*9*6*3.

Primorielle : exemple 11# signifie 2*3*5*7*11.

Primorielle réduite : exemple 17#5 signifie 5*7*11*13*17.

Fonctions :

PGCD(a,b) : Plus grand commun diviseur

exemple PGCD(120,28) = 4

Phi(n,x) : n-ième polynôme cyclotomique évalué en x

exemple Phi(3,5) = 1 + x + x^2 = 31

STATUT DE SORTIE

Le statut de sortie reflète le résultat de la dernière courbe ECM ou tentative P-1/P+1 que le programme a effectuée. Des bits individuels signifient des événements particuliers, spécifiquement :

Bit 0

0 si terminaison normale du programme, 1 si une erreur s'est produite

Bit 1

0 si aucun facteur propre n'a été trouvé, 1 sinon

Bit 2

0 si le facteur est composé, 1 si le facteur est un premier probable

Bit 3

0 si le cofacteur est composé, 1 si le cofacteur est un premier probable

Ainsi, les valeurs de statut de sortie suivantes peuvent se produire :

0

Terminaison normale du programme, aucun facteur trouvé

1

Erreur

2

Facteur composé trouvé, cofacteur composé

6

Facteur premier probable trouvé, cofacteur composé

8

Nombre d'entrée trouvé

10

Facteur composé trouvé, cofacteur premier probable

14

Facteur premier probable trouvé, cofacteur premier probable
