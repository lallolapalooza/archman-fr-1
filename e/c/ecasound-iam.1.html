DESCRIPTIO

N

La bibliothèque ecasound contient un module interprète qui comprend un ensemble de commandes visant

à contrôler divers services de la bibliothèque. C'est ce qu'on appelle le mode interactif d'ecasoun
d (EIAM). Tous les programmes liés à la bibliothèque ecasound peuvent utiliser cette fonctionnalité.

API ECI et types de

retour

Un cas particulier d'utilisation du mode interactif est l'interface de contrôle d'ecasound (ECI), qui est une petite bibliothèque offrant un accès facile aux commandes du mode interactif depuis l'extérieur de libecasound. Lors de l'émission de commandes inter via l'interface de contrôle, il est pos

sible que les commandes renvoient également des informations. Les types de valeurs de retour actuellement pris en charge sont : chaîne [s], liste de chaînes [S] (éléments séparés par des virgules ; échappés si nécessaire), entier [i], entier long [li] et nombre à virgule flottante [f]. Ces déf
initions sont utilisées tout au long de ce document. Les commandes qui ne renvoient rien (void) sont marquées avec [-]. De plus, le type de retour [e] marque une condition d'erreur. Lorsqu'une commande du mode interactif entraîne une erreur, une chaîne d'erreur expliquant la condition est renvoyée.

Limitations liées au contrôle et aux modifications en temps

réel

Il n'est pas possible d'utiliser toutes les commandes du mode interactif pour modifier et contrôler des objets appartenant à une chaîne de configuration (chainsetup) connectée. Ecasound déconnectera automatiquement (et essaiera plus tard de reconnecter) la chaîne de configuration si ces commandes sont reçues alors qu'elle est connectée. Les commandes ayant cette limitation sont

:
cs-remove, cs-set-length, cs-set-length-samples, cs-toggle-loop, cs-set-param, cs-option, c-add, c-remove, c-rename, c-clear, ai-add, ai-remove, ai-attach, ai-forward, ai-rewind, ai-set-position, ai-set-position-samples, ao-add, ao-add-default, ao-remove, ao-attach, ao-forward, ao-rewind, ao-set-position, ao-set-position-samples
.

Les commandes suivantes peuvent être utilisées avec une chaîne de configuration connectée, mais elles nécessitent de mettre temporairement le moteur en pause (s'il est en cours d'exécution) et cela peut causer des interruptions audibles lors de la lecture et de l'enregistrement. En pratique, cela signifie qu'il est actuellement impossible d'ajouter ou de supprimer des opérateurs de chaîne de manière sans couture. Les commandes concernées

:
cop-add,
ctrl-add,

Les commandes suivantes peuvent être utilisées sur une chaîne de configuration connectée et lorsque le moteur est en cours d'exécution (pas une liste complète mais au moins ces commandes sont prises en charge)

:
cop-set, copp-set, ctrlp-set, c-bypass, c-muting, setpos, cs-

CHAINSETUP

S

Il peut y avoir plusieurs chaînes de configuration mais seulement une peut être connectée. De même, seulement une chaîne de configuration peut être sélectionnée. Si rien n'est spécifié autrement, les opérations sont effectuées sur la chaîne de configuration sélectionnée. Certaines opérations nécessitent également que la chaîne de configuration sélectionnée ne soit pas

connectée.

Définit les paramètres d'échantillonnage par défaut pour le chainsetup actuellement sélectionné. Par exemple, un son de qualité CD serait "16,2,44100". Ceci fait la même chose que l'argument de ligne de commande "-f" (voir ecasound (1)). [-]
cs-status, status, st
Affiche des informations sur le statut des chainsetups disponibles. Des informations détaillées sont affichées pour les chainsetups connectés (= disponibles pour l'exécution) et sélectionnés (= disponibles pour l'édition). Les autres chainsetups sont listés, mais les détails supplémentaires sont supprimés. Pour obtenir tous les détails d'un chainsetup spécifique, sélectionnez-le avec ’cs-select’ ou ’cs-iselect’, puis exécutez ’cs-select’. [s]
cs-option ’-préfixe:arg1,...,argN’
Une des fonctionnalités puissantes du mode interactif est qu'il offre un accès complet à la syntaxe de ligne de commande d'ecasound. Par exemple, la commande "cs-option -efb:400,200" signifie qu'un filtre passe-bande est ajouté à la chaîne actuellement sélectionnée, avec les paramètres initiaux 400 (fréquence centrale) et 200 (largeur en Hz).

Notez que les options au niveau de la session (telles que la définition du niveau de débogage) ne peuvent pas être utilisées avec ’cs-option’ (c'est-à-dire, seules les options qui modifient les chainsetups).

Attention ! Le mode interactif d'Ecasound interprète implicitement toutes les chaînes commençant par un ’-’ comme des chaînes "cs-option".

CHAÎNES

Une chaîne est une abstraction simple de flux de signaux. Chaque chaîne possède une entrée et une sortie. Tous les opérateurs de chaîne et leurs contrôleurs sont attachés aux chaînes. Les chaînes peuvent être mises en sourdine, désactivées et contournées. Sauf indication contraire, toutes les opérations sont effectuées sur la chaîne sélectionnée.

c-add ’nomc1,...,nomcN’
Ajoute un ensemble de chaînes. Les chaînes ajoutées sont automatiquement sélectionnées. Notez que les virgules dans les noms de chaînes ne sont pas autorisées. [-]
c-remove
Supprime les chaînes sélectionnées. [-]
c-list
Retourne une liste de toutes les chaînes. [S]
c-select ’nomc1,...,nomcN’
Sélectionne les chaînes. Les autres chaînes sont automatiquement désélectionnées. [-]
c-index-select ’index1,...,indexN’, c-iselect ’index1,...,indexN’
Sélectionne un ensemble de chaînes basé sur la liste des index. Chaque index est une valeur entière, où ’1’ fait référence à la première chaîne. Vous pouvez utiliser ’c-list’ et ’c-status’ pour obtenir une liste complète des chaînes actuellement disponibles. [-]
c-select-all
Sélectionne toutes les chaînes. [-]
c-select-add ’nomc1,...,nomcN’
Sélectionne des chaînes supplémentaires. [-]
c-deselect ’nomc1,...,nomcN’
Désélectionne les chaînes. [-]
c-selected
Retourne une liste des chaînes sélectionnées. [S]
c-clear
Efface les chaînes sélectionnées en supprimant tous les opérateurs et contrôleurs de chaîne. Ne modifie pas la manière dont les chaînes sont connectées aux entrées et sorties. [-]
c-rename ’nouveau_nom’
Renomme la chaîne sélectionnée. Lors de l'utilisation de cette commande, une seule chaîne doit être sélectionnée. [-]
c-mute <on|off|toggle>
Définit l'état de mise en sourdine de la chaîne actuellement sélectionnée. Lorsque la chaîne est mise en sourdine, elle ne produira que du silence.

La commande prend un seul paramètre : "on" -> la chaîne est mise en sourdine, "off" -> pas de mise en sourdine, et "toggle" -> change l'état de la mise en sourdine. Si le paramètre est omis, "toggle" est présumé (la mise en sourdine est activée ou désactivée, en fonction de l'état précédent).

Le contrôle des états de mise en sourdine des chaînes et des opérateurs de chaîne est indépendant. Si "c-mute off" est exécuté, les états des commandes individuelles de contournement de cop prendront effet. Si la chaîne est mise en sourdine, la chaîne produira du silence indépendamment de l'état de mise en sourdine des opérateurs de chaîne individuels. [-]

c-bypass <on|off|toggle>
Définit l'état de contournement de la chaîne actuellement sélectionnée. Lorsque la chaîne est contournée, les données d'échantillons sont transmises sans traitement (tous les opérateurs de chaîne sont désactivés pour la chaîne donnée).

La commande prend un seul paramètre : "on" -> la chaîne est contournée, "off" -> pas de contournement, et "toggle" -> change l'état du contournement. Si le paramètre est omis, "toggle" est présumé (le contournement est activé ou désactivé, en fonction de l'état précédent).

Le contrôle des états de contournement des chaînes et des opérateurs de chaîne est indépendant. Si le contournement de la chaîne est désactivé, les états des commandes individuelles de contournement de cop prendront effet. Si la chaîne est contournée, tous les opérateurs sont contournés indépendamment de leur état de contournement cop. [-]

c-status, cs
Affiche des informations sur le statut de toutes les chaînes. [s]
c-is-bypassed
Retourne vrai si la chaîne sélectionnée est actuellement contournée (aucun des opérateurs de chaîne n'est exécuté). Voir ’c-bypass’. [i]
c-is-mute
Retourne vrai si la chaîne sélectionnée est actuellement mise en sourdine (sort du silence en sortie). Voir ’c-mute’. [i]

OBJETS D'ENTRÉE/SORTIE AUDIO

Sauf indication contraire, toutes les opérations sont effectuées sur l'objet actuellement sélectionné. Toutes les commandes avec le préfixe ai- opèrent sur les entrées audio, tandis que les commandes avec ao- opèrent sur les sorties.

ai-add ’chaîne_format_entrée’
Ajoute un nouvel objet d'entrée. Voir la page de manuel d'ecasound (1) pour plus d'informations sur le format de l'argument (option ’-i’). Note sur la syntaxe : si l'un des paramètres (tel qu'un nom de fichier) contient des virgules, le paramètre doit être entouré de guillemets doubles. [-]
ao-add ’chaîne_format_sortie’
Ajoute un nouvel objet de sortie. Voir la page de manuel d'ecasound (1) pour plus d'informations sur le format des arguments (option ’-o’). Si l'argument est omis, un périphérique de sortie par défaut est ajouté (voir ecasoundrc (5)). Remarque sur la syntaxe : si l'un des paramètres (comme un nom de fichier) contient des virgules, le paramètre devrait être entouré de guillemets doubles. [-]
ao-add-default
Ajoute le périphérique de sortie par défaut (voir ecasoundrc (5)). [-]
ai-describe, ao-describe
Retourne une chaîne conforme à la syntaxe des options Ecasound (EOS) décrivant l'entrée/sortie. Voir le Guide de l'utilisateur d'Ecasound pour plus d'informations sur EOS. Cette commande a été introduite dans ecasound 2.4.4. [s]
ai-select ’nom_objet_audio’, ao-select ’nom_objet_audio’
Sélectionne un objet audio. ’nom_objet_audio’ fait référence à la chaîne utilisée lors de la création de l'objet (le premier argument donné à ai-add/ao-add). Notez que, contrairement à ai-add/ao-add, il ne faut pas entourer le nom de l'objet de guillemets doubles pour ai-select/ao-select. Dans le cas où un chainsetup contient plusieurs entrées, ou sorties, avec le même nom, ’ai-select’ et ’ao-select’ sélectionneront la première instance correspondante. Afin de sélectionner une instance spécifique, les commandes ’ai-iselect’ et ’ao-iselect’ doivent être utilisées. [-]
ai-index-select ’index_objet_audio’, ai-iselect ’index_objet_audio’, ao-index-select ’index_objet_audio’, ao-iselect ’index_objet_audio’
Sélectionne un objet audio basé sur une chaîne d'index courte. Les noms de fichiers, en particulier, peuvent être assez longs. Cette commande peut être utilisée pour éviter de taper ces longs noms lors de la sélection d'objets audio. ’index_objet_audio’ est une valeur entière, où ’1’ fait référence à la première entrée/sortie audio. Vous pouvez utiliser ’ai-list’ et ’ao-list’ pour obtenir une liste complète des entrées/sorties actuellement disponibles. [-]
ai-selected, ao-selected
Retourne le nom de l'objet audio actuellement sélectionné. [s]
ai-attach, ao-attach
Attache l'objet audio actuellement sélectionné à toutes les chaînes sélectionnées. [-]
ai-remove, ao-remove
Supprime l'objet audio actuellement sélectionné du chainsetup. [-]
ai-forward ’temps_en_secondes’, ai-fw ’temps_en_secondes’, ao-forward ’temps_en_secondes’, ao-fw ’temps_en_secondes’
L'objet audio sélectionné est avancé de ’temps-en-secondes’ secondes. Le temps doit être donné sous forme de valeur flottante (par exemple, 0.001 équivaut à 1 ms). [-]
ai-rewind ’temps_en_secondes’, ai-rw ’temps_en_secondes’, ao-rewind ’temps_en_secondes’, ao-rw ’temps_en_secondes’
L'objet audio sélectionné est reculé de ’temps-en-secondes’ secondes. Le temps doit être donné sous forme de valeur flottante (par exemple, 0.001 équivaut à 1 ms). [-]
ai-setpos ’temps_en_secondes’, ai-set-position ’temps_en_secondes’, ao-setpos ’temps_en_secondes’, ao-set-position ’temps_en_secondes’
Définit la position de l'objet audio à ’temps_en_secondes’. [-]
ai-set-position-samples ’temps_en_echantillons’, ao-set-position-samples ’temps_en_echantillons’
Définit la position de l'objet audio à ’temps_en_echantillons’. [-]
ai-getpos, ai-get-position, ao-getpos, ao-get-position
Retourne la position de l'objet audio en secondes. [f]
ai-get-position-samples, ao-get-position-samples
Retourne la position de l'objet audio en échantillons. [li]
ai-get-length, ao-get-length
Retourne la durée de l'objet audio en secondes. [f]
ai-get-length-samples, ao-get-length-samples
Retourne la durée de l'objet audio en échantillons. [li]
ai-get-format, ao-get-format
Retourne le format audio de l'entrée/sortie audio sélectionnée sous forme de chaîne formatée. Voir la documentation de l'option de ligne de commande ’-f’. [s]
ai-list, ao-list
Retourne une liste de tous les objets d'entrée/sortie. [S]
aio-register
Affiche une liste des types d'objets audio enregistrés. [s]
aio-status
Statut des objets audio (chaînes d'index, position, durée, etc.). [s]

OPÉRATEURS DE CHAÎNE

Les opérateurs de chaîne sont utilisés pour traiter et analyser les données d'échantillons. Ils sont attachés aux chaînes. Sauf indication contraire, le chainsetup et la chaîne actuellement sélectionnés sont utilisés. De plus, ’chainop_id’ et ’param_id’ sont utilisés pour sélectionner les opérateurs de chaîne et leurs paramètres. La première valeur valide pour ces paramètres est 1.

cop-add ’chaîne_format_opc’
Ajoute un nouvel opérateur de chaîne. En plus des opérateurs de chaîne normaux, cette commande peut également être utilisée pour ajouter des presets d'effets et divers plugins. Remarque : il n'est pas possible d'ajouter des opérateurs à plusieurs chaînes à la fois. Autrement dit, une seule chaîne doit être sélectionnée lors de l'émission de ’cop-add’. Voir la page de manuel ecasound (1) pour plus d'informations. [-]
cop-bypass <on|off|toggle>
Définit l'état de contournement de l'opérateur de chaîne actuellement sélectionné. La commande prend un seul paramètre : "on" -> l'opérateur est contourné, "off" -> pas de contournement, et "toggle" -> change l'état de contournement. Si le paramètre est omis, "toggle" est supposé (le contournement est activé ou désactivé, selon l'état précédent). [-]
cop-is-bypassed
Retourne vrai si l'opérateur de chaîne sélectionné est actuellement contourné (temporairement non inclus dans la chaîne de traitement). [i]
cop-describe
Retourne une chaîne conforme à la syntaxe des options Ecasound (EOS) décrivant l'opérateur de chaîne. Voir le Guide de l'utilisateur d'Ecasound pour plus d'informations sur EOS. Cette commande a été introduite dans ecasound 2.4.4. [s]
cop-remove
Supprime l'opérateur de chaîne sélectionné. [-]
cop-list
Retourne une liste de tous les opérateurs de chaîne attachés à la chaîne actuellement sélectionnée. [S]
cop-select ’param_id’, cop-index-select ’param_id’, cop-iselect ’param_id’
Sélectionne un opérateur de chaîne. [-]
cop-selected
Retourne le numéro d'index de l'opérateur de chaîne actuellement sélectionné. [i]
cop-set ’id_opc,id_param,valeur’
Modifie la valeur d'un paramètre unique d'opérateur de chaîne. Contrairement aux autres commandes d'opérateur de chaîne, celle-ci peut également être utilisée pendant le traitement. Voir aussi ’cop-get’. [-]
cop-get ’id_opc,id_param’
Retourne la valeur actuelle du paramètre d'opérateur de chaîne identifié par ’id_opc’ et ’id_param’. Cette commande est un raccourci pour ’cop-select id_opc ; copp-iselect id_param ; copp-get’. [f]
cop-status
Retourne des informations sur le statut de l'opérateur de chaîne. [s]
