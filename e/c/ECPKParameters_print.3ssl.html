ECPKPARAMETERS_PRINT(3ssl) OpenSSL ECPKPARAMETERS_PRINT(3ssl)

NOM

ECPKParameters_print, ECPKParameters_print_fp - Fonctions pour décoder et encoder les représentations ASN1 des entités de courbe elliptique

SYNTAXE

#include <openssl/ec.h>

Les fonctions suivantes sont dépréciées depuis OpenSSL 3.0, et peuvent être entièrement masquées en définissant OPENSSL_API_COMPAT avec une valeur de version appropriée, voir openssl_user_macros(7):

int ECPKParameters_print(BIO *bp, const EC_GROUP *x, int off);
int ECPKParameters_print_fp(FILE *fp, const EC_GROUP *x, int off);

DESCRIPTION

Toutes les fonctions décrites sur cette page sont dépréciées. Les applications devraient plutôt utiliser EVP_PKEY_print_params(3)

Les ECPKParameters représentent les paramètres publics d'une structure EC_GROUP, qui représente une courbe.

Les fonctions ECPKParameters_print() et ECPKParameters_print_fp() impriment une sortie lisible par l'homme des paramètres publics de l'EC_GROUP vers bp ou fp. Les lignes de sortie sont indentées de off espaces.

VALEURS DE RETOUR

ECPKParameters_print() et ECPKParameters_print_fp() renvoient 1 en cas de succès et 0 en cas d'erreur.

VOIR AUSSI

crypto(7), EC_GROUP_new(3), EC_GROUP_copy(3), EC_POINT_new(3), EC_POINT_add(3), EC_KEY_new(3), EC_GFp_simple_method(3),

HISTORIQUE

Toutes ces fonctions ont été dépréciées dans OpenSSL 3.0.
