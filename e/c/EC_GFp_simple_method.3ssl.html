NOM

EC_GFp_simple_method, EC_GFp_mont_method, EC_GFp_nist_method, EC_GFp_nistp224_method, EC_GFp_nistp256_method, EC_GFp_nistp521_method, EC_GF2m_simple_method, EC_METHOD_get_field_type - Fonctions pour obtenir des objets EC_METHOD

SYNTAXE

#include <openssl/ec.h>

Les fonctions suivantes sont obsolètes depuis OpenSSL 3.0 et peuvent être entièrement masquées en définissant OPENSSL_API_COMPAT avec une valeur de version appropriée, voir openssl_user_macros(7):

const EC_METHOD *EC_GFp_simple_method(void);
const EC_METHOD *EC_GFp_mont_method(void);
const EC_METHOD *EC_GFp_nist_method(void);
const EC_METHOD *EC_GFp_nistp224_method(void);
const EC_METHOD *EC_GFp_nistp256_method(void);
const EC_METHOD *EC_GFp_nistp521_method(void);
const EC_METHOD *EC_GF2m_simple_method(void);
int EC_METHOD_get_field_type(const EC_METHOD *meth);

DESCRIPTION

Toutes les fonctions const EC_GF* ont été obsolètes dans OpenSSL 3.0, car EC_METHOD n'est plus un concept public.

La bibliothèque Elliptic Curve fournit un certain nombre d'implémentations différentes via une interface commune unique. Lors de la construction d'une courbe à l'aide de EC_GROUP_new (voir EC_GROUP_new(3)), une méthode d'implémentation doit être fournie. Les fonctions décrites ici retournent toutes un pointeur constant vers une structure EC_METHOD qui peut être passée à EC_GROUP_NEW. Il est important d'utiliser le type d'implémentation correct pour la forme de courbe sélectionnée.

Pour les courbes F2^m, il n'y a qu'un seul choix d'implémentation, c'est-à-dire EC_GF2_simple_method.

Pour les courbes Fp, l'implémentation la plus basique est l'implémentation EC_GFp_simple_method. Toutes les autres implémentations sont basées sur celle-ci. EC_GFp_mont_method s'appuie sur EC_GFp_simple_method mais ajoute l'utilisation de la multiplication de Montgomery (voir BN_mod_mul_montgomery(3)). EC_GFp_nist_method offre une implémentation optimisée pour une utilisation avec les courbes recommandées par le NIST (les courbes NIST sont disponibles via EC_GROUP_new_by_curve_name tel que décrit dans EC_GROUP_new(3)).

Les fonctions EC_GFp_nistp224_method, EC_GFp_nistp256_method et EC_GFp_nistp521_method offrent des implémentations optimisées sur 64 bits pour les courbes NIST P224, P256 et P521 respectivement. Notez cependant que ces implémentations ne sont pas disponibles sur toutes les plateformes.

EC_METHOD_get_field_type() a été obsolète dans OpenSSL 3.0. Les applications doivent utiliser EC_GROUP_get_field_type() en remplacement (voir EC_GROUP_copy(3)).

VALEURS DE RETOUR

Toutes les fonctions EC_GFp* et EC_GF2m_simple_method retournent toujours un pointeur constant vers une structure EC_METHOD.

EC_METHOD_get_field_type retourne un entier qui identifie le type de champ supporté par la structure EC_METHOD.
