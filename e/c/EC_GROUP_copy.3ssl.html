const EC_METHOD *EC_GROUP_method_of(const EC_GROUP *group);

DESCRIPTION

EC_GROUP_copy() copie la courbe src dans dst. Les deux src et dst doivent utiliser le même EC_METHOD.

EC_GROUP_dup() crée un nouvel objet EC_GROUP et copie le contenu de src vers l'objet EC_GROUP nouvellement créé.

EC_GROUP_method_of() obtient le EC_METHOD de group. Cette fonction a été dépréciée dans OpenSSL 3.0, car EC_METHOD n'est plus un concept public.

EC_GROUP_set_generator() définit les paramètres de la courbe qui doivent être convenus par tous les participants utilisant la courbe. Ces paramètres incluent le générateur, l' ordre et le cofacteur. Le générateur est un point bien défini sur la courbe choisi pour les opérations cryptographiques. Les entiers utilisés pour les multiplications de points seront compris entre 0 et n-1 où n est l' ordre. L' ordre multiplié par le cofacteur donne le nombre de points sur la courbe.

EC_GROUP_get0_generator() retourne le générateur pour le groupe identifié.

EC_GROUP_get_order() récupère l'ordre du groupe et copie sa valeur dans order. Elle échoue si le groupe n'est pas entièrement initialisé (c'est-à-dire que son ordre n'est pas défini ou est défini à zéro).

EC_GROUP_get_cofactor() récupère le cofacteur du groupe et copie sa valeur dans cofactor. Elle échoue si le groupe n'est pas entièrement initialisé ou si le cofacteur n'est pas défini (ou est défini à zéro).

Les fonctions EC_GROUP_set_curve_name() et EC_GROUP_get_curve_name()définissent et récupèrent respectivement le NID pour la courbe (voir EC_GROUP_new(3)). Si une courbe n'a pas de NID associé, alors EC_GROUP_get_curve_name retournera NID_undef.

La valeur asn1_flag est utilisée pour déterminer si l'encodage de la courbe utilise des paramètres explicites ou une courbe nommée utilisant un OID ASN1 : de nombreuses applications ne prennent en charge que cette dernière forme. Si asn1_flag est OPENSSL_EC_NAMED_CURVE alors la forme courbe nommée est utilisée et les paramètres doivent avoir un NID de courbe nommée correspondant défini. Si asn1_flags est OPENSSL_EC_EXPLICIT_CURVE les paramètres sont encodés explicitement. Les fonctions EC_GROUP_get_asn1_flag() et EC_GROUP_set_asn1_flag() récupèrent et définissent respectivement l'état de l'asn1_flag pour la courbe. Note : OPENSSL_EC_EXPLICIT_CURVE a été ajouté dans OpenSSL 1.1.0, pour les versions précédentes d'OpenSSL la valeur 0 doit être utilisée à la place. Avant OpenSSL 1.1.0, la forme par défaut était d'utiliser des paramètres explicites (signifiant que les applications devaient définir explicitement la forme courbe nommée) dans OpenSSL 1.1.0 et ultérieur la forme courbe nommée est la valeur par défaut.

Le point_conversion_form pour une courbe contrôle comment les données EC_POINT sont encodées en ASN1 comme défini dans X9.62 (ECDSA). point_conversion_form_t est un enum défini comme suit :

typedef enum {
       /** le point est encodé comme z||x, où l'octet z spécifie
        *   quelle solution de l'équation quadratique y est */
       POINT_CONVERSION_COMPRESSED = 2,
       /** le point est encodé comme z||x||y, où z est l'octet 0x04 */
       POINT_CONVERSION_UNCOMPRESSED = 4,
       /** le point est encodé comme z||x||y, où l'octet z spécifie
        *  quelle solution de l'équation quadratique y est */
       POINT_CONVERSION_HYBRID = 6
} point_conversion_form_t;

Pour POINT_CONVERSION_UNCOMPRESSED le point est encodé comme un octet signifiant que la forme NON COMPRIMÉE a été utilisée suivi des octets pour x, suivi des octets pour y.

Pour toute coordonnée x donnée d'un point sur une courbe, il est possible de dériver deux valeurs possibles de y. Pour POINT_CONVERSION_COMPRESSED le point est encodé comme un octet signifiant que la forme COMPRIMÉE a été utilisée ET laquelle des deux solutions possibles pour y a été utilisée, suivi des octets pour x.

Pour POINT_CONVERSION_HYBRID le point est encodé comme un octet signifiant que la forme HYBRIDE a été utilisée ET laquelle des deux solutions possibles pour y a été utilisée, suivi des octets pour x, suivi des octets pour y.

Les fonctions EC_GROUP_set_point_conversion_form() et EC_GROUP_get_point_conversion_form()définissent et récupèrent respectivement le point_conversion_form pour la courbe.

ANSI X9.62 (standard ECDSA) définit une méthode de génération du paramètre de courbe b à partir d'un nombre aléatoire. Cela présente l'avantage qu'un paramètre obtenu de cette manière est très peu susceptible d'être vulnérable à des attaques spécialisées, ou de contenir des portes dérobées. Si la graine est présente pour une courbe, alors le paramètre b a été généré de manière vérifiable en utilisant cette graine. La bibliothèque EC d'OpenSSL n'utilise pas cette valeur de graine mais permet de l'inspecter en utilisant EC_GROUP_get0_seed(). Cela retourne un pointeur vers un bloc mémoire contenant la graine qui a été utilisée. La longueur du bloc mémoire peut être obtenue en utilisant EC_GROUP_get_seed_len(). Un certain nombre des courbes intégrées à la bibliothèque fournissent des valeurs de graine qui peuvent être obtenues. Il est également possible de définir une graine personnalisée en utilisant EC_GROUP_set_seed() et en passant un pointeur vers un bloc mémoire, avec la longueur de la graine. Encore une fois, la bibliothèque EC n'utilisera pas cette valeur de graine, bien qu'elle soit préservée dans toute communication basée sur ASN1.

EC_GROUP_get_degree() obtient le degré du corps. Pour les corps Fp ce sera le nombre de bits dans p. Pour les corps F2^m ce sera la valeur m.

EC_GROUP_get_field_type() identifie quel type de corps la structure EC_GROUP supporte, qui sera soit F2^m soit Fp.

La fonction EC_GROUP_check_discriminant() calcule le discriminant pour la courbe et vérifie qu'il est valide. Pour une courbe définie sur Fp le discriminant est donné par la formule 4*a^3 + 27*b^2 tandis que pour les courbes F2^m le discriminant est simplement b. Dans les deux cas pour que la courbe soit valide le discriminant doit être non nul.

La fonction EC_GROUP_check() se comporte de la manière suivante : Pour leprovider, il effectue un certain nombre de vérifications sur une courbe pour vérifier qu'elle est valide. Les vérifications effectuées incluent la vérification que le discriminant est non nul ; qu'un générateur a été défini ; que le générateur est sur la courbe et a l'ordre correct. Pour le fournisseur FIPS d'OpenSSL, il utilise EC_GROUP_check_named_curve() pour se conformer à SP800-56Ar3.

La fonction EC_GROUP_check_named_curve() détermine si les paramètres de domaine du groupe correspondent à l'une des courbes intégrées prises en charge par la bibliothèque. Le nom de la courbe est renvoyé sous forme de NID s'il correspond. Si les paramètres de domaine du groupe ont été modifiés, aucune correspondance ne sera trouvée. Si le nom de la courbe du groupe donné est NID_undef (par ex. il a été créé en utilisant des paramètres explicites sans nom de courbe), alors cette méthode peut être utilisée pour rechercher le nom de la courbe qui correspond aux paramètres de domaine du groupe. Les courbes intégrées contiennent des alias, de sorte que plusieurs NID peuvent correspondre aux mêmes paramètres de domaine. Pour de telles courbes, il n'est pas spécifié lequel des alias sera renvoyé si le nom de la courbe du groupe donné est NID_undef. Si nist_only vaut 1, il ne cherchera que les courbes approuvées par le NIST ; sinon, il recherche toutes les courbes intégrées. Cette fonction peut être passée un objet BN_CTX dans le ctx paramètre. Le ctx paramètre peut être NULL.

EC_GROUP_cmp() compare a et b pour déterminer s'ils représentent la même courbe ou non.

Les fonctions EC_GROUP_get_basis_type(), EC_GROUP_get_trinomial_basis() et EC_GROUP_get_pentanomial_basis() ne doivent être appelées que pour les courbes définies sur un corps F2^m. Les opérations d'addition et de multiplication au sein d'un corps F2^m sont effectuées à l'aide d'un polynôme irréductible f(x). Ce polynôme est soit un trinôme de la forme :

f(x) = x^m + x^k + 1 avec m > k >= 1

soit un pentanôme de la forme :

f(x) = x^m + x^k3 + x^k2 + x^k1 + 1 avec m > k3 > k2 > k1 >= 1

La fonction EC_GROUP_get_basis_type() renvoie un NID identifiant si un trinôme ou un pentanôme est utilisé pour le corps. La fonction EC_GROUP_get_trinomial_basis() ne doit être appelée que lorsque f(x) est de la forme d'un trinôme, et renvoie la valeur de k. De même la fonction EC_GROUP_get_pentanomial_basis() ne doit être appelée que lorsque f(x) est de la forme d'un pentanôme, et renvoie les valeurs de k1, k2 et k3 respectivement.

VALEURS RENVOYÉES

Les fonctions suivantes renvoient 1 en cas de succès ou 0 en cas d'erreur : EC_GROUP_copy(), EC_GROUP_set_generator(), EC_GROUP_check(), EC_GROUP_check_discriminant(), EC_GROUP_get_trinomial_basis() et EC_GROUP_get_pentanomial_basis().

EC_GROUP_dup() renvoie un pointeur vers la courbe dupliquée, ou NULL en cas d'erreur.

EC_GROUP_method_of() renvoie l'implémentation EC_METHOD utilisée pour la courbe donnée ou NULL en cas d'erreur.

EC_GROUP_get0_generator() renvoie le générateur pour la courbe donnée ou NULL en cas d'erreur.

EC_GROUP_get_order() renvoie 0 si l'ordre n'est pas défini (ou défini à zéro) pour group ou si la copie dans order échoue, 1 sinon.

EC_GROUP_get_cofactor() renvoie 0 si le cofacteur n'est pas défini (ou est défini à zéro) pour group ou si la copie dans cofactor échoue, 1 sinon.

EC_GROUP_get_curve_name() renvoie le nom de la courbe (NID) pour group ou renverra NID_undef si aucun nom de courbe n'est associé.

EC_GROUP_get_asn1_flag() renvoie le drapeau ASN1 pour le groupe spécifié group .

EC_GROUP_get_point_conversion_form() renvoie le point_conversion_form pour group.

EC_GROUP_get_degree() renvoie le degré pour group ou 0 si l'opération n'est pas prise en charge par l'implémentation sous-jacente du groupe.

EC_GROUP_get_field_type() renvoie soit NID_X9_62_prime_field pour les courbes sur corps premiers, soit NID_X9_62_characteristic_two_field pour les courbes binaires ; ces valeurs sont définies dans le <openssl/obj_mac.h> fichier d'en-tête.

EC_GROUP_check_named_curve() renvoie le nid de la courbe nommée correspondante, sinon il renvoie 0 pour aucune correspondance, ou -1 en cas d'erreur.

EC_GROUP_get0_order() renvoie un pointeur interne vers l'ordre du groupe. EC_GROUP_order_bits() renvoie le nombre de bits dans l'ordre du groupe. EC_GROUP_get0_cofactor() renvoie un pointeur interne vers le cofacteur du groupe. EC_GROUP_get0_field() renvoie un pointeur interne vers le corps du groupe. Pour les courbes sur GF(p), c'est le module ; pour les courbes sur GF(2^m), c'est le polynôme irréductible définissant le corps.

EC_GROUP_get0_seed() renvoie un pointeur vers la graine qui a été utilisée pour générer le paramètre b, ou NULL si la graine n'est pas spécifiée. EC_GROUP_get_seed_len() renvoie la longueur de la graine ou 0 si la graine n'est pas spécifiée.

EC_GROUP_set_seed() renvoie la longueur de la graine qui a été définie. Si la graine fournie est NULL, ou si la longueur de la graine fournie est 0, la valeur de retour sera 1. En cas d'erreur, 0 est renvoyé.

EC_GROUP_cmp() renvoie 0 si les courbes sont égales, 1 si elles ne sont pas égales, ou -1 en cas d'erreur.

EC_GROUP_get_basis_type() renvoie les valeurs NID_X9_62_tpBasis ou NID_X9_62_ppBasis (telles que définies dans <openssl/obj_mac.h>) pour un trinôme ou un pentanôme respectivement. Alternativement, en cas d'erreur, un 0 est renvoyé.
