NOM

ecryptfs-verify - valider un répertoire personnel chiffré ou une configuration privée chiffrée eCryptfs

SYNTAXE

ecryptfs-verify [-h|--home] [-p|--private] [-e|--filenames-encrypted] [-n|--filenames-not-encrypted] [-u|--user UTILISATEUR] [--help]

OPTIONS

-h, --home
Vrai si HOME est correctement configuré pour le chiffrement, faux sinon.
-p, --private
Vrai si un répertoire autre que HOME est correctement configuré pour le chiffrement, faux sinon.
-e, --filenames-encrypted
Vrai si les noms de fichiers sont définis pour le chiffrement, faux sinon.
-n, --filenames-not-encrypted
Vrai si les noms de fichiers ne sont pas chiffrés, faux sinon.
-u, --user UTILISATEUR
Par défaut, la configuration de l'utilisateur actuel est vérifiée, remplacez avec cette option.
--help
Ces informations d'utilisation.

DESCRIPTION

Notez que les options sont additives. TOUTES les vérifications doivent réussir pour que ce programme se termine avec un code de sortie 0. Toute vérification échouée provoquera la sortie de ce programme avec un code non nul.
