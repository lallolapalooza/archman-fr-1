NOM

ecryptfs-mount-private - script wrapper interactif pour le montage privé eCryptfs.

SYNTAXE

ecryptfs-mount-private

DESCRIPTION

ecryptfs-mount-private est un script wrapper pour l'utilitaire mount.ecryptfs_private qui demandera interactivement le mot de passe de connexion de l'utilisateur, si nécessaire.

FICHIERS

~/.Private - répertoire sous-jacent contenant les données chiffrées

~/Private - point de montage contenant les données déchiffrées (lorsqu'il est monté)

~/.ecryptfs/Private.sig - fichier contenant la signature de la phrase secrète du point de montage

~/.ecryptfs/wrapped-passphrase - fichier contenant la phrase secrète enveloppée

~/.ecryptfs/wrapping-independent - ce fichier existe si la phrase secrète d'enveloppement est indépendante de la phrase secrète de connexion

VOIR AUSSI
