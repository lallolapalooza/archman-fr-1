EC_KEY_get_enc_flags(3ssl)

Paquet: openssl

Licences: Apache-2.0

EC_KEY_GET_ENC_FLAGS(3ssl) OpenSSL EC_KEY_GET_ENC_FLAGS(3ssl)

NOM

EC_KEY_get_enc_flags, EC_KEY_set_enc_flags - Obtenir et définir les indicateurs pour le codage des structures EC_KEY

SYNTAXE

#include <openssl/ec.h>
unsigned int EC_KEY_get_enc_flags(const EC_KEY *key);
void EC_KEY_set_enc_flags(EC_KEY *eckey, unsigned int flags);

DESCRIPTION

Le format de la représentation externe de la clé publique écrite par i2d_ECPrivateKey() (par exemple, si elle est stockée sous forme compressée ou non) est décrit par la forme_de_conversion_du_point. Voir EC_GROUP_copy(3) pour une description de forme_de_conversion_du_point.

Lors de la lecture d'une clé privée codée sans clé publique associée (par exemple, si EC_PKEY_NO_PUBKEY a été utilisé - voir ci-dessous), d2i_ECPrivateKey() génère automatiquement la clé publique manquante. Les clés privées codées sans paramètres (par exemple, si EC_PKEY_NO_PARAMETERS a été utilisé - voir ci-dessous) ne peuvent pas être chargées à l'aide de d2i_ECPrivateKey().

Les fonctions EC_KEY_get_enc_flags() et EC_KEY_set_enc_flags() obtiennent et définissent la valeur des indicateurs de codage pour la clé. Il existe actuellement deux indicateurs de codage définis : EC_PKEY_NO_PARAMETERS et EC_PKEY_NO_PUBKEY. Ces indicateurs définissent le comportement de la manière dont la clé est convertie en ASN1 lors d'un appel à i2d_ECPrivateKey(). Si EC_PKEY_NO_PARAMETERS est défini, les paramètres publics de la courbe ne sont pas codés avec la clé privée. Si EC_PKEY_NO_PUBKEY est défini, la clé publique n'est pas codée avec la clé privée.

VALEURS DE RETOUR

EC_KEY_get_enc_flags() renvoie la valeur des indicateurs de codage actuels pour l'EC_KEY.
