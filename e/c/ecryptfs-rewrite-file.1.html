NOM

ecryptfs-rewrite-file - force une réécriture (ré-chiffrement) d'un fichier dans le système de fichiers inférieur

SYNTAXE

ecryptfs-rewrite-file [fichier1] [fichier2] [fichier3] ...

DESCRIPTION

Ce script prend un ou plusieurs fichiers/répertoires/liens symboliques comme arguments, les déplace vers un fichier temporaire, puis les déplace à nouveau vers leur nom d'origine. Cela provoque la réécriture (et le ré-chiffrement) du fichier dans le système de fichiers inférieur.

Ce script peut être combiné avec find(1) et xargs(1) pour réécrire un point de montage eCryptfs entier, le démonter et synchroniser :


find . -xdev -print0 | xargs -r -0 /usr/bin/ecryptfs-rewrite-file
ecryptfs-umount-private
sync

Il est conseillé d'exécuter ce script en niveau d'exécution 1 ou 3, afin d'éviter les écritures simultanées et les conditions de concurrence avec les fichiers ciblés.

L'UTILISATION DE CE SCRIPT PENDANT L'EXÉCUTION DE GNOME, KDE OU D'AUTRES APPLICATIONS PEUT ENTRAÎNER UNE PERTE DE DONNÉES.

VOIR AUSSI

find(1), xargs(1), ecryptfs-umount-private(1), sync(1)
http://ecryptfs.org/
