NOM

ecryptfs-generate-tpm-key - génère une clé eCryptfs pour du matériel TPM.

SYNTAXE

ecryptfs-generate-tpm-key -p PCR [-p PCR]...

DESCRIPTION

ecryptfs-generate-tpm-key est un utilitaire pour générer une clé de scellement (de stockage) liée à un ensemble spécifié de valeurs PCR dans les PCR du TPM actuel.

EXEMPLE

ecryptfs-generate-tpm-key -p 0 -p 2 -p 3
