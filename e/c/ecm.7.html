NOM

ecm - Modules CMake Supplémentaires

INTRODUCTION

Le paquet Extra CMake Modules, ou ECM, complète les modules fournis par CMake, y compris ceux utilisés par find_package() pour trouver des logiciels courants, ceux qui peuvent être utilisés directement dans les fichiers CMakeLists.txt pour effectuer des tâches courantes et les fichiers de chaîne d'outils qui doivent être spécifiés en ligne de commande par l'utilisateur.

De plus, il fournit des paramètres de construction courants utilisés dans les logiciels produits par la communauté KDE.

Bien que le moteur de ce module soit de réduire la duplication dans les scripts CMake à travers les logiciels KDE, il est destiné à être utile pour tout logiciel utilisant le système de construction CMake.

UTILISATION

Pour utiliser ECM, ajoutez ce qui suit à votre CMakeLists.txt :

find_package(ECM REQUIRED NO_MODULE)
set(CMAKE_MODULE_PATH ${ECM_MODULE_PATH})

(notez que vous pourriez vouloir ajouter ${ECM_MODULE_PATH} à CMAKE_MODULE_PATH plutôt que de supprimer la valeur existante). Vous pouvez alors simplement inclure les modules dont vous avez besoin, ou utiliser find_package() au besoin. Par exemple :

include(ECMInstallIcons)

Les développeurs de logiciels KDE voudront souvent utiliser les paramètres standard de KDE fournis par ECM ; ils peuvent faire ce qui suit :

find_package(ECM REQUIRED NO_MODULE)
set(CMAKE_MODULE_PATH ${ECM_MODULE_PATH})
include(KDEInstallDirs)
include(KDECompilerSettings)
include(KDECMakeSettings)

Notez que n'importe quelle combinaison des inclusions ci-dessus peut être utilisée si vous ne souhaitez que certains des paramètres. Une partie de la fonctionnalité de KDECMakeSettings <#kde-module:KDECMakeSettings> peut également être désactivée sélectivement.

Organisation

ECM fournit quatre types différents de modules.

  • Les modules de base fournissent des macros utiles pour les scripts CMake de projet. Voir ecm-modules(7) <#manual:ecm-modules(7)> pour plus d'informations.
  • Les modules de recherche étendent la fonctionnalité de la commande find_package() de CMake. Voir ecm-find-modules(7) <#manual:ecm-find-modules(7)> pour plus d'informations.
  • Les modules KDE fournissent des paramètres courants pour les logiciels produits par KDE ; une grande partie de cela peut également être utile à d'autres projets. Voir ecm-kde-modules(7) <#manual:ecm-kde-modules(7)> pour plus d'informations.
  • Les fichiers de chaîne d'outils modifient les outils de construction et les cibles utilisés par CMake. Voir ecm-toolchains(7) <#manual:ecm-toolchains(7)> pour plus d'informations.

Les variables ${ECM_MODULE_DIR}, ${ECM_FIND_MODULE_DIR} et ${ECM_KDE_MODULE_DIR} peuvent être utilisées à la place de ${ECM_MODULE_PATH} si vous n'avez besoin que d'une partie de cette fonctionnalité.
