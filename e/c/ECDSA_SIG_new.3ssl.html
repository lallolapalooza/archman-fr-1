ECDSA_SIG_new(3ssl)

Paquet: openssl

Licences: Apache-2.0

ECDSA_SIG_NEW(3ssl) OpenSSL ECDSA_SIG_NEW(3ssl)

NOM

ECDSA_SIG_new, ECDSA_SIG_free, ECDSA_SIG_get0, ECDSA_SIG_get0_r, ECDSA_SIG_get0_s, ECDSA_SIG_set0 - Fonctions pour créer, détruire et manipuler les objets ECDSA_SIG

SYNOPIS

#include <openssl/ecdsa.h>
ECDSA_SIG *ECDSA_SIG_new(void);
void ECDSA_SIG_free(ECDSA_SIG *sig);
void ECDSA_SIG_get0(const ECDSA_SIG *sig, const BIGNUM **pr, const BIGNUM **ps);
const BIGNUM *ECDSA_SIG_get0_r(const ECDSA_SIG *sig);
const BIGNUM *ECDSA_SIG_get0_s(const ECDSA_SIG *sig);
int ECDSA_SIG_set0(ECDSA_SIG *sig, BIGNUM *r, BIGNUM *s);

DESCRIPTION

ECDSA_SIG est une structure opaque composée de deux BIGNUMs pour les valeurs r et s d'une signature Algorithme de Signature Numérique sur Courbe Elliptique (ECDSA) (voir FIPS186-4 ou X9.62). L'objet ECDSA_SIG était principalement utilisé par les fonctions de bas niveau obsolètes décrites dans ECDSA_sign(3), il est toujours nécessaire pour pouvoir définir ou obtenir les valeurs de r et s dans ou à partir d'une signature. Ceci est principalement utilisé à des fins de test comme indiqué dans les "EXEMPLES".

ECDSA_SIG_new() alloue une structure ECDSA_SIG vide. Remarque : avant OpenSSL 1.1.0, les composants r et s étaient initialisés.

ECDSA_SIG_free() libère la structure ECDSA_SIG sig. Si l'argument est NULL, rien n'est fait.

ECDSA_SIG_get0() renvoie des pointeurs internes aux valeurs r et s contenues dans sig et les stocke dans *pr et *ps, respectivement. Le pointeur pr ou ps peut être NULL, auquel cas la valeur correspondante n'est pas retournée.

Les valeurs r, s peuvent également être récupérées séparément par les fonctions correspondantes ECDSA_SIG_get0_r() et ECDSA_SIG_get0_s(), respectivement.

Des valeurs r et s non NULL peuvent être définies sur le sig en appelant ECDSA_SIG_set0(). L'appel de cette fonction transfère la gestion de la mémoire des valeurs à l'objet ECDSA_SIG, et par conséquent les valeurs qui ont été passées ne doivent pas être libérées par l'appelant.

Voir i2d_ECDSA_SIG(3) et d2i_ECDSA_SIG(3) pour des informations sur l'encodage et le décodage des signatures ECDSA en/depuis DER.

VALEURS DE RETOUR

ECDSA_SIG_new() renvoie NULL si l'allocation échoue.

ECDSA_SIG_set0() renvoie 1 en cas de succès ou 0 en cas d'échec.

ECDSA_SIG_get0_r() et ECDSA_SIG_get0_s() renvoient la valeur correspondante, ou NULL si elle n'est pas définie.

EXEMPLES

Extraire les valeurs r et s de la signature d'une signature ECDSA signature de longueur signaturelen :

ECDSA_SIG *obj;
const BIGNUM *r, *s;
/* Charger une signature dans l'objet ECDSA_SIG */
obj = d2i_ECDSA_SIG(NULL, &signature, signaturelen);
if (obj == NULL)
    /* erreur */
r = ECDSA_SIG_get0_r(obj);
s = ECDSA_SIG_get0_s(obj);
if (r == NULL || s == NULL)
    /* erreur */
/* Utiliser BN_bn2binpad() ici pour convertir r et s en tableaux d'octets */
/*
 * N'essayez pas d'accéder à I<r> ou I<s> après avoir appelé ECDSA_SIG_free(),
 * car ils seront tous deux libérés par cet appel.
 */
ECDSA_SIG_free(obj);

Convertir des tableaux d'octets r et s en une signature ECDSA signature de longueur signaturelen :

ECDSA_SIG *obj = NULL;
unsigned char *signature = NULL;
size_t signaturelen;
BIGNUM *rbn = NULL, *sbn = NULL;
obj = ECDSA_SIG_new();
if (obj == NULL)
    /* erreur */
rbn = BN_bin2bn(r, rlen, NULL);
sbn = BN_bin2bn(s, slen, NULL);
if (rbn == NULL || sbn == NULL)
    /* erreur */
if (!ECDSA_SIG_set0(obj, rbn, sbn))
    /* erreur */
/* Définir ces valeurs à NULL car elles sont maintenant détenues par obj */
rbn = sbn = NULL;
signaturelen = i2d_ECDSA_SIG(obj, &signature);
if (signaturelen <= 0)
    /* erreur */
/*
 * Cette signature pourrait maintenant être passée à L<EVP_DigestVerify(3)>
 * ou L<EVP_DigestVerifyFinal(3)>
 */
BN_free(rbn);
BN_free(sbn);
OPENSSL_free(signature);
ECDSA_SIG_free(obj);
