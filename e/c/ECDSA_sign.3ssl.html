ECDSA_sign(3ssl)

Paquet: openssl

Licences: Apache-2.0

ECDSA_SIGN(3ssl) OpenSSL ECDSA_SIGN(3ssl)

NOM

ECDSA_size, ECDSA_sign, ECDSA_do_sign, ECDSA_verify, ECDSA_do_verify, ECDSA_sign_setup, ECDSA_sign_ex, ECDSA_do_sign_ex - fonctions obsolètes de bas niveau pour l'algorithme de signature numérique sur courbe elliptique (ECDSA)

SYNOPSISSE

#include <openssl/ecdsa.h>

Les fonctions suivantes sont obsolètes depuis OpenSSL 3.0 et peuvent être entièrement masquées en définissant OPENSSL_API_COMPAT avec une valeur de version appropriée, voir openssl_user_macros(7):

int ECDSA_size(const EC_KEY *eckey);
int ECDSA_sign(int type, const unsigned char *dgst, int dgstlen,
               unsigned char *sig, unsigned int *siglen, EC_KEY *eckey);
ECDSA_SIG *ECDSA_do_sign(const unsigned char *dgst, int dgst_len,
                         EC_KEY *eckey);
int ECDSA_verify(int type, const unsigned char *dgst, int dgstlen,
                 const unsigned char *sig, int siglen, EC_KEY *eckey);
int ECDSA_do_verify(const unsigned char *dgst, int dgst_len,
                    const ECDSA_SIG *sig, EC_KEY* eckey);
ECDSA_SIG *ECDSA_do_sign_ex(const unsigned char *dgst, int dgstlen,
                            const BIGNUM *kinv, const BIGNUM *rp,
                            EC_KEY *eckey);
int ECDSA_sign_setup(EC_KEY *eckey, BN_CTX *ctx, BIGNUM **kinv, BIGNUM **rp);
int ECDSA_sign_ex(int type, const unsigned char *dgst, int dgstlen,
                  unsigned char *sig, unsigned int *siglen,
                  const BIGNUM *kinv, const BIGNUM *rp, EC_KEY *eckey);

DESCRIPTION

Voir ECDSA_SIG_new(3) pour une description de l'objet ECDSA_SIG .

Voir i2d_ECDSA_SIG(3) et d2i_ECDSA_SIG(3) pour des informations sur l'encodage et le décodage des signatures ECDSA vers/depuis DER.

Toutes les fonctions décrites ci-dessous sont obsolètes. Les applications devraient utiliser l'interface de haut niveau EVP telle que EVP_DigestSignInit(3) ou EVP_DigestVerifyInit(3) à la place.

ECDSA_size() renvoie la longueur maximale d'une signature ECDSA encodée en DER créée avec la clé EC privée eckey. Pour obtenir la taille réelle de la signature, utilisez EVP_PKEY_sign(3) avec un paramètre sig NULL.

ECDSA_sign() calcule une signature numérique de la valeur de hachage de dgstlen octets dgst en utilisant la clé EC privée eckey. La signature encodée en DER est stockée dans sig et sa longueur est renvoyée dans siglen. Remarque : sig doit pointer vers ECDSA_size(eckey) octets de mémoire. Le paramètre type est actuellement ignoré. ECDSA_sign() est une fonction enveloppe pour ECDSA_sign_ex() avec kinv et rp définis à NULL.

ECDSA_do_sign() est similaire à ECDSA_sign() sauf que la signature est renvoyée sous la forme d'une structure ECDSA_SIG nouvellement allouée (ou NULL en cas d'erreur). ECDSA_do_sign() est une fonction enveloppe pour ECDSA_do_sign_ex() avec kinv et rp définis à NULL.

ECDSA_verify() vérifie que la signature dans sig de taille siglen est une signature ECDSA valide de la valeur de hachage dgst de taille dgstlen en utilisant la clé publique eckey. Le paramètre type est ignoré.

ECDSA_do_verify() est similaire à ECDSA_verify() sauf que la signature est présentée sous la forme d'un pointeur vers une structure ECDSA_SIG .

Les fonctions restantes utilisent les valeurs internes kinv et r utilisées lors du calcul de la signature. La plupart des applications n'auront jamais besoin de les appeler et certaines implémentations ENGINE ECDSA externes peuvent ne pas les prendre en charge du tout si kinv ou r n'est pas NULL.

ECDSA_sign_setup() peut être utilisé pour précalculer des parties de l'opération de signature. eckey est la clé EC privée et ctx est un pointeur vers une structure BN_CTX (ou NULL). Les valeurs précalculées sont renvoyées dans kinv et rp et peuvent être utilisées dans un appel ultérieur à ECDSA_sign_ex() ou ECDSA_do_sign_ex().

ECDSA_sign_ex() calcule une signature numérique de la valeur de hachage de dgstlen octets dgst en utilisant la clé EC privée eckey et les valeurs optionnelles précalculées kinv et rp. La signature encodée en DER est stockée dans sig et sa longueur est renvoyée dans siglen. Remarque : sig doit pointer vers ECDSA_size(eckey) octets de mémoire. Le paramètre type est ignoré.

ECDSA_do_sign_ex() est similaire à ECDSA_sign_ex() sauf que la signature est renvoyée sous la forme d'une structure ECDSA_SIG nouvellement allouée (ou NULL en cas d'erreur).

VALEURS RENVOYÉES

ECDSA_size() renvoie la longueur maximale de la signature ou 0 en cas d'erreur.

ECDSA_sign(), ECDSA_sign_ex() et ECDSA_sign_setup() renvoient 1 en cas de succès ou 0 en cas d'erreur.

ECDSA_do_sign() et ECDSA_do_sign_ex() renvoient un pointeur vers une structure ECDSA_SIG allouée ou NULL en cas d'erreur.

ECDSA_verify() et ECDSA_do_verify() renvoient 1 pour une signature valide, 0 pour une signature invalide et -1 en cas d'erreur. Les codes d'erreur peuvent être obtenus par ERR_get_error(3).

EXEMPLES

Création d'une signature ECDSA d'une valeur de hachage SHA-256 donnée en utilisant la courbe nommée prime256v1 (alias P-256). Cet exemple utilise une fonctionnalité obsolète. Voir « DESCRIPTION ».

Première étape : créer un objet EC_KEY (remarque : cette partie n'est pas pas spécifique à ECDSA)

int ret;
ECDSA_SIG *sig;
EC_KEY *eckey;
eckey = EC_KEY_new_by_curve_name(NID_X9_62_prime256v1);
if (eckey == NULL)
    /* erreur */
if (EC_KEY_generate_key(eckey) == 0)
    /* erreur */

Deuxième étape : calculer la signature ECDSA d'une valeur de hachage SHA-256 en utilisant ECDSA_do_sign():

sig = ECDSA_do_sign(digest, 32, eckey);
if (sig == NULL)
    /* erreur */

ou en utilisant ECDSA_sign():

unsigned char *buffer, *pp;
int buf_len;
buf_len = ECDSA_size(eckey);
buffer = OPENSSL_malloc(buf_len);
pp = buffer;
if (ECDSA_sign(0, dgst, dgstlen, pp, &buf_len, eckey) == 0)
    /* erreur */

Troisième étape : vérifier la signature ECDSA créée en utilisant ECDSA_do_verify():

ret = ECDSA_do_verify(digest, 32, sig, eckey);

ou en utilisant ECDSA_verify():

ret = ECDSA_verify(0, digest, 32, buffer, buf_len, eckey);

et enfin évaluer la valeur de retour :

if (ret == 1)
    /* signature ok */
else if (ret == 0)
    /* signature incorrecte */
else
    /* erreur */

CONFORMITÉ

ANSI X9.62, Norme fédérale américaine de traitement de l'information FIPS186-2 (Digital Signature Standard, DSS)

VOIR AUSSI

EC_KEY_new(3), EVP_DigestSignInit(3), EVP_DigestVerifyInit(3), EVP_PKEY_sign(3) i2d_ECDSA_SIG(3), d2i_ECDSA_SIG(3)

HISTORIQUE

Toute la fonctionnalité décrite ici a été déclarée obsolète dans OpenSSL 3.0.
