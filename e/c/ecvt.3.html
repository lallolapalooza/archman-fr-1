ecvt(3) Manuel des fonctions de bibliothèque ecvt(3)

NOM

ecvt, fcvt - convertir un nombre à virgule flottante en chaîne

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <stdlib.h>
[[deprecated]] char *ecvt(double nombre, int ndigits,
                          int *restrict decpt, int *restrict sign);
[[deprecated]] char *fcvt(double nombre, int ndigits,
                          int *restrict decpt, int *restrict sign);
Exigences de la macro de test de fonctionnalités pour glibc (voir feature_test_macros(7)):

ecvt(), fcvt():

    Depuis glibc 2.17
        (_XOPEN_SOURCE >= 500 && ! (_POSIX_C_SOURCE >= 200809L))
            || /* glibc >= 2.20 */ _DEFAULT_SOURCE
            || /* glibc <= 2.19 */ _SVID_SOURCE
    glibc 2.12 à glibc 2.16 :
        (_XOPEN_SOURCE >= 500 && ! (_POSIX_C_SOURCE >= 2001112L))
            || _SVID_SOURCE
    Avant glibc 2.12 :
        _SVID_SOURCE || _XOPEN_SOURCE >= 500

DESCRIPTION

La fonction ecvt() convertit nombre en une chaîne de ndigits chiffres terminée par un caractère nul (où ndigits est réduit à une limite spécifique au système déterminée par la précision d'un double), et renvoie un pointeur vers la chaîne. Le chiffre de poids fort est non nul, sauf si nombre est zéro. Le chiffre de poids faible est arrondi. La chaîne elle-même ne contient pas de point décimal ; cependant, la position du point décimal par rapport au début de la chaîne est stockée dans *decpt. Une valeur négative pour *decpt signifie que le point décimal est à gauche du début de la chaîne. Si le signe de nombre est négatif, *sign est mis à une valeur non nulle, sinon il est mis à 0. Si nombre est zéro, il n'est pas spécifié si *decpt est 0 ou 1.

La fonction fcvt() est identique à ecvt(), sauf que ndigits spécifie le nombre de chiffres après le point décimal.

VALEUR DE RETOUR

Les fonctions ecvt() et fcvt() renvoient un pointeur vers une chaîne statique contenant la représentation ASCII de nombre. La chaîne statique est écrasée par chaque appel à ecvt() ou fcvt().

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
ecvt () Sécurité des threads MT-Unsafe race:ecvt
fcvt () Sécurité des threads MT-Unsafe race:fcvt

NORMES

Aucune.

HISTORIQUE

SVr2 ; marqué comme LEGACY dans POSIX.1-2001. POSIX.1-2008 supprime les spécifications de ecvt() et fcvt(), recommandant l'utilisation de sprintf(3) à la place (bien que snprintf(3) puisse être préférable).

NOTES

Tous les paramètres régionaux n'utilisent pas un point comme caractère de séparation décimale.

VOIR AUSSI
