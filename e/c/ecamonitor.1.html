NOM

ecatools - utilitaires de traitement audio basés sur ecasound

SYNTAXE

ecaconvert .extension fichier1 [ fichier2 ... fichierN ]

ecafixdc fichier1 [ fichier2 ... fichierN ]

ecalength fichier1 [ fichier2 ... fichierN ]

ecamonitor [hôte][:port]

ecanormalize fichier1 [ fichier2 ... fichierN ]

ecaplay [-dfhklopq] [ fichier1 fichier2 ... fichierN ]

ecasignalview [ options ] [ entrée ] [ sortie ]

DESCRIPTION

Ecatools sont de simples utilitaires en ligne de commande pour le traitement de fichiers audio. Chaque outil est conçu pour effectuer une opération spécifique. La plupart des outils prennent également en charge le traitement par lots.

ECACONVERT

Un outil pour convertir un ensemble de fichiers vers un format cible commun. Ce format cible est donné comme premier argument de la ligne de commande, et sa syntaxe est .ext.

ECAFIXDC

Un outil simple en ligne de commande pour corriger le décalage CC (courant continu).

ECALENGTH

Voir la page de manuel séparée ecalength(1).

ECAMONITOR

Ecamonitor est un programme utilitaire qui peut être utilisé pour surveiller une session ecasound active. Ecamonitor est capable d'afficher des informations sur la configuration de la chaîne actuelle, telles que la liste des entrées, des sorties, la position actuelle, les effets, l'état du moteur et de nombreuses autres choses.

Par défaut, ecamonitor tentera de se connecter à l'adresse IP4 "localhost", sur le port "2868". Une adresse différente peut être spécifiée lors du lancement d'ecamonitor, par exemple "ecamonitor foo.mynetwork.com" ou "ecamonitor foo.mynetwork.com:4500".

Pour activer les connexions entrantes, ecasound doit être lancé avec l'option --daemon. Ecamonitor est implémenté en Python en utilisant l'API NetECI.

ECANORMALIZE

Ecanormalize est un outil en ligne de commande pour normaliser les fichiers audio afin qu'ils utilisent toute la résolution d'échantillon disponible. Ecanormalize détermine d'abord de combien le fichier d'entrée peut être amplifié sans écrêtage et s'il y a de la place pour une augmentation, un gain statique sera appliqué au fichier.

ECAPLAY

Ecaplay est un outil en ligne de commande pour lire des fichiers audio. Ecaplay utilise le moteur libecasound et est ainsi capable de gérer tous les formats audio pris en charge par la bibliothèque.

Les fichiers peuvent être sélectionnés pour la lecture soit en spécifiant les noms de fichiers sur la ligne de commande, soit en utilisant le mécanisme de playlist. En mode playlist, les fichiers peuvent être ajoutés à la playlist en utilisant l'option -q. L'option -p peut ensuite être utilisée pour lire toutes les pistes de la playlist. Ecaplay répétera les pistes de la playlist jusqu'à ce qu'il soit explicitement arrêté (avec double Ctrl-C). La playlist peut être vidée avec -f et son contenu listé avec l'option -l.

Si rien d'autre n'est spécifié, ecaplay utilisera le périphérique de sortie audio spécifié dans ~/.ecasound/ecasoundrc pour la lecture. Un périphérique de sortie différent peut être sélectionné avec la variable d'environnement shell ECAPLAY_OUTPUT_DEVICE ou avec l'option de ligne de commande -o:périphérique_sortie.

La lecture peut être arrêtée à tout moment avec Ctrl-C. Si plusieurs fichiers sont lus, un premier Ctrl-C arrêtera le fichier courant et passera au suivant. Appuyer deux fois sur Ctrl-C (dans la seconde) fera quitter ecaplay.

-d:niveau_debug
Définit le niveau de débogage de libecasound. Voir ecasound(1).
-f
Vide le contenu de la playlist. Voir aussi les options -l, -p et -q.
-h
Affiche les informations d'utilisation et quitte.
-k:nombre
Ignore ’nombre’ de fichiers.
-l
Liste le contenu actuel de la playlist sur stdout. Voir aussi les options -f, -p et -q.
-o:périphérique_sortie
Utilise ’périphérique_sortie’ au lieu du périphérique de sortie par défaut (tel que spécifié dans ~/.ecasound/ecasoundrc). La syntaxe est la même que celle utilisée par l'option "-o" d'ecasound (voir la page de manuel d'ecasound(1)). Cette option remplace la variable d'environnement ECAPLAY_OUTPUT_DEVICE (plus d'informations ci-dessous).
-p
Lit les pistes dans la playlist (en mode boucle). Voir aussi les options -f, -l et -q.
-q
Ajoute de nouvelles pistes à la playlist. Tous les noms de fichiers donnés sur la ligne de commande seront ajoutés à la playlist. Il est possible d'ajouter de nouvelles pistes pendant qu'une autre instance d'ecaplay utilise la playlist. Voir aussi les options -f, -l et -p.
ECASIGNALVIEW

Ecasignalview est conçu pour surveiller l'amplitude du signal et les statistiques de crête. Il accepte les options suivantes:

entrée
La première option ne commençant pas par un ’-’ est interprétée comme une chaîne d'entrée. Il peut s'agir d'un périphérique ou d'un nom de fichier. Tous les formats pris en charge par libecasound sont acceptés. Par défaut ’/dev/dsp’.
sortie
De même que pour l'entrée, la deuxième option ne commençant pas par un ’-’ est interprétée comme une sortie. Par défaut ’null’.
-b:taille_buffer
Taille du tampon en images d'échantillons. Par défaut 128.
-c
Active le mode cumulatif. Les compteurs ne sont pas réinitialisés après l'actualisation. *obsolète*
-d
Active le mode de débogage.
-f:chaine_format
Spécifie le format audio par défaut. Voir ecasound(1) pour plus de détails.
-r:taux_ms
Spécifie le taux d'actualisation de l'écran en millisecondes.
-I
Utilise une échelle linéaire pour afficher l'amplitude des échantillons audio.
-L
Utilise une échelle logarithmique pour afficher l'amplitude des échantillons audio.
-G, -B, -M*, -r, -z
Les options Ecasound sont utilisées pour modifier le comportement du moteur, voir la page de manuel d'ecasound(1) pour plus de détails.
Lorsque ecasignalview est en cours d'exécution, les commandes clavier suivantes peuvent être utilisées pour contrôler l'opération (nécessite un support système pour le contrôle de l'interface de terminal UNIX) :
barre d'espace
Réinitialise les statistiques (pic max, amplitude moyenne et nombre d'échantillons écrêtés).
q ou Q ou Echap
Quitte ecasignalview.
Il est également possible de réinitialiser les compteurs de pic max et d'échantillons écrêtés en envoyant un signal SIGHUP au processus (par exemple, depuis une autre console : "killall -v -HUP ecasignalview").

Une documentation plus complète pour ecasignalview peut être trouvée dans le "Guide de l'utilisateur Ecasound" (voir ’’http://nosignal.fi/ecasound -> Documentation’’).

ENVIRONNEMENT

ECASOUND Chemin vers l'exécutable ecasound. Utilisé par de nombreux outils ecatools.

ECAPLAY_OUTPUT_DEVICE Périphérique qu'ecaplay doit utiliser pour la sortie audio. Même syntaxe que pour l'option "-o" d'ecaplay/ecasound.

FICHIERS

~/.ecasound/ecasoundrc Le fichier de ressources ecasound par défaut. Voir ecasoundrc(5) pour plus de détails.

~/.ecasound/ecaplay_queue Fichier utilisé pour stocker la playlist d'ecaplay (un morceau par ligne avec le chemin complet).
