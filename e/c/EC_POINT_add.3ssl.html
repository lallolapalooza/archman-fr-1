DESCRIPTIO

N

EC_POINT_add ajoute les deux points a et b et place le résultat dans r. De même, EC_POINT_dbl double le point a et place le résultat dans r. Dans les deux cas, il est valide que r soit l'un des points a ou b

.

EC_POINT_invert calcule l'inverse du point fourni a. Le résultat est placé dans a

.

La fonction EC_POINT_is_at_infinity teste si le point fourni est à l'infini ou

non.

EC_POINT_is_on_curve teste si le point fourni est sur la courbe ou

non.

EC_POINT_cmp compare les deux points fournis et teste s'ils sont égaux ou

non.

Les fonctions EC_POINT_make_affine et EC_POINTs_make_affine forcent la représentation interne du/des EC_POINT dans le système de coordonnées affine. Dans le cas de EC_POINTs_make_affine, la valeur num fournit le nombre de points dans le tableau points à forcer. Ces fonctions ont été dépréciées dans OpenSSL 3.0 et ne devraient plus être utilisées. Les versions modernes effectuent automatiquement cette conversion lorsque c'est

nécessaire.

EC_POINT_mul calcule la valeur générateur * n + q * m et stocke le résultat dans r. La valeur n peut être NULL, auquel cas le résultat est simplement q * m (multiplication de point variable). Alternativement, à la fois q et m peuvent être NULL, et n non-NULL, auquel cas le résultat est simplement générateur * n (multiplication de point fixe). Lors de l'exécution d'une seule multiplication de point fixe ou variable, l'implémentation sous-jacente utilise un algorithme à temps constant, lorsque le scalaire d'entrée (soit n ou m) est dans l'intervalle [0, ec_group_order)

.

Bien que dépréciée dans OpenSSL 3.0 et ne devant plus être utilisée, EC_POINTs_mul calcule la valeur générateur * n + q[0] * m[0] + ... + q[num-1] * m[num-1]. Comme pour EC_POINT_mul, la valeur n peut être NULL ou num peut être zéro. Lors de l'exécution d'une multiplication de point fixe (n est non-NULL et num vaut 0) ou d'une multiplication de point variable (n est NULL et num vaut 1), l'implémentation sous-jacente utilise un algorithme à temps constant, lorsque le scalaire d'entrée (soit n ou m[0]) est dans l'intervalle [0, ec_group_order). Les versions modernes devraient plutôt utiliser EC_POINT_mul(), combinée (si nécessaire) avec EC_POINT_add() dans de rares

circonstances.

La fonction EC_GROUP_precompute_mult stocke des multiples du générateur pour une multiplication de point plus rapide, tandis que EC_GROUP_have_precompute_mult teste si la précomputation a déjà été effectuée. Voir EC_GROUP_copy(3) pour des informations sur le générateur. La fonctionnalité de précomputation a été dépréciée dans OpenSSL 3.0. Les utilisateurs de EC_GROUP_precompute_mult() et EC_GROUP_have_precompute_mult() devraient passer aux courbes nom

mées pour lesquelles OpenSSL a des
tables de recherche intégrées.

VALEURS

RETOURNÉES

Les fonctions suivantes retournent 1 en cas de succès ou 0 en cas d'erreur : EC_POINT_add, EC_POINT_dbl, EC_POINT_invert, EC_POINT_make_affine, EC_POINTs_make_affine, EC_POINTs_make_affine, EC_POINT_mul, EC_POINTs_mul et EC_GROUP_precompute_mult

.

EC_POINT_is_at_infinity retourne 1 si le point est à l'infini, ou 0

sinon.

EC_POINT_is_on_curve retourne 1 si le point est sur la courbe, 0 s'il ne l'est pas, ou -1 en cas

d'erreur.

EC_POINT_cmp retourne 1 si les points ne sont pas égaux, 0 s'ils le sont, ou -1 en cas

d'erreur.

EC_GROUP_have_precompute_mult re

tourne 1 si une précomputation
a été effectuée, ou 0 sinon.
