NOM

ecl-config - Interrogation de configuration pour Embeddable Common Lisp

SYNTAXE

ecl-config [-cflags] [-libs] [-ldflags] [ LIBS]

DESCRIPTION

ecl-config renvoie via la sortie standard l'ensemble des indicateurs de compilation ou de liaison nécessaires pour construire des applications qui intègrent ecl.

OPTIONS

-cflags
Affiche les indicateurs requis pour compiler un fichier C/C++.
-libs
-ldflags
Renvoie les indicateurs de liaison requis pour construire une application C/C++ ou une bibliothèque partagée.
LIBS
Lorsqu'il est également utilisé avec -ldflags, ajoute la bibliothèque cmp (compilateur).

BOGUES

Probablement quelques-uns. Signalez-les !
