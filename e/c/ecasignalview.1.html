DESCRIPTIO

N

Ecatools sont des utilitaires simples en ligne de commande pour le traitement de fichiers audio. Chaque outil est conçu pour effectuer une opération spécifique. La plupart des outils prennent également en charge le traitement par

lots.

ECACONVER

T

Un outil pour convertir un ensemble de fichiers vers un format cible commun. Ce format cible est donné comme premier argument de la ligne de commande, et sa syntaxe est .ex

t.

ECAFIXD

C

Un outil simple en ligne de commande pour corriger le décalage

DC.

ECALENGT

H

Voir la page man séparée ecalength(1)

.

ECAMONITO

R

Ecamonitor est un programme utilitaire qui peut être utilisé pour surveiller une session ecasound active. Ecamonitor est capable d'afficher des informations sur la configuration de chaîne actuelle telles que la liste des entrées, des sorties, la position actuelle, les effets, l'état du moteur et de nombreuses autres

choses.

Par défaut, ecamonitor essaiera de se connecter à l'adresse IP4 "localhost", sur le port "2868". Une adresse différente peut être spécifiée au démarrage d'ecamonitor, par exemple "ecamonitor foo.mynetwork.com" ou "ecamonitor foo.mynetwork.com:

4500".

Pour permettre les connexions entrantes, ecasound doit être démarré avec l'option --daemon. Ecamonitor est implémenté en Python en utilisant l'API

NetECI.

ECANORMALIZ

E

Ecanormalize est un outil en ligne de commande pour normaliser les fichiers audio afin d'utiliser toute la résolution d'échantillonnage disponible. Ecanormalize détermine d'abord de combien le fichier d'entrée peut être amplifié sans écrêtage et s'il y a de la marge pour l'augmentation, un gain statique sera appliqué au

fichier.

ECAPLA

Y

Ecaplay est un outil en ligne de commande pour lire des fichiers audio. Ecaplay utilise le moteur libecasound et est donc capable de gérer tous les formats audio pris en charge par la

bibliothèque.

Les fichiers peuvent être sélectionnés pour la lecture soit en spécifiant les noms de fichiers sur la ligne de commande, soit en utilisant le mécanisme de liste de lecture. En mode liste de lecture, les fichiers peuvent être ajoutés à la liste de lecture en utilisant l'option -q . L'option -p peut ensuite être utilisée pour lire toutes les pistes de la liste de lecture. Ecaplay répétera les pistes de la liste de lecture jusqu'à ce qu'il soit explicitement arrêté (avec un double Ctrl-C). La liste de lecture peut être vidée avec -f et son contenu listé avec l'option

-l.

Si rien n'est spécifié autrement, ecaplay utilisera le périphérique de sortie audio spécifié dans ~/.ecasound/ecasoundrc pour la lecture. Un périphérique de sortie différent peut être sélectionné avec la variable d'environnement du shell ECAPLAY_OUTPUT_DEVICE ou avec l'option de ligne de commande -o:

output_device.

La lecture peut être arrêtée à tout moment avec Ctrl-C. Si plusieurs fichiers sont lus, le premier Ctrl-C arrêtera le fichier actuel et passera au suivant. Émettre Ctrl-C deux fois (en moins d'une seconde) fera qu'ecaplay se

terminera.

ECASIGNALVI
E
W

Ecasignalview est destiné à la surveillance de l'amplitude du signal et des statistiques de crête. Il accepte les options suivantes

:
entr
ée
La première option ne commençant pas par un ’-’ est interprétée comme une chaîne d'entrée. Cela peut être un périphérique ou un nom de fichier. Tous les formats pris en charge par libecasound sont acceptés. Par défaut
’/dev/dsp’.
sort
ie
De même que pour l'entrée, la deuxième option ne commençant pas par un ’-’ est interprétée comme sortie. Par défaut
’null’.
-b:
taille_buffer
Taille du buffer en trames d'échantillons. Par défaut
128.
-
c
Activer le mode cumulatif. Les compteurs ne sont pas réinitialisés après le rafraîchissement. *obsolèt
e*
-
d
Activer le mode
débogage.
-f:
chaine_format
Spécifier le format audio par défaut. Voir ecasound(1) pour les
détails.
-r:
rate_msec
Spécifier le taux de rafraîchissement de l'écran en
millisecondes.
-
I
Utiliser l'échelle linéaire pour afficher l'amplitude de l'échantillon
audio.
-
L
Utiliser l'échelle logarithmique pour afficher l'amplitude de l'échantillon
audio.
-G, -B, -M*, -r,
-z
Options d'ecasound utilisées pour modifier le comportement du moteur, voir la page man ecasound(1) pour les
détails.
Quand ecasignalview est en cours d'exécution, les commandes clavier suivantes peuvent être utilisées pour contrôler le fonctionnement (nécessite la prise en charge du système pour le contrôle de l'interface du terminal UNIX)
