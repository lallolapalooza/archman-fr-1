NOM

ecalength - imprime la longueur d'un fichier audio et d'autres informations

SYNTAXE

ecalength [-ahtsfmbcr] FICHIER1 [FICHIER2] [FICHIERN]

DESCRIPTION

C'est ecalength, quelques lignes de code pompeusement nommées ainsi parce qu'elles permettent de récupérer la longueur d'un fichier audio depuis la ligne de commande en utilisant le moteur d'ecasound.

Limitations :

- Avec des fichiers sans informations d'en-tête (fichiers bruts), ecalength ne fonctionnera correctement que si le fichier audio a un taux d'échantillonnage de 44100 Hz. (Géré avec l'option -a.)
- Ce n'est pas infaillible, le nourrir avec autre chose qu'un fichier audio provoquera l'affichage de choses peu ragoutantes. (Un peu mieux)
- Mille autres que je n'ai pas pensées.

OPTIONS

-h
Imprime ce message d'utilisation. (aide)
-a[:]bits,canaux,taux
Change le format supposé par défaut pour les données sans en-tête. (ajuster)
-t
Imprime la longueur totale de tous les fichiers traités. (total) (Ignoré si utilisé avec -s)
-s
Active le mode script : un type d'information par fichier par ligne. (script) (Par défaut, la longueur en secondes.)
-f
Avec -s, renverra la chaîne de format comme information, seul, il l'ajoutera à l'affichage principal. (format)
-b
Si -s et -f sont activés avec cette option, l'information imprimée sera la largeur de bits de l'échantillon. (bits)
-c
Si -s et -f sont activés avec cette option, l'information imprimée sera le nombre de canaux. (nombre de canaux)
-r
Si -s et -f sont activés avec cette option, l'information imprimée sera le taux d'échantillonnage. (taux)
-m
Imprimera le temps calculable par l'homme comme dans l'affichage principal, mais en mode batch. (minutes) (Uniquement avec -s)
