NOM

ecasoundrc - fichier de configuration rc d'ecasound

SYNOPSIS

{prefix}/share/ecasound/ecasoundrc (par exemple ’/usr/local/share/ecasound/ecasoundrc’) $HOME/.ecasound/ecasoundrc

DESCRIPTION

ecasoundrc est le fichier de configuration principal d'ecasound. Toute modification spécifique à l'utilisateur doit être faite dans $HOME/.ecasound/ecasoundrc, et non dans le fichier de ressources global. Ecasound permet également de désactiver la politique normale et de lire uniquement à partir d'un fichier de ressources spécifique (voir ecasound (1) et la documentation pour l' -R option).

Le format est assez simple. Une ligne consiste en une variable de configuration et sa valeur. La variable et la valeur sont séparées soit par ’=’ soit par ’ ’. Les lignes commençant par un "#" sont ignorées (lignes de commentaire).

VARIABLES

midi-device
Périphérique MIDI. Si le nom du périphérique est donné au format rawmidi,/dev/midi* , les pilotes OSS/Linux ou OSS/Lite sont utilisés. Le périphérique rawmidi,/dev/snd/midiCxDy ouvre un périphérique MIDI brut ALSA avec le numéro de carte ’x’ et le numéro de périphérique ’y’. Voir la page man ecasound (1) (l’option ’-Md) pour plus d’informations. Par défaut : rawmidi,/dev/midi.
default-output
Périphérique de sortie à utiliser par défaut. Si un chainsetup avec zéro sortie, mais avec une ou plusieurs entrées, est connecté, une sortie par défaut est ajoutée et toutes les chaînes y sont connectées. Si la valeur spéciale ’autodetect’ est spécifiée, ecasound essaiera de détecter automatiquement un périphérique approprié (JACK -> ALSA -> OSS -> rtnull). Par défaut : autodetect.
default-audio-format
Valeurs par défaut pour le format d'échantillonnage, le nombre de canaux, la fréquence d'échantillonnage et l'entrelacement des canaux. La syntaxe est la même que celle utilisée par l’option -f d’ecasound (voir ecasound (1)). Par défaut : s16_le,2,44100,i.
default-to-precise-sample-rates
S'il faut ignorer les différences de fréquence d'échantillonnage (et éventuellement éviter le rééchantillonnage). Affecte actuellement uniquement les périphériques OSS. Par défaut : false.
default-mix-mode
Si default-mix-mode est sum, le moteur mélangera plusieurs canaux en un canal de sortie en additionnant tous les canaux d'entrée. En mode avg, le mélange est effectué en prenant la moyenne de tous les canaux d'entrée. Le mode avg est sûr contre la saturation, tandis que sum est plus proche de la façon dont fonctionnent les tables de mixage analogiques. Par défaut : avg.
bmode-defaults-nonrt
Sélectionne les paramètres par défaut à utiliser avec le mode de mise en tampon ’nonrt’ (les autres modes sont ’rt’ et ’rtlowlatency). Les paramètres sont donnés sous forme de tuple de valeurs séparées par des virgules : 1) taille du tampon (nombre,-b), 2) priorité élevée (true/false,-r), 3) sched_priority (nombre,-r:X), 4) mise en tampon double (true/false,-z:db), 5) db-bufsize (nombre,-z:db,X), et 6) intbuf max (true/false,-z:intbuf). Par défaut : 1024,false,50,false,100000,true.
bmode-defaults-rt
Voir ’bmode-defaults-nonrt’. Par défaut : 1024,true,50,true,100000,true.
bmode-defaults-rtlowlatency
Voir ’bmode-defaults-nonrt’. Par défaut : 256,true,50,true,100000,false.
resource-directory
Répertoire pour les fichiers de configuration globaux d'ecasound. Par défaut : {prefix-dir}/share/ecasound. Note ! Les fichiers de ressources spécifiques à l'utilisateur peuvent être stockés dans ’$(HOME)/.ecasound/’. Par exemple, vous pouvez ajouter vos propres définitions de préréglages à ’$(HOME)/.ecasound/effect_presets’.
resource-file-genosc-envelopes
Fichier de configuration pour les oscillateurs génériques. Se trouve dans le répertoire de ressources. Par défaut : generic_oscillators.
resource-file-effect-presets
Fichier de configuration pour les préréglages d'effets. Se trouve dans le répertoire de ressources. Par défaut : effect_presets.
ladspa-plugin-directory
Répertoire contenant les plugins d'effets LADSPA. Par défaut : {prefix-dir}/lib/ladspa. Si la variable d'environnement LADSPA_PATH existe, les répertoires spécifiés y sont automatiquement recherchés pour les plugins. Note ! Pour correspondre à la syntaxe de la variable d'environnement LADSPA_PATH , ’ladspa-plugin-directory’ peut contenir plusieurs répertoires, séparés par des caractères ’:’.
ext-cmd-text-editor
Si ext-cmd-text-editor-use-getenv est false ou si "EDITOR" est nul, la valeur de ce champ est utilisée.
ext-cmd-text-editor-use-getenv
Ecasound doit-il essayer d'interroger la variable d'environnement "EDITOR". Par défaut : true.
ext-cmd-mp3-input
Commande pour démarrer l'entrée mp3. Ecasound s'attend à lire des échantillons audio stéréo signés, 16 bits, little-endian depuis son entrée standard. Ecasound interrogera les autres paramètres de format audio en analysant l'en-tête du fichier mp3. Avant l'exécution, %f est remplacé par le chemin du mp3 d'entrée. S'il existe, "%o" est remplacé par le décalage de départ en trames mp3. Les guillemets et l'échappement par barre oblique inverse peuvent être utilisés pour inclure des espaces dans les paramètres individuels. Par défaut, mpg123 est lancé.
ext-cmd-mp3-output
Commande pour démarrer la sortie mp3. Ecasound écrira des échantillons stéréo signés, 16 bits, little-endian vers la sortie standard. La fréquence d'échantillonnage est configurable. Avant l'exécution, %f est remplacé par le chemin du mp3 de sortie, %S par la fréquence d'échantillonnage en kHz, et %B par le débit d'encodage en kbps. Les guillemets et l'échappement par barre oblique inverse peuvent être utilisés pour inclure des espaces dans les paramètres individuels. Par défaut, Ecasound essaiera de lancer lame. Comme exception spéciale (ajoutée à Ecasound 2.7.0), si le programme de sortie est "lame" et que les options incluent "--big-endian", Ecasound le détectera et produira des échantillons big-endian.
ext-cmd-ogg-input
Commande pour démarrer l'entrée Ogg Vorbis. Ecasound s'attend à ce que les échantillons audio soient écrits vers la sortie standard. Il convient de noter qu'Ecasound n'est pas capable d'interroger les paramètres de format audio à partir des fichiers ogg, ceux-ci doivent donc être définis manuellement par l'utilisateur. Avant l'exécution, %f est remplacé par le chemin du ogg d'entrée. Les guillemets et l'échappement par barre oblique inverse peuvent être utilisés pour inclure des espaces dans les paramètres individuels. Par défaut, Ecasound essaiera de lancer (ogg123).
ext-cmd-ogg-output
Commande pour démarrer la sortie Ogg Vorbis. Ecasound écrira des échantillons au format little-endian vers la sortie standard. Les autres paramètres audio sont configurables. Avant l'exécution, %f est remplacé par le chemin du ogg de sortie, %c, %s et %b par les paramètres de format audio correspondants, et %B par le débit d'encodage en kbps. Les guillemets et l'échappement par barre oblique inverse peuvent être utilisés pour inclure des espaces dans les paramètres individuels. Par défaut, Ecasound essaiera de lancer (oggenc).
ext-cmd-mikmod
Commande pour démarrer l'entrée mikmod. Ecasound s'attend à ce que des échantillons audio stéréo signés, 16 bits, soient écrits vers la sortie standard. Avant l'exécution, %f est remplacé par le chemin du fichier, et %s par la fréquence d'échantillonnage sélectionnée. Les guillemets et l'échappement par barre oblique inverse peuvent être utilisés pour inclure des espaces dans les paramètres individuels. Par défaut, Ecasound essaiera de lancer mikmod.
ext-cmd-timidity
Commande pour démarrer l'entrée timidity++. Ecasound s'attend à ce que des échantillons audio stéréo signés, 16 bits, soient écrits vers la sortie standard. Avant l'exécution, %f est remplacé par le chemin du fichier, et %s par la fréquence d'échantillonnage. Les guillemets et l'échappement par barre oblique inverse peuvent être utilisés pour inclure des espaces dans les paramètres individuels. Par défaut, Ecasound essaiera de lancer timidity.
ext-cmd-flac-input
Commande pour démarrer l'entrée FLAC. Ecasound s'attend à ce que les échantillons audio soient écrits vers la sortie standard. Il convient de noter qu'Ecasound n'est pas capable d'interroger les paramètres de format audio à partir des fichiers FLAC,o ces doivent être configurés manuellement par l'utilisateur. Avant l'exécution, %f est remplacé par le chemin vers le fichier FLAC d'entrée. Des guillemets doubles et des échappements par barre oblique inverse peuvent être utilisés pour inclure des espaces blancs dans les paramètres individuels. Par défaut, Ecasound essaiera de lancer (flac).
ext-cmd-flac-output
Commande pour lancer la sortie FLAC. Ecasound écrira les échantillons sur la sortie standard . Tous les paramètres audio sont configurables. Avant l'exécution, %f est remplacé par le chemin vers le fichier FLAC de sortie, %c, %b et %s par les paramètres correspondants du format audio, %I par soit ’signed’ soit ’unsigned’, et %E par soit ’little’ soit ’big’. Des guillemets doubles et des échappements par barre oblique inverse peuvent être utilisés pour inclure des espaces blancs dans les paramètres individuels. Par défaut, Ecasound essaiera de lancer (flac).
ext-cmd-aac-input
Commande pour lancer l'entrée AAC. Ecasound s'attend à ce que des échantillons audio signés, 16 bits, stéréo et big-endian soient écrits sur la sortie standard. Il convient de noter que Ecasound n'est pas capable de interroger le taux d'échantillonnage d'entrée, donc cela doit être configuré manuellement par l'utilisateur. Avant l'exécution, %f est remplacé par le chemin vers le fichier AAC d'entrée. Attention ! FAAC doit être compilé avec le support MP4. Des guillemets doubles et des échappements par barre oblique inverse peuvent être utilisés pour inclure des espaces blancs dans les paramètres individuels. Par défaut, Ecasound essaiera de lancer faad.
ext-cmd-aac-output
Commande pour lancer la sortie AAC. Ecasound écrira des échantillons audio big-endian sur la sortie standard. Tous les autres paramètres audio sont configurables. Avant l'exécution, %f est remplacé par le chemin vers le fichier AAC de sortie, %c, %b et %s par les paramètres correspondants du format audio. Attention ! FAAC doit être compilé avec le support MP4. Des guillemets doubles et des échappements par barre oblique inverse peuvent être utilisés pour inclure des espaces blancs dans les paramètres individuels. Par défaut, Ecasound essaiera de lancer faac.
