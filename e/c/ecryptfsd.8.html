NOM

ecryptfsd - démon utilisateur de eCryptfs.

DESCRIPTION

ecryptfsd est un démon utilisateur qui s'exécute en tant que l'utilisateur effectuant les opérations sur les fichiers sous le point de montage eCryptfs. Il répond aux requêtes de clé publique du module noyau eCryptfs ; ces requêtes sont envoyées via /dev/ecryptfs lors des événements d'ouverture de fichier. ecryptfsd doit seulement être exécuté lorsqu'un montage est effectué avec un module de clé publique.

Le démon peut être démarré simplement en exécutant ecryptfsd. ecryptfsd s'enregistrera auprès du noyau comme étant le démon qui doit répondre à toutes les requêtes du système de fichiers eCryptfs effectuées dans le contexte de l'utilisateur qui exécute le démon.
