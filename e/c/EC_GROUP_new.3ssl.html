DESCRIPTION

Au sein de la bibliothèque, il existe deux formes de courbes elliptiques d'intérêt. La première forme est celle définie sur le corps premier Fp. Les éléments de Fp sont les entiers de 0 à p-1, où p est un nombre premier. Cela nous donne une équation de courbe elliptique révisée comme suit :

y^2 mod p = x^3 +ax + b mod p

La deuxième forme est celle définie sur un corps binaire F2^m où les éléments du corps sont des entiers d'une longueur d'au plus m bits. Pour cette forme, l'équation de la courbe elliptique est modifiée en :

y^2 + xy = x^3 + ax^2 + b (où b != 0)

Les opérations dans un corps binaire sont effectuées par rapport à un polynôme irréductible. Toutes ces courbes avec OpenSSL utilisent un trinôme ou un pentinôme pour ce paramètre.

Bien qu'obsolète depuis OpenSSL 3.0 et ne devant plus être utilisé, une nouvelle courbe peut être construite en appelant EC_GROUP_new(), en utilisant l'implémentation fournie par meth (voir EC_GFp_simple_method(3)) et associée au contexte de bibliothèque ctx (voir OSSL_LIB_CTX(3)). Le paramètre ctx peut être NULL, auquel cas le contexte de bibliothèque par défaut est utilisé. Il est alors nécessaire d'appeler EC_GROUP_set_curve() pour définir les paramètres de la courbe. Les applications devraient plutôt utiliser l'un des autres constructeurs EC_GROUP_new_*.

EC_GROUP_new_from_params() crée un groupe avec les paramètres spécifiés par params. Le contexte de bibliothèque libctx (voir OSSL_LIB_CTX(3)) et la chaîne de requête de propriété propq sont utilisés pour récupérer des algorithmes auprès des fournisseurs. params peut être soit une liste de paramètres explicites, soit un groupe nommé. Les valeurs pour ctx et propq peuvent être NULL. Les params utilisables sont décrits dans EVP_PKEY-EC(7).

EC_GROUP_to_params crée un tableau OSSL_PARAM avec les paramètres correspondants décrivant l'EC_GROUP donné. Les paramètres résultants peuvent contenir des paramètres décrivant une courbe nommée ou explicite selon l'EC_GROUP. Le contexte de bibliothèque libctx (voir OSSL_LIB_CTX(3)) et la chaîne de requête de propriété propq sont utilisés pour récupérer des algorithmes auprès des fournisseurs. bnctx est un BN_CTX préalloué optionnel (pour économiser le surcoût d'allocation et de libération de la structure dans une boucle). Les valeurs pour libctx, propq et bnctx peuvent être NULL. L'appelant est responsable de libérer le pointeur OSSL_PARAM retourné.

EC_GROUP_new_from_ecparameters() créera un groupe à partir des paramètres params spécifiés et EC_GROUP_new_from_ecpkparameters() créera un groupe à partir des paramètres PK paramsspécifiques.

EC_GROUP_set_curve() définit les paramètres de la courbe p, a et b. Pour une courbe sur Fp, p est le nombre premier du corps. Pour une courbe sur F2^m, p représente le polynôme irréductible - chaque bit représente un terme du polynôme. Par conséquent, il y aura soit trois, soit cinq bits à 1 selon que le polynôme est un trinôme ou un pentinôme. Dans les deux cas, a et b représentent les coefficients a et b de l'équation pertinente introduite ci-dessus.

EC_group_get_curve() obtient les paramètres de courbe définis précédemment.

EC_GROUP_set_curve_GFp() et EC_GROUP_set_curve_GF2m() sont des synonymes pour EC_GROUP_set_curve(). Elles sont définies uniquement pour la rétrocompatibilité et ne devraient pas être utilisées.

EC_GROUP_get_curve_GFp() et EC_GROUP_get_curve_GF2m() sont des synonymes pour EC_GROUP_get_curve(). Elles sont définies uniquement pour la rétrocompatibilité et ne devraient pas être utilisées.

Les fonctions EC_GROUP_new_curve_GFp() et EC_GROUP_new_curve_GF2m() sont des raccourcis pour appeler EC_GROUP_new() puis la fonction EC_GROUP_set_curve() . Une méthode d'implémentation par défaut appropriée sera utilisée.

Bien que la bibliothèque puisse être utilisée pour créer n'importe quelle courbe à l'aide des fonctions décrites ci-dessus, il existe également un certain nombre de courbes prédéfinies disponibles. Afin d'obtenir une liste de toutes les courbes prédéfinies, appelez la fonction EC_get_builtin_curves(). Le paramètre r doit être un tableau de structures EC_builtin_curve de taille nitems. La fonction remplira le tableau r avec des informations sur les courbes intégrées. Si nitems est inférieur au nombre total de courbes disponibles, les premières nitems courbes seront retournées. Sinon, le nombre total de courbes sera fourni. La valeur de retour est le nombre total de courbes disponibles (que ce nombre ait été rempli dans r ou non). Passer un rNULL, ou définir nitems à 0 ne fera rien d'autre que de retourner le nombre total de courbes disponibles. La structure EC_builtin_curve est définie comme suit :

typedef struct {
       int nid;
       const char *comment;
       } EC_builtin_curve;

Chaque élément EC_builtin_curve a un identifiant entier unique (nid), et une chaîne de commentaire lisible décrivant la courbe.

Afin de construire une courbe intégrée, utilisez la fonction EC_GROUP_new_by_curve_name_ex() et fournissez le nid de la courbe à construire, le contexte de bibliothèque associé à utiliser dans ctx (voir OSSL_LIB_CTX(3)) et toute chaîne de requête de propriété dans propq. La valeur ctx peut être NULL, auquel cas le contexte de bibliothèque par défaut est utilisé. La valeur propq peut également être NULL.

EC_GROUP_new_by_curve_name() est identique à EC_GROUP_new_by_curve_name_ex() sauf que le contexte de bibliothèque par défaut est toujours utilisé avec une chaîne de requête de propriété NULL.

EC_GROUP_free() libère la mémoire associée à l'EC_GROUP. Si group est NULL, rien n'est fait.

EC_GROUP_clear_free() est obsolète : elle était destinée à détruire toute donnée sensible contenue dans l'EC_GROUP puis libérer sa mémoire, mais comme toutes les données stockées dans l'EC_GROUP sont publiques de toute façon, cette fonction est inutile. Son utilisation peut être remplacée en toute sécurité par EC_GROUP_free(). Si group est NULL, rien n'est fait.

OSSL_EC_curve_nid2name() convertit un nid de courbe nid en le nom correspondant.

VALEURS DE RETOUR

Toutes les fonctions EC_GROUP_new* retournent un pointeur vers le groupe nouvellement construit, ou NULL en cas d'erreur.

EC_get_builtin_curves() retourne le nombre de courbes intégrées qui sont disponibles.

EC_GROUP_set_curve_GFp(), EC_GROUP_get_curve_GFp(), EC_GROUP_set_curve_GF2m(), EC_GROUP_get_curve_GF2m() retournent 1 en cas de succès ou 0 en cas d'erreur.

OSSL_EC_curve_nid2name() retourne une chaîne de caractères constante, ou NULL en cas d'erreur.
