DESCRIPTIO

N

EVP_EC_gen() génère une nouvelle paire de clés EC sur la courbe donnée

.

Toutes les fonctions décrites ci-dessous sont dépréciées. Les applications devraient plutôt utiliser EVP_EC_gen(), EVP_PKEY_Q_keygen(3), ou EVP_PKEY_keygen_init(3) et EVP_PKEY_keyg

en(3).

Un EC_KEY représente une clé publique et, éventuellement, la clé privée associée. Un nouvel EC_KEY sans courbe associée peut être construit en appelant EC_KEY_new_ex() et en spécifiant le contexte de bibliothèque associé dans ctx (voir OSSL_LIB_CTX(3)) et la chaîne de requête de propriété propq. Le paramètre ctx peut être NULL, auquel cas le contexte de bibliothèque par défaut est utilisé. Le compteur de références du nouvel EC_KEY créé est initialement défini à 1. Une courbe peut être associée à l'EC_KEY en appelant EC_KEY_set_gr

oup().

EC_KEY_new() est identique à EC_KEY_new_ex() sauf que le contexte de bibliothèque par défaut est toujours

utilisé.

Alternativement, un nouvel EC_KEY peut être construit en appelant EC_KEY_new_by_curve_name_ex() et en fournissant le nid de la courbe associée, le contexte de bibliothèque à utiliser ctx (voir OSSL_LIB_CTX(3)) et toute chaîne de requête de propriété propq. Le paramètre ctx peut être NULL, auquel cas le contexte de bibliothèque par défaut est utilisé. La valeur propq peut également être NULL. Voir EC_GROUP_new(3) pour une description des noms de courbes. Cette fonction enveloppe simplement les appels à EC_KEY_new_ex() et EC_GROUP_new_by_curve

_name_ex().

EC_KEY_new_by_curve_name() est identique à EC_KEY_new_by_curve_name_ex() sauf que le contexte de bibliothèque par défaut est toujours utilisé et que la chaîne de requête de propriété est

NULL.

Appeler EC_KEY_free() décrémente le compteur de références de l'objet EC_KEY et, s'il est descendu à zéro, libère la mémoire qui lui est associée. Si key est NULL, rien n'est

fait.

EC_KEY_copy() copie le contenu de l'EC_KEY dans src vers dest

.

EC_KEY_dup() crée un nouvel objet EC_KEY et copie ec_key à

l'intérieur.

EC_KEY_up_ref() incrémente le compteur de références associé à l'objet

EC_KEY.

EC_KEY_get0_engine() renvoie un identifiant vers le ENGINE qui a été défini pour cet objet

EC_KEY.

EC_KEY_generate_key() génère une nouvelle clé publique et privée pour l'objet eckey fourni. eckey doit avoir un objet EC_GROUP associé avant d'appeler cette fonction. La clé privée est un entier aléatoire (0 < priv_key < ordre, où ordre est l'ordre de l'objet EC_GROUP). La clé publique est un EC_POINT sur la courbe, calculé en multipliant le générateur de la courbe par la clé

privée.

EC_KEY_check_key() effectue diverses vérifications de cohérence sur l'objet EC_KEY pour confirmer qu'il est

valide.

EC_KEY_set_public_key_affine_coordinates() définit la clé publique pour key sur la base de ses coordonnées affines ; c'est-à-dire qu'il construit un objet EC_POINT basé sur les valeurs x et y fournies et définit la clé publique comme étant cet EC_POINT. Il effectue également certaines vérifications de cohérence sur la clé pour confirmer qu'elle est

valide.

Les fonctions EC_KEY_get0_group(), EC_KEY_set_group(), EC_KEY_get0_private_key(), EC_KEY_set_private_key(), EC_KEY_get0_public_key() et EC_KEY_set_public_key() obtiennent et définissent respectivement l'objet EC_GROUP, la clé privée et la clé publique EC_POINT pour key. La fonction EC_KEY_set_private_key() accepte NULL comme argument priv_key pour effacer de manière sécurisée le composant de clé privée de

l'EC_KEY.

Les fonctions EC_KEY_get_conv_form() et EC_KEY_set_conv_form() obtiennent et définissent le point_conversion_form pour key. Pour une description des point_conversion_forms, voir EC_POINT_ne

w(3).

EC_KEY_set_flags() définit les drapeaux dans le paramètre flags sur l'objet EC_KEY. Les drapeaux déjà définis restent définis. Les drapeaux actuellement définis sont EC_FLAG_NON_FIPS_ALLOW et EC_FLAG_FIPS_CHECKED. De plus, il existe le drapeau EC_FLAG_COFACTOR_ECDH qui est spécifique à ECDH. EC_KEY_get_flags() renvoie les drapeaux actuellement définis pour cet EC_KEY. EC_KEY_clear_flags() efface les drapeaux indiqués par le paramètre flags ; tous les autres drapeaux restent dans leur état

existant.

EC_KEY_set_asn1_flag() définit l'asn1_flag sur l'objet EC_GROUP sous-jacent (s'il est défini). Se référer à EC_GROUP_copy(3) pour plus d'informations sur

l'asn1_flag.

EC_KEY_decoded_from_explicit_params() renvoie 1 si le groupe de key a été décodé à partir de données avec des paramètres de groupe encodés explicitement, -1 si key est NULL ou si les paramètres de groupe sont manquants, et 0

sinon.

EC_KEY_precompute_mult() stocke des multiples du générateur EC_GROUP sous-jacent pour une multiplication de point plus rapide. Voir aussi EC_POINT_add(3). Les versions modernes devraient plutôt utiliser les courbes nommées pour lesquelles OpenSSL a des tables de recherche

intégrées.

EC_KEY_oct2key() et EC_KEY_key2buf() sont identiques aux fonctions EC_POINT_oct2point() et EC_POINT_point2buf() sauf qu'elles utilisent le EC_POINT de clé publique dans eckey

.

EC_KEY_oct2priv() et EC_KEY_priv2oct() convertissent entre le composant de clé privée de eckey et sa forme octet. La forme octet se compose des octets de contenu de la OCTET STRING privateKey dans une structure ECPrivateKey ASN.

1.

La fonction EC_KEY_priv2oct() doit recevoir un tampon suffisamment long pour stocker la octet. La valeur de retour fournit le nombre d'octets stockés. Appeler la fonction avec un tampon NULL n'effectue pas la conversion mais renvoie simplement la longueur de tampon

requise.

La fonction EC_KEY_priv2buf() alloue un tampon de longueur appropriée et y écrit un EC_KEY au format octet. Le tampon alloué est écrit dans *pbuf et sa longueur est renvoyée. L'appelant doit libérer le tampon alloué en appelant OPENSSL_free(). Étant donné que la valeur du tampon alloué est écrite dans *pbuf, le pbuf paramètre NE DOIT PAS être NULL

.

EC_KEY_priv2buf() convertit une clé p

rivée EC_KEY en un
tampon alloué.

VALEURS DE

RETOUR

EC_KEY_new_ex(), EC_KEY_new(), EC_KEY_new_by_curve_name_ex(), EC_KEY_new_by_curve_name() et EC_KEY_dup() renvoient un pointeur vers l'objet EC_KEY nouvellement créé, ou NULL en cas

d'erreur.

EC_KEY_get_flags() renvoie les drapeaux associés à l'objet EC_KEY sous forme

d'entier.

EC_KEY_copy() renvoie un pointeur vers la clé de destination, ou NULL en cas

d'erreur.

EC_KEY_get0_engine() renvoie un pointeur vers un ENGINE, ou NULL s'il n'a pas été

défini.

EC_KEY_up_ref(), EC_KEY_set_group(), EC_KEY_set_public_key(), EC_KEY_precompute_mult(), EC_KEY_generate_key(), EC_KEY_check_key(), EC_KEY_set_public_key_affine_coordinates(), EC_KEY_oct2key() et EC_KEY_oct2priv() renvoient 1 en cas de succès ou 0 en cas

d'erreur.

EC_KEY_set_private_key() renvoie 1 en cas de succès ou 0 en cas d'erreur, sauf lorsque l'argument priv_key est NULL ; dans ce cas, il renvoie 0, pour compatibilité avec les anciennes versions, et cela ne doit pas être considéré comme une

erreur.

EC_KEY_get0_group() renvoie le EC_GROUP associé à

l'EC_KEY.

EC_KEY_get0_private_key() renvoie la clé privée associée à

l'EC_KEY.

EC_KEY_get_conv_form() renvoie le point_conversion_form pour

l'EC_KEY.

EC_KEY_key2buf(), EC_KEY_priv2oct() et EC_KEY_priv2buf() renvoient la longu

eur du tampon ou
0 en cas d'erreur.
