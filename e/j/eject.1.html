EJECT(1) Commandes utilisateur EJECT(1)

NOM

eject - éjecter un support amovible

eject [options] périphérique|point_de_montage

DESCRIPTION

eject permet d'éjecter des supports amovibles (généralement un CD-ROM, une disquette, une bande, un JAZ, un ZIP ou un disque USB) sous contrôle logiciel. La commande peut également contrôler certains chargeurs multi-disques de CD-ROM, la fonction d'éjection automatique prise en charge par certains périphériques, et fermer le plateau de certains lecteurs de CD-ROM.

Le périphérique correspondant à périphérique ou point_de_montage est éjecté. Si aucun nom n'est spécifié, le nom par défaut /dev/cdrom est utilisé. Le périphérique peut être désigné par nom de périphérique (par ex. 'sda'), chemin du périphérique (par ex. '/dev/sda'), UUID=uuid ou LABEL=label .

Il existe quatre méthodes différentes d'éjection, selon que le périphérique est un CD-ROM, un périphérique SCSI, une disquette amovible ou une bande. Par défaut, eject essaie les quatre méthodes dans l'ordre jusqu'à ce qu'une réussisse.

Si une partition de périphérique est spécifiée, le périphérique entier est utilisé.

Si le périphérique ou une partition du périphérique est actuellement monté, il est démonté avant l'éjection. L'éjection est traitée sur le descripteur de fichier de périphérique de bloc ouvert en exclusivité si --no-unmount ou --force ne sont pas spécifiés.

OPTIONS

-a, --auto on|off

Cette option contrôle le mode d'éjection automatique, pris en charge par certains périphériques. Lorsqu'il est activé, le lecteur éjecte automatiquement le support lorsque le périphérique est fermé.

-c, --changerslot emplacement

Avec cette option, un emplacement CD peut être sélectionné dans un chargeur de CD-ROM ATAPI/IDE. Le lecteur de CD-ROM ne doit pas être en cours d'utilisation (CD de données monté ou CD audio en cours de lecture) pour qu'une demande de changement fonctionne. Veuillez également noter que le premier emplacement du chargeur est désigné par 0, et non 1.

-d, --default

Affiche le nom du périphérique par défaut.

-F, --force

Force l'éjection, ne vérifie pas le type de périphérique, n'ouvre pas le périphérique avec un verrou exclusif. Le résultat réussi peut être un faux positif sur des périphériques non amovibles à chaud.

-f, --floppy

Cette option spécifie que le lecteur doit être éjecté à l'aide d'une commande d'éjection de disquette amovible.

-i, --manualeject on|off

Cette option contrôle le verrouillage du bouton d'éjection matériel. Lorsqu'il est activé, le lecteur ne sera pas éjecté lorsque le bouton est pressé. C'est utile lorsque vous transportez un ordinateur portable dans un sac ou une housse et que vous ne voulez pas qu'il s'éjecte si le bouton est pressé par inadvertance.

-M, --no-partitions-unmount

L'option indique à eject de ne pas essayer de démonter les autres partitions sur les périphériques partitionnés. Si une autre partition est toujours montée, le programme n'essaiera pas d'éjecter le support. Il essaiera de démonter uniquement le périphérique ou le point de montage donné sur la ligne de commande.

-m, --no-unmount

L'option indique à eject de ne pas essayer de démonter du tout. Si cette option n'est pas spécifiée, eject ouvre le périphérique avec l'indicateur O_EXCL pour s'assurer que le périphérique n'est pas utilisé (depuis la v2.35).

-n, --noop

Avec cette option, le périphérique sélectionné est affiché mais aucune action n'est effectuée.

-p, --proc

Cette option vous permet d'utiliser /proc/mounts au lieu de /etc/mtab. Elle passe également l'option -n à umount(8).

-q, --tape

Cette option spécifie que le lecteur doit être éjecté à l'aide d'une commande hors ligne de lecteur de bande.

-r, --cdrom

Cette option spécifie que le lecteur doit être éjecté à l'aide d'une commande d'éjection CDROM.

-s, --scsi

Cette option spécifie que le lecteur doit être éjecté à l'aide de commandes SCSI.

-T, --traytoggle

Avec cette option, le lecteur reçoit une commande de fermeture du plateau CD-ROM s'il est ouvert, et une commande d'éjection du plateau CD-ROM s'il est fermé. Tous les périphériques ne prennent pas en charge cette commande, car elle utilise la commande de fermeture du plateau CD-ROM mentionnée ci-dessus.

-t, --trayclose

Avec cette option, le lecteur reçoit une commande de fermeture du plateau CD-ROM. Tous les périphériques ne prennent pas en charge cette commande.

-v, --verbose

Exécution en mode verbeux ; plus d'informations sont affichées sur ce que fait la commande.

-X, --listspeed

Avec cette option, le lecteur de CD-ROM sera interrogé pour détecter les vitesses disponibles. La sortie est une liste de vitesses qui peut être utilisée comme argument de l'option -x . Cela ne fonctionne qu'avec Linux 2.6.13 ou supérieur ; sur les versions précédentes, seule la vitesse maximale sera signalée. Notez également que certains lecteurs peuvent ne pas signaler correctement la vitesse et que cette option ne fonctionne donc pas avec eux.

-x, --cdspeed vitesse

Avec cette option, le lecteur reçoit une commande de sélection de vitesse CD-ROM. L'argument vitesse est un nombre indiquant la vitesse souhaitée (par ex. 8 pour une vitesse 8X), ou 0 pour le débit de données maximal. Tous les périphériques ne prennent pas en charge cette commande et vous ne pouvez spécifier que des vitesses que le lecteur est capable de fournir. Chaque fois que le support est changé, cette option est réinitialisée. Cette option peut être utilisée seule, ou avec les options -t et -c .

-h, --help

Affiche le texte d'aide et quitte.

-V, --version

Affiche la version et quitte.

CODE DE RETOUR

Renvoie 0 si l'opération a réussi, 1 si l'opération a échoué ou si la syntaxe de la commande n'était pas valide.

REMARQUES

eject ne fonctionne qu'avec les périphériques qui prennent en charge une ou plusieurs des quatre méthodes d'éjection. Cela inclut la plupart des lecteurs de CD-ROM (IDE, SCSI et propriétaires), certains lecteurs de bande SCSI, les lecteurs JAZ, les lecteurs ZIP (versions port parallèle, SCSI et IDE) et les disquettes amovibles LS120. Des utilisateurs ont également signalé un succès avec des lecteurs de disquettes sur les systèmes Sun SPARC et Apple Macintosh. Si eject ne fonctionne pas, il s'agit très probablement d'une limitation du pilote du noyau pour le périphérique, et non du programme eject lui-même.

Les options -r, -s, -fet -q permettent de contrôler les méthodes utilisées pour éjecter. Plus d'une méthode peut être spécifiée. Si aucune de ces options n'est spécifiée, les quatre sont essayées (ce qui fonctionne bien dans la plupart des cas).

eject peut ne pas toujours être en mesure de déterminer si le périphérique est monté (par ex. s'il a plusieurs noms). Si le nom du périphérique est un lien symbolique, eject suivra le lien et utilisera le périphérique auquel il pointe.

Si eject détermine que le périphérique peut avoir plusieurs partitions, il essaiera de démonter toutes les partitions montées du périphérique avant l'éjection (voir aussi --no-partitions-unmount). Si un démontage échoue, le programme n'essaiera pas d'éjecter le support.

Vous pouvez éjecter un CD audio. Certains lecteurs de CD-ROM refuseront d'ouvrir le plateau si le lecteur est vide. Certains périphériques ne prennent pas en charge la commande de fermeture du plateau.

Si la fonction d'éjection automatique est activée, le lecteur sera toujours éjecté après l'exécution de cette commande. Tous les pilotes CD-ROM du noyau Linux ne prennent pas en charge le mode d'éjection automatique. Il n'existe aucun moyen de connaître l'état du mode d'éjection automatique.

Vous avez besoin des privilèges appropriés pour accéder aux fichiers de périphérique. L'exécution en tant que root est requise pour éjecter certains périphériques (par ex. les périphériques SCSI).
