NOM

egk-tool - affiche des informations sur la carte santé électronique allemande (elektronische Gesundheitskarte, eGK)

SYNTAXE

egk-tool [OPTIONS]

DESCRIPTION

L'utilitaire egk-tool est utilisé pour afficher les informations stockées sur la carte santé électronique allemande (elektronische Gesundheitskarte, eGK).

OPTIONS

--help, -h

Affiche l'aide et quitte.

--version, -V

Affiche la version et quitte.

--reader arg, -r arg

Numéro du lecteur à utiliser. Par défaut, le premier lecteur avec une carte présente est utilisé. Si arg est un ATR, le lecteur avec une carte correspondante sera choisi.

--verbose, -v

Permet à egk-tool d'être plus verbeux. Spécifiez ce drapeau plusieurs fois pour être plus verbeux.

'Gesundheitsanwendung', Application de soins de santé (HCA)

--pd

Affiche les 'Persönliche Versichertendaten' (XML).

--vd

Affiche les 'Allgemeine Versichertendaten' (XML).

--gvd

Affiche les 'Geschützte Versichertendaten' (XML).

--vsd-status

Affiche le 'Versichertenstammdaten-Status'.
