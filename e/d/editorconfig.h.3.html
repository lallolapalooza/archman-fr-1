h)

Analyse les fichiers editorconfig correspondant au chemin de fichier donné par full_filename, et les informations associées sont entrées et sorties dans h. Un exemple est disponible dans src/bin/main.c du code source d'EditorConfig C

Core.

Paramètre

s
full_filename Le chemin complet d'un fichier qui est édité par l'éditeur pour lequel le résultat d'analyse est destiné.
h Le editorconfig_handle à utiliser et renvoyer depuis cette fonction (y compris le résultat d'analyse). Le editorconfig_handle doit être créé par editorconfig_handl
e_init().

retour
0 Tout est en ordre.
Entier positif Une erreur d'analyse s'est produite. La valeur de retour sera le numéro de ligne de l'erreur d'analyse. err_file obtenu de h en appelant editorconfig_handle_get_err_file() sera également rempli avec le chemin du fichier qui a causé l'erreur d'analyse.
Entier négatif Une erreur s'est produite. Voir ci-dessous la raison de l'erreur pour chaque valeur de retour.
EDITORCONFIG_PARSE_NOT_FULL_PATH full_filename n'est pas un chemin complet.
