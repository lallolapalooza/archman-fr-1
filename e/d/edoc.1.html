edoc(1) Commandes utilisateur edoc(1)

NOM

edoc - Générer de la documentation au format HTML ou des fragments de documentation EEP-48

DESCRIPTION

Ce programme est un point d'entrée en ligne de commande pour les fonctions edoc:application/2 et edoc:files/2. Il permet également de générer uniquement les fragments de documentation EEP-48 (en utilisant l'option -chunks) au lieu de la documentation HTML complète.

edoc -app <app> [-chunks]

EDoc est appelé via edoc:application/2, avec l'ensemble d'options par défaut. Si -chunks est donné, seuls les fragments de documentation seront générés, pas la documentation HTML complète.

Exécutez le script sans arguments pour obtenir la liste complète des options.

edoc -files <fichier_erl>... [-chunks]

EDoc est appelé via edoc:files/2, avec l'ensemble d'options par défaut. Si -chunks est donné, seuls les fragments de documentation seront générés, pas la documentation HTML complète.

Exécutez le script sans arguments pour obtenir la liste complète des options.
