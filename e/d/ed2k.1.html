NOM

ed2k - analyseur de liens eD2k pour aMule

SYNTAXE

ed2k [-c <chemin>] [-t <num>] [-e] [-l] <lien-eD2k>

ed2k [-h]

ed2k [-v]

DESCRIPTION

Envoie le <lien-eD2k> donné à aMule, c'est-à-dire l'écrit dans le fichier ~/.aMule/ED2KLinks, qui sera vérifié par aMule chaque seconde pour les liens.

[ -c <chemin>, --config-dir=<chemin> ]
Lit la configuration depuis <chemin> au lieu du répertoire personnel.
[ -t, --category=<num> ]
Définit la catégorie pour les liens eD2k transmis à <num>.
[ -e, --emulecollection ]
Charge tous les liens trouvés dans le fichier emulecollection donné comme <lien-ed2k>.
[ -l, --list ]
Liste tous les liens trouvés dans le fichier emulecollection donné comme <lien-ed2k>.
[ -h, --help ]
Affiche une brève description de l'utilisation.
[ -v, --version ]
Affiche le numéro de version actuel.
[ lien-eD2k ]
Ajoute un lien eD2k au cœur.

Le lien eD2k à ajouter peut être :

  • un lien de fichier (ed2k://|file|...), il sera ajouté à la file d'attente de téléchargement ;
  • un lien de serveur (ed2k://|server|...), il sera ajouté à la liste des serveurs ;
  • un lien de liste de serveurs, auquel cas tous les serveurs de la liste seront ajoutés à la liste des serveurs ;
  • un lien magnet ;
  • un fichier emulecollection.

L'ordre dans lequel vous donnez les paramètres est important. Vous pouvez donner plus d'un lien, et chaque lien peut avoir ses propres paramètres. Par exemple ed2k <lien1> -t2 <lien2> téléchargera <lien1> dans la catégorie standard et <lien2> dans la catégorie 2.

FICHIERS
