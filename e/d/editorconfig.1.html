NOM

editorconfig - Commande EditorConfig

EMPLOI de l'outil en ligne de commande editorconfig

Usage : editorconfig [OPTIONS] FICHIER1 [FICHIER2 FICHIER3 ...]

Le CHEMIN_FICHIER peut être un tiret (-) si vous voulez que le(s) chemin(s) soit(ent) lu(s) depuis stdin. Le tiret peut aussi être spécifié avec d'autres noms de fichiers. De cette façon, les chemins de fichiers depuis stdin et les chemins spécifiés sur la ligne de commande seront utilisés. Si plus d'un chemin est spécifié sur la ligne de commande, ou si les chemins sont lus depuis stdin (même si un seul chemin est lu depuis stdin), le format de sortie sera au format INI, au lieu des simples lignes "clé=valeur".

-f Spécifier un nom de fichier de configuration autre que ".editorconfig".

-b Spécifier la version (utilisé par les développeurs pour tester la compatibilité).

-h OU --help Afficher ce message d'aide.

--version Afficher les informations de version.
