void editorconfig_handle_set_version (const editorconfig_handle h, int major, int minor, int patch)

Définir les champs de editorconfig_handle.h(3) — EditorConfig

NAME

editorconfig_handle - gère les informations d'un objet editorconfig_handle

SYNOPSIS

#include <editorconfig.h>

void
editorconfig_handle_set_version (editorconfig_handle *h, int major,
int minor, int patch);

Detailed Description

Cette fonction définit les champs de version d'un objet editorconfig_handle.

Paramètres

h L'objet editorconfig_handle dont les champs de version doivent être définis.
major Si non inférieur à 0, le champ de version majeure sera défini sur major. Si ce paramètre est inférieur à 0, le champ de version majeure de l'objet editorconfig_handle restera inchangé.
minor Si non inférieur à 0, le champ de version mineure sera défini sur minor. Si ce paramètre est inférieur à 0, le champ de version mineure de l'objet editorconfig_handle restera inchangé.
patch Si non inférieur à 0, le champ de version de correction sera défini sur patch. Si ce paramètre est inférieur à 0, le champ de version de correction de l'objet editorconfig_handle restera inchangé.

Retourne

Aucun.
