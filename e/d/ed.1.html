ED(1) Commandes utilisateur ED(1)

NOM

ed - éditeur de texte orienté ligne

SYNTAXE

ed [options] [[+ligne] fichier]

DESCRIPTION

GNU ed est un éditeur de texte orienté ligne. Il est utilisé pour créer, afficher, modifier et manipuler autrement des fichiers texte, à la fois interactivement et via des scripts shell. Une version restreinte de ed, red, ne peut éditer que des fichiers dans le répertoire courant et ne peut pas exécuter des commandes shell. Ed est l'éditeur de texte « standard » dans le sens où c'est l'éditeur original pour Unix, et donc largement disponible. Pour la plupart des usages, cependant, il est supplanté par des éditeurs plein écran.

Le nom de fichier peut être précédé de '+ligne', '+/RE', ou '+?RE' pour définir la ligne courante au numéro de ligne spécifié ou à la première ou dernière ligne correspondant à l'expression régulière 'RE'.

Démarre l'édition en lisant 'fichier' s'il est donné. Si 'fichier' commence par un '!', lit la sortie de la commande shell.

La variable d'environnement LINES peut être utilisée pour définir la taille initiale de la fenêtre.

OPTIONS

-h, --help
affiche cette aide et quitte
-V, --version
affiche les informations de version et quitte
-E, --extended-regexp
utilise les expressions régulières étendues
-G, --traditional
exécute en mode compatibilité
-l, --loose-exit-status
quitte avec le statut 0 même si une commande échoue
-p, --prompt=CHAINE
utilise CHAINE comme invite interactive
-q, --quiet, --silent
supprime les diagnostics écrits sur stderr
-r, --restricted
exécute en mode restreint
-s, --script
supprime les comptages d'octets et l'invite '!'
-v, --verbose
soyez verbeux ; équivalent à la commande 'H'
--strip-trailing-cr
supprime les retours chariot en fin de lignes de texte
--unsafe-names
autorise les caractères de contrôle dans les noms de fichiers

CODE DE SORTIE

0 pour une sortie normale, 1 pour des problèmes d'environnement (options de ligne de commande invalides, mémoire épuisée, commande échouée, etc.), 2 pour des problèmes avec le fichier d'entrée (fichier non trouvé, tampon modifié, erreurs d'E/S), 3 pour une erreur de cohérence interne (par exemple, bug) qui a provoqué la panique de ed.
