Nom

libedit - bibliothèque d'édition de ligne de commande

SYNOPSIS

#include <editline/readline.h>

DESCRIPTION

La bibliothèque libedit fournit des fonctionnalités d'édition de ligne de commande similaires à celles de la bibliothèque readline du projet GNU. Elle permet aux applications interactives de permettre aux utilisateurs de taper et de modifier des lignes de texte de manière efficace. La bibliothèque prend en charge deux modes d'édition principaux : Vi et Emacs.

Si la sortie standard n'est pas connectée à un périphérique terminal ou si el_set(3) a été utilisé pour définir EL_EDITMODE sur 0, toutes les liaisons de caractères d'entrée sont désactivées et tous les caractères tapés sont ajoutés au tampon d'édition. Dans ce cas, le tampon d'édition est renvoyé au programme après qu'un caractère de nouvelle ligne ou de retour chariot a été tapé, ou après le premier caractère tapé si el_set(3) a été utilisé pour définir EL_UNBUFFERED sur une valeur non nulle.

Commandes de l'éditeur

La plupart des commandes de l'éditeur acceptent un argument facultatif. L'argument est entré en préfixant la commande de l'éditeur avec un ou plusieurs des commandes de l'éditeur ed-argument-digit, ed-digit, em-universal-argument, ou vi-zero. Lorsqu'un argument n'est pas fourni, il prend par défaut la valeur 1. Pour la plupart des commandes de l'éditeur, l'effet d'un argument est d'exécuter la commande répétitivement autant de fois.

Lorsqu'on parle d'une chaîne de caractères d'un caractère gauche à un caractère droit, le caractère gauche est inclus dans la chaîne, tandis que le caractère droit n'est pas inclus.

Si une commande de l'éditeur provoque une erreur, le caractère d'entrée est rejeté, aucune action n'est effectuée et la cloche du terminal est activée. En cas d'erreur non fatale, la cloche du terminal est également activée, mais la commande de l'éditeur prend effet de toute façon.

Dans la liste suivante, les liaisons de touches par défaut sont indiquées après chaque commande de l'éditeur.

ed-argument-digit (commande vi : 1 à 9 ; emacs : Meta-0 à Meta-9)
Si en mode de saisie d'argument, ajoute le chiffre d'entrée à l'argument en cours de lecture. Sinon, passe en mode de saisie d'argument et utilise le chiffre d'entrée comme chiffre le plus significatif de l'argument. C'est une erreur si le caractère d'entrée n'est pas un chiffre ou si l'argument existant est déjà supérieur à un million.
ed-clear-screen (commande vi : Ctrl-L ; emacs : Ctrl-L, Ctrl-Meta-L)
Efface l'écran et affiche le tampon d'édition en haut. Ignore tout argument.
ed-command (commande vi : « : » ; emacs : Meta-X, Meta-x)
Lit une ligne depuis le terminal en contournant la fonctionnalité normale d'édition de ligne et exécute cette ligne comme une commande intégrée editrc(5). Si en mode de commande vi, repasse également en mode d'insertion vi. Ignore tout argument.
ed-delete-next-char (commande vi : x)
Supprime le caractère à la position du curseur. Avec un argument, supprime ce nombre de caractères. En mode emacs, c'est une erreur si le curseur est à la fin du tampon d'édition. En mode vi, le dernier caractère du tampon d'édition est supprimé dans ce cas, et c'est une erreur si le tampon est vide.
ed-delete-prev-char (commande vi : X, Ctrl-H, BS, Ctrl-?, DEL)
Supprime le caractère à gauche de la position du curseur. Avec un argument, supprime ce nombre de caractères. C'est une erreur si le curseur est au début du tampon d'édition.
ed-delete-prev-word (vi : Ctrl-W ; emacs : Ctrl-Meta-H, Ctrl-Meta-?)
Se déplace vers la gauche jusqu'au début le plus proche d'un mot, supprime la chaîne de cette position jusqu'au curseur et la sauvegarde dans le tampon de coupure. Avec un argument, supprime ce nombre de mots. C'est une erreur si le curseur est au début du tampon d'édition.
ed-digit (emacs : 0 à 9)
Si en mode de saisie d'argument, ajoute le chiffre d'entrée à l'argument en cours de lecture. Sinon, appelle ed-insert. C'est une erreur si le caractère d'entrée n'est pas un chiffre ou si l'argument existant est déjà supérieur à un million.
ed-end-of-file (non lié par défaut)
Rejette le tampon d'édition et indique la fin de fichier au programme. Ignore tout argument.
ed-ignore (divers)
Rejette le caractère d'entrée et ne fait rien.
ed-insert (insertion vi : presque tous ; emacs : caractères imprimables)
En mode d'insertion, insère le caractère d'entrée à gauche de la position du curseur. En mode de remplacement, écrase le caractère à la position du curseur et déplace le curseur d'une position vers la droite. Accepte un argument pour faire cela de manière répétée. I
est une erreur si le caractère d'entrée est le caractère NUL (Ctrl-@). L'échec de l'agrandissement du tampon d'édition entraîne également une erreur.
ed-kill-line (commande vi : D, Ctrl-K ; emacs : Ctrl-K, Ctrl-U)
Supprime la chaîne de la position du curseur jusqu'à la fin de la ligne et l'enregistre dans le tampon de coupe. Ignore tout argument.
ed-move-to-beg (commande vi : ^, Ctrl-A ; emacs : Ctrl-A)
En mode vi, déplace le curseur vers le premier caractère non blanc dans le tampon d'édition. En mode emacs, déplace le curseur vers le début du tampon d'édition. Ignore tout argument. Peut être utilisé comme commande de déplacement après vi_change_meta, vi_delete_meta, ou vi_yank.
ed-move-to-end (commande vi : $, Ctrl-E ; emacs : Ctrl-E)
Déplace le curseur vers la fin du tampon d'édition. Ignore tout argument. Peut être utilisé comme commande de déplacement après vi_change_meta, vi_delete_meta, ou vi_yank.
ed-newline (tous modes : Ctrl-J, LF, Ctrl-M, CR)
Ajoute un caractère de nouvelle ligne au tampon d'édition et renvoie le tampon d'édition au programme. Ignore tout argument.
ed-next-char (commande vi : Espace, l ; emacs : Ctrl-F)
Déplace le curseur d'une position vers la droite. Avec un argument, se déplace du nombre de caractères spécifié. Peut être utilisé comme commande de déplacement après vi_change_meta, vi_delete_meta, ou vi_yank. Est une erreur si le curseur est déjà à la fin du tampon d'édition.
ed-next-history (commande vi : j, +, Ctrl-N ; emacs : Ctrl-N)
Remplace le tampon d'édition par la ligne d'historique suivante. Cette ligne est plus ancienne que la ligne actuelle. Avec un argument, avance du nombre de lignes d'historique spécifié. Le fait d'avancer de plus de lignes que disponible est une erreur non fatale.
ed-next-line (non lié par défaut)
Déplace le curseur d'une ligne vers le bas. Avec un argument, se déplace du nombre de lignes spécifié vers le bas. Est une erreur si le tampon d'édition ne contient pas suffisamment de caractères de nouvelle ligne à droite de la position du curseur.
ed-prev-char (commande vi : h ; emacs : Ctrl-B)
Déplace le curseur d'une position vers la gauche. Avec un argument, se déplace du nombre de caractères spécifié. Peut être utilisé comme commande de déplacement après vi_change_meta, vi_delete_meta, ou vi_yank. Est une erreur si le curseur est déjà au début du tampon d'édition.
ed-prev-history (commande vi : k, -, Ctrl-P ; emacs : Ctrl-P)
Remplace le tampon d'édition par la ligne d'historique précédente. Cette ligne est plus récente que la ligne actuelle. Avec un argument, recule du nombre de lignes spécifié. Le fait de reculer de plus de lignes que disponible est une erreur non fatale.
ed-prev-line (non lié par défaut)
Déplace le curseur d'une ligne vers le haut. Avec un argument, se déplace du nombre de lignes spécifié vers le haut. Est une erreur si le tampon d'édition ne contient pas suffisamment de caractères de nouvelle ligne à gauche de la position du curseur.
ed-prev-word (emacs : Meta-B, Meta-b)
Déplace le curseur vers la gauche jusqu'au début le plus proche d'un mot. Avec un argument, répète ce nombre de fois. Peut être utilisé comme commande de déplacement après vi_change_meta, vi_delete_meta, ou vi_yank. Est une erreur si le curseur est déjà au début du tampon d'édition.
ed-quoted-insert (insertion vi, emacs : Ctrl-V)
Lit un caractère du terminal en contournant la fonctionnalité normale d'édition de ligne et appelle ed-insert sur celui-ci. Si la lecture du caractère renvoie la fin de fichier ou une erreur, appelle ed-end-of-file à la place.
ed-redisplay (commande vi, emacs : Ctrl-R)
Rediffuse tout. Ignore tout argument.
ed-search-next-history (commande vi : J ; emacs : Meta-N, Meta-n)
Remplace le tampon d'édition par la prochaine entrée d'historique correspondante.
ed-search-prev-history (commande vi : K ; emacs : Meta-P, Meta-p)
Remplace le tampon d'édition par l'entrée d'historique précédente correspondante.
ed-sequence-lead-in (cmd vi : O, [ ; emacs : Ctrl-X ; les deux : Meta-O, Meta-[)
Appelle une macro. Voir la section sur les Macros ci-dessous pour plus de détails.
ed-start-over (non lié par défaut)
Écarte le contenu du tampon d'édition et recommence à zéro. Ignore tout argument.
ed-transpose-chars (emacs : Ctrl-T)
Échange le caractère à la position du curseur avec celui qui se trouve à sa gauche et déplace le curseur vers le caractère situé à droite des deux caractères échangés. Ignore tout argument. Est une erreur si le curseur est au début du tampon d'édition ou si le tampon d'édition contient moins de deux caractères.
ed-unassigned (tous caractères non listés)
Cette commande d'éditeur entraîne toujours une erreur.
em-capitol-case (emacs : Meta-C, Meta-c)
Met en majuscule la chaîne allant du curseur à la fin du mot courant. C'est-à-dire, si elle contient au moins un caractère alphabétique, convertit le premier caractère alphabétique en majuscule et convertit tous les caractères à sa droite en minuscules. Dans tous les cas, déplace le curseur vers le caractère suivant après la fin du mot courant.
em-copy-prev-word (emacs : Ctrl-Meta-_)
Copie la chaîne du début du mot courant jusqu'au curseur et l'insère à gauche du curseur. Déplace le curseur vers le caractère suivant la chaîne insérée. Est une erreur si le curseur est au début du tampon d'édition.
em-copy-region (emacs : Meta-W, Meta-w)
Copie la chaîne du curseur jusqu'au marqueur dans le tampon de coupe. Est une erreur si le marqueur n'est pas défini.
em-delete-next-word (emacs : Meta-D, Meta-d)
Supprime la chaîne allant du curseur jusqu'à la fin du mot courant et l'en- registre dans le tampon de coupe. Est une erreur si le curseur est à la fin du tampon d'édition.
em-delete-or-list (emacs : Ctrl-D, EOF)
Si le curseur n'est pas à la fin de la ligne, supprime le caractère au niveau du curseur. Si le tampon d'édition est vide, indique la fin de fichier au programme. Est une erreur si le curseur est à la fin du tampon d'édition et que le tampon d'édition n'est pas vide.
em-delete-prev-char (emacs : Ctrl-H, BS, Ctrl-?, DEL)
Supprime le caractère à gauche du curseur. Est une erreur si le curseur est au début du tampon d'édition.
em-exchange-mark (non lié par défaut)
Échange le curseur et le marqueur.
em-gosmacs-transpose (non lié par défaut)
Échange les deux caractères à gauche du curseur. Est une erreur si le curseur est sur le premier ou le deuxième caractère du tampon d'édition.
em-inc-search-next (non lié par défaut)
Recherche incrémentielle suivante d'Emacs.
em-inc-search-prev (non lié par défaut)
Recherche incrémentielle inverse d'Emacs.
em-kill-line (non lié par défaut)
Supprime l'intégralité du contenu du tampon d'édition et l'enregistre dans le tampon de coupe.
em-kill-region (emacs : Ctrl-W)
Supprime la chaîne allant du curseur au marqueur et l'enregistre dans le tampon de coupe. Est une erreur si le marqueur n'est pas défini.
em-lower-case (emacs : Meta-L, Meta-l)
Convertit les caractères allant du curseur à la fin du mot courant en minuscules.
em-meta-next (commande vi, emacs : Ctrl-[, ESC)
Définit le bit 0x80 sur le prochain caractère tapé. Sauf si le point de code résultant est imprimable, maintenir la touche ‘Meta’ enfoncée tout en tapant ce caractère est un moyen plus simple d'obtenir le même effet.
em-next-word (Meta-F, Meta-f)
Déplace le curseur jusqu'à la fin du mot courant. Peut être utilisé comme commande de déplacement après vi_change_meta, vi_delete_meta, ou vi_yank. Est une erreur si le curseur est déjà à la fin du tampon d'édition.

Macro

s

Si un caractère d'entrée est lié à la commande d'éditeur ed-sequence-lead-in, editline tente d'appeler une macro. Si le caractère d'entrée forme à lui seul le nom d'une macro, cette macro est exécutée. Sinon, des caractères d'entrée supplémentaires sont lus jusqu'à ce que la chaîne lue forme le nom d'une macro, auquel cas cette macro est exécutée, ou jusqu'à ce que la chaîne lue ne corresponde au début d'aucun des noms de macro existants, auquel cas la chaîne incluant le caractère final non correspondant est jetée et la cloche du terminal est

sonnée.

Il existe deux types de macros. Les macros de commande exécutent une seule commande d'éditeur. Les macros de clavier renvoient une chaîne de caractères qui est ajoutée comme nouvelle ligne à la File d'e

ntrée.

Les commandes macros suivantes sont définies par défaut en mode commande vi et en mode emacs

: O A tory O B tory O C char O D char O F -end O H ove-to
Esc [ A, Esc ed-prev-his
Esc [ B, Esc ed-next-his
Esc [ C, Esc ed-next-
Esc [ D, Esc ed-prev-
Esc [ F, Esc ed-move-to
Esc [ H, Esc ed-m
-beg

En mode commande vi, elles sont également définies par défaut sans le caractère d'échappement

initial.

De plus, la bibliothèque editline tente de lier les chaînes générées par les touches flèches telles que rapportées par la base de données terminfo(5) à ces commandes d'éditeur, à moins que cela ne remplace les réglages de

l'utilisateur.

En mode emacs, la chaîne de deux caractères « Ctrl-X Ctrl-X » est liée à la commande d'éditeur em-exchange-mar

k
.

File

d'entrée

La bibliothèque editline maintient une file d'entrée opérée en mode FIFO. Chaque fois qu'elle a besoin d'un caractère d'entrée, elle prend le premier caractère de la première ligne de la file d'entrée. Lorsque la file est vide, elle lit depuis le

terminal.

Une ligne peut être ajoutée à la fin de la file d'entrée de plusieurs manières

:
  • En appelant une des macros de clavie
    • r.
  • En appelant la commande d'éditeur vi-red
    • o.
  • En appelant la commande d'éditeur vi-alia
    • s.
  • En appuyant sur une touche en mode de recherche incrémentale emacs qui n'a pas de signification particulière dans ce mode mais qui revient au mode emacs
    • normal.
  • Si un programme d'application appelle directement les fonctions el_push(3) ou el_wpush(3), il peut fournir des mo
    • yens supplémentaires,
spécifiques au progr
amme, d'ajouter à la
file d'entrée.
