Le fichier editrc définit divers paramètres à utiliser par la bibliothèque editline(3)

.

Le format de chaque ligne est

:
[prog:]commande [arg ...
]

commande est l'une des commandes intégrées de editline(3). Consultez COMMANDES INTÉGRÉES pour plus

d'informations.

prog est la chaîne de nom de programme qu'un programme définit lorsqu'il appelle el_init(3) pour configurer editline(3), qui est généralement argv[0]. commande sera exécutée pour tout programme qui correspond à prog

.

prog peut également être une expression régulière de style regex(3), auquel cas commande sera exécutée pour tout programme qui correspond à l'expression

régulière.

Si prog est absent, commande est exécutée po

ur tous les
programmes.

COMMANDES

INTÉGRÉES

La bibliothèque editline possède quelques commandes intégrées, qui affectent la manière dont les fonctions d'édition de ligne et d'historique fonctionnent. Elles sont basées sur des commandes intégrées de nom similaire présentes dans le shell tcsh(

1).

Les commandes intégrées suivantes sont disponibles

:
bind [-aeklrsv] [touche [command
e]]
Sans options ni arguments, liste toutes les touches et macros liées, ainsi que la commande d'éditeur ou la chaîne d'entrée à laquelle chacune est liée. Si seule la touche est fournie, affiche la liaison pour cette touche ou macro. Si touche commande est fournie, lie la commande d'éditeur à cette touche ou macro.

Les options sont les suivantes

:
-
a
Liste ou modifie les liaisons de touches dans la table de touches alternative (mode commande) du mode
vi(1).
-
e
Lie toutes les touches aux liaisons standard de type GNU
Emacs.
-
k
touche est interprétée comme un nom symbolique de touche flèche, qui peut être l'un des suivants : up, down, left ou rig
ht.
-
l
Liste toutes les commandes d'éditeur avec une courte description de
chacune.
-
r
Supprime la liaison de la touche ou de la macro tou
che.
-
s
Définit une macro clavier plutôt qu'une liaison de touche ou une macro de commande : commande est prise comme une chaîne littérale et ajoutée à la file d'entrée chaque fois que la touche est tapée. Les touches et macros liées dans la commande sont elles-mêmes réinterprétées, et cela continue sur dix niveaux
d'interprétation.
-
v
Lie toutes les touches aux liaisons standard de type vi(
1
).

d'entrée.

Exerce les capacités du terminal données dans arg. Si arg est «baud », «cols », «lines », «rows », «meta », ou «tabs », la valeur de cette capacité est imprimée, avec « yes » ou « no » indiquant que le terminal a ou n'a pas cette capacité.

Active ou désactive les fonctionnalités de editline dans un

history list | size n | unique
n
La commande «list » liste toutes les entrées de l'historique. La commande «size » définit la taille de l'historique à n entrées. La commande «unique » contrôle si l'historique doit conserver les entrées en double. Si n est non nul, ne conserver que les entrées d'historique uniques. Si n est zéro, alors conserver toutes les entrées (par défaut)
.
settc cap va

Définit la capacité du terminal cap à val, comme défini dans termcap(5). Aucune vérification de cohérence n'est
effectuée.
setty [-a] [-d] [-q] [-x] [+mode] [-mode] [mode] [char=c
]
Contrôle les modes tty que editrc n'autorisera pas l'utilisateur à changer. -d, -q ou -x indique à setty d'agir respectivement sur l'ensemble des modes tty « edit », « quote » ou « execute » ; par défaut sur -x.

Sans autres arguments, setty liste les modes de l'ensemble choisi qui sont fixés à actif (+mode) ou inactif (-mode). -a liste tous les modes tty de l'ensemble choisi quel que soit leur réglage. Avec +mode, -mode ou mode, fixe mode à actif ou inactif ou supprime le contrôle de mode dans l'ensemble

choisi.

Setty peut aussi être utilisé pour définir des caractères tty à des valeurs particulières en utilisant char=value. Si value est vide, le caractère est défini à _POSIX_VDISA
