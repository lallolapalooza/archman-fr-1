NOM

ettercap - Page man de l'interface graphique Ncurses.

DESCRIPTION GENERALE

L'interface graphique Curses est assez simple et intuitive.
Elle est dirigée par des menus. Chaque drapeau ou fonction peut être modifié/appelé via le menu supérieur. Tous les messages utilisateur sont affichés dans la fenêtre du bas. Si vous souhaitez voir les anciens messages, vous pouvez faire défiler le tampon de la fenêtre en appuyant sur les touches UP, DOWN, PPAGE, NPAGE. La partie centrale est utilisée pour afficher des informations ou des dialogues pour l'utilisateur.

Les menus peuvent être ouverts en appuyant sur la touche de raccourci correspondante. Pour les menus, la touche de raccourci est représentée par la lettre initiale majuscule du titre (par exemple, 'S' pour Sniffing, 'T' pour Targets). Les fonctions au sein d'un menu peuvent être appelées en appuyant sur la touche de raccourci indiquée près du nom de la fonction à droite. Les touches de raccourci précédées de 'C-' doivent être utilisées conjointement avec la touche CTRL (par exemple, 'C-f' signifie CTRL+f).

Vous pouvez basculer la mise au point entre les objets à l'écran en appuyant sur la touche TAB ou en cliquant dessus avec la souris (si vous exécutez ettercap dans un xterm). Les événements de la souris ne sont pris en charge que via xterm. Vous pouvez utiliser la souris pour sélectionner des objets, ouvrir un menu, choisir une fonction, faire défiler les ascenseurs pour les fenêtres défilantes, etc.

Lorsque vous ouvrez plusieurs fenêtres dans la partie centrale, elles se chevaucheront. Utilisez la touche TAB pour basculer entre elles. Utilisez CTRL+Q pour fermer la fenêtre active.
Vous pouvez également utiliser CTRL+Q pour fermer la boîte de dialogue de saisie si vous souhaitez annuler la saisie demandée. (c'est-à-dire que vous avez sélectionné la mauvaise fonction et que vous souhaitez revenir en arrière).

Pour obtenir une aide rapide sur les raccourcis que vous pouvez utiliser dans une fenêtre particulière, appuyez sur la touche ESPACE. Une fenêtre d'aide s'affichera avec une liste des raccourcis utilisables. Si la fenêtre n'apparaît pas, aucun raccourci n'est disponible.

COMMENT LE SELECTIONNER

Pour utiliser l'interface graphique Ncurses, vous devez :

- compiler ettercap avec le support ncurses (évidemment)
- l'exécuter avec le drapeau -C

Passer le drapeau -C est suffisant, mais si vous le souhaitez, vous pouvez passer d'autres drapeaux qui seront automatiquement définis pour l'interface graphique ncurses. Vous pourrez les remplacer en utilisant le menu pour modifier les options.

UNE FOIS DEMARRE

Dès qu'ettercap est lancé avec l'interface graphique Ncurses, plusieurs choix vous seront proposés. Le premier écran vous permet de sélectionner si vous souhaitez ouvrir un fichier pcap ou enregistrer le trafic intercepté dans un fichier, si vous souhaitez un sniffing unifié ou ponté, vous permet de définir un fichier pcap sur le trafic capturé et vous permet d'enregistrer toutes les données interceptées.

Une fois que vous avez sélectionné une méthode de sniffing (depuis un fichier, unifié ou ponté), cet écran ne sera plus accessible. La seule façon est de redémarrer ettercap.

Analysons chaque menu de l'écran de démarrage :

Fichier
Ouvrir...
Ouvre un fichier pcap et l'analyse. Toutes les fonctionnalités disponibles pour l'interception en direct sont en place, à l'exception de celles qui envoient ou transfèrent des paquets (attaques MITM et autres...).
Sauvegarder dans un fichier...
Tout le trafic intercepté par la capture en direct sera enregistré dans ce fichier. Les filtres, pas les cibles, ont un effet sur ce fichier, car tous les paquets reçus par pcap seront enregistrés. La seule façon de ne pas enregistrer un paquet donné est de définir un filtre pcap approprié (voir ci-dessous).
Quitter

Quitte ettercap et retourne à l'invite de commande.
Sniff
Sniffing unifié...
En choisissant cette fonction, vous serez invité à sélectionner l'interface réseau à utiliser pour le sniffing. La première interface opérationnelle est suggérée dans la zone de saisie. Pour une explication de ce qu'est le sniffing unifié, référez-vous à ettercap(8).
ASTUCE : si vous utilisez la touche de raccourci 'u', cette étape sera ignorée et l'interface par défaut sera automatiquement sélectionnée.
Sniffing ponté...
Après avoir sélectionné les deux interfaces à utiliser, vous entrerez en mode de sniffing ponté. Pour une explication de ce qu'est le sniffing ponté, référez-vous à ettercap(8).
Définir le filtre pcap...
Ici, vous pouvez insérer un filtre de type tcpdump pour le processus de capture.
IMPORTANT : si vous parvenez à utiliser une attaque MITM, rappelez-vous qu'ettercap ne voit pas un paquet, il ne sera PAS transféré. Soyez donc sûr de ce que vous faites en définissant un filtre pcap.
Options
Non-offensif
Active/désactive le drapeau non-offensif. L'astérisque '*' signifie "l'option est activée". Sinon, l'option n'est pas activée.
Mode promiscuous
Active/désactive le mode promiscuous pour la capture en direct sur une interface réseau. C'est une "option astérisque" comme la non-offensive.
Définir le masque réseau
Utilise le masque réseau spécifié au lieu de celui associé à l'interface actuelle. Cette option est utile si votre carte réseau a un masque réseau de classe B associé et que vous souhaitez analyser (avec l'analyse ARP) uniquement une classe C.

LA PARTIE INTERESSANTE

Une fois que vous avez sélectionné un sniffing hors ligne ou une capture en direct, le menu supérieur est modifié et vous pouvez commencer à faire les choses intéressantes...
Certains des menus suivants ne sont disponibles qu'en capture en direct.

Démarrer
Démarrer le sniffing
Démarre le processus de sniffing en fonction de ce que vous avez sélectionné au démarrage (en direct ou depuis un fichier)
Arrêter le sniffing
Arrête le thread de sniffing.
Quitter

Retourne à votre shell préféré ;)
Cibles
Cibles actuelles
Affiche une liste d'hôtes dans chaque CIBLE. Vous pouvez supprimer sélectivement un hôte en le sélectionnant et en appuyant sur 'd' ou ajouter un nouvel hôte en appuyant sur 'a'. Pour basculer entre les deux listes, utilisez les touches FLÉCHÉES.
Sélectionner une ou plusieurs CIBLE(s)
Vous permet de sélectionner la ou les CIBLE(s) comme expliqué dans ettercap(8). La syntaxe est la même que pour la spécification en ligne de commande.
Protocole...
Vous pouvez choisir de sniffer uniquement TCP, uniquement UDP ou les deux (TOUT).
Inverser la correspondance
Inverse la correspondance d'un paquet. C'est équivalent à un NOT avant la spécification de la cible.
Effacer les cibles
Restaure les deux CIBLES à TOUT/TOUT/TOUT
Hôtes
Liste des hôtes
Affiche la liste des hôtes détectés via un scan ARP ou convertis à partir des profils passifs. Cette liste est utilisée par les attaques MITM lorsque la cible TOUT est sélectionnée, donc si vous souhaitez exclure un hôte de l'attaque, supprimez-le simplement de la liste.
Vous pouvez supprimer un hôte de la liste en appuyant sur 'd', l'ajouter à CIBLE1 en appuyant sur '1' ou l'ajouter à CIBLE2 en appuyant sur '2'.
Analyser les hôtes
Effectue l'analyse ARP du masque réseau si aucune CIBLE n'est sélectionnée. Si des CIBLES ont été spécifiées, il analyse uniquement ces hôtes.
Charger depuis un fichier...
Charge la liste des hôtes depuis un fichier précédemment

Ce site n'est en aucun cas associé à Arch Linux ni affilié à ce projet. Le contenu est uniquement une traduction des pages de manuel d'Arch publiées sur man.archlinux.org.

enregistré avec « enregistrer dans un fichier » ou créé manuellement.
Enregistrer dans un fichier...
Enregistre la liste des hôtes actuelle dans un fichier.
Affichage
Connexions
Affiche la liste des connexions. Pour voir les informations détaillées d'une connexion, appuyez sur 'd', ou appuyez sur 'k' pour la tuer. Pour voir le trafic d'une connexion spécifique, sélectionnez-la et appuyez sur entrée. Une fois l'interface à deux panneaux affichée, vous pouvez déplacer le focus avec les touches fléchées. Appuyez sur 'j' pour basculer entre la visualisation jointe et séparée. Appuyez sur 'k' pour tuer la connexion. Appuyez sur 'y' pour injecter de manière interactive et 'Y' pour injecter un fichier. Notez qu'il est important de savoir quel panneau a le focus, car les données injectées seront envoyées à cette adresse.
ASTUCE : les connexions marquées d'un astérisque contiennent des informations de compte(s).
Profils
Affiche la liste des hôtes du profil passif. Sélectionner un hôte affichera les détails relatifs (y compris le compte avec l'utilisateur et le mot de passe pour cet hôte).
Vous pouvez convertir la liste du profil passif en liste des hôtes en appuyant sur 'c'. Pour purger les hôtes distants, appuyez sur 'l'. Pour purger les hôtes locaux, appuyez sur 'r'. Vous pouvez aussi exporter le profil actuel dans un fichier en appuyant sur 'd' ; le fichier exporté peut être ouvert avec etterlog(8).
ASTUCE : les profils marqués d'un astérisque contiennent des informations de compte(s).
Statistiques
Affiche quelques statistiques sur le processus d'écoute.
Résoudre les adresses IP
Active la résolution DNS pour toutes les adresses IP écoutées. ATTENTION : cela ralentira extrêmement ettercap. De toute façon, la résolution DNS passive est toujours active. Elle écoute les réponses DNS et les stocke dans un cache. Si une adresse IP est présente dans ce cache, elle sera automatiquement résolue. C'est de la résolution DNS gratuite... ;)
Méthode de visualisation
Change la méthode de visualisation des données écoutées. Méthodes disponibles : ascii, hex, ebcdic, text, html.
Expression régulière de visualisation
Définit l'expression régulière de visualisation. Seuls les paquets correspondant à cette expression régulière seront affichés dans la fenêtre de données de connexion.
Définir la clé WiFi
Définit la clé WiFi utilisée pour déchiffrer les paquets WiFi chiffrés. Voir ettercap(8) pour le format de la clé.
Mitm
[...]
Pour chaque type d'attaque, une entrée de menu est affichée. Sélectionnez simplement l'attaque que vous voulez et remplissez les arguments lorsque demandé. Vous pouvez activer plus d'une attaque à la fois.
Arrêter les attaques mitm
Arrête toutes les attaques mitm actuellement actives.
Filtres
Charger un filtre...
Charge un fichier de filtre précompilé. Le fichier doit être compilé avec etterfilter(8) avant de pouvoir être chargé.
Arrêter le filtrage
Décharge le filtre et arrête le filtrage des connexions.
Journalisation
Journaliser tous les paquets et les infos...
Étant donné un nom de fichier, il créera deux fichiers : filename.eci (pour les informations sur les hôtes) et filename.ecp (pour tous les paquets intéressants). C'est la même chose que l'option -L.
Journaliser seulement les infos...
C'est utilisé uniquement pour écouter les informations sur les hôtes (identique à l'option -l).
Arrêter la journalisation des infos
Allez, c'est explicite tout seul.
Journaliser les messages utilisateur...
Journalisera tous les messages apparaissant dans la fenêtre du bas (identique à l'option -m).
Fichier compressé
Option astérisque pour contrôler si le fichier journal doit être compressé ou non.
Plugins
Gérer les plugins
Ouvre la fenêtre de gestion des plugins. Vous pouvez sélectionner un plugin et l'activer en appuyant sur 'entrée'. Les plugins déjà actifs peuvent être reconnus par le symbole [1] au lieu de [0]. Si vous sélectionnez un plugin actif, il sera désactivé.
Charger un plugin...
Vous pouvez charger un fichier plugin qui n'est pas dans le chemin de recherche par défaut. (rappelez-vous que vous pouvez parcourir les répertoires avec les permissions EC_UID).
