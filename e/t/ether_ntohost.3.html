ether_aton(3) Manuel des fonctions de bibliothèque ether_aton(3)

NOM

ether_aton, ether_ntoa, ether_ntohost, ether_hostton, ether_line, ether_ntoa_r, ether_aton_r - Routines de manipulation d'adresses Ethernet

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNOPSIS

#include <netinet/ether.h>
char *ether_ntoa(const struct ether_addr *addr);
struct ether_addr *ether_aton(const char *asc);
int ether_ntohost(char *hostname, const struct ether_addr *addr);
int ether_hostton(const char *hostname, struct ether_addr *addr);
int ether_line(const char *line, struct ether_addr *addr,
               char *hostname);
/* Extensions GNU */
char *ether_ntoa_r(const struct ether_addr *addr, char *buf);
struct ether_addr *ether_aton_r(const char *asc,
                                struct ether_addr *addr);

DESCRIPTION

ether_aton() convertit l'adresse hôte Ethernet 48 bits asc, à partir de la notation standard avec chiffres hexadécimaux et deux-points, en données binaires en ordre d'octets réseau et retourne un pointeur vers celles-ci dans un tampon alloué statiquement, qui sera écrasé par les appels suivants. ether_aton() retourne NULL si l'adresse est invalide.

La fonction ether_ntoa() convertit l'adresse hôte Ethernet addr, donnée en ordre d'octets réseau, en une chaîne de caractères dans la notation standard avec chiffres hexadécimaux et deux-points, en omettant les zéros non significatifs. La chaîne est retournée dans un tampon alloué statiquement, qui sera écrasé par les appels suivants.

La fonction ether_ntohost() mappe une adresse Ethernet au nom d'hôte correspondant dans /etc/ethers et retourne une valeur non nulle si elle ne peut pas être trouvée.

La fonction ether_hostton() mappe un nom d'hôte à l'adresse Ethernet correspondante dans /etc/ethers et retourne une valeur non nulle si elle ne peut pas être trouvée.

La fonction ether_line() analyse une ligne au format /etc/ethers (adresse Ethernet suivie d'espaces blancs suivis d'un nom d'hôte ; '#' introduit un commentaire) et retourne une paire adresse et nom d'hôte, ou une valeur non nulle si l'analyse échoue. Le tampon pointé par hostname doit être suffisamment long — par exemple, avoir la même longueur que line—.

Les fonctions ether_ntoa_r() et ether_aton_r() sont des versions réentrantes et thread-safe de ether_ntoa() et ether_aton() respectivement, et n'utilisent pas de tampons statiques.

La structure ether_addr est définie dans <net/ethernet.h> comme suit :


struct ether_addr {
    uint8_t ether_addr_octet[6];
}

ATTRIBUTS

Interface Attribut Valeur
ether_aton (), ether_ntoa () Thread safety MT-Unsafe
ether_ntohost (), ether_hostton (), ether_line (), ether_ntoa_r (), ether_aton_r () Thread safety MT-Safe

NORMES

Aucune.

HISTORIQUE

4.3BSD, SunOS.

BOGUES

Dans glibc 2.2.5 et versions antérieures, l'implémentation de ether_line() est défectueuse.
