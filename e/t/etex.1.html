ETEX(1) Manuel des commandes générales ETEX(1)

NOM

etex - TeX étendu (simple)

SYNOPSIS

etex [options] [&format] [fichier|\commandes]

DESCRIPTION

Lance le compositeur e-TeX sur fichier, créant par défaut fichier.dvi. Si le nom de fichier n'a pas d'extension, ".tex" lui sera ajouté. Au lieu d'un nom de fichier, un ensemble de commandes e-TeX peut être fourni, la première devant commencer par une barre oblique inverse. Avec l'argument &format, e-TeX utilise un ensemble différent de commandes précompilées, contenues dans format.fmt ; il est généralement préférable d'utiliser plutôt l'option -fmt format.

e-TeX est le premier résultat concret d'un projet international de recherche et développement, le Projet NTS, créé sous l'égide de DANTE e.V. en 1992. Les objectifs du projet sont de perpétuer et de développer l'esprit et la philosophie de TeX, tout en respectant le souhait de Knuth que TeX reste figé.

e-TeX peut être utilisé dans deux modes différents : en mode compatible, il est censé être complètement interchangeable avec TeX standard. En mode étendu, plusieurs primitives nouvelles sont ajoutées qui facilitent (entre autres choses) la composition bidirectionnelle.

Un format en mode étendu est généré en préfixant le nom du fichier source du format par un astérisque (*).

La gestion des arguments de ligne de commande par e-TeX est similaire à celle des autres programmes TeX de l'implémentation web2c.

OPTIONS

Cette version d'e-TeX comprend les options de ligne de commande suivantes.

-fmt format
Utilise format comme nom du format à utiliser, au lieu du nom sous lequel e-TeX a été appelé ou d'une ligne %&.
-enc
Active les extensions encTeX. Cette option n'est effective qu'en combinaison avec -ini. Pour la documentation des extensions encTeX, voir http://www.olsak.net/enctex.html.
-etex
Active les extensions e-TeX. Cette option n'est effective qu'en combinaison avec -ini.
-file-line-error
Affiche les messages d'erreur sous la forme fichier:ligne:erreur, similaire à la façon dont de nombreux compilateurs les formatent.
-no-file-line-error
Désactive l'affichage des messages d'erreur au style fichier:ligne:erreur.
-file-line-error-style
C'est l'ancien nom de l'option -file-line-error.
-halt-on-error
Se termine avec un code d'erreur lorsqu'une erreur est rencontrée pendant le traitement.
-help
Affiche le message d'aide et quitte.
-ini
Démarre en mode INI, utilisé pour sauvegarder des formats. Le mode INI peut être utilisé pour la composition, mais aucun format n'est préchargé, et des initialisations de base comme la définition des codes de catégorie peuvent être nécessaires.
-interaction mode
Définit le mode d'interaction. Le mode peut être batchmode, nonstopmode, scrollmode ou errorstopmode. La signification de ces modes est la même que celle des \commandes correspondantes.
-ipc
Envoie la sortie DVI à un socket ainsi qu'au fichier de sortie habituel. La disponibilité de cette option dépend de l'installateur.
-ipc-start
Comme -ipc, et démarre également le serveur à l'autre extrémité. La disponibilité de cette option dépend de l'installateur.
-jobname nom
Utilise nom pour le nom du travail, au lieu de le dériver du nom du fichier d'entrée.
-kpathsea-debug masque_binaire
Définit les indicateurs de débogage de recherche de chemin selon le masque binaire. Voir le manuel de Kpathsea pour plus de détails.
-mktex fmt
Active mktexfmt, où fmt doit être soit tex soit tfm.
-mltex
Active les extensions MLTeX. Uniquement effectif en combinaison avec -ini.
-no-mktex fmt
Désactive mktexfmt, où fmt doit être soit tex soit tfm.
-output-comment chaîne
Utilise chaîne pour le commentaire du fichier DVI au lieu de la date.
-output-directory répertoire
Écrit les fichiers de sortie dans répertoire au lieu du répertoire courant. Recherche les fichiers d'entrée dans répertoire d'abord, puis le long du chemin de recherche normal.
-parse-first-line
Si la première ligne du fichier d'entrée principal commence par %&, elle est analysée pour rechercher un nom de dump ou une option -translate-file.
-no-parse-first-line
Désactive l'analyse de la première ligne du fichier d'entrée principal.
-progname nom
Se fait passer pour le programme nom. Cela affecte à la fois le format utilisé et les chemins de recherche.
-recorder
Active l'enregistreur de noms de fichiers. Cela laisse une trace des fichiers ouverts pour l'entrée et la sortie dans un fichier avec l'extension .fls.
-shell-escape
Active la construction \write18{commande}. La commande peut être n'importe quelle commande shell. Cette construction est normalement interdite pour des raisons de sécurité.
-no-shell-escape
Désactive la construction \write18{commande}, même si elle est activée dans le fichier texmf.cnf.
-src-specials
Insère des spécifications sources dans le fichier DVI.
-src-specials où
Insère des spécifications sources à certains endroits du fichier DVI. où est une liste de valeurs séparées par des virgules : cr, display, hbox, math, par, parent ou vbox.
-translate-file nomtcx
Utilise la table de traduction nomtcx pour définir le mappage des caractères d'entrée et le remappage des caractères de sortie.
-default-translate-file nomtcx
Comme -translate-file, sauf qu'une ligne %& peut annuler ce réglage.
-version
Affiche les informations de version et quitte.

ENVIRONNEMENT

Voir la documentation de la bibliothèque Kpathsearch (le nœud 'Spécifications de chemin') pour les détails précis sur l'utilisation des variables d'environnement. L'utilitaire kpsewhich peut être utilisé pour interroger les valeurs des variables.

Une mise en garde : dans la plupart des formats e-TeX, vous ne pouvez pas utiliser ~ dans un nom de fichier que vous fournissez directement à e-TeX, car ~ est un caractère actif et est donc développé, et non considéré comme partie du nom de fichier. D'autres programmes, comme Metafont, n'ont pas ce problème.

Par exemple, si vous dites etex paper et le répertoire courant n'est pas inscriptible, si TEXMFOUTPUT a la valeur /tmp, e-TeX tente de créer /tmp/paper.log (et /tmp/paper.dvi, si une sortie est produite.) BUG

S

Cette version d'e-TeX implémente un certain nombre d'extensions optionnelles. En fait, beaucoup de ces extensions entrent en conflit à un degré plus ou moins grand avec la définition d'e-TeX. Lorsque de telles extensions sont activées, la bannière affichée au démarrage d'e-TeX est modifiée pour afficher e-TeXk au lieu de e-TeX
