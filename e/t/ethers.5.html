NOM

ethers - Base de données des adresses Ethernet vers les numéros IP

DESCRIPTION

/etc/ethers contient des adresses Ethernet de 48 bits et leurs numéros IP correspondants, une ligne pour chaque numéro IP :

adresse-Ethernet numéro-IP

Les deux éléments sont séparés par un nombre quelconque d'espaces et/ou de tabulations. Un # au début d'une ligne indique un commentaire qui s'étend jusqu'à la fin de la ligne. L'adresse-Ethernet est écrite sous la forme x:x:x:x:x:x, où x est un nombre hexadécimal compris entre 0 et ff qui représente un octet de l'adresse, qui est en ordre d'octets réseau (big-endian). Le numéro-IP peut être un nom d'hôte résoluble par DNS ou un nombre séparé par des points.

EXEMPLES

08:00:20:00:61:CA pal
