NOM

etc-update - gérer les mises à jour des fichiers de configuration

SYNTAXE

etc-update [options] [--automode <mode>] [chemins à analyser]

DESCRIPTION

etc-update est censé être exécuté après la fusion d'un nouveau paquet pour vérifier s'il y a des mises à jour des fichiers de configuration. Si un nouveau fichier de configuration doit remplacer un ancien, etc-update demandera à l'utilisateur une décision.

etc-update vérifiera tous les répertoires spécifiés sur la ligne de commande. Si aucun chemin n'est donné, la variable CONFIG_PROTECT sera utilisée. Tous les fichiers de configuration trouvés dans CONFIG_PROTECT_MASK seront automatiquement mis à jour pour vous par etc-update. Voir make.conf(5) pour plus d'informations.

etc-update respecte les variables normales PORTAGE_CONFIGROOT et EROOT pour trouver les variables de protection de configuration susmentionnées.

OPTIONS

-d, --debug
Exécuter avec le traçage du shell activé.
-h, --help
Étonnamment, afficher l'aide.
-p, --preen
Fusionner automatiquement uniquement les changements triviaux et quitter.
-v, --verbose
Afficher les paramètres et les informations importantes sur les décisions pendant l'exécution.
--automode <mode>
Sélectionner l'un des modes de fusion automatique. Les modes valides sont : -3 -5 -7 -9. Voir le texte de l'aide (--help) pour plus de détails.
