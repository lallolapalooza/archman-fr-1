NOM

etwdump - Fournir une interface pour lire les traces d'événements Windows (ETW)

SYNTAXE

etwdump [ --help ] [ --version ] [ --extcap-interfaces ] [ --extcap-dlts ] [ --extcap-interface=<interface> ] [ --extcap-config ] [ --capture ] [ --fifo=<chemin vers fichier ou tube> ] [ --iue=<Les événements non décidables doivent-ils être inclus> ] [ --etlfile=<fichier etl> ] [ --params=<paramètres de filtrage> ]

DESCRIPTION

etwdump est un outil extcap qui fournit un accès à un fichier de journal de trace d'événements ou à une session de trace d'événements en direct. Il est uniquement utilisé pour afficher la trace d'événements sous Windows, incluant des messages texte lisibles et différents protocoles (comme MBIM et les paquets IP).

OPTIONS

--help

Affiche les arguments du programme.

--version

Affiche la version du programme.

--extcap-interfaces

Liste les interfaces disponibles.

--extcap-interface=<interface>

Utilise les interfaces spécifiées.

--extcap-dlts

Liste les DLTs de l'interface spécifiée.

--extcap-config

Liste les options de configuration de l'interface spécifiée.

--capture

Démarre la capture de l'interface spécifiée et l'enregistre à l'emplacement spécifié par --fifo.

--fifo=<chemin vers fichier ou tube>

Enregistre le paquet capturé dans un fichier ou l'envoie via un tube.

--iue=<Les événements non décidables doivent-ils être inclus>

Choisit si l'événement non décidable doit être inclus.

--etlfile=<Fichier etl>

Sélectionne le fichier etl à afficher dans Wireshark.

--params=<paramètres de filtrage>

Entrée des fournisseurs, mots-clés et niveaux de filtrage pour le fichier etl et la session en direct.

EXEMPLES

Pour voir les arguments du programme :

etwdump --help

Pour voir la version du programme :

etwdump --version

Pour voir les interfaces :

etwdump --extcap-interfaces

Exemple de sortie

interface {value=etwdump}{display=Lecteur ETW}

Pour voir les DLTs de l'interface :

etwdump --extcap-interface=etwdump --extcap-dlts

Exemple de sortie

dlt {number=1}{name=etwdump}{display=DLT_ETW}

Pour voir les options de configuration de l'interface :

etwdump --extcap-interface=etwdump --extcap-config

Exemple de sortie

arg {number=0}{call=--etlfile}{display=Fichier etl}{type=fileselect}{tooltip=Sélectionne le fichier etl à afficher dans Wireshark}{group=Capture}
arg {number=1}{call=--params}{display=Paramètres de filtrage}{type=string}{tooltip=Entrée des fournisseurs, mots-clés et niveaux de filtrage pour le fichier etl et la session en direct}{group=Capture}
arg {number=2}{call=--iue}{display=Les événements non décidables doivent-ils être inclus}{type=boolflag}{default=false}{tooltip=Choisit si l'événement non décidable doit être inclus}{group=Capture}

Pour capturer :

etwdump --extcap-interface etwdump --fifo=/tmp/etw.pcapng --capture --params "--p=Microsoft-Windows-Wmbclass-Opn --p=Microsoft-Windows-wmbclass --k=0xff --l=4"
etwdump --extcap-interface etwdump --fifo=/tmp/etw.pcapng --capture --params "--p=Microsoft-Windows-Wmbclass-Opn --p=Microsoft-Windows-NDIS-PacketCapture"

Note

Pour arrêter la capture, appuyez sur CTRL+C / tuez / terminez l'application.
