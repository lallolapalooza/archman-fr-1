ETF2LY(1) Commandes utilisateur ETF2LY(1)

NOM

etf2ly - page de manuel pour etf2ly (LilyPond) 2.24.4

SYNTAXE

etf2ly [OPTION]... FICHIER-ETF

DESCRIPTION

Enigma Transport Format est un format utilisé par le produit Finale de Coda Music Technology. etf2ly convertit un sous-ensemble d'ETF en un fichier LilyPond prêt à l'emploi.

OPTIONS

-h, --help
afficher cette aide et quitter
--version
afficher le numéro de version et quitter
-o, --output=FICHIER
écrire la sortie dans FICHIER
-w, --warranty
afficher la garantie et les droits d'auteur

SIGNALER LES BOGUES

Signaler les bogues via bug-lilypond@gnu.org

VOIR AUSSI

La documentation complète d'etf2ly est maintenue sous la forme d'un manuel Texinfo. Si les programmes info et etf2ly sont correctement installés sur votre site, la commande

info etf2ly

devrait vous donner accès au manuel complet.
