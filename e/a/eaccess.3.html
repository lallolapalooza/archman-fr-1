euidaccess(3) Manuel des fonctions de bibliothèque euidaccess(3)

NOM

euidaccess, eaccess - vérifier les permissions d'un fichier pour l'utilisateur effectif

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#define _GNU_SOURCE             /* Voir feature_test_macros(7) */
#include <unistd.h>
int euidaccess(const char *path, int mode);
int eaccess(const char *path, int mode);

DESCRIPTION

Comme access(2), euidaccess() vérifie les permissions et l'existence du fichier identifié par son argument path. Cependant, alors que access(2) effectue des vérifications en utilisant les identifiants réels de l'utilisateur et du groupe du processus, euidaccess() utilise les identifiants effectifs.

mode est un masque composé d'un ou plusieurs des indicateurs R_OK, W_OK, X_OK et F_OK, avec les mêmes significations que pour access(2).

eaccess() est un synonyme de euidaccess(), fourni pour la compatibilité avec certains autres systèmes.

VALEUR DE RETOUR

En cas de succès (toutes les permissions demandées accordées), zéro est retourné. En cas d'erreur (au moins un bit dans mode demandait une permission refusée, ou une autre erreur s'est produite), -1 est retourné et errno est défini pour indiquer l'erreur.

ERREURS

Comme pour access(2).

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
euidaccess (), eaccess () Sécurité des threads MT-Safe

VERSIONS

Certains autres systèmes ont une fonction eaccess().

NORMES

Aucune.

HISTORIQUE

eaccess()
glibc 2.4.

NOTES

Attention : Utiliser cette fonction pour vérifier les permissions d'un processus sur un fichier avant d'effectuer une opération basée sur cette information entraîne des conditions de concurrence : les permissions du fichier peuvent changer entre les deux étapes. Généralement, il est plus sûr de simplement tenter l'opération souhaitée et de gérer toute erreur de permission qui survient.

Cette fonction déréférence toujours les liens symboliques. Si vous avez besoin de vérifier les permissions sur un lien symbolique, utilisez faccessat(2) avec les indicateurs AT_EACCESS et AT_SYMLINK_NOFOLLOW.

VOIR AUSSI

access(2), chmod(2), chown(2), faccessat(2), open(2), setgid(2), setuid(2), stat(2), credentials(7), path_resolution(7)
