NOM

eidenv - utilitaire pour accéder aux données visibles des cartes d'identité électroniques

SYNTAXE

eidenv [OPTIONS]

DESCRIPTION

L'utilitaire eidenv est utilisé pour accéder aux données des cartes d'identité électroniques (comme les cartes d'identité nationales) qui ne sont peut-être pas présentes dans les objets PKCS#15 mais disponibles dans des fichiers personnalisés sur la carte. Les données peuvent être imprimées à l'écran ou utilisées par d'autres programmes via des variables d'environnement.

OPTIONS

--exec prog, -x prog

Exécute le programme donné avec les données dans les variables d'environnement.

--help, -h

Affiche le message d'aide à l'écran.

--print, -p

Imprime tous les champs de données de la carte, tels que la période de validité, le numéro de document, etc.

--reader arg, -r arg

Numéro du lecteur à utiliser. Par défaut, le premier lecteur avec une carte présente est utilisé. Si arg est une ATR, le lecteur avec une carte correspondante sera choisi.

--stats, -t

Imprime les statistiques d'utilisation clés (uniquement pour la carte d'identité estonienne).

--version, -v

Imprime la version de l'utilitaire et quitte.

--wait, -w

Attend qu'une carte soit insérée.

AUTEURS

L'utilitaire eidenv a été écrit par Stef Hoeben et Martin Paljak <martin@martinpaljak.net>.
