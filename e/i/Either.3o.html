Type Either.

Either est le type somme/variant le plus simple et le plus générique : une valeur de ('a, 'b) Either.t est soit un Left (v : 'a) soit un Right (v : 'b).

C'est un choix naturel dans l'API des fonctions génériques où les valeurs pourraient tomber dans deux cas différents, potentiellement avec des types différents, sans assigner de signification spécifique à ce que chaque cas devrait représenter.

Par exemple:

List.partition_map:
    ('a -> ('b, 'c) Either.t) -> 'a list -> 'b list * 'c list

Si vous recherchez un type paramétré où une alternative signifie succès et l'autre échec, vous devriez utiliser le type plus spécifique Result.t.

Depuis 4.12

type ('a, 'b) t =
| Left of 'a
| Right of 'b

Une valeur de ('a, 'b) Either.t contient soit une valeur de type 'a, soit une valeur de type 'b.

val left : 'a -> ('a, 'b) t

left v est Left v.

val right : 'b -> ('a, 'b) t

right v est Right v.

val is_left : ('a, 'b) t -> bool

is_left (Left v) retourne true, is_left (Right v) retourne false.

val is_right : ('a, 'b) t -> bool

is_right (Left v) retourne false, is_right (Right v) retourne true.

val get_left : ('a, 'b) t -> 'a

get_left e retourne v si e est Left v, et lève une exception sinon.

Depuis 5.4

Lève Invalid_argument si e est Right _.

val get_right : ('a, 'b) t -> 'b

get_right e retourne v si e est Right v, et lève une exception sinon.

Depuis 5.4

Lève Invalid_argument si e est Left _.

val find_left : ('a, 'b) t -> 'a option

find_left (Left v) retourne Some v, find_left (Right _) retourne None.

val find_right : ('a, 'b) t -> 'b option

find_right (Right v) retourne Some v, find_right (Left _) retourne None.

val map_left : ('a1 -> 'a2) -> ('a1, 'b) t -> ('a2, 'b) t

map_left f e retourne Left (f v) si e est Left v, et e si e est Right _.

val map_right : ('b1 -> 'b2) -> ('a, 'b1) t -> ('a, 'b2) t

map_right f e retourne Right (f v) si e est Right v, et e si e est Left _.

val map : left:('a1 -> 'a2) -> right:('b1 -> 'b2) -> ('a1, 'b1) t -> ('a2, 'b2) t

map ~left ~right (Left v) retourne Left (left v), map ~left ~right (Right v) retourne Right (right v).

val fold : left:('a -> 'c) -> right:('b -> 'c) -> ('a, 'b) t -> 'c

fold ~left ~right (Left v) retourne left v, et fold ~left ~right (Right v) retourne right v.

val retract : ('a, 'a) t -> 'a

retract (Left v) retourne v, et retract (Right v) retourne v.

Depuis 5.4

val iter : left:('a -> unit) -> right:('b -> unit) -> ('a, 'b) t -> unit

iter ~left ~right (Left v) appelle left v, et iter ~left ~right (Right v) appelle right v.

val for_all : left:('a -> bool) -> right:('b -> bool) -> ('a, 'b) t -> bool

for_all ~left ~right (Left v) retourne left v, et for_all ~left ~right (Right v) retourne right v.

val equal : left:('a -> 'a -> bool) -> right:('b -> 'b -> bool) -> ('a, 'b) t -> ('a, 'b) t -> bool

equal ~left ~right e0 e1 teste l'égalité de e0 et e1 en utilisant left et right pour comparer respectivement les valeurs enveloppées par Left _ et Right _.

val compare : left:('a -> 'a -> int) -> right:('b -> 'b -> int) -> ('a, 'b) t -> ('a, 'b) t -> int

compare ~left ~right e0 e1 ordonne totalement e0 et e1 en utilisant left et right pour comparer respectivement les valeurs enveloppées par Left _ et Right _. Les valeurs Left _ sont plus petites que les valeurs Right _.
