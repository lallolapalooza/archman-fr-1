NOM

eza — un remplacement moderne pour ls

SYNOPSIS

eza [options] [fichiers...]

eza est un remplacement moderne pour ls. Il utilise des couleurs pour l'information par défaut, vous aidant à distinguer de nombreux types de fichiers, comme le fait que vous en êtes le propriétaire ou membre du groupe propriétaire.

Il possède également des fonctionnalités supplémentaires absentes de l'original ls, comme la visualisation du statut Git d'un répertoire, ou la récursion dans les répertoires avec une vue en arborescence.

EXEMPLES

eza
Liste le contenu du répertoire courant sous forme de grille.
eza --oneline --reverse --sort=size
Affiche une liste de fichiers avec les plus grands en haut.
eza --long --header --inode --git
Affiche un tableau de fichiers avec un en-tête, montrant les métadonnées, l'inode et le statut Git de chaque fichier.
eza --long --tree --level=3
Affiche une arborescence de fichiers, sur trois niveaux de profondeur, ainsi que les métadonnées de chaque fichier.

OPTIONS MÉTA

--help
Affiche la liste des options en ligne de commande.
-v, --version
Affiche la version de eza.

OPTIONS D'AFFICHAGE

-1, --oneline
Affiche une entrée par ligne.
--absolute=QUAND
Affiche les entrées avec leur chemin absolu.

Les valeurs valides sont `on', `follow' et `off'. Lorsqu'il est utilisé sans valeur, la valeur par défaut est `on'.

`on' : Affiche les chemins absolus pour toutes les entrées. `follow' : Affiche les chemins absolus et résout les liens symboliques vers leurs cibles. `off' : Affiche les chemins relatifs (comportement par défaut).

-F, --classify=QUAND
Affiche des indicateurs de type de fichier à côté des noms de fichiers.

Les valeurs valides sont `always', `automatic' (ou `auto' pour faire court) et `never'. Lorsqu'il est utilisé sans valeur, la valeur par défaut est `automatic'.

automatic ou auto affichera les indicateurs de type de fichier uniquement lorsque la sortie standard est connectée à un vrai terminal. Si eza est exécuté dans un tty, ou si la sortie de eza est redirigée vers un fichier ou envoyée dans un pipe vers un autre programme, les indicateurs de type de fichier ne seront pas utilisés. Régler cette option sur `always' fait eza afficher toujours les indicateurs de type de fichier, tandis que `never' désactive l'utilisation des indicateurs de type de fichier.

-G, --grid
Affiche les entrées sous forme de grille (par défaut).
-l, --long
Affiche les métadonnées étendues des fichiers sous forme de tableau.
-R, --recurse
Récursif dans les répertoires.
-T, --tree
Récursif dans les répertoires sous forme d'arborescence.
--follow-symlinks
Descend dans les liens symboliques qui pointent vers des répertoires.
-X, --dereference
Référence les liens symboliques lors de l'affichage des informations.
-x, --across
Trie la grille en largeur plutôt qu'en hauteur.
--color=QUAND, --colour=QUAND
Quand utiliser les couleurs du terminal (en utilisant les codes d'échappement ANSI pour coloriser la sortie).

Les valeurs valides sont `always', `automatic' (ou `auto' pour faire court) et `never'. Lorsqu'il est utilisé sans valeur, la valeur par défaut est `automatic'.

Le comportement par défaut (`automatic' ou `auto') est de coloriser la sortie uniquement lorsque la sortie standard est connectée à un vrai terminal. Si la sortie de eza est redirigée vers un fichier ou envoyée dans un pipe vers un autre programme, les couleurs du terminal ne seront pas utilisées. Régler cette option sur `always' fait eza toujours produire une sortie avec les couleurs du terminal, tandis que `never' désactive l'utilisation des couleurs du terminal.

Régler manuellement cette option remplace NO_COLOR de l'environnement.

--color-scale, --colour-scale
met en évidence les niveaux de champ distinctement. Utilisez une liste séparée par des virgules(,) de all, age, size
--color-scale-mode=MODE, --colour-scale-mode=MODE
Utilise des couleurs en dégradé ou fixes dans --color-scale.

Les options valides sont fixed ou gradient. Lorsqu'il est utilisé sans valeur, la valeur par défaut est gradient.

--icons=QUAND
Affiche des icônes à côté des noms de fichiers.

Les valeurs valides sont `always', `automatic' (`auto' pour faire court) et `never'. Lorsqu'il est utilisé sans valeur, la valeur par défaut est `automatic'.

automatic ou auto affichera les icônes uniquement lorsque la sortie standard est connectée à un vrai terminal. Si eza est exécuté dans un tty, ou si la sortie de eza est redirigée vers un fichier ou envoyée dans un pipe vers un autre programme, les icônes ne seront pas utilisées. Régler cette option sur `always' fait eza toujours afficher les icônes, tandis que `never' désactive l'utilisation des icônes.

--no-quotes
Ne pas mettre les noms de fichiers contenant des espaces entre guillemets.
--hyperlink
Affiche les entrées sous forme d'hyperliens
-w, --width=COLS
Définit la largeur de l'écran en colonnes.

OPTIONS DE FILTRAGE ET DE TRI

-a, --all
Affiche les fichiers cachés et les fichiers « point ». Utilisez cette option deux fois pour afficher aussi les répertoires `.' et `..'.
-A, --almost-all
Équivalent à –all ; inclus pour la compatibilité avec ls -A.
-d, --treat-dirs-as-files
Ce drapeau, hérité de ls, change la façon dont eza traite les arguments de répertoire. Au lieu dersant dans les répertoires et en listant leur contenu (le comportement par défaut), il traite les répertoires comme des fichiers réguliers et liste les informations sur l'entrée de répertoire elle-même. C'est utile lorsque vous voulez voir les métadonnées du répertoire (par ex. permissions, taille, date de modification) plutôt que son contenu. Pour simplement lister uniquement les répertoires et pas les fichiers, envisagez d'utiliser l'option --only-dirs (-
