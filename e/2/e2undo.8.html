E2UNDO(8) Manuel de l'administrateur système E2UNDO(8)

NOM

e2undo - Rejouer un journal d'annulation pour un système de fichiers ext2/ext3/ext4

SYNTAXE

e2undo [ -f ] [ -h ] [ -n ] [ -o décalage ] [ -v ] [ -z fichier_undo ] journal_annulation périphérique

DESCRIPTION

e2undo rejouera le journal d'annulation journal_annulation pour un système de fichiers ext2/ext3/ext4 trouvé sur périphérique. Ceci peut être utilisé pour annuler une opération échouée par un programme e2fsprogs.

OPTIONS

-f
Normalement, e2undo vérifiera le superbloc du système de fichiers pour s'assurer que le journal d'annulation correspond au système de fichiers sur le périphérique. S'ils ne correspondent pas, e2undo refusera d'appliquer le journal d'annulation comme mécanisme de sécurité. L'option -f désactive ce mécanisme de sécurité.
-h
Afficher un message d'aide.
-n
Simulation ; n'écrit pas réellement les blocs dans le système de fichiers.
-o décalage
Spécifie le décalage du système de fichiers (en octets) depuis le début du périphérique ou du fichier.
-v
Rapporter le bloc en cours de rejeu.
-z fichier_undo
Avant de réécrire un bloc du système de fichiers, écrire le contenu précédent du bloc dans un fichier d'annulation. Ce fichier d'annulation peut être utilisé avec e2undo(8) pour restaurer l'ancien contenu du système de fichiers en cas de problème. Si la chaîne vide est passée comme argument fichier_undo, le fichier d'annulation sera écrit dans un fichier nommé e2undo-périphérique.e2undo dans le répertoire spécifié via la variable d'environnement E2FSPROGS_UNDO_DIR.

AVERTISSEMENT : Le fichier d'annulation ne peut pas être utilisé pour récupérer d'une panne d'alimentation ou d'un crash système.
