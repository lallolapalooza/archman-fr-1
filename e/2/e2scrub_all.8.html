NOM

e2scrub_all - vérifie tous les systèmes de fichiers ext[234] montés pour des erreurs.

SYNTAXE

e2scrub_all [OPTION]

DESCRIPTION

Recherche dans le système tous les volumes logiques LVM contenant un système de fichiers ext2, ext3 ou ext4, et vérifie s'ils présentent des problèmes. La vérification est effectuée en invoquant l'outil e2scrub, qui recherchera les corruptions. Les systèmes de fichiers corrompus seront marqués comme ayant des erreurs afin que fsck soit invoqué avant le prochain montage. Si aucune erreur n'est rencontrée, fstrim sera appelé sur le système de fichiers s'il est monté. Voir la page de manuel de e2scrub pour plus d'informations sur la manière dont la vérification est effectuée.

OPTIONS

-n
Affiche les commandes que e2scrub_all exécuterait pour initier les opérations e2scrub. (Note : ces commandes ne seront pas réellement exécutées ; cependant, comme e2scrub_all doit exécuter des commandes supplémentaires et privilégiées pour interroger le système afin de déterminer quelles commandes e2scrub seraient exécutées, il doit toujours être exécuté en tant que root.)
-r
Supprime les instantanés e2scrub mais ne vérifie rien.
-A
Scrub tous les systèmes de fichiers ext[234] même s'ils ne sont pas montés.
-V
Affiche les informations de version et quitte.
