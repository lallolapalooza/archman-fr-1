E2MMPSTATUS(8) Manuel du administrateur système E2MMPSTATUS(8)

NOM

e2mmpstatus - Vérifier le statut MMP d'un système de fichiers ext4

SYNTAXE

e2mmpstatus [-i] <systèmedefichiers>

OPTIONS

-i
affiche les informations MMP plutôt que de les vérifier.

DESCRIPTION

e2mmpstatus est utilisé pour vérifier le statut de la protection multi-montage (MMP - Multiple-Mount Protection) d'un système de fichiers ext4 avec la fonctionnalité mmp activée. Le système de fichiers spécifié peut être un nom de périphérique (par exemple /dev/hdc1, /dev/sdb2), ou une étiquette ou un UUID de système de fichiers ext4, par exemple UUID=8868abf6-88c5-4a83-98b8-bfc24057f7bd ou LABEL=root. Par défaut, le programme e2mmpstatus vérifie s'il est sûr de monter le système de fichiers sans risquer de le monter plusieurs fois.

La MMP (protection contre le montage multiple) est une fonctionnalité qui ajoute une protection contre la modification simultanée du système de fichiers par plus d'un nœud. Il N'EST PAS sûr de monter un système de fichiers si l'une des conditions suivantes est vraie :
1. e2fsck est en cours d'exécution sur le système de fichiers.
2. le système de fichiers est utilisé par un autre nœud.
3. Le bloc MMP est corrompu ou ne peut pas être lu pour une raison quelconque.
Le programme e2mmpstatus peut attendre un certain temps pour voir si le bloc MMP est mis à jour par un autre nœud pendant cette période. Le temps nécessaire dépend de la fréquence à laquelle le bloc MMP est écrit par l'autre nœud.

CODE DE SORTIE

Le code de sortie renvoyé par e2mmpstatus est 0 lorsqu'il est sûr de monter le système de fichiers, 1 lorsque le bloc MMP indique que le système de fichiers est utilisé sur un autre nœud et qu'il N'EST PAS sûr de monter le système de fichiers, et 2 si une autre erreur s'est produite qui empêche la vérification de détecter correctement le statut MMP actuel.
