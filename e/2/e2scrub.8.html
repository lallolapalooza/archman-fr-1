NOM

e2scrub - vérifier le contenu d'un système de fichiers ext[234] monté

SYNTAXE

e2scrub [OPTION] POINT_DE_MONTAGE | PRÉVOIR

DESCRIPTION

e2scrub tente de vérifier (mais pas de réparer) toutes les métadonnées d'un système de fichiers ext[234] monté si le système de fichiers réside sur un volume logique LVM. Le périphérique bloc du volume logique LVM peut également être passé en argument.

Ce programme crée un instantané (snapshot) du volume et exécute une vérification du système de fichiers sur cet instantané pour rechercher des erreurs de corruption. Le groupe de volumes LVM doit disposer d'au moins 256 Mio d'espace non alloué pour être dédié à l'instantané, sinon le volume logique sera ignoré. L'instantané sera nommé lvname.e2scrub et udev ne créera pas de liens symboliques vers celui-ci sous /dev/disk. Toutes les tentatives seront faites pour supprimer les instantanés avant d'exécuter e2scrub, mais dans une situation désespérée, il peut être nécessaire de supprimer l'instantané manuellement.

Si aucune erreur n'est trouvée, fstrim peut être appelé sur le système de fichiers s'il est monté. Si des erreurs sont trouvées, le système de fichiers sera marqué comme ayant des erreurs. Le système de fichiers doit être démonté et e2fsck exécuté dès que possible, car e2scrub ne répare pas les corruptions. Si le système de fichiers n'est pas réparé, e2fsck sera exécuté avant le prochain montage.

OPTIONS

-n
Affiche les commandes que e2scrub exécuterait pour vérifier le système de fichiers. (Note : les commandes ne seront pas réellement exécutées ; cependant, comme e2scrub doit exécuter certaines commandes pour interroger le système afin de déterminer quelles commandes seraient exécutées, il doit toujours être exécuté en tant que root.)
-r
Supprime l'instantané e2scrub et quitte sans rien vérifier.
-t
Exécute fstrim(1) sur le système de fichiers monté si aucune erreur n'est trouvée.
-V
Affiche les informations de version et quitte.

CODE DE SORTIE

Les codes de sortie sont les mêmes que dans e2fsck(8)
