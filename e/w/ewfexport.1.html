DESCRIPTIO

N

ewfexport est un utilitaire pour exporter les données média stockées dans des fichiers

EWF.

ewfexport fait partie du paquet libewf. libewf est une bibliothèque pour accéder au format de compression Expert Witness (EWF)

.

ewf_files le premier ou l'ensemble des fichiers de segment

EWF

Les options sont les suivantes

:
-A codepa
ge
la page de code de la section d'en-tête, options : ascii (par défaut), windows-874, windows-932, windows-936, windows-949, windows-950, windows-1250, windows-1251, windows-1252, windows-1253, windows-1254, windows-1255, windows-1256, windows-1257 ou
windows-1258
-b number_of_sect
ors
le nombre de secteurs à lire à la fois (par bloc), options : 16, 32, 64 (par défaut), 128, 256, 512, 1024, 2048, 4096, 8192, 16384 ou
32768
-B number_of_by
tes
le nombre d'octets à
exporter
-c compression_val
ues
spécifier les valeurs de compression sous la forme : niveau ou méthode:niveau options de méthode de compression : deflate (par défaut) options de niveau de compression : none (par défaut), empty-block, fast ou
best
-d digest_ty
pe
calculer des types de digest (hachage) supplémentaires en plus de md5, options : sha1 (non utilisé pour les formats raw et
files)
-f form
at
le format de sortie vers lequel écrire, options : raw (par défaut), files (restreint aux fichiers de volume logique), ewf, smart, ftk, encase1, encase2, encase3, encase4, encase5, encase6, encase7, encase7-v2, linen5, linen6, linen7,
ewfx.
-
h
affiche cette
aide
-l log_filena
me
journalise les erreurs d'export et le digest (hachage) dans le fichier de
journal
-o offs
et
le décalage pour commencer l'export (par défaut est
0)
-p process_buffer_s
ize
la taille du tampon de traitement (par défaut est la taille du
bloc)
-
s
échanger les paires d'octets des données média (de AB à BA) (utilisez ceci pour la conversion de big endian vers little endian et vice
versa)
-S segment_file_s
ize
la taille du fichier de segment en octets (par défaut est 1,4 Gio) (minimum est 1,0 Mio, maximum est 7,9 Eio pour les formats raw, encase6 et encase7 et 1,9 Gio pour les autres formats) (non utilisé pour le format
files)
-t targ
et
le fichier cible vers lequel exporter, utilisez - pour stdout (par défaut est export) stdout n'est pris en charge que pour le format
raw
-
u
mode non supervisé (désactive l'interaction
utilisateur)
-
v
sortie verbeuse vers
stderr
-
V
affiche la
version
-
w
met à zéro les secteurs en cas d'erreur de somme de contrôle (mimique le comportement
d'EnCase)
-
x
utilise les données du
bloc au lieu des fon
ctions de lecture et
d'écriture tamponnées.
