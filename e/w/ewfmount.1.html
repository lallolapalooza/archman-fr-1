ewfmount LOCAL ewfmount

NOM

ewfmount — monter des données stockées dans des fichiers EWF

SYNTAXE

ewfmount [-f format] [-X options_étendues] [-hvV] fichiers_ewf

DESCRIPTION

ewfmount est un utilitaire pour monter des données stockées dans des fichiers EWF.

ewfmount fait partie du paquet libewf. libewf est une bibliothèque pour accéder au format de compression Expert Witness (EWF).

fichiers_ewf le premier ou l'ensemble complet des fichiers segments EWF point_de_montage le répertoire servant de point de montage

Les options sont les suivantes :

-f format
spécifier le format d'entrée, options : raw (par défaut), files (restreint aux fichiers de volume logique)
-h
affiche cette aide
-v
sortie verbeuse sur stderr
-V
afficher la version
-X options_étendues
options étendues à passer au sous-système

ENVIRONNEMENT

Aucun

FICHIERS

Aucun

EXEMPLES

# ewfmount floppy.E01 floppy/
ewfmount 20110918

DIAGNOSTICS

Les erreurs, les sorties verbeuses et de débogage sont affichées sur stderr lorsque l'option de sortie verbeuse -v est activée. Les sorties verbeuses et de débogage ne sont affichées que lorsqu'elles sont activées à la compilation.
