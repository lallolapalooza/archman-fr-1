ewfinfo(1)

Paquet: libewf

Licences: LGPL-3.0-or-later

ewfinfo LOCAL ewfinfo

NOM

ewfinfo — affiche les métadonnées stockées dans les fichiers EWF

SYNTAXE

ewfinfo [-A codepage] [-d format_date] [-f format] [-ehimvV] fichiers_ewf

DESCRIPTION

ewfinfo est un utilitaire pour afficher les métadonnées stockées dans les fichiers EWF.

ewfinfo fait partie du paquet libewf. libewf est une bibliothèque d'accès au format de compression Expert Witness (EWF).

fichiers_ewf est le premier ou l'ensemble des fichiers segments EWF.

Les options sont les suivantes :

-A codepage
la codepage de la section d'en-tête, options : ascii (par défaut), windows-874, windows-932, windows-936, windows-949, windows-950, windows-1250, windows-1251, windows-1252, windows-1253, windows-1254, windows-1255, windows-1256, windows-1257 ou windows-1258
-d format_date
le format de date, options : ctime (par défaut), dm (jour/mois), md (mois/jour), iso8601
-e
afficher uniquement les informations d'erreur de lecture EWF
-f format
spécifier le format de sortie, options : text (par défaut), dfxml
-h
affiche cette aide
-i
afficher uniquement les informations d'acquisition EWF
-m
afficher uniquement les informations de média EWF
-v
sortie verbeuse vers stderr
-V
afficher la version

ENVIRONNEMENT

Aucun

FICHIERS

Aucun

EXEMPLES

# ewfinfo -d dm floppy.E01

DIAGNOSTICS

Les erreurs, la sortie verbeuse et le débogage sont affichés sur stderr lorsque la sortie verbeuse -v est activée. La sortie verbeuse et le débogage ne sont affichés que lorsqu'ils sont activés à la compilation.
