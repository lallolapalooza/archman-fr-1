NOM

Event::ExecFlow::Job::Command - Commande externe pour une exécution asynchrone

SYNOPSIS

Event::ExecFlow::Job::Command->new (
  command              => Commande shell à exécuter,
  fetch_output         => Booléen si la sortie doit être récupérée,
  progress_parser      => Une fermeture (closure) ou une expression régulière pour l'analyse de la progression,
  configure_callback   => Une fermeture (closure) pour configurer la commande
                          avant son exécution,
  ...
  attributs de Event::ExecFlow::Job
);

DESCRIPTION

Utilisez ce module pour l'exécution asynchrone d'une commande externe avec Event::ExecFlow.
