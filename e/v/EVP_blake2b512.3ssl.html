EVP_blake2b512(3ssl)

Paquet: openssl

Licences: Apache-2.0

EVP_BLAKE2B512(3ssl) OpenSSL EVP_BLAKE2B512(3ssl)

NOM

EVP_blake2b512, EVP_blake2s256 - BLAKE2 pour EVP

SYNTAXE

#include <openssl/evp.h>
const EVP_MD *EVP_blake2b512(void);
const EVP_MD *EVP_blake2s256(void);

DESCRIPTION

BLAKE2 est une version améliorée de BLAKE, qui a été soumise au concours d'algorithmes NIST SHA-3. Les algorithmes BLAKE2s et BLAKE2b sont décrits dans la RFC 7693.

EVP_blake2s256()
L'algorithme BLAKE2s qui produit une sortie de 256 bits à partir d'une entrée donnée.
EVP_blake2b512()
L'algorithme BLAKE2b qui produit une sortie de 512 bits à partir d'une entrée donnée.

NOTES

Les développeurs doivent être conscients des implications négatives sur les performances lors de l'appel de ces fonctions à plusieurs reprises et devraient envisager d'utiliser EVP_MD_fetch(3) avec EVP_MD-BLAKE2(7) à la place. Voir "Performance" dans crypto(7) pour plus d'informations.

Les deux algorithmes prennent en charge un résumé de longueur variable, mais ceci n'est accessible que via EVP_MD-BLAKE2(7).

VALEURS DE RETOUR

Ces fonctions retournent une structure EVP_MD qui contient l'implémentation du résumé de message. Voir EVP_MD_meth_new(3) pour les détails de la structure EVP_MD.

CONFORMITÉ

RFC 7693.

VOIR AUSSI

evp(7), EVP_DigestInit(3)
