NOM

EV::MakeMaker - Colle MakeMaker pour l'API C d'EV

SYNOPSIS

Ceci vous permet d'accéder à certaines fonctionnalités de libevent depuis d'autres modules Perl.

DESCRIPTION

Pour des performances optimales, intégrez-vous à EV au niveau C. Vous devrez apporter des modifications à votre "Makefile.PL", charger "EV" dans votre fichier "pm" et ajouter du code à vos fichiers "xs" / "c".

COMMENT FAIRE

Makefile.PL

use EV::MakeMaker qw(ev_args);
# ... configurer %args ...
WriteMakefile (ev_args (%args));

extension.pm

use EV (); # importe optionnellement

extension.xs

#include "EVAPI.h"
[...]
BOOT:
  I_EV_API (HvNAME (GvSTASH (CvGV (cv))));

API

Voir l'en-tête EVAPI.h http://cvs.schmorp.de/EV/EV/EVAPI.h, que vous devriez inclure à la place de ev.h.

En bref, toutes les fonctions et macros de ev.h devraient fonctionner, à l'exception des macros se terminant par un trait de soulignement ("EV_A_", "EV_DEFAULT_") qui ne sont pas disponibles (sauf "EV_P_" :).

La multiplicité est activée.

Le membre "data" dans chaque watcher est de type "SV *" et non "void *" (cela pourrait changer à un moment donné).

EXEMPLE

Les modules EV::Glib, EV::ADNS et Glib::EV donnent tous de bons exemples sur la manière d'utiliser ce module.

Voici quelques fragments de .xs tirés de EV::ADNS qui devraient vous mettre sur la bonne voie :

#include "EVAPI.h"
static ev_prepare pw;
static ev_idle iw;
static void
idle_cb (EV_P_ ev_idle *w, int revents)
{
  ev_idle_stop (EV_A, w);
}
MODULE = ...
BOOT:
{
  I_EV_API ("EV::ADNS");
  ev_prepare_init (&pw, prepare_cb);
  ev_init (&iw, idle_cb); ev_set_priority (&iw, EV_MINPRI);
  ev_idle_start (EV_DEFAULT, &iw);
}
