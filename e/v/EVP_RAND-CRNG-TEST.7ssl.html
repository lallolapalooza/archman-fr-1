NOM

EVP_RAND-CRNG-TEST - Le filtre de test de santé FIPS EVP_RAND

DESCRIPTION

Cet objet EVP_RAND agit comme un filtre entre la source d'entropie et ses utilisateurs. Il effectue des tests de santé CRNG tels que définis dans SP 800-90B https://csrc.nist.gov/pubs/sp/800/90/b/final Section 4 "Health Tests". La plupart des requêtes sont transmises à la source d'entropie, soit via sa référence parente, soit via les appels de remontée d'entropie du fournisseur.

Identité

"CRNG-TEST" est le nom de cette implémentation ; il peut être utilisé avec la fonction EVP_RAND_fetch().

Paramètres pris en charge

Si un EVP_RAND parent est spécifié lors de la création du contexte, les paramètres du parent sont pris en charge car la requête est transmise à la source de semence parente pour traitement.

Si aucun EVP_RAND parent n'est spécifié lors de la création du contexte, les paramètres suivants sont pris en charge :

"state" (OSSL_RAND_PARAM_STATE) <entier>
"strength" (OSSL_RAND_PARAM_STRENGTH) <entier non signé>
"max_request" (OSSL_RAND_PARAM_MAX_REQUEST) <entier non signé>
Ces paramètres fonctionnent comme décrit dans "PARAMETERS" dans EVP_RAND(3).
"fips-indicator" (OSSL_DRBG_PARAM_FIPS_APPROVED_INDICATOR) <entier>
Ce paramètre fonctionne comme décrit dans "PARAMETERS" dans provider-rand(7).

NOTES

Cet EVP_RAND n'est implémenté que par le fournisseur FIPS OpenSSL.

Un contexte pour un filtre de test de santé peut être obtenu en appelant :

EVP_RAND *parent = ...;
EVP_RAND *rand = EVP_RAND_fetch(NULL, "CRNG-TEST", NULL);
EVP_RAND_CTX *rctx = EVP_RAND_CTX_new(rand, parent);
