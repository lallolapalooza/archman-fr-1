NOM

Event::ExecFlow::Job - Classe de base abstraite pour toutes les classes de job

SYNOPIS

Event::ExecFlow::Job->new (
  title                => Titre descriptif,
  name                 => Nom interne court,
  depends_on           => Noms des jobs dont ce job dépend,
  progress_max         => Valeur maximale attendue de la progression,
  progress_ips         => Chaîne à afficher comme « éléments par seconde »,
  no_progress          => Le job n'a pas d'état de progression du tout,
  pre_callbacks        => Callbacks exécutés avant le démarrage du job,
  post_callbacks       => Callbacks exécutés après la fin du job,
  error_callbacks      => Callbacks exécutés si le job a eu des erreurs,
  warning_callbacks    => Callbacks exécutés si le job a eu des avertissements,
  stash                => Un hachage de données personnalisé stocké avec le job,
);

DESCRIPTION

Ceci est une classe de base abstraite et n'est généralement pas utilisée directement par l'application. Pour la programmation quotidienne, les attributs définis dans cette classe sont les plus importants, car ils sont communs à tous les Jobs du framework Event::ExecFlow.
