NOM

EVP_SIGNATURE-HMAC, EVP_SIGNATURE-Siphash, EVP_SIGNATURE-Poly1305, EVP_SIGNATURE-CMAC - Les implémentations de signature MAC héritées d'EVP_PKEY

DESCRIPTION

Les algorithmes décrits ici ont un support hérité pour la création de MACs en utilisant EVP_DigestSignInit(3) et les fonctions associées. Ce n'est pas la manière préférée de créer des MACs. Vous devriez plutôt utiliser les nouvelles fonctions EVP_MAC_init(3). Ce mécanisme est fourni pour la compatibilité descendante avec les anciennes versions d'OpenSSL.

Les mêmes paramètres de signature peuvent être définis en utilisant EVP_PKEY_CTX_set_params() que ceux qui peuvent être définis via EVP_MAC_CTX_set_params() pour l'EVP_MAC sous-jacent. Voir EVP_MAC-HMAC(7), EVP_MAC-Siphash(7), EVP_MAC-Poly1305(7) et EVP_MAC-CMAC(7) pour plus de détails.

Voir L<EVP_PKEY-HMAC(7)>, L<EVP_PKEY-Siphash(7)>, L<EVP_PKEY-Poly1305(7)> ou
L<EVP_PKEY-CMAC(7)> pour les détails sur les paramètres supportés lors de la
création d'un EVP_PKEY.
