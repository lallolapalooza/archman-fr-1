DESCRIPTIO

N

Toutes les fonctions décrites sur cette page sont obsolètes. Les applications devraient plutôt utiliser les API

OSSL_PROVIDER.

EVP_PKEY_METHOD est une structure qui contient un ensemble de méthodes pour un algorithme cryptographique de clé publique spécifique. Ces méthodes sont généralement utilisées pour effectuer différentes tâches, telles que la génération d'une clé, la signature ou la vérification, le chiffrement ou le déchiffrement,

etc.

Il existe deux endroits où les objets EVP_PKEY_METHOD sont stockés : l'un est un tableau statique intégré représentant les méthodes standard pour différents algorithmes, et l'autre est une pile de méthodes spécifiques à l'application définies par l'utilisateur, qui peuvent être manipulées en utilisant EVP_PKEY_meth_a

dd0(3).

Les objets EVP_PKEY_METHOD sont généralement référencés par des objets EVP_P

KEY_CTX.

Fonction

s

EVP_PKEY_meth_new() crée et retourne un nouvel objet EVP_PKEY_METHOD, et associe l' id et les flags donnés. Les drapeaux suivants sont pris en charge

: 
EVP_PKEY_FLAG_AUTOARGLEN
EVP_PKEY_FLAG_SIGCTX_CUSTO
M

Si un EVP_PKEY_METHOD est défini avec le drapeau EVP_PKEY_FLAG_AUTOARGLEN, la taille maximale du tampon de sortie sera automatiquement calculée ou vérifiée dans les méthodes EVP correspondantes par le framework EVP. Ainsi, les implémentations de ces méthodes n'ont pas besoin de se soucier de gérer elles-mêmes le cas du retour de la taille du tampon de sortie. Pour plus de détails sur la taille du tampon de sortie, voir EVP_PKEY_si

gn(3).

Le EVP_PKEY_FLAG_SIGCTX_CUSTOM est utilisé pour indiquer que la méthode signctx() d'un EVP_PKEY_METHOD est toujours appelée par le framework EVP lors d'une opération de signature de digest en appelant EVP_DigestSignF

inal(3).

EVP_PKEY_meth_free() libère un EVP_PKEY_METHOD existant pointé par pmeth. Si l'argument est NULL, rien n'est

fait.

EVP_PKEY_meth_copy() copie un objet EVP_PKEY_METHOD de src vers dst

.

EVP_PKEY_meth_find() trouve un objet EVP_PKEY_METHOD avec l' id. Cette fonction recherche d'abord à travers les objets de méthode définis par l'utilisateur puis les objets

intégrés.

EVP_PKEY_meth_add0() ajoute pmeth à la pile de méthodes définie par

l'utilisateur.

EVP_PKEY_meth_remove() supprime un objet EVP_PKEY_METHOD ajouté par EVP_PKEY_meth_

add0().

Les fonctions EVP_PKEY_meth_set définissent les champs correspondants de la structure EVP_PKEY_METHOD avec les arguments

passés.

Les fonctions EVP_PKEY_meth_get récupèrent les champs correspondants de la structure EVP_PKEY_METHOD d

ans les a
rguments
fournis.

VALEURS DE

RETOUR

EVP_PKEY_meth_new() retourne un pointeur vers un nouvel objet EVP_PKEY_METHOD ou retourne NULL en cas

d'erreur.

EVP_PKEY_meth_free() et EVP_PKEY_meth_copy() ne retournent pas de

valeurs.

EVP_PKEY_meth_find() retourne un pointeur vers l'objet EVP_PKEY_METHOD trouvé ou retourne NULL s'il n'est pas

trouvé.

EVP_PKEY_meth_add0() retourne 1 si la méthode est ajoutée avec succès ou 0 si une erreur est

survenue.

EVP_PKEY_meth_remove() retourne 1 si la méthode est supprimée avec succès ou 0 si une erreur est

survenue.

Toutes les fonctions EVP_PKEY_meth_set et EVP_PKEY_meth_get n'

ont pas de valeurs de retour. Pour les fonctions « get », l
es pointeurs de fonction sont retournés par les arguments.
