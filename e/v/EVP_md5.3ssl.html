NOM

EVP_md5, EVP_md5_sha1 - MD5 pour EVP

SYNOPIS

#include <openssl/evp.h>
const EVP_MD *EVP_md5(void);
const EVP_MD *EVP_md5_sha1(void);

DESCRIPTION

MD5 est une fonction de hachage cryptographique standardisée dans la RFC 1321 et conçue par Ronald Rivest.

Le CMU Software Engineering Institute considère que MD5 n'est plus adapté à une utilisation future car sa sécurité a été gravement compromise.

EVP_md5()
L'algorithme MD5 qui produit une sortie de 128 bits à partir d'une entrée donnée.
EVP_md5_sha1()
Un algorithme de hachage de SSL v3 qui combine MD5 avec SHA-1 tel que décrit dans la RFC 6101.

AVERTISSEMENT : cet algorithme n'est pas destiné à un usage autre que SSL.

NOTES

Les développeurs doivent être conscients des implications négatives sur les performances lors de l'appel répété de ces fonctions et devraient envisager d'utiliser EVP_MD_fetch(3) avec EVP_MD-MD5(7) ou EVP_MD-MD5-SHA1(7) à la place. Voir "Performance" dans crypto(7) pour plus d'informations.

VALEURS DE RETOUR

Ces fonctions renvoient une structure EVP_MD qui contient l'implémentation du résumé de message. Voir EVP_MD_meth_new(3) pour les détails de la structure EVP_MD.

CONFORMITÉ

IETF RFC 1321.

VOIR AUSSI

evp(7), EVP_DigestInit(3)
