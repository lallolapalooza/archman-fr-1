EVP_PKEY_print_private(3ssl)

Paquet: openssl

Licences: Apache-2.0

EVP_PKEY_PRINT_PRIVATE(3ssl) OpenSSL EVP_PKEY_PRINT_PRIVATE(3ssl)

NOM

EVP_PKEY_print_public, EVP_PKEY_print_private, EVP_PKEY_print_params, EVP_PKEY_print_public_fp, EVP_PKEY_print_private_fp, EVP_PKEY_print_params_fp - routines d'impression d'algorithmes de clé publique

SYNTAXE

#include <openssl/evp.h>
int EVP_PKEY_print_public(BIO *out, const EVP_PKEY *pkey,
                          int indent, ASN1_PCTX *pctx);
int EVP_PKEY_print_public_fp(FILE *fp, const EVP_PKEY *pkey,
                             int indent, ASN1_PCTX *pctx);
int EVP_PKEY_print_private(BIO *out, const EVP_PKEY *pkey,
                           int indent, ASN1_PCTX *pctx);
int EVP_PKEY_print_private_fp(FILE *fp, const EVP_PKEY *pkey,
                              int indent, ASN1_PCTX *pctx);
int EVP_PKEY_print_params(BIO *out, const EVP_PKEY *pkey,
                          int indent, ASN1_PCTX *pctx);
int EVP_PKEY_print_params_fp(FILE *fp, const EVP_PKEY *pkey,
                             int indent, ASN1_PCTX *pctx);

DESCRIPTION

Les fonctions EVP_PKEY_print_public(), EVP_PKEY_print_private() et EVP_PKEY_print_params() impriment les composantes publiques, privées ou les paramètres de la clé pkey respectivement. La clé est envoyée au BIO out sous forme lisible par l'homme. Le paramètre indent indique le niveau d'indentation de l'impression.

Le paramètre pctx permet d'affiner la sortie d'impression en utilisant des options d'impression ASN1. Si pctx est mis à NULL, les valeurs par défaut seront utilisées.

Les fonctions EVP_PKEY_print_public_fp(), EVP_PKEY_print_private_fp() et EVP_PKEY_print_params_fp() font la même chose que les fonctions basées sur BIO mais utilisent un fichier FILE fp à la place.

NOTES

Actuellement, aucun algorithme de clé publique n'inclut d'options dans le paramètre pctx.

Si la clé ne contient pas toutes les composantes indiquées par la fonction, seules celles contenues dans la clé seront imprimées. Par exemple, passer une clé publique à EVP_PKEY_print_private() n'imprimera que les composantes publiques.

VALEURS DE RETOUR

Ces fonctions retournent toutes 1 en cas de succès et 0 ou une valeur négative en cas d'échec. En particulier, une valeur de retour de -2 indique que l'opération n'est pas supportée par l'algorithme de clé publique.

VOIR AUSSI

EVP_PKEY_CTX_new(3), EVP_PKEY_keygen(3)

HISTORIQUE

Les fonctions EVP_PKEY_print_public(), EVP_PKEY_print_private(), et EVP_PKEY_print_params() ont été ajoutées dans OpenSSL 1.0.0.

Les fonctions EVP_PKEY_print_public_fp(), EVP_PKEY_print_private_fp(), et EVP_PKEY_print_params_fp() ont été ajoutées dans OpenSSL 3.0.
