DESCRIPTIO

N

Les routines de digest EVP sont une interface de haut niveau pour les empreintes de message (message digests) et les fonctions de sortie extensible (XOF)

.

Le type EVP_MD est une structure pour l'implémentation de la méthode de

digest.

Chaque algorithme d'empreinte de message (tel que SHA256) produit une longueur de sortie de taille fixe qui est retournée lorsque EVP_DigestFinal_ex() est appelé. Les fonctions de sortie extensible (XOF) telles que SHAKE256 ont une longueur de sortie de taille variable outlen qui peut être utilisée avec soit EVP_DigestFinalXOF() ou EVP_DigestSqueeze(). EVP_DigestFinal_ex() peut également être utilisé pour un XOF, mais "xoflen" doit être défini au préalable (Voir « PARAMETERS »). Notez que EVP_MD_get_size() et EVP_MD_CTX_get_size_ex() se comportent différemment pour un

XOF.

NOTE

S

L'interface EVP pour les messages digests doit presque toujours être utilisée de préférence aux interfaces de bas niveau. En effet, le code devient alors transparent vis-à-vis du digest utilisé et beaucoup plus

flexible.

Les nouvelles applications devraient utiliser les algorithmes SHA-2 (tels que EVP_sha256(3)) ou les algorithmes de digest SHA-3 (tels que EVP_sha3_512(3)). Les autres algorithmes de digest sont toujours couramment

utilisés.

Pour la plupart des applications, le paramètre impl de EVP_DigestInit_ex() sera défini à NULL pour utiliser l'implémentation de digest par

défaut.

Ignorer les codes de retour d'échec de EVP_DigestInit_ex(), EVP_DigestInit_ex2() ou EVP_DigestInit() peut entraîner un comportement indéfini lors des appels suivants mettant à jour ou finalisant le EVP_MD_CTX, comme les fonctions EVP_DigestUpdate() ou EVP_DigestFinal(). Les seuls appels valides sur le EVP_MD_CTX lorsque l'initialisation échoue sont les appels qui tentent une autre initialisation du contexte ou libèrent le

contexte.

Les fonctions EVP_DigestInit(), EVP_DigestFinal() et EVP_MD_CTX_copy() sont obsolètes mais sont conservées pour maintenir la compatibilité avec le code existant. Les nouvelles applications devraient utiliser EVP_DigestInit_ex(), EVP_DigestFinal_ex() et EVP_MD_CTX_copy_ex() car elles peuvent réutiliser efficacement un contexte de digest au lieu de l'initialiser et de le nettoyer à chaque appel, et permettent de spécifier des implémentations de digests non par

défaut.

Si les contextes de digest ne sont pas nettoyés après utilisation, des fuites de mémoire se

produiront.

EVP_MD_CTX_get0_name(), EVP_MD_CTX_get_size(), EVP_MD_CTX_get_block_size(), EVP_MD_CTX_get_type(), EVP_get_digestbynid() et EVP_get_digestbyobj() sont définies comme des

macros.

EVP_MD_CTX_ctrl() envoie des commandes aux messages digest

s pour une configuration o
u un contrôle supplémentaire.

EXEMPLE

S

Cet exemple calcule le message digest des données "Test Message\n" et "Hello World\n", en utilisant le nom du digest passé sur la ligne de

commande. 
#include <stdio.h>
#include <string.h>
#include <openssl/evp.h>
int main(int argc, char *argv[])
{
    EVP_MD_CTX *mdctx;
    const EVP_MD *md;
    char mess1[] = "Test Message\n";
    char mess2[] = "Hello World\n";
    unsigned char md_value[EVP_MAX_MD_SIZE];
    unsigned int md_len, i;
    if (argv[1] == NULL) {
        printf("Usage: mdtest digestname\n");
        exit(1);
    }
    md = EVP_get_digestbyname(argv[1]);
    if (md == NULL) {
        printf("Unknown message digest %s\n", argv[1]);
        exit(1);
    }
    mdctx = EVP_MD_CTX_new();
    if (mdctx == NULL) {
       printf("Message digest create failed.\n");
       exit(1);
    }
    if (!EVP_DigestInit_ex2(mdctx, md, NULL)) {
        printf("Message digest initialization failed.\n");
        EVP_MD_CTX_free(mdctx);
        exit(1);
    }
    if (!EVP_DigestUpdate(mdctx, mess1, strlen(mess1))) {
        printf("Message digest update failed.\n");
        EVP_MD_CTX_free(mdctx);
        exit(1);
    }
    if (!EVP_DigestUpdate(mdctx, mess2, strlen(mess2))) {
        printf("Message digest update failed.\n");
        EVP_MD_CTX_free(mdctx);
        exit(1);
    }
    if (!EVP_DigestFinal_ex(mdctx, md_value, &md_len)) {
        printf("Message digest finalization failed.\n");
        EVP_MD_CTX_free(mdctx);
        exit(1);
    }
    EVP_MD_CTX_free(mdctx);
    printf("Digest is: ");
    for (i = 0; i < md_len; i++)
        printf("%02x", md_value[i]);
    printf("\n");
    exit(0);
}
