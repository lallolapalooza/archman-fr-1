NOM

EVP_MD-NULL - L'implémentation NULL d'EVP_MD

DESCRIPTION

Support d'un digest NULL via l'API EVP_MD. Cet algorithme ne fait rien et retourne 1 pour ses méthodes init, update et final.

Nom de l'algorithme

L'algorithme suivant est disponible dans le fournisseur par défaut :

"NULL"

Paramètres pouvant être récupérés

Cette implémentation supporte les paramètres communs récupérables décrits dans EVP_MD-common(7).

VOIR AUSSI

EVP_MD_CTX_set_params(3), provider-digest(7), OSSL_PROVIDER-default(7)
