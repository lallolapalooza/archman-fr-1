EVP_PKEY_set1_encoded_public_key(3ssl)

Paquet: openssl

Licences: Apache-2.0

EVP_PKEY_SET1_ENCODED_PUBLIC_KEY(3ssl) OpenSSL EVP_PKEY_SET1_ENCODED_PUBLIC_KEY(3ssl)

NOM

EVP_PKEY_set1_encoded_public_key, EVP_PKEY_get1_encoded_public_key, EVP_PKEY_set1_tls_encodedpoint, EVP_PKEY_get1_tls_encodedpoint - fonctions pour définir et récupérer les données de clé publique au sein d'un EVP_PKEY

SYNOPSIS

#include <openssl/evp.h>
int EVP_PKEY_set1_encoded_public_key(EVP_PKEY *pkey,
                                     const unsigned char *pub, size_t publen);
size_t EVP_PKEY_get1_encoded_public_key(EVP_PKEY *pkey, unsigned char **ppub);

Les fonctions suivantes sont obsolètes depuis OpenSSL 3.0 et peuvent être entièrement masquées en définissant OPENSSL_API_COMPAT avec une valeur de version appropriée, voir openssl_user_macros(7):

int EVP_PKEY_set1_tls_encodedpoint(EVP_PKEY *pkey,
                                   const unsigned char *pt, size_t ptlen);
size_t EVP_PKEY_get1_tls_encodedpoint(EVP_PKEY *pkey, unsigned char **ppt);

DESCRIPTION

EVP_PKEY_set1_encoded_public_key() peut être utilisé pour définir la valeur de la clé publique au sein d'un objet EVP_PKEY existant qui n'a encore ni clé publique ni clé privée assignée. Pour les algorithmes OpenSSL intégrés, cela ne fonctionne actuellement que pour ceux qui prennent en charge l'échange de clés ou l'encapsulation de clés. Les paramètres ne sont pas définis dans le cadre de cette opération, donc généralement une application créera d'abord un EVP_PKEY, définira les paramètres dessus, puis appellera cette fonction. Par exemple, la définition des paramètres pourrait se faire à l'aide de EVP_PKEY_copy_parameters(3).

Le format de la clé publique encodée dépendra de l'algorithme utilisé. Pour DH, elle doit être encodée sous forme d'entier positif en big-endian. Pour EC, il doit s'agir d'un point conforme à la Sec. 2.3.4 de la norme SECG SEC 1 (« Elliptic Curve Cryptography »). Pour X25519 et X448 elle doit être encodée dans le format défini par RFC7748. Pour ML-KEM-512, ML-KEM-768 et ML-KEM-1024, il s'agit du format de clé publique défini dans FIPS 203 (le vecteur public encodé sur 12 bits par coefficient t et la graine de matrice de 32 octets rho).

La clé à mettre à jour est fournie dans pkey. Le tampon contenant la clé encodée est pointé par pub. La longueur du tampon est fournie dans publen.

EVP_PKEY_get1_encoded_public_key() effectue l'opération équivalente, sauf que la clé publique encodée est renvoyée à l'application. La clé contenant les données de clé publique est fournie dans pkey. Un tampon contenant la clé encodée sera alloué et stocké dans *ppub. La longueur de la clé publique encodée est renvoyée par la fonction. L'application est responsable de la libération du tampon alloué.

La macro EVP_PKEY_set1_tls_encodedpoint() est obsolète et appelle simplement EVP_PKEY_set1_encoded_public_key() avec tous les mêmes arguments. Les nouvelles applications devraient utiliser EVP_PKEY_set1_encoded_public_key() à la place.

La macro EVP_PKEY_get1_tls_encodedpoint() est obsolète et appelle simplement EVP_PKEY_get1_encoded_public_key() avec tous les mêmes arguments. Les nouvelles applications devraient utiliser EVP_PKEY_get1_encoded_public_key() à la place.

VALEURS RENVOYÉES

EVP_PKEY_set1_encoded_public_key() renvoie 1 en cas de succès et 0 ou une valeur négative en cas d'échec.

EVP_PKEY_get1_encoded_public_key() renvoie la longueur de la clé encodée ou 0 en cas d'échec.

EXEMPLES

Voir EVP_PKEY_derive_init(3) et EVP_PKEY_derive(3) pour des informations sur la réalisation d'une opération d'échange de clés.

Configurer l'EVP_PKEY d'un pair prêt pour une opération d'échange de clés

#include <openssl/evp.h>
int exchange(EVP_PKEY *ourkey, unsigned char *peer_pub, size_t peer_pub_len)
{
    EVP_PKEY *peerkey = EVP_PKEY_new();
    if (peerkey == NULL || EVP_PKEY_copy_parameters(peerkey, ourkey) <= 0)
        return 0;
    if (EVP_PKEY_set1_encoded_public_key(peerkey, peer_pub,
                                         peer_pub_len) <= 0)
        return 0;
    /* Do the key exchange here */
    EVP_PKEY_free(peerkey);
    return 1;
}

Obtenir une clé publique encodée à envoyer à un pair

#include <openssl/evp.h>
int get_encoded_pub_key(EVP_PKEY *ourkey)
{
    unsigned char *pubkey;
    size_t pubkey_len;
   pubkey_len = EVP_PKEY_get1_encoded_public_key(ourkey, &pubkey);
   if (pubkey_len == 0)
       return 0;
   /*
    * Send the encoded public key stored in the buffer at "pubkey" and of
    * length pubkey_len, to the peer.
    */
   OPENSSL_free(pubkey);
   return 1;
}

HISTORIQUE

EVP_PKEY_set1_encoded_public_key() et EVP_PKEY_get1_encoded_public_key() ont été ajoutés dans OpenSSL 3.0.

EVP_PKEY_set1_tls_encodedpoint() et EVP_PKEY_get1_tls_encodedpoint() sont devenus obsolètes dans OpenSSL 3.0.

La prise en charge de ML-KEM a été ajoutée dans OpenSSL 3.5.
