NOM

Event::ExecFlow::Job::Code - Exécuter une fermeture

SYNOPSIS

Event::ExecFlow::Job::Code->new (
  code     => Fermeture à exécuter,
  ...
  attributs de Event::ExecFlow::Job
);

DESCRIPTION

Utilisez ce module pour exécuter du code Perl arbitraire (passé sous forme de fermeture) au sein d'un Event::ExecFlow.
