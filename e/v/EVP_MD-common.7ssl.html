NOM

EVP_MD-common - Les implémentations EVP_MD d'OpenSSL, choses communes

DESCRIPTION

Toutes les implémentations EVP_MD d'OpenSSL comprennent les entrées OSSL_PARAM(3) suivantes qui peuvent être récupérées avec EVP_MD_get_params(3), ainsi que celles-ci :

"blocksize" (OSSL_DIGEST_PARAM_BLOCK_SIZE) <entier non signé>
La taille du bloc de hachage. La longueur du paramètre "blocksize" ne doit pas dépasser celle d'un size_t.

Cette valeur peut également être récupérée avec EVP_MD_get_block_size(3).

"size" (OSSL_DIGEST_PARAM_SIZE) <entier non signé>
La taille de sortie du hachage. La longueur du paramètre "size" ne doit pas dépasser celle d'un size_t.

Cette valeur peut également être récupérée avec EVP_MD_get_size(3).

"flags" (OSSL_DIGEST_PARAM_FLAGS) <entier non signé>
Divers drapeaux décrivant un comportement exceptionnel pour le hachage. Ces drapeaux sont décrits dans "DESCRIPTION" dans EVP_MD_meth_set_flags(3).

La longueur du paramètre "flags" doit être égale à celle d'un unsigned long int.

Cette valeur peut également être récupérée avec EVP_MD_get_flags(3).

VOIR AUSSI

"PARAMETERS" dans EVP_DigestInit(3), EVP_MD_get_params(3), provider-digest(7)
