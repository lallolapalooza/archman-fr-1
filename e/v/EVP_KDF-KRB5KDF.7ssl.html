NOM

EVP_KDF-KRB5KDF - Implémentation EVP_KDF du KDF RFC3961 Krb5KDF

DESCRIPTION

Prise en charge du calcul du KDF KRB5KDF via l'API EVP_KDF.

L'algorithme EVP_KDF-KRB5KDF implémente la fonction de dérivation de clé définie dans la RFC 3961, section 5.1, et est utilisé par Krb5 pour dériver les clés de session. Trois entrées sont nécessaires pour effectuer la dérivation de clé : un chiffrement (par exemple AES-128-CBC), la clé initiale et une constante.

Identité

"KRB5KDF" est le nom de cette implémentation ; il peut être utilisé avec la fonction EVP_KDF_fetch().

Paramètres supportés

Les paramètres supportés sont :

"properties" (OSSL_KDF_PARAM_PROPERTIES) <chaîne UTF8>
"cipher" (OSSL_KDF_PARAM_CIPHER) <chaîne UTF8>
"key" (OSSL_KDF_PARAM_KEY) <chaîne d'octets>
Ces paramètres fonctionnent comme décrit dans "PARAMÈTRES" dans EVP_KDF(3).
"constant" (OSSL_KDF_PARAM_CONSTANT) <chaîne d'octets>
Ce paramètre définit la valeur constante pour le KDF. Si une valeur est déjà définie, son contenu est remplacé.

NOTES

Un contexte pour KRB5KDF peut être obtenu en appelant :

EVP_KDF *kdf = EVP_KDF_fetch(NULL, "KRB5KDF", NULL);
EVP_KDF_CTX *kctx = EVP_KDF_CTX_new(kdf);

La longueur de sortie de la dérivation KRB5KDF est spécifiée via le paramètre keylen de la fonction EVP_KDF_derive(3), et DOIT correspondre à la longueur de clé du chiffrement choisi, sinon une erreur est retournée. De plus, la longueur de la constante ne doit pas dépasser la taille de bloc du chiffrement. Étant donné que la longueur de sortie de KRB5KDF dépend du chiffrement choisi, l'appel à EVP_KDF_CTX_get_kdf_size(3) pour obtenir la longueur requise ne renvoie la longueur correcte qu'après que le chiffrement ait été défini. Avant cela, EVP_MAX_KEY_LENGTH est renvoyé. L'appelant doit allouer un tampon de la longueur correcte pour le chiffrement choisi et passer ce tampon à la fonction EVP_KDF_derive(3) avec cette longueur.

EXEMPLES

Cet exemple dérive une clé en utilisant le chiffrement AES-128-CBC :

EVP_KDF *kdf;
EVP_KDF_CTX *kctx;
unsigned char key[16] = "01234...";
unsigned char constant[] = "Je suis une constante";
unsigned char out[16];
size_t outlen = sizeof(out);
OSSL_PARAM params[4], *p = params;
kdf = EVP_KDF_fetch(NULL, "KRB5KDF", NULL);
kctx = EVP_KDF_CTX_new(kdf);
EVP_KDF_free(kdf);
*p++ = OSSL_PARAM_construct_utf8_string(OSSL_KDF_PARAM_CIPHER,
                                        SN_aes_128_cbc,
                                        strlen(SN_aes_128_cbc));
*p++ = OSSL_PARAM_construct_octet_string(OSSL_KDF_PARAM_KEY,
                                         key, (size_t)16);
*p++ = OSSL_PARAM_construct_octet_string(OSSL_KDF_PARAM_CONSTANT,
                                         constant, strlen(constant));
*p = OSSL_PARAM_construct_end();
if (EVP_KDF_derive(kctx, out, outlen, params) <= 0)
    /* Erreur */
EVP_KDF_CTX_free(kctx);
