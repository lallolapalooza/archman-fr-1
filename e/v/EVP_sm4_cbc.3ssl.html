EVP_sm4_cbc(3ssl)

EVP_SM4_CBC(3ssl) OpenSSL EVP_SM4_CBC(3ssl)

NOM

EVP_sm4_cbc, EVP_sm4_ecb, EVP_sm4_cfb, EVP_sm4_cfb128, EVP_sm4_ofb, EVP_sm4_ctr - Chiffre SM4 EVP

SYNOPSIS

#include <openssl/evp.h>
const EVP_CIPHER *EVP_sm4_cbc(void);
const EVP_CIPHER *EVP_sm4_ecb(void);
const EVP_CIPHER *EVP_sm4_cfb(void);
const EVP_CIPHER *EVP_sm4_cfb128(void);
const EVP_CIPHER *EVP_sm4_ofb(void);
const EVP_CIPHER *EVP_sm4_ctr(void);

DESCRIPTION

Le chiffrement par bloc SM4 (GB/T 32907-2016) pour EVP.

Tous les modes ci-dessous utilisent une longueur de clé de 128 bits et agissent sur des blocs de 128 bits.

EVP_sm4_cbc(), EVP_sm4_ecb(), EVP_sm4_cfb(), EVP_sm4_cfb128(), EVP_sm4_ofb(), EVP_sm4_ctr()
Le chiffrement par bloc SM4 avec une clé de 128 bits en modes CBC, ECB, CFB, OFB et CTR respectivement.

NOTES

Les développeurs doivent être conscients des implications négatives en termes de performances de l'appel de ces fonctions à plusieurs reprises et devraient envisager d'utiliser EVP_CIPHER_fetch(3) avec EVP_CIPHER-SM4(7) à la place. Voir "Performances" dans crypto(7) pour plus d'informations.

VALEUR RETOUR

Ces fonctions retournent une structure EVP_CIPHER qui contient l'implémentation du chiffrement symétrique. Voir EVP_CIPHER_meth_new(3) pour les détails de la structure EVP_CIPHER.

VOIR AUSSI

evp(7), EVP_EncryptInit(3), EVP_CIPHER_meth_new(3)
