NOM

EVP_desx_cbc - Chiffrement DES-X d'EVP

SYNOPSIS

#include <openssl/evp.h>
const EVP_CIPHER *EVP_desx_cbc(void);

DESCRIPTION

L'algorithme de chiffrement DES-X pour EVP.

Tous les modes ci-dessous utilisent une clé de 128 bits et opèrent sur des blocs de 128 bits.

EVP_desx_cbc()
L'algorithme DES-X en mode CBC.

Cet algorithme n'est pas fourni par le fournisseur par défaut d'OpenSSL. Pour l'utiliser, il est nécessaire de charger soit le fournisseur hérité d'OpenSSL, soit une autre implémentation.

Les développeurs doivent être conscients des implications négatives sur les performances de l'appel de cette fonction plusieurs fois et devraient envisager d'utiliser EVP_CIPHER_fetch(3) avec EVP_CIPHER-DES(7) à la place. Voir "Performance" dans crypto(7) pour plus d'informations.

VALEUR DE RETOUR

Ces fonctions retournent une structure EVP_CIPHER qui contient l'implémentation du chiffrement symétrique. Voir EVP_CIPHER_meth_new(3) pour les détails de la structure EVP_CIPHER.

VOIR AUSSI

evp(7), EVP_EncryptInit(3), EVP_CIPHER_meth_new(3)
