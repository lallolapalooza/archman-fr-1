EVP_cast5_cbc(3ssl)

Paquet: openssl

Licences: Apache-2.0

EVP_cast5_cbc(3ssl) OpenSSL EVP_cast5_cbc(3ssl)

NOM

EVP_cast5_cbc, EVP_cast5_cfb, EVP_cast5_cfb64, EVP_cast5_ecb, EVP_cast5_ofb - Chiffrement CAST EVP

SYNTAXIS

#include <openssl/evp.h>
const EVP_CIPHER *EVP_cast5_cbc(void);
const EVP_CIPHER *EVP_cast5_cfb(void);
const EVP_CIPHER *EVP_cast5_cfb64(void);
const EVP_CIPHER *EVP_cast5_ecb(void);
const EVP_CIPHER *EVP_cast5_ofb(void);

DESCRIPTION

Algorithme de chiffrement CAST pour EVP.

Il s'agit d'un chiffrement à longueur de clé variable.

EVP_cast5_cbc(), EVP_cast5_ecb(), EVP_cast5_cfb(), EVP_cast5_cfb64(), EVP_cast5_ofb()
Algorithme de chiffrement CAST en mode CBC, ECB, CFB et OFB respectivement.

NOTES

Les développeurs doivent être conscients des implications négatives sur les performances lors de l'appel de ces fonctions plusieurs fois et devraient envisager d'utiliser EVP_CIPHER_fetch(3) avec EVP_CIPHER-CAST(7) à la place. Voir « Performance » dans crypto(7) pour plus d'informations.

VALEURS DE RETOUR

Ces fonctions retournent une structure EVP_CIPHER qui contient l'implémentation du chiffrement symétrique. Voir EVP_CIPHER_meth_new(3) pour les détails de la structure EVP_CIPHER.

VOIR AUSSI

evp(7), EVP_EncryptInit(3), EVP_CIPHER_meth_new(3)
