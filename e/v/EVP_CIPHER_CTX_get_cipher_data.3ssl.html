EVP_CIPHER_CTX_get_cipher_data(3ssl)

Paquet: openssl

Licences: Apache-2.0

EVP_CIPHER_CTX_GET_CIPHER_DATA(3ssl) OpenSSL EVP_CIPHER_CTX_GET_CIPHER_DATA(3ssl)

NOM

EVP_CIPHER_CTX_get_cipher_data, EVP_CIPHER_CTX_set_cipher_data - Procédures pour inspecter et modifier les objets EVP_CIPHER_CTX

SYNTAXE

#include <openssl/evp.h>
void *EVP_CIPHER_CTX_get_cipher_data(const EVP_CIPHER_CTX *ctx);
void *EVP_CIPHER_CTX_set_cipher_data(EVP_CIPHER_CTX *ctx, void *cipher_data);

DESCRIPTION

La fonction EVP_CIPHER_CTX_get_cipher_data() retourne un pointeur vers les données de chiffrement pertinentes pour EVP_CIPHER_CTX. Le contenu de ces données est spécifique à l'implémentation particulière du chiffrement. Par exemple, ces données peuvent être utilisées par les moteurs pour stocker des informations spécifiques au moteur. Les données sont automatiquement allouées et libérées par OpenSSL, donc les applications et les moteurs ne devraient normalement pas les libérer directement (mais voir ci-dessous).

La fonction EVP_CIPHER_CTX_set_cipher_data() permet à une application ou à un moteur de remplacer les données de chiffrement par de nouvelles données. Un pointeur vers les données de chiffrement existantes est retourné par cette fonction. Si les anciennes données ne sont plus nécessaires, elles doivent être libérées par un appel à OPENSSL_free().

VALEURS DE RETOUR

La fonction EVP_CIPHER_CTX_get_cipher_data() retourne un pointeur vers les données de chiffrement actuelles pour le EVP_CIPHER_CTX.

La fonction EVP_CIPHER_CTX_set_cipher_data() retourne un pointeur vers les anciennes données de chiffrement pour le EVP_CIPHER_CTX.

HISTORIQUE

Les fonctions EVP_CIPHER_CTX_get_cipher_data() et EVP_CIPHER_CTX_set_cipher_data() ont été ajoutées dans OpenSSL 1.1.0.
