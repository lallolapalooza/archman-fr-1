NOM

EVP_SKEYMGMT, EVP_SKEYMGMT_fetch, EVP_SKEYMGMT_up_ref, EVP_SKEYMGMT_free, EVP_SKEYMGMT_get0_provider, EVP_SKEYMGMT_is_a, EVP_SKEYMGMT_get0_description, EVP_SKEYMGMT_get0_name, EVP_SKEYMGMT_do_all_provided, EVP_SKEYMGMT_names_do_all, EVP_SKEYMGMT_get0_gen_settable_params, EVP_SKEYMGMT_get0_imp_settable_params - Routines de gestion de clés EVP pour les clés symétriques opaques

SYNOPSISSE

#include <openssl/evp.h>
typedef struct evp_sskeymgmt_st EVP_SKEYMGMT;
EVP_SKEYMGMT *EVP_SKEYMGMT_fetch(OSSL_LIB_CTX *ctx, const char *algorithm,
                                 const char *properties);
int EVP_SKEYMGMT_up_ref(EVP_SKEYMGMT *skeymgmt);
void EVP_SKEYMGMT_free(EVP_SKEYMGMT *skeymgmt);
const OSSL_PROVIDER *EVP_SKEYMGMT_get0_provider(const EVP_SKEYMGMT *skeymgmt);
int EVP_SKEYMGMT_is_a(const EVP_SKEYMGMT *skeymgmt, const char *name);
const char *EVP_SKEYMGMT_get0_name(const EVP_SKEYMGMT *skeymgmt);
const char *EVP_SKEYMGMT_get0_description(const EVP_SKEYMGMT *skeymgmt);
void EVP_SKEYMGMT_do_all_provided(OSSL_LIB_CTX *libctx,
                                  void (*fn)(EVP_SKEYMGMT *skeymgmt, void *arg),
                                  void *arg);
int EVP_SKEYMGMT_names_do_all(const EVP_SKEYMGMT *skeymgmt,
                              void (*fn)(const char *name, void *data),
                              void *data);
const OSSL_PARAM *EVP_SKEYMGMT_get0_gen_settable_params(const EVP_SKEYMGMT *skeymgmt);
const OSSL_PARAM *EVP_SKEYMGMT_get0_imp_settable_params(const EVP_SKEYMGMT *skeymgmt);

DESCRIPTION

EVP_SKEYMGMT est un objet méthode qui représente les implémentations de gestion de clés symétriques pour différents algorithmes cryptographiques. Cet objet méthode fournit des fonctionnalités permettant aux fournisseurs d'importer du matériel de clé depuis l'extérieur, ainsi que d'exporter du matériel de clé vers l'extérieur.

La plupart des fonctionnalités ne peuvent être utilisées qu'en interne et n'ont pas d'interface publique ; cet objet opaque est simplement transmis à d'autres fonctions lorsqu'il est nécessaire.

EVP_SKEYMGMT_fetch() recherche un algorithme au sein d'un fournisseur qui a été chargé dans le OSSL_LIB_CTX donné par ctx, ayant le nom donné par algorithm et les propriétés données par properties.

EVP_SKEYMGMT_up_ref() incrémente le compteur de références pour le EVP_SKEYMGMT skeymgmtdonné.

EVP_SKEYMGMT_free() décrémente le compteur de références pour le EVP_SKEYMGMT skeymgmtdonné, et le libère lorsque le compteur atteint zéro. Si l'argument est NULL, rien n'est fait.

EVP_SKEYMGMT_get0_provider() renvoie le fournisseur qui possède cette implémentation particulière.

EVP_SKEYMGMT_is_a() vérifie si skeymgmt est une implémentation d'un algorithme identifié par name.

EVP_SKEYMGMT_get0_name() renvoie le nom de l'algorithme de l'implémentation fournie pour le skeymgmtdonné. Notez que le skeymgmt peut avoir plusieurs synonymes associés. Dans ce cas, le premier nom de la définition de l'algorithme est renvoyé. La propriété de la chaîne renvoyée est conservée par l'objet skeymgmt et ne doit pas être libérée par l'appelant.

EVP_SKEYMGMT_names_do_all() parcourt tous les noms pour le skeymgmtet appelle fn avec chaque nom et data.

EVP_SKEYMGMT_get0_description() renvoie une description du skeymgmtdestinée à l'affichage et à la consommation humaine. La description est à la discrétion de l'implémentation du skeymgmt .

EVP_SKEYMGMT_do_all_provided() parcourt toutes les implémentations de gestion de clés skeymgmt par tous les fournisseurs activés dans le contexte de bibliothèque libctx, et pour chacune des implémentations, appelle fn avec la méthode d'implémentation et data comme arguments.

EVP_SKEYMGMT_get0_gen_settable_params() et EVP_SKEYMGMT_get0_imp_settable_params() obtiennent un tableau constant OSSL_PARAM(3) qui décrit les paramètres définissables pouvant être utilisés avec EVP_SKEY_generate() et EVP_SKEY_import() respectivement.

NOTES

EVP_SKEYMGMT_fetch() peut être appelé implicitement par d'autres fonctions de récupération, en utilisant le même contexte de bibliothèque et les mêmes propriétés. Toute autre API utilisant des clés symétriques fera généralement cela.

VALEURS RENVOYÉES

EVP_SKEYMGMT_fetch() renvoie un pointeur vers l'implémentation de gestion de clés représentée par un objet EVP_SKEYMGMT, ou NULL en cas d'erreur.

EVP_SKEYMGMT_up_ref() renvoie 1 en cas de succès, ou 0 en cas d'erreur.

EVP_SKEYMGMT_names_do_all() renvoie 1 si le rappel a été appelé pour tous les noms. Une valeur de retour de 0 signifie que le rappel n'a été appelé pour aucun nom.

EVP_SKEYMGMT_free() ne renvoie aucune valeur.

EVP_SKEYMGMT_get0_provider() renvoie un pointeur vers un objet fournisseur, ou NULL en cas d'erreur.

EVP_SKEYMGMT_is_a() renvoie 1 si skeymgmt a été identifiable, sinon 0.

EVP_SKEYMGMT_get0_name() renvoie le nom de l'algorithme, ou NULL en cas d'erreur.

EVP_SKEYMGMT_get0_description() renvoie un pointeur vers une description, ou NULL s'il n'y en a pas.
