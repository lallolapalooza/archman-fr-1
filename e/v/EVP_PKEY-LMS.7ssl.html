EVP_PKEY-LMS(7ssl) OpenSSL EVP_PKEY-LMS(7ssl)

NOM

EVP_PKEY-LMS, EVP_KEYMGMT-LMS, LMS - Support du type de clé et de l'algorithme de signature Leighton-Micali (LMS) EVP_PKEY

DESCRIPTION

Le type de clé LMS est implémenté dans les fournisseurs par défaut et FIPS d'OpenSSL. Les fournisseurs OpenSSL ne prennent en charge que la vérification de signature LMS, car il s'agit d'une exigence [SP 800-208](https://csrc.nist.gov/pubs/sp/800/208/final) pour les modules logiciels FIPS.

Paramètres communs LMS

Les clés publiques LMS sont encodées au format XDR (c'est-à-dire pas au format ASN1). Les paramètres suivants sont utilisés par EVP_PKEY_fromdata() et par le gestionnaire de clés LMS pour l'importation et l'exportation.

"pub" (OSSL_PKEY_PARAM_PUB_KEY) <chaîne d'octets>
Utilisé pour obtenir et définir l'encodage d'une clé publique LMS. La clé publique est attendue au format XDR.

CONFORME À

RFC 8554
Signatures basées sur des hachages Leighton-Micali
SP800-208 du NIST
Recommandation pour les schémas de signature basés sur des hachages à état
CNSA 2.0
Suite d'algorithmes de sécurité nationaux commerciaux

NOTES

Le support LMS est désactivé par défaut au moment de la compilation. Pour l'activer, spécifiez l'option de configuration de construction enable-lms.

EXEMPLES

NOTE la vérification des erreurs a été omise dans ces exemples

Un contexte EVP_PKEY peut être obtenu en appelant :

EVP_PKEY_CTX *ctx = EVP_PKEY_CTX_new_from_name(libctx, "LMS", propq);

Une clé publique LMS peut être chargée simplement comme ceci :

EVP_PKEY *pkey = NULL;
OSSL_DECODER_CTX *dctx = NULL;
int selection = OSSL_KEYMGMT_SELECT_PUBLIC_KEY;
dctx = OSSL_DECODER_CTX_new_for_pkey(&pkey, "XDR", NULL,
                                     "LMS", selection, libctx, propq);
ret = OSSL_DECODER_from_bio(dctx, bio);
OSSL_DECODER_CTX_free(dctx);

Pour charger une clé LMS à partir de données "data" encodées en XDR de taille "datalen" :

EVP_PKEY *key = NULL;
OSSL_PARAM params[2];
params[0] =
    OSSL_PARAM_construct_octet_string(OSSL_PKEY_PARAM_ENCODED_PUBLIC_KEY,
                                      (unsigned char *)data, datalen);
params[1] = OSSL_PARAM_construct_end();
ret = EVP_PKEY_fromdata_init(ctx)
ret = EVP_PKEY_fromdata(ctx, &key, EVP_PKEY_PUBLIC_KEY, params);
