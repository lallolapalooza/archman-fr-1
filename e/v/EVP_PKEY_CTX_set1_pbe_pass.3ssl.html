NOM

EVP_PKEY_CTX_set1_pbe_pass - fonctions de support génériques KDF

SYNTAXE

#include <openssl/kdf.h>
int EVP_PKEY_CTX_set1_pbe_pass(EVP_PKEY_CTX *pctx, unsigned char *pass,
                               int passlen);

DESCRIPTION

Ces fonctions sont des fonctions de support génériques pour tous les algorithmes KDF.

EVP_PKEY_CTX_set1_pbe_pass() définit le mot de passe sur les passlen premiers octets de pass.

CONTRÔLE CHAÎNE

Il existe également un support pour les opérations de contrôle basées sur des chaînes via EVP_PKEY_CTX_ctrl_str(3). Le paramètre password peut être directement spécifié en utilisant le paramètre type "pass" ou donné en encodage hexadécimal en utilisant le paramètre "hexpass".

VALEURS RETOURNÉES

Toutes ces fonctions retournent 1 en cas de succès et 0 ou une valeur négative en cas d'échec. Notamment, une valeur de retour de -2 indique que l'opération n'est pas prise en charge par l'algorithme de clé publique.

VOIR AUSSI

EVP_PKEY_CTX_new(3), EVP_PKEY_CTX_ctrl_str(3), EVP_PKEY_derive(3)

HISTORIQUE

EVP_PKEY_CTX_set1_pbe_pass() a été converti d'une macro en fonction dans OpenSSL 3.0.
