NOM

eval - Évaluer un script Tcl

SYNTAXE

eval arg ?arg ...?

DESCRIPTION

Eval prend un ou plusieurs arguments, qui constituent ensemble un script Tcl contenant une ou plusieurs commandes. Eval concatène tous ses arguments de la même manière que la commande concat, passe la chaîne concaténée de manière récursive à l'interpréteur Tcl, et retourne le résultat de cette évaluation (ou toute erreur qu'elle pourrait générer). Notez que la commande list encadre des séquences de mots de telle sorte qu'elles ne soient pas davantage développées par la commande eval.

EXEMPLES

Il est souvent utile de stocker un fragment de script dans une variable et de l'exécuter plus tard avec des valeurs supplémentaires ajoutées. Cette technique est utilisée dans un certain nombre d'endroits de l'ensemble du cœur de Tcl (par exemple dans les rappels des commandes fcopy, lsort et trace). Cet exemple montre comment faire cela en utilisant les commandes principales de Tcl :

set script {
    puts "logging now"
    lappend $myCurrentLogVar
}
set myCurrentLogVar log1
# Configuration d'un changement de variable de journalisation à mi-chemin !
after 20000 set myCurrentLogVar log2
for {set i 0} {$i<10} {incr i} {
    # Introduire un délai aléatoire
    after [expr {int(5000 * rand())}]
    update    ;# Vérifier le changement de journalisation asynchrone
    eval $script $i [clock clicks]
}

Notez que dans le cas le plus courant (où le fragment de script est en fait juste une liste de mots formant un préfixe de commande), il est préférable d'utiliser {*}$script lors de l'utilisation de ce modèle d'invocation. C'est moins général que la commande eval, et donc plus facile à rendre robuste en pratique. La procédure suivante agit de manière analogue à la commande lappend, sauf qu'elle insère les valeurs des arguments au début de la liste dans la variable :

proc lprepend {varName args} {
    upvar 1 $varName var
    # Assurer que la variable existe et contient une liste
    lappend var
    # Maintenant, nous insérons tous les arguments en une seule fois
    set var [eval [list linsert $var 0] $args]
}

Cependant, la dernière ligne serait maintenant normalement écrite sans eval, comme ceci :

set var [linsert $var 0 {*}$args]
