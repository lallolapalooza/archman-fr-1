NOM

EVP_KDF-HMAC-DRBG - L'implémentation de KDF déterministe HMAC DRBG

DESCRIPTION

Support pour un HMAC DRBG déterministe utilisant l'API EVP_KDF. Ceci est similaire à EVP_RAND-HMAC-DRBG(7), mais utilise des valeurs fixes pour ses valeurs d'entropie et de nonce. Ceci est utilisé pour générer la valeur de nonce déterministe requise par ECDSA et DSA (tels que définis dans la RFC 6979).

Identité

"HMAC-DRBG-KDF" est le nom de cette implémentation ; il peut être utilisé avec la fonction EVP_KDF_fetch().

Paramètres supportés

Les paramètres supportés sont :

"digest" (OSSL_DRBG_PARAM_DIGEST) <chaîne UTF8>
"properties" (OSSL_DRBG_PARAM_PROPERTIES) <chaîne UTF8>
Ces paramètres fonctionnent comme décrit dans "PARAMÈTRES" dans EVP_KDF(3).
"entropy" (OSSL_KDF_PARAM_HMACDRBG_ENTROPY) <chaîne octets>
Définit les octets d'entropie fournis au HMAC-DRBG.
"nonce" (OSSL_KDF_PARAM_HMACDRBG_NONCE) <chaîne octets>
Définit les octets de nonce fournis au HMAC-DRBG.

NOTES

Un contexte pour KDF HMAC DRBG peut être obtenu en appelant :

EVP_KDF *kdf = EVP_KDF_fetch(NULL, "HMAC-DRBG-KDF", NULL);
EVP_KDF_CTX *kdf_ctx = EVP_KDF_CTX_new(kdf, NULL);

CONFORME À
