NOM

EVP_MAC-HMAC - L'implémentation EVP_MAC HMAC

DESCRIPTION

Support pour le calcul de MAC HMAC via l'API EVP_MAC.

Cette implémentation utilise les fonctions EVP_MD pour accéder au digest sous-jacent.

Identité

Cette implémentation est identifiée par ce nom et ces propriétés, à utiliser avec EVP_MAC_fetch() :

"HMAC", "provider=default" ou "provider=fips"

Paramètres supportés

La description générale de ces paramètres se trouve dans "PARAMETERS" dans EVP_MAC(3).

Les paramètres suivants peuvent être définis avec EVP_MAC_CTX_set_params() :

"key" (OSSL_MAC_PARAM_KEY) <chaîne d'octets>
Définit la clé MAC. La définition de ce paramètre est identique au passage d'une clé à EVP_MAC_init(3).
"digest" (OSSL_MAC_PARAM_DIGEST) <chaîne UTF8>
Définit le nom du digest sous-jacent à utiliser.
"properties" (OSSL_MAC_PARAM_PROPERTIES) <chaîne UTF8>
Définit les propriétés à interroger lors de la tentative de récupération du digest sous-jacent. Ceci doit être fourni avec le paramètre de nommage du digest ("digest", ou OSSL_MAC_PARAM_DIGEST) pour être considéré comme valide.
"digest-noinit" (OSSL_MAC_PARAM_DIGEST_NOINIT) <entier>
Un indicateur pour que le digest MAC n'initialise pas les données spécifiques à l'implémentation. La valeur 0 ou 1 est attendue. Cette option est dépréciée et sera supprimée dans une future version. Elle peut être définie mais est actuellement ignorée.
"digest-oneshot" (OSSL_MAC_PARAM_DIGEST_ONESHOT) <entier>
Un indicateur pour que le digest MAC soit une opération ponctuelle. La valeur 0 ou 1 est attendue. Cette option est dépréciée et sera supprimée dans une future version. Elle peut être définie mais est actuellement ignorée.
"tls-data-size" (OSSL_MAC_PARAM_TLS_DATA_SIZE) <entier non signé>
"key-check" (OSSL_MAC_PARAM_FIPS_KEY_CHECK) <entier>
Voir "Mac Parameters" dans provider-mac(7).

Les paramètres suivants peuvent être récupérés avec EVP_MAC_CTX_get_params() :

"size" (OSSL_MAC_PARAM_SIZE) <entier non signé>
Le paramètre "size" peut également être récupéré avec EVP_MAC_CTX_get_mac_size(). La longueur du paramètre "size" est égale à celle d'un unsigned int.
"block-size" (OSSL_MAC_PARAM_BLOCK_SIZE) <entier non signé>
Récupère la taille du bloc MAC. Le paramètre "block-size" peut également être récupéré avec EVP_MAC_CTX_get_block_size().
"fips-indicator" (OSSL_KDF_PARAM_FIPS_APPROVED_INDICATOR) <entier>
Voir "Mac Parameters" dans provider-mac(7).
