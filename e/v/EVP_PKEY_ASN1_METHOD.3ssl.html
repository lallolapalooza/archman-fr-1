DESCRIPTIO

N

EVP_PKEY_ASN1_METHOD est une structure qui contient un ensemble de méthodes de conversion, d'affichage et d'information ASN.1 pour un algorithme de clé publique

spécifique.

Il y a deux endroits où les objets EVP_PKEY_ASN1_METHOD sont stockés : l'un est un tableau intégré représentant les méthodes standard pour les différents algorithmes, et l'autre est une pile de méthodes spécifiques à l'application définies par l'utilisateur, qui peuvent être manipulées en utilisant EVP_PKEY_asn1_a

dd0(3).

Fonction

s

EVP_PKEY_asn1_new() crée et retourne un nouvel objet EVP_PKEY_ASN1_METHOD, et associe les valeurs id, flags, pem_str et info. id est un NID, pem_str est la chaîne de type PEM, info est une chaîne descriptive. Les flags suivants sont supportés

: 
ASN1_PKEY_SIGPARAM_NUL
L

Si ASN1_PKEY_SIGPARAM_NULL est défini, alors les paramètres de l'algorithme de signature reçoivent par défaut le type V_ASN1_NULL, sinon ils recevront le type V_ASN1_UNDEF (c'est-à-dire que le paramètre est omis). Voir X509_ALGOR_set0(3) pour plus

d'informations.

EVP_PKEY_asn1_copy() copie un objet EVP_PKEY_ASN1_METHOD depuis src vers dst. Cette fonction n'est pas sûre pour les threads, il est recommandé de ne l'utiliser que lors de l'initialisation de

l'application.

EVP_PKEY_asn1_free() libère un EVP_PKEY_ASN1_METHOD existant pointé par ameth. Si l'argument est NULL, rien n'est

fait.

EVP_PKEY_asn1_add0() ajoute ameth à la pile de méthodes définies par l'utilisateur sauf si un autre EVP_PKEY_ASN1_METHOD avec le même NID y est déjà présent. Cette fonction n'est pas sûre pour les threads, il est recommandé de ne l'utiliser que lors de l'initialisation de

l'application.

EVP_PKEY_asn1_add_alias() crée un alias avec le NID to pour le EVP_PKEY_ASN1_METHOD avec le NID from sauf si un autre EVP_PKEY_ASN1_METHOD avec le même NID est déjà ajouté. Cette fonction n'est pas sûre pour les threads, il est recommandé de ne l'utiliser que lors de l'initialisation de

l'application.
