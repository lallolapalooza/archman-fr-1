NOM

EVP_PKEY_set_type, EVP_PKEY_set_type_str, EVP_PKEY_set_type_by_keymgmt - fonctions pour changer le type de EVP_PKEY

SYNOPSIS

#include <openssl/evp.h>
int EVP_PKEY_set_type(EVP_PKEY *pkey, int type);
int EVP_PKEY_set_type_str(EVP_PKEY *pkey, const char *str, int len);
int EVP_PKEY_set_type_by_keymgmt(EVP_PKEY *pkey, EVP_KEYMGMT *keymgmt);

DESCRIPTION

Toutes les fonctions décrites ici se comportent de la même manière car elles effacent toutes les données de clé et méthodes précédentes de pkey, et le réinitialisent pour qu'il soit du type de clé donné par les différents arguments. Si pkey est NULL, ces fonctions retourneront toujours les mêmes valeurs de retour que si ce n'était pas le cas.

EVP_PKEY_set_type() initialise pkey pour contenir une clé héritée interne. Ce faisant, elle trouve une EVP_PKEY_ASN1_METHOD(3) correspondant à type, et associe pkey aux découvertes. C'est une erreur si aucune EVP_PKEY_ASN1_METHOD(3) n'a pu être trouvée pour type.

EVP_PKEY_set_type_str() initialise pkey pour contenir une clé héritée interne. Ce faisant, elle trouve une EVP_PKEY_ASN1_METHOD(3) correspondant à str de longueur len, et associe pkey aux découvertes. C'est une erreur si aucune EVP_PKEY_ASN1_METHOD(3) n'a pu être trouvée pour type.

Pour EVP_PKEY_set_type() et EVP_PKEY_set_type_str(), pkey obtient un type numérique, qui peut être récupéré avec EVP_PKEY_get_id(3). Ce type numérique provient de la EVP_PKEY_ASN1_METHOD(3) qui a été trouvée, et est égal ou étroitement lié à type dans le cas de EVP_PKEY_set_type(), ou lié à str dans le cas de EVP_PKEY_set_type_str().

EVP_PKEY_set_type_by_keymgmt() initialise pkey pour contenir une clé interne du côté fournisseur. Ce faisant, elle associe pkey à keymgmt. Pour les clés initialisées de cette manière, le type numérique récupéré avec EVP_PKEY_get_id(3) sera toujours EVP_PKEY_NONE.

VALEURS DE RETOUR

Toutes les fonctions décrites retournent 1 en cas de succès, ou 0 en cas d'erreur.
