NOM

EVP_mdc2 - MDC-2 pour EVP

SYNTAXE

#include <openssl/evp.h>
const EVP_MD *EVP_mdc2(void);

DESCRIPTION

MDC-2 (Modification Detection Code 2 ou Meyer-Schilling) est une fonction de hachage cryptographique basée sur un chiffrement par bloc. Cette implémentation n'est disponible qu'avec le fournisseur hérité.

EVP_mdc2()
L'algorithme MDC-2DES utilisant MDC-2 avec le chiffrement par bloc DES. Il produit une sortie de 128 bits à partir d'une entrée donnée.

NOTES

Les développeurs doivent être conscients des implications négatives en termes de performances lors de l'appel de cette fonction plusieurs fois et devraient envisager d'utiliser EVP_MD_fetch(3) avec EVP_MD-MDC2(7) à la place. Voir "Performances" dans crypto(7) pour plus d'informations.

VALEURS DE RETOUR

Ces fonctions renvoient une structure EVP_MD qui contient l'implémentation du résumé de message. Voir EVP_MD_meth_new(3) pour les détails de la structure EVP_MD.

CONFORMITE

ISO/IEC 10118-2:2000 Fonction de hachage 2, avec DES comme chiffrement par bloc sous-jacent.

VOIR AUSSI

evp(7), provider(7), EVP_DigestInit(3)
