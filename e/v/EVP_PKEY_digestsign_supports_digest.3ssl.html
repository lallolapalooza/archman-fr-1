NOM

EVP_PKEY_digestsign_supports_digest - indiquer la prise en charge du condensat de signature

SYNOPSIS

#include <openssl/evp.h>
int EVP_PKEY_digestsign_supports_digest(EVP_PKEY *pkey, OSSL_LIB_CTX *libctx,
                                        const char *name, const char *propq);

DESCRIPTION

La fonction EVP_PKEY_digestsign_supports_digest() interroge si le condensat de message name est pris en charge pour les opérations de signature de clé publique associées à la clé pkey. L'interrogation est effectuée dans un contexte de bibliothèque optionnel libctx et avec une requête de propriétés optionnelle propq.

VALEURS DE RETOUR

La fonction EVP_PKEY_digestsign_supports_digest() retourne 1 si l'algorithme de condensat de message identifié par name peut être utilisé pour les opérations de signature de clé publique associées à la clé pkey et 0 s'il ne peut pas être utilisé. Elle retourne une valeur négative en cas d'échec.

HISTORIQUE
