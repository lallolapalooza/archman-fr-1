NOM

EVP_ripemd160 - RIPEMD160 pour EVP

SYNTAXE

#include <openssl/evp.h>
const EVP_MD *EVP_ripemd160(void);

DESCRIPTION

RIPEMD-160 est une fonction de hachage cryptographique publiée pour la première fois en 1996, appartenant à la famille RIPEMD (RACE Integrity Primitives Evaluation Message Digest). Cette implémentation n'est disponible qu'avec le fournisseur hérité.

EVP_ripemd160()
L'algorithme RIPEMD-160 qui produit une sortie de 160 bits à partir d'une entrée donnée.

NOTES

Les développeurs doivent être conscients des implications négatives sur les performances lors de l'appel de cette fonction plusieurs fois et devraient envisager d'utiliser EVP_MD_fetch(3) avec EVP_MD-RIPEMD160(7) à la place. Voir "Performances" dans crypto(7) pour plus d'informations.

VALEURS DE RETOUR

Ces fonctions retournent une structure EVP_MD qui contient l'implémentation du résumé de message. Voir EVP_MD_meth_new(3) pour les détails de la structure EVP_MD.

CONFORMITÉ

ISO/IEC 10118-3:2016 Dedicated Hash-Function 1 (RIPEMD-160).

VOIR AUSSI

evp(7), provider(7), EVP_DigestInit(3)
