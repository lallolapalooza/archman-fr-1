EVP_PKEY_decrypt(3ssl)

Paquet: openssl

Licences: Apache-2.0

EVP_PKEY_DECRYPT(3ssl) OpenSSL EVP_PKEY_DECRYPT(3ssl)

NOM

EVP_PKEY_decrypt_init, EVP_PKEY_decrypt_init_ex, EVP_PKEY_decrypt - déchiffrer à l'aide d'un algorithme à clé publique

SYNOPSIS

#include <openssl/evp.h>
int EVP_PKEY_decrypt_init(EVP_PKEY_CTX *ctx);
int EVP_PKEY_decrypt_init_ex(EVP_PKEY_CTX *ctx, const OSSL_PARAM params[]);
int EVP_PKEY_decrypt(EVP_PKEY_CTX *ctx,
                     unsigned char *out, size_t *outlen,
                     const unsigned char *in, size_t inlen);

DESCRIPTION

La fonction EVP_PKEY_decrypt_init() initialise un contexte d'algorithme à clé publique en utilisant la clé pkey pour une opération de déchiffrement.

La fonction EVP_PKEY_decrypt_init_ex() initialise un contexte d'algorithme à clé publique en utilisant la clé pkey pour une opération de déchiffrement et définit les params spécifiques à l'algorithme.

La fonction EVP_PKEY_decrypt() effectue une opération de déchiffrement à clé publique en utilisant ctx. Les données à déchiffrer sont spécifiées par les paramètres in et inlen. Si out est NULL, la taille minimale requise du tampon de sortie est écrite dans le paramètre *outlen.

Si out n'est pas NULL, avant l'appel, le paramètre *outlen doit contenir la longueur du tampon out. Si l'appel réussit, les données déchiffrées sont écrites dans out et la quantité de données déchiffrées écrites dans *outlen, sinon une erreur est retournée.

NOTES

Après l'appel à EVP_PKEY_decrypt_init(), des opérations de contrôle spécifiques à l'algorithme peuvent être effectuées pour définir les paramètres appropriés pour l'opération. Ces opérations peuvent être incluses dans l'appel EVP_PKEY_decrypt_init_ex().

La fonction EVP_PKEY_decrypt() peut être appelée plus d'une fois sur le même contexte si plusieurs opérations sont effectuées avec les mêmes paramètres.

VALEUR DE RETOUR

EVP_PKEY_decrypt_init(), EVP_PKEY_decrypt_init_ex() et EVP_PKEY_decrypt() retournent 1 en cas de succès et 0 ou une valeur négative en cas d'échec. En particulier, une valeur de retour de -2 indique que l'opération n'est pas supportée par l'algorithme à clé publique.

AVERTISSEMENTS

Dans les versions d'OpenSSL antérieures à 3.2.0, lorsqu'il était utilisé avec le padding PKCS#1 v1.5, la valeur de retour de EVP_PKEY_decrypt() et le outlen fournissaient des informations utiles pour monter une attaque de Bleichenbacher contre la clé privée utilisée. Ils devaient être traités d'une manière insensible aux canaux auxiliaires.

Depuis la version 3.2.0, la méthode EVP_PKEY_decrypt() lorsqu'elle est utilisée avec le padding PKCS#1 v1.5, tel qu'implémenté dans le fournisseur défaut, implémente le mécanisme de rejet implicite (voir OSSL_ASYM_CIPHER_PARAM_IMPLICIT_REJECTION dans provider-asym_cipher(7)). Cela signifie qu'elle ne renvoie pas d'erreur lorsqu'elle détecte une erreur dans le padding, mais renvoie plutôt un message généré de manière pseudo-aléatoire, supprimant ainsi la nécessité d'un code sécurisé contre les canaux auxiliaires pour les applications utilisant OpenSSL. Si OpenSSL est configuré pour utiliser un fournisseur qui n'implémente pas le rejet implicite, le code doit toujours gérer les valeurs retournées en utilisant un code insensible aux canaux auxiliaires. La gestion insensible aux canaux auxiliaires de la pile d'erreurs peut être effectuée soit à l'aide d'une paire d'appels inconditionnels ERR_set_mark(3) et ERR_pop_to_mark(3), soit en utilisant l'appel ERR_clear_error(3).

EXEMPLES

Déchiffrer des données en utilisant OAEP (pour les clés RSA) :

#include <openssl/evp.h>
#include <openssl/rsa.h>
EVP_PKEY_CTX *ctx;
ENGINE *eng;
unsigned char *out, *in;
size_t outlen, inlen;
EVP_PKEY *key;
/*
 * NB : suppose que key, eng, in, inlen sont déjà configurés
 * et que key est une clé privée RSA
 */
ctx = EVP_PKEY_CTX_new(key, eng);
if (!ctx)
    /* Une erreur s'est produite */
if (EVP_PKEY_decrypt_init(ctx) <= 0)
    /* Erreur */
if (EVP_PKEY_CTX_set_rsa_padding(ctx, RSA_PKCS1_OAEP_PADDING) <= 0)
    /* Erreur */
/* Déterminer la longueur du tampon */
if (EVP_PKEY_decrypt(ctx, NULL, &outlen, in, inlen) <= 0)
    /* Erreur */
out = OPENSSL_malloc(outlen);
if (!out)
    /* Échec de malloc */
if (EVP_PKEY_decrypt(ctx, out, &outlen, in, inlen) <= 0)
    /* Erreur */
/* Les données déchiffrées sont de taille outlen octets écrites dans le tampon out */
