NOM

EVP_KDF-PKCS12KDF - L'implémentation EVP_KDF PKCS#12

DESCRIPTION

Support pour le calcul de la fonction de dérivation de clé basée sur mot de passe PKCS#12 via l'API EVP_KDF.

L'algorithme EVP_KDF-PKCS12KDF implémente la fonction de dérivation de clé basée sur mot de passe PKCS#12, telle que décrite dans l'annexe B de la RFC 7292 (PKCS #12: Personal Information Exchange Syntax) ; elle dérive une clé d'un mot de passe en utilisant un sel, un nombre d'itérations et l'usage prévu.

Identité

"PKCS12KDF" est le nom de cette implémentation ; il peut être utilisé avec la fonction EVP_KDF_fetch().

Paramètres supportés

Les paramètres supportés sont :

"pass" (OSSL_KDF_PARAM_PASSWORD) <chaîne d'octets>
"salt" (OSSL_KDF_PARAM_SALT) <chaîne d'octets>
"iter" (OSSL_KDF_PARAM_ITER) <entier non signé>
"properties" (OSSL_KDF_PARAM_PROPERTIES) <chaîne UTF8>
"digest" (OSSL_KDF_PARAM_DIGEST) <chaîne UTF8>
Ces paramètres fonctionnent comme décrit dans "PARAMÈTRES" dans EVP_KDF(3).
"id" (OSSL_KDF_PARAM_PKCS12_ID) <entier>
Ce paramètre est utilisé pour spécifier l'usage prévu des bits de sortie, conformément à la section B.3 de la RFC 7292.

NOTES

Cet algorithme n'est pas disponible dans le fournisseur FIPS car il n'est pas approuvé par FIPS.

Une application typique de cet algorithme consiste à dériver des matériaux de clé pour un algorithme de chiffrement à partir d'un mot de passe dans "pass", d'un sel dans "salt", et d'un nombre d'itérations.

Augmenter le paramètre "iter" ralentit l'algorithme, ce qui rend plus difficile pour un attaquant de réaliser une attaque par force brute utilisant un grand nombre de mots de passe candidats.

Aucune hypothèse n'est faite concernant le mot de passe donné ; il est simplement traité comme une séquence d'octets.
