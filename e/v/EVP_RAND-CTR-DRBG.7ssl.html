NOM

EVP_RAND-CTR-DRBG - L'implémentation EVP_RAND de CTR-DRBG

DESCRIPTION

Prise en charge du générateur de bits aléatoires déterministes par compteur via l'API EVP_RAND.

Identité

"CTR-DRBG" est le nom de cette implémentation ; elle peut être utilisée avec la fonction EVP_RAND_fetch().

Paramètres pris en charge

Les paramètres pris en charge sont :

"state" (OSSL_RAND_PARAM_STATE) <entier>
"strength" (OSSL_RAND_PARAM_STRENGTH) <entier non signé>
"max_request" (OSSL_RAND_PARAM_MAX_REQUEST) <entier non signé>
"reseed_requests" (OSSL_DRBG_PARAM_RESEED_REQUESTS) <entier non signé>
"reseed_time_interval" (OSSL_DRBG_PARAM_RESEED_TIME_INTERVAL) <entier>
"min_entropylen" (OSSL_DRBG_PARAM_MIN_ENTROPYLEN) <entier non signé>
"max_entropylen" (OSSL_DRBG_PARAM_MAX_ENTROPYLEN) <entier non signé>
"min_noncelen" (OSSL_DRBG_PARAM_MIN_NONCELEN) <entier non signé>
"max_noncelen" (OSSL_DRBG_PARAM_MAX_NONCELEN) <entier non signé>
"max_perslen" (OSSL_DRBG_PARAM_MAX_PERSLEN) <entier non signé>
"max_adinlen" (OSSL_DRBG_PARAM_MAX_ADINLEN) <entier non signé>
"reseed_counter" (OSSL_DRBG_PARAM_RESEED_COUNTER) <entier non signé>
"properties" (OSSL_DRBG_PARAM_PROPERTIES) <chaîne UTF8>
"cipher" (OSSL_DRBG_PARAM_CIPHER) <chaîne UTF8>
Ces paramètres fonctionnent comme décrit dans "PARAMÈTRES" dans EVP_RAND(3).
"use_derivation_function" (OSSL_DRBG_PARAM_USE_DF) <entier>
Cette valeur booléenne indique si une fonction de dérivation doit être utilisée ou non. Une valeur non nulle (par défaut) utilise la fonction de dérivation. Une valeur zéro ne l'utilise pas.

NOTES

Un contexte pour CTR DRBG peut être obtenu en appelant :

EVP_RAND *rand = EVP_RAND_fetch(NULL, "CTR-DRBG", NULL);
EVP_RAND_CTX *rctx = EVP_RAND_CTX_new(rand, NULL);

L'implémentation par défaut de CTR-DRBG tente de récupérer les algorithmes internes requis du fournisseur dans lequel ils sont intégrés (par exemple, le fournisseur par défaut), quelles que soient les propriétés fournies. Si le fournisseur n'implémente pas les algorithmes requis, les propriétés seront utilisées pour trouver une implémentation différente.

EXEMPLES

EVP_RAND *rand;
EVP_RAND_CTX *rctx;
unsigned char bytes[100];
OSSL_PARAM params[2], *p = params;
unsigned int strength = 128;
rand = EVP_RAND_fetch(NULL, "CTR-DRBG", NULL);
rctx = EVP_RAND_CTX_new(rand, NULL);
EVP_RAND_free(rand);
*p++ = OSSL_PARAM_construct_utf8_string(OSSL_DRBG_PARAM_CIPHER,
                                        SN_aes_256_ctr, 0);
*p = OSSL_PARAM_construct_end();
EVP_RAND_instantiate(rctx, strength, 0, NULL, 0, params);
EVP_RAND_generate(rctx, bytes, sizeof(bytes), strength, 0, NULL, 0);
EVP_RAND_CTX_free(rctx);
