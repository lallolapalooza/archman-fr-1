EVP_PKEY_is_a(3ssl)

Paquet: openssl

Licences: Apache-2.0

EVP_PKEY_IS_A(3ssl) OpenSSL EVP_PKEY_IS_A(3ssl)

NOM

EVP_PKEY_is_a, EVP_PKEY_can_sign, EVP_PKEY_type_names_do_all, EVP_PKEY_get0_type_name, EVP_PKEY_get0_description, EVP_PKEY_get0_provider - fonctions de type et de capacités de clé

SYNTAXE

#include <openssl/evp.h>
int EVP_PKEY_is_a(const EVP_PKEY *pkey, const char *name);
int EVP_PKEY_can_sign(const EVP_PKEY *pkey);
int EVP_PKEY_type_names_do_all(const EVP_PKEY *pkey,
                               void (*fn)(const char *name, void *data),
                               void *data);
const char *EVP_PKEY_get0_type_name(const EVP_PKEY *key);
const char *EVP_PKEY_get0_description(const EVP_PKEY *key);
const OSSL_PROVIDER *EVP_PKEY_get0_provider(const EVP_PKEY *key);

DESCRIPTION

EVP_PKEY_is_a() vérifie si le type de clé de pkey est name.

EVP_PKEY_can_sign() vérifie si la fonctionnalité du type de clé de pkey prend en charge la signature. Aucune autre vérification n'est effectuée, comme par exemple la présence d'une clé privée dans pkey.

EVP_PKEY_type_names_do_all() parcourt tous les noms pour le type de clé de pkey, et appelle fn avec chaque nom et data. Par exemple, une EVP_PKEY RSA peut être nommée à la fois "RSA" et "rsaEncryption". L'ordre des noms dépend de l'implémentation du fournisseur qui détient la clé.

EVP_PKEY_get0_type_name() renvoie le premier nom de type de clé trouvé pour le pkey donné. Notez que le pkey peut avoir plusieurs synonymes associés. Dans ce cas, celui qui sera renvoyé dépend de l'implémentation du fournisseur qui détient la clé. La propriété de la chaîne renvoyée est conservée par l'objet pkey et ne doit pas être libérée par l'appelant.

EVP_PKEY_get0_description() renvoie une description du type d'EVP_PKEY, destinée à être affichée et comprise par les humains. La description est à la discrétion de l'implémentation du type de clé.

EVP_PKEY_get0_provider() renvoie le fournisseur de EVP_KEYMGMT(3) de l'EVP_PKEY.

VALEURS DE RETOUR

EVP_PKEY_is_a() renvoie 1 si pkey a le type de clé name, sinon 0.

EVP_PKEY_can_sign() renvoie 1 si la fonctionnalité du type de clé pkey prend en charge la signature, sinon 0.

EVP_PKEY_get0_type_name() renvoie le nom trouvé ou NULL en cas d'erreur.

EVP_PKEY_get0_description() renvoie la description si elle est trouvée, ou NULL si elle ne l'est pas.

EVP_PKEY_get0_provider() renvoie le fournisseur si trouvé, ou NULL si ce n'est pas le cas.

EVP_PKEY_type_names_do_all() renvoie 1 si la fonction de rappel a été appelée pour tous les noms. Une valeur de retour de 0 signifie que la fonction de rappel n'a été appelée pour aucun nom.

EXEMPLES

EVP_PKEY_is_a()

Les fournisseurs chargés et les types de clés qu'ils prennent en charge détermineront finalement quel name peut être utilisé avec EVP_PKEY_is_a(). Nous savons que le fournisseur par défaut prend en charge les clés RSA, DH, DSA et EC, nous pouvons donc l'utiliser comme exemple brut :

#include <openssl/evp.h>
...
    /* |pkey| est un EVP_PKEY* */
    if (EVP_PKEY_is_a(pkey, "RSA")) {
        BIGNUM *modulus = NULL;
        if (EVP_PKEY_get_bn_param(pkey, "n", &modulus))
            /* faire quelque chose avec le module */
        BN_free(modulus);
    }

EVP_PKEY_can_sign()

#include <openssl/evp.h>
...
    /* |pkey| est un EVP_PKEY* */
    if (!EVP_PKEY_can_sign(pkey)) {
        fprintf(stderr, "Ce n'est pas une clé de signature !");
        exit(1);
    }
    /* Signer quelque chose... */
