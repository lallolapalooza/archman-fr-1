EVP_PKEY_CTX_set_scrypt_N(3ssl)

Paquet: openssl

Licences: Apache-2.0

EVP_PKEY_CTX_SET_SCRYPT_N(3ssl) OpenSSL EVP_PKEY_CTX_SET_SCRYPT_N(3ssl)

NOM

EVP_PKEY_CTX_set1_scrypt_salt, EVP_PKEY_CTX_set_scrypt_N, EVP_PKEY_CTX_set_scrypt_r, EVP_PKEY_CTX_set_scrypt_p, EVP_PKEY_CTX_set_scrypt_maxmem_bytes - Fonctions de support KDF scrypt EVP_PKEY

SYNOPSIS

#include <openssl/kdf.h>
int EVP_PKEY_CTX_set1_scrypt_salt(EVP_PKEY_CTX *pctx, unsigned char *salt,
                                  int saltlen);
int EVP_PKEY_CTX_set_scrypt_N(EVP_PKEY_CTX *pctx, uint64_t N);
int EVP_PKEY_CTX_set_scrypt_r(EVP_PKEY_CTX *pctx, uint64_t r);
int EVP_PKEY_CTX_set_scrypt_p(EVP_PKEY_CTX *pctx, uint64_t p);
int EVP_PKEY_CTX_set_scrypt_maxmem_bytes(EVP_PKEY_CTX *pctx,
                                         uint64_t maxmem);

DESCRIPTION

Ces fonctions sont utilisées pour configurer les données nécessaires à l'utilisation du KDF scrypt. Pour plus d'informations sur scrypt, voir EVP_KDF-SCRYPT(7).

EVP_PKEY_CTX_set1_scrypt_salt() définit la valeur de salt de longueur saltlen octets.

EVP_PKEY_CTX_set_scrypt_N(), EVP_PKEY_CTX_set_scrypt_r() et EVP_PKEY_CTX_set_scrypt_p() configurent les facteurs de travail N, r et p.

EVP_PKEY_CTX_set_scrypt_maxmem_bytes() définit la quantité maximale de RAM que la dérivation de clé peut utiliser, exprimée en octets. Si la RAM est dépassée parce que les facteurs de charge sont choisis trop élevés, la dérivation de clé échouera.

CONTROLES DE CHAÎNE

scrypt supporte également les opérations de contrôle basées sur des chaînes via EVP_PKEY_CTX_ctrl_str(3). De même, le salt peut être spécifié soit en utilisant le paramètre type "salt", soit en encodage hexadécimal en utilisant le paramètre "hexsalt". Les facteurs de travail N, r et p ainsi que maxmem_bytes peuvent être définis en utilisant les paramètres "N", "r", "p" et "maxmem_bytes" respectivement.

NOTES

Il existe une API générique plus récente pour les KDF, EVP_KDF(3), qui est préférée à la méthode EVP_PKEY.

Le KDF scrypt utilise également EVP_PKEY_CTX_set1_pbe_pass() ainsi que la valeur des contrôles de chaîne "pass" et "hexpass". Voir EVP_PKEY_CTX_set1_pbe_pass(3).

VALEURS DE RETOUR

Toutes ces fonctions retournent 1 en cas de succès et 0 ou une valeur négative en cas d'échec. En particulier, une valeur de retour de -2 indique que l'opération n'est pas supportée par l'algorithme de clé publique.

VOIR AUSSI

EVP_KDF(3) EVP_PKEY_CTX_new(3), EVP_PKEY_CTX_ctrl_str(3), EVP_PKEY_derive(3)
