Module Event
: sig end

Communication synchrone de première classe.

Ce module implémente les communications synchrones inter-threads sur des canaux. Comme dans le système Concurrent ML de John Reppy, les événements de communication sont des valeurs de première classe : ils peuvent être construits et combinés indépendamment avant d'être offerts pour la communication.

type 'a channel

Le type des canaux de communication transportant des valeurs de type 'a .

val new_channel : unit -> 'a channel

Retourne un nouveau canal.

type +'a event

Le type des événements de communication retournant un résultat de type 'a .

val send : 'a channel -> 'a -> unit event

send ch v retourne l'événement consistant à envoyer la valeur v sur le canal ch . La valeur résultat de cet événement est () .

val receive : 'a channel -> 'a event

receive ch retourne l'événement consistant à recevoir une valeur du canal ch . La valeur résultat de cet événement est la valeur reçue.

val always : 'a -> 'a event

always v retourne un événement toujours prêt pour la synchronisation. La valeur résultat de cet événement est v .

val choose : 'a event list -> 'a event

choose evl retourne l'événement qui est l'alternative de tous les événements de la liste evl .

val wrap : 'a event -> ('a -> 'b) -> 'b event

wrap ev fn retourne l'événement qui effectue les mêmes communications que ev , puis applique la fonction de post-traitement fn sur la valeur de retour.

val wrap_abort : 'a event -> (unit -> unit) -> 'a event

wrap_abort ev fn retourne l'événement qui effectue les mêmes communications que ev , mais s'il n'est pas sélectionné, la fonction fn est appelée après la synchronisation.

val guard : (unit -> 'a event) -> 'a event

guard fn retourne l'événement qui, lors de la synchronisation, calcule fn() et se comporte comme l'événement résultant. Ceci permet de calculer des événements avec des effets de bord au moment de l'opération de synchronisation.

val sync : 'a event -> 'a

'Synchronise' sur un événement : offre toutes les possibilités de communication spécifiées dans l'événement au monde extérieur, et bloque jusqu'à ce qu'une des communications réussisse. La valeur résultat de cette communication est retournée.

val select : 'a event list -> 'a

'Synchronise' sur une alternative d'événements. select evl est un raccourci pour sync(choose evl) .

val poll : 'a event -> 'a option

Version non bloquante de Event.sync : offre toutes les possibilités de communication spécifiées dans l'événement au monde extérieur, et si l'une peut avoir lieu immédiatement, l'effectue et retourne Some r où r est la valeur résultat de cette communication. Sinon, retourne None sans bloquer.
