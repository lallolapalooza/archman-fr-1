NOM

EVP_CIPHER-NULL - L'implémentation EVP_CIPHER NULL

DESCRIPTION

Prise en charge du chiffrement symétrique NULL utilisant l'API EVP_CIPHER. Ceci est utilisé lorsque la suite de chiffrement TLS est TLS_NULL_WITH_NULL_NULL. Cela n'effectue aucun chiffrement (copie simplement les données) et a une taille de mac de zéro.

Nom de l'algorithme

L'algorithme suivant est disponible dans le fournisseur par défaut :

"NULL"

Paramètres

Cette implémentation prend en charge les paramètres suivants :

Paramètres EVP_CIPHER pouvant être récupérés

Voir "Paramètres EVP_CIPHER pouvant être récupérés" dans EVP_EncryptInit(3)

Paramètres EVP_CIPHER_CTX pouvant être récupérés

"keylen" (OSSL_CIPHER_PARAM_KEYLEN) <entier non signé>
"ivlen" (OSSL_CIPHER_PARAM_IVLEN et <OSSL_CIPHER_PARAM_AEAD_IVLEN) <entier non signé>
"tls-mac" (OSSL_CIPHER_PARAM_TLS_MAC) <pointeur octet>

Voir "PARAMÈTRES" dans EVP_EncryptInit(3) pour plus d'informations.

Paramètres EVP_CIPHER_CTX pouvant être définis

"tls-mac-size" (OSSL_CIPHER_PARAM_TLS_MAC_SIZE) <entier non signé>

Voir "PARAMÈTRES" dans EVP_EncryptInit(3) pour plus d'informations.

CONFORMITÉ À

RFC 5246 section 6.2.3.1
