NOM

EVP_KDF-PBKDF2 - L'implémentation EVP_KDF de PBKDF2

DESCRIPTION

Support pour le calcul de la fonction de dérivation de clé basée sur mot de passe PBKDF2 via l'API EVP_KDF.

L'algorithme EVP_KDF-PBKDF2 implémente la fonction de dérivation de clé basée sur mot de passe PBKDF2, telle que décrite dans SP800-132 ; elle dérive une clé d'un mot de passe en utilisant un sel et un nombre d'itérations.

La sortie est considérée comme une clé cryptographique.

Identité

"PBKDF2" est le nom de cette implémentation ; il peut être utilisé avec la fonction EVP_KDF_fetch().

Paramètres supportés

Les paramètres supportés sont :

"pass" (OSSL_KDF_PARAM_PASSWORD) <chaîne d'octets>
"salt" (OSSL_KDF_PARAM_SALT) <chaîne d'octets>
"iter" (OSSL_KDF_PARAM_ITER) <entier non signé>
Ce paramètre a une valeur par défaut de 2048.
"properties" (OSSL_KDF_PARAM_PROPERTIES) <chaîne UTF8>
"digest" (OSSL_KDF_PARAM_DIGEST) <chaîne UTF8>
Ces paramètres fonctionnent comme décrit dans "PARAMÈTRES" dans EVP_KDF(3).
"pkcs5" (OSSL_KDF_PARAM_PKCS5) <entier>
Ce paramètre peut être utilisé pour activer ou désactiver les vérifications de conformité SP800-132. Définir le mode à 0 active les vérifications de conformité.

Les vérifications effectuées sont :

- le nombre d'itérations est d'au moins 1000.
- la longueur du sel est d'au moins 128 bits.
- la longueur de la clé dérivée est d'au moins 112 bits.

Le fournisseur par défaut utilise un mode par défaut de 1 pour la compatibilité ascendante, et le fournisseur FIPS utilise un mode par défaut de 0. Cette option enfreint la conformité FIPS si elle fait que l'"indicateur-fips" approuvé renvoie 0.

"fips-indicator" (OSSL_KDF_PARAM_FIPS_APPROVED_INDICATOR) <entier>
Cette option est utilisée par le fournisseur FIPS d'OpenSSL.

Un accesseur qui renvoie 1 si l'opération est approuvée par FIPS, ou 0 sinon. Cela peut être utilisé après avoir appelé EVP_KDF_derive. Il renvoie 0 si "pkcs5" est défini à 1 et que les tests de longueur de clé dérivée, de longueur de sel ou de nombre d'itérations échouent.

NOTES

Une application typique de cet algorithme consiste à dériver du matériel de clé pour un algorithme de chiffrement à partir d'un mot de passe dans le paramètre "pass", d'un sel dans "salt", et d'un nombre d'itérations.

Augmenter le paramètre "iter" ralentit l'algorithme, ce qui rend plus difficile pour un attaquant d'effectuer une attaque par force brute en utilisant un grand nombre de mots de passe candidats.

Aucune supposition n'est faite concernant le mot de passe donné ; il est simplement traité comme une séquence d'octets.

CONFORME À

SP800-132
