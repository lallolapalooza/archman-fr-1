EVP_PKEY_asn1_get_count(3ssl)

Paquet: openssl

Licences: Apache-2.0

EVP_PKEY_asn1_get_count(3ssl) OpenSSL EVP_PKEY_asn1_get_count(3ssl)

NOM

EVP_PKEY_asn1_find, EVP_PKEY_asn1_find_str, EVP_PKEY_asn1_get_count, EVP_PKEY_asn1_get0, EVP_PKEY_asn1_get0_info - énumérer les méthodes ASN.1 de clé publique

SYNOPIS

Les fonctions suivantes sont obsolètes depuis OpenSSL 3.6, et peuvent être entièrement masquées en définissant OPENSSL_API_COMPAT avec une valeur de version appropriée, voir openssl_user_macros(7) ; utiliser l'API du fournisseur à la place.

#include <openssl/evp.h>
int EVP_PKEY_asn1_get_count(void);
const EVP_PKEY_ASN1_METHOD *EVP_PKEY_asn1_get0(int idx);
const EVP_PKEY_ASN1_METHOD *EVP_PKEY_asn1_find(ENGINE **pe, int type);
const EVP_PKEY_ASN1_METHOD *EVP_PKEY_asn1_find_str(ENGINE **pe,
                                                   const char *str, int len);
int EVP_PKEY_asn1_get0_info(int *ppkey_id, int *pkey_base_id,
                            int *ppkey_flags, const char **pinfo,
                            const char **ppem_str,
                            const EVP_PKEY_ASN1_METHOD *ameth);

DESCRIPTION

EVP_PKEY_asn1_count() retourne le nombre de méthodes ASN.1 de clé publique disponibles : il inclut les méthodes standard et toutes les méthodes ajoutées par l'application.

EVP_PKEY_asn1_get0() retourne la méthode ASN.1 de clé publique idx. La valeur de idx doit être comprise entre zéro et EVP_PKEY_asn1_get_count() - 1.

EVP_PKEY_asn1_find() recherche la EVP_PKEY_ASN1_METHOD avec le NID type. Si pe n'est pas NULL, alors il recherche un moteur implémentant une EVP_PKEY_ASN1_METHOD pour le NID type et retourne celle-ci à la place, et définit également *pe pour pointer vers le moteur qui l'implémente.

EVP_PKEY_asn1_find_str() recherche la EVP_PKEY_ASN1_METHOD avec la chaîne de type PEM str. Tout comme EVP_PKEY_asn1_find(), si pe n'est pas NULL, alors il recherche un moteur implémentant une EVP_PKEY_ASN1_METHOD pour le NID type et retourne celle-ci à la place, et définit également *pe pour pointer vers le moteur qui l'implémente.

EVP_PKEY_asn1_get0_info() retourne l'identifiant de clé publique, l'identifiant de clé publique de base (tous deux des NID), tous les indicateurs, la description de la méthode et la chaîne de type PEM associés à la méthode ASN.1 de clé publique *ameth.

EVP_PKEY_asn1_count(), EVP_PKEY_asn1_get0(), EVP_PKEY_asn1_find() et EVP_PKEY_asn1_find_str() ne sont pas thread-safe, mais tant que tous les objets EVP_PKEY_ASN1_METHOD sont ajoutés avant que l'application ne passe en mode multi-thread, leur utilisation est sûre. Voir EVP_PKEY_asn1_add0(3).

VALEURS DE RETOUR

EVP_PKEY_asn1_count() retourne le nombre de méthodes de clé publique disponibles.

EVP_PKEY_asn1_get0() retourne une méthode de clé publique ou NULL si idx est hors limites.

EVP_PKEY_asn1_get0_info() retourne 0 en cas d'échec, 1 en cas de succès.

VOIR AUSSI

EVP_PKEY_asn1_new(3), EVP_PKEY_asn1_add0(3)

HISTORIQUE

Ces fonctions sont obsolètes dans OpenSSL 3.6.
