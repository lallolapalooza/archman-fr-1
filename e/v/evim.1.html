NOM

evim - Vim facile, éditer un fichier avec Vim et configuration pour l'édition sans mode

SYNTAXE

evim [options] [fichier ..]
eview

DESCRIPTION

eVim démarre Vim et configure les options pour qu'il se comporte comme un éditeur sans mode. Il s'agit toujours de Vim mais utilisé comme un éditeur pointer-cliquer. Cela ressemble beaucoup à l'utilisation de Notepad sur MS-Windows. eVim s'exécutera toujours en mode graphique, pour permettre l'utilisation des menus et de la barre d'outils.

À n'utiliser que pour les personnes qui ne peuvent vraiment pas travailler avec Vim de la manière normale. L'édition sera beaucoup moins efficace.

eview est identique, mais démarre en mode lecture seule. Il fonctionne exactement comme evim -R.

Voir vim(1) pour les détails sur Vim, les options, etc.

L'option 'insertmode' est définie pour permettre de taper du texte directement.
Des raccourcis sont configurés pour que Copier et Coller fonctionnent avec les touches de MS-Windows. CTRL-X coupe le texte, CTRL-C copie le texte et CTRL-V colle le texte. Utilisez CTRL-Q pour obtenir la signification originale de CTRL-V.

OPTIONS

Voir vim(1).

FICHIERS

/usr/local/share/vim/vim??/evim.vim
Le script chargé pour initialiser eVim.
vim?? est le numéro de version court, comme vim91 pour Vim 9.1

AUSSI CONNU SOUS LE NOM DE

Aussi connu sous le nom de "Vim pour les idiots". Lorsque vous utilisez evim, on s'attend à ce que vous preniez un mouchoir, que vous fassiez un nœud à chaque coin et que vous le portiez sur votre tête.
