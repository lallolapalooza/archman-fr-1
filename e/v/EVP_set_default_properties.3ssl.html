EVP_set_default_properties(3ssl)

Paquet: openssl

Licences: Apache-2.0

EVP_SET_DEFAULT_PROPERTIES(3ssl) OpenSSL EVP_SET_DEFAULT_PROPERTIES(3ssl)

NOM

EVP_set_default_properties, EVP_default_properties_enable_fips, EVP_default_properties_is_fips_enabled, EVP_get1_default_properties - gérer les propriétés par défaut pour les futures récupérations d'algorithmes

SYNTAXE

#include <openssl/evp.h>
int EVP_set_default_properties(OSSL_LIB_CTX *libctx, const char *propq);
char *EVP_get1_default_properties(OSSL_LIB_CTX *libctx);
int EVP_default_properties_enable_fips(OSSL_LIB_CTX *libctx, int enable);
int EVP_default_properties_is_fips_enabled(OSSL_LIB_CTX *libctx);

DESCRIPTION

EVP_set_default_properties() définit les propriétés par défaut pour toutes les futures récupérations d'algorithmes EVP, implicites comme explicites. Voir "ALGORITHM FETCHING" dans crypto(7) pour des informations sur les récupérations implicites et explicites.

EVP_set_default_properties stocke les propriétés fournies avec la chaîne propq parmi les données EVP qui ont été stockées dans le contexte de librairie donné par libctx (NULL signifie le contexte de librairie par défaut).

Toute propriété par défaut précédente pour le contexte de librairie spécifié sera supprimée.

EVP_get1_default_properties() récupère les propriétés par défaut définies pour toutes les futures récupérations d'algorithmes EVP, implicites comme explicites, pour le contexte de librairie spécifique.

EVP_default_properties_enable_fips() définit 'fips=yes' comme une propriété par défaut si enable est non nul, sinon il efface 'fips' de la requête de propriété par défaut pour le libctx donné. Il fusionne la requête de propriété par défaut FIPS avec toute chaîne de requête existante qui a été définie via EVP_set_default_properties().

EVP_default_properties_is_fips_enabled() indique si 'fips=yes' est une propriété par défaut pour le libctx donné.

NOTES

EVP_set_default_properties() et EVP_default_properties_enable_fips() ne sont pas thread-safe. Ils sont destinés à être appelés uniquement pendant la phase d'initialisation d'un libctx.

EVP_get1_default_properties() n'est pas thread-safe. L'application doit s'assurer que la référence du contexte est valide et que les propriétés de récupération par défaut ne sont pas modifiées par un autre thread.

VALEURS DE RETOUR

EVP_set_default_properties() et EVP_default_properties_enable_fips() retournent 1 en cas de succès, ou 0 en cas d'échec. Une erreur est placée dans la pile d'erreurs si un échec survient.

EVP_default_properties_is_fips_enabled() retourne 1 si la propriété par défaut 'fips=yes' est définie pour le libctx donné, sinon elle retourne 0.

EVP_get1_default_properties() retourne de la mémoire allouée qui doit être libérée par OPENSSL_free(3) en cas de succès et NULL en cas d'échec.

VOIR AUSSI

EVP_MD_fetch(3)

HISTORIQUE

Les fonctions EVP_set_default_properties(), EVP_default_properties_enable_fips(), EVP_default_properties_is_fips_enabled() ont été ajoutées dans OpenSSL 3.0.

La fonction EVP_get1_default_properties() a été ajoutée dans OpenSSL 3.5.
