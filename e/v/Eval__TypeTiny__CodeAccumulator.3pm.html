Eval::TypeTiny::CodeAccumulator(3) Documentation Perl fournie par l'utilisateur Eval::TypeTiny::CodeAccumulator(3)

NOM

Eval::TypeTiny::CodeAccumulator - API alternative pour Eval::TypeTiny

SYNOPSIS

my $make_adder = 'Eval::TypeTiny::CodeAccumulator'->new(
  description => 'additionneur',
);

my $n = 40;
my $varname = $make_adder->add_variable( '$addend' => \$n );

$make_adder->add_line( 'sub {' );
$make_adder->increase_indent;
$make_adder->add_line( 'my $other_addend = shift;' );
$make_adder->add_gap;
$make_adder->add_line( 'return ' . $varname . ' + $other_addend;' );
$make_adder->decrease_indent;
$make_adder->add_line( '}' );

my $adder = $make_adder->compile;

say $adder->( 2 );  ## ==> 42

STATUT

Ce module est couvert par la politique de stabilité de Type-Tiny.

DESCRIPTION

Constructeur

new( %attrs )
L'unique attribut supporté actuellement est "description".

Méthodes

env()
Retourne l'environnement de compilation courant, un hashref de variables à capturer.
code()
Retourne le code source jusqu'à présent.
description()
Retourne la même description que celle passée au constructeur, le cas échéant.
add_line( @lignes_de_code )
Ajoute la ligne de code suivante.
"addf( $fmt, @args )"
Raccourci pour "add_line( sprintf $fmt, @args )".
add_gap()
Ajoute une ligne de code vide.
increase_indent()
Augmente le niveau d'indentation pour les lignes de code suivantes.
decrease_indent()
Diminue le niveau d'indentation pour les lignes de code suivantes.
"add_variable( $varname, $reference_vers_valeur )"
Ajoute une variable à l'environnement de compilation afin que le coderef généré puisse la capturer.

Si une variable existe déjà dans l'environnement avec ce nom, une nouvelle variable sera ajoutée avec un nom différent et ce nouveau nom sera retourné. Vous devriez toujours continuer à vous référer à la variable par ce nom retourné, au cas où.

add_placeholder( $nom_placeholder )
Ajoute une ligne de code qui est juste un commentaire, mais mémorise son numéro de ligne.
"fill_placeholder( $nom_placeholder, @lignes_de_code )"
Retourne à un placeholder précédemment inséré et le remplace par du code.

Alternativement, "add_placeholder" retourne un coderef, que vous pouvez appeler comme $callback->( @lignes_de_code ).

compile( %opts )
Compile le code et le retourne sous forme de coderef.

Les options sont passées à "eval_closure" de Eval::TypeTiny, mais ne peuvent pas inclure "code" ou "environment". "alias => 1" est probablement l'option la plus susceptible d'être utile, mais en général vous n'aurez pas besoin de fournir d'options.

finalize()
Cette méthode est appelée par "compile" juste avant de compiler le code. Tout ce qu'elle fait est de supprimer les commentaires de placeholders non remplis. Elle n'est pas destinée à être appelée par les utilisateurs finaux, mais elle est documentée car elle peut constituer un point d'extension utile si vous sous-classez cette classe.
