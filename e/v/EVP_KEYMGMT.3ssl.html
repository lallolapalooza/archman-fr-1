EVP_KEYMGMT(3ssl)

Paquet: openssl

Licences: Apache-2.0

EVP_KEYMGMT(3ssl) OpenSSL EVP_KEYMGMT(3ssl)

NOM

EVP_KEYMGMT, EVP_KEYMGMT_fetch, EVP_KEYMGMT_up_ref, EVP_KEYMGMT_free, EVP_KEYMGMT_get0_provider, EVP_KEYMGMT_is_a, EVP_KEYMGMT_get0_description, EVP_KEYMGMT_get0_name, EVP_KEYMGMT_do_all_provided, EVP_KEYMGMT_names_do_all, EVP_KEYMGMT_gettable_params, EVP_KEYMGMT_settable_params, EVP_KEYMGMT_gen_gettable_params, EVP_KEYMGMT_gen_settable_params - routines de gestion des clés EVP

SYNOPSISSE

#include <openssl/evp.h>
typedef struct evp_keymgmt_st EVP_KEYMGMT;
EVP_KEYMGMT *EVP_KEYMGMT_fetch(OSSL_LIB_CTX *ctx, const char *algorithm,
                               const char *properties);
int EVP_KEYMGMT_up_ref(EVP_KEYMGMT *keymgmt);
void EVP_KEYMGMT_free(EVP_KEYMGMT *keymgmt);
const OSSL_PROVIDER *EVP_KEYMGMT_get0_provider(const EVP_KEYMGMT *keymgmt);
int EVP_KEYMGMT_is_a(const EVP_KEYMGMT *keymgmt, const char *name);
const char *EVP_KEYMGMT_get0_name(const EVP_KEYMGMT *keymgmt);
const char *EVP_KEYMGMT_get0_description(const EVP_KEYMGMT *keymgmt);
void EVP_KEYMGMT_do_all_provided(OSSL_LIB_CTX *libctx,
                                 void (*fn)(EVP_KEYMGMT *keymgmt, void *arg),
                                 void *arg);
int EVP_KEYMGMT_names_do_all(const EVP_KEYMGMT *keymgmt,
                             void (*fn)(const char *name, void *data),
                             void *data);
const OSSL_PARAM *EVP_KEYMGMT_gettable_params(const EVP_KEYMGMT *keymgmt);
const OSSL_PARAM *EVP_KEYMGMT_settable_params(const EVP_KEYMGMT *keymgmt);
const OSSL_PARAM *EVP_KEYMGMT_gen_settable_params(const EVP_KEYMGMT *keymgmt);
const OSSL_PARAM *EVP_KEYMGMT_gen_gettable_params(const EVP_KEYMGMT *keymgmt);

DESCRIPTION

EVP_KEYMGMT est un objet méthode qui représente les implémentations de gestion des clés pour différents algorithmes cryptographiques. Cet objet méthode fournit la fonctionnalité permettant aux fournisseurs d'importer du matériel de clé de l'extérieur, ainsi que d'exporter du matériel de clé vers l'extérieur. La plupart de la fonctionnalité ne peut être utilisée qu'en interne et n'a pas d'interface publique ; cet objet est simplement transmis à d'autres fonctions lorsqu'il est nécessaire.

EVP_KEYMGMT_fetch() recherche un algorithme dans le fournisseur qui a été chargé dans le OSSL_LIB_CTX donné par ctx, ayant le nom donné par algorithm et les propriétés données par properties.

EVP_KEYMGMT_up_ref() incrémente le compteur de références pour le fourni EVP_KEYMGMT keymgmt.

EVP_KEYMGMT_free() décrémente le compteur de références pour le fourni EVP_KEYMGMT keymgmt, et lorsque le compteur atteint zéro, le libère. Si l'argument est NULL, rien n'est fait.

EVP_KEYMGMT_get0_provider() retourne le fournisseur qui a cette implémentation particulière.

EVP_KEYMGMT_is_a() vérifie si keymgmt est une implémentation d'un algorithme identifiable avec name.

EVP_KEYMGMT_get0_name() retourne le nom de l'algorithme de l'implémentation fournie pour le keymgmtdonné. Notez que le keymgmt peut avoir plusieurs synonymes associés. Dans ce cas, le premier nom de la définition de l'algorithme est retourné. La propriété de la chaîne retournée est conservée par l'objet keymgmt et ne doit pas être libérée par l'appelant.

EVP_KEYMGMT_names_do_all() parcourt tous les noms pour le keymgmt, et appelle fn avec chaque nom et data.

EVP_KEYMGMT_get0_description() retourne une description du keymgmt, destinée à l'affichage et à la consommation humaine. La description est à la discrétion de l'implémentation keymgmt .

EVP_KEYMGMT_do_all_provided() parcourt toutes les implémentations de keymgmt par tous les fournisseurs activés dans le contexte de bibliothèque libctx, et pour chacune des implémentations, appelle fn avec la méthode d'implémentation et data comme arguments.

EVP_KEYMGMT_gettable_params() et EVP_KEYMGMT_settable_params() retournent un tableau constant OSSL_PARAM(3) qui décrit les noms et les types des paramètres de clé qui peuvent être récupérés ou définis. EVP_KEYMGMT_gettable_params() est utilisé par EVP_PKEY_gettable_params(3).

EVP_KEYMGMT_gen_gettable_params() et EVP_KEYMGMT_gen_settable_params() retournent un tableau constant OSSL_PARAM(3) qui décrit les noms et les types des paramètres de génération de clé qui peuvent être récupérés ou définis via EVP_PKEY_CTX_get_params(3) ou EVP_PKEY_CTX_set_params(3) respectivement.

NOTES

EVP_KEYMGMT_fetch() peut être appelé implicitement par d'autres fonctions de récupération, en utilisant le même contexte de bibliothèque et les mêmes propriétés. Toute autre API qui utilise des clés fera généralement cela.

VALEURS RETOURNÉES

EVP_KEYMGMT_fetch() retourne un pointeur vers l'implémentation de gestion des clés représentée par un objet EVP_KEYMGMT, ou NULL en cas d'erreur.

EVP_KEYMGMT_up_ref() retourne 1 en cas de succès, ou 0 en cas d'erreur.

EVP_KEYMGMT_names_do_all() retourne 1 si le rappel a été appelé pour tous les noms. Une valeur de retour de 0 signifie que le rappel n'a pas été appelé pour aucun nom.

EVP_KEYMGMT_free() ne retourne aucune valeur.

EVP_KEYMGMT_get0_provider() retourne un pointeur vers un objet fournisseur, ou NULL en cas d'erreur.

EVP_KEYMGMT_is_a() retourne 1 si keymgmt était identifiable, sinon 0.

EVP_KEYMGMT_get0_name() retourne le nom de l'algorithme, ou NULL en cas d'erreur.

EVP_KEYMGMT_get0_description() retourne un pointeur vers une description, ou NULL s'il n'y en a pas.

EVP_KEYMGMT_gettable_params(), EVP_KEYMGMT_settable_params(), EVP_KEYMGMT_gen_gettable_params() et EVP_KEYMGMT_gen_settable_params() retournent un tableau constant OSSL_PARAM(3) ou NULL en cas d'erreur.
