NOM

EVP_MAC-Siphash - Implémentation EVP_MAC Siphash

DESCRIPTION

Support pour le calcul des MAC Siphash via l'API EVP_MAC.

Identité

Cette implémentation est identifiée par ce nom et ces propriétés, à utiliser avec EVP_MAC_fetch() :

"SIPHASH", "provider=default"

Paramètres supportés

La description générale de ces paramètres se trouve dans "PARAMETERS" dans EVP_MAC(3).

Tous ces paramètres peuvent être définis avec EVP_MAC_CTX_set_params(). De plus, le paramètre "size" peut être récupéré avec EVP_MAC_CTX_get_params(), ou avec EVP_MAC_CTX_get_mac_size(). La longueur du paramètre "size" ne doit pas dépasser celle d'un size_t.

"key" (OSSL_MAC_PARAM_KEY) <chaîne d'octets>
Définit la clé MAC. La définition de ce paramètre est identique au passage d'une key à EVP_MAC_init(3).
"size" (OSSL_MAC_PARAM_SIZE) <entier non signé>
Définit la taille du MAC.
"c-rounds" (OSSL_MAC_PARAM_C_ROUNDS) <entier non signé>
Spécifie le nombre de tours par bloc de message. Par défaut, il est de 2.
"d-rounds" (OSSL_MAC_PARAM_D_ROUNDS) <entier non signé>
Spécifie le nombre de tours de finalisation. Par défaut, il est de 4.

VOIR AUSSI

EVP_MAC_CTX_get_params(3), EVP_MAC_CTX_set_params(3), "PARAMETERS" dans EVP_MAC(3), OSSL_PARAM(3)
