EVP_PKEY_get_attr(3ssl)

Paquet: openssl

Licences: Apache-2.0

EVP_PKEY_GET_ATTR(3ssl) OpenSSL EVP_PKEY_GET_ATTR(3ssl)

NOM

EVP_PKEY_get_attr, EVP_PKEY_get_attr_count, EVP_PKEY_get_attr_by_NID, EVP_PKEY_get_attr_by_OBJ, EVP_PKEY_delete_attr, EVP_PKEY_add1_attr, EVP_PKEY_add1_attr_by_OBJ, EVP_PKEY_add1_attr_by_NID, EVP_PKEY_add1_attr_by_txt - Fonctions EVP_PKEY X509_ATTRIBUTE

SYNOPSIS

#include <openssl/x509.h>
int EVP_PKEY_get_attr_count(const EVP_PKEY *key);
int EVP_PKEY_get_attr_by_NID(const EVP_PKEY *key, int nid, int lastpos);
int EVP_PKEY_get_attr_by_OBJ(const EVP_PKEY *key, const ASN1_OBJECT *obj,
                             int lastpos);
X509_ATTRIBUTE *EVP_PKEY_get_attr(const EVP_PKEY *key, int loc);
X509_ATTRIBUTE *EVP_PKEY_delete_attr(EVP_PKEY *key, int loc);
int EVP_PKEY_add1_attr(EVP_PKEY *key, X509_ATTRIBUTE *attr);
int EVP_PKEY_add1_attr_by_OBJ(EVP_PKEY *key,
                              const ASN1_OBJECT *obj, int type,
                              const unsigned char *bytes, int len);
int EVP_PKEY_add1_attr_by_NID(EVP_PKEY *key,
                              int nid, int type,
                              const unsigned char *bytes, int len);
int EVP_PKEY_add1_attr_by_txt(EVP_PKEY *key,
                              const char *attrname, int type,
                              const unsigned char *bytes, int len);

DESCRIPTION

Ces fonctions sont utilisées par PKCS12.

EVP_PKEY_get_attr_by_OBJ() trouve l'emplacement du premier objet correspondant obj dans la liste d'attributs de key. La recherche commence à la position après lastpos. Si la valeur retournée est positive, elle peut être utilisée lors de l'appel suivant à EVP_PKEY_get_attr_by_OBJ() comme valeur de lastpos afin d'itérer sur les attributs restants. lastpos peut être défini à n'importe quelle valeur négative lors du premier appel, afin de commencer la recherche depuis le début de la liste d'attributs.

EVP_PKEY_get_attr_by_NID() est similaire à EVP_PKEY_get_attr_by_OBJ(), sauf qu'elle passe l'identifiant numérique (NID) nid associé à l'objet. Voir <openssl/obj_mac.h> pour une liste de NID_*.

EVP_PKEY_get_attr() retourne l'objet X509_ATTRIBUTE à l'indice loc dans la liste d'attributs de key. loc doit être dans l'intervalle de 0 à EVP_PKEY_get_attr_count() - 1.

EVP_PKEY_delete_attr() supprime l'objet X509_ATTRIBUTE à l'indice loc dans la liste d'attributs de key.

EVP_PKEY_add1_attr() ajoute une copie de l'objet X509_ATTRIBUTE passé à la liste d'attributs de key. Une nouvelle liste d'attributs key est créée si nécessaire. Une erreur se produit si attr est NULL, ou si l'attribut existe déjà.

EVP_PKEY_add1_attr_by_OBJ() crée un nouvel X509_ATTRIBUTE en utilisant X509_ATTRIBUTE_set1_object() et X509_ATTRIBUTE_set1_data() pour assigner un nouveau obj de type type et de données bytes de longueur len, puis l'ajoute à la liste d'attributs de l'objet key. Si obj existe déjà dans la liste d'attributs, une erreur se produit.

EVP_PKEY_add1_attr_by_NID() est similaire à EVP_PKEY_add1_attr_by_OBJ(), sauf qu'elle passe l'identifiant numérique (NID) nid associé à l'objet. Voir <openssl/obj_mac.h> pour une liste de NID_*.

EVP_PKEY_add1_attr_by_txt() est similaire à EVP_PKEY_add1_attr_by_OBJ(), sauf qu'elle passe un nom attrname associé à l'objet. Voir <openssl/obj_mac.h> pour une liste de noms SN_*.

VALEURS DE RETOUR

EVP_PKEY_get_attr_count() retourne le nombre d'attributs dans la liste d'attributs de l'objet key ou -1 si la liste d'attributs est NULL.

EVP_PKEY_get_attr_by_OBJ() retourne -1 si la liste est vide OU si l'objet n'est pas trouvé, sinon elle retourne l'emplacement de l'objet dans la liste.

EVP_PKEY_get_attr_by_NID() est similaire à EVP_PKEY_get_attr_by_OBJ(), sauf qu'elle retourne -2 si le nid n'est pas connu par OpenSSL.

EVP_PKEY_get_attr() retourne soit un X509_ATTRIBUTE, soit NULL en cas d'erreur.

EVP_PKEY_delete_attr() retourne soit le X509_ATTRIBUTE supprimé, soit NULL en cas d'erreur.

EVP_PKEY_add1_attr(), EVP_PKEY_add1_attr_by_OBJ(), EVP_PKEY_add1_attr_by_NID() et EVP_PKEY_add1_attr_by_txt() retournent 1 en cas de succès ou 0 sinon.

NOTES

La liste d'attributs d'un objet EVP_PKEY est initialement NULL. Toutes les fonctions énumérées ci-dessus retourneront une erreur à moins que EVP_PKEY_add1_attr() ne soit appelée. Toutes les fonctions énumérées supposent que key n'est pas NULL.
