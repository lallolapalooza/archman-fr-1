NOM

EVP_MAC-Poly1305 - L'implémentation EVP_MAC de Poly1305

DESCRIPTION

Support pour le calcul des MAC Poly1305 via l'API EVP_MAC.

Identité

Cette implémentation est identifiée par ce nom et ces propriétés, à utiliser avec EVP_MAC_fetch() :

"POLY1305", "provider=default"

Paramètres supportés

La description générale de ces paramètres se trouve dans "PARAMETERS" dans EVP_MAC(3).

Le paramètre suivant peut être défini avec EVP_MAC_CTX_set_params() :

"key" (OSSL_MAC_PARAM_KEY) <chaîne d'octets>
Définit la clé MAC. La définition de ce paramètre est identique au passage d'une clé à EVP_MAC_init(3).

Les paramètres suivants peuvent être récupérés avec EVP_MAC_CTX_get_params() :

"size" (OSSL_MAC_PARAM_SIZE) <entier non signé>
Récupère la taille du MAC.

Le paramètre "size" peut également être récupéré avec EVP_MAC_CTX_get_mac_size(). La longueur du paramètre "size" ne doit pas dépasser celle d'un unsigned int.

NOTES

L'implémentation OpenSSL du MAC Poly 1305 correspond à la RFC 7539.

Il est essentiel de ne jamais réutiliser la clé. L'implication de sécurité notée dans la RFC 8439 s'applique également à l'implémentation OpenSSL.

VOIR AUSSI

EVP_MAC_CTX_get_params(3), EVP_MAC_CTX_set_params(3), "PARAMETERS" dans EVP_MAC(3), OSSL_PARAM(3)
