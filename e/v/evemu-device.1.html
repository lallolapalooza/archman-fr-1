NOM

evemu-device, evemu-play, evemu-event - créer un périphérique d'entrée virtuel et relire une séquence d'événements

SYNTAXE

evemu-device [fichier-description]
evemu-play /dev/input/eventX < séquence-événements
evemu-play fichier-sequence-evenements.txt
evemu-event /dev/input/eventX [--sync] --type <type> --code <code> --value <valeur>

DESCRIPTION

evemu-device crée un périphérique d'entrée virtuel basé sur le fichier de description. Cette description est généralement créée par evemu-describe(1). evemu-device crée ensuite un nouveau périphérique d'entrée avec uinput et affiche son nom et son fichier périphérique sur la sortie standard.

evemu-play relit la séquence d'événements donnée sur l'entrée standard via le périphérique d'entrée. La séquence d'événements doit être dans le format créé par evemu-record(1). Si l'argument est un fichier contenant un enregistrement, evemu-play crée le périphérique et demande à l'utilisateur une relecture interactive des événements.

evemu-event joue exactement un événement avec l'heure actuelle. Si --sync est spécifié, evemu-event génère un événement EV_SYN après l'événement. Le type et le code de l'événement peuvent être spécifiés sous forme de valeur numérique ou de nom symbolique de linux/input.h.

evemu-device doit pouvoir écrire dans le nœud du périphérique uinput, et evemu-play doit pouvoir écrire dans le nœud du périphérique spécifié ; dans la plupart des cas, cela signifie qu'ils doivent être exécutés en tant que root.

VOIR AUSSI

evemu-describe(1) evemu-record(1)
