DESCRIPTIO

N

Ces types et fonctions aident l'application à calculer des MAC de différents types et avec différents algorithmes sous-jacents s'il y en

a.

Les MAC sont un peu complexes en ce sens que certains d'entre eux utilisent d'autres algorithmes pour le calcul effectif. HMAC utilise un condensat (digest), et CMAC utilise un chiffrement. Par conséquent, il y a parfois deux contextes à suivre, un pour l'algorithme MAC lui-même et un pour l'algorithme de calcul sous-jacent s'il y en a

un.

Pour rendre les choses moins ambiguës, ce manuel parle d'un « contexte » ou « contexte MAC », qui désigne le contexte au niveau MAC, et d'un « contexte sous-jacent » ou « contexte de calcul », qui désigne le contexte pour l'algorithme de calcul sous-jacent s'il y en a

un.

Type

s

EVP_MAC est un type qui contient l'implémentation d'un

MAC.

EVP_MAC_CTX est un type de contexte qui contient les informations MAC internes ainsi qu'une réfé

rence à un contexte de calcul, pour les MAC qui
reposent sur un algorithme de calcul sous-jacent.

Récupération d'implémentation

d'algorithme

EVP_MAC_fetch() récupère une implémentation d'un algorithme MAC, étant donné un contexte de bibliothèque libctx et un ensemble de propriétés. Voir « ALGORITHM FETCHING » dans crypto(7) pour plus

d'informations.

Voir « Message Authentication Code (MAC) » dans OSSL_PROVIDER-default(7) pour la liste des algorithmes pris en charge par le fournisseur par

défaut.

La valeur retournée doit éventuellement être libérée avec EVP_MAC_fre

e(3).

EVP_MAC_up_ref() incrémente le compteur de références d'un MAC déjà

récupéré.

EVP_MAC_free() libère un algorithme récupéré. NULL est un

paramètre valide, pour lequel
cette fonction est sans effet.

Fonctions de manipulation du

contexte

EVP_MAC_CTX_new() crée un nouveau contexte pour le type MAC mac. Le contexte créé peut ensuite être utilisé avec la plupart des autres fonctions décrites

ici.

EVP_MAC_CTX_free() libère le contenu du contexte, y compris un contexte sous-jacent s'il y en a un, ainsi que le contexte lui-même. NULL est un paramètre valide, pour lequel cette fonction est sans

effet.

EVP_MAC_CTX_dup() duplique le contexte src et retourne un contexte nouvellement

alloué.

EVP_MAC_CTX_get0_mac() retourne le EVP_MAC associé au contexte ct

x
.

Fonctions de

calcul

EVP_Q_mac() calcule le code d'authentification de message de data de longueur datalen en utilisant l'algorithme MAC name et la clé key de longueur keylen. L'algorithme MAC est récupéré en utilisant le libctx et la chaîne de requête de propriétés propq fournis. Il prend les paramètres subalg et params supplémentaires, qui peuvent tous deux être NULL si non nécessaires. Si out n'est pas NULL, il place le résultat dans la mémoire pointée par out, mais seulement si outsize est suffisant (sinon aucun calcul n'est effectué). Si out est NULL, il alloue et utilise un tampon de longueur appropriée, qui sera retourné en cas de succès et doit être libéré par l'appelant. Dans les deux cas, y compris en cas d'erreur, il assigne le nombre d'octets écrits à *outlen sauf si outlen est

NULL.

EVP_MAC_init() configure le contexte sous-jacent ctx avec les informations données via les arguments key et params. La clé MAC a une longueur de keylen et les paramètres dans params sont traités avant de définir la clé. Si key est NULL, la clé doit être définie via params soit dans le cadre de cet appel, soit séparément en utilisant EVP_MAC_CTX_set_params(). Fournir des params non NULL à cette fonction équivaut à appeler EVP_MAC_CTX_set_params() avec ces params pour le même ctx au préalable. Remarque : Il y a des exigences supplémentaires pour certains algorithmes MAC lors de la réinitialisation (c'est-à-dire l'appel à EVP_MAC_init() sur un EVP_MAC après EVP_MAC_final() a été appelé sur le même objet). Voir la section NOTES

ci-dessous.

EVP_MAC_init() doit être appelé avant EVP_MAC_update() et EVP_MAC_fin

al().

EVP_MAC_init_SKEY() est similaire à EVP_MAC_init() mais il accepte un objet opaque EVP_SKEY comme

clé.

EVP_MAC_update() ajoute datalen octets de data à l'entrée du

MAC.

EVP_MAC_final() effectue le calcul final et stocke le résultat dans la mémoire pointée par out de taille outsize, et définit le nombre d'octets écrits dans *outl. Si out est NULL ou outsize est trop petit, alors aucun calcul n'est effectué. Pour déterminer quelle sera la longueur de sortie et allouer de l'espace pour elle dynamiquement, appelez simplement avec out étant NULL et outl pointant vers un emplacement valide, puis allouez de l'espace et faites un deuxième appel avec out pointant vers l'espace

alloué.

EVP_MAC_finalXOF() effectue le calcul final pour un MAC basé sur un XOF et stocke le résultat dans la mémoire pointée par out de taille outsize

.

EVP_MAC_get_params() récupère des détails sur l'implémentation mac. L'ensemble de paramètres donné avec params détermine exactement quels paramètres doivent être récupérés. Notez qu'un paramètre qui est inconnu dans le contexte sous-jacent est simplement

ignorée.

EVP_MAC_CTX_get_params() récupère les paramètres choisis, étant donné le contexte ctx et son contexte sous-jacent. L'ensemble des paramètres donnés avec params détermine exactement quels paramètres doivent être récupérés. Notez qu'un paramètre qui est inconnu dans le contexte sous-jacent est simplement

ignoré.

EVP_MAC_CTX_set_params() transmet les paramètres choisis au contexte sous-jacent, étant donné un contexte ctx. L'ensemble des paramètres donnés avec params détermine exactement quels paramètres sont transmis. Si params vaut NULL, le contexte sous-jacent ne doit rien faire et doit retourner 1. Notez qu'un paramètre qui est inconnu dans le contexte sous-jacent est simplement ignoré. De plus, ce qui se passe lorsqu'un paramètre nécessaire n'est pas transmis est défini par l'implémentation

.

EVP_MAC_gettable_params() retourne un tableau OSSL_PARAM(3) qui décrit les paramètres récupérables et définissables. EVP_MAC_gettable_params() retourne les paramètres qui peuvent être utilisés avec EVP_MAC_get_pa

rams().

EVP_MAC_gettable_ctx_params() et EVP_MAC_CTX_gettable_params() retournent des tableaux constants OSSL_PARAM(3) qui décrivent les paramètres récupérables qui peuvent être utilisés avec EVP_MAC_CTX_get_params() . EVP_MAC_gettable_ctx_params() retourne les paramètres qui peuvent être récupérés depuis l'algorithme, alors que EVP_MAC_CTX_gettable_params() retourne les paramètres qui peuvent être récupérés dans l'état actuel du contexte. EVP_MAC_settable_ctx_params(

)

et EVP_MAC_CTX_settable_params() retournent des tableaux constants OSSL_PARAM(3) qui décrivent les paramètres définissables qui peuvent être utilisés avec EVP_MAC_CTX_set_params(). EVP_MAC_settable_ctx_params() retourne les paramètres qui peuvent être récupérés depuis l'algorithme, alors que EVP_MAC_CTX_settable_params() retourne les paramètres qui peuvent être récupérés dans l'état actuel du contexte. EXEMPLES
#include <stdlib.h>
#include <stdio.h>
#include <string.h>
#include <stdarg.h>
#include <unistd.h>
#include <openssl/evp.h>
#include <openssl/err.h>
#include <openssl/params.h>
int main() {
    EVP_MAC *mac = EVP_MAC_fetch(NULL, getenv("MY_MAC"), NULL);
    const char *cipher = getenv("MY_MAC_CIPHER");
    const char *digest = getenv("MY_MAC_DIGEST");
    const char *key = getenv("MY_KEY");
    EVP_MAC_CTX *ctx = NULL;
    unsigned char buf[4096];
    size_t read_l;
    size_t final_l;
    size_t i;
    OSSL_PARAM params[3];
    size_t params_n = 0;
    if (cipher != NULL)
        params[params_n++] =
            OSSL_PARAM_construct_utf8_string("cipher", (char*)cipher, 0);
    if (digest != NULL)
        params[params_n++] =
            OSSL_PARAM_construct_utf8_string("digest", (char*)digest, 0);
    params[params_n] = OSSL_PARAM_construct_end();
    if (mac == NULL
        || key == NULL
        || (ctx = EVP_MAC_CTX_new(mac)) == NULL
        || !EVP_MAC_init(ctx, (const unsigned char *)key, strlen(key),
                         params))
        goto err;
    while ( (read_l = read(STDIN_FILENO, buf, sizeof(buf))) > 0) {
        if (!EVP_MAC_update(ctx, buf, read_l))
            goto err;
    }
    if (!EVP_MAC_final(ctx, buf, &final_l, sizeof(buf)))
        goto err;
    printf("Result: ");
    for (i = 0; i < final_l; i++)
        printf("%02X", buf[i]);
    printf("\n");
    EVP_MAC_CTX_free(ctx);
    EVP_MAC_free(mac);
    exit(0);
 err:
    EVP_MAC_CTX_free(ctx);
    EVP_MAC_free(mac);
    fprintf(stderr, "Something went wrong\n");
    ERR_print_errors_fp(stderr);
    exit (1);
}
