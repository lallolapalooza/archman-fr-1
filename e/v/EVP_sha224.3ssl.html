NOM

EVP_sha224, EVP_sha256, EVP_sha512_224, EVP_sha512_256, EVP_sha384, EVP_sha512 - SHA-2 pour EVP

SYNOPIS

#include <openssl/evp.h>
const EVP_MD *EVP_sha224(void);
const EVP_MD *EVP_sha256(void);
const EVP_MD *EVP_sha512_224(void);
const EVP_MD *EVP_sha512_256(void);
const EVP_MD *EVP_sha384(void);
const EVP_MD *EVP_sha512(void);

DESCRIPTION

SHA-2 (Secure Hash Algorithm 2) est une famille de fonctions de hachage cryptographiques standardisées dans le NIST FIPS 180-4, publiées pour la première fois en 2001.

EVP_sha224(), EVP_sha256(), EVP_sha512_224, EVP_sha512_256, EVP_sha384(), EVP_sha512()
Les algorithmes SHA-2 SHA-224, SHA-256, SHA-512/224, SHA512/256, SHA-384 et SHA-512, qui génèrent respectivement 224, 256, 224, 256, 384 et 512 bits de sortie à partir d'une entrée donnée.

Les deux algorithmes : SHA-512/224 et SHA512/256 sont des formes tronquées de l'algorithme SHA-512. Ils sont distincts de SHA-224 et SHA-256 même si leurs sorties ont la même taille.

NOTES

Les développeurs doivent être conscients des implications négatives sur les performances lors de l'appel de ces fonctions à plusieurs reprises et devraient envisager d'utiliser EVP_MD_fetch(3) avec EVP_MD-SHA2(7) à la place. Voir "Performances" dans crypto(7) pour plus d'informations.

VALEURS DE RETOUR

Ces fonctions retournent une structure EVP_MD qui contient l'implémentation du digest de message. Voir EVP_MD_meth_new(3) pour les détails de la structure EVP_MD.

CONFORMITÉ

NIST FIPS 180-4.
