NOM

Event::ExecFlow::Scheduler - Classe abstraite pour la planification parallèle

SYNOPSIS

#-- Créer un nouvel objet Scheduler
my $scheduler = Event::ExecFlow::Scheduler::XYZ->new ( ... );
#-- Attacher le planificateur à un travail de groupe avec exécution parallèle
$group_job->set_parallel(1);
$group_job->set_scheduler($scheduler);
#-- Les méthodes suivantes sont appelées par Event::ExecFlow
#-- à l'exécution
$scheduler->schedule_job($job);
$scheduler->job_finished($job);

DESCRIPTION

Cette classe de base abstraite représente simplement une interface qui doit être implémentée par des planificateurs personnalisés pour contrôler l'exécution des travaux dans un Event::ExecFlow::Group dont l'option parallèle est définie.

Event::ExecFlow fournit un exemple très simple de planificateur qui limite simplement le nombre maximum de travaux exécutés en parallèle : Event::ExecFlow::Scheduler::SimpleMax.
