NOM

EVP_md2 - MD2 pour EVP

SYNTAXE

#include <openssl/evp.h>
const EVP_MD *EVP_md2(void);

DESCRIPTION

MD2 est une fonction de hachage cryptographique standardisée dans la RFC 1319 et conçue par Ronald Rivest. Cette implémentation n'est disponible qu'avec le fournisseur hérité.

EVP_md2()
L'algorithme MD2 qui produit une sortie de 128 bits à partir d'une entrée donnée.

NOTES

Les développeurs doivent être conscients des implications négatives sur les performances de l'appel de cette fonction plusieurs fois et envisager d'utiliser EVP_MD_fetch(3) avec EVP_MD-MD2(7) à la place. Voir "Performance" dans crypto(7) pour plus d'informations.

VALEURS DE RETOUR

Ces fonctions retournent une structure EVP_MD qui contient l'implémentation du résumé de message. Voir EVP_MD_meth_new(3) pour les détails de la structure EVP_MD.

CONFORMITE

IETF RFC 1319.

VOIR AUSSI

evp(7), provider(7), EVP_DigestInit(3)
