NOM

EVP_sha3_224, EVP_sha3_256, EVP_sha3_384, EVP_sha3_512, EVP_shake128, EVP_shake256 - SHA-3 pour EVP

SYNTAXE

#include <openssl/evp.h>
const EVP_MD *EVP_sha3_224(void);
const EVP_MD *EVP_sha3_256(void);
const EVP_MD *EVP_sha3_384(void);
const EVP_MD *EVP_sha3_512(void);
const EVP_MD *EVP_shake128(void);
const EVP_MD *EVP_shake256(void);

DESCRIPTION

SHA-3 (Secure Hash Algorithm 3) est une famille de fonctions de hachage cryptographiques standardisées dans le NIST FIPS 202, publiées pour la première fois en 2015. Elle est basée sur l'algorithme Keccak.

EVP_sha3_224(), EVP_sha3_256(), EVP_sha3_384(), EVP_sha3_512()
Les algorithmes SHA-3 SHA-3-224, SHA-3-256, SHA-3-384 et SHA-3-512 respectivement. Ils produisent 224, 256, 384 et 512 bits de sortie à partir d'une entrée donnée.
EVP_shake128(), EVP_shake256()
Les fonctions à sortie extensible (XOF) SHAKE-128 et SHAKE-256 qui peuvent générer une longueur de hachage variable.

Plus spécifiquement, EVP_shake128 offre une sécurité globale de 128 bits, tandis que EVP_shake256 offre une sécurité globale de 256 bits.

NOTES

Les développeurs doivent être conscients des implications négatives en termes de performances lors de l'appel de ces fonctions à plusieurs reprises et devraient envisager d'utiliser EVP_MD_fetch(3) avec EVP_MD-SHA3(7) ou EVP_MD-SHAKE(7) à la place. Voir "Performance" dans crypto(7) pour plus d'informations.

VALEURS DE RETOUR

Ces fonctions retournent une structure EVP_MD qui contient l'implémentation du résumé de message. Voir EVP_MD_meth_new(3) pour les détails de la structure EVP_MD.

CONFORME À

NIST FIPS 202.
