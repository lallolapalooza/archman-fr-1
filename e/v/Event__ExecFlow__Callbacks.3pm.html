NOM

Event::ExecFlow::Callbacks - Callbacks attachés aux jobs

SYNOPSIS

#-- Créer un nouvel objet Callbacks
my $callbacks = Event::ExecFlow::Callbacks->new (
  sub { print "sub appelée\n" },
  sub { print "une autre sub de celle-ci appelée\n" },
);
#-- Attacher des callbacks à un job
$job->set_pre_callbacks($callbacks);

#-- Ajouter d'autres subs
$callbacks->add(sub { print "une sub ajoutée plus tard\n" });
$callbacks->prepend(sub { print "une sub ajoutée au début de la liste des subs } );
#-- les méthodes execute() sont exécutées plus tard par Event::ExecFlow
$callbacks->execute($job);

DESCRIPTION

Cette classe représente une ou plusieurs fermetures (closures) qui peuvent être attachées comme callbacks à un Event::ExecFlow::Job.
