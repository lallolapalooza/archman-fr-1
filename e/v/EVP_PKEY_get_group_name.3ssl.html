NOM

EVP_PKEY_get_group_name - obtenir le nom du groupe d'une clé

SYNTAXE

#include <openssl/evp.h>
int EVP_PKEY_get_group_name(EVP_PKEY *pkey, char *gname, size_t gname_sz,
                            size_t *gname_len);

DESCRIPTION

EVP_PKEY_get_group_name() remplit le nom du groupe de la clé pkey dans gname, jusqu'à un maximum de gname_sz octets, y compris le octet NUL final, et assigne *gname_len la longueur réelle du nom sans inclure le octet NUL, si le type de clé de pkey le prend en charge. gname ainsi que gname_len peuvent être individuellement NULL, et ne seront pas remplis ou assignés dans ce cas.

NOTES

Parmi les types de clés OpenSSL standards, cela n'est pris en charge que pour les clés DH, EC et SM2. D'autres fournisseurs peuvent prendre en charge cela pour des types de clés supplémentaires.

VALEURS DE RETOUR

EVP_PKEY_get_group_name() retourne 1 si le nom du groupe a pu être rempli, sinon 0.

HISTORIQUE

Cette fonction a été ajoutée dans OpenSSL 3.0.
