EVP_SIGNATURE(3ssl)

Paquet: openssl

Licences: Apache-2.0

EVP_SIGNATURE(3ssl) OpenSSL EVP_SIGNATURE(3ssl)

NOM

EVP_SIGNATURE, EVP_SIGNATURE_fetch, EVP_SIGNATURE_free, EVP_SIGNATURE_up_ref, EVP_SIGNATURE_is_a, EVP_SIGNATURE_get0_provider, EVP_SIGNATURE_do_all_provided, EVP_SIGNATURE_names_do_all, EVP_SIGNATURE_get0_name, EVP_SIGNATURE_get0_description, EVP_SIGNATURE_gettable_ctx_params, EVP_SIGNATURE_settable_ctx_params - Fonctions pour gérer les objets d'algorithmes EVP_SIGNATURE

SYNOPIS

#include <openssl/evp.h>
typedef struct evp_signature_st EVP_SIGNATURE;
EVP_SIGNATURE *EVP_SIGNATURE_fetch(OSSL_LIB_CTX *ctx, const char *algorithm,
                                   const char *properties);
void EVP_SIGNATURE_free(EVP_SIGNATURE *signature);
int EVP_SIGNATURE_up_ref(EVP_SIGNATURE *signature);
const char *EVP_SIGNATURE_get0_name(const EVP_SIGNATURE *signature);
int EVP_SIGNATURE_is_a(const EVP_SIGNATURE *signature, const char *name);
OSSL_PROVIDER *EVP_SIGNATURE_get0_provider(const EVP_SIGNATURE *signature);
void EVP_SIGNATURE_do_all_provided(OSSL_LIB_CTX *libctx,
                                   void (*fn)(EVP_SIGNATURE *signature,
                                              void *arg),
                                   void *arg);
int EVP_SIGNATURE_names_do_all(const EVP_SIGNATURE *signature,
                               void (*fn)(const char *name, void *data),
                               void *data);
const char *EVP_SIGNATURE_get0_name(const EVP_SIGNATURE *signature);
const char *EVP_SIGNATURE_get0_description(const EVP_SIGNATURE *signature);
const OSSL_PARAM *EVP_SIGNATURE_gettable_ctx_params(const EVP_SIGNATURE *sig);
const OSSL_PARAM *EVP_SIGNATURE_settable_ctx_params(const EVP_SIGNATURE *sig);

DESCRIPTION

EVP_SIGNATURE_fetch() récupère l'implémentation pour l'algorithme donné algorithm auprès de tout fournisseur qui l'offre, selon les critères spécifiés par les properties. L'algorithme sera celui qui offre des fonctions pour effectuer des tâches liées à la signature, telles que la signature et la vérification. Voir "ALGORITHM FETCHING" dans crypto(7) pour plus d'informations.

La valeur retournée doit être libérée ultérieurement avec EVP_SIGNATURE_free().

EVP_SIGNATURE_free() décrémente le compteur de références pour la structure EVP_SIGNATURE. Typiquement, cette structure aura été obtenue par un appel précédent à EVP_SIGNATURE_fetch(). Si le compteur de références tombe à 0, la structure est libérée. Si l'argument est NULL, rien n'est fait.

EVP_SIGNATURE_up_ref() incrémente le compteur de références pour une structure EVP_SIGNATURE.

EVP_SIGNATURE_is_a() retourne 1 si signature est une implémentation d'un algorithme identifiable par name, sinon 0.

EVP_SIGNATURE_get0_provider() retourne le fournisseur à partir duquel signature a été récupéré.

EVP_SIGNATURE_do_all_provided() parcourt toutes les SIGNATURES implémentées par tous les fournisseurs activés dans le contexte de bibliothèque donné libctx, et pour chacune des implémentations, appelle la fonction donnée fn avec la méthode d'implémentation et le arg donné comme argument.

EVP_SIGNATURE_get0_name() retourne le nom de l'algorithme à partir de l'implémentation fournie pour la signature donnée. Notez que la signature peut avoir plusieurs synonymes associés. Dans ce cas, le premier nom de la définition de l'algorithme est retourné. La propriété de la chaîne retournée est conservée par l'objet signature et ne doit pas être libérée par l'appelant.

EVP_SIGNATURE_names_do_all() parcourt tous les noms pour la signature, et appelle fn avec chaque nom et data.

EVP_SIGNATURE_get0_description() retourne une description de la signature, destinée à l'affichage et à la consommation humaine. La description est à la discrétion de l'implémentation de la signature.

EVP_SIGNATURE_gettable_ctx_params() et EVP_SIGNATURE_settable_ctx_params() retournent un tableau constant OSSL_PARAM(3) qui décrit les noms et types des paramètres de clé qui peuvent être récupérés ou définis par un algorithme de signature en utilisant EVP_PKEY_CTX_get_params(3) et EVP_PKEY_CTX_set_params(3).

VALEURS DE RETOUR

EVP_SIGNATURE_fetch() retourne un pointeur vers un EVP_SIGNATURE en cas de succès ou NULL en cas d'échec.

EVP_SIGNATURE_up_ref() retourne 1 en cas de succès ou 0 sinon.

EVP_SIGNATURE_names_do_all() retourne 1 si la fonction de rappel a été appelée pour tous les noms. Une valeur de retour de 0 signifie que la fonction de rappel n'a été appelée pour aucun nom.

EVP_SIGNATURE_gettable_ctx_params() et EVP_SIGNATURE_settable_ctx_params() retournent un tableau constant OSSL_PARAM(3) ou NULL en cas d'erreur.

VOIR AUSSI

"ALGORITHM FETCHING" dans crypto(7), OSSL_PROVIDER(3)
