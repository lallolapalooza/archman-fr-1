NOM

evemu-device, evemu-play, evemu-event - créer un périphérique d'entrée virtuel et rejouer une séquence d'événements

SYNOPIS

evemu-device [fichier-description]
evemu-play /dev/input/eventX < séquence-événements
evemu-play fichier-séquence.txt
evemu-event /dev/input/eventX [--sync] --type <type> --code <code> --value <valeur>

DESCRIPTION

evemu-device crée un périphérique d'entrée virtuel basé sur le fichier-description. Cette description est généralement créée par evemu-describe(1). evemu-device crée ensuite un nouveau périphérique d'entrée avec uinput et affiche le nom et le fichier du périphérique sur stdout.

evemu-play rejoue la séquence d'événements donnée sur stdin via le périphérique d'entrée. La séquence d'événements doit être dans le format créé par evemu-record(1). Si l'argument est un fichier contenant un enregistrement, evemu-play crée le périphérique et invite l'utilisateur à rejouer interactivement les événements.

evemu-event joue exactement un événement avec l'heure actuelle. Si --sync est donné, evemu-event génère un événement EV_SYN après l'événement. Le type et le code de l'événement peuvent être spécifiés sous forme de valeur numérique ou de nom symbolique de linux/input.h.

evemu-device doit pouvoir écrire dans le nœud de périphérique uinput, et evemu-play doit pouvoir écrire dans le nœud de périphérique spécifié ; dans la plupart des cas, cela signifie qu'il doit être exécuté en tant que root.

VOIR AUSSI

evemu-describe(1) evemu-record(1)
