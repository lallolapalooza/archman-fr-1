NOM

EVP_rc5_32_12_16_cbc, EVP_rc5_32_12_16_cfb, EVP_rc5_32_12_16_cfb64, EVP_rc5_32_12_16_ecb, EVP_rc5_32_12_16_ofb - Chiffrement EVP RC5

SYNOPSIS

#include <openssl/evp.h>
const EVP_CIPHER *EVP_rc5_32_12_16_cbc(void);
const EVP_CIPHER *EVP_rc5_32_12_16_cfb(void);
const EVP_CIPHER *EVP_rc5_32_12_16_cfb64(void);
const EVP_CIPHER *EVP_rc5_32_12_16_ecb(void);
const EVP_CIPHER *EVP_rc5_32_12_16_ofb(void);

DESCRIPTION

Algorithme de chiffrement RC5 pour EVP.

EVP_rc5_32_12_16_cbc(), EVP_rc5_32_12_16_cfb(), EVP_rc5_32_12_16_cfb64(), EVP_rc5_32_12_16_ecb(), EVP_rc5_32_12_16_ofb()
Algorithme de chiffrement RC5 en modes CBC, CFB, ECB et OFB respectivement. Il s'agit d'un chiffrement à longueur de clé variable avec un paramètre supplémentaire « nombre de tours ». Par défaut, la longueur de clé est de 128 bits et le nombre de tours est de 12. D'autres longueurs de clé peuvent être définies à l'aide de EVP_CIPHER_CTX_set_key_length(3). La longueur maximale de clé est de 2040 bits.

Les ctrl spécifiques à rc5 suivants sont pris en charge (voir EVP_CIPHER_CTX_ctrl(3)).

EVP_CIPHER_CTX_ctrl(ctx, EVP_CTRL_SET_RC5_ROUNDS, rounds, NULL)
Définit le nombre de tours à rounds. Il doit s'agir de l'une des valeurs RC5_8_ROUNDS, RC5_12_ROUNDS ou RC5_16_ROUNDS.
EVP_CIPHER_CTX_ctrl(ctx, EVP_CTRL_GET_RC5_ROUNDS, 0, &rounds)
Stocke le nombre de tours actuellement configuré dans *rounds, où *rounds est un entier.

NOTES

Les développeurs doivent être conscients des implications négatives en termes de performance lors de l'appel répété de ces fonctions et devraient envisager d'utiliser EVP_CIPHER_fetch(3) avec EVP_CIPHER-RC5(7) à la place. Voir « Performance » dans crypto(7) pour plus d'informations.

VALEUR DE RETOUR

Ces fonctions retournent une structure EVP_CIPHER qui contient l'implémentation du chiffrement symétrique. Voir EVP_CIPHER_meth_new(3) pour plus de détails sur la structure EVP_CIPHER.
