DESCRIPTIO

N

La génération de clés est parfois simple : il suffit de générer les nombres de la clé et le tour est joué. Cependant, certains types de clés nécessitent des paramètres de clé, souvent appelés paramètres de domaine mais pas nécessairement limités à cela, qui doivent également être générés. En plus de cela, l'appelant peut souhaiter définir des paramètres de génération fournis par l'utilisateur qui affectent davantage la génération des paramètres de clé ou de la clé, comme la taille de clé

souhaitée.

Pour permettre flexiblement tout ce qui vient d'être décrit, la génération des paramètres de clé et de la clé est divisée en une initialisation d'un contexte d'algorithme de clé, des fonctions pour définir les paramètres fournis par l'utilisateur, et enfin la fonction de génération des paramètres de clé ou de la clé

elle-même.

Le contexte d'algorithme de clé doit être créé à l'aide de EVP_PKEY_CTX_new(3) ou de variantes de celle-ci, voir ce manuel pour les

détails.

EVP_PKEY_keygen_init() initialise un contexte d'algorithme de clé publique ctx pour une opération de génération de

clé.

EVP_PKEY_paramgen_init() est similaire à EVP_PKEY_keygen_init() sauf que les paramètres de clé sont

générés.

Après l'initialisation, les paramètres de génération peuvent être fournis avec EVP_PKEY_CTX_ctrl(3) ou EVP_PKEY_CTX_set_params(3), ou toute autre fonction décrite dans ces

manuels.

EVP_PKEY_generate() effectue l'opération de génération, les paramètres de clé ou la clé résultants sont écrits dans *ppkey. Si *ppkey est NULL lorsque cette fonction est appelée, il sera alloué, et devrait être libéré par l'appelant lorsqu'il n'est plus utile, à l'aide de EVP_PKEY_fr

ee(3).

EVP_PKEY_paramgen() et EVP_PKEY_keygen() font exactement la même chose que EVP_PKEY_generate(), après avoir vérifié que l' EVP_PKEY_paramgen_init() ou EVP_PKEY_keygen_init() correspondant a été utilisé pour initialiser ctx. Ce sont des fonctions plus anciennes qui sont conservées pour la compatibilité ascendante. Il est sûr d'utiliser EVP_PKEY_generate() à la

place.

La fonction EVP_PKEY_set_cb() définit le rappel de génération de clé ou de paramètre à cb. La fonction EVP_PKEY_CTX_get_cb() renvoie le rappel de génération de clé ou de

paramètre.

La fonction EVP_PKEY_CTX_get_keygen_info() renvoie les paramètres associés à l'opération de génération. Si idx vaut -1, le nombre total de paramètres disponibles est renvoyé. Toute valeur non négative renvoie la valeur de ce paramètre. EVP_PKEY_CTX_gen_keygen_info() avec une valeur non négative pour idx ne devrait être appelée qu'à l'intérieur du rappel de

génération.

Si le rappel renvoie 0, l'opération de génération de clé est interrompue et une erreur se produit. Cela peut se produire pendant une opération longue où un utilisateur clique sur un bouton « annuler »

.

Les fonctions EVP_PKEY_CTX_set_app_data() et EVP_PKEY_CTX_get_app_data() définissent et récupèrent un pointeur opaque. Cela peut être utilisé pour définir une valeur définie par l'application qui peut être récupérée dans le rappel : par exemple un handle utilisé pour mettre à jour une « boîte de dialogue de progression »

.

EVP_PKEY_Q_keygen() abstracte l'utilisation explicite de EVP_PKEY_CTX tout en fournissant une manière « rapide » mais limitée de générer une nouvelle paire de clés asymétriques. Il fournit des raccourcis pour les cas simples et courants de génération de clé. Comme d'habitude, le contexte de bibliothèque libctx et la requête de propriété propq peuvent être donnés pour récupérer des algorithmes auprès des fournisseurs. Si type est « RSA », un paramètre size_t doit être donné pour spécifier la taille de la clé RSA. Si type est « EC », un paramètre de chaîne de caractères doit être donné pour spécifier le nom de la courbe EC. Si type est : « ED25519 », « ED448 », « SM2 », « X25519 », « X448 », « ML-DSA-44 », « ML-DSA-65 », « ML-DSA-87 », « ML-KEM-512 », « ML-KEM-768 », ou « ML-KEM-1024 », aucun autre paramètre n'est nécessaire. D'autres types de clés peuvent être possibles s'ils sont fournis par les fournisseurs chargés. EVP_PKEY_Q_keygen() peut être utilisable avec ces types de

clés tant qu'ils ne nécessi
tent pas d'autres paramètres.

VALEURS

RENVOYÉES

EVP_PKEY_keygen_init(), EVP_PKEY_paramgen_init(), EVP_PKEY_keygen() et EVP_PKEY_paramgen() renvoient 1 en cas de succès et 0 ou une valeur négative en cas d'échec. En particulier, une valeur de retour de -2 indique que l'opération n'est pas prise en charge par l'algorithme de clé

publique.

EVP_PKEY_Q_keygen() renvoie un EVP_PKEY, ou NULL

en cas
d'échec.

REMARQUE

S

Après l'appel à EVP_PKEY_keygen_init() ou EVP_PKEY_paramgen_init(), des opérations de contrôle spécifiques à l'algorithme peuvent être effectuées pour définir les paramètres appropriés pour

l'opération.

Les fonctions EVP_PKEY_keygen() et EVP_PKEY_paramgen() peuvent être appelées plus d'une fois sur le même contexte si plusieurs opérations sont effectuées avec les mêmes

paramètres.

La signification des paramètres passés au rappel dépendra de l'algorithme et de l'implémentation spécifique de l'algorithme. Certains peuvent ne donner aucune information utile pendant la génération de la clé ou des paramètres. D'autres peuvent ne même pas appeler le

rappel.

L'opération effectuée par la génération de clé ou de paramètre dépend de l'algorithme utilisé. Dans certains cas (par exemple EC avec une courbe nommée fournie), l'option « génération » se contente de définir les champs appropriés dans une structure

EVP_PKEY.

Dans OpenSSL, une structure EVP_PKEY contenant une clé privée contient également les composants et paramètres de la clé

publique (s'il y en a). Une clé privée OpenSSL est équivalente à ce que certaines bibliothèques appellent une « paire de clé
s ». Une clé privée peut être utilisée dans des fonctions qui nécessitent l'utilisation d'une clé publique ou de paramètres.

EXEMPLE

S

Générer une clé RSA de 2048 bits

: 
#include <openssl/evp.h>
#include <openssl/rsa.h>
EVP_PKEY_CTX *ctx;
EVP_PKEY *pkey = NULL;
ctx = EVP_PKEY_CTX_new_id(EVP_PKEY_RSA, NULL);
if (!ctx)
    /* Une erreur s'est produite */
if (EVP_PKEY_keygen_init(ctx) <= 0)
    /* Erreur */
if (EVP_PKEY_CTX_set_rsa_keygen_bits(ctx, 2048) <= 0)
    /* Erreur */
/* Générer la clé */
if (EVP_PKEY_keygen(ctx, &pkey) <= 0)
    /* Erreur
*/

Générer une clé à partir d'un ensemble de paramètres

: 
#include <openssl/evp.h>
#include <openssl/rsa.h>
EVP_PKEY_CTX *ctx;
ENGINE *eng;
EVP_PKEY *pkey = NULL, *param;
/* On suppose que param et eng sont déjà configurés */
ctx = EVP_PKEY_CTX_new(param, eng);
if (!ctx)
    /* Une erreur s'est produite */
if (EVP_PKEY_keygen_init(ctx) <= 0)
    /* Erreur */
/* Générer la clé */
if (EVP_PKEY_keygen(ctx, &pkey) <= 0)
    /* Erreur
*/

Exemple de rappel de génération pour les implémentations de clé publique OpenSSL

: 
/* Les données de l'application sont un BIO pour sortir l'état */
EVP_PKEY_CTX_set_app_data(ctx, status_bio);
static int genpkey_cb(EVP_PKEY_CTX *ctx)
{
    char c = '*';
    BIO *b = EVP_PKEY_CTX_get_app_data(ctx);
    int p = EVP_PKEY_CTX_get_keygen_info(ctx, 0);
    if (p == 0)
        c = '.';
    if (p == 1)
        c = '+';
    if (p == 2)
        c = '*';
    if (p == 3)
        c = '\n';
    BIO_write(b, &c, 1);
    (void)BIO_flush(b);
    return 1;
}
