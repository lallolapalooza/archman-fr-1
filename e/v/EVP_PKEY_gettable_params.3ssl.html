DESCRIPTIO

N

Voir OSSL_PARAM(3) pour des informations sur les

paramètres.

EVP_PKEY_get_params() récupère les paramètres de la clé pkey, selon le contenu de params. EVP_PKEY_gettable_params() renvoie une

liste constante de

params indiquant les noms et les types des paramètres de clé qui peuvent être récupérés. U

n

OSSL_PARAM(3) de type OSSL_PARAM_INTEGER ou OSSL_PARAM_UNSIGNED_INTEGER est de longueur arbitraire. Un tel paramètre peut être obtenu à l'aide de l'une des fonctions EVP_PKEY_get_int_param(), EVP_PKEY_get_size_t_param() ou EVP_PKEY_get_bn_param(). Tenter d'obtenir une valeur entière qui ne tient pas dans un type C natif int entraînera l'échec de EVP_PKEY_get_int_param(). De même, tenter d'obtenir une valeur entière qui est négative ou qui ne tient pas dans un type C natif size_t en utilisant EVP_PKEY_get_size_t_param() échouera également. EVP_PKEY_get_int_param() récupère la valeur

entière

*out associée à la clé pkey avec un nom de key_name si elle tient dans le type "int". Pour les paramètres qui ne tiennent pas dans "int", utiliser EVP_PKEY_get_bn_param(). EVP_PKEY_get_size_t_param() récupèr

e la valeur size_t

*out associée à la clé pkey avec un nom de key_name si elle tient dans le type "size_t". Pour les paramètres qui ne tiennent pas dans "size_t", utiliser EVP_PKEY_get_bn_param(). EVP_PKEY_get_bn_param() récupère

la valeur BIGNUM

**bn associée à la clé pkey avec un nom de key_name. Si *bn est NULL, alors le BIGNUM est alloué par la méthode. EVP_PKEY_get_utf8_string_param() récupère la valeur de chaîne

UTF8

d'une clé pkey dans un tampon str de taille maximale max_buf_sz associée à un nom de key_name. La taille maximale doit être suffisamment grande pour accueillir la valeur de la chaîne, y compris l'octet de terminaison NUL, sinon cette fonction échouera. Si out_len n'est pas NULL, *out_len est défini à la longueur de la chaîne sans compter l'octet de terminaison NUL. La taille de tampon requise sans compter l'octet de terminaison NUL peut être obtenue à partir de *out_len en appelant la fonction avec str défini à

NULL.

EVP_PKEY_get_octet_string_param() récupère la valeur de chaîne d'octets d'une clé pkey dans un tampon buf de taille maximale max_buf_sz associée à un nom de key_name. Si out_len n'est pas NULL, *out_len est défini à la longueur du contenu. La taille de tampon requise peut être obtenue à partir de *out_len en appe

lant la fon
ction avec

VALEURS REN

VOYÉES

EVP_PKEY_gettable_params() renvoie NULL en cas d'erreur ou si elle n'est pas prise en charge. Toutes les autres méthodes renvoient 1 si une valeur associée au key_name de la clé a été renvoyée avec succès, ou 0 en cas d'erreur. Une erreur peut être renvoyée par les méthodes EVP_PKEY_get_utf8_string_param() et EVP_PKEY_get_octet_string_param() si max_buf_sz n'est pas assez grand pour contenir la valeur. Si out_len n'es

t pas
NULL,

*out_len sera assigné à la taille de tampon requise pour contenir

la valeur.
