NOM

EVP_CIPHER-BLOWFISH - Les implémentations EVP_CIPHER de BLOWFISH

DESCRIPTION

Support du chiffrement symétrique BLOWFISH en utilisant l'API EVP_CIPHER.

Noms d'algorithmes

Les algorithmes suivants sont disponibles dans le fournisseur hérité :

"BF-ECB"
"BF-CBC"
"BF-OFB"
"BF-CFB"

Paramètres

Cette implémentation supporte les paramètres décrits dans "PARAMETERS" dans EVP_EncryptInit(3).

VOIR AUSSI

provider-cipher(7), OSSL_PROVIDER-legacy(7)
