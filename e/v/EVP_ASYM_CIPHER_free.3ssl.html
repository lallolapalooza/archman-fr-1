EVP_ASYM_CIPHER_free(3ssl)

EVP_ASYM_CIPHER_FREE(3ssl) OpenSSL EVP_ASYM_CIPHER_FREE(3ssl)

NOM

EVP_ASYM_CIPHER_fetch, EVP_ASYM_CIPHER_free, EVP_ASYM_CIPHER_up_ref, EVP_ASYM_CIPHER_is_a, EVP_ASYM_CIPHER_get0_provider, EVP_ASYM_CIPHER_do_all_provided, EVP_ASYM_CIPHER_names_do_all, EVP_ASYM_CIPHER_get0_name, EVP_ASYM_CIPHER_get0_description, EVP_ASYM_CIPHER_gettable_ctx_params, EVP_ASYM_CIPHER_settable_ctx_params - Fonctions pour gérer les objets des algorithmes EVP_ASYM_CIPHER

SYNOPSIS

#include <openssl/evp.h>
EVP_ASYM_CIPHER *EVP_ASYM_CIPHER_fetch(OSSL_LIB_CTX *ctx, const char *algorithm,
                                       const char *properties);
void EVP_ASYM_CIPHER_free(EVP_ASYM_CIPHER *cipher);
int EVP_ASYM_CIPHER_up_ref(EVP_ASYM_CIPHER *cipher);
const char *EVP_ASYM_CIPHER_get0_name(const EVP_ASYM_CIPHER *cipher);
int EVP_ASYM_CIPHER_is_a(const EVP_ASYM_CIPHER *cipher, const char *name);
OSSL_PROVIDER *EVP_ASYM_CIPHER_get0_provider(const EVP_ASYM_CIPHER *cipher);
void EVP_ASYM_CIPHER_do_all_provided(OSSL_LIB_CTX *libctx,
                                     void (*fn)(EVP_ASYM_CIPHER *cipher,
                                                void *arg),
                                     void *arg);
int EVP_ASYM_CIPHER_names_do_all(const EVP_ASYM_CIPHER *cipher,
                                 void (*fn)(const char *name, void *data),
                                 void *data);
const char *EVP_ASYM_CIPHER_get0_description(const EVP_ASYM_CIPHER *cipher);
const OSSL_PARAM *EVP_ASYM_CIPHER_gettable_ctx_params(const EVP_ASYM_CIPHER *cip);
const OSSL_PARAM *EVP_ASYM_CIPHER_settable_ctx_params(const EVP_ASYM_CIPHER *cip);

DESCRIPTION

EVP_ASYM_CIPHER_fetch() récupère l'implémentation pour l'algorithm donné à partir de n'importe quel fournisseur l'offrant, dans les critères donnés par les properties et dans le cadre du contexte de bibliothèque ctx donné (voir OSSL_LIB_CTX(3)). L'algorithme sera l'un offrant des fonctions pour effectuer des tâches liées au chiffrement asymétrique, telles que le chiffrement et le déchiffrement asymétriques. Voir "ALGORITHM FETCHING" dans crypto(7) pour plus d'informations.

La valeur retournée doit être libérée ultérieurement avec EVP_ASYM_CIPHER_free().

EVP_ASYM_CIPHER_free() décrémente le compteur de références pour la structure EVP_ASYM_CIPHER. Typiquement, cette structure aura été obtenue lors d'un appel précédent à EVP_ASYM_CIPHER_fetch(). Si le compteur de références tombe à 0, la structure est libérée. Si l'argument est NULL, rien n'est fait.

EVP_ASYM_CIPHER_up_ref() incrémente le compteur de références pour une structure EVP_ASYM_CIPHER.

EVP_ASYM_CIPHER_is_a() retourne 1 si cipher est une implémentation d'un algorithme identifiable par name, sinon 0.

EVP_ASYM_CIPHER_get0_provider() retourne le fournisseur d'où cipher a été récupéré.

EVP_ASYM_CIPHER_do_all_provided() parcourt tous les EVP_ASYM_CIPHER implémentés par tous les fournisseurs activés dans le contexte de bibliothèque libctx donné, et pour chacune des implémentations, appelle la fonction fn donnée avec la méthode d'implémentation et le arg donné comme argument.

EVP_ASYM_CIPHER_get0_name() retourne le nom de l'algorithme depuis l'implémentation fournie pour le cipher donné. Notez que le cipher peut avoir plusieurs synonymes associés. Dans ce cas, le premier nom de la définition de l'algorithme est retourné. La propriété de la chaîne retournée est conservée par l'objet cipher et ne doit pas être libérée par l'appelant.

EVP_ASYM_CIPHER_names_do_all() parcourt tous les noms pour cipher, et appelle fn avec chaque nom et data.

EVP_ASYM_CIPHER_get0_description() retourne une description du cipher, destinée à l'affichage et à la consommation humaine. La description est à la discrétion de l'implémentation du cipher.

EVP_ASYM_CIPHER_gettable_ctx_params() et EVP_ASYM_CIPHER_settable_ctx_params() retournent un tableau constant OSSL_PARAM(3) qui décrit les noms et types des paramètres de clé qui peuvent être récupérés ou définis par un algorithme de chiffrement de clé en utilisant EVP_PKEY_CTX_get_params(3) et EVP_PKEY_CTX_set_params(3).

VALEUR DES RETOURS

EVP_ASYM_CIPHER_fetch() retourne un pointeur vers un EVP_ASYM_CIPHER en cas de succès ou NULL en cas d'échec.

EVP_ASYM_CIPHER_up_ref() retourne 1 en cas de succès ou 0 sinon.

EVP_ASYM_CIPHER_names_do_all() retourne 1 si la fonction de rappel a été appelée pour tous les noms. Une valeur de retour de 0 signifie que la fonction de rappel n'a été appelée pour aucun nom.

EVP_ASYM_CIPHER_gettable_ctx_params() et EVP_ASYM_CIPHER_settable_ctx_params() retournent un tableau constant OSSL_PARAM(3) ou NULL en cas d'erreur.

VOIR AUSSI

"ALGORITHM FETCHING" dans crypto(7), OSSL_PROVIDER(3)
