EVP_chacha20(3ssl)

Paquet: openssl

Licences: Apache-2.0

EVP_CHACHA20(3ssl) OpenSSL EVP_CHACHA20(3ssl)

NOM

EVP_chacha20, EVP_chacha20_poly1305 - Chiffrement de flux EVP ChaCha20

SYNTAXE

#include <openssl/evp.h>
const EVP_CIPHER *EVP_chacha20(void);
const EVP_CIPHER *EVP_chacha20_poly1305(void);

DESCRIPTION

Le chiffrement de flux ChaCha20 pour EVP.

EVP_chacha20()
Le chiffrement de flux ChaCha20. La longueur de la clé est de 256 bits, le IV est de 128 bits. Les 64 premiers bits consistent en un compteur en ordre little-endian suivi d'un nonce de 64 bits. Par exemple, un nonce de :

0000000000000002

Avec un compteur initial de 42 (2a en hexadécimal) serait exprimé comme :

2a000000000000000000000000000002

EVP_chacha20_poly1305()
Chiffrement authentifié avec ChaCha20-Poly1305. Comme EVP_chacha20(), la clé est de 256 bits et le IV est de 96 bits. Ceci prend en charge les données authentifiées supplémentaires (AAD) et produit une étiquette d'authentification de 128 bits. Voir l'interface "AEAD INTERFACE" dans la section EVP_EncryptInit(3) pour plus d'informations.

NOTES

Les développeurs doivent être conscients des implications négatives sur les performances de l'appel de ces fonctions à plusieurs reprises et devraient envisager d'utiliser EVP_CIPHER_fetch(3) avec EVP_CIPHER-CHACHA(7) à la place. Voir "Performance" dans crypto(7) pour plus d'informations.

Le RFC 7539 https://www.rfc-editor.org/rfc/rfc7539.html#section-2.4 utilise un compteur de 32 bits et un nonce de 96 bits pour le IV.

VALEURS DE RETOUR

Ces fonctions retournent une structure EVP_CIPHER qui contient l'implémentation du chiffrement symétrique. Voir EVP_CIPHER_meth_new(3) pour les détails de la structure EVP_CIPHER.

VOIR AUSSI

evp(7), EVP_EncryptInit(3), EVP_CIPHER_meth_new(3)
