DESCRIPTIO

N

Toutes les fonctions décrites sur cette page sont dépréciées. Les applications devraient plutôt utiliser les API

OSSL_PROVIDER.

Le type EVP_CIPHER est une structure pour l'implémentation d'une méthode de chiffrement

symétrique.

EVP_CIPHER_meth_new() crée une nouvelle structure

EVP_CIPHER.

EVP_CIPHER_meth_dup() crée une copie de cipher

.

EVP_CIPHER_meth_free() détruit une structure EVP_CIPHER. Si l'argument est NULL, rien n'est

fait.

EVP_CIPHER_meth_set_iv_length() définit la longueur du IV. Cela n'est nécessaire que lorsque le mode de chiffrement implémenté

l'exige.

EVP_CIPHER_meth_set_flags() définit les indicateurs décrivant les comportements optionnels dans le chiffrement particulier. À l'exception des modes de chiffrement, dont un seul peut être présent, plusieurs indicateurs peuvent être combinés par un OU bit à bit. Les indicateurs disponibles sont

EVP_CIPHER_meth_set_init() définit la fonction d'initialisation du chiffrement pour cipher. La fonction d'initialisation du chiffrement est appelée par EVP_CipherInit(), EVP_CipherInit_ex(), EVP_EncryptInit(), EVP_EncryptInit_ex(), EVP_DecryptInit(), EVP_DecryptIni

EVP_CIPHER_meth_set_cleanup() définit la fonction pour cipher afin d'effectuer un nettoyage supplémentaire avant que la structure de données privée de la méthode ne soit libérée et détruite. Notez que la fonction de nettoyage reçoit un EVP_CIPHER_CTX *, la structure de données privée est ensuite accessible avec EVP_CIPHER_CTX_get_cipher_data(). Cette fonction de nettoyage est appelée par EVP_CIPHER_CTX_reset() et EVP_CIPHER_CTX_

free().

EVP_CIPHER_meth_set_set_asn1_params() définit la fonction pour cipher afin de définir le "paramètre" AlgorithmIdentifier basé sur le chiffrement passé. Cette fonction est appelée par EVP_CIPHER_param_to_asn1(). EVP_CIPHER_meth_set_get_asn1_params() définit la fonction pour cipher qui définit les paramètres du chiffrement basés sur un "paramètre" AlgorithmIdentifier ASN.1. Ces deux fonctions sont nécessaires lorsqu'il y a besoin de données personnalisées (plus ou différentes que le IV du chiffrement). Elles sont appelées par EVP_CIPHER_param_to_asn1() et EVP_CIPHER_asn1_to_param() respectivement si elles sont

définies.

EVP_CIPHER_meth_set_ctrl() définit la fonction de contrôle pour cipher

RETOUR

EVP_CIPHER_meth_new() et EVP_CIPHER_meth_dup() retournent un pointeur vers un EVP_CIPHER nouvellement créé, ou NULL en cas d'échec. Toutes les fonctions EVP_CIPHER_meth_set_*() retournent 1. Toutes les fonctions EVP_CIPHER_meth_get_*() retournent des pointeurs vers leur fonction de chiffrement respective. cipher function.
