NOM

Event::ExecFlow::Frontend - Classe de base abstraite pour les interfaces personnalisées

SYNTAXE

#-- Dérivé de Event::ExecFlow::Frontend
my $frontend = MyApp::GUI::Frontent->new();
my $job      = Event::ExecFlow::Job::Command->new ( ... );
$frontend->start_job($job);
#-- Plus tard, les méthodes suivantes sont appelées et doivent être
#-- implémentées par vous
$frontend->report_job_start($job);
$frontend->report_job_progress($job);
$frontend->report_job_error($job);
$frontend->report_job_warning($job);
$frontend->report_job_finished($job);
$frontend->log($message);

DESCRIPTION

Ceci est une classe de base abstraite et n'est généralement pas utilisée directement depuis l'application. Pour la programmation quotidienne, les attributs définis dans cette classe sont les plus importants, car ils sont communs à tous les Jobs du framework Event::ExecFlow.
