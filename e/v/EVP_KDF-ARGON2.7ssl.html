L'implémentation
EVP KDF d'Argon2

DESCRIPTIO

N

Prise en charge du calcul de la fonction de dérivation de clé basée sur le mot de passe argon2 à travers l'API EVP_KDF. Prise en charge du calcul de la fonction de dérivation de clé basée sur le mot de passe argon2 à travers l'API EVP_KDF. EVP_KDF

API.

L'algorithme EVP_KDF-ARGON2 implémente la fonction de dérivation de clé basée sur le mot de passe Argon2, t que décrit dans la RFC 9106 de l'IETF. Elle est résistante à la mémoire (memory-hard) en ce sens qu'elle requiert délibérément une quantité importante de RAM pour un calcul efficace. L'intention est de rendre le force brute des mots de passe sur les systèmes qui manquent de grande quantité de mémoire vive (comme les GPU ou les ASIC) computationnellement

infaisable.

Argon2d (Argon2i) utilise un accès à la mémoire dépendant des données (indépendant des données) et vise principalement à contrer les attaques par canal auxiliaire (side-channel)

.

Argon2id est une construction hybride qui, dans les deux premières tranches du premier passage, génère des adresses de référence indépendamment des données comme dans Argon2i, alors que dans les tranches suivantes et les passages suivants, elle les génère de manière dépendante des données comme dans

Argon2d.

La version renforcée par Sbox, Argon2ds, n'est pas prise en

charge.

Pour plus d'informations, veuillez consulter la RFC

9106.

charge

Argon2 divise la taille de mémoire demandée en voies (lanes), chacune étant conçue pour être traitée en parallèle. Par exemple, sur un système avec p cœurs, il est recommandé d'utiliser p voies.

Le nombre de voies est utilisé pour dériver la clé. Il est possible de

EXEMPLE

S

Cet exemple utilise Argon2d avec le mot de passe "1234567890", le sel "saltsalt", en utilisant 2 voies, 2 threads, et un coût mémoire de 65536

: 
#include <string.h>                 /* strlen               */
#include <openssl/core_names.h>     /* OSSL_KDF_*           */
#include <openssl/params.h>         /* OSSL_PARAM_*         */
#include <openssl/thread.h>         /* OSSL_set_max_threads */
#include <openssl/kdf.h>            /* EVP_KDF_*            */
int main(void)
{
    int retval = 1;
    EVP_KDF *kdf = NULL;
    EVP_KDF_CTX *kctx = NULL;
    OSSL_PARAM params[6], *p = params;
    /* argon2 params, please refer to RFC9106 for recommended defaults */
    uint32_t lanes = 2, threads = 2, memcost = 65536;
    char pwd[] = "1234567890", salt[] = "saltsalt";
    /* derive result */
    size_t outlen = 128;
    unsigned char result[outlen];
    /* required if threads > 1 */
    if (OSSL_set_max_threads(NULL, threads) != 1)
        goto fail;
    p = params;
    *p++ = OSSL_PARAM_construct_uint32(OSSL_KDF_PARAM_THREADS, &threads);
    *p++ = OSSL_PARAM_construct_uint32(OSSL_KDF_PARAM_ARGON2_LANES,
                                       &lanes);
    *p++ = OSSL_PARAM_construct_uint32(OSSL_KDF_PARAM_ARGON2_MEMCOST,
                                       &memcost);
    *p++ = OSSL_PARAM_construct_octet_string(OSSL_KDF_PARAM_SALT,
                                             salt,
                                             strlen((const char *)salt));
    *p++ = OSSL_PARAM_construct_octet_string(OSSL_KDF_PARAM_PASSWORD,
                                             pwd,
                                             strlen((const char *)pwd));
    *p++ = OSSL_PARAM_construct_end();
    if ((kdf = EVP_KDF_fetch(NULL, "ARGON2D", NULL)) == NULL)
        goto fail;
    if ((kctx = EVP_KDF_CTX_new(kdf)) == NULL)
        goto fail;
    if (EVP_KDF_derive(kctx, &result[0], outlen, params) != 1)
        goto fail;
    printf("Output = %s\n", OPENSSL_buf2hexstr(result, outlen));
    retval = 0;
fail:
    EVP_KDF_free(kdf);
    EVP_KDF_CTX_free(kctx);
    OSSL_set_max_threads(NULL, 0);
    return retval;
}
