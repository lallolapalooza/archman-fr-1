NOM

EVP_CIPHER-RC4 - Les implémentations EVP_CIPHER de RC4

DESCRIPTION

Support pour le chiffrement symétrique RC4 utilisant l'API EVP_CIPHER.

Noms des algorithmes

Les algorithmes suivants sont disponibles dans le fournisseur legacy :

"RC4"
"RC4-40"
"RC4-HMAC-MD5"

Paramètres

Cette implémentation supporte les paramètres décrits dans "PARAMÈTRES" dans EVP_EncryptInit(3).

VOIR AUSSI

provider-cipher(7), OSSL_PROVIDER-legacy(7)
