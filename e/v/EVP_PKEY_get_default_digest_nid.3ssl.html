NOM

EVP_PKEY_get_default_digest_name, EVP_PKEY_get_default_digest_nid - obtenir le condensat par défaut pour la signature

SYNTAXE

#include <openssl/evp.h>
int EVP_PKEY_get_default_digest_name(EVP_PKEY *pkey,
                                     char *mdname, size_t mdname_sz);
int EVP_PKEY_get_default_digest_nid(EVP_PKEY *pkey, int *pnid);

DESCRIPTION

EVP_PKEY_get_default_digest_name() remplit le nom du condensat de message par défaut pour les opérations de signature de clé publique associées à la clé pkey dans mdname, jusqu'à un maximum de mdname_sz octets, y compris le caractère nul final. Le nom pourrait être "UNDEF", signifiant qu'un condensat doit (pour la valeur de retour 2) ou peut (pour la valeur de retour 1) être laissé non spécifié.

EVP_PKEY_get_default_digest_nid() définit pnid sur le NID du condensat de message par défaut pour les opérations de signature de clé publique associées à la clé pkey. Notez que certains algorithmes de signature (c'est-à-dire Ed25519 et Ed448) n'utilisent pas de condensat lors de la signature. Dans ce cas, pnid sera défini sur NID_undef. Cette fonction n'est fiable que pour les clés héritées, c'est-à-dire les clés avec une méthode EVP_PKEY_ASN1_METHOD ; ces clés ont généralement été chargées à partir de moteurs, ou créées avec EVP_PKEY_assign_RSA(3) ou une fonction similaire.

NOTES

Pour tous les algorithmes de clé publique standards actuels d'OpenSSL, SHA256 est retourné.

VALEURS DE RETOUR

EVP_PKEY_get_default_digest_name() et EVP_PKEY_get_default_digest_nid() retournent toutes deux 1 si le condensat de message est consultatif (c'est-à-dire que d'autres condensats peuvent être utilisés) et 2 s'il est obligatoire (d'autres condensats ne peuvent pas être utilisés). Elles retournent 0 ou une valeur négative en cas d'échec. En particulier, une valeur de retour de -2 indique que l'opération n'est pas prise en charge par l'algorithme de clé publique.

VOIR AUSSI

EVP_PKEY_CTX_new(3), EVP_PKEY_sign(3), EVP_PKEY_digestsign_supports_digest(3), EVP_PKEY_verify(3), EVP_PKEY_verify_recover(3),
