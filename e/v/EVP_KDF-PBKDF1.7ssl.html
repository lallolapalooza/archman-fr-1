NOM

EVP_KDF-PBKDF1 - L'implémentation EVP_KDF de PBKDF1

DESCRIPTION

Prise en charge du calcul de la fonction de dérivation de clé basée sur un mot de passe PBKDF1 via l'API EVP_KDF.

L'algorithme EVP_KDF-PBKDF1 implémente la fonction de dérivation de clé basée sur un mot de passe PBKDF1, telle que décrite dans la RFC 8018 ; elle dérive une clé d'un mot de passe en utilisant un sel et un nombre d'itérations.

Identité

"PBKDF1" est le nom de cette implémentation ; il peut être utilisé avec la fonction EVP_KDF_fetch().

Paramètres supportés

Les paramètres supportés sont :

"pass" (OSSL_KDF_PARAM_PASSWORD) <chaîne d'octets>
"salt" (OSSL_KDF_PARAM_SALT) <chaîne d'octets>
"iter" (OSSL_KDF_PARAM_ITER) <entier non signé>
Ce paramètre a une valeur par défaut de 0 et doit être défini.
"properties" (OSSL_KDF_PARAM_PROPERTIES) <chaîne UTF8>
"digest" (OSSL_KDF_PARAM_DIGEST) <chaîne UTF8>
Ces paramètres fonctionnent comme décrit dans "PARAMETERS" dans EVP_KDF(3).

NOTES

Une application typique de cet algorithme est de dériver le matériel de clé pour un algorithme de chiffrement à partir d'un mot de passe dans le champ "pass", d'un sel dans "salt", et d'un nombre d'itérations.

Augmenter le paramètre "iter" ralentit l'algorithme, ce qui rend plus difficile pour un attaquant d'effectuer une attaque par force brute en utilisant un grand nombre de mots de passe candidats.

Aucune hypothèse n'est faite concernant le mot de passe fourni ; il est simplement traité comme une séquence d'octets.

Le fournisseur hérité doit être disponible pour accéder à cet algorithme.

CONFORME À

RFC 8018
