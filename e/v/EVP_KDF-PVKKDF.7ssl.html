NOM

EVP_KDF-PVKKDF - L'implémentation PVK EVP_KDF

DESCRIPTION

Prise en charge du calcul de la fonction de dérivation de clé PVK KDF basée sur PIN via l'API EVP_KDF.

L'algorithme EVP_KDF-PVKKDF implémente une fonction de dérivation de clé basée sur PIN PVK ; il dérive une clé d'un mot de passe à l'aide d'un sel.

Identité

« PVKKDF » est le nom de cette implémentation ; elle peut être utilisée avec la fonction EVP_KDF_fetch().

Paramètres pris en charge

Les paramètres pris en charge sont :

"pass" (OSSL_KDF_PARAM_PASSWORD) <chaîne d'octets>
"salt" (OSSL_KDF_PARAM_SALT) <chaîne d'octets>
"properties" (OSSL_KDF_PARAM_PROPERTIES) <chaîne UTF8>
"digest" (OSSL_KDF_PARAM_DIGEST) <chaîne UTF8>
Ces paramètres fonctionnent comme décrit dans "PARAMÈTRES" dans EVP_KDF(3).

NOTES

Une application typique de cet algorithme consiste à dériver du matériel de chiffrement pour un algorithme de chiffrement à partir d'un mot de passe dans le champ "pass" et d'un sel dans le champ "salt".

Aucune hypothèse n'est faite concernant le mot de passe fourni ; il est simplement traité comme une séquence d'octets.

Le fournisseur hérité doit être disponible pour accéder à cet algorithme.

VOIR AUSSI
