EVP_KEM-ML-KEM(7ssl) OpenSSL EVP_KEM-ML-KEM(7ssl)

NOM

EVP_KEM-ML-KEM-512, EVP_KEM-ML-KEM-768, EVP_KEM-ML-KEM-1024, EVP_KEM-ML-KEM - Support du type de clé et de l'algorithme EVP_KEM ML-KEM

DESCRIPTION

Les types de clé et les paramètres ML-KEM sont décrits dans EVP_PKEY-ML-KEM(7). Voir EVP_PKEY_encapsulate(3) et EVP_PKEY_decapsulate(3) pour plus de détails sur les opérations KEM de base.

PARAMÈTRES KEM ML-KEM

"ikme" (OSSL_KEM_PARAM_IKME) <chaîne d'octets>
Le mécanisme d'encapsulation ML-KEM d'OpenSSL ne peut être modifié qu'en définissant des valeurs aléatoires lors de l'encapsulation, ce qui permet les tests, conformément à la norme FIPS 203, section 6.2, algorithme 17.

Ce paramètre ne doit pas être utilisé à d'autres fins que les tests.

Lorsque ce paramètre n'est pas défini, l'encapsulation se déroule conformément à la norme FIPS 203, section 7.2

Ce paramètre est uniquement configurable.

Ceci peut être défini lors de l'utilisation de EVP_PKEY_encapsulate_init().

CONFORMITÉ

FIPS203

VOIR AUSSI

EVP_PKEY_encapsulate(3), EVP_PKEY_decapsulate(3), EVP_KEYMGMT(3), EVP_PKEY(3), provider-keymgmt(7)
