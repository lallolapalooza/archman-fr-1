EVP_seed_cbc(3ssl)

Paquet: openssl

Licences: Apache-2.0

EVP_SEED_CBC(3ssl) OpenSSL EVP_SEED_CBC(3ssl)

NOM

EVP_seed_cbc, EVP_seed_cfb, EVP_seed_cfb128, EVP_seed_ecb, EVP_seed_ofb - Chiffrement SEED EVP

SYNOPIS

#include <openssl/evp.h>
const EVP_CIPHER *EVP_seed_cbc(void);
const EVP_CIPHER *EVP_seed_cfb(void);
const EVP_CIPHER *EVP_seed_cfb128(void);
const EVP_CIPHER *EVP_seed_ecb(void);
const EVP_CIPHER *EVP_seed_ofb(void);

DESCRIPTION

L'algorithme de chiffrement SEED pour EVP.

Tous les modes ci-dessous utilisent une longueur de clé de 128 bits et agissent sur des blocs de 128 bits.

EVP_seed_cbc(), EVP_seed_cfb(), EVP_seed_cfb128(), EVP_seed_ecb(), EVP_seed_ofb()
L'algorithme de chiffrement SEED en modes CBC, CFB, ECB et OFB respectivement.

NOTES

Les développeurs doivent être conscients des implications négatives sur les performances de l'appel de ces fonctions plusieurs fois et devraient envisager d'utiliser EVP_CIPHER_fetch(3) avec EVP_CIPHER-SEED(7) à la place. Voir "Performances" dans crypto(7) pour plus d'informations.

VALEUR DE RETOUR

Ces fonctions retournent une structure EVP_CIPHER qui contient l'implémentation du chiffrement symétrique. Voir EVP_CIPHER_meth_new(3) pour les détails de la structure EVP_CIPHER.

VOIR AUSSI

evp(7), EVP_EncryptInit(3), EVP_CIPHER_meth_new(3)
