NOM

EVP_MAC-CMAC - L'implémentation CMAC d'EVP_MAC

DESCRIPTION

Prise en charge du calcul des MAC CMAC via l'API EVP_MAC.

Cette implémentation utilise les fonctions EVP_CIPHER pour accéder au chiffrement sous-jacent.

Identité

Cette implémentation est identifiée par ce nom et ces propriétés, à utiliser avec EVP_MAC_fetch() :

"CMAC", "provider=default" ou "provider=fips"

Paramètres supportés

La description générale de ces paramètres se trouve dans "PARAMETERS" dans EVP_MAC(3).

Le paramètre suivant peut être défini avec EVP_MAC_CTX_set_params() :

"key" (OSSL_MAC_PARAM_KEY) <chaîne d'octets>
Définit la clé MAC. La définition de ce paramètre est identique au passage d'une key à EVP_MAC_init(3).
"cipher" (OSSL_MAC_PARAM_CIPHER) <chaîne UTF8>
Définit le nom du chiffrement sous-jacent à utiliser. Le mode du chiffrement doit être CBC.
"properties" (OSSL_MAC_PARAM_PROPERTIES) <chaîne UTF8>
Définit les propriétés à interroger lors de la tentative de récupération du chiffrement sous-jacent. Cela doit être donné avec le paramètre de nommage du chiffrement pour être considéré comme valide.
"encrypt-check" (OSSL_CIPHER_PARAM_FIPS_ENCRYPT_CHECK) <entier>
Cette option est utilisée par le fournisseur FIPS d'OpenSSL. Si requis, ce paramètre doit être défini avant EVP_MAC_init().

La valeur par défaut de 1 provoque une erreur lorsqu'une opération de chiffrement Triple-DES non approuvée est déclenchée. La définir à 0 ignorera l'erreur et définira l'"indicateur-fips" approuvé à 0. Cette option enfreint la conformité FIPS si elle amène l'"indicateur-fips" approuvé à retourner 0.

Les paramètres suivants peuvent être récupérés avec EVP_MAC_CTX_get_params() :

"size" (OSSL_MAC_PARAM_SIZE) <entier non signé>
Le paramètre "size" peut également être récupéré avec EVP_MAC_CTX_get_mac_size(). La longueur du paramètre "size" est égale à celle d'un unsigned int.
"block-size" (OSSL_MAC_PARAM_BLOCK_SIZE) <entier non signé>
Récupère la taille du bloc MAC. Le paramètre "block-size" peut également être récupéré avec EVP_MAC_CTX_get_block_size().
"fips-indicator" (OSSL_CIPHER_PARAM_FIPS_APPROVED_INDICATOR) <entier>
Cette option est utilisée par le fournisseur FIPS d'OpenSSL.

Un getter qui retourne 1 si l'opération est approuvée FIPS, ou 0 sinon. Cela peut être utilisé après avoir appelé EVP_MAC_final(). Il peut retourner 0 si l'option "encrypt-check" est définie à 0.
