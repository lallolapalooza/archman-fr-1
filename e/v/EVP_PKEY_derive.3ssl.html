EVP_PKEY_derive(3ssl)

Paquet: openssl

Licences: Apache-2.0

EVP_PKEY_DERIVE(3ssl) OpenSSL EVP_PKEY_DERIVE(3ssl)

NOM

EVP_PKEY_derive_init, EVP_PKEY_derive_init_ex, EVP_PKEY_derive_set_peer_ex, EVP_PKEY_derive_set_peer, EVP_PKEY_derive, EVP_PKEY_derive_SKEY - dériver un secret partagé d'algorithme de clé publique

SYNOPSIS

#include <openssl/evp.h>
int EVP_PKEY_derive_init(EVP_PKEY_CTX *ctx);
int EVP_PKEY_derive_init_ex(EVP_PKEY_CTX *ctx, const OSSL_PARAM params[]);
int EVP_PKEY_derive_set_peer_ex(EVP_PKEY_CTX *ctx, EVP_PKEY *peer,
                                int validate_peer);
int EVP_PKEY_derive_set_peer(EVP_PKEY_CTX *ctx, EVP_PKEY *peer);
int EVP_PKEY_derive(EVP_PKEY_CTX *ctx, unsigned char *key, size_t *keylen);
EVP_SKEY *EVP_PKEY_derive_SKEY(EVP_PKEY_CTX *ctx, EVP_SKEYMGMT *mgmt,
                               const char *key_type, const char *propquery,
                               size_t keylen, const OSSL_PARAM params[]);

DESCRIPTION

EVP_PKEY_derive_init() initialise un contexte d'algorithme de clé publique ctx pour la dérivation d'un secret partagé en utilisant l'algorithme spécifié lors de la création du contexte avec EVP_PKEY_CTX_new(3) ou ses variantes. L'algorithme est utilisé pour récupérer implicitement une méthode EVP_KEYEXCH, voir "Récupération implicite" dans provider(7) pour plus d'informations.

EVP_PKEY_derive_init_ex() est identique à EVP_PKEY_derive_init() mais définit en plus les paramètres params passés sur le contexte avant de retourner.

EVP_PKEY_derive_set_peer_ex() définit la clé du pair : il s'agit normalement d'une clé publique. Le paramètre validate_peer validera la clé publique si sa valeur est non nulle.

EVP_PKEY_derive_set_peer() est similaire à EVP_PKEY_derive_set_peer_ex() avec validate_peer mis à 1.

EVP_PKEY_derive() dérive un secret partagé en utilisant ctx. Si key est NULL, la taille maximale du tampon de sortie est inscrite dans le paramètre keylen. Si key n'est pas NULL, avant l'appel, le paramètre keylen doit contenir la taille du tampon key. Si l'appel réussit, le secret partagé est écrit dans key et la quantité de données écrites est mise dans keylen.

EVP_PKEY_derive_SKEY() est similaire à EVP_PKEY_derive() mais retourne un objet EVP_SKEY qui stocke les données opaques pour la clé dérivée. Si un argument EVP_SKEYMGMT est passé, il sera explicitement utilisé pour la création de EVP_SKEY. Sinon, l'objet EVP_SKEYMGMT utilisé pour EVP_SKEY sera récupéré en fonction de skeymgmtname et propquery. Si skeymgmtname est NULL, le nom correspondant au nom de la méthode d'échange de clés est supposé.

NOTES

Après l'appel à EVP_PKEY_derive_init(), des opérations de contrôle spécifiques à l'algorithme peuvent être effectuées pour définir les paramètres appropriés pour l'opération.

La fonction EVP_PKEY_derive() peut être appelée plusieurs fois sur le même contexte si plusieurs opérations sont effectuées avec les mêmes paramètres.

VALEUR DES RETOURS

EVP_PKEY_derive_init() et EVP_PKEY_derive() retournent 1 en cas de succès et 0 ou une valeur négative en cas d'échec. En particulier, une valeur de retour de -2 indique que l'opération n'est pas prise en charge par l'algorithme de clé publique.

EVP_PKEY_derive_SKEY() retourne un objet EVP_SKEY fraîchement créé en cas de succès ou NULL en cas d'échec.

EXEMPLES

Dériver un secret partagé (par exemple pour des clés DH ou EC) :

#include <openssl/evp.h>
#include <openssl/rsa.h>
EVP_PKEY_CTX *ctx;
ENGINE *eng;
unsigned char *skey;
size_t skeylen;
EVP_PKEY *pkey, *peerkey;
/* NB : suppose que pkey, eng, peerkey ont déjà été configurés */
ctx = EVP_PKEY_CTX_new(pkey, eng);
if (!ctx)
    /* Une erreur s'est produite */
if (EVP_PKEY_derive_init(ctx) <= 0)
    /* Erreur */
if (EVP_PKEY_derive_set_peer(ctx, peerkey) <= 0)
    /* Erreur */
/* Déterminer la longueur du tampon */
if (EVP_PKEY_derive(ctx, NULL, &skeylen) <= 0)
    /* Erreur */
skey = OPENSSL_malloc(skeylen);
if (!skey)
    /* Échec d'allocation mémoire */
if (EVP_PKEY_derive(ctx, skey, &skeylen) <= 0)
    /* Erreur */
/* Le secret partagé est skey octets écrits dans le tampon skey */

HISTORIQUE

Les fonctions EVP_PKEY_derive_init(), EVP_PKEY_derive_set_peer() et EVP_PKEY_derive() ont été ajoutées initialement dans OpenSSL 1.0.0.

Les fonctions EVP_PKEY_derive_init_ex() et EVP_PKEY_derive_set_peer_ex() ont été ajoutées dans OpenSSL 3.0.

La fonction EVP_PKEY_derive_SKEY() a été ajoutée dans OpenSSL 3.6.
