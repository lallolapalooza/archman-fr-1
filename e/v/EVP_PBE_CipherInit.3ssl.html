EVP_PBE_CipherInit(3ssl)

EVP_PBE_CIPHERINIT(3ssl) OpenSSL EVP_PBE_CIPHERINIT(3ssl)

NOM

EVP_PBE_CipherInit, EVP_PBE_CipherInit_ex, EVP_PBE_find, EVP_PBE_find_ex, EVP_PBE_alg_add_type, EVP_PBE_alg_add - Routines de chiffrement par mot de passe

SYNOPSIS

#include <openssl/evp.h>
int EVP_PBE_CipherInit(ASN1_OBJECT *pbe_obj, const char *pass, int passlen,
                       ASN1_TYPE *param, EVP_CIPHER_CTX *ctx, int en_de);
int EVP_PBE_CipherInit_ex(ASN1_OBJECT *pbe_obj, const char *pass, int passlen,
                          ASN1_TYPE *param, EVP_CIPHER_CTX *ctx, int en_de,
                          OSSL_LIB_CTX *libctx, const char *propq);
int EVP_PBE_find(int type, int pbe_nid, int *pcnid, int *pmnid,
                 EVP_PBE_KEYGEN **pkeygen);
int EVP_PBE_find_ex(int type, int pbe_nid, int *pcnid, int *pmnid,
                    EVP_PBE_KEYGEN **pkeygen, EVP_PBE_KEYGEN_EX **keygen_ex);
int EVP_PBE_alg_add_type(int pbe_type, int pbe_nid, int cipher_nid,
                         int md_nid, EVP_PBE_KEYGEN *keygen);
int EVP_PBE_alg_add(int nid, const EVP_CIPHER *cipher, const EVP_MD *md,
                    EVP_PBE_KEYGEN *keygen);

DESCRIPTION

Opérations PBE

EVP_PBE_CipherInit() et EVP_PBE_CipherInit_ex() initialisent un EVP_CIPHER_CTX ctx pour le chiffrement (en_de=1) ou le déchiffrement (en_de=0) en utilisant le mot de passe pass de longueur passlen. Le type d'algorithme PBE et ses paramètres sont extraits d'un OID pbe_obj et des paramètres param.

EVP_PBE_CipherInit_ex() permet également à l'application de spécifier un contexte de bibliothèque libctx et une requête de propriété propq pour sélectionner les implémentations d'algorithmes appropriées.

Recherche d'algorithmes PBE

EVP_PBE_find() et EVP_PBE_find_ex() recherchent un algorithme correspondant à l'aide de deux paramètres :

1. Un type d'algorithme type qui peut être :

  • EVP_PBE_TYPE_OUTER - Un algorithme PBE
  • EVP_PBE_TYPE_PRF - Une fonction pseudo-aléatoire
  • EVP_PBE_TYPE_KDF - Une fonction de dérivation de clé

2. Un pbe_nid qui peut représenter l'identifiant de l'algorithme avec paramètres, par exemple NID_pbeWithSHA1AndRC2_CBC ou une classe d'algorithme, par exemple NID_pbes2.

Ils retournent l'ID du chiffrement de l'algorithme pcnid, l'ID du digest pmnid et une fonction de génération de clé pour l'algorithme pkeygen. EVP_PBE_CipherInit_ex() retourne également une fonction de génération de clé étendue keygen_ex qui prend un contexte de bibliothèque et une requête de propriété.

Si NULL est fourni pour l'un des paramètres pcnid, pmnid, pkeygen ou pkeygen_ex, ce paramètre n'est pas retourné.

Ajout d'algorithmes PBE

EVP_PBE_alg_add_type() et EVP_PBE_alg_add() ajoutent un algorithme à la liste des algorithmes connus. Leurs paramètres ont la même signification que pour les fonctions EVP_PBE_find() et EVP_PBE_find_ex().

NOTES

Les arguments pbe_obj et param pour EVP_PBE_CipherInit() et EVP_PBE_CipherInit_ex() forment ensemble un X509_ALGOR et peuvent souvent être extraits directement de cette structure.

VALEUR DE RETOUR

La valeur de retour est 1 en cas de succès et 0 en cas d'erreur.
