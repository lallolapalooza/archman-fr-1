NOM

EVP_PKEY_todata, EVP_PKEY_export - fonctions pour retourner les clés sous forme d'un tableau de paramètres de clé

SYNTAXE

#include <openssl/evp.h>
int EVP_PKEY_todata(const EVP_PKEY *pkey, int selection, OSSL_PARAM **params);
int EVP_PKEY_export(const EVP_PKEY *pkey, int selection,
                    OSSL_CALLBACK *export_cb, void *export_cbarg);

DESCRIPTION

Les fonctions décrites ici sont utilisées pour extraire les valeurs de clé EVP_PKEY sous forme d'un tableau de OSSL_PARAM(3).

EVP_PKEY_todata() extrait les valeurs d'une clé pkey en utilisant la selection. La selection est décrite dans "Selections" dans EVP_PKEY_fromdata(3). OSSL_PARAM_free(3) doit être utilisé pour libérer les paramètres retournés dans *params.

EVP_PKEY_export() est similaire à EVP_PKEY_todata() mais utilise une fonction de rappel export_cb qui reçoit la valeur de export_cbarg. Voir openssl-core.h(7) pour plus d'informations sur la fonction de rappel. Notez que le tableau OSSL_PARAM(3) qui est passé à la fonction de rappel n'est pas persistant après le retour de la fonction de rappel. L'utilisateur doit conserver les éléments d'intérêt, ou utiliser EVP_PKEY_todata() si la persistance est requise.

NOTES

Ces fonctions ne fonctionnent qu'avec les méthodes de gestion de clés provenant d'un fournisseur. C'est la fonction miroir de EVP_PKEY_fromdata(3).

Le support LMS est désactivé par défaut au moment de la compilation. Pour l'activer, spécifiez l'option de configuration de construction enable-lms.

VALEURS DE RETOUR

EVP_PKEY_todata() et EVP_PKEY_export() retournent 1 en cas de succès et 0 en cas d'échec.

VOIR AUSSI

OSSL_PARAM(3), openssl-core.h(7), EVP_PKEY_fromdata(3), EVP_PKEY-RSA(7), EVP_PKEY-EC(7), EVP_PKEY-DSA(7), EVP_PKEY-ED25519(7) EVP_PKEY-ED448(7), EVP_PKEY-DH(7), EVP_PKEY-X25519(7), EVP_PKEY-X448(7), EVP_PKEY-LMS(7), EVP_PKEY-ML-DSA(7), EVP_PKEY-ML-KEM(7), EVP_PKEY-SLH-DSA(7).

HISTORIQUE

Ces fonctions ont été ajoutées dans OpenSSL 3.0.

Le support pour ML-DSA, ML-KEM et SLH-DSA a été ajouté dans OpenSSL 3.5.

Le support pour LMS a été ajouté dans OpenSSL 3.6.
