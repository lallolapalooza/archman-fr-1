NOM

EVP_RAND-JITTER - L'implémentation EVP_RAND source de remplissage aléatoire

DESCRIPTION

Prise en charge de l'initialisation déterministe du générateur de nombres aléatoires via l'API EVP_RAND.

Cette source de remplissage logicielle produit de l'aléatoire basé sur de minuscules fluctuations de "gigue" (jitter) du CPU.

Elle est disponible lorsque OpenSSL est compilé avec l'option enable-jitter. Lorsqu'elle est disponible, elle est listée dans openssl list -random-generators et openssl info -seeds.

Identité

"JITTER" est le nom de cette implémentation ; elle peut être utilisée avec la fonction EVP_RAND_fetch().

Paramètres supportés

Les paramètres supportés sont :

"state" (OSSL_RAND_PARAM_STATE) <entier>
"strength" (OSSL_RAND_PARAM_STRENGTH) <entier non signé>
"max_request" (OSSL_RAND_PARAM_MAX_REQUEST) <entier non signé>
Ces paramètres fonctionnent comme décrit dans "PARAMÈTRES" dans EVP_RAND(3).

NOTES

Un contexte pour la source de remplissage peut être obtenu en appelant :

EVP_RAND *rand = EVP_RAND_fetch(NULL, "JITTER", NULL);
EVP_RAND_CTX *rctx = EVP_RAND_CTX_new(rand, NULL);

L'option enable-jitter a été ajoutée dans OpenSSL 3.4.

En spécifiant l'option de configuration enable-fips-jitter, le fournisseur FIPS utilisera une source de gigue interne pour son entropie. L'activation de cette option fera fonctionner le fournisseur FIPS dans un mode non conforme à moins qu'une évaluation d'entropie ESV https://csrc.nist.gov/Projects/cryptographic-module-validation-program/entropy-validations et une validation via le CMVP https://csrc.nist.gov/projects/cryptographic-module-validation-program ne soient en outre menées. Cette option a été ajoutée dans OpenSSL 3.5.

EXEMPLES

EVP_RAND *rand;
EVP_RAND_CTX *seed, *rctx;
unsigned char bytes[100];
OSSL_PARAM params[2], *p = params;
unsigned int strength = 128;
/* Créer et initialiser une source de remplissage */
rand = EVP_RAND_fetch(NULL, "JITTER", NULL);
seed = EVP_RAND_CTX_new(rand, NULL);
EVP_RAND_instantiate(seed, strength, 0, NULL, 0, NULL);
EVP_RAND_free(rand);
/* L'intégrer dans un DRBG */
rand = EVP_RAND_fetch(NULL, "CTR-DRBG", NULL);
rctx = EVP_RAND_CTX_new(rand, seed);
EVP_RAND_free(rand);
/* Configurer le DRBG */
*p++ = OSSL_PARAM_construct_utf8_string(OSSL_DRBG_PARAM_CIPHER,
                                        SN_aes_256_ctr, 0);
*p = OSSL_PARAM_construct_end();
EVP_RAND_instantiate(rctx, strength, 0, NULL, 0, params);
EVP_RAND_generate(rctx, bytes, sizeof(bytes), strength, 0, NULL, 0);
EVP_RAND_CTX_free(rctx);
EVP_RAND_CTX_free(seed);
