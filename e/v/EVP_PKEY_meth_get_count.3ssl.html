EVP_PKEY_meth_get_count(3ssl)

EVP_PKEY_METH_GET_COUNT(3ssl) OpenSSL EVP_PKEY_METH_GET_COUNT(3ssl)

NOM

EVP_PKEY_meth_get_count, EVP_PKEY_meth_get0, EVP_PKEY_meth_get0_info - énumérer les méthodes de clé publique

SYNOPIS

#include <openssl/evp.h>

Les fonctions suivantes sont dépréciées depuis OpenSSL 3.0, et peuvent être entièrement masquées en définissant OPENSSL_API_COMPAT avec une valeur de version appropriée, voir openssl_user_macros(7) :

size_t EVP_PKEY_meth_get_count(void);
const EVP_PKEY_METHOD *EVP_PKEY_meth_get0(size_t idx);
void EVP_PKEY_meth_get0_info(int *ppkey_id, int *pflags,
                             const EVP_PKEY_METHOD *meth);

DESCRIPTION

Toutes les fonctions décrites sur cette page sont dépréciées. Les applications devraient utiliser les API OSSL_PROVIDER à la place.

EVP_PKEY_meth_count() retourne le nombre de méthodes de clé publique disponibles : il comprend les méthodes standard et toute méthode ajoutée par l'application.

EVP_PKEY_meth_get0() retourne la méthode de clé publique idx. La valeur de idx doit être comprise entre zéro et EVP_PKEY_meth_get_count() - 1.

EVP_PKEY_meth_get0_info() retourne l'identifiant de la clé publique (un NID) et tout drapeau associé à la méthode de clé publique *meth.

VALEUR DE RETOUR

EVP_PKEY_meth_count() retourne le nombre de méthodes de clé publique disponibles.

EVP_PKEY_meth_get0() retourne une méthode de clé publique ou NULL si idx est hors limites.

EVP_PKEY_meth_get0_info() ne retourne pas de valeur.

VOIR AUSSI

EVP_PKEY_new(3)
