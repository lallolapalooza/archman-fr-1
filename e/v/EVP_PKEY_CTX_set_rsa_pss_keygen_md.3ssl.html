EVP_PKEY_CTX_set_rsa_pss_keygen_md(3ssl)

Paquet: openssl

Licences: Apache-2.0

EVP_PKEY_CTX_SET_RSA_PSS_KEYGEN_MD(3ssl) OpenSSL EVP_PKEY_CTX_SET_RSA_PSS_KEYGEN_MD(3ssl)

NOM

EVP_PKEY_CTX_set_rsa_pss_keygen_md, EVP_PKEY_CTX_set_rsa_pss_keygen_md_name, EVP_PKEY_CTX_set_rsa_pss_keygen_mgf1_md, EVP_PKEY_CTX_set_rsa_pss_keygen_mgf1_md_name, EVP_PKEY_CTX_set_rsa_pss_keygen_saltlen - Fonctions de support de l'algorithme EVP_PKEY RSA-PSS

SYNOPSIS

#include <openssl/rsa.h>
int EVP_PKEY_CTX_set_rsa_pss_keygen_md(EVP_PKEY_CTX *pctx,
                                       const EVP_MD *md);
int EVP_PKEY_CTX_set_rsa_pss_keygen_md_name(EVP_PKEY_CTX *ctx,
                                            const char *mdname,
                                            const char *mdprops);
int EVP_PKEY_CTX_set_rsa_pss_keygen_mgf1_md(EVP_PKEY_CTX *pctx,
                                            const EVP_MD *md);
int EVP_PKEY_CTX_set_rsa_pss_keygen_mgf1_md_name(EVP_PKEY_CTX *pctx,
                                                 const char *mdname);
int EVP_PKEY_CTX_set_rsa_pss_keygen_saltlen(EVP_PKEY_CTX *pctx,
                                            int saltlen);

DESCRIPTION

Ce sont les fonctions qui implémentent RSA-PSS(7).

Signature et Vérification

La macro EVP_PKEY_CTX_set_rsa_padding() est supportée mais une erreur est retournée si une tentative est faite pour définir le mode de remplissage sur autre chose que PSS. Elle est sinon similaire à la version RSA.

La macro EVP_PKEY_CTX_set_rsa_pss_saltlen() est utilisée pour définir la longueur du sel. Si la clé a des restrictions d'utilisation, une erreur est retournée si une tentative est faite pour définir la longueur du sel en dessous de la valeur minimale. Elle est sinon similaire à l'opération RSA, sauf que la détection de la longueur du sel (utilisant RSA_PSS_SALTLEN_AUTO) n'est pas supportée pour la vérification si la clé a des restrictions d'utilisation.

Les fonctions EVP_PKEY_CTX_set_signature_md(3) et EVP_PKEY_CTX_set_rsa_mgf1_md(3) sont utilisées pour définir respectivement les algorithmes de hachage et MGF1. Si la clé a des restrictions d'utilisation, une erreur est retournée si une tentative est faite pour définir le hachage sur autre chose que la valeur restreinte. Sinon, elles sont similaires aux versions RSA.

Génération de clé

Comme pour la génération de clé RSA, les macros EVP_PKEY_CTX_set_rsa_keygen_bits() et EVP_PKEY_CTX_set_rsa_keygen_pubexp() sont supportées pour RSA-PSS : elles ont exactement la même signification que pour l'algorithme RSA.

Des restrictions de paramètres optionnelles peuvent être spécifiées lors de la génération d'une clé PSS. Si des restrictions sont définies (en utilisant les macros décrites ci-dessous), alors tous les paramètres sont restreints. Par exemple, définir une longueur de sel minimale restreint également les algorithmes de hachage et MGF1. Si des restrictions sont en place, elles se reflètent dans les paramètres correspondants de la clé publique lorsque (par exemple) une demande de certificat est signée.

EVP_PKEY_CTX_set_rsa_pss_keygen_md() restreint l'algorithme de hachage que la clé générée peut utiliser à md. EVP_PKEY_CTX_set_rsa_pss_keygen_md_name() fait la même chose, mais passe l'algorithme par son nom plutôt que par EVP_MD.

EVP_PKEY_CTX_set_rsa_pss_keygen_mgf1_md() restreint l'algorithme MGF1 que la clé générée peut utiliser à md. EVP_PKEY_CTX_set_rsa_pss_keygen_mgf1_md_name() fait la même chose, mais passe l'algorithme par son nom plutôt que par EVP_MD.

EVP_PKEY_CTX_set_rsa_pss_keygen_saltlen() restreint la longueur minimale du sel à saltlen.

NOTES

Un contexte pour l'algorithme RSA-PSS peut être obtenu en appelant :

EVP_PKEY_CTX *pctx = EVP_PKEY_CTX_new_id(EVP_PKEY_RSA_PSS, NULL);

VALEUR DE RETOUR

Toutes ces fonctions retournent 1 en cas de succès et 0 ou une valeur négative en cas d'échec. En particulier, une valeur de retour de -2 indique que l'opération n'est pas supportée par l'algorithme de clé publique.
