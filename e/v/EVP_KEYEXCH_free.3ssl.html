EVP_KEYEXCH_free(3ssl)

Paquet: openssl

Licences: Apache-2.0

EVP_KEYEXCH_FREE(3ssl) OpenSSL EVP_KEYEXCH_FREE(3ssl)

NOM

EVP_KEYEXCH_fetch, EVP_KEYEXCH_free, EVP_KEYEXCH_up_ref, EVP_KEYEXCH_get0_provider, EVP_KEYEXCH_is_a, EVP_KEYEXCH_do_all_provided, EVP_KEYEXCH_names_do_all, EVP_KEYEXCH_get0_name, EVP_KEYEXCH_get0_description, EVP_KEYEXCH_gettable_ctx_params, EVP_KEYEXCH_settable_ctx_params - Fonctions pour gérer les objets d'algorithmes EVP_KEYEXCH

SYNOPIS

#include <openssl/evp.h>
EVP_KEYEXCH *EVP_KEYEXCH_fetch(OSSL_LIB_CTX *ctx, const char *algorithm,
                               const char *properties);
void EVP_KEYEXCH_free(EVP_KEYEXCH *exchange);
int EVP_KEYEXCH_up_ref(EVP_KEYEXCH *exchange);
OSSL_PROVIDER *EVP_KEYEXCH_get0_provider(const EVP_KEYEXCH *exchange);
int EVP_KEYEXCH_is_a(const EVP_KEYEXCH *exchange, const char *name);
const char *EVP_KEYEXCH_get0_name(const EVP_KEYEXCH *exchange);
void EVP_KEYEXCH_do_all_provided(OSSL_LIB_CTX *libctx,
                                 void (*fn)(EVP_KEYEXCH *exchange, void *arg),
                                 void *arg);
int EVP_KEYEXCH_names_do_all(const EVP_KEYEXCH *exchange,
                             void (*fn)(const char *name, void *data),
                             void *data);
const char *EVP_KEYEXCH_get0_description(const EVP_KEYEXCH *keyexch);
const OSSL_PARAM *EVP_KEYEXCH_gettable_ctx_params(const EVP_KEYEXCH *keyexch);
const OSSL_PARAM *EVP_KEYEXCH_settable_ctx_params(const EVP_KEYEXCH *keyexch);

DESCRIPTION

EVP_KEYEXCH_fetch() récupère l'implémentation d'échange de clés pour l'algorithm donné à partir de n'importe quel fournisseur l'offrant, selon les critères définis par les properties. Voir "ALGORITHM FETCHING" dans crypto(7) pour plus d'informations.

La valeur retournée doit éventuellement être libérée avec EVP_KEYEXCH_free().

EVP_KEYEXCH_free() décrémente le compteur de références pour la structure EVP_KEYEXCH. Typiquement, cette structure aura été obtenue par un appel précédent à EVP_KEYEXCH_fetch(). Si le compteur de références tombe à 0, la structure est libérée. Si l'argument est NULL, rien n'est fait.

EVP_KEYEXCH_up_ref() incrémente le compteur de références pour une structure EVP_KEYEXCH.

EVP_KEYEXCH_get0_provider() retourne le fournisseur à partir duquel exchange a été récupéré.

EVP_KEYEXCH_is_a() vérifie si exchange est une implémentation d'un algorithme identifiable par name.

EVP_KEYEXCH_get0_name() retourne le nom de l'algorithme à partir de l'implémentation fournie pour l'exchange donné. Notez que l'exchange peut avoir plusieurs synonymes associés. Dans ce cas, le premier nom de la définition de l'algorithme est retourné. La propriété de la chaîne retournée est conservée par l'objet exchange et ne doit pas être libérée par l'appelant.

EVP_KEYEXCH_names_do_all() parcourt tous les noms de l'exchange et appelle fn avec chaque nom et data.

EVP_KEYEXCH_get0_description() retourne une description de keyexch, destinée à l'affichage et à la consommation humaine. La description est à la discrétion de l'implémentation de keyexch.

EVP_KEYEXCH_do_all_provided() parcourt toutes les implémentations d'échange de clés par tous les fournisseurs activés dans le contexte de bibliothèque libctx, et pour chacune des implémentations, appelle fn avec la méthode d'implémentation et data comme arguments.

EVP_KEYEXCH_gettable_ctx_params() et EVP_KEYEXCH_settable_ctx_params() retournent un tableau constant OSSL_PARAM(3) qui décrit les noms et types des paramètres de clé qui peuvent être récupérés ou définis par un algorithme d'échange de clés en utilisant EVP_PKEY_CTX_get_params(3) et EVP_PKEY_CTX_set_params(3).

VALEURS DE RETOUR

EVP_KEYEXCH_fetch() retourne un pointeur vers un EVP_KEYEXCH en cas de succès ou NULL en cas d'échec.

EVP_KEYEXCH_up_ref() retourne 1 en cas de succès ou 0 sinon.

EVP_KEYEXCH_names_do_all() retourne 1 si la fonction de rappel a été appelée pour tous les noms. Une valeur de retour de 0 signifie que la fonction de rappel n'a été appelée pour aucun nom.

EVP_KEYEXCH_is_a() retourne 1 si exchange était identifiable, sinon 0.

EVP_KEYEXCH_gettable_ctx_params() et EVP_KEYEXCH_settable_ctx_params() retournent un tableau constant OSSL_PARAM(3) ou NULL en cas d'erreur.

VOIR AUSSI

"ALGORITHM FETCHING" dans crypto(7), OSSL_PROVIDER(3)
