EVP_MAC-KMAC(7ssl) OpenSSL EVP_MAC-KMAC(7ssl)

NOM

EVP_MAC-KMAC, EVP_MAC-KMAC128, EVP_MAC-KMAC256 - Les implémentations EVP_MAC de KMAC

DESCRIPTION

Support pour le calcul des MACs KMAC via l'API EVP_MAC.

Identité

Ces implémentations sont identifiées par l'un des noms et propriétés suivants, à utiliser avec EVP_MAC_fetch() :

"KMAC-128", "provider=default" ou "provider=fips"
"KMAC-256", "provider=default" ou "provider=fips"

Paramètres supportés

La description générale de ces paramètres se trouve dans "PARAMETERS" dans EVP_MAC(3).

Tous ces paramètres (à l'exception de "block-size") peuvent être définis avec EVP_MAC_CTX_set_params(). De plus, le paramètre "size" peut être récupéré avec EVP_MAC_CTX_get_params(), ou avec EVP_MAC_CTX_get_mac_size(). La longueur du paramètre "size" ne doit pas dépasser celle d'un size_t. De même, le paramètre "block-size" peut être récupéré avec EVP_MAC_CTX_get_params(), ou avec EVP_MAC_CTX_get_block_size().

"key" (OSSL_MAC_PARAM_KEY) <chaîne d'octets>
Définit la clé MAC. La définition de ce paramètre est identique au passage d'une key à EVP_MAC_init(3). La longueur de la clé (en octets) doit être comprise entre 4 et 512.
"custom" (OSSL_MAC_PARAM_CUSTOM) <chaîne d'octets>
Définit la chaîne de personnalisation. Il s'agit d'une valeur optionnelle d'une longueur maximale de 512 octets, et elle est vide par défaut.
"size" (OSSL_MAC_PARAM_SIZE) <entier non signé>
Définit la taille du MAC. Par défaut, elle est de 32 pour "KMAC-128" et de 64 pour "KMAC-256".
"block-size" (OSSL_MAC_PARAM_BLOCK_SIZE) <entier non signé>
Récupère la taille du bloc MAC. Elle est de 168 pour "KMAC-128" et de 136 pour "KMAC-256".
"xof" (OSSL_MAC_PARAM_XOF) <entier>
La valeur du paramètre "xof" est attendue comme étant 1 ou 0. Utilisez 1 pour activer le mode XOF. La valeur par défaut est 0.
"fips-indicator" (OSSL_MAC_PARAM_FIPS_APPROVED_INDICATOR) <int>
Ce paramètre configurable est décrit dans provider-mac(7).
"no-short-mac" (OSSL_MAC_PARAM_FIPS_NO_SHORT_MAC) <entier>
Ce paramètre configurable est décrit dans provider-mac(7). Il est utilisé par le fournisseur FIPS d'OpenSSL et la sortie de longueur minimale pour KMAC est définie par la SP 800-185 8.4.2 du NIST.
"key-check" (OSSL_MAC_PARAM_FIPS_KEY_CHECK) <entier>
Ce paramètre configurable est décrit dans provider-mac(7).

Les paramètres "custom" et "no-short-mac" doivent être définis dans le cadre de l'appel à EVP_MAC_init() ou avant celui-ci. Les paramètres "xof" et "size" peuvent être définis à tout moment avant EVP_MAC_final(). Le paramètre "key" est défini dans le cadre de l'appel à EVP_MAC_init(), mais peut être défini avant celui-ci à la place.

EXEMPLES

#include <openssl/evp.h>
#include <openssl/params.h>
static int do_kmac(const unsigned char *in, size_t in_len,
                   const unsigned char *key, size_t key_len,
                   const unsigned char *custom, size_t custom_len,
                   int xof_enabled, unsigned char *out, int out_len)
{
    EVP_MAC_CTX *ctx = NULL;
    EVP_MAC *mac = NULL;
    OSSL_PARAM params[4], *p;
    int ret = 0;
    size_t l = 0;
    mac = EVP_MAC_fetch(NULL, "KMAC-128", NULL);
    if (mac == NULL)
        goto err;
    ctx = EVP_MAC_CTX_new(mac);
    /* Le mac peut être libéré après avoir été utilisé par EVP_MAC_CTX_new */
    EVP_MAC_free(mac);
    if (ctx == NULL)
        goto err;
    /*
     * Configuration des paramètres requis avant d'appeler EVP_MAC_init()
     * Les paramètres OSSL_MAC_PARAM_XOF et OSSL_MAC_PARAM_SIZE peuvent également
     * être utilisés à ce stade.
     */
    p = params;
    *p++ = OSSL_PARAM_construct_octet_string(OSSL_MAC_PARAM_KEY,
                                             (void *)key, key_len);
    if (custom != NULL && custom_len != 0)
      *p++ = OSSL_PARAM_construct_octet_string(OSSL_MAC_PARAM_CUSTOM,
                                               (void *)custom, custom_len);
    *p = OSSL_PARAM_construct_end();
    if (!EVP_MAC_CTX_set_params(ctx, params))
        goto err;
    if (!EVP_MAC_init(ctx))
        goto err;
    /*
     * Note : les paramètres optionnels suivants peuvent être définis à tout moment
     * avant EVP_MAC_final().
     */
    p = params;
    *p++ = OSSL_PARAM_construct_int(OSSL_MAC_PARAM_XOF, &xof_enabled);
    *p++ = OSSL_PARAM_construct_int(OSSL_MAC_PARAM_SIZE, &out_len);
    *p = OSSL_PARAM_construct_end();
    if (!EVP_MAC_CTX_set_params(ctx, params))
        goto err;
    /* La mise à jour peut être appelée plusieurs fois ici pour une entrée en flux */
    if (!EVP_MAC_update(ctx, in, in_len))
        goto err;
    if (!EVP_MAC_final(ctx, out, &l, out_len))
        goto err;
    ret = 1;
err:
    EVP_MAC_CTX_free(ctx);
    return ret;
}
