EVP_PKEY_ENCRYPT(3ssl) OpenSSL EVP_PKEY_ENCRYPT(3ssl)

NOM

EVP_PKEY_encrypt_init_ex, EVP_PKEY_encrypt_init, EVP_PKEY_encrypt - chiffrer à l'aide d'un algorithme à clé publique

SYNOPSIS

#include <openssl/evp.h>
int EVP_PKEY_encrypt_init(EVP_PKEY_CTX *ctx);
int EVP_PKEY_encrypt_init_ex(EVP_PKEY_CTX *ctx, const OSSL_PARAM params[]);
int EVP_PKEY_encrypt(EVP_PKEY_CTX *ctx,
                     unsigned char *out, size_t *outlen,
                     const unsigned char *in, size_t inlen);

DESCRIPTION

La fonction EVP_PKEY_encrypt_init() initialise un contexte d'algorithme à clé publique en utilisant la clé pkey pour une opération de chiffrement.

La fonction EVP_PKEY_encrypt_init_ex() initialise un contexte d'algorithme à clé publique en utilisant la clé pkey pour une opération de chiffrement et définit les params spécifiques à l'algorithme.

La fonction EVP_PKEY_encrypt() effectue une opération de chiffrement à clé publique à l'aide de ctx. Les données à chiffrer sont spécifiées à l'aide des paramètres in et inlen. Si out est NULL, alors la taille maximale du tampon de sortie est écrite dans le paramètre outlen. Si out n'est pas NULL, alors avant l'appel, le paramètre outlen doit contenir la longueur du tampon out. Si l'appel réussit, les données chiffrées sont écrites dans out et la quantité de données écrite est dans outlen.

NOTES

Après l'appel à EVP_PKEY_encrypt_init(), des opérations de contrôle spécifiques à l'algorithme peuvent être effectuées pour définir les paramètres appropriés pour l'opération. Ces opérations peuvent être incluses dans l'appel EVP_PKEY_encrypt_init_ex().

La fonction EVP_PKEY_encrypt() peut être appelée plus d'une fois sur le même contexte si plusieurs opérations sont effectuées avec les mêmes paramètres.

VALEURS DE RETOUR

EVP_PKEY_encrypt_init(), EVP_PKEY_encrypt_init_ex() et EVP_PKEY_encrypt() retournent 1 en cas de succès et 0 ou une valeur négative en cas d'échec. En particulier, une valeur de retour de -2 indique que l'opération n'est pas supportée par l'algorithme à clé publique.

EXEMPLES

Chiffrer des données en utilisant OAEP (pour les clés RSA). Voir également PEM_read_PUBKEY(3) ou d2i_X509(3) pour les moyens de charger une clé publique. Vous pouvez aussi simplement définir 'eng = NULL;' pour commencer avec l'implémentation RSA par défaut d'OpenSSL:

#include <openssl/evp.h>
#include <openssl/rsa.h>
#include <openssl/engine.h>
EVP_PKEY_CTX *ctx;
ENGINE *eng;
unsigned char *out, *in;
size_t outlen, inlen;
EVP_PKEY *key;
/*
 * NB : suppose que eng, key, in, inlen sont déjà configurés,
 * et que key est une clé publique RSA
 */
ctx = EVP_PKEY_CTX_new(key, eng);
if (!ctx)
    /* Une erreur s'est produite */
if (EVP_PKEY_encrypt_init(ctx) <= 0)
    /* Erreur */
if (EVP_PKEY_CTX_set_rsa_padding(ctx, RSA_PKCS1_OAEP_PADDING) <= 0)
    /* Erreur */
/* Déterminer la longueur du tampon */
if (EVP_PKEY_encrypt(ctx, NULL, &outlen, in, inlen) <= 0)
    /* Erreur */
out = OPENSSL_malloc(outlen);
if (!out)
    /* Échec de malloc */
if (EVP_PKEY_encrypt(ctx, out, &outlen, in, inlen) <= 0)
    /* Erreur */
/* Les données chiffrées sont outlen octets écrits dans le tampon out */
