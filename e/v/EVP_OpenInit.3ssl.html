NOM

EVP_OpenInit, EVP_OpenUpdate, EVP_OpenFinal - Déchiffrement d'enveloppe EVP

SYNTAXE

#include <openssl/evp.h>
int EVP_OpenInit(EVP_CIPHER_CTX *ctx, EVP_CIPHER *type, unsigned char *ek,
                 int ekl, unsigned char *iv, EVP_PKEY *priv);
int EVP_OpenUpdate(EVP_CIPHER_CTX *ctx, unsigned char *out,
                   int *outl, unsigned char *in, int inl);
int EVP_OpenFinal(EVP_CIPHER_CTX *ctx, unsigned char *out, int *outl);

DESCRIPTION

Les routines d'enveloppe EVP sont une interface de haut niveau pour le déchiffrement d'enveloppe. Elles déchiffrent une clé symétrique chiffrée par clé publique, puis déchiffrent les données à l'aide de celle-ci.

EVP_OpenInit() initialise un contexte de chiffrement ctx pour le déchiffrement avec le chiffrement type. Il déchiffre la clé symétrique chiffrée de longueur ekl octets passée dans le paramètre ek en utilisant la clé privée priv. Le vecteur d'initialisation est fourni dans le paramètre iv.

EVP_OpenUpdate() et EVP_OpenFinal() ont exactement les mêmes propriétés que les routines EVP_DecryptUpdate() et EVP_DecryptFinal(), telles que décrites dans la page de manuel de EVP_EncryptInit(3).

NOTES

Il est possible d'appeler EVP_OpenInit() deux fois de la même manière que EVP_DecryptInit(). Le premier appel doit avoir priv défini sur NULL et (après avoir défini les paramètres de chiffrement) il doit être appelé à nouveau avec type défini sur NULL.

Si le chiffrement passé dans le paramètre type est un chiffrement de longueur variable, alors la longueur de la clé sera définie sur la valeur de la longueur de la clé récupérée. Si le chiffrement est un chiffrement de longueur fixe, alors la longueur de la clé récupérée doit correspondre à la longueur fixe du chiffrement.

VALEURS DE RETOUR

EVP_OpenInit() retourne 0 en cas d'erreur ou un entier non nul (en fait, la taille de la clé secrète récupérée) en cas de succès.

EVP_OpenUpdate() retourne 1 en cas de succès ou 0 en cas d'échec.

EVP_OpenFinal() retourne 0 si le déchiffrement a échoué ou 1 en cas de succès.
