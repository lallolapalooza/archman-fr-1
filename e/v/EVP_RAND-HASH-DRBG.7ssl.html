NOM

EVP_RAND-HASH-DRBG - L'implémentation HASH-DRBG d'EVP_RAND

DESCRIPTION

Prise en charge du générateur de bits aléatoires déterministes HASH via l'API EVP_RAND.

Identité

"HASH-DRBG" est le nom de cette implémentation ; il peut être utilisé avec la fonction EVP_RAND_fetch().

Paramètres pris en charge

Les paramètres pris en charge sont :

"state" (OSSL_RAND_PARAM_STATE) <entier>
"strength" (OSSL_RAND_PARAM_STRENGTH) <entier non signé>
"max_request" (OSSL_RAND_PARAM_MAX_REQUEST) <entier non signé>
"reseed_requests" (OSSL_DRBG_PARAM_RESEED_REQUESTS) <entier non signé>
"reseed_time_interval" (OSSL_DRBG_PARAM_RESEED_TIME_INTERVAL) <entier>
"min_entropylen" (OSSL_DRBG_PARAM_MIN_ENTROPYLEN) <entier non signé>
"max_entropylen" (OSSL_DRBG_PARAM_MAX_ENTROPYLEN) <entier non signé>
"min_noncelen" (OSSL_DRBG_PARAM_MIN_NONCELEN) <entier non signé>
"max_noncelen" (OSSL_DRBG_PARAM_MAX_NONCELEN) <entier non signé>
"max_perslen" (OSSL_DRBG_PARAM_MAX_PERSLEN) <entier non signé>
"max_adinlen" (OSSL_DRBG_PARAM_MAX_ADINLEN) <entier non signé>
"reseed_counter" (OSSL_DRBG_PARAM_RESEED_COUNTER) <entier non signé>
"properties" (OSSL_DRBG_PARAM_PROPERTIES) <chaîne UTF8>
"digest" (OSSL_DRBG_PARAM_DIGEST) <chaîne UTF8>
Ces paramètres fonctionnent comme décrit dans "PARAMETERS" de EVP_RAND(3).
"fips-indicator" (OSSL_DRBG_PARAM_FIPS_APPROVED_INDICATOR) <entier>
"digest-check" (OSSL_DRBG_PARAM_FIPS_DIGEST_CHECK) <entier>
Ces paramètres fonctionnent comme décrit dans "PARAMETERS" de provider-rand(7).

NOTES

Lorsque le fournisseur FIPS est installé en utilisant l'option -no_drbg_truncated_digests de fipsinstall, seuls ces digests sont autorisés (conformément à FIPS 140-3 IG D.R https://csrc.nist.gov/CSRC/media/Projects/cryptographic-module-validation-program/documents/fips%20140-3/FIPS%20140-3%20IG.pdf) :

L'implémentation par défaut de HASH-DRBG tente de récupérer les algorithmes internes requis auprès du fournisseur dans lequel elle est intégrée (par exemple, le fournisseur par défaut), indépendamment des propriétés fournies. Si le fournisseur n'implémente pas les algorithmes requis, les propriétés seront utilisées pour trouver une implémentation différente.

SHA-1
SHA2-256
SHA2-512
SHA3-256
SHA3-512

Un contexte pour HASH DRBG peut être obtenu en appelant :

EVP_RAND *rand = EVP_RAND_fetch(NULL, "HASH-DRBG", NULL);
EVP_RAND_CTX *rctx = EVP_RAND_CTX_new(rand, NULL);

EXEMPLES

EVP_RAND *rand;
EVP_RAND_CTX *rctx;
unsigned char bytes[100];
OSSL_PARAM params[2], *p = params;
unsigned int strength = 128;
rand = EVP_RAND_fetch(NULL, "HASH-DRBG", NULL);
rctx = EVP_RAND_CTX_new(rand, NULL);
EVP_RAND_free(rand);
*p++ = OSSL_PARAM_construct_utf8_string(OSSL_DRBG_PARAM_DIGEST, SN_sha512, 0);
*p = OSSL_PARAM_construct_end();
EVP_RAND_instantiate(rctx, strength, 0, NULL, 0, params);
EVP_RAND_generate(rctx, bytes, sizeof(bytes), strength, 0, NULL, 0);
EVP_RAND_CTX_free(rctx);

CONFORMITÉ

NIST SP 800-90A et SP 800-90B

VOIR AUSSI

EVP_RAND(3), "PARAMETERS" dans EVP_RAND(3), openssl-fipsinstall(1)

HISTORIQUE

OpenSSL 3.1.1 a introduit l'option -no_drbg_truncated_digests pour fipsinstall, qui restreint les digests autorisés lors de l'utilisation du fournisseur FIPS de manière conforme. Pour plus de détails, voir FIPS 140-3 IG D.R https://csrc.nist.gov/CSRC/media/Projects/cryptographic-module-validation-program/documents/fips%20140-3/FIPS%20140-3%20IG.pdf.
