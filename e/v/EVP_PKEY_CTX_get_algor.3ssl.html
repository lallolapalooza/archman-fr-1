EVP_PKEY_CTX_get_algor(3ssl)

Paquet: openssl

Licences: Apache-2.0

EVP_PKEY_CTX_GET_ALGOR(3ssl) OpenSSL EVP_PKEY_CTX_GET_ALGOR(3ssl)

NOM

EVP_CIPHER_CTX_get_algor, EVP_CIPHER_CTX_get_algor_params, EVP_CIPHER_CTX_set_algor_params, EVP_PKEY_CTX_get_algor, EVP_PKEY_CTX_get_algor_params, EVP_PKEY_CTX_set_algor_params - passer l'identifiant d'algorithme et ses paramètres aux implémentations d'algorithmes / depuis celles-ci

SYNTAXE

int EVP_TYPE_CTX_get_algor(EVP_TYPE_CTX *ctx, X509_ALGOR **alg);
int EVP_TYPE_CTX_get_algor_params(EVP_TYPE_CTX *ctx, X509_ALGOR *alg);
int EVP_TYPE_CTX_set_algor_params(EVP_TYPE_CTX *ctx, const X509_ALGOR *alg);

DESCRIPTION

Dans la description ici et dans la section "SYNTAXE" ci-dessus, TYPE est utilisé comme espace réservé pour tout type d'opération EVP.

EVP_TYPE_CTX_get_algor() tente de récupérer un identifiant d'algorithme complet à partir de l'implémentation EVP_TYPE, et remplit *alg avec celui-ci. Si alg est NULL, appeler cette fonction permettra de vérifier si cet appel est supporté par l'implémentation EVP_TYPE. Si *alg est NULL, de l'espace sera alloué automatiquement et assigné à *alg.

EVP_TYPE_CTX_get_algor_params() tente de récupérer la partie paramètres d'un identifiant d'algorithme à partir de l'implémentation EVP_TYPE, et remplit alg-parameters> avec. Si alg est NULL, appeler cette fonction permettra de vérifier si cet appel est supporté par l'implémentation EVP_TYPE. Si alg->parameters est NULL, de l'espace sera alloué automatiquement et assigné à alg->parameters. Si alg->parameters n'est pas NULL, son contenu précédent sera écrasé par les paramètres d'identifiant d'algorithme récupérés. Attention !

EVP_TYPE_CTX_set_algor_params() tente de passer alg->parameters à l'implémentation EVP_TYPE. Si alg est NULL, appeler cette fonction permettra de vérifier si cet appel est supporté par l'implémentation EVP_TYPE.

VALEURS DE RETOUR

Toutes les fonctions retournent 1 en cas de succès, et 0 ou un nombre négatif si une erreur se produit. En particulier, -2 est retourné lorsque la fonction n'est pas supportée par l'implémentation EVP_TYPE.

HISTORIQUE

Ces fonctions ont été ajoutées dans OpenSSL 3.4.
