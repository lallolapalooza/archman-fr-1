EVP_PKEY_CTX_set_params(3ssl)

Paquet: openssl

Licences: Apache-2.0

EVP_PKEY_CTX_SET_PARAMS(3ssl) OpenSSL EVP_PKEY_CTX_SET_PARAMS(3ssl)

NOM

EVP_PKEY_CTX_set_params, EVP_PKEY_CTX_settable_params, EVP_PKEY_CTX_get_params, EVP_PKEY_CTX_gettable_params - opérations de passage de paramètres du fournisseur

SYNTAXE

#include <openssl/evp.h>
int EVP_PKEY_CTX_set_params(EVP_PKEY_CTX *ctx, const OSSL_PARAM *params);
const OSSL_PARAM *EVP_PKEY_CTX_settable_params(const EVP_PKEY_CTX *ctx);
int EVP_PKEY_CTX_get_params(EVP_PKEY_CTX *ctx, OSSL_PARAM *params);
const OSSL_PARAM *EVP_PKEY_CTX_gettable_params(const EVP_PKEY_CTX *ctx);

DESCRIPTION

Les fonctions EVP_PKEY_CTX_get_params() et EVP_PKEY_CTX_set_params() permettent le transfert de paramètres de clé arbitraires vers et depuis les fournisseurs. Tous les paramètres ne sont pas nécessairement pris en charge par tous les fournisseurs. Voir OSSL_PROVIDER(3) pour plus d'informations sur les fournisseurs. Le champ params est un pointeur vers une liste de structures OSSL_PARAM, terminée par une structure OSSL_PARAM_END(3). Voir OSSL_PARAM(3) pour des informations sur le passage des paramètres. Ces fonctions ne doivent être appelées qu'après que l'EVP_PKEY_CTX a été initialisé pour être utilisé dans une opération. Ces méthodes remplacent le mécanisme EVP_PKEY_CTX_ctrl(). (EVP_PKEY_CTX_ctrl appelle maintenant ces méthodes en interne pour interagir avec les fournisseurs).

EVP_PKEY_CTX_gettable_params() et EVP_PKEY_CTX_settable_params() obtiennent un tableau constant OSSL_PARAM(3) qui décrit les paramètres récupérables et configurables pour l'implémentation algorithmique actuelle, c'est-à-dire les paramètres qui peuvent être utilisés avec EVP_PKEY_CTX_get_params() et EVP_PKEY_CTX_set_params() respectivement. Ces fonctions ne doivent être appelées qu'après que l'EVP_PKEY_CTX a été initialisé pour être utilisé dans une opération.

Paramètres

Les exemples de paramètres EVP_PKEY incluent les suivants :

"Paramètres courants" dans provider-keymgmt(7) "Paramètres d'échange de clés" dans provider-keyexch(7) "Paramètres de signature" dans provider-signature(7)

"Paramètres RSA courants" dans EVP_PKEY-RSA(7) "Paramètres de génération de clés RSA" dans EVP_PKEY-RSA(7) "Paramètres FFC" dans EVP_PKEY-FFC(7) "Paramètres de génération de clés FFC" dans EVP_PKEY-FFC(7) "Paramètres DSA" dans EVP_PKEY-DSA(7) "Paramètres de génération de clés DSA" dans EVP_PKEY-DSA(7) "Paramètres DH" dans EVP_PKEY-DH(7) "Paramètres de génération de clés DH" dans EVP_PKEY-DH(7) "Paramètres EC courants" dans EVP_PKEY-EC(7) "Paramètres courants X25519, X448, ED25519 et ED448" dans EVP_PKEY-X25519(7) "Paramètres LMS courants" dans EVP_PKEY-LMS(7) "Paramètres courants" dans EVP_PKEY-ML-DSA(7) "Paramètres courants" dans EVP_PKEY-ML-KEM(7)

VALEURS DE RETOUR

EVP_PKEY_CTX_set_params() retourne 1 en cas de succès ou 0 sinon. EVP_PKEY_CTX_settable_params() retourne un tableau OSSL_PARAM en cas de succès ou NULL en cas d'erreur. Il peut également retourner NULL s'il n'y a pas de paramètres configurables disponibles.

Toutes les autres fonctions et macros décrites sur cette page retournent une valeur positive en cas de succès et 0 ou une valeur négative en cas d'échec. En particulier, une valeur de retour de -2 indique que l'opération n'est pas prise en charge par l'algorithme de clé publique.

NOTES

La prise en charge de LMS est désactivée par défaut au moment de la compilation. Pour l'activer, spécifiez l'option de configuration de build enable-lms.
