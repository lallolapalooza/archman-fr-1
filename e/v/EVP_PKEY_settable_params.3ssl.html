EVP_PKEY_settable_params(3ssl)

Paquet: openssl

Licences: Apache-2.0

EVP_PKEY_SETTABLE_PARAMS(3ssl) OpenSSL EVP_PKEY_SETTABLE_PARAMS(3ssl)

NOM

EVP_PKEY_settable_params, EVP_PKEY_set_params, EVP_PKEY_set_int_param, EVP_PKEY_set_size_t_param, EVP_PKEY_set_bn_param, EVP_PKEY_set_utf8_string_param, EVP_PKEY_set_octet_string_param - définir des paramètres de clé dans une clé

SYNTAXE

#include <openssl/evp.h>
const OSSL_PARAM *EVP_PKEY_settable_params(const EVP_PKEY *pkey);
int EVP_PKEY_set_params(EVP_PKEY *pkey, OSSL_PARAM params[]);
int EVP_PKEY_set_int_param(EVP_PKEY *pkey, const char *key_name, int in);
int EVP_PKEY_set_size_t_param(EVP_PKEY *pkey, const char *key_name, size_t in);
int EVP_PKEY_set_bn_param(EVP_PKEY *pkey, const char *key_name,
                          const BIGNUM *bn);
int EVP_PKEY_set_utf8_string_param(EVP_PKEY *pkey, const char *key_name,
                                   const char *str);
int EVP_PKEY_set_octet_string_param(EVP_PKEY *pkey, const char *key_name,
                                    const unsigned char *buf, size_t bsize);

DESCRIPTION

Ces fonctions peuvent être utilisées pour définir des paramètres supplémentaires dans un EVP_PKEY existant.

EVP_PKEY_set_params() définit un ou plusieurs params dans un pkey. Voir OSSL_PARAM(3) pour plus d'informations sur les paramètres.

EVP_PKEY_settable_params() renvoie une liste constante de params indiquant les noms et types des paramètres de clé qui peuvent être définis. Voir OSSL_PARAM(3) pour plus d'informations sur les paramètres.

EVP_PKEY_set_int_param() définit une valeur entière in dans une clé pkey pour le champ associé key_name.

EVP_PKEY_set_size_t_param() définit une valeur size_t in dans une clé pkey pour le champ associé key_name.

EVP_PKEY_set_bn_param() définit la valeur BIGNUM bn dans une clé pkey pour le champ associé key_name.

EVP_PKEY_set_utf8_string_param() définit la chaîne UTF8 str dans une clé pkey pour le champ associé key_name.

EVP_PKEY_set_octet_string_param() définit la chaîne d'octets buf d'une taille bsize dans une clé pkey pour le champ associé key_name.

NOTES

Ces fonctions ne fonctionnent que pour les EVP_PKEY qui contiennent une clé côté fournisseur.

VALEUR DE RETOUR

EVP_PKEY_settable_params() renvoie NULL en cas d'erreur ou si elle n'est pas prise en charge.

Toutes les autres méthodes renvoient 1 si une valeur a été définie avec succès, ou 0 en cas d'erreur.
