EVP_PKEY_get_size(3ssl)

Paquet: openssl

Licences: Apache-2.0

EVP_PKEY_GET_SIZE(3ssl) OpenSSL EVP_PKEY_GET_SIZE(3ssl)

NOM

EVP_PKEY_get_size, EVP_PKEY_get_bits, EVP_PKEY_get_security_bits, EVP_PKEY_bits, EVP_PKEY_security_bits, EVP_PKEY_get_security_category, EVP_PKEY_size - Fonctions d'information EVP_PKEY

SYNTAXE

#include <openssl/evp.h>
int EVP_PKEY_get_size(const EVP_PKEY *pkey);
int EVP_PKEY_get_bits(const EVP_PKEY *pkey);
int EVP_PKEY_get_security_bits(const EVP_PKEY *pkey);
int EVP_PKEY_get_security_category(const EVP_PKEY *pkey);
#define EVP_PKEY_bits EVP_PKEY_get_bits
#define EVP_PKEY_security_bits EVP_PKEY_get_security_bits
#define EVP_PKEY_size EVP_PKEY_get_size

DESCRIPTION

EVP_PKEY_get_size() renvoie la taille maximale appropriée pour les tampons de sortie pour presque toutes les opérations pouvant être effectuées avec pkey. Ceci correspond au paramètre du fournisseur OSSL_PKEY_PARAM_MAX_SIZE. L'utilisation principale documentée est avec EVP_SignFinal(3) et EVP_SealInit(3), mais elle ne s'y limite pas. La taille renvoyée est également suffisamment grande pour le tampon de sortie de EVP_PKEY_sign(3), EVP_PKEY_encrypt(3), EVP_PKEY_decrypt(3), EVP_PKEY_derive(3).

Il faut souligner que, sauf indication contraire dans la documentation de l'opération effectuée, la taille renvoyée par EVP_PKEY_get_size() est seulement préliminaire et non exacte, donc le contenu final du tampon cible peut être plus petit. Il est donc crucial de prendre note de la taille renvoyée par la fonction qui effectue l'opération, telle que EVP_PKEY_sign(3) (l'argument siglen recevra cette longueur), pour éviter les bugs.

EVP_PKEY_get_bits() renvoie la longueur cryptographique du système cryptographique auquel appartient la clé dans pkey, en bits. Notez que la définition de la longueur cryptographique est spécifique au système cryptographique de la clé. Cette longueur correspond au paramètre du fournisseur OSSL_PKEY_PARAM_BITS.

EVP_PKEY_get_security_bits() renvoie le nombre de bits de sécurité de pkey donné, les bits de sécurité étant définis dans le NIST SP800-57. Ceci correspond au paramètre du fournisseur OSSL_PKEY_PARAM_SECURITY_BITS.

EVP_PKEY_get_security_category() renvoie la catégorie de sécurité post-quantique https://nvlpubs.nist.gov/nistpubs/ir/2024/NIST.IR.8547.ipd.pdf telle que définie par le NIST. La catégorie de sécurité post-quantique est une valeur entière de 0 à 5 basée sur la classification d'un algorithme dans la plage des forces de sécurité offertes par les normes existantes en cryptographie symétrique :

VALEURS DE RETOUR

EVP_PKEY_get_size(), EVP_PKEY_get_bits() et EVP_PKEY_get_security_bits() renvoient un nombre positif, ou 0 si cette taille n'est pas disponible.

EVP_PKEY_get_security_category() renvoie la catégorie de sécurité post-quantique, qui est un entier dans la plage de zéro à cinq inclusivement. Elle renvoie -1 si les informations sur la catégorie de sécurité ne sont pas disponibles. Pour tous les algorithmes classiques, 0 est renvoyé, signifiant qu'ils ne sont pas considérés comme quantiquement sûrs.

NOTES

La plupart des fonctions qui ont un tampon de sortie et sont mentionnées avec EVP_PKEY_get_size() ont une fonctionnalité où vous pouvez passer NULL pour le tampon et toujours passer un pointeur vers un entier et obtenir la taille exacte que cet appel de fonction délivre dans le contexte où il est appelé. Cela permet d'appeler ces fonctions deux fois, une fois pour connaître la taille exacte du tampon, puis allouer le tampon entre les deux, et rappeler cette fonction pour réellement sortir les données. Pour ces fonctions, il n'est pas strictement nécessaire d'appeler EVP_PKEY_get_size() pour connaître la taille du tampon, mais cela peut être utile dans les cas où il est souhaitable de connaître la limite supérieure à l'avance.

Il convient également de noter en particulier que EVP_PKEY_get_size() ne doit pas être utilisé pour obtenir la taille de sortie de EVP_DigestSignFinal(), conformément aux « NOTES » dans EVP_DigestSignFinal(3).

VOIR AUSSI

provider-keymgmt(7), EVP_SignFinal(3), EVP_SealInit(3), EVP_PKEY_sign(3), EVP_PKEY_encrypt(3), EVP_PKEY_decrypt(3), EVP_PKEY_derive(3)

HISTORIQUE

Les fonctions EVP_PKEY_bits(), EVP_PKEY_security_bits() et EVP_PKEY_size() ont été renommées pour inclure "get" dans leurs noms dans OpenSSL 3.0, respectivement. Les anciens noms sont conservés en tant que macros d'alias non obsolètes.

EVP_PKEY_get_security_category() a été ajoutée dans OpenSSL 3.6.
