EVP_BYTESTOKEY(3ssl) OpenSSL EVP_BYTESTOKEY(3ssl)

NOM

EVP_BytesToKey - routine de chiffrement basée sur mot de passe

SYNTAXE

#include <openssl/evp.h>
int EVP_BytesToKey(const EVP_CIPHER *type, const EVP_MD *md,
                   const unsigned char *salt,
                   const unsigned char *data, int datal, int count,
                   unsigned char *key, unsigned char *iv);

DESCRIPTION

EVP_BytesToKey() dérive une clé et un IV à partir de divers paramètres. type est le chiffrement pour lequel dériver la clé et l'IV. md est le résumé de message à utiliser. Le paramètre salt est utilisé comme sel dans la dérivation : il doit pointer vers un tampon de 8 octets ou être NULL si aucun sel n'est utilisé. data est un tampon contenant datal octets qui est utilisé pour dériver les données de clé. count est le nombre d'itérations à utiliser. La clé et l'IV dérivés seront écrits respectivement dans key et iv.

NOTES

Une application typique de cette fonction est de dériver un matériel de clé pour un algorithme de chiffrement à partir d'un mot de passe dans le paramètre data.

Augmenter le paramètre count ralentit l'algorithme, ce qui rend plus difficile pour un attaquant de réaliser une attaque par force brute en utilisant un grand nombre de mots de passe candidats.

Si la longueur totale de la clé et de l'IV est inférieure à la longueur du résumé et que MD5 est utilisé, alors l'algorithme de dérivation est compatible avec PKCS#5 v1.5, sinon une extension non standard est utilisée pour dériver les données supplémentaires.

Les applications plus récentes devraient utiliser un algorithme plus moderne tel que PBKDF2 tel que défini dans PKCS#5v2.1 et fourni par PKCS5_PBKDF2_HMAC.

ALGORITHME DE DÉRIVATION DE CLÉ

La clé et l'IV sont dérivés en concaténant D_1, D_2, etc. jusqu'à ce que suffisamment de données soient disponibles pour la clé et l'IV. D_i est défini comme suit :

D_i = HASH^count(D_(i-1) || data || salt)

où || dénote la concaténation, D_0 est vide, HASH est l'algorithme de résumé utilisé, HASH^1(data) est simplement HASH(data), HASH^2(data) est HASH(HASH(data)) et ainsi de suite.

Les octets initiaux sont utilisés pour la clé et les octets suivants pour l'IV.

VALEURS DE RETOUR

Si data est NULL, alors EVP_BytesToKey() renvoie le nombre d'octets nécessaires pour stocker la clé dérivée. Sinon, EVP_BytesToKey() renvoie la taille de la clé dérivée en octets, ou 0 en cas d'erreur.
