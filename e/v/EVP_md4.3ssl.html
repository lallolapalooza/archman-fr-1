NOM

EVP_md4 - MD4 pour EVP

SYNTAXE

#include <openssl/evp.h>
const EVP_MD *EVP_md4(void);

DESCRIPTION

MD4 est une fonction de hachage cryptographique standardisée dans la RFC 1320 et conçue par Ronald Rivest, publiée pour la première fois en 1990. Cette implémentation n'est disponible qu'avec le fournisseur hérité (legacy provider).

EVP_md4()
L'algorithme MD4 qui produit une sortie de 128 bits à partir d'une entrée donnée.

NOTES

Les développeurs doivent être conscients des implications négatives sur les performances lors de l'appel de cette fonction à plusieurs reprises et devraient envisager d'utiliser EVP_MD_fetch(3) avec EVP_MD-MD4(7) à la place. Voir "Performance" dans crypto(7) pour plus d'informations.

VALEUR DE RETOUR

Ces fonctions retournent une structure EVP_MD qui contient l'implémentation du résumé de message. Voir EVP_MD_meth_new(3) pour les détails de la structure EVP_MD.

CONFORMITÉ

IETF RFC 1320.

VOIR AUSSI

evp(7), provider(7), EVP_DigestInit(3)
