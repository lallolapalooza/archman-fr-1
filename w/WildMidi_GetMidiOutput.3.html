WildMidi_GetMidiOutput(3)

WildMidi_GetMidiOutput(3) Manuel du programmeur WildMidi WildMidi_GetMidiOutput(3)

NOM

WildMidi_GetMidiOutput - obtenir un fichier midi d'un fichier en cours de traitement.

BIBLIOTHEQUE

libWildMidi

SYNTAXE

#include <wildmidi_lib.h>

int WildMidi_GetMidiOutput (midi *handle, int8_t **buffer, uint32_t *size)

DESCRIPTION

Écrit les données au format midi du fichier en cours de traitement dans l'emplacement mémoire pointé par buffer. Les données seront au format type-0 pour les fichiers de type-0 et type-1. Pour les fichiers de type-2, les données seront au format type-2 à moins que l'option WM_MO_SAVEASTYPE0 ne soit définie.

handle
L'identifiant obtenu en ouvrant un fichier avec WildMidi_Open(3) ou WildMidi_OpenBuffer(3)
buffer
L'emplacement mémoire où libWildMidi doit stocker les données midi du handle. Le buffer sera alloué avec malloc() et doit être libéré avec free() par l'appelant lorsqu'il n'est plus nécessaire.
size
L'emplacement où libWildMidi doit stocker la taille des données midi stockées dans buffer.

VALEUR DE RETOUR

Retourne -1 en cas d'erreur, sinon retourne 0
