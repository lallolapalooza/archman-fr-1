NOM

WildMidi_Open - Ouvrir un fichier midi pour traitement

BIBLIOTHÈQUE

libWildMidi

SYNOPSIS

#include <wildmidi_lib.h>

midi *WildMidi_Open (const char *midifile)

DESCRIPTION

Ouvre un fichier de type MIDI pointé par midifile pour traitement. Ce fichier doit être au format HMP, HMI, MIDI ou XMIDI.

VALEUR DE RETOUR

Retourne NULL en cas d'erreur et envoie un message sur stderr, sinon retourne un descripteur pour le fichier midi ouvert. Ce descripteur est utilisé par la plupart des fonctions de libWildMidi pour identifier le fichier midi auquel nous faisons référence.
