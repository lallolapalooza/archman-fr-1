WildMidi_GetOutput(3)

WildMidi_GetOutput(3) Manuel du programmeur WildMidi WildMidi_GetOutput(3)

NOM

WildMidi_GetOutput - récupérer les données audio brutes

BIBLIOTHÈQUE

libWildMidi

SYNTAXE

#include <wildmidi_lib.h>

int WildMidi_GetOutput (midi *handle, int8_t *buffer, uint32_t size);

DESCRIPTION

Place size octets de données audio provenant d'un handle, précédemment ouvert par WildMidi_Open(3) ou WildMidi_OpenBuffer(3), dans un tampon pointé par buffer.

buffer doit avoir une taille d'au moins size octets, et size doit être un multiple de 4 car les données sont stockées au format stéréo entrelacé 16 bits.

handle
L'identifiant obtenu en ouvrant un fichier midi avec WildMidi_Open(3) ou WildMidi_OpenBuffer(3)
buffer
L'emplacement fourni par le programme appelant où libWildMidi doit stocker les données audio. Les données audio seront stockées en stéréo entrelacé 16 bits signé, dans l'ordre des octets natif.
size
La taille du tampon en octets. Comme libWildMidi traite l'audio au format stéréo entrelacé 16 bits, cette valeur doit être un multiple de 4.

VALEUR DE RETOUR

Retourne -1 en cas d'erreur, avec un message d'erreur envoyé sur stderr, 0 lorsqu'il n'y a plus de données audio, sinon le nombre d'octets de données audio écrits dans buffer.

NOTE : si la valeur de retour est inférieure à la taille que vous avez fournie, cela ne signifie pas une erreur, cela signifie simplement que la lib a atteint la fin du midi avant de pouvoir remplir le tampon.
