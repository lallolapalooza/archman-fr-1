openssl

obtenir la dernière version d'openssl depuis http://www.openssl.org

$ ./config
$ make
$ make test
$ make install

WWW::SMS

obtenir la dernière version de Www::Sms depuis http://search.cpan.org/author/GIULIENK/
mettre à jour SMS.pm avec le nouveau fournisseur si désiré
copier o2UK.pm dans votre répertoire de bibliothèque Perl /WWW/SMS/, par exemple dans :
linux:/usr/lib/perl5/site_perl/5.6.1/WWW/SMS>
vous devez vous inscrire auprès d'O2 http://www.o2.co.uk/ (anciennement genie)
ce qui est gratuit pour le moment et vous permet d'envoyer 100 sms/mois gratuitement
vous devez fournir le nom d'utilisateur/mot de passe ou le fichier qui les contient
je ne connais pas encore toutes les cartes SIM fournies : o2 et vodafone fonctionnent
et tester :-)
use WWW::SMS;
#préfixe international, préfixe opérateur, numéro de téléphone, texte du message
my $sms = WWW::SMS->new('44', '7777', '123456', 'Ceci est un test.','username' => 'votre_nom_utilisateur_o2', 'password' => 'votre_mot_de_passe_o2');
for ( $sms->gateways() ) {
    print "Essai avec $_...\n";
    if ( $sms->send($_) ) {               # essayer d'envoyer un sms...
        last;                             # jusqu'à ce que ça réussisse ;)
    } else {
        print $WWW::SMS::Error;           # pas de chance !
    }
}
