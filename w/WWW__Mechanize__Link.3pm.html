WWW::Mechanize::Link(3) Documentation Perl fournie par l'utilisateur WWW::Mechanize::Link(3)

NOM

WWW::Mechanize::Link - Objet Lien pour WWW::Mechanize

VERSION

version 2.20

SYNOPSIS

Objet Lien pour encapsuler toutes les informations que Mech nécessite mais que personne ne veut gérer sous forme de tableau.

CONSTRUCTEUR

new()

my $link = WWW::Mechanize::Link->new( {
    url  => $url,
    text => $text,
    name => $name,
    tag  => $tag,
    base => $base,
    attr => $attr_href,
} );

Pour des raisons de compatibilité, l'ancienne interface est également prise en charge :

new( $url, $text, $name, $tag, $base, $attr_href )

Crée et retourne un nouvel objet "WWW::Mechanize::Link".

ACCESSEURS

$link->url()

URL du lien

$link->text()

Texte du lien

$link->name()

Attribut NAME de la balise source, le cas échéant.

$link->tag()

Nom de la balise (l'un de : "a", "area", "frame", "iframe" ou "meta").

$link->base()

URL de base à laquelle les liens sont relatifs.

$link->attrs()

Retourne une référence de hachage de tous les attributs et de leurs valeurs dans la balise.

$link->URI()

Retourne l'URL sous forme d'objet URI::URL.

$link->url_abs()

Retourne un objet URI::URL pour la forme absolue de la chaîne.

VOIR AUSSI

WWW::Mechanize et WWW::Mechanize::Image
