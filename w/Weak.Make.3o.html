Module Make
: (H : Hashtbl.HashedType) -> sig end

Fonctionnalité construisant une implémentation de la structure d'ensemble de hachage faible. H.equal ne peut pas être l'égalité physique, car seules des copies superficielles des éléments de l'ensemble lui sont fournies.

Paramètres :

« H »

Stdlib.Hashtbl.HashedType

type data

Le type des éléments stockés dans la table.

type t

Le type des tables contenant des éléments de type data. Notez que les ensembles de hachage faibles ne peuvent pas être sérialisés en utilisant output_value ou les fonctions du module Marshal.

val create : int -> t

create n crée un nouvel ensemble de hachage faible vide, de taille initiale n. La table augmentera au besoin.

val clear : t -> unit

Supprime tous les éléments de la table.

val merge : t -> data -> data

merge t x renvoie une instance de x trouvée dans t s'il y en a, sinon ajoute x à t et renvoie x.

val add : t -> data -> unit

add t x ajoute x à t. S'il existe déjà une instance de x dans t, il est indéterminé laquelle sera renvoyée par les appels ultérieurs à find et merge.

val remove : t -> data -> unit

remove t x supprime de t une instance de x. Ne fait rien s'il n'existe aucune instance de x dans t.

val find : t -> data -> data

find t x renvoie une instance de x trouvée dans t.

Lève Not_found s'il n'y a pas d'élément correspondant.

val find_opt : t -> data -> data option

find_opt t x renvoie une instance de x trouvée dans t ou None s'il n'y a pas d'élément correspondant.

Depuis 4.05

val find_all : t -> data -> data list

find_all t x renvoie une liste de toutes les instances de x trouvées dans t.

val mem : t -> data -> bool

mem t x renvoie true s'il existe au moins une instance de x dans t, sinon false.

val iter : (data -> unit) -> t -> unit

iter f t appelle f sur chaque élément de t, dans un ordre indéterminé. Il n'est pas spécifié ce qui se passe si f tente de modifier t lui-même.

val fold : (data -> 'acc -> 'acc) -> t -> 'acc -> 'acc

fold f t init calcule (f d1 (... (f dN init))) où d1 ... dN sont les éléments de t dans un ordre indéterminé. Il n'est pas spécifié ce qui se passe si f tente de modifier t lui-même.

val count : t -> int

Compte le nombre d'éléments dans la table. count t donne le même résultat que fold (fun _ n -> n+1) t 0 mais ne retarde pas la désallocation des éléments morts.

val stats : t -> int * int * int * int * int * int

Renvoie des statistiques sur la table. Les nombres sont, dans l'ordre : longueur de la table, nombre d'entrées, somme des longueurs des compartiments, longueur du plus petit compartiment, longueur médiane du compartiment, longueur du plus grand compartiment.
