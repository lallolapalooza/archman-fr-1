Win::Hivex(3) Documentation Perl fournie par l'utilisateur Win::Hivex(3)

NOM

Win::Hivex - Liens Perl pour lire et écrire les fichiers de ruche du Registre Windows

SYNTAXE

use Win::Hivex;
$h = Win::Hivex->open ('SOFTWARE');
$root_node = $h->root ();
print $h->node_name ($root_node);

DESCRIPTION

Le module "Win::Hivex" fournit un lien XS Perl à l'API hivex(3) pour lire et écrire les fichiers binaires de ruche du Registre Windows.

ERREURS

Toutes les erreurs déclenchent des appels à "croak" (voir Carp(3)).

MÉTHODES

open
$h = Win::Hivex->open ($filename,
                       [verbose => 1,]
                       [debug => 1,]
                       [write => 1,]
                       [unsafe => 1,])

Ouvre un fichier de ruche binaire du Registre Windows.

Les indicateurs "verbose" et "debug" activent différents niveaux de messages de débogage.

L'indicateur "write" est requis si vous allez modifier le fichier de ruche (voir "ÉCRIRE DANS LES FICHIERS DE RUCHE" dans hivex(3)).

Cette fonction retourne un handle de ruche. La ruche est fermée automatiquement lorsque son compteur de références tombe à 0.

root
$node = $h->root ()

Retourne le nœud racine de la ruche. Toutes les ruches valides doivent contenir un nœud racine.

Retourne un handle de nœud.

last_modified
$int64 = $h->last_modified ()

Retourne l'heure de modification depuis l'en-tête de la ruche.

La valeur retournée est une filetime Windows. Pour la convertir en "time_t" Unix, voir : http://stackoverflow.com/questions/6161776/convert-windows-filetime-to-second-in-unix-linux/6161842#6161842

node_name
$string = $h->node_name ($node)

Retourne le nom du nœud.

Notez que le nom du nœud racine est un nom factice, tel que "$$$PROTO.HIV" (d'autres noms sont possibles : cela semble dépendre de l'outil ou du programme qui a créé la ruche initialement). Vous ne pouvez connaître le nom "réel" du nœud racine qu'en sachant de quel fichier de registre provient initialement cette ruche, une connaissance qui sort du cadre de cette bibliothèque.

Le nom est recodé en UTF-8 et peut contenir des caractères NUL embarqués.

node_name_len
$size = $h->node_name_len ($node)

Retourne la longueur du nom du nœud tel que produit par "node_name".

Retourne une taille.

node_timestamp
$int64 = $h->node_timestamp ($node)

Retourne l'heure de modification du nœud.

La valeur retournée est une filetime Windows. Pour la convertir en "time_t" Unix, voir : http://stackoverflow.com/questions/6161776/convert-windows-filetime-to-second-in-unix-linux/6161842#6161842

node_children
@nodes = $h->node_children ($node)

Retourne un tableau de nœuds qui sont les sous-clés (enfants) de "node".

Retourne une liste de handles de nœuds.

node_get_child
$node = $h->node_get_child ($node, $name)

Retourne l'enfant du nœud avec le nom "name", s'il existe.

Le nom est comparé sans tenir compte de la casse.

Retourne un handle de nœud, ou "undef" si le nœud n'a pas été trouvé.

node_nr_children
$size = $h->node_nr_children ($node)

Retourne le nombre de nœuds tel que produit par "node_children".

Retourne une taille.

node_parent
$node = $h->node_parent ($node)

Retourne le parent de "node".

Le pointeur parent du nœud racine dans les fichiers de registre que nous avons examinés semble être invalide, et cette fonction retournera donc une erreur si elle est appelée sur le nœud racine.

Retourne un handle de nœud.

node_values
@values = $h->node_values ($node)

Retourne le tableau de paires (clé, valeur) attachées à ce nœud.

Retourne une liste de handles de valeur.

node_get_value
$value = $h->node_get_value ($node, $key)

Retourne la valeur attachée à ce nœud qui a le nom "key", si elle existe.

Le nom de la clé est comparé sans tenir compte de la casse.

Notez que pour obtenir la clé par défaut, vous devez passer la chaîne vide "" ici. La clé par défaut est souvent écrite "@", mais à l'intérieur des ruches cela n'a pas de sens et ne vous donnera pas la clé par défaut.

Retourne un handle de valeur.

node_nr_values
$size = $h->node_nr_values ($node)

Retourne le nombre de paires (clé, valeur) attachées à ce nœud tel que produit par "node_values".

Retourne une taille.

value_key_len
$size = $h->value_key_len ($val)

Retourne la longueur de la clé (nom) d'une paire (clé, valeur) telle que produite par "value_key". La longueur peut légitimement être de 0, donc errno est le mécanisme nécessaire pour vérifier les erreurs.

Dans le contexte des Registres Windows, un nom de longueur zéro signifie que cette valeur est la clé par défaut pour ce nœud dans l'arbre. Ceci est généralement écrit sous la forme "@".

La clé est recodée en UTF-8 et peut contenir des caractères NUL embarqués.

Retourne une taille.

value_key
$string = $h->value_key ($val)

Retourne la clé (nom) d'une paire (clé, valeur). Le nom est réencodé en UTF-8 et retourné sous forme de chaîne.

La chaîne doit être libérée par l'appelant lorsqu'elle n'est plus nécessaire.

Notez que cette fonction peut retourner une chaîne de longueur zéro. Dans le contexte des Registres Windows, cela signifie que cette valeur est la clé par défaut pour ce nœud dans l'arbre. Ceci est généralement écrit sous la forme "@".

value_type
($type, $len) = $h->value_type ($val)

Retourne la longueur des données et le type de données de la valeur dans cette paire (clé, valeur). Voir également "value_value" qui retourne toutes ces informations, ainsi que la valeur elle-même. De plus, les fonctions "value_*" ci-dessous peuvent être utilisées pour retourner la valeur sous une forme plus utile lorsque vous connaissez le type à l'avance.

node_struct_length
$size = $h->node_struct_length ($node)

Retourne la longueur de la structure de nœud.

Retourne une taille.

NAME

Win::Hivex

interface to the Windows Registry hive format

SYNOPSIS

 use Win::Hivex;

 my $h = Win::Hivex->new ();
 my $h = Win::Hivex->open (filename);
 my $h = Win::Hivex->open_windows_registry ();
 my ($err, $errstr) = $h->open (filename);
 my ($err, $errstr) = $h->open_windows_registry ();

 my $root = $h->root
 my $node = $h->node_get_child ($parent, $name)
 my $node = $h->node_get_child_by_path ($parent, $path)
 my $node = $h->node_get_child_by_offset ($parent, $offset)
 my $parent = $h->node_parent ($node)
 my $name = $h->node_name ($node)
 my @children = $h->node_children ($node)
 my @values = $h->node_values ($node)
 my $key = $h->value_key ($val)
 my $type = $h->value_type ($val)
 my ($len, $value) = $h->value_data ($val)
 my $node = $h->value_node ($val)

 my $size = $h->node_struct_length ($node)
 my $size = $h->value_struct_length ($val)
 my ($len, $value) = $h->value_data_cell_offset ($val)
 my ($type, $data) = $h->value_value ($val)
 my $string = $h->value_string ($val)
 my @strings = $h->value_multiple_strings ($val)
 my $int32 = $h->value_dword ($val)
 my $int64 = $h->value_qword ($val)

 $h->commit ([$filename|undef])
 my $node = $h->node_add_child ($parent, $name)
 $h->node_delete_child ($node)
 $h->node_set_values ($node, \@values)
 $h->node_set_value ($node, $val)

DESCRIPTION

This module provides a Perl interface to the hivex library. Hivex is a library for accessing the Windows Registry hive files.

Use this module if you want to read or write Windows Registry files from within Perl.

ERRORS

The hivex library returns an error code on failure. If the error code is non-zero, then the Perl module throws an exception with the error message.

Some functions return an error code and an error string. These are returned as a list: ($err, $errstr). If the operation succeeds, then $err will be 0.

You can check the value of errno for some functions.

METHODS

new
$h = Win::Hivex->new ()

Create a new, empty hive object.

open
($err, $errstr) = $h->open (filename)

Open a registry hive file named filename.

If the operation fails, return an error code and error string.

open_windows_registry
($err, $errstr) = $h->open_windows_registry ()

Open the main Windows registry hive (usually located in C:\WINDOWS\System32\config\SOFTWARE or C:\WINDOWS\System32\config\SAM).

This only works if the code is running under Windows. On other platforms, it will fail.

If the operation fails, return an error code and error string.

root
$node = $h->root ()

Return the root node of the hive.

node_get_child
$node = $h->node_get_child ($parent, $name)

Return the child node named name of the node parent

node_get_child_by_path
$node = $h->node_get_child_by_path ($parent, $path)

Return the child node specified by the path pathparent/) as separators.

node_get_child_by_offset
$node = $h->node_get_child_by_offset ($parent, $offset)

Return the child node at the given byte offset within the hive file.

node_parent
$parent = $h->node_parent ($node)

Return the parent node of the given node.

node_name
$name = $h->node_name ($node)

Return the name of the given node.

node_children
@children = $h->node_children ($node)

Return a list of child nodes of the given node.

node_values
@values = $h->node_values ($node)

Return a list of values (key/value pairs) stored at the given node.

value_key
$key = $h->value_key ($val)

Return the key name of the given value.

value_type
$type = $h->value_type ($val)

Return the type of the given value. The type is an integer. See the "hive_type" constants in the C API.

value_data
($len, $data) = $h->value_data ($val)

Return the raw data of the value. This is returned as a scalar string. The length of the data is returned in $len.

value_node
$node = $h->value_node ($val)

Return the node which contains this value.

node_struct_length
$size = $h->node_struct_length ($node)

Return the length of the node data structure.

This returns a size.

value_struct_length
$size = $h->value_struct_length ($val)

Return the length of the value data structure.

This returns a size.

value_data_cell_offset
($len, $value) = $h->value_data_cell_offset ($val)

Return the offset and length of the value's data cell.

The data cell is a registry structure that contains the length (a 4 byte, little endian integer) followed by the data.

If the length of the value is less than or equal to 4 bytes then the offset and length returned by this function is zero as the data is inlined in the value.

Returns 0 and sets errno on error.

value_value
($type, $data) = $h->value_value ($val)

Return the value of this (key, value) pair. The value should be interpreted according to its type (see "hive_type").

value_string
$string = $h->value_string ($val)

If this value is a string, return the string reencoded as UTF-8 (as a C string). This only works for values which have type "hive_t_string", "hive_t_expand_string" or "hive_t_link".

value_multiple_strings
@strings = $h->value_multiple_strings ($val)

If this value is a multiple-string, return the strings reencoded as UTF-8 (in C, as a NULL-terminated array of C strings, in other language bindings, as a list of strings). This only works for values which have type "hive_t_multiple_strings".

value_dword
$int32 = $h->value_dword ($val)

If this value is a DWORD (Windows int32), return it. This only works for values which have type "hive_t_dword" or "hive_t_dword_be".

value_qword
$int64 = $h->value_qword ($val)

If this value is a QWORD (Windows int64), return it. This only works for values which have type "hive_t_qword".

commit
$h->commit ([$filename|undef])

Commit (write) any changes which have been made.

"filename" is the new file to write. If "filename" is null/undefined then we overwrite the original file (ie. the file name that was passed to "open").

Note this does not close the hive handle. You can perform further operations on the hive after committing, including making more modifications. If you no longer wish to use the hive, then you should close the handle after committing.

node_add_child
$node = $h->node_add_child ($parent, $name)

Add a new child node named "name" to the existing node "parent". The new child initially has no subnodes and contains no keys or values. The sk-record (security descriptor) is inherited from the parent.

The parent must not have an existing child called "name", so if you want to overwrite an existing child, call "node_delete_child" first.

This returns a node handle.

node_delete_child
$h->node_delete_child ($node)

Delete the node "node". All values at the node and all subnodes are deleted (recursively). The "node" handle and the handles of all subnodes become invalid. You cannot delete the root node.

node_set_values
$h->node_set_values ($node, \@values)

This call can be used to set all the (key, value) pairs stored in "node".

"node" is the node to modify.

@values is an array of (keys, value) pairs. Each element should be a hashref containing "key", "t" (type) and "data".

Any existing values stored at the node are discarded, and their "value" handles become invalid. Thus you can remove all values stored at "node" by passing "@values = []".

node_set_value
$h->node_set_value ($node, $val)

This call can be used to replace a single "(key, value)" pair stored in "node". If the key does not already exist, then a new key is added. Key matching is case insensitive.

"node" is the node to modify.
