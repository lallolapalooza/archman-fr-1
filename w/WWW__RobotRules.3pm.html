NOM

WWW::RobotRules - base de données des permissions dérivées de robots.txt

SYNOPSIS

use WWW::RobotRules;
my $rules = WWW::RobotRules->new('MOMspider/1.0');
use LWP::Simple qw(get);
{
  my $url = "http://some.place/robots.txt";
  my $robots_txt = get $url;
  $rules->parse($url, $robots_txt) if defined $robots_txt;
}
{
  my $url = "http://some.other.place/robots.txt";
  my $robots_txt = get $url;
  $rules->parse($url, $robots_txt) if defined $robots_txt;
}
# Nous pouvons maintenant vérifier si une URL est valide pour ces serveurs
# dont nous avons récupéré et analysé les fichiers "robots.txt" :
if($rules->allowed($url)) {
    $c = get $url;
    ...
}

DESCRIPTION

Ce module analyse les fichiers /robots.txt comme spécifié dans "A Standard for Robot Exclusion", à http://www.robotstxt.org/wc/norobots.html Les administrateurs de sites web peuvent utiliser le fichier /robots.txt pour interdire aux robots conformes d'accéder à des parties de leur site web.

Les fichiers analysés sont conservés dans un objet WWW::RobotRules, et cet objet fournit des méthodes pour vérifier si l'accès à une URL donnée est interdit. Le même objet WWW::RobotRules peut être utilisé pour un ou plusieurs fichiers /robots.txt analysés sur n'importe quel nombre d'hôtes.

Les méthodes suivantes sont fournies :

$rules = WWW::RobotRules->new($robot_name)
C'est le constructeur des objets WWW::RobotRules. Le premier argument passé à new() est le nom du robot.
$rules->parse($robot_txt_url, $content, $fresh_until)
La méthode parse() prend comme arguments l'URL utilisée pour récupérer le fichier /robots.txt, et le contenu du fichier.
$rules->allowed($uri)
Retourne TRUE si ce robot est autorisé à récupérer cette URL.
$rules->agent([$name])
Obtenir/définir le nom de l'agent. NOTE : Changer le nom de l'agent effacera les règles robots.txt et les temps d'expiration du cache.

ROBOTS.TXT

Le format et la sémantique du fichier "/robots.txt" sont les suivants (ceci est un extrait édité de http://www.robotstxt.org/wc/norobots.html) :

Le fichier se compose d'un ou plusieurs enregistrements séparés par une ou plusieurs lignes vides. Chaque enregistrement contient des lignes de la forme

<nom-champ>: <valeur>

Le nom du champ ne respecte pas la casse. Le texte après le caractère '#' sur une ligne est ignoré lors de l'analyse. Ceci est utilisé pour les commentaires. Les <nom-champ> suivants peuvent être utilisés :

User-Agent
La valeur de ce champ est le nom du robot pour lequel l'enregistrement décrit une politique d'accès. Si plusieurs champs User-Agent sont présents, l'enregistrement décrit une politique d'accès identique pour plusieurs robots. Au moins un champ doit être présent par enregistrement. Si la valeur est '*', l'enregistrement décrit la politique d'accès par défaut pour tout robot qui n'a pas correspondu à l'un des autres enregistrements.

Les champs User-Agent doivent apparaître avant les champs Disallow. Si un enregistrement contient un champ User-Agent après un champ Disallow, cela constitue un enregistrement mal formé. Ce parseur supposera qu'une ligne vide aurait dû être placée avant ce champ User-Agent, et divisera l'enregistrement en deux. Tous les champs avant le champ User-Agent constitueront un enregistrement, et le champ User-Agent sera le premier champ d'un nouvel enregistrement.

Disallow
La valeur de ce champ spécifie une partie d'URL qui ne doit pas être visitée. Cela peut être un chemin complet, ou un chemin partiel ; toute URL qui commence par cette valeur ne sera pas récupérée.

Les enregistrements non reconnus sont ignorés.

EXEMPLES ROBOTS.TXT

L'exemple de fichier "/robots.txt" suivant spécifie qu'aucun robot ne doit visiter d'URL commençant par "/cyberworld/map/" ou "/tmp/" :

User-agent: *
Disallow: /cyberworld/map/ # Ceci est un espace d'URL virtuel infini
Disallow: /tmp/ # ceux-ci disparaîtront bientôt

Cet exemple de fichier "/robots.txt" spécifie qu'aucun robot ne doit visiter d'URL commençant par "/cyberworld/map/", à l'exception du robot nommé "cybermapper" :

User-agent: *
Disallow: /cyberworld/map/ # Ceci est un espace d'URL virtuel infini
# Cybermapper sait où aller.
User-agent: cybermapper
Disallow:

Cet exemple indique qu'aucun robot ne doit visiter ce site davantage :

# partez
User-agent: *
Disallow: /

Voici un exemple de fichier robots.txt mal formé.

# robots.txt pour ancientcastle.example.com
# Je me suis enfermé.
User-agent: *
Disallow: /
# Le château est votre maison maintenant, vous pouvez donc aller où vous voulez.
User-agent: Belle
Disallow: /west-wing/ # sauf l'aile ouest !
# C'est bien d'être le Prince...
User-agent: Beast
Disallow:

Ce fichier manque des lignes vides requises entre les enregistrements. Cependant, l'intention est claire.
