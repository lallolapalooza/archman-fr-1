NOM

WMShell — La classe de widget WMShell

SYNTAXE

#include <Xm/Xm.h>
#include <X11/Shell.h>

DESCRIPTION

WMShell est un widget de haut niveau qui encapsule l'interaction avec le gestionnaire de fenêtres.

Classes

WMShell hérite des comportements et des ressources des classes Core, Composite et Shell.

Le pointeur de classe est wmShellWidgetClass.

Le nom de la classe est WMShell.

Nouvelles ressources

Le tableau suivant définit un ensemble de ressources de widget utilisées par le programmeur pour spécifier des données. Le programmeur peut également définir les valeurs des ressources pour les classes héritées afin de définir les attributs de ce widget. Pour faire référence à une ressource par son nom ou par sa classe dans un fichier .Xdefaults, supprimez le préfixe XmN ou XmC et utilisez les lettres restantes. Pour spécifier l'une des valeurs définies pour une ressource dans un fichier .Xdefaults, supprimez le préfixe Xm et utilisez les lettres restantes (en minuscules ou en majuscules, mais incluez les underscores entre les mots). Les codes dans la colonne d'accès indiquent si la ressource donnée peut être définie au moment de la création (C), définie en utilisant XtSetValues (S), récupérée en utilisant XtGetValues (G), ou n'est pas applicable (N/A).

XmNbaseHeight
Spécifie la base pour une progression des hauteurs préférées que le gestionnaire de fenêtres utilisera pour dimensionner le widget. Les hauteurs préférées sont XmNbaseHeight plus des multiples entiers de XmNheightInc, avec un minimum de XmNminHeight et un maximum de XmNmaxHeight. Si aucune valeur initiale n'est fournie pour XmNbaseHeight mais qu'elle est fournie pour XmNbaseWidth, la valeur de XmNbaseHeight est définie à 0 (zéro) lorsque le widget est réalisé.
XmNbaseWidth
Spécifie la base pour une progression des largeurs préférées que le gestionnaire de fenêtres utilisera pour dimensionner le widget. Les largeurs préférées sont XmNbaseWidth plus des multiples entiers de XmNwidthInc, avec un minimum de XmNminWidth et un maximum de XmNmaxWidth. Si aucune valeur initiale n'est fournie pour XmNbaseWidth mais qu'elle est fournie pour XmNbaseHeight, la valeur de XmNbaseWidth est définie à 0 (zéro) lorsque le widget est réalisé.
XmNheightInc
Spécifie l'incrément pour une progression des hauteurs préférées que le gestionnaire de fenêtres utilisera pour dimensionner le widget. Les hauteurs préférées sont XmNbaseHeight plus des multiples entiers de XmNheightInc, avec un minimum de XmNminHeight et un maximum de XmNmaxHeight. Si aucune valeur initiale n'est fournie pour XmNheightInc mais qu'elle est fournie pour XmNwidthInc, la valeur de XmNheightInc est définie à 1 lorsque le widget est réalisé.
XmNiconMask
Spécifie un bitmap qui pourrait être utilisé par le gestionnaire de fenêtres pour découper le bitmap XmNiconPixmap afin de rendre l'icône non rectangulaire.
XmNiconPixmap
Spécifie un bitmap qui pourrait être utilisé par le gestionnaire de fenêtres comme icône de l'application.
XmNiconWindow
Spécifie l'ID d'une fenêtre qui pourrait être utilisée par le gestionnaire de fenêtres comme icône de l'application.
XmNiconX
Spécifie un endroit approprié pour placer l'icône de l'application ; ceci est une indication pour le gestionnaire de fenêtres dans les coordonnées de la fenêtre racine. Comme le gestionnaire de fenêtres contrôle la politique de placement des icônes, cette ressource peut être ignorée.
XmNiconY
Spécifie un endroit approprié pour placer l'icône de l'application ; ceci est une indication pour le gestionnaire de fenêtres dans les coordonnées de la fenêtre racine. Comme le gestionnaire de fenêtres contrôle la politique de placement des icônes, cette ressource peut être ignorée.
XmNinitialState
Spécifie l'état dans lequel l'application souhaite que l'instance du widget démarre. Il doit s'agir de l'une des constantes NormalState ou IconicState.
XmNinput
Spécifie le modèle d'entrée de l'application pour ce widget et ses descendants. La signification d'une valeur Vrai ou Faux pour cette ressource dépend de la présence ou de l'absence d'un atome WM_TAKE_FOCUS dans la propriété WM_PROTOCOLS :

Passif True Absent
Actif localement True Présent

Pour plus d'informations sur les modèles d'entrée, consultez le document standard du Consortium X Inter-Client Communication Conventions Manual (ICCCM).

RESOURCES

WMShell provides the following resources:

XmNallowShellResize
Specifies whether the window manager can resize the widget instance. If this resource is True, the window manager can resize the widget. If it is False, the window manager cannot resize the widget. The default value is False.
XmNbaseHeight
Specifies the base height for a progression of preferred heights for the window manager to use in sizing the widget. The preferred heights are XmNbaseHeight plus integral multiples of XmNheightInc, with a minimum of XmNminHeight and a maximum of XmNmaxHeight. If an initial value is not supplied for XmNbaseHeight but is supplied for XmNbaseWidth, the value of XmNbaseHeight is set to 1 when the widget is realized.
XmNbaseWidth
Specifies the base width for a progression of preferred widths for the window manager to use in sizing the widget. The preferred widths are XmNbaseWidth plus integral multiples of XmNwidthInc, with a minimum of XmNminWidth and a maximum of XmNmaxWidth. If an initial value is not supplied for XmNbaseWidth but is supplied for XmNbaseHeight, the value of XmNbaseWidth is set to 1 when the widget is realized.
XmNcreatePopupChildProc
Specifies a procedure that is called when a popup shell is created. This procedure is responsible for creating the child widget for the popup shell. The default is NULL.
XmNfont
Specifies the font to be used for the widget. The default is the font of the parent widget.
XmNfontSet
Specifies the font set to be used for the widget. The default is the font set of the parent widget.
XmNgeometry
Specifies the initial geometry (size and position) of the widget instance. The format of the string is the same as that used by the xrdb resource manager. If a value is specified, the window manager may honor it. If the window manager does not honor the geometry specification, the widget may not be placed correctly. If the value is NULL, the widget is placed according to the window manager's conventions.
XmNheightInc
Specifies the increment for a progression of preferred heights for the window manager to use in sizing the widget. The preferred heights are XmNbaseHeight plus integral multiples of XmNheightInc, with a minimum of XmNminHeight and a maximum of XmNmaxHeight. If an initial value is not supplied for XmNheightInc but is supplied for XmNwidthInc, the value of XmNheightInc is set to 1 when the widget is realized.
XmNiconMask
Specifies the icon mask bitmap for the widget. The default is None.
XmNiconName
Specifies the icon name for the widget. The default is the widget's name.
XmNiconNameEncoding
Specifies a property type that represents the encoding of the XmNiconName string. If a language procedure has been set, the default is None; otherwise, the default is XA_STRING.
XmNinputCallback
Specifies a callback procedure that is invoked when the widget receives input. The default is NULL.
XmNinputNgrams
Specifies the input ngrams for the widget. The default is NULL.
XmNinputTranslations
Specifies the input translations for the widget. The default is NULL.
XmNkeyboardFocusPolicy
Specifies the keyboard focus policy for the widget. The possible values are XmEXPLICIT and XmIMPLICIT. The default value is XmEXPLICIT.
XmNmapCallback
Specifies a callback procedure that is invoked when the widget is mapped. The default is NULL.
XmNmaxAspectX
Specifies the numerator of the maximum aspect ratio (X/Y) that the application wants the widget instance to have.
XmNmaxAspectY
Specifies the denominator of the maximum aspect ratio (X/Y) that the application wants the widget instance to have.
XmNmaxHeight
Specifies the maximum height that the application wants the widget instance to have.
XmNmaxWidth
Specifies the maximum width that the application wants the widget instance to have.
XmNminAspectX
Specifies the numerator of the minimum aspect ratio (X/Y) that the application wants the widget instance to have.
XmNminAspectY
Specifies the denominator of the minimum aspect ratio (X/Y) that the application wants the widget instance to have.
XmNminHeight
Specifies the minimum height that the application wants the widget instance to have.
XmNminWidth
Specifies the minimum width that the application wants the widget instance to have.
XmNtitle
Specifies the application name to be displayed by the window manager. The default is the icon name, if specified; otherwise, it is the name of the application. When XtGetValues is called on this resource, the returned value is a pointer to the actual resource value and should not be freed.
XmNtitleEncoding
Specifies a property type that represents the encoding of the XmNtitle string. If a language procedure has been set, the default is None; otherwise, the default is XA_STRING. When the widget is realized, if the value is None, the corresponding name is assumed to be in the current locale. The name is passed to XmbTextListToTextProperty with an encoding style of XStdICCTextStyle. The resulting encoding is STRING if the name is fully convertible to STRING; otherwise it is COMPOUND_TEXT. The values of the encoding resources are not changed; they remain None.
XmNtransient
Specifies a Boolean value that is True if the widget instance is transient, typically a popup on behalf of another widget. The window manager may treat a transient widget's window differently from other windows. For example, a window manager may not iconify a transient window separately from its associated application. Applications and users should not normally alter this resource.
XmNwaitForWm
When True, specifies that the Intrinsics waits the length of time given by the XmNwmTimeout resource for the window manager to respond to certain actions before assuming that there is no window manager present. This resource is altered by the Intrinsics as it receives, or fails to receive, responses from the window manager.
XmNwidthInc
Specifies the base for a progression of preferred widths for the window manager to use in sizing the widget. The preferred widths are XmNbaseWidth plus integral multiples of XmNwidthInc, with a minimum of XmNminWidth and a maximum of XmNmaxWidth. If an initial value is not supplied for XmNwidthInc but is supplied for XmNheightInc, the value of XmNwidthInc is set to 1 when the widget is realized.
XmNwindowGroup
Specifies the ID of a window with which this widget instance is associated. By convention, this window is the "leader" of a group of windows. A window manager may treat all windows in a group in some way; for example, it may always move or iconify them together.
If no initial value is specified, the value is set to the window of the first realized ancestor widget in the parent hierarchy when the widget is realized. If a value of XtUnspecifiedWindowGroup is specified, no window group is set.
XmNwinGravity
Specifies the window gravity for use by the window manager in positioning the widget. If no initial value is specified, the value is set when the widget is realized. If XmNgeometry is not NULL, XmNwinGravity is set to the window gravity returned by XWMGeometry. Otherwise, XmNwinGravity is set to NorthWestGravity.
XmNwmTimeout
Specifies the length of time that the Intrinsics waits for the window manager to respond to certain actions before assuming that there is no window manager present. The value is in milliseconds and must not be negative.
