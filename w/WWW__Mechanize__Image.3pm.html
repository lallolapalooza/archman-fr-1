WWW::Mechanize::Image(3) Documentation Perl fournie par l'utilisateur WWW::Mechanize::Image(3)

NOM

WWW::Mechanize::Image - Objet image pour WWW::Mechanize

VERSION

version 2.20

SYNOPSIS

Objet image pour encapsuler toutes les informations dont Mech a besoin.

CONSTRUCTEUR

new()

Crée et retourne un nouvel objet "WWW::Mechanize::Image".

my $image = WWW::Mechanize::Image->new( {
    url    => $url,
    base   => $base,
    tag    => $tag,
    name   => $name,     # De la balise INPUT
    height => $height,   # optionnel
    width  => $width,    # optionnel
    alt    => $alt,      # optionnel
    attrs  => $attr_ref, # optionnel
} );

ACCESSEURS

$image->url()

URL de l'image provenant de l'attribut "src" de la balise source.

Peut être "undef" si la balise source n'a pas d'attribut "src".

$image->base()

URL de base à laquelle les liens sont relatifs.

$image->name()

Nom du champ provenant de l'attribut NAME, le cas échéant.

$image->tag()

Nom de la balise (soit "image" soit "input")

$image->height()

Hauteur de l'image.

$image->width()

Largeur de l'image.

$image->alt()

Attribut ALT de la balise source, le cas échéant.

$image->attrs()

Référence de hachage de tous les attributs et de leurs valeurs dans la balise.

$image->URI()

Retourne l'URL sous forme d'objet URI::URL.

$image->url_abs()

Retourne l'URL sous forme de chaîne d'URL absolue.

VOIR AUSSI

WWW::Mechanize et WWW::Mechanize::Link
