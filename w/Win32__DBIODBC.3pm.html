NOM

Win32::DBIODBC - Couche d'émulation Win32::ODBC pour le DBI

SYNOPIS

use Win32::DBIODBC;     # au lieu de use Win32::ODBC

DESCRIPTION

Ceci est une émulation de Win32::ODBC de qualité très basique et très alpha pour le DBI. Pour l'utiliser, remplacez simplement

use Win32::ODBC;

dans vos scripts par

use Win32::DBIODBC;

ou, lors d'expérimentations, vous pouvez précharger ce module sans modifier vos scripts en faisant

perl -MWin32::DBIODBC votre_nom_de_script

À FAIRE

La gestion des erreurs est pratiquement inexistante.
