INTRODUCTION

Tout d'abord, veuillez noter que beaucoup de ces actions sont possibles en utilisant simplement LWP::UserAgent. Comme "WWW::Mechanize" est une sous-classe de LWP::UserAgent, tout ce qui fonctionne sur "LWP::UserAgent" devrait fonctionner sur "WWW::Mechanize". Voir la page de manuel lwpcook incluse avec LWP.

BASES

Lancer le navigateur WWW::Mechanize

use WWW::Mechanize;
my $mech = WWW::Mechanize->new( autocheck => 1 );

L'option "autocheck => 1" indique à Mechanize de mourir si une opération d'E/S échoue, vous n'avez donc pas besoin de vérifier manuellement. C'est plus facile comme ça. Si vous voulez faire votre propre gestion des erreurs, omettez-la.

Récupérer une page

$mech->get( "http://search.cpan.org" );
print $mech->content;

"$mech->content" contient le HTML brut de la page web. Il n'est pas analysé ou traité de quelque manière que ce soit, du moins pas via la méthode "content".

Récupérer une page dans un fichier

Parfois, vous voulez enregistrer vos résultats directement dans un fichier. Par exemple, il n'y a aucune raison de charger un JPEG en mémoire si vous n'allez que l'écrire immédiatement. Cela peut également aider avec les problèmes de mémoire sur les fichiers volumineux.

$mech->get( "http://www.cpan.org/src/stable.tar.gz",
            ":content_file" => "stable.tar.gz" );

Récupérer une page protégée par mot de passe

Généralement, il suffit d'appeler "credentials" avant de récupérer la page.

$mech->credentials( 'admin' => 'password' );
$mech->get( 'http://10.11.12.13/password.html' );
print $mech->content();

LIENS

Trouver tous les liens d'images

Trouver tous les liens qui pointent vers un JPEG, GIF ou PNG.

my @links = $mech->find_all_links(
    tag => "a", url_regex => qr/\.(jpe?g|gif|png)$/i );

Trouver tous les liens de téléchargement

Trouver tous les liens qui contiennent le mot "download" (téléchargement).

my @links = $mech->find_all_links(
    tag => "a", text_regex => qr/\bdownload\b/i );

AVANCÉ

Voir ce qui sera envoyé sans réellement envoyer quoi que ce soit

$mech->add_handler("request_send", sub { shift->dump; exit; });
$mech->get("http://www.example.com");
