NOM

WildMidi_FastSeek - Se déplacer à une position dans un fichier midi

BIBLIOTHÈQUE

libWildMidi

SYNOPSIS

#include <wildmidi_lib.h>

int WildMidi_FastSeek (midi *handle, unsigned long int *sample_pos);

DESCRIPTION

Réinitialise tous les états midi spécifiques aux notes et les notes actives avant de scanner jusqu'à sample_pos échantillons à partir du début, en tenant compte de tout changement d'état des canaux midi. Le prochain appel à WildMidi_GetOutput(3) se comportera comme si vous aviez commencé à jouer le midi à partir de cette position.

handle
L'identifiant obtenu en ouvrant un fichier midi avec WildMidi_Open(3) ou WildMidi_OpenBuffer(3)
sample_pos
Le nombre d'échantillons à partir du début auquel vous souhaitez que libWildMidi se déplace.

NOTE : un délai important peut survenir lors de l'utilisation de cette fonction. Vous pouvez vous attendre à un délai encore plus important si vous sélectionnez une position qui a déjà été dépassée, forçant la bibliothèque à recommencer depuis le début.
