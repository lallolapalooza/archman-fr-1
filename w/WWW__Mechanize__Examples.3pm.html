NOM

WWW::Mechanize::Examples - Exemples de programmes utilisant WWW::Mechanize

VERSION

version 2.20

SYNOPSIS

Beaucoup de gens ont appris WWW::Mechanize, et maintenant, vous le pouvez aussi !

Vous trouverez ci-dessous des exemples fournis par les utilisateurs de WWW::Mechanize en action. Si vous avez des exemples que vous aimeriez contribuer, veuillez les envoyer à "<andy@petdance.com>".

Vous pouvez également consulter les fichiers t/*.t de la distribution.

Veuillez noter que ces exemples ne sont pas destinés à accomplir une tâche spécifique. Pour autant que je sache, ils ne fonctionnent plus car les sites qu'ils ont visités ont changé. Ils sont là pour donner des exemples de la manière dont les gens ont utilisé WWW::Mechanize.

Notez que les exemples sont présentés dans l'ordre inverse de leur réception, de sorte que les exemples les plus récents se trouvent toujours en haut.

Calculateur de densité Starbucks, par Nat Torkington

Voici une paire de programmes de Nat Torkington, éditeur pour O'Reilly Media et co-auteur du Perl Cookbook.

Rael [Dornfest] a découvert qu'on peut facilement savoir combien il y a de Starbucks dans une région en cherchant "Starbucks". J'ai donc écrit un petit scraper pour d'anciennes données de recensement et j'ai trouvé des chiffres de densité Starbucks. Ces chiffres n'ont aucune signification en raison des erreurs dues à l'utilisation d'anciennes données de recensement couplées à des faux positifs dans la recherche Yahoo (par exemple, "Dodie Starbuck-Your Style Desgn" à Portland OR). Mais c'était amusant d'y passer une nuit.

"get_pop_data"

#!/usr/bin/perl -w
use WWW::Mechanize;
use Storable;
$url = 'http://www.census.gov/population/www/documentation/twps0027.html';
$m = WWW::Mechanize->new();
$m->get($url);
$c = $m->content;
$c =~ m{<A NAME=.tabA.>(.*?)</TABLE>}s
  or die "Impossible de trouver le tableau de population\n";
$t = $1;
@outer = $t =~ m{<TR.*?>(.*?)</TR>}gs;
shift @outer;
foreach $r (@outer) {
  @bits = $r =~ m{<TD.*?>(.*?)</TD>}gs;
  for ($x = 0; $x < @bits; $x++) {
    $b = $bits[$x];
    @v = split /\s*<BR>\s*/, $b;
    foreach (@v) { s/^\s+//; s/\s+$// }
    push @{$data[$x]}, @v;
  }
}
for ($y = 0; $y < @{$data[0]}; $y++) {
    $data{$data[1][$y]} = {
        NAME => $data[1][$y],
        RANK => $data[0][$y],
        POP  => comma_free($data[2][$y]),
        AREA => comma_free($data[3][$y]),
        DENS => comma_free($data[4][$y]),
    };
}
store(\%data, "cities.dat");
sub comma_free {
  my $n = shift;
  $n =~ s/,//;
  return $n;
}

"plague_of_coffee"

#!/usr/bin/perl -w
use WWW::Mechanize;
use strict;
use Storable;
$SIG{__WARN__} = sub {} ;  # ssssssh
my $Cities = retrieve("cities.dat");
my $m = WWW::Mechanize->new();
$m->get("http://local.yahoo.com/");
my @cities = sort { $Cities->{$a}{RANK} <=> $Cities->{$b}{RANK} } keys %$Cities;
foreach my $c ( @cities ) {
  my $fields = {
    'stx' => "starbucks",
    'csz' => $c,
  };
  my $r = $m->submit_form(form_number => 2,
                          fields => $fields);
  die "Impossible de soumettre le formulaire" unless $r->is_success;
  my $hits = number_of_hits($r);
  #  my $ppl  = sprintf("%d", 1000 * $Cities->{$c}{POP} / $hits);
  #  print "$c a $hits Starbucks. C'est un pour $ppl personnes.\n";
  my $density = sprintf("%.1f", $Cities->{$c}{AREA} / $hits);
  print "$c : $density\n";
}
sub number_of_hits {
  my $r = shift;
  my $c = $r->content;
  if ($c =~ m{\d+ sur <b>(\d+)</b> résultats totaux pour}) {
    return $1;
  }
  if ($c =~ m{Désolé, aucun .*? trouvé}) {
    return 0;
  }
  if ($c =~ m{Votre recherche a trouvé plusieurs villes}) {
    warn "Votre recherche a trouvé plusieurs villes\n";
    return 0;
  }
  if ($c =~ m{Désolé, nous n'avons pas pu trouver cet endroit}) {
    warn "Aucune ville\n";
    return 0;
  }
  if ($c =~ m{Impossible de trouver.*?, affichage des résultats pour}) {
    warn "Aucune correspondance\n";
    return 0;
  }
  die "Réponse inconnue\n$c\n";
}

pb-upload, par John Beppu

Ce programme prend des noms de fichiers d'images en ligne de commande et les télécharge sur un dossier www.photobucket.com. John Beppu, l'auteur, dit :

J'avais 92 photos à télécharger, et le faire via un navigateur aurait été un supplice. Mais grâce à mech, tout ce que j'ai eu à faire, c'est `./pb.upload *.jpg` et le regarder faire son travail. C'était une bonne sensation. Si j'avais plus de temps, j'implémenterais WWW::Photobucket au-dessus de WWW::Mechanize.
#!/usr/bin/perl -w
use strict;
use WWW::Mechanize;
my $login    = "nom_connexion";
my $password = "mot_de_passe";
my $folder   = "dossier";
my $url = "http://img78.photobucket.com/albums/v281/$login/$folder/";
# se connecter à votre compte photobucket.com
my $mech = WWW::Mechanize->new();
$mech->get($url);
$mech->submit_form(
    form_number => 1,
    fields      => { password => $password },
);
die unless ($mech->success);
# télécharger les fichiers image spécifiés en ligne de commande
foreach (@ARGV) {
    print "$_\n";
    $mech->form_number(2);
    $mech->field('the_file[]' => $_);
    $mech->submit();
}

listmod, par Ian Langworth

Ian Langworth apporte ce petit bijou qui apportera de la joie aux administrateurs de listes de diffusion désespérés. Il écarte les messages de spam via l'interface web de mailman.

#!/arch/unix/bin/perl
use strict;
use warnings;
#
# listmod - alternative rapide à l'interface de liste mailman
#
# usage: listmod crew XXXXXXXX
#
die "usage: $0 <nom_liste> <mot_de_passe>\n" unless @ARGV == 2;
my ($listname, $password) = @ARGV;
use CGI qw(unescape);
use WWW::Mechanize;
my $m = WWW::Mechanize->new( autocheck => 1 );
use Term::ReadLine;
my $term = Term::ReadLine->new($0);
# soumettre le formulaire, obtenir le cookie, aller à la page d'administration de la liste
$m->get("https://lists.ccs.neu.edu/bin/admindb/$listname");
$m->set_visible( $password );
$m->click;
# quitter si rien à faire
print "Il n'y a pas de requêtes en attente.\n" and exit
    if $m->content =~ /Il n'y a pas de requêtes en attente/;
# sélectionner le premier formulaire et examiner son contenu
$m->form_number(1);
my $f = $m->current_form or die "Impossible d'obtenir le premier formulaire !\n";
# obtenir l'élément de formulaire de base pour chaque élément de courriel
my @items = map {m/^.+?-(.+)/} grep {m/senderbanp/} $f->param
    or die "Impossible d'obtenir les éléments du premier formulaire !\n";
# itérer sur les éléments, demander à l'utilisateur, valider les actions
foreach my $item (@items) {
    # afficher les informations de l'élément
    my $sender = unescape($item);
    my ($subject) = [$f->find_input("senderbanp-$item")->value_names]->[1]
        =~ /Subject:\s+(.+?)\s+Size:/g;
    # demander à l'utilisateur
    my $choice = '';
    while ( $choice !~ /^[DAX]$/ ) {
        print "$sender\: '$subject'\n";
        $choice = uc $term->readline("Action: différer/accepter/rejeter [dax]: ");
        print "\n\n";
    }
    # définir le bouton
    $m->field("senderaction-$item" => {D=>0,A=>1,X=>3}->{$choice});
}
# soumettre les actions
$m->click;

ccdl, par Andy Lester

Steve McConnell, auteur du landmark Code Complete, a mis en ligne les chapitres de la 2ème édition en format PDF sur son site web. J'avais besoin de les télécharger pour les faire imprimer chez Kinko's.
Ce petit programme l'a fait pour moi.

#!/usr/bin/perl -w
use strict;
use WWW::Mechanize;
my $start = "http://www.stevemcconnell.com/cc2/cc.htm";
my $mech = WWW::Mechanize->new( autocheck => 1 );
$mech->get( $start );
my @links = $mech->find_all_links( url_regex => qr/\d+.+\.pdf$/ );
for my $link ( @links ) {
    my $url = $link->url_abs;
    my $filename = $url;
    $filename =~ s[^.+/][];
    print "Téléchargement de $url"
; $mech->get( $url, ':content_file' => $filename ); print " ", -s $filename, " octets\n"; }

quotes.pl, par Andy Lester

C'était un programme qui allait obtenir un hack dans Spidering Hacks, mais qui a été coupé à la dernière minute, probablement parce que l'extraction de données à partir d'IMDB va à l'encontre de ses conditions d'utilisation. Je le présente ici comme un exemple, pas comme une suggestion de violer leurs conditions d'utilisation.

Au mieux de mes souvenirs, il ne fonctionnait plus parce que leur HTML ne correspondait plus, mais il reste un bon exemple de code.

#!/usr/bin/perl -w
use strict;
use WWW::Mechanize;
use Getopt::Long;
use Text::Wrap;
my $match = undef;
my $random = undef;
GetOptions(
    "match=s" => \$match,
    "random" => \$random,
) or exit 1;
my $movie = shift @ARGV or die "Il faut spécifier un film\n";
my $quotes_page = get_quotes_page( $movie );
my @quotes = extract_quotes( $quotes_page );
if ( $match ) {
    $match = quotemeta($match);
    @quotes = grep /$match/i, @quotes;
}
if ( $random ) {
    print $quotes[rand @quotes];
}
else {
    print join( "\n", @quotes );
}
sub get_quotes_page {
    my $movie = shift;
    my $mech = WWW::Mechanize->new;
    $mech->get( "http://www.imdb.com/search" );
    $mech->success or die "Impossible d'obtenir la page de recherche";
    $mech->submit_form(
        form_number => 2,
        fields => {
            title   => $movie,
            restrict    => "Films uniquement",
        },
    );
    my @links = $mech->find_all_links( url_regex => qr[^/Title] )
        or die "Aucun résultat pour \"$movie\" n'a été trouvé.\n";
    # Utiliser le premier lien
    my ( $url, $title ) = @{$links[0]};
    warn "Vérification de $title...\n";
    $mech->get( $url );
    my $link = $mech->find_link( text_regex => qr/Citations mémorables/i )
        or die qq{"$title" n'a pas de citations sur IMDB !\n};
    warn "Récupération des citations...\n\n";
    $mech->get( $link->[0] );
    return $mech->content;
}
sub extract_quotes {
    my $page = shift;
    # Supprimer le contenu indésirable du début...
    $page =~ s/.+Citations mémorables//si;
    $page =~ s/.+?(<a name)/$1/si;
    # ...et de la fin de la page
    $page =~ s/Parcourir les titres dans les citations de films.+$//si;
    $page =~ s/<p.+$//g;
    # Citations séparées par une balise <HR>
    my @quotes = split( /<hr.+?>/, $page );
    for my $quote ( @quotes ) {
        my @lines = split( /<br>/, $quote );
        for ( @lines ) {
            s/<[^>]+>//g;   # Supprimer les balises HTML
            s/\s+/ /g;          # Compacter les espaces blancs
            s/^ //;     # Supprimer l'espace en début de ligne
            s/ $//;     # Supprimer l'espace en fin de ligne
            s/&#34;/"/g;    # Remplacer les entités HTML des guillemets
            # Retour à la ligne automatique pour s'adapter à 72 colonnes
            $Text::Wrap::columns = 72;
            $_ = wrap( '', '    ', $_ );
        }
        $quote = join( "\n", @lines );
    }
    return @quotes;
}

cpansearch.pl, par Ed Silva

Un petit utilitaire rapide pour rechercher sur CPAN et lancer un navigateur avec une page de résultats.

#!/usr/bin/perl
# activer les fonctionnalités de sécurité de perl
use strict;
use warnings;
# déterminer le nom du module que nous recherchons
my $module_name = $ARGV[0]
  or die "Il faut spécifier le nom du module sur la ligne de commande";
# créer un nouveau navigateur
use WWW::Mechanize;
my $browser = WWW::Mechanize->new();
# lui demander d'obtenir la page principale
$browser->get("http://search.cpan.org/");
# ok, remplir la boîte avec le nom du
# module que nous voulons rechercher
$browser->form_number(1);
$browser->field("query", $module_name);
$browser->click();
# cliquer sur le lien qui correspond au nom du module
$browser->follow_link( text_regex => $module_name );
my $url = $browser->uri;
# lancer un navigateur...
system('galeon', $url);
exit(0);

Hacking Movable Type, par Dan Rinzel

use strict;
use WWW::Mechanize;
# un outil pour poster automatiquement des entrées sur un weblog movable type, et définir des dates de création arbitraires
my $mech = WWW::Mechanize->new();
my $entry;
$entry->{title} = "Titre d'entrée automatique de test";
$entry->{btext} = "Corps d'entrée automatique de test";
$entry->{date} = '2002-04-15 14:18:00';
my $start = qq|http://mon.site.de.blog/mt.cgi|;
$mech->get($start);
$mech->field('username','und3f1n3d');
$mech->field('password','obscur3d');
$mech->submit(); # pour obtenir le cookie de connexion
$mech->get(qq|$start?__mode=view&_type=entry&blog_id=1|);
$mech->form_name('entry_form');
$mech->field('title',$entry->{title});
$mech->field('category_id',1); # ajuster si nécessaire
$mech->field('text',$entry->{btext});
$mech->field('status',2); # publier, ou 1 = brouillon
$results = $mech->submit();
# si nous sommes d'accord pour que cette entrée soit horodatée "MAINTENANT" (pas de {date} dans %entry)
# nous avons terminé. Sinon, il est temps d'être astucieux
# MT retourne une redirection 302 à partir de ce formulaire. la redirection elle-même contient un gestionnaire dans <body onload="">
# qui emmène l'utilisateur vers une version modifiable du formulaire où la date de création peut être modifiée
# le format de date MT de AAAA-MM-JJ HH:MI:SS est le seul qui ne produira pas d'erreur
if ($entry->{date} && $entry->{date} =~ /^\d{4}-\d{2}-\d{2}\s+\d{2}:\d{2}:\d{2}/) {
    # suivre la redirection
    $results = $mech->get($results->{_headers}->{location});
    $results->{_content} =~ /<body onLoad="([^\"]+)"/is;
    my $js = $1;
    $js =~ /\'([^']+)\'/;
    $results = $mech->get($start.$1);
    $mech->form_name('entry_form');
    $mech->field('created_on_manual',$entry->{date});
    $mech->submit();
}

get-despair, par Randal Schwartz

Randal a soumis ce bot qui parcourt le site despair.com en téléchargeant toutes les images.

use strict;
$|++;
use WWW::Mechanize;
use File::Basename;
my $m = WWW::Mechanize->new;
$m->get("http://www.despair.com/indem.html");
my @top_links = @{$m->links};
for my $top_link_num (0..$#top_links) {
    next unless $top_links[$top_link_num][0] =~ /^http:/;
    $m->follow_link( n=>$top_link_num ) or die "impossible de suivre $top_link_num";
    print $m->uri, "\n";
    for my $image (grep m{^http://store4}, map $_->[0], @{$m->links}) {
        my $local = basename $image;
        print " $image...", $m->mirror($image, $local)->message, "\n"
    }
    $m->back or die "impossible de revenir en arrière";
}
