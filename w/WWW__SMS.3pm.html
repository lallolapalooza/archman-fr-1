WWW::SMS(3) Documentation Perl fournie par l'utilisateur WWW::SMS(3)

NOM

WWW::SMS - envoie des SMS via un service fourni par des sites web gratuits

SYNOPIS

use WWW::SMS;
my $sms = WWW::SMS->new(
    '39',                # préfixe international
    '333',               # préfixe opérateur
    '1234567',           # numéro de téléphone
    'Ceci est un test.', # texte du message
    username => 'abcde', # paramètres optionnels
    passwd => 'edcba'    # sous forme de hachage
);
# ou maintenant même juste
my $sms = WWW::SMS->new($numéro_entier, $texte_sms);

for ( $sms->gateways(sorted => 'reliability') ) {
                               # pour chaque passerelle compatible
    if ($sms->send( $_ ) {     # essayer d'envoyer le sms
        last;                  # jusqu'à ce que cela réussisse
    } else {
        print $WWW::SMS:Error; # voici l'erreur
    }
}

DESCRIPTION

WWW::SMS est un framework Perl pour envoyer des SMS gratuits via le web.

Un nouvel objet WWW::SMS doit être créé avec la méthode new. Une fois créé, vous pouvez l'envoyer via l'un des sous-modules disponibles.

WWW::SMS->new(PREFXINT, PREFXOP, NUMTEL, TEXTEMSG [, OPTIONS]);
WWW::SMS->new(NUMEROTOTAL, TEXTEMSG [, OPTIONS]);
C'est le constructeur par défaut de l'objet SMS.

"PREFXINT" est le préfixe international : certaines passerelles n'utilisent tout simplement pas le préfixe international, mais mettez quelque chose ici quand même.

"PREFXOP" est le préfixe de l'opérateur

"NUMTEL" pas grand chose à dire

"NUMEROTOTAL" le constructeur alternatif utilise le numéro complet de votre téléphone portable : il inclut le préfixe international et le préfixe opérateur. Il repose sur la base de données de Telephone::Number pour diviser votre numéro en ses 3 parties de base. Donc, en cas de doute, utilisez simplement le constructeur « numéro de téléphone en trois parties ».

"TEXTEMSG" même ici, pas grand chose à dire. Les sous-modules vont couper le SMS à la longueur maximale autorisée par l'opérateur. Vous pouvez vérifier la longueur maximale en recherchant la constante MAXLENGTH dans les sous-modules.

"OPTIONS" sont passées sous forme de hachage. Les options utiles à définir incluent

"proxy" votre proxy HTTP

"cookie_jar" Le fichier où stocker les cookies. S'il n'est pas défini, chaque cookie va dans le fichier "lwpcookies.txt" dans votre répertoire de travail.

"username" et "passwd" Utilisés par les passerelles basées sur l'enregistrement

D'autres paramètres peuvent être requis par des sous-modules spécifiques.

MÉTHODES

$sms->send("PASSERELLE")
Envoie $sms en utilisant "PASSERELLE" : retourne 1 en cas de succès, 0 en cas d'erreur. La dernière erreur se trouve dans la variable $WWW::SMS::Error.

"PASSERELLE" la passerelle que vous souhaitez utiliser pour envoyer le SMS : doit être un scalaire.

gateways([OPTIONS])
Scanne les répertoires @INC et retourne un TABLEAU contenant les noms des sous-modules de passerelle disponibles. S'il est utilisé sur un objet SMS, la liste des sous-modules retournée est filtrée par la capacité de PRÉFIXE. Comme ceci : 
WWW::SMS->gateways(); # retourne toutes les passerelles disponibles
$sms->gateways(); # retourne uniquement les passerelles qui peuvent envoyer $sms
# passerelles compatibles triées par fiabilité
$sms->gateways(sorted => 'reliability');

DIRECTIVES POUR LES SOUS-MODULES

Alors, vous avez WWW::SMS mais quelle est la suite ? Eh bien, tout ce qui est cool à ce sujet réside dans les sous-modules. Un sous-module doit faire le sale boulot de récupérer et d'envoyer des pages web. Comment écrire un sous-module alors ? Il y a quelques points à observer :

1 Regardez d'abord les sous-modules fournis en exemple !
Oui, copier-coller la structure d'un sous-module est un bon point de départ.
2 sub MAXLENGTH
Veuillez définir la constante EXPORTABLE "MAXLENGTH" à la longueur maximale de SMS que la passerelle pour laquelle vous écrivez le script autorise.
3 @PREFIXES
@PREFIXES doit être un tableau d'objets "Telephone::Number". "Telephone::Number"->new prend 3 paramètres : chacun peut être un scalaire ou une référence d'array. Chaque scalaire ou élément des tableaux référencés est une expression régulière. Le code vérifiera que le numéro de téléphone correspond à au moins une des expressions régulières pour chaque champ de préfixe international, préfixe et numéro de téléphone. Si vous n'avez pas d'expression régulière pour l'un de ces champs, donnez simplement undef à "Telephone::Number"->new. Regardez les autres sous-modules pour mieux vous décider.
4 Étapes et $WWW::SMS::Error
Effectuez des GET et POST comme vous le souhaitez, en utilisant d'autres sous-modules comme vous le désirez. Rappelez-vous simplement de marquer chaque GET ou POST avec un numéro d'étape croissant. Et lorsque vous rencontrez une erreur, veuillez définir la variable d'erreur $WWW::SMS::Error à quelque chose d'utile et y inclure le numéro de l'étape, afin que le débogage soit plus facile. Ensuite, retournez 0. Si tout se passe bien, retournez 1.
5 Soumettez votre module à la communauté !
C'est important, car avoir un grand nombre de passerelles fonctionnelles est difficile (les sites web changent très rapidement), donc tout le monde devrait partager sa nouvelle et cool implémentation de sous-module. Merci.
