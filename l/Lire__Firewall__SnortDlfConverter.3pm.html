NOM

Lire::Firewall::SnortDlfConverter - convertir les logs Snort en DLF de pare-feu

DESCRIPTION

Lire::Firewall::SnortDlfConverter convertit les logs Snort au format DLF de pare-feu. L'entrée pour ce convertisseur est le fichier log standard de Snort.

VOIR AUSSI

Le site web du projet Snort à http://www.snort.org/ .

AUTEUR

Code basé sur le code snort2dlf de Torsten Fellhauer <torsten@fellhauer-web.de>.
