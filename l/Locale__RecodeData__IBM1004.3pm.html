NOM

Locale::RecodeData::IBM1004 - Routines de conversion pour IBM1004

SYNTHAXE

Ce module est interne à libintl. Ne l'utilisez pas directement !

DESCRIPTION

Ce module est généré et contient les tables de conversion et les routines pour IBM1004.

COMMENTAIRES

Les commentaires suivants ont été extraits de la table de caractères originale :

version : 1.0
 source : CEN/TC304 N283, 1994-02-04
 alias CP1004
 alias OS2LATIN1

Note : les alias mentionnés ci-dessus ne sont pas nécessairement valides !

NAME


Locale::RecodeData::IBM1004 - Perl module for codepage IBM1004.






SYNOPSIS


 use Locale::RecodeData::IBM1004;






DESCRIPTION


This module provides the codepage IBM-1004.
