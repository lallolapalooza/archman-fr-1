DESCRIPTION

Ces macros définissent et manipulent quatre types de structures de données qui peuvent être utilisées aussi bien en code source C qu'en code source C++ :

  1. Listes
  2. Listes chaînées simples
  3. Files d'attente chaînées simples avec queue
  4. Files d'attente chaînées avec queue
Les quatre structures supportent la fonctionnalité suivante :
  1. Insertion d'une nouvelle entrée en tête de liste.
  2. Insertion d'une nouvelle entrée après n'importe quel élément de la liste.
  3. Suppression en temps O(1) d'une entrée de la tête de la liste.
  4. Parcours avant dans la liste.
  5. Échange du contenu de deux listes.

Les listes chaînées simples sont les plus simples des quatre structures de données et ne supportent que la fonctionnalité ci-dessus. Les listes chaînées simples sont idéales pour les applications avec de grands ensembles de données et peu ou pas de suppressions, ou pour implémenter une file LIFO (dernier entré, premier sorti). Les listes chaînées simples ajoutent la fonctionnalité suivante :

  1. Suppression en temps O(n) de n'importe quelle entrée de la liste.
  2. Concaténation en temps O(n) de deux listes.

Les files d'attente chaînées simples avec queue ajoutent la fonctionnalité suivante :

  1. Des entrées peuvent être ajoutées à la fin d'une liste.
  2. Suppression en temps O(n) de n'importe quelle entrée de la liste.
  3. Elles peuvent être concaténées.
Cependant :
  1. Toutes les insertions de liste doivent spécifier la tête de la liste.
  2. Chaque entrée de tête nécessite deux pointeurs plutôt qu'un seul.
  3. La taille du code est environ 15% plus grande et les opérations sont environ 20% plus lentes que pour les listes chaînées simples.

Les files d'attente chaînées simples avec queue sont idéales pour les applications avec de grands ensembles de données et peu ou pas de suppressions, ou pour implémenter une file FIFO (premier entré, premier sorti).

Tous les types de structures de données doublement chaînées (listes et files d'attente avec queue) permettent en outre :

  1. Insertion d'une nouvelle entrée avant n'importe quel élément de la liste.
  2. Suppression en temps O(1) de n'importe quelle entrée de la liste.
Cependant :
  1. Chaque élément nécessite deux pointeurs plutôt qu'un seul.
  2. La taille du code et le temps d'exécution des opérations (à l'exception de la suppression) sont environ le double de ceux des structures de données chaînées simples.

Les listes chaînées sont les plus simples des structures de données doublement chaînées. Elles ajoutent la fonctionnalité suivante par rapport à ce qui précède :

  1. Concaténation en temps O(n) de deux listes.
  2. Elles peuvent être parcourues en arrière.
Cependant :
  1. Pour parcourir en arrière, une entrée pour commencer le parcours et la liste dans laquelle elle est contenue doivent être spécifiées.

Les files d'attente avec queue ajoutent la fonctionnalité suivante :

  1. Des entrées peuvent être ajoutées à la fin d'une liste.
  2. Elles peuvent être parcourues en arrière, de la queue à la tête.
  3. Elles peuvent être concaténées.
Cependant :
  1. Toutes les insertions et suppressions de liste doivent spécifier la tête de la liste.
  2. Chaque entrée de tête nécessite deux pointeurs plutôt qu'un seul.
  3. La taille du code est environ 15% plus grande et les opérations sont environ 20% plus lentes que pour les listes chaînées simples.

Dans les définitions de macros, TYPE est le nom d'une structure définie par l'utilisateur. La structure doit contenir un champ nommé NAME qui est de type SLIST_ENTRY, STAILQ_ENTRY, LIST_ENTRY, ou TAILQ_ENTRY. Dans les définitions de macros, CLASSTYPE est le nom d'une classe définie par l'utilisateur. La classe doit contenir un champ nommé NAME qui est de type SLIST_CLASS_ENTRY, STAILQ_CLASS_ENTRY, LIST_CLASS_ENTRY, ou TAILQ_CLASS_ENTRY. L'argument HEADNAME est le nom d'une structure définie par l'utilisateur qui doit être déclarée en utilisant les macros SLIST_HEAD, SLIST_CLASS_HEAD, STAILQ_HEAD, STAILQ_CLASS_HEAD, LIST_HEAD, LIST_CLASS_HEAD, TAILQ_HEAD, ou TAILQ_CLASS_HEAD. Voir les exemples ci-dessous pour plus d'explications sur la manière dont ces macros sont utilisées.

LISTES CHAÎNÉES SIMPLES

Une liste chaînée simple est dirigée par une structure définie par la macro SLIST_HEAD. Cette structure contient un seul pointeur vers le premier élément de la liste. Les éléments sont chaînés simplement pour un minimum d'espace et de surcharge de manipulation de pointeurs, au détriment d'une suppression en O(n) pour les éléments arbitraires. De nouveaux éléments peuvent être ajoutés à la liste après un élément existant ou en tête de liste. Une structure SLIST_HEAD est déclarée comme suit :

SLIST_HEAD(HEADNAME, TYPE) head;

où HEADNAME est le nom de la structure à définir, et TYPE est le type des éléments à chaîner dans la liste. Un pointeur vers la tête de la liste peut être déclaré plus tard comme suit :

struct HEADNAME *headp;

(Les noms head et headp sont sélectionnables par l'utilisateur.)

La macro SLIST_HEAD_INITIALIZER est évaluée comme un initialiseur pour la liste head.

La macro SLIST_CONCAT concatène la liste dirigée par head2 à la fin de celle dirigée par head1, en supprimant toutes les entrées de la première. L'utilisation de cette macro doit être évitée car elle parcourt la totalité de la liste head1. Une file d'attente chaînée simple avec queue doit être utilisée si cette macro est nécessaire dans des chemins de code à forte utilisation ou pour opérer sur de longues listes.

La macro SLIST_EMPTY est évaluée à vrai s'il n'y a aucun élément dans la liste.

La macro SLIST_ENTRY déclare une structure qui relie les éléments de la liste.

La macro SLIST_FIRST renvoie le premier élément de la liste ou NULL si la liste est vide.

La macro SLIST_FOREACH parcourt la liste référencée par head dans le sens avant, assignant chaque élément successivement à var.

La macro SLIST_FOREACH_FROM se comporte de manière identique à SLIST_FOREACH lorsque var est NULL, sinon elle traite var comme un élément SLIST trouvé précédemment et commence la boucle à var au lieu du premier élément de la SLIST référencée par head.

La macro SLIST_FOREACH_SAFE parcourt la liste référencée par head dans le sens avant, assignant chaque élément successivement à var. Cependant, contrairement à SLIST_FOREACH(), ici il est permis de supprimer var ainsi que de le libérer de la boucle en toute sécurité sans interférer avec le parcours.

La macro SLIST_FOREACH_FROM_SAFE se comporte de manière identique à SLIST_FOREACH_SAFE lorsque var est NULL, sinon elle traite var comme un élément SLIST trouvé précédemment et commence la boucle à var au lieu du premier élément de la SLIST référencée par head.

La macro SLIST_INIT initialise la liste référencée par head.

La macro SLIST_INSERT_HEAD insère le nouvel élément elm en tête de liste.

La macro SLIST_INSERT_AFTER insère le nouvel élément elm après l'élément

s="Fa">listelm.

La macro SLIST_NEXT retourne l'élément suivant dans la liste.

La macro SLIST_REMOVE_AFTER supprime l'élément qui suit elm de la liste. Contrairement à SLIST_REMOVE, cette macro ne parcourt pas toute la liste.

La macro SLIST_REMOVE_HEAD supprime l'élément elm de la tête de la liste. Pour une efficacité optimale, les éléments supprimés de la tête de la liste doivent utiliser explicitement cette macro plutôt que la macro générique SLIST_REMOVE.

La macro SLIST_REMOVE supprime l'élément elm de la liste. L'utilisation de cette macro doit être évitée car elle parcourt toute la liste. Une liste doublement chaînée doit être utilisée si cette macro est nécessaire dans des chemins de code à usage intensif ou pour opérer sur de longues listes.

La macro SLIST_SWAP échange le contenu de head1 et head2.

EXEMPLE DE LISTE SIMPLEMENT CHAÎNÉE

SLIST_HEAD(slisthead, entry) head =
    SLIST_HEAD_INITIALIZER(head);
struct slisthead *headp;		/* Tête de liste simplement chaînée. */
struct entry {
	...
	SLIST_ENTRY(entry) entries;	/* Liste simplement chaînée. */
	...
} *n1, *n2, *n3, *np;

SLIST_INIT(&head);			/* Initialiser la liste. */

n1 = malloc(sizeof(struct entry));	/* Insérer en tête. */
SLIST_INSERT_HEAD(&head, n1, entries);

n2 = malloc(sizeof(struct entry));	/* Insérer après. */
SLIST_INSERT_AFTER(n1, n2, entries);

SLIST_REMOVE(&head, n2, entry, entries);/* Suppression. */
free(n2);

n3 = SLIST_FIRST(&head);
SLIST_REMOVE_HEAD(&head, entries);	/* Suppression de la tête. */
free(n3);
					/* Parcours avant. */
SLIST_FOREACH(np, &head, entries)
	np-> ...
					/* Parcours avant sûr. */
SLIST_FOREACH_SAFE(np, &head, entries, np_temp) {
	np->do_stuff();
	...
	SLIST_REMOVE(&head, np, entry, entries);
	free(np);
}

while (!SLIST_EMPTY(&head)) {		/* Suppression de la liste. */
	n1 = SLIST_FIRST(&head);
	SLIST_REMOVE_HEAD(&head, entries);
	free(n1);
}

FILES D'ATTENTE SIMPLEMENT CHAÎNÉES

Une file d'attente simplement chaînée est dirigée par une structure définie par la macro STAILQ_HEAD. Cette structure contient une paire de pointeurs, l'un vers le premier élément de la file d'attente et l'autre vers le dernier élément de la file d'attente. Les éléments sont chaînés simplement pour un minimum d'espace et de manipulation de pointeurs, au détriment d'une suppression en O(n) pour les éléments arbitraires. De nouveaux éléments peuvent être ajoutés à la file d'attente après un élément existant, en tête de la file d'attente, ou à la fin de la file d'attente. Une structure STAILQ_HEAD est déclarée comme suit :

STAILQ_HEAD(HEADNAME, TYPE) head;

où HEADNAME est le nom de la structure à définir, et TYPE est le type des éléments à lier dans la file d'attente. Un pointeur vers la tête de la file d'attente peut ensuite être déclaré comme suit :

struct HEADNAME *headp;

(Les noms head et headp sont sélectionnables par l'utilisateur.)

La macro STAILQ_HEAD_INITIALIZER évalue à un initialiseur pour la file d'attente head.

La macro STAILQ_CONCAT concatène la file d'attente dirigée par head2 à la fin de celle dirigée par head1, supprimant toutes les entrées de la première.

La macro STAILQ_EMPTY évalue à vrai s'il n'y a pas d'éléments dans la file d'attente.

La macro STAILQ_ENTRY déclare une structure qui relie les éléments dans la file d'attente.

La macro STAILQ_FIRST retourne le premier élément de la file d'attente ou NULL si la file d'attente est vide.

La macro STAILQ_FOREACH parcourt la file d'attente référencée par head dans le sens avant, assignant chaque élément successivement à var.

La macro STAILQ_FOREACH_FROM se comporte identiquement à STAILQ_FOREACH lorsque var est NULL, sinon elle traite var comme un élément STAILQ précédemment trouvé et commence la boucle à var au lieu du premier élément dans la STAILQ référencée par head.

La macro STAILQ_FOREACH_SAFE parcourt la file d'attente référencée par head dans le sens avant, assignant chaque élément successivement à var. Cependant, contrairement à STAILQ_FOREACH(), il est permis ici de supprimer var ainsi que de le libérer de l'intérieur de la boucle en toute sécurité sans interférer avec le parcours.

La macro STAILQ_FOREACH_FROM_SAFE se comporte identiquement à STAILQ_FOREACH_SAFE lorsque var est NULL, sinon elle traite var comme un élément STAILQ précédemment trouvé et commence la boucle à var au lieu du premier élément dans la STAILQ référencée par head.

La macro STAILQ_INIT initialise la file d'attente référencée par head.

La macro STAILQ_INSERT_HEAD insère le nouvel élément elm en tête de la file d'attente.

La macro STAILQ_INSERT_TAIL insère le nouvel élément elm à la fin de la file d'attente.

La macro STAILQ_INSERT_AFTER insère le nouvel élément elm après l'élément listelm.

La macro STAILQ_LAST retourne le dernier élément de la file d'attente. Si la file d'attente est vide, la valeur retournée est NULL.

La macro STAILQ_NEXT retourne le prochain élément de la file d'attente, ou NULL si cet élément est le dernier.

La macro STAILQ_REMOVE_AFTER supprime l'élément qui suit elm de la file d'attente. Contrairement à STAILQ_REMOVE, cette macro ne parcourt pas toute la file d'attente.

La macro STAILQ_REMOVE_HEAD supprime l'élément en tête de la file d'attente. Pour une efficacité optimale, les éléments supprimés de la tête de la file d'attente doivent utiliser explicitement cette macro plutôt que la macro générique STAILQ_REMOVE.

La macro STAILQ_REMOVE supprime l'élément elm de la file d'attente. L'utilisation de cette macro doit être évitée car elle parcourt toute la liste. Une file d'attente doublement chaînée doit être utilisée si cette macro est nécessaire dans des chemins de code à usage intensif ou pour opérer sur de longues files d'attente.

La macro STAILQ_SWAP échange le contenu de head1 et head2.

EXEMPLE DE FILE D'ATTENTE SIMPLEMENT CHAÎNÉE

STAILQ_HEAD(stailhead, entry) head =
    STAILQ_HEAD_INITIALIZER(head);
struct stailhead *headp;		/* Tête de file d'attente simplement chaînée. */
struct entry {
	...
	STAILQ_ENTRY(entry) entries;	/* File d'attente. */
	...
} *n1, *n2, *n3, *np;

STAILQ_INIT(&head);			/* Initialiser la file. */

n1 = malloc(sizeof(struct entry));	/* Insérer en tête. */
STAILQ_INSERT_HEAD(&head, n1, entries);

n1 = malloc(sizeof(struct entry));	/* Insérer à la queue. */
STAILQ_INSERT_TAIL(&head, n1, entries);

n2 = malloc(sizeof(struct entry));	/* Insérer après. */
STAILQ_INSERT_AFTER(&head, n1, n2, entries);
					/* Suppression. */
STAILQ_REMOVE(&head, n2, entry, entries);
free(n2);
					/* Suppression de la tête. */
n3 = STAILQ_FIRST(&head);
STAILQ_REMOVE_HEAD(&head, entries);
free(n3);
					/* Parcours avant. */
STAILQ_FOREACH(np, &head, entries)
	np-> ...
					/* Parcours avant sûr. */
STAILQ_FOREACH_SAFE(np, &head, entries, np_temp) {
	np->do_stuff();
	...
	STAILQ_REMOVE(&head, np, entry, entries);
	free(np);
}
					/* Suppression de TailQ. */
while (!STAILQ_EMPTY(&head)) {
	n1 = STAILQ_FIRST(&head);
	STAILQ_REMOVE_HEAD(&head, entries);
	free(n1);
}
					/* Suppression plus rapide de TailQ. */
n1 = STAILQ_FIRST(&head);
while (n1 != NULL) {
	n2 = STAILQ_NEXT(n1, entries);
	free(n1);
	n1 = n2;
}
STAILQ_INIT(&head);

LISTES

Une liste est dirigée par une structure définie par la macro LIST_HEAD. Cette structure contient un seul pointeur vers le premier élément de la liste. Les éléments sont doublement chaînés de sorte qu'un élément arbitraire puisse être supprimé sans parcourir la liste. De nouveaux éléments peuvent être ajoutés à la liste après un élément existant, avant un élément existant, ou en tête de la liste. Une structure LIST_HEAD est déclarée comme suit :

LIST_HEAD(HEADNAME, TYPE) head;

où HEADNAME est le nom de la structure à définir, et TYPE est le type des éléments à lier dans la liste. Un pointeur vers la tête de la liste peut ensuite être déclaré comme suit :

struct HEADNAME *headp;

(Les noms head et headp sont sélectionnables par l'utilisateur.)

La macro LIST_HEAD_INITIALIZER évalue à un initialiseur pour la liste head.

La macro LIST_CONCAT concatène la liste dirigée par head2 à la fin de celle dirigée par head1, supprimant toutes les entrées de la première. L'utilisation de cette macro doit être évitée car elle parcourt la totalité de la liste head1. Une file d'attente doit être utilisée si cette macro est nécessaire dans des chemins de code à usage intensif ou pour opérer sur de longues listes.

La macro LIST_EMPTY évalue à vrai s'il n'y a aucun élément dans la liste.

La macro LIST_ENTRY déclare une structure qui relie les éléments dans la liste.

La macro LIST_FIRST retourne le premier élément de la liste ou NULL si la liste est vide.

La macro LIST_FOREACH parcourt la liste référencée par head /var> en la dirección forward, asignando cada elemento en su vez a var.

El macro LIST_FOREACH_FROM comporta identicamente a LIST_FOREACH cuando var es NULL, else trata var como un elemento previamente encontrado en la lista referida a head y empieza el bucle desde var en lugar del primer elemento de la lista referida a head.

El macro LIST_FOREACH_SAFE recorre la lista referida a head en la dirección forward, asignando cada elemento en su vez a var. Sin embargo, a diferencia de LIST_FOREACH() aquí es permitido tanto eliminar var como liberar de manera segura de dentro del bucle sin interferir con la travesía.

El macro LIST_FOREACH_FROM_SAFE comporta identicamente a LIST_FOREACH_SAFE cuando var es NULL, else trata var como un elemento previamente encontrado en la lista referida a head y empieza el bucle desde var en lugar del primer elemento de la lista referida a head.

El macro LIST_INIT inicializa la lista referida a head.

El macro LIST_INSERT_HEAD inserta el nuevo elemento elm al principio de la lista.

El macro LIST_INSERT_AFTER inserta el nuevo elemento elm después del elemento listelm.

El macro LIST_INSERT_BEFORE inserta el nuevo elemento elm antes del elemento listelm.

El macro LIST_NEXT devuelve el siguiente elemento en la lista, o NULL si este es el último.

El macro LIST_PREV devuelve el elemento anterior en la lista, o NULL si este es el primero. La lista head debe contener el elemento elm.

El macro LIST_REMOVE elimina el elemento elm de la lista.

El macro LIST_SWAP intercambia el contenido de head1 y head2.

LIST EXAMPLE

LIST_HEAD(listhead, entry) head =
    LIST_HEAD_INITIALIZER(head);
struct listhead *headp;			/* List head. */
struct entry {
	...
	LIST_ENTRY(entry) entries;	/* List. */
	...
} *n1, *n2, *n3, *np, *np_temp;

LIST_INIT(&head);			/* Initialize the list. */

n1 = malloc(sizeof(struct entry));	/* Insert at the head. */
LIST_INSERT_HEAD(&head, n1, entries);

n2 = malloc(sizeof(struct entry));	/* Insert after. */
LIST_INSERT_AFTER(n1, n2, entries);

n3 = malloc(sizeof(struct entry));	/* Insert before. */
LIST_INSERT_BEFORE(n2, n3, entries);

LIST_REMOVE(n2, entries);		/* Deletion. */
free(n2);
					/* Forward traversal. */
LIST_FOREACH(np, &head, entries)
	np-> ...

					/* Safe forward traversal. */
LIST_FOREACH_SAFE(np, &head, entries, np_temp) {
	np->do_stuff();
	...
	LIST_REMOVE(np, entries);
	free(np);
}

while (!LIST_EMPTY(&head)) {		/* List Deletion. */
	n1 = LIST_FIRST(&head);
	LIST_REMOVE(n1, entries);
	free(n1);
}

while (n1 != NULL) {
	n2 = LIST_NEXT(n1, entries);
	free(n1);

}

TAIL QUEUES

Una cola de cola se define por la macro TAILQ_HEAD. Esta estructura contiene un par de punteros, uno al primer elemento en la cola de cola y otro al último elemento en la cola de cola. Los elementos están vinculados de forma doble, de modo que un elemento arbitrario puede ser eliminado sin recorrer la cola de cola. Los elementos nuevos pueden ser agregados a la cola de cola después de un elemento existente, antes de un elemento existente, al principio de la cola de cola, o al final de la cola de cola. Una estructura TAILQ_HEAD se declara así:

TAILQ_HEAD(HEADNAME, TYPE) head;

donde HEADNAME es el nombre de la estructura a definir y TYPE es el tipo de los elementos vinculados en la cola de cola. Un puntero al cabeza de la cola de cola puede ser posteriormente declarado así:

struct HEADNAME *headp;

(Los nombres head y headp son seleccionables por el usuario.)

La macro TAILQ_HEAD_INITIALIZER evalúa a un inicializador para la cola de cola head.

La macro TAILQ_CONCAT concatená la cola de cola dirigida por head2 en la cola de cola dirigida por head1, eliminando todos los elementos de la anterior.

La macro TAILQ_EMPTY evalúa a verdadero si no hay elementos en la cola de cola.

La macro TAILQ_ENTRY declara una estructura que conecta los elementos de la cola de cola.

La macro TAILQ_FIRST devuelve el primer elemento en la cola de cola o NULL si la cola de cola está vacía.

La macro TAILQ_FOREACH recorre la cola de cola referida a head en la dirección forward, asignando cada elemento en su vez a var. var es establecido a NULL si el bucle termina normally, o si no hay elementos.

La macro TAILQ_FOREACH_FROM comporta identicamente a TAILQ_FOREACH cuando var es NULL, else trata var como un elemento previamente encontrado en la cola de cola y empieza el bucle desde var en lugar del primer elemento de la cola de cola referida a head.

La macro TAILQ_FOREACH_REVERSE recorre la cola de cola referida a head en la dirección reverse, asignando cada elemento en su vez a var.

La macro TAILQ_FOREACH_REVERSE_FROM comporta identicamente a TAILQ_FOREACH_REVERSE cuando var es NULL, else trata var como un elemento previamente encontrado en la cola de cola y empieza el bucle en reversa desde var en lugar del último elemento de la cola de cola referida a head.

Las macros TAILQ_FOREACH_SAFE y TAILQ_FOREACH_REVERSE_SAFE recorren la lista referida a head en la dirección forward o reverse respectivamente, asignando cada elemento en su vez a var. Sin embargo, a diferencia de sus contrapartes inseguras, TAILQ_FOREACH y TAILQ_FOREACH_REVERSE permiten eliminar var y liberar de manera segura de dentro del bucle sin interferir con la travesía.

La macro TAILQ_FOREACH_FROM_SAFE comporta identicamente a TAILQ_FOREACH_SAFE cuando var es NULL, else trata var como un elemento previamente encontrado en la cola de cola y empieza el bucle desde var en lugar del primer elemento de la cola de cola referida a head.

La macro TAILQ_FOREACH_REVERSE_FROM_SAFE comporta identicamente a TAILQ_FOREACH_REVERSE_SAFE cuando var es NULL, else trata var como un elemento previamente encontrado en la cola de cola y empieza el bucle en reversa desde var en lugar del último elemento de la cola de cola referida a head.

La macro TAILQ_INIT inicializa la cola de cola referida a head.

La macro TAILQ_INSERT_HEAD inserta el nuevo elemento elm al principio de la cola de cola.

La macro TAILQ_INSERT_TAIL inserta el nuevo elemento elm al final de la cola de cola.

La macro TAILQ_INSERT_AFTER inserta el nuevo elemento elm después del elemento listelm.

La macro TAILQ_INSERT_BEFORE inserta el nuevo elemento elm antes del elemento listelm.

La macro TAILQ_LAST devuelve el último elemento en la cola de cola. Si la cola de cola está vacía, el valor devuelto es NULL.

La macro TAILQ_NEXT devuelve el siguiente elemento en la cola de cola, o NULL si este es el último.

La macro TAILQ_PREV devuelve el elemento anterior en la cola de cola, o NULL si este es el primero.

La macro TAILQ_REMOVE elimina el elemento elm de la cola de cola.

La macro TAILQ_SWAP intercambia el contenido de head1 y head2.

DIAGNOSTICS

Lorsque vous déboguez queue(3), il peut être utile de suivre les modifications de la file d'attente. Pour activer le traçage, définissez la macro QUEUE_MACRO_DEBUG_TRACE lors de la compilation.

Il peut également être utile de collecter les pointeurs qui ont été détachés d'une file d'attente, afin de détecter une utilisation après suppression. Pour activer la collecte des pointeurs, définissez la macro QUEUE_MACRO_DEBUG_TRASH lors de la compilation. La macro QMD_IS_TRASHED(void *ptr) renvoie vrai si ptr a été collecté par l'option QUEUE_MACRO_DEBUG_TRASH.
