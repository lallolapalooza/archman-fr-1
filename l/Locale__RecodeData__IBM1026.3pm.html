NOM

Locale::RecodeData::IBM1026 - Routines de conversion pour IBM1026

SYNTAXE

Ce module est interne à libintl. Ne l'utilisez pas directement !

DESCRIPTION

Ce module contient les tables de conversion et les routines pour IBM1026.

COMMENTAIRES

Les commentaires suivants ont été extraits de la charmap d'origine :

version: 1.0
 source: IBM NLS RM Vol2 SE09-8002-01, March 1990
 alias CP1026
 alias 1026

Note : les alias mentionnés ci-dessus ne sont pas nécessairement valides !
