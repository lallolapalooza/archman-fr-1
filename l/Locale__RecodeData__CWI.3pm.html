NOM

Locale::RecodeData::CWI - Routines de conversion pour CWI

SYNOPSIS

Ce module est interne à libintl. Ne pas l'utiliser directement !

DESCRIPTION

Ce module est généré et contient les tables et routines de conversion pour CWI.

COMMENTAIRES

Les commentaires suivants ont été extraits de la charmap originale :

version: 1.0
 source: Computerworld Sza'mita'stechnika vol 3 issue 13 1988-06-29
alias CWI-2
alias CP-HU

Veuillez noter que les alias listés ci-dessus ne sont pas nécessairement valides !
