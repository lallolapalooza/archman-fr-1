NOM

Lire::DlfAnalyser - Interface de base pour tous les analyseurs DLF.

SYNOPSIS

use base qw/ Lire::DlfAnalyser /;

DESCRIPTION

Ce paquet définit l'interface qui doit être implémentée par tous les Analyseurs DLF. Toutes les méthodes définies dans ce paquet lanceront une exception de type « méthode non implémentée » si elles sont appelées.

Les analyseurs qui produisent des enregistrements DLF pour un schéma étendu devraient probablement utiliser l'interface plus simple Lire::DlfCategoriser.

MÉTHODES MÉTA INFORMATION

Ces méthodes fournissent des informations au framework Lire sur les analyseurs DLF.

L'interface Lire::DlfAnalyser étend l'interface Lire::Plugin, donc elle doit implémenter toutes les méthodes standard de méta-information (name(), title(), description()).

src_schema()

Retourne le schéma DLF qui est analysé par cet analyseur.

Exemple : "www"

dst_schema()

Retourne le schéma DLF qui est produit par cet analyseur.

Exemple : "www-user_session"

MÉTHODE IMPLÉMENTATION

L'analyseur fait son travail en utilisant la méthode analyse().

analyse( $process, $config )

Le paramètre $process contient l'objet Lire::DlfAnalyserProcess qui contrôle le processus de conversion.

Le paramètre $config contient les données de configuration qui ont été spécifiées dans l'AnalysisJob pour ce convertisseur. Pour enregistrer une spécification de configuration pour votre DlfAnalyser, il vous suffit de définir une spécification de configuration sous le nom analyser_name_properties. Il devrait s'agir d'un RecordSpec ou d'un ObjectSpec.

VOIR AUSSI

Lire::DlfAnalyserProcess(3pm), Lire::DlfStore(3pm), Lire::PluginManager(3pm), Lire::DlfCategoriser(3pm).
