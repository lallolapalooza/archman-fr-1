NOM

Lire::Report::Group - Objet incluant des sous-groupes et d'autres entrées.

SYNTAXE

foreach my $e ( $group->entries() ) {
    # Traiter les données des entrées.
}

DESCRIPTION

L'objet Lire::Report::Group contient des entrées regroupées dans un sous-rapport.

CONSTRUCTEUR

Vous créez un nouvel objet Lire::Report::Group en appelant la méthode create_group() sur un objet Lire::Report::Entry.

MÉTHODES OBJET

parent_entry()

Retourne l'entrée dans laquelle ce groupe est contenu. Ce sera undef pour le sous-rapport car il n'est contenu dans aucune entrée.

group_info()

Retourne le Lire::Report::GroupInfo qui contient les informations décrivant les entrées de ce groupe.

subreport()

Retourne l'objet Lire::Report::Subreport dans lequel cette entrée se trouve.

row_idx()

Retourne l'indice de ligne dans le corps du tableau où le résumé de ce groupe doit être affiché. S'il est undef, ce groupe n'est pas affiché.

show( [$show] )

Retourne le nombre d'entrées qui doivent être affichées dans le rapport formaté. Il peut y avoir plus d'entrées que cela dans le groupe. Lorsque ce paramètre est zéro ou indéfini, toutes les entrées disponibles doivent être affichées.

Si le paramètre $show est défini, le paramètre show du groupe sera défini à cette nouvelle valeur.

nrecords( [$n] )

Retourne le nombre d'enregistrements DLF qui ont été inclus dans ce groupe.

missing_cases( [$n] )

Retourne le nombre d'enregistrements DLF qui contenaient des cas manquants, empêchant leur inclusion dans le sous-rapport.

summary_values()

Retourne les valeurs résumées de ce groupe. C'est un tableau de références de hachage comme ceux retournés par la méthode values() décrite dans Lire::Report::Entry(3pm).

get_summary_value( $name )

Retourne la valeur résumée de l'opérateur $name. C'est une référence de hachage comme celle retournée par la méthode values() décrite dans Lire::Report::Entry(3pm). Retourne undef si la valeur résumée n'a pas été calculée pour l'opérateur $name.

set_summary_value( $name, %value )

Définit la valeur de l'opérateur $name calculée sur tous les enregistrements DLF du groupe. Consultez la méthode add_value() dans Lire::Report::Entry(3pm) pour des informations sur les paramètres.

entries()

Retourne les entrées dans le groupe.

create_entry()

Ajoute une entrée de données à ce groupe. Cela créera un nouvel objet Lire::Report::Entry qui pourra ensuite être rempli de données.

find_entry( $name, $dlf )
