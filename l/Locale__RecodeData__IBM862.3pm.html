NAME

Locale::RecodeData::IBM862 - Fonctions de conversion pour IBM862

SYNOPSIS

Ce module est interne à libintl. Ne l'utilisez pas directement !

DESCRIPTION

Ce module est généré automatiquement et contient les tables et routines de conversion pour IBM862.

COMMENTS

Les commentaires suivants ont été extraits de la charmap originale :

version: 1.0
 source: IBM NLS RM Vol2 SE09-8002-01, March 1990
alias CP862
alias 862

Note : Les alias mentionnés ci-dessus ne sont pas nécessairement valides !
