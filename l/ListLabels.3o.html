Module ListLabels
: sig end

Opérations sur les listes.

Certaines fonctions sont marquées comme non récursives en pile. Une fonction récursive en pile utilise un espace constant sur la pile, tandis qu'une fonction non récursive en pile utilise un espace proportionnel à la longueur de son argument liste, ce qui peut poser problème avec des listes très longues. Lorsque plusieurs arguments liste sont passés, une formule approximative donnant l'utilisation de la pile (dans une unité constante quelconque) est indiquée entre parenthèses.

Ces considérations sont généralement ignorées si vos listes ne dépassent pas environ 10000 éléments.

La version étiquetée de ce module peut être utilisée comme décrit dans le module StdLabels.

type 'a list =
| []
| :: of 'a * 'a list

Un alias pour le type des listes.

val length : 'a list -> int

Retourne la longueur (nombre d'éléments) de la liste donnée.

val compare_lengths : 'a list -> 'b list -> int

Compare les longueurs de deux listes. compare_lengths l1 l2 est équivalent à compare (length l1) (length l2), sauf que le calcul s'arrête après avoir atteint la fin de la liste la plus courte.

Depuis 4.05

val compare_length_with : 'a list -> len:int -> int

Compare la longueur d'une liste à un entier. compare_length_with l len est équivalent à compare (length l) len, sauf que le calcul s'arrête après au moins len itérations dans la liste.

Depuis 4.05

val is_empty : 'a list -> bool

is_empty l est vrai si et seulement si l ne contient aucun élément. C'est équivalent à compare_length_with l 0 = 0.

Depuis 5.1

val cons : 'a -> 'a list -> 'a list

cons x xs est x :: xs

Depuis 4.05

val singleton : 'a -> 'a list

singleton x retourne la liste d'un seul élément [x].

Depuis 5.4

val hd : 'a list -> 'a

Retourne le premier élément de la liste donnée.

Lève Failure si la liste est vide.

val tl : 'a list -> 'a list

Retourne la liste donnée sans son premier élément.

Lève Failure si la liste est vide.

val nth : 'a list -> int -> 'a

Retourne le n-ième élément de la liste donnée. Le premier élément (tête de la liste) est à la position 0.

Lève Failure si la liste est trop courte.

Lève Invalid_argument si n est négatif.

val nth_opt : 'a list -> int -> 'a option

Retourne le n-ième élément de la liste donnée. Le premier élément (tête de la liste) est à la position 0. Retourne None si la liste est trop courte.

Depuis 4.05

Lève Invalid_argument si n est négatif.

val rev : 'a list -> 'a list

Inverse la liste.

val init : len:int -> f:(int -> 'a) -> 'a list

init ~len ~f est [f 0; f 1; ...; f (len-1)], évalué de gauche à droite.

Depuis 4.06

Lève Invalid_argument si len < 0.

val append : 'a list -> 'a list -> 'a list

append l0 l1 annexe l1 à l0. La même fonction que l'opérateur de concaténation @.

Depuis 5.1 cette fonction est récursive en pile.

val rev_append : 'a list -> 'a list -> 'a list

rev_append l1 l2 inverse l1 et l'annexe à l2. Ceci est équivalent à (ListLabels.rev l1) @ l2.

val concat : 'a list list -> 'a list

Concatène une liste de listes. Les éléments de l'argument sont tous concaténés ensemble (dans le même ordre) pour produire le résultat. N'est pas récursive en pile (longueur de l'argument + longueur de la sous-liste la plus longue).

val flatten : 'a list list -> 'a list

C'est la même chose que ListLabels.concat. N'est pas récursive en pile (longueur de l'argument + longueur de la sous-liste la plus longue).

Comparaison

val equal : eq:('a -> 'a -> bool) -> 'a list -> 'a list -> bool

equal eq [a1; ...; an] [b1; ..; bm] est vrai lorsque les deux listes d'entrée ont la même longueur, et pour chaque paire d'éléments ai, bi à la même position, on a eq ai bi.

Note : la fonction eq peut être appelée même si les listes ont des longueurs différentes. Si vous savez que votre fonction d'égalité est coûteuse, vous pourriez vouloir vérifier ListLabels.compare_lengths au préalable.

Depuis 4.12

val compare : cmp:('a -> 'a -> int) -> 'a list -> 'a list -> int

compare cmp [a1; ...; an] [b1; ...; bm] effectue une comparaison lexicographique des deux listes d'entrée, en utilisant la même interface 'a -> 'a -> int que compare :

- a1 :: l1 est plus petit que a2 :: l2 (résultat négatif) si a1 est plus petit que a2, ou s'ils sont égaux (résultat zéro) et l1 est plus petit que l2. - La liste vide [] est plus petite que les listes non vides.

Note : la fonction cmp sera appelée même si les listes ont des longueurs différentes.

Itérateurs

val iter : f:('a -> unit) -> 'a list -> unit

iter ~f [a1; ...; an] applique la fonction f dans l'ordre à [a1; ...; an]. C'est équivalent à f a1; f a2; ...; f an.

val iteri : f:(int -> 'a -> unit) -> 'a list -> unit

C'est la même chose que ListLabels.iter, mais la fonction est appliquée à l'indice de l'élément comme premier argument (en commençant par 0), et à l'élément comme second argument.

Depuis 4.00

val map : f:('a -> 'b) -> 'a list -> 'b list

map ~f [a1; ...; an] applique la fonction f à a1, ..., an et construit la liste [f a1; ...; f an] avec les résultats retournés par f.

val mapi : f:(int -> 'a -> 'b) -> 'a list -> 'b list

C'est la même chose que ListLabels.map, mais la fonction est appliquée à l'indice de l'élément comme premier argument (en commençant par 0), et à l'élément comme second argument.

Depuis 4.00

val rev_map : f:('a -> 'b) -> 'a list -> 'b list

rev_map ~f l donne le même résultat que ListLabels.rev (ListLabels.map f l), mais est plus efficace.

val filter_map : f:('a -> 'b option) -> 'a list -> 'b list

filter_map ~f l applique f à chaque élément de l, filtre les éléments None et retourne la liste des arguments des éléments Some.

Depuis 4.08

val concat_map : f:('a -> 'b list) -> 'a list -> 'b list

concat_map ~f l donne le même résultat que ListLabels.concat (ListLabels.map f l), est récursive en pile.

Itérateurs sur deux listes

val iter2 : f:('a -> 'b -> unit) -> 'a list -> 'b list -> unit

iter2 ~f [a1; ...; an] [b1; ...; bn] appelle successivement f a1 b1; ...; f an bn .

Raises Invalid_argument si les deux listes sont de longueurs différentes.

val map2 : f:('a -> 'b -> 'c) -> 'a list -> 'b list -> 'c list

map2 ~f [a1; ...; an] [b1; ...; bn] vaut [f a1 b1; ...; f an bn].

Raises Invalid_argument si les deux listes sont de longueurs différentes.

val rev_map2 : f:('a -> 'b -> 'c) -> 'a list -> 'b list -> 'c list

rev_map2 ~f l1 l2 donne le même résultat que ListLabels.rev ( ListLabels.map2 f l1 l2) , mais est plus efficace.

val fold_left2 : f:('acc -> 'a -> 'b -> 'acc) -> init:'acc -> 'a list -> 'b list -> 'acc

fold_left2 ~f ~init [a1; ...; an] [b1; ...; bn] vaut f (... (f (f init a1 b1) a2 b2) ...) an bn.

Raises Invalid_argument si les deux listes sont de longueurs différentes.

val fold_right2 : f:('a -> 'b -> 'acc -> 'acc) -> 'a list -> 'b list -> init:'acc -> 'acc

fold_right2 ~f [a1; ...; an] [b1; ...; bn] ~init vaut f a1 b1 (f a2 b2 (... (f an bn init) ...)).

Raises Invalid_argument si les deux listes sont de longueurs différentes. Pas récursif terminal.

Balayage de listes

val for_all : f:('a -> bool) -> 'a list -> bool

for_all ~f [a1; ...; an] vérifie si tous les éléments de la liste satisfont le prédicat f . C'est-à-dire, cela retourne (f a1) && (f a2) && ... && (f an) pour une liste non vide et true si la liste est vide.

val exists : f:('a -> bool) -> 'a list -> bool

exists ~f [a1; ...; an] vérifie si au moins un élément de la liste satisfait le prédicat f . C'est-à-dire, cela retourne (f a1) || (f a2) || ... || (f an) pour une liste non vide et false si la liste est vide.

val for_all2 : f:('a -> 'b -> bool) -> 'a list -> 'b list -> bool

Identique à ListLabels.for_all , mais pour un prédicat à deux arguments.

Raises Invalid_argument si les deux listes sont de longueurs différentes.

val exists2 : f:('a -> 'b -> bool) -> 'a list -> 'b list -> bool

Identique à ListLabels.exists , mais pour un prédicat à deux arguments.

Raises Invalid_argument si les deux listes sont de longueurs différentes.

val mem : 'a -> set:'a list -> bool

mem a ~set est vrai si et seulement si a est égal à un élément de set .

val memq : 'a -> set:'a list -> bool

Identique à ListLabels.mem , mais utilise l'égalité physique au lieu de l'égalité structurelle pour comparer les éléments de la liste.

Recherche dans une liste

val find : f:('a -> bool) -> 'a list -> 'a

find ~f l retourne le premier élément de la liste l qui satisfait le prédicat f .

Raises Not_found s'il n'y a aucune valeur satisfaisant f dans la liste l .

val find_opt : f:('a -> bool) -> 'a list -> 'a option

find ~f l retourne le premier élément de la liste l qui satisfait le prédicat f . Retourne None s'il n'y a aucune valeur satisfaisant f dans la liste l .

Since 4.05

val find_index : f:('a -> bool) -> 'a list -> int option

find_index ~f xs retourne Some i , où i est l'index du premier élément de la liste xs qui satisfait f x , s'il existe un tel élément.

Il retourne None s'il n'existe aucun élément de ce type.

Since 5.1

val find_map : f:('a -> 'b option) -> 'a list -> 'b option

find_map ~f l applique f aux éléments de l dans l'ordre, et retourne le premier résultat de la forme Some v , ou None si aucun n'existe.

Since 4.10

val find_mapi : f:(int -> 'a -> 'b option) -> 'a list -> 'b option

Identique à find_map , mais le prédicat est appliqué à l'index de l'élément comme premier argument (en commençant à 0), et à l'élément lui-même comme second argument.

Since 5.1

val filter : f:('a -> bool) -> 'a list -> 'a list

filter ~f l retourne tous les éléments de la liste l qui satisfont le prédicat f . L'ordre des éléments dans la liste d'entrée est préservé.

val find_all : f:('a -> bool) -> 'a list -> 'a list

find_all est un autre nom pour ListLabels.filter .

val filteri : f:(int -> 'a -> bool) -> 'a list -> 'a list

Identique à ListLabels.filter , mais le prédicat est appliqué à l'index de l'élément comme premier argument (en commençant à 0), et à l'élément lui-même comme second argument.

Since 4.11

Manipulation de listes

val take : int -> 'a list -> 'a list

take n l retourne le préfixe de l de longueur n , ou une copie de l si n > length l . C'est la liste vide si n est négatif.

Attention. Dans la version 5.3 uniquement, cette fonction lève Invalid_argument pour les valeurs négatives de n.

Since 5.3

val drop : int -> 'a list -> 'a list

drop n l retourne le suffixe de l après n éléments, ou [] si n > length l . C'est l si n est négatif.

Attention. Dans la version 5.3 uniquement, cette fonction lève Invalid_argument pour les valeurs négatives de n.

Since 5.3

val take_while : f:('a -> bool) -> 'a list -> 'a list

take_while p l est le plus long préfixe (possiblement vide) de l contenant uniquement des éléments qui satisfont p .

Since 5.3

val drop_while : f:('a -> bool) -> 'a list -> 'a list

drop_while p l est le plus long suffixe (possiblement vide) de l commençant au premier élément qui ne satisfait pas p .

Since 5.3

val partition : f:('a -> bool) -> 'a list -> 'a list * 'a list

partition ~f l retourne une paire de listes (l1, l2) , où l1 est la liste de tous les éléments de l qui satisfont le prédicat f , et l2 est la liste de tous les éléments de l qui ne satisfont pas f . L'ordre des éléments dans la liste d'entrée est préservé.

val partition_map : f:('a -> ('b, 'c) Either.t) -> 'a list -> 'b list * 'c list

partition_map f l retourne une paire de listes (l1, l2) telle que, pour chaque élément x de la liste d'entrée l :

- si f x est Left y1 , alors y1 est dans l1 , et

- si f x est Right y2 , alors y2 est dans l2.

Les éléments de sortie sont inclus dans l1 et l2 dans le même ordre relatif que les éléments d'entrée correspondants dans l .

En particulier, partition_map (fun x -> if f x then Left x else Right x) l est équivalent à partition f l .

Since 4.12

Listes d'association

val assoc : 'a -> ('a * 'b) list -> 'b

assoc a l l retourne la valeur associée à la clé a dans la liste de paires l . C'est-à-dire, assoc a [ ...; (a,b); ...] = b si (a,b) est la première association de a dans la liste l .

Raises Not_found s'il n'y a aucune valeur associée à a dans la liste l .

val assoc_opt : 'a -> ('a * 'b) list -> 'b option

assoc_opt a l l retourne la valeur associée à la clé a dans la liste de paires l . C'est-à-dire, assoc_opt a [ ...; (a,b); ...] = Some b si (a,b) est la première association de a dans la liste l . Retourne None s'il n'y a aucune valeur associée à a dans la liste l .

Since 4.05

val assq : 'a -> ('a * 'b) list -> 'b

Identique à ListLabels.assoc , mais utilise l'égalité physique au lieu de l'égalité structurelle pour comparer les clés.

val assq_opt : 'a -> ('a * 'b) list -> 'b option

Identique à ListLabels.assoc_opt , mais utilise l'égalité physique au lieu de l'égalité structurelle pour comparer les clés.

Since 4.05

val mem_assoc : 'a -> map:('a * 'b) list -> bool

Identique à ListLabels.assoc , mais retourne simplement true si une liaison existe, et false si aucune liaison n'existe pour la clé donnée.

val mem_assq : 'a -> map:('a * 'b) list -> bool

Identique à ListLabels.mem_assoc , mais utilise l'égalité physique au lieu de l'égalité structurelle pour comparer les clés.

val remove_assoc : 'a -> ('a * 'b) list -> ('a * 'b) list

remove_assoc a l retourne la liste de paires l sans la première paire avec la clé a , le cas échéant. Pas récursif terminal.

val remove_assq : 'a -> ('a * 'b) list -> ('a * 'b) list

Identique à ListLabels.remove_assoc , mais utilise l'égalité physique au lieu de l'égalité structurelle pour comparer les clés. Pas récursif terminal.
