NOM

Lire::Utils - Fonctions génériques.

SYNOPIS

use Lire:Utils qw/ xml_encode /;

DESCRIPTION

Ce module définit plusieurs fonctions génériques. Aucune fonction n'est exportée par défaut, vous devez spécifier celle que vous souhaitez importer dans votre espace de noms lorsque vous utilisez le module.

xml_encode( $str )

Convertit les caractères standards <,>,&," et ' en leurs entités XML.

Exemple

print XML_STREAM xml_encode( $value );

latex_encode( $str )

Retourne $str avec tous les caractères spéciaux LaTeX échappés.

tilde_expand( $path )

Effectue l'expansion du tilde dans un chemin, si possible. Cela signifie que les chemins de la forme ~/foo sont transformés en quelque chose comme /home/user/foo, où "/home/user" est le contenu de la variable $HOME. Les chemins de la forme ~otheruser/foo sont traduits de manière similaire en recherchant dans le répertoire de l'utilisateur.

diff_lists( $list1, $list2 )

Compare deux listes. Si les deux listes contiennent les mêmes éléments (même s'ils sont dans un ordre différent), retourne undef. Sinon, retourne une référence vers un hash contenant la liste des nouveaux éléments sous la clé 'new' et la liste des éléments à supprimer (pour que $list1 devienne $list2) sous la clé 'remove'.

FONCTIONS DE PORTABILITÉ

Pour la portabilité entre les versions de Perl, ce module définit quelques fonctions qui sont généralement présentes dans la dernière version de Perl mais qui peuvent ne pas être disponibles dans certaines anciennes versions (la plus ancienne que nous supportons est Perl 5.00503).

tmpdir()

Cette méthode (fournie par les versions récentes de File::Spec) retourne l'emplacement où les fichiers temporaires doivent être placés.

tempfile()

my $fh = tempfile();
my $fh = tempfile( $template, 'SUFFIX' => ".txt" )
my ( $fh, $name ) = tempfile( $template, 'SUFFIX' => ".dlf" );

Ceci est un wrapper autour de la fonction File::Temp::tempfile de Perl lorsqu'elle est disponible, et offre une version "maison" qui devrait être sûre lorsqu'elle n'est pas disponible. La seule différence est que le fichier sera toujours créé dans le répertoire spécifié dans $ENV{'TMPDIR'} ou /tmp lorsqu'il est désactivé.

Le premier argument de la fonction doit être un modèle contenant au moins 6 X (c'est-à-dire tempXXXXXX) qui seront remplacés pour générer un nom aléatoire. Lorsque aucun argument n'est passé, un modèle par défaut de tempfileXXXXXX sera utilisé.

D'autres options peuvent être passées à la fonction par paires clé-valeur. La seule option comprise par la version "maison" est SUFFIX, qui sera ajouté au nom du fichier. (La version Perl comprend plus d'options, mais vous ne devriez pas les utiliser pour la compatibilité.)

La fonction est protégée contre les attaques par déni de service (et crée le fichier avec des permissions de lecture et d'écriture uniquement pour le propriétaire). Si la création d'un fichier temporaire échoue après 10 tentatives, die() sera lancé. (Cela ne devrait pas arriver sauf si quelqu'un essaie de nous nuire.)

La fonction retournera dans un contexte scalaire un descripteur de fichier anonyme ouvert sur le fichier temporaire. Le fichier temporaire sera supprimé automatiquement lorsque vous fermerez le descripteur de fichier.

Lorsqu'elle est utilisée dans un contexte de tableau, la fonction retournera un descripteur de fichier et le chemin du fichier temporaire (cela peut être utile à des fins de débogage ou lorsque vous ne pouvez pas passer le fichier par descripteur à un autre processus). Dans ce cas, le fichier doit être supprimé manuellement.

tempdir()

my $dir = tempdir();
my $dir = tempdir( $template )

Ceci est un wrapper autour de la fonction File::Temp::tempdir de Perl lorsqu'elle est disponible, et offre une version "maison" qui devrait être sûre lorsqu'elle n'est pas disponible. La seule différence est que le répertoire sera toujours créé dans le répertoire spécifié dans $ENV{'TMPDIR'} ou /tmp lorsqu'il est désactivé.

Le premier argument de la fonction doit être un modèle contenant au moins 6 X (c'est-à-dire tempXXXXXX) qui seront remplacés pour générer un nom aléatoire. Lorsque aucun argument n'est passé, un modèle par défaut de tempdirXXXXXX sera utilisé.

D'autres options peuvent être passées à la fonction par paires clé-valeur. La seule option comprise par la version "maison" est DIR, qui spécifie où le répertoire sera créé (La version Perl comprend plus d'options, mais vous ne devriez pas les utiliser pour la compatibilité.)

La fonction est protégée contre les attaques par déni de service (et crée le fichier avec des permissions de lecture et d'écriture uniquement pour le propriétaire). Si la création d'un répertoire temporaire échoue après 10 tentatives, die() sera lancé. (Cela ne devrait pas arriver sauf si quelqu'un essaie de nous nuire.)

La fonction retournera le nom du répertoire qui a été créé.

min()

my $least = min(@values);
my $least = min($a,$b,$c);

max()

my $greatest = max(@values);
my $greatest = max($a,$b,$c);

Ces fonctions trouvent la plus petite ou la plus grande valeur dans une liste de nombres. Une liste vide retournera undef. Les valeurs indéfinies sont ignorées et ne seront retournées que si la liste est vide ou ne contient que des valeurs indéfinies.

ratio( $dividend, $divisor )

Retourne $dividende / $divisor et retourne "NaN" lorsque $divisor est égal à 0. Arrondit le résultat à deux décimales.

ratio100( $part, $total )

Retourne un pourcentage de $part sur $total. Cette fonction est sûre à utiliser lorsque $total est égal à 0 (elle retournera "NaN"). Le pourcentage est arrondi à une décimale.

shell_quote($string)

Retourne $string dans un format sûr pour être passé au shell, de sorte que les métacaractères ne soient pas interprétés par le shell. Ceci est fait en retournant $string entre guillemets et en échappant les guillemets présents dans $string.

indent( $string, [ $count ] )

Retourne $string indenté de $count espaces. Si $count n'est pas spécifié, une valeur par défaut de 2 sera supposée.

check_param( $param, $name, [ $regex | $coderef, $msg ] )

Vérifie que le paramètre "$name" n'est pas indéfini et qu'il correspond éventuellement au regex donné. La validation peut également être effectuée à l'aide d'une référence de code passée comme troisième paramètre. La convention dans ce cas est que la sous-routine retourne une valeur booléenne indiquant si $param est valide.

Exemples :

check_param( $req_param, 'req_param' );
check_param( $param_string, 'param_string', qr/^[a-z]+$/ );
check_param( $integer, 'integer', qr/^[0-9]+$/, "not a valid integer" );
check_param( $bool, 'bool', sub { return $_[0] }, "boolean was false" );

Description du module Lire::Utils

SYNTAXE

Exemples :

check_param( $object, 'object', 'Wawa::Class' );
check_param( $object, 'object', [ 'Wawa::Class', 'Other::Class' ] );

DESCRIPTION

La fonction check_param est utilisée pour valider des paramètres dans un objet. Elle peut recevoir une valeur chaîne de caractères ou une référence à un tableau contenant une ou plusieurs chaînes de caractères.
