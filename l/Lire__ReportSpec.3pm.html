ReportSpec(3pm) Documentation de Lire::Report ReportSpec(3pm)

NOM

Lire::ReportSpec - API des spécifications de rapports XML.

SYNTAXE

use Lire::ReportSpec;

DESCRIPTION

MÉTHODES D'INFORMATIONS MÉTA

list_specs( $superservice )

Retourne une référence de tableau contenant tous les types de spécifications de rapports disponibles pour le superservice $superservice.

has_spec( $superservice, $type )

Retourne vrai s'il existe une spécification de type $type pour le superservice $superservice.

MÉTHODES OBJET

subreport_id( [ $new_subreport_id ] )

Retourne (et modifie optionnellement) l'identifiant qui sera associé au sous-rapport qui sera généré par cette spécification.

chart_configs()

Retourne une référence de tableau contenant les objets Lire::Report::ChartConfig qui spécifient les graphiques qui devraient être générés lorsque l'objet Lire::Report::Subreport spécifié par cet objet sera formaté.

add_chart_config( $chart_config )

Ajoute un objet Lire::Report::ChartConfig qui devrait être ajouté à l'objet Lire::Report::Subreport qui est spécifié par cet objet.

filter_spec( [ $new_filter_spec ] )

Retourne (et modifie optionnellement) l'expression de filtre Lire::FilterExpr qui devrait être appliquée pour créer le sous-rapport Lire::Report::Subreport spécifié par cet objet. Ce sera undef s'il ne faut appliquer aucun filtrage.

calc_spec( [ $new_aggregator ] )

Retourne (et modifie optionnellement) l'agrégateur Lire::Aggregator qui devrait être utilisé pour créer le sous-rapport Lire::Report::Subreport spécifié par cet objet.

mark_missing( $reason )

Indique que le rapport qui devrait être généré par cette spécification de rapport doit être marqué comme manquant. Le paramètre $reason donne la raison pour laquelle le sous-rapport sera manquant.

is_missing()

Retourne vrai si le sous-rapport généré par cette spécification de rapport doit être marqué comme manquant.

set_store( $store )

Définit le magasin DLF sur lequel cette ReportSpec sera générée lorsque create_subreport() sera appelé.

create_subreport()

Crée un objet Lire::Report::Subreport basé sur cette spécification de rapport. Ce sera un sous-rapport manquant si la méthode mark_missing() a été appelée.

Appelé par Lire::ReportSection::create_report_section().

create_table_info()

Retourne un objet Lire::Report::TableInfo qui décrit la table générée par un sous-rapport de ce type.
