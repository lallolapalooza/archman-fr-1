NOM

Locale::RecodeData::MACCROATIAN - Fonctions de conversion pour MACCROATIAN

SYNTAXE

Ce module est interne à libintl. Ne l'utilisez pas directement !

DESCRIPTION

Ce module contient les tables de conversion et les routines pour MACCROATIAN.

COMMENTAIRES

Cette charmap a été générée automatiquement à partir des modifications de libiconv.

Veuillez noter que les alias mentionnés ci-dessus ne sont pas nécessairement valides !
