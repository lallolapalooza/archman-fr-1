Locale::Recode::_Aliases(3) Documentation Perl Contribuée par l'Utilisateur Locale::Recode::_Aliases(3)

NOM

Locale::Recode::_Aliases - Base de données interne des alias de jeu de caractères pour libintl-perl

SYNTAXE

use Locale::Recode::_Aliases

die "Ce module est interne à libintl. Ne l'utilisez pas directement !\n";

DESCRIPTION

Contient une liste d'alias de codes de caractères connus en interne par libintl.

CONSTANTES

ALIASES
La constante Locale::Recode::_Aliases::ALIASES contient une référence de hachage dont les clés sont des noms d'alias de jeu de caractères connus en interne, tous en majuscules. La valeur correspondante est le nom canonique du jeu de caractères.

BOGUES

Le format de la table de correspondance changera très probablement, ne vous fiez pas au format actuel !
