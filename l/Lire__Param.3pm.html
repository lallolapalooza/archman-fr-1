NOM

Lire::Param - Objet représentant un paramètre dans une spécification XML.

DESCRIPTION

Les Lire::Param sont des objets qui représentent des paramètres dans une spécification XML. L'objet est utilisé pour représenter la spécification du paramètre ainsi que sa valeur actuelle.

new( 'name' => $name, 'type' => $type, [ 'default' => $default ] )

Crée un nouvel objet Lire::Param.

name()

Retourne le nom de ce paramètre.

type()

Retourne le type de ce paramètre.

value( [ $new_value ] )

Retourne (et modifie optionnellement) la valeur actuelle de ce paramètre. Si aucune valeur n'a été définie, mais qu'une valeur par défaut est disponible, la valeur par défaut sera retournée.

default( [ $new_default ] )

Retourne (et modifie optionnellement) la valeur par défaut du paramètre.

description( [ $new_description ] )

Retourne (et modifie optionnellement) la description actuelle du paramètre.

as_type_spec()

Retourne un objet Lire::Config::TypeSpec qui représente adéquatement le paramètre actuel.

VOIR AUSSI

Lire::Config::TypeSpec(3pm), Lire::XMLSpecContainer(3pm)
