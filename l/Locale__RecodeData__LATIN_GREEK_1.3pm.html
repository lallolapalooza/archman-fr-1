NOM

Locale::RecodeData::LATIN_GREEK_1 - Routines de conversion pour LATIN_GREEK_1

SYNTAXE

Ce module est interne à libintl. Ne l'utilisez pas directement !

DESCRIPTION

Ce module contient les tables de conversion et les routines pour LATIN-GREEK-1.

COMMENTAIRES

Les commentaires suivants ont été extraits du fichier charmap original :

 version: 1.0
 source: ECMA registry
 alias ISO-IR-27

Note : les alias mentionnés ci-dessus ne sont pas forcément valides !
