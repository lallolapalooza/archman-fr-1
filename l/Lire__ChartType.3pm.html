ChartType(3pm) Documentation de Lire pour LogReport ChartType(3pm)

NOM

Lire::ChartType - Interface de base pour tous les ChartType.

SYNTAXE

use base qw/ Lire::ChartType /;

DESCRIPTION

Ce paquet définit l'interface qui est implémentée par les différents graphiques que Lire est capable de produire en utilisant la commande ploticus pl(1).

Un type de graphique générera un graphique à partir des données d'un sous-rapport.

MÉTHODES D'INFORMATION MÉTA

L'interface Lire::ChartType étend l'interface Lire::Plugin, elle doit donc implémenter toutes les méthodes standards d'information méta (name(), title(), description()).

GÉNÉRATION D'UN GRAPHIQUE

write_chart( $chart_config, $sous-rapport, [ %paramètres ] )

Ceci écrira un graphique à partir des données contenues dans le Lire::Report::Subreport $sous-rapport en utilisant la configuration $chart_config. Des paramètres additionnels sont passés sous forme de 'clé' => $valeur. Les paramètres de $chart_config doivent être un objet Lire::Config::Dictionary instancié à partir d'un Lire::Config::ChartSpec.

outputdir
Répertoire où le fichier sera créé. Utilise le répertoire de travail par défaut.
format
L'un des formats eps, png, jpeg ou gif. Utilise par défaut la variable de configuration lr_image_format.

La fonction retourne le chemin vers le fichier créé. Le nom du fichier est généré en se basant sur la valeur de configuration 'name' ou l'id du sous-rapport si l'autre n'est pas défini. L'extension est ajoutée en fonction du format de sortie.

Elle retourne le fichier où le graphique a été écrit.

prefab()

Cette méthode doit être implémentée par la sous-classe et doit retourner une chaîne représentant les premiers paramètres à passer à ploticus (c'est soit -prefab name, soit le chemin vers un fichier script).

write_parameters( $chart_config, $fh )

Cette méthode est utilisée pour écrire les paramètres dans le descripteur de fichier de ploticus. C'est l'endroit pour utiliser la commande #set afin de définir tous les paramètres prédéfinis. Les sous-classes doivent chaîner à cette implémentation pour les paramètres standards du graphique. Elle écrit également des directives '#set name' pour chaque variable numérique définie par get_vars().

write_data( $chart_config, $sous-rapport, $fh )

Cette méthode est utilisée par l'implémentation de write_chart() pour écrire les données du graphique du $sous-rapport dans la commande Ploticus ouverte sur $fh. Elle utilise la méthode get_vars() pour obtenir les variables numériques qui doivent être écrites dans le flux et la méthode encode_value() pour organiser les valeurs avant de les écrire. Avant que toute donnée ne soit écrite dans $fh, la valeur maximale sur l'axe Y est déterminée et sortie comme un réglage ploticus. (ploticus échoue si ce n'est pas défini, une seule barre est dessinée et la valeur est supérieure à 1.1e9.)

get_vars( $chart_config )

Cette méthode doit être surchargée par les sous-classes pour retourner une référence de tableau contenant les Lire::Report::ColumnInfo spécifiant les colonnes de données numériques qui doivent être écrites. Ceci est généralement spécifié en utilisant un ReferenceSpec avec l'index 'numerical_variables'.

Ces variables commenceront à l'index ploticus 2 (@2).

encode_value( $valeur )

Par défaut, cette méthode retourne simplement le composant 'content' de l'élément lorsque $valeur est un nom et le composant 'value' sinon. Elle peut être utilisée pour les types de données nécessitant un encodage spécial (comme les dates/heures).
