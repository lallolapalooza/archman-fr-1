NOM

Lire::Test::PluginTestCase - Classe de base pour l'écriture de tests unitaires de plugins

SYNTAXE

use base qw/ Lire::Test::PluginTestCase /;
use MyPlugin;
use File::Basename;
sub create_plugin {
  return new MyPlugin();
}
sub registration_file {
  return dirname( __FILE__ ) .  "../../plugin_init";
}

DESCRIPTION

Ceci est une sous-classe de Test::Unit::TestCase qui peut être utilisée pour écrire facilement des tests pour Lire::Plugin. Cette classe implémente ce qui est nécessaire pour fournir le fixture nécessaire dans set_up() et tear_down().

Elle fournit deux tests de base : test_api() et test_registration_file().

La classe de test doit implémenter deux méthodes pour aider à compléter le fixture.

FIXTURES

Ce sont les méthodes que les sous-classes remplaceront généralement pour fournir les données nécessaires à la configuration des fixtures de ChartType.

registration_file()

Doit retourner le script responsable de l'enregistrement de l'analyseur auprès du Lire::PluginManager. Ceci est utilisé par le test_registration_file() par défaut.

properties_spec_file()

Si cette méthode retourne un nom de fichier, il sera défini comme la spécification de configuration par défaut pour le test. Utilisez-la lorsque le plugin a des propriétés.

create_plugin()

Doit retourner une instance de l'instance Lire::Plugin à tester.

TESTS PAR DÉFAUT

test_api()

S'assure que toutes les méthodes requises par Lire::Plugin sont implémentées.

Vérifie que description() est correctement formaté en DocBook.

test_registration_file()

Vérifie que le script d'enregistrement enregistre correctement l'analyseur auprès du PluginManager.

VOIR AUSSI

Lire::Test::TestCase(3pm), Lire::Plugin(3pm)
