Locale::Maketext::Simple(3perl) Guide du programmeur Perl Locale::Maketext::Simple(3perl)

NOM

Locale::Maketext::Simple - Interface simple pour Locale::Maketext::Lexicon

VERSION

Ce document décrit la version 0.18 de Locale::Maketext::Simple, publiée le 8 septembre 2006.

SYNTAXE

Configuration minimale (recherche auto/Foo/*.po et auto/Foo/*.mo) :

package Foo;
use Locale::Maketext::Simple;       # exporte 'loc'
loc_lang('fr');                     # définit la langue sur français
sub hello {
    print loc("Hello, [_1]!", "World");
}

Exemple plus sophistiqué :

package Foo::Bar;
use Locale::Maketext::Simple (
    Class       => 'Foo',       # recherche dans auto/Foo/
    Style       => 'gettext',   # %1 au lieu de [_1]
    Export      => 'maketext',  # maketext() au lieu de loc()
    Subclass    => 'L10N',      # Foo::L10N au lieu de Foo::I18N
    Decode      => 1,           # décode les entrées en chaînes unicode
    Encoding    => 'locale',    # mais encode les lexiques dans la locale actuelle
                                # (nécessite Locale::Maketext::Lexicon 0.36)
);
sub japh {
    print maketext("Just another %1 hacker", "Perl");
}

DESCRIPTION

Ce module est un simple wrapper autour de Locale::Maketext::Lexicon, conçu pour alléger le besoin de créer des *Classes de Langue* pour les auteurs de modules.

La langue utilisée est choisie à partir de l'appel loc_lang. Si une recherche n'est pas possible, la langue par défaut i sera utilisée. Si la recherche n'est pas dans la langue par défaut i, alors la clé sera retournée.

Si Locale::Maketext::Lexicon n'est pas présent, il implémente une fonction de localisation minimale en interpolant simplement "[_1]" avec le premier argument, "[_2]" avec le second, etc. Les fonctions interpolées comme "[quant,_1]" sont traitées comme "[_1]", à la seule exception de "[tense,_1,X]", qui ajoutera "ing" à "_1" lorsque X est "present", ou ajoutera "ed" sinon.

OPTIONS

Toutes les options sont passées soit via l'instruction "use", soit via un "import" explicite.

Class

Par défaut, Locale::Maketext::Simple tire sa source du répertoire auto/ du paquet appelant ; vous pouvez outrepasser ce comportement en spécifiant explicitement un autre paquet comme "Class".

Path

Si vos fichiers PO et MO se trouvent ailleurs que dans "auto/", vous pouvez le spécifier en utilisant l'option "Path".

Style

Par défaut, ce module utilise le style "maketext" de "[_1]" et "[quant,_1]" pour l'interpolation. Alternativement, vous pouvez spécifier le style "gettext", qui utilise %1 et %quant(%1) pour l'interpolation.

Cette option est insensible à la casse.

Export

Par défaut, ce module exporte une seule fonction, "loc", dans l'espace de noms de son appelant. Vous pouvez la définir sur un autre nom, ou la définir sur une chaîne vide pour désactiver l'exportation.

Subclass

Par défaut, ce module crée une sous-classe "::I18N" sous le paquet de l'appelant (ou le paquet spécifié par "Class"), et stocke les données du lexique dans ses sous-classes. Vous pouvez assigner un nom autre que "I18N" via cette option.

Decode

Si défini sur une valeur vraie, les entrées source seront converties en chaînes utf8 (disponible à partir de Perl 5.6.1). Cette fonctionnalité nécessite le module Encode ou Encode::compat.

Encoding

Spécifie un encodage pour stocker les entrées du lexique, au lieu des chaînes utf8. Si défini sur "locale", l'encodage de la configuration de la locale actuelle est utilisé. Implique une valeur vraie pour "Decode".
