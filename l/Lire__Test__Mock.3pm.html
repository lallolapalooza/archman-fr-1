NOM

Lire::Test::Mock - Créer un objet factice (mock)

SYNTAXE

use Lire::Report;
use Lire::Test::Mock;
use Lire::DlfResult;
my $mock = new Lire::Test::Mock( 'Lire::Report' );
$mock->set_result( 'timestamp', $time );
$mock->timestamp(); # retournera $time
$mock->get_calls(); # [ 'timestamp' ]
$mock->get_invocation( 'timestamp', 0 ); # [ $mock ]

DESCRIPTION

Cette classe facilite la définition d'objets factices (mock objects). Les objets factices sont des objets qui offrent la même interface qu'un autre objet mais qui ne partagent pas sa fonctionnalité. Cela facilite le test des objets qui nécessitent des fixtures ayant de nombreuses dépendances.

L'objet factice peut être utilisé pour collecter des informations sur les appels effectués à l'objet. La valeur de retour pour de telles invocations de méthodes peut également être spécifiée.

new( $class, 'methode' => $resultat, 'methode' => $resultat )

Crée un nouvel objet factice qui encapsulera $class. Tout autre argument mot-clé sera utilisé pour initialiser le résultat d'un appel de méthode. Voir set_result() pour plus d'informations sur le fonctionnement.

new_proxy( $class, @paramètres_constructeur )

Ceci crée un objet factice pour la classe de base $class. Un objet factice proxy continuera de surveiller les appels à l'objet, mais les vraies méthodes seront appelées, sauf si un résultat a été spécifié à l'aide de set_result(). Les paramètres restants seront transmis à la méthode new() qui doit être définie dans la classe.

new_proxy( $instance )

Crée un objet Lire::Test::Mock qui est un clone de $instance.

is_proxy()

Retourne si cet objet factice agira comme un proxy pour les méthodes réelles lorsqu'aucun résultat n'a été défini pour une méthode spécifique.

get_calls()

Retourne une référence de tableau contenant toutes les méthodes appelées sur l'objet.

compteur_invocations( $methode )

Retourne le nombre de fois où $methode a été appelée.

get_invocation( $methode, $index )

Retourne les paramètres qui ont été donnés lors de l'appel de la méthode $methode.

set_result( methode => $resultat, ... )

Ceci assigne le résultat $resultat à $methode. Si $resultat est une référence de code, elle sera appelée avec les mêmes arguments que la méthode pour calculer le résultat.

UTILISATION DES FABRIQUES DE FACTURES (MOCK FACTORIES)

Parfois, il n'est pas possible d'instancier un objet proxy ou factice lors de la configuration des fixtures. Cela se produit généralement lorsque l'objet dont nous voulons suivre l'accès est instancié par la méthode sous test. Dans ces cas, on peut utiliser la méthode de classe set_mock_factory() pour changer la méthode de fabrique pour une qui retournera une instance proxy au lieu d'une instance réelle. Il faut appeler reset_factories() pendant tear_down() afin que la vraie méthode de fabrique redevienne directement accessible.

set_mock_factory( $class, %resultats )

Fait en sorte que la méthode new() du paquet $class retourne une instance Lire::Test::Mock proxy. Les instances créées seront accessibles via la méthode mock_instances(). Tous les autres arguments seront transmis à la méthode set_result() lors de la création de l'instance factice.

mock_instances( $class )

Retourne une référence de tableau contenant toutes les instances qui ont été créées par la fabrique factice installée dans $class. Cette méthode lèvera une exception si aucune fabrique factice n'a été installée pour la classe $class.

reset_factories()

Supprime toutes les fabriques factices qui ont été configurées à l'aide de set_mock_factory().
