NOM

Locale::RecodeData::IBM278 - Routines de conversion pour IBM278

Ce module est interne à libintl. Ne l'utilisez pas directement !

DESCRIPTION

Ce module contient les tables de conversion et les routines pour IBM278.

COMMENTAIRES

Les commentaires suivants ont été extraits de la table de caractères originale :

version: 1.0
 source: IBM NLS RM Vol2 SE09-8002-01, March 1990
 alias CP278
 alias EBCDIC-CP-FI
 alias EBCDIC-CP-SE

Note : Les alias mentionnés ci-dessus ne sont pas nécessairement valides !

Nom

                    
Locale::RecodeData::IBM278 - Données de l'encodage IBM 278

                

                

                    
Synopsis

                    
 use Locale::RecodeData;

 my $recode_data = Locale::RecodeData->new("IBM278");


                

                

                    
Description

                    
La classe Locale::RecodeData::IBM278 est une implémentation pour l'encodage IBM278. Elle contient les informations nécessaires pour la conversion entre les différents encodages de caractères.

                

                

                    
Commentaires

                    
Cette section contient des commentaires sur l'implémentation spécifique de cet encodage.
