NOM

Locale::Po4a::Dia - convertir les diagrammes Dia non compressés de/vers les fichiers PO

DESCRIPTION

L'objectif du projet po4a (PO for anything) est de faciliter les traductions (et plus intéressant encore, la maintenance des traductions) en utilisant les outils gettext dans des domaines où ils n'étaient pas attendus, comme la documentation.

Locale::Po4a::Dia est un module pour aider à la traduction des diagrammes au format Dia non compressé dans d'autres langues [humaines].

Vous pouvez obtenir Dia (l'éditeur graphique pour ces diagrammes) à l'adresse :
http://www.gnome.org/projects/dia/

TRADUIRE AVEC PO4A::DIA

Ce module ne traduit que les diagrammes Dia non compressés. Vous pouvez enregistrer vos diagrammes non compressés avec Dia lui-même, en décochant l'option "Compresser les fichiers de diagrammes" dans la boîte de dialogue "Enregistrer le diagramme".

Une autre façon est de décompresser les fichiers dia depuis la ligne de commande avec :
gunzip < original.dia > uncompressed.dia

STATUT DE CE MODULE

Ce module est pleinement fonctionnel, car il repose sur le module Locale::Po4a::Xml. Celui-ci définit uniquement les balises traduisibles (<dia:string>), et filtre les chaînes internes (le contenu de la balise <dia:diagramdata>), qui ne sont pas intéressantes pour la traduction.
