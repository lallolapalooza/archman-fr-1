NOM

Locale::RecodeData::IBM285 - Routines de conversion pour IBM285

SYNTAXE

Ce module est interne à libintl. Ne pas utiliser directement !

DESCRIPTION

Ce module est généré et contient les tables et routines de conversion pour IBM285.

COMMENTAIRES

Les commentaires suivants ont été extraits de la charmap originale :

version: 1.0
 source: IBM NLS RM Vol2 SE09-8002-01, March 1990
alias CP285
alias EBCDIC-CP-GB

Veuillez noter que les alias listés ci-dessus ne sont pas nécessairement valides !

NOM

Locale::RecodeData::IBM285

SYNOPSIS

use Locale::RecodeData::IBM285;

DESCRIPTION

Locale::RecodeData::IBM285 est un module qui contient la table des caractères pour le système de codage IBM285. Cette table est utilisée pour recoder les chaînes de caractères au format ASCII dans d'autres formats de codage.

COMMENTAIRES

Cette table de caractères est conçue pour être utilisée dans les systèmes nécessitant le recodage du texte au format ASCII vers d'autres formats. Le module fournit un moyen efficace de gérer cette conversion en utilisant des fonctions prédéfinies.
