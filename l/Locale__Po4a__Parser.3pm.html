NOM

Locale::Po4a::SimplePod::Parser - module d'aide pour analyser le POD

DESCRIPTION

Ce module sert d'aide pour Locale::Po4a::SimplePod et n'est pas destiné à être utilisé directement par les utilisateurs finaux, tels que les traducteurs.

À FAIRE

La suppression de l'indentation des blocs verbatim pourrait être utile. J'envisage d'utiliser la fonction "strip_verbatim_indent" pour contrôler ce comportement.

VOIR AUSSI

Ce module est basé sur Pod::Simple::JustPod, qui effectue une transformation d'identité de POD en POD. Ce module est particulièrement utile pour comprendre comment sérialiser les événements de document POD analysés dans le format de fichier POD.

Pour un aperçu fondamental de la bibliothèque, voir Pod::Simple. De plus, Locale::Po4a::SimplePod utilise ce module dans po4a.
