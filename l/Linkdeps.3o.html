Module Linkdeps
: sig end

type t

L'état de la vérification de liaison. Il garde une trace des unités de compilation fournies et requises jusqu'à présent.

type compunit = string

type filename = string

val create : complete:bool -> t

create ~complete renvoie un état vide. Si complete est true , les unités de compilation manquantes seront traitées comme des erreurs.

val add : t -> filename:filename -> compunit:compunit -> provides:compunit list -> requires:compunit list -> unit

add t ~filename ~compunit ~provides ~requires enregistre l'unité de compilation compunit trouvée dans filename dans t .

- provides sont les unités et sous-unités fournies par compunit

- requires sont les unités requises par compunit

add doit être appelé dans l'ordre topologique inverse.

val required : t -> compunit -> bool

required t compunit renvoie true si compunit est une dépendance des unités de compilation ajoutées précédemment.

type compunit_and_source = {
compunit : compunit ;
filename : filename ;
}

type error =
| Missing_implementations of (compunit * compunit_and_source list) list
| Wrong_link_order of (compunit_and_source * compunit_and_source list) list
| Multiple_definitions of (compunit * filename list) list

val check : t -> error option

check t doit être appelé une fois que toutes les unités de compilation à lier ont été ajoutées. Il renvoie une erreur si :

-Il y a des implémentations manquantes et complete est true

-Certaines implémentations apparaissent avant leurs dépendances
