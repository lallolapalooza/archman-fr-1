NOM

Locale::RecodeData::IBM870 - Routines de conversion pour IBM870

SYNOPSIS

Ce module est interne à libintl. Ne l'utilisez pas directement !

DESCRIPTION

Ce module est généré et contient les tables et routines de conversion pour IBM870.

COMMENTAIRES

Les commentaires suivants ont été extraits de la charmap originale :

version: 1.0
 source: IBM NLS RM Vol2 SE09-8002-01, March 1990
alias CP870
alias EBCDIC-CP-ROECE
alias EBCDIC-CP-YU

Veuillez noter que les alias listés ci-dessus ne sont pas nécessairement valides !

NOM


Locale::RecodeData






SYNTAXE


use Locale::RecodeData;






DESCRIPTION


Locale::RecodeData est un module qui fournit une table de caractères pour le réencodage des données de localisation.






COMMENTAIRES


La table de caractères contient des correspondances pour divers caractères utilisés dans le réencodage des données de localisation.
