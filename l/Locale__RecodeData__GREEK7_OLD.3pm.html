NOM

Locale::RecodeData::GREEK7_OLD - Routines de conversion pour GREEK7_OLD

SYNTAXE

Ce module est interne à libintl. Ne l'utilisez pas directement !

DESCRIPTION

Ce module contient les tables de conversion et les routines pour GREEK7-OLD.

COMMENTAIRES

Les commentaires suivants ont été extraits du charmap original :

version : 1.0
 source : ECMA Registry
 alias : ISO-IR-18

Note : les alias susmentionnés ne sont pas nécessairement valides !
