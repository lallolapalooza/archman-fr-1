LOGIMPORT(3) Manuel des fonctions de bibliothèque LOGIMPORT(3)

NOM

LOGIMPORT - introduction à la bibliothèque d'importation de données et de création d'archives PCP

C SYNTAXE

#include <pcp/pmapi.h>
#include <pcp/import.h>

cc ... -lpcp_import -lpcp

SYNTAXE Perl

use PCP::LogImport;

SYNTAXE Python

from pcp import pmi

DESCRIPTION

L'API LOGIMPORT (Log Import) de Performance Co-Pilot est une bibliothèque (avec des wrappers Perl et Python) qui prend en charge la création d'archives PCP à partir de sources externes de données de performance, que ce soit sous forme de journaux historiques et de feuilles de calcul, ou à partir de sources en temps réel qui ne sont pas intégrées en tant qu'agent de domaine de métriques de performance (PMDA) sous le contrôle de pmcd(1).

L'utilisation typique de LOGIMPORT impliquerait :

  • Un appel initial à pmiStart(3).
  • Des appels optionnels à pmiSetHostname(3) et/ou pmiSetTimezone(3) pour définir le nom d'hôte et le fuseau horaire de la source des données de performance.
  • Un ou plusieurs appels à pmiAddMetric(3) pour définir les métriques de performance.
  • Un ou plusieurs appels à pmiAddInstance(3) pour définir les instances associées aux métriques.
  • Des appels optionnels à pmiGetHandle(3) pour définir des poignées de commodité pour les paires métrique-instance.
  • Une boucle principale dans laquelle les données de performance sont ingérées et, pour chaque intervalle de temps d'échantillonnage, l'enregistrement de l'archive PCP est construit par des appels à pmiPutValue(3), pmiPutValueHandle(3), pmiPutText(3), et/ou pmiPutLabel(3), suivis d'un appel à pmiWrite(3) pour vider toutes les données et les métadonnées associées dans l'archive PCP. Alternativement, pmiPutResult(3) pourrait être utilisé pour empaqueter et traiter toutes les données d'un intervalle de temps d'échantillonnage.
  • Une fois la source d'entrée de données consommée, appeler pmiEnd(3) pour terminer la création de l'archive PCP et fermer tous les fichiers ouverts.

Si de nouvelles métriques et/ou instances sont découvertes pendant l'ingestion des données, celles-ci peuvent être ajoutées par des appels ultérieurs à pmiAddMetric(3) et/ou pmiAddInstance(3), à condition que toutes les métriques et instances aient été définies avant un appel à pmiGetHandle(3), pmiPutValue(3)ou pmiPutResult(3) qui référence ces métriques et instances.
