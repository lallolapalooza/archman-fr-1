NAME


Locale::RecodeData::IBM297 - Data for IBM EBCDIC (French)






SYNOPSIS


    use Locale::RecodeData::IBM297;
    # ... or let Locale::Recode discover it







DESCRIPTION


This module provides the data for the IBM297
    (EBCDIC French) code set, also known as cp297,
    cp037, ebcdic-fr, ibm-297,
    297. It maps it to Unicode.


See Locale::RecodeData(3)
    for details.






COMMENTS


    This file is part of libintl-perl.
