NOM

Lire::Timegroup - Classe de base pour l'implémentation de l'agrégateur de groupe temporel

SYNTAXE

use Lire::Timegroup;

DESCRIPTION

Ce module est la classe de base pour l'implémentation de l'agrégateur de groupe temporel. Cet agrégateur divisera les enregistrements DLF en fonction d'une période contrôlée par l'attribut 'period'. Par exemple, en utilisant '1d' comme valeur de période, cet agrégateur regroupera tous les enregistrements de la même période journalière.

CONSTRUCTEUR

new( %parametres )

Crée une nouvelle instance d'un agrégateur de groupe temporel. En plus des paramètres normaux de l'opérateur de rapport, l'agrégateur de groupe temporel peut accepter plusieurs paramètres:

champ
Ce paramètre optionnel contient le champ DLF qui contient la valeur temporelle utilisée pour regrouper les enregistrements DLF. Voir la méthode champ() pour plus d'informations.
période
Ce paramètre obligatoire doit contenir la durée de la période qui sera utilisée pour regrouper les enregistrements. Voir la méthode période() pour plus d'informations.

MÉTHODES

champ( [$nouveau_champ] )

Retourne le nom du champ DLF utilisé pour regrouper les enregistrements DLF. Il doit s'agir d'un champ DLF d'horodatage valide dans le schéma actuel. Par défaut, le champ d'horodatage par défaut du schéma DLF est utilisé.

Vous pouvez changer le champ en passant un paramètre $nouveau_champ.

période( [$nouvelle_période])

Retourne la durée de la période pendant laquelle les enregistrements sont regroupés. Il peut s'agir d'une valeur de durée ou du nom d'un paramètre de spécification de rapport contenant une valeur de durée.

La durée de la période peut être modifiée en utilisant le paramètre $nouvelle_période.
