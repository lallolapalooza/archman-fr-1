NOM

Locale::RecodeData::ECMA_CYRILLIC - Routines de conversion pour ECMA_CYRILLIC

SYNTAXE

Ce module est interne à libintl. Ne l'utilisez pas directement !

DESCRIPTION

Ce module est généré et contient les tables et routines de conversion pour ECMA-CYRILLIC.

COMMENTAIRES

Les commentaires suivants ont été extraits de la charmap d'origine :

version: 1.0
 source: ECMA registry
alias ISO-IR-111

Veuillez noter que les alias indiqués ci-dessus ne sont pas nécessairement valides !

NOM

Locale::RecodeData

SYNTAXE

use Locale::RecodeData;

DESCRIPTION

Locale::RecodeData est un module pour l'encodage et le décodage des données de localisation, fournissant un moyen de gérer différents jeux de caractères et schémas d'encodage.

COMMENTAIRES

Ce module est conçu pour aider à l'encodage et au décodage des données de localisation, offrant une interface flexible et puissante pour travailler avec différents jeux de caractères et schémas d'encodage.
