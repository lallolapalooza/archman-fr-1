NOM

Log::Message::Simple - Interface simplifiée pour Log::Message

SYNOPIS

use Log::Message::Simple qw[msg error debug
                            carp croak cluck confess];
use Log::Message::Simple qw[:STD :CARP];
### fonctionnalité de reporting standard
msg(    "Connexion à la base de données",           $verbose );
error(  "La connexion à la base de données a échoué : $@",   $verbose );
debug(  "Les arguments de connexion étaient : $args", $debug );
### fonctionnalité carp standard
carp(   "Mauvais arguments passés : @_" );
croak(  "Fatal : mauvais arguments passés : @_" );
cluck(  "Mauvais arguments passés -- y compris la pile d'appels : @_" );
confess("Fatal : mauvais arguments passés -- y compris la pile d'appels : @_" );
### récupérer un message individuel
my @stack = Log::Message::Simple->stack;
my @stack = Log::Message::Simple->flush;
### récupérer la pile entière sous forme imprimable
my $msgs  = Log::Message::Simple->stack_as_string;
my $trace = Log::Message::Simple->stack_as_string(1);
### rediriger la sortie
local $Log::Message::Simple::MSG_FH     = \*STDERR;
local $Log::Message::Simple::ERROR_FH   = \*STDERR;
local $Log::Message::Simple::DEBUG_FH   = \*STDERR;
### forcer une pile d'appels sur erreur
local $Log::Message::Simple::STACKTRACE_ON_ERROR = 1

DESCRIPTION

Ce module fournit des facilités de journalisation standardisées utilisant le module "Log::Message".

FONCTIONS

msg("chaîne message" [,VERBOSE])

Enregistre un message dans la pile, et l'imprime sur "STDOUT" (ou en fait $MSG_FH, voir la section "VARIABLES GLOBALES" ci-dessous), si l'option "VERBOSE" est vraie. L'option "VERBOSE" est fausse par défaut.

Exporté par défaut, ou en utilisant le tag ":STD".

debug("chaîne message" [,VERBOSE])

Enregistre un message de débogage dans la pile, et l'imprime sur "STDOUT" (ou en fait $DEBUG_FH, voir la section "VARIABLES GLOBALES" ci-dessous), si l'option "VERBOSE" est vraie. L'option "VERBOSE" est fausse par défaut.

Exporté par défaut, ou en utilisant le tag ":STD".

error("chaîne erreur" [,VERBOSE])

Enregistre une erreur dans la pile, et l'imprime sur "STDERR" (ou en fait $ERROR_FH, voir les sections "VARIABLES GLOBALES" ci-dessous), si l'option "VERBOSE" est vraie. L'option "VERBOSE" est vraie par défaut.

Exporté par défaut, ou en utilisant le tag ":STD".

carp();

Fournit une fonctionnalité égale à Carp::carp() tout en journalisant dans la pile.

Exporté en utilisant le tag ":CARP".

croak();

Fournit une fonctionnalité égale à Carp::croak() tout en journalisant dans la pile.

Exporté en utilisant le tag ":CARP".

confess();

Fournit une fonctionnalité égale à Carp::confess() tout en journalisant dans la pile.

Exporté en utilisant le tag ":CARP".

cluck();

Fournit une fonctionnalité égale à Carp::cluck() tout en journalisant dans la pile.

Exporté en utilisant le tag ":CARP".

MÉTHODES DE CLASSE

Log::Message::Simple->stack()

Récupère tous les éléments de la pile. Puisque "Log::Message::Simple" est implémenté en utilisant "Log::Message", consultez sa page man pour la fonction "retrieve" pour voir ce qui est renvoyé et comment utiliser les éléments.

Log::Message::Simple->stack_as_string([TRACE])

Renvoie la pile entière sous forme de chaîne imprimable. Si l'option "TRACE" est vraie, tous les éléments sont renvoyés avec la sortie de "Carp::longmess", plutôt que juste le message. "TRACE" vaut faux par défaut.

Log::Message::Simple->flush()

Supprime tous les éléments de la pile et les renvoie. Puisque "Log::Message::Simple" est implémenté en utilisant "Log::Message", consultez sa page man pour la fonction "retrieve" pour voir ce qui est renvoyé et comment utiliser les éléments.

VARIABLES GLOBALES

$ERROR_FH
C'est le handle de fichier sur lequel tous les messages envoyés à error() sont imprimés. Cela vaut par défaut *STDERR.
$MSG_FH
C'est le handle de fichier sur lequel tous les messages envoyés à msg() sont imprimés. Cela vaut par défaut *STDOUT.
$DEBUG_FH
C'est le handle de fichier sur lequel tous les messages envoyés à debug() sont imprimés. Cela vaut par défaut *STDOUT.
$STACKTRACE_ON_ERROR
Si cette option est définie sur "vrai", chaque appel à error() générera une pile d'appels en utilisant Carp::shortmess(). Vaut par défaut "faux".
