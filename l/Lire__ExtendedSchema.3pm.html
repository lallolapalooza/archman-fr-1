NOM

Lire::ExtendedSchema - Ajoute des champs à chaque enregistrement DLF d'un schéma de base

SYNTAXE

my $schema = Lire::DlfSchema::load_schema( 'www-robot' );
my $ext_fields = $schema->extended_fields();

DESCRIPTION

Un Lire::ExtendedSchema définit un DlfSchema qui ajoute des champs à chaque enregistrement d'un DlfSchema de base. Les valeurs des champs étendus sont généralement calculées à partir de valeurs basées sur les valeurs des champs de l'enregistrement DLF de base. Ces valeurs ne sont pas écrites par Lire::DlfConverters, mais par Lire::DlfAnalysers (ou généralement un Lire::DlfCategoriser).

base()

Retourne l'objet Lire::DlfSchema pour lequel les enregistrements de ce schéma sont une extension.

peut_rejoindre_schema( $schema )

Retourne vrai si $schema peut être joint avec ce schéma. Pour un ExtendedSchema, cela sera vrai uniquement lorsque $schema est un ExtendedSchema qui partage le même nom que ce schéma.

VOIR AUSSI

Lire::DlfSchema(3pm), Lire::DerivedSchema(3pm), Lire::DlfAnalyser(3pm), Lire::DlfCategoriser(3pm)
