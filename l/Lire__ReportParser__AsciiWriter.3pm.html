NOM

Lire::ReportParser::AsciiWriter - Processeur Lire::ReportParser qui formate le rapport en ASCII

SYNOPIS

use Lire::ReportParser::AsciiWriter;
my $parser = new Lire::ReportParser::AsciiWriter;
eval { $parser->parsefile( "report.xml" ) };
print "Échec de l'analyse : $@" if $@;

DESCRIPTION

Ceci est un processeur Lire::ReportParser qui imprimera le Rapport XML de Lire en ASCII sur STDOUT.

Son constructeur accepte les paramètres suivants :

colonnes
Le nombre de colonnes pour lesquelles le rapport doit être formaté. Par défaut, 80.
longueur_nom_max
Le nombre maximum de caractères qui seront conservés dans l'élément name. Par défaut, 180.
niveau_utilisateur
Dans la description, le niveau maximum d'éléments qui seront affichés. Par défaut, "normal" (c'est-à-dire que les éléments "avancé" ne sont pas formatés).
