Locale::Maketext::Lexicon::Msgcat(3) Documentation Perl fournie par l'utilisateur Locale::Maketext::Lexicon::Msgcat(3)

NOM

Locale::Maketext::Lexicon::Msgcat - Analyseur de catalogue Msgcat pour Maketext

VERSION

version 1.00

SYNOPSIS

package Hello::I18N;
use base 'Locale::Maketext';
use Locale::Maketext::Lexicon {
    en => ['Msgcat', 'en_US/hello.pl.m'],
};
package main;
my $lh = Hello::I18N->get_handle('en');
print $lh->maketext(1,2);   # jeu 1, msg 2
print $lh->maketext("1,2"); # même chose

DESCRIPTION

Ce module analyse un ou plusieurs catalogues Msgcat au format texte brut et retourne une table de hachage Lexicon, qui peut être recherchée soit avec une forme à deux arguments ("$id_jeu, $id_msg"), soit sous forme d'une chaîne unique ("$id_jeu,$id_msg").

NOTES

Tous les caractères spéciaux ("[", "]" et "~") dans les catalogues seront échappés afin qu'ils perdent leurs significations magiques. Cela signifie que les appels "->maketext" à ce lexique ne prendront aucun argument supplémentaire.

VOIR AUSSI

Locale::Maketext, Locale::Maketext::Lexicon
