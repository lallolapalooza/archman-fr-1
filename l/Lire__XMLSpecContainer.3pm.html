NOM

Lire::XMLSpecContainer - Classe de base pour les spécifications de rapport et de filtre XML

SYNOPSIS

use base qw/Lire::XMLSpecContainer/;

DESCRIPTION

Ceci est la classe de base pour Lire::ReportSpec et Lire::FilterSpec, qui sont des spécifications XML utilisées pour calculer des rapports. Ce manuel documente les attributs communs aux deux types de spécification.

id( [ $new_id ] )

Retourne le type d'identité de cette spécification. Si $new_id est défini, il changera l'identité de la spécification.

superservice( [ $new_superservice ] )

Retourne le super service (aussi appelé DLF de base) utilisé par cette spécification. Si $new_superservice est défini, il changera le super service de la spécification.

schema( [ $new_schema ] )

Retourne l'objet Lire::DLfSchema utilisé par cette spécification. Il peut s'agir du super service ou de l'un de ses Lire::ExtendedSchema ou Lire::DerivedSchema.

Si $new_schema est une chaîne de caractères, le schéma de la spécification sera changé pour cette chaîne. Si $new_schema est undef, le DLF de base (aussi appelé super service) sera utilisé.

joined_schemas( [ $new_schemas ] )

Retourne, sous forme de référence de tableau, la liste des schémas joints dans cette spécification.

Si $new_schemas est défini, la liste des schémas joints sera changée pour cette liste. Il s'agit d'un tableau de noms de schémas. Tous ces schémas doivent être compatibles avec le schéma spécifié dans l'attribut schema().

schemas()

Retourne, sous forme de référence de tableau, tous les schémas utilisés par cette spécification. Cela inclura le schéma de base ainsi que tous les schémas joints.

has_field( $name )

Retourne si le champ nommé $name est disponible dans cette spécification ou dans l'un de ses schémas joints.

field( $name )

Retourne l'objet Lire::Field nommé $name présent dans l'un des schémas joints de cette spécification.

title( [ $new_title ]

Cette méthode retourne le titre de cette spécification. Si $new_title est défini, le titre de la spécification sera changé pour cette valeur.

La valeur retournée est localisée s'il existe une chaîne de traduction disponible. Le domaine utilisé pour la traduction est 'lire-<superservice'.

description( [ $new_description ]

Cette méthode retourne la description de cette spécification. Si $new_description est défini, la description de la spécification sera changée pour cette valeur. La description est une chaîne DocBook décrivant le but de la spécification.

La valeur retournée est localisée s'il existe une chaîne de traduction disponible. Le domaine utilisé pour la traduction est 'lire-<superservice'.

display_title( [ $new_title ]

Cette méthode retourne le titre qui sera affiché dans la spécification générée. Cette valeur peut contenir des références à des paramètres de la spécification en utilisant le symbole '$name'.

Si $new_title est défini, le titre de la spécification sera changé pour cette valeur.

La valeur retournée est localisée s'il existe une chaîne de traduction disponible. Le domaine utilisé pour la traduction est 'lire-<superservice'.

display_description( [ $new_description ]

Cette méthode retourne la description qui sera affichée dans le rapport généré. Cette valeur peut contenir des références à des paramètres de la spécification en utilisant le symbole '$name'.

Si $new_description est défini, la description de la spécification sera changée pour cette valeur. La description est une chaîne DocBook décrivant le but de la spécification.

La valeur retournée est localisée s'il existe une chaîne de traduction disponible. Le domaine utilisé pour la traduction est 'lire-<superservice'.

expanded_display_title()

Retourne display_title() avec les paramètres référencés développés.

expanded_display_description()

Retourne display_description() avec les paramètres référencés développés.

print( $fh )

Imprime cette spécification sous forme de XML dans $fh.

NOM

Lire::XMLSpecContainer - Interface pour les conteneurs de spécifications XML

SYNOPSIS

use Lire::XMLSpecContainer;

my $container = Lire::XMLSpecContainer->new(file => 'spec.xml');
my @elements = $container->get_elements;
my $element = $container->get_element_by_id('element-id');

DESCRIPTION

La classe Lire::XMLSpecContainer fournit une interface pour charger et accéder aux données à partir de fichiers de spécifications XML.

MÉTHODES

new(file => $file_path)

Crée un nouvel objet XMLSpecContainer. Le paramètre file est le chemin d'accès au fichier XML à charger.

get_elements()

Retourne un tableau de tous les éléments du conteneur de spécifications.

get_element_by_id($id)

Retourne l'élément correspondant à l'identifiant donné. Retourne undef si aucun élément n'est trouvé.
