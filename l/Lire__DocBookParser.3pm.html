NOM

Lire::XMLParser - Analyseur DocBook de base.

SYNTAXE

package MonAnalyseur;
use base qw/ Lire::XMLParser /;

DESCRIPTION

Ce paquet contient un analyseur DocBook pour Lire::XMLParser. Il définit les méthodes pertinentes "_start", "_end" et "_char" pour le sous-ensemble de DocBook utilisé par Lire. Tous les gestionnaires définis ont la forme "dbk_nom_start", "dbk_nom_end" et "dbk_nom_char" (lorsque l'élément accepte du contenu PCDATA).

Sa fonctionnalité de base est de collecter le balisage DocBook pour une utilisation ultérieure. Il sera le plus souvent sous-classé.

METHODES CLIENT

dbk_init()

Les sous-classes doivent appeler cette méthode chaque fois que l'état de l'analyse DocBook doit être réinitialisé. Elle est appelée depuis la méthode parse_start() lorsque l'analyseur est utilisé de manière autonome.

dbk_string()

Retourne le XML DocBook accumulé par l'analyseur. Ceci est retourné par la méthode parse_end() lorsqu'il est utilisé de manière autonome.

METHODES DE SPECIFICATION XML IMPLEMENTATION

namespaces()

DocBook n'utilise pas d'espaces de noms, donc cette méthode retourne une référence de hachage vide.

elements_spec()

Retourne la spécification des éléments pour le sous-ensemble de DocBook supporté par Lire.

VOIR AUSSI

Lire::XMLParser(3pm), Lire::ReportParser::AsciiDocBookFormatter(3pm),
Lire::ReportParser::HtmlDocBookFormatter(3pm)
