Module Local_store
: sig end

Ce module fournit quelques facilités pour créer des références (et des tables de hachage) qui peuvent être facilement capturées dans un état et restaurées à une version arbitraire.

Il est utilisé dans l'ensemble du frontend (c'est-à-dire le vérificateur de types) pour enregistrer tout l'état global (ou du moins espérons-le), ce qui permet à des outils comme Merlin de revenir en arrière et de vérifier différemment différents fichiers.

CRÉATEURS

val s_ref : 'a -> 'a ref

Similaire à ref , sauf que la référence allouée est enregistrée dans le magasin.

val s_table : ('a -> 'b) -> 'a -> 'b ref

Utilisé pour enregistrer les tables de hachage. Celles-ci doivent également être placées dans des références pour être facilement remplaçables, mais on ne peut pas simplement « capturer » la valeur initiale pour créer de nouvelles instances, donc un initialiseur est requis.

Utilisez-le comme ceci :

      let my_table = s_table Hashtbl.create 42

GESTION ÉTAT

Remarque : toutes les fonctions suivantes ne sont actuellement pas utilisées dans le code source du compilateur. Merlin est leur seul utilisateur pour le moment.

type store

val fresh : unit -> store

Retourne une nouvelle instance du magasin.

La première fois que cette fonction est appelée, elle capture la valeur de toutes les références enregistrées. Les appels ultérieurs à fresh retourneront des instances initialisées à ces valeurs.

val with_store : store -> (unit -> 'a) -> 'a

with_store s f réinitialise toutes les références enregistrées à la valeur qu'elles ont dans s pour l'exécution de f . Si f met à jour l'une des références enregistrées, s est mis à jour pour se souvenir de ces changements.

val reset : unit -> unit

Réinitialise toutes les références à l'instantané initial (c'est-à-dire aux mêmes valeurs avec lesquelles les nouvelles instances commencent).

val is_bound : unit -> bool

Retourne true lorsqu'un magasin est actif (c'est-à-dire lorsqu'il est appelé depuis la fonction de rappel passée à Local_store.with_store ), false sinon.
