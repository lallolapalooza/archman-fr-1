NOM

Lire::Report::Entry - Interface aux données d'un sous-rapport.

SYNTAXE

foreach my $name ( $entry->names() ) {
    print "Nom : ", $name->{'content'}, "\n";
}
foreach my $value ( $entry->values() ) {
    if ( ref $value eq 'Lire::Report::Group' ) {
        # La valeur est un groupe
        foreach my $e ( $value->entries() ) {
            print_entry( $e );
        }
    } else {
        print "Valeur : ", $value->{'content'}, "\n";
    }
}

DESCRIPTION

Les objets Lire::Report::Entry sont utilisés pour contenir les données d'un sous-rapport.

CONSTRUCTEUR

On crée un nouvel objet Entry en utilisant la méthode create_entry sur un objet Lire::Report::Subreport ou Lire::Report::Group. Utilisez les méthodes add_name(), create_group() et add_value() pour remplir l'entrée.

MÉTHODES OBJET

row_idx()

Retourne l'index de ligne dans le corps du tableau où les données de cette entrée devraient être affichées. Si indéfini, cette entrée ne devrait pas être affichée.

subreport()

Retourne l'objet Lire::Report::Subreport dans lequel cette entrée est contenue.

group()

Retourne l'objet Lire::Report::Group qui contient cette entrée.

group_info()

Retourne les informations du groupe Lire::Report::GroupInfo qui contiennent les informations relatives au groupe dans lequel se trouve cette entrée.

data()

Retourne sous forme de tableau les données contenues dans cette entrée. C'est une liste de hachages ou d'objets Lire::Report::Group.

data_by_name( $name )

Retourne l'élément de données contenu dans cette Entrée qui a été généré par l'opérateur nommé $name. Retourne undef si aucun élément de données de ce type ne peut être trouvé.

names()

Retourne les noms de l'entrée. C'est un tableau de hachages. Le hachage du nom contient les clés suivantes :

type
Toujours défini à 'name'.
content
C'est le contenu réel de l'élément nom. Il contient le nom dans un format adapté à l'affichage.
value
Ceci contient la valeur non formatée du nom. Par exemple, lorsque le nom est une chaîne de temps, cet attribut contiendra le temps en secondes depuis l'époque.
missing_cases
Cette valeur contient le nombre d'enregistrements DLF qui avaient une valeur indéfinie dans l'un des champs requis pour calculer cette statistique.
range
Pour certains noms, le contenu réel exprime une plage (temps, taille, etc.). Cet attribut contient la longueur de la plage.
col_info
L'objet Lire::Report::ColumnInfo décrivant ce nom.

add_name( $content, [$value], [$range] )

Ajoute un nouveau nom à cette entrée. Consultez la documentation de la méthode names() pour une description de la signification des divers paramètres qui ont la même signification que les clés du même nom.

Les noms, valeurs et groupes doivent être ajoutés dans l'ordre spécifié par GroupInfo de cette entrée. Vous obtiendrez sinon une exception.

values()

Retourne les valeurs de l'entrée. C'est un tableau de hachages ou d'objets. Si la valeur est un hachage, elle a les clés suivantes :

type
Toujours défini à 'value'.
content
C'est le contenu réel de l'élément valeur. Il contient la valeur dans un format adapté à l'affichage.
value
Ceci contient la valeur non formatée. Par exemple, lorsque les octets sont affichés en utilisant "1M" ou "1.1G", ceci contiendra la valeur en octets.
missing_cases
Le nombre d'enregistrements DLF qui avaient une valeur indéfinie dans l'un des champs requis par cet opérateur.
total
Ceci est utilisé par les valeurs qui représentent une moyenne. Il contient le total qui compose la moyenne.
n
Ceci est utilisé par les valeurs qui représentent une moyenne. Il contient le total qui a été utilisé dans la division pour calculer la moyenne.
col_info
L'objet Lire::Report::ColumnInfo décrivant cette valeur.

groups()

Retourne dans un tableau les Lire::Report::Group contenus dans cette Entrée.

create_group()

Crée un nouveau groupe pour cette entrée. Cela l'ajoutera également aux données de cette entrée. Si vous créez le groupe dans le désordre par rapport aux noms et valeurs qui devraient se trouver dans cette entrée, vous obtiendrez une exception.

add_value( %value )

Ajoute une nouvelle valeur à cette entrée. Le hachage de valeur doit au moins contenir la clé 'content'. Il peut également inclure des valeurs pour les clés 'n', 'total' et 'missing_cases'. Consultez la documentation de la méthode values() pour une description de la signification des divers paramètres : ceux-ci ont la même signification que les clés du même nom.

Les noms, valeurs et groupes doivent être ajoutés dans l'ordre spécifié par GroupInfo de cette entrée. Vous obtiendrez sinon une exception.
