NOM

Locale::Maketext::Lexicon::Tie - Utiliser des hachages liés comme lexiques pour Maketext

VERSION

version 1.00

SYNOPIS

package Hello::I18N;
use base 'Locale::Maketext';
use Locale::Maketext::Lexicon {
    en => [ Tie => [ DB_File => 'en.db' ] ],
};

DESCRIPTION

Ce module vous permet de facilement lier (tie) le hachage %Lexicon à une base de données ou à d'autres sources de données. Il prend une référence de tableau d'arguments et les passe directement à tie().

Les entrées seront alors récupérées chaque fois qu'elles seront utilisées ; ce module ne les met pas en cache.
