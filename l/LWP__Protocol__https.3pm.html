NOM

LWP::Protocol::https - Fournit le support https pour LWP::UserAgent

SYNTAXE

use LWP::UserAgent;
$ua = LWP::UserAgent->new(ssl_opts => { verify_hostname => 1 });
$res = $ua->get("https://www.example.com");
# spécifier un chemin CA
$ua = LWP::UserAgent->new(
    ssl_opts => {
        SSL_ca_path     => '/etc/ssl/certs',
        verify_hostname => 1,
    }
);

DESCRIPTION

Le module LWP::Protocol::https fournit le support pour utiliser des URL avec le schéma https avec LWP. Ce module est un plug-in pour la gestion des protocoles de LWP, vous ne l'utilisez donc pas directement. Une fois le module installé, LWP est capable d'accéder à des sites utilisant HTTP sur SSL/TLS.

Si la vérification du nom d'hôte est demandée par les "ssl_opts" de LWP::UserAgent, et que ni "SSL_ca_file" ni "SSL_ca_path" n'est défini, alors "SSL_ca_file" est implicitement le fichier fourni par Mozilla::CA. Si le module Mozilla::CA n'est pas disponible, les requêtes SSL échoueront. Installez ce module, configurez un "SSL_ca_file" alternatif ou désactivez la vérification du nom d'hôte.

Ce module était auparavant inclus dans libwww-perl, mais il a été retiré à partir de la v6.02 afin de pouvoir déclarer correctement ses dépendances pour la chaîne d'outils CPAN. Les applications qui nécessitent le support https peuvent simplement déclarer leur dépendance envers LWP::Protocol::https et n'auront plus besoin de savoir quels modules sous-jacents installer.

VOIR AUSSI

IO::Socket::SSL, Crypt::SSLeay, Mozilla::CA
