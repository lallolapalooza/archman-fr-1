NAME

Locale::RecodeData::TIS_620 - Routines de conversion pour TIS-620

SYNOPSIS

Ce module est interne à libintl. Ne l'utilisez pas directement !

DESCRIPTION

Ce module contient les tables de conversion et routines pour TIS-620.

COMMENTS

Les commentaires suivants ont été extraits du charmap original :

version: 1.0
 sources: Thai Industrial Standards Institute, ECMA registry, IANA
alias TIS620
alias TIS620-0
alias TIS620.2529-1
alias TIS620.2533-0
alias ISO-IR-166

Veuillez noter que les alias mentionnés ci-dessus ne sont pas nécessairement valides !

NAME

Locale::RecodeData::TIS_620 - TIS-620 character mapping for Locale::Recode

SYNOPSIS

 use Locale::Recode 'recode';

 recode( 'TIS_620', $string )
 recode( \$from_encoding, \$to_encoding, \$string )

DESCRIPTION

This module provides the TIS-620 character mapping for the Locale::Recode module. TIS-620 is a character encoding for the Thai language.

COMMENTS

 THIS FILE IS GENERATED BY THE "encode_heap.pl" SCRIPT AND SHOULD NOT BE EDITED MANUALLY.
