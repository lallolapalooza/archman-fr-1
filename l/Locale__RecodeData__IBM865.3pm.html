Locale::RecodeData::IBM865(3pm) — Description

NOM

Locale::RecodeData::IBM865 - Table de conversion pour IBM-DOS 865 (Éclair-Nordique).

SYNOPIS

use Locale::RecodeData::IBM865;

DESCRIPTION

Cette page de manuel documente le module Locale::RecodeData::IBM865. Il implémente la table de conversion pour le jeu de caractères IBM-DOS 865 (Éclair-Nordique).

COMMENTAIRES

Les commentaires suivants sont tirés des fichiers sources :

  IBM865 « Éclair-Nordique » (également connu sous le nom de « PC-865 » ou « DOS-865 »)
  est un jeu de caractères qui prend en charge les langues nordiques (Danois,
  Norvégien, Suédois) et l'anglais.
  Ce jeu de caractères est une variante de code page 437, avec quelques
  modifications pour mieux supporter les langues mentionnées.
  La table de caractères est utilisée par le système d'exploitation DOS de
  Microsoft dans certaines configurations régionales.
