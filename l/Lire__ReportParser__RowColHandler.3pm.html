NOM

Lire::ReportParser::RowColHandler - Sous-classe de Lire::ReportParser qui synthétise les lignes

SYNOPSIS

Dans les processeurs de rapports XML :

package MonParser;
use base qw/Lire::ReportParser::RowColHandler/;
sub handle_header_row {
    my ( $self, $row ) = @_;
    ...
}
sub handle_row {
    my ( $self, $row ) = @_;
    ...
}
sub handle_table_summary {
    my ( $self, $nrecords, $row ) = @_;
    ....
}

DESCRIPTION

Le module Lire::ReportParser::RowColHandler est une sous-classe de Lire::ReportParser qui synthétisera les événements handle_row(). Cela rend plus facile l'écriture de sous-classes dont le seul but est de formater le rapport. Au lieu d'avoir à reconstruire la ligne du tableau à partir des divers événements entry_start, group_start, handle_name, la sous-classe n'a qu'à traiter les événements handle_row().

UTILISATION DE Lire::ReportParser::RowColHandler

Le client n'a qu'à hériter de Lire::ReportParser::RowColHandler. Ensuite, il peut définir les méthodes handle_row(), handle_header_row() et handle_table_summary().

Il existe un paramètre que RowColHandler accepte, il s'agit de "summary_when", qui spécifie quand l'événement handle_table_summary() sera synthétisé ( "before" ou "after" le corps du tableau.) Quand il est "before", l'événement sera généré après les événements header_row mais avant tout événement handle_row(). Sinon, il sera généré une fois que tous les événements handle_row() seront traités. La valeur par défaut est "before".

handle_table_summary( $nrecords, $row )

Appelé après que le résumé du tableau soit disponible (et selon le paramètre d'initialisation "summary_when"). $nrecords contient le nombre d'enregistrements utilisés pour calculer le rapport et $row est une référence de tableau vers la valeur du résumé du tableau. Le tableau $row contient autant d'éléments qu'il y a de colonnes dans le tableau. Seule la colonne numérique aura une valeur, les autres seront définies à undef.

Les valeurs de résumé sont des références de hachage contenant les mêmes valeurs que celles disponibles dans l'événement handle_summary_value() de Lire::ReportParser.

handle_header_row( $row )

Ceci sera appelé une fois pour chaque ligne d'en-tête présente. La première ligne d'en-tête contient toutes les colonnes numériques ainsi que la colonne catégorique principale.

$row est une référence de tableau contenant autant d'éléments qu'il y a de colonnes dans le tableau. Les étiquettes de colonnes qui ne devraient pas apparaître sur cette ligne sont undef. Les autres éléments contiendront l'objet Lire::Report::ColumnInfo associé.

handle_row( $row )

Cet événement sera appelé pour chaque ligne à afficher dans le tableau.

$row est une référence de tableau contenant les données qui devraient apparaître dans la ligne. Il contient autant d'éléments qu'il y a de colonnes définies dans le tableau. Les colonnes vides auront undef comme contenu. Les autres éléments seront une référence de hachage identique à ce qui serait reçu dans la méthode handle_name() ou handle_value() de Lire::ReportParser. La seule différence est que la valeur de résumé aura une clé "is_summary" définie à 1.

Dans le cas de colonnes fusionnées, l'élément de données sera dans l'élément col_start(). Les autres cellules seront undef.
