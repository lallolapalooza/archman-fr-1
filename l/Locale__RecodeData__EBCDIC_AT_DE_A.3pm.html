NOM

Locale::RecodeData::EBCDIC_AT_DE_A - Routines de conversion pour EBCDIC_AT_DE_A

SYNOPSIS

Ce module est interne à libintl. Ne l'utilisez pas directement !

DESCRIPTION

Ce module contient les tables de conversion et les routines pour EBCDIC-AT-DE-A.

COMMENTAIRES

Les commentaires suivants sont extraits de la charmap d'origine :

version: 1.0
 source: IBM 3270 Char Set Ref Ch 10, GA27-2837-9, avril 1987

Note : les alias mentionnés ci-dessus ne sont pas nécessairement valides !
