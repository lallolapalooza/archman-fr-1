NOM

Locale::RecodeData::IBM863 - Fonctions de conversion pour IBM863

SYNOPSIS

Ce module est interne à libintl. Ne l'utilisez pas directement !

DESCRIPTION

Ce module contient les tables de conversion et les fonctions pour IBM863.

COMMENTAIRES

Les observations suivantes ont été extraites du charmap original :

version: 1.0
 source: IBM Keyboard layouts and code pages, PN 07G4586 June 1991
alias CP863
alias 863

Note : Les alias mentionnés ci-dessus ne sont pas nécessairement valides !

NAME

Locale::RecodeData::IBM863 - IBM Code Page 863 (Canada-Multilingual).

SYNOPSIS

use Locale::Recode::IBM863;

DESCRIPTION

This module provides the necessary encoding and decoding subroutines for the IBM Code Page 863 character set.

The following table lists the characters supported by this encoding:
