NOM

Lire::Group - Classe de base pour l'implémentation de l'agrégateur de groupe

SYNTHÈSE

use Lire::Group;

DESCRIPTION

Ce module est la classe de base pour l'implémentation de l'agrégateur de groupe. Cet agrégateur divisera les enregistrements DLF en groupes ayant la même clé. La clé est composée d'un ou plusieurs champs non numériques. Le nombre de clés à conserver dans le rapport peut être configuré via l'attribut limit. Les clés peuvent également être triées en utilisant l'attribut sort.

CONSTRUCTEUR

new( %paramètres )

Crée une nouvelle instance d'un agrégateur de groupe. En plus des paramètres normaux de l'opérateur de rapport, l'attribut limit peut être initialisé au moment de la création.

MÉTHODES

limit( [$nouvelle_limite] )

Retourne le nombre de clés à afficher dans le rapport. Il peut s'agir d'un entier ou du nom d'un des paramètres de spécification du rapport (lorsqu'il commence par $).

L'attribut limit peut être modifié en passant un paramètre $nouvelle_limite.

sort_fields( [$nouveaux_champs_de_tri] )

Retourne les champs et/ou les valeurs d'opérateur qui seront utilisés pour trier les entrées générées par cet agrégateur. Il s'agit d'une référence de tableau contenant les noms des champs de groupe et/ou le nom des opérateurs.

Les champs de tri peuvent être modifiés en passant une nouvelle référence de tableau.

group_fields( [$nouveaux_champs] )

Retourne sous forme de référence à un tableau d'objets Lire::GroupField les champs DLF utilisés pour grouper les enregistrements.

Si $nouveaux_champs est défini, les champs DLF utilisés pour grouper les enregistrements seront modifiés. Ce paramètre devrait être une référence à un tableau d'objets Lire::GroupField.

binary_insert

Fonction récursive qui utilise une recherche binaire pour insérer $item dans $array en utilisant $cmp comme opérateur de comparaison. $first_idx et $max_idx spécifient les limites de la recherche. La recherche se termine lorsque $first_idx == $max_idx ou lorsque $sort_key trie à ou avant $first_idx ou à ou après $max_idx.

VOIR AUSSI

Lire::ReportOperator(3pm)
