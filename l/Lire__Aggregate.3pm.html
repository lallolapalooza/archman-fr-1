NAME

Lire::Aggregate - Classe de base pour tous les opérateurs calculant des valeurs à partir d'un groupe d'enregistrements DLF

SYNOPSIS

use Lire::Aggregate;

DESCRIPTION

Lire::Aggregate est la classe de base pour tous les opérateurs calculant des valeurs à partir d'un groupe d'enregistrements DLF. Ce sont les opérateurs utilisés au sein des agrégateurs.

Ce paquet définit également la plupart des classes représentant les opérateurs d'agrégation disponibles dans la spécification de rapport de Lire.

MÉTHODES POUR LES SOUS-CLASSES DE Aggregate

init( %params )

Deux paramètres supplémentaires sont nécessaires pour les Agrégateurs :

parent
Le Lire::Aggregator contenant cet Aggregate.
name
Un identifiant utilisable pour trouver cet opérateur dans la spécification du rapport. Il est retourné par la méthode name().

print( $fh, $prefix)

Cette méthode implémente la méthode print() requise par Lire::ReportOperator. Elle imprime un élément XML vide nommé d'après le op(). Elle s'occupera également d'écrire les attributs name et label. D'autres attributs peuvent être ajoutés à cet élément XML en surchargeant la méthode xml_attrs().

xml_attrs()

Cette méthode peut être utilisée pour ajouter des attributs XML supplémentaires. Le texte retourné sera affiché dans l'élément XML.

set_name( $name )

Change le nom de cet opérateur.

create_numerical_info( $group_info )

Les sous-classes doivent implémenter cette méthode.

Le paramètre $group_info est un objet Lire::Report::GroupInfo, à partir duquel l'implémentation de l'opérateur doit ajouter l'objet ColumnInfo approprié pour représenter les données générées par cet agrégateur.

build_query( $query )

FIXME.

Implémente la fonction build_query par défaut.

set_missing_cases_aggr_expr( $query )

Ajoute l'expression d'agrégation qui calcule le nombre de cas manquants sur la base des champs requis retournés par la méthode sql_required_fields() de l'opérateur.

La méthode set_missing_cases_value() peut être utilisée pour définir la valeur à partir de la ligne DLF retournée par la requête.

set_missing_cases_value( $row, $value )

Définit la valeur des cas manquants à $value à partir de la valeur calculée par l'expression utilisée dans set_missing_cases_aggr_expr().

sql_aggr_expr()

Cette méthode est utilisée par l'implémentation par défaut de build_query(). Elle doit retourner l'expression d'agrégation SQL associée au nom de cet Aggregate. Par exemple, une implémentation simple de Count pourrait retourner 'count(*)' ici.

sql_required_fields()

Cette méthode est utilisée par set_missing_cases_aggr_expr() pour définir une expression d'agrégation qui retournera le nombre de cas manquants pour cet agrégateur. Elle doit retourner une liste de champs qui créeront un cas manquant lorsqu'une valeur est NULL.

create_value( $parent_group, $row )

Cette méthode est utilisée par l'Aggregator lors de la construction du tableau de rapport. Le rapport doit retourner une référence de hachage avec les clés appropriées définies. Voir Lire::Report::Entry(3pm) pour les détails.

Le paramètre $parent_group est le Lire::Report::Group auquel la valeur est ajoutée. Ce sera la table ou le groupe contenant les valeurs ajoutées aux entrées, et ce sera le groupe parent lors de la création d'une valeur résumée.

Le paramètre $row est une référence de hachage contenant la ligne DlfResult pour laquelle la valeur est créée.

L'implémentation doit utiliser la méthode set_missing_cases_value() pour définir la valeur de la propriété 'missing_cases' de l'objet.
