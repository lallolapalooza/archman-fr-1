NOM

Locale::RecodeData::EBCDIC_CA_FR - Routines de conversion pour EBCDIC_CA_FR

SYNTAXE

Ce module est interne à libintl. Ne l'utilisez pas directement !

DESCRIPTION

Ce module contient les tables de conversion et routines pour EBCDIC-CA-FR.

COMMENTAIRES

Les commentaires suivants ont été extraits du charmap original :

 version: 1.0
 source: IBM 3270 Char Set Ref Ch 10, GA27-2837-9, April 1987

Veuillez noter que les alias mentionnés ci-dessus ne sont pas nécessairement valides !
