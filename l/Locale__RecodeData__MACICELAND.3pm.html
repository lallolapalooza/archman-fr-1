NOM

Locale::RecodeData::MACICELAND - Routines de conversion pour MACICELAND

SYNTAXE

Ce module est interne à libintl. Ne l'utilisez pas directement !

DESCRIPTION

Ce module est généré et contient les tables et routines de conversion pour MACICELAND.
