NOM

Lire::ReportOperator - Classe de base pour tous les opérateurs pouvant être utilisés pour calculer des rapports

SYNTAXE

print $op->name(), "\n";
print $op->op(), "\n";
print $op->label(), "\n";

DESCRIPTION

Lire::ReportOperator est la classe de base pour tous les opérateurs pouvant être utilisés pour calculer les données apparaissant dans les rapports de Lire. Cette classe fournit uniquement le comportement commun à tous les opérateurs.

Actuellement, les opérateurs définis dans Lire se présentent en deux variétés principales : premièrement, il y a les agrégateurs qui sont des opérateurs pouvant diviser les enregistrements DLF en plusieurs groupes, deuxièmement, il y a les opérateurs de groupe qui peuvent calculer des données basées sur un groupe d'enregistrements DLF. Les agrégateurs sont des sous-classes de Lire::Aggregator et les opérations de groupe sont des sous-classes de Lire::Aggregate.

MÉTHODES

op()

Retourne le nom de l'élément XML qui fait référence à cet opérateur.

report_spec()

Retourne l'objet Lire::ReportSpec dans lequel se trouve cet opérateur.

parent()

Retourne le parent de cet opérateur. Ce sera indéfini pour l'agrégateur de niveau supérieur dans la spécification du rapport. Seuls les Lire::Aggregator peuvent avoir des enfants et ainsi être un parent.

last_parent()

Retourne notre parent de niveau supérieur.

name( [$nouveau_nom] )

Retourne le nom de cet opérateur dans la spécification de rapport actuelle. Le nom de l'opérateur est un identifiant qui doit être unique dans une spécification de rapport donnée. Ce nom sera utilisé pour identifier les valeurs générées par cet opérateur dans le rapport généré.

Si $nouveau_nom est défini, le nom de cet opérateur sera changé à cette nouvelle valeur.

has_label()

Retourne vrai si cet opérateur a une étiquette explicite attribuée.

label( [$nouvelle_étiquette] )

Retourne ce qui doit être utilisé comme étiquette de colonne pour les données générées par cet opérateur.

Si le deuxième argument est défini, l'étiquette de colonne sera définie à cette nouvelle valeur.

MÉTHODES POUR LES SOUS-CLASSES

Les sous-classes doivent utiliser une table de hachage pour représenter les données de leur instance. Elles doivent appeler init() depuis leur méthode constructeur.

init( %params )

Lire::Report est une classe abstraite qui ne devrait pas être instanciée directement. Les sous-classes devraient appeler la méthode init() dans leur constructeur. Cette méthode initialise les attributs communs à tous les opérateurs. Les clés %params qui doivent être définies sont :

op
Le type d'opérateur. C'est le nom de l'élément XML. C'est un paramètre obligatoire.
parent
Le parent de cet opérateur. Il doit être présent sauf si l'élément est l'agrégateur de niveau supérieur.
report_spec
La spécification de rapport dans laquelle cet opérateur est ajouté.
label
L'étiquette de cet opérateur. C'est une information optionnelle.

Cette méthode retourne l'objet.

print( $fh, $préfixe )

C'est la méthode qui est appelée pour écrire une représentation XML de cet opérateur.

$fh est le descripteur de fichier sur lequel écrire la représentation XML. $indent est un entier qui donne le nombre d'espaces qui devraient être utilisés comme indentation lors de l'écriture du XML.

build_query( $requête )

API DE FUSION

Les méthodes devraient être implémentées pour supporter la fusion des données générées par cet opérateur à partir de deux rapports.

init_merge()

Cette méthode est appelée une fois avant que la fusion des rapports XML ne commence.

end_merge()

Cette méthode est appelée une fois après que tous les rapports XML ont été fusionnés.

init_group_data()

Cette méthode doit retourner une structure de données qui sera passée à l'appel de update_group_data() et merge_group_data(). Il y aura une telle structure de données pour chaque groupe qui existe dans l'agrégateur contenant cet opérateur.

Il y a quelques restrictions placées sur cette structure de données afin d'assurer qu'elle puisse être triée par l'agrégateur qui doit trier ses entrées. Si la structure de données est

SCALAR
Cette valeur peut être utilisée à des fins de tri.
RÉFÉRENCE SCALAIRE
La valeur scalaire sera utilisée comme clé de tri.
ARRAY
Le premier élément de la référence de tableau sera utilisé comme clé de tri.
HASH
Les éléments "sort_value" dans le hash seront utilisés comme clé de tri.
OBJET
La valeur retournée par la méthode sort_value() sera utilisée comme clé de tri.

Une fonction group_data_value() peut être utilisée pour extraire la valeur de la clé de tri selon ces règles. Elle peut être importée :

use Lire::ReportOperator qw/group_data_value/;
my $v = group_data_value( $data );

merge_group_data( $valeur, $données )

Cette méthode sera appelée une fois pour chaque valeur générée par cet opérateur dans les rapports XML à fusionner.

Le paramètre $valeur peut être soit une référence de table de hachage, soit un objet Lire::Report::Group. Ce sera la même chose que ce qui a été généré par cet opérateur.

$données est la structure de données de groupe retournée par init_group_data() pour le groupe dans lequel ce $valeur doit être fusionné.

end_group_data( $données )

Cette méthode sera appelée une fois pour chaque groupe qui a été créé par l'agrégateur contenant cet opérateur. Le paramètre $données est la structure de données qui a été retournée par init_group_data() pour le groupe courant.

Une utilisation possible de cette méthode serait, par exemple, pour l'opérateur `avg` de calculer la moyenne réelle car elle ne peut pas être effectuée tant que tous les enregistrements ne sont pas traités.

add_entry_value( $entrée, $données )

Cette méthode sera appelée une fois pour chaque groupe créé par l'agrégateur. Dans cette méthode, l'opérateur doit ajouter le nom et/ou la valeur appropriés pour cette entrée. $entrée est l'objet Lire::Report::Entry auquel les noms et/ou valeurs doivent être ajoutés. $données est la structure de données retournée par init_group_data() correspondant au groupe courant.

Par exemple, c'est dans cette méthode que l'opérateur `sum` ajoutera la valeur contenant la somme pour l'entrée courante.

group_data_value($données)

Retourne la « valeur » d'un élément de données créé par une méthode init_group_data(). C'est une fonction et non une méthode.
