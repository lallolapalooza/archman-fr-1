NOM

Lire::Count - Classe Lire qui implémente l'opérateur count

SYNOPSIS

use Lire::Count

DESCRIPTION

Classe qui implémente l'opérateur count. Cet opérateur compte le nombre d'enregistrements DLF dans le groupe courant.

Si l'attribut fields est défini, les statistiques de count seront égales au nombre de valeurs différentes présentes dans les champs spécifiés par cet attribut.

Il est également possible d'exprimer le count comme un ratio du count total pour le groupe ou la table.

MÉTHODES

new( %params )

Crée un nouvel objet Lire::Count. En plus des valeurs supportées par ses parents, les attributs fields et ratio seront initialisés aux valeurs spécifiées dans l'argument %params.

fields( [$nouveaux_champs] )

Retourne les champs pour lesquels nous comptons les valeurs différentes. C'est une référence vers un tableau de noms de champs DLF.

Si le paramètre $nouveaux_champs est défini, il sera utilisé comme nouvelle valeur de $fields. Il doit s'agir d'une référence de tableau et ne doit contenir que des noms de champs valides pour le schéma de la spécification de rapport actuelle.

ratio([$nouveau_ratio])

Retourne comment le count sera exprimé. Cela peut être l'une des trois valeurs possibles :

aucun
Défaut. Le count absolu sera utilisé.
groupe
Le count sera exprimé en pourcentage du count du groupe.
table
Le count sera exprimé en pourcentage du count total de la table.
