Nom

Locale::RecodeData::IBM437 - Routines de conversion pour IBM437

SYNTAXE

Ce module est interne à libintl. Ne l'utilisez pas directement !

DESCRIPTION

Ce module contient les tables de conversion et les routines pour IBM437.

COMMENTAIRES

Les commentaires suivants ont été extraits du charmap original :

version: 1.0
 source: IBM NLS RM Vol2 SE09-8002-01, Mars 1990
 alias CP437
 alias 437

Note : les alias mentionnés ci-dessus ne sont pas forcément valides !
