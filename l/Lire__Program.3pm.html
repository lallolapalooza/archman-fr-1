NOM

Lire::Program - Infrastructure commune des programmes de Lire.

SYNTAXE

N'importe quel programme :

use Lire::Program qw/ :msg /;
lr_info( "doing stuff " );
lr_debug( "debugging information" );
lr_warn( "encountered unexpected value: ", $value );
open( CFGFILE, "my.conf" ) or lr_err( "open error: ", $! );

DESCRIPTION

Ce module doit être utilisé par tous les programmes Lire (du moins les programmes Perl :-)).

Il inclut :

1.
Un comportement commun pour une bonne intégration dans la suite Lire. (Sortie d'informations de performance et autres).
2.
Des fonctions pour la portabilité.
3.
Des fonctions de journalisation.

COMPORTEMENT COMMUN POUR LES PROGRAMMES LIRE

Lorsque vous utilisez le module Lire::Program, vous vous assurez que votre programme se comportera correctement dans la chaîne d'outils Lire. Ce module installera des blocs BEGIN et END pour se conformer à la politique de Lire.

1.
Seuls les messages au format de journalisation approprié 
I<superservice> I<service> I<lr_id> I<program> I<level> I<msg>

doivent être affichés. Ce module installera un gestionnaire de signal __WARN__ qui garantit que tous les modules utilisant `warn` pour afficher des messages sont réécrits dans le bon format.

Voir aussi lr_run(1).

2.
Tous les programmes doivent commencer par un message "info" qui enregistre leurs arguments. Ce module s'en charge.
3.
Tous les programmes doivent se terminer en affichant des messages "info" avec des statistiques de performance et le message 'ended'. L'utilisation de ce module s'en charge. À la fin de votre programme, ce qui suit sera affiché (sans les informations communes) : 
memory stats: vsize=10688K rss=9380K majflt=406
elapsed time in seconds real=9 user=8.72 system=0.06
stopped

Les informations de profilage mémoire ne seront affichées que sur les plates-formes exécutant le noyau Linux.

VARIABLES COMMUNES

Par commodité, vous pouvez importer dans votre espace de noms en utilisant la balise :env certaines variables communes à tous les programmes Lire. (Notez que vous pouvez également utiliser ces variables sans les importer en les préfixant avec le namespace Lire::Program::).

$PROG
Le nom de votre programme (c'est la valeur de $0 sans le chemin du répertoire).
$LR_SUPERSERVICE
Le superservice que vous traitez, ou "all" si cette information n'est pas disponible.
$LR_SERVICE
Le service que vous traitez, ou "all" si cette information n'est pas spécifiée.
$LR_ID
C'est l'identifiant de la tâche. Il doit être partagé par toutes les commandes d'une tâche Lire. C'est la valeur UNSET lorsqu'aucun n'a été spécifié.
$LR_TAG
C'est le préfixe de tous les messages de journalisation. Devrait correspondre à 
$LR_SUPERSERVICE $LR_SERVICE $LR_ID $PROG
.

FONCTIONS DE JOURNALISATION

Les fonctions de journalisation font maintenant partie du module Lire::Logger. Consultez Lire::Logger(3pm) pour plus d'informations. Les anciens noms sont toujours exportés de ce module en utilisant la balise ':msg'.

FONCTIONS CONVERTISSEURS DLF

L'API du convertisseur DLF est maintenant définie dans Lire::DlfConverter(3pm). Le Lire::OldDlfAdapter(3pm) peut être utilisé pour travailler avec des convertisseurs DLF de style ancien.

VOIR AUSSI

Lire::DlfSchema(3pm), lr_run(1)
