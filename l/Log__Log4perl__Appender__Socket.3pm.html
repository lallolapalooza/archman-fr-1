NOM

Log::Log4perl::Appender::Socket - Journaliser vers un socket

SYNOPIS

use Log::Log4perl::Appender::Socket;
my $appender = Log::Log4perl::Appender::Socket->new(
  PeerAddr => "serveur.foo.com",
  PeerPort => 1234,
);
$appender->log(message => "Journalise-moi\n");

DESCRIPTION

Ceci est un simple appender pour écrire sur un socket. Il s'appuie sur IO::Socket::INET et offre tous les paramètres que ce module propose.

Lors de la destruction de l'objet, les messages en attente seront vidés et le socket sera fermé.

Si l'appender ne parvient pas à contacter le serveur lors de la phase d'initialisation (lors de l'exécution du constructeur "new"), il mourra() (die).

Si l'appender échoue à journaliser un message parce que la méthode send() du socket échoue (très probablement parce que le serveur est tombé), il tentera de se reconnecter une fois. S'il réussit, le message sera envoyé. Si la reconnexion échoue, un avertissement est envoyé sur STDERR et la méthode log() retourne, jetant le message.

Si l'option "silent_recovery" est donnée au constructeur et définie à une valeur vraie, le comportement est différent: Si la connexion socket ne peut être établie au moment de l'initialisation, un simple avertissement est émis. Chaque tentative de journalisation tentera alors d'établir la connexion et jettera le message silencieusement si elle échoue. Si vous ne souhaitez même pas l'avertissement, définissez l'option "no_warning" à une valeur vraie.

Se connecter au moment de l'initialisation peut ne pas être la meilleure option lors de l'exécution sous Apache1 Apache2/prefork, car le processus parent crée le socket et les connexions sont partagées entre les enfants (children) issus du fork--tous les enfants écrivant sur le même socket pourraient intermêler les messages. Donc, au lieu de cela, vous pouvez utiliser "defer_connection" qui retardera la connexion jusqu'à ce que le premier message de journalisation soit envoyé.

EXEMPLE

Écrivez rapidement un serveur en utilisant le module IO::Socket::INET :

use IO::Socket::INET;
my $sock = IO::Socket::INET->new(
    Listen    => 5,
    LocalAddr => 'localhost',
    LocalPort => 12345,
    Proto     => 'tcp');
while(my $client = $sock->accept()) {
    print "Client connecté\n";
    while(<$client>) {
        print "$_\n";
    }
}

Démarrez-le, puis exécutez le script suivant en tant que client :

use Log::Log4perl qw(:easy);
my $conf = q{
    log4perl.category                  = WARN, Socket
    log4perl.appender.Socket           = Log::Log4perl::Appender::Socket
    log4perl.appender.Socket.PeerAddr  = localhost
    log4perl.appender.Socket.PeerPort  = 12345
    log4perl.appender.Socket.layout    = SimpleLayout
};
Log::Log4perl->init(\$conf);
sleep(2);
for(1..10) {
    ERROR("Coin!");
    sleep(5);
}
