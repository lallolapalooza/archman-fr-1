NOM

Lire::Timegroup - Classe de base pour l'implémentation de l'agrégateur de créneaux horaires

SYNTAXE

use Lire::Timeslot;

DESCRIPTION

Ce module est la classe de base pour l'implémentation de l'agrégateur de créneaux horaires. Cet agrégateur divisera les enregistrements DLF en fonction d'une unité de temps. Par exemple, si l'unité est 1h, tous les enregistrements DLF survenant à la même heure de la journée (indépendamment du jour où cela se produit) seront regroupés ensemble.

CONSTRUCTEUR

new( %params )

Crée une nouvelle instance d'un agrégateur de groupe horaire. En plus des paramètres normaux de l'opérateur de rapport, l'agrégateur de groupe horaire peut prendre plusieurs paramètres :

champ
Ce paramètre optionnel contient le champ DLF qui contient la valeur temporelle utilisée pour grouper les enregistrements DLF. Voir la méthode champ() pour plus d'informations.
unite
Ce paramètre obligatoire doit contenir l'unité de temps qui sera utilisée pour grouper les enregistrements. Voir la méthode unite() pour plus d'informations.

MÉTHODES

champ( [$nouveau_champ] )

Retourne le nom du champ DLF utilisé pour grouper les enregistrements DLF. Il doit s'agir d'un champ DLF horodaté valide dans le schéma actuel. Par défaut, le champ horodaté par défaut du schéma DLF est utilisé.

Vous pouvez changer le champ en passant un paramètre $nouveau_champ.

unite( [$nouvelle_unite])

Retourne l'unité de temps qui sera utilisée pour grouper les enregistrements DLF. L'unité est exprimée comme une valeur de durée (par exemple 1s), mais il convient de noter que cela groupera les enregistrements en fonction de l'unité de seconde de la valeur de l'horodatage de l'enregistrement DLF. Il peut également s'agir du nom d'un paramètre de spécification de rapport contenant une valeur de durée.

L'unité de temps peut être changée en utilisant le paramètre $nouvelle_unite.
