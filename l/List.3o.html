Opérations sur les listes.

Certaines fonctions sont marquées comme non récursives terminales. Une fonction récursive terminale utilise un espace de pile constant, tandis qu'une fonction non récursive terminale utilise un espace de pile proportionnel à la taille de la liste d'entrée, ce qui peut être problématique pour de très longues listes. Lorsque plusieurs arguments de liste sont passés, une formule approximative est affichée donnant l'utilisation de la pile (dans une unité constante spécifiée).

Les considérations ci-dessus peuvent généralement être ignorées si vos listes ne contiennent pas plus de 10000 éléments.

La version étiquetée de ce module peut être utilisée comme décrit dans le module StdLabels.

val length : 'a list -> int

Retourne la longueur (nombre d'éléments) de la liste donnée.

val compare_lengths : 'a list -> 'b list -> int

Compare les longueurs de deux listes. compare_lengths l1 l2 est équivalent à compare (length l1) (length l2), sauf que le calcul s'arrête après avoir atteint la fin de la liste la plus courte.

Since 4.05

val compare_length_with : 'a list -> int -> int

Compare la longueur d'une liste à un entier. compare_length_with l len est équivalent à compare (length l) len, sauf que le calcul s'arrête après au plus len itérations sur la liste.

Since 4.05

val is_empty : 'a list -> bool

is_empty l est vrai si et seulement si l n'a aucun élément. C'est équivalent à compare_length_with l 0 = 0 .

val append : 'a list -> 'a list -> 'a list

append l0 l1 ajoute l1 à l0. Fonction équivalente à l'opérateur infixe @.

rev_append l1 l2 inverse l1 et concatène avec l2. C'est équivalent à (List.rev l1) @ l2 .

val concat : 'a list list -> 'a list

Concatène une liste de listes. Les éléments de l'entrée sont concaténés (dans le même ordre) pour donner le résultat. N'est pas récursive terminale (longueur de l'entrée + longueur de la sous-liste la plus longue).

Est équivalent à List.concat. N'est pas récursive terminale (longueur de l'entrée + longueur de la sous-liste la plus longue).

Comparaison

val equal : ('a -> 'a -> bool) -> 'a list -> 'a list -> bool

equal eq [a1; ...; an] [b1; ..; bm] est vrai lorsque les deux listes d'entrée ont la même taille, et pour chaque paire d'éléments ai et bi à la même position, on a eq ai bi .

Note : eq peut être appelé même si les listes ont des tailles différentes. Si vous savez que votre fonction d'égalité est coûteuse, il peut être utile de vérifier d'abord List.compare_lengths.

Since 4.12

val compare : ('a -> 'a -> int) -> 'a list -> 'a list -> int

compare cmp [a1; ...; an] [b1; ...; bm] compare lexicographiquement les deux listes d'entrée, en utilisant la même interface 'a -> 'a -> int que compare :

- a1 :: l1 est plus petit que a2 :: l2 (résultat négatif) si a1 est plus petit que a2, ou si ils sont égaux (résultat 0) et l1 est plus petit que l2. - La liste vide [] est plus petite que les listes non vides.

Note : cmp sera appelé même si les listes ont des tailles différentes.

val for_all : ('a -> bool) -> 'a list -> bool

for_all f [a1; ...; an] vérifie si tous les éléments de la liste satisfont le prédicat f. Autrement dit, renvoie (f a1) && (f a2) && ... && (f an) pour une liste non vide et true si la liste est vide.

val exists : ('a -> bool) -> 'a list -> bool

exists f [a1; ...; an] vérifie si au moins un des éléments de la liste satisfait le prédicat f. Autrement dit, renvoie (f a1) || (f a2) || ... || (f an) pour une liste non vide et false si la liste est vide.

val for_all2 : ('a -> 'b -> bool) -> 'a list -> 'b list -> bool

Est identique à List.for_all, mais pour un prédicat à deux arguments.

Raises Invalid_argument si les deux listes ont une longueur différente.

val exists2 : ('a -> 'b -> bool) -> 'a list -> 'b list -> bool

Est identique à List.exists, mais pour un prédicat à deux arguments.

Raises Invalid_argument si les deux listes ont une longueur différente.

Est identique à List.mem, mais utilise l'égalité physique au lieu de l'égalité structurelle pour comparer les éléments de la liste.

Depuis 5.3

val partition : ('a -> bool) -> 'a list -> 'a list * 'a list

partition f l renvoie une paire de listes (l1, l2), où l1 est la liste de tous les éléments de l satisfaisant le prédicat f, et l2 est la liste de tous les éléments de l ne satisfaisant pas f. L'ordre des éléments dans la liste d'entrée est conservé.

val partition_map : ('a -> ('b, 'c) Either.t) -> 'a list -> 'b list * 'c list

partition_map f l renvoie une paire de listes (l1, l2) telle que, pour chaque élément x de la liste d'entrée l :

- si f x est Left y1, alors y1 est dans l1, et

- si f x est Right y2, alors y2 est dans l2.

Les éléments de sortie sont inclus dans l1 et l2 dans la même relation d'ordre que les éléments correspondants dans l.

En particulier, partition_map (fun x -> if f x then Left x else Right x) l est équivalent à partition f l.

NAME

List – Operations on lists.

Module

List

Documentation

This module provides functions for manipulating lists. The lists are immutable, all functions return new lists.

The functions are not generally tail-recursive. For example, List.map performs a traversal of the list. If the function applied to each element is not tail-recursive, the whole computation might not be tail-recursive.

The comparison functions used in List.sort, List.stable_sort, List.fast_sort, List.sort_uniq and List.merge are called with arguments (x, y) such that x is one of the elements and y is the element immediately preceding it in the original list, or the first element of the list, or an element already placed in the result. The comparison function must return 0 if its arguments compare as equal, a positive integer if the first argument is greater than the second, and a negative integer if the first argument is less than the second.

Exception Invalid_argument

Raised when arguments are out of bounds.

val fold_right : ('a -> 'b -> 'b) -> 'a list -> 'b -> 'b

Same as List.fold_left, but folds from right to left.

val fold_map : (int -> 'a -> 'b -> 'a * 'c option) -> 'a -> 'b list -> 'a * 'c list option

A map coupled with a fold. The fold function takes the current accumulator, the index, and the element. It returns a pair of the new accumulator and the mapped element. If the mapped element is None the traversal stops and returns None.

Sorting

val sort : ('a -> 'a -> int) -> 'a list -> 'a list

Sort a list in increasing order according to a comparison function. The comparison function must return 0 if its arguments compare as equal, a positive integer if the first is greater, and a negative integer if the first is smaller (see Array.sort for a complete specification). For example, compare is a suitable comparison function. The resulting list is sorted in increasing order. List.sort is guaranteed to run in constant heap space (in addition to the size of the result list) and logarithmic stack space.

The current implementation uses Merge Sort. It runs in constant heap space and logarithmic stack space.

val stable_sort : ('a -> 'a -> int) -> 'a list -> 'a list

Same as List.sort , but the sorting algorithm is guaranteed to be stable (i.e. elements that compare equal are kept in their original order).

The current implementation uses Merge Sort. It runs in constant heap space and logarithmic stack space.

val fast_sort : ('a -> 'a -> int) -> 'a list -> 'a list

Same as List.sort or List.stable_sort , whichever is faster on typical input.

val sort_uniq : ('a -> 'a -> int) -> 'a list -> 'a list

Same as List.sort , but also remove duplicates: if multiple elements compare equal, keep only the first.

Before5.4 the element kept was not necessarily the first one.

Since 4.02 (4.03 in ListLabels)

val merge : ('a -> 'a -> int) -> 'a list -> 'a list -> 'a list

Merge two lists: Assuming that l1 and l2 are sorted according to the comparison function cmp , merge cmp l1 l2 will return a sorted list containing all the elements of l1 and l2 . If several elements compare equal, the elements of l1 will be before the elements of l2 . Not tail-recursive (sum of the lengths of the arguments).
