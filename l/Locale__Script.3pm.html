NOM

Locale::Script - module pour traiter les ensembles de codes de script

SYNTAXE

use Locale::Script;
$name = code2script(CODE);
$code = script2code(NAME);
@codes   = all_script_codes();
@names   = all_script_names();

DESCRIPTION

Ce module fournit un accès aux ensembles de codes de script.

Veuillez consulter le document Locale::Codes::Types pour une description des ensembles de codes disponibles.

La plupart des routines acceptent un argument supplémentaire facultatif qui spécifie l'ensemble de codes à utiliser. L'ensemble de codes peut être spécifié en utilisant le nom d'un ensemble de codes, ou la constante perl spécifiée dans le document ci-dessus. Si non spécifié, l'ensemble de codes par défaut sera utilisé.

ROUTINES

Toutes les routines de ce module appellent la méthode appropriée dans le module Locale::Codes, en utilisant un objet de type : script Veuillez vous reporter à la documentation du module Locale::Codes pour plus de détails sur chaque fonction.

Les fonctions suivantes sont exportées automatiquement :

code2script(CODE [,CODESET] [,'retired'])
Voir code2name dans Locale::Codes
code2scripts(CODE [,CODESET])
Voir code2names dans Locale::Codes
script2code(NOM [,CODESET] [,'retired'])
Voir name2code dans Locale::Codes
script_code2code(CODE ,CODESET ,CODESET2)
Voir code2code dans Locale::Codes
all_script_codes([CODESET] [,'retired'])
Voir all_codes dans Locale::Codes
all_script_names([CODESET] [,'retired'])
Voir all_names dans Locale::Codes

Les fonctions suivantes ne sont pas exportées et doivent être appelées entièrement qualifiées avec le nom du package :

Locale::Script::show_errors(FLAG)
Par défaut, une entrée invalide produira des résultats vides, mais aucune erreur. En passant une valeur non nulle pour FLAG, des erreurs seront produites.

Voir show_errors dans Locale::Codes mais notez que le défaut pour les modules non-OO est de NE PAS produire d'erreurs.

Locale::Script::rename_script(CODE ,NOUVEAU_NOM [,CODESET])
Voir rename_code dans Locale::Codes
Locale::Script::add_script(CODE ,NOM [,CODESET])
Voir add_code dans Locale::Codes
Locale::Script::delete_script(CODE [,CODESET])
Voir delete_code dans Locale::Codes
Locale::Script::add_script_alias(NOM ,NOUVEAU_NOM)
Voir add_alias dans Locale::Codes
Locale::Script::delete_script_alias(NOM)
Voir delete_alias dans Locale::Codes
Locale::Script::rename_script_code(CODE ,NOUVEAU_CODE [,CODESET])
Voir replace_code dans Locale::Codes
Locale::Script::add_script_code_alias(CODE ,NOUVEAU_CODE [,CODESET])
Voir add_code_alias dans Locale::Codes
Locale::Script::delete_script_code_alias(CODE [,CODESET])
Voir delete_code_alias dans Locale::Codes
