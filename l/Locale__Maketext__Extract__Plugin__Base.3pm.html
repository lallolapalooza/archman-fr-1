NOM

Locale::Maketext::Extract::Plugin::Base - Module de base pour les plugins d'extraction de format

VERSION

version 1.00

SYNOPSIS

package My::Parser::Plugin;
use base qw(Locale::Maketext::Extract::Plugin::Base);
sub file_types {
    return [qw( ext ext2 )]
}
sub extract {
    my $self = shift;
    local $_ = shift;
    my $line = 1;
    while (my $found = $self->routine_to_extract_strings) {
        $self->add_entry($str,[$filename,$line,$vars])
    }
    return;
}

DESCRIPTION

Tous les plugins d'analyse de format dans Locale::Maketext::Extract héritent de Locale::Maketext::Extract::Plugin::Base.

Si vous souhaitez écrire votre propre plugin d'analyse personnalisé, vous devrez hériter de ce module et fournir les méthodes file_types() et extract(), comme indiqué ci-dessus.

MÉTHODES

new()
$plugin = My::Parser->new(
    @file_types         # Facultativement, spécifier une liste de types de fichiers reconnus
)
add_entry()
$plugin->add_entry($str,$line,$vars)
entries()
$entries = $plugin->entries;
clear()
$plugin->clear

Efface toutes les entrées stockées.

file_types()
@default_file_types = $plugin->file_types

Retourne une liste de types de fichiers que votre module sait analyser.

Chaque type de fichier peut être l'un des suivants :

  • Une chaîne de caractères simple 
    'pl'  => le nom du fichier correspond à qr/\.pl$/
'*'   => tous les fichiers sont acceptés
  • Une expression régulière 
    qr/\.tt2?\./ => le nom du fichier correspond à cette expression régulière
  • Un coderef 
    sub {}  => ce coderef est appelé comme $coderef->($base_filename,$path_to_file)
           Il doit retourner vrai ou faux
extract()
$plugin->extract($filecontents);

La méthode extract() est appelée pour traiter le contenu du fichier actuel.

Lorsqu'elle trouve une chaîne qui doit être extraite, elle doit appeler

$self->add_entry($string,$line,$vars])

où $vars fait référence à tous les arguments passés à la fonction de localisation. Par exemple :

l("You found [quant,_1,file,files]",files_found)
  string: "You found [quant,_1,file,files]"
  vars  : (files_found)

IMPORTANT : Une seule instance de plugin est utilisée pour tous les fichiers, donc si vous prévoyez de stocker des informations d'état dans l'objet $plugin, vous devez les effacer au début de extract()

known_file_type()
if ($plugin->known_file_type($filename_with_path)) {
    ...
}

Détermine si le fichier actuel doit être traité par cet analyseur, en fonction de la liste des types de fichiers spécifiée lors de la création de cet objet ou des types de fichiers par défaut du module.
