NOM

Lire::WELF - Implémentation de base d'un analyseur de format de journal WebTrends(tm) Enhanced

SYNTAXE

use Lire::WELF;

my $parser = new Lire::WELF;

my $welf_rec = $parser->parse( $line );

DESCRIPTION

Ce module définit un objet capable d'analyser le format de journal WebTrends(tm) Enhanced Log Format. Ce format de journal a été défini par WebTrends(tm) pour sa Firewall Suite. Il définit un format extensible qui est maintenant utilisé par plusieurs pare-feux de paquets et/ou de proxy.

Le document décrivant ce format est disponible à l'adresse http://www.webtrends.com/partners/welfOverview.htm

Une liste de produits/fournisseurs qui supportent ce format peut être trouvée à l'adresse http://www.webtrends.com/partners/firewall.htm

Vous créez un objet analyseur WELF en utilisant la méthode new() :

my $parser = new Lire::WELF();

Pour analyser un enregistrement WELF, vous appelez la méthode parser() avec la ligne contenant l'enregistrement comme paramètre :

my $rec    = $parser->parse( $line );

Le $rec est une référence de hachage dont les clés sont les noms de champs WELF et les valeurs sont les valeurs des enregistrements.

Aucune valeur n'est interprétée ou vérifiée, à l'exception des suivantes :

time
Le champ heure sera converti en temps epoch
quotation
Les guillemets utilisés lorsque la valeur contient des espaces sont supprimés.

EXTENSIONS WELF

L'analyseur prend également en charge les "extensions" du format trouvées dans le champ.

port
Nous interpréterons correctement les champs src et dst qui ont le port incorporé : 
src=192.168.1.1:1037
interface
Un éventuel :IFNAME sera également interprété comme le nom de l'interface : 
dst=192.168.100.10:23:WAN
timezone
Le champ heure peut contenir un identifiant de fuseau horaire : 
time="2001-12-02 12:34:12 UTC"

Champs dérivés

L'analyseur générera quelques champs 'dérivés' pour compléter le format.

src_port
Contiendra la partie port source du champ dst lorsque les extensions SonicWall sont utilisées.
dst_port
Contiendra la partie interface du champ dst lorsque les extensions SonicWall sont utilisées.
src_if
Contiendra la partie interface du champ src lorsque les extensions SonicWall sont utilisées.
dst_if
Contiendra la partie interface du champ dst lorsque les extensions SonicWall sont utilisées.
