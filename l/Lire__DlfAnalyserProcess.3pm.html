NOM

Lire::DlfAnalyseProcess - Objet qui contrôle le processus d'analyse.

SYNOPSIS

use Lire::DlfStore;
use Lire::DlfAnalyserProcess;
my $store = Lire::DlfStore->open( "store" );
my $process = new Lire::DlfAnalyserProcess( $store, $analyser_name,
                                            $analyser_config, $dlf_source );
$process->run_analysis_job();
print "Enregistrements DLF créés: ", $process->dlf_count(),    "\n";
print "Erreurs rencontrées: ",  $process->errors_count(), "\n";

DESCRIPTION

Cet objet encapsule le processus d'analyse DLF de Lire. Il prend en paramètres un Lire::DlfStore, le nom de l'analyseur, sa configuration et optionnellement, un identifiant de source DLF. Lorsqu'une source DLF est utilisée, l'analyse ne sera effectuée qu'à partir des DLF provenant de cette source.

L'objet fournit l'API au convertisseur. Des méthodes sont également disponibles pour interroger des informations sur le processus de conversion.

new( $store, $analyser_name, $analyser_config, [ $dlf_source ] );

Crée un Lire::DlfAnalysisProcess.

run_analysis_job()

Importe les données du journal depuis ImportJob sous forme de DLF. Cette méthode lèvera une exception si elle est appelée plus d'une fois.

job_id()

Retourne l'identifiant de tâche associé à ce processus.

dlf_store()

Retourne le Lire::DlfStore dans lequel ce processus de conversion stocke les enregistrements DLF.

dlf_source()

Retourne la source à partir de laquelle les DLF doivent provenir dans le schéma source à analyser.

dlf_analyser()

Retourne le nom de l'analyseur qui sera exécuté.

dlf_analyser_config()

Retourne les données de configuration d'analyse qui doivent être utilisées par le convertisseur.

dlf_count()

Retourne le nombre d'enregistrements DLF créés.

error_count()

Retourne le nombre d'erreurs rencontrées lors du processus de conversion.

source_filter()

Retourne une expression Lire::FilterExpr qui devrait être utilisée pour limiter les enregistrements DLF à analyser.

Cette méthode retourne null si l'intégralité du flux DLF doit être analysée.

API POUR LES ANALYSEURS DLF

C'est l'objet qui encapsule l'implémentation DLF et cache la complexité du framework de stockage aux analyseurs DLF. Il offre les méthodes suivantes au convertisseur DLF.

write_dlf( $dlf, [$related_to] )

Cela écrit l'enregistrement DLF $dlf, conforme au schéma de $schema, dans le Lire::DlfStore. $Dlf est une référence de hachage. Les clés sont le nom du champ du schéma. Une valeur indéfinie signifie que ce champ n'est pas disponible dans cet enregistrement.

Lors de l'écriture dans un schéma dérivé, le paramètre $related_to peut être une référence de tableau contenant les identifiants DLF de l'enregistrement lié.

error( $error_msg );

Méthode qui doit être utilisée par Lire::Analyser pour signaler qu'une erreur a été rencontrée pendant le processus d'analyse. $error_msg doit être utilisé pour signaler la nature de l'erreur.
