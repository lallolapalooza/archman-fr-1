NOM

Locale::Codes::Country - module pour gérer les ensembles de codes de pays

SYNTAXE

use Locale::Codes::Country;
$nom = code2pays(CODE);
$code = pays2code(NOM);
@codes   = tous_codes_pays();
@noms   = tous_noms_pays();

DESCRIPTION

Ce module fournit un accès aux ensembles de codes de pays.

Veuillez vous référer au document Locale::Codes::Types pour une description des ensembles de codes disponibles.

La plupart des routines acceptent un argument supplémentaire optionnel qui spécifie l'ensemble de codes à utiliser. L'ensemble de codes peut être spécifié en utilisant le nom d'un ensemble de codes, ou la constante Perl spécifiée dans le document ci-dessus. Si non spécifié, l'ensemble de codes par défaut sera utilisé.

ROUTINES

Toutes les routines de ce module appellent la méthode appropriée dans le module Locale::Codes, en utilisant un objet de type : pays. Veuillez vous référer à la documentation du module Locale::Codes pour les détails de chaque fonction.

Les fonctions suivantes sont exportées automatiquement :

code2pays(CODE [,CODESET] [,'retiré'])
Voir code2nom dans Locale::Codes
code2payss(CODE [,CODESET])
Voir code2noms dans Locale::Codes
pays2code(NOM [,CODESET] [,'retiré'])
Voir nom2code dans Locale::Codes
code_pays2code(CODE ,CODESET ,CODESET2)
Voir code2code dans Locale::Codes
tous_codes_pays([CODESET] [,'retiré'])
Voir tous_codes dans Locale::Codes
tous_noms_pays([CODESET] [,'retiré'])
Voir tous_noms dans Locale::Codes

Les fonctions suivantes ne sont pas exportées et doivent être appelées avec leur nom de paquet qualifié complet :

Locale::Codes::Country::afficher_erreurs(FLAG)
Par défaut, une entrée invalide produira des résultats vides, mais aucune erreur. En passant une valeur non nulle pour FLAG, des erreurs seront produites.

Voir afficher_erreurs dans Locale::Codes, mais noter que la valeur par défaut pour les modules non OO est de NE PAS produire d'erreurs.

Locale::Codes::Country::renommer_pays(CODE ,NOUVEAU_NOM [,CODESET])
Voir renommer_code dans Locale::Codes
Locale::Codes::Country::ajouter_pays(CODE ,NOM [,CODESET])
Voir ajouter_code dans Locale::Codes
Locale::Codes::Country::supprimer_pays(CODE [,CODESET])
Voir supprimer_code dans Locale::Codes
Locale::Codes::Country::ajouter_alias_pays(NOM ,NOUVEL_ALIAS)
Voir ajouter_alias dans Locale::Codes
Locale::Codes::Country::supprimer_alias_pays(NOM)
Voir supprimer_alias dans Locale::Codes
Locale::Codes::Country::renommer_code_pays(CODE ,NOUVEAU_CODE [,CODESET])
Voir remplacer_code dans Locale::Codes
Locale::Codes::Country::ajouter_alias_code_pays(CODE ,NOUVEAU_CODE [,CODESET])
Voir ajouter_alias_code dans Locale::Codes
Locale::Codes::Country::supprimer_alias_code_pays(CODE [,CODESET])
Voir supprimer_alias_code dans Locale::Codes
