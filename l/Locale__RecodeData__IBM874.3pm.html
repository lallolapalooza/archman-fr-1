NAME

Locale::RecodeData::IBM874 - Routines de conversion pour IBM874

SYNOPSIS

Ce module est dans libintl. Ne l'utilisez pas directement !

DESCRIPTION

Ce module est généré et contient les tables et routines de conversion pour IBM874.

COMMENTS

Les notes suivantes sont extraites de la charmap d'origine :

généré automatiquement à partir de charDB
alias CP874

Note : les alias mentionnés ci-dessus ne sont pas nécessairement valides !

TABLE DES CARACTÈRES

La table suivante est triée dans le même ordre que la charmap d'origine. Tous les codes de caractères sont en hexadécimal. Veuillez lire 'ISO-10646' comme 'ISO-10646-UCS4'.
