NOM

Locale::RecodeData::IBM871 - Fonctions de conversion pour IBM871

SYNOPSIS

Ce module est interne à libintl. Ne l'utilisez pas directement !

DESCRIPTION

Ce module contient les tables de conversion et les fonctions pour IBM871.

COMMENTAIRES

Les commentaires suivants sont extraits du charmap original :

version: 1.0
 source: IBM NLS RM Vol2 SE09-8002-01, Mars 1990
 alias CP871
 alias EBCDIC-CP-IS

Note : Les alias mentionnés ci-dessus ne sont pas nécessairement valides !

NAME


Locale::RecodeData::IBM871 — Table de correspondance pour l'encodage IBM871 (Islandais).






SYNOPSIS


  use Locale::RecodeData 'IBM871';






DESCRIPTION


Cette classe fournit la table de correspondance pour l'encodage de caractères IBM871, qui est utilisé principalement pour l'islandais.


Elle hérite de la classe de base Locale::RecodeData et implémente la méthode map_table pour fournir la table de correspondance nécessaire au recodage.






COMMENTS


  C'est une table de codage pour l'Islandais.
