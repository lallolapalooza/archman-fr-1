NOM

Log::Log4perl::MDC - Contexte de diagnostic mappé

DESCRIPTION

Log::Log4perl permet aux journaux de maintenir des données globales spécifiques aux threads, appelées Contexte de Diagnostic Imbricé (NDC) et Contexte de Diagnostic Mappé (MDC).

Le MDC est une table de hachage simple spécifique aux threads, dans laquelle l'application peut stocker des valeurs sous certaines clés et les récupérer plus tard via le placeholder "%X{clé}" dans les "Log::Log4perl::Layout::PatternLayout".

Log::Log4perl::MDC->put($clé, $valeur);
Stocke une valeur $valeur sous la clé $clé dans la map.
mon $valeur = Log::Log4perl::MDC->get($clé);
Récupère le contenu de la map sous la clé spécifiée. Typiquement fait par %X{clé} dans "Log::Log4perl::Layout::PatternLayout". Si aucune valeur n'existe pour la clé donnée, "undef" est retourné.
mon $texte = Log::Log4perl::MDC->remove();
Supprime toutes les entrées de la map.
Log::Log4perl::MDC->get_context();
Retourne une référence à la table de hachage.

Veuillez noter que toutes les méthodes ci-dessus sont des méthodes de classe, il n'y a pas d'instances de cette classe. Étant donné que le modèle de threads dans perl 5.8.0 est « pas de données partagées à moins qu'elles ne soient explicitement demandées », les structures de données utilisées sont simplement globales (et donc spécifiques aux threads).
