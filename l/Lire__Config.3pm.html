NOM

Lire::Config - importer les variables de configuration de Lire en perl

SYNOPSIS

use Lire::Config;
Lire::Config->init();
my $cfg->value = Lire::Config->get( 'lr_schemas_path' );
my $var = Lire::Config->get_var( 'lr_schemas_path' );

DESCRIPTION

Ce paquet fournit l'API pour accéder à la configuration de Lire.

MÉTHODES

Ces méthodes peuvent être appelées directement sur une instance de Lire::Config ou sur le paquet Lire::Config lui-même. Dans ce dernier cas, c'est la même chose que d'appeler la méthode sur l'objet retourné par la méthode instance().

instance()

Retourne l'objet singleton Lire::Config à partir duquel la configuration peut être interrogée.

config_spec()

Retourne la spécification de configuration utilisée par la configuration actuelle.

config_spec_path()

Retourne une liste de répertoires qui seront recherchés pour le fichier de spécification de configuration. Par défaut, les spécifications de configuration ne sont recherchées que dans <datadir/lire/config-spec>.

add_config_spec_path_dir( $dir )

Cette méthode ajoute un répertoire à la liste des répertoires utilisés pour rechercher les fichiers de spécification de configuration.

del_config_spec_path_dir( $dir )

Cette méthode supprime un répertoire de la liste des répertoires utilisés pour rechercher les fichiers de spécification de configuration.

config_files()

Retourne la liste des fichiers de configuration qui seront utilisés pour cette configuration.

add_config_path( $path )

Ajoute des fichiers de configuration à la liste des fichiers qui font partie de la configuration. Les répertoires seront scannés récursivement.

add_config_file( $file )

Ajoute un fichier de configuration à la liste des fichiers qui seront analysés pour initialiser la configuration.

del_config_file( $file )

Supprime un fichier de configuration de la liste des fichiers qui font partie de la configuration.

get_config_file($file)

Obtient un objet de fichier de configuration analysé à partir de la liste des fichiers.

init()

Cette méthode charge et analyse les fichiers de configuration. Elle doit être appelée avant d'utiliser la méthode get() pour obtenir les données de configuration. Cette méthode lèvera une exception en cas de paramètre invalide dans la configuration.

get( $varname )

Retourne la valeur de configuration pour la variable de configuration $varname. La méthode init() devrait avoir été appelée pour charger les données de configuration avant d'utiliser cette méthode. Elle fera un croak() sinon. Si $varname est inconnu, une exception sera également levée.

get_var( $varname )

Retourne la valeur de configuration pour la variable de configuration $varname en tant qu'objet de configuration. La méthode init() devrait avoir été appelée pour charger les données de configuration avant d'utiliser cette méthode. Elle fera un croak() sinon. Si $varname est inconnu, une exception sera également levée.

DÉBOGAGE

On peut appeler ce module directement depuis la ligne de commande, par exemple à des fins de débogage, en faisant quelque chose comme:

perl -e 'use lib "/path/to/your/share/perl5"; use Lire::Config; \
 use Lire::Program; print Lire::Config->get( "lr_mail_from" ), "\n"'

ou

perl -e 'use Lire::Config; use Lire::Program; \
 $a = Lire::Config->get( lr_converters_init_path );  print "@$a\n"; '

.
