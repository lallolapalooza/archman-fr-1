DlfQuery(3pm) Documentation de Lire de LogReport DlfQuery(3pm)

NOM

Lire::DlfQuery - Interface vers des wrappers SQL spécialisés utilisés en interne par l'API Lire.

SYNOPIS

use Lire::DlfQuery;

DESCRIPTION

new( $nom_de_flux )

C'est la méthode constructeur pour la classe Lire::DlfQuery. Elle prend un nom de flux DLF et un objet Lire::DlfStore comme paramètres. Lire::DlfStore est censé contenir le flux spécifié. Les deux paramètres sont obligatoires. Cette méthode retourne une instance de Lire::DlfQuery.

nom_de_flux()

Retourne le nom du flux DLF sur lequel cette DlfQuery est définie.

rejoindre_flux( $nom_de_flux )

Cette méthode peut être utilisée pour ajouter un flux ExtendedSchema qui sera joint dans la requête.

flux_rejoints()

Retourne sous forme de référence de tableau tous les flux qui font partie de la requête.

liberer()

Les DlfQuery imbriquées introduisent une référence circulaire entre les enfants et le parent. Appelez liberer() sur la DlfQuery de haut niveau pour supprimer la référence circulaire lorsque l'objet DlfQuery n'est plus nécessaire, afin que Perl puisse collecter les objets en mémoire.

creer_requete_imbriquee()

Cette méthode créera et retournera une instance de Lire::DlfQuery imbriquée dans la requête actuelle. La requête retournée sera modifiée plus tard avec des méthodes régulières.

requetes_imbriquees()

Cette méthode retourne une référence vers un tableau contenant toutes les requêtes imbriquées de la requête actuelle.

a_champ( $nom_de_champ )

Retourne vrai s'il existe un champ $nom_de_champ défini dans la requête.

definition_champ( $nom_de_champ )

Retourne l'expression SQL associée au champ $nom_de_champ dans la requête. Cette méthode lèvera une exception s'il n'y a pas de champ $nom_de_champ défini dans la requête.

champs()

Retourne les noms des champs définis comme champs simples dans une référence de tableau. Ce sont des champs ajoutés via la méthode ajouter_champ().

champs_de_groupe()

Retourne les noms des champs définis comme champs de groupe dans une référence de tableau. Ce sont des champs ajoutés via la méthode ajouter_champ_de_groupe().

champs_agreges()

Retourne les noms des champs définis comme champs agrégés dans une référence de tableau. Ce sont des champs ajoutés via la méthode ajouter_champ_agregé().

ajouter_champ( $nom_de_champ, $expr )

Ajoute un champ simple à la requête actuelle. Le premier paramètre sera le nom du champ. Le second représente une expression qui sera ensuite renommée avec le nom de champ spécifié. Seul le nom du champ est obligatoire.

Certaines restrictions s'appliquent : les champs simples ne peuvent pas être ajoutés à des requêtes contenant des sous-requêtes ou des champs de groupe.

ajouter_champ_agregé( $nom_de_champ, $agregat )

Ajoute un champ de groupe à la requête actuelle. Le premier paramètre sera le nom du champ. Le second représente l'expression d'agrégation qui sera ensuite renommée avec le nom de champ spécifié. Les deux paramètres sont obligatoires.

Les champs agrégés ne peuvent être ajoutés qu'à des requêtes contenant des champs de groupe.

ajouter_champ_de_groupe( $nom_de_champ, $expr )

Ajoute un champ de groupe à la requête actuelle. Le premier paramètre sera le nom du champ. Le second représente une expression qui sera ensuite renommée avec le nom de champ spécifié. Seul le nom du champ est obligatoire.

Certaines restrictions s'appliquent : les champs de groupe ne peuvent pas être ajoutés à des requêtes contenant des champs simples.

definir_clause_ordre( $clause )

Définit la clause d'ordre de la requête, c'est-à-dire ce qui apparaîtra dans la clause "ORDER BY" de l'instruction SQL.

clause_ordre()

Retourne la clause ORDER BY actuelle ou undef lorsqu'aucune n'a été définie.

definir_spec_tri( $spec )

spec_tri()

Retourne la spécification de tri qui a été définie à l'aide de definir_spec_tri(). Si aucune spécification de tri n'a été définie (ou si elle a été définie à l'aide de la méthode definir_clause_ordre()), elle sera undef.

definir_limite()

Définit la clause limite de la requête, c'est-à-dire ce qui apparaîtra dans la clause "LIMIT" de l'instruction SQL. Cette méthode aura également un impact sur la gestion interne de la requête.

limite()

Retourne le nombre maximum d'enregistrements qui devraient être retournés par la requête. Lorsqu'aucune limite n'a été définie, elle retourne 0.

definir_clause_filtre( $clause, @parametres )

Définit la clause de filtre de la requête, la clause de filtre étant les restrictions SQL sur les résultats qui seront retournés par la requête, c'est-à-dire ce qui apparaîtra dans la clause "WHERE" de l'instruction SQL.

Elle est compatible avec la gestion des marqueurs de substitution ('?') de DBI. Bien sûr, le nombre de marqueurs de substitution doit être le même que le nombre de valeurs et de variables passées dans @parametres.

Seul le paramètre de clause est obligatoire, le nombre d'éléments dans @parametres dépendant du nombre de marqueurs de substitution spécifiés.

clause_filtre()

Retourne la clause WHERE actuelle ou undef lorsqu'aucune n'a été définie.

executer()

Cette méthode exécute la requête via l'interface de base de données et retourne une instance de Lire::DlfResult pour obtenir les données.

executer_resume()

Identique à executer() sauf que la requête est exécutée comme une requête de résumé.

Lire::DlfQuery(3pm)

Lire::DlfQuery

NOM

Lire::DlfQuery - Interface pour les requêtes de métadonnées DlfQuery

SYNTAXE

  use Lire::DlfQuery;

DESCRIPTION

L'objet Lire::DlfQuery fournit une interface pour interroger des données de métadonnées à partir de fichiers au format DlfQuery.

Cette classe est généralement utilisée en conjonction avec d'autres modules Lire pour analyser et manipuler des données bibliographiques et de catalogage.
