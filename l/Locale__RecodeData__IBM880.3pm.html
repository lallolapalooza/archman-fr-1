NAME

Locale::RecodeData::IBM880 - Routines de conversion pour IBM880

SYNOPSIS

Ce module est interne à libintl. Ne l'utilisez pas directement !

DESCRIPTION

Ce module contient les tables de conversion et les routines pour IBM880.

COMMENTS

Les commentaires suivants ont été extraits du charmap original :

version: 1.0
 source: IBM NLS RM Vol2 SE09-8002-01, mars 1990
 alias CP880
 alias EBCDIC-CYRILLIC

Veuillez noter que les alias mentionnés ci-dessus ne sont pas nécessairement valides !

Locale::RecodeData::IBM880(3pm) — Documentation Perl

NAME

Locale::RecodeData::IBM880 — Données de codage pour IBM Code Page 00880 (TCVN)

SYNOPSIS

  use Locale::Recode::IBM880;

DESCRIPTION

Le module Locale::Recode::IBM880 fournit les données de codage pour IBM Code Page 00880, qui est une page de code vietnamienne.

Ce module est utilisé par le framework Locale::Recode pour effectuer des conversions entre différentes pages de code.

COMMENTS

Ce module ne contient pas de code exécutable. Il est utilisé comme un jeu de données par le module Locale::Recode.
