Module Longident
: sig fin

Identifiants longs, utilisés dans le parsetree.

Attention : ce module est instable et fait partie de Compiler_libs.

Pour imprimer un longident, voir Pprintast.longident, en utilisant Format.asprintf pour convertir en une chaîne.

type t =
| Lident de string
| Ldot de t Location.loc * string Location.loc
| Lapply de t Location.loc * t Location.loc

val same : t -> t -> bool

same t t' compare les longidents t et t' sans tenir compte des emplacements.

val flatten : t -> string list

val unflatten : string list -> t option

Pour une liste non vide l, unflatten l est Some lid où lid est l'identifiant long créé en concaténant les éléments de l avec Ldot. unflatten [] est None.

val last : t -> string

val parse : string -> t

Déprécié. cette fonction peut mal analyser son entrée, utilisez "Parse.longident" ou "Longident.unflatten"

Cette fonction est défaillante sur les identifiants qui ne sont pas simplement "Word.Word.word"; par exemple, elle renvoie des résultats incorrects sur les opérateurs infixes et les chemins de modules étendus.

Si vous souhaitez générer des identifiants longs qui sont une liste d'identifiants séparés par des points, la fonction Longident.unflatten est plus sûre et plus rapide. Longident.unflatten est disponible depuis OCaml 4.06.0.

Si vous souhaitez analyser correctement tout identifiant, utilisez les fonctions de long-ident du module Parse, en particulier Parse.longident. Elles sont disponibles depuis OCaml 4.11, et fournissent également un support adéquat pour la localisation d'entrée.
