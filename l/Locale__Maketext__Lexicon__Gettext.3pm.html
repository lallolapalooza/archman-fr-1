NOM

Locale::Maketext::Lexicon::Gettext - Analyseur de fichiers PO et MO pour Maketext

VERSION

version 1.00

SYNOPSIS

Appelé via Locale::Maketext::Lexicon :

package Hello::I18N;
use base 'Locale::Maketext';
use Locale::Maketext::Lexicon {
    de => [Gettext => 'hello/de.mo'],
};

Appel direct de parse() :

use Locale::Maketext::Lexicon::Gettext;
my %Lexicon = %{ Locale::Maketext::Lexicon::Gettext->parse(<DATA>) };
__DATA__
#: Hello.pm:10
msgid "Hello, World!"
msgstr "Hallo, Welt!"
#: Hello.pm:11
msgid "You have %quant(%1,piece) of mail."
msgstr "Sie haben %quant(%1,Poststueck,Poststuecken)."

DESCRIPTION

Ce module implémente un analyseur "Gettext" basé sur Perl pour Locale::Maketext. Il transforme toutes les séquences %1, %2, <%*>... en "[_1]", "[_2]", "[_*]", et ainsi de suite. Il accepte soit un fichier PO brut, soit un fichier MO qui sera traité avec un analyseur purement Perl adapté de "Locale::Maketext::Gettext" de Imacat.

Depuis la version 0.03, ce module recherche également "%fonction(args...)" dans les chaînes de lexique, et le transforme en "[fonction,args...]". Tous les %1, %2... dans les args auront leurs signes pourcentage ("%") remplacés par des tirets ("_").

Le nom de fonction ci-dessus doit commencer par une lettre ou un tiret, suivi d'un nombre quelconque de caractères alphanumériques et/ou de tirets. Par exception, le nom de la fonction peut également être un seul astérisque ("*") ou un dièse ("#"), qui sont les raccourcis de "Locale::Maketext" pour "quant" et "numf", respectivement.

En tant que fonctionnalité supplémentaire, ce module analyse également les métadonnées de style d'en-tête MIME spécifiées dans le msgstr nul (""), et les ajoute au %Lexicon avec un préfixe "__". Par exemple, l'exemple ci-dessus définira "__Content-Type" à "text/plain; charset=iso8859-1", sans le nouvell ligne ni les deux-points.

Toute entrée normale qui duplique une entrée de métadonnées a la priorité. Ainsi, une ligne "msgid "__Content-Type"" n'importe où devrait remplacer la valeur ci-dessus.

OPTIONS

use_fuzzy

Lors de l'analyse des fichiers PO, les entrées floues (entrées marquées avec "#, fuzzy") sont ignorées silencieusement. Si vous souhaitez utiliser les entrées floues, spécifiez une valeur vraie à l'option "_use_fuzzy" :

use Locale::Maketext::Lexicon {
    de => [Gettext => 'hello/de.mo'],
    _use_fuzzy => 1,
};

allow_empty

Lors de l'analyse des fichiers PO, les entrées vides (entrées avec "msgstr """) sont ignorées silencieusement. Si vous souhaitez autoriser les entrées vides, spécifiez une valeur vraie à l'option "_allow_empty" :

use Locale::Maketext::Lexicon {
    de => [Gettext => 'hello/de.mo'],
    _allow_empty => 1,
};
