NOM

Log::Log4perl::Util::TimeTracker - Suivre le temps écoulé

SYNTAXE

use Log::Log4perl::Util::TimeTracker;
my $timer = Log::Log4perl::Util::TimeTracker->new();
  # équivalent à Time::HiRes::gettimeofday(), que Time::HiRes
  # soit présent ou non. 
my($secondes, $microsecondes) = $timer->gettimeofday();
  # réinitialise le timer interne
$timer->reset();
  # renvoie les millisecondes depuis la dernière réinitialisation
$msecs = $timer->milliseconds();
  # renvoie les millisecondes depuis le dernier appel
$msecs = $timer->delta_milliseconds();

DESCRIPTION

Ce module utilitaire aide à suivre le temps écoulé pour les espaces réservés date et heure de PatternLayout. Sa précision dépend de la disponibilité du module Time::HiRes. S'il est disponible, sa granularité est en millisecondes, sinon en secondes.

L'utilisation la plus courante de ce module est l'appel de la méthode gettimeofday() :

my($secondes, $microsecondes) = $timer->gettimeofday();

Elle renvoie les secondes et les microsecondes du temps d'époque actuel. Si Time::HiRes est installé, elle délèguera simplement à sa fonction gettimeofday(), sinon, time() sera appelée à la place et $microsecondes sera toujours égal à 0.

Pour mesurer le temps écoulé en millisecondes, utilisez la méthode reset() pour réinitialiser le timer à l'heure actuelle, suivie d'un ou plusieurs appels à la méthode milliseconds() :

  # réinitialise le timer interne
$timer->reset();
  # renvoie les millisecondes depuis la dernière réinitialisation
$msecs = $timer->milliseconds();

En plus de l'intervalle de temps entre la dernière réinitialisation et l'heure actuelle, le module suit le temps écoulé entre les appels à delta_milliseconds() :

$msecs = $timer->delta_milliseconds();

Au premier appel, cela renverra le nombre de millisecondes depuis le dernier reset(), lors des appels suivants, cela renverra le temps écoulé en millisecondes depuis le dernier appel à delta_milliseconds() à la place. Notez que reset() réinitialise également l'heure du dernier appel.

Le timer interne de ce module obtient son apport temporel de la fonction POSIX time(), ou, si le module Time::HiRes est disponible, de sa fonction gettimeofday(). Pour savoir lequel est utilisé, utilisez :

if( $timer->hires_available() ) {
    print "Hourra, nous obtenons de vraies millisecondes !\n";
} else {
    print "Les millisecondes sont bidon\n";
}

À des fins de test, une source de temps différente peut être fournie, afin que les suites de tests puissent simuler le passage du temps sans avoir à attendre réellement :

my $start_time = time();
my $timer = Log::Log4perl::Util::TimeTracker->new(
        time_function => sub {
            return $start_time++;
        },
);

Chaque appel à $timer->epoch() renverra alors une valeur de temps une seconde supérieure à la valeur renvoyée lors de l'appel précédent. Cela signifie également que chaque appel à delta_milliseconds() renverra une valeur supérieure de 1000 à la valeur renvoyée lors de l'appel précédent.
