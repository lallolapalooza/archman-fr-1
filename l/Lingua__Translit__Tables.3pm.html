NOM

Lingua::Translit::Tables - fournit des tables de translittération

SYNOPIS

use Lingua::Translit::Tables qw/:checks/;
my $truth;
$truth = translit_supported("ISO 9");
$truth = translit_reverse_supported("ISO 9");
use Lingua::Translit::Tables qw/:list/;
translit_list_supported();

DESCRIPTION

Ce module est principalement utilisé pour fournir des tables de translittération à Lingua::Translit et permet donc de séparer les données de l'algorithme.

En plus de cela, il fournit des routines pour vérifier si une translittération donnée est supportée et permet d'imprimer une liste simple des translittérations supportées avec quelques métadonnées.

EXPORTATIONS

Aucun symbole n'est exporté par défaut.

Utilisez soit le nom de la routine, soit l'un des tags suivants pour importer des symboles dans votre espace de noms.

all
Importe tous les symboles.
checks
Importe tous les symboles qui permettent de vérifier si une translittération donnée est supportée : translit_supported() et translit_reverse_supported().
list
Importe translit_list_supported(). (Tag de commodité)

ROUTINES

translit_supported(translit_name)

Retourne vrai (1) si translit_name est supporté. Faux (0) sinon.

translit_reverse_supported(translit_name)

Retourne vrai (1) si translit_name est supporté et permet la translittération inverse. Faux (0) sinon.

translit_list_supported()

Imprime une liste de toutes les translittérations supportées sur STDOUT (en format UTF-8), fournissant les informations suivantes :

* Nom
* Réversibilité
* Description

Les mêmes informations sont fournies dans ce document également :

TRANSLITTÉRATIONS SUPPORTÉES

Cyrillique
ALA-LC RUS, non réversible, ALA-LC:1997, Cyrillique vers Latin, russe.

ISO 9, réversible, ISO 9:1995, Cyrillique vers Latin.

ISO/R 9, réversible, ISO 9:1954, Cyrillique vers Latin.

DIN 1460 RUS, réversible, DIN 1460:1982, Cyrillique vers Latin, russe.

DIN 1460 UKR, réversible, DIN 1460:1982, Cyrillique vers Latin, ukrainien.

DIN 1460 BUL, réversible, DIN 1460:1982, Cyrillique vers Latin, bulgare.

Streamlined System BUL, non réversible, Le Système Simplifié: 2006, Cyrillique vers Latin, bulgare.

GOST 7.79 RUS, réversible, GOST 7.79:2000 (table B), Cyrillique vers Latin, russe.

GOST 7.79 RUS OLD, non réversible, GOST 7.79:2000 (table B), Cyrillique vers Latin, avec prise en charge du russe ancien (avant 1918).

GOST 7.79 UKR, réversible, GOST 7.79:2000 (table B), Cyrillique vers Latin, ukrainien.

BGN/PCGN RUS Standard, non réversible, BGN/PCGN:1947 (Version Standard), Cyrillique vers Latin, russe.

BGN/PCGN RUS Strict, non réversible, BGN/PCGN:1947 (Version Strict), Cyrillique vers Latin, russe.

Grec
ISO 843, non réversible, ISO 843:1997, Grec vers Latin.

DIN 31634, non réversible, DIN 31634:1982, Grec vers Latin.

Greeklish, non réversible, Greeklish (phonétique), Grec vers Latin.

Latin
Common CES, non réversible, Tchèque sans diacritiques.

Common DEU, non réversible, Allemand sans accent (umlauts).

Common POL, non réversible, Polonais sans accents.

Common RON, non réversible, Roumain sans diacritiques tel qu'utilisé couramment.

Common SLK, non réversible, Slovaque sans diacritiques (sans accents).

Common SLV, non réversible, Slovaque sans diacritiques (sans accents).

ISO 8859-16 RON, réversible, Roumain avec diacritiques appropriés.

Arabe
Common ARA, non réversible, Romanisation commune de l'arabe.
Sanskrit
IAST Devanagari, non réversible, IAST vers Devanāgarī, Devanāgarī IAST vers IAST.

AJOUTER DE NOUVELLES TRANSLITTÉRATIONS

Si vous souhaitez ajouter vos propres tables de translittération à Lingua::Translit, veuillez consulter la documentation de développement sur https://www.netzum-sorglos.de/software/lingua-translit/developer-documentation.html.

Un modèle de table de translittération (xml/template.xml) est fourni pour vous aider à démarrer facilement le développement.
