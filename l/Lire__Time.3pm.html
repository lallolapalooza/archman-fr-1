NOM

Lire::Time - analyse et imprime la date dans des formats courants pour de nombreux fichiers journaux.

SYNTAXE

use Lire::Time qw/ syslog2cal /;
my @ltime = localtime;
while ( <LOGFILE> ) {
    #...
    my $time = syslog2cal( $m, $d, $t, \@ltime );
}

DESCRIPTION

Ce module fournit de nombreuses fonctions pour analyser des dates dans des formats que vous êtes susceptible de rencontrer dans les fichiers journaux. Il propose également de nombreuses fonctions pour formater le temps Unix epoch dans un format utile.

NOTE SUR L'EXPORTATION DES FONCTIONS

Bien que toutes les fonctions documentées soient exportées par défaut dans l'espace de noms de l'appelant, vous devriez explicitement importer les fonctions dont vous avez besoin, car l'exportation par défaut n'est pas recommandée par les directives des modules perl.

FONCTIONS D'ANALYSE DE DATE

Ce module comprend plusieurs fonctions qui convertissent entre un format de date plus lisible par l'homme et le temps Unix epoch. Toutes les fonctions d'analyse retourneront le nombre de secondes depuis le 1er janvier 1970 00:00:00 UTC et utiliseront die() lorsqu'elles recevront des arguments invalides.

date2cal()

my $time = date2cal( $year, $month, $day, $time, [$timezone] );
my $time = date2cal( "2001 Mar 20 09:32:29 +0100" );

Cette fonction convertira une date au format de sortie par défaut de date(1) en temps Unix epoch. La fonction accepte la date soit sous forme de chaîne de caractères, soit séparée par des espaces. Si le composant fuseau horaire est omis, le fuseau horaire local est supposé (généralement basé sur la valeur de la variable d'environnement TZ).

syslog2cal()

my $time = syslog2cal( $month, $day, $time, $local_tm_ref );
my $time = syslog2cal( "Mar 11 13:21:00", $local_tm_ref );

Cette fonction convertira une date au format de sortie par défaut de syslog en temps Unix epoch. La fonction accepte la date soit sous forme de chaîne de caractères, soit séparée par des espaces.

Comme le format syslog ne contient pas d'informations de fuseau horaire, le fuseau horaire local est supposé (généralement déterminé par la variable d'environnement TZ).

Le dernier argument est une référence à un tableau retourné par localtime().

my $local_tm_ref = [localtime()];

Il est utilisé pour déterminer l'année.

clf2cal()

my $time = clf2cal( "[18/Mar/2001:15:59:30 +0100]" );

Cette fonction convertira une date telle que trouvée dans le format Common Log Format en temps Unix epoch.

FONCTIONS DE FORMATAGE DE DATE

Ce module comprend quelques fonctions pour convertir le temps Unix epoch en une sortie plus lisible par l'homme. Toutes les fonctions utiliseront die() lorsqu'elles recevront des arguments invalides.

cal2rfc()

print cal2rfc( $time );

Cette fonction convertira une date en temps Unix epoch au format RFC822 (utilisé dans les e-mails, par exemple). Une date RFC822 ressemble à ceci :

Wed, 30 May 2001 12:45:13 +0000

La spécification du décalage du fuseau horaire correspondra au fuseau horaire local (généralement déterminé par la variable d'environnement TZ).

cal2ymdhms()

print cal2ymdhms( $time );

Cette fonction convertit une date en temps Unix epoch en une chaîne de caractères de la forme :

YYYYMMDDHHMMSS

Cette représentation correspondra à l'heure dans le fuseau horaire local (généralement déterminé par la variable d'environnement TZ).

getMonthName()

print getMonthName( 0 ); # Donne 'Jan'

Cette fonction prend en paramètre un nombre (0-11) représentant le mois (tel que retourné par localtime() par exemple) et retournera le nom abrégé en anglais de ce mois (Jan, Fév, etc.).
