NOM

Locale::RecodeData::IBM273 - Routines de conversion pour IBM273

SYNOPSIS

Ce module est interne à libintl. Ne pas l'utiliser directement !

DESCRIPTION

Ce module est généré et contient les tables et routines de conversion pour IBM273.

COMMENTAIRES

Les commentaires suivants ont été extraits de la table de caractères originale :

version: 1.0
 source: IBM NLS RM Vol2 SE09-8002-01, March 1990
alias CP273

Veuillez noter que les alias listés ci-dessus ne sont pas nécessairement valides !
