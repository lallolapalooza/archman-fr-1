NOM

Lire::Config::Plugin - Objet de valeur pour la configuration des plugins.

SYNOPSIS

use Lire::Config::Plugin;

DESCRIPTION

Cet objet de configuration contient le nom d'un plugin sélectionné ainsi que ses options.

get_plugin()

Retourne le plugin actuellement sélectionné.

set_plugin( $plugin )

Change le plugin sélectionné. Si le plugin sélectionné est changé, un nouvel ensemble de propriétés sera créé à partir des propriétés définies par le plugin.

get_properties_spec()

Retourne le TypeSpec utilisé pour spécifier les propriétés du plugin. Cette méthode retournera un RecordSpec vide lorsque le plugin n'aura défini aucune propriété. On peut aussi utiliser la méthode has_properties() pour vérifier si le plugin a défini des propriétés de configuration.

has_properties()

Retourne une valeur booléenne indiquant si le plugin actuel est configurable.

get_properties()

Retourne l'objet Lire::Config::Dictionary qui contient la configuration du plugin.

as_value()

Retourne une référence de hachage avec deux clés : 'plugin' qui contient le plugin sélectionné et 'properties' qui est une référence de hachage contenant les propriétés du plugin.

get( $name )

Délègue au dictionnaire qui contient les propriétés du plugin.

set( $name, $value )

Délègue au dictionnaire qui contient les propriétés du plugin.

is_set( $name )

Délègue au dictionnaire qui contient les propriétés du plugin.
