NAME

Locale::RecodeData::IBM904 - Routines de conversion pour IBM904

SYNOPSIS

Ce module est interne à libintl. Ne l'utilisez pas directement !

DESCRIPTION

Ce module est généré et contient les tables de conversion et les routines pour IBM904.

COMMENTS

Les remarques suivantes sont extraites du charmap original :

version: 1.0
 source: IBM NLS RM Vol2 SE09-8002-01, March 1990
alias CP904
alias 904

Note : Les alias mentionnés ci-dessus ne sont pas nécessairement valides !
