NOM

Lire::Aggregator - Classe de base pour tous les opérateurs d'agrégation

SYNOPSIS

use base qw/ Lire::Aggregator /;

DESCRIPTION

La classe Lire::Aggregator est la classe de base pour tous les opérateurs d'agrégation disponibles dans Lire. Elle implémente des comportements communs à tous les opérateurs d'agrégation et définit certaines méthodes qui doivent être implémentées par les sous-classes.

Dans Lire, un opérateur d'agrégation est un opérateur qui regroupe des enregistrements DLF. D'autres opérateurs tels que avg ou sum calculent des valeurs sur ces groupes d'enregistrements DLF. Les opérateurs d'agrégation peuvent être imbriqués pour calculer des valeurs dans des groupes hiérarchiques.

MÉTHODES

ops( [$new_ops] )

Renvoie les opérateurs contenus dans cet agrégateur. La valeur renvoyée est une référence vers un tableau d'objets Lire::ReportOperator.

Si $new_ops est utilisé, il change le contenu de cet agrégateur avec ces nouvelles valeurs.

Le $new_ops doit être une référence vers un tableau contenant des objets Lire::ReportOperator.

op_by_name( $name )

Renvoie l'opérateur nommé $name dans cet agrégateur. Une exception sera levée si un tel opérateur n'existe pas.

is_name_defined( $name )

Renvoie vrai si cet agrégateur contient un opérateur nommé $name.

MÉTHODES POUR LES SOUS-CLASSES

print( $fh, $pfx )

Cette méthode implémente la méthode print() requise par Lire::ReportOpetor. Elle imprime l'élément XML nommé après op() et gère l'écriture de la représentation XML de tous les opérateurs enfants. Elle gère également l'écriture du nom et de l'attribut label. D'autres attributs peuvent être ajoutés à l'élément XML en surchargeant la méthode xml_attrs(). D'autres éléments enfants peuvent être ajoutés au flux de sortie en surchargeant la méthode print_content().

xml_attrs()

Cette méthode peut être utilisée pour ajouter des attributs XML supplémentaires. La chaîne renvoyée sera sortie dans l'élément XML.

print_content( $fh, $pfx )

Cette méthode imprime les opérateurs contenus dans cet agrégateur. Elle peut être surchargée pour ajouter d'autres éléments.

create_group_info( $info )

FIXME

Les sous-classes doivent surcharger la méthode create_categorical_info() pour cette implémentation.

create_categorical_info( $info )

Cette méthode est utilisée par l'implémentation de create_group_info() pour ajouter l'information de ColumnInfo catégorique fournie par l'agrégateur.

create_entries( $subreport )

Cette méthode est utilisée par Lire::ReportSpec pour remplir Lire::Report::Subreport avec les enregistrements lors de la création du sous-rapport.

Le paramètre $subreport contient l'objet Subreport auquel les enregistrements du sous-rapport doivent être ajoutés.

Cette méthode ne sera appelée que sur l'agrégateur de niveau supérieur du rapport.

build_query( $query )

FIXME

set_group_summary( $group, $row )

FIXME

create_entry( $group, $row )

FIXME

API D'AGRÉGATEUR DE FUSION

Définit les méthodes supplémentaires requises par l'implémentation de Aggregator pour pouvoir fusionner des données.

L'implémentation de base de Aggregator gère la fusion des informations de résumé contenues dans les rapports XML de Lire.

Les spécifications de fusion spécifiques à l'agrégateur doivent être implémentées dans les méthodes init_agggregator_data(), update_agggregator_data() et end_agggregator_data().

Cette classe gère également le cas où l'agrégateur est l'agrégateur de niveau supérieur, c'est-à-dire le fils direct de l'élément report-calc-spec dans la spécification du rapport.

IMPLÉMENTATION DES MÉTHODES DE FUSION DE Lire::ReportOperator

init_merge( $period_start, $period_end )

L'implémentation par défaut garantit que tous les opérateurs comptés sont initialisés.

L'implémentation d'un agrégateur spécifique doit hériter de cette méthode, si elle la surcharge.

end_merge()

L'implémentation par défaut garantit que tous les opérateurs reçoivent l'événement end_report().

Les sous-classes doivent hériter de cette méthode, si elles la surchargent.

init_group_data()

Aggregator implémente init_group_data(). Il gère le calcul des informations de résumé. La sous-classe fait de même dans init_agggregator_data().

merge_group_data( $value, $data )

Aggregator implémente merge_group_data(). Il gère la fusion des informations de résumé. La sous-classe fait de même dans merge_agggregator_data().

end_group_data($data)

Aggregator implémente end_group_data(). Il gère le calcul des informations de résumé. La sous-classe fait de même dans end_agggregator_data().

add_entry_value( $entry, $data )

Cette méthode garantit que les enregistrements d'agrégateurs imbriqués sont enveloppés dans un élément Lire::Report::Group.

Il n'y a aucune raison de surcharger cette méthode, car les enregistrements d'agrégateurs sont ajoutés dans la méthode create_group_entries().

MÉTHODES QUI DOIVENT ÊTRE IMPLÉMENTÉES PAR LES SOUS-CLASSES POUR LA FUSION

init_agggregator_data()

Ceci est l'équivalent de init_group_data() et est appelé depuis l'implémentation de init_group_data() de l'agrégateur.

merge_agggregator_data( $value, $data )

Cette méthode est l'équivalent de merge_group_data() et est appelée depuis l'implémentation de merge_group_data() de l'agrégateur.

end_agggregator_data( $data )

Cette méthode est l'équivalent de end_group_data() et est appelée depuis l'implémentation de end_group_data() de l'agrégateur.

Lire::Aggregator(3pm) — ArchWiki

NOM

Lire::Aggregator - Interface pour les agrégateurs

SYNOPSIS

    package Lire::Aggregator::MyAggregator;

    use Lire::Report::Entry;
    use Lire::Report::Group;
    use Lire::ReportSpec;
    use Lire::Aggregate;

    @ISA = qw( Lire::Aggregate );

    sub init_merge { ... }
    sub create_group_entries { ... }
    sub merge_entries { ... }
    sub finalize_merge { ... }

DESCRIPTION

Cette classe définit l'interface que les agrégateurs doivent implémenter. Les agrégateurs sont utilisés dans le cadre du rapport Lire pour regrouper des entrées de rapport selon une logique définie par l'utilisateur.

Les agrégateurs sont généralement des sous-classes de Lire::Aggregate(3pm) et sont appelés par le système Lire pendant le processus de génération de rapport. Ils sont responsables de la manière dont les données sont traitées et agrégées.

METHODS

Cette classe ne fournit aucune méthode par défaut. Les sous-classes doivent implémenter les méthodes suivantes si nécessaire pour leurs besoins spécifiques.

METHODS FOR SUBCLASSES

Les méthodes suivantes sont les points d'extension principaux pour les agrégateurs personnalisés.

init_merge( $period_start, $period_end )
Cette méthode est appelée une fois avant que le processus de fusion ne commence. Elle est destinée à l'initialisation de l'état de l'agrégateur pour une période de temps donnée. Les arguments sont le temps de début et de fin de la période de fusion.
create_group_entries( $group, $data )
Cette méthode est appelée par l'agrégateur pour ajouter des objets Lire::Report::Entry pour chaque groupe fusionné par l'agrégateur.
merge_entries( $group, $entry_data )
Cette méthode est appelée pour fusionner des données dans un groupe existant.
finalize_merge( $group )
Cette méthode est appelée une fois après que toutes les entrées ont été traitées et fusionnées. Elle est destinée à des actions de nettoyage ou de finalisation.

MERGING AGGRATOR API

Les agrégateurs fournissent une API pour le processus de fusion.

IMPLEMENTATION OF Lire::ReportOperator MERGING METHODS

Les agrégateurs sont des types spéciaux d'opérateurs et doivent donc implémenter les méthodes d'interface d'opérateur pertinentes pour le processus de fusion.

init_merge( $period_start, $period_end )

Cette méthode est appelée une fois au début du processus de fusion pour une période donnée. Elle est destinée à l'initialisation de l'état interne de l'agrégateur. Les arguments sont les horodatages de début et de fin de la période qui sera fusionnée.

Les agrégateurs doivent implémenter cette méthode pour préparer leurs structures de données internes pour recevoir les données fusionnées.

create_group_entries( $group, $data )

Dans cette méthode, l'agrégateur doit ajouter un objet Lire::Report::Entry pour chaque groupe fusionné par l'agrégateur.

$group est une instance de Lire::Report::Group à laquelle les entrées doivent être ajoutées. $data est la structure de données retournée par init_group_data() pour le groupe dans lequel l'agrégateur est imbriqué (ou la seule structure qui a été créée lorsque l'agrégateur est l'agrégateur de niveau supérieur).

Dans cette méthode, l'agrégateur doit s'assurer d'appeler add_entry_value() sur ses opérateurs contenus pour chaque entrée créée.
