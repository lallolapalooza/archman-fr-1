NOM

List::AllUtils - Combine List::Util, List::SomeUtils et List::UtilsBy dans un seul paquet compact

VERSION

version 0.19

SYNOPSIS

use List::AllUtils qw( first any );
# _Tout_ de List::Util, List::SomeUtils et List::UtilsBy
use List::AllUtils qw( :all );
my @numbers = ( 1, 2, 3, 5, 7 );
# ou n'importez rien
return List::AllUtils::first { $_ > 5 } @numbers;

DESCRIPTION

Êtes-vous fatigué de vous souvenir si une aide particulière est définie dans List::Util, List::SomeUtils ou List::UtilsBy ? Vous devriez l'être. Maintenant, vous n'aurez plus à vous en souvenir. Ce module exportera toutes les fonctions que ces trois modules définissent.

Note : La documentation de toutes les fonctions a été copiée sans vergogne depuis List::Util, List::SomeUtils et List::UtilsBy.

Quel est le gagnant ?

Récemment, List::Util a commencé à inclure certains des subs qui étaient autrefois uniquement dans List::SomeUtils. De même, List::SomeUtils a quelques petits chevauchements avec List::UtilsBy.

"List::AllUtils" favorise toujours la sous-routine fournie par List::Util, List::SomeUtils ou List::UtilsBy dans l'ordre de préférence. Cependant, depuis List::Util 1.56, il inclut certaines fonctions, "mesh" et "zip", portant le même nom que les fonctions de List::SomeUtils mais avec un comportement différent.

Par conséquent, à partir de maintenant, nous privilégierons toujours la compatibilité ascendante. Cela signifie que "mesh" et "zip" proviendront toujours de List::SomeUtils. Si d'autres fonctions incompatibles étaient ajoutées à List::Util, elles seraient également omises au profit de la version de List::SomeUtils.

Les notes ci-dessous proviennent de List::Util 1.56, List::SomeUtils 0.58 et List::UtilsBy 0.11.

Qu'est-ce qui est exporté ?

Tout ce que fait ce module est le suivant : il charge List::Util, List::SomeUtils et List::UtilsBy, puis réexporte tout ce qu'ils offrent. Cela signifie que, indépendamment de la documentation ci-dessous, vous obtiendrez toutes les sous-routines que votre version installée fournit.

FONCTIONS DE RÉDUCTION DE LISTE

Les fonctions suivantes appliquent un bloc de code à une liste de valeurs.

reduce

$resultat = reduce { BLOCK } @liste

Réduit @liste en appelant "BLOCK" en contexte scalaire plusieurs fois, en définissant $a et $b à chaque fois. Le premier appel aura $a et $b définis sur les deux premiers éléments de la liste, et les appels suivants seront effectués en définissant $a sur le résultat de l'appel précédent et $b sur l'élément suivant de la liste.

Renvoie le résultat du dernier appel à "BLOCK". Si @liste est vide, renvoie "undef". Si @liste n'a qu'un seul élément, cet élément est renvoyé et "BLOCK" n'est pas exécuté.

Les exemples suivants montrent comment "reduce" pourrait être utilisé pour implémenter les autres fonctions de réduction de liste dans ce module. (Ils ne sont pas réellement implémentés ainsi, mais de manière plus efficace dans des fonctions C individuelles).

$foo = reduce { defined($a) ? $a :
                $code-(local $_ = $b) ? $b :
                                         undef } undef, @liste # first
$foo = reduce { $a > $b ? $a : $b } 1..10       # max
$foo = reduce { $a gt $b ? $a : $b } 'A'..'Z'   # maxstr
$foo = reduce { $a < $b ? $a : $b } 1..10       # min
$foo = reduce { $a lt $b ? $a : $b } 'aa'..'zz' # minstr
$foo = reduce { $a + $b } 1 .. 10               # sum
$foo = reduce { $a . $b } @bar                  # concat
$foo = reduce { $a || $code-(local $_ = $b) } 0, @bar   # any
$foo = reduce { $a && $code-(local $_ = $b) } 1, @bar   # all
$foo = reduce { $a && !$code-(local $_ = $b) } 1, @bar  # none
$foo = reduce { $a || !$code-(local $_ = $b) } 0, @bar  # not all
   # Notez que ces implémentations ne coupent pas complètement

Si votre algorithme nécessite que "reduce" produise une valeur identité, assurez-vous de toujours passer cette valeur identité comme premier argument pour éviter qu'"undef" ne soit renvoyé.

$foo = reduce { $a + $b } 0, @values;             # somme avec valeur identité 0

Les exemples de code ci-dessus suggèrent également comment utiliser "reduce" pour construire une version plus efficace de l'une de ces fonctions de base combinée avec un bloc "map". Par exemple, pour trouver la longueur totale de toutes les chaînes dans une liste, on pourrait utiliser

$total = sum map { length } @strings;

Cependant, cela produit une liste de valeurs entières temporaires de la longueur de la liste originale de chaînes, juste pour la réduire à une seule valeur à nouveau. Nous pouvons calculer le même résultat plus efficacement en utilisant "reduce" avec un bloc qui accumule les longueurs en écrivant ceci comme suit :

$total = reduce { $a + length $b } 0, @strings

Les autres fonctions de réduction de liste sont des spécialisations de cette idée générale.

reductions

@results = reductions { BLOCK } @liste

Depuis la version 1.54.

Similaire à "reduce", sauf qu'il renvoie également les valeurs intermédiaires ainsi que le résultat final. Comme auparavant, $a est défini sur le premier élément de la liste donnée, et le bloc est appelé une fois pour chaque élément restant dans la liste, le résultat étant capturé pour être renvoyé ainsi que la nouvelle valeur de $a.

La liste renvoyée commencera par la valeur initiale de $a, suivie de chaque valeur renvoyée par le bloc dans l'ordre. La valeur finale du résultat sera identique au résultat que la fonction "reduce" aurait renvoyé étant donné le même bloc et la même liste.

reduce     { "$a-$b" } "a".."d"    # "a-b-c-d"
reductions { "$a-$b" } "a".."d"    # "a", "a-b", "a-b-c", "a-b-c-d"

any

my $bool = any { BLOCK } @liste;

Depuis la version 1.33.

Similaire à "grep" en ce qu'il évalue "BLOCK" en définissant $_ sur chaque élément de @liste dans l'ordre. "any" renvoie vrai si un élément fait renvoyer une valeur vraie par "BLOCK". Si "BLOCK" ne renvoie jamais vrai ou si @liste est vide, il renvoie faux.

De nombreuses occasions d'utiliser "grep" dans des conditions peuvent être écrites en utilisant "any" car il peut s'arrêter après le premier résultat vrai.

if( any { length > 10 } @strings ) {
    # au moins une chaîne a plus de 10 caractères
}

Note : En raison de problèmes XS, le bloc passé peut accéder directement à @_ externe. Ce n'est pas intentionnel et peut causer des problèmes dans le débogueur.

all

my $bool = all { BLOCK } @liste;

Depuis la version 1.33.

Similaire à "any", mais exige que tous les éléments de @liste fassent renvoyer vrai par "BLOCK". Si un élément renvoie faux, il renvoie faux. Si "BLOCK" ne renvoie jamais faux ou si @liste est vide, il renvoie vrai.

none

notall

my $bool = none { BLOC } @liste;
my $bool = notall { BLOC } @liste;

Depuis la version 1.33.

Similaire à "any" et "all", mais avec le sens du retour inversé. "none" retourne vrai uniquement si aucune valeur dans @liste ne fait que le "BLOC" retourne vrai, et "notall" retourne vrai uniquement si ce n'est pas toutes les valeurs qui le font.

Note : En raison de problèmes XS, le bloc passé peut accéder directement à @_ externe. Ce n'est pas intentionnel et cela échouera sous le débogueur.

first

my $val = first { BLOC } @liste;

Similaire à "grep" en ce qu'il évalue le "BLOC" en définissant $_ sur chaque élément de @liste tour à tour. "first" retourne le premier élément pour lequel le résultat du "BLOC" est une valeur vraie. Si le "BLOC" ne retourne jamais vrai ou si @liste était vide, alors "undef" est retourné.

$foo = first { defined($_) } @liste    # première valeur définie dans @liste
$foo = first { $_ > $valeur } @liste    # première valeur dans @liste qui
                                      # est supérieure à $valeur

max

my $num = max @liste;

Retourne l'entrée de la liste ayant la plus grande valeur numérique. Si la liste est vide, alors "undef" est retourné.

$foo = max 1..10                # 10
$foo = max 3,9,12               # 12
$foo = max @bar, @baz           # ce que ce soit

maxstr

my $str = maxstr @liste;

Similaire à "max", mais traite toutes les entrées de la liste comme des chaînes de caractères et retourne la chaîne la plus grande telle que définie par l'opérateur "gt". Si la liste est vide, alors "undef" est retourné.

$foo = maxstr 'A'..'Z'          # 'Z'
$foo = maxstr "hello","world"   # "world"
$foo = maxstr @bar, @baz        # ce que ce soit

min

my $num = min @liste;

Similaire à "max" mais retourne l'entrée de la liste ayant la plus petite valeur numérique. Si la liste est vide, alors "undef" est retourné.

$foo = min 1..10                # 1
$foo = min 3,9,12               # 3
$foo = min @bar, @baz           # ce que ce soit

minstr

my $str = minstr @liste;

Similaire à "min", mais traite toutes les entrées de la liste comme des chaînes de caractères et retourne la chaîne la plus petite telle que définie par l'opérateur "lt". Si la liste est vide, alors "undef" est retourné.

$foo = minstr 'A'..'Z'          # 'A'
$foo = minstr "hello","world"   # "hello"
$foo = minstr @bar, @baz        # ce que ce soit

product

my $num = product @liste;

Depuis la version 1.35.

Retourne le produit numérique de tous les éléments de @liste. Si @liste est vide, alors 1 est retourné.

$foo = product 1..10            # 3628800
$foo = product 3,9,12           # 324

sum

my $num_or_undef = sum @liste;

Retourne la somme numérique de tous les éléments de @liste. Pour des raisons de compatibilité ascendante, si @liste est vide, alors "undef" est retourné.

$foo = sum 1..10                # 55
$foo = sum 3,9,12               # 24
$foo = sum @bar, @baz           # ce que ce soit

sum0

my $num = sum0 @liste;

Depuis la version 1.26.

Similaire à "sum", sauf que celui-ci retourne 0 lorsqu'il reçoit une liste vide, au lieu de "undef".

FONCTIONS DE LISTES DE PAIRES CLÉ/VALEUR

L'ensemble des fonctions suivantes, toutes inspirées par List::Pairwise, consomme une liste de paires de taille paire. Les paires peuvent être des associations clé/valeur d'une table de hachage, ou simplement une liste de valeurs. Les fonctions préserveront toutes l'ordre d'origine des paires, et ne seront pas déroutées par plusieurs paires ayant la même valeur de "clé" - ni même ne requièrent que le premier élément de chaque paire soit une chaîne de caractères simple.

NOTE : Au moment de la rédaction, les fonctions "pair*" suivantes qui prennent un bloc ne modifient pas la valeur de $_ dans le bloc, et opèrent plutôt en utilisant les variables globales $a et $b. Cela s'est avéré être une mauvaise conception, car cela exclut la possibilité de fournir une fonction "pairsort". Il serait préférable de passer des objets de type paire sous forme de références d'arrays à 2 éléments dans $_, dans un style similaire à la valeur de retour de la fonction "pairs". Dans une future version, ce comportement pourrait être ajouté.

En attendant, les utilisateurs sont avertis de **NE PAS** se fiér à la valeur de $_ qui reste inchangée entre l'extérieur et l'intérieur du bloc de contrôle. En particulier, l'exemple suivant est **DANGEREUX** :

my @liste_kv = ...
foreach (qw( certaines clés ici )) {
   my @elements = pairgrep { $a eq $_ } @liste_kv;
   ...
}

Écrivez plutôt ceci en utilisant une variable lexicale :

foreach my $cle (qw( certaines clés ici )) {
   my @elements = pairgrep { $a eq $cle } @liste_kv;
   ...
}

pairs

my @paires = pairs @liste_kv;

Depuis la version 1.29.

Raccourci pratique pour opérer sur des listes de paires de taille paire, cette fonction retourne une liste de références "ARRAY", chacune contenant deux éléments de la liste donnée. C'est une version plus efficace de

@paires = pairmap { [ $a, $b ] } @liste_kv

Il est plus pratique de l'utiliser dans une boucle "foreach", par exemple :

foreach my $paire ( pairs @liste_kv ) {
   my ( $cle, $valeur ) = @$paire;
   ...
}

Depuis la version 1.39, ces références "ARRAY" sont des objets bénis, reconnaissant les deux méthodes "key" et "value". Le code suivant est équivalent :

foreach my $paire ( pairs @liste_kv ) {
   my $cle   = $paire->key;
   my $valeur = $paire->value;
   ...
}

Depuis la version 1.51, ils ont également une méthode "TO_JSON" pour faciliter la sérialisation.

unpairs

my @liste_kv = unpairs @paires

Depuis la version 1.42.

La fonction inverse de "pairs" ; cette fonction prend une liste de références "ARRAY" contenant deux éléments chacune, et retourne une liste aplatie des deux valeurs de chacune des paires, dans l'ordre. Ceci est notionnellement équivalent à

my @liste_kv = map { @{$_}[0,1] } @paires

sauf qu'elle est implémentée plus efficacement en interne. Spécifiquement, pour tout élément d'entrée, elle extraira exactement deux valeurs pour la liste de sortie ; utilisant "undef" si les références d'array d'entrée sont courtes.

Entre "pairs" et "unpairs", une fonction de liste d'ordre supérieur peut être utilisée pour opérer sur les paires comme des scalaires uniques ; comme les quasi-équivalents suivants des autres fonctions d'ordre supérieur "pair*" :

@liste_kv = unpairs grep { FUNC } pairs @liste_kv
# Comme pairgrep, mais prend $_ au lieu de $a et $b
@liste_kv = unpairs map { FUNC } pairs @liste_kv
# Comme pairmap, mais prend $_ au lieu de $a et $b

Notez cependant que ces versions ne se comporteront pas aussi bien en contexte scalaire.

Enfin, cette technique peut être utilisée pour implémenter un tri sur une liste de paires clé-valeur ; par exemple :

@liste_kv = unpairs sort { $a->key cmp $b->key } pairs @liste_kv

pairkeys

my @cles = pairkeys @liste_kv;

Depuis la version 1.29.

Raccourci pratique pour opérer sur des listes de paires de taille paire, cette fonction retourne une liste des premiers éléments de chacune des paires dans la liste donnée. C'est une version plus efficace de

@cles = pairmap { $a } @liste_kv

pairvalues

my @valeurs = pairvalues @liste_kv;

Depuis la version 1.29.

Raccourci pratique pour opérer sur des listes de paires de taille paire, cette fonction retourne une liste des deuxièmes éléments de chacune des paires dans la liste donnée. C'est une version plus efficace de

@valeurs = pairmap { $b } @liste_kv

pairgrep

my @liste_kv = pairgrep { BLOC } @liste_kv;
my $count = pairgrep { BLOC } @liste_kv;

Depuis la version 1.29.

Similaire au mot-clé "grep" de Perl, mais interprète la liste donnée comme une liste de paires de taille paire. Il invoque le "BLOC" plusieurs fois, en contexte scalaire, avec $a et $b définis sur des paires successives de valeurs de @liste_kv.

Retourne une liste de taille paire de ces paires pour lesquelles le "BLOC" a retourné vrai en contexte de liste, o

r le nombre de paires en contexte scalaire. (Notez qu'en contexte scalaire, il renvoie un nombre égal à la moitié du nombre d'éléments qu'il aurait renvoyés en contexte de liste).

@subset = pairgrep { $a =~ m/^[[:upper:]]+$/ } @kvlist

Comme pour l'alias "grep" qui associe $_ aux éléments de la liste, "pairgrep" associe $a et $b aux éléments de la liste donnée. Toute modification effectuée par le bloc de code sera visible par l'appelant.

pairfirst

my ( $key, $val ) = pairfirst { BLOCK } @kvlist;
my $found = pairfirst { BLOCK } @kvlist;

Depuis la version 1.30.

Similaire à la fonction "first", mais interprète la liste donnée comme une liste de paires de taille paire. Elle invoque le "BLOCK" plusieurs fois, en contexte scalaire, avec $a et $b définis sur des paires successives de valeurs de @kvlist.

Renvoie la première paire de valeurs de la liste pour laquelle le "BLOCK" a renvoyé vrai en contexte de liste, ou une liste vide si aucune paire de ce type n'a été trouvée. En contexte scalaire, elle renvoie une simple valeur booléenne, plutôt que la clé ou la valeur trouvée.

( $key, $value ) = pairfirst { $a =~ m/^[[:upper:]]+$/ } @kvlist

Comme pour l'alias "grep" qui associe $_ aux éléments de la liste, "pairfirst" associe $a et $b aux éléments de la liste donnée. Toute modification effectuée par le bloc de code sera visible par l'appelant.

pairmap

my @list = pairmap { BLOCK } @kvlist;
my $count = pairmap { BLOCK } @kvlist;

Depuis la version 1.29.

Similaire au mot-clé "map" de Perl, mais interprète la liste donnée comme une liste de paires de taille paire. Elle invoque le "BLOCK" plusieurs fois, en contexte de liste, avec $a et $b définis sur des paires successives de valeurs de @kvlist.

Renvoie la concaténation de toutes les valeurs renvoyées par le "BLOCK" en contexte de liste, ou le nombre d'éléments qui auraient été renvoyés en contexte scalaire.

@result = pairmap { "La clé $a a la valeur $b" } @kvlist

Comme pour l'alias "map" qui associe $_ aux éléments de la liste, "pairmap" associe $a et $b aux éléments de la liste donnée. Toute modification effectuée par le bloc de code sera visible par l'appelant.

Voir "BOGUES CONNUS" pour un bogue connu avec "pairmap", et une solution de contournement.

AUTRES FONCTIONS

shuffle

my @values = shuffle @values;

Renvoie les valeurs d'entrée dans un ordre aléatoire.

@cards = shuffle 0..51      # 0..51 dans un ordre aléatoire

Cette fonction est affectée par la variable $RAND.

sample

my @items = sample $count, @values

Depuis la version 1.54.

Sélectionne aléatoirement le nombre donné d'éléments dans la liste d'entrée. Chaque position dans la liste d'entrée sera sélectionnée au plus une fois.

S'il y a moins de $count éléments dans la liste, la fonction renverra tous les éléments une fois qu'ils auront été sélectionnés aléatoirement ; la fonction se comporte donc de manière similaire à "shuffle".

Cette fonction est affectée par la variable $RAND.

uniq

my @subset = uniq @values

Depuis la version 1.45.

Filtre une liste de valeurs pour supprimer les doublons ultérieurs, tels que jugés par une égalité de chaînes de caractères DWIM (Do What I Mean) ou un test "undef". Préserve l'ordre des éléments uniques et conserve la première valeur de tout ensemble de doublons.

my $count = uniq @values

En contexte scalaire, renvoie le nombre d'éléments qui auraient été renvoyés sous forme de liste.

La valeur "undef" est traitée par cette fonction comme distincte de la chaîne vide, et aucun avertissement ne sera produit. Elle est laissée telle quelle dans la liste renvoyée. Les valeurs "undef" ultérieures sont toujours considérées comme identiques à la première et seront supprimées.

uniqint

my @subset = uniqint @values

Depuis la version 1.55.

Filtre une liste de valeurs pour supprimer les doublons ultérieurs, tels que jugés par un test d'égalité numérique entière. Préserve l'ordre des éléments uniques et conserve la première valeur de tout ensemble de doublons. Les valeurs de la liste renvoyée seront converties en entiers.

my $count = uniqint @values

En contexte scalaire, renvoie le nombre d'éléments qui auraient été renvoyés sous forme de liste.

Notez que "undef" est traité beaucoup comme d'autres opérations numériques le traitent ; il est égal à zéro mais produit en outre un avertissement si de tels avertissements sont activés ("use warnings 'uninitialized';"). De plus, un "undef" dans la liste renvoyée est converti en un zéro numérique, de sorte que l'intégralité des valeurs renvoyées par "uniqint" se comporte bien en tant qu'entiers.

uniqnum

my @subset = uniqnum @values

Depuis la version 1.44.

Filtre une liste de valeurs pour supprimer les doublons ultérieurs, tels que jugés par un test d'égalité numérique. Préserve l'ordre des éléments uniques et conserve la première valeur de tout ensemble de doublons.

my $count = uniqnum @values

En contexte scalaire, renvoie le nombre d'éléments qui auraient été renvoyés sous forme de liste.

Notez que "undef" est traité beaucoup comme d'autres opérations numériques le traitent ; il est égal à zéro mais produit en outre un avertissement si de tels avertissements sont activés ("use warnings 'uninitialized';"). De plus, un "undef" dans la liste renvoyée est converti en un zéro numérique, de sorte que l'intégralité des valeurs renvoyées par "uniqnum" se comporte bien en tant que nombres.

Notez également que plusieurs valeurs IEEE "NaN" sont traitées comme des doublons les unes des autres, quelles que soient les différences dans leurs charges utiles, et ce malgré le fait que "0+'NaN' == 0+'NaN'" renvoie faux.

uniqstr

my @subset = uniqstr @values

Depuis la version 1.45.

Filtre une liste de valeurs pour supprimer les doublons ultérieurs, tels que jugés par un test d'égalité de chaînes de caractères. Préserve l'ordre des éléments uniques et conserve la première valeur de tout ensemble de doublons.

my $count = uniqstr @values

En contexte scalaire, renvoie le nombre d'éléments qui auraient été renvoyés sous forme de liste.

Notez que "undef" est traité beaucoup comme d'autres opérations de chaînes de caractères le traitent ; il est égal à la chaîne vide mais produit en outre un avertissement si de tels avertissements sont activés ("use warnings 'uninitialized';"). De plus, un "undef" dans la liste renvoyée est converti en une chaîne vide, de sorte que l'intégralité des valeurs renvoyées par "uniqstr" se comporte bien en tant que chaînes de caractères.

head

my @values = head $size, @list;

Depuis la version 1.50.

Renvoie les $size premiers éléments de @list. Si $size est négatif, renvoie tous les éléments sauf les $size derniers de @list.

@result = head 2, qw( foo bar baz );
# foo, bar
@result = head -2, qw( foo bar baz );
# foo

tail

my @values = tail $size, @list;

Depuis la version 1.50.

Renvoie les $size derniers éléments de @list. Si $size est négatif, renvoie tous les éléments sauf les $size premiers de @list.

@result = tail 2, qw( foo bar baz );
# bar, baz
@result = tail -2, qw( foo bar baz );
# baz

List::SomeUtils FONCTIONS

Junctions

Traitement d'une liste vide

Il existe deux écoles de pensée quant à la manière d'évaluer une jonction sur une liste vide :

  • Réduction à une identité (booléenne)
  • Le résultat est indéfini (trois valeurs)

Dans le premier cas, le résultat de la jonction appliquée à la liste vide est déterminé par une réduction mathématique à une identité en fonction de la comparaison sous-jacente soit "ou" soit "et". Conceptuellement :

                "quelques-uns sont vrais"      "tous sont vrais"
                --------------      --------------
2 éléments:     A || B || 0         A && B && 1
1 élément:      A || 0              A && 1
0 élément:      0                   1

Dans le second cas, la logique à trois valeurs est souhaitée, où une jonction appliquée à une liste vide renvoie "undef" plutôt que vrai ou faux.

Les jonctions avec un suffixe "_u" implémentent la logique à trois valeurs. Celles sans suffixe sont booléennes.

all BLOCK LIST

all_u BLOCK LIST

Renvoie une valeur vraie si tous les éléments de LIST satisfont le critère donné à travers

List Functions

These functions are found in the List::Util module.

Boolean Operations

all BLOCK LIST

all_u BLOCK LIST

Returns a true value if all items in LIST meet the criterion given through BLOCK. Sets $_ for each item in LIST in turn:

print "Toutes les valeurs sont non-négatives"
  if all { $_ >= 0 } ($x, $y, $z);

Pour une LISTE vide, "all" renvoie true (c'est-à-dire qu'aucune valeur n'a échoué au test) et "all_u" renvoie "undef".

Ainsi, all_u(@list) est équivalent à "@list ? all(@list) : undef".

Note : comme Perl traite "undef" comme faux, vous devez vérifier la valeur de retour de "all_u" avec "defined", sinon vous obtiendrez le résultat inverse de celui attendu.

any BLOCK LIST

any_u BLOCK LIST

Renvoie une valeur vraie si au moins un élément de LIST satisfait le critère donné par BLOCK. Définit $_ pour chaque élément de LIST à tour de rôle :

print "Au moins une valeur non-négative"

sort_by BLOCK LIST

Retourne la liste de valeurs triées selon les valeurs chaîne retournées par le bloc KEYFUNC ou la fonction. Une utilisation typique pourrait être de trier des objets selon la valeur chaîne d'un certain accès, comme :

sort_by { $_->name } @people

La fonction clé est appelée en contexte scalaire, chaque valeur étant passée à tour de rôle à $_ et comme unique argument dans les paramètres, @_. Les valeurs sont triées selon les comparaisons de chaînes des valeurs retournées. Ceci est équivalent à :

sort { $a->name cmp $b->name } @people

Bien que cela garantisse que l'accès au nom ne sera effectué qu'une seule fois par valeur. Une utilisation intéressante est de trier des chaînes qui peuvent contenir des nombres intégrés "naturellement" plutôt que lexicalement :

sort_by { s/(\d+)/sprintf "%09d", $1/eg; $_ } @strings

Ceci trie les chaînes en générant des clés de tri qui remplissent de zéros les nombres intégrés à un certain niveau (9 chiffres dans ce cas), assurant ainsi un tri lexical correct.

minmax LIST

Calcule le minimum et le maximum de LIST et retourne une liste de deux éléments, le premier élément étant le minimum et le second le maximum. Retourne une liste vide si LIST était vide.

L'algorithme minmax diffère d'une itération naïve où chaque élément est comparé à deux valeurs, les valeurs courantes de min et max mises à jour. Il ne nécessite que 3n/2 - 2 comparaisons, ce qui en fait l'algorithme le plus efficace possible.

Cependant, l'implémentation Perl de cet algorithme a une certaine surcharge due au plus grand nombre de lignes de code Perl impliquées. Par conséquent, LIST doit être relativement grand pour que minmax soit plus avantageux qu'une implémentation naïve. Cette limitation ne s'applique pas à la version XS.

mode LIST

Calcule les éléments les plus courants dans la liste et les retourne sous forme de liste. Ceci est effectué par des comparaisons de chaînes, donc les références sont sérialisées sous forme de chaînes. Si elles implémentent la surcharge de chaînes, cette fonctionnalité sera utilisée.

Si plus d'un élément apparaît le même nombre de fois dans la liste, tous ces éléments sont retournés. Par exemple, le mode d'une liste unique est la liste elle-même.

Cette fonction retourne une liste en contexte de liste. En contexte scalaire, elle retourne un compte indiquant le nombre de modes dans la liste.

my %nums = zip_by { @_ } [qw( one two three )], [ 1, 2, 3 ];

LIST-REDUCTION FUNCTIONS

product

Returns the product of the elements of the list.

sum

Returns the sum of the elements of the list.

KEY/VALUE PAIR LIST FUNCTIONS

hash_kv

Takes a list of key/value pairs and returns a hash reference.

For example:

    my @list = (
        'key1', 'value1',
        'key2', 'value2',
        'key3', 'value3',
    );
    my $hash = hash_kv(@list);
    # $hash is { key1 => 'value1', key2 => 'value2', key3 => 'value3' }
kv_hash

An alias for "hash_kv".

OTHER FUNCTIONS

clamp

Takes a list of three numbers, and returns the first number clamped to be within the range defined by the second and third numbers.

For example:

    clamp(5, 1, 10)  # returns 5
    clamp(15, 1, 10) # returns 10
    clamp(0, 1, 10)  # returns 1
deep_compact

Recursively removes empty elements from a list. Empty elements are defined as undef, empty strings, empty arrays, and empty hashes.

deep_flatten

Recursively flattens a list of lists into a single list.

difference

Returns the list of elements in the first list that are not present in any of the subsequent lists.

For example:

    difference([1, 2, 3], [2, 4], [3, 5]) # returns [1]
distinct

Returns a list with duplicate elements removed. The order of the remaining elements is preserved.

duplicate

Returns a list of elements that appear more than once in the input list. The order of the returned elements is determined by the order in which the second occurrence of each element appears.

For example:

    duplicate([1, 2, 3, 2, 4, 1, 5]) # returns [2, 1]
each_slice

Similar to a regular "map" functional, returns a list of the values returned by "BLOCKFUNC". Values from the input list are given to the block function in bundles of $number.

If given a list of values whose length does not evenly divide by $number, the final call will be passed fewer elements than the others.

ends_with

Given a list and a suffix, returns true if the list ends with the suffix.

For example:

    ends_with([1, 2, 3], [2, 3]) # returns true
    ends_with([1, 2, 3], [1, 2]) # returns false
flatten

Flattens a list of lists into a single list. Only flattens one level deep.

grep_recursive

Recursively searches through a list of lists and returns all elements that match the given predicate.

head

Returns the first element of a list.

indexed_list

Takes a list and returns a list of arrays, where each inner array contains an index and the corresponding element from the original list.

For example:

    indexed_list(['a', 'b', 'c']) # returns [[0, 'a'], [1, 'b'], [2, 'c']]
intersection

Returns the list of elements that are present in all of the input lists.

For example:

    intersection([1, 2, 3], [2, 3, 4], [3, 4, 5]) # returns [3]
is_anagram

Given two lists, returns true if they are anagrams of each other (i.e., contain the same elements with the same frequencies, but possibly in a different order).

is_empty

Returns true if the given list is empty, or if it contains only empty elements (see "deep_compact").

is_scalar_ref

Returns true if the argument is a reference to a scalar value.

join_map

Takes a separator, a block function, and a list. It applies the block function to each element of the list, and then joins the results with the separator.

For example:

    join_map('-', sub { uc($_[0]) }, ['a', 'b', 'c']) # returns "A-B-C"
map_by

Takes a list and a key-generating function. It returns a hash where the keys are generated by the function, and the values are the corresponding elements from the list.

For example:

    my @people = (
        { name => 'Alice', age => 30 },
        { name => 'Bob',   age => 25 },
        { name => 'Charlie', age => 30 },
    );
    my $people_by_age = map_by { $_->{age} } @people;
    # $people_by_age is { 25 => { name => 'Bob', age => 25 }, 30 => { name => 'Charlie', age => 30 } }
    # Note that if multiple elements map to the same key, only the last one is kept.
max

Returns the maximum element in the list.

min

Returns the minimum element in the list.

none

Takes a predicate and a list. Returns true if no element in the list satisfies the predicate.

onlyovs

Takes a list and returns a new list containing only the odd-positioned elements (1st, 3rd, 5th, etc.).

pair_first

Takes a list and returns a list of key/value pairs, where the keys are the elements at even indices and the values are the elements at odd indices.

For example:

    pair_first('a', 'b', 'c', 'd') # returns [['a', 'b'], ['c', 'd']]
pair_hash

Takes a hash reference and returns a list of key/value pairs.

For example:

    my $hash = { key1 => 'value1', key2 => 'value2' };
    pair_hash($hash) # returns [['key1', 'value1'], ['key2', 'value2']]
pair_last

Takes a list and returns a list of key/value pairs, where the keys are the elements at odd indices and the values are the elements at even indices (starting from the second element).

For example:

    pair_last('a', 'b', 'c', 'd') # returns [['b', 'c'], ['d', 'a']] (wraps around)
pairs

An alias for "pair_first".

partition

Takes a predicate and a list. Returns a two-element list, where the first element is a list of elements that satisfy the predicate, and the second element is a list of elements that do not.

pick

Takes a list and returns a random element from it.

pluck

Takes a list of hash references (or array references) and a key (or index). Returns a list of the values corresponding to that key (or index) from each hash (or array) in the input list.

For example:

    my @people = (
        { name => 'Alice', age => 30 },
        { name => 'Bob',   age => 25 },
    );
    pluck(\@people, 'name') # returns ['Alice', 'Bob']
    pluck(\@people, 'age')  # returns [30, 25]
prepend

Takes a list of elements and prepends them to the beginning of the given list.

For example:

    prepend(1, 2, 3, [4, 5, 6]) # returns [1, 2, 3, 4, 5, 6]
push_deref

Takes a reference to an array and one or more values. Pushes the values onto the array referenced.

rand_list

Returns a list of random elements from the input list. The number of elements to return is specified by the first argument.

For example:

    rand_list(3, 1, 2, 3, 4, 5) # returns a list of 3 random elements from [1, 2, 3, 4, 5]
reduce_with

A generalized version of "reduce". Takes a binary function and a list. Applies the function cumulatively to the items of the list, from left to right, so as to reduce the list to a single value.

For example:

    reduce_with(sub { $_[0] + $_[1] }, [1, 2, 3, 4]) # returns 10
    reduce_with(sub { $_[0] x $_[1] }, [2, 3, 4])    # returns "8" (2 * 3 * 4)
repeat

Takes an element and a number n, and returns a list containing n copies of the element.

For example:

    repeat('a', 3) # returns ['a', 'a', 'a']
replace

Takes a list, a list of elements to find, and a list of elements to replace them with. Returns a new list with the replacements made.

For example:

    replace([1, 2, 3, 4], [2, 4], [20, 40]) # returns [1, 20, 3, 40]
reverse_list

Reverses the given list.

rotate

Rotates the elements of a list. A positive argument rotates to the right, a negative argument rotates to the left.

For example:

    rotate(1, [1, 2, 3, 4]) # returns [4, 1, 2, 3]
    rotate(-1, [1, 2, 3, 4]) # returns [2, 3, 4, 1]
set_difference

Returns the set difference of two lists. Elements in the first list that are not in the second list.

set_intersection

Returns the set intersection of two lists. Elements common to both lists.

set_symmetric_difference

Returns the symmetric difference of two lists. Elements in either list, but not both.

set_union

Returns the set union of two lists. All unique elements from both lists.

shuffle

Randomly permutes the elements of a list.

slice

Takes a list and a list of indices, and returns a new list containing the elements at those indices.

For example:

    slice([1, 2, 3, 4, 5], [0, 2, 4]) # returns [1, 3, 5]
slice_by

Takes a list and a predicate. Returns a list of lists, where each inner list is a slice of consecutive elements that satisfy the predicate.

starts_with

Given a list and a prefix, returns true if the list starts with the prefix.

For example:

    starts_with([1, 2, 3], [1, 2]) # returns true
    starts_with([1, 2, 3], [2, 3]) # returns false
symmetric_difference

Returns the list of elements that are in either the first list or the second list, but not in both.

For example:

    symmetric_difference([1, 2, 3], [3, 4, 5]) # returns [1, 2, 4, 5]
tail

Returns all elements of a list except the first one.

take

Takes the first n elements from a list.

For example:

    take(3, [1, 2, 3, 4, 5]) # returns [1, 2, 3]
take_random

Takes n random elements from a list.

For example:

    take_random(3, [1, 2, 3, 4, 5]) # returns a list of 3 random elements from [1, 2, 3, 4, 5]
take_while

Takes elements from the beginning of a list as long as the predicate is true.

through

Takes a list and a function. It applies the function to each element of the list, and returns the list of results. This is essentially an alias for map.

times

Takes a list and a number n. It returns a new list containing n copies of the original list, concatenated together.

For example:

    times(2, [1, 2]) # returns [1, 2, 1, 2]
to_hash

Takes a list of key/value pairs and returns a hash reference.

For example:

    my @list = (
        'key1', 'value1',
        'key2', 'value2',
        'key3', 'value3',
    );
    my $hash = to_hash(@list);
    # $hash is { key1 => 'value1', key2 => 'value2', key3 => 'value3' }
to_list

Takes a reference to a scalar, array, or hash, and returns a list containing the corresponding elements. If given a scalar, it returns a single-element list. If given an array reference, it returns a copy of the array. If given a hash reference, it returns a list of key/value pairs.

transpose

Transposes a list of lists. The first row of the result contains the first element of each of the input lists. The second row contains the second element of each input list, and so on.

For example:

    transpose([[1, 2, 3], [4, 5, 6]]) # returns [[1, 4], [2, 5], [3, 6]]
trim

Removes leading and trailing whitespace from each string element in a list.

unbias

Takes a list of elements that may contain duplicates, and returns a list of unique elements. The order is preserved.

union

Returns the union of two lists. All unique elements from both lists.

For example:

    union([1, 2, 3], [3, 4, 5]) # returns [1, 2, 3, 4, 5]
unique

An alias for "distinct".

where

Takes a list and a predicate. Returns a list of elements that satisfy the predicate.

For example:

    where(sub { $_[0] % 2 == 0 }, [1, 2, 3, 4, 5]) # returns [2, 4]
zip

Takes two or more lists and returns a list of lists, where the first inner list contains the first element from each input list, the second inner list contains the second element from each input list, and so on. The resulting list will have the length of the shortest input list.

For example:

    zip([1, 2, 3], ['a', 'b', 'c']) # returns [[1, 'a'], [2, 'b'], [3, 'c']]
zip_longest

Similar to "zip", but the resulting list will have the length of the longest input list. Missing elements are filled with undef.

For example:

    zip_longest([1, 2], ['a', 'b', 'c']) # returns [[1, 'a'], [2, 'b'], [undef, 'c']]
zip_map

Takes a block function and two or more lists. Applies the block function to corresponding elements from the lists and returns a list of the results.

For example:

    zip_map(sub { $_[0] + $_[1] }, [1, 2, 3], [4, 5, 6]) # returns [5, 7, 9]
