NOM

IptablesDlfConverter - convertir les journaux syslog de netfilter/iptables au format DLF de pare-feu

DESCRIPTION

IptablesDlfConverter convertit les journaux de paquets iptables du noyau Linux 2.4 au format DLF (Data Log File) du pare-feu.

LIMITATIONS

Les modules de journalisation de netfilter ne consignent pas le statut du paquet (rejeté, accepté, refusé) comme le fait le code de journalisation d'ipchains. Vous pouvez spécifier un préfixe qui sera utilisé dans le journal. Ce convertisseur marquera le paquet comme 'denied' (refusé) chaque fois que ce préfixe correspond (insensible à la casse) à l'expression régulière suivante : 'denied|deny|drop|reject|unallowed'. Il marquera le paquet comme 'permitted' (permis) chaque fois que ce préfixe correspond (insensible à la casse) à l'expression régulière suivante : 'accept|permit', et tous les autres paquets auront '-' comme valeur du champ 'action'.

Ainsi, pour que ce convertisseur puisse détecter les paquets 'denied', vous devriez utiliser un préfixe contenant l'une de ces sous-chaînes.

Par exemple :

iptables -N lodrop
iptables -A logdrop -j LOG --log-prefix "Packet-DENY: "
iptables -A logdrop -j DROP

ou d'autres préfixes similaires : 'denied: ', 'Packet-REJECT: ', ...

Le préfixe utilisé finira dans le champ 'rule' de l'enregistrement DLF.

EXEMPLES

IptablesDlfConverter sera rarement utilisé seul, mais est plus susceptible d'être appelé par lr_log2report :

$ lr_log2report iptables < /var/log/iptables.log > report
