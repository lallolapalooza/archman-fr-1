NOM

Linux::Pid - Obtenir le PID natif et le PPID sous Linux

SYNOPSIS

use Linux::Pid;
print Linux::Pid::getpid(), "\t", Linux::Pid::getppid(), "\n";
use Linux::Pid qw(getpid getppid);
print getpid(), "\t", getppid(), "\n";

DESCRIPTION

Pourquoi utiliser un module pour obtenir le PID et le PPID d'un processus alors qu'il existe la variable $$ et la fonction intégrée getppid() ? (Sans mentionner les fonctions équivalentes POSIX::getpid() et POSIX::getppid().)

En fait, cela est utile sous Linux, avec les programmes multithreadés. La bibliothèque C de Linux, utilisant le modèle de thread linux, renvoie des valeurs différentes de PID et de PPID à partir de différents threads. (D'autres modèles de threads comme NPTL n'ont pas le même comportement). Ce module force Perl à appeler les fonctions C sous-jacentes getpid() et getppid().
