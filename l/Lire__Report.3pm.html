NOM

Lire::Report - Interface à un rapport Lire.

SYNOPSIS

use Lire::ReportParser::ReportBuilder;
my $parser = new Lire::ReportParser::ReportBuilder;
my $report = $parser->parse( "report.xml" );
print $report->superservice(), " report\n";
print "Généré le ", scalar( localtime( $report->date() ) ), "\n";
print "Période commence le ", scalar( localtime( $report->timespan_start() ) ), "\n";
print "Période se termine le ", scalar( localtime( $report->timespan_start() ) ), "\n";
foreach my $s ( $report->sections() ) {
    print "Section : '", $s->title(), "' a ", scalar $s->subreports(),
        " sous-rapports en son sein\n";
}

DESCRIPTION

Ce module offre une API au rapport généré par Lire. Le module Lire::ReportParser::ReportBuilder(3pm) peut être utilisé pour créer un objet Lire::Report à partir d'un fichier XML conforme à la DTD Lire Report Markup Language.

CONSTRUCTEUR

Un objet Lire::Report peut être construit à partir d'un fichier de rapport XML, à partir de la méthode new() ou à partir d'un objet Lire::ReportConfig.

new( [ $period_periode ], [ $debut_periode ], [ $fin_periode ] )

Crée un nouveau Lire::Report. Les paramètres $period_periode, $debut_periode et $fin_periode initialisent les attributs du même nom.

MÉTHODES OBJET

version()

Retourne le numéro de version du format de rapport utilisé dans la représentation externe de ce rapport. La version actuelle est 2.1.

generator([$generator)

Retourne la chaîne du générateur qui sera affichée dans les commentaires lorsque la méthode write_report() est utilisée. On peut changer cette valeur en passant une nouvelle valeur via le paramètre $generator.

date( [ $nouvelle_date ] )

Retourne (et modifie optionnellement) la date en secondes depuis l'époque à laquelle ce rapport a été généré.

timespan_period( [ $nouvelle_periode ] )

Retourne (et modifie optionnellement) la période du rapport. La période peut être 'hourly', 'daily', 'weekly', 'monthly' ou 'yearly'. Lorsque la période est indéfinie, il s'agit d'une période arbitraire.

timespan_start( [ $nouveau_debut ] )

Retourne (et modifie optionnellement) le début de la période couverte par ce rapport en secondes depuis l'époque.

timespan_end( [ $nouvelle_fin ] )

Retourne (et modifie optionnellement) la fin de la période couverte par ce rapport en secondes depuis l'époque.

title( [$titre] )

Retourne le titre du rapport, s'il en a un.

Si le paramètre $titre est défini, le titre du rapport sera défini à cette nouvelle valeur.

description( [$nouvelle_desc] )

Retourne la description du rapport. Cette description est encodée en DocBook XML.

Si le paramètre $description est défini, cette méthode définira la description à cette nouvelle valeur. Si le paramètre $description est indéfini, cette description sera supprimée.

sections( )

Retourne les sections du rapport sous forme de tableau. Ce sera un tableau d'objets Lire::Report::Section.

add_section( $section )

Ajoute une section à ce rapport. Le paramètre $section doit être un objet Lire::Report::Section.

subreport_by_id( $id )

Retourne l'objet Lire::Report::Subreport avec l'identifiant $id. Retourne undef lorsqu'il n'y a pas de sous-rapport avec cet identifiant.

schemas()

Retourne une référence de tableau contenant tous les schémas utilisés par ce rapport.

write_report( [FH] );

Écrit le rapport au format XML sur le descripteur de fichier FH ou sur STDOUT si omis.

Cette méthode prend soin d'ajouter des éléments tels que l'en-tête XML "<?xml version=[...]". Elle encode le rapport XML en UTF-8, en utilisant Lire::I18N::set_fh_encoding().

delete( )

Supprime toutes les références circulaires afin que l'objet puisse être libéré.
