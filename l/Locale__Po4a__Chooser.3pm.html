NOM

Locale::Po4a::Chooser - gérer les modules po4a

DESCRIPTION

Locale::Po4a::Chooser est un module pour gérer les modules po4a. Auparavant, tous les binaires po4a connaissaient tous les modules po4a (pod, man, sgml, etc.). Cela rendait l'ajout d'un nouveau module fastidieux, car il fallait s'assurer que la documentation était synchronisée dans tous les modules, et que chacun d'eux pouvait accéder au nouveau module.

Maintenant, il suffit d'appeler la fonction Locale::Po4a::Chooser::new() en passant le nom du module comme argument.

La fonction Locale::Po4a::Chooser::list() liste les formats disponibles et se termine avec la valeur passée en argument. Ainsi, nous appelons Locale::Po4a::Chooser::list(0) lorsque la liste des formats est demandée, et Locale::Po4a::Chooser::list(1) lorsqu'un nom de format invalide est passé.
