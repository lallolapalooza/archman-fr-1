Module Load_path.Dir

DOCUMENTATION

Module Dir
: sig end

type t

Représente un répertoire dans le chemin de chargement.

val create : hidden:bool -> string -> t

val path : t -> string

val files : t -> string list

Tous les fichiers de ce répertoire. Cela n'inclut pas les fichiers des sous-répertoires de ce répertoire.

val hidden : t -> bool

Si les modules de ce répertoire ne doivent pas être liés dans la portée initiale

val find : t -> string -> string option

find dir fn renvoie le chemin complet vers fn dans dir.

val find_normalized : t -> string -> string option

Comme Load_path.Dir.find, mais recherche également le nom non capitalisé, c'est-à-dire si le nom est Foo.ml, /chemin/Foo.ml ou /chemin/foo.ml peut être retourné.
