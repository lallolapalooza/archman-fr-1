NOM

Locale::RecodeData::NATS_SEFI - Fonctions de conversion pour NATS_SEFI

SYNTAXE

Ce module est interne à libintl. Ne l'utilisez pas directement !

DESCRIPTION

Ce module contient la table de conversion et les fonctions pour NATS-SEFI.

COMMENTAIRES

Les observations suivantes ont été extraites du charmap d'origine :

 version : 1.0
 source : ECMA Register
 alias ISO-IR-8-1

Veuillez noter que les alias mentionnés ci-dessus ne sont pas nécessairement valides !
