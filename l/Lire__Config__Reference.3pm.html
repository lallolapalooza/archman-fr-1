NOM

Lire::Config::Reference - Scalaire qui pointe vers un Index.

SYNTAXE

use Lire::Config::Reference;

DESCRIPTION

Il s'agit d'un scalaire provenant d'un Lire::Config::ReferenceSpec et qui retournera l'entrée référencée dans l'Index lors de l'appel à as_value().
