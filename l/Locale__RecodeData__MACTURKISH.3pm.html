NAME

Locale::RecodeData::MACTURKISH - Macintosh Turkish encoding

SYNOPSIS

  use Locale::RecodeData 'MACTURKISH';

DESCRIPTION

This module provides the Macintosh Turkish encoding. It is a subclass of Locale::RecodeData(3).

COMMENTS

This encoding is obsolete and has been replaced by the ISO-8859-9 and Windows-1254 encodings.
