NAME

Locale::RecodeData::MACARABIC - Fonctions de conversion pour MACARABIC

SYNOPSIS

Ce module est interne à libintl. Ne l'utilisez pas directement !

DESCRIPTION

Ce module contient les tables et les fonctions de conversion pour MACARABIC.
