NOM

Locale::RecodeData::CP10007 - Routines de conversion pour CP10007

SYNTAXE

Ce module est interne à libintl. Ne pas utiliser directement !

DESCRIPTION

Ce module est généré et contient les tables et routines de conversion pour CP10007.

COMMENTAIRES

Les commentaires suivants ont été extraits de la table de caractères d'origine :

This is the old MacCyrillic which M$ keeps around as CP10007.

Veuillez noter que les alias listés ci-dessus ne sont pas nécessairement valides !
