NOM

Log::Log4perl::Appender::Screen - Journaliser vers STDOUT/STDERR

SYNTAXE

use Log::Log4perl::Appender::Screen;
my $app = Log::Log4perl::Appender::Screen->new(
  autoflush => 1,
  stderr    => 0,
  utf8      => 1,
);
$file->log(message => "Journaliser moi\n");

DESCRIPTION

Ceci est un simple appendice pour écrire vers STDOUT ou STDERR.

Le constructeur new() accepte un paramètre optionnel "stderr":

  • S'il est défini à une valeur fausse, il journalisera tous les niveaux vers STDOUT (ou, plus précisément, le flux de fichiers sélectionné via select(), STDOUT par défaut).
  • S'il est défini à une table de hachage, alors tout "log4p_level" avec une valeur vraie utilisera dynamiquement STDERR, ou STDOUT sinon.
  • Sinon, si une valeur vraie (le réglage par défaut est 1), les messages seront journalisés vers STDERR.
# Tous les messages/niveaux vers STDERR
my $app = Log::Log4perl::Appender::Screen->new(
    stderr  => 1,
);
# SEULEMENT ERROR et FATAL vers STDERR (sensible à la casse)
my $app = Log::Log4perl::Appender::Screen->new(
    stderr  => { ERROR => 1, FATAL => 1},
);

La conception et l'implémentation de ce module ont été grandement inspirées par le framework d'appendice "Log::Dispatch" de Dave Rolsky.

Pour activer l'impression de caractères utf8 larges, définissez l'option utf8 à une valeur vraie :

my $app = Log::Log4perl::Appender::Screen->new(
  stderr    => 1,
  utf8      => 1,
);

Ceci émettra la commande binmode nécessaire sur le canal de sortie sélectionné (stderr/stdout).

Pour activer le vidage automatique, définissez l'option "autoflush" à une valeur vraie :

my $app = Log::Log4perl::Appender::Screen->new(
  autoflush => 1,
);

Ceci émettra la commande autoflush nécessaire sur le canal de sortie sélectionné (stderr/stdout).

Ceci est requis dans les conteneurs, en particulier lorsque le volume de logs est faible, pour ne pas mettre en mémoire tampon les messages de log et causer un délai important.
