NOM

List::Compare::Functional - Comparer des éléments de deux listes ou plus

VERSION

Ce document fait référence à la version 0.55 de List::Compare::Functional. Cette version a été publiée le 16 août 2020. La première version publiée de List::Compare::Functional était la v0.21. Les numéros de version sont conformes aux autres éléments de la distribution List::Compare.

Notes de version sur l'interface

Avec l'introduction de la version 0.25 en avril 2004, des changements significatifs ont été apportés à l'interface de List::Compare::Functional. La documentation ci-dessous reflète ces changements, donc si vous utilisez ce module pour la première fois avec cette version ou une version ultérieure, lisez simplement et suivez la documentation ci-dessous. Cependant, si vous avez déjà utilisé List::Compare::Functional avant la version 0.25, consultez la discussion des changements d'interface plus loin : Changement d'interface d'avril 2004.

SYNOPSIS

Pour commencer

List::Compare::Functional n'exporte aucune sous-routine par défaut.

use List::Compare::Functional qw(:originals :aliases);

importe toutes les sous-routines publiques de List::Compare::Functional. Le modèle pour importer une seule sous-routine de List::Compare::Functional est le suivant :

use List::Compare::Functional qw( get_intersection );

Il sera probablement plus pratique pour l'utilisateur d'importer des fonctions en utilisant l'une des deux balises d'exportation suivantes :

use List::Compare::Functional qw(:main :mainrefs);

L'attribution des fonctions de comparaison aux balises d'exportation est discutée plus loin.

Pour plus de clarté, nous commencerons par discuter des comparaisons de seulement deux listes. Plus tard, nous discuterons des comparaisons de trois listes ou plus.

Comparaison de deux listes stockées dans des tableaux

  • On vous donne deux listes : 
    @Llist = qw(abel abel baker camera delta edward fargo golfer);
@Rlist = qw(baker camera delta delta edward fargo golfer hilton);
  • Obtenez les éléments qui apparaissent au moins une fois dans les deux listes (leur intersection). 
    @intersection = get_intersection( [ \@Llist, \@Rlist ] );

    Remarque : vous pouvez placer des références aux listes à comparer dans un tableau nommé, puis passer une référence à ce tableau à get_intersection().

    @to_be_compared = ( \@Llist, \@Rlist );
@intersection = get_intersection( \@to_be_compared );

    Depuis la version 0.29 (mai 2004), List::Compare::Functional offre une méthode supplémentaire pour passer des arguments à ses fonctions. Si vous préférez une séparation plus explicite entre les types d'arguments passés à une fonction, passez une référence de hachage unique contenant les listes à comparer dans un tableau anonyme, qui est la valeur correspondante à la clé "lists" :

    @intersection = get_intersection( {
   lists => [ \@Llist, \@Rlist ],
} );
  • Obtenez les éléments qui apparaissent au moins une fois dans chaque liste (leur union). 
    @union = get_union( [ \@Llist, \@Rlist ] );

    ou

    @union = get_union( { lists => [ \@Llist, \@Rlist ] } );
  • Obtenez les éléments qui apparaissent (au moins une fois) uniquement dans la première liste. 
    @Lonly = get_unique( [ \@Llist, \@Rlist ] );

    ou

    @Lonly = get_unique( { lists => [ \@Llist, \@Rlist ] } );
  • Obtenez les éléments qui apparaissent (au moins une fois) uniquement dans la deuxième liste. 
    @Ronly = get_complement( [ \@Llist, \@Rlist ] );

    ou

    @Ronly = get_complement( { lists => [ \@Llist, \@Rlist ] } );
  • @LorRonly = get_symmetric_difference( [ \@Llist, \@Rlist ] );
@LorRonly = get_symdiff( [ \@Llist, \@Rlist ] );       # alias

    ou

    @LorRonly = get_symmetric_difference( { lists => [ \@Llist, \@Rlist ] } );
  • Génère un sac de tous les éléments des deux listes. Le sac diffère de l'union des deux listes en ce qu'il conserve autant de copies de chaque élément qu'il apparaît dans les listes d'origine. 
    @bag = get_bag( [ \@Llist, \@Rlist ] );

    ou

    @bag = get_bag( { lists => [ \@Llist, \@Rlist ] } );
  • Une approche alternative aux fonctions précédentes : si vous n'avez pas besoin d'un tableau comme valeur de retour de l'appel de fonction, mais que vous avez simplement besoin d'une *référence* à un tableau anonyme, utilisez l'une des sous-routines suivantes : 
    $intersection_ref = get_intersection_ref(         [ \@Llist, \@Rlist ] );
$union_ref        = get_union_ref(                [ \@Llist, \@Rlist ] );
$Lonly_ref        = get_unique_ref(               [ \@Llist, \@Rlist ] );
$Ronly_ref        = get_complement_ref(           [ \@Llist, \@Rlist ] );
$LorRonly_ref     = get_symmetric_difference_ref( [ \@Llist, \@Rlist ] );
$LorRonly_ref     = get_symdiff_ref(              [ \@Llist, \@Rlist ] );
                        # alias
$bag_ref          = get_bag_ref(                  [ \@Llist, \@Rlist ] );

    ou

    $intersection_ref =
    get_intersection_ref(         { lists => [ \@Llist, \@Rlist ] } );
$union_ref        =
    get_union_ref(                { lists => [ \@Llist, \@Rlist ] } );
$Lonly_ref        =
    get_unique_ref(               { lists => [ \@Llist, \@Rlist ] } );
$Ronly_ref        =
    get_complement_ref(           { lists => [ \@Llist, \@Rlist ] } );
$LorRonly_ref     =
    get_symmetric_difference_ref( { lists => [ \@Llist, \@Rlist ] } );
$LorRonly_ref     =
    get_symdiff_ref(              { lists => [ \@Llist, \@Rlist ] } );
    # alias
$bag_ref          =
    get_bag_ref(                  { lists => [ \@Llist, \@Rlist ] } );
  • Renvoie une valeur vraie si la première liste ('L' pour 'gauche') est un sous-ensemble de la deuxième liste ('R' pour 'droite'). 
    $LR = is_LsubsetR( [ \@Llist, \@Rlist ] );

    ou

    $LR = is_LsubsetR( { lists => [ \@Llist, \@Rlist ] } );
  • Renvoie une valeur vraie si 'R' est un sous-ensemble de 'L'. 
    $RL = is_RsubsetL( [ \@Llist, \@Rlist ] );

    ou

    $RL = is_RsubsetL( { lists => [ \@Llist, \@Rlist ] } );
  • Renvoie une valeur vraie si 'L' et 'R' sont équivalentes, c'est-à-dire si chaque élément de 'L' apparaît au moins une fois dans 'R' et vice versa. 
    $eqv = is_LequivalentR( [ \@Llist, \@Rlist ] );
$eqv = is_LeqvlntR( [ \@Llist, \@Rlist ] );            # alias

    ou

    $eqv = is_LequivalentR( { lists => [ \@Llist, \@Rlist ] } );
  • Renvoie une valeur vraie si 'L' et 'R' sont disjointes, c'est-à-dire si elles n'ont aucun élément en commun. 
    $disj = is_LdisjointR( [ \@Llist, \@Rlist ] );

    ou

    $disj = is_LdisjointR( { lists => [ \@Llist, \@Rlist ] } );
  • Imprime un tableau formaté de manière stylisée qui indique si une liste est un sous-ensemble de l'autre. 
    print_subset_chart( [ \@Llist, \@Rlist ] );

    ou

    print_subset_chart( { lists => [ \@Llist, \@Rlist ] } );
  • Imprime un tableau formaté de manière stylisée qui indique si les deux listes sont équivalentes (ont les mêmes éléments, au moins une fois dans chaque). 
    print_equivalence_chart( [ \@Llist, \@Rlist ] );

    ou

    print_equivalence_chart( { lists => [ \@Llist, \@Rlist ] } );
  • Détermine dans quelles listes (le cas échéant) une chaîne de caractères peut être trouvée. Dans le contexte d'une liste, renvoie une liste d'indices correspondant aux listes qui contiennent la chaîne testée. 
    @memb_arr = is_member_which( [ \@Llist, \@Rlist ] , [ 'abel' ] );

    ou

    @memb_arr = is_member_which( {
    lists => [ \@Llist, \@Rlist ],  # la valeur est une référence
    item  => 'abel',                # la valeur est une chaîne
} );

    Dans l'exemple ci-dessus, @memb_arr sera :

    ( 0 )

    car 'abel' se trouve uniquement dans @Al, qui contient la position 0 dans la liste d'arguments passée à new().

  • Comme d'autres fonctions de List::Compare::Functional qui renvoient un tableau, vous pouvez demander que la fonction renvoie une référence scalaire à un tableau contenant le tableau. 
    $memb_arr_ref = is_member_which_ref( [ \@Llist
, \@Rlist ] , [ 'baker' ] );

ou

$memb_arr_ref = is_member_which_ref( {
    lists => [ \@Llist, \@Rlist ],  # la valeur est une référence de tableau
    item  => 'baker',               # la valeur est une chaîne de caractères
} );

Dans l'exemple ci-dessus, $memb_arr_ref sera :

[ 0, 1 ]

car 'baker' se trouve dans @Llist et @Rlist, qui occupent respectivement les positions 0 et 1 dans la liste des arguments passés à new().

Note : les fonctions is_member_which() et "is_member_which_ref" ne testent qu'une chaîne à la fois et ne prennent donc qu'un seul argument. Pour tester plusieurs chaînes à la fois, voir la fonction suivante, are_members_which().

  • Détermine dans "quel" (le cas échéant) des listes passées en argument on peut trouver une ou plusieurs chaînes données. Les listes recherchées sont placées dans un tableau, dont une référence est le premier argument passé à are_members_which(). Les chaînes à tester sont également placées dans un tableau, dont une référence est le second argument passé à cette fonction. 
    $memb_hash_ref =
    are_members_which( [ \@Llist, \@Rlist ] ,
                       [ qw| abel baker fargo hilton zebra | ]
                     );

    ou

    $memb_hash_ref = are_members_which( {
    lists => [ \@Llist, \@Rlist ],                    # la valeur est une référence de tableau
    items => [ qw| abel baker fargo hilton zebra | ], # la valeur est une référence de tableau
} );

    La valeur de retour est une référence à une table de hachage contenant des tableaux. La clé pour chaque élément de cette table de hachage est la chaîne testée. La valeur de chaque élément est une référence à un tableau anonyme dont les éléments sont les indices dans la liste des arguments du constructeur correspondant aux listes contenant les chaînes testées. Dans les exemples ci-dessus, $memb_hash_ref sera :

    {
     abel     => [ 0    ],
     baker    => [ 0, 1 ],
     fargo    => [ 0, 1 ],
     hilton   => [    1 ],
     zebra    => [      ],
};

    Note : are_members_which() peut prendre plusieurs arguments ; is_member_which() et is_member_which_ref() ne prennent chacun qu'un seul argument. Contrairement à ces fonctions, are_members_which() retourne une référence de table de hachage.

  • Détermine si une chaîne donnée peut être trouvée dans *l'une quelconque* des listes passées en argument. Renvoie 1 si une chaîne spécifiée peut être trouvée dans l'une des listes et 0 sinon. 
    $found = is_member_any( [ \@Llist, \@Rlist ] , [ 'abel' ] );

    ou

    $found = is_member_any( {
    lists => [ \@Llist, \@Rlist ], # la valeur est une référence de tableau
    item  => 'abel',               # la valeur est une chaîne de caractères
} );

    Dans l'exemple ci-dessus, $found sera 1 car 'abel' se trouve dans une ou plusieurs des listes passées en arguments à new().

  • Détermine si une ou plusieurs chaînes spécifiées peuvent être trouvées dans *l'une quelconque* des listes passées en argument. Les listes recherchées sont placées dans un tableau, dont une référence est le premier argument passé à are_members_any(). Les chaînes à tester sont également placées dans un tableau, dont une référence est le second argument passé à cette fonction. 
    $memb_hash_ref =
    are_members_any( [ \@Llist, \@Rlist ] ,
                     [ qw| abel baker fargo hilton zebra | ]
                   );

    ou

    $memb_hash_ref = are_members_any( {
    lists => [ \@Llist, \@Rlist ],                    # la valeur est une référence de tableau
    items => [ qw| abel baker fargo hilton zebra | ], # la valeur est une référence de tableau
} );

    La valeur de retour est une référence à une table de hachage où la clé de chaque élément est la chaîne testée et la valeur de l'élément est 1 si la chaîne peut être trouvée dans *l'une quelconque* des listes et 0 sinon. Dans les exemples ci-dessus, $memb_hash_ref sera :

    {
     abel     => 1,
     baker    => 1,
     fargo    => 1,
     hilton   => 1,
     zebra    => 0,
};

    "zebra" a la valeur 0 car "zebra" ne se trouve dans aucune des listes passées en arguments à are_members_any().

  • Retourne le numéro de version actuel de List::Compare::Functional. 
    $vers = get_version;

    @Al     = qw(abel abel baker camera delta edward fargo golfer);
@Bob    = qw(baker camera delta delta edward fargo golfer hilton);
@Carmen = qw(fargo golfer hilton icon icon jerky kappa);
@Don    = qw(fargo icon jerky);
@Ed     = qw(fargo icon icon jerky);

      @intersection = get_intersection( [ \@Al, \@Bob, \@Carmen, \@Don, \@Ed ] );

      ou

      @intersection = get_intersection( {
    lists => [ \@Al, \@Bob, \@Carmen, \@Don, \@Ed ],

      @union = get_union( [ \@Al, \@Bob, \@Carmen, \@Don, \@Ed ] );

      ou
      @union = get_union( {

    • Pour obtenir les éléments qui sont uniques à une liste particulière, fournissez à get_unique() deux références de tableaux. La première contient des références aux tableaux qui contiennent à leur tour les listes individuelles comparées. La seconde contient la position d'indice dans la première référence de la liste particulière considérée. Exemple : Pour obtenir les éléments uniques à @Carmen : 
      @Lonly = get_unique(
             [ \@Al, \@Bob, \@Carmen, \@Don, \@Ed ],
             [ 2 ]
         );

      ou

      @Lonly = get_unique( {
    lists => [ \@Al, \@Bob, \@Carmen, \@Don, \@Ed ], # la valeur est une référence de tableau
    item  => 2,                                      # la valeur est un nombre
} );

      Si aucune position d'indice n'est passée à get_unique(), elle prendra par défaut la valeur 0 et signalera les éléments uniques à la première liste passée à la fonction. Par conséquent,

      @Lonly = get_unique( [ \@Al, \@Bob, \@Carmen, \@Don, \@Ed ] );

      est équivalent à :

      @Lonly = get_unique( [ \@Al, \@Bob, \@Carmen, \@Don, \@Ed ], [ 0 ] );
    • Si vous avez besoin d'identifier les éléments uniques à *chacune* des listes considérées, appelez "get_unique_all" et obtenez une référence à un tableau de références de tableaux : 
      $unique_all_ref = get_unique_all(
    [ \@Al, \@Bob, \@Carmen, \@Don, \@Ed ]
);

      ou

      $unique_all_ref = get_unique_all( {
    lists => [ \@Al, \@Bob, \@Carmen, \@Don, \@Ed ],
} );
    • Pour obtenir les éléments qui n'apparaissent que dans les listes *autres que* une liste particulière, passez deux références de tableaux à la fonction get_complement(). La première contient des références aux tableaux qui contiennent à leur tour les listes individuelles comparées. La seconde contient la position d'indice dans la première référence de la liste particulière considérée. Exemple : pour obtenir tous les éléments trouvés dans les listes autres que @Don : 
      @Ronly = get_complement(
             [ \@Al, \@Bob, \@Carmen, \@Don, \@Ed ],
             [ 3 ]
         );

      ou

      @Ronly = get_complement( {
    lists => [ \@Al, \@Bob, \@Carmen, \@Don, \@Ed ], # la valeur est une référence de tableau
    item  => 3,                                      # la valeur est un nombre
} );

      Si aucune position d'indice n'est passée à get_complement(), elle prendra par défaut la valeur 0 et signalera les éléments trouvés dans toutes les listes *autres que* la première liste passée à get_complement().

      @Lonly = get_complement( [ \@Al, \@Bob, \@Carmen, \@Don, \@Ed ] );

      est équivalent à :

      @Lonly = get_complement( [ \@Al, \@Bob, \@Carmen, \@Don, \@Ed ], [ 0 ] );

      $complement_all_ref = get_complement_all(

      ou

      $complement_all_ref = get_complement_all( {

      @nonintersection = get_nonintersection(

      @shared = get_shared( [ \@Al, \@Bob, \@Carmen, \@Don, \@Ed ] );

      ou

    • Pour déterminer si une liste particulière est un sous-ensemble d'une autre des listes passées à la fonction, passez deux références de tableau à is_LsubsetR(). La première de celles-ci est une référence à un tableau de références de tableaux, les tableaux contenant les listes à examiner. La seconde est une référence à un tableau à deux éléments composé de l'indice du sous-ensemble présumé, suivi de la position de l'indice du sur-ensemble présumé. Une valeur vraie (1) est retournée si le premier élément (de gauche) de la seconde liste de références est un sous-ensemble du second élément (de droite) ; une valeur fausse (0) est retournée sinon.

      Exemple : Pour déterminer si @Ed est un sous-ensemble de @Carmen, appelez :

      $LR = is_LsubsetR(
          [ \@Al, \@Bob, \@Carmen, \@Don, \@Ed ],
          [ 4, 2 ]
      );

      ou

      $LR = is_LsubsetR( {
    lists => [ \@Al, \@Bob, \@Carmen, \@Don, \@Ed ], # la valeur est une référence de tableau
    pair  => [ 4, 2 ],                               # la valeur est une référence de tableau
} );

      Si seule la première référence (au tableau des listes) est passée à "is_LsubsetR", alors le second argument de la fonction est par défaut "(0,1)" et compare les deux premières listes passées au constructeur. Donc,

      $LR = is_LsubsetR([ \@Al, \@Bob, \@Carmen, \@Don, \@Ed ] );

      ... est équivalent à :

      $LR = is_LsubsetR([ \@Al, \@Bob, \@Carmen, \@Don, \@Ed ], [0,1] );
    • Pour inverser l'ordre dans lequel les listes particulières sont évaluées pour le statut de sur-ensemble/sous-ensemble, appelez "is_RsubsetL" : 
      $RL = is_RsubsetL([ \@Al, \@Bob, \@Carmen, \@Don, \@Ed ], [2,4] );

      ou

      $RL = is_RsubsetL( {
    lists => [ \@Al, \@Bob, \@Carmen, \@Don, \@Ed ],
    pair  => [ 2, 4 ],
} );
    • List::Compare::Functional considère deux listes comme équivalentes si chaque élément de l'une des listes apparaît au moins une fois dans R et vice versa. Pour déterminer si une liste particulière passée à la fonction est équivalente à une autre des listes passées à la fonction, fournissez à is_LequivalentR() deux références de tableau. La première est une référence à un tableau de références de tableaux, les tableaux contenant les listes à examiner. La seconde est une référence à un tableau à deux éléments composé des deux listes testées pour l'équivalence. Une valeur vraie (1) est retournée si les listes sont équivalentes ; une valeur fausse (0) est retournée sinon.

      Exemple : Pour déterminer si @Don et @Ed sont équivalentes, appelez :

      $eqv = is_LequivalentR(
           [ \@Al, \@Bob, \@Carmen, \@Don, \@Ed ],
           [3,4]
       );
$eqv = is_LeqvlntR(                                # alias
           [ \@Al, \@Bob, \@Carmen, \@Don, \@Ed ],
           [3,4]
       );

      ou

      $eqv = is_LequivalentR( {
    items => [ \@Al, \@Bob, \@Carmen, \@Don, \@Ed ],
    pair  => [3,4],
} );

      Si aucun argument n'est passé, "is_LequivalentR" utilise par défaut "[0,1]" et compare les deux premières listes passées à la fonction. Donc,

      $eqv = is_LequivalentR( [ \@Al, \@Bob, \@Carmen, \@Don, \@Ed ] );

      ... se traduit par :

      $eqv = is_LequivalentR( [ \@Al, \@Bob, \@Carmen, \@Don, \@Ed ], [0,1] );
    • Pour déterminer si deux listes quelconques parmi celles passées à la fonction sont disjointes l'une de l'autre (c'est-à-dire qu'elles n'ont aucun membre en commun), fournissez à is_LdisjointR() deux références de tableau. La première est une référence à un tableau de références de tableaux, les tableaux contenant les listes à examiner. La seconde est une référence à un tableau à deux éléments composé des deux listes testées pour la disjointude. Une valeur vraie (1) est retournée si les listes sont disjointes ; une valeur fausse (0) est retournée sinon.

      Exemple : Pour déterminer si @Don et @Ed sont disjointes, appelez :

      $disj = is_LdisjointR(
           [ \@Al, \@Bob, \@Carmen, \@Don, \@Ed ],
           [3,4]
       );

      ou

      $disj = is_LdisjointR( {
    items => [ \@Al, \@Bob, \@Carmen, \@Don, \@Ed ],
    pair  => [3,4]
} );
    • Afficher joliment un tableau montrant les relations de sous-ensemble entre les différentes listes sources : 
      print_subset_chart( [ \@Al, \@Bob, \@Carmen, \@Don, \@Ed ] );

      ou

      print_subset_chart( { lists => [ \@Al, \@Bob, \@Carmen, \@Don, \@Ed ] } );
    • Afficher joliment un tableau montrant les relations d'équivalence entre les différentes listes sources : 
      print_equivalence_chart( [ \@Al, \@Bob, \@Carmen, \@Don, \@Ed ] );

      ou

      print_equivalence_chart( { lists => [ \@Al, \@Bob, \@Carmen, \@Don, \@Ed ] } );
    • Déterminer dans *quelle(s)* (le cas échéant) de plusieurs listes une chaîne donnée peut être trouvée. Passez deux références de tableau, la première contenant des références aux tableaux qui contiennent les listes à examiner, et la seconde contenant une liste d'un seul élément constituée de la chaîne testée. 
      @memb_arr = is_member_which(
                [ \@Al, \@Bob, \@Carmen, \@Don, \@Ed ],
                [ 'abel' ]
            );

      ou

      @memb_arr = is_member_which( {
    lists => [ \@Al, \@Bob, \@Carmen, \@Don, \@Ed ], # la valeur est une référence de tableau
    item  => 'abel',                                 # la valeur est une chaîne
} );

      Dans un contexte de liste, retourne une liste de ces indices dans la liste d'arguments de la fonction correspondant aux listes contenant la chaîne testée. Dans l'exemple ci-dessus, @memb_arr sera :

      ( 0 )

      parce que 'abel' n'est trouvé que dans @Al qui détient la position 0 dans la liste d'arguments passée à is_member_which().

    • Comme avec les autres fonctions de List::Compare::Functional qui retournent une liste, vous pourriez souhaiter que la fonction ci-dessus retourne une référence à un tableau contenant la liste : 
      $memb_arr_ref = is_member_which_ref(
                    [ \@Al, \@Bob, \@Carmen, \@Don, \@Ed ],
                    [ 'jerky' ]
                );

      ou

      $memb_arr_ref = is_member_which_ref( {
    lists => [ \@Al, \@Bob, \@Carmen, \@Don, \@Ed ], # la valeur est une référence de tableau
    item  => 'jerky',                                # la valeur est une chaîne
} );

      Dans l'exemple ci-dessus, $memb_arr_ref sera :

      [ 3, 4 ]

      parce que 'jerky' est trouvé dans @Don et @Ed, qui détiennent les positions 3 et 4, respectivement, dans la liste d'arguments passée à is_member_which().

      Note : les fonctions is_member_which() et "is_member_which_ref" testent une seule chaîne à la fois et prennent donc un seul élément dans le second argument de référence de tableau. Pour tester plusieurs chaînes à la fois, voir la fonction suivante, are_members_which().

    • Déterminer dans *quelles* (le cas échéant) de plusieurs listes une ou plusieurs chaînes données peuvent être trouvées. Passez deux références de tableau, la première contenant des références aux tableaux qui contiennent les listes à examiner, et la seconde contenant une liste des chaînes à tester. 
      $memb_hash_ref = are_members_which(
                     [ \@Al, \@Bob, \@Carmen, \@Don, \@Ed ],
                     [ qw| abel baker fargo hilton zebra | ]
                 );

      ou

      $memb_hash_ref = are_members_which( {
    lists => [ \@Al, \@Bob, \@Carmen, \@Don, \@Ed ],  # la valeur est une référence de tableau
    items => [ qw| abel baker fargo hilton zebra | ], # la valeur est une référence de tableau
} );

      La valeur de retour est une référence à une table de hachage. Dans cette table de hachage, chaque élément est une référence à un tableau anonyme dont les éléments sont les indices dans la liste d'arguments correspondant aux listes contenant les chaînes testées. Dans les deux exemples ci-dessus, $memb_hash_ref sera :

      {
     abel     => [ 0             ],
     baker    => [ 0, 1          ],
     fargo    => [ 0, 1, 2, 3, 4 ],
     hilton   => [    1, 2       ],
     zebra    => [               ],
};

      Note : are_members_which() teste plusieurs chaînes à la fois. Par conséquent, son second argument de référence de tableau peut contenir plus d'un élément. is_member_which() et is_member_which_ref() ne prennent qu'un seul élément dans leurs seconds arguments de référence de tableau. are_members_which() retourne une référence de table de hachage ; les autres fonctions retournent soit une liste, soit une référence à un tableau contenant cette liste, selon le contexte.

    • Déterminer si une chaîne donnée peut être trouvée dans *une* quelconque de plusieurs listes. Passez deux références de tableau, la première contenant des références aux tableaux qui contiennent les listes à examiner, et la seconde contenant une liste d'un seul élément de la chaîne testée. 
      $found = is_member_any(
                [ \@Al, \@Bob, \@Carmen, \@Don, \@Ed ],
                [ 'abel' ]
            );

      DESCRIPTION

      List::Compare::Functional proporciona un conjunto de funciones para comparar dos o más listas al mismo tiempo. La principal ventaja de este módulo es que su código está escrito en código de compilación C, lo que lo hace significativamente más rápido que sus predecesores escritos íntegramente en Perl.

      Las funciones de List::Compare::Functional operan en listas representadas como referencias a arrays y también como referencias a "seen-hashes". Un seen-hash es una implementación típica de una tabla de búsqueda en Perl: una hash donde el valor de un elemento representa el número de veces que la clave del elemento se observa en una lista. Para List::Compare::Functional, lo que es crucial es si un elemento se observa en una lista o no; cuántas veces aparece el elemento en una lista es, con una excepción, irrelevante.

      Las funciones de List::Compare::Functional devuelven generalmente arrays que contienen los resultados de la comparación. La excepción son las funciones de la forma getref*(), que devuelven referencias a arrays que contienen los resultados.

      Las listas que se comparan pueden representarse como referencias a arrays o como referencias a seen-hashes. Si se utilizan seen-hashes, sus claves y valores pueden ser de cualquier tipo de datos Perl.

      Aquí hay una tabla de las funciones disponibles en List::Compare::Functional, junto con una breve descripción de lo que hace cada función y un ejemplo de uso:

      • Determina la intersección de dos o más listas: 
        $intersection_ref = get_intersection_ref( [ \@Llist, \@Rlist ] );

        o

        $intersection_ref = get_intersection_ref( {
    lists => [ \@Llist, \@Rlist ],
} );

        El valor devuelto es una referencia a un array que contiene todos los elementos que están presentes en ambas listas. En el ejemplo anterior, si \@Llist es ['a', 'b', 'c'] y \@Rlist es ['b', 'c', 'd'], entonces $intersection_ref será una referencia a ['b', 'c'].

      • Determina la unión de dos o más listas: 
        $union_ref = get_union_ref( [ \@Llist, \@Rlist ] );

        o

        $union_ref = get_union_ref( {
    lists => [ \@Llist, \@Rlist ],
} );

        El valor devuelto es una referencia a un array que contiene todos los elementos que están presentes en cualquiera de las listas. En el ejemplo anterior, $union_ref será una referencia a ['a', 'b', 'c', 'd'].

      • Devuelve todos los elementos que son únicos en la primera lista pasada como argumento: 
        $unique_ref = get_unique_ref( [ \@Llist, \@Rlist ] );

        o

        $unique_ref = get_unique_ref( {
    lists => [ \@Llist, \@Rlist ],
} );

        El valor devuelto es una referencia a un array que contiene todos los elementos que están presentes solo en la primera lista (\@Llist) y no en la segunda (\@Rlist). En el ejemplo anterior, $unique_ref será una referencia a ['a'].

      • Devuelve todos los elementos que están en la segunda lista pero no en la primera: 
        $complement_ref = get_complement_ref( [ \@Llist, \@Rlist ] );

        o

        $complement_ref = get_complement_ref( {
    lists => [ \@Llist, \@Rlist ],
} );

        El valor devuelto es una referencia a un array que contiene todos los elementos que están presentes en la segunda lista (\@Rlist) pero no en la primera (\@Llist). En el ejemplo anterior, $complement_ref será una referencia a ['d'].

      • Devuelve todos los elementos que están en una lista u otra, pero no en ambas: 
        $symdiff_ref = get_symmetric_difference_ref( [ \@Llist, \@Rlist ] );

        o

        $symdiff_ref = get_symmetric_difference_ref( {
    lists => [ \@Llist, \@Rlist ],
} );

        El valor devuelto es una referencia a un array que contiene todos los elementos que están presentes en la primera lista (\@Llist) o en la segunda (\@Rlist), pero no en ambas. En el ejemplo anterior, $symdiff_ref será una referencia a ['a', 'd'].

      • Determina si la primera lista es un subconjunto de la segunda: 
        $is_subset = is_LsubsetR( [ \@Llist, \@Rlist ] );

        o

        $is_subset = is_LsubsetR( {
    lists => [ \@Llist, \@Rlist ],
} );

        El valor devuelto es 1 si todos los elementos de la primera lista (\@Llist) están contenidos en la segunda lista (\@Rlist), y 0 en caso contrario. En el ejemplo anterior, si \@Llist es ['b', 'c'] y \@Rlist es ['a', 'b', 'c', 'd'], entonces $is_subset será 1.

      • Determina si un elemento especificado se puede encontrar en alguna de varias listas: 
        $found = is_member_any(
                     [ \@Al, \@Bob, \@Carmen, \@Don, \@Ed ],
                     'abel'
                 );

        o

        $found = is_member_any( {
    lists => [ \@Al, \@Bob, \@Carmen, \@Don, \@Ed ], # la valeur est un arrayref
    item  => 'abel',                                 # la valeur est une chaîne
} );

        La valeur retournée est 1 si une chaîne spécifiée peut être trouvée dans l'une quelconque des listes et 0 sinon. Dans l'exemple ci-dessus, $found sera 1 car "abel" se trouve dans une ou plusieurs des listes passées en arguments à is_member_any().

      • Détermine si une chaîne ou plusieurs chaînes spécifiées peuvent être trouvées dans l'une quelconque de plusieurs listes. Passer deux références de tableaux, la première contenant des références de tableaux qui stockent les listes considérées, et la seconde contenant une liste des chaînes à tester. 
        $memb_hash_ref = are_members_any(
                     [ \@Al, \@Bob, \@Carmen, \@Don, \@Ed ],
                     [ qw| abel baker fargo hilton zebra | ]
                 );

        ou

        $memb_hash_ref = are_members_any( {
    lists => [ \@Al, \@Bob, \@Carmen, \@Don, \@Ed ],  # la valeur est un arrayref
    items => [ qw| abel baker fargo hilton zebra | ], # la valeur est un arrayref
} );

        La valeur retournée est une référence de hachage où la clé d'un élément est la chaîne à tester et la valeur de cet élément est 1 si la chaîne peut être trouvée dans n'importe laquelle des listes et 0 sinon. Dans l'exemple ci-dessus, $memb_hash_ref sera :

        {
     abel     => 1,
     baker    => 1,
     fargo    => 1,
     hilton   => 1,
     zebra    => 0,
};

        "zebra" a une valeur de 0 car "zebra" ne se trouve dans aucune des listes passées en arguments à are_members_any().

      • Retourne le numéro de version actuel de List::Compare::Functional : 
        $vers = get_version;

    Comparaison des listes contenues dans les Seen-Hashes

    Qu'est-ce qu'un seen-hash ? Un seen-hash est une implémentation typique d'une table de recherche en Perl : une hash où la valeur d'un élément représente le nombre de fois où la clé de l'élément est observée dans une liste. Pour List::Compare::Functional, ce qui est crucial est de savoir si un élément est observé dans une liste ou non ; combien de fois l'élément apparaît dans une liste est, à une exception près, non pertinent. (L'exception concerne la fonction get_bag() et son frère get_bag_ref(). Dans ce cas, la clé de chaque élément du seen-hash est mise dans le sac autant de fois qu'indiqué par la valeur de cet élément.) La valeur d'un élément dans une table de recherche List::Compare doit être un nombre positif, mais que ce nombre soit 1 ou 1 000 001 n'est pas pertinent pour toutes les fonctions List::Compare::Functional, sauf pour la formation d'un sac.

    Les deux listes comparées ci-dessus étaient représentées par des tableaux ; des références à ces tableaux ont été passées aux diverses fonctions de List::Compare::Functional. Cependant, elles auraient pu être représentées par des seen-hashes comme les suivantes et passées exactement de la même manière aux diverses fonctions.

    %Llist = (
    abel   => 2,
    baker  => 1,
    camera => 1,
    delta  => 1,
    edward => 1,
    fargo  => 1,
    golfer => 1,
);
%Rlist = (
    baker  => 1,
    camera => 1,
    delta  => 2,
    edward => 1,
    fargo  => 1,
    golfer => 1,
    hilton => 1,
);
@intersection = get_intersection( [ \%Llist, \%Rlist ] );
@union        = get_union(        [ \%Llist, \%Rlist ] );
@complement   = get_complement(   [ \%Llist, \%Rlist ] );

    et ainsi de suite.

    Pour comparer trois listes ou plus simultanément, fournissez à la fonction appropriée de List::Compare::Functional une première référence de tableau contenant une liste de trois références de seen-hashes ou plus. Ainsi,

    @union = get_intersection( [ \%Alpha, \%Beta, \%Gamma ] );

    Le format "single hashref" pour les fonctions de List::Compare::Functional est également disponible lors du passage de seen-hashes en arguments. Exemples :

    @intersection = get_intersection( {
    lists => [ \%Alpha, \%Beta, \%Gamma ],
} );
@Ronly = get_complement( {
    lists => [ \%Alpha, \%Beta, \%Gamma ],
    item  => 3,
} );
$LR = is_LsubsetR( {
    lists => [ \%Alpha, \%Beta, \%Gamma ],
    pair  => [ 4, 2 ],
} );
$memb_hash_ref = are_members_any( {
    lists => [ \%Alpha, \%Beta, \%Gamma ],
    items => [ qw| abel baker fargo hilton zebra | ],
} );

    Résultats plus rapides avec l'option "non trié"

    Par défaut, les fonctions de List::Compare::Functional retournent des listes triées selon le mode de comparaison ASCII standard de Perl. Le tri implique un coût de performance, et si vous n'avez pas besoin d'une liste triée et que vous ne souhaitez pas supporter ce coût de performance, vous pouvez appeler les fonctions suivantes de List::Compare::Functional avec l'option "non trié" :

    @intersection = get_intersection(        '-u',  [ \@Llist, \@Rlist ] );
@union        = get_union(               '-u',  [ \@Llist, \@Rlist ] );
@Lonly        = get_unique(              '-u',  [ \@Llist, \@Rlist ] );
@Ronly        = get_complement(          '-u',  [ \@Llist, \@Rlist ] );
@LorRonly     = get_symmetric_difference('-u',  [ \@Llist, \@Rlist ] );
@bag          = get_bag(                 '-u',  [ \@Llist, \@Rlist ] );

    Pour plus de clarté, l'option peut être écrite comme suit :

    @intersection = get_intersection('--unsorted',  [ \@Llist, \@Rlist ] );

    ou

    @intersection = get_intersection( {
    unsorted => 1,
    lists    => [ \@Llist, \@Rlist ],
} );

    Si vous avez besoin d'une référence à une liste non triée comme valeur de retour, vous pouvez appeler l'option "non trié" de cette manière :

    $intersection_ref = get_intersection_ref(
                        '-u',         [ \@Llist, \@Rlist ] );
$intersection_ref = get_intersection_ref(
                        '--unsorted', [ \@Llist, \@Rlist ] );

    Commentaires généraux

    List::Compare::Functional est une implémentation non orientée objet de code très courant en Perl utilisé pour déterminer des relations intéressantes entre deux ou plusieurs listes en même temps.     DISCUSSION

    Dans les versions précédentes, les arguments des fonctions de List::Compare::Funcional étaient passés comme scalaires, comme :

    @memb_arr = is_member_which(\@Llist, \@Rlist, 'abel');

    Maintenant, ces arguments doivent être contenus dans un tableau anonyme (ou nommé), qui est passé en référence à la fonction, comme ceci :

    @memb_arr = is_member_which( [ \@Llist, \@Rlist ], [ 'abel' ] );

    Ou alternativement :

    @to_be_compared = (\@Llist, \@Rlist);
@opts = ( 'abel' );
@memb_arr = is_member_which( \@to_be_compared, \@opts );

    Comme dans les versions précédentes, pour améliorer la vitesse, l'utilisateur peut fournir l'option '-u' ou '--unsorted' comme premier argument à certaines fonctions de List::Compare::Funcional. En utilisant cette option, la fonction get_intersection() précédente apparaîtrait ainsi :

    @intersection = get_intersection( '-u', [ \@Llist, \@Rlist ] );

    Ou alternativement :

    @intersection = get_intersection( '--unsorted', [ \@Llist, \@Rlist ] );

    Les arguments de toute fonction de List::Compare::Funcional seront éventuellement l'option '-u', suivie d'une ou deux références à des tableaux, la première étant une référence à un tableau de tableaux ou un tableau de hachages visibles.
