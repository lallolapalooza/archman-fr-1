GroupInfo(3pm) Documentation de Lire::Report GroupInfo(3pm)

NOM

Lire::Report::GroupInfo - Objet qui regroupe les colonnes créées par le même agrégateur.

SYNTAXE

my $info = $subreport->group_info( 0 );
print "Nom du groupe : ", $info->name(),   "\n";
print "Colonnes du groupe débutant à : ", $info->index(), "\n";

DESCRIPTION

L'objet Lire::Report::GroupInfo contient les objets ColumnInfo qui ont été créés par le même agrégateur.

CONSTRUCTEUR

new( $nom )

Vous créez un nouvel objet Lire::Report::GroupInfo en appelant la méthode create_group_info() sur un objet Lire::Report::TableInfo ou un autre objet Lire::Report::GroupInfo.

METHODES OBJET

name()

Retourne le nom de ce groupe. Ce nom peut être utilisé pour trouver l'agrégateur (à partir de la spécification du rapport) responsable des données contenues dans ce groupe.

row_idx()

Retourne l'indice de ligne dans lequel les étiquettes de la colonne catégorielle de ce groupe doivent être affichées dans l'en-tête du tableau.

max_row_idx()

parent_group_info()

Retourne le GroupInfo qui contient ce GroupInfo. Sera indéfini pour l'objet TableInfo de niveau supérieur.

index()

Retourne l'indice de colonne dans le tableau où les colonnes de ce groupe commencent. Sera indéfini jusqu'à ce que l'objet group_info soit ajouté à un Lire::Subreport ou un autre objet Lire::Group.

children()

Retourne sous forme de tableau, les objets Lire::Report::ColumnInfo et Lire::Report::GroupInfo contenus dans ce groupe.

info_by_index( $idx )

Retourne le ColumnInfo ou GroupInfo qui se trouve à l'indice $idx parmi les enfants de ce GroupInfo.

group_children

Retourne sous forme de tableau, uniquement les Lire::Report::GroupInfo contenus dans ce GroupInfo.

column_children

Retourne sous forme de tableau, uniquement les Lire::Report::ColumnInfo contenus dans ce GroupInfo.

categorical_names()

Retourne les noms des colonnes catégorielles sous forme de référence de tableau.

create_column_info( $name, $class, $type, [$label]])

Crée un nouvel objet Lire::Report::ColumnInfo comme enfant de ce GroupInfo. Les attributs de l'objet ColumnInfo sont initialisés en fonction de $name, $class, $type et $label.

Ceci définira l'indice de l'objet ColumnInfo.

Retourne l'objet ColumnInfo créé.

create_group_info( $name )

Crée un Lire::Report::GroupInfo comme enfant de ce groupe. Ceci définira également l'indice de colonne de départ sur l'objet GroupInfo. Le paramètre $name doit contenir le nom de l'agrégateur de la spécification du rapport responsable du contenu de ce groupe.

Retourne l'objet GroupInfo créé.

column_info_by_name( $name )

Retourne l'objet Lire::Report::ColumnInfo qui a le nom $name. Cette méthode recherche dans le groupe courant ainsi que dans ses sous-groupes.

Retourne indéfini si la colonne n'est pas trouvée.

column_info_by_col_start( $col_idx )

Retourne l'objet Lire::Report::ColumnInfo qui commence à l'indice de colonne $col_idx. Cette méthode recherche dans le groupe courant ainsi que dans ses sous-groupes.

Retourne indéfini si la colonne n'est pas trouvée dans le groupe courant.

group_info( $name )

Retourne l'objet Lire::Report::GroupInfo qui a le nom $name. Sera indéfini si elle ne peut pas être trouvée dans cet group info.

VOIR AUSSI

Lire::Report::Subreport(3pm) Lire::Report::ColumnInfo(3pm)
