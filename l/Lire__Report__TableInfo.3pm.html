NOM

Lire::Report::TableInfo - Objet contenant toutes les informations de groupe et de colonne pour un sous-rapport

SYNTAXE

my $info = $subreport->table_info;
my $col_info = $info->colum_info( "request_total" );

DESCRIPTION

L'objet Lire::Report::TableInfo contient les objets ColumnInfo et GroupInfo pour un sous-rapport.

CONSTRUCTEUR

new()

Crée un nouvel objet Lire::Report::TableInfo.

column_info_by_name( $name )

Retourne l'objet Lire::Report::ColumnInfo dont le nom est $name.

Contrairement à la méthode dans Lire::Report::GroupInfo, celle-ci lèvera une exception s'il n'y a pas de colonne nommée $name.

column_info_by_col_start( $idx )

Retourne l'objet Lire::Report::ColumnInfo qui commence à l'index de colonne $idx.

Contrairement à la méthode dans Lire::Report::GroupInfo, celle-ci lèvera une exception si cette colonne est hors limites.

group_info( $name )

Retourne l'objet Lire::Report::GroupInfo dont le nom est $name.

Contrairement à la méthode dans Lire::Report::GroupInfo, celle-ci lèvera une exception s'il n'y a pas de colonne nommée $name.

ncols()

Retourne le nombre de colonnes dans cette table.

column_infos()

Retourne un tableau contenant toutes les colonnes de la table. Chaque élément est un objet Lire::Report::ColumnInfo.

groups()

Retourne un tableau contenant tous les groupes de la table. Chaque élément est un objet Lire::Report::GroupInfo.

columns_width()

Retourne un tableau où chaque élément représente la largeur suggérée des colonnes en caractères.

header_rows()

Retourne une référence de tableau contenant une référence de tableau pour chaque ligne de l'en-tête. Chaque ligne contient les ColumnInfo qui devraient apparaître sur la ligne d'en-tête. La première ligne contient toutes les colonnes numériques et les colonnes catégorielles apparaissent en fonction de leur imbrication. Les indices de la colonne sont toujours égaux à son début de colonne.

set_variables_indices()

Enregistre les variables de cette TableInfo en utilisant Lire::Config::VariableIndex.

reset_variable_indices()

Supprime les indices de variables. Ceci peut être appelé pour annuler l'effet de set_variables_indices().

VOIR AUSSI

Lire::Report::Subreport(3pm) Lire::Report::ColumnInfo(3pm)
