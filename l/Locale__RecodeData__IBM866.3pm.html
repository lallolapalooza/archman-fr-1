NOM

Locale::RecodeData::IBM866 - Routines de conversion pour IBM866

SYNOPIS

Ce module est interne à libintl. Ne pas utiliser directement !

DESCRIPTION

Ce module est généré et contient les tables et routines de conversion pour IBM866.

COMMENTAIRES

Les commentaires suivants ont été extraits de la charmap d'origine :

généré automatiquement à partir de charDB
alias CP866
alias 866

Veuillez noter que les alias listés ci-dessus ne sont pas nécessairement valides !
