NOM

Log::Message::Handlers - Gestionnaires de messages pour Log::Message

SYNOPSIS

# Utilisé implicitement par Log::Message pour servir de gestionnaires aux
# objets Log::Message::Item
# Créez votre propre fichier avec un package nommé
# Log::Message::Handlers pour ajouter aux gestionnaires existants, ou même
# pour les remplacer
$item->carp;
$item->trace;

DESCRIPTION

Log::Message::Handlers fournit des gestionnaires pour les objets Log::Message::Item. Le gestionnaire correspondant au niveau (voir la page de manuel Log::Message::Item pour une explication des niveaux) sera appelé automatiquement lors du stockage de l'erreur.

Les gestionnaires peuvent également être appelés explicitement sur un objet Log::Message::Item si on le souhaite (voir la page de manuel Log::Message sur la manière de récupérer les objets Item).

Gestionnaires par défaut

log

Enregistre simplement l'erreur dans la pile, sans action spéciale.

carp

Utilise `carp` (voir la page de manuel Carp) avec l'erreur, et ajoute l'horodatage de sa survenue.

croak

Utilise `croak` (voir la page de manuel Carp) avec l'erreur, et ajoute l'horodatage de sa survenue.

cluck

Utilise `cluck` (voir la page de manuel Carp) avec l'erreur, et ajoute l'horodatage de sa survenue.

confess

Utilise `confess` (voir la page de manuel Carp) avec l'erreur, et ajoute l'horodatage de sa survenue.

die

Termine simplement l'exécution avec le message d'erreur de l'élément.

warn

Affiche simplement un avertissement avec le message d'erreur de l'élément.

trace

Fournit une trace de cet élément d'erreur jusqu'au premier qui s'est produit, en affichant chaque élément au fur et à mesure.

Gestionnaires personnalisés

Si vous souhaitez fournir vos propres gestionnaires, vous pouvez simplement faire ce qui suit :

  • Créez un fichier contenant un package nommé "Log::Message::Handlers"
  • Créez des sous-routines portant le même nom que les niveaux que vous souhaitez gérer dans le module Log::Message (voir la page de manuel Log::Message pour une explication sur les niveaux)
  • Incluez ce fichier dans votre programme, ou ajoutez-le dans votre configuration (voir la page de manuel Log::Message::Config pour une explication sur l'utilisation d'un fichier de configuration)

Et c'est tout, le gestionnaire sera alors disponible pour traiter les messages pour vous.

Les arguments qu'un gestionnaire peut recevoir sont ceux spécifiés par la clé "extra", lors du stockage du message. Voir la page de manuel Log::Message pour plus de détails sur les arguments.

VOIR AUSSI

Log::Message, Log::Message::Item, Log::Message::Config
