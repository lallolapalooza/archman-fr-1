NOM

Lire::Subreport - Interface à un sous-rapport Lire.

SYNOPIS

use Lire::ReportParser::ReportBuilder;
my $parser = new Lire::ReportParser::ReportBuilder;
my $report = $parser->parse( "report.xml" );
foreach my $s ( $report->sections() ) {
    print "Section: '", $s->title(), "\n\n";
    foreach my $r ( $s->subreports() ) {
        print "Sous-rapport ", $r->title(), " a ", scalar $r->entries(),
            " entrées\n";
    }
}

DESCRIPTION

Ce module offre une API aux sous-rapports inclus dans les sections d'un rapport Lire.

Cet objet possède toutes les méthodes offertes par l'objet Lire::Report::Group(3pm). Vous trouverez plus d'informations sur l'accès aux données contenues dans un sous-rapport dans cette page man.

CONSTRUCTEURS

new( $superservice, $type)

Crée un nouvel objet Lire::Report::Subreport. Les paramètres $superservice et $type définissent la spécification du rapport qui a été utilisée pour générer les données de ce sous-rapport.

new_missing( $superservice, $type, [$reason])

Crée un nouvel objet Lire::Report::Subreport marqué comme manquant. Les paramètres $superservice et $type définissent la spécification du rapport qui a été utilisée pour générer les données de ce sous-rapport. Le paramètre $reason définit la raison pour laquelle ce sous-rapport est manquant.

MÉTHODES D'OBJET

id( [ $new_id ] )

Retourne (et change optionnellement) l'ID de ce sous-rapport. L'ID du sous-rapport l'identifie de manière unique dans son Rapport. Les sous-rapports ayant le même ID seront fusionnés.

is_missing()

Retourne vrai si ce sous-rapport a été marqué comme manquant dans le fichier XML. Un sous-rapport manquant est un sous-rapport qui était présent dans le fichier de configuration du rapport mais qui a été marqué comme manquant dans le rapport XML. Cela se produit lorsque la spécification du rapport exige des champs qui n'étaient pas disponibles dans les fichiers DLF générés. Cela peut également se produire lorsqu'une erreur survient lors du processus de génération du rapport.

missing_reason()

Indique la raison pour laquelle le sous-rapport est manquant. Cela sera indéfini lorsque le sous-rapport n'est pas manquant.

superservice()

Retourne le superservice de ce sous-rapport. C'est le superservice qui a défini la spécification du rapport à partir duquel le sous-rapport a été généré.

type()

Retourne le type de ce sous-rapport. C'est l'ID de la spécification du rapport qui a été utilisée pour générer ce sous-rapport.

schemas( [ $schema, ... ] )

Retourne les schémas utilisés par ce Sous-rapport.

field_schema( $field )

Retourne le schéma qui contient le champ $field. Retourne undef si ce nom n'est défini dans aucun schéma.

chart_configs()

Retourne une référence de tableau contenant des objets Lire::Report::ChartConfig spécifiant les graphiques qui doivent être générés à partir de ce Sous-rapport.

add_chart_config( $chart_config )

Ajoute un objet Lire::Report::ChartConfig spécifiant un graphique qui doit être généré à partir des données de ce Sous-rapport.

title( [$title] )

Retourne le titre du sous-rapport.

Si le paramètre $title est défini, le titre du sous-rapport sera défini à cette nouvelle valeur.

description( [$new_desc] )

Retourne la description de ce sous-rapport. La description est codée en XML DocBook.

Si le paramètre $description est défini, cette méthode définira la description de ce sous-rapport à cette nouvelle valeur. Si le paramètre $description est indéfini, cette description sera supprimée.

table_info( [$table_info] )

Retourne l'objet Lire::Report::TableInfo de haut niveau décrivant la disposition de cette table. Si le paramètre $table_info est défini, les informations de table du sous-rapport seront définies à cet objet.

nrows()

Retourne le nombre de lignes dans la table.

last_row_idx()

Retourne l'index de la dernière ligne de données.

getrow_by_idx( $index )

Retourne une référence de tableau contenant la ligne 'idx' des données du sous-rapport. Une ligne contiendra toutes les valeurs (catégorielles et numériques) qui apparaîtraient sur la même ligne. Lorsqu'une entrée est composée de variables catégorielles plus des groupes imbriqués, les valeurs résumées du groupe apparaîtront sur la même ligne que la variable catégorielle.

Chaque valeur est la référence de hachage qui est retournée par Entry::data_by_name() pour cette colonne et elle est dans la ligne à l'indice de la colonne.

getrows()

Retourne toutes les lignes contenues dans le sous-rapport. Cette méthode est utile pour le rendu du tableau du sous-rapport.

finalize()

Cette méthode doit être appelée après que toutes les entrées ont été ajoutées. Elle assigne les indices de ligne et calcule la largeur des colonnes et les statistiques.
