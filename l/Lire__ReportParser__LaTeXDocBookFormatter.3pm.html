LaTeXDocBookFormatter(3pm) Documentation de Lire::ReportParser LaTeXDocBookFormatter(3pm)

NOM

Lire::ReportParser::LaTeXDocBookFormatter - Sous-classe de Lire::DocBookParser qui formate la description en LaTeX.

SYNOPSIS

Pour convertir une description DocBook en LaTeX :

use Lire::ReportParser::LaTeXDocBookFormatter qw/dbk2latex/;
my $LaTeX = dbk2latex( "<para>Test</para>" );

DESCRIPTION

Ce paquet implémente des méthodes qui peuvent gérer le contenu des éléments "description" et peut être utilisé par une sous-classe de Lire::ReportParser. Le client n'a qu'à hériter de ce module pour disposer d'une méthode handle_description() afin de traiter le texte formaté de la description DocBook.

Ce module fournit également une fonction pratique dbk2txt() qui peut être utilisée pour formater une chaîne contenant des éléments DocBook en un équivalent ASCII.

UTILISATION DE Lire::ReportParser::LaTeXDocBookFormatter

Les processeurs Lire::ReportParser qui souhaitent travailler avec la version texte de la description doivent hériter de Lire::ReportParser::LaTeXDocBookFormatter en plus de Lire::ReportParser. S'ils redéfinissent les méthodes description_start() et description_end(), ils doivent faire appel à la version de leurs parents en utilisant "SUPER::".

De plus, ils devraient fusionner la valeur de elements_spec() dans leur implémentation de elements_spec().

Lire::ReportParser::LaTeXDocBookFormatter doit être listé avant Lire::ReportParser dans @ISA. LaTeXDocBookFormatter n'hérite pas directement de Lire::ReportParser afin de pouvoir être utilisé dans des scénarios d'héritage multiple.

dbk_start_processing()

Initialise la structure du parseur pour le formatage du XML DocBook en ASCII. Ceci est utilisé à partir de l'implémentation de description_start.

dbk_end_processing()

Nettoie la structure du parseur. Ceci est utilisé à partir de l'implémentation de description_end().

handle_description( $description )

Cette méthode est appelée après la rencontre de la balise de fermeture de l'élément "description". Le $description contient la description convertie en LaTeX.

TRAITEMENT DE LA DESCRIPTION LaTeX

Le LaTeX généré est encodé en UTF-8, donc Omega doit être utilisé pour le traiter. De plus, le résultat de l'appel à dbk_latex_environment() devrait être ajouté au préambule du document. Il ajoute des définitions d'environnements et de commandes utilisées par le formateur.

FORMATAGE DES CHAÎNES DocBook

Si vous avez du contenu DocBook dans une chaîne, comme vous pouvez en obtenir à partir de certains objets de Spécifications de Rapport, vous pouvez le convertir en LaTeX en utilisant la fonction dbx2latex().

dbk2txt( $docbook_str, [$colonnes] )

Retourne une version texte brut du fragment XML DocBook $docbook_str. Le paramètre "colonnes" définit le nombre de colonnes dans lesquelles le texte DocBook doit être formaté.

Cette méthode provoquera une erreur (die()) en cas de problème.
