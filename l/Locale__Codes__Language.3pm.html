NOM

Locale::Codes::Language - module pour gérer les ensembles de codes de langue

SYNTAXE

use Locale::Codes::Language;
$nom = code2langue(CODE);
$code = langue2code(NOM);
@codes   = toutes_codes_langues();
@noms   = toutes_noms_langues();

DESCRIPTION

Ce module fournit un accès aux ensembles de codes de langue.

Veuillez vous référer au document Locale::Codes::Types pour une description des ensembles de codes disponibles.

La plupart des routines acceptent un argument supplémentaire optionnel qui spécifie l'ensemble de codes à utiliser. L'ensemble de codes peut être spécifié en utilisant le nom d'un ensemble de codes, ou la constante Perl spécifiée dans le document ci-dessus. Si non spécifié, l'ensemble de codes par défaut sera utilisé.

ROUTINES

Toutes les routines de ce module appellent la méthode appropriée dans le module Locale::Codes, en utilisant un objet de type : langue Veuillez vous référer à la documentation du module Locale::Codes pour plus de détails sur chaque fonction.

Les fonctions suivantes sont exportées automatiquement :

code2langue(CODE [,ENSEMBLE_CODES] [,'retiré'])
Voir code2nom dans Locale::Codes
code2langues(CODE [,ENSEMBLE_CODES])
Voir code2noms dans Locale::Codes
langue2code(NOM [,ENSEMBLE_CODES] [,'retiré'])
Voir nom2code dans Locale::Codes
langue_code2code(CODE ,ENSEMBLE_CODES ,ENSEMBLE_CODES2)
Voir code2code dans Locale::Codes
toutes_codes_langues([ENSEMBLE_CODES] [,'retiré'])
Voir tous_codes dans Locale::Codes
toutes_noms_langues([ENSEMBLE_CODES] [,'retiré'])
Voir tous_noms dans Locale::Codes

Les fonctions suivantes ne sont pas exportées et doivent être appelées en qualifiant complètement avec le nom du paquet :

Locale::Codes::Language::afficher_erreurs(INDICATEUR)
Par défaut, une entrée invalide produira des résultats vides, mais aucune erreur. En passant une valeur non nulle pour INDICATEUR, des erreurs seront produites.

Voir afficher_erreurs dans Locale::Codes, mais noter que la valeur par défaut pour les modules non-OO est de NE PAS produire d'erreurs.

Locale::Codes::Language::renommer_langue(CODE ,NOUVEAU_NOM [,ENSEMBLE_CODES])
Voir renommer_code dans Locale::Codes
Locale::Codes::Language::ajouter_langue(CODE ,NOM [,ENSEMBLE_CODES])
Voir ajouter_code dans Locale::Codes
Locale::Codes::Language::supprimer_langue(CODE [,ENSEMBLE_CODES])
Voir supprimer_code dans Locale::Codes
Locale::Codes::Language::ajouter_alias_langue(NOM ,NOUVEAU_NOM)
Voir ajouter_alias dans Locale::Codes
Locale::Codes::Language::supprimer_alias_langue(NOM)
Voir supprimer_alias dans Locale::Codes
Locale::Codes::Language::renommer_code_langue(CODE ,NOUVEAU_CODE [,ENSEMBLE_CODES])
Voir remplacer_code dans Locale::Codes
Locale::Codes::Language::ajouter_alias_code_langue(CODE ,NOUVEAU_CODE [,ENSEMBLE_CODES])
Voir ajouter_alias_code dans Locale::Codes
Locale::Codes::Language::supprimer_alias_code_langue(CODE [,ENSEMBLE_CODES])
Voir supprimer_alias_code dans Locale::Codes
