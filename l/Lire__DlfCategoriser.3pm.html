DlfCategoriser(3pm) Documentation de Lire de LogReport DlfCategoriser(3pm)

NOM

Lire::DlfCategoriser - Classe de base pour les analyseurs qui produisent des enregistrements DLF étendus.

SYNTAXE

use base qw/ Lire::DlfCategoriser /;
sub categorise {
  my ( $self, $dlf ) = @_;
  # Ajoute le champ étendu au DLF.
  return;
}

DESCRIPTION

Ce paquet définit une classe de base qui peut être utilisée pour Lire::DlfAnalyser qui écrit dans un ExtendedSchema. Le categoriseur doit seulement implémenter la méthode categorise() au lieu de la méthode plus générique analyse().

MÉTHODES DE MÉTADONNÉES

Lire::DlfCategoriser doit implémenter les mêmes méthodes de métadonnées que Lire::DlfAnalyser (name(), src_schema(), dst_schema(), title(), description()).

MÉTHODES D'IMPLÉMENTATION

Le categoriseur fait son travail en utilisant les méthodes initialise() et categorise().

analyse( $process, $config )

Lire::DlfCategoriser implémente la méthode analyse(). Elle exécutera la requête sur le src_schema() en utilisant le filtre correct et appellera categorise() sur chaque DLF retourné. Le champ étendu sera alors écrit dans le dst_schema(). Les erreurs doivent être signalées en mourant.

initialise( $config )

Cette méthode est appelée avant que la méthode categorise() ne soit appelée.

Le paramètre $config contient des données de configuration qui ont été spécifiées dans l'AnalysisJob pour cet analyseur. Pour enregistrer une spécification de configuration pour votre DlfCategoriser, il suffit de définir une spécification de configuration sous le nom analyser_name_properties. Ceci devrait être soit un RecordSpec, soit un ObjectSpec.

categorise( $dlf )

Appelée une fois pour chaque enregistrement DLF qui doit être catégorisé. Le categoriseur doit ajouter les champs étendus directement à la référence de tableau haché $dlf.

finalise( $config )

Cette méthode est appelée après que tous les enregistrements DLF ont été catégorisés.

Le paramètre $config contient des données de configuration qui ont été spécifiées dans l'AnalysisJob pour cet analyseur. Pour enregistrer une spécification de configuration pour votre DlfCategoriser, il suffit de définir une spécification de configuration sous le nom analyser_name_properties. Ceci devrait être soit un RecordSpec, soit un ObjectSpec.

L'implémentation par défaut ne fait rien.
