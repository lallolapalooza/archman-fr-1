NOM

Lire::Syslog - analyseur de lignes de style syslog

SYNOPIS

use Lire::Syslog;

my $parser = new Lire::Syslog;

my $rec = $parser->parse( $line );

DESCRIPTION

Ce module définit des objets capables d'analyser les journaux provenant de plusieurs variantes de démons de journalisation.

Il prend actuellement en charge les formats de fichier syslog suivants :

Démon syslog BSD classique
Le format syslog BSD "classique" : 
MMM DD HH:MM:SS NomHote Message
Démon syslog Solaris 8
Le démon syslog de Solaris 8 inclut également la facilité et le niveau : 
MMM DD HH:MM:SS NomHote Processus[Pid]: [ID DDDDDD Facilite.Niveau] Message
Démon de journalisation Netscape Messaging Server
Le démon syslog fourni avec Netscape Messaging Server utilise une date au format de journalisation commun : 
[DD/MMM/YYYY:HH:MM:SS +ZZZZ] NomHote Processus[Pid]: Facilite Niveau: Message
Démon syslog WebTrends
Le format utilisé par le démon syslog fourni avec WebTrends : 
WTsyslog[YYYY-MM-DD HH:MM:SS ip=NOMHOTE pri=PRIORITE_WT] <XX>Message
Syslog Kiwi (format de date ISO)
Les formats de journaux ISO utilisés par le démon Syslog Kiwi (http://www.kiwisyslog.com/info_sysd.htm), un démon de journalisation souvent rencontré sur les plateformes Win32 : 
YYYY-MM-DD HH:MM:SS [TAB] Facilite.Niveau [TAB] NomHote [TAB] Message
Syslog Kiwi (format de date US)
Le format de date US utilisé par le démon Syslog Kiwi : 
MM-DD-YYYY HH:MM:SS [TAB] Facilite.Niveau [TAB] NomHote [TAB] Message
Syslog Kiwi (format de date JJ-MM-AAAA)
Le format de date JJ-MM-AAAA utilisé par le démon Syslog Kiwi : 
DD-MM-YYYY HH:MM:SS [TAB] Facilite.Niveau [TAB] NomHote [TAB] Message
Démon de journalisation Sendmail Switch
Le format utilisé par le démon de journalisation fourni avec Sendmail Switch sur les plateformes Win32 : 
MM/DD/YY HH:MM:SS Processus(Pid): Niveau: Message
Démon Syslog conforme à la RFC 3164
Un format des démons Syslog conformes à la RFC 3164 qui inclut la priorité codée et l'année dans la date. La RFC 3164 définit le "protocole Syslog BSD". 
<Priorite>MMM DD AAAA HH:MM:SS: Processus[Pid]: Message

Lors de la première utilisation de la méthode parse(), l'analyseur essaiera chacun des formats pris en charge pour détecter le format syslog. Si aucun format ne correspond, le module appellera lr_err() et arrêtera le programme. Chaque autre invocation de parse() utilisera le même format.

La méthode parse() retournera une référence de hachage qui contiendra les clés suivantes :

timestamp
L'horodatage de l'événement.
hostname
Le nom ou l'adresse IP de l'hôte qui a envoyé le message.
process
Le "processus" qui a enregistré l'événement. Formellement, le message syslog ne contient pas de champ processus, mais c'est généralement le premier mot avant un deux-points dans le contenu du message.
pid
Le PID du processus qui a enregistré l'événement. C'est généralement ce qui se trouve entre [] dans la partie processus du message.
identifier
Cette clé n'est présente que lorsque le journal provient d'un démon syslog Solaris 8. Elle contient l'identifiant qui suit ID dans le message.
facility
La facilité (kern, mail, local0, etc.) syslog du message. Ceci n'est pas pris en charge dans tous les formats de fichier, cette clé peut donc être indisponible.
level
Le niveau (emerg, info, notice, etc.) syslog du message. Ceci n'est pas pris en charge dans tous les formats de fichier, cette clé peut donc être indisponible.
content
Le message syslog réel (avec le processus et le PID supprimés). De nombreux périphériques réseau auront également un autre horodatage de style BSD au début du message. S'il est présent, il sera également supprimé.

UTILISATION

package Lire::Foo;
use base qw/ Lire::Syslog /;
sub parse {
   my $self = shift;
   my $line = shift;
   # ceci exécute parse de Lire::Syslog, définissant des clés comme 'jour', 'processus'
   # et 'nomhote'
   my $rec = $self->SUPER::parse($line);
   $rec->{'foo'} = dosomethingwith( $rec->{'content'} );
   return $rec
}

Maintenant, on peut exécuter dans un script

my $parser = new Lire::Foo();
while ( <> ) {
   chomp;
   my $log = $parser->parse( $line );
}

ce qui définit $log->{'jour'}, ... $log->{'processus'} et $log->{'foo'}.
