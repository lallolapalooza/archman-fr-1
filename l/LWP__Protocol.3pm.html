NOM

LWP::Protocol - Classe de base pour les protocoles LWP

SYNTAXE

package LWP::Protocol::foo;
use parent qw(LWP::Protocol);

DESCRIPTION

Cette classe est utilisée comme classe de base pour toutes les implémentations de protocoles prises en charge par la bibliothèque LWP.

Lors de la création d'une instance de cette classe en utilisant LWP::Protocol::create($url), vous obtenez une sous-classe initialisée appropriée pour cette méthode d'accès. En d'autres termes, la fonction "create" de LWP::Protocol appelle le constructeur d'une de ses sous-classes.

Toutes les classes dérivées de "LWP::Protocol" doivent surcharger la méthode request() qui est utilisée pour traiter une requête. La méthode surchargée peut utiliser la méthode collect() pour rassembler des morceaux de données au fur et à mesure de leur réception.

MÉTHODES

Les méthodes et fonctions suivantes sont fournies :

new

my $prot = LWP::Protocol->new();

Le constructeur LWP::Protocol est hérité par les sous-classes. Comme il s'agit d'une classe de base virtuelle, cette méthode ne doit pas être appelée directement.

create

my $prot = LWP::Protocol::create($scheme)

Crée un objet de la classe implémentant le protocole pour gérer le schéma donné. Il s'agit d'une fonction, pas d'une méthode. C'est plus une fabrique d'objets qu'un constructeur. C'est la fonction que les agents utilisateurs devraient utiliser pour accéder aux protocoles.

implementor

my $class = LWP::Protocol::implementor($scheme, [$class])

Obtient et/ou définit la classe d'implémentation pour un schéma. Retourne '' si le schéma spécifié n'est pas pris en charge.

request

$response = $protocol->request($request, $proxy, undef);
$response = $protocol->request($request, $proxy, '/tmp/sss');
$response = $protocol->request($request, $proxy, \&callback, 1024);
$response = $protocol->request($request, $proxy, $fh);

Déclenche une requête sur le protocole et retourne un objet de réponse. Cette méthode doit être surchargée dans les sous-classes. Voir LWP::UserAgent pour la description des arguments.

collect

my $res = $prot->collect(undef, $response, $collector); # stocké dans $response
my $res = $prot->collect($filename, $response, $collector);
my $res = $prot->collect(sub { ... }, $response, $collector);

Collecte le contenu d'une requête et le traite de manière appropriée dans un scalaire, un fichier, ou en appelant un callback. Si le premier paramètre est indéfini, le contenu est stocké dans $response. S'il s'agit d'un scalaire simple, il est interprété comme un nom de fichier et le contenu est écrit dans ce fichier. S'il s'agit d'une référence de code, le contenu est passé à cette routine. S'il s'agit d'un descripteur de fichier, ou similaire, comme un objet File::Temp, le contenu y sera écrit.

Le collecteur est une routine qui sera appelée et qui est responsable de retourner des morceaux (sous forme de référence à un scalaire) de contenu à traiter. Le $collector signale "EOF" en retournant une référence à une chaîne vide.

La valeur de retour est la référence à l'objet HTTP::Response.

Note : Nous utiliserons l'argument callback ou fichier uniquement si "$response->is_success()". Cela évite d'envoyer des données de contenu pour les redirections et les réponses d'authentification au callback, ce qui serait déroutant.

collect_once

$prot->collect_once($arg, $response, $content)

Peut être appelée lorsque tout le contenu de la réponse est disponible sous forme de contenu. Cela invoquera "collect" dans LWP::Protocol avec un callback collecteur qui retourne une référence à $content la première fois et une chaîne vide la fois suivante.

VOIR AUSSI

Inspectez les fichiers LWP/Protocol/file.pm et LWP/Protocol/http.pm pour des exemples d'utilisation.
