NOM

Lire::Config::SpecParser - Créer une spécification de configuration à partir de fichiers XML

SYNTAXE

use Lire::Config::SpecParser;
my $parser = new Lire::Config::SpecParser;
my $spec = $parser->parsefile( 'spec.xml' );
$parser->merge_specifications_dir( '/etc/lire/config' );
my $spec = $parser->configspec();

DESCRIPTION

Il s'agit d'un Lire::XMLParser qui peut construire des objets Lire::Config::ConfigSpec à partir d'un fichier XML.

new()

Crée un nouvel objet analyseur.

configspec()

Retourne l'objet Lire::Config::ConfigSpec analysé.

merge_specifications_dir( $dir )

Analyse tous les fichiers se terminant par '.xml' dans le $directory. Les types définis dans ces fichiers seront fusionnés à l'objet ConfigSpec de cet analyseur.

merge_specification_dir( $file )

Analyse le fichier XML $file et fusionne les types qu'il définit dans le ConfigSpec défini par cet analyseur.
