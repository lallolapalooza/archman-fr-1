Plugin(3pm) Documentation Lire de LogReport Plugin(3pm)

NOM

Lire::Plugin - Interface de base de tous les plugins Lire.

SYNTAXE

use base qw/ Lire::Plugin /;

DESCRIPTION

Ce paquet définit l'interface de base implémentée par tous les plugins.

CONSTRUCTEUR PAR DÉFAUT

La classe de plugin possède un constructeur new() qui bénit une référence de hachage.

name()

Retourne le nom du plugin.

title()

Retourne un nom plus convivial pour le plugin.

description()

Retourne une documentation basée sur XML DocBook du plugin.

type

Retourne le type de plugin. Il existe trois types de plugins dans Lire :

dlf_converter
Ces plugins sont utilisés pour convertir les fichiers journaux en DLF. Le plugin devra également implémenter l'interface Lire::DlfConverter.
output_format
Ces plugins sont utilisés pour formater les rapports XML. Les plugins de ce type doivent implémenter l'interface Lire::OutputFormat.
dlf_analyser
Ces plugins sont utilisés pour générer d'autres enregistrements DLF à partir d'enregistrements Dlf existants. Ils doivent implémenter l'interface Lire::Analaser.
chart_type
Ces plugins sont utilisés pour générer des graphiques.

VOIR AUSSI

Lire::PluginManager(3pm), Lire::DlfConverter(3pm), Lire::OutputFormat(3pm), Lire::DlfAnalyser(3pm), Lire::DlfChartType(3pm)
