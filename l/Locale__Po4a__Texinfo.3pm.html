NOM

Locale::Po4a::Texinfo - Convertit des documents Texinfo et leurs dérivés depuis/vers des fichiers PO

DESCRIPTION

L'objectif du projet po4a (PO pour tout) est de faciliter les traductions (et plus intéressant encore, la maintenance des traductions) en utilisant les outils gettext dans des domaines où ils n'étaient pas attendus, comme la documentation.

Locale::Po4a::Texinfo est un module pour aider à la traduction de documents Texinfo vers d'autres langues [humaines].

Ce module contient les définitions des commandes et environnements Texinfo courants.

Seuls les commentaires commençant par 'TRANSLATORS' sont ajoutés aux fichiers PO pour guider les traducteurs.

STATUT DE CE MODULE

Ce module est encore en version bêta et n'est pas prêt pour une utilisation en production. Veuillez envoyer des correctifs pour contribuer, pas des rapports de bogues car nous ne savons pas comment les traiter.

OPTIONS ACCEPTÉES PAR CE MODULE

Ce sont les options particulières de ce module :

no-warn
Ne pas avertir sur l'état actuel de ce module.
