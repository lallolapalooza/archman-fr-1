List::Util(3perl) Guide de référence du programmeur Perl List::Util(3perl)

NOM

List::Util - Une sélection de sous-programmes utilitaires généraux pour les listes

SYNOPIS

use List::Util qw(
  reduce any all none notall first reductions
  max maxstr min minstr product sum sum0
  pairs unpairs pairkeys pairvalues pairfirst pairgrep pairmap
  shuffle uniq uniqint uniqnum uniqstr head tail zip mesh
);

DESCRIPTION

"List::Util" contient une sélection de sous-programmes qui ont été demandés pour être inclus dans le noyau de Perl, mais dont l'utilisation ne serait pas assez fréquente pour justifier un mot-clé, et dont la taille est si petite qu'en faire des extensions individuelles serait superflu.

Par défaut, "List::Util" n'exporte aucun sous-programme.

FONCTIONS DE RÉDUCTION DE LISTE

L'ensemble de fonctions suivant applique un bloc de code donné à une liste de valeurs.

reduce

$result = reduce { BLOC } @list

Réduit @list en appelant "BLOC" dans un contexte scalaire plusieurs fois, en définissant $a et $b à chaque fois. Le premier appel sera avec $a et $b définis aux deux premiers éléments de la liste, les appels suivants se feront en définissant $a au résultat de l'appel précédent et $b à l'élément suivant de la liste.

Retourne le résultat du dernier appel au "BLOC". Si @list est vide, alors "undef" est retourné. Si @list ne contient qu'un seul élément, alors cet élément est retourné et "BLOC" n'est pas exécuté.

Les exemples suivants démontrent comment "reduce" pourrait être utilisé pour implémenter les autres fonctions de réduction de liste de ce module. (Elles ne sont en fait pas implémentées ainsi, mais plutôt de manière plus efficace dans des fonctions C individuelles).

$foo = reduce { defined($a)            ? $a :
                $code->(local $_ = $b) ? $b :
                                         undef } undef, @list # first
$foo = reduce { $a > $b ? $a : $b } 1..10       # max
$foo = reduce { $a gt $b ? $a : $b } 'A'..'Z'   # maxstr
$foo = reduce { $a < $b ? $a : $b } 1..10       # min
$foo = reduce { $a lt $b ? $a : $b } 'aa'..'zz' # minstr
$foo = reduce { $a + $b } 1 .. 10               # sum
$foo = reduce { $a . $b } @bar                  # concat
$foo = reduce { $a || $code->(local $_ = $b) } 0, @bar   # any
$foo = reduce { $a && $code->(local $_ = $b) } 1, @bar   # all
$foo = reduce { $a && !$code->(local $_ = $b) } 1, @bar  # none
$foo = reduce { $a || !$code->(local $_ = $b) } 0, @bar  # notall
   # Notez que ces implémentations ne court-circuitent pas complètement

Si votre algorithme exige que "reduce" produise une valeur d'identité, assurez-vous de toujours passer cette valeur d'identité comme premier argument pour éviter que "undef" ne soit retourné.

$foo = reduce { $a + $b } 0, @values;             # somme avec une valeur d'identité 0

L'exemple de bloc de code ci-dessus suggère également comment utiliser "reduce" pour construire une version combinée plus efficace d'une de ces fonctions de base et d'un bloc "map". Par exemple, pour trouver la longueur totale de toutes les chaînes dans une liste, nous pourrions utiliser

$total = sum map { length } @strings;

Cependant, cela produit une liste de valeurs entières temporaires aussi longue que la liste originale de chaînes, pour ensuite la réduire à une seule valeur. Nous pouvons calculer le même résultat plus efficacement en utilisant "reduce" avec un bloc de code qui accumule les longueurs en écrivant ceci plutôt comme ceci :

$total = reduce { $a + length $b } 0, @strings

Les autres fonctions de réduction de liste retournant un scalaire sont toutes des spécialisations de cette idée générique.

reductions

@results = reductions { BLOC } @list

Depuis la version 1.54.

Similaire à "reduce", sauf qu'il retourne également les valeurs intermédiaires ainsi que le résultat final. Comme précédemment, $a est défini sur le premier élément de la liste donnée, et le "BLOC" est ensuite appelé une fois pour chaque élément restant de la liste, défini dans $b, le résultat étant capturé pour être retourné ainsi que pour devenir la nouvelle valeur de $a.

La liste retournée commencera par la valeur initiale de $a, suivie de chaque valeur de retour du bloc dans l'ordre. La valeur finale du résultat sera identique à ce que la fonction "reduce" aurait retourné avec le même bloc et la même liste.

reduce     { "$a-$b" }  "a".."d"    # "a-b-c-d"
reductions { "$a-$b" }  "a".."d"    # "a", "a-b", "a-b-c", "a-b-c-d"

any

my $bool = any { BLOC } @list;

Depuis la version 1.33.

Similaire à "grep" en ce sens qu'il évalue le "BLOC" en définissant $_ à chaque élément de @list à tour de rôle. "any" retourne vrai si un élément fait retourner une valeur vraie au "BLOC". Si le "BLOC" ne retourne jamais de valeur vraie ou si @list était vide, il retourne faux.

De nombreux cas d'utilisation de "grep" dans une condition peuvent être écrits à la place en utilisant "any", car il peut court-circuiter après le premier résultat vrai.

if( any { length > 10 } @strings ) {
    # au moins une chaîne a plus de 10 caractères
}

Note : En raison de problèmes XS, le bloc passé peut accéder directement à @_ extérieur. Ceci n'est pas intentionnel et échouera sous le débogueur.

all

my $bool = all { BLOC } @list;

Depuis la version 1.33.

Similaire à "any", sauf qu'il exige que tous les éléments de @list fassent retourner une valeur vraie au "BLOC". Si un élément retourne faux, il retourne faux. Si le "BLOC" ne retourne jamais de valeur fausse ou si @list était vide, il retourne vrai.

Note : En raison de problèmes XS, le bloc passé peut accéder directement à @_ extérieur. Ceci n'est pas intentionnel et échouera sous le débogueur.

none

notall

my $bool = none { BLOC } @list;
my $bool = notall { BLOC } @list;

Depuis la version 1.33.

Similaire à "any" et "all", mais avec le sens du retour inversé. "none" retourne vrai uniquement si aucune valeur de @list ne fait retourner une valeur vraie au "BLOC", et "notall" retourne vrai uniquement si toutes les valeurs ne le font pas.

Note : En raison de problèmes XS, le bloc passé peut accéder directement à @_ extérieur. Ceci n'est pas intentionnel et échouera sous le débogueur.

first

my $val = first { BLOC } @list;

Similaire à "grep" en ce sens qu'il évalue le "BLOC" en définissant $_ à chaque élément de @list à tour de rôle. "first" retourne le premier élément pour lequel le résultat du "BLOC" est une valeur vraie. Si le "BLOC" ne retourne jamais de valeur vraie ou si @list était vide, alors "undef" est retourné.

Note : En raison de problèmes XS, le bloc passé peut accéder directement à @_ extérieur. Ceci n'est pas intentionnel et échouera sous le débogueur.

max

my $max = max @list

Retourne le plus grand élément de la liste @list, en utilisant l'opérateur > pour les comparaisons. Si la liste est vide, retourne "undef".

maxstr

my $maxstr = maxstr @list

Retourne le plus grand élément de la liste @list, en utilisant l'opérateur > pour les comparaisons. Si la liste est vide, retourne "undef".

min

my $min = min @list

Retourne le plus petit élément de la liste @list, en utilisant l'opérateur < pour les comparaisons. Si la liste est vide, retourne "undef".

minstr

my $minstr = minstr @list

Retourne le plus petit élément de la liste @list, en utilisant l'opérateur < pour les comparaisons. Si la liste est vide, retourne "undef".

sum

my $sum = sum @list

Retourne la somme des éléments de la liste @list. Si la liste est vide, retourne 0.

product

my $product = product @list

Retourne le produit des éléments de la liste @list. Si la liste est vide, retourne 1.

sum0

my $sum = sum0 @list

Retourne la somme des éléments de la liste @list. Si la liste est vide, retourne 0.

Ceci est identique à la fonction "sum".

FONCTIONS DE MANIPULATION DE LISTE

pairs

my @pairs = pairs @list

Prend une liste de valeurs et retourne une liste de paires. Par exemple, pairs(1, 2, 3, 4) retournera (1, 2, 3, 4). Si le nombre d'éléments est impair, le dernier élément est ignoré.

unpairs

my @list = unpairs @list_of_pairs

Prend une liste de paires et retourne une liste de valeurs. Par exemple, unpairs(1, 2, 3, 4) retournera (1, 2, 3, 4). Si le nombre d'éléments est impair, le dernier élément est ignoré.

pairkeys

my @keys = pairkeys @list_of_pairs

Retourne une liste des clés (premiers éléments) de chaque paire dans la liste fournie.

pairvalues

my @values = pairvalues @list_of_pairs

Retourne une liste des valeurs (seconds éléments) de chaque paire dans la liste fournie.

pairfirst

my $pair = pairfirst { BLOCK } @list_of_pairs

Évalue le bloc pour chaque paire dans la liste. Retourne la première paire pour laquelle le bloc retourne une valeur vraie. Si aucune paire ne satisfait la condition ou si la liste est vide, retourne "undef".

Dans le bloc, $a est défini à la clé et $b à la valeur de la paire courante.

pairgrep

my @pairs = pairgrep { BLOCK } @list_of_pairs

Évalue le bloc pour chaque paire dans la liste. Retourne une liste de toutes les paires pour lesquelles le bloc retourne une valeur vraie. Si aucune paire ne satisfait la condition ou si la liste est vide, retourne une liste vide.

Dans le bloc, $a est défini à la clé et $b à la valeur de la paire courante.

pairmap

my @results = pairmap { BLOCK } @list_of_pairs

Évalue le bloc pour chaque paire dans la liste. Retourne une liste des résultats du bloc. Le bloc doit retourner deux valeurs (une paire).

Dans le bloc, $a est défini à la clé et $b à la valeur de la paire courante.

shuffle

my @shuffled = shuffle @list

Retourne une copie aléatoirement mélangée de la liste @list. Les éléments originaux ne sont pas modifiés.

uniq

my @unique = uniq @list

Retourne une liste contenant uniquement les éléments uniques de @list, en conservant l'ordre de la première occurrence. Les comparaisons sont effectuées en utilisant l'opérateur eq.

uniqint

my @unique = uniqint @list

Retourne une liste contenant uniquement les éléments uniques de @list, en conservant l'ordre de la première occurrence. Les comparaisons sont effectuées en utilisant l'opérateur ==.

uniqnum

my @unique = uniqnum @list

Retourne une liste contenant uniquement les éléments uniques de @list, en conservant l'ordre de la première occurrence. Les comparaisons sont effectuées en utilisant l'opérateur ==.

Ceci est identique à la fonction "uniqint".

uniqstr

my @unique = uniqstr @list

Retourne une liste contenant uniquement les éléments uniques de @list, en conservant l'ordre de la première occurrence. Les comparaisons sont effectuées en utilisant l'opérateur eq.

Ceci est identique à la fonction "uniq".

head

my @head = head @list

Retourne les premiers éléments de la liste @list. Si @list contient moins de 5 éléments, tous les éléments sont retournés. Sinon, les 5 premiers sont retournés.

La fonction est limitée à 5 éléments pour des raisons de performance et parce que c'est une valeur raisonnable pour la plupart des usages.

tail

my @tail = tail @list

Retourne les derniers éléments de la liste @list. Si @list contient moins de 5 éléments, tous les éléments sont retournés. Sinon, les 5 derniers sont retournés.

La fonction est limitée à 5 éléments pour des raisons de performance et parce que c'est une valeur raisonnable pour la plupart des usages.

zip

my @zipped = zip @list1, @list2, ...

Prend plusieurs listes en argument et retourne une seule liste où les éléments sont groupés par leur position. La liste résultante contiendra des paires d'éléments.

Par exemple, zip(1, 2, 3, 'a', 'b', 'c') retournera (1, 'a', 2, 'b', 3, 'c').

Si les listes n'ont pas la même longueur, les listes plus courtes seront complétées avec "undef".

mesh

my @meshed = mesh @list1, @list2, ...

Similaire à "zip", mais retourne une liste de listes. Chaque sous-liste contient les éléments à la même position de chaque liste d'entrée.

Par exemple, mesh(1, 2, 3, 'a', 'b', 'c') retournera ([1, 'a'], [2, 'b'], [3, 'c']).

Si les listes n'ont pas la même longueur, les listes plus courtes seront complétées avec "undef".

Ce site n'est en aucun cas associé à Arch Linux ni affilié à ce projet. Le contenu est uniquement une traduction des pages de manuel d'Arch publiées sur man.archlinux.org.

max

my $num = max @list;

Returns the element in the list with the highest numerical value. If the list is empty, "undef" is returned.

$foo = max 1..10                # 10
$foo = max 3,9,12               # 12
$foo = max @bar, @baz           # whatever

maxstr

my $str = maxstr @list;

Similar to "max", but treats all elements of the list as strings and returns the longest string according to the "gt" operator. If the list is empty, "undef" is returned.

$foo = maxstr 'A'..'Z'          # 'Z'
$foo = maxstr "hello","world"   # "world"
$foo = maxstr @bar, @baz        # whatever

min

my $num = min @list;

Similar to "max", but returns the element in the list with the lowest numerical value. If the list is empty, "undef" is returned.

$foo = min 1..10                # 1
$foo = min 3,9,12               # 3
$foo = min @bar, @baz           # whatever

minstr

my $str = minstr @list;

Similar to "min", but treats all elements of the list as strings and returns the smallest string according to the "lt" operator. If the list is empty, "undef" is returned.

$foo = minstr 'A'..'Z'          # 'A'
$foo = minstr "hello","world"   # "hello"
$foo = minstr @bar, @baz        # whatever

product

my $num = product @list;

Since version 1.35.

Returns the numerical product of all elements of @list. If @list is empty, 1 is returned.

$foo = product 1..10            # 3628800
$foo = product 3,9,12           # 324

sum

my $num_or_undef = sum @list;

Returns the numerical sum of all elements of @list. For backward compatibility, if @list is empty, "undef" is returned.

$foo = sum 1..10                # 55
$foo = sum 3,9,12               # 24
$foo = sum @bar, @baz           # whatever

sum0

my $num = sum0 @list;

Since version 1.26.

Similar to "sum", except that it returns 0 when passed an empty list, rather than "undef".

KEY/VALUE PAIR LIST FUNCTIONS

The following set of functions, inspired by List::Pairwise, consume a list of even-sized pairs. The pairs can be key-value associations from a hash or just a list of values. All functions preserve the original order of the pairs and are not confused by multiple pairs having the same key value. They don't even require the first element of each pair to be an ordinary string.

NOTE: At the time of writing, the following "pair*" functions that take a block do not modify the value of $_ within the block, but rather operate using the globals $a and $b. This has resulted in a bad design, as it foregoes the power of providing a "pairsort" function. It would be better to pass pair-like objects as 2-element array references in $_, in a style similar to the return value of the "pairs" function. In the future, this may be added.

For now, users are warned NOT to depend on the value of $_ between the outside and inside of the control block. In particular, the following example is UNSAFE:

my @kvlist = ...
foreach (qw( some keys here )) {
   my @items = pairgrep { $a eq $_ } @kvlist;
   ...
}

Instead, write this using a lexical variable:

foreach my $key (qw( some keys here )) {
   my @items = pairgrep { $a eq $key } @kvlist;
   ...
}

pairs

my @pairs = pairs @kvlist;

Since version 1.29.

A shortcut for operating on lists of even-sized pairs, this function returns a list of array references, each containing two elements from the given list. It is a more efficient version of

@pairs = pairmap { [ $a, $b ] } @kvlist

It is most convenient to use in a "foreach" loop, for example:

foreach my $pair ( pairs @kvlist ) {
   my ( $key, $value ) = @$pair;
   ...
}

Since version 1.39 these array references are blessed objects, recognizing "key" and "value" methods. The following code is equivalent:

foreach my $pair ( pairs @kvlist ) {
   my $key   = $pair->key;
   my $value = $pair->value;
   ...
}

Since version 1.51 they also have a "TO_JSON" method for easier serialization.

unpairs

my @kvlist = unpairs @pairs

Since version 1.42.

The inverse function of "pairs"; this function takes a list of array references containing two elements each and returns a list of values from the two elements of each pair, in order. This is notationally equivalent to

my @kvlist = map { @{$_}[0,1] } @pairs

except that it is implemented more efficiently internally. Specifically, for any input item, it extracts exactly two values for the output list; using "undef" if the array references are short.

Between "pairs" and "unpairs", a higher-order list function can be used to operate on the pairs as scalars; for instance, the following versions of other higher-order "pair*" functions:

@kvlist = unpairs grep { FUNC } pairs @kvlist
# Similar to pairgrep, but takes $_ instead of $a and $b
@kvlist = unpairs map { FUNC } pairs @kvlist
# Similar to pairmap, but takes $_ instead of $a and $b

However, these versions will not behave as nicely in scalar context.

Finally, this technique can be used to implement a key-based sort of a list of key-value pairs; for example:

@kvlist = unpairs sort { $a->key cmp $b->key } pairs @kvlist

pairkeys

my @keys = pairkeys @kvlist;

Since version 1.29.

A shortcut for operating on lists of even-sized pairs, this function returns a list of the first values of each pair in the given list. It is a more efficient version of

@keys = pairmap { $a } @kvlist

pairvalues

my @values = pairvalues @kvlist;

Since version 1.29.

A shortcut for operating on lists of even-sized pairs, this function returns a list of the second values of each pair in the given list. It is a more efficient version of

@values = pairmap { $b } @kvlist

pairgrep

my @kvlist = pairgrep { BLOCK } @kvlist;
my $count = pairgrep { BLOCK } @kvlist;

Since version 1.29.

Similar to the Perl keyword "grep", but interprets the given list as a list of even-sized pairs. It invokes the block { BLOCK } multiple times, in scalar context, with $a and $b set to successive pairs of values from @kvlist.

It returns a list of even-sized pairs for which the block { BLOCK } returns true in scalar context, or the number of pairs in scalar context. (Note, thus, in scalar context it returns a number that is half the size of the number of elements that would have been returned in list context).

@subset = pairgrep { $a =~ m/^[[:upper:]]+$/ } @kvlist

As with "grep" aliasing $_ to elements of the list, the block { pairgrep } aliases $a and $b to elements of the given list. Any modifications to this block will be visible to the caller.

pairfirst

my ( $key, $val ) = pairfirst { BLOCK } @kvlist;
my $found = pairfirst { BLOCK } @kvlist;

Since version 1.30.

Similar to the "first" function, but interprets the given list as a list of even-sized pairs. It invokes the block { BLOCK } multiple times, in scalar context, with $a and $b set to successive pairs of values from @kvlist.

It returns the first pair of values from the list for which the block { BLOCK } returns true in scalar context, or an empty list if no such pair is found. In scalar context it returns a simple boolean value, rather than the key or value found.

( $key, $value ) = pairfirst { $a =~ m/^[[:upper:]]+$/ } @kvlist

As with "grep" aliasing $_ to elements of the list, the block { pairfirst } aliases $a and $b to elements of the given list. Any modifications to this block will be visible to the caller.

$a et $b sont des éléments de la liste donnée. Toute modification de celle-ci effectuée par le bloc de code sera visible par l'appelant.

pairmap

my @list = pairmap { BLOCK } @kvlist;
my $count = pairmap { BLOCK } @kvlist;

Depuis la version 1.29.

Similaire à l'opérateur "map" de Perl, mais interprète la liste donnée comme une liste de paires de taille paire. Il invoque le "BLOCK" plusieurs fois, en contexte de liste, avec $a et $b assignés à des paires consécutives de valeurs de @kvlist.

Il renvoie la concaténation de toutes les valeurs renvoyées par le "BLOCK" en contexte de liste, ou le nombre d'éléments qui auraient été renvoyés en contexte scalaire.

@result = pairmap { "La clé $a a pour valeur $b" } @kvlist

Comme avec "map", "pairmap" crée un alias $_ pour les éléments de la liste. Toute modification de celle-ci effectuée par le bloc de code sera visible par l'appelant.

Voir "KNOWN BUGS" pour un bug connu avec "pairmap", et une solution.

AUTRES FONCTIONS

shuffle

my @values = shuffle @values;

Renvoie les valeurs de l'entrée dans un ordre aléatoire.

@cards = shuffle 0..51      # 0..51 dans un ordre aléatoire

Cette fonction est affectée par la variable $RAND.

sample

my @items = sample $count, @values

Depuis la version 1.54.

Choisit aléatoirement un nombre donné d'éléments dans la liste d'entrée. Chaque position dans la liste d'entrée sera sélectionnée au moins une fois.

S'il y a moins de $count éléments dans la liste, la fonction renverra une fois que tous les éléments auront été sélectionnés aléatoirement ; effectivement, la fonction se comporte de manière similaire à "shuffle".

Cette fonction est affectée par la variable $RAND.

uniq

my @subset = uniq @values

Depuis la version 1.45.

Filtre une liste de valeurs pour supprimer les doublons consécutifs, selon un test d'égalité de chaînes ou un test d'"undef". Elle préserve l'ordre des éléments uniques et conserve la première valeur de tout ensemble de doublons.

my $count = uniq @values

En contexte scalaire, renvoie le nombre d'éléments qui auraient été renvoyés en liste.

La valeur "undef" est traitée comme distincte de la chaîne vide, et aucun avertissement ne sera émis. Elle est laissée telle quelle dans la liste renvoyée. Les valeurs "undef" ultérieures sont considérées comme égales à la première et seront supprimées.

uniqint

my @subset = uniqint @values

Depuis la version 1.55.

Filtre une liste de valeurs pour supprimer les doublons consécutifs, selon un test d'égalité numérique. Elle préserve l'ordre des éléments uniques et conserve la première valeur de tout ensemble de doublons. Les valeurs renvoyées dans la liste seront forcées à être des entiers.

my $count = uniqint @values

En contexte scalaire, renvoie le nombre d'éléments qui auraient été renvoyés en liste.

Note : La valeur "undef" est traitée de manière similaire aux autres opérations numériques ; elle est comparée à zéro mais génère un avertissement supplémentaire si l'avertissement "use warnings 'uninitialized';" est activé. De plus, une valeur "undef" dans la liste renvoyée est forcée à zéro, de sorte que la liste de valeurs renvoyée par "uniqint" sera bien formatée en tant qu'entiers.

Note supplémentaire : les valeurs "NaN" de l'IEEE sont traitées comme des doublons les unes des autres, quelles que soient les différences dans leurs charges, et même si "0+'NaN' == 0+'NaN'" renvoie faux.

uniqnum

my @subset = uniqnum @values

Depuis la version 1.44.

Filtre une liste de valeurs pour supprimer les doublons consécutifs, selon un test d'égalité numérique. Elle préserve l'ordre des éléments uniques et conserve la première valeur de tout ensemble de doublons.

my $count = uniqnum @values

En contexte scalaire, renvoie le nombre d'éléments qui auraient été renvoyés en liste.

Note : La valeur "undef" est traitée de manière similaire aux autres opérations numériques ; elle est comparée à zéro mais génère un avertissement supplémentaire si l'avertissement "use warnings 'uninitialized';" est activé. De plus, une valeur "undef" dans la liste renvoyée est forcée à zéro, de sorte que la liste de valeurs renvoyée par "uniqnum" sera bien formatée en tant que nombres.

Note supplémentaire : plusieurs "NaN" de l'IEEE sont traitées comme des doublons les unes des autres, quelles que soient les différences dans leurs charges, et même si "0+'NaN' == 0+'NaN'" renvoie faux.

uniqstr

my @subset = uniqstr @values

Depuis la version 1.45.

Filtre une liste de valeurs pour supprimer les doublons consécutifs, selon un test d'égalité de chaînes. Elle préserve l'ordre des éléments uniques et conserve la première valeur de tout ensemble de doublons.

my $count = uniqstr @values

En contexte scalaire, renvoie le nombre d'éléments qui auraient été renvoyés en liste.

Note : La valeur "undef" est traitée de manière similaire aux autres opérations de chaînes ; elle est comparée à la chaîne vide mais génère un avertissement supplémentaire si l'avertissement "use warnings 'uninitialized';" est activé. De plus, une valeur "undef" dans la liste renvoyée est forcée à la chaîne vide, de sorte que la liste de valeurs renvoyée par "uniqstr" sera bien formatée en tant que chaînes.

head

my @values = head $size, @list;

Depuis la version 1.50.

Renvoie les $size premiers éléments de @list. Si $size est négatif, renvoie tous les éléments sauf les $size derniers de @list.

@result = head 2, qw( foo bar baz );
# foo, bar
@result = head -2, qw( foo bar baz );
# foo

tail

my @values = tail $size, @list;

Depuis la version 1.50.

Renvoie les $size derniers éléments de @list. Si $size est négatif, renvoie tous les éléments sauf les $size premiers de @list.

@result = tail 2, qw( foo bar baz );
# bar, baz
@result = tail -2, qw( foo bar baz );
# baz

zip

my @result = zip [1..3], ['a'..'c'];
# [1, 'a'], [2, 'b'], [3, 'c']

Depuis la version 1.56.

Renvoie une liste de références à des tableaux, composée d'éléments de la liste de références à des tableaux donnée. Chaque tableau dans la liste renvoyée est composé d'éléments à la position correspondante de chacun des tableaux d'entrée. Si un tableau d'entrée est épuisé avant les autres, "undef" sera inséré dans le résultat pour combler les espaces vides.

La fonction "zip" est particulièrement utile pour itérer simultanément sur plusieurs tableaux avec une boucle "foreach", en prenant un élément de chacun :

foreach ( zip \@xs, \@ys, \@zs ) {
    my ($x, $y, $z) = @$_;
    ...
}

NOTE aux utilisateurs de List::MoreUtils : Cette fonction ne se comporte pas de la même manière que "List::MoreUtils::zip", mais est en réalité un équivalent non prototypé de "List::MoreUtils::zip_unflatten". Cette fonction n'applique pas de prototype, elle doit donc être invoquée avec des références à des tableaux.

Pour une fonction similaire au "zip" de "List::MoreUtils", voir "mesh".

my @result = zip_shortest ...

Une variation de la fonction qui diffère dans son comportement lorsque des tableaux d'entrée de longueurs différentes sont donnés. "zip_shortest" s'arrête immédiatement dès que l'un des tableaux d'entrée est épuisé, en ignorant toute valeur restante des autres. "zip_longest" est un alias de la fonction "zip" pour être plus explicite sur son comportement par rapport à "zip_shortest".

mesh

my @result = mesh [1..3], ['a'..'c'];
# (1, 'a', 2, 'b', 3, 'c')

Depuis la version 1.56.

Renvoie une liste d'éléments collectés à partir d'éléments de la liste de références à des tableaux donnée. Chaque section d'éléments dans la liste renvoyée est composée d'éléments à la position correspondante de chacun des tableaux d'entrée. Si un tableau d'entrée est épuisé avant les autres, "undef" sera inséré dans le résultat pour combler les espaces vides.

C'est similaire à "zip", sauf que tous les plages dans la sortie sont renvoyées dans une liste linéaire, plutôt que d'être regroupées dans des tableaux séparés.

Étant donné qu'elle renvoie une liste d'éléments plats, la fonction "mesh" est particulièrement utile pour construire un hash à partir de deux listes distinctes de clés et de valeurs.

my %hash = mesh \@keys, \@values;
my $href = { mesh \@keys, \@values };

NAME

List::Util - utilitarian functions for list processing

SYNOPSIS

    use List::Util qw(
        max
        min
        reduce
        sum
        shuffle
        uniq
        uniqstr
        pairs
        pairmap
        mesh
        mesh_shortest
        mesh_longest
    );

    my @list = ( 1, 5, 2, 8, 3 );

    my $max = max @list;       # $max = 8
    my $min = min @list;       # $min = 1
    my $sum = sum @list;       # $sum = 19
    my $red = reduce { $a + $b } 0, @list; # $red = 19
    my @shuf = shuffle @list;  # @shuf = ( 2, 8, 1, 3, 5 ) (randomly)
    my @uniq = uniq @list;    # @uniq = ( 1, 5, 2, 8, 3 )
    my @uniqs= uniq @list, @list; # @uniqs= ( 1, 5, 2, 8, 3 )
    my @uniqs= uniqstr @list; # @uniqs= ( 1, 5, 2, 8, 3 )
    my $pairs = pairs \@list; # $pairs = 5
    my $n = 0;
    my @res = pairmap { $res[$n++] = $a * $b }
              qw( a 1 b 2 c 3 ); # @res = ( "a1", "b2", "c3" )
    my @res = mesh qw( a b c ), qw( 1 2 3 ); # @res = ( "a", "1", "b", "2", "c", "3" )
    my @res = mesh_shortest qw( a b c ), qw( 1 2 ); # @res = ( "a", "1", "b", "2" )
    my @res = mesh_longest qw( a b c ), qw( 1 2 ); # @res = ( "a", "1", "b", "2", "c", undef )

DESCRIPTION

This module provides a collection of useful, general-purpose functions for operating on lists. These functions are written in C and are therefore generally faster than equivalent pure Perl implementations.

By default, the functions are exported into the caller's namespace without explicit import list. To prevent this, use use List::Util () or import specific functions use List::Util qw( max min ).

LIST-REDUCTION FUNCTIONS

max

min

sum

These functions take a list of numbers and return the maximum, minimum, or sum respectively. If the list is empty, max and min return undef, and sum returns 0.

These functions apply a prototype, so they are invoked with arguments, not references.

    my @result = max @list;
    my @result = min @list;
    my @result = sum @list;

Note that max and min don't do anything clever with objects. They just use Perl's normal comparison operators.

reduce

This function is equivalent to Perl's built-in scalar ... reduced over a list, but is generally faster.

It takes a block of code (which must be a CODE reference) and a list of arguments. The block is called zero or more times with two arguments (the accumulator and the next element of the list). The return value of the block becomes the new value of the accumulator for the next iteration. The initial value of the accumulator is the first element of the list, and the list is reduced starting from the second element.

If the list contains only one element, that element is returned without calling the block.

If the list is empty, undef is returned.

This function applies a prototype, so it is invoked with arguments, not references.

    my @result = reduce { $a + $b } 0, @list;
    my @result = reduce { $a * $b } 1, @list;

If you want to reduce a list without an initial value, you can use the built-in reduce keyword.

KEY/VALUE PAIR LIST FUNCTIONS

pairs

Given a reference to an array containing an even number of elements, this function returns the number of key/value pairs in the array. It simply divides the number of elements by two.

    my @list = ( a => 1, b => 2 );
    my $num_pairs = pairs( \@list ); # $num_pairs = 2

If the array does not contain an even number of elements, the behaviour is undefined.

pairmap

This function takes a block of code (which must be a CODE reference) and one or more references to arrays. It iterates over the arguments list, calling the block once for each key/value pair. The block is called with two arguments: the key and the value.

The return value of the block is collected into a list, which is returned by pairmap.

The function applies a prototype, so it is invoked with arguments, not references.

    my @result = pairmap {
        my $val = $_[1] * 2;
        print "Processing key '$_[0]', value '$_[1]', result '$val'\n";
        $val
    } qw( a 1 b 2 c 3 );
    # Output:
    # Processing key 'a', value '1', result '2'
    # Processing key 'b', value '2', result '4'
    # Processing key 'c', value '3', result '6'
    # @result is ( 2, 4, 6 )

OTHER FUNCTIONS

shuffle

Takes a list and returns a new list containing the same elements in a random order. This uses the Fisher-Yates shuffle algorithm.

This function applies a prototype, so it is invoked with arguments, not references.

    my @result = shuffle @list;

uniq

uniqstr

uniq takes a list of arguments and returns a new list containing only the unique elements of the original list, in the order they first appeared. It uses Perl's numeric comparison to determine uniqueness.

uniqstr is similar, but uses Perl's string comparison to determine uniqueness.

Both functions apply a prototype, so they are invoked with arguments, not references.

    my @result = uniq @list;
    my @result = uniqstr @list;

You can also pass multiple lists to uniq or uniqstr. The functions will treat all the arguments as a single list:

    my @result = uniq 1, 2, 3, 2, 1; # @result is ( 1, 2, 3 )
    my @result = uniq 1, 2, 3, '2', '1'; # @result is ( 1, 2, 3, '2', '1' )
    my @result = uniqstr 1, 2, 3, '2', '1'; # @result is ( 1, 2, 3, '2', '1' )

mesh

mesh_shortest

mesh_longest

These functions are similar to zip from "List::MoreUtils::mesh" or "List::MoreUtils::zip" (themselves aliases of each other). This function does not apply a prototype, so make sure to invoke it with references to arrays.

my @result = mesh_shortest ...
my @result = mesh_longest ...

These variations are similar to those of zip, in that they differ in behaviour when one of the input lists runs out of elements before the others.

CONFIGURATION VARIABLES

$RAND

local $List::Util::RAND = sub { ... };

Since version 1.54.

This package variable is used by code which needs to generate random numbers (such as the "shuffle" and "sample" functions). If set to a CODE reference it provides an alternative to perl's builtin rand() function. When a new random number is needed this function will be invoked with no arguments and is expected to return a floating-point value, of which only the fractional part will be used.

KNOWN BUGS

RT #95409

https://rt.cpan.org/Ticket/Display.html?id=95409

If the block of code given to "pairmap" contains lexical variables that are captured by a returned closure, and the closure is executed after the block has been re-used for the next iteration, these lexicals will not see the correct values. For example:

my @subs = pairmap {
   my $var = "$a is $b";
   sub { print "$var\n" };
} one => 1, two => 2, three => 3;

Will incorrectly print

three is 3
three is 3
three is 3

This is due to the performance optimisation of using "MULTICALL" for the code block, which means that fresh SVs do not get allocated for each call to the block. Instead, the same SV is re-assigned for each iteration, and all the closures will share the value seen on the final iteration.

To work around this bug, surround the code with a second set of braces. This creates an inner block that defeats the "MULTICALL" logic, and does get fresh SVs allocated each time:

my @subs = pairmap {
   {
      my $var = "$a is $b";
      sub { print "$var\n"; }
   }
} one => 1, two => 2, three => 3;

This bug only affects closures that are generated by the block but used afterwards. Lexical variables that are only used during the lifetime of the block's execution will take their individual values for each invocation, as normal.

uniqnum() on oversized bignums

Due to the way that uniqnum() compares numbers, it cannot distinguish differences between bignums (especially bigints) that are too large to fit in the native platform types. For example,

my $x = Math::BigInt->new( "1" x 100 );
my $y = $x + 1;
say for uniqnum( $x, $y );

Will print just the value of $x, believing that $y is a numerically- equivalent value. This bug does not affect uniqstr(), which will correctly observe that the two values stringify to different strings.
