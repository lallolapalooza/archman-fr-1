NOM

Lire::DlfStream - Interface avec le flux de données DLF

SYNTAXE

use Lire::DlfStore;
my $store = Lire::DlfStore->open( "mystore" );
my $dlf_stream = $store->open_dlf_stream( "www", "r" );
print "Les données commencent le ", scalar localtime $dlf_stream->start_time(), "\n";
print "Les données se terminent le   ", scalar localtime $dlf_stream->end_time(), "\n";
while ( my $dlf = $dlf_stream->read_dlf() ) {
  ...
}

DESCRIPTION

Cet objet encapsule un flux DLF.

nom

Retourne le nom du schéma du DlfStream.

mode()

Retourne le mode dans lequel le DlfStream a été ouvert.

sort_spec()

Retourne la spécification de tri définie sur le flux.

close()

Cette méthode doit être appelée lorsque le Lire::DlfStream n'est plus nécessaire, sinon le même DlfStream ne pourra pas être ouvert avant cela.

nrecords()

Retourne le nombre d'enregistrements DLF dans le flux.

start_time()

Retourne l'horodatage du plus ancien enregistrement DLF dans le flux, en secondes depuis l'époque.

end_time()

Retourne l'horodatage du plus récent enregistrement DLF dans le flux, en secondes depuis l'époque.

read_dlf()

Retourne une référence de hachage contenant le prochain enregistrement DLF dans le flux. Retourne undef une fois la fin du flux atteinte.

Cette méthode lèvera une exception si le DlfStream n'est pas ouvert en mode 'r' ou s'il y a une erreur lors de la lecture de l'enregistrement DLF.

read_dlf_aref()

Retourne le prochain enregistrement DLF dans le flux sous forme de référence de tableau. Les champs sont dans l'ordre spécifié par le schéma.

Cette méthode lèvera une exception si le DlfStream n'est pas ouvert en mode 'r' ou s'il y a une erreur lors de la lecture de l'enregistrement DLF.

write_dlf( $dlf, [ $link_ids ] )

Écrit les champs contenus dans la référence de hachage $dlf dans le flux DLF.

Cette méthode lèvera une exception en cas d'erreur lors de l'écriture de l'enregistrement DLF ou si le flux n'est pas ouvert en mode 'w'.

Le paramètre $link_ids est utilisé lorsque le schéma du flux est un Lire::DerivedSchema. Il doit s'agir d'une référence de tableau contenant les identifiants DLF des enregistrements qui sont liés à cet enregistrement.

clean( [ $time ] )

Cette méthode supprimera tous les enregistrements DLF plus anciens que $time. Si $time est omis, tous les enregistrements Dlf seront supprimés.
