NOM

Log::Message::Item - Objets de message pour Log::Message

SYNOPSIS

# Utilisé implicitement par Log::Message pour créer des objets Log::Message::Item
print "id du message : ",     $item->id;
print "message stocké : ",   $item->message;
print "quand c'est arrivé : ",     $item->when;
print "le message a été tagué : ",       $item->tag;
print "le niveau de sévérité était : ",  $item->level;
$item->remove;  # supprime l'élément de la pile sur laquelle il se trouve
# En plus de ces méthodes, vous pouvez également appeler les gestionnaires sur
# l'objet spécifiquement.
# Voir la page de manuel Log::Message::Handlers pour la documentation sur les
# gestionnaires disponibles par défaut et comment ajouter les vôtres

DESCRIPTION

Log::Message::Item est une classe qui génère des éléments de journal génériques. Ces éléments sont stockés sur une pile Log::Message. Consultez donc la page de manuel de Log::Message pour plus de détails sur la manière de les récupérer.

Vous ne devriez probablement pas créer vous-même de nouveaux éléments, mais utiliser le mécanisme de stockage fourni par Log::Message.

Cependant, les accesseurs et les gestionnaires sont intéressants si vous souhaitez affiner la manière dont vos messages sont traités.

Les accesseurs et méthodes sont décrits ci-dessous, les gestionnaires sont documentés dans la page de manuel de Log::Message::Handlers.

Méthodes et accesseurs

remove

Appeler remove supprimera l'objet de la pile sur laquelle il se trouvait, il n'apparaîtra donc plus dans les récupérations ultérieures de messages.

Vous pouvez cependant toujours appeler des accesseurs et des gestionnaires dessus, pour le traiter comme vous le souhaitez.

id

Retourne l'ID interne de l'élément. Cela peut être utile pour comparer, car l'ID est incrémenté à chaque création d'un nouvel élément. Par conséquent, un élément avec l'ID 4 doit avoir été enregistré avant un élément avec l'ID 9.

when

Retourne l'horodatage de l'enregistrement du message

message

Le message réel qui a été stocké

level

Le type de sévérité de ce message, ainsi que le nom du gestionnaire qui a été appelé lors de son enregistrement.

tag

Retourne le tag d'identification qui a été appliqué au message.

shortmess

Retourne l'équivalent d'un "Carp::shortmess" pour cet élément. Voir la page de manuel "Carp" pour plus de détails.

longmess

Retourne l'équivalent d'un "Carp::longmess" pour cet élément, qui est essentiellement une trace de pile. Voir la page de manuel "Carp" pour plus de détails.

parent

Retourne une référence à l'objet Log::Message qui a stocké cet élément. C'est utile si vous souhaitez avoir accès à la pile complète dans un gestionnaire.

VOIR AUSSI

Log::Message, Log::Message::Handlers, Log::Message::Config
