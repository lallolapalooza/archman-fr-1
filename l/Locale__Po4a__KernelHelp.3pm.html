NOM

Locale::Po4a::KernelHelp - convertir les aides de configuration du noyau des/vers les fichiers PO

DESCRIPTION

Locale::Po4a::KernelHelp est un module pour aider à la traduction de la documentation des options de configuration du noyau Linux vers d'autres langues [humaines].

STATUT DE CE MODULE

Ce module vient d'être écrit et nécessite davantage de tests. La plupart du travail nécessaire concernera les outils utilisés pour analyser ce fichier (et configurer le noyau), afin qu'ils acceptent de lire la documentation à partir d'un autre fichier (traduit).

VOIR AUSSI
