NOM

Lire::OldDlfAdapter - Module qui fait le pont avec les convertisseurs DLF anciens

SYNTAXE

my $converter = new Lire::OldDlfAdatper( "www",
                                         "/usr/libexec/lire/converters/combined2dlf" );

DESCRIPTION

Cette classe peut être utilisée pour intégrer les convertisseurs DLF anciens basés sur des scripts à la nouvelle API.

new( $schema, $script )

Le constructeur prend le schéma supporté par le script et le chemin vers le script qui implémente le convertisseur DLF.

script()

Retourne le chemin vers le script utilisé pour créer les enregistrements DLF.

VOIR AUSSI

Lire::DlfConverterProcess(3pm), Lire::DlfStore(3pm), Lire::ImportJob(3pm), Lire::PluginManager(3pm), Lire::DlfConverter(3pm)
