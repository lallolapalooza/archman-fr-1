NOM

Lire::Firewall::IpfilterDlfConverter - convertir les logs ipf (ipmon) en format DLF de pare-feu

DESCRIPTION

Lire::Firewall::IpfilterDlfConverter convertit les logs Ipfilter au format DLF de pare-feu. L'entrée pour ce convertisseur est le fichier de log syslog standard d'ipf tel que produit par ipmon. IP Filter est inclus avec FreeBSD, OpenBSD (jusqu'à 2.9) et certains autres OS.
