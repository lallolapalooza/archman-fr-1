NOM

Locale::Po4a::RubyDoc -- Convertit les données de documentation Ruby du/vers les fichiers PO

DESCRIPTION

Le projet po4a (PO for anything) a pour objectif de faciliter les traductions (et plus intéressant encore, la maintenance des traductions) à l'aide des outils gettext dans des domaines où ils n'étaient pas attendus, comme la documentation.

Locale::Po4a::RubyDoc est un module qui aide à la traduction de la documentation au format Ruby Document (RD) (un langage utilisé pour documenter Ruby) vers d'autres langues [humaines].

STATUT DE CE MODULE

Ce module a été testé avec succès sur des fichiers simples de documentation Ruby couvrant une bonne partie de la syntaxe du format.

Une limitation connue est qu'il ne parvient pas à reconnaître correctement la structure imbriquée de la documentation Ruby d'entrée : cela implique que lorsqu'un EnumListItem, par exemple, est composé de plus d'un Block, seul le premier Block est effectivement reconnu comme EnumListItem, tandis que les blocs suivants sont considérés comme de simples TextBlocks...

OPTIONS ACCEPTÉES PAR CE MODULE

Ce module prend en charge l'option suivante :

puredoc
Traite les fichiers entièrement constitués de texte au format Ruby Document (sans aucune ligne "=begin").

Par défaut, ce module ne traite que le texte au format Ruby Document situé entre les lignes "=begin" et "=end" (ignorant ainsi, entre autres, tout ce qui précède la première ligne "=begin").
