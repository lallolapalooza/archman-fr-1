NAME

Locale::RecodeData::EBCDIC_DK_NO - Routines de conversion pour EBCDIC_DK_NO

SYNOPSIS

Ce module est interne à libintl. Ne l'utilisez pas directement !

DESCRIPTION

Ce module contient les tables de conversion et les routines pour EBCDIC-DK-NO.

COMMENTS

Les observations suivantes ont été extraites du charmap original :

version: 1.0
repertoiremap: mnemonic,ds
 source: IBM 3270 Char Set Ref Ch 10, GA27-2837-9, April 1987

Note : les alias mentionnés ci-dessus ne sont pas forcément valides !
