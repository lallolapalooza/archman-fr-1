NAME

Locale::RecodeData::ATARI_ST_EURO - Routines de conversion pour ATARI-ST-EURO

SYNOPSIS

Ce module est interne à libintl. Ne pas l'utiliser directement !

DESCRIPTION

Ce module contient les tables de conversion et les routines pour ATARI-ST-EURO.

COMMENTS

Les remarques suivantes ont été extraites de la charmap originale :

version: 1.1
 source: Guido Flohr E<lt>guido.flohr@cantanea.comE<gt>
 alias ATARIST-EURO
 alias X-ATARIST-EURO
 alias X-ATARI-ST-EURO

Note : les alias listés ci-dessus ne sont pas nécessairement valides !
