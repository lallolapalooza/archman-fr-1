NOM

Locale::RecodeData - Classe de base abstraite pour les convertisseurs de jeux de caractères

SYNTAXE

# Pour la compatibilité avec Perl 5.005 et antérieur, vous devez
# *utiliser* le module avant d'en hériter !
use qw (Locale::RecodeData);
use base qw (Locale::RecodeData);

DESCRIPTION

Le module Locale::RecodeData sert de classe de base abstraite à tous les convertisseurs utilisés par Locale::Recode(3).

L'ajout de nouveaux modules de conversion n'est actuellement pas simple et vous devrez modifier les sources de certains modules à cette fin.

Tout d'abord, vous devez ajouter votre nouvelle classe de convertisseur à la liste trouvée dans Locale::_Conversions(3), afin que Locale::Recode(3) soit informé de sa présence. S'il existe des alias valides pour le codeset de votre convertisseur, vous devrez également modifier Locale::_Aliases(3).

Enfin, vous devez implémenter la routine de conversion (protégée) _recode(). Voir ci-dessous ("INTERFACE") pour les détails.

CONSTRUCTEUR

new (from => FROM_CODESET, to => TO_CODESET)
Le constructeur prend deux arguments (nommés) :
from
Le nom canonique du codeset source. Les alias ont déjà été résolus et le nom est converti en majuscules.
to
Le nom canonique du codeset destination. Les alias ont déjà été résolus et le nom est converti en majuscules.

Vous ne devez normalement pas implémenter le constructeur. Le constructeur par défaut implémenté ici stockera les codesets source et destination dans les membres protégés "_from" et "_to".

MÉTHODES

La classe implémente une méthode :

_getError
Retourne le membre (protégé) "_error".

INTERFACE

Les nouvelles classes de conversion doivent fournir l'interface suivante :

new (from => FROM_CODESET, to => TO_CODESET)
Le constructeur prend deux arguments (nommés) :
from
Le nom canonique du codeset source. Les alias ont déjà été résolus et le nom est converti en majuscules.
to
Le nom canonique du codeset destination. Les alias ont déjà été résolus et le nom est converti en majuscules.
_getError
Doit retourner la dernière erreur (sous forme de chaîne de caractères) ou false s'il n'y a pas eu d'erreur.

Cette méthode est déjà implémentée dans la classe de base.

_recode STRINGREF
Doit convertir l'argument "STRINGREF" en place. En cas d'échec, retourner false, et faire en sorte que la méthode _getError() retourne un message d'erreur informatif.
