NOM

Log::Log4perl::Layout::PatternLayout::Multiline

SYNOPSIS

use Log::Log4perl::Layout::PatternLayout::Multiline;
my $layout = Log::Log4perl::Layout::PatternLayout::Multiline->new(
    "%d (%F:%L)> %m");

DESCRIPTION

"Log::Log4perl::Layout::PatternLayout::Multiline" est une sous-classe de PatternLayout de Log4perl et est utile si vous envoyez des messages multilignes à vos appenders qui apparaissent comme

2007/04/04 23:59:01 This is
a message with
multiple lines

et vous voulez qu'ils apparaissent comme

2007/04/04 23:59:01 This is
2007/04/04 23:59:01 a message with
2007/04/04 23:59:01 multiple lines

à la place. Cette classe de layout divise simplement le message entrant en plusieurs morceaux séparés par des sauts de ligne et les rend avec PatternLayout comme s'ils étaient arrivés en morceaux séparés dès le départ.
