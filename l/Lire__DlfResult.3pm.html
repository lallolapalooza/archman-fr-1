NOM

Lire::DlfResult - interface avec le gestionnaire de base de données pour les données retournées

SYNTAXE

use Lire::DlfResult;

DESCRIPTION

new( $query, $sql )

C'est la méthode constructeur de la classe Lire::DlfResult. Elle prend un objet Lire::DlfQuery et une chaîne de requête SQL comme paramètres.

Cette méthode ne devrait jamais être appelée directement. Lire::DlfQuery retournera des instances appropriées de Lire::DlfResult par ses méthodes execute() et execute_summary().

dlf_query()

Retourne l'objet DlfQuery à partir duquel ce DlfResult a été obtenu.

next_row()

Retourne la "ligne suivante" d'une requête exécutée, c'est-à-dire, le premier enregistrement après le dernier, de manière incrémentale. Retourne une valeur indéfinie si appelée après que tous les enregistrements ont été retournés et échoue lors d'appels subséquents.

L'enregistrement est retourné sous forme de référence HASH.

next_row_aref()

Identique à next_row() sauf que l'enregistrement est retourné sous forme de référence ARRAY.
