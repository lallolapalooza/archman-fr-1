DESCRIPTION

Le module Locale::gettext_xs est l'interface de bas niveau pour la traduction de messages selon l'approche Uniforum qui est par exemple utilisée dans GNU gettext et Solaris de Sun.

Le module ne fonctionnera pas nécessairement sur votre système. Il dépend de la présence de bibliothèques partagées qui ne sont pas toujours disponibles. Les modules de plus haut niveau Locale::TextDomain::(3), resp. Locale::Messages(3) se rabattront sur une version pure Perl si l'amorçage de Locale::gettext_xs échoue.

L'interface de Locale::gettext_xs est en grande partie identique à la version pure Perl telle que décrite dans Locale::gettext_pp(3), voir cette page pour les détails. Les différences sont esquissées ci-dessous.

Locale::gettext_xs est compatible vers le bas avec Locale::gettext(3) de Phillip Vandry <vandry@Mlink.NET>. Vous pouvez l'utiliser comme remplacement pour Locale::gettext(3).

Veuillez noter que les noms de répertoire passés à la fonction bindtextdomain() sont automatiquement convertis des sémantiques Perl (slash comme séparateur de répertoire) vers les sémantiques locales (par exemple, le backslash pour MS-DOS).
