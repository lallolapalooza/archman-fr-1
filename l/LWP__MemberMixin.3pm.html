NOM

LWP::MemberMixin - Classe de mélange pour l'accès aux membres

SYNTAXE

package Foo;
use parent qw(LWP::MemberMixin);

DESCRIPTION

Une classe de mélange pour obtenir des méthodes qui fournissent un accès facile aux variables membres dans %$self. Idéalement, il devrait y avoir un meilleur support du langage Perl pour cela.

MÉTHODES

Une seule méthode est fournie :

_elem

_elem($elem [, $val])

Méthode interne pour obtenir/définir la valeur de la variable membre $elem. Si $val est présent, il est utilisé comme nouvelle valeur pour la variable membre. S'il n'est pas présent, la valeur actuelle n'est pas modifiée. Dans les deux cas, la valeur précédente de la variable membre est retournée.
