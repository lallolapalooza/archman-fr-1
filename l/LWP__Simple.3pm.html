LWP::Simple(3) Documentation Perl fournie par la communauté LWP::Simple(3)

NOM

LWP::Simple — interface procédurale simple à LWP

SYNTAXE

perl -MLWP::Simple -e 'getprint "http://www.sn.no"'
use LWP::Simple;
$content = get("http://www.sn.no/");
die "Couldn't get it!" unless defined $content;
if (mirror("http://www.sn.no/", "foo") == RC_NOT_MODIFIED) {
    ...
}
if (is_success(getprint("http://www.sn.no/"))) {
    ...
}

DESCRIPTION

Ce module est destiné aux personnes qui souhaitent une vue simplifiée de la bibliothèque libwww-perl. Il devrait également convenir aux lignes de commande. Si vous avez besoin de plus de contrôle ou d'accès aux champs d'en-tête des requêtes envoyées et des réponses reçues, vous devriez utiliser l'interface orientée objet complète fournie par le module LWP::UserAgent.

Le module exportera également l'objet LWP::UserAgent sous le nom $ua si vous le demandez explicitement.

L'agent utilisateur créé par ce module s'identifiera comme "LWP::Simple/#.##" et initialisera ses valeurs par défaut de proxy à partir de l'environnement (en appelant "$ua->env_proxy").

FONCTIONS

Les fonctions suivantes sont fournies (et exportées) par ce module :

get

my $res = get($url);

La fonction get() récupérera le document identifié par l'URL donnée et le retournera. Elle retourne "undef" en cas d'échec. L'argument $url peut être une chaîne de caractères ou une référence à un objet URI.

Vous ne pourrez pas examiner le code de réponse ou les en-têtes de réponse (comme "Content-Type") lorsque vous accéderez au web en utilisant cette fonction. Si vous avez besoin de ces informations, vous devriez utiliser l'interface OO complète (voir LWP::UserAgent).

head

my $res = head($url);

Récupère les en-têtes du document. Retourne les 5 valeurs suivantes en cas de succès : ($content_type, $document_length, $modified_time, $expires, $server)

Retourne une liste vide en cas d'échec. En contexte scalaire, retourne TRUE si succès.

getprint

my $code = getprint($url);

Récupère et affiche un document identifié par une URL. Le document est affiché sur le fichier par défaut sélectionné pour la sortie (normalement STDOUT) au fur et à mesure que les données sont reçues du réseau. Si la requête échoue, le code et le message d'état sont affichés sur STDERR. La valeur de retour est le code de réponse HTTP.

getstore

my $code = getstore($url, $file)
my $code = getstore($url, $filehandle)

Récupère un document identifié par une URL et le stocke dans le fichier. La valeur de retour est le code de réponse HTTP. Vous pouvez également passer un handle de fichier accessible en écriture ou similaire, comme un objet File::Temp.

mirror

my $code = mirror($url, $file);

Récupère et stocke un document identifié par une URL, en utilisant If-modified-since, et en vérifiant le Content-Length. Retourne le code de réponse HTTP.

FONCTIONS CLASSIFICATION

Les fonctions de classification HTTP::Status sont :

is_success

my $bool = is_success($rc);

Vrai si le code de réponse indique une requête réussie.

is_error

my $bool = is_error($rc)

Vrai si le code de réponse indique qu'une erreur s'est produite.

MISE EN GARDE

Notez que si vous utilisez à la fois LWP::Simple et le module très populaire CGI, vous pourriez importer une fonction "head" de chaque module, produisant un avertissement tel que "Prototype mismatch: sub main::head ($) vs none". Contournez ce problème en n'important simplement pas la fonction "head" de LWP::Simple, comme suit :

use LWP::Simple qw(!head);
use CGI qw(:standard);  # alors seul CGI.pm définit un head()

Alors, si vous avez besoin de la fonction "head" de LWP::Simple, vous pouvez simplement l'appeler comme LWP::Simple::head($url).
