ReportSchedule(3pm) Documentation de Lire pour LogReport ReportSchedule(3pm)

NOM

Lire::ReportSchedule - Objet représentant la génération d'un rapport périodique.

SYNTAXE

use Lire::ReportJob;
use Lire::ReportSchedule;
my $store = Lire::DlfStore->open( 'aStore' );
my $job = new Lire::ReportJob( "webServer" );
my $cfg = $store->get_report_config( 'daily_www_report' );
$job->add_schedule( new Lire::ReportSchedule( 'daily', $cfg );
$job->run( 'daily', $store );

DESCRIPTION

Les objets Lire::ReportSchedule, associés aux objets Lire::OutputJob, permettent de configurer toutes sortes de générations de rapports périodiques. Alors que Lire::OutputJob est utilisé pour représenter le formatage d'un rapport généré, Lire::ReportSchedule représente une telle génération. Il sera utilisé pour générer périodiquement un rapport XML dans un DlfStore en utilisant un fichier de configuration de rapport.

Les ReportSchedules groupés au sein d'un même ReportJob sont supposés générer des rapports compatibles en ce qui concerne la fusion. L'idée est que les rapports précédents générés dans un ReportJob (selon différents horaires) pourraient être utilisés comme source de données lorsque le DlfStore ne contient pas tous les enregistrements DLF pour la période entière. Par exemple, si vous ne conservez pas une année de DLF www dans votre magasin, vous pourriez quand même générer un rapport annuel en utilisant les rapports quotidiens générés au cours de l'année.

new( $period, $cfg );

Crée un nouveau Lire::ReportSchedule qui générera un rapport XML en utilisant le Lire::ReportConfig $cfg sur une période $period. $period doit être l'une des valeurs suivantes : 'hourly', 'daily', 'weekly', 'monthly' ou 'yearly'.

period()

Retourne la période de ce ReportSchedule.

period_range( [ $time ] )

Retourne les bornes de début et de fin de la période du planning qui inclut $time. (Par défaut, l'heure actuelle). La borne de fin est exclue de la période et la borne de début est incluse.

report_config( [ $new_cfg ] )

Retourne (et change éventuellement) l'objet Lire::ReportConfig à utiliser pour ce planning.

init_report_config( [ $time ] )

Retourne l'objet Lire::ReportConfig avec les filtres définis. Un FilterSpec aura été ajouté à chaque section de l'objet ReportConfig, qui restreindra le rapport à la période définie pour le planning. Les bornes de la période sont déterminées selon $time, qui est par défaut l'heure actuelle.

add_output_jobs( $job, ... )

Ajoute un ou plusieurs Lire::OutputJob à l'objet ReportSchedule.

output_jobs()

Retourne les Lire::OutputJobs liés à cet objet.

run( $store, $report_job, [$time] )

Génère un rapport XML et le sauvegarde dans le Lire::DlfStore $store. Le rapport sera généré soit en utilisant les DlfStreams, soit des rapports générés précédemment. La préférence est donnée à la génération du rapport en utilisant les données DLF. Pour plus de détails, consultez la documentation de find_report_source() dans Lire::DlfStore(3pm).

La période pour laquelle le rapport sera généré est déterminée en utilisant le paramètre $time qui est par défaut l'heure actuelle. Par exemple, un rapport 'daily' générera un rapport pour la journée entière (minuit-minuit basé sur le jour représenté par $time).

Une fois le rapport généré, tous les OutputJob enregistrés seront exécutés avec le nouveau rapport.
