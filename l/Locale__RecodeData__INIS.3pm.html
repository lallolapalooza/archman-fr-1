NOM

Locale::RecodeData::INIS - Routines de conversion pour INIS

SYNTAXE

Ce module est interne à libintl. Ne pas utiliser directement !

DESCRIPTION

Ce module est généré et contient les tables de conversion et les routines pour INIS.

COMMENTAIRES

Les commentaires suivants ont été extraits de la table de caractères originale :

version: 1.0
 source: ECMA registry
alias ISO-IR-49

Veuillez noter que les alias listés ci-dessus ne sont pas nécessairement valides !
