NOM

Log::Log4perl::JavaMap::RollingFileAppender - encapsule Log::Dispatch::FileRotate

SYNTAXE

DESCRIPTION

Ceci mappe le RollingFileAppender de log4j à Log::Dispatch::FileRotate par Mark Pfeiffer, <markpf@mlp-consulting.com.au>.

Les propriétés de configuration possibles pour log4j ConsoleAppender sont

File
Append      "true|false|1|0" par défaut=true
BufferedIO  "true|false|1|0" par défaut=false (c.-à-d. autoflush est activé)
MaxFileSize par défaut 10_000_000
MaxBackupIndex par défaut est 1

Les propriétés de configuration possibles pour Log::Dispatch::FileRotate sont

filename
mode  "write|append"
autoflush 0|1
size
max
