NOM

Locale::RecodeData::ISO_8859_8 - Routines de conversion pour ISO-8859-8

SYNTAXE

Ce module est interne à libintl. Ne pas utiliser directement !

DESCRIPTION

Ce module est généré et contient les tables et routines de conversion pour ISO-8859-8.

COMMENTAIRES

Les commentaires suivants ont été extraits de la table de caractères originale :

version: 1.0
 source: ECMA registry
alias ISO-IR-138
alias ISO_8859-8:1988
alias ISO_8859-8
alias HEBREW

Veuillez noter que les alias listés ci-dessus ne sont pas nécessairement valides !

TABLE DE CARACTERES

Le tableau suivant est trié dans le même ordre que la table de caractères originale. Tous les codes de caractères sont en hexadécimal. Veuillez lire 'ISO-10646' comme 'ISO-10646-UCS4'.

SYNOPSIS

    use Locale::RecodeData qw( :ISO_8859_8 );

DESCRIPTION

This module provides data for the Hebrew character set and the ISO-8859-8 standard.

It is used by the Locale::Recode module.

COMMENTS

    There are no specific comments in the source file.
