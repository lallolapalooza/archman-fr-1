NOM

Locale::Po4a::Ini - convertir des fichiers INI en fichiers PO et vice versa

DESCRIPTION

Locale::Po4a::Ini est un module qui aide à la traduction de fichiers INI vers d'autres langues [humaines].

Le module recherche les lignes du format suivant et extrait le texte entre guillemets :

identificateur="texte qui peut être traduit"

NOTE : Si le texte n'est pas entre guillemets, il sera ignoré.
