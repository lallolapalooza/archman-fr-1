NOM

Locale::RecodeData::CP1250 - Chemins de conversion pour CP1250

SYNOPIS

Cette section est interne à libintl. Ne pas l'utiliser directement !

DESCRIPTION

Cette section contient les tables de conversion et les routines pour CP1250.

COMMENTAIRES

Les commentaires suivants ont été extraits de la charmap originale :

version: 1.0
repertoiremap: mnemonic,ds
 source: UNICODE 1.0
alias MS-EE

Note : Les alias mentionnés ci-dessus ne sont pas nécessairement valides !

NOM

Locale::RecodeData

SYNTAXE

use Locale::RecodeData;

DESCRIPTION

Locale::RecodeData est un module qui contient des données pour la conversion des caractères dans les systèmes locaux.

COMMENTAIRES

Ce module est conçu pour gérer la conversion des caractères entre différentes codifications locales.
