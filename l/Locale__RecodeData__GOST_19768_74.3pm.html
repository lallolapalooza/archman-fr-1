NAME

SYNOPSIS

Ce module est interne et ne doit pas être utilisé directement !

DESCRIPTION

Ce module contient les tables de conversion et les routines pour GOST_19768_74.

COMMENTS

Les commentaires suivants ont été extraits de la charmap d'origine :

version: 1.0
 source: ECMA Registry
 alias ST_SEV_358-88
 alias ISO-IR-153

Note : Les alias mentionnés ci-dessus ne sont pas nécessairement valides !

NAME

Locale::RecodeData::GOST_19768_74 - GOST 19768-74 character set

SYNOPSIS

use Locale::RecodeData::GOST_19768_74;

DESCRIPTION

This module provides character set conversion for the GOST 19768-74 (also known as KOI8-R) character set. This is a Cyrillic character set that was widely used in Russia and other countries of the former Soviet Union.

The module defines the mapping between GOST 19768-74 and other character sets, allowing for conversion between them using the Locale::Recode module.

COMMENTS

The GOST 19768-74 standard is an 8-bit character encoding. It is similar to KOI8-R, but with some differences in character placement and the inclusion of certain characters.

This module is part of the libintl-perl package, which provides internationalization and localization support for Perl.
