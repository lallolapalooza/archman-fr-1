NOM

Locale::RecodeData::IBM875 - Routines de conversion pour IBM875

SYNTAXE

Ce module est interne à libintl. Ne l'utilisez pas directement !

DESCRIPTION

Ce module est généré et contient les tables et routines de conversion pour IBM875.

COMMENTAIRES

Les commentaires suivants ont été extraits de la map de caractères originale :

version: 1.0
 source: UNICODE 1.0
alias CP875
alias EBCDIC-GREEK

Veuillez noter que les alias listés ci-dessus ne sont pas nécessairement valides !
