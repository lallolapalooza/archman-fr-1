NOM

Locale::RecodeData::ATARI_ST - Routines de conversion pour ATARI-ST

SYNOPSIS

Ce module est interne à libintl. Ne pas utiliser directement !

DESCRIPTION

Ce module est généré et contient les tables et routines de conversion pour ATARI-ST.

COMMENTAIRES

Les commentaires suivants ont été extraits de la map de caractères originale :

alias X-ATARIST
alias X-ATARI-ST
