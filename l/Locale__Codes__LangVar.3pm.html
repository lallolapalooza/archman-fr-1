NOM

Locale::Codes::LangVar - module pour gérer les jeux de codes langvar

SYNOPIS

use Locale::Codes::LangVar;
$nom = code2langvar(CODE);
$code = langvar2code(NOM);
@codes   = all_langvar_codes();
@names   = all_langvar_names();

DESCRIPTION

Ce module fournit un accès aux jeux de codes langvar.

Veuillez vous référer au document Locale::Codes::Types pour une description des jeux de codes disponibles.

La plupart des routines acceptent un argument supplémentaire optionnel qui spécifie le jeu de codes à utiliser. Le jeu de codes peut être spécifié en utilisant le nom d'un jeu de codes, ou la constante perl spécifiée dans le document ci-dessus. Si non spécifié, le jeu de codes par défaut sera utilisé.

ROUTINES

Toutes les routines de ce module appellent la méthode appropriée dans le module Locale::Codes, en utilisant un objet de type : langvar. Veuillez vous référer à la documentation du module Locale::Codes pour les détails de chaque fonction.

Les fonctions suivantes sont exportées automatiquement :

code2langvar(CODE [,CODESET] [,'retired'])
Voir code2name dans Locale::Codes
code2langvars(CODE [,CODESET])
Voir code2names dans Locale::Codes
langvar2code(NAME [,CODESET] [,'retired'])
Voir name2code dans Locale::Codes
langvar_code2code(CODE ,CODESET ,CODESET2)
Voir code2code dans Locale::Codes
all_langvar_codes([CODESET] [,'retired'])
Voir all_codes dans Locale::Codes
all_langvar_names([CODESET] [,'retired'])
Voir all_names dans Locale::Codes

Les fonctions suivantes ne sont pas exportées et doivent être appelées avec leur nom de paquet complet :

Locale::Codes::Langvar::show_errors(FLAG)
Par défaut, les entrées invalides produiront des résultats vides, mais pas d'erreurs. En passant une valeur non nulle pour FLAG, des erreurs seront produites.

Voir show_errors dans Locale::Codes, mais notez que la valeur par défaut pour les modules non-OO est de NE PAS produire d'erreurs.

Locale::Codes::Langvar::rename_langvar(CODE ,NOUVEAU_NOM [,CODESET])
Voir rename_code dans Locale::Codes
Locale::Codes::Langvar::add_langvar(CODE ,NOM [,CODESET])
Voir add_code dans Locale::Codes
Locale::Codes::Langvar::delete_langvar(CODE [,CODESET])
Voir delete_code dans Locale::Codes
Locale::Codes::Langvar::add_langvar_alias(NOM ,NOUVEAU_NOM)
Voir add_alias dans Locale::Codes
Locale::Codes::Langvar::delete_langvar_alias(NOM)
Voir delete_alias dans Locale::Codes
Locale::Codes::Langvar::rename_langvar_code(CODE ,NOUVEAU_CODE [,CODESET])
Voir replace_code dans Locale::Codes
Locale::Codes::Langvar::add_langvar_code_alias(CODE ,NOUVEAU_CODE [,CODESET])
Voir add_code_alias dans Locale::Codes
Locale::Codes::Langvar::delete_langvar_code_alias(CODE [,CODESET])
Voir delete_code_alias dans Locale::Codes
