NOM

Locale::RecodeData::MAC_IS - Routines de conversion pour MAC-IS

SYNTAXE

Ce module est interne à libintl. Ne pas utiliser directement !

DESCRIPTION

Ce module est généré et contient les tables et routines de conversion pour MAC-IS.

COMMENTAIRES

Les commentaires suivants ont été extraits de la charmap originale :

version: 1.0

Veuillez noter que les alias listés ci-dessus ne sont pas nécessairement valides !

Locale::RecodeData::MAC_IS(3pm) — Perl 5.42.0 documentation

NOM

Locale::RecodeData::MAC_IS - Caractères pour le jeu de caractères Macintosh (version 1).

SYNOPIS

 package Locale::RecodeData::MAC_IS;
 use strict;
 use warnings;
 our $VERSION = '0.10';

DESCRIPTION

Ceci définit la table de caractères pour le jeu de caractères Macintosh (version 1). La table est définie dans le format utilisé par la bibliothèque Encode.

Le jeu de caractères Macintosh, également connu sous le nom de MAC_IS, est un ancien jeu de caractères de Mac OS.

COMMENTAIRES

Ce jeu de caractères est rarement utilisé aujourd'hui.
