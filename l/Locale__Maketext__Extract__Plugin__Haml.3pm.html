Locale::Maketext::Extract::Plugin::Haml(3) Documentation Perl fournie par l'utilisateur Locale::Maketext::Extract::Plugin::Haml(3)

NOM

Locale::Maketext::Extract::Plugin::Haml - Analyseur de format HAML

VERSION

version 1.00

SYNOPSIS

$plugin = Locale::Maketext::Extract::Plugin::Haml->new(
    $lexicon            # Un objet Locale::Maketext::Extract
    @file_types         # Optionnellement spécifier une liste de types de fichiers reconnus
)
$plugin->extract($filename,$filecontents);

DESCRIPTION

Extrait les chaînes à localiser des fichiers HAML.

NOM COURT DU PLUG-IN

haml

FORMATS VALIDES

Extrait les chaînes de la même manière que Locale::Maketext::Extract::Plugin::Perl, mais seulement celles qui se trouvent dans les composants "text" des fichiers HAML.

TYPES DE FICHIERS CONNUS

.haml
