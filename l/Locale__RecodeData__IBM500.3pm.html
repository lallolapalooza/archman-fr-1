NAME

Locale::RecodeData::IBM500 - Routines de conversion pour IBM500

SYNOPSIS

Ce module est interne à libintl. Ne l'utilisez pas directement !

DESCRIPTION

Ce module contient les tables de conversion et les routines pour IBM500.

COMMENTS

Les commentaires suivants ont été extraits du fichier charmap original :

version: 1.0
 source: IBM NLS RM Vol2 SE09-8002-01, March 1990
alias CP500
alias 500
alias 500V1
alias EBCDIC-CP-BE
alias EBCDIC-CP-CH

Note : Les alias mentionnés ci-dessus ne sont pas nécessairement valides !

NOM

Locale::RecodeData::IBM500.3pm

SYNOPIS

use Locale::RecodeData::IBM500;

DESCRIPTION

Locale::RecodeData::IBM500 est un module Perl qui fournit des données pour le jeu de caractères IBM500.

COMMENTAIRES

Ce module est conçu pour gérer l'encodage et le décodage des caractères pour le jeu de caractères IBM500.
