NOM

Locale::RecodeData::EBCDIC_FI_SE - Routines de conversion pour EBCDIC_FI_SE

SYNOPIS

Ce module est interne à libintl. Ne pas utiliser directement !

DESCRIPTION

Ce module est généré et contient les tables et routines de conversion pour EBCDIC-FI-SE.

COMMENTAIRES

Les commentaires suivants ont été extraits de la charmap d'origine :

version: 1.0
 source: IBM 3270 Char Set Ref Ch 10, GA27-2837-9, April 1987

Veuillez noter que les alias listés ci-dessus ne sont pas nécessairement valides !
