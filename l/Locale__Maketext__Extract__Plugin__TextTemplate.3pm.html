Locale::Maketext::Extract::Plugin::TextTemplate(3) Documentation Perl Contribuée par l'Utilisateur Locale::Maketext::Extract::Plugin::TextTemplate(3)

NOM

Locale::Maketext::Extract::Plugin::TextTemplate - Analyseur de format Text::Template

VERSION

version 1.00

SYNOPSIS

$plugin = Locale::Maketext::Extract::Plugin::TextTemplate->new(
    $lexicon            # Un objet Locale::Maketext::Extract
    @file_types         # Optionnellement spécifier une liste de types de fichiers reconnus
)
$plugin->extract($filename,$filecontents);

DESCRIPTION

Extrait les chaînes à localiser des fichiers Text::Template

NOM COURT DU PLUGIN

text

FORMATS VALIDES

Les phrases entre STARTxxx et ENDxxx sont extraites individuellement.

TYPES DE FICHIERS CONNUS

Tous types de fichiers

VOIR AUSSI

xgettext.pl
pour extraire les chaînes traduisibles des systèmes de templates courants et des fichiers sources Perl.
