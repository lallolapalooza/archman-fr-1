NOM

Locale::RecodeData::INIS_CYRILLIC - Routines de conversion pour INIS_CYRILLIC

SYNOPSIS

Ce module est interne à libintl. Ne l'utilisez pas directement !

DESCRIPTION

Ce module est généré et contient les tables de conversion et les routines pour INIS-CYRILLIC.

COMMENTAIRES

Les remarques suivantes ont été extraites du charmap d'origine :

version: 1.0
 source: ECMA registry
alias ISO-IR-51

Note : Les alias mentionnés ci-dessus ne sont pas nécessairement valides !
