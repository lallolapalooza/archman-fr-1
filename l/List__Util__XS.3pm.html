NOM

List::Util::XS - Indique si List::Util a été compilé avec un compilateur C

SYNTAXE

use List::Util::XS 1.20;

DESCRIPTION

"List::Util::XS" peut être utilisé comme une dépendance pour s'assurer que List::Util a été installé à l'aide d'un compilateur C et que la version XS est installée.

Lors de l'installation, $List::Util::XS::VERSION sera défini à "undef" si le XS n'a pas été compilé.

À partir de la version 1.23_03, Scalar-List-Util utilise **toujours** l'implémentation XS, mais pour des raisons de compatibilité ascendante, nous expédions toujours le module "List::Util::XS" qui charge simplement "List::Util".

VOIR AUSSI

Scalar::Util, List::Util, List::MoreUtils
