NOM

Locale::RecodeData::CP1253 - Routines de conversion pour CP1253

SYNTAXE

Ce module est interne à libintl. Ne pas l'utiliser directement !

DESCRIPTION

Ce module est généré et contient les tables et routines de conversion pour CP1253.

COMMENTAIRES

Les commentaires suivants ont été extraits de la table de caractères originale :

version: 1.0
repertoiremap: mnemonic,ds
 source: UNICODE 1.0
alias MS-GREEK

Veuillez noter que les alias listés ci-dessus ne sont pas nécessairement valides !
