LWP::Debug(3) Documentation Perl fournie par l'utilisateur LWP::Debug(3)

NOM

LWP::Debug - obsolète

DESCRIPTION

Ce module est obsolète. Veuillez consulter LWP::ConsoleLogger pour vos besoins de débogage.

LWP::Debug était utilisé pour fournir des facilités de traçage, mais elles ne sont plus utilisées par LWP. Le code de ce module est conservé (non documenté) afin que le code tiers qui utilise les anciennes interfaces continue de fonctionner.

Une fonctionnalité utile que LWP::Debug fournissait (d'une manière imprécise et problématique) était la surveillance du trafic réseau. La section suivante fournit quelques indications sur les remplacements recommandés.

Surveillance du trafic réseau

La meilleure façon de surveiller le trafic réseau généré par LWP est d'utiliser un programme de surveillance TCP externe. Le programme WireShark http://www.wireshark.org/ est fortement recommandé pour cela.

Une autre approche consiste à utiliser un serveur proxy HTTP de débogage et à faire en sorte que LWP redirige tout son trafic via celui-ci. Appelez "$ua->proxy" pour le configurer, puis utilisez LWP comme d'habitude.

Pour des besoins de surveillance moins précis, il suffit de mettre en place quelques gestionnaires simples. L'exemple suivant configure des gestionnaires pour afficher les objets de requête et de réponse qui transitent par LWP :

use LWP::UserAgent;
$ua = LWP::UserAgent->new;
$ua->default_header('Accept-Encoding' => scalar HTTP::Message::decodable());
$ua->add_handler("request_send",  sub { shift->dump; return });
$ua->add_handler("response_done", sub { shift->dump; return });
$ua->get("http://www.example.com");

VOIR AUSSI

LWP::ConsoleLogger, LWP::ConsoleLogger::Everywhere, LWP::UserAgent
