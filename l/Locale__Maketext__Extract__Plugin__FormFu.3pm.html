NOM

Locale::Maketext::Extract::Plugin::FormFu - analyseur de format FormFu

VERSION

version 1.00

SYNOPSIS

$plugin = Locale::Maketext::Extract::Plugin::FormFu->new(
    $lexicon            # Un objet Locale::Maketext::Extract
    @file_types         # Optionnellement, spécifier une liste de types de fichiers reconnus
)
$plugin->extract($filename,$filecontents);

DESCRIPTION

HTML::FormFu utilise un fichier de configuration pour générer des formulaires, avec un support intégré pour la localisation des erreurs, des étiquettes, etc.

NOM COURT DU PLUGIN

formfu

FORMATS VALIDES

Nous extrayons le texte après toute clé se terminant par "_loc" :

content_loc: ce sont les chaînes
message_loc: ['Taille maximale [_1]', 10]

TYPES DE FICHIERS CONNUS

.yaml
.yml
.conf

REQUIERT

YAML

NOTES

La documentation du module YAML la décrit comme du code alpha. Elle n'est pas aussi tolérante aux erreurs que YAML::Syck. Cependant, parce qu'elle est en pur Perl, il est facile de s'y accrocher.

Je l'ai vue entrer dans des boucles sans fin, donc si xgettext.pl se bloque, essayez de le relancer avec "--verbose --verbose" (deux fois) activé, afin de pouvoir voir si la faute incombe à YAML. Si c'est le cas, corrigez le fichier source YAML ou utilisez les types de fichiers pour exclure ce fichier.
