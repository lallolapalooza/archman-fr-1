NOM

Lire::Section - Interface avec le contenu de l'élément de la section.

SYNOPIS

my $section = Lire::ReportParser::ReportBuilder( "report.xml" );
foreach my $s ( $report->sections() ) {
    print "Section : '", $s->title(), "' a ", scalar $s->subreports(),
        " sous-rapports en elle\n";
}

DESCRIPTION

Cette classe offre une API aux éléments de section d'un rapport Lire.

CONSTRUCTEUR

new( [$titre] )

Crée une nouvelle Lire::Report::Section. Le titre de la section sera défini sur le paramètre $titre s'il est présent.

MÉTHODES D'OBJET

title( [$titre] )

Retourne le titre de la section, si elle en a un. Le titre de la section sera modifié par $titre si ce paramètre est défini.

description( [$description] )

Retourne la description de cette section. La description est codée en XML DocBook.

Si le paramètre $description est défini, cette méthode définira la description de cette section à cette nouvelle valeur. Si le paramètre $description est undef, cette description sera supprimée.

sous-rapports()

Retourne les sous-rapports inclus dans cette section. Ce sera un tableau d'objets Lire::Report::Subreport.

add_subreport( $subreport )

Ajoute un sous-rapport à ce rapport. Le paramètre $subreport doit être un objet Lire::Report::Subreport.

subreports_by_type( $type )

Retourne tous les sous-rapports de cette section du type $type. Le type du sous-rapport est l'identifiant de la spécification de rapport utilisée pour calculer les rapports. Les sous-rapports sont retournés sous forme d'un tableau d'objets Lire::Report::Subreport.
