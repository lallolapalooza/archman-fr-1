NOM

Locale::Po4a::Wml - convertir des documents WML (langage de balisage web) depuis/vers des fichiers PO

DESCRIPTION

L'objectif du projet po4a (PO pour tout) est de faciliter les traductions (et plus intéressant encore, la maintenance des traductions) en utilisant les outils gettext dans des domaines où ils n'étaient pas attendus, comme la documentation.

Locale::Po4a::Wml est un module pour aider à la traduction des documents WML dans d'autres langues [humaines]. Ne confondez pas le WML dont nous parlons ici (langage de balisage web) et la camelote WAP utilisée sur les téléphones portables.

Notez que ce module s'appuie sur le module Locale::Po4a::Xhtml, qui lui-même s'appuie sur le module Locale::Po4a::Xml. Cela signifie que toutes les balises pour les expressions de pages web sont supposées être écrites en syntaxe XHTML.

OPTIONS ACCEPTÉES PAR CE MODULE

AUCUNE.

STATUT DE CE MODULE

Ce module fonctionne pour certains documents simples, mais il est encore jeune. Actuellement, le plus gros problème du module est probablement qu'il ne peut pas gérer les documents contenant des balises en ligne non-XML telles que <email "foo@example.org">, qui sont souvent définies dans le WML. Des améliorations seront ajoutées dans les futures versions.
