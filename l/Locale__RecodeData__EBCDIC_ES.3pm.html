NOM

Locale::RecodeData::EBCDIC_ES - Routines de conversion pour EBCDIC_ES

SYNTAXE

Ce module est interne à libintl. Ne pas l'utiliser directement !

DESCRIPTION

Ce module est généré et contient les tables et routines de conversion pour EBCDIC_ES.

COMMENTAIRES

Les commentaires suivants ont été extraits de la charmap d'origine :

version: 1.0
 source: IBM 3270 Char Set Ref Ch 10, GA27-2837-9, April 1987

Veuillez noter que les alias listés ci-dessus ne sont pas nécessairement valides !
