NAME

Lire::ReportConfig - API pour la configuration des rapports

SYNOPSIS

use Lire::ReportConfig;
my $templates = Lire::ReportConfig->templates();
if ( Lire::ReportConfig->has_template( 'www_default' ) ) {
    my $report_cfg = Lire::ReportConfig->template( 'www_default' )->as_value();
    my $report = $report_cfg->generate_report( $report );
}

DESCRIPTION

Cette classe représente les configurations de rapports. Les configurations de rapports sont stockées sous forme de fichiers de spécification de modèles utilisant le type de configuration Lire::Report::ReportSpec.

MODÈLES

Les modèles de rapports sont des fichiers de spécification de modèles trouvés dans les répertoires spécifiés par la variable de configuration 'lr_templates_path'.

templates()

Retourne une référence à un tableau des noms de tous les modèles définis.

has_template( $name )

Retourne vrai s'il existe un modèle nommé $name disponible.

template( $name )

Retourne un objet Lire::Config::Object qui définit le modèle de rapport Lire::ReportConfig nommé $name. Sa méthode spec() retourne un objet Lire::Config::ReportSpec et sa méthode as_value() instancie un objet Lire::ReportConfig.

CONSTRUCTEURS

new()

Crée un objet Lire::ReportConfig vide.

L'objet de configuration de rapport créé n'a aucune section, aucun rapport ni aucun filtre spécifié.

new_from_file( $superservice, $report_cfg )

Crée un objet de configuration de rapport pour le superservice $superservice basé sur le fichier de configuration de rapport $report_cfg.

MÉTHODES D'OBJET

filename( [ $new_filename ] )

Retourne (et change optionnellement) le nom du fichier à partir duquel ce ReportConfig a été chargé. Retourne undef si le ReportConfig n'a pas été chargé depuis un fichier.

title( [ $new_title ] )

Retourne (et change optionnellement) le titre qui sera attribué au rapport.

schemas()

Retourne une référence à un tableau des noms de schémas utilisés dans ce rapport.

sections()

Retourne cette configuration de rapport sous forme d'un tableau d'objets Lire::Section.

add_section( $section )

Ajoute une section à cette configuration de rapport. Le paramètre $section doit être un objet Lire::ReportSection.

merge_filters()

Appeler cette méthode garantira que toutes les spécifications de rapport prennent en compte leur spécification de filtre de section.

Cette méthode modifiera toutes les spécifications de rapport. Après avoir appelé cette méthode, leur représentation objet ne sera pas identique à celle de la spécification XML du rapport.

print( [$fh] )

Imprime la configuration de rapport dans le descripteur de fichier de sortie $fh. Si le descripteur de fichier $fh n'est pas spécifié, la configuration de rapport sera imprimée sur STDOUT.

create_report( $timespan_start, $timespan_end )

Retourne un objet Lire::Report basé sur cette configuration de rapport. Les attributs $timespan_start et $timespan_end seront utilisés pour initialiser l'objet Report.

Utilisé lors de la génération d'un rapport XML à partir d'une source DLF et lors de la fusion de rapports XML.

Le travail réel est délégué à Lire::ReportSection::create_report_section().

create_analyser_streams( $store )

Cette méthode garantira qu'un DlfStream est disponible dans le Lire::DlfStore $store pour chaque schéma utilisé par cette configuration de rapport. Le flux sera créé en exécutant le premier analyseur capable de générer le schéma avec les flux existants.

generate_report( $store )

Génère un Lire::Report à partir de cette configuration de rapport. Le rapport est calculé en utilisant les flux dans le Lire::DlfStore $store.

merge_report_files( @report_files )

Génère un nouveau Lire::Report basé sur cette configuration de rapport en fusionnant des rapports XML. Chaque spécification de rapport contenue dans la configuration sera le résultat de la fusion de tous les sous-rapports ayant le même id.

VOIR AUSSI
