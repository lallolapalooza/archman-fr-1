NOM

Locale::RecodeData::ISO_5427_EXT - Routines de conversion pour ISO_5427_EXT

SYNOPIS

Ce module est interne à libintl. Ne l'utilisez pas directement !

DESCRIPTION

Ce module est généré et contient les tables et routines de conversion pour ISO_5427-EXT.

COMMENTAIRES

Les commentaires suivants ont été extraits de la map de caractères originale :

version: 1.0
repertoiremap: mnemonic,ds
 source: ECMA registry
alias ISO-IR-54
alias ISO_5427:1981

Veuillez noter que les alias listés ci-dessus ne sont pas nécessairement valides !
