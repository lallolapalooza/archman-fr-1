NOM

Lire::Config::Dictionary - Objet valeur Dictionnaire.

SYNTAXE

use Lire::Config::Dictionary;

DESCRIPTION

Paramètre de configuration qui contient un ensemble de paramètres nommés et d'autres valeurs accessibles par nom.

Cette valeur est utilisée pour les ensembles de configuration de haut niveau.

est_defini( $nom )

Retourne vrai si le paramètre $nom a été défini dans ce dictionnaire.

obtenir( $nom )

Retourne l'objet Valeur pour le sous-paramètre $nom. Une exception sera levée s'il n'y a pas de sous-paramètre nommé $nom.

définir( $valeur )

Définit un paramètre dans ce dictionnaire.
