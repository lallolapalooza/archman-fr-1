NOM

Locale::Maketext::Extract::Plugin::Generic - Analyseur de modèle générique

VERSION

version 1.00

SYNTAXE

$plugin = Locale::Maketext::Extract::Plugin::Generic->new(
    $lexicon            # Un objet Locale::Maketext::Extract
    @file_types         # Optionnellement, spécifier une liste de types de fichiers reconnus
)
$plugin->extract($filename,$filecontents);

DESCRIPTION

Extrait les chaînes à localiser à partir de modèles génériques.

NOM_COURT_DU_PLUGIN

generic

FORMATS_VALIDES

Les chaînes à l'intérieur de {{...}} sont extraites.

TYPES_DE_FICHIERS_CONNUS

Tous les types de fichiers

VOIR_AUSSI

xgettext.pl
pour l'extraction de chaînes traduisibles à partir de systèmes de modèles courants et de fichiers sources perl.
