NOM

Locale::RecodeData::ISO_8859_13 - Routines de conversion pour ISO-8859-13

SYNOPIS

Ce module est interne à libintl. Ne pas utiliser directement !

DESCRIPTION

Ce module est généré et contient les tables de conversion et les routines pour ISO-8859-13.

COMMENTAIRES

Les commentaires suivants ont été extraits de la charmap d'origine :

généré automatiquement depuis charDB
alias ISO-IR-179
alias LATIN7
alias L7

Veuillez noter que les alias listés ci-dessus ne sont pas forcément valides !

NAME

Locale::RecodeData::ISO_8859_13 - ISO 8859-13 character set definitions for Locale::Recode(3).

SYNOPSIS

    use Locale::RecodeData::ISO_8859_13;
    # No exported functions or variables.

DESCRIPTION

This module provides the character set definitions for ISO 8859-13.

It is used internally by Locale::Recode(3). You should not use it directly.
