NOM

Locale::RecodeData::IEC_P27_1 - Routines de conversion pour IEC_P27_1

SYNOPIS

Ce module est interne à libintl. Ne pas l'utiliser directement !

DESCRIPTION

Ce module est généré et contient les tables et routines de conversion pour IEC_P27-1.

COMMENTAIRES

Les commentaires suivants ont été extraits de la charmap originale :

version: 1.0
 source: ECMA registry
alias ISO-IR-143

Veuillez noter que les alias listés ci-dessus ne sont pas nécessairement valides !

NAME

Locale::RecodeData::IEC_P27_1 - Recode module for IEC P27-1 characters

SYNOPSIS

    use Locale::Recode::register "IEC_P27_1";

DESCRIPTION

This module provides character recoding for the International Electrotechnical Commission standard IEC P27-1.

IEC P27-1 defines a character set for electronic data interchange.

COMMENTS

This module is part of the libintl-perl package.
