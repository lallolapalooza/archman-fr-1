NOM

Lire::Test::HashConfig - Implémentation basique de Lire::Config

SYNTAXE

use base qw/Test::Unit::TestCase/;
use Lire::Test::HashConfig;
sub set_up {
    my $self = $_[0];
    $self->{'old_config'} = $Lire::Config::SINGLETON;
    $Lire::Config::SINGLETON = new Lire::Test::HashConfig( {
                                                            'lr_archive' => undef,
                                                           } );
}

DESCRIPTION

Ceci est un module simple destiné à être utilisé depuis la méthode set_up() dans les tests unitaires. Il peut être utilisé pour créer une configuration « bidon » afin de fournir des valeurs connues au module testé.

La méthode new() accepte une référence de hachage contenant la variable de configuration.

Les seules méthodes de l'interface Lire::Config implémentées sont get() et config_spec(). La méthode get() retournera exactement les valeurs fournies dans la méthode new(). Essayer d'obtenir d'autres variables de configuration lèvera une exception « Pas de telle variable de configuration » (comme si la variable n'était pas définie dans le schéma).

La méthode config_spec() retournera l'objet associé à la clé '_lr_config_spec'. Elle lèvera une exception si cette clé n'a pas été définie.

Toutes les autres méthodes de Lire::Config lèveront une exception « Méthode non implémentée ».

VOIR AUSSI

Lire::Config(3pm), Test::Unit::TestCase(3pm)
