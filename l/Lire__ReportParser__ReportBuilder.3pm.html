NOM

Lire::ReportParser::ReportBuilder - Crée des objets Lire::Report à partir de fichiers XML

SYNOPIS

use Lire::ReportParser::ReportBuilder;
my $parser = new Lire::ReportParser::ReportBuilder;
my $report = $parser->parsefile( "report.xml" );

DESCRIPTION

Il s'agit d'une sous-classe de Lire::ReportParser qui crée une représentation objet d'un rapport Lire contenu dans un fichier XML.
