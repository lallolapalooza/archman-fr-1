Locale__Po4a__Org(3pm)

Paquet: po4a

Licences: GPL

LOCALE::PO4A::ORG.3PM(1) Documentation Perl fournie par l'utilisateur LOCALE::PO4A::ORG.3PM(1)

NOM

Locale::Po4a::Org - convertir des documents Org depuis/vers des fichiers PO.

SYNTAXE

[type:org] /chemin/vers/master.org              \
       $lang:/chemin/vers/traduction.$lang.org \
       opt:"                                \
       --option skip_keywords='             \
           include                          \
           export_file_name                 \
           link'                            \
       --option skip_properties='           \
           copying                          \
           NOBLOCKING                       \
           ORDERED'"

DESCRIPTION

L'objectif du projet po4a (PO pour tout) est de faciliter les traductions (et plus intéressant encore, la maintenance des traductions) en utilisant les outils gettext dans des domaines où ils n'étaient pas attendus, comme la documentation.

"Locale::Po4a::Org" est un module pour aider à la traduction de la documentation au format Org, utilisée par le mode Org https://orgmode.org/.

CONFIGURATION

skip_keywords
Liste de mots-clés séparés par des espaces qui ne seront pas traduits.
skip_properties
Liste de propriétés séparées par des espaces qui ne seront pas traduites.
skip_heading
Si ceci a une valeur vraie, ignorer la traduction des titres. Lorsque votre traduction est convertie au format Texinfo, la traduction des titres peut rendre les noms de nœuds bizarres. Cette option empêche cela.

STATUT DE CE MODULE

Ce module est à un stade précoce de développement. Il a été testé avec succès sur des fichiers Org simples, tels que le guide compact du mode Org https://orgmode.org/guide/. Cependant, il ne prend pas en charge la syntaxe Org complète https://orgmode.org/worg/org-syntax.html ; les notes de bas de page et les listes simples imbriquées ne peuvent pas être analysées actuellement, par exemple.
