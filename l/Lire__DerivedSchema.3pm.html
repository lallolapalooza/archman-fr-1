NOM

Lire::DerivedSchema - Définit un schéma pour lequel les enregistrements sont dérivés d'un autre schéma

SYNOPSIS

my $schema = Lire::DlfSchema::load_schema( 'www-user_session' );
my $fields = $schema->fields();

DESCRIPTION

Un Lire::DerivedSchema définit un schéma pour lequel les enregistrements sont calculés par un analyseur utilisant les enregistrements d'un schéma de base. Un exemple de schéma dérivé est le schéma www-user_session qui calcule les informations de session à partir des enregistrements du schéma www.

base()

Retourne l'objet Lire::DlfSchema dont les enregistrements de ce schéma sont dérivés.

peut_joindre_schema( $schema )

Retourne vrai si $schema peut être joint à ce schéma. Pour un DerivedSchema, cela ne sera vrai que lorsque $schema est un ExtendedSchema de ce schéma ou de la base de ce schéma. Il est également possible de joindre le DerivedSchema avec sa base.
