List::MoreUtils::XS(3) Documentation Perl Contribuée par l'Utilisateur List::MoreUtils::XS(3)

NOM

List::MoreUtils::XS - Fournit des fonctions compilées de List::MoreUtils

SYNTAXE

use List::MoreUtils::XS (); # n'exporte rien
use List::MoreUtils ':all'; # requis pour importer des fonctions
my @procs = get_process_stats->fetchall_array;
# trier par ppid, puis par pid
qsort { $a->[3] <=> $b->[3] or $a->[2] <=> $b->[2] } @procs;
while( @procs ) {
    my $proc = shift @procs;
    my @children = equal_range { $_->[3] <=> $proc->[2] } @procs;
}
my @left = qw(ceci est un test);
my @right = qw(ceci est aussi un test);
my %rlinfo = listcmp @left, @right;
# sur des listes non triées
my $i = firstidx { $_ eq 'ouais' } @foo;
# sur des listes triées - toujours le premier, mais pourrait ne pas être 'ouais'
my $j = lower_bound { $_ cmp 'ouais' } @bar;
# sur des listes triées - n'importe lequel des éléments correspondants, est sûrement 'ouais'
my $k = bsearchidx { $_ cmp 'ouais' } @bar;

DESCRIPTION

List::MoreUtils::XS est un backend pour List::MoreUtils. Même s'il est possible (en raison des souhaits des utilisateurs) qu'il soit pratiquement indépendant de List::MoreUtils, il dépend techniquement de "List::MoreUtils". Puisqu'il ne s'agit que d'un backend, l'API n'est pas publique et peut changer sans aucun avertissement.
