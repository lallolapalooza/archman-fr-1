NOM

Log::Message::Config - Options de configuration pour Log::Message

SYNTAXE

# Ce module est implicitement utilisé par Log::Message pour créer une configuration
# qu'il utilise pour enregistrer les messages.
# Pour les options que vous pouvez passer, voir la méthode C<Log::Message new()>.
# Ci-dessous un exemple de fichier de configuration que vous pourriez utiliser
# les commentaires sont indiqués par un seul '#'
# utiliser une pile partagée, ou avoir une instance privée ?
# si aucune n'est fournie, définie à '0',
private = 1
# ne pas être verbeux
verbose = 0
# balise par défaut à définir sur les nouveaux éléments
# si aucune n'est fournie, définie à 'NONE'
tag = UNE BALISE QUELCONQUE
# niveau par défaut pour gérer les éléments
# si aucun n'est fourni, défini à 'log'
level = carp
# fichiers supplémentaires à inclure
# si aucun n'est fourni, aucun fichier n'est inclus automatiquement
include = mylib.pl
include = ../my/other/lib.pl
# supprimer automatiquement les éléments
# lorsque vous les récupérez de la pile ?
# si aucun n'est fourni, défini à '0'
remove = 1
# récupérer les erreurs dans l'ordre chronologique, ou pas ?
# si aucun n'est fourni, défini à '1'
chrono = 0

DESCRIPTION

Log::Message::Config fournit un objet de configuration standardisé pour les objets Log::Message.

Il peut lire les options comme arguments perl, ou comme un fichier de configuration. Voir la page de manuel Log::Message pour plus d'informations sur les arguments valides, et voir la Syntaxe pour un exemple de fichier de configuration que vous pouvez utiliser.

VOIR AUSSI

Log::Message, Log::Message::Item, Log::Message::Handlers
