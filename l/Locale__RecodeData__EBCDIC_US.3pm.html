NOM

Locale::RecodeData::EBCDIC_US - Routines de conversion pour EBCDIC_US

SYNOPSIS

Ce module est interne à libintl. Ne l'utilisez pas directement !

DESCRIPTION

Ce module contient la table de conversion et les routines pour EBCDIC-US.

COMMENTAIRES

Les remarques suivantes ont été extraites de la charmap originale :

version : 1.0
 source : IBM 3270 Char Set Ref Ch 10, GA27-2837-9, avril 1987

Veuillez noter que les alias mentionnés ci-dessus ne sont pas nécessairement valides !
