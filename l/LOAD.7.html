NOM

LOAD - charger un fichier de bibliothèque partagée

SYNTAXE

LOAD 'nom_fichier'

DESCRIPTION

Cette commande charge un fichier de bibliothèque partagée dans l'espace d'adressage du serveur PostgreSQL. Si le fichier a déjà été chargé, la commande ne fait rien. Les fichiers de bibliothèques partagées contenant des fonctions C sont automatiquement chargés chaque fois que l'une de leurs fonctions est appelée. Par conséquent, un LOAD explicite n'est généralement nécessaire que pour charger une bibliothèque qui modifie le comportement du serveur par le biais de « hooks » plutôt que de fournir un ensemble de fonctions.

Le nom du fichier de bibliothèque est généralement donné comme un simple nom de fichier, qui est recherché dans le chemin de recherche des bibliothèques du serveur (défini par dynamic_library_path). Alternativement, il peut être donné sous forme de chemin d'accès complet. Dans les deux cas, l'extension de fichier de bibliothèque partagée standard de la plateforme peut être omise. Voir la section 36.10.1 pour plus d'informations sur ce sujet.

Les non-superutilisateurs ne peuvent appliquer LOAD qu'aux fichiers de bibliothèques situés dans $libdir/plugins/ — le nom_fichier spécifié doit commencer exactement par cette chaîne. (Il incombe à l'administrateur de la base de données de s'assurer que seules des bibliothèques « sûres » y sont installées.)

COMPATIBILITÉ

LOAD est une extension PostgreSQL.
