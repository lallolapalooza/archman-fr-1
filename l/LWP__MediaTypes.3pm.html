LWP::MediaTypes(3) Documentation Perl contribuée par l'utilisateur LWP::MediaTypes(3)

NOM

LWP::MediaTypes - deviner le type média pour un fichier ou une URL

SYNTAXE

use LWP::MediaTypes qw(guess_media_type);
$type = guess_media_type("/tmp/foo.gif");

DESCRIPTION

Ce module fournit des fonctions pour gérer les types et les encodages médias (également connus sous le nom de types MIME). La correspondance entre les extensions de fichiers et les types médias est définie dans le fichier media.types. Si le fichier ~/.media.types existe, il est utilisé à la place. Pour la compatibilité ascendante, nous chercherons également dans ~/.mime.types.

Les fonctions suivantes sont exportées par défaut :

guess_media_type( $filename )
guess_media_type( $uri )
guess_media_type( $filename_or_object, $header_to_modify )
Cette fonction essaie de deviner le type média et l'encodage pour un fichier ou des objets qui supportent une méthode "path" ou "filename", par exemple les objets URI ou File::Temp. Lorsqu'un objet ne supporte aucune de ces méthodes, il sera stringifié pour déterminer le nom du fichier. Elle renvoie le type de contenu, qui est une chaîne comme "text/html". En contexte de tableau, elle renvoie également tous les encodages de contenu appliqués (dans l'ordre utilisé pour encoder le fichier). Vous pouvez passer une référence d'objet URI, au lieu du nom du fichier.

Si le type ne peut pas être déduit en regardant le nom du fichier, guess_media_type() laissera l'opérateur Perl "-T" jeter un œil. Si cela fonctionne (et "-T" renvoie une valeur VRAIE) alors nous renvoyons text/plain comme type, sinon nous renvoyons application/octet-stream comme type.

L'argument optionnel, le deuxième, devrait être une référence vers un objet HTTP::Headers ou tout objet qui implémente la méthode $obj->header de manière similaire. Lorsqu'il est présent, les valeurs de 'Content-Type' et 'Content-Encoding' seront définies pour cet en-tête.

media_suffix( $type, ... )
Cette fonction renverra tous les suffixes qui peuvent être utilisés pour désigner le ou les types médias spécifiés. Des types génériques peuvent être utilisés. En contexte scalaire, elle renverra le premier suffixe trouvé. Exemples : 
@suffixes = media_suffix('image/*', 'audio/basic');
$suffix = media_suffix('text/html');

Les fonctions suivantes ne sont exportées que sur demande explicite :

add_type( $type, @exts )
Associe une liste d'extensions de fichiers au type média donné. Exemple : 
add_type("x-world/x-vrml" => qw(wrl vrml));
add_encoding( $type, @ext )
Associe une liste d'extensions de fichiers à un type d'encodage. Exemple : 
add_encoding("x-gzip" => "gz");
read_media_types( @files )
Analyse les fichiers de types médias et ajoute les correspondances de types trouvées. Exemple : 
read_media_types("conf/mime.types");
