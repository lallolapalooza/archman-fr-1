NOM

Lire::LrCommand - Classe de base pour les programmes en ligne de commande.

SYNOPSIS

my $prog = new Lire::LrCommand();
$prog->init();
$prog->add_section( 'myprog', __( 'Options de mon programme' ) );
$prog->add_option( 'name' => 'myoption', 'type' => '=s',
                   'help' => __( 'Aide sur mon option.' ) );
$prog->add_common_options();
$prog->parse_options();

DESCRIPTION

Classe utilisée pour créer des programmes en ligne de commande qui partagent des fonctionnalités.

MÉTHODES

new( [$usage], [$help] )

Crée une nouvelle instance de Lire::LrCommon. Initialise la chaîne d'utilisation et le message d'aide à $usage et $help.

set_usage( [$usage] )

set_help( [$help] )

set_section( [$name], [$label] )

add_option( [%args] )

add_common_options()

import_log( [$converter], [$logfile] )

import_log appelle Lire::ImportJob et Lire::DlfConverterProcess. Il utilise &handle_logfile.

Cela signifie que si le $logfile est compressé, il est décompressé dans un fichier dans $TMPDIR. Si le $logfile est lu depuis un pipe ou STDIN, il est écrit dans un fichier dans $TMPDIR. Donc, si vous manquez d'espace disque, passez le fichier journal comme un fichier non compressé.

generate_report( [$converter], [$logfile] )

Génère un rapport à partir d'un $logfile, en utilisant $converter. Renvoie $reportfile. Utilise Lire::ReportConfig::generate_report pour faire le travail réel.
