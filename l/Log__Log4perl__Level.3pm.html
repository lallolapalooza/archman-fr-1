NOM

Log::Log4perl::Level - Niveaux de journalisation prédéfinis

SYNOPSIS

use Log::Log4perl::Level;
print $ERROR, "\n";
# -- ou --
use Log::Log4perl qw(:levels);
print $ERROR, "\n";

DESCRIPTION

"Log::Log4perl::Level" exporte simplement un ensemble prédéfini de niveaux de journalisation Log4perl dans l'espace de noms de l'appelant. Il est utilisé en interne par "Log::Log4perl". Les scalaires suivants sont définis :

$OFF
$FATAL
$ERROR
$WARN
$INFO
$DEBUG
$TRACE
$ALL

"Log::Log4perl" exporte également ces constantes dans l'espace de noms de l'appelant si vous l'importez en fournissant la balise ":levels" :

use Log::Log4perl qw(:levels);

C'est la méthode préférée, il n'est généralement pas nécessaire d'appeler "Log::Log4perl::Level" explicitement.

Les valeurs numériques assignées à ces constantes sont purement virtuelles, utilisées uniquement par Log4perl en interne et peuvent changer à tout moment, veuillez donc ne faire aucune supposition. Vous pouvez tester l'égalité numérique en comparant directement deux valeurs de niveau, c'est correct :

if( get_logger()->level() == $DEBUG ) {
    print "Le niveau du logger est DEBUG\n";
}

Mais si vous voulez savoir lequel de deux niveaux est le plus verbeux, utilisez le comparateur propre à Log4perl :

if( Log::Log4perl::Level::isGreaterOrEqual( $level1, $level2 ) ) {
    print Log::Log4perl::Level::to_level( $level1 ), 
        " est égal ou plus verbeux que ", 
        Log::Log4perl::Level::to_level( $level2 ), "\n";
}

Si l'appelant souhaite importer les constantes de niveau dans un espace de noms différent, il peut le fournir avec la commande "use" :

use Log::Log4perl::Level qw(MonEspaceNom);

Après cela, $MonEspaceNom::ERROR, $MonEspaceNom::INFO etc. seront définis en conséquence.

Niveaux numériques et chaînes

Les variables de niveau comme $DEBUG ou $WARN ont des valeurs numériques internes à Log4perl. Transformez-les en chaînes utilisables dans un fichier de configuration Log4perl, utilisez la fonction c<to_level()> fournie par Log::Log4perl::Level :

use Log::Log4perl qw(:easy);
use Log::Log4perl::Level;
    # affiche "DEBUG"
print Log::Log4perl::Level::to_level( $DEBUG ), "\n";

Pour effectuer la transformation inverse, qui prend une chaîne comme "DEBUG" et la convertit en une constante comme $DEBUG, utilisez la fonction to_priority() :

use Log::Log4perl qw(:easy);
use Log::Log4perl::Level;
my $numval = Log::Log4perl::Level::to_priority( "DEBUG" );

après quoi $numval pourrait être utilisé là où une valeur numérique est requise :

Log::Log4perl->easy_init( $numval );
