NOM

Lire::Config::List - Objet de valeur de liste.

DESCRIPTION

Utilisé pour les paramètres de configuration qui contiennent une liste de valeurs.

elements()

Retourne les valeurs de cette liste sous forme de tableau d'objets Lire::Config::Value.

get( $idx )

Retourne la valeur stockée à l'index $idx de cette liste. Une exception est levée si l'index est hors limites.

remove( $idx )

Supprime la valeur stockée à l'index $idx de cette liste. Une exception est levée si l'index est hors limites. Elle retourne l'élément supprimé.

clear()

Supprime tous les éléments de cette liste.

append( $val, [ $idx ] )

Ajoute $val après l'élément $idx. Si $idx est omis, l'élément sera ajouté à la fin du tableau. Un index négatif est interprété par rapport à la fin du tableau.

move( $idx, $new_idx )

Déplace l'élément $idx à la position $new_idx. Les indices peuvent être négatifs et sont interprétés comme une position relative à la fin du tableau.

set( $idx, $value )

Remplace la valeur à l'index $idx par $value.
