NOM

Locale::RecodeData::CP1251 - Fonctions de conversion pour CP1251

SYNOPIS

Ce module est interne à libintl. Ne l'utilisez pas directement !

DESCRIPTION

Ce module est généré et contient les tables de conversion et les routines pour CP1251.

COMMENTAIRES

Les remarques suivantes ont été extraites de la charmap d'origine :

version : 1.0
repertoiremap : mnémonique,ds
 source : UNICODE 1.0
 alias MS-CYRL

Note : les alias mentionnés ci-dessus ne sont pas nécessairement valides !
