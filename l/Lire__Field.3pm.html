NOM

Lire::Field - Interface à la spécification des champs Dlf.

SYNTAXE

my $field = $schema->field( 'time' );
print "Nom: ", $field->name(), "\n", "Type: ", $field->type(), "\n";

DESCRIPTION

Ce module représente les spécifications des champs Dlf. Vous obtiendrez une référence à ce type d'objet lorsque vous appellerez les méthodes field(), timestamp_field() ou fields() sur un objet Lire::DlfSchema(3pm). Vous pouvez obtenir des informations sur ce champ en interrogeant ses méthodes.

MÉTHODES OBJET

name()

Retourne le nom du champ.

label()

Retourne l'étiquette par défaut qui devrait être utilisée pour la colonne contenant les valeurs de ce champ.

pos()

Retourne la position du champ dans l'enregistrement. Les positions des champs sont indexées à partir de 0.

type()

Retourne le type du champ. Ce sera une chaîne décrivant le nom du type tel qu'utilisé dans les spécifications XML.

sql_type()

Retourne le type SQL qui devrait être utilisé pour stocker les valeurs de ce champ.

default()

Cette méthode est obsolète car les champs n'ont plus de valeur par défaut.

description()

Cette méthode retournera la description du champ. (C'est le contenu de l'élément description dans la spécification XML.) Sachez que cela contiendra très probablement du balisage DocBook.
