NOM

Locale::Po4a::Common - parties communes des scripts et utilitaires po4a

DESCRIPTION

Locale::Po4a::Common contient les parties communes des scripts po4a et quelques fonctions utiles utilisées par les autres modules.

Si nécessaire, vous pouvez désactiver l'utilisation de Text::WrapI18N comme suit :

use Locale::Po4a::Common qw(nowrapi18n);
use Locale::Po4a::Text;

au lieu de :

use Locale::Po4a::Text;

L'ordre est important ici : comme la plupart des modules Locale::Po4a se chargent eux-mêmes de Locale::Po4a::Common, la première fois que ce module est chargé détermine si Text::WrapI18N est utilisé.

FONCTIONS

Affichage des messages de sortie

  • show_version($)

    Affiche la version actuelle du script et un bref message de copyright. Il prend le nom du script comme argument.

  • wrap_msg($@)

    Cette fonction affiche un message de la même manière que sprintf(), mais en renvoyant le résultat pour qu'il s'affiche correctement dans le terminal.

  • wrap_mod($$@)

    Cette fonction fonctionne comme wrap_msg(), mais elle prend un nom de module comme premier argument et laisse un espace à gauche du message.

  • wrap_ref_mod($$$@)

    Cette fonction fonctionne comme wrap_msg(), mais elle prend une référence fichier:ligne comme premier argument, un nom de module comme deuxième, et laisse un espace à gauche du message.

Wrappers pour d'autres modules

•
Locale::Gettext

Lorsque le module Locale::Gettext ne peut pas être chargé, ce module fournit une implémentation factice (vide) des fonctions suivantes. Dans ce cas, les messages po4a ne seront pas traduits mais le programme continuera de fonctionner.

Si Locale::gettext est présent, ce wrapper appelle également setlocale(LC_MESSAGES, "") afin que les appelants ne dépendent pas non plus du module POSIX.

  • bindtextdomain($$)
  • textdomain($)
  • gettext($)
  • dgettext($$)
