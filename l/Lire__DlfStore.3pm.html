NOM

Lire::DlfStore - Interface pour un magasin DLF

SYNOPSIS

use Lire::DlfStore;
my $store = Lire::DlfStore->open( "mystore", 1 );
my $avail_streams = $store->dlf_streams;

DESCRIPTION

open( $chemin_magasin, [ $creation ] );

Ouvre un Lire::DlfStore résidant dans le répertoire pointé par $chemin_magasin et retourne une instance de Lire::DlfStore qui peut être utilisée pour accéder à son contenu.

Si le magasin $chemin_magasin n'a pas été créé, la méthode échouera à moins que le paramètre $creation n'ait été défini à vrai.

Si le magasin est verrouillé par un autre processus, la méthode échouera également.

Essayer d'ouvrir le même magasin deux fois depuis le même processus échouera.

close()

Appelle cette méthode pour libérer le verrou détenu par le processus actuel sur le magasin. Si vous ne l'appelez pas, elle sera appelée automatiquement lorsque la référence du magasin sortira de la portée, mais il est préférable de ne pas compter sur cela pour fermer vos magasins.

is_closed()

Retourne vrai si ce DlfStore a été fermé et ne peut plus être utilisé.

chemin

Retourne le chemin vers le magasin. C'est l'argument utilisé pour créer le magasin.

config

Retourne la configuration du magasin instanciée en tant que Lire::Config::ConfigFile.

import_jobs()

Retourne sous forme de référence de tableau la liste des ImportJob actuellement configurés dans le DlfStore

report_jobs()

Retourne sous forme de référence de tableau la liste des ReportJob actuellement configurés dans le DlfStore

a_config_report( $nom )

Retourne vrai s'il existe une configuration de rapport nommée $nom dans ce DlfStore.

report_configurations()

Retourne sous forme de référence de tableau la liste des ReporConfig actuellement configurés dans le DlfStore

get_report_config( $nom )

Retourne l'objet Lire::ReportConfig nommé $nom. Lève une exception s'il n'existe pas.

METHODES LIEES AUX FLUX DLF

Un DlfStore peut contenir plusieurs Flux DLF. Un Flux DLF contient des données conformes à un schéma DLF. Les flux sont représentés par des objets Lire::DlfStream.

dlf_streams()

Liste les flux DLF disponibles dans le magasin DLF. Ceci retourne une liste des noms de DlfSchema.

a_dlf_stream( $nom )

Retourne vrai si le DlfStore contient un DlfStream conforme au schéma $nom.

get_stream_config( $nom )

Retourne l'instance Lire::Config::Dictionary qui contient la configuration du flux pour le DlfStream $nom. Cette méthode créera une instance à partir de la valeur par défaut si nécessaire. Si $nom n'est pas un nom de schéma valide, cette méthode lèvera une erreur.

configured_dlf_streams()

Retourne la liste des DlfStreams qui sont référencés par la configuration du magasin. C'est le résultat de dlf_streams() plus tous les schémas qui existent et sont utilisés par un des ImportJob ou DlfStreamSpec configurés.

open_dlf_stream( $nom, [$mode], [$sort_spec] )

Retourne un objet Lire::DlfStream qui peut être utilisé pour accéder à un flux DLF dans le schéma $nom. Le paramètre $mode peut être "r" (lecture) ou "w" (écriture) et vaut "r" par défaut.

Si le mode est "w", le Lire::DlfStream est ouvert en écriture (de nouveaux enregistrements DLF peuvent être insérés). Si le DlfStore ne contenait pas de flux $nom, un flux vide sera créé.

Si le mode est "r", le Lire::DlfStream est ouvert en lecture (aucun enregistrement DLF ne peut être inséré). Une exception sera levée s'il n'y a pas de flux $nom disponible.

Lorsque le flux est ouvert en mode "r", un ordre de tri peut être spécifié en passant un $sort_spec. Un $sort_spec est une liste d'identifiants de champs séparés par des espaces qui devrait spécifier l'ordre de tri. L'ordre de tri inversé peut être spécifié en préfixant le nom du champ par '-'.

run_analysers( $stream, [ $dlf_source ] )

Exécute tous les analyseurs configurés sur le flux DLF $stream. $dlf_source limite les enregistrements qui devraient être analysés.

clean_streams()

Supprime les enregistrements qui ont plus de jours que ce qui est configuré dans le paramètre 'keep_days'.

METHODES LIEES AUX RAPPORTS

Un DlfStore contient également les rapports générés périodiquement. Ces rapports sont généralement configurés via la commande lire(1). Les rapports générés sont stockés au format natif XML de Lire par période.

put_report( $job, $schedule, $report )

Sauvegarde le Lire::Report $report qui a été généré par $job et $schedule. Retourne le nom du fichier où le rapport a été sauvegardé.

find_report_source( $job, $schedule, [$time] )

Cette méthode retournera une référence de hachage contenant les paramètres sur la façon dont le ReportJob $job devrait être généré pour le ReportSchedule $schedule. Les limites de la période sont déterminées selon $time qui vaut par défaut 'now' (maintenant).

La référence de hachage contiendra une clé 'source' ainsi que d'autres clés possibles :

source
Spécifie à partir de quel type de source le rapport devrait être généré. Les valeurs possibles sont 'dlf' lorsque le rapport devrait être généré à partir de DLF, 'merging' lorsque le rapport devrait être généré en fusionnant des rapports XML précédents et 'none' lorsqu'aucune donnée n'est disponible pour cette période et que le rapport ne peut être généré.

Notez que 'merging' n'est disponible qu'en tant que source pour les planifications au-dessus de 'daily' (quotidien). C'est-à-dire que les rapports 'hourly' (horaires) et 'daily' (quotidiens) ne peuvent être générés qu'à partir de DLF. Il est également important de noter que seuls les rapports 'daily' (quotidiens) sont disponibles comme source pour la fusion. Vous avez donc besoin d'une planification de rapport quotidienne pour générer les planifications 'weekly' (hebdomadaires), 'monthly' (mensuelles) et 'yearly' (annuelles) par fusion.

start
Le timestamp auquel les données disponibles pour la période commencent. Ceci peut être supérieur à la limite de début de la période demandée.
end
Le timestamp auquel les données disponibles pour la période se terminent. Ceci peut être inférieur à la limite de fin de la période demandée.
coverage
Un entier compris entre 0 et 100 représentant le ratio de données disponibles pour la période demandée.

use Lire::DlfStore;

DESCRIPTION

Lire::DlfStore est un module Perl qui fournit des méthodes pour gérer les fichiers DLF.

METHODES LIEES AUX FLUX DLF

Ce module fournit des méthodes pour gérer les flux DLF.
