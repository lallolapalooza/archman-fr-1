NOM

Lire::FTP::IisFtpDlfConverter - convertir les journaux du serveur FTP Microsoft en DLF

SYNTAXE

Lire::FTP::IisFtpDlfConverter

DESCRIPTION

Lire::FTP::IisFtpDlfConverter convertit les fichiers journaux du serveur FTP Microsoft au format DLF FTP. Ces fichiers journaux sont dans un format basé sur le format de journalisation étendu W3C.

Pour avoir un maximum d'informations dans vos rapports, nous suggérons de journaliser les champs suivants :

time, time-taken, c-dns ou c-ip, cs-uri-stem, sc-bytes

Nous supportons également le champ cs-uri.

Les autres champs seront ignorés.

LIMITATIONS

Le convertisseur ne gère pas l'agrégation (enregistrement avec champ de comptage) et refusera de traiter ces journaux. De plus, il ne supporte pas le changement de champs au milieu du fichier journal. Cela signifie que tous les enregistrements du fichier journal doivent avoir le même format.
