NOM

Lingua::Translit - translittère le texte entre systèmes d'écriture

SYNOPSIS

use Lingua::Translit;
my $tr = new Lingua::Translit("ISO 843");
my $text_tr = $tr->translit("character oriented string");
if ($tr->can_reverse()) {
  $text_tr = $tr->translit_reverse("character oriented string");
}

DESCRIPTION

Lingua::Translit peut être utilisé pour convertir du texte d'un système d'écriture à un autre, basé sur des tables de translittération nationales ou internationales. Lorsque cela est possible, une translittération inverse est prise en charge.

Le terme "translittération" décrit la conversion de texte d'un système d'écriture ou d'un alphabet à un autre. La conversion est idéalement unique, associant un caractère à exactement un caractère, de sorte que l'orthographe d'origine puisse être reconstruite. En pratique, ce n'est pas toujours le cas et une seule lettre de l'alphabet d'origine peut être transcrite en deux, trois lettres ou même plus.

De plus, il existe plus d'un schéma de translittération pour un même système d'écriture. Par conséquent, il est important et nécessaire de savoir quel schéma sera ou a été utilisé pour translittérer un texte, afin de travailler de manière intégrée et de pouvoir reconstruire les données d'origine.

La reconstruction est cependant un problème pour les translittérations non uniques, si aucune connaissance spécifique à la langue n'est disponible, car les séquences de lettres résultantes peuvent être ambiguës. Par exemple, le caractère grec "PSI" correspond à "ps", mais "ps" pourrait également résulter de la séquence "PI", "SIGMA" puisque "PI" correspond à "p" et "SIGMA" à "s". Si une table de translittération conduit à des conversions ambiguës, la table fournie ne peut pas être utilisée en sens inverse.

Sinon, la table peut être utilisée dans les deux directions, si apprécié. Ainsi, si l'ISO 9 est à l'origine créé pour convertir les lettres cyrilliques en alphabet latin, la translittération inverse transformera les lettres latines en lettres cyrilliques.

MÉTHODES

new("nom de la table")

Initialise un objet avec la table de translittération spécifique, par exemple "ISO 9".

translit("chaîne orientée caractères")

Translittère le texte donné selon la table de translittération de l'objet. Retourne le texte translittéré.

translit_reverse("chaîne orientée caractères")

Translittère le texte donné selon la table de translittération de l'objet, mais l'utilise dans l'autre sens. Par exemple, la table ISO 9 est un schéma de translittération pour la conversion des lettres cyrilliques vers l'alphabet latin. Ainsi, si utilisée en sens inverse, les lettres latines seront mappées sur des lettres cyrilliques.

Retourne le texte translittéré.

can_reverse()

Retourne vrai (1) si la translittération inverse est possible. Faux (0) sinon.

name()

Retourne le nom de la table de translittération choisie, par exemple "ISO 9".

desc()

Retourne une description de la translittération, par exemple "ISO 9:1995, Cyrillique vers Latin".

AJOUTER DE NOUVELLES TRANSLITTÉRATIONS

Si vous souhaitez ajouter vos propres tables de translittération à Lingua::Translit, consultez la documentation pour les développeurs à l'adresse : https://www.netzum-sorglos.de/software/lingua-translit/developer-documentation.html.

Un modèle de table de translittération est également fourni (xml/template.xml) afin que vous puissiez facilement commencer le développement.

RESTRICTIONS

Lingua::Translit est adapté pour gérer l'Unicode et utilise des comparaisons et des expressions régulières qui reposent sur des **points de code**. Par conséquent, toute entrée est censée être **orientée caractères** ("use utf8;", ...) plutôt qu'orientée octets.

Cependant, si vos données sont orientées octets, assurez-vous de les passer **encodées en UTF-8** à translit() et/ou translit_reverse() - elles seront converties en interne.
