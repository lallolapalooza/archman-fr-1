NOM

Locale::RecodeData::IBM290 - Routines de conversion pour IBM290

SYNOPIS

Ce module est interne à libintl. Ne l'utilisez pas directement !

DESCRIPTION

Ce module contient les tables de conversion et les routines pour IBM290.

COMMENTAIRES

Les remarques suivantes sont extraites du fichier charmap original :

version: 1.0
 source: IBM 3174 Character Set Ref, GA27-3831-02, Mars 1990
 alias CP290
 alias EBCDIC-JP-KANA

Remarque : les alias mentionnés ci-dessus ne sont pas nécessairement valides !
