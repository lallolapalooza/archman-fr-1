NOM

Locale::RecodeData::MACCYRILLIC

SYNOPIS

use Locale::RecodeData::MACCYRILLIC;

DESCRIPTION

Locale::RecodeData::MACCYRILLIC est un module qui fournit une table de caractères pour l'encodage et le décodage des caractères cyrilliques, spécifiquement pour être utilisé dans le module Recode.

COMMENTAIRES

Ce module est conçu pour gérer la conversion des caractères cyrilliques entre différents encodages, garantissant une représentation précise et la compatibilité entre divers systèmes.
