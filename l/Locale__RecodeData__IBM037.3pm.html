NOM

Locale::RecodeData::IBM037 - Fonctions de conversion pour IBM037

SYNOPIS

Ce module est interne à libintl. Ne l'utilisez pas directement !

DESCRIPTION

Ce module contient les tables de conversion et les routines pour IBM037.

COMMENTAIRES

Les remarques suivantes ont été extraites du charmap original :

version: 1.0
 source: IBM NLS RM Vol2 SE09-8002-01, Mars 1990
alias CP037
alias EBCDIC-CP-US
alias EBCDIC-CP-CA
alias EBCDIC-CP-WT
alias EBCDIC-CP-NL

Note : Les alias mentionnés ci-dessus ne sont pas nécessairement valides !
