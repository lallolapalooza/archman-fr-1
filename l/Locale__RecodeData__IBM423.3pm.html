NOM

Locale::RecodeData::IBM423 - Routines de conversion pour IBM423

SYNOPSE

Ce module est interne à libintl. Ne l'utilisez pas directement !

DESCRIPTION

Ce module est généré et contient les tables de conversion et les routines pour IBM423.

COMMENTAIRES

Les remarques suivantes ont été extraites du charmap d'origine :

version: 1.0
 source: IBM NLS Vol2 SE09-8002-01, mars 1990
 alias CP423
 alias EBCDIC-CP-GR

Note : les alias mentionnés ci-dessus ne sont pas nécessairement valides !

Les codes de caractères qui ne sont pas définis dans le jeu de caractères IBM423 sont représentés par le symbole de caractère pour U+0000 à U+0020, c'est-à-dire le caractère NUL (00). Dans ce cas, ils sont codés comme le caractère `NUL`.

Il y a des différences dans la représentation de certains caractères, et par conséquent, l'utilisation de ce module peut avoir des résultats inattendus. Par exemple, une tabulation \t est représentée par le caractère U+0009, alors que son code IBM423 est 0x05.

NOM

Locale::RecodeData

SYNOPIS

use Locale::RecodeData;

DESCRIPTION

Locale::RecodeData est un module qui fournit des données pour le module Locale::Recode. Il contient des correspondances de codes de caractères à leurs valeurs Unicode correspondantes.

COMMENTAIRES

Ce module est utilisé pour fournir des correspondances de caractères pour le module Locale::Recode. Il contient une liste de codes de caractères et leurs valeurs Unicode correspondantes.
