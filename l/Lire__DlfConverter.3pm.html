NOM

Lire::DlfConverter - Interface de base de tous les convertisseurs DLF.

SYNOPSIS

use base qw/ Lire::DlfConverter /;

DESCRIPTION

Ce paquet définit l'interface qui doit être implémentée par tous les convertisseurs DLF. Toutes les méthodes définies dans ce paquet lanceront une exception « méthode non implémentée » si elles sont appelées.

MÉTHODES D'INFORMATION MÉTA

Ces méthodes fournissent des informations au framework Lire sur le convertisseur DLF.

name()

Retourne le nom du convertisseur DLF, c'est-à-dire le nom du service (également appelé format de journal).

Par exemple, "combined".

title()

Retourne un nom plus convivial pour le convertisseur DLF.

Par exemple, "Convertisseur DLF au format de journal combiné".

description()

Retourne une documentation basée sur XML DocBook du convertisseur DLF.

Par exemple, <para>Ce convertisseur DLF peut être utilisé pour traiter les fichiers journaux au format de journal combiné vers le schéma DLF www.</para>.

schemas()

Retourne une liste de schémas DLF pour lesquels des enregistrements DLF peuvent être écrits à partir des données contenues dans le fichier journal.

Par exemple, pour les convertisseurs DLF combinés, ce serait 'www'.

Pour le convertisseur 'nms', cela pourrait être "qw/daemon email/", ce qui signifie que le convertisseur DLF écrit des enregistrements DLF dans le schéma hypothétique "daemon" (démarrages, arrêts, redémarrages, etc. du serveur) et le schéma email.

Cette liste ne devrait contenir que les schémas 'de base' (alias superservice). Aucun nom de schéma étendu ou dérivé ne devrait apparaître dans cette liste. (Ceux-ci sont réservés aux analyseurs).

handle_log_lines()

Cette méthode doit renvoyer vrai si le DlfConverter traite des fichiers journaux orientés ligne. C'est le comportement par défaut. Si cette méthode renvoie faux, seule la méthode process_log_file() sera appelée, sinon la méthode process_log_line() est utilisée pour chaque ligne d'entrée.

Méthodes d'implémentation

Ce sont les méthodes où le travail de conversion DLF est effectué. La méthode init_dlf_converter() sera appelée une fois avant tout traitement. Ensuite, process_log_line() sera appelée une fois pour chaque ligne marquée pour la continuation du journal et pour chaque ligne contenue dans le fichier journal. La méthode finish_conversion() sera appelée une fois que toutes les lignes auront été traitées. Toutes les exceptions (erreurs non capturées) survenant pendant l'une des méthodes interrompront le processus de conversion.

init_dlf_converter( $process, [$config] )

Cette méthode sera appelée par le framework avant le traitement du fichier journal. Cette méthode doit être utilisée par le convertisseur pour initialiser son état.

Le paramètre $process contient l'objet Lire::DlfConverterProcess qui contrôle le processus de conversion.

Le paramètre $config contient des données de configuration spécifiées dans le Job d'importation pour ce convertisseur. Pour enregistrer les spécifications de configuration de votre DlfConverter, il vous suffit de définir une spécification de configuration sous le nom nom_du_convertisseur_properties. Cela devrait être soit une RecordSpec, soit une ObjectSpec.

process_log_file( $process, $fd )

Cette méthode est appelée afin que le convertisseur puisse convertir les données contenues dans le descripteur de fichier $fd en DLF. Cette méthode n'est utilisée que lorsque la méthode handle_log_lines() a renvoyé faux.

$process contient une référence à l'objet Lire::DlfConverterProcess qui contrôle le processus de conversion et définit l'API pour écrire en DLF et signaler les erreurs.

process_log_line( $process, $line )

Cette méthode est appelée par le framework une fois pour chaque ligne de journal présente dans le fichier journal. Cette méthode n'est appelée que si la méthode handles_log_lines() renvoie vrai.

$process est une référence à l'objet Lire::DlfConverterProcess. Cet objet définit une méthode pour signaler les erreurs, sauvegarder les lignes à des fins de continuation et écrire des enregistrements DLF.

$line contient la ligne de journal qui doit être traitée, sans le caractère de fin de ligne.

finish_conversion( $dlf_store )

Cette méthode est appelée une fois par le framework une fois que toutes les lignes de journal ont été traitées. Elle peut être utilisée par le convertisseur pour écrire tout enregistrement DLF restant en raison d'une analyse étatiste.
