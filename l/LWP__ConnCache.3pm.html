NOM

LWP::ConnCache - Gestionnaire de cache de connexion

NOTE

Ce module est expérimental. Les détails de son interface sont susceptibles d'être modifiés à l'avenir.

SYNTAXE

use LWP::ConnCache;
my $cache = LWP::ConnCache->new;
$cache->deposit($type, $key, $sock);
$sock = $cache->withdraw($type, $key);

DESCRIPTION

La classe "LWP::ConnCache" est le gestionnaire de cache de connexion standard pour LWP::UserAgent.

MÉTHODES

Les méthodes de base suivantes sont fournies :

new

my $cache = LWP::ConnCache->new( %options )

Cette méthode crée un nouvel objet LWP::ConnCache. Le seul paramètre actuellement accepté est "total_capacity". S'il est spécifié, il initialise l'option "total_capacity" dans l'objet LWP::ConnCache. Par défaut, il vaut 1.

total_capacity

my $cap = $cache->total_capacity;
$cache->total_capacity(0); # tout supprimer immédiatement
$cache->total_capacity(undef); # pas de limite
$cache->total_capacity($number);

Obtenir/mettre à jour le nombre de connexions à mettre en cache. Les connexions commenceront à être supprimées lorsque cette limite sera atteinte. Si défini sur 0, toutes les connexions sont supprimées immédiatement. Si défini sur "undef", il n'y a pas de limite.

capacity

my $http_capacity = $cache->capacity('http');
$cache->capacity('http', 2 );

Obtenir/mettre à jour une limite pour le nombre de connexions d'un type spécifique qui peuvent être mises en cache. Le premier argument est une chaîne courte comme "http" ou "ftp".

drop

$cache->drop(); # Supprimer toutes les connexions
# ce qui est un synonyme de :
$cache->drop(sub{1}); # Supprimer toutes les connexions
# supprimer toutes les connexions plus anciennes que 22 secondes et ajouter une raison à cela !
$cache->drop(22, "Older than 22 secs dropped");
# ce qui est un synonyme de :
$cache->drop(sub {
    my ($conn, $type, $key, $deposit_time) = @_;
    if ($deposit_time < 22) {
        # les valeurs vraies suppriment la connexion
        return 1;
    }
    # les valeurs fausses ne suppriment pas la connexion
    return 0;
}, "Older than 22 secs dropped" );

Supprimer les connexions selon des critères. L'argument $checker est une sous-routine qui est appelée pour chaque connexion. Si elle renvoie TRUE, la connexion est supprimée. La sous-routine est appelée avec "($conn, $type, $key, $deposit_time)" comme arguments.

Raccourcis : Si l'argument $checker est absent (ou "undef"), toutes les connexions dans le cache sont supprimées. Si le $checker est un nombre, toutes les connexions qui ont été mises en cache pendant plus de ce nombre de secondes sont supprimées. Si le $checker est une chaîne, toutes les connexions du type spécifié sont supprimées.

La raison "reason" est passée à la propriété "dropped" dans la méthode LWP::ConnCache.

prune

$cache->prune();

Appeler cette méthode supprimera toutes les connexions qui sont mortes. Ceci est vérifié en appelant la méthode "ping" sur la méthode LWP::ConnCache sur les connexions. Si le "ping" sur la méthode LWP::ConnCache existe et renvoie une valeur fausse, la connexion est supprimée.

get_types

my @types = $cache->get_types();

Renvoie tous les "type" utilisés dans les connexions actuellement mises en cache.

get_connections

my @conns = $cache->get_connections(); # toutes les connexions
my @conns = $cache->get_connections('http'); # connexions pour http

Renvoie tous les objets de connexion d'un type spécifique. Si aucun type n'est spécifié, toutes les connexions sont renvoyées. En contexte scalaire, le nombre de connexions mises en cache du type spécifié est renvoyé.

MÉTHODES DE PROTOCOLE

Les méthodes suivantes sont appelées par les modules de protocole de bas niveau pour tenter de mettre en cache les connexions et de les récupérer.

deposit

$cache->deposit($type, $key, $conn);

Cette méthode ajoute une nouvelle connexion au cache. D'autres connexions déjà mises en cache peuvent être supprimées en conséquence. Plusieurs connexions avec le même type/clé peuvent être ajoutées.

withdraw

my $conn = $cache->withdraw($type, $key);

Cette méthode tente de récupérer une connexion qui avait été préalablement déposée. S'il n'y a pas de connexion mise en cache avec le type $type/$key, "undef" est renvoyé. Il n'y a aucune garantie qu'une connexion déposée puisse être récupérée, car le gestionnaire de cache peut supprimer des connexions à tout moment.

MÉTHODES INTERNES

Les méthodes suivantes sont appelées en interne. Les sous-classes pourraient vouloir les redéfinir.

enforce_limits

$conn->enforce_limits([$type])

Cette méthode est appelée après qu'une nouvelle connexion ait été ajoutée (déposée) au cache ou que les limites de capacité aient été ajustées. L'implémentation par défaut supprime les connexions jusqu'à ce que les limites spécifiées ne soient plus dépassées.

dropping

$conn->dropping($conn_record, $reason)

Cette méthode est appelée lorsqu'une connexion est supprimée. L'enregistrement de la connexion qui a été supprimée est passé comme premier argument et une chaîne décrivant la raison de la suppression comme second argument. L'implémentation par défaut fait du bruit si la variable $LWP::ConnCache::DEBUG est active, et rien d'autre.

SOUS-CLASSEMENT

Pour une politique de mise en cache spécialisée, il est utile d'hériter de "LWP::ConnCache" et de redéfinir les méthodes "deposit" dans "LWP::ConnCache", "enforce_limits" dans "LWP::ConnCache" et "dropping" dans "LWP::ConnCache".

L'objet lui-même est un hash. Les clés préfixées par "cc_" sont réservées à la classe de base.
