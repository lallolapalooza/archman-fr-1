NOM

Locale::RecodeData::IBM864 - Routines de conversion pour IBM864

SYNTAXE

Ce module est interne à libintl. Ne l'utilisez pas directement !

DESCRIPTION

Ce module est généré automatiquement et contient les tables de conversion et les routines pour IBM864.

COMMENTAIRES

Les commentaires suivants ont été extraits de la charmap originale :

généré automatiquement à partir de la base de données de caractères
alias CP864

Veuillez noter que les alias listés ci-dessus ne sont pas nécessairement valides !
