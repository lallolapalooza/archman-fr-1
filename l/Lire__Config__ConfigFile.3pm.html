NOM

Lire::Config::ConfigFile - Classe pour la manipulation des fichiers de configuration.

SYNTAXE

use Lire::Config::ConfigFile;

DESCRIPTION

Objet représentant un fichier de configuration Lire.

new( 'nom_fichier' => $fichier, spécification => $spéc_config )

Crée un nouvel objet Lire::Config::ConfigFile. Le constructeur prend deux paramètres :

nom_fichier
Le fichier à partir duquel la configuration a été stockée ou chargée.
spécification
L'objet Lire::Config::TypeSpec auquel cette configuration adhère.

nom_fichier( [nouveau_nom_fichier] )

Retourne (et modifie éventuellement) le nom du fichier où cette configuration doit être stockée.

spécification()

Retourne l'objet Lire::Config::TypeSpec auquel cette configuration adhère.

global( [ $config] )

Retourne ou modifie la partie 'globale' de la configuration du fichier. C'est une instance de l'objet Lire::Config::Compound.

sauvegarder()

Sauvegarde cet objet ConfigConfigFile vers le nom de fichier à partir duquel il a été chargé.

annuler()

Relit la configuration depuis le fichier.

comme_valeur()

Retourne ce fichier de configuration sous forme de référence de hachage. Délègue à l'objet de configuration global contenu dans le fichier.

obtenir( $nom )

Retourne le paramètre de configuration $nom de ce fichier. Délègue à l'objet de configuration global contenu dans le fichier.

est_défini( $nom )

Vérifie si un paramètre de configuration est défini dans ce fichier. Délègue à l'objet de configuration global contenu dans le fichier.

définir( $param )

Définit une variable de configuration dans le fichier. Délègue à l'objet de configuration global contenu dans le fichier.
