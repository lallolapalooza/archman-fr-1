NOM

Log::Log4perl::Appender::ScreenColoredLevels - Coloriser les messages en fonction du niveau

SYNOPSIS

use Log::Log4perl qw(:easy);
Log::Log4perl->init(\ <<'EOT');
  log4perl.category = DEBUG, Screen
  log4perl.appender.Screen = \
      Log::Log4perl::Appender::ScreenColoredLevels
  log4perl.appender.Screen.layout = \
      Log::Log4perl::Layout::PatternLayout
  log4perl.appender.Screen.layout.ConversionPattern = \
      %d %F{1} %L> %m %n
EOT
  # Apparaît en noir
DEBUG "Message de débogage";
  # Apparaît en vert
INFO  "Message d'information";
  # Apparaît en bleu
WARN  "Message d'avertissement";
  # Apparaît en magenta
ERROR "Message d'erreur";
  # Apparaît en rouge
FATAL "Message critique";

DESCRIPTION

Cet appeundeur agit comme Log::Log4perl::Appender::Screen, sauf qu'il colorise sa sortie, en fonction de la priorité du message envoyé.

Vous pouvez configurer les couleurs et les attributs utilisés pour les différents niveaux, en les spécifiant dans votre configuration :

log4perl.appender.Screen.color.TRACE=cyan
log4perl.appender.Screen.color.DEBUG=bold blue

Vous pouvez également ne rien spécifier, pour indiquer que ce niveau ne doit pas avoir de coloration appliquée, ce qui signifie que le texte sera la couleur par défaut de votre terminal. C'est le comportement par défaut pour les messages de débogage.

log4perl.appender.Screen.color.DEBUG=

Vous pouvez utiliser n'importe quel attribut pris en charge par Term::ANSIColor comme option de configuration.

log4perl.appender.Screen.color.FATAL=\
    bold underline blink red on_white

Les couleurs et attributs couramment utilisés sont :

attributs
BOLD, DARK, UNDERLINE, UNDERSCORE, BLINK
couleurs
BLACK, RED, GREEN, YELLOW, BLUE, MAGENTA, CYAN, WHITE
couleurs de fond
ON_BLACK, ON_RED, ON_GREEN, ON_YELLOW, ON_BLUE, ON_MAGENTA, ON_CYAN, ON_WHITE

Voir Term::ANSIColor pour une liste complète et des informations sur les terminaux couramment pris en charge.

Les valeurs par défaut pour ces options sont :

Trace
Jaune
Debug
Aucune (couleur par défaut du terminal)
Info
Vert
Warn
Bleu
Error
Magenta
Fatal
Rouge

Le constructeur new() prend un paramètre optionnel "stderr" ; s'il est défini sur une valeur vraie, l'appeundeur enverra tous les niveaux vers STDERR. Si "stderr" est défini sur une valeur fausse, il enverra tous les niveaux vers STDOUT. Sinon, "stderr" peut être défini sur un hash, avec une clé pour chaque "log4p_level" et une valeur vérité pour utiliser dynamiquement stderr. Le réglage par défaut pour "stderr" est 1, donc tous les messages seront envoyés vers STDERR par défaut.

# Tous les messages/niveaux vers STDERR
my $app = Log::Log4perl::Appender::Screen->new(
    stderr  => 1,
);
# SEULEMENT ERROR et FATAL vers STDERR (sensible à la casse)
my $app = Log::Log4perl::Appender::Screen->new(
    stderr  => { ERROR => 1, FATAL => 1},
);

Le constructeur peut également prendre un paramètre optionnel "color", dont la valeur est un hashref d'options de configuration de couleur ; tous les niveaux non inclus dans le hashref seront définis sur leurs valeurs par défaut.

Utilisation de ScreenColoredLevels sous Windows

Notez que si vous utilisez cet appeundeur sous Windows, vous devez récupérer Win32::Console::ANSI depuis CPAN et ajouter

use Win32::Console::ANSI;

à votre script.
