NOM

Locale::Codes::Currency - module pour manipuler les jeux de codes de devises

SYNTAXE

use Locale::Codes::Currency;
$nom = code2currency(CODE);
$code = currency2code(NOM);
@codes   = all_currency_codes();
@noms   = all_currency_names();

DESCRIPTION

Ce module permet d'accéder aux jeux de codes de devises.

Veuillez vous référer au document Locale::Codes::Types pour une description des jeux de codes disponibles.

La plupart des routines prennent un argument optionnel supplémentaire qui spécifie le jeu de codes à utiliser. Le jeu de codes peut être spécifié en utilisant le nom d'un jeu de codes, ou la constante perl spécifiée dans le document ci-dessus. S'il n'est pas spécifié, le jeu de codes par défaut sera utilisé.

ROUTINES

Toutes les routines de ce module appellent la méthode appropriée dans le module Locale::Codes, en utilisant un objet de type : currency. Veuillez vous référer à la documentation du module Locale::Codes pour plus de détails sur chaque fonction.

Les fonctions suivantes sont exportées automatiquement :

code2currency(CODE [,CODESET] [,'retired'])
Voir code2name dans Locale::Codes
code2currencys(CODE [,CODESET])
Voir code2names dans Locale::Codes
currency2code(NOM [,CODESET] [,'retired'])
Voir name2code dans Locale::Codes
currency_code2code(CODE ,CODESET ,CODESET2)
Voir code2code dans Locale::Codes
all_currency_codes([CODESET] [,'retired'])
Voir all_codes dans Locale::Codes
all_currency_names([CODESET] [,'retired'])
Voir all_names dans Locale::Codes

Les fonctions suivantes ne sont pas exportées et doivent être appelées avec leur nom de paquet complet :

Locale::Codes::Currency::show_errors(FLAG)
Par défaut, une entrée invalide produira des résultats vides, mais aucune erreur. En passant une valeur non nulle à FLAG, des erreurs seront produites.

Voir show_errors dans Locale::Codes, mais notez que le défaut pour les modules non-OO est de NE PAS produire d'erreurs.

Locale::Codes::Currency::rename_currency(CODE ,NEW_NAME [,CODESET])
Voir rename_code dans Locale::Codes
Locale::Codes::Currency::add_currency(CODE ,NAME [,CODESET])
Voir add_code dans Locale::Codes
Locale::Codes::Currency::delete_currency(CODE [,CODESET])
Voir delete_code dans Locale::Codes
Locale::Codes::Currency::add_currency_alias(NOM ,NEW_NAME)
Voir add_alias dans Locale::Codes
Locale::Codes::Currency::delete_currency_alias(NOM)
Voir delete_alias dans Locale::Codes
Locale::Codes::Currency::rename_currency_code(CODE ,NEW_CODE [,CODESET])
Voir replace_code dans Locale::Codes
Locale::Codes::Currency::add_currency_code_alias(CODE ,NEW_CODE [,CODESET])
Voir add_code_alias dans Locale::Codes
Locale::Codes::Currency::delete_currency_code_alias(CODE [,CODESET])
Voir delete_code_alias dans Locale::Codes
