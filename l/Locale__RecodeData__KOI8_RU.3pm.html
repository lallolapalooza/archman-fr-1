NOM

Locale::RecodeData::KOI8_RU - Routines de conversion pour KOI8-RU

SYNTAXE

Ce module est interne à libintl. Ne l'utilisez pas directement !

DESCRIPTION

Ce module est généré automatiquement et contient les tables de conversion et les routines pour KOI8-RU.

COMMENTAIRES

Les commentaires suivants ont été extraits de la charmap d'origine :

This charmap has been generated automatically from GNU libiconv
conversions.

Veuillez noter que les alias listés ci-dessus ne sont pas nécessairement valides !

TABLE DES CARACTERES

Le tableau suivant est trié dans le même ordre que la charmap d'origine. Tous les codes de caractères sont en hexadécimal. Veuillez lire 'ISO-10646' comme 'ISO-10646-UCS4'.

SYNOPSIS

use Locale::RecodeData::KOI8_RU;

DESCRIPTION

Cette distribution fournit des définitions de jeux de caractères pour les jeux de caractères KOI8-R et KOI8-U, utilisés pour l'encodage du russe et de l'ukrainien, respectivement. Ces définitions sont utilisées par la famille de modules Locale::Recode pour convertir des chaînes de caractères entre différents jeux de caractères et l'Unicode.

COMMENTS

La majeure partie de ce code provient du projet libintl-perl, qui a été abandonné. Les fonctions ont été déplacées vers des modules distincts pour la maintenance et le développement futurs.
