NOM

Locale::Po4a::Debconf - convertir les modèles debconf depuis/vers des fichiers PO

DESCRIPTION

Le projet po4a (PO pour tout) vise à faciliter les traductions (et plus intéressant encore, la maintenance des traductions) en utilisant les outils gettext dans des domaines où ils n'étaient pas attendus, comme la documentation.

Locale::Po4a::Debconf est un module qui aide à la traduction des modèles debconf dans d'autres langues [humaines].

AUCUNE.

ÉTAT DE CE MODULE

Non testé.

N'UTILISEZ PAS CE MODULE POUR PRODUIRE DES MODÈLES. Il est seulement bon pour extraire des données.
