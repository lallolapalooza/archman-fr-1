Locale::Maketext::Extract::Plugin::TT2(3) Documentation Perl fournie par l'utilisateur Locale::Maketext::Extract::Plugin::TT2(3)

NOM

Locale::Maketext::Extract::Plugin::TT2 - Analyseur de format Template Toolkit

VERSION

version 1.00

SYNTAXE

$plugin = Locale::Maketext::Extract::Plugin::TT2->new(
    $lexicon            # Un objet Locale::Maketext::Extract
    @file_types         # Facultatif : spécifier une liste de types de fichiers reconnus
)
$plugin->extract($filename,$filecontents);

DESCRIPTION

Extrait les chaînes à localiser à partir des modèles Template Toolkit.

NOM ABREGÉ DU PLUGIN

tt2

FORMATS VALIDES

Les formats valides sont :

[% |l(args) %]chaîne[% END %]
[% 'chaîne' | l(args) %]
[% l('chaîne',args) %]
[% c.l('chaîne') %]
Toutes les combinaisons ci-dessus avec "c." préfixé devraient également fonctionner correctement. C'est la syntaxe par défaut lors de l'utilisation de modèles TT avec Mojolicious.

l et loc sont interchangeables.

| et FILTER sont interchangeables.

TYPES DE FICHIERS CONNUS

.tt
.tt2
.html
.tt.*
.tt2.*

REQUIS

Template

NOTES

  • ATTENTION L'utilisation de la forme "loc" peut donner de faux positifs si vous utilisez le plugin d'analyseur Perl sur des fichiers TT. Si vous souhaitez utiliser la forme "loc", vous devriez spécifier les types de fichiers que vous souhaitez que le plugin Perl analyse, ou activer les types de fichiers par défaut, par exemple : 
    xgetext.pl -P perl ....        # types de fichiers par défaut
xgettext.pl -P perl=pl,pm  ... # types de fichiers spécifiés
  • La chaîne à localiser doit être une chaîne, pas une variable. Nous essayons de ne pas extraire les appels à votre fonction de localisation qui contiennent des variables, par exemple : 
    l('chaîne',arg)  # extrait
l(var,arg)       # non extrait

    Cela ne fonctionne pas pour les filtres de bloc, alors ne faites pas cela. Par exemple :

    [%  FILTER l %]
   chaîne [% var %]      # MAUVAIS !
[% END %]
  • Obtenir le bon numéro de ligne est difficile dans TT. Souvent, ce sera une plage de lignes, ou cela pourrait être faussé par l'utilisation de PRE_CHOMP ou POST_CHOMP. Ce sera toujours à quelques lignes de l'emplacement correct.
  • Si vous avez PRE/POST_CHOMP activés par défaut dans vos modèles, vous devriez extraire les chaînes en utilisant les mêmes valeurs. Pour les définir, vous pouvez utiliser le script wrapper suivant : 
    #!/usr/bin/perl
use Locale::Maketext::Extract::Run qw(xgettext);
use Locale::Maketext::Extract::Plugin::TT2();
%Locale::Maketext::Extract::Plugin::TT2::PARSER_OPTIONS = (
     PRE_CHOMP  => 1, # ou 2
     POST_CHOMP => 1, # ou 2
     # Aussi START/END_TAG, ANYCASE, INTERPOLATE, V1DOLLAR, EVAL_PERL
);
xgettext(@ARGV);
