NOM

Lire::Config::Value - Conteneurs de valeur Lire pour les variables de configuration

SYNTAXE

use base qw/ Lire::Config::Value /;

DESCRIPTION

Conteneurs de valeur pour les variables de configuration. C'est la superclasse abstraite pour les autres classes Lire::Config::Value.

new( ['spec' => $spec], ... )

C'est le constructeur pour l'objet de valeur. Les objets Lire::Config::Value devraient être instanciés à partir de la méthode instance() définie dans l'objet TypeSpec.

name()

Retourne le nom de ce paramètre de configuration.

spec()

Retourne la spécification pour ce paramètre.

summary()

Retourne le résumé de la spécification pour cette valeur.

description()

Retourne la description de la spécification pour cette valeur.

text_description()

Retourne la description de la spécification (formatée en texte brut) pour cette valeur.

as_value()

Retourne cette valeur sous forme de valeur native perl. Ce sera soit une valeur scalaire, soit une référence de tableau ou de hachage. Les valeurs retournées doivent être normalisées.

as_label()

Retourne le libellé de cet objet pour affichage dans les interfaces graphiques.

as_shell_var()

Retourne la valeur de cette variable de configuration sous une forme qui peut être évaluée dans un script shell.

clone()

Retourne une copie profonde de cette instance. La référence à la spécification est conservée mais n'est pas copiée.

is_equals( $param )

Retourne si l'instance $param est identique à celle-ci.

is_valid()

Vérifie que la valeur actuelle est valide selon la spécification.

is_default()

Retourne vrai si cette valeur est égale à la valeur par défaut de sa spécification.

save_xml( $fh )

Écrit une configuration XML de la variable récursivement sur $fh.
