NOM

Locale::Codes::LangExt - module pour gérer les ensembles de codes langext

SYNOPSIS

use Locale::Codes::LangExt;
$name = code2langext(CODE);
$code = langext2code(NAME);
@codes   = all_langext_codes();
@names   = all_langext_names();

DESCRIPTION

Ce module fournit un accès aux ensembles de codes langext.

Veuillez vous référer au document Locale::Codes::Types pour une description des ensembles de codes disponibles.

La plupart des routines prennent un argument supplémentaire optionnel qui spécifie l'ensemble de codes à utiliser. L'ensemble de codes peut être spécifié en utilisant le nom d'un ensemble de codes, ou la constante perl spécifiée dans le document ci-dessus. S'il n'est pas spécifié, l'ensemble de codes par défaut sera utilisé.

ROUTINES

Toutes les routines de ce module appellent la méthode appropriée dans le module Locale::Codes, en utilisant un objet de type : langext Veuillez vous référer à la documentation du module Locale::Codes pour plus de détails sur chaque fonction.

Les fonctions suivantes sont exportées automatiquement :

code2langext(CODE [,CODESET] [,'retired'])
Voir code2name dans Locale::Codes
code2langexts(CODE [,CODESET])
Voir code2names dans Locale::Codes
langext2code(NAME [,CODESET] [,'retired'])
Voir name2code dans Locale::Codes
langext_code2code(CODE ,CODESET ,CODESET2)
Voir code2code dans Locale::Codes
all_langext_codes([CODESET] [,'retired'])
Voir all_codes dans Locale::Codes
all_langext_names([CODESET] [,'retired'])
Voir all_names dans Locale::Codes

Les fonctions suivantes ne sont pas exportées et doivent être appelées entièrement qualifiées avec le nom du package :

Locale::Codes::Langext::show_errors(FLAG)
Par défaut, une entrée invalide produira des résultats vides, mais aucune erreur. En passant une valeur non nulle pour FLAG, des erreurs seront produites.

Voir show_errors dans Locale::Codes, mais notez que par défaut, les modules non-OO NE produisent PAS d'erreurs.

Locale::Codes::Langext::rename_langext(CODE ,NEW_NAME [,CODESET])
Voir rename_code dans Locale::Codes
Locale::Codes::Langext::add_langext(CODE ,NAME [,CODESET])
Voir add_code dans Locale::Codes
Locale::Codes::Langext::delete_langext(CODE [,CODESET])
Voir delete_code dans Locale::Codes
Locale::Codes::Langext::add_langext_alias(NAME ,NEW_NAME)
Voir add_alias dans Locale::Codes
Locale::Codes::Langext::delete_langext_alias(NAME)
Voir delete_alias dans Locale::Codes
Locale::Codes::Langext::rename_langext_code(CODE ,NEW_CODE [,CODESET])
Voir replace_code dans Locale::Codes
Locale::Codes::Langext::add_langext_code_alias(CODE ,NEW_CODE [,CODESET])
Voir add_code_alias dans Locale::Codes
Locale::Codes::Langext::delete_langext_code_alias(CODE [,CODESET])
Voir delete_code_alias dans Locale::Codes
