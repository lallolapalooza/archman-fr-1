NOM Documentation Perl contribuée par l'utilisateur Locale::RecodeData::EBCDIC_ES_S(3)

NOM

Locale::RecodeData::EBCDIC_ES_S - Routines de conversion pour EBCDIC_ES_S

SYNOPSIS

Ce module est interne à libintl. Ne l'utilisez pas directement !

DESCRIPTION

Ce module contient les tables de conversion et routines pour EBCDIC-ES-S.

COMMENTAIRES

Les observations suivantes ont été extraites du charmap d'origine :

version: 1.0
 source: IBM 3270 Char Set Ref Ch 10, GA27-2837-9, avril 1987

Note : Les alias mentionnés ci-dessus ne sont pas nécessairement valides !
