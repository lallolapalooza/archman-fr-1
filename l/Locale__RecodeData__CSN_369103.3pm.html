NAME

Locale::RecodeData::CSN_369103 - Rotines de recodage pour CSN_369103

SYNOPSIS

Ce module est interne à libintl. Ne l'utilisez pas directement !

DESCRIPTION

Ce module est généré et contient les tables de conversion et les rotines pour CSN_369103.

COMMENTS

Les commentaires suivants ont été extraits du charmap original :

version: 1.0
repertoiremap: mnemonic,ds
 source: ECMA registry
alias ISO-IR-139

Note : les alias mentionnés ci-dessus ne sont pas nécessairement valides !

NAME


Locale::RecodeData::CSN_369103 - Recode support for ISO-8859-15






SYNOPSIS


    require Locale::RecodeData::CSN_369103;







DESCRIPTION


This module provides the recode mapping for the CSN_369103
    character set, also known as ISO-8859-15.


It is intended for use by the Locale::Recode(3)
    module.






COMMENTS


The character set is a variant of ISO-8859-1 (Latin-1) that includes
    the Euro currency symbol ($) in place of the
    fractional sign (₠) at code point 0xA0.
