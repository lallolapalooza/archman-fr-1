Lingua::EN::Numbers::Ordinate(3) Documentation Perl fournie par l'utilisateur Lingua::EN::Numbers::Ordinate(3)

NOM

Lingua::EN::Numbers::Ordinate -- passe du nombre cardinal (3) à l'ordinal ("3rd")

SYNOPIS

use Lingua::EN::Numbers::Ordinate;
print ordinate(4), "\n";
 # imprime 4th
print ordinate(-342), "\n";
 # imprime -342nd
# Exemple d'utilisation réelle :
...
for(my $i = 0; $i < @records; $i++) {
  unless(is_valid($record[$i]) {
    warn "Le ", ordinate($i), " enregistrement est invalide !\n"; 
    next;
  }
  ...
}

DESCRIPTION

Il existe deux types de nombres en anglais -- les cardinaux (1, 2, 3...), et les ordinaux (1st, 2nd, 3rd...). Cette librairie fournit des fonctions pour obtenir la forme ordinale d'un nombre, étant donné sa valeur cardinale.

FONCTIONS

ordinate(SCALAR)
Retourne une chaîne de caractères composée de la forme de cette scalaire, plus le suffixe ordinal approprié. Exemple : ordinate(23) retourne "23rd".

Comme cas spécial, ordinate(undef) et ordinate("") retournent "0th", et non "th".

Cette fonction est exportée par défaut.

th(SCALAR)
Est simplement un alias pour "ordinate", mais n'est pas exporté par défaut.
ordsuf(SCALAR)
Retourne seulement le suffixe ordinal approprié pour la valeur numérique scalaire donnée. C'est ce que "ordinate" utilise pour faire son travail. Par exemple, ordsuf(3) est "rd".

N'est pas exporté par défaut.

Les fonctions ci-dessus sont toutes prototypées pour prendre une valeur scalaire, donc ordinate(@stuff) est la même chose que "ordinate(scalar @stuff)".

CAVEATS

* Notez que cette librairie ne connaît que les nombres, pas les mots représentant des nombres. ordinate('seven') pourrait tout aussi bien être ordinate('superglue') ou ordinate("\x1E\x9A") -- vous obtiendrez le cas de repli de la chaîne d'entrée plus "th".

* Comme il est inévitable, ordinate(0256) retourne "174th" (parce que ordinate voit la valeur 174). De même, ordinate(1E12) retourne "1000000000000th". Retourner "trillionth" serait bien, mais c'est un cas extrêmement atypique.

* Notez que l'algorithme de cette librairie (ainsi que le concept de base et l'implémentation des nombres ordinaux) est totalement spécifique à la langue.

Pour prendre un exemple trivial, considérez qu'en français, 1 se classe comme "1ier", alors que 41 se classe comme "41ieme".

VOIR AUSSI

Lingua::EN::Inflect fournit une fonction "ORD", qui retourne la forme ordinale d'un nombre cardinal.

Lingua::EN::Number::IsOrdinal fournit une fonction "is_ordinal", qui retourne vrai si un nombre ordinal est passé.

Lingua::EN::Numbers fournit la fonction num2en_ordinal() qui prendra un nombre et retournera l'ordinal sous forme de mot. Ainsi, 3 résultera en "third".
