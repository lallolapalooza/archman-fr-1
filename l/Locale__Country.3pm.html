NOM

Locale::Country - module pour gérer les ensembles de codes de pays

SYNTAXE

use Locale::Country;
$nom = code2pays(CODE);
$code = pays2code(NOM);
@codes   = all_country_codes();
@names   = all_country_names();

DESCRIPTION

Ce module fournit un accès aux ensembles de codes de pays.

Veuillez vous référer au document Locale::Codes::Types pour une description des ensembles de codes disponibles.

La plupart des routines prennent un argument supplémentaire optionnel qui spécifie l'ensemble de codes à utiliser. L'ensemble de codes peut être spécifié en utilisant le nom d'un ensemble de codes, ou la constante perl spécifiée dans le document ci-dessus. S'il n'est pas spécifié, l'ensemble de codes par défaut sera utilisé.

ROUTINES

Toutes les routines de ce module appellent la méthode appropriée dans le module Locale::Codes, en utilisant un objet de type : pays. Veuillez vous référer à la documentation du module Locale::Codes pour les détails sur chaque fonction.

Les fonctions suivantes sont exportées automatiquement :

code2pays(CODE [,CODESET] [,'retired'])
Voir code2name dans Locale::Codes
code2payss(CODE [,CODESET])
Voir code2names dans Locale::Codes
pays2code(NOM [,CODESET] [,'retired'])
Voir name2code dans Locale::Codes
pays_code2code(CODE ,CODESET ,CODESET2)
Voir code2code dans Locale::Codes
tous_les_codes_pays([CODESET] [,'retired'])
Voir all_codes dans Locale::Codes
tous_les_noms_pays([CODESET] [,'retired'])
Voir all_names dans Locale::Codes

Les fonctions suivantes ne sont pas exportées et doivent être appelées en spécifiant le nom du paquet :

Locale::Country::afficher_erreurs(FLAG)
Par défaut, une entrée invalide produira un résultat vide, mais aucune erreur. En passant une valeur non nulle de FLAG, des erreurs seront produites.

Voir show_errors dans Locale::Codes, mais noter que par défaut les modules non-OO ne produisent PAS d'erreurs.

Locale::Country::renommer_pays(CODE ,NOUVEAU_NOM [,CODESET])
Voir rename_code dans Locale::Codes
Locale::Country::ajouter_pays(CODE ,NOM [,CODESET])
Voir add_code dans Locale::Codes
Locale::Country::supprimer_pays(CODE [,CODESET])
Voir delete_code dans Locale::Codes
Locale::Country::ajouter_alias_pays(NOM ,NOUVEAU_NOM)
Voir add_alias dans Locale::Codes
Locale::Country::supprimer_alias_pays(NOM)
Voir delete_alias dans Locale::Codes
Locale::Country::renommer_code_pays(CODE ,NOUVEAU_CODE [,CODESET])
Voir replace_code dans Locale::Codes
Locale::Country::ajouter_alias_code_pays(CODE ,NOUVEAU_CODE [,CODESET])
Voir add_code_alias dans Locale::Codes
Locale::Country::supprimer_alias_code_pays(CODE [,CODESET])
Voir delete_code_alias dans Locale::Codes
