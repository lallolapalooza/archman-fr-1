LWP::RobotUA(3) Documentation Perl fournie par l'utilisateur LWP::RobotUA(3)

NOM

LWP::RobotUA - une classe pour les robots Web bien élevés

SYNOPIS

use LWP::RobotUA;
my $ua = LWP::RobotUA->new('my-robot/0.1', 'me@foo.com');
$ua->delay(10);  # être très gentil -- maximum un appel toutes les dix minutes !
...
# Ensuite, utilisez-le comme un LWP::UserAgent normal :
my $response = $ua->get('http://whatever.int/...');
...

DESCRIPTION

Cette classe implémente un agent utilisateur adapté aux applications de robot. Les robots doivent être courtois envers les serveurs qu'ils visitent. Ils doivent consulter le fichier /robots.txt pour s'assurer qu'ils sont les bienvenus et ne pas effectuer de requêtes trop fréquemment.

Mais avant d'envisager d'écrire un robot, jetez un œil à http://www.robotstxt.org/.

Lorsque vous utilisez un objet LWP::RobotUA comme agent utilisateur, vous n'avez pas vraiment à y penser vous-même ; les fichiers "robots.txt" sont automatiquement consultés et respectés, le serveur n'est pas interrogé trop rapidement, etc. Envoyez simplement des requêtes comme vous le feriez avec un objet LWP::UserAgent normal (en utilisant "$ua->get(...)", "$ua->head(...)", "$ua->request(...)", etc.), et cet agent spécial s'assurera que vous êtes courtois.

MÉTHODES

LWP::RobotUA est une sous-classe de LWP::UserAgent et implémente les mêmes méthodes. En outre, les méthodes suivantes sont fournies :

new

my $ua = LWP::RobotUA->new( %options )
my $ua = LWP::RobotUA->new( $agent, $from )
my $ua = LWP::RobotUA->new( $agent, $from, $rules )

Les options LWP::UserAgent "agent" et "from" sont obligatoires. Les options "delay", "use_sleep" et "rules" initialisent des attributs privés au RobotUA. Si "rules" n'est pas fourni, alors WWW::RobotRules est instancié, fournissant une base de données interne de robots.txt.

Il est également possible de simplement passer la valeur de "agent", "from" et optionnellement "rules" comme arguments positionnels simples.

delay

my $delay = $ua->delay;
$ua->delay( $minutes );

Obtenir/définir le délai minimum entre les requêtes au même serveur, en minutes. La valeur par défaut est de 1 minute. Notez que ce nombre n'a pas besoin d'être un entier ; par exemple, ceci définit le délai à 10 secondes :

$ua->delay(10/60);

use_sleep

my $bool = $ua->use_sleep;
$ua->use_sleep( $boolean );

Obtenir/définir une valeur indiquant si l'agent utilisateur doit "dormir" dans LWP::RobotUA si les requêtes arrivent trop rapidement, défini comme $ua->delay minutes non écoulées depuis la dernière requête au serveur donné. La valeur par défaut est vraie. Si cette valeur est fausse, une réponse interne "SERVICE_UNAVAILABLE" sera générée. Elle aura un en-tête "Retry-After" qui indiquera quand il sera acceptable d'envoyer une autre requête à ce serveur.

rules

my $rules = $ua->rules;
$ua->rules( $rules );

Définir/obtenir quel objet WWW::RobotRules utiliser.

no_visits

my $num = $ua->no_visits( $netloc )

Retourne le nombre de documents récupérés sur cet hôte serveur. Oui, je sais, cette méthode aurait probablement dû être nommée "num_visits" ou quelque chose de similaire. :-(

host_wait

my $num = $ua->host_wait( $netloc )

Retourne le nombre de secondes (à partir de maintenant) que vous devez attendre avant de pouvoir faire une nouvelle requête à cet hôte.

as_string

my $string = $ua->as_string;

Retourne une chaîne décrivant l'état de l'agent utilisateur. Principalement utile pour le débogage.

VOIR AUSSI

LWP::UserAgent, WWW::RobotRules
