NOM

Lire::OutputJob - Objet utilisé pour représenter une mise en forme configurée d'un rapport

SYNOPSIS

use Lire::OutputJob;
use Lire::OutputFormat;
my $email = new Lire::OutputJob( 'email', $output, $output_cfg,
                                 'emails' => [ 'email@domain.org' ] );
$email->run( 'report.xml' );
my $file = new Lire::OutputJob( 'file', $output, $output_cfg,
                                'filename' => '/var/www/reports/daily-%Y%m%d'  );
$file->run( 'report.xml' );

DESCRIPTION

Les objets Lire::OutputJob sont utilisés pour représenter comment un rapport doit être formaté. Ces objets sont le plus souvent créés à partir de la configuration de Lire. (La spécification 'output_jobs'.)

new( $type_de_destination, $format, $cfg_de_format, ... );

Crée un nouvel objet Lire::OutputJob. Deux paramètres sont requis :

$type_de_destination
Peut être soit 'email', soit 'file'.
$format
Un objet Lire::OutputFormat.
$cfg_de_format
Les données de configuration qui seront passées à l'objet OutputFormat.

La méthode retourne une instance de Lire::EmailOutputJob ou de Lire::FileOutputJob.

format

Retourne le Lire::OutputFormat associé à ce OutputJob.

format_cfg

Retourne les données de configuration qui seront utilisées lors du formatage du rapport.

run( $fichier_de_rapport )

Formate et envoie ou sauvegarde le rapport XML $fichier_de_rapport selon les paramètres de l'OutputJob.

Lire::EmailOutputJob

Paramètres supplémentaires pour le type 'email'

emails
Une référence de tableau vers les adresses e-mail qui recevront le rapport formaté.
sujet
L'objet de l'e-mail.
fichier_supplementaire
Un fichier texte supplémentaire qui sera joint au rapport texte ou attaché à d'autres types de rapports.

emails()

Retourne sous forme de tableau les adresses e-mail auxquelles le rapport sera envoyé.

subject()

Retourne l'objet de l'e-mail.

extra_file()

Retourne le nom du fichier qui sera joint au rapport texte ou attaché au message pour les autres types de rapports.

Lire::FileOutputJob

Paramètres supplémentaires pour le type 'file'.

fichier
Un chemin de fichier avec une interpolation possible de strftime(3pm). C'est là que le rapport formaté sera sauvegardé.

file()

Retourne le fichier de destination de ce OutputJob.

output_file( [$temps] )

Retourne le fichier de destination avec les spécificateurs strftime(3) interpolés.
