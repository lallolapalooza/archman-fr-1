NOM

Lire::Test::CommandResult - Objet utilisé pour rapporter les résultats des commandes shell

SYNTAXE

use Lire::Test::FunctionalTestCase;
my $result = $self->lire_run( "echo Test" );
print $result->status();
print $result->stdout();
print $result->stderr();
print scalar $result->sent_mail(), " emails ont été envoyés.\n";

DESCRIPTION

Les objets Lire::Test::ComandResult sont utilisés pour rapporter les résultats des commandes shell exécutées via Lire::Test::FunctionalTestCase::lire_run().

command()

Retourne la commande shell qui a été exécutée. Il s'agit de la ligne de commande complète qui a été interprétée par le shell.

status()

Retourne le statut de résultat de la commande. (Ce qui est généralement contenu dans $?).

stdout()

Retourne ce qui a été affiché sur la sortie standard (stdout) pendant l'exécution de la commande.

stderr()

Retourne ce qui a été affiché sur la sortie d'erreur (stderr) pendant l'exécution de la commande.

sent_mail()

Retourne dans une référence de tableau les messages qui ont été envoyés pendant l'exécution de cette commande. Les éléments de ce tableau sont des références de hachage contenant deux clés :

recipients
Une référence de tableau contenant les destinataires tels qu'ils ont été passés sur la ligne de commande à sendmail.
message
L'e-mail qui a été envoyé. C'est le texte complet de l'e-mail. C'est ce qui a été passé à sendmail via STDIN.
