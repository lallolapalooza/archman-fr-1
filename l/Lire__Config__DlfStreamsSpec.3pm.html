NOM

Lire::Config::DlfStreamsSpec - Contient la configuration DlfStream.

DESCRIPTION

Ce Lire::Config::TypeSpec est un ListSpec qui définit virtuellement un Lire::Config::DlfStreamSpec pour chaque schéma disponible.

Cette sous-classe de ListSpec surcharge les méthodes has_component() et get() pour rendre disponible un Lire::Config::DlfStreamSpec pour chaque schéma défini.

VOIR AUSSI

Lire::Config::DlfStreamsSpec(3pm), Lire::Config::DlfAnalyserSpec(3pm)
