NOM

Lire::ReportSection - API pour déclarer la section de configuration

SYNTAXE

use Lire::ReportConfig;
use Lire::ReportSection;
my $report_cfg = new Lire::ReportConfig( "www" );
my $section = new Lire::ReportSection( "www", "Général" );
$report_cfg->add_section( $section );

DESCRIPTION

Cette classe offre une API orientée objet pour déclarer la section de configuration. Elle offre des méthodes pour accéder et modifier les attributs de la section.

CONSTRUCTEUR

new( $superservice, [$titre] )

Crée un nouvel objet Lire::Section qui contiendra les spécifications de rapport du super-service $superservice. Le titre de la section sera défini à la valeur de $titre.

MÉTHODES OBJET

superservice()

Retourne le super-service de cette section.

titre([$titre])

Retourne le titre actuel de la section.

Lorsque le paramètre $titre est utilisé, il définira le titre de la section à une nouvelle valeur.

filtres()

Retourne les spécifications de filtre de cette section sous forme d'un tableau d'objets Lire::FilterSpec. Ces spécifications de filtre seront utilisées par toutes les spécifications de rapport de cette section en plus de la spécification de filtre qu'elles pourraient déjà utiliser.

ajouter_filtre($spec_filtre)

Ajoute la spécification de filtre $spec_filtre à cette section. Le paramètre $spec_filtre doit être une instance de Lire::FilterSpec ou l'un de ses descendants.

Cette méthode mourra si le schéma de la spécification de filtre n'est pas compatible avec le super-service de cette section.

rapports()

Retourne les spécifications de rapport de cette section sous forme d'un tableau d'objets Lire::ReportSpec.

ajouter_rapport( $spec_rapport )

Ajoute la spécification de rapport $spec_rapport à cette section. Cette méthode mourra si le schéma de la spécification de rapport n'est pas compatible avec le super-service de cette section.
