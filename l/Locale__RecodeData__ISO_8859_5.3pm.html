NOM

Locale::RecodeData::ISO_8859_5 - Routines de conversion pour ISO-8859-5

SYNTAXE

Ce module est interne à libintl. Ne pas utiliser directement !

DESCRIPTION

Ce module contient les tables de conversion et les routines pour ISO-8859-5.

COMMENTAIRES

Les commentaires suivants ont été extraits du charmap original :

version: 1.0
 source: ECMA registry
 alias: ISO-IR-144
 alias: ISO_8859-5:1988
 alias: ISO_8859-5
 alias: CYRILLIC

Note : les alias mentionnés ci-dessus ne sont pas nécessairement valides !
