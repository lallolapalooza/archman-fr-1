NOM

Lire::Config::Index - Registre et interface de configuration

SYNTAXE

use base qw/Lire::Config::Index/;
sub has_entry { my ($self, $name) = @_; ... }
sub entries { my $self = $_[0]; ... }
sub get_ref { my ($self, $name) = @_; ... }

DESCRIPTION

L'interface Lire::Config::Index est utilisée par Lire::Config::ReferenceSpec(3pm) pour valider et obtenir les objets référencés.

REGISTRE DE CONFIGURATION

Ce sont les méthodes de classe utilisées pour enregistrer et obtenir des objets Index.

has_index( $name )

Retourne vrai si une configuration a été enregistrée sous le nom $name.

get_index( $name )

Retourne l'index nommé $name. Provoque une erreur si aucun index de ce nom n'a été enregistré.

set_index( $name, $index )

Enregistre $index sous le nom $name. Remplace toute configuration précédente enregistrée sous le même nom.

INTERFACE DE CONFIGURATION

has_entry( $name )

Doit retourner vrai si $name est défini dans cette configuration.

entries()

Doit retourner toutes les entrées définies dans la configuration.

get_ref( $name )

Doit retourner l'objet indexé sous le nom $name. Une erreur doit être déclenchée s'il n'y a pas d'entrée correspondante.
