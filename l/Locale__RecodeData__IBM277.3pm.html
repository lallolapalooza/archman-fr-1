NAME

Locale::RecodeData::IBM277 - Routines de conversion pour IBM277

SYNOPSIS

Ce module est interne à libintl. Ne l'utilisez pas directement !

DESCRIPTION

Ce module contient les tables de conversion et les routines pour IBM277.

COMMENTS

Les remarques suivantes sont extraites du charmap d'origine :

 version: 1.0
 source: IBM NLS RM Vol2 SE09-8002-01, mars 1990
 alias EBCDIC-CP-DK
 alias EBCDIC-CP-NO

Note : les alias mentionnés ci-dessus ne sont pas nécessairement valides !
