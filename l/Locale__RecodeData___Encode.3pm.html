Locale::RecodeData::_Encode(3) Documentation Perl fournie par l'utilisateur Locale::RecodeData::_Encode(3)

NOM

Locale::RecodeData::_Encode - Enveloppe interne autour d'Encode

SYNTAXE

use Locale::RecodeData::_Encode;

Ce module est interne à libintl. Ne l'utilisez pas directement !

DESCRIPTION

Ce module convertit le texte à l'aide d'Encode(3). Il est essayé en premier pour les conversions si libintl-perl détecte la présence d'Encode.
