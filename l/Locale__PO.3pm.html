NOM Documentation contribuée par Perl Locale::PO(3)

NOM

Locale::PO - Module Perl pour manipuler les entrées .po de GNU gettext

SYNTAXE

use Locale::PO;
$po = new Locale::PO([-option=>value,...])
[$string =] $po->msgid([new string]);
[$string =] $po->msgstr([new string]);
[$string =] $po->comment([new string]);
[$string =] $po->automatic([new string]);
[$string =] $po->reference([new string]);
[$value =] $po->fuzzy([value]);
[$value =] $po->add_flag('c-format');
print $po->dump;
$quoted_string = $po->quote($string);
$string = $po->dequote($quoted_string);
$aref = Locale::PO->load_file_asarray(<filename>,[encoding]);
$href = Locale::PO->load_file_ashash(<filename>,[encoding]);
Locale::PO->save_file_fromarray(<filename>,$aref,[encoding]);
Locale::PO->save_file_fromhash(<filename>,$href,[encoding]);

DESCRIPTION

Ce module simplifie la gestion des fichiers .po de GNU gettext et est une alternative à l'utilisation du mode po d'emacs. Il fournit une interface orientée objet où chaque entrée dans un fichier .po est un objet Locale::PO.

MÉTHODES

new
my Locale::PO $po = new Locale::PO;
my Locale::PO $po = new Locale::PO(%options);

Crée un objet Locale::PO pour représenter une entrée po. Il est possible de définir les propriétés de l'entrée en passant une liste/hash de la forme :

-option=>value, -option=>value, etc.

Où les options sont msgid, msgid_plural, msgstr, msgctxt, comment, automatic, reference, fuzzy_msgctxt, fuzzy_msgid, fuzzy_msgid_plural, fuzzy, et c-format. Voir les méthodes d'accès aux attributs mentionnées.

Pour générer un en-tête po, ajoutez une entrée avec un msgid vide, comme ceci :

$po = new Locale::PO(-msgid=>'', -msgstr=>
        "Project-Id-Version: PACKAGE VERSION\\n" .
        "PO-Revision-Date: YEAR-MO-DA HO:MI +ZONE\\n" .
        "Last-Translator: FULL NAME <EMAIL@ADDRESS>\\n" .
        "Language-Team: LANGUAGE <LL@li.org>\\n" .
        "MIME-Version: 1.0\\n" .
        "Content-Type: text/plain; charset=CHARSET\\n" .
        "Content-Transfer-Encoding: ENCODING\\n");
msgid
Définit ou obtient la chaîne non traduite de l'objet.
msgid_plural
Définit ou obtient la chaîne plurielle non traduite de l'objet.
msgstr
Définit ou obtient la chaîne traduite de l'objet.
msgstr_n
Obtient ou définit les traductions lorsqu'il y a des pluriels impliqués. Prend et renvoie un hashref où les clés sont le cas 'N' et les valeurs sont les chaînes. Par exemple :
$po->msgstr_n(
    {
        0 => 'found %d plural translations',
        1 => 'found %d singular translation',
    }
);

Cette méthode attend les nouvelles chaînes non quotées mais renvoie les chaînes actuelles sous forme quotée.

msgctxt
Définit ou obtient la chaîne de contexte de traduction de l'objet.
fuzzy_msgid
Définit ou obtient la chaîne non traduite de l'objet.
fuzzy_msgid_plural
Définit ou obtient la chaîne plurielle non traduite de l'objet.
fuzzy_msgctxt
Définit ou obtient la chaîne de contexte de traduction non traduite de l'objet.
obsolete
Renvoie 1 si l'entrée est obsolète. Les entrées obsolètes ont leurs lignes msgid, msgid_plural, msgstr, msgstr_n et msgctxt commentées avec "#~".

Lors de l'utilisation de load_file_ashash, les entrées non obsolètes remplacent toujours les entrées obsolètes ayant le même msgid.

comment
Définit ou obtient les commentaires de traduction de l'objet.
automatic
Définit ou obtient les commentaires automatiques de l'objet (insérés par emacs po-mode ou xgettext).
reference
Définit ou obtient les balises de référence de l'objet (insérées par emacs po-mode ou gettext).
fuzzy
Définit ou obtient le drapeau fuzzy sur l'objet ("vérifier cette traduction"). Lors de la définition, utilisez 1 pour activer le drapeau et 0 pour le désactiver.
c_format
Définit ou obtient le drapeau c-format ou non-c-format sur l'objet.
php_format
Définit ou obtient le drapeau php-format ou non-php-format sur l'objet.
has_flag
if ($po->has_flag('perl-format')) {
        ...
}

Renvoie vrai si le drapeau existe sur la ligne #~ de l'entrée.

add_flag
$po->add_flag('perl-format');

Ajoute le drapeau à la ligne #~ de l'entrée.

remove_flag
$po->remove_flag('perl-format');

Supprime le drapeau de la ligne #~ de l'entrée.

loaded_line_number
Lors de l'utilisation de l'une des méthodes load_file_as*, cette fonction renverra le numéro de ligne où l'entrée a commencé dans le fichier.
dump
Renvoie l'entrée sous forme de chaîne appropriée pour être écrite dans un fichier po.
quote
Applique les règles de mise entre guillemets de po à une chaîne et renvoie la chaîne mise entre guillemets. La chaîne mise entre guillemets aura tous les caractères de double guillemet échappés par des barres obliques inverses et sera entourée de doubles guillemets.
dequote
Renvoie une chaîne mise entre guillemets de po dans sa forme naturelle.
load_file_asarray
Prend le nom d'un fichier po en paramètre, lit le fichier et renvoie une référence à une liste d'objets Locale::PO correspondant au contenu du fichier, dans le même ordre. Un paramètre optionnel de type encodage (par exemple, "utf8") est accepté, qui définit comment le flux d'entrée du fichier po sera configuré.
load_file_ashash
Prend le nom d'un fichier po en paramètre, lit le fichier et renvoie une référence à un hash d'objets Locale::PO correspondant au contenu du fichier, dans le même ordre. Un paramètre optionnel de type encodage (par exemple, "utf8") est accepté, qui définit comment le flux d'entrée du fichier po sera configuré.

NOM

Module : Locale::PO

SYNOPSIS

Utilisez le module Locale::PO pour gérer les fichiers de traduction au format PO.

DESCRIPTION

Le module Locale::PO gère les fichiers de traduction au format PO. Les clés de hachage sont les chaînes non traduites, permettant une suppression efficace des doublons. La méthode privilégie le maintien des entrées traduites. Un paramètre optionnel 'encoding' (par exemple, « utf8 ») est accepté et définit comment le flux d'entrée du fichier PO sera configuré.

MÉTHODES

Les méthodes incluent :

  • save_file_fromarray
  • save_file_fromhash

La méthode save_file_fromarray enregistre les objets Locale::PO dans un fichier PO, en en créant un s'il n'existe pas. Un paramètre optionnel 'encoding' (par exemple, « utf8 ») est accepté et définit comment le flux de sortie du fichier PO sera configuré.

La méthode save_file_fromhash enregistre les objets Locale::PO dans un fichier PO, en en créant un s'il n'existe pas. Les entrées sont triées par ordre alphabétique selon la chaîne non traduite. Un paramètre optionnel 'encoding' (par exemple, « utf8 ») est accepté et définit comment le flux de sortie du fichier PO sera configuré.

BOGUES

Si un fichier est chargé avec load_file_as* et enregistré avec save_file_from*, le fichier de sortie peut présenter des différences cosmétiques (une ligne vide supplémentaire).

msgid, msgid_plural, msgstr, msgstr_n et msgctxt attendent une chaîne non citée en entrée, mais retournent des chaînes citées. Je suis indécis quant à la modification de ce comportement par crainte de casser des modules/scripts d'utilisateurs utilisant déjà Locale::PO.

Locale::PO requiert des lignes vides entre les entrées, mais les fichiers PO de style Uniforum n'en ont pas.

Veuillez soumettre tous les rapports de bogues via le système de tickets de CPAN.
