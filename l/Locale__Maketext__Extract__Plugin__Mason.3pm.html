NOM

Locale::Maketext::Extract::Plugin::Mason - Analyseur de format HTML::Mason (dit Mason 1) et Mason (dit Mason 2)

VERSION

version 1.00

SYNOPSIS

$plugin = Locale::Maketext::Extract::Plugin::Mason->new(
    $lexicon            # Un objet Locale::Maketext::Extract
    @file_types         # Facultatif : spécifier une liste de types de fichiers reconnus
)
$plugin->extract($filename,$filecontents);

DESCRIPTION

Extrait les chaînes à localiser des fichiers Mason.

NOM COURT DU PLUGIN

mason

FORMATS VALIDES

HTML::Mason (dit Mason 1)
Les chaînes dans <&|/l>...</&> et <&|/loc>...</&> sont extraites.

Mason (dit Mason 2) Les chaînes dans <% $.floc { %>...</%> ou <% $.fl { %>...</%> ou <% $self->floc { %>...</%> ou <% $self->fl { %>...</%> sont extraites.

TYPES DE FICHIERS CONNUS

Tous les types de fichiers
