NOM

Locale::RecodeData::IBM861 - Routines de conversion pour IBM861

SYNOPIS

Ce module est interne à libintl. Ne l'utilisez pas directement !

DESCRIPTION

Ce module contient les tables de conversion et les routines pour IBM861.

COMMENTAIRES

Les observations suivantes ont été extraites du charmap d'origine :

version : 1.0
 source : IBM NLS RM Vol2 SE09-8002-01, Mars 1990
 alias CP861
 alias 861
 alias CP-IS

Note : Les alias mentionnés ci-dessus ne sont pas nécessairement valides !
