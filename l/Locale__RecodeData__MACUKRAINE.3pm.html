Locale::RecodeData::MACUKRAINE(3pm)

NAME

Locale::RecodeData::MACUKRAINE - MAC Ukrainian codeset data

SYNOPSIS

    require Locale::RecodeData::MACUKRAINE;
    # or
    use Locale::RecodeData::MACUKRAINE;

DESCRIPTION

Locale::RecodeData::MACUKRAINE provides the character mappings for the MAC Ukrainian character set.

This module is part of the perl(1) manual set for character recoding.

It provides the following table definitions:

    MACCyrillic_Ukraine_2:1, MACCyrillic_Ukraine_2

The data is used by the Locale::Recode(3) module to convert between different character encodings.

COMMENTS

This module is intended for internal use by the Locale::Recode(3) module and should not be used directly.
