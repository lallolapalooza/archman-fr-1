NOM

Locale::RecodeData::IBM857 - Routines de conversion pour IBM857

SYNTAXE

Ce module est interne à libintl. Ne l'utilisez pas directement !

DESCRIPTION

Ce module généré contient les tables de conversion et les routines pour IBM857.

COMMENTAIRES

Les commentaires suivants ont été extraits du charmap original :

version: 1.0
 source: IBM NLS RM Vol2 SE09-8002-01, March 1990
 alias CP857
 alias 857

Note : les alias mentionnés ci-dessus ne sont pas nécessairement valides !
