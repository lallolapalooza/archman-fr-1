NAME


Locale::RecodeData::ISO_8859_15 - ISO 8859-15 mapping for Locale::Recode






SYNOPSIS


    use Locale::Recode;
    
    # Convert an ISO 8859-15 string to UTF-8
    my $utf8_string = Locale::Recode::decode('ISO_8859_15', $iso_string);
    
    # Convert a UTF-8 string to ISO 8859-15
    my $iso_string = Locale::Recode::encode('ISO_8859_15', $utf8_string);






DESCRIPTION


This module provides the mapping for the ISO 8859-15 character set for
    the Locale::Recode(3) module.


ISO 8859-15 is an extension of ISO 8859-1 of 1994, which contains
    the characters needed for most Western European languages. This includes
    most of the characters that were missing in ISO 8859-1, such as the euro
    sign (€), and a few other symbols.
