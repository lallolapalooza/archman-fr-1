NAME


Locale::RecodeData::IBM869 -- Données pour le codage IBM-869.






SYNOPSIS


 use Locale::RecodeData::IBM869;






DESCRIPTION


Ce module fournit les données nécessaires à la conversion de et vers le jeu de caractères IBM-869 (également connu sous le nom de DOS-869, WINS/GUI-869, ou des variantes grecques d'IBM). Ce codage était utilisé pour le grec dans les versions DOS de Microsoft Windows.


Il est utilisé par le module Locale::Recode(3) pour permettre la conversion de chaînes de caractères entre différents codages.






COMMENTS


Ce jeu de caractères couvre l'alphabet grec, ainsi que certains symboles et caractères de dessin de boîtes.
