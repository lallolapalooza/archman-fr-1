NOM

Lire::Config::DlfAnalyserSpec - PluginSpec pour sélectionner un analyseur.

DESCRIPTION

Ce Lire::Config::TypeSpec est un PluginSpec qui peut être utilisé pour sélectionner le DlfAnalyser qui doit être utilisé pour créer les enregistrements Dlf d'un schéma étendu ou dérivé.

new( 'nom' => $nom_flux_dst, ['src_schema' => $schema_src])

Le nom de la spécification de type est le nom du schéma pour lequel l'analyseur est sélectionné. Si le paramètre 'src_stream' est utilisé, seuls les analyseurs qui utilisent cette valeur comme leur src_schema() seront sélectionnés.

Le constructeur remplira automatiquement le PluginSpec avec les options disponibles et il définira le premier analyseur comme défaut.

src_schema()

Retourne le src_schema() qui doit être utilisé par le DlfAnalyser sélectionné. Si aucun schéma particulier n'est requis, undef sera retourné.

VOIR AUSSI

Lire::Config::PluginSpec(3pm), Lire::Config::DlfStreamSpec(3pm)
