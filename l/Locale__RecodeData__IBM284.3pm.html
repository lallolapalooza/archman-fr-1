NAME

Locale::RecodeData::IBM284 - Fonctions de conversion pour IBM284

SYNOPSIS

Ce module est interne à libintl. Ne l'utilisez pas directement !

DESCRIPTION

Ce module est généré et contient les tables de conversion et les routines pour IBM284.

COMMENTS

Les commentaires suivants ont été extraits du fichier charmap original :

version: 1.0
 source: IBM NLS RM Vol2 SE09-8002-01, March 1990
 alias CP284
 alias EBCDIC-CP-ES

Note : Les alias mentionnés ci-dessus ne sont pas nécessairement valides !

Locale::RecodeData::IBM284(3pm) -- Perl manual page

NAME

Locale::RecodeData::IBM284 - Perl module for character set conversion

SYNOPSIS

 use Locale::RecodeData::IBM284;

DESCRIPTION

This module provides the character mapping for the IBM284 (CP284) character set. It is used internally by the Locale::Recode module.

The IBM284 character set is a code page used on IBM mainframes.

COMMENTS

This module is not intended to be used directly by end users. It is a data provider for the Locale::Recode module.
