NOM

Locale::RecodeData::IBM256 - Routines de conversion pour IBM256

SYNOPIS

Ce module est interne à libintl. Ne pas utiliser directement !

DESCRIPTION

Ce module est généré et contient les tables et routines de conversion pour IBM256.

COMMENTAIRES

Les commentaires suivants ont été extraits de la table de caractères originale :

version: 1.0
 source: IBM Registry C-H 3-3220-050
alias EBCDIC-INT1

Veuillez noter que les alias listés ci-dessus ne sont pas nécessairement valides !
