NOM

Lire::OutputFormat - Interface de base pour tous les formats de sortie.

SYNTAXE

use base qw/ Lire::OutputFormat /;

DESCRIPTION

Les objets Lire::OutputFormat sont utilisés pour

Ce paquet définit l'interface qui est implémentée par les différents formats de sortie que Lire est capable de produire. C'est cet objet qui a la responsabilité de convertir le rapport XML dans son format final.

MÉTHODES D'INFORMATIONS MÉTADONNÉES

L'interface Lire::OutputFormat étend l'interface Lire::Plugin, ils doivent donc implémenter toutes les méthodes standard d'informations métadonnées (name(), title(), description()).

missing_requirements()

Cette méthode est interrogée à l'exécution pour déterminer si des exigences sont manquantes. Elle devrait retourner un tableau de messages expliquant chaque exigence manquante pour le format.

MISE EN FORME D'UN RAPPORT

format_report( $xml_file, $output_file, $format_cfg )

Cette méthode doit mettre en forme le rapport XML contenu dans $xml_file dans le fichier $output_file (ou répertoire). Des options de configuration supplémentaires sont passées dans l'objet Lire::Config::TypeSpec $format_cfg spécifique au plugin.

mime_report( $xml_file, $format_cfg )

Lorsque cette méthode est invoquée, le plugin doit mettre en forme le rapport contenu dans $xml_file et l'encapsuler MIME dans un objet MIME::Entity qui est retourné. Les options de mise en forme peuvent être dans l'objet Lire::Config::TypeSpec $format_cfg.
