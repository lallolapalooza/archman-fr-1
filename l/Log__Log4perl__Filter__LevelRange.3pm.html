NOM

Log::Log4perl::Filter::LevelRange - Filtre pour une plage de niveaux de journalisation

SYNOPSIS

log4perl.filter.Match1               = Log::Log4perl::Filter::LevelRange
log4perl.filter.Match1.LevelMin      = INFO
log4perl.filter.Match1.LevelMax      = ERROR
log4perl.filter.Match1.AcceptOnMatch = true

DESCRIPTION

Ce filtre personnalisé Log4perl vérifie si le message actuel a une priorité correspondant à une plage prédéfinie. Les paramètres "LevelMin" et "LevelMax" définissent les niveaux (choisir parmi "DEBUG", "INFO", "WARN", "ERROR", "FATAL") marquant la fenêtre des priorités de messages autorisées.

"LevelMin" est par défaut "DEBUG", et "LevelMax" est par défaut "FATAL".

Le paramètre supplémentaire "AcceptOnMatch" définit si le filtre doit accepter ou bloquer le message ("true" ou "false").
