NOM

Locale::gettext - fonctions de gestion des messages

SYNTAXE

use Locale::gettext;
use POSIX;     # Nécessaire pour setlocale()
setlocale(LC_MESSAGES, "");
# Interface orientée objet
my $d = Locale::gettext->domain("mon_programme");
print $d->get("Bienvenue dans mon programme"), "\n";
        # (affiché dans la langue locale)
# Accès direct aux fonctions C
textdomain("mon_programme");
print gettext("Bienvenue dans mon programme"), "\n";
        # (affiché dans la langue locale)

DESCRIPTION

Le module gettext permet d'accéder depuis perl aux fonctions de la famille gettext() pour récupérer des chaînes de messages à partir de bases de données construites pour internationaliser les logiciels.

$d = Locale::gettext->domain(DOMAINE)
$d = Locale::gettext->domain_raw(DOMAINE)
Crée un nouvel objet pour récupérer les chaînes dans le domaine DOMAINE et le retourne. "domain" demande que les chaînes soient retournées en tant que chaînes Perl (potentiellement avec des caractères larges) si possible, tandis que "domain_raw" demande des chaînes d'octets directement depuis des fonctions comme dgettext().
$d->get(MSGID)
Appelle dgettext() pour retourner la chaîne traduite pour le MSGID donné.
$d->cget(MSGID, CATEGORIE)
Appelle dcgettext() pour retourner la chaîne traduite pour le MSGID donné dans la CATÉGORIE donnée.
$d->nget(MSGID, MSGID_PLURIEL, N)
Appelle dngettext() pour retourner la chaîne traduite pour le MSGID ou MSGID_PLURIEL donné en fonction de N.
$d->ncget(MSGID, MSGID_PLURIEL, N, CATEGORIE)
Appelle dngettext() pour retourner la chaîne traduite pour le MSGID ou MSGID_PLURIEL donné en fonction de N dans la CATÉGORIE donnée.
$d->dir([NOUVDIR])
Si NOUVDIR est donné, appelle "bindtextdomain" pour définir le nom du répertoire où se trouvent les messages pour le domaine représenté par $d. Retourne le nom du répertoire actuel (potentiellement modifié).
$d->codeset([NOUVEAUCODE])
Pour les instances créées avec "Locale::gettext->domain_raw", manipule le jeu de caractères des chaînes retournées. Si NOUVEAUCODE est donné, appelle "bind_textdomain_codeset" pour définir l'encodage de caractères dans lequel les messages pour le domaine représenté par $d sont retournés. Retourne le nom de l'encodage actuel (potentiellement modifié).

gettext(), dgettext() et dcgettext() tentent de récupérer une chaîne correspondant à leur paramètre "msgid" dans le contexte de la locale actuelle. dcgettext() prend la catégorie du message et le domaine de texte comme paramètres, tandis que dgettext() utilise par défaut la catégorie LC_MESSAGES et gettext() utilise la catégorie LC_MESSAGES et le domaine de texte actuel. Si la chaîne n'est pas trouvée dans la base de données, alors "msgid" est retourné.

ngettext(), dngettext() et dcngettext() fonctionnent de manière similaire mais implémentent la différenciation des messages entre singulier et pluriel. Voir la documentation des fonctions C correspondantes pour plus de détails.

textdomain() définit le domaine de texte actuel et retourne le domaine précédemment actif.

bindtextdomain(domaine, dirname) demande aux fonctions de récupération de rechercher les bases de données appartenant au domaine "domaine" dans le répertoire "dirname".

bind_textdomain_codeset(domaine, codeset) demande aux fonctions de récupération de traduire les messages retournés vers l'encodage de caractères donné par codeset si l'encodage du catalogue de messages est connu.

NOTES

Tous les plateformes ne fournissent pas toutes les fonctions. Les fonctions qui ne sont pas disponibles dans la bibliothèque C sous-jacente ne seront pas disponibles en Perl non plus.

Les programmes Perl devraient utiliser l'interface objet. En plus de pouvoir retourner des chaînes Perl natives en caractères larges, "bind_textdomain_codeset" sera émulé si la bibliothèque C ne le fournit pas.
