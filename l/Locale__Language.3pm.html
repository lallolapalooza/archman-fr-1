NOM

Locale::Language - module pour gérer les ensembles de codes linguistiques

SYNTAXE

use Locale::Language;
$nom = code2language(CODE);
$code = language2code(NOM);
@codes   = all_language_codes();
@names   = all_language_names();

DESCRIPTION

Ce module fournit un accès aux ensembles de codes linguistiques.

Veuillez vous référer au document Locale::Codes::Types pour une description des ensembles de codes disponibles.

La plupart des routines acceptent un argument supplémentaire optionnel qui spécifie l'ensemble de codes à utiliser. L'ensemble de codes peut être spécifié en utilisant le nom d'un ensemble de codes, ou la constante perl spécifiée dans le document ci-dessus. S'il n'est pas spécifié, l'ensemble de codes par défaut sera utilisé.

ROUTINES

Toutes les routines de ce module appellent la méthode appropriée dans le module Locale::Codes, en utilisant un objet de type : language Veuillez vous référer à la documentation du module Locale::Codes pour des détails sur chaque fonction.

Les fonctions suivantes sont exportées automatiquement :

code2language(CODE [,CODESET] [,'retired'])
Voir code2name dans Locale::Codes
code2languages(CODE [,CODESET])
Voir code2names dans Locale::Codes
language2code(NOM [,CODESET] [,'retired'])
Voir name2code dans Locale::Codes
language_code2code(CODE ,CODESET ,CODESET2)
Voir code2code dans Locale::Codes
all_language_codes([CODESET] [,'retired'])
Voir all_codes dans Locale::Codes
all_language_names([CODESET] [,'retired'])
Voir all_names dans Locale::Codes

Les fonctions suivantes ne sont pas exportées et doivent être appelées en utilisant le nom complet du package :

Locale::Language::show_errors(FLAG)
Par défaut, une entrée invalide produira des résultats vides, mais aucune erreur. En passant une valeur non nulle pour FLAG, des erreurs seront produites.

Voir show_errors dans Locale::Codes mais notez que la valeur par défaut pour les modules non-OO est de NE PAS produire d'erreurs.

Locale::Language::rename_language(CODE ,Nouveau_NOM [,CODESET])
Voir rename_code dans Locale::Codes
Locale::Language::add_language(CODE ,NOM [,CODESET])
Voir add_code dans Locale::Codes
Locale::Language::delete_language(CODE [,CODESET])
Voir delete_code dans Locale::Codes
Locale::Language::add_language_alias(NOM ,Nouveau_NOM)
Voir add_alias dans Locale::Codes
Locale::Language::delete_language_alias(NOM)
Voir delete_alias dans Locale::Codes
Locale::Language::rename_language_code(CODE ,Nouveau_CODE [,CODESET])
Voir replace_code dans Locale::Codes
Locale::Language::add_language_code_alias(CODE ,Nouveau_CODE [,CODESET])
Voir add_code_alias dans Locale::Codes
Locale::Language::delete_language_code_alias(CODE [,CODESET])
Voir delete_code_alias dans Locale::Codes
