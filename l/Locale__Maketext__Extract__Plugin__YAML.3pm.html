NOM Documentation fournie par l'utilisateur Perl Locale::Maketext::Extract::Plugin::YAML(3)

NOM

Locale::Maketext::Extract::Plugin::YAML - Analyseur de fichiers YAML

VERSION

version 1.00

SYNOPSIS

$plugin = Locale::Maketext::Extract::Plugin::YAML->new(
    $lexicon            # Objet Locale::Maketext::Extract
    @file_types         # Optionnellement spécifier une liste de types de fichiers reconnus
)
$plugin->extract($filename,$filecontents);

DESCRIPTION

Extrait des chaînes pour la localisation à partir de fichiers YAML.

NOM COURT DU PLUGIN

yaml

FORMATS VALIDES

Les formats valides sont :

  • key: _"string"

  • key: _'string'

  • key: _'string avec des guillemets imbriqués 'guillemets''

  • key: |-
     _'ma chaîne repliée
     à traduire'

    Notez que le côté gauche de la chaîne repliée doit être aligné avec le "_", sinon YAML ajoutera des espaces au début de chaque ligne.

  •     key: |-
         _'ma chaîne
         de bloc
         à traduire
         '
Notez que vous devez utiliser le C<-> final pour que YAML n'ajoute pas de retour chariot après votre dernière guillemet.

TYPES DE FICHIERS CONNUS

.yaml
.yml
.conf

REQUIS

YAML

NOTES

La documentation du module YAML la décrit comme un code alpha. Elle n'est pas aussi tolérante aux erreurs que YAML::Syck. Cependant, étant en pur Perl, elle est facile à intégrer.

J'ai vu qu'elle entrait dans des boucles infinies, donc si xgettext.pl plante, essayez de le réexécuter avec "--verbose --verbose" (deux fois), pour voir si le problème vient de YAML. Si c'est le cas, corrigez le fichier source ou utilisez file_types pour exclure ce fichier.
