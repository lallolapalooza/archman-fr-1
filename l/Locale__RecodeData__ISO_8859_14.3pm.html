NOM

Locale::RecodeData::ISO_8859_14 - Routines de conversion pour ISO-8859-14

SYNTAXE

Ce module est interne à libintl. Ne pas utiliser directement !

DESCRIPTION

Ce module est généré automatiquement et contient les tables et routines de conversion pour ISO-8859-14.

COMMENTAIRES

Les commentaires suivants ont été extraits de la charmap originale :

automatiquement généré à partir de charDB
alias LATIN8
alias L8

Veuillez noter que les alias listés ci-dessus ne sont pas nécessairement valides !
