NOM

Lire::ImportJob - Objet utilisé pour représenter une source de données de logs

SYNTAXE

use Lire::ImportJob;
my $src = new Lire::ImportJob( "nom",
                               'pattern'    => "/var/log/messsages",
                               'period'     => "unique",
                               'processor'  => $name,
                              );
my $file = $src->file;

DESCRIPTION

L'objet Lire::ImportJob est utilisé pour représenter une source de données de logs. Il peut également être créé à partir de données de configuration (la spécification de configuration 'import_job').

new( $name, ... );

Crée un nouvel objet Lire::ImportJob. Il prend comme paramètre obligatoire le nom de la source de logs.

Paramètres supplémentaires :

pattern
Le chemin vers un fichier contenant les données de logs. Ce nom de fichier peut contenir des motifs strftime(3) qui seront substitués pour obtenir le nom du fichier. (Utile pour la rotation automatique).
period
La périodicité à laquelle ce ImportJob doit être traité. La valeur par défaut est 'unique', ce qui signifie qu'il s'agit d'un ImportJob à usage unique. Les autres valeurs reconnues sont 'hourly', 'daily', 'weekly', 'monthly' et 'yearly'.
converter
Le nom du convertisseur qui peut être utilisé pour traiter l'ImportJob. Il doit être connu de Lire::PluginManager.
converter_config
Paramètre de configuration pour le DlfConverter.
filter
Une commande shell qui sera utilisée pour filtrer le fichier de logs.
encoding
L'encodage du fichier de logs. S'il n'est pas spécifié, l'encodage par défaut du système sera utilisé.

name()

Retourne le nom de cet ImportJob.

period( [$new_period] )

Sans argument, retourne la périodicité de cet ImportJob. Avec un paramètre, définit la périodicité de l'ImportJob à cette nouvelle valeur.

file( [$time] )

Retourne le fichier à utiliser. Le paramètre optionnel $time (qui est l'heure actuelle par défaut) est utilisé pour calculer le nom du fichier. Pour trouver le fichier à utiliser pour les données d'hier, on pourrait passer time - 86400.

pattern( [$new_file] )

Retourne le motif de fichier qui sera utilisé comme source de données de logs. Ce motif peut contenir des substitutions strftime(3). S'il est utilisé avec un argument, il change le fichier.

filter( [$new_filter] )

Retourne la commande shell qui sera utilisée comme filtre. Undef ou '' n'utilisera pas de filtre.

encoding( [$new_encoding] )

Retourne l'encodage du fichier de logs. Undef et '' signifient utiliser l'encodage par défaut du système.

converter( [$new_name] )

Retourne le nom du convertisseur qui sera utilisé pour cet ImportJob.

converter_config( [$new_config] )

Retourne un objet de configuration qui sera utilisé par le DlfConverter (via la méthode set_configuration()).

log_fh( [ $time ] )

Retourne un handle de fichier qui peut être utilisé pour lire le fichier de logs. $time est le paramètre pris par file pour déterminer le nom final du fichier. Tous les filtres et encodages seront correctement configurés.

run( $store, [$time] )

Exécute cet ImportJob et l'importe dans le $store DlfStore. Le paramètre $time sera utilisé pour déterminer l'intervalle de temps couvert par la périodicité. Par défaut, c'est l'heure actuelle.
