Locale::RecodeData::MAC_UK - Routines de conversion pour MAC-UK

SYNOPIS

Ce module est interne à libintl. Ne l'utilisez pas directement !

DESCRIPTION

Ce module est généré et contient les tables de conversion et les routines pour MAC-UK.

NAME


Locale::RecodeData::MAC_UK - Macintosh UK character set






SYNOPSIS


    use Locale::RecodeData::MAC_UK;






DESCRIPTION


This module provides the character set definitions for Macintosh
    UK.






COMMENTS


    This file is part of the libintl-perl package.
    See the main manual page for details.
