Module Load_path
: sig end

Gestion des répertoires d'inclusion.

Ce module offre une interface de haut niveau pour localiser des fichiers dans le chemin de chargement, qui est construit à partir des indicateurs de ligne de commande -I et -H ainsi que de quelques autres paramètres.

Il suppose que le contenu des répertoires d'inclusion ne change pas pendant l'exécution du compilateur.

val add_dir : hidden:bool -> string -> unit

Ajoute un répertoire à la fin du chemin de chargement (c'est-à-dire à la plus basse priorité.)

val remove_dir : string -> unit

Supprime un répertoire du chemin de chargement.

val reset : unit -> unit

Supprime tous les répertoires.

module Dir : sig end

type auto_include_callback = (Dir.t -> string -> string option) -> string -> string

Le type des fonctions de rappel pour init ~auto_include

val no_auto_include : auto_include_callback

Aucune inclusion automatique de répertoire : les manques dans le chemin de chargement lèvent Not_found comme d'habitude.

val init : auto_include:auto_include_callback -> visible:string list -> hidden:string list -> unit

init ~visible ~hidden est équivalent à reset ();
List.iter add_dir (List.rev hidden);
List.iter add_dir (List.rev visible)

val auto_include_otherlibs : (string -> unit) -> auto_include_callback

auto_include_otherlibs alert est une fonction de rappel à passer à Load_path.init et ajoute automatiquement -I +lib au chemin de chargement après avoir appelé alert lib .

val get_path_list : unit -> string list

Retourne la liste des répertoires passés à add_dir jusqu'à présent.

type paths = {
visible : string list ;
hidden : string list ;
}

val get_paths : unit -> paths

Retourne les répertoires passés à add_dir jusqu'à présent.

val find : string -> string

Localise un fichier dans le chemin de chargement. Lève Not_found si le fichier ne peut pas être trouvé. Cette fonction est optimisée pour le cas où le nom de fichier est un nom de base, c'est-à-dire qu'il ne contient pas de séparateur de répertoire.

val find_normalized : string -> string

Identique à find , mais recherche également le nom d'unité normalisé (voir Misc.normalized_unit_filename ), c'est-à-dire si le nom est Foo.ml , autorise /path/Foo.ml et /path/foo.ml à correspondre.

type visibility =
| Visible
| Hidden

val find_normalized_with_visibility : string -> string * visibility

Identique à find_normalized , mais indique également si le cmi a été trouvé dans un répertoire -I (Visible) ou un répertoire -H (Hidden).

val add : Dir.t -> unit

Obsolète.

Ancien nom pour Load_path.append_dir

val append_dir : Dir.t -> unit

append_dir d ajoute d à la fin du chemin de chargement (c'est-à-dire à la plus basse priorité.

val prepend_dir : Dir.t -> unit

prepend_dir d ajoute d au début du chemin de chargement (c'est-à-dire à la plus haute priorité.

val get_visible : unit -> Dir.t list

Identique à get_paths () , sauf qu'il retourne une Dir.t list et n'inclut pas les chemins -H.
