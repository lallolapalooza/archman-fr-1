NAME

Locale::RecodeData::EBCDIC_FI_SE_A - Routines de conversion pour EBCDIC_FI_SE_A

SYNOPSIS

Ce module est interne à libintl. Ne pas l'utiliser directement !

DESCRIPTION

Ce module est généré et contient les tables de conversion et routines pour EBCDIC_FI_SE_A.

COMMENTS

Les commentaires suivants sont extraits du charmap original :

version: 1.0
 source: IBM 3270 Char Set Ref Ch 10, GA27-2837-9, avril 1987

Note: les alias mentionnés ci-dessus ne sont pas nécessairement valides !
