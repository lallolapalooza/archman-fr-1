NOM

Locale::RecodeData::IBM274 - Routines de conversion pour IBM274

SYNTAXE

Ce module est interne à libintl. Ne l'utilisez pas directement !

DESCRIPTION

Ce module est généré et contient les tables et routines de conversion pour IBM274.

COMMENTAIRES

Les commentaires suivants ont été extraits de la charmap originale :

version: 1.0
 source: IBM 3174 Character Set Ref, GA27-3831-02, March 1990
alias EBCDIC-BE
alias CP274

Veuillez noter que les alias listés ci-dessus ne sont pas nécessairement valides !

NAME

Locale::RecodeData::IBM274 - Perl module for character set conversion (IBM274).

SYNOPSIS

 use Locale::Recode;

 my $recode_obj = Locale::Recode->new('IBM274');
 my $latin1_string = $recode_obj->string_to_utf8($ibm274_string);
 my $ibm274_string = $recode_obj->utf8_to_string($latin1_string);

DESCRIPTION

This module provides the character set conversion routines for IBM274. It's designed to be used with the Locale::Recode module.

IBM274 is a code page used on IBM mainframe systems. It's a variant of EBCDIC.

This module is generally not needed directly, as Locale::Recode handles the selection and loading of appropriate modules.

COMMENTS

This module was generated from the Unicode Character Database. It might not be perfectly accurate, especially for characters not present in the original code page.

CHARACTER TABLE

A comprehensive character table for IBM274 can be found in the Unicode Character Database.

AUTHOR

The original conversion tables were created by the Unicode Consortium.

This Perl module wrapper was created by the Arch Linux project.
