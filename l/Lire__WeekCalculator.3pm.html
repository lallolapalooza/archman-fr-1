NOM

Lire::WeekCalculator - gérer différents schémas de numérotation des semaines

SYNTAXE

use Lire::WeekCalculator;
my $week_calc = new Lire::WeekCalculator();
my $week_no   = $week_calc->week_number( $time );

DESCRIPTION

Nous supportons trois valeurs pour LR_WEEK_NUMBERING : ISO (strftime's %V) : la semaine commence le lundi ; W (la semaine commence le lundi) et U (la semaine commence le dimanche). Voir strftime(1).

CONSTRUCTEUR

new( %params )

Crée un nouveau calculateur de semaine. Le style de numérotation des semaines est sélectionné en utilisant le paramètre "style". Si ce paramètre est omis, il prend par défaut le style défini dans la variable de configuration 'lr_week_numbering'.

style()

Retourne le style de numérotation des semaines utilisé. Ce sera soit "U", "W" ou "ISO".

week_number( $time )

Retourne le numéro de la semaine de $time selon le schéma de numérotation des semaines actuel. Le numéro de semaine retourné est compris entre 1 et 53.

week_idx( $time )

Retourne l'indice de la semaine de $time selon le schéma de numérotation des semaines. L'indice de semaine est spécifique à Lire et est utilisé pour normaliser les calculs entre différents schémas par rapport à la première semaine incomplète de l'année. Dans le cas ISO, l'indice de semaine est toujours égal à week_number() - 1, pour les autres styles, l'indice de semaine de la semaine 0 sera un de moins que le dernier numéro de semaine de l'année précédente.

last_week_of_year($year)

Retourne le numéro de la semaine de la dernière semaine de l'année $year.

week_start( $year, $week_no )

Retourne le temps epoch du premier jour de la semaine $week_no de l'année $year lorsqu'il est calculé en utilisant le style actuel.

find_year_week1_start_date($year)

Retourne la date (epoch) à laquelle commence le premier jour de la première semaine de l'année $year.

strformat()

Retourne une chaîne qui peut être utilisée comme spécificateur de format dans les appels à strftime pour afficher le numéro de semaine de ce style.

strfdate()

Émule POSIX::strftime() mais récupère le spécificateur %V si le strftime du système ne le supporte pas. Devrait être appelé chaque fois que vous utilisez des chaînes de format qui peuvent contenir des codes de semaine de l'année.
