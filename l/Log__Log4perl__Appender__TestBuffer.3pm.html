NOM

Log::Log4perl::Appender::TestBuffer - Classe d'appender pour les tests

SYNOPSIS

use Log::Log4perl::Appender::TestBuffer;
my $appender = Log::Log4perl::Appender::TestBuffer->new( 
    name      => 'mybuffer',
);
    # Ajouter au tampon
$appender->log( 
    level =  > 'alert', 
    message => "Je cherche de la wasabi de science-fiction dans la ville\n" 
);
    # Récupérer le résultat
my $result = $appender->buffer();
    # Vider le tampon pour qu'il soit une chaîne vide
$appender->clear();

DESCRIPTION

Cette classe est utilisée pour les tests internes de "Log::Log4perl". C'est un appender de style "Log::Dispatch", qui écrit dans un tampon en mémoire, à partir duquel les résultats réels peuvent être facilement récupérés plus tard pour être comparés aux résultats attendus.

Chaque tampon créé est stocké dans un tableau global interne, et peut être référencé plus tard par son nom :

my $app = Log::Log4perl::Appender::TestBuffer->by_name("mybuffer");

récupère l'objet appender d'un tampon précédemment créé "mybuffer". Pour réinitialiser ce tableau global et lui faire oublier tous les appenders testbuffer précédemment créés (malgré les références externes à ces appenders), utilisez

Log::Log4perl::Appender::TestBuffer->reset();
