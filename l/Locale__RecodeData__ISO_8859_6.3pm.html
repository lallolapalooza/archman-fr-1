NOM

Locale::RecodeData::ISO_8859-6 - Routines de conversion pour ISO-8859-6

SYNOPIS

Ce module est interne à libintl. Ne l'utilisez pas directement !

DESCRIPTION

Ce module est généré et contient les tables de conversion et les routines pour ISO-8859-6.

NAME

                    
Locale::RecodeData::ISO_8859_6 - Données pour le jeu de caractères ISO-8859-6 (Arabe).

                

                

                    
SYNOPSIS

                    
use Locale::RecodeData::ISO_8859_6;

                

                

                    
DESCRIPTION

                    
Cette classe fournit les données de mapping pour le jeu de caractères ISO-8859-6. Ce jeu de caractères est également connu sous le nom d'ARABIC.

                    
La table suivante montre les octets codés dans ISO-8859-6 et leur représentation Unicode correspondante.

                    
EA |  0000064A | LETTRE ARABE ALEF MAKSURA
EB |  0000064B | LETTRE ARABE YEH
EC |  0000064C | ARABE FATHATAN
ED |  0000064D | ARABE DAMMATAN
EE |  0000064E | ARABE KASRATAN
EF |  0000064F | ARABE FATHA
F0 |  00000650 | ARABE DAMMA
F1 |  00000651 | ARABE KASRA
F2 |  00000652 | ARABE SHADDA
F3 |  00000653 | ARABE SUKUN
