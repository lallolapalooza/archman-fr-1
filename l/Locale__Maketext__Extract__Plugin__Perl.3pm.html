Locale::Maketext::Extract::Plugin::Perl(3) Documentation Perl fournie par l'utilisateur Locale::Maketext::Extract::Plugin::Perl(3)

NOM

Locale::Maketext::Extract::Plugin::Perl - analyseur de format Perl

VERSION

version 1.00

SYNOPSIS

$plugin = Locale::Maketext::Extract::Plugin::Perl->new(
    $lexicon            # Un objet Locale::Maketext::Extract
    @file_types         # Optionnellement, spécifier une liste de types de fichiers reconnus
)
$plugin->extract($filename,$filecontents);

DESCRIPTION

Extrait les chaînes à localiser (y compris les HEREDOC et les chaînes concaténées) du code Perl.

Cet analyseur Perl est très rapide et très performant, mais pas parfait - il fait des erreurs. L'analyseur PPI (Locale::Maketext::Extract::Plugin::PPI) est plus précis, mais beaucoup plus lent, et n'est donc pas activé par défaut.

perl
