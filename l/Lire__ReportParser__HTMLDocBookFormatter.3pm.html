HTMLDocBookFormatter(3pm) Documentation de Lire::ReportParser HTMLDocBookFormatter(3pm)

NOM

Lire::ReportParser::HTMLDocBookFormatter - sous-classe de Lire::ReportParser qui formate la description.

SYNTAXE

Pour formater en DocBook :

use Lire::ReportParser::HTMLDocBookFormatter qw/dbk2html/;
my $txt = dbk2html( "<para>Test</para>" );

Dans les processeurs de rapports XML :

package MyParser;
use base qw/ Lire::ReportParser::HTMLDocBookFormatter Lire::ReportParser /;
sub new {
    my $self = shift->SUPER::new( @_ );
    $self->init_docbook_formatter( @_ );
    return $self;
}
sub handle_description {
    my ( $self, $desc ) = @_;
    print $desc;
    return;
}

DESCRIPTION

Lire::ReportParser::HTMLDocBookFormatter est le pendant de Lire::ReportParser::AsciiDocBookFormatter pour le format de sortie HTML. Veuillez lire sa documentation pour apprendre comment utiliser cette classe. Leur utilisation est exactement la même.

dbk2html( $docbook_str, [$colonnes], [$xhtml] )

Retourne une version HTML du fragment XML DocBook $docbook_str. Le paramètre "colonnes" définit le nombre de colonnes dans lesquelles le texte DocBook HTML doit être formaté. Le paramètre "xhtml" définit si le code généré sera conforme XHTML ; par défaut, c'est oui.

Cette méthode mourra en cas d'erreur.
