Locale::RecodeData::KOI8_T(3pm) — Perl 5.32.0 manual

NAME

Locale::RecodeData::KOI8_T - Perl module for KOI8-T character set.

SYNOPSIS

    use Locale::RecodeData::KOI8_T qw( :all );

DESCRIPTION

This module provides functions to convert characters from and to the KOI8-T character set.

COMMENTS

KOI8-T is an 8-bit character set for the Cyrillic alphabet, based on the KOI8 standard. It is commonly used in the Russian-speaking world for e-mail and web pages.
