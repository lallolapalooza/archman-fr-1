NOM

Lire::Config::ReferenceSpec - SelectSpec qui prend ses options d'un Index.

DESCRIPTION

Ce Lire::Config::TypeSpec est un SelectSpec qui définit une option pour chaque entrée disponible dans l'Index nommé sur sa propriété index.

new( 'nom' => $nom, 'index' => $index, ... )

Crée un nouvel objet ReferenceSpec. Les options disponibles seront interrogées au moment de l'exécution sous Index.

index( [ $nouvel_index )

Retourne (et change optionnellement) le réglage des attributs d'index.

VOIR AUSSI

Lire::Config::ReportConfigIndex(3pm) Lire::Config::Index(3pm)
