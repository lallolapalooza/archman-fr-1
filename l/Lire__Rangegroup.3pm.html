NOM

Lire::Group - Classe de base pour l'implémentation de l'agrégateur rangegroup

SYNOPSIS

use Lire::Rangegroup;

DESCRIPTION

Ce module est la classe de base pour l'implémentation de l'agrégateur rangegroup. Cet agrégateur divisera les enregistrements DLF selon un champ numérique. Les agrégateurs rangegroup créent des classes numériques (par exemple, 1-10, 11-20, etc.) et les enregistrements DLF seront regroupés avec d'autres enregistrements qui se trouvent dans la même classe.

CONSTRUCTEUR

new( %params )

Crée une nouvelle instance d'un agrégateur rangegroup. En plus des paramètres normaux des opérateurs de rapport, l'agrégateur rangegroup peut prendre plusieurs paramètres supplémentaires :

field
Ce paramètre est obligatoire. Il doit s'agir du nom du champ DLF qui sera utilisé comme clé pour cet agrégateur.
range-size
Ce paramètre est obligatoire. Il sera utilisé comme taille de chaque groupe rangegroup.
range-start
Le nombre à partir duquel le premier groupe rangegroup commence. La valeur par défaut est 0.
min-value
La valeur inférieure à ce nombre sera triée dans le premier groupe rangegroup.
max-value
La valeur supérieure à ce nombre sera triée dans le dernier groupe rangegroup.
size-scale
Ce paramètre peut être utilisé pour créer une échelle logarithmique. Dans ce cas, chaque nouveau groupe rangegroup sera plus grand que le précédent selon la valeur de size-scale. Par exemple, définir range-size=5 et size-scale=2 créera des rangegroups tels que [0-5>, [5-15>, [15-35>, ...

MÉTHODES

field( [$new_field] )

Renvoie le nom du champ DLF qui sera utilisé comme clé d'agrégation.

Si le paramètre $new_field est défini, il modifie le champ d'agrégation. Il doit s'agir du nom d'un champ de type rapport dans le schéma de spécifications DLF.

range_start( [$new_start] )

Renvoie le nombre qui constitue la limite inférieure du premier groupe rangegroup.

Si le paramètre $new_start est défini, il modifie la limite inférieure du premier groupe rangegroup. Il doit s'agir d'un entier positif ou du nom d'un des paramètres de la spécification du rapport.

range_size( [$new_size] )

Renvoie la largeur de chaque groupe rangegroup.

Si le paramètre $new_size est défini, il modifie la largeur de chaque groupe rangegroup. Il doit s'agir d'un entier positif ou du nom d'un des paramètres de la spécification du rapport.

min_value( [$new_min] )

Renvoie le nombre en dessous duquel aucun nouveau groupe rangegroup ne sera créé.

Si le paramètre $new_min est défini, il modifie la limite inférieure en dessous de laquelle aucun nouveau groupe ne sera créé. Il doit s'agir d'un nombre ou du nom d'un des paramètres de la spécification du rapport.

max_value( [$new_max] )

Renvoie le nombre au-dessus duquel aucun nouveau groupe rangegroup ne sera créé.

Si le paramètre $new_max est défini, il modifie la limite supérieure au-dessus de laquelle aucun nouveau groupe ne sera créé. Il doit s'agir d'un nombre ou du nom d'un des paramètres de la spécification du rapport.

size_scale( [$new_size_scale] )

Renvoie le multiplicateur qui sera appliqué à chaque largeur de groupe rangegroup après le premier.

Lorsque cet attribut est supérieur à 1, il crée une échelle logarithmique où chaque nouveau groupe rangegroup est plus large que le précédent selon la valeur de size_scale. Par exemple, définir size_scale=2 et range-size=5 crée des rangegroups tels que [0-5>, [5-15>, [15-35>, ...

Si le paramètre $new_size_scale est utilisé, il modifie l'attribut à cette nouvelle valeur. Il doit s'agir d'un entier positif ou il peut également s'agir d'une référence à un paramètre.
