NOM

Lire::Config::Parser - Crée un objet Lire::Config::ConfigFile à partir de XML

SYNTAXE

use Lire::Config;
use Lire::Config::Parser;
my $parser = new Lire::Config::Parser( 'spec' => Lire::Config->config_spec());
my $conf = $parser->parsefile( 'config.xml' );

DESCRIPTION

Analyseur XML assez simple qui suit la spécification de configuration pour analyser un fichier XML.

new( 'spec' => $spec )

Crée un objet analyseur qui analysera le fichier de configuration qui valide contre la spécification Lire::Config::ConfigSpec $spec.

load_config_file( $file )

Analyse le fichier XML $file et retourne un objet Lire::Config::ConfigFile le représentant.

VOIR AUSSI

Lire::Config::ConfigFile(3pm), Lire::Config::SpecParser(3pm),
Lire::Config::ConfigSpec(3pm)
