NOM

Lire::DlfConverterProcess - Objet qui contrôle le processus de conversion DLF

SYNTAXE

use Lire::ImportJob;
use Lire::DlfStore;
use Lire::DlfConverterProcess;
my $src = new Lire::ImportJob( "fichier", 'pattern' => "/var/log/messages" );
my $store = Lire::DlfStore->open( "store" );
my $process = new Lire::DlfConverterProcess( $src, $store );
$process->run_import_job();
print "Lignes de log lues : ",      $process->line_count(), "\n";
print "Enregistrements DLF créés : ", $process->dlf_count,    "\n";
print "Erreurs rencontrées : ",  $process->errors_count, "\n";
print "Enregistrements ignorés : ",     $process->ignored_count,"\n";

DESCRIPTION

Cet objet encapsule le processus de conversion DLF de Lire. Il prend en paramètre un Lire::ImportJob et un Lire::DlfStore. Il mettra en place le convertisseur et convertira le contenu de Lire::ImportJob en DLF qui sera sauvegardé dans le Lire::DlfStore.

L'objet fournit l'API du convertisseur. Des méthodes sont également disponibles pour interroger des informations sur le processus de conversion.

new( $job, $store );

Crée un Lire::DlfConverterProcess qui sera utilisé pour importer le log spécifié dans Lire::ImportJob en enregistrements DLF qui seront stockés dans Lire::DlfStore.

run_import_job( [$time] )

Importe les données du log depuis ImportJob sous forme de DLF. Cette méthode lancera une exception si elle est appelée plus d'une fois. Le paramètre $time sera utilisé pour déterminer la fenêtre temporelle couverte par la période. Il est défini par défaut à l'heure actuelle.

job_id()

Retourne l'identifiant de la tâche associé à ce processus.

dlf_store()

Retourne le Lire::DlfStore dans lequel ce processus de conversion stocke les enregistrements DLF.

import_job()

Retourne le Lire::ImportJob sur lequel ce processus de conversion opère.

line_count()

Retourne le nombre de lignes traitées. Cela sera 0 dans le cas où le convertisseur DLF traite un fichier et non des lignes de log. Pendant un traitement, cela est toujours égal à la ligne en cours de conversion.

dlf_count()

Retourne le nombre d'enregistrements DLF créés.

error_count()

Retourne le nombre d'erreurs rencontrées dans le processus de conversion.

ignored_count()

Retourne le nombre d'enregistrements qui ont été ignorés dans le processus de conversion.

saved_count()

Retourne le nombre de lignes qui ont été sauvegardées pour un traitement ultérieur.

API POUR LES CONVERTISSEURS DLF

C'est l'objet qui encapsule l'implémentation Dlf et cache la complexité du framework de stockage au convertisseur DLF. Il offre les méthodes suivantes au convertisseur DLf.

write_dlf( $schema, $dlf )

Cela écrit l'enregistrement DLF $dlf conforme au schéma de $schema dans le Lire::DlfStore. Le schéma est le nom du schéma (par exemple, 'www'). $dlf est une référence de hash. Les clés sont le nom des champs du schéma. Une valeur indéfinie signifie que ce champ n'est pas disponible dans cet enregistrement.

save_log_line( $line )

Méthode qui devrait être utilisée pour sauvegarder $line pour une future exécution du convertisseur sur le même Lire::ImportJob.

ignored_log_line( $line, [ $reason ] )

Méthode qui peut être utilisée par Lire::DlfConverter pour signaler que la ligne de log '$line' a été ignorée pendant ce traitement. La raison pour laquelle la ligne a été ignorée peut être donnée dans $reason. Par exemple, un convertisseur basé sur syslog devrait utiliser cette méthode pour signaler des lignes qui sont destinées à un autre 'service' que le leur.

error( $error_msg, [ $line ] );

Méthode qui devrait être utilisée par Lire::DlfConveter pour signaler qu'une erreur a été rencontrée lors du traitement de Lire::ImportJob. $error_msg devrait être utilisé pour signaler la nature de l'erreur. Le paramètre $line devrait être utilisé par les convertisseurs opérant sur des lignes pour associer le message d'erreur à une ligne particulière.
