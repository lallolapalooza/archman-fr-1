NOM

Lire::Max - Classe Lire qui implémente l'opérateur max

SYNTAXE

use Lire::Max

DESCRIPTION

Classe qui implémente l'opérateur max. Cet opérateur trouvera la valeur minimum apparaissant dans un champ DLF parmi un groupe d'enregistrements DLF.

MÉTHODES

new( %params )

Crée un nouvel objet Lire::Max.

VOIR AUSSI

Lire::ReportSpec(3pm), Lire::ReportOperator(3pm), Lire::Aggregator(3pm), Lire::Aggregate(3pm).
