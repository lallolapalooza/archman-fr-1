LIST(3) Manuel des fonctions standard LIST(3)

NOM

LIST_EMPTY, LIST_ENTRY, LIST_FIRST, LIST_FOREACH, LIST_HEAD, LIST_HEAD_INITIALIZER, LIST_INIT, LIST_INSERT_AFTER, LIST_INSERT_BEFORE, LIST_INSERT_HEAD, LIST_NEXT, LIST_REMOVE - implémentation d'une liste doublement chaînée

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <sys/queue.h>
LIST_ENTRY(TYPE);
LIST_HEAD(HEADNAME, TYPE);
LIST_HEAD LIST_HEAD_INITIALIZER(LIST_HEAD head);
void LIST_INIT(LIST_HEAD *head);
int LIST_EMPTY(LIST_HEAD *head);
void LIST_INSERT_HEAD(LIST_HEAD *head,
                        struct TYPE *elm, LIST_ENTRY NAME);
void LIST_INSERT_BEFORE(struct TYPE *listelm,
                        struct TYPE *elm, LIST_ENTRY NAME);
void LIST_INSERT_AFTER(struct TYPE *listelm,
                        struct TYPE *elm, LIST_ENTRY NAME);
struct TYPE *LIST_FIRST(LIST_HEAD *head);
struct TYPE *LIST_NEXT(struct TYPE *elm, LIST_ENTRY NAME);
LIST_FOREACH(struct TYPE *var, LIST_HEAD *head, LIST_ENTRY NAME);
void LIST_REMOVE(struct TYPE *elm, LIST_ENTRY NAME);

DESCRIPTION

Ces macros définissent et opèrent sur une liste doublement chaînée.

Dans les définitions de macros, TYPE est le nom d'une structure définie par l'utilisateur, qui doit contenir un champ de type LIST_ENTRY, nommé NAME. L'argument HEADNAME est le nom d'une structure définie par l'utilisateur qui doit être déclarée en utilisant la macro LIST_HEAD().

Création

Une liste est dirigée par une structure définie par la macro LIST_HEAD(). Cette structure contient un seul pointeur vers le premier élément de la liste. Les éléments sont doublement chaînés de sorte qu'un élément arbitraire puisse être retiré sans parcourir la liste. De nouveaux éléments peuvent être ajoutés à la liste après un élément existant, avant un élément existant, ou au début de la liste. Une structure LIST_HEAD est déclarée comme suit :


LIST_HEAD(HEADNAME, TYPE) head;

où struct HEADNAME est la structure à définir, et struct TYPE est le type des éléments de la liste. Un pointeur vers la tête de la liste peut ensuite être déclaré comme :


struct HEADNAME *headp;

(Les noms head et headp sont choisissables par l'utilisateur.)

LIST_ENTRY() déclare une structure qui relie les éléments de la liste.

LIST_HEAD_INITIALIZER() évalue à un initialiseur pour la liste head.

LIST_INIT() initialise la liste référencée par head.

LIST_EMPTY() évalue à vrai si la liste est vide.

Insertion

LIST_INSERT_HEAD() insère le nouvel élément elm au début de la liste.

LIST_INSERT_BEFORE() insère le nouvel élément elm avant l'élément listelm.

LIST_INSERT_AFTER() insère le nouvel élément elm après l'élément listelm.

Parcours

LIST_FIRST() renvoie le premier élément de la liste, ou NULL si la liste est vide.

LIST_NEXT() renvoie le prochain élément de la liste, ou NULL si c'est le dernier.

LIST_FOREACH() parcourt la liste référencée par head dans le sens direct, attribuant chaque élément dans son ordre à var.

Suppression

LIST_REMOVE() retire l'élément elm de la liste.

VALEUR DE RETOUR

LIST_EMPTY() renvoie non zéro si la liste est vide, et zéro si elle contient au moins un élément.

LIST_FIRST(), et LIST_NEXT() renvoient un pointeur vers la structure TYPE, le premier ou le suivant.

LIST_HEAD_INITIALIZER() renvoie un initialiseur qui peut être assigné à la liste head.

NORMES

BSD.

HISTORIQUE

4.4BSD.

PROBLÈMES

LIST_FOREACH() ne permet pas que var soit supprimé ou libéré à l'intérieur de la boucle, car cela pourrait interférer avec le parcours. LIST_FOREACH_SAFE(), présent dans les BSD mais pas dans glibc, corrige cette limite en permettant que var soit supprimé et libéré en toute sécurité à l'intérieur de la boucle sans interférer avec le parcours.

EXEMPLE

#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>
struct entry {
    int data;
    LIST_ENTRY(entry) entries;              /* Liste */
};
LIST_HEAD(listhead, entry);
int
main(void)
{
    struct entry *n1, *n2, *n3, *np;
    struct listhead head;                   /* Tête de liste */
    int i;
    LIST_INIT(&head);                       /* Initialiser la liste */
    n1 = malloc(sizeof(struct entry));      /* Insertion au début */
    LIST_INSERT_HEAD(&head, n1, entries);
    n2 = malloc(sizeof(struct entry));      /* Insertion après */
    LIST_INSERT_AFTER(n1, n2, entries);
    n3 = malloc(sizeof(struct entry));      /* Insertion avant */
    LIST_INSERT_BEFORE(n2, n3, entries);
    i = 0;                                  /* Parcours forward */
    LIST_FOREACH(np, &head, entries)
        np->data = i++;
    LIST_REMOVE(n2, entries);               /* Suppression */
    free(n2);
                                            /* Parcours forward */
    LIST_FOREACH(np, &head, entries)
        printf("%i\n", np->data);
                                            /* Suppression de la liste */
    n1 = LIST_FIRST(&head);
    while (n1 != NULL) {
        n2 = LIST_NEXT(n1, entries);
        free(n1);
        n1 = n2;
    }
    LIST_INIT(&head);
    exit(EXIT_SUCCESS);
}
