NOM

Lire::Test::DlfConverterTestCase - Classe de base pour écrire des tests unitaires de DLfConverter

SYNOPSIS

use base qw/ Lire::Test::DlfConverterTestCase /;
use MyConverter;
use File::Basename;
sub create_converter {
  return new MyConverter();
}
sub schemasdir {
  return dirname( __FILE__ ) .  "../..";
}
sub registration_file {
  return dirname( __FILE__ ) .  "../../myconverter_init";
}

DESCRIPTION

Il s'agit d'une sous-classe de Test::Unit::TestCase qui peut être utilisée pour écrire facilement des tests pour DlfConverter. Cette classe implémente ce qui est nécessaire pour fournir le fixture nécessaire dans set_up() et tear_down().

Elle fournit deux tests de base : test_api() et test_registration_file().

La classe de test doit implémenter trois méthodes pour aider à compléter le fixture.

FIXTURES

Ce sont les méthodes que les sous-classes surchargeront généralement pour fournir les données nécessaires afin que les fixtures de test DlfConverter soient configurées.

registration_file()

Cette méthode doit retourner le script responsable de l'enregistrement du convertisseur auprès du Lire::PluginManager. Elle est utilisée par le test_registration_file() par défaut.

schemasdir()

Cette méthode doit retourner le répertoire qui contient les schémas utilisés par le convertisseur. Il sera ajouté à la variable de configuration lr_schemas_path si set_up_path() est appelé.

create_converter()

Cette méthode doit retourner une instance de l'instance Lire::DlfConverter à tester.

set_up_path()

Ceci ajoutera le schemasdir à 'lr_schemas_path'.

Processus de Simulation de Convertisseur

create_mock_process()

Cette méthode retournera un MockDlfConverterProcess qui peut être utilisé pour aider à tester le DlfConverter. Toutes les valeurs passées à write_dlf(), error(), ignore_log_line() et save_log_line() sont sauvegardées et peuvent être interrogées via les méthodes dlf( 'schema' ), errors(), ignored() et saved().

Le processus simulé possède également une méthode converter() qui retourne le DlfConverter créé par create_converter() et associé à son instance.

TESTS PAR DÉFAUT

test_api()

S'assure que toutes les méthodes requises par Lire::DlfConverter sont implémentées. Il teste également que les schémas retournés par schemas() sont disponibles.

Il vérifie que description() est formaté correctement en tant que DocBook.

test_registration_file()

Vérifie que le script d'enregistrement enregistre correctement le convertisseur auprès du PluginManager.
