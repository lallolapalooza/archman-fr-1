NOM

Locale::RecodeData::EBCDIC_IS_FRISS - Routines de conversion pour EBCDIC_IS_FRISS

SYNOPIS

Ce module est interne à libintl. Ne pas utiliser directement !

DESCRIPTION

Ce module est généré et contient les tables de conversion et les routines pour EBCDIC-IS-FRISS.

COMMENTAIRES

Les commentaires suivants ont été extraits de la charmap d'origine :

version: 1.0
 source: Skyrsuvelar Rikisins og Reykjavikurborgar, feb 1982
alias FRISS

Veuillez noter que les alias listés ci-dessus ne sont pas nécessairement valides !
