NOM

Locale::RecodeData::EBCDIC_UK - Routines de conversion pour EBCDIC_UK

SYNOPSIS

Ce module est interne à libintl. Ne l'utilisez pas directement !

DESCRIPTION

Ce module est généré et contient les tables de conversion et les routines pour EBCDIC-UK.

COMMENTAIRES

Les commentaires suivants ont été extraits de la charmap d'origine :

version: 1.0
 source: IBM 3270 Char Set Ref Ch 10, GA27-2837-9, April 1987

Veuillez noter que les alias listés ci-dessus ne sont pas nécessairement valides !

NOM

Locale::RecodeData::EBCDIC_UK - Données de recodage pour l'encodage EBCDIC_UK.

SYNTAXE

Aucune syntaxe n'est directement fournie pour ce module car il est destiné à être utilisé par le framework recode.

DESCRIPTION

Ce module fait partie du jeu de modules Locale::RecodeData, qui fournit les données nécessaires pour convertir des chaînes de caractères entre différents encodages de caractères. Spécifiquement, Locale::RecodeData::EBCDIC_UK contient les informations de mappage pour l'encodage EBCDIC utilisé au Royaume-Uni.

Ce module n'est pas destiné à être appelé directement par l'utilisateur final. Il est utilisé en interne par le module recode (qui fait partie de la distribution Perl standard ou peut être installé séparément) pour effectuer les conversions d'encodage nécessaires.

COMMENTAIRES

Les commentaires spécifiques à ce module sont généralement gérés par le framework recode lui-même. Aucune section de commentaire distincte n'est généralement présente dans les modules de données de recodage.

TABLEAU DE CARACTÈRES

Ce module contient les mappages de caractères entre l'encodage EBCDIC_UK et d'autres encodages pris en charge par le module recode. Le tableau de caractères spécifique n'est pas affiché ici, mais il est la raison d'être de ce module.
