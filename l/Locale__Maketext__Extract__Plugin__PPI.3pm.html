NOM

Locale::Maketext::Extract::Plugin::PPI - Analyseur de format Perl

VERSION

version 1.00

SYNTAXE IMPLIQUÉE

$plugin = Locale::Maketext::Extract::Plugin::PPI->new(
    $lexicon            # Un objet Locale::Maketext::Extract
    @file_types         # Optionnellement spécifier une liste de types de fichiers reconnus
)
$plugin->extract($filename,$filecontents);

DESCRIPTION

Fait exactement la même chose que l'analyseur Locale::Maketext::Extract::Plugin::Perl, mais de manière plus précise, et plus lentement. Considérablement plus lentement ! Pour cette raison, ce n'est pas un plugin intégré.

NOM COURT DU PLUGIN

aucun - le module doit être spécifié en entier
