NOM

Locale::RecodeData::IBM1047 - Routines de conversion pour IBM1047

SYNOPIS

Ce module est interne à libintl. Ne pas l'utiliser directement !

DESCRIPTION

Ce module est généré et contient les tables et routines de conversion pour IBM1047.

COMMENTAIRES

Les commentaires suivants ont été extraits de la table de caractères originale :

version: 1.0
 source: IBM Character Data Representation Architecture
 Registry SC09-1391-00 p 150.
alias CP1047
alias 1047

Veuillez noter que les alias listés ci-dessus ne sont pas nécessairement valides !

Locale::RecodeData::IBM1047 est un module qui fournit des données pour l'encodage de caractères IBM1047.

COMMENTAIRES

Ce module est conçu pour fournir les données nécessaires à l'encodage de caractères IBM1047, utilisé dans certains systèmes et applications.
