NOM

Locale::RecodeData::ISO_2033_1983 - Routines de conversion pour ISO_2033_1983

SYNOPSIS

Ce module est interne à libintl. Ne pas utiliser directement !

DESCRIPTION

Ce module est généré et contient les tables et routines de conversion pour ISO_2033-1983.

COMMENTAIRES

Les commentaires suivants ont été extraits de la table de caractères originale :

version: 1.0
repertoiremap: mnemonic,ds
 source: ECMA registry
alias ISO-IR-98
alias E13B

Veuillez noter que les alias listés ci-dessus ne sont pas nécessairement valides !
