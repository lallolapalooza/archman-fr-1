NOM Documentation des contributeurs Perl Locale::Maketext::Lexicon(3)

NOM

Locale::Maketext::Lexicon - Utiliser d'autres formats de catalogue que ceux utilisés par Maketext

VERSION

version 1.00

SYNOPSIS

Dans le cadre d'une classe de localisation, effectue automatiquement une recherche des catalogues disponibles :

package Hello::I18N;
use base 'Locale::Maketext';
use Locale::Maketext::Lexicon {
    '*' => [Gettext => '/usr/local/share/locale/*/LC_MESSAGES/hello.mo'],
    ### Décommentez pour retomber sur le cas où une clé manque dans un lexique
    # _auto   => 1,
    ### Décommentez pour décoder les entrées de lexique en chaînes Unicode
    # _decode => 1,
    ### Décommentez pour tout charger et analyser immédiatement
    # _preload => 1,
    ### Décommentez pour utiliser %1 / %quant(%1) au lieu de [_1] / [quant, _1]
    # _style  => 'gettext',
};

Spécifier explicitement des langues, lors de la compilation ou de l'exécution :

package Hello::I18N;
use base 'Locale::Maketext';
use Locale::Maketext::Lexicon {
    de => [Gettext => 'hello_de.po'],
    fr => [
        Gettext => 'hello_fr.po',
        Gettext => 'local/hello/fr.po',
    ],
};
# ... ajouter progressivement de nouveaux lexiques
Locale::Maketext::Lexicon->import({
    de => [Gettext => 'local/hello/de.po'],
})

Alternativement, dans le cadre d'une sous-classe de localisation :

package Hello::I18N::de;
use base 'Hello::I18N';
use Locale::Maketext::Lexicon (Gettext => \*DATA);
__DATA__
# Quelques données d'exemple
msgid ""
msgstr ""
"Project-Id-Version: Hello 1.3.22.1\n"
"MIME-Version: 1.0\n"
"Content-Type: text/plain; charset=iso8859-1\n"
"Content-Transfer-Encoding: 8bit\n"
#: Hello.pm:10
msgid "Hello, World!"
msgstr "Hallo, Welt!"
#: Hello.pm:11
msgid "You have %quant(%1,piece) of mail."
msgstr "Sie haben %quant(%1,Poststueck,Poststuecken)."

DESCRIPTION

Ce module fournit des modules de gestion de catalogue qui lisent à partir d'autres formats de localisation, tels que Gettext, Msgcat, et d'autres.

Si vous n'êtes pas familier avec le concept des modules de catalogue, consultez Locale::Maketext et les fichiers HTML "webl10n" dans le répertoire "docs/" de ce module.

Une utilitaire en ligne de commande xgettext.pl est également installé pour extraire les chaînes traduisibles des fichiers sources.

La fonction import()

La fonction import() accepte deux formes d'arguments :

(format => source ...)
Cette forme prend n'importe quel nombre de paires d'arguments (généralement une) ; source peut être un nom de fichier, un fichier d'entrée ou une référence de tableau.
Pour chaque paire, elle passe le contenu spécifié par le deuxième argument à Locale::Maketext::Lexicon::format->parse en tant que liste normale, et exporte sa valeur retournée sous le nom de %Lexicon dans le paquet appelant.
En cas de paires multiples, le catalogue défini par les derniers écrase les précédents.
{ langue => [format, source ...] ... }
Cette forme accepte une référence de hash. Un %Lexicon sera exporté vers chaque sous-classe spécifiée par chaque langue, en utilisant le processus décrit ci-dessus. Elle est conçue pour réduire la nécessité de créer une sous-classe distincte pour chaque langue localisée, et simplement utiliser les fichiers de catalogue.
Ce module convertira les arguments de langue en minuscules, et remplacera tous les "-" par "_", donc "zh_TW" et "zh-tw" seront mappés sur "zh_tw".
Si la langue commence par "_", elle est considérée comme une option qui contrôle la façon dont les catalogues sont analysés. Voir "Options" pour une liste des options disponibles.
Le "*" est une langue spéciale ; il doit être utilisé avec un nom de fichier qui contient également "*". Tous les fichiers correspondant à un code de langue valide à la place de "*" seront automatiquement préparés comme sous-classe de catalogue. S'il y a plusieurs "*" dans le nom du fichier, le dernier sera utilisé comme nom de langue.

Options

"_auto"
Si défini à une valeur vraie, les recherches effectuées sur des catalogues vides seront gérées silencieusement, comme si un catalogue "Auto" avait été ajouté à tous les catalogues de langue.
"_decode"
Si défini à une valeur vraie, les entrées sources seront converties en chaînes UTF-8 (disponible dans Perl 5.6.1 ou plus récent). Cette fonctionnalité nécessite le module Encode ou Encode::compat.
Actuellement, seul le backend "Gettext" prend en charge cette option.
"_encoding"
Cette option n'a d'effet que lorsque _decode est défini à vrai. Elle spécifie un encodage pour stocker les entrées du catalogue, au lieu de chaînes UTF-8.
Si _encoding est défini à "locale", l'encodage sera celui de l'environnement local actuel.
"_preload"
Par défaut, l'analyse est différée jusqu'à ce que le catalogue soit utilisé pour la première fois. Si défini à une valeur vraie, il est analysé immédiatement. L'augmentation du chargement des catalogues force l'analyse.

NOTES

Lorsque vous essayez de localiser une entrée qui n'existe pas dans le catalogue, Maketext lèvera une exception par défaut. Pour éviter ce comportement, remplacez la clé _AUTO dans votre sous-classe de langue, par exemple :

$Hello::I18N::en::Lexicon{_AUTO} = 1; # créer automatiquement les clés manquantes

Si vous souhaitez implémenter un nouveau backend de catalogue "Lexicon::*", notez que la fonction parse() prend un tableau contenant les chaînes sources des fichiers d'entrée ou des noms, qui ne sont pas "chompées". Bien que si la source est une référence de tableau, ses éléments ne contiendront probablement pas de caractères de nouvelle ligne.

La fonction parse() devrait retourner une référence de hash, qui est assignée au %Lexicon (typglob *Lexicon) du module de langue. Tout ce qui importe est que si la référence retournée pointe vers un hash lié, le %Lexicon sera aliasé au même hash lié s'il n'a pas été initialisé auparavant.
