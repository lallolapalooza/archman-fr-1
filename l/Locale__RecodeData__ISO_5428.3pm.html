NOM

Locale::RecodeData::ISO_5428 - Routines de conversion pour ISO_5428

SYNOPSIS

Ce module est interne à libintl. Ne l'utilisez pas directement !

DESCRIPTION

Ce module contient les tables de conversion et les routines pour ISO_5428.

COMMENTAIRES

Les commentaires suivants ont été extraits de la charmap originale :

 version: 1.0
 source: ECMA Register
 alias ISO-IR-55
 alias ISO_5428:1980

Note : Les alias ci-dessus ne sont pas nécessairement valides !
