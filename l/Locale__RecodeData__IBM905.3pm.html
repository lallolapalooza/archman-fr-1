NOM

Locale::RecodeData::IBM905 - Routines de conversion pour IBM905

SYNTAXE

Ce module est interne à libintl. Ne l'utilisez pas directement !

DESCRIPTION

Ce module est généré et contient les tables de conversion et les routines pour IBM905.

COMMENTAIRES

Les observations suivantes ont été extraites de la charmap originale :

version: 1.0
 source: IBM 3174 Character Set Ref, GA27-3831-02, Mars 1990
 alias: CP905
 alias: EBCDIC-CP-TR

Note : les alias mentionnés ci-dessus ne sont pas nécessairement valides !
