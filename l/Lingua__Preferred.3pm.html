NOM

Lingua::Preferred - Extension Perl pour choisir une langue

SYNOPSIS

use Lingua::Preferred qw(which_lang acceptable_lang);
my @wanted = qw(en de fr it de_CH);
my @available = qw(fr it de);
my $which = which_lang(\@wanted, \@available);
print "la langue $which est la meilleure parmi celles disponibles\n";
foreach (qw(en_US fr nl de_DE)) {
    print "la langue $_ est acceptable\n"
      if acceptable_lang(\@wanted, $_);
}

DESCRIPTION

Souvent, les informations lisibles par l'homme sont disponibles dans plus d'une langue. Laquelle devriez-vous utiliser ? Ce module fournit un moyen à l'utilisateur de spécifier des langues possibles par ordre de préférence, puis de choisir la meilleure langue parmi celles disponibles. Différents « dialectes » donnés par la partie « territoire » du spécificateur de langue (comme en, en_GB, et en_US) sont également pris en charge.

La routine which_lang() choisit la meilleure langue parmi une liste d'alternatives. Les arguments sont :

  • une référence à une liste de langues préférées (la première est la meilleure). Ici, une langue est une chaîne comme 'en' ou 'fr_CA'. ('fr_*' peut également être donné - voir ci-dessous.) 'C' (nommée d'après la locale 'C' de Unix) correspond à n'importe quelle langue.
  • une référence à une liste non vide de langues disponibles. Ici, une langue peut être comme 'en', 'en_CA', ou "undef" signifiant « inconnu ».

Le code de retour est la langue à utiliser. Ce sera toujours un élément de la liste des langues disponibles.

L'astuce de ce module (si on peut l'appeler ainsi) vient de l'inférence de préférences linguistiques implicites basées sur la liste explicite fournie. Par exemple, si vous dites que l'anglais est acceptable, alors en_IE et en_DK seront probablement aussi acceptables (mais pas aussi bien que l'anglais simple). Si vous donnez votre langue comme en_US, alors l'anglais est presque aussi bon, suivi de près par les autres dialectes de l'anglais.

En cas d'égalité entre deux choix, comme lorsque deux dialectes de la même langue sont disponibles et qu'aucun n'est explicitement préféré, ou lorsqu'aucune des langues disponibles n'apparaît dans la liste de l'utilisateur, le choix apparaissant plus tôt dans la liste disponible est préféré.

Parfois, l'inférence automatique de dialectes apparentés n'est pas ce que vous voulez, car un dialecte linguistique peut être très différent de la langue « principale », par exemple l'allemand suisse ou certaines formes d'anglais. Pour ce cas, la forme spéciale 'XX_*' est disponible. Si vous n'aimez pas l'espagnol mexicain (comme exemple complètement arbitraire), alors "[ 'es', 'es_*', 'es_MX' ]" classerait ce dialecte en dessous de tout autre dialecte de l'espagnol (mais toujours acceptable). Vous n'avez pas besoin de lister explicitement tous les autres dialectes de l'espagnol avant es_MX.

Donc, par exemple, en supposant que @avail contient les langues disponibles :

  • Vous connaissez l'anglais et préférez l'anglais américain : 
    $which = which_lang([ 'en_US' ], \@avail);
  • Vous connaissez l'anglais et l'allemand, l'allemand/Allemagne est préféré : 
    $which = which_lang([ 'en', 'de_DE' ], \@avail);
  • Vous connaissez l'anglais et l'allemand, mais de préférence pas l'allemand suisse : 
    $which = which_lang([ 'en', 'de', 'de_*', 'de_CH' ], \@avail);

    Ici, n'importe quel dialecte de l'allemand (par exemple de_DE, de_AT) est préférable à de_CH.

    Alors que which_lang() choisit la meilleure langue parmi une liste d'alternatives, acceptable_lang() répond si une seule langue est incluse (explicitement ou implicitement) dans la liste des langues souhaitées. Elle ajoute les dialectes implicites de la même manière.
