NOM

Font::TTF - Module Perl pour le bidouillage de polices TrueType

DESCRIPTION

Ce module vous permet de faire presque n'importe quoi avec une police TrueType/OpenType, y compris modifier et inspecter presque toutes ses tables.

AUTEUR

Martin Hosken http://scripts.sil.org/FontUtils. (voir CONTRIBUTORS pour d'autres auteurs).

Le dépôt est disponible sur https://github.com/silnrsi/font-ttf.git
