NOM

Font::TTF::OldMort - Table de métamorphose de glyphes dans une police

DESCRIPTION

VARIABLES D'INSTANCE

version
numéro de version de la table (Fixed: actuellement 1.0)
chains
liste de chaînes de métamorphose, chacune ayant ses propres champs :
defaultFlags
indicateurs de sous-fonction par défaut de la chaîne (UInt32)
featureEntries
liste d'entrées de fonctions, chacune ayant les champs :
type
setting
enable
disable
subtables
liste de sous-tables de métamorphose, chacune ayant les champs :
type
type de sous-table (0 : réarrangement ; 1 : substitution contextuelle ; 2 : ligature ; 4 : substitution non contextuelle ; 5 : insertion)
direction
direction de traitement ('LR' ou 'RL')
orientation
s'applique au texte dans lequel l'orientation ('VH', 'V' ou 'H')
subFeatureFlags
les indicateurs de sous-fonction qui contrôlent si la table est utilisée (UInt32)

Les champs supplémentaires dépendent du type de sous-table :

Table de réarrangement :
classes
tableau de listes de glyphes
states
tableau de tableaux de hachages{'nextState', 'flags'}

Table de substitution contextuelle :

classes
tableau de listes de glyphes
states
tableau de tableaux de hachages{'nextState', 'flags', 'actions'}, où "actions" est un tableau de deux éléments qui sont des décalages à ajouter à [marqué, actuel] glyphe pour obtenir l'index dans "mappings" (ou "undef" si aucune correspondance à appliquer)
mappings
liste des codes de glyphes mappés via les correspondances de la table d'états
