Font::TTF::Maxp(3) Documentation Perl fournie par l'utilisateur Font::TTF::Maxp(3)

NOM

Font::TTF::Maxp - Tableau de Profil Maximum dans une police

DESCRIPTION

Une collection de variables d'instance utiles suivant la norme TTF. Probablement la plus utilisée est "numGlyphs". Notez que cette valeur particulière est fondamentale et doit être tenue à jour par l'application, elle n'est pas mise à jour par "update".

Gère les versions 0.5, 1.0 du tableau

VARIABLES D'INSTANCE

Aucune autre que celles spécifiées dans la norme :

numGlyphs
maxPoints
maxContours
maxCompositePoints
maxCompositeContours
maxZones
maxTwilightPoints
maxStorage
maxFunctionDefs
maxInstructionDefs
maxStackElements
maxSizeOfInstructions
maxComponentElements
maxComponentDepth

MÉTHODES

$t->read

Lit le tableau en mémoire

$t->out($fh)

Écrit le tableau dans un fichier, soit depuis la mémoire, soit par copie.

$t->minsize()

Retourne la taille minimale que ce tableau peut avoir. S'il est plus petit que cela, alors le tableau est corrompu et devrait être supprimé ou traité comme tel.

$t->update

Calcule toutes les valeurs maximales pour une police en se basant sur les glyphes de la police. Seuls les champs qui nécessitent une interprétation du code de l'hinting sont ignorés et laissés tels qu'ils ont été lus.
