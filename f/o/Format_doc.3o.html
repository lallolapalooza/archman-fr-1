Module Format_doc

Document composable pour le moteur de mise en forme Format.

Ce module introduit un type de document pur et immuable qui représente une séquence d'instructions de mise en forme à imprimer par un moteur de mise en forme à un moment ultérieur. Dans le même temps, il fournit également un interpréteur de chaînes de format qui produit ce type de document à partir de chaînes de format et de leurs imprimantes associées.

Le module est conçu pour être source compatible avec le code définissant les imprimantes de format : remplacer `Format` par `Format_doc` dans votre code convertira les imprimantes `Format` en imprimantes `Format_doc`.

API de compatibilité

Les fonctions et types ci-dessous fournissent une compatibilité source avec les imprimantes de format et les fonctions de conversion des imprimantes Format_doc vers Format. La direction inverse est implémentée à l'aide d'une échappatoire dans l'instruction de mise en forme et ne doit être utilisée que pour préserver la compatibilité ascendante.

NAME

Format_doc.3o - Formater la sortie dans deux colonnes.

Module

Ce module est inclus dans le module Format.

Documentation

Écrit deux chaînes de caractères sur une seule ligne, séparées par un délimiteur. Par défaut, le délimiteur est le caractère |.

L'option max_lines peut être utilisée pour indiquer un nombre maximum de lignes à imprimer. Des points de suspension sont insérés au milieu si l'entrée contient trop de lignes.

Exemple:

pp_two_columns ~max_lines:3 Format.std_formatter [ "abc", "hello"; "def", "zzz"; "a" , "bllbl"; "bb" , "dddddd"; ]

imprime

abc | hello ... bb | dddddd
