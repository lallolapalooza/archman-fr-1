NOM

Font::TTF::Kern - Tables de crénage

DESCRIPTION

Les tables de crénage sont conservées comme une collection ordonnée de sous-tables, chacune fournissant des informations incrémentielles concernant le crénage de diverses paires de glyphes.

La structure de base de la structure de données de crénage est :

$kern = $f->{'kern'}{'tables'}[$tnum]{'kerns'}{$leftnum}{$rightnum};

En raison de la complexité potentielle de certaines tables de crénage, les informations ci-dessus sont insuffisantes. Il faut également se référer au type de la table et au champ de couverture.

VARIABLES D'INSTANCE

Les variables d'instance d'une table de crénage sont relativement simples.

Version
Numéro de version de la table de crénage
Num
Nombre de sous-tables dans la table de crénage
tables
Tableau de sous-tables dans la table de crénage

Chaque sous-table a un certain nombre de variables d'instance.

kern
Un tableau associatif à deux niveaux contenant les valeurs de crénage. L'indexation se fait par classe gauche et classe droite. Il peut sembler étrange d'utiliser des tableaux associatifs, mais la plupart des tables ne sont pas de type 2 et cette méthode permet d'économiser des valeurs de tableau vides.
type
Stocke le type de table. Seules les tables de type 0 et 2 sont spécifiées pour TrueType jusqu'à présent.
coverage
Un champ de bits contenant des informations de couverture concernant la valeur de crénage. Voir la spécification TrueType pour les détails.
Version
Contient le numéro de version de la table.
Num
Nombre de paires de crénage dans cette table de type 0.
left
Un tableau indexé par glyphe - left_first qui renvoie un numéro de classe pour le glyphe dans les tables de type 2.
right
Un tableau indexé par glyphe - right_first qui renvoie un numéro de classe pour le glyphe dans les tables de type 2.
left_first
le numéro du glyphe du premier élément du tableau gauche pour les tables de type 2.
right_first
le numéro du glyphe du premier élément du tableau droit pour les tables de type 2.
num_left
Nombre de classes gauches
num_right
Nombre de classes droites

MÉTHODES

$t->read

Lit la table de crénage entière dans des structures

$t->out($fh)

Affiche les tables de crénage dans le fichier donné

$t->XML_element($context, $depth, $key, $value)

Gère l'affichage du tableau associatif de crénage en XML de manière un peu plus propre

$t->minsize()

Renvoie la taille minimale que cette table peut avoir. Si elle est plus petite que cela, la table est probablement corrompue et devrait être supprimée ou traitée en conséquence.

BOGUES

  • Ne prend en charge que les types de tables de crénage 0 et 2.
  • Aucune fonction de support réelle pour *faire* quoi que ce soit avec les tables de crénage pour le moment.
