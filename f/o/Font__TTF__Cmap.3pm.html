NOM

Font::TTF::Cmap - Table de mappage de caractères

DESCRIPTION

Gère la table de mappage de caractères (cmap). Pour faciliter l'utilisation, la cmap réelle est conservée dans une table de hachage indexée par le point de code. Ainsi, pour une table donnée :

$gid = $font->{'cmap'}{'Tables'}[0]{'val'}{$code};

Notez que $code doit être une valeur numérique (0x1234) plutôt qu'une représentation textuelle.

VARIABLES D'INSTANCE

Les variables d'instance listées ici ne sont pas précédées d'un espace car elles émulent les informations structurelles de la police.

Num
Nombre de sous-tables dans cette table
Tables
Un tableau de sous-tables ([0..Num-1])

Chaque sous-table possède également ses propres variables d'instance qui, encore une fois, ne sont pas précédées d'un espace.

Platform
Le numéro de plateforme pour cette sous-table
Encoding
Le numéro d'encodage pour cette sous-table
Format
Indique le format stocké de cette sous-table
Ver
Indique les informations de version (ou de langue) pour cette sous-table
val
Une table de hachage indexée par la valeur du point de code (pas une chaîne) stockant l'ID du glyphe

Les options de cmap suivantes sont contrôlées par des variables d'instance qui commencent par un espace :

allowholes
Par défaut, lors de la génération des sous-tables cmap de format 4, les codes de caractères qui pointent vers le glyphe zéro (normalement appelé .notdef) ne sont pas inclus dans la sous-table. Dans certains cas, l'inclusion de certains de ces codes de caractères peut entraîner une sous-table de format 4 plus petite. Pour activer ce comportement, définissez allowholes à une valeur non nulle.

MÉTHODES

$t->read

Lit la cmap en mémoire. Les sous-tables de format 4 lisent la sous-table entière et remplissent le tableau segmenté en conséquence.

$t->ms_lookup($uni)

Recherche une table Unicode, en privilégiant celle de MS, et recherche le point de code Unicode donné pour trouver l'ID du glyphe.

$t->find_ms

Recherche une table Unicode, en privilégiant celle de Microsoft, et définit la variable d'instance "mstable" sur celle-ci si elle est trouvée. Renvoie la table trouvée.

$t->ms_enc

Renvoie l'encodage de la table Microsoft (0 => symbole, etc.). Renvoie undef s'il n'y a pas de cmap Microsoft.

$t->out($fh)

Écrit une table cmap dans un descripteur de fichier. Si elle n'a pas été lue, elle copie simplement du fichier d'entrée vers la sortie.

$t->XML_element($context, $depth, $name, $val)

Génère les éléments de la cmap en XML. Nous devons uniquement traiter `val` ici.

$t->minsize()

Renvoie la taille minimale de cette table en octets. Si elle est plus petite que cela, alors la table doit être corrompue et doit être supprimée ou traitée en conséquence.

$t->update

Nettoie la table cmap.

Supprime la cmap MS Fmt12 si elle n'est plus nécessaire.

Supprime de toutes les cmaps tout point de code qui mappe vers GID=0. Notez que de telles entrées seront réintroduites si nécessaire en fonction du format de la cmap.

@map = $t->reverse(%opt)

Renvoie une carte inversée de la cmap Unicode. C'est-à-dire, étant donné un glyphe, elle renvoie la valeur Unicode correspondante. Les options sont :

tnum
Numéro de table à utiliser plutôt que la table Unicode par défaut
array
Renvoie chaque élément de l'inversion sous forme de tableau car un glyphe peut être mappé par plusieurs valeurs Unicode. Les tableaux ne sont pas triés. Sinon, stocke une seule valeur Unicode pour un glyphe.

is_unicode($index)

Indique si la table d'un index donné est connue pour être une table Unicode (telle que spécifiée dans les spécifications).

BOGUES

•
Les cmaps de format 14 (Séquences de variation Unicode) ne sont pas prises en charge.
