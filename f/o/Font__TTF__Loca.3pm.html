NOM

Font::TTF::Loca - la table des emplacements, intimement liée à la table glyf

DESCRIPTION

La table d'emplacements contient le répertoire des emplacements de chaque glyphe dans la table glyf. En raison de cette relation et de l'importance peu élevée des emplacements réels lors du stockage des glyphes en mémoire, la lecture de la table d'emplacements aboutit à la création d'objets glyphes pour chaque glyphe et les stocke ici. Donc, si vous cherchez des glyphes, ne regardez pas dans la table "glyf", regardez plutôt ici.

Les choses se compliquent si vous essayez de modifier la liste des glyphes au sein de la même table. La recommandation est de créer un autre objet d'emplacement propre pour remplacer cette table dans la police, en s'assurant que l'ancienne table est lue en premier et en transférant ou copiant les glyphes de la table lue vers la nouvelle table.

VARIABLES D'INSTANCE

Les variables d'instance ne commencent pas par un espace

glyphs
Un tableau d'objets glyphes pour chaque glyphe.
glyphtype
Une chaîne contenant le nom de la classe à créer pour chaque nouveau glyphe. Si elle est vide, la valeur par défaut est Font::TTF::Glyph.

MÉTHODES

$t->new

Crée une nouvelle table d'emplacements en s'assurant qu'elle possède un tableau de glyphes

$t->read

Lit la table d'emplacements en créant des objets glyphes (Font::TTF::Glyph) pour chaque glyphe, permettant leur lecture ultérieure.

$t->out($fh)

Écrit la table d'emplacements dans $fh. Notez que ne pas avoir lu la table d'emplacements implique que la table glyf n'a pas non plus été lue, donc les nombres dans la table d'emplacements sont toujours valides. Espérons que "maxp/numGlyphs" et "head/indexToLocFmt" n'ont pas changé, sinon nous sommes en gros pétrin.

La fonction utilise l'emplacement OUTLOC dans le glyphe calculé lors de la tentative de sortie de la table glyf.

$t->out_xml($context, $depth)

Pas besoin de générer une table loca, celle-ci est générée dynamiquement

$t->glyphs_do(&func)

Appelle func pour chaque glyphe dans cette table d'emplacements dans l'ordre numérique :

&func($glyph, $glyph_num)
