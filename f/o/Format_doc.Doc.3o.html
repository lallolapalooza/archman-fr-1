type ('a, 'b) fmt = ('a, t, t, 'b) format4

type printer0 = t -> t

type 'a printer = 'a -> printer0

val empty : t

Document vide

val format : Format.formatter -> t -> unit

format ppf doc envoie l'instruction de formatage de doc au formateur doc de Format.

val fold : ('acc -> element -> 'acc) -> 'acc -> t -> 'acc

Plie sur un document comme une séquence d'instructions

val msg : ('a, t) fmt -> 'a

Format_doc.Doc.msg et Format_doc.Doc.kmsg produisent un document à partir d'une chaîne de format et de son argument

val kmsg : (t -> 'b) -> ('a, 'b) fmt -> 'a

val printf : ('a, printer0) fmt -> 'a

Format_doc.Doc.printf et Format_doc.Doc.kprintf produisent une imprimante à partir d'une chaîne de format et de son argument

val kprintf : (t -> 'b) -> ('a, t -> 'b) fmt -> 'a

Fonctions d'alignement

val align_prefix : (t * int) list -> t list

Aligne le côté droit d'une boîte de balise "@{<ralign>...@}" en insérant des espaces au début des boîtes. Ces fonctions ne font rien si la boîte de balise apparaît après un indice de saut de ligne.
