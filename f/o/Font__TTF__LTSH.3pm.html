NOM

Font::TTF::LTSH - Table de seuil linéaire

DESCRIPTION

Contient le seuil linéaire pour chaque glyphe. Il s'agit de la valeur ppem à laquelle les métriques d'un glyphe deviennent linéaires. La valeur est définie à 1 si les métriques d'un glyphe sont toujours linéaires.

VARIABLES D'INSTANCE

glyphes
Un tableau de valeurs ppem. Une valeur par glyphe.

MÉTHODES

$t->lire

Lit la table.

$t->sortir($fh)

Écrit la table LTSH dans le fichier spécifié par $fh.

$t->taille_minimale()

Retourne la taille minimale de cette table. Si elle est inférieure à cette valeur, la table est considérée comme erronée et doit être supprimée ou traitée en conséquence.

BOGUES

Aucun connu.
