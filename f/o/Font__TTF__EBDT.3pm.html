NOM

Font::TTF::EBDT - Table de données de bitmap intégrées

DESCRIPTION

Contient les métriques et les données d'image bitmap.

VARIABLES INSTANCES

Ne possède qu'une variable d'instance 'bitmap'. C'est un tableau de tableaux associatifs indexés par l'ID de glyphe. L'élément est un objet composé d'informations de métriques et de données d'image.

objet bitmap
format
Seul 7 est pris en charge.
hauteur
largeur
horiBearingX
horiBearingY
horiAdvance
vertBearingX
vertBearingY
vertAdvance
imageData

MÉTHODES

$t->read

Lit les données de bitmap intégrées à partir du fichier TTF en mémoire. Cette routine doit être appelée _après_ {'EBLC'}->read.

$t->update

Met à jour les informations EBLC en utilisant les données EBDT.

$t->out($fh)

Sort les données bitmap des bitmaps intégrées pour cette police.

BOGUES

Seul le format 7 est implémenté. La sortie XML n'est pas prise en charge (pour l'instant).
