Font::TTF::Head(3) Documentation Perl Contribuée par l'Utilisateur Font::TTF::Head(3)

NOM

Font::TTF::Head - La table head pour une police TTF

DESCRIPTION

Ceci est une table très basique avec uniquement des variables d'instance comme décrit dans la documentation TTF, en utilisant les mêmes noms. L'une des plus couramment utilisées est "unitsPerEm".

VARIABLES D'INSTANCE

La table "head" n'a pas de variables d'instance internes au-delà de celles communes à toutes les tables et de celles spécifiées dans la norme :

version
fontRevision
checkSumAdjustment
magicNumber
flags
unitsPerEm
created
modified
xMin
yMin
xMax
yMax
macStyle
lowestRecPPEM
fontDirectionHint
indexToLocFormat
glyphDataFormat

Les deux dates sont conservées sous forme de tableau de deux entiers non signés longs (32 bits)

MÉTHODES

$t->lire

Lit la table en mémoire grâce à certaines fonctions utilitaires

$t->écrire($fh)

Écrit la table dans un fichier soit depuis la mémoire, soit en copiant. Si en mémoire (ce qui est généralement le cas) le champ checkSumAdjustment est défini à 0 comme par défaut si la somme de contrôle du fichier n'est pas à prendre en compte.

$t->minsize()

Retourne la taille minimale que cette table peut avoir. Si elle est plus petite que cela, alors la table est mauvaise et devrait être supprimée ou quoi que ce soit.

$t->XML_element($contexte, $profondeur, $cle, $valeur)

Gère le traitement des dates pour l'exportateur XML

$t->mettre_à_jour

Met à jour la table head en fonction des données de glyphes et de la table hmtx

$t->getdate($is_create)

Convertit l'heure de modification de la police (ou l'heure de création si $is_create est défini) en un entier 32 bits tel que retourné par time(). Retourne undef si la valeur est hors limites, soit avant l'époque, soit après l'heure maximale stockable.

$t->setdate($temps, $is_create)

Définit les informations de temps pour la modification (ou l'heure de création si $is_create est défini) selon les informations de temps 32 bits.
