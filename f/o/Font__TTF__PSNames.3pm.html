Font::TTF::PSNames(3) Documentation Perl fournie par l'utilisateur Font::TTF::PSNames(3)

NOM

Font::TTF::PSNames - Utilitaires pour le traitement des noms de glyphes Postscript

SYNOPIS

use Font::TTF::PSNames qw(parse lookup);
$nom = lookup($uni);
$uni = parse($nom);

MÉTHODES

lookup ( $usv [, $noAlt [, $noUni] ])

renvoie le nom de glyphe recommandé par Adobe pour un point de code Unicode spécifique (entier). Par défaut, renvoie les noms "uniXXXX" plutôt que les noms "afiiNNNNN" ou "SFnnnnnn".

Si $noAlt est vrai, les noms "afii" et "SF" sont renvoyés plutôt que "uniXXXX".

si $noUni est vrai, renvoie undef s'il doit recourir aux noms de style "uniXXXX" ou "uXXXXXX". Essentiellement, cela représente une recherche directe dans la liste recommandée par Adobe.

parse ( $nomdeglyphe )

Analyse un nom de glyphe conforme à Adobe, générant une séquence de points de code Unicode équivalente au glyphe (ou aux composants du glyphe, si le nom représente une ligature). En contexte scalaire, renvoie une référence à un tableau d'Unicode (décimaux). Le tableau est vide si le nom du glyphe n'est pas conforme. En contexte de liste, le premier élément renvoyé est une référence au tableau d'Unicode comme ci-dessus. Le second élément est une référence à un tableau contenant les extensions (le cas échéant) présentes sur le nom du glyphe. Le '.' qui précède chaque extension n'est pas inclus.
