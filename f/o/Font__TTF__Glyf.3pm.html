NOM

Font::TTF::Glyf - La table de données Glyf

DESCRIPTION

Ceci est une table de substitution. Les données réelles sont détenues dans la table loca. Si vous voulez obtenir un glyphe, recherchez-le dans la table loca comme "$f-"{'loca'}{'glyphs'}[$num]>. Il ne sera pas ici !

La différence entre la lecture de cette table et celle de la table loca est que la lecture de cette table entraînera la sortie des glyphes mis à jour plutôt que la simple copie des informations de glyphe du fichier d'entrée. Cela ralentit l'écriture de la police. Lisez donc la table glyf par opposition à la table loca si vous souhaitez modifier les données de glyphe. Lisez la table loca uniquement si vous souhaitez simplement lire les informations de glyphe.

Cette classe est cependant utilisée lors de l'écriture des glyphes.

MÉTHODES

$t->read

Lit la table "loca" à la place !

$t->out($fh)

Écrit tous les glyphes dans l'emplacement de la table parente, calculant un nouvel emplacement de sortie pour chacun.

$t->out_xml($context, $depth)

Sort tous les glyphes de la table des glyphes exactement là où ils sont censés être sortis !

$t->XML_start($context, $tag, %attrs)

Transfère le contrôle aux glyphes au fur et à mesure de leur apparition

$t->XML_end($context, $tag, %attrs)

Collecte les glyphes et les place dans la table loca
