Font::TTF::Anchor(3) Documentation Perl fournie par l'utilisateur Font::TTF::Anchor(3)

NOM

Font::TTF::Anchor - Points d'ancrage pour les tables GPOS

DESCRIPTION

L'ancre définit un point d'ancrage sur un glyphe fournissant diverses informations selon la quantité disponible, y compris des informations telles que les coordonnées, un point de courbe et même des modificateurs spécifiques à l'appareil.

VARIABLES D'INSTANCE

x
Coordonnée X du point d'ancrage
y
Coordonnée Y du point d'ancrage
p
Point de courbe sur le glyphe à utiliser comme point d'ancrage
xdev
Table d'appareil (delta) pour la coordonnée x
ydev
Table d'appareil (delta) pour la coordonnée y
xid
Ancre XId pour l'identifiant de métrique horizontal multi-maîtres
yid
Ancre YId pour l'identifiant de métrique vertical multi-maîtres

MÉTHODES

new

Crée une nouvelle Ancre.

read($fh)

Lit l'ancre à partir du descripteur de fichier donné à cet endroit. Le descripteur de fichier est laissé à un point de lecture arbitraire, généralement la fin de quelque chose !

out($fh, $style)

Écrit l'ancre dans le descripteur de fichier donné à cet endroit, traitant également les problèmes de deltas. Si $style est défini, aucune sortie n'est envoyée au descripteur de fichier. La valeur de retour est la chaîne de sortie.

$a->out_xml($context)

Écrit l'ancre en XML.
