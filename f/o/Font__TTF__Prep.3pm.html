NOM

Font::TTF::Prep - Programme de préparation d'indices. Appelée lorsque ppem change

DESCRIPTION

Il s'agit d'une classe minimale n'ajoutant rien au-delà d'une table, mais c'est un répertoire d'informations de type prep pour les processus qui osent s'attaquer au hinting.

$t->read

Lit les données à l'aide de "read_dat".

$t->out_xml($context, $depth)

Sortie du programme Prep en XML

$t->XML_end($context, $tag, %attrs)

Analyse tout ce code de hinting
