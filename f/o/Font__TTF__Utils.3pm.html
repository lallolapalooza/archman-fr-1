NOM

Font::TTF::Utils - Fonctions utilitaires pour épargner les doigts

DESCRIPTION

De nombreuses fonctions utiles pour m'épargner les doigts, en particulier pour les tables triviales.

FONCTIONS

Les fonctions suivantes sont exportées.

($val, $pos) = TTF_Init_Fields ($str, $pos)

Étant donné une description de champ de la section "DATA", crée une entrée absolue dans le tableau associatif des champs pour la classe.

TTF_Read_Fields($obj, $dat, $fields)

Étant donné un bloc de données suffisamment grand pour couvrir tous les champs d'une table, traite le bloc de données pour convertir les valeurs dans les variables d'instance de l'objet par nom, en se basant sur la liste dans le bloc "DATA" qui a été traité par "TTF_Init_Fields".

TTF_Unpack($fmt, $dat)

L'équivalent des types TrueType de la fonction "unpack" de Perl. Ainsi, $fmt se compose d'un type suivi d'un nombre optionnel d'éléments à lire, y compris *. Le type peut être l'un des suivants :

c       BYTE
C       CHAR
f       FIXED
F       F2DOT14
l       LONG
L       ULONG
s       SHORT
S       USHORT
v       Numéro de version (FIXED)

Notez que "FUNIT", "FWORD" et "UFWORD" ne sont pas des types de données mais des unités.

Retourne un tableau de scalaires (premier élément) selon le contexte.

$dat = TTF_Out_Fields($obj, $fields, $len)

Étant donné la table des champs de "TTF_Init_Fields", écrit les variables d'instance de l'objet dans le descripteur de fichier sous forme binaire TTF.

$dat = TTF_Pack($fmt, @data)

L'équivalent TrueType de la fonction "pack" de Perl. Voir les détails de "TTF_Unpack" pour savoir comment utiliser la chaîne $fmt.

($num, $range, $select, $shift) = TTF_bininfo($num)

Calcule les informations de recherche binaire à partir d'un nombre d'éléments.

TTF_word_utf8($str)

Retourne la forme UTF8 de la chaîne de 16 bits, supposée être en ordre big-endian, y compris la gestion des surrogats.

TTF_utf8_word($str)

Retourne la forme 16 bits en ordre big-endian de la chaîne UTF8, y compris la gestion des surrogats vers Unicode.

XML_hexdump($context, $dat)

Affiche les données fournies sous forme d'une séquence de blocs <data>, chacun de 16 octets de large.

XML_outhints

Convertit une chaîne binaire de code de hinting en une représentation textuelle.

make_circle($f, $cmap, [$dia, $sb, $opts])

Ajoute un cercle pointillé à une police. Cette fonction est très configurable. Les paramètres passés sont :

f
Police avec laquelle travailler. Obligatoire.
cmap
Une table cmap (pas l'élément `val` d'un cmap) à laquelle ajouter le glyphe. Optionnel.
dia
Diamètre optionnel pour le cercle principal. Par défaut 80% de l'em.
sb
Graisse latérale. Les graisses latérales gauche et droite sont toujours identiques. Cette valeur par défaut est de 10% de l'em.

Il existe diverses options pour contrôler tous les aspects intéressants du cercle.

nombreDePoints
Nombre de points dans le cercle.
nombreDeCourbes
Nombre de points de courbe à utiliser pour créer chaque point.
identifiantUnique
Référence Unicode pour stocker ce glyphe dans le cmap. Par défaut 0x25CC.
nomPostscript
Nom Postscript à donner au glyphe. Par défaut uni25CC.
-rayonDunPoint
Rayon de chaque point.
