NOM

Font::TTF::GSUB - Module de support pour la table GSUB en conjonction avec TTOpen

DESCRIPTION

Gère les sous-tables GSUB en relation avec les tables Ttopen. En raison de la variété des différents types de recherche, les structures de données ne sont pas si simples, bien que j'aie essayé de me faciliter la vie en l'utilisant !

VARIABLES D'INSTANCE

La structure d'une table GSUB est la même que celle donnée dans Font::TTF::Ttopen. Ici, nous donnons quelques sémantiques spécifiques aux recherches GSUB.

ACTION_TYPE
C'est une chaîne de caractères prenant l'une des 4 valeurs indiquant la nature de l'information dans le tableau ACTION de la règle :
g
L'action contient une chaîne de glyphes pour remplacer la chaîne de correspondance.
l
Le tableau d'action contient une liste d'offsets et de recherches à exécuter, dans l'ordre, sur la chaîne correspondante.
a
Le tableau d'action est un ensemble non ordonné de remplacements optionnels pour le glyphe correspondant. L'application devrait faire la sélection d'une manière ou d'une autre.
o
Le tableau d'action est vide (en fait, il n'y a pas de tableau de règle pour ce type de règle) et la valeur ADJUST doit être ajoutée à l'identifiant du glyphe pour trouver l'identifiant du glyphe de remplacement.
r
Le tableau d'action est une liste de glyphes de remplacement dans l'ordre de la couverture. Ce ACTION_TYPE est utilisé uniquement pour les recherches inversées enchaînées de type 8 qui, par conception, sont une substitution de glyphe unique.
MATCH_TYPE
Ceci indique quel type d'information les divers tableaux MATCH (MATCH, PRE, POST) contiennent dans la règle :
g
Le tableau contient une chaîne d'identifiants de glyphes qui doivent correspondre exactement.
c
Le tableau contient une séquence de définitions de classes auxquelles chaque glyphe doit correspondre.
o
Le tableau contient des offsets vers les tables de couverture.

CORRESPONDANCE AUX TYPES DE MISE EN PAGE

Le tableau suivant donne les valeurs pour ACTION_TYPE et MATCH_TYPE pour chacun des 12 différents types de recherche trouvés dans la définition de la table GSUB :

              1.1 1.2  2  3  4  5.1 5.2 5.3  6.1 6.2 6.3  8
ACTION_TYPE    o   g   g  a  g   l   l   l    l   l   l   r
MATCH_TYPE                   g   g   c   o    g   c   o   o

On espère que le reste des utilisations des variables aura du sens à partir de ce tableau.

MÉTHODES

$t->read_sub($fh, $lookup, $index)

Demandé par la superclasse pour lire depuis le fichier donné l'index de sous-table du numéro de recherche lookup. Le fichier est positionné prêt pour la lecture.

$t->extension

Retourne le numéro de type de table pour la table d'extension.

$t->out_sub($fh, $lookup, $index)

Transmis le handle de fichier pour la sortie, convenablement positionné, la recherche et l'index de sous-table, cette fonction sort la sous-table vers $fh à ce moment-là.
