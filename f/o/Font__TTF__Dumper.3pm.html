Font::TTF::Dumper(3) Documentation Perl Contribuée par l'Utilisateur Font::TTF::Dumper(3)

NOM

Font::TTF::Dumper - Vidage de débogage d'une structure de données de police, évitant la récursion sur ' PARENT'

SYNOPIS

use Font::TTF::Dumper;

# Afficher une table de la structure de police :
print ttfdump($font->{$tag});

# Afficher la table de police avec son nom
print ttfdump($font->{'head'}, 'head');

# Afficher la table de police avec son nom et d'autres options
print ttfdump($font->{'head'}, 'head', %opts);
# Afficher les données d'un glyphe :
print ttfdump($font->{'loca'}->read->{'glyphs'}[$gid], "glyph_$gid");

DESCRIPTION

Les structures de données de Font::TTF sont des arbres créés à partir de hachages et de tableaux. Lorsque l'on essaie de comprendre le fonctionnement des structures, il est parfois utile d'utiliser Data::Dumper. Cependant, bon nombre des structures d'objets ont des liens ' PARENT' qui renvoient au parent de l'objet, ce qui signifie que Data::Dumper finit par tout vider, quoi qu'il arrive.

Le but principal de ce module est d'appeler Data::Dumper avec un filtre qui ignore l'élément ' PARENT' de tout hachage.

Pour réduire davantage la sortie, ce module ignore également les éléments ' CACHE' et tout élément de hachage dont la valeur est un objet Font::TTF::Glyph ou Font::TTF::Font. (Il faudrait vraiment rendre cela configurable.)

Si $opts{'d'}, alors le mode Deepcopy est activé pour minimiser l'utilisation de références croisées.
