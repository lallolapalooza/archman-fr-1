NOM

Font::TTF::Cvt_ - Table des valeurs de contrôle dans une police TrueType

DESCRIPTION

Il s'agit d'une classe minimale n'ajoutant rien au-delà d'une table, mais elle constitue un dépôt d'informations sur le type de cvt pour les processus suffisamment audacieux pour aborder le 'hinting' (ajustement des polices).

VARIABLES DISTINCTES

val
Ceci est un tableau de valeurs CVT. L'accès au CVT se fait donc via : 
$f->{'cvt_'}{'val'}[$num];

MÉTHODES

$t->lecture

Lit la table CVT dans la variable ' dat' de la table ainsi que dans le tableau "val".

$t->mise_à_jour

Met à jour la copie en mémoire du fichier ' dat' pour qu'elle soit identique au tableau.
