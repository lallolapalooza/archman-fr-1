NOM

Font::TTF::Fmtx - Table des métriques de police

DESCRIPTION

Il s'agit d'une table simple avec uniquement des variables d'instance standard spécifiées.

VARIABLES INSTANCE

version
glyphIndex
horizontalBefore
horizontalAfter
horizontalCaretHead
horizontalCaretBase
verticalBefore
verticalAfter
verticalCaretHead
verticalCaretBase

MÉTHODES

$t->read

Lit la table en mémoire sous forme de variables d'instance.

$t->out($fh)

Écrit la table dans un fichier, soit à partir de la mémoire, soit par copie.

BOGUES

Aucun connu.
