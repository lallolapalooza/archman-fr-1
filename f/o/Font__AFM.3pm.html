NOM

Font::AFM - Interface avec les fichiers Adobe Font Metrics

SYNTAXE

use Font::AFM;
$h = new Font::AFM "Helvetica";
$copyright = $h->Notice;
$w = $h->Wx->{"aring"};
$w = $h->stringwidth("Gisle", 10);
$h->dump;  # pour le débogage

DESCRIPTION

Ce module implémente la classe Font::AFM. Les objets de cette classe sont initialisés à partir d'un fichier AFM (Adobe Font Metrics) et vous permettent d'obtenir des informations sur la police et les métriques des différents glyphes de la police.

Toutes les mesures dans les fichiers AFM sont données en unités égales à 1/1000 du facteur d'échelle de la police utilisée. Pour calculer les tailles réelles dans un document, ces montants doivent être multipliés par (facteur d'échelle de la police)/1000.

Les méthodes suivantes sont disponibles :

$afm = Font::AFM->new($nom_police)
Constructeur d'objet. Prend le nom de la police comme argument. Croak si la police ne peut pas être trouvée.
$afm->latin1_wx_table()
Retourne un tableau de 256 éléments, où chaque élément contient la largeur du caractère correspondant dans l'ensemble de caractères iso-8859-1.
$afm->stringwidth($chaine, [$taille_police])
Retourne la largeur de la chaîne d'argument. La chaîne est supposée être encodée dans l'ensemble de caractères iso-8859-1. Un deuxième argument peut être utilisé pour mettre à l'échelle la largeur en fonction de la taille de la police.
$afm->FontName
Le nom de la police tel qu'il est présenté à l'opérateur "findfont" du langage PostScript, par exemple "Times-Roman".
$afm->FullName
Nom unique et lisible par l'homme pour une police individuelle, par exemple "Times Roman".
$afm->FamilyName
Nom lisible par l'homme pour un groupe de polices qui sont des variantes stylistiques d'un même design. Toutes les polices qui sont membres d'un tel groupe doivent avoir exactement le même "FamilyName". Exemple de nom de famille : "Times".
$afm->Weight
Nom lisible par l'homme pour l'attribut de graisse, ou "force", d'une police. Exemples : "Roman", "Bold", "Light".
$afm->ItalicAngle
Angle en degrés dans le sens antihoraire par rapport à la verticale des traits verticaux dominants de la police.
$afm->IsFixedPitch
Si "true", la police est une police à pas fixe (monospaced).
$afm->FontBBox
Une chaîne de quatre nombres donnant le coin inférieur gauche x, le coin inférieur gauche y, le coin supérieur droit x et le coin supérieur droit y de la boîte englobante de la police. La boîte englobante de la police est le plus petit rectangle englobant la forme qui résulterait si tous les caractères de la police étaient placés avec leurs origines coïncidentes, puis peints.
$afm->UnderlinePosition
Distance recommandée par rapport à la ligne de base pour positionner les traits de soulignement. Ce nombre est la coordonnée y du centre du trait.
$afm->UnderlineThickness
Épaisseur de trait recommandée pour le soulignement.
$afm->Version
Numéro de version de la police.
$afm->Notice
Avis de marque commerciale ou de droit d'auteur, le cas échéant.
$afm->Comment
Commentaires trouvés dans le fichier AFM.
$afm->EncodingScheme
Le nom du schéma d'encodage standard pour la police. La plupart des polices Adobe utilisent "AdobeStandardEncoding". Les polices spéciales peuvent indiquer "FontSpecific".
$afm->CapHeight
Habituellement, la valeur y du haut de la lettre capitale H.
$afm->XHeight
Typiquement, la valeur y du haut de la lettre minuscule x.
$afm->Ascender
Typiquement, la valeur y du haut de la lettre minuscule d.
$afm->Descender
Typiquement, la valeur y du bas de la lettre minuscule p.
$afm->Wx
Retourne une table de hachage qui mappe les noms des glyphes à la largeur de ce glyphe.
$afm->BBox
Retourne une table de hachage qui mappe les noms des glyphes aux informations de boîte englobante. La boîte englobante se compose de quatre nombres : llx, lly, urx, ury.
$afm->dump
Vide le contenu de l'objet Font::AFM sur STDOUT. Peut parfois être utile pour le débogage.

La spécification AFM peut être trouvée à :

http://partners.adobe.com/asn/developer/pdfs/tn/5004.AFM_Spec.pdf

ENVIRONNEMENT

METRICS
Contient le chemin de recherche des fichiers AFM. Le format est le même que pour la variable d'environnement PATH. Le chemin par défaut intégré à cette bibliothèque est : 
/usr/lib/afm:/usr/local/lib/afm:/usr/openwin/lib/fonts/afm/:.

BOGUES

Les données de crénage et les données de caractères composites ne sont pas encore analysées. Les données de ligatures ne sont pas analysées.
