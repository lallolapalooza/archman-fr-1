Font::TTF::OTTags(3) Documentation Perl fournie par l'utilisateur Font::TTF::OTTags(3)

NOM

Font::TTF::OTTags - Utilitaires pour les étiquettes TrueType/OpenType

SYNOPSIS

use Font::TTF::OTTags qw( %tttags %ttnames %iso639 readtagsfile );

# Examiner les éléments intégrés :
$script_tag = $tttags{'SCRIPT'}{'Cypriot Syllabary'};  # renvoie 'cprt'
$lang_name = $ttnames{'LANGUAGE'}{'ALT '};             # renvoie 'Altai'

# Mapper une étiquette iso639-2 vers/depuis une étiquette de langue OT
@isotags = $iso639{'ALT '};    # renvoie [ 'atv', 'alt' ]
$lang_tag = $iso639{'atv'};    # renvoie 'ALT '

# Lire le dernier fichier d'étiquettes pour ajouter aux définitions intégrées
readtagsfile ("C:\\Program Files\\Microsoft VOLT\\TAGS.txt");

Les clés de premier niveau pour %tttags et %ttnames sont :

SCRIPT
récupérer l'étiquette ou le nom du script
LANGAGE
récupérer l'étiquette ou le nom de la langue
FONCTIONNALITE
récupérer l'étiquette ou le nom de la fonctionnalité

Les données intégrées sont dérivées du brouillon du 11-07-2014 de la 3ème édition de la norme ISO/IEC 14496-22 (Technologies de l'information - Codage des objets audiovisuels - Partie 22 : Format Open Font) qui, une fois finalisée et approuvée, remplacera la seconde édition (ISO/IEC 14496-22:2009).

MÉTHODES

lirefichierétiquettes ( nomfichier )

Lit un fichier dans la syntaxe de Tags.txt (inclus avec Microsoft VOLT) pour obtenir des définitions d'étiquettes supplémentaires/de remplacement.

Renvoie 0 si le fichier ne peut être ouvert ; sinon, renvoie 1.
