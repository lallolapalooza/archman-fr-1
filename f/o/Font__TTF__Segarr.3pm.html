NOM

Font::TTF::Segarr - Tableau segmenté

DESCRIPTION

Contient des données soit directement, soit indirectement sous forme d'une série de tableaux. Cette classe gère l'ensemble des tableaux et masque les sous-tableaux individuels, économisant ainsi une classe, nous l'espérons.

VARIABLES D'INSTANCE

Toutes les variables d'instance ne commencent pas par un espace.

Le tableau segmenté est simplement un tableau de segments.

Chaque segment est une affaire plus complexe :

START
En termes de tableau, l'adresse du 0ème élément dans ce segment.
LEN
Nombre d'éléments dans ce segment.
VAL
Le tableau contenant les éléments.

MÉTHODES

Font::TTF::Segarr->new($taille)

Crée un nouveau tableau segmenté avec une taille de données donnée.

$s->fastadd_segment($debut, $is_sparse, @données)

Crée un nouveau segment et l'ajoute au tableau en supposant qu'il n'y a pas de chevauchement entre le nouveau segment et les autres du tableau. $is_sparse indique si le tableau passé contient des "undef" ou non. Si faux, aucune vérification n'est effectuée (ce qui est plus rapide, mais plus risqué). Si égal à 2, 0 est également considéré comme undef.

Retourne le nombre de segments insérés.

$s->add_segment($debut, $ecraser, @données)

Crée un nouveau segment et l'ajoute au tableau, permettant des chevauchements possibles entre le nouveau segment et ceux existants. En cas de chevauchement, les éléments du nouveau segment sont supprimés, sauf si $ecraser est défini, auquel cas les éléments déjà présents sont écrasés.

Cette méthode vérifie également si les données entrantes sont éparses (c'est-à-dire si elles contiennent des valeurs undef). Les écarts entraînent la création de nouveaux segments ou le non-écrasement des valeurs existantes.

$s->tidy

Fusionne tous les segments immédiatement adjacents.

$s->at($adresse, [$longueur])

Recherche les données détenues à l'adresse donnée en localisant le segment approprié, etc. Si $longueur > 1, retourne un tableau de valeurs, les espaces étant remplis avec undef.

$s->remove($adresse, [$longueur])

Supprime l'élément ou les éléments de l'adresse, les retournant sous forme de tableau ou la première valeur dans un contexte scalaire. Ceci est très similaire à "at", y compris le remplissage avec undef, mais cela supprime des éléments au fur et à mesure.

$s->copy

Copie en profondeur ce tableau.

$s->copy_seg($seg)

Crée une copie en profondeur d'un segment.

BOGUES
