NOM

Font::TTF::Hhea - Table d'en-tête horizontal

DESCRIPTION

Ceci est une table simple avec des variables d'instance standard uniquement

VARIABLES D'INSTANCE

version
Ascender
Descender
LineGap
advanceWidthMax
minLeftSideBearing
minRightSideBearing
xMaxExtent
caretSlopeRise
caretSlopeRun
metricDataFormat
numberOfHMetrics

MÉTHODES

$t->lire

Lit la table en mémoire sous forme de variables d'instance

$t->ecrire($fh)

Écrit la table dans un fichier, soit depuis la mémoire, soit par copie.

$t->taille_minimale()

Retourne la taille minimale que cette table peut avoir. Si elle est plus petite que cela, alors la table est considérée comme corrompue et doit être supprimée ou traitée en conséquence.

$t->mettre_a_jour

Met à jour divers paramètres de la table hhea à partir de la table hmtx.
