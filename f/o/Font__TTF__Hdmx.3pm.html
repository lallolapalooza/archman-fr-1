NOM

Font::TTF::Hdmx - Métriques de périphériques horizontales

DESCRIPTION

La table se compose d'une table de métriques de périphériques indexée par le ppem pour cette sous-table. Chaque sous-table se compose d'un tableau de largeurs d'avance en pixels pour chaque glyphe à ce ppem (horizontalement).

VARIABLES D'INSTANCE

Les métriques individuelles sont accessibles en utilisant la référence suivante :

$f->{'hdmx'}{$ppem}[$glyph_num]

De plus, il y a une variable d'instance :

Num
Nombre de tables de périphériques.

MÉTHODES

$t->read

Lit la table dans des structures de données.

$t->out($fh)

Sort les métriques de périphériques pour cette police.

$t->minsize()

Renvoie la taille minimale que cette table peut avoir. Si elle est plus petite que cela, alors la table doit être corrompue et devrait être supprimée ou traitée comme telle.

$t->tables_do(&func)

Pour chaque sous-table, appelle &sub($ref, $ppem)

$t->XML_element($context, $depth, $key, $value)

Sort les métriques de périphériques d'une manière un peu plus soignée.
