NOM

Font::TTF::OldCmap - Table de correspondance de caractères

Ce module est obsolète

DESCRIPTION

Gère la table de correspondance de caractères. La structure principale utilisée pour gérer une cmap est Font::TTF::Segarr qui gère les tableaux segmentés des tables de format 4, et sous une forme plus simple pour les tables de format 0.

En raison de la complexité du travail avec les tableaux segmentés, la plupart de la gestion de tels tableaux se fait par des méthodes plutôt que par des variables d'instance.

Une caractéristique importante d'une table de format 4 est qu'elle contient toujours un segment avec une adresse finale de 0xFFFF. Si vous créez une table à partir de zéro, c'est important (bien que Font::TTF::Segarr puisse fonctionner tout à fait correctement sans elle).

VARIABLES D'INSTANCE

Les variables d'instance listées ici ne sont pas précédées d'un espace en raison de leur émulation des informations structurelles dans la police.

Num
Nombre de sous-tables dans cette table
Tables
Un tableau de sous-tables ([0..Num-1])

Chaque sous-table a également ses propres variables d'instance qui ne sont, encore une fois, pas précédées d'un espace.

Platform
Le numéro de plateforme pour cette sous-table
Encoding
Le numéro d'encodage pour cette sous-table
Format
Indique le format stocké de cette sous-table
Ver
Indique les informations de version (ou de langue) pour cette sous-table
val
Ceci pointe vers un Font::TTF::Segarr qui contient le contenu de la sous-table particulière.

MÉTHODES

$t->read

Lit la cmap en mémoire. Les sous-tables de format 4 lisent toute la sous-table et remplissent le tableau segmenté en conséquence.

Les sous-tables de format 2 ne sont pas lues du tout.

$t->ms_lookup($uni)

Étant donné une valeur Unicode dans la table MS (Plateforme 3, Encodage 1), localise cette table et en recherche le numéro de glyphe approprié.

$t->find_ms

Trouve la table Unicode Microsoft et y définit la variable d'instance "mstable" si elle est trouvée. Renvoie la table trouvée.

$t->out($fh)

Écrit une table cmap dans un descripteur de fichier. Si elle n'a pas été lue, copie simplement du fichier d'entrée vers la sortie.

@map = $t->reverse([$num])

Renvoie une carte inversée de la table du numéro donné ou de la cmap Microsoft. C'est-à-dire que pour un glyphe donné, elle renvoie la valeur Unicode correspondante.

BOGUES

•
Aucun support pour les tables de format 2 (MBCS)
