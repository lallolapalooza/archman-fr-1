NOM

Font::TTF::Gloc - Décalages dans la table Glat pour le début des attributs de chaque glyphe

DESCRIPTION

La table Gloc est un peu comme la table Loca, mais pour les attributs de glyphes Graphite. La table contient les éléments suivants :

Version
Version du format de la table
numAttrib
Nombre maximum d'attributs associés à un glyphe.
locations
Un tableau de décalages dans la table Glat pour le début de chaque glyphe.
names
Si défini, un tableau d'identifiants de noms de la table des noms indexé par le numéro d'attribut.

$t->minsize()

Retourne la taille minimale que cette table peut avoir. Si elle est plus petite que cela, alors la table est probablement corrompue et devrait être supprimée ou traitée autrement.
