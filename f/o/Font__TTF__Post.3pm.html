NOM

Font::TTF::Post - Contient les noms Postscript pour chaque glyphe

DESCRIPTION

Contient les noms postscript pour les glyphes. Notez qu'ils ne sont pas stockés sous forme de tableau, mais sous forme d'index dans deux listes. La première liste est la liste standard des noms Postscript définie par la norme TrueType. La seconde provient directement de la police.

La recherche d'un glyphe à partir d'un nom Postscript ou d'un nom à partir d'un numéro de glyphe s'effectue par le biais de méthodes plutôt que par l'accès aux variables.

Cette classe gère les tables PostScript de types 1, 2, 2.5 et 3, mais pas la version 4. La prise en charge de la version 2.5 est conforme à la spécification Apple plutôt qu'à celle de MS.

La manière de rechercher des noms Postscript ou des glyphes est la suivante :

$pname = $f->{'post'}{'VAL'}[$gnum];
$gnum = $f->{'post'}{'STRINGS'}{$pname};

VARIABLES D'INSTANCE

En raison des différentes limitations des systèmes, plusieurs variables de classe sont disponibles pour contrôler les types de tables post qui peuvent être écrits.

$Font::TTF::Post::no25
Si cette variable est définie, elle indique à Font::TTF::Post::out d'utiliser le type de table 2 au lieu de 2.5 si les applications ne peuvent pas gérer la version 2.5.
VAL
Contient un tableau indexé par le numéro de glyphe des noms Postscript. Ceci est utilisé lors de l'écriture d'une police.
STRINGS
Un tableau associatif des noms Postscript mappant au glyphe le plus élevé ayant ce nom. Ceux-ci peuvent ne pas être synchronisés avec VAL.

En outre, il existe les variables introductives standard définies dans la norme :

FormatType
italicAngle
underlinePosition
underlineThickness
isFixedPitch
minMemType42
maxMemType42
minMemType1
maxMemType1

MÉTHODES

$t->read

Lit la table Postscript dans la mémoire depuis le disque.

$t->out($fh)

Écrit une nouvelle table de noms Postscript depuis la mémoire ou la copie depuis le disque.

$t->XML_element($context, $depth, $key, $val)

Affiche les noms sous forme d'un bloc XML.

$t->minsize()

Retourne la taille minimale que cette table peut avoir. Si elle est plus petite que cela, alors la table doit être défectueuse et devrait être supprimée ou traitée.

BOGUES

•
Aucune prise en charge des tables de type 4.
