NOM

Font::TTF::Mort - Table de métamorphose de glyphes dans une police

MÉTHODES

$t->lire

Lit la table en mémoire.

$t->sortir($fh)

Écrit la table dans un fichier, soit depuis la mémoire, soit par copie.

$t->taille_minimale()

Retourne la taille minimale que cette table peut avoir. Si elle est plus petite que cela, la table est corrompue et doit être supprimée ou traitée en conséquence.

$t->afficher($fh)

Affiche une représentation de la table lisible par l'homme.
