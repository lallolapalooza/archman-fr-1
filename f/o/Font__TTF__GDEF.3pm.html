NOM

Font::TTF::GDEF - Support de la table GDEF d'OpenType

DESCRIPTION

La table GDEF contient diverses listes globales d'informations qui sont apparemment utilisées dans d'autres parties d'un moteur de rendu OpenType. Mais précisément où, cela reste sujet à spéculation...

VARIABLES DISTINCTES

Il peut y avoir jusqu'à 5 tables dans la table GDEF, chacune avec sa propre structure :

GLYPH
Ceci est une table de définition de classe Font::TTF::Coverage contenant des informations sur le type de chaque glyphe.
ATTACH
La table d'attachement consiste en une table de couverture, puis des points d'attachement pour chaque glyphe dans la table de couverture :
COVERAGE
Ceci est une table de couverture
POINTS
Ceci est un tableau d'éléments de points. Chaque élément est un tableau de points de courbe correspondant aux points d'attachement sur ce glyphe. L'ordre des points de courbe dans le tableau correspond au numéro de point d'attachement spécifié dans la table de couverture MARKS (voir ci-dessous).
LIG
Ceci contient les informations de positionnement des tirets de ligature pour les glyphes de ligature
COVERAGE
Une table de couverture pour indiquer quels glyphes sont des ligatures
LIGS
Un tableau d'éléments pour chaque ligature. Chaque élément est un tableau d'informations pour chaque position de tiret dans la ligature (il y en a autant que le nombre de composants moins 1, généralement)
FMT
Ceci est le format des informations et il est important de définir la sémantique de la valeur. Cette valeur doit être correctement définie avant la sortie
VAL
La valeur qui a un sens selon FMT
DEVICE
Pour FMT = 3, une table de périphériques est également référencée, qui est stockée ici
MARKS
Cette table de définition de classe définit les classes de glyphes de marque qui peuvent être sélectionnés pour le traitement en utilisant le champ MarkAttachmentType des mots de drapeau de recherche.
MARKSETS
Contient un tableau de tables de couverture indexées par la valeur FILTER d'une recherche.

MÉTHODES

$t->read

Lit la table dans la structure de données

$t->out($fh)

Écrit cette table.

$t->minsize()

Retourne la taille minimale que cette table peut avoir. Si elle est plus petite que cela, alors la table est probablement défectueuse et devrait être supprimée ou autre chose.

$t->update

Trie les tables COVERAGE.
