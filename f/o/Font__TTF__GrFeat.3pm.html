Font::TTF::GrFeat(3) Documentation Perl fournie par l'utilisateur Font::TTF::GrFeat(3)

NOM

Font::TTF::GrFeat - Caractéristiques des polices Graphite

DESCRIPTION

VARIABLES D'INSTANCE

version
features
Un tableau d'hashes de la forme suivante
feature
numéro d'identifiant de la caractéristique
name
index du nom dans la table des noms
exclusive
indicateur exclusif
default
le numéro du paramètre par défaut
settings
hash du numéro de paramètre contre l'index de la chaîne de nom

MÉTHODES

$t->read

Lit les caractéristiques depuis le fichier TTF en mémoire

$t->out($fh)

Écrit les caractéristiques dans un fichier TTF

$t->minsize()

Retourne la taille minimale que cette table peut avoir. Si elle est plus petite que cela, alors la table doit être corrompue et doit être supprimée ou autre.

$t->print($fh)

Affiche une représentation lisible par l'homme de la table

$t->tag_to_num ($feat_str)

Convertit une balise d'identifiant de caractéristique alphanumérique (chaîne) en un nombre (32 bits). Les balises font normalement 4 caractères. Graphite ignore le remplissage d'espaces s'il est présent, nous faisons de même ici.

$t->num_to_tag ($feat_num)

Convertit un numéro d'identifiant de caractéristique (32 bits) en une balise (chaîne). Le remplissage d'espaces ou de zéros à la fin est supprimé. Les numéros d'identifiant de caractéristique qui ne représentent pas de balises alphanumériques sont retournés inchangés.

BOGUES

La table Feat version 1 se termine par une caractéristique (id 1) nommée NoName avec zéro paramètre mais avec un décalage vers la dernière entrée du tableau de paramètres. Ce dernier paramètre a l'id 0 et un identifiant de nom invalide. Cette dernière caractéristique est modifiée pour avoir un paramètre.
