NOM

Font::TTF::Features::Size - Classe pour les paramètres de la fonctionnalité de variantes de caractères

DESCRIPTION

Gère les valeurs des paramètres de fonctionnalité pour les fonctionnalités de variantes de caractères.

VARIABLES D'INSTANCE

INFILE
Le descripteur de fichier lu
OFFSET
Emplacement du fichier dans le fichier d'entrée
Format
Format de la table - défini à 0
UINameID
L'ID du nom de la table 'name' qui spécifie une chaîne (ou des chaînes, pour plusieurs langues) pour une étiquette d'interface utilisateur pour cette fonctionnalité
TooltipNameID
L'ID du nom de la table 'name' pour le texte d'infobulle pour la fonctionnalité
SampleTextNameID
L'ID du nom de la table 'name' pour le texte d'exemple illustrant la fonctionnalité
NumNamedParms
Le nombre de paramètres nommés
FirstNamedParmID
L'ID du nom de la table 'name' pour le premier paramètre nommé
Characters
Un tableau contenant les valeurs unicode des caractères pour lesquels la fonctionnalité fournit des variantes de glyphes

MÉTHODES

$t->read

Lit les paramètres de la fonctionnalité.

$t->out($fh)

Écrit la table FeatureParams dans la sortie.

Font::TTF::Features::Sset->new()

Crée un nouvel objet FeatureParams. Les valeurs pour INFILE et OFFSET peuvent être passées comme paramètres.
