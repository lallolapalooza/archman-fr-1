NOM

Font::TTF::OS_2 - la table OS/2 dans une police TTF

DESCRIPTION

La table OS/2 a deux versions et formes, l'une étant une extension de l'autre. Ce module supporte les deux formes et le passage de l'une à l'autre.

MÉTHODES

$t->read

Lit les différentes valeurs depuis le disque (voir les détails de la table OS/2).

$t->out($fh)

Écrit la table dans un fichier soit depuis la mémoire, soit par copie.

$t->XML_element($context, $depth, $key, $value)

Nettoie les valeurs hexadécimales pour les afficher en hexadécimal.

$t->XML_end($context, $tag, %attrs)

Maintenant, on les traite à l'envers.

$t->minsize()

Retourne la taille minimale que cette table peut avoir. Si elle est plus petite que cela, alors la table doit être invalide et devrait être supprimée ou autre.

$t->update

Met à jour la table OS/2 en récupérant des informations d'autres sources :

Met à jour les valeurs "firstChar" et "lastChar" en se basant sur la table MS de la cmap.

Met à jour sTypoAscender, sTypoDescender et sTypoLineGap pour qu'ils soient identiques aux valeurs Ascender, Descender et Linegap de la table hhea (en supposant qu'elle soit "sale") et définit également usWinAscent pour être la somme de Ascender+Linegap et usWinDescent pour être l'opposé de Descender.

$t->guessRangeBits (\%map, [$cp_threshold, [%u_threshold]])

Définit les champs ulCodePageRange et ulUnicodeRange en fonction des caractères réellement présents dans la police.

%map est une table de hachage indexée par USV retournant une valeur non nulle pour les caractères présents (par exemple, utiliser {'val'} a de la cmap Unicode).

Les deux paramètres optionnels sont le pourcentage de caractères dans la page de code ou la plage Unicode qui doivent être présents pour constituer une couverture. Un seuil de 0 entraîne la définition des bits de plage correspondants si des caractères sont présents, tandis qu'une valeur négative entraîne la non-modification des bits de plage correspondants. Les valeurs par défaut sont 50 et 0, respectivement.

Pour les bits de page de code, le seuil est le pourcentage de caractères entre 0xC0 et 0xFF qui doivent être présents pour constituer une couverture. Pour les pages de code autres que 1252, les caractères (par exemple, la ponctuation) qui sont définis de manière identique à cp1252 sont ignorés pour le calcul de ce pourcentage. Ne recherche que les pages de code SBCS, pas les DBCS.

Pour les plages de bits Unicode qui représentent plusieurs plages, par exemple, le bit 29 représente :

Latin Extended Additional  1E00-1EFF
Latin Extended-C           2C60-2C7F
Latin Extended-D           A720-A7FF

le bit sera défini si l'une de ces plages satisfait aux exigences du seuil.
