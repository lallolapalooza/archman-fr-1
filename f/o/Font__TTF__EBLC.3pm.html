NOM

Font::TTF::EBLC - Table d'emplacement de bitmap incorporé

DESCRIPTION

Contient les tailles et les plages de glyphes des bitmaps, et les décalages vers les données de bitmaps de glyphes dans indexSubTables pour EBDT.

Peut potentiellement contenir des informations de métriques de glyphes.

VARIABLES D'INSTANCE

Les informations marquées '(R)ead only' (lecture seule) sont en lecture seule, elles sont calculées à partir de EBDT, lorsqu'il est mis à jour ('update').

bitmapSizeTable
Un tableau de tables d'informations suivantes
indexSubTableArrayOffset (R)
indexTablesSize (R)
numberOfIndexSubTables (R)
colorRef
hori
vert
startGlyphIndex (R)
endGlyphIndex (R)
ppemX
ppemY
bitDepth
flags
indexSubTableArray (R)
Un tableau qui contient des informations de plage.
indexSubTable (R)
Un tableau qui contient les décalages de la table EBDT.

MÉTHODES

$t->read

Lit les informations d'emplacement des bitmaps incorporés à partir du fichier TTF en mémoire.

$t->out($fh)

Produit les informations d'emplacement des bitmaps incorporés pour cette police.

BOGUES

Seul indexFormat ==1 est implémenté. La sortie XML n'est pas prise en charge (encore).
