NOM

Font::TTF::WOFF - contient les données du fichier de police Web Open Font File (WOFF) pour la police

DESCRIPTION

Contient les données d'empaquetage WOFF.

VARIABLES D'INSTANCE

Cet objet prend en charge les variables d'instance suivantes (qui, parce qu'elles reflètent la structure de la table, ne commencent pas par un espace) :

majorVersion
minorVersion
Les deux numéros de version proviennent directement de l'en-tête de la police WOFF.
metaData
Contient une référence à la structure Font::TTF::Woff::Meta, si la police possède des métadonnées WOFF.
privateData
Contient une référence à une structure Font::TTF::Woff::Private, si la police possède un bloc de données privées WOFF.
