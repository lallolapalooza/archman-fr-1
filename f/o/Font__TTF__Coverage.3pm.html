NOM

Font::TTF::Coverage - Objets de définition de classe et de couverture Opentype

DESCRIPTION

Les tables de couverture et les objets de définition de classe sont pratiquement des concepts identiques dans Opentype. Leur différence réside uniquement dans leur stockage. Par conséquent, on peut dire qu'une table de couverture est une définition de classe dans laquelle la définition de classe pour chaque glyphe est l'index correspondant dans la table de couverture. La structure de données résultante est qu'une table de couverture a les champs suivants :

couverture
Un booléen pour indiquer si cette table est une table de couverture (VRAI) ou une définition de classe (FAUX)
val
Une table de hachage d'identifiants de glyphes contre des valeurs (index de couverture ou valeur de classe)
fmt
Le format de stockage utilisé est indiqué ici, mais est recalculé lors de l'écriture de la table.
nb
Nombre d'éléments dans une table de couverture pour être utilisé avec `add`. Chaque ajout successif est ajouté avec le compte actuel et incrémente le compte.
max
Valeur de classe maximale dans une table de classe.

MÉTHODES

new($estCouverture [, vals])

Crée une nouvelle table de couverture ou une nouvelle définition de classe, selon la valeur de $estCouverture. Si $estCouverture est vrai, `vals` peut être une liste de glyphes à inclure dans l'ordre. Sinon, `vals` est une table de hachage de glyphes contre des valeurs de classe.

read($fh)

Lit la table de couverture/classe depuis le descripteur de fichier fourni.

out($fh, $état)

Écrit la table de couverture/classe dans le descripteur de fichier fourni. Si $état est 1, la chaîne de sortie est renvoyée au lieu d'être envoyée à un descripteur de fichier.

$c->ajouter($idGlyphe[, $classe])

Ajoute un identifiant de glyphe à la table de couverture ou de classe. Renvoie l'index ou le numéro de classe du glyphe ajouté.

$c->signature

Renvoie un vecteur de tous les identifiants de glyphes couverts par cette table de couverture ou classe.

@map=$c->trier

Trie la table de couverture de sorte que les index soient dans l'ordre croissant des identifiants de glyphes. Renvoie une carte telle que $map[$nouvel_index]=$ancien_index.

$c->out_xml($contexte)

Sortie de cette couverture/classe en XML.
