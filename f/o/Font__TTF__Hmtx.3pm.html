NOM

Font::TTF::Hmtx - Métriques horizontales

DESCRIPTION

Contient la largeur d'avancement et le repère de côté gauche pour chaque glyphe. Compte tenu de la compressibilité des données sur disque, cette table utilise des informations provenant d'autres tables, et doit donc effectuer une partie de sa sortie lors de la sortie d'autres tables.

VARIABLES D'INSTANCE

Les métriques horizontales sont conservées dans deux tableaux par ID de glyphe. Les noms des variables ne commencent pas par un espace.

advance
Un tableau contenant la largeur d'avancement pour chaque glyphe.
lsb
Un tableau contenant le repère de côté gauche pour chaque glyphe.

MÉTHODES

$t->read

Lit les métriques horizontales du fichier TTF en mémoire.

$t->numMetrics

Calcule à nouveau le nombre de métriques longues nécessaires pour stocker les informations ici. Renvoie undef si la table n'a pas été lue.

$t->out($fh)

Écrit les métriques dans un fichier TTF. Suppose que le "hhea" a mis à jour le numHMetrics à partir d'ici.

$t->update

Met à jour les valeurs lsb à partir du xMin de chaque glyphe.

$t->out_xml($context, $depth)

Affiche la table en XML.
