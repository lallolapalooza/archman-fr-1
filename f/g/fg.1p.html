FG(1P) Manuel du programmeur POSIX FG(1P)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation de cette interface sous Linux peut différer (consultez la page de manuel Linux correspondante pour connaître les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

fg — exécute des tâches au premier plan

SYNTAXE

fg [id_tache]

DESCRIPTION

Si le contrôle de tâches est activé (voir la description de set -m), l'utilitaire fg déplace une tâche en arrière-plan de l'environnement courant (voir Section 2.12, Environnement d'exécution du shell) vers le premier plan.

L'utilisation de fg pour placer une tâche au premier plan retire son identifiant de processus de la liste de ceux « connus dans l'environnement d'exécution du shell courant » ; voir Section 2.9.3.1, Exemples.

OPTIONS

Aucune.

OPÉRANDES

Le opérande suivant sera pris en charge :

id_tache
Spécifie la tâche à exécuter comme tâche au premier plan. Si aucun opérande id_tache n'est fourni, l'id_tache de la tâche la plus récemment suspendue, placée en arrière-plan, ou exécutée comme tâche en arrière-plan sera utilisée. Le format de id_tache est décrit dans le volume Définitions de base de POSIX.1‐2017, Section 3.204, ID de tâche de contrôle de tâches.

ENTRÉE STANDARD

Non utilisé.

FICHIERS D'ENTRÉE

Aucun.

VARIABLES D'ENVIRONNEMENT

Les variables d'environnement suivantes affecteront l'exécution de fg :

LANG
Fournit une valeur par défaut pour les variables d'internationalisation qui sont non définies ou vides. (Voir le volume Définitions de base de POSIX.1‐2017, Section 8.2, Variables d'internationalisation pour la précédence des variables d'internationalisation utilisées pour déterminer les valeurs des catégories de localisation.)
LC_ALL
Si défini à une chaîne de caractères non vide, remplace les valeurs de toutes les autres variables d'internationalisation.
LC_CTYPE
Détermine la localisation pour l'interprétation des séquences d'octets de données textuelles en caractères (par exemple, caractères mono-octet par opposition aux caractères multi-octets dans les arguments).
LC_MESSAGES

Détermine la localisation qui devrait être utilisée pour affecter le format et le contenu des messages de diagnostic écrits sur la sortie d'erreur standard.
NLSPATH
Détermine l'emplacement des catalogues de messages pour le traitement de LC_MESSAGES.

ÉVÉNEMENTS ASYNCHRONES

Par défaut.

SORTIE STANDARD

L'utilitaire fg écrira la ligne de commande de la tâche sur la sortie standard dans le format suivant :

"%s\n", <commande>

ERREUR STANDARD

La sortie d'erreur standard sera utilisée uniquement pour les messages de diagnostic.

FICHIERS DE SORTIE

Aucun.

DESCRIPTION ÉTENDUE

Aucune.

STATUT DE SORTIE

Les valeurs de sortie suivantes seront retournées :

 0
Achèvement réussi.
>0
Une erreur s'est produite.

CONSÉQUENCES DES ERREURS

Si le contrôle de tâches est désactivé, l'utilitaire fg se terminera avec une erreur et aucune tâche ne sera placée au premier plan.

Les sections suivantes sont informatives.

USAGE APPLICATIF

L'utilitaire fg ne fonctionne pas comme prévu lorsqu'il s'exécute dans son propre environnement d'exécution d'utilitaire car cet environnement n'a pas de tâches applicables à manipuler. Voir la section USAGE APPLICATIF pour bg. Pour cette raison, fg est généralement implémenté comme un shell intégré régulier.

EXEMPLES

Aucun.

RATIONALE

Les extensions apportées au shell spécifiées dans ce volume de POSIX.1‐2017 sont largement basées sur les fonctionnalités fournies par le KornShell. Les fonctionnalités de contrôle de tâches fournies par bg, fg et jobs sont également basées sur le KornShell. Les développeurs standards ont examiné les caractéristiques des versions C shell de ces utilitaires et ont constaté des différences. Malgré l'utilisation répandue du C shell, les versions KornShell ont été sélectionnées pour ce volume de POSIX.1‐2017 afin de maintenir un certain degré d'uniformité avec le reste des fonctionnalités KornShell sélectionnées (comme les fonctionnalités d'édition de ligne de commande très populaires).
