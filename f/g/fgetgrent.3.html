fgetgrent(3) Manuel des fonctions de bibliothèque fgetgrent(3)

NOM

fgetgrent - obtenir une entrée du fichier de groupes

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <stdio.h>
#include <sys/types.h>
#include <grp.h>
struct group *fgetgrent(FILE *stream);
Exigences des macros de test de fonctionnalité pour glibc (voir feature_test_macros(7)):

fgetgrent():

    Depuis glibc 2.19 :
        _DEFAULT_SOURCE
    glibc 2.19 et versions antérieures :
        _SVID_SOURCE

DESCRIPTION

La fonction fgetgrent() renvoie un pointeur vers une structure contenant les informations du groupe du fichier référencé par stream. Lorsqu'elle est appelée pour la première fois, elle renvoie la première entrée ; par la suite, elle renvoie les entrées successives. Le fichier référencé par stream doit avoir le même format que /etc/group (voir group(5)).

La structure group est définie dans <grp.h> comme suit :


struct group {
    char   *gr_name;        /* nom du groupe */
    char   *gr_passwd;      /* mot de passe du groupe */
    gid_t   gr_gid;         /* ID du groupe */
    char  **gr_mem;         /* tableau de pointeurs terminé par NULL
                               vers les noms des membres du groupe */
};

VALEUR DE RETOUR

La fonction fgetgrent() renvoie un pointeur vers une structure group, ou NULL s'il n'y a plus d'entrées ou si une erreur se produit. En cas d'erreur, errno est défini pour indiquer l'erreur.

ERREURS

ENOMEM
Mémoire insuffisante pour allouer la structure group.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

NORMES

Aucune.
