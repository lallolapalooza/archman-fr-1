getgrent_r(3) Manuel des fonctions de la bibliothèque getgrent_r(3)

NOM

getgrent_r, fgetgrent_r — obtenir une entrée du fichier des groupes de manière réentrante

BIBLIOTHÈQUE

Bibliothèque C standard (libc,-lc)

SYNOPSIS

#include <grp.h>
int getgrent_r(size_t size;
               struct group *restrict gbuf,
               char buf[restrict size], size_t size,
               struct group **restrict gbufp);
int fgetgrent_r(size_t size;
               FILE *restrict stream, struct group *restrict gbuf,
               char buf[restrict size], size_t size,
               struct group **restrict gbufp);
Exigences des macros de test de fonctionnalités pour glibc (voir feature_test_macros(7)) :

getgrent_r() :

    _GNU_SOURCE

fgetgrent_r() :

    Depuis glibc 2.19 :
        _DEFAULT_SOURCE
    glibc 2.19 et antérieures :
        _SVID_SOURCE

DESCRIPTION

Les fonctions getgrent_r() et fgetgrent_r() sont les versions réentrantes de getgrent(3) et fgetgrent(3). La première lit l'entrée de groupe suivante depuis le flux initialisé par setgrent(3). La seconde lit l'entrée de groupe suivante depuis stream.

La structure group est définie dans <grp.h> comme suit :


struct group {
    char   *gr_name;        /* group name */
    char   *gr_passwd;      /* group password */
    gid_t   gr_gid;         /* group ID */
    char  **gr_mem;         /* NULL-terminated array of pointers
                               to names of group members */
};

Pour plus d'informations sur les champs de cette structure, voir group(5).

Les fonctions non réentrantes renvoient un pointeur vers un stockage statique, où ce stockage statique contient d'autres pointeurs vers le nom du groupe, le mot de passe et les membres. Les fonctions réentrantes décrites ici renvoient tout cela dans des tampons fournis par l'appelant. Tout d'abord, il y a le tampon gbuf qui peut contenir une struct group. Et ensuite le tampon buf de taille size qui peut contenir des chaînes supplémentaires. Le résultat de ces fonctions, la struct group lue depuis le flux, est stocké dans le tampon fourni *gbuf, et un pointeur vers cette struct group est renvoyé dans *gbufp.

VALEUR RENVOYÉE

En cas de succès, ces fonctions renvoient 0 et *gbufp est un pointeur vers la struct group. En cas d'erreur, ces fonctions renvoient une valeur d'erreur et *gbufp est NULL.

ERREURS

ENOENT
Plus d'entrées.
ERANGE
Espace de tampon insuffisant fourni. Réessayez avec un tampon plus grand.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
getgrent_r () Sécurité des threads MT-Unsafe race:grent locale
fgetgrent_r () Sécurité des threads MT-Safe

Dans le tableau ci-dessus, grent dans race:grent signifie que si l'une des fonctions setgrent(3), getgrent(3), endgrent(3), ou getgrent_r() est utilisée en parallèle dans différents threads d'un programme, des conditions de course sur les données peuvent survenir.

VERSIONS

D'autres systèmes utilisent le prototype


struct group *getgrent_r(struct group *grp, char buf[.size],
                         int size);

ou, de préférence,


int getgrent_r(struct group *grp, char buf[.size], int size,
               FILE **gr_fp);

NORMES

GNU.

HISTORIQUE

Ces fonctions sont réalisées dans un style ressemblant à la version POSIX de fonctions comme getpwnam_r(3).

REMARQUES

La fonction getgrent_r() n'est pas vraiment réentrante car elle partage la position de lecture dans le flux avec tous les autres threads.

EXEMPLES

#define _GNU_SOURCE
#include <grp.h>
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>
#define BUFLEN 4096
int
main(void)
{
    struct group grp;
    struct group *grpp;
    char buf[BUFLEN];
    int i;
    setgrent();
    while (1) {
        i = getgrent_r(&grp, buf, sizeof(buf), &grpp);
        if (i)
            break;
        printf("%s (%jd):", grpp->gr_name, (intmax_t) grpp->gr_gid);
        for (size_t j = 0; ; j++) {
            if (grpp->gr_mem[j] == NULL)
                break;
            printf(" %s", grpp->gr_mem[j]);
        }
        printf("\n");
    }
    endgrent();
    exit(EXIT_SUCCESS);
}

VOIR AUSSI

fgetgrent(3), getgrent(3), getgrgid(3), getgrnam(3), putgrent(3), group(5)
