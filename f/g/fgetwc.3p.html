DESCRIPTIO

N

La fonctionnalité décrite sur cette page de référence est alignée avec la norme ISO C. Tout conflit entre les exigences décrites ici et la norme ISO C est involontaire. Ce volume de POSIX.1‐2017 se réfère à la norme ISO

C.

La fonction fgetwc() doit obtenir le caractère suivant (s'il est présent) depuis le flux d'entrée pointé par stream, le convertir en le code de caractère large correspondant, et avancer l'indicateur de position de fichier associé au flux (s'il est défini)

.

Si une erreur se produit, la valeur résultante de l'indicateur de position de fichier pour le flux est

indéterminée.

La fonction fgetwc() peut marquer l'horodatage du dernier accès aux données du fichier associé à stream pour mise à jour. L'horodatage du dernier accès aux données doit être marqué pour mise à jour par la première exécution réussie de fgetwc(), fgetws(), fwscanf(), getwc(), getwchar(), vfwscanf(), vwscanf(), ou wscanf() utilisant stream qui retourne des données non fournies par un appel précédent à ungetwc

().

La fonction fgetwc() ne doit pas changer le paramètre de errno en cas

de s
uccès.

VALEUR

RENVOYÉE

Lors de l'achèvement réussi, la fonction fgetwc() doit retourner le code de caractère large du caractère lu depuis le flux d'entrée pointé par stream converti en un type wint_t. Si l'indicateur de fin de fichier pour le flux est défini, ou si le flux est à la fin de fichier, l'indicateur de fin de fichier pour le flux doit être défini et fgetwc() doit retourner WEOF. Si une erreur de lecture se produit, l'indicateur d'erreur pour le flux doit être défini, fgetwc() doit retourner WEOF, et doit définir errno pour indiquer l'erreur. Si une erreur d'encodage se produit, l'indicateur d'erreur pour le flux doit être défini, fgetwc() doit retourner WEOF, et doit définir errno pour ind

iquer l'
erreur.
