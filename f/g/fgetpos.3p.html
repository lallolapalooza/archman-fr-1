FGETPOS(3P) Manuel du programmeur POSIX FGETPOS(3P)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation de cette interface sous Linux peut différer (consulter la page de manuel Linux correspondante pour connaître les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

fgetpos — obtenir les informations de position actuelle du fichier

SYNTAXE

#include <stdio.h>
int fgetpos(FILE *restrict stream, fpos_t *restrict pos);

DESCRIPTION

La fonctionnalité décrite sur cette page de référence est alignée sur la norme ISO C. Tout conflit entre les exigences décrites ici et la norme ISO C est involontaire. Ce volume de POSIX.1‐2017 renvoie à la norme ISO C.

La fonction fgetpos() doit stocker les valeurs actuelles de l'état d'analyse (s'il y en a) et de l'indicateur de position du fichier pour le flux pointé par stream dans l'objet pointé par pos. La valeur stockée contient des informations non spécifiées utilisables par fsetpos() pour repositionner le flux à sa position au moment de l'appel à fgetpos().

La fonction fgetpos() ne doit pas modifier le réglage de errno en cas de succès.

VALEUR DE RETOUR

En cas de succès, fgetpos() retourne 0 ; sinon, elle retourne une valeur non nulle et définit errno pour indiquer l'erreur.

ERREURS

La fonction fgetpos() échoue si :

EBADF
Le descripteur de fichier sous-jacent de stream n'est pas valide.
EOVERFLOW
La valeur actuelle de la position du fichier ne peut pas être représentée correctement dans un objet de type fpos_t.
ESPIPE
Le descripteur de fichier sous-jacent de stream est associé à un tube, un FIFO ou une socket.
