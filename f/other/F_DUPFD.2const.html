F_DUPFD(2const) F_DUPFD(2const)

NOM

F_DUPFD, F_DUPFD_CLOEXEC - dupliquer un descripteur de fichier

BIBLIOTHQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <fcntl.h>
int fcntl(int fd, F_DUPFD, int arg);
int fcntl(int fd, F_DUPFD_CLOEXEC, int arg);

DESCRIPTION

F_DUPFD
Duplique le descripteur de fichier fd en utilisant le descripteur de fichier disponible de plus petit numéro, supérieur ou égal à arg. Ceci est différent de dup2(2), qui utilise exactement le descripteur de fichier spécifié.
En cas de succès, le nouveau descripteur de fichier est retourné.
Voir dup(2) pour plus de détails.
F_DUPFD_CLOEXEC
Comme pour F_DUPFD, mais définit en plus le drapeau de fermeture lors de l'exécution (close-on-exec) pour le descripteur de fichier dupliqué. Spécifier ce drapeau permet à un programme d'éviter une opération fcntl(2) supplémentaire pour définir le drapeau FD_CLOEXEC. Pour une explication de l'utilité de ce drapeau, voir la description de O_CLOEXEC dans open(2).

VALEUR DE RETOUR

Le nouveau descripteur de fichier.

En cas d'erreur, -1 est retourné, et errno est définie pour indiquer l'erreur.

ERREURS

Voir fcntl(2).

EINVAL
arg est négatif ou est supérieur à la valeur maximale autorisée (voir la discussion de RLIMIT_NOFILE dans getrlimit(2)).
EMFILE
La limite par processus du nombre de descripteurs de fichiers ouverts a été atteinte.

VERSIONS

POSIX.1-2024 spécifie F_DUPFD_CLOFORK, mais Linux ne le prend pas en charge.

NORMES

POSIX.1-2024.

HISTORIQUE

F_DUPFD
SVr4, 4.3BSD, POSIX.1-2001.
F_DUPFD_CLOEXEC
Linux 2.6.24. POSIX.1-2008. (Pour obtenir cette définition, définissez _POSIX_C_SOURCE avec la valeur 200809L ou supérieure, ou _XOPEN_SOURCE avec la valeur 700 ou supérieure.)

AVERTISSEMENTS

Les erreurs retournées par dup2(2) sont différentes de celles retournées par F_DUPFD.

VOIR AUSSI

dup2(2), fcntl(2)
