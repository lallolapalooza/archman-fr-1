F_GETFL(2const) F_GETFL(2const)

NOM

F_GETFL, F_SETFL - obtenir/définir les indicateurs d'état de fichier

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <fcntl.h>
int fcntl(int fd, F_GETFL);
int fcntl(int fd, F_SETFL, int arg);

DESCRIPTION

Chaque description de fichier ouvert possède certains indicateurs d'état associés, initialisés par open(2) et éventuellement modifiés par fcntl(2). Les descripteurs de fichiers dupliqués (créés avec dup(2), F_DUPFD(2const), fork(2), etc.) font référence à la même description de fichier ouverte, et partagent donc les mêmes indicateurs d'état de fichier.

Les indicateurs d'état de fichier et leurs sémantiques sont décrits dans open(2).

F_GETFL
Retourne (comme résultat de la fonction) le mode d'accès au fichier et les indicateurs d'état de fichier ; arg est ignoré.
F_SETFL
Définit les indicateurs d'état de fichier à la valeur spécifiée par arg. Les indicateurs de mode d'accès au fichier (O_RDONLY, O_WRONLY, O_RDWR) et les indicateurs de création de fichier (c'est-à-dire O_CREAT, O_EXCL, O_NOCTTY, O_TRUNC) dans arg sont ignorés. Sous Linux, cette opération ne peut modifier que les indicateurs O_APPEND, O_ASYNC, O_DIRECT, O_NOATIME, et O_NONBLOCK. Il n'est pas possible de modifier les indicateurs O_DSYNC et O_SYNC ; voir BUGS, ci-dessous.

VALEUR DE RETOUR

F_GETFL
Valeur des indicateurs d'état de fichier.
F_SETFL
Zéro.

En cas d'erreur, -1 est retourné et errno est défini pour indiquer l'erreur.

ERREURS

Voir fcntl(2).

EPERM
Tentative de suppression de l'indicateur O_APPEND sur un fichier qui possède l'attribut "append-only" (écriture seulement à la fin).

NORMES

POSIX.1-2024.

HISTORIQUE

SVr4, 4.3BSD, POSIX.1-2001.

BOGUES

F_SETFL

Il n'est pas possible d'utiliser F_SETFL pour modifier l'état des indicateurs O_DSYNC et O_SYNC. Les tentatives de modification de l'état de ces indicateurs sont silencieusement ignorées.

VOIR AUSSI

fcntl(2), open(2)
