F_GET_RW_HINT(2const) F_GET_RW_HINT(2const)

NOM

F_GET_RW_HINT, F_SET_RW_HINT, F_GET_FILE_RW_HINT, F_SET_FILE_RW_HINT - obtenir/définir des indications de lecture/écriture de fichier

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNOPSIS

#include <fcntl.h>
int fcntl(int fd, F_GET_RW_HINT, uint64_t *arg);
int fcntl(int fd, F_SET_RW_HINT, uint64_t *arg);
int fcntl(int fd, F_GET_FILE_RW_HINT, uint64_t *arg);
int fcntl(int fd, F_GET_FILE_RW_HINT, uint64_t *arg);

DESCRIPTION

Les indications de durée de vie d'écriture peuvent être utilisées pour informer le noyau sur la durée de vie attendue relative des écritures sur un inode donné ou via une description de fichier ouverte particulière. (Voir open(2) pour une explication des descriptions de fichier ouvertes.) Dans ce contexte, le terme « durée de vie d'écriture » signifie le temps attendu pendant lequel les données resteront sur le support, avant d'être écrasées ou effacées.

Une application peut utiliser les différentes valeurs d'indication spécifiées ci-dessous pour séparer les écritures en différentes classes d'écriture, afin que plusieurs utilisateurs ou applications s'exécutant sur un seul backend de stockage puissent agréger leurs modèles d'E/S de manière cohérente. Cependant, il n'y a aucune sémantique fonctionnelle implicite dans ces indicateurs, et différentes classes d'E/S peuvent utiliser les indications de durée de vie d'écriture de manière arbitraire, tant que les indications sont utilisées de manière cohérente.

Les opérations suivantes peuvent être appliquées au descripteur de fichier, fd :

F_GET_RW_HINT
Retourne la valeur de l'indication de lecture/écriture associée à l'inode sous-jacent référencé par fd.
F_SET_RW_HINT
Définit la valeur de l'indication de lecture/écriture associée à l'inode sous-jacent référencé par fd. Cette indication persiste jusqu'à ce qu'elle soit explicitement modifiée ou que le système de fichiers sous-jacent soit démonté.
F_GET_FILE_RW_HINT
Retourne la valeur de l'indication de lecture/écriture associée à la description de fichier ouverte référencée par fd.
F_SET_FILE_RW_HINT
Définit la valeur de l'indication de lecture/écriture associée à la description de fichier ouverte référencée par fd.

Si une description de fichier ouverte n'a pas reçu d'indication de lecture/écriture, elle utilisera la valeur attribuée à l'inode, le cas échéant.

Les indications de lecture/écriture suivantes sont prises en charge :

RWH_WRITE_LIFE_NOT_SET
Aucune indication spécifique n'a été définie. C'est la valeur par défaut.
RWH_WRITE_LIFE_NONE
Aucune durée de vie d'écriture spécifique n'est associée à ce fichier ou à cet inode.
RWH_WRITE_LIFE_SHORT
Les données écrites sur cet inode ou via cette description de fichier ouverte sont censées avoir une courte durée de vie.
RWH_WRITE_LIFE_MEDIUM
Les données écrites sur cet inode ou via cette description de fichier ouverte sont censées avoir une durée de vie plus longue que les données écrites avec RWH_WRITE_LIFE_SHORT.
RWH_WRITE_LIFE_LONG
Les données écrites sur cet inode ou via cette description de fichier ouverte sont censées avoir une durée de vie plus longue que les données écrites avec RWH_WRITE_LIFE_MEDIUM.
RWH_WRITE_LIFE_EXTREME
Les données écrites sur cet inode ou via cette description de fichier ouverte sont censées avoir une durée de vie plus longue que les données écrites avec RWH_WRITE_LIFE_LONG.

Toutes les indications relatives à l'écriture sont relatives les unes aux autres, et aucune signification absolue individuelle ne doit leur être attribuée.

VALEUR DE RETOUR

Zéro.

En cas d'erreur, -1 est retourné et errno est défini pour indiquer l'erreur.

ERREURS

Voir fcntl(2).

NORMES

Linux.
