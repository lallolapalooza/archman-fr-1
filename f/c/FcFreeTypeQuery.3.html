NOM

FcFreeTypeQuery - calculer un modèle à partir d'un fichier de police (et d'un index)

SYNTAXE

#include <fontconfig.h> #include <fcfreetype.h>

FcPattern * FcFreeTypeQuery (const FcChar8 *file, int id, FcBlanks *blanks, int *count);

DESCRIPTION

Construit un modèle représentant la 'id'ème police dans 'file'. Le nombre de polices dans 'file' est renvoyé dans 'count'. FcBlanks est obsolète, blanks est ignoré et accepté uniquement pour la compatibilité avec le code plus ancien.
