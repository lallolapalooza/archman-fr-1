NOM

fc-cache - construire les fichiers d'informations de police en cache

SYNTAXE

fc-cache [ -EfrsvVh ] [ --error-on-no-fonts ] [ --force ] [ --really-force ] [ -y rép | --sysroot rép ] [ --system-only ] [ --verbose ] [ --version ] [ --help ] [ rép ... ]

DESCRIPTION

fc-cache analyse les répertoires de polices sur le système et construit des fichiers de cache d'informations de polices pour les applications utilisant fontconfig pour la gestion des polices.

Si aucun répertoire n'est donné en argument, fc-cache utilise chaque répertoire dans la configuration de polices actuelle. Chaque répertoire est analysé pour trouver les fichiers de polices lisibles par FreeType. Un cache est créé qui contient les propriétés de chaque police et le nom de fichier associé. Ce cache est utilisé pour accélérer le démarrage des applications lors de l'utilisation de la bibliothèque fontconfig.

Notez que fc-cache doit être exécuté une fois par architecture pour générer des informations de polices personnalisées pour cette architecture.

OPTIONS

Ce programme suit la syntaxe habituelle de ligne de commande GNU, avec des options longues commençant par deux tirets (`-'). Un résumé des options est inclus ci-dessous.

-E --error-on-no-fonts
Lève une erreur s'il n'y a pas de polices dans rép ou dans les répertoires de la configuration si aucun n'est donné.
-f --force
Force la régénération des fichiers de cache apparemment à jour, en ignorant la vérification des horodatages.
-r --really-force
Efface tous les fichiers de cache existants et réanalyse.
-s --system-only
Analyse uniquement les répertoires système, en omettant les emplacements situés dans le répertoire personnel de l'utilisateur.
-v --verbose
Affiche des informations de statut pendant l'exécution.
-y -sysroot rép
Prépare rép à tous les chemins pour l'analyse.
-h --help
Affiche un résumé des options.
-V --version
Affiche la version du programme et quitte.
rép
Répertoire à analyser pour les polices.

CODES DE RETOUR

fc-cache retourne zéro si les caches ont été générés avec succès. Sinon, retourne une valeur non nulle.

FICHIERS

%cachedir%/*-%arch%.cache-%version%
Ces fichiers sont générés par fc-cache et contiennent des mappages des noms de fichiers aux propriétés des polices. Ils sont lus par la bibliothèque fontconfig au démarrage des applications pour localiser les polices appropriées.
