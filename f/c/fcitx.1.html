NOM

fcitx - Free Chinese Input Toy of X - une méthode de saisie chinoise pour XIM

SYNTAXE

fcitx [OPTION]

DESCRIPTION

Cette page de manuel documente brièvement la commande fcitx.

fcitx est une méthode de saisie chinoise pour XIM, intentionnellement conçue pour ne pas dépendre d'un environnement de bureau. Elle inclut par défaut le Pinyin et la table pour la saisie, mais elle peut également prendre en charge d'autres méthodes de saisie.

OPTIONS

-r
remplacer fcitx existant
-d
exécuter en tant que démon (par défaut)
-D
ne pas exécuter en tant que démon
-s[temps de pause]
remplacer le délai de démarrage dans le fichier de configuration, 0 pour un démarrage immédiat
-u, --ui[nom de l'interface]
forcer l'utilisation de l'interface utilisateur spécifiée
--enable[module A,module B]
spécifier une liste séparée par des virgules de modules à activer qui remplacera l'option enable
--disable[module A,module B]
spécifier une liste séparée par des virgules de modules à désactiver explicitement, la priorité est plus élevée que --enable
-v
afficher les informations de version et quitter
-h
afficher l'aide et quitter

ENVIRONNEMENT

XMODIFIERS
Si $XMODIFIERS est défini, fcitx s'exécutera avec le nom spécifié dans $XMODIFIERS, sinon il s'exécutera avec le nom de méthode de saisie fcitx.

VOIR AUSSI

Veuillez consulter la page d'accueil sur https://fcitx-im.org/
