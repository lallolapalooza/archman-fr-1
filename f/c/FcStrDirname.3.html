NOM

FcStrDirname - partie répertoire d'un nom de fichier

SYNOPSIS

#include <fontconfig/fontconfig.h>

FcChar8 * FcStrDirname (const FcChar8 *file);

DESCRIPTION

Retourne le répertoire contenant file. Ceci est retourné dans un espace nouvellement alloué qui doit être libéré lorsqu'il n'est plus nécessaire.
