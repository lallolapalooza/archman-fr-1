NOM

fc-validate - valider les fichiers de polices

SYNTAXE

fc-validate [ -Vhv ]
[ -i index | --index index ] [ -l lang | --lang lang ] [ --verbose ] [ --version ] [ --help ] fichier-de-police ...

DESCRIPTION

fc-validate valide le(s) fichier(s) fichier-de-police si chaque police satisfait la couverture linguistique selon les fichiers d'orthographe de fontconfig. Si --index est spécifié, une seule face de chaque fichier est validée, sinon toutes les faces sont validées.

OPTIONS

Ce programme suit la syntaxe habituelle des lignes de commande GNU, avec des options longues commençant par deux tirets (`-'). Un résumé des options est inclus ci-dessous.

-i --index index
Interroger uniquement la face d'indice index de chaque fichier.
-l --lang lang
Définir lang comme langue au lieu de la locale actuelle. Ceci est utilisé pour -m.
-v --verbose
Afficher des informations plus détaillées.
-V --version
Afficher la version du programme et quitter.
-h --help
Afficher un résumé des options.
fichier-de-police
Interroger fichier-de-police pour les faces de polices.

CODES DE RETOUR

fc-validate retourne le code d'erreur 0 en cas d'analyse réussie, ou 1 si des erreurs se sont produites ou si au moins une face de police n'a pas pu être ouverte.
