NOM

fcrontab - manipuler les fichiers fcrontab par utilisateur qui adhèrent au format défini dans fcrontab(5)

SYNOPSIS

fcrontab [ -c fichier ] [ -n ] fichier [ utilisateur | -u utilisateur ]

fcrontab [ -c fichier ] [ -n ] { -l | -r | -e | -z } [ utilisateur | -u utilisateur ]

fcrontab [ -h ]

DESCRIPTION

Fcrontab est le programme destiné à installer, éditer, lister et supprimer les tables utilisées par le démon fcron(8). Comme fcron utilise en interne un format non lisible par l'homme (ceci est nécessaire car fcron sauvegarde plus d'informations que l'utilisateur ne fournit, par exemple l'heure et la date de la prochaine exécution), l'utilisateur ne peut pas éditer son fcrontab directement (celui utilisé par fcron).

Lorsqu'un utilisateur installe un fcrontab, le fichier source est sauvegardé dans le répertoire spool (/usr/local/var/spool/fcron) pour permettre son édition, et un fichier formaté est généré pour le démon fcron. Ce fichier formaté (non lisible par l'homme) avec tous les changements récents inclus est alors envoyé au démon. Le démon n'est pas informé des changements immédiatement, mais après un certain temps pour empêcher les utilisateurs mal intentionnés de bloquer le démon en installant des fcrontab de manière répétée (c'est-à-dire une attaque par déni de service). Par défaut, le fichier est envoyé une fois par minute (environ dix secondes avant la minute complète) au démon, le paramètre de compilation --with-max-fcrontab-reload-delay-seconds peut être utilisé pour spécifier un temps maximum différent pour envoyer ces données. Nous appellerons "fcrontab" le fichier source du fcrontab dans la suite.

Les fichiers fcrontab que l'utilisateur modifie doivent suivre le format défini dans fcrontab(5).

Les utilisateurs peuvent installer un fcrontab s'ils sont listés dans /usr/local/etc/fcron.allow et non listés dans /usr/local/etc/fcron.deny (voir la section "fichiers" ci-dessous). Le mot-clé 'all' est un raccourci pour tous les utilisateurs. Si ni fcron.allow ni fcron.deny n'existent, tous les utilisateurs sont autorisés. Aucun de ces fichiers n'a besoin d'exister, mais s'ils existent, le fichier deny a la priorité.

La première forme de la commande est utilisée pour installer un nouveau fichier fcrontab, à partir de n'importe quel fichier nommé ou de l'entrée standard (si le nom de fichier pseudo "-" est donné), remplaçant le précédent (s'il existe). Chaque utilisateur ne peut avoir qu'un seul fcrontab.

Par exemple, root peut créer un fichier fcrontab système, disons /etc/fcrontab, et exécuter "fcrontab /etc/fcrontab" pour installer la nouvelle version après chaque modification du fichier. Ou root peut créer un nouveau fcrontab en exécutant un simple "fcrontab", puis le maintenir en utilisant "fcrontab -e". Les mêmes considérations s'appliquent à un utilisateur non privilégié.

OPTIONS

-u utilisateur
Spécifie l'utilisateur dont le fcrontab sera géré, ou "systab" pour le fcrontab système. Ne doit être utilisé que par root. Si non spécifié, le fichier fcrontab de l'utilisateur qui invoque fcrontab sera traité. Cela peut être utile car la commande su(8) peut confondre fcrontab.
Note: le 'utilisateur' dans la synopsis est équivalent à un '-u utilisateur'.
-l
Liste le fcrontab actuel de l'utilisateur sur la sortie standard.
-e
Édite le fcrontab actuel de l'utilisateur en utilisant soit l'éditeur spécifié par la variable d'environnement VISUAL, soit EDITOR si VISUAL n'est pas définie. Si aucune des deux n'est définie, /usr/bin/vi sera utilisé.
-r
Supprime le fcrontab de l'utilisateur.
-z
Réinstalle le fcrontab de l'utilisateur à partir de son code source. Toutes les informations que fcron peut avoir conservées dans le fcrontab binaire (comme la dernière heure et date d'exécution) seront oubliées (c'est-à-dire perdues).
-n
Ignore la version précédente. Si cette option n'est pas donnée, fcron essaiera de conserver autant d'informations que possible entre l'ancienne et la nouvelle version du fcrontab (heure et date de la prochaine exécution, si la tâche est dans une file séquentielle, etc.) si la ligne n'a pas été modifiée (mêmes champs, même commande shell).
-c fichier
Fait utiliser à fcrontab le fichier de configuration fichier au lieu du fichier de configuration par défaut /usr/local/etc/fcron.conf. Pour interagir avec un processus fcron en cours d'exécution, fcrontab doit utiliser le même fichier de configuration que le processus. Ainsi, plusieurs processus fcron peuvent s'exécuter simultanément sur un seul système.
-d
Exécuter en mode débogage. Dans ce mode, de nombreux messages d'information seront affichés afin de vérifier si quelque chose s'est mal passé.
-h
Affiche une brève description des options.
-V
Affiche un message d'information sur fcrontab, y compris sa version et la licence sous laquelle il est distribué.

VALEUR DE RETOUR

Fcrontab retourne 0 en cas de sortie normale et 1 en cas d'erreur.

CONFORMITÉ

Doit être conforme à POSIX.

FICHIERS

/usr/local/etc/fcron.conf
Fichier de configuration pour fcron, fcrontab et fcrondyn: contient les chemins (répertoire spool, fichier pid) et les programmes par défaut à utiliser (éditeur, shell, etc.). Voir fcron.conf(5) pour plus de détails.
/usr/local/etc/fcron.allow
Utilisateurs autorisés à utiliser fcrontab et fcrondyn (un nom par ligne, le nom spécial "all" s'applique à tout le monde)
/usr/local/etc/fcron.deny
Utilisateurs non autorisés à utiliser fcrontab et fcrondyn (même format que le fichier allow)
/usr/local/etc/pam.d/fcron (ou /usr/local/etc/pam.conf)
Fichier de configuration PAM pour fcron. Jetez un œil à pam(8) pour plus de détails.
