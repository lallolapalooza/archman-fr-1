NOM

fc-match - trouver des polices disponibles

SYNTAXE

fc-match [ -asvVh ] [ --all ] [ --sort ] [ --verbose ] [ -f format | --format format ] [ --version ] [ --help ]
[ modèle [ élément ... ] ]

DESCRIPTION

fc-match recherche le modèle (modèle vide par défaut) en utilisant les règles de correspondance normales de fontconfig pour trouver la meilleure police disponible. Si --sort est spécifié, la liste triée des meilleures polices correspondantes est affichée. L'option --all fonctionne comme --sort sauf qu'aucun élagage n'est effectué sur la liste des polices.

Si des éléments sont spécifiés, seuls ceux-ci sont affichés. Sinon, le nom de fichier court, la famille et le style sont affichés, sauf si une sortie détaillée est demandée.

OPTIONS

Ce programme suit la syntaxe habituelle de ligne de commande de GNU, avec des options longues commençant par deux tirets (`-'). Un résumé des options est inclus ci-dessous.

-a --all
Affiche la liste triée des meilleures polices correspondantes, mais n'effectue aucun élagage sur la liste.
-s --sort
Affiche la liste triée des meilleures polices correspondantes.
-v --verbose
Affiche une sortie détaillée de l'ensemble du modèle de police pour chaque correspondance, ou des éléments si un est fourni.
-f --format format
Formate la sortie selon le spécificateur de format format.
-V --version
Affiche la version du programme et quitte.
-h --help
Affiche un résumé des options.
modèle
Affiche les polices correspondant au modèle (utilise un modèle vide par défaut).
élément
S'il est défini, la propriété élément est affichée pour les polices correspondantes.

EXEMPLES

fc-match sans
Affiche la meilleure police correspondante catégorisée dans la famille générique sans-serif, filtrée par la locale actuelle.
fc-match sans:lang=en
Affiche la meilleure police correspondante catégorisée dans la famille générique sans-serif, filtrée par la langue anglaise.
fc-match sans:lang=en:weight=bold
Affiche la meilleure police correspondante catégorisée dans la famille générique sans-serif, filtrée par la langue anglaise et un poids gras.
