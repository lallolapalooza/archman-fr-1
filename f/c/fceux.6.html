NOM

fceux - Un émulateur pour la console de jeu Nintendo / Famicom (8 bits) originale.

SYNTAXE

fceux [options] "nom_fichier"

DESCRIPTION

FCEUX est un émulateur pour la console de jeu originale (8 bits) Nintendo Entertainment System (NES). Il dispose d'un moteur de rendu de palette de couleurs robuste et entièrement personnalisable, ainsi que d'un excellent support du son et des joysticks, et prend même en charge l'enregistrement et la lecture de films.

OPTIONS

Options diverses

--no-config {0|1}
Utilise le fichier de configuration par défaut et n'y enregistre pas, lorsque activé.
-g {0|1}, --gamegenie {0|1}
Active ou désactive le Game Genie émulé.
--nogui {0|1}
Active ou désactive l'interface graphique GTK.
--loadlua FICHIER
Charge le script lua du fichier FICHIER.

Options d'émulation

--pal {0|1}
Active ou désactive le mode PAL.

Options d'entrée

-i DEV, --inputcfg DEV
Configure le périphérique d'entrée DEV au démarrage. Périphériques : gamepad powerpad hypershot quizking
--input{1|2} DEV
Définit quel périphérique d'entrée émuler pour l'entrée 1 ou 2. Périphériques : gamepad zapper powerpad.0 powerpad.1 arkanoid
--input{3|4} DEV
Définit le périphérique d'extension Famicom à émuler pour l'entrée 3 ou 4. Périphériques : quizking hypershot mahjong toprider ftrainer familykeyboard oekakids arkanoid shadow bworld 4player
--inputdisplay {0|1}
Active ou désactive l'affichage des entrées.
--fourscore {0|1}
Active ou désactive l'émulation FourScore.

Options graphiques

--newppu {0|1}
Active ou désactive le nouveau cœur PPU. (ATTENTION : peut corrompre les sauvegardes)
--frameskip NUM
Définit NUM images à sauter par image émulée.
--clipsides {0|1}
Active ou désactive le rognage des 8 colonnes les plus à gauche et les plus à droite de la sortie vidéo.
--slstart SCANLINE
Définit la première ligne de balayage à rendre.
--slend SCANLINE
Définit la dernière ligne de balayage à rendre.
--nospritelim {0|1}
Lorsque réglé sur 0, désactive la limitation normale de 8 sprites par ligne de balayage. Lorsque réglé sur 1, active la limitation normale de 8 sprites par ligne de balayage. NOTE : Oui, cette option est 'à l'envers'.
-x XRES, --xres XRES
Définit la résolution horizontale pour le mode plein écran.
-y YRES, --yres YRES
Définit la résolution verticale pour le mode plein écran.
--doublebuf {0|1}
Active ou désactive la double mise en mémoire tampon.
--autoscale {0|1}
Active ou désactive la mise à l'échelle automatique en plein écran.
--keepratio {0|1}
Conserve le rapport d'aspect natif de la NES lors de la mise à l'échelle automatique.
--{x|y}scale VAL
Multiplie la largeur/hauteur par VAL. (Nombres réels > 0 avec OpenGL, sinon entiers > 0).
--{x|y}stretch {0|1}
Étire pour remplir la surface sur l'axe x/y (OpenGL uniquement).
-b {8|16|24|32}, --bpp {8|16|24|32}
Définit le nombre de bits par pixel.
--opengl {0|1}
Active ou désactive le support OpenGL.
--openglip {0|1}
Active ou désactive l'interpolation linéaire OpenGL.
-f {0|1}, --fullscreen {0|1}
Active ou désactive le mode plein écran.
--noframe {0|1}
Masque la barre de titre et les décorations de fenêtre.
--special {1-4}
Utilise des filtres spéciaux de mise à l'échelle vidéo. (1 = hq2x 2 = Scale2x 3 = NTSC 2x 4 = hq3x 5 = Scale3x)
-p FICHIER, --palette FICHIER
Utilise la palette personnalisée dans FICHIER.
--ntsccolor {0|1}
Active ou désactive les couleurs NTSC NES.
--tint VAL
Définit la teinte NTSC.
--hue VAL
Définit la nuance NTSC.

Options sonores

-s {0|1}, --sound {0|1}
Active ou désactive le son.
--soundrate TAUX
Définit le taux d'échantillonnage de la lecture audio (0 = désactivé ?).
--soundq {0|1|2}
Définit la qualité sonore. (0 = Basse 1 = Haute 2 = Très haute)
--soundbufsize MS
Définit la taille du tampon sonore à MS millisecondes.
--volume {0-256}
Définit le volume sonore à la valeur donnée, où 256 est le volume maximal.
--trianglevol {0-256}
Définit le volume sonore de l'onde triangulaire à la valeur donnée, où 256 est le volume maximal.
--square1vol {0-256}
Définit le volume sonore de l'onde carrée 1 à la valeur donnée, où 256 est le volume maximal.
--square2vol {0-256}
Définit le volume sonore de l'onde carrée 2 à la valeur donnée, où 256 est le volume maximal.
--noisevol {0-256}
Définit le volume sonore du générateur de bruit à la valeur donnée, où 256 est le volume maximal.
--lowpass {0|1}
Active ou désactive le filtrage passe-bas du son.
--soundrecord FICHIER
Enregistre le son dans le fichier FICHIER.

Options de film

--playmov FICHIER
Reproduit un film FCM/FM2 enregistré depuis le fichier FICHIER.
--pauseframe IMAGE
Met en pause la lecture du film à l'image IMAGE.
--moviemsg {0|1}
Active ou désactive les messages de film.
--fcmconvert FICHIER
Convertit le fichier de film fcm FICHIER en fm2.
--ripsubs FICHIER
Convertit les sous-titres du film en srt.
--subtitles {0|1}
Active ou désactive l'affichage des sous-titres.

Options réseau

--netplay {0|1}
Active ou désactive le jeu en réseau.
--host ADDRESS
Héberge une partie sur l'adresse ADDRESS.
--port PORT
Utilise le port PORT pour le jeu en réseau.
--connect ADDRESS
Se connecte à une partie sur l'adresse ADDRESS.
--password PASSWORD
Utilise le mot de passe PASSWORD pour se connecter à une partie.
--numconnections NUM
Définit le nombre de connexions autorisées à NUM.
--timedifference SECONDS
Définit la différence de temps en SECONDES.

FICHIERS

~/.fceux.cfg
Fichier de configuration de l'utilisateur.

VOIR AUSSI

gtk(3)(7), lua(1)(1), sdl(3)(3)
