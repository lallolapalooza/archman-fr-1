FCHDIR(3P) Manuel du programmeur POSIX FCHDIR(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

fchdir — changer le répertoire de travail

SYNTAXE

#include <unistd.h>
int fchdir(int fildes);

DESCRIPTION

La fonction fchdir() est équivalente à chdir() à ceci près que le répertoire qui doit devenir le nouveau répertoire de travail courant est spécifié par le descripteur de fichier fildes.

Une application conforme peut obtenir un descripteur de fichier pour un fichier de type répertoire en utilisant open(), à condition que les indicateurs d'état de fichier et les modes d'accès ne contiennent pas O_WRONLY ou O_RDWR.

VALEUR DE RETOUR

En cas de succès, fchdir() retourne 0. Sinon, elle retourne -1 et définit errno pour indiquer l'erreur. En cas d'échec, le répertoire de travail courant reste inchangé.

ERREURS

La fonction fchdir() échouera si :

EACCES
La permission de recherche est refusée pour le répertoire référencé par fildes.
EBADF
L'argument fildes n'est pas un descripteur de fichier ouvert.
ENOTDIR
Le descripteur de fichier ouvert fildes ne fait pas référence à un répertoire.

La fonction fchdir() peut échouer si :

EINTR
Un signal a été intercepté pendant l'exécution de fchdir().
EIO
Une erreur d'E/S s'est produite lors de la lecture ou de l'écriture du système de fichiers.
