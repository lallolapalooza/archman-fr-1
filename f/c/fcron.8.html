NOM

fcron

— démon de planification de tâches

SYNOPIS

fcron [-f] [-s] [-r] [-d NiveauDebug]

DESCRIPTION

fcron est un démon qui exécute des tâches planifiées par les utilisateurs. Il est plus performant et plus flexible que le cron standard de Vixie.

fcron s'occupe de l'ensemble des utilisateurs et peut lancer des scripts avec les privilèges de l'utilisateur qui les a créés, ou lancer un script pour tous les utilisateurs. Il peut aussi lancer des scripts en tâche de fond, ce qui permet aux utilisateurs de quitter la session sans que le script ne soit interrompu.

Il lit les fichiers de configuration dans /etc/fcron.conf (ou /usr/local/etc/fcron.conf) et les fichiers *.cron dans le répertoire de configuration de l'utilisateur. Il gère aussi les fichiers /etc/fcron.allow et /etc/fcron.deny pour contrôler l'accès.

Pour plus de détails sur le format des fichiers de planification et la configuration, veuillez consulter les pages de manuel fcrontab(1) et fcron.conf(5).

OPTIONS

-f
Mode premier plan : fcron ne se détachera pas du terminal et écrira les messages dans la sortie standard.
-s
Mode silencieux : fcron n'écrira aucun message dans les logs.
-r
Mode de reprise : fcron relance tous les processus qui étaient en cours au moment de son arrêt.
-d NiveauDebug
Active le mode de débogage avec le niveau spécifié. Les niveaux de débogage sont des entiers et plus le niveau est élevé, plus fcron sera verbeux.

VALEURS DE RETOUR

En cas de succès, fcron retourne 0. Sinon, il retourne une valeur non nulle.

SIGNALS

SIGHUP
Recharge la configuration de fcron sans le redémarrer.
SIGUSR1
Envoie un message d'information dans les logs sur l'état actuel de fcron.
SIGUSR2
Affiche les tâches en attente dans les logs.

CONFORMANT À

fcron est une implémentation du démon cron. Il vise à être compatible avec le cron standard tout en offrant des fonctionnalités supplémentaires.

FICHIERS

/etc/fcron.conf
Fichier de configuration principal pour fcron.
/usr/local/etc/fcron.conf
Fichier de configuration principal pour fcron (alternative).
/home/user/crondyn.allow
Fichier listant les utilisateurs autorisés à utiliser fcrontab et fcrondyn (un nom par ligne, le nom spécial "all" s'applique à tout le monde).
/usr/local/etc/fcron.allow
Fichier listant les utilisateurs autorisés à utiliser fcrontab et fcrondyn (même format que le fichier allow).
/usr/local/etc/fcron.deny
Fichier listant les utilisateurs qui ne sont pas autorisés à utiliser fcrontab et fcrondyn (même format que le fichier allow).
/usr/local/etc/pam.d/fcron (ou /usr/local/etc/pam.conf)
Fichier de configuration PAM pour fcron. Consultez pam(8) pour plus de détails.
/usr/local/var/run/fcron.suspend
Emplacement du fichier de mise en veille de fcron, pour les systèmes non-Linux. Ceci devrait être utilisé pour informer fcron de la durée pendant laquelle le système a été suspendu (en mémoire ou sur disque), afin que les plannings des tâches puissent être mis à jour en conséquence. Le fichier doit appartenir à root:root et ne pas être accessible en écriture par les autres. Lorsque le système reprend, écrivez le nombre de secondes (sous forme de chaîne de caractères) pendant lesquelles le système a été suspendu dans ce fichier, puis envoyez un signal SIGCONT à fcron pour qu'il traite (et supprime ensuite) ce fichier. Ceci n'est pas nécessaire sur Linux car fcron utilise des API spécifiques à Linux pour détecter la reprise et mesurer la durée de la mise en veille.
