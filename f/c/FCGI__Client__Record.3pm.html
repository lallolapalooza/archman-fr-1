FCGI::Client::Record(3pm) Documentation Perl fournie par l'utilisateur FCGI::Client::Record(3pm)

NOM

FCGI::Client::Record - objet enregistrement pour FCGI

SYNTAXE

my $record = FCGI::Client::Record->new(header => $header, content => $content);
say $record->type;

DESCRIPTION

Ce module est la classe d'enregistrement pour FCGI::Client.

ATTRIBUTS

header
L'attribut 'header' est une instance de FCGI::Client::RecordHeader.
content
L'attribut 'content' est une chaîne de caractères du contenu de l'enregistrement.

MÉTHODE

$self->request_id()
$self->content_length()
$self->type()
raccourci pour $self->header->any_method()
