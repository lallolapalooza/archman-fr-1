NOM

fcft_destroy - libérer les objets fcft_font

SYNTAXE

#include <fcft/fcft.h>

void fcft_destroy(struct fcft_font *font);

DESCRIPTION

fcft_destroy() libère l'objet fcft_font font, qui doit avoir été créé avec fcft_from_name() ou fcft_clone().

Après avoir appelé fcft_destroy(), font ne peut plus être utilisé, et toutes les références aux objets fcft_glyph (obtenus avec fcft_codepoint_rasterize()) sont maintenant invalides.

font peut être NULL, auquel cas fcft_destroy() n'a aucun effet.

VALEUR DE RETOUR

Aucune

VOIR AUSSI

fcft_from_name(), fcft_from_name2(), fcft_clone(), fcft_codepoint_rasterize()
