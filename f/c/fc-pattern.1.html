NOM

fc-pattern - analyse et affiche un motif

SYNTAXE

fc-pattern [ -cdVh ] [ --config ] [ --default ] [ -f format | --format format ] [ --version ] [ --help ]
[ motif [ élément ... ] ]

DESCRIPTION

fc-pattern analyse le motif (motif vide par défaut) et affiche le résultat analysé. Si --config est donné, la substitution de configuration est effectuée sur le motif avant d'être affiché. Si --default est donné, la substitution par défaut est effectuée sur le motif avant d'être affiché.

Si des éléments sont spécifiés, seuls ceux-ci sont imprimés.

OPTIONS

Ce programme suit la syntaxe habituelle de ligne de commande GNU, avec les options longues commençant par deux tirets (`-'). Un résumé des options est inclus ci-dessous.

-c --config
Effectue la substitution de configuration sur le motif.
-d --default
Effectue la substitution par défaut sur le motif.
-f --format format
Formate la sortie selon le spécificateur de format format.
-V --version
Affiche la version du programme et quitte.
-h --help
Affiche un résumé des options.
motif
Analyse et affiche le motif (utilise un motif vide par défaut).
élément
S'il est défini, la propriété élément est affichée pour le motif analysé.
