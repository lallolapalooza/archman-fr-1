NOM

fcft_from_name - instancie une nouvelle police

SYNOPSIS

#include <fcft/fcft.h>

struct fcft_font *fcft_from_name(

size_t count, const char *names[static count], const char *attributes);

DESCRIPTION

fcft_from_name() instancie un nouvel objet police fcft à partir des noms de police au format FontConfig. Le premier élément de names est la police principale, et les éléments restants (le cas échéant) sont des polices de repli.

Vous devez fournir au moins un nom de police.

Tous les aspects de la police (taille, DPI, variante, etc.) sont configurés via le nomde la police, en utilisant des paires attribut=valeur séparées par des deux-points (par ex. "Serif:size=26:slant=italic").

attributes est un moyen pratique d'appliquer un ensemble d'attributs à toutes les polices de names. attributes peut être NULL, auquel cas aucun attribut supplémentaire n'est ajouté aux chaînes de names.

La taille de la police est définie dans le nom de la police : par ex. Helvetica:size=12, ou Helvetica:pixelsize=12.

Pour implémenter la mise à l'échelle du bureau, multipliez simplement la taille de la police par le facteur de mise à l'échelle du bureau.

La police principale sera instanciée immédiatement, et toute erreur entraînera un message d'erreur. Les polices de repli sont instanciées à la demande, et toute erreur entraînera l'ignorance de cette police de repli, la suivante de la liste sera essayée à la place.

VALEUR RENVOYÉE

En cas de succès, fcft_from_name() renvoie un pointeur vers un objet alloué fcft_font . En cas d'erreur, NULL est renvoyé.

struct fcft_font {
    int height;
    int descent;
    int ascent;
    struct {
        int x;
        int y;
    } max_advance;
    struct {
        int x;
        int y;
    } space_advance;
    struct {
        int position;
        int thickness;
    } underline;
    struct {
        int position;
        int thickness;
    } strikeout;
};

height est la hauteur de ligne, en pixels.

descent est la distance entre la ligne de base et le glyphe descendant le plus bas de la police, en pixels. Dans le cas de fcft, elle est généralement positive (une valeur négative signifie que le descent s'étend vers le haut à partir de la ligne de base).

ascent est la distance entre la ligne de base et le glyphe ascendant le plus haut de la police, en pixels. Généralement un nombre positif (une valeur négative signifie que l' ascent s'étend vers le bas sous la ligne de base).

ascent + descent est souvent égal à height, mais pas nécessairement. height peut être plus grand, ce qui signifie que la police ajoute intentionnellement de l'espace (vertical) supplémentaire entre les lignes. Ou il peut être plus petit, auquel cas les lignes se chevauchent.

max_advance est la quantité, en pixels, dont le glyphe le plus large de la police fait avancer la position du stylo ; x pour une disposition horizontale, et y pour une disposition verticale.

space_advance est la quantité, en pixels, dont le glyphe pour l'espace (0x20) fait avancer la position du stylo ; x pour une disposition horizontale, et y pour une disposition verticale.

underline décrit comment rendre les soulignements. position est la distance, en pixels, depuis la ligne de base. Une valeur positive signifie au-dessus de la ligne de base, et une valeur négative signifie en dessous de la ligne de base. thickness est l'épaisseur de la ligne, en pixels.

strikeout décrit comment rendre les barrés. Voir underline pour une description de ses membres.

EXEMPLE

Dans cet exemple, nous instancions Times New Roman à une taille de 8 points comme police principale.

Nous lui demandons également d'utiliser Serif Bold (taille de 10 points) comme police de repli (notez qu'il est généralement préférable de laisser FontConfig gérer le repli vers des poliques génériques comme celle-ci).

De plus, les deux polices seront en italique, et utiliseront DPI=140.

Nous procédons ensuite au rendu de la chaîne hello world. On suppose que vous savez comment créer et utiliser une image pixman. Cet exemple montre uniquement comment utiliser fcft pour instancier une police, rasteriser des glyphes puis les fusionner sur une image pixman cible.

#include <stdlib.h>
#include <uchar.h>
#include <fcft/fcft.h>
int
main(void)
{
    setlocale(LC_CTYPE, "en_US.UTF-8");
    if (!fcft_set_scaling_filter(FCFT_SCALING_FILTER_LANCZOS3))
       return EXIT_FAILURE;
    struct fcft_font *font = fcft_from_name(
        2,
        (const char *[]){
            "Times New Roman:size=8",
            "Serif:size=10:weight=bold",
        },
        "slant=italic:dpi=140");
    if (font == NULL)
        return EXIT_FAILURE;
    /* Here you need to instantiate a 'target' pixman image, to blend
       with */
    pixman_image_t *canvas = ...;
    /* String to print */
    static const char32_t const hello[] = U"hello world";
    /*
     * Pen position in canvas. The numbers chosen here are more or less
     * random. Note however, that the composite calls below assume 'y'
     * is the font's baseline (and thus the glyphs will be rendered
     * above 'y')
     */
    struct {
        int x;
        int y;
    } pen = {.x = 25, .y = 50};
    /* Glyphs will be rendered in white */
    pixman_image_t *color = pixman_image_create_solid_fill(
        &(struct pixman_color_t){
            .red = 0xffff,
            .green = 0xffff,
            .blue = 0xffff,
            .alpha = 0xffff,
        });
    for (size_t i = 0; i < sizeof(hello) / sizeof(hello[0]) - 1; i++) {
        const struct fcft_glyph *glyph = fcft_codepoint_rasterize(
            font, hello[i], FCFT_SUBPIXEL_DEFAULT);
        if (glyph == NULL)
            continue;
        /* Kerning */
        long x_kern = 0;
        if (i > 0) {
            fcft_kerning(font, hello[i - 1], hello[i], &x_kern, NULL);
        pen.x += x_kern;
        if (glyph->is_color_glyph) {
            /* Glyph is a pre-rendered image; typically a color emoji */
            pixman_image_composite32(
                PIXMAP_OP_OVER, glyph->pix, NULL, canvas, 0, 0, 0, 0,
                pen.x + glyph->x, pen.y + font->ascent - glyph->y,
                glyph->width, glyph->height);
        }
        else {
            /* Glyph is an alpha mask */
            pixman_image_composite32(
                PIXMAN_OP_OVER, color, glyph->pix, canvas, 0, 0, 0, 0,
                pen.x + glyph->x, pen.y + font->ascent - glyph->y,
                glyph->width, glyph->height);
        }
        /* Advance pen position */
        pen.x += glyph->advance.x;
    }
    pixman_image_unref(src);
    fcft_destroy(font);
    return EXIT_SUCCESS;
}
