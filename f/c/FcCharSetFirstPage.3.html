FcCharSetFirstPage(3) FcCharSetFirstPage(3)

NOM

FcCharSetFirstPage - Démarrer le dénombrement du contenu d'un jeu de caractères

SYNTAXE

#include <fontconfig/fontconfig.h>

FcChar32 FcCharSetFirstPage (const FcCharSet *a, FcChar32[FC_CHARSET_MAP_SIZE] map, FcChar32 *next);

DESCRIPTION

Construit un tableau de bits dans map marquant la première page de la couverture Unicode de a. *next est défini pour contenir le point de code de base de la page suivante dans a. Renvoie le point de code de base pour la page, ou FC_CHARSET_DONE si a ne contient aucune page. Par exemple, si FcCharSetFirstPage renvoie 0x300 et remplit map avec

0xffffffff 0xffffffff 0x01000008 0x44300002 0xffffd7f0 0xfffffffb 0xffff7fff 0xffff0003
Alors la page contient les points de code 0x300 à 0x33f (les 64 premiers points de code de la page) car map[0] et map[1] ont tous leurs bits définis. Elle contient également les points de code 0x343 (0x300 + 32*2 + (4-1)) et 0x35e (0x300 + 32*2 + (31-1)) car map[2] a les 4ème et 31ème bits définis. Les points de code représentés par map[3] et suivants sont laissés comme exercice pour le lecteur ;).
