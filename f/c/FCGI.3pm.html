FCGI(3pm)

Paquet: perl-fcgi

Licences: PerlArtistic, GPL

FCGI(3) Documentation Perl fournie par l'utilisateur FCGI(3)

NOM

FCGI - Module Fast CGI

SYNTAXE

use FCGI;
my $count = 0;
my $request = FCGI::Request();
while($request->Accept() >= 0) {
    print("Content-type: text/html\r\n\r\n", ++$count);
}

DESCRIPTION

Fonctions :

FCGI::Request
Crée un descripteur de requête. Il possède les paramètres optionnels suivants :
Descripteur de fichier Perl d'entrée (par défaut : \*STDIN)
Descripteur de fichier Perl de sortie (par défaut : \*STDOUT)
Descripteur de fichier Perl d'erreur (par défaut : \*STDERR)
Ces descripteurs de fichiers seront configurés pour agir comme entrée/sortie/erreur en cas d'acceptation réussie.
Référence de hachage d'environnement (par défaut : \%ENV)
Le hachage sera rempli avec l'environnement.
Socket (par défaut : 0)
Socket pour communiquer avec le serveur. Peut être le résultat de la fonction OpenSocket. Pour l'instant, c'est le descripteur de fichier du socket qui doit être passé. Cela pourra changer à l'avenir.

Vous ne devriez utiliser votre propre socket que si votre programme n'est pas lancé par un gestionnaire de processus tel que mod_fastcgi (sauf pour le cas FastCgiExternalServer) ou cgi-fcgi. Si vous utilisez cette option, vous devez informer votre serveur FastCGI sur quel port (et éventuellement serveur) votre programme écoute. Voir remote.pl pour un exemple.

Indicateurs (par défaut : FCGI::FAIL_ACCEPT_ON_INTR)
Valeurs possibles :
FCGI::FAIL_ACCEPT_ON_INTR
S'il est activé, Accept échouera s'il est interrompu. S'il n'est pas activé, il continuera simplement d'attendre.

Exemple d'utilisation :
my $req = FCGI::Request;

Ou :
my %env;
my $in = new IO::Handle;
my $out = new IO::Handle;
my $err = new IO::Handle;
my $req = FCGI::Request($in, $out, $err, \%env);

FCGI::OpenSocket(path, backlog)
Crée un socket utilisable comme argument pour Request.
chemin
Nom de chemin du socket ou deux-points suivis du port TCP local. Notez que certains systèmes prennent en compte les permissions de fichier sur les sockets de domaine Unix, vous devrez donc vous assurer que le serveur peut écrire dans le fichier créé, en changeant l'umask avant l'appel et/ou en changeant les permissions et/ou le groupe du fichier par la suite.
file d'attente
Taille maximale de la file d'attente des connexions en attente. Si une requête de connexion arrive alors que la file est pleine, le client peut recevoir une erreur indiquant ECONNREFUSED.
FCGI::CloseSocket(socket)
Ferme un socket ouvert avec OpenSocket.
$req->Accept()
Accepte une connexion sur $req, en attachant les descripteurs de fichiers et en remplissant le hachage d'environnement. Retourne 0 en cas de succès. Si une connexion a déjà été acceptée auparavant, l'ancienne sera terminée d'abord.

Notez qu'contrairement à l'ancienne interface, aucun gestionnaire de die et warn n'est installé par défaut. Cela signifie que si vous n'exécutez pas un Perl activé pour sfio, tout message warn ou die ne se retrouvera pas dans le log du serveur par défaut. Il est conseillé de mettre en place vous-même des gestionnaires de die et warn. FCGI.pm contient un exemple de gestionnaires de die et warn.

$req->Finish()
Termine la connexion acceptée. Détache également les descripteurs de fichiers.
$req->Flush()
Vide la connexion acceptée.
$req->Detach()
Détache temporairement les descripteurs de fichiers d'une connexion acceptée.
$req->Attach()
Ré-attache les descripteurs de fichiers d'une connexion acceptée.
$req->LastCall()
Indique à la librairie de ne plus accepter de requêtes sur ce descripteur. Il devrait être sûr d'appeler cette méthode depuis des gestionnaires de signaux.

Notez que cette méthode est encore expérimentale et tout ce qui la concerne, y compris son nom, est susceptible d'être modifié.

$env = $req->GetEnvironment()
Retourne les paramètres d'environnement passés à FCGI::Request.
($in, $out, $err) = $req->GetHandles()
Retourne les paramètres de descripteurs de fichiers passés à FCGI::Request.
$isfcgi = $req->IsFastCGI()
Retourne si le programme a été exécuté en tant que FastCGI ou non.

LIMITATIONS

FCGI.pm n'est pas conscient de Unicode, seuls les caractères dans la plage 0x00-0xFF sont supportés. Les tentatives de sortie de chaînes contenant des caractères supérieurs à 0xFF entraînent une exception : (F) "Wide character in %s".

Les utilisateurs qui souhaitent le comportement incorrect précédent (FCGI.pm <= 0.68) peuvent désactiver l'exception en utilisant le pragma "bytes".

{
    use bytes;
    print "\x{263A}";
}
