NOM

fcrondyn - dialogue dynamiquement avec un démon fcron en cours d'exécution

SYNOPSIS

fcrondyn [ -c fichier ] [ -i ]

fcrondyn [ -c fichier ] -x commande

fcrondyn [ -h ]

DESCRIPTION

Fcrondyn est un outil utilisateur destiné à interagir avec un démon fcron en cours d'exécution. Il peut, par exemple, lister les tâches utilisateur chargées par fcron, exécuter l'une d'elles, modifier la priorité d'une tâche en cours d'exécution, envoyer un signal à une tâche en cours d'exécution, etc.

OPTIONS

-i
Exécute fcrondyn en mode interactif. fcrondyn est également exécuté en mode interactif lorsqu'aucune option n'est donnée.
-x commande
Exécute la commande et revient immédiatement. Voir ci-dessous pour la syntaxe et la liste des commandes.
-c fichier
Fait utiliser à fcrondyn le fichier de configuration fichier au lieu du fichier de configuration par défaut /usr/local/etc/fcron.conf. Pour interagir avec un processus fcron en cours d'exécution, fcrondyn doit utiliser le même fichier de configuration que le processus. Ainsi, plusieurs processus fcron peuvent s'exécuter simultanément sur un même système.
-d
Exécute en mode débogage. Dans ce mode, de nombreux messages d'information seront affichés afin de vérifier si quelque chose s'est mal passé.
-h
Affiche une brève description des options.
-V
Affiche un message d'information sur fcrondyn, y compris sa version et la licence sous laquelle il est distribué.

DESCRIPTION DES COMMANDES

La syntaxe des commandes de Fcrondyn est la suivante :

commande arg1 arg2 [...]

Un argument d'une commande fcrondyn est de l'un des types suivants : "TYPES D'ARGUMENTS DES COMMANDES DE FCRONDYN"

utilisateur
Un nom d'utilisateur valide.
id_tache
Un identifiant de tâche donné par l'une des commandes ls* de fcrondyn (c'est-à-dire un entier).
signal
Un numéro de signal, ou son nom (la casse n'a pas d'importance). Par exemple, "term" ou "15".
valeur_nice
Une valeur de priorité de tâche. Une valeur_nice est un entier allant de -20 (priorité la plus élevée) à 19 (la plus basse) (seul root est autorisé à utiliser une valeur négative avec cette option).

Enfin, les commandes suivantes sont reconnues (les arguments optionnels sont entre []) : "COMMANDES VALIDES DE FCRONDYN"

aide
h
Affiche un message d'aide sur les commandes de fcrondyn.
quitter
q
En mode interactif, quitte fcrondyn.
lister [utilisateur]
Liste toutes les tâches de l'utilisateur. Lorsque lister est exécuté par root, tous les utilisateurs sont listés sauf si un nom d'utilisateur est donné en argument. Voir ci-dessous pour quelques explications sur les champs utilisés par les commandes ls*.
lister_lavgq [utilisateur]
Identique à lister, mais liste uniquement les tâches qui sont dans la file d'attente de charge moyenne (c'est-à-dire celles qui attendent une charge moyenne plus basse pour être exécutées).
lister_serialq [utilisateur]
Identique à lister, mais liste uniquement les tâches qui sont dans la file d'attente série (c'est-à-dire celles qui attendent la fin d'autres tâches pour être exécutées).
lister_exeq [utilisateur]
Identique à lister, mais liste uniquement les tâches qui sont en cours d'exécution.
detail id_tache
Affiche les détails d'une tâche. id_tache est celui donné par lister.
executernow id_tache
Au lieu d'attendre la prochaine heure d'exécution programmée, exécute la tâche maintenant. La prochaine heure d'exécution est modifiée comme si la tâche s'était exécutée à l'heure prévue.
executer id_tache
Exécute la tâche maintenant. Sa prochaine heure d'exécution n'est pas modifiée.
tuer signal id_tache
Envoie un signal à une tâche en cours d'exécution.
renice valeur_nice id_tache
Change la priorité d'une tâche en cours d'exécution. "CHAMPS UTILISÉS PAR LES COMMANDES DETAIL ET LS*"
ID
Numéro d'identification unique de la tâche.
UTILISATEUR
Utilisateur propriétaire de cette tâche.
PID
Le pid de la tâche en cours d'exécution.
INDEX
Index de la tâche dans la file d'attente série (c'est-à-dire qu'elle sera exécutée lorsque toutes les tâches d'un index inférieur auront été exécutées)
R&Q
La tâche a ce nombre d'instances de la tâche donnée qui sont soit en cours d'exécution, soit en file d'attente dans la file série ou lavg.
OPTIONS
Liste des options principales définies pour la tâche. L pour les tâches qui s'exécutent uniquement sous une charge système donnée (option lavg, lavg1, lavg5 et lavg15), LO (Load average Once) si une seule instance au maximum de la tâche peut être dans la file d'attente de charge moyenne à un moment donné (option lavgonce), S pour les tâches sérialisées (option serial), SO pour les tâches qui ne seront sérialisées que pour la prochaine exécution (Serial Once), et ES si plusieurs instances de la même tâche peuvent s'exécuter simultanément (option exesev).
LAVG
3 valeurs, correspondant aux valeurs de charge moyenne du système sur 1, 5 et 15 minutes (dans cet ordre) en dessous desquelles la tâche sera exécutée, sinon elle sera mise en file d'attente jusqu'à ce que la charge moyenne du système soit appropriée (voir l'option lavg ).
JUSQU'À
Champ correspondant à l'option until.
STRICT
Champ correspondant à l'option strict. Y pour oui, N pour non.
PLANIFICATION
La prochaine exécution est programmée à cette heure et date. Veuillez noter que fcrondyn affiche l'heure et la date de la prochaine exécution dans le fuseau horaire du système où fcron s'exécute, et non le fuseau horaire qui peut être défini pour utiliser l'option timezone.
CMD
La commande qui sera exécutée.

VALEURS DE RETOUR

Fcrondyn retourne 0 en cas de sortie normale et 1 en cas d'erreur.

CONFORMITE

Devrait être conforme à POSIX.

FICHIERS

/usr/local/etc/fcron.conf
Fichier de configuration pour fcron, fcrontab et fcrondyn : contient les chemins (répertoire spool, fichier pid) et les programmes par défaut à utiliser (éditeur, shell, etc.). Voir fcron.conf(5) pour plus de détails.
/usr/local/etc/fcron.allow
Utilisateurs autorisés à utiliser fcrontab et fcrondyn (un nom par ligne, le nom spécial "all" s'applique à tout le monde)
/usr/local/etc/fcron.deny
Utilisateurs non autorisés à utiliser fcrontab et fcrondyn (même format que le fichier allow)
/usr/local/etc/pam.d/fcron (ou /usr/local/etc/pam.conf)
Fichier de configuration PAM pour fcron. Regardez pam(8) pour plus de détails.
