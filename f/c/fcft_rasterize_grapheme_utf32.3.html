NOM

fcft_rasterize_grapheme_utf32 - rasteriser le(s) glyphe(s) d'un cluster de graphèmes

SYNTAXE

#include <fcft/fcft.h>

const struct fcft_grapheme *fcft_rasterize_grapheme_utf32(

struct fcft_font *font, size_t len, const uint32_t grapheme_cluster[static len], enum fcft_subpixel subpixel);

DESCRIPTION

fcft_rasterize_grapheme_utf32() rasterise le cluster de graphèmes cluster en utilisant la police principale, ou l'une des polices de repli, dans font.

Chaque élément du cluster est un point de code Unicode encodé en UTF-32.

Les polices sont recherchées pour tous les points de code du cluster de graphèmes, en commençant par la police principale, puis les polices de repli personnalisées, et enfin les polices de repli fournies par FontConfig.

subpixel vous permet de spécifier le mode sous-pixel à utiliser. Voir fcft_rasterize_char_utf32() pour plus de détails.

VALEUR DE RETOUR

En cas d'erreur, NULL est retourné.

En cas de succès, un pointeur vers un graphème rasterisé est retourné. Le graphème est mis en cache dans fcft, ce qui rend les appels ultérieurs avec les mêmes arguments très rapides (c'est-à-dire qu'il n'est pas nécessaire que les programmes mettent eux-mêmes les glyphes en cache).

Le grapheme est géré par font. Il n'est pas nécessaire de le libérer explicitement ; il est libéré lorsque font est détruit (avec fcft_destroy()).

struct fcft_grapheme {
    int cols;
    size_t count;
    const struct fcft_glyph **glyphs;
};

cols est le nombre de "colonnes" occupées par le glyphe (effectivement, wcswidth(cluster)).

glyphs est un tableau de count glyphes rasterisés. Voir fcft_rasterize_char_utf32() pour une description de struct fcft_glyph.

VOIR AUSSI

fcft_destroy(), fcft_rasterize_char_utf32(), fcft_rasterize_text_run_utf32()
