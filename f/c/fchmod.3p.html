FCHMOD(3P) Manuel du programmeur POSIX FCHMOD(3P)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

fchmod — changer le mode d'un fichier

SYNTAXE

#include <sys/stat.h>
int fchmod(int fildes, mode_t mode);

DESCRIPTION

La fonction fchmod() est équivalente à chmod() sauf que le fichier dont les permissions sont modifiées est spécifié par le descripteur de fichier fildes.

Si fildes référence un objet de mémoire partagée, fchmod() doit seulement affecter les bits de permission de fichier S_IRUSR, S_IWUSR, S_IRGRP, S_IWGRP, S_IROTH et S_IWOTH.

Si fildes référence un objet de mémoire typée, le comportement de fchmod() n'est pas spécifié.

Si fildes fait référence à une socket, le comportement de fchmod() n'est pas spécifié.

Si fildes fait référence à un STREAM (qui est fattach()-é dans l'espace de noms du système de fichiers), l'appel retourne avec succès, sans rien faire.

VALEUR DE RETOUR

En cas de succès, fchmod() retourne 0. Sinon, elle retourne -1 et définit errno pour indiquer l'erreur.

ERREURS

La fonction fchmod() échouera si :

EBADF
L'argument fildes n'est pas un descripteur de fichier ouvert.
EPERM
L'ID utilisateur effectif ne correspond pas au propriétaire du fichier et le processus ne dispose pas des privilèges appropriés.
EROFS
Le fichier référencé par fildes réside sur un système de fichiers en lecture seule.

La fonction fchmod() peut échouer si :

EINTR
La fonction fchmod() a été interrompue par un signal.
EINVAL
La valeur de l'argument mode est invalide.
EINVAL
L'argument fildes fait référence à un pipe et l'implémentation interdit l'exécution de fchmod() sur un pipe.

Les sections suivantes sont informatives.

EXEMPLES

Modification des permissions actuelles d'un fichier

L'exemple suivant montre comment modifier les permissions d'un fichier nommé /home/cnd/mod1 afin que le propriétaire et le groupe aient les permissions de lecture/écriture/exécution, mais que le reste du monde n'ait que les permissions de lecture/écriture.

#include <sys/stat.h>
#include <fcntl.h>
mode_t mode;
int    fildes;
...
fildes = open("/home/cnd/mod1", O_RDWR);
fchmod(fildes, S_IRWXU | S_IRWXG | S_IROTH | S_IWOTH);
