FCGI::Client::RecordFactory(3pm) Documentation Perl fournie par la communauté FCGI::Client::RecordFactory(3pm)

NOM

FCGI::Client::RecordFactory - Fabrique d'enregistrements FCGI

MÉTHODES API HAUT NIVEAU

FCGI::Client::RecordFactory->create_request($reqid, $env, $content);
Cette méthode crée un ensemble d'enregistrements de requête. $env sont les variables d'environnement identiques à CGI. $content est le corps de la requête. Cette méthode retourne une chaîne d'enregistrements de requête. Vous pouvez l'envoyer à un socket.

MÉTHODES API BAS NIVEAU

FCGI::Client::RecordFactory->build_begin_request($reqid, FCGI_RESPONDER, $flags);
Construit un enregistrement FCGI_BEGIN_REQUEST.
FCGI::Client::RecordFactory->build_params($reqid, %$env)
Construit un enregistrement FCGI_PARAMS.
FCGI::Client::RecordFactory->build_stdin($reqid, $content);
Construit un enregistrement FCGI_STDIN.
