NOM

fcft_clone - copier une police déjà instanciée

SYNTAXE

#include <fcft/fcft.h>

struct fcft_font *fcft_clone(const struct fcft_font *font);

DESCRIPTION

fcft_clone() crée une nouvelle instance en copiant font. fcft utilise en interne le comptage de références, ce qui rend cette opération très rapide (beaucoup plus rapide que d'instancier explicitement une nouvelle police avec fcft_from_name()).

Pour libérer toutes les ressources associées à la police d'origine ainsi qu'à la police clonée, fcft_destroy() doit être appelée pour **la police d'origine** ainsi que pour **le clone**.

VALEUR DE RETOUR

En cas de succès, fcft_clone() renvoie un pointeur vers un nouvel objet fcft_font. En cas d'erreur, NULL est renvoyé.

VOIR AUSSI

fcft_from_name(), fcft_from_name2(), fcft_destroy()
