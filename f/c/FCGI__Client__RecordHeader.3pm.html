FCGI::Client::RecordHeader(3pm) Documentation Perl Contribuée par l'utilisateur FCGI::Client::RecordHeader(3pm)

NOM

FCGI::Client::RecordHeader - objet d'en-tête d'enregistrement pour FCGI

SYNTAXE

my $header = FCGI::Client::RecordHeader->new(raw => $raw);
say $header->type;

DESCRIPTION

Ce module est la classe d'en-tête d'enregistrement pour FCGI::Client.

ATTRIBUTS

raw
la chaîne brute de l'en-tête d'enregistrement. La taille de l'en-tête d'enregistrement est définie dans FCGI::Client::Constant::FCGI_HEADER_LEN.

MÉTHODE INSTANCE

$self->request_id()
$self->type()
$self->content_length()
$self->padding_length()
Ces méthodes retournent chaque champ de l'en-tête d'enregistrement.
