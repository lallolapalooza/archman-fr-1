NOM

fcft_precompose - précomposer deux caractères larges en un seul

SYNTAXE

#include <fcft/fcft.h>

bool fcft_precompose(

const struct fcft_font *font, uint32_t base, uint32_t comb, bool *base_is_from_primary, bool *comb_is_from_primary, bool *composed_is_from_primary);

DESCRIPTION

fcft_precompose() compose les caractères larges base et comb en un seul caractère large. Par exemple, L'a' + L'\u0301' peut être combiné en L'á'.

Si *_is_from_primary ne sont pas NUL, ils seront à true si le caractère large correspondant existe dans la police principale. S'il est à false, il n'existe pas dans la police principale et fcft_codepoint_rasterize() choisira le glyphe dans l'une des polices de secours.

VALEUR DE RETOUR

En cas de succès, fcft_precompose() retourne un caractère large composé. En cas d'erreur, (uint32_t)-1 est retourné.

VOIR AUSSI

fcft_codepoint_rasterize(), fcft_kerning()
