NOM

fcgistarter - Démarrer un programme FastCGI

SYNTAXE

fcgistarter -c commande -p port [ -i interface ] -N num

RÉSUMÉ

NOTE

Actuellement, ne fonctionne que sur les systèmes Unix.

OPTIONS

-c commande
Chemin absolu du programme FastCGI
-p port
Port sur lequel le programme écoutera
-i interface
Interface sur laquelle le programme écoutera
-N num
Nombre d'instances du programme
