fcft_text_run_destroy(3) fcft fcft_text_run_destroy(3)

NOM

fcft_text_run_destroy - libérer les objets fcft_text_run

SYNTAXE

#include <fcft/fcft.h>

void fcft_text_run_destroy(struct fcft_text_run *run);

DESCRIPTION

fcft_text_run_destroy() libère l'objet fcft_text_run run, qui doit avoir été créé avec fcft_text_run_rasterize().

Notez qu'il est acceptable d'appeler fcft_destroy() sur l'objet de police utilisé pour pixelliser la ligne de texte, avant de libérer la ligne de texte elle-même. C'est-à-dire que les applications peuvent mettre en cache les lignes de texte au-delà de la durée de vie de l'objet de police.

run peut être NULL, auquel cas fcft_text_run_destroy() ne fait rien.

VOIR AUSSI
