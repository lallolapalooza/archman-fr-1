NOM

fc-list - lister les polices disponibles

SYNTAXE

fc-list [ -vVh ] [ --verbose ] [ -f format | --format format ] [ -q | --quiet ] [ --version ] [ --help ]
[ motif [ élément ... ] ]

DESCRIPTION

fc-list liste les polices et les styles disponibles sur le système pour les applications utilisant fontconfig. Si des éléments sont spécifiés, seuls ceux-ci sont affichés. Sinon, la famille et le style sont affichés, sauf si la sortie détaillée est demandée.

OPTIONS

Ce programme suit la syntaxe habituelle des lignes de commande GNU, avec des options longues commençant par deux tirets (`-'). Un résumé des options est inclus ci-dessous.

-v --verbose
Affiche une sortie détaillée de tout le motif de police pour chaque correspondance, ou les éléments si certains sont fournis.
-f --format format
Formate la sortie selon le spécificateur de format format.
-q --quiet
Supprime toute sortie normale. Renvoie 1 comme code d'erreur si aucune police ne correspond.
-V --version
Affiche la version du programme et quitte.
-h --help
Affiche le résumé des options.
motif
Si cet argument est défini, seules les polices correspondant au motif sont affichées.
élément
S'il est défini, la propriété élément est affichée pour les polices correspondantes.

EXEMPLES

fc-list
Liste toutes les graisses de polices.
fc-list :lang=hi
Liste les graisses de polices qui couvrent l'hindi.
fc-list : famille style fichier espacement
Liste le nom de fichier et la valeur d'espacement pour chaque graisse de police. ``:'' est un motif vide qui correspond à toutes les polices.
