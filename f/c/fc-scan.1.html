NOM

fc-scan - scanner des fichiers ou des répertoires de polices

SYNTAXE

fc-scan [ -Vh ]
[ -f format | --format format ] [ --version ] [ --help ] fichier ...

DESCRIPTION

fc-scan scanne récursivement les fichiers et affiche un modèle de police pour chaque aspect trouvé.

OPTIONS

Ce programme suit la syntaxe habituelle des lignes de commande GNU, avec les options longues commençant par deux tirets (`-'). Un résumé des options est inclus ci-dessous.

-f --format format
Formate la sortie selon le spécificateur de format format.
-V --version
Affiche la version du programme et quitte.
-h --help
Affiche un résumé des options.
fichier
Scanne récursivement le fichier pour trouver des aspects de polices.

CODES DE RETOUR

fc-scan renvoie le code d'erreur 0 si au moins une police a été trouvée, ou 1 sinon.
