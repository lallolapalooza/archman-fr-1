NOM

fcft_capabilities - capacités optionnelles disponibles de la bibliothèque

SYNTAXE

#include <fcft/fcft.h>

enum fcft_capabilities fcft_capabilities(void);

DESCRIPTION

fcft_capabilities() retourne un masque de bits des capacités optionnelles activées de la bibliothèque :

enum fcft_capabilities {
    FCFT_CAPABILITY_GRAPHEME_SHAPING = 0x1,  /* Depuis 2.3.0 */
    FCFT_CAPABILITY_TEXT_RUN_SHAPING = 0x2,  /* Depuis 2.4.0 */
    FCFT_CAPABILITY_SVG = 0x4,               /* Depuis 3.1.0 */
};

FCFT_CAPABILITY_GRAPHEME_SHAPING

fcft peut faire la mise en forme des graphèmes (en utilisant HarfBuzz), et fcft_grapheme_rasterize() peut être attendue pour retourner non-NULL.

FCFT_CAPABILITY_TEXT_RUN_SHAPING

fcft peut faire la mise en forme des séquences de caractères (en utilisant HarfBuzz), et fcft_text_run_rasterize() peut être attendue pour retourner non-NULL.

FCFT_CAPABILITY_SVG

fcft peut tracer des glyphes à partir de polices OT-SVG.

VOIR AUSSI

fcft_grapheme_glyph_rasterize(), fcft_text_run_rasterize()
