NOM

fcft_set_emoji_presentation - configure la présentation par défaut des emojis

SYNTAXE

#include <fcft/fcft.h>

bool fcft_set_emoji_presentation(struct fcft_font *font,

enum fcft_emoji_presentation presentation);

DESCRIPTION

Note : cette fonction est obsolète et sera supprimée dans la prochaine version majeure.

fcft_set_emoji_presentation() configure le style de présentation par défaut à utiliser avec les emojis, tant pour une présentation textuelle que pour un style de présentation d'emoji.

Ces emojis peuvent être suivis d'un sélecteur de variation (invisible). Lorsqu'ils ne sont pas suivis d'un sélecteur, l'implémentation doit choisir un style.

Un exemple d'un tel emoji est U+263A - VISAGE BLANC SOURIANT :

  • non qualifié : ☺
  • texte : ☺︎
  • emoji : ☺️

La norme Unicode définit les styles de présentation par défaut, et c'est ce que fcft utilise par défaut.

Cependant, dans certains cas, l'application peut souhaiter utiliser toujours le style texte ou le style emoji.

C'est à cela que sert fcft_set_emoji_presentation(). Les valeurs possibles pour presentation sont :

  • FCFT_EMOJI_PRESENTATION_DEFAULT
  • FCFT_EMOJI_PRESENTATION_TEXT
  • FCFT_EMOJI_PRESENTATION_EMOJI

Pour répéter : ce réglage affecte les emojis sans sélecteur de variation explicite. En d'autres termes, il remplace le style de présentation par défaut.

FCFT_EMOJI_PRESENTATION_DEFAULT est la valeur par défaut et amène fcft à utiliser la présentation par défaut telle que définie par Unicode.

FCFT_EMOJI_PRESENTATION_TEXT force le rendu de tous les emojis à style de présentation multiple dans leur style de présentation textuelle.

FCFT_EMOJI_PRESENTATION_EMOJI force le rendu de tous les emojis à style de présentation multiple dans leur style de présentation emoji.

Cette fonction ne vide pas les caches de glyphes et doit par conséquent être appelée avant la rastérisation de tout glyphe.
