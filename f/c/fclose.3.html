fclose(3) Manuel des fonctions de bibliothèque fclose(3)

NOM

fclose - fermer un flux

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNOPSIS

#include <stdio.h>
int fclose(FILE *stream);

DESCRIPTION

La fonction fclose() vide le flux pointé par stream (en écrivant toute donnée de sortie mise en mémoire tampon à l'aide de fflush(3)) et ferme le descripteur de fichier sous-jacent.

VALEUR RENVOYÉE

En cas de succès, 0 est renvoyé. Sinon, EOF est renvoyé et errno est défini pour indiquer l'erreur. Dans les deux cas, tout accès ultérieur (y compris un autre appel à fclose()) au flux entraîne un comportement indéfini.

ERREURS

EBADF
Le descripteur de fichier sous-jacent à stream n'est pas valide.

La fonction fclose() peut également échouer et définir errno pour l'une des erreurs spécifiées pour les routines close(2), write(2), ou fflush(3).

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
fclose () Sécurité des threads MT-Safe

NORMES

C11, POSIX.1-2008.

HISTORIQUE

C89, POSIX.1-2001.

NOTES

Notez que fclose() ne vide que les tampons de l'espace utilisateur fournis par la bibliothèque C. Pour garantir que les données sont physiquement stockées sur le disque, les tampons du noyau doivent également être vidés, par exemple, avec sync(2) ou fsync(2).

VOIR AUSSI

close(2), fcloseall(3), fflush(3), fileno(3), fopen(3), setbuf(3)
