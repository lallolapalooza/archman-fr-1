fcft_font_options_destroy(3) fcft fcft_font_options_destroy(3)

NOM

fcft_font_options_destroy - libérer les objets fcft_font_options

SYNTAXE

#include <fcft/fcft.h>

void fcft_font_options_destroy(struct fcft_font_options *options);

DESCRIPTION

fcft_font_options_destroy() libère l'objet fcft_font_options options, qui doit avoir été créé avec fcft_font_options_create().

options peut être NULL, dans ce cas fcft_font_options_destroy() ne fait rien.

VOIR AUSSI
