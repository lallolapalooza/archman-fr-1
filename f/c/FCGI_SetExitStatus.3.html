FCGI_SetExitStatus(3)

Paquet: fcgi

Licences: custom

() ()
NOM
FCGI_SetExitStatus - bibliothèque de compatibilité fcgi_stdio

SYNTAXE
#include "fcgi_stdio.h"


void
FCGI_SetExitStatus(int status);

DESCRIPTION
Définit le code de sortie pour la requête FastCGI actuelle.
Le code de sortie est le code d'état avec lequel la requête se serait
terminée si elle avait été exécutée en tant que programme CGI.


Vous pouvez appeler FCGI_SetExitStatus plusieurs fois pendant une requête ;
le dernier appel avant la fin de la requête détermine la valeur.
