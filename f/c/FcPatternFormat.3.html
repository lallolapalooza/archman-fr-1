format. La valeur de retour fait référence à une mémoire nouvellement allouée qui devrait être libérée par l'appelant à l'aide de free(), ou NULL si format est invalide. Le format est librement inspiré des chaînes de format de style

printf.

La chaîne de format est composée de zéro ou plusieurs directives : des caractères ordinaires (pas "%"), qui sont copiés tels quels dans le flux de sortie ; et des balises qui sont interprétées pour construire du texte à partir du motif de diverses manières (expliqué ci-dessous). Les caractères spéciaux peuvent être échappés à l'aide du caractère d'échappement. Les caractères spéciaux de style chaîne C comme \n et \r sont également pris en charge (ce qui est utile lorsque la chaîne de format n'est pas une chaîne littérale C). Il est conseillé d'échapper toujours les accolades destinées à être copiées dans la sortie en tant que caractères ordinaires.

Chaque

balise est introduite par le caractère "%", suivi d'une largeur de champ minimale facultative, suivie du contenu de la balise entre accolades ({}). Si la valeur de largeur de champ minimale est fournie, la balise sera développée et le résultat sera complété pour atteindre la largeur minimale. Si la largeur de champ minimale est positive, le remplissage alignera le texte à droite. Une largeur de champ négative alignera à gauche. Le reste de cette section décrit divers contenus de balises pris en

charge

e t leur expansion. Une balise simple est celle dont le contenu est un identifiant. Lorsque les balises simples sont développées, l'identifiant nommé sera recherché dans le motif et la liste de valeurs résultante sera retournée, jointe ensemble à l'aide d'une virgule. Par exemple, pour imprimer le nom de la famille et le style du motif, utilisez le format "%{family} %{style}\n". Pour étendre la colonne de la famille à

quarante

caractères, utilisez "%-40{family}%{style}\n". Les balises simples se développent en une liste de toutes les valeurs pour un élément. Pour ne choisir qu'une seule des valeurs, on peut indexer à l'aide de la syntaxe

"%{elt[idx]

}". Par exemple, pour obtenir seulement le premier nom de famille, utilisez "%{family[0]}". Si une balise simple se termine par "=" et que l'élément est trouvé dans le motif, le nom de l'élément suivi de "=" sera produit avant la liste des valeurs. Par exemple, "%{weight=} " peut se développer en la

chaîne

"weight=80". Ou en la chaîne vide si le motif n'a pas de poids défini. Si une balise simple commence par ":" et que l'élément est trouvé dans le motif, ":" sera imprimé en premier. Par exemple, en combinant cela avec le =, le format "%{:weight=} " peut se développer en ":

weight=80"

ou en la chaîne vide si le motif n'a pas de poids défini. Si une balise simple contient la chaîne ":-", le reste du contenu de la balise sera utilisé comme chaîne par défaut. La chaîne par défaut est produite si l'élément n'est pas trouvé dans le motif. Par exemple, le format "%{:weight=:-123}" peut se développer en ":weight=80" ou en la chaîne

":

w eight=123" si le motif n'a pas de poids défini. Une balise de comptage est celle qui commence par le caractère "#" suivi d'un nom d'élément, et se développe en le nombre de valeurs pour l'élément dans le motif. Par exemple, "%{#family}" se développe en le nombre de noms

de

famille que le motif a définis, qui peut être zéro. Une balise de sous-expression est celle qui développe une sous-expression. Le contenu de la balise est la sous-expression à développer placée à l'intérieur d'un autre ensemble d'accolades. Les balises de sous-expression sont utiles pour aligner une sous-expression entière, ou pour appliquer des convertisseurs (expliqués plus tard) à toute la sortie de la sous-expression. Par exemple, le format "%40{{%{family} %{style}}}" développe la sous-expression pour construire le nom de la famille suivi du style, puis

prend

la chaîne entière et la complète à gauche pour qu'elle fasse au moins quarante caractères. Une balise de filtrage sortant est celle qui commence par le caractère "-" suivi d'une liste de noms d'éléments séparés par des virgules, suivie d'une sous-expression enclose entre accolades. La sous-expression sera développée mais avec un motif duquel les éléments listés ont été supprimés. Par exemple, le format "%{-size,pixelsize{sub-expr}}

"

d éveloppera "sub-expr" avec le motif sans les éléments size et pixelsize. Une balise de filtrage entrant est celle qui commence par le caractère "+" suivi d'une liste de noms d'éléments séparés par des virgules, suivie d'une sous-expression enclose entre accolades. La sous-expression sera développée mais avec un motif qui n'a que les éléments listés du motif environnant. Par exemple, le format "%{+family,familylang{sub-expr}}" développera "sub-expr" avec un sous-motif ne consistant qu'

en

les éléments family et familylang de le motif. Une balise conditionnelle est celle qui commence par le caractère "?" suivi d'une liste de conditions d'éléments séparées par des virgules, suivie de deux sous-expressions encloses entre accolades. Une condition d'élément peut être un nom d'élément, auquel cas elle teste si l'élément est défini dans le motif, ou le caractère "!" suivi d'un nom d'élément, auquel cas le test est nié. La conditionnelle passe si toutes les conditions d'éléments passent. La balise développe la première sous-expression si la conditionnelle passe, et développe la deuxième sous-expression sinon. Par exemple, le format "%{?size,dpi,!pixelsize{pass}{fail}}" se développera en "pass" si le motif a les éléments size et dpi mais pas l'élément pixelsize, et en

"fail"

s inon. Une balise d'énumération est celle qui commence par la chaîne "[]" suivie d'une liste de noms d'éléments séparés par des virgules, suivie d'une sous-expression enclose entre accolades. La liste des valeurs pour les éléments nommés est parcourue en parallèle et la sous-expression est développée chaque fois avec un motif n'ayant qu'une seule valeur pour ces éléments, en commençant par la première valeur et en continuant aussi longtemps que l'un de ces éléments a une valeur. Par exemple, le format "%{[]family,familylang{%{family} (%{familylang})\n}}" développera le motif "%{family} (%{familylang})\n}" avec un motif n'ayant que la première valeur des éléments family et familylang, puis le développera avec les deuxièmes valeurs, puis les

troisièmes,

etc. Comme cas particulier, si une balise d'énumération n'a qu'un seul élément, et que cet élément n'a qu'une seule valeur dans le motif, et que cette valeur est de type FcLangSet, les langues individuelles du jeu de langues
