NOM

fcft_font_options_create - instancier une nouvelle police

SYNTAXE

#include <fcft/fcft.h>

struct fcft_font_options *fcft_font_options_create(void);

DESCRIPTION

fcft_font_options_create() alloue un objet struct fcft_font_options à utiliser avec fcft_from_name2(3).

L'objet retourné sera initialisé avec des valeurs par défaut. Modifiez manuellement les membres de la structure pour les remplacer.

Note : vous devez utiliser fcft_font_options_create() pour allouer l'objet options ; ne l'allouez pas vous-même, que ce soit depuis le tas ou sur la pile. Ceci est fait pour assurer la compatibilité future.

struct fcft_font_options {
    enum fcft_scaling_filter scaling_filter;
    enum fcft_emoji_presentation emoji_presentation;
    struct {
        bool srgb_decode;
        pixman_format_code_t format;
    } color_glyphs;
};

FILTRE DE REMISE À L'ÉCHELLE

Configure le filtre à utiliser lors de la réduction de la taille des polices bitmap (typiquement les polices emoji).

Les valeurs possibles sont :

  • FCFT_SCALING_FILTER_NONE
  • FCFT_SCALING_FILTER_NEAREST
  • FCFT_SCALING_FILTER_BILINEAR
  • FCFT_SCALING_FILTER_IMPULSE
  • FCFT_SCALING_FILTER_BOX
  • FCFT_SCALING_FILTER_LINEAR
  • FCFT_SCALING_FILTER_CUBIC
  • FCFT_SCALING_FILTER_GAUSSIAN
  • FCFT_SCALING_FILTER_LANCZOS2
  • FCFT_SCALING_FILTER_LANCZOS3
  • FCFT_SCALING_FILTER_LANCZOS3_STRETCHED

FCFT_SCALING_FILTER_NONE désactive le filtrage.

FCFT_SCALING_FILTER_NEAREST et FCFT_SCALING_FILTER_BILINEAR sont des filtres traditionnels, nearest étant le plus rapide.

Le reste sont des filtres de convolution séparables.

La valeur par défaut est FCFT_SCALING_FILTER_CUBIC.

PRÉSENTATION EMOJI

emoji_presentation configure le style de présentation par défaut à utiliser avec les emojis ayant à la fois une présentation texte et un style de présentation emoji.

Ces emojis peuvent être suivis d'un sélecteur de variation (invisible). Lorsqu'ils ne sont pas suivis d'un sélecteur, l'implémentation doit choisir un style.

Un exemple d'emoji de ce type est U+263A - VISAGE BLANC SOURIANT :

  • non qualifié : ☺
  • texte : ☺
  • emoji : ☺️

La norme Unicode définit les styles de présentation par défaut, et c'est ce que fcft utilise par défaut.

Cependant, dans certains cas, l'application peut vouloir utiliser toujours soit le style texte, soit le style emoji.

C'est à cela que sert emoji_presentation. Les valeurs possibles sont :

  • FCFT_EMOJI_PRESENTATION_DEFAULT
  • FCFT_EMOJI_PRESENTATION_TEXT
  • FCFT_EMOJI_PRESENTATION_EMOJI

Pour répéter : ce paramètre affecte les emojis sans sélecteur de variation explicite. Autrement dit, il remplace le style de présentation par **défaut**.

FCFT_EMOJI_PRESENTATION_DEFAULT est la valeur par défaut et amène fcft à utiliser la présentation par défaut telle que définie par Unicode.

FCFT_EMOJI_PRESENTATION_TEXT force le rendu de tous les emojis à présentation multiple dans leur style de présentation texte.

FCFT_EMOJI_PRESENTATION_EMOJI force le rendu de tous les emojis à présentation multiple dans leur style de présentation emoji.

GLYPHES DE COULEUR

srgb_decode : si vrai, les données pixel seront décodées de sRGB vers l'espace linéaire. Si faux (par défaut), les données pixel sont utilisées telles quelles.

format définit le format de surface pixman à utiliser pour les glyphes de couleur. Par défaut, c'est PIXMAN_a8r8g8b8. Une utilisation est d'activer une précision de couleur plus élevée lorsque srgb_decode est activé, afin d'éviter une perte de précision lors du décodage depuis sRGB.
