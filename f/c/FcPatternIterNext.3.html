FcPatternIterNext(3)

Paquet: fontconfig

Licences: HPND AND Unicode-DFS-2016

FcPatternIterNext(3) FcPatternIterNext(3)

NOM

FcPatternIterNext -

SYNTAXE

#include <fontconfig/fontconfig.h>

FcBool FcPatternIterNext (const FcPattern *p, FcPatternIter *iter);

DESCRIPTION

Définit iter pour pointer vers l'objet suivant dans p et renvoie FcTrue si iter a été modifié pour pointer vers l'objet suivant. Renvoie FcFalse sinon.
