NOM

fcron.conf - fichier de configuration pour fcron et fcrontab

DESCRIPTION

RÉSUMÉ

Cette page décrit la syntaxe utilisée pour le fichier de configuration de fcrontab(1), fcrondyn(1) et fcron(8).

Les lignes vides, les lignes commençant par un signe dièse (#) (considérées comme des commentaires), les blancs et tabulations en début de ligne sont ignorés. Chaque ligne d'un fichier fcron.conf est de la forme :

nom = valeur

où les blancs autour du signe égal (=) sont ignorés et optionnels. Les blancs en fin de ligne sont également ignorés.

Les noms suivants sont reconnus (valeur par défaut entre parenthèses) : "VARIABLES VALIDES DANS UN FICHIER FCRON.CONF"

fcrontabs=répertoire (/usr/local/var/spool/fcron)
Répertoire de spool de Fcron.
pidfile=chemin-fichier (/usr/local/var/run/fcron.pid)
Emplacement du fichier PID de fcron (nécessaire pour que fcrontab fonctionne correctement).
suspendfile=chemin-fichier (/usr/local/var/run/fcron.suspend)
Emplacement du fichier de suspension de fcron. Sur les systèmes non-Linux, ceci devrait être utilisé pour indiquer à fcron combien de temps le système a été suspendu (en mémoire ou sur disque), afin que les planifications des tâches puissent être mises à jour en conséquence.
fifofile=chemin-fichier (/usr/local/var/run/fcron.fifo)
Emplacement du fichier FIFO de fcron (nécessaire pour que fcrondyn communique avec fcron).
fcronallow=chemin-fichier (/usr/local/etc/fcron.allow)
Emplacement du fichier fcron.allow.
fcrondeny=chemin-fichier (/usr/local/etc/fcron.deny)
Emplacement du fichier fcron.deny.
shell=chemin-fichier (/usr/bin/sh)
Emplacement du shell par défaut appelé par fcron lors de l'exécution d'une tâche. Lorsque fcron exécute une tâche, il utilise la valeur de SHELL de la fcrontab s'il y en a une, sinon il utilise la valeur de fcron.conf s'il y en a une, ou en dernier recours la valeur de /etc/passwd.
sendmail=chemin-fichier (/usr/sbin/sendmail)
Emplacement du programme de messagerie appelé par fcron pour envoyer la sortie des tâches.
editor=chemin-fichier (/usr/bin/vi)
Emplacement de l'éditeur par défaut utilisé lors de l'invocation de "fcrontab -e".
maildisplayname=chaîne (Fcron Daemon)
Nom d'affichage pour l'en-tête "From: " des courriels envoyés par nous. Notez que par le passé, fcron suivait le format d'en-tête d'email par défaut de Vixie cron, qui n'est pas entièrement conforme à la RFC 5322 (voir le problème #15 <URL:https://github.com/yo8192/fcron/issues/15>). fcron reviendra à ce comportement ancien lorsque cette option sera définie sur une chaîne vide. Les chemins de fichiers et les répertoires sont complets et absolus (c'est-à-dire commençant par "/").

Pour exécuter plusieurs instances de fcron simultanément sur le même système, vous devez utiliser un fichier de configuration différent pour chaque instance. Chaque instance doit avoir un fcrontabs, un pidfile et un fifofile différents. Ensuite, utilisez l'option de ligne de commande de fcron(8) -c pour sélectionner le fichier de configuration (donc l'instance) auquel vous faites référence.

FICHIERS

/usr/local/etc/fcron.conf
Fichier de configuration pour fcron, fcrontab et fcrondyn : contient les chemins (répertoire de spool, fichier PID) et les programmes par défaut à utiliser (éditeur, shell, etc.). Voir fcron.conf(5) pour plus de détails.
/usr/local/etc/fcron.allow
Utilisateurs autorisés à utiliser fcrontab et fcrondyn (un nom par ligne, le nom spécial "all" s'applique à tout le monde)
/usr/local/etc/fcron.deny
Utilisateurs non autorisés à utiliser fcrontab et fcrondyn (même format que le fichier allow)
/usr/local/etc/pam.d/fcron (ou /usr/local/etc/pam.conf)
Fichier de configuration PAM pour fcron. Consultez pam(8) pour plus de détails.
