NOM

fc-query - interroger les fichiers de polices

SYNTAXE

fc-query [ -Vh ]
[ -b | --ignore-blanks ] [ -i index | --index index ] [ -f format | --format format ] [ --version ] [ --help ] fichier-police ...

DESCRIPTION

fc-query interroge le(s) fichier(s) de police fichier-police en utilisant les règles normales de fontconfig et affiche le modèle de police pour chaque face trouvée. Si --index est donné, seule une face de chaque fichier est interrogée, sinon toutes les faces sont interrogées.

OPTIONS

Ce programme suit la syntaxe habituelle des lignes de commande GNU, avec les options longues commençant par deux traits d'union (`-'). Un résumé des options est inclus ci-dessous.

-b --ignore-blanks
Ignore les espaces pour calculer les langues
-i --index index
Interroge uniquement la face d'indice index de chaque fichier.
-f --format format
Formate la sortie selon le spécificateur de format format.
-V --version
Affiche la version du programme et quitte.
-h --help
Affiche un résumé des options.
fichier-police
Interroge le fichier-police pour les faces de polices.

CODES DE RETOUR

fc-query retourne le code d'erreur 0 pour une analyse réussie, ou 1 si des erreurs se sont produites ou si au moins une face de police n'a pas pu être ouverte.
