FCGI_Finish(3)

Paquet: fcgi

Licences: custom

() ()
NOM
FCGI_Finish
- bibliothèque de compatibilité fcgi_stdio

SYNTAXE
#include "fcgi_stdio.h"


void
FCGI_Finish(void);

DESCRIPTION
La fonction FCGI_Finish termine la requête actuelle du serveur
HTTP. La requête actuelle a été démarrée par l'appel le plus récent
à FCGI_Accept(3).


FCGI_Finish permet à une application d'entrelacer d'autres activités
avec le traitement des requêtes. Dans un cas extrême, une
application appellerait FCGI_Finish pour terminer la requête actuelle
avant de se terminer, par exemple pour récupérer du stockage qui fuit.


En terminant la requête actuelle, FCGI_Finish peut détecter
des erreurs, par exemple un tuyau cassé vers un client qui s'est déconnecté
tôt. FCGI_Finish ignore ces erreurs. Une application
qui souhaite gérer de telles erreurs devrait explicitement appeler
fclose(stderr), puis fclose(stdout) ; un retour EOF de
l'un ou l'autre indique une erreur.


FCGI_Finish libère tout stockage alloué par l'appel le plus récent
à FCGI_Accept. Voir FCGI_Accept(3) pour les avertissements contre la conservation
de pointeurs vers ce stockage.
