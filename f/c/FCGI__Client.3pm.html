FCGI::Client(3pm) Documentation Perl fournie par l'utilisateur FCGI::Client(3pm)

NOM

FCGI::Client - bibliothèque cliente pour le protocole fastcgi

SYNTAXE

use FCGI::Client;
my $sock = IO::Socket::INET->new(
    PeerAddr => '127.0.0.1',
    PeerPort => $port,
) or die $!;
my $client = FCGI::Client::Connection->new( sock => $sock );
my ( $stdout, $stderr ) = $client->request(
    +{
        REQUEST_METHOD => 'GET',
        QUERY_STRING   => 'foo=bar',
    },
    ''
);

DESCRIPTION

FCGI::Client est une bibliothèque cliente pour le protocole fastcgi.
