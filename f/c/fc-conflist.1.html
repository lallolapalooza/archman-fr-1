NOM

fc-conflist - liste les fichiers de configuration traités par Fontconfig

SYNTAXE

fc-conflist [ -Vh ]
[ --version ] [ --help ]

DESCRIPTION

fc-conflist affiche une liste annotée de tous les fichiers de configuration traités par Fontconfig.

La sortie est un `-' ou `+' selon que le fichier est ignoré ou traité, un espace, le chemin du fichier, un deux-points et un espace, puis la description du fichier ou `Aucune description' si aucune n'est présente.

L'ordre des fichiers ressemble à la manière dont fontconfig les traite réellement, sauf si un contient un élément <include>. Dans ce cas, il sera affiché après le traitement de tous les sous-répertoires ciblés par <include>.

OPTIONS

Ce programme suit la syntaxe habituelle des lignes de commande GNU, avec les options longues commençant par deux traits d'union (`-'). Un résumé des options est inclus ci-dessous.

-V --version
Affiche la version du programme et quitte.
-h --help
Affiche un résumé des options.

CODES DE RETOUR

fc-conflist retourne le code d'erreur 0 pour un analyse réussi, ou 1 si des erreurs se sont produites ou si au moins une face de police n'a pas pu être ouverte.
