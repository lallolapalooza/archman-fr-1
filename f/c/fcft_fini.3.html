NOM

fcft_fini - libérer les ressources globales

SYNTAXE

#include <fcft/fcft.h>

void fcft_fini(void);

DESCRIPTION

Libère toutes les ressources globales : le cache de polices, les primitives de synchronisation de threads, et appelle FT_Done_FreeType() et FcFini().

Appeler fcft_fini() n'est généralement pas requis, mais est nécessaire pour des exécutions Valgrind propres.

VOIR AUSSI

fcft_init(), FT_Done_FreeType(), FcFini()
