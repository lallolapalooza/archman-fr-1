NOM

FcPatternBuild, FcPatternVaBuild, FcPatternVapBuild - Créer des modèles à partir d'arguments

SYNTAXE

#include <fontconfig/fontconfig.h>

FcPattern * FcPatternBuild (FcPattern *pattern, ...);

FcPattern * FcPatternVaBuild (FcPattern *pattern, va_list va);

void FcPatternVapBuild (FcPattern *result, FcPattern *pattern, va_list va);

DESCRIPTION

Construit un modèle à l'aide d'une liste d'objets, de types et de valeurs. Chaque valeur à entrer dans le modèle est spécifiée avec trois arguments :

1.
Nom de l'objet, une chaîne de caractères décrivant la propriété à ajouter.
2.
Type de l'objet, une des valeurs énumérées FcType
3.
Valeur, pas une FcValue, mais le type brut tel que passé à l'une des fonctions FcPatternAdd<type>. Doit correspondre au type du deuxième argument.

La liste des arguments est terminée par un nom d'objet nul, aucun type d'objet ni aucune valeur ne doit être passé pour cela. Les valeurs sont ajoutées à `pattern', si `pattern' est nul, un nouveau modèle est créé. Dans les deux cas, le modèle est retourné. Exemple

pattern = FcPatternBuild (0, FC_FAMILY, FcTypeString, "Times", (char *) 0);

FcPatternVaBuild est utilisée lorsque les arguments sont déjà sous la forme d'une valeur varargs. FcPatternVapBuild est une version macro de FcPatternVaBuild qui renvoie son résultat directement dans la variable result.
