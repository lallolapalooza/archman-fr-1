NOM

fceux-net-server - Serveur de jeu FCE Ultra

SYNTAXE

fceux-net-server [options]

DESCRIPTION

Cette page de manuel documente brièvement la commande fceux-net-server.

fceux-net-server est le serveur de jeu pour l'utilisation multijoueur de la famille d'émulateurs FCE Ultra NES. Ce serveur recherchera d'abord les options dans /etc/fceux-server.conf. Si ce fichier n'existe pas, il utilisera les valeurs par défaut données ici. Tout argument donné directement remplacera toute valeur par défaut.

OPTIONS

Ces programmes suivent la syntaxe habituelle de la ligne de commande GNU, avec des options longues commençant par deux tirets (`-'). Un résumé des options est inclus ci-dessous.

-h, --help
Affiche un message d'aide.
-v, --version
Affiche le numéro de version et quitte.
-p, --port
Démarre le serveur sur le port donné (par défaut = 4046).
-w, --password
Spécifie un mot de passe pour l'accès.
-m, --maxclients
Spécifie le nombre maximum de clients autorisés à accéder au serveur (par défaut = 100).
-t, --timeout
Spécifie le nombre de secondes avant que le serveur ne expire (par défaut = 5).
-f, --framedivisor
Spécifie le diviseur d'images, qui contrôle le nombre de mises à jour envoyées au client ; calculé comme suit : 60 / framedivisor = mises à jour par seconde (par défaut = 1).
-c, --configfile
Charge le fichier de configuration donné (par défaut = /etc/fceux-server.conf).
