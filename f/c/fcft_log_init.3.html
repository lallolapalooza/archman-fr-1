NOM

fcft_log_init - configurer la journalisation dans fcft

SYNTAXE

#include <fcft/fcft.h>

void fcft_log_init(

enum fcft_log_colorize colorize, bool do_syslog, enum fcft_log_class log_level);

DESCRIPTION

Par défaut, fcft ne journalise rien ; utilisez fcft_log_init() pour activer et configurer la journalisation dans fcft.

fcft_log_init() est généralement appelée tôt, au démarrage du programme.

colorize est l'une des valeurs suivantes :

enum fcft_log_colorize {
    FCFT_LOG_COLORIZE_NEVER,
    FCFT_LOG_COLORIZE_ALWAYS,
    FCFT_LOG_COLORIZE_AUTO
};

FCFT_LOG_COLORIZE_AUTO active les couleurs si stderr est un TTY.

Si do_syslog est défini, fcft journalisera vers syslog, en plus de la journalisation régulière sur stderr.

Notez que fcft n'appelle pas openlog(), même si do_syslog est défini. Faites-le depuis l'application appelante. Avant ou après avoir appelé fcft_log_init() n'a pas d'importance, tant que cela est fait avant d'appeler toute autre fonction API de fcft.

Enfin, log_level configure quels types de messages de journalisation seront affichés.

enum fcft_log_class {
    FCFT_LOG_CLASS_NONE,
    FCFT_LOG_CLASS_ERROR,
    FCFT_LOG_CLASS_WARNING,
    FCFT_LOG_CLASS_INFO,
    FCFT_LOG_CLASS_DEBUG
};

Notez qu'il ne s'agit pas d'un masque de bits ; définir FCFT_LOG_CLASS_INFO active également FCFT_LOG_CLASS_WARNING et FCFT_LOG_CLASS_ERROR.
