NOM

FcConfigFileInfoIterGet - Obtenir les informations sur le fichier de configuration

SYNTAXE

#include <fontconfig/fontconfig.h>

FcBool FcConfigFileInfoIterGet (FcConfig *config, FcConfigFileInfoIter *iter, FcChar8 **name, FcChar8 **description, FcBool *enabled);

DESCRIPTION

Obtenir le nom du fichier, la description et le drapeau indiquant s'il est activé ou non pour 'iter' où pointe les informations actuelles du fichier de configuration. Si l'itérateur est invalide, FcFalse est retourné.

Cette fonction n'est pas thread-safe. FcConfigReference doit être appelé avant d'utiliser FcConfigFileInfoIterInit et ensuite FcConfigDestroy lorsque les valeurs pertinentes ne sont plus référencées.
