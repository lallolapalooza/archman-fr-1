NOM

FcDirScan - analyser un répertoire de polices sans le mettre en cache

SYNTAXE

#include <fontconfig/fontconfig.h>

FcBool FcDirScan (FcFontSet *set, FcStrSet *dirs, FcFileCache *cache, FcBlanks *blanks, const FcChar8 *dir, FcBool force);

DESCRIPTION

Si cache est différent de zéro ou si force est FcFalse, cette fonction retourne actuellement FcFalse. Sinon, elle analyse un répertoire entier et ajoute toutes les polices trouvées à set. Tous les sous-répertoires trouvés sont ajoutés à dirs. L'appel de cette fonction ne crée aucun fichier de cache. Utilisez FcDirCacheRead() si la mise en cache est souhaitée.
