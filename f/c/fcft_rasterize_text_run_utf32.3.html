NOM

fcft_rasterize_text_run_utf32 - rastériser une série de glyphes pour une chaîne de caractères

SYNTAXE

#include <fcft/fcft.h>

struct fcft_text_run *fcft_rasterize_text_run_utf32(

struct fcft_font *font, size_t len, const uint32_t text[static len], enum fcft_subpixel subpixel);

DESCRIPTION

fcft_rasterize_text_run_utf32() met en forme et rastérise la chaîne Unicode encodée en UTF-32 text en une série de glyphes en utilisant la police primaire, et éventuellement une ou plusieurs polices de secours, dans font.

subpixel vous permet de spécifier le mode subpixel à utiliser. Voir fcft_rasterize_char_utf32() pour plus de détails.

La chaîne est d'abord segmentée en clusters de graphèmes en utilisant utf8proc. Chaque graphème se voit attribuer une police en utilisant les règles normales de recherche de police (voir fcft_rasterize_char_utf32()).

Ensuite, HarfBuzz est utilisé pour deviner le script (~langue) de chaque graphème. Les graphèmes consécutifs qui ont tous deux reçu la même police, et qui appartiennent au même script sont fusionnés en une "partielle" exécution de texte.

Finalement, chaque exécution de texte partielle est mise en forme avec HarfBuzz.

VALEUR RENVOYÉE

En cas d'erreur, NULL est renvoyé.

En cas de succès, un pointeur vers une exécution de texte allouée dynamiquement est renvoyé :

struct fcft_text_run {
    const struct fcft_glyph **glyphs;
    int *cluster;
    size_t count;
};

glyphs et cluster sont des tableaux avec count éléments. cluster contient les décalages de caractères (dans la chaîne d'origine) de chaque glyphe correspondant.

Notez que le membre cols des glyphes est invalide.

L'exécution de texte n'est pas mise en cache dans fcft. L'application appelante peut la mettre en cache aussi longtemps qu'elle le souhaite, y compris après la destruction de la police.

L'exécution de texte doit être libérée avec fcft_text_run_destroy().

VOIR AUSSI

fcft_text_run_destroy(), fcft_rasterize_char_utf32(), fcft_rasterize_grapheme_utf32()
