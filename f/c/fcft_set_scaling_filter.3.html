NOM

fcft_set_scaling_filter - configure le filtre à utiliser lors de la réduction d'échelle des polices bitmap

SYNTAXE

#include <fcft/fcft.h>

bool fcft_set_scaling_filter(enum fcft_scaling_filter filter);

DESCRIPTION

fcft_set_scaling_filter() configure le filtre à utiliser lors de la réduction d'échelle des polices bitmap (généralement les polices d'emoji). Le réglage affecte **toutes** les instances de polices.

Cette fonction ne **vide pas** les caches de glyphes et devrait par conséquent être appelée avant tout appel à fcft_codepoint_rasterize().

Les valeurs possibles pour filter sont :

  • FCFT_SCALING_FILTER_NONE
  • FCFT_SCALING_FILTER_NEAREST
  • FCFT_SCALING_FILTER_BILINEAR
  • FCFT_SCALING_FILTER_IMPULSE
  • FCFT_SCALING_FILTER_BOX
  • FCFT_SCALING_FILTER_LINEAR
  • FCFT_SCALING_FILTER_CUBIC
  • FCFT_SCALING_FILTER_GAUSSIAN
  • FCFT_SCALING_FILTER_LANCZOS2
  • FCFT_SCALING_FILTER_LANCZOS3
  • FCFT_SCALING_FILTER_LANCZOS3_STRETCHED

FCFT_SCALING_FILTER_NONE désactive le filtrage.

FCFT_SCALING_FILTER_NEAREST et FCFT_SCALING_FILTER_BILINEAR sont des filtres traditionnels, avec nearest étant le plus rapide.

Les autres sont des filtres de convolution séparables.

Si cette fonction n'est pas appelée, fcft utilise par défaut FCFT_SCALING_FILTER_CUBIC.

VALEUR DE RETOUR

En cas de succès, fcft_set_scaling_filter() retourne vrai. En cas d'erreur, faux est retourné.
