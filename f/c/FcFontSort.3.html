NOM

FcFontSort - Retourner la liste des polices correspondantes

SYNOPSIS

#include <fontconfig/fontconfig.h>

FcFontSet * FcFontSort (FcConfig *config, FcPattern *p, FcBool trim, FcCharSet **csp, FcResult *result);

DESCRIPTION

Retourne la liste des polices triées par proximité avec p. Si trim est FcTrue, les éléments de la liste qui n'incluent pas une couverture Unicode non fournie par des éléments précédents de la liste sont éludés. L'union de la couverture Unicode de toutes les polices est retournée dans csp, si csp n'est pas NULL. Cette fonction ne doit être appelée qu'après que FcConfigSubstitute et FcDefaultSubstitute aient été appelés pour p ; sinon les résultats ne seront pas corrects.

Le FcFontSet retourné référence des structures FcPattern qui peuvent être partagées par le résultat de plusieurs appels à FcFontSort, les applications ne doivent pas modifier ces motifs. Au lieu de cela, ils doivent être passés, avec p, à FcFontRenderPrepare qui les combine en un motif complet.

Le FcFontSet retourné par FcFontSort est détruit en appelant FcFontSetDestroy. Si config est NULL, la configuration actuelle est utilisée.
