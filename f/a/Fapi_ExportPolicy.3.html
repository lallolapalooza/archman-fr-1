TSS2_RC Fapi_ExportPolicy (FAPI_CONTEXT * context, char const * path, char ** jsonPolicy)

Fonction en un seul appel pour Fapi_ExportPolicy

Exporte une politique vers un tampon d'octets encodé en JSON.

Paramètres

context Le FAPI_CONTEXT
path Le chemin vers la politique à exporter
jsonPolicy La politique encodée en JSON. jsonPolicy NE DOIT PAS être NULL.

Valeurs de retour

TSS2_RC_SUCCESS si l'appel de fonction a réussi.
TSS2_FAPI_RC_BAD_REFERENCE si context, path ou jsonPolicy est NULL.
TSS2_FAPI_RC_BAD_CONTEXT si une corruption de contexte est détectée.
TSS2_FAPI_RC_BAD_PATH si le chemin ne correspond pas à une politique FAPI.
TSS2_FAPI_RC_BAD_SEQUENCE si le contexte a déjà une opération asynchrone en attente.
TSS2_FAPI_RC_IO_ERROR si les données ne peuvent pas être sauvegardées.
TSS2_FAPI_RC_MEMORY si la FAPI ne peut pas allouer suffisamment de mémoire pour les opérations internes ou les paramètres de retour.
TSS2_FAPI_RC_NO_TPM si la FAPI a été initialisée en mode sans TPM via son fichier de configuration.
TSS2_FAPI_RC_TRY_AGAIN si une opération d'E/S n'est pas encore terminée et que cette fonction doit être appelée à nouveau.
TSS2_FAPI_RC_GENERAL_FAILURE si une erreur interne s'est produite.
TSS2_FAPI_RC_BAD_VALUE si une valeur invalide a été passée à la fonction.
TSS2_FAPI_RC_PATH_NOT_FOUND si un chemin d'objet FAPI n'a pas été trouvé lors de l'autorisation.
TSS2_FAPI_RC_KEY_NOT_FOUND si une clé n'a pas été trouvée.
TSS2_ESYS_RC_* codes d'erreur possibles de l'ESAPI.
TSS2_FAPI_RC_NOT_PROVISIONED La FAPI n'a pas été provisionnée.

TSS2_RC Fapi_ExportPolicy_Finish (FAPI_CONTEXT * context, char ** jsonPolicy)

Fonction de fin asynchrone pour Fapi_ExportPolicy

Cette fonction doit être appelée après un appel précédent à Fapi_ExportPolicy_Async.

Paramètres

context Le FAPI_CONTEXT
jsonPolicy La politique encodée en JSON. jsonPolicy NE DOIT PAS être NULL.

Valeurs de retour

TSS2_RC_SUCCESS si l'appel de fonction a réussi.
TSS2_FAPI_RC_BAD_REFERENCE si context ou jsonPolicy est NULL.
TSS2_FAPI_RC_BAD_CONTEXT si une corruption de contexte est détectée.
TSS2_FAPI_RC_BAD_SEQUENCE si le contexte a déjà une opération asynchrone en attente.
TSS2_FAPI_RC_IO_ERROR si les données ne peuvent pas être sauvegardées.
TSS2_FAPI_RC_MEMORY si la FAPI ne peut pas allouer suffisamment de mémoire pour les opérations internes ou les paramètres de retour.
TSS2_FAPI_RC_TRY_AGAIN si l'opération asynchrone n'est pas encore terminée. Appelez à nouveau cette fonction plus tard.
TSS2_FAPI_RC_BAD_PATH si un chemin est utilisé dans un contexte inapproprié ou contient des caractères illégaux.
TSS2_FAPI_RC_GENERAL_FAILURE si une erreur interne s'est produite.
TSS2_FAPI_RC_BAD_VALUE si une valeur invalide a été passée à la fonction.
TSS2_FAPI_RC_PATH_NOT_FOUND si un chemin d'objet FAPI n'a pas été trouvé lors de l'autorisation.
TSS2_FAPI_RC_KEY_NOT_FOUND si une clé n'a pas été trouvée.
