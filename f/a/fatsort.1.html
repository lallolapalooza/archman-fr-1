FATSORT(1) Commandes utilisateur FATSORT(1)

NOM

fatsort - outil de tri pour FAT

SYNTAXE

fatsort [OPTIONS] PÉRIPH

DESCRIPTION

FATSort trie les structures de répertoires des systèmes de fichiers FAT (FAT12, FAT16, FAT32 et exFAT). De nombreux lecteurs MP3 ne trient pas les fichiers automatiquement mais les lisent dans l'ordre où ils ont été transférés sur le périphérique. FATSort peut aider ici.

Options de tri :

-a
Utiliser l'ordre ASCIIbetique pour le tri.
-c
Ignorer la casse des noms de fichiers (par défaut pour la plupart des locales)
-I PRÉFIXE
Ignorer le PRÉFIXE du nom de fichier.
-n
Tri par ordre naturel.

-o ORDRE L'ordre de tri des fichiers où ORDRE est l'un des suivants :

d : répertoires d'abord (par défaut)
f : fichiers d'abord
a : les fichiers et les répertoires ne sont pas différenciés
-r
Trier dans l'ordre inverse.
-R
Trier dans l'ordre aléatoire.
Ces options rendent toutes les autres options de tri obsolètes.
-t
Trier par date et heure de dernière modification.

Les options suivantes peuvent être spécifiées plusieurs fois pour sélectionner quels répertoires doivent être triés :

-d DIR
Trier uniquement le répertoire DIR.
-D DIR
Trier le répertoire DIR et tous ses sous-répertoires.
-x DIR
Ne pas trier le répertoire DIR.
-X DIR
Ne pas trier le répertoire DIR et ses sous-répertoires.

Les options suivantes peuvent être spécifiées plusieurs fois pour sélectionner quels répertoires doivent être triés en utilisant les expressions régulières étendues POSIX.2 :

-e RE
Ne trier que les répertoires qui correspondent à l'expression régulière RE.
-E RE
Ne pas trier les répertoires qui correspondent à l'expression régulière RE.

Cependant, les options -e et -E ne peuvent pas être utilisées simultanément avec les options -d, -D, -x et -X.

-L LOC
Utiliser la locale LOC au lieu de la locale des variables d'environnement.

Plus d'options :

-l
Afficher uniquement l'ordre actuel des fichiers.
-i
Afficher uniquement les informations du système de fichiers.
-f
Forcer le tri même si le système de fichiers est monté.

-h, --help

Afficher une aide.

-v, --version

Afficher les informations de version.
-q
Être silencieux.

PÉRIPH doit être un système de fichiers FAT12, FAT16, FAT32 ou exFAT.

ATTENTION : LE SYSTÈME DE FICHIERS DOIT ÊTRE COHÉRENT (PAS D'ERREURS DE SYSTÈME DE FICHIERS). VEUILLEZ SAUVEGARDER VOS DONNÉES AVANT D'UTILISER FATSORT. RISQUE DE CORRUPTION DU SYSTÈME DE FICHIERS ! L'UTILISATEUR DE FATSORT ASSUME TOUT RISQUE. FATSORT NE POURRA ÊTRE TENU RESPONSABLE DE LA PERTE DE DONNÉES !

EXEMPLES

fatsort /dev/sda
Trier /dev/sda.
fatsort -n /dev/sdb1
Trier /dev/sdb1 en ordre naturel.
