TSS2_RC Fapi_SetDescription (FAPI_CONTEXT * context, char const * path, char const * description)

Fonction en un seul appel pour Fapi_SetDescription

Associe une description lisible par l'homme à un objet dans le magasin de métadonnées.

Paramètres

context Le FAPI_CONTEXT
path Le chemin de l'objet dans le magasin de métadonnées
description La description associée à l'objet. Peut être NULL

Valeurs de retour

TSS2_RC_SUCCESS si l'appel de fonction a réussi.
TSS2_FAPI_RC_BAD_REFERENCE si context ou path est NULL.
TSS2_FAPI_RC_BAD_CONTEXT si une corruption du contexte est détectée.
TSS2_FAPI_RC_BAD_PATH si le chemin ne correspond à aucune entité FAPI.
TSS2_FAPI_RC_BAD_SEQUENCE si le contexte a déjà une opération asynchrone en attente.
TSS2_FAPI_RC_IO_ERROR si les données ne peuvent pas être enregistrées.
TSS2_FAPI_RC_MEMORY si FAPI ne peut pas allouer suffisamment de mémoire pour les opérations internes ou les paramètres de retour.
TSS2_FAPI_RC_BAD_VALUE si une valeur invalide a été passée à la fonction.
TSS2_FAPI_RC_PATH_NOT_FOUND si un chemin d'objet FAPI n'a pas été trouvé pendant l'autorisation.
TSS2_FAPI_RC_KEY_NOT_FOUND si une clé n'a pas été trouvée.
TSS2_FAPI_RC_TRY_AGAIN si une opération d'E/S n'est pas encore terminée et que cette fonction doit être appelée à nouveau.
TSS2_FAPI_RC_GENERAL_FAILURE si une erreur interne s'est produite.
TSS2_FAPI_RC_NOT_PROVISIONED FAPI n'a pas été provisionné.

TSS2_RC Fapi_SetDescription_Async (FAPI_CONTEXT * context, char const * path, char const * description)

Fonction asynchrone pour Fapi_SetDescription

TSS2_FAPI_RC_BAD_REFERENCE si context ou path est NULL.
TSS2_FAPI_RC_BAD_CONTEXT si une corruption du contexte est détectée.
TSS2_FAPI_RC_BAD_PATH si le chemin ne correspond à aucune entité FAPI.
TSS2_FAPI_RC_BAD_SEQUENCE si le contexte a déjà une opération asynchrone en attente.
TSS2_FAPI_RC_IO_ERROR si les données ne peuvent pas être enregistrées.
TSS2_FAPI_RC_MEMORY si FAPI ne peut pas allouer suffisamment de mémoire pour les opérations internes ou les paramètres de retour.
TSS2_FAPI_RC_BAD_VALUE si une valeur invalide a été passée à la fonction.
TSS2_FAPI_RC_PATH_NOT_FOUND si un chemin d'objet FAPI n'a pas été trouvé pendant l'autorisation.
TSS2_FAPI_RC_KEY_NOT_FOUND si une clé n'a pas été trouvée.
TSS2_FAPI_RC_NOT_PROVISIONED FAPI n'a pas été provisionné.

TSS2_RC Fapi_SetDescription_Finish (FAPI_CONTEXT * context)

Fonction de fin asynchrone pour Fapi_SetDescription

Cette fonction doit être appelée après un appel précédent à Fapi_SetDescription_Async.

Paramètres

context Le FAPI_CONTEXT

Valeurs de retour

TSS2_RC_SUCCESS si l'appel de fonction a réussi.
TSS2_FAPI_RC_BAD_REFERENCE si context est NULL.
TSS2_FAPI_RC_BAD_CONTEXT si une corruption du contexte est détectée.
TSS2_FAPI_RC_BAD_SEQUENCE si le contexte a déjà une opération asynchrone en attente.
TSS2_FAPI_RC_IO_ERROR si les données ne peuvent pas être enregistrées.
TSS2_FAPI_RC_MEMORY si FAPI ne peut pas allouer suffisamment de mémoire pour les opérations internes ou les paramètres de retour.
TSS2_FAPI_RC_PATH_NOT_FOUND Si aucun fichier n'est trouvé après l'expansion du nom de chemin.
TSS2_FAPI_RC_TRY_AGAIN si l'opération asynchrone n'est pas encore terminée. Appelez cette fonction à nouveau plus tard.
TSS2_FAPI_RC_GENERAL_FAILURE si une erreur interne s'est produite.
TSS2_FAPI_RC_BAD_VALUE si une valeur invalide a été passée à la fonction.
TSS2_FAPI_RC_BAD_PATH si le chemin est utilisé dans un contexte inapproprié ou contient des caractères illégaux.
