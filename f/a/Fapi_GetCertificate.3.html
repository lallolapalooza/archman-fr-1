TSS2_RC Fapi_GetCertificate (FAPI_CONTEXT * context, char const * path, char ** x509certData)

Fonction en un seul appel pour Fapi_GetCertificate

Obtient un certificat x.509 pour la clé à un chemin donné.

Paramètres

context Le FAPI_CONTEXT
path Le chemin vers la clé dont le certificat est créé
x509certData Le certificat encodé en PEM

Valeurs de retour

TSS2_RC_SUCCESS si l'appel de fonction a réussi.
TSS2_FAPI_RC_BAD_REFERENCE si context, path ou x509CertData est NULL.
TSS2_FAPI_RC_BAD_CONTEXT si une corruption de contexte est détectée.
TSS2_FAPI_RC_PATH_NOT_FOUND si le chemin ne correspond à aucune entité FAPI.
TSS2_FAPI_RC_BAD_KEY si la clé n'est pas appropriée pour l'opération demandée.
TSS2_FAPI_RC_NO_CERTIFICATE s'il n'y a pas de certificat x.509 associé au chemin de la clé.
TSS2_FAPI_RC_BAD_SEQUENCE si le contexte a déjà une opération asynchrone en attente.
TSS2_FAPI_RC_IO_ERROR si les données ne peuvent pas être sauvegardées.
TSS2_FAPI_RC_MEMORY si le FAPI ne peut pas allouer suffisamment de mémoire pour les opérations internes ou les paramètres de retour.
TSS2_FAPI_RC_KEY_NOT_FOUND si une clé n'a pas été trouvée.
TSS2_FAPI_RC_BAD_VALUE si une valeur invalide a été passée à la fonction.
TSS2_FAPI_RC_TRY_AGAIN si une opération d'E/S n'est pas encore terminée et que cette fonction doit être appelée à nouveau.
TSS2_FAPI_RC_GENERAL_FAILURE si une erreur interne s'est produite.
TSS2_FAPI_RC_NOT_PROVISIONED FAPI n'a pas été provisionné.
TSS2_FAPI_RC_BAD_PATH si le chemin est utilisé dans un contexte inapproprié ou contient des caractères illégaux.

TSS2_RC Fapi_GetCertificate_Finish (FAPI_CONTEXT * context, char ** x509certData)

Fonction asynchrone de fin pour Fapi_GetCertificate

Cette fonction doit être appelée après un appel précédent à Fapi_GetCertificate_Async.

Paramètres

x509certData Le certificat encodé en PEM

Valeurs de retour

TSS2_RC_SUCCESS si l'appel de fonction a réussi.
TSS2_FAPI_RC_BAD_REFERENCE si context ou x509certData est NULL.
TSS2_FAPI_RC_BAD_CONTEXT si une corruption de contexte est détectée.
TSS2_FAPI_RC_BAD_SEQUENCE si le contexte a déjà une opération asynchrone en attente.
TSS2_FAPI_RC_IO_ERROR si les données ne peuvent pas être sauvegardées.

TSS2_FAPI_RC_TRY_AGAIN si l'opération asynchrone n'est pas encore terminée. Appelez à nouveau cette fonction plus tard.
