TSS2_RC Fapi_Initialize (FAPI_CONTEXT ** context, char const * uri)

Fonction en un seul appel pour Fapi_Initialize

Initialise un FAPI_CONTEXT qui contient toutes les informations d'état et de métadonnées lors d'une interaction avec le TPM.

Paramètres

context Le FAPI_CONTEXT
uri Inutilisé dans cette version de la FAPI. Doit être NULL

Valeurs de retour

TSS2_RC_SUCCESS si l'appel de fonction a réussi.
TSS2_FAPI_RC_BAD_REFERENCE si context est NULL.
TSS2_FAPI_RC_BAD_VALUE si uri n'est pas NULL.
TSS2_FAPI_RC_IO_ERROR si les données ne peuvent pas être sauvegardées.
TSS2_FAPI_RC_MEMORY si la FAPI ne parvient pas à allouer suffisamment de mémoire pour les opérations internes ou les paramètres de retour.
TSS2_FAPI_RC_TRY_AGAIN si une opération d'E/S n'est pas encore terminée et que cette fonction doit être appelée à nouveau.
TSS2_FAPI_RC_BAD_SEQUENCE si le contexte a déjà une opération asynchrone en attente.
TSS2_FAPI_RC_GENERAL_FAILURE si une erreur interne s'est produite.
TSS2_FAPI_RC_BAD_PATH si un chemin est utilisé dans un contexte inapproprié ou contient des caractères illégaux.
TSS2_ESYS_RC_* codes d'erreur possibles de l'ESAPI.

TSS2_RC Fapi_Initialize_Async (FAPI_CONTEXT ** context, char const * uri)

Fonction asynchrone pour Fapi_Initialize

Initialise un FAPI_CONTEXT qui contient toutes les informations d'état et de métadonnées lors d'une interaction avec le TPM.

Appelez Fapi_Initialize pour terminer l'exécution de cette commande.

Paramètres

context Le FAPI_CONTEXT
uri Inutilisé dans cette version de la FAPI. Doit être NULL

Valeurs de retour

TSS2_RC_SUCCESS si l'appel de fonction a réussi.
TSS2_FAPI_RC_BAD_REFERENCE si context est NULL.
TSS2_FAPI_RC_BAD_VALUE si uri n'est pas NULL.
TSS2_FAPI_RC_IO_ERROR si les données ne peuvent pas être sauvegardées.
TSS2_FAPI_RC_MEMORY si la FAPI ne parvient pas à allouer suffisamment de mémoire pour les opérations internes ou les paramètres de retour.

TSS2_RC Fapi_Initialize_Finish (FAPI_CONTEXT ** context)

Fonction de fin asynchrone pour Fapi_Initialize

Cette fonction doit être appelée après un précédent Fapi_Initialize_Async.

Paramètres

context Le FAPI_CONTEXT

Valeurs de retour

TSS2_RC_SUCCESS si l'appel de fonction a réussi.
TSS2_FAPI_RC_BAD_REFERENCE si context est NULL.
TSS2_FAPI_RC_BAD_CONTEXT si une corruption du contexte est détectée.
TSS2_FAPI_RC_BAD_SEQUENCE si le contexte a déjà une opération asynchrone en attente.
TSS2_FAPI_RC_IO_ERROR si les données ne peuvent pas être sauvegardées.
TSS2_FAPI_RC_MEMORY si la FAPI ne parvient pas à allouer suffisamment de mémoire pour les opérations internes ou les paramètres de retour.
TSS2_FAPI_RC_TRY_AGAIN si l'opération asynchrone n'est pas encore terminée. Appelez à nouveau cette fonction plus tard.
TSS2_FAPI_RC_BAD_VALUE si une valeur invalide a été passée à la fonction.
TSS2_FAPI_RC_GENERAL_FAILURE si une erreur interne s'est produite.
TSS2_FAPI_RC_BAD_PATH si un chemin est utilisé dans un contexte inapproprié ou contient des caractères illégaux.
TSS2_ESYS_RC_* codes d'erreur possibles de l'ESAPI.
