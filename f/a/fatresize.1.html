FATRESIZE(1) Manuel des commandes générales FATRESIZE(1)

NOM

fatresize — Redimensionner un volume FAT16/FAT32 non destructivement

SYNOPSIS

fatresize [-s TAILLE] [périphérique]

DESCRIPTION

Cette page de manuel documente brièvement fatresize

Cette page de manuel a été écrite pour la distribution Debian car le programme original n'a pas de page de manuel.

OPTIONS

Ces programmes suivent la syntaxe habituelle des lignes de commande GNU, avec des options longues commençant par deux tirets (`-'). Un résumé des options est inclus ci-dessous. Pour une description complète, consultez les fichiers Info.

-h --help
Afficher le résumé des options.
-s --size
Redimensionner le volume à TAILLE[k|M|G|ki|Mi|Gi] octets ou "max"
-i --info
Afficher les informations du volume
-p --progress
Afficher la progression
-q --quiet
Être silencieux
-v --verbose
Verbeux (pas la version)

EXEMPLES

fatresize -s 2G /dev/evms/hdb2

fatresize -q -s max /dev/hde6

fatresize -i /dev/hdg3

La taille et le périphérique sont requis pour l'exécution. Vous pouvez redimensionner des partitions mappées par périphérique, par exemple des partitions EVMS.

BOGUES

Vous ne pouvez pas redimensionner une partition FAT32 à moins de 512 Mo car Windows(R) ne fonctionne pas correctement avec un petit système de fichiers FAT32. Utilisez FAT16.
