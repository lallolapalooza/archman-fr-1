Fonction à appel unique pour Fapi_GetTpmBlobs

Obtenir les blobs public et privé d'un objet TPM. Ils peuvent être chargés avec une API de niveau inférieur telle que la SAPI ou l'ESAPI.

Paramètres

context Le FAPI_CONTEXT
path Le chemin vers la clé pour laquelle les blobs seront renvoyés
tpm2bPublic La zone publique renvoyée de l'objet. Peut être NULL
tpm2bPublicSize La taille de tpm2bPublic en octets. Peut être NULL
tpm2bPrivate La zone privée renvoyée de l'objet. Peut être NULL
tpm2bPrivateSize La taille de tpm2bPrivate en octets. Peut être NULL
policy La politique associée à l'objet, encodée en JSON. Peut être NULL

Valeurs de retour

TSS2_RC_SUCCESS si l'appel de fonction a été un succès.
TSS2_FAPI_RC_BAD_REFERENCE si context ou path est NULL.
TSS2_FAPI_RC_BAD_CONTEXT si une corruption du contexte est détectée.
TSS2_FAPI_RC_BAD_PATH si path ne correspond pas à une entité FAPI.
TSS2_FAPI_RC_BAD_SEQUENCE si le contexte a déjà une opération asynchrone en attente.
TSS2_FAPI_RC_IO_ERROR si les données ne peuvent pas être sauvegardées.
TSS2_FAPI_RC_MEMORY si la FAPI ne peut pas allouer assez de mémoire pour les opérations internes ou les paramètres de retour.
TSS2_FAPI_RC_PATH_NOT_FOUND si un chemin d'objet FAPI n'a pas été trouvé pendant l'autorisation.
TSS2_FAPI_RC_KEY_NOT_FOUND si une clé n'a pas été trouvée.
TSS2_FAPI_RC_BAD_VALUE si une valeur invalide a été passée à la fonction.
TSS2_FAPI_RC_TRY_AGAIN si une opération d'E/S n'est pas encore terminée et que cette fonction doit être rappelée.
TSS2_FAPI_RC_GENERAL_FAILURE si une erreur interne s'est produite.
TSS2_FAPI_RC_NOT_PROVISIONED La FAPI n'a pas été provisionnée.
