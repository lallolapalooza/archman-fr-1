FASTFETCH(1) Manuel des commandes générales FASTFETCH(1)

NOM

fastfetch - un outil d'information système rapide et personnalisable similaire à neofetch

SYNTAXE

fastfetch [options...]

DESCRIPTION

Fastfetch est un outil pour afficher les informations système de manière visuellement attrayante. Principalement écrit en C, il met l'accent sur les performances et la personnalisation tout en offrant des fonctionnalités similaires à neofetch. Il prend en charge Linux, Android, *BSD, macOS, Haiku et Windows 7 ou plus récent.

STATUT DE SORTIE

Fastfetch retourne zéro en cas d'exécution réussie. Toute erreur entraîne un code de sortie non nul.

OPTIONS

Options Informatifs

-h, --help [commande]
Affiche les informations d'aide pour toutes les options disponibles ou pour une commande spécifique
-v, --version
Affiche la version de fastfetch
--version-raw
Affiche la chaîne de version brute (majeur.mineur.correctif)
--list-config-paths
Liste les chemins de recherche des fichiers de configuration
--list-data-paths
Liste les chemins de recherche des préréglages et des logos
--list-logos
Liste les logos disponibles pouvant être chargés avec --logo
--list-modules
Liste tous les modules disponibles
--list-presets
Liste les préréglages disponibles pouvant être chargés avec --config
--list-features
Liste les fonctionnalités avec lesquelles fastfetch a été compilé (principalement pour le développement)
--print-logos
Affiche tous les logos disponibles
--print-structure
Affiche la structure par défaut
--format <type>
Définit le format de sortie. Options disponibles :
  • default : Format lisible par l'homme par défaut
  • json : Format JSON pour le traitement par machine

Options de Configuration

-c, --config <config>
Utilise le fichier de configuration ou le préréglage spécifié. Spécifiez none pour désactiver le chargement ultérieur de la configuration. Voir la section CONFIGURATION pour plus de détails sur les fichiers de configuration.
--gen-config [chemin]
Génère un fichier de configuration avec les options spécifiées en ligne de commande. Si chemin n'est pas spécifié, il utilise par défaut ~/.config/fastfetch/config.jsonc. Si chemin est « - », la configuration sera écrite sur la sortie standard.
--gen-config-force [chemin]
Identique à --gen-config, mais écrase tout fichier existant au chemin de destination.

Options de Logo

-l, --logo <logo>
Définit le logo à afficher. Peut être le nom d'un logo intégré ou le chemin d'un fichier image. Utilisez none pour désactiver le logo.
--logo-type <type>
Définit le type du logo spécifié avec --logo. Les types disponibles incluent auto, builtin, file, sixel, kitty, et d'autres. Voir --help logo-type pour plus de détails.
--logo-width <largeur>
Définit la largeur du logo en caractères (pour les logos image)
--logo-height <hauteur>
Définit la hauteur du logo en caractères (pour les logos image)
--logo-color-[1-9] <couleur>
Remplace des couleurs spécifiques dans le logo

Options d'Affichage

-s, --structure <structure>
Définit la structure du fetch (une liste de noms de modules séparés par des deux-points :)
--color <couleur>
Définit la couleur des clés et du titre. Voir --help color pour les couleurs disponibles.
--color-keys <couleur>
Définit la couleur des clés uniquement
--color-title <couleur>
Définit la couleur du titre uniquement
--separator <chaîne>
Définit le séparateur entre la clé et la valeur (par défaut : « : »)
--key-width <num>
Aligne la largeur des clés sur <num> caractères
--show-errors
Affiche les erreurs lorsqu'elles se produisent (par défaut : false)
--pipe
Désactive les couleurs (détecté automatiquement selon que la sortie standard est un terminal)

Pour lister toutes les options disponibles, y compris les options spécifiques aux modules, utilisez --help.

CONFIGURATION

Structure du Fetch

La structure définit quels modules afficher et dans quel ordre. Elle est composée de noms de modules séparés par des deux-points (:). Par exemple : title:separator:os:kernel:uptime

Pour lister tous les modules disponibles, utilisez --list-modules

Fichiers de Configuration

Fastfetch utilise JSONC pour les fichiers de configuration. JSONC est du JSON avec la prise en charge des commentaires (// et /* */). Les fichiers de configuration doivent avoir l'extension .jsonc.

Vous pouvez générer un fichier de configuration par défaut en utilisant --gen-config. Par défaut, le fichier de configuration est enregistré à l'emplacement ~/.config/fastfetch/config.jsonc.

Les fichiers de configuration/préréglages sont recherchés dans les emplacements suivants (dans l'ordre) :

1.
Par rapport au répertoire de travail actuel
2.
Par rapport à ~/.local/share/fastfetch/presets/
3.
Par rapport à /usr/share/fastfetch/presets/

Pour des informations détaillées sur les options de logo, la configuration des modules et le formatage, visitez :

https://github.com/fastfetch-cli/fastfetch/wiki/Configuration

Fastfetch fournit plusieurs préréglages intégrés. Listez-les avec --list-presets.

Schéma JSON

Un schéma JSON est disponible pour l'intelligence de l'éditeur lors de l'édition du fichier de configuration. Ajoutez la ligne suivante au début de votre fichier de configuration :

"$schema": "https://github.com/fastfetch-cli/fastfetch/raw/dev/doc/json_schema.json"

EXEMPLES

Utilisation basique :
fastfetch
Utiliser un logo spécifique :
fastfetch --logo arch
Structure personnalisée :
fastfetch --structure title:os:kernel:uptime:memory
Générer un fichier de configuration :
fastfetch --gen-config
Utiliser un préréglage :
fastfetch --config neofetch
