TSS2_RC Fapi_GetInfo (FAPI_CONTEXT * context, char ** info)

Fonction en un seul appel pour Fapi_GetInfo

Retourne une chaîne encodée en UTF-8 qui identifie les versions de FAPI, TPM, les configurations et d'autres informations pertinentes.

Paramètres

context Le FAPI_CONTEXT
info Le tampon d'octets pour la chaîne d'informations

Valeurs de retour

TSS2_RC_SUCCESS si l'appel de fonction a réussi.
TSS2_FAPI_RC_BAD_REFERENCE si context ou info est NULL.
TSS2_FAPI_RC_BAD_CONTEXT si une corruption du contexte est détectée.
TSS2_FAPI_RC_BAD_SEQUENCE si le contexte a déjà une opération asynchrone en attente.
TSS2_FAPI_RC_IO_ERROR si les données ne peuvent pas être sauvegardées.
TSS2_FAPI_RC_MEMORY si FAPI ne peut pas allouer suffisamment de mémoire pour les opérations internes ou les paramètres de retour.
TSS2_FAPI_RC_NO_TPM si FAPI a été initialisé en mode sans TPM via son fichier de configuration.
TSS2_FAPI_RC_TRY_AGAIN si une opération d'E/S n'est pas encore terminée et que cette fonction doit être appelée à nouveau.
TSS2_FAPI_RC_GENERAL_FAILURE si une erreur interne s'est produite.
TSS2_FAPI_RC_BAD_VALUE si une valeur invalide a été passée à la fonction.
TSS2_ESYS_RC_* codes d'erreur possibles de ESAPI.

TSS2_RC Fapi_GetInfo_Async (FAPI_CONTEXT * context)

Fonction asynchrone pour Fapi_GetInfo

Retourne une chaîne encodée en UTF-8 qui identifie les versions de FAPI, TPM, les configurations et d'autres informations pertinentes.

Appelez Fapi_GetInfo_Finish pour terminer l'exécution de cette commande.

Paramètres

context Le FAPI_CONTEXT

Valeurs de retour

TSS2_RC_SUCCESS si l'appel de fonction a réussi.
TSS2_FAPI_RC_BAD_REFERENCE si context est NULL.
TSS2_FAPI_RC_BAD_CONTEXT si une corruption du contexte est détectée.
TSS2_FAPI_RC_BAD_SEQUENCE si le contexte a déjà une opération asynchrone en attente.
TSS2_FAPI_RC_IO_ERROR si les données ne peuvent pas être sauvegardées.
TSS2_FAPI_RC_MEMORY si FAPI ne peut pas allouer suffisamment de mémoire pour les opérations internes ou les paramètres de retour.
TSS2_FAPI_RC_NO_TPM si FAPI a été initialisé en mode sans TPM via son fichier de configuration.

TSS2_RC Fapi_GetInfo_Finish (FAPI_CONTEXT * context, char ** info)

Fonction asynchrone de fin pour Fapi_GetInfo

Cette fonction doit être appelée après un appel précédent à Fapi_GetInfo_Async.

Paramètres

context Le FAPI_CONTEXT
info Le tampon d'octets pour la chaîne d'informations

Valeurs de retour

TSS2_RC_SUCCESS si l'appel de fonction a réussi.
TSS2_FAPI_RC_BAD_REFERENCE si context ou info est NULL.
TSS2_FAPI_RC_BAD_CONTEXT si une corruption du contexte est détectée.
TSS2_FAPI_RC_BAD_SEQUENCE si le contexte a déjà une opération asynchrone en attente.
TSS2_FAPI_RC_IO_ERROR si les données ne peuvent pas être sauvegardées.
TSS2_FAPI_RC_MEMORY si FAPI ne peut pas allouer suffisamment de mémoire pour les opérations internes ou les paramètres de retour.
TSS2_FAPI_RC_TRY_AGAIN si l'opération asynchrone n'est pas encore terminée. Appelez à nouveau cette fonction plus tard.
TSS2_FAPI_RC_GENERAL_FAILURE si une erreur interne s'est produite.
TSS2_FAPI_RC_BAD_VALUE si une valeur invalide a été passée à la fonction.
