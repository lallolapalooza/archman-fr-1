NOM

FascistCheck - une bibliothèque de vérification proactive de mots de passe

SYNTAXE

#include <crack.h>

static char const CRACKLIB_DICTPATH[] =  ...;

extern char const *
FascistCheck(char const passwd[], char const dictpath[]);

DESCRIPTION

cracklib est une bibliothèque contenant la fonction C FascistCheck qui peut être utilisée dans un programme de type « passwd ». L'idée est simple : essayer d'empêcher les utilisateurs de choisir des mots de passe qui pourraient être devinés par « crack » en les filtrant à la source. cracklib est une ramification de la version 5 du logiciel « crack » et contient un nombre considérable d'idées volées au nouveau logiciel.

Le premier argument formel password est le mot de passe potentiel. Le second argument formel dictpath est le chemin complet + le préfixe du nom de fichier de la base de données du dictionnaire cracklib. FascistCheck renvoie le pointeur NULL pour un bon mot de passe, ou un pointeur vers une chaîne diagnostique s'il s'agit d'un mot de passe faible.

La base de données est dans un format binaire généré par les utilitaires crack_mkdict(8) et crack_packer(8). Sur un système Debian, la base de données se trouve dans le répertoire défini par la constante statique CRACKLIB_DICTPATH et est définie sur /var/cache/cracklib/cracklib_dict. Aucune des sous-routines des bibliothèques cracklib n'a cet emplacement codé en dur dans leurs implémentations. Il est généré quotidiennement avec le programme /etc/cron.daily/cracklib.

FICHIERS

/var/cache/cracklib/cracklib_dict.[hwm|pwd|pwi]
Fichiers de la base de données du dictionnaire cracklib utilisés par les utilitaires.
/etc/cron.daily/cracklib
Programme cron quotidien de cracklib pour reconstruire la base de données du dictionnaire cracklib.
/etc/cracklib/cracklib.conf
Fichier de configuration de cracklib utilisé par le programme cron quotidien de cracklib pour reconstruire la base de données du dictionnaire cracklib.
/usr/sbin/crack_mkdict
Script shell de cracklib pour créer la liste initiale de mots pour la base de données du dictionnaire.
/usr/share/doc/cracklib2-dev/examples
Exemples de fichiers source cc(1) qui montrent comment FascistCheck est utilisé.
