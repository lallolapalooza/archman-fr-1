Étant donné un ensemble de PCRs et une clé de signature restreinte, elle signera ces PCRs et renverra la

citation.

s

qualifyingData Un nonce fourni par l'appelant. Peut être NULL
qualifyingDataSize La taille de qualifyingData en octets. Doit être 0 si qualifyingData est NULL
quoteInfo Une structure encodée en JSON contenant les entrées de l'opération de citation
signature La signature des PCRs
signatureSize La taille de la signature en octets. Peut être NULL
pcrLog Le journal du PCR. Peut être NULL
certificate Le certificat associé à la clé de signature. Peut être
NULL

qualifyingDataSize La taille de qualifyingData en octets. Doit être 0 si qualifyingData est
NULL
