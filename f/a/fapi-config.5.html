fapi-config(5) Manuel des formats de fichier fapi-config(5)

VOIR AUSSI

fapi-profile(5)

DESCRIPTION

Fichier de configuration FAPI

Les paramètres FAPI qui peuvent être ajustés via le fichier de configuration sont les suivants :

•
profile_name : Nom du profil cryptographique par défaut choisi dans le répertoire profile_dir.
•
profile_dir : Répertoire contenant tous les profils cryptographiques connus de FAPI.
•
user_dir : Répertoire où sont stockés les objets utilisateur.
•
system_dir : Répertoire où sont stockés les objets système, les politiques et les objets importés.
•
tcti : L'interface TCTI qui sera utilisée.
•
system_pcrs : Les registres PCR utilisés par le système.
•
log_dir : Le répertoire pour le journal des événements.
•
ek_cert_less : Un commutateur pour désactiver la vérification du certificat (optionnel).
•
ek_fingerprint : L'empreinte de la clé d'endossement (optionnel).

Si elle n'est pas spécifiée autrement lors de l'installation de TSS, l'emplacement par défaut pour les profils exemplaires est /etc/tpm2-tss/profiles/ et /etc/tpm2-tss/ pour le fichier de configuration FAPI. La variable d'environnement TSS2_FAPICONF peut être utilisée pour définir un chemin d'accès alternatif pour le fichier de configuration FAPI. Si les fichiers de mesure système (IMA et bios) n'existent pas, /dev/null sera utilisé pour firmware_log_file et ima_log_file.

EXEMPLES

Le fichier de configuration FAPI est encodé en JSON :

{
     "profile_name": "P_ECCP256SHA256",
     "profile_dir": "/etc/tpm2-tss/fapi-profiles/",
     "user_dir": "~/.local/share/tpm2-tss/user/keystore/",
     "system_dir": "/home/myhome/keystore/system/keystore",
     "tcti": "",
     "system_pcrs" : [0, 1, 2, 3, 4, 5, 6, 7],
     "log_dir" : "/home/myhome/eventlog/",
     "firmware_log_file" : "/sys/kernel/security/tpm0/binary_bios_measurements",
      "ima_log_file" : "/sys/kernel/security/ima/binary_runtime_measurements"
}

Pour cet exemple, le TCTI par défaut du système sera utilisé. Les certificats pour les clés d'endossement stockées seront vérifiés. Si la vérification des certificats n'est pas nécessaire, l'option :

"ek_cert_less": "yes" peut être ajoutée au fichier de configuration. Alternativement à la vérification standard des certificats, une empreinte (hash de la clé publique) pour la clé d'endossement stockée peut être définie dans le fichier de configuration :

"ek_fingerprint":  {     "hashAlg" : "sha256",     "digest" : "9e56...214d"     }
