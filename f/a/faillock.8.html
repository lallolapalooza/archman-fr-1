NOM

faillock - Outil d'affichage et de modification des fichiers d'enregistrements d'échecs d'authentification

SYNTAXE

faillock [--dir /chemin/vers/repertoire-comptage] [--user nom_utilisateur] [--reset]

DESCRIPTION

Le module pam_faillock.so maintient une liste des tentatives d'authentification échouées par utilisateur pendant un intervalle spécifié et verrouille le compte en cas de plus de deny tentatives échouées consécutives. Il stocke les enregistrements d'échecs dans des fichiers par utilisateur dans le répertoire de comptage.

La commande faillock est une application qui peut être utilisée pour examiner et modifier le contenu des fichiers de comptage. Elle peut afficher les tentatives récentes d'authentification échouées de l’nom_utilisateur ou effacer les fichiers de comptage de tous les noms_utilisateurs ou d'utilisateurs individuels.

OPTIONS

--conf /chemin/vers/fichier-configuration

Le fichier où se trouve la configuration. Le défaut est /etc/security/faillock.conf.

--dir /chemin/vers/repertoire-comptage

Le répertoire où sont conservés les fichiers utilisateur avec les enregistrements d'échecs.

La priorité pour définir cette option est d'utiliser la valeur fournie depuis la ligne de commande. Si elle n'est pas fournie, alors la valeur du fichier de configuration est utilisée. Enfin, si aucune n'a été fournie, alors /var/run/faillock est utilisé.

--user nom_utilisateur

L'utilisateur dont les enregistrements d'échecs doivent être affichés ou effacés.

--reset

Au lieu d'afficher les enregistrements d'échecs de l'utilisateur, les effacer.

FICHIERS

/var/run/faillock/*

les fichiers enregistrant les échecs d'authentification pour les utilisateurs
