TSS2_RC Fapi_NvRead (FAPI_CONTEXT * context, char const * nvPath, uint8_t ** data, size_t * size, char **

logData)

Fonction à un seul appel pour

Fapi_NvRead

Lit des données à partir d'un index NV dans le TPM. La FAPI effectuera automatiquement les lectures multiples si l'index NV est plus grand que la constante TPM2_MAX_NV_BUFFER_SIZE du

TPM.

Paramètre

s
context Le FAPI_CONTEXT
nvPath Le chemin de l'index NV à lire
data Les données qui ont été lues à partir de l'index NV
size La taille des données en octets. Peut être NULL
logData Les données de journal de l'index NV si l'index est de type « extend ». Peut être
NULL

Valeurs de

retour
TSS2_RC_SUCCESS si l'appel de fonction a réussi.
TSS2_FAPI_RC_BAD_REFERENCE si context, nvPath ou data est NULL.
TSS2_FAPI_RC_BAD_CONTEXT si une corruption du contexte est détectée.
TSS2_FAPI_RC_BAD_PATH si nvPath est introuvable.
TSS2_FAPI_RC_AUTHORIZATION_FAILED si l'autorisation échoue.
TSS2_FAPI_RC_AUTHORIZATION_UNKNOWN si la méthode d'authentification est inconnue.
TSS2_FAPI_RC_NV_NOT_READABLE si le NV n'est pas un index lisible.
TSS2_FAPI_RC_BAD_SEQUENCE si le contexte a déjà une opération asynchrone en attente.
TSS2_FAPI_RC_IO_ERROR si les données ne peuvent pas être enregistrées.
TSS2_FAPI_RC_MEMORY si la FAPI ne peut pas allouer assez de mémoire pour les opérations internes ou les paramètres de retour.
TSS2_FAPI_RC_NO_TPM si la FAPI a été initialisée en mode no-TPM via son fichier de configuration.
TSS2_FAPI_RC_PATH_NOT_FOUND si un chemin d'objet FAPI est introuvable lors de l'autorisation.
TSS2_FAPI_RC_KEY_NOT_FOUND si une clé est introuvable.
TSS2_FAPI_RC_BAD_VALUE si une valeur invalide a été passée à la fonction.
TSS2_FAPI_RC_TRY_AGAIN si une opération d'E/S n'est pas encore terminée et que cette fonction doit être rappelée.
TSS2_FAPI_RC_GENERAL_FAILURE si une erreur interne s'est produite.
TSS2_FAPI_RC_POLICY_UNKNOWN si la recherche de politique pour un certain empreinte de politique n'a pas réussi.
