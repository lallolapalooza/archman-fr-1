FAIL2BAN-SERVER(1) Commandes utilisateur FAIL2BAN-SERVER(1)

NOM

fail2ban-server - démarre le serveur

SYNTAXE

fail2ban-server [OPTIONS]

DESCRIPTION

Fail2Ban v1.1.0 lit les fichiers journaux contenant des rapports d'échec de mot de passe et bannit les adresses IP correspondantes à l'aide de règles de pare-feu.

OPTIONS

-c, --conf <DIR>
répertoire de configuration
-s, --socket <FICHIER>
chemin du socket
-p, --pidfile <FICHIER>
chemin du fichier PID
--pname <NOM>
nom du processus (thread principal) pour identifier l'instance (par défaut fail2ban-server)
--loglevel <NIVEAU>
niveau de journalisation
--logtarget <CIBLE>
cible de journalisation, utilisez nom-de-fichier ou stdout, stderr, syslog ou sysout.

--syslogsocket auto|<FICHIER>

-d
imprime la configuration. Pour le débogage
--dp, --dump-pretty
imprime la configuration en utilisant une représentation plus lisible par l'homme
-t, --test
teste la configuration (peut également être spécifié avec les paramètres de démarrage)
-i
mode interactif
-v
augmente la verbosité
-q
diminue la verbosité
-x
force l'exécution du serveur (supprime le fichier socket)
-b
démarre le serveur en arrière-plan (par défaut)
-f
démarre le serveur en avant-plan
--async
démarre le serveur en mode asynchrone (pour usage interne uniquement, ne lit pas la configuration)
--timeout
délai d'attente pour le serveur (pour usage interne uniquement, ne lit pas la configuration)
--str2sec <CHAINE>
convertit le format d'abréviation de temps en secondes
-h, --help
affiche ce message d'aide
-V, --version
imprime la version (-V renvoie un format court lisible par machine)
