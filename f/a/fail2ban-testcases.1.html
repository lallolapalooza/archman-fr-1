NOM

fail2ban-testcases - exécute les tests unitaires de Fail2Ban

SYNOPSIS

fail2ban-testcases [OPTIONS] [expressions_régulières]

DESCRIPTION

Script pour exécuter la batterie de tests de Fail2Ban

OPTIONS

--version
affiche la version du programme et quitte
-h, --help
affiche ce message d'aide et quitte
-l NIVEAU_LOG, --log-level=NIVEAU_LOG
Niveau de journalisation à utiliser par le logger lors de l'exécution des tests
-v
Augmente la verbosité
--verbosity=VERBOSITY
Définit le niveau numérique de verbosité (0..4)
--log-direct
Empêche la journalisation différée dans les tests
-n, --no-network
Ne pas exécuter les tests qui nécessitent le réseau
-m, --memory-db
Exécuter les tests de base de données en utilisant la mémoire au lieu d'un fichier
-f, --fast
Essayer d'augmenter la vitesse des tests, en diminuant les intervalles d'attente, base de données en mémoire
-i, --ignore
Négation du filtre [expressions_régulières] pour ignorer les tests correspondant aux expressions régulières spécifiées
-t, --log-traceback
Enrichir les messages de journalisation avec des tracebacks compressés
--full-traceback
Rendre les tracebacks complets, non compressés (par défaut)

VOIR AUSSI
