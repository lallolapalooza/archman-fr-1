NOM

faillog - fichier de journalisation des échecs de connexion

DESCRIPTION

Le fichier `/var/log/faillog` maintient un compte des échecs de connexion et les limites pour chaque compte.

Le fichier contient des enregistrements de longueur fixe, indexés par UID numérique. Chaque enregistrement contient le nombre d'échecs de connexion depuis la dernière connexion réussie ; le nombre maximal d'échecs avant que le compte ne soit désactivé ; la ligne sur laquelle le dernier échec de connexion s'est produit ; la date du dernier échec de connexion ; et la durée (en secondes) pendant laquelle le compte sera verrouillé après un échec.

La structure du fichier est la suivante :

struct	faillog {
	short   fail_cnt;
	short   fail_max;
	char    fail_line[12];
	time_t  fail_time;
	long    fail_locktime;
};

FICHIERS

`/var/log/faillog`

Fichier de journalisation des échecs.
