TSS2_RC Fapi_GetPlatformCertificates (FAPI_CONTEXT * context, uint8_t ** certificates, size_t * certificatesSize)

Fonction à appel unique pour Fapi_GetPlatformCertificates

Les certificats de plateforme pour TPM 2.0 peuvent ne pas se limiter à un seul certificat, mais à une série de soi-disant certificats delta. Cette fonction renvoie l'ensemble des certificats de plateforme concaténés dans un tampon continu.

Paramètres

context Le FAPI_CONTEXT
certificates Les certificats de plateforme
certificatesSize La taille du tampon contenant les certificats. Peut être NULL

Valeurs de retour

TSS2_RC_SUCCESS si l'appel de fonction a été un succès.
TSS2_FAPI_RC_BAD_REFERENCE si context ou certificates est NULL.
TSS2_FAPI_RC_BAD_CONTEXT si une corruption du contexte est détectée.
TSS2_FAPI_RC_BAD_SEQUENCE si le contexte a déjà une opération asynchrone en attente.
TSS2_FAPI_RC_IO_ERROR si les données ne peuvent pas être enregistrées.
TSS2_FAPI_RC_MEMORY si la FAPI ne peut pas allouer assez de mémoire pour les opérations internes ou les paramètres de retour.
TSS2_FAPI_RC_NO_TPM si la FAPI a été initialisée en mode sans TPM via son fichier de configuration.
TSS2_FAPI_RC_NO_CERT si une erreur s'est produite lors du téléchargement du certificat.
TSS2_FAPI_RC_TRY_AGAIN si une opération d'E/S n'est pas encore terminée et que cette fonction doit être rappelée.
TSS2_FAPI_RC_AUTHORIZATION_UNKNOWN si un rappel d'autorisation requis n'est pas défini.
TSS2_FAPI_RC_AUTHORIZATION_FAILED si la tentative d'autorisation échoue.

TSS2_FAPI_RC_POLICY_UNKNOWN si la recherche de politique pour un certain empreinte de politique n'a pas réussi.
TSS2_ESYS_RC_* codes d'erreur possibles d'ESAPI.
TSS2_FAPI_RC_NOT_PROVISIONED La FAPI n'a pas été approvisionnée.
TSS2_FAPI_RC_KEY_NOT_FOUND si une clé n'a pas été trouvée.

    NOM

    Fapi_GetPlatformCertificates - Récupère les certificats de plateforme.

    SYNTHÈSE

    #include <fapi.h>

Fapi_Status_t Fapi_GetPlatformCertificates(
    Fapi_Certificate_Type_t certificate_type,
    Fapi_Certificate_Data_t *certificate_data
);

    DESCRIPTION

    La fonction Fapi_GetPlatformCertificates récupère les certificats de plateforme du système.

    certificate_type spécifie le type de certificat à récupérer. Les types de certificats possibles sont définis dans l'énumération Fapi_Certificate_Type_t.

    certificate_data est un pointeur vers une structure Fapi_Certificate_Data_t qui sera remplie avec les données du certificat récupéré.

    VALEUR DE RETOUR

    Fapi_Status_t indique le succès ou l'échec de l'opération.

    • Fapi_Status_Success : L'opération a réussi.
    • Fapi_Status_Failure : Une erreur s'est produite.
    • Autres codes d'erreur spécifiques à FAPI.

    NOTES

    Cette fonction ne doit être appelée qu'après que le système FAPI a été initialisé avec succès.

    EXEMPLES

    // Exemple d'utilisation :
Fapi_Certificate_Data_t cert_data;
Fapi_Status_t status = Fapi_GetPlatformCertificates(Fapi_Certificate_Type_Platform, &cert_data);

if (status == Fapi_Status_Success) {
    // Traiter les données du certificat
    printf("Certificat récupéré avec succès.\n");
} else {
    fprintf(stderr, "Erreur lors de la récupération du certificat : %d\n", status);
}
