TSS2_RC Fapi_ExportKey (FAPI_CONTEXT * context, char const * pathOfKeyToDuplicate, char const * pathToPublicKeyOfNewParent, char **

exportedData)

Fonction à appel unique pour

Fapi_ExportKey

Étant donné une clé, elle dupliquera (si la clé est une clé de stockage) la clé et empaquetera la clé dupliquée et toutes les clés situées en dessous dans un fichier prêt à être transféré vers un nouveau

TPM.

Paramètre

s
context Le FAPI_CONTEXT
pathOfKeyToDuplicate Le chemin vers la racine du sous-arbre à exporter.
pathToPublicKeyOfNewParent Le chemin vers la clé publique du nouveau parent. Peut être NULL
exportedData Le sous-arbre
exporté

Valeurs de

retour
TSS2_RC_SUCCESS si l'appel de fonction a été un succès.
TSS2_FAPI_RC_BAD_REFERENCE si context, pathOfKeyToDuplicate ou exportedData est NULL.
TSS2_FAPI_RC_BAD_CONTEXT si une corruption du contexte est détectée.
TSS2_FAPI_RC_KEY_NOT_FOUND si pathOfKeyToDuplicate ou pathToPublicKeyOfNewParent ne correspond pas à un objet . FAPI.
TSS2_FAPI_RC_BAD_KEY si la clé à pathToPublicKeyOfNewParent n'est pas adaptée à l'opération demandée.
TSS2_FAPI_RC_KEY_NOT_DUPLICABLE si la clé n'est pas une clé duplicable.
TSS2_FAPI_RC_BAD_SEQUENCE si le contexte a déjà une opération asynchrone en attente.
TSS2_FAPI_RC_IO_ERROR si les données ne peuvent pas être sauvegardées.
TSS2_FAPI_RC_MEMORY si la FAPI ne peut pas allouer assez de mémoire pour les opérations internes ou les paramètres de retour.
TSS2_FAPI_RC_NO_TPM si la FAPI a été initialisée en mode sans TPM via son fichier de configuration.
TSS2_FAPI_RC_PATH_NOT_FOUND si un chemin d'objet FAPI n'a pas été trouvé lors de l'autorisation.
TSS2_FAPI_RC_BAD_VALUE si une valeur invalide a été passée à la fonction.
TSS2_FAPI_RC_BAD_PATH si un chemin est utilisé dans un contexte inapproprié ou contient des caractères illégaux.
TSS2_FAPI_RC_TRY_AGAIN si une opération d'E/S n'est pas encore terminée et que cette fonction doit être rappelée.
TSS2_FAPI_RC_GENERAL_FAILURE si une erreur interne s'est produite.
TSS2_FAPI_RC_AUTHORIZATION_UNKNOWN si un rappel d'autorisation requis n'est pas défini.
TSS2_FAPI_RC_AUTHORIZATION_FAILED si la tentative d'autorisation échoue.
TSS2_FAPI_RC_POLICY_UNKNOWN si la recherche de politique pour un certain empreinte de politique n'a pas réussi.
TSS2_ESYS_RC_* codes d'erreur possibles de l'ESAPI.
TSS2_FAPI_RC_NOT_PROVISIONED La
FAPI n'a pas é
