FAT_IOCTL_SET_ATTRIBUTES(2const) FAT_IOCTL_SET_ATTRIBUTES(2const)

NOM

FAT_IOCTL_GET_ATTRIBUTES, FAT_IOCTL_SET_ATTRIBUTES - obtenir et définir les attributs de fichier dans un système de fichiers FAT

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <linux/msdos_fs.h>  /* Définition des constantes FAT_* et
                                ATTR_* */
#include <sys/ioctl.h>
int ioctl(int fd, FAT_IOCTL_GET_ATTRIBUTES, uint32_t *attr);
int ioctl(int fd, FAT_IOCTL_SET_ATTRIBUTES, uint32_t *attr);

DESCRIPTION

Les fichiers et les répertoires dans le système de fichiers FAT possèdent un masque de bits d'attributs qui peut être lu avec FAT_IOCTL_GET_ATTRIBUTES et écrit avec FAT_IOCTL_SET_ATTRIBUTES.

L'argument fd contient un descripteur de fichier pour un fichier ou un répertoire. Il suffit de créer le descripteur de fichier en appelant open(2) avec le drapeau O_RDONLY.

L'argument attr contient un pointeur vers un masque de bits. Les bits du masque de bits sont :

ATTR_RO
Ce bit spécifie que le fichier ou le répertoire est en lecture seule.
ATTR_HIDDEN
Ce bit spécifie que le fichier ou le répertoire est caché.
ATTR_SYS
Ce bit spécifie que le fichier est un fichier système.
ATTR_VOLUME
Ce bit spécifie que le fichier est une étiquette de volume. Cet attribut est en lecture seule.
ATTR_DIR
Ce bit spécifie qu'il s'agit d'un répertoire. Cet attribut est en lecture seule.
ATTR_ARCH
Ce bit indique que ce fichier ou répertoire doit être archivé. Il est défini lorsqu'un fichier est créé ou modifié. Il est réinitialisé par un système d'archivage.

La valeur zéro ATTR_NONE peut être utilisée pour indiquer qu'aucun bit d'attribut n'est défini.

VALEUR DE RETOUR

En cas de succès, 0 est retourné. En cas d'erreur, -1 est retourné et errno est défini pour indiquer l'erreur.

NORMES

Linux.

HISTORIQUE

Linux 2.6.12.

EXEMPLES

Le programme suivant démontre l'utilisation de ioctl(2) pour manipuler les attributs de fichiers. Le programme lit et affiche l'attribut d'archivage d'un fichier. Après avoir inversé la valeur de l'attribut, le programme lit et affiche à nouveau l'attribut.

Ce qui suit a été enregistré lors de l'application du programme pour le fichier /mnt/user/foo :


# ./toggle_fat_archive_flag /mnt/user/foo
Archive flag is set
Toggling archive flag
Archive flag is not set

Source du programme (toggle_fat_archive_flag.c)

#include <fcntl.h>
#include <linux/msdos_fs.h>
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/ioctl.h>
#include <unistd.h>
/*
 * Lit les attributs de fichier d'un fichier sur un système de fichiers FAT.
 * Affiche l'état du drapeau d'archivage.
 */
static uint32_t
readattr(int fd)
{
    int       ret;
    uint32_t  attr;
    ret = ioctl(fd, FAT_IOCTL_GET_ATTRIBUTES, &attr);
    if (ret == -1) {
        perror("ioctl");
        exit(EXIT_FAILURE);
    }
    if (attr & ATTR_ARCH)
        printf("Archive flag is set\n");
    else
        printf("Archive flag is not set\n");
    return attr;
}
int
main(int argc, char *argv[])
{
    int       fd;
    int       ret;
    uint32_t  attr;
    if (argc != 2) {
        printf("Usage: %s FILENAME\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    fd = open(argv[1], O_RDONLY);
    if (fd == -1) {
        perror("open");
        exit(EXIT_FAILURE);
    }
    /*
     * Lit et affiche les attributs de fichier FAT.
     */
    attr = readattr(fd);
    /*
     * Inverse l'attribut d'archivage.
     */
    printf("Toggling archive flag\n");
    attr ^= ATTR_ARCH;
    /*
     * Écrit les attributs de fichier FAT modifiés.
     */
    ret = ioctl(fd, FAT_IOCTL_SET_ATTRIBUTES, &attr);
    if (ret == -1) {
        perror("ioctl");
        exit(EXIT_FAILURE);
    }
    /*
     * Lit et affiche les attributs de fichier FAT.
     */
    readattr(fd);
    close(fd);
    exit(EXIT_SUCCESS);
}
