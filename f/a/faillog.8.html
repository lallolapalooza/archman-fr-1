FAILLOG(8) Commandes de gestion système FAILLOG(8)

NOM

faillog - affiche les enregistrements faillog ou définit les limites d'échecs de connexion

SYNTAXE

faillog [options]

DESCRIPTION

faillog affiche le contenu de la base de données des échecs de connexion (/var/log/faillog). Il peut également définir les compteurs et les limites d'échecs. Lorsque faillog est exécuté sans arguments, il affiche uniquement les enregistrements faillog des utilisateurs ayant eu un échec de connexion.

OPTIONS

Les options qui s'appliquent à la commande faillog sont :

-a, --all

Affiche (ou agit sur) les enregistrements faillog de tous les utilisateurs ayant une entrée dans la base de données faillog.

La plage d'utilisateurs peut être restreinte avec l'option -u.

En mode d'affichage, cela reste restreint aux utilisateurs existants mais force l'affichage des entrées faillog même si elles sont vides.

Avec les options -l, -m, -r, -t, les enregistrements des utilisateurs sont modifiés, même si l'utilisateur n'existe pas sur le système. Ceci est utile pour réinitialiser les enregistrements des utilisateurs qui ont été supprimés ou pour définir une politique à l'avance pour une plage d'utilisateurs.

-h, --help

Affiche le message d'aide et quitte.

-l, --lock-secs SEC

Verrouille le compte pendant SEC secondes après un échec de connexion.

Un accès en écriture à /var/log/faillog est requis pour cette option.

-m, --maximum MAX

Définit le nombre maximum d'échecs de connexion après lequel le compte est désactivé à MAX.

Choisir une valeur MAX de 0 a pour effet de ne pas imposer de limite au nombre d'échecs de connexion.

Le nombre maximum d'échecs devrait toujours être de 0 pour root afin d'éviter une attaque par déni de service contre le système.

Un accès en écriture à /var/log/faillog est requis pour cette option.

-r, --reset

Réinitialise les compteurs d'échecs de connexion.

Un accès en écriture à /var/log/faillog est requis pour cette option.

-R, --root CHROOT_DIR

Applique les modifications dans le répertoire CHROOT_DIR et utilise les fichiers de configuration du répertoire CHROOT_DIR. Seuls les chemins absolus sont supportés.

-t, --time DAYS

Affiche les enregistrements faillog plus récents que DAYS.

-u, --user LOGIN|RANGE

Affiche l'enregistrement faillog ou maintient les compteurs et limites d'échecs (si utilisé avec les options -l, -m ou -r) uniquement pour l'utilisateur spécifié.

Les utilisateurs peuvent être spécifiés par un nom de connexion, un identifiant utilisateur numérique, ou une PLAGE d'utilisateurs. Cette PLAGE d'utilisateurs peut être spécifiée avec des valeurs min et max (UID_MIN-UID_MAX), une valeur max (-UID_MAX), ou une valeur min (UID_MIN-).

Lorsque aucune des options -l, -m, ou -r n'est utilisée, faillog affiche l'enregistrement faillog de l'utilisateur spécifié.

CAVEATS

faillog n'affiche que les utilisateurs n'ayant eu aucune connexion réussie depuis leur dernier échec. Pour afficher un utilisateur qui a eu une connexion réussie depuis son dernier échec, vous devez explicitement le demander avec le drapeau -u, ou afficher tous les utilisateurs avec le drapeau -a.

FICHIERS

/var/log/faillog

Fichier d'enregistrement des échecs.

VOIR AUSSI

login(1), faillog(5).
