FASTD(1) Commandes utilisateur FASTD(1)

NOM

fastd - Daemon de tunnel rapide et sécurisé

SYNTAXE

fastd OPTION...

DESCRIPTION

fastd est un démon VPN très léger qui tunnelise les paquets IP et les trames Ethernet via UDP. Il prend en charge divers schémas modernes de chiffrement et d'authentification et peut être utilisé dans de nombreuses topologies réseau différentes (1:1, 1:n, maillées).

OPTIONS

--help, -h
Affiche un texte d'aide.
--version, -v
Affiche la version de fastd.
--daemon, -d
Exécute fastd en arrière-plan.
--pid-file <nom_fichier>
Écrit le PID de fastd dans le fichier spécifié.
--status-socket <socket>
Configure un socket pour obtenir le statut de fastd.
--config, -c <nom_fichier>
Charge un fichier de configuration. - peut être spécifié pour lire un fichier de configuration depuis stdin. Plus d'un fichier de configuration peut être chargé.
--config-peer <nom_fichier>
Charge un fichier de configuration pour un seul pair. Le nom de fichier sera utilisé comme nom de pair.
--config-peer-dir <répertoire>
Charge tous les fichiers d'un répertoire en tant que configurations de pairs. Au signal SIGHUP, fastd rechargera les répertoires de pairs.
--user <utilisateur>
Définit l'utilisateur sous lequel exécuter fastd.
--group <groupe>
Définit le groupe sous lequel exécuter fastd.
--log-level error|warn|info|verbose|debug|debug2
Définit le niveau de journalisation sur stderr ; la valeur par défaut est info si aucune autre destination de journalisation n'est configurée.
--syslog-level error|warn|info|verbose|debug|debug2
Définit le niveau de journalisation pour la sortie syslog ; la valeur par défaut est de ne pas utiliser syslog.
--syslog-ident <identifiant>
Définit l'identification syslog ; la valeur par défaut est fastd.
--hide-ip-addresses
Masque les adresses IP dans la sortie du journal.
--hide-mac-addresses
Masque les adresses MAC dans la sortie du journal.
--mode, -m tap|multitap|tun
Définit le mode de l'interface ; le mode TAP est le mode par défaut.
--interface, -i <nom>
Définit le nom de l'interface TUN/TAP à utiliser. Si non spécifié, les noms par défaut spécifiés par le système seront utilisés.
--mtu, -M <mtu>
Définit le MTU ; doit être au moins 576.
--bind, -b <adresse>[:<port>]
Définit l'adresse de liaison. L'adresse peut être une adresse IPv4 ou IPv6, ou le mot-clé any. Les adresses IPv6 doivent être placées entre crochets.

Par défaut, fastd se liera à un port aléatoire pour IPv4 et IPv6. Il n'est actuellement pas possible de spécifier une adresse link-local IPv6 en ligne de commande.

--protocol, -p <protocole>
Définit le protocole de handshake. Actuellement, le seul protocole disponible est ec25519-fhmqvc, qui assure une authentification sécurisée des pairs basée sur des clés publiques/secrètes.
--method <méthode>
Définit la méthode de chiffrement.
--forward
Active le transfert de paquets entre pairs ; lisez la documentation complète avant utilisation !
--on-pre-up <commande>
Définit une commande shell à exécuter avant la création de l'interface.
--on-up <commande>
Définit une commande shell à exécuter après la création de l'interface.
--on-down <commande>
Définit une commande shell à exécuter avant la destruction de l'interface.
--on-post-down <commande>
Définit une commande shell à exécuter après la destruction de l'interface.
--on-connect <commande>
Définit une commande shell à exécuter lorsqu'un handshake est envoyé pour établir une nouvelle connexion.
--on-establish <commande>
Définit une commande shell à exécuter lorsqu'une nouvelle connexion est établie.
--on-disestablish <commande>
Définit une commande shell à exécuter lorsqu'une connexion est perdue.
--on-verify <commande>
Définit une commande shell à exécuter pour vérifier une tentative de connexion par un pair inconnu.
--verify-config
Vérifie la configuration et quitte.
--generate-key
Génère une nouvelle paire de clés.
--show-key
Affiche la clé publique correspondant à la clé secrète configurée.
--machine-readable
Supprime l'affichage du texte explicatif dans les commandes --show-key et --generate-key.

VOIR AUSSI

La documentation complète de fastd est disponible en ligne sur https://gluon.readthedocs.io/.

Des ressources supplémentaires peuvent être trouvées sur le Wiki à l'adresse https://github.com/NeoRaider/fastd/wiki.
