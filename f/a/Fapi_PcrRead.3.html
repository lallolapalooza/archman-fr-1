TSS2_RC Fapi_PcrRead (FAPI_CONTEXT * context, uint32_t pcrIndex, uint8_t ** pcrValue, size_t * pcrValueSize, char ** pcrLog)

Fonction en appel unique pour Fapi_PcrRead

Lit à partir d'un PCR donné et renvoie la valeur et le journal d'événements.

Paramètres

context Le FAPI_CONTEXT
pcrIndex L'indice du PCR à lire
pcrValue La valeur du PCR. Peut être NULL
pcrValueSize La taille de la valeur en octets. Peut être NULL
pcrLog Le journal du PCR. Peut être NULL

Valeurs de retour

TSS2_RC_SUCCESS si l'appel de fonction a réussi.
TSS2_FAPI_RC_BAD_REFERENCE si context, pcrValue ou pcrValueSize est NULL.
TSS2_FAPI_RC_BAD_CONTEXT si une corruption du contexte est détectée.
TSS2_FAPI_RC_BAD_VALUE si pcrIndex est invalide.
TSS2_FAPI_RC_BAD_SEQUENCE si le contexte a déjà une opération asynchrone en attente.
TSS2_FAPI_RC_IO_ERROR si les données ne peuvent pas être sauvegardées.
TSS2_FAPI_RC_MEMORY si le FAPI ne peut pas allouer suffisamment de mémoire pour les opérations internes ou les paramètres de retour.
TSS2_FAPI_RC_NO_TPM si le FAPI a été initialisé en mode sans TPM via son fichier de configuration.
TSS2_FAPI_RC_TRY_AGAIN si une opération d'E/S n'est pas encore terminée et que cette fonction doit être appelée à nouveau.
TSS2_FAPI_RC_AUTHORIZATION_UNKNOWN si un rappel d'autorisation requis n'est pas défini.
TSS2_FAPI_RC_AUTHORIZATION_FAILED si la tentative d'autorisation échoue.
TSS2_FAPI_RC_GENERAL_FAILURE si une erreur interne s'est produite.
TSS2_FAPI_RC_POLICY_UNKNOWN si la recherche de politique pour un certain digest de politique n'a pas abouti.
TSS2_FAPI_RC_NO_CERT si une erreur s'est produite lors du téléchargement du certificat.
TSS2_FAPI_RC_PATH_NOT_FOUND si un chemin d'objet FAPI n'a pas été trouvé lors de l'autorisation.
TSS2_FAPI_RC_KEY_NOT_FOUND si une clé n'a pas été trouvée.
TSS2_ESYS_RC_* codes d'erreur possibles de ESAPI.

TSS2_RC Fapi_PcrRead_Async (FAPI_CONTEXT * context, uint32_t pcrIndex)

Fonction asynchrone pour Fapi_PcrRead

Lit à partir d'un PCR donné et renvoie la valeur et le journal d'événements.

Appelez Fapi_PcrRead_Finish pour terminer l'exécution de cette commande.

Paramètres

context Le FAPI_CONTEXT
pcrIndex L'indice du PCR à lire

Valeurs de retour

TSS2_RC_SUCCESS si l'appel de fonction a réussi.
TSS2_FAPI_RC_BAD_REFERENCE si context est NULL.
TSS2_FAPI_RC_BAD_CONTEXT si une corruption du contexte est détectée.
TSS2_FAPI_RC_BAD_VALUE si pcrIndex est invalide.
TSS2_FAPI_RC_BAD_SEQUENCE si le contexte a déjà une opération asynchrone en attente.
TSS2_FAPI_RC_IO_ERROR si les données ne peuvent pas être sauvegardées.
TSS2_FAPI_RC_MEMORY si le FAPI ne peut pas allouer suffisamment de mémoire pour les opérations internes ou les paramètres de retour.
TSS2_FAPI_RC_NO_TPM si le FAPI a été initialisé en mode sans TPM via son fichier de configuration.
TSS2_ESYS_RC_* codes d'erreur possibles de ESAPI.

TSS2_RC Fapi_PcrRead_Finish (FAPI_CONTEXT * context, uint8_t ** pcrValue, size_t * pcrValueSize, char ** pcrLog)

Fonction asynchrone de fin pour Fapi_PcrRead

Cette fonction doit être appelée après un précédent Fapi_PcrRead_Async.

Paramètres

context Le FAPI_CONTEXT
pcrValue La valeur du PCR. Peut être NULL
pcrValueSize La taille de la valeur en octets. Peut être NULL
pcrLog Le journal du PCR. Peut être NULL

Valeurs de retour

TSS2_RC_SUCCESS si l'appel de fonction a réussi.
TSS2_FAPI_RC_BAD_REFERENCE si context, pcrValue ou pcrValueSize est NULL.
TSS2_FAPI_RC_BAD_CONTEXT si une corruption du contexte est détectée.
TSS2_FAPI_RC_BAD_SEQUENCE si le contexte a déjà une opération asynchrone en attente.
TSS2_FAPI_RC_IO_ERROR si les données ne peuvent pas être sauvegardées.
TSS2_FAPI_RC_MEMORY si le FAPI ne peut pas allouer suffisamment de mémoire pour les opérations internes ou les paramètres de retour.
TSS2_FAPI_RC_TRY_AGAIN si l'opération asynchrone n'est pas encore terminée. Appelez à nouveau cette fonction plus tard.
TSS2_FAPI_RC_BAD_VALUE si une valeur invalide a été passée à la fonction.
TSS2_ESYS_RC_* codes d'erreur possibles de ESAPI.
