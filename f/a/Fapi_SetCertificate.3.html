TSS2_RC Fapi_SetCertificate (FAPI_CONTEXT * context, char const * path, char const * x509certData)

Fonction en un seul appel pour Fapi_SetCertificate

Définit un certificat x509 dans le chemin d'une clé.

Paramètres

context Le FAPI_CONTEXT
path Le chemin de l'entité à associer au certificat
x509certData Le certificat associé à l'entité. S'il vaut NULL, un certificat existant sera supprimé de l'entité

Valeurs de retour

TSS2_RC_SUCCESS si l'appel de fonction a réussi.
TSS2_FAPI_RC_BAD_REFERENCE si context ou path vaut NULL.
TSS2_FAPI_RC_BAD_CONTEXT si une corruption du contexte est détectée.
TSS2_FAPI_RC_KEY_NOT_FOUND si path ne correspond pas à une entité FAPI.
TSS2_FAPI_RC_BAD_KEY si x509certData est invalide.
TSS2_FAPI_RC_BAD_SEQUENCE si le contexte a déjà une opération asynchrone en attente.
TSS2_FAPI_RC_IO_ERROR si les données ne peuvent pas être enregistrées.
TSS2_FAPI_RC_MEMORY si la FAPI ne peut pas allouer assez de mémoire pour les opérations internes ou les paramètres de retour.
TSS2_FAPI_RC_PATH_NOT_FOUND si un chemin d'objet FAPI n'a pas été trouvé pendant l'autorisation.
TSS2_FAPI_RC_BAD_VALUE si une valeur invalide a été passée à la fonction.
TSS2_FAPI_RC_TRY_AGAIN si une opération d'E/S n'est pas encore terminée et que cette fonction doit être rappelée.
TSS2_FAPI_RC_GENERAL_FAILURE si une erreur interne s'est produite.
TSS2_ESYS_RC_* codes d'erreur possibles d'ESAPI.
TSS2_FAPI_RC_NOT_PROVISIONED La FAPI n'a pas été provisionnée.
TSS2_FAPI_RC_BAD_PATH si le chemin est utilisé dans un contexte inapproprié ou contient des caractères illégaux.
