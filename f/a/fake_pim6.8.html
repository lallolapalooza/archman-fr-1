NOM

fake_pim6

SYNTAXE


fake_pim6 [-l|-f] [-t ttl] [-s src6] [-d dst6] interface hello [dr_priority]
fake_pim6 [-l|-f] [-t ttl] [-s src6] [-d dst6] interface bootstrap bsr6 [bsr_prio [rp6]]
fake_pim6 [-l|-f] [-t ttl] [-s src6] [-d dst6] interface assert multicast6 [metric [sender6]]
fake_pim6 [-l|-f] [-t ttl] [-s src6] [-d dst6] interface join|prune neighbor6 multicast6 target6

OPTIONS

  -l       boucler le paquet toutes les 5 secondes
  -f       inonder le paquet (avec des valeurs aléatoires si utile, par ex. src)
  -t ttl   spécifier un ttl non standard
  -s src6  spécifier l'adresse source IPv6
  -d dst6  spécifier une adresse de destination IPv6 non standard
La commande hello prend éventuellement la priorité DR (défaut : 0).
Les commandes join et prune nécessitent le groupe multicast à modifier, l'adresse cible
qui rejoint ou quitte et le routeur PIM voisin.
La commande bootstrap nécessite l'adresse du routeur bootstrap et éventuellement sa
priorité et le point de rendez-vous (rendezvous point).
La commande assert nécessite l'adresse multicast concernée et éventuellement sa
métrique et l'expéditeur multicast.
