NOM

fail2ban-regex - tester l'option « failregex » de Fail2ban

SYNOPSIS

fail2ban-regex [OPTIONS] <LOG> <REGEX> [IGNOREREGEX]

DESCRIPTION

Fail2Ban lit un fichier journal contenant des rapports d'échec d'authentification et bannit les adresses IP correspondantes à l'aide de règles de pare-feu.

Cet outil permet de tester des expressions rationnelles pour « fail2ban ».

LOG :

chaîne
une chaîne représentant une ligne de journal
nom de fichier
chemin vers un fichier journal (/var/log/auth.log)
systemd-journal
recherche dans le journal systemd (systemd-python requis), éventuellement avec des paramètres de backend, voir `man jail.conf` pour l'utilisation et des exemples (systemd-journal[journalflags=1]).

REGEX :

chaîne
une chaîne représentant un « failregex »
filtre
nom du filtre, éventuellement avec des options (sshd[mode=aggressive])
nom de fichier
chemin vers un fichier de filtre (filter.d/sshd.conf)

IGNOREREGEX :

chaîne
une chaîne représentant un « ignoreregex »
nom de fichier
chemin vers un fichier de filtre (filter.d/sshd.conf)

OPTIONS

--version
afficher le numéro de version du programme et quitter
-h, --help
afficher ce message d'aide et quitter
-c CONFIG, --config=CONFIG
définir un répertoire de configuration alternatif
-d DATEPATTERN, --datepattern=DATEPATTERN
définir un motif personnalisé utilisé pour correspondre aux dates/heures
--timezone=TIMEZONE, --TZ=TIMEZONE
définir le fuseau horaire utilisé pour convertir le format de l'heure
-e ENCODING, --encoding=ENCODING
Encodage du fichier. Par défaut : locale du système
-r, --raw
Hôtes bruts, ne pas résoudre le DNS
--usedns=USEDNS
Remplacement DNS spécifié des balises <HOST> dans l'expression rationnelle ('yes' - correspond à toutes les formes d'hôtes, 'no' - adresses IP uniquement)
-L MAXLINES, --maxlines=MAXLINES
nombre maximal de lignes pour les expressions rationnelles multilignes.
-m JOURNALMATCH, --journalmatch=JOURNALMATCH
correspondances de style journalctl remplaçant le fichier de filtre. « systemd-journal » uniquement
-l LOG_LEVEL, --log-level=LOG_LEVEL
Niveau de journalisation à utiliser pour le logger de Fail2Ban
-V
obtenir la version dans un format court lisible par machine
-v, --verbose
Augmenter le niveau de verbosité
--verbosity=VERBOSE
Définir le niveau numérique de verbosité (0..4)
--verbose-date, --VD
Motifs/expressions rationnelles de date verbeux dans la sortie
-D, --debuggex
Produire des URL debuggex.com pour le débogage
--no-check-all
Désactiver la vérification de toutes les expressions rationnelles
-o OUT, --out=OUT
Définir le jeton pour n'afficher que les informations d'échec (ligne, id, ip, msg, host, ip4, ip6, dns, correspondances, ...)
--print-no-missed
Ne pas afficher les lignes non détectées
--print-no-ignored
Ne pas afficher les lignes ignorées
--print-all-matched
Afficher toutes les lignes correspondantes
--print-all-missed
Afficher toutes les lignes non détectées, peu importe leur nombre
--print-all-ignored
Afficher toutes les lignes ignorées, peu importe leur nombre
-t, --log-traceback
Enrichir les messages de journal avec des traces d'exécution compressées
--full-traceback
Rendre les traces d'exécution complètes, non compressées (comme par défaut)
