TSS2_RC Fapi_SetPolicyActionCB (FAPI_CONTEXT * context, Fapi_CB_PolicyAction callback, void * userData)

Fapi_SetActionCB() enregistre une fonction définie par l'application comme rappel qui sera appelée lors de la rencontre d'un élément d'action de politique.

Paramètres

context Le FAPI_CONTEXT
callback La fonction de rappel pour la sélection de branche
userData Un pointeur qui est fourni à toutes les invocations de rappel

Valeurs de retour

TSS2_RC_SUCCESS si l'appel de fonction a réussi.
TSS2_FAPI_RC_BAD_REFERENCE si le contexte est NULL.
TSS2_FAPI_RC_BAD_CONTEXT si une corruption du contexte est détectée.
TSS2_FAPI_RC_MEMORY si le FAPI ne peut pas allouer suffisamment de mémoire pour les opérations internes ou les paramètres de retour.
TSS2_FAPI_RC_BAD_SEQUENCE si les fonctions synchrones ou Async sont appelées alors que le contexte a une autre opération asynchrone en attente, ou si la fonction Finish est appelée alors que le contexte n'a pas d'opération asynchrone appropriée en attente.
TSS2_FAPI_RC_IO_ERROR si les données ne peuvent pas être sauvegardées.

TSS2_RC Fapi_SetSignCB (FAPI_CONTEXT * context, Fapi_CB_Sign callback, void * userData)

Fapi_SetSignCB() enregistre une fonction définie par l'application comme rappel pour permettre au FAPI d'obtenir des signatures autorisant l'utilisation des objets TPM.

Paramètres

context Le FAPI_CONTEXT
callback La fonction de rappel pour la sélection de signature
userData Un pointeur qui est fourni à toutes les invocations de rappel

Valeurs de retour

TSS2_RC_SUCCESS si l'appel de fonction a réussi.
TSS2_FAPI_RC_BAD_REFERENCE si le contexte est NULL.
TSS2_FAPI_RC_BAD_CONTEXT si une corruption du contexte est détectée.
TSS2_FAPI_RC_MEMORY si le FAPI ne peut pas allouer suffisamment de mémoire pour les opérations internes ou les paramètres de retour.
TSS2_FAPI_RC_BAD_SEQUENCE si les fonctions synchrones ou Async sont appelées alors que le contexte a une autre opération asynchrone en attente, ou si la fonction Finish est appelée alors que le contexte n'a pas d'opération asynchrone appropriée en attente.
TSS2_FAPI_RC_IO_ERROR si les données ne peuvent pas être sauvegardées.
