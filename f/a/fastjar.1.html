NOM

fastjar - outil d'archivage pour les archives Java

SYNTAXE

fastjar -ctxu [OPTIONS] [fichier-archive] [fichier-manifeste] [-C répertoire] fichiers...

DESCRIPTION

"fastjar" est une implémentation de l'utilitaire jar de Sun, écrite entièrement en C, qui s'exécute en une fraction de temps tout en étant compatible en fonctionnalités.

Si un fichier est un répertoire, il est traité récursivement. Le nom du fichier de manifeste et le nom du fichier d'archive doivent être spécifiés dans le même ordre que les indicateurs -m et -f.

OPTIONS

Une seule des actions suivantes doit être spécifiée :

-c
Créer une nouvelle archive.
-t
Lister le contenu de l'archive.
-x
Extraire les fichiers nommés (ou tous) de l'archive.
-u
Mettre à jour une archive existante.

Les paramètres suivants sont facultatifs :

-@
Lire les noms des fichiers à ajouter à l'archive depuis stdin. Cette option n'est supportée qu'en combinaison avec -c ou -u. Option non standard ajoutée dans la version GCC.
-C répertoire
Se placer dans le répertoire et inclure le fichier suivant.
-E
Empêcher fastjar de lire le contenu d'un répertoire lors de la spécification d'un répertoire (et de s'appuyer plutôt sur la liste des fichiers fournis pour populer l'archive concernant l'entrée du répertoire). Option non standard ajoutée dans la version GCC.
-M
Ne pas créer de fichier manifeste pour les entrées.
-i
Générer un index des paquets dans ce jar et son Class-Path.
-J
Toutes les options commençant par -J sont ignorées.
-0
Stocker uniquement ; n'utiliser aucune compression ZIP.
-V
--version
Afficher les informations de version.
-f archive
Spécifier le nom du fichier d'archive.
-m manifeste
Inclure les informations du manifeste à partir du fichier manifeste spécifié.
-v
Générer une sortie détaillée sur la sortie standard.

Les paramètres de la forme @option{@}FICHIER sont considérés comme des noms de fichiers et sont développés avec le contenu du fichier.

Toutes les options restantes sont considérées comme des noms de fichiers.
