TSS2_RC Fapi_GetTcti (FAPI_CONTEXT * context, TSS2_TCTI_CONTEXT ** tcti)

Fonction en un seul appel pour Fapi_GetTcti

Fapi_GetTcti retourne le TSS2_TCTI_CONTEXT actuellement utilisé par le FAPI_CONTEXT fourni. Le but est de permettre un accès avancé au TPM avec lequel on communique actuellement. C'est particulièrement utile en combinaison avec Fapi_GetTpmBlobs().

Note : L'application doit s'assurer que ce TSS2_TCTI_CONTEXT n'est pas utilisé en parallèle du traitement d'une commande FAPI.

Paramètres

context Le FAPI_CONTEXT
tcti Le TSS2_TCTI_CONTEXT utilisé pour communiquer avec le TPM actuel.

Valeurs de retour

TSS2_RC_SUCCESS si l'appel de fonction a réussi.
TSS2_FAPI_RC_BAD_REFERENCE si context ou tcti est NULL.
TSS2_FAPI_RC_BAD_CONTEXT si une corruption du contexte est détectée.
TSS2_FAPI_RC_NO_TPM si FAPI a été démarré en mode sans TPM.
