TSS2_RC Fapi_List (FAPI_CONTEXT * context, char const * searchPath, char ** pathList)

Fonction en un seul appel pour Fapi_List

Énumère tous les objets dans le metadatastore à un chemin donné et les retourne dans une liste de chemins complets à partir de la racine, les valeurs étant séparées par des deux-points.

Paramètres

context Le FAPI_CONTEXT
searchPath Le chemin qui identifie la racine de la recherche
pathList Une liste séparée par des deux-points de tous les objets dans le chemin racine

Valeurs de retour

TSS2_RC_SUCCESS si l'appel de fonction a réussi.
TSS2_FAPI_RC_BAD_REFERENCE si context, searchPath, pathlist est NULL.
TSS2_FAPI_RC_BAD_CONTEXT si une corruption du contexte est détectée.
TSS2_FAPI_RC_BAD_PATH si searchPath ne correspond à aucune entité FAPI.
TSS2_FAPI_RC_BAD_SEQUENCE si le contexte a déjà une opération asynchrone en attente.
TSS2_FAPI_RC_IO_ERROR si les données ne peuvent pas être enregistrées.
TSS2_FAPI_RC_MEMORY si FAPI ne peut pas allouer suffisamment de mémoire pour les opérations internes ou les paramètres de retour.
TSS2_FAPI_RC_PATH_NOT_FOUND si un chemin d'objet FAPI n'a pas été trouvé lors de l'autorisation.
TSS2_FAPI_RC_NOT_PROVISIONED FAPI n'a pas été provisionné.
TSS2_FAPI_RC_BAD_VALUE si une valeur invalide a été passée à la fonction.

TSS2_RC Fapi_List_Async (FAPI_CONTEXT * context, char const * searchPath)

Fonction asynchrone pour Fapi_List

Énumère tous les objets dans le metadatastore à un chemin donné et les retourne dans une liste de chemins complets à partir de la racine, les valeurs étant séparées par des deux-points.

Appelez Fapi_List_Finish pour terminer l'exécution de cette commande.

Valeurs de retour

TSS2_RC_SUCCESS si l'appel de fonction a réussi.

Paramètres

context Le FAPI_CONTEXT
searchPath Le chemin qui identifie la racine de la recherche

Valeurs de retour

TSS2_FAPI_RC_BAD_REFERENCE si context ou searchPath est NULL.
TSS2_FAPI_RC_BAD_CONTEXT si une corruption du contexte est détectée.
TSS2_FAPI_RC_BAD_PATH si searchPath ne correspond à aucune entité FAPI.
TSS2_FAPI_RC_BAD_SEQUENCE si le contexte a déjà une opération asynchrone en attente.
TSS2_FAPI_RC_IO_ERROR si les données ne peuvent pas être enregistrées.
TSS2_FAPI_RC_MEMORY si FAPI ne peut pas allouer suffisamment de mémoire pour les opérations internes ou les paramètres de retour.

TSS2_RC Fapi_List_Finish (FAPI_CONTEXT * context, char ** pathList)

Fonction de fin asynchrone pour Fapi_List

Cette fonction doit être appelée après un appel précédent à Fapi_List_Async.

Paramètres

context Le FAPI_CONTEXT
pathList Une liste séparée par des deux-points de tous les objets dans le chemin racine

Valeurs de retour

TSS2_RC_SUCCESS si l'appel de fonction a réussi.
TSS2_FAPI_RC_BAD_REFERENCE si context ou pathList est NULL.
TSS2_FAPI_RC_BAD_CONTEXT si une corruption du contexte est détectée.
TSS2_FAPI_RC_BAD_SEQUENCE si le contexte a déjà une opération asynchrone en attente.
TSS2_FAPI_RC_IO_ERROR si les données ne peuvent pas être enregistrées.
TSS2_FAPI_RC_MEMORY si FAPI ne peut pas allouer suffisamment de mémoire pour les opérations internes ou les paramètres de retour.
TSS2_FAPI_RC_TRY_AGAIN si l'opération asynchrone n'est pas encore terminée. Appelez cette fonction à nouveau plus tard.
TSS2_FAPI_RC_PATH_NOT_FOUND si un chemin d'objet FAPI n'a pas été trouvé lors de l'autorisation.
TSS2_FAPI_RC_NOT_PROVISIONED FAPI n'a pas été provisionné.
TSS2_FAPI_RC_BAD_PATH si le chemin est utilisé dans un contexte inapproprié ou contient des caractères illégaux.
TSS2_FAPI_RC_BAD_VALUE si une valeur invalide a été passée à la fonction.
