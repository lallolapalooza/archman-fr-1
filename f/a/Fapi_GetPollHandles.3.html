Documentation de la fonction

TSS2_RC Fapi_GetPollHandles (FAPI_CONTEXT * context, FAPI_POLL_HANDLE ** handles, size_t * num_handles)

Récupère les descripteurs pour le sondage

Renvoie un tableau de descripteurs qui peuvent être sondés pour être notifiés lorsque des données du TPM ou d'une opération disque sont disponibles.

Le code correspondant devrait ressembler à ceci : do { r = Fapi_GetPollHandles(fc, &ph, &nph); if (r == TSS2_RC_SUCCESS) { poll(ph, nph, -1); Fapi_Free(ph); } r = Fapi_*_Finish(fc, ...); } while (r == TSS2_FAPI_RC_TRY_AGAIN);

Paramètres

context Le FAPI_CONTEXT
handles Un tableau d'entrées de descripteurs de sondage
num_handles La taille du tableau en descripteurs

Valeurs de retour

TSS2_RC_SUCCESS si l'appel de fonction a réussi.
TSS2_FAPI_RC_BAD_REFERENCE si context ou data est NULL.
TSS2_FAPI_RC_BAD_CONTEXT si une corruption du contexte est détectée.
TSS2_FAPI_RC_BAD_SEQUENCE si le contexte n'a pas d'opération asynchrone en attente.
TSS2_FAPI_RC_NO_HANDLE s'il n'y a pas de descripteurs à sonder
TSS2_FAPI_RC_MEMORY si FAPI ne peut pas allouer suffisamment de mémoire pour les opérations internes ou les paramètres de retour.
