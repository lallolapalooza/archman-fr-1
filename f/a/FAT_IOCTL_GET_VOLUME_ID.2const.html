FAT_IOCTL_GET_VOLUME_ID(2const) FAT_IOCTL_GET_VOLUME_ID(2const)

NOM

FAT_IOCTL_GET_VOLUME_ID - lire l'identifiant de volume dans un système de fichiers FAT

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNOPSIS

#include <linux/msdos_fs.h>  /* Définition des constantes FAT_* */
#include <sys/ioctl.h>
int ioctl(int fd, FAT_IOCTL_GET_VOLUME_ID, uint32_t *id);

DESCRIPTION

Les systèmes de fichiers FAT sont identifiés par un identifiant de volume. L'identifiant de volume peut être lu avec FAT_IOCTL_GET_VOLUME_ID.

L'argument fd peut être un descripteur de fichier pour n'importe quel fichier ou répertoire du système de fichiers. Il suffit de créer le descripteur de fichier en appelant open(2) avec l'indicateur O_RDONLY.

L'argument id est un pointeur vers le champ qui sera rempli avec l'identifiant de volume. Typiquement, l'identifiant de volume est affiché à l'utilisateur sous forme d'un groupe de deux champs de 16 bits :


printf("Volume ID %04x-%04x\n", id >> 16, id & 0xFFFF);

VALEUR DE RETOUR

En cas de succès, 0 est retourné. En cas d'erreur, -1 est retourné, et errno est défini pour indiquer l'erreur.

NORMES

Linux.

HISTORIQUE

Linux 3.11.

EXEMPLES

Le programme suivant démontre l'utilisation de ioctl(2) pour afficher l'identifiant de volume d'un système de fichiers FAT.

La sortie suivante a été enregistrée lors de l'application du programme pour le répertoire /mnt/user :


$ ./display_fat_volume_id /mnt/user
Volume ID 6443-6241

Source du programme (display_fat_volume_id.c)

#include <fcntl.h>
#include <linux/msdos_fs.h>
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/ioctl.h>
#include <unistd.h>
int
main(int argc, char *argv[])
{
    int       fd;
    int       ret;
    uint32_t  id;
    if (argc != 2) {
        printf("Usage: %s FILENAME\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    fd = open(argv[1], O_RDONLY);
    if (fd == -1) {
        perror("open");
        exit(EXIT_FAILURE);
    }
    /*
     * Lire l'identifiant de volume.
     */
    ret = ioctl(fd, FAT_IOCTL_GET_VOLUME_ID, &id);
    if (ret == -1) {
        perror("ioctl");
        exit(EXIT_FAILURE);
    }
    /*
     * Formater la sortie en deux groupes de 16 bits chacun.
     */
    printf("Volume ID %04x-%04x\n", id >> 16, id & 0xFFFF);
    close(fd);
    exit(EXIT_SUCCESS);
}
