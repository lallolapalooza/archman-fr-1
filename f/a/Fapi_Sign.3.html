TSS2_RC Fapi_Sign (FAPI_CONTEXT * context, char const * keyPath, char const * padding, uint8_t const * digest, size_t digestSize, uint8_t ** signature, size_t * signatureSize, char ** publicKey, char **

certificate)

Fonction à un seul appel pour

Fapi_Sign

Utilise une clé, identifiée par son chemin, pour signer un empreinte et place le résultat dans un flux d'octets

TPM2B.

Paramètre

s
context Le FAPI_CONTEXT
keyPath Le chemin de la clé de signature
padding Un algorithme de remplissage. Doit être soit 'RSA_SSA' soit 'RSA_PSS' ou NULL
digest L'empreinte à signer. Doit déjà être hachée
digestSize La taille de l'empreinte en octets
signature La signature
signatureSize La taille de la signature en octets. Peut être NULL
publicKey La clé publique pouvant être utilisée pour vérifier la signature, au format PEM. Peut être NULL
certificate Le certificat associé à la clé de signature, au format PEM. Peut être
NULL

Valeurs de

retour
TSS2_RC_SUCCESS si l'appel de fonction a été un succès.
TSS2_FAPI_RC_BAD_REFERENCE si context, keyPath, digest ou signature est NULL.
TSS2_FAPI_RC_BAD_CONTEXT si une corruption du contexte est détectée.
TSS2_FAPI_RC_KEY_NOT_FOUND si keyPath ne correspond pas à une clé FAPI.
TSS2_FAPI_RC_BAD_KEY si l'objet à keyPath n'est pas une clé, ou est une clé inadaptée à l'opération demandée.
TSS2_FAPI_RC_BAD_VALUE si digestSize est égal à zéro.
TSS2_FAPI_RC_BAD_SEQUENCE si le contexte a déjà une opération asynchrone en attente.
TSS2_FAPI_RC_IO_ERROR si les données ne peuvent pas être enregistrées.
TSS2_FAPI_RC_MEMORY si la FAPI ne peut pas allouer assez de mémoire pour les opérations internes ou les paramètres de retour.
TSS2_FAPI_RC_NO_TPM si la FAPI a été initialisée en mode sans TPM via son fichier de configuration.
TSS2_FAPI_RC_TRY_AGAIN si une opération d'E/S n'est pas encore terminée et que cette fonction doit être rappelée.
TSS2_FAPI_RC_PATH_NOT_FOUND si un chemin d'objet FAPI n'a pas été trouvé lors de l'autorisation.
TSS2_FAPI_RC_GENERAL_FAILURE si une erreur interne s'est produite.
TSS2_FAPI_RC_AUTHORIZATION_UNKNOWN si un rappel d'autorisation requis n'est pas défini.
TSS2_FAPI_RC_AUTHORIZATION_FAILED si la tentative d'autorisation échoue.
TSS2_FAPI_RC_POLICY_UNKNOWN si la recherche de politique pour un certain empreinte de politique n'a pas réussi.
TSS2_ESYS_RC_* codes d'erreur possibles d'ESAPI.
TSS2_FAPI_RC_NOT_PROVISIONED La FAPI n'a pas été approvisionnée.
TSS2_FAPI_RC_BAD_PATH si le chemin est utilisé dans un co
ntexte inapproprié ou conti
ent des caractères illégaux.
