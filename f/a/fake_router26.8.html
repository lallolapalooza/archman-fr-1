NOM

fake_router26

SYNOPIS

fake_router26 [-E type] [-A network/prefix] [-R network/prefix] [-D dns-server] [-s sourceip] [-S sourcemac] [-ardl seconds] [-Tt ms] [-n no] [-i interval] interface [target]

OPTIONS

 -A network/prefix  ajouter un réseau d'autoconfiguration (jusqu'à 16 fois)
 -a seconds         durée de vie du préfixe -A (par défaut 99999)
 -R network/prefix  ajouter une entrée de routage (jusqu'à 16 fois)
 -r seconds         durée de vie de l'entrée de routage -R (par défaut 4096)
 -D dns-server      spécifier un serveur DNS (jusqu'à 16 fois)
 -L searchlist      spécifier la liste de recherche de domaine DNS, séparer les entrées par ,
 -d seconds         durée de vie de l'entrée DNS -D (par défaut 4096
 -M mtu             l'MTU à envoyer, par défaut la configuration de l'interface
 -s sourceip        l'IP source du routeur, par défaut votre lien local
 -S sourcemac       l'adresse MAC source du routeur, par défaut celle de votre interface
 -f ethernetmac     l'adresse MAC Ethernet à utiliser pour envoyer les trames
 -l seconds         durée de vie du routeur (par défaut 2048)
 -T ms              timer de joignabilité (par défaut 0)
 -t ms              timer de retransmission (par défaut 0)
 -p priority        priorité "low", "medium", "high" (par défaut), "reserved"
 -F flags           Définir un ou plusieurs des drapeaux suivants : managed, other,
                    homeagent, proxy, reserved ; séparer par une virgule
 -E type            Option d'évasion d'annonce de routeur (RA). Types:
     F              évasion complète (Windows et FreeBSD)
     H              en-tête hop-by-hop simple
     1              en-tête de fragmentation simple en un seul coup (peut en ajouter plusieurs)
     D              insérer un grand en-tête de destination qui fera fragmenter
     O              fragments qui se chevauchent pour les cibles gardées en premier (Win, BSD, Mac)
     o              fragments qui se chevauchent pour les cibles gardées en dernier (Linux, Solaris)
                    Exemples : -E H111, -E D
 -m mac-address     si une seule machine doit recevoir les RA (pas avec -E DoO)
 -i interval        temps entre les paquets RA (par défaut : 5)
 -n number          nombre de RA à envoyer (par défaut : illimité)
 -X                 nettoyer en désannonçant le faux routeur (par défaut : désactivé)
Annoncez-vous comme routeur et essayez de devenir le routeur par défaut.
Si une adresse lien local ou MAC inexistante est fournie, cela entraîne un déni de service.
