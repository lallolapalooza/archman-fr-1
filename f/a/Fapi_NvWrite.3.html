TSS2_RC Fapi_NvWrite (FAPI_CONTEXT * context, char const * nvPath, uint8_t const * data, size_t size)

Fonction en un seul appel pour Fapi_NvWrite

Écrit des données dans un index NV 'régulier' (pas pin, extend ou counter).

Paramètres

context Le FAPI_CONTEXT
nvPath Le chemin de l'index NV à écrire
data Les données à écrire dans l'index NV
size La taille des données en octets

Valeurs de retour

TSS2_RC_SUCCESS si l'appel de fonction a réussi.
TSS2_FAPI_RC_BAD_REFERENCE si context, nvPath, ou data est NULL.
TSS2_FAPI_RC_BAD_CONTEXT si une corruption du contexte est détectée.
TSS2_FAPI_RC_BAD_PATH si nvPath n'est pas trouvé.
TSS2_FAPI_RC_NV_EXCEEDED si l'index NV n'est pas assez grand pour les données à écrire.
TSS2_FAPI_RC_NV_WRONG_TYPE si l'index NV n'est pas un index 'régulier'.
TSS2_FAPI_RC_NV_NOT_WRITEABLE si l'index NV n'est pas inscriptible.
TSS2_FAPI_RC_POLICY_UNKNOWN si la politique est inconnue.
TSS2_FAPI_RC_BAD_SEQUENCE si le contexte a déjà une opération asynchrone en attente.
TSS2_FAPI_RC_IO_ERROR si les données ne peuvent pas être sauvegardées.
TSS2_FAPI_RC_MEMORY si le FAPI ne peut pas allouer assez de mémoire pour les opérations internes ou les paramètres de retour.
TSS2_FAPI_RC_NO_TPM si FAPI a été initialisé en mode sans TPM via son fichier de configuration.
TSS2_FAPI_RC_TRY_AGAIN si une opération d'E/S n'est pas encore terminée et que cette fonction doit être appelée à nouveau.
TSS2_FAPI_RC_BAD_VALUE si une valeur invalide a été passée à la fonction.
TSS2_FAPI_RC_PATH_NOT_FOUND si un chemin d'objet FAPI n'a pas été trouvé lors de l'autorisation.
TSS2_FAPI_RC_KEY_NOT_FOUND si une clé n'a pas été trouvée.
TSS2_FAPI_RC_GENERAL_FAILURE si une erreur interne s'est produite.
TSS2_FAPI_RC_AUTHORIZATION_UNKNOWN si une fonction de rappel d'autorisation requise n'est pas définie.
TSS2_FAPI_RC_AUTHORIZATION_FAILED si la tentative d'autorisation échoue.
TSS2_ESYS_RC_* codes d'erreur possibles de ESAPI.
TSS2_FAPI_RC_NOT_PROVISIONED FAPI n'a pas été provisionné.
