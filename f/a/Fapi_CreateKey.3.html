TSS2_RC Fapi_CreateKey (FAPI_CONTEXT * context, char const * path, char const * type, char const * policyPath, char const * authValue)

Fonction en un seul appel pour Fapi_CreateKey

Crée une clé dans le TPM en se basant sur le type de clé, en utilisant la politique et la valeur d'authentification fournies. La clé est ensuite stockée soit dans le magasin de métadonnées FAPI, soit dans le TPM.

Paramètres

context Le FAPI_CONTEXT
path Le chemin où la nouvelle clé est stockée
type Le type de la nouvelle clé. Peut être NULL
policyPath Le chemin vers la politique associée à la nouvelle clé. Peut être NULL
authValue La valeur d'autorisation pour la nouvelle clé. Peut être NULL

Valeurs de retour

TSS2_RC_SUCCESS si l'appel de fonction a réussi.
TSS2_FAPI_RC_BAD_REFERENCE si context ou path est NULL.
TSS2_FAPI_RC_BAD_CONTEXT si une corruption du contexte est détectée.
TSS2_FAPI_RC_BAD_PATH si policyPath n'est pas NULL et ne correspond pas à une politique FAPI.
TSS2_FAPI_RC_KEY_NOT_FOUND si la clé parente ne correspond pas à une clé FAPI.
TSS2_FAPI_RC_PATH_ALREADY_EXISTS si un fichier existe déjà à cet endroit.
TSS2_FAPI_RC_BAD_VALUE si keyType n'est pas NULL et est invalide.
TSS2_FAPI_RC_BAD_SEQUENCE si le contexte a déjà une opération asynchrone en attente.
TSS2_FAPI_RC_IO_ERROR si les données ne peuvent pas être sauvegardées.
TSS2_FAPI_RC_MEMORY si FAPI ne peut pas allouer suffisamment de mémoire pour les opérations internes ou les paramètres de retour.
TSS2_FAPI_RC_NO_TPM si FAPI a été initialisé en mode sans TPM via son fichier de configuration.
TSS2_FAPI_RC_TRY_AGAIN si une opération d'E/S n'est pas encore terminée et que cette fonction doit être appelée à nouveau.
TSS2_FAPI_RC_AUTHORIZATION_UNKNOWN si une fonction de rappel d'autorisation requise n'est pas définie.
TSS2_ESYS_RC_* codes d'erreur possibles d'ESAPI.
TSS2_FAPI_RC_PATH_NOT_FOUND si un chemin d'objet FAPI n'a pas été trouvé pendant l'autorisation.
TSS2_FAPI_RC_GENERAL_FAILURE si une erreur interne s'est produite.
TSS2_FAPI_RC_NOT_PROVISIONED FAPI n'a pas été provisionné.
TSS2_FAPI_RC_AUTHORIZATION_FAILED si la tentative d'autorisation échoue.
TSS2_FAPI_RC_POLICY_UNKNOWN si la recherche de politique pour un certain résumé de politique n'a pas abouti.
