NOM

fake_advertise6

SYNTAXE

fake_advertise6 [-DHF] [-Ors] [-n count] [-w seconds] interface ip-address-advertised [target-address [mac-address-advertised [source-ip-address]]]

Annonce une adresse IPv6 sur le réseau (avec sa propre MAC si non spécifiée), l'envoyant à l'adresse multicast de tous les nœuds si aucune adresse cible n'est définie. L'adresse IP source est l'adresse annoncée si elle n'est pas définie.

Options d'envoi


-n count envoie combien de paquets (défaut : indéfini)
-w seconds temps d'attente entre les paquets envoyés (défaut : 5)
-m srcmac l'adresse srcmac à utiliser pour l'envoi (pas celle annoncée !

Options de drapeau


-O NE PAS définir le drapeau d'override (défaut : activé)
-r DÉFINIR le drapeau de routeur (défaut : désactivé)
-s DÉFINIR le drapeau de sollicitation (défaut : désactivé)

Options d'évasion de sécurité ND (peuvent être combinées)


-F attaque d'évasion complète (aucune autre option d'évasion autorisée)
-H ajouter un en-tête hop-by-hop
-f ajouter un en-tête de fragment à usage unique (peut être spécifié plusieurs fois)
-D ajouter un grand en-tête de destination qui fragmente le paquet.
