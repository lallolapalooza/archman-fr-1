TSS2_RC Fapi_Encrypt (FAPI_CONTEXT * context, char const * keyPath, uint8_t const * plainText, size_t plainTextSize, uint8_t ** cipherText, size_t *

cipherTextSize)

Fonction à un seul appel pour

Fapi_Encrypt

Chiffre les données fournies pour la clé cible en utilisant les schémas de chiffrement TPM tels que spécifiés dans le profil cryptographique. Cette fonction n'utilise pas le TPM, c'est-à-dire qu'elle fonctionne en mode

non-TPM.

Paramètre

s
context Le FAPI_CONTEXT
keyPath Le chemin vers la clé de chiffrement
plainText Les données en clair à chiffrer
plainTextSize La taille du texte en clair en octets
cipherText Le texte chiffré encodé.
cipherTextSize La taille du texte chiffré
encodé.

Valeurs de

retour
TSS2_RC_SUCCESS si l'appel de fonction a réussi.
TSS2_FAPI_RC_BAD_REFERENCE si context, keyPath, plainText ou cipherText est NULL.
TSS2_FAPI_RC_BAD_CONTEXT si une corruption du contexte est détectée.
TSS2_FAPI_RC_KEY_NOT_FOUND si keyPath ne correspond pas à une clé FAPI.
TSS2_FAPI_RC_BAD_KEY si la clé à keyPath n'est pas adaptée au chiffrement.
TSS2_FAPI_RC_BAD_VALUE si plainTextSize vaut 0.
TSS2_FAPI_RC_BAD_SEQUENCE si le contexte a déjà une opération asynchrone en attente.
TSS2_FAPI_RC_MEMORY si la FAPI ne peut pas allouer assez de mémoire pour les opérations internes ou les paramètres de retour.
TSS2_FAPI_RC_NO_TPM si la FAPI a été initialisée en mode no-TPM via son fichier de configuration.
TSS2_FAPI_RC_IO_ERROR si une erreur s'est produite lors de l'accès au magasin d'objets.
TSS2_FAPI_RC_NOT_IMPLEMENTED si l'algorithme de chiffrement n'est pas disponible.
TSS2_FAPI_RC_TRY_AGAIN si une opération d'E/S n'est pas encore terminée et que cette fonction doit être rappelée.
TSS2_FAPI_RC_PATH_NOT_FOUND si un chemin d'objet FAPI n'a pas été trouvé lors de l'autorisation.
TSS2_FAPI_RC_GENERAL_FAILURE si une erreur interne s'est produite.
TSS2_FAPI_RC_AUTHORIZATION_UNKNOWN si un rappel d'autorisation requis n'est pas défini.
TSS2_FAPI_RC_AUTHORIZATION_FAILED si la tentative d'autorisation échoue.
TSS2_FAPI_RC_POLICY_UNKNOWN si la recherche de politique pour un certain empreinte de politique n'a pas réussi.
TSS2_ESYS_RC_* codes d'erreur possibles d'ESAPI.
TSS2_FAPI_RC_NOT_PROVISIONED la FAPI n'a pas été provisionnée.
TSS2_FAPI_RC_BAD_PATH si le chemin est utilisé dans un co
ntexte inapproprié ou conti
