NOM

falcodump - Extraire les données de journaux dans un fichier à l'aide d'un plugin source Falco.

SYNTAXE

Options communes
falcodump [ --help ] [ --version ] [ --plugin-api-version ] [ --extcap-interfaces ] [ --extcap-dlts ] [ --extcap-interface=<interface> ] [ --extcap-config ] [ --extcap-capture-filter=<filtre de capture> ] [ --capture ] [ --fifo=<chemin vers fichier ou tube> ] [ --plugin-source=<chemin ou URL source> ] [ --log-level=<niveau de journalisation> ] [ --log-file=<chemin vers fichier> ]

Options des appels système
[ --include-capture-processes=<VRAI ou FAUX> ] [ --include-switch-calls=<VRAI ou FAUX> ]

Options du plugin CloudTrail
[ --cloudtrail-s3downloadconcurrency=<nombre de téléchargements simultanés> ] [ --cloudtrail-s3interval=<période> ] [ --cloudtrail-s3accountlist=<liste de comptes séparés par des virgules> ] [ --cloudtrail-sqsdelete=<vrai ou faux> ] [ --cloudtrail-useasync=<vrai ou faux> ] [ --cloudtrail-uses3sns=<vrai ou faux> ] [ --cloudtrail-aws-region=<région AWS> ] [ --cloudtrail-aws-profile=<profil AWS> ] [ --cloudtrail-aws-config=<chemin> ] [ --cloudtrail-aws-credentials=<chemin vers le fichier> ]

DESCRIPTION

falcodump est un outil extcap qui permet d'extraire des messages de journaux des fournisseurs de cloud.

Chaque plugin est répertorié comme une interface distincte. Par exemple, le plugin AWS CloudTrail est répertorié sous le nom de « cloudtrail ».

OPTIONS

--help

Affiche les arguments du programme. Cela listera également les arguments de configuration pour chaque plugin.

--version

Affiche la version du programme.

--plugin-api-version

Affiche la version de l'API des plugins Falco.

--extcap-interfaces

Liste les interfaces disponibles.

--extcap-interface=<interface>

Utilise l'interface spécifiée.

--extcap-dlts

Liste les DLTs de l'interface spécifiée.

--extcap-config

Liste les options de configuration de l'interface spécifiée.

--extcap-capture-filter=<filtre de capture>

Le filtre de capture. Doit être un filtre Sysdig / Falco valide.

--capture

Commence à capturer à partir de la source spécifiée par --plugin-source via l'interface spécifiée et écrit les données brutes des paquets à l'emplacement spécifié par --fifo.

--fifo=<chemin vers fichier ou tube>

Sauvegarde les paquets capturés dans un fichier ou les envoie via un tube.

--plugin-source=<chemin ou URL source du plugin>

Capture à partir de l'emplacement spécifié.

--log-level

Définit le niveau de journalisation

--log-file

Définit un fichier journal pour enregistrer les messages en plus de la console

OPTIONS DES APPELS SYSTÈME

--include-capture-processes

Inclut les appels système pour les processus de capture (falcodump, dumpcap et Stratoshark) si VRAI. Par défaut FAUX.

--include-switch-calls

Inclut les appels « switch » si VRAI. Par défaut FAUX.

PLUGINS

cloudtrail (AWS CloudTrail)

--cloudtrail-s3downloadconcurrency

Contrôle le nombre de goroutines d'arrière-plan utilisées pour télécharger les fichiers S3 (Défaut : 32)

--cloudtrail-s3interval

Télécharge les fichiers journaux sur l'intervalle spécifié (Défaut : pas d'intervalle)

--cloudtrail-s3accountlist

Si la source est un CloudTrail d'organisation, télécharge les fichiers journaux du bucket S3 pour tous les ID de compte spécifiés (Défaut : aucun ID de compte)

--cloudtrail-sqsdelete

Si vrai, le plugin supprimera les messages SQS de la file d'attente immédiatement après les avoir reçus (Défaut : vrai)

--cloudtrail-useasync

Si vrai, l'optimisation d'extraction asynchrone est activée (Défaut : vrai)

--cloudtrail-uses3sns

Si vrai, le plugin s'attendra à ce que les messages SNS proviennent de S3 plutôt que directement de Cloudtrail (Défaut : faux)

--cloudtrail-aws-profile

Si non vide, remplace le profil de configuration partagé AWS (par exemple 'default') et les variables d'environnement telles que AWS_PROFILE (Défaut : vide)

--cloudtrail-aws-region

Si non vide, remplace la région AWS spécifiée dans le profil (par exemple 'us-east-1') et les variables d'environnement telles que AWS_REGION (Défaut : vide)

--cloudtrail-aws-config

Si non vide, remplace le chemin du fichier de configuration partagé AWS (par exemple ~/.aws/config) et les variables d'environnement telles que AWS_CONFIG_FILE (Défaut : vide)

--cloudtrail-aws-credentials

Si non vide, remplace le chemin du fichier d'identifiants partagés AWS (par exemple ~/.aws/credentials) et les variables d'environnement telles que AWS_SHARED_CREDENTIALS_FILE (Défaut : vide)

Les sources CloudTrail peuvent être des buckets S3 ou des URL de files d'attente SQS. Les URL de bucket S3 ont la forme

's3://nom_du_bucket/préfixe/AWSLogs/id_compte/CloudTrail/région/année/mois/jour'

Pour un CloudTrail d'organisation, l'URL du bucket S3 peut être

's3://nom_du_bucket/préfixe/AWSLogs/id_org/id_compte/CloudTrail/région/année/mois/jour'

Les composantes région, année, mois et jour peuvent être omises afin de récupérer plus ou moins de données. Par exemple, la source 's3://mybucket/AWSLogs/012345678/CloudTrail/us-west-2/2023' récupérera tous les journaux CloudWatch pour l'année 2023.

Si l'URL se termine par 'id_compte/' ou 'id_compte/CloudTrail/' (par exemple 's3://mybucket/AWSLOGS/012345678912/') l'option '--cloudtrail-s3interval' peut être utilisée pour définir la période. Un s3interval de '1d' par exemple récupérera tous les événements des dernières 24 heures de toutes les régions disponibles. Un s3interval de '2w-1w' récupérera tous les événements de toutes les régions d'il y a deux semaines jusqu'à il y a une semaine. Le s3interval peut également être défini comme une horodatage de style RFC 3339 comme '2024-02-29T18:07:17Z' ou '2024-02-29T00:00:00Z-2024-03-01T23:59:59Z'.

Si l'URL se termine par 'AWSLogs/id_org', l'option '--cloudtrail-s3accountlist' peut être utilisée pour spécifier les ID de compte. Cela peut être combiné avec '--cloudtrail-s3interval'. Une source telle que 's3://my-org-bucket/AWSLogs/o-123abc/' avec '--cloudstrail-s3accountlist' défini sur '123456789012,987654321098' et '--cloudtrail-s3interval' défini sur '30m' récupérera tous les événements des 30 dernières minutes de toutes les régions pour les comptes 123456789012 et 987654321098.

Si l'URL source est le bucket CloudTrail de l'organisation (comme 's3://my-org-bucket/AWSLogs/o-123abc') et que '--s3accountlist' n'est pas défini, le plugin itère sur tous les comptes (limité par '--s3interval' s'il est défini). Attention : Selon la taille de l'organisation et l'intervalle de temps, cela peut prendre beaucoup de temps.

Le plugin cloudtrail utilise le SDK AWS pour Go, qui peut obtenir les paramètres du profil, de la région et des identifiants à partir d'un ensemble de variables d'environnement et de fichiers de configuration standard https://aws.github.io/aws-sdk-go-v2/docs/configuring-sdk/. Falcodump affichera une liste des profils configurés localement et des régions actuelles, et vous permettra également de fournir une valeur personnalisée.

Plus d'informations sont disponibles dans le README https://github.com/falcosecurity/plugins/blob/master/plugins/cloudtrail/.

EXEMPLES

Pour voir les arguments du programme :

falcodump --help

Pour voir la version du programme :

falcodump --version

Pour voir les interfaces :

falcodump --extcap-interfaces

Une seule interface (falcodump) est prise en charge.

Exemple de sortie

interface {value=cloudtrail}{display=Falco plugin}

Pour voir les DLT des interfaces :

falcodump --extcap-interface=cloudtrail --extcap-dlts

Exemple de sortie

dlt {number=147}{name=cloudtrail}{display=USER0}

Pour voir les options de configuration de l'interface :

falcodump --extcap-interface=cloudtrail --extcap-config

Exemple de sortie

arg {number=0}{call=--plugin-source}{display=Plugin source}{type=string}{tooltip=The plugin data source. This us usually a URL.}{placeholder=Enter a source URL…}{required=true}{group=Capture}
arg {number=1}{call=cloudtrail-s3downloadconcurrency}{display=s3DownloadConcurrency}{type=integer}{default=1}{tooltip=Controls the number of background goroutines used to download S3 files (Default: 1)}{group=Capture}
arg {number=2}{call=cloudtrail-sqsdelete}{display=sqsDelete}{type=boolean}{default=true}{tooltip=If true then the plugin will delete sqs messages from the queue immediately after receiving them (Default: true)}{group=Capture}
arg {number=3}{call=cloudtrail-useasync}{display=useAsync}{type=boolean}{default=true}{tooltip=If true then async extraction optimization is enabled (Default: true)}{group=Capture}

Pour capturer les événements AWS CloudTrail depuis un bucket S3 :

falcodump --extcap-interface=cloudtrail --fifo=/tmp/cloudtrail.pcap --plugin-source=s3://aws-cloudtrail-logs.../CloudTrail/us-east-2/... --capture

ou :

falcodump --capture --extcap-interface cloudtrail --fifo ~/cloudtrail.pcap --plugin-source s3://my-cloudtrail-bucket/AWSLogs/o-abc12345/123456789012/ --cloudtrail-s3downloadconcurrency 32 --cloudtrail-s3interval 5d-2d --cloudtrail-aws-region eu-west-1

Remarque

CTRL + C doit être utilisé pour arrêter la capture afin de garantir une terminaison propre.
