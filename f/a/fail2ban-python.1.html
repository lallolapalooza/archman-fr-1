FAIL2BAN-PYTHON(1) Commandes utilisateur FAIL2BAN-PYTHON(1)

NOM

fail2ban-python - un utilitaire pour Fail2Ban afin de s'assurer que le même Python est utilisé

DESCRIPTION

utilisation : fail2ban-python [option] ... [-c commande | -m module | fichier | -] [arg] ... Options (et variables d'environnement correspondantes) : -b : émet des avertissements concernant str(instance_bytes), str(instance_bytearray)

et la comparaison de bytes/bytearray avec str. (-bb : émet des erreurs)

-B : n'écrit pas de fichiers .pyc lors de l'importation ; aussi PYTHONDONTWRITEBYTECODE=x -c commande : programme passé sous forme de chaîne (termine la liste des options) -d : active la sortie de débogage du parseur (pour experts seulement, ne fonctionne que sur

les builds de débogage) ; aussi PYTHONDEBUG=x

-E : ignore les variables d'environnement PYTHON* (comme PYTHONPATH) -h : affiche ce message d'aide et quitte (aussi -? ou --help) -i : inspecte interactivement après l'exécution du script ; force une invite même

si stdin n'est pas un terminal ; aussi PYTHONINSPECT=x

-I : isole Python de l'environnement de l'utilisateur (implique -E et -s) -m module : exécute un module de bibliothèque comme script (termine la liste des options) -O : supprime les instructions assert et dépendantes de __debug__ ; ajoute .opt-1 avant

l'extension .pyc ; aussi PYTHONOPTIMIZE=x

-OO : effectue les modifications de -O et supprime également les docstrings ; ajoute .opt-2 avant

l'extension .pyc

-P : ne préfixe pas un chemin potentiellement dangereux à sys.path -q : n'affiche pas les messages de version et de copyright au démarrage interactif -s : n'ajoute pas le répertoire de site utilisateur à sys.path ; aussi PYTHONNOUSERSITE -S : n'implique pas 'import site' lors de l'initialisation -u : force les flux stdout et stderr à être non mis en mémoire tampon ;

cette option n'a aucun effet sur stdin ; aussi PYTHONUNBUFFERED=x

-v : verbeux (trace les instructions d'importation) ; aussi PYTHONVERBOSE=x

peut être fourni plusieurs fois pour augmenter la verbosité

-V : affiche le numéro de version de Python et quitte (aussi --version)

lorsqu'il est donné deux fois, affiche plus d'informations sur la construction

-W arg : contrôle des avertissements ; arg est action:message:catégorie:module:numéro_ligne

aussi PYTHONWARNINGS=arg

-x : saute la première ligne de la source, permettant l'utilisation de formes non-Unix de #!cmd -X opt : définit une option spécifique à l'implémentation --check-hash-based-pycs always|default|never:

contrôle comment Python invalide les fichiers .pyc basés sur le hachage

--help-env : affiche l'aide sur les variables d'environnement Python et quitte --help-xoptions : affiche l'aide sur les options -X spécifiques à l'implémentation et quitte --help-all : affiche l'aide complète et quitte Arguments : fichier : programme lu depuis un fichier script - : programme lu depuis stdin (par défaut ; mode interactif si un tty) arg ... : arguments passés au programme dans sys.argv[1:]
