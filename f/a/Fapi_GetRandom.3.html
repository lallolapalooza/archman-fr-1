TSS2_RC Fapi_GetRandom (FAPI_CONTEXT * context, size_t numBytes, uint8_t ** data)

Fonction en un seul appel pour Fapi_GetRandom

Crée un tableau avec un nombre d'octets spécifié. Peut exécuter la commande TPM sous-jacente plusieurs fois si le nombre d'octets demandé est trop grand.

Paramètres

context Le FAPI_CONTEXT
numBytes Le nombre d'octets demandés au TPM
data Le tableau d'octets aléatoires renvoyé par le TPM

Valeurs de retour

TSS2_RC_SUCCESS si l'appel de fonction a réussi.
TSS2_FAPI_RC_BAD_REFERENCE si context ou data est NULL.
TSS2_FAPI_RC_BAD_CONTEXT si une corruption du contexte est détectée.
TSS2_FAPI_RC_BAD_VALUE si numBytes est 0.
TSS2_FAPI_RC_BAD_SEQUENCE si le contexte a déjà une opération asynchrone en attente.
TSS2_FAPI_RC_IO_ERROR si les données ne peuvent pas être sauvegardées.
TSS2_FAPI_RC_MEMORY si FAPI ne peut pas allouer suffisamment de mémoire pour les opérations internes ou les paramètres de retour.
TSS2_FAPI_RC_NO_TPM si FAPI a été initialisé en mode sans TPM via son fichier de configuration.
TSS2_FAPI_RC_PATH_NOT_FOUND si un chemin d'objet FAPI n'a pas été trouvé lors de l'autorisation.
TSS2_FAPI_RC_KEY_NOT_FOUND si une clé n'a pas été trouvée.
TSS2_FAPI_RC_TRY_AGAIN si une opération d'E/S n'est pas encore terminée et que cette fonction doit être appelée à nouveau.
TSS2_FAPI_RC_GENERAL_FAILURE si une erreur interne s'est produite.
TSS2_FAPI_RC_AUTHORIZATION_UNKNOWN si un rappel d'autorisation requis n'est pas défini.
TSS2_FAPI_RC_AUTHORIZATION_FAILED si la tentative d'autorisation échoue.
TSS2_FAPI_RC_POLICY_UNKNOWN si la recherche de politique pour un digest de politique donné n'a pas abouti.
TSS2_ESYS_RC_* codes d'erreur possibles d'ESAPI.
TSS2_FAPI_RC_NOT_PROVISIONED FAPI n'a pas été provisionné.
TSS2_FAPI_RC_BAD_PATH si le chemin est utilisé dans un contexte inapproprié ou contient des caractères illégaux.

TSS2_RC Fapi_GetRandom_Async (FAPI_CONTEXT * context, size_t numBytes)

Fonction asynchrone pour Fapi_GetRandom

Crée un tableau avec un nombre d'octets spécifié. Peut exécuter la commande TPM sous-jacente plusieurs fois si le nombre d'octets demandé est trop grand.

Appelez Fapi_GetRandom_Finish pour terminer l'exécution de cette commande.

Paramètres

context Le FAPI_CONTEXT
numBytes Le nombre d'octets demandés au TPM

TSS2_FAPI_RC_BAD_VALUE si numBytes est 0.
TSS2_FAPI_RC_BAD_SEQUENCE si le contexte a déjà une opération asynchrone en attente.
TSS2_FAPI_RC_IO_ERROR si les données ne peuvent pas être sauvegardées.
TSS2_FAPI_RC_MEMORY si FAPI ne peut pas allouer suffisamment de mémoire pour les opérations internes ou les paramètres de retour.
TSS2_FAPI_RC_NO_TPM si FAPI a été initialisé en mode sans TPM via son fichier de configuration.
TSS2_FAPI_RC_PATH_NOT_FOUND si un chemin d'objet FAPI n'a pas été trouvé lors de l'autorisation.
TSS2_FAPI_RC_KEY_NOT_FOUND si une clé n'a pas été trouvée.
TSS2_FAPI_RC_NOT_PROVISIONED FAPI n'a pas été provisionné.
