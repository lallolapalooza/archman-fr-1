TSS2_RC Fapi_CreateNv (FAPI_CONTEXT * context, char const * path, char const * type, size_t size, char const * policyPath, char const *

authValue)

Fonction à appel unique pour

Fapi_CreateNv

Cette commande crée un index NV dans le TPM en utilisant un chemin et un type

donnés.

Paramètre

s
context Le FAPI_CONTEXT
path Le chemin vers le nouvel index NV
type Le type prévu pour le nouvel index NV. Peut être NULL
size La taille du nouvel index NV en octets. Peut être 0 si la taille est déduite du type
policyPath Le chemin vers la politique associée au nouvel index NV. Peut être NULL
authValue La valeur d'autorisation associée au nouvel index NV. Peut être
NULL

Valeurs de

retour
TSS2_RC_SUCCESS si l'appel de fonction a réussi.
TSS2_FAPI_RC_BAD_REFERENCE si context ou path est NULL.
TSS2_FAPI_RC_BAD_CONTEXT si une corruption du contexte est détectée.
TSS2_FAPI_RC_PATH_ALREADY_EXISTS si un index NV existe déjà à path.
TSS2_FAPI_RC_BAD_VALUE si type n'est pas NULL mais est invalide ou ne correspond pas à la taille.
TSS2_FAPI_RC_BAD_PATH si policyPath n'est pas NULL et ne correspond pas à une politique FAPI, ou si path ne fait pas référence à un chemin d'index NV valide.
TSS2_FAPI_RC_BAD_SEQUENCE si le contexte a déjà une opération asynchrone en attente.
TSS2_FAPI_RC_IO_ERROR si les données ne peuvent pas être enregistrées.
TSS2_FAPI_RC_MEMORY si la FAPI ne peut pas allouer assez de mémoire pour les opérations internes ou les paramètres de retour.
TSS2_FAPI_RC_NO_TPM si la FAPI a été initialisée en mode sans TPM via son fichier de configuration.
TSS2_FAPI_RC_TRY_AGAIN si une opération d'E/S n'est pas encore terminée et que cette fonction doit être rappelée.
TSS2_FAPI_RC_PATH_NOT_FOUND si un chemin d'objet FAPI n'a pas été trouvé lors de l'autorisation.
TSS2_FAPI_RC_KEY_NOT_FOUND si une clé n'a pas été trouvée.
TSS2_FAPI_RC_GENERAL_FAILURE si une erreur interne s'est produite.
TSS2_FAPI_RC_NV_TOO_SMALL si trop de handles NV sont définis.
TSS2_FAPI_RC_AUTHORIZATION_UNKNOWN si un rappel d'autorisation requis n'est pas défini.
TSS2_FAPI_RC_AUTHORIZATION_FAILED si la tentative d'autorisation échoue.
TSS2_FAPI_RC_POLICY_UNKNOWN si la recherche de politique pour un certain empreinte de politique n'a pas réussi.
TSS2_ESYS_RC_* codes d'erreur possibles de l'ESAPI.
TSS2_FAPI_RC_NOT_PROVISIONED la
FAPI n'a pas é
té provisionnée.
