NOM

fail2ban-client - configurer et contrôler le serveur

SYNOPSIS

fail2ban-client [OPTIONS] <COMMANDE>

DESCRIPTION

Fail2Ban v1.1.0 lit un fichier de journal contenant des rapports d'échec de mot de passe et bannit les adresses IP correspondantes à l'aide de règles de pare-feu.

OPTIONS

-c, --conf <DIR>
répertoire de configuration
-s, --socket <FILE>
chemin du socket
-p, --pidfile <FILE>
chemin du fichier pid
--pname <NAME>
nom du processus (thread principal) pour identifier l'instance (par défaut fail2ban-server)
--loglevel <LEVEL>
niveau de journalisation
--logtarget <TARGET>
cible de journalisation, utilisez un nom de fichier ou stdout, stderr, syslog ou sysout.

--syslogsocket auto|<FILE>

-d
affiche la configuration. Pour le débogage
--dp, --dump-pretty
affiche la configuration avec une représentation plus lisible
-t, --test
teste la configuration (peut aussi être spécifié avec les paramètres de démarrage)
-i
mode interactif
-v
augmenter la verbosité
-q
diminuer la verbosité
-x
forcer l'exécution du serveur (supprimer le fichier socket)
-b
démarrer le serveur en arrière-plan (par défaut)
-f
démarrer le serveur au premier plan
--async
démarrer le serveur en mode asynchrone (usage interne uniquement, ne pas lire la configuration)
--timeout
délai d'attente pour le serveur (usage interne uniquement, ne pas lire la configuration)
--str2sec <STRING>
convertir le format d'abréviation de temps en secondes
-h, --help
afficher ce message d'aide
-V, --version
afficher la version (-V retourne un format court lisible par la machine)

COMMANDE

BASIQUE
start
démarre le serveur et les jails
restart
redémarre le serveur
restart [--unban] [--if-exists] <JAIL>
redémarre la jail <JAIL> (alias pour 'reload --restart ... <JAIL>')
reload [--restart] [--unban] [--all]
recharge la configuration sans redémarrer le serveur, l'option '--restart' active le redémarrage complet des jails concernées, ce qui peut débannir des adresses IP (si l'option '--unban' est spécifiée)
reload [--restart] [--unban] [--if-exists] <JAIL>
recharge la jail <JAIL>, ou la redémarre (si l'option '--restart' est spécifiée)
stop
arrête toutes les jails et termine le serveur
unban --all
débannit toutes les adresses IP (dans toutes les jails et la base de données)
unban <IP> ... <IP>
débannit <IP> (dans toutes les jails et la base de données)
banned
retourne les jails avec des IP bannies sous forme de dictionnaire
banned <IP> ... <IP>]
retourne la ou les listes de jails où les IP données sont bannies
status
obtient l'état actuel du serveur
status --all [FLAVOR]
obtient l'état actuel de toutes les jails, avec un type ou des informations étendues optionnels
stat[istic]s
obtient les statistiques actuelles de toutes les jails sous forme de tableau
ping
teste si le serveur est en vie
echo
pour usage interne, renvoie et affiche une chaîne donnée
help
retourne cette sortie
version
retourne la version du serveur
JOURNALISATION
set loglevel <LEVEL>
définit le niveau de journalisation à <LEVEL>. Niveaux : CRITICAL, ERROR, WARNING, NOTICE, INFO, DEBUG, TRACEDEBUG, HEAVYDEBUG ou la valeur numérique correspondante (50-5)
get loglevel
obtient le niveau de journalisation
set logtarget <TARGET>
définit la cible de journalisation à <TARGET>. Peut être STDOUT, STDERR, SYSLOG, SYSTEMD-JOURNAL ou un fichier
get logtarget
obtient la cible de journalisation
set syslogsocket auto|<SOCKET>
définit le chemin du socket syslog à auto ou <SOCKET>. Utilisé uniquement si logtarget est SYSLOG
get syslogsocket
obtient le chemin du socket syslog
flushlogs
vide la cible de journalisation si c'est un fichier et le rouvre. Pour la rotation des journaux.
BASE DE DONNÉES
set dbfile <FILE>
définit l'emplacement du magasin de données persistant de fail2ban. Définir à "None" pour désactiver
get dbfile
obtient l'emplacement du magasin de données persistant de fail2ban
set dbmaxmatches <INT>
définit le nombre maximal de correspondances stockées dans la base de données par ticket
get dbmaxmatches
obtient le nombre maximal de correspondances stockées dans la base de données par ticket
set dbpurgeage <SECONDS>
définit l'âge maximal en <SECONDS> que l'historique des bannissements sera conservé
get dbpurgeage
obtient l'âge maximal en secondes que l'historique des bannissements sera conservé
CONTRÔLE DES JAILS
add <JAIL> <BACKEND>
crée <JAIL> en utilisant <BACKEND>
start <JAIL>
démarre la jail <JAIL>
stop <JAIL>
arrête la jail <JAIL>. La jail est supprimée
status <JAIL> [FLAVOR]
obtient l'état actuel de <JAIL>, avec un type ou des informations étendues optionnels
CONFIGURATION DES JAILS
set <JAIL> idle on|off
définit l'état inactif de <JAIL>d>
set <JAIL> ignoreself true|false
permet d'ignorer ses propres adresses IP
set <JAIL> addignoreip <IP>
ajoute <IP> à la liste d'ignorés de <JAIL>
set <JAIL> delignoreip <IP>
supprime <IP> de la liste d'ignorés de <JAIL>
set <JAIL> ignorecommand <VALUE>
définit ignorecommand de <JAIL>
set <JAIL> ignorecache <VALUE>
définit ignorecache de <JAIL>
set <JAIL> addlogpath <FILE> ['tail']
ajoute <FILE> à la liste de surveillance de <JAIL>, éventuellement en commençant par la 'tail' (fin) du fichier (par défaut 'head' (début)).
set <JAIL> dellogpath <FILE>
supprime <FILE> de la liste de surveillance de <JAIL>
set <JAIL> logencoding <ENCODING>
définit l'<ENCODING> des fichiers journal pour <JAIL>
set <JAIL> addjournalmatch <MATCH>
ajoute <MATCH> au filtre journal de <JAIL>
set <JAIL> deljournalmatch <MATCH>
supprime <MATCH> du filtre journal de <JAIL>
set <JAIL> addfailregex <REGEX>
ajoute l'expression régulière <REGEX> qui doit correspondre aux échecs pour <JAIL>
set <JAIL> delfailregex <INDEX>
supprime l'expression régulière à l'<INDEX> pour failregex
set <JAIL> addignoreregex <REGEX>
ajoute l'expression régulière <REGEX> qui doit correspondre aux motifs à exclure pour <JAIL>
set <JAIL> delignoreregex <INDEX>
supprime l'expression régulière à l'<INDEX> pour ignoreregex
set <JAIL> findtime <TIME>
définit le nombre de secondes <TIME> sur lequel le filtre remontera pour <JAIL>
set <JAIL> bantime <TIME>
définit le nombre de secondes <TIME> pendant lesquelles un hôte sera banni pour <JAIL>
set <JAIL> datepattern <PATTERN>
définit le <PATTERN> utilisé pour faire correspondre les dates/heures pour <JAIL>
set <JAIL> usedns <VALUE>
définit le mode usedns pour <JAIL>
set <JAIL> attempt <IP> [<failure1> ... <failureN>]
notifie manuellement un échec pour <IP>
set <JAIL> banip <IP> ... <IP>
bannit manuellement <IP> pour <JAIL>
set <JAIL> unbanip [--report-absent] <IP> ... <IP>
lève manuellement le bannissement de <IP> dans <JAIL>
set <JAIL> maxretry <RETRY>
définit le nombre d'échecs <RETRY> avant de bannir l'hôte pour <JAIL>
set <JAIL> maxmatches <INT>
définit le nombre maximal de correspondances stockées en mémoire par ticket dans <JAIL>
set <JAIL> maxlines <LINES>
définit le nombre de <LINES> à mettre en tampon pour la recherche par expression régulière pour <JAIL>
set <JAIL> addaction <ACT>[ <PYTHONFILE> <JSONKWARGS>]
ajoute une nouvelle action nommée <ACT> pour <JAIL>. Éventuellement pour une action basée sur Python, un <PYTHONFILE> et <JSONKWARGS> peuvent être spécifiés, sinon ce sera une Action de Commande
set <JAIL> delaction <ACT>
supprime l'action <ACT> de <JAIL>
CONFIGURATION DES ACTIONS DE COMMANDE
set <JAIL> action <ACT> actionstart <CMD>
définit la commande de démarrage <CMD> de l'action <ACT> pour <JAIL>
set <JAIL> action <ACT> actionstop <CMD> définit la commande d'arrêt <CMD> de l'
action <ACT> pour <JAIL>
set <JAIL> action <ACT> actioncheck <CMD>
définit la commande de vérification <CMD> de l'action <ACT> pour <JAIL>
set <JAIL> action <ACT> actionban <CMD>
définit la commande de bannissement <CMD> de l'action <ACT> pour <JAIL>
set <JAIL> action <ACT> actionunban <CMD>
définit la commande de levée de bannissement <CMD> de l'action <ACT> pour <JAIL>
set <JAIL> action <ACT> timeout <TIMEOUT>
définit <TIMEOUT> comme délai d'attente de commande en secondes pour l'action <ACT> pour <JAIL>
CONFIGURATION GÉNÉRALE DES ACTIONS
set <JAIL> action <ACT> <PROPERTY> <VALUE>
définit la <VALUE> de <PROPERTY> pour l'action <ACT> pour <JAIL>
set <JAIL> action <ACT> <METHOD>[ <JSONKWARGS>]
appelle la <METHOD> avec <JSONKWARGS> pour l'action <ACT> pour <JAIL>
INFORMATIONS SUR LA JAIL
get <JAIL> banned
renvoie les IP bannies de <JAIL>
get <JAIL> banned <IP> ... <IP>]
renvoie 1 si l'IP est bannie dans <JAIL> sinon 0, ou une liste de 1/0 pour plusieurs IP
get <JAIL> logpath
obtient la liste des fichiers surveillés pour <JAIL>
get <JAIL> logencoding
obtient l'encodage des fichiers journal pour <JAIL>
get <JAIL> journalmatch
obtient la correspondance du filtre journal pour <JAIL>
get <JAIL> ignoreself
obtient la valeur actuelle de l'ignorance de ses propres adresses IP
get <JAIL> ignoreip
obtient la liste des adresses IP ignorées pour <JAIL>
get <JAIL> ignorecommand
obtient ignorecommand de <JAIL>
get <JAIL> failregex
obtient la liste des expressions régulières qui correspondent aux échecs pour <JAIL>
get <JAIL> ignoreregex
obtient la liste des expressions régulières qui correspondent aux motifs à ignorer pour <JAIL>
get <JAIL> findtime
obtient le temps sur lequel le filtre remontera pour les échecs pour <JAIL>
get <JAIL> bantime
obtient le temps pendant lequel un hôte est banni pour <JAIL>
get <JAIL> datepattern
obtient le motif utilisé pour faire correspondre les dates/heures pour <JAIL>
get <JAIL> usedns
obtient le réglage usedns pour <JAIL>
get <JAIL> banip [<SEP>|--with-time]
obtient la liste des adresses IP bannies pour <JAIL>. Éventuellement le caractère séparateur ('<SEP>', par défaut est l'espace) ou l'option ' --with-time' (imprimant les heures de bannissement) peuvent être spécifiés. Les IP sont ordonnées par fin de bannissement.
get <JAIL> maxretry
obtient le nombre d'échecs autorisés pour <JAIL>
get <JAIL> maxmatches
obtient le nombre maximal de correspondances stockées en mémoire par ticket dans <JAIL>
get <JAIL> maxlines
obtient le nombre de lignes à mettre en tampon pour <JAIL>
get <JAIL> actions
obtient une liste d'actions pour <JAIL>
INFORMATIONS SUR LES ACTIONS DE COMMANDE
get <JAIL> action <ACT> actionstart
obtient la commande de démarrage pour l'action <ACT> pour <JAIL>
get <JAIL> action <ACT> actionstop
obtient la commande d'arrêt pour l'action <ACT> pour <JAIL>
get <JAIL> action <ACT> actioncheck
obtient la commande de vérification pour l'action <ACT> pour <JAIL>
get <JAIL> action <ACT> actionban
obtient la commande de bannissement pour l'action <ACT> pour <JAIL>
get <JAIL> action <ACT> actionunban
obtient la commande de levée de bannissement pour l'action <ACT> pour <JAIL>
get <JAIL> action <ACT> timeout
obtient le délai d'attente de commande en secondes pour l'action <ACT> pour <JAIL>
INFORMATIONS GÉNÉRALES SUR LES ACTIONS
get <JAIL> actionproperties <ACT>
obtient une liste de propriétés pour l'action <ACT> pour <JAIL>
get <JAIL> actionmethods <ACT>
obtient une liste de méthodes pour l'action <ACT> pour <JAIL>
get <JAIL> action <ACT> <PROPERTY>
obtient la valeur de <PROPERTY> pour l'action <ACT> pour <JAIL>
