NOM

faad — Traiter un flux Advanced Audio Codec

SYNTAXE

faad [options] [-w | -o <nom_fichier_sortie> | -a <nom_fichier_sortie>] nom_fichier_entrée

DESCRIPTION

Cet utilitaire fournit une interface en ligne de commande à libfaad2. Ce programme lit les fichiers MPEG‐4 AAC, les traite et les sort au format Microsoft WAV, MPEG‐4 AAC ADTS ou PCM standard.

OPTIONS

-a <nom_fichier>, --adtsout <nom_fichier>
Définit le traitement pour sortir vers le fichier spécifié au format MPEG‐4 AAC ADTS.
-b <nombre>, --bits <nombre>
Définit le format d'échantillon de sortie (individuel). Le nombre prend une des valeurs suivantes :
1 : Données PCM 16 bits (par défaut).
2 : Données PCM 24 bits.
3 : Données PCM 32 bits.
4 : Données en virgule flottante 32 bits.
5 : Données en virgule flottante 64 bits.
-d , --downmix
Définit le traitement pour sous-échantillonner de 5.1 (son surround et basses) à 2 canaux (stéréo).
-f <nombre>, --format <nombre>
Définit le format du fichier de sortie. Le nombre prend une des valeurs suivantes :
1 : Format WAV Microsoft (par défaut).
2 : Données PCM brutes.
-g
Définit le traitement pour ne pas effectuer de décodage sans lacunes.
-h , --help
Affiche un résumé d'utilisation.
-i , --info
Affiche des informations sur le fichier d'entrée.
-l <nombre>, --objecttype <nombre>
Définit le MPEGpe à utiliser pour le traitement. Le nombre prend une des valeurs suivantes :
1 : Type d'objet principal.
2 : Type d'objet Low Complexity (LC) (par défaut).
4 : Type d'objet Long Term Prediction (LTP).
23 : Type d'objet Low Delay (LD).
-o <nom_fichier>, --outfile <nombre>
Définit le nom du fichier pour la sortie du traitement.
-q , --quiet
Silencieux - Supprime les messages d'état pendant le traitement.
-t , --oldformat
Définit le traitement pour utiliser l'ancien format MPEG‐4 AAC ADTS lors de la sortie dans ledit format.
-w , --stdio
Définit la sortie du traitement à envoyer vers la sortie standard.
