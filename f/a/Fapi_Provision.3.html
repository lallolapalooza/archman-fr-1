TSS2_RC Fapi_Provision (FAPI_CONTEXT * context, char const * authValueEh, char const * authValueSh, char const * authValueLockout)

Fonction en un seul appel pour le provisionnement FAPI initial.

Provisionne un TSS avec son TPM. Cela inclut la définition des mots de passe importants et des paramètres de politique, ainsi que la lecture de l'EK et de son certificat, et l'initialisation du keystore système.

Paramètres

context Le FAPI_CONTEXT.
authValueEh La valeur d'autorisation pour la hiérarchie d'endossement. Peut être NULL
authValueSh La valeur d'autorisation pour la hiérarchie de stockage. Devrait être NULL
authValueLockout La valeur d'autorisation pour le verrouillage.

Valeurs de retour

TSS2_RC_SUCCESS si l'appel de fonction a réussi.
TSS2_FAPI_RC_BAD_REFERENCE si context est NULL.
TSS2_FAPI_RC_BAD_CONTEXT si une corruption du contexte est détectée.
TSS2_FAPI_RC_BAD_SEQUENCE si le contexte a déjà une opération asynchrone en attente.
TSS2_FAPI_RC_NO_CERT si aucun certificat n'a été trouvé pour l'EK calculé.
TSS2_FAPI_RC_BAD_KEY si la clé publique de l'EK ne correspond pas au certificat configuré ou si l'empreinte digitale configurée ne correspond pas à l'EK calculé.
TSS2_FAPI_RC_IO_ERROR si les données ne peuvent pas être enregistrées.
TSS2_FAPI_RC_MEMORY si FAPI ne peut pas allouer suffisamment de mémoire pour les opérations internes ou les paramètres de retour.
TSS2_FAPI_RC_NO_TPM si FAPI a été initialisé en mode sans TPM via son fichier de configuration.
TSS2_FAPI_RC_TRY_AGAIN si une opération d'E/S n'est pas encore terminée et que cette fonction doit être appelée à nouveau.
TSS2_FAPI_RC_BAD_VALUE si une valeur invalide a été passée à la fonction.
TSS2_FAPI_RC_AUTHORIZATION_UNKNOWN si une fonction de rappel d'autorisation requise n'est pas définie.
TSS2_FAPI_RC_AUTHORIZATION_FAILED si la tentative d'autorisation échoue.
TSS2_FAPI_RC_GENERAL_FAILURE si une erreur interne s'est produite.
TSS2_FAPI_RC_POLICY_UNKNOWN si la recherche de politique pour un digest de politique donné n'a pas abouti.
TSS2_FAPI_RC_PATH_NOT_FOUND si un chemin d'objet FAPI n'a pas été trouvé pendant l'autorisation.
TSS2_FAPI_RC_KEY_NOT_FOUND si une clé n'a pas été trouvée.
TSS2_ESYS_RC_* codes d'erreur possibles d'ESAPI.
TSS2_FAPI_RC_BAD_PATH si le chemin est utilisé dans un contexte inapproprié ou contient des caractères illégaux.
TSS2_FAPI_RC_NOT_PROVISIONED FAPI n'a pas été provisionné.
TSS2_FAPI_RC_PATH_ALREADY_EXISTS si l'objet existe déjà dans le magasin d'objets.

TSS2_RC Fapi_Provision_Async (FAPI_CONTEXT * context, char const * authValueEh, char const * authValueSh, char const * authValueLockout)

Fonction asynchrone pour le provisionnement FAPI initial.

Provisionne un TSS avec son TPM. Cela inclut la définition des mots de passe importants et des paramètres de politique, ainsi que la lecture de l'EK et de son certificat, et l'initialisation du keystore système.

Appelez Fapi_Provision_Finish pour terminer l'exécution de cette commande.

Paramètres

context Le FAPI_CONTEXT.
authValueEh La valeur d'autorisation pour la hiérarchie d'endossement. Peut être NULL
authValueSh La valeur d'autorisation pour la hiérarchie de stockage. Devrait être NULL
authValueLockout La valeur d'autorisation pour le verrouillage.

Valeurs de retour

TSS2_RC_SUCCESS si l'appel de fonction a réussi.
TSS2_FAPI_RC_BAD_REFERENCE si context est NULL.
TSS2_FAPI_RC_BAD_CONTEXT si une corruption du contexte est détectée.
TSS2_FAPI_RC_BAD_SEQUENCE si le contexte a déjà une opération asynchrone en attente.
TSS2_FAPI_RC_IO_ERROR si les données ne peuvent pas être enregistrées.
TSS2_FAPI_RC_MEMORY si FAPI ne peut pas allouer suffisamment de mémoire pour les opérations internes ou les paramètres de retour.
TSS2_FAPI_RC_NO_TPM si FAPI a été initialisé en mode sans TPM via son fichier de configuration.
TSS2_FAPI_RC_BAD_VALUE si une valeur invalide a été passée à la fonction.
TSS2_FAPI_RC_BAD_PATH si le chemin est utilisé dans un contexte inapproprié ou contient des caractères illégaux.
TSS2_FAPI_RC_PATH_NOT_FOUND si un chemin d'objet FAPI n'a pas été trouvé pendant l'autorisation.
