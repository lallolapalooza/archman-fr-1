FABS(3P) Manuel du programmeur POSIX FABS(3P)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

fabs, fabsf, fabsl — fonction de valeur absolue

SYNOPSIS

#include <math.h>
double fabs(double x);
float fabsf(float x);
long double fabsl(long double x);

DESCRIPTION

La fonctionnalité décrite dans cette page de référence est alignée sur la norme ISO C. Tout conflit entre les exigences décrites ici et la norme ISO C est involontaire. Ce volume de POSIX.1‐2017 s'en remet à la norme ISO C.

Ces fonctions calculent la valeur absolue de leur argument x, |x|.

VALEUR DE RETOUR

En cas de succès, ces fonctions retournent la valeur absolue de x.

Si x est NaN, un NaN est retourné.

Si x est ±0, +0 est retourné.

Si x est ±Inf, +Inf est retourné.

ERREURS

Aucune erreur n'est définie.

Les sections suivantes sont informatives.

EXEMPLES

Calcul de la norme 1 d'un vecteur à virgule flottante

Cet exemple montre l'utilisation de fabs() pour calculer la norme 1 d'un vecteur définie comme suit :

norme1(v) = |v[0]| + |v[1]| + ... + |v[n-1]|

où |x| désigne la valeur absolue de x, n désigne la dimension du vecteur et v[i] désigne la i-ème composante de v (0≤i<n).

#include <math.h>
double
norme1(const double v[], const int n)
{
    int     i;
    double  n1_v;  /* norme 1 de v */
    n1_v = 0;
    for (i=0; i<n; i++) {
        n1_v += fabs (v[i]);
    }
    return n1_v;
}
