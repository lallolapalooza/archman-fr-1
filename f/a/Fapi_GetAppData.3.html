TSS2_RC Fapi_GetAppData (FAPI_CONTEXT * context, char const * path, uint8_t ** appData, size_t * appDataSize)

Fonction en un seul appel pour Fapi_GetAppData

Chaque objet a un champ de description qui peut être récupéré afin d'obtenir des informations supplémentaires dans son entrée 'path'.

Paramètres

context Le FAPI_CONTEXT
path Le chemin de l'objet pour lequel les appData sont retournés
appData Une copie des appData. Peut être NULL (alloué par l'appelé)
appDataSize La taille des AppData retournés. Peut être NULL

Valeurs de retour

TSS2_RC_SUCCESS si l'appel de la fonction a réussi.
TSS2_FAPI_RC_BAD_REFERENCE si context ou path est NULL.
TSS2_FAPI_RC_BAD_CONTEXT si une corruption du contexte est détectée.
TSS2_FAPI_RC_BAD_PATH si le chemin ne correspond à aucune entité FAPI.
TSS2_FAPI_RC_BAD_SEQUENCE si le contexte a déjà une opération asynchrone en attente.
TSS2_FAPI_RC_IO_ERROR si les données ne peuvent pas être sauvegardées.
TSS2_FAPI_RC_MEMORY si le FAPI ne peut pas allouer suffisamment de mémoire pour les opérations internes ou les paramètres de retour.
TSS2_FAPI_RC_NO_TPM si le FAPI a été initialisé en mode sans TPM via son fichier de configuration.
TSS2_FAPI_RC_PATH_NOT_FOUND si un chemin d'objet FAPI n'a pas été trouvé lors de l'autorisation.
TSS2_FAPI_RC_KEY_NOT_FOUND si une clé n'a pas été trouvée.
TSS2_FAPI_RC_BAD_VALUE si une valeur invalide a été passée à la fonction.
TSS2_FAPI_RC_TRY_AGAIN si une opération d'E/S n'est pas encore terminée et que cette fonction doit être appelée à nouveau.
TSS2_FAPI_RC_GENERAL_FAILURE si une erreur interne s'est produite.
TSS2_FAPI_RC_NOT_PROVISIONED FAPI n'a pas été provisionné.
