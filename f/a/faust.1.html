DESCRIPTIO

N

Faust (Functional Audio Stream) est un langage de programmation fonctionnel spécialement conçu pour

le traitement et la synthèse de signaux en temps réel. Faust cible les applications de traitement
de signaux haute performance et les plug-ins audio pour une variété de plateformes et de standards.

OPTION

S

Options d'entrée

:

-a <fichier> fichier d'architecture

wrapper.

-i --inline-architecture-files intégrer les fichiers

d'architecture.

-A <rép> --architecture-dir <rép> ajouter le répertoire <rép> au chemin de recherche des

architectures.

-I <rép> --import-dir <rép> ajouter le répertoire <rép> au chemin de recherche des

bibliothèques.

-L <fichier> --library <fichier> lier avec

le module
LLVM <fichier>.

Options de sortie

:

-o <fichier> le fichier de

sortie.

-e --export-dsp exporter le DSP étendu (avec toutes les bibliothèques incluses)

.

-uim --user-interface-macros ajouter les définitions de macros d'interface utilisateur au code de

sortie.

-xml générer un fichier de description

XML.

-json générer un fichier de description

JSON.

-O <rép> --output-dir <rép> spécifier le répertoire relatif du code de sortie généré et des fichiers supplémentaires générés (SVG, XML...

)
.

Options de génération de code

:

-lang <lang> --language sélectionner le langage de sortie, `lang' doit être c, cpp (par défaut), cmajor, codebox, csharp, dlang, fir, interp, java, jax, jsfx, julia, llvm, ocpp, rust, sdf3, vhdl ou

wast/wasm.

-single --single-precision-floats utiliser des flottants de précision simple pour les calculs internes (par défaut)

.

-double --double-precision-floats utiliser des flottants de double précision pour les calculs

internes.

-quad --quad-precision-floats utiliser des flottants de quadruple précision pour les calculs

internes.

-fx --fixed-point utiliser le virgule fixe pour les calculs

internes.

-fx-size --fixed-point-size taille totale du nombre en virgule fixe en bits (-1 est utilisé pour générer un type fixpoint_t unique)

.

-es 1|0 --enable-semantics 1|0 utiliser les sémantiques d'activation quand 1 (par défaut), et une simple multiplication

sinon.

-lcc --local-causality-check vérifier la causalité aussi au niveau

local.

-light --light-mode ne pas générer l'ensemble de l'API

DSP.

-clang --clang lorsqu'il est compilé avec clang/clang++, ajoute des #pragma spécifiques pour la vectorisation

automatique.

-nvi --no-virtual lorsqu'il est compilé avec le backend C++, n'ajoute pas le mot-clé

`virtual'.

-fp --full-parentheses toujours ajouter des parenthèses autour des opérateurs

binaires.

-cir --check-integer-range vérifier la conversion de plage flottant vers

entier.

-exp10 --generate-exp10 pow(10,x) remplacé par exp10(x) potentiellement plus

rapide.

-os --one-sample générer le calcul d'un

échantillon.

-ec --external-control séparer les fonctions `control' et

`compute'.

-it --inline-table intégrer le code rdtable/rwtable dans la classe

principale.

-cm --compute-mix mélanger dans les tampons de

sortie.

-ct --check-table vérifier la plage d'index de rtable/rwtable et générer du code d'accès sûr [0/1 : 1 par défaut]

.

-cn <nom> --class-name <nom> spécifier le nom de la classe dsp à utiliser à la place de

mydsp.

-scn <nom> --super-class-name <nom> spécifier le nom de la super-classe à utiliser à la place de

dsp.

-pn <nom> --process-name <nom> spécifier le nom du point d'entrée dsp à la place de

process.

-mcd <n> --max-copy-delay <n> utiliser un délai par copie jusqu'au délai max <n> et un délai dense au-delà (ocpp uniquement) ou un tampon circulaire (16 échantillons par défaut)

.

-mdd <n> --max-dense-delay <n> utiliser un délai dense jusqu'au délai max <n> (si densité suffisante) et un délai par tampon circulaire au-delà (ocpp uniquement, 1024 par défaut)

.

-mdy <n> --min-density <n> densité minimale (100*nombre de délais/délai max) pour utiliser des délais denses (ocpp uniquement, 33 par défaut)

.

-dlt <n> --delay-line-threshold <n> utiliser des tampons circulaires basés sur un masque pour les délais jusqu'au délai max <n> et des tampons circulaires basés sur select au-delà (INT_MAX échantillons par défaut)

.

-mem --memory-manager allocations effectuées à l'aide d'un gestionnaire de mémoire

personnalisé.

-mem1 --memory-manager1 allocations effectuées à l'aide d'un gestionnaire de mémoire personnalisé, utilisant le modèle iControl/fControl et

iZone/fZone.

-mem2 --memory-manager2 utiliser le modèle iControl/fControl, iZone/fZone et pas de gestionnaire de mémoire

explicite.

-mem3 --memory-manager3 utiliser le modèle iControl/fControl, iZone/fZone et pas de gestionnaire de mémoire explicite avec l'accès en paramètres de

fonction.

-ftz <n> --flush-to-zero <n> code ajouté aux signaux récursifs [0 : non (par défaut), 1 : basé sur fabs, 2 : basé sur masque (le plus rapide)]

.

-rui --range-ui s'il faut générer du code pour contraindre les valeurs vslider/hslider/nentry dans la plage [min..max]

.

-fui --freeze-ui s'il faut geler vslider/hslider/nentry à une valeur donnée (valeur initiale par défaut)

.

-inj <f> --inject <f> injecter le fichier source <f> dans le fichier d'architecture au lieu de compiler un fichier

dsp.

-scal --scalar générer du code non vectorisé (par défaut)

.

-inpl --in-place générer du code fonctionnel lorsque les tampons d'entrée et de sortie sont identiques (mode scalaire uniquement)

.

-vec --vectorize générer du code plus facile à

vectoriser.

-vs <n> --vec-size <n> taille du vecteur (32 échantillons par défaut)

.

-lv <n> --loop-variant <n> [0 : le plus rapide, taille de vecteur fixe et une boucle résiduelle (par défaut), 1 : simple, taille de vecteur variable, 2 : fixe, taille de vecteur fixe]

.

-omp --openmp générer des pragmas OpenMP, active l'option

--vectorize.

-pl --par-loop générer des boucles parallèles en mode

--openmp.

-sch --scheduler générer des tâches et utiliser un ordonnanceur Work Stealing, active l'option

--vectorize.

-ocl --opencl générer des tâches avec OpenCL (expérimental)

.

-cuda --cuda générer des tâches avec CUDA (expérimental)

.

-dfs --deep-first-scheduling ordonnancer les boucles vectorielles en ordre profond

d'abord.

-g --group-tasks regrouper les tâches séquentielles mono-thread lorsque -omp ou -sch est

utilisé.

-fun --fun-tasks séparer le code des tâches en fonctions séparées (en mode -vec, -sch ou -omp)

.

-fm <fichier> --fast-math <fichier> utiliser des versions optimisées des fonctions mathématiques implémentées dans <fichier>, utiliser `faust/dsp/fastmath.cpp' quand le fichier est `def', supposer que les fonctions sont définies dans le fichier d'architecture quand le fichier est

`arch'.

-mapp --math-approximation versions plus simples/plus rapides des fonctions `floor/ceil/fmod/remainder'

.

-noreprc --no-reprc (Rust uniquement) Ne pas forcer la disposition de la structure dsp à suivre l'ABI

C.

-ns <nom> --namespace <nom> générer du code C++ ou D dans un espace de noms <nom>

.

-vhdl-trace --vhdl-trace activer la

trace.

-vhdl-float --vhdl-float utiliser le format IEEE-754 pour les échantillons au lieu du virgule

fixe.

-vhdl-components <fichier> --vhdl-components <fichier> chemin vers un fichier décrivant des composants personnalisés pour le backend

VHDL.

-fpga-mem <n> --fpga-mem <n> taille max de la RAM par bloc FPGA, utilisée en mode

-mem1/-mem2.

-wi <n> --widening-iterations <n> nombre d'itérations avant l'élargissement dans le délimitage de

signal.

-ni <n> --narrowing-iterations <n> nombre d'itérations avant d'arrêter le rétrécissement dans le délimitage de

signal.

-rnt --rust-no-faustdsp-trait (Rust uniquement) Ne pas générer l'implémentation du trait

FaustDsp.

-rnlm --rust-no-libm (Rust uniquement) Ne pa

s générer d'ap
pels FFI vers libm.

Options de diagramme en blocs

:

-ps --postscript imprimer le diagramme en blocs dans un fichier

postscript.

-svg --svg imprimer le diagramme en blocs dans un fichier

svg.

-sd --simplify-diagrams essayer de simplifier davantage les diagrammes avant de les

dessiner.

-drf --draw-route-frame dessiner les cadres de routage au lieu de simples

câbles.

-f <n> --fold <n> seuil pour activer le mode pliage lors de la génération du diagramme en blocs (par défaut 25 éléments)

.

-fc <n> --fold-complexity <n> seuil de complexité pour plier une expression en mode pliage (par défaut 2)

.

-mns <n> --max-name-size <n> seuil lors de la génération du diagramme en blocs (par défaut 40 caractères)

.

-sn --simple-names utiliser des noms simples (sans arguments) lors de la génération du diagramme en

blocs.

-blur --shadow-blur ajouter un flou d'ombre aux boîtes

SVG.

-sc --scaled-svg SVG redime

nsionnable
automatique.

Options de documentation mathématique

:

-mdoc --mathdoc imprimer la documentation mathématique du programme Faust au format LaTeX dans un dossier

-mdoc.

-mdlang <l> --mathdoc-lang <l> si le fichier de traduction existe (<l> = en, fr, ...)

.

-stripmdoc --strip-mdoc-tags supprimer les balises mdoc lor

s de l'impression d
es listages Faust -mdoc.

Options de débogage

:

-d --details imprimer les détails de

compilation.

-time --compilation-time afficher les informations de chronométrage des phases de

compilation.

-flist --file-list imprimer la liste des fichiers (y compris les bibliothèques) utilisés pour évaluer le

processus.

-tg --task-graph imprimer le graphe de tâches interne au format

dot.

-sg --signal-graph imprimer le graphe de signaux interne au format

dot.

-rg --retiming-graph imprimer le graphe de signaux interne après recalcul des horodatages au format

dot.

-norm --normalized-form imprimer les signaux sous forme normalisée et

quitter.

-norm1 --normalized-form1 imprimer les signaux sous forme normalisée avec des identifiants pour les sous-expressions partagées et

quitter.

-me --math-exceptions vérifier / comme dénominateur et reste, domaine des fonctions fmod, sqrt, log10, log, acos,

asin.

-sts --strict-select générer du code strict pour `selectX' même pour les branches sans état (les deux sont calculées)

.

-wall --warning-all imprimer tous les

avertissements.

-t <sec> --timeout <sec> interrompre la compila

tion après <sec> secon
des (par défaut 120).

d'aide.

-libdir --libdir imprimer le répertoire contenant les bibliothèques

Faust.

-includedir --includedir imprimer le répertoire contenant les en-têtes

Faust.

-archdir --archdir imprimer le répertoire contenant les architectures

-dspdir --dspdir imprimer le répertoire contenant les bibliothèques dsp
