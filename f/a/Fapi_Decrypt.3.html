plainTextSize)

Fonction à un seul appel pour

Fapi_Decrypt

Déchiffre des données qui ont été précédemment chiffrées avec

Fapi_Encrypt.

Paramètre

s
context Le FAPI_CONTEXT
keyPath La clé de déchiffrement.
cipherText Le texte chiffré à déchiffrer.
cipherTextSize La taille du texte chiffré à déchiffrer.
plainText le texte chiffré déchiffré. Peut être NULL (alloué par l'appelant)
plainTextSize La taille du texte chiffré en octets. Peut être
NULL

Valeurs de

retour
TSS2_RC_SUCCESS si l'appel de fonction a été un succès.
TSS2_FAPI_RC_BAD_REFERENCE si context ou cipherText est NULL.
TSS2_FAPI_RC_BAD_CONTEXT si une corruption du contexte est détectée.
TSS2_FAPI_RC_KEY_NOT_FOUND si la clé nécessaire pour déchiffrer le fichier ne peut pas être trouvée.
TSS2_FAPI_RC_BAD_KEY si la clé de déchiffrement est inadaptée à l'opération demandée.
TSS2_FAPI_RC_BAD_VALUE si le déchiffrement échoue
TSS2_FAPI_RC_BAD_SEQUENCE si le contexte a déjà une opération asynchrone en attente.
TSS2_FAPI_RC_IO_ERROR si les données ne peuvent pas être enregistrées.
TSS2_FAPI_RC_MEMORY si la FAPI ne peut pas allouer assez de mémoire pour les opérations internes ou les paramètres de retour.
TSS2_FAPI_RC_NO_TPM si la FAPI a été initialisée en mode sans TPM via son fichier de configuration.
TSS2_FAPI_RC_GENERAL_FAILURE si une erreur interne s'est produite.
TSS2_FAPI_RC_TRY_AGAIN si une opération d'E/S n'est pas encore terminée et que cette fonction doit être rappelée.
TSS2_FAPI_RC_PATH_NOT_FOUND si un chemin d'objet FAPI n'a pas été trouvé pendant l'autorisation.
TSS2_FAPI_RC_AUTHORIZATION_UNKNOWN si un rappel d'autorisation requis n'est pas défini.
TSS2_FAPI_RC_AUTHORIZATION_FAILED si la tentative d'autorisation échoue.
TSS2_FAPI_RC_POLICY_UNKNOWN si la recherche de politique pour un certain empreinte de politique n'a pas réussi.
TSS2_ESYS_RC_* codes d'erreur possibles d'ESAPI.
TSS2_FAPI_RC_NOT_PROVISIONED La FAPI n'a pas été provisionnée.
