Nom

feedbackd - Un démon pour fournir des retours sur les événements

SYNTAXE

feedbackd [OPTIONS...]

DESCRIPTION

Feedbackd est un démon qui s'exécute dans la session de l'utilisateur pour déclencher des retours d'événements tels que la lecture d'un son, le déclenchement d'un moteur haptique ou le clignotement d'une LED.

Le retour déclenché par un événement donné est déterminé par le thème de retour utilisé (voir feedback-themes(5)). Les événements sont soumis via une API DBus.

Tout retour déclenché par un client via un événement sera arrêté au plus tard lorsque le client se déconnectera de DBus. Cela garantit que tous les retours sont annulés si l'application qui les a déclenchés plante.

Pour plus de détails, consultez les spécifications des événements et des thèmes de retour sur https://gitlab.freedesktop.org/agx/feedbackd/.

Feedbackd recharge le thème de retour sur SIGHUP (c'est-à-dire pkill -HUP feedbackd).

Options

-h, --help
affiche l'aide et quitte

Configuration

Ces gsettings sont utilisés par feedbackd:

•
org.gnome.desktop.sound
•
sound-theme: Le thème sonore utilisé pour les événements sonores
•
org.sigxcpu.feedbackd
  • profile: Le profil global de retour actuel. Les valeurs valides sont full, quiet et silent.
  • allow-important: Liste des applications qui peuvent outrepasser le niveau de retour global (utile, par exemple, pour permettre à l'horloge d'alarme d'émettre également un son lorsque l'appareil est en mode silencieux).
  • prefer-flash: Préfère le flash de l'appareil photo à la LED d'état.
  • theme: Le thème de retour à utiliser. Ceci peut être utilisé pour remplacer le thème de retour choisi par feedbackd en fonction des informations de l'appareil.
  • max-haptic-strength: Limite la force maximale utilisée pour le moteur haptique [0.0, 1.0].
•
org.sigxcpu.feedbackd.application
•
profile: Niveaux de profil par application. Les valeurs valides sont
full, quiet et silent.
