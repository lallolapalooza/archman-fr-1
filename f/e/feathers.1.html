NOM

feathers — un débogueur simple au niveau source pour CHICKEN Scheme

SYNTAXE

feathers [OPTION ...] [PROGRAMME ARGUMENTS ...]

DESCRIPTION

feathers exécute un programme compilé avec CHICKEN Scheme et permet un débogage basique au niveau source comme la définition de points d'arrêt, le pas à pas et l'inspection des arguments de procédure et des variables globales.

Le code Scheme doit être compilé avec le niveau de débogage 3 pour que le débogage soit possible. La communication avec le débogueur se fait en échangeant des messages via un socket TCP, l'adresse et le port étant donnés par la variable d'environnement CHICKEN_DEBUGGER qui contient une adresse de connexion de la forme ⟨ADRESSE⟩:⟨PORT⟩.

PROGRAMME doit fournir le chemin vers l'exécutable à lancer, PATH n'est pas recherché.

Le programme accepte les arguments suivants :

-help
Affiche une liste des options de ligne de commande prises en charge.
-n
Ne pas charger le fichier de démarrage par défaut .feathers.
-d
TODO : Documenter ceci
-dir RÉPERTOIRE
Ajoute RÉPERTOIRE à la liste des chemins recherchés pour localiser les fichiers source.
-port PORT
Sélectionne un port TCP différent du port par défaut (9999).

ENVIRONNEMENT

Les variables d'environnement suivantes modifient le comportement de feathers :

CHICKEN_DEBUGGER
Doit contenir une adresse et un port TCP sur lesquels le débogueur est à l'écoute. Cette variable est définie par le débogueur lorsqu'un programme est lancé depuis celui-ci, et vaut par défaut localhost:9999.

CODE DE SORTIE

L'utilitaire feathers se termine avec le code 0 en cas de succès, et >0 en cas d'erreur.

VOIR AUSSI

Plus d'informations peuvent être trouvées dans le Manuel de l'utilisateur CHICKEN.
