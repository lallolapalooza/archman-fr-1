Le mode diaporama est le mode par défaut. Il ouvre une fenêtre et y affiche la première image ; la position dans le diaporama peut avancer (ou être modifiée autrement) à l'aide de raccourcis clavier et souris. En mode diaporama, les images peuvent être supprimées soit de la liste de fichiers, soit du disque ; une liste de fichiers modifiée peut également être enregistrée sur le disque et rouverte ultérieurement. Une image peut aussi être lue depuis stdin via « feh - ». Le mode montage forme un montage à partir de la liste de fichiers. L'image résultante peut être visualisée ou enregistrée, et sa taille peut être limitée par la hauteur, la largeur ou les deux. Le mode index forme une planche d'épreuvages à partir de la liste de fichiers. Les vignettes des images sont affichées avec le nom du fichier, la taille et les dimensions, imprimées avec une police truetype de votre choix. L'image résultante peut être visualisée ou enregistrée, et sa taille peut être limitée par la hauteur, la largeur ou les deux. Le mode vignettes est semblable au mode index, mais les mini-images sont cliquables et ouvrent l'image sélectionnée dans une nouvelle fenêtre. Le mode multi-fenêtres affiche les images dans plusieurs fenêtres, au lieu d'un diaporama dans une seule fenêtre. N'utilisez pas avec une longue liste de fichiers ;) Le mode liste n'affiche pas d'images. À la place, il produit une liste de fichi

taille
Définit le cache en mémoire d'imlib2 à taille Mio. Une taille de cache plus élevée peut améliorer considérablement les performances, en particulier pour les petits diaporamas, mais au prix d'une consommation mémoire accrue. taille doit être comprise entre 0 et 2048 Mio et vaut par défaut 4.
-P, --cache-thumbnails
Active la mise en cache des miniatures. Les miniatures sont enregistrées dans $XDG_CACHE_HOME/thumbnails, qui correspond par défaut à ~/.cache/thumbnails. Notez que les miniatures ne sont mises en cache que si la taille configurée des miniatures ne dépasse pas 256x256 pixels.
-K, --caption-path chemin
Chemin vers le répertoire contenant les légendes des images. Cela active l'affichage des légendes, et si des légendes sont trouvées dans chemin, qui est relatif au répertoire de chaque image, elles sont superposées à l'image affichée. Par exemple, avec le chemin de légendes "captions/" et l'affichage de l'image "images/foo.jpg", la légende sera recherchée dans "images/captions/foo.jpg.txt".
--conversion-timeout délai
feh peut utiliser ImageMagick pour tenter de convertir des fichiers non chargeables dans un format de fichier pris en charge. Comme cela peut prendre beaucoup de temps, cette fonction est désactivée par défaut. Définissez délai à une valeur non négative pour l'activer. Une valeur positive spécifie le nombre de secondes après lesquelles les tentatives de conversion doivent être abandonnées, zéro fait que feh tentera indéfiniment. Les valeurs négatives restaurent le comportement par défaut en désactivant complètement la conversion.

--edit
Active l'édition de base des fichiers. Cela fait que la rotation et le miroir (liés à "<", ">", "|", et "_" par défaut) modifient le fichier sous-jacent et pas seulement son contenu affiché.
-f, --filelist fichier
Cette option est similaire aux listes de lecture utilisées par les logiciels de musique. Si fichier existe, il sera lu pour obtenir une liste de fichiers à charger, dans l'ordre où ils apparaissent. Le format est une liste de noms de fichiers d'images, absolus ou relatifs au répertoire courant, un nom de fichier par ligne.

Si fichier n'existe pas, il sera créé à partir de la liste de fichiers interne à la fin d'une session de visualisation. C'est le meilleur moyen de stocker les résultats de tris complexes (-Spixels par exemple) pour une visualisation ultérieure.

Toute modification de la liste de fichiers interne (comme la suppression d'un fichier ou son élimination car il n'est pas chargeable) sera enregistrée dans fichier lorsque feh se termine. Vous pouvez ajouter des fichiers aux listes de fichiers en les spécifiant sur la ligne de commande lorsque vous spécifiez également la liste.

Si fichier est "-", feh lira la liste de fichiers depuis son entrée standard.

-I, --fullindex
Identique au mode index, mais avec des informations supplémentaires sous les miniatures. Fonctionne exactement comme "feh --index --index-info "%n\n%S\n%wx%h"". Active OPTIONS DU MODE MONTAGE.

Note : Cette option nécessite de charger toutes les images pour calculer les dimensions de la fenêtre feh , donc lors de son utilisation avec de nombreux fichiers, il faudra un certain temps avant qu'une fenêtre feh ne soit visible. Utilisez --preload pour obtenir une barre de progression.

-F, --fullscreen
Rend la fenêtre plein écran. Notez que dans ce mode, les grandes images seront toujours réduites pour s'adapter à l'écran, et --zoom le zoom n'affecte que les plus petites images et n'agrandit jamais plus que nécessaire pour s'adapter à la taille de l'écran. La seule exception est un zoom de 100, auquel cas les images seront toujours affichées à 100% de zoom.

Lorsqu'il est combiné avec --thumbnails, cette option n'affecte que les images ouvertes depuis l'aperçu des miniatures. La liste des miniatures elle-même restera dans une fenêtre.

-g, --geometry largeur x hauteur | + x + y | largeur x hauteur + x + y
Utilise une taille de fenêtre fixe telle que spécifiée dans la chaîne de géométrie de style X chaîne, par ex. 640x480. Un décalage de fenêtre optionnel +x+y peut être spécifié. Combinez avec --scale-down pour réduire les images plus grandes comme en mode plein écran. Notez que cette option n'impose pas la taille de la fenêtre ; il est toujours possible de la modifier par un gestionnaire de fenêtres en mosaïque ou manuellement. Cependant, le redimensionnement automatique reste désactivé.
-Y, --hide-pointer
Masque le pointeur (utile pour les diaporamas).
-B, --image-bg style
Utilise style comme arrière-plan pour les parties transparentes des images et similaires. Valeurs acceptées : default, checks, ou une XColor (par ex. "black" ou "#428bdd"). Notez que certains interpréteurs de commandes traitent le caractère dièse comme un caractère spécial, vous devrez donc peut-être le mettre entre guillemets ou l'échapper pour que le code XColor fonctionne. En mode fenêtré, la valeur par défaut est checks (un fond en damier pour que les parties transparentes des images soient facilement visibles). En mode plein écran et en mode définition d'arrière-plan, checks n'est pas accepté et la valeur par défaut est black.
-i, --index
Active le mode Index. Le mode Index est similaire au mode montage, et accepte les mêmes options. Il crée une planche d'index de miniatures, imprimant le nom de l'image sous chaque miniature. Le mode Index active certaines autres options, voir OPTIONS DES MODES INDEX ET MINIATURES et OPTIONS DU MODE MONTAGE.
--info [drapeau]ligne_de_commande
Exécute ligne_de_commande et affiche sa sortie dans le coin inférieur gauche de l'image. Peut être utilisé pour afficher par ex. les dimensions de l'image ou des informations EXIF. Prend en charge les SPÉCIFICATEURS DE FORMAT. Si drapeau est défini à ";", la sortie ne sera pas affichée par défaut, mais devra être activée par la touche toggle_info.
--insecure
Lors de la visualisation de fichiers avec HTTPS, cette option désactive toutes les vérifications de certificats. Elle permet d'ouvrir des images sur des sites avec des certificats auto-signés ou expirés, mais n'est pas plus sécurisé que le HTTP simple.
-k, --keep-http
Lors de la visualisation de fichiers utilisant HTTP, feh supprime normalement les copies locales après visualisation, ou, en cas de mise en cache, à la sortie. Cette option les stocke définitivement sur disque, soit dans le répertoire spécifié par --output-dir, soit dans le répertoire de travail courant.
--keep-zoom-vp
Lors du changement d'image, conserve les paramètres de zoom et de zone d'affichage (niveau de zoom et décalages X, Y)
-l, --list
N'affiche pas les images. Les analyse et affiche une liste de style ls(1) - style . Utile dans les scripts pour rechercher des images d'une certaine taille/résolution/type etc.
-U, --loadable
N'affiche pas les images. Imprime simplement leurs noms si imlib2 peut les charger avec succès. Renvoie faux si au moins une image a échoué à se charger. Lorsqu'il est combiné avec --action, l'action spécifiée sera exécutée pour chaque image chargeable.
--max-dimension largeur x hauteur
N'affiche que les images dont la largeur <= largeur et la hauteur <= hauteur. Si vous ne vous souciez que d'un seul paramètre, définissez l'autre à 0 (ou une valeur négative).
-M, --menu-font police
Utilise police (truetype, avec taille, comme "yudit/12") comme police de menu.
--min-dimension largeur x hauteur
N'affiche que les images dont la largeur >= largeur et la hauteur >= hauteur. Si vous ne vous souciez que d'un seul paramètre, définissez l'autre à 0.
-m, --montage
Active le mode montage. Le mode montage crée une nouvelle image composée d'une grille de miniatures des images de la liste de fichiers. Lorsque le mode montage est sélectionné, certaines autres options deviennent disponibles. Voir OPTIONS DU MODE MONTAGE.
-w, --multiwindow
Désactive le mode diaporama. Avec ce réglage, au lieu d'ouvrir plusieurs fichiers en mode diaporama, plusieurs fenêtres seront ouvertes ; une par fichier.
--no-conversion-cache
Lors du chargement d'images via HTTP, ImageMagick ou dcraw, feh ne chargera/convertira les images qu'une seule fois et réutilisera le fichier en cache lors des passages suivants du diaporama. Cette option désactive le cache. Il est également désactivé lorsque --reload est utilisé. Utilisez-le si vous dépendez de fichiers changeant fréquemment chargés via l'une de ces sources. Notez que cela dégradera les performances.
--no-jump-on-resort
Ne saute pas à la première image après le réordonnancement de la liste de fichiers.
-N, --no-menus
Ne charge ni n'affiche aucun menu.
--no-screen-clip
Par défaut, la taille des fenêtres est limitée à la taille de l'écran. Avec cette option, les fenêtres auront la taille de l'image qu'elles contiennent. Notez qu'elles peuvent devenir très grandes de cette façon, les rendant ingérables dans certains gestionnaires de fenêtres.
--no-xinerama
(fonctionnalité optionnelle, activée dans cette version) Désactive le support de Xinerama.
--on-last-slide hold | quit | resume
Sélectionne le comportement lors de la tentative de sélection de l'image suivante sur la dernière diapositive (ou de l'image précédente sur la première diapositive) dans un diaporama.

Avec hold, feh cessera d'avancer les images dans ce cas et continuera d'afficher respectivement la première/la dernière image. Ceci est destiné aux diaporamas linéaires. Le comportement n'est pas spécifié lors de l'utilisation d'autres commandes de navigation que l'image précédente et suivante.

quit fera que feh quittera lors de la tentative d'avancer au-delà de la dernière image du diaporama. C'est le comportement de l'option obsolète --cycle-once .

resume est le comportement par défaut : sur la dernière (première) image, feh bouclera jusqu'à la première (dernière) image.

-j, --output-dir répertoire
Enregistre les fichiers dans répertoire lors de l'utilisation de --keep-http ou de la commande save_image ou save_filelist. Par défaut, les fichiers sont enregistrés dans le répertoire de travail courant.
-p, --preload
Précharge les images. Cela ne signifie pas les garder en RAM, cela signifie les parcourir et éliminer d'abord les images non chargeables. Sinon, elles seront supprimées au fur et à mesure que vous les parcourez. Cela analyse également les images pour obtenir des données à utiliser pour le tri, telles que la taille en pixels, le type, etc. Une précharge sera automatiquement effectuée si vous spécifiez l'un de ces modes de tri.
-q, --quiet
Ne signale pas les erreurs non fatales pour les chargements échoués. Les modes verbeux et silencieux ne sont pas mutuellement exclusifs, le premier contrôle les messages informatifs, le second seulement les erreurs.
-z, --randomize
Lors de l'affichage de plusieurs fichiers dans un diaporama, randomise la liste de fichiers avant l'affichage. La liste est re-randomisée à chaque fois que le diaporama boucle (c'est-à-dire passe de la dernière à la première image).
-r, --recursive
Développe récursivement tous les répertoires des arguments de la ligne de commande vers le contenu de ces répertoires, jusqu'au niveau le plus bas.
--no-recursive
Ne développe pas récursivement les répertoires. C'est le comportement par défaut, mais cette option est utile pour remplacer les thèmes contenant --recursive.
-R, --reload int
Recharge la liste de fichiers et l'image courante après int secondes. Utile pour visualiser des webcams HTTP ou des répertoires changeant fréquemment. (Notez que le rechargement de la liste de fichiers est toujours expérimental.) Définissez à zéro pour désactiver tout type de rechargement automatique.

Si une image est supprimée, feh affichera soit la suivante, soit quittera. Cependant, si une image existe toujours, mais ne peut plus être chargée, feh continuera d'essayer de la charger.

Le réglage de cette option désactive le rechargement automatique basé sur inotify. Le rechargement n'est pas pris en charge en mode montage, index ou miniature.

-n, --reverse
Inverse l'ordre de tri. Utilisez ceci pour inverser l'ordre de la liste de fichiers. Par exemple, pour trier par largeur en ordre inverse, utilisez -nSwidth.
-., --scale-down
Redimensionne les images pour s'adapter à la géométrie de la fenêtre (par défaut à la taille de l'écran si aucune géométrie n'a été spécifiée). Notez que la géométrie de la fenêtre n'est pas mise à jour lors du changement d'image pour le moment. Cette option est recommandée pour les gestionnaires de fenêtres en mosaïque. Cette option est ignorée en mode plein écran et en mode liste de miniatures.

Dans les environnements en mosaïque, cela centre également l'image dans la fenêtre.

--scroll-step nombre
Fait défiler de nombre pixels à chaque fois que scroll_up, scroll_down, scroll_left ou scroll_right est pressé. Notez que cette option accepte des nombres négatif si vous avez besoin d'inverser la direction de défilement. Voir SYNTAXE DE LA CONFIGURATION DES TOUCHES pour savoir comment l'inverser de manière permanente. Par défaut : 20
-D, --slideshow-delay flottant
Pour le mode diaporama, attend flottant secondes entre les changements automatiques de diapositives. Utile pour les présentations. Spécifiez un nombre négatif pour définir le délai (qui sera alors flottant * (-1)), mais démarre feh en mode pause.
-S, --sort type_de_tri
Trie la liste de fichiers selon les paramètres des images. Les types de tri autorisés sont : name, none, filename, dirname, mtime, width, height, pixels, size, format. Pour les modes de tri autres que name, none, filename, dirname, ou mtime, une précharge est nécessaire, causant un délai proportionnel au nombre d'images dans la liste.

mtime commence par l'image la plus récemment modifiée. width, height, pixels et size commencent par la plus petite. Utilisez --reverse pour trier par la plus ancienne ou la plus grande en premier.

Pour name, filename, et dirname vous pouvez utiliser --version-sort pour trier les nombres naturellement, de sorte que par exemple 10.jpg vienne après 2.jpg.

none est le comportement par défaut ; vous pouvez le spécifier explicitement pour annuler un mode de tri qui a été spécifié à un point antérieur des arguments de la ligne de commande.

-|, --start-at fichier
Commence la liste de fichiers à fichier. Si aucun autre fichier ou liste de fichiers n'a été spécifié sur la ligne de commande, feh chargera d'abord tous les fichiers du répertoire dans lequel fichier réside. De cette façon, il est possible de regarder une image spécifique et d'utiliser les touches suivant / précédent pour parcourir le répertoirey. Voir EXEMPLES D'UTILISATION pour des exemples. Si filename est une URL distante et qu'aucun fichier ou fichier de liste n'a été spécifié, feh affichera filename et n'essaiera pas de charger de fichiers ou de répertoires supplémentaires.

Note : Si vous utilisez des chemins relatifs dans votre fichier de liste, filename devrait également être un chemin relatif. Si vous utilisez des chemins absolus, il devrait également être un chemin absolu. Si feh ne trouve pas de correspondance exacte, il comparera les noms de base (les noms de fichiers sans le suffixe de répertoire). Cela peut entraîner des erreurs de correspondance si plusieurs fichiers de votre fichier de liste ont le même nom de base.

-T, --theme theme
Charge les options depuis le fichier de configuration nommé theme - voir SYNTAXE DE LA CONFIGURATION DES THÈMES pour plus d'informations. Notez que les options de la ligne de commande remplacent toujours les options du thème. Le thème peut également être défini via le nom du programme (par exemple avec des liens symboliques), donc par défaut feh cherchera un thème "feh".
-t, --thumbnails
Identique au mode Index, mais les miniatures sont des lanceurs d'images cliquables. Notez que --fullscreen et --scale-down n'affectent pas la fenêtre des miniatures. Cependant, ils fonctionnent pour les fenêtres d'images lancées depuis le mode miniature. Prend également en charge les OPTIONS DU MODE INDEX ET DES MINIATURES ainsi que les OPTIONS DU MODE MONTAGE.
-~, --thumb-title string
Définit le titre pour les fenêtres ouvertes depuis le mode miniature. Voir aussi SPÉCIFICATEURS DE FORMAT.
-^, --title title

Ces options supplémentaires peuvent être utilisées pour les modes index, montage et (partiellement) miniature.

-a, --alpha int
Lors du dessin des miniatures sur l'arrière-plan, définit leur niveau de transparence à int (0 - 255).
-b, --bg file | trans
Utilise file comme arrière-plan pour votre montage. Avec cette option spécifiée, la taille du montage sera par défaut la taille de file si aucune restriction de taille n'a été spécifiée. Alternativement, si file est "trans", l' arrière-plan sera rendu transparent.
-X, --ignore-aspect
Par défaut, les miniatures du montage conservent leurs proportions, tout en s'adaptant à la largeur/hauteur des miniatures. Cette option les force à avoir la taille définie par --thumb-width et --thumb-height. Cela empêchera tout espace vide dans le montage final.
-H, --limit-height pixels
Limite la hauteur du montage.
-W, --limit-width pixels
Limite la largeur du montage, par défaut 800 pixels.

-O, --output-only file
Enregistre simplement le montage créé dans file sans l'afficher.

Normalement, si une image est plus petite que la taille de miniature spécifiée, elle ne sera pas agrandie. Si cette option est définie, l'image sera mise à l'échelle pour s'adapter à la taille de miniature. Les proportions seront maintenues sauf si --ignore-aspect est spécifié.

En plus des OPTIONS DU MODE MONTAGE --alpha, --bg, --limit-height, --limit-width, --output, --output-only, --thumb-height, --thumb-width, les options suivantes peuvent être utilisées.

--index-info format
Affiche les informations de l'image basées sur format sous les miniatures en mode index / miniature. Voir SPÉCIFICATEURS DE FORMAT. Peut contenir des sauts de ligne. Utilisez "--index-info ''" pour afficher les miniatures sans aucun texte d'information

Note : Si vous spécifiez des formats liés aux images (comme %w ou %s), feh doit charger toutes les images pour calculer les dimensions de sa propre fenêtre. Donc, lors de leur utilisation avec de nombreux fichiers, il faudra un certain temps avant qu'une fenêtre feh ne devienne visible. Utilisez --preload pour obtenir une barre de progression.

-@, --title-font police
Définit la police à utiliser pour imprimer un titre sur l'index ; si aucune police n'est spécifiée, aucun titre ne sera imprimé.
-J, --thumb-redraw n
Redessine la fenêtre des miniatures tous les n images lors de la génération des miniatures. Le redessin prend beaucoup de temps, donc la valeur par défaut est 10. Définissez n à = 1 pour mettre à jour la fenêtre des miniatures immédiatement. Avec n = 0, il n'y aura qu'un seul redessin une fois toutes les miniatures chargées.

CONFIGURATION DU FOND D'ÉCRAN

Dans de nombreux environnements de bureau, feh peut également être utilisé comme programme de configuration du fond d'écran. À moins que vous ne passiez l'option --no-fehbg, il écrira un script pour définir le fond d'écran actuel dans ~/.fehbg. Ainsi, pour que votre fond d'écran soit restauré à chaque démarrage de X, vous pouvez ajouter « ~/.fehbg & » à votre script de démarrage X (comme ~/.xinitrc). Notez que la commande écrite dans ~/.fehbg inclut toujours l'option --no-fehbg pour s'assurer qu'elle n'est pas modifiée par inadvertance par des différences dans la disposition de l'écran X11 ou similaires.

Notez que feh ne prend pas en charge la configuration du fond d'écran des environnements GNOME Shell. Dans cet environnement, vous pouvez utiliser « gsettings set org.gnome.desktop.background picture-uri file:///« chemin » » à la place.

Pour --bg-center, --bg-fill et --bg-max, vous pouvez utiliser --geometry pour spécifier un décalage par rapport à un côté du moniteur au lieu de centrer l'image. Les valeurs positives décale le côté gauche/haut, les valeurs négatives le côté inférieur/droit. +0 et -0 sont des valeurs valides et distinctes.

Notez que toutes les options sauf --bg-tile prennent en charge Xinerama. Par exemple, si vous avez plusieurs moniteurs connectés et que vous utilisez par ex. --bg-center, feh centrera ou décale l'image de manière appropriée sur chaque moniteur. Vous pouvez même spécifier plusieurs fichiers ; dans ce cas, le premier fichier est défini sur le moniteur 0, le second sur le moniteur 1, et ainsi de suite. Utilisez xrandr --listmonitors pour déterminer comment les identifiants de moniteurs Xinerama correspondent aux écrans / moniteurs dans votre configuration.

Utilisez --no-xinerama pour traiter l'ensemble de l'affichage X comme un seul moniteur lors de la définition des fonds d'écran. Vous pouvez également utiliser --xinerama-index pour utiliser feh comme programme de configuration du fond d'écran pour un moniteur spécifique.

--bg-center
Centre le fichier sur le fond d'écran. S'il est trop petit, il sera entouré d'une bordure comme spécifié par --image-bg.
--bg-fill
Similaire à --bg-scale, mais conserve le rapport d'aspect en zoomant l'image jusqu'à ce qu'elle remplisse l'écran. Une partie horizontale ou verticale de l'image sera coupée.
--bg-max
Similaire à --bg-fill, mais adapte l'image à la taille maximale qui remplit l'écran avec des bordures d'un côté. La couleur de la bordure peut être définie à l'aide de --image-bg.
--bg-scale
Adapte le fichier au fond d'écran sans le répéter, sans couper d'éléments ou utiliser de bordures. Mais le rapport d'aspect n'est pas non plus conservé.
--bg-tile
Répète l'image (carreaux) si elle est trop petite pour l'écran.
--no-fehbg
Ne pas écrire de fichier ~/.fehbg.

CONFIGURATION

feh possède trois fichiers de configuration : themes pour les définitions de thèmes, keys pour les raccourcis clavier et buttons pour les raccourcis de boutons de souris. Il essaiera de les lire à partir de $XDG_CONFIG_HOME/feh/, qui (lorsque XDG_CONFIG_HOME est non défini) est par défaut ~/.config/feh/. Si les fichiers ne sont pas trouvés dans ce répertoire, il essaiera également /etc/feh/.

Tous les fichiers de configuration traitent les lignes commençant par un caractère « # » comme des commentaires. Les commentaires en fin de ligne ne sont pas pris en charge.

SYNTAXE DE CONFIGURATION DES THÈMES

.config/feh/themes permet de nommer des groupes d'options, appelés thèmes.

Il accepte des entrées de la forme « thème options ... », où thème est le nom de l'entrée et options sont les options qui seront appliquées lorsque le thème sera utilisé.

Notez que l'analyseur d'options ne se comporte pas comme un shell normal : l'expansion de noms de fichiers et les séquences d'échappement par antislash ne sont pas prises en charge et sont passées telles quelles à l'analyseur d'options de feh. Cependant, le traitement des guillemets pour les arguments est respecté et peut être utilisé pour les arguments contenant des espaces. Ainsi, la séquence « --info "foo bar" » fonctionne comme prévu (c'est-à-dire qu'elle affiche la chaîne « foo bar »), tandis que la chaîne d'options « --info foo\ bar » n'affichera que « foo\ » et se plaindra que le fichier bar n'existe pas. Veuillez garder cela à l'esprit lors de la rédaction des fichiers de thèmes.

Une entrée d'exemple est « imagemap -rVq --thumb-width 40 --thumb-height 30 --index-info '%n\n%wx%h' ».

Vous pouvez utiliser ce thème de deux manières. Soit en appelant « feh -Timagemap *.jpg », soit en créant un lien symbolique vers feh portant le nom du thème que vous souhaitez utiliser. Pour l'exemple ci-dessus, ce serait « ln -s `which feh` ~/bin/imagemap ». Exécutez maintenant « imagemap *.jpg » pour utiliser ces options.

Notez que vous pouvez diviser un thème sur plusieurs lignes en plaçant une barre oblique inverse à la fin d'une ligne inachevée. Une paire option-argument unique ne doit pas s'étendre sur plusieurs lignes. Une seule ligne ne doit pas dépasser 1023 caractères, mais il n'y a pas de limite supérieure à la longueur d'un thème.

Les options de ligne de commande remplacent toujours les options du thème.

SYNTAXE DE CONFIGURATION DES CLÉS

.config/feh/keys définit les raccourcis clavier. Il a des entrées de la forme « action [clé1 [clé2 [clé3]]] ».

Chaque clé est un nom de keysym X11 tel qu'affiché par xev(1), comme « Delete ». Il peut éventuellement commencer par des modificateurs pour des choses comme Control, auquel cas clé ressemble à mod-keysym (par exemple « C-Delete » pour Ctrl+Delete ou « C-1-Delete » pour Ctrl+Alt+Delete)

Les modificateurs disponibles sont C pour Control, S pour Shift et 1, 4 pour Mod1 et Mod4. Pour faire correspondre une lettre majuscule comme « S » au lieu de « s », le modificateur Shift n'est pas requis.

Spécifier une action sans aucune clé la désactive (c'est-à-dire que les liaisons par défaut sont supprimées).

Note : N'utilisez pas la même combinaison de touches pour plusieurs actions. Lorsque vous liez une action à une nouvelle touche (ou bouton de souris), assurez-vous de la désactiver de son action précédente, le cas échéant. feh ne vérifie pas les conflits de liaisons, donc leur comportement est indéfini.

Pour une liste des noms d'action, voir CLÉS. Notez que tous les noms de touches utilisés ici ne correspondent pas aux clésyms X11. Les plus notables sont les touches page précédente (Prior / Page_Up), page suivante (Next / Page_Down) et les touches du pavé numérique (KP_*).

Associations par défaut : Lors de l'affichage d'une image, le bouton 1 de la souris fait un panoramique de l'image (la déplace) ou, lorsqu'il est simplement cliqué, passe à l'image suivante (uniquement en mode diaporama). Les glissements rapides avec moins de 2 px de mouvement par axe seront considérés comme des clics pour aider les utilisateurs de tablettes graphiques. Le bouton 2 de la souris
zoome (cliquez et glissez de gauche à droite
pour zoomer avant, de droite à gauche pour zoomer
arrière, cliquez une fois pour restaurer le zoom
à 100 %) et le bouton 3 de la souris ouvre le menu.

Ctrl+Bouton 1 floute ou rend l'image plus nette (glissez à gauche pour flouter, à droite pour rendre plus nette) ; Ctrl+Bouton 2 fait pivoter l'image autour du point

central.

Une note sur les modes panoramique et zoom : En mode panoramique, si vous atteignez un bord de la fenêtre mais que vous n'avez pas encore fait défiler jusqu'à la fin de

l'image,

fe

h

déplacera votre curseur vers le bord opposé afin que vous puissiez continuer le panoramique. Lorsque vous cliquez sur le bouton de zoom et le relâchez immédiatement, l'image reviendra à un zoom de 100 %. Lorsque vous cliquez dessus et déplacez la souris tout en maintenant le bouton enfoncé, le zoom continuera au niveau de zoom précédent. Le zoom se fera toujours de sorte que le pixel sur lequel vous êtes entré en mode zoom reste immobile. Ainsi, pour agrandir une partie spécifique d'une image, cliquez sur le bouton de zoom sur cette

partie.

BUGS CONNUS Les versions d'Imlib2 antérieures à 1.7.4 sont incapables de charger les images gif, tiff et webp si le nom de fichier ne se termine pas par gif, tiff ou webp respectivement. Notamment, cela signifie que feh est incapable d'afficher les images gif, tiff et webp depuis stdin ou des URL réseau sur les systèmes utilisant une version d'Imlib2 plus ancienne

que
1.7.4.

Les versions d'Imlib2 1.7.5+ tournent automatiquement les images en fonction de leurs balises EXIF. Combiné avec

l'option

--auto-rotate [[57]], cela fait tourner les images deux fois et les laisse dans une orientation incorrecte. En contournement, n'utilisez

pas

--auto-rotate sur les systèmes avec une version d'Imlib2 1.7.5 ou ultérieure. Sur les systèmes avec giflib 5.1.2, fe

h

peut être incapable de charger les images gif. Pour les appareils mips, mipsel et arm concernés, la prise en charge de gif est complètement cassée, tandis que sur x86 / x86_64 les gifs ne peuvent généralement être chargés que s'ils sont la première image de la liste de fichiers. Cela semble être un bug de giflib, voir ⟨ https://bugs.debian.org/cgi-bin/bugreport.cgi?bug=813729⟩ pour les détails. Contournement : Utilisez --conversion-timeout

5

(ou une autre valeur positive) pour charger les gifs avec imagemagick à la place, ou rétrogradez vers giflib 5.1.1, ou passez à giflib 5.1.4. Pendant le chargement des images via

libcurl,

fe

h

ne réagira pas aux actions de clavier ou de

souris.
