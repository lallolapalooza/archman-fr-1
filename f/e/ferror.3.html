ferror(3) Manuel des fonctions de bibliothèque ferror(3)

NOM

clearerr, feof, ferror - vérifier et réinitialiser l'état d'un flux

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <stdio.h>
void clearerr(FILE *stream);
int feof(FILE *stream);
int ferror(FILE *stream);

DESCRIPTION

La fonction clearerr() efface les indicateurs de fin de fichier et d'erreur pour le flux pointé par stream.

La fonction feof() teste l'indicateur de fin de fichier pour le flux pointé par stream, renvoyant une valeur non nulle s'il est défini. L'indicateur de fin de fichier ne peut être effacé que par la fonction clearerr().

La fonction ferror() teste l'indicateur d'erreur pour le flux pointé par stream, renvoyant une valeur non nulle s'il est défini. L'indicateur d'erreur ne peut être réinitialisé que par la fonction clearerr().

Pour les contreparties non bloquantes, voir unlocked_stdio(3).

VALEUR DE RETOUR

La fonction feof() renvoie une valeur non nulle si l'indicateur de fin de fichier est défini pour stream ; sinon, elle renvoie zéro.

La fonction ferror() renvoie une valeur non nulle si l'indicateur d'erreur est défini pour stream ; sinon, elle renvoie zéro.

ERREURS

Ces fonctions ne devraient pas échouer et ne définissent pas errno.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
clearerr (), feof (), ferror () Sécurité des threads MT-Safe

NORMES

C11, POSIX.1-2008.

HISTORIQUE

C89, POSIX.1-2001.

NOTES

POSIX.1-2008 spécifie que ces fonctions ne modifient pas la valeur de errno si stream est valide.

AVERTISSEMENTS

Normalement, les programmes devraient lire la valeur de retour d'une fonction de lecture, telle que fgetc(3), avant d'utiliser les fonctions de la famille feof(3). Ce n'est que lorsque la fonction a renvoyé la valeur sentinelle EOF qu'il est pertinent de distinguer entre la fin d'un fichier ou une erreur avec feof(3) ou ferror(3).

VOIR AUSSI

open(2), fdopen(3), fileno(3), stdio(3), unlocked_stdio(3)
