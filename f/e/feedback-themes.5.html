Nom

feedback-themes - Configuration des thèmes pour feedbackd

DESCRIPTION

Le retour d'information fourni à l'utilisateur pour un événement est déterminé par le thème de retour d'information. Chaque thème se compose de jusqu'à trois profils (full, quiet et silent) contenant les noms des événements et leur retour d'information associé.

Les événements dans le thème sont nommés conformément à la spécification de nommage des événements https://gitlab.freedesktop.org/agx/feedbackd/-/blob/main/doc/Event-naming-spec-0.0.0.md

Les thèmes de retour d'information utilisent un format JSON qui peut être validé avec fbd-theme-validate(1). Ils peuvent inclure d'autres thèmes pour éviter la répétition.

Pour plus de détails sur la création ou la modification des thèmes de retour d'information, consultez la documentation de feedbackd à l'adresse https://gitlab.freedesktop.org/agx/feedbackd#feedback-theme

Types de retour d'information

Pour construire un thème, vous pouvez utiliser plusieurs types de retour d'information différents :

  • Sound : Joue un son du thème sonore installé
  • VibraRumble : Un seul grondement utilisant le moteur haptique
  • VibraPeriodic : Un grondement périodique utilisant le moteur haptique
  • VibraPattern : Un motif spécifiant le grondement du moteur haptique
  • Led : Une LED clignotante selon un motif périodique

Retour d'information sonore

Les retours d'information sonores spécifient un nom d'événement à partir d'un thème sonore XDG. Les thèmes sonores sont décrits dans la spécification du thème sonore à l'adresse https://freedesktop.org/wiki/Specifications/sound-theme-spec/

  • event-name : Le nom de l'événement sonore à utiliser.
  • media-role : Le rôle multimédia à définir pour le flux audio lu. Par défaut, il est défini sur event.

Retour d'information VibraRumble

Le retour d'information VibraRumble utilise une propriété unique

  • count : Le nombre de grondements.
  • pause : La pause entre chaque grondement en ms.
  • duration : La durée du grondement en ms.
  • mangitude : La magnitude relative du grondement ([0, 1]).

Retour d'information VibraPattern

Le retour d'information VibraPattern possède ces propriétés

  • magnitudes : La magnitude relative de chaque grondement [0, 1] sous forme de tableau de doubles.
  • durations : Les durées de chaque grondement en ms sous forme de tableau d'entiers non signés.

Les deux tableaux doivent avoir la même longueur.

Retour d'information LED

Le type de retour d'information Led utilise deux propriétés pour spécifier la manière dont une LED clignote.

  • color : Ceci spécifie la couleur avec laquelle une LED doit clignoter. Il prend en charge les noms de couleurs fixes red, green, blue et white ainsi que les valeurs au format HEX RVB (#RRGGBB) où RR, GG et BB sont des valeurs hexadécimales à deux chiffres comprises entre 00 et FF spécifiant la valeur de chaque composant. Par exemple, #00FFFF correspond à la couleur cyan.
  • frequency : La fréquence de clignotement de la LED en mHz.
