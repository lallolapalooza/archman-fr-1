Nom

fbd-theme-validate - Valide les thèmes feedbackd

SYNOPSIS

fbd-theme-validate [OPTIONS...] <FICHIER>

DESCRIPTION

fbd-theme-validate analyse et valide le fichier de thème feedbackd donné. Si le thème spécifie des thèmes parents, ceux-ci sont également analysés et validés.

OPTIONS

-h, --help
affiche l'aide et quitte
--version
affiche les informations de version et quitte
--compatible=COMPATIBLE
Spécifie l'appareil compatible à utiliser. Spécifiez ceci si vous validez un thème utilisateur et souhaitez simuler comment il apparaîtrait sur un appareil avec le `COMPATIBLE` spécifié.

EXEMPLES

Valide un thème personnalisé dans le répertoire personnel de l'utilisateur de la même manière qu'il serait chargé sur un Librem 5 :

fbd-theme-validate --compatible=purism,librem5 ~/.config/feedbackd/themes/custom.json

Valide le thème de l'appareil pour un OnePlus 6T :

fbd-theme-validate /usr/share/feedbackd/themes/oneplus,fajita.json
