FBDEV(4) Manuel des pilotes de périphériques FBDEV(4)

NOM

fbdev - pilote vidéo pour le périphérique de framebuffer

SYNTAXE

Section "Device"
  Identifier "nom_périph"
  Driver "fbdev"
  BusID  "pci:bus:périph:func"
  ...
EndSection

DESCRIPTION

fbdev est un pilote Xorg pour les périphériques de framebuffer. C'est un pilote non accéléré, les profondeurs de framebuffer suivantes sont supportées : 8, 15, 16, 24. Tous les types visuels sont supportés pour la profondeur 8, et le visual TrueColor est supporté pour les autres profondeurs. Les configurations multi-écrans sont supportées.

MATERIEL SUPPORTÉ

Le pilote fbdev supporte tout matériel pour lequel un pilote de framebuffer est disponible. fbdev utilise le sous-module spécifique à l'OS fbdevhw(4) pour communiquer avec le pilote du périphérique noyau. Actuellement, un module fbdevhw est disponible pour linux.

DÉTAILS DE CONFIGURATION

Veuillez vous référer à xorg.conf(5) pour les détails de configuration généraux. Cette section couvre uniquement les détails de configuration spécifiques à ce pilote.

Pour ce pilote, il n'est pas nécessaire de spécifier les modes dans la section écran du fichier de configuration. Le pilote fbdev peut récupérer le mode vidéo actuellement utilisé auprès du pilote de framebuffer et l'utilisera s'il n'y a pas de modes vidéo configurés.

Pour les cartes PCI, vous pourriez avoir à ajouter une ligne BusID dans la section Device. Voir ci-dessus pour un exemple de ligne.

Les Options de pilote suivantes sont supportées :

Option "fbdev" "chaîne"
Le périphérique de framebuffer à utiliser. Par défaut : /dev/fb0.
Option "ShadowFB" "booléen"
Activer ou désactiver l'utilisation de la couche de framebuffer fantôme. Obligatoire pour les framebuffers 24bpp sur les serveurs plus récents. Par défaut : activé.
Option "Rotate" "chaîne"
Activer la rotation de l'affichage. Les valeurs supportées sont "CW" (sens horaire, 90 degrés), "UD" (à l'envers, 180 degrés) et "CCW" (sens anti-horaire, 270 degrés). Implique l'utilisation de la couche de framebuffer fantôme. Désactivé pour les framebuffers 24bpp. Par défaut : désactivé.

VOIR AUSSI

Xorg(1), xorg.conf(5), Xserver(1), X(7), fbdevhw(4)
