fblocked(n) Commandes intégrées Tcl fblocked(n)

NOM

fblocked - Tester si la dernière opération d'entrée a épuisé toute l'entrée disponible

SYNTAXE

fblocked channelId

DESCRIPTION

La commande fblocked renvoie 1 si la dernière opération d'entrée sur channelId a renvoyé moins d'informations que demandé parce que toute l'entrée disponible a été épuisée. Par exemple, si gets est invoqué alors qu'il n'y a que trois caractères disponibles pour l'entrée et aucune séquence de fin de ligne, gets renvoie une chaîne vide et un appel ultérieur à fblocked renverra 1.

ChannelId doit être un identifiant pour un canal ouvert tel qu'un canal standard Tcl (stdin, stdout, ou stderr), la valeur de retour d'une invocation de open ou socket, ou le résultat d'une commande de création de canal fournie par une extension Tcl.

EXEMPLE

La commande fblocked est particulièrement utile lors de l'écriture de serveurs réseau, car elle vous permet d'écrire votre code dans un style ligne par ligne sans empêcher le service d'autres connexions. Ceci peut être vu dans ce simple service d'écho :

# Ceci est appelé chaque fois qu'un nouveau client se connecte au serveur proc connect {chan host port} {
set clientName [format <%s:%d> $host $port]
puts "connexion depuis $clientName"
fconfigure $chan -blocking 0 -buffering line
fileevent $chan readable [list echoLine $chan $clientName] }

# Ceci est appelé chaque fois qu'au moins un octet de données d'entrée # est disponible, ou que le canal a été fermé par le client. proc echoLine {chan clientName} {
gets $chan line
if {[eof $chan]} {
puts "fin de la connexion pour $clientName"
close $chan
} elseif {![fblocked $chan]} {
# N'a pas bloqué en attendant la fin de ligne
puts "$clientName - $line"
puts $chan $line
} }

# Créez le socket serveur et entrez dans la boucle d'événements pour attendre # les connexions entrantes... socket -server connect 12345 vwait forever
