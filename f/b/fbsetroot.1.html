FBSETROOT(1) Manuel Fluxbox FBSETROOT(1)

NOM

fbsetroot - utilitaire simple de fond d'écran utilisé par le gestionnaire de fenêtres fluxbox(1), originellement écrit pour et par le gestionnaire de fenêtres blackbox(1) original.

SYNTAXE

fbsetroot [-display display] -solid couleur

fbsetroot [-display display] -mod x y -fg couleur -bg couleur

fbsetroot [-display display] -gradient texture -from couleur -to couleur

fbsetroot -help

DESCRIPTION

fbsetroot(1) est un utilitaire qui peut contrôler l'apparence de la fenêtre racine de trois manières : soit lui donner une couleur unie, soit y écrire un motif modulaire à deux couleurs, soit rendre une texture de dégradé, basée sur deux couleurs différentes.

fbsetroot ressemble à xsetroot(1) dans cette fonctionnalité, mais il prend en charge les affichages multi-écrans et les textures de dégradé de la même manière que blackbox ou fluxbox. Il ne gère pas les curseurs, etc. fbsetroot faisait originellement partie du paquet Blackbox et a été repris avec le code qui est devenu Fluxbox. Il s'appelait bsetroot à l'époque.

Si des erreurs sont rencontrées, fbsetroot utilisera soit gxmessage(1), soit xmessage(1) pour informer l'utilisateur des erreurs.

OPTIONS

fbsetroot fonctionne de trois manières, vous devez choisir l'une des 3 premières options :

-solid couleur

Définit la fenêtre racine à la couleur spécifiée.

-mod x y

Crée un motif modulaire. Vous devez spécifier les couleurs -bg et -fg.

-gradient chaîne_texture

Rend la chaîne de texture spécifiée dans la fenêtre racine.

chaîne_texture peut être l'une des suivantes :

Horizontal / Vertical / Diagonal / Crossdiagonal / Pipecross / Elliptic / Rectangle / Pyramid

Sélectionnez l'un de ces types de texture, ils ne s'appliquent que lorsque -gradient est spécifié. Vous devez également spécifier une couleur -from et une couleur -to.

-display display

Indique à fbsetroot de se connecter à l'affichage spécifié.

-bg, -background couleur

Couleur d'arrière-plan. Nécessaire pour les motifs -mod.

-fg, -foreground couleur

Couleur de premier plan. Nécessaire pour les motifs -mod.

-from couleur

Couleur de départ pour le rendu des textures. Nécessaire pour les motifs -gradient.

-to couleur

Couleur de fin pour le rendu des textures. Nécessaire pour les motifs -gradient.

-help

Affiche les informations de version et un bref texte d'aide.
