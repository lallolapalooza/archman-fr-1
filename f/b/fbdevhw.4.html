FBDEVHW(4) Manuel des pilotes de périphériques FBDEVHW(4)

NOM

fbdevhw - sous-module spécifique à l'OS pour l'accès aux périphériques framebuffer

DESCRIPTION

fbdevhw fournit des fonctions pour communiquer avec un périphérique framebuffer. Il est spécifique à l'OS. C'est un sous-module utilisé par d'autres pilotes vidéo. Un module fbdevhw est actuellement disponible pour les périphériques framebuffer Linux.

fbdev(4) est un pilote non accéléré qui fonctionne au-dessus du module fbdevhw. fbdevhw peut également être utilisé par d'autres pilotes, ceci est généralement activé avec `Option "UseFBDev"' dans la section `Device'.

VOIR AUSSI

Xorg(1), xorg.conf(5), xorgconfig(1), Xserver(1), X(7), fbdev(4)

AUTEURS

Parmi les auteurs figurent : Gerd Knorr, basé sur le code du serveur XF68_FBDev (Martin Schaller, Geert Uytterhoeven).
