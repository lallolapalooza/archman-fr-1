FBGS(1) Visionneuse PostScript/pdf pour la console framebuffer linux FBGS(1)

NOM

fbgs - Visionneuse PostScript/pdf pour la console framebuffer linux à bas coût.

SYNTAXE

fbgs [-l|-xl|-xxl|-r n] [-c] [-b] [-p motdepasse] [--fp nombre] [--lp nombre] [options fbi] fichier

DESCRIPTION

Fbgs est un script wrapper simple qui prend un fichier PostScript (PS) ou Portable Document Format (PDF) en entrée, rend les pages en utilisant gs(1) - GhostScript - dans un répertoire temporaire, puis appelle fbi(1) pour les afficher.

OPTIONS

Fbgs comprend toutes les options de fbi(1) (elles sont transmises), sauf : store, list, text, (no)comments, e, (no)edit, (no)backup, (no)preserve, (no)readahead, cachemem, blend.

De plus, vous pouvez spécifier :

-h, --help
Affiche les informations d'utilisation (écrase l'option fbi).
-b, --bell
Émet un signal sonore lorsque le document est prêt.
-c, --color
Pour rendre les pages en couleur (par défaut, N&B).
-l
Pour que les pages soient rendues avec 100 dpi (par défaut, 75).
-xl
Pour que les pages soient rendues avec 120 dpi.
-xxl
Pour que les pages soient rendues avec 150 dpi.
-r n, --resolution n
Pour que les pages soient rendues avec n dpi (écrase l'option fbi).
-fp nombre, --firstpage nombre
Commence l'interprétation à la page désignée du document.
-lp nombre, --lastpage nombre
Arrête l'interprétation après la page désignée du document.
-p motdepasse, --password motdepasse
Vous pouvez utiliser cette option si votre fichier PDF nécessite un mot de passe.

VOIR AUSSI

fbi(1), gs(1)
