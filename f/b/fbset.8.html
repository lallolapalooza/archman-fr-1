fbset est un utilitaire système pour afficher ou modifier les paramètres du périphérique de mémoire tampon d'affichage (frame buffer). Le périphérique de mémoire tampon d'affichage fournit une interface simple et unique pour accéder à différents types d'affichages

graphiques.

Les périphériques de mémoire tampon d'affichage sont accessibles via des nœuds de périphérique spéciaux situés dans le répertoire /dev. Le schéma de nommage de ces nœuds est toujours fb<n>, où n est le numéro du périphérique de mémoire tampon d'affichage

utilisé.

fbset utilise sa propre base de données de modes vidéo située dans /etc/fb.modes. Un nombre illimité de modes vidéo peut être défini dans cette base de données. Pour plus d'informations, voir fb.mod

es(
5).

Si aucune option n'est donnée, fbset affichera les paramètres actuels de la mémoire tampon

d'affichage.

Drapeaux d'affichage

:
-hsync{low|high
}
définir la polarité de la synchronisation
horizontale
-vsync{low|high
}
définir la polarité de la synchronisation
verticale
-csync{low|high
}
définir la polarité de la synchronisation
composite
-extsync{false|true
}
activer ou désactiver la resynchronisation externe. Si activée, les synchronisations ne sont pas générées par le périphérique de mémoire tampon d'affichage et doivent être fournies de l'extérieur. Notez que cette option peut ne pas être prise en charge par tous les périphériques de mémoire tampon
d'affichage
-bcast{false|true
}
activer ou désactiver les modes de diffusion. Si activé, la mémoire tampon d'affichage génère les synchronisations exactes pour plusieurs modes de diffusion (par ex. PAL ou NTSC). Notez que cette option peut ne pas être prise en charge par tous les périphériques de mémoire tampon
d'affichage
-laced{false|true
}
activer ou désactiver l'entrelacement. Si activé, l'affichage sera divisé en deux trames, chaque trame ne contenant que les lignes paires ou impaires respectivement. Ces deux trames seront affichées en alternance, de cette façon deux fois plus de lignes peuvent être affichées et la fréquence verticale du moniteur reste la même, mais la fréquence verticale visible est divisée par
deux
-double{false|true
}
activer ou désactiver le doublescan. Si activé, chaque ligne sera affichée deux fois et de cette façon
la fréquence horizontale peut facilement être doublée, de sorte que la même résolution peut être aff
ichée sur différents moniteurs, même si la spécification de fréquence horizontale diffère. Notez que
cette option peut ne pas être prise en charge par tous les périphériques de mémoire tampon d'affichage
