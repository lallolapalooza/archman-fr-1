DESCRIPTIO

N

Cette opération a été ajoutée pour prendre en charge certains cas d'utilisation en espace utilisateur où plus d'un futex doit être géré en même temps. L'exemple le plus notable est l'implémentation de pthread_cond_signal(3), qui nécessite des opérations sur deux futex, celui utilisé pour implémenter le mutex et celui utilisé dans l'implémentation de la file d'attente associée à la variable de condition. FUTEX_WAKE_OP permet de mettre en œuvre de tels cas sans entraîner de taux élevés de contention et de commutation de

contexte.

L'opération FUTEX_WAKE_OP est équivalente à l'exécution du code suivant de manière atomique et totalement ordonnée par rapport aux autres opérations sur futex sur l'un ou l'autre des deux mots futex fournis

: 


uint32_t oldval = *(uint32_t *) uaddr2;
*(uint32_t *) uaddr2 = oldval op oparg;
futex(uaddr, FUTEX_WAKE, val, 0, 0, 0);
if (oldval cmp cmparg)
    futex(uaddr2, FUTEX_WAKE, val2, 0, 0, 0)
;

En d'autres termes, FUTEX_WAKE_OP fait ce qui suit

:
•
enregistre la valeur originale du mot futex à l'adresse uaddr2 et effectue une opération pour modifier la valeur du futex à l'adresse uaddr2 ; il s'agit d'un accès mémoire atomique de lecture-modification-écriture (c'est-à-dire utilisant des instructions machine atomiques de l'architecture
respective)
•
réveille un maximum de val attente(s) sur le futex pour le mot futex à l'adresse uaddr ;
et
•
en fonction des résultats d'un test de la valeur originale du mot futex à l'adresse uaddr2, réveille un maximum de val2 attente(s) sur le futex pour le mot futex à l'adresse uadd
r
2.

L'opération et la comparaison à effectuer sont encodées dans les bits de l'argument val3. Graphiquement, l'encodage est

: 


+---+---+-----------+-----------+
|op |cmp|   oparg   |  cmparg   |
+---+---+-----------+-----------+
  4   4       12          12    <== # de
bits

Exprimé en code, l'encodage est

: 


#define FUTEX_OP(op, oparg, cmp, cmparg) \
                (((op & 0xf) << 28) | \
                ((cmp & 0xf) << 24) | \
                ((oparg & 0xfff) << 12) | \
                (cmparg & 0xfff)
)

Dans ce qui précède, op et cmp sont chacun l'un des codes listés ci-dessous. Les composantes oparg et cmparg sont des valeurs numériques littérales, sauf mention contraire

ci-dessous.

FUTEX_OP_ARG_SHIFT  8  /* Utiliser (1 << oparg) comme opérande

Le champ cmp est l'un des suivants

: 


FUTEX_OP_CMP_EQ     0  /* if (oldval == cmparg) wake */
FUTEX_OP_CMP_NE     1  /* if (oldval != cmparg) wake */
FUTEX_OP_CMP_LT     2  /* if (oldval < cmparg) wake */
