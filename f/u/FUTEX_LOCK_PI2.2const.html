FUTEX_LOCK_PI2(2const) FUTEX_LOCK_PI2(2const)

NOM

FUTEX_LOCK_PI2 - verrouiller un futex d'héritage de priorité

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNOPSIS

#include <linux/futex.h>  /* Définition des constantes FUTEX_* */
#include <sys/syscall.h>  /* Définition des constantes SYS_* */
#include <unistd.h>
long syscall(SYS_futex, uint32_t *uaddr, FUTEX_LOCK_PI2, 0,
             const struct timespec *timeout);

DESCRIPTION

Cette opération est identique à FUTEX_LOCK_PI(2const), à l'exception près que l'horloge contre laquelle le délai d'attente timeout est mesuré est sélectionnable.

Par défaut, le délai d'attente (absolu) spécifié dans timeout est mesuré par rapport à l'horloge CLOCK_MONOTONIC.

VALEUR DE RETOUR

Voir FUTEX_LOCK_PI(2const).

ERREURS

Voir FUTEX_LOCK_PI(2const).

NORMES

Linux.

HISTORIQUE

Linux 5.14.

VOIR AUSSI
