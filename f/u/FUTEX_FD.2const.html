FUTEX_FD(2const) FUTEX_FD(2const)

NOM

FUTEX_FD - créer un descripteur de fichier associé à un futex

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <linux/futex.h>  /* Définition des constantes FUTEX_* */
#include <sys/syscall.h>  /* Définition des constantes SYS_* */
#include <unistd.h>
[[deprecated]]
long syscall(SYS_futex, uint32_t *uaddr, FUTEX_FD, uint32_t val);

DESCRIPTION

Cette opération crée un descripteur de fichier qui est associé au futex à l'adresse uaddr. L'appelant doit fermer le descripteur de fichier retourné après utilisation.

Lorsqu'un autre processus ou thread effectue un FUTEX_WAKE(2const) sur le mot futex, le descripteur de fichier indique qu'il est lisible avec select(2), poll(2), et epoll(7)

Le descripteur de fichier peut être utilisé pour obtenir des notifications asynchrones : si val est non nul, alors, lorsqu'un autre processus ou thread exécute un FUTEX_WAKE(2const), l'appelant recevra le numéro de signal qui a été passé dans val.

VALEUR RETOUR

En cas d'erreur, -1 est retourné, et errno est défini pour indiquer l'erreur.

En cas de succès, FUTEX_FD retourne le nouveau descripteur de fichier associé au futex.

ERREURS

Voir futex(2).

EINVAL
Le numéro de signal fourni dans val est invalide.
ENFILE
La limite globale du système sur le nombre total de fichiers ouverts a été atteinte.

NORMES

Linux.

HISTORIQUE

De Linux 2.6.0 jusqu'à Linux 2.6.25 inclus.

Parce qu'il était intrinsèquement sujet aux conditions de concurrence (race conditions), FUTEX_FD a été supprimé à partir de Linux 2.6.26.
