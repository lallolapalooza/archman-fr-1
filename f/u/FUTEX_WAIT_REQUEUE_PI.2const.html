FUTEX_WAIT_REQUEUE_PI(2const) FUTEX_WAIT_REQUEUE_PI(2const)

NOM

FUTEX_WAIT_REQUEUE_PI - attendre sur un futex non-PI, et potentiellement être réengagé vers un futex PI

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNOPSIS

#include <linux/futex.h>  /* Définition des constantes FUTEX_* */
#include <sys/syscall.h>  /* Définition des constantes SYS_* */
#include <unistd.h>
long syscall(SYS_futex, uint32_t *uaddr, FUTEX_WAIT_REQUEUE_PI,
             uint32_t val,
             const struct timespec *timeout,
             uint32_t *uaddr2);

DESCRIPTION

Attend sur un futex non-PI à l'adresse uaddr et potentiellement être réengagé (via une opération FUTEX_CMP_REQUEUE_PI(2const) dans une autre tâche) vers un futex PI à l'adresse uaddr2. L'opération d'attente sur uaddr est la même que pour FUTEX_WAIT(2const).

Le processus en attente peut être retiré de l'attente sur uaddr sans réengagement sur uaddr2 via une opération FUTEX_WAKE(2const) dans une autre tâche. Dans ce cas, l'opération FUTEX_WAIT_REQUEUE_PI échoue avec l'erreur EAGAIN.

Si timeout n'est pas NULL, la structure qu'il pointe spécifie un délai d'attente absolu pour l'opération d'attente. Si timeout est NULL, l'opération peut bloquer indéfiniment.

VALEUR DE RETOUR

En cas d'erreur, -1 est retourné, et errno est défini pour indiquer l'erreur.

En cas de succès, FUTEX_WAIT_REQUEUE_PI retourne 0 si l'appelant a été correctement réengagé vers le futex pour le mot futex à l'adresse uaddr2.

ERREURS

Voir futex(2).

EAGAIN
La valeur pointée par uaddr n'était pas égale à la valeur attendue val au moment de l'appel.
Note : sous Linux, les noms symboliques EAGAIN et EWOULDBLOCK (qui apparaissent tous deux dans différentes parties du code futex du noyau) ont la même valeur.
EFAULT
uaddr2 ou timeout ne pointaient pas vers une adresse valide de l'espace utilisateur.
EINVAL
L'argument timeout fourni était invalide (tv_sec était inférieur à zéro, ou tv_nsec n'était pas inférieur à 1 000 000 000).
EINVAL
uaddr2 ne pointe pas vers un objet valide — c'est-à-dire que l'adresse n'est pas alignée sur quatre octets.
ENOSYS
Une vérification à l'exécution a déterminé que l'opération n'est pas disponible. Les opérations PI-futex ne sont pas implémentées sur toutes les architectures et ne sont pas supportées sur certaines variantes de CPU.
ETIMEDOUT
Le délai d'attente a expiré avant que l'opération ne soit terminée.

NORMES

Linux.

HISTORIQUE

Linux 2.6.31.
