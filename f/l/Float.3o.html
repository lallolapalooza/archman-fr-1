Arithmétique en virgule

flottante.

Les nombres en virgule flottante d'OCaml suivent la norme IEEE 754, en utilisant des nombres en double précision (64 bits). Les opérations en virgule flottante ne lèvent jamais d'exception en cas de débordement, de sous-dépassement, de division par zéro, etc. À la place, des nombres IEEE spéciaux sont renvoyés en fonction du cas, tels que infinity pour 1.0 /. 0.0 , neg_infinity pour -1.0 /. 0.0 , et nan ('not a number', non un nombre) pour 0.0 /. 0.0 . Ces nombres spéciaux se propagent ensuite à travers les calculs en virgule flottante comme prévu : par exemple, 1.0 /. infinity vaut 0.0 , les opérations arithmétiques de base ( +. , -. , *. , /. ) avec nan comme argument renvoient nan , ..

.

val fma : float -> float -> float ->

float

fma x y z renvoie x * y + z , avec un effort au mieux pour calculer cette expression avec un seul arrondi, en utilisant soit des instructions matérielles (fournissant une conformité complète à l'IEEE) soit une émulation

logicielle.

Sur Cygwin 64 bits, mingw-w64 64 bits et MSVC 2017 et antérieurs, cette fonction peut être émulée en raison de bugs connus ou de limitations sur ces plateformes. Remarque : puisque l'émulation logicielle de fma est coûteuse, assurez-vous que vous utilisez le support matériel de fma si la performance est

importante.

val nan : floa

t

Une valeur en virgule flottante spéciale dénotant le résultat d'une opération indéfinie telle que 0.0 /. 0.0 . Signifie 'not a number' (non un nombre). Toute opération en virgule flottante avec nan comme argument renvoie nan comme résultat, sauf indication contraire dans la norme IEEE 754. Quant aux comparaisons en virgule flottante, = , < , <= , > et >= renvoient false et <> renvoie true si un ou deux de leurs arguments est nan

.

nan est quiet_nan depuis 5.1 ; c'était un NaN signalant

avant.

val of_string : string ->

float

Convertit la chaîne donnée en un flottant. La chaîne est lue en décimal (par défaut) ou en hexadécimal (marqué par 0x ou 0X ). Le format des nombres en virgule flottante décimaux est [-] dd.ddd (e|E) [+|-] dd , où d représente un chiffre décimal. Le format des nombres en virgule flottante hexadécimaux est [-] 0(x|X) hh.hhh (p|P) [+|-] dd , où h représente un chiffre hexadécimal et d un chiffre décimal. Dans les deux cas, au moins une des parties entière et fractionnaire doit être donnée ; la partie exposant est facultative. Le _ (soulignement) peut apparaître n'importe où dans la chaîne et est ignoré. Selon les plateformes d'exécution, d'autres représentations des nombres en virgule flottante peuvent être acceptées, mais il ne faut pas s'y

fier.

Lève Failure si la chaîne donnée n'est pas une représentation valide d'un

flottant.

val of_string_opt : string -> float

option

Identique à of_string , mais renvoie None au lieu de lever une

exception.

val to_string : float ->

string

Renvoie une représentation sous forme de chaîne d'un nombre en virgule

Cette conversion peut entraîner une perte de précision. Pour un meilleur contrôle sur la manière dont le nombre est imprimé, voir Printf

Cette fonction est un alias pour string_of_f

val cos : float -> float

Cosinus. L'argument est en radians.

Sinus. L'argument est en radians.

Tangente. L'argument est en radians.

val acos : float -> float

Arc cosinus. L'argument doit être dans l'intervalle [-1.0, 1.0] . Le résultat est en radians et est compris entre 0.0 et pi .

val asin : float -> float

Arc sinus. L'argument doit être dans l'intervalle [-1.0, 1.0] . Le résultat est en radians et est compris entre -pi/2 et pi/2 .

val atan : float -> float

Arc tangente. Le résultat est en radians et est compris entre -pi/2 et pi/2 .

val atan2 : float -> float -> float

atan2 y x retourne l'arc tangente de y /. x . Les signes de x et y sont utilisés pour déterminer le quadrant du résultat. Le résultat est en radians et est compris entre -pi et pi .

val hypot : float -> float -> float

hypot x y retourne sqrt(x *. x +. y *. y) , c'est-à-dire la longueur de l'hypoténuse d'un triangle rectangle avec des côtés de longueur x et y , ou, de manière équivalente, la distance du point (x,y) à l'origine. Si l'un de x ou y est infini, retourne infinity même si l'autre est nan .

val cosh : float -> float

val sinh : float -> float

Sinus hyperbolique. L'argument est en radians.

val tanh : float -> float

Tangente hyperbolique. L'argument est en radians.

val acosh : float -> float

Arc cosinus hyperbolique. L'argument doit être dans l'intervalle [1.0, inf] . Le résultat est en radians et est compris entre 0.0 et inf .

Since 4.13

val asinh : float -> float

Since 4.13

val atanh : float -> float

Since 4.13

val erf : float -> float

Fonction d'erreur. L'argument parcourt toute la droite réelle. Le résultat est toujours compris entre [-1.0, 1.0] .

Since 4.13

val erfc : float -> float

Fonction d'erreur complémentaire ( erfc x = 1 - erf x ). L'argument parcourt toute la droite réelle. Le résultat est toujours compris entre [0.0, 2.0] .

Since 4.13

val trunc : float -> float

trunc x arrondit x à l'entier le plus proche dont la valeur absolue est inférieure ou égale à x .

Since 4.08

val round : float -> float

round x arrondit x à l'entier le plus proche, avec les cas d'égalité (valeurs fractionnaires de 0.5) arrondis à l'opposé de zéro, indépendamment de la direction d'arrondi actuelle. Si x est un entier, +0. , -0. , nan , ou infini, x lui-même est retourné.

Sur mingw-w64 64 bits, cette fonction peut être émulée en raison d'un bug dans la bibliothèque d'exécution C (CRT) sur cette plateforme.

Since 4.08

val ceil : float -> float

Arrondi supérieur à une valeur entière. ceil f retourne la plus petite valeur entière supérieure ou égale à f . Le résultat est retourné en tant que float.

val floor : float -> float

Arrondi inférieur à une valeur entière. floor f retourne la plus grande valeur entière inférieure ou égale à f . Le résultat est retourné en tant que float.

val next_after : float -> float -> float

next_after x y retourne la prochaine valeur flottante représentable suivant x dans la direction de y . Plus précisément, si y est supérieur (resp. inférieur) à x , il retourne le plus petit (resp. le plus grand) nombre représentable supérieur (resp. inférieur) à x . Si x est égal à y , la fonction retourne y . Si x ou y est nan , un nan est retourné. Notez que next_after max_float infinity = infinity et que next_after 0. infinity est le plus petit nombre positif dénormalisé. Si x est le plus petit nombre positif dénormalisé, next_after x 0. = 0.

Since 4.08

val copy_sign : float -> float -> float

copy_sign x y retourne un flottant dont la valeur absolue est celle de x et dont le signe est celui de y . Si x est nan , retourne nan . Si y est nan , retourne soit x soit -. x , mais on ne spécifie pas lequel.

val sign_bit : float -> bool

sign_bit x est true si et seulement si le bit de signe de x est défini. Par exemple, sign_bit 1. et signbit 0. sont false tandis que sign_bit (-1.) et sign_bit (-0.) sont true .

Since 4.08

val frexp : float -> float * int

frexp f retourne la paire de la mantisse et de l'exposant de f . Lorsque f est zéro, la mantisse x et l'exposant n de f sont égaux à zéro. Lorsque f est non nul, ils sont définis par f = x *. 2 ** n et 0.5 <= x < 1.0 .

val ldexp : float -> int -> float

ldexp x n retourne x *. 2 ** n .

val modf : float -> float * float

modf f retourne la paire de la partie fractionnaire et entière de f .

type t = float

Un alias pour le type des nombres à virgule flottante.

val compare : t -> t -> int

compare x y retourne 0 si x est égal à y , un entier négatif si x est inférieur à y , et un entier positif si x est supérieur à y . compare traite nan comme égal à lui-même et inférieur à toute autre valeur flottante. Ce traitement de nan garantit que compare définit une relation d'ordre total.

val equal : t -> t -> bool

La fonction d'égalité pour les nombres à virgule flottante, comparés en utilisant Float.compare .

val min : t -> t -> t

min x y retourne le minimum de x et y . Il retourne nan lorsque x ou y est nan . De plus, min (-0.) (+0.) = -0.

Since 4.08

val max : float -> float -> float

max x y retourne le maximum de x et y . Il retourne nan lorsque x ou y est nan . De plus, max (-0.) (+0.) = +0.

Since 4.08

val min_max : float -> float -> float * float

min_max x y est (min x y, max x y) , juste plus efficace.

Since 4.08

val min_num : t -> t -> t

min_num x y retourne le minimum de x et y en traitant nan comme des valeurs manquantes. Si x et y sont tous deux nan , nan est retourné. De plus, min_num (-0.) (+0.) = -0.

Since 4.08

val max_num : t -> t -> t

max_num x y retourne le maximum de x et y en traitant nan comme des valeurs manquantes. Si x et y sont tous deux nan , nan est retourné. De plus, max_num (-0.) (+0.) = +0.

Since 4.08

val min_max_num : float -> float -> float * float

min_max_num x y est (min_num x y, max_num x y) , juste plus efficace. Notez qu'en particulier, min_max_num x nan = (x, x) et min_max_num nan y = (y, y) .

Since 4.08

val seeded_hash : int -> t -> int

Une fonction de hachage amorcée pour les flottants, avec la même valeur de sortie que Hashtbl.seeded_hash . Cette fonction permet de passer ce module en argument au foncteur Hashtbl.MakeSeeded .

Since 5.1

val hash : t -> int

Une fonction de hachage non amorcée pour les flottants, avec la même valeur de sortie que Hashtbl.hash . Cette fonction permet de passer ce module en argument au foncteur Hashtbl.Make .
