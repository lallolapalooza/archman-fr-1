NOM

f2fscrypt - utilitaire de chiffrement du système de fichiers f2fs

SYNTAXE

f2fscrypt add_key -S [ -k keyring ] [-v] [-q] [ chemin ... ]
f2fscrypt new_session
f2fscrypt get_policy chemin ...
f2fscrypt set_policy politique chemin ...

DESCRIPTION

f2fscrypt effectue la gestion du chiffrement pour les systèmes de fichiers f2fs.

COMMANDES

f2fscrypt add_key -S [ -k keyring ] [-v] [-q] [ chemin ... ]
Demande à l'utilisateur une phrase secrète et l'insère dans le keyring spécifié. Si aucun keyring n'est spécifié, f2fscrypt utilisera le keyring de session s'il existe ou le keyring de session de l'utilisateur s'il n'existe pas.
Si un ou plusieurs chemins de répertoire sont spécifiés, f2fscrypt tentera de définir la politique de ces répertoires pour utiliser la clé qui vient d'être entrée par l'utilisateur.
f2fscrypt get_policy chemin ...
Affiche la politique pour les répertoires spécifiés sur la ligne de commande.
f2fscrypt new_session
Donne au processus appelant (généralement un shell) un nouveau keyring de session, en écartant son ancien keyring de session.
f2fscrypt set_policy politique chemin ...
Définit la politique pour les répertoires spécifiés sur la ligne de commande. Tous les répertoires doivent être vides pour définir la politique ; si le répertoire a déjà une politique établie, f2fscrypt validéra que la politique correspond à ce qui a été spécifié. Une politique est un identifiant de clé de chiffrement composé de 16 caractères hexadécimaux.

NOTES

Le répertoire cible doit être vide.

EXEMPLE

Formate un système de fichiers f2fs qui supporte le chiffrement.
# mkfs.f2fs -O encrypt /dev/sdxx
# mount /dev/sdxx /encrypted/
# mkdir /encrypted/dir
Créez d'abord la clé dans le keyring en utilisant un sel simple
(ou générez un sel aléatoire).
Utilisez-la ensuite pour définir la politique du répertoire à chiffrer.
# f2fscrypt add_key -S 0x1234
  Entrez la phrase secrète (l'affichage est désactivé) :
  Clé ajoutée avec le descripteur [28e21cc0c4393da1]
# f2fscrypt set_policy 28e21cc0c4393da1 /encrypted/dir
  Clé avec le descripteur [28e21cc0c4393da1] appliquée à /encrypted/dir.
# touch /encrypted/dir/test.txt
# ls -l /encrypted/dir/
  -rw-r--r--. 1 root root 0 Mar  5 21:41 test.txt
Après chaque redémarrage, la même commande peut être utilisée pour définir la
clé de déchiffrement du répertoire et de ses descendants.
# ls -l /encrypted/dir/
  -rw-r--r--. 1 root root 0 Mar  5 21:41 zbx7tsUEMLzh+AUVMkQcnB
# f2fscrypt get_policy /encrypted/dir/
  /encrypted/dir/: 28e21cc0c4393da1
# f2fscrypt add_key -S 0x1234
  Entrez la phrase secrète (l'affichage est désactivé) :
  Clé ajoutée avec le descripteur [28e21cc0c4393da1]
# ls -l /encrypted/dir/
  -rw-r--r--. 1 root root 0 Mar  5 21:41 test.txt
Afficher les keyrings de processus.
# keyctl show
  Keyring de session
    84022412 --alswrv      0     0  keyring: _ses
   204615789 --alswrv      0 65534   \_ keyring: _uid.0
   529474961 --alsw-v      0     0   \_ logon: f2fs:28e21cc0c4393da1
