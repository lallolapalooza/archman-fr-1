f2fs_io(8) Utilitaires d'administration système f2fs_io(8)

NOM

f2fs_io - utilitaire d'ioctl pour f2fs

DESCRIPTION

f2fs_io est utilisé pour envoyer diverses commandes au système de fichiers f2fs à des fins administratives.

COMMANDES DISPONIBLES

set_verity [fichier]
Définit les indicateurs de vérification associés au fichier spécifié.
getflags [fichier]
Récupère les indicateurs associés au fichier spécifié.
setflags [indicateur] [fichier]
Définit un indicateur de fichier f2fs sur le fichier spécifié. L'indicateur peut être casefold, compression, et nocompression.
shutdown systeme_de_fichiers
Gèle et arrête toutes les opérations d'E/S pour le système de fichiers monté sur dir. Le paramètre de niveau peut être :
0
arrêt avec synchronisation complète
1
arrêt avec seulement un point de contrôle
2
arrêt sans synchronisation
3
arrêt avec vidage des métadonnées
4
arrêt avec marquage fsck
pinfile [get|set] [fichier]
Obtient ou définit l'état d'épinglage sur un fichier.
fallocate [keep_size] [offset] [length] [fichier]
Demande l'allocation d'espace sur un fichier. Le paramètre keep_size peut être 1 ou 0.
write [taille_chunk_en_4kb] [offset_en_taille_chunk] [nombre] [motif] [IO] [chemin_fichier]
Écrit un motif donné dans chemin_fichier. Le paramètre motif peut être :
zero
zéros
inc_num
nombres incrémentiels
rand
nombres aléatoires
Le paramètre IO peut être :
buffered
E/S tamponnées
dio
E/S directes
dsync
E/S directes avec O_DSYNC
read [taille_chunk_en_4kb] [offset_en_taille_chunk] [nombre] [IO] [print_nbytes] [chemin_fichier]
Lit les données dans chemin_fichier et affiche print_nbytes. Les options IO peuvent être :
buffered
E/S tamponnées
dio
E/S directes
fiemap [offset_en_4kb] [nombre] [chemin_fichier]
obtient l'adresse du bloc dans le fichier
gc_urgent dev [start|end|run] [temps en secondes]
Démarre, termine ou exécute gc_urgent pendant une période donnée
defrag_file [start] [longueur] [chemin_fichier]
Défragmente un fichier.
copy [-d] [-m] [-s] [chemin_source] [chemin_destination]
Copie le fichier de chemin_source vers chemin_destination. Le paramètre motif peut être :
-d
utilise les E/S directes
-m
utilise mmap pour le fichier source
-s
utilise sendfile pour transférer les données
get_cblocks [fichier]
Obtient le nombre de blocs compressés.
release_cblocks [fichier]
Libère les blocs compressés pour obtenir de l'espace libre.
reserve_cblocks [fichier]
Réserve des blocs libres pour préparer la décompression des blocs dans le fichier.
gc [mode_sync] [fichier]
Déclenche le GC du système de fichiers
