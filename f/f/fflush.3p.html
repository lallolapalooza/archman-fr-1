Les fonctionnalités décrites sur cette page de référence sont alignées avec la norme ISO C. Tout conflit entre les exigences décrites ici et la norme ISO C est involontaire. Ce volume de POSIX.1‐2017 se conforme à la norme ISO

Si stream pointe vers un flux de sortie ou un flux de mise à jour dont la dernière opération n'était pas une entrée, fflush() fera en sorte que toutes les données non écrites pour ce flux soient écrites dans le fichier, et les horodatages de dernière modification des données et de dernier changement de statut du fichier sous-jacent seront marqués pour mise à

jour.

Pour un flux ouvert en lecture avec une description de fichier sous-jacente, si le fichier n'est pas déjà à EOF, et si le fichier est un fichier permettant le déplacement, le décalage de fichier de la description de fichier ouvert sous-jacente sera défini sur la position du flux, et tout caractère remis sur le flux par ungetc() ou ungetwc() qui n'a pas été lu par la suite depuis le flux sera jeté (sans modifier davantage le décalage de fichier)

.

Si stream est un pointeur nul, fflush() effectuera cette action de vidage sur tous les

flux pour lesquels le compor
tement est défini ci-dessus.

Envoi d'invites vers la sortie

standard

L'exemple suivant utilise des appels à printf() pour afficher une série d'invites pour des informations que l'utilisateur doit saisir depuis l'entrée standard. Les appels fflush() forcent l'écriture vers la sortie standard. La fonction fflush() est utilisée car la sortie standard est généralement tamponnée et l'invite peut ne pas être immédiatement imprimée sur la sortie ou le terminal. Les appels à la fonction getline() lisent des chaînes depuis l'entrée standard et placent les résultats dans des variables, pour une utilisation ultérieure dans le

programme.
