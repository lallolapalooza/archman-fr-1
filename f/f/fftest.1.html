fftest(1) Manuel des commandes générales fftest(1)

NOM

fftest - teste les périphériques à retour de force.

SYNTAXE

fftest <périphérique>

DESCRIPTION

fftest fournit une variété de tests qui peuvent être appliqués aux périphériques à retour de force. Attention, les tests peuvent endommager votre périphérique !

OPTIONS

<périphérique>
Le périphérique à tester.

VOIR AUSSI

ffcfstress(1), ffmvforce(1), jstest(1).
