FFMPEGTHUMBNAILER(1) Manuel des commandes générales FFMPEGTHUMBNAILER(1)

NOM

ffmpegthumbnailer - générateur de miniatures vidéo rapide et léger

SYNTAXE

ffmpegthumbnailer [options]

DESCRIPTION

Ffmpegthumbnailer est un générateur de miniatures vidéo léger qui peut être utilisé par les gestionnaires de fichiers pour créer des miniatures pour vos fichiers vidéo. Le générateur utilise ffmpeg pour décoder les images des fichiers vidéo, donc les formats vidéo pris en charge dépendent des options de configuration de ffmpeg.

OPTIONS

-i<s>
: fichier d'entrée
-o<s>
: fichier de sortie
-s<n>
: taille de la miniature (utiliser 0 pour la taille originale) (défaut : 128)
-q<n>
: qualité de l'image (0 = mauvaise, 10 = meilleure) (défaut : 8) (uniquement pour jpeg)
-c<s>
: remplacer le format de l'image (jpeg ou png) (défaut : déterminé par le nom de fichier)
-t<n|s>
: temps de recherche (pourcentage ou temps absolu hh:mm:ss) (défaut : 10 %)
-a
: ignorer le rapport d'aspect et générer une miniature carrée
-f
: créer une superposition de bande de film
-m
: préférer les métadonnées d'image intégrées au contenu vidéo
-h
: afficher cette aide
