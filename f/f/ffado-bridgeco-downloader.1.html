FFADO-BRIDGECO-DOWNLOADER(1) Manuel des commandes générales FFADO-BRIDGECO-DOWNLOADER(1)

NOM

ffado-bridgeco-downloader - application de téléchargement de firmware pour les périphériques BridgeCo

SYNTAXE

ffado-bridgeco-downloader [OPTION...] OPÉRATION

DESCRIPTION

ffado-bridgeco-downloader permet la mise à jour du firmware des périphériques BridgeCo (également appelés BeBoB) sous Linux. OPÉRATION décrit l'action à effectuer. Une OPÉRATION est introduite par le GUID du périphérique sur lequel opérer. Ceci est suivi par l'un des mots-clés suivants et tout argument requis par ce mot-clé.

afficher
Afficher des informations sur l'interface
setguid NOUVEAU_GUID
Définir le GUID du périphérique à NOUVEAU_GUID
firmware FICHIER
Télécharger le fichier firmware FICHIER sur le périphérique.
cne FICHIER
Télécharger le fichier CnE FICHIER sur le périphérique.
bcd FICHIER
Analyser le fichier BeBoB BCD FICHIER et afficher des informations sur son contenu.

OPTIONS

-?, --help, --usage
Afficher un bref message d'utilisation et quitter
-V, --version
Afficher la version du programme et quitter
-p, --port=NUM
Spécifier l'utilisation du port IEEE1394 NUM
-v, --verbose=NIVEAU
Produire une sortie détaillée. Plus le NIVEAU est élevé, plus les messages sont détaillés. Certains messages détaillés peuvent seulement être disponibles si FFADO a été compilé avec le débogage activé.
-b, --noboot
Ne pas démarrer le chargeur de démarrage. Utilisez cette option si le chargeur de démarrage est déjà en cours d'exécution.
-f, --force
Forcer le téléchargement du firmware même si le programme estime que ce n'est pas une bonne idée. À utiliser avec prudence.
-m, --magic=MAGIE
Un nombre magique que vous devez obtenir avant que ce programme puisse fonctionner. Le spécifier sur la ligne de commande signifie que vous acceptez les risques associés à cet outil. Le nombre magique peut être obtenu dans le code source.

NOTES

La manipulation du firmware peut entraîner l'arrêt de fonctionnement de votre périphérique. Le projet FFADO décline toute responsabilité en cas de dysfonctionnement résultant de l'utilisation de cet outil.
