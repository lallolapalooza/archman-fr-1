FFI(3) Manuel des fonctions de bibliothèque FFI(3)

NOM

FFI — Interface de fonction étrangère

BIBLIOTHÈQUE

libffi, -lffi

SYNTAXE

#include <ffi.h>

ffi_status
ffi_prep_cif(ffi_cif *cif, ffi_abi abi, unsigned int nargs, ffi_type *rtype, ffi_type **atypes);

void
ffi_prep_cif_var(ffi_cif *cif, ffi_abi abi, unsigned int nfixedargs, unsigned int ntotalargs, ffi_type *rtype, ffi_type **atypes);

void
ffi_call(ffi_cif *cif, void (*fn)(void), void *rvalue, void **avalue);

DESCRIPTION

L'interface de fonction étrangère fournit un mécanisme par lequel une fonction peut générer un appel à une autre fonction à l'exécution sans nécessiter la connaissance de l'interface de la fonction appelée au moment de la compilation.

VOIR AUSSI

ffi_prep_cif(3), ffi_prep_cif_var(3), ffi_call(3)
