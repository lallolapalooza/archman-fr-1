fflush(3) Manuel des fonctions de bibliothèque fflush(3)

NOM

fflush - vider un flux

BIBLIOTHQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <stdio.h>
int fflush(FILE *_Nullable stream);

DESCRIPTION

Pour les flux de sortie, fflush() force l'écriture de toutes les données en mémoire tampon de l'espace utilisateur pour le flux de sortie ou de mise à jour donné via la fonction d'écriture sous-jacente du flux.

Pour les flux d'entrée associés à des fichiers déplaçables (par exemple, les fichiers sur disque, mais pas les pipes ou les terminaux), fflush() abandonne toute donnée mise en mémoire tampon qui a été récupérée du fichier sous-jacent, mais qui n'a pas été consommée par l'application.

Le statut d'ouverture du flux n'est pas affecté.

Si l'argument stream est NULL, fflush() vide tous les flux de sortie ouverts.

Pour une contrepartie non verrouillable, voir unlocked_stdio(3).

VALEUR DE RETOUR

En cas de succès, 0 est renvoyé. Sinon, EOF est renvoyé et errno est défini pour indiquer l'erreur.

ERREURS

EBADF
stream n'est pas un flux ouvert, ou n'est pas ouvert en écriture.

La fonction fflush() peut également échouer et définir errno pour toutes les erreurs spécifiées pour write(2).

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
fflush () Sécurité des threads MT-Safe

NORMES

C11, POSIX.1-2008.

HISTORIQUE

C89, POSIX.1-2001, POSIX.1-2008.

POSIX.1-2001 ne spécifiait pas le comportement pour le vidage des flux d'entrée, mais le comportement est spécifié dans POSIX.1-2008.

NOTES

Notez que fflush() ne vide que les tampons de l'espace utilisateur fournis par la bibliothèque C. Pour s'assurer que les données sont physiquement stockées sur le disque, les tampons du noyau doivent également être vidés, par exemple, avec sync(2) ou fsync(2).
