Paquet: libffi

ffi_call(3) Manuel des fonctions de bibliothèque ffi_call(3)

NOM

ffi_call — Invoquer une fonction étrangère.

SYNTAXE

#include <ffi.h>

void
ffi_call(ffi_cif *cif, void (*fn)(void), void *rvalue, void **avalue);

DESCRIPTION

La fonction ffi_call fournit un mécanisme simple pour invoquer une fonction sans nécessiter la connaissance de son interface au moment de la compilation. fn est appelé avec les valeurs récupérées des pointeurs dans le tableau avalue. La valeur de retour de fn est placée dans le stockage pointé par rvalue. cif contient des informations décrivant les types de données, les tailles et les alignements des arguments de et de la valeur de retour de fn, et doit être initialisé avec ffi_prep_cif avant d'être utilisé avec ffi_call.

rvalue doit pointer vers un espace de stockage de taille égale ou supérieure à sizeof(ffi_arg) pour les types non flottants. Pour les types de valeurs de retour de taille plus petite, le type intégral ffi_arg ou ffi_sarg doit être utilisé pour conserver la valeur de retour.

EXEMPLES

#include <ffi.h>
#include <stdio.h>

unsigned char
foo(unsigned int, float);

int
main(int argc, const char **argv)
{
    ffi_cif cif;
    ffi_type *arg_types[2];
    void *arg_values[2];
    ffi_status status;

    // Comme la valeur de retour de foo() est plus petite que sizeof(long), elle
    // doit être passée en tant que ffi_arg ou ffi_sarg.
    ffi_arg result;

    // Spécifier le type de données de chaque argument. Les types disponibles sont définis
    // dans <ffi/ffi.h>.
    arg_types[0] = &ffi_type_uint;
    arg_types[1] = &ffi_type_float;

    // Préparer la structure ffi_cif.
    if ((status = ffi_prep_cif(&cif, FFI_DEFAULT_ABI,
        2, &ffi_type_uint8, arg_types)) != FFI_OK)
    {
        // Gérer l'erreur ffi_status.
    }

    // Spécifier les valeurs de chaque argument.
    unsigned int arg1 = 42;
    float arg2 = 5.1;

    arg_values[0] = &arg1;
    arg_values[1] = &arg2;

    // Invoquer la fonction.
    ffi_call(&cif, FFI_FN(foo), &result, arg_values);

    // Le ffi_arg 'result' contient maintenant l'unsigned char retourné par foo(),
    // qui peut être accédé par un transtypage.
    printf("le résultat est %hhu", (unsigned char)result);

    return 0;
}

// La fonction cible.
unsigned char
foo(unsigned int x, float y)
{
    unsigned char result = x - y;
    return result;
}
