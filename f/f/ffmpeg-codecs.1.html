NOM

ffmpeg-codecs - Codecs FFmpeg

DESCRIPTION

Ce document décrit les codecs (décodeurs et encodeurs) fournis par la bibliothèque libavcodec.

OPTIONS DE CODEC

libavcodec fournit des options globales génériques qui peuvent être définies sur tous les encodeurs et décodeurs. De plus, chaque codec peut supporter des options dites privées, spécifiques à un codec donné.

Parfois, une option globale ne peut affecter qu'un type spécifique de codec et peut être absurde ou ignorée par un autre, vous devez donc être conscient de la signification des options spécifiées. De plus, certaines options sont uniquement destinées au décodage ou à l'encodage.

Les options peuvent être définies en spécifiant -option valeur dans les outils FFmpeg, ou en définissant explicitement la valeur dans les options de "AVCodecContext" ou en utilisant l'API libavutil/opt.h pour une utilisation programmatique.

La liste des options supportées suit :

b entier (encodage,audio,vidéo)
Définit le débit binaire en bits/s. La valeur par défaut est 200K.
ab entier (encodage,audio)
Définit le débit binaire audio (en bits/s). La valeur par défaut est 128K.
bt entier (encodage,vidéo)
Définit la tolérance du débit binaire vidéo (en bits/s). En mode 1 passe, la gestion du débit spécifie à quel point le contrôle du débit est prêt à s'écarter de la valeur moyenne cible du débit. Ceci n'est pas lié au débit minimum/maximum. Abaisser trop la tolérance a un effet néfaste sur la qualité.
flags flags (décodage/encodage,audio,vidéo,sous-titres)
Définit des flags génériques.

Valeurs possibles :

mv4
Utilise quatre vecteurs de mouvement par macrobloc (mpeg4).
qpel
Utilise une compensation de mouvement de 1/4 de pixel.
loop
Utilise une boucle de filtrage.
qscale
Utilise une qscale fixe.
pass1
Utilise un contrôle de débit 2 passes interne en mode première passe.
pass2
Utilise un contrôle de débit 2 passes interne en mode deuxième passe.
gray
Décode/encode uniquement en niveaux de gris.
psnr
Définit les variables d'erreur[?] pendant l'encodage.
truncated
Le flux binaire d'entrée peut être tronqué aléatoirement.
drop_changed
Ne pas sortir les trames dont les paramètres diffèrent de la première trame décodée dans le flux. L'erreur AVERROR_INPUT_CHANGED est retournée lorsqu'une trame est ignorée.
ildct
Utilise la DCT entrelacée.
low_delay
Forcer une faible latence.
global_header
Placer les en-têtes globaux dans les métadonnées supplémentaires (extradata) au lieu de chaque image clé.
bitexact
N'écrire que des données indépendantes de la plateforme, de la compilation et du temps. (sauf DCT (I)). Cela garantit que les sommes de contrôle des fichiers et des données sont reproductibles et correspondent entre les plateformes. Son utilisation principale est pour les tests de régression.
aic
Appliquer le codage intra avancé H263 / prédiction AC mpeg4.
ilme
Appliquer une estimation de mouvement entrelacée.
cgop
Utiliser un GOP fermé.
output_corrupt
Sortir même les trames potentiellement corrompues.
time_base nombre rationnel
Définit la base de temps du codec.

C'est l'unité fondamentale de temps (en secondes) par rapport à laquelle les timestamps des trames sont représentés. Pour un contenu à FPS fixe, la base de temps devrait être "1 / frame_rate" et les incréments de timestamp devraient être identiques à 1.

g entier (encodage,vidéo)
Définit la taille du groupe d'images (GOP). La valeur par défaut est 12.
ar entier (décodage/encodage,audio)
Définit le taux d'échantillonnage audio (en Hz).
ac entier (décodage/encodage,audio)
Définit le nombre de canaux audio.
cutoff entier (encodage,audio)
Définit la bande passante de coupure. (Supporté uniquement par certains encodeurs, voir leurs sections de documentation respectives.)
frame_size entier (encodage,audio)
Définit la taille des trames audio.

Chaque trame soumise, sauf la dernière, doit contenir exactement frame_size échantillons par canal. Peut être 0 lorsque le codec a le drapeau CODEC_CAP_VARIABLE_FRAME_SIZE défini, auquel cas la taille de la trame n'est pas limitée. Il est défini par certains décodeurs pour indiquer une taille de trame constante.

frame_number entier
Définit le numéro de trame.
delay entier
qcomp flottant (encodage,vidéo)
Définit la compression de l'échelle de quantification vidéo (VBR). Elle est utilisée comme constante dans l'équation de contrôle du débit. Plage recommandée pour l'équation de contrôle du débit par défaut : 0.0-1.0.
qblur flottant (encodage,vidéo)
Définit le flou de l'échelle de quantification vidéo (VBR).
qmin entier (encodage,vidéo)
Définit l'échelle minimale de quantification vidéo (VBR). Doit être comprise entre -1 et 69, la valeur par défaut est 2.
qmax entier (encodage,vidéo)
Définit l'échelle maximale de quantification vidéo (VBR). Doit être comprise entre -1 et 1024, la valeur par défaut est 31.
qdiff entier (encodage,vidéo)
Définit la différence maximale entre les échelles de quantification (VBR).
bf entier (encodage,vidéo)
Définit le nombre maximum de trames B entre les trames non-B.

Doit être un entier compris entre -1 et 16. 0 signifie que les trames B sont désactivées. Si la valeur -1 est utilisée, une valeur automatique sera choisie en fonction de l'encodeur.

La valeur par défaut est 0.

QSVEnc

ffmpeg supports acceleration of encoding via the Intel® Quick Sync Video (QSV) technology.

The following encoders are available:

  • h264_qsv
  • hevc_qsv
  • mpeg2_qsv
  • vp9_qsv
  • av1_qsv
  • jpeg_qsv

For the fastest encoding speed set the qscale parameter (4 is the recommended value) and do not set a size constraint.

QSV Encoders

The family of Intel QuickSync Video encoders (MPEG-2, H.264, HEVC, JPEG/MJPEG, VP9, AV1)

Ratecontrol Method

The ratecontrol method is selected as follows:

•
When global_quality is specified, a quality-based mode is used. Specifically this means either
  • CQP - constant quantizer scale, when the qscale codec flag is also set (the -qscale ffmpeg option).
  • LA_ICQ - intelligent constant quality with lookahead, when the look_ahead option is also set.
  • ICQ -- intelligent constant quality otherwise. For the ICQ modes, global quality range is 1 to 51, with 1 being the best quality.
•
Otherwise when the desired average bitrate is specified with the b option, a bitrate-based mode is used.
  • LA - VBR with lookahead, when the look_ahead option is specified.
  • VCM - video conferencing mode, when the vcm option is set.
  • CBR - constant bitrate, when maxrate is specified and equal to the average bitrate.
  • VBR - variable bitrate, when maxrate is specified, but is higher than the average bitrate.
  • AVBR - average VBR mode, when maxrate is not specified, both avbr_accuracy and avbr_convergence are set to non-zero. This mode is available for H264 and HEVC on Windows.
•
Otherwise the default ratecontrol method CQP is used.

Note that depending on your system, a different mode than the one you specified may be selected by the encoder. Set the verbosity level to verbose or higher to see the actual settings used by the QSV runtime.

Global Options -> MSDK Options

Additional libavcodec global options are mapped to MSDK options as follows:

  • g/gop_size -> GopPicSize
  • bf/max_b_frames+1 -> GopRefDist
  • rc_init_occupancy/rc_initial_buffer_occupancy -> InitialDelayInKB
  • slices -> NumSlice
  • refs -> NumRefFrame
  • b_strategy/b_frame_strategy -> BRefType
  • cgop/CLOSED_GOP codec flag -> GopOptFlag
  • For the CQP mode, the i_qfactor/i_qoffset and b_qfactor/b_qoffset set the difference between QPP and QPI, and QPP and QPB respectively.
  • Setting the coder option to the value vlc will make the H.264 encoder use CAVLC instead of CABAC.
