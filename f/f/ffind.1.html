FFIND(1) Manuel des commandes générales FFIND(1)

NOM

ffind - Trouve le nom du fichier ou du répertoire à l'aide d'un inode donné

SYNTAXE

ffind [-aduvV] [-f fstype] [-i imgtype] [-o imgoffset] [-b taille_secteur_dev] image [images] inode

DESCRIPTION

ffind trouve les noms des fichiers ou répertoires qui sont alloués à inode sur l'image disque image. Par défaut, il ne renverra que le premier nom trouvé. Avec certains systèmes de fichiers, cela permettra de trouver les noms de fichiers supprimés.

ARGUMENTS

-a
Trouver toutes les occurrences de l'inode.
-d
Trouver uniquement les entrées supprimées.
-f fstype
Identifier le type de système de fichiers de l'image. Utiliser '-f list' pour lister les types de systèmes de fichiers supportés. Si non spécifié, des méthodes de détection automatique sont utilisées.
-u
Trouver uniquement les entrées non supprimées.
-i imgtype
Identifier le type de fichier image, comme 'raw'. Utiliser '-i list' pour lister les types supportés. Si non spécifié, des méthodes de détection automatique sont utilisées.
-o imgoffset
Le décalage de secteur où le système de fichiers commence dans l'image.
-b taille_secteur_dev
La taille, en octets, des secteurs du périphérique sous-jacent. Si non spécifié, la valeur dans le format de l'image est utilisée (si elle existe) ou 512 octets sont supposés.
-v
Sortie détaillée sur stderr.
-V
Afficher la version.
image [images]
L'image disque ou de partition à lire, dont le format est donné avec '-i'. Plusieurs noms de fichiers image peuvent être donnés si l'image est divisée en plusieurs segments. Si un seul fichier image est donné et que son nom est le premier d'une séquence (par exemple, indiqué par une fin en '.001'), les segments d'image suivants seront inclus automatiquement.
inode
Entier de l'inode à trouver.

Ce programme recherche toutes les entrées de répertoire à la recherche de l'inode donné. Ceci est utile lorsqu'un inode a été identifié à partir d'une adresse d'unité disque en utilisant ifind(1).

EXEMPLE

# ffind -a image 212
