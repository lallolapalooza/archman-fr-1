NOM

ffplay - Lecteur multimédia FFplay

SYNOPSIS

ffplay [options] [input_url]

DESCRIPTION

FFplay est un lecteur multimédia très simple et portable utilisant les bibliothèques FFmpeg et la bibliothèque SDL. Il est principalement utilisé comme banc d'essai pour les différentes API FFmpeg.

OPTIONS

Toutes les options numériques, sauf indication contraire, acceptent une chaîne représentant un nombre en entrée, qui peut être suivie de l'un des préfixes d'unité SI, par exemple : 'K', 'M' ou 'G'.

Si 'i' est ajouté au préfixe d'unité SI, le préfixe complet sera interprété comme un préfixe d'unité pour les multiples binaires, qui sont basés sur les puissances de 1024 au lieu des puissances de 1000. L'ajout de 'B' au préfixe d'unité SI multiplie la valeur par 8. Cela permet d'utiliser, par exemple : 'KB', 'MiB', 'G' et 'B' comme suffixes numériques.

Les options qui ne prennent pas d'arguments sont des options booléennes et définissent la valeur correspondante à true. Elles peuvent être définies à false en préfixant le nom de l'option par "no". Par exemple, l'utilisation de "-nofoo" définira l'option booléenne nommée "foo" à false.

Les options qui prennent des arguments prennent en charge une syntaxe spéciale où l'argument donné sur la ligne de commande est interprété comme un chemin vers le fichier à partir duquel la valeur réelle de l'argument est chargée. Pour utiliser cette fonctionnalité, ajoutez une barre oblique '/' immédiatement avant le nom de l'option (après le tiret initial). Par exemple :

ffmpeg -i INPUT -/filter:v filter.script OUTPUT

chargera une description de graphe de filtres à partir du fichier nommé filter.script.

Spécificateurs de flux

Certaines options sont appliquées par flux, par exemple le débit binaire ou le codec. Les spécificateurs de flux sont utilisés pour spécifier précisément à quel(s) flux une option donnée appartient.

Un spécificateur de flux est une chaîne généralement ajoutée au nom de l'option et séparée de celle-ci par un deux-points. Par exemple : "-codec:a:1 ac3" contient le "a:1" spécificateur de flux, qui correspond au deuxième flux audio. Par conséquent, il sélectionnera le codec ac3 pour le deuxième flux audio.

Un spécificateur de flux peut correspondre à plusieurs flux, de sorte que l'option est appliquée à tous. Par exemple, le spécificateur de flux dans "-b:a 128k" correspond à tous les flux audio.

Un spécificateur de flux vide correspond à tous les flux. Par exemple, "-codec copy" ou "-codec: copy" copieraient tous les flux sans réencodage.

Les formes possibles de spécificateurs de flux sont :

stream_index
Correspond au flux avec cet index. Par exemple : "-threads:1 4" définirait le nombre de threads du deuxième flux à 4. Si stream_index est utilisé comme spécificateur de flux supplémentaire (voir ci-dessous), alors il sélectionne le numéro de flux stream_index parmi les flux correspondants. La numérotation des flux est basée sur l'ordre des flux tels que détectés par libavformat, sauf si un spécificateur de groupe de flux ou un identifiant de programme est également spécifié. Dans ce cas, elle est basée sur l'ordre des flux dans le groupe ou le programme.
stream_type[:additional_stream_specifier]
stream_type est l'un des suivants : 'v' ou 'V' pour la vidéo, 'a' pour l'audio, 's' pour les sous-titres, 'd' pour les données et 't' pour les pièces jointes. 'v' correspond à tous les flux vidéo, 'V' ne correspond qu'aux flux vidéo qui ne sont pas des images jointes, des miniatures vidéo ou des pochettes. Si additional_stream_specifier est utilisé, alors il correspond aux flux qui ont à la fois ce type et correspondent au additional_stream_specifier. Sinon, il correspond à tous les flux du type spécifié.
g:group_specifier[:additional_stream_specifier]
Correspond aux flux qui sont dans le groupe avec le spécificateur group_specifier. Si additional_stream_specifier est utilisé, alors il correspond aux flux qui font à la fois partie du groupe et correspondent au additional_stream_specifier. group_specifier peut être l'un des suivants :
group_index
Correspond au flux avec cet index de groupe.
#group_id ou i:group_id
Correspond au flux avec cet identifiant de groupe.
p:program_id[:additional_stream_specifier]
Correspond aux flux qui sont dans le programme avec l'identifiant program_id. Si additional_stream_specifier est utilisé, alors il correspond aux flux qui font à la fois partie du programme et correspondent au additional_stream_specifier.
#stream_id ou i:stream_id
Correspond au flux par identifiant de flux (par exemple PID dans un conteneur MPEG-TS).
m:key[:value]
Correspond aux flux avec la balise de métadonnée key ayant la valeur spécifiée. Si value n'est pas donnée, correspond aux flux qui contiennent la balise donnée avec n'importe quelle valeur. Le caractère deux-points ':' dans key ou value doit être échappé par une barre oblique inverse.
disp:dispositions[:additional_stream_specifier]
Correspond aux flux avec la ou les disposition(s) donnée(s). dispositions est une liste d'une ou plusieurs dispositions (telles qu'affichées par l' -dispositions option) jointes par '+'.
u
Correspond aux flux avec une configuration utilisable, le codec doit être défini et les informations essentielles telles que les dimensions vidéo ou la fréquence d'échantillonnage audio doivent être présentes.

Notez que dans ffmpeg, la correspondance par métadonnées ne fonctionnera correctement que pour les fichiers d'entrée.

-loglevel [drapeaux+]niveau_de_journalisation | -v [drapeaux+]niveau_de_journalisation
Définit le niveau de journalisation et les drapeaux utilisés par la bibliothèque.

Le préfixe drapeaux facultatif peut être composé des valeurs suivantes :

repeat
Indique que la sortie de journal répétée ne doit pas être compressée dans la première ligne et que la ligne « Last message repeated n times » sera omise.
level
Indique que la sortie de journal doit ajouter un préfixe "[level]" à chaque ligne de message. Cela peut être utilisé comme alternative à la coloration du journal, par exemple lors de l'écriture du journal dans un fichier.
time
Indique que les lignes de journal doivent être préfixées par des informations de temps.
datetime
Indique que les lignes de journal doivent être préfixées par des informations de date et d'heure.

Les drapeaux peuvent également être utilisés seuls en ajoutant un préfixe '+'/'-' pour activer/réinitialiser un seul drapeau sans affecter les autres drapeaux ni modifier le niveau_de_journalisation. Lors de la définition à la fois des drapeaux et du niveau_de_journalisation, un séparateur '+' est attendu entre la dernière valeur de drapeaux et avant le niveau_de_journalisation.

niveau_de_journalisation est une chaîne ou un nombre contenant l'une des valeurs suivantes :

quiet, -8
N'affiche rien du tout ; rester silencieux.
panic, 0
Affiche uniquement les erreurs fatales qui pourraient faire planter le processus, comme un échec d'assertion. Cela n'est actuellement utilisé pour rien.
fatal, 8
Affiche uniquement les erreurs fatales. Ce sont des erreurs après lesquelles le processus ne peut absolument pas continuer.
error, 16
Affiche toutes les erreurs, y compris celles dont on peut se remettre.
warning, 24
Affiche tous les avertissements et erreurs. Tout message lié à des événements potentiellement incorrects ou inattendus sera affiché.
info, 32
Affiche des messages informatifs pendant le traitement. C'est en plus des avertissements et des erreurs. C'est la valeur par défaut.
verbose, 40
Identique à "info", mais plus verbeux.
debug, 48
Affiche tout, y compris les informations de débogage.
trace, 56

Par exemple, pour activer la sortie de journal répétée, ajoutez le préfixe "level" et définissez niveau_de_journalisation sur "verbose":

ffmpeg -loglevel repeat+level+verbose -i input output

Un autre exemple qui active la sortie de journal répétée sans affecter l'état actuel du drapeau de préfixe "level" ou du niveau_de_journalisation:

ffmpeg [...] -loglevel +repeat

Par défaut, le programme journalise sur stderr. Si le terminal prend en charge la coloration, des couleurs sont utilisées pour marquer les erreurs et les avertissements. La coloration du journal peut être désactivée en définissant la variable d'environnement AV_LOG_FORCE_NOCOLOR, ou peut être forcée en définissant la variable d'environnement AV_LOG_FORCE_COLOR.

-report
Écrit la ligne de commande complète et la sortie du journal dans un fichier nommé "programme-AAAAMMJJ-HHMMSS.log" dans le répertoire courant. Ce fichier peut être utile pour les rapports de bogues. Cela implique également "-loglevel debug".

Définir la variable d'environnement FFREPORT sur n'importe quelle valeur a le même effet. Si la valeur est une séquence clé=valeur séparée par des ':', ces options affecteront le rapport ; les valeurs d'options doivent être échappées si elles contiennent des caractères spéciaux ou le délimiteur d'options ':' (voir la section « Quoting and escaping » du manuel ffmpeg-utils).

Les options suivantes sont reconnues :

file
définit le nom de fichier à utiliser pour le rapport ; %p est développé en le nom du programme, %t est développé en un horodatage, "%%" est développé en un simple "%"
level
définit le niveau de verbosité du journal à l'aide d'une valeur numérique (voir "-loglevel").

Par exemple, pour écrire un rapport dans un fichier nommé ffreport.log en utilisant un niveau de journalisation de 32 (alias pour le niveau de journalisation "info") :

FFREPORT=file=ffreport.log:level=32 ffmpeg -i input output

Les erreurs lors de l'analyse de la variable d'environnement ne sont pas fatales et n'apparaîtront pas dans le rapport.

AVOptions

Ces options sont fournies directement par les bibliothèques libavformat, libavdevice et libavcodec. Pour voir la liste des AVOptions disponibles, utilisez l'option -help . Elles sont séparées en deux catégories :

génériques
Ces options peuvent être définies pour tout conteneur, codec ou dispositif. Les options génériques sont listées sous les options AVFormatContext pour les conteneurs/dispositifs et sous les options AVCodecContext pour les codecs.
privées
Ces options sont spécifiques au conteneur, dispositif ou codec donné. Les options privées sont listées sous leurs conteneurs/dispositifs/codecs correspondants.

Par exemple, pour écrire un en-tête ID3v2.3 au lieu d'un ID3v2.4 par défaut dans un fichier MP3, utilisez l'option privée id3v2_version du multiplexeur MP3 :

ffmpeg -i input.flac -id3v2_version 3 out.mp3

Toutes les AVOptions de codec sont par flux, et donc un spécificateur de flux doit leur être attaché :

ffmpeg -i multichannel.mxf -map 0:v:0 -map 0:a:0 -map 0:a:0 -c:a:0 ac3 -b:a:0 640k -ac:a:1 2 -c:a:1 aac -b:2 128k out.mp4

Dans l'exemple ci-dessus, un flux audio multicanal est mappé deux fois pour la sortie. La première instance est encodée avec le codec ac3 et un débit de 640k. La deuxième instance est rééchantillonnée en 2 canaux et encodée avec le codec aac. Un débit de 128k est spécifié pour elle en utilisant l'index absolu du flux de sortie.

Remarque : la syntaxe -nooption ne peut pas être utilisée pour les AVOptions booléennes, utilisez -option 0/-option 1.

Remarque : l'ancienne méthode non documentée de spécification des AVOptions par flux en préfixant le nom de l'option par v/a/s est désormais obsolète et sera bientôt supprimée.

-vf filtergraph
Crée le graphe de filtres spécifié par filtergraph et l'utilise pour filtrer le flux vidéo.

Dans le graphe de filtres, l'entrée est associée à l'étiquette "in", et la sortie à l'étiquette "out". Voir le manuel ffmpeg-filters pour plus d'informations sur la syntaxe des graphes de filtres.

-af filtergraph

Options avancées

-stats
Affiche plusieurs statistiques de lecture, en particulier la durée du flux, les paramètres du codec, la position actuelle dans le flux et la dérive de synchronisation audio/vidéo. Il est affiché par défaut, sauf si le niveau de journalisation est inférieur à "info". Son affichage peut être forcé en spécifiant manuellement cette option. Pour le désactiver, vous devez spécifier "-nostats".
-fast
Optimisations non conformes à la spécification.
-genpts
Génère les pts.
-sync type
Définit l'horloge maître sur audio ("type=audio"), vidéo ("type=video") ou externe ("type=ext"). Par défaut, c'est l'audio. L'horloge maître est utilisée pour contrôler la synchronisation audio-vidéo. La plupart des lecteurs multimédias utilisent l'audio comme horloge maître, mais dans certains cas (diffusion en flux ou de haute qualité) il est nécessaire de changer cela. Cette option est principalement utilisée à des fins de débogage.
-ast audio_stream_specifier
Sélectionnez le flux audio souhaité à l'aide du spécificateur de flux donné. Les spécificateurs de flux sont décrits dans le Spécificateurs de flux chapitre. Si cette option n'est pas spécifiée, le flux audio « best » (meilleur) est sélectionné dans le programme du flux vidéo déjà sélectionné.
-vst video_stream_specifier
Sélectionnez le flux vidéo souhaité à l'aide du spécificateur de flux donné. Les spécificateurs de flux sont décrits dans le Spécificateurs de flux chapitre. Si cette option n'est pas spécifiée, le flux vidéo « best » (meilleur) est sélectionné.
-sst subtitle_stream_specifier
Sélectionnez le flux de sous-titres souhaité à l'aide du spécificateur de flux donné. Les spécificateurs de flux sont décrits dans le Spécificateurs de flux chapitre. Si cette option n'est pas spécifiée, le flux de sous-titres « best » (meilleur) est sélectionné dans le programme du flux vidéo ou audio déjà sélectionné.
-autoexit
Quitte lorsque la lecture de la vidéo est terminée.
-exitonkeydown
Quitte si une touche est pressée.
-exitonmousedown
Quitte si un bouton de la souris est pressé.
-codec:media_specifier codec_name
Force une implémentation de décodeur spécifique pour le flux identifié par media_specifier, qui peut prendre les valeurs "a" (audio), "v" (vidéo), et "s" sous-titres.
-acodec codec_name
Force un décodeur audio spécifique.
-vcodec codec_name
Force un décodeur vidéo spécifique.
-scodec codec_name
Force un décodeur de sous-titres spécifique.
-autorotate
Fait pivoter automatiquement la vidéo en fonction des métadonnées du fichier. Activé par défaut, utilisez -noautorotate pour le désactiver.
-framedrop
Abandonne les images vidéo si la vidéo est désynchronisée. Activé par défaut si l'horloge maître n'est pas réglée sur la vidéo. Utilisez cette option pour activer l'abandon d'images pour toutes les sources d'horloge maître, utilisez -noframedrop pour le désactiver.
-infbuf
Ne limite pas la taille du tampon d'entrée, lit autant de données que possible depuis l'entrée dès que possible. Activé par défaut pour les flux temps réel, où des données peuvent être abandonnées si elles ne sont pas lues à temps. Utilisez cette option pour activer des tampons infinis pour toutes les entrées, utilisez -noinfbuf pour le désactiver.
-filter_threads nb_threads
Définit combien de threads sont utilisés pour traiter un pipeline de filtres. Chaque pipeline produira un pool de threads avec ce nombre de threads disponibles pour un traitement parallèle. La valeur par défaut est 0, ce qui signifie que le nombre de threads sera déterminé par le nombre de CPU disponibles.
-enable_vulkan
Utilise le rendu vulkan plutôt que le rendu intégré de SDL. Dépend de libplacebo.
-vulkan_params
Configuration Vulkan à l'aide d'une liste de paires clé=valeur séparées par ":".
-hwaccel
Utilise le décodage accéléré par le matériel. L'activation de cette option activera automatiquement le rendu vulkan.
