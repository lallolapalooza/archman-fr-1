NOM

ffado-fireworks-downloader - application de téléchargement de firmware pour les périphériques Echo Fireworks

SYNTAXE

ffado-fireworks-downloader [OPTION...] OPERATION

DESCRIPTION

ffado-bridgeco-downloader permet de mettre à jour le firmware des périphériques Echo Fireworks sous Linux. OPERATION décrit l'action à effectuer. Une OPERATION comprend l'un des mots-clés suivants et les arguments requis par ce mot-clé.

lister
Lister les périphériques sur le bus FireWire.
afficher
Afficher des informations sur un périphérique et son firmware.
télécharger FICHIER
Télécharger le firmware contenu dans FICHIER vers le périphérique
dossier FICHIER ADR_DÉBUT LONGUEUR
Télécharger le contenu de la mémoire flash du périphérique. LONGUEUR octets seront téléchargés à partir de ADR_DÉBUT et écrits dans le fichier FICHIER
vérifier FICHIER
Vérifier que le firmware contenu dans le périphérique correspond à celui de FICHIER
session_afficher
Afficher des informations sur la session sur le périphérique.
session_info FICHIER
Afficher des informations sur la session du périphérique stockée dans FICHIER
session_dossier FICHIER
Télécharger le contenu de la session du périphérique dans FICHIER
session_télécharger FICHIER
Télécharger la session depuis FICHIER vers le périphérique.

OPTIONS

-h, --help
Afficher un bref résumé d'utilisation et quitter
-p, --port=NUM
Spécifier l'utilisation du port IEEE1394 NUM
-v, --verbose=NIVEAU
Produire une sortie détaillée. Plus le NIVEAU est élevé, plus les messages sont détaillés. Certains messages détaillés peuvent uniquement être disponibles si FFADO a été compilé avec le débogage activé.
-g, --guid=GUID
Spécifier le GUID du périphérique avec lequel interagir. Si ce n'est pas spécifié, une tentative sera faite pour détecter automatiquement un périphérique approprié.
-m, --magic=MAGIE
Un nombre magique que vous devez obtenir avant que ce programme ne fonctionne. Le spécifier sur la ligne de commande signifie que vous acceptez les risques associés à cet outil. Le nombre magique peut être obtenu dans le code source.

NOTES

La manipulation du firmware peut entraîner l'arrêt de votre périphérique. Le projet FFADO n'accepte aucune responsabilité si cela se produit à la suite de l'utilisation de cet outil.
