NOM

fftw-wisdom-to-conf - génère des sagesses FFTW (transformations pré-planifiées)

SYNTAXE

fftw-wisdom-to-conf [< ENTRÉE] [> SORTIE]

DESCRIPTION

fftw-wisdom-to-conf est un utilitaire pour générer des routines de **configuration** C à partir de fichiers de **sagesse** FFTW, ces derniers contenant des informations sauvegardées sur la manière de calculer de manière optimale des transformations (de Fourier) de différentes tailles. Une routine de configuration est une sous-routine C que vous liez à votre programme, remplaçant une routine du même nom dans la bibliothèque FFTW, qui détermine quelles parties de FFTW sont appelables par votre programme.

La raison d'être de ceci est que, si vous n'avez besoin que de transformations d'un ensemble limité de tailles et de types, et si vous liez statiquement votre programme, l'utilisation d'un fichier de configuration généré à partir de la sagesse pour ces types peut réduire considérablement la taille de votre exécutable. (Sinon, en raison de la nature dynamique de FFTW, tout le code de transformation de FFTW doit être lié à tout programme utilisant FFTW.)

FFTW est une bibliothèque libre pour calculer des transformées de Fourier discrètes en une ou plusieurs dimensions, pour des tailles arbitraires, et sur des données réelles et complexes, entre autres opérations connexes. Plus d'informations sur FFTW peuvent être trouvées sur la page d'accueil de FFTW : http://www.fftw.org

fftw-wisdom-to-conf lit la sagesse depuis l'entrée standard et écrit la configuration en sortie standard. Il peut être facilement combiné avec l'outil fftw-wisdom, par exemple :

fftw-wisdom -n -o sagesse cof1024 cob1024
fftw-wisdom-to-conf < sagesse > conf.c

créera une configuration « conf.c » contenant uniquement les parties de FFTW nécessaires pour les transformations complexes directes et inverses optimisées hors emplacement de taille 1024 (sauvegardant également la sagesse elle-même dans « sagesse »).

Alternativement, vous pouvez exécuter votre programme réel, exporter la sagesse pour tous les plans qui ont été créés (idéalement en mode FFTW_PATIENT ou FFTW_EXHAUSTIVE), utiliser ceci comme entrée pour fftw-wisdom-to-conf, puis relier votre programme avec la routine de configuration résultante.

Notez que la routine de configuration ne contient pas la sagesse, mais seulement les routines nécessaires pour implémenter la sagesse. Votre programme devrait donc également importer la sagesse afin de bénéficier des plans pré-optimisés.
