NOM

ffado-dbus-server - exposer les fonctionnalités du mixeur des périphériques FFADO connectés via DBus

SYNTAXE

ffado-dbus-server [OPTION...]

DESCRIPTION

ffado-dbus-server expose les fonctionnalités du mixeur et de contrôle des périphériques FFADO connectés via une interface DBus. L'étendue du support des contrôles sur un périphérique donné dépend entièrement de l'état du pilote FFADO de ce périphérique.

En utilisant DBus, il est possible de développer des applications de contrôle indépendamment de FFADO. L'interface DBus fournie par ffado-dbus-server est utilisée par ffado-mixer, mais il n'y a aucune raison pour que d'autres implémentations ne puissent pas être écrites.

OPTIONS

-?, --help, --usage
Afficher un bref résumé d'utilisation et quitter
-V, --version
Afficher la version du programme et quitter
, --quiet, --silent
Ne produire aucune sortie
-n, --node=ID
Exposer uniquement le mixeur d'un périphérique sur un nœud spécifique avec l'identifiant ID
-p, --port=NUM
Spécifier l'utilisation du port IEEE1394 NUM
-v, --verbose=LEVEL
Produire une sortie détaillée. Plus le LEVEL est élevé, plus les messages sont détaillés. Certains messages détaillés peuvent n'être disponibles que si FFADO a été compilé avec le débogage activé.
