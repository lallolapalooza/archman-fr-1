FFADO-MIXER(1) Manuel des commandes générales FFADO-MIXER(1)

NOM

ffado-mixer - une interface graphique pour les contrôles du mixeur FFADO exposés par ffado-dbus-server.

SYNTAXE

ffado-mixer [options]

Options disponibles : [-b]

DESCRIPTION

ffado-mixer présente une application graphique permettant de contrôler un périphérique FFADO. L'étendue du contrôle est déterminée par le niveau de prise en charge du périphérique dans FFADO et dans ffado-dbus-server. Les contrôles typiques offerts par ffado-mixer incluent les faders pour le mixeur intégré, le contrôle de l'alimentation fantôme, les commutateurs de mode, etc.

OPTIONS

-b
Ne pas interroger ffado-dbus-server pour une interface active. Au lieu de cela, créer une instance d'un mixeur pour chaque interface prise en charge telle que définie dans le fichier de configuration de FFADO, avec des stubs fournissant des valeurs de substitution à la place des réglages obtenus de l'interface. Ceci est principalement destiné à aider au débogage.
