NOM

ffmpeg-resampler - Rééchantillonneur FFmpeg

DESCRIPTION

Le rééchantillonneur FFmpeg fournit une interface de haut niveau aux utilitaires de rééchantillonnage audio de la bibliothèque libswresample. En particulier, il permet d'effectuer le rééchantillonnage audio, la rematrice des disposition de canaux audio, et de convertir le format audio et la disposition de l'empaquetage.

OPTIONS DU RÉÉCHANTILLONNEUR

Le rééchantillonneur audio prend en charge les options nommées suivantes.

Les options peuvent être définies en spécifiant -option valeur dans les outils FFmpeg, option=valeur pour le filtre aresample, en définissant la valeur explicitement dans les "SwrContext" options ou en utilisant libavutil/opt.h API pour une utilisation programmatique.

uchl, used_chlayout
Définit la disposition de canaux d'entrée utilisée. Par défaut, non définie. Cette option n'est utilisée que pour un remappage spécial.
isr, in_sample_rate
Définit la fréquence d'échantillonnage d'entrée. La valeur par défaut est 0.
osr, out_sample_rate
Définit la fréquence d'échantillonnage de sortie. La valeur par défaut est 0.
isf, in_sample_fmt
Spécifie le format d'échantillon d'entrée. Il est défini par défaut à "none".
osf, out_sample_fmt
Spécifie le format d'échantillon de sortie. Il est défini par défaut à "none".
tsf, internal_sample_fmt
Définit le format d'échantillon interne. La valeur par défaut est "none". Il sera automatiquement choisi lorsqu'il n'est pas défini explicitement.
ichl, in_chlayout
ochl, out_chlayout
Définit la disposition de canaux d'entrée/sortie.

Voir la section Disposition des canaux dans le manuel ffmpeg-utils(1) pour la syntaxe requise.

clev, center_mix_level
Définit le niveau de mixage du canal central. C'est une valeur exprimée en décibels, et doit être dans l'intervalle [-32,32].
slev, surround_mix_level
Définit le niveau de mixage des canaux surround. C'est une valeur exprimée en décibels, et doit être dans l'intervalle [-32,32].
lfe_mix_level
Définit le niveau de mixage LFE vers non-LFE. Il est utilisé lorsqu'il y a une entrée LFE mais pas de sortie LFE. C'est une valeur exprimée en décibels, et doit être dans l'intervalle [-32,32].
rmvol, rematrix_volume
Définit le volume de rematrice. La valeur par défaut est 1.0.
rematrix_maxval
Définit la valeur de sortie maximale pour la rematrice. Cela peut être utilisé pour prévenir le clipping par rapport à la prévention de la réduction du volume. Une valeur de 1.0 prévient le clipping.
flags, swr_flags
Définit les drapeaux utilisés par le convertisseur. La valeur par défaut est 0.

Il prend en charge les drapeaux individuels suivants :

res
force le rééchantillonnage, ce drapeau force l'utilisation du rééchantillonnage même lorsque les fréquences d'échantillonnage d'entrée et de sortie correspondent.
dither_scale
Définit l'échelle de dither. La valeur par défaut est 1.
dither_method
Définit la méthode de dither. La valeur par défaut est 0.

Valeurs prises en charge :

rectangular
sélectionne le dither rectangulaire
triangular
sélectionne le dither triangulaire
triangular_hp
sélectionne le dither triangulaire avec passe-haut
lipshitz
sélectionne le dither de façonnage de bruit Lipshitz.
shibata
sélectionne le dither de façonnage de bruit Shibata.
low_shibata
sélectionne le dither de façonnage de bruit Shibata bas.
high_shibata
sélectionne le dither de façonnage de bruit Shibata haut.
f_weighted
sélectionne le dither de façonnage de bruit pondéré par f
modified_e_weighted
sélectionne le dither de façonnage de bruit pondéré par e modifié
improved_e_weighted
sélectionne le dither de façonnage de bruit pondéré par e amélioré
resampler
Définit le moteur de rééchantillonnage. La valeur par défaut est swr.

Valeurs prises en charge :

swr
sélectionne le rééchantillonneur SW natif ; les options de filtre precision et cheby ne sont pas applicables dans ce cas.
soxr
sélectionne le rééchantillonneur SoX (si disponible) ; la compensation et les options de filtre filter_size, phase_shift, exact_rational, filter_type et kaiser_beta ne sont pas applicables dans ce cas.
filter_size
Uniquement pour swr, définit la taille du filtre de rééchantillonnage, la valeur par défaut est 32.
phase_shift
Uniquement pour swr, définit le décalage de phase du rééchantillonnage, la valeur par défaut est 10, et doit être dans l'intervalle [0,30].
linear_interp
Utilise l'interpolation linéaire lorsqu'elle est activée (par défaut). Désactivez-la si vous souhaitez préserver la vitesse plutôt que la qualité lorsque exact_rational échoue.
exact_rational
Uniquement pour swr, lorsqu'il est activé, essaie d'utiliser un phase_count exact basé sur les fréquences d'échantillonnage d'entrée et de sortie. Cependant, s'il est supérieur à "1 << phase_shift", le phase_count sera "1 << phase_shift" en secours. Activé par défaut.
cutoff
Définit le rapport de la fréquence de coupure (swr : point à 6dB ; soxr : point à 0dB) ; doit être une valeur flottante entre 0 et 1. La valeur par défaut est 0.97 avec swr, et 0.91 avec soxr (ce qui, avec une fréquence d'échantillonnage de 44100, préserve toute la bande audio jusqu'à 20kHz).
precision
Uniquement pour soxr, la précision en bits à laquelle le signal rééchantillonné sera calculé. La valeur par défaut de 20 (qui, avec un dithering approprié, convient à une profondeur de bits de destination de 16) donne le « High Quality » de SoX ; une valeur de 28 donne le « Very High Quality » de SoX.
cheby
Uniquement pour soxr, sélectionne le roulement de bande passante aucun (Tchebychev) et l'approximation de plus haute précision pour les ratios « irrationnels ». La valeur par défaut est 0.
async
Uniquement pour swr, synchronisation audio simple à 1 paramètre aux horodatages en utilisant l'étirement, la compression, le remplissage et le rognage. Définir cela à 1 activera le remplissage et le rognage, des valeurs plus grandes représentent la quantité maximale en échantillons que les données peuvent être étirées ou compressées par seconde. La valeur par défaut est 0, aucune compensation n'est donc appliquée pour faire correspondre les échantillons aux horodatages audio.
first_pts
Uniquement pour swr, suppose que le premier pts doit être cette valeur. L'unité de temps est 1 / fréquence d'échantillonnage. Cela permet de compléter/rogner au début du flux. Par défaut, aucune hypothèse n'est faite sur le pts attendu de la première image, donc aucun complément ou rognage n'est effectué. Par exemple, cela pourrait être défini à 0 pour compléter le début avec du silence si un flux audiorts après la vidéo ou pour rogner tout échantillon dont le pts est négatif en raison du délai de l'encodeur.
min_comp
Pour swr uniquement, définir la différence minimale entre les horodatages et les données audio (en secondes) pour déclencher l'étirement/la compression/le remplissage ou le rognage des données afin de les faire correspondre aux horodatages. Par défaut, l'étirement/la compression/le remplissage et le rognage sont désactivés (min_comp = "FLT_MAX").
min_hard_comp
Pour swr uniquement, définir la différence minimale entre les horodatages et les données audio (en secondes) pour déclencher l'ajout/suppression d'échantillons afin de les faire correspondre aux horodatages. Cette option sert effectivement de seuil pour choisir entre une compensation dure (rognage/remplissage) et souple (compression/étirement). Notez que toute compensation est désactivée par défaut via min_comp. La valeur par défaut est 0.1.
comp_duration
Pour swr uniquement, définir la durée (en secondes) sur laquelle les données sont étirées/compressées pour les faire correspondre aux horodatages. Doit être une valeur flottante double non négative, la valeur par défaut est 1.0.
max_soft_comp
Pour swr uniquement, définir le facteur maximal par lequel les données sont étirées/compressées pour les faire correspondre aux horodatages. Doit être une valeur flottante double non négative, la valeur par défaut est 0.
matrix_encoding
Sélectionner l'encodage stéréo matriciel.

Il accepte les valeurs suivantes :

none
sélectionner none
dolby
sélectionner Dolby
dplii
sélectionner Dolby Pro Logic II

La valeur par défaut est "none".

filter_type
Pour swr uniquement, sélectionner le type de filtre de rééchantillonnage. Cela n'affecte que les opérations de rééchantillonnage.

Il accepte les valeurs suivantes :

cubic
sélectionner cubique
blackman_nuttall
sélectionner fenêtre de Blackman Nuttall appliquée à un sinc
kaiser
sélectionner fenêtre de Kaiser appliquée à un sinc
kaiser_beta
Pour swr uniquement, définir la valeur bêta de la fenêtre de Kaiser. Doit être une valeur flottante double dans l'intervalle [2,16], la valeur par défaut est 9.
output_sample_bits
Pour swr uniquement, définir le nombre de bits d'échantillon de sortie utilisés pour le dithering. Doit être un entier dans l'intervalle [0,64], la valeur par défaut est 0, ce qui signifie qu'il n'est pas utilisé.
