NOM

ffi_prep_cif — Prépare une structure ffi_cif pour une utilisation avec ffi_call

SYNTAXE

#include <ffi.h>

ffi_status
ffi_prep_cif(ffi_cif *cif, ffi_abi abi, unsigned int nargs, ffi_type *rtype, ffi_type **atypes);

DESCRIPTION

La fonction ffi_prep_cif prépare une structure ffi_cif pour une utilisation avec ffi_call. abi spécifie un ensemble de conventions d'appel à utiliser. atypes est un tableau de nargs pointeurs vers des structures ffi_type décrivant le type de données, la taille et l'alignement de chaque argument. rtype pointe vers une structure ffi_type décrivant le type de données, la taille et l'alignement de la valeur de retour. Notez que pour appeler une fonction variadique, il faut utiliser ffi_prep_cif_var à la place.

VALEURS DE RETOUR

En cas de succès, ffi_prep_cif renvoie FFI_OK. Elle renvoie FFI_BAD_TYPEDEF si cif est NULL ou si atypes ou rtype sont malformés. Si abi ne fait pas référence à un ABI valide, FFI_BAD_ABI sera renvoyé. Les ABI disponibles sont définis dans <ffitarget.h>.

VOIR AUSSI

ffi(3), ffi_call(3), ffi_prep_cif_var(3)
