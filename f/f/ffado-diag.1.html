NOM

ffado-diag - imprime les informations de diagnostic système relatives à FFADO.

SYNTAXE

ffado-diag[--static|-V|--version|--usage]

DESCRIPTION

ffado-diag imprime une collection étendue d'informations de diagnostic sur l'ordinateur sur lequel il est exécuté. Les informations incluent le numéro de version de FFADO, le numéro de version des bibliothèques dont FFADO dépend, la carte d'interface FireWire, l'utilisation des interruptions, etc. Ceci est utile pour les développeurs afin de savoir quand fournir un support via les listes de diffusion FFADO. Pour tout problème autre que trivial, la sortie de ffado-diag sera l'une des premières choses demandées lors du débogage d'un problème.

OPTIONS

-V, --version Affiche les informations de version. --usage Imprime un court message d'utilisation et quitte. --static N'affiche que les chemins des exécutables et les bibliothèques.
