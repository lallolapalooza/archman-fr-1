FFADO-DICE-FIRMWARE(1) Manuel des commandes générales FFADO-DICE-FIRMWARE(1)

NOM

ffado-dice-firmware - application de téléchargement de firmware pour les appareils basés sur DICE

SYNTAXE

ffado-dice-firmware [OPTION...]

DESCRIPTION

ffado-dice-firmware permet les mises à jour du firmware des appareils basés sur DICE sous Linux.

OPTIONS

-h, --help
Afficher un bref résumé d'utilisation et quitter
-p, --port=NUM
Spécifier l'utilisation du port IEEE1394 NUM
-v, --verbose=LEVEL
Produire une sortie verbeuse. Plus le LEVEL est élevé, plus les messages sont verbeux. Certains messages verbeux peuvent n'être disponibles que si FFADO a été compilé avec le débogage activé.
-d, --delete=IMAGENAME
Supprimer l'image par nom.
-e, --dump=FILENAME
Extraire le contenu actuel de la mémoire flash de l'appareil DICE dans le fichier FILENAME
-f, --flash=FILENAME
Écrire le fichier de firmware FILENAME sur l'appareil DICE.
-i, --image-info
Afficher des informations détaillées sur chaque image du firmware sur l'appareil.
-m, --flash-info
Afficher des informations sur la mémoire flash de l'appareil.
-s, --dice-info
Afficher les informations du fournisseur et du produit de l'image DICE.
-t, --test OPERATION
Invoquer une opération de test/débogage. Les OPERATIONs possibles sont 1 (POKE, écrire à une adresse) et 2 (PEEK, lire depuis une adresse). Référez-vous au code source pour plus d'informations.
-n, --node NODE
Spécifier le nœud sur lequel opérer.

NOTES

La manipulation du firmware peut entraîner le dysfonctionnement de votre appareil. Le projet FFADO décline toute responsabilité en cas de tels problèmes résultant de l'utilisation de cet outil.
