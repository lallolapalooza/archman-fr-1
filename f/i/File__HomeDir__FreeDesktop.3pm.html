NOM

File::HomeDir::FreeDesktop - Trouver votre répertoire personnel et d'autres répertoires sur Unix FreeDesktop.org

DESCRIPTION

Ce module fournit des implémentations pour déterminer les répertoires utilisateur courants. En utilisation normale, ce module sera toujours utilisé via File::HomeDir.

Ce module ne peut fonctionner que lorsque la commande "xdg-user-dir" est disponible et exécutable, ce qui est généralement réalisé en installant un paquet nommé "xdg-user-dirs" ou similaire.

On peut trouver la dernière spécification à https://specifications.freedesktop.org/basedir-spec/basedir-spec-latest.html.

SYNTAXE

use File::HomeDir;

# Trouver les répertoires pour l'utilisateur courant
$home     = File::HomeDir->my_home;        # /home/mylogin
$desktop  = File::HomeDir->my_desktop;
$docs     = File::HomeDir->my_documents;
$music    = File::HomeDir->my_music;
$pics     = File::HomeDir->my_pictures;
$videos   = File::HomeDir->my_videos;
$data     = File::HomeDir->my_data;
$config   = File::HomeDir->my_config;

# Certains non documentés, attendez-vous à ce qu'ils ne fonctionnent pas - utilisez avec prudence
$download    = File::HomeDir->my_download;
$publicshare = File::HomeDir->my_publicshare;
$templates   = File::HomeDir->my_templates;
$cache       = File::HomeDir->my_cache;
