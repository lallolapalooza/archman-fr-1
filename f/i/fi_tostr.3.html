NOM

fi_fabric - Opérations réseau de fabric

fi_fabric / fi_close
Ouvrir / fermer un réseau de fabric
fi_tostr / fi_tostr_r
Convertir les attributs, les indicateurs et les capacités de fabric en chaîne imprimable

SYNOPSIS

#include <rdma/fabric.h>
int fi_fabric(struct fi_fabric_attr *attr,
    struct fid_fabric **fabric, void *context);
int fi_close(struct fid *fabric);
char * fi_tostr(const void *data, enum fi_type datatype);
char * fi_tostr_r(char *buf, size_t len, const void *data,
    enum fi_type datatype);

Tampon de sortie dans lequel écrire la chaîne.

DESCRIPTION

Un identifiant de fabric est utilisé pour référencer les ressources de fabric ouvertes et les objets liés à la bibliothèque.

Le réseau de fabric représente un ensemble de ressources matérielles et logicielles qui accèdent à un réseau physique ou virtuel unique. Tous les ports réseau d'un système qui peuvent communiquer entre eux via leurs réseaux attachés appartiennent au même fabric. Un réseau de fabric partage des adresses réseau et peut s'étendre sur plusieurs fournisseurs. Une application doit ouvrir un réseau de fabric avant d'allouer d'autres ressources réseau, comme les points de communication.

fi_fabric

Ouvre un fournisseur de réseau de fabric. Les attributs du fournisseur de fabric sont spécifiés via l'appel d'ouverture et peuvent être obtenus en appelant fi_getinfo.

fi_close

L'appel fi_close est utilisé pour libérer toutes les ressources associées à un objet fabric. Tous les éléments associés au fabric ouvert doivent être libérés avant d'appeler fi_close.

fi_tostr / fi_tostr_r

Convertit les attributs d'interface de fabric, les capacités, les indicateurs et les valeurs d'énumération en une chaîne imprimable. Le paramètre data accepte un pointeur vers l'attribut ou les valeurs à afficher, le paramètre datatype indiquant le type de données référencé par le paramètre data. fi_tostr() renverra un pointeur vers un tampon interne de libfabric qui ne doit pas être modifié et qui sera écrasé la prochaine fois que fi_tostr() sera invoqué. fi_tostr() n'est pas sûr dans un environnement multi-thread.

La fonction fi_tostr_r() est une version réentrante et sûre dans un environnement multi-thread de fi_tostr(). Elle écrit la chaîne dans un tampon fourni par l'appelant. fi_tostr_r() renvoie le début du tampon de l'appelant.

NOTES

Les ressources suivantes sont associées aux domaines de fabric : domaines d'accès, points de passif et files d'événements CM.

ATTRIBUTS DE FABRIC

La structure fi_fabric_attr définit l'ensemble des attributs associés à un fabric et à un fournisseur de fabric.

struct fi_fabric_attr {
    struct fid_fabric *fabric;
    char              *name;
    char              *prov_name;
    uint32_t          prov_version;
    uint32_t          api_version;
};

fabric

En entrée de fi_getinfo, un utilisateur peut définir ceci sur une instance de fabric ouverte pour limiter la sortie au fabric donné. En sortie de fi_getinfo, si aucun fabric n'a été spécifié, mais que l'utilisateur a une instance ouverte du fabric nommé, celui-ci référencera la première instance ouverte. Si aucune instance n'a été ouverte, ce champ sera NULL.
