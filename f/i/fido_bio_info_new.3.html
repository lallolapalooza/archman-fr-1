FIDO_BIO_INFO_NEW(3) Manuel des fonctions de bibliothèque FIDO_BIO_INFO_NEW(3)

NOM

fido_bio_info_new, fido_bio_info_free, fido_bio_info_type, fido_bio_info_max_samples — API d'informations sur le capteur biométrique FIDO2

SYNOPIS

#include <fido.h>
#include <fido/bio.h>

fido_bio_info_t *
fido_bio_info_new(void);

void
fido_bio_info_free(fido_bio_info_t **info_p);

uint8_t
fido_bio_info_type(const fido_bio_info_t *info);

uint8_t
fido_bio_info_max_samples(const fido_bio_info_t *info);

DESCRIPTION

Les métadonnées du capteur biométrique sont abstraites dans libfido2 par le type fido_bio_info_t.

Les fonctions décrites dans cette page permettent d'allouer, de désallouer et d'inspecter un type fido_bio_info_t. Pour les opérations sur les périphériques concernant fido_bio_info_t, veuillez vous référer à fido_bio_dev_get_info(3).

La fonction fido_bio_info_new() renvoie un pointeur vers un type fido_bio_info_t nouvellement alloué et vide. Si la mémoire ne peut être allouée, NULL est renvoyé.

La fonction fido_bio_info_free() libère la mémoire qui soutient *info_p, où *info_p doit avoir été préalablement alloué par fido_bio_info_new(). Au retour, *info_p est mis à NULL. Soit info_p soit *info_p peut être NULL, auquel cas fido_bio_info_free() ne fait rien.

La fonction fido_bio_info_type() renvoie le type de capteur d'empreintes digitales, qui est 1 pour les capteurs tactiles et 2 pour les capteurs par balayage.

La fonction fido_bio_info_max_samples() renvoie le nombre maximum d'échantillons réussis requis pour l'enregistrement.
