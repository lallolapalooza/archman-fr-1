NOM

File::HomeDir::Darwin - Trouver votre répertoire personnel et autres répertoires sous Darwin (OS X)

DESCRIPTION

Ce module fournit des implémentations spécifiques à Darwin pour déterminer les répertoires utilisateur courants. En utilisation normale, ce module sera toujours utilisé via File::HomeDir.

Note -- comme ce module nécessite Mac::Carbon et que Mac::Carbon ne fonctionne pas avec les perls 64 bits, sur de tels systèmes, File::HomeDir essaiera File::HomeDir::Darwin::Cocoa puis se rabattra sur File::HomeDir::Darwin (en pur Perl).

SYNTAXE

use File::HomeDir;
# Trouver les répertoires pour l'utilisateur actuel
$home    = File::HomeDir->my_home;      # /Users/mylogin
$desktop = File::HomeDir->my_desktop;   # /Users/mylogin/Desktop
$docs    = File::HomeDir->my_documents; # /Users/mylogin/Documents
$music   = File::HomeDir->my_music;     # /Users/mylogin/Music
$pics    = File::HomeDir->my_pictures;  # /Users/mylogin/Pictures
$videos  = File::HomeDir->my_videos;    # /Users/mylogin/Movies
$data    = File::HomeDir->my_data;      # /Users/mylogin/Library/Application Support
