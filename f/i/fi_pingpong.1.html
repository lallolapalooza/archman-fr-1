DESCRIPTIO

N

fi_pingpong est un test pingpong pour la fonctionnalité principale de la bibliothèque libfabric : la transmission de données entre deux processus. fi_pingpong affiche également des statistiques agrégées après chaque exécution du test, et peut en plus vérifier l'intégrité des données à la

réception.

Par défaut, le point de terminaison datag

ramme (FI_EP_DGRAM) est utilisé pour le
test, sauf indication contraire via -e.

OPTION

S

Le serveur et le client doivent pouvoir communiquer correctement pour que l'utilitaire fi_pingpong fonctionne. Si l'une des options -e, -I, -S ou -p est utilisée, elle doit être spécifiée lors de l'invocation pour à la fois le serveur et le processus client. Si l'option -d est spécifiée sur le serveur, alors le client sélectionnera le domaine approprié si aucune indication n'est fournie sur le côté client. Si l'option -d est spécifiée sur le client, elle doit également être spécifiée sur le serveur. Si à la fois le serveur et le client spécifient l'option -d et que les domaines donnés ne peuvent pas communiquer, alors l'application

échouera.

VALEURS PAR

DÉFAUT

Il n'y a pas de fournisseur par défaut ; si un fournisseur n'est pas spécifié via l'option -p, le test en sélectionnera un dans la liste des fournisseurs disponibles (tels que renvoyés par fi_getinfo(3))

.

Si aucun type de point de terminaison n'est spécifié, `dgram' est

utilisé.

Les tailles testées par défaut sont : 64, 256, 1024, 4096, 65536 et 104

8576. Le test ne testera que les tailles qui se situent dans les limites
de la taille maximale de message des points de terminaison sélectionnés.
