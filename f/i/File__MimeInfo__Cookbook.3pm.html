NOM

File::MimeInfo::Cookbook - divers extraits de code

DESCRIPTION

Quelques extraits de code pour des utilisations non basiques du module File::MimeInfo :

Correspondance d'une extension
Un fichier n'a pas besoin d'exister réellement pour obtenir son type MIME. Cela signifie que ce qui suit fonctionnera : 
my $extension = '*.txt';
my $mimetype = mimetype( $extension );
Détermination du type MIME d'un scalaire
Si vous souhaitez connaître le type MIME d'une valeur scalaire, vous avez besoin d'une détermination magique des types MIME ; après tout, un scalaire n'a ni nom de fichier ni inode. Ce que vous devez faire est d'utiliser IO::Scalar : 
use File::MimeInfo::Magic;
use IO::Scalar;
my $io_scalar = new IO::Scalar \$data;
my $mimetype = mimetype( $io_scalar );

En fait, la plupart des autres objets "IO::" fonctionneront tant qu'ils supporteront les méthodes seek() et read(). Bien sûr, si vous voulez des choses vraiment obscures, vous pouvez toujours écrire votre propre objet IO et le lui fournir.

Soyez conscient que lors de l'utilisation d'un descripteur de fichier de cette manière, vous devrez définir vous-même le mode binaire ":utf8" si approprié.

Détermination du type MIME d'un descripteur de fichier
Malheureusement, pour les descripteurs de fichier non exploitables en recherche telle que STDIN, l'utilisation d'un objet "IO::" ne fonctionnera pas. Vous devrez mettre en mémoire tampon suffisamment de données pour une détermination correcte du type MIME. Par exemple, vous pourriez déterminer le type MIME des données provenant de STDIN comme ceci : 
use File::MimeInfo::Magic;
use IO::Scalar;
my $data;
read(STDIN, $data, $File::MimeInfo::Magic::max_buffer);
my $io_scalar = new IO::Scalar \$data;
my $mimetype = mimetype( $io_scalar );

Soyez conscient que lors de l'utilisation d'un descripteur de fichier de cette manière, vous devrez définir vous-même le mode binaire ":utf8" si approprié.

Création d'un nouveau nom de fichier
Supposons que vous ayez un fichier temporaire que vous souhaitez enregistrer avec un nom de fichier plus approprié. 
use File::MimeInfo::Magic qw#mimetype extensions#;
use File::Copy;
my $tmpfile = '/tmp/foo';
my $mimetype = mimetype($tmpfile);
my $extension = extensions($mimetype);
my $newfile = 'untitled1';
$newfile .= '.'.$extension if length $extension;
move($tmpfile, $newfile);
Forcer l'utilisation d'un répertoire de base de données donné
Normalement, il vous suffit d'ajouter le répertoire où se trouve votre base de données MIME à l'une des variables d'environnement XDG_DATA_HOME ou XDG_DATA_DIRS pour qu'elle soit trouvée. Mais dans certains cas rares, vous pourriez vouloir contourner ce système entièrement. Essayez l'une des méthodes suivantes : 
@File::MimeInfo::DIRS = ('/home/moi/share/mime');
eval 'use File::MimeInfo';
die if $@;

ou :

use File::MimeInfo;
@File::MimeInfo::DIRS = ('/home/moi/share/mime');
File::MimeInfo->rehash();

Cela peut également être utilisé pour basculer entre les bases de données à l'exécution tout en laissant intacts les autres éléments de configuration XDG.
