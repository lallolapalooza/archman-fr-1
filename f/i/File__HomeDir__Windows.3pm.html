NOM

File::HomeDir::Windows - Trouver votre répertoire personnel et autres répertoires sous Windows

SYNTAXE

use File::HomeDir;

# Trouver les répertoires pour l'utilisateur courant (par ex. en utilisant Windows XP Professionnel)
$home    = File::HomeDir->my_home;        # C:\Documents and Settings\monlogin
$desktop = File::HomeDir->my_desktop;     # C:\Documents and Settings\monlogin\Bureau
$docs    = File::HomeDir->my_documents;   # C:\Documents and Settings\monlogin\Mes Documents
$music   = File::HomeDir->my_music;       # C:\Documents and Settings\monlogin\Mes Documents\Ma Musique
$pics    = File::HomeDir->my_pictures;    # C:\Documents and Settings\monlogin\Mes Documents\Mes Images
$videos  = File::HomeDir->my_videos;      # C:\Documents and Settings\monlogin\Mes Documents\Mes Vidéos
$data    = File::HomeDir->my_data;        # C:\Documents and Settings\monlogin\Paramètres locaux\Application Data

DESCRIPTION

Ce module fournit des implémentations spécifiques à Windows pour déterminer les répertoires utilisateur courants. En utilisation normale, ce module sera toujours utilisé via File::HomeDir.

En interne, ce module utilisera Win32::GetFolderPath pour récupérer l'emplacement de vos répertoires. Par conséquent, dans certaines situations inhabituelles (généralement rencontrées dans les grandes organisations), les méthodes peuvent renvoyer des chemins UNC tels que "\\cifs.local\home$".

Si votre application s'exécute sous Windows et que vous souhaitez qu'elle fonctionne de manière exhaustive partout, vous devrez peut-être implémenter votre propre gestion de ces chemins, car ils peuvent causer des comportements étranges.

Par exemple, les appels stat sur les chemins UNC peuvent fonctionner mais bloquer pendant plusieurs secondes, tandis que opendir() peut ne pas pouvoir lire de fichiers (créant l'apparence d'un répertoire existant mais vide).

Pour éviter de compliquer davantage le problème, dans la rare situation où un chemin UNC est renvoyé par "GetFolderPath", les vérifications de validation usuelles -d ne seront pas effectuées.
