NOM

fido_assert_verify — vérifie la signature d'une instruction d'assertion FIDO2

SYNOP.

#include <fido.h>

int
fido_assert_verify(const fido_assert_t *assert, size_t idx, int cose_alg, const void *pk);

DESCRIPTION

La fonction fido_assert_verify() vérifie si la signature contenue dans l'index d'instruction idx de assert correspond aux paramètres de l'assertion. Avant d'utiliser fido_assert_verify() dans un contexte sensible, il est fortement recommandé au lecteur de se familiariser avec le processus d'instruction d'assertion FIDO2 tel que défini dans la norme Web Authentication (webauthn).

Une brève description suit :

La fonction fido_assert_verify() vérifie si le hachage des données client, l'ID du fournisseur de services, la présence utilisateur et les attributs de vérification utilisateur de assert ont été attestés par le détenteur du compagnon privé de la clé publique pk de type COSE cose_alg, où cose_alg est COSE_ES256, COSE_ES384, COSE_RS256, ou COSE_EDDSA, et pk pointe vers un type es256_pk_t, es384_pk_t, rs256_pk_t, ou eddsa_pk_t en conséquence.

Veuillez noter que la première instruction dans assert a un idx de 0.

VALEUR DE RETOUR

Les codes d'erreur renvoyés par fido_assert_verify() sont définis dans <fido/err.h>. Si l'instruction idx de assert passe la vérification avec pk, alors FIDO_OK est renvoyé.

VOIR AUSSI

fido_assert_new(3), fido_assert_set_authdata(3)
