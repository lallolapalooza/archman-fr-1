NOM

firewall-config - outil de configuration graphique pour firewalld

SYNTAXE

firewall-config [OPTIONS...]

DESCRIPTION

firewall-config est un outil de configuration graphique pour firewalld.

OPTIONS

firewall-config ne prend en charge aucune option spéciale. Les seules options qui peuvent être utilisées sont les options générales que Gtk utilise pour l'initialisation des applications Gtk. Pour plus d'informations sur ces options, veuillez consulter la documentation d'exécution de Gtk.

Les options suivantes sont prises en charge :

-h, --help

Affiche un court texte d'aide et quitte.
