NOM

File::ShareDir - Localiser les fichiers partagés par distribution et par module

SYNOPSIS

use File::ShareDir ':ALL';

# Où se trouvent les fichiers de données partagés au niveau de la distribution
$dir = dist_dir('File-ShareDir');

# Où se trouvent les fichiers de données partagés au niveau du module
$dir = module_dir('File::ShareDir');

# Trouver un fichier spécifique dans notre répertoire partagé de dist/module
$file = dist_file(  'File-ShareDir',  'file/name.txt');
$file = module_file('File::ShareDir', 'file/name.txt');

# Comme module_file, mais recherche dans l'arbre d'héritage
$file = class_file( 'Foo::Bar', 'file/name.txt' );

DESCRIPTION

L'intention de File::ShareDir est de fournir un compagnon à Class::Inspector et File::HomeDir, des modules qui prennent un processus bien connu des développeurs Perl avancés mais qui devient un peu délicat, et le rendent plus accessible à la communauté Perl dans son ensemble.

Très souvent, vous voulez ou avez besoin que votre module Perl (CPAN ou autre) ait accès à une grande quantité de données en lecture seule stockées sur le système de fichiers au moment de l'exécution.

Sur un système de type Linux, cela se trouverait dans un endroit comme /usr/share, cependant Perl s'exécute sur une grande variété de systèmes différents, et donc l'utilisation d'un seul emplacement n'est pas fiable.

Perl fournit une méthode peu connue pour faire cela, mais presque personne n'est conscient de son existence. En conséquence, les auteurs de modules passent souvent par des moyens très étranges pour rendre les données disponibles à leur code.

Le plus courant consiste à déverser les données dans une structure de données Perl énorme et à l'enregistrer dans le module lui-même. Le résultat sont des fichiers .pm énormes de plusieurs mégaoctets qui consomment beaucoup de mémoire inutilement.

Une autre méthode consiste à mettre les données "fichier" après la balise de compilateur __DATA__ et à se limiter à l'accès comme un filehandle.

Le problème à résoudre est vraiment assez simple.

1. Écrire les fichiers de données sur le système au moment de l'installation.

2. Savoir où vous les avez placés au moment de l'exécution.

Le système d'installation de Perl crée un répertoire "auto" pour chaque distribution et pour chaque fichier de module.

Ceux-ci sont utilisés par quelques systèmes de chargement automatique différents pour stocker des fragments de code générés à l'installation, et divers autres modules écrits par les "anciens maîtres" de Perl.

Mais le même mécanisme est disponible à toute dist ou module pour stocker n'importe quel type de données.

Utilisation de Données dans votre Module

"File::ShareDir" constitue une moitié d'une solution en deux parties.

Une fois que les fichiers ont été installés dans le répertoire correct, vous pouvez utiliser "File::ShareDir" pour retrouver vos fichiers après l'installation.

Pour la partie installation de la solution, voir File::ShareDir::Install et sa directive "install_share" [[38]].

L'utilisation de File::ShareDir::Install avec File::ShareDir permet de s'appuyer sur les fichiers dans les dist_dir() ou module_dir() appropriés aussi en phase de développement.

FONCTIONS

"File::ShareDir" fournit quatre fonctions pour localiser les fichiers et les répertoires.

Pour une meilleure maintenabilité, aucune de celles-ci n'est exportée par défaut et vous devez nommer celles que vous voulez au moment du use, ou fournir la balise ':ALL' . Toutes les suivantes sont équivalentes.

# Charger mais ne pas importer, puis appeler directement
use File::ShareDir;
$dir = File::ShareDir::dist_dir('My-Dist');

# Importer une seule fonction
use File::ShareDir 'dist_dir';
dist_dir('My-Dist');

# Importer toutes les fonctions
use File::ShareDir ':ALL';
dist_dir('My-Dist');

Toutes les fonctions vérifieront pour vous que le répertoire/fichier existe réellement, et que vous avez les permissions de lecture, ou elles lèveront une exception.

dist_dir

# Obtenir le répertoire des fichiers partagés d'une distribution
my $dir = dist_dir('My-Distribution');

La fonction "dist_dir" prend un paramètre unique, le nom d'une distribution installée (CPAN ou autre), et localise le répertoire de données partagé créé à l'installation pour elle.

Retourne le chemin du répertoire sous forme de chaîne, ou meurt s'il ne peut pas être localisé ou n'est pas lisible.

module_dir

# Obtenir le répertoire des fichiers partagés d'un module
my $dir = module_dir('My::Module');

La fonction "module_dir" prend un paramètre unique, le nom d'un module installé (CPAN ou autre), et localise le répertoire de données partagé créé à l'installation pour lui.

Afin de trouver le répertoire, le module doit être chargé lors de l'appel de cette fonction.

Retourne le chemin du répertoire sous forme de chaîne, ou meurt s'il ne peut pas être localisé ou n'est pas lisible.

dist_file

# Trouver un fichier dans notre répertoire partagé de distribution
my $dir = dist_file('My-Distribution', 'file/name.txt');

La fonction "dist_file" prend deux paramètres, le nom de la distribution et le nom du fichier, localise le répertoire de la dist, puis trouve le fichier à l'intérieur, vérifiant que le fichier existe réellement, et qu'il est lisible.

Le nom de fichier doit être un chemin relatif au format de votre système de fichiers local. Il sera simplement ajouté au répertoire en utilisant la méthode "catfile" de File::Spec.

Retourne le chemin du fichier sous forme de chaîne, ou meurt si le fichier ou le répertoire de la dist ne peuvent pas être localisés, ou si le fichier n'est pas lisible.

module_file

# Trouver un fichier dans notre répertoire partagé de module
my $dir = module_file('My::Module', 'file/name.txt');

La fonction "module_file" prend deux paramètres, le nom du module et le nom du fichier. Elle localise le répertoire du module, puis trouve le fichier à l'intérieur, vérifiant que le fichier existe réellement, et qu'il est lisible.

Afin de trouver le répertoire, le module doit être chargé lors de l'appel de cette fonction.

Le nom de fichier doit être un chemin relatif au format de votre système de fichiers local. Il sera simplement ajouté au répertoire en utilisant la méthode "catfile" de File::Spec.

Retourne le chemin du fichier sous forme de chaîne, ou meurt si le fichier ou le répertoire de la dist ne peuvent pas être localisés, ou si le fichier n'est pas lisible.

class_file

# Trouver un fichier dans notre répertoire partagé de module, ou dans notre classe parente
my $dir = class_file('My::Module', 'file/name.txt');

La fonction "module_file" prend deux paramètres, le nom du module et le nom du fichier. Elle localise le répertoire du module, puis trouve le fichier à l'intérieur, vérifiant que le fichier existe réellement, et qu'il est lisible.

Afin de trouver le répertoire, le module doit être chargé lors de l'appel de cette fonction.

Le nom de fichier doit être un chemin relatif au format de votre système de fichiers local. Il sera simplement ajouté au répertoire en utilisant la méthode "catfile" de File::Spec.

Si le fichier n'est PAS trouvé pour ce module, "class_file" parcourra l'arbre @ISA du module, à la recherche du fichier dans toutes les classes parentes.

Cela vous permet, en effet, de "sous-classer" les fichiers partagés.

Retourne le chemin du fichier sous forme de chaîne, ou meurt si le fichier ou le répertoire de la dist ne peuvent pas être localisés, ou si le fichier n'est pas lisible.

EXTENSION

Redéfinition de la Résolution des Répertoires

"File::ShareDir" a deux hachages de commodité pour les personnes ayant des exigences d'utilisation avancées de "File::ShareDir" comme l'utilisation de répertoires "share" non installés pendant le développement.

#
# Nom-Dist => /chemin/absolu/pour/NomDist/share/dir
#
%File::ShareDir::DIST_SHARE
#
# Nom::Module => /chemin/absolu/pour/Nom/Module/share/dir


    
        
        
        File::ShareDir::MODULE_SHARE - Perl documentation
        
    
    
        

            

                



File::ShareDir::MODULE_SHARE


Définir ces valeurs à tout moment avant les appels correspondants


dist_dir('Dist-Name')
dist_file('Dist-Name','some/file');
module_dir('Module::Name');
module_file('Module::Name','some/file');


Remplacera le répertoire de base pour la résolution de ces appels.


Un exemple où cela pourrait être utile est dans un test pour un module
    qui dépend de fichiers installés dans un répertoire partagé, pour permettre aux tests
    d'utiliser la copie de développement sans avoir à les installer au préalable.


use File::ShareDir;
use Cwd qw( getcwd );
use File::Spec::Functions qw( rel2abs catdir );
$File::ShareDir::MODULE_SHARE{'Foo::Module'} = rel2abs(catfile(getcwd,'share'));
use Foo::Module;
# les appels internes dans Foo::Module à module_file('Foo::Module','bar') résolvent maintenant vers
# le répertoire share/ de l'arbre source au lieu de quelque chose dans @INC
