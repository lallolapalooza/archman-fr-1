NOM

FileZilla - Client FTP

SYNTAXE

filezilla
filezilla [-l <typedeconnexion>] <URL FTP>
filezilla -h|-s|-v
filezilla -c <site>
filezilla -a <chemin>

DESCRIPTION

FileZilla est un client puissant pour le FTP simple, le FTP sur SSL/TLS (FTPS) et le protocole de transfert de fichiers SSH (SFTP).

OPTIONS

-c <site>, --site <site>
Se connecte au site donné à partir du Gestionnaire de sites. Le site doit être fourni sous forme de chemin complet, avec une barre oblique comme caractère de séparation. Toute barre oblique ou anti-slash faisant partie d'un segment doit être échappée avec une barre oblique inverse. Le chemin doit être précédé de 0 pour les entrées définies par l'utilisateur ou de 1 pour les entrées par défaut. Le chemin du site ne peut pas contenir de guillemets doubles.
Exemple : filezilla -c 0/foo/bar/sl\/ash se connecte au site utilisateur sl/ash dans le répertoire du site foo/bar
Ne peut pas être utilisé avec -s ni avec le paramètre URL.
-a <chemin>, --local <chemin>
Définit le site local sur le chemin donné.
Exemple : filezilla -a "/foo bar/"
-h, --help
Affiche une boîte de dialogue d'aide listant ces options de ligne de commande.
-l <typedeconnexion>, --logontype <typedeconnexion>
Définit un type de connexion spécial, ne peut être utilisé qu'en combinaison avec une URL FTP comme argument.

Le type de connexion doit être ask ou interactive. Si -l n'est pas donné, le type de connexion normal est utilisé.

-s, --sitemanager
Démarre avec le Gestionnaire de sites ouvert. Ne peut pas être utilisé avec -c ni avec le paramètre URL.
-v, --version
Affiche le numéro de version de FileZilla.

ENVIRONNEMENT

La variable d'environnement FZ_DATADIR peut être utilisée pour spécifier le répertoire contenant les fichiers de données de FileZilla.

SUPPORT

Veuillez visiter https://filezilla-project.org/ pour plus d'informations. Signalez les bugs uniquement si vous utilisez la dernière version disponible sur le site Web de FileZilla.
