NOM

firewalld.policy-sets - Ensembles de règles

DESCRIPTION

Que sont les ensembles de règles ?

Les ensembles de règles sont des collections de règles qui servent de configuration de départ pour des cas d'utilisation spécifiques, par exemple un routeur domestique. Ils offrent un moyen simple de commencer. Les utilisateurs peuvent ensuite affiner la configuration pour leur environnement. Chaque ensemble de règles possède une page de manuel dédiée pour expliquer son cas d'utilisation.

Tous les ensembles de règles fournis par firewalld sont désactivés administrativement par défaut. Leur utilisation consiste à ajouter vos interfaces aux zones et à supprimer la désactivation.

Activation d'un ensemble de règles

Voici un exemple complet d'utilisation de l'ensemble de règles de passerelle. Dans cet exemple : eth0 est l'interface LAN et eth1 est la liaison vers Internet.

	      # firewall-cmd --permanent --zone internal eth0
	      # firewall-cmd --permanent --zone external eth1
	      # firewall-cmd --permanent --policy-set gateway --remove-disable
	      # firewall-cmd --reload

Activation de plusieurs ensembles de règles

Les ensembles de règles sont garantis d'interopérer. Plusieurs ensembles de règles peuvent être activés simultanément.

Ensembles de règles existants

gateway

Fournit des fonctionnalités de base pour une passerelle, par exemple un routeur domestique. Voir firewalld.policy-set-gateway(5).
