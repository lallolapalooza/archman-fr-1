File::Compare(3perl) Guide de référence des programmeurs Perl File::Compare(3perl)

NOM

File::Compare - Compare des fichiers ou des descripteurs de fichiers

SYNOPIS

use File::Compare;
if (compare("fichier1", "fichier2") == 0) {
    print "Ils sont égaux\n";
}

DESCRIPTION

La fonction "File::Compare::compare" compare le contenu de deux sources, chacune pouvant être un fichier ou un descripteur de fichier. Elle est exportée par défaut depuis "File::Compare".

"File::Compare::cmp" est un synonyme de "File::Compare::compare". Il n'est exporté depuis "File::Compare" que sur demande.

"File::Compare::compare_text" effectue une comparaison ligne par ligne des deux fichiers. Elle s'arrête dès qu'une différence est détectée. compare_text() accepte un troisième argument optionnel : ce doit être une référence CODE vers une fonction de comparaison de lignes, qui retourne 0 lorsque les deux lignes sont considérées comme égales. Par exemple :

compare_text($fichier1, $fichier2)

est essentiellement équivalent à

compare_text($fichier1, $fichier2, sub {$_[0] ne $_[1]} )

RETOUR

"File::Compare::compare" et ses fonctions sœurs retournent 0 si les fichiers sont égaux, 1 si les fichiers sont inégaux, ou -1 si une erreur a été rencontrée.
