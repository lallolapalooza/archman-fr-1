FILECAP:(8) Utilitaires d'administration système FILECAP:(8)

NOM

filecap - un programme pour visualiser les capacités

SYNTAXE

filecap [ -a | -d | /dir | /dir/fichier [cap1 cap2 ...] ]

DESCRIPTION

filecap est un programme qui affiche un rapport des programmes possédant des capacités basées sur les fichiers. Si un fichier n'est pas dans le rapport ou s'il n'y a aucun rapport du tout, aucune capacité n'a été trouvée. Par souci de rapidité, par défaut, seuls les répertoires de la variable d'environnement PATH sont vérifiés. Si l'option de ligne de commande -a est fournie, alors tous les répertoires seront vérifiés. Si un répertoire est passé en argument, il sera vérifié récursivement. Si un chemin vers un fichier est donné, seul ce fichier sera vérifié. Si un fichier est donné suivi de capacités, alors les capacités sont écrites dans le fichier.

OPTIONS

-a
Ceci indique au programme d'afficher toutes les capacités à partir du répertoire /. Normalement, la variable d'environnement PATH est utilisée pour vous montrer les capacités sur les fichiers que vous êtes susceptible d'exécuter.
-d
Ceci décharge toutes les capacités pour référence.

EXEMPLES

Pour vérifier les capacités de fichiers dans $PATH :
filecap
Pour vérifier les capacités de fichiers de tout le système :
filecap -a
Pour vérifier récursivement les capacités de fichiers dans un répertoire :
filecap /usr
Pour vérifier les capacités de fichiers d'un programme spécifique :
filecap /bin/passwd
Pour lister toutes les capacités possibles :
filecap -d
Pour définir une capacité de fichier sur un programme spécifique :
filecap /bin/ping net_raw net_admin
Pour supprimer les capacités de fichier sur un programme spécifique :
filecap /bin/ping none

VOIR AUSSI

pscap(8), netcap(8), capabilities(7).
