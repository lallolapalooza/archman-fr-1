NOM

File::HomeDir::MacOS9 - Trouver votre répertoire personnel et d'autres répertoires sur les systèmes Macintosh hérités

SYNOPSIS

use File::HomeDir;

# Trouver les répertoires pour l'utilisateur actuel
$home    = File::HomeDir->my_home;
$desktop = File::HomeDir->my_desktop;

DESCRIPTION

Ce module fournit des implémentations pour déterminer les répertoires courants de l'utilisateur sur les hôtes Mac hérités. En utilisation normale, ce module sera toujours utilisé via File::HomeDir.

Ce module n'est plus activement maintenu et n'est inclus que pour une extrême compatibilité ascendante.

Seules les méthodes "my_home" et "my_desktop" sont prises en charge.
