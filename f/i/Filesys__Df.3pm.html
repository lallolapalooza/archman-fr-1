NOM

Filesys::Df - Extension Perl pour les informations d'espace disque des systèmes de fichiers.

SYNOPSIS

use Filesys::Df;
#### Obtenir des informations en passant une valeur scalaire de répertoire/nom de fichier
my $ref = df("/tmp");  # La sortie par défaut est en blocs de 1Ko
if(defined($ref)) {
   print "Blocs totaux de 1Ko : $ref->{blocks}\n";
   print "Blocs totaux de 1Ko libres : $ref->{bfree}\n";
   print "Blocs totaux de 1Ko disponibles pour moi : $ref->{bavail}\n";
   print "Blocs totaux de 1Ko utilisés : $ref->{used}\n";
   print "Pourcentage d'utilisation : $ref->{per}\n";
   if(exists($ref->{files})) {
      print "Total d'inodes : $ref->{files}\n"; 
      print "Total d'inodes libres : $ref->{ffree}\n"; 
      print "Pourcentage d'inodes utilisés : $ref->{fper}\n";
   }
}
#### Obtenir des informations en passant un descripteur de fichier
open(FILE, "some_file");  # Obtenir des informations pour le système de fichiers à "some_file"
my $ref = df(\*FILE);  
#### ou
my $ref = df(*FILE);  
#### ou
my $fhref = \*FILE;
my $ref = df($fhref);  
#### Obtenir des informations dans d'autres unités que des blocs de 1Ko
my $ref = df("/tmp", 8192);  # la sortie est en blocs de 8Ko
my $ref = df("/tmp", 1);     # la sortie est en octets

DESCRIPTION

Ce module fournit un moyen d'obtenir des informations sur l'espace disque des systèmes de fichiers. Il s'agit d'une distribution uniquement Unix. Si vous souhaitez collecter ces informations pour Unix et Windows, utilisez "Filesys::DfPortable". Le seul avantage majeur de l'utilisation de "Filesys::Df" par rapport à "Filesys::DfPortable" est que "Filesys::Df" prend en charge l'utilisation de descripteurs de fichiers ouverts comme arguments.

Le module devrait fonctionner avec toutes les saveurs d'Unix qui implémentent les appels statvfs() et fstatvfs(), ou les appels statfs() et fstatfs(). Cela inclurait Linux, *BSD, HP-UX, AIX, Solaris, Mac OS X, Irix, Cygwin, etc ...

df() nécessite un argument qui représente le système de fichiers que vous souhaitez interroger. L'argument peut être soit un nom de répertoire/fichier scalaire, soit un descripteur de fichier ouvert. Il existe également un argument facultatif pour la taille des blocs afin que vous puissiez adapter la taille des valeurs retournées. La taille de bloc par défaut est de 1024. Cela amènera la fonction à retourner les valeurs en blocs de 1 Ko. Si vous voulez des octets, définissez la taille des blocs à 1.

df() retourne une référence à une table de hachage. Les clés disponibles dans la table de hachage sont les suivantes :

"{blocks}" = Blocs totaux sur le système de fichiers.

"{bfree}" = Blocs totaux libres sur le système de fichiers.

"{bavail}" = Blocs totaux disponibles pour l'utilisateur exécutant l'application Perl. Cela peut être différent de "{bfree}" si vous avez des quotas par utilisateur sur le système de fichiers, ou si le superutilisateur a une quantité réservée. "{bavail}" peut également être une valeur négative pour cette raison. Par exemple, s'il y a plus d'espace utilisé que vous n'en avez de disponible.

"{used}" = Blocs totaux utilisés sur le système de fichiers.

"{per}" = Pourcentage d'espace disque utilisé. Ceci est basé sur l'espace disque disponible pour l'utilisateur exécutant l'application. En d'autres termes, si le système de fichiers a 10% de son espace réservé au superutilisateur, alors le pourcentage utilisé peut monter jusqu'à 110%.

Vous pouvez également obtenir des informations sur les inodes via le module, mais vous devez appeler exists() sur la clé "{files}" en premier, pour vous assurer que les informations sont disponibles. Certains systèmes de fichiers peuvent ne pas retourner d'informations sur les inodes, par exemple certains systèmes de fichiers NFS.

Voici les clés d'inodes disponibles :

"{files}" = Total d'inodes sur le système de fichiers.

"{ffree}" = Total d'inodes libres sur le système de fichiers.

"{favail}" = Total d'inodes disponibles pour l'utilisateur exécutant l'application. Voir les règles pour la clé "{bavail}".

"{fused}" = Total d'inodes utilisés sur le système de fichiers.

"{fper}" = Pourcentage d'inodes utilisés sur le système de fichiers. Voir les règles pour la clé "{per}".

Il existe quelques clés non documentées qui sont définies pour maintenir la compatibilité ascendante : "{su_blocks}", "{user_blocks}", etc ...

Si l'appel df() échoue pour une raison quelconque, il retournera undef. Cela se produira probablement si vous faites quelque chose de fou comme essayer d'obtenir des informations pour /proc, ou si vous passez un nom de système de fichiers invalide, ou s'il y a une erreur interne. df() croak() si vous lui passez une valeur indéfinie.

Prérequis : Votre système doit contenir statvfs() et fstatvfs(), ou statfs() et fstatfs() Vous devez exécuter Perl 5.6 ou supérieur.
