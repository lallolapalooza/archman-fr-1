FIREWALLD.POLICY-(5) Configuration de Passerelle Firewalld FIREWALLD.POLICY-(5)

NOM

firewalld.policy-set-gateway - Configuration de Passerelle Firewalld

DESCRIPTION

Ensemble de politiques : Passerelle

L'ensemble de politiques Gateway est un bon point de départ pour un routeur domestique. Il active le masquerading, les helpers de suivi de connexion et le transfert entre zones.

Les zones utilisées par cet ensemble sont groupées logiquement. Ces noms de groupes sont utilisés par les politiques prédéfinies.

            +-----------+                  +-----------+
            |    LAN    |                  |   MONDE   |
            |-----------|                  |-----------|
            | zones:    |                  | zones:    |
            |  internal |                  |  external |
            |  home     |                  |  public   |
            |  trusted  |                  |           |
            +-----------+                  +-----------+
                  |                              |
                  |                              |
                  |         +-----------+        |
                  +---------|    HÔTE   |--------+
                            |-----------|
                            | zones:    |
                  +---------|   HÔTE    |--------+
                  |         +-----------+        |
                  |                              |
                  |                              |
            +-----------+                  +-----------+
            |   TRAVAIL |                  |    DMZ    |
            |-----------|                  |-----------|
            | zones:    |                  | zones:    |
            |  work     |                  |  dmz      |
            +-----------+                  +-----------+

Politiques dans l'ensemble Gateway

gateway-dmz-to-HOST

Active les services couramment nécessaires pour une passerelle, par exemple dns, dhcp.

Emplacement du fichier : /usr/lib/firewalld/policies/gateway-dmz-to-HOST.xml

gateway-lan-to-work

Autorise tout le trafic de LAN vers travail. Active le masquerading et les helpers de suivi de connexion courants.

Emplacement du fichier : /usr/lib/firewalld/policies/gateway-lan-to-work.xml

gateway-lan-to-world

Autorise tout le trafic de LAN vers le monde. Si une interface est ajoutée à la zone "external", le trafic sera masqué. Active également les helpers de suivi de connexion pour les services courants, par exemple ftp.

Emplacement du fichier : /usr/lib/firewalld/policies/gateway-lan-to-world.xml

gateway-lan-to-HOST

Active les services couramment nécessaires pour une passerelle, par exemple dns, dhcp.

Emplacement du fichier : /usr/lib/firewalld/policies/gateway-lan-to-HOST.xml

gateway-world-to-HOST

Peut être utilisé pour exposer des services internes/dmz au monde en ajoutant un port de transfert à cette politique.

Voici un exemple pour ajouter un port de transfert. Il transfère le port 8080 vers 10.1.1.42:80.

# firewall-cmd --permanent --policy gateway-world-to-HOST \
               --add-forward-port=port=8080:proto=tcp:toport=80:toaddr=10.1.1.42
# firewall-cmd --reload

Emplacement du fichier : /usr/lib/firewalld/policies/gateway-world-to-HOST.xml
