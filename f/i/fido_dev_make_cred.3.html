NOM

fido_dev_make_cred — génère une nouvelle identification sur un périphérique FIDO2

SYNTAXE

#include <fido.h>

int
fido_dev_make_cred(fido_dev_t *dev, fido_cred_t *cred, const char *pin);

DESCRIPTION

La fonction fido_dev_make_cred() demande au périphérique FIDO2 représenté par dev de générer une nouvelle identification selon les paramètres suivants définis dans cred :

  • type ;
  • hash des données client ;
  • partie prenante ;
  • attributs utilisateur ;
  • liste des identifiants d'identification exclus ;
  • clé résidente/découvrable et attributs de vérification utilisateur.

Voir fido_cred_set_authdata(3) pour savoir comment ces valeurs sont définies.

Si un PIN n'est pas nécessaire pour authentifier la demande auprès de dev, alors pin peut être NULL. Sinon, pin doit pointer vers une chaîne UTF-8 se terminant par un caractère nul.

Après un appel réussi à fido_dev_make_cred(), les fonctions fido_cred_authdata_ptr(3), fido_cred_pubkey_ptr(3), fido_cred_x5c_ptr(3), et fido_cred_sig_ptr(3) peuvent être invoquées sur cred pour récupérer les diverses parties de l'identification générée.

Veuillez noter que fido_dev_make_cred() est synchrone et bloquera si nécessaire.

VALEURS DE RETOUR

Les codes d'erreur retournés par fido_dev_make_cred() sont définis dans <fido/err.h>. En cas de succès, FIDO_OK est retourné.

VOIR AUSSI

fido_cred_new(3), fido_cred_set_authdata(3)
