NOM

filetypes.conf - configuration des types de fichiers de highlight

DESCRIPTION

Ce fichier de configuration contient les extensions de noms de fichiers et les motifs shebang qui sont associés aux définitions de syntaxe de highlight.

S'il n'y a qu'une seule extension, nommez simplement le fichier de langage en conséquence et cela fonctionnera (aucune entrée nécessaire dans ce fichier).

Les entrées de type de fichier dans gui_files/ext/fileopenfilter.conf doivent également être mises à jour.

Les extensions peuvent être configurées pour plusieurs langages (voir "asm", qui est attribué à assembleur et fasm).

La ligne de commande (CLI) et les versions GUI Qt traitent les affectations ambiguës comme suit :

- CLI : la première association listée ici sera utilisée

- GUI : une invite de sélection de syntaxe sera affichée

Si un nom de fichier n'a pas d'extension par convention (par exemple, makefile), il peut néanmoins être ajouté ici ou configuré comme "Shebang".

Emplacement : Le premier fichier filetypes.conf trouvé dans un répertoire de recherche highlight l'emporte.

Il est facile d'enrichir la base de données des langages de programmation et des thèmes de couleurs de highlight. Voir le fichier README pour plus de détails.

EXEMPLE DE MAPPING D'EXTENSION

{ Lang='purebasic', Extensions={'pb', 'pbi'} }

EXEMPLE DE MAPPING SHEBANG

{ Lang='xml', Shebang=[[^\s*<\?xml\s+version='1.0'\s+[^(\?>)]*?>\s*$]] }
