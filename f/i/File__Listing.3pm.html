NOM

File::Listing - Analyser la liste de répertoire

VERSION

version 6.16

SYNOPSIS

use File::Listing qw(parse_dir);
$ENV{LANG} = "C";  # les dates dans les locales non-anglaises ne sont pas supportées
foreach my $file (parse_dir(`ls -l`)) {
    my ($name, $type, $size, $mtime, $mode) = @$file;
    next if $type ne 'f'; # fichier simple
    #...
}

# la liste de répertoire peut aussi être lue depuis un fichier
open my $listing, "zcat ls-lR.gz|";
$dir = parse_dir($listing, '+0000');

DESCRIPTION

Ce module exporte une seule fonction appelée "parse_dir", qui peut être utilisée pour analyser les listes de répertoires.

FONCTIONS

parse_dir

my $dir = parse_dir( $listing );
my $dir = parse_dir( $listing, $time_zone );
my $dir = parse_dir( $listing, $time_zone, $type );
my $dir = parse_dir( $listing, $time_zone, $type, $error );
my @files = parse_dir( $listing );
my @files = parse_dir( $listing, $time_zone );
my @files = parse_dir( $listing, $time_zone, $type );
my @files = parse_dir( $listing, $time_zone, $type, $error );

Le premier paramètre ($listing) est la liste de répertoire à analyser. Il peut être un scalaire, une référence à un tableau de lignes de répertoire, ou un glob représentant un descripteur de fichier à partir duquel lire la liste de répertoire.

Le second paramètre ($time_zone) est le fuseau horaire à utiliser lors de l'analyse des horodatages dans la liste. Si cette valeur est indéfinie, le fuseau horaire local est présumé.

Le troisième paramètre ($type) est le type de liste à présumer. Les formats actuellement supportés sont 'unix', 'apache' et 'dosftp'. La valeur par défaut est 'unix'. Idéalement, le type de liste devrait être déterminé automatiquement.

Le quatrième paramètre ($error) spécifie comment traiter les lignes non analysables. Les valeurs peuvent être 'ignore', 'warn' ou une référence de code. Warn signifie que la fonction Perl warn() sera appelée. Si une référence de code est passée, alors cette routine sera appelée et la valeur de retour sera incorporée dans la liste. La valeur par défaut est 'ignore'.

Seul le premier paramètre est obligatoire.

# contexte de liste
foreach my $file (parse_dir($listing)) {
    my($name, $type, $size, $mtime, $mode) = @$file;
}

# contexte scalaire
my $dir = parse_dir($listing);
foreach my $file (@$dir) {
    my($name, $type, $size, $mtime, $mode) = @$file;
}

La valeur de retour de parse_dir() est une liste d'entrées de répertoire. Dans un contexte scalaire, la valeur de retour est une référence à la liste. Les entrées de répertoire sont représentées par un tableau composé de :

nom
Le nom du fichier.
type
L'un des suivants : "f" fichier, "d" répertoire, "l" lien symbolique, "?" inconnu.
taille
La taille du fichier.
temps
Le nombre de secondes écoulées depuis le 1er janvier 1970.
mode
Masque de bits, à l'instar du mode retourné par "stat".
