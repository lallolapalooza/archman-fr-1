NOM

fig2ps2tex - génère un fichier TeX pour inclure un fichier PostScript

SYNTAXE

fig2ps2tex fichier

DESCRIPTION

Fig2ps2tex génère un fichier TeX pour inclure un fichier PostScript dans un document TeX. Cela implique le calcul de la boîte englobante à partir du document Postscript. Le fichier d'inclusion TeX est écrit sur la sortie standard.

Il existe également Fig2ps2tex.csh pour les systèmes disposant de csh et dc.

Notez que le paquet de macros psfig offre une approche plus sophistiquée pour inclure des fichiers Postscript dans des documents LaTeX. Fig2ps2tex fonctionne cependant avec TeX brut.

UTILISATION

Supposons que le fichier Postscript s'appelle foo.ps. La commande

% fig2ps2tex foo.ps >foo.tex

créera le fichier d'inclusion avec les informations de bordure. Incluez ensuite ce fichier dans votre document TeX avec la commande

\input{foo}
