NOM

fi_info - Utilitaire simple pour interroger les interfaces de fabric

SYNOPSIS

 fi_info [OPTIONS]

DESCRIPTION

L'utilitaire fi_info peut être utilisé pour interroger les interfaces de fabric disponibles. L'utilitaire prend en charge le filtrage basé sur un certain nombre d'options telles que le type de point de terminaison, le nom du fournisseur ou les modes pris en charge. De plus, fi_info peut également être utilisé pour découvrir les variables d'environnement qui peuvent être utilisées pour régler des paramètres spécifiques au fournisseur. Si aucun filtre n'est spécifié, toutes les interfaces de fabric disponibles pour tous les fournisseurs et tous les types de points de terminaison seront retournées.

OPTIONS

Filtrage

-n, –node=<NOM>
Nom de nœud ou adresse utilisée pour filtrer les interfaces. Seules les interfaces qui peuvent atteindre le nœud ou l'adresse donné répondront.
-P, –port=<PORT>
Numéro de port utilisé pour filtrer les interfaces.
-c, –caps=<CAP1|CAP2>..
Liste de capacités séparées par des barres verticales utilisée pour filtrer les interfaces. Seules les interfaces prenant en charge toutes les capacités données répondront. Pour plus d'informations sur les capacités, voir fi_getinfo(3).
-m, –mode=<MOD1|MOD2>..
Liste de modes séparés par des barres verticales utilisée pour filtrer les interfaces. Seules les interfaces prenant en charge tous les modes donnés répondront. Pour plus d'informations sur les modes, voir fi_getinfo(3).
-t, –ep_type=<TYPEPT>
Spécifie le type de communication d'interface de fabric souhaité. Par exemple, spécifier FI_EP_DGRAM ne retournera que les interfaces qui prennent en charge les datagrammes non fiables. Pour plus d'informations sur les types de points de terminaison, voir fi_endpoint(3).
-a, –addr_format=<FMT>
Filtre les interfaces de fabric par leur format d'adresse. Par exemple, spécifier FI_SOCKADDR_IN ne retournera que les interfaces qui utilisent les structures sockaddr_in pour l'adressage. Pour plus d'informations sur les formats d'adresse, voir fi_getinfo(3).
-p, –provider=<PROV>
Filtre les interfaces de fabric par l'implémentation du fournisseur. Pour une liste des fournisseurs, voir l'option --list.
-d, –domain=<DOMAINE>
Filtre les interfaces pour ne retourner que celles avec le nom de domaine donné.
-f, –fabric=<FABRIC>
Filtre les interfaces pour ne retourner que celles avec le nom de fabric donné.

Découverte

-e, –env
Liste les variables d'environnement liées à libfabric qui peuvent être utilisées pour activer une configuration ou un réglage supplémentaire.
-g [filtre]
Identique à l'option -e, avec une sortie limitée aux variables d'environnement contenant le filtre comme sous-chaîne.
-l, –list
Liste les fournisseurs libfabric disponibles.
-v, –verbose
Par défaut, fi_info affiche un résumé de chacune des interfaces découvertes. Si l'option verbose est activée, alors tout le contenu de la structure fi_info est affiché. Pour plus d'informations sur les données contenues dans la structure fi_info, voir fi_getinfo(3).
–version
Affiche les informations de version.

EXEMPLES D'UTILISATION

$ fi_info -p verbs -t FI_EP_DGRAM

Cela répondra avec toutes les interfaces de fabric qui utilisent le type de point de terminaison FI_EP_DGRAM avec le fournisseur verbs.

fi_info -c 'FI_MSG|FI_READ|FI_RMA'

Cela répondra avec toutes les interfaces de fabric qui peuvent prendre en charge les capacités FI_MSG|FI_READ|FI_RMA.

Pour voir les variables d'environnement liées à libfabric, utilisez l'option -e.

$ ./fi_info -e
# FI_LOG_INTERVAL: Integer
# Délai en ms entre les messages de journal limités en débit (par défaut 2000)
# FI_LOG_LEVEL: String
# Spécifier le niveau de journalisation : warn, trace, info, debug (par défaut : warn)
# FI_LOG_PROV: String
# Spécifier le fournisseur à journaliser (par défaut : tous)
# FI_PROVIDER: String
# Utiliser uniquement le fournisseur spécifié (par défaut : tous les disponibles)
