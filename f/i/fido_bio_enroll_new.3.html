DESCRIPTION

Les enrôlements biométriques FIDO2 en cours sont abstraits dans libfido2 par le type fido_bio_enroll_t.

Les fonctions décrites sur cette page permettent à un type fido_bio_enroll_t d'être alloué, désalloué et inspecté. Pour les opérations sur les périphériques concernant fido_bio_enroll_t, veuillez vous référer à fido_bio_dev_get_info(3).

La fonction fido_bio_enroll_new() renvoie un pointeur vers un type fido_bio_enroll_t nouvellement alloué et vide. Si la mémoire ne peut pas être allouée, NULL est renvoyé.

La fonction fido_bio_enroll_free() libère la mémoire sous-jacente de *enroll_p, où *enroll_p doit avoir été précédemment alloué par fido_bio_enroll_new(). Au retour, *enroll_p est mis à NULL. Soit enroll_p, soit *enroll_p peuvent être NULL, auquel cas fido_bio_enroll_free() est une opération nulle.

La fonction fido_bio_enroll_last_status() renvoie le statut d'enrôlement de enroll.

La fonction fido_bio_enroll_remaining_samples() renvoie le nombre d'échantillons restants pour que enroll se termine.
