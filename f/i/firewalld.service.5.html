NOM

firewalld.service - Fichiers de configuration de service firewalld

SYNOPSIS

/etc/firewalld/services/service.xml
/usr/lib/firewalld/services/service.xml

DESCRIPTION

Un fichier de configuration de service firewalld fournit les informations d'une entrée de service pour firewalld. Les options de configuration les plus importantes sont les ports, les modules et les adresses de destination.

Ce fichier de configuration d'exemple montre la structure d'un fichier de configuration de service :

<?xml version="1.0" encoding="utf-8"?>
<service>
  <short>Mon Service</short>
  <description>description</description>
  <port port="137" protocol="tcp"/>
  <protocol value="igmp"/>
  <module name="nf_conntrack_netbios_ns"/>
  <destination ipv4="224.0.0.251" ipv6="ff02::fb"/>
  <include service="ssdp"/>
  <helper name="ftp"/>
</service>

OPTIONS

La configuration peut contenir ces balises et attributs. Certains sont obligatoires, d'autres facultatifs.

service

La balise de début et de fin service obligatoire définit le service. Cette balise ne peut être utilisée qu'une seule fois dans un fichier de configuration de service. Il existe des attributs facultatifs pour les services :

version="chaîne"

Pour attribuer une version au service.

short

Est une balise de début et de fin facultative utilisée pour donner à un service un nom plus lisible.

description

Est une balise de début et de fin facultative pour avoir une description pour un service.

port

Est une balise d'élément vide facultative et peut être utilisée plusieurs fois pour avoir plus d'une entrée de port. Tous les attributs d'une entrée de port sont obligatoires :

port="chaîne"

Le port chaîne peut être un numéro de port unique ou une plage de ports portid-portid ou aussi vide pour correspondre uniquement à un protocole.

protocol="chaîne"

La valeur du protocole peut être soit tcp, udp, sctp ou dccp.

Pour la compatibilité avec les versions plus anciennes de firewalld, il est possible d'ajouter des protocoles avec l'option de port où le port est vide. Avec l'ajout du support natif des protocoles dans le service, cela n'est plus nécessaire. Ces entrées seront automatiquement converties en protocoles. Lors de la prochaine modification du fichier de service, les entrées seront listées comme des protocoles.

protocol

Est une balise d'élément vide facultative et peut être utilisée plusieurs fois pour avoir plus d'une entrée de protocole. Une entrée de protocole a exactement un attribut :

value="chaîne"

Le protocole peut être n'importe quel protocole pris en charge par le système. Veuillez consulter /etc/protocols pour les protocoles pris en charge.

source-port

Est une balise d'élément vide facultative et peut être utilisée plusieurs fois pour avoir plus d'une entrée de port source. Tous les attributs d'une entrée de port source sont obligatoires :

port="chaîne"

Le port chaîne peut être un numéro de port unique ou une plage de ports portid-portid.

protocol="chaîne"

La valeur du protocole peut être soit tcp, udp, sctp ou dccp.

module

Cet élément est déprécié. Veuillez utiliser helper décrit ci-dessous dans la section intitulée « helper ».

destination

Est une balise d'élément vide facultative et ne peut être utilisée qu'une seule fois. La destination spécifie le réseau de destination comme une adresse IP de réseau (facultatif avec /masque), ou une adresse IP simple. L'utilisation de noms d'hôtes n'est pas recommandée, car ceux-ci ne seront résolus qu'à l'activation du service et transmis au noyau. Pour plus d'informations sur cet élément, veuillez consulter --destination dans iptables(8) et ip6tables(8).

ipv4="adresse[/masque]"

L'adresse de destination IPv4 avec masque facultatif.

ipv6="adresse[/masque]"

L'adresse de destination IPv6 avec masque facultatif.

include

Est une balise d'élément vide facultative et peut être utilisée plusieurs fois pour avoir plus d'une entrée d'inclusion. Une entrée d'inclusion a exactement un attribut :

service="chaîne"

L'inclusion peut être n'importe quel service pris en charge par firewalld.

Avertissement :Firewalld ne vérifiera que le service inclus est un service valide que lorsqu'il est appliqué à une zone.

helper

Est une balise d'élément vide facultative et peut être utilisée plusieurs fois pour avoir plus d'une entrée de helper. Une entrée de helper a exactement un attribut :

name="chaîne"

Le helper peut être n'importe quel helper pris en charge par firewalld.
