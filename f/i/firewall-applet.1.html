NOM

firewall-applet - Applet pour firewalld

SYNTAXE

firewall-applet [OPTIONS...]

DESCRIPTION

firewall-applet est une applet de plateau pour firewalld.

OPTIONS

firewall-applet ne prend en charge aucune option spéciale.

Les options suivantes sont prises en charge :

-h, --help

Affiche un court message d'aide et quitte.

QSETTINGS

firewall-applet dispose de paramètres supplémentaires pour adapter l'apparence. QSettings est utilisé et les stocke dans ~/.config/firewall/applet.conf. Le fichier est automatiquement rechargé s'il a été modifié et les nouveaux paramètres prendront immédiatement effet.

Il existe également le fichier de configuration global /etc/firewall/applet.conf, qui contient les valeurs par défaut. Les paramètres de ce fichier seront surchargés par les paramètres du fichier de configuration utilisateur.

Voici un exemple de fichier applet.conf :

[General]
notifications=true
show-inactive=true

Les paramètres suivants sont pris en charge :

notifications

L'applet affiche des notifications si elles sont activées. Ce paramètre peut également être activé dans l'applet avec la case à cocher « Activer les notifications » dans le menu du bouton droit de la souris.

Ce paramètre est désactivé par défaut (false).

Les notifications sont affichées pour les actions suivantes si elles sont activées :

•Connexion à firewalld établie
•Connexion à firewalld perdue
•Pare-feu rechargé
•Zone par défaut modifiée
•Mode panique activé ou désactivé
•Activation, désactivation ou changement de zones liées aux interfaces
•Activation, désactivation ou changement de zones liées aux adresses sources

show-inactive

Affiche l'applet même si firewalld n'est pas en cours d'exécution. Si firewalld a été arrêté ou ne fonctionne pas, l'applet sera masquée et ne sera pas visible dans le plateau d'applets. Activez ce paramètre pour voir l'applet en permanence afin, par exemple, de vous assurer que le pare-feu est actif.

Ce paramètre est désactivé par défaut (false).

shields-up

Le nom de la zone « shields-up » à utiliser si cette option est activée.

Ce paramètre est par défaut 'block'.

shields-down

Le nom de la zone « shields-down » à utiliser si « shields-up » a été désactivé.

Ce paramètre est par défaut 'public'.

blink

Si activé, l'icône de l'applet clignote dans les cas suivants :
•Connexion à firewalld perdue
•Mode panique activé ou désactivé

Ce paramètre est désactivé par défaut (false).

blink-count

Le nombre de clignotements si blink est activé.

Ce paramètre est par défaut 5.
