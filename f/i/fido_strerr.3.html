FIDO_STRERR(3) Manuel des fonctions de bibliothèque FIDO_STRERR(3)

NOM

fido_strerr — Codes d'erreur FIDO2

SYNTAXE

#include <fido.h>

const char *
fido_strerr(int n);

DESCRIPTION

La fonction fido_strerr() traduit le code d'erreur n en une chaîne de caractères lisible, où n est un code d'erreur défini dans <fido/err.h>. fido_strerr() ne retourne jamais NULL. Les pointeurs retournés pointent vers des chaînes statiques.
