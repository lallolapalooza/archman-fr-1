FBB::Field(3bobcat) Champs numériques FBB::Field(3bobcat)

NOM

FBB::Field - définit et récupère des champs numériques basés sur des décalages

SYNTAXE

#include <bobcat/field>

DESCRIPTION

Les nombres peuvent contenir des sous-champs basés sur des décalages. Par exemple, une valeur comme 12345 pourrait être composée des champs 12 et 345. Ces champs peuvent être considérés comme basés sur des décalages, en utilisant les décalages de fin et de début dans les représentations numériques. Dans cet exemple, 345 commence à la position de chiffre 0 (indiquant le chiffre le moins significatif de 12345) et à la position de chiffre 3, le champ suivant commence. De même, le champ 12 commence à la position de chiffre 3 et se termine à la position de chiffre 5.

Le modèle de classe Field fournit des fonctionnalités pour récupérer et attribuer des valeurs numériques basées sur la position, pour des valeurs numériques existantes (actuellement) au maximum de 64 bits.

Pour représenter de tels champs, le format suivant est utilisé :

    Field<base, end, begin>::function(argument(s))
où base spécifie la valeur de base du système numérique, end spécifie la position d'indice (basée sur 0) où le champ numérique se termine, et begin spécifie la position d'indice où le champ numérique commence. Voici deux exemples, utilisant le système numérique décimal : 
    Field<10, 3, 0>::get(12345)    // retourne 345
    Field<10, 5, 3>::get(12345)    // retourne  12

La décision de spécifier le décalage end avant (c'est-à-dire à gauche) le décalage begin est basée sur la considération que cela correspond à la manière standard de regarder les positions des chiffres dans les nombres, où le décalage de fin se trouve à gauche du décalage de début.

Les valeurs des champs peuvent être récupérées, mais elles peuvent aussi être définies : pour définir la valeur d'un champ, le format suivant est utilisé :

    Field<10, 3, 1>::set(12345, 99)   // retourne 12995
    Field<10, 1, 0>::set(12345, 0)    // retourne 12450
Lorsque des valeurs sont attribuées aux champs, la largeur maximale du champ de destination est prise en compte. En spécifiant 9999 au lieu de 99 dans l'exemple ci-dessus, la valeur retournée sera toujours 12995, car le champ de destination a une largeur de deux positions de chiffre. De même, spécifier une valeur plus petite met les chiffres restants (plus significatifs) à 0 : 
    Field<10, 3, 1>::set(12345, 9)    // retourne 12095

Les modèles de classe eux-mêmes ne connaissent pas les bases des systèmes numériques. Comme 0xdeaf est égal à la valeur décimale 57007 et 0xd à 13, appeler la fonction ci-dessus comme

    Field<16, 1, 0>::set(76007, 13)
retourne la valeur hexadécimale 0xdead’.

Le modèle de classe Field nécessite trois arguments numériques non-type :

o
base, spécifiant la base du système numérique ;
o
end, spécifiant le décalage (basé sur 0) de la position de chiffre où le champ se termine ;
o
begin, spécifiant le décalage (basé sur 0) de la position de chiffre où le champ commence ;

Le modèle de classe est spécialisé pour les situations où base est une simple puissance de 2 (comme 2, 4, 8, 16, ...) car dans ces cas, des opérations sur les bits peuvent être utilisées, ce qui est plus rapide que les multiplications, divisions et calculs de modulo qui sont requis lorsque d'autres bases de systèmes numériques sont utilisées.

FONCTIONS MEMBRES

o
uint64_t Field<base, end, begin>::get(uint64_t value) :
value est interprété comme une valeur dans le système numérique de base, et en utilisant les positions de chiffres dans ce système numérique, la valeur des chiffres du décalage begin jusqu'au décalage end (exclu) est retournée ;
o
uint64_t Field<base, end, begin>::set(uint64_t value, uint64_t field) :
value est interprété comme une valeur dans le système numérique de base, et en utilisant les positions de chiffres dans ce système numérique, les chiffres du décalage begin jusqu'au décalage end (exclu) sont remplacés par la valeur de field. Lorsque le nombre de chiffres de field (utilisant également le système numérique base) dépasse end - begin, ces chiffres en excédent sont ignorés.
