FILE65(1) Manuel des commandes générales FILE65(1)

NOM

file65 - affiche des informations pour les fichiers objets o65

SYNOPSIS

file65 [OPTION]... FICHIER...

DESCRIPTION

file65 affiche des informations de fichier pour les fichiers au format objet o65.

OPTIONS

-v
Affiche les étiquettes indéfinies et globales.
-vv
Affiche les étiquettes indéfinies et globales, ainsi que les tables de relocalisation.
-P
Affiche les adresses de fin de segment (adapté pour le paramètre de ligne de commande -b de xa(1)).
-a offset
Affiche le paramètre « ROMmable » de xa(1) pour un autre fichier situé derrière celui-ci dans la même ROM, à l'offset spécifié.
-A offset
Fait la même chose que -a mais n'affiche que l'adresse de départ du fichier suivant dans la ROM.
--help
Affiche un résumé des options.
--version
Affiche la version du programme.

VOIR AUSSI
