File::Spec::OS2(3perl) Guide du programmeur Perl File::Spec::OS2(3perl)

NOM

File::Spec::OS2 - méthodes pour les spécifications de fichiers OS/2

SYNTAXE

require File::Spec::OS2; # Fait en interne par File::Spec si nécessaire

DESCRIPTION

Voir File::Spec et File::Spec::Unix. Ce paquet remplace l'implémentation de ces méthodes, pas la sémantique.

Parmi les changements apportés pour OS/2, on trouve...

tmpdir
Modifie la liste des emplacements où les informations du répertoire temporaire sont recherchées. 
$ENV{TMPDIR}
$ENV{TEMP}
$ENV{TMP}
/tmp
/
splitpath
Les volumes peuvent être des lettres de lecteur ou des noms de partage UNC (\\serveur\partage).
