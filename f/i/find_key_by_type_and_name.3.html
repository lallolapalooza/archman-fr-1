FIND_KEY_BY_TYPE_AND_NAME(3) Appels utilitaires de clé Linux FIND_KEY_BY_TYPE_AND_NAME(3)

NOM

find_key_by_type_and_name - trouver une clé par type et nom

SYNTAXE

#include <keyutils.h>

key_serial_t find_key_by_type_and_name(const char *type,
    const char *description, key_serial_t destringid);

DESCRIPTION

find_key_by_type_and_name() recherche une clé avec le type et la description exacte donnés, d'abord dans les keyrings de thread, de processus et de session auxquels un processus est abonné, puis dans /proc/keys.

Si une clé est trouvée, et que destringid n'est pas 0 et spécifie un keyring, alors la clé trouvée y sera liée.

VALEUR DE RETOUR

La fonction retourne l'ID de la clé si une clé a été trouvée ou -1 sinon.

ERREURS

ENOKEY
Aucune clé n'a été trouvée ou le keyring spécifié est invalide.
EKEYEXPIRED
La clé ou le keyring a expiré.
EKEYREVOKED
La clé ou le keyring a été révoqué.
EACCES
La clé n'est pas accessible ou le keyring existe, mais n'est pas écrivable par le processus appelant.

LIAISON

Lors de la liaison, -lkeyutils doit être spécifié à l'éditeur de liens.

VOIR AUSSI

request_key(2), keyctl(3), keyrings(7)
