fi_av_set - Opérations sur les ensembles de vecteurs d'adresses

fi_av_set / fi_close
Ouvrir ou fermer un ensemble de vecteurs d'adresses
fi_av_set_union
Effectuer une opération d'union d'ensembles sur deux ensembles AV

Effectuer une opération d'intersection d'ensembles sur deux ensembles AV

Effectuer une opération de différence d'ensembles sur deux ensembles AV

Ajouter une adresse à un ensemble AV

Supprimer une adresse d'un ensemble AV

Obtenir une adresse collective pour les adresses actuelles d'un ensemble AV

Attributs de l'ensemble de vecteurs d'adresses

DESCRIPTION

Un ensemble de vecteurs d'adresses (ensemble AV) représente un sous-ensemble ordonné d'adresses d'un vecteur d'adresses. Les ensembles AV sont utilisés pour identifier les participants à une opération collective. Les points d'extrémité utilisent l'opération fi_join_collective() pour s'associer à un ensemble AV. L'opération de jointure collective fournit une fi_addr qui est utilisée lors de la communication avec un groupe collectif.

La création et la manipulation d'un ensemble AV sont des opérations locales. Aucun trafic réseau n'est échangé entre les pairs. Par conséquent, chaque pair est responsable de la création d'ensembles AV correspondants dans le cadre de sa définition de membre collectif. Voir fi_collective(3) pour une discussion des modèles de membres.

fi_av_set

L'appel fi_av_set crée un nouvel ensemble AV. Les propriétés initiales de l'ensemble AV sont spécifiées par le paramètre struct fi_av_set_attr. Cette structure est définie ci-dessous et permet d'inclure un sous-ensemble d'adresses dans l'ensemble AV lors de sa création. Des adresses peuvent être ajoutées ou supprimées d'un ensemble AV à l'aide des interfaces AV définies ci-dessous.

fi_av_set_attr

struct fi_av_set_attr {
    size_t count;
    fi_addr_t start_addr;
    fi_addr_t end_addr;
    uint64_t stride;
    size_t comm_key_size;
    uint8_t *comm_key;
    uint64_t flags;
};
count
Indique le nombre attendu de membres qui feront partie de l'ensemble AV. Le fournisseur l'utilise pour optimiser l'allocation des ressources. Si count est 0, le fournisseur sélectionnera une taille basée sur les données de configuration système disponibles ou les limitations sous-jacentes.
start_addr / end_addr
Les adresses de début et de fin, incluses, à inclure dans l'ensemble AV. L'utilisation des adresses de début et de fin nécessite que l'AV associé ait été créé comme type FI_AV_TABLE. Les adresses valides dans l'AV qui tombent dans la plage spécifiée et qui satisfont aux autres exigences (telles que le pas) seront ajoutées en tant que membres initiaux à l'ensemble AV. Les start_addr et end_addr doivent être définis sur FI_ADDR_NOTAVAIL lors de la création d'un ensemble AV vide, de la fourniture d'une clé de communication, ou si l'AV est de type FI_AV_MAP.

Le nombre d'adresses entre start_addr et end_addr doit être inférieur ou égal à la valeur count spécifiée.

stride
Le nombre d'entrées entre les adresses successives incluses dans l'ensemble AV. L'ensemble AV inclura toutes les adresses de start_addr + stride x i, pour des valeurs entières croissantes et non négatives de i, jusqu'à end_addr. Un pas de 1 indique que toutes les adresses entre start_addr et end_addr doivent être ajoutées à l'ensemble AV. Le pas doit être défini sur 0, sauf si les champs start_addr et end_addr sont valides.
comm_key_size
La longueur de la clé de communication en octets. Ce champ doit être 0 si une clé de communication n'est pas disponible.
comm_key
Si pris en charge par le réseau, il s'agit d'une clé associée à l'ensemble AV. La clé de communication est utilisée par les applications qui gèrent directement l'appartenance collective via un agent de gestion du réseau ou un gestionnaire de ressources. La clé est utilisée pour transmettre les résultats de la configuration de l'appartenance au fournisseur sous-jacent. L'utilisation et le format d'une clé de communication sont spécifiques au fournisseur du réseau.
flags
Les drapeaux peuvent être utilisés pour configurer l'ensemble AV, y compris pour restreindre les opérations collectives que l'ensemble AV doit prendre en charge. Voir la section drapeaux pour une liste des drapeaux qui peuvent être spécifiés lors de la création de l'ensemble AV.

fi_av_set_union

L'appel d'union d'ensembles AV ajoute à l'ensemble AV de destination toutes les adresses de l'ensemble AV source qui ne sont pas déjà présentes dans l'ensemble AV de destination. Lorsque l'ordre est important, les adresses nouvellement insérées sont placées à la fin de l'ensemble AV.

fi_av_set_intersect

L'appel d'intersection d'ensembles AV supprime de l'ensemble AV de destination toutes les adresses qui ne sont pas également membres de l'ensemble AV source. L'ordre des adresses dans l'ensemble AV de destination reste inchangé.

fi_av_set_diff

L'appel de différence d'ensembles AV supprime de l'ensemble AV de destination toutes les adresses qui sont également membres de l'ensemble AV source. L'ordre des adresses dans l'ensemble AV de destination reste inchangé.

fi_av_set_insert

L'appel d'insertion d'ensembles AV ajoute l'adresse spécifiée à la fin de l'ensemble AV.

fi_av_set_remove

L'appel de suppression d'ensembles AV supprime l'adresse spécifiée de l'ensemble AV donné. L'ordre des adresses restantes dans l'ensemble AV reste inchangé.

fi_av_set_addr

Retourne une adresse qui peut être utilisée pour communiquer avec tous les membres actuels d'un ensemble AV. Il s'agit d'une opération purement locale qui n'implique aucune communication réseau. L'adresse retournée peut être utilisée comme entrée pour fi_join_collective. fi_close

Ferme un AV set et libère toutes les ressources qui lui sont associées. Toutes les opérations actives au moment de la fermeture d'un AV set seront annulées, le résultat du collectif étant indéfini.

DRAPEAUX

Les drapeaux suivants peuvent être spécifiés lors de la création d'un AV set.

FI_UNIVERSE
Lorsqu'il est défini, le AV set sera créé contenant toutes les adresses stockées dans le AV correspondant.
FI_BARRIER_SET
S'il est défini, le AV set sera configuré pour prendre en charge les opérations de barrière.
FI_BROADCAST_SET
S'il est défini, le AV set sera configuré pour prendre en charge les opérations de diffusion.
FI_ALLTOALL_SET
S'il est défini, le AV set sera configuré pour prendre en charge les opérations de tous à tous.
FI_ALLREDUCE_SET
S'il est défini, le AV set sera configuré pour prendre en charge les opérations de réduction globale.
FI_ALLGATHER_SET
S'il est défini, le AV set sera configuré pour prendre en charge les opérations de collecte globale.
FI_REDUCE_SCATTER_SET
S'il est défini, le AV set sera configuré pour prendre en charge les opérations de réduction-distribution.
FI_REDUCE_SET
S'il est défini, le AV set sera configuré pour prendre en charge les opérations de réduction.
FI_SCATTER_SET
S'il est défini, le AV set sera configuré pour prendre en charge les opérations de distribution.
FI_GATHER_SET
S'il est défini, le AV set sera configuré pour prendre en charge les opérations de collecte.

NOTES

Les développeurs familiers avec MPI trouveront que les AV sets sont similaires aux groupes MPI, et peuvent servir de correspondance directe dans certaines, mais pas toutes, les situations.

Par défaut, un AV set sera créé pour prendre en charge toutes les opérations collectives prises en charge par le fournisseur sous-jacent (voir fi_query_collective). Les utilisateurs peuvent réduire les besoins en ressources en spécifiant uniquement les opérations collectives nécessaires au AV set à l'aide des drapeaux de création : FI_BARRIER_SET, FI_BROADCAST_SET, etc. Si aucun de ces drapeaux n'est spécifié, le AV set sera configuré pour prendre en charge toutes celles qui le sont. Il est une erreur pour un utilisateur de demander un collectif non pris en charge.

VALES DE RETOUR

Retourne 0 en cas de succès. En cas d'erreur, une valeur négative correspondant à l'errno du fabric est retournée. Les valeurs d'errno du fabric sont définies dans rdma/fi_errno.h.
