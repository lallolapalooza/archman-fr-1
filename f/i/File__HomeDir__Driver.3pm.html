NOM

File::HomeDir::Driver - Classe de base pour tous les pilotes de File::HomeDir

DESCRIPTION

Ce module est la classe de base pour tous les pilotes de File::HomeDir, et doit être hérité pour identifier une classe comme étant un pilote.

Il est principalement fourni comme une commodité pour ce but d'identification spécifique, car File::HomeDir prend en charge la spécification de pilotes personnalisés et une vérification "->isa" est utilisée lors du chargement du pilote.
