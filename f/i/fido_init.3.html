FIDO_INIT(3) Manuel des fonctions de bibliothèque FIDO_INIT(3)

NOM

fido_init, fido_set_log_handler — initialiser la bibliothèque FIDO2

SYNTAXE

#include <fido.h>

typedef void fido_log_handler_t(const char *);

void
fido_init(int flags);

void
fido_set_log_handler(fido_log_handler_t *handler);

DESCRIPTION

La fonction fido_init() initialise la bibliothèque libfido2. Son invocation doit précéder celle de toute autre fonction libfido2 dans le contexte du thread exécutant.

Si FIDO_DEBUG est défini dans flags, alors une sortie de débogage sera émise par libfido2 sur stderr. Alternativement, la variable d'environnement FIDO_DEBUG peut être définie.

Si FIDO_DISABLE_U2F_FALLBACK est défini dans flags, alors libfido2 ne fera pas de retour à U2F dans fido_dev_open(3) si un périphérique prétend prendre en charge FIDO2 mais échoue à répondre à une salutation CTAP 2.0.

La fonction fido_set_log_handler() fait en sorte que handler soit appelé pour chaque ligne de journal générée dans le contexte du thread exécutant. Les lignes passées à handler incluent un caractère de nouvelle ligne final et ne sont pas imprimées par libfido2 sur stderr.
