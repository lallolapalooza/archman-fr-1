NOM

figlist - liste les polices et fichiers de contrôle figlet

SYNTAXE

figlist [ -d répertoire ]

DESCRIPTION

Liste toutes les polices et fichiers de contrôle dans le répertoire de polices par défaut de figlet. Remplace "figlet -F", qui a été supprimé de la version 2.1 de figlet.

EXEMPLES

Pour utiliser figlist avec ses paramètres par défaut, tapez simplement

exemple% figlist

Pour lister tous les fichiers de polices et de contrôle dans /usr/share/fonts/figlet

exemple% figlist -d /usr/share/fonts/figlet
