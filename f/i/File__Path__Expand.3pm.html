NOM

File::Path::Expand - développer les noms de fichiers

SYNOPSIS

use File::Path::Expand;
print expand_filename("~richardc/foo"); # affiche "/home/richardc/foo"

DESCRIPTION

File::Path::Expand développe les répertoires utilisateurs dans les noms de fichiers. Dans le cas simple, il n'est pas plus complexe que s{^~/}{$HOME/}, mais pour d'autres cas, il consulte "getpwent" et fait ce qu'il faut.
