NOM

fi_mrail - Le fournisseur utilitaire Multi-Rail

APERÇU

Le fournisseur mrail (ofi_mrail) est un fournisseur utilitaire qui se superpose à un fournisseur sous-jacent pour permettre l'utilisation de multiples ports réseau (rails). Cela augmente la bande passante totale disponible d'un fournisseur sous-jacent. L'état actuel du fournisseur mrail est expérimental - toutes les fonctionnalités de libfabric ne sont pas supportées et les performances ne sont pas garanties.

EXIGENCES

Exigences pour le fournisseur sous-jacent

Le fournisseur mrail exige que le fournisseur sous-jacent supporte les capacités / modes suivants :

•
Réception tamponnée (FI_BUFFERED_RECV)
•
FI_SOURCE
•
FI_AV_TABLE

Exigences pour les applications

Les applications doivent : * Supporter le bit de mode MR RAW FI pour utiliser la capacité FI_RMA. * Définir la variable d'environnement FI_OFI_MRAIL_ADDR (voir la section PARAMÈTRES D'EXÉCUTION ci-dessous).

FONCTIONNALITÉS SUPPORTÉES

Types d'extrémité
Le fournisseur ne supporte que FI_EP_RDM.
Capacités d'extrémité
L'interface de transfert de données suivante est supportée : FI_MSG, FI_TAGGED, FI_RMA.
# LIMITATIONS
Les limitations du fournisseur sous-jacent peuvent apparaître comme celles du fournisseur mrail. Le fournisseur mrail ne permet pas de passer de bits de mode au fournisseur sous-jacent.

Fonctionnalités non supportées

Voici les principales fonctionnalités de libfabric qui ne sont pas supportées. Toute autre fonctionnalité non listée dans "Fonctionnalités supportées" peut être considérée comme non supportée.

•
FI_ATOMIC
•
Points d'extrémité évolutifs
•
Contextes partagés
•
FABRIC_DIRECT
•
Multicast
•
Opérations déclenchées

APERÇU DE LA FONCTIONNALITÉ

Pour les messages (FI_MSG, FI_TAGGED), le fournisseur utilise différentes politiques pour envoyer des messages sur un ou plusieurs rails en fonction de la taille du message (voir FI_OFI_MRAIL_CONFIG dans la section PARAMÈTRES D'EXÉCUTION). L'ordonnancement est garanti grâce à l'utilisation de numéros de séquence.

Pour RMA, les données sont réparties équitablement sur tous les rails.

PARAMÈTRES D'EXÉCUTION

Le fournisseur ofi_mrail vérifie les variables d'environnement suivantes.

FI_OFI_MRAIL_ADDR
Liste d'adresses de rails individuels délimitées par des virgules. Chaque adresse peut être une adresse au format FI_ADDR_STR, un nom d'hôte, une adresse IP ou un nom d'interface réseau.
FI_OFI_MRAIL_ADDR_STRC
Obsolète. Remplacé par FI_OFI_MRAIL_ADDR.
FI_OFI_MRAIL_CONFIG
Liste d'éléments <taille_max>:<politique> séparés par des virgules, triés par ordre croissant de <taille_max>. Chaque élément indique la politique de partage de rail à utiliser pour les messages jusqu'à la taille <taille_max> et non couverte par tous les éléments précédents. La valeur de <politique> peut être fixed (un rail fixe est utilisé), round-robin (un rail par message, sélectionné de manière circulaire), ou striping (répartition sur tous les rails). La configuration par défaut est 16384:fixed,ULONG_MAX:striping. La valeur ULONG_MAX peut être entrée comme -1.
