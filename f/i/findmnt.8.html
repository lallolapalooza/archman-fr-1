DESCRIPTIO

N

findmnt listera tous les systèmes de fichiers montés ou cherchera un système de fichiers. La commande findmnt est capable de chercher dans /etc/fstab, /etc/mtab ou /proc/self/mountinfo. Si le périphérique ou le point de montage n'est pas donné, tous les systèmes de fichiers sont

affichés.

Le périphérique peut être spécifié par nom de périphérique, numéros majeur:mineur, étiquette de système de fichiers ou UUID, ou étiquette de partition ou UUID. Notez que findmnt suit le comportement de mount(8) où un nom de périphérique peut être interprété comme un point de montage (et vice versa) si les options --target, --mountpoint ou --source ne sont pas

spécifiées.

L'option de ligne de commande --target accepte n'importe quel fichier ou répertoire et ensuite findmnt affiche le système de fichiers pour le chemin

donné.

La commande imprime tous les systèmes de fichiers montés dans un format arborescent par défaut. La sortie par défaut est susceptible de changer. Ainsi, chaque fois que possible, vous devriez éviter d'utiliser la sortie par défaut dans vos scripts. Définissez toujours explicitement les colonnes attendues en utilisant --output liste-de-colonnes dans les environnements où une sortie stable est

requise.

La relation entre les périphériques de bloc et les systèmes de fichiers n'est pas toujours un-à-un. Le système de fichiers peut utiliser plusieurs périphériques de bloc. C'est pourquoi findmnt fournit les colonnes SOURCE et SOURCES (pl.). La colonne SOURCES affiche tous les périphériques où il est possible de trouver le même UUID de système de fichiers (ou une autre balise spécifiée dans fstab lorsqu'il est exécuté avec --fstab et --eval

uat
e).

OPTION

S

-A, --al

l
Désactive tous les filtres intégrés et imprime tous les systèmes de
fichiers.

-a, --asci

i
Utilise des caractères ascii pour le formatage de
l'arborescence.

-b, --byte

s
Imprime les tailles en octets plutôt que dans un format lisible par l'humain.

Par défaut, l'unité dans laquelle les tailles sont exprimées est l'octet, et les préfixes d'unité sont en puissance de 2^10 (1024). Les abréviations des

symboles sont affichées tronquées afin d'atteindre une meilleure lisibilité, en affichant seule la première lettre de celles-ci ; exemples : « 1 KiB » et
« 1 MiB » sont respectivement affichés comme « 1 K » et « 1 M », omettant alors volontairement la mention « iB », qui fait partie de ces abréviations.

-C, --nocanonicaliz

e
Ne canonise pas les chemins du tout. Cette option affecte la comparaison des chemins et l'évaluation des balises (LABEL, UUID, etc.)
.

-c, --canonicaliz

e
Canonise tous les chemins
imprimés.

-D, --d

f
Imite la sortie de df(1). Cette option est équivalente à -o SOURCE,FSTYPE,SIZE,USED,AVAIL,USE%,TARGET mais exclut tous les pseudo-systèmes de fichiers. Utilisez --all pour imprimer tous les systèmes de fichiers. Voir aussi -I, --dfi opt
ions.

-d, --direction mo

t
La direction de la recherche, soit forward (avant) ou backward (arr
ière).

-e, --evaluat

e
Convertit toutes les balises (LABEL, UUID, PARTUUID, ou PARTLABEL) en noms de périphériques correspondants pour la colonne SOURCE. C'est une situation inhabituelle, mais la même balise peut être dupliquée (utilisée pour plusieurs périphériques). À cette fin, il y a la colonne SOURCES (pl.). Cette colonne affiche par cellule multi-lignes tous les périphériques où la balise est détectée par libblkid. Cette option n'a de sens que pour fstab
.

--hyperlink[=mode

]
Imprime les chemins des points de montage comme liens hypertexte de terminal. Le mode peut être défini à "always", "never", ou "auto". L'argument optionnel when peut être défini à "auto", "never", ou "always". Si l'argument when est omis, il sera par défaut à "auto". Le réglage "auto" signifie que les liens hypertexte ne seront utilisés que si la sortie est sur un
terminal.

n
Cherche dans un fichier alternatif. S'il est utilisé avec --fstab, --mtab ou --kernel, alors il remplace les chemins par défaut. S'il est spécifié plus d'une fois, alors la sortie arborescente est désactivée (voir l' option --list)

]
Lit les informations sur les systèmes de fichiers depuis le noyau. C'est la sortie par défaut. Le format est arborescent et n'inclut que les options de montage gérées par le noyau (voir aussi --mtab).

L'argument optionnel méthode n'est pris en charge que pour la variante longue (--kernel). La variante courte (-k) utilise par défaut la méthode mountinfo pour la rétrocompatibilité. Les méthodes prises en charge peuvent être

•listmount - C'est une méthode EXPÉRIMENTALE qui utilise les appels système listmount() et statmount() pour générer la table de m
ontage. La sortie peut ne pas contenir tous les détails sur les n
œuds de montage (par exemple, SOURCE est actuellement manquant).

Utilise le format de sortie liste. Ce format de sortie est automatiquement activé si la sortie est restreinte par l' option -t, -O, -S ou -T et l'option --submounts n'est pas utilisée ou si plus d'un fichier source (l'option -F) est

Limite l'ensemble des systèmes de fichiers imprimés. Plus d'une option peut être spécifiée dans une liste séparée par des virgules. Les options -t et -O sont cumulatives dans leur effet. C'est différent de -t en ce que chaque option est appariée exactement ; un no initial au début n'a pas de signification globale. Le "no" peut être utilisé pour des éléments individuels dans la liste. L'interprétation du préfixe "no" peut être désactivée par le préfixe
"+".

Notez que la colonne SOURCES utilise des cellules multi-lignes. Dans ces cas, la colonne utilise un formatage de type tableau dans la sortie, par exemple name=("aaa"

-p, --poll[=list

Surveille les changements dans le fichier /proc/self/mountinfo. Les actions prises en charge sont : mount, umount, remount et move. Plusieurs actions peuvent être spécifiées dans une liste séparée par des virgules. Toutes les actions sont surveillées par défaut.

La durée pendant laquelle --poll se bloquera peut être restreinte avec les --timeout ou --first-only o

ptions.

Les colonnes standard utilisent toujours la nouvelle version des informations du fichier mountinfo, sauf l'action umount qui est basée sur les informations originales mises en cache par findmnt. Le mode poll permet d'utiliser des colonnes supplémentaires

Définit la cible du montage. -t, --types lis

Limite l'ensemble des systèmes de fichiers affichés. Plusieurs types peuvent être spécifiés dans une liste séparée par des virgules. Ne tronque pas le texte dans les colonnes. Par défaut, le texte n'est pas tronqué dans les colonnes TARGET, SOURCE, UUID, LABEL, PARTUUID, PARTLABEL. Cette option désactive également la troncature du texte dans toutes les autres

-x, --verif

y
Vérifie le contenu de la table de montage. Par défaut, il s'agit de vérifier la lisibilité et l'utilisabilité de /etc/fstab. Il est possible d'utiliser cette option aussi avec --tab-file. Il est possible de spécifier la source (device) ou la cible (mountpoint) pour filtrer la table de montage. L'option --verbose force findmnt à afficher plus de
détails.

--verbos

Force findmnt à afficher plus d'informations (--verify uniquement pour le moment)

--vfs-al

-y, --shel

Le nom de la colonne sera modifié pour ne contenir que des caractères autorisés pour les identifiants de variables de shell. C'est utile, par exemple, avec --pairs. Notez que cette fonctionnalité a été automatiquement activée pour --pairs dans la version 2.37, mais en raison de problèmes de compatibilité, il est maintenant nécessaire de demander ce comportement par --shell

pas)

EXEMPLE

S

findmnt --fstab -t

nfs
Affiche tous les systèmes de fichiers NFS définis dans /etc/fstab
.

findmnt --fstab

/mnt/foo
Affiche tous les systèmes de fichiers de /etc/fstab où le répertoire du point de montage est /mnt/foo. Affiche aussi les montages bind où /mnt/foo est une
source.

findmnt --fstab --target

/mnt/foo
Affiche tous les systèmes de fichiers de /etc/fstab où le répertoire du point de montage est /mnt/foo
.

findmnt --fstab

--evaluate
Affiche tous les systèmes de fichiers de /etc/fstab et convertit les étiquettes LABEL= et UUID= en noms d'appareils
réels.

findmnt -n --raw --evaluate --output=target

LABEL=/boot
Affiche uniquement le point de montage où le système de fichiers avec l'étiquette "/boot" est
monté.

findmnt --poll --mountpoint

/mnt/foo
Surveille le montage, le démontage, le remontage et le déplacement sur /mnt/foo
.

findmnt --poll=umount --first-only --mountpoint

/mnt/foo

/mnt/foo.

ro
