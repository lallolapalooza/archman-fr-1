NOM

File::Type::Builder - analyse les mime-magic et génère du code

SYNOPSIS

my $build = File::Type::Builder->new();

while (<magic>) {
  chomp;
  my $parsed = $build->parse_magic($_);

  my $code   = $build->string_start($parsed);
  (ou string_offset ou beshort)
}

DESCRIPTION

Lit le format de fichier mime-magic et le traduit en code. (Cette documentation serait plus longue si je m'attendais vraiment à ce que quelqu'un d'autre que moi exécute ce code.)

MÉTHODES

new

Crée un nouvel objet File::Type::Builder.

parse_magic

Désassemble une ligne d'un fichier mime-magic à l'aide d'une chaîne d'expressions régulières.

Un exemple de fichier mime-magic peut être trouvé dans le CVS de cleancode à l'adresse http://cleancode.org/cgi-bin/viewcvs.cgi/email/mime-magic.mime?rev=1.1.1.1

string

Construit du code pour correspondre à la magie de type chaîne.

Doit effectuer des manipulations intelligentes pour que l'expression régulière fonctionne correctement.

be

Construit du code pour correspondre à la magie 'beshort' et 'belong' (par ex. audio/mpeg, image/jpeg).

MÉTHODES PRIVÉES

_substr_matching

Parfois, les données sont plus petites que le décalage que nous recherchons dans le fichier. Si c'est le cas, alors le fichier n'est évidemment pas de ce type, et de plus, nous devrions éviter d'émettre quelques avertissements que Perl émettrait autrement.

Cette sous-routine génère ce code.

_get_escapes

Retourne une référence à une table de hachage définissant les caractères qui ne doivent pas être échappés.

À FAIRE

BOGUES

Incomplet. Certains problèmes connus avec des entrées étranges dans mime-magic. Ignore certaines lignes de mime-magic.
