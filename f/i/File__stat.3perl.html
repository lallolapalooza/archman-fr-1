File::stat(3perl) Guide de référence des programmeurs Perl File::stat(3perl)

NOM

File::stat - interface par nom aux fonctions stat() intégrées de Perl

SYNTAXE

use File::stat;
my $st = stat($fichier) or die "Pas de $fichier : $!";
if ( ($st->mode & 0111) && ($st->nlink > 1) ) {
    print "$fichier est exécutable avec beaucoup de liens\n";
} 
if ( -x $st ) {
    print "$fichier est exécutable\n";
}
use Fcntl "S_IRUSR";
if ( $st->cando(S_IRUSR, 1) ) {
    print "Mon UID effectif peut lire $fichier\n";
}
use File::stat qw(:FIELDS);
stat($fichier) or die "Pas de $fichier : $!";
if ( ($st_mode & 0111) && ($st_nlink > 1) ) {
    print "$fichier est exécutable avec beaucoup de liens\n";
}

DESCRIPTION

Les exportations par défaut de ce module remplacent les fonctions core stat() et lstat() par des versions qui retournent des objets "File::stat". Cet objet possède des méthodes qui retournent le champ de structure du même nom de la fonction stat(2); à savoir, dev, ino, mode, nlink, uid, gid, rdev, size, atime, mtime, ctime, blksize et blocks.

Depuis la version 1.02 (fournie avec perl 5.12), l'objet fournit un surcharge des opérateurs "-X", vous pouvez donc appeler des opérateurs de test de fichier ("-f", "-x", etc.) dessus. Il fournit également une méthode "->cando", appelée comme suit :

$st->cando( ACCES, EFFECTIF )

où ACCES est l'un des "S_IRUSR", "S_IWUSR" ou "S_IXUSR" du module Fcntl, et EFFECTIF indique s'il faut utiliser les identifiants effectifs (vrai) ou réels (faux). La méthode interprète les champs "mode", "uid" et "gid", et retourne si le processus actuel serait autorisé ou non l'accès spécifié.

Si vous ne souhaitez pas utiliser les objets, vous pouvez importer la méthode "->cando" dans votre espace de noms sous forme de fonction régulière appelée "stat_cando". Celle-ci prend un arrayref contenant les valeurs de retour de "stat" ou "lstat" comme premier argument, et l'interprète pour vous.

Vous pouvez également importer tous les champs de structure directement dans votre espace de noms sous forme de variables régulières en utilisant la balise d'importation :FIELDS. (Notez que cela remplace toujours vos fonctions stat() et lstat().) Accédez à ces champs en tant que variables nommées avec un préfixe "st_" devant leurs noms de méthode. Ainsi, "$stat_obj->dev()" correspond à $st_dev si vous importez les champs.

Pour accéder à cette fonctionnalité sans les remplacements core, passez une liste d'importation vide à "use", puis accédez aux fonctions avec leurs noms qualifiés complets. D'autre part, les fonctions intégrées restent disponibles via le pseudo-paquet "CORE::".

BOGUES

Depuis Perl 5.8.0, après avoir utilisé ce module, vous ne pouvez plus utiliser le $_ implicite ou le handle de fichier spécial "_" avec stat() ou lstat(), essayer de le faire conduit à des erreurs étranges. La solution de contournement consiste à rendre $_ explicite :

my $stat_obj = stat $_;

et pour "_" à peupler explicitement l'objet en utilisant la fonction non exportée et non documentée populate() avec CORE::stat() :

my $stat_obj = File::stat::populate(CORE::stat(_));

ERREURS

-%s n'est pas implémenté sur un objet File::stat
Les opérateurs de test de fichier "-t", "-T" et "-B" ne sont pas implémentés, car ils nécessitent plus d'informations qu'un simple tampon stat.

AVERTISSEMENTS

Ceux-ci peuvent tous être désactivés avec :

no warnings "File::stat";
File::stat ignore use filetest 'access'
Vous avez essayé d'utiliser l'un des tests de fichier "-rwxRWX" avec "use filetest 'access'" en vigueur. "File::stat" ignorera le pragma et utilisera simplement les informations du membre "mode" comme d'habitude.
File::stat ignore les ACL VMS
Les systèmes VMS ont une structure de permissions qui ne peut pas être entièrement représentée dans un tampon stat, et contrairement aux autres systèmes, les opérateurs de test de fichier intégrés la respectent. Les surcharges de "File::stat", cependant, ne le font pas, car les informations requises ne sont pas disponibles.

NOTE

Bien que cette classe soit actuellement implémentée à l'aide du module Class::Struct pour construire une classe de type structure, vous ne devriez pas vous y fier.
