NOM

fi_nic - attributs de la carte réseau

ATTRIBUTS DE CARTE RESEAU

La structure fid_nic définit les attributs d'une structure fi_info qui est directement associée au matériel réseau sous-jacent et peut être retournée directement en appelant fi_getinfo(3). Le format de fid_nic et des sous-structures associées est défini ci-dessous.

Notez que tous les champs de toutes les structures ne peuvent pas être disponibles. Les champs indisponibles ou non applicables à l'appareil indiqué seront définis sur NULL ou 0.

struct fid_nic {
    struct fid             fid;
    struct fi_device_attr *device_attr;
    struct fi_bus_attr    *bus_attr;
    struct fi_link_attr   *link_attr;
    void                  *prov_attr;
};
struct fi_device_attr {
    char *name;
    char *device_id;
    char *device_version;
    char *vendor_id;
    char *driver;
    char *firmware;
};
struct fi_pci_attr {
    uint16_t domain_id;
    uint8_t  bus_id;
    uint8_t  device_id;
    uint8_t  function_id;
};
struct fi_bus_attr {
    enum fi_bus_type       bus_type;
    union {
        struct fi_pci_attr pci;
    } attr;
};
struct fi_link_attr {
    char               *address;
    size_t             mtu;
    size_t             speed;
    enum fi_link_state state;
    char               *network_type;
};

Attributs de périphérique

Les attributs de périphérique sont utilisés pour identifier la carte réseau virtuelle ou matérielle spécifique associée à une structure fi_info.

name
Le nom associé au périphérique par le système d'exploitation. Il peut s'agir d'un nom d'interface réseau logique (par exemple, eth0 ou eno1) ou d'un nom de fichier absolu.
device_id
Il s'agit d'un identifiant spécifique au fournisseur pour l'appareil ou le produit.
device_version
Indique la version de l'appareil.
vendor_id
Indique le nom du fournisseur qui distribue la carte réseau.
driver
Le nom du pilote associé au périphérique.
firmware
La version du firmware de l'appareil.

Attributs de bus

Les attributs de bus sont utilisés pour identifier l'emplacement physique de la carte réseau dans le système.

bus_type
Indique le type de bus système où se trouve la carte réseau. Les valeurs valides sont FI_BUS_PCI ou FI_BUS_UNKNOWN.
attr.pci.domain_id
Le domaine où se trouve le bus PCI. Valide uniquement si bus_type est FI_BUS_PCI.
attr.pci.bus_id
L'identifiant du bus PCI où se trouve l'appareil. Valide uniquement si bus_type est FI_BUS_PCI.
attr.pci.device_id
L'identifiant sur le bus PCI où se trouve l'appareil. Valide uniquement si bus_type est FI_BUS_PCI.
attr.pci.function_id
La fonction sur l'appareil référencé. Valide uniquement si bus_type est FI_BUS_PCI.

Attributs de lien

Les attributs de lien décrivent les détails de bas niveau de la connexion réseau à la fabric.

address
L'adresse principale au niveau de la liaison associée à la carte réseau, telle qu'une adresse MAC. Si plusieurs adresses sont disponibles, une seule sera rapportée.
mtu
L'unité de transfert maximale des trames ou paquets au niveau de la liaison, en octets.
speed
Le débit de données actif du lien, donné en bits par seconde.
state
L'état actuel du port physique. Les valeurs possibles sont FI_LINK_UNKNOWN, FI_LINK_DOWN et FI_LINK_UP, pour indiquer si l'état du port est inconnu ou non applicable (inconnu), inactif (down) ou actif (up).
network_type
Spécifie le type d'interface réseau actuellement active, comme Ethernet ou InfiniBand.

Attributs du fournisseur

Les attributs du fournisseur font référence aux détails spécifiques au fournisseur de l'appareil. Ces attributs sont spécifiques au fournisseur et à l'appareil. Les attributs peuvent être interprétés par fi_tostr(3). Les applications peuvent également utiliser les autres champs d'attributs, tels que le champ related fi_fabric_attr: prov_name, pour déterminer une structure appropriée dans laquelle caster les attributs. Le format et la définition de ce champ sont hors de portée du framework principal de libfabric, mais peuvent être disponibles dans un fichier d'en-tête spécifique au fournisseur inclus dans le package libfabric.

NOTES

La structure fid_nic est retournée dans le cadre d'un appel à fi_getinfo(3). Elle est automatiquement libérée dans le cadre de l'appel à fi_freeinfo(3)
