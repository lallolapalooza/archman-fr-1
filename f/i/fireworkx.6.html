NOM

fireworkx - Effet visuel pyrotechnique.

SYNTAXE

fireworkx [--display hôte:écran.visualisation] [--visual visualisation] [--window] [--root] [--window-id nombre] [--verbose] [--noflash] [--shoot] [--delay nombre] [--maxlife nombre] [--fps]

DESCRIPTION

Anime des explosions.

OPTIONS

--visual visualisation
Spécifie quelle visualisation utiliser. Les valeurs légales sont le nom d'une classe de visualisation, ou l'identifiant (décimal ou hexadécimal) d'une visualisation spécifique.
--window
Dessine dans une nouvelle fenêtre. C'est le comportement par défaut.
--root
Dessine sur la fenêtre racine.
--window-id nombre
Dessine sur la fenêtre spécifiée.
--noflash
Désactive l'effet de flash lumineux. (Fonctionne plus rapidement)
--shoot
Lance des fusées vers le haut à partir d'un mortier.
--delay nombre
Délai entre les images. En microsecondes. (Par défaut : 10000)
--maxlife nombre
Période de décroissance maximale pour une explosion. (Plage : 0-100)
--verbose
Pour des raisons de recherche scientifique uniquement..!
--fps
Affiche le taux d'images par seconde et la charge CPU actuels.

ENVIRONNEMENT

DISPLAY
pour obtenir l'hôte et le numéro d'écran par défaut.
XENVIRONMENT
pour obtenir le nom d'un fichier de ressources qui remplace les ressources globales stockées dans la propriété RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
L'identifiant de fenêtre à utiliser avec --root.

VOIR AUSSI

X(1), xscreensaver(1)
