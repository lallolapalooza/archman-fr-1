NOM

fiascotopnm - Convertit une image FIASCO compressée en PGM ou PPM

SYNTAXE

fiascotopnm [option]... [fichier]...

Tous les noms d'options peuvent être abrégés ; par exemple, --output peut être écrit --outp ou --ou. Pour toutes les options, une option courte à une seule lettre est fournie. Les arguments obligatoires ou optionnels pour les options longues sont obligatoires ou optionnels pour les options courtes, également. Les options courtes et longues sont sensibles à la casse.

DESCRIPTION

Ce programme fait partie de Netpbm(1)

fiascotopnm décompresse les fichiers FIASCO nommés, ou l'entrée standard s'il n'y a pas de fichier nommé, et écrit les images au format PGM ou PPM, selon que l'image FIASCO est en noir et blanc ou en couleur.

OPTIONS

-o[nom], --output=[nom]

Écrit l'image décompressée dans le fichier nom.ppm (si PPM) ou nom.pgm (si PGM). Si nom est -, alors produit le fichier image sur la sortie standard. L'argument optionnel nom peut être omis, alors le nom du fichier d'entrée est utilisé comme base avec le suffixe .ppm ou .pgm. Dans le cas de flux vidéo, les images sont stockées dans les fichiers nom.N.ppm où N est le numéro de l'image (de la forme 00..0 - 99..9) ; la sortie sur la sortie standard n'est pas possible avec les flux vidéo.


Si nom est un chemin relatif et que la variable d'environnement FIASCO_IMAGES est une liste de répertoires (séparés par des deux-points), alors le(s) fichier(s) de sortie sont écrits dans le premier répertoire (accessible en écriture) de cette liste. Sinon, le répertoire courant est utilisé pour stocker le(s) fichier(s) de sortie.

-z, --fast
Décompresse les images au format 4:2:0 ; c'est-à-dire que chaque canal de chroma est décompressé en une image de largeur et hauteur réduites de moitié. Utilisez cette option sur les machines lentes lorsque le taux de rafraîchissement souhaité n'est pas atteint ; la qualité de sortie est seulement légèrement diminuée.
-d, --double
Double la taille de la fenêtre X11 en largeur et en hauteur ; aucune interpolation de pixel n'est utilisée, chaque pixel est simplement remplacé par quatre pixels identiques.
-p, --panel
Affiche un panneau avec des boutons lecture, arrêt, pause, enregistrer et quitter pour contrôler l'affichage des vidéos. Lorsque le bouton enregistrer est pressé, toutes les images sont décompressées et stockées en mémoire. Les autres boutons fonctionnent de manière habituelle.
-m N, --magnify=N
Définit le grossissement de l'image décompressée. Les valeurs positives agrandissent et les valeurs négatives réduisent la largeur et la hauteur de l'image par un facteur de 2^|N|.
-s N, --smoothing=N
Lisse les images décompressées le long des bordures de partitionnement selon le montant donné N. N est de 1 (minimum) à 100 (maximum) ; la valeur par défaut est 70. Lorsque N=0, le montant de lissage spécifié dans le fichier FIASCO est utilisé (défini par le codeur FIASCO).
-F N, --fps=N
Définit le nombre d'images par seconde à N. Lorsque cette option est utilisée, le taux de rafraîchissement spécifié dans le fichier FIASCO est remplacé.
--verbose=N
Définit le niveau de verbosité de fiascotopnm à N.
-v, --version
Affiche le numéro de version de fiascotopnm, puis quitte.
-f nom, --config=nom
Charge le fichier de paramètres nom pour initialiser les options de fiascotopnm. Voir le fichier system.fiascorc pour un exemple de syntaxe. Les options de fiascotopnm sont définies par l'une des méthodes suivantes (dans l'ordre spécifié) :
  • Fichier de ressources global /etc/system.fiascorc
  • $HOME/.fiascorc
  • Ligne de commande
  • --config=nom
-h, --info
Affiche une aide brève, puis quitte.
-H, --help
Affiche une aide détaillée, puis quitte.

EXEMPLES

fiascotopnm foo.wfa >foo.ppm

Décompresse le fichier FIASCO 'foo.wfa' et le stocke sous le nom 'foo.ppm'.

fiascotopnm -o foo1.wfa foo2.wfa

Décompresse les fichiers FIASCO 'foo1.wfa' et 'foo2.wfa' et écrit les images dans les fichiers 'foo1.wfa.ppm' et 'foo2.wfa.ppm'.

fiascotopnm -oimage foo1.wfa

Décompresse le fichier FIASCO 'foo1.wfa' et écrit les 15 images dans les fichiers 'image.00.ppm', ... , 'image.14.ppm'.

fiascotopnm --fast --magnify=-1 --double video.wfa >stream.ppm

Décompresse le fichier FIASCO 'video.wfa'. La vitesse de décompression est aussi rapide que possible : l'image est décompressée (au format 4:2:0) à un quart de sa taille d'origine ; puis l'image est à nouveau agrandie par doublement des pixels.

FICHIERS

/etc/system.fiascorc
Le fichier d'initialisation à l'échelle du système.
$HOME/.fiascorc
Le fichier d'initialisation personnel.

ENVIRONNEMENT

FIASCO_IMAGES
Chemin de sauvegarde pour les fichiers image. La valeur par défaut est './'.
FIASCO_DATA
Chemin de recherche pour les fichiers FIASCO. La valeur par défaut est './'.
