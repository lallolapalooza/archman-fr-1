NOM

File::HomeDir::Test - Empêche la création accidentelle de fichiers appartenant à l'utilisateur pendant les tests

SYNTAXE

use Test::More test => 1;
use File::HomeDir::Test;
use File::HomeDir;

DESCRIPTION

File::HomeDir::Test est un pilote File::HomeDir destiné à être utilisé dans les scripts de test de modules ou d'applications qui écrivent des fichiers dans des répertoires appartenant à l'utilisateur.

Il est conçu pour empêcher la pollution des répertoires utilisateur avec des fichiers qui ne font pas partie de l'installation de l'application elle-même, mais qui ont été créés pendant les tests. Ces fichiers peuvent laisser fuiter des informations d'état des tests dans l'utilisation d'une application en cours d'exécution, et sur les systèmes Unix, ils empêchent également les tests (qui peuvent être exécutés en tant que root via sudo) d'écrire des fichiers qui ne pourront pas être modifiés ou supprimés ultérieurement par l'utilisateur régulier.
