NOM

fips_config - Configuration des paramètres du module FIPS

DESCRIPTION

Ce fichier de configuration spécifie les paramètres qui sont utilisés par le fournisseur FIPS. Ils sont stockés dans la section [fips_sect].

kmac-key-check
Voir "OPTIONS" dans openssl-fipsinstall(1) -kmac_key_check

Par exemple :

[fips_sect]
activate = 1
install-version = 1
conditional-errors = 1
security-checks = 1
module-mac = 41:D0:FA:C2:5D:41:75:CD:7D:C3:90:55:6F:A4:DC
install-mac = FE:10:13:5A:D3:B4:C7:82:1B:1E:17:4C:AC:84:0C
install-status = INSTALL_SELF_TEST_KATS_RUN

NOTES

Lors de l'utilisation du fournisseur FIPS, il est recommandé d'activer l'option config_diagnostics pour éviter l'utilisation accidentelle d'algorithmes non validés FIPS via une configuration erronée ou mistaken. Voir config(5).

VOIR AUSSI

config(5) openssl-fipsinstall(1)

HISTORIQUE

Cette fonctionnalité a été ajoutée dans OpenSSL 3.0.
