File::LibMagic(3) Documentation Perl fournie par l'utilisateur File::LibMagic(3)

NOM

File::LibMagic - Déterminer les types MIME de données ou de fichiers à l'aide de libmagic

VERSION

version 1.23

SYNOPSIS

use File::LibMagic;
my $magic = File::LibMagic->new;
my $info = $magic->info_from_filename('chemin/vers/fichier');
# Affiche une description comme "texte ASCII"
print $info->{description};
# Affiche un type MIME comme "text/plain"
print $info->{mime_type};
# Affiche un encodage de caractères comme "us-ascii"
print $info->{encoding};
# Affiche un type MIME avec encodage comme "text/plain; charset=us-ascii"
print $info->{mime_with_encoding};
my $contenu_fichier = read_file('chemin/vers/fichier');
$info = $magic->info_from_string($contenu_fichier);
open my $fh, '<', 'chemin/vers/fichier' or die $!;
$info = $magic->info_from_handle($fh);

DESCRIPTION

Le module "File::LibMagic" est une interface Perl simple pour libmagic du paquet file (version 4.x ou 5.x). Vous aurez besoin de la bibliothèque (libmagic.so) et du fichier d'en-tête (magic.h) pour compiler ce module Perl.

Installation de libmagic

Sur Debian/Ubuntu exécutez :

sudo apt-get install libmagic-dev

sur Red Hat exécutez :

sudo yum install file-devel

Sur Mac vous pouvez utiliser homebrew (https://brew.sh/) :

brew install libmagic

Spécification des répertoires lib et/ou include

Sur certains systèmes, vous devrez peut-être passer des répertoires lib et include supplémentaires à Makefile.PL. Vous pouvez le faire avec les paramètres `--lib` et `--include` :

perl Makefile.PL --lib /usr/local/lib --include /usr/local/include

Vous pouvez passer ces paramètres plusieurs fois pour spécifier plus d'un emplacement.

API

Ce module fournit une API orientée objet avec les méthodes suivantes :

File::LibMagic->new

Crée un nouvel objet File::LibMagic.

L'utilisation de l'interface orientée objet n'ouvre la base de données magique qu'une seule fois, ce qui est probablement plus efficace pour des utilisations répétées.

Chaque objet "File::LibMagic" charge la base de données magique indépendamment des autres objets "File::LibMagic", vous pourriez donc vouloir partager un seul objet entre plusieurs modules.

Cette méthode accepte les paramètres nommés suivants :

  • "magic_file"

    Cela doit être une chaîne de caractères ou une référence de tableau contenant un ou plusieurs fichiers magiques.

    Si un fichier que vous fournissez n'existe pas, le constructeur lèvera une exception, mais seulement avec libmagic 4.17+.

    Si vous ne définissez pas ce paramètre, le constructeur lèvera une exception s'il ne parvient pas du tout à trouver de fichiers magiques.

    Notez que même si vous utilisez un fichier personnalisé, vous voudrez probablement *également* utiliser le fichier standard (/usr/share/misc/magic sur mon système, le vôtre peut varier).

  • "follow_symlinks"

    Si cette valeur est vraie, alors les appels à "$magic->info_from_filename" suivront les liens symboliques vers le fichier réel.

  • "uncompress"

    Si cette valeur est vraie, alors les fichiers compressés (comme les fichiers gzip) seront décompressés, et les diverses méthodes "info_from_*" retourneront des informations sur le fichier décompressé.

  • Limites de traitement

    Les versions plus récentes de la bibliothèque libmagic ont un certain nombre de limites afin d'éviter que des fichiers malformés ou malveillants ne provoquent une exhaustion de ressources ou d'autres erreurs.

    Si votre libmagic le supporte, vous pouvez définir les limites suivantes via les paramètres du constructeur. Si votre version ne supporte pas la définition de ces limites, passer ces options provoquera un plantage du constructeur. De plus, les limites spécifiques ont été introduites sur un certain nombre de versions de libmagic, et votre version de libmagic peut ne pas supporter chaque paramètre. L'utilisation d'un paramètre non supporté par votre libmagic provoquera également un plantage du constructeur.

  • "max_indir"

    Ceci limite la récursion pour l'indirection lors du traitement des entrées dans le fichier magique.

  • "max_name"

    Ceci limite le nombre maximum de niveaux de noms/utilisations magiques qui seront traités dans le fichier magique.

  • "max_elf_notes"

    Ceci limite le nombre maximum de notes ELF qui seront traitées lors de la détermination du type MIME d'un fichier.

  • "max_elf_phnum"

    Ceci limite le nombre maximum de sections de programme ELF qui seront traitées lors de la détermination du type MIME d'un fichier.

  • "max_elf_shnum"

    Ceci limite le nombre maximum de sections ELF qui seront traitées lors de la détermination du type MIME d'un fichier.

  • "max_regex"

    Ceci limite la taille maximale des expressions régulières lors du traitement des entrées dans le fichier magique.

  • "max_bytes"

    Ceci limite le nombre maximal d'octets lus à partir d'un fichier lors de la détermination du type MIME d'un fichier.

Les valeurs de ces paramètres doivent être des limites entières.

•
"max_future_compat"

Pour la compatibilité avec les futures additions aux paramètres de limite de traitement de libmagic, vous pouvez passer un paramètre "max_future_compat". Il s'agit d'une référence de hachage où les clés sont des constantes (entiers définis par libmagic, pas des noms) et les valeurs sont la limite que vous souhaitez définir.

$magic->info_from_filename('chemin/vers/fichier')

Cette méthode renvoie des informations sur le fichier donné. La valeur de retour est une référence de hachage avec quatre clés :

  • "description"

    Une description textuelle du contenu du fichier comme "texte de programme C ASCII".

  • "mime_type"

    Le type MIME sans encodage de caractères, comme "text/x-c".

  • "encoding"

    Juste l'encodage des caractères, comme "us-ascii".

  • "mime_with_encoding"

    Le type MIME avec un encodage de caractères, comme "text/x-c; charset=us-ascii". Notez que si aucun encodage n'a été trouvé, cela sera identique à la clé "mime_type".

$magic->info_from_string($chaine)

Cette méthode renvoie des informations sur le contenu de la chaîne donnée. La chaîne peut être passée sous forme de référence pour économiser de la mémoire.

La valeur de retour est la même que celle de "$mime->info_from_filename".

$magic->info_from_handle($fh)

Cette méthode renvoie des informations sur le contenu lu à partir du descripteur de fichier donné. Elle lira les données à partir de la position actuelle du descripteur, et laissera le descripteur à la même position après la lecture.

File::LibMagic->max_param_constant
