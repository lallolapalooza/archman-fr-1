NOM

findrule - enveloppe de ligne de commande pour File::Find::Rule

EMPLOI

findrule [chemin...] [expression]

DESCRIPTION

"findrule" emprunte principalement l'interface à GNU find(1) pour fournir une interface en ligne de commande aux modules de la hiérarchie File::Find::Rule.

La syntaxe des expressions est le nom de la règle, précédé d'un trait d'union, suivi d'un argument optionnel. Si l'argument est une parenthèse ouverte, il est interprété comme une liste d'arguments, terminée par une parenthèse fermante.

Quelques exemples :

find -file -name ( foo bar )

fichiers nommés "foo" ou "bar", sous le répertoire courant.

find -file -name foo -bar

fichiers nommés "foo", qui ont des publications (car c'est ce que spécifie notre clause fictive "bar"), sous le répertoire courant.

find -file -name ( -bar )

fichiers nommés "-bar", sous le répertoire courant. Dans ce cas, si nous avions omis les parenthèses, il aurait été analysé comme un appel à name sans arguments, suivi d'un appel à -bar.

Commutateurs pris en charge

Je suis très laxiste. Veuillez consulter la page man de File::Find::Rule pour l'instant, et ajouter un - devant les commandes que vous souhaitez.

Commutateurs bonus supplémentaires

findrule charge automatiquement tous vos modules d'extension File::Find::Rule::* installés, alors consultez la documentation pour voir ce que cela implique.
