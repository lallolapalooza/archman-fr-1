DESCRIPTION

Les enrôlements biométriques FIDO2 existants sont abstraits dans libfido2 par les types fido_bio_template_t et fido_bio_template_array_t .

Les fonctions décrites dans cette page permettent d'allouer, de libérer, de modifier et d'inspecter un type fido_bio_template_t , et d'allouer, de libérer et d'inspecter un type fido_bio_template_array_t . Pour les opérations sur l'appareil concernant fido_bio_template_t et fido_bio_template_array_t, veuillez consulter fido_bio_dev_get_info(3).

La fonction fido_bio_template_new() renvoie un pointeur vers un type fido_bio_template_t nouvellement alloué et vide. Si la mémoire ne peut pas être allouée, NULL est renvoyé.

La fonction fido_bio_template_free() libère la mémoire de *template_p, où *template_p doit avoir été préalablement alloué par fido_bio_template_new(). Au retour, *template_p est défini à NULL. Soit template_p soit *template_p peut être NULL, auquel cas fido_bio_template_free() est une NOP.

La fonction fido_bio_template_name() renvoie un pointeur vers une chaîne terminée par NUL contenant le nom convivial de template, ou NULL si template n'a pas de nom convivial défini.

La fonction fido_bio_template_id_ptr() renvoie un pointeur vers l'identifiant du modèle de template, ou NULL si template n'a pas d'identifiant. La longueur correspondante peut être obtenue par fido_bio_template_id_len().

La fonction fido_bio_template_set_name() définit le nom convivial de template à name. Si name est NULL, le nom convivial de template est supprimé.

La fonction fido_bio_template_array_new() renvoie un pointeur vers un type fido_bio_template_array_t nouvellement alloué et vide. Si la mémoire ne peut pas être allouée, NULL est renvoyé.

La fonction fido_bio_template_array_free() libère la mémoire de *array_p, où *array_p doit avoir été préalablement alloué par fido_bio_template_array_new(). Au retour, *array_p est défini à NULL. Soit array_p soit *array_p peut être NULL, auquel cas fido_bio_template_array_free() est une NOP.

La fonction fido_bio_template_array_count() renvoie le nombre de modèles dans array.

La fonction fido_bio_template() renvoie un pointeur vers le modèle à l'index idx dans array. Veuillez noter que le premier modèle dans array a une valeur idx (index) de 0.

VALEURS RENVOYÉES

Les codes d'erreur renvoyés par fido_bio_template_set_id() et fido_bio_template_set_name() sont définis dans <fido/err.h>. En cas de succès, FIDO_OK est renvoyé.
