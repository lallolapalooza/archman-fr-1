NOM

login.users - Syntaxe du fichier de connexion pour Firejail

DESCRIPTION

Le fichier /etc/firejail/login.users décrit les arguments supplémentaires passés à l'exécutable firejail lors de la connexion d'un utilisateur à un shell restreint par Firejail. Chaque entrée utilisateur dans le fichier se compose d'un nom d'utilisateur suivi des arguments passés à firejail. Le format est le suivant :

nom_utilisateur: arguments

Exemple :

netblue: --net=none --protocol=unix

Les modèles génériques sont acceptés dans le champ nom d'utilisateur :

user*: --private

SHELL RESTREINT

Pour configurer un shell restreint, remplacez /bin/bash par /usr/bin/firejail dans le fichier /etc/passwd pour chaque utilisateur qui doit être restreint. Alternativement, vous pouvez spécifier /usr/bin/firejail en utilisant les commandes `adduser` ou `usermod` :

adduser --shell /usr/bin/firejail nom_utilisateur
usermod --shell /usr/bin/firejail nom_utilisateur
