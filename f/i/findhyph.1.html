NOM

findhyph – trouver les mots coupés par des traits d'union dans un document TeX

INSTALLATION

Copiez findhyph ou findhyph.bat (selon le système d'exploitation utilisé) dans un répertoire inclus dans le PATH du système. L'interpréteur Perl doit être dans "/usr/bin/" pour les systèmes de type Unix ou dans le PATH lors de l'utilisation de findhyph.bat.

SYNTAXE

findhyph [options] foo.log

DESCRIPTION

Pour utiliser ce programme :

1)
définissez "\tracingparagraphs=1" dans un document TeX foo.tex et exécutez :
2)
tex foo.tex
3)
findhyph [options] foo.log

Si vous définissez "\looseness=<N>" pour optimiser les paragraphes, vous devez passer cette information au fichier foo.log sous la forme "@looseness=<N>" (sur une ligne séparée). Vous pouvez utiliser une macro comme "\def\setlooseness#1{\looseness=#1 \immediate\write-1{@looseness=#1}}" à cet effet. Si le paragraphe contient du contenu en mode mathématique affiché, vous devez utiliser la macro dans toutes les parties divisées du paragraphe.

OPTIONS

-c
afficher les mots coupés par des traits d'union dans leur contexte
-f
afficher les sélecteurs de police et autres chaînes commençant par un caractère backslash
-v
afficher la version du programme
-p
générer un fichier contenant des informations sur les prépositions/conjonctions d'une seule lettre laissées en fin de ligne
-l=CHAINE
utiliser les prépositions/conjonctions listées dans CHAINE au lieu de la liste par défaut de prépositions et conjonctions "kKsSvVzZoOuUiIA" utilisée pour les langues slovaque et tchèque

FICHIERS DE SORTIE

foo.hyph
Liste des mots coupés par des traits d'union. Tous les caractères de ponctuation, parenthèses et autres caractères précédant ou suivant immédiatement les mots affichés sont inclus dans cette liste. Les constructions TeX difficiles à afficher ("\hbox{}", "\mark{}" etc.) sont affichées comme "[]". Le mode mathématique est indiqué par le signe "$".

Les numéros de page entre crochets font référence au fichier LOG et peuvent occasionnellement différer du document composé. La raison est que TeX peut avoir besoin de diviser plus de paragraphes qu'il n'en tiendrait finalement sur la page afin de trouver une coupure de page.

Les mots coupés par des traits d'union dans les notes de bas de page sont listés avant les mots coupés par des traits d'union dans le paragraphe auquel la note de bas de page est référencée.

foo.prep
Liste des prépositions si l'option -p est utilisée.

HISTORIQUE

1.0 (2001-04-08)

•
première publication

2.0 (2009-08-10)

  • corrections dans l'algorithme de détection des coupures de ligne ; prise en charge de la troisième passe de l'algorithme de coupure de ligne dans TeX ( "\emergencystretch" positif) ; prise en charge des coupures discrétionnaires dans la première passe
  • détection des numéros de page améliorée (numéros de page négatifs reconnus, numéros de page composés lorsque les registres "\count1" à "\count9" sont non nuls et les formats "[nn{mapfile}]", "[nn<picture>]" et "[nn<newline>" utilisés par pdfTeX ; la détection de faux numéros de page devrait être beaucoup plus rare)
  • liste configurable de prépositions et conjonctions
  • les mots coupés par des traits d'union peuvent être affichés dans leur contexte
  • suggestions et tests par Pavel Stříž

3.0 (2012-02-01)

  • correction d'un bug lorsque les démérites totaux du paragraphe sont négatifs
  • le réglage "\looseness" est maintenant pris en compte (grâce à Karel Horák pour avoir identifié le problème)

3.1 (2012-11-03)

•
correction de l'affichage des ligatures coupées par des traits d'union (bug signalé par Karel Horák)

3.2 (2012-11-21)

•
exemple amélioré de définition de la macro "\setlooseness" (grâce à Karl Berry)

3.3 (2013-06-18)

3.4 (2015-10-18)

  • correction du traitement des journaux produits à l'aide de l'option "\lastlinefit" de ε-TeX (bug signalé par Karel Horák)
  • correction de la gestion multiplateforme des sauts de ligne dans le fichier d'entrée
