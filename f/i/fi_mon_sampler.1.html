NOM

fi_mon_sampler - Échantillonneur simple pour le fournisseur ofi_hook_monitor.

SYNTAXE

 fi_mon_sampler [OPTIONS] <cible>      échantillonne à partir de fichiers à <cible>

DESCRIPTION

Extrait des données du fournisseur ofi_hook_monitor via des fichiers de communication. <cible> peut être un fichier de communication ou un dossier de fichiers. Les données sont exportées en fonction de -f <format> et soit imprimées sur stdout (uniquement pour les fichiers uniques), soit stockées par fichier de communication à -o <chemin_sortie>. L'échantillonneur peut surveiller les fichiers de communication pour les changements via l'option -w <msec> pour des échantillonnages répétés.

Le format du nom des fichiers de sortie est basé sur le fournisseur ofi_hook_monitor et est le suivant : <ppid>_<pid>_<identifiant séquentiel>_<identifiant de tâche>_<nom du fournisseur>. ppid et pid sont pris du point de vue de l'application surveillée. Dans un environnement batch exécutant SLURM, l'identifiant de tâche est défini sur l'identifiant de tâche SLURM, sinon il est défini sur 0.

COMMENT EXECUTER

Lancez une application libfabric avec FI_HOOK=monitor pour activer le fournisseur ofi_hook_monitor. Ajustez les paramètres du fournisseur moniteur conformément à fi_hook(7).

Lancez ensuite l'échantillonneur via fi_mon_sampler -o <sortie> <cible>. Par défaut, le fournisseur ofi_hook_monitor stocke les données dans /dev/shm/ofi/<uid>/<nom_hote>.

L'échantillonneur générera des fichiers de sortie dans le répertoire spécifié dans <sortie>, un pour chaque fournisseur surveillé.

OPTIONS

-w <msec>
Surveille les fichiers pour les changements, vérifie toutes les <msec> millisecondes.
-f <format>
Format de sortie. Prend actuellement uniquement en charge CSV.
-o <chemin_sortie>
Chemin du fichier de sortie. Utilise stdout si non défini.

EXEMPLES D'UTILISATION

Lancez une application libfabric et activez le fournisseur ofi_hook_monitor :

FI_HOOK=monitor fi_pingpong [OPTIONS]

Lancez un autre fi_pingpong avec les paramètres respectifs.

Enfin, lancez l'échantillonneur :

fi_mon_sampler -o $HOME -w 1000 -f csv /dev/shm/ofi/$UID/$HOSTNAME

SORTIE

Des fichiers de sortie seront générés dans le dossier spécifié avec -o <sortie>.

En mode -f csv, cela contiendra un fichier CSV avec les données de toutes les fonctions libfabric surveillées. Pour chaque fonction, les compteurs de nombre et de somme sont exportés, indiqués par les suffixes de nom de colonne _c et _s respectivement. De plus, chaque fonction est surveillée pour chaque groupe de tailles de données. Reportez-vous à fi_hook(7) pour plus de détails.

Exemple de sortie CSV, les quatre premières colonnes, les trois premières lignes :

mon_recv_0_64_c,mon_recv_0_64_s,mon_recv_64_512_c,mon_recv_64_512_s
0,0,0,0
22529,0,0,0
113664,0,0,0
