NOM

File::Find::Rule::Procedural - Interface procédurale de File::Find::Rule

SYNTAXE

use File::Find::Rule;
# trouve tous les fichiers .pm, de manière procédurale
my @files = find(file => name => '*.pm', in => \@INC);

DESCRIPTION

En plus de l'interface orientée objet habituelle, File::Find::Rule propose deux sous-routines que vous pouvez utiliser.

find( @clauses )
rule( @clauses )
"find" et "rule" peuvent être utilisés pour invoquer n'importe quelle méthode disponible pour la version OO. "rule" est un synonyme de "find".

Passer plusieurs valeurs à une clause se fait avec un tableau anonyme :

my $finder = find( name => [ '*.mp3', '*.ogg' ] );

"find" et "rule" retournent tous deux une instance de File::Find::Rule, sauf si l'un des arguments est "in", auquel cas il retourne une liste d'éléments correspondant à la règle.

my @files = find( name => [ '*.mp3', '*.ogg' ], in => $ENV{HOME} );

Notez bien que "in" sera la dernière clause évaluée, et donc ce code recherchera des mp3s indépendamment de leur taille.

my @files = find( name => '*.mp3', in => $ENV{HOME}, size => '<2k' );

                                                   |

Il est également possible d'inverser une règle unique en la précédant de "!" comme suit :

# gros fichiers qui ne sont pas des vidéos
my @files = find( file    =>
                  '!name' => [ '*.avi', '*.mov' ],
                  size    => '>20M',
                  in      => $ENV{HOME} );
