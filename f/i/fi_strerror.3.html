NOM

fi_errno - Erreurs de fabric

fi_strerror - Convertir une erreur de fabric en chaîne imprimable

SYNOPSIS

#include <rdma/fi_errno.h>
const char *fi_strerror(int errno);

ERREURS

FI_ENOENT
Aucun fichier ou répertoire de ce nom.
FI_EIO
Erreur d'entrée/sortie
FI_E2BIG
Liste d'arguments trop longue.
FI_EBADF
Numéro de fichier invalide.
FI_EAGAIN
Réessayer.
FI_ENOMEM
Mémoire insuffisante.
FI_EACCES
Permission refusée.
FI_EBUSY
Périphérique ou ressource occupé
FI_ENODEV
Aucun périphérique de ce nom
FI_EINVAL
Argument invalide
FI_EMFILE
Trop de fichiers ouverts
FI_ENOSPC
Espace disque insuffisant
FI_ENOSYS
Fonction non implémentée
FI_EWOULDBLOCK
L'opération bloquerait
FI_ENOMSG
Aucun message du type désiré
FI_ENODATA
Aucune donnée disponible
FI_EOVERFLOW
Valeur trop grande pour le type de données défini
FI_EMSGSIZE
Message trop long
FI_ENOPROTOOPT
Protocole non disponible
FI_EOPNOTSUPP
Opération non prise en charge sur le point de terminaison de transport
FI_EADDRINUSE
Adresse déjà en utilisation
FI_EADDRNOTAVAIL
Impossible d'attribuer l'adresse demandée
FI_ENETDOWN
Le réseau est indisponible
FI_ENETUNREACH
Le réseau est injoignable
FI_ECONNABORTED
Abandon de connexion causé par le logiciel
FI_ECONNRESET
Connexion réinitialisée par le pair
FI_ENOBUFS
Aucun espace tampon disponible
FI_EISCONN
Le point de terminaison de transport est déjà connecté
FI_ENOTCONN
Le point de terminaison de transport n'est pas connecté
FI_ESHUTDOWN
Impossible d'envoyer après l'arrêt du point de terminaison de transport
FI_ETIMEDOUT
Opération expirée
FI_ECONNREFUSED
Connexion refusée
FI_EHOSTDOWN

FI_EHOSTUNREACH
Aucun chemin vers l'hôte
FI_EALREADY
Opération déjà en cours
FI_EINPROGRESS
Opération en cours
FI_EREMOTEIO
Erreur d'entrée/sortie distante
FI_ECANCELED
Opération annulée
FI_ENOKEY

FI_EKEYREJECTED

FI_EOTHER

FI_ETOOSMALL

FI_EOPBADSTATE

FI_EBADFLAGS

FI_ENOEQ

FI_EDOMAIN

FI_ECRC

FI_ETRUNC

FI_ENOKEY

FI_EOVERRUN

FI_ENORX
