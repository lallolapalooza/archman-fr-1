FIDENTIFY(8) Outils d'administration FIDENTIFY(8)

NOM

fidentify - Détermine le type de fichier à l'aide de la base de données PhotoRec

SYNTAXE

fidentify [--check] [répertoire|fichier]

fidentify --version

DESCRIPTION


fidentify identifie le type de fichier, l'"extension", en utilisant la même base de données que PhotoRec.
Lorsqu'un fichier ou un répertoire est spécifié, fidentify affichera le type de fichier, ou les types de fichiers sous le répertoire spécifié.
Si aucun argument n'est fourni, fidentify affichera le type des fichiers sous le répertoire courant.
fidentify est similaire à file(1).

OPTIONS

--check
vérifie le format de fichier comme le fait PhotoRec par défaut

VOIR AUSSI

photorec(8), testdisk(8), file(1)
