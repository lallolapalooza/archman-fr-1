FIDO_ASSERT_ALLOW_CRED(3) Manuel des fonctions de bibliothèque FIDO_ASSERT_ALLOW_CRED(3)

NOM

fido_assert_allow_cred, fido_assert_empty_allow_list — gérer les listes d'autorisation dans une assertion FIDO2

SYNTAXE

#include <fido.h>

int
fido_assert_allow_cred(fido_assert_t *assert, const unsigned char *ptr, size_t len);

int
fido_assert_empty_allow_list(fido_assert_t *assert);

DESCRIPTION

La fonction fido_assert_allow_cred() ajoute ptr à la liste des identifiants autorisés dans assert, où ptr pointe vers un identifiant de credential de len octets. Une copie de ptr est effectuée, et aucune référence au pointeur passé n'est conservée. Si fido_assert_allow_cred() échoue, la liste existante des identifiants autorisés est préservée.

Pour connaître le format d'un identifiant de credential FIDO2, veuillez vous référer à la norme Web Authentication (webauthn).

La fonction fido_assert_empty_allow_list() vide la liste des identifiants autorisés dans assert.

VALEUR DE RETOUR

Les codes d'erreur renvoyés par fido_assert_allow_cred() et fido_assert_empty_allow_list() sont définis dans <fido/err.h>. En cas de succès, FIDO_OK est renvoyé.

VOIR AUSSI

fido_assert_new(3), fido_assert_set_authdata(3), fido_dev_get_assert(3)
