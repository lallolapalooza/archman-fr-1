NOM

File::UserDirs - Trouver des répertoires supplémentaires pour les médias et les documents

VERSION

version 0.09

SYNOPSIS

use File::UserDirs qw(:all);
print xdg_desktop_dir; # par exemple /home/utilisateur/Bureau

DESCRIPTION

Ce module peut être utilisé pour trouver des répertoires comme spécifié de manière informelle par le logiciel Freedesktop.org xdg-user-dirs. Cela donne un mécanisme pour localiser des répertoires supplémentaires pour les fichiers multimédias et documentaires.

FONCTIONS

Peut être exporté sur demande. Le groupe ":all" est également défini et exporte toutes les méthodes.

xdg_desktop_dir

my $dir = xdg_desktop_dir;

Retourne le répertoire du bureau. Sauf modification par l'utilisateur, il s'agit du répertoire Bureau dans le répertoire personnel.

xdg_documents_dir

my $dir = xdg_documents_dir;

Retourne le répertoire des documents. Sauf modification par l'utilisateur, il s'agit du répertoire personnel.

xdg_download_dir

my $dir = xdg_download_dir;

Retourne le répertoire de téléchargement. Sauf modification par l'utilisateur, il s'agit du répertoire personnel.

xdg_music_dir

my $dir = xdg_music_dir;

Retourne le répertoire de musique. Sauf modification par l'utilisateur, il s'agit du répertoire personnel.

xdg_pictures_dir

my $dir = xdg_pictures_dir;

Retourne le répertoire des images. Sauf modification par l'utilisateur, il s'agit du répertoire personnel.

xdg_publicshare_dir

my $dir = xdg_publicshare_dir;

Retourne le répertoire de partage public. Sauf modification par l'utilisateur, il s'agit du répertoire personnel.

xdg_templates_dir

my $dir = xdg_templates_dir;

Retourne le répertoire des modèles. Sauf modification par l'utilisateur, il s'agit du répertoire personnel.

xdg_videos_dir

my $dir = xdg_videos_dir;

Retourne le répertoire des vidéos. Sauf modification par l'utilisateur, il s'agit du répertoire personnel.

DIAGNOSTICS

""xdg-user-dir" a échoué au démarrage : %s"
L'exécutable "xdg-user-dir" n'a pas pu être exécuté, très probablement parce qu'il n'était pas installé. Voir "DEPENDANCES".

CONFIGURATION ET ENVIRONNEMENT

L'emplacement des répertoires peut être spécifié par l'utilisateur dans le fichier $XDG_CONFIG_HOME/user-dirs.dirs. C'est un fichier shell définissant un certain nombre de variables d'environnement. Pour trouver le chemin d'accès exact depuis Perl, exécutez :

use File::BaseDir qw(config_home);
print config_home('user-dirs.dirs');

Exemple de user-dirs.dirs personnalisé

XDG_DESKTOP_DIR="$HOME/Workspace"
XDG_DOCUMENTS_DIR="$HOME/Files"
XDG_DOWNLOAD_DIR="$HOME/Files/Downloads"
XDG_MUSIC_DIR="$HOME/Files/Audio"
XDG_PICTURES_DIR="$HOME/Files/Images"
XDG_PUBLICSHARE_DIR="$HOME/public_html"
XDG_TEMPLATES_DIR="$HOME/Files/Document templates"
XDG_VIDEOS_DIR="$HOME/Files/Video"

DÉPENDANCES

Ce module nécessite l'exécutable xdg-user-dir du paquet "xdg-user-dirs". Le code source est disponible sur http://cgit.freedesktop.org/xdg/xdg-user-dirs/.
