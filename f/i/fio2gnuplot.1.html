NOM

fio2gnuplot - Rendre les fichiers de sortie de fio avec gnuplot

SYNOPSIS

fio2gnuplot [-ghbiodvk] [-t titre] [-o fichier_sortie]
               [-d dossier_sortie] [-p motif]
               [-G type] [-m temps_min] [-M temps_max]

DESCRIPTION

fio2gnuplot analyse un ensemble de fichiers journaux de fio pour les transformer en un ensemble de graphiques tracés à l'aide de l'outil gnuplot. Plusieurs types de graphiques sont produits.

Graphique 2D Individuel
Chaque fichier est tracé dans un fichier image séparé avec plusieurs options.
  • raw : Trace la performance exacte rapportée. Ce tracé peut être difficile à lire.
  • smooth : une version plus lisse de l'impression brute. En utilisant l'option csplines de gnuplot, le rendu est filtré pour obtenir un graphique plus facile à lire.
  • trend : une version encore plus lisse de l'impression brute pour obtenir des tendances. Les courbes de Bézier permettent d'obtenir des tracés beaucoup plus filtrés. Le graphique résultant aide à comprendre les tendances.
Graphique 2D Regroupé
Tous les fichiers sont tracés dans une seule image pour faciliter la comparaison. Les mêmes options de rendu que pour le graphique 2D individuel sont utilisées :
  • raw
  • smooth
  • trend
Graphique 3D Regroupé
Tous les fichiers sont tracés dans un seul graphique 3D. Le tracé 3D génère une « surface » pour estimer la proximité des performances. Une surface plane signifie une bonne cohérence entre les tracés. Une surface accidentée signifie un manque de cohérence entre les tracés.
Tracé Mathématique
Graphique Moyen
Un graphique à barres pour montrer la performance moyenne de chaque fichier. Une ligne verte est ajoutée pour montrer la performance moyenne globale. Cette ligne verte aide à comprendre à quel point chaque fichier individuel s'éloigne de la moyenne.
Graphique Min
Une ligne verte est ajoutée pour montrer la moyenne globale des performances minimales. Cette ligne verte aide à comprendre à quel point chaque fichier individuel s'éloigne de la moyenne.
Graphique Max
Un graphique à barres pour montrer la performance maximale de chaque fichier. Une ligne verte est ajoutée pour montrer la moyenne globale des performances maximales. Cette ligne verte aide à comprendre à quel point chaque fichier individuel s'éloigne de la moyenne.
Écart-type
Un graphique à barres pour montrer l'écart-type de chaque fichier. Une ligne verte est ajoutée pour montrer la moyenne globale de l'écart-type. Cette ligne verte aide à comprendre à quel point chaque fichier individuel s'éloigne de la moyenne.

OPTIONS

-h ou --help
L'option -h affiche l'aide.
-p 'motif' ou --motif 'motif'
Un motif en expression régulière pour sélectionner les fichiers d'entrée fio. N'oubliez pas les guillemets simples pour éviter les interactions du shell.
-b ou --bandwidth
Un motif prédéfini pour sélectionner les fichiers *_bw.log.
-i ou --iops
Un motif prédéfini pour sélectionner les fichiers *_iops.log.
-g ou --gnuplot
Rendre les tracés gnuplot avant de quitter.
-o fichier ou --fichier_sortie fichier
Le nom de base pour les tracés gnuplot (défini avec le motif si défini).
-d dossier ou --outputdir dossier
Le répertoire où gnuplot doit rendre les fichiers.
-t titre ou --titre titre
Le titre des tracés gnuplot. Le titre est défini avec la taille de bloc détectée dans le tracé fio.
-G type ou --Global type
Recherche le 'type' dans les fichiers .global correspondant à un motif. Les types disponibles sont : min, max, avg, stddev. L'extension .global est ajoutée automatiquement au motif.
-m temps ou --temps_min temps
Ne considérer que les données à partir de 'temps' secondes. Par défaut, c'est 0.
-M temps ou --temps_max temps
Ne considérer que les données se terminant avant 'temps' secondes. Par défaut, c'est -1 (pas de limite).
-v ou --verbose
Augmente la verbosité.
-k ou --keep
Conserve tous les fichiers temporaires du répertoire de sortie de gnuplot.

EXEMPLE

Pour tracer tous les tracés nommés comme 'host*_read_4k_iops.log'
$ fio2gnuplot -p 'host*_read_4k_iops.log' -g
Pour tracer tous les fichiers de journaux orientés IO du répertoire courant
$ fio2gnuplot -g -i
Pour tracer tous les fichiers de journaux orientés Bande Passante du répertoire courant
$ fio2gnuplot -g -b
Pour tracer tous les fichiers de journaux orientés Bande Passante dans un répertoire nommé 'outdir'
$ fio2gnuplot -g -b -d outdir
