firewalld - Gestionnaire de pare-feu

dynamique

SYN

OP
SIS

firewall

d

[OPTIONS...] DESCRIPTI

O
N

firewalld fournit un pare-feu géré dynamiquement avec prise en charge des zones réseau/pare-feu pour définir le niveau de confiance des connexions ou des interfaces réseau. Il prend en charge les paramètres de pare-feu IPv4 et IPv6 ainsi que les ponts Ethernet, et sépare les options de configuration temporaire et permanente. Il prend également en charge une interface permettant aux services ou aux applications d'ajouter

directement des règles de pare-feu.

CONCEPT

S

firewalld possède une interface D-Bus pour la configuration du pare-feu des services et des applications. Il possède également un client en ligne de commande pour l'utilisateur. Les services ou les applications utilisant déjà D-Bus peuvent demander des modifications du pare-feu directement via l'interface D-Bus. Pour plus d'informations sur l'interface D-Bus de firewalld, veuillez consulter firewalld.db

us(5).

firewalld prend en charge les zones, les services prédéfinis et les types ICMP, et sépare les options de configuration temporaire et permanente. La configuration permanente est chargée à partir de fichiers XML dans /usr/lib/firewalld (--default-config) ou /etc/firewalld (--system-config) (voir la section intitulée « RÉPERTOIRES »)

.

Si NetworkManager n'est pas utilisé et que firewalld est démarré après que le réseau est déjà actif, les connexions et les interfaces créées manuellement ne sont pas liées à la zone spécifiée dans le fichier ifcfg. Les interfaces seront automatiquement gérées par la zone par défaut. firewalld ne sera pas non plus notifié des renommages de périphériques réseau. Tout cela s'applique également aux interfaces qui ne sont pas contrôlées par NetworkManager si NM_CONTROLLED=no est

défini.

Vous pouvez ajouter ces interfaces à une zone avec firewall-cmd [--permanent] --zone=zone --add-interface=interface. S'il existe un fichier /etc/sysconfig/network-scripts/ifcfg-interface, firewalld essaie de modifier le paramètre ZONE=zone dans ce

fichier.

Si firewalld est rechargé, il restaurera les liaisons d'interfaces qui étaient en place avant le rechargement afin de maintenir la stabilité des liaisons d'interfaces dans le cas des interfaces non contrôlées par NetworkManager. Ce mécanisme n'est pas possible dans le cas d'un redémarrage du service

firewalld.

Il est essentiel de maintenir la cohérence du paramètre ZONE= dans le fichier ifcfg avec la liaison dans firewalld dans le cas des interfaces non contrôlées par

NetworkManager.

Zone

s

Un réseau ou une zone de pare-feu définit le niveau de confiance de l'interface utilisée pour une connexion. Plusieurs zones prédéfinies sont fournies par firewalld. Les options de configuration des zones et les informations génériques sur les zones sont décrites dans firewa

lld.z
one(5)

Service

s

Un service peut être une liste de ports locaux, de protocoles et de destinations, et éventuellement aussi une liste de modules d'assistance de pare-feu chargés automatiquement si un service est activé. Les options de configuration des services et les informations génériques sur les services sont décrites dans firewalld.service(5). L'utilisation de services prédéfinis facilite pour

l'utilisateur l'activation et la dé
sactivation de l'accès à un service.

Types

ICMP

Le protocole de contrôle de messagerie Internet (ICMP) est utilisé pour échanger des informations et également des messages d'erreur dans le protocole Internet (IP). Les types ICMP peuvent être utilisés dans firewalld pour limiter l'échange de ces messages. Pour plus d'informations, veuillez consulter firewalld.i

cmpty
pe(5).

Configuration

temporaire

La configuration temporaire est la configuration active réelle et n'est pas permanente. Apr

ès le rechargement/redémarrage du service ou un redémarrage du système, les paramètres tempo
raires seront perdus s'ils n'ont pas également été inclus dans la configuration permanente.

Configuration

permanente

La configuration permanente est stockée dans des fichiers de configurat

ion et sera chargée et deviendra la nouvelle configuration temporaire à
chaque démarrage de la machine ou rechargement/redémarrage du service.

Interface

directe

OBSOLETE

L'interface directe a été dépréciée. Elle sera supprimée dans une version future. Elle est remplacée par les politiques, voir firewalld.p

olici
es(5).

L'interface directe est principalement utilisée par les servic

es ou les applications pour ajouter des règles de pare-feu spé
cifiques. Elle nécessite des connaissances de base des concepts
ip(6)tables (tables, chaînes, commandes, paramètres, cibles).

RÉPERTOIRE

S

firewalld prend en charge deux répertoires de configuration

:

Configuration par défaut/de repli dans /usr/lib/firewalld (--default-config

)

Ce répertoire contient la configuration par défaut et de repli fournie par firewalld pour les icmptypes, les services et les zones. Les fichiers fournis avec le paquet firewalld ne doivent pas être modifiés et les modifications sont perdues lors d'une mise à jour du paquet firewalld. Des icmptypes, services et zones supplémentaires peuvent être fournis

par des paquets ou en
créant des fichiers.

Paramètres de configuration système dans /etc/firewalld (--system-config

)

La configuration système ou utilisateur stockée ici est soit créée par l'administrateur système, soit par personnalisation avec l'interface de configuration de firewalld, soit à la main. Les fichiers remplaceront les fichiers de configuration par

défaut.

Pour modifier manuellement les paramètres des icmptypes, des zones ou des services prédéfinis, copiez le fichier du répertoire de configuration par défaut vers le répertoire correspondant du répertoire de configuration système et modifiez-le en

conséquence.
