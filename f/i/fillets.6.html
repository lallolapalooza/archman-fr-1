NOM

fillets - jeu de puzzle sur des poissons pleins d'esprit qui sauvent le monde dans le style de Sokoban

SYNOPIS

fillets [options]

DESCRIPTION

Fish Fillets est un jeu de puzzle à proprement parler. Le but dans chacun des soixante-dix niveaux est toujours le même : trouver une issue sûre. Les poissons prononcent des remarques spirituelles sur leur environnement, les divers habitants de leur royaume sous-marin se querellent entre eux ou commentent les efforts de vos poissons. L'ensemble du jeu est accompagné d'une musique calme et réconfortante.

Il existe un excellent tutoriel dans le jeu, vous pouvez donc commencer à jouer immédiatement.

OPTIONS

-h, --help
Afficher le résumé des options.
-v, --version
Afficher la version du programme.
-c, --config
Afficher les variables de configuration et leurs valeurs.
fullscreen=<booléen>
Activer/désactiver le plein écran.
Par défaut : fullscreen=0
lang=<code>
Code ISO 639 à 2 lettres (par ex. : fr, en, de)
voir http://www.w3.org/WAI/ER/IG/ert/iso639.htm
Par défaut : lang=LC_MESSAGES
loglevel=<nombre>
Le niveau de journalisation utilise les mêmes numéros que syslog.
par ex. : 3 pour ERROR, 4 pour WARNING, 6 pour INFO, 7 pour DEBUG
Par défaut : loglevel=6
show_steps=<booléen>
Afficher le compteur de pas dans le niveau.
Par défaut : show_steps=0
sound=<booléen>
Activer/désactiver le son.
Par défaut : sound=1
speech=<code>
Code ISO 639 à 2 lettres (par ex. : fr, en, de)
voir http://www.w3.org/WAI/ER/IG/ert/iso639.htm
Par défaut : identique à lang
subtitles=<booléen>
Afficher les sous-titres dans le niveau.
Par défaut : subtitles=1
systemdir=<chemin>
Chemin vers les données du jeu.
userdir=<chemin>
Chemin vers les données du jeu.
Par défaut : userdir=$HOME/.fillets-ng
volume_sound=<nombre>
Volume sonore en pourcentage.
Par défaut : volume_sound=90
volume_music=<nombre>
Volume musical en pourcentage.
Par défaut : volume_music=50
worldmap=<chemin>
Chemin relatif vers le fichier de carte du monde.
Utile pour les niveaux externes.
Par défaut : worldmap=script/worldmap.lua

UTILISATION

Les touches fléchées haut, bas, gauche et droite contrôlent le poisson actuel.
Utilisez la barre d'espace pour passer d'un poisson à l'autre.

redémarrer le niveau - Retour arrière
annuler - -
aide - F1
sauvegarder le jeu - F2
charger le jeu - F3
afficher/masquer le compteur de mouvements du niveau - F5
afficher/masquer les sous-titres - F6
menu du jeu - F10
basculer le plein écran - F11
augmenter la vitesse du jeu - maintenir la touche Maj enfoncée

Trouvez plus d'informations dans le manuel html "Comment jouer" ci-dessous.
