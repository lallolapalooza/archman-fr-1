NOM

fio_generate_plots - Générer des graphiques pour Flexible I/O Tester

SYNTAXE

fio_generate_plots titre

DESCRIPTION

Cette page de manuel documente brièvement la commande fio_generate_plots. Cette page de manuel a été écrite pour la distribution Debian car le programme original ne possède pas de page de manuel.

fio_generate_plots est un script shell qui utilise gnuplot pour générer des graphiques à partir de fio exécuté avec --latency-log (-l) et/ou --bandwidth-log (-w). Il s'attend à trouver les fichiers journaux générés par fio dans le répertoire courant.

OPTIONS

Le script prend le titre du graphique comme seul argument. Il n'offre aucune option supplémentaire.
