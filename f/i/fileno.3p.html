FILENO(3P) Manuel du programmeur POSIX FILENO(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation de cette interface sous Linux peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

fileno — mapper un pointeur de flux à un descripteur de fichier

SYNTAXE

#include <stdio.h>
int fileno(FILE *stream);

DESCRIPTION

La fonction fileno() renvoie le descripteur de fichier entier associé au flux pointé par stream.

VALEUR DE RETOUR

En cas de succès, fileno() renvoie la valeur entière du descripteur de fichier associé à stream. Sinon, la valeur -1 est renvoyée et errno est définie pour indiquer l'erreur.

ERREURS

La fonction fileno() échoue si :

EBADF
Le flux n'est pas associé à un fichier.

La fonction fileno() peut échouer si :

EBADF
Le descripteur de fichier sous-jacent à stream n'est pas un descripteur de fichier valide.

RATIONNEL

Sans une spécification des descripteurs de fichiers associés à ces flux, il est impossible pour une application de configurer les flux pour une autre application qu'elle lance avec fork() et exec. En particulier, il ne serait pas possible d'écrire une version portable de l'interpréteur de commandes sh (bien qu'il puisse y avoir d'autres contraintes qui empêcheraient cette portabilité).
