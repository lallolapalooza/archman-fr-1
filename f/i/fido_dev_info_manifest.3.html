DESCRIPTION

La fonction fido_dev_info_manifest() remplit devlist avec jusqu'à ilen périphériques FIDO2 trouvés par le système d'exploitation sous-jacent. Actuellement, seuls les périphériques USB HID sont pris en charge. Le nombre de périphériques découverts est renvoyé dans olen, où olen est un pointeur adressable.

La fonction fido_dev_info_new() renvoie un pointeur vers une liste de périphériques vide nouvellement allouée avec n emplacements disponibles. Si la mémoire n'est pas disponible, NULL est renvoyé.

La fonction fido_dev_info_free() libère la mémoire qui soutient *devlist_p, où *devlist_p doit avoir été précédemment alloué par fido_dev_info_new(). Le nombre n d'emplacements alloués doit également être fourni. Au retour, *devlist_p est mis à NULL. Soit devlist_p soit *devlist_p peut être NULL, dans ce cas fido_dev_info_free() est une NOP.

La fonction fido_dev_info_ptr() renvoie un pointeur vers l'emplacement numéro i de devlist. Il incombe à l'appelant de s'assurer que i est borné. Veuillez noter que le premier emplacement a l'indice 0.

La fonction fido_dev_info_path() renvoie le chemin d'accès au système de fichiers ou la chaîne d'identification spécifique au sous-système de di.

La fonction fido_dev_info_product() renvoie l'identifiant produit de di.

La fonction fido_dev_info_vendor() renvoie l'identifiant du fournisseur de di.

La fonction fido_dev_info_manufacturer_string() renvoie la chaîne du fabricant de di. Si di n'a pas de chaîne de fabricant associée, fido_dev_info_manufacturer_string() renvoie une chaîne vide.

La fonction fido_dev_info_product_string() renvoie la chaîne du produit de di. Si di n'a pas de chaîne de produit associée, fido_dev_info_product_string() renvoie une chaîne vide.

Un exemple d'utilisation des fonctions décrites dans ce document peut être trouvé dans le fichier examples/manifest.c livré avec libfido2.

La fonction fido_dev_info_set() initialise une entrée dans une liste de périphériques allouée par fido_dev_info_new() avec le chemin d'accès spécifié, les chaînes de fabricant et de produit, et avec les gestionnaires d'E/S spécifiés et, facultativement, les fonctions de transport, comme décrit dans fido_dev_set_io_functions(3). L'argument io doit être spécifié ; l'argument transport peut être NULL. Le chemin d'accès, les gestionnaires d'E/S et les fonctions de transport seront utilisés automatiquement par fido_dev_new_with_info(3) et fido_dev_open_with_info(3). Une application peut l'utiliser, par exemple, pour substituer des périphériques FIDO2 simulés dans les tests aux périphériques réels que fido_dev_info_manifest() découvrirait.

VALEURS DE RETOUR

La fonction fido_dev_info_manifest() renvoie toujours FIDO_OK. Si une erreur de découverte se produit, le pointeur olen est mis à 0.

En cas de succès, la fonction fido_dev_info_set() renvoie FIDO_OK. En cas d'erreur, un code d'erreur différent défini dans <fido/err.h> est renvoyé.

Les pointeurs renvoyés par fido_dev_info_ptr(), fido_dev_info_path(), fido_dev_info_manufacturer_string(), et fido_dev_info_product_string() sont garantis d'exister jusqu'à ce que fido_dev_info_free() soit appelé sur la liste de périphériques correspondante.
