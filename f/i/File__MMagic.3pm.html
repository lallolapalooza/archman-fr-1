    NAME

    File::MMagic - Perl interface to the libmagic file type determination library

    SYNOPSIS

    use File::MMagic;

my $mm = File::MMagic->new();
my $type = $mm->mime_type('/path/to/file');
print "The file is of type: $type\n";

my $desc = $mm->description('/path/to/file');
print "File description: $desc\n";

# You can also pass a filehandle
open my $fh, '<', '/path/to/file' or die;
my $type_from_fh = $mm->mime_type($fh);
print "File type from filehandle: $type_from_fh\n";
close $fh;

# To get the magic database loaded by default
print $mm->magic_database();

    ABSTRACT

    This module provides a Perl interface to the libmagic library, which is used by the file command to determine file types. It allows you to determine the MIME type and a human-readable description of a file.

    DESCRIPTION

    File::MMagic is a Perl wrapper around the libmagic library. libmagic is a library that determines the type of a file by examining its contents. It uses a database of "magic numbers" (unique sequences of bytes) and other heuristics to identify file types.

    The primary functions of this module are:

    • mime_type(FILE): Returns the MIME type of the given file (e.g., text/plain, image/jpeg).
    • description(FILE): Returns a human-readable description of the file (e.g., ASCII text, JPEG image data).

    Both methods accept a filename string or a filehandle as an argument.

    magic_database(): Returns the path to the magic database file that libmagic is using.

    METHODS

    new()
    Creates a new File::MMagic object. No arguments are required.
    mime_type(FILE)

    Takes a filename or a filehandle as an argument and returns the MIME type of the file.

    Returns undef if the type cannot be determined or if an error occurs.

    description(FILE)

    Takes a filename or a filehandle as an argument and returns a human-readable description of the file.

    Returns undef if the description cannot be determined or if an error occurs.

    magic_database()

    Returns the path to the magic database file loaded by libmagic.
