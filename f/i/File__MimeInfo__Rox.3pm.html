NOM

File::MimeInfo::Rox - Ouvrir des fichiers par type MIME "style Rox"

SYNOPSIS

use File::MimeInfo::Magic;
use File::MimeInfo::Rox qw/:magic/;
# ouvrir un fichier avec le programme approprié
mime_system($somefile);
# version plus verbeuse
my $mt = mimetype($somefile)
  || die "Impossible de trouver le type MIME pour $somefile\n";
mime_system($somefile, $mt)
  || die "Aucun programme disponible pour ouvrir $somefile\n";

DESCRIPTION

Ce module essaie d'imiter le comportement du navigateur de fichiers rox http://rox.sf.net lors de "l'ouverture" de fichiers de données. Il détermine le type MIME et recherche dans les répertoires "Choices" de rox un programme pour gérer ce type MIME.

Voir la documentation de rox pour une discussion approfondie de ce mécanisme.

EXPORT

Les méthodes "mime_exec" et "mime_system" sont exportées. Si vous utilisez la balise d'exportation ":magic", vous obtenez les mêmes méthodes, mais File::MimeInfo::Magic sera utilisé pour la recherche du type MIME.

ENVIRONNEMENT

La variable d'environnement "CHOICESPATH" est utilisée lors de la recherche des répertoires de configuration de rox. Elle est par défaut "$ENV{HOME}/Choices:/usr/local/share/Choices:/usr/share/Choices"

METHODES

mime_system($file)
"mime_system($file, $mimetype, @_)"
Essaye d'ouvrir $file avec le programme approprié pour le type MIME de celui-ci. Vous pouvez utiliser $mimetype pour forcer le type MIME. De plus, si vous connaissez déjà le type MIME, cela permet d'économiser beaucoup de temps.

Si le type MIME n'a pas pu être déterminé ou si aucun programme approprié n'a été trouvé, "undef" est retourné. Si le système échoue réellement, une exception est levée.

Tous les arguments restants sont passés au gestionnaire.

mime_exec($file)
"mime_exec($file, $mimetype, @_)"
Similaire à mime_system(), mais utilise exec au lieu de system, donc ne retourne jamais en cas de succès.
suggest_script_name($mimetype)
Retourne la liste "($dir, $file)" pour l'endroit suggéré pour écrire de nouveaux scripts (ou liens symboliques) pour le type MIME $mimetype. Le répertoire suggéré n'a pas besoin d'exister.
