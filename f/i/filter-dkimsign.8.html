NOM

filter-dkimsign - ajoute une signature dkim aux messages

SYNTAXE

filter-dkimsign [-tz] [-a algorithme] [-c canonicalisation] [-h en-têtes] [-x secondes] -d domaine -D fichier -k fichier -s sélecteur

DESCRIPTION

filter-dkimsign ajoute une signature dkim au message. Les options suivantes sont prises en charge :

-a algorithme
L’algorithme à utiliser. Les algorithmes de signature pris en charge sont rsa et ed25519 (lorsqu’il est activé à la compilation). Seul sha256 doit être utilisé pour le hachage, car les autres algorithmes ne sont très probablement pas pris en charge par les vérificateurs. La valeur par défaut est rsa-sha256.
-c canonicalisation
L’algorithme de canonicalisation utilisé pour signer le message. La valeur par défaut est simple/simple.
-D fichier
Le fichier doit pointer vers un fichier contenant une liste de domaines. Un seul domaine par ligne doit être spécifié. Voir -d pour plus d’informations.
-d domaine
Le domaine où la clé publique peut être trouvée. Cette option peut être spécifiée plusieurs fois pour sélectionner le meilleur domaine lors de la signature. Si elle est spécifiée plusieurs fois, elle examine le composant domaine de la première boîte aux lettres dans l’en-tête from et essaie de trouver une correspondance. Si aucune correspondance exacte ne peut être trouvée, elle recherche le domaine parent le plus proche. Si aucune correspondance ne peut être trouvée, le premier domaine spécifié sera utilisé.
-h en-têtes
Les en-têtes de courrier électronique inclus dans la signature du courrier. Conformément à la RFC, cette option nécessite qu’au moins l’en-tête from soit inclus. Les en-têtes sont spécifiés en les séparant par deux-points. La valeur par défaut est from:reply-to:subject:date:to:cc:resent-date:resent-from:resent-to:resent-cc:in-reply-to:references:list-id:list-help:list-unsubscribe:list-subscribe:list-post:list-owner:list-archive.
-k fichier
Le fichier doit pointer vers un fichier contenant la clé privée RSA pour signer les messages.
-s sélecteur
Le sélecteur dans le sous-domaine _domainkey de domaine où la clé publique peut être trouvée.
-t
Ajoute l'heure de signature à l'en-tête dkim.
-x secondes
Ajoute la durée de validité de la signature en secondes à l'en-tête dkim.
-z
Ajoute les en-têtes de courrier utilisés dans la signature dkim à l'en-tête dkim. Si un second -z est spécifié, tous les en-têtes seront inclus dans l'en-tête dkim. Utile à des fins de débogage.
