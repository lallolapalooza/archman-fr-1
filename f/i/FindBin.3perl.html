FindBin(3perl) Guide de référence du programmeur Perl FindBin(3perl)

NOM

FindBin - Localiser le répertoire du script Perl original

SYNTAXE

use FindBin;
use lib "$FindBin::Bin/../lib";
use FindBin qw($Bin);
use lib "$Bin/../lib";

DESCRIPTION

Localise le chemin complet vers le répertoire bin du script afin de permettre l'utilisation de chemins relatifs au répertoire bin.

Cela permet à un utilisateur de mettre en place une arborescence de répertoires pour un logiciel avec les répertoires "<racine>/bin" et "<racine>/lib", et l'exemple ci-dessus permettra alors d'utiliser les modules du répertoire lib sans connaître l'emplacement d'installation de l'arborescence logicielle.

Si "perl" est invoqué en utilisant l'option "-e" ou si le script Perl est lu depuis "STDIN", alors "FindBin" définit à la fois $Bin et $RealBin au répertoire courant.

VARIABLES EXPORTABLES

$Bin ou $Dir
Chemin vers le répertoire bin à partir duquel le script a été invoqué
$Script
Nom de base du script à partir duquel "perl" a été invoqué
$RealBin ou $RealDir
$Bin avec tous les liens résolus
$RealScript
$Script avec tous les liens résolus

Vous pouvez également utiliser la balise "ALL" pour exporter toutes les variables ci-dessus ensemble :

use FindBin ':ALL';

PROBLÈMES CONNUS

S'il y a deux modules utilisant "FindBin" depuis des répertoires différents sous le même interpréteur, cela ne fonctionnera pas. Étant donné que "FindBin" utilise un bloc "BEGIN", il ne sera exécuté qu'une seule fois, et seul le premier appelant obtiendra le bon résultat. C'est un problème sous "mod_perl" et d'autres environnements Perl persistants, où vous ne devriez pas utiliser ce module. Cela signifie également que vous devriez éviter d'utiliser "FindBin" dans des modules que vous prévoyez de mettre sur CPAN. Appelez la fonction "again" pour vous assurer que "FindBin" fonctionnera :

use FindBin;
FindBin::again(); # ou FindBin->again;

Dans les versions antérieures de "FindBin", il n'y avait pas de fonction "again". La solution de contournement consistait à forcer l'exécution du bloc "BEGIN" à nouveau :

delete $INC{'FindBin.pm'};
require FindBin;
