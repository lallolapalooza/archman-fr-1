NOM

firejail.users - Base de données d'accès des utilisateurs de Firejail

DESCRIPTION

Le fichier `/etc/firejail/firejail.users` liste les utilisateurs autorisés à exécuter l'exécutable SUID de Firejail. L'utilisateur root est autorisé par défaut, l'utilisateur nobody n'est jamais autorisé.

Si l'utilisateur n'est pas autorisé à démarrer le bac à sable, Firejail tentera d'exécuter le programme sans le mettre en bac à sable.

Si le fichier n'est pas présent sur le système, tous les utilisateurs sont autorisés à utiliser le bac à sable.

Exemple :

$ cat /etc/firejail/firejail.users
dustin
lucas
mike
eleven

Utilisez un éditeur de texte pour ajouter ou supprimer des utilisateurs de la liste. Vous pouvez également utiliser la commande `firecfg --add-users`. Exemple :

$ sudo firecfg --add-users dustin lucas mike eleven

Par défaut, l'exécution de `firecfg` crée le fichier et ajoute l'utilisateur actuel à la liste. Exemple :

$ sudo firecfg

Voir man 1 firecfg pour plus de détails.

SOLUTION ALTERNATIVE

Une autre façon de restreindre l'accès des utilisateurs à l'exécutable Firejail est de créer un groupe d'utilisateurs Firejail spécial et d'autoriser uniquement les utilisateurs de ce groupe à exécuter le bac à sable :

# addgroup --system firejail
# chown root:firejail /usr/bin/firejail
# chmod 4750 /usr/bin/firejail
