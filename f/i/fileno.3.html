fileno(3) Manuel des fonctions de bibliothèque fileno(3)

NOM

fileno — obtenir le descripteur de fichier d'un flux stdio

BIBLIOTHQUE

Bibliothèque C standard (libc, -lc)

SYNOPSIS

#include <stdio.h>
int fileno(FILE *stream);
Exigences pour les macros de test de fonctionnalités glibc (voir feature_test_macros(7)):

fileno():

    _POSIX_C_SOURCE

DESCRIPTION

La fonction fileno() examine l'argument stream et retourne le descripteur de fichier entier utilisé pour implémenter ce flux. Le descripteur de fichier appartient toujours à stream et sera fermé lorsque fclose(3) sera appelé. Dupliquez le descripteur de fichier avec dup(2) avant de le passer à du code qui pourrait le fermer.

Pour l'équivalent non verrouillant, voir unlocked_stdio(3).

VALEUR DE RETOUR

En cas de succès, fileno() retourne le descripteur de fichier associé à stream. En cas d'échec, -1 est retourné et errno est défini pour indiquer l'erreur.

ERREURS

EBADF
stream n'est pas associé à un fichier.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
fileno () Thread safety MT-Safe

NORMES

POSIX.1-2008.

HISTORIQUE

POSIX.1-2001.

VOIR AUSSI
