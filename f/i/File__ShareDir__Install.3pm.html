DESCRIPTIO

N

File::ShareDir::Install vous permet d'installer des fichiers de données en lecture seule à partir d'une distribution. C'est un module compagnon de File::ShareDir, qui vous permet de localiser ces fichiers après

l'installation.

C'est un portage de Module::Install::Share vers ExtUtils::MakeMaker avec l'amélioration de n'installer que les fichiers que vous voulez ; ".svn", ".git" et autres fichiers de contrôle de source seront

ignorés.

Veuillez noter que ce module installe des

fichiers de données en lecture seul
e ; les répertoires vides seront ignorés.

EXPOR

T

install_shar

e 
install_share $dir;
install_share dist => $dir;
install_share module => $module,
$dir;

Fait en sorte que tous les fichiers dans $dir et ses sous-répertoires soient installés dans un répertoire de partage par distribution ou par module. Doit être appelé avant "WriteMakefile"

.

Les 2 premières formes sont équivalentes ; les fichiers sont installés dans un répertoire par distribution. Par exemple "/usr/lib/perl5/site_perl/auto/share/dist/My-Dist". Le nom de ce répertoire peut être récupéré avec "dist_dir" dans File::

ShareDir.

La dernière forme installe les fichiers dans un répertoire par module. Par exemple "/usr/lib/perl5/site_perl/auto/share/module/My-Dist-Package". Le nom de ce répertoire peut être récupéré avec "module_dir" dans File::

ShareDir.

Le paramètre $dir peut être un tableau de

répertoires.

Les fichiers seront installés lorsque vous exécuterez "make install". Cependant, la liste des fichiers à installer est générée lorsque Makefile.PL est

exécuté.

Notez que si vous faites plusieurs appels à "install_share" sur différents répertoires qui contiennent les mêmes noms de fichiers, le dernier de ces appels prend le dessus. Autrement dit, si vous faites

: 
install_share 'share1';
install_share
'share2';

Et que "share1" et "share2" contiennent tous deux un fichier appelé "info.txt", le fichier "share2/info.txt" sera installé dans votre dist_d

ir
().

delete_shar

e 
delete_share $list;
delete_share dist => $list;
delete_share module => $module,
$list;

Supprime des fichiers ou des répertoires précédemment

installés.

Contrairement à "install_share", le dernier paramètre est une liste de fichiers ou de répertoires qui ont été installés précédemment. Ces fichiers et répertoires seront supprimés lorsque vous exécuterez "make ins

tall".

Le paramètre $list peut être un tableau de fichiers ou de

répertoires.

La suppression se fait dans l'ordre, en même temps que l'installation. Cela signifie que vous pouvez supprimer tous les fichiers précédemment installés en mettant ce qui suit au début de votre Makefile.

PL. 
delete_share '.
';

Vous pouvez aussi supprimer sélectivement certains fichiers de

l'installation. 
install_share 'some-dir';
if( ... ) {
    delete_share 'not-this-file.rc';
}

CONFIGURATIO

N

Deux variables contrôlent le traitement des fichiers et des répertoires à

point.

Un fichier à point a un nom de fichier qui commence par un point (.). Par exemple ".htaccess". Un répertoire à point est un répertoire qui commence par un point (.). Par exemple ".config/". Tous les systèmes de fichiers ne prennent pas en charge l'utilisation des fichiers à

point.

$INCLUDE_DOTFILE

S

S'il est défini à une valeur vraie,

les fichiers à point seront cop
iés. La valeur par défaut est faux.

$INCLUDE_DOTDIR

S

S'il est défini à une valeur vraie, les fichiers à l'intérieur des

répertoires à point seront copiés. Les répertoires de contrôle de
version connus sont toujours ignorés. La valeur par défaut est faux.

Not

e

Ces variables n'influencent que les appels ultérieurs à install_share(). Cela vous permet de contrôler le comportement pour chaque

répertoire.

Par exemple

: 
$INCLUDE_DOTDIRS = 1;
install_share 'share1';
$INCLUDE_DOTFILES = 1;
$INCLUDE_DOTDIRS = 0;
install_share
'share2';

Le répertoire "share1" aura les fichiers de ses répertoires à point installés, mais pas les fichiers à point. Le répertoire "share2" aura les fichiers de ses fichie

rs à point installés,
mais les répertoires à
point seront ignorés.
