NOM

firewalld.ipset - Fichiers de configuration des ipsets firewalld

SYNOPSIS

/etc/firewalld/ipsets/ipset.xml
/usr/lib/firewalld/ipsets/ipset.xml

DESCRIPTION

Un fichier de configuration d'ipset firewalld fournit les informations d'un ipset pour firewalld. Les options de configuration les plus importantes sont le type, l'option et l'entrée.

Cet exemple de fichier de configuration montre la structure d'un fichier de configuration d'ipset :

<?xml version="1.0" encoding="utf-8"?>
<ipset type="hash:ip">
  <short>Mon Ipset</short>
  <description>description</description>
  <entry>1.2.3.4</entry>
  <entry>1.2.3.5</entry>
  <entry>1.2.3.6</entry>
</ipset>

OPTIONS

La configuration peut contenir ces balises et attributs. Certains sont obligatoires, d'autres optionnels.

ipset

La balise de début et de fin obligatoire ipset définit l'ipset. Cette balise ne peut être utilisée qu'une seule fois dans un fichier de configuration d'ipset. Il y a un attribut obligatoire et également optionnel pour les ipsets :

type="string"

Le type obligatoire de l'ipset. Pour obtenir la liste des types pris en charge, utilisez firewall-cmd --get-ipset-types.

version="string"

Pour donner une version à l'ipset.

short

Est une balise de début et de fin optionnelle et est utilisée pour donner un nom plus lisible à un ipset.

description

Est une balise de début et de fin optionnelle pour avoir une description d'un ipset.

option

Est une balise d'élément vide optionnelle et peut être utilisée plusieurs fois pour avoir plus d'une option. La plupart des attributs d'une entrée d'option sont obligatoires :

name="string"

Le nom d'option obligatoire string.

value="string"

La valeur optionnelle de l'option.

Les options prises en charge sont : family : "inet"|"inet6", timeout : entier, hashsize : entier, maxelem : entier. Pour plus d'informations sur ces options, veuillez consulter la documentation ipset.

entry

Est une balise de début et de fin optionnelle et peut être utilisée plusieurs fois pour avoir plus d'une entrée. Une entrée n'a pas d'attributs.
