find(n) [incr Tcl] find(n)

NOM

itcl::find - rechercher des classes et des objets

SYNOPIS

itcl::find option ?arg arg ...?

DESCRIPTION

La commande find est utilisée pour trouver les classes et les objets disponibles dans l'interpréteur courant. Les classes et les objets sont rapportés d'abord dans l'espace de noms actif, puis dans tous les autres espaces de noms de l'interpréteur.

L'argument option détermine l'action effectuée par la commande. Les options légales (qui peuvent être abrégées) sont :

find classes ?pattern?
Retourne une liste des classes [incr Tcl]. Les classes dans l'espace de noms courant sont listées en premier, suivies par les classes dans tous les autres espaces de noms de l'interpréteur. Si le pattern optionnel est spécifié, alors les noms rapportés sont comparés en utilisant les règles de la commande "string match", et seuls les noms correspondants sont rapportés.

Si une classe réside dans le contexte de l'espace de noms courant, cette commande rapporte son nom simple - sans qualificateurs. Cependant, si le pattern contient des qualificateurs ::, ou si la classe réside dans un autre contexte, cette commande rapporte son nom complet. Par conséquent, vous pouvez utiliser la commande suivante pour obtenir une liste où tous les noms sont entièrement qualifiés :

itcl::find classes ::*
find objects ?pattern? ?-class className? ?-isa className?
Retourne une liste d'objets [incr Tcl]. Les objets dans l'espace de noms courant sont listés en premier, suivis par les objets dans tous les autres espaces de noms de l'interpréteur. Si le pattern optionnel est spécifié, alors les noms rapportés sont comparés en utilisant les règles de la commande "string match", et seuls les noms correspondants sont rapportés. Si le paramètre optionnel "-class" est spécifié, cette liste est limitée aux objets dont la classe la plus spécifique est className. Si le paramètre optionnel "-isa" est spécifié, cette liste est en outre limitée aux objets ayant la className donnée quelque part dans leur ascendance.

Si un objet réside dans le contexte de l'espace de noms courant, cette commande rapporte son nom simple - sans qualificateurs. Cependant, si le pattern contient des qualificateurs ::, ou si l'objet réside dans un autre contexte, cette commande rapporte son nom complet. Par conséquent, vous pouvez utiliser la commande suivante pour obtenir une liste où tous les noms sont entièrement qualifiés :

itcl::find objects ::*
