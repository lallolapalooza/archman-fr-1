File::Slurper(3) Documentation Perl fournie par l'utilisateur File::Slurper(3)

NOM

File::Slurper - Un module simple, sain et efficace pour "engloutir" un fichier

VERSION

version 0.014

SYNOPSIS

use File::Slurper 'read_text';
my $contenu = read_text($nom_fichier);

DESCRIPTION

Ce module fournit des fonctions pour engloutir et cracher des fichiers rapidement et correctement. Toutes les fonctions sont exportées optionnellement. Toutes les fonctions lancent des exceptions en cas d'erreur, les fonctions d'écriture ne retournent aucune valeur significative.

FONCTIONS

read_text($nom_fichier, $encodage, $crlf)

Lit le fichier $nom_fichier dans un scalaire et le décode depuis $encodage (qui est par défaut UTF-8). Si $crlf est vrai, une traduction crlf est effectuée. La valeur par défaut pour cet argument est désactivée. La valeur spéciale 'auto' la définira à une valeur par défaut spécifique à la plateforme.

read_binary($nom_fichier)

Lit le fichier $nom_fichier dans un scalaire sans aucun décodage ni transformation.

read_lines($nom_fichier, $encodage, $crlf, $saut_chomp)

Lit le fichier $nom_fichier dans une liste/tableau ligne par ligne, après décodage depuis $encodage, traduction crlf optionnelle et suppression de la fin de ligne. Il utilisera toujours une nouvelle ligne comme séparateur.

write_text($nom_fichier, $contenu, $encodage, $crlf)

Écrit $contenu dans le fichier $nom_fichier, en l'encodant en $encodage (qui est par défaut UTF-8). Il peut aussi prendre un argument "crlf" qui fonctionne exactement comme dans read_text.

write_binary($nom_fichier, $contenu)

Écrit $contenu dans le fichier $nom_fichier en tant que données binaires.

read_dir($nom_rep)

Ouvre le répertoire "nom_rep" et retourne toutes les entrées à l'exception de "." et "..".

RATIONALE

Ce module essaie de rendre aussi simple que possible la lecture et l'écriture de fichiers correctement et rapidement. La manière la plus correcte de le faire n'est pas toujours évidente (par exemple #83126 https://rt.cpan.org/Public/Bug/Display.html?id=83126), et très souvent, la manière la plus évidente et correcte n'est pas la manière la plus rapide et correcte. Ce module cache toutes ces complications derrière une interface intuitive et simple.

DÉPENDANCES

Ce module a une dépendance optionnelle à PerlIO::utf8_strict. L'installation de celle-ci rendra les E/S encodées en UTF-8 significativement plus rapides, mais ne devrait pas affecter autrement le fonctionnement de ce module. Cela pourrait changer en une dépendance à Unicode::UTF8 lié dans le futur.

VOIR AUSSI

  • Path::Tiny

    Une abstraction minimaliste gérant non seulement les E/S mais aussi les chemins.

  • IO::All

    Une tentative d'exposer autant de fonctionnalités liées aux E/S que possible via une seule API.

  • File::Slurp

    Ceci est un module d'engloutissement de fichiers de génération précédente. Il présente un certain nombre de problèmes, comme décrit ici http://blogs.perl.org/users/leon_timmermans/2015/08/fileslurp-is-broken-and-wrong.html.

  • File::Slurper::Tiny

    C'était ma tentative précédente de créer un meilleur module d'engloutissement de fichiers. C'est principalement (mais pas entièrement) un remplacement direct pour File::Slurp, ce qui est à la fois une fonctionnalité (conversion facile) et un bug (problèmes d'interface).
