DESCRIPTIO

N

Si un système de fichiers prend en charge le partage du stockage physique entre plusieurs fichiers, cette opération ioctl(2) peut être utilisée pour faire apparaître certaines des données du fichier src_fd dans le fichier dest_fd en partageant le stockage sous-jacent si les données des fichiers sont identiques (« déduplication »). Les deux fichiers doivent se trouver dans le même système de fichiers. Cela réduit la consommation de stockage en permettant au système de fichiers de stocker une seule copie partagée des données. Si une écriture doit avoir lieu dans une région partagée, le système de fichiers doit s'assurer que les modifications restent privées pour le fichier en cours d'écriture. Ce comportement est couramment appelé « copie sur écriture »

.

Cette ioctl effectue l'opération « comparer et partager si identique » sur jusqu'à src_length octets du descripteur de fichier src_fd à l'offset src_offset. Cette information est transmise dans une structure de la forme suivante

: 


struct file_dedupe_range {
    __u64 src_offset;
    __u64 src_length;
    __u16 dest_count;
    __u16 reserved1;
    __u32 reserved2;
    struct file_dedupe_range_info info[0];
}
;

La déduplication est atomique par rapport aux écritures concurrentes, de sorte qu'aucune n'a besoin d'être prise pour obtenir une copie dédupliquée

cohérente.

Les champs reserved1 et reserved2 doivent être à

zéro.

Les destinations de l'opération de déduplication sont transmises dans le tableau à la fin de la structure. Le nombre de destinations est donné dans dest_count, et les informations sur les destinations sont transmises sous la forme suivante

: 


struct file_dedupe_range_info {
    __s64 dest_fd;
    __u64 dest_offset;
    __u64 bytes_deduped;
    __s32 status;
    __u32 reserved;
}
;

Chaque opération de déduplication cible src_length octets dans le descripteur de fichier dest_fd à l'offset dest_offset. Le champ reserved doit être à zéro. Pendant l'appel, src_fd doit être ouvert en lecture et dest_fd doit être ouvert en écriture. La taille combinée de la struct file_dedupe_range et du tableau de struct file_dedupe_range_info ne doit pas dépasser la taille de page du système. La taille maximale de src_length dépend du système de fichiers et est généralement de 16 Mio. Cette limite sera imposée silencieusement par le système de fichiers. Par convention, le stockage utilisé par src_fd est mappé dans dest_fd et le contenu précédent dans dest_fd est

libéré.

Lors de l'achèvement réussi de cette ioctl, le nombre d'octets dédupliqués avec succès est renvoyé dans bytes_deduped et un code de statut pour l'opération de déduplication est renvoyé dans status. Si même un seul octet de la plage ne correspond pas, la requête d'opération de déduplication sera ignorée et status sera défini à FILE_DEDUPE_RANGE_DIFFERS. Le code de statut est défini à FILE_DEDUPE_RANGE_SAME en cas de succès, un code d'erreur négatif en cas d'erreur, ou FILE_DEDUPE_RANGE_DIFFERS si

les données ne co
rrespondent pas.
