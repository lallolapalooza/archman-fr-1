NOM

File::MimeInfo::Magic - Déterminer le type de fichier avec des données magiques

SYNOPSIS

use File::MimeInfo::Magic;
my $mime_type = mimetype($file);

DESCRIPTION

Ce module hérite de File::MimeInfo, il est transparent pour ses fonctions mais ajoute la prise en charge du fichier magic de freedesktop.

Les données magiques sont hachées lors de leur première utilisation. Si vous souhaitez forcer le hachage plus tôt, utilisez la fonction rehash().

EXPORT

La méthode "mimetype" est exportée par défaut. Les méthodes "magic", "inodetype", "globs" et "describe" peuvent être exportées sur demande.

MÉTHODES

Voir également File::MimeInfo pour les méthodes héritées.

mimetype($file)
Retourne une chaîne de type MIME pour $file, retourne `undef` en cas d'échec.

Cette méthode combine inodetype(), globs() et magic().

Les règles magiques avec une priorité de 80 et supérieure sont vérifiées avant l'appel à globs(), toutes les autres règles magiques après.

Si cela ne fonctionne pas, le fichier est lu et le type MIME devient par défaut 'text/plain' ou 'application/octet-stream' si les dix premiers caractères du fichier correspondent à des caractères de contrôle ASCII (espaces exclus). Si le fichier n'existe pas ou n'est pas lisible, "undef" est retourné.

Si $file est une référence d'objet, seules "magic" et la méthode par défaut sont utilisées. Voir ci-dessous pour plus de détails.

magic($file)
Retourne une chaîne de type MIME pour $file basée sur les règles magiques, retourne `undef` en cas d'échec.

$file peut être une référence d'objet, dans ce cas, il est censé avoir une méthode seek() et une méthode read(). Cela vous permet, par exemple, de déterminer le type MIME de données en mémoire en utilisant IO::Scalar.

Soyez conscient que lorsque vous utilisez un descripteur de fichier ou un objet "IO::", vous devez définir vous-même le mode binaire ":utf8" si nécessaire.

rehash()
Ré-hache les fichiers de données. Les informations glob et magic sont pré-analysées lorsque cette méthode est appelée.

Si vous souhaitez contourner le système XDG basedir, vous pouvez spécifier vos répertoires de base de données en définissant @File::MimeInfo::DIRS. Mais il est normalement préférable de modifier les variables d'environnement XDG basedir.

"default"
"describe"
"extensions"
"globs"
"inodetype"
Ces routines sont importées depuis File::MimeInfo.

VOIR AUSSI

File::MimeInfo

LIMITATIONS

Seules les tailles de mots de 1, 2 ou 4 sont prises en charge. Toute autre taille de mot est ignorée et provoquera un avertissement.
