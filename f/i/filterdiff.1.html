DESCRIPTIO

N

Vous pouvez utiliser filterdiff pour obtenir un patch qui s'applique aux fichiers correspondant au motif générique de shell MOTIF à partir d'une plus grande collection de patches. Par exemple, pour voir les patches dans patch-2.4.3.gz qui s'appliquent à tous les fichiers nommés lp.c

: 
filterdiff -z
-i '*/lp.c' p
atch-2.4.3.gz

Si ni l'option -i ni -x n'est donnée, -i '*' est supposée. De cette manière, filterdiff peut être utilisé pour nettoyer un fichier diff existant, en supprimant les lignes redondantes du début (par ex. le texte du corps du courriel) ou entre les morceaux (par ex. dans les diffs CVS). Pour extraire des données de patch pures, utilisez une commande comme celle-ci

: 
filterdiff messa
ge-with-diff-in-
the-body > patch

Notez que l'interprétation du motif générique de shell ne considère pas les barres obliques ou les points comme spéciaux (en d'autres termes, aucun drapeau n'est donné à fnmatch). C'est afin que « */basename »-type de motifs puissent être donnés sans limiter le nombre de composants de

chemin.

Vous pouvez utiliser à la fois les

diffs au format unifié et au form
at contexte avec ce programme.

OPTION

S

-i MOTIF, --include=MOTI

F
Inclure uniquement les fichiers correspondant au MOTIF. Toutes les autres lignes de l'entrée sont
supprimées.

-I FICHIER, --include-from-file=FICHIE

R
Inclure uniquement les fichiers correspondant à un motif listé dans le FICHIER, un motif par ligne. Toutes les autres lignes de l'entrée sont
supprimées.

-x MOTIF, --exclude=MOTI

F
Exclure les fichiers correspondant au MOTIF. Toutes les autres lignes de l'entrée sont
affichées.

-X FICHIER, --exclude-from-file=FICHIE

R
Exclure les fichiers correspondant à un motif listé dans le FICHIER, un motif par ligne. Toutes les autres lignes de l'entrée sont
affichées.

-p n, --strip-match=

n
Lors de la correspondance, ignorer les premiers n composants du
chemin.

-# PLAGE, --hunks=PLAG

E
Inclure uniquement les morceaux (hunks) dans la PLAGE spécifiée. Les morceaux sont numérotés à partir de 1, et la plage est une liste de nombres ou d'étendues « premier-dernier » séparés par des virgules, éventuellement précédée d'un modificateur 'x' qui inverse toute la plage ; soit le premier soit le dernier de l'étendue peut être omis pour indiquer aucune limite dans cette
direction.

--lines=PLAG

E
Inclure uniquement les morceaux qui contiennent des lignes du fichier original qui se trouvent dans la PLAGE spécifiée. Les lignes sont numérotées à partir de 1, et la plage est une liste de nombres ou d'étendues « premier-dernier » séparés par des virgules, éventuellement précédée d'un modificateur 'x' qui inverse toute la plage ; soit le premier soit le dernier de l'étendue peut être omis pour indiquer aucune limite dans cette
direction.

-F=PLAGE, --files=PLAG

E
Inclure uniquement les fichiers indiqués par la PLAGE spécifiée. Les fichiers sont numérotés à partir de 1 dans l'ordre où ils apparaissent dans l'entrée de patch, et la plage est une liste de nombres ou d'étendues « premier-dernier » séparés par des virgules, éventuellement précédée d'un modificateur 'x' qui inverse toute la plage ; soit le premier soit le dernier de l'étendue peut être omis pour indiquer aucune limite dans cette
direction.

--annotat

e
Annoter chaque morceau avec le nom de fichier et le numéro de
morceau.

--format=unified|contex

t
Utiliser le format de sortie
spécifié.

--strip=

n
Supprimer les premiers n composants des chemins dans la
sortie.

--addprefix=PRÉFIX

E
Préfixer les chemins dans la sortie par le PRÉFIXE. Cela remplacera tout paramètre individuel spécifié avec les options --addoldprefix ou --addnewprefix
.

--addoldprefix=PRÉFIX

E
Préfixer les chemins des fichiers anciens ou originaux dans la sortie par le PRÉFIXE
.

--addnewprefix=PRÉFIX

E
Préfixer les chemins des fichiers mis à jour ou nouveaux dans la sortie par le PRÉFIXE
.

--as-numbered-lines=before|afte

r
Au lieu d'un fragment de patch, afficher les lignes des morceaux sélectionnés avec le numéro de ligne du fichier avant (ou après) l'application du patch, suivi d'un caractère TAB et de deux-points, au début de chaque ligne. Chaque morceau sauf le premier aura une ligne composée de « ... » avant
lui.

--remove-timestamp

s
Ne pas inclure les horodatages de fichier dans la
sortie.

-v, --verbos

e
Toujours afficher les lignes non-diff dans la sortie. Par défaut, les lignes non-diff ne sont affichées que lors de l'exclusion d'un motif de nom de
fichier.

--clea

n
Toujours supprimer toutes les lignes non-diff de la sortie. Même lors de l'exclusion d'un motif de nom de
fichier.

-z, --decompres

s
Décompresser les fichiers avec les extensions .gz et .
bz2.

--hel

p
Afficher un court message
d'utilisation.

--versio

n
Afficher le numéro de version de
filterdiff.

--lis

t
Se comporter comme lsdiff(1) à la
place.

--gre

p
Se comporter comme grepdiff(1)
à la
place.

EXEMPLE

S

Pour voir tous les morceaux de patch qui affectent les cinq premières lignes d'un fichier C

: 
filterdiff -i
'*.c' --lin
es=-5 < patch

Pour voir le premier morceau de chaque fichier patch, utilisez

: 
filterdi
ff -#1 p
atchfile

Pour voir les patches modifiant un fichier ChangeLog dans un sous-répertoire, utilisez

: 
filterdi
ff -p1 C
hangelog

Pour voir les patches complets de chaque patch qui modifie la ligne 1 du fichier original, utilisez

: 
filterdiff --lines=1 patchf
ile | lsdiff | \ xargs -
rn1 filterdiff patchfile -i

Pour voir tous les morceaux sauf le premier d'un patch particulier, vous pourriez utiliser

: 
filterdiff -p
1 -i file.c -
#2- foo-patch

Si vous avez une liste très spécifique de morceaux dans un patch que vous voulez voir, listez-les

: 
filterdiff
-#1,2,5-8
,10,12,27-

Pour voir les lignes des fichiers qui seraient patchés telles qu'elles apparaîtront après l'application du patch, utilisez

: 
filterdiff --as-
numbered-lines=
after patch.file

Vous pouvez voir le même contexte avant l'application du patch avec

: 
filterdiff --as-
numbered-lines=b
efore patch.file

Filterdiff peut aussi être utilisé pour convertir entre les diffs au format unifié et au format contexte

: 
filterdiff
-v --format
=unified c
ontext.diff
