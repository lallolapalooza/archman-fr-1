NOM

File::IconTheme - Trouver des répertoires d'icônes

VERSION

version 0.09

SYNOPIS

use File::IconTheme qw(xdg_icon_theme_search_dirs);
print join "\n", xdg_icon_theme_search_dirs;

DESCRIPTION

Ce module peut être utilisé pour trouver des répertoires comme spécifié par la spécification de thème d'icônes de Freedesktop.org. Actuellement, seule une partie minime (mais très utile) de la spécification est implémentée.

Si vous souhaitez **stocker** un thème d'icônes, utilisez le répertoire retourné par :

use File::BaseDir qw(data_dirs);
print scalar data_dirs('icons');

FONCTIONS

Peut être exporté sur demande.

xdg_icon_theme_search_dirs

my @dirs = xdg_icon_theme_search_dir;

Retourne une liste des répertoires de base des thèmes d'icônes.

CONFIGURATION ET ENVIRONNEMENT

$XDG_DATA_HOME, $XDG_DATA_DIRS

VOIR AUSSI

http://standards.freedesktop.org/icon-theme-spec/
