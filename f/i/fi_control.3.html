NOM

fi_control - Effectuer une opération sur une ressource fabric.

SYNTAXE

#include <rdma/fabric.h>
int fi_control(struct fid *fid, int command, void *arg);
int fi_alias(struct fid *fid, struct fid **alias_fid, uint64_t flags);
int fi_get_val(struct fid *fid, int name, void *val);
int fi_set_val(struct fid *fid, int name, void *val);

ARGUMENTS

fid
Ressource fabric
commande
Opération à effectuer
arg
Argument optionnel pour la commande

DESCRIPTION

L'opération fi_control est utilisée pour effectuer une ou plusieurs opérations sur une ressource fabric. Conceptuellement, fi_control est similaire à la routine POSIX fcntl. Le comportement exact de l'utilisation de fi_control dépend de la ressource fabric sur laquelle l'opération est effectuée, de la commande spécifiée et des arguments fournis pour la commande. Pour des détails spécifiques, consultez les pages d'aide spécifiques aux ressources fabric mentionnées ci-dessous.

fi_alias, fi_get_val et fi_set_val sont des wrappers pour fi_control avec les commandes FI_ALIAS, FI_GET_VAL et FI_SET_VAL, respectivement. fi_alias crée un alias de la ressource fabric spécifiée. fi_get_val lit la valeur du paramètre nommé associé à la ressource fabric, tandis que fi_set_val met à jour cette valeur. Les noms de paramètres disponibles dépendent du type de la ressource fabric et du fournisseur utilisé. Les fournisseurs peuvent définir des noms spécifiques au fournisseur dans les fichiers d'en-tête d'extension du fournisseur (’rdma/fi_ext_*.h’). Veuillez vous référer aux pages man du fournisseur pour plus de détails.
