NOM

File::Type - déterminer le type de fichier en utilisant des signatures magiques

SYNOPSIS

my $ft = File::Type->new();

# lire les données du fichier dans $data, puis
my $type_from_data = $ft->checktype_contents($data);

# alternativement, vérifier un fichier sur disque
my $type_from_file = $ft->checktype_filename($file);
# méthode pratique pour vérifier soit un fichier, soit des données
my $type_1 = $ft->mime_type($file);
my $type_2 = $ft->mime_type($data);

DESCRIPTION

File::Type utilise des nombres magiques (généralement au début d'un fichier) pour déterminer le type MIME de ce fichier.

File::Type peut utiliser soit un nom de fichier, soit le contenu d'un fichier, pour déterminer le type d'un fichier.

MÉTHODES

new

Retourne un nouvel objet File::Type.

mime_type($argument)

Prend soit des données, soit un nom de fichier, détermine de quoi il s'agit et transmet l'argument à la méthode correspondante ci-dessous. Si l'argument est un répertoire, retourne undef.

checktype_filename($filename)

Ouvre $filename (si possible ; sinon, retourne undef) et retourne le type MIME du fichier.

checktype_contents($data)

Fait correspondre $data aux critères de la base de données magique et retourne le type MIME du fichier.

À FAIRE

* Ajouter des critères de correspondance magiques supplémentaires

BOGUES

Aucun connu.

NOTES

Certaines définitions magiques dans le fichier mime-magic utilisé pour la création de ce module varient par rapport à celles d'autres applications (par exemple, image/x-png au lieu de image/png).

VOIR AUSSI

File::MMagic et File::MimeInfo remplissent la même fonction, mais présentent un certain nombre de problèmes qui ont conduit à la création de ce module.

File::MMagic intègre une copie de la base de données magique et utilise un descripteur de fichier DATA, ce qui pose des problèmes lors de l'exécution sous mod_perl.

File::MimeInfo utilise un fichier magique externe et s'appuie sur les extensions de fichiers plutôt que sur les signatures magiques pour déterminer le type MIME.

Par conséquent, File::Type utilise un module et un script séparés pour créer le code au cœur de ce module, ce qui signifie qu'il n'est pas nécessaire d'inclure une base de données magique et qu'il est sûr de l'exécuter sous mod_perl.

File::Type::Builder, qui génère le code au cœur de ce module.

REMERCIEMENTS

File::Type est construit à partir d'un fichier mime-magic de cleancode.org. L'original se trouve à http://cleancode.org/cgi-bin/viewcvs.cgi/email/mime-magic.mime?rev=1.1.1.1.
