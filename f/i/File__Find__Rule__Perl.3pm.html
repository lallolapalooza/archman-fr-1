NOM

File::Find::Rule::Perl - Règles communes pour la recherche d'éléments Perl

SYNOPSIS

use File::Find::Rule       ();
use File::Find::Rule::Perl ();

# Trouver tous les fichiers Perl de moins de 10 Ko
my @fichiers = File::Find::Rule->perl_file
                            ->size('<10Ki')
                            ->in('dir');

# Localiser tous les modules que PAUSE indexera
my @mod = File::Find::Rule->no_index
                          ->perl_module
                          ->in('Ma-Distribution');

DESCRIPTION

J'écris beaucoup de choses qui manipulent des fichiers Perl. Et cela m'a toujours ennuyé que la recherche de « fichiers Perl » nécessite un modèle File::Find::Rule modérément complexe.

File::Find::Rule::Perl fournit des méthodes pour trouver divers types de fichiers liés à Perl, ou pour reproduire des requêtes de recherche exécutées sur une distribution dans diverses parties de l'écosystème CPAN.

MÉTHODES

perl_module

La règle « perl_module » localise les modules Perl. C'est-à-dire les fichiers nommés « *.pm ».

Cette règle est équivalente à "->"file->name( '*.pm' )> et est incluse principalement par souci de complétude.

perl_test

La règle « perl_test » localise les scripts de test Perl. C'est-à-dire les fichiers nommés « *.t ».

Cette règle est équivalente à "->"file->name( '*.t' )> et est incluse principalement par souci de complétude.

perl_installer

La règle « perl_installer » localise les installateurs de distribution Perl. C'est-à-dire qu'elle localise les fichiers « Makefile.PL » et « Build.PL ».

perl_script

La règle « perl_script » localise les scripts Perl.

Il s'agit de tout fichier se terminant par .pl, ou de tout fichier sans extension ayant une ligne « hash-bang » Perl.

perl_file

La règle « perl_file » localise tous les fichiers contenant du code Perl.

Cela inclut tous les fichiers correspondant aux règles « perl_module », « perl_test », « perl_installer » et « perl_script » ci-dessus.

no_index

# Fournir les règles directement
$rule->no_index(
    directory => [ 'inc', 't', 'examples' ],
    file      => [ 'Foo.pm', 'lib/Foo.pm' ],
);

# Fournir un fichier META.yml à utiliser
$rule->no_index( 'META.yml' );

# Fournir un répertoire racine de distribution pour rechercher un fichier META.yml
$rule->no_index( 'Ma-Distribution' );

# Récupérer automatiquement un fichier META.yml du répertoire cible
$rule->no_index->in( 'Ma-Distribution' );

La méthode « no_index » applique un ensemble de règles conformément à la section no_index d'un fichier « META.yml ».
