DESCRIPTIO

N

L'interface de filtre de CUPS fournit une méthode standard pour ajouter la prise en charge de nouveaux types de documents ou de nouvelles imprimantes à CUPS. Chaque filtre est capable de convertir un ou plusieurs formats d'entrée vers un autre format qui peut soit être imprimé directement, soit être transmis à un autre filtre pour l'amener à un format

imprimable.

Les filtres DOIVENT être capables de lire depuis un nom de fichier sur la ligne de commande ou depuis l'entrée standard, en copiant l'entrée standard vers un fichier temporaire si le format de fichier l'exige. Toute sortie DOIT être envoyée vers la sortie standard. Les filtres NE DOIVENT PAS tenter de communiquer directement avec l'imprimante, d'autres processus ou d'autres

services.

Le nom de la commande (argv[0]) est défini sur le nom de l'imprimante de destination mais est également disponible dans la variable d'environnement PRINTER

.

OPTION

S

Les options sont transmises dans argv[5] et sont encodées à partir des attributs IPP correspondants utilisés lors de la soumission du travail. Utilisez la fonction cupsParseOptions() pour charger les options dans un tableau cups_option_t et la fonction cupsGetOption() pour obtenir la valeur d'un attribut spécifique. Faites attention à rechercher les alias courants des attributs IPP, tels que « landscape » pour l'attribut IPP « orientation-requested »

.

Les options transmises sur la ligne de commande n'incluent généralement pas les choix par défaut du fichier PPD de l'imprimante. Utilisez les fonctions ppdMarkDefaults() et cupsMarkOptions() de la bibliothèque CUPS pour appliquer les options aux valeurs par défaut du PPD et faire correspondre les attributs IPP aux options PPD correspondantes. Utilisez ppdFindMarkedChoice() pour obtenir le choix sélectionné par l'utilisateur pour une option PPD. Par exemple, un filtre pourrait utiliser le code suivant pour déterminer la valeur actuelle de l'option PPD Duple

x : 
    ppd_file_t *ppd = ppdOpenFile(getenv("PPD"));
    cups_option_t *options = NULL;
    int num_options = cupsParseOptions(argv[5], 0, &options);
    ppdMarkDefaults(ppd);
    cupsMarkOptions(ppd, num_options, options);
    ppd_choice_t *choice = ppdFindMarkedChoice(ppd, "Duplex")
;

Les filtres raster devraient utiliser les choix d'options définis via l'en-tête de page raster, car ils

reflètent les options en vigueur pour une page donnée. Les options spécifiées sur la ligne de commande d
éterminent les valeurs par défaut pour l'ensemble du travail, qui peuvent être remplacées page par page.

NOTE

S

Les pilotes et les backends d'imprimante de CUPS sont dépréciés et ne seront plus pris en charge dans une prochaine version fonctionnelle de CUPS. Les imprimantes qui ne prennent pas en charge IPP peuvent être prises en charge à l'aide d'applications telles que ippeveprint

er(1).

Les filtres de CUPS ne sont pas destinés à être exécutés directement par l'utilisateur. En plus des problèmes liés à la compatibilité avec les scripts d'interface System V (argv[0] est le nom de l'imprimante), les filtres de CUPS s'attendent également à des variables d'environnement et des descripteurs de fichiers spécifiques, et s'exécutent généralement dans une session utilisateur qui (sur macOS) comporte des restrictions supplémentaires affectant son exécution. À moins que vous ne soyez un développeur et ne sachiez ce que vous faites, veuillez ne pas exécuter les filtres directement. Utilisez plutôt le programme cupsfilter(8) pour utiliser les filtres appropriés afin

d'effectuer les conver
sions dont vous avez besoin.
