DESCRIPTIO

N

Ce module nécessite Perl 5.005 ou une version

supérieure.

Ce module prend le module existant "File::Glob" comme point de départ et l'étend pour permettre de dériver de nouveaux noms de fichiers à partir des fichiers correspondant à "File::Gl

ob".

Cela peut être utile lors de l'exécution d'opérations par lots sur plusieurs fichiers qui ont à la fois un nom de fichier d'entrée et un nom de fichier de sortie et dont le fichier de sortie peut être dérivé du nom de fichier d'entrée. Des exemples d'opérations où cela peut être utile incluent le renommage de fichiers, la copie de fichiers et la compression de

fichiers.

En

coulisses

Pour aider à expliquer ce que "File::GlobMapper" fait, considérez le code que vous écririez si vous vouliez renommer tous les fichiers du répertoire courant qui se terminent par ".tar.gz" en ".tgz". Disons que ces fichiers sont dans le répertoire

courant 
alpha.tar.gz
beta.tar.gz
gamma.tar.
gz

et qu'ils doivent être renommés

ainsi 
alpha.tgz
beta.tgz
gamma.
tgz

Voici une implémentation possible d'un script pour effectuer le renommage (les cas d'erreur ont été

omis) 
foreach my $old ( glob "*.tar.gz" )
{
    my $new = $old;
    $new =~ s#(.*)\.tar\.gz$#$1.tgz# ;
    rename $old => $new
        or die "Cannot rename '$old' to '$new': $!\n;
}

Remarquez qu'un motif de glob de fichier "*.tar.gz" a été utilisé pour faire correspondre les fichiers ".tar.gz", puis une expression régulière assez similaire a été utilisée dans la substitution pour permettre la création du nouveau nom de

fichier.

Étant donné que le glob de fichier est juste une expression régulière simplifiée et qu'il a déjà fait une grande partie du travail difficile pour faire correspondre les noms de fichiers, ne serait-il pas pratique de pouvoir utiliser les motifs du glob de fichier pour générer le nouveau nom de fichier

?

Eh bien, c'est exactement ce que "File::GlobMappe

r" fait.

Voici le même extrait de code réécrit en utilisant "globmap

" 
for my $pair (globmap '<*.tar.gz>' => '<#1.tgz>' )
{
    my ($from, $to) = @$pair;
    rename $from => $to
        or die "Cannot rename '$old' to '$new': $!\n;
}

Alors, comment cela fonctionne-t-il

?

En coulisses, la fonction "globmap" effectue une combinaison d'un glob de fichier pour faire correspondre les noms de fichiers existants suivi d'une substitution pour créer les nouveaux noms de

fichiers.

Remarquez comment les deux paramètres de "globmap" sont des chaînes délimitées par <>. Cela est fait pour les faire ressembler davantage à des globs de fichier - c'est juste du sucre syntaxique, mais cela peut être pratique lorsque vous voulez que les chaînes soient visuellement distinctives. Les <> englobants sont facultatifs, vous n'avez donc pas à les utiliser - en fait, la première chose que globmap fera est de supprimer ces délimiteurs s'ils sont

présents.

Le premier paramètre de "globmap", "*.tar.gz", est un Glob de Fichier d'Entrée. Une fois le "< ... >" englobant supprimé, il est passé (plus ou moins) inchangé à "File::Glob" pour effectuer une correspondance de

fichier.

Ensuite, le glob de fichier "*.tar.gz" est transformé en coulisses en une expression régulière Perl complète, avec l'étape supplémentaire d'envelopper chaque séquence de métacaractère générique transformée entre

parenthèses.

Dans ce cas, le glob de fichier d'entrée "*.tar.gz" sera transformé en cette expression régulière

Perl 
([^/]*)\.tar\.
gz

L'enveloppement entre parenthèses permet aux parties génériques du Glob de Fichier d'Entrée d'être référencées par le deuxième paramètre de "globmap", "#1.tgz", le Glob de Fichier de Sortie. Ce paramètre fonctionne exactement comme la partie de remplacement d'une commande de substitution. La différence est que la syntaxe "#1" est utilisée pour référencer les sous-motifs correspondus dans le glob de fichier d'entrée, plutôt que la syntaxe $1 utilisée avec les expressions régulières Perl. Dans ce cas, "#1" est utilisé pour faire référence au texte correspondant par le "*" dans le Glob de Fichier d'Entrée. Cela rend plus facile l'utilisation de ce module lorsque les paramètres de "globmap" sont tapés à la ligne de

commande.

L'étape finale consiste à passer chaque nom de fichier correspondant au glob de fichier "*.tar.gz" à travers l'expression régulière Perl dérivée à tour de rôle et à développer le glob de fichier de sortie en l'utilisant.

.

Le résultat final de tout cela est une liste de paires de noms de fichiers. Par défaut, c'est ce qui est renvoyé par "globmap". Dans cet exemple, la structure de données renvoyée ressemblera à

ceci 
( ['alpha.tar.gz' => 'alpha.tgz'],
  ['beta.tar.gz'  => 'beta.tgz' ],
  ['gamma.tar.gz' => 'gamma.tgz']
)

Chaque paire est une référence de tableau avec deux éléments - à savoir le nom de fichier source, que "File::Glob" a fait correspondre, et un nom de fichier cible qui est dérivé du nom de fich

ier s
ource.

EXEMPLE

S

Un script de

renommage

Voici un simple script "rename" qui utilise "globmap"" pour déterminer les noms de fichiers source et de destination.

use File::GlobMapper qw(globmap) ;
use File::Copy;
die "rename: Usage rename 'from' 'to'\n"
    unless @ARGV == 2 ;
my $fromGlob = shift @ARGV;
my $toGlob   = shift @ARGV;
my $pairs = globmap($fromGlob, $toGlob)
    or die $File::GlobMapper::Error;
for my $pair (@$pairs)
{
    my ($from, $to) = @$pair;
    move $from => $to ;
}

Voici un exemple qui renomme tous les fichiers c en cpp.

$ rename '*.c' '#1.cpp'

Quelques exemples de globmaps

Ci-dessous quelques exemples de globmaps

Pour copier tous vos fichiers .c dans un répertoire de sauvegarde

'</my/home/*.c>'    '</my/backup/#1.c>'

Si vous voulez compresser tous

'</my/home/*.[ch]>'    '<*.gz>'

Pour décompresser

'</my/home/*.[ch].gz>'    '</my/home/#1.#2>'
