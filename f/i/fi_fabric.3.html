NOM

fi_fabric - Opérations réseau de fabric

fi_fabric / fi_close
Ouvrir / fermer un réseau de fabric
fi_tostr / fi_tostr_r
Convertir les attributs, drapeaux et capacités de fabric en chaîne imprimable

SYNOPSIS

#include <rdma/fabric.h>
int fi_fabric(struct fi_fabric_attr *attr,
    struct fid_fabric **fabric, void *context);
int fi_close(struct fid *fabric);
char * fi_tostr(const void *data, enum fi_type datatype);
char * fi_tostr_r(char *buf, size_t len, const void *data,
    enum fi_type datatype);

ARGUMENTS

attr
Attributs du fabric à ouvrir.
fabric
Réseau de fabric
context
Contexte spécifié par l'utilisateur associé à l'objet ouvert. Ce contexte est renvoyé dans le cadre de tout événement asynchrone associé.
buf
Tampon de sortie dans lequel écrire la chaîne.
len
Taille en octets de la mémoire référencée par buf.
data
Données d'entrée à convertir en chaîne. Le format des données est déterminé par le paramètre datatype.
datatype
Indique les données à convertir en chaîne imprimable.

DESCRIPTION

Un identifiant de fabric est utilisé pour référencer les ressources de fabric ouvertes et les objets liés à la bibliothèque.

Le réseau de fabric représente un ensemble de ressources matérielles et logicielles qui accèdent à un réseau physique ou virtuel unique. Tous les ports réseau d'un système qui peuvent communiquer entre eux via leurs réseaux attachés appartiennent au même fabric. Un réseau de fabric partage des adresses réseau et peut s'étendre sur plusieurs fournisseurs. Une application doit ouvrir un réseau de fabric avant d'allouer d'autres ressources réseau, telles que des points de terminaison de communication.

fi_fabric

Ouvre un fournisseur de réseau de fabric. Les attributs du fournisseur de fabric sont spécifiés via l'appel d'ouverture et peuvent être obtenus en appelant fi_getinfo.

fi_close

L'appel fi_close est utilisé pour libérer toutes les ressources associées à un objet fabric. Tous les éléments associés au fabric ouvert doivent être libérés avant d'appeler fi_close.

fi_tostr / fi_tostr_r

Convertit les attributs d'interface de fabric, les capacités, les drapeaux et les valeurs d'enum en une chaîne imprimable. Le paramètre data accepte un pointeur vers l'attribut ou la/les valeur(s) à afficher, le paramètre datatype indiquant le type de données référencé par le paramètre data. Les valeurs valides pour le datatype sont listées ci-dessous, avec le datatype ou le champ correspondant.

FI_TYPE_EP_CAP
champ struct fi_info::ep_cap
FI_TYPE_OP_FLAGS

FI_TYPE_ADDR_FORMAT

fi_tostr() renverra un pointeur vers un tampon interne de libfabric qui ne doit pas être modifié et qui sera écrasé la prochaine fois que fi_tostr() est invoqué. fi_tostr() n'est pas sûr pour les threads.

La fonction fi_tostr_r() est une version réentrante et sûre pour les threads de fi_tostr(). Elle écrit la chaîne dans un tampon fourni par l'appelant. fi_tostr_r() renvoie le début du tampon de l'appelant.

NOTES

Les ressources suivantes sont associées aux domaines de fabric : domaines d'accès, points de terminaison passifs et files d'événements CM.

ATTRIBUTS DE FABRIC

La structure fi_fabric_attr définit l'ensemble des attributs associés à un fabric et à un fournisseur de fabric.

struct fi_fabric_attr {
    struct fid_fabric *fabric;
    char              *name;
    char              *prov_name;
    uint32_t          prov_version;
    uint32_t          api_version;
};

fabric

En entrée de fi_getinfo, un utilisateur peut définir ceci sur une instance de fabric ouverte pour restreindre la sortie au fabric donné. En sortie de fi_getinfo, si aucun fabric n'a été spécifié, mais que l'utilisateur a une instance ouverte du fabric nommé, celui-ci référencera la première instance ouverte. Si aucune instance n'a été ouverte, ce champ sera NULL.

NAME

fi_fabric - Fabric interface query

SYNOPSIS

#include <rdma/fabric.h>

struct fi_fabric *fi_fabric_open(struct fid_fabric *fabric, const char *name, void *context);

int fi_getinfo(int version, const char *name, const char *mask, uint64_t flags, struct fi_info **info);

void fi_freeinfo(struct fi_info *info);

DESCRIPTION

The fabric interface query functions are used to discover the capabilities of the underlying fabric and providers. They allow applications to query information about available fabric resources and select appropriate providers and features.

fi_getinfo is the primary function used to discover fabric information. It takes a version number, an optional fabric name, an optional provider name mask, and flags to specify desired capabilities. It returns a linked list of fi_info structures, each describing a fabric provider and its supported features.

The name parameter can be used to specify a particular fabric or set of providers. If name is NULL, all available providers will be returned.

The mask parameter is used to filter the returned information based on desired capabilities. For example, a mask can be used to request providers that support specific network protocols or communication modes.

The flags parameter allows for further customization of the query, such as specifying whether to return information about domain attributes or endpoint capabilities.

fi_freeinfo is used to free the memory allocated for the fi_info structures returned by fi_getinfo.

fi_fabric_open is used to open a fabric based on the information obtained from fi_getinfo. It returns a struct fi_fabric pointer which represents the opened fabric instance.

ARGUMENTS

version
The version of the fabric interface to use. This should be set to FI_VERSION(1, X) where X is the desired minor version.
name
The name of the fabric to query. If NULL, all available fabrics will be queried.
mask
A bitmask of flags used to filter the results. See fi_getinfo(3) for a list of available flags.
flags
Additional flags to control the query behavior. See fi_getinfo(3) for a list of available flags.
info
A pointer to a pointer to a fi_info structure. On successful return, this will point to the head of a linked list of available fabric information.
fabric
A pointer to a fid_fabric structure obtained from a previous call to fi_fabric_open.
context
User-specified context associated with the fabric instance.

FABRIC ATTRIBUTES

The following members of the fi_info structure are relevant for fabric attributes:

name

A fabric identifier.

prov_name - Provider Name

The name of the underlying fabric provider.

To request an utility provider layered over a specific core provider, both the provider names have to be specified using “;” as delimiter.

e.g. “ofi_rxm;verbs” or “verbs;ofi_rxm”

For debugging and administrative purposes, environment variables can be used to control which fabric providers will be registered with libfabric. Specifying “FI_PROVIDER=foo,bar” will allow any providers with the names “foo” or “bar” to be registered. Similarly, specifying “FI_PROVIDER=^foo,bar” will prevent any providers with the names “foo” or “bar” from being registered. Providers which are not registered will not appear in fi_getinfo results. Applications which need a specific set of providers should implement their own filtering of fi_getinfo’s results rather than relying on these environment variables in a production setting.

prov_version - Provider Version

Version information for the fabric provider, in a major.minor format. The use of the FI_MAJOR() and FI_MINOR() version macros may be used to extract the major and minor version data. See fi_version(3).

In case of an utility provider layered over a core provider, the version would always refer to that of the utility provider.

api_version

The interface version requested by the application. This value corresponds to the version parameter passed into fi_getinfo(3).

NOTES

The results returned by fi_getinfo should only be considered valid if the application does not close any fabric instances from another thread while fi_getinfo is being processed.

RETURN VALUE

Returns FI_SUCCESS on success. On error, a negative value corresponding to fabric errno is returned. Fabric errno values are defined in rdma/fi_errno.h.

ERRORS

The following are some of the common fabric errors that can be returned by fi_getinfo:

-FI_ENODATA
No matching fabric providers found.
-FI_EINVAL
Invalid arguments were provided.
-FI_EVERSION
The requested API version is not supported.
