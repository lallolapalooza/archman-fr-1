File::Spec::Functions(3perl) Guide du programmeur Perl File::Spec::Functions(3perl)

NOM

File::Spec::Functions - effectuer des opérations sur les noms de fichiers de manière portable

SYNOPIS

use File::Spec::Functions;
my $x = catfile('a', 'b');

DESCRIPTION

Ce module exporte des fonctions pratiques pour toutes les méthodes de classe fournies par File::Spec.

Pour une référence des fonctions disponibles, veuillez consulter File::Spec::Unix, qui contient l'ensemble complet, et qui est hérité par les modules pour d'autres plateformes. Pour plus d'informations, veuillez voir File::Spec::Mac, File::Spec::OS2, File::Spec::Win32, ou File::Spec::VMS.

Exports

Les fonctions suivantes sont exportées par défaut.

canonpath
catdir
catfile
curdir
rootdir
updir
no_upwards
file_name_is_absolute
path

Les fonctions suivantes sont exportées uniquement sur demande.

devnull
tmpdir
splitpath
splitdir
catpath
abs2rel
rel2abs
case_tolerant

Toutes les fonctions peuvent être importées en utilisant la balise ":ALL".
