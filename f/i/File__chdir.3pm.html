DESCRIPTIO

N

La fonction chdir() de Perl a le problème fâcheux d'être très, très, très globale. Si une partie de votre programme appelle chdir() ou si une bibliothèque que vous utilisez appelle chdir(), cela change le répertoire de travail courant pour le *programme

entier*.

C'est

nul.

File::chdir vous donne une alternative, $CWD et @CWD. Ces deux variables combinent toute la puissance de chdir(), File:

:Spec
et Cwd.

$CW

D

Utilisez la variable $CWD au lieu de chdir() et

Cwd. 
use File::chdir;
$CWD = $dir;  # comme chdir($dir) !
print $CWD;   # affiche le répertoire de travail
courant

Elle peut être localisée, et elle fait la bonne

chose. 
$CWD = "/foo";      # c'est /foo ici dehors.
{
    local $CWD = "/bar";  # /bar ici dedans
}
# toujours /foo ici dehors
!

$CWD retourne toujours le chemin absolu dans la forme native pour le système

d'exploitation.

$CWD et chdir() normal fonctio

nnent très b
ien ensemble.

@CW

D

@CWD représente le répertoire de travail courant sous forme de tableau, chaque répertoire du chemin est un élément du tableau. Cela rend souvent le répertoire plus facile à manipuler, et vous n'avez pas à vous battre avec "File::Spec->splitpath" et "File::Spec->catdir" pour faire du code

portable. 
# Similaire à chdir("/usr/local/src/perl")
@CWD = qw(usr local src perl)
;

pop, push, shift, unshift et splice fonctionnent tous. pop et push sont probablement les plus

utiles. 
pop @CWD;                 # équivalent à chdir(File::Spec->updir)
push @CWD, 'some_dir'     # équivalent à chdir('some_dir'
)

@CWD et $CWD fonctionnent bien

ensemble.

*NOTE* En raison d'un bug de perl, vous ne pouvez pas localiser @CWD. Voir "CAVEATS" pour un

e solution de
contournement.

EXEMPLE

S

(Nous omettons "use File::chdir" de ces exemples par

concision)

Voici $CWD au lieu de chdir()

: 
$CWD = 'foo';           #
chdir('foo')

et maintenant au lieu de

Cwd. 
print $CWD;             # use Cwd;  print Cwd::
abs_path

vous pouvez même faire du style zsh "cd foo

bar" 
$CWD = '/usr/local/foo';
$CWD =~
s/usr/var/;

si vous voulez localiser cela, assurez-vous de mettre les parenthèses au bon

endroit 
{
    (local $CWD) =~ s/usr/var/;
    ...
}

C'est surtout utile pour écrire des sous-routines polies qui ne laissent pas le programme dans un répertoire étrange

: 
sub foo {
    local $CWD = 'some/other/dir';
    ...faites votre travail...
}

ce qui est beaucoup plus simple que l'équivalent

: 
sub foo {
    use Cwd;
    my $orig_dir = Cwd::getcwd;
    chdir('some/other/dir');
    ...faites votre travail...
    chdir($orig_dir);
}

@CWD est pratique quand vous voulez commencer à monter et descendre la hiérarchie des répertoires de manière multiplateforme sans avoir à utiliser File::

Spec. 
pop @CWD;                   # chdir(File::Spec->updir);
push @CWD, 'some', 'dir'    # chdir(File::Spec->catdir(qw(some dir)))
;

Vous pouvez facilement changer votre répertoire parent

: 
# chdir de /some/dir/ba
r/moo vers /some/dir/fo
o/moo $CWD[-2] = 'foo';

MISES EN

GARDE

"local @CWD" ne fonctionne

pas.

"local @CWD" ne localisera pas @CWD. C'est un bug de Perl, vous ne pouvez pas localiser des tableaux liés (tied). Comme solution de contournement, localiser $CWD localisera effectivement @CWD

. 
{
    local $CWD;
    pop @CWD;
    ...
}

L'affectation à @CWD appelle chdir() pour chaque

élément 
@CWD = qw/a b c
d/;

En interne, Perl vide @CWD et affecte chaque élément à tour de rôle. Ainsi, le code ci-dessus fera ceci

: 
chdir 'a';
chdir 'a/b';
chdir 'a/b/c';
chdir
'a/b/c/d';

Généralement, évitez d'affecter à @CWD et utilisez simplem

ent push et p
op à la place.

Les volumes ne sont pas

gérés

Il n'y a actuellement

aucun moyen de chang
er le volume courant
via File::chdir.

NOTE

S

$CWD retourne le répertoire courant en utilisant les séparateurs de chemin natifs, c'est-à-dire "\" sur Win32. Cela garantit que $CWD se comparera correctement avec les répertoires créés à l'aide de File::Spec. Par exemple

: 
my $working_dir = File::Spec->catdir( $CWD, "foo" );
$CWD = $working_dir;
doing_stuff_might_chdir();
is( $CWD, $working_dir, "back to original working_dir?" )
;

Supprimer le dernier élément de @CWD agira comme un pop. Supprimer un élément du milieu lèvera une

exception. 
delete @CWD[-1]; # OK
delete @CWD[-2]; #
Meurt

Que devrait faire %CWD ? Quelque chose avec les volumes

?

erra\Half Life ? $CWD{C} = '\\Pr
ogram Files\\Sierra\\Half Life';
