NOM

File::MimeInfo - Déterminer le type de fichier à partir de son nom

SYNOPSIS

use File::MimeInfo;
my $mime_type = mimetype($file);
my $mime_type2 = mimetype('test.png');

DESCRIPTION

Ce module peut être utilisé pour déterminer le type mime d'un fichier. Il tente d'implémenter la spécification freedesktop pour une base de données MIME partagée.

Pour ce module, shared-mime-info-spec 0.13 a été utilisé.

Ce paquet n'utilise que le fichier globs. Aucune vérification réelle de magic n'est utilisée. Le paquet File::MimeInfo::Magic est fourni pour le typage par magic.

Si vous souhaitez déterminer le mimetype de données dans un tampon mémoire, vous devriez utiliser File::MimeInfo::Magic en combinaison avec IO::Scalar.

Ce module charge les différents fichiers de données au besoin. Si vous souhaitez hacher les données plus tôt, voir les « rehash » méthodes ci-dessous.

EXPORT

La méthode « mimetype » est exportée par défaut. Les méthodes « inodetype », « globs », « extensions », « describe », « mimetype_canon » et « mimetype_isa » peuvent être exportées sur demande.

MÉTHODES

new()
Constructeur simple permettant l'utilisation orientée objet de ce module. Si vous souhaitez l'utiliser, incluez le paquet avec « use File::MimeInfo (); » pour éviter d'importer la sous-routine mimetype().
mimetype($file)
Renvoie une chaîne mimetype pour $file, renvoie undef en cas d'échec.

Cette méthode regroupe « inodetype » et « globs ».

Si ces méthodes échouent, le fichier est lu et le mimetype par défaut est 'text/plain' ou 'application/octet-stream' lorsque les dix premiers caractères du fichier correspondent à des caractères de contrôle ascii (espaces blancs exclus). Si le fichier n'existe pas ou n'est pas lisible, « undef » est renvoyé.

inodetype($file)
Renvoie un mimetype dans l'espace de noms 'inode' ou undef lorsque le fichier est en fait un fichier normal.
globs($file)
Renvoie une chaîne mimetype pour $file basée sur le nom de fichier et les extensions de nom de fichier. Renvoie undef en cas d'échec. Le fichier n'a pas besoin d'exister.

Le comportement en contexte liste (wantarray) est non spécifié et sera modifié dans les futures versions.

default($file)
Cette méthode détermine si un fichier est binaire ou texte en regardant les premiers octets du fichier. Utilisée pour choisir entre « text/plain » et « application/octet-stream » si toutes les autres méthodes ont échoué.

La spécification indique que nous devrions vérifier les caractères de contrôle ascii et laisser passer les caractères de poids fort pour permettre utf8. Nous essayons d'être plus intelligents en utilisant le support utf8 de perl.

extensions($mimetype)
En contexte liste, renvoie la liste des extensions de nom de fichier qui correspondent au mimetype donné. En contexte scalaire, renvoie la première extension qui est trouvée dans la base de données pour ce mimetype.
« describe($mimetype, $lang) »
Renvoie une description de ce mimetype telle que fournie par la base de données mime info. Vous pouvez spécifier une langue avec le paramètre optionnel $lang, qui devrait être le code de langue à deux lettres utilisé dans les fichiers xml. Vous pouvez aussi définir la variable globale $File::MimeInfo::LANG pour spécifier une langue.

Cette méthode renvoie undef lorsque aucun fichier xml n'a été trouvé (c'est-à-dire que le mimetype n'existe pas dans la base de données). Elle renvoie une chaîne vide lorsque le fichier xml ne contient pas de description dans la langue que vous avez spécifiée.

Actuellement, aucun vrai parsing xml n'est effectué, il fait confiance au fait que les fichiers xml sont bien formatés.

mimetype_canon($mimetype)
Renvoie le mimetype canonique pour un mimetype donné. Les mimetypes obsolètes sont généralement aliasés à leurs variantes canoniques. Cette méthode ne vérifie que les alias, elle ne vérifie pas si le mimetype existe.

Utilisez cette méthode comme filtre lorsque vous prenez un mimetype en entrée.

mimetype_isa($mimetype)
« mimetype_isa($mimetype, $mimetype) »
Lorsqu'un seul argument est donné, cette méthode renvoie une liste avec les mimetypes qui sont des classes parentes pour ce mimetype.

Lorsque deux arguments sont donnés, renvoie vrai si le second mimetype est une classe parente du premier.

Cette méthode vérifie la table des sous-classes et applique quelques règles pour les sous-classes implicites.

has_mimeinfo_database()
Vérifie s'il y a des fichiers de base de données mimeinfo disponibles ; renvoie 1 en cas de succès. Si vous n'avez pas le paquet shared-mime-info installé ou pas dans le PATH ou @File::MimeInfo::DIRS ne contient pas de répertoires de base de données, vous n'obtiendrez pas la réponse de succès.

Nouveau dans la version 0.30.

rehash()
Recalcule les fichiers de données. Les informations glob sont pré-analysées lorsque cette méthode est appelée.

Si vous souhaitez contourner le système basedir XDG, vous pouvez spécifier vos répertoires de base de données en définissant @File::MimeInfo::DIRS. Mais normalement, il est préférable de modifier les variables d'environnement basedir XDG.

rehash_aliases()
Recalcule les fichiers mime/aliases .
rehash_subclasses()
Recalcule les fichiers mime/subclasses .

DIAGNOSTICS

Ce module lance une exception lorsqu'il ne peut trouver aucun fichier de données, lorsqu'il ne peut pas ouvrir un fichier de données trouvé pour lecture ou lorsqu'une sous-routine ne reçoit pas assez d'arguments. Dans le premier cas, vous n'avez soit pas la base de données mime info freedesktop installée, soit vos variables d'environnement pointent vers les mauvais emplacements ; dans le second cas, vous avez la base de données installée, mais elle est cassée (la base de données mime info devrait logiquement être lisible par tous).

À FAIRE

Créer une option pour utiliser un mécanisme de cache afin de réduire le temps d'initialisation.

Faire en sorte que describe() utilise un vrai parsing xml ?

LIMITATIONS

Les versions de Perl antérieures à 5.8.0 n'ont pas la couche IO ':utf8', ainsi pour la méthode par défaut et pour la lecture des fichiers xml, utf8 n'est pas pris en charge pour ces versions.

Comme il n'est pas possible de distinguer entre les types d'encodage (utf8, latin1, latin2 etc.) de manière simple, seul utf8 est pris en charge (car la spécification le recommande).

Ce module ne vérifie pas encore les attributs étendus pour un mimetype. Les correctifs pour cela sont très bienvenus.

Ce module utilise la base de données shared mime info de FreeDesktop.org. Sur votre bureau linux, elle est généralement pré-installée, donc ce n'est pas un problème. Sur votre serveur, vous pouvez installer le paquet shared-mime-info via apt ou dnf ou apk ou quoi que ce soit.

Pour installer sur macOS, vous pouvez l'installer comme ceci :

brew install shared-mime-info
