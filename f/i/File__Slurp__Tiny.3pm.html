NOM

File::Slurp::Tiny - Un "slurper" de fichier simple, sain et efficace [DÉCONSEILLÉ]

VERSION

version 0.004

SYNOPIS

use File::Slurp::Tiny 'read_file';
my $content = read_file($filename);

DÉCONSEILLÉ

Ce module est déconseillé au profit de File::Slurper. Bien qu'il ait été une expérience utile, il s'est avéré à la fois trop similaire à File::Slurp (contenant toujours la plupart des fonctionnalités problématiques de l'interface de File::Slurp) et pourtant pas assez similaire pour être un véritable remplacement direct.

Les bugs seront toujours corrigés, mais de nouvelles fonctionnalités ne seront probablement pas ajoutées.

DESCRIPTION

Ce module fournit des fonctions pour "slurper" (lire l'intégralité d'un fichier en mémoire) et "spewer" (écrire un contenu dans un fichier) de manière rapide et correcte. Toutes les fonctions sont exportées sur demande.

FONCTIONS

read_file($filename, %options)

Lit le fichier $filename dans un scalaire. Par défaut, elle retourne ce scalaire. Peut éventuellement prendre les arguments nommés suivants :

  • binmode

    Définit les couches pour lire le fichier. La valeur par défaut sera quelque chose de raisonnable sur votre plateforme.

  • buf_ref

    Passe une référence à un scalaire dans lequel lire le fichier, au lieu de le retourner par valeur. Cela présente des avantages en termes de performance.

  • scalar_ref

    Si réglé sur vrai, "read_file" retournera une référence à un scalaire contenant le contenu du fichier.

read_lines($filename, %options)

Lit le fichier $filename dans une liste/un tableau. Par défaut, elle retourne cette liste. Peut éventuellement prendre les arguments nommés suivants :

  • binmode

    Définit les couches pour lire le fichier. La valeur par défaut sera quelque chose de raisonnable sur votre plateforme.

  • array_ref

    Passe une référence à un tableau dans lequel lire les lignes, au lieu de les retourner par valeur. Cela présente des avantages en termes de performance.

  • chomp

    "Chompe" (supprime les sauts de ligne finaux) les lignes.

write_file($filename, $content, %options)

Ouvre $filename et écrit $content dedans. Peut éventuellement prendre l'argument nommé suivant :

•
binmode

Définit les couches pour écrire le fichier. La valeur par défaut sera quelque chose de raisonnable sur votre plateforme.

read_dir($dirname, %options)

Ouvre "dirname" et retourne toutes les entrées sauf "." et "..". Peut éventuellement prendre l'argument nommé suivant :

•
prefix

Cela ajoutera $dir au début des entrées.
