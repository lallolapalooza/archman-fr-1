FIDO_DEV_GET_ASSERT(3) Manuel des fonctions de bibliothèque FIDO_DEV_GET_ASSERT(3)

NOM

fido_dev_get_assert — obtient une assertion d'un appareil FIDO2

SYNTAXE

#include <fido.h>

int
fido_dev_get_assert(fido_dev_t *dev, fido_assert_t *assert, const char *pin);

DESCRIPTION

La fonction fido_dev_get_assert() demande à l'appareil FIDO2 représenté par dev une assertion selon les paramètres suivants définis dans assert :

  • identifiant du fournisseur de services ;
  • hash des données client ;
  • liste des identifiants de credential autorisés ;
  • attributs de présence utilisateur et de vérification utilisateur.

Voir fido_assert_set_authdata(3) pour savoir comment ces valeurs sont définies.

Si un code PIN n'est pas nécessaire pour authentifier la requête auprès de dev, alors pin peut être NULL. Sinon pin doit pointer vers une chaîne UTF-8 terminée par un caractère nul.

Après un appel réussi à fido_dev_get_assert(), les fonctions fido_assert_count(3), fido_assert_user_display_name(3), fido_assert_user_icon(3), fido_assert_user_name(3), fido_assert_authdata_ptr(3), fido_assert_user_id_ptr(3), fido_assert_sig_ptr(3), et fido_assert_sigcount(3) peuvent être invoquées sur assert pour récupérer les divers attributs de l'assertion générée.

Notez que fido_dev_get_assert() est synchrone et bloquera si nécessaire.

VALEURS DE RETOUR

Les codes d'erreur retournés par fido_dev_get_assert() sont définis dans <fido/err.h>. En cas de succès, FIDO_OK est retourné.

VOIR AUSSI

fido_assert_new(3), fido_assert_set_authdata(3)
