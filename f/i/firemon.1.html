NOM

firemon - Programme de surveillance des processus démarrés dans un bac à sable Firejail.

SYNTAXE

firemon [OPTIONS] [PID]

DESCRIPTION

Firemon surveille les programmes démarrés dans un bac à sable Firejail. Sans spécification de PID, tous les processus démarrés par Firejail sont surveillés. Les descendants de ces processus sont également surveillés. Sur les systèmes Grsecurity, seul l'utilisateur root peut exécuter ce programme.

OPTIONS

--apparmor
Affiche l'état de confinement AppArmor pour chaque bac à sable.
--arp
Affiche la table ARP pour chaque bac à sable.
--caps
Affiche la configuration des capacités pour chaque bac à sable.
--cpu
Affiche l'affinité CPU pour chaque bac à sable.
--debug
Affiche les messages de débogage.
-?, --help
Affiche les options et quitte.
--list
Liste tous les bacs à sable.
--name=nom
Affiche les informations uniquement sur le bac à sable nommé.
--netstats
Surveille les statistiques réseau pour les bacs à sable créant un nouvel espace réseau.
--route
Affiche la table de routage pour chaque bac à sable.
--seccomp
Affiche la configuration seccomp pour chaque bac à sable.
--top
Surveille les bacs à sable les plus gourmands en CPU. Cette commande est similaire à la commande UNIX top régulière, mais elle s'applique uniquement aux bacs à sable.
--tree
Affiche un arbre de tous les processus en bac à sable.
--version
Affiche la version du programme et quitte.
--wrap
Active le retour à la ligne dans les terminaux. Par défaut, les lignes sont coupées.
--x11
Affiche le numéro de l'affichage X11.

Le format pour chaque entrée de bac à sable listée est le suivant :

PID:UTILISATEUR:Nom du bac à sable:Commande

Ci-dessous sont listés les champs (colonnes) disponibles dans diverses commandes firemon par ordre alphabétique :

Commande
Commande utilisée pour démarrer le bac à sable.
CPU%
Utilisation du CPU, la part du temps CPU écoulé depuis la dernière mise à jour de l'écran par le bac à sable.
PID
Identifiant unique du processus pour la tâche contrôlant le bac à sable.
Prcs
Nombre de processus en cours d'exécution dans le bac à sable, y compris le processus contrôlant.
RES
Taille de la mémoire résidente (KiB), mémoire physique non échangée du bac à sable. C'est la somme des valeurs RES pour tous les processus en cours d'exécution dans le bac à sable.
Nom du bac à sable
Le nom du bac à sable, le cas échéant.
SHR
Taille de la mémoire partagée (KiB), elle reflète la mémoire partagée avec d'autres processus. C'est la somme des valeurs SHR pour tous les processus en cours d'exécution dans le bac à sable, y compris le processus contrôlant.
Temps de fonctionnement
Temps de fonctionnement du bac à sable au format heures:minutes:secondes.
UTILISATEUR
Le propriétaire du bac à sable.
