NOM

File::HomeDir::Darwin::Cocoa - Trouver votre répertoire personnel et d'autres répertoires sur Darwin (OS X)

DESCRIPTION

Ce module fournit des implémentations spécifiques à Darwin pour déterminer les répertoires utilisateur courants en utilisant l'API Cocoa via Mac::SystemDirectory. En utilisation normale, ce module sera toujours utilisé via File::HomeDir.

Théoriquement, cela devrait retourner les mêmes chemins que les deux autres pilotes Darwin.

Comme ce module nécessite Mac::SystemDirectory, si le module n'est pas installé, File::HomeDir se rabattra sur File::HomeDir::Darwin.

SYNOPSIS

use File::HomeDir;

# Trouver les répertoires pour l'utilisateur courant
$home    = File::HomeDir->my_home;      # /Users/mylogin
$desktop = File::HomeDir->my_desktop;   # /Users/mylogin/Desktop
$docs    = File::HomeDir->my_documents; # /Users/mylogin/Documents
$music   = File::HomeDir->my_music;     # /Users/mylogin/Music
$pics    = File::HomeDir->my_pictures;  # /Users/mylogin/Pictures
$videos  = File::HomeDir->my_videos;    # /Users/mylogin/Movies
$data    = File::HomeDir->my_data;      # /Users/mylogin/Library/Application Support
