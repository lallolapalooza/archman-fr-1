NOM

findMSB - trouver l'indice du bit le plus significatif défini à 1 dans un entier

DÉCLARATION

genIType findMSB(genIType valeur);

genIType findMSB(genUType valeur);

PARAMÈTRES

valeur

Spécifie la valeur dont les bits doivent être analysés.

DESCRIPTION

findMSB renvoie le numéro du bit le plus significatif qui est défini à 1 dans la représentation binaire de valeur. Pour les entiers positifs, le résultat sera le numéro du bit le plus significatif qui est défini à 1. Pour les entiers négatifs, le résultat sera le numéro du bit le plus significatif qui est défini à 0. Pour une valeur de zéro ou moins un, -1 sera renvoyé.
