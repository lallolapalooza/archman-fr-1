NOM

File::MimeInfo::Applications - Trouver des programmes pour ouvrir un fichier par mimetype

SYNOPSIS

use File::MimeInfo::Magic;
use File::MimeInfo::Applications;
my $file = '/foo/bar';
my $mimetype = mimetype($file)
  || die "Impossible de trouver le mimetype pour $file\n";
my ($default, @other) = mime_applications($mimetype);
if (defined $default) {
  $default->system($file)
}
else {
  # demander à l'utilisateur avec un choix parmi @others
  # ...
}

DESCRIPTION

Ce module essaie de trouver des applications qui peuvent ouvrir des fichiers avec un certain mimetype. Ceci est fait de la manière suggérée par la spécification des entrées de bureau de freedesktop. Ce module est destiné à être compatible avec les gestionnaires de fichiers et autres applications qui implémentent cette spécification.

Ce module dépend de l'installation de File::DesktopEntry.

Pour utiliser ce module efficacement, vous devez disposer du paquet desktop-file-utils de freedesktop et exécuter update-desktop-database après l'installation de nouveaux fichiers .desktop. Voir http://www.freedesktop.org/wiki/Software/desktop-file-utils.

Au moment de la rédaction, ce module est compatible avec la manière dont Nautilus (Gnome) et Thunar (XFCE) gèrent les applications pour les mimetypes. Je comprends que KDE travaille toujours à l'implémentation des spécifications mime de freedesktop mais suivra. Au minimum, toutes les applications perl utilisant ce module utilisent les mêmes valeurs par défaut.

EXPORT

Toutes les méthodes sont exportées par défaut.

MÉTHODES

mime_applications(MIMETYPE)
Retourne un tableau d'objets File::DesktopEntry. Le premier est l'application par défaut pour ce mimetype, les autres sont des applications qui déclarent pouvoir gérer ce mimetype.

Si le premier résultat est indéfini, il n'y a pas d'application par défaut et il est de bonne pratique de demander à l'utilisateur quelle application il souhaite utiliser.

mime_applications_all(MIMETYPE)
Similaire à mime_applications() mais prend également en compte les applications qui peuvent ouvrir des mimetypes dont MIMETYPE hérite. Les mimetypes parents renseignent sur le format des données, tous les codes héritent de text/plain par exemple.
"mime_applications_set_default(MIMETYPE, APPLICATION)"
Enregistre une application par défaut pour ce mimetype. Cette action affectera d'autres applications utilisant le même mécanisme pour trouver une application par défaut.

APPLICATION peut être soit un objet File::DesktopEntry soit le nom de base d'un fichier .desktop.

"mime_applications_set_custom(MIMETYPE, COMMAND)"
Enregistre une commande shell personnalisée comme application par défaut. Génère un fichier DesktopEntry à la volée et appelle "mime_applications_set_custom". Retourne l'objet DesktopEntry.

Aucune vérification n'est effectuée sur COMMAND. Il devrait cependant contenir au moins un mot.

NOTES

Ce module recherche les fichiers d'associations dans l'ordre spécifié dans la version 1.0 de la spécification des applications MIME. Il tentera également une recherche de dernier recours dans le fichier hérité $XDG_DATA_HOME/applications/defaults.list. Dans tous les cas, il écrira uniquement dans le fichier de configuration par défaut recommandé par utilisateur situé à $XDG_CONFIG_HOME/mimeapps.list.
