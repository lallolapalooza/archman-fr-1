DESCRIPTIO

N

Ce module peut être utilisé pour trouver des répertoires et des fichiers tels que spécifiés par la spécification de répertoire de base de Freedesktop.org. Cette spécification donne un mécanisme pour localiser des répertoires pour la configuration, les données d'application et les données de cache. Il est suggéré que les applications de bureau, par exemple pour les plateformes GNOME, KDE ou Xfce, suivent cette disposition. Cependant, la même disposition peut tout aussi bien être utilisée pour des applications non

graphiques.

Ce module a été dérivé de File::

MimeInfo.

Ce module suit la v

ersion 0.6 de la spé
cification BaseDir.

FONCTION

S

Aucune de celles-ci n'est exportée par défaut, mais toutes les fonctions peuvent être exportées sur demande. De plus, les groupes ":lookup" et ":vars" sont définis. Le groupe ":vars" contient toutes les routines avec un préfixe "xdg_". Le groupe ":lookup" contient les routines pour localiser les fichiers et les

répertoires.

data_hom

e 
my $path = data_home(@path);
my $path = $bd->data_home(@path)
;

Prend une liste d'éléments de chemin de fichier et retourne un nouveau chemin en les ajoutant au répertoire de données personnelles. Le nouveau chemin n'a pas besoin d'exister. Utilisez ceci lors de l'écriture de données d'application spécifiques à

l'utilisateur.

Exemple

: 
# data_home est : /home/USER/.local/share
$path = $bd->data_home('Foo', 'Bar', 'Baz');
# retourne : /home/USER/.local/share/Foo/Bar/B

s

my $dir = data_dirs(@path);
my $dir = $bd->data_dirs(@path);
my @dirs = data_dirs(@path);

;

Recherche les répertoires spécifiés par @path dans le répertoire de données personnelles et les autres répertoires de données. Retourne une liste (éventuellement vide) de répertoir

PLATEFORMES

NON-UNIX

L'utilisation de File::Spec garantit que tous les chemins sont retournés dans leurs formats natifs quelle que soit la plateforme. Sur Windows, ce module utilisera les variables d'environnement natives, plutôt que la valeur par défaut sur UNIX (qui est traditionnellement $HOME

).

Veuillez noter que la spécification cible les plateformes Unix uniquement et n'aura q

u'une pertinence limitée sur d'autres plateformes. Tout comportement dépendant de la p
lateforme dans ce module doit être considéré comme une extension de la spécification.

COMPATIBILITÉ

DESCENDANTE

Les méthodes xdg_data_files() et xdg_config_files() sont exportées pour la compatibilité descendante avec la version 0.02. Elles sont identiques à data_files() et config_files() respectivement mais sans le comportement

"wanta
rray".
