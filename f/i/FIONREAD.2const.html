FIONREAD(2const) FIONREAD(2const)

NOM

FIONREAD, TIOCINQ, TIOCOUTQ, TCFLSH, TIOCSERGETLSR - nombre d'octets dans les tampons et vidage

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <asm/termbits.h>  /* Définition des constantes */
#include <sys/ioctl.h>
int ioctl(int fd, FIONREAD, int *argp);
int ioctl(int fd, TIOCINQ, int *argp);
int ioctl(int fd, TIOCOUTQ, int *argp);
int ioctl(int fd, TCFLSH, int arg);
int ioctl(int fd, TIOCSERGETLSR, int *argp);

DESCRIPTION

FIONREAD
Obtenir le nombre d'octets dans le tampon d'entrée.
TIOCINQ
Identique à FIONREAD.
TIOCOUTQ
Obtenir le nombre d'octets dans le tampon de sortie.
TCFLSH
Équivalent à tcflush(fd, arg).
Voir tcflush(3) pour les valeurs d'argument TCIFLUSH, TCOFLUSH, TCIOFLUSH.
TIOCSERGETLSR
Obtenir le registre d'état de la ligne. Le registre d'état a le bit TIOCSER_TEMT défini lorsque le tampon de sortie est vide et que l'émetteur matériel est également physiquement vide.
Pas nécessairement pris en charge par tous les pilotes de terminal série.
tcdrain(3) n'attend pas et renvoie immédiatement lorsque le bit TIOCSER_TEMT est défini.

VALEUR DE RETOUR

En cas de succès, 0 est renvoyé. En cas d'erreur, -1 est renvoyé et errno est défini pour indiquer l'erreur.

VOIR AUSSI

ioctl(2), ioctl_tty(2), tcflush(3), termios(3)
