FIREWALLD.ICMPTYPE(5) firewalld.icmptype FIREWALLD.ICMPTYPE(5)

NOM

firewalld.icmptype - Fichiers de configuration des types ICMP de firewalld

SYNTAXE

/etc/firewalld/icmptypes/type_icmp.xml
/usr/lib/firewalld/icmptypes/type_icmp.xml

DESCRIPTION

Un fichier de configuration de type ICMP de firewalld fournit des informations sur un type de protocole ICMP (Internet Control Message Protocol) pour firewalld.

Cet exemple de fichier de configuration montre la structure d'un fichier de configuration de type ICMP :

<?xml version="1.0" encoding="utf-8"?>
<icmptype>
  <short>Mon type ICMP</short>
  <description>description</description>
  <destination ipv4="oui" ipv6="oui"/>
</icmptype>

OPTIONS

La configuration peut contenir ces balises et attributs. Certains sont obligatoires, d'autres optionnels.

icmptype

La balise de début et de fin obligatoire icmptype définit le type ICMP. Cette balise ne peut être utilisée qu'une seule fois dans un fichier de configuration de type ICMP. Cette balise a des attributs optionnels :

version="chaîne"

Pour donner une version au type ICMP.

short

Est une balise de début et de fin optionnelle et est utilisée pour donner un nom plus lisible à un type ICMP.

description

Est une balise de début et de fin optionnelle pour avoir une description d'un type ICMP.

destination

Est une balise optionnelle à élément vide et ne peut être utilisée qu'une seule fois. La balise destination spécifie si une entrée de type ICMP est disponible pour IPv4 et/ou IPv6. La valeur par défaut est IPv4 et IPv6, où cette balise peut être omise.

ipv4="booléen"

Décrit si le type ICMP est disponible pour IPv4.

ipv6="booléen"

Décrit si le type ICMP est disponible pour IPv6.
