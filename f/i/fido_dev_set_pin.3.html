fido_dev_set_pin(3)

Paquet: libfido2

Licences: BSD-2-Clause

FIDO_DEV_SET_PIN(3) Manuel des fonctions de bibliothèque FIDO_DEV_SET_PIN(3)

NOM

fido_dev_set_pin, fido_dev_get_retry_count, fido_dev_get_uv_retry_count, fido_dev_reset — Fonctions de gestion de périphérique FIDO2

SYNOPIS

#include <fido.h>

int
fido_dev_set_pin(fido_dev_t *dev, const char *pin, const char *oldpin);

int
fido_dev_get_retry_count(fido_dev_t *dev, int *retries);

int
fido_dev_get_uv_retry_count(fido_dev_t *dev, int *retries);

int
fido_dev_reset(fido_dev_t *dev);

DESCRIPTION

La fonction fido_dev_set_pin() définit le code PIN du périphérique dev sur pin, où pin est une chaîne UTF-8 se terminant par un caractère nul. Si oldpin n'est pas NULL, le code PIN du périphérique est changé de oldpin à pin, où pin et oldpin sont des chaînes UTF-8 se terminant par un caractère nul.

La fonction fido_dev_get_retry_count() remplit retries avec le nombre de tentatives de code PIN restantes sur dev avant le blocage, où retries est un pointeur accessible.

La fonction fido_dev_get_uv_retry_count() remplit retries avec le nombre de tentatives UV intégrées restantes sur dev avant que l'UV intégrée ne soit désactivée, où retries est un pointeur accessible.

La fonction fido_dev_reset() effectue une réinitialisation sur dev, réinitialisant le code PIN du périphérique et effaçant les identifiants stockés sur le périphérique.

Veuillez noter que fido_dev_set_pin(), fido_dev_get_retry_count(), fido_dev_get_uv_retry_count(), et fido_dev_reset() sont synchrones et bloqueront si nécessaire.

VALEUR DE RETOUR

Les codes d'erreur retournés par fido_dev_set_pin(), fido_dev_get_retry_count(), fido_dev_get_uv_retry_count(), et fido_dev_reset() sont définis dans <fido/err.h>. En cas de succès, FIDO_OK est retourné.

VOIR AUSSI

fido_cbor_info_uv_attempts(3)

CAVEATS

Concernant fido_dev_reset(), le flux utilisateur réel pour effectuer une réinitialisation est hors de portée de la spécification FIDO2, et peut donc varier en fonction de l'authentificateur. Les authentificateurs Yubico retourneront FIDO_ERR_NOT_ALLOWED si une réinitialisation est émise plus de 5 secondes après la mise sous tension, et FIDO_ERR_ACTION_TIMEOUT si l'utilisateur ne parvient pas à confirmer la réinitialisation en touchant la clé dans les 30 secondes.
