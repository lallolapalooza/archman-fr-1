DESCRIPTIO

N

fd est une alternative simple, rapide et conviviale à find(

1).

Par défaut, fd utilise des expressions rationnelles pour le motif. Cependant, cela peut être modifié pour utiliser des motifs glob simples avec l'option

'--glob'.

Par défaut, fd exclura les fichiers et répertoires cachés, ainsi que tout fichier correspondant aux règles gitignore ou aux règles d'ignorance dans les fichiers .ignore ou .

fdignore.

Si vous souhaitez rechercher tous les fichiers dans un répertoire spécifique, vous pouvez utiliser '' ou . comme motif de recherche, pour correspondre à tous les fichiers. Ou vous pouvez utiliser l'option '--search-path' pour spécifier le(s) chemin(s) au lieu du paramètre

positionnel.

Les options peuvent être

données n'importe où s
ur la ligne de commande.

-x, --exec comma

Exécuter command pour chaque résultat de recherche en parallèle (utilisez --threads=1 pour une exécution séquentielle des commandes).

Notez que tous les arguments positionnels suivants sont considérés comme des arguments pour la command - pas pour fd. Il est donc recommandé de placer l'option -x/--exec en dernier. Alternativement, vous pouvez fournir un argument ';' pour terminer la liste d'arguments et continuer avec plus d'options fd. La plupart des shells nécessitent que ';' soit échappé : '\;'. Cette option peut être spécifiée plusieurs fois, auquel cas toutes les commandes sont exécutées pour chaque fichier trouvé, dans l'ordre où elles sont fournies. Dans ce cas, vous devez fournir un argument ';' pour toutes les commandes sauf la

dernière.

Si le parallélisme est activé, l'ordre dans lequel les commandes seront exécutées est non déterministe. Et même avec --threads=1, l'ordre est déterminé par le système d'exploitation et peut ne pas être celui que vous attendez. Il est donc recommandé que vous ne vous fiez à aucun ordre des

résultats.

Avant d'exécuter la commande, les motifs de remplacement (placeholders) dans la commande sont remplacés par les valeurs correspondantes pour le fichier courant. Les mêmes emplacements de remplacement sont utilisés que pour l'option « --format »

Exécuter commande une seule fois, avec tous les résultats de recherche comme arguments.

L'ordre des arguments est non déterministe et ne doit pas être considéré comme

fiable.

Cela utilise les mêmes emplacements de remplacement que « --format » et « --exec », mais au lieu de les développer une fois par invocation de commande, chaque argument contenant un emplacement de remplacement est développé pour chaque fichier d'un lot et passé comme arguments

séparés.

Si aucun emplacement de remplacement n'est présent, un « {} » implicite à la fin est

supposé.

Comme pour --exec, les arguments suivants sont supposés faire partie de commande jusqu'à la fin des arguments de commande ou un argument « ; ». Voir

ci-dessus.

Comme pour --exec, cela peut être utilisé plusieurs fois, auquel cas chaque commande sera exécutée dans l'ordre

donné.

Astuces et

Trucs
•
Si vous ajoutez « .git/ » à votre fichier d'exclusion global ($XDG_CONFIG_HOME/fd/ignore), alors les dossiers « .git » seront ignorés par défaut, même lorsque l'option --hidden est
utilisée.
•
Vous pouvez utiliser un alias de shell ou un script d'encapsulation afin de passer les opt
ions souhaitées à fd par défaut. Par exemple, si vous n'aimez pas le comportement par défa
ut de respecter gitignore, vous pouvez utiliser `alias fd="/usr/bin/fd --no-ignore-vcs"` da
ns votre .bashrc pour créer un alias pour fd qui n'ignore pas les fichiers git par défaut.
