FDATASYNC(3P) Manuel du programmeur POSIX FDATASYNC(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

fdatasync — synchronise les données d'un fichier (REALTIME)

SYNOPIS

#include <unistd.h>
int fdatasync(int fildes);

DESCRIPTION

La fonction fdatasync() force toutes les opérations d'E/S actuellement mises en file d'attente associées au fichier indiqué par le descripteur de fichier fildes à l'état de complétion des E/S synchronisées.

La fonctionnalité est équivalente à fsync() avec le symbole _POSIX_SYNCHRONIZED_IO défini, à l'exception près que toutes les opérations d'E/S doivent être complétées telles que définies pour la complétion d'intégrité des données des E/S synchronisées.

VALEUR DE RETOUR

En cas de succès, la fonction fdatasync() renvoie la valeur 0 ; sinon, la fonction renvoie la valeur -1 et définit la variable errno pour indiquer l'erreur. Si la fonction fdatasync() échoue, il n'est pas garanti que les opérations d'E/S en attente aient été complétées.

ERREURS

La fonction fdatasync() échoue si :

EBADF
L'argument fildes n'est pas un descripteur de fichier valide.
EINVAL
Cette implémentation ne prend pas en charge les E/S synchronisées pour ce fichier.

Dans le cas où l'une des opérations d'E/S mises en file d'attente échoue, fdatasync() renverra les conditions d'erreur définies pour read() et write().

Les sections suivantes sont informatives.

EXEMPLES

Aucun.

UTILISATION PAR L'APPLICATION

Notez que même si le descripteur de fichier n'est pas ouvert en écriture, s'il y a des requêtes d'écriture en attente sur le fichier sous-jacent, ces E/S seront complétées avant le retour de fdatasync().
