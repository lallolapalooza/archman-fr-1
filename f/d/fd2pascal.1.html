NOM

fd2pascal - Convertisseur de fichiers de description de formulaires XForms en programme Pascal

SYNTAXE

fd2pascal [-compensate] [-altformat] [-main] [-callback] nom_fichier

DESCRIPTION

fd2pascal lit un fichier de conception XForms ( .fd ) et génère du code Pascal pour créer le formulaire décrit dans le fichier. Le code Pascal est écrit dans un fichier portant le même nom que le fichier d'entrée, mais avec l'extension .pp. Si un fichier portant ce nom existe déjà, il sera renommé avec l'extension .bak ajoutée.

OPTIONS

fd2pascal a un petit nombre d'options pour contrôler son comportement :

-altformat
Par défaut, un type enregistrement est émis pour la définition du formulaire, avec un champ pour chaque widget (objet) du formulaire. Le format alternatif déclare une variable globale pour le formulaire et pour chaque widget du formulaire.
-compensate
Si cette option est fournie, un appel à fl_adjust_form_size est émis après la création du formulaire.
-callback
Si cette option est fournie, une procédure de rappel (callback) est générée pour chaque widget du formulaire.
-main
Par défaut, une unité est créée qui peut être incluse dans la clause uses d'un programme. Si cette option est spécifiée, un fichier programme est émis à la place.
