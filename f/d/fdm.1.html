DESCRIPTIO

N

Le programme fdm récupère le courrier depuis un serveur POP3 ou IMAP ou depuis stdin et le distribue en fonction d'un ensemble de règles défini dans le fichier de

configuration.

Les options sont les suivantes

:
-a no
m
Traite uniquement le compte spécifié. Cette option peut apparaître plusieurs fois. Le nom du compte peut inclure des caractères génériques du shell pour correspondre à plusieurs
comptes.
-D nom=vale
ur
Cette option définit une macro à utiliser lors de l'analyse du fichier de configuration. Le nom de la macro doit être préfixé par $ ou % pour spécifier une macro de type chaîne ou numérique. Cette option peut apparaître plusieurs
fois.
-f fichierc
onf
Spécifie l'emplacement du fichier de configuration. Par défaut, c'est ~/.fdm.conf, ou /etc/fdm.conf si celui-ci n'existe
pas.
-
h
Utilise la variable d'environnement HOME pour déterminer le répertoire personnel de
l'utilisateur.
-
k
Conserve tout le courrier après distribution, qu'il corresponde ou non à une action de suppression. Notez que les courriers conservés de cette manière seront récupérés à nouveau par fdm s'il est relancé sur le même
compte.
-
l
Journalise via syslog(3) plutôt que vers stder
r.
-
m
Ignore le fichier de verrouillage et s'exécute malgré la présence d'autres instances de fdm
.
-
n
Ne traite aucun compte, vérifie uniquement la syntaxe du fichier de configuration et se
termine.
-
q
Mode silencieux. N'affiche que les
erreurs.
-u utilis
ateur
Spécifie l'utilisateur par défaut pour la distribution. Cela remplace l'option default-user du fichier de
configuration.
-
v
Demande un journal détaillé. Cette option peut être spécifiée plusieurs fois. -vv affichera des informations sur la configuration (utile avec -n). -vvvv duplique tout le trafic entrant et sortant vers et depuis les serveurs distants vers stdout. Cette fonctionnalité est désactivée lorsque l'on utilise l'indicateur -l
.
-x no
m
Exclut le compte nommé. Plusieurs -x peuvent être spécifiés. Comme pour -a, des caractères génériques du shell peuvent être
utilisés.
fetch | poll | cac
he
La commande fetch indique à fdm de récupérer et distribuer les messages. La commande poll interroge les comptes du fichier de configuration et rapporte le nombre de messages pour chacun. cache permet de manipuler les fichiers de cache de fdm : voir l
a secti
on sui
vante.

COMMANDES DE

CACHE

Les commandes de manipulation du cache suivantes sont prises en charge

:
cache add chemin chaî
ne
 
cache remove chemin chaî
ne
Ajoute ou supprime chaîne en tant que clé dans le cache situé au chemi
n.
cache list [chemi
n]
Liste le nombre de clés dans le cache spécifié, ou si chemin est omis, dans tous les caches déclarés dans le fichier de
configuration.
cache dump che
min
Affiche le contenu du cache chemin vers stdout. Chaque clé est imprimée suivie d'un espace et de l'horodatage en temps
Unix.
cache clear che
min
Supprime toutes les clés du cache situé au che
m
in
