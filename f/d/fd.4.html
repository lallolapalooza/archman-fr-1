CONFIGURATIO

N

Les lecteurs de disquettes sont des périphériques de bloc avec le numéro majeur 2. Typiquement, ils appartiennent à root:floppy (c'est-à-dire l'utilisateur root, le groupe floppy) et ont soit le mode 0660 (vérification d'accès via l'appartenance au groupe) soit le mode 0666 (tout le monde a accès). Les numéros mineurs encodent le type de périphérique, le numéro du lecteur et le numéro du contrôleur. Pour chaque type de périphérique (c'est-à-dire la combinaison de la densité et du nombre de pistes), il existe un numéro mineur de base. À ce numéro de base, ajoutez le numéro du lecteur sur son contrôleur et 128 si le lecteur est sur le contrôleur secondaire. Dans les tables de périphériques suivantes, n représente le numéro du

lecteur.

Avertissement : si vous utilisez des formats avec plus de pistes que ce qui est pris en charge par votre lecteur, vous risquez de lui causer des dommages mécaniques. Essayer une fois si plus de pistes que les 40/80 habituels sont prises en charge ne devrait pas l'endommager, mais aucune garantie n'est donnée à ce sujet. Si vous n'êtes pas sûr, ne créez pas d'entrées de périphérique pour ces formats, afin d'en empêcher

l'utilisation.

DESCRIPTIO

N

Les fichiers spéciaux fd accèdent aux lecteurs de disquettes en mode brut. Les appels ioctl(2) suivants sont pris en charge par les périphériques fd

:
FDCLRP
RM
efface les informations sur le support d'un lecteur (géométrie du disque dans le lecteur)
.
FDSETP
RM
définit les informations sur le support d'un lecteur. Ces informations seront perdues lorsque le support est
changé.
FDDEFP
RM
définit les informations sur le support d'un lecteur (géométrie du disque dans le lecteur). Ces informations ne seront pas perdues lorsque le support est changé. Cela désactivera la détection automatique. Afin de réactiver la détection automatique, vous devez émettre un FDCLRPR
M.
FDGETDRVT
YP
renvoie le type d'un lecteur (paramètre nom). Pour les formats qui fonctionnent avec plusieurs types de lecteurs, FDGETDRVTYP renvoie un nom qui est approprié pour le type de lecteur le plus ancien qui prend en charge ce
format.
FDFLU
SH
invalide le cache de tampon pour le lecteur
donné.
FDSETMAXER
RS
définit les seuils d'erreur pour signaler les erreurs, interrompre l'opération, recalibrer, réinitialiser et lire secteur par
secteur.
FDSETMAXER
RS
récupère les seuils d'erreur
actuels.
FDGETDRVT
YP
récupère le nom interne du
lecteur.
FDWERRORC
LR
efface les statistiques d'erreurs
d'écriture.
FDWERRORG
ET
lit les statistiques d'erreurs d'écriture. Celles-ci incluent le nombre total d'erreurs d'écriture, l'emplacement et le disque de la première erreur d'écriture, et l'emplacement et le disque de la dernière erreur d'écriture. Les disques sont identifiés par un numéro de génération qui est incrémenté à (presque) chaque changement de
disque.
FDTWADD
LE
Éteint le moteur du lecteur pendant quelques microsecondes. Cela peut être nécessaire afin d'accéder à un disque dont les secteurs sont trop
rapprochés.
FDSETDRVP
RM
définit divers paramètres du
lecteur.
FDGETDRVP

FDGETDRVST

FDPOLLDRVST

REMARQUE

S

Les différents formats permettent de lire et d'écrire de nombreux types de disques. Cependant, si une disquette est formatée avec un espace inter-secteurs trop petit, les performances peuvent chuter, au point de nécessiter quelques secondes pour accéder à une piste entière. Pour éviter cela, utilisez des formats

entrelacés.

Il n'est pas possible de lire les disquettes formatées avec GCR (group code recording), qui est utilisé par les ordinateurs Apple II et Macintosh (disques de 800k)

.

La lecture des disquettes à secteurs physiques (un trou par secteur

, avec le trou d'index légèrement décalé) n'est pas prise en cha
rge. C'était courant avec les anciennes disquettes de 8 pouces.
