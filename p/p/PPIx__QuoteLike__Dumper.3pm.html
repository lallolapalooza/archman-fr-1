NOM

PPIx::QuoteLike::Dumper - Afficher les résultats de l'analyse des éléments de type quote

SYNOPIS

use PPIx::QuoteLike::Dumper;
PPIx::QuoteLike::Dumper->new( '"foo$bar baz"' )
  ->print();

DESCRIPTION

Cette classe génère une représentation formatée d'un objet PPIx::QuoteLike, ou d'une chaîne qui peut être transformée en un tel objet.

MÉTHODES

Cette classe supporte les méthodes publiques suivantes. Les méthodes non documentées ici sont privées et non supportées dans le sens où l'auteur se réserve le droit de les modifier ou de les supprimer sans préavis.

new

my $dumper = PPIx::QuoteLike::Dumper->new(
    '"foo$bar baz"',
    variables  => 1,
);

Cette méthode statique instancie le dumper. Elle prend la chaîne de caractères ou l'objet PPIx::QuoteLike à dumper comme premier argument. D'autres arguments optionnels peuvent être passés sous forme de paires nom/valeur.

Les arguments optionnels suivants sont reconnus :

encodage nom
Cet argument est l'encodage de l'objet à dumper. Il est transmis à PPIx::QuoteLike new(), sauf si le premier argument était un objet PPIx::QuoteLike, auquel cas il est ignoré.
indentation nombre
Cet argument spécifie le nombre d'espaces supplémentaires à indenter pour chaque niveau de la hiérarchie d'analyse. Ceci est ignoré si l'argument "tokens" est vrai.

La valeur par défaut est 2.

marge nombre
Cet argument est le nombre d'espaces supplémentaires à indenter la hiérarchie d'analyse, en plus de ceux spécifiés par la marge.

La valeur par défaut est 0.

version_perl Booléen
Cet argument spécifie si les versions de Perl introduites et supprimées sont incluses ou non dans la sortie.

La valeur par défaut est 0 (c'est-à-dire faux).

postderef Booléen
CET ARGUMENT EST DÉPRÉCIÉ. Voir la NOTICE DE DÉPRÉCATION dans PPIx::QuoteLike pour les détails.

Cet argument spécifie si les déréférences postfixées sont reconnues dans les interpolations. Il est transmis à PPIx::QuoteLike new(), sauf si le premier argument était un objet PPIx::QuoteLike, auquel cas il est ignoré.

ppi Booléen
Cet argument spécifie si une sortie PPI est fournie pour les interpolations.

La valeur par défaut est 0 (c'est-à-dire faux).

court Booléen
Si vrai, les préfixes 'PPIx::QuoteLike::' seront supprimés des noms de classes dans la sortie.
tokens booléen
Si vrai, cet argument provoque une sortie non structurée des jetons trouvés dans l'analyse.

La valeur par défaut est 0 (c'est-à-dire faux).

variables Booléen
Si vrai, cet argument provoque la sortie de toutes les variables effectivement interpolées par n'importe quelle interpolation.

La valeur par défaut est 0 (c'est-à-dire faux).

dump

print PPIx::Regexp::Dumper->dump( 'foo/bar.pl',
    variables => 1,
);

Cette méthode statique retourne une chaîne qui représente une sortie de son premier argument. Elle prend les mêmes arguments optionnels que new(). Cette méthode diffère de new() dans son interprétation du premier argument.

  • Si le premier argument est le nom d'un fichier, ou une référence SCALAR, il est transformé en un PPI::Document et toutes les chaînes du document sont affichées.
  • Si le premier argument est un PPI::Node, toutes les chaînes du nœud sont affichées. Notez qu'un PPI::Document est un PPI::Node.

Sinon, le premier argument est traité comme le ferait new().

La valeur retournée est la représentation sous forme de chaîne de caractères de la sortie.

En plus des arguments optionnels acceptés par new(), les suivants peuvent être spécifiés :

aucun
Cet argument spécifie une chaîne à retourner si aucune sortie ne peut être produite (typiquement parce que le premier argument n'est ni un nom de fichier ni un texte reconnu par ce paquet). Si non spécifié, ou spécifié comme "undef", rien n'est retourné dans ce cas.

La sortie pour un objet individuel de type quote diffère de la sortie "string" sur le même objet en ce qu'elle est précédée de la chaîne littérale affichée, ainsi que des informations sur le fichier et l'emplacement si elles peuvent être déterminées.

list

print map { "$_\n" } $dumper->list();

Cette méthode retourne un tableau contenant la sortie de l'affichage. une ligne par élément. La sortie n'a pas de marge gauche appliquée, ni de sauts de ligne finaux. Des sauts de ligne intégrés sont probables si l'argument "ppi" a été spécifié lors de l'instanciation du dumper.

print

$dumper->print();

Cette méthode imprime simplement le résultat de "string" sur la sortie standard.

string

print $dumper->string();

Cette méthode ajoute la marge gauche et des sauts de ligne à la sortie de "list", concatène le résultat en une seule chaîne et retourne cette chaîne.
