NOM

PPI::Structure::Given - Accolades circulaires pour une instruction switch

SYNTAXE

given ( quelque chose ) {
    ...
}

HÉRITAGE

PPI::Structure::Given
isa PPI::Structure
    isa PPI::Node
        isa PPI::Element

DESCRIPTION

"PPI::Structure::Given" est la classe utilisée pour les accolades circulaires qui contiennent l'élément à comparer dans une instruction switch.

MÉTHODES

"PPI::Structure::Given" n'a pas de méthodes autres que celles fournies par les méthodes standard PPI::Structure, PPI::Node et PPI::Element.
