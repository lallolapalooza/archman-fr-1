PPIx__Regexp__Token__GroupType(3pm)

PPIx::Regexp::Token::GroupType(3) Documentation Perl Contributeur PPIx::Regexp::Token::GroupType(3)

NOM

PPIx::Regexp::Token::GroupType - Représenter un type de groupe de parenthèses.

SYNOPSIS

use PPIx::Regexp::Dumper;
PPIx::Regexp::Dumper->new( 'qr{(?i:foo)}smx' )
    ->print();

HÉRITAGE

"PPIx::Regexp::Token::GroupType" est un "PPIx::Regexp::Token".

"PPIx::Regexp::Token::GroupType" est le parent de PPIx::Regexp::Token::GroupType::Assertion, PPIx::Regexp::Token::GroupType::Atomic_Script_Run, PPIx::Regexp::Token::GroupType::BranchReset, PPIx::Regexp::Token::GroupType::Code, PPIx::Regexp::Token::GroupType::Modifier, PPIx::Regexp::Token::GroupType::NamedCapture, PPIx::Regexp::Token::GroupType::Script_Run, PPIx::Regexp::Token::GroupType::Subexpression et PPIx::Regexp::Token::GroupType::Switch.

DESCRIPTION

Cette classe représente toute séquence de caractères magiques qui peut suivre une parenthèse ouvrante. Cette classe particulière est conçue pour être abstraite.

MÉTHODES

Cette classe ne fournit aucune méthode publique en plus de celles fournies par sa superclasse.

__defining_string

my $string = $class->__defining_string();

Cette méthode est privée pour le package "PPIx-Regexp", et n'est documentée que pour l'usage de l'auteur. Elle peut être modifiée ou supprimée sans préavis.

Cette méthode renvoie un tableau de chaînes qui définissent le type spécifique du groupe. Ces chaînes commencent généralement par '?'.

Optionnellement, le premier élément retourné peut être une référence à un hash. La seule clé supportée est "{suffix}", qui est une chaîne ajoutée à la fin de chaque expression régulière générée par "__make_group_type_matcher()" à partir des définitions de chaînes, à l'intérieur de "(?= ... )", de sorte qu'elle ne soit pas incluse dans la correspondance.

Cette méthode doit être redéfinie, sauf si "__make_group_type_matcher()" l'est. La redéfinition doit renvoyer la même chose à chaque fois, car les résultats de "__make_group_type_matcher()" sont mis en cache.

__make_group_type_matcher

my $hash_ref = $class->__make_group_type_matcher();

Cette méthode est privée pour le package "PPIx-Regexp", et n'est documentée que pour l'usage de l'auteur. Elle peut être modifiée ou supprimée sans préavis.

Cette méthode renvoie une référence à un hash. Les clés sont des caractères délimiteurs d'expression régulière qui apparaissent dans les définitions de chaînes du type de groupe. Pour chaque clé, la valeur est une référence à un tableau d'objets "Regexp", correctement échappés pour le caractère délimiteur. La clé '' fournit les expressions régulières à utiliser si le délimiteur d'expression régulière n'apparaît dans aucune des définitions de chaînes.

Si cette méthode est redéfinie par la classe dérivée, la méthode "__defining_string()" ne doit pas l'être, sauf si la redéfinition de "__make_group_type_matcher()" appelle "__defining_string()".

__match_setup

$class->__match_setup( $tokenizer );

Cette méthode est privée pour le package "PPIx-Regexp", et n'est documentée que pour l'usage de l'auteur. Elle peut être modifiée ou supprimée sans préavis.

Cette méthode effectue la configuration nécessaire une fois qu'il a été déterminé que le type de groupe donné a été détecté. Cette méthode est appelée uniquement si la classe a correspondu à la position actuelle du texte en cours d'analyse. Elle doit effectuer toute configuration supplémentaire nécessaire pour la correspondance. Elle ne renvoie rien.

Cette méthode ne doit pas être redéfinie. La valeur par défaut ne fait rien.

__setup_class

$class->__setup_class( \%definition, \%opt );

Cette méthode est privée pour le package "PPIx-Regexp", et n'est documentée que pour l'usage de l'auteur. Elle peut être modifiée ou supprimée sans préavis.

Cette méthode utilise le hash %definition pour créer les méthodes "__defining_string()", explain(), perl_version_introduced() et perl_version_removed() pour la classe appelante. Celles qui existent déjà ne seront pas remplacées.

Le hash %definition définit toutes les chaînes qui spécifient les tokens de la classe invoquée. Vous ne pouvez pas utiliser ce mécanisme si vous avez besoin d'une expression régulière pour reconnaître un token appartenant à cette classe. Les clés du hash %definition sont des chaînes qui spécifient des membres de cette classe. Les valeurs sont des hashes qui définissent le membre spécifique de la classe. Les valeurs supportées sont :

{expl}
Ceci est l'explication de l'élément, qui est retournée par la méthode explain().
{intro}
Ceci est la version Perl qui a introduit l'élément, sous forme de chaîne. La valeur par défaut est la valeur de la constante MINIMUM_PERL.
{remov}
Ceci est la version Perl qui a supprimé l'élément, sous forme de chaîne. La valeur par défaut est "undef", ce qui signifie que l'élément est toujours présent dans la version la plus haute de Perl, qu'elle soit en développement ou en production.

Le hash %opt est optionnel et se comporte par défaut comme une chaîne vide. Il est principalement utilisé pour ad hoc. Les clés supportées sont :

{suffix}
Si cet élément est défini, le premier élément retourné par la méthode générée _defining_string() est un hash contenant cette clé et cette valeur.
