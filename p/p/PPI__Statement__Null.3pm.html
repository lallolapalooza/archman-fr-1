PPI::Statement::Null(3) Documentation Perl fournie par l'utilisateur PPI::Statement::Null(3)

NOM

PPI::Statement::Null - Une instruction nulle inutile

SYNTAXE

my $foo = 1;

; # <-- Instruction nulle

my $bar = 1;

HÉRITAGE

PPI::Statement::Null
isa PPI::Statement
    isa PPI::Node
        isa PPI::Element

DESCRIPTION

"PPI::Statement::Null" est une classe utilitaire conçue pour gérer les situations où PPI rencontre un séparateur d'instruction nu.

Bien qu'à strictement parler, le point-virgule soit un séparateur d'instruction et non un terminateur d'instruction, PPI considère un point-virgule comme un terminateur d'instruction dans la plupart des circonstances.

Dans tous les cas, l'instruction nulle n'a pas de but et peut être supprimée en toute sécurité sans aucun effet indésirable.

MÉTHODES

"PPI::Statement::Null" n'a pas de méthodes supplémentaires au-delà de celles par défaut fournies par PPI::Statement, PPI::Node et PPI::Element.
