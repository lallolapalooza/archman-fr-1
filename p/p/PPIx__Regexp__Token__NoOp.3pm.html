PPIx::Regexp::Token::NoOp(3) Documentation Perl fournie par l'utilisateur PPIx::Regexp::Token::NoOp(3)

NOM

PPIx::Regexp::Token::NoOp - Représente un jeton qui ne fait rien.

SYNOPSIS

use PPIx::Regexp::Dumper;
PPIx::Regexp::Dumper->new( 'qr< \N{} >smx' )
    ->print();

HÉRITAGE

"PPIx::Regexp::Token::NoOp" est un PPIx::Regexp::Token.

"PPIx::Regexp::Token::NoOp" est le parent de PPIx::Regexp::Token::Whitespace.

DESCRIPTION

Cette classe représente un jeton qui ne fait rien.

MÉTHODES

Cette classe ne fournit pas de méthodes publiques au-delà de celles fournies par sa superclasse.
