NOM

PPI::Token::QuoteLike - Classe de base abstraite pour les opérateurs de type citation

HÉRITAGE

PPI::Token::QuoteLike
isa PPI::Token
    isa PPI::Element

DESCRIPTION

La classe "PPI::Token::QuoteLike" n'est jamais instanciée et fournit simplement une classe de base abstraite commune pour les cinq classes d'opérateurs de type citation. Dans PPI, une "citation" est l'ensemble des éléments de type citation qui excluent les guillemets de chaîne et les expressions régulières.

Les sous-classes de "PPI::Token::QuoteLike" sont :

qw{} - PPI::Token::QuoteLike::Words
`` - PPI::Token::QuoteLike::Backtick
qx{} - PPI::Token::QuoteLike::Command
qr// - PPI::Token::QuoteLike::Regexp
<FOO> - PPI::Token::QuoteLike::Readline

Les noms sont, espérons-le, suffisamment explicites pour ne pas avoir à expliquer ce que fait chaque classe. Consultez leurs pages pour plus de détails.

Vous remarquerez peut-être que les guillemets inversés et les guillemets de commande sont traités séparément, même s'ils font la même chose. Ceci est intentionnel, car ils héritent et sont traités par deux parties différentes du moteur de citation de PPI.
