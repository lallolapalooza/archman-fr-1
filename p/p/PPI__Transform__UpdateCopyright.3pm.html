PPI::Transform::UpdateCopyright(3) Documentation Perl fournie par l'utilisateur PPI::Transform::UpdateCopyright(3)

NOM

PPI::Transform::UpdateCopyright - Classe de démonstration PPI::Transform

SYNTAXE

my $transform = PPI::Transform::UpdateCopyright->new(
    name => 'Adam Kennedy'
);

$transform->file('Module.pm');

DESCRIPTION

PPI::Transform::UpdateCopyright fournit une démonstration d'une classe PPI::Transform typique.

Cette classe implémente une transformation de document qui prendra le nom d'un auteur et mettra à jour la déclaration de copyright pour faire référence à l'année en cours, si ce n'est pas déjà le cas.

METHODES

new

my $transform = PPI::Transform::UpdateCopyright->new(
    name => 'Adam Kennedy'
);

Le constructeur "new" crée un nouvel objet de transformation pour un auteur spécifique. Il prend un paramètre unique "name" qui doit être le nom (ou une chaîne plus longue) de l'auteur.

La spécification du nom est nécessaire pour permettre la modification d'un sous-ensemble des déclarations de copyright qui vous font référence, parmi un plus grand ensemble dans un fichier.

name

L'accesseur "name" renvoie le nom de l'auteur que la transformation recherchera dans les déclarations de copyright.

À FAIRE

- Peut nécessiter de surcharger certaines méthodes pour empêcher de force que les objets Document ne deviennent enfants d'un autre nœud.
