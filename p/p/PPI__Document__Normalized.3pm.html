NOM

PPI::Document::Normalized - Un document Perl normalisé

DESCRIPTION

Un objet "Document Normalisé" est le résultat du processus de normalisation contenu dans la classe PPI::Normal. Voir la documentation de PPI::Normal pour plus d'informations.

L'objet contient une estampille de version et une liste de fonctions pour la version de PPI::Normal utilisée pour le créer, ainsi qu'un objet PPI::Document traité et délinsé.

Typiquement, l'objet Document aura été modifié par le processus de normalisation d'une manière qui le rendrait fatal d'essayer d'en faire quelque chose.

En termes simples, n'utilisez **jamais** l'objet Document après la normalisation. **VOUS AVEZ ÉTÉ PRÉVENU !**

L'objet est conçu ainsi pour favoriser les faux négatifs. Une comparaison entre deux objets ::Normalized ne retournera vrai que s'ils ont été produits par la même version de PPI::Normal, avec le même ensemble de fonctions de normalisation (dans le même ordre).

Vous pourriez obtenir de faux négatifs si vous mettez en cache des objets lors d'une mise à niveau.

Veuillez noter que ceci est fait pour des raisons de sécurité, car il existe de nombreux cas où une normalisation de bas niveau est susceptible d'être effectuée dans le cadre d'un processus de sécurité du code, et les faux positifs pourraient être très dangereux.

MÉTHODES

new

La méthode "new" est destinée à être utilisée uniquement par la classe PPI::Normal, et pour obtenir des objets ::Normalized, il est fortement recommandé d'utiliser soit ce module, soit la méthode "normalized" de l'objet PPI::Document lui-même.

version

L'accesseur "version" retourne la version de PPI::Normal utilisée pour créer l'objet.

functions

L'accesseur "functions" retourne une référence vers un tableau des fonctions de normalisation (dans l'ordre) qui ont été appelées lors de la création de l'objet.

equal $Normalized

La méthode "equal" est la méthode de comparaison principale, prenant un autre objet PPI::Document::Normalized, et vérifiant son équivalence.

L'opérateur "==" est également surchargé vers cette méthode, de sorte que vous puissiez faire quelque chose comme ceci :

my $first  = PPI::Document->load('first.pl');
my $second = PPI::Document->load('second.pl');

if ( $first->normalized == $second->normalized ) {
      print "Les deux documents sont équivalents";
}

Retourne vrai si les documents normalisés sont équivalents, faux sinon, ou "undef" en cas d'erreur.
