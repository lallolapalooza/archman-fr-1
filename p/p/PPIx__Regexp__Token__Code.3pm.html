PPIx::Regexp::Token::Code(3) Documentation Perl fournie par l'utilisateur PPIx::Regexp::Token::Code(3)

NOM

PPIx::Regexp::Token::Code - Représente un fragment de code Perl embarqué dans une expression régulière.

SYNTAXE

use PPIx::Regexp::Dumper;
PPIx::Regexp::Dumper->new(
    'qr{(?{print "hello sailor\n"})}smx')->print;

HÉRITAGE

"PPIx::Regexp::Token::Code" est un PPIx::Regexp::Token.

"PPIx::Regexp::Token::Code" est le parent de PPIx::Regexp::Token::Interpolation.

DESCRIPTION

Cette classe représente un fragment de code Perl embarqué dans une expression régulière. Plus spécifiquement, elle résulte du parsing de choses comme

(?{ code })
(??{ code })

ou du côté remplacement d'un s///e. Techniquement, les interpolations sont aussi du code, mais elles sont analysées différemment et finissent donc dans un jeton différent.

Ce jeton ne peut pas apparaître à l'intérieur d'un ensemble d'expressions régulières (c'est-à-dire "(?[ ... ])". S'il est trouvé, il deviendra un "PPIx::Regexp::Token::Unknown".

MÉTHODES

Cette classe fournit les méthodes publiques suivantes. Les méthodes non documentées ici sont privées et non prises en charge dans le sens où l'auteur se réserve le droit de les modifier ou de les supprimer sans préavis.

is_matcher

Cette méthode retourne "undef" car une analyse statique ne peut généralement pas déterminer si une valeur interpolée correspond à quelque chose.

ppi

Cette méthode pratique retourne le document PPI représentant le contenu. Ce document doit être considéré comme en lecture seule.

Note : si l'emplacement de l'invocant est disponible, le document PPI aura des éléments préfixés pour rendre l'emplacement des jetons dans le nouveau document cohérent avec l'emplacement d'origine. Ces « éléments » incluront au moins une directive "#line", et peut-être des espaces blancs de début.
