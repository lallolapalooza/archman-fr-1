NOM

PPI::Token::Number::Float - Classe de jeton pour un nombre à virgule flottante

SYNOPSIS

$n = 1.234;

HÉRITAGE

PPI::Token::Number::Float
isa PPI::Token::Number
    isa PPI::Token
        isa PPI::Element

DESCRIPTION

La classe "PPI::Token::Number::Float" est utilisée pour les jetons représentant des nombres à virgule flottante. Un nombre flottant est identifié par un point décimal. La notation exponentielle (le "e" ou "E") est gérée par la classe PPI::Token::Number::Exp.

MÉTHODES

base

Retourne la base du nombre : 10.

literal

Retourne la valeur numérique de ce jeton.
