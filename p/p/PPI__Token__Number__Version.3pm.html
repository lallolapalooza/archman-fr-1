PPI::Token::Number::Version(3) Documentation Perl fournie par l'utilisateur PPI::Token::Number::Version(3)

NOM

PPI::Token::Number::Version - Classe de jeton pour un nombre empaqueté en octets

SYNTAXE

$n = 1.1.0;
$n = 127.0.0.1;
$n = 10_000.10_000.10_000;
$n = v1.2.3.4

HIÉRARCHIE

PPI::Token::Number::Version
isa PPI::Token::Number
    isa PPI::Token
        isa PPI::Element

DESCRIPTION

La classe "PPI::Token::Number::Version" est utilisée pour les jetons qui ont plusieurs points décimaux. En réalité, ceux-ci ne sont pas du tout traités comme des nombres par Perl, mais ils ressemblent à des nombres pour un analyseur.

MÉTHODES

base

Retourne la base du nombre : 256.

littéral

Retourne la valeur numérique de ce jeton.

BOGUES

- Ne gère pas correctement le signe moins en tête. Devrait se traduire par un Mot Collé. Voir http://perlmonks.org/?node_id=574573

-95.0.1.0  --> "-_\000\cA\000"
-96.0.1.0  --> Argument "`\0^A\0" n'est pas numérique en négation (-)
