PPIx::Utilities::Statement(3) Documentation Perl Contribuée par les utilisateurs PPIx::Utilities::Statement(3)

NOM

PPIx::Utilities::Statement - Extensions pour PPI::Statement.

VERSION

Ce document décrit la version 1.1.0 de PPIx::Utilities::Statement.

SYNTAXE

use PPI::Document qw< >;
use PPIx::Utilities::Statement qw<
    get_constant_name_elements_from_declaring_statement
>;
my $document = PPI::Document->new(\'Readonly::Scalar my $THINGY => 47.2;');
# Retourne le PPI::Token::Symbol pour « $THINGY ».
my ($constant) = get_constant_name_elements_from_declaring_statement(
    $document->schild(0)
);

DESCRIPTION

Ceci est une collection de fonctions pour manipuler les PPI::Statements.

INTERFACE

Rien n'est exporté par défaut.

get_constant_name_elements_from_declaring_statement($statement)

Étant donné un PPI::Statement, si l'instruction est une déclaration Readonly ou Const::Fast ou une instruction "use constant", retourne les noms des éléments en cours de définition.

Étant donné

use constant 1.16 FOO => 'bar';

cela retournera le PPI::Token::Word contenant 'FOO'. Étant donné

use constant 1.16 { FOO => 'bar', 'BAZ' => 'burfle' };

cela retournera une liste des PPI::Tokens contenant 'FOO' et 'BAZ'. De même, étant donné

Readonly::Hash my %FOO => ( bar => 'baz' );

ou

const my %FOO => ( bar => 'baz' );

cela retournera le PPI::Token::Symbol contenant '%FOO'.
