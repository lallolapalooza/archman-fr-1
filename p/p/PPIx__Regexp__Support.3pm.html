NOM

PPIx::Regexp::Support - Base pour les classes de support PPIx::Regexp

SYNOPSIS

use PPIx::Regexp::Dumper;
PPIx::Regexp::Dumper->new( 'qr{foo}smx' )
    ->print();

HIÉRARCHIE

"PPIx::Regexp::Support" n'est descendant d'aucune autre classe.

"PPIx::Regexp::Support" est le parent de PPIx::Regexp::Dumper, PPIx::Regexp::Lexer et PPIx::Regexp::Tokenizer.

DESCRIPTION

Cette classe abstraite fournit des méthodes pour les classes de support "PPIx::Regexp".

MÉTHODES

Cette classe fournit les méthodes publiques suivantes. Les méthodes non documentées ici sont privées, et non supportées dans le sens où l'auteur se réserve le droit de les modifier ou de les supprimer sans préavis.

close_bracket

Cette méthode prend un caractère comme argument. Si ce caractère est une parenthèse ouvrante, la parenthèse fermante correspondante est retournée. Sinon, "undef" est retourné. Seuls les caractères de parenthèses ASCII sont considérés comme des parenthèses : (), {}, [], et <>.

decode

Cette méthode encapsule la sous-routine Encode::decode. Si l'objet ne spécifie aucun encodage ou si encode_available() retourne faux, cette méthode retourne simplement sa chaîne d'entrée.

encode

Cette méthode encapsule la sous-routine Encode::encode. Si l'objet ne spécifie aucun encodage ou si encode_available() retourne faux, cette méthode retourne simplement sa chaîne d'entrée.

encode_available

Cette méthode retourne vrai si le module Encode est disponible, et faux sinon. S'il retourne vrai, le module Encode a effectivement été chargé.
