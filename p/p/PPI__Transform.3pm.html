PPI::Transform(3) Documentation Perl fournie par la communauté PPI::Transform(3)

NOM

PPI::Transform - Classe de base abstraite pour les classes de transformation de documents

DESCRIPTION

"PPI::Transform" fournit une API pour la création de classes et d'objets qui modifient ou transforment des documents PPI.

MÉTHODES

new

my $transform = PPI::Transform->new(
    param1 => 'valeur1',
    param2 => 'valeur2',
);

Le constructeur "new" crée un nouvel objet pour votre sous-classe "PPI::Transform". Un constructeur par défaut est fourni pour vous, qui ne prend aucun paramètre et crée un objet simple et vide.

Si vous souhaitez que votre constructeur de transformation accepte des paramètres, ceux-ci doivent être sous la forme d'une liste de paires clé/valeur.

Retourne un nouvel objet compatible "PPI::Transform", ou retourne "undef" en cas d'erreur.

document

La méthode "document" doit être implémentée par chaque sous-classe, et prend un seul argument, un objet PPI::Document, le modifiant en place comme il convient à la classe de transformation particulière.

C'est exact, cette méthode ne clonera pas et ne devrait pas cloner l'objet document. Si vous ne souhaitez pas que l'original soit modifié, vous devez le cloner vous-même avant de le passer.

Retourne le nombre de modifications apportées au document. Si la transformation ne parvient pas à suivre la quantité (y compris la situation où elle ne peut pas dire SI elle a effectué une modification), elle devrait retourner 1. Retourne zéro si aucune modification n'a été apportée au document, ou "undef" en cas d'erreur.

Par défaut, cette erreur signifie probablement que vous avez passé quelque chose qui n'était pas un PPI::Document, mais peut inclure des erreurs supplémentaires en fonction de la sous-classe.

apply

La méthode "apply" est utilisée pour appliquer la transformation à quelque chose. L'argument doit être un PPI::Document, ou quelque chose qui peut être transformé en un et ensuite réécrit à nouveau.

Actuellement, cette liste est limitée à une référence "SCALAR", bien qu'un processus d'enregistrement de gestionnaire soit disponible pour vous permettre d'ajouter la prise en charge de types d'objets supplémentaires si vous le souhaitez (voir la source de ce module).

Retourne vrai si la transformation a été appliquée, faux s'il y a une erreur dans le processus de transformation, ou peut mourir s'il y a une erreur critique dans le gestionnaire d'application.

file

# Lire depuis un fichier et écrire vers un autre
$transform->file( 'Input.pm' => 'Output.pm' );

# Modifier un fichier en place
$transform->file( 'Change.pm' );

La méthode "file" modifie un document Perl par nom de fichier. Si elle reçoit un seul paramètre, elle modifie le fichier en place. Si elle reçoit un second paramètre, elle tentera d'enregistrer le fichier modifié sous le nom de fichier alternatif.

Retourne vrai en cas de succès, ou "undef" en cas d'erreur.
