NOM

PPIx::Regexp::Token::Recursion - Représenter une récursion

SYNOPSIS

use PPIx::Regexp::Dumper;
PPIx::Regexp::Dumper->new( 'qr{(foo(?1)?)}smx' )
    ->print();

HÉRITAGE

"PPIx::Regexp::Token::Recursion" est une PPIx::Regexp::Token::Reference.

"PPIx::Regexp::Token::Recursion" n'a pas de descendants.

DESCRIPTION

Cette classe représente une récursion vers un groupe capturant nommé ou numéroté.

MÉTHODES

Cette classe ne fournit pas de méthodes publiques au-delà de celles fournies par sa superclasse.
