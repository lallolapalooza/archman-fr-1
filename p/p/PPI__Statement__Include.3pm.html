Paquet: perl-ppi

Licences: PerlArtistic

PPI::Statement::Include(3) Documentation Perl fournie par l'utilisateur PPI::Statement::Include(3)

NOM

PPI::Statement::Include - Déclarations qui incluent d'autres codes

SYNTAXE

# Les déclarations suivantes sont toutes des inclusions
use 5.006;
use strict;
use My::Module;
use constant FOO => 'Foo';
require Foo::Bar;
require "Foo/Bar.pm";
require $foo if 1;
no strict 'refs';

HIÉRARCHIE

PPI::Statement::Include
isa PPI::Statement
    isa PPI::Node
        isa PPI::Element

DESCRIPTION

Malgré son nom, la classe "PPI::Statement::Include" couvre un certain nombre de types de déclarations différents, englobant toutes les déclarations commençant par "use", "no" et "require".

Mais fondamentalement, elles couvrent trois situations.

Premièrement, une dépendance sur une version particulière de perl (pour laquelle la méthode "version" retourne vrai), un pragma (pour lequel la méthode "pragma" retourne vrai), ou le chargement (et le déchargement via no) de modules.

MÉTHODES

"PPI::Statement::Include" possède un certain nombre de méthodes en plus des méthodes standards de PPI::Statement, PPI::Node et PPI::Element.

type

La méthode "type" retourne le type général de la déclaration ('use', 'no' ou 'require').

Retourne le type sous forme de chaîne de caractères, ou "undef" si le type ne peut pas être détecté.

module

La méthode "module" retourne le nom du module spécifié dans toute déclaration d'inclusion. Cela inclut les pragmas (car les pragmas sont implémentés comme des modules. Et avouons-le, la définition d'un pragma peut être floue au mieux).

Cela couvre tous ceux-ci...

use strict;
use My::Module;
no strict;
require My::Module;

... mais ne couvre aucun de ceux-ci...

use 5.006;
require 5.005;
require "explicit/file/name.pl";

Retourne le nom du module sous forme de chaîne de caractères, ou "undef" si l'inclusion ne spécifie pas de nom de module.

module_version

La méthode "module_version" retourne la version minimale du module requise par la déclaration, s'il y en a une.

pragma

La méthode "pragma" vérifie si une déclaration d'inclusion est utilisée comme pragma et la retourne si c'est le cas.

Ou du moins, elle prétend le faire. En pratique, il est beaucoup plus difficile de dire exactement ce qui est un pragma et ce qui ne l'est pas, car la définition est floue.

L'"intention" d'un pragma est de modifier la façon dont l'analyseur fonctionne. Ceci est fait grâce à l'utilisation de modules qui effectuent divers types de magie interne.

Pour l'instant, PPI suppose que tout "nom de module" qui est uniquement un ensemble de lettres minuscules (et peut-être des chiffres, comme "use utf8;"). Ce comportement devrait changer, plus probablement vers quelque chose qui connaîtra les noms spécifiques des divers "pragmas".

Retourne le nom du pragma, ou faux ('') si l'inclusion n'est pas un pragma.

version

La méthode "version" vérifie une déclaration d'inclusion qui introduit une dépendance sur la version de "perl" avec laquelle le code est compatible.

Cela couvre deux déclarations spécifiques.

use 5.006;
require 5.006;

Actuellement, la version est retournée sous forme de chaîne de caractères, bien qu'à l'avenir, la version puisse être retournée sous forme d'objet version. Si vous souhaitez une représentation numérique, utilisez version_literal(). Retourne faux si la déclaration n'est pas une dépendance de version.

version_literal

La méthode "version_literal" a le même comportement que version(), mais la version est retournée sous forme de littéral numérique. Retourne faux si la déclaration n'est pas une dépendance de version.

arguments

La méthode "arguments" vous donne le reste de la déclaration après le module/pragma et la version du module, c'est-à-dire les éléments qui seront utilisés pour construire ce qui est passé à la sous-routine import() du module. Cela inclut les virgules, les opérateurs etc., mais n'inclut pas les enfants directs non significatifs ou un éventuel point-virgule final.

feature_mods

# `use feature 'signatures';`
my %mods = $include->feature_mods;
# { signatures => "perl" }
# `use 5.036;`
my %mods = $include->feature_mods;
# { signatures => "perl" }

Retourne un hashref des fonctionnalités identifiées comme activées par l'inclusion, ou undef si l'inclusion n'active pas de fonctionnalités. La valeur pour chaque fonctionnalité indique le fournisseur de la fonctionnalité.
