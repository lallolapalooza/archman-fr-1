PPIx::QuoteLike::Token::Whitespace(3) Documentation Perl contribuée par l'utilisateur PPIx::QuoteLike::Token::Whitespace(3)

NOM

PPIx::QuoteLike::Token::Whitespace - Représente les espaces blancs insignifiants.

SYNTAXE

Cette classe ne doit pas être instanciée par l'utilisateur. Voir ci-dessous pour les méthodes publiques.

HÉRITAGE

"PPIx::QuoteLike::Token::Whitespace" est un PPIx::QuoteLike::Token.

"PPIx::QuoteLike::Token::Whitespace" n'a pas de descendants.

DESCRIPTION

Cette classe Perl représente les espaces blancs insignifiants.

MÉTHODES

Cette classe ne prend en charge aucune méthode publique supplémentaire par rapport à celles de sa superclasse. Cependant, les méthodes suivantes ont été remplacées :

significant

Cette méthode retourne une valeur fausse.

VOIR AUSSI

PPIx::QuoteLike::Token.
