PPIx::QuoteLike::Token(3) Documentation de paquets contribués Perl PPIx::QuoteLike::Token(3)

NOM

PPIx::QuoteLike::Token - Représente n'importe quel jeton.

SYNOPIS

C'est une classe abstraite et ne doit pas être instanciée par l'utilisateur.

DESCRIPTION

Ceci est la base de la hiérarchie des jetons.

HIÉRARCHIE

PPIx::QuoteLike::Token ne dérive d'aucune autre classe.

PPIx::QuoteLike::Token est la classe mère de PPIx::QuoteLike::Token::Control, PPIx::QuoteLike::Token::Interpolation, PPIx::QuoteLike::Token::String, PPIx::QuoteLike::Token::Structure, PPIx::QuoteLike::Token::Unknown et PPIx::QuoteLike::Token::Whitespace.

MÉTHODES

Cette classe supporte les méthodes publiques suivantes :

column_number

Cette méthode retourne le numéro de colonne du premier caractère de l'élément, ou "undef" s'il ne peut être déterminé.

content

say $token->content();

Cette méthode retourne le texte qui compose le jeton.

error

say $token->error();

Cette méthode retourne le texte de l'erreur. Ce sera "undef" sauf si le jeton représente effectivement une erreur.

line_number

Cette méthode retourne le numéro de ligne du premier caractère de l'élément, ou "undef" s'il ne peut être déterminé.

location

Cette méthode retourne une référence vers un tableau décrivant la position de l'élément dans la chaîne, ou "undef" si la position n'est pas disponible.

Le tableau est compatible avec la méthode correspondante de PPI::Element.

logical_filename

Cette méthode retourne le nom logique du fichier (en tenant compte des directives "#line") qui contient le premier caractère de l'élément, ou "undef" s'il ne peut être déterminé.

logical_line_number

Cette méthode retourne le numéro de ligne logique (en tenant compte des directives "#line") du premier caractère de l'élément, ou "undef" s'il ne peut être déterminé.

parent

my $parent = $token->parent();

Cette méthode retourne le jeton parent, qui sera l'objet PPIx::QuoteLike contenant le jeton.

next_sibling

my $next = $token->next_sibling();

Cette méthode retourne le jeton suivant l'appelant, ou rien s'il n'y en a pas.

perl_version_introduced

Cette méthode retourne la version de Perl dans laquelle l'élément a été introduit. Ce sera au moins 5.000. Avant 5.006, elle dépendait des documents perldelta, perlre et perlop, car je n'avais pas pu construire de versions de Perl antérieures. Comme je n'avais trouvé aucune documentation avant 5.003, je suppose que tout ce qui est trouvé dans 5.003 est également dans 5.000.

Puisque tout dépend de ma capacité à lire et à comprendre des centaines de documents, les résultats de cette méthode doivent être considérés avec prudence, voire avec méfiance.

Il existe également des cas qui sont ambigus de diverses manières. Pour ces cas, voir "RESTRICTIONS" dans PPIx::Regexp, en particulier "CHANGEMENTS DE SYNTAXE" dans PPIx::Regexp.

perl_version_removed

Cette méthode retourne la version de Perl dans laquelle l'élément a été supprimé. Si l'élément est toujours valide, le retour sera "undef".

Toutes les remarques concernant perl_version_introduced() s'appliquent également ici, bien que peut-être moins sévèrement, car même si de nombreuses fonctionnalités ont été introduites depuis 5.0, peu ont été supprimées.

previous_sibling

my $prev = $token->previous_sibling();

Cette méthode retourne le jeton précédent l'appelant, ou rien s'il n'y en a pas.

significant

$token->significant()
    and say 'significatif';

Cette méthode retourne une valeur vraie si le jeton est significatif, et fausse dans le cas contraire.

snext_sibling

my $next = $token->snext_sibling();

Cette méthode retourne le jeton significatif suivant l'appelant, ou rien s'il n'y en a pas.

sprevious_sibling

my $prev = $token->sprevious_sibling();

Cette méthode retourne le jeton significatif précédent l'appelant, ou rien s'il n'y en a pas.

statement

Cette méthode retourne le PPI::Statement qui contient ce jeton, ou rien s'il ne peut être déterminé.

En général, cette méthode retournera quelque chose seulement sous les conditions suivantes :

  • Le jeton est contenu dans un objet PPIx::QuoteLike ;
  • L'objet a été initialisé à partir d'un PPI::Element ;
  • Le PPI::Element est contenu dans une instruction.

top

Cette méthode retourne le sommet de la hiérarchie.

variables

say "Interpolan $_" for $elem->variables();

NOTEZ que cette méthode est dépréciée et peut être rejetée et supprimée. J'ai deux problèmes avec elle. Le premier est qu'elle retourne les noms de variables au lieu d'objets PPI::Element, ce qui ne permet pas de savoir comment les variables sont utilisées. Le second est qu'elle ne gère pas correctement des choses comme "${^CAPTURE[0]}", et il semble impossible de le faire. Elle a été initialement écrite pour le bénéfice de Perl::Critic::Policy::Variables::ProhibitUnusedVarsStricter, mais s'est avérée insuffisante pour les besoins de cette politique.

Cette méthode de commodité retourne toutes les variables interpolées. Chacune est retournée une seule fois, et elle est retournée dans aucun ordre particulier.

NOTEZ que parce que cette classe ne représente pas une interpolation, cette méthode retourne rien.

visual_column_number

Cette méthode retourne le numéro de colonne visuel (en tenant compte des tabulations) du premier caractère de l'élément, ou "undef" s'il ne peut être déterminé.
