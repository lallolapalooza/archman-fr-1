PPI::Token::Quote(3) Documentation Perl fournie par l'utilisateur PPI::Token::Quote(3)

NOM

PPI::Token::Quote - Classe de base abstraite pour les guillemets de chaîne

HÉRITAGE

PPI::Token::Quote
isa PPI::Token
    isa PPI::Element

DESCRIPTION

La classe "PPI::Token::Quote" n'est jamais instanciée et fournit simplement une classe de base abstraite commune pour les quatre classes de guillemets. Dans PPI, un "guillemet" se limite uniquement aux éléments qui ressemblent à des guillemets et qui représentent eux-mêmes directement une chaîne. (bien que cela inclue les guillemets doubles avec des éléments interpolés à l'intérieur, notez que String::InterpolatedVariables permet de les extraire).

Les sous-classes de "PPI::Token::Quote" sont :

'' - PPI::Token::Quote::Single
"q{}" - PPI::Token::Quote::Literal
"" - PPI::Token::Quote::Double
"qq{}" - PPI::Token::Quote::Interpolate

Les noms sont, on l'espère, suffisamment évidents pour ne pas avoir à expliquer ce qu'est chaque classe ici. Voir leurs pages respectives pour plus de détails.

Veuillez noter que bien que le here-doc représente une chaîne littérale, c'est un travail tellement fastidieux que dans PPI, il se voit accorder l'honneur de sa propre classe de jeton (PPI::Token::HereDoc).

MÉTHODES

string

La méthode "string" est fournie par les quatre classes ::Quote. Elle ne vous donnera pas la valeur littérale réelle de Perl, mais elle retirera les guillemets environnants.

# Les lignes suivantes retournent toutes foo à partir de la méthode ->string
'foo'
"foo"
q{foo}
qq <foo>

literal

La méthode "literal" est fournie par ::Quote::Literal et ::Quote::Single. Elle retourne la valeur de la chaîne telle que Perl la voit : sans les guillemets et avec "\\" et "\'" résolus en "\" et "'".

La méthode "literal" n'est pas encore implémentée par ::Quote::Double ou ::Quote::Interpolate.
