PPI::Cache(3) Documentation Perl fournie par l'utilisateur PPI::Cache(3)

NOM

PPI::Cache - La couche de mise en cache des documents PPI

SYNOPSIS

# Définir le cache
use PPI::Cache path => '/var/cache/ppi-cache';

# Créer manuellement un cache
my $Cache = PPI::Cache->new(
    path     => '/var/cache/perl/class-PPI',
    readonly => 1,
);

DESCRIPTION

"PPI::Cache" fournit la fonctionnalité de mise en cache par défaut pour PPI.

Il s'intègre automatiquement à PPI lui-même. Une fois activée, toute tentative de chargement d'un document depuis le système de fichiers sera mise en cache via cache.

Veuillez noter que la création d'un PPI::Document à partir d'une source brute ou d'un autre objet ne sera pas mise en cache.

Utilisation de PPI::Cache

La manière la plus courante d'utiliser "PPI::Cache" est de fournir des paramètres à l'instruction "use" au début de votre programme.

# Charger la classe mais ne pas définir de cache
use PPI::Cache;

# Utiliser un emplacement de cache assez normal
use PPI::Cache path => '/var/cache/ppi-cache';

N'importe lequel des arguments qui peuvent être fournis au constructeur "new" peut également être fourni à "use".

MÉTHODES

new param => $valeur, ...

Le constructeur "new" crée un nouveau objet de cache autonome.

Il prend un certain nombre de paramètres pour contrôler le cache.

path
Le paramètre "path" définit le répertoire racine pour le cache. Il doit déjà exister et doit être accessible en écriture.
readonly
Le paramètre "readonly" est un indicateur vrai/faux qui permet d'utiliser un cache existant par un utilisateur moins privilégié (tel que l'utilisateur web).

Les documents existants seront récupérés du cache, mais les nouveaux documents ne seront pas écrits dedans.

Renvoie un nouvel objet "PPI::Cache", ou plante en cas d'erreur.

path

L'accesseur "path" renvoie le chemin sur le système de fichiers local qui est la racine du cache.

readonly

L'accesseur "readonly" renvoie vrai si les documents ne doivent pas être écrits dans le cache.

get_document $md5sum | $source

La méthode "get_document" vérifie si un Document est stocké dans le cache et le récupère si c'est le cas.

store_document $Document

La méthode "store_document" prend un PPI::Document comme argument et l'ajoute explicitement au cache.

Renvoie vrai si sauvegardé, ou "undef" (ou plante) en cas d'erreur.
