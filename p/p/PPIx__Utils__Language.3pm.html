NOM

PPIx::Utils::Language - Fonctions utilitaires pour PPI relatives au langage Perl

SYNOPSIS

use PPIx::Utils::Language ':all';

DESCRIPTION

Ce paquet est un composant de PPIx::Utils qui contient des fonctions relatives aux aspects du langage Perl.

FONCTIONS

Toutes les fonctions peuvent être importées par leur nom, ou avec l'étiquette ":all".

precedence_of

my $precedence = precedence_of($element);

Étant donné un PPI::Token::Operator ou une chaîne de caractères, retourne la précédence de l'opérateur, où 1 est la précédence la plus élevée. Retourne undef si la précédence ne peut pas être déterminée (ce qui se produit généralement parce que ce n'est pas un opérateur).

symbol_without_sigil

my $name = symbol_without_sigil($symbol);

Retourne le nom du symbole spécifié sans aucun sigil au début. Le paramètre peut être une chaîne de caractères Perl standard ou un PPI::Element.
