NOM

PPIx::Regexp::Structure - Représente une structure.

SYNOPSIS

use PPIx::Regexp::Dumper;
PPIx::Regexp::Dumper->new( 'qr{(foo)}' )->print();

HIÉRARCHIE

"PPIx::Regexp::Structure" est un PPIx::Regexp::Node.

"PPIx::Regexp::Structure" est le parent de PPIx::Regexp::Structure::Assertion, PPIx::Regexp::Structure::BranchReset, PPIx::Regexp::Structure::Capture, PPIx::Regexp::Structure::CharClass, PPIx::Regexp::Structure::Code, PPIx::Regexp::Structure::Main, PPIx::Regexp::Structure::Modifier, PPIx::Regexp::Structure::Quantifier, PPIx::Regexp::Structure::Script_Run, PPIx::Regexp::Structure::Subexpression, PPIx::Regexp::Structure::Switch et PPIx::Regexp::Structure::Unknown.

DESCRIPTION

Cette classe représente une construction entre crochets d'une sorte. Les crochets sont considérés comme faisant partie de la structure, mais pas à l'intérieur. Ainsi, la méthode elements() renvoie les crochets s'ils sont définis, mais la méthode children() ne le fait pas.

MÉTHODES

Cette classe fournit les méthodes publiques suivantes. Les méthodes non documentées ici sont privées et non prises en charge dans le sens où l'auteur se réserve le droit de les modifier ou de les supprimer sans préavis.

elements

Cette surcharge renvoie tous les composants de la structure, y compris ceux qui la définissent.

finish

my $elem = $struct->finish();
my @elem = $struct->finish();
my $elem = $struct->finish( 0 );

Renvoie l'élément de structure de fin. Ceci est inclus dans "elements" mais pas dans "children".

L'élément de fin est en fait un tableau, bien qu'il ne doive jamais avoir plus d'un élément. Appeler "finish" en contexte de liste vous donne tous les éléments du tableau. L'appeler en contexte scalaire vous donne un élément du tableau, par défaut l'élément 0 si aucun argument n'est passé.

start

my $elem = $struct->start();
my @elem = $struct->start();
my $elem = $struct->start( 0 );

Renvoie l'élément de structure de début. Ceci est inclus dans "elements" mais pas dans "children".

L'élément de début est en fait un tableau. Le premier élément (élément 0) est le délimiteur de début réel. Les éléments suivants, le cas échéant, sont des éléments insignifiants (commentaires ou espaces) absorbés dans l'élément de début pour faciliter l'analyse des éléments suivants.

Appeler "start" en contexte de liste vous donne tous les éléments du tableau. L'appeler en contexte scalaire vous donne un élément du tableau, par défaut l'élément 0 si aucun argument n'est passé.

type

my $elem = $struct->type();
my @elem = $struct->type();
my $elem = $struct->type( 0 );

Renvoie le type de groupe, le cas échéant. Ce sera le jeton PPIx::Regexp::Token::GroupType principal s'il y en a un. Ceci est inclus dans "elements" mais pas dans "children".

Le type est en fait un tableau. Le premier élément (élément 0) est le déterminant de type réel. Les éléments suivants, le cas échéant, sont des éléments insignifiants (commentaires ou espaces) absorbés dans l'élément de type pour la cohérence avec la manière dont l'élément de début est géré.

Appeler "type" en contexte de liste vous donne tous les éléments du tableau. L'appeler en contexte scalaire vous donne un élément du tableau, par défaut l'élément 0 si aucun argument n'est passé.
