NOM

PPIx::Regexp::Dumper - Dumper des résultats d'analyse d'expressions régulières

SYNOPSIS

use PPIx::Regexp::Dumper;
PPIx::Regexp::Dumper->new( 'qr{foo}smx' )
    ->print();

HÉRITAGE

"PPIx::Regexp::Dumper" est une classe de "PPIx::Regexp::Support".

"PPIx::Regexp::Dumper" n'a pas de descendants.

DESCRIPTION

Cette classe génère un dump formaté d'un objet "PPIx::Regexp::Element" (ou de toute sous-classe de celui-ci), d'un objet "PPIx::Regexp::Tokenizer", ou d'une chaîne qui peut être analysée en l'un de ceux-ci.

MÉTHODES

Cette classe fournit les méthodes publiques suivantes. Les méthodes non documentées ici sont considérées comme privées et ne sont pas supportées dans le sens où l'auteur se réserve le droit de les modifier ou de les supprimer sans préavis.

new

my $dumper = PPIx::Regexp::Dumper->new(
    '/foo/', ordinal => 1,
);

Cette méthode statique crée une instance du dumper. Le premier argument est la chaîne, l'"PPI::Element", "PPIx::Regexp::Element" ou "PPIx::Regexp::Tokenizer" à dumper. Des arguments supplémentaires peuvent être passés sous forme de paires nom-valeur.

Les options suivantes sont reconnues :

modificateurs par défaut
Cet argument est une référence à une liste de modificateurs par défaut à appliquer à la déclaration analysée. Voir "PPIx::Regexp new()" pour plus de détails.
encodage
Cet argument est le nom de l'encodage de l'expression régulière. S'il est spécifié, il est transmis à "PPIx::Regexp->new()". Il entraîne également un "Encode::encode" sur le contenu analysé.
expliquer
Si vrai, cette option fait imprimer la sortie explain() de chaque objet.
indentation
Cet argument est le nombre d'espaces supplémentaires à ajouter à chaque niveau de la hiérarchie d'analyse. Il est ignoré si l'argument "test" ou "tokens" est vrai.
marge
C'est le nombre d'espaces d'indentation pour le niveau supérieur de la hiérarchie d'analyse. Il est ignoré si l'argument "test" est vrai.
ordinal
Si vrai, cette option fait imprimer les valeurs "ordinal" des objets "PPIx::Regexp::Token::Literal".
perl_version
Si vrai, cette option fait afficher les valeurs "perl_version_introduced" et "perl_version_removed" associées à chaque objet.
ppi
Si vrai, tout code Perl contenu dans l'objet sera imprimé.
court
Si vrai, les préfixes "PPIx::Regexp::" dans les noms de classe de la sortie seront omis.
strict
Cette option est passée à l'analyseur, où elle spécifie si l'analyse doit supposer que "use re 'strict'" est en vigueur. L'option 'strict' a été introduite dans Perl 5.22, et sa documentation indique qu'elle est expérimentale et qu'il n'y a aucun engagement de rétrocompatibilité. La même chose s'applique à la sortie produite lorsque cette option est activée.
significatif
Si vrai, cette option fait imprimer uniquement les éléments significatifs.
test
Si vrai, cette option fait que la sortie est formatée comme un test de régression au lieu d'un dump direct. La sortie générée avec cette option n'est explicitement pas documentée, car l'auteur se réserve le droit de modifier la sortie générée sans aucun préavis.
tokens
Si vrai, cette option fait imprimer la sortie du tokenizer au lieu d'une analyse complète de l'expression régulière. Cette option est forcée à vrai si le dump concerne un objet "PPIx::Regexp::Tokenizer".
trace
Si supérieur à zéro, cette option génère un journal de l'analyse. Cette option n'est pas supportée car l'auteur se réserve le droit de la modifier sans préavis.
verbeux
Si supérieur à zéro, cette option fournit des informations supplémentaires sur les éléments trouvés. Cette option n'est pas supportée car l'auteur se réserve le droit de la modifier sans préavis.
largeur
Si vrai, cette option fait imprimer la largeur de l'objet.

Si l'objet à dumper était une chaîne, les arguments non reconnus sont transmis à "PPIx::Regexp::Tokenizer->new()". Sinon, ils sont ignorés.

list

print map { "$_\n" } $dumper->list();

Cette méthode génère un tableau contenant la sortie du dump, une ligne par élément. La sortie n'a pas de marge gauche appliquée et pas de sauts de ligne.

print

$dumper->print();

Cette méthode imprime simplement le résultat de "string" sur la sortie standard.

string

print $dumper->string();

Cette méthode ajoute une marge gauche et des sauts de ligne à la sortie de "list", concatène la sortie en une seule chaîne et renvoie cette chaîne.
