PPI::Document::File(3) Documentation Perl fournie par la communauté PPI::Document::File(3)

NOM

PPI::Document::File - Un document Perl situé dans un fichier spécifique

DESCRIPTION

AVERTISSEMENT : Cette classe est expérimentale et peut changer sans préavis

PPI::Document::File fournit une sous-classe de PPI::Document qui représente un document Perl stocké dans un fichier nommé spécifique.

MÉTHODES

new

my $file = PPI::Document::File->new( 'Module.pm' );

Le constructeur "new" fonctionne de la même manière que pour celui habituel, sauf que les seuls paramètres autorisés sont un nom de fichier. Vous ne pouvez pas créer d'objet PPI::Document::File "anonyme", ni en créer un vide.

Retourne un nouvel objet PPI::Document::File, ou "undef" en cas d'erreur.

save

# Sauvegarder dans le fichier à partir duquel nous avons été chargés
$file->save;

# Sauvegarder une copie ailleurs
$file->save( 'Module2.pm' );

La méthode "save" fonctionne de manière similaire à celle de la classe parente PPI::Document, sauvegardant une copie du document dans un fichier.

La différence avec cette sous-classe est que si "save" ne reçoit aucun nom de fichier, elle le sauvegardera dans le fichier à partir duquel il a été chargé.

Note : Lors de la sauvegarde dans un fichier différent, cela est considéré comme une sauvegarde d'une copie, et donc la valeur retournée par l'accesseur "filename" restera la même et ne changera pas pour le nouveau nom de fichier.

À FAIRE

- Peut nécessiter de surcharger certaines méthodes pour empêcher de force que les objets Document ne deviennent enfants d'un autre Nœud.
