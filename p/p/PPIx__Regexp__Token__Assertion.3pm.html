PPIx::Regexp::Token::Assertion(3) Documentation Perl fournie par l'utilisateur PPIx::Regexp::Token::Assertion(3)

NOM

PPIx::Regexp::Token::Assertion - Représente une assertion simple.

SYNOPSIS

use PPIx::Regexp::Dumper;
PPIx::Regexp::Dumper->new( 'qr{\bfoo\b}smx' )
    ->print();

HÉRITAGE

"PPIx::Regexp::Token::Assertion" est un PPIx::Regexp::Token.

"PPIx::Regexp::Token::Assertion" n'a pas de descendants.

DESCRIPTION

Cette classe représente l'une des assertions simples ; c'est-à-dire celles qui ne sont pas définies par des parenthèses. Cela inclut les assertions de largeur nulle "^", "$", "\b", "\B", "\A", "\Z", "\z" et "\G", ainsi que :

  • L'assertion "\z" ajoutée dans Perl 5.005,
  • L'assertion "\K" ajoutée dans Perl 5.009005,
  • L'assertion "\b{gcb}" (et ses similaires) ajoutée dans Perl 5.021009. Des constructions entre accolades similaires (comme "\b{foo}") sont des jetons inconnus.

MÉTHODES

Cette classe ne fournit pas de méthodes publiques au-delà de celles fournies par sa superclasse.

is_matcher

Cette méthode renvoie une valeur vraie car une assertion correspond réellement à quelque chose.
