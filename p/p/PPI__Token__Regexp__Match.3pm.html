NOM

PPI::Token::Regexp::Match - Une expression régulière de correspondance standard

HÉRITAGE

PPI::Token::Regexp::Match
isa PPI::Token::Regexp
    isa PPI::Token
        isa PPI::Element

SYNOPSIS

$texte =~ m/regexp de correspondance/;
$texte =~ /regexp de correspondance/;

DESCRIPTION

Un objet "PPI::Token::Regexp::Match" représente une expression régulière de correspondance unique. Juste pour être doublement clair, voici ce qui est et ce qui n'est **pas** considéré comme une expression régulière de correspondance.

# Est une expression régulière de correspondance
/Ceci est une expression régulière de correspondance/;
m/Old McDonald avait une ferme/eieio;

# Ce ne sont PAS des expressions régulières de correspondance
qr/Ceci est un opérateur de type quote pour expressions régulières/;
s/Ceci est un/expression régulière de remplacement/;

MÉTHODES

Il n'y a pas de méthodes disponibles pour "PPI::Token::Regexp::Match" au-delà de celles fournies par les classes parentes PPI::Token::Regexp, PPI::Token et PPI::Element.
