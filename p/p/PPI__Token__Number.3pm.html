PPI__Token__Number(3pm)

Paquet: perl-ppi

Licences: PerlArtistic

PPI::Token::Number(3) Documentation Perl fournie par l'utilisateur PPI::Token::Number(3)

NOM

PPI::Token::Number - Classe de jeton pour un nombre

SYNTAXE

$n = 1234;       # entier décimal
$n = 0b1110011;  # entier binaire
$n = 01234;      # entier octal
$n = 0x1234;     # entier hexadécimal
$n = 12.34e-56;  # notation exponentielle ( ne fonctionne pas actuellement )

HÉRITAGE

PPI::Token::Number
isa PPI::Token
    isa PPI::Element

DESCRIPTION

La classe "PPI::Token::Number" est utilisée pour les jetons qui représentent des nombres, dans les divers types que Perl supporte.

MÉTHODES

base

La méthode "base" est fournie par toutes les sous-classes de ::Number. C'est 10 pour le décimal, 16 pour l'hexadécimal, 2 pour le binaire, etc.

literal

Retourne la valeur numérique de ce jeton.

ATTENTION

Comparé à Perl, le tokenizer de nombres est trop libéral quant à l'autorisation des underscores n'importe où. Par exemple, ce qui suit est une erreur de syntaxe dans Perl, mais est autorisé dans PPI :

0_b10

À FAIRE

- Traiter les v-strings comme des chaînes binaires ou des barewords, pas comme des nombres "base-256"

- Diviser les entiers décimaux en leur propre sous-classe ?

- Implémenter literal()
