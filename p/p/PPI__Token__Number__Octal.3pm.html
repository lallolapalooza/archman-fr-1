NOM

PPI::Token::Number::Octal - Classe de jeton pour un nombre binaire

SYNTAXE

$n = 0777;      # entier octal

HÉRITAGE

PPI::Token::Number::Octal
isa PPI::Token::Number
    isa PPI::Token
        isa PPI::Element

DESCRIPTION

La classe "PPI::Token::Number::Octal" est utilisée pour les jetons représentant des nombres en base 8.

MÉTHODES

base

Retourne la base du nombre : 8.

literal

Retourne la valeur numérique de ce jeton.
