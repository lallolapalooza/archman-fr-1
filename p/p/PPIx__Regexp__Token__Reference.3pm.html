PPIx::Regexp::Token::Reference(3) Documentation Perl fournie par l'utilisateur PPIx::Regexp::Token::Reference(3)

NOM

PPIx::Regexp::Token::Reference - Représente une référence à une capture

SYNTAXE

use PPIx::Regexp::Dumper;
PPIx::Regexp::Dumper->new( 'qr{\1}smx' )
    ->print();

HÉRITAGE

"PPIx::Regexp::Token::Reference" est un PPIx::Regexp::Token.

"PPIx::Regexp::Token::Reference" est le parent de PPIx::Regexp::Token::Backreference, PPIx::Regexp::Token::Condition et PPIx::Regexp::Token::Recursion.

DESCRIPTION

Cette classe abstraite représente une référence à un tampon de capture, numéroté ou nommé. Elle ne doit jamais être instanciée, mais elle fournit un certain nombre de méthodes à ses sous-classes.

MÉTHODES

Cette classe fournit les méthodes publiques suivantes. Les méthodes non documentées ici sont privées et non prises en charge dans le sens où l'auteur se réserve le droit de les modifier ou de les supprimer sans préavis.

absolute

print "La référence absolue est ", $ref->absolute(), "\n";

Cette méthode renvoie le numéro absolu du tampon de capture référencé. C'est la même chose que number() pour les références numériques non signées. Si la référence est à un tampon nommé, "undef" est renvoyé.

is_named

$ref->is_named and print "référence nommée\n";

Cette méthode renvoie vrai si la référence est nommée plutôt que numérotée.

is_relative

$ref->is_relative()
    and print "référence numérotée relative\n";

Cette méthode renvoie vrai si la référence est numérotée et qu'il s'agit d'un numéro relatif (c'est-à-dire s'il est signé).

is_matcher

Cette méthode renvoie une valeur vraie car, bien que nous n'effectuions pas d'analyse sur l'entité référencée, nous supposons qu'elle correspond à quelque chose.

name

print "Le nom est ", $ref->name(), "\n";

Cette méthode renvoie le nom du tampon de capture référencé. Dans le cas d'une référence à une capture numérotée (c'est-à-dire si "is_named" renvoie faux), cette méthode renvoie "undef".

number

print "Le numéro est ", $ref->number(), "\n";

Cette méthode renvoie le numéro du tampon de capture référencé. Dans le cas d'une référence à une capture nommée (c'est-à-dire si "is_named" renvoie vrai), cette méthode renvoie "undef".
