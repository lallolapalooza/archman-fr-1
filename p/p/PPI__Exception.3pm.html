PPI::Exception(3) Documentation Perl fournie par la communauté PPI::Exception(3)

NOM

PPI::Exception - La classe de base des exceptions PPI

SYNOPSIS

use PPI::Exception;

my $e = PPI::Exception->new( 'quelque chose s'est passé' );
$e->throw;
PPI::Exception->new( message => 'quelque chose s'est passé' )->throw;
PPI::Exception->throw( message => 'quelque chose s'est passé' );

DESCRIPTION

Toutes les exceptions levées depuis l'intérieur de PPI seront des instances ou des dérivations de cette classe.

MÉTHODES

new $message | message => $message, ...

Construit et retourne un nouvel objet "PPI::Exception".

Un message pour l'exception peut être passé, soit sous forme de chaîne, soit sous forme de "message => $message". Le message est disponible via la méthode "message".

throw

Si appelée sur un objet "PPI::Exception", lève l'objet. Si appelée sur le nom de la classe, utilise les arguments pour construire un "PPI::Exception" puis le lever.

Chaque fois que l'objet est levé, des informations provenant de l'appel Perl <caller(0)> sont sauvegardées et rendues disponibles via la méthode "callers".

Cette méthode ne retourne jamais.

message

Retourne le message d'exception passé au constructeur de l'objet, ou un message par défaut.

callers

Retourne une référence de liste, dont chaque élément est une référence de liste d'informations de caller(0). La liste retournée peut être vide.
