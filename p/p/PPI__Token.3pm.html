Paquet: perl-ppi

PPI::Token(3) Documentation Perl Contribuée PPI::Token(3)

NOM

PPI::Token - un seul jeton de code source Perl

INHERITANCE

PPI::Token
isa PPI::Element

DESCRIPTION

"PPI::Token" est la classe de base abstraite pour tous les jetons. Dans les termes de PPI, un "jeton" est un "PPI::Element" qui représente directement des octets de code source.

MÉTHODES

définir_contenu $chaîne

La méthode "définir_contenu" vous permet de définir/modifier la chaîne que l'objet "PPI::Token" représente.

Retourne la chaîne à laquelle vous avez défini le jeton.

ajouter_contenu $chaîne

La méthode "ajouter_contenu" vous permet d'ajouter des octets de code supplémentaires à la fin du jeton.

Retourne la nouvelle chaîne complète après l'ajout des octets.

longueur

La méthode "longueur" retourne la longueur de la chaîne dans un jeton.
