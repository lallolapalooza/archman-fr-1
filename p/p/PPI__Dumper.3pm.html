PPI::Dumper(3) Documentation Perl fournie par l'utilisateur PPI::Dumper(3)

NOM

PPI::Dumper - Sauvegarde des arbres PDOM

SYNOPSIS

# Charger un document
my $Module = PPI::Document->new( 'MyModule.pm' );

# Créer le dump
my $Dumper = PPI::Dumper->new( $Module );

# Afficher le dump
$Dumper->print;

DESCRIPTION

Les arbres PDOM dans PPI sont assez complexes, et il est important d'obtenir une sauvegarde de leur structure à des fins de développement et de débogage.

Ce module fournit cette fonctionnalité.

Le processus est relativement simple. Créez un objet dumper avec un ensemble d'options particulier, puis appelez l'une des méthodes de dump pour générer le contenu du dump.

MÉTHODES

new $Élément, param => valeur, ...

Le constructeur "new" crée un dumper et prend comme argument un seul objet PPI::Element de n'importe quel type pour servir de racine de l'arbre à sauvegarder, ainsi qu'un certain nombre de paramètres clé-valeur pour contrôler le format de sortie du Dumper. Les détails des paramètres sont listés ci-dessous.

Retourne un nouvel objet "PPI::Dumper", ou "undef" si le constructeur ne reçoit pas un objet racine PPI::Element correct.

memaddr
Le dumper doit-il afficher les adresses mémoire de chaque élément PDOM ? Valeur vraie/fausse, désactivé par défaut.
indent
Les structures sauvegardées doivent-elles être indentées ? Cette valeur est numérique, le nombre représentant le nombre d'espaces à utiliser lors de l'indentation de la sortie du dumper. Défini à '2' par défaut.
class
Le dumper doit-il afficher la classe complète de chaque élément ? Valeur vraie/fausse, activé par défaut.
content
Le dumper doit-il afficher le contenu de chaque élément ? Valeur vraie/fausse, activé par défaut.
whitespace
Le dumper doit-il afficher les jetons d'espacement ? En ne montrant pas les nombreux jetons d'espacement, la structure du code peut souvent être rendue beaucoup plus claire. Valeur vraie/fausse, activé par défaut.
comments
Le dumper doit-il afficher les jetons de commentaire ? Dans les situations où vous avez beaucoup de commentaires, le code peut souvent être rendu plus clair en ignorant les jetons de commentaire. Valeur vraie/fausse, activé par défaut.
locations
Le dumper doit-il afficher l'emplacement de chaque jeton ? Les valeurs affichées sont [ ligne, caractère_colonne, colonne ]. Voir "location" dans PPI::Element pour une description de ce que sont réellement ces valeurs. Valeur vraie/fausse, désactivé par défaut.

print

La méthode "print" génère la sauvegarde et l'affiche sur STDOUT.

Retourne comme pour la fonction d'impression interne.

string

La méthode "string" génère la sauvegarde et la fournit sous forme d'une seule chaîne de caractères.

Retourne une chaîne ou undef s'il y a une erreur lors de la génération de la sauvegarde.

list

La méthode "list" génère la sauvegarde et la fournit sous forme d'une liste brute, sans sauts de ligne finaux.

Retourne une liste ou la liste nulle s'il y a une erreur lors de la génération de la sauvegarde.
