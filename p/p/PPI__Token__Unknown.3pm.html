NOM

PPI::Token::Unknown - Jeton de type inconnu ou indéterminé

HEREDITE

PPI::Token::Unknown
isa PPI::Token
    isa PPI::Element

DESCRIPTION

Les objets de type "PPI::Token::Unknown" existent principalement dans le tokenizer, où ils sont temporairement créés pendant une très courte durée pour représenter un jeton qui pourrait être de plusieurs types.

En général, ils n'existent que pendant un ou deux caractères, après quoi ils sont résolus et convertis dans le type correct. La survie d'un objet de ce type au processus d'analyse est considérée comme un bug majeur.

Veuillez signaler tout "PPI::Token::Unknown" que vous rencontrez dans un objet PPI::Document comme un bug.
