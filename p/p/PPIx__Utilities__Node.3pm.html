NOM

PPIx::Utilities::Node - Extensions à PPI::Node.

VERSION

Ce document décrit la version 1.1.0 de PPIx::Utilities::Node.

SYNOPSIS

use PPIx::Utilities::Node qw< split_ppi_node_by_namespace >;
my $dom = PPI::Document->new("...");
while (
    my ($namespace, $sub_doms) = each split_ppi_node_by_namespace($dom)
) {
    foreach my $sub_dom ( @{$sub_doms} ) {
        ...
    }
}

DESCRIPTION

Ceci est une collection de fonctions pour manipuler les PPI::Nodes.

INTERFACE

Rien n'est exporté par défaut.

split_ppi_node_by_namespace($node)

Retourne les sous-arbres pour chaque espace de noms dans le nœud sous la forme d'une référence à une table de hachage de références à des tableaux de PPI::Nodes. Supposons que nous ayons le code suivant :

#!perl
my $x = blah();
package Foo;
my $y = blah_blah();
{
    say 'Whee!';
    package Bar;
    something();
}
thingy();
package Baz;
da_da_da();
package Foo;
foreach ( blrfl() ) {
    ...
}

Appeler cette fonction sur un PPI::Document pour le code ci-dessus renvoie une valeur qui ressemble à ceci, en utilisant des littéraux de chaînes multi-lignes pour les parties de code réelles au lieu d'arbres PPI pour faciliter la lecture :

{
    main    => [
        q<
            #!perl
            my $x = blah();
        >,
    ],
    Foo     => [
        q<
            package Foo;
            my $y = blah_blah();
            {
                say 'Whee!';
            }
            thingy();
        >,
        q<
            package Foo;
            foreach ( blrfl() ) {
                ...
            }
        >,
    ],
    Bar     => [
        q<
            package Bar;
            something();
        >,
    ],
    Baz     => [
        q<
            package Baz;
            da_da_da();
        >,
    ],
}

Notez que la valeur de retour contient des copies des nœuds originaux, et non les nœuds originaux eux-mêmes en raison de la nécessité de gérer les espaces de noms qui ne sont pas au niveau du fichier. (Remarquez comment le premier élément pour « Foo » ci-dessus diffère du code original.)
