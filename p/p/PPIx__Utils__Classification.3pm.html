NOM

PPIx::Utils::Classification - Fonctions utilitaires pour la classification des éléments PPI

SYNTAXE

use PPIx::Utils::Classification ':all';

DESCRIPTION

Ce paquet est un composant de PPIx::Utils qui contient des fonctions pour la classification des éléments PPI.

FONCTIONS

Toutes les fonctions peuvent être importées par nom, ou avec le tag ":all".

est_operateur_assignation

my $bool = est_operateur_assignation($element);

Étant donné un PPI::Token::Operator ou une chaîne de caractères, renvoie vrai si ce token représente l'un des opérateurs d'affectation (par exemple "= &&= ||= //= += -=" etc.).

est_global_perl

my $bool = est_global_perl($element);

Étant donné un PPI::Token::Symbol ou une chaîne de caractères, renvoie vrai si ce token représente l'une des variables globales fournies par le module English, ou l'une des variables globales intégrées comme %SIG, %ENV, ou @ARGV. Le sigil sur le symbole est ignoré, donc des choses comme $ARGV ou $ENV renverront toujours vrai.

est_builtin_perl

my $bool = est_builtin_perl($element);

Étant donné un PPI::Token::Word, PPI::Statement::Sub, ou une chaîne de caractères, renvoie vrai si ce token représente un appel à l'une des fonctions intégrées définies dans Perl 5.8.8.

est_motcle_perl

my $bool = est_motcle_perl($element);

Étant donné un PPI::Token::Word, PPI::Statement::Sub, ou une chaîne de caractères, renvoie vrai si ce token représente un mot-clé (par exemple, "if", "else", "sub", "package") défini dans Perl 5.8.8.

est_fichier_perl

my $bool = est_fichier_perl($element);

Étant donné un PPI::Token::Word, ou une chaîne de caractères, renvoie vrai si ce token représente l'un des descripteurs de fichiers globaux (par exemple, "STDIN", "STDERR", "STDOUT", "ARGV") qui sont définis dans Perl 5.8.8. Notez que cette fonction renverra faux si elle reçoit un descripteur de fichier représenté comme un glob de type (par exemple, *STDIN)

est_builtin_perl_contexte_liste

my $bool = est_builtin_perl_contexte_liste($element);

Étant donné un PPI::Token::Word, PPI::Statement::Sub, ou une chaîne de caractères, renvoie vrai si ce token représente un appel à l'une des fonctions intégrées définies dans Perl 5.8.8 qui fournissent un contexte de liste aux tokens suivants.

est_builtin_perl_multi_arguments

my $bool = est_builtin_perl_multi_arguments($element);

Étant donné un PPI::Token::Word, PPI::Statement::Sub, ou une chaîne de caractères, renvoie vrai si ce token représente un appel à l'une des fonctions intégrées définies dans Perl 5.8.8 qui peuvent prendre plusieurs arguments.

est_builtin_perl_sans_arguments

my $bool = est_builtin_perl_sans_arguments($element);

Étant donné un PPI::Token::Word, PPI::Statement::Sub, ou une chaîne de caractères, renvoie vrai si ce token représente un appel à l'une des fonctions intégrées définies dans Perl 5.8.8 qui ne peuvent prendre aucun argument.

est_builtin_perl_un_argument

my $bool = est_builtin_perl_un_argument($element);

Étant donné un PPI::Token::Word, PPI::Statement::Sub, ou une chaîne de caractères, renvoie vrai si ce token représente un appel à l'une des fonctions intégrées définies dans Perl 5.8.8 qui prend un et un seul argument.

est_builtin_perl_argument_optionnel

my $bool = est_builtin_perl_argument_optionnel($element);

Étant donné un PPI::Token::Word, PPI::Statement::Sub, ou une chaîne de caractères, renvoie vrai si ce token représente un appel à l'une des fonctions intégrées définies dans Perl 5.8.8 qui prend pas plus d'un argument.

Les ensembles de valeurs pour lesquels "est_builtin_perl_multi_arguments", "est_builtin_perl_sans_arguments", "est_builtin_perl_un_argument", et "est_builtin_perl_argument_optionnel" renvoient vrai sont disjoints et leur union est précisément l'ensemble des valeurs pour lesquelles "est_builtin_perl" renverra vrai.

est_builtin_perl_zero_ou_un_arguments

my $bool = est_builtin_perl_zero_ou_un_arguments($element);

Étant donné un PPI::Token::Word, PPI::Statement::Sub, ou une chaîne de caractères, renvoie vrai si ce token représente un appel à l'une des fonctions intégrées définies dans Perl 5.8.8 qui prend zéro et/ou un argument.

Renvoie vrai si l'une des fonctions "est_builtin_perl_sans_arguments", "est_builtin_perl_un_argument", et "est_builtin_perl_argument_optionnel" renvoie vrai.

est_nom_qualifie

my $bool = est_nom_qualifie($name);

Étant donné une chaîne de caractères, un PPI::Token::Word, ou un PPI::Token::Symbol, répond si elle a un composant de module, c'est-à-dire contient "::".

est_cle_hash

my $bool = est_cle_hash($element);

Étant donné un PPI::Element, renvoie vrai si l'élément est une clé de hash littérale. PPI ne distingue pas entre les mots-clés ordinaires (comme les mots-clés ou les appels de sous-routine) et les mots-clés dans les sous-éléments de hash (qui sont considérés comme littéraux). Cette sous-routine est donc utile si votre politique recherche des éléments PPI::Token::Word et que vous souhaitez filtrer la variété des sous-éléments de hash. Dans les deux exemples suivants, "foo" est considéré comme une clé de hash :

$hash1{foo} = 1;
%hash2 = (foo => 1);

Mais si le mot-clé est suivi d'une liste d'arguments, alors perl le traite comme un appel de fonction. Donc, dans ces exemples, "foo" n'est pas considéré comme une clé de hash :

$hash1{ foo() } = 1;
&hash2 = (foo() => 1);

est_module_inclus

my $bool = est_module_inclus($element);

Étant donné un PPI::Token::Word, renvoie vrai si l'élément est le nom d'un module qui est inclus via "use", "require", ou "no".

est_entier

my $bool = est_entier($value);

Répond si le paramètre, en tant que chaîne de caractères, ressemble à une valeur entière.

est_nom_classe

my $bool = est_nom_classe($element);

Étant donné un PPI::Token::Word, renvoie vrai si l'élément qui suit immédiatement cet élément est l'opérateur de déréférencement "->". Lorsqu'un mot-clé a un "->" sur le côté droit, cela signifie généralement qu'il s'agit du nom de la classe (à partir de laquelle une méthode est appelée).

NOM

PPIx::Utils::Classification - Fonctions d'aide à la classification des éléments PPI.

SYNOPIS

  use PPIx::Utils::Classification qw(
      is_in_void_context
      is_method_call
      is_package_declaration
      is_subroutine_name
      is_function_call
      is_unchecked_call
      is_ppi_expression_or_generic_statement
      is_ppi_generic_statement
      is_ppi_statement_subclass
      is_ppi_simple_statement
      is_ppi_constant_element
      is_subroutine_declaration
      is_in_subroutine
  );

DESCRIPTION

Cette distribution fournit un ensemble de fonctions d'aide pour la classification des éléments PPI (Perl::Critic::Parse::Element).

FONCTIONS

is_label_pointer

my $bool = is_label_pointer($element);

Retourne vrai si l'élément est le label dans une instruction "next", "last", "redo", ou "goto". Notez que ce n'est pas la même chose que la déclaration de label.

is_method_call

my $bool = is_method_call($element);

Étant donné un PPI::Token::Word, retourne vrai si l'élément qui précède immédiatement cet élément est l'opérateur de déréférencement "->". Lorsqu'un bareword a un "->" du côté gauche, cela signifie généralement qu'il s'agit du nom d'une méthode (qui est appelée à partir d'une classe).

is_package_declaration

my $bool = is_package_declaration($element);

Étant donné un PPI::Token::Word, retourne vrai si l'élément est le nom d'un package qui est déclaré.

is_subroutine_name

my $bool = is_subroutine_name($element);

Étant donné un PPI::Token::Word, retourne vrai si l'élément est le nom d'une déclaration de sous-routine. Ceci est utile pour distinguer les barewords des appels de fonction par rapport aux déclarations de sous-routines.

is_function_call

my $bool = is_function_call($element);

Étant donné un PPI::Token::Word, retourne vrai si l'élément apparaît comme un appel à une fonction statique. Spécifiquement, cette fonction retourne vrai si "is_hash_key", "is_method_call", "is_subroutine_name", "is_included_module_name", "is_package_declaration", "is_perl_bareword", "is_perl_filehandle", "is_label_pointer" et "is_subroutine_name" retournent tous faux pour l'élément donné.

is_in_void_context

my $bool = is_in_void_context($token);

Étant donné un PPI::Token, répond si celui-ci semble être dans un contexte vide.

is_unchecked_call

my $bool = is_unchecked_call($element);

Étant donné un PPI::Element, teste pour voir s'il contient un appel de fonction dont la valeur de retour n'est pas vérifiée.

is_ppi_expression_or_generic_statement

my $bool = is_ppi_expression_or_generic_statement($element);

Répond si le paramètre est une expression ou une instruction indifférenciée. C'est-à-dire, soit le paramètre est un PPI::Statement::Expression, soit la classe du paramètre est PPI::Statement et non l'une de ses sous-classes autres que "Expression".

is_ppi_generic_statement

my $bool = is_ppi_generic_statement($element);

Répond si le paramètre est une instruction indifférenciée, c'est-à-dire, si le paramètre est un PPI::Statement mais pas l'une de ses sous-classes.

is_ppi_statement_subclass

my $bool = is_ppi_statement_subclass($element);

Répond si le paramètre est une instruction spécialisée, c'est-à-dire, si le paramètre est un PPI::Statement mais que la classe du paramètre n'est pas PPI::Statement.

is_ppi_simple_statement

my $bool = is_ppi_simple_statement($element);

Répond si le paramètre représente une instruction simple, c'est-à-dire, si le paramètre est un PPI::Statement, PPI::Statement::Break, PPI::Statement::Include, PPI::Statement::Null, PPI::Statement::Package, ou PPI::Statement::Variable.

is_ppi_constant_element

my $bool = is_ppi_constant_element($element);

Répond si le paramètre représente une valeur constante, c'est-à-dire, si le paramètre est un PPI::Token::Number, PPI::Token::Quote::Literal, PPI::Token::Quote::Single, ou PPI::Token::QuoteLike::Words, ou s'il s'agit d'un PPI::Token::Quote::Double ou PPI::Token::Quote::Interpolate qui ne contient en fait aucune variable interpolée.

Cette sous-routine n'interprète pas les formes de here-documents comme des valeurs constantes, et pourrait ne pas le faire tant que PPI::Token::HereDoc n'aura pas acquis les parties pertinentes de l'interface PPI::Token::Quote.

Cette sous-routine n'interprète pas non plus les entités créées par le module ReadonlyX (ou similaire) ou le pragma constant comme des constantes.

is_subroutine_declaration

my $bool = is_subroutine_declaration($element);

Le paramètre est-il une déclaration de sous-routine, nommée ou non ?

is_in_subroutine

my $bool = is_in_subroutine($element);

Le paramètre est-il une sous-routine ou à l'intérieur d'une sous-routine ?
