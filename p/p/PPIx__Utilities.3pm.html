PPIx::Utilities(3) Documentation Perl fournie par l'utilisateur PPIx::Utilities(3)

NOM

PPIx::Utilities - Extensions à PPI.

VERSION

Ce document décrit la version 1.1.0 de PPIx::Utilities.

SYNOPSIS

Ce module ne fait rien d'autre que servir de porte d'entrée pour la distribution PPIx-Utilities.

DESCRIPTION

Ceci est une collection de fonctions pour manipuler des objets PPI, dont beaucoup sont originaires de Perl::Critic. Elles sont organisées en modules selon le type de classe PPI auquel elles se rapportent, en remplaçant "PPI" au début du nom du module par "PPIx::Utilities", par exemple la fonctionnalité liée aux Nœuds PPI est dans PPIx::Utilities::Node.

INTERFACE

Aucune.

BOGUES ET LIMITATIONS

Veuillez signaler tout bogue ou demande de fonctionnalité à "bug-ppix-utilities@rt.cpan.org", ou via l'interface web à l'http://rt.cpan.org.
