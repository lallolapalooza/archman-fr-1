NOM

PPIx::Regexp::Token::Greediness - Représente un qualificateur de gourmandise.

SYNTAXE

use PPIx::Regexp::Dumper;
PPIx::Regexp::Dumper->new( 'qr{foo*+}smx' )
    ->print();

HÉRITAGE

"PPIx::Regexp::Token::Greediness" est un PPIx::Regexp::Token.

"PPIx::Regexp::Token::Greediness" n'a pas de descendants.

DESCRIPTION

Cette classe représente un qualificateur de gourmandise pour le quantificateur précédent.

MÉTHODES

Cette classe fournit les méthodes publiques suivantes. Les méthodes non documentées ici sont privées et non prises en charge dans le sens où l'auteur se réserve le droit de les modifier ou de les supprimer sans préavis.

peut_être_une_gourmandise

PPIx::Regexp::Token::Greediness->could_be_greediness( '?' );

Cette méthode renvoie vrai si la chaîne donnée peut être un indicateur de gourmandise ; c'est-à-dire, si c'est '+' ou '?'.
