PPI::Token::Attribute(3) Documentation Perl fournie par l'utilisateur PPI::Token::Attribute(3)

NOM

PPI::Token::Attribute - Un jeton pour un attribut de sous-routine

HEREDITE

PPI::Token::Attribute
isa PPI::Token
    isa PPI::Element

DESCRIPTION

En Perl, les attributs sont une addition relativement récente au langage.

Étant donné le code " sub foo : bar(something) {} ", la partie bar(something) est l'attribut.

Un jeton "PPI::Token::Attribute" représente l'intégralité de l'attribut, car les parenthèses et leur contenu ne sont pas analysés dans l'arbre, et sont traités par Perl (et donc par nous) comme une seule chaîne de caractères.

METHODES

Cette classe fournit des méthodes supplémentaires par rapport à celles fournies par ses classes parentes PPI::Token et PPI::Element.

identifiant

L'attribut "identifier" retourne la partie identifiant de l'attribut.

C'est-à-dire, pour l'attribut foo(bar), la méthode "identifier" retournerait "foo".

paramètres

La méthode "parameters" retourne la chaîne de paramètres pour l'attribut.

C'est-à-dire, pour l'attribut foo(bar), la méthode "parameters" retournerait "bar".

Retourne les paramètres sous forme de chaîne (y compris la chaîne nulle '' pour le cas d'un attribut tel que foo().)

Retourne "undef" si l'attribut n'a pas de paramètres.
