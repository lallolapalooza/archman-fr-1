PPIx::QuoteLike::Token::Delimiter(3) Documentation Perl Contribuée PPIx::QuoteLike::Token::Delimiter(3)

perl_version_introduced

L'expérimentation avec des délimiteurs étranges montre qu'ils n'ont pas fonctionné avant Perl 5.8.3, nous retournons donc '5.008003' pour de tels délimiteurs.

perl_version_removed

Perl 5.29.0 a rendu fatale l'utilisation de graphèmes non autonomes comme délimiteurs de chaînes. Étant donné que les non-caractères et les points de code jamais assignés sont toujours autorisés selon perldeprecation, j'interprète cela comme les caractères qui correspondent à "/\p{Mark}/" (c'est-à-dire les marques diacritiques combinatoires). Mais cette expression régulière ne compile pas sous Perl 5.6.

Donc :

Cette méthode retourne '5.029' pour de tels délimiteurs, à condition que l'expression régulière requise compile. Sinon, elle retourne "undef".

NOM

PPIx::QuoteLike::Token::Delimiter - Représenter un délimiteur de chaîne

SYNOPSIS

Cette classe ne doit pas être instanciée par l'utilisateur. Voir ci-dessous pour les méthodes publiques.

HÉRITAGE

"PPIx::QuoteLike::Token::Delimiter" est un PPIx::QuoteLike::Token.

"PPIx::QuoteLike::Token::Delimiter" n'a pas de descendants.

DESCRIPTION

Ce jeton représente les délimiteurs de la chaîne.

MÉTHODES

Cette classe ne prend en charge aucune méthode publique en plus de celles de sa superclasse.

VOIR AUSSI

PPIx::QuoteLike::Token.
