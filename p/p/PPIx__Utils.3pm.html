NOM

PPIx::Utils - Fonctions utilitaires pour PPI

SYNTAXE

use PPIx::Utils qw(:classification :language :traversal);

DESCRIPTION

"PPIx::Utils" est une collection de fonctions utilitaires pour travailler avec des documents PPI. Les fonctions sont organisées en sous-modules et peuvent être importées depuis le sous-module approprié ou via ce module.

Ces fonctions proviennent à l'origine de Perl::Critic::Utils et de modules associés, et ont été détachées dans cette distribution pour être utilisées en dehors de Perl::Critic.

MODULES

Le tag d'importation ":all" importera les fonctions de tous les modules listés ci-dessous.

PPIx::Utils::Classification

Fonctions relatives à la classification des éléments PPI. Toutes les fonctions de ce module peuvent être importées avec le tag d'importation ":classification".

PPIx::Utils::Language

Fonctions relatives au langage Perl. Toutes les fonctions de ce module peuvent être importées avec le tag d'importation ":language".

PPIx::Utils::Traversal

Fonctions relatives à la traversée des documents PPI. Toutes les fonctions de ce module peuvent être importées avec le tag d'importation ":traversal".
