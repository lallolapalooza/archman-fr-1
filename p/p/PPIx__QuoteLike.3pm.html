PPIx__QuoteLike(3pm)

Paquet: perl-ppix-quotelike

Licences: PerlArtistic

PPIx::QuoteLike(3) Documentation Perl fournie par l'utilisateur PPIx::QuoteLike(3)

NOM

PPIx::QuoteLike - Analyse les littéraux de chaînes Perl et les choses similaires.

SYNTAXE

use PPIx::QuoteLike;
my $str = PPIx::QuoteLike->new( q<"fu$bar"> );
say $str->interpolates() ?
   'interpolates' :
   'does not interpolate';

DESCRIPTION

Cette classe Perl analyse les littéraux de chaînes Perl et les éléments qui leur ressemblent raisonnablement. Sa véritable raison d'être est de trouver les variables interpolées pour les politiques de Perl::Critic et des usages similaires.

L'analyse est assez simple, et un peu d'exploration avec eg/pqldump devrait montrer comment cela se passe normalement.

Mais il existe au moins une chose ressemblant à une chaîne qui nécessite probablement quelques explications.

Documents intercalés

Ceux-ci ont été introduits dans Perl 5.25.7 (novembre 2016) mais n'ont été reconnus par ce module qu'à partir de sa version 0.015 (février 2021). L'indentation est analysée comme des objets PPIx::QuoteLike::Token::Whitespace, à condition qu'elle soit large d'au moins un caractère, sinon elle n'est pas représentée dans l'analyse. Autrement dit,

<<~EOD
    How doth the little crocodile
    Improve his shining tail
    EOD

aura les trois indentations représentées par des objets d'espacement et chaque ligne du littéral représentée par son propre objet chaîne, mais

<<~EOD
How doth the little crocodile
Improve his shining tail
EOD

sera analysé de la même manière que la version non indentée, à l'exception de l'ajout du jeton représentant le '~'.

PPI est en avance sur ce module, et a reconnu les documents intercalés dès sa version 1.246 (mai 2019). Malheureusement, à partir de la version 1.270, l'indentation est perdue lors de l'analyse, de sorte qu'un objet "PPIx::QuoteLike" initialisé à partir d'un tel PPI::Token::HereDoc sera vu comme ayant une indentation de '' quelle que soit l'indentation réelle dans la source. Je pense que cette restriction disparaîtra lorsque https://github.com/Perl-Critic/PPI/issues/251 sera résolu.

AVIS DE DÉPRÉCATION

L'argument "postderef" de new() est en cours de dépréciation et sera retiré. Après son retrait, les déréférencements postfixés seront toujours reconnus.

À partir de la version 0.012_01, la première utilisation de cet argument a généré un avertissement. Avec la version 0.016_01, toutes les utilisations génèrent un avertissement. Avec la version 0.017_01, toutes les utilisations sont fatales. Avec la version 0.0.021_01, toute mention de cet argument est supprimée, sauf bien sûr cet avis.

HÉRITAGE

"PPIx::QuoteLike" n'est pas hérité d'une autre classe.

"PPIx::QuoteLike" n'a pas de descendants.

MÉTHODES

Cette classe prend en charge les méthodes publiques suivantes :

new

my $str = PPIx::QuoteLike->new( $source, %arg );

Cette méthode statique analyse l'argument et retourne un nouvel objet contenant l'analyse. L'argument $source peut être une chaîne scalaire ou un objet PPI::Element approprié.

Si l'argument $source est une chaîne scalaire, il est présumé représenter un littéral de type chaîne de caractères, à condition qu'il commence comme tel. Sinon, cette méthode ne retournera rien. La représentation scalaire d'un here document est une chaîne multiligne dont la première ligne est constituée des " << " et du délimiteur de début, et dont les lignes suivantes sont constituées du contenu du here document et du délimiteur de fin. Les documents intercalés n'étaient pas supportés par cette classe avant la version 0.015.

Les classes "PPI" qui peuvent être gérées sont PPI::Token::Quote, PPI::Token::QuoteLike::Backtick, PPI::Token::QuoteLike::Command, PPI::Token::QuoteLike::Readline, et PPI::Token::HereDoc. Tout autre objet amènera new() à retourner rien.

Des arguments optionnels supplémentaires peuvent être passés sous forme de paires nom/valeur. Les arguments supportés sont :

encoding
Il s'agit de l'encodage de $source. Si cela est spécifié comme autre chose que "undef", le $source sera décodé avant le traitement.

Si $source est un "PPI::Element", cet encodage n'est utilisé que si le document qui contient l'élément n'a ni marque d'ordre des octets ni 'use utf8'.

index_locations
Cet argument booléen détermine si les emplacements des jetons doivent être calculés. Il vaut par défaut vrai si l'argument $source est un PPI::Element ou si l'argument "location" a été fourni, et faux sinon.
location
Cet argument est une référence à un tableau compatible avec celui retourné par la méthode location() de PPI::Element. Il vaut par défaut l'emplacement de l'argument $source si celui-ci était un PPI::Element, sinon aucun emplacement ne sera disponible.
trace
Cet argument booléen provoque l'écriture d'une trace de l'analyse sur la sortie standard. Définir cette valeur sur vrai n'est pas supporté dans le sens où l'auteur ne fait aucune déclaration sur ce qui se passera si vous le faites, et se réserve le droit d'apporter des modifications à la fonctionnalité, ou de la retirer complètement, sans préavis.

Tous les autres arguments ne sont pas supportés et sont réservés à l'auteur.

child

my $kid = $str->child( 0 );

Cette méthode retourne l'élément enfant dont l'indice est donné en argument. Les enfants n'incluent pas le type(), ni les délimiteurs de start() ou finish(). Les indices négatifs sont valides, et avec l'interprétation Perl habituelle.

children

my @kids = $str->children();

Cette méthode retourne tous les éléments enfants. Les enfants n'incluent pas le type(), ni les délimiteurs de start() ou finish().

column_number

Cette méthode retourne le numéro de colonne du premier caractère de l'élément, ou "undef" si cela ne peut être déterminé.

content

say $str->content();

Cette méthode retourne le contenu de l'objet. Si l'argument original était une chaîne Perl valide, cela devrait être identique à la chaîne analysée à l'origine.

delimiters

say $str->delimiters();

Cette méthode retourne les délimiteurs de l'objet, sous forme de chaîne. Ce sera deux caractères, sauf si l'argument de new() était un here document, manquant son délimiteur de fin, ou une chaîne invalide. Dans ce dernier cas, le retour peut être n'importe quoi.

elements

my @elem = $str->elements();

Cette méthode retourne tous les éléments de l'objet. Cela inclut type(), start(), children(), et finish(), dans cet ordre.

failures

say $str->failures();

Cette méthode retourne le nombre d'échecs d'analyse rencontrés. Ce sont des instances où l'analyseur n'a pas pu comprendre ce qui se passait, et devrait être identique au nombre d'objets PPIx::QuoteLike::Token::Unknown retournés par elements().

find

print map { $_->content() } $str->find();

Cette méthode trouve et renvoie une référence à un tableau de tous les éléments qui correspondent au critère donné. Si rien n'est trouvé, une valeur fausse est renvoyée.

Le $criteria peut être soit le nom d'une classe PPIx::QuoteLike::Token, soit une référence à un code. Dans le cas de la seconde option, le code est appelé pour chaque élément dans elements(), avec l'élément comme seul argument. L'élément est inclus dans la sortie si le code renvoie une valeur vraie.

finish

print map { $_->content() } $str->finish();

Cette méthode renvoie les éléments finaux de l'analyse. C'est en fait un tableau, dont le premier élément est un PPIx::QuoteLike::Token::Delimiter. Si l'analyse concerne un here document, il y aura un deuxième élément, qui sera un PPIx::QuoteLike::Token::Whitespace contenant le caractère de nouvelle ligne final.

Si appelée dans un contexte de liste, vous obtenez le tableau complet. Si appelée dans un contexte scalaire, vous obtenez l'élément dont l'indice est donné en argument, ou l'élément zéro si aucun argument n'est spécifié.

handles

print PPIx::QuoteLike::handles( $string ) ? "We can handle $string" : "We can not handle $string";

Cette méthode statique est disponible et renvoie une valeur vraie si ce package peut s'attendre à gérer le contenu de $string (qu'il soit scalaire ou objet), et une valeur fausse sinon.

indentation

Cette méthode renvoie la chaîne d'indentation si l'objet représente un here document indenté, ou "undef" s'il représente autre chose, y compris un here document non indenté.

Notez que si la syntaxe d'indentation est utilisée mais que le here document n'est pas réellement indenté, cette méthode renverra '', qui s'évalue à faux.

interpolates

print $str->interpolates() ? "The string interpolates" : "The string does not interpolate";

Cette méthode renvoie une valeur vraie si la chaîne analysée s'interpole, et une valeur fausse si ce n'est pas le cas. Cela n'indique pas si une interpolation a réellement lieu, seulement si la chaîne est entre guillemets doubles ou simples.

line_number

Cette méthode renvoie le numéro de ligne du premier caractère de l'élément, ou "undef" si cela ne peut pas être déterminé.

location

Cette méthode renvoie une référence à un tableau décrivant la position de la chaîne, ou "undef" si la localisation n'est pas disponible.

Le tableau est compatible avec la méthode correspondante de PPI::Element.

logical_filename

Cette méthode renvoie le nom de fichier logique (en tenant compte des directives "#line") du fichier contenant le premier caractère de l'élément, ou "undef" si cela ne peut pas être déterminé.

logical_line_number

Cette méthode renvoie le numéro de ligne logique (en tenant compte des directives "#line") du premier caractère de l'élément, ou "undef" si cela ne peut pas être déterminé.

parent

Cette méthode ne renvoie rien, car l'appelant est utilisé uniquement au sommet de la hiérarchie de l'objet.

perl_version_introduced

Cette méthode renvoie la valeur maximale de "perl_version_introduced" renvoyée par l'un de ses éléments. En d'autres termes, elle renvoie la version minimale de Perl sous laquelle cet objet de type quote-like est valide. S'il n'y a pas d'éléments, 5.000 est renvoyé, car c'est la version minimale de Perl prise en charge par ce package.

perl_version_removed

Cette méthode renvoie la valeur minimale définie de "perl_version_removed" renvoyée par l'un des objets de type quote-like. En d'autres termes, elle renvoie la version la plus basse de Perl dans laquelle cet objet n'est "pas" valide. S'il n'y a pas d'éléments, ou si aucun élément n'a défini "perl_version_removed", "undef" est renvoyé.

schild

my $skid = $str->schild( 0 );

Cette méthode renvoie les éléments enfants significatifs dont l'indice est spécifié en argument. Les indices négatifs sont interprétés de manière habituelle.

schildren

my @skids = $str->schildren();

Cette méthode renvoie les enfants significatifs.

source

my $source = $str->source();

Cette méthode renvoie l'argument $source à new(), quelle que soit sa valeur.

start

print map { $_->content() } $str->start();

Cette méthode renvoie les éléments de début de l'analyse. C'est en fait un tableau, dont le premier élément est un PPIx::QuoteLike::Token::Delimiter. Si l'analyse concerne un here document, il y aura un deuxième élément, qui sera un PPIx::QuoteLike::Token::Whitespace contenant le caractère de nouvelle ligne final.

Si appelée dans un contexte de liste, vous obtenez le tableau complet. Si appelée dans un contexte scalaire, vous obtenez l'élément dont l'indice est donné en argument, ou l'élément zéro si aucun argument n'est spécifié.

statement

Cette méthode renvoie le PPI::Statement qui contient cette chaîne, ou rien si le statement ne peut pas être déterminé.

En général, cette méthode renverra quelque chose seulement sous les conditions suivantes :

  • La chaîne est contenue dans un objet PPIx::QuoteLike;
  • L'objet a été initialisé à partir d'un PPI::Element;
  • Le PPI::Element est contenu dans un statement.

top

Cette méthode renvoie le sommet de la hiérarchie - dans ce cas, l'appelant.

type

my $type = $str->type();

Cette méthode renvoie l'objet de type. Ce sera un PPIx::QuoteLike::Token::Structure si l'analyse a réussi; sinon, cela pourrait être "undef". Son contenu sera tout ce qui précède le délimiteur initial, et sera typiquement 'q', 'qq', 'qx', << (pour les here documents), ou "'' (pour les chaînes entre guillemets).

Les données de type forment en réalité un tableau. Si le deuxième élément est présent, ce sera l'espace blanc (le cas échéant) qui sépare le type réel de sa valeur. Si appelée dans un contexte de liste, vous obtenez le tableau complet. Si appelée dans un contexte scalaire, vous obtenez l'élément dont l'indice est donné en argument, ou l'élément zéro si aucun argument n'est spécifié.

variables

print "Interpolates $_" for $str->variables();

NOTEZ que cette méthode est déconseillée et peut être obsolète et supprimée. J'ai deux problèmes avec elle. Le premier est qu'elle renvoie des noms de variables au lieu d'objets PPI::Element, vous laissant ignorer comment les variables sont utilisées. Le second est qu'elle ne gère pas correctement des éléments comme "${^CAPTURE[0]}", et il semble impossible de la rendre correcte. Elle a été initialement écrite pour le bénéfice de Perl::Critic::Policy::Variables::ProhibitUnusedVarsStricter, mais s'est avérée insuffisante pour les exigences de cette politique.

Cette méthode de commodité renvoie toutes les variables interpolées. Chacune n'est renvoyée qu'une seule fois et elles sont renvoyées dans aucun ordre particulier. Si l'objet ne représente pas une chaîne qui s'interpole, rien n'est renvoyé.

visual_column_number

Cette méthode renvoie le numéro de colonne visuel (en tenant compte des tabulations) du premier caractère de l'élément, ou "undef" si cela ne peut pas être déterminé.

RESTRICTIONS

Par la nature de ce module, vous n'obtiendrez jamais tout correctement. Beaucoup des domaines de problèmes connus impliquent des interpolations dans tous les sens.

Changements de syntaxe

Parfois, l'introduction de nouvelles syntaxes change la façon dont une chaîne est analysée. Par exemple, le "\F" (contrôle de casse) a été introduit dans Perl 5.15.8. Cependant, il ne représentait pas une erreur de syntaxe avant cette version, il était simplement analysé comme "F". C'est pourquoi :

$ perl -le 'print "Foo\FBar"'

affiche "FooFBar" sous Perl 5.14.4, mais "Foobar" sous 5.16.0. "PPIx::QuoteLike" suppose généralement l'analyse la plus moderne dans de tels cas.

Analyse statique

Il est bien connu que Perl ne peut pas être analysé statiquement. C'est-à-dire, vous ne pouvez pas complètement analyser un bloc de code Perl sans exécuter le code lui-même.

Cependant, cette classe tente de faire une analyse statique.

NOM

PPIx::QuoteLike

SYNOPIS

use PPIx::QuoteLike;

DESCRIPTION

PPIx::QuoteLike est un module qui fournit des fonctionnalités pour l'analyse et la manipulation des expressions de type guillemet en Perl. Il est conçu pour reconnaître et traiter divers types de contenu entre guillemets, tels que les chaînes de caractères, les variables, et plus encore, d'une manière cohérente avec la syntaxe de Perl. Le module vise à fournir une interface robuste et flexible pour travailler avec le contenu entre guillemets dans le code Perl.

AVIS DE DEPRECATION

Ce module est déprécié. Veuillez utiliser la dernière version disponible.

HERITAGE

PPIx::QuoteLike hérite de PPIx::Base.

METHODES

Les méthodes suivantes sont disponibles :

  • quote_like()

  • quote_like_str()

  • quote_like_var()

RESTRICTIONS

Depuis la version 0.015 de ce module, la seule instance connue est la gestion des here documents indentés, comme discuté ci-dessus sous la rubrique Here Documents Indentés.
