NOM

PPI::Structure::Unknown - Une structure d'accolades inconnue ou non résolue

HÉRITAGE

PPI::Structure::Unknown
isa PPI::Structure
    isa PPI::Node
        isa PPI::Element

DESCRIPTION

"PPI::Structure::Unknown" est une classe pour les accolades dont le type est inconnu, ou temporairement inconnu.

Elle existe principalement temporairement dans le lexer. Bien que certains types d'accolades puissent être déterminés immédiatement à l'ouverture, il existe un certain nombre de types d'accolades qui ne peuvent être correctement identifiés qu'après la fermeture des accolades.

Une structure est typée comme inconnue pendant cette période où elle est indéterminée.

Un objet "PPI::Structure::Unknown" ne devrait jamais sortir du lexer sans être converti à son type final. Chaque fois que vous rencontrez cette classe dans un arbre PDOM, cela devrait être considéré comme un bug et signalé en conséquence.

MÉTHODES

"PPI::Structure::Unknown" n'a pas de méthodes au-delà de celles fournies par les méthodes standard PPI::Structure, PPI::Node et PPI::Element.
