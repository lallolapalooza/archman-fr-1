PPI::Token::Regexp(3) Documentation Perl fournie par l'utilisateur PPI::Token::Regexp(3)

NOM

PPI::Token::Regexp - Classe de base abstraite pour les expressions régulières

HIÉRARCHIE

PPI::Token::Regexp
isa PPI::Token
    isa PPI::Element

DESCRIPTION

La classe "PPI::Token::Regexp" n'est jamais instanciée et fournit simplement une classe de base abstraite commune pour les trois classes d'expressions régulières. Celles-ci sont :

m// - PPI::Token::Regexp::Match
s/// - PPI::Token::Regexp::Substitute
tr/// - PPI::Token::Regexp::Transliterate

Les noms sont, espérons-le, suffisamment explicites pour ne pas avoir à expliquer ce que fait chaque classe. Voir leurs pages pour plus de détails.

Pour éviter une certaine confusion, il est utile de souligner ici que "qr//" n'est **pas** une expression régulière (ce que PPI entend par quelque chose qui examinera ou modifiera effectivement une chaîne), mais plutôt un opérateur de type quote qui agit comme un constructeur pour des objets Regexp compilés.

MÉTHODES

Les méthodes suivantes sont héritées par les descendants de cette classe :

get_match_string

La méthode "get_match_string" retourne la partie de l'expression régulière qui effectue la correspondance.

get_substitute_string

La méthode "get_substitute_string" retourne la partie de l'expression régulière qui est substituée à la correspondance, le cas échéant. Si l'expression régulière ne substitue pas, "undef" est retourné.

get_modifiers

La méthode "get_modifiers" retourne les modificateurs de l'expression régulière.

get_delimiters

La méthode "get_delimiters" retourne les délimiteurs de l'expression régulière sous forme de tableau. Le premier élément est les délimiteurs de la chaîne de correspondance, et le deuxième élément (le cas échéant) est les délimiteurs de la chaîne de substitution (le cas échéant).
