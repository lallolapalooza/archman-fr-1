NOM

PPIx::QuoteLike::Token::Interpolation - Représenter une interpolation

SYNOPIS

Cette classe ne devrait pas être instanciée par l'utilisateur. Voir ci-dessous pour les méthodes publiques.

HERITAGE

"PPIx::QuoteLike::Token::Interpolation" est un PPIx::QuoteLike::Token.

"PPIx::QuoteLike::Token::Interpolation" n'a pas de descendants.

DESCRIPTION

Cette classe Perl représente une interpolation dans une chaîne de type citation.

METHODES

Cette classe prend en charge les méthodes publiques suivantes en plus de celles de sa superclasse :

ppi

my $ppi = $elem->ppi();

Cette méthode de commodité retourne le PPI::Document représentant le contenu. Ce document doit être considéré comme en lecture seule. Une exception sera levée si PPI::Document ne peut pas être chargé.

Notez que le contenu du PPI::Document retourné peut ne pas être identique au contenu de l'original "PPIx::Regexp::Token::Interpolation". Cela peut se produire car les noms de variables interpolés peuvent être entourés d'accolades, mais cela ne se produit pas dans le code normal. Par exemple, dans "/${foo}bar/", le contenu de l'objet "PPIx::Regexp::Token::Interpolation" sera '${foo}', mais le contenu du "PPI::Document" sera '$foo'.

variables

say "Interpolates $_" for $elem->variables();

NOTEZ que cette méthode est déconseillée, et pourrait bien être obsolète et supprimée. J'ai deux problèmes avec elle. Le premier est qu'elle retourne des noms de variables plutôt que des objets PPI::Element, vous laissant sans idée sur la façon dont les variables sont utilisées. Le second est qu'elle ne gère pas correctement des choses comme "${^CAPTURE[0]}", et il semble infaisable de le faire. Elle a été initialement écrite pour le bénéfice de Perl::Critic::Policy::Variables::ProhibitUnusedVarsStricter, mais s'est avérée inadéquate aux besoins de cette politique.

Cette méthode de commodité retourne toutes les variables interpolées. Chacune est retournée une seule fois, et elles sont retournées sans ordre particulier.

VOIR AUSSI

PPIx::QuoteLike::Token.
