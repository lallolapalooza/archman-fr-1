NAME

PPIx::QuoteLike::Utils - Sous-programmes utilitaires pour PPIx::QuoteLike;

SYNOPSIS

use PPIx::QuoteLike::Utils qw{ __variables };

say for __variables( PPI::Document->new( \'$foo' );

DESCRIPTION

Ce module Perl contient du code pour PPIx::QuoteLike qui ne semblait pas trouver sa place ailleurs.

SUBROUTINES

Ce module prend en charge les sous-programmes publics suivants :

column_number

Ce sous-programme/méthode renvoie le numéro de colonne de la première caractéristique de l'élément, ou "undef" s'il ne peut pas être déterminé.

is_ppi_quotelike_element

Ce sous-programme renvoie vrai si son argument est un élément PPI que ce module peut gérer. À savoir, l'un des éléments suivants :

PPI::Token::Quote
PPI::Token::QuoteLike::Backtick
PPI::Token::QuoteLike::Command
PPI::Token::QuoteLike::Readline
PPI::Token::HereDoc

Renvoie faux pour les références non blessées et pour les non-références.

line_number

Ce sous-programme/méthode renvoie le numéro de ligne de la première caractéristique de l'élément, ou "undef" s'il ne peut pas être déterminé.

logical_filename

Ce sous-programme/méthode renvoie le nom de fichier logique (en tenant compte des directives "#line") qui contient la première caractéristique de l'élément, ou "undef" s'il ne peut pas être déterminé.

logical_line_number

Ce sous-programme/méthode renvoie le numéro de ligne logique (en tenant compte des directives "#line") de la première caractéristique de l'élément, ou "undef" s'il ne peut pas être déterminé.

__normalize_interpolation_for_ppi

Bien qu'il y ait des tirets initiaux, ce sous-programme public et supporté est exportable. Les tirets sont ainsi pour qu'ils n'apparaissent pas comme du code public pour d'autres modules.

Ce sous-programme prend comme argument une chaîne représentant un interpolé. Il supprime des choses comme des accolades autour des noms de variables pour en faire un Perl plus normal, ce qui est-à-dire du Perl qui produit une analyse PPI plus normale. Les transformations d'exemples sont :

'${foo}'        => '$foo'
'@{[ foo() ]}'  => 'foo()'
'${\( foo() )}' => 'foo()'

NOTE que ce n'est pas conçu pour nettoyer du code général. C'est-à-dire qu'il suppose que son argument est un interpolé et seulement un interpolé. Passer autre chose que cela n'est pas supporté et ne renverra probablement rien d'utile.

statement

Ce sous-programme/méthode renvoie le PPI::Statement qui contient cet élément, ou rien s'il ne peut pas être déterminé.

En général, cette méthode ne renverra quelque chose que dans les conditions suivantes :

  • L'élément est contenu dans un objet PPIx::Regexp ;
  • L'objet a été initialisé à partir d'un élément PPI ;
  • L'élément PPI est contenu dans une instruction.

visual_column_number

Ce sous-programme/méthode renvoie le numéro de colonne visuel (en tenant compte des tabulations) de la première caractéristique de l'élément, ou "undef" s'il ne peut pas être déterminé.

__variables

say for __variables( PPI::Document->new( \'$foo' );

NOTE que ce sous-programme est découplé et peut être déprécié et supprimé. J'ai deux problèmes avec lui. Le premier est qu'il renvoie des noms de variables au lieu d'objets PPI::Element, laissant sans savoir comment les variables sont utilisées. Le second est qu'il ne gère pas correctement des choses comme "${^CAPTURE[0]}", et il semble impossible de le faire. Il a été initialement écrit au bénéfice de Perl::Critic::Policy::Variables::ProhibitUnusedVarsStricter, mais s'est avéré insuffisant pour les besoins de cette politique.

Bien qu'il y ait des tirets initiaux, ce sous-programme public et supporté est exportable. Les tirets sont ainsi pour qu'ils n'apparaissent pas comme du code public pour d'autres modules.

Ce sous-programme prend comme seul argument un élément PPI, et renvoie les noms de toutes les variables trouvées dans cet élément dans un ordre quelconque. La portée n'est pas prise en compte.

En plus de signaler les variables analysées par PPI, et des cas comme "${]}" où PPI ne voit pas l'utilisation de la variable, ce sous-programme recherche dans les classes PPI suivantes :

PPI::Token::Quote
PPI::Token::QuoteLike::Backtick
PPI::Token::QuoteLike::Command
PPI::Token::QuoteLike::Readline
PPI::Token::HereDoc

Si PPIx::Regexp est installé, il recherche également dans :

PPI::Token::QuoteLike::Regexp
PPI::Token::Regexp::Match
PPI::Token::Regexp::Substitute

Bien que je ne puisse pas faire de "PPIx::Regexp" une exigence pour ce module en raison de la possibilité de dépendance cyclique.

PPIx::QuoteLike::Utils(3pm)

Nom
PPIx::QuoteLike::Utils - Utilitaires pour la génération de code Perl pour les chaînes de caractères avec guillemets.

Synopsis
use PPIx::QuoteLike::Utils qw( quote_like_utils );
my @quoted = quote_like_utils( $string );

Description
La classe PPIx::QuoteLike est une classe fondamentale pour la manipulation de chaînes de caractères Perl avec guillemets. Cependant, pour la génération de code Perl qui devrait ressembler le plus possible à ce qui est généré par des bibliothèques comme PPI (et dans une moindre mesure Syntax::Keyword::match), il existe des utilitaires supplémentaires pour s'assurer que le code généré est aussi idiomatique et lisible que possible.

Ces utilitaires visent à choisir le type de guillemets le plus approprié (simples, doubles, heredoc, etc.) en fonction du contenu de la chaîne, et à échapper correctement les caractères si nécessaire. L'objectif est de produire un code Perl qui est non seulement syntaxiquement correct, mais aussi facile à comprendre et à maintenir.

La fonction quote_like_utils est l'une des fonctions principales fournies par ce module. Elle prend une chaîne de caractères en entrée et retourne une liste de chaînes, où chaque chaîne est une représentation de la chaîne d'entrée avec des guillemets, choisie pour être la plus appropriée.

Exemples
use PPIx::QuoteLike::Utils qw( quote_like_utils );
my $string1 = "Ceci est une chaîne avec des \"guillemets\" et des \t tabulations.";
my @quoted1 = quote_like_utils( $string1 );
# @quoted1 pourrait contenir quelque chose comme qq{"Ceci est une chaîne avec des \"guillemets\" et des \t tabulations."}

my $string2 = "Une chaîne sans caractères spéciaux.";
my @quoted2 = quote_like_utils( $string2 );
# @quoted2 pourrait contenir quelque chose comme q{'Une chaîne sans caractères spéciaux.'}

my $string3 = "Une chaîne\navec une nouvelle ligne.";
my @quoted3 = quote_like_utils( $string3 );
# @quoted3 pourrait contenir quelque chose comme qq{Une chaîne\navec une nouvelle ligne.} ou un heredoc.

Fonctions

  • quote_like_utils( $string ): Prend une chaîne et retourne une liste de représentations de cette chaîne avec des guillemets.

Dépendances

  • PPI
  • Syntax::Keyword::match (indirectement, pour les inspirations)

Voir également

  • PPIx::QuoteLike
  • perlstyle - Quoting
