PPI::Statement::Data(3) Documentation Perl fournie par l'utilisateur PPI::Statement::Data(3)

NOM

PPI::Statement::Data - La section __DATA__ d'un fichier

SYNTAXE

# Contenu normal

__DATA__
This: data
is: part
of: the
PPI::Statement::Data: object

HEREDITE

PPI::Statement::Compound
isa PPI::Statement
    isa PPI::Node
        isa PPI::Element

DESCRIPTION

"PPI::Statement::Data" est une classe utilitaire conçue pour contenir le contenu de la section __DATA__ d'un fichier. Elle fournit une seule instruction pour contenir toutes les données.

METHODES

"PPI::Statement::Data" n'a pas de méthodes supplémentaires au-delà de celles fournies par défaut par PPI::Statement, PPI::Node et PPI::Element.

Cependant, on s'attend à ce qu'elle gagne des méthodes pour accéder directement aux données (par exemple, comme un descripteur de fichier), tout comme vous accéderiez aux données dans le code Perl lui-même.

À FAIRE

- Ajouter les méthodes pour lire les données

- Ajouter des tests unitaires appropriés
