NOM

PPIx::Regexp::Constant - Constantes pour le système PPIx::Regexp

SYNTAXE

use PPIx::Regexp::Constant qw{ TOKEN_UNKNOWN }
print "La classe d'un jeton inconnu est TOKEN_UNKNOWN\n";

HÉRITAGE

"PPIx::Regexp::Constant" est un Exporter.

"PPIx::Regexp::Constant" n'a pas de descendants.

DÉTAILS

Ce module définit des constantes manifestes pour être utilisées par les divers modules "PPIx::Regexp". Ces constantes sont considérées comme privées au système "PPIx::Regexp", et l'auteur se réserve le droit de les modifier sans préavis.

Ce module exporte les constantes manifestes suivantes :

@PAS_CARP

Cette variable globale contient les noms de tous les modules du paquet.

RÉF_TABLEAU

Ceci est le résultat de "ref []".

RÉF_CODE

Ceci est le résultat de "ref sub {}".

CLÉ_BISCUIT_CLASSES_CARACTÈRES

Le nom du biscuit utilisé pour contrôler la construction des classes de caractères.

Ce biscuit est défini dans PPIx::Regexp::Token::Structure lors de la rencontre du crochet ouvrant, et effacé dans le même module lors de la rencontre d'un crochet fermant.

CLÉ_BISCUIT_ASSERTION_PORTÉE

Le nom du biscuit utilisé pour contrôler l'analyse des assertions de largeur nulle.

Ce biscuit est défini dans PPIx::Regexp::Token::GroupType::Assertion, et il persiste jusqu'à la fin de l'assertion.

CLÉ_BISCUIT_QUANT

Le nom du biscuit utilisé pour contrôler la construction des quantificateurs entre accolades.

Ce biscuit est défini dans PPIx::Regexp::Token::Structure lors de la rencontre d'une accolade ouvrante. Il demande à être effacé lors de la rencontre de tout autre caractère qu'une virgule littérale, un chiffre littéral, ou une interpolation, ou si plus d'une virgule est rencontrée. S'il survit jusqu'à ce que PPIx::Regexp::Token::Structure traite l'accolade fermante, il y est effacé.

CLÉ_BISCUIT_GUILLEMET

Le nom du biscuit utilisé pour contrôler l'analyse des littéraux entre guillemets "\Q ... \E".

Ce biscuit est défini dans PPIx::Regexp::Token::Control lors de la rencontre d'un "\Q", et il persiste jusqu'au prochain "\E".

CLÉ_BISCUIT_ENSEMBLE_EXPR_RÉG

Le nom du biscuit utilisé pour contrôler les ensembles d'expressions régulières.

FAUX

Une valeur fausse. L'auteur ne s'engage pas sur la valeur exacte, seulement sur le fait que les opérations booléennes la verront comme fausse.

RÉF_HASH

Ceci est le résultat de "ref {}".

INFINI

C'est la valeur IEEE 754 de "Inf" si elle peut être générée, ou un objet surchargé opaque sinon. Parce que l'objet n'implémente pas (et je pense ne peut pas implémenter) le comportement complet de l'IEEE 754 "Inf", cette constante manifester ne devrait être utilisée que pour la stringification et la comparaison numérique. Soyez conscient que la numérification de l'objet doit être la même que sa stringification pour satisfaire looks_like_number(). Attention à vous.

ACCOLADE_OUVRANTE_LITTÉRALE_AUTORISÉE

La version de Perl à laquelle les accolades ouvrantes littérales non échappées ont été supprimées. Cela pourrait avoir plus de sens si je mentionnais que sa valeur est "undef".

ACCOLADE_OUVRANTE_LITTÉRALE_SUPPRIMÉE_PHASE_1

La version de Perl à laquelle la première phase de suppression des accolades ouvrantes littérales non échappées a eu lieu. La valeur de cette constante est '5.025001'.

ACCOLADE_OUVRANTE_LITTÉRALE_SUPPRIMÉE_PHASE_2

La version de Perl à laquelle la deuxième phase de suppression des accolades ouvrantes littérales non échappées a eu lieu. La valeur de cette constante est "undef", mais elle recevra une valeur lorsque le moment de la deuxième phase sera connu.

ACCOLADE_OUVRANTE_LITTÉRALE_SUPPRIMÉE_PHASE_3

La version de Perl à laquelle la troisième phase de suppression des accolades ouvrantes littérales non échappées a eu lieu. Il s'agit de la suppression des accolades après une parenthèse ouvrante. La valeur de cette constante est "undef", mais elle recevra une valeur lorsque le moment de la deuxième phase sera connu.

PERL_MINIMUM

La version minimale de Perl comprise par ce parseur, en tant que nombre flottant. Elle est actuellement définie à 5.000, car c'est la version minimale de Perl accessible à l'auteur.

GROUPE_MODIFICATEUR_SEMANTIQUE_MATCH

Le nom du groupe PPIx::Regexp::Token::Modifier utilisé pour contrôler la sémantique des correspondances.

MSG_PORTÉE_TROP_LONGUE

Un message d'erreur approprié pour une entité inconnue créée à partir d'un quantificateur qui rendrait une assertion de portée trop longue. Ceci est copié verbatim du message d'erreur Perl.

MSG_PROHIBÉ_PAR_STRICT

Un message d'erreur approprié pour une entité inconnue créée parce que 'strict' était en vigueur. C'est de l'improvisation de bas étage, et plus que d'habitude sujet à changement, sans aucun préavis. Attention à vous.

NŒUD_INCONNU

Le nom de la classe qui représente un nœud inconnu. C'est-à-dire, PPIx::Regexp::Node::Unknown.

NOM_CAPTURE_EXPR_RÉG

Une représentation sous forme de chaîne de caractères d'une expression régulière qui correspond au nom d'un tampon de capture nommé.

RÉF_EXPR_RÉG

Ceci est le résultat de "ref qr{}".

RÉF_SCALAIRE

Ceci est le résultat de "ref \0".

STRUCTURE_INCONNUE

Le nom de la classe qui représente une structure inconnue. C'est-à-dire, PPIx::Regexp::Structure::Unknown.

SUPPORT_UTF8_SUFFISANT_POUR_DÉLIMITEURS_Bizarres

Cette constante indique si la version actuelle de Perl a un support UTF-8 suffisant pour gérer des délimiteurs d'expression régulière non ASCII. La valeur est une chaîne de caractères représentant une version de Perl.

TRUE

Une valeur vraie. L'auteur ne s'engage pas sur la valeur exacte, seulement sur le fait que les opérations booléennes la verront comme vraie.

TYPE_TOKEN_INCONNU

Le nom de la classe qui représente un jeton inconnu. C'est-à-dire, PPIx::Regexp::Token::Unknown.

VERSION_SUPPRIMÉE_ACCOLADE_OUVRANTE_LITTÉRALE

La version de Perl à laquelle l'analyse des accolades ouvrantes littérales non échappées a été supprimée.

VALEUR_PAR_DÉFAUT_QUANTIFICATEUR

La valeur par défaut pour un quantificateur absent. C'est-à-dire, une quantité de 1.

VRAI

Une valeur vraie. L'auteur ne s'engage pas sur la valeur exacte, seulement sur le fait que les opérations booléennes la verront comme vraie.

PPIx::Regexp::Constant - constantes pour PPIx::Regexp
PPIx::Regexp 0.091

NOM

PPIx::Regexp::Constant - constantes pour PPIx::Regexp

SYNOPSIS

 use PPIx::Regexp::Constant qw(
    UTF8_SUPPORT
    TOKEN_LITERAL
    TOKEN_UNKNOWN
    TRUE
    VARIABLE_LENGTH_LOOK_BEHIND_INTRODUCED
 );

INHERITANCE

Aucune hiérarchie d'héritage.

DETAILS

UTF8_SUPPORT

Un booléen qui est vrai si la version de Perl en cours d'exécution a un support UTF-8 suffisant pour nos besoins.

Actuellement, cela signifie 5.8.3 ou plus, avec les exigences spécifiques étant "use open qw{ :std :encoding(utf-8) }", "/\p{Mark}/", et la capacité d'analyser des choses comme "qr \N{U+FFFF}foo\N{U+FFFF}".

TOKEN_LITERAL

Le nom de la classe qui représente un jeton littéral. C'est-à-dire, PPIx::Regexp::Token::Literal.

TOKEN_UNKNOWN

Le nom de la classe qui représente le jeton inconnu. C'est-à-dire, PPIx::Regexp::Token::Unknown.

TRUE

Une valeur vraie. L'auteur ne s'engage pas sur la valeur exacte, seulement que les opérations booléennes la verront comme vraie.

VARIABLE_LENGTH_LOOK_BEHIND_INTRODUCED

La version dans laquelle les look-behinds de longueur variable ont été introduits. Actuellement, c'est '5.029009', et implique les lookbehinds limités introduits à peu près à cette version.
