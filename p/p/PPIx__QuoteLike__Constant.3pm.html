NOM

PPIx::QuoteLike::Constant - Constantes nécessaires à PPIx-QuoteLike

SYNTAXE

Ce paquet est privé à la distribution "PPIx-QuoteLike".

DESCRIPTION

Ce module est privé au paquet "PPIx-QuoteLike". La documentation est destinée à l'auteur, qui se réserve le droit de modifier ou d'annuler tout ce qui est mentionné ici, y compris le module entier, sans préavis.

Ce module fournit des constantes de manifeste importables utilisées par plusieurs modules du paquet "PPIx-QuoteLike". Rien n'est exporté par défaut.

CONSTANTES

Les constantes importables suivantes sont fournies :

@CARP_NOT

Cette variable globale contient les noms de tous les modules du paquet. Ce n'est pas une constante au sens de "use constant", mais elle doit résider ici pour des raisons d'héritage.

ARRAY_REF

Cette constante de manifeste contient la valeur de "ref []", c'est-à-dire 'ARRAY'.

MINIMUM_PERL

La version minimale de Perl comprise par ce parseur, sous forme de chaîne. Elle est actuellement définie à '5.000', car c'est la version minimale de Perl accessible à l'auteur.

SUFFICIENT_UTF8_SUPPORT_FOR_WEIRD_DELIMITERS

Un booléen qui est vrai si la version de Perl exécutée dispose d'un support UTF-8 suffisant pour nos besoins.

Actuellement, cela signifie 5.8.3 ou supérieur, avec les exigences spécifiques étant "use open qw{ :std :encoding(utf-8) }", "/\p{Mark}/", et la capacité d'analyser des choses comme "qr \N{U+FFFF}foo\N{U+FFFF}".

VARIABLE_RE

Cette constante est un objet d'expression régulière qui correspond aux noms de variables Perl, sans le sigil de préfixe. Rien n'est capturé.
