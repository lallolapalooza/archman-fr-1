NOM

PPI::Token::Prototype - Un descripteur de prototype de sous-routine

INHERITANCE

PPI::Token::Prototype
isa PPI::Token::Quote::Literal
    isa PPI::Token::Quote
        isa PPI::Token
            isa PPI::Element

SYNOPSIS

sub ($@) prototype;

DESCRIPTION

Bien qu'il ressemble un peu à une liste ou une condition, un prototype de sous-routine ressemble beaucoup plus à une chaîne de caractères. Son rôle est de fournir des indices au compilateur perl sur le type d'arguments attendus par une sous-routine particulière, que le compilateur utilise pour valider les paramètres au moment de la compilation, et permet aux programmeurs d'utiliser les fonctions sans parenthèses explicites pour les paramètres.

En raison de l'essor de la programmation OO en Perl, qui ignore ces prototypes, ils sont le plus souvent utilisés pour permettre des choses de type constante et pour "étendre" le langage et créer des éléments qui agissent comme des mots-clés et des fonctions de base.

# Créer quelque chose qui agit comme une constante
sub MYCONSTANT () { 10 }

# Créer la fonction qui ressemble à une fonction de base "any"
sub any (&@) { ... }

if ( any { $_->cute } @babies ) {
      ...
}

METHODES

Cette classe fournit une méthode supplémentaire par rapport à celles définies par les classes parentes PPI::Token et PPI::Element.

prototype

L'accesseur "prototype" renvoie le motif de prototype réel, dépouillé des parenthèses environnantes et de tous les espaces blancs. Ceci reflète le comportement de la fonction intégrée Perl "prototype".

Notez que le retrait des parenthèses et des espaces blancs signifie que la valeur de retour de "prototype" peut être une chaîne vide.
