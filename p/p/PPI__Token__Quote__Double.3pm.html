NOM

PPI::Token::Quote::Double - Un jeton standard de "guillemet double"

HÉRITAGE

PPI::Token::Quote::Double
isa PPI::Token::Quote
    isa PPI::Token
        isa PPI::Element

DESCRIPTION

Un objet "PPI::Token::Quote::Double" représente une chaîne de caractères interpolée entre guillemets doubles.

La chaîne est traitée comme une entité unique, PPI n'essaiera pas de comprendre ce qu'il y a dans la chaîne pendant le processus d'analyse.

MÉTHODES

Il existe plusieurs méthodes disponibles pour "PPI::Token::Quote::Double", au-delà de celles fournies par les classes parentes PPI::Token::Quote, PPI::Token et PPI::Element.

interpolations

La méthode interpolations vérifie si le guillemet double contient réellement des variables interpolées.

Renvoie vrai si la chaîne contient des interpolations, ou faux sinon.

simplify

Pour diverses raisons, certaines personnes se sentent obligées d'avoir leur code sous sa forme la plus simple possible.

La méthode "simplify" modifiera, si possible, un simple jeton de chaîne entre guillemets doubles sur place, en le transformant en sa chaîne équivalente entre guillemets simples. Si le jeton est modifié, il est reblessé dans le package PPI::Token::Quote::Single.

Étant donné que la longueur du contenu n'est pas modifiée, il n'est pas nécessaire d'appeler la méthode "flush_locations" du document.

L'objet lui-même est renvoyé à titre de commodité.
