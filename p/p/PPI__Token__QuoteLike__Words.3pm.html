NOM

PPI::Token::QuoteLike::Words - Opérateur de type citation pour le constructeur de listes de mots

INHERITANCE

PPI::Token::QuoteLike::Words
isa PPI::Token::QuoteLike
    isa PPI::Token
        isa PPI::Element

DESCRIPTION

Un objet "PPI::Token::QuoteLike::Words" représente un opérateur de type citation qui agit comme un constructeur pour une liste de mots.

# Créer une liste pour une partie importante de l'alphabet
my @liste = qw{a b c d e f g h i j k l};

MÉTHODES

literal

Retourne les mots contenus sous forme de liste. Notez que cette méthode ne vérifie pas le contexte dans lequel le token se trouve ; elle retourne toujours la liste et pas seulement le dernier élément si le token est dans un contexte scalaire.
