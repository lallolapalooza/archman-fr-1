PPI__Statement__Compound(3pm)

Paquet: perl-ppi

Licences: PerlArtistic

PPI::Statement::Compound(3) Documentation Perl fournie par la communauté PPI::Statement::Compound(3)

NOM

PPI::Statement::Compound - Décrit toutes les instructions composées

SYNOPSIS

# Une instruction if composée
if ( foo ) {
    bar();
} else {
    baz();
}
# Une instruction de boucle composée
foreach ( @list ) {
    bar($_);
}

HÉRITAGE

PPI::Statement::Compound
isa PPI::Statement
    isa PPI::Node
        isa PPI::Element

DESCRIPTION

Les objets "PPI::Statement::Compound" sont utilisés pour décrire toutes les formes actuelles d'instructions composées, telles que décrites dans perlsyn.

Cela couvre les blocs utilisant "if", "unless", "for", "foreach", "while", et "continue". Veuillez noter que cela ne couvre pas les instructions "simples" avec des conditions finales. Veuillez également noter que "do" ne fait pas non plus partie d'une instruction composée.

# Ce n'est PAS une instruction composée
my $foo = 1 if $condition;
# Ce n'est pas non plus une instruction composée
do { ... } until $condition;

MÉTHODES

"PPI::Statement::Compound" a un certain nombre de méthodes en plus des méthodes standard PPI::Statement, PPI::Node et PPI::Element.

type

La méthode "type" renvoie le type syntaxique de l'instruction composée.

Il existe quatre types de base d'instructions composées.

Le type 'if' inclut toutes les variations des instructions if et unless, y compris toutes les parties 'elsif' ou 'else' de l'instruction composée.

Le type 'while' décrit les instructions while et until standard, mais ne décrit **pas** les instructions simples avec un while final.

Le type 'for' couvre les boucles de style C, qu'elles aient été déclarées en utilisant 'for' ou 'foreach'.

Le type 'foreach' couvre les boucles qui itèrent sur des collections, qu'elles aient été déclarées en utilisant 'for' ou 'foreach'.

Tous les composés sont une variation de l'un de ces quatre.

Retourne la chaîne simple 'if', 'for', 'foreach' ou 'while', ou "undef" si le type ne peut pas être déterminé.
