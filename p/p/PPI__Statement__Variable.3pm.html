PPI::Statement::Variable(3) Documentation Perl fournie par l'utilisateur PPI::Statement::Variable(3)

NOM

PPI::Statement::Variable - Déclarations d'instructions de variables

SYNTAXE

# Toutes les lignes suivantes sont des déclarations de variables
my $foo = 1;
my ($foo, $bar) = (1, 2);
our $foo = 1;
local $foo;
local $foo = 1;
LABEL: my $foo = 1;

HÉRITAGE

PPI::Statement::Variable
isa PPI::Statement::Expression
    isa PPI::Statement
        isa PPI::Node
            isa PPI::Element

DESCRIPTION

L'intention principale de la classe "PPI::Statement::Variable" est de décrire des instructions simples qui déclarent explicitement de nouvelles variables locales ou globales.

Notez que cela ne rend pas cette classe exclusivement le seul endroit où les variables sont définies, et plus tard, vous devriez vous attendre à ce que la méthode "variables" migre plus profondément dans l'arbre vers PPI::Statement ou PPI::Node pour reconnaître ce fait, mais pour l'instant, elle reste ici.

MÉTHODES

type

La méthode "type" vérifie et retourne le type de déclaration de l'instruction, qui sera l'un des suivants : 'my', 'local', 'our', ou 'state'.

Retourne une chaîne de caractères représentant le type, ou "undef" si le type ne peut pas être détecté (ce qui est probablement un bug).

variables

Comme pour plusieurs autres types d'éléments PDOM qui peuvent déclarer des variables, la méthode "variables" retourne une liste des formes canoniques des variables définies par l'instruction.

Retourne une liste des formes canoniques de chaînes de caractères des variables, ou la liste nulle si elle ne parvient pas à trouver de variables.

symbols

Retourne une liste des variables définies par l'instruction, sous forme de PPI::Token::Symbols.
