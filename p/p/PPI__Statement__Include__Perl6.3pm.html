NOM

PPI::Statement::Include::Perl6 - Section de fichier Perl 6 incluse en ligne

SYNOPIS

use v6-alpha;

grammar My::Grammar {
    ...
}

HERITAGE

PPI::Statement::Include::Perl6
isa PPI::Statement::Include
    isa PPI::Statement
        isa PPI::Node
            isa PPI::Element

DESCRIPTION

Un "PPI::Statement::Include::Perl6" est une instruction d'inclusion spéciale qui indique le début d'une section de code Perl 6 incluse dans un fichier de code Perl 5 ordinaire.

Le but principal de la classe est de permettre à PPI de fournir au moins un support de base pour les modules "6 dans 5" tels que v6.pm ;

Actuellement, PPI ne prend en charge que le démarrage d'un bloc Perl 6. Il ne prend pas en charge le retour à Perl 5. De plus, tous les blocs POD et les blocs __DATA__ et __END__ seront inclus dans la chaîne Perl 6 et ne seront pas analysés par PPI.

perl6

La méthode "perl6" renvoie le bloc de code Perl 6 qui est attaché à la commande "use v6...;".
