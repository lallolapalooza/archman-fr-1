NOM

PPIx::Regexp::Util - Fonctions utilitaires pour PPIx::Regexp ;

SYNOPSIS

use PPIx::Regexp::Util qw{ __instance };
    .
    .
    .
__instance( $foo, 'Bar' )
    or die '$foo n\'est pas un Bar';

DESCRIPTION

Ce module contient des fonctions utilitaires pour PPIx::Regexp qui sont pratiques à centraliser.

Les sous-routines à double trait de soulignement sont privées du paquet "PPIx-Regexp". Leur documentation est fournie uniquement pour la commodité de l'auteur, et elles sont susceptibles de changer sans préavis. Attention à l'utilisateur.

Ce module n'exporte rien par défaut.

SOUS-ROUTINES

Ce module peut exporter les sous-routines suivantes :

is_ppi_regexp_element

is_ppi_regexp_element( $elem )
  and print "$elem est une expression régulière d'une sorte ou d'une autre\n";

Cette sous-routine est publique et supportée.

Cette sous-routine prend comme argument un PPI::Element. Elle renvoie une valeur vraie si l'argument représente une expression régulière d'une sorte ou d'une autre, et une valeur fausse sinon.

__instance

__instance( $foo, 'Bar' )
    and print '$foo est un Bar', "\n";

Cette sous-routine est privée du paquet "PPIx-Regexp".

Cette sous-routine renvoie vrai si son premier argument est une instance de la classe spécifiée par son second argument. Contrairement à "UNIVERSAL::isa", le résultat est toujours faux, sauf si le premier argument est une référence.

__is_ppi_regexp_element

__is_ppi_regexp_element( $elem )
  and print "$elem est une expression régulière d'une sorte ou d'une autre\n";

Cette sous-routine est privée du paquet "PPIx-Regexp".

C'est un synonyme de is_ppi_regexp_element(), et il est déprécié en sa faveur. S'il est appelé, il se plaindra via Carp::cluck() puis fera un "goto &is_ppi_regexp_element".

__merge_perl_requirements

Cette sous-routine est privée du paquet "PPIx-Regexp".

Cette sous-routine fusionne les exigences perl telles que retournées par les diverses méthodes "__perl_requirements()".

__ns_can

Cette sous-routine est privée du paquet "PPIx-Regexp".

Cette méthode est analogue à can(), mais renvoie une référence au code uniquement s'il est effectivement implémenté par l'espace de noms appelant.

__post_rebless_error

Cette méthode est privée du paquet "PPIx-Regexp". Son utilisation prévue est de l'aliaser vers "__PPIX_ELEM__post_reblessing()".

Elle prend des arguments sous forme de paires nom/valeur. L'argument "{error}" est le message d'erreur ; s'il est omis, vous obtenez un avertissement avec une trace de la pile. L'argument "{explanation}" vaut par défaut "{error}".

Elle renvoie le nombre d'erreurs à ajouter à l'analyse.

raw_width

Cette méthode publique renvoie la largeur minimale et maximale correspondant à l'élément avant de prendre en compte des détails tels que ce qu'est réellement l'élément et comment il est quantifié.

Cette implémentation convient aux choses qui correspondent exactement à un seul caractère - c'est-à-dire qu'elle renvoie "( 1, 1 )".

__to_ordinal_en

Cette sous-routine est privée du paquet "PPIx-Regexp".

Cette sous-routine prend comme argument un entier et renvoie une chaîne représentant son ordinal en anglais. Par exemple :

say __to_ordinal_en( 17 );
# 17th

width

my ( $min_wid, $max_wid ) = $self->width();

Cette méthode publique (en fait, un mixin) renvoie la largeur minimale et maximale du texte correspondant à l'élément.

Les éléments qui importent cette méthode doivent également implémenter une méthode raw_width() qui renvoie la largeur non quantifiée de l'élément.

TAGS D'EXPORTATION

Les tags d'exportation suivants sont définis par ce module. Tous sont privés au paquet "PPIx-Regexp", sauf indication contraire.

all

Ce tag exporte tout ce qui est exportable par ce module.

width_one

Ce tag convient à un élément qui, lorsqu'il n'est pas quantifié, correspond exactement à un caractère. Il exporte raw_width() et width().

VOIR AUSSI

Params::Util, que je recommande, mais dans le cas de "PPIx::Regexp", je ne voulais pas introduire de dépendance sur un module XS alors que tout ce que je voulais vraiment était la fonctionnalité de la sous-routine _INSTANCE() de ce module.

NOM

PPIx::Regexp::Util - Fonctions utilitaires pour la manipulation des expressions régulières PPIx.

SYNOPSIS

    use PPIx::Regexp::Util qw(
        is_regex_literal
        is_regex_interpolation
        regex_from_string
        regex_to_string
        regex_add_flags
        regex_remove_flags
        regex_set_flags
        regex_get_flags
        regex_has_flags
    );

DESCRIPTION

Cette classe fournit un ensemble de fonctions utilitaires pour travailler avec les expressions régulières Perl dans le contexte de la bibliothèque PPIx::Regexp.

Elle vous permet de vérifier les types d'expressions régulières, de les convertir entre différentes représentations et de manipuler leurs drapeaux.

SOUS-ROUTINES

is_regex_literal($expr)

Retourne vrai si l'expression régulière donnée est un littéral d'expression régulière (par exemple, qr/.../).

is_regex_interpolation($expr)

Retourne vrai si l'expression régulière donnée contient une interpolation (par exemple, qr/$_/).

regex_from_string($string, \%options)

Crée une expression régulière Perl à partir d'une chaîne de caractères. Les options peuvent inclure :

  • flags: Une chaîne spécifiant les drapeaux (par exemple, 'i', 'm', 's').
regex_to_string($regex)

Convertit une expression régulière Perl en sa représentation sous forme de chaîne de caractères.

regex_add_flags($regex, $flags)

Ajoute les drapeaux spécifiés à une expression régulière.

regex_remove_flags($regex, $flags)

Supprime les drapeaux spécifiés d'une expression régulière.

regex_set_flags($regex, $flags)

Définit les drapeaux d'une expression régulière aux drapeaux spécifiés.

regex_get_flags($regex)

Retourne les drapeaux actuels d'une expression régulière sous forme de chaîne de caractères.

regex_has_flags($regex, $flags)

Retourne vrai si l'expression régulière a tous les drapeaux spécifiés.
