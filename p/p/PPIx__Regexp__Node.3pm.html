PPIx__Regexp__Node(3pm)

Paquet: perl-ppix-regexp

Licences: PerlArtistic

PPIx::Regexp::Node(3) Documentation Perl Contribuée par les Utilisateurs PPIx::Regexp::Node(3)

NOM

PPIx::Regexp::Node - Représenter un conteneur

SYNOPSIS

use PPIx::Regexp::Dumper;
PPIx::Regexp::Dumper->new( 'qr{(foo)}' )->print();

HEREDITE

"PPIx::Regexp::Node" est un PPIx::Regexp::Element.

"PPIx::Regexp::Node" est le parent de PPIx::Regexp, PPIx::Regexp::Node::Range et PPIx::Regexp::Structure.

DESCRIPTION

Cette classe représente un élément structurel qui contient d'autres classes. C'est une classe abstraite, non instanciée par le lexer.

METHODES

Cette classe fournit les méthodes publiques suivantes. Les méthodes non documentées ici sont privées et non supportées dans le sens où l'auteur se réserve le droit de les modifier ou de les supprimer sans préavis.

enfant

my $kid = $node->enfant( 0 );

Cette méthode retourne l'enfant à l'indice donné. Les indices commencent à zéro, et les indices négatifs comptent à partir de la fin de la liste, de sorte que "$node->enfant( -1 )" retourne le dernier enfant du nœud.

enfants

Cette méthode retourne les enfants du Nœud. Appelée dans un contexte scalaire, elle retourne le nombre d'enfants.

contient

print $node->contient( $elem ) ? "oui\n" : "non\n";

Cette méthode retourne vrai si l'élément donné est contenu dans le nœud, faux sinon.

elements

Cette méthode retourne les éléments dans le Nœud. Pour un "PPIx::Regexp::Node" propre, c'est la même chose que enfants().

trouver

my $rslt = $node->trouver( 'PPIx::Regexp::Token::Literal' );
my $rslt = $node->trouver( 'Token::Literal' );
my $rslt = $node->trouver( sub {
    return $_[1]->isa( 'PPIx::Regexp::Token::Literal' )
        && $_[1]->ordinal < ord(' ');
    } );

Cette méthode trouve des choses.

Si une chaîne de caractères est passée en argument, elle est supposée être un nom de classe (éventuellement sans le préfixe 'PPIx::Regexp::'), et tous les éléments de la classe donnée sont trouvés.

Si une référence de code est passée, cette référence de code est appelée une fois pour chaque élément, et reçoit $self et l'élément. Le code doit retourner vrai pour accepter l'élément, faux pour le rejeter, et (pour les sous-classes de "PPIx::Regexp::Node") "undef" pour empêcher la récursion dans le nœud. Si le code lève une exception, vous n'obtenez rien de cette méthode.

Dans tous les cas, le retour est une référence à la liste des choses trouvées, une valeur fausse (mais définie) si rien n'a été trouvé, ou "undef" si une erreur s'est produite.

trouver_parents

my $rslt = $node->trouver_parents( sub {
    return $_[1]->isa( 'PPIx::Regexp::Token::Operator' )
        && $_[1]->content() eq '|';
    } );

Cette méthode pratique prend les mêmes arguments que "trouver", mais au lieu des objets trouvés eux-mêmes, elle retourne leurs parents. Aucun parent n'apparaîtra plus d'une fois dans la sortie.

Cette méthode retourne une référence au tableau des parents s'il y en a eu. Si aucun parent n'a été trouvé, le retour est faux mais défini. Si une erreur s'est produite, le retour est "undef".

trouver_premier

Cette méthode a les mêmes arguments que "trouver", mais retourne soit une référence au premier élément trouvé, une valeur fausse (mais définie) si aucun élément n'a été trouvé, ou "undef" si une erreur s'est produite.

premier_element

Cette méthode retourne le premier élément du nœud.

premier_token

Cette méthode retourne le premier jeton (token) du nœud. S'il n'y en a pas, elle ne retourne rien.

dernier_element

Cette méthode retourne le dernier élément du nœud.

dernier_token

Cette méthode retourne le dernier jeton (token) du nœud. S'il n'y en a pas, elle ne retourne rien.

est_detecteur

Cette méthode retourne une valeur vraie si l'un des enfants du nœud l'est. Sinon, elle retourne "undef" si l'un des enfants du nœud l'est. Sinon, elle retourne une valeur fausse (mais définie).

version_perl_introduit

Cette méthode retourne la valeur maximale de "version_perl_introduit" retournée par l'un de ses éléments. En d'autres termes, elle retourne la version minimale de Perl sous laquelle ce nœud est valide. S'il n'y a pas d'éléments, 5.000 est retourné, puisque c'est la valeur minimale de Perl supportée par ce paquet.

version_perl_supprime

Cette méthode retourne la valeur définie minimale de "version_perl_supprime" retournée par l'un des éléments du nœud. En d'autres termes, elle retourne la plus basse version de Perl dans laquelle ce nœud n'est "pas" valide. S'il n'y a pas d'éléments, ou si aucun élément n'a de "version_perl_supprime" défini, "undef" est retourné.

enfant_significatif

Cette méthode retourne l'enfant significatif à l'indice donné ; c'est-à-dire que "$node->enfant_significatif(0)" retourne le premier enfant significatif, "$node->enfant_significatif(1)" retourne le deuxième enfant significatif, et ainsi de suite. Les indices négatifs comptent à partir de la fin.

enfants_significatifs

Cette méthode retourne les enfants significatifs du Nœud. Appelée dans un contexte scalaire, elle retourne le nombre d'enfants significatifs.
