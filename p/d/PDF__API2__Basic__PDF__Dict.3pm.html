NOM

PDF::API2::Basic::PDF::Dict - Objets de dictionnaire et de flux de bas niveau

VARIABLES D'INSTANCE

Il existe diverses variables d'instance spéciales utilisées pour la gestion, en particulier des flux. Chacune commence par un espace :

flux
Contient le contenu du flux pour la sortie.
fluxfichier
Contient le contenu du flux dans un fichier externe plutôt qu'en mémoire. Ce n'est pas la même chose qu'un flux de fichier PDF. Les données sont stockées sous leur forme non filtrée.
fluxloc
Si à la fois ' flux' et ' fluxfichier' sont vides, ceci indique où le flux commence dans le fichier PDF source.

MÉTHODES

$type = $d->type($type)

Obtenir/Définir la clé Type standard. Elle peut être passée et renverra une valeur texte plutôt qu'un objet Nom.

@filtres = $d->filter(@filtres)

Obtenir/Définir un ou plusieurs filtres utilisés par le flux facultatif attaché au dictionnaire.

$d->outobjdeep($fh)

Écrit le contenu du dictionnaire dans un fichier PDF. Ceci est un appel récursif.

Il écrit également un flux si le dictionnaire a un élément de flux. Si cela se produit, cette méthode calculera la longueur du flux et l'insérera dans le dictionnaire du flux.

$d->read_stream($force_memory)

Lit un flux à partir d'un fichier PDF. Si le flux est supérieur à "PDF::Dict::mincache" (par défaut 32768) octets à stocker, alors l'action par défaut est de créer un fichier pour celui-ci quelque part et d'utiliser ce fichier comme cache de données. Si $force_memory est défini, la mise en cache n'aura pas lieu et toutes les données seront stockées dans la variable $self->{' flux'}.

$d->val

Renvoie le dictionnaire, qui est lui-même.
