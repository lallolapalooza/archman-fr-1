NOM

PDF::Builder::Resource::XObject::Image::TIFF::File_GT - Routines de support pour la bibliothèque d'images TIFF (avec Graphics::TIFF activé)

MÉTHODES

new

PDF::Builder::Resource::XObject::Image::TIFF::File_GT->new()
Crée un objet image à partir d'une entrée TIFF, en utilisant la bibliothèque Graphics::TIFF. N'oubliez pas d'utiliser la méthode image_tiff de Builder.pm pour cette fonctionnalité.
