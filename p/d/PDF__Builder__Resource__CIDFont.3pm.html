NOM

PDF::Builder::Resource::CIDFont - Classe de base pour les polices CID

Hérite de PDF::Builder::Resource::BaseFont

MÉTHODES

new

$font = PDF::Builder::Resource::CIDFont->new($pdf, $name)
Retourne un objet cid-font, classe de base pour toutes les polices basées sur CID.

cidsByStr

$cidstring = $font->cidsByStr($string)
Retourne la chaîne de CID à partir de la chaîne en se basant sur la carte d'encodage de la police.

cidsByUtf

$cidstring = $font->cidsByUtf($utf8string)
Retourne la chaîne encodée en CID à partir de la chaîne utf8.
