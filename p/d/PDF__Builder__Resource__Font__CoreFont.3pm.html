NOM

PDF::Builder::Resource::Font::CoreFont - Module pour utiliser les 14 polices intégrées standards PDF (plus 15 polices Windows)

Hérite de PDF::Builder::Resource::Font

SYNTAXE

 #
 use PDF::Builder;
 #
 my $pdf = PDF::Builder->new();
 my $cft = $pdf->font('Times-Roman');
#my $cft = $pdf->corefont('Times-Roman');
 #
 my $page = $pdf->page();
 my $text = $page->text();
 $text->font($cft, 20);
 $text->translate(200, 700);
 $text->text("Bonjour, Monde !");

MÉTHODES

new

$font = PDF::Builder::Resource::Font::CoreFont->new($pdf, $fontname, %options)
Retourne un objet corefont.

Créneaux supportés

Créneaux PDF standards

Voir examples/020_corefonts pour une liste des glyphes de chaque police.

  • helvetica, helveticaoblique, helveticabold, helvetiaboldoblique

    Sans-serif, peut être substitué par Arial sur certains systèmes (ex: Windows).

  • courier, courieroblique, courierbold, courierboldoblique

    À espacement fixe, peut être substitué par Courier New sur certains systèmes (ex: Windows).

  • timesroman, timesitalic, timesbold, timesbolditalic

    Serif, peut être substitué par Times New Roman sur certains systèmes (ex: Windows).

  • symbol, zapfdingbats

    Divers symboles, y compris l'alphabet grec (dans Symbol).

Créneaux principalement Windows

Voir examples/022_truefonts /Windows/Fonts/<name>.ttf pour une liste des glyphes de chaque police.

  • georgia, georgiaitalic, georgiabold, georgiabolditalic

    Serif proportionnel.

  • verdana, verdanaitalic, verdanabold, verdanabolditalic

    Sans-serif proportionnel avec des traits simples.

  • trebuchet, trebuchetitalic, trebuchetbold, trebuchetbolditalic

    Sans-serif proportionnel avec des traits simples.

  • bankgothic, bankgothicitalic, bankgothicbold, bankgothicitalic

    Sans-serif proportionnel avec des traits simples. Les versions gratuites de Bank Gothic sont souvent seulement de poids moyen Roman (bankgothic).

  • webdings, wingdings

    Divers symboles, dans le genre de Zapf Dingbats.

Gardez à l'esprit que seules les métriques de police (largeurs) sont fournies avec PDF::Builder ; les polices elles-mêmes sont fournies par la machine du lecteur (souvent empaquetées avec le système d'exploitation, ou obtenues séparément par l'utilisateur). L'utilisation d'une police spécifique peut nécessiter que vous obteniez un ou plusieurs fichiers d'une certaine source.

Si une police (créneau et variante) n'est pas disponible sur la machine d'un lecteur donné, une substitution *peut* être automatiquement effectuée. Par exemple, Helvetica n'est généralement pas fournie avec les machines Windows, et Arial pourrait être substituée. Pour la plupart des caractères, les largeurs des glyphes seront les mêmes, mais cela ne peut être garanti !

PDF::Builder utilise actuellement les fichiers [créneau].pm pour mapper les noms de glyphes aux points de code (encodages sur un seul octet uniquement) et pour rechercher les largeurs des glyphes pour le positionnement des caractères. Il n'y a aucune garantie qu'un fichier de police donné inclut tous les glyphes souhaités, ni que les largeurs seront absolument les mêmes, même dans différentes versions de la même police.

Options

encode
Change l'encodage de la police par rapport à son défaut. Notez que l'encodage (et non l'intégralité de la liste des glyphes de la police) est indiqué dans un objet PDF (enregistrement), listant 256 glyphes associés à cet encodage (et qui sont disponibles dans cette police).

Voir Encode de Perl pour les valeurs supportées. Attention : seuls les encodages sur un seul octet sont autorisés. Les encodages multibytes tels que 'utf8' sont interdits.

dokern
Active le crénage si des données sont disponibles.

"kerning" est un ancien nom pour cette option, et est toujours disponible en tant qu'alternative à "dokern".

pdfname
Change le nom de référence de la police par rapport à son défaut. Le nom de référence est normalement généré automatiquement et peut être récupéré via $pdfname=$font->name().
metrics
Si donné, il est attendu comme un hachage anonyme de données de fichier de police. Ceci doit être utilisé au lieu de rechercher le fichier $fontname.pm pour la largeur et d'autres données. Vous pourriez avoir besoin d'utiliser cette option si votre police installée se trouve être désynchronisée avec le fichier de métriques de police intégré de PDF::Builder (par ex. helveticabold.pm).

is_standard

$bool = $class->is_standard($name)
Retourne vrai si $name correspond exactement, en respectant la casse, à l'un des noms de police standards indiqués ci-dessus.

loadallfonts

PDF::Builder::Resource::Font::CoreFont->loadallfonts()
"Requiert" toutes les polices disponibles en tant que corefonts.
