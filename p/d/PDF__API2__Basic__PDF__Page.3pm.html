NOM

PDF::API2::Basic::PDF::Page - Objet de page PDF de bas niveau

DESCRIPTION

Représente une page de sortie en PDF. Elle conserve également une trace du flux de contenu, de toutes les ressources (telles que les polices) qui sont commutées, etc.

Page hérite de Pages en raison d'un certain nombre de méthodes partagées. Elles sont en réalité structurellement assez différentes.

VARIABLES D'INSTANCE

Une page a diverses variables de travail :

curstrm
Le flux actuellement ouvert

MÉTHODES

PDF::API2::Basic::PDF::Page->new($pdf, $parent, $index)

Crée une nouvelle page basée sur un objet de pages (peut-être l'objet racine).

La page est également ajoutée au parent à ce stade, de sorte que les pages soient ordonnées dans un document PDF dans l'ordre où elles sont créées plutôt que dans l'ordre où elles sont fermées.

Seuls les éléments essentiels du dictionnaire de page sont créés ici, tous les autres sont soit optionnels, soit peuvent être hérités.

La valeur facultative de l'index indique l'index dans la liste du parent où cette page doit être insérée (afin que les nouvelles pages n'aient pas besoin d'être ajoutées)

$p->ship_out($pdf)

Envoie la page vers le contexte de fichier de sortie donné
