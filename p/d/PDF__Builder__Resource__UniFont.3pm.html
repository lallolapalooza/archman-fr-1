NOM

PDF::Builder::Resource::UniFont - Support des polices Unicode

MÉTHODES

new

$font = PDF::Builder::Resource::UniFont->new($pdf, @fontspecs, %opts)
Retourne un objet uni-font.

SPÉCIFICATIONS_DE_POLICES : les polices peuvent être enregistrées en utilisant la référence de hachage suivante :

{
    font   => $obj_police,     # la police à enregistrer
    blocks => $spec_blocs,   # les blocs unicode pour lesquels la police est enregistrée
    codes  => $spec_codes,    # les points de code unicode, -*-
}

SPÉCIFICATIONS_DE_BLOCS :

[
     $bloc1, $bloc3,    # enregistrer la police pour les blocs 1 + 3
    [$blocA, $blocZ],   # enregistrer la police pour les blocs A .. Z
]

SPÉCIFICATIONS_DE_CODES :

[
     $cp1, $cp3,          # enregistrer la police pour les points de code 1 + 3
    [$cpA, $cpZ],         # enregistrer la police pour les points de code A .. Z
]

NOTE : si vous souhaitez enregistrer une police pour l'ensemble de l'espace unicode (c'est-à-dire U+0000 .. U+FFFF), spécifiez simplement un objet police sans la référence de hachage.

Options valides (%opts)

encode
Change l'encodage de la police par rapport à sa valeur par défaut. Voir "perldoc Encode" pour une liste des balises valides.
