$egs->strokealpha $alpha
La constante alpha de trait actuelle, spécifiant la forme constante ou la valeur d'opacité constante à utiliser pour les opérations de trait dans le modèle d'imagerie transparente.
$egs->fillalpha $alpha
Identique à strokealpha, mais pour les opérations de non-trait.
$egs->blendmode $nomFusion

Le mode de fusion actuel à utiliser dans le modèle d'imagerie transparente.
$egs->alphaisshape $booléen
Le drapeau source alpha (alpha est forme), spécifiant si le masque doux actuel et la constante alpha doivent être interprétés comme des valeurs de forme (vrai) ou des valeurs d'opacité (faux).
$egs->textknockout $booléen
Le drapeau d'évidement de texte, qui détermine le comportement des glyphes qui se chevauchent dans un objet texte dans le modèle d'imagerie transparente.
$egs->transparency $t
La transparence graphique, 0 étant complètement opaque et 1 étant complètement transparent. C'est une méthode de commodité qui définit les valeurs appropriées pour strokealpha et fillalpha.
$egs->opacity $op
L'opacité graphique, 1 étant complètement opaque et 0 étant complètement transparent. C'est une méthode de commodité qui définit les valeurs appropriées pour strokealpha et fillalpha.
