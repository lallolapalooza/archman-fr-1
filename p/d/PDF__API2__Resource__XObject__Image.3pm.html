PDF::API2::Resource::XObject::Image(3) Documentation Perl fournie par l'utilisateur PDF::API2::Resource::XObject::Image(3)

NOM

PDF::API2::Resource::XObject::Image - Classe de base pour les objets images raster externes

MÉTHODES

$image = PDF::API2::Resource::XObject::Image->new($pdf, $name)
Retourne un objet ressource image.
$width = $image->width($width)
Obtient ou définit la valeur de largeur pour l'objet image.
$height = $image->height($height)
Obtient ou définit la valeur de hauteur pour l'objet image.
$image->smask($xobject)
Définit l'objet image de masque souple.
$image->mask(@color_range)
$image->mask($xobject)
Définit le masque sur un objet XObject de masque d'image ou un tableau contenant une plage de couleurs à appliquer comme masque de clé de couleur.
$image->colorspace($name)
$image->colorspace($array)
Définit l'espace colorimétrique utilisé par l'image. Selon l'espace colorimétrique, il s'agira soit du nom de l'espace colorimétrique, soit d'un tableau contenant l'espace colorimétrique et tous les paramètres requis.

Si vous passez un tableau, les paramètres doivent déjà être encodés sous forme d'objets PDF. Le tableau lui-même peut également être un objet PDF. Sinon, un sera créé.

$image->bits_per_component($integer)
Définit le nombre de bits utilisés pour représenter chaque composante de couleur.
