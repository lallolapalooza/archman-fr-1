PDF::Builder::Basic::PDF::Name(3) Documentation Perl fournie par l'utilisateur PDF::Builder::Basic::PDF::Name(3)

NOM

PDF::Builder::Basic::PDF::Name - Stocke les noms PDF (les choses commençant par /)

Hérite de PDF::Builder::Basic::PDF::String

MÉTHODES

from_pdf

$n = PDF::Builder::Basic::PDF::Name->from_pdf($string)
Crée un nouvel objet chaîne (pas encore un objet complet) à partir d'une chaîne donnée. La chaîne est analysée selon les critères d'entrée avec échappement fonctionnel, particulièrement pour les Noms.

convertir

$n->convert($string, $pdf)
Convertit un nom en chaîne en supprimant le / et en convertissant tout encodage hexadécimal.

en_pdf

$s->en_pdf($pdf)
Retourne un nom formaté en PDF. $pdf est optionnel mais doit être l'objet Fichier PDF pour lequel le nom est destiné s'il est fourni.

string_vers_nom

PDF::Builder::Basic::PDF::Name->string_vers_nom($string, $pdf)
Encode convenablement la chaîne $string pour la sortie dans l'objet Fichier $pdf (le format exact peut dépendre de la version de $pdf).

nom_vers_string

PDF::Builder::Basic::PDF::Name->nom_vers_string($string, $pdf)
Décode convenablement la chaîne $string telle que lue depuis l'objet Fichier $pdf (le décodage exact peut dépendre de la version de $pdf). Principalement, annule l'encodage hexadécimal pour les versions PDF > 1.1.
