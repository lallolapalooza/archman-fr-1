PDF::Builder::NamedDestination(3) Documentation Perl fournie par l'utilisateur PDF::Builder::NamedDestination(3)

NOM

PDF::Builder::NamedDestination - Ajouter des destinations nommées (vues) à un PDF

Hérite de PDF::Builder::Basic::PDF::Dict

MÉTHODES

new

$dest = PDF::Builder::NamedDestination->new($pdf, ...)
Crée un nouvel objet de destination nommée. Tous les arguments optionnels supplémentaires seront transmis à "destination".

Types de destination

dest

$dest->dest($page, %opts)
Une destination (dest) est une vue particulière d'un PDF, composée d'un objet de page, de l'emplacement de la fenêtre sur cette page, et éventuellement d'arguments de coordonnées et de zoom. 
# L'emplacement XYZ prend trois arguments
my $dest1 = PDF::Builder::NamedDestination->new($pdf);
$dest->dest($pdf->open_page(1), 'xyz' => [$x, $y, $zoom]);
# L'emplacement Fit ne nécessite aucun argument, mais un est toujours
# nécessaire pour le tableau associatif
my $dest2 = PDF::Builder::NamedDestination->new($pdf);
$dest->dest($pdf->open_page(2), 'fit' => 1);

Voir "Options d'ajustement de page" dans PDF::Builder::Docs pour une liste des emplacements disponibles et leur syntaxe.

"xyz" est le réglage d'ajustement par défaut, avec une position (gauche et haut) et un zoom identiques à ceux de la page appelante.

Destinations cibles

link, goto

$dest->link($page, %opts)
Une action aller (link) change la vue vers une destination spécifiée (page, emplacement et facteur d'agrandissement).

Les paramètres sont décrits dans "dest".

Nom alternatif : "goto"

Initialement, cette méthode était "link", mais récemment PDF::API2 a changé le nom en "goto". "goto" est ajouté pour la compatibilité.

uri, url

$dest->uri($url)
Définit la destination comme un lancement d'URL avec l'URI $url.

Nom alternatif : "url"

Initialement, cette méthode était "url", mais récemment PDF::API2 a changé le nom en "uri". "url" est conservé pour la compatibilité.

launch, file

$dest->launch($file)
Définit la destination comme un lancement de fichier avec le chemin d'accès $file et des options d'ajustement de page %opts. L'application cible est exécutée. Notez que ce n'est pas un fichier PDF ou un fichier de navigateur, mais une application locale.

Nom alternatif : "file"

Initialement, cette méthode était "file", mais récemment PDF::API2 a changé le nom en "launch". "file" est conservé pour la compatibilité.

pdf, pdf_file, pdfile

$dest->pdf($pdf_file, $pagenum, %opts)
Définit la destination comme un fichier PDF avec le chemin d'accès $pdf_file, sur la page $pagenum, et les options %opts (identiques à dest()).

Noms alternatifs : "pdf_file" et "pdfile"

Initialement, cette méthode était "pdfile", et avait été renommée plus tôt en "pdf_file", mais récemment PDF::API2 a changé le nom en "pdf". "pdfile" et "pdf_file" sont conservés pour la compatibilité. Notez que les informations de position et de zoom sont toujours fournies comme élément de tableau associatif dans PDF::Builder, tandis que PDF::API2 a changé pour une chaîne de position et un tableau de dimensions.
