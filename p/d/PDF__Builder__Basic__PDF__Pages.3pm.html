PDF::Builder::Basic::PDF::Pages(3) Documentation Perl fournie par l'utilisateur PDF::Builder::Basic::PDF::Pages(3)

NOM

PDF::Builder::Basic::PDF::Pages - Élément hiérarchique de pages PDF

Hérite de PDF::Builder::Basic::PDF::Dict

DESCRIPTION

Un objet Pages est le parent d'autres objets Pages ou d'objets Page eux-mêmes.

MÉTHODES

new

PDF::Builder::Basic::PDF::Pages->new($pdf, $parent)
Ceci crée un nouvel objet Pages dans un PDF. Notez que le $parent ici n'est pas le contexte de fichier pour l'objet, mais l'objet Pages parent pour ces pages. Si nous utilisons cette classe pour créer un nœud racine, $parent doit pointer vers le contexte de fichier, qui est identifié par *ne pas* avoir de Type Pages. $pdf est l'objet fichier (ou une référence à un tableau d' *un seul* objet fichier [3.016 et plus tard, ou plusieurs objets fichiers plus tôt]) dans lequel créer le nouvel objet Pages.

find_page

$p->find_page($numéro_de_page)
Retourne la page donnée, en utilisant les valeurs de comptage de pages dans l'arbre des pages. Les pages commencent à 0.

add_page

$p->add_page($page, $numéro_de_page)
Insère la page avant le $numéro_de_page donné. $numéro_de_page peut être négatif pour compter à rebours depuis la FIN du document. -1 est après la dernière page. De même, $numéro_de_page peut être supérieur au nombre de pages actuellement dans le document, pour ajouter à la fin.

Cette méthode garantit seulement de fournir un arbre de pages raisonnable si les pages sont ajoutées à la fin ou au début du document. Les pages insérées au milieu du document peuvent simplement être insérées dans la feuille appropriée de l'arbre des pages sans ajouter de nouvelles branches ou feuilles, le laissant déséquilibré (performances plus lentes, mais toujours utilisable).

get_pages

@objets = $p->get_pages()
Retourne une liste d'objets Page dans le document, dans l'ordre des pages.

find_prop

$p->find_prop($clé)
Recherche dans l'arbre d'héritage pour trouver une propriété (clé).

add_font

$p->add_font($pdf, $police)
Crée ou modifie le dictionnaire des ressources à ce niveau de la hiérarchie. Si la police est déjà supportée, même à travers la hiérarchie, alors elle n'est pas ajoutée.

ATTENTION : si cette méthode était utilisée dans les anciennes versions, le code pouvait inverser l'ordre de $pdf et $police, nécessitant l'échange ad hoc de paramètres dans le code utilisateur, contrairement à la définition POD ci-dessus. Maintenant, le code correspond à la documentation.

bbox

$p->bbox($xmin,$ymin, $xmax,$ymax, $param)
$p->bbox($xmin,$ymin, $xmax,$ymax)
Spécifie la boîte englobante pour cette page et toutes les pages enfants. Si les valeurs sont identiques à celles héritées, aucun changement n'est effectué. $param spécifie le nom de l'attribut afin que d'autres 'boîtes englobantes' puissent être définies avec cette méthode.

proc_set

$p->proc_set(@entrées)
Assure que la ressource actuelle contient toutes les entrées dans les proc_sets listés. Si nécessaire, il crée un dictionnaire de ressources local pour y parvenir.

get_top

$p->get_top()
Retourne le sommet de l'arbre des pages.
