NOM

PDF::Builder::Basic::PDF::Page - Représente une page PDF

Hérite de PDF::Builder::Basic::PDF::Pages

DESCRIPTION

Représente une page de sortie en PDF. Elle conserve également la piste du flux de contenu, des ressources éventuelles (comme les polices) qui sont commutées, etc.

Page hérite de Pages en raison d'un certain nombre de méthodes partagées. Elles sont structurellement assez différentes.

VARIABLES D'INSTANCE

Une page possède diverses variables de travail :

' curstrm'
Le flux actuellement ouvert

MÉTHODES

new

PDF::Builder::Basic::PDF::Page->new($pdf, $parent, $index)
Crée une nouvelle page basée sur un objet pages (peut-être l'objet racine).

La page est également ajoutée au parent à ce moment-là, de sorte que les pages sont ordonnées dans un document PDF dans l'ordre où elles sont créées plutôt que dans l'ordre où elles sont fermées.

Seuls les éléments essentiels du dictionnaire de page sont créés ici, tous les autres sont soit facultatifs, soit peuvent être hérités.

La valeur d'index facultative indique l'index dans la liste parent où cette page doit être insérée (de sorte que les nouvelles pages n'ont pas besoin d'être ajoutées).

ship_out

$p->ship_out($pdf)
Expédie la page vers le contexte de fichier de sortie donné
