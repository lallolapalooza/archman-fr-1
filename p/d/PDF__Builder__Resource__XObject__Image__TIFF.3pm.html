NOM

PDF::Builder::Resource::XObject::Image::TIFF - prise en charge des images TIFF

Hérite de PDF::Builder::Resource::XObject::Image

MÉTHODES

new

$res = PDF::Builder::Resource::XObject::Image::TIFF->new($pdf, $file, %opts)
Retourne un objet image TIFF.

Si le paquet Graphics::TIFF est installé, la bibliothèque TIFF_GT sera utilisée à la place de la bibliothèque TIFF. Dans ce cas, l'utilisation de la bibliothèque TIFF peut être forcée via le drapeau "nouseGT" (voir la documentation de Builder pour image_tiff()).

Options:

'name' => 'string'
C'est le nom que vous pouvez donner à l'objet image TIFF. Le défaut est Ixnnnn.

N'oubliez pas que vous devez utiliser la méthode image_tiff de Builder.pm afin d'afficher un fichier TIFF.

usesLib

$mode = $tif->usesLib()
Retourne 1 si Graphics::TIFF est installé et utilisé, 0 si non installé, ou -1 si installé mais non utilisé (option nouseGT donnée à "image_tiff").

Attention : cette méthode ne peut être utilisée qu'*après* la création de l'objet image. Elle ne peut pas vous dire si Graphics::TIFF est disponible avant son utilisation réelle, au cas où vous voudriez utiliser une fonctionnalité disponible uniquement dans TIFF_GT. Voir l'appel LA_GT() de <PDF::Builder> si vous avez besoin de le savoir à l'avance.

tiffTag

$value = $tif->tiffTag($tag)
retourne la valeur du tiff-tag interne.

Tags utiles :

xRes, yRes (dpi; pixels/cm si resUnit==3)
