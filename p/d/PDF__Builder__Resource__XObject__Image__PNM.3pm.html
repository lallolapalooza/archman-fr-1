NOM

PDF::Builder::Resource::XObject::Image::PNM - Routines de support pour la bibliothèque d'images PNM (Portable aNy Map)

Hérite de PDF::Builder::Resource::XObject::Image

MÉTHODES

new

$res = PDF::Builder::Resource::XObject::Image::PNM->new($pdf, $file, %opts)
Options:
'name' => 'string'
C'est le nom que vous pouvez donner à l'objet image PNM. La valeur par défaut est Nxnnnn.
'compress' => 1
C'est la compression que vous pouvez donner à l'objet image PNM. Toute valeur provoquera l'utilisation de la compression Flate, sinon (si "compress" n'est pas spécifié), ASCIIHexDecode est utilisé.

Retourne une image dans le PDF. Les types PNM 1 (bi-niveau ASCII/plain (PBM)), 2 (niveau de gris ASCII/plain (PGM)), 3 (RVB ASCII/plain (PPM)), 4 (bi-niveau binaire/brut (PBM)), 5 (niveau de gris binaire/brut (PGM)), et 6 (RVB binaire/brut (PPM)) sont pris en charge.

Pour le bi-niveau, seules les valeurs 0/1 (blanc/noir) sont prises en charge. Pour le niveau de gris, l'échantillon maximum (blanc complet) peut être n'importe quoi de 1 à 65535, 0 étant noir complet. Si la valeur d'échantillon maximale est de 255 ou moins, un octet de données binaires brutes par pixel, sinon deux octets. Pour le RVB, chaque échantillon (pleine intensité de cette couleur) peut être n'importe quoi de 1 à 65535 (le même maximum pour les trois couleurs), 0 étant noir complet. Si la valeur d'échantillon maximale est de 255 ou moins, trois octets de données binaires brutes par pixel, sinon six octets.

N'oubliez pas que vous devez utiliser la méthode image_pnm de Builder.pm pour utiliser cette fonctionnalité.
