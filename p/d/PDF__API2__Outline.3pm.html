PDF::API2::Outline(3) Documentation Perl contribuée par l'utilisateur PDF::API2::Outline(3)

NOM

PDF::API2::Outline - Gérer les plans PDF (aussi appelés signets)

SYNOPSIS

# Obtenir/créer l'arbre de plan de niveau supérieur
my $outline = $pdf->outline();
# Ajouter une entrée
my $item = $outline->outline();
$item->title('Première page');
$item->destination($pdf->open_page(1));

MÉTHODES

Examiner l'arbre de plan

has_children

my $boolean = $outline->has_children();

Retourne vrai si l'élément de plan actuel a des enfants.

count

my $integer = $outline->count();

Retourne le nombre de descendants visibles lorsque l'élément de plan actuel est ouvert (développé).

first

my $child = $outline->first();

Retourne le premier enfant du niveau de plan actuel, s'il en existe un.

last

my $child = $outline->last();

Retourne le dernier enfant du niveau de plan actuel, s'il en existe un.

parent

my $parent = $outline->parent();

Retourne le parent de l'élément actuel, s'il n'est pas au plus haut niveau de l'arbre de plan.

prev

my $sibling = $outline->prev();

Retourne l'élément précédent du niveau actuel de l'arbre de plan.

next

my $sibling = $outline->next();

Retourne l'élément suivant du niveau actuel de l'arbre de plan.

Modifier l'arbre de plan

outline

my $child = $outline->outline();

Ajoute un élément de plan à la fin de la liste des enfants du plan actuel.

insert_after

my $sibling = $outline->insert_after();

Ajoute un élément de plan immédiatement après l'élément actuel.

insert_before

$sibling = $outline->insert_before();

Ajoute un élément de plan immédiatement avant l'élément actuel.

delete

$outline->delete();

Supprime l'élément de plan actuel de l'arbre de plan. Si l'élément a des enfants, ils seront effectivement supprimés également car ils ne seront plus liés.

is_open

# Obtenir
my $boolean = $outline->is_open();
# Définir
my $outline = $outline->is_open($boolean);

Obtenir/définir si le plan est développé ou réduit.

Définir les attributs du plan

title

# Obtenir
my $title = $outline->title();
# Définir
$outline = $outline->title($text);

Obtenir/définir le titre de l'élément de plan.

destination

$outline = $outline->destination($destination, $location, @args);

Définit la page de destination et la position optionnelle du plan. $location et @args sont tels que définis dans "destination" dans PDF::API2::NamedDestination.

$destination peut éventuellement être le nom d'une destination nommée définie ailleurs.

uri

$outline = $outline->uri($uri);

Lance une URI — généralement une page Web — lorsque l'élément de plan est activé.

launch

$outline->launch($file);

Lance une application ou un fichier lorsque l'élément de plan est activé.

pdf

$outline = $outline->pdf($filename, $page_number, $location, @args);

Ouvre un autre fichier PDF à un numéro de page particulier (la première page est zéro, ce qui est aussi la valeur par défaut). La page peut éventuellement être positionnée à un emplacement particulier si $location et @args sont définis — voir "destination" dans PDF::API2::NamedDestination pour les réglages possibles.
