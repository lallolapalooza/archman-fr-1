FORMATS DE PAPIER PRÉDÉFINIS

Les dimensions sont en points.

paper_size

@box_corners = paper_size($x1,$y1, $x2,$y2);
Retourne un tableau ($x1,$y1, $x2,$y2) (boîte englobante complète).
@box_corners = paper_size($x1,$y1);
Retourne un tableau (0,0, $x1,$y1) (demi-boîte englobante).
@box_corners = paper_size($media_name);
Retourne un tableau (0,0, largeur_papier,hauteur_papier) pour le média nommé.
@box_corners = paper_size($x1);
Retourne un tableau (0,0, $x1,$x1) (quadratique simple).

Sinon, le tableau (0,0, 612,792) (dimensions US Letter) est retourné.

getPaperSizes

%sizes = getPaperSizes();
Retourne une table de hachage contenant les alias de formats de papier disponibles en tant que clés et leurs dimensions en tant que référence de tableau à deux éléments.

Voir la source de PDF::Builder::Resource::PaperSizes pour la liste complète.

CHAÎNE VERS DIMENSION

Convertit une chaîne "nombre [unité]" en la valeur dans les unités souhaitées. Les unités ne sont pas sensibles à la casse (l'entrée est d'abord convertie en minuscules).

Unités prises en charge : mm, cm, in (pouce), pt (point typographique, 72/pouce), ppt (point d'imprimeur, 72.27/pouce), pc (pica, 6/pouce), dd (point Didot, 67.5532/pouce), et cc (cicéros, 5.62943/pouce). D'autres peuvent être ajoutées facilement. Les unités invalides entraînent une erreur fatale.

str2dim

$value = str2dim($string, $type, $default_units);
$string contient un nombre et, éventuellement, une unité. Les espaces entre le nombre et l'unité sont facultatifs. Par exemple, '200', '35.2 mm' et '1.5in' sont toutes des chaînes d'entrée valides.

$type sert à valider la valeur numérique de la chaîne d'entrée $string. Le premier caractère est i si un entier est requis (pas de point décimal), ou f pour d'autres nombres (à virgule flottante). Ensuite, il y a un c facultatif pour indiquer qu'une valeur d'entrée hors plage doit être silencieusement limitée pour rester dans la plage donnée (le défaut est de déclencher une erreur fatale). Enfin, une expression de plage facultative : {limite inférieure,limite supérieure}. Les limites sont des nombres ou * (pour indiquer +/- l'infini (pas de limite) à cette extrémité de la plage. { est [ pour indiquer que la limite inférieure est incluse dans la plage, tandis que ( indique que la limite inférieure est exclue de la plage. De même, } est ] pour la limite supérieure incluse, et ) pour exclue. Les limites (et la limitation silencieuse, ou l'erreur fatale si l'entrée est hors plage) s'appliquent à la valeur d'entrée, avant la conversion vers les unités de sortie.

Exemples de types :

'f(*,*)' aucune limite (par défaut) -- toutes les valeurs sont OK
'i(0,*)' entier supérieur à 0
'fc[-3.2,7.86]' un nombre entre -3.2 et 7.86, la valeur étant limitée pour rester dans cette plage (y compris les points de terminaison)

$default_units est une chaîne obligatoire, indiquant les unités vers lesquelles l'entrée est convertie. Par exemple, si les unités par défaut sont 'pt' et que la chaîne d'entrée est '2 in', la valeur de sortie serait '144'. Si la chaîne d'entrée n'a pas d'unités explicites, elle est supposée être dans les unités par défaut (aucune conversion n'est effectuée).
