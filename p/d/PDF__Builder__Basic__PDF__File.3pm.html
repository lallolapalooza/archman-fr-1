PDF::Builder::Basic::PDF::File(3) Documentation Perl fournie par l'utilisateur PDF::Builder::Basic::PDF::File(3)

NOM

PDF::Builder::Basic::PDF::File - Détient les trailers et les tables de références croisées pour un fichier PDF

SYNOPSIS

$p = PDF::Builder::Basic::PDF::File->open("filename.pdf", 1);
$p->new_obj($obj_ref);
$p->free_obj($obj_ref);
$p->append_file();
$p->close_file();
$p->release();       # IMPORTANT !

DESCRIPTION

Cette classe gère les aspects d'annuaire d'un fichier PDF. Il y a deux parties à l'annuaire : l'objet d'annuaire principal, qui est le parent de tous les autres objets, et une chaîne de tables de références croisées et de dictionnaires de trailers correspondants, commençant par l'objet d'annuaire principal.

VARIABLES D'INSTANCE

Au sein de cette hiérarchie de classes, plutôt que de rendre tout visible via des méthodes, ce qui représenterait beaucoup de travail, il existe diverses variables d'instance accessibles via une référence associative. Pour distinguer les variables d'instance des variables de contenu (qui peuvent provenir du contenu PDF lui-même), chaque nom de variable de ce type commencera par un espace.

Les noms de variables qui ne commencent pas par un espace reflètent directement des éléments dans un dictionnaire PDF. Dans le cas d'un "PDF::Builder::Basic::PDF::File", les éléments reflètent ceux du dictionnaire de trailer.

Étant donné que certaines variables ne sont pas destinées à être accessibles par l'utilisateur de la classe, les variables sont marquées dans la documentation avec (R) pour indiquer qu'une telle entrée ne doit être utilisée qu'à des fins d'information en lecture seule. (P) indique que l'information est privée et n'est pas du tout destinée à être utilisée par l'utilisateur, mais est incluse dans la documentation par souci de complétude et pour s'assurer que personne d'autre n'essaie de l'utiliser.

newroot
Cette variable permet à l'utilisateur de créer une nouvelle entrée racine qui apparaîtra dans le dictionnaire de trailer lorsqu'il sera écrit ou ajouté au fichier. Si vous souhaitez remplacer l'élément racine dans le dictionnaire que vous avez, utilisez cette entrée pour l'indiquer sans perdre l'entrée Root actuelle. Notez que newroot doit pointer vers un objet de niveau PDF et non pas juste vers un dictionnaire, qui n'a pas de statut d'objet.
INFILE (R)
Contient le descripteur de fichier utilisé pour lire ces informations dans cet annuaire PDF. C'est un objet IO.
fname (R)
C'est le nom de fichier reflété par INFILE, ou l'objet IO original passé en paramètre.
update (R)
Indique que le fichier lu a été ouvert pour mise à jour et qu'à un moment donné, "$p->appendfile()" peut être appelé pour mettre à jour le fichier avec les changements apportés à la représentation en mémoire.
maxobj (R)
Contient le premier numéro d'objet utilisable au-dessus de tous ceux qui sont déjà apparus dans le fichier jusqu'à présent.
outlist (P)
C'est une liste de Objind qui doivent être générés lors du prochain appel à appendfile() ou outfile().
firstfree (P)
Contient le premier objet libre dans la liste des objets libres. Les objets libres sont retirés du début de la liste et ajoutés à la fin.
lastfree (P)
Contient le dernier objet libre dans la liste des libres. Il peut être le même que "firstfree" s'il n'y a qu'un seul objet libre.
objcache (P)
Tous les objets sont conservés en cache pour s'assurer qu'un système n'a qu'une seule occurrence de chaque objet. En effet, la classe objind agit comme une classe de type conteneur pour maintenir la structure de l'objet PDF, et il serait regrettable qu'il y ait deux espace-placeurs identiques circulant dans un système.
epos (P)
La position de fin du fichier lu.

Chaque dictionnaire de trailer contient un certain nombre de variables d'instance privées qui maintiennent la chaîne.

loc (P)
Contient la localisation du début de la table de références croisées précédant le trailer.
xref (P)
Contient un tableau anonyme de chaque entrée de la table de références croisées.
prev (P)
Une référence à la table précédente. Notez que cela diffère de l'entrée Prev qui est dans le PDF, laquelle contient l'emplacement de la table de références croisées précédente.

MÉTHODES

new

PDF::Builder::Basic::PDF::File->new()
Crée un nouvel objet de fichier vide qui peut servir d'hôte à d'autres objets PDF. Puisqu'aucun fichier n'est associé à cet objet, on suppose que l'objet est créé en vue de la création d'un nouveau fichier PDF.

open

$p = PDF::Builder::Basic::PDF::File->open($filename, $update, %options)
Ouvre le fichier et lit tous les trailers et tables de références croisées pour construire un annuaire complet d'objets.

$filename peut être une chaîne de caractères ou un objet IO.

$update spécifie si ce fichier est ouvert pour mise à jour et édition (valeur VRAIE), ou simplement pour lecture (valeur FAUSSE ou indéfinie).

%options peut inclure

diags => 1
Si "diags" est réglé sur 1, divers messages d'avertissement seront donnés si une structure PDF suspecte est trouvée, et certaines corrections pourront être tentées. Rien ne garantit que toute correction rendra le PDF légitime, ni qu'il n'y aura pas d'autres problèmes détectés plus tard. Si ce drapeau n'est pas donné, et qu'un problème structurel est trouvé, il est fort probable que des erreurs (et même un crash du programme) surviennent plus tard. Si vous rencontrez des crashs lors de la lecture d'un fichier PDF, essayez de l'exécuter avec "diags" et voyez ce qui est rapporté.

Il existe de nombreux fichiers PDF "en circulation" qui, bien qu'ils ne soient pas conformes aux normes d'Adobe, semblent être tolérés par les lecteurs PDF. Ainsi, Builder ne bloquera pas sur eux, mais se contentera de commenter leur existence.

version

$new_version = $p->pdf_version($version, %opts) # Définir 
$ver = $p->pdf_version() # Obtenir
Obtient/définit la version PDF (par exemple, 1.5). Le réglage définit à la fois les versions de l'en-tête et du trailer. L'obtention renvoie la plus élevée des versions de l'en-tête et du trailer.

Pour la compatibilité avec les versions antérieures, si aucun point décimal n'est donné, supposez que "1." précède le nombre donné.

Un message d'avertissement est donné si vous tentez de diminuer la version PDF, car vous pourriez avoir déjà lu un fichier de niveau supérieur, ou utilisé une fonctionnalité de niveau supérieur. Ce message est supprimé si l'option 'silent' est donnée avec n'importe quelle valeur.

header_version

$new_version = $p->header_version($version, %opts) # Définir
$version = $p->header_version() # Obtenir
Obtient/définit la version PDF stockée dans l'en-tête du fichier.

Pour la compatibilité avec les versions antérieures, si aucun point décimal n'est donné, supposez que "1." précède le nombre donné.

Un message d'avertissement est donné si vous tentez de diminuer la version PDF, car vous pourriez avoir déjà lu un fichier de niveau supérieur, ou utilisé une fonctionnalité de niveau supérieur. Ce message est supprimé si l'option 'silent' est donnée avec n'importe quelle valeur.

trailer_version

$new_version = $p->trailer_version($version, %opts) # Définir
$version = $p->trailer_version() # Obtenir
Obtient/définit la version PDF stockée dans le catalogue du document.

Notez que le niveau PDF minimum pour une version de trailer est 1.4. Il n'est pas permi

Mantenga toda la estructura del archivo.

Para compatibilidad con versiones anteriores, si no se especifica un punto decimal, asume que el valor "1." precede al número dado.

Se muestra un mensaje de alerta si intentas reducir la versión del PDF, ya que podrías haber leído un archivo de mayor nivel o utilizado una función de mayor nivel. Este mensaje se suprime si se proporciona el opción 'silent' con cualquier valor.

require_version

$prev_version = $p->require_version($version)
Asegura que la versión del PDF sea de al menos $version. Silenciosamente establece la versión a la más alta.

release

$p->release()
Libera toda la memoria usada por el documento PDF y todos sus componentes. Después de llamar a este método, no esperes que haya nada restante en el objeto "PDF::Builder::Basic::PDF::File" (así que si necesitas guardar, hazlo antes de llamar a este método).

NOTA, que es importante que lo llames a cualquier objeto "PDF::Builder::Basic::PDF::File" cuando desees destruirlo y liberar su memoria. Internamente, los archivos PDF tienen un número enorme de referencias cruzadas, y esto causa referencias cíclicas dentro de las estructuras internas. Llamar a release() causa una limpieza bruta de las estructuras de datos, liberando todo el espacio de memoria. Una vez que hayas llamado a este método, aunque lo intentes, no podrás hacer nada más con el objeto "PDF::Builder::Basic::PDF::File"; tendrá ningún estado interno.

append_file

$p->append_file()
Añade los objetos de salida a un archivo leído y luego añade la tabla adecuada.

out_file

$p->out_file($fname)
Escribe un archivo PDF en un archivo con el nombre especificado, basado en la lista actual de objetos a ser salida. Crea el diccionario de tráiler basado en la información en $self

$fname puede ser una cadena o un objeto IO.

create_file

$p->create_file($fname)
Crea un nuevo archivo de salida (sin verificar si un archivo ya está abierto) con el nombre o objeto IO especificado. Nota: asegúrate de que "$p->{' version'}" esté correctamente configurado antes de llamar a esta función.

close_file

$p->close_file()
Cierra el archivo de salida para la impresión, imprimiendo el tráiler, etc.

readval

($value, $str) = $p->readval($str, %opts)
Lee un valor PDF desde la posición actual del archivo. Si $str es demasiado corto, lee más de lo que está en la posición actual del archivo hasta que se lea todo el objeto. Esto es una llamada recursiva que puede absorber un flujo completo (no procesado).

Devuelve la estructura de datos recursiva leída y también el str actual que se ha leído del archivo.

read_obj

$ref = $p->read_obj($objind, %opts)
Dado una referencia de objeto indirecto, localiza y lee el objeto, devolviendo el objeto leído.

read_objnum

$ref = $p->read_objnum($num, $gen, %opts)
Devuelve un objeto completamente leído de número y generación especificados en este archivo.

new_obj

$objind = $p->new_obj($obj)
Crea un nuevo objeto de referencia libre basado en el espacio de referencias libre en la cadena de referencias. Si no hay espacio libre, piensa en un nuevo número. Si $obj, entonces lo convierte en este nuevo objeto en lugar de devolver un nuevo objeto.

out_obj

$p->out_obj($obj)
Indica que la referencia dada debería aparecer en la tabla de referencias de salida, ya sea con datos o liberado.

free_obj

$p->free_obj($obj)
Marca una referencia de objeto como liberada.

remove_obj

$p->remove_obj($objind)
Elimina el objeto de todas las posiciones donde lo puedas recordar.

ship_out

$p->ship_out(@objects)
$p->ship_out()
Envía los objetos dados (o todos los objetos de salida si @objects está vacío) a archivo de salida actual (asumiendo que existe). Los objetos liberados no se envían y una vez enviado, se cambia para que este archivo sea el origen y no se lo envíe nuevamente, a menos que se llame a out_obj de nuevo. Nota que un objeto enviado puede re-salirse o incluso ser liberado, pero no causará que los datos ya salidos sean modificados.

copy

$p->copy($outpdf, \&filter)
Itera sobre cada objeto en el archivo leyendo el objeto, llamando a "filter" con el objeto, y salida el resultado. Si "filter" no está definido, solo copia el input a output.

MÉTODOS Y FUNCIONES PRIVADAS

Los siguientes métodos y funciones son considerados privados a esta clase. Esto no significa que no puedas usarlos si tienes una necesidad, sino que no están diseñados para los usuarios de esta clase.

locate_obj

$offset = $p->locate_obj($num, $gen)
Devuelve un offset de archivo para el objeto solicitado al seguir la cadena de tablas de referencias cruzadas hasta encontrar la que quieres.

update

update($fh, $str, $instream)
Lee más datos de $fh para asegurar que $str tenga al menos una línea completa para trabajar en "readval". A esta altura también tomamos el tiempo para ignorar los comentarios.

test_obj

$objind = $p->test_obj($num, $gen)
Prueba el caché para ver si una referencia de objeto (que puede haber sido getobj()ed) ha sido almacenada. Devuelve la referencia si ha sido.

add_obj

$p->add_obj($objind)
Añade el objeto dado al caché de objetos internos.

readxrtr

$tdict = $p->readxrtr($xpos, %options)
Función recursiva que lee cada tabla de referencias y tráiler por turnos hasta que no haya más.

Devuelve un diccionario correspondiente a la cadena de tráiler. Cada tráiler también incluye la tabla de referencias cruzadas correspondiente.

La estructura del elemento xref privado en un diccionario de tráiler es una estructura anónima de elementos de referencias cruzadas por número de objeto. Cada elemento consiste en un array de 3 elementos correspondientes a los tres elementos leídos en [location, generation number, free or used]. Véase la especificación de PDF para detalles.

Ver "open" para las opciones permitidas.

out_trailer

$p->out_trailer($tdict, $update)
$p->out_trailer($tdict)
Imprime el cuerpo y el tráiler de un archivo PDF imprimiendo todos los objetos en el 'outlist' y luego imprimiendo una tabla de referencias cruzadas para esos objetos y cualquier que haya sido liberado. Luego imprime el diccionario final y el código del tráiler.

_new

PDF::Builder::Basic::PDF::File->_new()
Crea un objeto muy vacío de PDF (usado por new() y open())
