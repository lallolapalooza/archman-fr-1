NOM

PDF::API2::Resource::Font::BdFont - Module pour utiliser les polices bitmapées.

SYNTAXE

#
use PDF::API2;
#
$pdf = PDF::API2->new;
$sft = $pdf->bdfont($file);
#

MÉTHODES

$font = PDF::API2::Resource::Font::BdFont->new $pdf, $font, %options
Retourne un objet BmpFont.

Les %options valides sont :

-encode ... change l'encodage de la police par rapport à son défaut. Voir le module Encode de Perl pour les valeurs prises en charge.

-pdfname ... change le nom de référence de la police par rapport à son défaut. Le nom de référence est normalement généré automatiquement et peut être récupéré via $pdfname=$font->name.
