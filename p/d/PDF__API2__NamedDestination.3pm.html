NOM

PDF::API2::NamedDestination - Ajouter des destinations nommées (vues) à un PDF

MÉTHODES

new

$destination = PDF::API2::NamedDestination->new($pdf, ...);

Crée un nouvel objet de destination nommée. Si des arguments supplémentaires sont présents, ils seront passés à destination().

destination

$destination = $destination->destination($page, $location, @args);

Une destination est une vue particulière d'un PDF, composée d'un objet page, de l'emplacement de la fenêtre sur cette page, et d'arguments possibles pour les coordonnées et le zoom.

# L'emplacement XYZ prend trois arguments
my $dest1 = PDF::API2::NamedDestination->new($pdf);
$dest->destination($pdf->open_page(1), 'xyz' => ($x, $y, $zoom));
# L'emplacement Fit ne nécessite aucun argument
my $dest2 = PDF::API2::NamedDestination->new($pdf);
$dest->destination($pdf->open_page(2), 'fit');

Les emplacements suivants sont disponibles :

  • xyz ($left, $top, $zoom)

    Affiche la page avec les coordonnées ($left, $top) positionnées dans le coin supérieur gauche de la fenêtre et le contenu de la page agrandi par le facteur $zoom. Une valeur "undef" pour l'un des arguments spécifie que la valeur actuelle de cet argument doit être conservée inchangée. Un facteur de zoom de 0 a la même signification que "undef".

  • fit

    Affiche la page en agrandissant son contenu juste assez pour que la page entière tienne dans la fenêtre, horizontalement et verticalement. Si les facteurs d'agrandissement horizontal et vertical requis sont différents, utilisez le plus petit des deux, en centrant la page dans la fenêtre dans l'autre dimension.

  • fith ($top)

    Affiche la page avec la coordonnée verticale $top positionnée sur le bord supérieur de la fenêtre et le contenu de la page agrandi juste assez pour que toute la largeur de la page tienne dans la fenêtre. Une valeur "undef" pour $top spécifie que la valeur actuelle de cet argument doit être conservée inchangée.

  • fitv ($left)

    Affiche la page avec la coordonnée horizontale $left positionnée sur le bord gauche de la fenêtre et le contenu de la page agrandi juste assez pour que toute la hauteur de la page tienne dans la fenêtre. Une valeur "undef" pour $left spécifie que la valeur actuelle de cet argument doit être conservée inchangée.

  • fitr ($left, $bottom, $right, $top)

    Affiche la page en agrandissant son contenu juste assez pour que le rectangle spécifié par les coordonnées $left, $bottom, $right et $top tienne entièrement dans la fenêtre, horizontalement et verticalement. Si les facteurs d'agrandissement horizontal et vertical requis sont différents, utilisez le plus petit des deux, en centrant le rectangle dans la fenêtre dans l'autre dimension.

  • fitb

    Affiche la page en agrandissant son contenu juste assez pour que sa boîte englobante tienne entièrement dans la fenêtre, horizontalement et verticalement. Si les facteurs d'agrandissement horizontal et vertical requis sont différents, utilisez le plus petit des deux, en centrant la boîte englobante dans la fenêtre dans l'autre dimension.

  • fitbh ($top)

    Affiche la page avec la coordonnée verticale $top positionnée sur le bord supérieur de la fenêtre et le contenu de la page agrandi juste assez pour que toute la largeur de sa boîte englobante tienne dans la fenêtre. Une valeur "undef" pour $top spécifie que la valeur actuelle de cet argument doit être conservée inchangée.

  • fitbv ($left)

    Affiche la page avec la coordonnée horizontale $left positionnée sur le bord gauche de la fenêtre et le contenu de la page agrandi juste assez pour que toute la hauteur de sa boîte englobante tienne dans la fenêtre. Une valeur "undef" pour $left spécifie que la valeur actuelle de cet argument doit être conservée inchangée.

goto

$destination = $destination->goto($page, $location, @args);

Une action « aller à » change la vue pour une destination spécifiée (page, emplacement et facteur d'agrandissement).

Les paramètres sont tels que décrits dans "destination".

uri

$destination = $destination->uri($uri);

Une action URI indique qu'un URI — généralement une page web — doit être lancé.

launch

$destination = $destination->launch($file);

Une action de lancement exécute une application ou ouvre ou imprime un document.

$file contient le chemin d'accès à l'application à lancer ou au document à ouvrir ou imprimer.

pdf

$destination = $destination->pdf($file, $page_number, $location, @args);

Similaire à "goto", mais la destination se trouve dans un autre fichier PDF situé à $file. $page_number est un entier plutôt qu'un objet page, et les autres paramètres sont tels que décrits dans "destination".
