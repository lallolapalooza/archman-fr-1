NOM

PDF::Builder::Basic::PDF::Array - Correspond à un tableau PDF

Hérite de PDF::Builder::Basic::PDF::Objind

MÉTHODES

new

PDF::Array->new($parent, @values)
Crée un tableau avec le parent de stockage donné et une liste optionnelle de valeurs pour initialiser le tableau.

outobjdeep

$a->outobjdeep($fh, $pdf)
Extrait un tableau sous forme de tableau PDF vers le descripteur de fichier donné. Il est inhabituel de devoir appeler cette méthode depuis du code utilisateur.

elements

$a->elements()
Retourne le contenu du tableau.

add_elements

$a->add_elements(@elements)
Ajoute les éléments donnés à la fin du tableau. Un élément n'est ajouté que s'il est défini.

remove_element

$a->remove_element($element)
Supprime toutes les occurrences d'un élément d'un tableau.

val

$a->val()
Retourne une référence au contenu du tableau.

copy

$a->copy($pdf)
Copie le tableau avec une copie profonde des éléments qui ne sont pas des objets PDF complets par rapport à un contexte de sortie $pdf particulier.
