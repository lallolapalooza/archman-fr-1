PDF::API2::Basic::PDF::Name(3) Documentation Perl fournie par la communauté PDF::API2::Basic::PDF::Name(3)

NOM

PDF::API2::Basic::PDF::Name - Objet nom PDF de bas niveau

MÉTHODES

PDF::API2::Basic::PDF::Name->from_pdf($string)

Crée un nouvel objet chaîne (pas encore un objet complet) à partir d'une chaîne donnée. La chaîne est analysée selon les critères d'entrée avec les échappements fonctionnels, spécifiques aux Noms.

$n->convert ($string, $pdf)

Convertit un nom en une chaîne en supprimant le / et en convertissant toute manipulation hexadécimale.

$s->as_pdf ($pdf)

Retourne un nom formaté en PDF. $pdf est optionnel mais doit être l'objet Fichier PDF pour lequel le nom est destiné s'il est fourni.

PDF::API2::Basic::PDF::Name->string_to_name ($string, $pdf)

Encode la chaîne $string de manière appropriée pour la sortie dans l'objet Fichier $pdf (le format exact peut dépendre de la version de $pdf).

PDF::API2::Basic::PDF::Name->name_to_string ($string, $pdf)

Décode la chaîne $string de manière appropriée telle qu'elle est lue à partir de l'objet Fichier $pdf (le décodage exact peut dépendre de la version de $pdf). Principalement, annule l'encodage hexadécimal pour les versions PDF > 1.1.
