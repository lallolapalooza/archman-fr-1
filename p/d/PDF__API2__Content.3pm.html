PDF::API2::Content(3) Documentation Perl fournie par l'utilisateur PDF::API2::Content(3)

NOM

PDF::API2::Content - Méthodes pour ajouter des graphiques et du texte à un PDF

SYNOPSIS

# Commencer avec une page PDF (nouvelle ou ouverte)
my $pdf = PDF::API2->new();
my $page = $pdf->page();
# Ajouter un nouvel objet de contenu
my $content = $page->graphics();
my $content = $page->text();
# Ensuite, appeler les méthodes ci-dessous pour ajouter des graphiques et du texte à la page.

TRANSFORMATIONS DE COORDONNÉES

Les méthodes de cette section modifient le système de coordonnées pour l'objet de contenu actuel par rapport au reste du document.

Les modifications apportées au système de coordonnées n'affectent que les chemins ou le texte ultérieurs.

Un appel à l'une des méthodes de cette section réinitialise le système de coordonnées avant d'appliquer ses modifications, à moins que l'option "relative" ne soit définie.

translate

$content = $content->translate($x, $y);

Déplace l'origine le long des axes x et y.

rotate

$content = $content->rotate($degrees);

Fait pivoter le système de coordonnées dans le sens inverse des aiguilles d'une montre.

Utilisez un argument négatif pour faire pivoter dans le sens des aiguilles d'une montre.

scale

$content = $content->scale($x, $y);

Met à l'échelle (étire) les systèmes de coordonnées le long des axes x et y. Une valeur de 1 pour $x ou $y représente une échelle de 100 % (c'est-à-dire aucune modification).

skew

$content = $content->skew($a, $b);

Incline le système de coordonnées de $a degrés (sens inverse des aiguilles d'une montre) par rapport à l'axe x et de $b degrés (sens des aiguilles d'une montre) par rapport à l'axe y.

transform

$content = $content->transform(
    translate => [$x, $y],
    rotate    => $degrees,
    scale     => [$x, $y],
    skew      => [$a, $b],
    repeat    => $boolean,
);

Effectue plusieurs transformations de coordonnées, dans l'ordre recommandé par la spécification PDF (translation, rotation, mise à l'échelle, puis inclinaison). Les options omises ne seront pas modifiées.

Si "repeat" est vrai et s'il ne s'agit pas du premier appel à une méthode de transformation, la transformation précédente sera à nouveau effectuée, modifiée par tous les autres arguments fournis.

matrix

$graphics = $graphics->matrix($a, $b, $c, $d, $e, $f);
($a, $b, $c, $d, $e, $f) = $text->matrix($a, $b, $c, $d, $e, $f);

Définit manuellement la matrice de transformation actuelle. Sauf si vous avez un besoin particulier d'entrer manuellement les transformations, vous devriez utiliser la méthode "transform" à la place.

La valeur de retour diffère selon que l'appelant est un objet de contenu graphique ou un objet de contenu texte.

ÉTAT GRAPHIQUE

save

$content = $content->save();

Enregistre l'état graphique actuel dans une pile.

restore

$content = $content->restore();

Restaure le dernier état graphique enregistré, en le retirant de la pile.

line_width

$content = $content->line_width($points);

Définit l'épaisseur du trait en points.

line_cap

$content = $content->line_cap($style);

Définit la forme utilisée aux extrémités des sous-chemins ouverts (et des tirets, le cas échéant) lorsqu'ils sont tracés.

  • "butt" ou 0 = Extrémité droite, par défaut

    Le trait se termine à l'extrémité du chemin, sans projection.

  • "round" ou 1 = Extrémité arrondie)

    Un arc est dessiné autour de l'extrémité du chemin avec un diamètre égal à l'épaisseur du trait, et il est rempli.

  • "square" ou 2 = Extrémité carrée projetée

    Le trait se prolonge au-delà de l'extrémité du chemin de la moitié de l'épaisseur du trait.

line_join

$content = $content->line_join($style);

Définit le style de jointure à utiliser aux coins d'un chemin.

  • "miter" ou 0 = Jointure en onglet, par défaut

    Les bords extérieurs du trait s'étendent jusqu'à ce qu'ils se rencontrent, jusqu'à la limite spécifiée ci-dessous. Si la limite est dépassée, une jointure en biseau est utilisée à la place.

  • "round" ou 1 = Jointure arrondie

    Un cercle avec un diamètre égal à l'épaisseur du trait est dessiné autour du point d'angle, produisant un coin arrondi.

  • "bevel" ou 2 = Jointure en biseau

    Un triangle est dessiné pour combler l'encoche entre les deux traits.

miter_limit

$content = $content->miter_limit($ratio);

Définit la limite de l'onglet lorsque le style de jointure est une jointure en onglet.

Le $ratio est la longueur maximale de l'onglet (du coin intérieur au coin extérieur) divisée par l'épaisseur du trait. Tout onglet dépassant ce ratio sera converti en jointure en biseau. L'effet pratique est que les lignes se rencontrant sous des angles faibles sont coupées au lieu de produire de longs coins pointus.

Il n'y a pas de limite d'onglet par défaut documentée.

line_dash_pattern

# Ligne pleine
$content = $content->line_dash_pattern();
# Lignes et espaces de longueur égale
$content = $content->line_dash_pattern($length);
# Longueurs de ligne et d'espace spécifiées
$content = $content->line_dash_pattern($line1, $gap1, $line2, $gap2, ...);
# Décaler le point de départ
$content = $content->line_dash_pattern(
    pattern => [$line1, $gap1, $line2, $gap2, ...],
    offset => $points,
);

Définit le motif de tirets de ligne.

Si appelé sans arguments, une ligne pleine sera dessinée.

Si appelé avec un argument, les tirets et les espaces auront des longueurs égales.

Si appelé avec deux arguments ou plus, les arguments représentent des longueurs alternées de tiret et d'espace.

Si appelé avec une table de hachage d'arguments, une phase de tiret peut être définie, qui spécifie la distance dans le motif à partir de laquelle commencer le tiret.

flatness_tolerance

$content = $content->flatness_tolerance($tolerance);

Définit la distance maximale en pixels de l'appareil entre le chemin mathématiquement correct pour une courbe et une approximation construite à partir de segments de ligne droite.

$tolerance est un entier compris entre 0 et 100, où 0 représente la tolérance de platitude par défaut de l'appareil.

egstate

$content = $content->egstate($object);

Ajoute un objet PDF::API2::Resource::ExtGState contenant un ensemble de paramètres d'état graphique.

CONSTRUCTION DE CHEMINS (DESSIN)

Notez que les chemins n'apparaîtront qu'après l'appel d'une méthode de peinture de chemin ("stroke", "fill", ou "paint").

move

$content = $content->move($x, $y);

Démarre un nouveau chemin aux coordonnées spécifiées.

line

$content = $content->line($x, $y);

Prolonge le chemin en ligne droite depuis les coordonnées actuelles jusqu'aux coordonnées spécifiées.

hline

$content = $content->hline($x);

Ce site n'est en aucun cas associé à Arch Linux ni affilié à ce projet. Le contenu est uniquement une traduction des pages de manuel d'Arch publiées sur man.archlinux.org.

>

Prolonge le chemin en ligne horizontale depuis la position actuelle jusqu'à la coordonnée x spécifiée.

vline

$content = $content->vline($x);

Prolonge le chemin en ligne verticale depuis la position actuelle jusqu'à la coordonnée y spécifiée.

polyline

$content = $content->polyline($x1, $y1, $x2, $y2, ...);

Prolonge le chemin depuis la position actuelle en une ou plusieurs lignes droites.

curve

$content = $content->curve($cx1, $cy1, $cx2, $cy2, $x, $y);

Prolonge le chemin en courbe depuis le point actuel jusqu'à "($x, $y)", en utilisant les deux points spécifiés pour créer une courbe de Bézier cubique.

spline

$content = $content->spline($cx1, $cy1, $x, $y);

Prolonge le chemin en courbe depuis le point actuel jusqu'à "($x, $y)", en utilisant les deux points spécifiés pour créer une courbe spline.

arc

$content = $content->arc($x, $y, $major, $minor, $a, $b);

Prolonge le chemin le long d'un arc d'ellipse centré en "[$x, $y]". $major et $minor représentent les axes de l'ellipse, et l'arc se déplace de $a degrés à $b degrés.

close

$content = $content->close();

Ferme le chemin actuel en prolongeant une ligne de la position actuelle vers la position de départ.

CONSTRUCTION DE FORMES (DESSIN)

Ce sont des méthodes pratiques pour dessiner des chemins fermés.

Notez que les formes n'apparaîtront pas tant qu'une méthode de dessin de chemin n'est pas appelée ("stroke", "fill", ou "paint").

rectangle

$content = $content->rectangle($x1, $y1, $x2, $y2);

Crée un nouveau chemin de forme rectangulaire, entre les deux points "[$x1, $y1]" et "[$x2, $y2]".

circle

$content = $content->circle($x, $y, $radius);

Crée un nouveau chemin circulaire centré sur "[$x, $y]" avec le rayon spécifié.

ellipse

$content = $content->ellipse($x, $y, $major, $minor);

Crée un nouveau chemin elliptique centré sur "[$x, $y]" avec les axes majeur et mineur spécifiés.

pie

$content = $content->pie($x, $y, $major, $minor, $a, $b);

Crée un nouveau chemin en forme de secteur à partir d'une ellipse centrée sur "[$x, $y]" avec les axes majeur et mineur spécifiés, s'étendant de $a degrés à $b degrés.

PEINTURE DE CHEMIN (DESSIN)

stroke_color

$content->stroke_color($color, @arguments);

Définit la couleur de contour, qui est noir par défaut.

# Utiliser une couleur nommée
$content->stroke_color('blue');
# Utiliser une couleur RVB (commençant par '#')
$content->stroke_color('#FF0000');
# Utiliser une couleur CMJN (commençant par '%')
$content->stroke_color('%FF000000');
# Utiliser une couleur d'accompagnement avec une couverture de 100%.
my $spot = $pdf->colorspace('spot', 'PANTONE Red 032 C', '#EF3340');
$content->stroke_color($spot, 1.0);

Les couleurs RVB et CMJN peuvent avoir des valeurs d'un, deux, trois ou quatre octets pour chaque couleur, en fonction du niveau de précision requis. Par exemple, le cyan peut être donné comme %F000 ou %FFFF000000000000.

fill_color

$content->fill_color($color, @arguments);

Définit la couleur de remplissage, qui est noir par défaut. Les arguments sont les mêmes que pour "stroke_color".

stroke

$content = $content->stroke();

Trace le chemin actuel.

fill

$content = $content->fill(rule => $rule);

Remplit le chemin actuel.

$rule décrit quelles zones sont remplies lorsque le chemin s'intersecte avec lui-même.

  • nonzero (par défaut)

    Utilise la règle du nombre de rotations non nul. Cela a tendance à signifier que toute la zone délimitée par le chemin est remplie, avec quelques exceptions en fonction de la direction du chemin.

  • even-odd

    Utilise la règle pair-impair. Cela a tendance à signifier que la présence de remplissage alterne à chaque intersection du chemin.

Voir la spécification PDF 1.7 section 8.5.3.3, Remplissage, pour plus de détails.

paint

$content = $content->paint(rule => $rule);

Remplit et trace le chemin actuel. $rule est décrit dans "fill".

clip

$content = $content->clip(rule => $rule);

Modifie le chemin de découpe actuel (initialement la page entière) en l'intersectant avec le chemin actuel après la prochaine commande de peinture de chemin. $rule est décrit dans "fill".

end

$content = $content->end();

Termine le chemin actuel sans le remplir ni le tracer. Ceci est principalement utilisé pour le résultat secondaire de la modification du chemin de découpe actuel.

OBJETS EXTERNES

object

$content = $content->object($object, $x, $y, $scale_x, $scale_y);

Place une image ou un autre objet externe (également appelé XObject) sur la page à l'emplacement spécifié.

Si $x et $y sont omis, l'objet sera placé à "[0, 0]".

Pour les images, $scale_x et $scale_y représentent la largeur et la hauteur de l'image sur la page en points. Si $scale_x est omis, il prendra par défaut 72 pixels par pouce. Si $scale_y est omis, l'image sera mise à l'échelle proportionnellement en fonction des dimensions de l'image.

Pour les autres objets externes, l'échelle est un multiplicateur, où 1 (la valeur par défaut) représente 100% (c'est-à-dire aucun changement).

Si des transformations de coordonnées ont été effectuées (voir Transformations de coordonnées ci-dessus), la position et l'échelle seront relatives aux coordonnées mises à jour.

Si aucune transformation de coordonnées n'est nécessaire, cette méthode peut être appelée directement depuis l'objet PDF::API2::Page.

ÉTAT DU TEXTE

Tous les paramètres suivants qui prennent une taille sont appliqués avant toute mise à l'échelle, vous n'avez donc pas besoin d'ajuster les valeurs pour contrer la mise à l'échelle.

font

$content = $content->font($font, $size);

Définit la police et la taille de la police. $font est un objet créé en appelant "font" dans PDF::API2 pour ajouter la police au document.

my $pdf = PDF::API2->new();
my $page = $pdf->page();
my $text = $page->text();
my $font = $pdf->font('Helvetica');
$text->font($font, 24);
$text->position(72, 720);
$text->text('Bonjour, le Monde !');
$pdf->save('sample.pdf');

character_spacing

$spacing = $content->character_spacing($spacing);

Définit l'espacement entre les caractères. Il est initialement de zéro.

word_spacing

$spacing = $content->word_spacing($spacing);

Définit l'espacement entre les mots. Il est initialement de zéro (c'est-à-dire juste la largeur de l'espace).

L'espacement des mots peut n'affecter que les polices simples et les polices composites où le caractère espace est un code d'un octet. C'est une limitation de la spécification PDF au moins depuis la version 1.7 (voir la section 9.3.3). Il est possible qu'une version ultérieure de la spécification prenne en charge l'espacement des mots dans les polices qui utilisent des codes multibytes.

hscale

$scale = $content->hscale($scale);

Définit/obtient le pourcentage de mise à l'échelle horizontale du texte. Entrez une échelle supérieure à 100 pour étirer le texte, inférieure à 100 pour compresser le texte, ou 100 pour désactiver toute mise à l'échelle existante.

leading

$leading = $content->leading($leading);

Définit/obtient l'interlignage, qui est la distance entre les lignes de base. Il est initialement de zéro (c'est-à-dire que les lignes seront imprimées les unes sur les autres).

render

$mode = $content->render($mode);

Définit le mode de rendu du texte.

  • 0 = Remplir le texte
  • 1 = Tracer le texte (contour)
  • 2 = Remplir, puis tracer le texte
  • 3 = Ne pas remplir ni tracer le texte (invisible)
  • 4 = Remplir le texte et l'ajouter au chemin pour le découpage
  • 5 = Tracer le texte et l'ajouter au chemin pour le découpage
  • 6 = Remplir, puis tracer le texte et l'ajouter au chemin pour le découpage

MISCELLANEOUS

Various other methods not easily categorized.

  • set_encoding( $encoding )

    Sets the character encoding to be used for the text. This should typically be done at the start of a document.

    If this method is called with no arguments, it will attempt to guess the encoding from the PDF specification.

  • set_charspace( $value )

    Sets the inter-character spacing, in points.

  • set_wordspace( $value )

    Sets the inter-word spacing, in points.

  • set_leading( $value )

    Sets the distance between lines of text, in points.

  • set_hscale( $scale )

    Sets the horizontal scaling of the text, expressed as a percentage. Default is 100.

  • set_font( $font, $size )

    Sets the font and size to be used for subsequent text operations. $size is in points.

  • current_font()

    Returns the current font object.

  • current_font_size()

    Returns the current font size.

  • current_text_state()

    Returns a hash reference containing the current font, size, encoding, character spacing, word spacing, leading, and horizontal scaling.

  • duplicate_object()

    Makes a copy of the content object. This is useful when you want to draw multiple similar objects, possibly with some modifications.

    my $copy = $content->duplicate_object();

  • set_object_name( $name )

    Assigns a name to the content object. This is not a standard PDF feature, but may be useful for debugging.

  • get_object_name()

    Returns the name assigned to the content object, if any.

  • add_text_for_clipping( $text )

    Adds the specified text to a list of text objects which will be used for clipping.

    Note: This is a low-level method. It is generally easier to use clipping_text().

TEXT EFFECTS

rise

$distance = $content->rise($distance);

Adjusts the baseline up or down from its current location. This is initially zero.

Use this to create superscripts or subscripts (usually with an adjustment to the font size as well).

TEXT PLACEMENT

position

# Set
$content = $content->position($x, $y);
# Get
($x, $y) = $content->position();

If called with arguments, moves to the start of the current line of text, offset by $x and $y.

If called without arguments, returns the current position of the cursor (before the effects of any coordinate transformation methods).

crlf

$content = $content->crlf();

Moves to the start of the next line, based on the "leading" setting.

If leading isn't set, a default distance of 120% of the font size will be used.

text

my $width = $content->text($text, %options);

Places text on the page. Returns the width of the text in points.

Options:

  • align

    One of "left" (default), "center", or "right". Text will be placed such that it begins, is centered on, or ends at the current text position, respectively.

    In each case, the position will then be moved to the end of the text.

  • indent

    Indents the text by the number of points.

    If "align" is set to anything other than "left", this setting will be ignored.

  • underline

    Underlines the text. The value may be one of the following:

  • auto

    Determines the underline distance from the text based on the font and font size.

  • $distance

    Manually set the underline distance in points. A positive distance moves the line downward.

  • [$distance, $thickness, ...]

    Manually set both the underline distance and line thickness, both in points.

    Repeat these arguments to include multiple underlines.

text_justified

my $width = $content->text_justified($text, $width, %options);

As "text", filling the specified width by adjusting the space between words.

paragraph

# Scalar context
$overflow_text = $content->paragraph($text, $width, $height, %options);
# Array context
($overflow, $height) = $content->paragraph($text, $width, $height, %options);

Fills the rectangle with as much of the provided text as will fit.

In array context, returns the remaining text (if any) of the positioned text and the remaining (unused) height. In scalar context, returns the remaining text (if any).

Line spacing follows "leading", if set, or 120% of the font size by default.

Options

  • align

    Specifies the alignment for each line of text. May be set to "left" (default), "center", "right", or "justified".

  • align-last

    Specifies the alignment for the last line of justified text. May be set to "left" (default), "center", "right", or "justified".

  • underline

    As described in "text".

text_width

my $width = $content->text_width($line, %overrides);

Returns the width of a line of text based on the current text state attributes. These can optionally be overridden:

my $width = $content->text_width($line,
    font => $font,
    size => $size,
    character_spacing => $spacing,
    word_spacing => $spacing,
    hscale => $scale,
);
