NOM

PDF::Builder::Resource::XObject::Image::PNG - Routines de support pour la bibliothèque d'images PNG (utilisant du code Perl pur)

Hérite de PDF::Builder::Resource::XObject::Image

MÉTHODES

new

$res = PDF::Builder::Resource::XObject::Image::PNG->new($pdf, $file, %opts)
Retourne un objet image PNG. $pdf est l'objet PDF auquel on ajoute, $file est le fichier PNG d'entrée, et le $name optionnel du nouvel objet image parent vaut par défaut PxAAA.

Si le paquet Image::PNG::Libpng est installé, la bibliothèque PNG_IPL sera utilisée à la place de la bibliothèque PNG. Dans ce cas, l'utilisation de la bibliothèque PNG peut être forcée via le flag "nouseIPL" (voir la documentation de Builder pour image_png()).

opts :

'notrans' => 1
Pas de transparence -- ignorer le chunk tRNS s'il est fourni, ignorer le canal Alpha s'il est fourni.
'name' => 'string'
C'est le nom que vous pouvez donner à l'objet image PNG. Le défaut est Pxnnnn.

N'oubliez pas d'invoquer la méthode image_png de Builder.pm afin d'utiliser cette fonctionnalité.

Types PNG supportés

(0) Échelle de gris de profondeur 1, 2, 4 ou 8 bits par pixel (2, 4, 16 ou 256
    niveaux de gris). 16 bpp n'est pas actuellement supporté (un PNG avec 16 bpp
    est une erreur fatale). La transparence complète (d'une valeur de gris 8 bits) via
    le chunk tRNS est autorisée, sauf si l'option notrans spécifie qu'elle doit être ignorée.
(2) RVB 24 bits truecolor avec 8 bits par échantillon (16,7 millions de couleurs).
    16 bps n'est pas actuellement supporté (un PNG avec 16 bps
    est une erreur fatale). La transparence complète (d'une valeur de couleur RVB 3x8 bits) via le
    chunk tRNS est autorisée, sauf si l'option notrans spécifie qu'elle doit être ignorée.
(3) Couleur palette avec 1, 2, 4 ou 8 bits par pixel (2, 4, 16 ou 256
    entrées de table de couleurs/palette). 16 bpp n'est pas actuellement supporté par
    PNG ou PDF. La transparence partielle (Alpha 8 bits) pour chaque entrée de palette
    via le chunk tRNS est autorisée, sauf si l'option notrans spécifie qu'elle doit être ignorée (toutes les entrées sont complètement opaques).
(4) Échelle de gris de profondeur 8 bits par pixel plus canal Alpha 8 bits (256
    niveaux de gris et 256 niveaux de transparence). 16 bpp n'est pas
    actuellement supporté (un PNG avec 16 bpp est une erreur fatale). Le canal
    Alpha est ignoré si l'option notrans est donnée. Le chunk tRNS
    n'est pas autorisé.
(6) RVB 24 bits truecolor avec 8 bits par échantillon (16,7 millions de couleurs)
    plus canal Alpha 8 bits (256 niveaux de transparence). 16 bps n'est pas
    actuellement supporté (un PNG avec 16 bps est une erreur fatale). Le canal
    Alpha est ignoré si l'option notrans est donnée. Le chunk tRNS
    n'est pas autorisé.

Dans tous les cas, 16 bits par échantillon ne sont pas implémentés. Une erreur fatale sera retournée si une image PNG avec des données 16 bps est fournie. Le code suppose un ordre de bits standard "réseau" (Big Endian). Les images entrelacées (progressives) ne sont pas supportées. Utilisez la version PNG_IPL si vous avez besoin de supporter des images 16 bps ou entrelacées.

Le chunk de transparence (tRNS) spécifiera une entrée de niveau de gris ou une entrée RVB à considérer comme transparente (Alpha = 0). Pour la couleur palette, jusqu'à 256 valeurs Alpha de 8 bits pour les entrées de palette sont spécifiées (256 niveaux de transparence, de 0 = transparent à 255 = opaque).

Seul un nombre limité de chunks est géré : IHDR, IDAT (interne), PLTE, tRNS et IEND (interne). Tous les autres chunks sont ignorés pour le moment. Certains filtres et compressions appliqués aux données seront gérés, mais il peut y avoir des méthodes non supportées.

usesLib

$mode = $png->usesLib()
Retourne 1 si Image::PNG::Libpng est installé et utilisé, 0 si non installé, ou -1 si installé mais non utilisé (option nouseIPL donnée à "image_png").

Attention : cette méthode ne peut être utilisée qu' *après* la création de l'objet image. Elle ne peut pas vous dire si Image::PNG::Libpng est disponible avant de l'utiliser réellement, au cas où vous voudriez utiliser une fonctionnalité disponible uniquement dans PNG_IPL. Voir l'appel PDF::Builder LA_IPL() si vous avez besoin de savoir à l'avance.
