strokealpha

$egs->strokealpha($alpha)
La constante alpha de trait actuelle, spécifiant la forme constante ou la valeur d'opacité constante à utiliser pour les opérations de trait dans le modèle d'imagerie transparent.

fillalpha

$egs->fillalpha($alpha)
Identique à strokealpha, mais pour les opérations de remplissage (non-trait).

blendmode

$egs->blendmode($nomDuMode)

Le mode de fusion actuel à utiliser dans le modèle d'imagerie transparent.

alphaisshape

$egs->alphaisshape($booléen)
Le drapeau source alpha (alpha est forme), spécifiant si le masque doux actuel et la constante alpha doivent être interprétés comme des valeurs de forme (vrai) ou des valeurs d'opacité (faux).

textknockout

$egs->textknockout($booléen)
Le drapeau de suppression de texte, qui détermine le comportement des glyphes qui se chevauchent dans un objet texte dans le modèle d'imagerie transparent.

transparency

$egs->transparency($t)
La transparence graphique, 0 étant complètement opaque et 1 étant complètement transparent. C'est une méthode de commodité, réglant les valeurs appropriées pour "strokealpha" et "fillalpha".

opacity

$egs->opacity($op)
L'opacité graphique, 1 étant complètement opaque et 0 complètement transparent. C'est une méthode de commodité, réglant les valeurs appropriées pour "strokealpha" et "fillalpha".
