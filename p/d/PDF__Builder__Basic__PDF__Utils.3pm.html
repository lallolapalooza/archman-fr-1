NOM

PDF::Builder::Basic::PDF::Utils - Fonctions utilitaires pour la bibliothèque PDF

DESCRIPTION

Un ensemble de fonctions utilitaires pour épargner les doigts des utilisateurs de la bibliothèque PDF !

PDFString

PDFString($text, $usage)
Retourne soit PDFStr($text) soit PDFUtf($text), selon que $text est déjà en UTF-8 et si $usage autorise l'UTF-8. Si l'UTF-8 n'est pas autorisé, "downgrade" sera appelé sur un $text formaté en UTF-8.

$usage est une chaîne d'un seul caractère indiquant l'usage auquel $text est destiné. Certains usages autorisent l'UTF-8, tandis que d'autres (actuellement) l'interdisent :

's'
Une chaîne ordinaire, où le texte UTF-8 est autorisé.
'n'
Une destination nommée, où le texte UTF-8 est autorisé.
'o'
Un titre de plan, où le texte UTF-8 est autorisé.
'p'
Un titre de popup, où le texte UTF-8 est autorisé.
'm'
métadonnées, où le texte UTF-8 est autorisé.
'f'
Un chemin et/ou nom de fichier, où le texte UTF-8 n'est actuellement pas autorisé.
'u'
Une URL, où le texte UTF-8 n'est actuellement pas autorisé.
'x'
Tout autre usage où le texte UTF-8 n'est pas autorisé.
