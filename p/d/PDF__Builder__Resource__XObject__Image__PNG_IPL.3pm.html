NOM

PDF::Builder::Resource::XObject::Image::PNG_IPL - Routines de support pour la bibliothèque d'images PNG (utilisant Image::PNG::Libpng)

Hérite de PDF::Builder::Resource::XObject::Image

MÉTHODES

new

$res = PDF::Builder::Resource::XObject::Image::PNG_IPL->new($pdf, $file, %opts)
Retourne un objet image PNG. $pdf est l'objet PDF auquel on ajoute, $file est le fichier PNG d'entrée, et le nom optionnel $name du nouvel objet image parent par défaut est PxAAA.

Si le paquet Image::PNG::Libpng est installé, et que son utilisation n'est pas supprimée via le drapeau "nouseIPL" (voir la documentation de Builder pour "image_png"), la bibliothèque PNG_IPL sera utilisée. Sinon, la bibliothèque PNG sera utilisée à la place.

opts :

'notrans' => 1
Pas de transparence -- ignorer le bloc tRNS s'il est fourni, ignorer le canal Alpha s'il est fourni.
'force8bps' => 1
Si la source PNG est 16 bits par échantillon, dire à la bibliothèque libpng de réduire tous les canaux à 8 bits par échantillon, permettant une utilisation sur une sortie PDF 1.4.
'name' => 'string'
C'est le nom que vous pouvez donner à l'objet image PNG. Le défaut est Pxnnnn.

N'oubliez pas que vous devez utiliser image_png de Builder.pm pour traiter les images PNG.

Types PNG supportés

(0) Échelle de gris de profondeur 1, 2, 4, 8 ou 16 bits par pixel (2, 4, 16, 256 ou 65536 niveaux de gris). Transparence totale (d'une valeur de gris 16 bits) via le bloc tRNS est autorisée, sauf si l'option notrans spécifie qu'elle doit être ignorée.
(2) Véritable couleur RVB avec 8 ou 16 bits par échantillon (3 échantillons : 16,7 millions ou 281,5 billions de couleurs). Transparence totale (d'une valeur de couleur RVB 3x16 bits) via le bloc tRNS est autorisée, sauf si l'option notrans spécifie qu'elle doit être ignorée.
(3) Couleur de palette avec 1, 2, 4 ou 8 bits par pixel (2, 4, 16 ou 256 entrées de table de couleurs/palette). 16 bpp n'est actuellement pas supporté par PNG ou PDF. Transparence partielle (Alpha 8 bits) pour chaque entrée de palette via le bloc tRNS est autorisée, sauf si l'option notrans spécifie qu'elle doit être ignorée (toutes les entrées complètement opaques).
(4) Échelle de gris de profondeur 8 ou 16 bits par pixel plus un canal Alpha de taille égale (256 ou 65536 niveaux de gris et 256 ou 65536 niveaux de transparence). Le canal Alpha est ignoré si l'option notrans est donnée. Le bloc tRNS n'est pas autorisé.
(5) B<RÉSERVÉ> pour l'échelle de gris via palette + canal Alpha
(6) Véritable couleur RVB avec 8 ou 16 bits par échantillon, avec un canal Alpha de taille égale (256 ou 65536 niveaux de transparence). Le canal Alpha est ignoré si l'option notrans est donnée. Le bloc tRNS n'est pas autorisé.
(7) B<RÉSERVÉ> pour la véritable couleur via palette + canal Alpha

Dans tous les cas, 16 bits par échantillon force une sortie PDF 1.5 (ou supérieure), sauf si vous donnez l'option "force8bps", pour "dépouiller" les échantillons de 16 bits à 8 bits, et permettre une sortie compatible PDF 1.4. La bibliothèque libpng.a suppose un ordre de bits et d'octets standard "réseau" (Big Endian), bien que des drapeaux puissent être ajoutés pour changer cela.

Le bloc de transparence (tRNS) spécifiera une seule entrée de niveau de gris ou une seule entrée RVB à traiter comme transparente (Alpha = 0). Pour la couleur de palette, jusqu'à 256 valeurs Alpha 8 bits d'entrées de palette sont spécifiées (256 niveaux de transparence, de 0 = transparent à 255 = opaque).

Seul un nombre limité de blocs est géré : IHDR, IDAT (en interne), PLTE, tRNS, et IEND (en interne). Tous les autres blocs sont ignorés pour le moment. Les filtres et la compression appliqués aux données sont gérés en interne par libpng.a -- il peut y avoir des méthodes non supportées.

utiliseLib

$mode = $png->usesLib()
Retourne 1 si Image::PNG::Libpng est installé et utilisé, 0 s'il n'est pas installé, ou -1 s'il est installé mais non utilisé (option nouseIPL donnée à "image_png").

Attention : cette méthode ne peut être utilisée *après* que l'objet image a été créé. Elle ne peut pas vous dire si Image::PNG::Libpng est disponible avant de l'utiliser effectivement, au cas où vous voudriez utiliser une fonctionnalité disponible uniquement dans PNG_IPL. Voir l'appel LA_IPL() de PDF::Builder si vous avez besoin de savoir à l'avance.
