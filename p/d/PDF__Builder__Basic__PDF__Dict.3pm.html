NOM

PDF::Builder::Basic::PDF::Dict - Dictionnaires et flux PDF

Hérite de PDF::Builder::Basic::PDF::Objind

VARIABLES D'INSTANCE

Il existe plusieurs variables d'instance spéciales qui sont utilisées pour la gestion, en particulier pour les flux. Chacune commence par un espace :

' stream'
Contient le contenu du flux pour la sortie
' streamfile'
Contient le contenu du flux dans un fichier externe plutôt qu'en mémoire. Ce n'est pas la même chose qu'un flux de fichier PDF. Les données sont stockées sous leur forme non filtrée.
' streamloc'
Si ' stream' et ' streamfile' sont tous deux vides, cela indique où commence le flux dans le fichier PDF source.

MÉTHODES

new

$d = PDF::Builder::Basic::PDF->new()
Crée une nouvelle instance de dictionnaire. La pratique habituelle est d'appeler PDFDict() à la place.

type

$type = $d->type($type)
Récupère/Définit la clé Type standard. Elle peut être passée et retournera une valeur texte plutôt qu'un objet Nom.

filter

@filters = $d->filter(@filters)
Récupère/Définit un ou plusieurs filtres utilisés par le flux optionnel attaché au dictionnaire.

outobjdeep

$d->outobjdeep($fh, $pdf)
Écrit le contenu du dictionnaire dans un fichier PDF. Il s'agit d'un appel récursif.

Il écrit également un flux si le dictionnaire possède un élément de flux. Si cela se produit, cette méthode calculera la longueur du flux et l'insérera dans le dictionnaire du flux.

read_stream

$d->read_stream($force_memory)
Lit un flux à partir d'un fichier PDF. Si le flux dépasse "PDF::Dict::mincache" (par défaut 32768) octets à stocker, l'action par défaut est de créer un fichier quelque part et de l'utiliser comme cache de données. Si $force_memory est défini, ce caching ne se produira pas et les données seront toutes stockées dans la variable $self->{' stream'}.

val

$d->val()
Retourne le dictionnaire, qui est lui-même.
