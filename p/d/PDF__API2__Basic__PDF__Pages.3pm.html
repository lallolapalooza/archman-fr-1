PDF::API2::Basic::PDF::Pages(3) Documentation Perl fournie par l'utilisateur PDF::API2::Basic::PDF::Pages(3)

NOM

PDF::API2::Basic::PDF::Pages - Objet de bas niveau de l'arborescence des pages

DESCRIPTION

Un objet Pages est le parent d'autres objets pages ou d'objets page eux-mêmes.

MÉTHODES

PDF::API2::Basic::PDF::Pages->new($pdf, $parent)

Ceci crée un nouvel objet Pages dans un PDF. Notez que $parent ici n'est pas le contexte de fichier pour l'objet mais l'objet pages parent pour ces pages. Si nous utilisons cette classe pour créer un nœud racine, alors $parent devrait pointer vers le contexte de fichier, qui est identifié par l'absence d'un Type de Pages. $pdf est l'objet fichier (ou une référence à un tableau d'objets fichiers) dans lequel créer le nouvel objet Pages.

$p->find_page($page_number)

Retourne la page donnée, en utilisant les valeurs du nombre de pages dans l'arbre des pages. Les pages commencent à 0.

$p->add_page($page, $page_number)

Insère la page avant le $page_number donné. $page_number peut être négatif pour compter à partir de la FIN du document. -1 est après la dernière page. De même, $page_number peut être supérieur au nombre de pages actuellement dans le document, pour ajouter à la fin.

@objects = $p->get_pages()

Retourne une liste d'objets page dans le document dans l'ordre des pages

$p->find_prop($key)

Recherche dans l'arborescence d'héritage pour trouver une propriété.

$p->add_font($pdf, $font)

Crée ou modifie le dictionnaire de ressources à ce niveau de la hiérarchie. Si la police est déjà prise en charge, même à travers la hiérarchie, elle n'est pas ajoutée.

$p->bbox($xmin, $ymin, $xmax, $ymax, [$param])

Spécifie la boîte englobante pour cette page et toutes les pages enfant. Si les valeurs sont identiques à celles héritées, aucune modification n'est apportée. $param spécifie le nom de l'attribut afin que d'autres 'boîtes englobantes' puissent être définies avec cette méthode.

$p->proc_set(@entries)

Assure que la ressource actuelle contient toutes les entrées des proc_sets listés. Si nécessaire, elle crée un dictionnaire de ressources local pour y parvenir.

$p->get_top

Retourne le sommet de l'arborescence des pages
