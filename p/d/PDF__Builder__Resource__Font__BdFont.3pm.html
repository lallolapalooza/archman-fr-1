NOM

PDF::Builder::Resource::Font::BdFont - Module pour utiliser les polices bitmap

Hérite de PDF::Builder::Resource::Font

SYNOPIS

#
use PDF::Builder;
#
$pdf = PDF::Builder->new();
$sft = $pdf->bdfont($file);
#

Ceci crée une police bitmap à partir d'un fichier .bdf (bitmap distribution font). Par défaut, il utilise des éléments carrés et le style peut être changé pour utiliser des points remplis (ressemblant davantage à une imprimante matricielle). La police sera incorporée dans le fichier PDF.

Les polices bitmap sont assez rudimentaires, de basse résolution et difficiles à lire. Donc, à moins que vous ne soyez un sadique qui veuille forcer les lecteurs à revenir aux bons vieux temps des imprimantes matricielles et des terminaux X bitmap, essayez de limiter l'utilisation d'une telle police à des effets décoratifs ou de nouveauté, tels que les titres de chapitre et les en-têtes majeurs. Ayez pitié de vos lecteurs et utilisez une vraie police (TrueType, etc.) pour le corps du texte !

MÉTHODES

new

$font = PDF::Builder::Resource::Font::BdFont->new($pdf, $font, %opts)
Retourne un objet BmpFont.

Les options valides (%opts) sont :

style
Une valeur de 'block' (par défaut) assemble un caractère à partir de blocs carrés contigus. Une valeur de 'dot' assemble un caractère à partir de cercles remplis qui se chevauchent, dans le style d'une imprimante matricielle.
