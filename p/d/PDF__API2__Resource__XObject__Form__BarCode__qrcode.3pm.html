NOM

PDF::API2::Resource::XObject::Form::BarCode::qrcode - Générer des codes QR

SYNOPSIS

use PDF::API2;
my $pdf = PDF::API2->new();
my $page = $pdf->page();
# Créer un objet code-barres QR
my $barcode = $pdf->barcode('qr', 'Ceci est un test');
# Calculer l'échelle nécessaire pour une taille désirée (72pts / pouce)
my $desired_inches = 2;
my $scale = $desired_inches * 72 / $barcode->width();
# Placer le code QR à un pouce (72pts) du coin inférieur gauche
$page->object($barcode, 72, 72, $scale);
$pdf->save('qr_test.pdf');

EXIGENCES

Text::QRCode est utilisé pour encoder les codes QR.

OPTIONS

my $barcode = $pdf->barcode('qr', $value, %options);

Les options standard suivantes pour les codes-barres sont prises en charge, comme décrit dans "barcode" de PDF::API2 :

  • bar_width (défaut : 1 ; l'unité est en points)
  • bar_height (défaut : largeur de la barre)
  • quiet_zone (défaut : 4x la largeur de la barre)
  • color (défaut : noir)

Les options suivantes sont spécifiques aux codes QR :

•
error_correction (défaut : L)

Le niveau de correction d'erreur du code QR. Des niveaux plus élevés de correction d'erreur génèrent des codes-barres plus grands mais restent lisibles lorsque des parties du code sont endommagées ou obscurcies.

Dans un ordre croissant de correction d'erreur, les valeurs possibles sont :

  • L (7%)
  • M (15%)
  • Q (25%)
  • H (30%)
  • version (défaut : 0)

    Si vous avez besoin d'une version spécifique du code QR, entrez-la ici. Sinon, la version minimale sera utilisée qui peut prendre en charge la valeur encodée.

  • mode (défaut : 8-bit)

    Vous pouvez générer des codes QR plus petits si vous utilisez un ensemble de caractères restreint :

  • 8-bit (typiquement l'ensemble de caractères ISO-8859-1)
  • kanji
  • alphanumérique (chiffres, lettres majuscules, espace ou "$ % * + - . / :")
  • numérique (chiffres)
•
case_sensitive (défaut : 1)

Indique si les caractères 8 bits doivent être traités de manière sensible à la casse.
