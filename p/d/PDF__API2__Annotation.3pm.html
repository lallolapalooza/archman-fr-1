PDF::API2::Annotation(3) Documentation Perl fournie par l'utilisateur PDF::API2::Annotation(3)

NOM

PDF::API2::Annotation - Ajouter des annotations à un PDF

SYNTAXE

my $pdf = PDF::API2->new();
my $font = $pdf->font('Helvetica');
my $page1 = $pdf->page();
my $page2 = $pdf->page();
my $content = $page1->text();
my $message = 'Aller à la Page 2';
my $size = 18;
$content->distance(1 * 72, 9 * 72);
$content->font($font, $size);
$content->text($message);
my $annotation = $page1->annotation();
my $width = $content->text_width($message);
$annotation->rect(1 * 72, 9 * 72, 1 * 72 + $width, 9 * 72 + $size);
$annotation->link($page2);
$pdf->save('sample.pdf');

MÉTHODES

Types d'annotations

link

$annotation = $annotation->link($destination, $location, @args);

Lier l'annotation à une autre page de ce PDF. $location et @args sont optionnels et définissent quelle partie de la page doit être affichée, tel que défini dans "destination" dans PDF::API2::NamedDestination.

$destination peut être soit un objet PDF::API2::Page soit le nom d'une destination nommée définie ailleurs.

url

$annotation = $annotation->uri($uri);

Lancer $uri -- typiquement une page web -- lorsque l'annotation est sélectionnée.

file

$annotation = $annotation->launch($file);

Ouvrir $file lorsque l'annotation est sélectionnée.

pdf

$annotation = $annotation->pdf($file, $dest, $location, @args);

Ouvrir le fichier PDF situé à $file vers la destination spécifiée. $location et @args sont optionnels et définissent quelle partie de la page doit être affichée, tel que défini dans "destination" dans PDF::API2::NamedDestination.

$dest peut être un numéro de page, ou une destination nommée préfixée par "#".

text

$annotation = $annotation->text($text);

Définir l'annotation comme une note textuelle avec le contenu spécifié.

movie

$annotation = $annotation->movie($filename, $content_type);

Incorporer et lier au film situé à $filename avec le type MIME spécifié.

Attributs communs d'annotation

rect

$annotation = $annotation->rect($llx, $lly, $urx, $ury);

Définir le rectangle autour de l'annotation.

border

$annotation = $annotation->border($h_radius, $v_radius, $width);

Définir le style de la bordure. Par défaut 0, 0, 0 (pas de bordure).

content

$annotation = $annotation->content(@lines);

Définir le contenu textuel de l'annotation, si applicable.

open

$annotation = $annotation->open($boolean);

Définir l'annotation pour qu'elle soit initialement ouverte ou fermée. Uniquement pertinent pour les annotations textuelles.
