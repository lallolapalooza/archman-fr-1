NOM

PDF::API2 - Créer, modifier et examiner des fichiers PDF

SYNOPSIS

use PDF::API2;
# Créer un fichier PDF vide
$pdf = PDF::API2->new();
# Ouvrir un fichier PDF existant
$pdf = PDF::API2->open('some.pdf');
# Ajouter une page vide
$page = $pdf->page();
# Obtenir une page existante
$page = $pdf->open_page($page_number);
# Définir la taille de la page
$page->size('Letter');
# Ajouter une police de type système à PDF
$font = $pdf->font('Helvetica-Bold');
# Ajouter une police TrueType externe à PDF
$font = $pdf->font('/path/to/font.ttf');
# Ajouter du texte à la page
$text = $page->text();
$text->font($font, 20);
$text->position(200, 700);
$text->text('Hello World!');
# Sauvegarder le PDF
$pdf->save('/path/to/new.pdf');

MÉTHODES D'ENTRÉE/SORTIE

new

my $pdf = PDF::API2->new(%options);

Crée un nouveau fichier PDF.

Les options suivantes sont disponibles :

  • file

    Si vous connaissez déjà le nom du fichier dans lequel le PDF sera stocké et que vous souhaitez l'ouvrir en écriture dès le départ, vous pouvez l'inclure ici. "file" peut aussi être un handle de fichier.

  • compress

    Par défaut, la plupart du contenu du PDF sera compressé pour économiser de l'espace. Pour désactiver cette fonctionnalité (généralement utile pour les tests ou le débogage), définissez "compress" sur 0.

open

my $pdf = PDF::API2->open('/path/to/file.pdf', %options);

Ouvre un fichier PDF existant.

L'option suivante est disponible :

•
compress

Par défaut, la plupart du contenu du PDF sera compressé pour économiser de l'espace. Pour désactiver cette fonctionnalité (généralement utile pour les tests ou le débogage), définissez "compress" sur 0.

save

$pdf->save('/path/to/file.pdf');

Écrit le PDF sur le disque et ferme le fichier. Un nom de fichier est facultatif s'il a été spécifié lors de l'ouverture ou de la création du PDF.

En tant qu'effet secondaire, la structure du document est supprimée de la mémoire une fois le fichier sauvegardé, elle ne sera donc plus utile.

close

$pdf->close();

Ferme un fichier ouvert (si pertinent) et supprime la structure de l'objet de la mémoire.

PDF::API2 contient des références cycliques, cet appel est donc nécessaire dans les processus longs pour éviter de manquer de mémoire.

Cet appel sera effectué automatiquement lors de la sauvegarde ou de la conversion d'un PDF en chaîne de caractères. Vous ne devriez l'appeler explicitement que si vous lisez des PDF et n'en écrivez pas.

from_string

my $pdf = PDF::API2->from_string($pdf_string, %options);

Lit un document PDF contenu dans une chaîne.

L'option suivante est disponible :

•
compress

Par défaut, la plupart du contenu du PDF sera compressé pour économiser de l'espace. Pour désactiver cette fonctionnalité (généralement utile pour les tests ou le débogage), définissez "compress" sur 0.

to_string

my $string = $pdf->to_string();

Retourne le document PDF sous forme de chaîne.

En tant qu'effet secondaire, la structure du document est supprimée de la mémoire une fois la chaîne créée, elle ne sera donc plus utile.

MÉTHODES DE MÉTADONNÉES

title

$title = $pdf->title();
$pdf = $pdf->title($title);

Obtient/définit/efface le titre du document.

author

$author = $pdf->author();
$pdf = $pdf->author($author);

Obtient/définit/efface le nom du créateur du document.

subject

$subject = $pdf->subject();
$pdf = $pdf->subject($subject);

Obtient/définit/efface le sujet du document.

keywords

$keywords = $pdf->keywords();
$pdf = $pdf->keywords($keywords);

Obtient/définit/efface une chaîne de mots-clés séparés par des espaces associée au document.

creator

$creator = $pdf->creator();
$pdf = $pdf->creator($creator);

Obtient/définit/efface le nom du produit qui a créé le document avant sa conversion en PDF.

producer

$producer = $pdf->producer();
$pdf = $pdf->producer($producer);

Obtient/définit/efface le nom du produit qui a converti le document original en PDF.

PDF::API2 remplit ce champ lors de la création d'un PDF.

created

$date = $pdf->created();
$pdf = $pdf->created($date);

Obtient/définit/efface la date de création du document.

Le format de la date est "D:YYYYMMDDHHmmSSOHH'mm", où "D:" est un préfixe statique identifiant la chaîne comme une date PDF. La date peut être tronquée à tout moment après l'année. "O" est soit "+", "-", ou "Z", avec "HH'mm" représentant une différence en heures par rapport à l'UTC.

Lors de la définition de la date, "D:" sera ajouté automatiquement s'il n'est pas inclus.

modified

$date = $pdf->modified();
$pdf = $pdf->modified($date);

Obtient/définit/efface la date de modification du document. Le format de la date est le même qu'avec "created" ci-dessus.

info_metadata

# Obtenir toutes les clés et valeurs
%info = $pdf->info_metadata();
# Obtenir la valeur d'une clé
$value = $pdf->info_metadata($key);
# Définir la valeur d'une clé
$pdf = $pdf->info_metadata($key, $value);

Obtient/définit/efface une clé dans le dictionnaire de métadonnées du document. Les clés standard (title, author, etc.) ont leurs propres accesseurs, cette méthode est donc principalement destinée à l'interaction avec des métadonnées personnalisées.

Passez "undef" comme valeur pour supprimer la clé du dictionnaire.

xml_metadata

$xml = $pdf->xml_metadata();
$pdf = $pdf->xml_metadata($xml);

Obtient/définit le flux de métadonnées XML du document.

version

$version = $pdf->version($new_version);

Obtient/définit la version du PDF (par exemple, 1.4).

is_encrypted

$boolean = $pdf->is_encrypted();

Retourne vrai si le PDF ouvert est crypté.

MÉTHODES DE PAGE

page

# Ajoute une page à la fin du document
$page = $pdf->page();
# Insère une page avant le numéro de page spécifié
$page = $pdf->page($page_number);

Renvoie un objet page. Par défaut, la page est ajoutée à la fin du document. Si un numéro de page existant est spécifié, la nouvelle page est insérée à cet endroit, décalant les pages existantes.

Si $page_number vaut -1, la nouvelle page est insérée comme l'avant-dernière page ; si elle vaut 0, elle est insérée comme la dernière page.

open_page

$page = $pdf->open_page($page_number);

Renvoie l'objet PDF::API2::Page de la page $page_number, si elle existe.

Si $page_number vaut 0 ou -1, renvoie la dernière page du document.

import_page

$page = $pdf->import_page($source_pdf, $source_page_num, $target_page_num);

Importe une page de $source_pdf et l'ajoute à la position spécifiée dans $pdf.

Si $source_page_num ou $target_page_num vaut 0, -1 ou n'est pas spécifié, la dernière page du document est utilisée.

Note : Une seule page peut être importée d'un fichier PDF existant.

Exemple :

my $pdf = PDF::API2->new();
my $source = PDF::API2->open('source.pdf');
# Ajouter la page 2 du PDF source comme page 1 du nouveau PDF
my $page = $pdf->import_page($source, 2);
$pdf->save('sample.pdf');

Note : Une seule page peut être importée d'un fichier PDF existant.

embed_page

$xobject = $pdf->embed_page($source_pdf, $source_page_number);

Renvoie un objet XObject créé en extrayant la page spécifiée d'un $source_pdf.

C'est utile si vous souhaitez positionner la page importée différemment (par exemple, deux par colonne, quatre par colonne, etc.).

Si $source_page_number vaut 0 ou -1, renvoie la dernière page du document.

Exemple :

my $pdf = PDF::API2->new();
my $source = PDF::API2->open('source.pdf');
my $page = $pdf->page();
# Importer la page 2 du PDF source
my $object = $pdf->embed_page($source, 2);
# Ajouter à la première page du nouveau PDF à l'échelle 1/2
my ($x, $y) = (0, 0);
$page->object($object, $x, $y, 0.5);
$pdf->save('sample.pdf');

Note : Une seule page peut être importée d'un fichier PDF existant.

page_count

$integer = $pdf->page_count();

Renvoie le nombre de pages du document.

page_labels

$pdf = $pdf->page_labels($page_number, %options);

Décrit comment les pages sont numérotées en commençant par le numéro spécifié.

# Générer un PDF de 30 pages
my $pdf = PDF::API2->new();
$pdf->page() for 1..30;
# Numéroter les pages i à v, 1 à 20, et A-1 à A-5, respectivement
$pdf->page_labels(1, style => 'roman');
$pdf->page_labels(6, style => 'decimal');
$pdf->page_labels(26, style => 'decimal', prefix => 'A-');
$pdf->save('sample.pdf');

Les options suivantes sont disponibles :

  • style

    L'un de "decimal" (chiffres décimaux standard), "Roman" (chiffres romains majuscules), "roman" (chiffres romains minuscules), "Alpha" (lettres majuscules), ou "alpha" (lettres minuscules).

    Il n'y a pas de style par défaut. S'il n'est pas spécifié, l'étiquetage sera uniquement le préfixe (s'il est défini) ou une chaîne vide.

  • prefix

    Préfixe d'étiquette pour les pages de cette plage.

  • start

    Un entier (par défaut : 1) représentant la première valeur à utiliser dans cette plage de pages.

default_page_size

# Définir
$pdf->default_page_size($size);
# Obtenir
@rectangle = $pdf->default_page_size()

Définit la taille physique par défaut pour les pages du PDF. Si elle est appelée sans arguments, elle renvoie les coordonnées du rectangle décrivant la taille physique par défaut.

Voir "Tailles de page" dans PDF::API2::Page pour les valeurs possibles.

default_page_boundaries

# Définir
$pdf->default_page_boundaries(%boundaries);
# Obtenir
%boundaries = $pdf->default_page_boundaries();

Définit les limites d'impression par défaut pour les pages du PDF. Si elle est appelée sans arguments, elle renvoie les coordonnées des rectangles décrivant chacune des limites d'impression prises en charge.

Voir la méthode équivalente "page_boundaries" dans PDF::API2::Page pour les détails.

MÉTHODES DE POLICE

font

my $font = $pdf->font($name, %options)

Ajoute une police à un PDF. Renvoie l'objet de police, à utiliser par PDF::API2::Content.

La police $name peut être le nom de l'une des 14 polices standard (par exemple, Helvetica), un objet "Font::TTF::Font" ou le chemin d'accès à un fichier de police.

my $pdf = PDF::API2->new();
my $font1 = $pdf->font('Helvetica-Bold');
my $font2 = $pdf->font('/path/to/ComicSans.ttf');
my $page = $pdf->page();
my $content = $page->text();
$content->position(1 * 72, 9 * 72);
$content->font($font1, 24);
$content->text('Hello, World!');
$content->position(0, -36);
$content->font($font2, 12);
$content->text('This is some sample text.');
$pdf->save('sample.pdf');

Le chemin peut être omis si la police se trouve dans le répertoire courant ou dans l'un des répertoires renvoyés par "font_path".

Les polices TrueType (ttf/otf), PostScript Type 1 (pfa/pfb) et le format de glyphes bitmap (bdf) sont pris en charge.

Les %options suivantes sont disponibles :

  • format

    Le format de la police est détecté automatiquement en fonction du nom du fichier. Si vous utilisez une police avec une extension non standard, vous pouvez définir "format" sur l'un de "truetype" (TrueType ou OpenType), "type1" (PostScript Type 1) ou "bitmap" (Adobe Bitmap).

  • kerning

    L'espacement automatique des paires de caractères est activé par défaut si la police contient ces informations. Vous pouvez le désactiver en définissant cette option sur false.

  • afm_file (Pour les polices PostScript Type 1 uniquement)

    Spécifie l'emplacement du fichier de métadonnées de la police.

  • pfm_file (Pour les polices PostScript Type 1 uniquement)

    Spécifie l'emplacement du fichier de métadonnées de la police d'impression. Cette option remplace l'option -encode.

  • embed (Pour les polices TrueType uniquement)

    Les polices sont incluses par défaut dans le PDF, ce qui est nécessaire pour qu'elles s'affichent correctement sur les appareils qui n'ont pas la police installée. Vous pouvez le désactiver en définissant cette option sur false.

synthetic_font

$font = $pdf->synthetic_font($base_font, %options)

Crée et renvoie une police synthétique.

MÉTHODES DE FONTS

font

$font = $pdf->font($filename, %options);

Crée et renvoie un nouvel objet de police synthétique. Voir PDF::API2::Resource::Font::SynFont pour plus de détails.

standard_fonts

@names = $pdf->standard_fonts()

font_path

Ajoute un ou plusieurs répertoires à la liste des chemins à rechercher pour les fichiers de polices.

Renvoie le chemin de recherche des polices.

@directories = PDF::API2->set_font_path('/mon/polices', '/chemin/vers/polices');

Remplace le chemin de recherche des polices existant. Ceci ne devrait être nécessaire que si vous avez besoin de supprimer un répertoire du chemin pour une raison quelconque, ou si vous avez besoin de réordonner la liste.

Renvoie le chemin de recherche des polices.

MÉTHODES GRAPHIQUES

image

$object = $pdf->image($file, %options);

Importe un type d'image pris en charge et renvoie un objet qui peut être placé comme faisant partie du contenu d'une page :

my $pdf = PDF::API2->new();
my $page = $pdf->page();
my $image = $pdf->image('/chemin/vers/image.jpg');
$page->object($image, 100, 100);
$pdf->save('sample.pdf');

$file peut être soit un nom de fichier, un descripteur de fichier, soit un objet GD::Image.

Voir "object" dans PDF::API2::Content pour les détails sur le placement des images sur une page une fois qu'elles sont importées.

Le format de l'image est normalement détecté automatiquement en fonction de l'extension du fichier. Si un descripteur de fichier est passé, les formats d'image GIF, JPEG et PNG seront détectés en fonction de l'en-tête du fichier.

Si le fichier a une extension atypique ou si le descripteur de fichier est pour un autre type d'image, vous pouvez définir l'option "format" sur l'un des types pris en charge : "gif", "jpeg", "png", "pnm", ou "tiff".

Note : Les images PNG qui incluent un canal alpha (transparence) subissent un processus relativement lent de division de l'image en composantes RVB et alpha séparées, comme requis par les images dans les PDF. Si vous rencontrez des problèmes de performance, installez PDF::API2::XS ou Image::PNG::Libpng pour accélérer ce processus d'un ordre de grandeur ; l'un ou l'autre module sera utilisé automatiquement s'il est disponible.

barcode

$object = $pdf->barcode($format, $code, %options);

Génère et renvoie un code-barres qui peut être placé comme faisant partie du contenu d'une page :

my $pdf = PDF::API2->new();
my $page = $pdf->page();
my $barcode = $pdf->barcode('ean13', '0123456789012');
$page->object($barcode, 100, 100);
my $qr_code = $pdf->barcode('qr', 'http://www.example.com');
$page->object($qr_code, 100, 300, 144 / $qr_code->width())
$pdf->save('sample.pdf');

$format peut être l'un des suivants : "codabar", "code128", "code39" (alias 3 of 9), "ean128", "ean13", "itf" (alias interleaved 2 of 5), ou "qr".

$code est la valeur à encoder. Les caractères de début et de fin ne sont requis que lorsqu'ils ne sont pas statiques (par exemple, pour Codabar).

Les options suivantes sont disponibles :

  • bar_width

    La largeur de la plus petite barre ou espace en points (72 points = 1 pouce).

    Si vous suivez une spécification qui donne la largeur de barre en mils (millièmes de pouce), utilisez cette conversion : "$points = $mils / 1000 * 72".

  • bar_height

    La hauteur de base du code-barres en points.

  • bar_extend

    Si présent et applicable, les barres pour les caractères non imprimables (par exemple, caractères de début et de fin) seront étendues vers le bas de ce nombre de points, et les caractères imprimables seront affichés sous leurs barres respectives.

    Ceci est activé par défaut pour les codes-barres EAN-13.

  • caption

    Si présent, cette valeur sera imprimée, centrée, sous le code-barres, et devrait être une représentation lisible par l'homme du code-barres. Cette option est ignorée pour les codes QR.

  • font

    Un objet de police (créé par "font") qui sera utilisé pour imprimer la légende, ou les caractères imprimables lorsque "bar_extend" est défini.

    Helvetica sera utilisé par défaut.

  • font_size

    La taille de la police utilisée pour imprimer la légende ou les caractères imprimables.

    La valeur par défaut sera calculée en fonction de la taille du code-barres, si "bar_extend" est défini, ou 10 sinon.

  • quiet_zone

    Une marge, en points, qui sera placée avant les bords gauche et inférieur du code-barres (y compris la légende, si présente). Ceci est utilisé pour aider les scanners de codes-barres à déterminer où le code-barres commence et se termine.

    La valeur par défaut est la largeur d'un caractère encodé, ou quatre carrés pour les codes QR.

  • bar_overflow

    Rétrécit la largeur horizontale des barres de ce montant en points pour tenir compte de l'étalement de l'encre lors de l'impression. Cette option est ignorée pour les codes QR.

    La valeur par défaut est de 0,01 points.

  • color

    Dessine les barres en utilisant cette couleur, qui peut être n'importe quelle valeur acceptée par "fillcolor" dans PDF::API2::Content.

    La valeur par défaut est le noir.

Les codes QR ont des options supplémentaires pour personnaliser le niveau de correction d'erreur et d'autres paramètres de niche.

colorspace

$colorspace = $pdf->colorspace($type, @arguments);

Les espaces de couleurs peuvent être ajoutés à un PDF pour contrôler spécifiquement la sortie couleur sur un appareil particulier (couleurs alternatives, couleurs de périphérique) ou pour économiser de l'espace en limitant les couleurs disponibles à une palette de couleurs définie (palette web-safe, fichier ACT).

Une fois ajoutés au PDF, ils peuvent être utilisés à la place des codes hexadécimaux réguliers ou des couleurs nommées :

my $pdf = PDF::API2->new();
my $page = $pdf->page();
my $content = $page->graphics();
# Ajout des espaces de couleurs pour une couleur alternative et la palette de couleurs web-safe
my $spot = $pdf->colorspace('spot', 'PANTONE Red 032 C', '#EF3340');
my $web = $pdf->colorspace('web');
# Remplissage en utilisant la couleur alternative avec 100% de couverture
$content->fill_color($spot, 1.0);
# Contour en utilisant la première couleur de la palette web-safe
$content->stroke_color($web, 0);
# Ajout d'un rectangle à la page
$content->rectangle(100, 100, 200, 200);
$content->paint();
$pdf->save('sample.pdf');

Les types d'espaces de couleurs suivants sont pris en charge :

  • spot 
    my $spot = $pdf->colorspace('spot', $tint, $alt_color);

    Les couleurs alternatives sont utilisées pour demander à un appareil (généralement une imprimante) d'utiliser ou d'émuler une encre particulière ($tint) pour certaines parties du document. Un $alt_color est fourni pour les appareils (par exemple, les visualiseurs PDF) qui ne savent pas comment produire la couleur nommée. Il peut s'agir d'une approximation de la couleur au format RVB, CMJN ou HSV, ou d'une couleur radicalement différente (par exemple, 100% magenta, %0F00) pour indiquer clairement si la couleur alternative n'est pas utilisée comme prévu.

  • web 
    my $web = $pdf->colorspace('web');

    La palette de couleurs web-safe est une collection historique de couleurs qui était utilisée lorsque de nombreux appareils d'affichage ne pouvaient prendre en charge que 256 couleurs.

  • act 
    my $act = $pdf->colorspace('act', $filename);

    Un fichier Adobe Color Table (ACT) fournit une palette de couleurs personnalisée qui peut être référencée par les commandes de dessin graphiques et textuelles du PDF.

  • device 
    my $devicen = $pdf->colorspace('device', @colorspaces);

    Un espace de couleurs spécifique au périphérique permet une sortie couleur précise sur un périphérique donné (généralement une presse d'imprimerie), contournant l'interprétation normale des couleurs effectuée par les processeurs d'images raster (RIP).

    Les espaces de couleurs de périphérique sont également nécessaires si vous souhaitez mélanger des couleurs alternatives :

    my $pdf = PDF::API2->new();
my $page = $pdf->page();
my $content = $page->graphics();
# Créer un espace de couleurs de périphérique à deux couleurs
my $yellow = $pdf->colorspace('spot', 'Yellow', '%00F0');
my $spot = $pdf->colorspace('spot', 'PANTONE Red 032 C', '#EF3340');
my $device = $pdf->colorspace('device', $yellow, $spot);
# Remplissage utilisant un mélange de 25% de jaune et 75% de couleur alternative
$content->fill_color($device, 0.25, 0.75);
# Contour en utilisant 100% de couleur alternative
$content->stroke_color($device, 0, 1);
# Ajout d'un rectangle à la page
$content->rectangle(100, 100, 200, 200);
$content->paint();
$pdf->save('sample.pdf');

COMPATIBILITÉ ASCENDANTE

Le code écrit en utilisant PDF::API2 devrait continuer à fonctionner sans modification pendant la durée de vie de la plupart des distributions de serveurs stables à long terme (LTS). Spécifiquement, il devrait continuer à fonctionner pour les versions de Perl qui ont été publiées au cours des cinq dernières années (la fenêtre de support typique pour les versions LTS) plus six mo

nths (permettant un délai suffisant pour les gelées de paquets avant la publication).

Dans PDF::API2, les noms de méthodes, les options et les fonctionnalités changent avec le temps. Les fonctionnalités qui sont documentées (pas seulement dans les commentaires du code source) devraient continuer à fonctionner pendant la même période de cinq ans et six mois, bien que des avertissements de dépréciation puissent être ajoutés. Il peut y avoir des exceptions si votre code dépend accidentellement de bogues qui sont corrigés, y compris lorsqu'une méthode dans PDF::API2 est modifiée pour suivre de plus près la spécification PDF.

Des changements occasionnels pouvant introduire des ruptures peuvent être inévitables ou jugés suffisamment mineurs en portée pour valoir le coup de faire le changement plutôt que de conserver l'ancien comportement. Celles-ci seront notées dans le fichier Changes comme des éléments commençant par la phrase "Breaking Change".

Les fonctionnalités non documentées, le code non publié, les fonctionnalités marquées comme expérimentales et les structures de données sous-jacentes peuvent changer à tout moment. Une exception s'applique aux fonctionnalités qui ont été précédemment publiées et documentées, lesquelles devraient continuer à fonctionner pendant la période susmentionnée après la suppression de la documentation.

Avant de migrer vers une nouvelle version LTS du serveur, il est recommandé de mettre à niveau vers la dernière version de PDF::API2, "use warnings", et de vérifier les journaux de votre serveur pour les messages de dépréciation après avoir exercé votre code. Une fois ceux-ci résolus, il devrait être sûr d'utiliser les futures versions de PDF::API2 pendant cette fenêtre de support LTS.

Si votre code utilise une méthode PDF::API2 qui n'est pas documentée ici, elle a probablement été dépréciée. Recherchez-la dans la section Migration ci-dessous pour trouver son remplacement.

MIGRATION

Utilisez cette section pour mettre à jour votre code existant avec les noms de méthodes et les options actuels. Si vous n'obtenez pas d'avertissement de dépréciation, c'est facultatif, mais toujours recommandé.

Par exemple, dans les cas où une méthode a simplement été renommée, l'ancien nom sera configuré comme un alias pour le nouveau, qui pourra être maintenu indéfiniment. Le principal avantage de passer au nouveau nom est de faciliter la recherche de la documentation appropriée lorsque vous en avez besoin.

infoMetaAttributes
Utilisez "info_metadata" sans arguments pour obtenir une liste des clés actuellement définies dans le dictionnaire Info (y compris les clés personnalisées). Le comportement est légèrement différent de celui de l'appel à "infoMetaAttributes" sans arguments, qui renvoie toujours les noms de clés standard et les noms de clés personnalisées définis, qu'ils soient présents ou non dans le PDF.

L'appel à "infoMetaAttributes" avec des arguments définit la liste des clés Info prises en charge par la méthode dépréciée "info". Vous pouvez maintenant simplement appeler "info_metadata" avec une clé et une valeur standard ou personnalisée.
