PDF::Builder::Resource::BaseFont(3) Documentation Perl fournie par l'utilisateur PDF::Builder::Resource::BaseFont(3)

NOM

PDF::Builder::Resource::BaseFont - Classe de base pour les ressources de police

Hérite de PDF::Builder::Resource

MÉTHODES

new

$font = PDF::Builder::Resource::BaseFont->new($pdf, $name)
Retourne un objet ressource de police.

descrByData

$descriptor = $font->descrByData()
Retourne la structure de clé FontDescriptor de la police, basée sur les données de la police.

MÉTHODES LIÉES À LA GESTION DES POLICES

fontname

$name = $font->fontname()
Retourne le nom de la police (également appelé nom d'affichage).

altname

$name = $font->altname()
Retourne le nom alternatif de la police (également appelé nom Windows pour une police PostScript).

subname

$name = $font->subname()
Retourne le sous-nom de la police (également appelé variante de police).

apiname

$name = $font->apiname()
Retourne le nom de la police à utiliser en interne (devrait être égal à $font->name()).

issymbol

$issymbol = $font->issymbol()
Retourne l'indicateur de symbole de la police (c'est-à-dire, s'agit-il d'une police de symboles).

iscff

$iscff = $font->iscff()
Retourne l'indicateur Compact Font Format de la police.

MÉTHODES LIÉES À LA TYPOGRAPHIE

upem

$upem = $font->upem()
Retourne le facteur d'échelle de la police (Unités Par em). Il est typiquement de 1000 pour la plupart des polices, mais les polices TTF et OTF plus récentes utilisent souvent 2048 unités.

fontbbox

($llx,$lly, $urx,$ury) = $font->fontbbox()
Retourne la boîte englobante de la police.

capheight

$capheight = $font->capheight()
Retourne la valeur capheight (hauteur des majuscules) de la police.

xheight

$xheight = $font->xheight()
Retourne la valeur xheight (hauteur des lettres minuscules comme x) de la police.

missingwidth

$missingwidth = $font->missingwidth()
Retourne la valeur missingwidth (largeur du caractère manquant) de la police.

maxwidth

$maxwidth = $font->maxwidth()
Retourne la valeur maxwidth (largeur maximale) de la police.

avgwidth

$avgwidth = $font->avgwidth()
Retourne la valeur avgwidth (largeur moyenne) de la police.

flags

$flags = $font->flags()
Retourne la valeur des indicateurs (flags) de la police.

stemv

$stemv = $font->stemv()
Retourne la valeur stemv (épaisseur verticale des empattements) de la police.

stemh

$stemh = $font->stemh()
Retourne la valeur stemh (épaisseur horizontale des empattements) de la police.

italicangle

$italicangle = $font->italicangle()
Retourne la valeur italicangle (inclinaison, obliquité) de la police.

isfixedpitch

$isfixedpitch = $font->isfixedpitch()
Retourne l'indicateur isfixedpitch (police à chasse fixe) de la police.

underlineposition

$underlineposition = $font->underlineposition()
Retourne la valeur underlineposition (position du soulignement) de la police.

underlinethickness

$underlinethickness = $font->underlinethickness()
Retourne la valeur underlinethickness (épaisseur du soulignement) de la police.

ascender

$ascender = $font->ascender()
Retourne la valeur ascender (approchant supérieur) de la police.

descender

$descender = $font->descender()
Retourne la valeur descender (approchant inférieur) de la police.

MÉTHODES LIÉES AUX GLYPHES

glyphNames

@names = $font->glyphNames()
Retourne les noms des glyphes définis de la police.

glyphNum

$glNum = $font->glyphNum()
Retourne le nombre de noms de glyphes définis de la police.

uniByGlyph

$uni = $font->uniByGlyph($char)
Retourne l'unicode par nom de glyphe.

uniByEnc

$uni = $font->uniByEnc($char)
Retourne l'unicode par la carte d'encodage de la police.

uniByMap

$uni = $font->uniByMap($char)
Retourne l'unicode par la carte par défaut de la police.

encByGlyph

$char = $font->encByGlyph($glyph)
Retourne le caractère par le nom de glyphe donné de la carte d'encodage de la police.

encByUni

$char = $font->encByUni($uni)
Retourne le caractère par l'unicode donné de la carte d'encodage de la police.

mapByGlyph

$char = $font->mapByGlyph($glyph)
Retourne le caractère par le nom de glyphe donné de la carte par défaut de la police.

mapByUni

$char = $font->mapByUni($uni)
Retourne le caractère par l'unicode donné de la carte par défaut de la police.

glyphByUni

$name = $font->glyphByUni($unicode)
Retourne le nom du glyphe par la carte unicode de la police. ATTENTION : les noms de glyphes non standard sont mappés sur la zone ms-symbol (0xF000).

glyphByEnc

$name = $font->glyphByEnc($char)
Retourne le nom du glyphe par la carte d'encodage de la police.

glyphByMap

$name = $font->glyphByMap($char)

PDF::Builder::Resource::BaseFont(3pm)

NAME

PDF::Builder::Resource::BaseFont - Font resource object

METHODS

FONT-MANAGEMENT RELATED METHODS

This section describes methods that are related to font management.

encoding

$encoding = $font->encoding()
Returns the font's encoding.

setEncoding

$font->setEncoding($encoding)
Sets the font's encoding.

name

$name = $font->name()
Returns the font's name.

setName

$font->setName($name)
Sets the font's name.

isTTF

$flag = $font->isTTF()
Returns true if the font is a TrueType font.

isEmbeddable

$flag = $font->isEmbeddable()
Returns true if the font can be embedded in the PDF.

isSubsettable

$flag = $font->isSubsettable()
Returns true if the font can be subsetted.

isCIDKeyed

$flag = $font->isCIDKeyed()
Returns true if the font is CID keyed.

descendantFonts

@fonts = $font->descendantFonts()
Returns a list of descendant fonts for a composite font.

defaultWidth

$width = $font->defaultWidth()
Returns the default width of a character in the font.

setDefaultWidth

$font->setDefaultWidth($width)
Sets the default width of a character in the font.

missingWidth

$width = $font->missingWidth()
Returns the width of a missing character in the font.

setMissingWidth

$font->setMissingWidth($width)
Sets the width of a missing character in the font.

TYPOGRAPHY-RELATED METHODS

This section describes methods related to typography.

fontmetrics

$fm = $font->fontmetrics()
Returns the font metrics object.

ascender

$ascender = $font->ascender()
Returns the ascender of the font.

descender

$descender = $font->descender()
Returns the descender of the font.

xHeight

$xheight = $font->xHeight()
Returns the x height of the font.

capHeight

$capheight = $font->capHeight()
Returns the cap height of the font.

italicAngle

$angle = $font->italicAngle()
Returns the italic angle of the font.

leading

$leading = $font->leading()
Returns the suggested line spacing for the font.

stemV

$stemv = $font->stemV()
Returns the vertical stem width of the font.

italicCorrection

$correction = $font->italicCorrection()
Returns the italic correction of the font.

bold

$flag = $font->bold()
Returns true if the font is bold.

italic

$flag = $font->italic()
Returns true if the font is italic.

underline

$flag = $font->underline()
Returns true if the font is underlined.

strikeout

$flag = $font->strikeout()
Returns true if the font is strikeout.

GLYPH-RELATED METHODS

This section describes methods related to glyphs.

gidByUni

$gid = $font->gidByUni($uni)
Return the glyph ID for a Unicode character.

uniByGid

$uni = $font->uniByGid($gid)
Return the Unicode character for a glyph ID.

uniByEnc

$uni = $font->uniByEnc($char)
Return the Unicode character for an encoded character.

encByUni

$char = $font->encByUni($uni)
Return the encoded character for a Unicode character.

mapByUni

$glyph = $font->mapByUni($uni)
Return the glyph's name by the font's default map.

wxByGlyph

$width = $font->wxByGlyph($glyph)
Return the glyph's width. This is a value, that when divided by 1000 and multiplied by the font size (height in points), gives the advance width to the next character's start. Typically, the width will be under 1000.

wxByUni

$width = $font->wxByUni($uni)
Return the Unicode character's width. This is a value, that when divided by 1000 and multiplied by the font size (height in points), gives the advance width to the next character's start. Typically, the width will be under 1000.

wxByEnc

$width = $font->wxByEnc($char)
Return the character's width based on the current encoding. This is a value, that when divided by 1000 and multiplied by the font size (height in points), gives the advance width to the next character's start. Typically, the width will be under 1000.

wxMissingByEnc

$flag = $font->wxMissingByEnc($char)
Return true if the character's width (based on the current encoding) is supplied by "missing width" of font.

wxByMap

$width = $font->wxByMap($char)
Return the character's width based on the font's default encoding. This is a value, that when divided by 1000 and multiplied by the font size (height in points), gives the advance width to the next character's start. Typically, the width will be under 1000.

width

$wd = $font->width($text)
Return the width of $text as if it were at font size 1 (unscaled). CAUTION: works correctly only if a proper Perl string is used, either in native or UTF-8 format (check utf8-flag).

width_array

@widths = $font->width_array($text)
Return (as an array) the widths of the words in $text as if they were at size 1.

utfByStr

$utf8string = $font->utfByStr($string)
Return the utf8-string from string based on the font's encoding map.

strByUtf

$string = $font->strByUtf($utf8_string)
Return the encoded string from utf8-string based on the font's encoding map.

textByStr

$pdf_string = $font->textByStr($string)
Return a properly formatted representation of $string for use in the PDF.

textByStrKern

$pdf_string = $font->textByStrKern($string)
Return a properly formatted representation of $string, with kerning, for use in the PDF.
