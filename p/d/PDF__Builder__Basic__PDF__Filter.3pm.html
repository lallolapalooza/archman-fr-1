NOM

PDF::Builder::Basic::PDF::Filter - Superclasse abstraite pour les filtres de flux PDF

SYNOPSIS

$f = PDF::Builder::Basic::PDF::Filter->new();
$str = $f->outfilt($str, 1);
print FICHIER_SORTIE $str;
while (read(FICHIER_ENTREE, $dat, 4096))
{ $stock .= $f->infilt($dat, 0); }
$stock .= $f->infilt("", 1);

DESCRIPTION

Un objet Filtre contient des informations d'état pour le processus d'entrée et de sortie de données via le filtre. Les informations d'état précises stockées dépendent du filtre particulier et peuvent aller de rien à des objets entiers créés et détruits.

Chaque filtre stocke des informations d'état différentes pour l'entrée et la sortie, et peut ainsi gérer un processus de filtrage d'entrée et un processus de filtrage de sortie en même temps.

MÉTHODES

new

PDF::Builder::Basic::PDF::Filter->new()
Crée un nouvel objet filtre avec des informations d'état vides, prêt pour le traitement des données en entrée et en sortie.

infilt

$dat = $f->infilt($str, $isend)
Filtre les données de la sortie vers l'entrée. Notez que "$isend == 0" implique que d'autres données vont suivre et que donc $f peut contenir des informations d'état (généralement en raison du point de rupture de $str qui n'est pas net). Les appels suivants intégreront ces informations d'état stockées.

"$isend == 1" implique qu'il n'y a plus de données à suivre. L'état final de $f sera que les informations d'état sont vides. Les messages d'erreur sont les plus susceptibles de se produire ici car s'il y a des informations d'état requises à stocker après ces données, cela impliquerait une erreur dans les données.

outfilt

$str = $f->outfilt($dat, $isend)
Filtre les données stockées prêtes pour la sortie. Parallèle à "infilt".
