NOM

PTBatcherGUI - Processeur par lots Hugin

SYNTAXE

PTBatcherGUI [options] [<projet1 <préfixe de sortie>> <projet2 <préfixe de sortie>> <projet3...>]

DESCRIPTION

Un processeur par lots avec interface graphique pour gérer l'assemblage d'une file d'attente de projets Hugin .pto.

OPTIONS

-h|--help
Afficher le message d'utilisation
-b|--batch
Exécuter le traitement par lots immédiatement
-p|--parallel
Exécuter les projets par lots en parallèle
-o|--overwrite
Écraser les fichiers précédents sans demander
-s|--shutdown
Éteindre l'ordinateur une fois le traitement par lots terminé
-v|--verbose
Afficher une sortie détaillée lors du traitement des projets
-a|--assistant
Exécuter l'assistant sur les projets donnés
