NOM

PTAInterpolate - Interpole des images intermédiaires entre des photos stéréo.

SYNTAXE

PTAInterpolate fichier_script [param2]

DESCRIPTION

PTAInterpolate Interpole des images intermédiaires entre des photos stéréo.

Description : Ce programme est une version améliorée du programme original PTInterpolate de Helmut Dersch. Le code source de PTInterpolate n'a jamais été publié, ce programme a donc été écrit à partir de zéro. On pense que ce programme devrait fonctionner comme un substitut au programme original PTInterpolate dans la plupart des cas. Les améliorations par rapport au programme original PTInterpolate incluent :

1. Lorsqu'il est utilisé avec le code source correspondant dans la distribution originale, la sortie est au format TIFF, pas PSD (avec une extension incorrecte).

2. Les fichiers de sortie produits par ce programme incluent une valeur numérique indiquant le degré d'interpolation entre les images gauche et droite.

3. Si aucune ligne « i » valide n'est incluse dans le script, ce programme triangule les lignes « c » et écrase le fichier script.

Utilisation :

PTAInterpolate script.txt [param2]

Où « param2 » est soit un indice d'image (0=gauche, 1=droite) à utiliser lors de la triangulation, soit un préfixe de nom de fichier à utiliser lors de l'interpolation.
