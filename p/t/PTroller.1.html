NOM

PTroller - Fusionne plusieurs images en une seule

SYNTAXE

PTroller [options] fichier_tiff(s)

DESCRIPTION

PTroller prend un ensemble d'images et les fusionne en une seule.

OPTIONS

-o nom_fichier
Nom du fichier de sortie (par défaut merged.tif).
-f
Forcer le traitement (ne pas s'arrêter sur les avertissements).
-x
Supprimer les fichiers sources (à utiliser avec précaution).
-q
Exécution silencieuse
-h
Afficher ce message
