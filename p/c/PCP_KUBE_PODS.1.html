PCP_KUBE_PODS(1) Manuel des commandes générales PCP_KUBE_PODS(1)

NOM

pcp-kube-pods - lister les pods Kubernetes à scanner pour les services PCP en cours d'exécution

SYNTAXE

$PCP_BINADM_DIR/discover/pcp-kube-pods

DESCRIPTION

pcp-kube-pods utilise kubectl(1) pour fournir une liste d'adresses IP pour les PODs s'exécutant dans un cluster Kubenetes local, qui peuvent exécuter des services PCP tels que pmcd(1) et pmproxy(1).

Il est utilisé par la commande pmfind(1) et l'API pmDiscoverServices(3) comme commande « shell ».

Le script appelle la ligne de commande kubectl get pod (voir kubectl-get(1)) pour découvrir les adresses IP des pods. Le champ de sortie .status.podIP est extrait de(s) objet(s) de pod Kubernetes. Des options supplémentaires peuvent être spécifiées via un fichier de configuration, tel que -l service=database pour restreindre les résultats en utilisant les étiquettes de pod Kubernetes. Le fichier de configuration par défaut est $PCP_SYSCONF_DIR/discover/pcp-kube-pods.conf.

Si aucune commande kubectl locale n'est trouvée, rien n'est signalé et un code de sortie indiquant le succès est retourné.

DIAGNOSTICS

Tous les diagnostics produits sont fournis par la commande kubectl.

Le statut de sortie de kubectl est propagé inchangé.

FICHIERS

$PCP_BINADM_DIR/discover
chemin par défaut vers les commandes de découverte d'adresses telles que pcp-kube-pods
$PCP_SYSCONF_DIR/discover/pcp-kube-pods.conf
fichier de configuration contenant les options de ligne de commande passées à kubectl-get
$PCP_SYSCONF_DIR/discover/pcp-kube-pods.disabled
l'existence de ce fichier fait en sorte que le script ne signale rien

ENVIRONNEMENT PCP

Les variables d'environnement avec le préfixe PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Sur chaque installation, le fichier /etc/pcp.conf contient les valeurs locales de ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5).

VOIR AUSSI

kubectl-get(1), kubectl(1), pmcd(1), pmfind(1), pmDiscoverServices(3) et pcp.env(5).
