NOM

PCP::LogSummary - Interface Perl pour pmlogsummary(1)

SYNTAXE

use PCP::LogSummary;
my $summary = new PCP::LogSummary($log, \@metrics, $start, $end);

DESCRIPTION

Le module PCP::LogSummary est une enveloppe autour de la commande pmlogsummary(1) de Performance Co-Pilot. Son but principal est d'automatiser la production de données pmlogsummary post-traitées, en particulier pour automatiser l'étape où les données résumées sont importées dans une feuille de calcul pour une analyse plus approfondie. Cela s'est souvent avéré être un processus itératif : effectué manuellement, il implique beaucoup de copier-coller et peut être une perte de temps considérable.
