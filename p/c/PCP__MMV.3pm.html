NOM

PCP::MMV - Module Perl pour l'instrumentation de valeurs mappées en mémoire

SYNOPSIS

use PCP::MMV;

DESCRIPTION

Le module Perl PCP::MMV contient les liaisons de langage pour construire des programmes Perl instrumentés avec l'infrastructure de valeurs mappées en mémoire du Performance Co-Pilot - un mécanisme de transport de données efficace pour rendre les données de performance d'un programme Perl disponibles en tant que métriques PCP à l'aide du PMDA MMV.

VOIR AUSSI

mmv_stats_init(3), mmv_inc_value(3), mm_set_value(3), mmv_lookup_value_desc(3), mmv(5) et PMDA(3).

La liste de diffusion PCP pcp@groups.io peut être utilisée pour les questions concernant ce module.

Plus de détails peuvent être trouvés sur https://pcp.io
