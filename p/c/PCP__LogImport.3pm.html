NOM

PCP::LogImport - Module Perl pour importer des données de performance afin de créer une archive Performance Co-Pilot

SYNOPSIS

use PCP::LogImport;

DESCRIPTION

Le module PCP::LogImport contient les liaisons de langage pour construire des applications Perl qui importent des données de performance à partir d'un fichier ou d'une source en temps réel et créent une archive Performance Co-Pilot (PCP) adaptée à une utilisation avec les outils PCP.

Les routines de ce module fournissent des wrappers autour de la bibliothèque libpcp_import et certaines des routines de la bibliothèque libpcp.
