Ces callbacks sont utilisés pour signaler une liste d'entrées de répertoire à un appelant original, un fichier/répertoire/lien symbolique par callback. Toutes les chaînes sont codées en UTF-8. Les fonctions ne doivent pas essayer de modifier ou de libérer la mémoire d'une chaîne. Ces callbacks sont utilisés, à partir de PhysicsFS 1.1, comme une alternative aux fonctions qui retourneraient des listes qui nécessiteraient d'être nettoyées avec PHYSFS_freeList()
. Le callback signifie que la bibliothèque n'a pas besoin d' allouer une liste entière et toutes les chaînes en amont. Soyez conscient que l'ordre des données promis dans les versions de liste ne sont pas nécessairement tels dans les versions de callback. Vérifiez la documentation sur les APIs spécifiques, mais les chaînes peuvent ne pas être triées comme vous l'attendez et vous pourriez obtenir des chaînes dupliquées.
