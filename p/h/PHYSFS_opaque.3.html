SYNTAXE

#include <physfs.h>

Champs de données


void * opaque

Description détaillée

Un descripteur de fichier PhysicsFS.

Vous obtenez un pointeur vers l'un de ces éléments lorsque vous ouvrez un fichier en lecture, écriture ou ajout via PhysicsFS.

Comme vous pouvez le constater par l'absence de champs significatifs, vous devez le traiter comme une donnée opaque. N'essayez pas de manipuler le descripteur de fichier, mais transmettez simplement le pointeur que vous avez obtenu, intact, aux différentes API de PhysicsFS.
