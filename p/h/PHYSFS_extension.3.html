Description détaillée

Informations sur les diverses archives supportées par PhysicsFS.

Cette structure vous donne des détails sur le type d'archives supportées par cette implémentation de PhysicsFS. Les archives sont généralement des fichiers comme les fichiers ZIP et similaires.

Attention

Tous les binaires ne sont pas créés égaux ! PhysicsFS peut être compilé avec ou sans support pour diverses archives. Vous pouvez vérifier avec PHYSFS_supportedArchiveTypes() si votre type d'archive est supporté.
