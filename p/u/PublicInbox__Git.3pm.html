Paquet: perl-publicinbox

Licences: AGPL

PublicInbox::Git(3) Documentation Perl fournie par l'utilisateur PublicInbox::Git(3)

NOM

PublicInbox::Git - enveloppe git

VERSION

version 1.0

SYNOPSIS

use PublicInbox::Git;
chomp(my $git_dir = `git rev-parse --git-dir`);
$git_dir or die "GIT_DIR= must be specified\n";
my $git = PublicInbox::Git->new($git_dir);

DESCRIPTION

API instable en dehors de la méthode "new". Elle nécessite que git(1) soit installé.

MÉTHODES

new

my $git = PublicInbox::Git->new($git_dir);

Initialise un nouvel objet PublicInbox::Git à utiliser avec PublicInbox::Import. C'est la seule méthode d'API publique que nous prenons en charge. Tout le reste dans ce module est sujet à changement.

VOIR AUSSI

Git, PublicInbox::Import
