NOM

PublicInbox::WWW - Interface PSGI pour public-inbox

SYNOPIS

Dans votre fichier .psgi :

use PublicInbox::WWW;
my $www = PublicInbox::WWW->new;
builder {
        enable 'Head';
        mount '/inboxes' => sub { $www->call(@_) };
};

DESCRIPTION

L'interface web PSGI pour public-inbox.

Il n'est pas nécessaire de l'utiliser directement, sauf si vous souhaitez personnaliser votre déploiement PSGI de public-inbox ou si vous utilisez un serveur PSGI autre que public-inbox-netd(1) ("-netd") / public-inbox-httpd(1) ("-httpd").

Bien que cette application PSGI devrait fonctionner avec tous les serveurs web PSGI/Plack tels que starman(1), starlet(1) ou twiggy(1) ; PublicInbox::WWW tire parti des API internes de "-netd" et "-httpd" pour améliorer l'équité lors de la fourniture de réponses volumineuses pour les vues de fils, les téléchargements mbox et les clones git.

ENVIRONNEMENT

PI_CONFIG
Utilisé pour remplacer la valeur par défaut de "~/.public-inbox/config".
