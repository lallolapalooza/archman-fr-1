PublicInbox__Import(3pm)

Paquet: perl-publicinbox

Licences: AGPL

PublicInbox::Import(3) Documentation Perl fournie par la communauté PublicInbox::Import(3)

NOM

PublicInbox::Import - importateur de messages pour les boîtes aux lettres de public-inbox v1

VERSION

version 1.0

SYNOPIS

use PublicInbox::Eml;
# PublicInbox::Eml existe depuis public-inbox 1.5.0,
# Email::MIME était utilisé dans les anciennes versions
use PublicInbox::Git;
use PublicInbox::Import;
chomp(my $git_dir = `git rev-parse --git-dir`);
$git_dir or die "GIT_DIR= doit être spécifié\n";
my $git = PublicInbox::Git->new($git_dir);
my @committer = ('inbox', 'inbox@example.org');
my $im = PublicInbox::Import->new($git, @committer);
# pour ajouter un message :
my $message = "From: <u\@example.org>\n".
        "Subject: message de test \n" .
        "Date: Thu, 01 Jan 1970 00:00:00 +0000\n" .
        "Message-ID: <m\@example.org>\n".
        "\nmessage de test";
my $parsed = PublicInbox::Eml->new($message);
my $ret = $im->add($parsed);
if (!defined $ret) {
        warn "doublon : ", $parsed->header_raw('Message-ID'), "\n";
} else {
        print "importé à la marque $ret\n";
}
$im->done;
# pour supprimer un message
my $junk = PublicInbox::Eml->new($message);
my ($mark, $orig) = $im->remove($junk);
if ($mark eq 'MISSING') {
        print "non trouvé\n";
} elsif ($mark eq 'MISMATCH') {
        print "Le message existe mais ne correspond pas\n\n",
                $orig->as_string, "\n\n";
} else {
        print "supprimé à la marque $mark\n\n",
                $orig->as_string, "\n";
}
$im->done;

DESCRIPTION

Un importateur et suppresseur pour les boîtes aux lettres de public-inbox qui prend des messages de type "PublicInbox::Eml" ou Email::MIME en entrée et les stocke dans un dépôt git comme documenté dans https://public-inbox.org/public-inbox-v1-format.txt, sauf qu'il n'autorise pas les Message-ID dupliqués.

Il nécessite que git(1) et git-fast-import(1) soient installés.

MÉTHODES

new

my $im = PublicInbox::Import->new($git, @committer);

Initialise un nouvel objet PublicInbox::Import.

add

my $parsed = PublicInbox::Eml->new($message);
$im->add($parsed);

Ajoute un message au dépôt git. Cela acquerra "$GIT_DIR/ssoma.lock" et démarrera git-fast-import(1) si nécessaire.

Les messages ajoutés ne seront pas visibles par d'autres processus avant que "done" ne soit appelé, mais "remove" peut être appelé sur eux.

remove

my $junk = PublicInbox::Eml->new($message);
my ($code, $orig) = $im->remove($junk);

Supprime un message du dépôt. En cas de succès, il renvoie un code numérique préfixé par ':' représentant la marque de git-fast-import et le message original sous forme d'objet PublicInbox::Eml (ou Email::MIME). Si le message n'a pas pu être trouvé, le code est "MISSING" et le message original est undef. S'il y a une divergence où le "Message-ID" correspond mais que l'objet et le corps ne correspondent pas, le code renvoyé est "MISMATCH" et le message conflictuel est renvoyé sous forme de orig.

done

Finalise la commande git-fast-import(1) et déverrouille le dépôt. Appeler cette méthode est nécessaire pour finaliser les changements apportés au dépôt.

VOIR AUSSI

Email::MIME
