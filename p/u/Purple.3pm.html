NOM

Purple - Extension Perl pour la bibliothèque de messagerie instantanée libpurple.

SYNTAXE

use Purple;

RÉSUMÉ

Ce module fournit l'interface pour utiliser des scripts perl comme plugins
dans libpurple.

DESCRIPTION

Ce module fournit l'interface pour utiliser des scripts perl comme plugins dans Purple. Avec cela, les développeurs peuvent écrire des scripts perl qui peuvent être chargés dans Purple en tant que plugins. Les scripts peuvent interagir avec les messages instantanés, les chats, les comptes, la liste de contacts, les signaux libpurple, et plus encore.

L'API de l'interface perl est très similaire à celle de l'API C de Purple, qui peut être consultée à http://developer.pidgin.im/doxygen/ ou dans les fichiers d'en-tête de l'arbre source de Purple.

FONCTIONS

@comptes = Purple::comptes
Retourne une liste de tous les comptes, en ligne ou hors ligne.
@chats = Purple::chats
Retourne une liste de tous les chats actuellement ouverts.
@connexions = Purple::connexions
Retourne une liste de toutes les connexions actives.
@conversations = Purple::conversations
Retourne une liste de toutes les conversations, à la fois les messages instantanés et les chats, actuellement ouvertes.
@fenetres_conv = Purple::fenetres_conv
Retourne une liste de toutes les fenêtres de conversation actuellement ouvertes.
@ims = Purple::ims
Retourne une liste de tous les messages instantanés actuellement ouverts.
