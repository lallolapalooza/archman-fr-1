Signature de sortie du foncteur Pqueue.MakeMin .

Files de priorité minimales

type t

Le type des files de priorité.

type elt

Le type des éléments de la file de priorité.

val create : unit -> t

Retourne une nouvelle file de priorité, initialement vide.

val length : t -> int

Retourne le nombre d'éléments dans une file de priorité.

val is_empty : t -> bool

is_empty q est true si et seulement si q est vide, c'est-à-dire si length q = 0 .

val add : t -> elt -> unit

add q x ajoute l'élément x dans la file de priorité q .

val add_iter : t -> ((elt -> unit) -> 'x -> unit) -> 'x -> unit

add_iter q iter x ajoute chaque élément de x à la fin de q . C'est iter (add q) x .

val min_elt : t -> elt option

min_elt q est un élément de q ayant une priorité minimale ou None si la file est vide. La file n'est pas modifiée.

val get_min_elt : t -> elt

get_min_elt q retourne un élément de q ayant une priorité minimale, ou lève Invalid_argument si la file est vide. La file n'est pas modifiée.

val pop_min : t -> elt option

pop_min q retire et retourne un élément de la file q ayant une priorité minimale, ou retourne None si la file est vide.

val remove_min : t -> unit

remove_min q retire un élément de la file q ayant une priorité minimale. Ne fait rien si q est vide.

val clear : t -> unit

clear q retire tous les éléments de q .

val copy : t -> t

copy q est une nouvelle file de priorité avec les mêmes éléments que q .

Conversions à partir d'autres structures de données

val of_array : elt array -> t

of_array a retourne une nouvelle file de priorité contenant les éléments du tableau a . S'exécute en temps linéaire.

val of_list : elt list -> t

of_list l retourne une nouvelle file de priorité contenant les éléments de la liste l . S'exécute en temps linéaire.

val of_iter : ((elt -> unit) -> 'x -> unit) -> 'x -> t

of_iter iter x retourne une nouvelle file de priorité contenant les éléments de x , obtenus à partir de iter .

Par exemple, of_iter Seq.iter s retourne une nouvelle file de priorité contenant tous les éléments de la séquence s (en supposant qu'elle soit finie).

S'exécute en temps linéaire (hors du temps passé dans iter ).

Itération

L'ordre dans lequel les éléments d'une file de priorité sont parcourus n'est pas spécifié.

Il s'agit d'une erreur de programmation de modifier une file de priorité (en ajoutant ou en retirant des éléments) pendant une itération de la file. Une telle erreur peut être détectée et signalée par l'implémentation du tableau dynamique sous-jacent, mais cela n'est pas garanti.

val iter_unordered : (elt -> unit) -> t -> unit

iter_unordered f q applique f à tous les éléments de q . L'ordre dans lequel les éléments sont passés à f n'est pas spécifié.

Le comportement n'est pas spécifié si la file de priorité est modifiée par f pendant l'itération.

val fold_unordered : ('acc -> elt -> 'acc) -> 'acc -> t -> 'acc

fold_unordered f accu q est (f (... (f (f accu x1) x2) ...)
xn) où x1,x2,...,xn sont les éléments de q . L'ordre dans lequel les éléments sont passés à f n'est pas spécifié.

Le comportement n'est pas spécifié si la file de priorité est modifiée par f pendant l'itération.
