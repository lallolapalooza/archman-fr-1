Module Pqueue
: sig end

Files d'attente à priorité.

Le module Pqueue implémente une structure de données de files d'attente à priorité, étant donné un type totalement ordonné pour les éléments. Il s'agit d'une structure de données mutable. Les files d'attente à priorité minimale et maximale sont fournies.

L'implémentation utilise un tas stocké dans un tableau dynamique, et est donc raisonnablement efficace : l'accès à l'élément minimum (resp. maximum) prend un temps constant, et l'insertion et la suppression prennent un temps logarithmique par rapport à la taille de la file d'attente à priorité. Notez que of_array s'exécute en temps linéaire (et doit donc être préféré aux insertions répétées avec add).

Il est acceptable d'avoir plusieurs éléments ayant la même priorité. Rien n'est garanti quant à l'ordre dans lequel ils seront extraits. Cependant, il est garanti que l'élément retourné par min_elt (ou get_min_elt ) est celui qui est retiré de la file d'attente à priorité par pop_min (ou remove_min ). Ceci est important dans de nombreux algorithmes (par exemple, lorsqu'on examine plusieurs files d'attente à priorité, puis qu'on en sélectionne une à retirer).

Files d'attente à priorité polynomiales

Les foncteurs suivants, plus complexes, créent des files d'attente à priorité polynomiales de type 'a t , tout comme les autres conteneurs polynomiales (listes, tableaux...). Ils nécessitent une notion d'"éléments polynomiaux" 'a
elt qui peuvent être comparés sans dépendre des valeurs de 'a .

Un scénario d'utilisation est lorsque l'utilisateur souhaite passer les priorités séparément de la valeur stockée dans la file d'attente. Ceci est fait en utilisant des paires priority * 'a comme éléments.

      module Prio : OrderedType = ...
      module PrioQueue = Pqueue.MakeMinPoly(struct
        type 'a t = Prio.t * 'a
        let compare (p1, _) (p2, _) = Prio.compare p1 p2
      end)
      (* par exemple, nous avons maintenant : *)
      PrioQueue.add: 'a PrioQueue.t -> Prio.t * 'a -> unit
      PrioQueue.min_elt: 'a PrioQueue.t -> (Prio.t * 'a) option
