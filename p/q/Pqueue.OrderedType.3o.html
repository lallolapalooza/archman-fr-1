type t

Le type des éléments.

val compare : t -> t -> int

Une fonction d'ordre total pour comparer les éléments.

C'est une fonction à deux arguments f telle que f e1 e2 est zéro si les éléments e1 et e2 sont égaux, f e1 e2 est strictement négatif si e1 est inférieur à e2, et f e1
e2 est strictement positif si e1 est supérieur à e2.

La fonction de comparaison structurelle générique compare est une fonction d'ordre appropriée pour les types d'éléments tels que int ou string.
