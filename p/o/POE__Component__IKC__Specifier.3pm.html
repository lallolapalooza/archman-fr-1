NOM

POE::Component::IKC::Specifier - Spécificateur d'événement IKC

SYNOPSIS

use POE;
use POE::Component::IKC::Specifier;
$state=specifier_parse('poe://*/timeserver/connect');
print 'L\'état étranger est '.specifier_name($state);

DESCRIPTION

Ceci est un module d'aide qui encapsule les spécificateurs POE IKC. Un spécificateur IKC est une façon de désigner soit un noyau, une session, soit un état au sein d'un cluster IKC.

Les spécificateurs IKC ont le format suivant :

poe:://noyau/session/état

noyau peut être un nom de noyau, un ID de noyau, vide (pour le noyau local), un '*' (tous les noyaux étrangers connus) ou hôte:port (pas encore pris en charge).

session peut être n'importe quel alias de session qui a été publié par le noyau étranger.

état est un état qui a été publié par une session étrangère.

Exemples :

"poe://Pulse/timeserver/connect"
État 'connect' dans la session 'timeserver' sur le noyau 'Pulse'.
"poe:/timeserver/connect"
État 'connect' dans la session 'timeserver' sur le noyau local.
"poe://*/timeserver/connect"
État 'connect' dans la session 'timeserver' sur n'importe quel noyau étranger connu.
"poe://Billy/bob/"
Session 'bob' sur le noyau étranger 'Billy'.

FONCTIONS EXPORTÉES

specifier_parse($spec)

Transforme un spécificateur en représentation interne (référence de hachage). Retourne undef() si le spécificateur n'était pas valide.

print Dumper specifer_parse('poe://Pulse/timeserver/time');

imprimerait

$VAR1 = {
    kernel => 'Pulse',
    session => 'timeserver',
    state => 'time',
};

Note : la représentation interne est susceptible de changer un jour.

specifier_name($spec)

Transforme un spécificateur en une chaîne de caractères.
