POE::Resource::Clock(3) Documentation Perl fournie par l'utilisateur POE::Resource::Clock(3)

NOM

POE::Resource::Clock - horloge interne utilisée pour ordonnancer la file

SYNTAXE

sub POE::Kernel::USE_POSIXRT { 0 }
use POE;

DESCRIPTION

POE::Resource::Clock est un module d'aide pour POE::Kernel. Il fournit les fonctionnalités pour maintenir une horloge interne monotone et une horloge murale. Il effectue également la conversion entre cette horloge monotone et l'horloge murale.

L'horloge monotone est utilisée pour maintenir une file d'événements ordonnée. L'horloge murale est utilisée pour communiquer l'heure avec le code utilisateur ("alarm_set" dans POE::Kernel, "alarm_remove" dans POE::Kernel).

Il existe 3 sources d'horloge possibles par ordre de préférence : POSIX::RT::Clock, Time::HiRes et "time" dans perlfunc. Seul "POSIX::RT::Clock" dispose d'une horloge monotone et d'une horloge murale distinctes ; les deux autres utilisent la même source pour les deux horloges.

La sélection et le comportement de l'horloge sont contrôlés par les éléments suivants :

USE_POSIXRT

export POE_USE_POSIXRT=0
    ou
sub POE::Kernel::USE_POSIXRT { 0 }

Utilise la source d'horloge "monotone" pour la priorité de la file et la source d'horloge "temps réel" pour l'horloge murale. Non utilisé si POSIX::RT::Clock n'est pas installé ou si votre système n'a pas d'horloge "monotone".

Par défaut, la valeur est vraie. Si vous souhaitez le comportement ancien de POE, définissez cette valeur à 0.

USE_STATIC_EPOCH

export POE_USE_STATIC_EPOCH=0
    ou
sub POE::Kernel::USE_STATIC_EPOCH { 0 }

L'époque de la horloge monotone de POSIX::RT::Clock est différente de celle de l'horloge temps réel. Par exemple, sous Linux 2.6.18, l'horloge monotone est le nombre de secondes depuis le démarrage du système. Cette époque est utilisée pour convertir le temps mural en temps monotone pour "alarm" dans POE::Kernel, "alarm_add" dans POE::Kernel et "alarm_set" dans POE::Kernel. Si "USE_STATIC_EPOCH" est vrai (par défaut), alors l'époque est calculée au moment du chargement. Si elle est fausse, l'époque est calculée chaque fois qu'elle est nécessaire.

Par défaut, la valeur est vraie. Uniquement pertinent si vous utilisez POSIX::RT::Clock. Les serveurs POE fonctionnant longtemps devraient avoir cette valeur définie sur fausse afin que le décalage de l'horloge système ne perturbe pas la file.

Il est important de souligner qu'en l'absence d'une époque statique, l'ordre des deux alarmes suivantes n'est pas défini.

$poe_kernel->alarm_set( a1 => $time );
$poe_kernel->alarm_set( a2 => $time );

USE_EXACT_EPOCH

export POE_USE_EXACT_EPOCH=1
    ou
sub POE::Kernel::USE_EXACT_EPOCH { 1 }

Il n'existe actuellement aucun moyen d'obtenir précisément l'époque de l'horloge monotone. Au lieu de cela, on utilise la différence entre la valeur actuelle de l'horloge monotone et celle de l'horloge temps réel. Ceci est évidemment inexact car il y a un léger délai entre les 2 appels système. La définition de USE_EXACT_EPOCH à vrai calculera une moyenne de cette différence sur 250 ms ou au moins 20 échantillons. De plus, les appels système sont effectués dans les deux ordres (monotone puis temps réel, temps réel puis monotone) pour essayer d'obtenir une valeur plus exacte.

Par défaut, la valeur est fausse. Uniquement pertinent si "USE_STATIC_EPOCH" est vrai.

USE_HIRES

export POE_USE_HIRES=0
    ou
sub POE::Kernel::USE_HIRES { 0 }

Utilise Time::HiRes comme source d'horloge monotone et murale. C'était le comportement par défaut précédent de POE pour l'horloge.

Par défaut, la valeur est vraie. Uniquement pertinent si "USE_POSIXRT" est fausse. Définissez cette valeur à fausse pour utiliser "time" dans perlfunc.

EXPORTATIONS

Ce module exporte optionnellement quelques fonctions d'aide à la gestion du temps.

mono2wall

mono2wall() convertit un temps monotone en un temps mural d'époque.

my $wall = mono2wall( $monotonic );

monotime

monotime() fait un effort maximal pour renvoyer le temps d'une horloge système monotone. Elle peut se rabattre sur un temps non monotone si aucune horloge monotone n'est disponible.

my $monotonic = monotime();

sleep

sleep() fait un effort maximal pour suspendre un laps de temps spécifique en haute résolution en utilisant une horloge monotone. Cette fonctionnalité se dégradera gracieusement vers des horloges non monotones en haute résolution, puis vers des horloges en basse résolution, en fonction des bibliothèques disponibles.

sleep( 3.141 );

time

time() est un alias rétrocompatible pour walltime(). Veuillez consulter la documentation de walltime() pour plus de détails.

wall2mono

wall2mono() fait un effort maximal pour convertir un temps mural en son temps d'horloge monotone équivalent. Ses fonctionnalités se dégradent gracieusement en fonction de la disponibilité de l'horloge.

my $monotonic = wall2mono( $epoch );

walltime

time() fait un effort maximal pour renvoyer un temps mural non monotone à la plus haute résolution disponible.

my $epoch = walltime();
