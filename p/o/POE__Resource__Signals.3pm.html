NOM

POE::Resource::Signals - gestionnaire de signaux interne pour POE::Kernel

SYNOPSIS

Il n'y a pas d'API publique.

DESCRIPTION

POE::Resource::Signals est une classe d'inclusion pour POE::Kernel. Elle fournit les fonctionnalités nécessaires à la gestion des signaux. Elle est utilisée en interne par POE::Kernel, donc elle n'a pas d'interface publique.

VOIR AUSSI

Voir "Signals" dans POE::Kernel pour une discussion plus approfondie sur la gestion des signaux par POE.

Voir "Signal Watcher Methods" dans POE::Kernel pour l'API publique des signaux de POE.

Voir "Resources" dans POE::Kernel pour des informations publiques sur les ressources POE.

Voir POE::Resource pour une discussion générale sur les ressources et les classes qui les gèrent.

BOGUES

Aucun connu.

Veuillez consulter POE pour plus d'informations sur les auteurs et les contributeurs.
