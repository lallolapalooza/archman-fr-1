NOM

Pod::Select, podselect() - extraire des sections de POD d'entrée

SYNOPIS

use Pod::Select;
## sélectionner toutes les sections de POD dans chaque fichier de @filelist et afficher le résultat sur la sortie standard.
podselect(@filelist);
## identique à ci-dessus, mais écrire dans tmp.out
podselect({-output => "tmp.out"}, @filelist):
## sélectionner uniquement les sections de POD qui se trouvent dans une section de 1er niveau dont le nom est l'un des suivants : NAME, SYNOPSIS, OPTIONS.
podselect({-sections => ["NAME|SYNOPSIS", "OPTIONS"]}, @filelist):
## sélectionner la section DESCRIPTION des POD d'entrée standard et écrire le résultat sur STDERR.
podselect({-output => ">&STDERR", -sections => ["DESCRIPTION"]}, \*STDIN);

ou

use Pod::Select;
## créer un objet analyseur pour sélectionner les sections de POD d'entrée
$parser = new Pod::Select();
## sélectionner toutes les sections de POD dans chaque fichier de @filelist et afficher le résultat dans tmp.out.
$parser->parse_from_file("<&STDIN", "tmp.out");
## sélectionner uniquement les sections de POD qui se trouvent dans une section de 1er niveau dont le nom est l'un des suivants : NAME, SYNOPSIS, OPTIONS.
$parser->select("NAME|SYNOPSIS", "OPTIONS");
for (@filelist) { $parser->parse_from_file($_); }
## sélectionner la section DESCRIPTION et la section SEE ALSO des POD d'entrée standard et écrire le résultat sur STDERR.
$parser->select("DESCRIPTION");
$parser->add_selection("SEE ALSO");
$parser->parse_from_filehandle(\*STDIN, \*STDERR);

REQUIS

perl5.005, Pod::Parser, Exporter, Carp

EXPORTATIONS

podselect()

DESCRIPTION

NOTE : Ce module est considéré comme obsolète ; les versions modernes de Perl (5.31.1 et supérieures) vont supprimer Pod-Parser du noyau et utiliser Pod::Simple pour tout ce qui concerne le format POD.

podselect() est une fonction qui extrait des sections spécifiques de la documentation POD d'une entrée. Cette capacité est fournie par le module Pod::Select, qui est une sous-classe de Pod::Parser. Pod::Select fournit une méthode appelée select() pour spécifier les sections de POD à extraire pour le traitement/l'impression. podselect() crée simplement un objet Pod::Select puis invoque podselect() suivi de parse_from_file().

SPÉCIFICATIONS DE SECTION

podselect() et Pod::Select::select() peuvent recevoir une ou plusieurs "spécifications de section" pour restreindre le texte traité aux seules sections désirées et leurs sous-sections correspondantes. Une spécification de section est une chaîne contenant une ou plusieurs expressions régulières Perl séparées par des /. Si vous avez besoin d'utiliser un caractère / littéralement dans le titre d'une section, vous pouvez l'échapper avec un caractère backslash ("\/").

La syntaxe formelle d'une spécification de section est :

•
regex-titre-head1/regex-titre-head2/...

Toute expression régulière omise ou vide est supposée correspondre à ".*". Veuillez noter que chaque expression régulière donnée est supposée ancrée en ajoutant "^" au début et "$" à la fin. De plus, si une expression régulière commence par un caractère "!", alors l'expression est considérée comme niée (ainsi, "!foo" correspond à tout sauf "foo").

Quelques exemples de spécifications de section suivent :

  • Correspond au "NAME" et "SYNOPSIS" ainsi qu'à leurs sous-sections :

    "NAME|SYNOPSIS"

  • Correspond uniquement aux "Question" et "Answer" de la section "DESCRIPTION" :

    "DESCRIPTION/Question|Answer"

  • Correspond à la sous-section "Comments" de toutes les sections :

    "/Comments"

  • Correspond à toutes les sous-sections de "DESCRIPTION" sauf "Comments" :

    "DESCRIPTION/!Comments"

  • Correspond à la section "DESCRIPTION" mais pas aux sous-sections de l'une de ses sections :

    "DESCRIPTION/!.+"

  • Correspond à toutes les sections de niveau supérieur mais à aucune de leurs sous-sections :

    "/!.+"

MÉTHODES D'OBJET

Les méthodes suivantes sont disponibles dans ce module. Chacune prend en tant que premier paramètre une référence à l'objet lui-même.

curr_headings()

($head1, $head2, $head3, ...) = $parser->curr_headings();
$head1 = $parser->curr_headings(1);

Cette méthode renvoie une liste des sections et sous-sections actuelles dans le document en cours d'analyse. La liste des en-têtes renvoyée correspond au paragraphe le plus récemment traité de l'entrée.

Si un argument est fourni, il doit correspondre au numéro de section souhaité, auquel cas seule la section correspondante est renvoyée. S'il n'y a pas de section actuelle au niveau spécifié, "undef" est renvoyé.

select()

$parser->select($section_spec1,$section_spec2,...);

Cette méthode est utilisée pour sélectionner les sections et sous-sections de la documentation POD qui doivent être imprimées et/ou traitées. L'ensemble des sections actuellement sélectionnées est *remplacé* par l'ensemble donné. Voir add_selection() pour ajouter à la liste des sections actuellement sélectionnées.

Chacun des arguments $section_spec doit être une spécification de section telle que décrite dans "SPÉCIFICATIONS DE SECTION". Les spécifications de section sont traitées par cette méthode et les expressions régulières résultantes sont stockées dans l'objet appelé.

Si aucun argument $section_spec n'est donné, l'ensemble des sections actuellement sélectionnées est vidé (ce qui signifie que toutes les sections seront traitées).

Cette méthode ne devrait normalement pas être surchargée par vos hérités.

add_selection()

$parser->add_selection($section_spec1,$section_spec2,...);

Cette méthode est utilisée pour ajouter aux sections et sous-sections de documentation POD qui doivent être imprimées et/ou traitées. Voir select() pour remplacer les sections actuellement sélectionnées.

Chacun des arguments $section_spec doit être une spécification de section telle que décrite dans "SPÉCIFICATIONS DE SECTION". Les spécifications de section sont traitées par cette méthode et les expressions régulières résultantes sont stockées dans l'objet appelé.

Cette méthode ne devrait normalement pas être surchargée par vos hérités.

clear_selections()

$parser->clear_selections();

Cette méthode n'accepte aucun argument, elle a le même effet que l'appel à select() sans argument.

match_section()

$boolean = $parser->match_section($heading1,$heading2,...);

Renvoie une valeur vraie si les titres de section et de sous-section spécifiés correspondent à l'une des spécifications de section actuelles de priorité dans les appels précédents à select() et add_selection() (ou si aucune section n'est explicitement sélectionnée/désélectionnée).

Les arguments $heading1, $heading2, etc. sont les titres de sections, sous-sections, etc. à faire correspondre. Si $headingN n'est pas spécifié, le titre de section actuel correspondant de l'entrée est utilisé.

Cette méthode ne devrait normalement pas être surchargée par vos hérités.

is_selected()

>$boolean = $parser->is_selected($paragraph);

Cette méthode est utilisée pour déterminer si le bloc de texte donné dans $paragraph fait partie des sections et sous-sections POD actuellement sélectionnées à imprimer ou à traiter. Cette méthode est également responsable du suivi de la section d'entrée actuelle et des sous-sections. On suppose que $paragraph est le paragraphe d'entrée le plus récemment lu (mais pas encore traité).

La valeur retournée sera vraie si $paragraph et le reste du texte de la même section que $paragraph doivent être sélectionnés (inclus) pour traitement ; sinon, une valeur fausse est retournée.

FONCTIONS EXPORTÉES

Les fonctions suivantes sont exportées par ce module. Veuillez noter qu'il s'agit de fonctions (et non de méthodes) et qu'elles ne prennent donc pas d'argument premier implicite.

podselect()

podselect(\%options,@filelist);

podselect imprimera les paragraphes POD bruts (non traduits) de toutes les sections POD dans les fichiers d'entrée spécifiés par @filelist selon les options données dans "\%options".

Si un argument à podselect est une référence à une table de correspondances (tableau associatif), les valeurs avec les clés suivantes sont traitées comme suit :

-output
Une chaîne correspondant au fichier de sortie souhaité (ou ">&STDOUT" ou ">&STDERR"), ou un descripteur de fichier sur lequel écrire. La valeur par défaut est la sortie standard.
-sections
Une référence à un tableau de spécifications de sections (comme décrit dans "SPÉCIFICATIONS DE SECTIONS") qui indiquent l'ensemble souhaité de sections et sous-sections POD à sélectionner à partir des entrées. Si aucune spécification de section n'est donnée, alors toutes les sections des POD sont utilisées.

Tous les autres arguments sont facultatifs et doivent correspondre à des descripteurs de fichiers à lire ou aux noms de fichiers d'entrée contenant des sections POD. Un nom de fichier de "", "-" ou "<&STDIN" sera interprété comme l'entrée standard (ce qui est la valeur par défaut si aucun argument n'est donné).

MÉTHODES ET DONNÉES PRIVÉES

Pod::Select utilise un certain nombre de méthodes et de champs de données internes que les clients ne devraient pas avoir besoin de voir ou d'utiliser. Afin d'éviter les collisions de noms avec les données et méthodes des clients, ces méthodes et champs sont brièvement discutés ici. Les hackers déterminés peuvent obtenir plus d'informations à leur sujet en lisant le code source de Pod::Select.

Les champs de données privés sont stockés dans l'objet de table de correspondances dont la référence est retournée par le constructeur new() pour cette classe. Les noms de toutes les méthodes et champs de données privés utilisés par Pod::Select commencent par un préfixe de "_" et correspondent à l'expression régulière "/^_\w+$/".
