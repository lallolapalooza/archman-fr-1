NOM

POE::Loop::PerlSignals - routines communes de gestion des signaux pour les ponts POE::Loop

SYNTAXE

Voir POE::Loop.

DESCRIPTION

POE::Loop::PerlSignals implémente le code commun pour gérer les signaux pour de nombreuses boucles d'événements différentes. La plupart des boucles ne gèrent pas les signaux nativement, donc ce code a été abstrait dans un module réutilisable.

POE::Loop::PerlSignals suit l'interface publique de POE::Loop pour la gestion des signaux. Par conséquent, veuillez consulter POE::Loop pour plus de détails.

VOIR AUSSI

POE, POE::Loop
