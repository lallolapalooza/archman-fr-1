NOM

POE::Resource::Aliases - gestionnaire d'alias de session interne pour POE::Kernel

SYNTAXE

Il n'y a pas d'API publique.

DESCRIPTION

POE::Resource::Aliases est une classe de mélange (mix-in) pour POE::Kernel. Elle fournit les fonctionnalités pour gérer les alias de session. Elle est utilisée en interne par POE::Kernel, donc elle n'a pas d'interface publique.

VOIR AUSSI

Voir "Session Identifiers (IDs and Aliases)" dans POE::Kernel pour l'API publique des alias.

Voir "Resources" dans POE::Kernel pour des informations publiques sur les ressources POE.

Voir POE::Resource pour une discussion générale sur les ressources et les classes qui les gèrent.

BOGUES

Aucun connu.
