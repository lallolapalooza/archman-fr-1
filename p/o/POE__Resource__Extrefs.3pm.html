NOM

POE::Resource::Extrefs - gestionnaire interne des comptes de référence pour POE::Kernel

SYNTAXE

Il n'y a pas d'API publique.

DESCRIPTION

POE::Resource::Extrefs est une classe de mixage pour POE::Kernel. Elle fournit les fonctionnalités pour gérer les comptes de référence de session, en particulier ceux que les applications peuvent utiliser. POE::Resource::Extrefs est utilisé en interne par POE::Kernel, donc il n'a pas d'interface publique.

VOIR AUSSI

Voir "Public Reference Counters" dans POE::Kernel pour l'API publique des extrefs.

Voir "Resources" dans POE::Kernel pour des informations publiques sur les ressources POE.

Voir POE::Resource pour une discussion générale sur les ressources et les classes qui les gèrent.

BOGUES

Les compteurs de référence n'ont aucune information de propriété, donc les comptes de référence d'une entité peuvent entrer en conflit avec ceux d'une autre. Ce n'est généralement pas un problème si toutes les entités se comportent correctement.
