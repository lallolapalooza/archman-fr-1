NOM

POE::Resources - chargeur de ressources POE

SYNOPSIS

# Destiné à une utilisation interne par POE::Kernel.
use POE::Resources;
POE::Resources->load();

DESCRIPTION

POE::Kernel est divisé en interne en différentes ressources qui sont gérées séparément par des classes d'insertion (mix-in) individuelles.

POE::Resources est conçu comme un gestionnaire de macros de haut niveau pour les classes POE::Resource. Il implémente actuellement une seule méthode, load(), qui charge toutes les classes POE::Resource.

MÉTHODES

POE::Resources a une interface publique, mais il est destiné à être utilisé en interne par POE::Kernel. Les programmeurs d'applications n'ont jamais besoin d'utiliser POE::Resources directement.

load

POE::Kernel appelle load() pour charger tous les modules POE::Resource connus.

Chaque ressource peut être gérée par un module Perl pur, ou par un module XS. Pour chaque classe de ressource, load() essaie d'abord de charger la version "POE::XS::Resource::..." du module. Si cela échoue, load() se rabat sur "POE::Resource::...".

VOIR AUSSI

Voir "Resources" dans POE::Kernel pour des informations publiques sur les ressources POE.

Voir POE::Resource pour une discussion générale sur les ressources et les classes qui les gèrent.

AUTEURS ET LICENCE

Veuillez consulter POE pour plus d'informations sur ses auteurs, contributeurs et la licence de POE.
