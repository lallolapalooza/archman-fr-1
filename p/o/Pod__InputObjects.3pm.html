Paquet: perl-pod-parser

Pod::InputObjects(3) Documentation Perl fournie par l'utilisateur Pod::InputObjects(3)

NOM

Pod::InputObjects - objets représentant les paragraphes d'entrée POD, les commandes, etc.

SYNOPIS

use Pod::InputObjects;

REQUIERT

perl5.004, Carp

EXPORTE

Rien.

DESCRIPTION

NOTE : Ce module est considéré comme obsolète ; les versions récentes de Perl (5.31.1 et plus) vont supprimer Pod-Parser du noyau et utiliser Pod::Simple pour tout ce qui concerne POD.

Ce module définit quelques objets d'entrée de base utilisés par Pod::Parser lors de la lecture et de l'analyse syntaxique de texte POD à partir d'une source d'entrée. Les objets suivants sont définis :

package Pod::Paragraph
Un objet correspondant à un paragraphe de texte d'entrée POD. Il peut s'agir d'un paragraphe simple, d'un paragraphe verbatim, ou d'un paragraphe de commande (voir perlpod).
package Pod::InteriorSequence
Un objet correspondant à une commande de séquence intérieure du texte d'entrée POD (voir perlpod).
package Pod::ParseTree
Un objet correspondant à un arbre de texte POD analysé. Chaque "nœud" d'un arbre d'analyse (ou ptree) est soit une chaîne de texte, soit une référence à un objet Pod::InteriorSequence. Les nœuds apparaissent dans l'arbre d'analyse dans l'ordre où ils ont été analysés, de gauche à droite.

Chacun de ces objets d'entrée est décrit plus en détail dans les sections suivantes.

Pod::Paragraph

Un objet représentant un paragraphe de texte d'entrée POD. Il possède les méthodes/attributs suivants :

Pod::Paragraph->new()

my $pod_para1 = Pod::Paragraph->new(-text => $text);
my $pod_para2 = Pod::Paragraph->new(-name => $cmd,
                                    -text => $text);
my $pod_para3 = new Pod::Paragraph(-text => $text);
my $pod_para4 = new Pod::Paragraph(-name => $cmd,
                                   -text => $text);
my $pod_para5 = Pod::Paragraph->new(-name => $cmd,
                                    -text => $text,
                                    -file => $filename,
                                    -line => $line_number);

C'est une méthode de classe qui construit un objet "Pod::Paragraph" et retourne une référence vers le nouvel objet paragraphe. Elle peut recevoir un ou deux arguments mots-clés. Le mot-clé "-text" indique le texte correspondant du paragraphe POD. Le mot-clé "-name" indique le nom de la commande POD correspondante, tel que "head1" ou "item" (il ne doit pas contenir le préfixe "=") ; ceci n'est nécessaire que si le paragraphe POD correspond à un paragraphe de commande. Les mots-clés "-file" et "-line" indiquent le nom du fichier et le numéro de ligne correspondant au début du paragraphe.

$pod_para->cmd_name()

my $para_cmd = $pod_para->cmd_name();

Si ce paragraphe est un paragraphe de commande, cette méthode retourne le nom de la commande (sans le préfixe "=").

$pod_para->text()

my $para_text = $pod_para->text();

Cette méthode retourne le texte correspondant du paragraphe.

$pod_para->raw_text()

my $raw_pod_para = $pod_para->raw_text();

Cette méthode retourne le texte brut du paragraphe POD, exactement tel qu'il apparaissait dans l'entrée.

$pod_para->cmd_prefix()

my $prefix = $pod_para->cmd_prefix();

Si ce paragraphe est un paragraphe de commande, cette méthode retourne le préfixe utilisé pour désigner la commande (qui devrait être la chaîne "=" ou "==").

$pod_para->cmd_separator()

my $separator = $pod_para->cmd_separator();

Si ce paragraphe est un paragraphe de commande, cette méthode retourne le texte utilisé pour séparer le nom de la commande du reste du paragraphe (s'il y en a).

$pod_para->parse_tree()

my $ptree = $pod_parser->parse_text( $pod_para->text() );
$pod_para->parse_tree( $ptree );
$ptree = $pod_para->parse_tree();

Cette méthode permet d'obtenir/définir l'arbre d'analyse correspondant au texte du paragraphe.

$pod_para->file_line()

my ($filename, $line_number) = $pod_para->file_line();
my $position = $pod_para->file_line();

Retourne le nom de fichier et le numéro de ligne actuels pour l'objet paragraphe. Si appelée dans un contexte de liste, elle retourne une liste de deux éléments : d'abord le nom du fichier, puis le numéro de ligne. Si appelée dans un contexte scalaire, elle retourne une chaîne contenant le nom du fichier, suivi de deux points (':'), suivi du numéro de ligne.

Pod::InteriorSequence

Un objet représentant une commande de séquence intérieure POD. Il possède les méthodes/attributs suivants :

Pod::InteriorSequence->new()

my $pod_seq1 = Pod::InteriorSequence->new(-name => $cmd
                                          -ldelim => $delimiter);
my $pod_seq2 = new Pod::InteriorSequence(-name => $cmd,
                                         -ldelim => $delimiter);
my $pod_seq3 = new Pod::InteriorSequence(-name => $cmd,
                                         -ldelim => $delimiter,
                                         -file => $filename,
                                         -line => $line_number);
my $pod_seq4 = new Pod::InteriorSequence(-name => $cmd, $ptree);
my $pod_seq5 = new Pod::InteriorSequence($cmd, $ptree);

C'est une méthode de classe qui construit un objet "Pod::InteriorSequence" et retourne une référence vers le nouvel objet séquence intérieure. Elle doit recevoir deux arguments mots-clés. Le mot-clé "-ldelim" indique le délimiteur gauche correspondant de la séquence intérieure (par exemple, '<'). Le mot-clé "-name" indique le nom de la commande de séquence intérieure correspondante, telle que "I" ou "B" ou "C". Les mots-clés "-file" et "-line" indiquent le nom du fichier et le numéro de ligne correspondant au début de la séquence intérieure. Si l'argument $ptree est donné, il doit être le dernier argument, et il doit être soit une chaîne, soit une référence de tableau appropriée pour être passée à Pod::ParseTree::new (ou il peut être une référence à un objet Pod::ParseTree).

$pod_seq->cmd_name()

my $seq_cmd = $p

$pod_seq->prepend()

$pod_seq->prepend($text);
$pod_seq1->prepend($pod_seq2);

Ajoute la chaîne de caractères, l'arbre d'analyse ou l'objet séquence donné au début de l'arbre d'analyse de cette séquence intérieure.

$pod_seq->append()

$pod_seq->append($text);
$pod_seq1->append($pod_seq2);

Ajoute la chaîne de caractères, l'arbre d'analyse ou l'objet séquence donné à la fin de l'arbre d'analyse de cette séquence intérieure.

$pod_seq->nested()

$outer_seq = $pod_seq->nested || print "not nested";

Si cette séquence intérieure est imbriquée dans une autre séquence intérieure, alors la séquence extérieure/parente qui la contient est retournée. Sinon, "undef" est retourné.

$pod_seq->raw_text()

my $seq_raw_text = $pod_seq->raw_text();

Cette méthode retourne le texte brut de la séquence intérieure POD, exactement tel qu'il apparaissait dans l'entrée.

$pod_seq->left_delimiter()

my $ldelim = $pod_seq->left_delimiter();

Le délimiteur le plus à gauche commençant le texte de l'argument de la séquence intérieure (devrait être "<").

$pod_seq->right_delimiter()

Le délimiteur le plus à droite commençant le texte de l'argument de la séquence intérieure (devrait être ">").

$pod_seq->parse_tree()

my $ptree = $pod_parser->parse_text($paragraph_text);
$pod_seq->parse_tree( $ptree );
$ptree = $pod_seq->parse_tree();

Cette méthode obtient/définit l'arbre d'analyse correspondant au texte de la séquence intérieure.

$pod_seq->file_line()

my ($filename, $line_number) = $pod_seq->file_line();
my $position = $pod_seq->file_line();

Retourne le nom de fichier et le numéro de ligne actuels pour l'objet de séquence intérieure. Si appelée dans un contexte de liste, elle retourne une liste de deux éléments : d'abord le nom de fichier, puis le numéro de ligne. Si appelée dans un contexte scalaire, elle retourne une chaîne contenant le nom de fichier, suivi de deux-points (':'), suivi du numéro de ligne.

Pod::InteriorSequence::DESTROY()

Cette méthode effectue le nettoyage nécessaire pour la séquence intérieure. Si vous surchargez cette méthode, il est impératif que vous appeliez la méthode parente depuis votre propre méthode, sinon le stockage de la séquence intérieure ne sera pas libéré lors de sa destruction !

Pod::ParseTree

Cet objet correspond à un arbre de texte POD analysé. Lorsque le texte POD est balayé de gauche à droite, il est analysé en une liste ordonnée de chaînes de texte et d'objets Pod::InteriorSequence (dans l'ordre d'apparition). Un objet Pod::ParseTree correspond à cette liste de chaînes et de séquences. Chaque séquence intérieure de l'arbre d'analyse peut contenir elle-même un arbre d'analyse (car les séquences intérieures peuvent être imbriquées).

Pod::ParseTree->new()

my $ptree1 = Pod::ParseTree->new;
my $ptree2 = new Pod::ParseTree;
my $ptree4 = Pod::ParseTree->new($array_ref);
my $ptree3 = new Pod::ParseTree($array_ref);

Ceci est une méthode de classe qui construit un objet "Pod::Parse_tree" et retourne une référence au nouvel arbre d'analyse. Si un seul argument est donné, il doit être une référence à un tableau, et est utilisé pour initialiser la racine (le sommet) de l'arbre d'analyse.

$ptree->top()

my $top_node = $ptree->top();
$ptree->top( $top_node );
$ptree->top( @children );

Cette méthode obtient/définit le nœud supérieur de l'arbre d'analyse. Si aucun argument n'est donné, elle retourne le nœud le plus haut de l'arbre (la racine), qui est également un Pod::ParseTree. Si elle reçoit un seul argument qui est une référence, alors la référence est supposée être un arbre d'analyse et devient le nouveau nœud supérieur. Sinon, si des arguments sont donnés, ils sont traités comme la nouvelle liste d'enfants du nœud supérieur.

$ptree->children()

Cette méthode obtient/définit les enfants du nœud supérieur de l'arbre d'analyse. Si aucun argument n'est donné, elle retourne la liste (tableau) des enfants (chacun étant soit une chaîne de caractères, soit un Pod::InteriorSequence. Sinon, si des arguments sont donnés, ils sont traités comme la nouvelle liste d'enfants du nœud supérieur.

$ptree->prepend()

Cette méthode ajoute au début la chaîne de caractères ou l'arbre d'analyse donné à l'arbre d'analyse actuel. Si le premier élément de l'arbre d'analyse est du texte et que l'argument est également du texte, alors le texte est ajouté au début du premier élément (pas comme une chaîne séparée). Sinon, l'argument est ajouté comme une nouvelle chaîne ou un nouvel arbre d'analyse *avant* l'actuel.

$ptree->append()

Cette méthode ajoute à la fin la chaîne de caractères ou l'arbre d'analyse donné à l'arbre d'analyse actuel. Si le dernier élément de l'arbre d'analyse est du texte et que l'argument est également du texte, alors le texte est ajouté à la fin du dernier élément (pas comme une chaîne séparée). Sinon, l'argument est ajouté comme une nouvelle chaîne ou un nouvel arbre d'analyse *après* l'actuel.

$ptree->raw_text()

my $ptree_raw_text = $ptree->raw_text();

Cette méthode retourne le texte brut de l'arbre d'analyse POD exactement tel qu'il apparaissait dans l'entrée.

Pod::ParseTree::DESTROY()

Cette méthode effectue le nettoyage nécessaire pour l'arbre d'analyse. Si vous surchargez cette méthode, il est impératif que vous appeliez la méthode parente depuis votre propre méthode, sinon le stockage de l'arbre d'analyse ne sera pas libéré lors de sa destruction !
