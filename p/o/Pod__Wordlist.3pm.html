NOM

Pod::Wordlist - Mots anglais qui apparaissent dans la documentation Perl

VERSION

version 1.26

DESCRIPTION

Pod::Wordlist est utilisé par Pod::Spell, fournissant un ensemble de mots qui sont du jargon anglais apparaissant dans la documentation Perl, mais qui ne se trouvent pas dans les lexiques anglais généraux. (Par exemple : autovivify, backreference, chroot, stringify, wantarray.)

Vous pouvez également utiliser cette liste de mots avec votre traitement de texte en copiant simplement le contenu de "share/wordlist" dans votre traitement de texte, en supprimant le code Perl initial afin que seule la liste de mots reste, puis en vérifiant l'orthographe de cette liste résultante et en ajoutant chaque mot qu'elle contient à votre lexique privé.

MÉTHODES

learn_stopwords

$wordlist->learn_stopwords( $text );

Modifie la liste des mots vides (stopwords) en fonction d'un bloc de texte. Voir les règles pour <l'ajout de mots vides|Pod::Spell/ADDING STOPWORDS> pour plus de détails.

is_stopword

if ( $wordlist->is_stopword( $word ) ) { ... }

Renvoie vrai si le mot est trouvé dans la liste des mots vides.

strip_stopwords

my $out = $wordlist->strip_stopwords( $text );

Renvoie une chaîne avec les mots séparés par des espaces du texte original, les mots vides étant supprimés.

ATTRIBUTS

wordlist

ref $self->wordlist eq 'HASH'; # vrai

C'est l'instance de la liste de mots.

no_wide_chars

Si vrai, les mots contenant des caractères en dehors de la plage Latin-1 de 0x00 à 0xFF seront supprimés comme les mots vides.

LISTE DE MOTS

Notez que la portée de ce fichier est uniquement l'anglais, spécifiquement l'anglais américain. (Mais vous pourriez trouver utile de l'intégrer à vos propres lexiques, même s'ils sont pour d'autres dialectes/langues.)

supprimez toutes les q{'s} avant d'ajouter à la liste.

La liste doit être triée et unique. Ce qui suit fonctionnera (avec GNU Coreutils ).

sort share/wordlist -u > /tmp/sorted && mv /tmp/sorted share/wordlist
