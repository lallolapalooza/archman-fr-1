NOM

POE::Resource::Sessions - gestionnaire de sessions interne pour POE::Kernel

SYNTAXE

Aucune API publique.

DESCRIPTION

POE::Resource::Sessions est une classe d'inclusion pour POE::Kernel. Elle fournit les fonctionnalités internes qui gèrent les sessions, indépendamment du type de session. Elle est utilisée en interne par POE::Kernel, donc elle n'a pas d'interface publique.

VOIR AUSSI

Voir POE::Session et POE::NFA pour un type de session. CPAN en propose également d'autres.

Voir "Sessions" dans POE::Kernel pour une discussion sur les sessions POE::Kernel.

Voir "Durée de vie des sessions" dans POE::Kernel pour apprendre pourquoi les sessions s'exécutent et comment les arrêter.

Voir "Gestion des sessions" dans POE::Kernel pour des informations sur la gestion des sessions dans vos applications, et les événements qui se produisent lorsque les sessions apparaissent et disparaissent.

Voir "Méthodes d'aide aux sessions" dans POE::Kernel pour les méthodes amicales entre les classes POE::Kernel et POE::Session.

Voir "Ressources" dans POE::Kernel pour des informations publiques sur les ressources POE.

Voir POE::Resource pour une discussion générale sur les ressources et les classes qui les gèrent.

BOGUES

Aucun connu.
