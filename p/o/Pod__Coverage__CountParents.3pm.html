Pod::Coverage::CountParents(3) Documentation Perl fournie par l'utilisateur Pod::Coverage::CountParents(3)

NOM

Pod::Coverage::CountParents - sous-classe de Pod::Coverage qui examine l'arbre d'héritage

SYNTAXE

# tout en une seule invocation
use Pod::Coverage::CountParents package => 'Fishy';
# OO pure
use Pod::Coverage::CountParents;
my $pc = new Pod::Coverage::CountParents package => 'Pod::Coverage';
print "Nous assurons!" if $pc->coverage == 1;

DESCRIPTION

Ce module étend Pod::Coverage pour inclure la documentation des classes parentes lors de l'identification de la couverture du code.

Si vous voulez une documentation complète, nous vous suggérons de consulter la documentation de Pod::Coverage.
