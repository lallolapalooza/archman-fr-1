Pod::Simple::Debug(3perl) Guide du programmeur Perl Pod::Simple::Debug(3perl)

NOM

Pod::Simple::Debug -- mettre Pod::Simple en mode trace/débogage

SYNTAXE

use Pod::Simple::Debug (5);  # ou un entier quelconque

Ou:

my $debuglevel;
use Pod::Simple::Debug (\$debuglevel, 0);
...quelque chose qui utilise Pod::Simple pour faire des choses, mais dont
 vous ne voulez pas de sortie de débogage...
$debug_level = 4;
...quelque chose qui utilise Pod::Simple pour faire des choses, mais dont
 vous VOULEZ une sortie de débogage...
$debug_level = 0;

DESCRIPTION

Ceci est un module interne pour contrôler le niveau de débogage (aussi appelé niveau de trace) de Pod::Simple. Ceci n'intéresse que les développeurs de Pod::Simple.

CAVEATS

Notez que vous devriez charger ce module *avant* de charger Pod::Simple (ou toute classe basée sur Pod::Simple). Si vous essayez de charger Pod::Simple::Debug après que &Pod::Simple::DEBUG soit déjà défini, Pod::Simple::Debug générera une erreur fatale du type « Il est trop tard pour appeler Pod::Simple::Debug ».

Notez que le mode "use Pod::Simple::Debug (\$x, somenum)" ralentira considérablement l'exécution de Pod::Simple (et autres), car &Pod::Simple::DEBUG ne sera plus une sous-routine constante, et donc Pod::Simple (et autres) ne sera pas compilé avec une optimisation des constantes.

INTERNE

Faire ceci:

use Pod::Simple::Debug (5);  # ou un entier quelconque

Est essentiellement équivalent à:

BEGIN { sub Pod::Simple::DEBUG () {5} }  # ou un entier quelconque
use Pod::Simple ();

Et ceci:

use Pod::Simple::Debug (\$debug_level,0);  # ou un entier quelconque

Est essentiellement équivalent à ceci:

my $debug_level;
BEGIN { $debug_level = 0 }
BEGIN { sub Pod::Simple::DEBUG () { $debug_level }
use Pod::Simple ();
