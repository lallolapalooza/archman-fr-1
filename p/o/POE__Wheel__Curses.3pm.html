NOM

POE::Wheel::Curses - entrée non bloquante pour Curses

SYNOPSIS

use Curses;
use POE qw(Wheel::Curses);
POE::Session->create(
  inline_states => {
    _start => sub {
      $_[HEAP]{console} = POE::Wheel::Curses->new(
        InputEvent => 'got_keystroke',
      );
    },
    got_keystroke => sub {
      my $keystroke = $_[ARG0];
      # Rendre imprimables les touches de contrôle et étendues.
      if ($keystroke lt ' ') {
        $keystroke = '<' . uc(unctrl($keystroke)) . '>';
      }
      elsif ($keystroke =~ /^\d{2,}$/) {
        $keystroke = '<' . uc(keyname($keystroke)) . '>';
      }
      # L'afficher simplement.
      addstr($keystroke);
      noutrefresh();
      doupdate;
      # Sortir d'une manière ou d'une autre.
      delete $_[HEAP]{console} if $keystroke eq "<^C>";
    },
  }
);
POE::Kernel->run();
exit;

DESCRIPTION

POE::Wheel::Curses implémente l'entrée non bloquante pour les programmes Curses.

POE::Wheel::Curses émettra un "InputEvent" de votre choix chaque fois qu'un événement d'entrée est détecté sur un périphérique d'entrée reconnu (clavier et parfois souris, selon la bibliothèque curses). Pendant ce temps, les applications peuvent faire d'autres choses comme surveiller des connexions réseau ou des processus enfants, ou gérer des minuteurs et autres.

METHODES PUBLIQUES

POE::Wheel::Curses est plutôt simple.

new

new() crée un nouvel objet POE::Wheel::Curses. Pendant la construction, la roue enregistre un observateur d'entrée pour STDIN (via select_read()) et enregistre un gestionnaire interne pour prétraiter les frappes de clavier.

new() n'accepte qu'un seul paramètre, "InputEvent". "InputEvent" contient le nom de l'événement que la roue émettra chaque fois qu'il y aura une entrée sur la console ou le terminal. Comme avec toutes les roues, l'événement sera envoyé à la session qui était active lorsque la roue a été construite.

Il est à noter qu'une application ne peut avoir qu'un seul objet POE::Wheel::Curses actif.

ÉVÉNEMENTS ET PARAMÈTRES

Voici les événements envoyés par POE::Wheel::Curses.

InputEvent

"InputEvent" définit l'événement qui sera émis lorsque POE::Wheel::Curses détecte et lit l'entrée de la console.Elle inclut deux paramètres:

$_[ARG0] contient la frappe brute telle que reçue par Curses::getch(). Une application peut traiter la frappe en utilisant Curses::unctrl() et Curses::keyname() sur la frappe.

$_[ARG1] contient l'ID de l'objet POE::Wheel::Curses.

Les événements de souris ne sont pas portables. En octobre 2009, il appartient à l'application de décider si elle doit appeler mousemask().

VOIR AUSSI

POE::Wheel décrit les roues en général.
