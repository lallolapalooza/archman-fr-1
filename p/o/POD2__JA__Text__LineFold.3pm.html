NOM

Text::LineFold~[ja] - retournement de lignes de texte

SYNOPIS

use Text::LineFold;
$lf = Text::LineFold->new();

# Retourner les lignes
$folded = $lf->fold($string, 'PLAIN');
$indented = $lf->fold(' ' x 8, ' ' x 4, $string);
# Déplier les lignes
$unfolded = $lf->unfold($string, 'FIXED');

DESCRIPTION

Text::LineFold gère le retournement et le dépliement des lignes de texte. Principalement conçu pour les messages électroniques, il prend également en charge le format "flowed" de la RFC 3676.

Interface publique

TabSize => NUMBER
Le nombre d'espaces pour un caractère de tabulation. Si 0 est spécifié, les tabulations sont ignorées. La valeur par défaut est 8.

$self->fold (STRING, [METHOD])
$self->fold (INITIAL_TAB, SUBSEQUENT_TAB, STRING, ...)
Méthode d'instance. Retourne la chaîne STRING. Supprime les espaces de fin de ligne et les tabulations horizontales, les remplace par la chaîne spécifiée par l'option Newline, et ajoute un saut de ligne à la fin de la ligne si nécessaire. Les tabulations horizontales sont considérées comme des tabulations dans la plage spécifiée par l'option TabSize.

Pour la forme avec un seul argument, vous pouvez spécifier les options suivantes pour le paramètre METHOD :

"FIXED"
Les lignes commençant par ">" ne sont pas retournées. Les sauts de ligne sont séparés par une ligne vide.
"FLOWED"
Format "Format=Flowed; DelSp=Yes" tel que défini dans la RFC 3676.
"PLAIN"
La méthode par défaut. Retourne toutes les lignes.

La forme avec deux arguments est similaire à "wrap()" dans Text::Wrap. Elle retourne toutes les lignes. INITIAL_TAB est inséré au début des sauts de ligne, et SUBSEQUENT_TAB est inséré au début des autres lignes.

$self->unfold (STRING, METHOD)
Retourne la chaîne STRING en joignant les lignes retournées et en les rendant droites.

Les options suivantes peuvent être spécifiées pour le paramètre METHOD :

"FIXED"
La méthode par défaut. Les lignes commençant par ">" ne sont pas jointes. Les lignes vides sont considérées comme des séparateurs de sauts de ligne.
"FLOWED"
Joint le format "Format=Flowed; DelSp=Yes" tel que défini dans la RFC 3676.
"FLOWEDSP"
Défini dans la RFC 3676
perl-unicode-linebreak - Formats text for line breaking

NAME

Unicode::LineBreak - Formats text for line breaking

SYNOPSIS

    use Unicode::LineBreak qw(:all);

    my $text = "This is a sample text with Japanese characters like \xE3\x81\x82\xE3\x81\x84\xE3\x81\x86\xE3\x81\x88\xE3\x81\x8A.";
    my @lines = format_text($text, 20);
    print join("\n", @lines);

DESCRIPTION

This module implements the Unicode Line Breaking Algorithm.

The format_text function:
Takes a string and a line width, and returns an array of strings formatted to the specified width.
The format_lines function:
Takes a string and returns an array of strings, where each string is a sequence of characters that can form a line according to the Unicode Line Breaking Algorithm.

The module follows the specification defined by the Unicode Consortium.

The "Format=Flowed; DelSp=No" format applies.
