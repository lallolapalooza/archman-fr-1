POE::Component::Client::HTTP::Request(3) Documentation Perl fournie par l'utilisateur POE::Component::Client::HTTP::Request(3)

NOM

POE::Component::Client::HTTP::Request - une classe de requête HTTP

VERSION

version 0.949

SYNOPIS

# Utilisé en interne par POE::Component::Client::HTTP

DESCRIPTION

POE::Component::Client::HTTP::Request encapsule l'état des requêtes de POE::Component::Client::HTTP tout au long de leur cycle de vie. Il s'avère qu'il y a beaucoup d'état à gérer.

CONSTRUCTEUR

new PARAMETRES_NOMMES

Crée un objet POE::Component::Client::HTTP pour gérer une requête. Le constructeur prend plusieurs paramètres nommés :

Requête => HTTP_REQUEST
Un objet POE::Component::Client::HTTP::Request encapsule une requête HTTP simple. Obligatoire.
Fabrique => FABRIQUE_POE_COMPONENT_CLIENT_HTTP_REQUEST
La requête peut créer des requêtes supplémentaires au cours de sa durée de vie, par exemple lors du suivi des redirections. Le paramètre Fabrique spécifie la FABRIQUE_POE_COMPONENT_CLIENT_HTTP_REQUEST qui peut être utilisée pour les créer. Obligatoire.
Retour => RETOUR_REPONSE
POE::Component::Client::HTTP crée un retour qui sera utilisé pour envoyer les réponses à la session requérante. Obligatoire.
Progression => RETOUR_PROGRESSION
Définit la notification de progression si l'utilisateur a demandé des événements de progression. Facultatif.
Proxy
Définit le proxy utilisé pour cette requête, si demandé par l'utilisateur. Facultatif.

METHODES

ID

Retourne l'ID unique de la requête.

retourner_reponse

Envoie une réponse à la session de l'utilisateur. Appelée par POE::Component::Client::HTTP lorsqu'une réponse complète est arrivée.

ajouter_eof

Appelée par POE::Component::Client::HTTP pour indiquer que EOF est arrivé.

ajouter_contenu DONNEES_ANALYSEES

Appelée par POE::Component::Client::HTTP pour ajouter des données de contenu à une réponse construite de manière incrémentielle. Si DONNEES_ANALYSEES est un objet, il est traité comme un objet HTTP::Headers et ses en-têtes sont assimilés à la réponse en cours de construction par la requête. Sinon, DONNEES_ANALYSEES est ajouté au contenu de la réponse.

minuteur MINUTEUR

Accesseur pour manipuler le minuteur d'expiration de la requête. Définit le minuteur de la requête si MINUTEUR est spécifié, sinon récupère simplement celui actuellement associé à la requête.

creer_minuteur TEMPS_MORT

Crée et définit un minuteur pour cette requête. TEMPS_MORT est le nombre de secondes pendant lesquelles cette requête peut vivre.

supprimer_delai_expiration

Désactive le minuteur associé à cette requête et le supprime.

retour RETOUR

Accesseur pour manipuler le retour associé à cette requête. Définit le retour si RETOUR est défini, sinon le récupère simplement.

fait_redirection QUELQUE_CHOSE

FIXME - Pas sûr de ce que fait cet accesseur.

verifier_redirection

Vérifie si la dernière réponse est une redirection, si la requête est autorisée à suivre les redirections et si le nombre maximum de redirections n'a pas été atteint. Lance une redirection si toutes les conditions sont favorables.

fermer_connexion

Chaque objet de requête actif contient une connexion interne. Cette méthode la ferme.

envoyer_a_roue

Transmet la requête au socket associé à cette requête.

roue

Un accesseur pour retourner la roue associée à cette requête.

erreur CODE_ERREUR, MESSAGE_ERREUR

Génère une réponse d'erreur et la renvoie à la session de l'utilisateur.

erreur_connexion MESSAGE_ECHEC_CONNEXION

Génère une réponse d'erreur de connexion et la renvoie à la session de l'utilisateur.

hote

Retourne l'hôte avec lequel cette requête tente de travailler.

port

Retourne le port avec lequel cette requête tente de travailler.

scheme

Retourne le schéma de cette requête.
