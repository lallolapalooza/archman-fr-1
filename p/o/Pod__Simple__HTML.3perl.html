NOM

Pod::Simple::HTML - convertir du Pod en HTML

SYNOPSIS

perl -MPod::Simple::HTML -e Pod::Simple::HTML::go thingy.pod

DESCRIPTION

Cette classe sert à générer un rendu HTML d'un document Pod.

C'est une sous-classe de Pod::Simple::PullParser et elle hérite de toutes ses méthodes (et options).

Notez que si vous souhaitez effectuer une conversion par lots de nombreux documents Pod en HTML, vous devriez consulter le module Pod::Simple::HTMLBatch.

APPEL DEPUIS PERL

Code minimal

use Pod::Simple::HTML;
my $p = Pod::Simple::HTML->new;
$p->output_string(\my $html);
$p->parse_file('chemin/vers/Module/Name.pm');
open my $out, '>', 'out.html' or die "Impossible d'ouvrir 'out.html': $!\n";
print $out $html;

Exemple plus détaillé

use Pod::Simple::HTML;

Définir le type de contenu :

$Pod::Simple::HTML::Content_decl =  q{<meta http-equiv="Content-Type" content="text/html; charset=UTF-8" >};
my $p = Pod::Simple::HTML->new;

Inclure une seule source javascript :

$p->html_javascript('http://abc.com/a.js');

Ou insérer plusieurs sources javascript dans l'en-tête (ou, pour être précis, inclure quoi que ce soit, bien que ce ne soit pas recommandé)

$p->html_javascript('
    <script type="text/javascript" src="http://abc.com/b.js"></script>
    <script type="text/javascript" src="http://abc.com/c.js"></script>');

Inclure une seule source css dans l'en-tête :

$p->html_css('/style.css');

ou insérer plusieurs sources css :

$p->html_css('
    <link rel="stylesheet" type="text/css" title="pod_stylesheet" href="http://remote.server.com/jquery.css">
    <link rel="stylesheet" type="text/css" title="pod_stylesheet" href="/style.css">');

Indiquer au parseur où doit aller la sortie. Dans ce cas, elle sera placée dans la variable $html :

my $html;
$p->output_string(\$html);

Analyser et traiter un fichier contenant du pod :

$p->parse_file('chemin/vers/Module/Name.pm');

MÉTHODES

Les variables suivantes doivent être définies avant l'appel au constructeur ->new.

Définir la chaîne qui est incluse avant la balise ouvrante <html> :

$Pod::Simple::HTML::Doctype_decl = qq{<!DOCTYPE HTML PUBLIC "-//W3C//DTD HTML 4.01 Transitional//EN"
  "http://www.w3.org/TR/html4/loose.dtd">\n};

Définir le type de contenu dans la tête HTML : (par défaut ISO-8859-1)

$Pod::Simple::HTML::Content_decl =  q{<meta http-equiv="Content-Type" content="text/html; charset=UTF-8" >};

Définir la valeur qui sera intégrée dans les balises ouvrantes des balises F, C et du texte verbatim. F correspond à <em>, C correspond à <code>, le texte verbatim correspond à <pre> (Computerese vaut par défaut "")

$Pod::Simple::HTML::Computerese =  ' class="some_class_name';

html_css

html_javascript

title_prefix

title_postfix

html_header_before_title

Ceci inclut tout avant la balise ouvrante <title>, y compris le type de document et la balise ouvrante <title>. L'appel suivant la définira comme un fichier HTML simple :

$p->html_header_before_title('<html><head><title>');

top_anchor

Par défaut, Pod::Simple::HTML ajoute une ancre factice en haut du HTML. Vous pouvez la modifier en appelant

$p->top_anchor('<a name="zz" >');

html_h_level

Normalement, =head1 deviendra <h1>, =head2 deviendra <h2>, etc. L'utilisation de la méthode html_h_level modifiera ces niveaux en définissant le niveau h des balises =head1 :

$p->html_h_level(3);

Cela garantira que =head1 deviendra <h3> et =head2 deviendra <h4> etc...

index

Définissez-le à une valeur vraie si vous souhaitez qu'un index (en réalité une table des matières) soit ajouté en haut du HTML généré.

$p->index(1);

html_header_after_title

Inclut la balise fermante de </title> et le reste de la tête jusqu'à l'ouverture du corps

$p->html_header_after_title('</title>...</head><body id="my_id">');

html_footer

La toute fin du document :

$p->html_footer( qq[\n<!-- fin doc -->\n\n</body></html>\n] );

SOUS CLASSEMENT

Peut utiliser n'importe laquelle des méthodes décrites ci-dessus, mais pour une personnalisation plus poussée, il faut redéfinir certaines méthodes :

package My::Pod;
use strict;
use warnings;
use base 'Pod::Simple::HTML';
# doit retourner une chaîne d'URL telle que
# http://some.other.com/page.html
# #anchor_in_the_same_file
# /internal/ref.html
sub do_pod_link {
  # Objet My::Pod et objet Pod::Simple::PullParserStartToken
  my ($self, $link) = @_;
  say $link->tagname;          # sera L pour les liens
  say $link->attr('to');       #
  say $link->attr('type');     # sera toujours 'pod'
  say $link->attr('section');
  # Liens locaux à notre site web
  if ($link->tagname eq 'L' and $link->attr('type') eq 'pod') {
    my $to = $link->attr('to');
    if ($to =~ /^Padre::/) {
        $to =~ s{::}{/}g;
        return "/docs/Padre/$to.html";
    }
  }
  # tous les autres liens sont générés par la classe parente
  my $ret = $self->SUPER::do_pod_link($link);
  return $ret;
}
1;

Pendant ce temps, dans script.pl :

use My::Pod;
my $p = My::Pod->new;
my $html;
$p->output_string(\$html);
$p->parse_file('chemin/vers/Module/Name.pm');
open my $out, '>', 'out.html' or die;
print $out $html;
