NOM

POE::Resource::FileHandles - gestionnaire de descripteurs de fichier interne pour POE::Kernel

SYNTAXE

Il n'y a pas d'API publique.

DESCRIPTION

POE::Resource::FileHandles est une classe d'inclusion pour POE::Kernel. Elle fournit les fonctionnalités de bas niveau pour gérer les descripteurs de fichier. Elle est utilisée en interne par POE::Kernel, elle n'a donc pas d'interface publique.

VOIR AUSSI

Voir "I/O Watchers (Selects)" dans POE::Kernel pour l'API publique de surveillance d'E/S.

Voir "Resources" dans POE::Kernel pour des informations publiques sur les ressources POE.

Voir POE::Resource pour une discussion générale sur les ressources et les classes qui les gèrent.

BOGUES

POE surveille les E/S en se basant sur les descripteurs de fichier plutôt que sur les descripteurs de descripteurs, ce qui signifie qu'il peut y avoir des conflits entre son API et une boucle d'événements sous-jacente basée sur des descripteurs. Ce n'est généralement pas un problème, mais cela peut nécessiter une solution de contournement dans certains cas limites.
