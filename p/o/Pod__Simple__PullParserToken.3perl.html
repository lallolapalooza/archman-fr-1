Pod::Simple::PullParserToken(3perl) Guide du programmeur Perl Pod::Simple::PullParserToken(3perl)

NOM

Pod::Simple::PullParserToken -- jetons de Pod::Simple::PullParser

SYNTAXE

Étant donné un objet $parser de classe Pod::Simple::PullParser (ou une sous-classe)...

while(my $token = $parser->get_token) {
  $DEBUG and print STDERR "Jeton : ", $token->dump, "\n";
  if($token->is_start) {
    ...accès à $token->tagname, $token->attr, etc...
  } elsif($token->is_text) {
    ...accès à $token->text, $token->text_r, etc...
  } elsif($token->is_end) {
    ...accès à $token->tagname...
  }
}

(Voir aussi Pod::Simple::PullParser)

DESCRIPTION

Lorsque vous appelez $parser->get_token sur un objet Pod::Simple::PullParser, vous devriez obtenir un objet d'une sous-classe de Pod::Simple::PullParserToken.

Les sous-classes ajouteront des méthodes et hériteront également de ces méthodes :

$token->type
Ceci renvoie le type du jeton. Ce sera soit la chaîne de caractères "start", la chaîne "text", soit la chaîne "end".

Une fois que vous connaissez le type d'un objet, vous savez à quelle sous-classe il appartient, et donc quelles méthodes il prend en charge.

Oui, vous pourriez probablement faire la même chose avec du code comme $token->isa('Pod::Simple::PullParserEndToken'), mais ce n'est pas aussi joli que d'utiliser simplement $token->type, ou même les raccourcis suivants :

$token->is_start
Ceci est un raccourci pour "$token->type() eq "start""
$token->is_text
Ceci est un raccourci pour "$token->type() eq "text""
$token->is_end
Ceci est un raccourci pour "$token->type() eq "end""
$token->dump
Ceci renvoie une représentation sous forme de chaîne de caractères utile de cet objet. Ceci est utile pour le débogage, comme dans : 
while(my $token = $parser->get_token) {
  $DEBUG and print STDERR "Jeton : ", $token->dump, "\n";
  ...
}

VOIR AUSSI

Mes sous-classes : Pod::Simple::PullParserStartToken, Pod::Simple::PullParserTextToken, et Pod::Simple::PullParserEndToken.
