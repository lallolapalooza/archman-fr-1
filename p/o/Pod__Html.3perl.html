Pod::Html(3perl) Manuel du programmeur Perl Pod::Html(3perl)

NOM

Pod::Html - module pour convertir les fichiers au format pod en HTML

SYNOPIS

use Pod::Html;
pod2html([options]);

DESCRIPTION

Convertit les fichiers au format pod (voir perlpod) en format HTML. Il peut générer automatiquement des index et des références croisées, et conserve un cache des éléments qu'il sait référencer.

FONCTIONS

pod2html

pod2html("pod2html",
         "--podpath=lib:ext:pod:vms",
         "--podroot=/usr/src/perl",
         "--htmlroot=/perl/nmanual",
         "--recurse",
         "--infile=foo.pod",
         "--outfile=/perl/nmanual/foo.html");

pod2html prend les arguments suivants :

backlink
--backlink

Crée des liens de retour vers le début de la page pour chaque titre "head1". Par défaut, aucun lien de retour n'est généré.

cachedir
--cachedir=nom

Crée le répertoire de cache dans le répertoire spécifié.

css
--css=feuille_de_style

Spécifie l'URL d'une feuille de style en cascade. Désactive également toutes les attributions HTML/CSS "style" émises par défaut (pour éviter les conflits).

flush
--flush

Vide le répertoire de cache.

header
--header
--noheader

Crée des blocs d'en-tête et de pied de page contenant le texte de la section "NAME". Par défaut, aucun en-tête n'est généré.

help
--help

Affiche le message d'aide.

htmldir
--htmldir=nom

Définit le répertoire à partir duquel toutes les références croisées dans le fichier HTML résultant seront générées. Ne pas fournir cette valeur rend toutes les références absolues, car cette valeur indique la racine de l'arborescence des documents.

N'utilisez pas cette option et --htmlroot dans le même appel à pod2html ; elles sont mutuellement exclusives.

htmlroot
--htmlroot=nom

Définit l'URL de base pour les fichiers HTML. Lorsque des références croisées sont effectuées, l'URL sera préfixée par la valeur de htmlroot.

N'utilisez pas cette option si vous souhaitez des références relatives : utilisez --htmldir à la place.

Ne pas fournir ces deux options --htmlroot et --htmldir à pod2html ; elles sont mutuellement exclusives.

index
--index
--noindex

Génère un index en haut du fichier HTML. C'est le comportement par défaut.

infile
--infile=nom

Spécifie le fichier pod à convertir. L'entrée est prise depuis stdin si aucun infile n'est spécifié.

outfile
--outfile=nom

Spécifie le fichier HTML à créer. La sortie est envoyée à STDOUT si aucun outfile n'est spécifié.

poderrors
--poderrors
--nopoderrors

Inclut une section "POD ERRORS" dans l'outfile s'il y a eu des erreurs dans l'infile. Cette section est incluse par défaut.

podpath
--podpath=nom:...:nom

Spécifie quels sous-répertoires de podroot contiennent des fichiers pod dont les versions HTML peuvent être référencées par des liens croisés.

podroot
--podroot=nom

Spécifie le répertoire de base pour trouver les bibliothèques de pod. La valeur par défaut est le répertoire courant.

quiet
--quiet
--noquiet

Ne pas afficher les messages d'avertissement sans problème. Ces messages sont affichés par défaut. Cependant, ce n'est pas la même chose que le mode "verbose".

recurse
--recurse
--norecurse

Parcourt récursivement les sous-répertoires spécifiés dans podpath (comportement par défaut).

title
--title=titre

Spécifie le titre du fichier HTML résultant.

verbose
--verbose
--noverbose

Affiche les messages de progression. Par défaut, ils ne sont pas affichés.

Anciennes fonctions auxiliaires exportées

Avant perl-5.36, les trois fonctions suivantes étaient exportées par défaut ou sur demande depuis Pod::Html:

  • htmlify() (par défaut)
  • anchorify() (sur demande)
  • relativize_url() (sur demande)

La définition et la documentation de ces fonctions ont été déplacées vers Pod::Html::Util, accessible via "perldoc Pod::Html::Util".

Depuis perl-5.38, ces fonctions doivent être explicitement importées depuis Pod::Html::Util. Veuillez adapter votre code en conséquence.

ENVIRONNEMENT

Utilise $Config{pod2html} pour configurer les options par défaut.
