NOM

Pod::Simple::XMLOutStream -- transformer Pod en XML

SYNTAXE

perl -MPod::Simple::XMLOutStream -e \
 "exit Pod::Simple::XMLOutStream->filter(shift)->any_errata_seen" \
 thingy.pod

DESCRIPTION

Pod::Simple::XMLOutStream est une sous-classe de Pod::Simple qui analyse le Pod et le transforme en XML.

Pod::Simple::XMLOutStream hérite des méthodes de Pod::Simple.

VOIR AUSSI

Pod::Simple::DumpAsXML est assez similaire à cette classe ; voir sa documentation pour une discussion sur les différences.

Pod::Simple, Pod::Simple::DumpAsXML, Pod::SAX

Pod::Simple::Subclassing

Les anciennes bibliothèques (et potentiellement obsolètes) Pod::PXML, Pod::XML
