NOM

Pod::Perldoc::ToANSI - rendre le Pod avec des séquences d'échappement ANSI

SYNTAXE

perldoc -o ansi Nom::Module

DESCRIPTION

C'est une classe « plug-in » qui permet à Perldoc d'utiliser Pod::Text comme classe de formatage.

Elle prend en charge les options suivantes, qui sont expliquées dans Pod::Text : alt, indent, loose, quotes, sentence, width

Par exemple :

perldoc -o term -w indent:5 Nom::Module

MISE EN GARDE

Ce module pourrait être modifié pour utiliser une autre classe de formatage de texte à l'avenir, et cela pourrait changer les options prises en charge.

VOIR AUSSI

Pod::Text, Pod::Text::Color, Pod::Perldoc
