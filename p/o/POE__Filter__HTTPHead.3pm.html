POE::Filter::HTTPHead(3) Documentation Perl fournie par l'utilisateur POE::Filter::HTTPHead(3)

NOM

POE::Filter::HTTPHead - filtre les données sous forme d'objets HTTP::Response

VERSION

version 0.949

SYNOPSYS

$filter = POE::Filter::HTTPHead->new();
$arrayref_of_response_objects =
  $filter->get($arrayref_of_raw_chunks_from_driver);
$arrayref_of_leftovers = $filter->get_pending();

DESCRIPTION

Le filtre HTTPHead transforme les données en flux ayant le format approprié en objets HTTP::Response. Dans un monde entièrement POE, cela se situerait à l'autre extrémité d'une connexion en tant que POE::Filter::HTTPD.

new

Crée un nouveau filtre pour analyser les en-têtes HTTP. Ne prend aucun paramètre et retourne un nouvel objet POE::Filter::HTTPHead étincelant.

METHODES

Voir POE::Filter pour la documentation de l'API publique.

get_pending

Retourne les données non analysées en attente dans le tampon d'entrée de ce filtre. Il est utilisé par les objets POE::Wheel pour passer de manière transparente d'un filtre à l'autre.

Les détails peuvent être trouvés dans la documentation de POE::Filter.
