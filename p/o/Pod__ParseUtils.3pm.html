Pod::ParseUtils(3) Documentation Perl contribuée par l'utilisateur Pod::ParseUtils(3)

NOM

Pod::ParseUtils - Utilitaires pour l'analyse et la conversion POD

SYNOPIS

use Pod::ParseUtils;
my $list = new Pod::List;
my $link = Pod::Hyperlink->new('Pod::Parser');

DESCRIPTION

NOTE: Ce module est considéré comme obsolète ; les versions modernes de Perl (5.31.1 et supérieures) vont supprimer Pod-Parser du cœur et utiliser Pod::Simple pour toutes les opérations POD.

Pod::ParseUtils contient quelques packages utilitaires orientés objet pour l'analyse et le traitement des POD (c'est-à-dire pour les formateurs et traducteurs POD).

Pod::List

Pod::List peut être utilisé pour contenir des informations sur les listes POD (écrites avec =over ... =item ... =back) pour un traitement ultérieur. Les méthodes suivantes sont disponibles :

Pod::List->new()
Crée un nouvel objet liste. Les propriétés peuvent être spécifiées via une référence de table de hachage comme ceci : 
my $list = Pod::List->new({ -start => $., -indent => 4 });

Voir les méthodes/propriétés individuelles pour les détails.

$list->file()
Sans argument, récupère le nom du fichier dans lequel se trouve la liste. Ceci doit avoir été défini auparavant, soit en spécifiant -file dans la méthode new(), soit en appelant la méthode file() avec un argument scalaire.
$list->start()
Sans argument, récupère le numéro de ligne où la liste a commencé. Ceci doit avoir été défini auparavant, soit en spécifiant -start dans la méthode new(), soit en appelant la méthode start() avec un argument scalaire.
$list->indent()
Sans argument, récupère le niveau d'indentation de la liste tel que spécifié dans "=over n". Ceci doit avoir été défini auparavant, soit en spécifiant -indent dans la méthode new(), soit en appelant la méthode indent() avec un argument scalaire.
$list->type()
Sans argument, récupère le type de liste, qui peut être une valeur arbitraire, par exemple "OL", "UL", ... si l'on pense en termes HTML. Ceci doit avoir été défini auparavant, soit en spécifiant -type dans la méthode new(), soit en appelant la méthode type() avec un argument scalaire.
$list->rx()
Sans argument, récupère une expression régulière pour simplifier les chaînes d'éléments individuels une fois que le type de liste a été déterminé. Utilisation : Par exemple, lors de la conversion en HTML, on pourrait supprimer le numéro initial d'une liste ordonnée car "<OL>" imprime déjà les numéros lui-même. Ceci doit avoir été défini auparavant, soit en spécifiant -rx dans la méthode new(), soit en appelant la méthode rx() avec un argument scalaire.
$list->item()
Sans argument, récupère le tableau des éléments de cette liste. Les éléments peuvent être représentés par n'importe quel scalaire. Si un argument a été donné, il est ajouté à la liste des éléments.
$list->parent()
Sans argument, récupère des informations sur le parent contenant cette liste, qui est représenté par un scalaire arbitraire. Ceci doit avoir été défini auparavant, soit en spécifiant -parent dans la méthode new(), soit en appelant la méthode parent() avec un argument scalaire.
$list->tag()
Sans argument, récupère des informations sur la balise de liste, qui peut être n'importe quel scalaire. Ceci doit avoir été défini auparavant, soit en spécifiant -tag dans la méthode new(), soit en appelant la méthode tag() avec un argument scalaire.

Pod::Hyperlink

Pod::Hyperlink est une classe pour la manipulation des hyperliens POD. Utilisation :

my $link = Pod::Hyperlink->new('alternative text|page/"section in page"');

La classe Pod::Hyperlink est principalement conçue pour analyser le contenu de la séquence "L<...>", offrant une interface simple pour accéder aux différentes parties d'un hyperlien POD pour un traitement ultérieur. Elle peut également être utilisée pour construire des hyperliens.

Pod::Hyperlink->new()
La méthode new() peut soit recevoir un ensemble de paires clé/valeur, soit une seule valeur scalaire, à savoir le contenu d'une séquence "L<...>". Un objet de la classe "Pod::Hyperlink" est retourné. La valeur "undef" indique un échec, le message d'erreur est stocké dans $@.
$link->parse($string)
Cette méthode peut être utilisée pour (re)analyser un (nouvel) hyperlien, c'est-à-dire le contenu d'une séquence "L<...>". Le résultat est stocké dans l'objet courant. Les avertissements sont stockés dans la propriété warnings. Par exemple, les sections comme "L<open(2)>" sont dépréciées, car elles ne pointent pas vers des documents Perl. "L<DBI::foo(3p)>" est également incorrect, la section du manuel peut simplement être omise.
$link->markup($string)
Définit/récupère la valeur textuelle du lien. Cette chaîne contient des marqueurs spéciaux "P<>" et "Q<>" qui doivent être développés par le moteur d'expansion de séquences internes du traducteur pour mettre en évidence/activer l'hyperlien. Les détails doivent être implémentés dans le traducteur.
$link->text()
Cette méthode retourne la représentation textuelle de l'hyperlien telle que décrite ci-dessus, mais sans les marqueurs (lecture seule). Selon le type de lien, il s'agit de l'une des alternatives suivantes (les + et * dénotent les portions du texte qui sont mises en forme) : 
+perl+                    L<perl>
*$|* in +perlvar+         L<perlvar/$|>
*OPTIONS* in +perldoc+    L<perldoc/"OPTIONS">
*DESCRIPTION*             L<"DESCRIPTION">
$link->warning()
Après l'analyse, cette méthode retourne tous les avertissements rencontrés pendant le processus d'analyse.
$link->file()
$link->line()
Simples emplacements pour stocker des informations sur la ligne et le fichier où le lien a été rencontré. Doivent être remplis manuellement.
$link->page()
Cette méthode définit ou retourne la page POD vers laquelle ce lien pointe.
$link->node()
Comme ci-dessus, mais le texte du nœud de destination du lien.
$link->alttext()
Définit ou retourne un texte alternatif spécifié dans le lien.
$link->type()
Le type de nœud, soit "section", soit "item". En tant que type non officiel, il existe également "hyperlink", dérivé par exemple de "Lhttp://perl.com"
$link->link()
Retourne le lien sous forme de contenu de "L<>". Réciproque à parse().

Pod::Cache

Pod::Cache contient des informations sur un ensemble de documents POD, en particulier les nœuds pour les hyperliens. Les méthodes suivantes sont disponibles :

Pod::Cache->new()
Crée un nouvel objet cache. Cet objet peut contenir un nombre arbitraire de documents POD de classe Pod::Cache::Item.
$cache->item()
Ajoute un nouvel élément au cache. Sans argument, cette méthode retourne une liste de tous les éléments du cache.
$cache->find_page($name)
Recherche un document POD nommé $name dans le cache. Retourne une référence vers l'objet Pod::Cache::Item correspondant ou undef s'il n'est pas trouvé.

Pod::Cache::Item

Pod::Cache::Item contient des informations sur des documents POD individuels, qui peuvent être groupés dans un objet Pod::Cache. Il est destiné à contenir des informations sur les nœuds hyperliens des documents POD. Les méthodes suivantes sont disponibles :

Pod::Cache::Item->new()
Crée un nouvel objet.
$cacheitem->page()
Définit/récupère le nom du document POD (par exemple "Pod::Parser").
$cacheitem->description()
Définit/récupère la courte description POD telle que trouvée dans la section "=head1 NAME&q
