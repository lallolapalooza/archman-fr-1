NOM

Pod::Simple::PullParserStartToken -- jetons de début de Pod::Simple::PullParser

SYNTAXE

(Voir Pod::Simple::PullParser)

DESCRIPTION

Lorsque vous appelez $parser->get_token sur un objet Pod::Simple::PullParser, vous pouvez obtenir un objet de cette classe.

Ceci est une sous-classe de Pod::Simple::PullParserToken et hérite de toutes ses méthodes, et ajoute les méthodes suivantes :

$token->tagname
Ceci retourne le nom de la balise pour cet objet jeton de début. Par exemple, l'analyse d'une ligne "=head1 ..." donnera un jeton de début avec le nom de balise "head1", des jeton(s) pour son contenu, puis un jeton de fin avec le nom de balise "head1".
$token->tagname(chaînedecaractères)
Ceci change le nom de la balise pour cet objet jeton de début. Vous n'aurez probablement pas besoin de le faire.
$token->tag(...)
Un raccourci pour $token->tagname(...)
$token->is_tag(chaînedecaractères) ou $token->is_tagname(chaînedecaractères)
Ce sont des raccourcis pour "$token->tag() eq chaînedecaractères"
$token->attr(nomattribut)
Ceci retourne la valeur de l'attribut nomattribut pour cet objet jeton de début, ou undef.

Par exemple, l'analyse d'un lien L<Foo/"Bar"> produira un jeton de début avec un attribut "to" ayant la valeur "Foo", un attribut "type" ayant la valeur "pod", et un attribut "section" ayant la valeur "Bar".

$token->attr(nomattribut, nouvellevaleur)
Ceci définit l'attribut nomattribut pour cet objet jeton de début à nouvellevaleur. Vous n'aurez probablement pas besoin de le faire.
$token->attr_hash
Ceci retourne le hashref qui est l'ensemble des attributs pour ce jeton de début. Ceci est utile si (par exemple) vous voulez demander quels sont tous les attributs -- vous pouvez simplement faire "keys %{$token->attr_hash}"

Il est peu probable que vous ayez besoin de construire vous-même un objet de cette classe, mais si vous le souhaitez, appelez "Pod::Simple::PullParserStartToken->new( nomdelabaleise, hashdesattributs )"
