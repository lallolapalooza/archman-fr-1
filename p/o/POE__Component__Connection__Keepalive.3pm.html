POE::Component::Connection::Keepalive(3) Documentation Perl fournie par l'utilisateur POE::Component::Connection::Keepalive(3)

NOM

POE::Component::Connection::Keepalive - un wrapper de roue autour d'un socket maintenu en vie

VERSION

version 0.272

SYNOPSIS

Voir le SYNOPSIS de POE::Component::Client::Keepalive pour un
exemple complet et fonctionnel.
my $connection = $response->{connection};
$heap->{connection} = $connection;
$connection->start( InputEvent => "got_input" );
delete $heap->{connection};  # Quand vous n'en avez plus besoin.

DESCRIPTION

POE::Component::Connection::Keepalive est une classe d'aide pour POE::Component::Client::Keepalive. Elle enveloppe des sockets gérés, offrant quelques fonctionnalités supplémentaires.

Les objets Connection libèrent leurs sockets sous-jacents lorsqu'ils sont DÉTRUITS. Cela élimine le besoin de libérer explicitement les sockets lorsque vous avez terminé avec eux.

Les objets Connection gèrent des objets POE::Wheel::ReadWrite en interne, économisant un peu d'effort.

new
Crée une nouvelle instance de POE::Component::Connection::Keepalive. Elle accepte deux paramètres : un descripteur de socket (socket) et une référence vers un objet POE::Component::Client::Keepalive pour gérer le socket lorsque la connexion est détruite. 
my $conn = POE::Component::Connection::Keepalive->new(
  socket  => $socket_handle,
  manager => $poe_component_client_keepalive,
);

new() est généralement appelé par un objet POE::Component::Client::Keepalive.

start
Démarre un objet POE::Wheel::ReadWrite. Tous les paramètres sauf Handle pour start() sont passés directement au constructeur de POE::Wheel::ReadWrite. Handle est fourni par l'objet connection. start() renvoie une référence vers le nouvel objet POE::Wheel::ReadWrite, mais il n'est pas nécessaire de sauvegarder une copie de cette roue. L'objet connection garde une copie de la référence en interne, de sorte que la roue persistera tant que la connection durera. L'objet POE::Wheel::ReadWrite sera DÉTRUIT lorsque l'objet connection le sera. 
# Connexion asynchrone depuis Client::Keepalive.
sub handle_connection {
  my $connection_info = $_[ARG0];
  $_[HEAP]->{connection} = $connection_info->{connection};
  $heap->{connection}->start(
    InputEvent => "got_input",
    ErrorEvent => "got_error",
  );
}
# Arrête la connexion (et la roue) lorsqu'une erreur se produit.
sub handle_error {
  delete $_[HEAP]->{connection};
}
wheel
Renvoie une référence vers l'objet POE::Wheel::ReadWrite interne, afin que des méthodes puissent être appelées dessus. 
$heap->{connection}->wheel()->pause_input();
close
Ferme la connexion immédiatement. Appelle également shutdown_input() et shutdown_output() sur la roue.
