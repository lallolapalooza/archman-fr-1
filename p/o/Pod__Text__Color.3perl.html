Pod::Text::Color(3perl) Guide du programmeur Perl Pod::Text::Color(3perl)

NOM

Pod::Text::Color - Convertit les données POD en texte formaté en couleur ASCII

SYNOPIS

use Pod::Text::Color;
my $parser = Pod::Text::Color->new (sentence => 0, width => 78);
# Lit le POD depuis STDIN et écrit sur STDOUT.
$parser->parse_from_filehandle;
# Lit le POD depuis file.pod et écrit sur file.txt.
$parser->parse_from_file ('file.pod', 'file.txt');

DESCRIPTION

Pod::Text::Color est une sous-classe simple de Pod::Text qui met en évidence le texte de sortie en utilisant des séquences d'échappement de couleur ANSI. Outre la couleur, il fonctionne à tous égards comme Pod::Text. Voir Pod::Text pour les détails et les options disponibles.

Term::ANSIColor est utilisé pour obtenir les couleurs et doit donc être installé pour utiliser ce module.

COMPATIBILITÉ

Pod::Text::Color 0.05 (basé sur Pod::Parser) était la première version de ce module incluse avec Perl, dans Perl 5.6.0.

L'API actuelle basée sur Pod::Simple a été ajoutée dans Pod::Text::Color 2.00. Pod::Text::Color 2.01 a été inclus dans Perl 5.9.3, la première version de Perl à intégrer ces changements.

Plusieurs problèmes d'enroulement et de longueur de ligne ont été corrigés aussi récemment que Pod::Text::Color 6.0.0.

Ce module hérite de son API et de la plupart de ses comportements de Pod::Text, de sorte que les détails de "COMPATIBILITÉ" dans Pod::Text s'appliquent également. Pod::Text et Pod::Text::Color ont la même version de module depuis 4.00, incluse dans Perl 5.23.7. (Ils divergent malheureusement de manière déroutante avant cela.)

ATTENTION

L'enroulement des lignes se fait uniquement aux espaces et tabulations ASCII, plutôt que d'utiliser un algorithme d'enroulement de ligne correct et sensible à Unicode.
