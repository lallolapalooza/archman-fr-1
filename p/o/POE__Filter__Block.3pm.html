NOM

POE::Filter::Block - traduisez des données entre des flux et des blocs

SYNOPSIS

#!perl
use warnings;
use strict;
use POE::Filter::Block;
my $filter = POE::Filter::Block->new( BlockSize => 8 );
# Affiche trois lignes : abcdefgh, ijklmnop, qrstuvwx.
# Les octets "y" et "z" restent dans le tampon et attendent l'achèvement du
# prochain bloc de 8 octets.
$filter->get_one_start([ "abcdefghijklmnopqrstuvwxyz" ]);
while (1) {
  my $block = $filter->get_one();
  last unless @$block;
  print $block->[0], "\n";
}
# Affiche une ligne : yz123456
$filter->get_one_start([ "123456" ]);
while (1) {
  my $block = $filter->get_one();
  last unless @$block;
  print $block->[0], "\n";
}

DESCRIPTION

POE::Filter::Block traduit des données entre des flux série et des blocs. Il peut gérer des blocs de longueur fixe et des blocs préfixés par leur longueur, et il peut être étendu pour gérer d'autres types de blocs.

Les blocs de longueur fixe sont utilisés lorsque le constructeur de Block est appelé avec une valeur BlockSize. Sinon, le filtre Block utilise des blocs préfixés par leur longueur.

Les utilisateurs qui spécifient des tailles de bloc inférieures à un méritent ce qui leur arrive.

En mode de longueur variable, un paramètre LengthCodec peut être spécifié. La valeur LengthCodec doit être une référence à une liste de deux fonctions : l'encodeur de longueur et le décodeur de longueur :

LengthCodec => [ \&encoder, \&decoder ]

L'encodeur prend une référence à un tampon et lui ajoute sa longueur en préfixe. L'encodeur par défaut ajoute la représentation ASCII de la longueur du tampon et un octet chr(0) pour séparer la longueur des données réelles :

sub _default_encoder {
  my $stuff = shift;
  substr($$stuff, 0, 0) = length($$stuff) . "\0";
  return;
}

Le décodeur correspondant renvoie la longueur du bloc après l'avoir retirée, ainsi que le séparateur, du tampon. Il ne renvoie rien si aucune longueur ne peut être déterminée.

sub _default_decoder {
  my $stuff = shift;
  unless ($$stuff =~ s/^(\d+)\0//s) {
    warn length($1), " strange bytes removed from stream"
      if $$stuff =~ s/^(\D+)//s;
    return;
  }
  return $1;
}

Ce filtre conserve les blocs incomplets jusqu'à ce qu'ils soient complétés dans un tampon de cadrage. Pour contrôler l'utilisation de la mémoire, une taille maximale de tampon de cadrage est imposée. Cette taille maximale défaut à 512 Mo (512*1024*1024 octets). Vous pouvez modifier cette limite de taille avec le paramètre "MaxBuffer".

MaxBuffer => 1099511627776  # Un téraoctet !

La taille de chaque bloc individuel est également limitée. Par défaut, chaque bloc ne peut pas dépasser 64 Mo. Vous pouvez modifier cette limite de taille avec le paramètre "MaxLength".

MaxLength => 10             # petits blocs

N'oubliez pas que MaxBuffer doit être plus grand que MaxLength. De plus, il doit avoir de la place pour le préfixe de longueur.

Si la contrainte "MaxLength" ou "MaxBuffer" est dépassée, "POE::Filter::Bock" lèvera une exception.

MÉTHODES PUBLIQUES DU FILTRE

POE::Filter::Block n'a pas de méthodes publiques supplémentaires.

BOGUES

La méthode put() ne vérifie pas les tailles de bloc.
