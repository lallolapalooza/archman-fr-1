POE::Component::Client::HTTP::RequestFactory(3) Documentation Perl fournie par l'utilisateur POE::Component::Client::HTTP::RequestFactory(3)

NOM

POE::Component::Client::HTTP::RequestFactory - un objet de fabrique de requêtes HTTP

VERSION

version 0.949

SYNOPSIS

# Utilisé en interne par POE::Component::Client::HTTP

CONSTRUCTEUR

new

Crée un nouvel objet de fabrique de requêtes. Il attend ses paramètres sous forme de hashref.

Les paramètres suivants sont acceptés. Ils sont expliqués en détail dans POE::Component::Client::HTTP.

  • Agent
  • MaxSize
  • Streaming
  • Protocol
  • From
  • CookieJar
  • NoProxy
  • Proxy
  • FollowRedirects
  • Timeout

MÉTHODES

timeout [$timeout]

Méthode qui permet de consulter et/ou modifier la valeur de temporisation pour les requêtes créées par cette fabrique.

is_streaming

Accesseur du paramètre Streaming

agent

Accesseur du paramètre Agent

from

getter/setter pour le paramètre From

create_request

Crée une nouvelle POE::Component::Client::HTTP::Request

max_response_size

Méthode pour récupérer la taille maximale d'une réponse, telle que définie par le paramètre "MaxSize" de la méthode spawn() de Client::HTTP.

block_size

Accesseur du paramètre Streaming

frob_cookies $response

Stocke les cookies de la réponse HTTP::Response passée dans notre pot de cookies.

max_redirect_count [$count]

Fonction pour obtenir/définir le nombre maximum de redirections à suivre automatiquement. Ceci vous permet de récupérer ou de modifier la valeur que vous avez passée avec le paramètre FollowRedirects à la méthode "spawn" de Client::HTTP.

parse_proxy $proxy

Cette méthode statique est utilisée pour analyser les proxies. Le paramètre $proxy peut être une référence de tableau comme [hôte, port] ou une chaîne séparée par des virgules comme "http://1.2.3.4:80/,http://2.3.4.5:80/".

parse_proxy() retourne une référence de tableau de tuples à deux éléments (également des références de tableau), contenant chacun un hôte et un port :

[ [ host1, port1 ],
  [ host2, port2 ],
  ...
]
