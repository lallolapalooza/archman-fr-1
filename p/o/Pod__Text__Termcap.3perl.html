Pod::Text::Termcap(3perl) Guide de référence du programmeur Perl Pod::Text::Termcap(3perl)

NOM

Pod::Text::Termcap - Convertit les données POD en texte ASCII avec des codes de mise en forme

SYNOPIS

use Pod::Text::Termcap;
my $parser = Pod::Text::Termcap->new (sentence => 0, width => 78);
# Lit le POD depuis STDIN et écrit sur STDOUT.
$parser->parse_from_filehandle;
# Lit le POD depuis file.pod et écrit sur file.txt.
$parser->parse_from_file ('file.pod', 'file.txt');

DESCRIPTION

Pod::Text::Termcap est une sous-classe simple de Pod::Text qui met en évidence le texte de sortie en utilisant les séquences d'échappement termcap correctes pour le terminal actuel. En dehors des codes de format, il fonctionne de toutes les manières comme Pod::Text. Voir Pod::Text pour les détails et les options disponibles.

Ce module utilise Term::Cap pour trouver les paramètres du terminal. Voir la documentation de ce module pour savoir comment il trouve les informations de la base de données des terminaux et comment remplacer ce comportement si nécessaire. S'il ne parvient pas à trouver les chaînes de contrôle pour la mise en forme en gras et en souligné, cette mise en forme est ignorée, ce qui produit la même sortie que Pod::Text.

COMPATIBILITÉ

Pod::Text::Termcap 0.04 (basé sur Pod::Parser) a été la première version de ce module incluse avec Perl, dans Perl 5.6.0.

L'API actuelle basée sur Pod::Simple a été ajoutée dans Pod::Text::Termcap 2.00. Pod::Text::Termcap 2.01 a été inclus dans Perl 5.9.3, la première version de Perl à intégrer ces changements.

Pod::Text::Termcap 4.13 a cessé de définir la variable d'environnement TERMPATH lors du chargement du module. Elle a également cessé de revenir aux séquences d'échappement VT100 si Term::Cap n'était pas en mesure de trouver des séquences d'échappement utilisables, produisant plutôt une sortie non formatée pour de meilleurs résultats sur les terminaux basiques. La version suivante à être intégrée à Perl, 4.14, a été incluse dans Perl 5.31.8.

Plusieurs problèmes de retour à la ligne et de longueur de ligne ont été corrigés aussi récemment que Pod::Text::Termcap 6.0.0.

Ce module hérite de son API et de la plupart de ses comportements de Pod::Text, de sorte que les détails dans "COMPATIBILITÉ" dans Pod::Text s'appliquent également. Pod::Text et Pod::Text::Termcap ont eu la même version de module depuis 4.00, incluse dans Perl 5.23.7. (Ils divergent malheureusement de manière confuse avant cela.)

AVERTISSEMENTS

Le retour à la ligne n'est effectué qu'aux espaces ASCII et tabulations, plutôt que d'utiliser un algorithme de retour à la ligne correct et sensible à l'Unicode.
