NOM

Pod::POM::View::Text - créer des vues textuelles des objets POM

DESCRIPTION

Vue textuelle d'un modèle d'objet Pod (Pod Object Model).

"view_item($self, $item)"
"view_for($self, $for)"
"view_begin($self, $begin)"
"view_textblock($self, $textblock)"
"view_verbatim($self, $verbatim)"
"view_meta($self, $meta)"
"view_seq_bold($self, $text)"
Retourne le texte d'une séquence "B<>" en 'gras' (c'est-à-dire entouré d'astérisques, comme *ceci*).
"view_seq_italic($self, $text)"
Retourne le texte d'une séquence "I<>" en 'italique' (c'est-à-dire entouré d'underscores, comme _ceci_).
"view_seq_code($self, $text)"
"view_seq_file($self, $text)"
"view_seq_entity($self, $text)"
"view_seq_index($self, $text)"
Retourne une chaîne vide. Les séquences d'index sont supprimées dans la vue textuelle.
