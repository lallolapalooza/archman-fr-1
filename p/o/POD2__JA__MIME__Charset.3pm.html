NOM

MIME::Charset~[ja] - Informations sur les jeux de caractères pour MIME

SYNOPSIS

use MIME::Charset:
$charset = MIME::Charset->new("euc-jp");

Récupérer les informations sur le jeu de caractères :

$benc = $charset->body_encoding; # Ex: "Q"
$cset = $charset->as_string; # Ex: "US-ASCII"
$henc = $charset->header_encoding; # Ex: "S"
$cset = $charset->output_charset; # Ex: "ISO-2022-JP"

Convertir les données texte :

($text, $charset, $encoding) =
    $charset->header_encode(
       "\xc9\xc2\xc5\xaa\xc0\xde\xc3\xef\xc5\xaa".
       "\xc7\xd1\xca\xaa\xbd\xd0\xce\xcf\xb4\xef",
       Charset => 'euc-jp');
# ... renvoie (<chaîne transformée>, "ISO-2022-JP", "B") par exemple.
($text, $charset, $encoding) =
    $charset->body_encode(
        "Collectioneur path\xe9tiquement ",
        Charset => 'latin1');
# ... renvoie (<chaîne d'origine>, "ISO-8859-1", "QUOTED-PRINTABLE") par exemple.
$len = $charset->encoded_header_len(
    "Perl\xe8\xa8\x80\xe8\xaa\x9e",
    Charset => "utf-8",
    Encoding => "b");
# ... renvoie 28 par exemple.

Manipulation des valeurs prédéfinies du module :

MIME::Charset::alias("csEUCKR", "euc-kr");
MIME::Charset::default("iso-8859-1");
MIME::Charset::fallback("us-ascii");

Fonctions non OO (à déprécier bientôt) :

use MIME::Charset qw(:info);
$benc = body_encoding("iso-8859-2"); # "Q"
$cset = canonical_charset("ANSI X3.4-1968"); # "US-ASCII"
$henc = header_encoding("utf-8"); # "S"
$cset = output_charset("shift_jis"); # "ISO-2022-JP"
use MIME::Charset qw(:trans);
($text, $charset, $encoding) =
    header_encode(
       "\xc9\xc2\xc5\xaa\xc0\xde\xc3\xef\xc5\xaa".
       "\xc7\xd1\xca\xaa\xbd\xd0\xce\xcf\xb4\xef",
       "euc-jp");
# ... renvoie (<texte transformé>, "ISO-2022-JP", "B").
($text, $charset, $encoding) =
    body_encode(
        "Collectioneur path\xe9tiquement ".
        "\xe9clectique de d\xe9chets",
        "latin1");
# ... renvoie (<texte original>, "ISO-8859-1", "QUOTED-PRINTABLE").
$len = encoded_header_len(
    "Perl\xe8\xa8\x80\xe8\xaa\x9e", "b", "utf-8"); # 28

DESCRIPTION

MIME::Charset fournit des informations sur les jeux de caractères utilisés pour les messages MIME sur Internet.

Définitions

Un jeu de caractères est un terme MIME désignant une méthode de conversion d'une séquence d'octets en une séquence de caractères. Il inclut les concepts à la fois de "Character Collection Set" (CCS) de l'ISO/IEC et de "Character Encoding Scheme" (CES).

Un encodage désigne une méthode de représentation des données du corps du message ou des en-têtes du message sous forme de séquence de caractères US-ASCII imprimables. Cela diffère de l'encodage de l'en-tête du message.

Constructeur

$charset = MIME::Charset->new([CHARSET [, OPTS]])
Crée et renvoie un objet jeu de caractères.

OPTS peut spécifier les options suivantes. NOTE: Lorsque la prise en charge Unicode/multioctet n'est pas valide (voir "USE_ENCODE"), la conversion n'est pas effectuée, et les options suivantes n'ont aucun effet.

Mapping => MAPTYPE
Indique s'il faut étendre la cartographie pour le nom du jeu de caractères. "EXTENDED" utilise des cartographies étendues. "STANDARD" utilise des cartographies strictes et normalisées. La valeur par défaut est "EXTENDED".

Récupération d'informations sur le jeu de caractères

$charset->body_encoding
body_encoding CHARSET
Récupère l'encodage de transfert recommandé pour le corps du message pour le jeu de caractères CHARSET.

Les valeurs renvoyées sont "B" (BASE64), "Q" (QUOTED-PRINTABLE), "S" (l'un ou l'autre, plutôt court), ou "undef" (aucun encodage de transfert recommandé — 7BIT ou 8BIT). Cela peut différer de l'encodage de l'en-tête du message.

$charset->as_string
canonical_charset CHARSET
Récupère le nom canonique du jeu de caractères.
$charset->decoder
Renvoie un objet "Encode::Encoding" à utiliser pour décoder le jeu de caractères en Unicode. Si le jeu de caractères n'est pas spécifié ou s'il s'agit d'un jeu de caractères inconnu du module, renvoie undef.
$charset->dup
Duplique l'objet jeu de caractères.
$charset->encode
encoder CHARSET
Renvoie un objet "Encode::Encoding" pour encoder le jeu de caractères en Unicode. Renvoie undef si le jeu de caractères n'est pas spécifié ou s'il est inconnu du module.
$charset->fallback
Renvoie le jeu de caractères de secours (celui utilisé si la conversion échoue).
fallback_set CHARSET
Définit le jeu de caractères de secours.
$charset->header_encoding
header_encoding CHARSET
Récupère l'encodage de transfert recommandé pour les en-têtes MIME pour le jeu de caractères CHARSET.

Les valeurs renvoyées sont "B" (Base64), "Q" (Quoted-Printable), ou "S" (ASCII strict, sans encodage).

$charset->name
Renvoie le nom original passé au constructeur.
$charset->output_charset
output_charset CHARSET
Récupère le jeu de caractères de sortie recommandé pour les en-têtes MIME.
$charset->set_encoder
Définit le jeu de caractères à utiliser pour les encodages/décodages. Peut être un nom de jeu de caractères, ou un objet qui a les méthodes encode et decode.
$charset->use_encode(BOOLEAN)
Si BOOLEAN est vrai, utilise le module Encode pour les conversions. Si faux, n'utilise pas le module Encode. Ceci est activé par défaut si le module Encode est installé.

MIME::CHARSET

MIME-CHARSET -Charset determination for MIME

DESCRIPTION

This module guesses character set names for MIME.

If a charset is given, its properties are determined. If not, properties are unchanged.

In any case, the current properties of the charset are returned as a list of 3 elements (HEADERENC, BODYENC, ENCCHARSET).

HEADERENC is the suggested encoding for the message header. It can specify "B", "Q", "S" (whichever is shorter), or "undef" (no encoding needed).

BODYENC is the suggested transfer encoding for the message body. It can specify "B", "Q", "S" (whichever is shorter), or "undef" (no transfer encoding needed).

ENCCHARSET is the character set name recommended for use when exchanging data with the internet, by specifying a certain MIME charset. If exchange is not necessary (or the module doesn't know a suitable charset) then ENCCHARSET is "undef".

NOTE: In future versions of this function, it may be possible to add mandatory arguments (for example, regarding character width, line break handling, etc.). Therefore, the return format may change. To get individual properties, you should use "header_encoding", "body_encoding", and "output_charset".

CONSTANTS

USE_ENCODE
Flag for Unicode/multibyte compatibility. When Unicode and multibyte compatibility is enabled, an empty string is set as the character string. Currently, this flag is empty in Perl 5.7.3 and later, and an empty string in earlier Perl versions.

ERROR HANDLING

For the "body_encode" and "header_encode" "Replacement" options, the following can be specified:

"DEFAULT"
Replaces invalid characters with replacement characters. For character sets based on UCM, <subchar> may be used as the replacement character.
"FALLBACK"
Uses a fallback character set to perform the "DEFAULT" method (see "fallback"). If the fallback character set is undefined and a conversion error occurs, the code will output an error message and die. If the fallback character set is defined, and a conversion error occurs, the code will output an error message and die.
"CROAK"
The code will output an error message and die immediately. However, if an error occurs that does not cause death, it can be caught by eval{} and the fatal error can be prevented. The same applies to "STRICT".
"PERLQQ"
"HTMLCREF"
"XMLCREF"
Uses the "FB_PERLQQ", "FB_HTMLCREF", or "FB_XMLCREF" methods defined in the Encode module.
A number
Numbers can also be specified. See "Handling Malformed Data" in Encode for details.

If an error handling method is not specified, or if an error handling method other than those listed above is specified, it is assumed to be "DEFAULT".

CONFIGURATION FILE

The default values for the parameters in the options can be changed by modifying the MIME/Charset/Defaults.pm configuration file. Please read MIME/Charset/Defaults.pm.sample for details.

See the $VERSION variable.

NOM

MIME::Charset - Déterminer les jeux de caractères MIME.

SYNOPSIS

    use MIME::Charset;

    my $charset = MIME::Charset->new("EUC-JP");
    print $charset->mime_name;        # "euc-jp"
    print $charset->description;      # "Japanese, EUC"
    print $charset->iana_name;        # "EUC-JP"

    my $charset = MIME::Charset->new("Shift_JIS");
    print $charset->mime_name;        # "shift_jis"
    print $charset->description;      # "Japanese, Shift JIS"
    print $charset->iana_name;        # "Shift_JIS"

    my $charset = MIME::Charset->new("ISO-2022-JP");
    print $charset->mime_name;        # "iso-2022-jp"
    print $charset->description;      # "Japanese, JIS X 0201"
    print $charset->iana_name;        # "ISO-2022-JP"

    my $charset = MIME::Charset->new("utf8");
    print $charset->mime_name;        # "utf-8"
    print $charset->description;      # "UTF-8"
    print $charset->iana_name;        # "UTF-8"

DESCRIPTION

Le module MIME::Charset fournit une interface pour interroger le Registre des jeux de caractères IANA. Il peut être utilisé pour trouver des informations sur les jeux de caractères connus.

La liste des jeux de caractères est stockée dans un fichier de données qui est installé avec le module.
