NOM

Pod::Simple::RTF -- formater Pod en RTF

SYNOPSIS

perl -MPod::Simple::RTF -e \
 "exit Pod::Simple::RTF->filter(shift)->any_errata_seen" \
 thingy.pod > thingy.rtf

DESCRIPTION

Cette classe est un formateur qui prend du Pod et le rend en RTF, utile pour la visualisation/l'impression dans MSWord, WordPad/write.exe, TextEdit, etc.

C'est une sous-classe de Pod::Simple et hérite de toutes ses méthodes.

ATTRIBUTS DE CONTRÔLE DE FORMATAGE

Vous pouvez définir ces attributs sur l'objet analyseur avant d'appeler "parse_file" (ou une méthode similaire) dessus :

$parser->head1_halfpoint_size( entier_demi-points );
$parser->head2_halfpoint_size( entier_demi-points );
$parser->head3_halfpoint_size( entier_demi-points );
$parser->head4_halfpoint_size( entier_demi-points );
Ces méthodes définissent la taille (en demi-points, par exemple 52 pour 26 points) à laquelle ces niveaux de titre apparaîtront.
$parser->codeblock_halfpoint_size( entier_demi-points );
Cette méthode définit la taille (en demi-points, par exemple 21 pour 10,5 points) à laquelle les blocs de code (« sections verbatim ») apparaîtront.
$parser->header_halfpoint_size( entier_demi-points );
Cette méthode définit la taille (en demi-points, par exemple 15 pour 7,5 points) dans laquelle l'en-tête de chaque page apparaîtra. L'en-tête est généralement juste « nom_module p. numéro_page ».
$parser->normal_halfpoint_size( entier_demi-points );
Cette méthode définit la taille (en demi-points, par exemple 26 pour 13 points) à laquelle le texte normal en paragraphes apparaîtra.
$parser->no_proofing_exemptions( vrai_ou_faux );
Définissez cette valeur sur vrai si vous ne voulez pas que le formateur essaie d'ajouter un code caché sur tous les symboles Perl (au mieux de ses capacités) qui les étiquète comme n'étant pas en anglais, et donc ne valant pas la peine d'être vérifiés par un correcteur orthographique.
$parser->doc_lang( code_langue_décimal_microsoft )
Ceci définit le code de langue avec lequel ce document sera étiqueté. Par défaut, il s'agit de la valeur de la variable d'environnement "RTFDEFLANG", ou si elle n'est pas définie, alors la valeur 1033 (pour l'anglais américain).

Définir cela de manière appropriée est utile si vous voulez utiliser le RTF pour la vérification orthographique, et/ou si vous voulez qu'il y ait une césure correcte.

Voici quelques valeurs notables :

1033  Anglais américain
2057  Anglais britannique
3081  Anglais australien
4105  Anglais canadien
1034  Espagnol (Espagne)
2058  Espagnol (Mexique)
1031  Allemand (Allemagne)
1036  Français (France)
3084  Français (Canada)
1035  Finnois
1044  Norvégien (Bokmal)
2068  Norvégien (Nynorsk)

Si vous êtes particulièrement intéressé par la personnalisation encore plus poussée de la sortie de ce module, consultez le code source et/ou écrivez-moi.
