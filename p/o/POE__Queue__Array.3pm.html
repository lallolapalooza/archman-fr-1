NOM

POE::Queue::Array - une file d'attente prioritaire basée sur un tableau haute performance

SYNOPIS

Voir POE::Queue.

DESCRIPTION

Cette classe est une implémentation de l'interface abstraite POE::Queue. En tant que telle, sa documentation se trouve dans POE::Queue.

POE::Queue::Array implémente une file d'attente prioritaire en utilisant des tableaux Perl, `splice`, et une application abondante d'astuces.

Malgré son nom, POE::Queue::Array peut être utilisé comme une file d'attente prioritaire autonome sans le reste de POE.

VOIR AUSSI
