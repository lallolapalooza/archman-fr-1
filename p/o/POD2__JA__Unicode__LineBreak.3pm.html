NOM

Unicode::LineBreak~[ja] - Algorithme de césure de ligne Unicode UAX #14

SYNOPIS

use Unicode::LineBreak;
$lb = Unicode::LineBreak->new();
$broken = $lb->break($string);

DESCRIPTION

Unicode::LineBreak implémente l'algorithme de césure de ligne Unicode décrit dans l'Annexe 14 [UAX #14] de la norme Unicode. Lors de la détermination des positions de césure, il prend également en compte les propriétés East_Asian_Width définies dans l'Annexe 11 [UAX #11].

Terminologie

Il est pratique d'utiliser les termes suivants :

Césure obligatoire (mandatory break) : C'est une césure définie par les règles de base et effectuée obligatoirement, quelles que soient les caractères environnants. Césure conditionnelle (break) : C'est une césure autorisée par les règles de base et qui est effectuée uniquement lorsque l'utilisateur le décide. L'UAX #14 distingue les césures directes (direct break) des césures indirectes (indirect break) parmi les césures conditionnelles.

Caractères alphabétiques (alphabetic characters) : Ce sont des caractères qui, généralement, n'offrent pas de possibilité de césure à leur environnement et ne peuvent pas être coupés au sein de la même séquence de caractères. Caractères idéographiques (ideographic characters) : Ce sont des caractères qui, généralement, peuvent être coupés avant ou après eux. L'UAX #14 classe la plupart des caractères alphabétiques comme AL et la plupart des caractères idéographiques comme ID (ces termes, du point de vue de la linguistique, sont quelque peu imprécis). Pour de nombreux systèmes de caractères, comme les positions de césure ne sont pas claires pour chaque caractère, des méthodes heuristiques sont utilisées en fonction du dictionnaire.

La largeur (width) d'une séquence de caractères n'est pas liée au nombre de caractères qu'elle contient. Chaque caractère occupe soit 2 carreaux, 1 carreau, ou 0 carreau, déterminé par s'il est large (wide), étroit (narrow), ou non espacé (nonspacing). Selon la famille de caractères, les caractères peuvent occuper des largeurs variées. Avec la personnalisation, les caractères peuvent avoir une gamme plus étendue de largeurs.

PERSONNALISATION

Formatage des lignes

Lors de la spécification d'une référence à un sous-appel pour l'option "Format", le sous-appel doit accepter 3 arguments.

$Modified = &Subroutine(SELF, EVENT, STR);

SELF est l'objet Unicode::LineBreak, EVENT est une chaîne représentant le contexte dans lequel le sous-appel a été appelé, et STR est un fragment de chaîne Unicode avant ou après la position de césure.

EVENT | Contexte de l'événement | STR
-----------------------------------------------------------------
"sot" | Début du texte           | Fragment de la première ligne
"sop" | Après une césure forcée | Fragment de la ligne suivante
"sol" | Après une césure libre    | Fragment de la ligne suivante
""    | Juste avant une césure  | Ligne entière (sans les espaces blancs finaux)
"eol" | Césure libre            | Espaces blancs avant la position de césure
"eop" | Césure forcée           | Retour à la ligne
068;その前の空白文字 "eot" |テキスト終端 |テキスト終端の空白文字 (と改行) -----------------------------------------------------------------

サブルーチンは、テキストの断片を修正して返さなければならない。なにも修正しなかったことを示するには、"undef" を返せばよい。 なお、"sot"、"sop"、"sol" の文脈での修正はその後の分割位置の決定に影響するが、ほかの文脈での修正は影響しない。

Note。 La séquence d'index de caractère est en fait une séquence de classes de caractères écrite. Voir Unicode::GCString~[ja].

市といることのコードは、行末の空白を取り除いて行折りをする。

sub fmt {
    if ($_[1] =~ /^eo/) {
        return "\n";
    }
    return undef;
}
my $lb = Unicode::LineBreak->new(Format => \&fmt);
$output = $lb->break($text);

Opération de coupure de ligne définie par l'utilisateur

インスタンスの分割によって生じる行が CharMax, ColMax, ColMin のいずれかの制限を超えると見まれるときは、引き続く文字列に对して紧急分割を実行できる。 "Urgent" オプションにサブルーチンへの参照を指定する場合、そのサブルーチンは 2 つの引数を取らなければならない。

@分割後 = &サブルーチン(SELF, STR);

SELF は Unicode::LineBreak オブジェクト、STR は分割すべき Unicode 文字列。

サブルーチンは、文字列 STR を分割した結果の配列を返さなければならない。

Note。 La séquence d'index de caractère est en fait une séquence de classes de caractères écrite. Voir Unicode::GCString~[ja].

市といることのコードは、若干の化学物質 (Taurine) の名称にハイフンを挿入し、行折りできるようにする。

sub hyphenize {
    return map {$_ =~ s/yl$/yl-/; $_} split /(\w+?yl(?=\w))/, $_[1];
}
my $lb = Unicode::LineBreak->new(Urgent => \&hyphenize);
$output = $lb->break("Methionylthreonylthreonylglutaminylarginyl...");

オプション "Prep" [REGEX, SUBREF] の配列を指定する場合、サブルーチンは 2 つの引数を取らなければならない。

@分割後 = &サブルーチン(SELF, STR);

SELF は Unicode::LineBreak オブジェクト、STR は REGEX にマッチする分割すべき Unicode 文字列。

サブルーチンは、文字列 STR を分割した結果の配列を返さなければならない。

市といることのコードは、HTTP URL を [CMOS] の要件を用いて分割する。

my $url = qr{http://[\x21-\x7E]+}i;
sub breakurl {
    my $self = shift;
    my $str = shift;
    return split m{(?<=[/]) (?=[^/]) |
                   (?<=[^-.]) (?=[-~.,_?\#%=&]) |
                   (?<=[=&]) (?=.)}x, $str;
}
my $lb = Unicode::LineBreak->new(Prep => [$url, \&breakurl]);
$output = $lb->break($string);

Maintien de l'état

Unicode::LineBreak オブジェクトはハッシュ参照としてふるまう。 任意の要素を、オブジェクトの存在期間中保存できる。

市といることのコードは、段落を空行で分ける。

sub paraformat {
    my $self = shift;
    my $action = shift;
    my $str = shift;

    if ($action eq 'sot' or $action eq 'sop') {
        $self->{'line'} = '';
    } elsif ($action eq '') {
        $self->{'line'} = $str;
    } elsif ($action eq 'eol') {
        return "\n";
    } elsif ($action eq 'eop') {
        if (length $self->{'line'}) {
            return "\n\n";
        } else {
            return "\n";
        }
    } elsif ($action eq 'eot') {
        return "\n";
    }
    return undef;
}
my $lb = Unicode::LineBreak->new(Format => \&paraformat);
$output = $lb->break($string);

Calcul de la longueur de chaîne

オプション "Sizing" にサブルーチンへの参照を指定する場合、そのサブルーチンは 5 つの引数を取らなければならない。

$桁数 = &サブルーチン(SELF, LEN, PRE, SPC, STR);

SELF は Unicode::LineBreak オブジェクト、LEN は先行する文字列の長さ、PRE は先行する Unicode 文字列、SPC は述加される空白文字、STR は処理する Unicode 文字列。

サブルーチンは "PRE.SPC.STR" の桁数を算出して返さなければならない。 桁数は整数でなくてもよい。桁数の単位は隨意に選べるが、"ColMin" オプションおよび "ColMax" オプションのそれと一致させなければならない。

Note。 La séquence d'index de caractère est en fait une séquence de classes de caractères écrite. Voir Unicode::GCString~[ja].

市といることのコードは、行に 8 桁ごとのタブストっプがあるものとして処理する。

sub tabbedsizing {
    my ($self, $cols, $pre, $spc, $str) = @_;

    my $spcstr = $spc.$str;
    while ($spcstr->lbc == LB_SP) {
        my $c = $spcstr->item(0);
        if ($c eq "\t") {
            $cols += 8 - $cols % 8;
        } else {
            $cols += $c->columns;
        }
        $spcstr = $spcstr->substr(1);
    }
    $cols += $spcstr->columns;
    return $cols;
};
my $lb = Unicode::LineBreak->new(LBClass => [ord("\t") => LB_SP],
                                 Sizing => \&tabbedsizing);
$output = $lb->break($string);

Modification des propriétés de caractères

オプション "LBClass" および "EAWidth" オプションで個々の文字の行分割特性 (Classe) や East_Asian_Width 特性を手直しできる。その際に便利な定数をいくつか定義してある。

NOM

Unicode::LineBreak – 日本語の組版への支援

SYNTAX

 use Unicode::LineBreak qw(
     line_break
     property
     version
 );

DESCRIPTION

このモジュールは、Unicode 組版アルゴリズム [UAX #14] に基づく Unicode 文字列の組版処理を行います。 このモジュールは、 Unicode 組版アルゴリズム の日本語実行方醳 UAX14-C2 を実行しています。

モジュールの名前は Unicode 組版アルゴリズム のポーティンスラインのカラーに参照しています。

使用例

    use Unicode::LineBreak qw(line_break);
    my @lines = line_break("This is a Japanese text.\nThis is an English text.");
    print join "\n", @lines;
    # Output:
    # This is a Japanese text.
    # This is an English text.

メソッド

line_break( STRING [, OPTIONS] )

引数 STRING の組版を行い、組み分けられた字列のアレーを返します。

オプションには以下があります。

"lbclass" => CODE

組版クラスの分配を変更するためのコードを指定します。

コードは第一アルゴリズムに第一字列を引数として受け取り、組版クラスを返します。

        my $get_lbclass = sub {
            my ($char) = @_;
            # ... custom logic ...
            return $lbclass;
        };
        line_break($text, lbclass => $get_lbclass);
"columns" => CODE

文字的な幅を計算するためのコードを指定します。

コードは第一アルゴリズムに第一字列を引数として受け取り、文字の幅を返します。

        my $get_columns = sub {
            my ($char) = @_;
            # ... custom logic ...
            return $columns;
        };
        line_break($text, columns => $get_columns);
"config" => FILENAME

設定ファイルの名前を指定します。設定ファイルでの設定は、new メソッドおよび config メソッドのオプションによる設定より前に組み込ます。

"eawidth" => CODE

東亜幅を計算するためのコードを指定します。

このメソッドは Unicode::GCString の columns() の内で使用されます。

        my $get_eawidth = sub {
            my ($char) = @_;
            # ... custom logic ...
            return $width;
        };
        line_break($text, eawidth => $get_eawidth);
"lbclass" => CODE

このメソッドは Unicode::GCString の lbcext() および lbc() の内で使用されます。

        my $get_lbclass = sub {
            my ($char) = @_;
            # ... custom logic ...
            return $lbclass;
        };
        line_break($text, lbclass => $get_lbclass);
property( NAME )

組版クラスの分配を取得するためのファンクションを返します。

        my $get_lbclass = property('lbclass');
        my $lbclass = $get_lbclass->( $char );
version()

モジュールのバージョンを返します。

CUSTOMIZATION

このモジュールは、 line_break メソッドにて、ユーザーによってかすたいる分配を変更することができます。

IMPLEMENTATION NOTES

  • 一部の表語文字の文字を NS として扱うか ID として扱うかを選べる。
  • ハングル音節およびハングル連結チャモを ID として扱うか AL として扱うかを選べる。
  • AI に分類される文字を AL と ID のどちらに解決するかを選べる。
  • CB に分類される文字は解決しない。
  • CJ に分類される文字は常に NS に解決する。より柔軙な手直しの機構が提供される。
  • 東南アジアの表記体系の単語分節に対応しない場合は、 SA に分類される文字は AL に解決する。 ただし、Grapheme_Cluster_Break 特性の値が Extend か SpacingMark である文字は CM に解決する。
  • SG や XX に分類される文字は AL に解決する。
  • 以下の UCS の節囲にあるコードポイントは、文字が割り当てられていなくても決まった特性値を持つ。 
    節囲               | UAX #14    | UAX #11    | 説明
-------------------------------------------------------------
U+20A0..U+20CF     | PR [*1]    | N [*2]     | 通貨記号
U+3400..U+4DBF     | ID         | W          | CJK漢字
U+4E00..U+9FFF     | ID         | W          | CJK漢字
U+D800..U+DFFF     | AL (SG)    | N          | サロゲート
U+E000..U+F8FF     | AL (XX)    | F か N (A) | 私用領域
U+F900..U+FAFF     | ID         | W          | CJK漢字
U+20000..U+2FFFD   | ID         | W          | CJK漢字
U+30000..U+3FFFD   | ID         | W          | 古漢字
U+F0000..U+FFFFD   | AL (XX)    | F か N (A) | 私用領域
U+100000..U+10FFFD | AL (XX)    | F か N (A) | 私用領域
その他未割り当て   | AL (XX)    | N          | 未割り当て、
                   |            |            | 予約、非文字
-------------------------------------------------------------
[*1] U+20A7 ペセタ記号 (PO)、U+20B6 トゥール・リーヴル記号 
  (PO)、U+20BB スカンディナヴィア・マルク記号 (PO)、U+20BE
  ラリ記号 (PO) を除く。
[*2] U+20A9 ウォン記号 (H)、U+20AC ユーロ記号 (F か N (A)) を
  除く。
  • 一般カテゴリ特性が Mn、Me、Cc、Cf、Zl、Zp のいずれかである文字は、前進を伴わない文字とみなす。
