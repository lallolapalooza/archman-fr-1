Pod::Simple::HTMLBatch(3perl) Manuel du programmeur Perl Pod::Simple::HTMLBatch(3perl)

NOM

Pod::Simple::HTMLBatch - convertir plusieurs fichiers Pod en plusieurs fichiers HTML

SYNOPSIS

perl -MPod::Simple::HTMLBatch -e 'Pod::Simple::HTMLBatch::go' in out

DESCRIPTION

Ce module est utilisé pour exécuter des conversions par lots de plusieurs documents HTML.

Cette classe n'est pas une sous-classe de Pod::Simple::HTML (ni de l'ancien Pod::Html) — bien qu'elle utilise Pod::Simple::HTML pour effectuer la conversion de chaque document.

L'utilisation normale de cette classe est la suivante :

use Pod::Simple::HTMLBatch;
my $batchconv = Pod::Simple::HTMLBatch->new;
$batchconv->some_option( some_value );
$batchconv->some_other_option( some_other_value );
$batchconv->batch_convert( \@search_dirs, $output_dir );

DEPUIS LA LIGNE DE COMMANDE

Note : Cette classe fournit également (mais n'exporte pas) la méthode Pod::Simple::HTMLBatch::go. Il s'agit essentiellement d'un raccourci pour "Pod::Simple::HTMLBatch->batch_convert(@ARGV)". Elle est utile pour être appelée depuis la ligne de commande.

Cependant, le raccourci nécessite de spécifier exactement deux arguments de ligne de commande, "indirs" et "outdir".

Exemple :

% mkdir out_html
% perl -MPod::Simple::HTMLBatch -e Pod::Simple::HTMLBatch::go @INC out_html
    (pour convertir le pod de @INC de Perl dans le répertoire ./out_html)

(Note : La ligne de commande contient un @INC littéral. Celui-ci est traité comme un cas spécial par batch_convert, afin d'éviter d'avoir à taper "" comme premier argument de la ligne de commande lorsque vous voulez "utiliser ce qui est dans @INC".)

Exemple :

% mkdir ../seekrut
% chmod og-rx ../seekrut
% perl -MPod::Simple::HTMLBatch -e Pod::Simple::HTMLBatch::go . ../seekrut
    (pour convertir le pod du répertoire courant en HTML dans le répertoire ./seekrut)

Exemple :

% perl -MPod::Simple::HTMLBatch -e Pod::Simple::HTMLBatch::go happydocs .
    (pour convertir tous les pods de happydocs dans le répertoire courant)

MÉTHODES PRINCIPALES

$batchconv = Pod::Simple::HTMLBatch->new;
Ceci crée un nouveau convertisseur par lots. La méthode ne prend aucun paramètre. Pour modifier les propriétés du convertisseur, utilisez les méthodes d'accesseur ci-dessous.
$batchconv->batch_convert( indirs, outdir );
Recherche dans les répertoires donnés dans indirs et écrit des fichiers HTML pour chacun d'eux dans un répertoire correspondant dans outdir. Le répertoire outdir doit exister.
$batchconv->batch_convert( undef , ...);
$batchconv->batch_convert( q{@INC}, ...);
Ces deux valeurs pour indirs spécifient le @INC normal de Perl.
$batchconv->batch_convert( \@dirs , ...);
Ceux-ci spécifient que les répertoires d'entrée sont les éléments de l'arrayref "\@dirs".
$batchconv->batch_convert( "somedir" , ...);
Ceux-ci spécifient que le répertoire "somedir" est l'entrée. (Cela peut être un répertoire absolu ou relatif, peu importe.)
Une valeur courante que vous pourriez vouloir est "." pour le répertoire courant :
$batchconv->batch_convert( "." , ...);
$batchconv->batch_convert( 'somedir:someother:also' , ...);
Ceci spécifie que vous voulez rechercher "somedir", "someother", et "also" comme si vous aviez passé l'arrayref "[qw( somedir someother also)]". Notez qu'un séparateur ":" est normal sous Unix, mais sous MSWin, vous avez besoin de "somedir;someother;also" car le séparateur de chemin sous MSWin est ";" au lieu de ":". (Et c'est parce que ":" apparaît souvent dans les chemins, comme "c:/perl/lib".)
$batchconv->batch_convert( ... , undef );
Ceux-ci spécifient que la sortie HTML va dans le répertoire courant.
(Note : Une valeur manquante ou indéfinie signifie quelque chose de différent dans le premier argument que dans le second. C'est pour que batch_convert() sans arguments (ou avec des arguments indéfinis) signifie "aller de @INC au répertoire courant".)
$batchconv->batch_convert( ... , 'somedir' );
Ceux-ci spécifient que la sortie HTML va dans le répertoire "somedir".

Notez que vous pouvez également appeler "batch_convert" comme méthode de classe, ainsi :

Pod::Simple::HTMLBatch->batch_convert( ... );

Ce n'est qu'un raccourci pour :

Pod::Simple::HTMLBatch->new-> batch_convert(...);

C'est-à-dire qu'une conversion est exécutée avec les options par défaut pour les répertoires d'entrée et de sortie que vous spécifiez.

MÉTHODES D'ACCESSEUR

Les méthodes suivantes sont toutes des méthodes d'accesseur — c'est-à-dire qu'elles ne font rien par elles-mêmes, mais modifient simplement le contenu de l'objet de conversion, qui comprend les options de cette conversion par lots particulière.

Nous montrons le côté « setter » des accesseurs (c'est-à-dire la syntaxe que vous utilisez pour définir la valeur d'un accesseur à une valeur spécifique). Mais vous pouvez également appeler chaque méthode sans paramètres pour obtenir sa valeur actuelle. Par exemple, "$self->contents_file()" renvoie la valeur actuelle de l'attribut contents_file.

$batchconv->verbose( entier_non_négatif );
Ceci contrôle le niveau de verbosité pendant la conversion par lots, en envoyant des notes à STDOUT (ou à ce qui est actuellement sélectionné). Si 0, aucune information de progression n'est imprimée. Si 1 (la valeur par défaut), des informations de progression sont imprimées. Des valeurs plus élevées impriment plus d'informations.
$batchconv->index( vrai-ou-faux );
Ceci contrôle si chaque page HTML a une petite table des matières en haut (que nous appelons « index » pour des raisons historiques). Ceci est vrai par défaut.
$batchconv->contents_file( nom_de_fichier );
Si défini, ce doit être le nom d'un fichier (dans le répertoire de sortie) dans lequel écrire l'index HTML. La valeur par défaut est "index.html". Si vous le définissez à une valeur fausse, aucun fichier de contenu ne sera écrit.
$batchconv->contents_page_start( chaîne_HTML );
Ceci spécifie quelle chaîne doit être placée au début de la page de contenu. La valeur par défaut est une chaîne approximativement comme suit : 
<html>
<head><title>Documentation Perl</title></head>
<body class='contentspage'>
<h1>Documentation Perl</h1>
$batchconv->contents_page_end( chaîne_HTML );
Ceci spécifie quelle chaîne doit être placée à la fin de la page de contenu. La valeur par défaut est une chaîne approximativement comme suit : 
<p class='contentsfooty'>Généré par
Pod::Simple::HTMLBatch v3.01 sous Perl v5.008
<br >Le Fri May 14 22:26:42 2004 GMT,
ce qui est le Fri May 14 14:26:42 2004 heure locale.</p>
