Pod::Simple::SimpleTree(3perl) Guide du programmeur Perl Pod::Simple::SimpleTree(3perl)

NOM

Pod::Simple::SimpleTree -- analyser Pod en un arbre d'analyse simple

SYNTAXE

% cat ptest.pod
=head1 PIE
I like B<pie>!
% perl -MPod::Simple::SimpleTree -MData::Dumper -e \
   "print Dumper(Pod::Simple::SimpleTree->new->parse_file(shift)->root)" \
   ptest.pod
$VAR1 = [
          'Document',
          { 'start_line' => 1 },
          [
            'head1',
            { 'start_line' => 1 },
            'PIE'
          ],
          [
            'Para',
            { 'start_line' => 3 },
            'I like ',
            [
              'B',
              {},
              'pie'
            ],
            '!'
          ]
        ];

DESCRIPTION

Cette classe intéresse les personnes qui écrivent un processeur/formateur de Pod.

Cette classe prend Pod et l'analyse, renvoyant un arbre d'analyse composé uniquement d'arrayrefs, de hashrefs et de chaînes de caractères.

C'est une sous-classe de Pod::Simple et hérite de toutes ses méthodes.

Cette classe est inspirée du style d'analyse "Tree" de XML::Parser, bien qu'elle n'utilise pas exactement le même format LoL.

MÉTHODES

À la fin de l'analyse, appelez "$parser->root" pour obtenir le nœud racine de l'arbre.

CONTENU DE L'ARBRE

Chaque nœud élément de l'arbre d'analyse est représenté par un arrayref de la forme : "[ nom_element, \%attributs, ...nœuds_fils... ]". Voir le vidage de l'arbre dans la section Synopsis, ci-dessus.

Chaque nœud de texte dans l'arbre est représenté par un scalaire de chaîne simple (non-référencé). Vous pouvez donc tester ref($node) pour voir si vous avez un nœud élément ou juste un nœud de texte.

Le nœud racine de l'arbre est "[ 'Document', \%attributs, ...nœuds_fils... ]"
