Pod::Simple::PullParserTextToken(3perl) Guide de référence des programmeurs Perl Pod::Simple::PullParserTextToken(3perl)

NOM

Pod::Simple::PullParserTextToken -- jetons texte provenant de Pod::Simple::PullParser

SYNOPIS

(Voir Pod::Simple::PullParser)

DESCRIPTION

Lorsque vous appelez $parser->get_token sur un Pod::Simple::PullParser, vous pouvez obtenir un objet de cette classe.

C'est une sous-classe de Pod::Simple::PullParserToken et elle hérite de toutes ses méthodes, et ajoute ces méthodes :

$token->text
Ceci retourne le texte que ce jeton contient. Par exemple, analyser C<foo> retournera un jeton de début C, un jeton texte, et un jeton de fin C. Et si vous voulez extraire le « foo » du jeton texte, appelez "$token->text"
$token->text(chaîne)
Ceci modifie la chaîne que ce jeton contient. Vous n'aurez probablement pas besoin de le faire.
$token->text_r()
Ceci retourne une référence scalaire vers la chaîne que ce jeton contient. Cela peut être utile si vous ne voulez pas copier en mémoire la valeur texte potentiellement volumineuse (aussi volumineuse qu'un paragraphe ou un bloc verbatim) comme le ferait l'appel à $token->text.

Ou, si vous voulez modifier la valeur, vous pouvez même faire des choses comme celles-ci :

for ( ${  $token->text_r  } ) {  # Alias avec $_ !!
  s/ Le / le /g; # juste pour l'exemple
  if( 'A' eq chr(65) ) {  # (si dans un monde ASCII)
    tr/\xA0/ /;
    tr/\xAD//d;
  }
  ... ou de toute autre manière dont vous souhaitez modifier la valeur...
  (Notez qu'à partir de Perl v5.8, vous pouvez utiliser, par exemple,
      my $nbsp = chr utf8::unicode_to_native(0xA0);
      s/$nbsp/ /g;
  pour gérer ce qui précède, que ce soit un monde ASCII ou non)
}

Il est peu probable que vous ayez besoin de construire vous-même un objet de cette classe, mais si vous le souhaitez, appelez "Pod::Simple::PullParserTextToken->new( texte )"
