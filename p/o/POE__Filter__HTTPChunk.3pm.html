NOM

POE::Filter::HTTPChunk - Analyseur de morceaux HTTP incrémental non bloquant.

VERSION

version 0.949

SYNOPSIS

# Pas un programme complet.
use POE::Filter::HTTPChunk;
use POE::Wheel::ReadWrite;
sub setup_io {
  $_[HEAP]->{io_wheel} = POE::Wheel::ReadWrite->new(
    Filter => POE::Filter::HTTPChunk->new(),
    # Voir POE::Wheel::ReadWrite pour les autres paramètres requis.
  );
}

DESCRIPTION

Ce filtre analyse les morceaux HTTP à partir d'un flux de données. Il est utilisé par POE::Component::Client::HTTP pour effectuer la majeure partie de l'analyse de bas niveau du protocole HTTP.

CONSTRUCTEUR

new

"new" ne prend aucun paramètre et renvoie un nouvel objet POE::Filter::HTTPChunk prêt à l'emploi.

MÉTHODES

POE::Filter::HTTPChunk prend en charge les méthodes suivantes. La plupart d'entre elles respectent l'API standard de POE::Filter. La documentation de POE::Filter explique l'API plus en détail.

get_one_start ARRAYREF

Accepte une référence à un tableau contenant zéro ou plusieurs morceaux de données brutes. Ceux-ci sont ajoutés au tampon d'entrée du filtre. Le filtre tentera d'analyser ces données lorsque get_one() sera appelé.

$filter_httpchunk->get_one_start(\@stream_data);

get_one

Analyse un seul morceau HTTP à partir du tampon d'entrée du filtre. Les données sont entrées dans le tampon par la méthode get_one_start(). Renvoie une référence à un tableau contenant zéro ou un morceau HTTP analysé.

$ret_arrayref = $filter_httpchunk->get_one();

get_pending

Renvoie une référence à un tableau contenant les données de flux en attente d'analyse. Elle est utilisée pour transférer de manière transparente les données non analysées entre un ancien et un nouveau filtre lorsque le filtre d'une roue est modifié.

$pending_arrayref = $filter_httpchunk->get_pending();
