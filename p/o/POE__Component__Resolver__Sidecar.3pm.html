NOM

POE::Component::Resolver::Sidecar - déléguer le sous-processus pour appeler getaddrinfo()

VERSION

version 0.921

SYNOPIS

Utilisé en interne par POE::Component::Resolver.

DESCRIPTION

POE::Component::Resolver crée des sous-processus pour appeler getaddrinfo() afin que le programme principal ne se bloque pas pendant ce temps.

Le code d'appel réel de getaddrinfo() est abstrait dans ce module afin qu'il puisse être exécuté dans un programme exécutable séparé. Cela réduit l'empreinte mémoire du fork de l'ensemble du processus principal pour seulement getaddrinfo().

C'est un modèle solide et utile que d'autres POE::Components ont implémenté auparavant. POE::Quickie le fait de manière générique. POE::Component::SimpleDBI et POE::Component::EasyDBI le font pour que leurs sous-processus DBI soient relativement légers.

main

Le code principal pour lire les requêtes de POE::Component::Resolver depuis STDOUT et écrire les réponses de getaddrinfo() sur STDOUT.

VOIR AUSSI

POE::Component::Generic est une implémentation générique de ce modèle.

POE::Quickie est une autre implémentation générique de ce modèle.

BOGUES

Aucun connu.
