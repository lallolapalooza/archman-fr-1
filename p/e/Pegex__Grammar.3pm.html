NOM

Pegex::Grammar - Classe de base de grammaire Pegex

SYNTAXE

Définir une grammaire Pegex (pour la syntaxe Foo) :

package Pegex::Foo::Grammar;
use base 'Pegex::Base';
extends 'Pegex::Grammar';
has text => q{
foo: bar baz
... reste de la grammaire Foo ...
};

puis l'utiliser pour analyser du Foo :

use Pegex::Parser;
my $parse_tree = Pegex::Parser->new(
    grammar => 'Pegex::Foo::Grammar',
    receiver => 'Pegex::Tree',
)->parse('my/file.foo');

DESCRIPTION

Pegex::Grammar est une classe de base pour définir vos propres classes de grammaire Pegex. Il vous suffit de fournir la vue de la grammaire via les attributs "text" ou "file".

Lorsque Pegex::Parser utilisera votre grammaire, il la voudra sous forme compilée (arbre), donc Pegex::Grammar fournit un support de compilation automatique.

PROPRIÉTÉS ET MÉTHODES

tree
C'est la structure de données contenant la grammaire compilée pour votre syntaxe. Elle est généralement produite par "Pegex::Compiler". Vous pouvez l'intégrer dans la méthode "tree", ou sinon la méthode "make_tree" sera appelée pour la produire.

La méthode "make_tree" appellera Pegex::Compiler pour compiler la propriété "text" par défaut. Vous pouvez définir votre propre méthode "make_tree" pour outrepasser ce comportement.

Souvent, vous voudrez générer vos propres sous-classes Pegex::Grammar de manière automatisée. Les modules Pegex et TestML font cela pour être performants. Cela vous permet également de conserver votre texte de grammaire dans un fichier séparé, et souvent dans un dépôt séparé, afin qu'il puisse être partagé par des implémentations de modules de plusieurs langages de programmation.

Voir https://github.com/ingydotnet/pegex-pgx et https://github.com/ingydotnet/pegex-pm/blob/master/lib/Pegex/Pegex/Grammar.pm.

text
C'est simplement le texte de votre grammaire. Si vous définissez cela, vous ne devriez (probablement) pas définir la propriété "tree". Ce texte de grammaire sera automatiquement compilé lorsque la propriété "tree" sera requise.
file
C'est le fichier où se trouve votre grammaire Pegex. Il est généralement utilisé lorsque vous créez un module Pegex. Le chemin est relatif à votre répertoire de module de niveau supérieur.
make_tree
Cette méthode est appelée lorsque la grammaire a besoin de sa version compilée.
