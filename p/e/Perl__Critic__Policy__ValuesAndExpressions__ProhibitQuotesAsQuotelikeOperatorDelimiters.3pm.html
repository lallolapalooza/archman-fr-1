NOM

Perl::Critic::Policy::ValuesAndExpressions::ProhibitQuotesAsQuotelikeOperatorDelimiters - N'utilisez pas de guillemets ("'", """, "`") comme délimiteurs pour les opérateurs de type guillemet.

AFILATION

Cette politique fait partie de la distribution centrale de Perl::Critic.

DESCRIPTION

À l'exception évidente de l'utilisation de guillemets simples pour empêcher l'interpolation, l'utilisation de guillemets avec les opérateurs de type guillemet va un peu à l'encontre de leur objectif et produit du code obfusqué, causant des problèmes pour les futurs mainteneurs et leurs éditeurs/IDE.

$x = q"q";                # pas ok
$x = q'q';                # pas ok
$x = q`q`;                # pas ok
$x = qq"q";               # pas ok
$x = qr"r";               # pas ok
$x = qw"w";               # pas ok
$x = qx`date`;            # pas ok
$x =~ m"m";               # pas ok
$x =~ s"s"x";             # pas ok
$x =~ tr"t"r";            # pas ok
$x =~ y"x"y";             # pas ok
$x =~ m'$x';              # ok
$x =~ s'$x'y';            # ok
$x = qr'$x'm;             # ok
$x = qx'finger foo@bar';  # ok

CONFIGURATION

Cette politique a trois options : "single_quote_allowed_operators", "double_quote_allowed_operators", et "back_quote_allowed_operators", qui contrôlent quels opérateurs sont autorisés à utiliser chacun des délimiteurs "'", """, "`", respectivement.

Les valeurs autorisées pour ces options sont une sélection séparée par des espaces blancs des opérateurs "m", "q", "qq", "qr", "qw", "qx", "s", "tr" et "y".

Par défaut, les guillemets doubles et les guillemets arrière (backticks) ne sont pas autorisés comme délimiteurs pour aucun opérateur et les guillemets simples sont autorisés comme délimiteurs pour les opérateurs "m", "qr", "qx" et "s". Ces valeurs par défaut équivalent à avoir ce qui suit dans votre fichier .perlcriticrc :

[ValuesAndExpressions::ProhibitQuotesAsQuotelikeOperatorDelimiters]
single_quote_allowed_operators = m s qr qx
double_quote_allowed_operators =
back_quote_allowed_operators =
