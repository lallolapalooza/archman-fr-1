NOM

Perl::Critic::Policy::TestingAndDebugging::ProhibitProlongedStrictureOverride - Ne pas désactiver la directive strict sur de larges blocs de code.

AFFILIATION

Cette politique fait partie de la distribution principale de Perl::Critic.

DESCRIPTION

Tout le monde s'accorde à dire que "use strict" est la première étape pour écrire du code maintenable en Perl. Cependant, parfois "strict" est un peu trop strict. Dans ces cas, vous pouvez le désactiver brièvement avec une directive "no strict".

Cette politique vérifie que "no strict" n'est en vigueur que pour un petit nombre d'instructions.

CONFIGURATION

Le nombre par défaut d'instructions autorisées par "no strict" est de trois. Pour remplacer ce nombre, ajoutez ce qui suit dans votre fichier .perlcriticrc :

[TestingAndDebugging::ProhibitProlongedStrictureOverride]
statements = 5
