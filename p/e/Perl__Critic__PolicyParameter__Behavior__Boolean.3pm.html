NOM

Perl::Critic::PolicyParameter::Behavior::Boolean - Actions appropriées pour un paramètre booléen.

DESCRIPTION

Fournit un ensemble standard de fonctionnalités pour un Perl::Critic::PolicyParameter booléen afin que le développeur d'une politique n'ait pas à le faire lui-même.

NOTE : N'instanciez pas cette classe. Utilisez l'instance singleton maintenue par Perl::Critic::PolicyParameter.

PRISE EN CHARGE DE L'INTERFACE

Ceci est considéré comme une classe non publique. Son interface peut changer sans préavis.

MÉTHODES

"initialize_parameter( $parameter, $specification )"
Intègre la fonctionnalité fournie par ce comportement dans le paramètre. Actuellement, ce comportement n'est pas personnalisable par la spécification.
