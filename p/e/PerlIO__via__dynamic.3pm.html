NOM

PerlIO::via::dynamic - couches PerlIO dynamiques

SYNTAXE

open $fh, $fname;
$p = PerlIO::via::dynamic->new
 (translate =>
   sub { $_[1] =~ s/\$Filename[:\w\s\-\.\/\\]*\$/\$Filename: $fname\$/e},
  untranslate =>
   sub { $_[1] =~ s/\$Filename[:\w\s\-\.\/\\]*\$/\$Filename\$/});
$p->via ($fh);
binmode $fh, $p->via; # obsolète

DESCRIPTION

"PerlIO::via::dynamic" est utilisé pour créer des couches PerlIO dynamiques. C'est utile lorsque le comportement ou la couche dépend de variables. Vous ne devriez pas utiliser ce module comme couche via directement (c'est-à-dire :via(dynamic)).

Utilisez le constructeur pour créer de nouvelles couches, avec deux arguments : translate et untranslate. Ensuite, utilisez "$p-"via ($fh)> pour encapsuler le handle. Une fois que <$fh> est détruit, l'espace de noms temporaire pour la couche IO sera supprimé.

Notez que PerlIO::via::dynamic utilise les champs scalaires pour référencer l'objet représentant l'espace de noms dynamique.

OPTIONS

translate
Une fonction qui traduit le tampon lors de l' *écriture*.
untranslate
Une fonction qui traduit le tampon lors de la *lecture*.
use_read
Utilise "READ" au lieu de "FILL" pour la couche. Utile lorsque l'appelant attend une quantité exacte de données de la lecture, et que la fonction "untranslate" peut renvoyer une longueur différente.

Par défaut, "PerlIO::via::dynamic" crée une couche basée sur les lignes pour faciliter l'implémentation de "translate".
