NOM

Perl::Critic::Config - La configuration finale de Perl::Critic, combinée à partir de tout fichier de profil et de paramètres de ligne de commande.

DESCRIPTION

Perl::Critic::Config est responsable de trouver et de traiter les préférences de l'utilisateur pour Perl::Critic. L'objet Config définit quels modules de politique doivent être chargés dans le moteur Perl::Critic et comment ils doivent être configurés. Vous ne devriez pas avoir besoin d'instancier Perl::Critic::Config directement, car le constructeur de Perl::Critic le fera pour vous.

SUPPORT D'INTERFACE

Ceci est considéré comme une classe non publique. Son interface est susceptible d'être modifiée sans préavis.

CONSTRUCTEUR

new(...)
N'est pas correctement documenté car il ne devrait pas être utilisé.

MÉTHODES

"add_policy( -policy => $nom_politique, -params => \%hash_param )"
Crée un objet Politique et le charge dans ce Config. Si l'objet ne peut pas être instancié, il lèvera une exception fatale. Sinon, renvoie une référence à ce Critic.

-policy est le nom d'une classe de module Perl::Critic::Policy. La partie 'Perl::Critic::Policy' du nom peut être omise par souci de brièveté. Cet argument est obligatoire.

-params est une référence optionnelle à un hash de paramètres de Politique. Les contenus de ce hash de référence seront passés au constructeur du module de Politique. Voir la documentation du module correspondant pour une description des arguments qu'il accepte.

all_policies_enabled_or_not()
Renvoie une liste de références à tous les objets Politique qui ont été rencontrés. Vous devez être conscient que l'état de ces objets n'est pas fiable. En particulier, il est probable que certains d'entre eux ne soient pas prêts à examiner un document quelconque.

SOUS-ROUTINES

Perl::Critic::Config a quelques sous-routines statiques qui sont utilisées en interne, mais qui pourraient vous être utiles dans certains cas.

site_policy_names()
Renvoie une liste de tous les modules de politique actuellement installés dans l'espace de noms Perl::Critic::Policy. Cela inclura les modules distribués avec Perl::Critic ainsi que tout module tiers qui aurait été installé.

CONFIGURATION

La plupart des configurations de Perl::Critic et de chacun des modules de politique peuvent être contrôlées via un fichier de configuration. Le fichier de configuration par défaut s'appelle .perlcriticrc. Perl::Critic::Config recherchera d'abord ce fichier dans le répertoire courant, puis dans votre répertoire personnel. Alternativement, vous pouvez définir la variable d'environnement "PERLCRITIC" pour pointer vers un fichier différent ailleurs. Si aucun de ces fichiers n'existe et que le paramètre "-profile" n'est pas fourni au constructeur, alors tous les modules de politique seront chargés avec leur configuration par défaut.

Le format du fichier de configuration est un ensemble de blocs de style INI contenant des paires clé-valeur séparées par des '='. Les commentaires doivent commencer par '#' et peuvent être placés sur une ligne séparée ou après des paires clé-valeur, selon votre préférence.

Les valeurs par défaut de Perl::Critic lui-même peuvent être définies avant le premier bloc nommé. Par exemple, placer n'importe lequel ou tous les éléments suivants en haut de votre fichier de configuration définira la valeur par défaut pour l'argument correspondant du constructeur de Perl::Critic.

severity  = 3
