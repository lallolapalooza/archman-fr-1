NOM

Pegex::Receiver - Classe de base pour tous les récepteurs Pegex

SYNTAXE

package MonRecepteur;
use base 'Pegex::Receiver';
# Traiter les données pour une règle spécifique
sub got_nomderèglenspécifique {
    my ($self, $got) = @_;
    # ... traitement ...
    return $résultat;
}
# Traiter les données pour toute autre règle
sub gotrègle {
    my ($self, $got) = @_;
    return $résultat;
}
# Pré-traitement
sub initial { ... }
# Post-traitement
sub final {
    ...;
    return $résultat_final;
}

DESCRIPTION

Dans Pegex, un récepteur est l'objet de classe auquel un analyseur passe les données capturées lorsqu'une règle dans une grammaire correspond à une partie d'un flux d'entrée. Un récepteur fournit des méthodes d'action pour transformer les données analysées en ce que l'analyseur est censé faire.

C'est la classe de base de toutes les classes de récepteurs Pegex.

Elle ne fait pas grand-chose, ce qui est la bonne chose à faire. Si vous utilisez cette classe comme récepteur, elle n'effectuera aucun travail supplémentaire. Voir Pegex::Tree pour une classe de base de récepteur qui vous aidera à organiser vos correspondances par défaut.

Comment fonctionne un récepteur

Une grammaire Pegex est composée de règles nommées, d'expressions régulières et de groupes. Lorsqu'une expression régulière correspond, l'analyseur crée un tableau de ses chaînes de capture. Lorsqu'un groupe correspond, l'analyseur crée un tableau de tous les tableaux de sous-correspondances. De cette manière, un arbre d'analyse se forme.

Lorsqu'une règle nommée correspond, une méthode d'action est appelée dans la classe du récepteur. La méthode reçoit l'arbre d'analyse actuel et renvoie ce que l'analyseur considérera comme le nouvel arbre d'analyse.

Cela permet une API très élégante et compréhensible.

API

Cette section documente les méthodes que vous pouvez inclure dans une sous-classe de récepteur.

"got_$nomdurègle($got)"
Une méthode d'action pour une règle nommée spécifique. 
sub got_règle42 {
    my ($self, $got) = @_;
    ...
    return $résultat;
}

La valeur $got passée est la valeur actuelle de l'arbre d'analyse. Ce qui est renvoyé est ce que vous voulez que soit la nouvelle valeur.

gotrègle($got)
La méthode d'action pour une règle nommée qui n'a pas de méthode d'action spécifique.
initial()
Appelée au début d'une opération d'analyse, avant le début de l'analyse.
final($got)
Appelée à la fin d'une opération d'analyse. Ce que cette action renvoie sera le résultat de l'analyse.

Méthodes

"parser"
Un attribut contenant l'objet analyseur en cours d'exécution. Cela peut être très utile pour introspecter ce qui se passe, et éventuellement modifier la grammaire à la volée. (Pour experts uniquement !)
aplatir($array)
Une méthode utilitaire qui peut transformer un tableau de tableaux en un seul tableau. Par exemple : 
$self->aplatir([1, [2, [3, 4], 5], 6]);
# produit [1, 2, 3, 4, 5, 6]

Les hachages restent inchangés. Le tableau est modifié sur place, mais est également la valeur renvoyée.
