NOM

Perl::Critic::Policy::Modules::RequireFilenameMatchesPackage - La déclaration de paquet doit correspondre au nom du fichier.

AFILITATION

Cette politique fait partie de la distribution centrale de Perl::Critic.

DESCRIPTION

La déclaration de paquet doit toujours correspondre au nom du fichier qui la contient. Par exemple, "package Foo::Bar;" devrait se trouver dans un fichier appelé "Bar.pm". Cela permet aux développeurs de déterminer plus facilement d'où provient un symbole lorsqu'ils le voient dans votre code. Par exemple, lorsque vous voyez "Foo::Bar->new()", vous devriez pouvoir trouver la définition de la classe "Foo::Bar" dans un fichier nommé Bar.pm.

Par conséquent, cette politique exige que le dernier composant du premier nom de paquet déclaré dans le fichier corresponde au nom de fichier physique. Ou si des directives "#line" sont utilisées, alors il doit correspondre au nom de fichier logique défini par la directive "#line" prédominante au point de la déclaration du paquet. Voici quelques exemples :

# N'importe lequel des éléments suivants dans le fichier "Foo/Bar/Baz.pm" :
package Foo::Bar::Baz;     # ok
package Baz;               # ok
package Nuts;              # pas ok (ne correspond pas au nom de fichier physique)
# Utilisation de directives #line dans le fichier "Foo/Bar/Baz.pm" :
#line 1 Nuts.pm
package Nuts;             # ok
package Baz;              # pas ok (contredit la directive #line)

Si le fichier n'est pas considéré comme un module, cette politique ne s'applique pas. De plus, si le premier espace de noms de paquet trouvé dans le fichier est "main", cette politique ne s'applique pas.

CONFIGURATION

Cette politique n'est pas configurable, à l'exception des options standard.
