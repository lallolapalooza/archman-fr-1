Perl::Critic::Exception::Configuration::Option::Policy(3pm) Documentation Perl fournie par l'utilisateur Perl::Critic::Exception::Configuration::Option::Policy(3pm)

NOM

Perl::Critic::Exception::Configuration::Option::Policy - Un problème avec la configuration d'une politique.

DESCRIPTION

Une représentation d'un problème trouvé avec la configuration d'une Perl::Critic::Policy, que ce soit à partir d'un fichier .perlcriticrc, d'un autre fichier de profil, ou de la ligne de commande.

Ceci est une classe abstraite. Elle ne devrait jamais être instanciée.

SUPPORT D'INTERFACE

Ceci est considéré comme une classe publique. Tout changement à son interface passera par un cycle de dépréciation.

MÉTHODES

policy()
Le nom court de la politique qui a eu des problèmes de configuration.
