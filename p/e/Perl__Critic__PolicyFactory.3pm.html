Perl::Critic::PolicyFactory(3pm) Documentation Perl fournie par l'utilisateur Perl::Critic::PolicyFactory(3pm)

NOM

Perl::Critic::PolicyFactory - Instancie des objets Policy.

DESCRIPTION

Ceci est une classe utilitaire qui instancie des objets Perl::Critic::Policy avec les paramètres préférés de l'utilisateur. Il n'y a aucune partie ici que l'utilisateur puisse réparer.

PRISE EN CHARGE DE L'INTERFACE

Ceci est considéré comme une classe non publique. Son interface est sujette à changement sans préavis.

CONSTRUCTEUR

"new( -profile => $profile, -errors => $config_errors )"
Retourne une référence vers un nouvel objet Perl::Critic::PolicyFactory.

-profile est une référence vers un objet Perl::Critic::UserProfile. Cet argument est requis.

-errors est une référence vers une instance de Perl::Critic::ConfigErrors. Cet argument est optionnel. S'il est spécifié, les problèmes trouvés seront ajoutés à l'objet.

MÉTHODES

"create_policy( -name => $policy_name, -params => \%param_hash )"
Crée un objet Policy. Si l'objet ne peut pas être instancié, une exception fatale sera levée. Sinon, elle retourne une référence vers le nouvel objet Policy.

-name est le nom d'un module de sous-classe Perl::Critic::Policy. La partie 'Perl::Critic::Policy' du nom peut être omise par souci de brièveté. Cet argument est requis.

-params est une référence optionnelle vers une table de paramètres qui sera passée au constructeur de la Policy. Si "-params" n'est pas défini, nous utiliserons les paramètres de Policy appropriés de la Perl::Critic::UserProfile.

Notez que la Policy n'aura pas eu "initialize_if_enabled" dans Perl::Critic::Policy invoquée, elle pourrait donc ne pas être utilisable immédiatement.

create_all_policies()
Construit et retourne une instance de chaque sous-classe Perl::Critic::Policy installée sur le système local. Chaque Policy sera créée avec les paramètres appropriés du profil de configuration de l'utilisateur.

Notez que les Policies n'auront pas eu "initialize_if_enabled" dans Perl::Critic::Policy invoquée sur elles, elles pourraient donc ne pas être utilisables immédiatement.

SOUS-ROUTINES

Perl::Critic::PolicyFactory possède quelques sous-routines statiques qui sont utilisées en interne, mais qui pourraient vous être utiles d'une quelconque manière.

site_policy_names()
Retourne une liste de tous les modules Policy qui sont actuellement installés dans l'espace de noms Perl::Critic:Policy. Cela inclura les modules distribués avec Perl::Critic ainsi que tout module tiers qui a été installé.
