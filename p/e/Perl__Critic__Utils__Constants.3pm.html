Perl::Critic::Utils::Constants(3pm) Documentation Perl Contribuée par les Utilisateurs Perl::Critic::Utils::Constants(3pm)

NOM

Perl::Critic::Utils::Constants - Constantes globales.

DESCRIPTION

Définit les constantes couramment utilisées pour Perl::Critic.

SUPPORT D'INTERFACE

Ce module est considéré comme public. Tout changement apporté à son interface passera par un cycle de dépréciation.

CONSTANTES IMPORTABLES

$PROFILE_STRICTNESS_WARN
$PROFILE_STRICTNESS_FATAL
$PROFILE_STRICTNESS_QUIET
$PROFILE_STRICTNESS_DEFAULT
%PROFILE_STRICTNESSES
Valeurs valides pour l'option "-profile-strictness" de perlcritic. Détermine si les problèmes récupérables trouvés dans un fichier de profil apparaissent comme des avertissements, sont fatals ou sont ignorés. $PROFILE_STRICTNESS_DEFAULT est défini à $PROFILE_STRICTNESS_WARN. Importable via la balise ":profile_strictness".
$PROFILE_COLOR_SEVERITY_HIGHEST_DEFAULT
Défaut pour l'option -color-severity-highest. Importable via la balise ":color_severity".
$PROFILE_COLOR_SEVERITY_HIGH_DEFAULT
Défaut pour l'option -color-severity-high. Importable via la balise ":color_severity".
$PROFILE_COLOR_SEVERITY_MEDIUM_DEFAULT
Défaut pour l'option -color-severity-medium. Importable via la balise ":color_severity".
$PROFILE_COLOR_SEVERITY_LOW_DEFAULT
Défaut pour l'option -color-severity-low. Importable via la balise ":color_severity".
$PROFILE_COLOR_SEVERITY_LOWEST_DEFAULT
Défaut pour l'option -color-severity-lowest. Importable via la balise ":color_severity".
@STRICT_EQUIVALENT_MODULES
@WARNINGS_EQUIVALENT_MODULES
Comme leurs noms le suggèrent, il s'agit de listes de modules qui sont équivalents au chargement des pragmas strict ou warnings. À l'heure actuelle, les deux listes sont exactement identiques. Note : Ces listes ne sont pas exhaustives ; elles n'incluent que les modules les plus couramment utilisés. Les politiques qui utilisent ces listes devraient permettre la configuration de modules supplémentaires.
