Perl__Critic__OptionsProcessor(3pm)

Paquet: perl-perl-critic

Perl::Critic::OptionsProcessor(3pm) Documentation Perl Contribuée par la Communauté Perl::Critic::OptionsProcessor(3pm)

NOM

Perl::Critic::OptionsProcessor - Les valeurs par défaut de la configuration globale, combinées avec les valeurs de la ligne de commande.

DESCRIPTION

Ceci est une classe d'aide qui encapsule les paramètres par défaut pour la construction d'un objet Perl::Critic::Config. Il n'y a aucune partie utilisable par l'utilisateur ici.

SUPPORT D'INTERFACE

Ceci est considéré comme une classe non publique. Son interface peut changer sans préavis.

CONSTRUCTEUR

new( %DEFAULT_PARAMS )
Retourne une référence vers un nouvel objet "Perl::Critic::OptionsProcessor". Vous pouvez remplacer les valeurs par défaut codées en passant des paires nom-valeur correspondant aux méthodes listées ci-dessous.

Ceci n'est généralement invoqué que par Perl::Critic::UserProfile, qui passe les valeurs globales d'un fichier .perlcriticrc. Cet objet ne contient aucune information pour des Politiques individuelles.

MÉTHODES

exclude()
Retourne une référence vers une liste des motifs d'exclusion par défaut. S'il n'y a pas de motifs d'exclusion par défaut, la liste sera vide.
force()
Retourne la valeur par défaut du drapeau "force" (Soit 1 soit 0).
include()
Retourne une référence vers une liste des motifs d'inclusion par défaut. S'il n'y a pas de motifs d'exclusion par défaut, la liste sera vide.
only()
Retourne la valeur par défaut du drapeau "only" (Soit 1 soit 0).
profile_strictness()
Retourne la valeur par défaut de "profile_strictness" sous forme de chaîne non validée.
single_policy()
Retourne le motif "single-policy" par défaut. (Sous forme de chaîne.)
severity()
Retourne le paramètre "severity" par défaut. (1 à 5).
theme()
Retourne le paramètre "theme" par défaut. (Sous forme de chaîne).
top()
Retourne le paramètre "top" par défaut. (Soit 0 soit un entier positif).
verbose()
Retourne le paramètre "verbose" par défaut. (Soit un nombre soit une chaîne de format).
color()
Retourne le paramètre "color" par défaut. (Soit 1 soit 0).
pager()
Retourne le paramètre "pager" par défaut. (Soit une chaîne vide soit la chaîne de commande du pager).
allow_unsafe()
Retourne le paramètre "allow-unsafe" par défaut. (Soit 1 soit 0).
criticism_fatal()
Retourne le paramètre "criticism-fatal" par défaut (Soit 1 soit 0).
color_severity_highest()
Retourne la couleur à utiliser pour colorer les violations de sévérité la plus élevée.
color_severity_high()
Retourne la couleur à utiliser pour colorer les violations de sévérité élevée.
color_severity_medium()
Retourne la couleur à utiliser pour colorer les violations de sévérité moyenne.
color_severity_low()
Retourne la couleur à utiliser pour colorer les violations de sévérité faible.
color_severity_lowest()
Retourne la couleur à utiliser pour colorer les violations de sévérité la plus faible.
program_extensions()
Retourne une référence vers le tableau des extensions de nom de fichier à interpréter comme des programmes Perl.

VOIR AUSSI

Perl::Critic::Config, Perl::Critic::UserProfile
