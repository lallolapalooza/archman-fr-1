NOM

Perl::Critic::Policy::ControlStructures::ProhibitUnreachableCode - N'écrivez pas de code après un "die, exit, ou next" inconditionnel.

AFFILIATION

Cette politique fait partie de la distribution principale de Perl::Critic.

DESCRIPTION

Cette politique interdit le code suivant une instruction qui modifie inconditionnellement le flux du programme. Cela inclut les appels à "exit", "die", "return", "next", "last" et "goto". En raison de leur utilisation courante, "croak" et "confess" de Carp sont également inclus.

Le code est atteignable si l'une des conditions suivantes est vraie:

  • L'instruction modifiant le flux a une condition attachée
  • L'instruction se trouve à droite d'un opérateur "&&", "||", "//", "and", "or", ou "err".
  • Le code est précédé d'une étiquette (peut potentiellement être atteint via "goto")
  • Le code est une sous-routine

EXEMPLES

# pas ok
exit;
print "123\n";
# ok
exit if !$xyz;
print "123\n";
# pas ok
for ( 1 .. 10 ) {
    next;
    print 1;
}
# ok
for ( 1 .. 10 ) {
    next if $_ == 5;
    print 1;
}
# pas ok
sub foo {
    my $bar = shift;
    return;
    print 1;
}
# ok
sub foo {
    my $bar = shift;
    return if $bar->baz();
    print 1;
}
# pas ok
die;
print "123\n";
# ok
die;
LABEL: print "123\n";
# pas ok
croak;
do_something();
# ok
croak;
sub do_something {}

CONFIGURATION

Cette politique n'est pas configurable à l'exception des options standard.
