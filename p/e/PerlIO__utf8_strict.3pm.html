NOM

PerlIO::utf8_strict - E/S UTF-8 rapides et correctes

VERSION

version 0.010

SYNOPSIS

open my $fh, '<:utf8_strict', $filename;

DESCRIPTION

Ce module fournit une couche PerlIO UTF-8 rapide et correcte. Contrairement à la couche ":utf8" par défaut de Perl, elle vérifie la correction des données en entrée.

ARGUMENTS DE COUCHE

allow_noncharacters
allow_surrogates

EXPORT

PerlIO::utf8_strict n'exporte aucune sous-routine ni symbole, juste une couche Perl "utf8_strict".

DIAGNOSTICS

Impossible de décoder une séquence d'octets UTF-8 mal formée <%s>
(F) Rencontre d'une séquence d'octets UTF-8 mal formée. <%s> contient une représentation hexadécimale de la sous-séquence maximale mal formée.
Impossible d'interchanger le point de code non caractère U+%.4X
(F) Les points de code non caractères sont réservés de manière permanente pour un usage interne et ne doivent jamais être échangés. Les points de code non caractères comprennent les valeurs U+nFFFE et U+nFFFF (où n va de 0 à 10^16) et les valeurs U+FDD0..U+FDEF.
