NOM

Perl::Critic::Policy::Variables::ProhibitReusedNames - Ne pas réutiliser un nom de variable dans une portée lexicale

AFILIATION

Cette politique fait partie de la distribution principale de Perl::Critic.

DESCRIPTION

Il est vraiment difficile pour les futurs programmeurs de maintenance de réutiliser un nom de variable dans une portée lexicale. Le programmeur risque de confondre les variables. Et, pire encore, le programmeur pourrait accidentellement supprimer la déclaration interne, changeant ainsi silencieusement la signification du code interne pour utiliser la variable externe.

my $x = 1;
for my $i (0 .. 10) {
    my $x = $i+1;  # pas OK, "$x" réutilisé
}

Avec "use warnings" activé, Perl vous avertira si vous réutilisez un nom de variable au même niveau de portée mais pas dans des portées imbriquées. Comme ceci :

% perl -we 'my $x; my $x'
"my" variable $x masks earlier declaration in same scope at -e line 1.

Cette politique rend cet avertissement plus strict.

CAVEATS

Franchir les sous-routines

Cette politique examine les limites des sous-routines. Ainsi, le code suivant peut être un faux positif pour vous :

sub make_accessor {
    my ($self, $fieldname) = @_;
    return sub {
        my ($self) = @_;  # faux positif, $self déclaré comme réutilisé
        return $self->{$fieldname};
    }
}

Cependant, c'est intentionnel, car cela détecte des bugs comme celui-ci :

my $debug_mode = 0;
sub set_debug {
    my $debug_mode = 1;  # redéclaration accidentelle
}

Je l'ai fait moi-même plusieurs fois - c'est une forte habitude de mettre ce "my" devant les variables au début des sous-routines.

Performance

L'implémentation actuelle parcourt l'arbre de manière répétée. Pour un fichier volumineux, cela peut être un énorme goulet d'étranglement. J'envisage de réécrire pour rechercher le document une seule fois pour les déclarations de variables et de mettre en cache l'analyse de l'arbre lors de cette analyse unique.

CONFIGURATION

Cette politique a une seule option, "allow", qui est une liste de noms à ne jamais considérer comme des doublons. Elle contient par défaut $self et $class. Vous pouvez l'enrichir en ajoutant quelque chose comme ceci à votre fichier .perlcriticrc :

[Variables::ProhibitReusedNames]
allow = $self $class @blah
