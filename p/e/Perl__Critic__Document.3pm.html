Perl::Critic::Document(3pm) Documentation Perl fournie par l'utilisateur Perl::Critic::Document(3pm)

NOM

Perl::Critic::Document - Enveloppe de mise en cache autour d'un PPI::Document.

SYNOPSIS

use PPI::Document;
use Perl::Critic::Document;
my $doc = PPI::Document->new('Foo.pm');
$doc = Perl::Critic::Document->new(-source => $doc);
## Utilisez ensuite l'instance comme un PPI::Document

DESCRIPTION

Perl::Critic effectue de nombreuses itérations sur l'arbre du document PPI via la méthode PPI::Document::find(). Pour gagner du temps, cette classe met en cache bon nombre des appels find() courants lors d'un seul parcours. Ensuite, lors des demandes ultérieures, nous retournons les données mises en cache.

Ceci est implémenté comme une façade, où les appels de méthode sont transmis à l'instance "PPI::Document" stockée.

CAVEATS

Cette façade n'implémente pas les opérateurs surchargés de PPI::Document (c'est-à-dire le travail "use overload ..."). Par conséquent, les utilisateurs de cette façade ne doivent pas se fier à ce sucre syntaxique. Ainsi, par exemple, au lieu de "my $source = "$doc";", vous devriez écrire "my $source = $doc->content();".

Peut-être existe-t-il un module CPAN qui implémente une façade mieux que ce que nous faisons ici ?

SUPPORT D'INTERFACE

Ceci est considéré comme une classe publique. Tout changement de son interface passera par un cycle de dépréciation.

CONSTRUCTEUR

"new(-source => $source_code, '-filename-override' => $filename, '-program-extensions' => [program_extensions])"
Crée une nouvelle instance faisant référence à une instance de PPI::Document. Le $source_code peut être le nom d'un fichier, une référence à un scalaire contenant le code source réel, ou un PPI::Document ou PPI::Document::File.

Dans le cas où $source_code est une référence à un scalaire contenant le code source réel ou un PPI::Document, le Perl::Critic::Document résultant n'aura pas de nom de fichier. Cela peut amener Perl::Critic::Document à classifier incorrectement le code source comme un module ou un script. Pour éviter ce problème, vous pouvez éventuellement définir "-filename-override" pour forcer le Perl::Critic::Document à avoir un $filename particulier. N'utilisez pas cette option si $source_code est déjà le nom d'un fichier, ou est une référence à un PPI::Document::File.

L'argument '-program-extensions' est optionnel, et est une référence à une liste de chaînes et/ou d'expressions régulières. Les chaînes seront transformées en expressions régulières correspondant à la fin d'un nom de fichier, et tout document dont le nom de fichier correspond à l'une des expressions régulières sera considéré comme un programme.

Si -program-extensions n'est pas spécifié, ou s'il ne détermine pas le type de document, le document sera considéré comme un programme si la source a une ligne shebang ou si son nom de fichier (le cas échéant) correspond à "m/ [.] PL \z /smx".

MÉTHODES

ppi_document()
Accesseur pour l'instance PPI::Document enveloppée. Notez que la modification de cette instance de quelque manière que ce soit peut entraîner des échecs imprévisibles dans l'analyse ultérieure de Perl::Critic, car certains caches peuvent devenir obsolètes.
find($wanted)
find_first($wanted)
find_any($wanted)
Enveloppes de mise en cache autour des méthodes PPI. Si $wanted est un nom de classe PPI simple, le cache est utilisé. Sinon, nous transmettons l'appel à la méthode correspondante de l'instance "PPI::Document".
namespaces()
Retourne une liste des espaces de noms (noms de package) dans le document.
subdocuments_for_namespace($namespace)
Retourne une liste de sous-documents contenant les éléments de l'espace de noms donné. Par exemple, étant donné que le document actuel concerne le code source 
foo();
package Foo;
package Bar;
package Foo;

cette méthode retournera deux Perl::Critic::Documents pour un paramètre de "Foo". Pour en savoir plus, voir "split_ppi_node_by_namespace" dans PPIx::Utils::Traversal.

ppix_regexp_from_element($element)
Enveloppe de mise en cache autour de "PPIx::Regexp->new($element)". Si $element est un "PPI::Element", le cache est utilisé, sinon il retourne simplement les résultats de "PPIx::Regexp->new()". Dans les deux cas, il retourne "undef" à moins que l'argument ne soit quelque chose que PPIx::Regexp comprend réellement.
"element_is_in_lexical_scope_after_statement_containing( $inner, $outer )"
L'élément $inner est-il dans la portée lexicale après l'instruction contenant l'élément $outer ?

Dans le cas où $outer est lui-même un élément définissant la portée, retourne vrai si $outer contient $inner. Dans tout autre cas, $inner doit être après le dernier élément de l'instruction contenant $outer, et la portée la plus interne pour $outer contient également $inner.

Ce n'est pas la même chose que de demander si $inner est visible depuis $outer.

filename()
Retourne le nom de fichier du code source si applicable (PPI::Document::File) ou "undef" sinon (PPI::Document).
isa( $classname )
Pour être compatible avec d'autres modules qui s'attendent à recevoir un PPI::Document, la classe Perl::Critic::Document se fait passer pour la classe PPI::Document.
highest_explicit_perl_version()
Retourne un objet version pour la plus haute exigence de version Perl déclarée dans le document via une instruction "use" ou "require". Ne retourne rien s'il n'y a pas de déclaration de version.
uses_module($module_or_pragma_name)
Indique s'il y a un "use", "require", ou "no" du nom donné dans ce document. Notez qu'il n'y a pas de différenciation entre les modules et les pragmas ici.
process_annotations()
Fait en sorte que ce Document s'analyse lui-même et marque quelles lignes et quelles politiques sont désactivées par les annotations "## no critic".
"line_is_disabled_for_policy($line, $policy_object)"
Retourne vrai si l'objet $policy_object ou le nom de politique $policy_name donné a été désactivé pour la ligne $line dans ce Document. Sinon, retourne faux.
add_annotation( $annotation )
Ajoute un objet $annotation à ce Document.
annotations()
Retourne une liste contenant toutes les annotations Perl::Critic::Annotations qui ont été trouvées dans ce Document.

"permalink" href="#add_suppressed_violation($violation)">add_suppressed_violation($violation)
Informe ce Document qu'une $violation a été trouvée mais non signalée car elle tombait sur une ligne qui avait été supprimée par une annotation "## no critic". Retourne $self.
suppressed_violations()
Retourne une liste de références à tous les Perl::Critic::Violations qui ont été trouvés dans ce Document mais qui ont été supprimés.
is_program()
Retourne si ce document est considéré comme un programme.
is_module()
Retourne si ce document est considéré comme un module Perl.
