NOM

Perl::Critic::Policy::Subroutines::ProhibitExplicitReturnUndef - Retourner l'échec avec un simple "return" au lieu de "return undef".

AfFILIATION

Cette politique fait partie de la distribution principale de Perl::Critic.

DESCRIPTION

Retourner "undef" en cas d'échec depuis une sous-routine est assez courant. Mais si la sous-routine est appelée dans un contexte de liste, une instruction "return undef;" explicite retournera une liste à un seul élément contenant "(undef)". Or, si cette liste est ensuite mise dans un contexte booléen pour tester l'échec, elle sera évaluée comme vraie. Mais vous vouliez probablement qu'elle soit fausse.

sub read_file {
    my $file = shift;
    -f $file || return undef;  # le fichier n'existe pas !
    # Continuer la lecture du fichier...
}
# et plus tard...
if ( my @data = read_file($filename) ){
    # si $filename n'existe pas,
    # @data sera (undef),
    # mais je serai quand même ici !
    process(@data);
}
else{
    # C'est mon code de gestion d'erreurs.
    # Je veux probablement être ici
    # si $filename n'existe pas.
    die "$filename not found";
}

La solution est d'utiliser simplement une instruction "return" nue chaque fois que vous voulez retourner un échec. Dans un contexte de liste, Perl vous donnera alors une liste vide (qui est fausse), et "undef" dans un contexte scalaire (qui est également faux).

sub read_file {
    my $file = shift;
    -f $file || return;  # DWIM ! (Do What I Mean)
    # Continuer la lecture du fichier...
}

CONFIGURATION

Cette politique n'est pas configurable, sauf pour les options standard.

NOTES

Vous pouvez tromper cette politique assez facilement en cachant "undef" dans une expression booléenne. Mais ne vous embêtez pas à essayer. En fait, utiliser des valeurs de retour pour indiquer un échec est une technique assez médiocre de toute façon. Envisagez d'utiliser "die" ou "croak" avec "eval", ou le module Error pour un modèle de gestion d'exceptions beaucoup plus robuste. Conway discute très bien de la gestion des erreurs au chapitre 13 de PBP.
