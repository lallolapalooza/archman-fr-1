DESCRIPTION

Pour remplacer les fonctions dépréciées listées ci-dessus, les applications doivent utiliser le type EVP_PKEY et OSSL_DECODER_from_bio() et OSSL_ENCODER_to_bio() pour lire et écrire des données PEM contenant des paramètres de clé ou des clés privées et publiques.

Dans la description ci-dessous, TYPE est utilisé comme espace réservé pour n'importe quel type de données OpenSSL, tel que X509. La macro DECLARE_PEM_rw se développe dans l'ensemble des déclarations montrées dans les quatre lignes suivantes du synopsis.

Ces routines effectuent la conversion entre les instances locales des types de données ASN1 et l'encodage PEM. Pour plus d'informations sur les modèles, voir ASN1_ITEM(3). Pour plus d'informations sur les routines de niveau inférieur utilisées par les fonctions ici, voir PEM_read(3).

PEM_read_TYPE() lit un objet encodé en PEM de TYPE à partir du fichier fp et le retourne. Les paramètres cb et u sont tels que décrits dans pem_password_cb(3).

PEM_read_bio_TYPE() est similaire à PEM_read_TYPE() mais lit à partir du BIO bp.

PEM_write_TYPE() écrit l'encodage PEM de l'objet a dans le fichier fp.

PEM_write_bio_TYPE() écrit de manière similaire dans le BIO bp.

NOTES

Ces fonctions ne font aucune hypothèse concernant la phrase secrète reçue de la fonction de rappel de mot de passe. Elle sera simplement traitée comme une séquence d'octets.

VALEUR DE RETOUR

PEM_read_TYPE() et PEM_read_bio_TYPE() retournent un pointeur vers un objet alloué, qui doit être libéré en appelant TYPE_free(), ou NULL en cas d'erreur.

PEM_write_TYPE() et PEM_write_bio_TYPE() retournent 1 en cas de succès ou 0 en cas d'échec.
