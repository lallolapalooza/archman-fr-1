Perl::Critic::Policy::TestingAndDebugging::ProhibitNoWarnings(3pm) Documentation Perl fournie par l'utilisateur Perl::Critic::Policy::TestingAndDebugging::ProhibitNoWarnings(3pm)

NOM

Perl::Critic::Policy::TestingAndDebugging::ProhibitNoWarnings - Interdit diverses formes de "no warnings".

AFFILIATION

Cette politique fait partie de la distribution principale de Perl::Critic.

DESCRIPTION

Il existe de bonnes raisons pour désactiver certains types d'avertissements. Mais si vous avez été assez sage pour utiliser "use warnings" en premier lieu, alors il n'est pas logique de les désactiver complètement. Par défaut, toute instruction "no warnings" violera cette politique. Cependant, vous pouvez configurer cette politique pour autoriser la désactivation de certains types d'avertissements (voir "CONFIGURATION"). Une instruction "no warnings" nue déclenchera toujours une violation.

CONFIGURATION

Les types d'avertissements autorisés peuvent être configurés via l'option "allow". La valeur est une liste de types d'avertissements délimités par des espaces que vous souhaitez pouvoir désactiver. Voir perllexwarn pour une liste des types d'avertissements possibles. Un exemple de cette personnalisation :

[TestingAndDebugging::ProhibitNoWarnings]
allow = uninitialized once

Si une valeur vraie est spécifiée pour l'option "allow_with_category_restriction", alors tout "no warnings" qui restreint l'ensemble des avertissements désactivés sera valide.

[TestingAndDebugging::ProhibitNoWarnings]
allow_with_category_restriction = 1
