Perl::OSType(3perl) Guide du programmeur Perl Perl::OSType(3perl)

NOM

Perl::OSType - Mapper les noms de systèmes d'exploitation Perl vers des types génériques

VERSION

version 1.010

SYNOPSIS

use Perl::OSType ':all';
$current_type = os_type();
$other_type = os_type('dragonfly'); # donne 'Unix'

DESCRIPTION

Les modules qui fournissent des comportements spécifiques au système d'exploitation ont souvent besoin de savoir si le système d'exploitation actuel correspond à un type plus générique de systèmes d'exploitation. Par exemple, 'linux' est un type de système d'exploitation 'Unix' et 'freebsd' l'est aussi.

Ce module fournit un mappage entre un nom de système d'exploitation tel que donné par $^O et un type plus générique. La version initiale est basée sur les mappages de types d'OS fournis dans Module::Build et ExtUtils::CBuilder. (Ainsi, les systèmes d'exploitation Microsoft reçoivent le type 'Windows' plutôt que 'Win32'.)

UTILISATION

Aucune fonction n'est exportée par défaut. Le tag d'exportation ":all" exportera toutes les fonctions listées ci-dessous.

os_type()

$os_type = os_type();
$os_type = os_type('MSWin32');

Retourne un seul type d'OS générique pour un nom de système d'exploitation donné. Sans argument, retourne le type d'OS pour la valeur actuelle de $^O. Si le système d'exploitation n'est pas reconnu, la fonction retournera une chaîne vide.

is_os_type()

$is_windows = is_os_type('Windows');
$is_unix    = is_os_type('Unix', 'dragonfly');

Étant donné un type d'OS et un nom d'OS, retourne vrai ou faux si le nom d'OS est de ce type. Comme avec "os_type", il utilisera le système d'exploitation actuel par défaut si aucun nom d'OS n'est fourni.
