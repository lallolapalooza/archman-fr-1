NOM

Perl::Critic::Utils::McCabe - Fonctions qui calculent le score de McCabe du code source.

DESCRIPTION

Fournit des approximations des scores de McCabe. Le score de McCabe d'un ensemble de code décrit le nombre de chemins possibles à travers celui-ci. Les fonctions ici approximent le score de McCabe en additionnant le nombre d'instructions et d'opérateurs conditionnels dans un ensemble de code. Voir http://en.wikipedia.org/wiki/Cyclomatic_complexity pour une discussion sur le nombre de McCabe et d'autres métriques de complexité.

SUPPORT D'INTERFACE

Ceci est considéré comme un module public. Tout changement à son interface passera par un cycle de dépréciation.

SUBS IMPLTABLES

calculate_mccabe_of_sub( $sub )
Calcule une approximation du nombre de McCabe du code d'un PPI::Statement::Sub.
calculate_mccabe_of_main( $doc )
Calcule une approximation du nombre de McCabe de tout le code d'un PPI::Statement::Document qui n'est pas contenu dans une sous-routine.
