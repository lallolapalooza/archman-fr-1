NOM

Pegex::Tree::Wrap - Récepteur d'arbre d'analyse Pegex

SYNTAXE

use Pegex;
$tree = pegex($grammar, 'Pegex::Tree::Wrap')->parse($input);

DESCRIPTION

Pegex::Tree::Wrap est une classe réceptrice qui va structurer les données capturées à partir d'une opération d'analyse Pegex en un arbre composé de hachages. Les clés des hachages sont les noms des règles qui ont correspondu, et les valeurs sont des tableaux de données capturées.

Ce module n'est pas souvent utilisé comme classe de base réceptrice, mais c'est le récepteur par défaut pour une analyse Pegex. C'est parce que l'arbre est très lisible avec toutes les clés de règles qu'il contient.
