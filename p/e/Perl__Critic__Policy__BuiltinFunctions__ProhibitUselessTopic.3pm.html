Perl::Critic::Policy::BuiltinFunctions::ProhibitUselessTopic(3pm) Documentation Perl fournie par l'utilisateur Perl::Critic::Policy::BuiltinFunctions::ProhibitUselessTopic(3pm)

NOM

Perl::Critic::Policy::BuiltinFunctions::ProhibitUselessTopic - Ne pas passer $_ aux fonctions intégrées qui le supposent, ou à la plupart des opérateurs de test de fichier.

AFFILIATION

Cette politique fait partie de la distribution Perl::Critic.

DESCRIPTION

Il existe un certain nombre d'endroits où $_, ou la variable "topic", est inutile.

Sujet inutile pour certaines fonctions intégrées de Perl

De nombreuses fonctions intégrées de Perl opèrent sur $_ si aucun argument n'est passé. Par exemple, la fonction "length" opère sur $_ par défaut. Cet extrait :

for ( @list ) {
    if ( length( $_ ) == 4 ) { ...

est écrit de manière plus idiomatique comme suit :

for ( @list ) {
    if ( length == 4 ) { ...

Dans le cas de la fonction "split", le deuxième argument est celui qui prend par défaut $_. Cet extrait :

for ( @list ) {
    my @args = split /\t/, $_;

est mieux écrit comme suit :

for ( @list ) {
    my @args = split /\t/;

Il y a une fonction intégrée que cette politique ne vérifie pas : "reverse" appelée avec $_.

La fonction "reverse" n'opère sur $_ que si elle est appelée dans un contexte scalaire. Par conséquent :

for ( @list ) {
    my $backwards = reverse $_;

est mieux écrit comme suit :

for ( @list ) {
    my $backwards = reverse;

Cependant, la distinction entre contexte scalaire et liste pour "reverse" ne fonctionne pas encore. Voir ERREURS CONNUES ci-dessous.

Sujet inutile pour la plupart des opérateurs de test de fichier

Un autre endroit où $_ est inutile est avec un opérateur de test de fichier.

# Ces deux sont identiques.
my $size = -s $_;
my $size = -s;
# Ces deux sont identiques.
if ( -r $_ ) { ...
if ( -r ) { ...

L'exception est après l'opérateur de test de fichier "-t", qui au lieu de prendre par défaut $_, prend par défaut "STDIN".

# Ces deux ne sont PAS identiques.
if ( -t $_ ) { ...
if ( -t ) { ...  # Vérifie STDIN, pas $_

ERREURS CONNUES

Cette politique signale un faux positif sur "reverse" appelé dans un contexte de liste, car "reverse" dans un contexte de liste ne suppose pas $_.

my $s = reverse( $_ ); # $_ est inutile.
my @a = reverse( $_ ); # $_ n'est pas inutile ici.

CONFIGURATION

Cette politique n'est configurable qu'avec les options standard.
