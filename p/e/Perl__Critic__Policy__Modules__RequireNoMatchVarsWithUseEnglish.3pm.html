Perl::Critic::Policy::Modules::RequireNoMatchVarsWithUseEnglish(3pm) Documentation Perl fournie par l'utilisateur Perl::Critic::Policy::Modules::RequireNoMatchVarsWithUseEnglish(3pm)

NOM

Perl::Critic::Policy::Modules::RequireNoMatchVarsWithUseEnglish - "use English" doit recevoir un argument "-no_match_vars".

AFFILIATION

Cette politique fait partie de la distribution principale de Perl::Critic.

DESCRIPTION

En raison d'un historique malheureux, si vous utilisez le module English mais ne lui passez pas un argument "-no_match_vars", toutes les expressions régulières de l'intégralité du programme, et non seulement du module concerné, subissent une pénalité de performance significative, même si vous n'importez qu'un sous-ensemble des variables.

use English;                              # pas correct
use English '-no_match_vars';             # correct
use English qw< $ERRNO -no_match_vars >;  # correct
use English qw($OS_ERROR);                # pas correct

Dans le dernier exemple ci-dessus, bien que les variables de correspondance ne soient pas chargées dans votre espace de noms, elles sont tout de même créées dans l'espace de noms "English" et vous en payez toujours le coût.

CONFIGURATION

Cette politique n'est pas configurable, à l'exception des options standard.
