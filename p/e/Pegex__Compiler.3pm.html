NOM

Pegex::Compiler - Compilateur Pegex

SYNOPSIS

use Pegex::Compiler;
my $grammar_text = '... texte de la grammaire ...';
my $pegex_compiler = Pegex::Compiler->new();
my $grammar_tree = $pegex_compiler->compile($grammar_text)->tree;

ou :

perl -Ilib -MYourGrammarModule=compile

DESCRIPTION

Le module Pegex::Compiler transforme une chaîne de grammaire Pegex (ou un fichier) en une forme compilée. La forme compilée est connue sous le nom d'arbre de grammaire, qui est simplement une structure de données imbriquée.

L'arbre de grammaire peut être sérialisé en YAML, JSON, Perl, ou tout autre langage de programmation. Cela le rend extrêmement portable. Pegex::Grammar possède des méthodes pour sérialiser dans toutes ces formes.

NOTE : Sauf si vous développez des modules basés sur Pegex, vous pouvez ignorer ce module en toute sécurité. Même si c'est le cas, vous ne l'utiliserez probablement pas directement. Voir [Compilation sur place] ci-dessous.

MÉTHODES

Les méthodes publiques suivantes sont disponibles :

"$compiler = Pegex::Compiler->new();"
Retourne un nouvel objet Pegex::Compiler.
"$grammar_tree = $compiler->compile($grammar_input);"
Compile un texte de grammaire en un arbre de grammaire utilisable par un Pegex::Parser. Cette méthode appelle les méthodes "parse" et "combinate" et retourne l'arbre résultant.

L'entrée peut être une chaîne de caractères, une référence de chaîne de caractères, un chemin de fichier, un descripteur de fichier, ou un objet Pegex::Input. Retourne $self pour permettre l'enchaînement à d'autres méthodes.

"$compiler->parse($grammar_text)"
La première étape d'une "compile" est "parse". Celle-ci applique la grammaire du langage Pegex à votre texte de grammaire et produit un arbre non optimisé.

Cette méthode retourne $self pour permettre l'enchaînement à d'autres méthodes.

"$compiler->combinate()"
Avant qu'un arbre de grammaire Pegex puisse être utilisé pour analyser des choses, il doit être combiné. Ce processus transforme les jetons regex en vraies expressions régulières. Il combine également certaines règles ensemble et élimine les règles qui ne sont pas nécessaires ou qui ont été combinées. Le résultat est un arbre de grammaire Pegex utilisable par un Pegex::Parser.

NOTE : Bien que la phase d'analyse d'une compilation soit toujours la même pour divers langages de programmation, la phase de combinaison prend en compte les besoins spécifiques du langage cible. Pegex::Compiler ne combine que pour Perl, bien que cela soit souvent suffisant dans des langages similaires comme Ruby ou Python (expressions régulières basées sur PCRE). Des langages comme Java nécessitent probablement d'utiliser leurs propres combinateurs.

"$compiler->tree()"
Retourne l'état actuel de l'arbre de grammaire (sous forme de référence de hachage).
"$compiler->to_yaml()"
Sérialise l'arbre de grammaire actuel en YAML.
"$compiler->to_json()"
Sérialise l'arbre de grammaire actuel en JSON.
"$compiler->to_perl()"
Sérialise l'arbre de grammaire actuel en Perl.

COMPILATION SUR PLACE

Lorsque vous écrivez un module basé sur Pegex, vous voudrez pré-compiler votre grammaire en Perl afin qu'il n'y ait pas de pénalité au chargement. Pegex::Grammar fournit un mécanisme spécial pour cela. Supposons que vous ayez une classe comme celle-ci :

package MyThing::Grammar;
use Pegex::Base;
extends 'Pegex::Grammar';
use constant file => '../mything-grammar-repo/mything.pgx';
sub make_tree {
}

Utilisez simplement cette commande :

perl -Ilib -MMyThing::Grammar=compile

et Pegex::Grammar appellera Pegex::Compile pour insérer votre grammaire compilée à l'intérieur de votre sous-routine "make_tree". Il écrira réellement le texte dans votre module. Cela rend trivial la mise à jour de votre module de grammaire après avoir apporté des modifications au fichier de grammaire.

Voir Pegex::JSON pour un exemple.
