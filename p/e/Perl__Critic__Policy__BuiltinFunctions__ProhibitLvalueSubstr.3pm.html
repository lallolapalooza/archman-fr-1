Perl::Critic::Policy::BuiltinFunctions::ProhibitLvalueSubstr(3pm) Documentation Perl fournie par l'utilisateur Perl::Critic::Policy::BuiltinFunctions::ProhibitLvalueSubstr(3pm)

NOM

Perl::Critic::Policy::BuiltinFunctions::ProhibitLvalueSubstr - Utiliser « substr » avec 4 arguments au lieu d'écrire « substr($foo, 2, 6) = $bar ».

AFFILIATION

Cette politique fait partie de la distribution principale de Perl::Critic.

DESCRIPTION

Conway déconseille l'utilisation de substr() comme lvaleur, recommandant plutôt d'utiliser la version à 4 arguments de substr().

substr($quelquechose, 1, 2) = $nouvellevaleur;     # pas bien
substr($quelquechose, 1, 2, $nouvellevaleur);      # bien

La forme à quatre arguments de substr() a été introduite dans Perl 5.005. Cette politique ne signale pas de violations sur du code qui spécifie explicitement une version antérieure de Perl (par exemple, "use 5.004;").

CONFIGURATION

Cette politique n'est pas configurable, à l'exception des options standard.

VOIR AUSSI

"substr" dans perlfunc (ou "perldoc -f substr").

"4th argument to substr" dans perl5005delta
