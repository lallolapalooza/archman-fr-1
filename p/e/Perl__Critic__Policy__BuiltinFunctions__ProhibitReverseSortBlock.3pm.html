NOM

Perl::Critic::Policy::BuiltinFunctions::ProhibitReverseSortBlock - Interdire $b avant $a dans les blocs de tri.

AFfILIATION

Cette politique fait partie de la distribution principale de Perl::Critic.

DESCRIPTION

Conway dit qu'il est beaucoup plus clair d'utiliser "reverse" que d'inverser $a et $b dans un bloc "sort". Il suggère également que, dans les versions plus récentes de Perl, "reverse" est spécifiquement recherché et optimisé, et dans le cas d'un simple tri de chaînes inversé, utiliser "reverse" avec un "sort" sans bloc est plus rapide même dans les anciennes versions de Perl.

my @foo = sort { $b cmp $a } @bar;         # pas bon
my @foo = reverse sort @bar;               # bon
my @foo = sort { $b <=> $a } @bar;         # pas bon
my @foo = reverse sort { $a <=> $b } @bar; # bon

CONFIGURATION

Cette politique n'est configurable qu'avec les options standard.
