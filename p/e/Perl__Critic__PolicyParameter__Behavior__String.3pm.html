NOM

Perl::Critic::PolicyParameter::Behavior::String - Actions appropriées pour un paramètre de chaîne simple.

DESCRIPTION

Fournit un ensemble standard de fonctionnalités pour un paramètre Perl::Critic::PolicyParameter de type chaîne afin que le développeur d'une politique n'ait pas à le fournir lui-même.

NOTE : N'instanciez pas cette classe. Utilisez l'instance singleton conservée par Perl::Critic::PolicyParameter.

SUPPORT D'INTERFACE

Ceci est considéré comme une classe non publique. Son interface peut changer sans préavis.

MÉTHODES

"initialize_parameter( $parameter, $specification )"
Injecte la fonctionnalité fournie par ce comportement dans le paramètre. Actuellement, ce comportement n'est pas personnalisable par la spécification.
