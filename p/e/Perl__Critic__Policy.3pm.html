Perl::Critic::Policy(3pm) Documentation de contribution Perl Perl::Critic::Policy(3pm)

NOM

Perl::Critic::Policy - Classe de base pour tous les modules de politique.

DESCRIPTION

Perl::Critic::Policy est la classe abstraite pour tous les objets de politique. Si vous développez vos propres politiques, votre tâche est d'implémenter et de surcharger ses méthodes dans une classe dérivée. Pour travailler avec le moteur Perl::Critic, votre implémentation doit se comporter comme décrit ci-dessous. Pour une explication plus détaillée sur la façon de créer de nouveaux modules de politique, veuillez consulter le document de développement Perl::Critic::DEVELOPER inclus dans cette distribution.

SUPPORT D'INTERFACE

Ceci est considéré comme une classe publique. Tout changement à son interface sera soumis à un cycle d'obsolescence.

MÉTHODES

new( ... )
Ne l'appelez pas. En tant qu'auteur de politique, n'implémentez pas cette méthode. Utilisez la méthode initialize_if_enabled() pour la configuration de votre politique. Voir la documentation de développement pour plus de détails.
initialize_if_enabled( $config )
Reçoit un objet de type Perl::Critic::PolicyConfig en paramètre, et n'est invoqué que si cette politique est activée par l'utilisateur. C'est donc l'endroit préféré pour effectuer toute initialisation dans les classes dérivées.

Les implémentations de cette méthode doivent retourner une valeur booléenne indiquant si la politique doit continuer à être activée. Pour la plupart des classes dérivées, cette valeur sera toujours $TRUE. Les politiques qui dépendent de modules externes ou d'autres éléments du système qui peuvent ou non être disponibles doivent tester la disponibilité de ces dépendances et retourner $FALSE si elles ne sont pas disponibles.

prepare_to_scan_document( $document )
Le paramètre est le document qui doit être analysé par cette politique. Tout ce que cette politique doit faire en termes de préparation doit se passer ici. Retourne une valeur booléenne indiquant si le document doit être analysé ; si cette valeur est fausse, cette politique ne s'appliquera pas au document. Par défaut, ne fait rien mais retourne $TRUE.
" violates( $element, $document ) "
Prend en entrée un PPI::Element et un PPI::Document, retourne un objet de type Perl::Critic::Violation si le $element viole cette politique. S'il n'y a pas de violations, retourne une liste vide. Si la politique rencontre une erreur, elle doit "croak" avec un message d'erreur et laisser l'appelant décider comment le gérer.
" violation( $description, $explanation, $element ) "
Retourne un objet de type Perl::Critic::Violation. Les arguments sont une description de la violation (en chaîne de caractères), une explication pour la politique (en chaîne de caractères) ou une liste de pages dans PBP (en référence à un tableau) et une référence à un élément PPI qui a causé la violation.
" new_parameter_value_exception( $option_name, $option_value, $source, $message_suffix ) "
Crée un objet de type Perl::Critic::Exception::Configuration::Option::Policy::ParameterValue pour cette politique.
" throw_parameter_value_exception( $option_name, $option_value, $source, $message_suffix ) "
Crée et lance un objet de type Perl::Critic::Exception::Configuration::Option::Policy::ParameterValue. Utile dans les implémentations de paramètres de parser.
get_long_name()
Retourne le nom complet du package de cette politique.
get_short_name()
Retourne le nom de cette politique sans le préfixe "Perl::Critic::Policy::".
is_enabled()
Indique si cette politique est effectivement activée ou non. Retourne vrai si elle l'est, faux, mais défini si elle ne l'est pas, et undefined si il n'a pas encore été décidé si elle sera active.
applies_to()
Retourne une liste des noms de classes PPI qui intéressent cette politique. Par défaut, le résultat est "PPI::Element". La surcharge de cette méthode dans les classes dérivées de politique devrait entraîner une amélioration significative des performances.
default_maximum_violations_per_document()
Retourne le nombre maximum de violations que cette politique doit signaler par document. Par défaut, cette valeur n'est pas définie, mais les classes dérivées peuvent la surcharger.
get_maximum_violations_per_document()
Retourne le nombre maximum de violations que cette politique signalera par document. Si cette valeur n'est pas définie, il n'y a pas de limite. Si "set_maximum_violations_per_document()" n'a pas été appelée, "default_maximum_violations_per_document()" est retournée.
set_maximum_violations_per_document()
Définit le nombre maximum de violations que cette politique doit signaler par document.
default_severity()
Retourne le niveau de gravité par défaut pour la violation de cette politique. Voir les constantes "$SEVERITY" dans Perl::Critic::Utils pour une énumération des valeurs de gravité possibles. Par défaut, cette méthode retourne "$SEVERITY_LOWEST". Les auteurs de classes dérivées de Perl::Critic::Policy devraient surcharger cette méthode pour retourner une valeur appropriée pour leur politique. En général, les politiques largement acceptées ou qui tendent à prévenir les erreurs devraient avoir un niveau de gravité plus élevé que celles qui sont plus subjectives ou d'aspect esthétique.
get_severity()
Retourne la gravité de la violation de cette politique. Si le niveau de gravité n'a pas été explicitement défini en appelant "set_severity()", "default_severity()" est retournée. Voir les constantes "$SEVERITY" dans Perl::Critic::Utils pour une énumération des valeurs de gravité possibles.
set_severity( $N )
Définit la gravité pour la violation de cette politique. Les clients des objets Perl::Critic::Policy peuvent appeler cette méthode pour attribuer une gravité différente à la politique s'ils ne correspondent pas à la valeur par défaut "default_severity()". Voir les constantes "$SEVERITY" dans Perl::Critic::Utils pour une énumération des valeurs possibles.
default_themes()
Retourne une liste ordonnée des thèmes par défaut associés à cette politique. La méthode par défaut retourne une liste vide. Les auteurs de politiques devraient surcharger cette méthode pour retourner une liste de thèmes appropriés pour leur politique.
get_themes()
Retourne une liste ordonnée des thèmes associés à cette politique. Si vous n'avez pas ajouté de thèmes ni spécifié explicitement, cette méthode retourne les thèmes par défaut.
set_themes( @THEME_LIST )
Attribue les thèmes associés à cette politique. Les thèmes existants sont écrasés. Les doublons de thèmes sont supprimés.
add_themes( @THEME_LIST )
Ajoute des thèmes supplémentaires à cette politique. Les thèmes existants sont conservés. Les doublons de thèmes sont supprimés.
get_abstract()
Récupère le résumé de cette politique (partie de la section NOM du POD après le nom du module), si disponible.

NOM

Perl::Critic::Policy est un module Perl qui fournit des politiques pour l'analyse de code.

DESCRIPTION

Perl::Critic::Policy est un module Perl qui fournit des politiques pour l'analyse de code.

SUPPORT D'INTERFACE

Perl::Critic::Policy offre une interface simple aux développeurs pour créer leurs propres politiques.

MÉTHODES

Perl::Critic::Policy fournit des méthodes pour récupérer des informations sur les politiques et effectuer des analyses.

DOCUMENTATION

Lorsque votre module de politique "use" Perl::Critic::Violation pour la première fois, il essaiera d'extraire la section DESCRIPTION du POD de votre module de politique. Ces informations sont affichées par Perl::Critic si le niveau de verbosité est défini en conséquence. Par conséquent, veuillez inclure une section DESCRIPTION dans le POD de tout module de politique que vous écrivez. Merci.

SURCHARGES

Perl::Critic::Violation surcharge l'opérateur "" pour produire de jolis petits messages lorsqu'il est évalué dans un contexte de chaîne de caractères.

Les formats sont une combinaison de caractères littéraux et d'échappement, similaires à la façon dont fonctionne "sprintf". Si vous voulez connaître les capacités de formatage spécifiques, regardez String::Format. Les caractères d'échappement valides sont :

%P
Le nom du module de politique.
%p
Le nom de la politique sans le préfixe "Perl::Critic::Policy::".
%a
Le résumé de la politique.
%O
Une liste des paramètres de politique pris en charge. Elle prend une chaîne de format pour la méthode to_formatted_string de Perl::Critic::PolicyParameter. Par exemple, cela peut être utilisé comme "%{%n - %d\n}O" pour obtenir une liste des noms de paramètres suivis de leurs descriptions.
%U
Un message indiquant que les paramètres de la politique sont inconnus si parameter_metadata_available() renvoie false. Elle prend une option pour le message qui sera affiché, par défaut "Impossible de découvrir par programmation quels paramètres cette politique prend.". La valeur de cette option est interpolée pour développer les séquences d'échappement standard ("\n", "\t", etc.).
%S
Le niveau de gravité par défaut de la politique.
%s
Le niveau de gravité actuel de la politique.
%T
Les thèmes par défaut de la politique.
%t
Les thèmes actuellement utilisés par la politique.
%V
Le nombre maximal d'infractions par document par défaut de la politique.
%v
Le nombre maximal d'infractions par document actuel de la politique.
