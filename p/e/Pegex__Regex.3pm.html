NOM

Pegex::Regex - Utiliser Pegex comme une Expression Régulière

SYNTAXE

{
    # Activer les expressions régulières Pegex dans la portée lexicale.
    use Pegex::Regex;
    my $grammaire = qr{$texte_grammaire}x;
    $texte =~ $grammaire;
    my $resultat = \%/;
    # Désactiver Pegex dans cette portée.
    no Pegex::Regex;
}

DESCRIPTION

Ceci est un module de sucre syntaxique trivial qui vous permet d'utiliser les grammaires de parseur Pegex comme des expressions régulières, si vous êtes de ce genre de choses.

Il s'agit essentiellement d'un clone de l'API du module Regexp::Grammars de Damian Conway. Vous placez une grammaire dans un "qr{...}x" et l'appliquez à la chaîne d'entrée que vous souhaitez analyser. Si l'analyse réussit, vous obtenez une structure de données du contenu dans "%/".

Personnellement, construire un analyseur récursif descendant entièrement à l'intérieur d'une expression régulière n'est pas la façon la plus claire de coder. Mais, bien sûr, TMTOWTDI. :)

NOTE

Ce module est juste pour le fun expérimental. Voir Pegex pour la bonne façon d'utiliser le framework d'analyse Pegex.

TMTOWTDI

Voici un extrait de code Pegex::Regex :

use Pegex::Regex;
$texte =~ qr{... texte de grammaire Pegex ...};
$donnees = \%/;

Et le code Pegex équivalent :

use Pegex;
my $donnees = pegex('... texte de grammaire Pegex ...')->parse($texte);

ATTENTION

Cette porte d'entrée, euh, ce module, techniquement ne devrait même pas fonctionner.

Il transforme votre "grammaire dans une expression régulière" en un Pegex::Grammar en utilisant le surcharge de qr{}, puis transforme votre expression régulière elle-même en un shim qui appelle la méthode parse pour vous. C'est très magique et techniquement, cela fait un appel réentrant au moteur d'expressions régulières, ce qui n'est pas encore pris en charge. Utilisez à vos risques et périls.

Mieux encore, faites-vous une faveur et apprenez à utiliser la boîte à outils Pegex sans ce sucre ::Regex. ":-)"
