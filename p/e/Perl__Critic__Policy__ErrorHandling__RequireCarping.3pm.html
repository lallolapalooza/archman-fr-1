Perl::Critic::Policy::ErrorHandling::RequireCarping(3pm) Documentation Perl contribuée par l'utilisateur Perl::Critic::Policy::ErrorHandling::RequireCarping(3pm)

NOM

Perl::Critic::Policy::ErrorHandling::RequireCarping - Utiliser les fonctions de Carp au lieu de "warn" ou "die".

AFFILIATION

Cette politique fait partie de la distribution principale de Perl::Critic.

DESCRIPTION

Les fonctions "die" et "warn" signalent toutes deux le fichier et le numéro de ligne où l'exception s'est produite. Mais si quelqu'un d'autre utilise votre sous-routine, il ne se soucie généralement pas de l'endroit où votre code a échoué. Au lieu de cela, il veut savoir où son code a invoqué la sous-routine. Le module Carp fournit des méthodes alternatives qui signalent l'exception à partir du fichier et du numéro de ligne de l'appelant.

Par défaut, cette politique ne se plaindra pas de "die" ou "warn", si elle peut déterminer que le message entraînera toujours un retour à la ligne du terminal. Comme Perl supprime les noms de fichiers et les numéros de ligne dans cette situation, on suppose qu'aucune trace de pile n'est non plus souhaitée et qu'aucune des fonctions de Carp n'est nécessaire.

die "oops" if $explosion;             #pas ok
warn "Where? Where?!" if $tiger;      #pas ok
open my $mouth, '<', 'food'
    or die 'of starvation';           #pas ok
if (! $dentist_appointment) {
    warn "You have bad breath!\n";    #ok
}
die "$clock not set.\n" if $no_time;  #ok
my $message = "$clock not set.\n";
die $message if $no_time;             #pas ok, pas évident

CONFIGURATION

Par défaut, cette politique autorise les utilisations de "die" et "warn" se terminant par un retour à la ligne explicite. Si vous donnez à cette politique une option "allow_messages_ending_with_newlines" dans votre .perlcriticrc avec une valeur fausse, alors cette politique interdira de telles utilisations.

[ErrorHandling::RequireCarping]
allow_messages_ending_with_newlines = 0

Si vous donnez à cette politique une option "allow_in_main_unless_in_subroutine" dans votre .perlcriticrc avec une valeur vraie, alors cette politique autorisera "die" et "warn" dans l'espace de noms main:: à moins qu'ils n'apparaissent dans une sous-routine, même s'ils ne se terminent pas par un retour à la ligne explicite.

[ErrorHandling::RequireCarping]
allow_in_main_unless_in_subroutine = 1

BOGUES

Devrait autoriser "die" lorsqu'il est évident que le "message" est une référence.

VOIR AUSSI

Carp::Always
