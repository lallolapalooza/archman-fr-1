Perl::Critic::Policy::Variables::ProtectPrivateVars(3pm) Documentation Perl fournie par l'utilisateur Perl::Critic::Policy::Variables::ProtectPrivateVars(3pm)

NOM

Perl::Critic::Policy::Variables::ProtectPrivateVars - Empêche l'accès aux variables privées dans d'autres paquets.

AFfILIATION

Cette politique fait partie de la distribution principale de Perl::Critic.

DESCRIPTION

Par convention, les auteurs Perl (comme les auteurs de nombreux autres langages) indiquent les méthodes et variables privées en insérant un tiret bas de début avant l'identifiant. Cette politique intercepte les tentatives d'accès aux variables privées depuis l'extérieur du paquet lui-même.

CONFIGURATION

Cette politique n'est pas configurable, sauf pour les options standard.

HISTORIQUE

Cette politique est inspirée d'un test similaire dans B::Lint
