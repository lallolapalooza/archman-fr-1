Perl::Critic::Policy::CodeLayout::ProhibitQuotedWordLists(3pm) Documentation Perl Contribuée par les utilisateurs Perl::Critic::Policy::CodeLayout::ProhibitQuotedWordLists(3pm)

NOM

Perl::Critic::Policy::CodeLayout::ProhibitQuotedWordLists - Écrire "qw(foo bar baz)" au lieu de "('foo', 'bar', 'baz')".

AFILIATION

Cette politique fait partie de la distribution principale de Perl::Critic.

DESCRIPTION

Conway ne mentionne pas cela, mais je pense que qw() est une fonctionnalité sous-utilisée de Perl. Chaque fois que vous avez besoin de déclarer une liste de littéraux d'un seul mot, l'opérateur qw() est merveilleusement concis, et il est facile d'y ajouter des éléments à l'avenir.

@list = ('foo', 'bar', 'baz');  # pas ok
@list = qw(foo bar baz);        # ok
use Foo ('foo', 'bar', 'baz');  # pas ok
use Foo qw(foo bar baz);        # ok

CONFIGURATION

Cette politique peut être configurée pour ne prêter attention qu'aux listes de mots comportant au moins un certain nombre d'éléments. Par défaut, cette valeur est de 2, ce qui signifie que les listes contenant zéro ou un élément sont ignorées. La taille minimale de la liste à examiner peut être spécifiée en donnant une valeur pour "min_elements" dans le fichier .perlcriticrc comme suit :

[CodeLayout::ProhibitQuotedWordLists]
min_elements = 4

Cela ferait que cette politique ne se plaindrait que des listes contenant quatre mots ou plus.

Par défaut, cette politique ne se plaindra pas si l'une des valeurs de la liste contient des caractères non-mot. Si vous souhaitez qu'elle le fasse, définissez l'option "strict" à une valeur vraie.

[CodeLayout::ProhibitQuotedWordLists]
strict = 1

NOTES

Dans le langage de PPI, une "liste" est presque tout ce qui contient des parenthèses. J'ai essayé de rendre cette politique intelligente en ciblant uniquement les "listes" qui pourraient être exprimées de manière sensée avec qw(). Cependant, il peut y avoir quelques cas limites que je n'ai pas couverts. Si vous en trouvez un, envoyez-moi une note.

CHANGEMENTS IMPORTANTS

Cette politique s'appelait auparavant "RequireQuotedWords", ce qui semblait un peu contre-intuitif. Si vous obtenez de nombreuses erreurs de type "Impossible de charger le module de politique", vous devrez probablement changer "RequireQuotedWords" en "ProhibitQuotedWordLists" dans votre fichier .perlcriticrc.
