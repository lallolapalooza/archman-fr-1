NOM

Perl::Critic::Policy::ControlStructures::ProhibitMutatingListFunctions - Ne pas modifier de fonctions de liste avec mutation.

AFFILIATION

Cette politique fait partie de la distribution principale de Perl::Critic.

DESCRIPTION

"map", "grep" et d'autres opérateurs de liste sont destinés à transformer des tableaux en d'autres tableaux en appliquant du code aux éléments du tableau un par un. Pour des raisons de vitesse, les éléments sont référencés via un alias $_ plutôt que d'être copiés. En conséquence, si le bloc de code de "map" ou "grep" modifie $_ de quelque manière que ce soit, il modifie en fait le tableau source. Ceci est techniquement autorisé, mais ces effets secondaires peuvent être assez surprenants, surtout lorsque le tableau passé est @_ ou peut-être values(%ENV) ! Les auteurs devraient plutôt restreindre la modification de tableau en place aux constructions "for(@array) { ... }", ou utiliser List::SomeUtils:apply() ou List::MoreUtils::apply().

CONFIGURATION

Par défaut, cette politique s'applique aux fonctions de liste suivantes :

map grep
List::Util qw(first)
List::MoreUtils qw(any all none notall true false firstidx
                   first_index lastidx last_index insert_after
                   insert_after_string)
List::SomeUtils qw(any all none notall true false firstidx
                   first_index lastidx last_index insert_after
                   insert_after_string)

Cette liste peut être remplacée dans le fichier .perlcriticrc comme suit :

[ControlStructures::ProhibitMutatingListFunctions]
list_funcs = map grep List::Util::first

Ou, on peut simplement ajouter à la liste comme ceci :

[ControlStructures::ProhibitMutatingListFunctions]
add_list_funcs = Foo::Bar::listmunge

LIMITATIONS

Cette politique ne s'applique délibérément pas à "for (@array) { ... }" ou List::MoreUtils::apply() List::SomeUtils::apply().

Actuellement, la politique ne détecte que l'utilisation explicite de modules externes comme ceci :

my @out = List::MoreUtils::any {s/^foo//} @in;
my @out = List::SomeUtils::any {s/^foo//} @in;

et non comme ceci :

use List::MoreUtils qw(any);
my @out = any {s/^foo//} @in;
use List::SomeUtils qw(any);
my @out = any {s/^foo//} @in;

Cette politique ne recherche que les modifications de $_. D'autres actions indésirables pourraient inclure la modification de $a et $b dans "sort" et autres. Cela est hors de la portée de cette politique.
