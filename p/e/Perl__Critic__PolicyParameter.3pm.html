Perl::Critic::PolicyParameter(3pm) Documentation Perl fournie par l'utilisateur Perl::Critic::PolicyParameter(3pm)

NOM

Perl::Critic::PolicyParameter - Métadonnées sur un paramètre pour une Politique.

DESCRIPTION

Un fournisseur de validation et d'analyse des valeurs de paramètres et des métadonnées sur le paramètre.

SUPPORT D'INTERFACE

Ceci est considéré comme une classe publique. Tout changement dans son interface passera par un cycle de dépréciation.

MÉTHODES

get_name()
Retourne le nom du paramètre. C'est la clé qui sera recherchée dans le fichier .perlcriticrc.
get_description()
Retourne une explication de la signification du paramètre, telle que fournie par le développeur de la politique.
get_default_string()
Retourne une représentation de la valeur par défaut de ce paramètre telle qu'elle apparaîtrait si elle était spécifiée dans un fichier .perlcriticrc.
"parse_and_validate_config_value( $parser, $config )"
Extrait la valeur de configuration pour ce paramètre de la configuration globale et initialise la politique sur cette base.
generate_full_description()
Produit une explication plus complète de la signification de ce paramètre que la valeur retournée par get_description().

Si aucune description ne peut être dérivée, retourne une chaîne vide.

Notez que le résultat peut contenir plusieurs lignes.

to_formatted_string( $format )
Génère une représentation sous forme de chaîne de ce paramètre, basée sur le format.

Le format est une combinaison de caractères littéraux et d'échappement similaire au fonctionnement de "sprintf". Si vous voulez connaître les capacités de formatage spécifiques, regardez String::Format. Les caractères d'échappement valides sont :

%n
Le nom du paramètre.
%d
La description, telle que fournie par le programmeur.
%D
La valeur par défaut, sous forme analysable.
%f
La description complète, qui est une extension de la valeur retournée par %d. Prend un paramètre de préfixe pour le début de chaque ligne.
