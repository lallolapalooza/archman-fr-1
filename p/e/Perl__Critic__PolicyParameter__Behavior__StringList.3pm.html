NOM

Perl::Critic::PolicyParameter::Behavior::StringList - Actions appropriées pour un paramètre qui est une liste de chaînes de caractères.

DESCRIPTION

Fournit un ensemble standard de fonctionnalités pour un paramètre de politique Perl::Critic de type liste de chaînes de caractères, afin que le développeur d'une politique n'ait pas à le fournir lui-même.

NOTE : N'instanciez pas cette classe. Utilisez l'instance singleton maintenue par Perl::Critic::PolicyParameter.

SUPPORT D'INTERFACE

Ceci est considéré comme une classe non publique. Son interface peut changer sans préavis.

MÉTHODES

"initialize_parameter( $parameter, $specification )"
Greffe la fonctionnalité fournie par ce comportement au paramètre, en se basant sur la configuration fournie par la spécification.

Ce comportement recherche un élément de configuration :

valeurs_toujours_presentes
Optionnel. Valeurs qui devraient toujours être incluses, indépendamment de ce que spécifie la configuration du paramètre, sous forme de référence de tableau.
generer_description_parametre( $parameter )
Crée une description du paramètre, en se basant sur la description du paramètre lui-même, mais en l'enrichissant avec des informations de ce comportement.

Dans ce cas précis, les valeurs toujours présentes sont ajoutées à la fin.
