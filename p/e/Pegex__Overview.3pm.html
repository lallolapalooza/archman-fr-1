Qu'est-ce que Pegex ?

Pegex est un framework de parser PEG (Parser Expression Grammars) amical et acméiste. Amical signifie qu'il est simple de créer, comprendre, modifier et maintenir des parsers Pegex. Acméiste signifie que les parsers fonctionneront automatiquement dans de nombreux langages de programmation (tant qu'ils disposent d'une sorte de support « regex » traditionnel). PEG est le nouveau style de syntaxe de définition de grammaire de style Descendant Récursif/BNF.

Le nom « Pegex » vient de PEG + Regex. Avec Pegex, vous définissez des grammaires descendantes qui finissent par se décomposer en fragments regex. Autrement dit, les correspondances de bas niveau de l'analyse sont toujours effectuées avec des regex sur la position actuelle dans le flux d'entrée.

Qu'est-ce que l'analyse ?

Cela peut sembler une question idiote, mais il est important de comprendre ce qu'est l'analyse et ce qu'un parser peut faire pour vous. Au niveau le plus élémentaire, « l'analyse » est l'acte de lire une entrée, d'en comprendre le sens et éventuellement d'agir sur ce qui est trouvé.

Habituellement, un parser obtient ses instructions sur ce que signifie quoi de quelque chose appelé une grammaire. Une grammaire est un ensemble de règles qui définit comment l'entrée doit être structurée. Dans de nombreuses méthodologies d'analyse, l'entrée est prétraitée (éventuellement en tokens) avant que le parser/grammaire ne l'examine. Bien que ce soit une méthode courante, ce n'est pas la seule approche.

Comment fonctionne Pegex

L'analyse Pegex se compose de 4 parties ou objets distincts :

Parser
Le moteur d'analyse Pegex
Grammar
Les règles d'une syntaxe particulière
Receiver
La logique pour le traitement des correspondances
Input
Texte conforme aux règles de grammaire

Très simplement, un objet parser est créé avec un objet grammar et un objet receiver. Ensuite, la méthode parse() de l'objet parser est appelée sur un objet d'entrée. Le parser applique les règles de la grammaire à l'entrée et invoque des méthodes du receiver au fur et à mesure que les règles correspondent. L'analyse est soit réussie, soit entraîne une erreur. Le résultat est ce que l'objet receiver décide qu'il doit être.

Par exemple, considérons un parser qui convertit le langage texte Markdown en HTML. Le code Pegex pour l'utiliser pourrait ressembler à ceci :

Dans les termes les plus simples, Pegex fonctionne comme ceci (pseudocode) :

parser = new Pegex.Parser(
    grammar: new Markdown.Grammar
    receiver: new Markdown.Receiver.HTML
)
html = parser.parse(markdown)
