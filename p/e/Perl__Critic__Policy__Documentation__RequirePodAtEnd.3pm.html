Perl::Critic::Policy::Documentation::RequirePodAtEnd(3pm) Documentation Perl fournie par l'utilisateur Perl::Critic::Policy::Documentation::RequirePodAtEnd(3pm)

NOM

Perl::Critic::Policy::Documentation::RequirePodAtEnd - Tout le POD doit être après "__END__".

AFFILIATION

Cette politique fait partie de la distribution principale de Perl::Critic.

DESCRIPTION

Perl arrête de traiter le code lorsqu'il rencontre une instruction "__END__". Donc, pour économiser du temps de traitement, il est plus rapide de placer la documentation après "__END__". De plus, écrire tout le POD en un seul endroit conduit généralement à un document plus cohérent, plutôt que d'être obligé de suivre la mise en page de votre code. Cette politique émet des violations si du POD est trouvé avant un "__END__".

CONFIGURATION

Cette politique n'est configurable que pour les options standard.

NOTES

Certains aiment utiliser les balises "=for", "=begin" et "=end" pour créer des commentaires de bloc en ligne avec leur code. Comme ces balises ne font généralement pas partie de la documentation, cette politique les autorise à apparaître avant l'instruction "__END__".

=begin comments
frobulate()
Accepte : Une liste d'éléments à frobuler
Retourne : True si réussi
=end comments
sub frobulate { ... }
