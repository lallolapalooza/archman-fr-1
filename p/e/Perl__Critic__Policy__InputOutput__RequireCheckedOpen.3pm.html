Perl::Critic::Policy::InputOutput::RequireCheckedOpen(3pm) Documentation Perl Contribuée par les utilisateurs Perl::Critic::Policy::InputOutput::RequireCheckedOpen(3pm)

NOM

Perl::Critic::Policy::InputOutput::RequireCheckedOpen - Écrire "my $error = open $fh, $mode, $filename;" au lieu de "open $fh, $mode, $filename;".

AFFILIATION

Cette politique fait partie de la distribution principale de Perl::Critic.

DESCRIPTION

La fonction intégrée aux E/S de Perl "open" renvoie une valeur fausse en cas d'échec. Cette valeur doit toujours être vérifiée pour s'assurer que l'ouverture a réussi.

my $error = open( $filehandle, $mode, $filename );                  # ok
open( $filehandle, $mode, $filename ) or die "impossible d'ouvrir : $!";  # ok
open( $filehandle, $mode, $filename );                              # pas ok
use autodie;
open $filehandle, $mode, $filename;                                 # ok

Vous pouvez utiliser autodie, Fatal, ou Fatal::Exception pour contourner ce problème. Actuellement, autodie n'est pas correctement traité comme un pragma ; ses effets lexicaux ne sont pas pris en compte.

CONFIGURATION

Si vous créez un module qui exporte "autodie", vous pouvez informer cette politique à ce sujet avec le réglage "autodie_modules" :

[InputOutput::RequireCheckedSyscalls]
autodie_modules = My::Thing
