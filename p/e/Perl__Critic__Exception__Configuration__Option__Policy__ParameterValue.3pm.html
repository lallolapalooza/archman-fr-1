NOM

Perl::Critic::Exception::Configuration::Option::Policy::ParameterValue - Un problème avec la valeur d'un paramètre pour une politique.

DESCRIPTION

Une représentation d'un problème trouvé avec la valeur d'un paramètre pour une Perl::Critic::Policy, que ce soit à partir d'un .perlcriticrc, d'un autre fichier de profil, ou de la ligne de commande.

SUPPORT D'INTERFACE

Ceci est considéré comme une classe publique. Tout changement à son interface passera par un cycle de dépréciation.

MÉTHODES DE CLASSE

"throw( policy => $policy, option_name => $option_name, option_value => $option_value, source => $source, message_suffix => $message_suffix )"
Voir "throw" dans Exception::Class.
"new( policy => $policy, option_name => $option_name, option_value => $option_value, source => $source, message_suffix => $message_suffix )"
Voir "new" dans Exception::Class.

MÉTHODES

full_message()
Fournit un message standard pour les problèmes de valeur de paramètre de politique. Voir "full_message" dans Exception::Class.
