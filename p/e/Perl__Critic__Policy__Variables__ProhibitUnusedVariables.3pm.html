Perl::Critic::Policy::Variables::ProhibitUnusedVariables(3pm) Documentation Perl fournie par la communauté Perl::Critic::Policy::Variables::ProhibitUnusedVariables(3pm)

NOM

Perl::Critic::Policy::Variables::ProhibitUnusedVariables - Ne demandez pas de stockage dont vous n'avez pas besoin.

AFFILIATION

Cette politique fait partie de la distribution principale de Perl::Critic.

DESCRIPTION

Les variables inutilisées encombrent le code et obligent le lecteur à faire un travail mental de comptabilité pour déterminer si la variable est réellement utilisée ou non.

À l'heure actuelle, cette politique est très limitée afin de garantir qu'il n'y ait pas de faux positifs. Espérons que cela deviendra plus sophistiqué bientôt.

Pour le moment, cela ne recherche que les variables lexicales simplement déclarées et non initialisées.

my $x;          # pas bon, en supposant aucune autre apparition.
my @y = ();     # bon, pas encore géré.
our $z;         # bon, global.
local $w;       # bon, global.

Ce module est très simple : il ne détecte pas la portée, c'est-à-dire que si le même nom de variable est utilisé dans deux emplacements différents, même s'il ne s'agit pas de la même variable, cette politique ne se plaindra pas.

Il faut bien commencer quelque part.

CONFIGURATION

Cette politique n'est pas configurable, à l'exception des options standard.
