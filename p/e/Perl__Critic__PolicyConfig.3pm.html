Perl::Critic::PolicyConfig(3pm) Documentation Perl fournie par l'utilisateur Perl::Critic::PolicyConfig(3pm)

NOM

Perl::Critic::PolicyConfig - Données de configuration pour une Politique.

DESCRIPTION

Un conteneur pour la configuration d'une Politique.

SUPPORT D'INTERFACE

Ceci est considéré comme une classe non publique. Son interface est susceptible de changer sans préavis.

MÉTHODES

get_policy_short_name()
Le nom de la politique pour laquelle cette configuration s'applique. Principalement là pour le débogage.
get_set_themes()
La valeur de "set_themes" dans le fichier .perlcriticrc de l'utilisateur.
get_add_themes()
La valeur de "add_themes" dans le fichier .perlcriticrc de l'utilisateur.
get_severity()
La valeur de "severity" dans le fichier .perlcriticrc de l'utilisateur.
is_maximum_violations_per_document_unlimited()
Indique si la valeur de "maximum_violations_per_document" doit être considérée comme illimitée.
get_maximum_violations_per_document()
La valeur de "maximum_violations_per_document" dans le fichier .perlcriticrc de l'utilisateur.
get($parameter)
Récupère la valeur du paramètre spécifié dans le fichier .perlcriticrc de l'utilisateur.
remove($parameter)
Supprime la valeur du paramètre spécifié.
is_empty()
Indique s'il reste des informations de configuration non standard.
get_parameter_names()
Récupère les noms des paramètres de cet objet.
set_profile_strictness($profile_strictness)
Définit la rigueur du profil associée à la configuration.
" handle_extra_parameters($policy,$errors) "
Gère les paramètres supplémentaires en fonction du réglage de rigueur du profil. Doit être appelée par Perl::Critic::Policy->new() une fois que toutes les politiques valides ont été traitées et supprimées de la configuration.

Si profile_strictness est $PROFILE_STRICTNESS_QUIET, les paramètres de politique supplémentaires sont ignorés.

Si profile_strictness est $PROFILE_STRICTNESS_WARN, les paramètres de politique supplémentaires génèrent un avertissement.

Si profile_strictness est $PROFILE_STRICTNESS_FATAL, les paramètres de politique supplémentaires génèrent une erreur fatale.

Si aucune rigueur de profil n'a été définie, le comportement est celui spécifié par $PROFILE_STRICTNESS_DEFAULT.

VOIR AUSSI

"MAKING YOUR POLICY CONFIGURABLE" dans Perl::Critic::DEVELOPER
