NOM

Perl::Critic::Exception::Parse - Le code ne ressemble pas à du code.

DESCRIPTION

Il y a eu un problème lors de l'analyse du code source par PPI.

SUPPORT DES INTERFACES

Cette classe est considérée comme publique. Tout changement de son interface passera par un cycle de dépréciation.

MÉTHODES

file_name()
