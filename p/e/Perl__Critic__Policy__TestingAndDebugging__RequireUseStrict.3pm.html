Perl::Critic::Policy::TestingAndDebugging::RequireUseStrict(3pm) Documentation Perl fournie par l'utilisateur Perl::Critic::Policy::TestingAndDebugging::RequireUseStrict(3pm)

NOM

Perl::Critic::Policy::TestingAndDebugging::RequireUseStrict - Toujours "use strict".

AFFILIATION

Cette politique fait partie de la distribution principale de Perl::Critic.

DESCRIPTION

L'utilisation des strictures est probablement le moyen le plus efficace d'améliorer la qualité de votre code. Cette politique exige que l'instruction "use strict" doive précéder toute autre instruction, à l'exception de "package", "require" et des autres instructions "use". Ainsi, tout le code de l'ensemble du paquet sera affecté.

Il existe des dérogations spéciales pour Moose, Moose::Role et Moose::Util::TypeConstraints car ils imposent la rigueur ; par exemple, "use Moose" est traité comme équivalent à "use strict".

Le nombre maximum de violations par document pour cette politique est de 1 par défaut.

CONFIGURATION

Si vous utilisez des éléments tels que Moose::Exporter, vous pouvez créer vos propres modules qui importent le pragma strict dans le code qui les "use". Il existe une option pour ajouter aux ensembles par défaut de pragmas et de modules dans votre .perlcriticrc : "equivalent_modules".

[TestingAndDebugging::RequireUseStrict]
equivalent_modules = MooseX::My::Sugar

VOIR AUSSI

Perl::Critic::Policy::TestingAndDebugging::ProhibitNoStrict
