Perl::Critic::Policy::BuiltinFunctions::RequireBlockMap(3pm) Documentation Perl fournie par l'utilisateur Perl::Critic::Policy::BuiltinFunctions::RequireBlockMap(3pm)

NOM

Perl::Critic::Policy::BuiltinFunctions::RequireBlockMap - Écrire "map { /$pattern/ } @list" au lieu de "map /$pattern/, @list".

AFFILIATION

Cette politique fait partie de la distribution principale de Perl::Critic.

DESCRIPTION

Les formes d'expression de "grep" et "map" sont maladroites et difficiles à lire. Utilisez les formes de bloc à la place.

@matches = grep   /pattern/,   @list;        # Pas bien
@matches = grep { /pattern/ }  @list;        # Bien
@mapped = map   transform($_),   @list;      # Pas bien
@mapped = map { transform($_) }  @list;      # Bien

CONFIGURATION

Cette politique n'est configurable que pour les options standard.
