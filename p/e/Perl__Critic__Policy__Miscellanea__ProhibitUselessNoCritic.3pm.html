NOM

Perl::Critic::Policy::Miscellanea::ProhibitUselessNoCritic - Supprimer les annotations « ## no critic » inefficaces.

AFFILIATION

Cette politique fait partie de la distribution principale de Perl::Critic.

DESCRIPTION

Parfois, il peut être nécessaire d'utiliser une annotation « ## no critic » pour contourner un faux positif dans Perl::Critic. Mais finalement, ce bogue pourrait être corrigé, laissant votre code avec des annotations « ## no critic » supplémentaires. Ou vous pouvez les utiliser pour désactiver localement une politique, mais décider plus tard de supprimer définitivement cette politique de votre profil, rendant certaines de ces annotations « ## no critic » inutiles. Ou encore, vous pourriez accidentellement désactiver trop de politiques à la fois, créant une opportunité pour que de nouvelles violations se glissent sans être remarquées.

Cette politique générera des violations si vous avez une annotation « ## no critic » dans votre code source qui ne supprime en fait aucune violation compte tenu de votre profil actuel. Pour résoudre ce problème, vous devez soit supprimer complètement l'annotation, soit ajuster les modèles de noms de politique dans l'annotation pour qu'ils ne correspondent qu'aux politiques qui sont effectivement violées dans votre code.

EXEMPLE

Par exemple, disons que j'ai une expression régulière, mais que je ne veux pas utiliser l'indicateur « /x », ce qui viole la politique « RegularExpressions::RequireExtendedFormatting ». Dans le code suivant, l'annotation « ## no critic » supprimera les violations de cette politique et de TOUTES les politiques qui correspondent à « m/RegularExpressions/imx ».

my $re = qr/foo bar baz/ms;  ## no critic (RegularExpressions)

Cependant, cela crée une faille potentielle pour quelqu'un pour introduire des violations supplémentaires à l'avenir, sans les reconnaître explicitement. Cette politique est conçue pour attraper ces situations en vous avertissant que vous avez désactivé plus de politiques que la situation ne l'exige réellement. Le code ci-dessus devrait être corrigé comme suit :

my $re = qr/foo bar baz/ms;  ## no critic (RequireExtendedFormatting)

Notez comment le modèle « RequireExtendedFormatting » correspond plus précisément au nom de la politique que j'essaie de supprimer.

NOTE

La modification de votre fichier .perlcriticrc et la désactivation globale des politiques ou l'exécution à un niveau de sévérité plus élevé (c'est-à-dire moins restrictif) peuvent amener cette politique à émettre des violations supplémentaires. Vous pourriez donc vouloir reporter l'utilisation de cette politique jusqu'à ce que vous ayez un profil assez stable.

CONFIGURATION

Cette politique n'est pas configurable, à l'exception des options standard.
