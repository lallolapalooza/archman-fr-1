NOM

Perl::Critic::Policy::Modules::ProhibitEvilModules - Bannir les modules qui ne sont pas approuvés par votre entreprise.

AFFILIATION

Cette politique fait partie de la distribution principale de Perl::Critic.

DESCRIPTION

Utilisez cette politique si vous souhaitez interdire l'utilisation de modules spécifiques. Il peut s'agir de modules que vous jugez obsolètes, bogués, non pris en charge, non sécurisés, ou que vous n'aimez tout simplement pas.

CONFIGURATION

L'ensemble des modules interdits est configurable via les options "modules" et "modules_file".

La valeur de "modules" doit être une chaîne de noms de modules complets et/ou d'expressions régulières séparés par des espaces. Un exemple pour interdire deux modules spécifiques dans un fichier .perlcriticrc :

[Modules::ProhibitEvilModules]
modules = Getopt::Std Autoload

Les expressions régulières sont identifiées par des valeurs commençant et se terminant par des barres obliques. Tout module dont le nom correspond à "m/pattern/" sera interdit. Par exemple :

[Modules::ProhibitEvilModules]
modules = /Acme::/

interdira tous les modules qui correspondent à "m/Acme::/".

De plus, vous pouvez remplacer le message par défaut ( « Module interdit "module" utilisé » ) par le vôtre, afin de donner des suggestions d'action alternatives. Pour ce faire, placez votre message entre accolades après le nom du module ou l'expression régulière. Comme ceci :

[Modules::ProhibitEvilModules]
modules = Fatal {Utilisation de Fatal détectée. Utilisez autodie à la place} /Acme::/ {Nous n'utilisons pas de modules humoristiques}

De même, l'option "modules_file" donne le nom d'un fichier contenant les spécifications des modules interdits. Une seule spécification de module est autorisée par ligne et les commentaires commencent par un dièse et s'étendent jusqu'à la fin de la ligne ; aucune accolade n'est nécessaire pour délimiter les messages :

Evil     # Interdire le module "Evil" et utiliser le message par défaut.
# Interdire le module "Fatal" et donner un message de remplacement.
Fatal Utilisation de Fatal détectée. Utilisez autodie à la place.
# Utiliser une expression régulière.
/Acme::/     Nous n'utilisons pas de modules humoristiques.

Par défaut, les modules qui ont été dépréciés par les Perl 5 Porters sont signalés ; au moment de la rédaction, il s'agissait de Class::ISA, Pod::Plainer, Shell et Switch. La spécification d'une valeur pour l'option "modules" remplacera ce comportement.

NOTES

Notez que cette politique ne s'applique pas aux pragmas.
