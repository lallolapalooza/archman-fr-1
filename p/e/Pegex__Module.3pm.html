NOM

Pegex::Module - Classe de base pour les modules d'interface de grammaire Pegex

SYNOPSIS

package MonLangage;
use Pegex::Base;
extends 'Pegex::Module';
use Pegex::Parser;
has parser_class => 'Pegex::Parser';
has grammar_class => 'MonLangage::Grammaire';
has receiver_class => 'MonLangage::AST';
1;

DESCRIPTION

Le module dans le synopsis ci-dessus est un module complet d'analyse de langage. Il hérite simplement de Pegex::Module, puis surcharge les attributs "grammar_class" et "receiver_class". Pegex::Module fournit la méthode parse().

XXX

À ce stade, vous devez également spécifier l'attribut "parser_class". L'héritage de cette valeur par défaut ne fonctionne pas.
