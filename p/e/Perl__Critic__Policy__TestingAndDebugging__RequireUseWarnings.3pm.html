Perl::Critic::Policy::TestingAndDebugging::RequireUseWarnings(3pm) Documentation Perl fournie par la communauté Perl::Critic::Policy::TestingAndDebugging::RequireUseWarnings(3pm)

NOM

Perl::Critic::Policy::TestingAndDebugging::RequireUseWarnings - Toujours utiliser "use warnings".

AFILIALITION

Cette politique fait partie de la distribution principale de Perl::Critic.

DESCRIPTION

Utiliser les avertissements, et y prêter attention, est probablement le moyen le plus efficace d'améliorer la qualité de votre code. Cette politique exige que l'instruction 'use warnings' apparaisse avant toute autre instruction, sauf "package", "require" et autres instructions "use". Ainsi, tout le code de l'ensemble du paquet sera affecté.

Il existe des exemptions spéciales pour Moose, Moose::Role et Moose::Util::TypeConstraints car ils imposent les avertissements ; par exemple, 'use Moose' est traité comme équivalent à 'use warnings'.

Cette politique ne se plaindra pas si le fichier indique explicitement qu'il est compatible avec une version de perl antérieure à la 5.6 via une instruction d'inclusion, par exemple en contenant "require 5.005".

Le nombre maximum de violations par document pour cette politique est de 1 par défaut.

CONFIGURATION

Si vous utilisez des choses comme Moose::Exporter, vous pouvez créer vos propres modules qui importent le pragma d'avertissement dans le code qui les utilise. Il existe une option pour ajouter à l'ensemble par défaut des pragmas et modules dans votre fichier .perlcriticrc : "equivalent_modules".

[TestingAndDebugging::RequireUseWarnings]
equivalent_modules = MooseX::My::Sugar

BOGUES

Doit vérifier la présence de -w dans la ligne shebang.

VOIR AUSSI
