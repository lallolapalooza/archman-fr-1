NOM

Perl::Critic::Policy::Subroutines::ProhibitExcessComplexity - Minimiser la complexité en factorisant le code en sous-programmes plus petits.

AFILATION

Cette politique fait partie de la distribution principale de Perl::Critic.

DESCRIPTION

Toutes choses égales par ailleurs, un code compliqué est plus sujet aux erreurs et plus coûteux à maintenir qu'un code plus simple. La première étape vers la gestion de la complexité consiste à établir des métriques de complexité formelles. Une de ces métriques est le score de McCabe, qui décrit le nombre de chemins possibles à travers un sous-programme. Cette politique approxime le score de McCabe en additionnant le nombre d'instructions conditionnelles et d'opérateurs à l'intérieur d'un sous-programme. La recherche a montré qu'un score de McCabe supérieur à 20 est un signe de code à haut risque, potentiellement non testable. Voir http://en.wikipedia.org/wiki/Cyclomatic_complexity pour une discussion sur le nombre de McCabe et d'autres métriques de complexité.

La prescription habituelle pour réduire la complexité est de refactoriser le code en sous-programmes plus petits. Le livre de Mark Dominus, « Higher Order Perl », décrit également les rappels, la récursivité, la mémoïsation, les itérateurs et d'autres techniques qui aident à créer du code Perl simple et extensible.

CONFIGURATION

Le McCabe maximum acceptable peut être défini avec l'élément de configuration "max_mccabe". Tout sous-programme avec un score de McCabe supérieur à ce nombre générera une violation de politique. La valeur par défaut est 20. Un exemple de section pour un .perlcriticrc :

[Subroutines::ProhibitExcessComplexity]
max_mccabe = 30

NOTES

"Tout doit être rendu aussi simple que possible, mais pas plus simple."
                                                -- Albert Einstein

La complexité est subjective, mais les métriques de complexité formelles sont toujours incroyablement précieuses. Chaque problème a un niveau de complexité inhérent, il n'est donc pas nécessairement optimal de minimiser le nombre de McCabe. Alors ne vous offusquez pas si votre code déclenche cette politique. Considérez simplement s'il **pourrait** y avoir un moyen plus simple de faire le travail.
