Perl::Critic::Annotation(3pm) Documentation Perl fournie par l'utilisateur Perl::Critic::Annotation(3pm)

NOM

Perl::Critic::Annotation - Une annotation "## no critic" dans un document.

SYNOPSIS

use Perl::Critic::Annotation;
$annotation = Perl::Critic::Annotation->new( -element => $no_critic_ppi_element );
$bool = $annotation->disables_line( $number );
$bool = $annotation->disables_policy( $policy_object );
$bool = $annotation->disables_all_policies();
($start, $end) = $annotation->effective_range();
@disabled_policy_names = $annotation->disabled_policies();

DESCRIPTION

"Perl::Critic::Annotation" représente une seule annotation "## no critic" dans un document PPI::Document. L'Annotation s'occupe d'analyser l'annotation et de garder une trace des lignes et des politiques qu'elle affecte. Elle est destinée à encapsuler les détails des annotations no-critic et à fournir un moyen aux objets Policy d'interagir avec les annotations (via un Perl::Critic::Document).

PRISE EN CHARGE DE L'INTERFACE

Ceci est considéré comme une classe non publique. Son interface est susceptible de changer sans préavis.

MÉTHODES DE CLASSE

create_annotations( -doc => $doc )
Étant donné un Perl::Critic::Document, trouve toutes les annotations "## no critic" et construit une nouvelle "Perl::Critic::Annotation" pour chacune d'elles et les retourne. L'ordre des objets retournés n'est pas défini. Il est généralement attendu que les clients utilisent cette interface plutôt que d'appeler directement le constructeur "Perl::Critic::Annotation".

CONSTRUCTEUR

"new( -element => $ppi_annotation_element )"
Retourne une référence vers un nouvel objet Annotation. L'argument -element est requis et doit être un "PPI::Token::Comment" qui respecte la syntaxe "## no critic".

MÉTHODES

disables_line( $line )
Retourne vrai si cette Annotation désactive la ligne $line pour n'importe quelle (ou toutes les) Politiques.
disables_policy( $policy_object )
disables_policy( $policy_name )
Retourne vrai si cette Annotation désactive $polciy_object ou $policy_name à n'importe quelle (ou toutes les) lignes.
disables_all_policies()
Retourne vrai si cette Annotation désactive toutes les Politiques à n'importe quelle (ou toutes les) lignes. Si cette méthode retourne vrai, "disabled_policies" retournera une liste vide.
effective_range()
Retourne une liste à deux éléments, représentant les numéros de la première et de la dernière ligne où cette Annotation a un effet.
disabled_policies()
Retourne une liste des noms des Politiques qui sont affectées par cette Annotation. Si cette liste est vide, cela signifie que toutes les Politiques sont affectées par cette Annotation, et disables_all_policies() devrait retourner vrai.
element()
Retourne l'élément PPI où cette annotation a commencé. Il s'agit typiquement d'une instance de PPI::Token::Comment.
