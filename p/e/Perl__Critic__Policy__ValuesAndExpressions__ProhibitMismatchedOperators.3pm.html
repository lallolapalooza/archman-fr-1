NOM

Perl::Critic::Policy::ValuesAndExpressions::ProhibitMismatchedOperators - Ne pas mélanger les opérateurs numériques avec des opérandes de chaînes de caractères, ou vice-versa.

AFILATION

Cette politique fait partie de la distribution principale de Perl::Critic.

DESCRIPTION

Utiliser le mauvais type d'opérateur pour une valeur peut obscurcir l'intention du codage et potentiellement entraîner des erreurs subtiles. Un exemple est de mélanger un opérateur d'égalité de chaînes de caractères avec une valeur numérique, ou vice-versa.

if ($foo == 'bar') {}     # pas ok
if ($foo eq 'bar') {}     # ok
if ($foo eq 123) {}       # pas ok
if ($foo == 123) {}       # ok

CONFIGURATION

Cette politique n'est pas configurable, à l'exception des options standard.

NOTES

Si les avertissements sont activés, l'interpréteur Perl vous avertit généralement de l'utilisation d'opérateurs incompatibles au moment de l'exécution. Cette politique fait essentiellement la même chose, mais au moment de la création du code. De cette façon, vous pouvez en être informé plus tôt.

Perl traite les chaînes 'NaN' et 'inf' comme des nombres spéciaux et crée une structure NV lors de la comparaison avec un opérateur numérique. Bien que non nécessaire, il est permis d'écrire du code tel que :
my $i = 'inf'+0; Ce modèle aide les autres à comprendre que la variable représente effectivement les nombres infinis ou NaN tels qu'interprétés par Perl. Seuls ces deux nombres spéciaux de type chaîne peuvent avoir l'opérateur '+' qui serait autrement autorisé uniquement pour les chaînes.
