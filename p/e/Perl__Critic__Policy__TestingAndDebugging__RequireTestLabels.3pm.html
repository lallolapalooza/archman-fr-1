NOM

Perl::Critic::Policy::TestingAndDebugging::RequireTestLabels - Les tests doivent tous avoir des étiquettes.

AFFILIATION

Cette politique fait partie de la distribution principale de Perl::Critic.

DESCRIPTION

La plupart des modules Perl contenant des tests de régression utilisent Test::More comme infrastructure pour écrire et exécuter ces tests. Il offre une syntaxe procédurale simple pour comparer des résultats à des attentes.

La plupart des fonctions de Test::More permettent au programmeur d'ajouter une étiquette facultative décrivant ce que chaque test essaie de juger. Lorsqu'un test échoue, ces étiquettes sont très utiles pour déterminer rapidement l'origine du problème.

Cette politique impose que toutes les fonctions de Test::More aient des étiquettes lorsque cela est applicable. Cela s'applique uniquement au code qui contient une déclaration "use Test::More" ou "require Test::More" (voir ci-dessous pour ajouter d'autres modules de test à la liste).

CONFIGURATION

Une liste de modules supplémentaires pour lesquels les paramètres des méthodes doivent être étiquetés peut être spécifiée avec l'option "modules". La liste doit être composée de noms de modules entièrement qualifiés, séparés par des espaces blancs. Par exemple :

[TestingAndDebugging::RequireTestLabels]
modules = My::Test::SubClass  Some::Other::Module

La liste des modules inclut toujours implicitement Test::More.
