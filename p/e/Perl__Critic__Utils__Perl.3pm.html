NOM

Perl::Critic::Utils::Perl - Fonctions utilitaires pour traiter les problèmes du langage Perl.

SYNOPSIS

use Perl::Critic::Utils::Perl qw< :all >;
my $name = symbol_without_sigil('$foo');    # $name est "foo".

DESCRIPTION

Ceci gère divers problèmes liés à Perl, le langage, qui ne sont pas nécessairement liés à PPI.

SUPPORT D'INTERFACE

Ce module est considéré comme public. Tout changement à son interface passera par un cycle de dépréciation.

SOUS-ROUTINES IMPORTABLES

symbol_without_sigil( $symbol )
Retourne le nom du symbole spécifié sans aucun sigil au début. Le paramètre peut être une chaîne de caractères Perl classique ou un élément PPI.
