NOM

Perl::Critic::Exception::Configuration::Option::Global - Un problème avec la configuration globale de Perl::Critic.

DESCRIPTION

Une représentation d'un problème trouvé avec la configuration globale de Perl::Critic, que ce soit à partir d'un fichier .perlcriticrc, d'un autre fichier de profil, ou de la ligne de commande.

Ceci est une classe abstraite. Elle ne devrait jamais être instanciée.

SUPPORT D'INTERFACE

Ceci est considéré comme une classe publique. Tout changement à son interface passera par un cycle de dépréciation.
