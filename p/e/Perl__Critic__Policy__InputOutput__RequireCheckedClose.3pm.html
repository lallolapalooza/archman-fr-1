Perl::Critic::Policy::InputOutput::RequireCheckedClose(3pm) Documentation Perl contribuée par les utilisateurs Perl::Critic::Policy::InputOutput::RequireCheckedClose(3pm)

NOM

Perl::Critic::Policy::InputOutput::RequireCheckedClose - Écrire "my $error = close $fh;" au lieu de "close $fh;".

AFFILIATION

Cette politique fait partie de la distribution principale de Perl::Critic.

DESCRIPTION

La fonction intégrée au langage Perl pour les E/S, "close", renvoie une valeur fausse en cas d'échec. Cette valeur doit être vérifiée pour s'assurer que la fermeture a réussi.

my $error = close $filehandle;                   # ok
close $filehandle or die "impossible de fermer : $!";  # ok
close $filehandle;                               # pas ok
use autodie qw< :io >;
close $filehandle;                               # ok

Vous pouvez utiliser autodie, Fatal, ou Fatal::Exception pour contourner ce problème. Actuellement, autodie n'est pas correctement traité comme un pragma ; ses effets lexicaux ne sont pas pris en compte.

CONFIGURATION

Si vous créez un module qui exporte "autodie", vous pouvez en informer cette politique avec le paramètre "autodie_modules" :

[InputOutput::RequireCheckedSyscalls]
autodie_modules = My::Thing
