NOM

Perl::Critic::Statistics - Compile des statistiques sur les violations de Perl::Critic.

DESCRIPTION

Cette classe accumule des statistiques sur les violations de Perl::Critic sur un ou plusieurs fichiers. NOTE : Cette classe est expérimentale et sujette à modification.

SUPPORT D'INTERFACE

Ceci est considéré comme une classe non publique. Son interface est sujette à modification sans préavis.

MÉTHODES

new()
Crée une nouvelle instance de Perl::Critic::Statistics. Aucun argument n'est pris en charge pour le moment.
" accumulate( $doc, \@violations ) "
Accumule des statistiques sur le $doc et les @violations trouvés.
modules()
Le nombre de blocs de code (généralement des fichiers) qui ont été analysés.
subs()
Le nombre total de sous-routines analysées par ce Critic.
statements()
Le nombre total d'instructions analysées par ce Critic.
lines()
Le nombre total de lignes de code analysées par ce Critic.
lines_of_blank()
Le nombre total de lignes vides analysées par ce Critic. Cela inclut uniquement les lignes vides dans le code, pas le POD ni les données.
lines_of_comment()
Le nombre total de lignes de commentaires analysées par ce Critic. Cela inclut uniquement les lignes dont le premier caractère non blanc est "#".
lines_of_data()
Le nombre total de lignes de section de données analysées par ce Critic, sans compter la ligne "__END__" ou "__DATA__". Le POD dans une section de données est compté comme du POD, pas comme des données.
lines_of_perl()
Le nombre total de lignes de code Perl analysées par ce Critic. Le code Perl apparaissant dans la section de données n'est pas compté.
lines_of_pod()
Le nombre total de lignes de POD analysées par ce Critic. Le POD survenant dans une section de données est compté comme du POD, pas comme des données.
violations_by_severity()
Le nombre de violations de chaque niveau de gravité trouvées par ce Critic, sous forme de référence à un hash dont les clés sont les niveaux de gravité.
violations_by_policy()
Le nombre de violations de chaque politique trouvées par ce Critic, sous forme de référence à un hash dont les clés sont les noms complets des politiques.
total_violations()
Le nombre total de violations trouvées par ce Critic.
statements_other_than_subs()
Le nombre total d'instructions moins le nombre de sous-routines. Utile car une sous-routine est considérée comme une instruction par PPI.
average_sub_mccabe()
Le score moyen de McCabe de toutes les sous-routines analysées.
violations_per_file()
Le nombre total de violations divisé par le nombre de modules.
violations_per_statement()
Le nombre total de violations divisé par le nombre d'instructions moins les sous-routines.
violations_per_line_of_code()
Le nombre total de violations divisé par le nombre de lignes de code.
