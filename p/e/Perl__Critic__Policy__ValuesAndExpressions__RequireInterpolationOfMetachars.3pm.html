NOM

Perl::Critic::Policy::ValuesAndExpressions::RequireInterpolationOfMetachars - Avertit que vous avez peut-être utilisé des guillemets simples alors que vous vouliez en fait des guillemets doubles.

AFfILIATION

Cette politique fait partie de la distribution principale de Perl::Critic.

DESCRIPTION

Cette politique vous avertit si vous utilisez des guillemets simples ou "q//" avec une chaîne comportant des métacaractères non échappés qui pourraient nécessiter une interpolation. Il est difficile de savoir avec certitude si une chaîne doit réellement être interpolée sans consulter la table des symboles. Cette politique fait une supposition éclairée en recherchant les métacaractères et les sigils qui indiquent généralement que la chaîne doit être interpolée.

Exceptions

  • Noms de variables pour "use vars" : 
    use vars '$x';          # ok
use vars ('$y', '$z');  # ok
use vars qw< $a $b >;   # ok
  • Ce qui ressemble à des adresses e-mail : 
    print 'john@foo.com';           # ok
$address = 'suzy.bar@baz.net';  # ok

CONFIGURATION

L'option "rcs_keywords" vous permet d'empêcher cette politique de se plaindre de choses qui ressemblent à des variables RCS, par exemple, dans la dérivation de valeurs pour des variables $VERSION.

Par exemple, si vous avez du code comme

our ($VERSION) = (q<$Revision$> =~ m/(\d+)/mx);

Vous pouvez spécifier

[ValuesAndExpressions::RequireInterpolationOfMetachars]
rcs_keywords = Revision

dans votre fichier .perlcriticrc pour fournir une exemption.

NOTES

Le pragma "warnings" de Perl vous avertit également à ce sujet.
