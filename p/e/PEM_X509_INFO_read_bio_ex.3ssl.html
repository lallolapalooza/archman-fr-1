PEM_X509_INFO_read_bio_ex(3ssl)

Paquet: openssl

Licences: Apache-2.0

PEM_X509_INFO_READ_BIO_EX(3ssl) OpenSSL PEM_X509_INFO_READ_BIO_EX(3ssl)

NOM

PEM_X509_INFO_read_ex, PEM_X509_INFO_read, PEM_X509_INFO_read_bio_ex, PEM_X509_INFO_read_bio - lire des structures de données encodées en PEM dans un ou plusieurs objets X509_INFO

SYNTAXE

#include <openssl/pem.h>
STACK_OF(X509_INFO) *PEM_X509_INFO_read_ex(FILE *fp, STACK_OF(X509_INFO) *sk,
                                           pem_password_cb *cb, void *u,
                                           OSSL_LIB_CTX *libctx,
                                           const char *propq);
STACK_OF(X509_INFO) *PEM_X509_INFO_read(FILE *fp, STACK_OF(X509_INFO) *sk,
                                        pem_password_cb *cb, void *u);
STACK_OF(X509_INFO) *PEM_X509_INFO_read_bio_ex(BIO *bio,
                                               STACK_OF(X509_INFO) *sk,
                                               pem_password_cb *cb, void *u,
                                               OSSL_LIB_CTX *libctx,
                                               const char *propq);
STACK_OF(X509_INFO) *PEM_X509_INFO_read_bio(BIO *bp, STACK_OF(X509_INFO) *sk,
                                            pem_password_cb *cb, void *u);

DESCRIPTION

PEM_X509_INFO_read_ex() charge les objets X509_INFO à partir d'un fichier fp.

PEM_X509_INFO_read() est similaire à PEM_X509_INFO_read_ex() mais utilise le contexte de bibliothèque par défaut (NULL) libctx et une requête de propriétés vide propq.

PEM_X509_INFO_read_bio_ex() charge les objets X509_INFO en utilisant un bio bp.

PEM_X509_INFO_read_bio() est similaire à PEM_X509_INFO_read_bio_ex() mais utilise le contexte de bibliothèque par défaut (NULL) libctx et une requête de propriétés vide propq.

Chacun des objets X509_INFO chargés peut contenir une CRL, un certificat et/ou une clé privée. Les éléments sont lus séquentiellement et, dans la mesure où ils sont de type différent des éléments lus précédemment, ils sont combinés dans le même objet X509_INFO. L'idée derrière cela est que si, par exemple, un certificat est suivi d'une clé privée, la clé privée est censée correspondre au certificat.

Si la pile d'entrée sk est NULL, une nouvelle pile est allouée, sinon la pile donnée est étendue.

Les paramètres optionnels cb et u peuvent être utilisés pour fournir une phrase de passe nécessaire au déchiffrement des structures PEM chiffrées (normalement uniquement les clés privées). Voir PEM_read_bio_PrivateKey(3) et passphrase-encoding(7) pour plus de détails.

Le contexte de bibliothèque libctx et la requête de propriétés propq sont utilisés pour récupérer les algorithmes auprès des fournisseurs.

VALEURS DE RETOUR

PEM_X509_INFO_read_ex(), PEM_X509_INFO_read(), PEM_X509_INFO_read_bio_ex() et PEM_X509_INFO_read_bio() renvoient une pile d'objets X509_INFO ou NULL en cas d'échec.

VOIR AUSSI

PEM_read_bio_ex(3), PEM_read_bio_PrivateKey(3), passphrase-encoding(7)

HISTORIQUE

Les fonctions PEM_X509_INFO_read_ex() et PEM_X509_INFO_read_bio_ex() ont été ajoutées dans OpenSSL 3.0.
