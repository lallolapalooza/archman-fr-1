NOM

Perl::Critic::Policy::CodeLayout::RequireTidyCode - Doit exécuter le code à travers perltidy.

AFFILIATION

Cette politique fait partie de la distribution principale de Perl::Critic.

DESCRIPTION

Conway fait des recommandations spécifiques pour les espaces et les accolades dans votre code, mais le plus important est d'adopter une mise en page cohérente, quelles que soient les spécificités. Et la manière la plus simple de le faire est d'utiliser Perl::Tidy. Cette politique se plaindra si votre code n'a pas été exécuté à travers Perl::Tidy.

CONFIGURATION

Cette politique peut être configurée pour demander à Perl::Tidy d'utiliser un fichier perltidyrc particulier ou aucune configuration. Par défaut, il est demandé à Perl::Tidy de chercher la configuration dans son emplacement par défaut. Perl::Critic peut être configuré pour demander à Perl::Tidy d'utiliser un fichier de configuration spécifique en ajoutant une entrée dans un fichier .perlcriticrc comme ceci :

[CodeLayout::RequireTidyCode]
perltidyrc = /usr/share/perltidy.conf

Dans un cas spécial, définir "perltidyrc" sur une chaîne vide demande à Perl::Tidy de ne charger aucun fichier de configuration et d'utiliser simplement le style par défaut de Perl::Tidy.

[CodeLayout::RequireTidyCode]
perltidyrc =
