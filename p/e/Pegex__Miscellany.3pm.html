Aperçu de Pegex

Pour mémoire

Pegex s'auto-héberge. Cela signifie que la syntaxe du langage de grammaire Pegex est définie par une grammaire Pegex ! C'est important car (tout comme n'importe quel langage basé sur Pegex) cela facilite le portage vers de nouveaux langages de programmation. Vous pouvez trouver la grammaire Pegex pour les grammaires Pegex ici : http://github.com/ingydotnet/pegex-pgx/.

Pegex a été initialement inspiré par les Perl 6 Rules. Il reprend également des idées du module Perl 5 de Damian Conway, Regexp::Grammars. Pegex essaie de tirer le meilleur parti de ces œuvres remarquables et de les faire fonctionner dans autant de langages que possible. C'est de l'acméisme.

Astuces d'auto-compilation

Vous pouvez vous amuser en utilisant Pegex pour compiler lui-même. D'abord, obtenez le dépôt de grammaire Pegex :

git clone git://github.com/ingydotnet/pegex-pgx.git
cd pegex-pgx

Ensuite, analysez et affichez la grammaire Pegex avec Pegex :

perl -MXXX -MPegex -e 'XXX pegex("pegex.pgx")->parse("pegex.pgx")'

Pour une vue différente de l'arbre de données, essayez :

perl -MXXX -MPegex -e 'XXX pegex("pegex.pgx", receiver => "Pegex::Tree")->parse("pegex.pgx")'

Enfin, pour émuler le compilateur Pegex, faites ceci :

perl -MXXX -MPegex -e 'XXX pegex("pegex.pgx", receiver => "Pegex::Pegex::AST")->parse("pegex.pgx")'

Ceci spécifie une classe « réceptrice » qui peut façonner les résultats en quelque chose d'utile. En effet, c'est le cœur de Pegex::Grammar::Pegex.

UN EXEMPLE RÉEL

TestML est un nouveau langage de tests unitaires acméiste. Il est parfait pour les logiciels qui doivent s'exécuter de manière équivalente dans plus d'un langage. En fait, Pegex lui-même est testé avec TestML !!

TestML a une grammaire de spécification de langage : http://www.testml.org/specification/language/

L'implémentation Perl6 de TestML utilise cette grammaire dans : https://github.com/ingydotnet/testml-pm6/blob/master/lib/TestML/Parser/Grammar.pm

Toutes les autres implémentations de TestML utilisent cette grammaire Pegex : https://github.com/ingydotnet/testml-pgx/blob/master/testml.pgx

Dans Perl 5, Pegex::Compiler est utilisé pour compiler la grammaire dans cette structure de données simple (montrée en YAML) : https://github.com/ingydotnet/testml-pgx/blob/master/testml.pgx.yaml

La grammaire peut également être pré-compilée en JSON : https://github.com/ingydotnet/testml-pgx/blob/master/testml.pgx.json

Pegex::Compiler compile ensuite cela en une grammaire spécifique à Perl 5, qui devient ce module : https://github.com/ingydotnet/testml-pm/blob/master/lib/TestML/Compiler/Pegex/Grammar.pm

TestML::Parser::Grammar est une sous-classe de Pegex::Grammar. Il peut être utilisé pour analyser des fichiers TestML. TestML::Parser appelle la méthode parse() de la grammaire avec un objet TestML::AST qui reçoit des rappels lorsque diverses règles correspondent, et utilise les informations pour construire un objet TestML::Document.

Ainsi, TestML est un langage acméiste écrit en Pegex. Il peut être facilement porté dans tous les langages où Pegex existe. En fait, il doit être porté dans ces langages afin de tester la nouvelle implémentation de Pegex !
