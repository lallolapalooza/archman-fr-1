Perl::MinimumVersion(3) Documentation Perl fournie par l'utilisateur Perl::MinimumVersion(3)

NOM

Perl::MinimumVersion - Trouver une version minimale de perl requise pour du code Perl

SYNOPIS

# Créer l'objet de vérification de version
$objet = Perl::MinimumVersion->new( $nom_fichier );
$objet = Perl::MinimumVersion->new( \$source  );
$objet = Perl::MinimumVersion->new( $document_ppi );
# Trouver la version minimale
$version = $objet->minimum_version;

DESCRIPTION

"Perl::MinimumVersion" prend du code source Perl et calcule la version minimale de perl requise pour pouvoir l'exécuter. Parce qu'il est basé sur PPI, il peut le faire sans avoir à charger le code.

Actuellement, il teste à la fois la syntaxe de votre code et l'utilisation de dépendances de version explicites telles que "require 5.008".

Les plans futurs incluent également l'ajout de la prise en charge du traçage des dépendances de modules.

Utiliser "Perl::MinimumVersion" est extrêmement simple, le synopsis le couvre pratiquement.

La distribution est fournie avec un script appelé perlver, qui est le moyen le plus simple d'exécuter "Perl::MinimumVersion" sur votre code :

% perlver lib/Foo/Bar.pm

Voir la documentation de perlver pour plus de détails.

METHODES

new

# Créer l'objet de vérification de version
$objet = Perl::MinimumVersion->new( $nom_fichier );
$objet = Perl::MinimumVersion->new( \$source  );
$objet = Perl::MinimumVersion->new( $document_ppi );

Le constructeur "new" crée un nouvel objet de vérification de version pour un document PPI::Document. Vous pouvez également fournir le document à lire sous forme de nom de fichier, ou sous forme de référence "SCALAR" contenant le code.

Retourne un nouvel objet "Perl::MinimumVersion", ou "undef" en cas d'erreur.

Document

L'accesseur "Document" peut être utilisé pour récupérer l'objet PPI::Document à partir du vérificateur de version.

minimum_version

La méthode "minimum_version" est la méthode principale pour trouver la version minimale de perl requise en se basant sur "tous" les facteurs du document.

À l'heure actuelle, il ne s'agit que de la syntaxe et des vérifications explicites de version, car Perl::Depends n'est pas encore terminé.

Retourne un objet de version, ou "undef" en cas d'erreur.

minimum_explicit_version

La méthode "minimum_explicit_version" parcourt le code Perl à la recherche de dépendances de version explicites telles que.

use 5.006;
require 5.005_03;

Bien qu'il n'y ait presque toujours qu'une seule de ces occurrences dans un fichier, si plus d'une sont trouvées, la version la plus élevée sera retournée.

Retourne un objet de version, faux si aucune dépendance n'a pu être trouvée, ou "undef" en cas d'erreur.

minimum_syntax_version $limite

La méthode "minimum_syntax_version" teste explicitement uniquement la syntaxe du Document pour déterminer sa version minimale, dans la mesure où cela est possible.

Elle prend un paramètre optionnel d'un objet de version définissant la valeur actuelle la plus basse connue. Par exemple, s'il est déjà connu qu'elle doit être de 5.006 ou plus, vous pouvez fournir un paramètre qv(5.006) et la méthode n'exécutera aucun des tests en dessous de cette version. Cela devrait fournir des améliorations de vitesse spectaculaires pour des documents volumineux et/ou complexes.

Les limitations de l'analyse de Perl signifient que cette méthode peut fournir des résultats artificiellement bas, mais ne devrait pas fournir de résultats artificiellement élevés.

Par exemple, si "minimum_syntax_version" renvoie 5.006, vous pouvez être sûr qu'il ne s'exécutera pas sur quelque chose de plus bas, bien qu'il soit possible que lors de l'exécution réelle, il utilise une fonctionnalité non testable qui crée une dépendance à une version plus élevée.

Retourne un objet de version, faux si aucune dépendance n'a pu être trouvée, ou "undef" en cas d'erreur.

minimum_external_version

AVERTISSEMENT : Cette méthode n'a pas été implémentée. Toute tentative d'utilisation provoquera une exception

La méthode "minimum_external_version" examine le code pour les dépendances sur d'autres fichiers externes, et parcourt récursivement l'arbre de dépendances en appliquant les mêmes tests à ces fichiers qu'à l'original.

Retourne un objet "version", faux si aucune dépendance n'a pu être trouvée, ou "undef" en cas d'erreur.

version_markers

Cette méthode retourne une liste de paires sous la forme :

($version, \@marqueurs)

Chaque paire représente tous les marqueurs qui ont pu être trouvés indiquant que la version était la version minimale requise. @marqueurs est un tableau de chaînes de caractères. Actuellement, ces chaînes ne sont pas aussi claires qu'elles pourraient l'être, mais cela pourrait changer à l'avenir. Autrement dit : ne vous fiez pas à elles comme identificateurs spécifiques.

BOGUES

Perl::MinimumVersion fait un travail raisonnable pour capturer les dépendances de version explicites les mieux connues.

Cependant, il est extrêmement facile d'ajouter une nouvelle vérification de syntaxe, donc si vous trouvez quelque chose qui manque, copiez et collez l'une des fonctions de vérification de 5 lignes existantes, modifiez-la pour trouver ce que vous voulez, et signalez-le à rt.cpan.org, avec la version nécessaire.

Je n'ai même pas besoin d'un diff entier... juste de la fonction et de la version.
