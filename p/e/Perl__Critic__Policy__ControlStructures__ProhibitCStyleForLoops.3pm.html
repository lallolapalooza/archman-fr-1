Perl::Critic::Policy::ControlStructures::ProhibitCStyleForLoops(3pm) Documentation Perl contribuée par l'utilisateur Perl::Critic::Policy::ControlStructures::ProhibitCStyleForLoops(3pm)

NOM

Perl::Critic::Policy::ControlStructures::ProhibitCStyleForLoops - Écrire "for(0..20)" au lieu de "for($i=0; $i<=20; $i++)".

AFFILIATION

Cette politique fait partie de la distribution principale de Perl::Critic.

DESCRIPTION

La boucle "for" en 3 parties que Perl hérite de C est très laide, et seulement vraiment nécessaire si vous avez besoin d'un comptage irrégulier. L'opérateur "..", très Perl, est beaucoup plus élégant et lisible.

for($i=0; $i<=$max; $i++){      # beurk !
    do_something($i);
}
for(0..$max){                   # très bien
    do_something($_);
}

CONFIGURATION

Cette politique n'est pas configurable, sauf pour les options standard.
