Perl::Critic::Policy::RegularExpressions::ProhibitComplexRegexes(3pm) Documentation Perl fournie par l'utilisateur Perl::Critic::Policy::RegularExpressions::ProhibitComplexRegexes(3pm)

NOM

Perl::Critic::Policy::RegularExpressions::ProhibitComplexRegexes - Diviser les expressions régulières longues en plus petits morceaux "qr//".

AFfILIATION

Cette politique fait partie de la distribution principale de Perl::Critic.

DESCRIPTION

Les grandes expressions régulières sont difficiles à lire, peut-être même la partie la plus difficile de Perl. Une bonne pratique consiste à écrire des morceaux d'expressions régulières digestes et à les assembler. Cette politique signale toute expression régulière plus longue que "N" caractères, où "N" est une valeur configurable dont la valeur par défaut est 60. Si l'expression régulière utilise le drapeau "x", la longueur est calculée après l'analyse de tout commentaire ou espace blanc.

Malheureusement, l'utilisation de noms de variables descriptifs (et donc plutôt longs) peut entraîner des expressions régulières en violation de cette politique, c'est pourquoi les variables interpolées sont comptées comme 4 caractères, quelle que soit la longueur réelle de leur nom.

ÉTUDE DE CAS

À titre d'exemple, regardez l'expression régulière utilisée pour faire correspondre les adresses e-mail dans Email::Valid::Loose (légèrement ajustée pour le retour à la ligne pour POD)

(?x-ism:(?:[^(\040)<>@,;:".\\\[\]\000-\037\x80-\xff]+(?![^(\040)<>@,;:".\\\[\]
\000-\037\x80-\xff])|"[^\\\x80-\xff\n\015"]*(?:\\[^\x80-\xff][^\\\x80-\xff\n
\015"]*)*")(?:(?:[^(\040)<>@,;:".\\\[\]\000-\037\x80-\xff]+(?![^(\040)<>@,;:".\\\[
\]\000-\037\x80-\xff])|"[^\\\x80-\xff\n\015"]*(?:\\[^\x80-\xff][^\\\x80-\xff\n
\015"]*)*")|\.)*\@(?:[^(\040)<>@,;:".\\\[\]\000-\037\x80-\xff]+(?![^(\040)<>@,
;:".\\\[\]\000-\037\x80-\xff])|\[(?:[^\\\x80-\xff\n\015\[\]]|\\[^\x80-\xff])*\]
)(?:\.(?:[^(\040)<>@,;:".\\\[\]\000-\037\x80-\xff]+(?![^(\040)<>@,;:".\\\[\]\000
-\037\x80-\xff])|\[(?:[^\\\x80-\xff\n\015\[\]]|\\[^\x80-\xff])*\]))*)

qui est construite à partir du code suivant :

my $esc         = '\\\\';
my $period      = '\.';
my $space       = '\040';
my $open_br     = '\[';
my $close_br    = '\]';
my $nonASCII    = '\x80-\xff';
my $ctrl        = '\000-\037';
my $cr_list     = '\n\015';
my $qtext       = qq/[^$esc$nonASCII$cr_list\"]/; # "
my $dtext       = qq/[^$esc$nonASCII$cr_list$open_br$close_br]/;
my $quoted_pair = qq<$esc>.qq<[^$nonASCII]>;
my $atom_char   = qq/[^($space)<>\@,;:\".$esc$open_br$close_br$ctrl$nonASCII]/;# "
my $atom        = qq<$atom_char+(?!$atom_char)>;
my $quoted_str  = qq<\"$qtext*(?:$quoted_pair$qtext*)*\">; # "
my $word        = qq<(?:$atom|$quoted_str)>;
my $domain_ref  = $atom;
my $domain_lit  = qq<$open_br(?:$dtext|$quoted_pair)*$close_br>;
my $sub_domain  = qq<(?:$domain_ref|$domain_lit)>;
my $domain      = qq<$sub_domain(?:$period$sub_domain)*>;
my $local_part  = qq<$word(?:$word|$period)*>; # Cette partie est modifiée
$Addr_spec_re   = qr<$local_part\@$domain>;

Si vous lisez le code de bas en haut, il est assez lisible. Et vous pouvez même voir la violation de RFC822 que Tatsuhiko Miyagawa a délibérément introduite dans Email::Valid::Loose pour autoriser les points. Regardez "|\." dans l'expression régulière supérieure pour voir cette même déviation.

On pourrait certainement soutenir que l'expression régulière du haut pourrait être réécrite plus lisiblement avec "m//x" et des commentaires. Mais la version du bas s'auto-documente et, par exemple, ne répète pas "\x80-\xff" 18 fois. De plus, il est beaucoup plus facile de comparer la deuxième version à la grammaire BNF source dans RFC 822 pour juger si l'implémentation est correcte, même avant d'exécuter les tests.

CONFIGURATION

Cette politique autorise les expressions régulières jusqu'à "N" caractères de long, où "N" vaut par défaut 60. Vous pouvez remplacer cela pour le définir à un autre nombre avec le paramètre "max_characters". Pour ce faire, placez des entrées dans un fichier .perlcriticrc comme ceci :

[RegularExpressions::ProhibitComplexRegexes]
max_characters = 40
