NOM

Perl::Critic::Theme - Construire des ensembles thématiques de politiques.

DESCRIPTION

Ceci est une classe d'aide pour évaluer des expressions thématiques en ensembles d'objets de Politique. Il n'y a aucune partie réparable par l'utilisateur ici.

SUPPORT D'INTERFACE

Ceci est considéré comme une classe non publique. Son interface est susceptible d'être modifiée sans préavis.

MÉTHODES

"new( -rule => $expression_règle )"
Retourne une référence à un nouvel objet Perl::Critic::Theme. "-rule" est une expression chaîne qui s'évalue à vrai ou faux pour chaque Politique. Voir "RÈGLES THÉMATIQUES" pour plus d'informations.
"policy_is_thematic( -policy => $politique )"
Étant donné une référence à un objet Perl::Critic::Policy, cette méthode évalue la règle par rapport aux thèmes associés à la Politique. Retourne 1 si la Politique satisfait la règle, 0 sinon.
règle()
Retourne l'expression de règle utilisée pour construire ce Thème. La règle peut avoir été traduite en une expression normalisée. Voir "RÈGLES THÉMATIQUES" pour plus d'informations.

RÈGLES THÉMATIQUES

Une règle thématique est une expression booléenne simple, où les opérandes sont les noms de n'importe quels thèmes associés aux Politiques Perl::Critic.

Les noms de thèmes peuvent être combinés avec des opérateurs logiques pour former des expressions arbitrairement complexes. La précédence est la même que dans les mathématiques normales, mais vous pouvez utiliser des parenthèses pour imposer la précédence également. Les opérateurs supportés sont :

Opérateur    Alternative    Exemple
----------------------------------------------------------------
&&          and            'pbp && core'
||          or             'pbp || (bugs && security)'
!           not            'pbp && ! (portability || complexity)'

Voir "CONFIGURATION" dans Perl::Critic pour plus d'informations sur la personnalisation des thèmes pour chaque Politique.

SOUS-ROUTINES

cuisiner_règle( $règle )
Standardiser une règle en code Perl presque exécutable. Le "presque" vient du fait que les noms de thèmes sont laissés tels quels.

CONSTANTES

$RÈGLE_CARACTÈRE_INVALIDE_REGEX
Une expression régulière qui retournera le premier caractère dans l'expression correspondante qui n'est pas valide dans une règle.
