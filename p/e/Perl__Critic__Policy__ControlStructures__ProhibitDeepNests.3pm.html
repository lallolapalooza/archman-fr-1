NOM

Perl::Critic::Policy::ControlStructures::ProhibitDeepNests - N'écrivez pas de boucles et de conditions profondément imbriquées.

AFFILIATION

Cette politique fait partie de la distribution principale de Perl::Critic.

DESCRIPTION

Le code profondément imbriqué est souvent difficile à comprendre et peut être le signe qu'il doit être refactorisé. Il existe plusieurs bons livres sur la façon de refactoriser du code. J'aime "Refactoring: Improving The Design of Existing Code" de Martin Fowler.

CONFIGURATION

Le nombre maximum de structures de contrôle imbriquées peut être configuré via une valeur pour "max_nests" dans un fichier .perlcriticrc. Chaque boucle for, bloc if-else, while et until est compté comme une imbrication. Les formes postfixées de ces constructions ne sont pas comptées. Le maximum par défaut est 5. La personnalisation dans un fichier .perlcriticrc ressemble à ceci :

[ControlStructures::ProhibitDeepNests]
max_nests = 3
