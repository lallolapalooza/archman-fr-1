NOM

Perl::Critic::Policy::BuiltinFunctions::ProhibitVoidGrep - Ne pas utiliser "grep" dans des contextes vides.

AFFILIATION

Cette politique fait partie de la distribution principale de Perl::Critic.

DESCRIPTION

"map" et "grep" sont destinés à être des fonctions pures, et non des mutateurs. Si vous souhaitez itérer avec des effets secondaires, vous devriez utiliser une boucle "for" ou "foreach" appropriée.

grep{ print frobulate($_) } @list;           # pas ok
print map{ frobulate($_) } @list;            # ok
grep{ $_ = lc $_ } @list;                    # pas ok
for( @list ){ $_ = lc $_  };                 # ok
map{ push @frobbed, frobulate($_) } @list;   # pas ok
@frobbed = map { frobulate($_) } @list;      # ok

CONFIGURATION

Cette politique n'est pas configurable à l'exception des options standard.
