NOM

Perl::Critic::Exception::Configuration - Un problème avec la configuration de Perl::Critic.

DESCRIPTION

Une représentation d'un problème trouvé dans la configuration de Perl::Critic, que ce soit à partir d'un fichier .perlcriticrc, d'un autre fichier de profil, ou de la ligne de commande.

Ceci est une classe abstraite. Elle ne devrait jamais être instanciée.

SUPPORT D'INTERFACE

Ceci est considéré comme une classe publique. Tout changement dans son interface suivra un cycle de dépréciation.

MÉTHODES

source()
D'où proviennent les informations de configuration, si cela a pu être déterminé.

VOIR AUSSI

Perl::Critic::Exception::Configuration::Generic, Perl::Critic::Exception::Configuration::Option
