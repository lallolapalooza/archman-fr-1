NOM

Perl::Critic::Policy::CodeLayout::RequireConsistentNewlines - Utiliser la même nouvelle ligne dans la source.

AFFILIATION

Cette politique fait partie de la distribution principale de Perl::Critic.

DESCRIPTION

Les fichiers de code source sont divisés en lignes avec des fins de ligne de "\r", "\n" ou "\r\n". Le mélange de ces différentes fins de ligne cause des problèmes dans de nombreux éditeurs de texte et, notamment, dans Module::Signature et GnuPG.

AVERTISSEMENT

Cette politique fonctionne en dehors de PPI car PPI normalise automatiquement le code source aux conventions de fin de ligne locales. Ainsi, cela ne fonctionnera que si nous connaissons le nom du fichier source.

CONFIGURATION

Cette politique n'est pas configurable, à l'exception des options standard.
