Perl::Critic::Exception::Configuration::NonExistentPolicy(3pm) Documentation Perl fournie par l'utilisateur Perl::Critic::Exception::Configuration::NonExistentPolicy(3pm)

NOM

Perl::Critic::Exception::Configuration::NonExistentPolicy - La configuration faisait référence à une politique inexistante.

DESCRIPTION

Une représentation de la configuration tentant de spécifier une Perl::Critic::Policy inconnue, que ce soit à partir d'un fichier .perlcriticrc, d'un autre fichier de profil, ou de la ligne de commande.

SUPPORT DES INTERFACES

Cette classe est considérée comme publique. Tout changement de son interface fera l'objet d'un cycle de dépréciation.

MÉTHODES DE CLASSE

"throw( policy => $policy )"
Voir "throw" dans Exception::Class.
"new( policy => $policy )"
Voir "new" dans Exception::Class.

MÉTHODES

full_message()
Fournit un message standard. Voir "full_message" dans Exception::Class.
