NOM

PerlIO::via::symlink - Couches PerlIO pour créer des liens symboliques

SYNTAXE

open $fh, '>:via(symlink)', $fname;
print $fh "link foobar";
close $fh;

DESCRIPTION

La couche PerlIO "symlink" vous permet de créer un lien symbolique en écrivant sur le descripteur de fichier.

Vous devez écrire C"link $name" sur le descripteur de fichier. Si le format ne correspond pas, "close" échouera avec EINVAL.
