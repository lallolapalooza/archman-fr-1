NOM

Perl::Critic::Policy::CodeLayout::ProhibitHardTabs - Utiliser des espaces au lieu des tabulations.

AFFILIATION

Cette politique fait partie de la distribution principale de Perl::Critic.

DESCRIPTION

Placer des tabulations dans votre code source (ou POD) est l'une des pires choses que vous puissiez faire à vos collègues, surtout si ces tabulations ne sont pas en position initiale. Parce que diverses applications et appareils représentent les tabulations différemment, elles peuvent rendre votre code très différent pour d'autres personnes. Tout éditeur décent peut être configuré pour développer les tabulations en espaces. Perl::Tidy fait cela pour vous également.

Cette politique détecte toutes les tabulations dans votre code source, y compris le POD, les chaînes de caractères et les HEREDOCs. Le contenu de la section "__DATA__" n'est pas examiné.

CONFIGURATION

Les tabulations dans une chaîne de caractères sont toujours interdites (utilisez "\t" à la place). Mais les tabulations en position initiale sont autorisées lorsqu'elles sont utilisées pour indenter les instructions de code, les listes de mots qw() et les expressions régulières avec le modificateur "/x". Cependant, si vous souhaitez interdire toutes les tabulations partout, ajoutez ceci à votre fichier .perlcriticrc :

[CodeLayout::ProhibitHardTabs]
allow_leading_tabs = 0

NOTES

Attention, Perl::Critic peut signaler l'emplacement de la chaîne qui contient la tabulation, et non l'emplacement réel de la tabulation, vous pourriez donc avoir besoin de chercher un peu. J'essaierai de corriger cela à l'avenir.
