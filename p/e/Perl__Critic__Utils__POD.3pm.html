NOM

Perl::Critic::Utils::POD - Fonctions utilitaires pour manipuler le POD.

SYNTAXE

use Perl::Critic::Utils::POD qw< get_pod_section_from_file >;
my $synopsis =
    get_pod_section_from_file('Perl/Critic/Utils/POD.pm', 'SYNOPSIS');
my $see_also =
    get_pod_section_from_filehandle($file_handle, 'SEE ALSO');
my $see_also_content = trim_pod_section($see_also);
# "Fonctions utilitaires pour manipuler le POD."
my $module_abstract =
    get_module_abstract_from_file('Perl/Critic/Utils/POD.pm');
my $module_abstract =
    get_module_abstract_from_filehandle($file_handle);

DESCRIPTION

Fournit des moyens d'accéder à des fragments de POD.

SUPPORT D'INTERFACE

Ce module est considéré comme public. Tout changement à son interface suivra un cycle de dépréciation.

SOUS-PROGRAMMES IMPORtables

get_pod_file_for_module( $module_name )
Détermine où trouver le POD pour le paramètre.

Ceci dépend du module déjà chargé ; il ne trouvera pas le chemin pour des modules arbitraires.

S'il existe un fichier avec l'extension ".pod" à côté de l'emplacement réel du module, il sera retourné de préférence au module actuel.

"get_raw_pod_section_from_file( $file_name, $section_name )"
Récupère la section POD spécifiée (c'est-à-dire quelque chose marqué par "=head1") à partir du fichier. Ceci est non interprété ; les échappements ne sont pas traités et les sous-sections seront présentes. Par exemple, si le contenu contient "C<$x>", la valeur retournée contiendra "C<$x>".

Retourne rien si aucune section de ce type n'est trouvée.

Lance une exception Perl::Critic::Exception::IO s'il y a un problème avec le fichier.

"get_raw_pod_section_from_filehandle( $file_handle, $section_name )"
Fait la même chose que get_raw_pod_section_from_file(), mais avec un descripteur de fichier.
"get_raw_pod_section_from_string( $source, $section_name )"
Fait la même chose que get_raw_pod_section_from_file(), mais avec une chaîne contenant le POD brut.
"get_raw_pod_section_for_module( $module_name, $section_name )"
Fait la même chose que get_raw_pod_section_from_file(), mais avec un nom de module.

Lance une exception Perl::Critic::Exception::Generic si un fichier contenant du POD pour le module ne peut être trouvé.

"get_pod_section_from_file( $file_name, $section_name )"
Récupère la section POD spécifiée (c'est-à-dire quelque chose marqué par "=head1") à partir du fichier. Ceci est interprété en texte brut.

Retourne rien si aucune section de ce type n'est trouvée.

Lance une exception Perl::Critic::Exception::IO s'il y a un problème avec le fichier.

"get_pod_section_from_filehandle( $file_handle, $section_name )"
Fait la même chose que get_pod_section_from_file(), mais avec un descripteur de fichier.
"get_pod_section_from_string( $source, $section_name )"
Fait la même chose que get_pod_section_from_file(), mais avec une chaîne contenant le POD brut.
"get_pod_section_for_module( $module_name, $section_name )"
Fait la même chose que get_pod_section_from_file(), mais avec un nom de module.

Lance une exception Perl::Critic::Exception::Generic si un fichier contenant du POD pour le module ne peut être trouvé.

trim_raw_pod_section( $pod_section )
Retourne une copie du paramètre, avec tout début "=item1 BLAH" supprimé et tous les espaces en début et fin (y compris les nouvelles lignes) supprimés après cela.

Par exemple, utiliser une des fonctions "get_raw_pod_section_from_*" pour obtenir la section "NAME" de ce module, puis appeler trim_raw_pod_section() sur le résultat donnerait "Perl::Critic::Utils::POD - Fonctions utilitaires pour manipuler le POD.".

trim_pod_section( $pod_section )
Retourne une copie du paramètre, avec la ligne de début supprimée et les lignes vides initiales et les espaces blancs finaux (y compris les nouvelles lignes) supprimés après cela. Notez que seuls les espaces blancs au début de la première ligne réelle de la section resteront.

Comme ceci ne peut pas compter sur un marqueur "=item1", c'est beaucoup moins fiable que trim_raw_pod_section().

get_raw_module_abstract_from_file( $file_name )
Tente d'analyser la section "NAME" du fichier spécifié et d'en extraire le résumé du module. Si cela réussit, elle retourne le résumé. Si cela échoue, soit parce qu'il n'y a pas de section "NAME", soit parce qu'il n'y a pas de résumé après le nom du module, elle retourne rien. S'il semble y avoir un résumé mal formé, elle lance une exception Perl::Critic::Exception::Fatal::Generic.

Exemples de sections "NAME" "bien formées" sans résumés :

Some::Module
Some::Other::Module -

Exemples de sections "NAME" qui entraîneront une exception :

Some::Bad::Module Ceci n'a pas de trait d'union.
Some::Mean::Module -- Ceci a des doubles traits d'union.
Some::Nasty::Module - Ceci tente de
s'étendre sur plusieurs lignes.
get_raw_module_abstract_from_filehandle( $file_handle )
Fait la même chose que get_raw_module_abstract_from_file(), mais avec un descripteur de fichier.
get_raw_module_abstract_from_string( $source )
Fait la même chose que get_raw_module_abstract_from_file(), mais avec une chaîne contenant le POD brut.
get_raw_module_abstract_for_module( $module_name )
Fait la même chose que get_raw_module_abstract_from_file(), mais pour un nom de module.
get_module_abstract_from_file( $file_name )
Fait la même chose que get_raw_module_abstract_from_file(), mais avec les échappements interprétés.
get_module_abstract_from_filehandle( $file_handle )
Fait la même chose que get_module_abstract_from_file(), mais avec un descripteur de fichier.
get_module_abstract_from_string( $source )
Fait la même chose que get_module_abstract_from_file(), mais avec une chaîne contenant le POD brut.
get_module_abstract_for_module( $module_name )
Fait la même chose que get_module_abstract_from_file(), mais pour un nom de module.
