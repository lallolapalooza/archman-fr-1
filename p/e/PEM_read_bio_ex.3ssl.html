PEM_read_bio_ex(3ssl)

Paquet: openssl

Licences: Apache-2.0

PEM_READ_BIO_EX(3ssl) OpenSSL PEM_READ_BIO_EX(3ssl)

NOM

PEM_read_bio_ex, PEM_FLAG_SECURE, PEM_FLAG_EAY_COMPATIBLE, PEM_FLAG_ONLY_B64 - lire des fichiers au format PEM avec traitement personnalisé

SYNTAXE

#include <openssl/pem.h>
#define PEM_FLAG_SECURE             0x1
#define PEM_FLAG_EAY_COMPATIBLE     0x2
#define PEM_FLAG_ONLY_B64           0x4
int PEM_read_bio_ex(BIO *in, char **name, char **header,
                    unsigned char **data, long *len, unsigned int flags);

DESCRIPTION

PEM_read_bio_ex() lit des données au format PEM à partir d'un BIO d'entrée, en sortie le nom du type de données contenu, les informations d'en-tête concernant les données éventuellement chiffrées, et la charge utile binaire des données (après décodage base64). Elle ne devrait généralement être utilisée que pour implémenter les fonctions de la famille PEM_read_bio pour des types de données spécifiques ou pour d'autres usages, mais est exposée pour permettre une plus grande flexibilité sur la façon dont le traitement est effectué, si nécessaire.

Si PEM_FLAG_SECURE est défini, les tampons intermédiaires utilisés pour lire les lignes d'entrée sont alloués à partir du tas sécurisé.

Si PEM_FLAG_EAY_COMPATIBLE est défini, un algorithme simple est utilisé pour supprimer les espaces blancs et les caractères de contrôle à la fin de chaque ligne, afin d'être compatible avec le comportement historique de PEM_read_bio().

Si PEM_FLAG_ONLY_B64 est défini, tous les caractères doivent être des caractères base64 valides (ou des sauts de ligne) ; les caractères non-base64 sont traités comme la fin de l'entrée.

Si ni PEM_FLAG_EAY_COMPATIBLE ni PEM_FLAG_ONLY_B64 n'est défini, les caractères de contrôle sont ignorés.

Si PEM_FLAG_EAY_COMPATIBLE et PEM_FLAG_ONLY_B64 sont tous deux définis, une erreur est retournée ; ces options ne sont pas compatibles entre elles.

NOTES

L'appelant doit libérer l'espace alloué pour *name, *header, et *data. Si PEM_FLAG_SECURE a été défini, utilisez OPENSSL_secure_free() ; sinon, OPENSSL_free() est utilisé.

VALEUR DE RETOUR

PEM_read_bio_ex() retourne 1 en cas de succès ou 0 en cas d'échec.

VOIR AUSSI

PEM_bytes_read_bio(3)

HISTORIQUE

La fonction PEM_read_bio_ex() a été ajoutée dans OpenSSL 1.1.1.
