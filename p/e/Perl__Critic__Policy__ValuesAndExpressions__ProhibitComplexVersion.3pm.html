Perl::Critic::Policy::ValuesAndExpressions::ProhibitComplexVersion(3pm) Documentation Perl fournie par l'utilisateur Perl::Critic::Policy::ValuesAndExpressions::ProhibitComplexVersion(3pm)

NOM

Perl::Critic::Policy::ValuesAndExpressions::ProhibitComplexVersion - Interdire les valeurs de version provenant de l'extérieur du module.

AFFILIATION

Cette politique fait partie de la distribution centrale de Perl::Critic.

DESCRIPTION

Une façon tentante de maintenir un groupe de modules liés au même numéro de version est de faire importer ce numéro de version par un module désigné. Par exemple, le module "Foo::Master" pourrait être le maître de version pour le paquet "Foo", et tous les autres modules pourraient utiliser sa $VERSION en écrivant :

use Foo::Master; our $VERSION = $Foo::Master::VERSION;

Cela s'avère ne pas être une bonne idée, car toutes sortes de choses imprévues peuvent se produire - allant de changements de numéro de version non intentionnels à des attaques par déni de service (puisque "Foo::Master" est exécuté par le 'use').

Cette politique examine les instructions qui assignent à $VERSION et déclare une violation dans deux circonstances : premièrement, si cette instruction utilise un symbole entièrement qualifié qui n'est pas originaire d'un paquet déclaré dans le fichier ; deuxièmement, s'il y a une instruction "use" sur la même ligne que l'assignation.

Par défaut, une exception est faite pour "use version;" en raison de sa recommandation par Perl Best Practices. Voir la variable de configuration "forbid_use_version" si vous ne souhaitez pas qu'une exception soit faite pour "use version;".

CONFIGURATION

La construction

use version; our $VERSION = qv('1.2.3');

est exempte par défaut de cette politique, car elle est recommandée par Perl Best Practices. Si vous souhaitez identifier "use version;" comme une violation, ajoutez ce qui suit à votre fichier perlcriticrc :

[ValuesAndExpressions::ProhibitComplexVersion]
forbid_use_version = 1

CAVEATS

Ce code suppose que le signe distinctif d'une violation est un 'use' sur la même ligne que l'assignation de $VERSION, car c'est la manière de le faire voir par ExtUtils::MakeMaker->parse_version(). D'autres façons d'obtenir une valeur de version externe au module peuvent être imaginées, et cette politique les ignore actuellement.
