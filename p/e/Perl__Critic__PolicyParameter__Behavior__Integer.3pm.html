NOM

Perl::Critic::PolicyParameter::Behavior::Integer - Actions appropriées pour un paramètre entier.

DESCRIPTION

Fournit un ensemble standard de fonctionnalités pour un Perl::Critic::PolicyParameter entier afin que le développeur d'une politique n'ait pas à la fournir lui-même.

L'analyseur fourni par ce comportement autorise les tirets bas ("_") dans les valeurs d'entrée, comme dans une littérale numérique Perl.

NOTE : N'instanciez pas cette classe. Utilisez l'instance unique conservée par Perl::Critic::PolicyParameter.

PRISE EN CHARGE INTERFACE

Ceci est considéré comme une classe non publique. Son interface peut changer sans préavis.

MÉTHODES

"initialize_parameter( $parameter, $specification )"
Intègre les fonctionnalités fournies par ce comportement au paramètre, en se basant sur la configuration fournie par la spécification.

Ce comportement recherche deux éléments de configuration :

integer_minimum
Optionnel. La valeur minimale acceptable. Inclusive.
integer_maximum
Optionnel. La valeur maximale acceptable. Inclusive.
generate_parameter_description( $parameter )
Crée une description du paramètre, basée sur la description du paramètre lui-même, mais en l'enrichissant avec les informations de ce comportement.

Dans ce cas, cela signifie inclure les valeurs minimale et maximale.
