NOM

Perl::Critic::Policy::BuiltinFunctions::ProhibitVoidMap - Ne pas utiliser "map" dans des contextes vides.

AFFAIRE

Cette politique fait partie de la distribution principale de Perl::Critic.

DESCRIPTION

"map" et "grep" sont destinées à être des fonctions pures, et non des mutateurs. Si vous souhaitez itérer avec des effets secondaires, vous devriez utiliser une boucle "for" ou "foreach" appropriée.

grep{ print frobulate($_) } @list;           # pas bon
print map{ frobulate($_) } @list;            # bon
grep{ $_ = lc $_ } @list;                    # pas bon
for( @list ){ $_ = lc $_  };                 # bon
map{ push @frobbed, frobulate($_) } @list;   # pas bon
@frobbed = map { frobulate($_) } @list;      # bon

CONFIGURATION

Cette politique n'est pas configurable, sauf pour les options standard.
