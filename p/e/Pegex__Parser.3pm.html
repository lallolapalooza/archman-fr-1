NOM

Pegex::Parser - Moteur d'analyse Pegex

SYNOPSIS

use Pegex::Parser;
use SomeGrammarClass;
use SomeReceiverClass;
my $parser = Pegex::Parser->new(
    grammar => SomeGrammarClass->new,
    receiver => SomeReceiverClass->new,
);
my $result = $parser->parse($SomeInputText);

DESCRIPTION

Pegex::Parser est le composant Pegex qui fournit le moteur d'analyse en cours d'exécution. Il nécessite un objet Grammar et un objet Receiver. Sa méthode parse() prend une entrée qui doit correspondre à la grammaire, et applique les règles de grammaire à l'entrée. Au fur et à mesure que la grammaire est appliquée, le récepteur est notifié des correspondances. Le récepteur est libre de faire ce qu'il veut, mais construit souvent les données dans une structure communément appelée Arbre d'Analyse (Parse Tree).

Lorsque la méthode d'analyse est terminée, elle retourne l'objet que le récepteur a fourni comme résultat final. Si la grammaire échoue à faire correspondre l'entrée en cours de route, la méthode d'analyse déclenchera une erreur avec de nombreuses informations sur l'échec.

ATTRIBUTS

Le constructeur d'objet Pegex::Parser "new" prend ces attributs :

"grammar"
Un objet Pegex::Grammar. Obligatoire.
"receiver"
Un objet Pegex::Receiver.
"debug"
Booléen. Active le débogage. Par défaut : faux.
"recursion_limit"
Entier. Niveau de récursion pour arrêter. Par défaut : 0 (désactivé).
"recursion_warn_limit"
Entier. Niveau de récursion pour émettre un avertissement. Par défaut : 0 (désactivé).
"iteration_limit"
Entier. Nombre de correspondances à essayer avant de terminer. Par défaut : 0 (désactivé).

DÉBOGAGE

Pegex::Parser dispose actuellement de 4 paramètres utiles pour le débogage. Ceux-ci peuvent être définis comme attributs d'objet Pegex::Parser, variables globales ou variables d'environnement :

"debug" ou $Pegex::Parser::Debug ou $ENV{PERL_PEGEX_DEBUG}
S'il est défini sur une valeur vraie, il active des messages de trace très utiles pour chaque opération de correspondance interne.
"recursion_limit" ou "Pegex::Parser::RecursionLimit" ou $ENV{PERL_PEGEX_RECURSION_LIMIT}
S'il est défini sur un nombre supérieur à 0, Pegex::Parser s'arrêtera après avoir atteint ce nombre de niveaux de récursion.
"recursion_warn_limit" ou "Pegex::Parser::RecursionWarnLimit" ou $ENV{PERL_PEGEX_RECURSION_WARN_LIMIT}
S'il est défini sur un nombre supérieur à 0, Pegex::Parser émettra un avertissement chaque fois que ce nombre de niveaux de récursion est atteint.
"iteration_limit" ou "Pegex::Parser::IterationLimit" ou $ENV{PERL_PEGEX_ITERATION_LIMIT}
S'il est défini sur un nombre supérieur à 0, Pegex::Parser s'arrêtera après que ce nombre de correspondances ait été tenté.
"debug_indent" ou $Pegex::Parser::DebugIndent ou $ENV{PERL_PEGEX_DEBUG_INDENT}
Indique à l'analyseur le nombre d'espaces à utiliser pour indenter la sortie de débogage. Par défaut : 1.
"debug_color" ou $Pegex::Parser::DebugColor ou $ENV{PERL_PEGEX_DEBUG_COLOR}
S'il est activé, il coloriera les événements "got" et "not" dans la sortie de débogage ("bright_green" et "bright_red" respectivement). La couleur sera activée par défaut pour le débogage. Nécessite Term::ANSIColor.
"always" or 1
La couleur est activée.
"auto"
La couleur est activée lorsque STDERR est un tty.
"never" or 0
La couleur est désactivée.

Vous pouvez configurer les couleurs spécifiques utilisées en les ajoutant comme suit :

PERL_PEGEX_DEBUG_COLOR='always, cyan bold, black on_yellow'

Pour les couleurs disponibles, voir Term::ANSIColor

Remarque : L'utilisation de ces variables entraîne un léger impact sur les performances, mais si vous ne les utilisez pas, tout le code de débogage est optimisé.
