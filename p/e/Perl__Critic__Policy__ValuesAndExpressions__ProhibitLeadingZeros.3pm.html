Perl::Critic::Policy::ValuesAndExpressions::ProhibitLeadingZeros(3pm) Documentation Perl fournie par l'utilisateur Perl::Critic::Policy::ValuesAndExpressions::ProhibitLeadingZeros(3pm)

NOM

Perl::Critic::Policy::ValuesAndExpressions::ProhibitLeadingZeros - Écrire "oct(755)" au lieu de "0755".

AFFILIATION

Cette politique fait partie de la distribution principale de Perl::Critic.

DESCRIPTION

Perl interprète les nombres avec des zéros initiaux comme des nombres octaux. Si c'est ce que vous voulez vraiment, il est préférable d'utiliser "oct" et de le rendre évident.

$var = 041;     # pas ok, en fait 33
$var = oct(41); # ok
chmod 0644, $file;                              # ok par défaut
dbmopen %database, 'foo.db', 0600;              # ok par défaut
mkdir $directory, 0755;                         # ok par défaut
sysopen $filehandle, $filename, O_RDWR, 0666;   # ok par défaut
umask 0002;                                     # ok par défaut
use POSIX 'mkfifo';
mkfifo $fifo, 0600;                             # ok par défaut
POSIX::mkfifo $fifo, 0600;                      # ok par défaut

CONFIGURATION

Si vous souhaitez interdire tous les zéros initiaux, définissez "strict" à une valeur vraie dans un fichier .perlcriticrc.

[ValuesAndExpressions::ProhibitLeadingZeros]
strict = 1
