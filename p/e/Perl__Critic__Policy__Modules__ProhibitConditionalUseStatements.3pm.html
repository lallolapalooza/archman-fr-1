NOM

Perl::Critic::Policy::Modules::ProhibitConditionalUseStatements - Éviter de placer des instructions conditionnelles autour des instructions `use`.

AFFILIATION

Cette politique fait partie de la distribution principale de Perl::Critic.

DESCRIPTION

Les modules inclus via `use` sont chargés au moment de la compilation. Placer une logique conditionnelle autour de l'instruction `use` n'a aucun effet sur le chargement du module. Cela peut également prêter à confusion pour le lecteur quant à l'intention originale de l'auteur.

Si vous avez besoin de charger un module de manière conditionnelle, vous devriez plutôt utiliser `require`.

Cette politique détectera les formes suivantes d'instructions `use` conditionnelles :

# if-elsif-else
if ($a == 1) { use Module; }
if ($a == 1) { } elsif ($a == 2) { use Module; }
if ($a == 1) { } else { use Module; }
# for/foreach
for (1..$a) { use Module; }
foreach (@a) { use Module; }
# while
while ($a == 1) { use Module; }
# unless
unless ($a == 1) { use Module; }
# until
until ($a == 1) { use Module; }
# do-condition
do { use Module; } if $a == 1;
do { use Module; } while $a == 1;
do { use Module; } unless $a == 1;
do { use Module; } until $a == 1;
# operator-do
$a == 1 || do { use Module; };
$a == 1 && do { use Module; };
$a == 1 or do { use Module; };
$a == 1 and do { use Module; };
# eval sans chaîne de caractères
eval { use Module; };

L'inclusion d'un module via `use` dans des blocs nus, des blocs `do` autonomes ou des `eval` de chaînes de caractères est autorisée.

# bloc nu
{ use Module; }
# do
do { use Module; }
# eval de chaîne
eval "use Module";

CONFIGURATION

Cette politique n'est pas configurable, à l'exception des options standard.
