Perl::Critic::Policy::Variables::RequireInitializationForLocalVars(3pm) Documentation Perl fournie par l'utilisateur Perl::Critic::Policy::Variables::RequireInitializationForLocalVars(3pm)

NOM

Perl::Critic::Policy::Variables::RequireInitializationForLocalVars - Écrire "local $foo = $bar;" au lieu de simplement "local $foo;".

AFfILIATION

Cette politique fait partie de la distribution principale de Perl::Critic.

DESCRIPTION

La plupart des gens ne réalisent pas qu'une copie localisée d'une variable ne conserve pas sa valeur d'origine. À moins que vous n'initialisiez la variable lors de sa "local"isation, elle prend par défaut la valeur "undef". Si vous voulez que la variable conserve sa valeur d'origine, initialisez-la simplement à elle-même. Si vous voulez vraiment que la copie localisée soit indéfinie, alors rendez-le explicite.

package Foo;
$Bar = '42';
package Baz;
sub frobulate {
    local $Foo::Bar;              # pas bon, $Foo::Bar local est 'undef'
    local $Foo::Bar = undef;      # bon, $Foo::Bar local est évidemment 'undef'
    local $Foo::Bar = $Foo::Bar;  # bon, $Foo::Bar local est toujours égal à '42'
}

CONFIGURATION

Cette politique n'est pas configurable à l'exception des options standard.
