Perl::Critic::UserProfile(3pm) Documentation Perl fournie par l'utilisateur Perl::Critic::UserProfile(3pm)

NOM

Perl::Critic::UserProfile - Le contenu du profil utilisateur, souvent .perlcriticrc.

DESCRIPTION

Ceci est une classe d'assistance qui encapsule le contenu du profil utilisateur, généralement stocké dans un fichier .perlcriticrc. Il n'y a pas de pièces réparables par l'utilisateur ici.

PRISE EN CHARGE DE L'INTERFACE

Ceci est considéré comme une classe non publique. Son interface peut changer sans préavis.

CONSTRUCTEUR

"new( -profile => $p )"
-profile est le chemin d'accès au profil utilisateur. Si -profile n'est pas défini, il recherche le profil dans ./.perlcriticrc puis dans $HOME/.perlcriticrc. Si aucun de ces fichiers n'existe, alors UserProfile est créé avec les valeurs par défaut.

Cet objet ne prend pas en compte les substitutions de la ligne de commande ; Perl::Critic::Config s'en charge.

MÉTHODES

options_processor()
Retourne l'objet Perl::Critic::OptionsProcessor pour ce UserProfile.
policy_is_disabled( $policy )
Étant donné une référence à un objet Perl::Critic::Policy ou son nom, retourne vrai si l'utilisateur a désactivé cette politique dans son profil.
policy_is_enabled( $policy )
Étant donné une référence à un objet Perl::Critic::Policy ou son nom, retourne vrai si l'utilisateur a explicitement activé cette politique dans son profil utilisateur.
policy_params( $policy )
Étant donné une référence à un objet Perl::Critic::Policy ou son nom, retourne une Perl::Critic::PolicyConfig pour les paramètres de configuration de l'utilisateur pour cette politique.
raw_policy_params( $policy )
Étant donné une référence à un objet Perl::Critic::Policy ou son nom, retourne une référence à un hash des paramètres de configuration de l'utilisateur pour cette politique.
listed_policies()
Retourne une liste des noms de toutes les Politiques mentionnées dans le profil. Les noms des Politiques seront complètement qualifiés (par ex. Perl::Critic::Foo).
source()
L'endroit d'où proviennent les informations du profil, si disponibles. Généralement le chemin vers un .perlcriticrc.

VOIR AUSSI

Perl::Critic::Config, Perl::Critic::OptionsProcessor
