NOM

Perl::Critic::Policy::RegularExpressions::ProhibitUnusualDelimiters - Utiliser uniquement "//" ou "{}" pour délimiter les expressions régulières.

AFFILIATION

Cette politique fait partie de la distribution principale de Perl::Critic.

DESCRIPTION

Perl permet de délimiter les expressions régulières avec presque n'importe quel caractère, mais la plupart des choix sont illisibles. Comparez ces expressions équivalentes :

s/foo/bar/;   # bon
s{foo}{bar};  # bon
s#foo#bar#;   # mauvais
s;foo;bar;;   # pire
s|\|\||\||;   # douloureux pour les yeux

CONFIGURATION

Il y a une option pour cette politique, "allow_all_brackets". Si elle est vraie, alors, en plus de permettre "//" et "{}", les autres paires correspondantes de "()", "[]", et "<>" sont autorisées.
