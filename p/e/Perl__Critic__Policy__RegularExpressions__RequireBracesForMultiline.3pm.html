Perl::Critic::Policy::RegularExpressions::RequireBracesForMultiline(3pm) Documentation Perl Contribuée Perl::Critic::Policy::RegularExpressions::RequireBracesForMultiline(3pm)

NOM

Perl::Critic::Policy::RegularExpressions::RequireBracesForMultiline - Utiliser "{" et "}" pour délimiter les expressions régulières multilignes.

AFILIIATION

Cette politique fait partie de la distribution principale de Perl::Critic.

DESCRIPTION

Les expressions régulières longues sont difficiles à lire. Une bonne pratique consiste à utiliser le modificateur "x" et à diviser l'expression régulière en plusieurs lignes avec des commentaires expliquant les parties. Mais, avec les délimiteurs habituels "//", le début et la fin peuvent être difficiles à faire correspondre, en particulier dans une expression régulière "s///". Essayez plutôt d'utiliser les caractères "{}" pour délimiter vos expressions.

Comparez ceci :

s/
   <a \s+ href="([^"]+)">
    (.*?)
   </a>
 /link=$1, text=$2/xms;

à ceci :

s{
   <a \s+ href="([^"]+)">
    (.*?)
   </a>
 }
 {link=$1, text=$2}xms;

Est-ce une amélioration ? Marginalement, mais oui. Les accolades guident mieux le regard.

CONFIGURATION

Il existe une option pour cette politique, "allow_all_brackets". Si elle est définie sur vrai, alors, en plus d'autoriser "{}", les autres paires correspondantes "()", "[]" et "<>" sont autorisées.
