Perl::Critic::Exception::AggregateConfiguration(3pm) Documentation Perl fournie par l'utilisateur Perl::Critic::Exception::AggregateConfiguration(3pm)

NOM

Perl::Critic::Exception::AggregateConfiguration - Une collection d'un ensemble de problèmes trouvés dans la configuration et/ou les options de ligne de commande.

DESCRIPTION

Un ensemble de paramètres de configuration peut présenter plusieurs problèmes. Ceci est un objet pour collecter tous les problèmes trouvés afin que l'utilisateur puisse les voir en une seule exécution.

SUPPORT D'INTERFACE

Ceci est considéré comme une classe publique. Tout changement apporté à son interface passera par un cycle de dépréciation.

MÉTHODES

add_exception( $exception )
Accumule le paramètre avec le reste des exceptions.
add_exceptions_from( $aggregate )
Accumule les exceptions d'une autre instance de cette classe.
exceptions()
Retourne une référence vers un tableau des exceptions collectées.
add_exception_or_rethrow( $eval_error )
Si le paramètre est une instance de Perl::Critic::Exception::Configuration ou Perl::Critic::Exception::AggregateConfiguration, l'ajoute. Sinon, "die" avec le paramètre, s'il s'agit d'une référence, ou "confess" avec lui. Si le paramètre est faux, retourne simplement.
has_exceptions()
Indique si des problèmes de configuration ont été trouvés.
full_message()
Concatène les messages d'exception. Voir "full_message" dans Exception::Class.
