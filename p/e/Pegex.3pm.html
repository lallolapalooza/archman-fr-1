NOM

Pegex - Framework de parseur PEG acméiste

VERSION

Ce document décrit la version 0.75 de Pegex.

SYNTAXE

use Pegex;
my $result = pegex($grammar)->parse($input);

ou avec des options :

use Pegex;
use ReceiverClass;
my $parser = pegex($grammar, 'ReceiverClass');
my $result = $parser->parse($input);

ou plus explicitement :

use Pegex::Parser;
use Pegex::Grammar;
my $pegex_grammar = Pegex::Grammar->new(
    text => $grammar,
);
my $parser = Pegex::Parser->new(
    grammar => $pegex_grammar,
);
my $result = $parser->parse($input);

ou personnalisé explicitement :

{
    package MyGrammar;
    use Pegex::Base;
    extends 'Pegex::Grammar';
    has text => "votre définition de grammaire va ici";
    has receiver => "MyReceiver";
}
{
    package MyReceiver;
    use base 'Pegex::Receiver';
    got_some_rule { ... }
    got_other_rule { ... }
}
use Pegex::Parser;
my $parser = Pegex::Parser->new(
    grammar => MyGrammar->new,
    receiver => MyReceiver->new,
);
$parser->parse($input);
my $result = $parser->receiver->data;

DESCRIPTION

Pegex est un framework de parseur acméiste. Il vous permet de créer facilement des parseurs qui fonctionneront de manière équivalente dans de nombreux langages de programmation ! L'inspiration pour Pegex vient du moteur d'analyse sur lequel repose le langage de programmation postmoderne Perl 6. Pegex apporte cette beauté aux autres langages *juste* modernes qui disposent d'un moteur d'expressions régulières normal.

Pegex tire son nom de la combinaison des grammaires d'expressions d'analyse syntaxique (PEG) et des expressions régulières (Regex). C'est d'ailleurs ce que fait Pegex.

PEG est la nouvelle façon élégante de spécifier des grammaires de descente récursive. Le langage Perl 6 est défini en termes d'un langage PEG auto-modifiant appelé Perl 6 Rules. Les Regex sont familières aux programmeurs de la plupart des langages de programmation modernes. Pegex définit une syntaxe PEG simple, où tous les terminaux sont des regex. Cela signifie que Pegex peut être assez rapide et puissant.

Pegex tente d'être le moyen le plus simple de définir de nouveaux (ou anciens) langages spécifiques à un domaine (DSL) qui doivent être utilisés dans plusieurs langages et environnements de programmation. Des choses comme JSON, YAML, Markdown, etc. C'est aussi idéal pour écrire des parseurs/compilateurs qui n'ont besoin de fonctionner que dans un seul langage.

UTILISATION

Le module "Pegex.pm" lui-même (ce module) n'est qu'un moyen trivial d'utiliser le framework Pegex. Il est uniquement destiné aux utilisations les plus simples.

Ce module exporte une seule fonction, "pegex", qui prend une chaîne de grammaire Pegex en entrée. Vous pouvez également passer un nom de classe réceptrice après la grammaire.

my $parser = pegex($grammar, 'MyReceiver');

La fonction "pegex" renvoie un objet Pegex::Parser, sur lequel vous appellerez typiquement la méthode parse(), qui (en cas de succès) renverra une structure de données des données analysées.

Voir Pegex::API pour plus de détails.

DÉBOGAGE PEGEX

Pegex (Pegex::Parser) dispose de nombreuses méthodes de débogage faciles à utiliser. Voir la section "Debugging" de Pegex::Parser pour les détails.
