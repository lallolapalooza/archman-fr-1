NOM

PKCS5_PBKDF2_HMAC, PKCS5_PBKDF2_HMAC_SHA1 - routines de dérivation de clé basées sur un mot de passe avec sel et compteur d'itérations

SYNTAXE

#include <openssl/evp.h>
int PKCS5_PBKDF2_HMAC(const char *pass, int passlen,
                      const unsigned char *salt, int saltlen, int iter,
                      const EVP_MD *digest,
                      int keylen, unsigned char *out);
int PKCS5_PBKDF2_HMAC_SHA1(const char *pass, int passlen,
                           const unsigned char *salt, int saltlen, int iter,
                           int keylen, unsigned char *out);

DESCRIPTION

PKCS5_PBKDF2_HMAC() dérive une clé d'un mot de passe en utilisant un sel et un compteur d'itérations comme spécifié dans la RFC 2898.

pass est le mot de passe utilisé pour la dérivation de longueur passlen. pass est un paramètre optionnel et peut être NULL. Si passlen est -1, la fonction calculera la longueur de pass en utilisant strlen().

salt est le sel utilisé dans la dérivation de longueur saltlen. Si le salt est NULL, alors saltlen doit être 0. La fonction n'essaiera pas de calculer la longueur du salt car on suppose qu'il n'est pas terminé par un caractère nul.

iter est le compteur d'itérations et sa valeur doit être supérieure ou égale à 1. La RFC 2898 suggère un nombre d'itérations d'au moins 1000. Toute valeur d'iter inférieure à 1 est invalide ; de telles valeurs entraîneront un échec et lèveront l'erreur PROV_R_INVALID_ITERATION_COUNT.

digest est la fonction de résumé de message utilisée dans la dérivation. PKCS5_PBKDF2_HMAC_SHA1() appelle PKCS5_PBKDF2_HMAC() avec EVP_sha1().

La clé dérivée sera écrite dans out. La taille du tampon out est spécifiée via keylen.

NOTES

Une application typique de cette fonction est de dériver des matériaux de chiffrement pour un algorithme de chiffrement à partir d'un mot de passe dans pass, d'un sel dans salt, et d'un nombre d'itérations.

Augmenter le paramètre iter ralentit l'algorithme, ce qui rend plus difficile pour un attaquant d'effectuer une attaque par force brute à l'aide d'un grand nombre de mots de passe candidats.

Ces fonctions ne font aucune hypothèse concernant le mot de passe fourni. Il sera simplement traité comme une séquence d'octets.

VALEURS DE RETOUR

PKCS5_PBKDF2_HMAC() et PBKCS5_PBKDF2_HMAC_SHA1() renvoient 1 en cas de succès ou 0 en cas d'erreur.
