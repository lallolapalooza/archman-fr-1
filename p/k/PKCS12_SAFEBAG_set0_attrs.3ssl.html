NOM

PKCS12_SAFEBAG_set0_attrs - Définit les attributs d'un PKCS#12 safeBag

SYNOPSIS

#include <openssl/pkcs12.h>
void PKCS12_SAFEBAG_set0_attrs(PKCS12_SAFEBAG *bag, STACK_OF(X509_ATTRIBUTE) *attrs);

DESCRIPTION

PKCS12_SAFEBAG_set0_attrs() assigne la pile d'attributs X509_ATTRIBUTE à un PKCS#12 safeBag. bag est le PKCS12_SAFEBAG auquel les attributs doivent être assignés.

VALEURS DE RETOUR

PKCS12_SAFEBAG_set0_attrs() ne retourne aucune valeur.

HISTORIQUE

Cette fonction a été ajoutée dans OpenSSL 3.2.
