NOM

PKCS12_key_gen_asc, PKCS12_key_gen_asc_ex, PKCS12_key_gen_uni, PKCS12_key_gen_uni_ex, PKCS12_key_gen_utf8, PKCS12_key_gen_utf8_ex - Dérivation de clé PKCS#12 basée sur un mot de passe

SYNTAXE

#include <openssl/pkcs12.h>
int PKCS12_key_gen_asc(const char *pass, int passlen, unsigned char *salt,
                       int saltlen, int id, int iter, int n,
                       unsigned char *out, const EVP_MD *md_type);
int PKCS12_key_gen_asc_ex(const char *pass, int passlen, unsigned char *salt,
                          int saltlen, int id, int iter, int n,
                          unsigned char *out, const EVP_MD *md_type,
                          OSSL_LIB_CTX *ctx, const char *propq);
int PKCS12_key_gen_uni(unsigned char *pass, int passlen, unsigned char *salt,
                       int saltlen, int id, int iter, int n,
                       unsigned char *out, const EVP_MD *md_type);
int PKCS12_key_gen_uni_ex(unsigned char *pass, int passlen, unsigned char *salt,
                          int saltlen, int id, int iter, int n,
                          unsigned char *out, const EVP_MD *md_type,
                          OSSL_LIB_CTX *ctx, const char *propq);
int PKCS12_key_gen_utf8(const char *pass, int passlen, unsigned char *salt,
                        int saltlen, int id, int iter, int n,
                        unsigned char *out, const EVP_MD *md_type);
int PKCS12_key_gen_utf8_ex(const char *pass, int passlen, unsigned char *salt,
                           int saltlen, int id, int iter, int n,
                           unsigned char *out, const EVP_MD *md_type,
                           OSSL_LIB_CTX *ctx, const char *propq);

DESCRIPTION

Ces méthodes effectuent une dérivation de clé conformément à PKCS#12 (RFC7292) avec un mot de passe d'entrée pass de longueur passlen, un sel salt de longueur saltlen, un nombre d'itérations iter et un algorithme de hachage md_type. L'octet ID id détermine comment la clé résultante est censée être utilisée :

  • Si ID=1, alors les bits pseudo-aléatoires produits sont destinés à être utilisés comme matériau de clé pour le chiffrement ou le déchiffrement.
  • Si ID=2, alors les bits pseudo-aléatoires produits sont destinés à être utilisés comme IV (valeur initiale) pour le chiffrement ou le déchiffrement.
  • Si ID=3, alors les bits pseudo-aléatoires produits sont destinés à être utilisés comme clé d'intégrité pour le MAC.

Le format attendu du mot de passe fourni est déterminé par la méthode choisie :

  • PKCS12_key_gen_asc() et PKCS12_key_gen_asc_ex() attendent un mot de passe au format ASCII.
  • PKCS12_key_gen_uni() et PKCS12_key_gen_uni_ex() attendent un mot de passe au format Unicode.
  • PKCS12_key_gen_utf8() et PKCS12_key_gen_utf8_ex() attendent un mot de passe encodé en UTF-8.

pass est le mot de passe utilisé dans la dérivation de longueur passlen. pass est un paramètre optionnel et peut être NULL. Si passlen est -1, la fonction calculera la longueur de pass en utilisant strlen().

salt est le sel utilisé dans la dérivation de longueur saltlen. Si salt est NULL, alors saltlen doit être 0. La fonction ne tentera pas de calculer la longueur de salt car il n'est pas supposé être terminé par NULL.

iter est le nombre d'itérations et sa valeur doit être supérieure ou égale à 1. La RFC 2898 suggère un nombre d'itérations d'au moins 1000. Toute valeur de iter inférieure à 1 est traitée comme une seule itération.

digest est la fonction de résumé de message utilisée dans la dérivation.

La clé dérivée sera écrite dans out. La taille du tampon out est spécifiée par n.

Les fonctions se terminant par _ex() permettent d'utiliser un contexte de bibliothèque ctx et une requête de propriétés propq pour sélectionner les implémentations d'algorithmes.

NOTES

Une application typique de cette fonction est de dériver du matériau de clé pour un algorithme de chiffrement à partir d'un mot de passe dans pass, d'un sel dans salt et d'un nombre d'itérations.

Augmenter le paramètre iter ralentit l'algorithme, ce qui rend plus difficile pour un attaquant d'effectuer une attaque par force brute utilisant un grand nombre de mots de passe candidats.

VALEUR DE RETOUR

Retourne 1 en cas de succès ou 0 en cas d'erreur.
