PKCS12_decrypt_skey(3ssl)

Paquet: openssl

Licences: Apache-2.0

PKCS12_DECRYPT_SKEY(3ssl) OpenSSL PKCS12_DECRYPT_SKEY(3ssl)

NOM

PKCS12_decrypt_skey, PKCS12_decrypt_skey_ex - Fonctions de déchiffrement de clé protégée PKCS12

SYNOPSIS

#include <openssl/pkcs12.h>
PKCS8_PRIV_KEY_INFO *PKCS12_decrypt_skey(const PKCS12_SAFEBAG *bag,
                                         const char *pass, int passlen);
PKCS8_PRIV_KEY_INFO *PKCS12_decrypt_skey_ex(const PKCS12_SAFEBAG *bag,
                                            const char *pass, int passlen,
                                            OSSL_LIB_CTX *ctx,
                                            const char *propq);

DESCRIPTION

PKCS12_decrypt_skey() déchiffre le conteneur de clés protégé PKCS#8 contenu dans bag en utilisant le mot de passe fourni pass de longueur passlen.

PKCS12_decrypt_skey_ex() est similaire à la fonction ci-dessus, mais permet d'utiliser un contexte de bibliothèque ctx et une requête de propriétés propq pour sélectionner les implémentations d'algorithmes.

VALEURS DE RETOUR

Les deux fonctions retourneront la clé déchiffrée ou NULL en cas d'erreur.

CONFORMITÉ

IETF RFC 7292 (https://tools.ietf.org/html/rfc7292)

VOIR AUSSI

PKCS8_decrypt_ex(3), PKCS8_encrypt_ex(3), PKCS12_add_key_ex(3), PKCS12_SAFEBAG_create_pkcs8_encrypt_ex(3)

HISTORIQUE

PKCS12_decrypt_skey_ex() a été ajouté dans OpenSSL 3.0.
