PKCS12_PBE_keyivgen(3ssl)

Paquet: openssl

Licences: Apache-2.0

PKCS12_PBE_keyivgen(3ssl) OpenSSL PKCS12_PBE_KEYIVGEN(3ssl)

NOM

PKCS12_PBE_keyivgen, PKCS12_PBE_keyivgen_ex, PKCS12_pbe_crypt, PKCS12_pbe_crypt_ex - Chiffrement basé sur mot de passe PKCS#12

SYNTAXE

#include <openssl/evp.h>
int PKCS12_PBE_keyivgen(EVP_CIPHER_CTX *ctx, const char *pass, int passlen,
                        ASN1_TYPE *param, const EVP_CIPHER *cipher,
                        const EVP_MD *md_type, int en_de);
int PKCS12_PBE_keyivgen_ex(EVP_CIPHER_CTX *ctx, const char *pass, int passlen,
                           ASN1_TYPE *param, const EVP_CIPHER *cipher,
                           const EVP_MD *md_type, int en_de,
                           OSSL_LIB_CTX *libctx, const char *propq);
unsigned char *PKCS12_pbe_crypt(const X509_ALGOR *algor,
                                const char *pass, int passlen,
                                const unsigned char *in, int inlen,
                                unsigned char **data, int *datalen,
                                int en_de);
unsigned char *PKCS12_pbe_crypt_ex(const X509_ALGOR *algor,
                                   const char *pass, int passlen,
                                   const unsigned char *in, int inlen,
                                   unsigned char **data, int *datalen,
                                   int en_de, OSSL_LIB_CTX *libctx,
                                   const char *propq);

DESCRIPTION

PKCS12_PBE_keyivgen() et PKCS12_PBE_keyivgen_ex() prennent un mot de passe pass de longueur passlen, des paramètres param et une fonction de résumé de message md_type et effectuent une dérivation de clé selon PKCS#12. La clé résultante est ensuite utilisée pour initialiser le contexte de chiffrement ctx avec un chiffrement cipher pour le chiffrement (en_de=1) ou le déchiffrement (en_de=0).

PKCS12_PBE_keyivgen_ex() permet également à l'application de spécifier un contexte de bibliothèque libctx et une requête de propriété propq pour sélectionner les implémentations d'algorithmes appropriées.

PKCS12_pbe_crypt() et PKCS12_pbe_crypt_ex() vont chiffrer ou déchiffrer un tampon en se basant sur l'algorithme dans algor et le mot de passe pass de longueur passlen. L'entrée provient de in de longueur inlen et la sortie est dans un tampon alloué par malloc retourné dans *data de longueur datalen. L'opération est déterminée par en_de, chiffrement (en_de=1) ou déchiffrement (en_de=0).

PKCS12_pbe_crypt_ex() permet à l'application de spécifier un contexte de bibliothèque libctx et une requête de propriété propq pour sélectionner les implémentations d'algorithmes appropriées.

pass est le mot de passe utilisé dans la dérivation de longueur passlen. pass est un paramètre optionnel et peut être NULL. Si passlen est -1, la fonction calculera la longueur de pass en utilisant strlen().

salt est le sel utilisé dans la dérivation de longueur saltlen. Si le salt est NULL, alors saltlen doit être 0. La fonction ne tentera pas de calculer la longueur du salt car il n'est pas supposé être terminé par un nul.

iter est le nombre d'itérations et sa valeur doit être supérieure ou égale à 1. RFC 2898 suggère un nombre d'itérations d'au moins 1000. Tout iter inférieur à 1 est traité comme une seule itération.

digest est la fonction de résumé de message utilisée dans la dérivation.

Les fonctions se terminant par _ex() prennent des paramètres optionnels libctx et propq qui sont utilisés pour sélectionner les implémentations d'algorithmes appropriées.

NOTES

Les fonctions sont typiquement utilisées dans PKCS#12 pour chiffrer des objets.

Ces fonctions ne font aucune hypothèse concernant le mot de passe donné. Il sera simplement traité comme une séquence d'octets.

VALEURS DE RETOUR

PKCS12_PBE_keyivgen(), PKCS12_PBE_keyivgen_ex() retournent 1 en cas de succès ou 0 en cas d'erreur.

PKCS12_pbe_crypt() et PKCS12_pbe_crypt_ex() retournent un tampon contenant la sortie ou NULL si une erreur s'est produite.

CONFORMITE

IETF RFC 7292 (https://tools.ietf.org/html/rfc7292)

VOIR AUSSI

EVP_PBE_CipherInit_ex(3), PKCS8_encrypt_ex(3), passphrase-encoding(7)

HISTORIQUE

PKCS12_PBE_keyivgen_ex() et PKCS12_pbe_crypt_ex() ont été ajoutés dans OpenSSL 3.0.
