NOM

PkgConfig::LibPkgConf - Interface pour les fichiers .pc via libpkgconf

SYNOPIS

use PkgConfig::LibPkgConf;

if(pkgconf_exists('libarchive'))
{
  my $version = pkgconf_version('libarchive');
  my $cflags  = pkgconf_cflags('libarchive');
  my $libs    = pkgconf_libs('libarchive');
}

DESCRIPTION

Beaucoup de bibliothèques dans les langages compilés comme C ou C++ fournissent des fichiers ".pc" pour spécifier les drapeaux requis pour compiler et lier ces bibliothèques. Traditionnellement, le programme en ligne de commande "pkg-config" est utilisé pour interroger ces fichiers. Ce module fournit une API de niveau Perl utilisant "libpkgconf" pour accéder à ces fichiers.

Ce module fournit une interface simplifiée pour obtenir l'existence, la version, les cflags et les drapeaux de bibliothèque nécessaires à la compilation contre un paquet, en utilisant la configuration par défaut compilée dans "pkgconf". Pour une interface plus puissante, mais plus complexe, voir PkgConfig::LibPkgConf::Client. De plus, PkgConfig::LibPkgConf::Util fournit des fonctions utilitaires utiles qui sont également fournies par "pkgconf".

FONCTIONS

pkgconf_exists

my $bool = pkgconf_exists $nom_paquet;

Retourne vrai si le paquet est disponible.

Exporté par défaut.

pkgconf_version

my $version = pkgconf_version $nom_paquet;

Retourne la version du paquet, s'il existe. Lèvera une exception s'il n'est pas trouvé.

Exporté par défaut.

pkgconf_cflags

my $cflags = pkgconf_cflags $nom_paquet;

Retourne les drapeaux du compilateur pour le paquet, s'il existe. Lèvera une exception s'il n'est pas trouvé.

Exporté par défaut.

pkgconf_cflags_static

my $cflags = pkgconf_cflags_static $nom_paquet;

Retourne les drapeaux de compilation statiques pour le paquet, s'il existe. Lèvera une exception s'il n'est pas trouvé.

pkgconf_libs

my $libs = pkgconf_libs $nom_paquet;

Retourne les drapeaux de bibliothèques de l'éditeur de liens pour le paquet, s'il existe. Lèvera une exception s'il n'est pas trouvé.

Exporté par défaut.

pkgconf_libs_static

my $libs = pkgconf_libs_static $nom_paquet;

Retourne les drapeaux de bibliothèques statiques de l'éditeur de liens pour le paquet, s'il existe. Lèvera une exception s'il n'est pas trouvé.

VOIR AUSSI

Le meilleur point d'entrée vers l'interface de bas niveau de "pkgconf" peut être trouvé via PkgConfig::LibPkgConf::Client.

Les alternatives incluent :

PkgConfig
Implémentation pure Perl de "pkg-config" qui peut être utilisée en ligne de commande, ou comme API depuis Perl. Ne nécessite pas pkg-config dans votre PATH, donc c'est une dépendance sûre pour les modules CPAN.
ExtUtils::PkgConfig
Wrapper pour l'interface en ligne de commande "pkg-config". Ce module échouera à l'installation si "pkg-config" ne peut pas être trouvé dans le "PATH", il n'est donc pas sûr de l'utiliser comme dépendance si vous voulez que votre module CPAN fonctionne sur des plateformes où "pkg-config" n'est pas installé.
Alien::Base
Fournit des outils pour construire des bibliothèques non-Perl et en faire des dépendances pour vos modules CPAN, même sur des plateformes où les bibliothèques non-Perl ne sont pas déjà installées. Comprend des hooks pour sonder les fichiers ".pc" de "pkg-config" en utilisant soit "pkg-config", soit PkgConfig.
