PkgConfig::LibPkgConf::Client(3) Documentation Perl Contribuée par l'Utilisateur PkgConfig::LibPkgConf::Client(3)

NOM

PkgConfig::LibPkgConf::Client - Interroger les bibliothèques installées pour la compilation et la liaison de logiciels

SYNTAXE

use PkgConfig::LibPkgConf::Client;

my $client = PkgConfig::LibPkgConf::Client->new;
$client->env;

my $pkg = $client->find('libarchive');
my $cflags = $pkg->cflags;
my $libs = $pkg->libs;

DESCRIPTION

Les objets PkgConfig::LibPkgConf::Client stockent tout l'état nécessaire pour "libpkgconf", permettant à plusieurs instances de s'exécuter en parallèle.

CONSTRUCTEUR

new

my $client = PkgConfig::LibPkgConf::Client->new(%opts);
my $client = PkgConfig::LibPkgConf::Client->new(\%opts);

Crée une instance de PkgConfig::LibPkgConf::Client. Les options possibles incluent :

path
Le chemin de recherche pour les fichiers ".pc". Ceci peut être spécifié soit comme une chaîne avec le caractère séparateur de chemin approprié, soit comme une référence de liste. Cela remplacera les valeurs par défaut compilées de "pkgconf" et les variables d'environnement pour "PKG_CONFIG_PATH" ou "PKG_CONFIG_LIBDIR".
filter_lib_dirs
Liste des répertoires à filtrer pour les bibliothèques. Cela remplace la valeur par défaut compilée de "pkgconf" et la variable d'environnement pour "PKG_CONFIG_SYSTEM_LIBRARY_PATH".
filter_include_dirs
Liste des répertoires à filtrer pour les fichiers d'inclusion. Cela remplace la valeur par défaut compilée de "pkgconf" et la variable d'environnement pour "PKG_CONFIG_SYSTEM_INCLUDE_PATH".

Variables d'environnement prises en compte :

PKG_CONFIG_PATH
PKG_CONFIG_LIBDIR
PKG_CONFIG_SYSTEM_LIBRARY_PATH
PKG_CONFIG_SYSTEM_INCLUDE_PATH
PKG_CONFIG_ALLOW_SYSTEM_CFLAGS
PKG_CONFIG_ALLOW_SYSTEM_LIBS

ATTRIBUTS

path

my @path = $client->path;

Le chemin de recherche pour les fichiers ".pc".

filter_lib_dirs

my @dirs = $client->filter_lib_dirs;

Liste des répertoires à filtrer pour les bibliothèques.

filter_include_dirs

my @dirs = $client->filter_include_dirs;

Liste des répertoires à filtrer pour les fichiers d'inclusion.

sysroot_dir

my $dir = $client->sysroot_dir;
$client->sysroot_dir($dir);

Obtenir ou définir le répertoire sysroot.

buildroot_dir

my $dir = $client->buildroot_dir;
$client->buildroot_dir($dir);

Obtenir ou définir le répertoire buildroot.

maxdepth

my $int = $client->maxdepth;
$client->maxdepth($int);

Obtenir ou définir la profondeur de dépendance maximale. La valeur par défaut est 2000.

MÉTHODES

env

my $client->env;

Cette méthode charge les paramètres de l'objet client à partir de l'environnement en utilisant les variables d'environnement standard "pkg-config" ou "pkgconf". Elle respecte la liste suivante de variables d'environnement :

PKG_CONFIG_LOG

find

my $pkg = $client->find($package_name);

Recherche le fichier <.pc> pour le paquet avec le nom $package_name donné. S'il est trouvé, retourne une instance de PkgConfig::LibPkgConf::Package. Sinon, retourne "undef".

package_from_file

my $pkg = $client->package_from_file($filename);

Charge le fichier <.pc> spécifique.

scan_all

$client->scan_all(sub {
  my($client, $package) = @_;
  ...
  return $bool;
});

Itère sur tous les paquets et appelle la référence de sous-routine donnée pour chaque paquet. $package est une instance de PkgConfig::LibPkgConf::Package. L'analyse continue tant qu'une valeur non vraie est retournée (comme $bool).

global

$client->global($key => $value);
my $value = $client->global($key);

Définit ou obtient la variable globale.

error

my $client->error($message);

Appelé lorsque "libpkgconf" rencontre une erreur non fatale. Par défaut, l'erreur est simplement affichée comme un avertissement à l'aide de Carp. L'intention de cette méthode est que si vous souhaitez remplacer ce comportement, vous sous-classiez PkgConfig::LibPkgConf::Client et implémentiez votre propre version de la méthode "error".

audit_set_log

$client->audit_set_log($filename, $mode);

Ouvre un fichier avec le style C "fopen" pour le $mode, et l'utilise pour le journal d'audit. Le fichier est entièrement géré par la classe client et sera fermé lorsque l'objet sortira de sa portée. Exemples :

$client->audit_set_log("audit.log", "a"); # ajoute à un fichier existant
$client->audit_set_log("audit2.log", "w"); # nouveau fichier ou remplace le fichier existant

PkgConfig::LibPkgConf::Client(3pm)

Package PkgConfig-LibPkgConf Version 0.11-11

NAME

PkgConfig::LibPkgConf::Client - A Perl interface to libpkgconf's API

SYNOPSIS

use PkgConfig::LibPkgConf::Client;

my $client = PkgConfig::LibPkgConf::Client->new;
my $package = $client->get_package("foo");
if ($package) {
    print $package->get_cflags, "\n";
}

DESCRIPTION

This module provides a Perl interface to the libpkgconf library. libpkgconf is a library that implements the pkg-config tool's API. This module allows you to query information about installed libraries, such as their C compiler flags, linker flags, and version numbers, directly from your Perl scripts.

CONSTRUCTOR

new()

Creates a new PkgConfig::LibPkgConf::Client object. This will initialize the underlying libpkgconf context.

ATTRIBUTES

search_path

An array reference of directories to search for `.pc` files. Setting this attribute will update the search path for the libpkgconf context.

my @paths = $client->search_path;
$client->search_path([ "/usr/share/pkgconfig", "/usr/lib/pkgconfig" ]);
cflags_only

A boolean value. If true, only C compiler flags will be returned by default. Defaults to false.

$client->cflags_only(1);
requires_only

A boolean value. If true, only the requires flags will be returned by default. Defaults to false.

$client->requires_only(1);

METHODS

get_package($name)

Retrieves information about a package with the given name. Returns a PkgConfig::LibPkgConf::Package object if found, or undef otherwise.

exists($name)

Checks if a package with the given name exists. Returns true if it exists, false otherwise.

list_packages()

Returns a list of all available package names.

get_cflags($name)

Returns the C compiler flags for the specified package. Equivalent to pkgconf --cflags $name.

get_libs($name)

Returns the linker flags for the specified package. Equivalent to pkgconf --libs $name.

get_version($name)

Returns the version of the specified package. Equivalent to pkgconf --modversion $name.

get_requires($name)

Returns a list of package names that the specified package requires. Equivalent to pkgconf --requires $name.

get_requires_private($name)

Returns a list of package names that the specified package requires privately. Equivalent to pkgconf --requires-private $name.

get_provides($name)

Returns a list of package names that the specified package provides. Equivalent to pkgconf --provides $name.

get_description($name)

Returns the description of the specified package. Equivalent to pkgconf --description $name.

get_url($name)

Returns the URL of the specified package. Equivalent to pkgconf --url $name.
