NOM

PkgConfig::LibPkgConf::Package - Représente un paquet

SYNOPSIS

use PkgConfig::LibPkgConf::Client;

my $client = PkgConfig::LibPkgConf::Client->new;
$client->env;

my $pkg = $client->find('libarchive');

# utilisation avec system sous forme scalaire :
my $cflags = $pkg->cflags;
my $libs = $pkg->libs;
system "$cc $cflags foo.c";
system "$cc -o foo foo.o $libs";

# utilisation avec system sous forme de liste :
my @cflags = $pkg->list_cflags;
my @libs   = $pkg->list_libs;
system $cc, @cflags, 'foo.c';
system $cc, -p => 'foo', 'foo.o', @libs;

DESCRIPTION

L'objet PkgConfig::LibPkgConf::Package stocke les informations du paquet. Une partie des informations du paquet concerne les indicateurs du compilateur et de l'éditeur de liens. Celles-ci peuvent être récupérées sous forme de chaînes de caractères avec "cflags" et "libs", et sous forme de liste avec "list_cflags" et "list_libs". Sous forme de chaîne de caractères, les échappements sont conservés, mais sous forme de liste, les échappements d'espaces blancs sont convertis en espaces. Cela signifie que si vous utilisez la forme chaîne de caractères de "system"/"exec", vous devriez utiliser les accesseurs de chaîne de caractères, et si vous utilisez la forme liste de "system"/"exec", vous devriez utiliser les accesseurs de liste.

MÉTHODES

libs

Indicateurs de bibliothèques. Cela inclut généralement des éléments tels que "-L/foo/lib" et "-lfoo".

libs_static

Indicateurs de bibliothèques statiques.

cflags

Indicateurs du compilateur. Cela inclut généralement des éléments tels que "-I/foo/include" et "-DFOO=1".

cflags_static

Indicateurs statiques du compilateur.

list_libs

my @fragments = $package->list_libs;

Indicateurs de bibliothèques sous forme de liste de fragments PkgConfig::LibPkgConf::Fragment. C'est similaire à la méthode "libs" ci-dessus, mais comme elle renvoie une liste au lieu d'une seule chaîne de caractères, elle peut être utilisée pour filtrer des indicateurs spécifiques. Par exemple :

# équivalent à pkgconf --libs-only-L
my @lib_dirs = grep { $_->type eq 'L' } $package->list_libs;
# équivalent à pkgconf --libs-only-l
my @libs = grep { $_->type eq 'l' } $package->list_libs;

list_libs_static

my @fragments = $package->list_libs_static;

Similaire à "list_libs", mais pour les indicateurs des bibliothèques statiques.

list_cflags

my @fragments = $package->list_cflags;

Indicateurs du compilateur sous forme de liste de fragments PkgConfig::LibPkgConf::Fragment. C'est similaire à la méthode "cflags" ci-dessus, mais comme elle renvoie une liste au lieu d'une seule chaîne de caractères, elle peut être utilisée pour filtrer des indicateurs spécifiques. Par exemple :

# équivalent à pkgconf --cflags-only-I
my @include_dirs = grep { $_->type eq 'I' } $package->list_cflags;
# équivalent à pkgconf --cflags-only-other
my @other_cflags = grep { $_->type ne 'I' } $package->list_cflags;

list_cflags_static

my @fragments = $package->list_cflags_static;

Similaire à "list_cflags", mais pour les indicateurs statiques du compilateur.

variable

my $value = $package->variable($key);

Recherche la valeur de la variable donnée. Renvoie la valeur si elle est trouvée, sinon elle renvoie undef (techniquement une liste vide).
