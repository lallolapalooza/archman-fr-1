NOM

PKCS12_add_CSPName_asc - Ajoute un attribut de nom CSP Microsoft à un safeBag PKCS#12

SYNOPIS

#include <openssl/pkcs12.h>
int PKCS12_add_CSPName_asc(PKCS12_SAFEBAG *bag, const char *name, int namelen);

DESCRIPTION

PKCS12_add_CSPName_asc() ajoute une représentation sous forme de chaîne ASCII de l'attribut de nom CSP Microsoft à un safeBag PKCS#12.

bag est le PKCS12_SAFEBAG auquel ajouter l'attribut.

VALEUR DE RETOUR

Retourne 1 en cas de succès ou 0 en cas d'échec.
