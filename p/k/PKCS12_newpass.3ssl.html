PKCS12_NEWPASS(3ssl) OpenSSL PKCS12_NEWPASS(3ssl)

NOM

PKCS12_newpass - changer le mot de passe d'une structure PKCS12

SYNTAXE

#include <openssl/pkcs12.h>
int PKCS12_newpass(PKCS12 *p12, const char *oldpass, const char *newpass);

DESCRIPTION

PKCS12_newpass() change le mot de passe d'une structure PKCS12.

p12 est un pointeur vers une structure PKCS12. oldpass est le mot de passe existant et newpass est le nouveau mot de passe.

Chacun de oldpass et newpass est interprété indépendamment comme une chaîne de caractères encodée en UTF-8. Si ce n'est pas du UTF-8 valide, il est supposé être du ISO8859-1 à la place.

En particulier, cela signifie que les mots de passe dans le jeu de caractères local (ou la page de code sous Windows) doivent potentiellement être convertis en UTF-8 avant utilisation. Cela peut inclure les mots de passe provenant de fichiers texte locaux, ou des entrées du terminal ou de la ligne de commande. Référez-vous à la documentation de UI_OpenSSL(3), par exemple.

Si la structure PKCS#12 n'a pas de mot de passe, vous devez utiliser la chaîne vide "" pour oldpass. Utiliser NULL pour oldpass entraînera un échec de PKCS12_newpass().

Si le mauvais mot de passe est utilisé pour oldpass, la fonction échouera, avec une erreur de vérification MAC. Dans de rares cas, la structure PKCS12 ne contient pas de MAC : dans ce cas, elle échouera généralement avec une erreur de padding de décryptage.

VALEURS DE RETOUR

PKCS12_newpass() renvoie 1 en cas de succès ou 0 en cas d'échec. Les applications peuvent récupérer la dernière erreur de PKCS12_newpass() avec ERR_get_error().

EXEMPLES

Cet exemple charge un fichier PKCS#12, change son mot de passe et écrit le résultat dans un nouveau fichier.

#include <stdio.h>
#include <stdlib.h>
#include <openssl/pem.h>
#include <openssl/err.h>
#include <openssl/pkcs12.h>
int main(int argc, char **argv)
{
    FILE *fp;
    PKCS12 *p12;
    if (argc != 5) {
        fprintf(stderr, "Usage: pkread p12file password newpass opfile\n");
        return 1;
    }
    if ((fp = fopen(argv[1], "rb")) == NULL) {
        fprintf(stderr, "Erreur lors de l'ouverture du fichier %s\n", argv[1]);
        return 1;
    }
    p12 = d2i_PKCS12_fp(fp, NULL);
    fclose(fp);
    if (p12 == NULL) {
        fprintf(stderr, "Erreur lors de la lecture du fichier PKCS#12\n");
        ERR_print_errors_fp(stderr);
        return 1;
    }
    if (PKCS12_newpass(p12, argv[2], argv[3]) == 0) {
        fprintf(stderr, "Erreur lors du changement de mot de passe\n");
        ERR_print_errors_fp(stderr);
        PKCS12_free(p12);
        return 1;
    }
    if ((fp = fopen(argv[4], "wb")) == NULL) {
        fprintf(stderr, "Erreur lors de l'ouverture du fichier %s\n", argv[4]);
        PKCS12_free(p12);
        return 1;
    }
    i2d_PKCS12_fp(fp, p12);
    PKCS12_free(p12);
    fclose(fp);
    return 0;
}

BOGUES

Le format du mot de passe est une chaîne ASCII terminée par NULL qui est convertie en forme Unicode en interne. Par conséquent, certains mots de passe ne peuvent pas être fournis à cette fonction.
