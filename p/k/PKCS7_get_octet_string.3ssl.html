NOM

PKCS7_get_octet_string - renvoie la chaîne d'octets d'une structure envelopedData PKCS#7

SYNTAXE

#include <openssl/pkcs7.h>
ASN1_OCTET_STRING *PKCS7_get_octet_string(PKCS7 *p7);

DESCRIPTION

PKCS7_get_octet_string() renvoie un pointeur vers une chaîne d'octets ASN1 à partir d'une structure envelopedData PKCS#7 ou NULL si la structure ne peut pas être analysée.

NOTES

Comme le suggère le 0, PKCS7_get_octet_string() renvoie des pointeurs internes qui ne doivent pas être libérés par l'appelant.

VALEURS DE RETOUR

PKCS7_get_octet_string() renvoie un pointeur ASN1_OCTET_STRING.

VOIR AUSSI

PKCS7_type_is_data(3)
