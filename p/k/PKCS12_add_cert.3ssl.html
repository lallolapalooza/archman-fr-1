PKCS12_add_cert(3ssl)

Paquet: openssl

Licences: Apache-2.0

PKCS12_ADD_CERT(3ssl) OpenSSL PKCS12_ADD_CERT(3ssl)

NOM

PKCS12_add_cert, PKCS12_add_key, PKCS12_add_key_ex, PKCS12_add_secret - Ajouter un objet à un ensemble de safeBags PKCS#12

SYNTAXE

#include <openssl/pkcs12.h>
PKCS12_SAFEBAG *PKCS12_add_cert(STACK_OF(PKCS12_SAFEBAG) **pbags, X509 *cert);
PKCS12_SAFEBAG *PKCS12_add_key(STACK_OF(PKCS12_SAFEBAG) **pbags,
                              EVP_PKEY *key, int key_usage, int iter,
                              int key_nid, const char *pass);
PKCS12_SAFEBAG *PKCS12_add_key_ex(STACK_OF(PKCS12_SAFEBAG) **pbags,
                                  EVP_PKEY *key, int key_usage, int iter,
                                  int key_nid, const char *pass,
                                  OSSL_LIB_CTX *ctx, const char *propq);
PKCS12_SAFEBAG *PKCS12_add_secret(STACK_OF(PKCS12_SAFEBAG) **pbags,
                                 int nid_type, const unsigned char *value, int len);

DESCRIPTION

Ces fonctions créent un nouveau PKCS12_SAFEBAG et l'ajoutent à l'ensemble des safeBags dans pbags.

PKCS12_add_cert() crée un certBag PKCS#12 contenant le certificat fourni et l'ajoute à l'ensemble des safeBags PKCS#12.

PKCS12_add_key() crée un keyBag PKCS#12 (non chiffré) ou un pkcs8shroudedKeyBag (chiffré) contenant le EVP_PKEY fourni et l'ajoute à l'ensemble des safeBags PKCS#12. Si key_nid n'est pas -1, alors la clé est chiffrée avec l'algorithme fourni, en utilisant pass comme mot de passe et iter comme nombre d'itérations. Si iter est zéro, alors une valeur par défaut de 2048 est utilisée pour le nombre d'itérations.

PKCS12_add_key_ex() est identique à PKCS12_add_key() mais permet l'utilisation d'un contexte de bibliothèque ctx et d'une requête de propriétés propq pour sélectionner les implémentations d'algorithmes.

PKCS12_add_secret() crée un secretBag PKCS#12 avec un OID correspondant au nid_type fourni, contenant la valeur fournie sous forme de chaîne d'octets ASN1. Ceci est ensuite ajouté à l'ensemble des safeBags PKCS#12.

NOTES

Si un certificat contient un alias ou un keyid, ceux-ci seront utilisés pour le friendlyName ou le localKeyID correspondant dans la structure PKCS12.

PKCS12_add_key() fait des hypothèses concernant le codage de la phrase secrète donnée. Voir passphrase-encoding(7) pour plus d'informations.

VALEURS DE RETOUR

Une structure PKCS12_SAFEBAG valide ou NULL si une erreur s'est produite.

CONFORME À

IETF RFC 7292 (https://tools.ietf.org/html/rfc7292)

VOIR AUSSI

PKCS12_create(3)

HISTORIQUE

PKCS12_add_secret() et PKCS12_add_key_ex() ont été ajoutés dans OpenSSL 3.0.
