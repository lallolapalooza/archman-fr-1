PkgConfig::LibPkgConf::Fragment(3) Documentation Perl fournie par l'utilisateur PkgConfig::LibPkgConf::Fragment(3)

NOM

PkgConfig::LibPkgConf::Fragment - Indicateur de compilation ou de liaison unique

SYNOPSIS

use PkgConfig::LibPkgConf::Client;

my $client = PkgConfig::LibPkgConf::Client->new;
$client->scan_all(sub {
  my($client, $package) = @_;
  # $package isa PkgConfig::LibPkgConf::Package
  foreach my $frag ($package->list_libs)
  {
    # $frag isa PkgConfig::LibPkgConf::Fragment
    if($frag->type eq 'L')
    {
      say "Répertoire de bibliothèque : ", $frag->data;
    }
    elsif($frag->type eq 'l')
    {
      say "Nom de la bibliothèque : ", $frag->data;
    }
  }
});

ATTRIBUTS

type

my $type = $frag->type;

Le type de l'indicateur. Peut être "undef" s'il n'y a pas de type.

data

my $data = $frag->data;

Les données du fragment.

to_string

my $string = $frag->to_string;
my $string = "$frag";

La représentation sous forme de chaîne du fragment. Vous pouvez également interpoler l'objet fragment dans une chaîne pour le convertir en chaîne.
