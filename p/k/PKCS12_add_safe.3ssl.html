PKCS12_ADD_SAFE(3ssl) OpenSSL PKCS12_ADD_SAFE(3ssl)

NOM

PKCS12_add_safe, PKCS12_add_safe_ex, PKCS12_add_safes, PKCS12_add_safes_ex - Créer et ajouter des objets à une structure PKCS#12

SYNOPSIS

#include <openssl/pkcs12.h>
int PKCS12_add_safe(STACK_OF(PKCS7) **psafes, STACK_OF(PKCS12_SAFEBAG) *bags,
                   int safe_nid, int iter, const char *pass);
int PKCS12_add_safe_ex(STACK_OF(PKCS7) **psafes, STACK_OF(PKCS12_SAFEBAG) *bags,
                       int safe_nid, int iter, const char *pass,
                       OSSL_LIB_CTX *ctx, const char *propq);
PKCS12 *PKCS12_add_safes(STACK_OF(PKCS7) *safes, int p7_nid);
PKCS12 *PKCS12_add_safes_ex(STACK_OF(PKCS7) *safes, int p7_nid,
                            OSSL_LIB_CTX *ctx, const char *propq);

DESCRIPTION

PKCS12_add_safe() crée une nouvelle contentInfo PKCS7 contenant les PKCS12_SAFEBAGs fournis et l'ajoute à un ensemble de contentInfos PKCS7. Son type dépend de la valeur de safe_nid :

  • Si safe_nid est -1, une contentInfo PKCS7 data simple est créée.
  • Si safe_nid est un NID d'algorithme PBE valide, une contentInfo PKCS7 encryptedData est créée. L'algorithme utilise pass comme mot de passe et iter comme nombre d'itérations. Si iter est zéro, une valeur par défaut de 2048 est utilisée pour le nombre d'itérations.
  • Si safe_nid est 0, une contentInfo PKCS7 encryptedData est créée en utilisant un algorithme de chiffrement par défaut, actuellement NID_pbe_WithSHA1And3_Key_TripleDES_CBC.

PKCS12_add_safe_ex() est identique à PKCS12_add_safe() mais permet l'utilisation d'un contexte de bibliothèque ctx et d'une requête de propriété propq pour sélectionner les implémentations d'algorithmes.

PKCS12_add_safes() crée une structure PKCS12 contenant l'ensemble fourni de contentInfos PKCS7. Les safes sont encapsulés d'abord dans une contentInfo PKCS7 de type p7_nid. Actuellement, le seul type supporté est NID_pkcs7_data.

PKCS12_add_safes_ex() est identique à PKCS12_add_safes() mais permet l'utilisation d'un contexte de bibliothèque ctx et d'une requête de propriété propq pour sélectionner les implémentations d'algorithmes.

NOTES

PKCS12_add_safe() fait des hypothèses concernant le codage de la phrase de passe fournie. Voir passphrase-encoding(7) pour plus d'informations.

VALEURS DE RETOUR

PKCS12_add_safe() retourne 1 en cas de succès ou 0 en cas d'échec.

PKCS12_add_safes() retourne une structure PKCS12 valide ou NULL si une erreur s'est produite.

CONFORME À

IETF RFC 7292 (https://tools.ietf.org/html/rfc7292)
