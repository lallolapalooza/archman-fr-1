PkgConfig::LibPkgConf::Util(3) Documentation Perl Contribuée par l'Utilisateur PkgConfig::LibPkgConf::Util(3)

NOM

PkgConfig::LibPkgConf::Util - Fonctions non orientées objet pour PkgConfig::LibPkgConf

SYNOPSIS

use PkgConfig::LibPkgConf::Util qw( argv_split compare_version );

my @args = argv_split('-L/foo -lfoo'); # ('-L/foo', '-lfoo');
my $cmp  = compare_version('1.2.3','1.2.4');

DESCRIPTION

Ce module fournit quelques fonctions utilitaires utiles qui sont fournies avec "libpkgconf", mais qui ne sont pas orientées objet et n'ont donc pas leur propre classe.

FONCTIONS

argv_split

my @argv = argv_split $args;

Divise une chaîne en une liste d'arguments.

compare_version

my $cmp = compare_version($version1, $version2);

Compare des versions en utilisant les règles de comparaison de versions RPM telles que décrites dans le LSB. Renvoie -1 si la première version est supérieure, 0 si les deux versions sont égales, 1 si la seconde version est supérieure.

path_relocate

my $path = path_relocate($path);

Relocalise un chemin, appelant potentiellement realpath() ou cygwin_conv_path() dessus.

path_sep

my $sep = path_sep;

Renvoie le séparateur de chemin tel qu'il est compris par "pkgconf". C'est généralement ":" sur UNIX et ";" sur Windows.
