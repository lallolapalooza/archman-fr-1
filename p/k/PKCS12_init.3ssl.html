PKCS12_init(3ssl)

Paquet: openssl

Licences: Apache-2.0

PKCS12_INIT(3ssl) OpenSSL PKCS12_INIT(3ssl)

NOM

PKCS12_init, PKCS12_init_ex - Créer une nouvelle structure PKCS#12 vide

SYNTAXE

#include <openssl/pkcs12.h>
PKCS12 *PKCS12_init(int mode);
PKCS12 *PKCS12_init_ex(int mode, OSSL_LIB_CTX *ctx, const char *propq);

DESCRIPTION

PKCS12_init() crée une structure PKCS#12 vide. Les authSafes PKCS#7 ajoutées à cette structure sont d'abord encapsulées dans un seul contentInfo PKCS#7 de type mode. Actuellement, le seul type supporté est NID_pkcs7_data.

PKCS12_init_ex() crée une structure PKCS#12 vide et lui associe le ctx et le propq fournis pour être utilisés afin de sélectionner les implémentations d'algorithmes pour les opérations effectuées sur l'objet PKCS12.

VALEURS DE RETOUR

PKCS12_init() et PKCS12_init_ex() retournent une structure PKCS12 valide ou NULL si une erreur s'est produite.

VOIR AUSSI

d2i_PKCS12(3), PKCS12_create(3), passphrase-encoding(7)

HISTORIQUE

PKCS12_init_ex() a été ajoutée dans OpenSSL 3.0.
