NOM

PKCS7_type_is_other - déterminer le type de contenu de la structure envelopedData PKCS#7

SYNTAXE

#include <openssl/pkcs7.h>
int PKCS7_type_is_other(PKCS7 *p7);

DESCRIPTION

PKCS7_type_is_other() renvoie si le type de contenu d'une structure envelopedData PKCS#7 est l'un des types de contenu suivants :

NID_pkcs7_data NID_pkcs7_signed NID_pkcs7_enveloped NID_pkcs7_signedAndEnveloped NID_pkcs7_digest NID_pkcs7_encrypted

VALEURS DE RETOUR

PKCS7_type_is_other() renvoie soit 0 si le type de contenu correspond, soit 1 sinon.

VOIR AUSSI

PKCS7_type_is_data(3), PKCS7_get_octet_string(3)
