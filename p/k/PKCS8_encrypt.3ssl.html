PKCS8_encrypt(3ssl)

Paquet: openssl

Licences: Apache-2.0

PKCS8_ENCRYPT(3ssl) OpenSSL PKCS8_ENCRYPT(3ssl)

NOM

PKCS8_decrypt, PKCS8_decrypt_ex, PKCS8_encrypt, PKCS8_encrypt_ex, PKCS8_set0_pbe, PKCS8_set0_pbe_ex - Fonctions de chiffrement/déchiffrement PKCS8

SYNOPIS

#include <openssl/x509.h>
PKCS8_PRIV_KEY_INFO *PKCS8_decrypt(const X509_SIG *p8, const char *pass,
                                   int passlen);
PKCS8_PRIV_KEY_INFO *PKCS8_decrypt_ex(const X509_SIG *p8, const char *pass,
                                      int passlen, OSSL_LIB_CTX *ctx,
                                      const char *propq);
X509_SIG *PKCS8_encrypt(int pbe_nid, const EVP_CIPHER *cipher,
                        const char *pass, int passlen, unsigned char *salt,
                        int saltlen, int iter, PKCS8_PRIV_KEY_INFO *p8);
X509_SIG *PKCS8_encrypt_ex(int pbe_nid, const EVP_CIPHER *cipher,
                           const char *pass, int passlen, unsigned char *salt,
                           int saltlen, int iter, PKCS8_PRIV_KEY_INFO *p8,
                           OSSL_LIB_CTX *ctx, const char *propq);
X509_SIG *PKCS8_set0_pbe(const char *pass, int passlen,
                        PKCS8_PRIV_KEY_INFO *p8inf, X509_ALGOR *pbe);
X509_SIG *PKCS8_set0_pbe_ex(const char *pass, int passlen,
                            PKCS8_PRIV_KEY_INFO *p8inf, X509_ALGOR *pbe,
                            OSSL_LIB_CTX *ctx);

DESCRIPTION

PKCS8_encrypt() et PKCS8_encrypt_ex() effectuent le chiffrement d'un objet p8 à l'aide du mot de passe pass de longueur passlen, du sel salt de longueur saltlen et du compteur d'itérations iter. Le X509_SIG résultant contient les paramètres de l'algorithme encodés et la clé chiffrée.

PKCS8_decrypt() et PKCS8_decrypt_ex() effectuent le déchiffrement d'un X509_SIG dans p8 à l'aide du mot de passe pass de longueur passlen ainsi que des paramètres de l'algorithme obtenus à partir de p8.

PKCS8_set0_pbe() et PKCS8_set0_pbe_ex() effectuent le chiffrement de p8inf à l'aide du mot de passe pass de longueur passlen et des paramètres pbe.

Les fonctions se terminant par _ex() permettent d'utiliser un contexte de bibliothèque ctx et une requête de propriété propq pour sélectionner les implémentations d'algorithmes.

VALEUR DE RETOUR

PKCS8_encrypt(), PKCS8_encrypt_ex(), PKCS8_set0_pbe() et PKCS8_set0_pbe_ex() retournent une clé chiffrée dans une structure X509_SIG ou NULL si une erreur se produit.

PKCS8_decrypt() et PKCS8_decrypt_ex() retournent un PKCS8_PRIV_KEY_INFO ou NULL si une erreur se produit.

CONFORMITÉ

IETF RFC 7292 (https://tools.ietf.org/html/rfc7292)

VOIR AUSSI

crypto(7)

HISTORIQUE

PKCS8_decrypt_ex(), PKCS8_encrypt_ex() et PKCS8_set0_pbe_ex() ont été ajoutés dans OpenSSL 3.0.
