PKCS12_add_friendlyname_asc(3ssl)

Licences: Apache-2.0

PKCS12_ADD_FRIENDLYNAME_ASC(3ssl) OpenSSL PKCS12_ADD_FRIENDLYNAME_ASC(3ssl)

NOM

PKCS12_add_friendlyname_asc, PKCS12_add_friendlyname_utf8, PKCS12_add_friendlyname_uni - Fonctions pour ajouter l'attribut friendlyname à un PKCS#12 safeBag

SYNOPSIS

#include <openssl/pkcs12.h>
int PKCS12_add_friendlyname_asc(PKCS12_SAFEBAG *bag, const char *name,
                                int namelen);
int PKCS12_add_friendlyname_utf8(PKCS12_SAFEBAG *bag, const char *name,
                                int namelen);
int PKCS12_add_friendlyname_uni(PKCS12_SAFEBAG *bag,
                                const unsigned char *name, int namelen);

DESCRIPTION

PKCS12_add_friendlyname_asc() ajoute une représentation en chaîne ASCII de l'attribut PKCS#9 friendlyName à un PKCS#12 safeBag.

PKCS12_add_friendlyname_utf8() ajoute une représentation en chaîne UTF-8 de l'attribut PKCS#9 friendlyName à un PKCS#12 safeBag.

PKCS12_add_friendlyname_uni() ajoute une représentation en chaîne Unicode de l'attribut PKCS#9 friendlyName à un PKCS#12 safeBag.

bag est le PKCS12_SAFEBAG auquel ajouter l'attribut.

VALEUR DE RETOUR

Renvoie 1 en cas de succès ou 0 en cas d'échec.

VOIR AUSSI
