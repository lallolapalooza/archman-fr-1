PKCS12_item_decrypt_d2i(3ssl)

Paquet: openssl

Licences: Apache-2.0

PKCS12_ITEM_DECRYPT_D2I(3ssl) OpenSSL PKCS12_ITEM_DECRYPT_D2I(3ssl)

NOM

PKCS12_item_decrypt_d2i, PKCS12_item_decrypt_d2i_ex, PKCS12_item_i2d_encrypt, PKCS12_item_i2d_encrypt_ex - Fonctions de chiffrement/déchiffrement d'éléments PKCS12

SYNOPIS

#include <openssl/pkcs12.h>
void *PKCS12_item_decrypt_d2i(const X509_ALGOR *algor, const ASN1_ITEM *it,
                              const char *pass, int passlen,
                              const ASN1_OCTET_STRING *oct, int zbuf);
void *PKCS12_item_decrypt_d2i_ex(const X509_ALGOR *algor, const ASN1_ITEM *it,
                                 const char *pass, int passlen,
                                 const ASN1_OCTET_STRING *oct, int zbuf,
                                 OSSL_LIB_CTX *libctx,
                                 const char *propq);
ASN1_OCTET_STRING *PKCS12_item_i2d_encrypt(X509_ALGOR *algor,
                                           const ASN1_ITEM *it,
                                           const char *pass, int passlen,
                                           void *obj, int zbuf);
ASN1_OCTET_STRING *PKCS12_item_i2d_encrypt_ex(X509_ALGOR *algor,
                                              const ASN1_ITEM *it,
                                              const char *pass, int passlen,
                                              void *obj, int zbuf,
                                              OSSL_LIB_CTX *ctx,
                                              const char *propq);

DESCRIPTION

PKCS12_item_decrypt_d2i() et PKCS12_item_decrypt_d2i_ex() déchiffrent une chaîne d'octets contenant un objet encodé ASN.1 en utilisant l'algorithme algor et le mot de passe pass de longueur passlen. Si zbuf est non nul, le tampon de sortie sera mis à zéro après le déchiffrement.

PKCS12_item_i2d_encrypt() et PKCS12_item_i2d_encrypt_ex() chiffrent un objet ASN.1 it en utilisant l'algorithme algor et le mot de passe pass de longueur passlen, retournant un objet encodé dans obj. Si zbuf est non nul, le tampon contenant l'encodage d'entrée sera mis à zéro après le chiffrement.

Les fonctions se terminant par _ex() permettent d'utiliser un contexte de bibliothèque ctx et une requête de propriété propq pour sélectionner les implémentations d'algorithmes.

VALEUR DE RETOUR

PKCS12_item_decrypt_d2i() et PKCS12_item_decrypt_d2i_ex() retournent l'objet déchiffré ou NULL si une erreur s'est produite.

PKCS12_item_i2d_encrypt() et PKCS12_item_i2d_encrypt_ex() retournent les données chiffrées sous forme d'une chaîne d'octets ASN.1 ou NULL si une erreur s'est produite.

VOIR AUSSI

PKCS12_pbe_crypt_ex(3), PKCS8_encrypt_ex(3)

HISTORIQUE

PKCS12_item_decrypt_d2i_ex() et PKCS12_item_i2d_encrypt_ex() ont été ajoutés dans OpenSSL 3.0.
