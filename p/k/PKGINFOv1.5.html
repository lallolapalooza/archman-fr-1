(5) Pages de manuel de format de fichier (5)

NOM

PKGINFO - Informations sur les paquets basés sur ALPM (version 1).

DESCRIPTION

Le format PKGINFO est un format textuel qui décrit les métadonnées d'un paquet. Ces fichiers se trouvent à la racine des paquets ALPM et sont nommés .PKGINFO. Ils sont utilisés, par exemple, par les gestionnaires de paquets pour évaluer et présenter le contexte d'un paquet au sein de son environnement. Les cas d'utilisation incluent la représentation des métadonnées communes et la relation avec d'autres paquets.

Le format PKGINFO existe en plusieurs versions. Ce document décrit la version 1, qui est une ancienne version et a été introduite avec la sortie de pacman 5.1.0 le 28 mai 2018. Pour la spécification la plus récente, consultez PKGINFO.

Format général

Un fichier PKGINFO consiste en une série de lignes, chacune fournissant des informations sur un aspect d'un paquet. Les lignes commençant par le caractère # sont des commentaires et sont toujours ignorées. Les espaces en début de ligne sont toujours ignorés.

Sauf indication contraire, les informations contenues dans un fichier PKGINFO sont considérées comme étant couvertes par l'ensemble des 95 caractères ASCII imprimables[1].

Mots-clés

Chaque ligne code l'information qu'elle représente comme une assignation mot-clé. Toutes les assignations mot-clé consistent en un nom de clé de la liste suivante, suivi d'un espace, d'un signe égal, d'un autre espace et d'une valeur.

Par défaut, il doit y avoir exactement une assignation mot-clé par mot-clé dans un fichier PKGINFO. Comme exception à cette règle, les mots-clés license, replaces, group, conflict, provides, backup, depend, optdepend, makedepend et checkdepend peuvent être fournis zéro ou plusieurs fois.

pkgname

Le nom du paquet. La valeur est un alpm-package-name (par exemple, example).

pkgbase

La alpm-package-base du paquet. La valeur est un alpm-package-base (par exemple, example).

pkgver

La version complète du paquet. Il faut noter que ceci ne doit pas être confondu avec alpm-pkgver, qui ne représente qu'un sous-ensemble de ce mot-clé ! La valeur est un alpm-package-version, sous forme complète ou avec epoch (par exemple, 1.0.0-1 ou 1:1.0.0-1).

pkgdesc

La description du paquet. La valeur est une chaîne UTF-8, de longueur zéro ou plus (par exemple, Un projet utilisé pour quelque chose). Les descriptions de paquets ne doivent pas avoir d'espaces en début ou fin de ligne, ne peuvent pas contenir d'espaces blancs sauf des espaces simples, et ne peuvent pas avoir d'espaces consécutifs. Il est suggéré qu'elles soient courtes et ne contiennent pas le nom du paquet (voir pkgname).

url

L'URL du projet du paquet. La valeur est une URL valide ou une chaîne vide (par exemple, https://example.org).

builddate

La date à laquelle la construction du paquet a commencé. La valeur doit être numérique et représenter les secondes depuis l'Epoch, c'est-à-dire le « temps Unix » (par exemple, 1729181726).

packager

L'identifiant utilisateur qui a construit le paquet. La valeur est un identifiant utilisateur utilisé pour les recherches d'identité et représente un OpenPGP User ID[2]. Ainsi, la valeur est une chaîne UTF-8, qui est conventionnellement composée d'un nom et d'une adresse e-mail, en accord avec le format décrit dans la RFC 28223.

size

La taille (non compressée et dépaquetée) du contenu du paquet en octets. La valeur est un entier non négatif représentant la taille absolue du contenu du paquet, avec plusieurs fichiers en lien physique comptés une seule fois (par exemple, 181849963).

arch

L'architecture du paquet (voir alpm-architecture pour plus d'informations). La valeur doit être contenue dans l'ensemble des caractères alphanumériques et _ (par exemple, x86_64 ou any).

license

Une licence qui s'applique au paquet. Ce mot-clé peut être assigné zéro ou plusieurs fois. La valeur représente une identification de licence, qui est une chaîne de longueur non nulle (par exemple, GPL). Bien qu'aucune restriction spécifique ne soit appliquée sur la valeur, il est recommandé d'utiliser des expressions de licence SPDX (par exemple, GPL-3.0-or-later ou Apache-2.0 OR MIT). Pour plus d'informations, voir la SPDX License List[4].

replaces

Un autre composant virtuel ou paquet que le paquet remplace lors de l'installation. Ce mot-clé peut être assigné zéro ou plusieurs fois. La valeur est une alpm-package-relation de type replacement (par exemple, example ou example=1.0.0).

group

Une chaîne arbitraire dénotant un groupe distribué auquel le paquet appartient. Les groupes sont utilisés, par exemple, par les gestionnaires de paquets pour regrouper des paquets et permettre l'installation de plusieurs d'entre eux, ou par d'autres logiciels pour afficher des informations sur ces paquets liés. Ce mot-clé peut être assigné zéro ou plusieurs fois. La valeur est une chaîne UTF-8. Bien qu'il soit possible d'utiliser une chaîne UTF-8, il est recommandé d'utiliser le format pkgname pour la valeur, car les gestionnaires de paquets peuvent utiliser group pour installer un groupe complet de paquets.

conflict

Un autre composant virtuel ou paquet avec lequel le paquet est en conflit. Ce mot-clé peut être assigné zéro ou plusieurs fois. La valeur est une alpm-package-relation de type conflict (par exemple, example ou example=1.0.0).

provides

Un autre composant virtuel ou paquet que le paquet fournit. Ce mot-clé peut être assigné zéro ou plusieurs fois. La valeur est une alpm-package-relation de type provision (par exemple, example ou example=1.0.0).

backup

Un chemin de fichier relatif d'un fichier dans le paquet qui dénote un fichier pour lequel le gestionnaire de paquets doit conserver une sauvegarde en cas de modification ou de suppression lors d'une action de mise à jour de paquet (voir les fichiers ‘.pacnew’ et ‘.pacsave’ de pacman). Ce mot-clé peut être assigné zéro ou plusieurs fois. La valeur doit être un chemin de fichier Unix relatif valide (par exemple, etc/package.conf).

depend

Une dépendance d'exécution du paquet (composant virtuel ou paquet). Ce mot-clé peut être assigné zéro ou plusieurs fois. La valeur est une alpm-package-relation de type runtime dependency (par exemple, example ou example=1.0.0).

optdepend

Une dépendance optionnelle du paquet (composant virtuel ou paquet). Ce mot-clé peut être assigné zéro ou plusieurs fois. La valeur est une alpm-package-relation de type optional dependency (par exemple, example ou example: ceci est une description).

NOM

alpm-pkginfo(1)

DESCRIPTION

alpm-pkginfo(1) est un fichier d'informations de paquet Arch Linux, qui contient des données telles que le nom du paquet, la description, les autorisations, les fichiers de configuration, etc.

EXEMPLES

pkgname = example
pkgbase = example
pkgver = 1:1.0.0-1
pkgdesc = Un projet qui fait quelque chose
url = https://example.org
builddate = 1729181726
packager = John Doe <john@example.org>
size = 181849963
arch = any
license = GPL-3.0-or-later
license = LGPL-3.0-or-later
replaces = other-package>0.9.0-3
group = package-group
group = other-package-group
conflict = conflicting-package<1.0.0
conflict = other-conflicting-package<1.0.0
provides = some-component
provides = some-other-component=1:1.0.0-1
backup = etc/example/config.toml
backup = etc/example/other-config.txt
depend = glibc
depend = gcc-libs
optdepend = python: for special-python-script.py
optdepend = ruby: for special-ruby-script.rb
makedepend = cmake
makedepend = python-sphinx
checkdepend = extra-test-tool
checkdepend = other-extra-test-tool
