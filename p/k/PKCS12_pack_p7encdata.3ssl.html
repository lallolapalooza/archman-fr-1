PKCS12_pack_p7encdata(3ssl)

Paquet: openssl

Licences: Apache-2.0

PKCS12_PACK_P7ENCDATA(3ssl) OpenSSL PKCS12_PACK_P7ENCDATA(3ssl)

NOM

PKCS12_pack_p7encdata, PKCS12_pack_p7encdata_ex - Empaqueter un ensemble de safeBags PKCS#12 dans un objet de données chiffrées PKCS#7

SYNTAXE

#include <openssl/pkcs12.h>
PKCS7 *PKCS12_pack_p7encdata(int pbe_nid, const char *pass, int passlen,
                             unsigned char *salt, int saltlen, int iter,
                             STACK_OF(PKCS12_SAFEBAG) *bags);
PKCS7 *PKCS12_pack_p7encdata_ex(int pbe_nid, const char *pass, int passlen,
                                unsigned char *salt, int saltlen, int iter,
                                STACK_OF(PKCS12_SAFEBAG) *bags,
                                OSSL_LIB_CTX *ctx, const char *propq);

DESCRIPTION

PKCS12_pack_p7encdata() génère un objet PKCS#7 ContentInfo de type données chiffrées à partir de l'ensemble de safeBags bags. L'identifiant d'algorithme dans pbe_nid peut être un algorithme de chiffrement basé sur mot de passe PKCS#12 ou PKCS#5, ou un algorithme de chiffrement. Si un algorithme de chiffrement est passé, l'algorithme PKCS#5 PBES2 sera utilisé avec ce chiffrement comme paramètre. Le mot de passe pass de longueur passlen, le sel salt de longueur saltlen et le nombre d'itérations iter sont les entrées de l'opération de chiffrement.

PKCS12_pack_p7encdata_ex() fonctionne de manière similaire à ce qui précède, mais permet d'utiliser un contexte de librairie ctx et une requête de propriété propq pour sélectionner l'implémentation de l'algorithme.

VALEURS DE RETOUR

Un objet PKCS7 en cas de succès, ou NULL si une erreur est survenue.

CONFORMITÉ

IETF RFC 2315 (https://tools.ietf.org/html/rfc2315)

VOIR AUSSI

PKCS12_pbe_crypt_ex(3)

HISTORIQUE

PKCS12_pack_p7encdata_ex() a été ajouté dans OpenSSL 3.0.
