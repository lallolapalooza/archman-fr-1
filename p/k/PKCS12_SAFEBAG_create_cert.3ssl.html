PKCS12_SAFEBAG_create_cert(3ssl)

Paquet: openssl

Licences: Apache-2.0

PKCS12_SAFEBAG_CREATE_CERT(3ssl) OpenSSL PKCS12_SAFEBAG_CREATE_CERT(3ssl)

NOM

PKCS12_SAFEBAG_create_cert, PKCS12_SAFEBAG_create_crl, PKCS12_SAFEBAG_create_secret, PKCS12_SAFEBAG_create0_p8inf, PKCS12_SAFEBAG_create0_pkcs8, PKCS12_SAFEBAG_create_pkcs8_encrypt, PKCS12_SAFEBAG_create_pkcs8_encrypt_ex - Créer des objets PKCS#12 safeBag

SYNOPSIS

#include <openssl/pkcs12.h>
PKCS12_SAFEBAG *PKCS12_SAFEBAG_create_cert(X509 *x509);
PKCS12_SAFEBAG *PKCS12_SAFEBAG_create_crl(X509_CRL *crl);
PKCS12_SAFEBAG *PKCS12_SAFEBAG_create_secret(int type, int vtype,
                                             const unsigned char* value,
                                             int len);
PKCS12_SAFEBAG *PKCS12_SAFEBAG_create0_p8inf(PKCS8_PRIV_KEY_INFO *p8);
PKCS12_SAFEBAG *PKCS12_SAFEBAG_create0_pkcs8(X509_SIG *p8);
PKCS12_SAFEBAG *PKCS12_SAFEBAG_create_pkcs8_encrypt(int pbe_nid,
                                                    const char *pass,
                                                    int passlen,
                                                    unsigned char *salt,
                                                    int saltlen, int iter,
                                                    PKCS8_PRIV_KEY_INFO *p8inf);
PKCS12_SAFEBAG *PKCS12_SAFEBAG_create_pkcs8_encrypt_ex(int pbe_nid,
                                                       const char *pass,
                                                       int passlen,
                                                       unsigned char *salt,
                                                       int saltlen, int iter,
                                                       PKCS8_PRIV_KEY_INFO *p8inf,
                                                       OSSL_LIB_CTX *ctx,
                                                       const char *propq);

DESCRIPTION

PKCS12_SAFEBAG_create_cert() crée un nouveau PKCS12_SAFEBAG de type NID_certBag contenant le certificat fourni.

PKCS12_SAFEBAG_create_crl() crée un nouveau PKCS12_SAFEBAG de type NID_crlBag contenant le crl fourni.

PKCS12_SAFEBAG_create_secret() crée un nouveau PKCS12_SAFEBAG de type correspondant à un secretBag PKCS#12. Le contenu du secretBag est tagué avec type et une valeur ASN1 de type vtype construite à partir des octets dans value de longueur len.

PKCS12_SAFEBAG_create0_p8inf() crée un nouveau PKCS12_SAFEBAG de type NID_keyBag contenant la structure PKCS8 fournie.

PKCS12_SAFEBAG_create0_pkcs8() crée un nouveau PKCS12_SAFEBAG de type NID_pkcs8ShroudedKeyBag contenant la structure PKCS8 fournie.

PKCS12_SAFEBAG_create_pkcs8_encrypt() crée un nouveau PKCS12_SAFEBAG de type NID_pkcs8ShroudedKeyBag en chiffrant la structure PKCS8 p8inf fournie. Si pbe_nid est 0, un algorithme de chiffrement par défaut est utilisé. pass est le mot de passe et iter est le nombre d'itérations. Si iter est zéro, une valeur par défaut de 2048 est utilisée. Si salt est NULL, un sel est généré aléatoirement.

PKCS12_SAFEBAG_create_pkcs8_encrypt_ex() est identique à PKCS12_SAFEBAG_create_pkcs8_encrypt() mais permet l'utilisation d'un contexte de bibliothèque ctx et d'une requête de propriété propq pour sélectionner les implémentations d'algorithmes.

NOTES

PKCS12_SAFEBAG_create_pkcs8_encrypt() fait des hypothèses concernant l'encodage de la phrase secrète donnée. Voir passphrase-encoding(7) pour plus d'informations.

PKCS12_SAFEBAG_create_secret() a été ajouté dans OpenSSL 3.0.

VALEURS DE RETOUR

Toutes ces fonctions retournent une structure PKCS12_SAFEBAG valide ou NULL en cas d'erreur.

CONFORMITÉ

IETF RFC 7292 (https://tools.ietf.org/html/rfc7292)

VOIR AUSSI

HISTORIQUE
