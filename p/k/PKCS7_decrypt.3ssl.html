PKCS7_decrypt(3ssl)

PKCS7_DECRYPT(3ssl) OpenSSL PKCS7_DECRYPT(3ssl)

NOM

PKCS7_decrypt - décrypte le contenu d'une structure envelopedData PKCS#7

SYNOPSIS

#include <openssl/pkcs7.h>
int PKCS7_decrypt(PKCS7 *p7, EVP_PKEY *pkey, X509 *cert, BIO *data, int flags);

DESCRIPTION

PKCS7_decrypt() extrait et déchiffre le contenu d'une structure envelopedData PKCS#7. pkey est la clé privée du destinataire, cert est le certificat du destinataire, data est un BIO vers lequel écrire le contenu et flags est un ensemble optionnel de drapeaux.

NOTES

Bien que le certificat du destinataire ne soit pas nécessaire pour déchiffrer les données, il est nécessaire pour localiser les destinataires appropriés (parmi plusieurs possibles) dans la structure PKCS#7.

Les drapeaux suivants peuvent être passés dans le paramètre flags.

Si le drapeau PKCS7_TEXT est activé, les en-têtes MIME de type text/plain sont supprimés du contenu. Si le contenu n'est pas de type text/plain, une erreur est retournée.

VALEURS DE RETOUR

PKCS7_decrypt() retourne soit 1 en cas de succès, soit 0 en cas d'échec. L'erreur peut être obtenue à partir de ERR_get_error(3)

BOGUES

PKCS7_decrypt() doit se voir passer la clé et le certificat corrects du destinataire. Il serait préférable qu'il puisse rechercher la clé et le certificat corrects dans une base de données.

Le manque de traitement en une seule passe et la nécessité de conserver toutes les données en mémoire, comme mentionné dans PKCS7_sign(), s'appliquent également à PKCS7_verify().

VOIR AUSSI

ERR_get_error(3), PKCS7_encrypt(3)
