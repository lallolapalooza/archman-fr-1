Package::DeprecationManager(3) Documentation Perl fournie par les utilisateurs Package::DeprecationManager(3)

NOM

Package::DeprecationManager - Gère les avertissements de dépréciation pour vos distributions

VERSION

version 0.18

SYNOPSIS

package My::Class;
use Package::DeprecationManager -deprecations => {
    'My::Class::foo' => '0.02',
    'My::Class::bar' => '0.05',
    'feature-X'      => '0.07',
};
sub foo {
    deprecated( 'Do not call foo!' );
    ...
}
sub bar {
    deprecated();
    ...
}
sub baz {
    my %args = @_;
    if ( $args{foo} ) {
        deprecated(
            message => ...,
            feature => 'feature-X',
        );
    }
}
package Other::Class;
use My::Class -api_version => '0.04';
My::Class->new()->foo(); # avertit
My::Class->new()->bar(); # n'avertit pas
My::Class->new()->bar(); # n'avertit pas à nouveau

DESCRIPTION

Ce module vous permet de gérer un ensemble de dépréciations pour un ou plusieurs modules.

Lors de l'importation de Package::DeprecationManager, vous devez fournir un ensemble de -deprecations sous forme de référence de hachage. Les noms des fonctionnalités sont des chaînes de caractères et les valeurs sont la version à laquelle cette fonctionnalité a été dépréciée.

Dans de nombreux cas, vous pouvez utiliser le nom complet d'une sous-routine ou d'une méthode comme nom de la fonctionnalité. Cela fonctionne pour les cas où toute la sous-routine est dépréciée. Cependant, les noms des fonctionnalités peuvent être n'importe quelle chaîne. Ceci est utile si vous ne voulez pas déprécier la sous-routine entière, mais seulement une utilisation spécifique.

Vous pouvez également fournir un paramètre optionnel -ignore.

Les valeurs à ignorer peuvent être des noms de paquets ou des expressions régulières (créées avec qr//). Utilisez ceci pour ignorer des paquets dans votre distribution qui pourraient apparaître dans la pile d'appels lors de l'utilisation d'une fonctionnalité dépréciée.

Dans le cadre du processus d'importation, Package::DeprecationManager exportera deux sous-routines dans son appelant. Il fournit une sous-routine import() pour l'appelant et une sous-routine deprecated().

La sous-routine import() permet aux appelants de votre classe de spécifier un paramètre -api_version. Si celui-ci est fourni, les avertissements de dépréciation ne seront émis que pour les dépréciations dont la version de l'API est antérieure à celle spécifiée.

Vous devez appeler la sous-routine deprecated() dans chaque sous-routine dépréciée. Lorsqu'elle est appelée, elle émet un avertissement à l'aide de Carp::cluck().

La sous-routine deprecated() peut être appelée de plusieurs manières. Si vous ne passez aucun argument, elle génère un message d'avertissement approprié. Si vous passez un seul argument, celui-ci est utilisé comme message d'avertissement.

Enfin, vous pouvez l'appeler avec des arguments nommés. Actuellement, les seuls noms autorisés sont message et feature. L'argument feature doit correspondre au nom de la fonctionnalité passé dans la référence de hachage -deprecations.

Si vous ne spécifiez pas de nom de fonctionnalité, la sous-routine deprecated() utilise caller() pour identifier son appelant, en utilisant son nom de sous-routine complètement qualifié.

Un avertissement de dépréciation n'est émis qu'une seule fois par paquet. Ce module le contrôle par le nom de la fonctionnalité et le message d'erreur lui-même. Cela signifie que si vous fournissez plusieurs messages d'erreur différents pour la même fonctionnalité, toutes ces erreurs apparaîtront.

Autres sous-routines import()

Ce module fonctionne en installant une sous-routine import dans tout paquet qui l'utilise. Si ce paquet possède déjà une sous-routine import, alors elle est appelée après tous les arguments passés à Package::DeprecationManager. Vous devez définir votre sous-routine import avant d'utiliser Package::DeprecationManager pour que cela fonctionne :

package HasExporter;
use Exporter qw( import );
use Package::DeprecationManager -deprecations => {
    'HasExporter::foo' => '0.02',
};
our @EXPORT_OK = qw( some_sub another_sub );
