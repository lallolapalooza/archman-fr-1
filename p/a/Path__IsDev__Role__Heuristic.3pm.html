Path::IsDev::Role::Heuristic(3) Documentation Perl fournie par l'utilisateur Path::IsDev::Role::Heuristic(3)

NOM

Path::IsDev::Role::Heuristic - Rôle de base pour les éléments heuristiques.

VERSION

version 1.001003

LE RÔLE REQUIERT

"correspondances"

Les classes implémentant doivent fournir cette méthode.

retourne : 1 / undef
         1     -> ce chemin est un répertoire de développement pour cette heuristique
         undef -> ce chemin n'est pas un répertoire de développement pour cette heuristique
args : ( $classe , $objet_resultat )
    $classe         -> la méthode sera invoquée sur des paquets, pas des objets
    $objet_resultat -> sera un Path::IsDev::Result

De plus, les classes consommatrices doivent définir "$objet_resultat->result( 1 )" avant de retourner vrai.

Les rôles composant devraient également invoquer "$objet_resultat->add_reason( $self, $valeur_resultat, $raison_descriptive_pour_le_resultat, \%infos_contexte )".

Voir "Path::IsDev::Result" pour les détails

MÉTHODES

"nom"

Retourne le nom à utiliser dans le débogage.

Par défaut, il est dérivé du nom de la classe avec le préfixe "PIDH" retiré :

Path::IsDev::Heuristic::Tool::Dzil->name()
→ "+ ::Tool::Dzil"

"type_heuristique"

Retourne une description du type général d'heuristique

heuristique positive
