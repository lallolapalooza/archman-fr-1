Package::Stash::XS(3) Documentation Perl fournie par l'utilisateur Package::Stash::XS(3)

NOM

Package::Stash::XS - Implémentation plus rapide et plus correcte de l'API Package::Stash

VERSION

version 0.30

SYNOPSIS

use Package::Stash;

DESCRIPTION

Ceci est un backend pour Package::Stash, qui fournit les fonctionnalités d'une manière moins boguée et beaucoup plus rapide. Il sera utilisé par défaut s'il est installé, et devrait être privilégié dans tous les environnements avec un compilateur.

BOGUES

Aucun bogue connu (mais voir la section BUGS dans Package::Stash).

VOIR AUSSI

Package::Stash
