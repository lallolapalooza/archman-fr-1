Path::IsDev::Role::HeuristicSet::Simple(3) Documentation Perl fournie par l'utilisateur Path::IsDev::Role::HeuristicSet::Simple(3)

NOM

Path::IsDev::Role::HeuristicSet::Simple - Ensemble simple d'exclusions/inclusions

VERSION

version 1.001003

ROLE REQUIRES

"heuristics"

Les classes consommatrices doivent fournir cette méthode, et retourner une liste d'heuristiques abrégées.

sub heuristics {
    return qw( MYMETA )
}

"negative_heuristics"

Les classes consommatrices doivent fournir cette méthode, et retourner une liste d'heuristiques négatives abrégées.

sub negative_heuristics {
    return qw( IsDev::IgnoreFile )
}

MÉTHODES

"modules"

Retourne la liste des noms de modules qualifiés qui composent cette heuristique.

Développe les résultats de "->heuristics" et "->negative_heuristics", les négatives précédant les positives.
