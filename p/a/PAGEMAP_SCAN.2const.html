PAGEMAP_SCAN(2const) PAGEMAP_SCAN(2const)

NOM

PAGEMAP_SCAN - obtenir et/ou effacer certains indicateurs spécifiques des entrées de page

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNOPSIS

#include <linux/fs.h>  /* Définition des constantes PAGE* et PM_* */
#include <sys/ioctl.h>
int ioctl(int pagemap_fd, PAGEMAP_SCAN, struct pm_scan_arg *arg);
#include <linux/fs.h>
struct page_region {
    __u64  start;
    __u64  end;
    __u64  categories;
};
struct pm_scan_arg {
    __u64  size;
    __u64  flags;
    __u64  start;
    __u64  end;
    __u64  walk_end;
    __u64  vec;
    __u64  vec_len;
    __u64  max_pages;
    __u64  category_inverted;
    __u64  category_mask;
    __u64  category_anyof_mask;
    __u64  return_mask;
};

DESCRIPTION

Cet ioctl(2) est utilisé pour obtenir et éventuellement effacer certains indicateurs spécifiques des entrées de page. Les informations sont retournées avec une granularité de taille de page PAGE_SIZE.

Pour commencer à suivre l'état d'écriture (indicateur) d'une page ou d'une plage de mémoire, vous devez activer UFFD_FEATURE_WP_ASYNC via ioctl(2) sur userfaultfd et la mémoire de la plage doit être enregistrée avec ioctl(2) sur UFFDIO_REGISTER_MODE_WP.

Indicateurs de page supportés

Les indicateurs d'entrée de page suivants sont supportés :

PAGE_IS_WPALLOWED
La page a une protection en écriture asynchrone activée.
PAGE_IS_WRITTEN
La page a été écrite depuis que la protection en écriture lui a été appliquée.
PAGE_IS_FILE
La page est une page de fichier.
PAGE_IS_PRESENT
La page est présente en mémoire.
PAGE_IS_SWAPPED
La page est mise en swap.
PAGE_IS_PFNZERO
La page a un PFN zéro.
PAGE_IS_HUGE
La page est une THP ou supportée par Hugetlb.

Opérations supportées

L'opération de récupération est toujours effectuée si un tampon de sortie est spécifié. Les autres opérations sont les suivantes :

PM_SCAN_WP_MATCHING
Protéger les pages correspondantes.
PM_SCAN_CHECK_WPASYNC
Arrêter l'analyse lorsqu'une page sans protection en écriture asynchrone activée est trouvée.

L'argument struct pm_scan_arg

size
Ce champ doit être défini à la longueur en octets de la structure, comme dans sizeof(struct pm_scan_arg).
flags
Les opérations à effectuer sont spécifiées dans ce champ.
start
L'adresse de début de l'analyse est spécifiée dans ce champ.
end
L'adresse de fin de l'analyse est spécifiée dans ce champ.
walk_end
Le noyau retourne l'adresse de fin de l'analyse dans ce champ. Si walk_end est égal à end, l'analyse est terminée sur toute la plage.
vec
L'adresse du tableau de sortie page_region.
vec_len
La longueur du tableau de structures page_region.
max_pages
La limite optionnelle du nombre de pages de sortie.
category_inverted
Les catégories PAGE_IS_* dont la valeur correspond à 0 au lieu de 1.
category_mask
Ignorer les pages où aucune catégorie PAGE_IS_* ne correspond.
category_anyof_mask
Ignorer les pages où aucune catégorie PAGE_IS_* ne correspond.
return_mask
Les catégories PAGE_IS_* qui sont rapportées dans page_region.

VALEUR DE RETOUR

En cas d'erreur, -1 est retourné et errno est défini pour indiquer l'erreur.

ERREURS

Les codes d'erreur peuvent être l'un des suivants, mais ne s'y limitent pas :

EINVAL
Arguments invalides, tels que la taille size de l'argument, les flags, les categories, l'adresse start non alignée sur PAGE_SIZE, ou vec_len spécifié alors que vec est NULL.
EFAULT
Pointeur arg invalide, vec invalide, ou plage d'adresses invalide spécifiée par start et end.
ENOMEM
Pas assez de mémoire disponible.
EINTR
Un signal fatal est en attente.

NORMES

Linux.

HISTORIQUE

Linux 6.7.
