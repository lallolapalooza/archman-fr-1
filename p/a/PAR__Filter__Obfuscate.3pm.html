NOM

PAR::Filter::Obfuscate - Filtre d'obfuscation

SYNOPIS

PAR::Filter::Obfuscate->apply(\$code); # transforme $code

DESCRIPTION

Ce filtre utilise B::Deobfuscate (disponible séparément sur CPAN) pour transformer le script en code Perl indépendant de l'architecture et sans commentaires, avec des noms de variables brouillés.

AVERTISSEMENTS

Un message inoffensif sera affiché pendant "pp" :

/tmp/8ycSoLaSI1 syntax OK

Veuillez simplement l'ignorer. :-)

VOIR AUSSI

PAR::Filter, B::Deobfuscate, PAR::Filter::Crypto
