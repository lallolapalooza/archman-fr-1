NOM

Params::Classify - classification des types d'arguments

SYNTAXE

use Params::Classify qw(
    scalar_class
    is_undef check_undef
    is_string check_string
    is_number check_number
    is_glob check_glob
    is_regexp check_regexp
    is_ref check_ref ref_type
    is_blessed check_blessed blessed_class
    is_strictly_blessed check_strictly_blessed
    is_able check_able);
$c = scalar_class($arg);
if(is_undef($arg)) {
check_undef($arg);
if(is_string($arg)) {
check_string($arg);
if(is_number($arg)) {
check_number($arg);
if(is_glob($arg)) {
check_glob($arg);
if(is_regexp($arg)) {
check_regexp($arg);
if(is_ref($arg)) {
check_ref($arg);
$t = ref_type($arg);
if(is_ref($arg, "HASH")) {
check_ref($arg, "HASH");
if(is_blessed($arg)) {
check_blessed($arg);
if(is_blessed($arg, "IO::Handle")) {
check_blessed($arg, "IO::Handle");
$c = blessed_class($arg);
if(is_strictly_blessed($arg, "IO::Pipe::End")) {
check_strictly_blessed($arg, "IO::Pipe::End");
if(is_able($arg, ["print", "flush"])) {
check_able($arg, ["print", "flush"]);

DESCRIPTION

Ce module fournit plusieurs fonctions de classification de types de données. Celles-ci sont destinées aux fonctions qui, comme la plupart du code Perl, se demandent de quel type de données elles agissent. Par exemple, certaines fonctions souhaitent se comporter différemment selon le type de leurs arguments (comme les fonctions surchargées en C++).

Ce module a deux types de fonctions. Les fonctions du premier type fournissent uniquement la classification de type, pour permettre au code de distinguer les types d'arguments. Les fonctions du second type encapsulent le plus courant des fonctions de classification de type : vérifier qu'un argument est d'un type attendu. Les fonctions viennent par paires, l'une de chaque type, et ainsi les fonctions d'inspection de type ne gèrent que les exigences les plus simples pour les types d'arguments qui sont gérés par les fonctions de classification. Une inspection de type plus complexe peut bien sûr être construite à l'aide des fonctions de classification, ou il peut être plus pratique d'utiliser un module conçu pour le travail le plus complexe, tel que Params::Validate.

Ce module est implémenté en XS, avec une version Perl pure pour les systèmes qui ne peuvent pas gérer XS.

CLASSIFICATION DES TYPES

Ce module divise les valeurs scalaires dans les classes suivantes :

  • undef
  • chaîne (valeur scalaire ordinaire)
  • typeglob (oui, les typeglobs peuvent être stockés dans des variables scalaires)
  • regexp (objets d'expression régulière de première classe dans Perl 5.11 et plus tard)
  • référence vers un objet non béni (classé en outre selon le type physique de l'objet référencé)
  • référence vers un objet béni (classé en outre selon la classe bénie)

Ces classes sont mutuellement exclusives et devraient être exhaustives. Cette classification a été choisie comme la plus utile lorsque l'on souhaite distinguer les types de valeurs scalaires. D'autres classifications sont possibles. (Par exemple, les deux types de références diffèrent par une caractéristique de l'objet référencé ; Perl ne traite pas en interne cette caractéristique comme une caractéristique du référencé.)

FONCTIONS

Chacune de ces fonctions prend un argument scalaire (ARG) à tester, éventuellement avec d'autres arguments spécifiant des détails du test. N'importe quelle valeur scalaire est acceptable pour l'argument à tester. Chaque fonction "is_" retourne une valeur de vérité simple, qui est vraie si ARG est du type en cours de vérification. Chaque fonction "check_" retourne normalement si l'argument est du type en cours de vérification, ou lance une erreur si ce n'est pas le cas.

Classification

scalar_class(ARG)
Détermine à quelle des cinq classes décrites ci-dessus appartient ARG. Retourne "UNDEF", "STRING", "GLOB", "REGEXP", "REF" ou "BLESSED" selon le cas.

La Valeur Undefined

is_undef(ARG)
check_undef(ARG)
Vérifie si ARG est "undef". is_undef(ARG) est exactement équivalent à "!defined(ARG)", et est inclus par souci d'exhaustivité.

Chaînes

is_string(ARG)
check_string(ARG)
Vérifie si ARG est défini et est une valeur scalaire ordinaire (pas une référence, un typeglob ou une regexp). C'est ce à quoi on pense généralement comme une chaîne en Perl. En réalité, toute valeur scalaire (y compris "undef" et les références) peut être convertie en chaîne, mais si vous voulez classifier une valeur scalaire, vous ne devriez pas le faire ainsi.
is_number(ARG)
check_number(ARG)
Vérifie si ARG est défini et est une valeur scalaire ordinaire (c'est-à-dire qu'il satisfait "is_string" ci-dessus) et est un nombre acceptable pour Perl. C'est ce à quoi on pense généralement comme un nombre.

Note : Les valeurs simples (satisfaisant "is_string") peuvent avoir des valeurs numériques et des valeurs de chaîne indépendantes, bien qu'elles soient censées n'en avoir qu'une. Une valeur scalaire est considérée comme un nombre si elle possède déjà une valeur numérique (par exemple, elle a été générée par une constante numérique ou un calcul arithmétique) ou sa valeur chaîne a une syntaxe acceptable pour un nombre (elle peut être convertie). Lorsqu'une valeur scalaire a des valeurs numériques et de chaîne indépendantes (voir "dualvar" dans Scalar::Util), elle peut avoir une valeur numérique acceptable alors que sa valeur chaîne ne l'a pas. Notez que vous devez utiliser une telle valeur uniquement dans un contexte numérique, si vous l'utilisez comme nombre. "scalar_num_part" dans Scalar::Number extrait la partie numérique d'une valeur scalaire sous forme de nombre normal. ("0+ARG" est suffisant pour cela, sauf si vous avez besoin de conserver les zéros flottants.)

Un nombre peut être un nombre natif ou une valeur à virgule flottante native, et il existe plusieurs sous-types de valeurs à virgule flottante. Pour la classification et la manipulation des nombres dans les valeurs scalaires, voir Scalar::Number. Pour les détails des deux types de données numériques, voir Data::Integer et Data::Float.

Cette fonction diffère de "looks_like_number" (voir "looks_like_number" dans Scalar::Util ; voir aussi "looks_like_number" dans perlapi pour une description plus détaillée) en excluant "undef", les typeglobs et les références. Pourquoi "looks_like_number" retourne vrai pour "undef" ou les typeglobs est une énigme. Les références, lorsqu'elles sont traitées comme des nombres, s'évaluent à l'adresse mémoire qu'elles référencent ; c'est utile pour comparer des références pour l'égalité, mais pas utile autrement pour traiter les références comme des nombres. Les références bénies peuvent avoir des opérateurs numériques surchargés, mais si c'est le cas, elles ne se comporteront pas nécessairement comme des nombres ordinaires. "looks_like_number" est également induit en erreur par les dualvars : il examine la partie chaîne de la valeur scalaire.

Typeglobs

is_glob(ARG)
check_glob(ARG)
Vérifie si ARG est un typeglob.

NOM

Params::Classify - classifier types for arguments

SYNOPSIS

    use Params::Classify qw(
        is_regexp check_regexp
        is_ref check_ref ref_type
        is_blessed check_blessed blessed_class
        is_strictly_blessed check_strictly_blessed
        is_able check_able
    );

    my $arg = qr/foo/;

    if (is_regexp($arg)) {
        print "arg is a regexp\n";
    }

    my $ref = bless {}, "MyClass";

    if (is_blessed($ref, "MyClass")) {
        print "ref is a MyClass object\n";
    }

    if (is_able($ref, "method1")) {
        print "ref can do method1\n";
    }

DESCRIPTION

This module provides functions for classifying arguments to Perl subroutines, allowing them to check that arguments are of the expected type. The functions are provided in two forms: is_xxx functions which return true or false, and check_xxx functions which throw an exception if the check fails. The exception message includes the name of the subroutine that called it, taken from the caller stack.

The classifiers are divided into three groups: regular expressions, references to unblessed objects, and references to blessed objects.

TYPE CLASSIFICATION

Regular Expressions

is_regexp(ARG)
check_regexp(ARG)
Check whether ARG is a regexp object.

References to Unblessed Objects

is_ref(ARG)
check_ref(ARG)
Check whether ARG is a reference to an unblessed object. If it is, then the referenced data type can be determined using "ref_type" (see below), which will return a string such as "HASH" or "SCALAR".
ref_type(ARG)
Returns "undef" if ARG is not a reference to an unblessed object. Otherwise, determines what type of object is referenced. Returns "SCALAR", "ARRAY", "HASH", "CODE", "FORMAT", or "IO" accordingly.

Note that, unlike "ref", this does not distinguish between different types of referenced scalar. A reference to a string and a reference to a reference will both return "SCALAR". Consequently, what "ref_type" returns for a particular reference will not change due to changes in the value of the referent, except for the referent being blessed.

is_ref(ARG, TYPE)
check_ref(ARG, TYPE)
Check whether ARG is a reference to an unblessed object of type TYPE, as determined by "ref_type". TYPE must be a string. Possible TYPEs are "SCALAR", "ARRAY", "HASH", "CODE", "FORMAT", and "IO".

References to Blessed Objects

is_blessed(ARG)
check_blessed(ARG)
Check whether ARG is a reference to a blessed object. If it is, then the class into which the object was blessed can be determined using "blessed_class".
is_blessed(ARG, CLASS)
check_blessed(ARG, CLASS)
Check whether ARG is a reference to a blessed object that claims to be an instance of CLASS (via its "isa" method; see "isa" in perlobj). CLASS must be a string, naming a Perl class.
blessed_class(ARG)
Returns "undef" if ARG is not a reference to a blessed object. Otherwise, returns the class into which the object is blessed.

"ref" (see "ref" in perlfunc) gives the same result on references to blessed objects, but different results on other types of value. "blessed_class" is actually identical to "blessed" in Scalar::Util.

is_strictly_blessed(ARG)
check_strictly_blessed(ARG)
Check whether ARG is a reference to a blessed object, identically to "is_blessed". This exists only for symmetry; the useful form of "is_strictly_blessed" appears below.
is_strictly_blessed(ARG, CLASS)
check_strictly_blessed(ARG, CLASS)
Check whether ARG is a reference to an object blessed into CLASS exactly. CLASS must be a string, naming a Perl class. Because this excludes subclasses, this is rarely what one wants, but there are some specialised occasions where it is useful.
is_able(ARG)
check_able(ARG)
Check whether ARG is a reference to a blessed object, identically to "is_blessed". This exists only for symmetry; the useful form of "is_able" appears below.
is_able(ARG, METHODS)
check_able(ARG, METHODS)
Check whether ARG is a reference to a blessed object that claims to implement the methods specified by METHODS (via its "can" method; see "can" in perlobj). METHODS must be either a single method name or a reference to an array of method names. Each method name is a string. This interface check is often more appropriate than a direct ancestry check (such as "is_blessed" performs).

BUGS

Probably ought to handle something like Params::Validate's scalar type specification system, which makes much the same distinctions.
