NOM

PAR::StrippedPARL::Base - Classe de base pour les paquets de données PARL déshabillés

SYNTAXE

# Veuillez utiliser l'une des classes sœurs de cette classe à la place.
use base 'PAR::StrippedPARL::Base';

DESCRIPTION

Cette classe est interne à PAR. Ne l'utilisez pas en dehors de PAR.

Cette classe est essentiellement un conteneur pour un chargeur binaire statique PAR qui n'inclut pas le code PAR comme le parl ou le parl.exe auquel vous êtes habitué. Si vous êtes vraiment curieux, je vous dirai que ce n'est qu'une copie du fichier myldr/static (ou myldr/static.exe).

Les données sont ajoutées pendant la phase "make" du processus de construction de PAR.

Si les données binaires ne sont pas ajoutées pendant le processus de construction, les deux méthodes de classe retourneront la liste vide.

MÉTHODES DE CLASSE

write_parl

Prend un nom de fichier comme argument. Écrit les données binaires brutes du paquet dans le fichier spécifié et intègre les modules de base pour produire un chargeur PAR complet (parl).

Retourne vrai en cas de succès ou la liste vide en cas d'échec.

get_raw

Retourne les données binaires attachées au paquet de données.

Retourne la liste vide en cas d'échec.

write_raw

Prend un nom de fichier comme argument et écrit les données binaires dans le fichier.

Retourne vrai en cas de succès et la liste vide en cas d'échec.

SOUS-CLASSEMENT

Les sous-classes doivent implémenter la méthode de classe "_data_pos" qui retourne la valeur de "tell DATA" telle qu'elle était après le chargement de la classe.
