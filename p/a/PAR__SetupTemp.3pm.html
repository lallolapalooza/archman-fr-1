PAR::SetupTemp(3) Documentation Perl fournie par la communauté PAR::SetupTemp(3)

NOM

PAR::SetupTemp - Configuration de $ENV{PAR_TEMP}

SYNTAXE

Les rouages de PAR, attention. Vérifier PAR

DESCRIPTION

Rotines pour configurer la variable d'environnement "PAR_TEMP". La documentation sur la manière dont les répertoires temporaires sont gérés est actuellement dispersée dans le manuel "PAR" et le manuel "PAR::Environment".

La sous-routine set_par_temp_env() configure la variable d'environnement "PAR_TEMP".

VOIR AUSSI

PAR, PAR::Environment
