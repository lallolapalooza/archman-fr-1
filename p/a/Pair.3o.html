Opérations sur les paires.

Depuis 5.4

Paires

type ('a, 'b) t = 'a * 'b

Le type pour les paires.

val make : 'a -> 'b -> 'a * 'b

make a b est la paire (a, b) .

val fst : 'a * 'b -> 'a

fst (a, b) est a .

val snd : 'a * 'b -> 'b

snd (a, b) est b .

val swap : 'a * 'b -> 'b * 'a

swap (a, b) est (b, a) .

It~érateurs

val fold : ('a -> 'b -> 'c) -> 'a * 'b -> 'c

fold f (a, b) applique f à a et b .

val map : ('a -> 'c) -> ('b -> 'd) -> 'a * 'b -> 'c * 'd

map f g (a, b) applique f à a et g à b .

val iter : ('a -> unit) -> ('b -> unit) -> 'a * 'b -> unit

iter f g (a, b) applique d'abord f à a , puis g à b .

val map_fst : ('a -> 'c) -> 'a * 'b -> 'c * 'b

map_fst f p applique f à la première composante de p .

val map_snd : ('b -> 'c) -> 'a * 'b -> 'a * 'c

map_snd f p applique f à la seconde composante de p .

P~rédicats et comparaisons

val equal : ('a -> 'a -> bool) -> ('b -> 'b -> bool) -> 'a * 'b -> 'a * 'b -> bool

equal eqa eqb (a1, b1) (a2, b2) est true si et seulement si eqa a1 a2 et eqb b1 b2 sont tous deux true .

val compare : ('a -> 'a -> int) -> ('b -> 'b -> int) -> 'a * 'b -> 'a * 'b -> int

compare cmpa cmpb est un ordre total sur les paires utilisant cmpa pour comparer la première composante, et cmpb pour comparer la seconde composante. Il est implémenté par un ordre lexicographique.
