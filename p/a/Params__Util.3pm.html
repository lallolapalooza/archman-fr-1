NAME

Params::Util — Fonctions simples, concises et correctes de vérification de paramètres

SYNOPSIS

# Importer quelques fonctions
use Params::Util qw{_SCALAR _HASH _INSTANCE};

# Si vous êtes paresseux ou avez besoin de beaucoup, ...
use Params::Util ':ALL';

sub foo {
    my $object  = _INSTANCE(shift, 'Foo') or return undef;
    my $image   = _SCALAR(shift)          or return undef;
    my $options = _HASH(shift)            or return undef;
    # etc...
}

DESCRIPTION

Params::Util fournit une petite collection de fonctions exportables qui font de la vérification de paramètres une tâche moins pénible.

Bien qu'elles puissent être utilisées dans d'autres contextes, le point clé de cette librairie est que les fonctions font à la fois ce qui est attendu, et ce qui est correct, elles sont donc plus utiles lorsque vous recevez des paramètres de tiers, qu'ils proviennent de n'importe où ou de n'importe qui, et que leur qualité ne peut pas être garantie.

Par conséquent, Params::Util est le plus utile aux frontières de votre API, là où les paramètres et les données proviennent de l'extérieur de votre code.

Les fonctions fournies par Params::Util vérifient de la manière la plus strictement correcte possible, sont documentées aussi complètement que possible afin que leur comportement exact soit clair, et ont été testées de manière aussi intensive que possible afin que vous soyez assuré qu'elles ne seront pas affectées par des données inattendues ou des choses très mauvaises.

Pour les utiliser, chargez simplement la librairie avec les fonctions que vous souhaitez utiliser comme arguments (comme indiqué dans l'exemple).

Pour faciliter la maintenance, Params::Util n'exporte jamais par défaut.

Vous devez nommer explicitement les fonctions que vous souhaitez exporter, ou utiliser le paramètre :ALL pour exporter tout (bien que ce ne soit pas recommandé si vous avez vos propres _FOO qui pourraient entrer en conflit avec de futures mises à jour de Params::Util).

FONCTIONS

_STRING $string

La fonction "_STRING" est conçue pour être importée dans votre paquet et fournit un moyen pratique de vérifier si une valeur est une chaîne de caractères normale de longueur non nulle.

Note : Cette fonction ne fera rien de magique pour le cas spécial '0' comme faux, mais elle renverra la valeur.

# '0' n'est pas considéré comme une donnée valide
my $name = _STRING(shift) or die "Mauvais nom";

# '0' est considéré comme une donnée valide
my $string = _STRING($_[0]) ? shift : die "Mauvaise chaîne";

Il est également important de noter que cette fonction attend une chaîne de caractères normale. Elle ne prend pas en charge les surcharges ou les techniques magiques pour obtenir une chaîne de caractères.

Renvoie la chaîne de caractères par commodité si elle est valide, ou "undef" si elle ne l'est pas.

_IDENTIFIER $string

La fonction "_IDENTIFIER" est conçue pour être importée dans votre paquet et fournit un moyen pratique de vérifier si une valeur est une chaîne de caractères valide en tant qu'identifiant Perl.

Renvoie la chaîne de caractères par commodité si c'est un identifiant valide, ou "undef" si ce n'est pas le cas.

_CLASS $string

La fonction "_CLASS" est conçue pour être importée dans votre paquet et fournit un moyen pratique de vérifier si une valeur est une chaîne de caractères valide en tant que classe Perl.

Cette fonction vérifie uniquement que le format est valide, pas que la classe est réellement chargée. De plus, elle suppose une forme normalisée et n'accepte pas les noms de classe tels que "::Foo" ou "D'Oh").

Renvoie la chaîne de caractères par commodité si c'est un nom de classe valide, ou "undef" si ce n'est pas le cas.

_CLASSISA $string, $class

La fonction "_CLASSISA" est conçue pour être importée dans votre paquet et fournit un moyen pratique de vérifier si une valeur est une chaîne de caractères qui est une classe particulière, ou une sous-classe de celle-ci.

Cette fonction vérifie que le format est valide et appelle la méthode ->isa du nom de la classe. Elle ne vérifie pas que la classe est réellement chargée.

Elle suppose également une forme normalisée et n'accepte pas les noms de classe tels que "::Foo" ou "D'Oh").

Renvoie la chaîne de caractères par commodité si c'est un nom de classe valide, ou "undef" si ce n'est pas le cas.

_CLASSDOES $string, $role

Cette routine fonctionne exactement comme _CLASSISA, mais vérifie avec ->DOES au lieu de ->isa. C'est probablement une bonne idée de l'utiliser uniquement avec Perl 5.10 ou plus récent, lorsque UNIVERSAL::DOES a été implémenté.

_SUBCLASS $string, $class

La fonction "_SUBCLASS" est conçue pour être importée dans votre paquet et fournit un moyen pratique de vérifier si une valeur est une chaîne de caractères qui est une sous-classe d'une classe spécifiée.

Cette fonction vérifie que le format est valide et appelle la méthode ->isa du nom de la classe. Elle ne vérifie pas que la classe est réellement chargée.

Elle suppose également une forme normalisée et n'accepte pas les noms de classe tels que "::Foo" ou "D'Oh").

Renvoie la chaîne de caractères par commodité si c'est un nom de classe valide, ou "undef" si ce n'est pas le cas.

_NUMBER $scalar

La fonction "_NUMBER" est conçue pour être importée dans votre paquet et fournit un moyen pratique de vérifier si une valeur est un nombre. C'est-à-dire, elle est définie et Perl la considère comme un nombre.

Cette fonction est essentiellement un wrapper de Params::Util autour de la fonction Scalar::Util ->looks_like_number.

Renvoie la valeur par commodité si c'est un nombre, ou "undef" si ce n'est pas le cas.

_POSINT $integer

La fonction "_POSINT" est conçue pour être importée dans votre paquet et fournit un moyen pratique de vérifier si une valeur est un entier positif (de n'importe quelle longueur).

Renvoie la valeur par commodité si c'est un entier positif, ou "undef" si ce n'est pas le cas.

Le nom lui-même est dérivé de la contrainte XML du même nom.

_NONNEGINT $integer

La fonction "_NONNEGINT" est conçue pour être importée dans votre paquet et fournit un moyen pratique de vérifier si une valeur est un nombre non négatif (de n'importe quelle longueur). C'est-à-dire, un entier positif ou zéro.

Renvoie la valeur par commodité si c'est un nombre non négatif, ou "undef" si ce n'est pas le cas.

Comme pour d'autres tests qui peuvent renvoyer des valeurs fausses, il est important de faire attention en testant avec "defined" dans des contextes valides.

unless ( defined _NONNEGINT($value) ) {
   die "Valeur invalide";
}

Le nom lui-même est dérivé de la contrainte XML du même nom.

_ARRAY $value

La fonction "_ARRAY" est destinée à être importée dans votre package et fournit un moyen pratique de tester une référence "ARRAY" brute et non désignée contenant **au moins** un élément de quelque type que ce soit.

Pour une forme plus basique qui autorise les références ARRAY de longueur nulle, voir la fonction "_ARRAY0".

Renvoie la référence "ARRAY" elle-même par commodité, ou "undef" si la valeur fournie n'est pas une référence "ARRAY".

_ARRAY0 $value

La fonction "_ARRAY0" est destinée à être importée dans votre package et fournit un moyen pratique de tester une référence "ARRAY" brute et non désignée, autorisant les références "ARRAY" qui ne contiennent aucun élément.

Pour une forme plus basique "Un tableau de quelque chose" qui nécessite également au moins un élément, voir la fonction "_ARRAY".

Renvoie la référence "ARRAY" elle-même par commodité, ou "undef" si la valeur fournie n'est pas une référence "ARRAY".

_ARRAYLIKE $value

La fonction "_ARRAYLIKE" teste si une valeur scalaire donnée peut répondre à un déréférencement de tableau. Si c'est le cas, la valeur est renvoyée. Sinon, "_ARRAYLIKE" renvoie "undef".

_HASH $value

La fonction "_HASH" est destinée à être importée dans votre package et fournit un moyen pratique de tester une référence "HASH" brute et non désignée avec au moins une entrée.

Pour une version de cette fonction qui autorise que le "HASH" soit vide, voir la fonction "_HASH0".

Renvoie la référence "HASH" elle-même par commodité, ou "undef" si la valeur fournie n'est pas une référence "HASH".

_HASH0 $value

La fonction "_HASH0" est destinée à être importée dans votre package et fournit un moyen pratique de tester une référence "HASH" brute et non désignée, indépendamment du contenu du "HASH".

Pour une version plus simple "Un hash de quelque chose" qui nécessite au moins un élément, voir la fonction "_HASH".

Renvoie la référence "HASH" elle-même par commodité, ou "undef" si la valeur fournie n'est pas une référence "HASH".

_HASHLIKE $value

La fonction "_HASHLIKE" teste si une valeur scalaire donnée peut répondre à un déréférencement de hash. Si c'est le cas, la valeur est renvoyée. Sinon, "_HASHLIKE" renvoie "undef".

_CODE $value

La fonction "_CODE" est destinée à être importée dans votre package et fournit un moyen pratique de tester une référence "CODE" brute et non désignée.

Renvoie la référence "CODE" elle-même par commodité, ou "undef" si la valeur fournie n'est pas une référence "CODE".

_CODELIKE $value

La fonction "_CODELIKE" est la version plus générique de "_CODE". Contrairement à "_CODE", qui vérifie une référence "CODE" explicite, la fonction "_CODELIKE" inclut également les éléments qui se comportent comme tels, tels que les objets désignés qui surchargent '&{}'.

Veuillez noter que dans le cas d'objets surchargés avec '&{}', vous finirez presque toujours par les tester également dans un contexte 'bool' à un certain stade.

Par exemple :

sub foo {
    my $code1 = _CODELIKE(shift) or die "No code param provided";
    my $code2 = _CODELIKE(shift);
    if ( $code2 ) {
         print "Got optional second code param";
    }
}

En tant que tel, vous voudrez très probablement toujours vous assurer que votre classe a au moins ce qui suit pour lui permettre d'être évaluée à vrai dans un contexte booléen.

# Toujours évaluer à vrai dans un contexte booléen
use overload 'bool' => sub () { 1 };

Renvoie la valeur appelable par commodité, ou "undef" si la valeur fournie n'est pas appelable.

Note - Cette fonction était auparavant connue sous le nom de _CALLABLE mais a été renommée pour une plus grande symétrie avec les autres fonctions _XXXXLIKE.

L'utilisation de _CALLABLE a été dépréciée. Elle continuera de fonctionner, mais avec un avertissement, jusqu'à fin-2006, puis sera supprimée.

Je m'excuse pour tout inconvénient occasionné.

_INVOCANT $value

Cette routine teste si la valeur donnée est un invocant de méthode valide. Il peut s'agir d'une instance d'un objet ou d'un nom de classe.

Si c'est le cas, la valeur elle-même est renvoyée. Sinon, "_INVOCANT" renvoie "undef".

_INSTANCE $object, $class

La fonction "_INSTANCE" est destinée à être importée dans votre package et fournit un moyen pratique de tester un objet d'une classe particulière de manière strictement correcte.

Renvoie l'objet lui-même par commodité, ou "undef" si la valeur fournie n'est pas un objet de ce type.

_INSTANCEDOES $object, $role

Cette routine se comporte exactement comme "_INSTANCE", mais vérifie avec "->DOES" plutôt qu'avec "->isa". C'est probablement une bonne idée de l'utiliser uniquement sur Perl 5.10 ou plus récent, lorsque UNIVERSAL::DOES a été implémenté.

_REGEX $value

La fonction "_REGEX" est destinée à être importée dans votre package et fournit un moyen pratique de tester une expression régulière.

Renvoie la valeur elle-même par commodité, ou "undef" si la valeur fournie n'est pas une expression régulière.

_SET \@array, $class

La fonction "_SET" est destinée à être importée dans votre package et fournit un moyen pratique de tester un ensemble d'au moins un objet d'une classe particulière de manière strictement correcte.

L'ensemble est fourni sous forme de référence à un "ARRAY" d'objets de la classe fournie.

Pour une fonction alternative qui autorise les ensembles de longueur nulle, voir la fonction "_SET0".

Renvoie la référence "ARRAY" elle-même par commodité, ou "undef" si la valeur fournie n'est pas un ensemble de cette classe.

_SET0 \@array, $class

La fonction "_SET0" est destinée à être importée dans votre package et fournit un moyen pratique de tester un ensemble d'objets d'une classe particulière de manière strictement correcte, autorisant zéro objet.

L'ensemble est fourni sous forme de référence à un "ARRAY" d'objets de la classe fournie.

Pour une fonction alternative qui nécessite au moins un objet, voir la fonction "_SET".

Renvoie la référence "ARRAY" elle-même par commodité, ou "undef" si la valeur fournie n'est pas un ensemble de cette classe.
