NOM

PAR::Filter::Bytecode - Filtre de bytecode

SYNOPSIS

PAR::Filter::Bytecode->apply(\$code); # transforme $code

DESCRIPTION

Ce filtre est obsolète. Le code de B::Bytecode a été retiré de la dernière série de développement de Perl et ne sera plus inclus dans Perl 5.10. Veuillez consulter le module PAR::Filter::Crypto de Steve Hay si vous souhaitez masquer vos sources.

Ce filtre utilise B::Bytecode pour transformer le script en bytecode Perl sans commentaires, spécifique à l'architecture, et utilise ByteLoader pour le recharger lors de l'exécution.

Pour les utilisateurs de pp, veuillez ajouter une option -M supplémentaire, comme ceci :

pp -f Bytecode -M ByteLoader

Sinon, la dépendance implicite à ByteLoader ne sera pas détectée.

ATTENTION

Ce backend présente tous les bugs listés dans B::Bytecode, et plus encore.

Le support du bytecode est considéré comme extrêmement fragile sur les versions de Perl antérieures à 5.8.1, et est toujours loin d'être robuste (à ce jour).

Le bytecode n'est pas pris en charge par perl 5.9 et les versions ultérieures.

VOIR AUSSI

PAR::Filter, B::Bytecode, ByteLoader

Filter::Crypto, PAR::Filter::Crypto
