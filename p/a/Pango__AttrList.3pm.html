NOM

Pango::AttrList - wrapper pour PangoAttrList

DESCRIPTION

Pango::AttrList est une collection de Pango::Attributes. Ces attributs annotent le texte avec des styles.

($attr_list, $text, $accel_char) = Pango->parse_markup ($markup_text, $accel_marker)

  • $markup_text (chaîne de caractères)
  • $accel_marker (caractère)

Analyse le texte marqué pour créer une chaîne de caractères bruts et une liste d'attributs.

Si $accel_marker est fourni et non nul, le caractère donné marquera le caractère qui le suit comme un accélérateur. Par exemple, le marqueur d'accélérateur peut être une esperluette ou un trait de soulignement. Tous les caractères marqués comme accélérateurs recevront un attribut PANGO_UNDERLINE_LOW, et le premier caractère ainsi marqué sera retourné dans $accel_char. Deux caractères $accel_marker qui se suivent sont réduits à un seul caractère littéral $accel_marker.

Peut échouer avec une Glib::Error dans $@ en cas d'échec.
