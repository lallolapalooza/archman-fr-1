NOM

Path::IsDev::Role::Matcher::Child::Exists::Any::File - Correspond si un chemin contient un fichier quelconque parmi une liste de fichiers

VERSION

version 1.001003

MÉTHODES

"child_exists_file"

$class->child_exists_file( $result_object, $childname );

Retourne une correspondance si $childname existe en tant que fichier enfant de "$result_object->path"

"child_exists_any_file"

$class->child_exists_any_file( $result_object, @childnames );

Retourne une correspondance si n'importe lequel des éléments de @childnames existe sous "$result_object->path" et est un fichier.
