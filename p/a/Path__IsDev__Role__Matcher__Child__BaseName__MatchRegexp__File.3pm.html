NOM

Path::IsDev::Role::Matcher::Child::BaseName::MatchRegexp::File - Correspond si des enfants ont des noms de base qui correspondent à une regexp et sont des fichiers

VERSION

version 1.001003

MÉTHODES

"child_basename_matchregexp_file"

$class->child_basename_matchregexp_file( $result_object, $regexp );

Étant donné une regexp $regexp, correspond si un des enfants de "$result_object->path->children" correspond à la regexp donnée, à condition que ceux qui correspondent soient aussi des fichiers.

if ( $self->child_basename_matchregexp_file( $result_object, qr/^Change(.*)$/i ) ) {
    # result_object->path() contient au moins un enfant qui est un fichier et correspond à la regexp
}
