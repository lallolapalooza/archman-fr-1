Paquet: perl-path-isdev

Licences: PerlArtistic

Path::IsDev::Heuristic::Changelog(3) Documentation Perl fournie par l'utilisateur Path::IsDev::Heuristic::Changelog(3)

NOM

Path::IsDev::Heuristic::Changelog - Déterminer si un chemin contient un Changelog (ou similaire)

VERSION

version 1.001003

DESCRIPTION

Cette heuristique correspond à toute variation de casse de "Changes" ou "Changelog", y compris les fichiers portant ce nom avec une extension.

par exemple :

Changes
CHANGES
Changes.mkdn

etc.

MÉTHODES

"basename_regexp"

Les indicateurs pour cette heuristique sont l'existence d'un fichier tel que :

Changes             (i)
Changes.anyext      (i)
Changelog           (i)
Changelog.anyext    (i)

"matches"

Retourne une correspondance si un enfant de "path" existe correspondant à la regexp "basename_regexp"
