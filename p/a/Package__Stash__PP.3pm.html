Package::Stash::PP(3) Documentation Perl fournie par l'utilisateur Package::Stash::PP(3)

NOM

Package::Stash::PP - Implémentation pure Perl de l'API Package::Stash

VERSION

version 0.40

SYNOPIS

use Package::Stash;

DESCRIPTION

Ceci est un backend pour Package::Stash implémenté en pure Perl, pour ceux qui n'ont pas de compilateur ou qui souhaiteraient l'utiliser directement dans des scripts.

BOGUES

  • remove_symbol remplace également le glob de type associé

    Cela peut entraîner un comportement inattendu lors de manipulations en temps de compilation - la suppression de sous-programmes permettra toujours de les appeler depuis l'intérieur du paquet en tant que sous-programmes (bien qu'ils ne soient pas disponibles en tant que méthodes). Cela peut être considéré comme une fonctionnalité dans certains cas (c'est ainsi que fonctionne namespace::clean, par exemple), mais ne doit pas être utilisé comme tel - utilisez "remove_glob" directement si vous souhaitez ce comportement.

  • Quelques fuites de mémoire mineures

    L'implémentation pure Perl présente quelques fuites de mémoire mineures (voir les tests TODO dans t/20-leaks.t) que j'ai du mal à identifier - il pourrait s'agir de bugs du cœur de Perl, il est difficile de le dire.
