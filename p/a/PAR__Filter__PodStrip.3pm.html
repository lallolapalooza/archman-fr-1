NOM

PAR::Filter::PodStrip - Filtre de suppression de POD

SYNTAXE

# transforme $code
PAR::Filter::PodStrip->apply(\$code, $filename, $name);

DESCRIPTION

Ce filtre supprime toutes les sections POD, mais préserve le nom de fichier et les numéros de ligne d'origine via la directive "#line".

VOIR AUSSI
