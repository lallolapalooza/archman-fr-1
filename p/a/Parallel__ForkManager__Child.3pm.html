Parallel::ForkManager::Child(3) Documentation Perl fournie par l'utilisateur Parallel::ForkManager::Child(3)

NOM

Parallel::ForkManager::Child - rôle adopté par les processus forkés de Parallel::ForkManager

VERSION

version 2.04

SYNOPSIS

use 5.10.0;
use Parallel::ForkManager;
my $fm = Parallel::ForkManager->new;
say "le parent n'adopte pas le rôle enfant : ", $fm->does('Parallel::ForkManager::Child');
$fm->start_child(sub{ 
     sleep $_;
     say "mais l'enfant l'adopte : ", $fm->does('Parallel::ForkManager::Child');
     say "l'enfant $_ dit salut !"
}) for 1..3;

DESCRIPTION

Lorsque l'objet parent Parallel::ForkManager effectue un fork pour créer un processus enfant, son incarnation forkée adopte ce rôle. Le rôle ne fait pas grand-chose : il modifie les valeurs de retour de "is_child" et "is_parent" de la manière attendue, modifie "start" de sorte qu'il échoue s'il est appelé depuis l'enfant, et modifie l'implémentation de "finish" pour potentiellement renvoyer des données au processus parent.
