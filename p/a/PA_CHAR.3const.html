DESCRIPTION

Ces fonctions sont utilisées pour étendre ou modifier le comportement des familles de fonctions printf(3).

register_printf_specifier()

Cette fonction enregistre un spécificateur de conversion personnalisé pour les familles de fonctions printf(3).

spec
Le caractère qui sera utilisé comme spécificateur de conversion dans la chaîne de format.
func
La fonction de rappel qui sera exécutée par les familles de fonctions printf(3) pour formater les arguments d'entrée dans le flux de sortie stream.
stream
Le flux de sortie où le résultat sera imprimé. Ce flux est représenté de manière transparente, même dans les cas de fonctions écrivant dans une chaîne.
info
La structure contenant les informations de contexte, y compris les modificateurs spécifiés dans la chaîne de format. Elle contient les mêmes éléments que arginfo.
args
Tableau de pointeurs vers les arguments qui seront passés à la fonction de type printf(3).
arginfo
La fonction de rappel qui sera exécutée par les familles de fonctions printf(3) pour savoir combien d'arguments doivent être analysés pour le spécificateur personnalisé et également leur type.
info
La structure contenant les informations de contexte, y compris les modificateurs spécifiés dans la chaîne de format. Elle contient les mêmes éléments que func.
n
Nombre d'arguments restants à analyser.
argtypes
Ce tableau doit être défini pour spécifier le type de chacun des arguments à analyser. Chaque élément du tableau représente un argument à analyser, dans le même ordre qu'ils sont passés à la fonction de type printf(3). Chaque élément doit être défini à un type de base (PA_*) de l'énumération précédente, ou un type personnalisé, et éventuellement ORé avec un modificateur de longueur (PA_FLAG_*).

PA_WCHAR
wchar_t.
PA_STRING
const char *, une chaîne terminée par '\0'.
PA_WSTRING
const wchar_t *, une chaîne terminée par L'\0'.
PA_POINTER
void *.

float.

double.

size
Pour les types personnalisés, leur taille doit également être spécifiée via ce tableau. Sinon, laisser ce champ inutilisé.

Le arginfo est appelé avant func, préparant les informations nécessaires pour appeler func.

VALEUR DE RETOUR

register_printf_specifier(), register_printf_modifier() et register_printf_type() retournent zéro en cas de succès, ou -1 en cas d'erreur.

Callbacks

La fonction de rappel de type printf_function doit retourner le nombre de caractères écrits, ou -1 en cas d'erreur.

La fonction de rappel de type printf_arginfo_size_function doit retourner le nombre d'arguments à analyser par ce spécificateur. Elle transmet également des informations sur le type de ces arguments à l'appelant via argtypes. En cas d'erreur, elle doit retourner -1.

ERREURS

EINVAL
Le spécificateur n'était pas un caractère valide.

NOM

register_printf_specifier - Enregistrer un spécificateur de format printf personnalisé

SYNOPIS

#include <stdio.h>

int register_printf_specifier(int c, printf_render_hook render,
    printf_arginfo_hook arginfo);

DESCRIPTION

La fonction register_printf_specifier enregistre une nouvelle fonction de rendu pour le spécificateur de format donné c. Le spécificateur de format c doit être un caractère ASCII imprimable, non utilisé par les spécificateurs de format standard définis dans la norme C.

La fonction render est le crochet de rendu. Elle est appelée lorsque le spécificateur c est rencontré dans une chaîne de format printf. Elle reçoit le flux de sortie stream, une structure printf_info contenant des informations sur le spécificateur et ses drapeaux, et un tableau de pointeurs vers les arguments.printf_info est défini dans <stdio.h>.

La fonction arginfo est le crochet d'informations sur les arguments. Elle est appelée avant que la fonction de rendu ne soit appelée pour déterminer les types des arguments. Elle reçoit la structure printf_info, le nombre d'arguments n, et deux tableaux argtypes et size. La fonction doit remplir argtypes avec les spécificateurs de type appropriés pour chaque argument et size avec la taille de chaque argument. Elle doit renvoyer le nombre d'arguments attendus.

Si l'enregistrement réussit, register_printf_specifier renvoie 0. En cas d'échec (par exemple, si le spécificateur c est déjà enregistré ou si c est un spécificateur de format non valide), elle renvoie -1 et définit errno en conséquence.

STANDARDS

GNU.

HISTORY

register_printf_function(3) est une ancienne fonction similaire à register_printf_specifier(), et est maintenant obsolète. Cette fonction ne peut pas gérer les types définis par l'utilisateur.

register_printf_specifier() remplace register_printf_function(3).

static int
b_printf(FILE *stream, const struct printf_info *info,
         const void *const args[])
{
    char               bin[UINTMAX_WIDTH];
    size_t             min_len, bin_len;
    ssize_t            len, tmp;
    struct Printf_Pad  pad = {0};
    len = 0;
    min_len = b_bin_repr(bin, info, args[0]);
    bin_len = b_bin_len(info, min_len);
    pad.ch = pad_ch(info);
    if (pad.ch == ' ')
        pad.len = b_pad_len(info, bin_len);
    /* Padding with ' ' (right aligned) */
    if ((pad.ch == ' ') && !info->left) {
        tmp = pad_spaces(stream, pad.len);
        if (tmp == EOF)
            return EOF;
        len += tmp;
    }
    /* "0b"/"0B" prefix */
    if (info->alt) {
        tmp = b_print_prefix(stream, info);
        if (tmp == EOF)
            return EOF;
        len += tmp;
    }
    /* Padding with '0' */
    if (pad.ch == '0') {
        tmp = b_pad_zeros(stream, info, min_len);
        if (tmp == EOF)
            return EOF;
        len += tmp;
    }
    /* Print number (including leading 0s to fill precision) */
    tmp = b_print_number(stream, info, bin, min_len, bin_len);
    if (tmp == EOF)
        return EOF;
    len += tmp;
    /* Padding with ' ' (left aligned) */
    if (info->left) {
        tmp = pad_spaces(stream, pad.len);
        if (tmp == EOF)
            return EOF;
        len += tmp;
    }
    return len;
}
static int
b_arginf_sz(const struct printf_info *info, size_t n, int argtypes[n],
            [[maybe_unused]] int size[n])
{
    if (n < 1)
        return -1;
    if (info->is_long_double)
        argtypes[0] = PA_INT | PA_FLAG_LONG_LONG;
    else if (info->is_long)
        argtypes[0] = PA_INT | PA_FLAG_LONG;
    else
        argtypes[0] = PA_INT;
    return 1;
}
static uintmax_t
b_value(const struct printf_info *info, const void *arg)
{
    if (info->is_long_double)
        return *(const unsigned long long *)arg;
    if (info->is_long)
        return *(const unsigned long *)arg;
    /* short and char are both promoted to int */
    return *(const unsigned int *)arg;
}
static size_t
b_bin_repr(char bin[UINTMAX_WIDTH],
           const struct printf_info *info, const void *arg)
{
    size_t     min_len;
    uintmax_t  val;
    val = b_value(info, arg);
    bin[0] = '0';
    for (min_len = 0; val; min_len++) {
        bin[min_len] = '0' + (val % 2);
        val >>= 1;
    }
    return MAX(min_len, 1);
}
static size_t
b_bin_len(const struct printf_info *info, ptrdiff_t min_len)
{
    return MAX(info->prec, min_len);
}
static size_t
b_pad_len(const struct printf_info *info, ptrdiff_t bin_len)
{
    ptrdiff_t  pad_len;
    pad_len = info->width - bin_len;
    if (info->alt)
        pad_len -= 2;
    if (info->group)
        pad_len -= (bin_len - 1) / 4;
    return MAX(pad_len, 0);
}
static ssize_t
b_print_prefix(FILE *stream, const struct printf_info *info)
{
    ssize_t len;
    len = 0;
    if (fputc('0', stream) == EOF)
        return EOF;
    len++;
    if (fputc(info->spec, stream) == EOF)
        return EOF;
    len++;
    return len;
}
static ssize_t
b_pad_zeros(FILE *stream, const struct printf_info *info,
            ptrdiff_t min_len)
{
    ssize_t    len;
    ptrdiff_t  tmp;
    len = 0;
    tmp = info->width - (info->alt * 2);
    if (info->group)
        tmp -= tmp / 5 - !(tmp % 5);
    for (ptrdiff_t i = tmp - 1; i > min_len - 1; i--) {
        if (fputc('0', stream) == EOF)
            return EOF;
        len++;
        if (!info->group || (i % 4))
            continue;
        if (fputc(GROUP_SEP, stream) == EOF)
            return EOF;
        len++;
    }
    return len;
}
static ssize_t
b_print_number(FILE *stream, const struct printf_info *info,
               const char bin[UINTMAX_WIDTH],
               size_t min_len, size_t bin_len)
{
    ssize_t  len;
    len = 0;
    /* Print leading zeros to fill precision */
    for (size_t i = bin_len - 1; i > min_len - 1; i--) {
        if (fputc('0', stream) == EOF)
            return EOF;
        len++;
        if (!info->group || (i % 4))
            continue;
        if (fputc(GROUP_SEP, stream) == EOF)
            return EOF;
        len++;
    }
    /* Print number */
    for (size_t i = min_len - 1; i < min_len; i--) {
        if (fputc(bin[i], stream) == EOF)
            return EOF;
        len++;
        if (!info->group || (i % 4) || !i)
            continue;
        if (fputc(GROUP_SEP, stream) == EOF)
            return EOF;
        len++;
    }
    return len;
}
static char
pad_ch(const struct printf_info *info)
{
    if ((info->prec != -1) || (info->pad == ' ') || info->left)
        return ' ';
    return '0';
}
static ssize_t
pad_spaces(FILE *stream, size_t pad_len)
{
    ssize_t  len;
    len = 0;
    for (size_t i = pad_len - 1; i < pad_len; i--) {
        if (fputc(' ', stream) == EOF)
            return EOF;
        len++;
    }
    return len;
}

LIBRARY

libpam

SYNOPSIS

#include <security/pam_modules.h>

DESCRIPTION

Le type de données char, tel qu'utilisé dans les modules PAM, est encodé en UTF-8. Les constantes suivantes sont fournies pour représenter les valeurs courantes de caractères :

PA_CHAR_NULL
Représente le caractère nul ('\0').
PA_CHAR_SPACE
Représente le caractère d'espacement (' ').
PA_CHAR_TAB
Représente le caractère de tabulation ('\t').
PA_CHAR_NEWLINE
Représente le caractère de nouvelle ligne ('\n').

Ces constantes sont utiles pour la manipulation de chaînes de caractères et pour le traitement des entrées utilisateur dans les modules PAM.

RETURN VALUE

Non applicable pour les constantes.

ERRORS

Non applicable pour les constantes.

STANDARDS

Ces constantes font partie de l'API de la bibliothèque PAM (Pluggable Authentication Modules) et ne sont pas standardisées par une norme POSIX ou autre.

HISTORY

Introduites avec PAM.

EXAMPLES

#include <security/pam_modules.h>
#include <stdio.h>

int main() {
    char separator = PA_CHAR_SPACE;
    char newline = PA_CHAR_NEWLINE;

    printf("Le séparateur est : %c%c", separator, newline);

    return 0;
}
