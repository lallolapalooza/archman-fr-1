Path::FindDev::Object(3) Documentation Perl fournie par l'utilisateur Path::FindDev::Object(3)

NOM

Path::FindDev::Object - entrailles orientées objet pour FindDev

VERSION

version v0.5.3

SYNOPSIS

require Path::FindDev::Object;
my $finder = Path::FindDev::Object->new();
my $dev = $finder->find_dev($path);

DESCRIPTION

Ce module implémente les entrailles de "Path::FindDev", et son utilisation est uniquement recommandée si l'API de l'exportateur n'est pas suffisante pour vos besoins.

MÉTHODES

"a_un_ensemble"

Détermine si l'attribut "ensemble" existe.

"a_max_niveau_parent"

Détermine si l'attribut "max_niveau_parent" est fourni.

"trouver_dev"

Trouve un parent, au niveau de $AutreChemin ou au-dessus, qui ressemble à un répertoire "dev".

my $path = $object->trouver_dev( $AutreChemin );

ATTRIBUTS

"ensemble"

(optionnel)

La sous-classe "Path::IsDev::HeuristicSet" pour vos heuristiques souhaitées.

"max_niveau_parent"

S'il est fourni, limite le nombre d'itérations "monter_de_niveau" effectuées.

(c'est-à-dire, limite le nombre de fois où il remontera dans la hiérarchie)

"retry_imbrique"

Le nombre de répertoires "dev" à "ignorer" dans la hiérarchie.

Ceci est fourni dans le cas où vous avez un répertoire "dev" à l'intérieur d'un répertoire "dev", et que vous souhaitez résoudre un répertoire extérieur plutôt qu'un intérieur.

Par défaut, c'est 0, ou "arrêter au premier répertoire "dev""

"est_dev"

L'objet "Path::IsDev" qui vérifie les nœuds pour leur caractère "dev".

MÉTHODES PRIVÉES

"_id_instance"

Un numéro de séquence opportuniste pour aider aux messages de débogage.

Note : Ceci n'est pas garanti d'être unique par instance, seulement garanti d'être constant pendant la durée de vie de l'objet.

Basé sur "refaddr", et attribuant de nouveaux identifiants lorsque de nouveaux "refaddr" sont vus.

my $id = $object->_id_instance;

"BUILD"

"BUILD" est un détail d'implémentation de "Moo"/"Moose".

Ce module intercepte "BUILD" pour fournir un auto-rapport de l'objet à *STDERR après "->new" lorsque $DEBUG est activé.

"_debug"

La fonction de rappel de débogage.

export PATH_FINDDEV_DEBUG=1

pour obtenir des informations de débogage.

$object->_debug($message);

"_erreur"

La fonction de rappel de signalement d'erreur.

$object->_erreur($message);

"_pas"

Chemin de code interne de la traversée d'arbre.

my ($niveaux_dev, $niveaux_parent ) = (0,0);
my $resultat = $object->_pas( chemin($un_chemin), \$niveaux_dev, \$niveaux_parent );
$resultat->{type} eq 'stop'   # si le contrôle de flux doit se terminer
$resultat->{type} eq 'next'   # si le contrôle de flux doit monter vers le parent
$resultat->{type} eq 'found'  # si le contrôle de flux a trouvé le répertoire "final" dev
