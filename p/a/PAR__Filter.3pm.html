NOM

PAR::Filter - Filtre d'entrée pour PAR

SYNTAXE

$code = 'use strict; print "Hello, World!\n";';
$ref = PAR::Filter->new('PodStrip', 'Bleach')->apply(\$code);
print $code;    # code dépouillé de POD et obfusqué
print $$ref;    # la même chose
$ref = PAR::Filter->new('PodStrip', 'Bleach')->apply('file.pl');
print $$ref;    # la même chose, appliqué à file.pl

DESCRIPTION

À partir de PAR 0.76, "pp -f" prend un nom de filtre, comme "Bleach", et invoque ce module pour transformer les programmes avec PAR::Filter::Bleach. De même, "pp -F Bleach" applique le filtre Bleach à tous les modules inclus.

Il est possible de passer plusieurs filtres de ce type, qui sont appliqués tour à tour.

La sortie de chaque filtre de ce type est censée être sémantiquement équivalente à l'entrée, bien que potentiellement obfusquée.

La liste par défaut des filtres comprend :

  • PAR::Filter::Bleach

    Le filtre d'obfuscation archétypal.

  • PAR::Filter::Obfuscate

    Utilise B::Deobfuscate pour supprimer les indentations et les commentaires, ainsi que pour modifier les noms de variables.

  • PAR::Filter::PatchContent

    Corrige les modules incompatibles avec PAR, appliqué aux modules par défaut.

  • PAR::Filter::PodStrip

    Supprime les sections POD, appliqué aux modules par défaut.

  • PAR::Filter::Bytecode

    Utilise B::Bytecode pour supprimer les indentations et les commentaires. Ce filtre est déprécié ! Pour masquer la source, jeter un œil à PAR::Filter::Crypto à la place et assurez-vous de lire ses caveats.
