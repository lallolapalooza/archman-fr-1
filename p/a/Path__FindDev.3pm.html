NOM

Path::FindDev - Trouver un chemin de développement quelque part dans une hiérarchie supérieure.

VERSION

version v0.5.3

DESCRIPTION

Ce paquet est principalement une couche de liaison autour de "Path::IsDev" avec quelques astuces de parcours de répertoires.

use Path::FindDev qw( find_dev );
if ( my $root = find_dev('/some/path/to/something/somewhere')) {
    print "development root = $root";
} else {
    print "No development root :(";
}

FONCTIONS

find_dev

my $result = find_dev('/some/path');

Si un répertoire "dev" est trouvé à, ou au-dessus de, "/some/path", il sera retourné en tant que "Path::Tiny".

Si vous passez des configurations à importer :

use Path::FindDev find_dev => { set => $someset };

Alors le "find_dev" exporté passera ce nom d'ensemble à "Path::IsDev".

Bien que vous ne devriez faire cela que si :

  • l'ensemble par défaut est insuffisant pour votre usage
  • vous ne souhaitez pas que l'ensemble soit outrepassé par %ENV

De plus, vous pouvez appeler find_dev directement :

require Path::FindDev;
my $result = Path::FindDev::find_dev('/some/path');

Ce qui, par conception, inhibe votre capacité à spécifier un ensemble alternatif dans le code.

EXEMPLES CAS D'UTILISATION

Vous êtes-vous déjà retrouvé à faire

use FindBin;
use lib "$FindBin::Bin/../../../tlib"

Dans un test ?

Vous êtes-vous retrouvé paranoïaque des sémantiques du système de fichiers et avez essayé :

use FindBin;
use Path::Tiny qw(path)
use lib path($FindBin::Bin)->parent->parent->parent->child('tlib')->stringify;

Avez-vous déjà fait l'une des choses ci-dessus dans un test, pour découvrir que vous avez eu besoin de déplacer le test dans une hiérarchie plus profonde, et ainsi, besoin de réécrire toute votre résolution de chemin ?

Avez-vous déjà eu ce problème pour plusieurs fichiers ?

Plus maintenant !

use FindBin;
use Path::FindDev qw(find_dev);
use lib find_dev($FindBin::Bin)->child('t','tlib')->stringify;

^ Devrait fonctionner, quel que soit le test dans lequel vous le mettez, et quel que soit $CWD au moment où vous l'appelez.
