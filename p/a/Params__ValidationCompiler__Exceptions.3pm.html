Params::ValidationCompiler::Exceptions(3) Documentation Perl fournie par l'utilisateur Params::ValidationCompiler::Exceptions(3)

NOM

Params::ValidationCompiler::Exceptions - Définit les exceptions levées par Params::ValidationCompiler

VERSION

version 0.31

DESCRIPTION

Ce module définit les exceptions suivantes :

Params::ValidationCompiler::Exception::BadArguments

Exception levée lorsque @_ ne contient pas un hachage ou un pointeur vers un hachage.

Params::ValidationCompiler::Exception::Named::Extra

Exception levée lorsque @_ contient des arguments nommés supplémentaires inattendus.

Params::ValidationCompiler::Exception::Named::Required

Exception levée lorsqu'un paramètre nommé requis n'est pas passé.

Params::ValidationCompiler::Exception::Positional::Extra

Exception levée lorsque @_ contient des arguments supplémentaires inattendus.

Params::ValidationCompiler::Exception::Positional::Required

Exception levée lorsqu'un paramètre positionnel requis n'est pas passé.

Params::ValidationCompiler::Exception::ValidationFailedForMooseTypeConstraint

Exception levée lorsqu'une vérification de contrainte de type Moose échoue. Cette classe fournit les méthodes suivantes :

$e->parameter

Ceci retourne une chaîne décrivant le paramètre, quelque chose comme "Le paramètre 'foo'" ou "Paramètre #1".

$e->value

C'est la valeur qui n'a pas satisfait la contrainte de type.

$e->type

C'est l'objet de contrainte de type qui n'a pas accepté la valeur.
