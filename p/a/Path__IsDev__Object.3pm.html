Path::IsDev::Object(3) Documentation Perl fournie par l'utilisateur Path::IsDev::Object(3)

NOM

Path::IsDev::Object - Entrailles orientées objet pour l'exportation d'IsDev

VERSION

version 1.001003

SYNOPSIS

use Path::IsDev::Object;
my $dev = Path::IsDev::Object->new();
my $dev = Path::IsDev::Object->new( set => 'MySet' );
if ( $dev->matches($path) ){
    print "$path est dev";
}

DESCRIPTION

L'exportation de fonctions est pratique pour les utilisateurs finaux, mais devient rapidement un énorme casse-tête lorsqu'on essaie de les chaîner.

Exemple : Si vous écrivez vous-même un exportateur, et que vous souhaitez encapsuler les réponses d'un symbole exporté, tout en transmettant la configuration de l'utilisateur => Énorme casse-tête.

Ainsi, l'interface basée sur l'exportateur est là pour les personnes qui n'ont pas besoin de quelque chose de sophistiqué, tandis que l'interface orientée objet est là pour les personnes ayant des exigences plus complexes.

MÉTHODES

"matches"

Détermine si un chemin donné satisfait le "set"

if( $o->matches($path) ){
    print "Nous avons une correspondance !";
}

ATTRIBUTS

"set"

Le nom du "HeuristicSet::" à utiliser.

Par défaut, c'est "Basic", ou la valeur de $ENV{PATH_ISDEV_DEFAULT_SET}

"set_prefix"

Le préfixe "HeuristicSet" à utiliser pour développer "set" en nom de module.

Par défaut, c'est "Path::IsDev::HeuristicSet"

"set_module"

Le nom de module qualifié complet.

Composé en joignant "set" et "set_prefix"

"loaded_set_module"

Un accesseur qui renvoie un nom de module après l'avoir chargé.

MÉTHODES PRIVÉES

"_instance_id"

Un numéro de séquence opportuniste pour aider aux messages de débogage.

Note : Il n'est pas garanti d'être unique par instance, seulement garanti d'être constant pendant la durée de vie de l'objet.

Basé sur "refaddr", et attribuant de nouveaux identifiants lorsque de nouveaux "refaddr" sont rencontrés.

"_debug"

Le rappel de débogage.

export PATH_ISDEV_DEBUG=1

pour obtenir des informations de débogage.

"_with_debug"

Encapsule les appels à Path::IsDev::debug pour avoir un préfixe avec un identifiant d'objet.

$ob->_with_debug(sub{
    # Path::Tiny::debug est maintenant localisé.
});

"BUILD"

"BUILD" est un détail d'implémentation de "Class::Tiny".

Ce module accroche "BUILD" pour fournir un auto-rapport de l'objet à *STDERR après "->new" lorsque sous $DEBUG

"_matches"

my $result = $o->matches( $path );

$result ici sera un "Path::IsDev::Result" construit.

Note : cette méthode peut être utile pour le débogage, mais vous devriez quand même appeler "matches" pour tout code réel.
