Path::IsDev::NegativeHeuristic::HomeDir(3) Documentation Perl fournie par l'utilisateur Path::IsDev::NegativeHeuristic::HomeDir(3)

NOM

Path::IsDev::NegativeHeuristic::HomeDir - Les répertoires personnels des utilisateurs ne sont pas des racines de développement

VERSION

version 1.001003

MÉTHODES

"chemins"

Exclut toutes les valeurs renvoyées par "File::HomeDir"

uniq grep { defined and length }
  File::HomeDir->my_home,
  File::HomeDir->my_desktop,
  File::HomeDir->my_music,
  File::HomeDir->my_pictures,
  File::HomeDir->my_videos,
  File::HomeDir->my_data;

"exclut"

Exclut tout chemin qui correspond à un "realpath" d'un chemin "File::HomeDir"
