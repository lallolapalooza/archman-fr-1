NOM

Path::IsDev::Role::Matcher::Child::BaseName::MatchRegexp - Correspond lorsque un chemin possède un fichier enfant correspondant à une expression régulière

VERSION

version 1.001003

MÉTHODES

"child_basename_matchregexp"

$class->child_basename_matchregexp( $result_object, $regexp );

Étant donné une expression régulière $regexp, correspond si un des éléments de "$result_object->path->children" correspond à l'expression régulière donnée.

if ( $self->child_basename_matchregexp( $result_object, qr/^Change(.*)$/i ) ) {
    # result_object->path() contient au moins un enfant qui correspond à l'expression régulière
}
