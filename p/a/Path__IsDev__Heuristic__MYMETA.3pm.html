NOM

Path::IsDev::Heuristic::MYMETA - Déterminer si un chemin contient MYMETA.(json|yml)

VERSION

version 1.001003

DESCRIPTION

Cette heuristique est destinée à garantir que UNE sorte de marqueur de haut niveau sera présent dans une distribution, car toutes les chaînes d'outils principales émettent ce fichier pendant "configure".

Certes, cette heuristique ne devrait jamais être nécessaire, car pour créer un tel fichier, il faut d'abord un "Build.PL"/"Makefile.PL" pour le générer.

MÉTHODES

"fichiers"

Fichiers pertinents pour cette heuristique

MYMETA.json
MYMETA.yml

"correspondances"

Correspond si l'un des fichiers de "fichiers" existe en tant qu'enfant du "chemin"
