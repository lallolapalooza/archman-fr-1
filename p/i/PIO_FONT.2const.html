ioctl_kd(2) Pages man des appels système ioctl_kd(2)

NOM

ioctl_kd - appels ioctl pour terminaux de console et fenêtres virtuelles

SYNTAXE

#include <linux/kd.h>  /* Définition des constantes d'opération */
#include <sys/ioctl.h>
int ioctl(int fd, unsigned long op, void *argp);

DESCRIPTION

Les opérations ioctl(2) suivantes, spécifiques à Linux, sont supportées pour les terminaux de console et les fenêtres virtuelles.

KDGETLED
Obtenir l'état des LEDs. argp pointe vers un char. Les trois bits de poids faible de *argp représentent l'état des LEDs, selon le tableau suivant :
LED_CAP 0x04 LED de verr. majusc.
LED_NUM 0x02 LED de verr. num.
LED_SCR 0x01 LED de verr. défil.
KDSETLED
Définir les LEDs. Les LEDs sont définies selon les trois bits de poids faible de argp (un entier non signé). Cependant, si un bit de poids fort est actif, les LEDs se comportent normalement : elles indiquent l'état des fonctions du clavier verr. majusc., verr. num. et verr. défil. .

Avant Linux 1.1.54, les LEDs reflétaient l'état des drapeaux de clavier correspondants, et KDGETLED/KDSETLED changeaient également les drapeaux de clavier. Depuis Linux 1.1.54, les LEDs peuvent afficher des informations arbitraires, mais par défaut elles indiquent les drapeaux du clavier. Les deux appels ioctl suivants sont utilisés pour accéder aux drapeaux du clavier.

KDGKBLED
Obtenir l'état des drapeaux de clavier Verr. Majusc., Verr. Num., Verr. Défil. (pas les LEDs). argp pointe vers un char qui est défini sur l'état des drapeaux. Les trois bits de poids faible (masque 0x7) indiquent l'état actuel des drapeaux, et les bits de poids faible du quatrième suivant (masque 0x70) indiquent l'état par défaut. (Depuis Linux 1.1.54.)
KDSKBLED
Définir les drapeaux de clavier Verr. Majusc., Verr. Num., Verr. Défil. (pas les LEDs). argp est un entier non signé contenant l'état désiré des drapeaux. Les trois bits de poids faible (masque 0x7) indiquent l'état des drapeaux, et les bits de poids faible du quatrième suivant (masque 0x70) indiquent l'état par défaut. (Depuis Linux 1.1.54.)
KDGKBTYPE
Obtenir le type de clavier. Renvoie la valeur KB_101, définie comme 0x02.
KDADDIO
Ajouter un port d'E/S comme valide. Équivalent à ioperm(arg,1,1).
KD_TEXT 0x00 KD_GRAPHICS 0x01

SYNOPSIS

#include <sys/ioctl.h>

long ioctl(int fd, unsigned long request, ...);

DESCRIPTION

Les opérations ioctl sur un descripteur de fichier associé à un périphérique de console Linux (généralement console_ioctl(4)) permettent de contrôler le comportement de la console.

PIO_UNISCRNMAP
Charge la table "définissable par l'utilisateur" (quatrième) dans le noyau, qui mappe les octets en Unicodes, lesquels sont ensuite traduits en symboles d'écran selon la carte Unicode vers police actuellement chargée. Des Unicodes spéciaux commençant à U+F000 peuvent être utilisés pour mapper directement aux symboles de police. (Depuis Linux 1.3.1.)
GIO_UNIMAP
Obtenir la carte Unicode vers police depuis le noyau. argp pointe vers une

struct unimapdesc {
    unsigned short  entry_ct;
    struct unipair *entries;
};

où entries pointe vers un tableau de

struct unipair {
    unsigned short unicode;
    unsigned short fontpos;
};

(Depuis Linux 1.1.92.)
PIO_UNIMAP
Placer la carte Unicode vers police dans le noyau. argp pointe vers une struct unimapdesc. (Depuis Linux 1.1.92)
PIO_UNIMAPCLR
Effacer la table, potentiellement conseiller l'algorithme de hachage. argp pointe vers une

struct unimapinit {
    unsigned short advised_hashsize;  /* 0 si pas d'avis */
    unsigned short advised_hashstep;  /* 0 si pas d'avis */
    unsigned short advised_hashlevel; /* 0 si pas d'avis */
};

(Depuis Linux 1.1.92.)
KDGKBMODE
Obtient le mode courant du clavier. argp pointe vers un long qui est défini à l'une des valeurs suivantes :
K_RAW 0x00 /* Mode brut (scancode) */
K_XLATE 0x01 /* Traduit les codes de touche en utilisant la table de touches */
K_MEDIUMRAW 0x02 /* Mode brut moyen (scancode) */
K_UNICODE 0x03 /* Mode Unicode */
K_OFF 0x04 /* Mode désactivé (depuis Linux 2.6.39) */
KDSKBMODE
Définit le mode courant du clavier. argp est un long égal à l'une des valeurs indiquées pour KDGKBMODE.
KDGKBMETA
Obtient le mode de gestion de la touche méta. argp pointe vers un long qui est défini à l'une des valeurs suivantes :
K_METABIT 0x03 définit le bit d'ordre élevé
K_ESCPREFIX 0x04 préfixe d'échappement
KDSKBMETA
Définit le mode de gestion de la touche méta. argp est un long égal à l'une des valeurs indiquées ci-dessus pour KDGKBMETA.
KDGKBENT
Obtient une entrée dans la table de traduction des touches (code de touche vers code d'action). argp pointe vers une

struct kbentry {
    unsigned char  kb_table;
    unsigned char  kb_index;
    unsigned short kb_value;
};

avec les deux premiers membres remplis : kb_table sélectionne la table de touches (0 <= kb_table < MAX_NR_KEYMAPS), et kb_index est le code de touche (0 <= kb_index < NR_KEYS). kb_value est défini au code d'action correspondant, ou K_HOLE s'il n'y a pas de telle touche, ou K_NOSUCHMAP si kb_table est invalide.
KDSKBENT
Définit une entrée dans la table de traduction. argp pointe vers une struct kbentry.
KDGKBSENT
Obtient une chaîne de touche de fonction. argp pointe vers une

struct kbsentry {
    unsigned char kb_func;
    unsigned char kb_string[512];
};

kb_string est défini à la chaîne (terminée par null) correspondant au code d'action de la kb_func-ième touche de fonction.
KDSKBSENT
Définit une entrée de chaîne de touche de fonction. argp pointe vers une struct kbsentry.
KDGKBDIACR
Lit la table d'accents du noyau. argp pointe vers une

struct kbdiacrs {
    unsigned int   kb_cnt;
    struct kbdiacr kbdiacr[256];
};

où kb_cnt est le nombre d'entrées dans le tableau, chacune étant une

struct kbdiacr {
    unsigned char diacr;
    unsigned char base;
    unsigned char result;
};

KDGETKEYCODE
Lit une entrée de la table des codes de touche du noyau (code de scan vers code de touche). argp pointe vers une

struct kbkeycode {
    unsigned int scancode;
    unsigned int keycode;
};

keycode est défini pour correspondre au scancode donné. (Uniquement 89 <= scancode <= 255. Pour 1 <= scancode <= 88, keycode==scancode.) (Depuis Linux 1.1.63.)
KDSETKEYCODE
Écrit une entrée de la table des codes de touche du noyau. argp pointe vers une struct kbkeycode. (Depuis Linux 1.1.63.)
KDSIGACCEPT
Le processus appelant indique sa volonté d'accepter le signal argp lorsqu'il est généré en appuyant sur une combinaison de touches appropriée. (1 <= argp <= NSIG). (Voir spawn_console() dans linux/drivers/char/keyboard.c.)

VALEUR RENVOYÉE

En cas de succès, 0 est renvoyé (sauf indication contraire). En cas d'échec, -1 est renvoyé, et errno est défini pour indiquer l'erreur.

ERREURS

EINVAL
argp est invalide.

NORMES

Linux.

VOIR AUSSI

ioctl(2), ioctl_console(2)
