ioctl_kd(2) Manuel des appels système ioctl_kd(2)

NOM

ioctl_kd - ioctls pour le terminal console et les consoles virtuelles

SYNTAXE

#include <linux/kd.h>  /* Définition des constantes d'opération */
#include <sys/ioctl.h>
int ioctl(int fd, unsigned long op, void *argp);

DESCRIPTION

Les opérations ioctl(2) suivantes, spécifiques à Linux, sont supportées pour les terminaux consoles et les consoles virtuelles.

KDGETLED
Obtenir l'état des LED. argp pointe vers un char. Les trois bits de poids faible de *argp sont définis à l'état des LED, comme suit :
LED_CAP 0x04 LED du verrouillage majuscule
LED_NUM 0x02 LED du verrouillage numérique
LED_SCR 0x01 LED du verrouillage de défilement
KDSETLED
Définir les LED. Les LED sont définies pour correspondre aux trois bits de poids faible de l'entier non signé argp. Cependant, si un bit de poids fort est défini, les LED reviennent à la normale : affichant l'état des fonctions du clavier verrouillage majuscule, verrouillage numérique et verrouillage de défilement.

Avant Linux 1.1.54, les LED reflétaient simplement l'état des indicateurs correspondants du clavier, et KDGETLED/KDSETLED changeaient également les indicateurs du clavier. Depuis Linux 1.1.54, les LED peuvent être utilisées pour afficher des informations arbitraires, mais par défaut, elles affichent les indicateurs du clavier. Les deux ioctls suivants sont utilisés pour accéder aux indicateurs du clavier.

KDGKBLED
Obtenir les indicateurs du clavier verrouillage majuscule, verrouillage numérique, verrouillage de défilement (pas les lumières). argp pointe vers un char qui est défini à l'état de l'indicateur. Les trois bits de poids faible (masque 0x7) obtiennent l'état actuel de l'indicateur, et les bits de poids faible de la prochaine nibble (masque 0x70) obtiennent l'état par défaut de l'indicateur. (Depuis Linux 1.1.54.)
KDSKBLED
Définir les indicateurs du clavier verrouillage majuscule, verrouillage numérique, verrouillage de défilement (pas les lumières). argp est un entier non signé qui contient l'état souhaité de l'indicateur. Les trois bits de poids faible (masque 0x7) ont l'état de l'indicateur, et les bits de poids faible de la prochaine nibble (masque 0x70) ont l'état par défaut de l'indicateur. (Depuis Linux 1.1.54.)
KDGKBTYPE
Obtenir le type de clavier. Renvoie la valeur KB_101, définie comme 0x02.
KDADDIO
Ajouter un port d'E/S comme valide. Équivalent à ioperm(arg,1,1).
KDDELIO
Supprimer un port d'E/S comme valide. Équivalent à ioperm(arg,1,0).
KDENABIO
Activer les E/S vers la carte vidéo. Équivalent à ioperm(0x3b4, 0x3df-0x3b4+1, 1).
KDDISABIO
Désactiver les E/S vers la carte vidéo. Équivalent à ioperm(0x3b4, 0x3df-0x3b4+1, 0).
KDSETMODE
Définir le mode texte/graphique. argp est un entier non signé contenant l'une des valeurs suivantes :
KD_TEXT 0x00
KD_GRAPHICS 0x01
KDGETMODE
Obtenir le mode texte/graphique. argp pointe vers un int qui est défini à l'une des valeurs ci-dessus pour KDSETMODE.
KDMKTONE
Générer une tonalité de durée spécifiée. Les 16 bits de poids faible de l'entier non signé argp spécifient la période en cycles d'horloge, et les 16 bits de poids fort donnent la durée en ms. Si la durée est zéro, le son est désactivé. Le contrôle revient immédiatement. Par exemple, argp = (125<<16) + 0x637 spécifierait le bip normalement associé à un ctrl-G. (Ainsi, depuis Linux 0.99pl1 ; défectueux dans Linux 2.1.49-50.)
KIOCSOUND
Démarrer ou arrêter la génération de son. Les 16 bits de poids faible de argp spécifient la période en cycles d'horloge (c'est-à-dire argp = 1193180/fréquence). argp = 0 désactive le son. Dans les deux cas, le contrôle revient immédiatement.
GIO_CMAP
Obtenir la table de couleurs par défaut actuelle du noyau. argp pointe vers un tableau de 48 octets. (Depuis Linux 1.3.3.)
PIO_CMAP
Changer la table de couleurs par défaut en mode texte. argp pointe vers un tableau de 48 octets qui contient, dans l'ordre, les valeurs Rouge, Vert et Bleu pour les 16 couleurs d'écran disponibles : 0 est désactivé, et 255 est l'intensité maximale. Les couleurs par défaut sont, dans l'ordre : noir, rouge sombre, vert sombre, brun, bleu sombre, violet sombre, cyan sombre, gris clair, gris sombre, rouge vif, vert vif, jaune, bleu vif, violet vif, cyan vif, et blanc. (Depuis Linux 1.3.3.)
GIO_FONT
Obtenir la police d'écran de 256 caractères sous forme étendue. argp pointe vers un tableau de 8192 octets. Échoue avec le code d'erreur EINVAL si la police actuellement chargée est une police de 512 caractères, ou si la console n'est pas en mode texte.
GIO_FONTX
Obtenir la police d'écran et les informations associées. argp pointe vers une struct consolefontdesc (voir PIO_FONTX). À l'appel, le champ charcount doit être défini au nombre maximum de caractères qui tiendraient dans le tampon pointé par chardata. Au retour, charcount et charheight sont remplis avec les données respectives pour la police actuellement chargée, et le tableau chardata contient les données de la police si la valeur initiale de charcount indiquait que suffisamment d'espace était disponible ; sinon, le tampon est inchangé et errno est défini à ENOMEM. (Depuis Linux 1.3.1.)
PIO_FONT
Définir la police d'écran de 256 caractères. Charger la police dans le générateur de caractères EGA/VGA. argp pointe vers une carte de 8192 octets, avec 32 octets par caractère. Seuls les N premiers sont utilisés pour une police 8xN (0 < N <= 32). Cet appel invalide également le mappage Unicode.
PIO_FONTX
Définit la police d'écran et les informations de rendu associées. argp pointe vers une

struct consolefontdesc {
    unsigned short charcount;  /* caractères dans la police
                                  (256 ou 512) */
    unsigned short charheight; /* lignes de balayage par
                                  caractère (1-32) */
    char          *chardata;   /* données de la police sous
                                  forme étendue */
};

Si nécessaire, l'écran sera redimensionné de manière appropriée, et SIGWINCH sera envoyé aux processus appropriés. Cet appel invalide également le mappage Unicode. (Depuis Linux 1.3.1.)
PIO_FONTRESET
Réinitialise la police d'écran, la taille et le mappage Unicode aux valeurs par défaut au démarrage. argp n'est pas utilisé, mais doit être défini à NULL pour assurer la compatibilité avec les futures versions de Linux. (Depuis Linux 1.3.28.)
GIO_SCRNMAP
Obtenir la table de mappage de l'écran du noyau. argp pointe vers une zone de taille E_TABSZ, qui est chargée avec les positions de police utilisées pour afficher chaque caractère. Cet appel est susceptible de renvoyer des informations inutiles si la police actuellement chargée contient plus de 256 caractères.
GIO_UNISCRNMAP
Obtenir la table de mappage complète Unicode de l'écran du noyau. argp pointe vers une zone de taille E_TABSZ*sizeof(unsigned short), qui est chargée avec les Unicodes que chaque caractère représente. Un ensemble spécial d'Unicodes, commençant à U+F000, est utilisé pour représenter les mappages "directement vers la police". (Depuis Linux 1.3.1.)
PIO_SCRNMAP
Charge la table "définissable par l'utilisateur" (quatrième) dans le noyau qui mappe les octets aux symboles de l'écran de la console. argp pointe vers une zone de taille E_TABSZ.
