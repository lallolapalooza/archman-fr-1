ioctl_kd(2) Manuels d'appels système ioctl_kd(2)

NAME

ioctl_kd - appels ioctl pour les terminaux de console et les fenêtres virtuelles

SYNOPSIS

#include <linux/kd.h>  /* Définition des constantes d'op */
#include <sys/ioctl.h>
int ioctl(int fd, unsigned long op, void *argp);

DESCRIPTION

Les opérations ioctl spécifiques à Linux suivantes sont prises en charge pour les terminaux de console et les fenêtres virtuelles.

KDGETLED
Obtenir l'état des diodes lumineuses. argp pointe vers un char. Les trois bits de poids faible de *argp indiquent l'état des diodes lumineuses, comme suit :
LED_CAP 0x04 diode lumineuse du verrouillage majuscule
LED_NUM 0x02 diode lumineuse du verrouillage numérique
LED_SCR 0x01 diode lumineuse du verrouillage de défilement
KDSETLED
Définir les diodes lumineuses. Les diodes lumineuses sont définies selon les trois bits de poids faible de l'entier unsigned long dans argp. Cependant, si un bit de poids fort est activé, les diodes lumineuses deviennent normales, affichant l'état des fonctions du clavier du verrouillage majuscule, du verrouillage numérique et du verrouillage de défilement.

Avant Linux 1.1.54, les diodes lumineuses reflétaient seulement l'état des drapeaux de clavier correspondants, et KDGETLED/KDSETLED changeaient également les drapeaux de clavier. Depuis Linux 1.1.54, les diodes lumineuses peuvent afficher des informations arbitraires, mais par défaut elles affichent les drapeaux de clavier. Les deux ioctl suivants sont utilisés pour accéder aux drapeaux de clavier.

KDGKBLED
Obtenir l'état des drapeaux de clavier Verrouillage Maj, Verrouillage Num, Verrouillage Défil (pas les diodes lumineuses). argp pointe vers un char qui est défini à l'état des drapeaux. Les trois bits de poids faible (masque 0x7) indiquent l'état actuel des drapeaux, et les bits de poids faible du prochain groupe (masque 0x70) indiquent l'état par défaut des drapeaux. (Depuis Linux 1.1.54.)
KDSKBLED
Définir l'état des drapeaux de clavier Verrouillage Maj, Verrouillage Num, Verrouillage Défil (pas les diodes lumineuses). argp est un entier unsigned long qui contient l'état souhaité des drapeaux. Les trois bits de poids faible (masque 0x7) contiennent l'état des drapeaux, et les bits de poids faible du prochain groupe (masque 0x70) contiennent l'état par défaut des drapeaux. (Depuis Linux 1.1.54.)
KDGKBTYPE
Obtenir le type de clavier. Renvoie la valeur KB_101, définie comme 0x02.
KDADDIO
Ajouter un port d'E/S comme valide. Équivalent à ioperm(arg,1,1).
KDDELIO
Supprimer un port d'E/S comme valide. Équivalent à ioperm(arg,1,0).
KDENABIO
Activer l'accès aux E/S sur le périphérique vidéo. Équivalent à ioperm(0x3b4, 0x3df-0x3b4+1, 1).
KDDISABIO
Désactiver l'accès aux E/S sur le périphérique vidéo. Équivalent à ioperm(0x3b4, 0x3df-0x3b4+1, 0).
KDSETMODE
Définir le mode texte/graphique. argp est un entier unsigned contenant l'une des valeurs suivantes :
KD_TEXT 0x00
KD_GRAPHICS 0x01
KDGETMODE
Obtenir le mode texte/graphique. argp pointe vers un int qui est défini à l'une des valeurs ci-dessus pour KDSETMODE.
KDMKTONE
Générer une tonalité d'une durée spécifiée. Les 16 bits de poids faible de l'entier unsigned long dans argp spécifient la durée en cycles d'horloge, et les 16 bits de poids fort indiquent la durée en millisecondes. Si la durée est zéro, le son est désactivé. Le contrôle retourne immédiatement. Exemple : argp = (125<<16) + 0x637 spécifie la tonalité normale associée à un Ctrl-G. (Donc, depuis Linux 0.99pl1; échoue sous Linux 2.1.49-50.)
KIOCSOUND
Démarrer ou arrêter la génération de son. Les 16 bits de poids faible de argp correspondent à la durée en cycles d'horloge (c'est-à-dire, argp = 1193180/fréquence). argp = 0 désactive le son. Dans tous les cas, le contrôle retourne immédiatement.
GIO_CMAP
Obtenir la palette de couleurs actuelle du noyau. argp pointe vers un tableau de 48 octets. (Depuis Linux 1.3.3.)
PIO_CMAP
Changer la palette de couleurs par défaut du mode texte. argp pointe vers un tableau de 48 octets contenant, dans l'ordre, les valeurs rouge, verte et bleue pour les 16 couleurs d'écran disponibles : 0 est éteint, 255 est l'intensité maximale. Les couleurs par défaut sont : noir, rouge foncé, vert foncé, marron, bleu foncé, violet foncé, cyan foncé, gris clair, gris foncé, rouge vif, vert vif, jaune, bleu vif, violet vif, cyan vif, blanc. (Depuis Linux 1.3.3.)
GIO_FONT
Obtenir la police d'écran au format étendu. argp pointe vers un tableau de 8192 octets. Échoue avec le code d'erreur EINVAL si la police actuelle est une police de 512 caractères, ou si le terminal n'est pas en mode texte.
GIO_FONTX
Obtenir la police d'écran et les informations associées. argp pointe vers une structure struct consolefontdesc (voir PIO_FONTX). Lors de l'appel, le champ charcount doit être défini au nombre maximum de caractères pouvant tenir dans le tampon pointé par chardata. Au retour, les champs charcount et charheight sont remplis avec les données correspondantes de la police actuelle, et chardata contient les données de la police si la valeur initiale de charcount indiquait suffisamment d'espace ; sinon, le tampon n'est pas modifié et errno est défini à ENOMEM. (Depuis Linux 1.3.1.)
PIO_FONT
Définir la police d'écran de 256 caractères. Charge la police dans le générateur de caractères EGA/VGA. argp pointe vers une carte de 8192 octets avec 32 octets par caractère. Seuls les N premiers sont utilisés pour une police de 8xN (0 < N <= 32). Cet appel invalide également le mappage Unicode.
PIO_FONTX
Définir la police d'écran et les informations de rendu. argp pointe vers

struct consolefontdesc {
    unsigned short charcount;  /* caractères dans la police
                                  (256 ou 512) */
    unsigned short charheight; /* lignes de balayage par caractère (1-32) */
    char          *chardata;   /* données de la police au format étendu */
};

Si nécessaire, l'écran sera redimensionné correctement et le signal SIGWINCH sera envoyé aux processus appropriés. Cet appel invalide également le mappage Unicode. (Depuis Linux 1.3.1.)
PIO_FONTRESET
Réinitialise la police d'écran, la taille et le mappage Unicode aux valeurs par défaut au démarrage. argp n'est pas utilisé, mais doit être défini à NULL pour garantir la compatibilité avec les futures versions de Linux. (Depuis Linux 1.3.28.)
GIO_SCRNMAP
Obtenir la carte d'écran du noyau. argp pointe vers une zone de taille E_TABSZ, contenant les positions de la police utilisées pour afficher chaque caractère. Cet appel peut renvoyer des informations utiles si la police actuelle est supérieure à 256 caractères.
GIO_UNISCRNMAP
Obtenir la carte d'écran Unicode complète du noyau. argp pointe vers une zone de taille E_TABSZ*sizeof(unsigned short), contenant les codes Unicode représentant chaque caractère. Une séquence spéciale d'Unicode, commençant par U+F000, est utilisée pour représenter les mappages "direct vers la police". (Depuis Linux 1.3.1.)
PIO_SCRNMAP
Charge la table "utilisable" (quatrième) du noyau, qui mappe les octets aux symboles d'écran. argp pointe vers une zone de taille E_TABSZ.

NOM

PIO_UNISCRNMAP

RÉSUMÉ

struct unimapdesc { ... }

DESCRIPTION

Charge la table "définissable par l'utilisateur" (quatrième) dans le noyau qui met en correspondance des octets avec des Unicodes, qui sont ensuite traduits en symboles d'écran selon la table de mappage actuelle des Unicodes vers la typographie. Les Unicodes spéciaux commençant par U+F000 peuvent être utilisés directement pour les faire correspondre aux symboles de la typographie. (Depuis Linux 1.3.1.)

VALEUR DE RETOUR

En cas de succès, 0 est retourné (sauf indication contraire). En cas d'erreur, -1 est retourné et errno est défini pour indiquer l'erreur.

ERREURS

EINVAL
argp est invalide.

NORMES

Linux.

VOIR AUSSI

ioctl(2), ioctl_console(2)
