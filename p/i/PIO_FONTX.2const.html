ioctl_kd(2) Manuel des appels système ioctl_kd(2)

NOM

ioctl_kd - appels système pour les terminaux de console et les fenêtres virtuelles

SYNOPSIS

#include <linux/kd.h>  /* Définitions des constantes d'op */
#include <sys/ioctl.h>
int ioctl(int fd, unsigned long op, void *argp);

DESCRIPTION

Les opérations ioctl(2) suivantes, spécifiques aux terminaux de console et aux fenêtres virtuelles, sont disponibles sous Linux :

KDGETLED
Obtenir l'état des LEDs. argp pointe vers un char. Les trois derniers bits de *argp sont mis à l'état des LEDs, comme suit :

LED_CAP 0x04 LED du verrouillage des majuscules
LED_NUM 0x02 LED du verrouillage numérique
LED_SCR 0x01 LED du défilement
KDSETLED
Définir les LEDs. Les LEDs sont définies selon les trois derniers bits de argp, qui est un entier non signé. Cependant, si un bit de poids supérieur est défini, les LEDs sont réinitialisées à leur état normal : affichant l'état des fonctions du clavier de verrouillage des majuscules, de verrouillage numérique et de défilement.

Avant Linux 1.1.54, les LEDs reflétaient uniquement l'état des indicateurs de clavier correspondants, et KDGETLED/KDSETLED changeaient également les indicateurs de clavier. Depuis Linux 1.1.54, les LEDs peuvent afficher des informations arbitraires, mais par défaut, elles affichent les indicateurs du clavier. Les deux ioctls suivants sont utilisés pour accéder aux indicateurs du clavier :

KDGKBLED
Obtenir les indicateurs du clavier pour le verrouillage des majuscules, le verrouillage numérique et le défilement (pas les LEDs). argp pointe vers un char qui est mis à l'état des indicateurs. Les trois bits de poids faible (masque 0x7) obtiennent l'état actuel des indicateurs, et les bits de poids faible du quatrième octet suivant (masque 0x70) obtiennent l'état par défaut des indicateurs. (Depuis Linux 1.1.54.)
KDSKBLED
Définir les indicateurs du clavier pour le verrouillage des majuscules, le verrouillage numérique et le défilement (pas les LEDs). argp est un entier non signé qui contient l'état souhaité des indicateurs. Les trois bits de poids faible (masque 0x7) contiennent l'état des indicateurs, et les bits de poids faible du quatrième octet suivant (masque 0x70) contiennent l'état par défaut des indicateurs. (Depuis Linux 1.1.54.)
KDGKBTYPE
Obtenir le type de clavier. Renvoie la valeur KB_101, définie comme 0x02.
KDADDIO
Ajouter un port d'E/S comme valide. Équivalent à ioperm(arg,1,1).
KDDELIO
Supprimer un port d'E/S comme valide. Équivalent à ioperm(arg,1,0).
KDENABIO
Activer les E/S vers la carte vidéo. Équivalent à ioperm(0x3b4, 0x3df-0x3b4+1, 1).
KDDISABIO
Désactiver les E/S vers la carte vidéo. Équivalent à ioperm(0x3b4, 0x3df-0x3b4+1, 0).
KDSETMODE
Définir le mode texte/graphique. argp est un entier non signé contenant l'une des valeurs suivantes :

KD_TEXT 0x00
KD_GRAPHICS 0x01
KDGETMODE
Obtenir le mode texte/graphique. argp pointe vers un int qui est mis à l'une des valeurs indiquées ci-dessus pour KDSETMODE.
KDMKTONE
Générer un son d'une durée spécifiée. Les 16 bits de poids faible de argp spécifient la périodicité en cycles d'horloge, et les 16 bits de poids fort spécifient la durée en millisecondes. Si la durée est nulle, le son est désactivé. L'appel se termine immédiatement. Par exemple, argp = (125<<16) + 0x637 spécifie le son normal associé à un ctrl-G. (Depuis Linux 0.99pl1 ; cassé dans Linux 2.1.49-50.)
KIOCSOUND
Activer ou désactiver la génération du son. Les 16 bits de poids faible de argp spécifient la périodicité en cycles d'horloge (c'est-à-dire argp = 1193180/fréquence). argp = 0 désactive le son. Dans tous les cas, l'appel se termine immédiatement.
GIO_CMAP
Obtenir la palette de couleurs actuelle du noyau. argp pointe vers un tableau de 48 octets. (Depuis Linux 1.3.3.)
PIO_CMAP
Changer la palette de couleurs par défaut en mode texte. argp pointe vers un tableau de 48 octets contenant, dans l'ordre, les valeurs rouge, verte et bleue pour les 16 couleurs d'écran disponibles : 0 est éteint, et 255 est à intensité maximale. Les couleurs par défaut sont, dans l'ordre : noir, rouge foncé, vert foncé, marron, bleu foncé, pourpre bleu, cyan foncé, gris clair, gris foncé, rouge vif, vert vif, jaune, bleu vif, pourpre vif, cyan vif, blanc. (Depuis Linux 1.3.3.)
GIO_FONT
Obtenir la police de 256 caractères sous forme étendue. argp pointe vers un tableau de 8192 octets. Renvoie une erreur avec le code EINVAL si la police actuellement chargée est une police de 512 caractères, ou si la console n'est pas en mode texte.
GIO_FONTX
Obtenir la police d'écran et les informations associées. argp pointe vers une struct consolefontdesc (voir PIO_FONTX). Lors de l'appel, le champ charcount doit être défini sur le nombre maximal de caractères pouvant tenir dans le tampon pointé par chardata. Lors du retour, les champs charcount et charheight contiennent les données respectives de la police actuellement chargée, et le tableau chardata contient les données de la police si la valeur initiale de charcount indiquait qu'il y avait suffisamment d'espace ; sinon, le tampon n'est pas modifié et errno est défini sur ENOMEM. (Depuis Linux 1.3.1.)
PIO_FONT
Définir la police de 256 caractères en mode texte. Charge la police dans le générateur de caractères EGA/VGA. argp pointe vers un tableau de 8192 octets, avec 32 octets par caractère. Seuls les N premiers sont utilisés pour une police de 8xN (0 <= N < 32). Cet appel invalide également le mappage Unicode.
PIO_FONTX
Définir la police d'écran et les informations de rendu. argp pointe vers une

struct consolefontdesc {
    unsigned short charcount;  /* caractères dans la police (256 ou 512) */
    unsigned short charheight; /* lignes de balayage par caractère (1-32) */
    char          *chardata;   /* données de la police sous forme étendue */
};

Si nécessaire, l'écran sera redimensionné et SIGWINCH sera envoyé aux processus appropriés. Cet appel invalide également le mappage Unicode. (Depuis Linux 1.3.1.)
PIO_FONTRESET
Restaure le mode d'affichage, la taille et le mappage Unicode aux valeurs par défaut au démarrage. argp n'est pas utilisé, mais doit être défini à NULL pour assurer la compatibilité avec les futures versions de Linux. (Depuis Linux 1.3.28.)
GIO_SCRNMAP
Obtenir le mappage d'écran du noyau. argp pointe vers une zone de taille E_TABSZ, qui est remplie avec les emplacements de police utilisés pour afficher chaque caractère. Cet appel peut retourner des informations utiles si la police actuellement chargée contient plus de 256 caractères.
GIO_UNISCRNMAP
Obtenir le mappage d'écran Unicode complet du noyau. argp pointe vers une zone de taille E_TABSZ * sizeof(unsigned short), qui est remplie avec les Unicode représentant chaque caractère. Un ensemble spécial d'Unicode, commençant par U+F000, est utilisé pour représenter les mappages "directement dans la police". (Depuis Linux 1.3.1.)
PIO_SCRNMAP
Charge la "table définissable" (quatrième table) du noyau qui mappe les octets aux symboles d'écran de console. argp pointe vers une zone de taille E_TABSZ.
PIO_UNISCRNMAP
Obtient le mappage d'écran Unicode complet du noyau. argp pointe vers une zone de taille E_TABSZ * sizeof(unsigned short), qui est remplie avec les Unicode représentant chaque caractère. Un ensemble spécial d'Unicode, commençant par U+F000, est utilisé pour représenter les mappages "directement dans la police". (Depuis Linux 1.3.1.)
GIO_SCRNMAP
Obtient le mappage d'écran du noyau. argp pointe vers une zone de taille E_TABSZ, qui est remplie avec les emplacements de police utilisés pour afficher chaque caractère. Cet appel peut retourner des informations utiles si la police actuellement chargée contient plus de 256 caractères.

ioctl_console(2) — Linux manual pages

NAME

ioctl_console - divers ioctl(2) demandes pour la console Linux

SYNOPSIS

Les appels système suivants sont décrits dans cette page de manuel :

#include <linux/kd.h>
#include <linux/vt.h>
#include <linux/major.h>
#include <linux/console.h>

int ioctl(int fd, int request, ...);

DESCRIPTION

La console Linux, qui inclut le clavier et l'écran, peut être manipulée à l'aide de l'appel système ioctl(2). Les ioctls décrits ici peuvent être appelés sur un descripteur de fichier ouvert sur un périphérique de console (typiquement /dev/ttyN, où N est un numéro). Les constantes de requête sont définies dans <linux/kd.h>.

PIO_UNISCRNMAP
Charge la table "définissable par l'utilisateur" (quatrième) dans le noyau, qui mappe les octets en Unicodes, lesquels sont ensuite traduits en symboles d'écran selon la carte de mappage Unicode-vers-police actuellement chargée. Les Unicodes spéciaux commençant à U+F000 peuvent être utilisés pour mapper directement aux symboles de police. (Depuis Linux 1.3.1.)
GIO_UNIMAP
Obtenir le mappage Unicode-vers-police du noyau. argp pointe vers une

struct unimapdesc {
    unsigned short  entry_ct;
    struct unipair *entries;
};

où entries pointe vers un tableau de

struct unipair {
    unsigned short unicode;
    unsigned short fontpos;
};

(Depuis Linux 1.1.92.)
PIO_UNIMAP
Placer le mappage unicode-vers-police dans le noyau. argp pointe vers une struct unimapdesc. (Depuis Linux 1.1.92)
PIO_UNIMAPCLR
Effacer la table, éventuellement suggérer un algorithme de hachage. argp pointe vers une

struct unimapinit {
    unsigned short advised_hashsize;  /* 0 si aucune opinion */
    unsigned short advised_hashstep;  /* 0 si aucune opinion */
    unsigned short advised_hashlevel; /* 0 si aucune opinion */
};

(Depuis Linux 1.1.92.)
KDGKBMODE
Obtenir le mode actuel du clavier. argp pointe vers un long qui est défini sur l'une des valeurs suivantes :
K_RAW 0x00 /* Mode brut (scancode) */
K_XLATE 0x01 /* Traduit les codes de touches en utilisant la table de touches */
K_MEDIUMRAW 0x02 /* Mode brut moyen (scancode) */
K_UNICODE 0x03 /* Mode Unicode */
K_OFF 0x04 /* Mode désactivé (depuis Linux 2.6.39) */
KDSKBMODE
Définit le mode actuel du clavier. argp est un long égal à l'une des valeurs indiquées pour KDGKBMODE.
KDGKBMETA
Obtenir le mode de gestion de la touche méta. argp pointe vers un long qui est défini sur l'une des valeurs suivantes :
K_METABIT 0x03 définit le bit d'ordre élevé
K_ESCPREFIX 0x04 préfixe d'échappement
KDSKBMETA
Définit le mode de gestion de la touche méta. argp est un long égal à l'une des valeurs indiquées ci-dessus pour KDGKBMETA.
KDGKBENT
Obtenir une entrée dans la table de traduction des touches (code de touche vers code d'action). argp pointe vers une

struct kbentry {
    unsigned char  kb_table;
    unsigned char  kb_index;
    unsigned short kb_value;
};

avec les deux premiers membres remplis : kb_table sélectionne la table de touches (0 <= kb_table < MAX_NR_KEYMAPS), et kb_index est le code de touche (0 <= kb_index < NR_KEYS). kb_value est défini sur le code d'action correspondant, ou K_HOLE s'il n'y a pas de telle touche, ou K_NOSUCHMAP si kb_table est invalide.
KDSKBENT
Définit une entrée dans la table de traduction. argp pointe vers une struct kbentry.
KDGKBSENT
Obtenir une chaîne de touche de fonction. argp pointe vers une

struct kbsentry {
    unsigned char kb_func;
    unsigned char kb_string[512];
};

kb_string est définie sur la chaîne (terminée par null) correspondant au code d'action de la kb_func-ième touche de fonction.
KDSKBSENT
Définit une entrée de chaîne de touche de fonction. argp pointe vers une struct kbsentry.
KDGKBDIACR
Lire la table des accents du noyau. argp pointe vers une

struct kbdiacrs {
    unsigned int   kb_cnt;
    struct kbdiacr kbdiacr[256];
};

où kb_cnt est le nombre d'entrées dans le tableau, chacune d'elles étant une

struct kbdiacr {
    unsigned char diacr;
    unsigned char base;
    unsigned char result;
};

KDGETKEYCODE
Lire une entrée de la table des codes de touches du noyau (code de scan vers code de touche). argp pointe vers une

struct kbkeycode {
    unsigned int scancode;
    unsigned int keycode;
};

keycode est défini pour correspondre au scancode donné. (89 <= scancode <= 255 seulement. Pour 1 <= scancode <= 88, keycode==scancode.) (Depuis Linux 1.1.63.)
KDSETKEYCODE
Écrire une entrée de la table des codes de touches du noyau. argp pointe vers une struct kbkeycode. (Depuis Linux 1.1.63.)
KDSIGACCEPT
Le processus appelant indique sa volonté d'accepter le signal argp lorsqu'il est généré en appuyant sur une combinaison de touches appropriée. (1 <= argp <= NSIG). (Voir spawn_console() dans linux/drivers/char/keyboard.c.)

RETURN VALUE

En cas de succès, 0 est retourné (sauf indication contraire). En cas d'échec, -1 est retourné et errno est défini pour indiquer l'erreur.

ERRORS

EINVAL
argp est invalide.

STANDARDS

Linux.
