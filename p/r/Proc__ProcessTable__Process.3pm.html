NOM

Proc::ProcessTable::Process - Objets de processus Perl

SYNTAXE

$process->kill(9);
$process->priority(19);
$process->pgrp(500);
$uid = $process->uid;
...

DESCRIPTION

C'est un module stub pour fournir un accès aux attributs des processus orienté objet pour Proc::ProcessTable. Les objets Proc::ProcessTable::Process sont construits directement par Proc::ProcessTable; il n'y a pas de méthode constructeur, seulement des accesseurs.

MÉTHODES

kill
Envoie un signal au processus ; simple wrapper esthétique pour la fonction kill de Perl. Prend le signal (nom ou numéro) comme argument. Renvoie le nombre de processus signalés.
priority
Accesseur get/set ; si appelé avec un argument numérique, tente de réinitialiser la priorité du processus à ce nombre en utilisant la fonction setpriority de Perl. Renvoie la priorité du processus.
pgrp
Identique à ci-dessus pour le groupe de processus.
toutes les autres méthodes...
sont de simples accesseurs qui récupèrent les attributs du processus pour lesquels elles sont nommées. Actuellement supportés sont : 
uid         UID du processus
gid         GID du processus
euid        UID effectif du processus           (Solaris uniquement)
egid        GID effectif du processus           (Solaris uniquement)
pid         ID du processus
ppid        ID du processus parent
spid        ID sprod                           (IRIX uniquement)
pgrp        groupe de processus
sess        ID de session
cpuid       ID du CPU du processeur sur lequel il s'exécute (IRIX uniquement)
priority    priorité du processus
ttynum      numéro de tty du processus
flags       flags du processus
minflt      pages fautes mineures               (Linux uniquement)
cminflt     pages fautes mineures enfant        (Linux uniquement)
majflt      pages fautes majeures               (Linux uniquement)
cmajflt     pages fautes majeures enfant        (Linux uniquement)
utime       temps en mode utilisateur (1/100 de seconde) (Linux uniquement)
stime       temps en mode noyau                (Linux uniquement)
cutime      utime enfant                        (Linux uniquement)
cstime      stime enfant                        (Linux uniquement)
time        temps utilisateur + système
ctime       temps utilisateur + système enfant
timensec    partie nanoseconde utilisateur + système (Solaris uniquement)
ctimensec   nanoseconde utilisateur + système enfant (Solaris uniquement)
qtime       temps CPU cumulé                   (IRIX uniquement)
size        taille de la mémoire virtuelle (octets)
rss         taille de l'ensemble résident (octets)
wchan       adresse de l'appel système actuel
fname       nom du fichier
start       heure de démarrage (secondes depuis l'époque)
pctcpu      pourcentage de CPU utilisé depuis le démarrage du processus
state       état du processus
pctmem      pourcentage de mémoire
cmndline    ligne de commande complète du processus
ttydev      chemin du tty du processus
clname      nom de la classe de planification  (IRIX uniquement)

Voir les fichiers "README.osname" dans la distribution pour des informations plus à jour.
