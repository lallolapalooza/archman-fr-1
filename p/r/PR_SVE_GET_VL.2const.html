PR_SVE_GET_VL(2const) PR_SVE_GET_VL(2const)

NOM

PR_SVE_GET_VL - obtenir la longueur du vecteur SVE du thread

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <linux/prctl.h>  /* Définition des constantes PR_* */
#include <sys/prctl.h>
int prctl(PR_SVE_GET_VL);

DESCRIPTION

Obtenir la configuration actuelle de la longueur du vecteur SVE du thread.

Cette opération retourne une valeur non négative décrivant la configuration actuelle. Les bits correspondant à PR_SVE_VL_LEN_MASK contiennent la longueur du vecteur configurée actuellement en octets. Le bit correspondant à PR_SVE_VL_INHERIT indique si la longueur du vecteur sera héritée lors d'un appel execve(2).

VALEUR DE RETOUR

En cas de succès, PR_SVE_GET_VL retourne les valeurs non négatives décrites ci-dessus. En cas d'erreur, -1 est retourné et errno est défini pour indiquer l'erreur.

ERREURS

EINVAL
SVE n'est pas disponible sur cette plateforme.

NORMES

Linux. arm64 uniquement.

HISTORIQUE

Linux 4.15 (arm64).

NOTES DE MISE EN GARDE

Il n'y a aucun moyen de déterminer s'il existe un changement de longueur de vecteur en attente qui n'a pas encore pris effet.

VOIR AUSSI

prctl(2), PR_SVE_SET_VL(2const)
