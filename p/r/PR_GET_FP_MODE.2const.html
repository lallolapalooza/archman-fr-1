PR_GET_FP_MODE(2const) PR_GET_FP_MODE(2const)

NOM

PR_GET_FP_MODE - obtenir le mode à virgule flottante du processus appelant

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNOPSIS

#include <linux/prctl.h>  /* Définition des constantes PR_* */
#include <sys/prctl.h>
int prctl(PR_GET_FP_MODE);

DESCRIPTION

Retourne un masque de bits qui représente le mode courant à virgule flottante (voir PR_SET_FP_MODE(2const) pour plus de détails).

VALEUR RENVOYÉE

En cas de succès, cet appel retourne la valeur non négative décrite ci-dessus. En cas d'erreur, -1 est retourné et errno est défini pour indiquer l'erreur.

NORMES

Linux. MIPS uniquement.

HISTORIQUE

Linux 4.0 (MIPS).

VOIR AUSSI

prctl(2), PR_GET_FP_MODE(2const)
