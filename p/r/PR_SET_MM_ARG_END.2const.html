PR_SET_MM_ARG_START(2const) PR_SET_MM_ARG_START(2const)

NOM

PR_SET_MM_ARG_START, PR_SET_MM_ARG_END, PR_SET_MM_ENV_START, PR_SET_MM_ENV_END - modifier les champs du descripteur de carte mémoire du noyau

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <linux/prctl.h>  /* Définition des constantes PR_* */
#include <sys/prctl.h>
int prctl(PR_SET_MM, PR_SET_MM_ARG_START, unsigned long addr, 0L, 0L);
int prctl(PR_SET_MM, PR_SET_MM_ARG_END, unsigned long addr, 0L, 0L);
int prctl(PR_SET_MM, PR_SET_MM_ENV_START, unsigned long addr, 0L, 0L);
int prctl(PR_SET_MM, PR_SET_MM_ENV_END, unsigned long addr, 0L, 0L);

DESCRIPTION

PR_SET_MM_ARG_START
Définit l'adresse au-dessus de laquelle la ligne de commande du programme est placée.
PR_SET_MM_ARG_END
Définit l'adresse en dessous de laquelle la ligne de commande du programme est placée.
PR_SET_MM_ENV_START
Définit l'adresse au-dessus de laquelle l'environnement du programme est placé.
PR_SET_MM_ENV_END
Définit l'adresse en dessous de laquelle l'environnement du programme est placé.

L'adresse passée avec ces appels doit appartenir à une zone de pile du processus. Ainsi, la zone mémoire correspondante doit être lisible, modifiable et (selon la configuration du noyau) avoir l'attribut MAP_GROWSDOWN défini (voir mmap(2)).

VALEUR DE RETOUR

En cas de succès, 0 est retourné. En cas d'erreur, -1 est retourné, et errno est défini pour indiquer l'erreur.

ERREURS

EINVAL
addr est supérieur à TASK_SIZE (la limite de la taille de l'espace d'adressage utilisateur pour cette architecture).

NORMES

Linux.

HISTORIQUE

Linux 3.5.

VOIR AUSSI

prctl(2), PR_SET_MM(2const)
