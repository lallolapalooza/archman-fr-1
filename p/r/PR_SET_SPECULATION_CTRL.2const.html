PR_SET_SPECULATION_CTRL(2const) PR_SET_SPECULATION_CTRL(2const)

NOM

PR_SET_SPECULATION_CTRL - définir l'état d'un mauvais comportement de spéculation pour le thread appelant

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <linux/prctl.h>  /* Définition des constantes PR_* */
#include <sys/prctl.h>
int prctl(PR_SET_SPECULATION_CTRL, long misfeature, long val, 0L, 0L);

DESCRIPTION

Définit l'état du mauvais comportement de spéculation spécifié dans misfeature. Les paramètres de spéculation-mauvais comportement sont des attributs par thread.

Actuellement, misfeature doit être l'un des suivants :

PR_SPEC_STORE_BYPASS
Définit l'état du mauvais comportement de spéculation de contournement de stockage.
PR_SPEC_INDIRECT_BRANCH (depuis Linux 4.20)
Définit l'état du mauvais comportement de spéculation de branche indirecte.

L'argument val est utilisé pour fournir la valeur de contrôle, qui est l'une des suivantes :

PR_SPEC_ENABLE
La fonctionnalité de spéculation est activée, l'atténuation est désactivée.
PR_SPEC_DISABLE
La fonctionnalité de spéculation est désactivée, l'atténuation est activée.
PR_SPEC_FORCE_DISABLE
Identique à PR_SPEC_DISABLE, mais ne peut pas être annulé.
PR_SPEC_DISABLE_NOEXEC (depuis Linux 5.1)
Identique à PR_SPEC_DISABLE, mais l'état sera effacé lors de execve(2). Actuellement, uniquement pris en charge pour PR_SPEC_STORE_BYPASS.

La fonctionnalité de spéculation peut également être contrôlée par le paramètre de démarrage spec_store_bypass_disable. Ce paramètre peut imposer une politique en lecture seule, ce qui entraînera l'échec de l'appel prctl() avec l'erreur ENXIO. Pour plus de détails, consultez le fichier source du noyau Documentation/admin-guide/kernel-parameters.txt.

VALEUR DE RETOUR

En cas de succès, 0 est renvoyé. En cas d'erreur, -1 est renvoyé et errno est défini pour indiquer l'erreur.

ERREURS

ENODEV
Le noyau ou le CPU ne prend pas en charge le mauvais comportement de spéculation demandé.
ENXIO
Le contrôle du mauvais comportement de spéculation sélectionné n'est pas possible. Voir PR_GET_SPECULATION_CTRL pour les champs binaires permettant de déterminer quelle option est disponible.
EPERM
La spéculation a été désactivée avec PR_SPEC_FORCE_DISABLE et l'appelant a tenté de la réactiver.
ERANGE
misfeature n'est pas une valeur valide.

NORMES

Linux.

HISTORIQUE

Linux 4.17.

VOIR AUSSI

prctl(2), PR_GET_SPECULATION_CTRL(2const)
