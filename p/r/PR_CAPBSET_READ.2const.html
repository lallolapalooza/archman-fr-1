PR_CAPBSET_READ(2const) PR_CAPBSET_READ(2const)

NOM

PR_CAPBSET_READ - lire l'ensemble de limites de capacités du fil d'exécution appelant

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <linux/prctl.h>  /* Définition des constantes PR_* */
#include <sys/prctl.h>
int prctl(PR_CAPBSET_READ, long cap);

DESCRIPTION

Retourne 1 si la capacité spécifiée dans cap se trouve dans l'ensemble de limites de capacités du fil d'exécution appelant, ou 0 si ce n'est pas le cas.

Les constantes de capacité sont définies dans <linux/capability.h>.

L'ensemble de limites de capacités détermine si le processus peut recevoir la capacité via l'ensemble de capacités autorisées d'un fichier lors d'un appel ultérieur à execve(2).

VALEUR DE RETOUR

En cas de succès, cet appel retourne la valeur booléenne décrite ci-dessus. En cas d'erreur, -1 est retourné et errno est défini pour indiquer l'erreur.

ERREURS

EINVAL
cap ne spécifie pas une capacité valide.

VERSIONS

Une interface de plus haut niveau basée sur cette opération est fournie dans la bibliothèque libcap(3) sous la forme de cap_get_bound(3).

NORMES

Linux.

HISTORIQUE

Linux 2.6.25.

VOIR AUSSI

prctl(2), PR_CAPBSET_DROP(2const), libcap(3), cap_get_bound(3)
