PR_SET_TIMERSLACK(2const) PR_SET_TIMERSLACK(2const)

NOM

PR_SET_TIMERSLACK - définir la valeur de "slack" des timers « courants » pour le thread appelant

BIBLIOTHQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <linux/prctl.h>  /* Définition des constantes PR_* */
#include <sys/prctl.h>
int prctl(PR_SET_TIMERSLACK, unsigned long slack);

DESCRIPTION

Chaque thread a deux valeurs associées de slack de timer : une valeur par « défaut » et une valeur « courante ». Cette opération définit la valeur de slack de timer « courante » pour le thread appelant. slack est une valeur `unsigned long` dans l'intervalle [1L, ULONG_MAX]. Si la valeur en nanosecondes fournie dans slack est supérieure à zéro, la valeur « courante » est définie à cette valeur. Si slack est 0L, le slack de timer « courant » est réinitialisé à la valeur de slack de timer « par défaut » du thread.

Le slack de timer « courant » est utilisé par le noyau pour regrouper les expirations de timer pour le thread appelant qui sont proches les unes des autres ; en conséquence, les expirations de timer pour le thread peuvent être en retard jusqu'au nombre de nanosecondes spécifié (mais n'expireront jamais en avance). Le regroupement des expirations de timer peut aider à réduire la consommation d'énergie du système en minimisant les réveils du CPU.

Les expirations de timer affectées par le slack de timer sont celles définies par select(2), pselect(2), poll(2), ppoll(2), epoll_wait(2), epoll_pwait(2), clock_nanosleep(2), nanosleep(2) et futex(2) (et donc les fonctions de bibliothèque implémentées via futex, y compris pthread_cond_timedwait(3), pthread_mutex_timedlock(3), pthread_rwlock_timedrdlock(3), pthread_rwlock_timedwrlock(3) et sem_timedwait(3)).

Le slack de timer ne s'applique pas aux threads qui sont planifiés sous une politique d'ordonnancement temps réel (voir sched_setscheduler(2)).

Lorsqu'un nouveau thread est créé, les deux valeurs de slack de timer sont faites identiques à la valeur « courante » du thread créateur. Par la suite, un thread peut ajuster sa valeur de slack de timer « courante » via PR_SET_TIMERSLACK. La valeur « par défaut » ne peut pas être modifiée. Les valeurs de slack de timer de init (PID 1), l'ancêtre de tous les processus, sont de 50 000 nanosecondes (50 microsecondes). La valeur de slack de timer est héritée par un enfant créé via fork(2) et est préservée lors d'un execve(2).

VALEUR DE RETOUR

En cas de succès, 0 est retourné. En cas d'erreur, -1 est retourné et errno est défini pour indiquer l'erreur.

FICHIERS

/proc/pid/timerslack_ns
Depuis Linux 4.6, la valeur de slack de timer « courante » de n'importe quel processus peut être examinée et modifiée via ce fichier.

NORMES

Linux.

HISTORIQUE

Linux 2.6.28.

VOIR AUSSI

prctl(2), PR_GET_TIMERSLACK(2const), proc_pid_timerslack_ns(5)
