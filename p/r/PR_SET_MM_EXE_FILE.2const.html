PR_SET_MM_EXE_FILE(2const) PR_SET_MM_EXE_FILE(2const)

NOM

PR_SET_MM_EXE_FILE - modifier les champs du descripteur de la carte mémoire du noyau

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <linux/prctl.h>  /* Définition des constantes PR_* */
#include <sys/prctl.h>
int prctl(PR_SET_MM, PR_SET_MM_EXE_FILE, long fd, 0L, 0L);

DESCRIPTION

Remplace le lien symbolique /proc/pid/exe par un nouveau pointant vers un nouveau fichier exécutable identifié par le descripteur de fichier fourni dans l'argument fd. Le descripteur de fichier doit être obtenu avec un appel open(2) régulier.

Pour changer le lien symbolique, il faut démapper toutes les zones mémoire exécutables existantes, y compris celles créées par le noyau lui-même (par exemple, le noyau crée généralement au moins une zone mémoire exécutable pour la section .text de l'ELF).

VALEUR DE RETOUR

En cas de succès, 0 est retourné. En cas d'erreur, -1 est retourné, et errno est défini pour indiquer l'erreur.

ERREURS

EACCES
Le fichier n'est pas exécutable.
EBADF
Le descripteur de fichier passé dans fd n'est pas valide.
EBUSY
Il s'agit de la deuxième tentative de modification du lien symbolique /proc/pid/exe.

FICHIERS

/proc/pid/exe

NORMES

Linux.

HISTORIQUE

Linux 3.5.

Dans Linux 4.9 et versions antérieures, l'opération PR_SET_MM_EXE_FILE ne pouvait être effectuée qu'une seule fois dans la vie d'un processus ; tenter d'effectuer l'opération une deuxième fois entraînait l'erreur EPERM. Cette restriction était appliquée pour des raisons de sécurité qui ont été jugées fallacieuses par la suite, et la restriction a été supprimée dans Linux 4.10 car certaines applications en espace utilisateur devaient effectuer cette opération plus d'une fois.

VOIR AUSSI

prctl(2), PR_SET_MM(2const), proc_pid_exe(5)
