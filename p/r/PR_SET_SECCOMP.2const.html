PR_SET_SECCOMP(2const) PR_SET_SECCOMP(2const)

NOM

PR_SET_SECCOMP - définir le mode de calcul sécurisé (seccomp)

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <linux/prctl.h>  /* Définition des constantes PR_* */
#include <sys/prctl.h>
[[deprecated]]
int prctl(PR_SET_SECCOMP, long mode, ...);
[[deprecated]]
int prctl(PR_SET_SECCOMP, SECCOMP_MODE_STRICT);
[[deprecated]]
int prctl(PR_SET_SECCOMP, SECCOMP_MODE_FILTER,
          struct sock_fprog *filter);

DESCRIPTION

Définit le mode de calcul sécurisé (seccomp) pour le thread appelant, afin de limiter les appels système disponibles. L'appel système plus récent seccomp(2) fournit un sur-ensemble des fonctionnalités de PR_SET_SECCOMP, et constitue l'interface préférée pour les nouvelles applications.

Le mode seccomp est sélectionné via mode. Les constantes seccomp sont définies dans <linux/seccomp.h>. Les valeurs suivantes peuvent être spécifiées :

SECCOMP_MODE_STRICT (depuis Linux 2.6.23)
Voir la description de SECCOMP_SET_MODE_STRICT dans seccomp(2).
Cette opération n'est disponible que si le noyau est configuré avec CONFIG_SECCOMP activé.
SECCOMP_MODE_FILTER (depuis Linux 3.5)
Les appels système autorisés sont définis par un pointeur vers un filtre Berkeley Packet Filter (BPF) passé dans filter. Il peut être conçu pour filtrer des appels système et des arguments d'appels système arbitraires. Voir la description de SECCOMP_SET_MODE_FILTER dans seccomp(2).
Cette opération n'est disponible que si le noyau est configuré avec CONFIG_SECCOMP_FILTER activé.

VALEUR DE RETOUR

En cas de succès, 0 est retourné. En cas d'erreur, -1 est retourné, et errno est défini pour indiquer l'erreur.

ERREURS

EACCES
mode est SECCOMP_MODE_FILTER, mais le processus ne possède pas la capacité CAP_SYS_ADMIN ou n'a pas défini l'attribut no_new_privs (voir PR_SET_NO_NEW_PRIVS(2const)).
EFAULT
mode est SECCOMP_MODE_FILTER, et filter est une adresse invalide.
EINVAL
mode n'est pas une valeur valide.
EINVAL
Le noyau n'a pas été configuré avec CONFIG_SECCOMP.
EINVAL
mode est SECCOMP_MODE_FILTER, et le noyau n'a pas été configuré avec CONFIG_SECCOMP_FILTER.

NORMES

Linux.

HISTORIQUE

Linux 2.6.23.

VOIR AUSSI

prctl(2), PR_GET_SECCOMP(2const), seccomp(2)
