PR_SET_VMA(2const) PR_SET_VMA(2const)

NOM

PR_SET_VMA - définir un attribut pour les zones de mémoire virtuelle

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNOPSIS

#include <linux/prctl.h>  /* Définitions des constantes PR_* */
#include <sys/prctl.h>
int prctl(PR_SET_VMA, long attr, unsigned long addr, unsigned long size,
          const char *_Nullable val);

DESCRIPTION

Définit un attribut spécifié dans attr pour les zones de mémoire virtuelle commençant à l'adresse spécifiée dans addr et s'étendant sur la taille spécifiée dans size. val spécifie la valeur de l'attribut à définir.

Notez que l'assignation d'un attribut à une zone de mémoire virtuelle pourrait l'empêcher d'être fusionnée avec des zones de mémoire virtuelle adjacentes en raison de la différence de valeur de cet attribut.

Actuellement, attr doit être l'une des valeurs suivantes :

PR_SET_VMA_ANON_NAME
Définit un nom pour les zones de mémoire virtuelle anonymes. val doit être un pointeur vers une chaîne terminée par null contenant le nom. La longueur du nom, y compris le caractère nul, ne peut pas dépasser 80 octets. Si val est NULL, le nom des zones de mémoire virtuelle anonymes appropriées sera réinitialisé. Le nom ne peut contenir que des caractères ASCII imprimables (isprint(3)), sauf '[', ']', '\', '$', et '`'.

VALEUR DE RETOUR

En cas de succès, 0 est retourné. En cas d'erreur, -1 est retourné, et errno est défini pour indiquer l'erreur.

ERREURS

EINVAL
attr n'est pas un attribut valide.
EINVAL
addr est une adresse invalide.

NORMES

Linux.

HISTORIQUE

Linux 5.17.

VOIR AUSSI
