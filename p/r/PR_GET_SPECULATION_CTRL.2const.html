PR_GET_SPECULATION_CTRL(2const) PR_GET_SPECULATION_CTRL(2const)

NOM

PR_GET_SPECULATION_CTRL - obtenir l'état d'une anomalie de spéculation pour le thread appelant

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <linux/prctl.h>  /* Définition des constantes PR_* */
#include <sys/prctl.h>
int prctl(PR_GET_SPECULATION_CTRL, long misfeature, 0L, 0L, 0L);

DESCRIPTION

Retourne l'état de l'anomalie de spéculation spécifiée par misfeature.

Actuellement, misfeature doit être l'une des valeurs suivantes :

PR_SPEC_STORE_BYPASS
Obtenir l'état de l'anomalie de contournement de stockage spéculatif.
PR_SPEC_INDIRECT_BRANCH (depuis Linux 4.20)
Obtenir l'état de l'anomalie de spéculation de branche indirecte.

La valeur de retour utilise les bits 0 à 4 avec la signification suivante :

PR_SPEC_PRCTL
La mitigation peut être contrôlée par thread via PR_SET_SPECULATION_CTRL(2const).
PR_SPEC_ENABLE
La fonctionnalité de spéculation est activée, la mitigation est désactivée.
PR_SPEC_DISABLE
La fonctionnalité de spéculation est désactivée, la mitigation est activée.
PR_SPEC_FORCE_DISABLE
Identique à PR_SPEC_DISABLE mais ne peut pas être annulé.
PR_SPEC_DISABLE_NOEXEC (depuis Linux 5.1)
Identique à PR_SPEC_DISABLE, mais l'état sera effacé lors de execve(2).

Si tous les bits sont à 0, alors le CPU n'est pas affecté par l'anomalie de spéculation.

Si PR_SPEC_PRCTL est défini, alors le contrôle par thread de la mitigation est disponible. Si ce n'est pas défini, PR_SET_SPECULATION_CTRL(2const) pour l'anomalie de spéculation échouera.

VALEUR DE RETOUR

En cas de succès, PR_GET_SPECULATION_CTRL renvoie la valeur non négative décrite ci-dessus. En cas d'erreur, -1 est retourné et errno est défini pour indiquer l'erreur.

ERREURS

ENODEV
Le noyau ou le CPU ne prend pas en charge l'anomalie de spéculation demandée.

NORMES

Linux.

HISTORIQUE

Linux 4.17.

VOIR AUSSI

prctl(2), PR_SET_SPECULATION_CTRL(2const)
