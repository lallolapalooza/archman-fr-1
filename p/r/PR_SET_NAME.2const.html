PR_SET_NAME(2const) PR_SET_NAME(2const)

NOM

PR_SET_NAME, PR_GET_NAME - opérations sur un processus ou un thread

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNOPIS

#include <linux/prctl.h>  /* Définition des constantes PR_* */
#include <sys/prctl.h>
int prctl(PR_SET_NAME, char name[16]);
int prctl(PR_GET_NAME, const char name[16]);

DESCRIPTION

PR_SET_NAME
Définit le nom du thread appelant, en utilisant la valeur à l'emplacement pointé par name.
Le nom peut contenir jusqu'à 16 octets, y compris le caractère nul de fin. Si la longueur de la chaîne, y compris le caractère nul de fin, dépasse 16 octets, la chaîne est tronquée silencieusement.
PR_GET_NAME (depuis Linux 2.6.11)
Récupère le nom du thread appelant, dans le tampon pointé par name. La chaîne retournée sera terminée par un caractère nul.

C'est le même attribut qui peut être défini via pthread_setname_np(3) et récupéré via pthread_getname_np(3).

VALEUR RENVOYÉE

En cas de succès, 0 est renvoyé. En cas d'erreur, -1 est renvoyé et errno est défini pour indiquer l'erreur.

ERREURS

EFAULT
name est une adresse invalide.

FICHIERS

/proc/self/task/tid/comm
L'attribut est également accessible via ce fichier (voir proc_pid_comm(5)), où tid est l'ID du thread appelant, tel que renvoyé par gettid(2).

NORMES

Linux.

HISTORIQUE

PR_SET_NAME
Linux 2.6.9.
PR_GET_NAME
Linux 2.6.11.

VOIR AUSSI

prctl(2), pthread_setname_np(3), pthread_getname_np(3), proc_pid_comm(5)
