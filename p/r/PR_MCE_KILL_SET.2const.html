PR_MCE_KILL_SET(2const) PR_MCE_KILL_SET(2const)

NOM

PR_MCE_KILL_SET - définir la politique d'arrêt pour la corruption de mémoire de vérification de machine

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <linux/prctl.h>  /* Définition des constantes PR_* */
#include <sys/prctl.h>
int prctl(PR_MCE_KILL, PR_MCE_KILL_SET, long pol, 0L, 0L);

DESCRIPTION

Utiliser une politique d'arrêt spécifique au thread pour la corruption de mémoire.

pol définit si la politique est un arrêt précoce (PR_MCE_KILL_EARLY), un arrêt tardif (PR_MCE_KILL_LATE), ou la valeur par défaut à l'échelle du système (PR_MCE_KILL_DEFAULT).

L'arrêt précoce signifie que le thread reçoit un signal SIGBUS dès qu'une corruption de mémoire matérielle est détectée dans son espace d'adressage.

En mode d'arrêt tardif, le processus n'est arrêté que lorsqu'il accède à une page corrompue. Voir sigaction(2) pour plus d'informations sur le signal SIGBUS.

VALEUR DE RETOUR

En cas de succès, 0 est retourné. En cas d'erreur, -1 est retourné et errno est définie pour indiquer l'erreur.

ERREURS

EINVAL
pol n'est pas une valeur valide.

NORMES

Linux.

HISTORIQUE

Linux 2.6.32.

VOIR AUSSI

prctl(2), PR_MCE_KILL(2const)
