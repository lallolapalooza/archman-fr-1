PR_SET_MM_MAP(2const) PR_SET_MM_MAP(2const)

NOM

PR_SET_MM_MAP, PR_SET_MM_MAP_SIZE - modifier les champs du descripteur de la carte mémoire du noyau

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <linux/prctl.h>  /* Définition des constantes PR_* */
#include <sys/prctl.h>
int prctl(PR_SET_MM, PR_SET_MM_MAP,
          struct prctl_mm_map *map, unsigned long size, 0L);
int prctl(PR_SET_MM, PR_SET_MM_MAP_SIZE, unsigned int *size, 0L, 0L);

DESCRIPTION

PR_SET_MM_MAP
Fournit un accès unique à toutes les adresses modifiables avec PR_SET_MM(2const) en passant une struct prctl_mm_map (telle que définie dans <linux/prctl.h>). L'argument size doit fournir la taille de la structure.
PR_SET_MM_MAP_SIZE
Retourne (via l'argument size) la taille de la struct prctl_mm_map attendue par le noyau. Ceci permet à l'espace utilisateur de trouver une structure compatible.

Ces fonctionnalités ne sont disponibles que si le noyau est compilé avec l'option CONFIG_CHECKPOINT_RESTORE activée.

VALEUR RETOURNÉE

En cas de succès, 0 est retourné. En cas d'erreur, -1 est retourné, et errno est définie pour indiquer l'erreur.

ERREURS

EINVAL
Le troisième argument est une adresse invalide.

NORMES

Linux.

HISTORIQUE

Linux 3.18.
