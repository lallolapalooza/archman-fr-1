PR_PAC_RESET_KEYS(2const) PR_PAC_RESET_KEYS(2const)

NOM

PR_PAC_RESET_KEYS - réinitialise les clés de code d'authentification de pointeur du thread appelant

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <linux/prctl.h>  /* Définition des constantes PR_* */
#include <sys/prctl.h>
int prctl(PR_PAC_RESET_KEYS, unsigned long keys, 0L, 0L, 0L);

DESCRIPTION

Réinitialise en toute sécurité les clés d'authentification de pointeur du thread à de nouvelles valeurs aléatoires générées par le noyau.

L'ensemble des clés à réinitialiser est spécifié par keys, qui doit être un OR logique de zéro ou plusieurs des éléments suivants :

PR_PAC_APIAKEY
clé d'authentification d'instruction A
PR_PAC_APIBKEY
clé d'authentification d'instruction B
PR_PAC_APDAKEY
clé d'authentification de données A
PR_PAC_APDBKEY
clé d'authentification de données B
PR_PAC_APGAKEY
clé d'authentification générique « A ».
(Oui, il n'y a vraiment pas de clé B générique.)

Dans le cas spécial, si keys est zéro, alors toutes les clés sont réinitialisées. Étant donné que de nouvelles clés pourraient être ajoutées dans le futur, c'est la manière recommandée d'effacer complètement les clés existantes lors de l'établissement d'un contexte d'exécution propre.

Il n'est pas nécessaire d'utiliser PR_PAC_RESET_KEYS en préparation d'un appel à execve(2), car execve(2) réinitialise toutes les clés d'authentification de pointeur.

VALEUR RENVOYÉE

En cas de succès, 0 est renvoyé. En cas d'erreur, -1 est renvoyé et errno est défini pour indiquer l'erreur.

ERREURS

EINVAL
keys contient des bits définis qui sont invalides ou non pris en charge sur cette plateforme.

NORMES

Linux. arm64 uniquement.

HISTORIQUE

Linux 5.0 (arm64).

AVERTISSEMENTS

Étant donné que le compilateur ou l'environnement d'exécution peut utiliser certaines ou toutes les clés, un appel réussi à PR_PAC_RESET_KEYS peut faire planter le processus appelant. Les conditions pour l'utiliser en toute sécurité sont complexes et dépendantes du système. Ne l'utilisez pas à moins de savoir ce que vous faites.

VOIR AUSSI

prctl(2)

Pour plus d'informations, consultez le fichier source du noyau Documentation/arm64/pointer-authentication.rst (ou Documentation/arm64/pointer-authentication.txt avant Linux 5.3).
