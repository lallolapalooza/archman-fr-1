NOM

Proc::Killfam - tuer une liste de pids, ainsi que tous leurs sous-processus

SYNTAXE

use Proc::Killfam;
killfam $signal, @pids;

DESCRIPTION

killfam accepte les mêmes arguments que la fonction intégrée Perl kill, mais, en plus, recherche récursivement dans la table des processus les enfants et les tue également.

EXEMPLE

killfam 'TERM', ($pid1, $pid2, @more_pids);

MOTS-CLÉS

kill, signal
