Module Slot

Depuis 4.02

type t = Printexc.backtrace_slot

val is_raise : t -> bool

is_raise slot est true lorsque slot fait référence à un point de levée dans le code, et false lorsqu'il provient d'un appel de fonction simple.

Depuis 4.02

val is_inline : t -> bool

is_inline slot est true lorsque slot fait référence à un appel qui a été intégré par le compilateur, et false lorsqu'il provient de tout autre contexte.

Depuis 4.04

val location : t -> Printexc.location option

location slot renvoie les informations de localisation de la cellule, si elles sont disponibles, et None sinon.

Certaines raisons possibles pour lesquelles la localisation ne peut pas être renvoyée sont les suivantes :

- la cellule correspond à une levée insérée par le compilateur

- la cellule correspond à une partie du programme qui n'a pas été compilée avec des informations de débogage ( -g )

Depuis 4.02

val name : t -> string option

name slot renvoie le nom de la fonction ou de la définition englobant la localisation à laquelle la cellule fait référence.

name slot renvoie None si le nom n'est pas disponible, ce qui peut se produire pour les mêmes raisons que location renvoyant None.

Depuis 4.11

val format : int -> t -> string option

format pos slot renvoie la représentation sous forme de chaîne de caractères de slot telle que raw_backtrace_to_string la formaterait, en supposant qu'il s'agit du pos -ième élément de la trace : le 0 -ième élément est rendu de manière plus jolie que les autres.

Les fonctions d'impression de trace complète ignorent également certaines cellules peu informatives ; dans ce cas, format pos slot renvoie None.
