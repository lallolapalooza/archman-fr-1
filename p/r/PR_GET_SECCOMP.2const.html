PR_GET_SECCOMP(2) Manuel des appels système PR_GET_SECCOMP(2)

NOM

PR_GET_SECCOMP - obtenir le mode de calcul sécurisé

BIBLIOTHQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <linux/prctl.h>  /* Définition des constantes PR_* */
#include <sys/prctl.h>
int prctl(PR_GET_SECCOMP);

DESCRIPTION

Retourne le mode de calcul sécurisé du thread appelant.

Si l'appelant n'est pas en mode calcul sécurisé, cette opération retourne 0 ; si l'appelant est en mode calcul sécurisé strict, alors l'appel prctl() provoquera l'envoi d'un signal SIGKILL au processus. Si l'appelant est en mode filtre, et que cet appel système est autorisé par les filtres seccomp, il retourne 2 ; sinon, le processus est tué avec un signal SIGKILL.

Cette opération n'est disponible que si le noyau est configuré avec CONFIG_SECCOMP activé.

VALEUR DE RETOUR

En cas de succès, cet appel retourne la valeur non négative décrite ci-dessus. En cas d'erreur, -1 est retourné, et errno est défini pour indiquer l'erreur ; ou le processus est tué.

ERREURS

EINVAL
Le noyau n'a pas été configuré avec CONFIG_SECCOMP.
SIGKILL
L'appelant est en mode calcul sécurisé strict.
SIGKILL
L'appelant est en mode filtre, et cet appel système n'est pas autorisé par les filtres seccomp.

FICHIERS

/proc/pid/status
Depuis Linux 3.8, le champ Seccomp de ce fichier fournit une méthode pour obtenir les mêmes informations, sans le risque que le processus soit tué ; voir proc_pid_status(5).

NORMES

Linux.

HISTORIQUE

Linux 2.6.23.

VOIR AUSSI

prctl(2), PR_SET_SECCOMP(2const), seccomp(2)
