PR_SVE_SET_VL(2const) PR_SVE_SET_VL(2const)

NOM

PR_SVE_SET_VL - définit la longueur du vecteur SVE du thread

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNOPSIS

#include <linux/prctl.h>  /* Définition des constantes PR_* */
#include <sys/prctl.h>
int prctl(PR_SVE_SET_VL, unsigned long val);

DESCRIPTION

Configure la longueur du vecteur SVE du thread, telle que spécifiée par val.

Les bits de val correspondant à PR_SVE_VL_LEN_MASK doivent être définis à la longueur de vecteur désirée en octets. Ceci est interprété comme une limite supérieure : le noyau choisira la plus grande longueur de vecteur disponible qui ne dépasse pas la valeur spécifiée. En particulier, spécifier SVE_VL_MAX (défini dans <asm/sigcontext.h>) pour les bits PR_SVE_VL_LEN_MASK demande la longueur de vecteur maximale supportée.

En outre, les autres bits de val doivent être définis sur l'une des combinaisons de drapeaux suivantes :

0L
Effectuer le changement immédiatement. Lors du prochain execve(2) dans le thread, la longueur du vecteur sera réinitialisée à la valeur configurée dans /proc/sys/abi/sve_default_vector_length.
PR_SVE_VL_INHERIT
Effectuer le changement immédiatement. Les appels execve(2) ultérieurs préserveront la nouvelle longueur du vecteur.
PR_SVE_SET_VL_ONEXEC
Reporter le changement, afin qu'il soit effectué lors du prochain execve(2) dans le thread. D'autres appels execve(2) réinitialiseront la longueur du vecteur à la valeur configurée dans /proc/sys/abi/sve_default_vector_length.
PR_SVE_SET_VL_ONEXEC | PR_SVE_VL_INHERIT
Reporter le changement, afin qu'il soit effectué lors du prochain execve(2) dans le thread. D'autres appels execve(2) préserveront la nouvelle longueur du vecteur.

Dans tous les cas, tout changement différé précédemment en attente est annulé.

En cas de succès, une valeur non négative est retournée, qui décrit la configuration *sélectionnée*. Si PR_SVE_SET_VL_ONEXEC était inclus dans val, alors la configuration décrite par la valeur de retour prendra effet lors du prochain execve(2). Sinon, la configuration est déjà en vigueur lorsque l'appel PR_SVE_SET_VL retourne. Dans les deux cas, la valeur est encodée de la même manière que la valeur de retour de PR_SVE_GET_VL. Notez qu'il n'y a pas de drapeau explicite dans la valeur de retour correspondant à PR_SVE_SET_VL_ONEXEC.

La configuration (y compris tout changement différé en attente) est héritée lors des appels à fork(2) et clone(2).

VALEUR DE RETOUR

En cas de succès, PR_SVE_SET_VL retourne la valeur non négative décrite ci-dessus. En cas d'erreur, -1 est retourné et errno est défini pour indiquer l'erreur.

ERREURS

EINVAL
SVE n'est pas disponible sur cette plateforme.
EINVAL
La valeur dans les bits de val correspondant à PR_SVE_VL_LEN_MASK est en dehors de la plage [SVE_VL_MIN, SVE_VL_MAX] ou n'est pas un multiple de 16.
EINVAL
Les autres bits de val sont invalides ou non supportés.

FICHIERS

/proc/sys/abi/sve_default_vector_length

NORMES

Linux. arm64 uniquement.

HISTORIQUE

Linux 4.15 (arm64).

ATTENTION

Étant donné que le compilateur ou l'environnement d'exécution peut utiliser SVE, l'utilisation de cet appel sans le drapeau PR_SVE_SET_VL_ONEXEC peut faire planter le processus appelant. Les conditions pour l'utiliser en toute sécurité sont complexes et dépendent du système. Ne l'utilisez pas à moins de savoir vraiment ce que vous faites.

VOIR AUSSI
