PR_SET_IO_FLUSHER(2const) PR_SET_IO_FLUSHER(2const)

NOM

PR_SET_IO_FLUSHER - changer l'état IO_FLUSHER

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNOPSIS

#include <linux/prctl.h>  /* Définition des constantes PR_* */
#include <sys/prctl.h>
int prctl(PR_SET_IO_FLUSHER, long state, 0L, 0L, 0L);

DESCRIPTION

Si un processus utilisateur est impliqué dans la pile d'E/S du bloc ou du système de fichiers, et peut allouer de la mémoire lors du traitement des requêtes d'E/S, il doit définir state sur 1. Cela placera le processus dans l'état IO_FLUSHER, ce qui lui permettra un traitement spécial pour progresser lors de l'allocation de mémoire. Si state est 0, le processus effacera l'état IO_FLUSHER, et le comportement par défaut sera utilisé.

Le processus appelant doit posséder la capacité CAP_SYS_RESOURCE.

L'état IO_FLUSHER est hérité par un processus enfant créé via fork(2) et est préservé lors de execve(2).

Les exemples d'applications IO_FLUSHER sont les démons FUSE, les démons d'émulation de périphériques SCSI, et les démons qui effectuent la gestion des erreurs comme les applications de récupération de chemin multipath.

VALEUR RENVOYÉE

En cas de succès, 0 est renvoyé. En cas d'erreur, -1 est renvoyé, et errno est défini pour indiquer l'erreur.

ERREURS

EINVAL
state n'est pas une valeur valide.

NORMES

Linux.

HISTORIQUE

Linux 5.6.

VOIR AUSSI

prctl(2), PR_GET_IO_FLUSHER(2const)
