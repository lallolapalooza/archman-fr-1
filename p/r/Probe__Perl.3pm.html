Paquet: perl-probe-perl

Probe::Perl(3) Documentation Perl fournie par l'utilisateur Probe::Perl(3)

NOM

Probe::Perl - Informations sur le perl en cours d'exécution

VERSION

version 0.03

SYNTAXE

use Probe::Perl;
$p = Probe::Perl->new();

# Version de ce perl sous forme de nombre à virgule flottante
$ver = $p->perl_version();
$ver = Probe::Perl->perl_version();

# Convertir une chaîne avec plusieurs points en un nombre à virgule flottante
$ver = $p->perl_version_to_float($ver);
$ver = Probe::Perl->perl_version_to_float($ver);

# Vérifier si le perl donné est le même que celui en cours d'exécution
$bool = $p->perl_is_same($perl_path);
$bool = Probe::Perl->perl_is_same($perl_path);

# Trouver le chemin vers l'interpréteur perl en cours d'exécution
$path = $p->find_perl_interpreter();
$path = Probe::Perl->find_perl_interpreter();

# Obtenir @INC avant les ajouts à l'exécution
@paths = $p->perl_inc();
@paths = Probe::Perl->perl_inc();

# Obtenir le type général du système d'exploitation
$type = $p->os_type();
$type = Probe::Perl->os_type();

# Accéder aux valeurs de Config.pm
$val = $p->config('foo');
$val = Probe::Perl->config('foo');
$p->config('foo' => 'bar');  # Définir localement
$p->config_revert('foo');  # Revenir

DESCRIPTION

Ce module fournit des méthodes pour obtenir des informations sur l'interpréteur perl en cours d'exécution. Il a initialement vu le jour dans le projet "Module::Build", mais a été externalisé ici pour une utilisation générale.

MÉTHODES

new()
Crée un nouvel objet Probe::Perl et le retourne. La plupart des méthodes des packages Probe::Perl sont disponibles en tant que méthodes de classe, vous n'avez donc pas toujours besoin de créer un nouvel objet. Mais si vous souhaitez créer une vue mutable des données de "Config.pm", il est nécessaire de créer un objet pour y stocker les valeurs.
config( $key [, $value] )
Retourne la valeur de "Config.pm" associée à $key. Si $value est également spécifié, alors la valeur est définie à $value pour cette vue des données. Dans ce cas, config() doit être appelée comme une méthode d'objet, pas comme une méthode de classe.
config_revert( $key )
Supprime toute valeur attribuée par l'utilisateur dans cette vue des données de "Config.pm".
find_perl_interpreter( )
Retourne le chemin absolu de cet interpréteur perl. C'est en fait une chose assez délicate à découvrir parfois - dans ces cas, nous utilisons perl_is_same() pour vérifier.
perl_version( )
Retourne la version de cet interpréteur perl sous forme de numéro de version de style perl en utilisant perl_version_to_float(). Utilise $^V si votre perl est suffisamment récent, sinon utilise $].
perl_version_to_float( $version )
Formate $version comme un numéro de version de style perl comme 5.008001.
perl_is_same( $perl )
Étant donné le nom d'un interpréteur perl, cette méthode détermine s'il a la même configuration que celui représenté par l'instance perl actuelle. Habituellement, cela signifie qu'il est exactement le même.
perl_inc( )
Retourne une liste de répertoires dans le chemin @INC de ce perl, *avant* que toutes les entrées de "use lib", $ENV{PERL5LIB}, ou les commutateurs "-I" ne soient ajoutées.
$Config{osname}.
