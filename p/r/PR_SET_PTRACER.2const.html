PR_SET_PTRACER(2const) PR_SET_PTRACER(2const)

NOM

PR_SET_PTRACER - autoriser les processus à ptrace(2) le processus appelant

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <linux/prctl.h>  /* Définition des constantes PR_* */
#include <sys/prctl.h>
int prctl(PR_SET_PTRACER, long pid);

DESCRIPTION

Ceci n'a de sens que si le LSM Yama est activé et en mode 1 ("ptrace restreint", visible via /proc/sys/kernel/yama/ptrace_scope).

Lorsqu'un "identifiant de processus ptraceur" est passé dans pid, l'appelant déclare que le processus ptraceur peut ptrace(2) le processus appelant comme s'il était un ancêtre direct du processus.

Chaque opération PR_SET_PTRACER remplace l'"identifiant de processus ptraceur" précédent.

L'utilisation de PR_SET_PTRACER avec pid défini sur 0 efface l'"identifiant de processus ptraceur" de l'appelant. Si pid est PR_SET_PTRACER_ANY, les restrictions de ptrace introduites par Yama sont effectivement désactivées pour le processus appelant.

VALEUR DE RETOUR

En cas de succès, 0 est retourné. En cas d'erreur, -1 est retourné et errno est défini pour indiquer l'erreur.

ERREURS

EINVAL
pid n'est ni 0, ni PR_SET_PTRACER_ANY, ni le PID d'un processus existant.

NORMES

Linux.

HISTORIQUE

Linux 3.4.

VOIR AUSSI

prctl(2),

Pour plus d'informations, voir le fichier source du noyau Documentation/admin-guide/LSM/Yama.rst (ou Documentation/security/Yama.txt avant Linux 4.13).
