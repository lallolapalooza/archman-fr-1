PR_GET_TID_ADDRESS(2const) PR_GET_TID_ADDRESS(2const)

NOM

PR_GET_TID_ADDRESS - obtenir l'adresse clear_child_tid

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <linux/prctl.h>  /* Définition des constantes PR_* */
#include <sys/prctl.h>
int prctl(PR_GET_TID_ADDRESS, int **addrp);

DESCRIPTION

Retourne l'adresse de clear_child_tid définie par set_tid_address(2) et le drapeau CLONE_CHILD_CLEARTID de clone(2), à l'emplacement pointé par addrp.

Cette fonctionnalité n'est disponible que si le noyau est compilé avec l'option CONFIG_CHECKPOINT_RESTORE activée.

VALEUR DE RETOUR

En cas de succès, 0 est retourné. En cas d'erreur, -1 est retourné, et errno est défini pour indiquer l'erreur.

ERREURS

EFAULT
addrp est une adresse invalide.

NORMES

Linux.

HISTORIQUE

Linux 3.5.

ATTENTION

Notez que comme l'appel système prctl() n'a pas d'implémentation de compatibilité pour les ABI AMD64 x32 et MIPS n32, et que le noyau écrit un pointeur en utilisant la taille de pointeur du noyau, cette opération attend une zone utilisateur de 8 octets (pas 4) sur ces ABI.

VOIR AUSSI

prctl(2)
