Fonctions de sortie formatée.

val fprintf : out_channel -> ('a, out_channel, unit) format -> 'a

fprintf outchan format arg1 ... argN formate les arguments arg1 à argN selon la chaîne de format format et les imprime sur le canal outchan.

La chaîne de format contient deux types d'éléments: des caractères normaux, qui sont copiés directement sur le canal de sortie, et des spécifications de conversion, chacune produisant la conversion et l'impression des arguments.

Les spécifications de conversion ont la forme suivante:

% [flags] [width] [.precision] type

En résumé, une spécification de conversion commence par le caractère %, suivi de modificateurs optionnels et d'un type composé d'un ou deux caractères.

Les types et leurs significations sont:

- d, i: convertir un argument entier en décimal signé. Le drapeau # ajoute des traits pour les grandes valeurs.

- u, n, l, L, ou N: convertir un argument entier en décimal non signé. Attention: n, l, L et N sont utilisés pour scanf et ne doivent pas être utilisés pour printf. Le drapeau # ajoute des traits pour les grandes valeurs.

- x: convertir un argument entier en hexadécimal non signé, en utilisant des lettres minuscules. Le drapeau # ajoute un préfixe 0x pour les valeurs non nulles.

- X: convertir un argument entier en hexadécimal non signé, en utilisant des lettres majuscules. Le drapeau # ajoute un préfixe 0X pour les valeurs non nulles.

- o: convertir un argument entier en octal non signé. Le drapeau # ajoute un préfixe 0 pour les valeurs non nulles.

- s: insérer un argument chaîne.

- S: convertir un argument chaîne en syntaxe OCaml (guillemets doubles, échappements).

- c: insérer un argument caractère.

- C: convertir un argument caractère en syntaxe OCaml (guillemets simples, échappements).

- f: convertir un argument flottant en notation décimale, style dddd.ddd.

- F: convertir un argument flottant en syntaxe OCaml (dddd. ou dddd.ddd ou d.ddd e+-dd). Convertit en hexadécimal avec le drapeau # (voir h).

- e ou E: convertir un argument flottant en notation décimale, style d.ddd e+-dd (partie fractionnaire et exposant).

- g ou G: convertir un argument flottant en notation décimale, style f ou e (selon ce qui est le plus compact). De plus, tous les zéros de la partie fractionnaire du résultat sont supprimés et la virgule décimale est supprimée s'il n'y a pas de partie fractionnaire dans le résultat.

- h ou H: convertir un argument flottant en notation hexadécimale, style 0xh.hhhh p+-dd (partie fractionnaire hexadécimale, exposant en décimal et représentant une puissance de 2).

- B: convertir un argument booléen en chaîne true ou false

- b: convertir un argument booléen (obsolète; ne pas utiliser dans de nouveaux programmes).

- ld, li, lu, lx, lX, lo: convertir un argument int32 dans la notation spécifiée par le second caractère (décimal, hexadécimal, etc.).

- nd, ni, nu, nx, nX, no: convertir un argument nativeint dans la notation spécifiée par le second caractère.

- Ld, Li, Lu, Lx, LX, Lo: convertir un argument int64 dans la notation spécifiée par le second caractère.

- a: imprimeur personnalisé. Prend deux arguments et applique le premier à outchan (canal de sortie courant) et le second. Le premier argument doit avoir le type out_channel -> 'b -> unit et le second 'b. Le résultat de la fonction est inséré dans la sortie de fprintf à l'endroit actuel.

- t: idem que %a, mais ne prend qu'un seul argument (type out_channel -> unit) et l'applique à outchan.

- { fmt %}: convertir une chaîne de format en son empreinte digitale. L'argument doit avoir le même type que la chaîne de format interne fmt.

- ( fmt %): substitution de chaîne de format. Prend un argument chaîne de format et substitue sa valeur dans la chaîne de format interne fmt pour imprimer les arguments suivants. L'argument doit avoir le même type que la chaîne de format interne fmt.

- !: ne prend aucun argument et force la sortie.

- %: ne prend aucun argument et imprime un caractère %.

- @: ne prend aucun argument et imprime un caractère @.

- ,: ne prend aucun argument et n'imprime rien: un délimiteur de conversion qui ne produit rien.

Les drapeaux optionnels sont:

- -: justifier à gauche (par défaut, c'est justifier à droite).

- 0: pour les conversions numériques, remplir avec des zéros au lieu d'espaces.

- +: pour les conversions numériques signées, ajouter un + à gauche si positif.

-espace: pour les conversions numériques signées, ajouter un espace à gauche si positif.

- #: demande un style de formatage alternatif pour les types entiers et le type flottant F.

La largeur dans width ou precision est un entier indiquant la largeur minimale du résultat. Par exemple, %6d imprime un entier, le préfixant avec des espaces pour remplir au moins 6 caractères.

Le nombre dans width ou precision peut également être spécifié comme *, auquel cas un argument supplémentaire est pris pour spécifier la width ou la precision correspondante. Cet argument entier précède immédiatement l'argument à imprimer. Par exemple, %.*f imprime un float avec autant de chiffres après la virgule que la valeur de l'argument précédant le float.

val printf : ('a, out_channel, unit) format -> 'a

Identique à Printf.fprintf, mais la sortie se fait sur stdout.

val eprintf : ('a, out_channel, unit) format -> 'a

Identique à Printf.fprintf, mais la sortie se fait sur stderr.

val sprintf : ('a, unit, string) format -> 'a

Identique à Printf.fprintf, mais au lieu d'imprimer sur un canal de sortie, renvoie une chaîne contenant le résultat du formatage des arguments.

val bprintf : Buffer.t -> ('a, Buffer.t, unit) format -> 'a

Identique à Printf.fprintf, mais au lieu d'imprimer sur un canal de sortie, ajoute les arguments formatés à un tampon extensible (voir le module Buffer).

val ifprintf : 'b -> ('a, 'b, 'c, unit) format4 -> 'a

Identique à Printf.fprintf, mais n'imprime rien. Utile pour ignorer certains contenus lors d'impressions conditionnelles.

val sprintf : ('a, Buffer.t, unit, string) format4 -> 'a

Same as Printf.bprintf, but returns the formatted string.

Since 3.02

val fprintf : out_channel -> ('a, out_channel, unit, unit) format4 -> 'a

Same as Printf.bprintf, but prints to the given output channel.

Since 3.02

val printf : ('a, out_channel, unit, unit) format4 -> 'a

Same as fprintf, but prints to stdout.

Since 3.02

val eprintf : ('a, out_channel, unit, unit) format4 -> 'a

Same as fprintf, but prints to stderr.

Since 3.02

val sfprintf : (string -> 'd) -> ('a, Buffer.t, unit, 'd) format4 -> 'a

Same as sprintf above, but instead of returning the string, passes it to the first argument.

Since 3.09

val kbprintf : (Buffer.t -> 'd) -> Buffer.t -> ('a, Buffer.t, unit, 'd) format4 -> 'a

Same as bprintf, but instead of returning immediately, passes the buffer to its first argument at the end of printing.

Since 3.10

val ikbprintf : (Buffer.t -> 'd) -> Buffer.t -> ('a, Buffer.t, unit, 'd) format4 -> 'a

Same as kbprintf above, but does not print anything. Useful to ignore some material when conditionally printing.

Since 4.11

Deprecated

val kprintf : (string -> 'b) -> ('a, unit, string, 'b) format4 -> 'a

Deprecated. Use Printf.ksprintf instead.

A deprecated synonym for ksprintf.
