PR_TASK_PERF_EVENTS_DISABLE(2const) PR_TASK_PERF_EVENTS_DISABLE(2const)

NOM

PR_TASK_PERF_EVENTS_DISABLE, PR_TASK_PERF_EVENTS_ENABLE - désactiver ou activer les compteurs de performance attachés au processus appelant

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <linux/prctl.h>  /* Définition des constantes PR_* */
#include <sys/prctl.h>
int prctl(PR_TASK_PERF_EVENTS_DISABLE);
int prctl(PR_TASK_PERF_EVENTS_ENABLE);

DESCRIPTION

PR_TASK_PERF_EVENTS_DISABLE
Désactive tous les compteurs de performance attachés au processus appelant, que ces compteurs aient été créés par ce processus ou par un autre. Les compteurs de performance créés par le processus appelant pour d'autres processus ne sont pas affectés.
PR_TASK_PERF_EVENTS_ENABLE
L'inverse de PR_TASK_PERF_EVENTS_DISABLE ; active les compteurs de performance attachés au processus appelant.

VALEUR DE RETOUR

En cas de succès, 0 est retourné. En cas d'erreur, -1 est retourné et errno est défini pour indiquer l'erreur.

NORMES

Linux.

HISTORIQUE

Linux 2.6.31.

Initialement nommés PR_TASK_PERF_COUNTERS_DISABLE et PR_TASK_PERF_COUNTERS_ENABLE ; renommés (en conservant la même valeur numérique) dans Linux 2.6.32.

VOIR AUSSI

prctl(2)

Pour plus d'informations sur les compteurs de performance, consultez le fichier source du noyau Linux tools/perf/design.txt.
