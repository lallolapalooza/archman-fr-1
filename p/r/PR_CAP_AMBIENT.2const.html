PR_CAP_AMBIENT(2const) PR_CAP_AMBIENT(2const)

NOM

PR_CAP_AMBIENT - lire ou modifier l'ensemble des capacités ambiantes du thread appelant

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <linux/prctl.h>  /* Définition des constantes PR_* */
#include <sys/prctl.h>
int prctl(PR_CAP_AMBIENT, long op, ...);

DESCRIPTION

Lit ou modifie l'ensemble des capacités ambiantes du thread appelant, selon la valeur de op, qui doit être l'une des suivantes :

PR_CAP_AMBIENT_RAISE
PR_CAP_AMBIENT_LOWER
PR_CAP_AMBIENT_IS_SET
PR_CAP_AMBIENT_CLEAR_ALL

VALEUR DE RETOUR

En cas de succès, une valeur non négative est retournée. En cas d'erreur, -1 est retourné et errno est défini pour indiquer l'erreur.

ERREURS

EINVAL
op n'est pas une valeur valide.

VERSIONS

Des interfaces de plus haut niveau, basées sur les opérations ci-dessus, sont fournies dans la bibliothèque libcap(3) sous la forme de cap_get_ambient(3), cap_set_ambient(3) et cap_reset_ambient(3).

NORMES

Linux.

HISTORIQUE

Linux 4.3.
