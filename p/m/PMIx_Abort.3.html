PMIx_Abort - Abort des processus spécifiés

SYNTAXE

#include <pmix.h>
pmix_status_t PMIx_Abort(int status, const char msg[],
                         pmix_proc_t procs[], size_t nprocs);

ARGUMENTS

  • status: Valeur de statut à retourner. Une valeur de zéro est permise par PMIx, mais peut ne pas être retournée par certains gestionnaires de ressources.
  • msg: Un message sous forme de chaîne de caractères à afficher.
  • procs: Un tableau de structures pmix_proc_t définissant les processus à arrêter. Un NULL pour le tableau de procs indique que tous les processus de l'espace de noms de l'appelant doivent être arrêtés. Une valeur joker pour le rang dans toute structure indique que tous les processus de cet espace de noms doivent être arrêtés.
  • nprocs: Nombre de structures pmix_proc_t dans le tableau procs.

DESCRIPTION

Demande l'arrêt des processus du tableau fourni, en retournant le statut fourni et en affichant le message fourni. Un NULL pour le tableau procs indique que tous les processus de l'espace de noms de l'appelant doivent être arrêtés.

La réponse à cette demande dépend dans une certaine mesure du gestionnaire de ressources spécifique et de sa configuration (par exemple, certains gestionnaires de ressources n'arrêteront pas l'application si le statut fourni est zéro, sauf configuration contraire), et sort donc du contrôle de PMIx lui-même. Cependant, le client informera le RM de la demande d'arrêt de l'application, quelle que soit la valeur du statut fourni.

Passer un paramètre msg NULL est autorisé. Notez que les conditions de concurrence causées par plusieurs processus appelant PMIx_Abort sont laissées à l'implémentation du serveur pour résoudre quel statut est retourné et quels messages (le cas échéant) sont affichés.

VALEUR DE RETOUR

Retourne PMIX_SUCCESS en cas de succès. En cas d'erreur, une valeur négative correspondant à un errno de PMIx est retournée.

ERREURS

Les valeurs errno de PMIx sont définies dans pmix_common.h.
