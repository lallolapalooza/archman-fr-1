PMIx_Finalize - Finaliser le client PMIx

SYNTAXE

#include <pmix.h>
pmix_status_t PMIx_Finalize(void);

DESCRIPTION

Finalise le client PMIx, fermant la connexion avec le serveur PMIx local.

VALEUR DE RETOUR

Retourne PMIX_SUCCESS en cas de succès. En cas d'erreur, une valeur négative correspondant à un errno de PMIx est retournée.

ERREURS

Les valeurs errno de PMIx sont définies dans pmix_common.h.
