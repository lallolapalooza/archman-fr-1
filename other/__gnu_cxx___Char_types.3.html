__gnu_cxx::_Char_types< _CharT > - Mappage du type de caractère aux types associés.

#include <char_traits.h>

DESCRIPTION DÉTAILLÉE

template<typename _CharT>

struct __gnu_cxx::_Char_types< _CharT >"Mappage du type de caractère aux types associés.

Note

C'est une classe d'implémentation pour la version générique de char_traits. Elle définit int_type, off_type, pos_type et state_type. Par défaut, ce sont unsigned long, streamoff, streampos et mbstate_t. Les utilisateurs qui ont besoin d'un ensemble de types différent, mais qui n'ont pas besoin de modifier les définitions des fonctions définies dans char_traits, peuvent spécialiser __gnu_cxx::_Char_types tout en laissant __gnu_cxx::char_traits inchangé.
