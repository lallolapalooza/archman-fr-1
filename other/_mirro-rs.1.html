mirro-rs(1) Manuel des commandes générales mirro-rs(1)

NOM

mirro-rs - Gestionnaire de mirrorlist ArchLinux avec une IUG

SYNTAXE

mirro-rs [-o|--outfile] [-e|--export] [-v|--view] [-s|--sort] [-t|--ttl] [-u|--url] [--config] [-r|--rate] [--timeout] [-i|--include] [-d|--direct] [-a|--age] [-c ] [-p|--protocols] [--ipv4] [--ipv6] [--isos] [--completion-percent] [-h|--help] [-V|--version]

DESCRIPTION

Gestionnaire de mirrorlist ArchLinux avec une IUG (Interface Utilisateur Graphique)

OPTIONS

-o, --outfile=FICHIERDESORTIE
Fichier où écrire les miroirs
-e, --export=EXPORTATION
Nombre de miroirs à exporter [défaut : 50]
-v, --view=VUE
Ordre pour afficher tous les pays

[valeurs possibles : alphabetical, mirror-count]

-s, --sort=TRI
Tri par défaut pour les miroirs exportés

[valeurs possibles : percentage, delay, duration, score]

-t, --ttl=TTL
Nombre d'heures pendant lesquelles la mirrorlist sera mise en cache
-u, --url=URL
URL pour vérifier les miroirs
--config=CONFIG
Spécifier un fichier de configuration alternatif
-r, --rate
Trier les mirrorlists par vitesse de téléchargement lors de l'exportation
--timeout=TIMEOUT
Délai d'attente de connexion en secondes
-i, --include=INCLURE
CDNs supplémentaires à vérifier pour les miroirs
-d, --direct
Ignorer la session IUG et exporter directement la mirrorlist
-a, --age=ÂGE
Quel âge (en heures) doivent avoir les miroirs depuis la dernière synchronisation
-c=PAYS
Pays pour rechercher les mirrorlists
-p, --protocols=PROTOCOLES
Filtres à utiliser sur les mirrorlists

[valeurs possibles : https, http, rsync, ftp]

--ipv4
Retourner uniquement les miroirs qui supportent IPv4
--ipv6
Retourner uniquement les miroirs qui supportent IPv6
--isos
Retourner uniquement les miroirs qui hébergent des ISOs
--completion-percent=POURCENTAGE
Définir le pourcentage minimum d'achèvement pour les miroirs retournés
-h, --help
Afficher l'aide
-V, --version
Afficher la version
