6TUNNEL(1) Manuel des commandes générales 6TUNNEL(1)

NOM

6tunnel - Tunnelisation pour applications qui ne parlent pas IPv6

SYNTAXE

6tunnel [ -146dhfv ] [ -u nom_utilisateur ] [ -i mot_de_passe ] [ -I mot_de_passe ] [ -l hote_local ] [ -L limite ] [ -p fichier_pid ] [ -m fichier_map ] port_local hote_distant [ port_distant ]

DESCRIPTION

6tunnel vous permet d'utiliser des services fournis par des hôtes IPv6 avec des applications IPv4 uniquement et vice-versa. Il peut se lancer sur n'importe laquelle de vos adresses IPv4 (par défaut) ou IPv6 et transférer toutes les données vers un hôte IPv4 ou IPv6 (par défaut). Par exemple,

6tunnel -1 6668 irc6.net 6667

sera suffisant pour vous connecter à un serveur IRC IPv6 avec

irc votre_nom localhost:6668

Si vous ne souhaitez pas exécuter 6tunnel à chaque fois que vous voulez afficher votre adresse IPv6 :c001: ou :dead: sur IRC, vous pouvez utiliser le paramètre -i, qui demande à 6tunnel de demander à votre client un mot de passe spécifié. Exécutez simplement

6tunnel -i dupa.8 31337 irc6.net 6667

puis tapez

irc votre_nom localhost:31337:dupa.8

Si votre serveur IRC exige que vous envoyiez un mot de passe, spécifiez-le avec le paramètre -I -- après une authentification réussie du proxy, 6tunnel l'enverra au serveur.

6tunnel peut également être utilisé comme tunnel pour toutes les autres combinaisons de points d'extrémité IPv4 et IPv6. Si l'hôte distant n'a pas d'adresses IPv6, 6tunnel utilisera l'adresse IPv4. Dans les autres cas, utilisez le paramètre -4 qui fait de l'adresse IPv4 le point d'extrémité préféré. Pour les tunnels IPv6 vers n'importe quel, utilisez -6 qui fait que 6tunnel se lance sur une adresse IPv6.

OPTIONS

-1
Quitte après la première connexion.
-4
Préfère le point d'extrémité IPv4 si la machine possède les deux types d'adresses.
-6
Écoute sur une adresse IPv6 (IPv4 est par défaut).
-d
Ne pas se détacher.
-f
Force la tunnelisation même si l'hôte distant n'est pas résolvable au moment de l'exécution.
-h
Affiche une représentation hexadécimale de chaque paquet reçu ou envoyé.
-u nom_utilisateur
Change UID et GID après bind().
-i mot_de_passe
Agit comme un proxy IRC et exige que l'utilisateur s'authentifie.
-I mot_de_passe
Si vous utilisez 6tunnel comme proxy IRC et que le serveur IRC exige que vous envoyiez un mot de passe, placez-le ici.
-l hote_local
Écoute sur l'adresse spécifiée (IPv4, ou IPv6 si -6 est utilisé).
-L limite
Limite les connexions simultanées.
-p fichier_pid
Écrit le PID dans le fichier spécifié.
-s hote_source
Connecte à l'hôte distant en utilisant l'adresse source spécifiée.
-m fichier_map
Se lance sur les adresses IPv6 spécifiées en se basant sur l'adresse IPv4 source. Le fichier contient une correspondance par ligne avec l'adresse source IPv4 et l'adresse IPv6 correspondante. Seuls les hôtes listés sont autorisés à se connecter. Si vous souhaitez autoriser n'importe quel hôte, ajoutez une correspondance pour l'adresse default ou 0.0.0.0. Exemple :
192.168.0.2 3ffe:8010:18::1000:2
192.168.0.3 3ffe:8010:18::1000:3
-v
Soit verbeux et ne pas se détacher.

NOTES

L'option -H pour désactiver tous les indices du résolveur a été supprimée car la combinaison appropriée de -4 et -6 donnera n'importe quelle combinaison de sources et de destinations IPv4 et IPv6.

SIGNALS

Envoyer SIGHUP force le rechargement du fichier de mappage.

REMERCIEMENTS

Équipe #ipv6, Lam.

BOGUES

Page de manuel terrible. La sortie hexadécimale n'inclut pas l'authentification du proxy IRC. Le proxy IRC exige que votre client envoie d'abord le mot de passe (ne vous inquiétez pas, ircii, EPIC, BitchX, mIRC et beaucoup d'autres fonctionneront). Pas de journalisation, sauf la sortie de débogage.
