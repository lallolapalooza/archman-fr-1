PMCONNECTLOGGER(3) Manuel des fonctions de bibliothèque PMCONNECTLOGGER(3)

NOM

__pmConnectLogger - se connecter au port de contrôle d'un programme d'enregistrement de métriques de performance

C SYNTAXE

#include "pmapi.h"
#include "libpcp.h"

int __pmConnectLogger(const char *hostname, int pid);

cc ... -lpcp

AVERTISSEMENT

Cette documentation est destinée à un usage interne des développeurs de Performance Co-Pilot (PCP).

Ces interfaces ne font pas partie des API PCP garanties d'être stables entre les versions, et elles peuvent ne pas fonctionner, ou fournir des sémantiques différentes à un moment donné dans le futur.

DESCRIPTION

Chaque instance du programme de création d'archives Performance Co-Pilot (PCP) pmlogger(1) supporte un port de contrôle sur lequel les requêtes __pmControlLog(3) sont reçues et les réponses envoyées. Optionnellement, l'instance pmlogger(1) peut être désignée comme le journaliste « primaire ».

__pmConnectLogger peut être utilisé pour établir une connexion au port de contrôle du programme pmlogger(1) identifié par son ID de processus pid sur l'hôte hostname.

Un cas spécial est supporté ; pour la valeur réservée de pid PM_LOG_PRIMARY_PORT, la connexion demandée est au port de contrôle du journaliste « primaire », quel que soit son ID de processus.

En cas de succès, __pmConnectLogger retourne un entier non négatif, qui est un descripteur de fichier pouvant être utilisé pour la communication ultérieure avec l'instance pmlogger(1), par exemple pour __pmControlLog(3).

Comme le port de contrôle de pmlogger(1) n'est pas multiplexé, les applications utilisant __pmConnectLogger devraient utiliser close(2) pour terminer la connexion à pmlogger(1) dès qu'elles ont fini de communiquer.

Si l'application se connecte, et que l'instance pmlogger(1) se termine par la suite, par exemple parce que l'instance associée de pmcd(1) est terminée, l'application devra explicitement rétablir la connexion à une instance redémarrée de pmlogger(1) en appelant à nouveau __pmConnectLogger.

DIAGNOSTICS

PM_ERR_PERMISSION
pas de permission pour se connecter à l'instance spécifiée de pmlogger(1)
-ECONNREFUSED
l'instance désignée de pmlogger(1) n'existe pas
-EADDRINUSE
le port de contrôle demandé est déjà utilisé

VOIR AUSSI

pmcd(1), pmlc(1), pmlogger(1), PMAPI(3) et __pmControlLog(3).
