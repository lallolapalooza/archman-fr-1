Description

détaillée

Fonctionnalités de base pour un itérateur

sûr.

La classe de base _Safe_local_iterator_base implémente la fonctionnalité d'un itérateur local sûr qui n'est pas spécifique à un type d'itérateur particulier. Elle contient un pointeur vers le conteneur auquel il fait référence, ainsi que des informations de version de l'itérateur et des pointeurs pour former une liste doublement chaînée des itérateurs locaux référencés par le

conteneur.

Cette classe ne doit effectuer aucune opération pou

vant lever une exception, sinon les garanties d
'exception des itérateurs dérivés seront rompues.
