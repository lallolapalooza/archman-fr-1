template<typename

class __gnu_debug::_Safe_sequence< _Sequence >"Classe de base pour construire un type de séquence sûr qui suit les itérateurs qui la

référencent.

Le modèle de classe _Safe_sequence simplifie la construction de séquences sûres qui suivent les itérateurs qui référencent la séquence, de sorte que les itérateurs soient notifiés des changements dans la séquence qui peuvent affecter leur fonctionnement, par ex., si le conteneur invalide ses itérateurs ou est détru

it. Ce modèle de classe ne peut être utilisé qu'en en dérivant et en passant le nom de la classe dérivée comme son paramètre de m
odèle via le motif de modèle récursif étrange. La classe dérivée doit avoir des types iterator et const_iterator qui sont de
s instanciations du modèle de classe _Safe_iterator pour cette séquence. Les itérateurs seront alors suivis automatiquement.
