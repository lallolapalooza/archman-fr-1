Description

détaillée

Fonctionnalités de base pour un itérateur sûr. Fonctionnalités de base pour un itérateur

sûr.

La classe de base _Safe_iterator_base implémente les fonctionnalités d'un itérateur sûr qui ne sont pas spécifiques à un type d'itérateur particulier. Elle contient un pointeur vers la séquence à laquelle il fait référence, ainsi que des informations de version de l'itérateur et des pointeurs pour former une liste doublement chaînée des itérateurs référencés par le

conteneur.

Cette classe ne doit effectuer aucune opération p

ouvant lever une exception, sinon les garanties d
'exception des itérateurs dérivés seront violées.
