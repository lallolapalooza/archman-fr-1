Description détaillée

template<class _ForwardIterator, class _Tp = typename std::iterator_traits<_ForwardIterator>::value_type>

struct __gnu_cxx::temporary_buffer< _ForwardIterator, _Tp >"Cette classe fournit un comportement et une sémantique similaires aux fonctions standard get_temporary_buffer() et return_temporary_buffer(), mais encapsulés dans un type ressemblant vaguement à un conteneur standard.

Par défaut, un temporary_buffer<Iter> stocke de l'espace pour des objets du type vers lequel pointe l'itérateur Iter. Il est construit à partir d'une plage typique [first,last), et fournit les fonctions begin(), end(), size(), ainsi que requested_size(). Pour les types non triviaux, des copies de *first seront utilisées pour initialiser le stockage.

malloc est utilisé pour obtenir le stockage sous-jacent.

Comme get_temporary_buffer(), toute la mémoire demandée peut ne pas être disponible. Idéalement, le tampon créé sera suffisamment grand pour contenir une copie de [first,last), mais si size() est inférieur à requested_size(), alors cela ne s'est pas produit.
