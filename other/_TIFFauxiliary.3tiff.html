NOM

_TIFFauxiliary - fonctions auxiliaires

SYNTAXE

#include <tiffio.h>
uint32_t _TIFFClampDoubleToUInt32(double val)
uint32_t _TIFFMultiply32(TIFF *tif, uint32_t first, uint32_t second, const char *where)
uint64_t _TIFFMultiply64(TIFF *tif, uint64_t first, uint64_t second, const char *where)

DESCRIPTION

_TIFFClampDoubleToUInt32() contraint les valeurs double dans la plage de uint32_t (c'est-à-dire 0 .. 0xFFFFFFFF)

_TIFFMultiply32() et _TIFFMultiply64() vérifient le dépassement d'entier du résultat de la multiplication et retournent le résultat de la multiplication ou 0 si un dépassement se produirait. La chaîne where est imprimée dans le message d'erreur en cas de dépassement et peut être utilisée pour indiquer où la fonction a été appelée.
