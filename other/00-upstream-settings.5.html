00-UPSTREAM-SETTINGS(5) Commandes utilisateur 00-UPSTREAM-SETTINGS(5)

NOM

00-upstream-settings - Fichier de configuration dconf

SYNTAXE

/etc/dconf/db/ibus.d/00-upstream-settings

DESCRIPTION

IBus est un bus d'entrée intelligent. C'est un nouveau framework d'entrée pour le système d'exploitation Linux. Il fournit une interface utilisateur de méthode d'entrée conviviale et complète. Il peut également aider les développeurs à développer facilement des méthodes d'entrée.

00-upstream-settings est un fichier de configuration texte de dconf et peut être converti en /etc/dconf/db/ibus par la commande dconf update avec un privilège d'écriture dans /etc/dconf/db. /etc/dconf/db/ibus est un fichier de base de données de dconf et enregistre les paramètres par défaut d'IBus. Les clés et valeurs enregistrées peuvent être lues par la commande dconf.

env DCONF_PROFILE=ibus dconf list /desktop/ibus/
