99USER.LDIF(5) Manuel des formats de fichiers 99USER.LDIF(5)

NOM

/etc/dirsrv/schema/99user.ldif - Fichier LDIF contenant le schéma LDAP personnalisé pour 389 Directory Server.

SYNTAXE

/etc/dirsrv/schema/99user.ldif

DESCRIPTION

99user.ldif

Ce fichier contient les définitions de schéma LDAP définies par l'utilisateur, ou personnalisées (attributs et classes d'objets) utilisées par le serveur d'annuaire.

SYNTAXE DU FICHIER

attributeTypes: VALUE
objectClasses: VALUE

EXEMPLE

dn: cn=schema
attributeTypes: ( 1.1.1.1.1.1.1 NAME 'myNewAttribute' DESC 'Custom defined attribute type' SYNTAX 1.3.6.1.4.1.1466.115.121.1.15 SINGLE-VALUE X-ORIGIN
objectClasses: ( 1.1.1.1.1.1.1.2 NAME 'myNewObjectcass' DESC 'Custom defined objectclass' SUP top MUST ( myNewAttribute ) MAY ( uid $ cn ) X-ORIGIN 'user-defined' )
