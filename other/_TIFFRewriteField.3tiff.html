NOM

_TIFFRewriteField - réécrire un champ dans le répertoire sur disque

SYNTAXE

#include <tiffio.h>
int _TIFFRewriteField(TIFF *tif, uint16_t tag, TIFFDataType in_datatype, tmsize_t count, void *data)

DESCRIPTION

_TIFFRewriteField() réécrit un champ dans le répertoire sur disque sans tenir compte de la mise à jour de la structure du répertoire TIFF en mémoire. Actuellement, uniquement pris en charge pour les champs qui existent déjà dans le répertoire sur disque. Principalement utilisé pour mettre à jour les valeurs stripoffset / stripbytecount après que le répertoire est déjà sur disque.

VALEURS DE RETOUR

Retourne zéro en cas d'échec, et un en cas de succès.
