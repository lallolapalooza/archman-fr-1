void std::basic_filebuf< _CharT, encoding_char_traits< _CharT > >::_M_set_buffer (streamsize __off) [inline], [protected], [inherited]

Cette fonction définit les pointeurs du tampon interne, tant pour la zone de lecture que pour la zone d'écriture. Typiquement :

__off == egptr() - eback() lors d'un sous-flux/u-flux (mode lecture) ; __off == 0 lors d'un dépassement (mode écriture) ; __off == -1 lors de l'ouverture, setbuf, seekoff/pos (mode non validé).

NB : epptr() - pbase() == _M_buf_size - 1, car _M_buf_size reflète la mémoire réellement allouée et la dernière cellule est réservée au caractère de dépassement d'une zone d'écriture pleine.

Référencé par seekpos() et setbuf().

basic_filebuf< _CharT, encoding_char_traits< _CharT > >::__filebuf_type * std::basic_filebuf< _CharT, encoding_char_traits< _CharT > >::close () [inherited]

Ferme le fichier actuellement associé.

Retourne

this en cas de succès, NULL en cas d'échec

Si aucun fichier n'est actuellement ouvert, cette fonction échoue immédiatement.

Si une zone de tampon d'écriture existe, overflow(eof) est appelé pour vider tous les caractères. Le fichier est ensuite fermé.

Si des opérations échouent, cette fonction échoue également.

basic_filebuf< _CharT, encoding_char_traits< _CharT > >::int_type std::basic_filebuf< _CharT, encoding_char_traits< _CharT > >::overflow (int_type __c = _Traits::eof()) [protected], [virtual], [inherited]

Consomme des données du tampon ; écrit dans la séquence contrôlée.

Paramètres

__c Un caractère supplémentaire à consommer.

Retourne

eof() pour indiquer un échec, autre chose (généralement __c, ou not_eof())

Informellement, cette fonction est appelée lorsque le tampon d'écriture est plein (ou n'existe pas, car la mise en tampon n'est pas nécessairement effectuée). Si un tampon existe, il est consommé, avec un certain effet sur la séquence contrôlée. (Typiquement, le tampon est écrit dans la séquence tel quel.) Dans les deux cas, le caractère c est également écrit, si __c n'est pas eof().

Pour une définition formelle de cette fonction, consultez un bon ouvrage tel que Langer & Kreft, ou [27.5.2.4.5]/3-7.

Un flux de sortie fonctionnel peut être créé en surchargeant uniquement cette fonction (aucune zone tampon ne sera utilisée).

Note

La version de la classe de base ne fait rien, retourne eof().

Réimplémenté depuis std::basic_streambuf< _CharT, encoding_char_traits< _CharT > >.

Référencé par _M_ext_buf, _M_ext_next et eback().

streamsize std::basic_filebuf< _CharT, encoding_char_traits< _CharT > >::showmanyc () [protected], [virtual], [inherited]

Investigation des données disponibles.

Renvoie

Une estimation du nombre de caractères disponibles dans la séquence d'entrée, ou -1.

S'il renvoie une valeur positive, alors les appels successifs à underflow() ne renverront pas traits::eof() tant qu'au moins ce nombre de caractères n'aura pas été fourni. Si showmanyc() renvoie -1, alors les appels à underflow() ou uflow() échoueront. [27.5.2.4.3]/1

Note

La version de la classe de base ne fait rien, renvoie zéro.

La norme ajoute que l'intention est non seulement que les appels [à underflow ou uflow] ne renverront pas eof() mais qu'ils renverront immédiatement.

La norme ajoute que les morphèmes de showmanyc sont es-how-many-see, et non show-manic.

Réimplémenté à partir de std::basic_streambuf< _CharT, encoding_char_traits< _CharT > >.
