Description détaillée

template<typename _Tp>

class __gnu_cxx::_Relative_pointer_impl< _Tp >"Une politique de stockage pour utilisation avec _Pointer_adapter<> qui stocke l'adresse du pointeur sous forme de valeur de décalage relative à sa propre adresse.

Ceci est destiné aux pointeurs au sein de régions de mémoire partagée qui pourraient être mappées à différentes adresses par différents processus. Pour les pointeurs nuls, une valeur de 1 est utilisée. (0 est légitime parfois pour les nœuds dans les listes chaînées circulaires) Cette valeur a été choisie car étant la moins susceptible de générer un pointeur nul incorrect, puisqu'il n'y a aucune raison pour qu'un pointeur normal pointe 1 octet dans son propre adresse de pointeur.
