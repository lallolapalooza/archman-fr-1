Description détaillée

template<typename _Tp>

class __gnu_cxx::__detail::__mini_vector< _Tp >"__mini_vector<> est une version allégée du std::vector<> complet.

Il doit être utilisé uniquement pour les types intégrés ou les POD. Les différences notables sont :

1.
Toutes les fonctions d'accès ne sont pas présentes.
2.
Utilisé UNIQUEMENT pour les POD.
3.
Pas d'argument de modèle Allocator. Utilise operator new() pour obtenir la mémoire et operator delete() pour la libérer. Attention : le destructeur ne libère PAS la mémoire allouée, donc c'est un vecteur qui fuit de la mémoire !
