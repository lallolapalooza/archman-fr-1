Description détaillée

Classe de base qui prend en charge le suivi des itérateurs référençant une séquence.

La classe _Safe_sequence_base fournit un support de base pour le suivi des itérateurs vers une séquence. Les séquences qui suivent les itérateurs doivent hériter publicly de _Safe_sequence_base, afin que les itérateurs sûrs (qui héritent de _Safe_iterator_base) puissent s'y attacher. Cette classe contient deux listes chaînées d'itérateurs, une pour les itérateurs constants et une pour les itérateurs mutables, et un numéro de version qui permet une invalidation très rapide de tous les itérateurs qui référencent le conteneur.

Cette classe doit garantir qu'aucune opération sur celle-ci ne peut lancer d'exception, sinon les séquences sûres pourraient ne pas fournir les garanties de sécurité face aux exceptions requises par la norme C++.
