PMFREEPROFILE(3) Manuel des fonctions de bibliothèque PMFREEPROFILE(3)

NOM

__pmFreeProfile - libérer un profil d'instance PMAPI

SYNTAXE C

#include"pmapi.h"
#include"libpcp.h"

void __pmFreeProfile(pmProfile *prof);

cc ... -lpcp

AVERTISSEMENT

Cette documentation est destinée à un usage interne par les développeurs de Performance Co-Pilot (PCP).

Ces interfaces ne font pas partie des API PCP garanties pour rester fixes d'une version à l'autre, et elles pourraient ne pas fonctionner, ou avoir des sémantiques différentes à un moment donné dans le futur.

DESCRIPTION

__pmFreeProfile libère le stockage du profil d'instance PMAPI prof, en supposant que le stockage a été alloué en utilisant malloc(3) selon le schéma utilisé dans __pmDecodeProfile(3).

VOIR AUSSI

malloc(3), PMAPI(3) et __pmDecodeProfile(3).
