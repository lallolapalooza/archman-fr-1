template<typename _Container> class __gnu_debug::_Safe_unordered_container< _Container >"Classe de base pour construire un
conteneur non ordonné sûr qui suit les itérateurs qui le référencent.
Le modèle de classe _Safe_unordered_container simplifie la construction de conteneurs sûrsnon ordonnés qui suivent les itérateurs qui référencent le conteneur, afin que les itérateurs soient notifiés des changements dans le conteneur qui pourraient affecter leur fonctionnement, par exemple si le conteneur invalide ses itérateurs ou est détruit. Ce modèle de classe ne peut être utilisé qu'en en dérivant et en passant le nom de la classe dérivée en tant que paramètre de modèle via le motif de modèle récursif étrange (curiously recurring template pattern). La classe dérivée doit avoir des types iterator et const_iterator qui sont des instanciations du modèle de classe _Safe_iterator pour ce conteneur, et des types local_iterator et const_local_iterator qui sont des instanciations du modèle de classe _Safe_local_iterator pour ce conteneur. Les itérateurs seront alors suivis automatiquement.
