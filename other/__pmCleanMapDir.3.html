PMCLEANMAPDIR(3) Manuel des fonctions de bibliothèque PMCLEANMAPDIR(3)

NOM

__pmCleanMapDir - supprime les anciens fichiers d'un répertoire de mappage

SYNTAXE C

#include"pmapi.h"
#include"libpcp.h"

int __pmCleanMapDir(const char *dirname,
const char *special);

cc ... -lpcp

AVERTISSEMENT

Cette documentation est destinée à un usage interne par les développeurs de Performance Co-Pilot (PCP).

Ces interfaces ne font pas partie des API de PCP garanties pour rester constantes d'une version à l'autre, et elles pourraient ne pas fonctionner, ou avoir une sémantique différente à l'avenir.

DESCRIPTION

pmlogger(1) et pmie(1) maintiennent des répertoires de fichiers de mappage qui fournissent un lien entre un identifiant de processus (PID) de pmlogger(1) ou pmie(1) et les paramètres importants de ces processus.

__pmCleanMapDir supprime les fichiers "morts" dans ces répertoires. Plus précisément, les entrées du répertoire dans dirname doivent suivre ces règles, sinon __pmCleanMapDir les supprimera :

+
le nom doit être numérique, sinon il doit être égal à special (si special n'est pas NULL)
+
pour une entrée de répertoire numérique, ce doit être un fichier régulier et le nom doit être le PID d'un processus en cours d'exécution
+
pour une correspondance avec special, l'entrée du répertoire doit être un lien symbolique et le dernier composant du lien doit être l'encodage ASCII du PID d'un processus en cours d'exécution

Avant d'effectuer l'une de ces vérifications, __pmCleanMapDir vérifie que dirname est bien un répertoire, et que l'identifiant d'utilisateur et l'identifiant de groupe de l'appelant correspondent à ceux de dirname.

VALEURS DE RETOUR

En cas d'erreur grave, __pmCleanMapDir retourne une valeur négative appropriée pour être signalée avec pmErrStr(3). Sinon, la valeur de retour est le nombre d'entrées qui ont été supprimées.

DIAGNOSTICS

Des diagnostics détaillés décrivant les actions de __pmCleanMapDir seront rapportés sur la sortie standard d'erreur si l'option de débogage misc est activée, par exemple via -D misc depuis la ligne de commande.

VOIR AUSSI

pmdbg(1), PMAPI(3) et pmErrStr(3).
