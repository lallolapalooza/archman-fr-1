Description détaillée

Fait partie de RTTI.

La classe type_info décrit les informations de type générées par une implémentation.

Documentation constructeur et destructeur

virtual std::type_info::~type_info () [virtuel]

Destructeur en premier. Étant la première fonction virtuelle non-inline, cela contrôle dans quelle unité de traduction le vtable est émise. Le compilateur utilise ces informations pour savoir où émettre les structures type_info requises à l'exécution dans le nouveau-abi.

Documentation des fonctions membres

bool std::type_info::before (const type_info & __arg) const [noexcept]

Retourne vrai si *this précède __arg dans l'ordre de tri de l'implémentation.

const char * std::type_info::name () const [inline], [noexcept]

Retourne une chaîne d'octets *définie par l'implémentation* ; ceci n'est pas portable entre compilateurs !
