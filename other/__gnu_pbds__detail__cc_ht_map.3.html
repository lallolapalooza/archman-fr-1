class __gnu_pbds::detail::cc_ht_map< Clé, Mappé, FoncteurHash, FoncteurEq, Allocateur, StockeHash, FoncteurHashComb, StratégieRedimensionnement >"Un conteneur basé sur une table de hachage avec chaînage de collisions.

Paramètres de template

Clé Type de la clé.
Mappé Type de la valeur.
FoncteurHash Foncteur de hachage. Par défaut : __gnu_cxx::hash.
FoncteurEq Foncteur d'égalité. Par défaut : std::equal_to<Clé>
Allocateur Type de l'allocateur.
StockeHash Si le type de clé stocke des métadonnées supplémentaires. Par défaut : faux.
FoncteurHashComb Foncteur de combinaison de hachage. Si Hash_Fn n'est pas null_type, alors c'est le foncteur de hachage de plage ; sinon, c'est le foncteur de hachage de plage. XXX(Voir Design::Hash-Based Containers::Hash Policies.) Par défaut : direct_mask_range_hashing.
StratégieRedimensionnement Redimensionne la table de hachage. Par défaut : hash_standard_resize_policy, utilisant hash_exponential_size_policy et hash_load_check_resize_trigger.

Les bases sont : detail::hash_eq_fn, StratégieRedimensionnement, detail::ranged_hash_fn, detail::types_traits. (Optionnel : detail::debug_map_base.)
