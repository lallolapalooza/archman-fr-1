__ppc_get_timebase(3) Manuel des fonctions de bibliothèque __ppc_get_timebase(3)

NOM

__ppc_get_timebase, __ppc_get_timebase_freq - obtenir la valeur actuelle du registre de base temporelle sur l'architecture Power et sa fréquence.

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <sys/platform/ppc.h>
uint64_t __ppc_get_timebase(void);
uint64_t __ppc_get_timebase_freq(void);

DESCRIPTION

__ppc_get_timebase() lit la valeur actuelle du registre de base temporelle et retourne sa valeur, tandis que __ppc_get_timebase_freq() retourne la fréquence à laquelle le registre de base temporelle est mis à jour.

Le registre de base temporelle est un registre de 64 bits fourni par les processeurs de l'architecture Power. Il stocke une valeur incrémentée monotoniquement qui est mise à jour à une fréquence dépendante du système qui peut être différente de la fréquence du processeur.

VALEUR DE RETOUR

__ppc_get_timebase() retourne un entier non signé de 64 bits qui représente la valeur actuelle du registre de base temporelle.

__ppc_get_timebase_freq() retourne un entier non signé de 64 bits qui représente la fréquence à laquelle le registre de base temporelle est mis à jour.

NORMES

GNU.

HISTORIQUE

__ppc_get_timebase()
glibc 2.16.
__ppc_get_timebase_freq()
glibc 2.17.

EXEMPLES

Le programme suivant calculera le temps, en microsecondes, passé entre deux appels à __ppc_get_timebase().

Source du programme

#include <inttypes.h>
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/platform/ppc.h>
/* Valeur maximale du registre de base temporelle : 2^60 - 1.
   Source : Architecture ISA POWER.  */
#define MAX_TB 0xFFFFFFFFFFFFFFF
int
main(void)
{
    uint64_t tb1, tb2, diff;
    uint64_t freq;
    freq = __ppc_get_timebase_freq();
    printf("Fréquence de base temporelle = %"PRIu64" Hz\n", freq);
    tb1 = __ppc_get_timebase();
    // Faire quelque chose...
    tb2 = __ppc_get_timebase();
    if (tb2 > tb1) {
        diff = tb2 - tb1;
    } else {
        /* Traiter le débordement du registre de base temporelle.  */
        diff = (MAX_TB - tb2) + tb1;
    }
    printf("Temps écoulé = %1.2f microsecondes\n",
           (double) diff * 1000000 / freq);
    exit(EXIT_SUCCESS);
}
