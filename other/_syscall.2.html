_syscall(2) Manuel des appels système _syscall(2)

NOM

_syscall - invoquer un appel système sans support de bibliothèque (OBSOLÈTE)

SYNTAXE

#include <linux/unistd.h>
Macro _syscall
appel système désiré

DESCRIPTION

L'élément important à connaître concernant un appel système est son prototype. Vous devez connaître le nombre d'arguments, leurs types et le type de retour de la fonction. Il existe sept macros qui facilitent l'appel effectif au système.

Elles se présentent sous la forme :


_syscallX(type,nom,type1,arg1,type2,arg2,...)

où

X est 0 à 6, ce qui correspond au nombre d'arguments pris par l'appel système
type est le type de retour de l'appel système
nom est le nom de l'appel système
typeN est le type du N-ième argument
argN est le nom du N-ième argument

Ces macros créent une fonction nommée nom avec les arguments que vous spécifiez. Une fois que vous avez inclus _syscall() dans votre fichier source, vous appelez l'appel système par nom.

FICHIERS

/usr/include/linux/unistd.h

NORMES

Linux.

HISTORIQUE

À partir de Linux 2.6.18 environ, les macros _syscall ont été supprimées des fichiers d'en-tête fournis à l'espace utilisateur. Utilisez plutôt syscall(2). (Certaines architectures, notamment ia64, n'ont jamais fourni les macros _syscall ; sur ces architectures, syscall(2) était toujours requis.)

NOTES

Les macros _syscall() ne génèrent pas de prototype. Vous pourriez avoir à en créer un, en particulier pour les utilisateurs de C++.

Les appels système ne sont pas obligés de retourner uniquement des codes d'erreur positifs ou négatifs. Vous devez lire le code source pour être sûr de la manière dont les erreurs seront retournées. Généralement, c'est l'inverse d'un code d'erreur standard, par exemple, -EPERM. Les macros _syscall() retourneront le résultat r de l'appel système lorsque r est positif ou nul, mais retourneront -1 et définiront la variable errno à -r lorsque r est négatif. Pour les codes d'erreur, voir errno(3).

Lors de la définition d'un appel système, les types d'arguments *doivent* être passés par valeur ou par pointeur (pour les agrégats comme les structures).

EXEMPLES

#include <stdio.h>
#include <stdlib.h>
#include <errno.h>
#include <linux/unistd.h>       /* pour les macros _syscallX/éléments associés */
#include <linux/kernel.h>       /* pour la structure sysinfo */
_syscall1(int, sysinfo, struct sysinfo *, info);
int
main(void)
{
    struct sysinfo s_info;
    int error;
    error = sysinfo(&s_info);
    printf("code erreur = %d\n", error);
    printf("Temps de fonctionnement = %lds\nCharge : 1 min %lu / 5 min %lu / 15 min %lu\n"
           "RAM : total %lu / libre %lu / partagée %lu\n"
           "Mémoire en tampons = %lu\nSwap : total %lu / libre %lu\n"
           "Nombre de processus = %d\n",
           s_info.uptime, s_info.loads[0],
           s_info.loads[1], s_info.loads[2],
           s_info.totalram, s_info.freeram,
           s_info.sharedram, s_info.bufferram,
           s_info.totalswap, s_info.freeswap,
           s_info.procs);
    exit(EXIT_SUCCESS);
}

Exemple de sortie

Mémoire en tampons = 5066752
Swap : total 27881472 / libre 24698880
Nombre de processus = 40
