Description détaillée

template<typename _Storage_policy>

class __gnu_cxx::_Pointer_adapter< _Storage_policy >"Ce qui suit fournit un « pointeur alternatif » qui fonctionne avec les conteneurs lorsqu'il est spécifié comme la typedef de pointeur de l'allocateur.

Le type de pointeur utilisé avec les conteneurs n'a pas besoin d'être cette classe, mais il doit prendre en charge les conversions implicites, l'arithmétique des pointeurs, les opérateurs de comparaison, etc. pris en charge par cette classe, et éviter de provoquer des ambiguïtés à la compilation. Comme la création d'un pointeur fonctionnel peut être difficile, ce modèle de pointeur a été conçu pour envelopper un type de politique de stockage plus simple, afin qu'il devienne réutilisable pour créer d'autres types de pointeurs.

Un point clé de cette classe est également qu'elle permet aux auteurs de conteneurs de « supposer » que Allocator::pointer est une typedef pour un pointeur normal. Cette classe prend en charge la plupart des conventions d'un vrai pointeur et peut, par exemple, gérer la conversion implicite vers les types de pointeurs const et de classe de base. Les seules impositions aux auteurs de conteneurs pour prendre en charge les pointeurs étendus sont : 1) utiliser la typedef Allocator::pointer de manière appropriée pour les types de pointeurs. 2) si vous avez besoin de conversions de pointeurs, utiliser les fonctions __pointer_cast<> de ext/cast.h. Cela permet aux opérations de conversion de pointeur d'être surchargées si nécessaire par des pointeurs personnalisés.

Remarque : le qualificateur const fonctionne avec cet adaptateur de pointeur comme suit :

_Tp* == _Pointer_adapter<_Std_pointer_impl<_Tp> >; const _Tp* == _Pointer_adapter<_Std_pointer_impl<const _Tp> >; _Tp* const == const _Pointer_adapter<_Std_pointer_impl<_Tp> >; const _Tp* const == const _Pointer_adapter<_Std_pointer_impl<const _Tp> >;
