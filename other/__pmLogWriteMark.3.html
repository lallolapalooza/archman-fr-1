__pmLogWriteMark(3)

PMLOGWRITEMARK(3) Manuel des fonctions de bibliothèque PMLOGWRITEMARK(3)

NOM

__pmLogWriteMark - ajoute un enregistrement <mark> à une archive PCP

SYNTAXE EN C

#include <pcp/pmapi.h>
#include <pcp/libpcp.h>

int __pmLogWriteMark(__pmArchCtl *acp,
const __pmTimestamp *last_stamp, const __pmTimestamp *inc);

cc ... -lpcp

AVERTISSEMENT

Cette documentation est destinée à un usage interne par les développeurs de Performance Co-Pilot (PCP).

Ces interfaces ne font pas partie des API PCP garanties pour rester inchangées entre les versions, et à un moment donné dans le futur, elles pourraient ne plus fonctionner ou avoir des sémantiques différentes.

DESCRIPTION

__pmLogWriteMark ajoute un enregistrement <mark> au fichier de données courant d'une archive PCP. Un enregistrement <mark> indique une discontinuité dans la série temporelle des données enregistrées dans l'archive, voir PCPIntro(1) pour plus d'informations.

L'horodatage de l'enregistrement <mark> est donné par last_stamp éventuellement incrémenté par inc à moins que inc ne soit NULL (auquel cas aucune incrémentation n'est effectuée).

Le flux d'E/S du volume de données courant et la version de l'archive (qui détermine le format de l'enregistrement <mark>) sont déterminés à partir de acp.

DIAGNOSTICS ET VALEURS DE RETOUR

La valeur de retour est 0 si tout va bien, sinon un code d'erreur inférieur à zéro qui peut être transformé en message d'erreur en appelant pmErrStr(3).

VOIR AUSSI

PCPIntro(1), PMAPI(3) et __pmLogWrite(3).
