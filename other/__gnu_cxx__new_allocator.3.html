Description détaillée

template<typename _Tp>

class __gnu_cxx::new_allocator< _Tp >"Un allocateur qui utilise l'opérateur global new, conformément à C++03 [20.4.1].

C'est précisément l'allocateur défini dans la norme C++.

  • tous les appels d'allocation utilisent operator new
  • tous les appels de désallocation utilisent operator delete

Il s'agit d'une extension non standard qui peut être utilisée pour garantir l'allocation à partir de new, même si la bibliothèque a été configurée pour utiliser une implémentation différente pour std::allocator.

Paramètres de modèle

_Tp Type de l'objet alloué.
