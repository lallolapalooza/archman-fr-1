NOM

_U_dyn_register -- enregistre les informations de déroulement pour le code généré dynamiquement

SYNOPSIS

#include <libunwind.h>

void _U_dyn_register(unw_dyn_info_t *di);

DESCRIPTION

La routine _U_dyn_register() enregistre les informations de déroulement pour une procédure générée dynamiquement. Les informations de déroulement de la procédure sont décrites par une structure de type unw_dyn_info_t (voir libunwind-dynamic(3libunwind)). Un pointeur vers cette structure est passé en argument di.

La routine _U_dyn_register() est garantie de s'exécuter en temps constant (en l'absence de contention due à des appels concurrents à _U_dyn_register() ou _U_dyn_cancel()).

SURETÉ POUR LES THREADS ET LES SIGNAUX

_U_dyn_register() est sûr pour les threads mais pas sûr à utiliser depuis un gestionnaire de signaux.

VOIR AUSSI

libunwind-dynamic(3libunwind), _U_dyn_cancel(3libunwind)
