template<typename _Tp>

class __gnu_cxx::_Std_pointer_impl< _Tp >"Une politique de stockage pour une utilisation avec _Pointer_adapter<> qui renvoie un pointeur standard.

Une _Storage_policy doit fournir 4 choses : 1) une API get() pour renvoyer la valeur du pointeur stocké. 2) une API set() pour stocker une valeur de pointeur. 3) un typedef element_type pour définir le type vers lequel il pointe. 4) un opérateur<() pour supporter la comparaison de pointeurs. 5) un opérateur==() pour supporter la comparaison de pointeurs.
