NOM

__pmOverrideLastFd, __pmPrintIPC, __pmResetIPC - Support d'infrastructure de version IPC

C SYNTAXIS

#include "pmapi.h"
#include "libpcp.h"

void __pmOverrideLastFd(int fd);
void __pmPrintIPC(void);
void __pmResetIPC(int fd);

cc ... -lpcp

AVERTISSEMENT

Cette documentation est destinée à un usage interne par les développeurs de Performance Co-Pilot (PCP).

Ces interfaces ne font pas partie des API PCP qui sont garanties de rester stables entre les versions, et elles pourraient ne pas fonctionner, ou avoir une sémantique différente à l'avenir.

DESCRIPTION

Les canaux IPC dans le cadre distribué de PCP sont affectés par les changements de PDU de PCP 2.0 (et versions ultérieures). Ces fonctions sont l'interface vers les données globales de gestion des connexions IPC de libpcp. Ces données consistent en une table de hachage de structures __pmIPC (indexées par descripteur de fichier) et un descripteur de fichier en cache, le plus récemment utilisé.

__pmOverrideLastFd est un mécanisme d'échappatoire à utiliser dans les situations où la dernière récupération de PDU ne s'est pas faite par les canaux habituels (c'est-à-dire __pmGetPDU), afin de garantir que le descripteur de fichier mis en cache est le bon descripteur de fichier pour la PDU en cours de traitement. Ceci sera généralement utilisé pour le traitement des PDU d'archives ou lorsque les informations de version ne sont pas disponibles pour un descripteur de fichier donné (par exemple, juste avant un échange d'informations de version PDU).

__pmPrintIPC est une routine de débogage utile pour afficher une table associant tous les descripteurs de fichiers actuellement enregistrés à leurs numéros de version PDU associés. Les entrées inutilisées dans cette table devraient afficher la valeur zéro dans la colonne de version.

__pmResetIPC réinitialise les informations de version associées au descripteur de fichier donné à un nombre connu (invalide). Les recherches ultérieures sur ce descripteur de fichier retourneront une UNKNOWN_VERSION intégrée dans la structure __pmIPC.

DIAGNOSTICS

Une valeur de retour négative de __pmOverrideLastFd indique que l'argument descripteur de fichier n'est pas enregistré dans la table de hachage. Cela indique généralement la fermeture d'un canal IPC, c'est pourquoi PM_ERR_IPC est retourné dans ce cas.
