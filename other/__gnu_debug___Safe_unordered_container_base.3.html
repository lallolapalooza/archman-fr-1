Description

détaillée

Classe de base qui prend en charge le suivi des itérateurs locaux qui référencent un conteneur non

ordonné.

La classe _Safe_unordered_container_base fournit une prise en charge de base pour le suivi des itérateurs dans un conteneur non ordonné. Les conteneurs qui suivent les itérateurs doivent hériter publiquement de _Safe_unordered_container_base, de sorte que les itérateurs sûrs (qui héritent de _Safe_iterator_base) puissent s'y attacher. Cette classe contient quatre listes chaînées d'itérateurs, une pour les itérateurs constants, une pour les itérateurs modifiables, une pour les itérateurs locaux constants, une pour les itérateurs locaux modifiables et un numéro de version qui permet une invalidation très rapide de tous les itérateurs qui référencent le

conteneur.

Cette classe doit garantir qu'aucune opération sur elle ne peut lever une exception, sinon les conteneurs sûrs peuvent échouer à fournir les gara

nties de sécurité d'exception
requises par le standard C++.
