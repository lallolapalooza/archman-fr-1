PMCHECKATTRIBUTE(3) Manuel des fonctions de bibliothèque PMCHECKATTRIBUTE(3)

NOM

__pmCheckAttribute - vérifie la valeur d'un attribut de connexion client

SYNTAXE C

#include "pmapi.h"
#include "libpcp.h"

int __pmCheckAttribute(__pmAttrKey attr,
const char *value);

cc ... -lpcp

AVERTISSEMENT

Cette documentation est destinée à un usage interne par les développeurs de Performance Co-Pilot (PCP).

Ces interfaces ne font pas partie des API de PCP qui sont garanties de rester fixes d'une version à l'autre, et elles peuvent ne pas fonctionner, ou avoir des sémantiques différentes à un moment donné dans le futur.

DESCRIPTION

Les attributs de connexion sont échangés entre pmcd(1) et les outils clients PCP au début de l'échange de protocole. Ils fournissent des informations optionnelles relatives à une connexion individuelle, telles que le nom d'un conteneur spécifique analysé par le client.

__pmCheckAttribute vérifie que l'attribut attr donné suit la syntaxe attendue pour ce type d'attribut. Cela aide à prévenir que du contenu malveillant soit accepté par pmcd car ces attributs peuvent ultérieurement être utilisés dans des analyseurs ou transportés dans des sorties structurées telles que le format JSON.

VALEURS DE RETOUR

Lorsqu'un attribut non reconnu ou une value invalide pour l'attribut spécifié est présenté, __pmCheckAttribute retourne une valeur négative appropriée pour être rapportée avec pmErrStr(3). Sinon, la valeur de retour est zéro, indiquant le succès.

VOIR AUSSI

pmdbg(1), PMAPI(3) et pmErrStr(3).
