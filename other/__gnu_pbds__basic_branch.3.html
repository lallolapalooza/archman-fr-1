Description détaillée

template<typename Key, typename Mapped, typename Tag, typename Node_Update, typename Policy_Tl, typename _Alloc>

class __gnu_pbds::basic_branch< Key, Mapped, Tag, Node_Update, Policy_Tl, _Alloc >"Une abstraction de conteneur branched, en forme d'arbre (tree, trie).

Paramètres de modèle

Key Type de clé.
Mapped Type de mappage.
Tag Type de structure de données d'instanciation, voir container_tag.
Node_Update Met à jour les nœuds, restaure les invariants.
Policy_TL Typelist de politique.
_Alloc Type d'allocateur.

La base est choisie au moment de la compilation via Tag, parmi les choix suivants : tree_tag, trie_tag, et leurs descendants.

Les choix de base sont : detail::ov_tree_map, detail::rb_tree_map, detail::splay_tree_map, et detail::pat_trie_map.
