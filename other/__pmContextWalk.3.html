PMCONTEXTWALK(3) Manuel des fonctions de bibliothèque PMCONTEXTWALK(3)

NOM

__pmContextWalk - parcours de tous les contextes PMAPI

SYNTAXE C

#include"pmapi.h"
#include"libpcp.h"

void (*__pmContextWalkCallback)(void *handle, __pmContext *ctxp);
int __pmContextWalk(void *handle, __pmContextWalkCallback callback,

cc ... -lpcp

AVERTISSEMENT

Cette documentation est destinée à un usage interne par les développeurs de Performance Co-Pilot (PCP).

Ces interfaces ne font pas partie des API PCP garanties pour rester inchangées entre les versions, et elles peuvent ne pas fonctionner, ou fournir des sémantiques différentes à l'avenir.

DESCRIPTION

__pmContextWalk offre un moyen sûr, en termes de threads et de verrous, de traiter chaque contexte PMAPI en tour. .Pp Pour chaque contexte PMAPI valide, callback est appelé avec handle passé par l'appelant de __pmContextWalk et ctxp pointant vers un contexte pour lequel le verrou c_lock a été acquis. L'argument handle est un pointeur vers un objet arbitraire qui peut être partagé entre l'appelant de __pmContextWalk et la routine callback, mais qui n'est pas autrement accédé par __pmContextWalk, donc il pourrait être NULL.

Le verrou c_lock par contexte est libéré par __pmContextWalk après l'appel de callback et ne doit pas être déverrouillé par callback.

Pendant la durée de l'appel à __pmContextWalk, toute initiation de contexte (via pmNewContext(3), pmDupContext (3) ou pmReconnectContext(3)) et sa suppression (via pmDestroyContext(3)) est bloquée.

VALEURS DE RETOUR

__pmContextWalk retourne le nombre de contextes traités et donc le nombre de fois où callback a été appelé, sinon une valeur négative adaptée à un rapport avec pmErrStr(3).

VOIR AUSSI

PMAPI(3), pmDestroyContext(3), pmDupContext(3), pmErrStr(3), pmNewContext(3) et pmReconnectContext(3).
