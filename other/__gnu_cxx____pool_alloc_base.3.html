Description détaillée

Classe de base pour __pool_alloc.

Utilise divers allocateurs pour satisfaire les requêtes sous-jacentes (et effectue aussi peu de requêtes que possible en mode pool haute vitesse par défaut).

Propriétés importantes de l'implémentation :

0.
Si mandaté globalement, alors alloue des objets à partir de new.
1.
Si les clients demandent un objet de taille > _S_max_bytes, l'objet résultant sera obtenu directement à partir de new.
2.
Dans tous les autres cas, nous allouons un objet de taille exactement _S_round_up(requested_size). Ainsi, le client dispose de suffisamment d'informations de taille pour que nous puissions retourner l'objet à la liste libre appropriée sans perdre définitivement une partie de l'objet.
