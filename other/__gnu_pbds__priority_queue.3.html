Description détaillée

template<typename _Tv, typename Cmp_Fn = std::less<_Tv>, typename Tag = pairing_heap_tag, typename _Alloc = std::allocator<char>>

class __gnu_pbds::priority_queue< _Tv, Cmp_Fn, Tag, _Alloc >"Une file de priorité composée d'une politique de tas spécifique.

Paramètres de modèle

_Tv Type de valeur.
Cmp_Fn Functeur de comparaison.
Tag Type de structure de données à instancier, voir container_tag.
_Alloc Type d'allocateur.

La base est dispatchée au moment de la compilation via Tag, parmi les choix suivants : binary_heap_tag, binomial_heap_tag, pairing_heap_tag, rc_binomial_heap_tag, thin_heap_tag.

Les choix de base sont : detail::binary_heap, detail::binomial_heap, detail::pairing_heap, detail::rc_binomial_heap, detail::thin_heap.
