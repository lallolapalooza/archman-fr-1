NOM

buf-beta-registry-webhook-list - Lister les webhooks du dépôt

SYNTAXE

buf beta registry webhook list [flags]

DESCRIPTION

Lister les webhooks du dépôt

OPTIONS

-h, --help[=false] aide pour list

--owner="" Le nom du propriétaire du dépôt pour lequel lister les webhooks

--remote="" La télécommande du propriétaire et du dépôt pour lequel lister les webhooks

--repository="" Le nom du dépôt pour lequel lister les webhooks.

OPTIONS INHERITÉES DES COMMANDES PARENTES

--debug[=false] Activer la journalisation de débogage

--log-format="color" Le format du journal [text,color,json]

--timeout=0s La durée avant l'expiration, la définir à 0 signifie pas d'expiration
