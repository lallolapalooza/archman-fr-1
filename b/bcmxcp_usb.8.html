NOM

bcmxcp_usb - Pilote expérimental pour onduleurs supportant le protocole BCM/XCP sur USB

SYNTAXE

bcmxcp_usb -h

bcmxcp_usb -a NOM_ONDULEUR [OPTIONS]


Note

Cette page de manuel documente uniquement les fonctionnalités spécifiques au matériel du pilote bcmxcp_usb. Pour plus d'informations sur le pilote principal, voir nutupsdrv(8).


Note

Ce pilote est une variante du pilote série bcmxcp(8) et utilise le même code principal.

MATÉRIEL SUPPORTÉ

Ce pilote devrait reconnaître tous les onduleurs compatibles BCM/XCP connectés via USB. Il a été développé et testé sur le matériel Powerware PW3501. Il a également été testé sur le matériel PW5110.

ARGUMENTS SUPPLÉMENTAIRES

Ce pilote supporte les réglages optionnels suivants dans le fichier ups.conf(5).

shutdown_delay = delai

Le nombre de secondes que l'onduleur doit attendre entre la réception de la commande d'arrêt et l'arrêt effectif.

Note

Ce pilote ne supporte pas actuellement les paramètres de correspondance USB communs à d'autres pilotes, tels que vendor, vendorid, product, productid, serial, device ou bus.

VALEURS PAR DÉFAUT POUR LES ARGUMENTS SUPPLÉMENTAIRES

shutdown_delay =120

COMMANDES INSTANTANÉES

Ce pilote supporte les Commandes Instantanées suivantes :

shutdown.return

Éteint la charge et revient lorsque l'alimentation est rétablie.

shutdown.stayoff

Éteint la charge et reste éteint.

test.battery.start

Démarre un test de batterie.

LISTE DES AMÉLIORATIONS

Rapporter l'état de l'alarme de l'onduleur

BCM/XCP supporte le rapport d'une large gamme de conditions d'alarme de l'onduleur.

Rapporter les informations statistiques de l'onduleur

BCM/XCP supporte le rapport des données statistiques de l'onduleur.

PILOTE EXPÉRIMENTAL

Ce pilote a été marqué comme expérimental, même s'il a été rapporté comme stable. Il n'est donc pas adapté aux systèmes de production et il peut ne pas être compilé par défaut. Ceci est principalement dû au fait qu'il s'agit d'un nouveau pilote.

INSTALLATION

Ce pilote peut ne pas être compilé par défaut. Vous pouvez exiger sa compilation en utilisant `./configure --with-usb=yes` (notez que cela installera également d'autres pilotes USB) ou `./configure --with-drivers=bcmxcp_usb`. Dans tous les cas, vous aurez besoin de libusb-dev (paquet des bibliothèques et en-têtes) ou équivalent pour d'autres plateformes.

Vous devez également installer manuellement les fichiers hotplug (libhidups et libhid.usermap), généralement dans etc/hotplug/usb/, pour résoudre le problème des paramètres de permission. Enfin, notez que le fichier libhidups doit avoir le drapeau d'exécution défini (par exemple, en utilisant `chmod +x ...`).

IMPLÉMENTATION

bcmxcp_usb ne supporte qu'un seul onduleur pour le moment. Vous pouvez mettre la valeur « auto » pour le port dans ups.conf, c'est-à-dire :

[pw3105]
        driver = bcmxcp_usb
        port = auto

PROBLÈMES CONNUS ET BOGUES

Obtenu EPERM: Operation not permitted au démarrage du pilote""

Vous avez oublié d'installer les fichiers hotplug, comme expliqué dans la section INSTALLATION ci-dessus. N'oubliez pas de redémarrer hotplug pour qu'il applique ces modifications.
