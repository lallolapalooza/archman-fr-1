bin2obj(1) Convertisseur binaire en fichier d'inclusion bin2obj(1)

NOM

bin2obj - Le convertisseur de binaire en fichier d'inclusion Pascal de Free Pascal.

SYNTAXE

bin2obj [-aeouUz] -c nomconstante fichierentree

DESCRIPTION

bin2obj lit un fichier binaire et le convertit en une déclaration de constante Pascal. La constante est un tableau d'octets (commençant à l'indice 0), dans lequel chaque octet a la valeur de l'octet à l'offset index dans le fichier. (index est l'indice dans le tableau).

UTILISATION

bin2obj accepte le nom d'un fichier binaire et nécessite le nom d'une constante (utilisez l'option -c). La sortie va vers la sortie standard par défaut. Si aucun nom d'unité n'est donné, la sortie sera sous la forme de code pouvant être écrit dans un fichier d'inclusion.

OPTIONS

bin2obj a un petit nombre d'options pour contrôler son comportement :

-a
Écrit des données ASCII au lieu d'octets. Le tableau constant sera un tableau de char au lieu d'un tableau d'octets. Les octets seront écrits sous forme de constantes ASCII.
-e cle
Si cette option est donnée, les données seront chiffrées avec cle qui est une chaîne de 8 caractères.
-h
Affiche un court texte d'aide.
-o nomfichier
Par défaut, la sortie va vers la sortie standard (l'écran). Si cette option est donnée, bin2obj écrira la sortie dans un fichier nommé nomfichier à la place. Cette option est obligatoire si l'option -U est spécifiée.
-u [nomunite]
Cette option indique à bin2obj de générer une unité. Par défaut, la sortie n'est que la déclaration de la constante. Si le nom de l'unité n'est pas spécifié, bin2obj essaie de le déterminer à partir du nom du fichier d'entrée.
-U [nomunite]
Identique à l'option -u, seulement bin2obj appellera également le compilateur et compilera l'unité.
-z
Compresse les données avant de créer l'unité. La compression zlib est utilisée.
