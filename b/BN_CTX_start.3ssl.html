BN_CTX_START(3ssl) OpenSSL BN_CTX_START(3ssl)

NOM

BN_CTX_start, BN_CTX_get, BN_CTX_end - utiliser des variables temporaires BIGNUM

SYNOPSIS

#include <openssl/bn.h>
void BN_CTX_start(BN_CTX *ctx);
BIGNUM *BN_CTX_get(BN_CTX *ctx);
void BN_CTX_end(BN_CTX *ctx);

DESCRIPTION

Ces fonctions sont utilisées pour obtenir des variables BIGNUM temporaires à partir d'un BN_CTX (qui peut être créé en utilisant BN_CTX_new(3)) afin d'éviter la surcharge liée à la création et à la libération répétées de BIGNUM dans les fonctions appelées à l'intérieur d'une boucle.

Une fonction doit d'abord appeler BN_CTX_start(). Ensuite, BN_CTX_get() peut être appelé de manière répétée pour obtenir des BIGNUM temporaires. Tous les appels à BN_CTX_get() doivent être faits avant d'appeler d'autres fonctions qui utilisent le ctx comme argument.

Enfin, BN_CTX_end() doit être appelé avant de quitter la fonction. Si ctx est NULL, rien n'est fait. Lorsque BN_CTX_end() est appelé, les pointeurs BIGNUM obtenus à partir de BN_CTX_get() deviennent invalides.

VALEURS DE RETOUR

BN_CTX_start() et BN_CTX_end() ne retournent pas de valeurs.

BN_CTX_get() retourne un pointeur vers le BIGNUM, ou NULL en cas d'erreur. Une fois que BN_CTX_get() a échoué, les appels ultérieurs retourneront également NULL, il est donc suffisant de vérifier la valeur de retour du dernier appel à BN_CTX_get(). En cas d'erreur, un code d'erreur est défini, qui peut être obtenu par ERR_get_error(3).
