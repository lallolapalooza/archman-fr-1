NOM

bgltags - générer un fichier de tags pour Emacs

SYNTAXE

bgltags [ options ] [ fichier-objet [ gmon.out ] ]

DESCRIPTION

Le programme bgltags est utilisé pour créer un fichier de table de tags, dans un format compris par emacs(1). Ce programme comprend la syntaxe des fichiers Bigloo. Il lit les fichiers spécifiés sur la ligne de commande, et écrit une table de tags (par défaut : TAGS) dans le répertoire de travail courant. Les fichiers spécifiés avec des noms de fichiers relatifs seront enregistrés dans la table de tags avec des noms de fichiers relatifs au répertoire où réside la table de tags. Les fichiers spécifiés avec des noms de fichiers absolus seront enregistrés avec des noms de fichiers absolus. Le programme ne reconnaît pas le langage utilisé dans un fichier d'entrée en fonction de son nom de fichier et de son contenu. Le commutateur --language peut être utilisé pour forcer l'analyse des noms de fichiers suivant le commutateur selon le langage donné, outrepassant les suppositions basées sur les extensions de noms de fichiers. Les fichiers sources qui ne sont pas Scheme sont en fait traités par le programme etags.

OPTIONS

-a, --append
Ajouter à un fichier de tags existant.
-o nom-fichier, --output=nom-fichier
Nom explicite du fichier pour la table de tags ; outrepasse le défaut `TAGS'.
-v
Afficher la version actuelle du programme.
-module
Générer une entrée dans la table pour chaque module. Normalement, les identificateurs de modules ne sont pas indexés dans la table des tags.
