BN_CTX_new(3ssl)

Paquet: openssl

Licences: Apache-2.0

BN_CTX_NEW(3ssl) OpenSSL BN_CTX_NEW(3ssl)

NOM

BN_CTX_new_ex, BN_CTX_new, BN_CTX_secure_new_ex, BN_CTX_secure_new, BN_CTX_free - allouer et libérer des structures BN_CTX

SYNTAXE

#include <openssl/bn.h>
BN_CTX *BN_CTX_new_ex(OSSL_LIB_CTX *ctx);
BN_CTX *BN_CTX_new(void);
BN_CTX *BN_CTX_secure_new_ex(OSSL_LIB_CTX *ctx);
BN_CTX *BN_CTX_secure_new(void);
void BN_CTX_free(BN_CTX *c);

DESCRIPTION

Un BN_CTX est une structure qui contient des variables temporaires BIGNUM utilisées par les fonctions de la bibliothèque. Comme l'allocation mémoire dynamique pour créer des BIGNUM est assez coûteuse lorsqu'elle est utilisée en conjonction avec des appels de sous-routines répétés, la structure BN_CTX est utilisée.

BN_CTX_new_ex() alloue et initialise une structure BN_CTX pour le contexte de bibliothèque donné ctx. La valeur <ctx> peut être NULL, auquel cas le contexte de bibliothèque par défaut sera utilisé. BN_CTX_new() est identique à BN_CTX_new_ex(), sauf que le contexte de bibliothèque par défaut est toujours utilisé.

BN_CTX_secure_new_ex() alloue et initialise une structure BN_CTX, mais utilise le tas sécurisé (voir CRYPTO_secure_malloc(3)) pour contenir les BIGNUM pour le contexte de bibliothèque donné ctx. La valeur <ctx> peut être NULL, auquel cas le contexte de bibliothèque par défaut sera utilisé. BN_CTX_secure_new() est identique à BN_CTX_secure_new_ex(), sauf que le contexte de bibliothèque par défaut est toujours utilisé.

BN_CTX_free() libère les composants du BN_CTX et la structure elle-même. Comme BN_CTX_start() est requis pour obtenir des BIGNUM du BN_CTX, dans la plupart des cas BN_CTX_end() doit être appelé avant que le BN_CTX puisse être libéré par BN_CTX_free(). Si c est NULL, rien n'est fait.

Un BN_CTX donné ne doit être utilisé que par un seul fil d'exécution. Aucune synchronisation n'est effectuée, et l'allocateur de pool interne ne gérera pas correctement plusieurs fils d'exécution.

VALEURS DE RETOUR

BN_CTX_new() et BN_CTX_secure_new() retournent un pointeur vers le BN_CTX. Si l'allocation échoue, ils retournent NULL et définissent un code d'erreur qui peut être obtenu par ERR_get_error(3).

BN_CTX_free() n'a pas de valeurs de retour.

FONCTIONNALITÉ SUPPRIMÉE

void BN_CTX_init(BN_CTX *c);

BN_CTX_init() n'est plus disponible à partir d'OpenSSL 1.1.0. Les applications doivent remplacer l'utilisation de BN_CTX_init par BN_CTX_new à la place :

BN_CTX *ctx;
ctx = BN_CTX_new();
if (!ctx)
    /* erreur */
...
BN_CTX_free(ctx);

VOIR AUSSI

ERR_get_error(3), BN_add(3), BN_CTX_start(3)

HISTORIQUE

BN_CTX_init() a été supprimé dans OpenSSL 1.1.0.
