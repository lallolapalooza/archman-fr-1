NOM

basic_db_auth - Aide à l'authentification par base de données pour Squid

SYNOPIS

basic_db_auth [options]

DESCRIPTION

Ce programme vérifie le nom d'utilisateur et le mot de passe auprès d'une base de données.

OPTIONS

--debug
Écrit les informations de débogage sur stderr.
--dsn
DSN de la base de données. Par défaut, « DBI:mysql:database=squid ».
--user
Utilisateur de la base de données.
--password
Mot de passe de la base de données.
--table
Table de la base de données. Par défaut, « passwd ».
--usercol
Colonne du nom d'utilisateur. Par défaut, « user ».
--passwdcol
Colonne du mot de passe. Par défaut, « password ».
--cond
Condition, par défaut enabled=1. Spécifiez 1 ou « » pour aucune condition. Si vous utilisez l'option --joomla, cette condition sera modifiée en block=0.
--plaintext
La base de données contient des mots de passe en texte brut.
--md5
La base de données contient des mots de passe MD5 non salés.
--sha1
La base de données contient des mots de passe SHA1 non salés.
--salt
Sélectionne le sel correct pour évaluer les mots de passe.
--persist
Conserve une connexion persistante à la base de données entre les requêtes.
--joomla
Indique à l'aide que la base de données des utilisateurs est une base de données Joomla, de sorte que leur hachage de sel inhabituel soit compris.
