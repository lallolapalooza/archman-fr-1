NOM

blib - Utiliser la version non installée d'un paquet de MakeMaker

SYNTAXE

perl -Mblib script [args...]
perl -Mblib=dir script [args...]

DESCRIPTION

Recherche la structure de répertoire 'blib' de type MakeMaker en commençant dans dir (ou le répertoire courant) et en remontant jusqu'à cinq niveaux de '..'.

Destiné à être utilisé en ligne de commande avec l'option -M comme moyen de tester des scripts arbitraires contre une version non installée d'un paquet.

Cependant, il est possible de :

use blib;
or
use blib '..';

etc. si vous y tenez vraiment.

BOGUES

Pollue l'espace de noms global pour une tâche de développement uniquement.
