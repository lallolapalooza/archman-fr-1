NOM

bup-validate-object-links - analyse le dépôt pour les liens d'objets cassés

SYNTAXE

bup validate-object-links

DESCRIPTION

bup validate-object-links analyse les objets dans le dépôt et signale tous les « liens cassés » qu'il trouve, c'est-à-dire tout lien d'un arbre ou d'un commit dans le dépôt vers un objet qui n'existe pas. Actuellement, il n'inclut pas les « objets lâches » (ceux qui ne sont pas dans les fichiers pack – ce que git peut créer, mais bup ne crée pas), et il ne peut pas gérer les objets tag (que bup ne crée pas non plus).

Chaque fois qu'un lien cassé (référence manquante) est trouvé, une ligne encodée en ASCII formatée comme suit sera imprimée sur la sortie standard :

no MISSING_HASH for PARENT_HASH

CODE DE RETOUR

Le code de retour sera 1 si des liens cassés sont trouvés, 0 s'il n'y en a aucun, et un autre entier positif en cas d'autres échecs.

VOIR AUSSI

bup-fsck(1)

BUP
