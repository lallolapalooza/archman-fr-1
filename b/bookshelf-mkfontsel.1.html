NOM

bookshelf-mkfontsel - un script pour peupler le répertoire "fontsel" et créer le fichier "pickfont.tex" pour le paquet bookshelf

SYNTHAXE

bookshelf-mkfontsel FONTFILE

DESCRIPTION

Crée et peuple le répertoire fontsel à partir du fichier produit par le script listallfonts.pl(1), et crée le fichier "pickfont.tex". Utilisé par le paquet bookshelf.

OPTIONS

-v
Affiche les informations de version
-h
Affiche les informations d'utilisation
-m
Affiche la page de manuel
