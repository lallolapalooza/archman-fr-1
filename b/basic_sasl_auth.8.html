basic_sasl_auth(8) Manuel de l'administrateur système basic_sasl_auth(8)

NOM

basic_sasl_auth - Authentification de base utilisant SASL (spécifiquement la méthode d'authentification cyrus-sasl)

Version 1.0

SYNTAXE

basic_sasl_auth

DESCRIPTION

basic_sasl_auth est un utilitaire binaire installé pour Squid. SASL est configurable (un peu comme PAM). Chaque service s'authentifiant auprès de SASL s'identifie avec un nom d'application. Chaque application peut être configurée indépendamment par l'administrateur SASL.

CONFIGURATION

Pour configurer la méthode d'authentification utilisée, le fichier basic_sasl_auth.conf peut être placé à l'emplacement approprié, généralement /usr/lib/sasl.

La base de données d'authentification est définie par le paramètre pwcheck_method. Seul le mécanisme d'authentification PLAIN est utilisé.

Exemples : pwcheck_method:sasldb utilise sasldb - le défaut si aucun fichier de configuration n'est installé. pwcheck_method:pam
- utilise la base de données d'authentification PAM. pwcheck_method:passwd
- utilise le fichier traditionnel /etc/passwd. pwcheck_method:shadow
- utilise le fichier moins traditionnel /etc/shadow.

D'autres méthodes peuvent être prises en charge par votre implémentation de cyrus-sasl - consultez la documentation de cyrus-sasl pour plus d'informations.

Typiquement, la base de données d'authentification ( /etc/sasldb , /etc/shadow , PAM ) ne peut pas être accédée par un utilisateur normal. Vous devriez utiliser setuid/setgid et un utilisateur/groupe approprié sur l'exécutable pour permettre à l'authentificateur d'accéder à la base de données de mots de passe appropriée. Si l'accès à la base de données n'est pas autorisé, l'authentificateur échouera généralement avec « -1, generic error ».

chown root.mail basic_sasl_auth
chmod ug+s basic_sasl_auth

Si le nom de l'application basic_sasl_auth sera également utilisé pour le nom du service PAM si pwcheck_method:pam est choisi. Un exemple de fichier de configuration PAM basic_sasl_auth.pam est également inclus.
