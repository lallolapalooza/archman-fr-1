NOM

bglpp - un formatteur de code Scheme

SYNOPSIS

bglpp [ options ] fichier source

DESCRIPTION

bglpp lit le fichier source un par un et les formate. Normalement, bglpp produit son résultat sur la sortie standard.

OPTIONS

-o <fichier>
Produit les fichiers dans fichier.
-comment
Ne produit aucun commentaire Scheme.
-upper
Traduit les identifiants en majuscules.
-lower
Traduit les identifiants en minuscules.
-w<largeur>
Définit la largeur des colonnes du périphérique de sortie.

EXEMPLE

Pour formater le fichier ``foo.scm'' en traduisant les identifiants en minuscules, pour un périphérique de sortie de 50 colonnes :

``bglpp foo.scm -w50 -lower''.
