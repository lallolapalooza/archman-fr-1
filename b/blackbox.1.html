DESCRIPTIO

N

Blackbox est un gestionnaire de fenêtres pour le système de fenêtres X (X Window System) de l'Open Group, version 11 Release 6 et supérieure. Sa conception vise à être visuellement minimaliste et

rapide.

Blackbox est similaire à l'interface NeXT et à Windowmaker. Les applications sont lancées à l'aide d'un menu auquel on accède en faisant un clic droit sur la fenêtre racine. Les espaces de travail, un système de bureaux virtuels, sont contrôlés via un menu auquel on accède en faisant un clic molette sur la fenêtre racine et à l'aide de la barre d'outils. Les fenêtres individuelles peuvent être contrôlées par les boutons de la barre de titre et plus d'options sont disponibles en faisant un clic droit sur la barre de

titre.

Blackbox est capable de générer de magnifiques décorations de fenêtres à la volée et à grande vitesse. Les thèmes, appelés styles dans la terminologie de Blackbox, sont très flexibles mais l'utilisation de pixmaps a été volontairement évitée pour éliminer les dépendances et l'utilisation excessive de

mémoire.

Blackbox lui-même ne gère pas directement les raccourcis clavier comme la plupart des autres gestionnaires de fenêtres. Cette tâche est gérée par une utilitaire séparée appelée bbkeys. Bien que Blackbox ait un système d'espaces de travail (paging) intégré, bbpager, qui fournit un sélecteur graphique, est populaire auprès de nombreux utilisateurs. bbkeys, bbpager et plusieurs autres bbtools peuvent être trouvés en allant

à 
0
http://bbtools.thelinuxcommunity.org/
La
fente (slit) est un bord de l'écran qui peut contenir des programmes spécialement conçus appelés dock apps (de Windowmaker). En plus, le programme populaire gkrellm fonctionnera aussi dans la fente. Il existe une énorme sélection de dockapps disponibles et ils vont du gadget indispensable au gadget totalement inutile (mais mignon et/ou drôle) de décoration.

DÉMARRAGE ET SORTIE DE

BLACKBOX

La méthode la plus courante pour démarrer Blackbox est de placer la commande "blackbox" (sans guillemets) à la fin de votre ~/.xinitrc ou ~/.xsession. L'avantage de mettre Blackbox à la fin du fichier est que le serveur X s'arrêtera quand vous quitterez Blackbox. Blackbox peut aussi être démarré depuis la ligne de commande d'un programme terminal comme xterm dans une session X qui n'a pas déjà un gestionnaire de fenêtres en cours

d'exécution.

Au démarrage, Blackbox cherchera ~/.blackboxrc et utilisera la ressource session.menuFile pour déterminer où obtenir le menu pour la session. Si ce fichier n'est pas trouvé, Blackbox utilisera /usr/share/blackbox/menu comme fichier de menu. Si cela échoue aussi, Blackbox utilisera un menu par défaut qui contient des commandes pour démarrer un xterm ainsi que redémarrer et quitter le gestionnaire de fenêtres. Les autres ressources disponibles dans le fichier ~/.blackboxrc sont discutées plus tard dans ce manuel sous le titre FICHIER DE

RESSOURCES.

À la sortie, Blackbox écrit sa configuration actuelle dans ~/.

blackboxrc.

Ce menu donne à l'utilisateur le contrôle du système d'espaces de travail. L'utilisateur peut créer un nouvel espace de travail, supprimer le dernier espace de travail ou aller à une application via soit le menu d'icônes soit une entrée d'espace de travail. Blackbox utilise un programme externe, bbpager, pour fournir une interface de pagination graphique et traditionnelle au système d'espaces de travail. STYLE

S

Les styles sont des collections de couleurs, de polices et de textures qui contrôlent l'apparence de Blackbox. Ces caractéristiques sont enregistrées dans des fichiers de style. Les fichiers de style du système par défaut sont situés dans /usr/share/blackbox/styles. Le système de menus identifiera le style par son nom de fichier, et les styles peuvent être triés dans différents répertoires à la discrétion de

l'utilisateur.

Plus de 700 styles sont disponibles pour Blackbox. Le point de distribution officiel pour les styles de Blackbox

est 
http://blackbox.themes.
org/

Tous les thèmes devraient s'installer en les téléchargeant simplement vers ~/.blackbox/ puis en les décompressant et en les

extrayant.

Sur les Unix libres, cela sera

:

tar zxvf stylename.tar.

gz

Sur les Unix commerciaux, cela sera quelque chose comme

:

gunzip stylename.tar.gz && tar xvf stylename.

tar

Consultez les manuels de votre système pour plus de détails ou contactez votre administrateur

réseau.

Une entrée devrait apparaître immédiatement dans le menu des

styles.

FICHIER DE

MENU

Le fichier de menu par défaut est installé dans /usr/share/blackbox/menu. Ce menu peut être personnalisé en tant que menu par défaut du système ou l'utilisateur peut créer un menu

personnel.

Pour créer un menu personnel, copiez le menu par défaut dans un fichier dans votre répertoire personnel. Ensuite, ouvrez ~/.blackboxrc et ajoutez ou modifiez la ressource session.menuFile : ~/.

blackbox/menu

Ensuite, éditez le nouveau fichier de menu. Cela peut être fait pendant une session Blackbox et le menu sera automatiquement mis à jour lorsque le code vérifie les changements de

fichier.

Le menu par défaut inclus avec Blackbox contient de nombreux commentaires décrivant l'utilisation de toutes les commandes de menu. Les commandes de menu suivent cette forme générale

:

[commande] (libellé|nom_de_fichier) {commande shell|nom_de_fichier

}
Commandes de menu Blackbox
:
# chaîne.
..

valide.

e)
Cette balise n'est utilisée qu'une fois au début du fichier de menu. "chaîne" est le nom ou la description utilisée en haut du

sous-menu.

shell.

string)
Cette balise est utilisée pour insérer un séparateur dans le menu. label string est une description
optionnelle.
[submenu] (submenu name) {title

séparé.
