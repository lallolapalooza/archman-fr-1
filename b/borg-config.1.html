NOM

borg-config - obtenir, définir et supprimer des valeurs dans un fichier de configuration de dépôt ou de cache

SYNTAXE

borg [options communes] config [options] [DEPOT] [NOM] [VALEUR]

DESCRIPTION

Cette commande obtient et définit des options dans un fichier de configuration de dépôt ou de cache local. Pour des raisons de sécurité, cette commande ne fonctionne que sur les dépôts locaux.

Pour supprimer une valeur de configuration entièrement, utilisez --delete. Pour lister les valeurs du fichier de configuration ou les valeurs par défaut, utilisez --list. Pour obtenir une clé existante, ne passez que le nom de la clé. Pour définir une clé, passez à la fois le nom de la clé et la nouvelle valeur. Les clés peuvent être spécifiées au format "section.nom" ou simplement "nom"; la section sera par défaut "repository" et "cache" pour les configurations de dépôt et de cache, respectivement.

Par défaut, borg config manipule le fichier de configuration du dépôt. L'utilisation de --cache modifie le fichier de configuration du cache du dépôt à la place.

OPTIONS

Voir borg-common(1) pour les options communes des commandes Borg.

arguments

DEPOT
dépôt à configurer
NOM
nom de la clé de configuration
VALEUR
nouvelle valeur pour la clé

options

-c, --cache
obtenir et définir des valeurs à partir du cache du dépôt
-d, --delete
supprimer la clé du fichier de configuration
-l, --list
lister la configuration du dépôt

EXEMPLES

NOTE :

Les fichiers de configuration des dépôts et des caches sont parmi les rares parties directement manipulables d'un dépôt qui ne sont ni versionnées ni sauvegardées, alors soyez prudent lorsque vous apportez des modifications !
# trouver le répertoire de cache
$ cd ~/.cache/borg/$(borg config /chemin/vers/depot id)
# réserver de l'espace
$ borg config /chemin/vers/depot additional_free_space 2G
# rendre un dépôt en mode ajout uniquement
$ borg config /chemin/vers/depot append_only 1
