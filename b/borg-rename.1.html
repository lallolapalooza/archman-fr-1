NOM

borg-rename - Renommer une archive existante

SYNTAXE

borg [options communes] rename [options] ARCHIVE NOUVEAU_NOM

DESCRIPTION

Cette commande renomme une archive dans le dépôt.

Cela entraîne un identifiant d'archive différent.

OPTIONS

Voir borg-common(1) pour les options communes des commandes Borg.

arguments

ARCHIVE
archive à renommer
NOUVEAU_NOM
le nouveau nom d'archive à utiliser

EXEMPLES

$ borg create /chemin/vers/depot::nomarchive ~
$ borg list /chemin/vers/depot
nomarchive                          Lun, 2016-02-15 19:50:19
$ borg rename /chemin/vers/depot::nomarchive nouveau_nom
$ borg list /chemin/vers/depot
nouveau_nom                         Lun, 2016-02-15 19:50:19
