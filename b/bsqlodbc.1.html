NOM

bsqlodbc — processeur de scripts SQL par lots utilisant ODBC

SYNTAXE

bsqlodbc [-hqv] [-U nom_utilisateur] [-P mot_de_passe] [-S serveur] [-D base_de_donnees] [-i fichier_entree] [-o fichier_sortie] [-e fichier_erreurs] [-t delimiteur_champ] [-V version_odbc]

DESCRIPTION

bsqlodbc est un utilitaire distribué avec FreeTDS.

bsqlodbc est l'équivalent non interactif des utilitaires ‘isql’ distribués par Sybase et Microsoft. Comme eux, bsqlodbc utilise la commande ‘go’ sur une ligne seule comme séparateur entre les lots. Le dernier lot n'a pas besoin d'être suivi de ‘go’.

bsqlodbc utilise l'API ODBC fournie par FreeTDS. Cette API est bien sûr également disponible pour les développeurs d'applications.

OPTIONS

-U nom_utilisateur
Nom de connexion au serveur de base de données.
-P mot_de_passe
Mot de passe du serveur de base de données.
-S serveur
Serveur de base de données auquel se connecter.
-D base_de_donnees
Base de données à utiliser.
-i fichier_entree
Nom du fichier script, contenant le SQL.
-o fichier_sortie
Nom du fichier de sortie, contenant les données résultantes.
-e fichier_erreurs
Nom du fichier pour les erreurs.
-t delimiteur_champ
Spécifie le délimiteur de champ. Par défaut, c'est deux espaces ( ‘  ’ ). Les séquences d'échappement reconnues sont tabulation ( ‘\t’ ), retour chariot ( ‘\r’ ), nouvelle ligne ( ‘\n’ ), et antislash ( ‘\\’ ).
-h
Imprimer les en-têtes de colonnes avec les données dans le même fichier.
-q
Ne pas imprimer les métadonnées de colonne, le statut de retour, ou le nombre de lignes. Annule -h.
-v
Mode verbeux, pour plus d'informations sur l'interaction ODBC. Ceci rapporte également les métadonnées du jeu de résultats, y compris le code de retour. Toutes les données verbeuses sont écrites sur la sortie d'erreur standard (ou -e), afin de ne pas interférer avec le flux de données.
-V version_odbc
Spécifier la version ODBC (2 ou 3).

NOTES

bsqlodbc est un filtre ; il lit depuis l'entrée standard, écrit sur la sortie standard, et écrit les erreurs sur la sortie d'erreur standard. Les options -i, -o, et -e outrepassent ces valeurs par défaut.

STATUT DE SORTIE

bsqlodbc se termine avec 0 en cas de succès, et >0 si le serveur ne peut pas traiter la requête.

HISTORIQUE

bsqlodbc est apparu pour la première fois dans FreeTDS 0.65.
