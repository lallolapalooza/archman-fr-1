NOM

buildah-source-add - Ajouter un artefact source à une image source

SYNTAXE

buildah source add [options] chemin artefact

DESCRIPTION

Ajoute un artefact source à une image source. L'artefact sera ajouté sous forme de fichier tar compressé avec gzip. Add tente de créer automatiquement le fichier tar et de le compresser uniquement si nécessaire.

Notez que la commande buildah-source et toutes ses sous-commandes sont expérimentales et peuvent être sujettes à des changements futurs.

OPTIONS

--annotation clé=valeur

Ajoute une annotation au descripteur de couche dans le manifeste de l'image source. Le format d'entrée est clé=valeur.
