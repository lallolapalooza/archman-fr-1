DESCRIPTIO

N

La commande deinit déinitialise les paquets du projet spécifié (spécification-paquet), ou, si le projet lui-même est spécifié (spécification-projet), tous ses paquets précédemment initialisés, dans une ou plusieurs configurations de build (spécification-c

onfig).

Si aucun répertoire de projet n'est spécifié, le répertoire de travail courant est supposé. Si aucune configuration n'est spécifiée, les configurations par défaut sont supposées. Voir bdep-projects-configs(1) pour plus de détails su

r la spécification des proj
ets et des configurations.

DÉFAUT

Voir bdep-default-options-files(1) pour un aperçu des fichiers d'options par défaut. Pour la commande deinit, le répertoire de départ de la recherche est le répertoire du projet. Les fichiers d'options suivants sont recherchés dans chaque répertoire et, s'ils sont trouvés, chargés dans l'ordre indiqué

:
