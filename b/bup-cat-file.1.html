NOM

bup-cat-file - extraire le contenu d'une archive (bas niveau)

SYNOPIS

bup cat-file [--meta|--bupm] <chemin>

DESCRIPTION

bup cat-file extrait le contenu associé à chemin de l'archive et le déverse sur la sortie standard. Si rien de spécial n'est demandé, les données réelles contenues par chemin (qui doit être un fichier régulier) seront déversées.

OPTIONS

--meta
récupérer l'entrée de métadonnées associée à chemin. Notez que actuellement, cela ne renvoie pas les octets bruts de l'entrée enregistrée dans le fichier .bupm pertinent dans l'archive, mais plutôt une version décodée puis ré-encodée. Lorsque cela est important, il devrait être possible (bien qu'awkward) d'utiliser --bupm sur le répertoire parent, puis de trouver l'entrée pertinente dans la sortie.
--bupm
récupérer le fichier .bupm associé à chemin, qui doit être un répertoire.

EXEMPLES

# Récupérer le contenu de somefile.
$ bup cat-file /foo/latest/somefile > somefile-content
# Examiner les métadonnées associées à something.
$ bup cat-file --meta /foo/latest/something | bup meta -tvvf -
# Examiner les métadonnées de somedir, y compris les éléments qu'il contient.
$ bup cat-file --bupm /foo/latest/somedir | bup meta -tvvf -
