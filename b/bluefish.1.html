BLUEFISH(1) Commandes utilisateur BLUEFISH(1)

NOM

bluefish - éditeur pour concepteurs web et programmeurs expérimentés

SYNTAXE

bluefish [[-c|--curwindow] | [-n|--newwindow]] [FICHIER(S)...]

bluefish {[-?|--help|--help-all|--help-*] | [-v|--Version]}

DESCRIPTION

bluefish est un éditeur open-source pour concepteurs web et programmeurs expérimentés, supportant de nombreux langages de programmation et de balisage, mais se concentrant sur la création de sites web dynamiques et interactifs.

OPTIONS

bluefish supporte actuellement les options suivantes :

-c, --curwindow
Ouvre un fichier dans une fenêtre existante. Ceci peut être utilisé pour écraser la valeur par défaut choisie.
-n, --newwindow
Ouvre un fichier dans une nouvelle fenêtre. Ceci peut être utilisé pour écraser la valeur par défaut choisie.
-?, --help, --help-*, --help-all
Affiche toutes les options d'aide ou seulement un groupe d'entre elles. Certaines de ces options peuvent être documentées dans gtk-options(7) et gnome-options(7).
-v, --Version
Affiche les informations de version.

VOIR AUSSI

gnome-options(7), gtk-options(7)

Il y a aussi un manuel en ligne sur http://bluefish.openoffice.nl/manual/.
