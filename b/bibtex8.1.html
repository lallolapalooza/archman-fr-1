BIBTEX8(1) Commandes utilisateur BIBTEX8(1)

NOM

bibtex8 - BibTeX 8 bits pour les gros volumes

SYNTAXE

bibtex8 [options] fichier.aux

DESCRIPTION

BibTeX8 est une implémentation 8 bits de BibTeX écrite en C. Elle a été améliorée en ajoutant les fonctionnalités suivantes :

- Capacité « big » (32 bits) et personnalisable.

- Support flexible des langues non anglaises via des jeux de caractères 8 bits.

BibTeX8 accepte les caractères 8 bits dans ses fichiers d'entrée et écrit des caractères 8 bits dans ses fichiers de sortie. Le jeu de caractères est défini par un fichier de configuration externe — le fichier de jeu de caractères et d'ordre de tri (« CS »). Par défaut, il lit un fichier CS spécifique « 88591lat.csf », qui définit le jeu de caractères ISO 8859-1 et son ordre de tri alphabétique, y compris les caractères accentués.

OPTIONS

-? --help
affiche une brève aide.
-7 --traditional
fonctionne en mode 7 bits traditionnel, sans fichier CS. Seuls les caractères ASCII 7 bits sont pris en charge, et ils sont triés par leur code ASCII.
-8 --8bit
force le mode 8 bits, sans fichier CS. Tous les caractères 8 bits (code > 127) sont traités comme des lettres et triés par leur valeur de code.
-c --csfile FICHIER
lit FICHIER comme fichier de définition du jeu de caractères et de tri de BibTeX. Notez que les options -7, -8 et -c sont exclusives.
-d --debug TYPE
rapporte des informations de débogage. TYPE est un ou plusieurs parmi all, csf, io, mem, misc, search.
-s --statistics
rapporte les statistiques internes.
-t --trace
rapporte le traçage de l'exécution.
-v --version
rapporte la version de BibTeX.
-B --big
définit une grande capacité BibTeX.
-H --huge
définit une capacité BibTeX énorme.
-W --wolfgang
définit une capacité BibTeX vraiment énorme pour Wolfgang.
-M --min_crossrefs ##
définit min_crossrefs à ##.
--mcites ##
autorise ## \cites dans les fichiers .aux (obsolète).
--mentints ##
autorise ## entrées entières dans les bases de données .bib (obsolète).
--mentstrs ##
autorise ## entrées string dans les bases de données .bib (obsolète).
--mfields ##
autorise ## champs dans les bases de données .bib (obsolète).
--mpool ##
définit le pool de chaînes à ## octets (obsolète).
--mstrings ##
autorise ## chaînes uniques.
--mwizfuns ##
autorise ## fonctions wizard (obsolète).

SUPPORT DES LETTRES LATINES 8 BITS

BibTeX8 prend en charge des fonctionnalités étendues pour gérer les lettres latines 8 bits. Plusieurs fonctions intégrées dans les styles de bibliographie sont améliorées comme suit :

&
Dépile les deux dernières littéraux (entiers) et empile leur ET bit à bit.
|
Dépile les deux dernières littéraux (entiers) et empile leur OU bit à bit.
chr.to.int$, int.to.chr$
La fonction est identique à celle de BibTeX original, mais les caractères 8 bits sont acceptés.
width$
La fonction est identique à celle de BibTeX original, mais les lettres de Latin-1 sont prises en charge.

VOIR AUSSI

Une description plus détaillée de BibTeX8 est disponible sur $TEXMFDIST/doc/bibtex8/00readme.txt. La syntaxe du fichier de jeu de caractères et d'ordre de tri (CS) se trouve sur $TEXMFDIST/doc/bibtex8/csfile.txt.
