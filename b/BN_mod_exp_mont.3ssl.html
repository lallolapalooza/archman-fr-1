Paquet: openssl

Licences: Apache-2.0

BN_MOD_EXP_MONT(3ssl) OpenSSL BN_MOD_EXP_MONT(3ssl)

NOM

BN_mod_exp_mont, BN_mod_exp_mont_consttime, BN_mod_exp_mont_consttime_x2 - Exponentiation de Montgomery

SYNOPSIS

#include <openssl/bn.h>
int BN_mod_exp_mont(BIGNUM *rr, const BIGNUM *a, const BIGNUM *p,
                    const BIGNUM *m, BN_CTX *ctx, BN_MONT_CTX *in_mont);
int BN_mod_exp_mont_consttime(BIGNUM *rr, const BIGNUM *a, const BIGNUM *p,
                              const BIGNUM *m, BN_CTX *ctx,
                              BN_MONT_CTX *in_mont);
int BN_mod_exp_mont_consttime_x2(BIGNUM *rr1, const BIGNUM *a1,
                                 const BIGNUM *p1, const BIGNUM *m1,
                                 BN_MONT_CTX *in_mont1, BIGNUM *rr2,
                                 const BIGNUM *a2, const BIGNUM *p2,
                                 const BIGNUM *m2, BN_MONT_CTX *in_mont2,
                                 BN_CTX *ctx);

DESCRIPTION

BN_mod_exp_mont() calcule a à la puissance p modulo m ("rr=a^p % m") en utilisant la multiplication de Montgomery. in_mont est un contexte de Montgomery et peut être NULL. Si in_mont est NULL, il sera initialisé dans la fonction, vous pouvez donc gagner du temps d'initialisation si vous le fournissez à l'avance.

BN_mod_exp_mont_consttime() calcule a à la puissance p modulo m ("rr=a^p % m") en utilisant la multiplication de Montgomery. C'est une variante de BN_mod_exp_mont(3) qui utilise des fenêtres fixes et la disposition spéciale de précalcul des données pour minimiser la dépendance aux données afin de protéger les exposants secrets. Elle est appelée automatiquement lorsque BN_mod_exp_mont(3) est appelée avec les paramètres a, p, m, dont l'un quelconque a le drapeau BN_FLG_CONSTTIME.

BN_mod_exp_mont_consttime_x2() calcule deux exponentiations indépendantes a1 à la puissance p1 modulo m1 ("rr1=a1^p1 % m1") et a2 à la puissance p2 modulo m2 ("rr2=a2^p2 % m2") en utilisant la multiplication de Montgomery. Pour certaines tailles de module fixes et égales m1 et m2, elle utilise des optimisations qui permettent d'accélérer deux exponentiations. Dans tous les autres cas, la fonction se réduit à deux appels de BN_mod_exp_mont_consttime(3).

VALEUR DE RETOUR

Pour toutes les fonctions, 1 est retourné en cas de succès, 0 en cas d'erreur. Les codes d'erreur peuvent être obtenus par ERR_get_error(3).

VOIR AUSSI

ERR_get_error(3), BN_mod_exp_mont(3)
