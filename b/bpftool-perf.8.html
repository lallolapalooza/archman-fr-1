NOM

bpftool-perf - outil pour l'inspection des programmes bpf attachés à perf

SYNTAXE

bpftool [OPTIONS] perf COMMANDE

OPTIONS := { { -j | --json } [{ -p | --pretty }] | { -d | --debug } }

COMMANDES := { show | list | help }

COMMANDES PERF

bpftool perf { show | list }
bpftool perf help

DESCRIPTION

bpftool perf { show | list }
Liste toutes les attaches raw_tracepoint, tracepoint, kprobe dans le système.

La sortie commencera par l'identifiant du processus et le descripteur de fichier dans ce processus, suivi de l'identifiant du programme bpf, des informations d'attachement, et du point d'attachement. Le point d'attachement pour raw_tracepoint/tracepoint est le nom de la sonde de traçage. Le point d'attachement pour k[ret]probe est soit le nom du symbole et le décalage, soit une adresse virtuelle du noyau. Le point d'attachement pour u[ret]probe est le nom du fichier et le décalage du fichier.

bpftool perf help
Affiche un court message d'aide.

OPTIONS

-h, --help
Affiche un court message d'aide (similaire à bpftool help).
-V, --version
Affiche le numéro de version de bpftool (similaire à bpftool version), le numéro de la version de libbpf utilisée, et les fonctionnalités optionnelles qui ont été incluses lors de la compilation de bpftool. Les fonctionnalités optionnelles incluent la liaison avec LLVM ou libbfd pour fournir le désassembleur pour les programmes JIT-és (bpftool prog dump jited) et l'utilisation de squelettes BPF (certaines fonctionnalités comme bpftool prog profile ou l'affichage des pid associés aux objets BPF peuvent en dépendre).
-j, --json
Génère une sortie JSON. Pour les commandes qui ne peuvent pas produire de JSON, cette option n'a aucun effet.
-p, --pretty
Génère une sortie JSON lisible par l'homme. Implique -j.
-d, --debug
Affiche tous les journaux disponibles, y compris les informations de niveau débogage. Cela inclut les journaux de libbpf ainsi que ceux du vérificateur, lors de la tentative de chargement de programmes.
