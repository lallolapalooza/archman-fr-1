BITCOIN-WALLET(1) Commandes utilisateur BITCOIN-WALLET(1)

NOM

bitcoin-wallet - page de manuel pour bitcoin-wallet v28.1.0

DESCRIPTION

Bitcoin Core bitcoin-wallet version v28.1.0

bitcoin-wallet est un outil hors ligne pour créer et interagir avec les fichiers de portefeuille Bitcoin Core. Par défaut, bitcoin-wallet agit sur les portefeuilles dans le répertoire de portefeuille principal par défaut du datadir. Pour changer le portefeuille cible, utilisez les arguments -datadir, -wallet et -regtest/-signet/-testnet/-testnet4.

Usage :

bitcoin-wallet [options] <commande>

OPTIONS

-?

Affiche ce message d'aide et quitte

-datadir=<répertoire>

Spécifie le répertoire de données

-descriptors

Crée un portefeuille de descripteurs. Uniquement pour 'create'

-dumpfile=<nom de fichier>

Lorsqu'utilisé avec 'dump', écrit les enregistrements dans ce fichier. Lorsqu'utilisé avec 'createfromdump', charge les enregistrements dans un nouveau portefeuille.

-format=<format>

Le format du fichier de portefeuille à créer. Soit "bdb" soit "sqlite". Utilisé uniquement avec 'createfromdump'

-legacy

Crée un portefeuille hérité. Uniquement pour 'create'

-version

Affiche la version et quitte

-wallet=<nom-du-portefeuille>

Spécifie le nom du portefeuille

Options de débogage/test :

-debug=<catégorie>

Affiche les informations de débogage (par défaut : 0).

-printtoconsole

Envoie les informations de trace/débogage à la console (par défaut : 1 lorsqu'aucun -debug n'est vrai, 0 sinon).

-withinternalbdb

Utilise l'analyseur Berkeley DB interne lors de l'exportation d'un fichier de portefeuille Berkeley DB (par défaut : faux)

Options de sélection de chaîne :

-chain=<chaîne>

Utilise la chaîne <chaîne> (par défaut : main). Valeurs autorisées : main, test, testnet4, signet, regtest

-signet

Utilise la chaîne signet. Équivalent à -chain=signet. Notez que le réseau est défini par le paramètre -signetchallenge

-signetchallenge

Les blocs doivent satisfaire le script donné pour être considérés comme valides (uniquement pour les réseaux signet ; par défaut, le défi du réseau de test signet global par défaut)

-signetseednode

Spécifie un nœud d'amorçage pour le réseau signet, au format hostname[:port], par exemple sig.net:1234 (peut être utilisé plusieurs fois pour spécifier plusieurs nœuds d'amorçage ; par défaut, le(s) nœud(s) d'amorçage par défaut global(aux) du réseau de test signet)

-testnet

Utilise la chaîne testnet3. Équivalent à -chain=test. Le support de testnet3 est obsolète et sera supprimé dans une prochaine version. Envisagez de passer maintenant à testnet4 en utilisant -testnet4.

-testnet4

Utilise la chaîne testnet4. Équivalent à -chain=testnet4.

Commandes :

create
Crée un nouveau fichier de portefeuille
createfromdump
Crée un nouveau fichier de portefeuille à partir d'enregistrements exportés
dump
Affiche tous les enregistrements clé-valeur du portefeuille
info
Obtient des informations sur le portefeuille
salvage
Tente de récupérer les clés privées d'un portefeuille corrompu. Attention : 'salvage' est expérimental.
