NOM

borg-key-migrate-to-repokey - Migrer mot de passe -> repokey

SYNTAXE

borg [options communes] key migrate-to-repokey [options] [DÉPÔT]

DESCRIPTION

Cette commande migre un dépôt du mode mot de passe (supprimé dans Borg 1.0) au mode repokey.

Il vous sera d'abord demandé le mot de passe du dépôt (pour l'ouvrir en mode mot de passe). C'est le même mot de passe que vous utilisiez pour ce dépôt avant la version 1.0.

Les différents secrets seront alors dérivés de ce mot de passe.

Ensuite, il vous sera demandé un nouveau mot de passe (deux fois, par sécurité). Ce mot de passe sera utilisé pour protéger la clé du dépôt (qui contient ces mêmes secrets sous forme chiffrée). Vous pouvez utiliser le même mot de passe que celui que vous utilisiez auparavant, mais vous pouvez aussi en utiliser un différent.

Après la migration au mode repokey, vous pouvez changer le mot de passe à tout moment. Veuillez noter : les secrets resteront toujours les mêmes, et ils pourraient toujours être dérivés de votre mot de passe (ancien) en mode mot de passe.

OPTIONS

Voir borg-common(1) pour les options communes des commandes Borg.
