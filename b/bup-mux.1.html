NOM

bup-mux - multiplexe les flux de données et d'erreur sur une connexion

SYNTAXE

bup mux <commande> [options...]

DESCRIPTION

bup mux est utilisé dans le protocole client-serveur de bup pour envoyer à la fois les données et la sortie de débogage/erreur sur le flux de connexion unique.

bup mux bup server pourrait être utilisé dans une configuration de serveur inetd.

OPTIONS

commande
la commande à exécuter
options
options pour la commande

BUP

Fait partie de la suite bup(1).
