NOM

bt-obex - un client/serveur OBEX Bluetooth

SYNOPSIS

bt-obex [OPTION...]

Options d'aide :

-h, --help

Options de l'application :

-a, --adapter=<nom|mac>

-s, --server [<chemin>]

-p, --opp <nom|mac> <fichier>

-f, --ftp=<nom|mac>

DESCRIPTION

Cet utilitaire implémente la prise en charge du profil Push d'objets (OPP) et du profil de transfert de fichiers (FTP). Vous pouvez envoyer et recevoir des fichiers vers/depuis un appareil distant à l'aide de cet outil.

OPTIONS

-h, --help
Affiche l'aide

-a, --adapter <nom|mac>
Spécifie l'adaptateur à utiliser par son nom ou son adresse MAC
(si cette option n'est pas définie, l'adaptateur par défaut est utilisé)

-s, --server [<chemin>]
Enregistre un agent sur le serveur OBEX et définit le répertoire entrant/racine
sur `chemin` ou le dossier courant sera utilisé ; l'agent est utilisé pour
accepter/rejeter les requêtes entrantes de push d'objets Bluetooth

-p, --opp <nom|mac> <fichier>
Envoie le fichier local à l'appareil distant spécifié en utilisant le profil
de push d'objets

-f, --ftp <nom|mac>
Lance une session FTP avec l'appareil distant ; si la session est ouverte
avec succès, un shell FTP sera ouvert

Commandes FTP :
    help                    Affiche le message d'aide
    exit                    Ferme la session FTP
    cd <dossier>             Change le dossier courant de l'appareil distant
    mkdir <dossier>          Crée un nouveau dossier sur l'appareil distant
    ls                      Liste le contenu du dossier
    get <src> <dst>         Copie le fichier src (depuis l'appareil distant) vers le fichier dst (sur le système de fichiers local)
    put <src> <dst>         Copie le fichier src (depuis le système de fichiers local) vers le fichier dst (sur l'appareil distant)
    cp <src> <dst>          Copie un fichier sur l'appareil distant, depuis le fichier src vers le fichier dst
    mv <src> <dst>          Déplace un fichier sur l'appareil distant, depuis le fichier src vers le fichier dst
    rm <cible>              Supprime le fichier/dossier spécifié
