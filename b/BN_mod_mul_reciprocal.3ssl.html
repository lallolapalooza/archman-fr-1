BN_mod_mul_reciprocal(3ssl)

Paquet: openssl

Licences: Apache-2.0

BN_MOD_MUL_RECIPROCAL(3ssl) OpenSSL BN_MOD_MUL_RECIPROCAL(3ssl)

NOM

BN_mod_mul_reciprocal, BN_div_recp, BN_RECP_CTX_new, BN_RECP_CTX_free, BN_RECP_CTX_set - multiplication modulaire utilisant un réciproque

SYNOPSIS

#include <openssl/bn.h>
BN_RECP_CTX *BN_RECP_CTX_new(void);
void BN_RECP_CTX_free(BN_RECP_CTX *recp);
int BN_RECP_CTX_set(BN_RECP_CTX *recp, const BIGNUM *m, BN_CTX *ctx);
int BN_div_recp(BIGNUM *dv, BIGNUM *rem, const BIGNUM *a, BN_RECP_CTX *recp,
                BN_CTX *ctx);
int BN_mod_mul_reciprocal(BIGNUM *r, const BIGNUM *a, const BIGNUM *b,
                          BN_RECP_CTX *recp, BN_CTX *ctx);

DESCRIPTION

BN_mod_mul_reciprocal() peut être utilisée pour effectuer une opération efficace de BN_mod_mul(3) lorsque l'opération sera effectuée à plusieurs reprises avec le même module. Elle calcule r=(a*b)%m en utilisant recp=1/m, qui est défini comme décrit ci-dessous. ctx est un BN_CTX alloué précédemment utilisé pour les variables temporaires.

BN_RECP_CTX_new() alloue et initialise une structure BN_RECP.

BN_RECP_CTX_free() libère les composants de BN_RECP, et, s'il a été créé par BN_RECP_CTX_new(), libère également la structure elle-même. Si recp est NULL, rien n'est fait.

BN_RECP_CTX_set() stocke m dans recp et le prépare pour le calcul de 1/m et son décalage vers la gauche de BN_num_bits(m)+1 pour en faire un entier. Le résultat et le nombre de bits par lesquels il a été décalé seront stockés plus tard dans recp.

BN_div_recp() divise a par m en utilisant recp. Elle place le quotient dans dv et le reste dans rem.

La structure BN_RECP_CTX ne peut pas être partagée entre les threads.

VALEURS DE RETOUR

BN_RECP_CTX_new() retourne le BN_RECP_CTX nouvellement alloué, et NULL en cas d'erreur.

BN_RECP_CTX_free() n'a pas de valeur de retour.

Pour les autres fonctions, 1 est retourné en cas de succès, 0 en cas d'erreur. Les codes d'erreur peuvent être obtenus par ERR_get_error(3).

VOIR AUSSI

ERR_get_error(3), BN_add(3), BN_CTX_new(3)

HISTORIQUE

BN_RECP_CTX_init() a été supprimé dans OpenSSL 1.1.0
