NOM

bundle-issue - Obtenir de l'aide pour signaler des problèmes Bundler

SYNTAXE

bundle issue

DESCRIPTION

Fournit des conseils sur la façon de signaler les problèmes Bundler et affiche des informations système détaillées qui devraient être incluses lors du dépôt d'un rapport de bug. Cette commande :

1.
Affiche des liens vers les ressources de dépannage
2.
Montre des instructions pour signaler des problèmes
3.
Affiche des informations complètes sur l'environnement nécessaires au débogage

La commande permet de s'assurer que les rapports de bugs incluent tous les détails système nécessaires pour un dépannage efficace.

SORTIE

La commande génère plusieurs sections :

  • Liens et ressources de dépannage
  • Lien vers le modèle de ticket GitHub
  • Informations sur l'environnement, y compris : la version et les plateformes de Bundler, la version et la configuration de Ruby, la version et les chemins de RubyGems, les versions des outils de développement (Git, RVM, rbenv, chruby)
  • Métadonnées de construction de Bundler
  • Paramètres Bundler actuels
  • Résultat de Bundle Doctor

EXEMPLES

Obtenir des informations pour le signalement de problèmes :

$ bundle issue
