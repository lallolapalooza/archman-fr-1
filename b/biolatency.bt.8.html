NOM

biolatency.bt - Latence des I/O sur bloc sous forme d'histogramme. Utilise bpftrace/eBPF.

SYNTAXE

biolatency.bt

DESCRIPTION

Cet outil résume le temps (latence) passé dans les I/O des périphériques en bloc (I/O disque) sous forme d'histogramme de puissances de 2. Cela permet d'étudier la distribution, y compris les modes et les valeurs aberrantes. Il y a souvent deux modes, un pour les succès du cache du périphérique et un pour les échecs du cache, qui peuvent être affichés par cet outil. Les valeurs aberrantes de latence seront également affichées.

L'outil d'origine, conservé sous le nom de "biolatency-kp.bt", fonctionne actuellement en traçant dynamiquement les fonctions du noyau blk_account*(), qui devront être mises à jour pour correspondre aux éventuelles modifications de ces fonctions dans les futures versions du noyau.

La version mise à jour de l'outil utilise des tracepoints au lieu de kprobes afin d'être compatible avec une large gamme de versions du noyau.

Puisque ceci utilise BPF, seul l'utilisateur root peut utiliser cet outil.

PRÉREQUIS

CONFIG_BPF et bpftrace.

EXEMPLES

Tracer les I/O des périphériques en bloc (I/O disque) et afficher un histogramme de latence lorsque Ctrl-C est pressé :
# biolatency.bt

CHAMPS

1er, 2ème
Ceci est une plage de latence, en microsecondes (affichée en notation d'ensemble "[...").
3ème
Une colonne montrant le nombre d'opérations dans cette plage.
4ème
Ceci est un histogramme ASCII représentant la colonne de compte.

SURCHARGE

Puisque les I/O des périphériques en bloc ont généralement une fréquence relativement faible (< 10 000/s), la surcharge pour cet outil devrait être négligeable. Pour les systèmes de stockage à haute IOPS, testez et quantifiez avant utilisation.

SOURCE

Ceci vient de bpftrace.

https://github.com/bpftrace/bpftrace

Recherchez également dans la distribution bpftrace un fichier _examples.txt compagnon contenant des exemples d'utilisation, de sortie et des commentaires pour cet outil.

Ceci est une version bpftrace de l'outil bcc du même nom. L'outil bcc peut offrir plus d'options et de personnalisations.

https://github.com/iovisor/bcc
