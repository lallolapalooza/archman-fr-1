BATWATCH(1) Manuel des commandes générales BATWATCH(1)

NOM

batwatch - Surveille les changements dans les fichiers ou la sortie de commandes, et les affiche avec bat.

DESCRIPTION

UTILISATION


batwatch [OPTIONS] FICHIER...


batwatch [OPTIONS] --command COMMANDE [ARG...]

OPTIONS

Court Long Description
--command  -x
--file  -f
--watcher=[watcher] Utilise un programme externe pour surveiller les changements de fichiers. Voir ci-dessous pour plus de détails.
--interval=[secondes] L'intervalle d'exécution des commandes.
--clear Efface l'écran avant d'afficher les fichiers. Activé par défaut.
--no-clear N'efface pas l'écran avant d'afficher les fichiers.
--color Force la sortie couleur.
--no-color Désactive la sortie couleur.

Toutes les options restantes sont transmises à bat.

SURVEILLANTS

Batwatch utilise des programmes externes pour surveiller les changements de fichiers.
Actuellement, les programmes suivants sont pris en charge :

- entr

Il existe également un programme de repli poll disponible.
