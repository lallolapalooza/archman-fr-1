NOM

bt-device - un gestionnaire d'appareils Bluetooth

SYNTAXE

bt-device [OPTION...]

Options d'aide :
-h, --help

Options de l'application :
-a, --adapter=<nom|mac>
-l, --list
-c, --connect=<mac>
-d, --disconnect=<nom|mac>
-r, --remove=<nom|mac>
-i, --info=<nom|mac>
-s, --services <nom|mac> [<motif>]
--set <nom|mac> <propriété> <valeur>
-v, --verbose

DESCRIPTION

Cet utilitaire est utilisé pour gérer les appareils Bluetooth. Vous pouvez lister les appareils ajoutés, vous connecter à un nouvel appareil, déconnecter un appareil, supprimer un appareil ajouté, afficher des informations sur un appareil, découvrir les services distants de l'appareil ou modifier les propriétés de l'appareil.

OPTIONS

-h, --help
Afficher l'aide

-a, --adapter <nom|mac>
Spécifie l'adaptateur à utiliser par son nom ou son adresse MAC
(si cette option n'est pas définie, l'adaptateur par défaut est utilisé)

-l, --list
Lister les appareils ajoutés

-c, --connect <mac>
Se connecte à l'appareil distant par son MAC, récupère tous les enregistrements
SDP, puis lance l'appairage

-d, --disconnect <nom|mac>
Déconnecte un appareil distant spécifique en terminant la connexion
ACL de bas niveau.

-r, --remove
Supprime l'appareil (et également les informations d'appairage)

-i, --info
Affiche des informations sur l'appareil (renvoie toutes les propriétés)

-s, --services <nom|mac> [<motif>]
Lance la découverte des services pour récupérer les enregistrements de
services distants, le paramètre `motif` peut être utilisé pour spécifier des
UUIDs spécifiques

--set <propriété> <valeur>
Modifie les propriétés de l'appareil (voir la section PROPRIÉTÉS DE
L'APPAREIL pour la liste des propriétés disponibles)

-v, --verbose
Affiche de manière verbeuse les enregistrements de services distants
(affecte le mode de découverte des services)

PROPRIÉTÉS DE L'APPAREIL

string Address [ro]
L'adresse Bluetooth (MAC) de l'appareil distant.

string Name [ro]
Le nom de l'appareil Bluetooth distant.

string Icon [ro]
Nom d'icône proposé conformément à la spécification de nommage des
icônes de freedesktop.org.

uint32 Class [ro]
La classe de l'appareil Bluetooth distant.

list UUIDs [ro]
Liste des UUIDs sur 128 bits représentant les services distants
disponibles.

boolean Paired [ro]
Indique si l'appareil distant est appairé.

boolean Connected [ro]
Indique si l'appareil distant est actuellement connecté.

boolean Trusted [rw]
Indique si l'appareil distant est considéré comme fiable.

boolean Blocked [rw]
Si défini à vrai, toutes les connexions entrantes de l'appareil seront
immédiatement rejetées.

string Alias [rw]
L'alias du nom pour l'appareil distant. L'alias peut être utilisé
pour avoir un nom convivial différent pour l'appareil distant.

En cas d'absence d'alias, il renverra le nom de l'appareil
distant. Définir une chaîne vide comme alias le reconvertira
au nom de l'appareil distant.

boolean LegacyPairing [ro]
Défini à vrai si l'appareil ne prend en charge que le mécanisme
d'appairage pré-2.1.
