NOM

buildah-logout - Se déconnecter d'un registre de conteneurs

SYNTAXE

buildah logout [options] registre

DESCRIPTION

buildah logout se déconnecte d'un serveur de registre spécifié en supprimant les identifiants mis en cache stockés dans le fichier auth.json. Le chemin du fichier d'authentification peut être remplacé par l'utilisateur en définissant l'indicateur authfile. Le chemin par défaut utilisé est ${XDG_RUNTIME_DIR}/containers/auth.json. Voir containers-auth.json(5) pour plus d'informations. Tous les identifiants mis en cache peuvent être supprimés en définissant l'indicateur all.

buildah [OPTIONS GLOBALES]

buildah logout [OPTIONS GLOBALES]

buildah logout [OPTIONS] REGISTRE [OPTIONS GLOBALES]

OPTIONS

--all, -a

Supprimer les identifiants mis en cache pour tous les registres du fichier d'authentification

--authfile

Chemin du fichier d'authentification. Par défaut : ${XDG_RUNTIME_DIR}/containers/auth.json. Voir containers-auth.json(5) pour plus d'informations.

Note : Vous pouvez également remplacer le chemin par défaut du fichier d'authentification en définissant la variable d'environnement REGISTRY_AUTH_FILE. export REGISTRY_AUTH_FILE=chemin

--compat-auth-file=chemin

Au lieu de mettre à jour le fichier d'identifiants par défaut, mettez à jour celui situé à chemin, et utilisez un format compatible avec Docker.

--help, -h

Afficher le message d'utilisation

EXEMPLES

$ buildah logout quay.io
Removed login credentials for quay.io
$ buildah logout --authfile authdir/myauths.json quay.io
Removed login credentials for quay.io
$ buildah logout --all
Remove login credentials for all registries

VOIR AUSSI

buildah(1), buildah-login(1), containers-auth.json(5)
