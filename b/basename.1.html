BASENAME(1) Commandes utilisateur BASENAME(1)

NOM

basename - supprimer le répertoire et le suffixe des noms de fichiers

SYNTAXE

basename NOM [SUFFIXE]
basename OPTION... NOM...

DESCRIPTION

Imprime NOM avec tous les composants de répertoire de début supprimés. Si spécifié, supprime également un SUFFIXE final.

Les arguments obligatoires pour les options longues sont également obligatoires pour les options courtes.

-a, --multiple
prend en charge plusieurs arguments et traite chacun comme un NOM
-s, --suffixe=SUFFIXE
supprime un SUFFIXE final ; implique -a
-z, --zero
termine chaque ligne de sortie par NUL, pas par un saut de ligne
--help
affiche cette aide et quitte
--version
affiche les informations de version et quitte

EXEMPLES

basename /usr/bin/sort
-> "sort"
basename include/stdio.h .h
-> "stdio"
basename -s .h include/stdio.h
-> "stdio"
basename -a any/str1 any/str2
-> "str1" suivi de "str2"
