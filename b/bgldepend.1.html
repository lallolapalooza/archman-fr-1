NOM

bgldepend - créer des dépendances Bigloo dans les makefiles

SYNTAXE

bgldepend [ options ] fichier source ...

DESCRIPTION

Le programme bgldepend lit chaque fichier source en séquence et l'analyse pour trouver les directives de module include et import. bgldepend calcule la fermeture transitive de la relation d'importation. C'est-à-dire qu'il suffit de fournir à bgldepend un seul fichier Bigloo qui importe tous les fichiers du projet (par exemple, le fichier "main").

Chaque fichier qu'un fichier source inclut, directement ou indirectement, est ce que bgldepend appelle une dépendance. Ces dépendances sont ensuite écrites dans un makefile de telle sorte que make(1) sache quels fichiers objets doivent être recompilés lorsqu'une dépendance a changé.

Par défaut, bgldepend écrit sa sortie sur le périphérique de sortie standard. Si bgldepend est fourni avec l'option -o makefile, il mettra à jour le fichier makefile. C'est-à-dire qu'il recherchera dans le makefile la ligne :


# bgldepend start (ne pas éditer)

et


# bgldepend stop

Les dépendances seront écrites entre ces deux lignes.

OPTIONS

fichier
Implémente un module. Afile lit ce fichier pour découvrir le nom du module implémenté.
-chemin-recherche <chemin>
Ajoute chemin à la liste des répertoires lus pour rechercher les fichiers source Bigloo.
-exclure-chemin <chemin>
Exclut chemin de la liste des répertoires lus pour rechercher les fichiers source Bigloo.
-suffixe <suf>
Ajoute suf à la liste des suffixes de fichiers source bmake. Les suffixes par défaut sont "scm", "sch" et "bgl".
-v
Mode verbeux
-o <makefile>
Le nom du fichier makefile à mettre à jour

EXEMPLE

Normalement, bgldepend sera utilisé dans une cible makefile de sorte que taper ``make bgldepend'' mettra à jour les dépendances pour le makefile. Par exemple,


MAIN=foo.scm


SRCS = $(MAIN) bar.scm gee.scm


bgldepend:


bgldepend -o Makefile $(MAIN)
