base(3perl) Guide du programmeur Perl base(3perl)

NOM

base - Établit une relation ISA avec des classes de base au moment de la compilation

SYNTAXE

package Baz;
use base qw(Foo Bar);

DESCRIPTION

Sauf si vous utilisez le pragma "fields", considérez ce module comme déconseillé au profit de "parent", plus léger.

Permet de charger un ou plusieurs modules tout en configurant simultanément l'héritage de ces modules. L'effet est approximativement similaire à

package Baz;
BEGIN {
    require Foo;
    require Bar;
    push @ISA, qw(Foo Bar);
}

Lorsque "base" tente de "require" un module, il ne mourra pas s'il ne trouve pas le fichier du module, mais il mourra en cas de toute autre erreur. Après cela, si votre classe de base est vide, ne contenant aucun symbole, "base" mourra. Ceci est utile pour hériter de classes dans le même fichier que vous-même, mais où le nom du fichier ne correspond pas au nom du module de base, comme ceci :

# dans Bar.pm
package Foo;
sub exclaim { "I can have such a thing?!" }
package Bar;
use base "Foo";

Il n'y a pas de fichier Foo.pm, mais comme "Foo" définit un symbole (la sous-routine "exclaim"), "base" ne mourra pas lorsque la tentative de "require" échouera à charger Foo.pm.

"base" initialisera également les champs si l'une des classes de base en possède. L'héritage multiple de champs N'EST PAS pris en charge ; si deux classes de base ou plus ont chacune des champs héritables, le pragma 'base' provoquera une erreur. Voir fields pour une description de cette fonctionnalité.

La méthode "import" de la classe de base n'est pas appelée.

DIAGNOSTICS

Classe de base "%s" vide.
base.pm n'a pas pu requérir le paquet de base car il n'a pas été trouvé dans votre chemin.
La classe 'Foo' a essayé d'hériter d'elle-même
Tenter d'hériter de soi-même génère un avertissement. 
package Foo;
use base 'Foo';

HISTORIQUE

Ce module a été introduit avec Perl 5.004_04.

LIMITATIONS

En raison des limitations de l'implémentation, vous devez utiliser base avant de déclarer vos propres champs.
