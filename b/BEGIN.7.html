NOM

BEGIN - démarrer un bloc de transaction

SYNTAXE

BEGIN [ WORK | TRANSACTION ] [ mode_transaction [, ...] ]
où mode_transaction est l'un des suivants :
    NIVEAU D'ISOLATION { SERIALIZABLE | REPEATABLE READ | READ COMMITTED | READ UNCOMMITTED }
    READ WRITE | READ ONLY
    [ NOT ] DEFERRABLE

DESCRIPTION

BEGIN initie un bloc de transaction, c'est-à-dire que toutes les instructions après une commande BEGIN seront exécutées dans une unique transaction jusqu'à ce qu'un COMMIT ou ROLLBACK explicite soit donné. Par défaut (sans BEGIN), PostgreSQL exécute les transactions en mode “autocommit”, c'est-à-dire que chaque instruction est exécutée dans sa propre transaction et un commit est implicitement effectué à la fin de l'instruction (si l'exécution a été réussie, sinon un rollback est effectué).

Les instructions sont exécutées plus rapidement dans un bloc de transaction, car le démarrage/commit de transaction nécessite une activité CPU et disque importante. L'exécution de plusieurs instructions à l'intérieur d'une transaction est également utile pour garantir la cohérence lors de la réalisation de plusieurs modifications liées : les autres sessions ne pourront pas voir les états intermédiaires où toutes les mises à jour liées n'ont pas été effectuées.

Si le niveau d'isolation, le mode lecture/écriture ou le mode déferrable est spécifié, la nouvelle transaction a ces caractéristiques, comme si SET TRANSACTION avait été exécuté.

PARAMETRES

WORK
TRANSACTION

Mots-clés optionnels. Ils n'ont aucun effet.

Reportez-vous à SET TRANSACTION (SET_TRANSACTION(7)) pour des informations sur la signification des autres paramètres de cette instruction.

NOTES

START TRANSACTION a la même fonctionnalité que BEGIN.

Utilisez COMMIT ou ROLLBACK pour terminer un bloc de transaction.

Émettre BEGIN alors qu'on est déjà à l'intérieur d'un bloc de transaction provoquera un message d'avertissement. L'état de la transaction n'est pas affecté. Pour imbriquer des transactions dans un bloc de transaction, utilisez des points de sauvegarde (voir SAVEPOINT(7)).

Pour des raisons de compatibilité ascendante, les virgules entre les modes_transaction successifs peuvent être omises.

EXEMPLES

Pour commencer un bloc de transaction :

BEGIN;

COMPATIBILITE

BEGIN est une extension du langage PostgreSQL. Elle est équivalente à la commande SQL standard START TRANSACTION, dont la page de référence contient des informations de compatibilité supplémentaires.

Le mode_transaction DEFERRABLE est une extension du langage PostgreSQL.

Soit dit en passant, le mot-clé BEGIN est utilisé dans un but différent dans le SQL embarqué. Il est conseillé d'être prudent quant aux sémantiques de transaction lors de la portabilité des applications de base de données.

VOIR AUSSI
