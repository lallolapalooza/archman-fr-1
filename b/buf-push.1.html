NOM

buf-push - Pousser vers un registre

SYNTAXE

buf push [indicateurs]

DESCRIPTION

Le premier argument est la source à pousser, qui doit être l'un des formats [dir,git,protofile,tar,zip]. La valeur par défaut est "." si aucun argument n'est spécifié.

OPTIONS

--create[=false] Créer le module s'il n'existe pas. Par défaut, un module privé est créé si --create-visibility n'est pas défini.

--create-default-label="" Le réglage de l'étiquette par défaut du module, s'il est créé. Si ce n'est pas défini, le module sera créé avec l'étiquette par défaut "main".

--create-visibility="private" Le réglage de visibilité du module, s'il est créé. Ne peut être défini qu'avec --create. Doit être l'un des [public,private]

--disable-symlinks[=false] Ne pas suivre les liens symboliques lors de la lecture des sources ou de la configuration à partir du système de fichiers local. Par défaut, les liens symboliques sont suivis dans cette CLI, mais jamais suivis sur le Buf Schema Registry

--error-format="text" Le format des erreurs de compilation affichées sur stderr. Doit être l'un des [text,json,msvs,junit,github-actions,gitlab-code-quality]

--exclude-unnamed[=false] Ne pousser que les modules nommés vers le BSR. Les modules nommés ne doivent pas avoir de dépendances non nommées.

--git-metadata[=false] Utilise l'état du système de contrôle de source Git pour définir les valeurs des indicateurs. Si cet indicateur est défini, nous utiliserons les valeurs suivantes pour vos indicateurs :

--source-control-url vers <URL du dépôt Git>/<nom du dépôt>/<chemin>/<SHA du commit extrait> (par exemple, https://github.com/acme/weather/commit/ffac537e6cbbf934b08745a378932722df287a53).
--label pour chaque tag Git et branche pointant vers le commit actuellement extrait. Vous pouvez définir des étiquettes supplémentaires en utilisant --label avec cet indicateur.
--create-default-label vers la branche par défaut de Git (par exemple, main) - ceci n'est en vigueur que si --create est également défini.

L'URL du contrôle de source et la branche par défaut sont basées sur le dépôt Git distant obligatoire "origin". Cet indicateur est uniquement compatible avec les extractions de dépôts sources Git. Si vous définissez vous-même l'indicateur --source-control-url et/ou l'indicateur --create-default-label, alors la ou les valeurs seront utilisées à la place et les informations ne seront pas dérivées de l'état du contrôle de source Git.

-h, --help[=false] aide pour push

--label=[] Associer l'étiquette aux modules poussés. Peut être utilisé plusieurs fois.

--source-control-url="" L'URL pour visualiser le code source des modules poussés (par exemple, le commit spécifique dans le contrôle des sources).

OPTIONS HÉRITÉES DES COMMANDES PARENTES

--debug[=false] Activer la journalisation de débogage

--log-format="color" Le format du journal [text,color,json]

--timeout=0s La durée avant expiration, la définir à 0 signifie aucune expiration
