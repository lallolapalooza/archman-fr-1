Module Array0
: sig end

Tableaux zéro-dimensionnels. La structure Array0 fournit des opérations similaires à celles de Bigarray.Genarray , mais spécialisées pour le cas des tableaux zéro-dimensionnels qui ne contiennent qu'une seule valeur scalaire. Connaître statiquement le nombre de dimensions du tableau permet des opérations plus rapides et une vérification de type statique plus précise.

Depuis 4.05

type (!'a, !'b, !'c) t

Le type des Bigarrays zéro-dimensionnels dont les éléments ont le type OCaml 'a , le type de représentation 'b , et la disposition mémoire 'c .

val create : ('a, 'b) Bigarray.kind -> 'c Bigarray.layout -> ('a, 'b, 'c) t

Array0.create kind layout renvoie un nouveau Bigarray de dimension zéro. kind et layout déterminent le type des éléments du tableau et la disposition du tableau, comme décrit pour Bigarray.Genarray.create .

val init : ('a, 'b) Bigarray.kind -> 'c Bigarray.layout -> 'a -> ('a, 'b, 'c) t

Array0.init kind layout v se comporte comme Array0.create kind layout sauf que l'élément est en outre initialisé à la valeur v .

val change_layout : ('a, 'b, 'c) t -> 'd Bigarray.layout -> ('a, 'b, 'd) t

Array0.change_layout a layout renvoie un Bigarray avec la layout spécifiée, partageant les données avec a . Aucune copie d'éléments n'est impliquée : le nouveau tableau et le tableau original partagent le même espace de stockage.
