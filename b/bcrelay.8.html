NOM

bcrelay - un démon de relais de diffusion

SYNTAXE

bcrelay [OPTION]...

DESCRIPTION

bcrelay sert simplement de répéteur de diffusion. Lorsque bcrelay reçoit des paquets de l'interface entrante, il les relaie vers l'interface sortante.

OPTIONS

-d,--daemon
Exécuter bcrelay en tant que démon.
-p,--pidfile fichier-pid
spécifie un emplacement alternatif pour stocker le fichier d'identifiant de processus (par défaut /var/run/bcrelay.pid).
-h,--help
Afficher le message d'aide.
-i,--incoming interface-in
Définit depuis quelle interface les diffusions seront lues.
-s,--outgoing interface-out
Définit vers quelle interface les diffusions seront retransmises.
-n,--nolog
Désactive toute journalisation et trace vers /var/log/messages, à l'exception des messages d'erreur fatals.
-s,--ipsec argument
Définit un tunnel ipsec à retransmettre. Comme les tunnels ipsec se terminent sur la même interface, nous devons définir l'adresse de diffusion de l'autre point d'extrémité du tunnel. Ceci est fait comme ipsec0:x.x.x.255.
-v,--version
Afficher la version de bcrelay.
Les messages de journalisation et les informations de débogage sont envoyés à syslog en tant que démon.
Les interfaces peuvent être spécifiées comme des expressions régulières, par exemple ppp[0-9]+.
