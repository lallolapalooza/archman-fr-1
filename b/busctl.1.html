Invoquer une méthode et afficher la réponse. Prend un nom de service, un chemin d'objet, un nom d'interface et un nom de méthode. Pour plus de détails sur le format utilisé, voir ci-dessous. Pour supprimer la sortie des données retournées, utiliser l'option --quiet.

Si des paramètres doivent être passés, une chaîne de signature est requise, suivie des arguments, individuellement formatés en chaînes. Pour plus de détails sur le format utilisé, voir ci-dessous. Récupérer la valeur actuelle d'une ou plusieurs propriétés d'objet. Prend un nom de service, un chemin d'objet, un nom d'interface et un nom de propriété. Plusieurs propriétés peuvent être spécifiées à la fois, auquel cas leurs valeurs seront affichées l'une après l'autre, séparées par des sauts de ligne. La sortie est, par défaut, au format concis. Utiliser --verbose pour un format de sortie plus détaillé.

--expect-reply=BOO

L
Lorsqu'il est utilisé avec la commande call, spécifie si busctl doit attendre la fin de l'appel de méthode, afficher les données de réponse de méthode retournées, et retourner le succès ou l'échec via le code de sortie du processus. Si cette option est définie à « no », l'appel de méthode sera émis mais aucune réponse n'est attendue, l'outil se termine immédiatement, et ainsi aucune réponse ne peut être affichée, et ni succès ni échec n'est retourné via le code de sortie. Pour simplement supprimer l'affichage du contenu du message de réponse, utiliser --quiet ci-dessus. Par défaut à « yes ».

[[82]] PARAMÈTRE FORMATAGE [[84]] Les commandes call et set-property prennent une chaîne de signature suivie d'une liste de paramètres formatés en chaîne (pour plus de détails sur les chaînes de signature D-Bus, voir le chapitre sur le système de types de la spécification D-Bus[2]). Pour les types simples, chaque paramètre suivant la signature devrait simplement être la valeur du paramètre formatée en chaîne. Les valeurs booléennes positives peuvent être formatées comme « true », « yes », « on » ou « 1 » ; les valeurs booléennes négatives peuvent être spécifiées comme « false », « no », « off » ou « 0 ».
