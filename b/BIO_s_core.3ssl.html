BIO_s_core(3ssl)

Paquet: openssl

Licences: Apache-2.0

BIO_S_CORE(3ssl) OpenSSL BIO_S_CORE(3ssl)

NOM

BIO_s_core, BIO_new_from_core_bio - Fonctions OSSL_CORE_BIO

SYNTAXE

#include <openssl/bio.h>
const BIO_METHOD *BIO_s_core(void);
BIO *BIO_new_from_core_bio(OSSL_LIB_CTX *libctx, OSSL_CORE_BIO *corebio);

DESCRIPTION

BIO_s_core() renvoie la fonction de méthode BIO de cœur.

Un BIO de cœur est traité comme un BIO source/destination qui communique avec un BIO externe. Ceci est principalement utile aux auteurs de fournisseurs. Un certain nombre d'appels de libcrypto vers un fournisseur fournissent un paramètre OSSL_CORE_BIO. Ceci représente un BIO au sein de libcrypto, mais ne peut pas être utilisé directement par un fournisseur. Il doit plutôt être encapsulé à l'aide de BIO_s_core().

Une fois qu'un BIO est construit sur la base de BIO_s_core(), l'objet OSSL_CORE_BIO associé doit lui être défini à l'aide de BIO_set_data(3). Notez que le BIO ne fonctionnera correctement que s'il est associé à un contexte de bibliothèque construit à l'aide de OSSL_LIB_CTX_new_from_dispatch(3). Pour associer le BIO à un contexte de bibliothèque, construisez-le à l'aide de BIO_new_ex(3).

BIO_new_from_core_bio() est une fonction utilitaire qui construit un nouveau BIO basé sur BIO_s_core() et qui est associé au contexte de bibliothèque donné. Il définit ensuite également l'objet OSSL_CORE_BIO sur le BIO à l'aide de BIO_set_data(3).

VALEURS DE RETOUR

BIO_s_core() renvoie une structure BIO_METHOD de cœur pour BIO.

BIO_new_from_core_bio() renvoie une structure BIO en cas de succès ou NULL en cas d'échec. Un échec est le plus souvent dû au fait que le contexte de bibliothèque n'a pas été construit à l'aide de OSSL_LIB_CTX_new_from_dispatch(3).

HISTORIQUE

BIO_s_core() et BIO_new_from_core_bio() ont été ajoutés dans OpenSSL 3.0.

EXEMPLES

Créer un BIO de cœur et y écrire des données :

int some_function(OSSL_LIB_CTX *libctx, OSSL_CORE_BIO *corebio) {
    BIO *cbio = BIO_new_from_core_bio(libctx, corebio);
    if (cbio == NULL)
        return 0;
    BIO_puts(cbio, "Hello World\n");
    BIO_free(cbio);
    return 1;
}
