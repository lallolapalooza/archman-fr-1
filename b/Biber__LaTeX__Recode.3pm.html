NOM

Biber::LaTeX::Recode - Encoder/Décoder des caractères vers/depuis UTF-8/lacros en LaTeX

SYNTAXE

use Biber::LaTeX:Recode
my $string = 'Muḥammad ibn Mūsā al-Khwārizmī';
my $latex_string = latex_encode($string);
    # => 'Mu\d{h}ammad ibn M\=us\=a al-Khw\=arizm\={\i}'
my $string = 'Mu\d{h}ammad ibn M\=us\=a al-Khw\=arizm\={\i}';
my $utf8_string   = latex_decode($string);
    # => 'Muḥammad ibn Mūsā al-Khwārizmī'

DESCRIPTION

Permet la conversion entre les caractères Unicode et les macros LaTeX.

OPTIONS GLOBALES

Les valeurs possibles pour l'ensemble d'encodage/décodage à utiliser sont 'null', 'base' et 'full' ; la valeur par défaut est 'base'.

null => Pas de conversion

base => Macros et diacritiques les plus courants (suffisant pour les langues occidentales
et les symboles courants)

full => Convertit également la ponctuation, une plus large gamme de diacritiques et de macros
(par exemple pour l'API, le Latin Étendu Supplémentaire, etc.), les symboles, les lettres grecques,
les dingbats, les symboles niés, et les caractères et symboles en exposant ...

init_sets(<ensemble_décodage>, <ensemble_encodage>)

Initialise les ensembles de recodage. Nous ne pouvons pas le faire lors du chargement du module car nous n'avons pas encore les informations de configuration pour le faire

latex_decode($texte, @options)

Convertit les macros LaTeX dans $texte en caractères Unicode.

La fonction accepte un certain nombre d'options :

* normalize => $bool (défaut 1)
    si la chaîne de sortie doit être normalisée avec Unicode::Normalize
* normalization => < forme de normalisation > (défaut 'NFD')
    et si oui, la forme de normalisation à utiliser (voir la documentation de Unicode::Normalize)

latex_encode($texte, @options)

Convertit UTF-8 en LaTeX
