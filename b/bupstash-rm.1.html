bupstash-rm(1)

Paquet: bupstash

Licences: MIT

() ()

SYNTAXE

Supprime des éléments d'un dépôt bupstash.

bupstash rm [OPTIONS] REQUÊTE...

DESCRIPTION

bupstash rm supprime des éléments d'un dépôt bupstash.

Les éléments supprimés ne sont pas immédiatement effacés, leur suppression et la récupération d'espace sont planifiées pour la prochaine exécution du collecteur de déchets bupstash-gc(1).

Seules les métadonnées doivent être déchiffrées pour supprimer des éléments, une clé de métadonnées est donc suffisante pour la suppression d'éléments, même sans accès à la clé de déchiffrement des données.

LANGAGE DE REQUÊTE

Pour une documentation complète sur le langage de requête, consultez bupstash-query-language(7).

Exemples de requêtes de suppression

``` $ id=$(bupstash put ./some-data)

$ bupstash rm id=$id

$ bupstash rm name=backups.tar

$ bupstash rm --allow-many name='*.tar' and older-than 30d

$ bupstash rm --allow-many id="*" ```

MISE EN CACHE DES REQUÊTES

La commande rm utilise les mêmes mécanismes de mise en cache des requêtes que bupstash-list(1), consultez cette page pour plus d'informations sur le cache des requêtes.

OPTIONS

-r, --repository REPO
Le dépôt auquel se connecter. Peut être de la forme ssh://$SERVER/$PATH pour les dépôts distants si l'accès ssh est configuré. S'il n'est pas spécifié, il est défini sur BUPSTASH_REPOSITORY.
-k, --key CLÉ
Clé utilisée pour déchiffrer les métadonnées lors de l'exécution d'une requête. Si elle n'est pas définie, elle utilise par défaut BUPSTASH_KEY.
--query-cache CHEMIN
Chemin d'accès au fichier de cache de requêtes, par défaut l'un des suivants, dans l'ordre, à condition que les variables d'environnement appropriées soient définies : $BUPSTASH_QUERY_CACHE, $XDG_CACHE_HOME/.cache/bupstash/bupstash.qcache ou $HOME/.cache/bupstash/bupstash.qcache.
--query-encrypted
La requête ne déchiffrera aucune métadonnée, vous permettant de lister des éléments pour lesquels vous n'avez pas de clé de déchiffrement. Cette option insère la balise de pseudo-requête 'decryption-key-id'.
--ids-from-stdin
Supprime les éléments dont les IDs sont lus depuis stdin, un par ligne, au lieu d'exécuter une requête.
--allow-many
Par défaut, bupstash refuse de supprimer plusieurs éléments d'une seule requête, ce drapeau désactive cette fonction de sécurité.
--utc-timestamps
Affiche et recherche par rapport aux horodatages en temps UTC au lieu de l'heure locale.
--no-progress
Supprime les indicateurs de progression (les indicateurs de progression sont également supprimés lorsque stderr n'est pas un terminal interactif).
-q, --quiet
Soyez silencieux, implique --no-progress.

ENVIRONNEMENT

BUPSTASH_REPOSITORY
Le dépôt auquel se connecter. Peut être de la forme ssh://$SERVER/$PATH pour les dépôts distants si l'accès ssh est configuré.
BUPSTASH_REPOSITORY_COMMAND
Une commande à exécuter pour se connecter à une instance de bupstash-serve(1). Cela permet des connexions plus complexes au dépôt pour des cas d'utilisation moins courants.
BUPSTASH_KEY
Chemin d'accès à une clé principale qui sera utilisée pour déchiffrer les données et les métadonnées.
BUPSTASH_KEY_COMMAND
Une commande à exécuter qui doit imprimer les données de la clé, peut être utilisée à la place de BUPSTASH_KEY pour récupérer la clé à partir d'emplacements arbitraires tels que le réseau ou d'autres stockages secrets.
BUPSTASH_QUERY_CACHE
Chemin d'accès au fichier de cache des requêtes à utiliser.

EXEMPLES

Supprimer un élément avec un ID spécifique du dépôt

$ bupstash rm id=14ebd2073b258b1f55c5bbc889c49db4

Supprimer tous les éléments du dépôt

$ bupstash rm id="*"

Supprimer les éléments nommés backup.tar qui sont plus anciens que 30 jours

$ bupstash rm name=backup.tar and older-than 30d

Supprimer des éléments avec un script personnalisé

$ bupstash list --format=jsonl1 \ | custom-json-filter \ | bupstash rm --ids-from-stdin
