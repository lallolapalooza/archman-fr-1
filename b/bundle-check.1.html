BUNDLE-CHECK(1) Manuel des commandes générales BUNDLE-CHECK(1)

NOM

bundle-check - Vérifie si les dépendances sont satisfaites par les gems installés

SYNOPSIS

bundle check [--dry-run] [--gemfile=FICHIER] [--path=CHEMIN]

DESCRIPTION

check recherche sur la machine locale chacune des gems demandées dans le Gemfile. Si toutes les gems sont trouvées, Bundler affiche un message de succès et se termine avec un statut de 0.

Sinon, la première gem manquante est listée et Bundler se termine avec un statut de 1.

Si le lockfile doit être mis à jour, il sera résolu en utilisant les gems installées sur la machine locale, si elles satisfont les exigences.

OPTIONS

--dry-run
Verrouille le [Gemfile(5)][Gemfile(5)] avant d'exécuter la commande.
--gemfile=FICHIER
Utilise le gemfile spécifié au lieu du [Gemfile(5)][Gemfile(5)].
--path=CHEMIN
Spécifie un chemin différent de celui par défaut du système ($BUNDLE_PATH ou $GEM_HOME). Bundler mémorisera cette valeur pour les installations futures sur cette machine.
