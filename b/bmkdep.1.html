MKDEP(1) Manuel des commandes générales MKDEP(1)

NOM

mkdep — construire une liste de dépendances pour Makefile

SYNTAXE

mkdep [-aDdiopqv] [-f fichier] [-P préfix] [-s suffixes] -- [flags] fichier ...

DESCRIPTION

mkdep prend un ensemble d'options pour le compilateur C et une liste de fichiers sources C comme arguments, et construit un ensemble de dépendances de fichiers d'inclusion qui sont écrites dans le fichier ``.depend''. Un exemple de son utilisation dans un Makefile pourrait être :

CFLAGS= -O -I../include
SRCS= file1.c file2.c

depend:
	mkdep -- ${CFLAGS} ${SRCS}

où la macro SRCS est la liste des fichiers sources C et la macro CFLAGS est la liste des options pour le compilateur C.

Les options sont les suivantes :

-a
Ajoute au fichier de sortie, de sorte que plusieurs mkdep puissent être exécutés à partir d'un seul Makefile.
-D
Post-traitement (comme -d) mais lit la liste des noms de fichiers à partir de l'entrée standard.
-d
Post-traitement et fusion des fichiers de dépendance précédemment créés (par exemple par “cc -MD x.c”) en un seul fichier.
-f
Écrit les dépendances des fichiers d'inclusion dans fichier, au lieu du défaut ``.depend''.
-i
Lorsque -d ou -D est utilisé, au lieu d'intégrer le contenu des fichiers dans le fichier de dépendance résultant, utilise des instructions d'inclusion pour inclure les fichiers de dépendance source.
-o
Ajoute une ligne .OPTIONAL supplémentaire pour chaque fichier dépendant.
-P
Prépare la chaîne donnée dans préfix à chaque nom de fichier cible. Ceci est utile pour les programmes qui ont des fichiers source dans plusieurs sous-répertoires et un seul Makefile qui les référence tous explicitement (sans utiliser la fonctionnalité VPATH car il peut y avoir des fichiers portant le même nom dans chaque sous-répertoire).
-p
Fait en sorte que mkdep produise des dépendances de la forme : 
programme: programme.c

afin que les constructions ultérieures produisent programme directement à partir de son module C plutôt que d'utiliser un module .o intermédiaire. Ceci est utile pour les programmes dont la source est contenue dans un seul module. -p est équivalent à spécifier un suffixe nul avec -s.

-q
N'affiche pas d'avertissement pour les fichiers inaccessibles lorsque -d est donné.
-s
Développe chaque nom de fichier cible en une liste, en remplaçant le suffixe ‘.o’ par chaque élément de suffixes. La liste des suffixes peut être séparée par des espaces ou des virgules.
-v
affiche la sortie de débogage.

FICHIERS

.depend
Fichier contenant la liste des dépendances.

VOIR AUSSI

cc(1), cpp(1), make(1)

HISTORIQUE

La commande mkdep est apparue dans 4.3BSD-Tahoe.

BOGUES

Certains caractères spéciaux pour make(1), notamment le caractère de commentaire, ne sont pas échappés correctement s'ils apparaissent dans les noms de fichiers. Cela peut entraîner une sortie non analysable ou la perte silencieuse de dépendances.
