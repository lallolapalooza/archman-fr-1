NOM

bup-ftp - client de type ftp pour naviguer dans les dépôts bup

SYNTAXE

bup ftp

DESCRIPTION

bup ftp est un outil en ligne de commande pour naviguer dans les dépôts bup. Il possède des commandes similaires à la commande ftp(1) de Unix. La hiérarchie des fichiers est la même que celle affichée par bup-fuse(1) et bup-ls(1).

Remarque : si votre système a la bibliothèque python-readline installée, vous pouvez utiliser la touche <tab> pour compléter les noms de fichiers lors de la navigation dans vos données de sauvegarde. Cela vous évitera beaucoup de frappe.

COMMANDES

Les commandes suivantes sont disponibles dans bup ftp :

ls [-s] [-a] [chemin]
affiche le contenu d'un répertoire. Si aucun argument de chemin n'est donné, le contenu du répertoire courant est listé. Si -a est donné, inclure également les fichiers cachés (fichiers commençant par un caractère .). Si -s est donné, chaque fichier est affiché avec son hachage de l'archive bup à sa gauche.
cd nom_répertoire
change de répertoire de travail
pwd
affiche le chemin du répertoire de travail courant
cat noms_fichiers...
affiche le contenu d'un ou plusieurs fichiers sur stdout
get nom_fichier nom_local
télécharge le contenu de nom_fichier et l'enregistre sur le disque en tant que nom_local. Si nom_local est omis, utilise nom_fichier comme nom local.
mget noms_fichiers...
télécharge le contenu des noms_fichiers donnés et les stocke sur le disque sous les mêmes noms. Les noms de fichiers peuvent contenir des jokers de nom de fichier Unix (*, ?, etc.)
help
affiche une liste des commandes disponibles
quit
quitte le client bup ftp

EXEMPLES

$ bup ftp
bup> ls
mybackup/    yourbackup/
bup> cd mybackup/
bup> ls
2010-02-05-185507@   2010-02-05-185508@    latest@
bup> cd latest/
bup> ls
  (...etc...)
bup> get myfile
Saving 'myfile'
bup> quit
