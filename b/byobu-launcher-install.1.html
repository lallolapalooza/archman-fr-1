NOM

byobu-launcher-install - utilitaire d'installation du lanceur Byobu

SYNOPIS

byobu-launcher-install [-n|--no-logout]

DESCRIPTION

byobu-launcher-install(1) est un utilitaire simple qui ajoutera une ligne à votre fichier $HOME/.profile qui lancera byobu(1) à chaque connexion via ssh(1) ou sur une console(4).

Par défaut, lorsque les utilisateurs se détachent de la session byobu(1), ils se déconnectent également. Les utilisateurs peuvent modifier ce comportement en ajoutant l'option [-n|--no-logout] lorsqu'ils exécutent byobu-launcher-install(1).

Vous pouvez désactiver ce comportement entièrement à tout moment avec l'utilitaire byobu-launcher-uninstall(1).
