OPTIONS-h , --hel
p
Imprimer un court message d'aide (similaire à bpftool help.
-V, --version
Affiche le numéro de version de bpftool (similaire à bpftool version), le numéro de la version de libbpf utilisée et les fonctionnalités optionnelles qui ont été incluses lors de la compilation de bpftool. Les fonctionnalités optionnelles incluent la liaison avec LLVM ou libbfd pour fournir le désassembleur pour les programmes JIT-ted (bpftool prog dump jited) et l'utilisation de squelettes BPF (certaines fonctionnalités comme bpftool prog profile ou l'affichage des PIDs associés aux objets BPF peuvent en dépendre).
-j, --json
Génère une sortie JSON. Pour les commandes qui ne peuvent pas produire de JSON, cette option n'a aucun effet.
-p, --pretty
Génère une sortie JSON lisible par l'homme. Implique -j.
-d, --debug
Affiche tous les logs disponibles, y compris les informations de niveau débogage. Cela inclut les logs de libbpf ainsi que ceux du vérificateur, lorsqu'on tente de charger des programmes.
-f, --bpffs
Affiche les noms de fichiers des maps épinglées.
-n, --nomount
N'essaie pas automatiquement de monter un système de fichiers virtuel (tel que tracefs ou le système de fichiers virtuel BPF) lorsque cela est nécessaire.

Notez que la mise à jour de map peut également être utilisée pour modifier les références de programmes détenues par une map de type prog_array. Ceci peut être utilisé, par exemple, pour modifier les programmes utilisés pour les sauts tail-call à l'exécution, sans avoir à recharger le programme d'entrée. Ci-dessous un exemple pour ce cas d'utilisation : nous chargeons un programme définissant une map de type prog_array, et avec une fonction principale contenant un tail call vers d'autres programmes qui peuvent être utilisés soit pour "traiter" les paquets, soit pour "déboguer" le traitement. Notez que la map prog_array DOIT être épinglée dans le système de fichiers virtuel BPF pour que la mise à jour de la map fonctionne, car le noyau vide les maps prog_array lorsqu'elles n'ont plus de références depuis l'espace utilisateur (et la mise à jour serait perdue dès que bpftool se termine).
