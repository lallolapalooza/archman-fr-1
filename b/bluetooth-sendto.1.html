NOM

bluetooth-sendto - Application GTK pour le transfert de fichiers via Bluetooth

SYNTAXE

bluetooth-sendto [--device=XX:XX:XX:XX:XX:XX [--name=NOM]] [fichier...]

DESCRIPTION

bluetooth-sendto affiche une boîte de dialogue pour le transfert de fichiers via Bluetooth. bluetooth-sendto fait partie de gnome-bluetooth, voir aussi https://wiki.gnome.org/Projects/GnomeBluetooth

OPTIONS

--device
Définit l'adresse de l'appareil vers lequel envoyer le(s) fichier(s).
--name
Définit le nom de l'appareil vers lequel envoyer le(s) fichier(s). S'il est omis, il sera détecté automatiquement.
fichier
Le(s) fichier(s) à envoyer à l'appareil. S'il est omis, un sélecteur sera affiché.
