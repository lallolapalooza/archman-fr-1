NOM

bdftruncate - générer une police BDF tronquée à partir d'une police BDF encodée ISO 10646-1

SYNTAXE

bdftruncate seuil < source.bdf > destination.bdf

DESCRIPTION

bdftruncate permet de générer à partir d'une police BDF encodée ISO10646-1 d'autres polices BDF ISO10646-1 dans lesquelles tous les caractères supérieurs à une valeur de code seuil sont stockés sans encodage. Ceci est souvent souhaitable car l'API Xlib et les structures de données du protocole X11 utilisées pour représenter les informations métriques de police sont extrêmement inefficaces lorsqu'elles traitent des polices peu remplies.

EXEMPLE

La commande

bdftruncate 0x3200 < 6x13.bdf > 6x13t.bdf
générera le fichier 6x13t.bdf dans lequel tous les glyphes ayant des codes >= 0x3200 ne seront stockés que sans encodage (c'est-à-dire qu'ils sont codés au point de code -1).
