NOM

btrfs-select-super - écraser le superbloc primaire avec une copie de sauvegarde

SYNTAXE

btrfs-select-super -s nombre <périphérique>

DESCRIPTION

Écrase de manière destructive toutes les copies du superbloc avec une copie spécifiée. Cela aide dans certains cas, par exemple lorsque les barrières d'écriture ont été désactivées lors d'une panne de courant et que tous les superblocs n'ont pas été écrits, ou si le superbloc primaire est endommagé, par exemple accidentellement écrasé.

Le système de fichiers spécifié par périphérique ne doit pas être monté.

Remarque :

Avant d'écraser le superbloc primaire, assurez-vous que les copies de sauvegarde sont valides !

Pour sauvegarder un superbloc, utilisez la commande btrfs inspect-internal dump-super.

Ensuite, exécutez la vérification (en mode non-réparation) en utilisant la commande btrfs check -s où -s spécifie la copie du superbloc à utiliser.

Les copies du superbloc existent aux décalages suivants sur le périphérique :

  • primaire : 64Ko (65536)
  • 1ère copie : 64Mo (67108864)
  • 2ème copie : 256Go (274877906944)

Une taille de superbloc est de 4Ko (4096).

OPTIONS

-s|--super <N>
utiliser la N-ième copie du superbloc, les valeurs valides sont 0, 1 ou 2 si le décalage du superbloc respectif est dans la taille du périphérique
