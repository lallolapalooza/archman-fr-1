NOM

bookman - Génère un livre à partir de pages de manuel

SYNTAXE

bookman [-pPxn] [-o fichier_sortie] [-a auteur] [-d date] [-r version]
[-t titre] [-v volume] [-c fichier_couverture] [fichier_manuel]

DESCRIPTION

bookman compile un ensemble de fichiers de pages de manuel spécifiés par les arguments fichier_manuel, ou si aucun fichier_manuel n'est donné, les noms de fichiers sont lus depuis l'entrée standard.

OPTIONS

-p
Format de sortie PDF.
-P
Format de sortie Postscript.
-x
Aperçu X11, en utilisant gxditview(1).
-n
Pas de formatage, la sortie est au format intermédiaire gtroff direct.
-o fichier_sortie
Sortie dans le fichier fichier_sortie. Par défaut, sortie standard.
-a auteur
Définit l'*auteur*, sur la page de couverture.
-d date
Définit la *date* sur la page de couverture.
-r version
Définit le nom du livre et la *version* sur la page de couverture.
-t titre
Définit le *titre* sur la page de couverture.
-v volume
Spécifie le nom du *volume*.
-c fichier_couverture
Utilise le fichier fichier_couverture pour générer la page de couverture, c'est-à-dire toutes les pages précédant la table des matières. Le fichier_couverture doit être au format groff_ms(7).

ENVIRONNEMENT

SOURCE_DATE_EPOCH
Horodatage Unix utilisé pour la *date* dans l'en-tête au lieu de la *date* actuelle.

EXEMPLE

Pour construire un manuel de référence à partir de la section 2 des manuels, faites :

    $ cd /usr/share/man/man2
    $ bookman -p -t 'Manuel de référence Unix' * >livre.pdf

VOIR AUSSI

man(1), mandoc(7), groff_ms(7), groff(1), troff(1), grops(1), gxditview(1), ps2pdf(1).
