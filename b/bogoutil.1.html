DESCRIPTIO

N

Bogoutil fait partie du paquet de filtre anti-spam bayésien

bogofilter.

Il est utilisé pour vider et charger les bases de données Berkeley DB de bo

gofilter depuis et vers des fichiers texte, effectuer des fonctions de mai
ntenance de la base de données et afficher les valeurs de mots spécifiques.

OPTION

S

L'option -d fichier indique à bogoutil d'afficher le contenu du fichier de base de données sur stdout

.

L'option -H fichier indique à bogoutil d'afficher un histogramme du fichier de base de données sur stdout. La sortie est similaire à celle de bogofilter -vv. Enfin, les hapaxes (jetons vus une seule fois) et les jetons purs (jetons rencontrés uniquement dans du courrier légitime ou uniquement dans du spam) sont

comptés.

L'option -l fichier indique à bogoutil de charger les données de stdin dans le fichier de base de données. Si le fichier de base de données existe, les données de stdin sont fusionnées dans le fichier de base de données, avec addition des

compteurs.

L'option -m indique à bogoutil d'effectuer des fonctions de maintenance sur la base de données spécifiée, c'est-à-dire de supprimer les jetons qui sont plus anciens que souhaité, ont des compteurs trop faibles, ou des tailles (longueurs) trop longues ou trop

courtes.

L'option -w fichier indique à bogoutil d'afficher les informations sur les jetons du fichier de base de données. L'option prend un argument, qui est soit le nom de la liste de mots (généralement wordlist.db) soit le nom du répertoire la contenant. Les jetons peuvent être listés sur la ligne de commande ou envoyés par pipe à bogoutil. Lorsqu'il y a des arguments supplémentaires sur la ligne de commande, bogoutil les utilisera comme jetons à rechercher. S'il n'y a pas d'arguments supplémentaires, bogoutil lira les jetons depuis stdin

.

L'option -p fichier indique à bogoutil d'afficher les informations de la base de données pour un ou plusieurs jetons. L'affichage inclut une colonne de probabilité avec le score spam du jeton (calculé à l'aide des valeurs par défaut de bogofilter). L'option -p prend les mêmes arguments que l'option -w

.

L'option -r fichier indique à bogoutil de recalculer la valeur ROBX et de l'afficher sous forme de fraction à six

chiffres.

L'option -R fichier fait la même chose que -r, mais enregistre le résultat dans la base de données d'entraînement sans

l'afficher.

L'option -I fichier indique à bogoutil de lire son entrée depuis fichier plutôt que depuis

stdin.

L'option -O fichier indique à bogoutil d'écrire sa sortie dans fichier plutôt que sur

stdout.

L'option -v produit une sortie verbeuse sur stderr. Cette option est principalement utile pour le

débogage.

L'option -C empêche la lecture des fichiers de configuration et permet à bogoutil d'utiliser les valeurs par

défaut.

L'option --config-file fichier indique à bogoutil de lire fichier au lieu du fichier de configuration

standard.

L'option -D redirige la sortie de débogage vers stdout (elle va généralement vers stderr)

.

L'option -x drapeaux définit les drapeaux de

débogage.

L'option -n signifie "remplacer les caractères non-ascii". Elle remplacera les caractères ayant le bit haut (0x80) par des points d'interrogation. Cela peut être utile si une liste de mots contient de nombreux jetons illisibles, par exemple provenant de spams en caractères asiatiques. Les caractères "mauvais" seront convertis en points d'interrogation et les jetons correspondants seront combinés lorsqu'ils sont utilisés avec -m ou -l, mais pas avec -d

.

L'option -a âge indique un âge de jeton acceptable, les plus anciens étant supprimés. L'âge peut être une date (sous la forme AAAAMMJJ) ou un nombre de jours, c'est-à-dire supprimer les jetons plus vieux que âge jou

rs.

L'option -c valeur indique que les jetons dont les compteurs sont inférieurs ou égaux à valeur doivent être

supprimés.

L'option -s min,max est utilisée pour supprimer des jetons en fonction de leur taille, c'est-à-dire leur longueur. Tous les jetons plus courts que min ou plus longs que max seront

supprimés.

L'option -y date spécifie la date à donner aux jetons qui n'ont pas de date. Le format est

AAAAMMJJ.

L'option -h affiche le message d'aide et se

termine.

L'option -V affiche le numéro de

version et
se termine.

ENVIRONNEMENT

MAINTENANCE

L'option --db-checkpoint répertoire fait que bogoutil vide les caches tampons et crée un point de contrôle de l'environnement de la base de

données.

L'option --db-list-logfiles répertoire fait que bogoutil liste les fichiers journal dans l'environnement. Zéro ou plusieurs mots-clés peuvent être ajoutés ou combinés (séparés par des espaces) pour modifier le comportement de ce mode. Le comportement par défaut est de lister uniquement les fichiers journal inactifs avec des chemins relatifs. Vous pouvez ajouter all pour lister tous les fichiers journal (inactifs et actifs). Vous pouvez ajouter absolute pour passer la liste à des chemins

absolus.

L'option --db-prune répertoire fait que bogoutil crée un point de contrôle de l'environnement de la base de données et supprime les fichiers journal

inactifs.

L'option --db-recover répertoire exécute une récupération normale de la base de données dans le répertoire de base de données spécifié. Si cela échoue, elle réessaiera avec une récupération catastrophique de la base de données (généralement plus lente). Si cela échoue aussi, votre base de données ne peut pas être réparée et doit être reconstruite à partir de zéro. Cela n'est pris en charge que lorsqu'il est compilé avec le support Berkeley DB avec les transactions activées. Tenter une récupération avec le support QDBM ou SQLite3 entraînera une

erreur.

L'option --db-recover-harder répertoire exécute une récupération catastrophique de la base de données dans le répertoire de base de données spécifié. Si cela échoue, votre base de données ne peut pas être réparée et doit être reconstruite à partir de zéro. Cela n'est pris en charge que lorsqu'il est compilé avec le support Berkeley DB avec les transactions activées. Tenter une récupération avec le support QDBM ou SQLite3 entraînera une

erreur.

L'option --db-remove-environment répertoire n'a pas d'équivalent en option courte. Elle exécute une récupération dans le répertoire donné puis supprime l'environnement de la base de données. Utilisez ceci avant de mettre à jour vers une nouvelle version de Berkeley DB si la nouvelle version à installer nécessite une mise à jour du format de fichier

journal.

L'option --db-print-leafpage-count fichier affiche le nombre de pages feuilles dans le fichier de base de données fichier sous forme de nombre décimal, ou UNKNOWN si la base de données ne prend pas en charge l'interrogation de cette

valeur.

L'option --db-print-pagesize fichier affiche la taille d'une page de base de données dans fichier sous forme de nombre décimal, ou UNKNOWN pour les bases de données à taille de page variable ou celles qui ne permettent pas une interrogation de la taille de page de la base de

données.

L'option --db-verify fichier demande à bogofilter de vérifier le fichier de base de

données. Elle n'affiche que les
erreurs, sauf en mode verbeux.

FORMAT DES

DONNÉES

Bogoutil lit et écrit des fichiers texte où chaque ligne non vide consiste en un mot, un

e quantité quelconque d'espaces horizontaux, un compteur de mots numérique, plus d'espace
s, et (optionnellement) une date sous la forme AAAAMMJJ. Les lignes vides sont ignorées.

VALEURS DE

RETOUR

0 pour une opération réussie. 1 pour la plupart des erreurs. 3 pour l

es erreurs d'E/S ou autres. L'erreur 3 signifie généralement que quelq
ue chose ne va pas sérieusement avec les fichiers de base de données.
