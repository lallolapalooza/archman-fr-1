NOM

buf-export - Exporter des fichiers proto d'un emplacement à un autre

SYNTAXE

buf export [options]

DESCRIPTION

Le premier argument est la source ou le module à exporter, qui doit être de type [dir,git,mod,protofile,tar,zip]. Cela vaut par défaut "." si aucun argument n'est spécifié.

Exemples :

Exporter les fichiers proto dans un répertoire de sortie.

$ buf export <source> --output=<repertoire-sortie>

Exporter le répertoire courant vers un autre répertoire local.

$ buf export . --output=<repertoire-sortie>

Exporter le dernier module distant vers un répertoire local.

$ buf export <buf.build/proprietaire/depot> --output=<repertoire-sortie>

Exporter une version spécifique d'un module distant vers un répertoire local.

$ buf export <buf.build/proprietaire/depot:ref> --output=<repertoire-sortie>

Exporter un dépôt git vers un répertoire local.

$ buf export https://github.com/proprietaire/depot.git --output=<repertoire-sortie>

OPTIONS

--all[=false] Lorsqu'il est activé, inclut toute documentation et fichiers de licence disponibles pour l'entrée exportée. Si l'entrée contient plus d'un module, les noms des fichiers de documentation et de licence seront suffixés avec le nom du module.

--config="" Le fichier buf.yaml ou les données à utiliser pour la configuration

--disable-symlinks[=false] Ne pas suivre les liens symboliques lors de la lecture des sources ou de la configuration depuis le système de fichiers local. Par défaut, les liens symboliques sont suivis dans cette CLI, mais jamais suivis sur le Buf Schema Registry.

--exclude-imports[=false] Exclure les importations.

--exclude-path=[] Exclure des fichiers ou répertoires spécifiques, par exemple "proto/a/a.proto", "proto/a". Si spécifié plusieurs fois, l'union est prise.

-h, --help[=false] Aide pour export

-o, --output="" Le répertoire de sortie pour les fichiers exportés

--path=[] Limiter à des fichiers ou répertoires spécifiques, par exemple "proto/a/a.proto", "proto/a". Si spécifié plusieurs fois, l'union est prise.

OPTIONS HERITEES DES COMMANDES PARENTES

--debug[=false] Activer la journalisation de débogage

--log-format="color" Le format du journal [text,color,json]

--timeout=0s La durée avant expiration, la régler à 0 signifie aucune expiration
