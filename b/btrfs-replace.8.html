NOM

btrfs-replace - remplacer des périphériques gérés par btrfs par d'autres périphériques

SYNTAXE

btrfs replace <sous-commande> <arguments>

DESCRIPTION

btrfs replace est utilisé pour remplacer les périphériques gérés par btrfs par d'autres périphériques.

SOUS-COMMANDE

annuler <point_montage>
Annuler une opération de remplacement de périphérique en cours.
demarrer [options] <periph_source>|<id_periph> <periph_cible> <chemin>
Remplacer un périphérique d'un système de fichiers btrfs.

Sur un système de fichiers actif, dupliquer les données vers le périphérique cible qui sont actuellement stockées sur le périphérique source. Si le périphérique source n'est plus disponible, ou si l'option -r est définie, les données sont construites en utilisant uniquement les mécanismes de redondance RAID. Après l'achèvement de l'opération, le périphérique source est supprimé du système de fichiers. Si le periph_source est une valeur numérique, il est supposé être l'identifiant du périphérique du système de fichiers monté à chemin, sinon c'est le chemin vers le périphérique source. Si le périphérique source est déconnecté du système, vous devez utiliser le format de paramètre id_periph. Le periph_cible doit avoir la même taille ou être plus grand que le periph_source.

Note :

Le système de fichiers doit être redimensionné pour tirer pleinement parti d'un périphérique cible plus grand ; cela peut être réalisé avec btrfs filesystem resize <id_periph>:max /chemin

Note :

Le remplacement de périphérique peut être interrompu par divers événements après le noyau v6.19, y compris, mais sans s'y limiter, la mise en veille prolongée/hibernation de la gestion de l'alimentation, le gel du système de fichiers, le gel du cgroup (utilisé par systemd pour le gel de la tranche) et les signaux en attente.

Le remplacement de périphérique en cours sera annulé après une telle interruption, et l'utilisateur final devra redémarrer le remplacement de périphérique depuis le début.

Il est donc recommandé d'inhiber la mise en veille/hibernation avant d'exécuter l'opération de remplacement de périphérique.

Options

-r
ne lire que depuis periph_source s'il n'existe aucun autre miroir sans défaut. (activer ceci si votre disque présente de nombreuses erreurs de lecture, l'accès serait très lent)
-f
forcer l'utilisation et l'écrasement de periph_cible même s'il semble contenir un système de fichiers btrfs valide.

Un système de fichiers valide est supposé si une super-structure btrfs est trouvée qui contient une somme de contrôle correcte. Les périphériques actuellement montés ne sont jamais autorisés à être utilisés comme periph_cible.

-B
pas de remplacement en arrière-plan.
--enfiler
attendre s'il existe une autre opération exclusive en cours, sinon continuer
-K|--pas_discard
Ne pas effectuer d'opération TRIM sur le périphérique entier sur les périphériques qui en sont capables. Cela n'affecte pas l'opération discard/trim lorsque le système de fichiers est monté. Veuillez consulter l'option de montage discard dans btrfs(5) <>.
etat [-1] <point_montage>
Afficher l'état et la progression d'une opération de remplacement de périphérique en cours.

Options

-1
afficher une fois au lieu d'afficher en continu jusqu'à ce que l'opération de remplacement soit terminée (ou annulée)

EXEMPLES

Remplacer un disque en ligne par un plus gros

Étant donné le système de fichiers suivant monté sur /mnt/mon-coffre

Label: 'MonCoffre'  uuid: ae20903e-b72d-49ba-b944-901fc6d888a1
        Total devices 2 FS bytes used 1TiB
        devid    1 size 1TiB used 500.00GiB path /dev/sda
        devid    2 size 1TiB used 500.00GiB path /dev/sdb

Pour remplacer /dev/sda (id_periph 1) par un disque plus grand situé sur /dev/sdc, vous exécuteriez la commande suivante :

btrfs replace start 1 /dev/sdc /mnt/mon-coffre/

Vous pouvez suivre la progression via :

btrfs replace status /mnt/mon-coffre/

Une fois le remplacement terminé, conformément à la documentation de btrfs-filesystem(8) <>, pour utiliser tout l'espace de stockage du nouveau disque, vous devez exécuter :

btrfs filesystem resize 1:max /mnt/mon-coffre/

STATUT DE SORTIE

btrfs replace retourne un statut de sortie nul en cas de succès. Un statut non nul est retourné en cas d'échec.

DISPONIBILITÉ

btrfs fait partie de btrfs-progs. Veuillez vous référer à la documentation sur https://btrfs.readthedocs.io.

VOIR AUSSI
