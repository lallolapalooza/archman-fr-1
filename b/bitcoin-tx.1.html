BITCOIN-TX(1) Commandes utilisateur BITCOIN-TX(1)

NOM

bitcoin-tx - page de manuel pour bitcoin-tx v28.1.0

SYNTAXE

bitcoin-tx [options] <tx-hex> [commandes] Mettre à jour une transaction bitcoin encodée en hexadécimal
bitcoin-tx [options] -create [commandes] Créer une transaction bitcoin encodée en hexadécimal

DESCRIPTION

Utilitaire Bitcoin Core bitcoin-tx version v28.1.0

OPTIONS

-?

Afficher ce message d'aide et quitter

-create

Créer une nouvelle TX vide.

-json

Sélectionner la sortie JSON

-txid

Afficher uniquement l'identifiant de transaction encodé en hexadécimal de la transaction résultante.

-version

Afficher la version et quitter

Options de débogage/test :

Options de sélection de chaîne :

-chain=<chaîne>

Utiliser la chaîne <chaîne> (par défaut : main). Valeurs autorisées : main, test, testnet4, signet, regtest

-signet

Utiliser la chaîne signet. Équivalent à -chain=signet. Notez que le réseau est défini par le paramètre -signetchallenge

-signetchallenge

Les blocs doivent satisfaire le script donné pour être considérés comme valides (uniquement pour les réseaux signet ; par défaut, le défi global du réseau de test signet par défaut)

-signetseednode

Spécifier un nœud d'amorçage pour le réseau signet, au format nomhôte[:port], par exemple sig.net:1234 (peut être utilisé plusieurs fois pour spécifier plusieurs nœuds d'amorçage ; par défaut, le ou les nœuds d'amorçage du réseau de test signet global par défaut)

-testnet

Utiliser la chaîne testnet3. Équivalent à -chain=test. Le support pour testnet3 est déprécié et sera supprimé dans une future version. Envisagez de passer dès maintenant à testnet4 en utilisant -testnet4.

-testnet4

Utiliser la chaîne testnet4. Équivalent à -chain=testnet4.

Commandes :

delin=N
Supprimer l'entrée N de la TX
delout=N
Supprimer la sortie N de la TX
in=TXID:VOUT(:NUMÉRO_SÉQUENCE)
Ajouter une entrée à la TX
locktime=N
Définir le locktime de la TX à N
nversion=N
Définir la version de la TX à N
outaddr=VALEUR:ADRESSE
Ajouter une sortie basée sur l'adresse à la TX
outdata=[VALEUR:]DONNÉES
Ajouter une sortie basée sur les données à la TX
outmultisig=VALEUR:REQUIS:CLÉS_PUBLIQUES:CLÉ_PUBLIQUE1:CLÉ_PUBLIQUE2:....[:INDICATEURS]
Ajouter une sortie Multi-sig N sur M à la TX. N = REQUIS, M = CLÉS_PUBLIQUES. Ajoutez éventuellement l'indicateur "W" pour produire une sortie pay-to-witness-script-hash. Ajoutez éventuellement l'indicateur "S" pour encapsuler la sortie dans un pay-to-script-hash.
outpubkey=VALEUR:CLÉ_PUBLIQUE[:INDICATEURS]
Ajouter une sortie pay-to-pubkey à la TX. Ajoutez éventuellement l'indicateur "W" pour produire une sortie pay-to-witness-pubkey-hash. Ajoutez éventuellement l'indicateur "S" pour encapsuler la sortie dans un pay-to-script-hash.
outscript=VALEUR:SCRIPT[:INDICATEURS]
Ajouter une sortie de script brute à la TX. Ajoutez éventuellement l'indicateur "W" pour produire une sortie pay-to-witness-script-hash. Ajoutez éventuellement l'indicateur "S" pour encapsuler la sortie dans un pay-to-script-hash.
remplaçable(=N)
Définit le numéro de séquence d'option d'op-in Replace-By-Fee (RBF) pour l'entrée N. Si N n'est pas fourni, la commande tente d'opter pour toutes les entrées disponibles pour le RBF. Si la transaction n'a pas d'entrées, cette option est ignorée.
sign=INDICATEURS-SIGHASH
Ajouter zéro ou plusieurs signatures à la transaction. Cette commande nécessite des registres JSON :prevtxs=objet JSON, privatekeys=objet JSON. Voir la documentation de signrawtransactionwithkey pour le format des indicateurs sighash, des objets JSON.

Commandes d'enregistrement :

load=NOM:NOM FICHIER
Charger le fichier JSON NOM FICHIER dans le registre NOM
set=NOM:CHAÎNE-JSON
Définir le registre NOM à la CHAÎNE-JSON donnée
