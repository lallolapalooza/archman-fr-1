SYNOPSI

cfg-spec = (@cfg-name | --config|-c cfg-dir)... | --all|-a
prj-spec = --directory|-d prj-d

i
r

DESCRIPTIO

N

La commande fetch récupère la liste des paquets disponibles dans les dépôts prérequis/complémentaires du projet dans une ou plusieurs configurations de

compilation.

Si aucun répertoire de projet ou de paquet n'est spécifié, le répertoire de travail courant est supposé. Si aucune configuration n'est spécifiée, les configurations par défaut sont supposées. Voir bdep-projects-configs(1) pour des détails sur la spécification des projets et des

configurations.

Si l'option --full|-F est spécifiée, alors au lieu de fetch effectue une nouvelle récupération complète de tous les dépôts ajoutés à la configuration. Ce mode est principalement utile lorsqu'une configuration (et certains de

s dépôts prérequis/complémentaires) est partagée entre plusieurs projets. Dans cette s
ituation, une récupération incrémentielle peut entraîner un état de dépôt incohérent.

DÉFAUT

Voir bdep-default-options-files(1) pour un aperçu des fichiers d'options par défaut. Pour la commande fetch, le répertoire de départ de la recherche est le répertoire du projet. Les fichiers d'options suivants sont recherchés dans chaque répertoire et, s'ils sont trouvés, chargés dans l'ordre indiqué

: 
bdep.options
bdep-fetch.
options
