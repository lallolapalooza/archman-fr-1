BITS(1) Commandes utilisateur BITS(1)

NOM

bits - Convertit les masques de bits de/vers divers formats

SYNTAXE

bits [-h] [-V] [-w <NB>] [<MODE>] [<MASQUE_OU_LISTE>...]

DESCRIPTION

L'utilitaire bits convertit les masques de bits dans divers formats. Il prend en charge la combinaison de plusieurs masques à l'aide d'opérations binaires.

ARGUMENTS POSITIONNELS

<MASQUE_OU_LISTE>

Un ensemble de bits spécifié comme une valeur de masque hexadécimale (par exemple, 0xeec2) ou comme une liste d'identifiants de bits séparés par des virgules.

Si aucun argument n'est spécifié, les ensembles de bits seront lus depuis l'entrée standard ; un groupe par ligne.

Les identifiants consécutifs peuvent être compressés sous forme de plages (par exemple, 5,6,7,8,9,10 → 5-10).

Optionnellement, si un argument commence par une virgule, il sera analysé comme un seul masque hexadécimal divisé en groupes de 32 bits (par exemple, ,00014000,00000000,00020000 → 17,78,80).

Par défaut, tous les groupes seront combinés par une opération OU. Si un groupe a l'un des préfixes suivants, il sera combiné avec le masque résultant à l'aide d'une opération binaire différente :

&<MASQUE_OU_LISTE>

Le groupe sera combiné avec une opération ET binaire. Autrement dit, tous les bits qui sont définis à 1 dans le groupe ET les groupes combinés jusqu'à présent seront conservés à 1. Tous les autres bits seront réinitialisés à 0.

^<MASQUE_OU_LISTE>

Le groupe sera combiné avec une opération XOR binaire. Autrement dit, tous les bits qui sont définis à 1 dans le groupe ET à 0 dans les groupes combinés jusqu'à présent (ou vice versa) seront définis à 1. Les bits qui sont tous deux à 1 ou tous deux à 0 seront réinitialisés à 0.

~<MASQUE_OU_LISTE>

Tous les bits définis à 1 dans le groupe seront effacés (réinitialisés à 0) dans les groupes combinés jusqu'à présent.

OPTIONS

-w <NB>, --width <NB>

Nombre maximum de bits dans les masques gérés par bits (par défaut : 8192). Tout bit supérieur à ce nombre sera tronqué.

-h, --help

Affiche le texte d'aide et quitte.

-V, --version

Affiche la version et quitte.

MODE DE CONVERSION

L'un des modes de conversion suivants peut être spécifié. S'il n'est pas spécifié, il prend la valeur par défaut de -m, --mask.

-m, --mask

Imprime les arguments combinés sous forme de valeur de masque hexadécimale (par défaut).

-g, --grouped-mask

Imprime les arguments combinés sous forme de valeur de masque hexadécimale en groupes de 32 bits séparés par des virgules.

-b, --binary

Imprime les arguments combinés sous forme de valeur de masque binaire.

-l, --list

Imprime les arguments combinés sous forme de liste d'identifiants de bits. Les identifiants consécutifs sont compressés en plages.

EXEMPLES

~$ bits --mask 4,5-8 16,30
0x400101f0
~$ bits --list 0xeec2
1,6,7,9-11,13-15
~$ bits --binary 4,5-8 16,30
0b100_0000_0000_0001_0000_0001_1111_0000
~$ bits --list ,00300000,03000000,30000003
0,1,28,29,56,57,84,85
~$ bits --list 1,2,3,4 ~3-10
1,2
~$ bits --list 1,2,3,4 ^3-10
1,2,5-10
~$ bits --grouped-mask 2,22,74,79
8400,00000000,00400004
~$ bits --width 64 --list 2,22,74,79
2,22
