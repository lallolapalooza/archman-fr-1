bupstash-recover-removed(1)

Paquet: bupstash

Licences: MIT

() ()

SYNTAXE

Récupérer les éléments du dépôt qui ont été supprimés, mais qui n'ont pas encore été supprimés par le garbage collection.

bupstash recover-removed [OPTIONS]

DESCRIPTION

bupstash recover-removed permet à un utilisateur d'annuler toutes les opérations de ´rm´ qui ont eu lieu depuis la dernière invocation de bupstash-gc(1). En d'autres termes, cette commande fournit un moyen de corriger les erreurs et les invocations accidentelles de bupstash-rm(1).

bupstash recover-removed nécessite les permissions ´put´ et ´get´ pour le dépôt sur lequel opérer.

OPTIONS

-r, --repository REPO
Le dépôt auquel se connecter et sur lequel opérer. Peut être sous la forme ssh://$SERVER/$PATH pour les dépôts distants si l'accès ssh est configuré. Si non spécifié, est défini sur BUPSTASH_REPOSITORY.
--no-progress
Supprimer les indicateurs de progression (Les indicateurs de progression sont également supprimés lorsque stderr n'est pas un terminal interactif).
-q, --quiet
Être silencieux, implique --no-progress.

ENVIRONNEMENT

BUPSTASH_REPOSITORY
Le dépôt auquel se connecter. Peut être sous la forme ssh://$SERVER/$PATH pour les dépôts distants si l'accès ssh est configuré.
BUPSTASH_REPOSITORY_COMMAND
Une commande à exécuter pour se connecter à une instance de bupstash-serve(1). Cela permet des connexions plus complexes au dépôt pour des cas d'utilisation moins courants.

VOIR AUSSI

bupstash(1), bupstash-rm(1), bupstash-gc(1)
