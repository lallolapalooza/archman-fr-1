NOM

byobu-keybindings - activer/désactiver les raccourcis clavier de Byobu

SYNTAXE

byobu-keybindings

DESCRIPTION

byobu-keybindings active ou désactive les raccourcis clavier de Byobu dans la session tmux(1) ou screen(1) courante. Il n'opérera que sur la session courante.

Cet exécutable est fourni comme alternative à l'appui sur <Maj>-F12, et est utile dans les environnements où <Maj>-F12 ne fonctionne pas (par exemple, sur la console Linux TTY).

Certains utilisateurs de Byobu désactivent ces raccourcis clavier lorsqu'ils interfèrent avec d'autres programmes utilisant les mêmes raccourcis clavier (par exemple, mc(1)).
