DESCRIPTIO

N

brctl est utilisé pour configurer, maintenir et inspecter la configuration du pont ethernet dans le noyau

Linux.

Un pont ethernet est un appareil couramment utilisé pour connecter différents réseaux ethernet entre eux, afin que ces ethernets apparaissent comme un seul ethernet aux

participants.

Chacun des ethernets connectés correspond à une interface physique dans le

pont. Ces ethernets individuels sont regroupés en un plus grand ethernet («
logique »), ce plus grand ethernet correspond à l'interface réseau du pont.

INSTANCE

S

La commande brctl addbr <nom> crée une nouvelle instance du pont ethernet. L'interface réseau correspondant au pont sera appelée <nom>

.

La commande brctl delbr <nom> supprime l'instance <nom> du pont ethernet. L'interface réseau correspondant au pont doit être désactivée avant de pouvoir être supprimée

!

La commande brctl show affiche toutes les instan

ces actuelles du
pont ethernet.

PORT

S

Chaque pont a un certain nombre de ports qui lui sont attachés. Le trafic réseau entrant sur l'un de ces ports sera transmis aux autres ports de manière transparente, de sorte que le pont soit invisible pour le reste du réseau (c'est-à-dire qu'il n'apparaîtra pas dans traceroute(8) )

.

La commande brctl addif <brname> <ifname> rendra l'interface <ifname> un port du pont <brname>. Cela signifie que toutes les trames reçues sur <ifname> seront traitées comme si elles étaient destinées au pont. De plus, lors de l'envoi de trames sur <brname>, <ifname> sera considérée comme une interface de sortie

potentielle.

La commande brctl delif <brname> <ifname> détachera l'interface <ifname> du pont <brname>

.

La commande brctl show <brname> affichera des informat

ions sur le pont e
t ses ports attachés.

VIEILLISSEME

NT

Le pont garde une trace des adresses ethernet vues sur chaque port. Lorsqu'il doit transmettre une trame et qu'il connaît le port sur lequel l'adresse ethernet de destination (spécifiée dans la trame) se trouve, il peut « tricher » en transmettant la trame uniquement à ce port, économisant ainsi de nombreuses copies et transmissions

redondantes.

Cependant, les données de localisation des adresses ethernet ne sont pas statiques. Les machines peuvent se déplacer vers d'autres ports, les cartes réseau peuvent être remplacées (ce qui change l'adresse ethernet de la machine),

etc.

brctl showmacs <brname> affiche une liste des adresses MAC apprises pour ce

pont.

brctl setageing <brname> <temps> définit le temps de vieillissement de l'adresse ethernet (MAC), en secondes. Après <temps> secondes sans avoir vu de trame provenant d'une certaine adresse, le pont expirera (supprimera) cette adresse de la base de données de transmission (fdb)

.

brctl setgcint <brname> <temps> définit l'intervalle de collecte des déchets pour le pont <brname> à <temps> secondes. C

ela signifie que le pont vérifiera la base de données de tra
nsmission pour les entrées expirées toutes les <temps> secondes.

PROTOCOLE D'ARBRE

COUVRANT

Plusieurs ponts ethernet peuvent travailler ensemble pour créer des réseaux ethernet encore plus grands en utilisant le protocole d'arbre couvrant IEEE 802.1d. Ce protocole est utilisé pour trouver le chemin le plus court entre deux ethernets et pour éliminer les boucles de la topologie. Comme ce protocole est un standard, les ponts Linux interopéreront correctement avec d'autres produits de pont tiers. Les ponts communiquent entre eux en envoyant et en recevant des BPDUs (Bridge Protocol Data Units). Ces BPDUs peuvent être reconnus par une adresse de destination ethernet de 01:80:c2:00:00:

00.

Le protocole d'arbre couvrant peut également être désactivé (pour les situations où cela n'a tout simplement pas de sens, par exemple lorsque cette machine Linux est le seul pont sur le LAN, ou lorsque vous savez qu'il n'y a pas de boucles dans la topologie.

)

brctl(8) peut être utilisé pour configurer certains paramètres du protocole d'arbre couvrant. Pour une explication de ces paramètres, voir la spécification IEEE 802.1d (ou envoyez-moi un courriel). Les valeurs par défaut devraient être tout à fait correctes. Si vous ne savez pas ce que signifient ces paramètres, vous n'aurez probablement pas envie de les

modifier.

brctl stp <bridge> <state> contrôle la participation de cette instance de pont au protocole d'arbre couvrant. Si <state> est "on" ou "yes", le STP sera activé, sinon il sera désactivé. Lorsqu'il est désactivé, le pont n'enverra ni ne recevra de BPDUs et ne participera donc pas au protocole d'arbre couvrant. Si votre pont n'est pas le seul pont sur le LAN, ou s'il y a des boucles dans la topologie du LAN, NE DÉSACTIVEZ PAS cette option. Si vous désactivez cette option, sachez ce que vous

faites.

brctl setbridgeprio <bridge> <priority> définit la priorité du pont à <priority>. La valeur de priorité est une quantité non signée sur 16 bits (un nombre entre 0 et 65535) et n'a pas de dimension. Les valeurs de priorité plus basses sont « meilleures ». Le pont ayant la priorité la plus basse sera élu « pont racine »

.

brctl setfd <bridge> <time> définit le « bridge forward delay » (délai de transmission du pont) à <time>

secondes.

brctl sethello <bridge> <time> définit le « bridge hello time » (temps de salutation du pont) à <time>

secondes.

brctl setmaxage <bridge> <time> définit le « maximum message age » (âge maximal du message) à <time>

secondes.

brctl setpathcost <bridge> <port> <cost> définit le coût du port <port> à <cost>. C'est une métrique sans

dimension.

brctl setportprio <bridge> <port> <priority> définit la priorité du port <port> à <priority>. La valeur de priorité est une quantité non signée sur 8 bits

(un nombre entre 0 et 255) et n'a pas de dimension. Cette métrique est
utilisée dans les algorithmes de sélection du port désigné et du port racine.

NOTE

S

le de fonctionnali
tés plus complet.

    Nom

    brctl - utilitaire pour administrer les ponts Ethernet sous Linux

    Synopsis

    brctl [options] commande [arguments]

    Description

    brctl est un utilitaire pour configurer et administrer le pontage Ethernet sous Linux. Il peut être utilisé pour créer un pont, ajouter/supprimer des interfaces réseau au pont, afficher le contenu de la table de pontage, etc.

    Commandes

    addbr nom_pont
    Crée un nouveau pont nommé nom_pont.
    delbr nom_pont
    Supprime le pont nommé nom_pont.
    addif nom_pont interface
    Ajoute l'interface réseau interface au pont nom_pont.
    delif nom_pont interface
    Supprime l'interface réseau interface du pont nom_pont.
    show [nom_pont]
    Affiche les ponts et les interfaces qui leur sont associées. Si nom_pont est spécifié, affiche seulement les informations pour ce pont.
    setageing nom_pont temps
    Définit le temps de vieillissement (en secondes) pour le pont nom_pont.
    setforwardage nom_pont temps
    Définit le temps de transmission vers l'avant (forwarding delay) en secondes pour le pont nom_pont.
    sethello nom_pont temps
    Définit le temps d'attente de message Hello (en secondes) pour le pont nom_pont.
    setmaxage nom_pont temps
    Définit l'âge maximum (en secondes) pour les informations de table MAC pour le pont nom_pont.
    setpathcost nom_pont interface cout
    Définit le coût du chemin pour l'interface interface du pont nom_pont.
    setportprio nom_pont interface priorite
    Définit la priorité du port pour l'interface interface du pont nom_pont.
    setbridgeprio nom_pont priorite
    Définit la priorité du pont pour le pont nom_pont.
    stpstate nom_pont etat
    Définit l'état du protocole Spanning Tree pour le pont nom_pont. Les états possibles sont on et off.

    Options

    -a, --all
    Affiche toutes les informations de pontage.
    -e, --ether
    Affiche les informations de pontage au format Ethernet.
    -i, --interfaces
    Affiche les interfaces réseau attachées au pont.
    -M, --multicast
    Affiche les informations de pontage multicast.
    -n, --noheadings
    N'affiche pas les en-têtes.
    -r, --resolve
    Résout les adresses IP en noms d'hôtes.
    -s, --silent
    Mode silencieux.
    -V, --version
    Affiche la version de brctl.

    Exemples

    Pour créer un nouveau pont nommé br0 : 

    brctl addbr br0

    Pour ajouter l'interface eth0 au pont br0 : 

    brctl addif br0 eth0

    Pour afficher tous les ponts et leurs interfaces : 

    brctl show

    Voir également

    ip(8), bridge(8)
