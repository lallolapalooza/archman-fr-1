NOM

bbl2bib.pl - convertir l'environnement bibliographie en fichier bib

SYNTAXE

bbl2bib.pl [-d] [-u] [-o sortie] fichier

OPTIONS

[-d]
Envoyer la sortie de débogage sur stdout
-o sortie
Fichier de sortie. Si cette option n'est pas utilisée, le nom du fichier de sortie est formé en changeant l'extension en ".bib"
-u
Ne pas nettoyer les champs URL.

Normalement, "bbl2bib" reconnaît les champs URL du type "http://dx.doi.org" et leurs variantes et les convertit en champs DOI (voir aussi le script biburl2doi(1)). L'option -u supprime ce nettoyage.

DESCRIPTION

Le script essaie de reconstruire un fichier "bib" à partir de l'environnement "thebibliography" correspondant. On peut dire que cette opération est similaire à reconstruire une vache à partir du steak. La manière dont le script procède est en recherchant l'entrée dans la base de données MR, et en créant les champs BibTeX correspondants.

Le script lit un fichier TeX ou Bbl et en extrait l'environnement "thebibliography". Pour chaque bibitem, il crée une entrée de bibliographie en texte brut, puis essaie de la faire correspondre dans la base de données.

FICHIER D'ENTRÉE

Nous supposons une certaine structure du fichier d'entrée :

1.
La bibliographie est contenue entre les lignes 
\begin{thebibliography}...

et

\end{thebibliography}
2.
Chaque élément de bibliographie commence à la ligne 
\bibitem[...]{....}

EXEMPLES

bbl2bib  -o - file.tex > result.bib
bbl2bib  -o result.bib file.bbl
bbl2bib  file.tex
