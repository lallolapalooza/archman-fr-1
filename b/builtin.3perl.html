builtin(3perl) Guide du programmeur Perl builtin(3perl)

NOM

builtin - Pragma Perl pour importer des fonctions utilitaires intégrées

SYNTAXE

use builtin qw(
    true false is_bool
    inf nan
    weaken unweaken is_weak
    blessed refaddr reftype
    created_as_string created_as_number
    stringify
    ceil floor
    indexed
    trim
    is_tainted
    export_lexically
    load_module
);
use builtin ':5.40';  # la plupart des éléments ci-dessus

DESCRIPTION

Perl fournit plusieurs fonctions utilitaires dans le package "builtin". Ce sont des fonctions simples, qui ressemblent et se comportent comme des fonctions définies par l'utilisateur. Elles n'offrent pas de nouvelle syntaxe et ne nécessitent pas d'analyse spéciale. Ces fonctions sont toujours présentes dans l'interpréteur et peuvent être appelées à tout moment par leurs noms entièrement qualifiés. Par défaut, elles ne sont pas disponibles sous des noms courts, mais peuvent être demandées pour plus de commodité.

Les fonctions nommées individuelles peuvent être importées en les énumérant comme paramètres d'importation dans l'instruction "use" pour ce pragma.

Le module builtin::compat de CPAN fournit des versions de nombreuses fonctions qui peuvent être utilisées sur des versions de Perl où "builtin" ou certaines fonctions ne sont pas encore disponibles.

Attention : Actuellement, bon nombre des fonctions de l'espace de noms "builtin" sont expérimentales. Leur appel déclenchera des avertissements de la catégorie "experimental::builtin".

Importation Lexicale

Ce module pragma crée des alias lexicaux dans la portée de compilation actuelle pour ces fonctions intégrées. Ceci est similaire à l'effet lexical d'autres pragmas comme strict et feature.

sub classify
{
    my $val = shift;
    use builtin 'is_bool';
    return is_bool($val) ? "booléen" : "pas un booléen";
}
# la fonction is_bool() n'est plus visible ici
# mais peut toujours être appelée par builtin::is_bool()

Étant donné que ces fonctions sont importées de manière lexicale, plutôt que par des symboles de package, l'utilisateur n'a pas besoin de prendre de mesures spéciales pour s'assurer qu'elles n'apparaissent pas accidentellement comme méthodes d'objet d'une classe.

package An::Object::Class {
    use builtin 'true', 'false';
    ...
}
# n'apparaît pas comme méthode
An::Object::Class->true;
# Ne peut trouver la méthode d'objet "true" via le package "An::Object::Class"
#   à ...

Une fois importée, une fonction lexicale est très similaire à tout autre symbole lexical (comme une variable) dans le sens où elle ne peut pas être supprimée. Si vous souhaitez limiter la visibilité d'une fonction "builtin" importée, placez-la à l'intérieur de sa propre portée :

{
  use builtin 'refaddr';
  ...
}

Lots de Versions

L'ensemble complet des fonctions intégrées qui étaient considérées comme non expérimentales par une version de Perl peut être importé en une fois, en demandant un lot de versions. Ceci est fait en donnant la version de publication de Perl (sans son suffixe de sous-version) après un signe deux-points :

use builtin ':5.40';

Les lots suivants existent actuellement :

Version    Comprend
-------    --------
:5.40      true false weaken unweaken is_weak blessed refaddr reftype
           ceil floor is_tainted trim indexed

Optimisations de Fonctions

Il existe un certain nombre d'optimisations qui s'appliquent aux fonctions du package builtin. Si vous remplacez ou surchargez ces fonctions (par exemple par affectation dans des références glob), les optimisations pourraient ne pas prendre effet. Faites-le avec prudence.

FONCTIONS

true

$val = true;

Retourne la valeur booléenne vraie. Alors que n'importe quelle valeur scalaire peut être testée pour sa vérité et que la plupart des valeurs définies, non vides et non nulles sont considérées comme "vraies" par Perl, celle-ci est spéciale car "is_bool" la considère comme une valeur booléenne distinguée.

Ceci donne une valeur équivalente à des expressions comme "!!1" ou "!0".

Disponible à partir de Perl 5.36. Depuis Perl 5.40, elle n'est plus expérimentale et est incluse dans les lots de versions builtin 5.40 et supérieures.

false

$val = false;

Retourne la valeur booléenne fausse. Alors que n'importe quelle valeur scalaire non vraie est considérée comme "fausse" par Perl, celle-ci est spéciale car "is_bool" la considère comme une valeur booléenne distinguée.

Ceci donne une valeur équivalente à des expressions comme "!!0" ou "!1".

Disponible à partir de Perl 5.36. Depuis Perl 5.40, elle n'est plus expérimentale et est incluse dans les lots de versions builtin 5.40 et supérieures.

is_bool

$bool = is_bool($val);

Cette fonction est actuellement expérimentale.

Retourne vrai lorsqu'elle reçoit une valeur booléenne distinguée, ou faux sinon. Une valeur booléenne distinguée est le résultat de toute fonction intégrée retournant un booléen (telle que "true" ou "is_bool" elle-même), un opérateur retournant un booléen (tel que les tests de comparaison "eq" ou "==" ou l'opérateur de négation "!"), ou toute variable contenant l'un de ces résultats.

Cette fonction s'appelait auparavant "isbool". Un alias de compatibilité est actuellement fourni mais sera supprimé dans une version ultérieure.

Disponible à partir de Perl 5.36.

inf

$num = inf;

Cette fonction est actuellement expérimentale.

Retourne la valeur d'infini en virgule flottante. Si le type C numérique sous-jacent ne prend pas en charge une telle valeur, une erreur d'exécution est levée à la place.

Disponible à partir de Perl 5.40.

nan

$num = nan;

Cette fonction est actuellement expérimentale.

Retourne la valeur "Not-a-Number" (Nombres Irréguliers) en virgule flottante. Si le type C numérique sous-jacent ne prend pas en charge une telle valeur, une erreur d'exécution est levée à la place.

Disponible à partir de Perl 5.40.

weaken

weaken($ref);

Affaiblit une référence. Une référence affaiblie ne contribue pas au compteur de références de son référent. Si seules des références faibles restent vers un référent, il sera éliminé, et toutes les références faibles restantes vers celui-ci auront leur valeur définie à "undef".

Disponible à partir de Perl 5.36. Depuis Perl 5.40, elle n'est plus expérimentale et est incluse dans les lots de versions builtin 5.40 et supérieures.

unweaken

unweaken($ref);

Renforce une référence, annulant les effets d'un appel précédent à "weaken".

Disponible à partir de Perl 5.36. Depuis Perl 5.40, elle n'est plus expérimentale et est incluse dans les lots de versions builtin 5.40 et supérieures.

is_weak

$bool = is_weak($ref);

Retourne vrai lorsqu'elle reçoit une référence affaiblie, ou faux si ce n'est pas une référence ou si elle n'est pas faible.

Cette fonction s'appelait auparavant "isweak". Un alias de compatibilité est actuellement fourni mais sera supprimé dans une version ultérieure.

Disponible à partir de Perl 5.36. Depuis Perl 5.40, elle n'est plus expérimentale et est incluse dans les lots de versions builtin 5.40 et supérieures.

blessed

$str = blessed($ref);

Retourne le nom du package pour une référence d'objet, ou "undef" pour une non-référence ou une référence qui n'est pas un objet.

refaddr

$num = refaddr($ref);

Renvoie l'adresse mémoire d'une référence, ou "undef" pour une non-référence. Cette valeur n'est probablement pas très utile pour du code Perl pur, mais elle est pratique pour tester l'identité ou l'unicité référentielle.

Disponible à partir de Perl 5.36. Depuis Perl 5.40, il n'est plus expérimental et il est inclus dans les bundles de versions intégrées de 5.40 et supérieur.

reftype

$str = reftype($ref);

Renvoie le type de conteneur de base de ce à quoi pointe une référence, ou "undef" pour une non-référence. Ceci est renvoyé sous forme de chaîne de caractères en majuscules, comme "ARRAY" pour les références de tableaux, ou "HASH" pour les références de hachages.

Disponible à partir de Perl 5.36. Depuis Perl 5.40, il n'est plus expérimental et il est inclus dans les bundles de versions intégrées de 5.40 et supérieur.

created_as_string

$bool = created_as_string($val);

Cette fonction est actuellement expérimentale.

Renvoie une valeur booléenne indiquant si la valeur de l'argument a été créée à l'origine comme une chaîne. Elle renverra vrai pour toute expression scalaire dont la dernière affectation ou modification était de nature textuelle - comme une affectation à partir d'une chaîne littérale, ou le résultat d'une opération textuelle telle que la concaténation ou une expression régulière. Elle renverra faux pour les références (y compris tout objet), les nombres, les booléens et undef.

Il est peu probable que vous souhaitiez utiliser ceci pour une validation régulière des données dans Perl, car cela ne renverra pas vrai pour les nombres réguliers qui sont toujours parfaitement utilisables comme chaînes, ni pour une référence d'objet - en particulier les objets qui surcharge le littéral de surcharge d'opération textuelle dans une tentative de se comporter davantage comme des chaînes. Par exemple

my $val = URI->new( "https://metacpan.org/" );
if( created_as_string $val ) { ... }    # cela n'exécutera pas

Disponible à partir de Perl 5.36.

created_as_number

$bool = created_as_number($val);

Cette fonction est actuellement expérimentale.

Renvoie une valeur booléenne indiquant si la valeur de l'argument a été créée à l'origine comme un nombre. Elle renverra vrai pour toute expression scalaire dont la dernière affectation ou modification était de nature numérique - comme une affectation à partir d'un nombre littéral, ou le résultat d'une opération numérique telle qu'une addition. Elle renverra faux pour les références (y compris tout objet), les chaînes, les booléens et undef.

Il est peu probable que vous souhaitiez utiliser ceci pour une validation régulière des données dans Perl, car cela ne renverra pas vrai pour les chaînes régulières de chiffres décimaux qui sont toujours parfaitement utilisables comme nombres, ni pour une référence d'objet - en particulier les objets qui surcharge le littéral de surcharge d'opération numérique dans une tentative de se comporter davantage comme des nombres. Par exemple

my $val = Math::BigInt->new( 123 );
if( created_as_number $val ) { ... }    # cela n'exécutera pas

Bien que la plupart du code Perl devrait opérer sur des valeurs scalaires sans avoir besoin de connaître leur historique de création, ces deux fonctions sont destinées à être utilisées par des modules de sérialisation de données tels que les encodeurs JSON ou des situations similaires, où les préoccupations d'interopérabilité linguistique exigent de faire une distinction entre les valeurs qui sont fondamentalement textuelles par nature versus numériques.

Disponible à partir de Perl 5.36.

stringify

$str = stringify($val);

Cette fonction est actuellement expérimentale.

Renvoie une nouvelle chaîne Perl simple qui représente l'argument donné.

Lorsqu'elle est donnée une valeur qui est déjà une chaîne, une copie de cette valeur est renvoyée inchangée. Les booléens faux sont traités comme la chaîne vide.

Les nombres sont convertis en une représentation décimale. Les booléens vrais sont traités comme le nombre 1.

Les références à des objets dans des classes qui ont surcharge et définissent l'entrée de surcharge "" utiliseront la méthode déléguée pour fournir une valeur ici.

Les références non-objets, ou les références à des objets dans des classes sans surcharge "" renverront une chaîne qui nomme le type de conteneur sous-jacent de la référence, son adresse mémoire, et potentiellement le nom de sa classe s'il s'agit d'un objet.

Disponible à partir de Perl 5.40.

ceil

$num = ceil($num);

Renvoie la plus petite valeur entière supérieure ou égale à l'argument numérique donné.

Disponible à partir de Perl 5.36. Depuis Perl 5.40, il n'est plus expérimental et il est inclus dans les bundles de versions intégrées de 5.40 et supérieur.

floor

$num = floor($num);

Renvoie la plus grande valeur entière inférieure ou égale à l'argument numérique donné.

Disponible à partir de Perl 5.36. Depuis Perl 5.40, il n'est plus expérimental et il est inclus dans les bundles de versions intégrées de 5.40 et supérieur.

indexed

@ivpairs = indexed(@items)

Renvoie une liste de taille paire de paires nombre/valeur, où chaque paire est formée d'un nombre donnant un index dans la liste originale suivi de la valeur à cette position. C'est-à-dire, renvoie une liste deux fois plus grande que l'originale, égale à

(0, $items[0], 1, $items[1], 2, $items[2], ...)

Notez que contrairement à la fonction de base "values", cette fonction renvoie des copies de ses arguments originaux, pas des alias vers eux. Toute modification de ces copies n'est pas reflétée dans les modifications apportées à l'original.

my @x = ...;
$_++ for indexed @x;  # Le tableau @x reste inchangé

Cette fonction est principalement destinée à être utile combinée avec la syntaxe de boucle "foreach" à multi-variables ; comme

foreach my ($index, $value) (indexed LIST) {
    ...
}

En contexte scalaire, cette fonction renvoie la taille de la liste qu'elle aurait autrement renvoyée, et provoque un avertissement dans la catégorie "scalar".

Disponible à partir de Perl 5.36. Depuis Perl 5.40, il n'est plus expérimental et il est inclus dans les bundles de versions intégrées de 5.40 et supérieur.

trim

$stripped = trim($string);

Renvoie la chaîne d'entrée avec les espaces blancs supprimés du début et de la fin. trim() supprimera ces caractères :

" ", un espace ordinaire.

"\t", une tabulation.

"\n", une nouvelle ligne (saut de ligne).

"\r", un retour chariot.

et tous les autres caractères Unicode marqués comme espaces blancs. Une liste complète se trouve dans "Whitespace" dans perlrecharclass.

$var = "  Hello world   ";            # "Hello world"
$var = "\t\t\tHello world";           # "Hello world"
$var = "Hello world\n";               # "Hello world"
$var = "\x{2028}Hello world\x{3000}"; # "Hello world"

"trim" est équivalent à :

my $trimmed = $str =~ s/\A\s+//ur =~ s/\s+\z//ur;

Disponible à partir de Perl 5.36. Depuis Perl 5.40, il n'est plus expérimental et il est inclus dans les bundles de versions intégrées de 5.40 et supérieur.

is_tainted

$bool = is_tainted($var);

Renvoie vrai lorsqu'on lui donne une variable polluée.

Disponible à partir de Perl 5.38.

export_lexically

export_lexically($name1, $ref1, $name2, $ref2, ...)

Cette fonction est actuellement expérimentale.

Export des nouveaux noms lexicaux dans la portée en cours de compilation. Les noms donnés par le premier de chaque paire de valeurs feront référence à l'élément correspondant dont la référence est donnée par le second. Les types d'éléments autorisés sont les sous-routines, et les variables scalaires, de tableau et de hachage. Si l'élément est une sous-routine, le nom peut facultativement être préfixé par le sigil "&", mais par commodité, il n'est pas obligatoire. Pour les éléments qui sont des variables, le sigil est requis et doit correspondre au type de la variable.

export_lexically func    => \&func,
                 '&func' => \&func;  # identique à ci-dessus
export_lexically '$scalar' => \my $var;
# Les suivants ne sont pas autorisés
export_lexically '$var' => \@arr;   # le sigil ne correspond pas
export_lexically name => \$scalar;  # le sigil '&' implicite ne correspond pas
export_lexically '*name' => \*globref;  # les références glob ne sont pas prises en charge

Ceci doit être appelé au moment de la compilation ; ce qui signifie typiquement pendant un bloc "BEGIN". Habituellement, cela serait utilisé dans le cadre d'une méthode "import" d'un module, lorsqu'elle est invoquée dans le cadre d'une instruction "use ...".

Disponible à partir de Perl 5.38.

load_module

load_module($module_name);

Cette fonction est actuellement expérimentale.

Charge un module nommé à partir des chemins d'inclusion (@INC). $module_name doit être une chaîne qui fournit un nom de module. Il ne peut pas être omis, et fournir un nom de module invalide entraînera une exception. Ne pas fournir d'argument entraîne une erreur de compilation. Renvoie le nom du module chargé en cas de succès.

L'effet de "load_module"-er un module est globalement le même que "require"-er, y compris les mêmes conditions d'erreur lorsque le module n'existe pas, ne compile pas, ou n'évalue pas à une valeur vraie. Voir également la fonctionnalité "module_true".

"load_module" ne peut pas être utilisé pour requérir une version particulière de Perl, ni ca

n it be given a bareword module name as an

argument.
