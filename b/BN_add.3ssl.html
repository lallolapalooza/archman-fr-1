BN_add(3ssl)

Paquet: openssl

Licences: Apache-2.0

BN_ADD(3ssl) OpenSSL BN_ADD(3ssl)

NOM

BN_add, BN_sub, BN_mul, BN_sqr, BN_div, BN_mod, BN_nnmod, BN_mod_add, BN_mod_sub, BN_mod_mul, BN_mod_sqr, BN_mod_sqrt, BN_exp, BN_mod_exp, BN_gcd - opérations arithmétiques sur les BIGNUM

SYNOPSIS

#include <openssl/bn.h>
int BN_add(BIGNUM *r, const BIGNUM *a, const BIGNUM *b);
int BN_sub(BIGNUM *r, const BIGNUM *a, const BIGNUM *b);
int BN_mul(BIGNUM *r, const BIGNUM *a, const BIGNUM *b, BN_CTX *ctx);
int BN_sqr(BIGNUM *r, const BIGNUM *a, BN_CTX *ctx);
int BN_div(BIGNUM *dv, BIGNUM *rem, const BIGNUM *a, const BIGNUM *d,
           BN_CTX *ctx);
int BN_mod(BIGNUM *rem, const BIGNUM *a, const BIGNUM *m, BN_CTX *ctx);
int BN_nnmod(BIGNUM *r, const BIGNUM *a, const BIGNUM *m, BN_CTX *ctx);
int BN_mod_add(BIGNUM *r, const BIGNUM *a, const BIGNUM *b, const BIGNUM *m,
               BN_CTX *ctx);
int BN_mod_sub(BIGNUM *r, const BIGNUM *a, const BIGNUM *b, const BIGNUM *m,
               BN_CTX *ctx);
int BN_mod_mul(BIGNUM *r, const BIGNUM *a, const BIGNUM *b, const BIGNUM *m,
               BN_CTX *ctx);
int BN_mod_sqr(BIGNUM *r, const BIGNUM *a, const BIGNUM *m, BN_CTX *ctx);
BIGNUM *BN_mod_sqrt(BIGNUM *in, const BIGNUM *a, const BIGNUM *p, BN_CTX *ctx);
int BN_exp(BIGNUM *r, const BIGNUM *a, const BIGNUM *p, BN_CTX *ctx);
int BN_mod_exp(BIGNUM *r, const BIGNUM *a, const BIGNUM *p,
               const BIGNUM *m, BN_CTX *ctx);
int BN_gcd(BIGNUM *r, const BIGNUM *a, const BIGNUM *b, BN_CTX *ctx);

DESCRIPTION

BN_add() additionne a et b et place le résultat dans r ("r=a+b"). r peut être le même BIGNUM que a ou b.

BN_sub() soustrait b de a et place le résultat dans r ("r=a-b"). r peut être le même BIGNUM que a ou b.

BN_mul() multiplie a et b et place le résultat dans r ("r=a*b"). r peut être le même BIGNUM que a ou b. Pour une multiplication par des puissances de 2, utilisez BN_lshift(3).

BN_sqr() prend le carré de a et place le résultat dans r ("r=a^2"). r et a peuvent être le même BIGNUM. Cette fonction est plus rapide que BN_mul(r,a,a).

BN_div() divise a par d et place le résultat dans dv et le reste dans rem ("dv=a/d, rem=a%d"). L'un des deux dv et rem peut être NULL, auquel cas la valeur correspondante n'est pas retournée. Le résultat est arrondi vers zéro ; ainsi si a est négatif, le reste sera nul ou négatif. Pour une division par des puissances de 2, utilisez BN_rshift(3).

BN_mod() correspond à BN_div() avec dv défini à NULL.

BN_nnmod() réduit a modulo m et place le reste non négatif dans r.

BN_mod_add() additionne a à b modulo m et place le résultat non négatif dans r.

BN_mod_sub() soustrait b de a modulo m et place le résultat non négatif dans r.

BN_mod_mul() multiplie a par b et trouve le reste non négatif par rapport au module m ("r=(a*b) mod m"). r peut être le même BIGNUM que a ou b. Pour des algorithmes plus efficaces pour des calculs répétés utilisant le même module, voir BN_mod_mul_montgomery(3) et BN_mod_mul_reciprocal(3).

BN_mod_sqr() prend le carré de a modulo m et place le résultat dans r.

BN_mod_sqrt() renvoie la racine carrée modulaire de a telle que "in^2 = a (mod p)". Le module p doit être premier, sinon une erreur ou un "résultat" incorrect sera renvoyé. Le résultat est stocké dans in qui peut être NULL. Le résultat sera alors alloué à neuf.

BN_exp() élève a à la puissance pet place le résultat dans r ("r=a^p"). Cette fonction est plus rapide que des applications répétées de BN_mul().

BN_mod_exp() calcule a à la puissance pmodulo m ("r=a^p % m"). Cette fonction utilise moins de temps et d'espace que BN_exp(). N'appelez pas cette fonction lorsque m est pair et que l'un des paramètres a le drapeau BN_FLG_CONSTTIME défini.

BN_gcd() calcule le plus grand commun diviseur de a et b et place le résultat dans r. r peut être le même BIGNUM que a ou b.

Pour toutes les fonctions, ctx est un BN_CTX préalablement alloué utilisé pour les variables temporaires ; voir BN_CTX_new(3).

Sauf mention contraire, le résultat BIGNUM doit être différent des arguments.

NOTES

Pour les opérations modulaires telles que BN_nnmod() ou BN_mod_exp() il est une erreur d'utiliser le même objet BIGNUM pour le module que pour la sortie.

VALEURS RENVOYÉES

La fonction BN_mod_sqrt() renvoie le résultat (possiblement incorrect si p n'est pas premier), ou NULL.

Pour toutes les autres fonctions, 1 est renvoyé en cas de succès, 0 en cas d'erreur. La valeur de retour doit toujours être vérifiée (par ex., "if (!BN_add(r,a,b)) goto err;"). Les codes d'erreur peuvent être obtenus par ERR_get_error(3).
