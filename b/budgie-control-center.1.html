DESCRIPTIO

N

budgie-control-center est une interface graphique utilisateur pour configurer divers aspects de

Budgie.

Lorsqu'il est exécuté sans arguments, le shell affiche l'aperçu, qui montre tous les panneaux de configuration disponibles. L'aperçu permet d'ouvrir des panneaux individuels en cliquant dessus. Il dispose également d'une zone de recherche pour trouver des panneaux en recherchant des

mots-clés.

Il est également possible de spécifier un nom de panneau comme argument de ligne de commande pour accéder directement à ce panneau. Certains panneaux individuels peuvent accepter d'autres arguments pour spécifier l'onglet à ouvrir (pour les panneaux à plusieurs onglets) ou l'élément à afficher (pour les panneaux avec des listes)

.

Notez que budgie-control-center n'a pas pour but d'exposer chaque paramètre disponible. Les paramètres que l'on trouve ici représentent ce qui est considéré comme des options utiles et couramment nécessaires. Pour des options plus exotiques ou moins courantes, vous pouvez consulter gnome-tweak-tool ou l'utilitaire en ligne de commande gsett

ing
s.

Vous pouvez ouvrir ce panneau sur une boîte de dialogue spécifique en passant create-wifi, connect-hidden-wifi, connect-3g, connect-8021x-wifi ou show-device comme argument supplémentaire. Le panneau printers affiche toutes les imprimantes connues et leur statut. Il est possible d'inspecter les travaux d'impression en file d'attente et d'ajouter de nouvelles imprimantes.
