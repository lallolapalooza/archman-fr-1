NOM

bup-init - initialiser un dépôt bup

SYNTAXE

[BUP_DIR=cheminlocal] bup init [-r hôte:chemin]

DESCRIPTION

bup init initialise votre dépôt bup local. Par défaut, BUP_DIR est ~/.bup.

OPTIONS

-r, --remote=hôte:chemin
Initialise non seulement le dépôt local, mais aussi le dépôt distant donné par l'hôte et le chemin. Ceci n'est pas nécessaire si vous souhaitez sauvegarder vers l'emplacement par défaut sur le serveur (c'est-à-dire un chemin vide). La connexion au serveur distant est établie via SSH. Si vous souhaitez spécifier le port, l'utilisateur ou la clé privée à utiliser pour la connexion SSH, nous vous recommandons d'utiliser le fichier ~/.ssh/config.

EXEMPLES

bup init

VOIR AUSSI

bup-fsck(1), ssh_config(5)
