xml2bib

xml2bib convertit la bibliographie XML MODS en un fichier de références formaté en bibtex. L'utilisation de xml2bib est comme pour les autres outils

xml2bib xml_file.xml > output_file.bib

Étant donné que le format de référence BibTeX est assez flexible et semble avoir le plus grand nombre de préférences personnelles, il a également accumulé un certain nombre d'options spécifiques qui ne sont pas disponibles pour d'autres formats.

À partir de la version 3.24, la sortie de xml2bib utilise des étiquettes en minuscules et des types de référence en casse mixte pour une meilleure interaction avec d'autres logiciels. Le comportement précédent avec des étiquettes/types de référence entièrement en majuscules peut toujours être généré en utilisant le commutateur de ligne de commande -U/--uppercase.

Options spécifiques à xml2bib :

-fc --finalcomma ajouter une virgule finale dans la sortie bibtex pour ceux qui la veulent
-sd --singledash utiliser un tiret au lieu de deux (tiret plus long en latex) entre les nombres dans la sortie des pages
-b --brackets utiliser des crochets au lieu de guillemets autour des données de champ
-w --whitespace ajouter des espaces blancs d'embellissement à la sortie
-U --uppercase utiliser toutes les majuscules pour les étiquettes (noms de champs) et les types de référence (comportement pré-3.24)
-sk --strictkey utiliser uniquement des caractères alphanumériques pour les clés de citation bibtex

xml2ads

xml2ads convertit la bibliographie XML MODS au format de référence du Smithsonian Astrophysical Observatory (SAO)/National Aeronautics and Space Administration (NASA) Astrophyics Data System ou ADS[6] (qui est très similaire au style Endnote étiqueté). L'utilisation de xml2ads est comme pour les autres outils

xml2ads xml_file.xml > output_file.ads

xml2ris

xml2ris convertit la bibliographie XML MODS en un fichier bibliographique formaté en RIS. L'utilisation de xml2ris est comme pour les autres outils

xml2ris xml_file.xml > output_file.ris

xml2end

xml2end convertit la bibliographie XML MODS en un fichier bibliographique Endnote étiqueté (format refer). L'utilisation de xml2end est comme pour les autres outils

xml2end xml_file.xml > output_file.end

xml2wordbib

xml2wordbib convertit la bibliographie XML MODS en un fichier bibliographique XML formaté pour Word 2007. L'utilisation de xml2wordbib est comme pour les autres outils

xml2wordbib xml_file.xml > output_file.word.xml

xml2wordbib s'appelait xml2word dans les versions de bibutils antérieures à la 3.40. Il a été renommé pour éviter la confusion avec d'autres outils. Espérons que cela ne cassera pas trop de scripts déjà en cours d'utilisation.

NOM

bibutils - Outils de conversion de base de données bibliographique

SYNOPIS

bibutils [options] fichier_entree...

DESCRIPTION

Les outils bibutils sont une collection d'utilitaires permettant de convertir des formats de base de données bibliographique. Ils prennent en charge un certain nombre de formats d'entrée et de sortie courants.

CONVERSION VERS MODS

Pour convertir un fichier bibliographique vers le format MODS, vous pouvez utiliser l'option -o MODS.

CONVERSION DEPUIS MODS

Pour convertir un fichier au format MODS vers un autre format, spécifiez le format de sortie souhaité.

EXEMPLES

Convertir un fichier BibTeX en RIS :

bibutils -o RIS input.bib

Convertir un fichier EndNote en BibTeX :

bibutils -o BibTeX input.enl
