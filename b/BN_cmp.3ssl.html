BN_cmp(3ssl)

Paquet: openssl

Licences: Apache-2.0

BN_CMP(3ssl) OpenSSL BN_CMP(3ssl)

NOM

BN_cmp, BN_ucmp, BN_is_zero, BN_is_one, BN_is_word, BN_abs_is_word, BN_is_odd, BN_are_coprime - Fonctions de comparaison et de test BIGNUM

SYNTAXE

#include <openssl/bn.h>
int BN_cmp(const BIGNUM *a, const BIGNUM *b);
int BN_ucmp(const BIGNUM *a, const BIGNUM *b);
int BN_is_zero(const BIGNUM *a);
int BN_is_one(const BIGNUM *a);
int BN_is_word(const BIGNUM *a, const BN_ULONG w);
int BN_abs_is_word(const BIGNUM *a, const BN_ULONG w);
int BN_is_odd(const BIGNUM *a);
int BN_are_coprime(BIGNUM *a, const BIGNUM *b, BN_CTX *ctx);

DESCRIPTION

BN_cmp() compare les nombres a et b. BN_ucmp() compare leurs valeurs absolues.

BN_is_zero(), BN_is_one(), BN_is_word() et BN_abs_is_word() testent si a est égal à 0, 1, w, ou |w| respectivement. BN_is_odd() teste si a est impair.

BN_are_coprime() détermine si a et b sont copremiers. ctx est utilisé en interne pour stocker des variables temporaires. Les valeurs de a, b et ctx ne doivent pas être NULL.

VALEUR DE RETOUR

BN_cmp() retourne -1 si a < b, 0 si a == b et 1 si a > b. BN_ucmp() fait de même en utilisant les valeurs absolues de a et b.

BN_is_zero(), BN_is_one(), BN_is_word(), BN_abs_is_word() et BN_is_odd() retournent 1 si la condition est vraie, 0 sinon.

BN_are_coprime() retourne 1 si les BIGNUM sont copremiers, sinon elle retourne 0.

HISTORIQUE

Avant OpenSSL 1.1.0, BN_is_zero(), BN_is_one(), BN_is_word(), BN_abs_is_word() et BN_is_odd() étaient des macros.

La fonction BN_are_coprime() a été ajoutée dans OpenSSL 3.1.
