NOM

batpipe - Un préprocesseur pour less (et bat) pour afficher plus de types de fichiers dans le terminal.

DESCRIPTION

UTILISATION

Comme lesspipe, batpipe est conçu pour fonctionner avec les programmes qui supportent le préprocesseur via la variable d'environnement LESSOPEN. La configuration de batpipe dépendra de votre shell :

Bash :


eval "$(batpipe)"

Fish :


eval (batpipe)

ENVIRONNEMENT

Variable Description
BATPIPE_TERM_WIDTH Définit la largeur du terminal fournie à bat. Si cette variable commence par un tiret (-), le nombre fourni sera relatif à la taille détectée du terminal.

VISUALISEURS INTÉGRÉS

Fichiers Programme
Répertoires eza, ls
.tar, .tar.gz tar
.zip, .jar unzip
.gz gunzip
.xz xz

VISUALISEURS EXTERNES

Pour les formats de fichiers non pris en charge par défaut, un visualiseur de fichiers externe peut être ajouté à batpipe via l'API des visualiseurs externes.

Les visualiseurs externes sont ajoutés à batpipe en créant des scripts bash dans le répertoire ~/.config/batpipe/viewers.d/.

Création de visualiseurs

Les visualiseurs doivent définir deux fonctions et ajouter le nom du visualiseur au tableau $BATPIPE_VIEWERS.


- viewer_${viewer}_supports [nom_fichier] [chemin_fichier] [chemin_fichier_interne]
- viewer_${viewer}_process [chemin_fichier] [chemin_fichier_interne]

La fonction viewer_${viewer}_supports est appelée pour déterminer si le visualiseur externe est capable de visualiser le fichier fourni. Si cette fonction réussit, la fonction process correspondante sera appelée.

API


$BATPIPE_VIEWERS -- Un tableau des visualiseurs de fichiers chargés.
$BATPIPE_ENABLE_COLOR -- Indique si la couleur est prise en charge. (true|false)
$BATPIPE_INSIDE_LESS -- Indique si batpipe est à l'intérieur de less. (true|false)


batpipe_header [motif] [...] -- Affiche une ligne d'en-tête du visualiseur.
batpipe_subheader [motif] [...] -- Affiche une ligne de sous-en-tête du visualiseur.


strip_trailing_slashes [chemin] -- Supprime les barres obliques finales d'un chemin.

LIMITATIONS

- Par défaut, batpipe n'utilisera pas de couleurs lorsqu'il est prévisualisé dans less.
Les couleurs doivent être explicitement activées avec BATPIPE=color.
