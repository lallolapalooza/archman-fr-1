DESCRIPTIO

N

Bison est un générateur de parseur dans le style de yacc(1). Il devrait être compatible avec les fichiers d'entrée conçus pour yacc

.

Les fichiers d'entrée devraient suivre la convention de yacc de se terminer par .y. Contrairement à yacc, les fichiers générés n'ont pas de noms fixes, mais utilisent à la place le préfixe du fichier d'entrée. De plus, si vous devez mettre du code C++ dans le fichier d'entrée, vous pouvez terminer son nom par une extension de type C++ (.ypp ou .y++), alors bison suivra votre extension pour nommer le fichier de sortie (.cpp ou .c++). Par exemple, un fichier de description de grammaire nommé parse.yxx produirait le parseur généré dans un fichier nommé parse.tab.cxx, au lieu de y.tab.c de yacc ou de parse.tab.c des anciennes versions de Biso

n.

Cette description des options qui peuvent être données à bison est adaptée du nœud Invocation du manuel bison.texi, qui devrait être considéré comme faisant

autorité.

Bison prend en charge les options traditionnelles à une lettre ainsi que les noms d'options longs mnémoniques. Les noms d'options longs sont indiqués avec -- au lieu de -. Les abréviations des noms d'options sont autorisées pourvu qu'elles soient uniques. Lorsqu'une option longue prend un argument, comme --file-prefix, reliez le nom de l'option et l'argument avec =

.

Génère un parseur LR déterministe ou LR généralisé (GLR) en employant les tables de parseur LALR(1), IELR(1) ou LR(1)

canonique.

Les arguments obligatoires des options longues le sont aussi pour les options courtes. Il en va de même pour les arguments

facultatifs.
