NOM

besside-ng - Cracker une clé WEP ou WPA sans intervention de l'utilisateur et collaborer avec les statistiques de craquage WPA

SYNTAXE

besside-ng [options] <interface>

DESCRIPTION

besside-ng est un outil qui permet de cracker tous les réseaux WEP à portée et d'enregistrer toutes les poignées de main WPA. Les poignées de main WPA peuvent être téléversées vers le service de craquage en ligne à l'adresse wpa.darkircop.org. Wpa.darkircop.com fournit également des statistiques utiles basées sur les fichiers de capture soumis par les utilisateurs concernant la faisabilité du craquage WPA.

-b <mac> cible
Spécifie le BSSID de la cible
-s <serveur WPA>
Où téléverser le fichier de capture pour le craquage. Un bon choix est wpa.darkircop.org
-c <canal>
Verrouillage du canal
-p <paquets par seconde>
Paquets par seconde à envoyer (taux d'inondation).
-W
Craquer uniquement les réseaux WPA
-v
Mode verbeux. Utiliser -vv pour plus de verbeux, -vvv pour encore plus, et ainsi de suite.
-h
Écran d'aide
