NOM

borg-key-change-passphrase - Changer le mot de passe du fichier de clé

SYNTAXE

borg [options communes] key change-passphrase [options] [RÉPERTOIRE]

DESCRIPTION

Les fichiers de clé utilisés pour le chiffrement du dépôt sont facultativement protégés par un mot de passe. Cette commande peut être utilisée pour changer ce mot de passe.

Veuillez noter que cette commande ne fait que changer le mot de passe, mais pas les secrets protégés par celui-ci (par exemple, les clés de chiffrement/MAC ou la graine du chunker). Par conséquent, changer le mot de passe après que le mot de passe et la clé Borg aient été compromis ne protège pas les sauvegardes futures (ni passées) vers le même dépôt.

OPTIONS

Voir borg-common(1) pour les options communes des commandes Borg.

arguments

RÉPERTOIRE

EXEMPLES

# Créer un dépôt protégé par un fichier de clé
$ borg init --encryption=keyfile -v /chemin/vers/repo
Initializing repository at "/chemin/vers/repo"
Enter new passphrase:
Enter same passphrase again:
Remember your passphrase. Your data will be inaccessible without it.
Key in "/root/.config/borg/keys/mnt_backup" created.
Keep this key safe. Your data will be inaccessible without it.
Synchronizing chunks cache...
Archives: 0, w/ cached Idx: 0, w/ outdated Idx: 0, w/o cached Idx: 0.
Done.
# Changer le mot de passe du fichier de clé
$ borg key change-passphrase -v /chemin/vers/repo
Enter passphrase for key /root/.config/borg/keys/mnt_backup:
Enter new passphrase:
Enter same passphrase again:
Remember your passphrase. Your data will be inaccessible without it.
Key updated
# Importer une clé précédemment exportée dans le fichier de clé spécifié
# (créant ou écrasant la clé de sortie)
# (dépôts avec fichier de clé uniquement)
$ BORG_KEY_FILE=/chemin/vers/cle-sortie borg key import /chemin/vers/repo /chemin/vers/export

Entièrement automatisé à l'aide de variables d'environnement :

$ BORG_NEW_PASSPHRASE=ancien borg init -e=repokey repo
# maintenant "ancien" est le mot de passe actuel.
$ BORG_PASSPHRASE=ancien BORG_NEW_PASSPHRASE=nouveau borg key change-passphrase repo
# maintenant "nouveau" est le mot de passe actuel.
