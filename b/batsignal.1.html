BATSIGNAL(1) Manuel des commandes générales BATSIGNAL(1)

NOM

batsignal - démon de surveillance de batterie

SYNTAXE

batsignal [OPTIONS]

DESCRIPTION

batsignal est un démon de batterie léger écrit en C qui notifie l'utilisateur sur les états de la batterie. Il est destiné aux gestionnaires de fenêtres minimalistes, mais peut être utilisé dans tout environnement qui prend en charge les notifications de bureau via libnotify.

OPTIONS

-h
Afficher l'aide
-v
Afficher les informations de version
-b
Exécuter batsignal en tant que démon en arrière-plan
-o
Vérifier la batterie une fois et quitter
-i
Ignorer les erreurs de batterie manquante
-e
Faire expirer les notifications
-N
Désactiver les notifications de bureau
-w NIVEAU
Niveau d'alerte de batterie NIVEAU (défaut 15). 0 désactive ce niveau
-c NIVEAU
Niveau critique de batterie NIVEAU (défaut 5). 0 désactive ce niveau
-d NIVEAU
Niveau de danger de batterie NIVEAU (défaut 2). 0 désactive ce niveau
-f NIVEAU
Niveau de batterie pleine NIVEAU (défaut 0). 0 désactive ce niveau
-p
Afficher un message lorsque la batterie commence à charger ou à se décharger
-W MESSAGE
Afficher MESSAGE lorsque la batterie est au niveau d'alerte
-C MESSAGE
Afficher MESSAGE lorsque la batterie est au niveau critique
-D COMMANDE
Exécuter COMMANDE lorsque la batterie est au niveau de danger
-F MESSAGE
Afficher MESSAGE lorsque la batterie est pleine
-P MESSAGE
Afficher MESSAGE lorsque la batterie charge, si l'option -p est définie
-U MESSAGE
Afficher MESSAGE lorsque la batterie se décharge, si l'option -p est définie
-M COMMANDE
Envoyer chaque message en utilisant COMMANDE
-n NOM
NOM du périphérique batterie - plusieurs batteries peuvent être séparées par des virgules (par défaut BAT0)
-m SECONDES
Nombre minimum de SECONDES (par défaut 60) à attendre entre les vérifications de batterie. Définir SECONDES à 0 désactive le polling et attend le signal USR1 avant de vérifier le niveau de la batterie. Préfixer SECONDES avec un + (ex: -m +10) forcera une vérification à intervalles de SECONDES, quel que soit le niveau de la batterie.
-a NOM_APP
Nom de l'application utilisé dans les notifications (par défaut: batsignal)
-I ICÔNE
Afficher l'ICÔNE spécifiée dans les notifications

CONFIGURATION

Les options peuvent être passées à batsignal en tant qu'arguments de ligne de commande ou placées dans un fichier de configuration. Les options du fichier de configuration seront appliquées en premier, puis pourront être remplacées par les arguments de la ligne de commande.

Le fichier de configuration doit inclure les arguments d'options tels que décrits ci-dessus, un argument par ligne. Les lignes commençant par # et les lignes vides sont ignorées. Par exemple, pour spécifier un niveau d'alerte de 30 et s'exécuter en tant que démon en arrière-plan, le fichier de configuration suivant pourrait être utilisé :

# Exécuter en arrière-plan
-b
# Utiliser un niveau d'alerte de 30
-w
30

Les chemins suivants sont vérifiés en séquence pour un fichier de configuration :

•
Variable d'environnement BATSIGNAL_CONFIG (si présente)
•
$HOME/.config/batsignal (ou le répertoire de configuration de base spécifié dans XDG_CONFIG_HOME)
•
$HOME/.batsignal
•
/usr/local/etc/batsignal
•
/etc/batsignal

ENVIRONNEMENT

BATSIGNAL_CONFIG
Définit le chemin du fichier de configuration des options.
XDG_CONFIG_HOME
Le chemin de base pour le répertoire de configuration XDG. Utilisé dans la recherche du fichier d'options.

SIGNAUX

batsignal répond aux signaux suivants :

SIGUSR1
Envoyer le signal SIGUSR1 au processus déclenchera une vérification immédiate du niveau de la batterie.

NOTES

Dans la plupart des cas, batsignal effectuera moins de vérifications de l'état de la batterie lorsque la batterie se décharge et que le niveau de charge n'est pas proche d'un niveau d'alerte. Cette fréquence est affectée par l'option multiplicateur (-m) et n'est jamais inférieure à <multiplicateur> secondes. Si le niveau "plein" (-f) est défini ou si les messages de charge/décharge sont activés (-p), batsignal vérifiera l'état de la batterie toutes les <multiplicateur> secondes, quel que soit le niveau de charge.

Si le niveau "plein" (-f) est défini, la notification de batterie pleine sera déclenchée au niveau de charge spécifié ou lorsque le statut de la batterie passera à "pleine", selon la première éventualité.

La COMMANDE de message passée avec -M est une chaîne de format de style C printf. Elle peut utiliser deux espaces réservés de chaîne (%s) qui seront remplacés par le texte du message et le niveau actuel de la batterie. Assurez-vous de tester la commande - des chaînes de format invalides pourraient provoquer le plantage de batsignal.
Ex: -M "wall 'Alerte batterie : %s - Niveau %s'"
