NOM

borg-key-export - Exporter la clé du dépôt pour sauvegarde

SYNTAXE

borg [options communes] key export [options] [DÉPÔT] [CHEMIN]

DESCRIPTION

Si le chiffrement du dépôt est utilisé, le dépôt est inaccessible sans la clé. Cette commande permet de sauvegarder cette clé essentielle. Notez que la sauvegarde produite n'inclut pas le mot de passe lui-même (c'est-à-dire que la clé exportée reste chiffrée). Pour pouvoir accéder à nouveau à un dépôt, il faut disposer à la fois de la clé exportée et du mot de passe original.

Il existe trois formats de sauvegarde. Le format de sauvegarde normal convient au stockage numérique sous forme de fichier. Le format de sauvegarde --paper est optimisé pour l'impression et la saisie lors de l'importation, avec des contrôles par ligne pour réduire les problèmes de saisie manuelle. L'option --qr-html crée un modèle HTML imprimable avec un code QR et une copie de la clé au format --paper.

Pour les dépôts utilisant le chiffrement par fichier de clé, la clé est enregistrée localement sur le système capable d'effectuer des sauvegardes. Pour se prémunir contre la perte de cette clé, elle doit être sauvegardée indépendamment de la sauvegarde principale des données.

Pour les dépôts utilisant le chiffrement par clé de dépôt (repokey), la clé est enregistrée dans le dépôt dans le fichier de configuration. Une sauvegarde n'est donc pas strictement nécessaire, mais elle protège contre le fait que le dépôt devienne inaccessible si le fichier est endommagé pour une raison quelconque.

Exemples :

borg key export /chemin/vers/depot > sauvegarde-cle-chiffree
borg key export --paper /chemin/vers/depot > sauvegarde-cle-chiffree.txt
borg key export --qr-html /chemin/vers/depot > sauvegarde-cle-chiffree.html
# Ou passer le fichier de sortie en argument au lieu de rediriger stdout :
borg key export /chemin/vers/depot sauvegarde-cle-chiffree
borg key export --paper /chemin/vers/depot sauvegarde-cle-chiffree.txt
borg key export --qr-html /chemin/vers/depot sauvegarde-cle-chiffree.html

OPTIONS

Voir borg-common(1) pour les options communes des commandes Borg.

arguments

DÉPÔT

CHEMIN
où stocker la sauvegarde

options

--paper
Créer une exportation adaptée à l'impression et à une saisie ultérieure
--qr-html
Créer un fichier html adapté à l'impression et à une saisie ultérieure ou à un scan QR
