--no-default est spécifiée, la première configuration de compilation ajoutée ou créée de chaque type est désignée comme la configuration par défaut. Plusieurs commandes bdep utilisent une telle configuration par défaut si aucune configuration n'a été spécifiée

Notez aussi que dans le cas de plusieurs configurations par défaut, un paquet donné dans un projet ne peut être initialisé que dans l'une de ces configurations. La configuration de compilation par défaut de chaque type est aussi désignée comme transmise (forwarded) sauf si l'option--no-forwardest spécifiée ou si une autre configuration de ce type est déjà désignée comme transmise. Lorsqu'un projet est initialisé dans une configuration de compilation transmise, son répertoire source est configuré pour transmettre à cette configuration (voir b(1) pour plus de détails sur les configurations transmises). Pour désigner une configuration non par défaut comme transmise, utilisez l'option --forward. Notez aussi qu'il est possible d'avoir plusieurs configurations transmises, cependant, un paquet donné dans un projet ne peut être initialisé que dans l'une de ces configurations. Sauf si l'o
