BUNDLE-INFO(1) Manuel des commandes générales BUNDLE-INFO(1)

NOM

bundle-info - Afficher les informations pour le joyau donné dans votre bundle

SYNTAXE

bundle info [NOM_DU_JOYAU] [--path] [--version]

DESCRIPTION

Étant donné un nom de joyau présent dans votre bundle, affichez les informations de base à son sujet telles que la page d'accueil, la version, le chemin et le résumé.

OPTIONS

--path
Afficher le chemin du joyau donné
--version
Afficher la version du joyau
