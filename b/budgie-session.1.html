budgie-session(1) Manuel des commandes générales budgie-session(1)

NOM

budgie-session - Lance l'environnement de bureau budgie

SYNTAXE

budgie-session [-a|--autostart=DIR] [--session=SESSION] [--failsafe|-f] [--debug] [--whale]

DESCRIPTION

Le programme budgie-session lance l'environnement de bureau budgie. Cette commande est généralement exécutée par votre gestionnaire de connexion (gdm, xdm, ou depuis vos scripts de démarrage X). Il chargera soit votre session sauvegardée, soit l'installation budgie par défaut sur votre système. Notez que budgie-session est un script wrapper pour budgie-session-binary.

$XDG_CONFIG_HOME/budgie-session/sessions, $XDG_CONFIG_DIRS/budgie-session/sessions et $XDG_DATA_DIRS/budgie-session/sessions.

Lors de la sauvegarde d'une session, budgie-session enregistre les applications en cours d'exécution dans le répertoire $XDG_CONFIG_HOME/budgie-session/saved-session. La sauvegarde des sessions n'est prise en charge qu'avec la méthode de démarrage héritée non-systemd.

budgie-session est un gestionnaire de session X11R6. Il peut gérer les applications budgie ainsi que toute application conforme à X11R6 SM.

OPTIONS

Les options suivantes sont supportées :

--autostart=REP
Le répertoire REP dans lequel rechercher les fichiers .desktop d'autodémarrage. Cette option peut être utilisée plusieurs fois. Lorsque cette option est présente, les répertoires d'autodémarrage par défaut ne seront pas recherchés.
--session=SESSION
Utilise les applications définies dans SESSION.session. Si non spécifié, budgie.session sera utilisé.
--builtin
Utilise la méthode héritée non-systemd pour gérer la session utilisateur.
--failsafe
Exécute en mode de sécurité (fail-safe). Les applications spécifiées par l'utilisateur ne seront pas démarrées.
--debug
Active le code de débogage.
--whale
Affiche la baleine de sécurité (fail whale) dans une boîte de dialogue pour le débogage.

DÉFINITION DE SESSION

Les sessions sont définies dans des fichiers .session, qui utilisent un format similaire aux fichiers .desktop, avec les clés suivantes dans le groupe budgie Session :

Nom
Nom de la session. Peut être localisé.
RequiredComponents
Liste des identifiants de composants (fichiers desktop) requis par la session. Les composants requis seront toujours exécutés dans la session.

Voici un exemple de définition de session :


[budgie Session]
Nom=budgie
RequiredComponents=budgie-desktop;gnome-settings-daemon;

Les fichiers .session sont recherchés dans $XDG_CONFIG_HOME/budgie-session/sessions, $XDG_CONFIG_DIRS/budgie-session/sessions et $XDG_DATA_DIRS/budgie-session/sessions.

Il est préférable d'utiliser --builtin si des personnalisations de session sont nécessaires. Ceci est dû à la manière dont budgie définit actuellement les composants qui seront démarrés pour chaque type de session.

ENVIRONNEMENT

budgie-session définit plusieurs variables d'environnement pour l'utilisation de ses processus enfants :

SESSION_MANAGER

Cette variable est utilisée par les clients conscients du gestionnaire de session pour contacter budgie-session.

DISPLAY

Cette variable est définie sur l'écran X utilisé par budgie-session. Notez que si l'option --display est utilisée, cela peut être différent du réglage de la variable d'environnement lors de l'invocation de budgie-session.

Le comportement de budgie-session lui-même peut être modifié via la variable d'environnement suivante :

GNOME_SESSION_AUTOSTART_DIR

Cette variable spécifie une liste de répertoires à rechercher pour les fichiers d'autodémarrage. Cette variable remplace tous les répertoires spécifiés via l'option --autostart, ainsi que tous les répertoires d'autodémarrage par défaut.

FICHIERS

$XDG_CONFIG_HOME/autostart $XDG_CONFIG_DIRS/autostart /usr/share/gnome/autostart

Les applications définies via des fichiers .desktop dans ces répertoires seront démarrées à la connexion.

$XDG_CONFIG_HOME/budgie-session/sessions $XDG_CONFIG_DIRS/budgie-session/sessions $XDG_DATA_DIRS/budgie-session/sessions

Ces répertoires contiennent les fichiers .session qui peuvent être utilisés avec l'option --session.

$XDG_CONFIG_HOME/budgie-session/saved-session

Ce répertoire contient la liste des applications de la session sauvegardée.

BOGUES

Si vous trouvez des bogues dans le programme budgie-session, veuillez les signaler sur https://github.com/buddiesofbudgie/budgie-session/issues.
