BLKLS(1) Manuel des commandes générales BLKLS(1)

NOM

blkls - Lister ou sortir les unités de données du système de fichiers.

SYNTAXE

blkls [-aAelsvV] [-f type_fs ] [-i type_image ] [-o decalage_image ] [-b taille_secteur_dev] image [images] [debut-fin]

DESCRIPTION

blkls ouvre l'image(s) nommée(s) et copie les unités de données (blocs) du système de fichiers. Par défaut, blkls copie le contenu des blocs de données non alloués. blkls était appelé dls dans les versions de TSK antérieures à 3.0.0. blkls était appelé unrm dans TCT.

ARGUMENTS

-e
Copie chaque bloc, y compris les blocs de métadonnées du système de fichiers. La sortie représente le système de fichiers entier.
-a
Affiche tous les blocs alloués (identique à -e si -A est également donné).
-A
Affiche tous les blocs non alloués (identique à -e si -a est également donné). C'est le comportement par défaut.
-f type_fs
Spécifie le type de système de fichiers. Utiliser '-f list' pour lister les types de systèmes de fichiers supportés. Si non spécifié, les méthodes de détection automatique sont utilisées.
-i type_image
Identifie le type du fichier image, tel que brut. Utiliser '-i list' pour lister les types supportés. Si non spécifié, les méthodes de détection automatique sont utilisées.
-o decalage_image
Le décalage de secteur où le système de fichiers commence dans l'image.
-b taille_secteur_dev
La taille, en octets, des secteurs du périphérique sous-jacent. Si non spécifié, la valeur du format de l'image est utilisée (si elle existe) ou 512 octets sont supposés.
-l
Liste les informations de données au format machine à remonter le temps.
-s
Copie uniquement l'espace de décalage de l'image.
-v
Active le mode verbeux, sortie vers stderr.
-V
Affiche la version.
image [images]
L'image du disque ou de la partition à lire, dont le format est spécifié avec '-i'. Plusieurs noms de fichiers image peuvent être donnés si l'image est divisée en plusieurs segments. Si un seul fichier image est donné, et que son nom est le premier d'une séquence (par exemple, indiqué par une fin en '.001'), les segments d'image suivants seront inclus automatiquement.
debut-fin ...
Examine le numéro de bloc spécifié ou la plage de numéros.
