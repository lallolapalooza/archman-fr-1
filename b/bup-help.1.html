NOM

bup-help - ouvrir la documentation d'une commande bup donnée

SYNOPSIS

bup help <commande>

DESCRIPTION

bup help <commande> ouvre la documentation de la commande spécifiée. Ceci est actuellement équivalent à taper man bup-<commande>.

EXEMPLES

$ bup help help
(Imaginez que cette page de manuel soit collée ci-dessous,
 récursivement. Comme cela provoquerait une boucle infinie,
 nous incluons cette remarque idiote à la place. Poulet.)
