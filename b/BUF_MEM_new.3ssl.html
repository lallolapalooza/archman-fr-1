BUF_MEM_new(3ssl)

Paquet: openssl

Licences: Apache-2.0

BUF_MEM_NEW(3ssl) OpenSSL BUF_MEM_NEW(3ssl)

NOM

BUF_MEM_new, BUF_MEM_new_ex, BUF_MEM_free, BUF_MEM_grow, BUF_MEM_grow_clean, BUF_reverse - structure simple de tableau de caractères

SYNTAXE

#include <openssl/buffer.h>
BUF_MEM *BUF_MEM_new(void);
BUF_MEM *BUF_MEM_new_ex(unsigned long flags);
void BUF_MEM_free(BUF_MEM *a);
int BUF_MEM_grow(BUF_MEM *str, int len);
size_t BUF_MEM_grow_clean(BUF_MEM *str, size_t len);
void BUF_reverse(unsigned char *out, const unsigned char *in, size_t size);

DESCRIPTION

La bibliothèque de tampons gère des tableaux de caractères simples. Les tampons sont utilisés à diverses fins dans la bibliothèque, notamment les BIO en mémoire.

BUF_MEM_new() alloue un nouveau tampon de taille zéro.

BUF_MEM_new_ex() alloue un tampon avec les indicateurs spécifiés. L'indicateur BUF_MEM_FLAG_SECURE spécifie que le pointeur data doit être alloué sur le tas sécurisé ; voir CRYPTO_secure_malloc(3).

BUF_MEM_free() libère un tampon déjà existant. Les données sont mises à zéro avant d'être libérées au cas où le tampon contiendrait des données sensibles. Si l'argument est NULL, rien n'est fait.

BUF_MEM_grow() modifie la taille d'un tampon déjà existant à len. Toute donnée déjà présente dans le tampon est préservée s'il augmente de taille.

BUF_MEM_grow_clean() est similaire à BUF_MEM_grow() mais met à zéro toute mémoire libérée ou allouée supplémentaire.

BUF_reverse() inverse size octets à in dans out. Si in est NULL, le tableau est inversé sur place.

VALEURS DE RETOUR

BUF_MEM_new() renvoie le tampon ou NULL en cas d'erreur.

BUF_MEM_free() n'a pas de valeur de retour.

BUF_MEM_grow() et BUF_MEM_grow_clean() renvoient zéro en cas d'erreur ou la nouvelle taille (c'est-à-dire len).

VOIR AUSSI

bio(7), CRYPTO_secure_malloc(3).

HISTORIQUE

La fonction BUF_MEM_new_ex() a été ajoutée dans OpenSSL 1.1.0.
