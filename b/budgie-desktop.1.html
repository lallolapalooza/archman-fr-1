BUDGIE-DESKTOP(1) Commandes utilisateur BUDGIE-DESKTOP(1)

NOM

budgie-desktop - point d'entrée central depuis gnome-session pour afficher l'interface graphique

DESCRIPTION

Utilisation :

gnome-session-binary [OPTION?]
? le gestionnaire de session GNOME

Options d'aide :

-h, --help
Afficher les options d'aide

Options de l'application :

--systemd-service
Exécution en tant que service systemd
--systemd
Utiliser la gestion de session systemd
--builtin
Utiliser la gestion de session intégrée (plutôt que celle basée sur systemd)
-a, --autostart=RÉPERTOIRE_AUTOSTART
Remplacer les répertoires d'autostart standard
--session=NOM_SESSION
Session à utiliser
--debug
Activer le code de débogage
-f, --failsafe
Ne pas charger les applications spécifiées par l'utilisateur
--version
Version de cette application
--whale
Afficher la boîte de dialogue fail whale pour les tests
--disable-acceleration-check
Désactiver la vérification de l'accélération matérielle
