NOM

byobu-export - OBSOLÈTE

SYNTAXE

byobu-export

DESCRIPTION

L'utilitaire byobu-export est maintenant obsolète.

Pour installer byobu sur un système pour lequel byobu n'est pas packagé, ou lorsque vous n'êtes pas l'utilisateur root, il suffit de :
* Télécharger la dernière version (>= 3.0) depuis :
https://github.com/dustinkirkland/byobu
* Et suivre les instructions du README.
