NOM

basic_getpwnam_auth - Aide à l'authentification des utilisateurs locaux pour Squid

SYNTAXE

basic_getpwnam_auth

DESCRIPTION

basic_getpwnam_auth permet à Squid d'authentifier n'importe quel compte utilisateur local pour valider le nom d'utilisateur et le mot de passe de l'authentification HTTP de base.

Il utilise les routines getpwnam() et getspnam() pour l'authentification.

Cela présente les avantages suivants par rapport au module NCSA :

- Permet l'authentification de tous les utilisateurs locaux connus
- Permet l'authentification via nsswitch.conf
- Peut gérer les requêtes NIS(+)
- Peut gérer les requêtes LDAP
- Peut gérer les requêtes PAM

CONFIGURATION

auth_param basic program /chemin/vers/basic_getpwnam_auth
auth_param basic children concurrency=1

Lorsqu'il est utilisé pour authentifier auprès des bases de données de mots de passe shadow UNIX locales, le programme doit être exécuté en tant que root, sinon il n'aura pas les permissions suffisantes pour accéder à la base de données des mots de passe utilisateur. Une telle utilisation de ce programme n'est pas recommandée, mais si vous en avez absolument besoin, faites en sorte que le programme soit setuid root

chown root basic_getpwnam_auth
chmod u+s basic_getpwnam_auth

Veuillez noter que dans de telles configurations, il est également fortement recommandé de déplacer le programme dans un répertoire où les utilisateurs normaux ne peuvent pas y accéder, car ce mode de fonctionnement permettra à tout utilisateur local de forcer brute les mots de passe des autres utilisateurs. Notez également que le programme n'a pas été entièrement audité et que l'auteur ne peut être tenu responsable de tout problème de sécurité dû à de telles installations.
