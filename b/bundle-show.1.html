NOM

bundle-show - Affiche tous les gems de votre bundle, ou le chemin d'un gem

SYNOPSIS

bundle show [GEM] [--paths] [--outdated]

DESCRIPTION

Sans l'option [GEM], show affichera une liste des noms et versions de tous les gems requis par votre [Gemfile(5)][Gemfile(5)], triés par nom.

Appeler show avec [GEM] listera l'emplacement exact de ce gem sur votre machine.

OPTIONS

--paths
Liste les chemins de tous les gems requis par votre [Gemfile(5)][Gemfile(5)], triés par nom de gem.
--outdated
Affiche une sortie détaillée, y compris si les gems sont obsolètes.
