NOM

borg-version - Afficher la version du client borg / serveur borg

SYNTAXE

borg [options communes] version [options] [RÉFÉRENTIEL]

DESCRIPTION

Cette commande affiche la version du client Borg / la version du serveur Borg.

Si un dépôt local est spécifié, le code client accède directement au dépôt, nous affichons donc également la version du client comme version du serveur.

Si un dépôt distant est spécifié (par exemple, ssh:), le Borg distant est interrogé et sa version est affichée comme version du serveur.

Exemples :

# dépôt local (le client utilise la version alpha 1.4.0)
$ borg version /mnt/backup
1.4.0a / 1.4.0a
# dépôt distant (le client utilise la version alpha 1.4.0, le serveur utilise la version stable 1.2.7)
$ borg version ssh://borg@borgbackup:repo
1.4.0a / 1.2.7

En raison du format de tuple de version utilisé dans la négociation client/serveur de Borg, seule une version simplifiée est affichée (telle que fournie par borg.version.format_version).

Il existe également borg --version pour afficher une version client potentiellement plus précise.

OPTIONS

Voir borg-common(1) pour les options communes des commandes Borg.

arguments

RÉFÉRENTIEL
référentiel (utilisé pour déterminer la situation client/serveur)
