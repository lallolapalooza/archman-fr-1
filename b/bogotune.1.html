BOGOTUNE(1) Manuel de référence de Bogofilter BOGOTUNE(1)

NOM

bogotune - trouver les réglages optimaux pour bogofilter

SYNTAXE

bogotune [-v] [-c config] [-C] [-d dir] [-D] [-r valeur] [-T valeur] -n fichier_ok [[-n] fichier_ok [...]] -s fichier_spam [[-s] fichier_spam [...]] [-M fichier]

bogotune [-h]

DESCRIPTION

Bogotune tente de trouver les réglages optimaux pour bogofilter. Il nécessite au moins un ensemble de messages spam et non-spam. La liste de mots de production est normalement utilisée, mais il peut être dirigé pour lire une liste de mots différente, ou pour en construire une à partir de la moitié des messages fournis.

Afin de produire des résultats utiles, bogotune a des exigences minimales en nombre de messages. La liste de mots qu'il utilise doit contenir au moins 2 000 messages spam et 2 000 non-spam, et les fichiers de messages doivent contenir au moins 500 messages spam et 500 non-spam. De plus, le ratio de spam sur non-spam doit être compris entre 0,2 et 5. Si vous dirigez bogotune pour construire sa propre liste de mots, il utilisera la moitié des entrées ou 2000 messages (le plus grand des deux) pour la liste de mots.

Les fichiers de messages peuvent être au format mbox, maildir, ou dossier MH, ou toute combinaison. Les fichiers de comptage de messages peuvent également être utilisés, mais pas mélangés avec d'autres formats.

OPTIONS

L'option -h affiche le message d'aide et quitte.

L'option -v augmente le niveau de verbosité. Le niveau 1 affiche la sortie de l'analyse en détail au lieu d'utiliser une barre de progression.

L'option -c nom_fichier indique à bogofilter de lire le fichier de configuration nommé.

L'option -C empêche bogotune de lire un fichier de configuration.

L'option -d dir spécifie le répertoire pour la base de données. Voir la section ENVIRONNEMENT pour d'autres options de réglage de répertoire.

L'option -D indique à bogotune de construire une liste de mots en mémoire en utilisant les messages d'entrée. Les messages sont lus et divisés en deux groupes. Le premier groupe est utilisé pour construire une liste de mots (en RAM) et le second est utilisé pour l'optimisation. Pour respecter les exigences minimales de 2000 messages dans la liste de mots et 500 messages pour les tests, lorsque -D est utilisé, il doit y avoir 2500 non-spam et 2500 spam dans les fichiers d'entrée. S'il y a suffisamment de messages (plus de 4000), ils seront répartis équitablement entre la liste de mots et les tests. Sinon, ils seront répartis proportionnellement.

L'option -n indique à bogotune que l'argument suivant est un fichier (ou un dossier) contenant des non-spams. Depuis la version 1.0.3, plusieurs arguments à l'option -n peuvent être donnés. Tous les arguments sans option jusqu'à la prochaine option -s seront traités comme s'ils avaient été précédés de -n.

L'option -s indique à bogotune que l'argument suivant est un fichier (ou un dossier) contenant du spam. Elle peut être répétée autant de fois que nécessaire. Depuis la version 1.0.3, plusieurs arguments à l'option -s peuvent être donnés. Tous les arguments sans option jusqu'à la prochaine option -n seront traités comme s'ils avaient été précédés de -s.

L'option -r valeur indique à bogotune d'utiliser le paramètre suivant comme valeur robx.

L'option -T valeur indique à bogotune d'utiliser le paramètre suivant comme valeur cible fp.

L'option -M fichier indique à bogotune de convertir le fichier au format de comptage de messages. Ce format fournit une liste triée des tokens uniques de chaque message, ainsi que leurs comptes de ham et de spam. Le tri masque efficacement le sens des messages, protégeant ainsi la vie privée. Le format de comptage de messages permet à bogotune et bogofilter de scorer les messages rapidement sans avoir besoin de la base de données de tokens d'origine.

ENVIRONNEMENT

Bogofilter utilise un répertoire de base de données, qui peut être défini dans le fichier de configuration. S'il n'y est pas défini, bogofilter utilisera la valeur de BOGOFILTER_DIR. Les deux peuvent être remplacés par l'option -ddir. Si rien de tout cela n'est disponible, bogofilter utilisera le répertoire $HOME/.bogofilter.

BOGUES

Bogotune n'est pas particulièrement robuste lorsqu'il est présenté avec des entrées invalides.
