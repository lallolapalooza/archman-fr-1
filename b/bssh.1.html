NOM

bssh/bvnc/bshell - Recherche de serveurs SSH/VNC sur le réseau local

SYNTAXE

bssh

bvnc

bshell

DESCRIPTION

bssh/bvnc/bshell recherche des serveurs SSH/VNC sur le réseau local, les affiche dans une interface graphique pour que l'utilisateur en sélectionne un, et appelle finalement ssh/vncviewer une fois la sélection effectuée.

Si le binaire est appelé sous le nom bssh, seuls les serveurs SSH seront affichés. Si le binaire est appelé sous le nom bvnc, seuls les serveurs VNC seront affichés. Si le binaire est appelé sous le nom bshell, les serveurs VNC et SSH seront affichés.

OPTIONS

-s | --ssh
Recherche des serveurs SSH (et uniquement des serveurs SSH) quel que soit le nom sous lequel le binaire est appelé.
-v | --vnc
Recherche des serveurs VNC (et uniquement des serveurs VNC) quel que soit le nom sous lequel le binaire est appelé.
-S | --shell
Recherche à la fois des serveurs VNC et SSH quel que soit le nom sous lequel le binaire est appelé.
-d | --domain= DOMAINE
Recherche dans le domaine spécifié. Si omis, bssh/bvnc/bshell recherchera dans le domaine de recherche par défaut (généralement .local)
-h | --help
Afficher l'aide.
