NOM

Biber::DataLists - Objets Biber::DataLists

nouveau

Initialise un objet Biber::DataLists

ajouter_liste

Ajoute une liste de section à cette section

recuperer_listes

Retourne une référence d'array de toutes les listes de tri

recuperer_listes_pour_section

Retourne une référence d'array de toutes les listes de tri pour une section donnée
Utilise l'égalité numérique car les identifiants de section sont des nombres

recuperer_listes_par_attributs

Retourne une référence d'array de listes de données avec certains
attributs

recuperer_liste

Retourne une liste spécifique par métadonnées de liste

contient_listes_de_type_pour_section

Retourne un booléen indiquant s'il existe une liste de tri pour une section d'un
type spécifié
