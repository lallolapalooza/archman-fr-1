NOM

blitspin - faire pivoter un bitmap de manière intéressante

SYNTAXE

blitspin [--display hôte:écran.numéro] [--foreground couleur] [--background couleur] [--window] [--root] [--window-id numéro] [--mono] [--install] [--visual visuel] [--bitmap nom_fichier] [--delay usec] [--delay2 usec] [--duration sec]

DESCRIPTION

Le programme blitspin fait pivoter un bitmap de façon répétée de 90 degrés en utilisant des opérations logiques : le bitmap est divisé en quadrants, et les quadrants sont décalés dans le sens horaire. Ensuite, la même chose est répétée avec des quadrants de taille progressivement plus petite, sauf que tous les sous-quadrants d'une taille donnée sont tournés en parallèle. Cela prend donc O(16*log2(N)) opérations de blit d'une taille de NxN, avec la limitation que l'image doit être carrée et sa taille une puissance de 2.

OPTIONS

blitspin accepte les options suivantes :

--window
Dessiner sur une nouvelle fenêtre créée. C'est le comportement par défaut.
--root
Dessiner sur la fenêtre racine.
--window-id numéro
Dessiner sur la fenêtre spécifiée.
--mono
Si l'on est sur un écran couleur, faire comme si on était sur un écran monochrome.
--install
Installer une palette de couleurs privée pour la fenêtre.
--visual visuel
Spécifier quel visuel utiliser. Les valeurs valides sont le nom d'une classe de visuel, ou le numéro d'identifiant (décimal ou hexadécimal) d'un visuel spécifique.
--bitmap nom_fichier
Le nom du fichier contenant le bitmap à faire pivoter. Il n'a pas besoin d'être carré : il sera complété avec la couleur de fond. S'il n'est pas spécifié ou s'il contient la chaîne (default), un bitmap intégré est utilisé.

Si le support de la bibliothèque XPM était activé lors de la compilation, le fichier spécifié peut être au format XPM ainsi qu'XBM, et peut donc être une image couleur.

La ressource *bitmapFilePath sera recherchée si le nom du bitmap n'est pas un chemin d'accès complet.

--grab-screen
Si cette option est spécifiée, alors l'image qui sera tournée sera capturée à partir de la partie de l'écran sous-jacente à la fenêtre blitspin, ou à partir de l'entrée vidéo du système, ou à partir d'un fichier aléatoire sur le disque, comme indiqué par les options grabDesktopImages, grabVideoFrames, et chooseRandomImages dans le fichier ~/.xscreensaver ; voir xscreensaver-settings(1) pour plus de détails.
--delay microsecondes
Durée du délai entre les étapes du processus de rotation, en microsecondes. La valeur par défaut est 500000, soit une demi-seconde.
--duration secondes
Durée de fonctionnement avant de charger une nouvelle image. La valeur par défaut est 120 secondes.
--delay2 microsecondes
Durée du délai entre chaque rotation de 90 degrés, en microsecondes. La valeur par défaut est 500000, soit une demi-seconde. DISPLAY pour obtenir l'hôte et le numéro d'écran par défaut.
--fps
Afficher le taux de rafraîchissement actuel et la charge CPU.

ENVIRONNEMENT

XENVIRONMENT pour obtenir le nom d'un fichier de ressources qui remplace les ressources globales stockées dans la propriété RESOURCE_MANAGER.

XSCREENSAVER_WINDOW
L'identifiant de la fenêtre à utiliser avec --root.
