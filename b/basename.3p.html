BASENAME(3P) Manuel du programmeur POSIX BASENAME(3P)

PROLOGUE

Cette page manuelle fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page manuelle Linux correspondante pour les détails du comportement de Linux), ou l'interface peut ne pas être implémentée sur Linux.

NOM

basename — renvoyer le dernier composant d'un chemin d'accès

SYNOPSIS

#include <libgen.h>
char *basename(char *path);

DESCRIPTION

La fonction basename() doit prendre le chemin d'accès pointé par path et renvoyer un pointeur vers le composant final du chemin d'accès, en supprimant les caractères '/' de fin.

Si la chaîne pointée par path est constituée entièrement du caractère '/' , basename() doit renvoyer un pointeur vers la chaîne "/". Si la chaîne pointée par path est exactement "//", il est défini par l'implémentation si '/' ou "//" est renvoyé.

Si path est un pointeur nul ou pointe vers une chaîne vide, basename() doit renvoyer un pointeur vers la chaîne ".".

La fonction basename() peut modifier la chaîne pointée par path, et peut renvoyer un pointeur vers un stockage interne. Le pointeur renvoyé peut être invalidé ou le stockage peut être écrasé par un appel ultérieur à basename(). Le pointeur renvoyé peut également être invalidé si le thread appelant est terminé.

La fonction basename() n'a pas besoin d'être sûre dans un environnement multithread.

VALEUR RENVOYÉE

La fonction basename() doit renvoyer un pointeur vers le composant final de path.

ERREURS

Aucune erreur n'est définie.

Les sections suivantes sont informatives.

EXEMPLES

Utilisation de basename()

Le fragment de programme suivant renvoie un pointeur vers la valeur lib, qui est le nom de base de /usr/lib.

#include <libgen.h>
...
char name[] = "/usr/lib";
char *base;
base = basename(name);
...
