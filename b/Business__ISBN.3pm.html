Business::ISBN(3) Documentation Perl contribuée par les utilisateurs Business::ISBN(3)

NOM

Business::ISBN - travailler avec les numéros internationaux normalisés de livres

SYNOPSIS

use Business::ISBN;
# ISBN à 10 chiffres
$isbn10 = Business::ISBN->new('1565922573');
$isbn10 = Business::ISBN->new('1-56592-257-3');
# ISBN à 13 chiffres
$isbn13 = Business::ISBN->new('978-0-596-52724-2');
# convertir
$isbn10 = $isbn13->as_isbn10;    # pour les préfixes 978
$isbn13 = $isbn10->as_isbn13;
# peut-être que vous ne vous souciez pas de ce que c'est tant que tout fonctionne
$isbn = Business::ISBN->new( $ARGV[0] );
#imprimer l'ISBN avec des tirets aux positions habituelles
print $isbn->as_string;
#imprimer l'ISBN avec des tirets aux positions spécifiées.
#cela n'affecte pas les positions par défaut
print $isbn->as_string([]);
#imprimer le code de groupe ou le code de l'éditeur
print $isbn->group_code;
print $isbn->publisher_code;
#vérifier si l'ISBN est valide
$isbn->is_valid;
#corriger la somme de contrôle de l'ISBN.  ATTENTION :  l'erreur peut ne pas être
#dans la somme de contrôle !
$isbn->fix_checksum;
# créer un code-barres EAN13 au format PNG
$isbn->png_barcode;

DESCRIPTION

Ce module gère les numéros internationaux normalisés de livres, y compris les ISBN-10 et ISBN-13.

Les données proviennent de Business::ISBN::Data, ce qui signifie que vous pouvez mettre à jour les données indépendamment du code. De plus, vous pouvez utiliser Business::ISBN::Data avec n'importe quel RangeMessage.xml si vous avez des données mises à jour. Voir ce module pour plus de détails.

Interface de fonction

valid_isbn_checksum( ISBN10 | ISBN13 )
Cette fonction est exportable à la demande et fonctionne pour les ISBN de 10 ou 13 caractères). 
use Business::ISBN qw( valid_isbn_checksum );

Renvoie 1 si l'ISBN est un ISBN valide avec la bonne somme de contrôle.

Renvoie 0 si l'ISBN a des codes de préfixe et d'éditeur valides, mais une somme de contrôle invalide.

Renvoie undef si l'ISBN ne se valide pas pour toute autre raison.

Interface objet

new($isbn)
Le constructeur accepte un scalaire représentant l'ISBN.

La chaîne représentant l'ISBN peut contenir d'autres caractères que ceux de "[0-9xX]", bien que ceux-ci soient supprimés dans la représentation interne. La chaîne résultante doit ressembler à un ISBN - les neuf premiers caractères doivent être des chiffres et le dixième caractère doit être un chiffre, 'x' ou 'X'.

Le constructeur tente de déterminer le code de groupe et le code de l'éditeur. Si ces données ne peuvent pas être déterminées, le constructeur définit "$obj->error" à autre chose que "GOOD_ISBN". Un objet est quand même renvoyé et c'est au programme de vérifier la méthode "error" pour l'une des cinq valeurs ou l'une des méthodes "error_*" pour vérifier une erreur particulière. Les valeurs réelles de ces versions symboliques sont les mêmes que celles des versions précédentes de ce module qui utilisaient des valeurs littérales :

Business::ISBN::INVALID_PUBLISHER_CODE
Business::ISBN::INVALID_GROUP_CODE
Business::ISBN::BAD_CHECKSUM
Business::ISBN::GOOD_ISBN
Business::ISBN::BAD_ISBN

Si vous avez l'une de ces valeurs et que vous voulez la convertir en une chaîne, vous pouvez utiliser le hachage %Business::ISBN::ERROR_TEXT , qui est exportable en le demandant explicitement dans la liste d'importation :

use Business::ISBN qw(%ERROR_TEXT);

Depuis la version 2.010_01, vous pouvez obtenir ce texte à partir de "error_text" afin que vous n'ayez pas à importer quoi que ce soit.

La chaîne passée comme ISBN n'a pas besoin d'être un ISBN valide tant qu'elle ressemble superficiellement à un ISBN. Cela permet d'utiliser la méthode fix_checksum() . Malgré l'avertissement dans la discussion de cette méthode, l'auteur l'a trouvée extrêmement utile. On devrait vérifier la validité de l'ISBN avec is_valid() plutôt que de se fier à la valeur de retour du constructeur. Si tout ce que l'on veut faire est de vérifier la validité d'un ISBN, on peut ignorer l'interface orientée objet et utiliser la fonction valid_isbn_checksum() qui est exportable à la demande.

Si le constructeur décide qu'il ne peut pas créer un objet, il renvoie "undef". Il peut le faire si la chaîne passée comme ISBN ne peut pas être convertie au format interne, ce qui signifie qu'elle ne ressemble même pas de loin à un ISBN.

Méthodes d'instance

input_isbn
Renvoie l'ISBN de départ. Comme vous pouvez insérer des tirets ou corriger des sommes de contrôle, vous voudrez peut-être voir les données originales.
common_data
Renvoie l'ISBN de départ après normalisation, ce qui supprime tout ce qui n'est pas un chiffre ou un caractère de somme de contrôle valide.
isbn
Renvoie la valeur actuelle de l'ISBN, même s'il a une somme de contrôle invalide. Ce sont les données brutes, donc elles n'ont pas les tirets. Si vous voulez l'hyphenation, essayez "as_string".

La méthode "isbn" devrait être la même que as_string( [] ).

error
Renvoie le code d'erreur pour la raison pour laquelle l'ISBN n'est pas valide. La valeur de retour est une clé dans %ERROR_TEXT.
error_is_bad_group
error_is_bad_publisher
error_is_article_out_of_range
error_is_bad_checksum
Renvoie vrai si l'erreur de l'ISBN est de ce type.
error_text
Renvoie une version textuelle du message d'erreur
is_valid
Renvoie vrai si l'ISBN est valide, ce qui signifie qu'il a un préfixe valide (pour les ISBN-13), un code de groupe et un code d'éditeur valides ; et que sa somme de contrôle est valide.
type
Renvoie soit "ISBN10" ou "ISBN13".
prefix
Renvoie le préfixe de l'ISBN. C'est actuellement soit 978 soit 979 pour les ISBN-13. Il renvoie la chaîne vide (donc, une valeur définie) pour les ISBN-10.
group_code
Renvoie le code de groupe de l'ISBN. C'est la version numérique, par exemple, '0' pour le groupe anglais. Les codes de groupe valides proviennent de "Business::ISBN::Data".
group
Renvoie le nom du groupe de l'ISBN. C'est la version sous forme de chaîne. Par exemple, 'English' pour le groupe '0'. Les noms proviennent de "Business::ISBN::Data".
publisher_code
Renvoie le code de l'éditeur de l'ISBN. C'est la version numérique, par exemple '596' pour O'Reilly Media.
article_code
Renvoie le code de l'article de l'ISBN. C'est la version numérique qui identifie de manière unique l'élément.
article_code_length
Renvoie la longueur du code de l'article pour l'ISBN.
article_code_min
Renvoie la longueur minimale du code de l'article pour le code de l'éditeur.
article_code_max
Renvoie la longueur maximale du code de l'article pour le code de l'éditeur.
checksum
Renvoie le code de la somme de contrôle pour l'ISBN. Cette somme de contrôle peut ne pas être valide car vous pouvez créer un objet et corriger la somme de contrôle plus tard avec "fix_checksum".
is_valid_checksum
Renvoie "Business::ISBN::GOOD_ISBN" pour les sommes de contrôle valides et "Business::ISBN::BAD_CHECKSUM" sinon. Cela ne garantit pas que le reste de l'ISBN est réellement attribué à un livre.
fix_checksum
Vérifie la somme de contrôle et modifie l'ISBN pour la définir correctement si nécessaire.
as_string(), as_string([])
Renvoie l'ISBN sous forme de chaîne. Cette fonction prend un tableau anonyme (ou une référence de tableau) facultatif qui spécifie le placement des tirets dans la chaîne. Un tableau anonyme vide produit une chaîne sans tirets. Une liste d'arguments vide hyphénate automatiquement l'ISBN en fonction des codes de groupe et d'éditeur découverts. Un ISBN qui n'est pas valide peut produire des résultats étranges.

Les positions spécifiées dans le tableau anonyme transmis sont uniquement utilisées pour une seule méthode et ne remplacent pas les valeurs spécifiées par le constructeur. La méthode suppose que vous savez ce que vous faites et essaiera d'utiliser les trois dernières positions spécifiées. Si vous transmettez un tableau anonyme de plusieurs positions, la liste sera triée et les trois positions les plus basses seront utilisées. Les positions inférieures à 1 et supérieures à 12 sont silencieusement ignorées.

Un 'x' final est changé en 'X'.

as_isbn10
Renvoie un nouvel objet ISBN. Si l'objet est déjà ISBN-10, cette méthode le clone. S'il s'agit d'un ISBN-13 avec le préfixe 978, elle renvoie l'équivalent ISBN-10. Dans tous les autres cas, elle renvoie undef.
as_isbn13
Renvoie un nouvel objet ISBN. Si l'objet est déjà ISBN-13, cette méthode le clone. S'il s'agit d'un ISBN-10, elle renvoie l'équivalent ISBN-13 avec le préfixe 978.
increment
Renvoie le "Business::ISBN" suivant en incrémentant le code article de l'ISBN spécifié (objet ou scalaire).

Renvoie undef, si le paramètre est invalide ou égal à l'ISBN maximum possible pour l'éditeur.

$isbn = Business::ISBN->new('1565922573');  # 1-56592-257-3
$next_isbn = $isbn->increment;              # 1-56592-258-1

Si le code article suivant dépasserait le code article maximum possible (comme incrémenter 999 à 1000), cela renvoie ARTICLE_CODE_OUT_OF_RANGE comme erreur.

decrement
Renvoie le "Business::ISBN" précédent en décrémentant le code article de l'ISBN spécifié (objet ou scalaire).

Renvoie undef, si le paramètre est invalide ou égal à l'ISBN minimum possible pour l'éditeur.

$isbn = Business::ISBN->new('1565922573');  # 1-56592-257-3
$prev_isbn = $isbn->decrement;              # 1-56592-256-5

Si le code article suivant dépasserait le code article maximum possible (comme incrémenter 000 à -1), cela renvoie ARTICLE_CODE_OUT_OF_RANGE comme erreur.

png_barcode
Renvoie les données de l'image au format PNG pour le code-barres de l'ISBN. Cela fonctionne avec ISBN-10 et ISBN-13. Les ISBN-10 sont automatiquement convertis en ISBN-13.

Cela nécessite "GD::Barcode::EAN13".
