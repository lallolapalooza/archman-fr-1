BINDTEXTDOMAIN(3) Manuel des fonctions de bibliothèque BINDTEXTDOMAIN(3)

NOM

bindtextdomain - définir le répertoire contenant les catalogues de messages

SYNTAXE

#include <libintl.h>

char * bindtextdomain (const char * domainname, const char * dirname);

DESCRIPTION

La fonction bindtextdomain définit le répertoire de base de la hiérarchie contenant les catalogues de messages pour un domaine de messages donné.

Un domaine de messages est un ensemble de messages msgid traduisibles. Habituellement, chaque paquet logiciel a son propre domaine de messages. Le besoin d'appeler bindtextdomain apparaît parce que les paquets ne sont pas toujours installés avec le même préfixe que l'en-tête <libintl.h> et les bibliothèques libc/libintl.

Les catalogues de messages seront attendus aux chemins dirname/locale/category/domainname.mo, où locale est un nom de locale et category est une facette de locale telle que LC_MESSAGES.

domainname doit être une chaîne non vide.

Si dirname n'est pas NULL, le répertoire de base pour les catalogues de messages appartenant au domaine domainname est défini à dirname. La fonction crée des copies des chaînes d'arguments si nécessaire. Si le programme souhaite appeler la fonction chdir, il est important que dirname soit un chemin absolu ; sinon, il ne peut être garanti que les catalogues de messages seront trouvés.

Si dirname est NULL, la fonction retourne le répertoire de base précédemment défini pour le domaine domainname.

VALEUR DE RETOUR

En cas de succès, la fonction bindtextdomain retourne le répertoire de base actuel pour le domaine domainname, après l'avoir éventuellement modifié. La chaîne résultante est valide jusqu'au prochain appel à bindtextdomain pour le même domainname et ne doit pas être modifiée ni libérée. Si une erreur d'allocation de mémoire survient, elle définit errno à ENOMEM et retourne NULL.

ERREURS

Les erreurs suivantes peuvent survenir, entre autres :

ENOMEM
Pas assez de mémoire disponible.

BOGUES

Le type de retour devrait être const char *, mais est char * pour éviter les avertissements dans le code C antérieur à ANSI C.
