bind(2) Manuel des appels système bind(2)

NOM

bind - associer un nom à un socket

BIBLIOTHÈQUE

Bibliothèque C standard (libc,-lc)

SYNOPSIS

#include <sys/socket.h>
int bind(int sockfd, const struct sockaddr *addr,
         socklen_t addrlen);

DESCRIPTION

Lorsqu'un socket est créé avec socket(2), il existe dans un espace de noms (famille d'adresses) mais n'a pas d'adresse qui lui est assignée. bind() assigne l'adresse spécifiée par addr au socket référencé par le descripteur de fichier sockfd. addrlen spécifie la taille, en octets, de la structure d'adresse pointée par addr. Traditionnellement, cette opération est appelée « assigner un nom à un socket ».

Il est généralement nécessaire d'assigner une adresse locale en utilisant bind() avant qu'un socket SOCK_STREAM puisse recevoir des connexions (voir accept(2)).

Les règles utilisées pour l'association de noms varient selon les familles d'adresses. Consultez les entrées de manuel de la section 7 pour des informations détaillées. Pour AF_INET, voir ip(7); pour AF_INET6, voir ipv6(7); pour AF_UNIX, voir unix(7); pour AF_APPLETALK, voir ddp(7); pour AF_PACKET, voir packet(7); pour AF_X25, voir x25(7); et pour AF_NETLINK, voir netlink(7).

La structure réellement passée pour l'argument addr dépendra de la famille d'adresses. La structure sockaddr est définie comme quelque chose comme :


struct sockaddr {
    sa_family_t sa_family;
    char        sa_data[14];
}

Le seul but de cette structure est de convertir le pointeur de structure passé dans addr afin d'éviter les avertissements du compilateur. Voir EXEMPLES ci-dessous.

VALEUR RENVOYÉE

En cas de succès, zéro est renvoyé. En cas d'erreur, -1 est renvoyé, et errno est défini pour indiquer l'erreur.

ERREURS

EACCES
L'adresse est protégée et l'utilisateur n'est pas le superutilisateur.
EADDRINUSE
L'adresse donnée est déjà utilisée.
EADDRINUSE
(Sockets de domaine Internet) Le numéro de port était spécifié comme zéro dans la structure d'adresse du socket, mais, lors de la tentative de liaison à un port éphémère, il a été déterminé que tous les numéros de port dans la plage de ports éphémères sont actuellement utilisés. Voir la discussion sur /proc/sys/net/ipv4/ip_local_port_range dansip(7)
.
EBADF sockfd
n'est pas un descripteur de fichier valide.
EINVAL
Le socket est déjà lié à une adresse.
EINVAL addrlen est incorrect, ou addr
n'est pas une adresse valide pour le domaine de ce socket.
ENOTSOCK Le descripteur de fichier sockfd
ne référence pas un socket.
EADDRNOTAVAIL

Une interface inexistante a été demandée ou l'adresse demandée n'était pas locale.Les erreurs suivantes sont spécifiques aux sockets de domaine UNIX (AF_UNIX

) :
EACCES La permission de recherche est refusée sur un composant du préfixe de chemin. (Voir aussipath_resolution(7)
.)
EFAULT addr
pointe en dehors de l'espace d'adressage accessible par l'utilisateur.
ELOOP Trop de liens symboliques ont été rencontrés lors de la résolution deaddr
.
ENAMETOOLONG addr
est trop long.
ENOENT
Un composant du préfixe de répertoire du chemin du socket n'existe pas.
ENOMEM
La mémoire du noyau disponible était insuffisante.
ENOTDIR
Un composant du préfixe de chemin n'est pas un répertoire.
EROFS

L'inode du socket résiderait sur un système de fichiers en lecture seule.

D'autres erreurs peuvent être générées par les modules de protocole sous-jacents.

VERSIONS Les programmes portables doivent s'assurer que addr.sun_path est une chaîne terminée par un caractère nul pour les sockets AF_UNIX

.

NORMES

POSIX.1-2024.

HISTORIQUE

POSIX.1-2001, SVr4, 4.2BSD.

BOGUES

Les options de proxy transparent ne sont pas décrites.

EXEMPLES Un exemple d'utilisation debind () avec des sockets de domaine Internet se trouve dansgetaddrinfo(3)

.L'exemple suivant montre comment lier un socket de flux dans le domaine UNIX (AF_UNIX

) et accepter des connexions :

#include <err.h> #include <stdlib.h> #include <string.h> #include <sys/socket.h> #include <sys/un.h> #include <unistd.h> #define MY_SOCK_PATH "/somepath" #define LISTEN_BACKLOG 50 int main(void) { int sfd, cfd; socklen_t peer_addr_size; struct sockaddr_un my_addr, peer_addr; sfd = socket(AF_UNIX, SOCK_STREAM, 0); if (sfd == -1) err(EXIT_FAILURE, "socket"); memset(&my_addr, 0, sizeof(my_addr)); my_addr.sun_family = AF_UNIX; strncpy(my_addr.sun_path, MY_SOCK_PATH, sizeof(my_addr.sun_path) - 1); if (bind(sfd, (struct sockaddr *) &my_addr, sizeof(my_addr)) == -1) err(EXIT_FAILURE, "bind"); if (listen(sfd, LISTEN_BACKLOG) == -1) err(EXIT_FAILURE, "listen"); /* Now we can accept incoming connections one at a time using accept(2). */ peer_addr_size = sizeof(peer_addr); cfd = accept(sfd, (struct sockaddr *) &peer_addr, &peer_addr_size); if (cfd == -1) err(EXIT_FAILURE, "accept"); /* Code to deal with incoming connection(s)... */ if (close(sfd) == -1) err(EXIT_FAILURE, "close"); if (unlink(MY_SOCK_PATH) == -1) err(EXIT_FAILURE, "unlink"); }
