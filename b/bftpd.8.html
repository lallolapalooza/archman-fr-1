NOM

bftpd - Démon FTP B

SYNTAXE

bftpd [-c chemin_config| -n] [-d|-D|-i]

DESCRIPTION

bftpd est un serveur FTP très configurable qui utilise chroot sans configuration spéciale ni préparation de répertoire.

OPTIONS

-c
Remplace le chemin par défaut du fichier de configuration (normalement /etc/bftpd.conf).
-n
N'utilise aucun fichier de configuration ; utilise plutôt les valeurs par défaut pour tout. Ceci convient uniquement aux configurations très minimalistes.
-d
Démarre bftpd en mode démon (sans inetd).
-D
Démarre bftpd en mode démon sans fork, de sorte que le démon puisse être tué avec Ctrl+C.
-i
Démarre bftpd en mode inetd. C'est le comportement par défaut.
