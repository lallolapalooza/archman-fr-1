bsetroot(1) Manuel des commandes générales bsetroot(1)

NOM

bsetroot - utilitaire blackbox pour changer l'apparence de la fenêtre racine

SYNTAXE

bsetroot -help
bsetroot [ -display affichage ] -solid couleur
bsetroot [ -display affichage ] -mod x y -fg couleur -bg couleur
bsetroot [ -display affichage ] -gradient texture -from couleur -to couleur

DESCRIPTION

Bsetroot est un utilitaire qui peut contrôler l'apparence de la fenêtre racine de trois manières : lui donner une couleur unie, y écrire un motif modulaire à deux couleurs, ou rendre une texture dégradée, basée sur deux couleurs différentes.

Bsetroot ressemble à xsetroot(1) dans cette fonctionnalité mais il prend en charge plusieurs affichages d'écran, et des textures dégradées de la même manière que Blackbox. Il ne gère pas les curseurs, etc. Bsetroot fait partie du package Blackbox.

OPTIONS

Bsetroot fonctionne de trois manières, vous devez choisir l'une des 3 premières options :

-solid couleur
Définit la fenêtre racine à la couleur spécifiée.
-mod x y
Crée un motif modulaire. Vous devez spécifier les couleurs -bg et -fg.
-gradient chaîne_texture
Rend la chaîne de texture spécifiée sur la fenêtre racine. Pour les chaînes de texture possibles, veuillez vous référer à blackbox(1). Vous devez également spécifier une couleur -from et une couleur -to.
-display affichage
Indique à Bsetroot de se connecter à l'affichage spécifié.
-bg, -background couleur
Couleur de fond. Nécessaire pour les motifs -mod.
-fg, -foreground couleur
Couleur de premier plan. Nécessaire pour les motifs -mod.
-from couleur
Couleur de départ pour le rendu des textures. Nécessaire pour le mode opérationnel -gradient.
-to couleur
Couleur de fin pour le rendu des textures. Nécessaire pour le mode opérationnel -gradient.
-help
Affiche les informations de version et un bref texte d'aide.
