BN_set_bit(3ssl)

Paquet: openssl

Licences: Apache-2.0

BN_SET_BIT(3ssl) OpenSSL BN_SET_BIT(3ssl)

NOM

BN_set_bit, BN_clear_bit, BN_is_bit_set, BN_mask_bits, BN_lshift, BN_lshift1, BN_rshift, BN_rshift1 - opérations sur les bits des BIGNUMs

SYNTAXE

#include <openssl/bn.h>
int BN_set_bit(BIGNUM *a, int n);
int BN_clear_bit(BIGNUM *a, int n);
int BN_is_bit_set(const BIGNUM *a, int n);
int BN_mask_bits(BIGNUM *a, int n);
int BN_lshift(BIGNUM *r, const BIGNUM *a, int n);
int BN_lshift1(BIGNUM *r, BIGNUM *a);
int BN_rshift(BIGNUM *r, BIGNUM *a, int n);
int BN_rshift1(BIGNUM *r, BIGNUM *a);

DESCRIPTION

BN_set_bit() met le bit n de a à 1 ("a|=(1<<n)"). Le nombre est étendu si nécessaire.

BN_clear_bit() met le bit n de a à 0 ("a&=~(1<<n)"). Une erreur se produit si a est plus court que n bits.

BN_is_bit_set() teste si le bit n de a est mis.

BN_mask_bits() tronque a en un nombre de n bits ("a&=~((~0)<<n)"). Une erreur se produit si n est négatif. Une erreur est également renvoyée si la représentation interne de a est déjà plus courte que n bits. La représentation interne dépend de la taille du mot de la plateforme, et cette erreur peut être ignorée sans risque. Utilisez BN_num_bits(3) pour déterminer le nombre exact de bits si nécessaire.

BN_lshift() décale a vers la gauche de n bits et place le résultat dans r ("r=a*2^n"). Notez que n doit être non négatif. BN_lshift1() décale a vers la gauche d'un bit et place le résultat dans r ("r=2*a").

BN_rshift() décale a vers la droite de n bits et place le résultat dans r ("r=a/2^n"). Notez que n doit être non négatif. BN_rshift1() décale a vers la droite d'un bit et place le résultat dans r ("r=a/2").

Pour les fonctions de décalage, r et a peuvent être la même variable.

VALEURS DE RETOUR

BN_is_bit_set() renvoie 1 si le bit est mis, 0 sinon.

Toutes les autres fonctions renvoient 1 en cas de succès, 0 en cas d'erreur. Les codes d'erreur peuvent être obtenus par ERR_get_error(3).

VOIR AUSSI

BN_num_bytes(3), BN_add(3)
