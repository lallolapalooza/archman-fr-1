NOM

B::Hooks::EndOfScope - Exécute du code après la compilation d'une portée

VERSION

version 0.28

SYNOPSIS

on_scope_end { ... };

DESCRIPTION

Ce module permet d'exécuter du code lorsque perl a fini de compiler la portée environnante.

FONCTIONS

on_scope_end

on_scope_end { ... };
on_scope_end $code;

Enregistre $code pour être exécuté après que la portée environnante ait été compilée.

Ceci est exporté par défaut. Voir Sub::Exporter sur comment le personnaliser.

LIMITATIONS

Mise en garde sur le mode pur Perl

Cette mise en garde s'applique à **n'importe quelle** version de perl où Variable::Magic est indisponible ou désactivé.

Bien que Variable::Magic ait accès à de sombres sortilèges pour permettre de lancer une exception depuis un rappel, l'implémentation pure-perl n'a pas accès à ces astuces. Par conséquent, ce qui aurait été une **exception au moment de la compilation** est à la place **converti en un avertissement**, et votre exécution continuera comme si l'exception n'avait jamais eu lieu.

Pour demander explicitement une implémentation XS (ou PP), vous avez deux choix. Soit importer de l'implémentation souhaitée explicitement :

use B::Hooks::EndOfScope::XS
  or
use B::Hooks::EndOfScope::PP

ou en définissant $ENV{B_HOOKS_ENDOFSCOPE_IMPLEMENTATION} à "XS" ou "PP".

Perl 5.8.0 ~ 5.8.3

En raison d'un bug du noyau de l'interpréteur
https://rt.perl.org/Public/Bug/Display.html?id=27040#txn-82797 présent dans les anciennes versions de perl, l'implémentation de B::Hooks::EndOfScope laisse délibérément fuir un seul hachage vide pour chaque portée en cours de nettoyage. Ceci est fait pour éviter la corruption de mémoire associée au bug mentionné ci-dessus.

Afin de stabiliser cette solution de contournement, l'utilisation de Variable::Magic est désactivée sur les perls antérieurs à la version 5.8.4. Sur de tels systèmes, charger/demander explicitement B::Hooks::EndOfScope::XS entraînera une exception au moment de la compilation.

Versions de Perl 5.6.x

Les versions de perl antérieures à 5.8.0 n'ont pas la fonctionnalité permettant de changer la visibilité de "%^H" en définissant le bit 17 dans $^H. Par conséquent, la seule façon d'obtenir l'effet nécessaire au bon fonctionnement de ce module est d'utiliser explicitement l'opérateur "local" sur ces plateformes. Cela pourrait entraîner une interférence inattendue avec d'autres bibliothèques pilotées par la portée et reposant sur le même mécanisme. D'un autre côté, il n'y a pas de telles incompatibilités connues au moment de la rédaction de cette note.

Pour plus de détails sur le comportement indisponible, veuillez vous référer au fichier de test t/02-localise.t inclus dans la distribution.
