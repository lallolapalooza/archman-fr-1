NOM

bdep-argument-grouping - installation de regroupement d'arguments

SYNTAXE

bdep { options }+ argument +{ options }

DESCRIPTION

Pour certaines commandes, certaines options et variables de ligne de commande peuvent être regroupées pour ne s'appliquer qu'à des arguments spécifiques. Ce sujet d'aide décrit l'installation de regroupement d'arguments utilisée à cette fin.

Les groupes peuvent être spécifiés avant (préfixe) et/ou après (suffixe) l'argument auquel ils s'appliquent. Un groupe préfixe commence par '{' et se termine par '}+' tandis qu'un groupe suffixe commence par '+{' et se termine par '}'. Par exemple :

{ --foo --bar }+ arg   # 'arg' avec '--foo' '--bar'
arg +{ fox=1 baz=2 }   # 'arg' avec 'fox=1' 'baz=2'

Plusieurs groupes préfixes et/ou suffixes peuvent être spécifiés pour le même argument. Par exemple :

{ -f }+ { -b }+ arg +{ f=1 } +{ b=2 } # 'arg' avec '-f' 'b' 'f=1' 'b=2'

Le groupe s'applique à un seul argument uniquement, sauf si plusieurs arguments sont eux-mêmes regroupés avec '{' et '}'. Par exemple :

{ --foo }+ arg1  arg2 +{ --bar }      # 'arg1' avec '--foo'
                                      # 'arg2' avec '--bar'
{ --foo }+ { arg1  arg2 } +{ --bar }  # 'arg1' avec '--foo' '--bar'
                                      # 'arg2' avec '--foo' '--bar'

Les séparateurs de groupe ('{', '}+', etc.) doivent être des arguments distincts de la ligne de commande. En particulier, ils ne doivent pas être adjacents soit aux arguments à l'intérieur du groupe, soit à l'argument auquel ils s'appliquent. Tous ces cas seront traités comme des arguments ordinaires. Par exemple :

{--foo}+ arg   # '{--foo}+' ...
arg+{ --foo }  # 'arg+{' ...

Si l'un des séparateurs de groupe doit être spécifié comme argument littéral, il doit alors être échappé avec '\'. Par exemple :

}             # erreur : séparateur de groupe inattendu
}x            # '}x'
\}            # '}'
{ \}+ }+ arg  # 'arg' avec '}+'
