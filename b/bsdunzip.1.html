BSDUNZIP(1) Manuel des commandes générales BSDUNZIP(1)

NOM

bsdunzip — extraire des fichiers d'une archive ZIP

SYNTAXE

bsdunzip [-aCcfjLlnopqtuvy] [{ -O | -I } encodage] [-d dossier] [-x motif] [-P motdepasse] archive.zip [membre ...]

DESCRIPTION

Les options suivantes sont disponibles :

-a
Lors de l'extraction d'un fichier texte, convertir les fins de ligne de style DOS en fins de ligne de style Unix.
-C
Comparer les noms de fichiers sans tenir compte de la casse.
-c
Extraire vers la sortie standard/l'écran. Lors de l'extraction de fichiers de l'archive zip, ils sont écrits sur la sortie standard. Ceci est similaire à -p, mais ne supprime pas la sortie normale.
-d dossier
Extraire les fichiers dans le répertoire spécifié plutôt que dans le répertoire courant.
-f
Mettre à jour existant. Extraire uniquement les fichiers de l'archive zip si un fichier du même nom existe déjà sur le disque et est plus ancien que le premier. Sinon, le fichier est silencieusement ignoré.
-I encodage
 
-O encodage
Convertir les noms de fichiers de l'encodage spécifié.
-j
Ignorer les répertoires stockés dans l'archive zip ; au lieu de cela, extraire tous les fichiers directement dans le répertoire d'extraction.
-L
Convertir les noms des fichiers et répertoires extraits en minuscules.
-l
Lister, plutôt qu'extraire, le contenu de l'archive zip.
-n
Ne pas écraser. Lors de l'extraction d'un fichier de l'archive zip, si un fichier du même nom existe déjà sur le disque, le fichier est silencieusement ignoré.
-o
Écraser. Lors de l'extraction d'un fichier de l'archive zip, si un fichier du même nom existe déjà sur le disque, le fichier existant est remplacé par le fichier de l'archive zip.
-p
Extraire vers la sortie standard. Lors de l'extraction de fichiers de l'archive zip, ils sont écrits sur la sortie standard. La sortie normale est supprimée comme si -q était spécifié.
-P motdepasse
Extraire les fichiers chiffrés en utilisant un mot de passe. La saisie d'un mot de passe sur la ligne de commande avec cette option peut être non sécurisée.
-q
Silencieux : afficher moins d'informations lors de l'extraction.
-t
Tester : n'extraire rien, mais vérifier la somme de contrôle de chaque fichier dans l'archive.
-u
Mettre à jour. Lors de l'extraction d'un fichier de l'archive zip, si un fichier du même nom existe déjà sur le disque, le fichier existant est remplacé par le fichier de l'archive zip si et seulement si ce dernier est plus récent que le premier. Sinon, le fichier est silencieusement ignoré.
-v
Lister de manière verbeuse, plutôt qu'extraire, le contenu de l'archive zip. Cela diffère de -l en utilisant un listage long. Notez que la plupart des données sont actuellement factices et ne reflètent pas le contenu de l'archive.
-x motif
Exclure les fichiers correspondant au motif motif.
-y
Afficher les années sur quatre chiffres dans les listages au lieu de deux.
-Z mode
Émuler le mode de zipinfo(1L). L'activation du mode zipinfo(1L) modifie la manière dont les arguments supplémentaires sont analysés. Actuellement, seul le mode 1 de zipinfo(1L) est pris en charge, qui liste les noms de fichiers un par ligne.
[membre ...]
Liste optionnelle des membres à extraire de l'archive zip. Peut inclure des motifs, par exemple, 'membredir/*' extraira tous les fichiers et répertoires sous membredir.

Notez qu'une seule des options -n, -o et -u peut être spécifiée. Si le nom de fichier spécifié est "-", les données sont lues depuis stdin.

ENVIRONNEMENT

Si la variable d'environnement UNZIP_DEBUG est définie, l'option de ligne de commande -q n'a aucun effet, et des informations de débogage supplémentaires seront imprimées sur stderr.

COMPATIBILITÉ

L'utilitaire bsdunzip vise à être suffisamment compatible avec d'autres implémentations pour servir de remplacement direct dans le contexte du système de ports(7). Aucune tentative n'a été faite pour reproduire des fonctionnalités qui ne sont pas requises à cette fin.

Pour des raisons de compatibilité, les options de ligne de commande seront reconnues si elles sont listées non seulement avant, mais aussi après le nom de l'archive zip.

Normalement, l'option -a ne devrait affecter que les fichiers marqués comme fichiers texte dans le répertoire central de l'archive zip. Comme la bibliothèque archive(3) ne fournit pas d'accès à ces informations, elles ne sont pas disponibles pour l'utilitaire bsdunzip. Au lieu de cela, l'utilitaire bsdunzip supposera qu'un fichier est un fichier texte si aucun caractère non ASCII n'est présent dans le premier bloc de données décompressé pour ce fichier. Si des caractères non ASCII apparaissent dans des blocs de données ultérieurs, un avertissement sera émis.

L'utilitaire bsdunzip est seulement capable de traiter les archives ZIP gérées par libarchive(3). Selon la version installée de libarchive(3), cela peut inclure ou non des archives auto-extractibles ou ZIPX.

VOIR AUSSI

libarchive(3)

HISTORIQUE

L'utilitaire bsdunzip est apparu dans FreeBSD 8.0.

AUTEURS

L'utilitaire bsdunzip et cette page de manuel ont été rédigés par Dag-Erling Smørgrav <des@FreeBSD.org>. Il utilise la bibliothèque archive(3) développée par
Tim Kientzle <kientzle@FreeBSD.org>.

ATTENTION

L'utilitaire bsdunzip effectue deux passes de l'analyse de la ligne de commande pour les arguments avant et après le nom de l'archive, afin de maintenir la compatibilité avec Info-ZIP unzip. Par conséquent, la chaîne POSIX ‘--’> double-tirets utilisée pour séparer les options des arguments devra être répétée. Par exemple, pour extraire un

"-a.jpg" depuis "-b.zip" avec écrasement, on devrait invoquer

bsdunzip -o -- -a.jpg -- -b.zip
