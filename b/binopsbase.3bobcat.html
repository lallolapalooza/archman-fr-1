binopsbase(3bobcat) Opérateurs Binaires binopsbase(3bobcat)

NOM

BinopsBase - Gabarit de classe offrant des opérateurs binaires de type classe

SYNTAXE

#include <bobcat/binopsbase>

DESCRIPTION

Les classes peuvent surcharger les opérateurs binaires. Une classe nommée Derived peut surcharger les opérateurs binaires pour répondre à ses propres besoins. Elle pourrait, par exemple, permettre de sommer deux objets de classe Derived, ou définir une opération de décalage avec un opérande droit (rhs) de type size_t.

Les opérateurs binaires disponibles sont *, /, %, +, -, <<, >>, &, |, et ^ (dans cette page de manuel, ils sont indiqués génériquement comme l'opérateur `@'). De plus, les operator<< et operator>> surchargés pour l'insertion et l'extraction de flux sont fréquemment définis.

Si une classe Derived prend en charge la construction par copie et/ou par déplacement et si elle propose une fonction membre swap (void Derived::swap(Derived &rhs)), et est dérivée publiquement de FBB::BinopsBase<Derived>, alors une fois que Derived définit un membre

    void Class::operator@=(Rhs const &rhs) &&
définissant l'opérateur composé @ pour les objets Derived anonymes et temporaires et un type Rhs pour son opérande droit, les opérateurs suivants sont également disponibles : 
    Derived &operator@=(Rhs const &rhs) &
    Derived operator@(Derived &&lhs, Rhs const &rhs);
    Derived operator@(Derived const &lhs, Rhs const &rhs);

Une procédure similaire s'applique aux opérateurs d'insertion et d'extraction. Les opérateurs d'insertion et d'extraction deviennent disponibles une fois que BinopsBase<Derived> est déclarée classe amie de Derived. Pour rendre l'opérateur d'insertion disponible, un membre privé

    void Derived::insert(std::ostream &out) const
doit également être défini, insérant l'objet appelant dans out. De manière analogue, pour rendre l'opérateur d'extraction disponible, un membre privé

    void Derived::extract(std::istream &in)
doit être défini, extrayant l'objet appelant de in.

HERITE DE

--

OPERATEURS SURCHARGES

Pour chaque Derived &&operator@=(Rhs const &rhs) && défini dans la classe Derived, les opérateurs suivants sont automatiquement disponibles :

    Derived operator@(Derived &&lhs, Rhs const &rhs);
    Derived operator@(Derived const &lhs, Rhs const &rhs);

et

    Derived &operator@=(Rhs const &rhs) &;

L'opérateur d'insertion devient disponible une fois que

    void Derived::insert(std::ostream &out) const
(insérant l'objet appelant dans out) a été défini. De manière analogue, l'opérateur d'extraction devient disponible après la définition d'un membre privé

    void Derived::extract(std::istream &in)
(extrayant l'objet appelant de in).

DECLARATION AMIE

Pour rendre les opérateurs d'insertion et/ou d'extraction disponibles, la classe Derived doit également déclarer

    friend FBB::BinopsBase<Derived>;

EXEMPLE

#include <iostream>
#include <bobcat/binopsbase>
class Demo1: public FBB::BinopsBase<Demo1>
{
    friend FBB::BinopsBase<Demo1>;            // pour insert/extract
    public:
        void swap(Demo1 &other)
        {}
        Demo1 &&operator+=(Demo1 const &rhs) &&
        {
            std::cout << "addition de deux objets Demo1\n";
            return std::move(*this);
        }
//  Les définitions explicites priment sur les gabarits de fonctions
//  instanciés à partir des définitions dans bobcat/binopsbase.
//        Demo1 &operator+=(Demo1 const &rhs) &
//        {
//            std::cout << "addition (auto-définie) de deux objets Demo1\n";
//            return *this;
//        }
        Demo1 &&operator-=(Demo1 const &rhs) &&
        {
            std::cout << "soustraction de deux objets Demo1\n";
            return std::move(*this);
        }
        Demo1 &&operator<<=(Demo1 const &rhs) &&
        {
            std::cout << "décalage à gauche sur deux objets Demo1\n";
            return std::move(*this);
        }
        Demo1 &&operator<<=(size_t rhs) &&
        {
            std::cout << "décalage à gauche d'un objet Demo1 de rhs bits\n";
            return std::move(*this);
        }
        void insert(std::ostream &out) const        // nécessite friend
        {
            out << "insertion d'un objet Demo1\n";
        }
        void extract(std::istream &in)              // nécessite friend
        {
            std::cout << "extraction d'un objet Demo1\n";
        }
};
class Demo2: public FBB::BinopsBase<Demo2>
{
    public:
        void swap(Demo2 &other)
        {}
        Demo2 &&operator+=(Demo2 const &rhs) &&
        {
            std::cout << "addition de deux objets Demo2\n";
            return std::move(*this);
        }
        Demo2 &operator+=(Demo2 const &rhs) &
        {
            std::cout << "addition (auto-définie) de deux objets Demo2";
            return *this;
        }
        Demo2 &&operator^=(Demo2 const &rhs) &&
        {
            std::cout << "xor de deux objets Demo2\n";
            return std::move(*this);
        }
        Demo2 &&operator|=(Demo2 const &rhs) &&
        {
            std::cout << "ou de deux objets Demo2\n";
            return std::move(*this);
        }
};
int main()
{
    Demo1 d1a, d1b;
    Demo1 d1c = d1a + d1b;
    d1a += d1b;
    d1c = Demo1{} + d1b;
    std::cout << "Nous voici " << d1c << ’\n’;
    std::cin >> d1c;
    d1a <<= d1a;
    d1a <<= 5;
    Demo2 d2a, d2b;
    Demo2 d2c = d2a + d2b;
    d2a ^= d2b;
    d2c = Demo2{} ^ d2b;
    d2c = d2c | d2b;
}
