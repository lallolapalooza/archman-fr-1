NOM

buildah-source-create - Créer et initialiser une image source

SYNOPSIS

buildah source create [options] chemin

DESCRIPTION

Crée et initialise une image source. Une image source est un artefact OCI ; une image OCI avec un type de média de configuration personnalisé.

Notez que la commande buildah-source et toutes ses sous-commandes sont expérimentales et peuvent faire l'objet de changements futurs.

OPTIONS

--author auteur

Définit l'auteur de l'image source mentionné dans la configuration. Par défaut, aucun auteur n'est défini.

--time-stamp valeur-booléenne

Définit l'horodatage de création dans la configuration de l'image. Par défaut, l'horodatage est défini.
