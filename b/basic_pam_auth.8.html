NOM

basic_pam_auth - Aide à l'authentification de base PAM pour Squid

SYNTAXE

basic_pam_auth [-n nom du service TTL ] [-o] [-1]

DESCRIPTION

basic_pam_auth permet à Squid de se connecter à pratiquement toutes les bases de données PAM disponibles pour valider le nom d'utilisateur et le mot de passe de l'authentification HTTP de base.

OPTIONS

-s nom-du-service
Spécifie le nom du service PAM que Squid utilise, par défaut squid
-t TTL
Active les connexions PAM persistantes où la connexion à la base de données PAM est maintenue ouverte et réutilisée pour de nouvelles connexions. La TTL spécifie combien de temps la connexion sera maintenue ouverte (en secondes). Par défaut, les connexions PAM ne sont pas maintenues ouvertes. Veuillez noter que l'utilisation de connexions PAM persistantes est légèrement en dehors de la spécification PAM et peut ne pas fonctionner avec toutes les configurations PAM.
-o
N'effectue pas le groupe de gestion de compte PAM (expiration de compte, etc.)

CONFIGURATION

Le programme nécessite qu'un service PAM soit configuré dans /etc/pam.conf ou /etc/pam.d/squid

Le nom du service par défaut est squid , et le programme utilise les groupes de gestion auth et account pour vérifier le mot de passe et la validité des comptes.

Pour plus de détails sur la configuration des services PAM, consultez la documentation PAM de votre système. Ce manuel ne couvre pas les détails de configuration de PAM.

NOTES

Lorsqu'il est utilisé pour s'authentifier auprès des bases de données de mots de passe shadow UNIX locales, le programme doit être exécuté en tant que root, sinon il n'aura pas les permissions suffisantes pour accéder à la base de données des mots de passe des utilisateurs. Une telle utilisation de ce programme n'est pas recommandée, mais si vous en avez absolument besoin, rendez le programme setuid root

chown root basic_pam_auth
chmod u+s basic_pam_auth

Veuillez noter que dans de telles configurations, il est également fortement recommandé de déplacer le programme dans un répertoire où les utilisateurs normaux ne peuvent pas y accéder, car ce mode de fonctionnement permettra à tout utilisateur local de forcer par force brute les mots de passe des autres utilisateurs. Notez également que le programme n'a pas été entièrement audité et que l'auteur ne peut être tenu responsable de tout problème de sécurité dû à de telles installations.
