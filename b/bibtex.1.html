NOM

bibtex - créer une bibliographie pour (La)TeX

SYNTAXE

bibtex [-min-crossrefs=nombre] [-terse] nom_aux[.aux]

DESCRIPTION

Cette page de manuel n'est pas destinée à être exhaustive. La documentation complète pour cette version de TeX se trouve dans le fichier info ou le manuel Web2C: A TeX implementation.

BibTeX lit le fichier auxiliaire (.aux) de niveau supérieur nom_aux qui a été généré lors de l'exécution de latex(1) ou tex(1) et crée un fichier de bibliographie (.bbl) qui sera incorporé au document lors des exécutions ultérieures de LaTeX ou TeX.

BibTeX recherche, dans les fichiers de base de données bibliographiques (.bib) spécifiés par la commande \bibliography, les entrées spécifiées par les commandes \cite et \nocite dans le fichier source LaTeX ou TeX. Il formate les informations de ces entrées selon les instructions d'un fichier de style bibliographique (.bst) (spécifié par la commande \bibliographystyle), et il envoie les résultats dans le fichier .bbl.

Le manuel LaTeX explique ce qu'un fichier source LaTeX doit contenir pour fonctionner avec BibTeX. L'annexe B du manuel décrit le format des fichiers .bib. Le document `BibTeXing' décrit les extensions et les détails de ce format, et donne d'autres indications utiles pour l'utilisation de BibTeX.

OPTIONS

L'option -min-crossrefs définit le nombre minimum de crossref requis pour l'inclusion automatique de l'entrée de base de cross-référence dans la liste de citations ; la valeur par défaut est deux. Pour éviter complètement ces inclusions automatiques, donnez à cette option un nombre suffisamment grand et assurez-vous de supprimer tous les fichiers .aux et .bbl précédents. Sinon, l'option peut sembler n'avoir aucun effet, car BibTeX aura ajouté la citation de l'entrée de base au fichier .aux, et rien ne pourra la supprimer.

Avec l'option -terse, BibTeX fonctionne silencieusement. Sans elle, une bannière et des rapports de progression sont imprimés sur stdout.

ENVIRONNEMENT

BibTeX recherche dans les répertoires du chemin défini par la variable d'environnement BSTINPUTS les fichiers .bst. Si BSTINPUTS n'est pas défini, il utilise la valeur par défaut du système. Pour les fichiers .bib, il utilise la variable d'environnement BIBINPUTS si elle est définie, sinon la valeur par défaut. Voir tex(1) pour les détails de la recherche.

Si la variable d'environnement TEXMFOUTPUT est définie, BibTeX tente d'y placer ses fichiers de sortie, s'ils ne peuvent pas être placés dans le répertoire courant. Voir encore tex(1). Aucune recherche spéciale n'est effectuée pour le fichier .aux.

FICHIERS

*.bst
Fichiers de style bibliographique.
btxdoc.tex
« BibTeXing » - Documentation formatée LaTeX pour les utilisateurs généraux de BibTeX
btxhak.tex
« Designing BibTeX Styles » - Documentation formatée LaTeX pour les concepteurs de styles
btxdoc.bib
Fichier de base de données pour ces deux documents
xampl.bib
Fichier de base de données donnant des exemples de tous les types d'entrées standard
btxbst.doc
Fichier modèle et documentation pour les styles standard

Tous ces fichiers devraient être disponibles quelque part sur votre système.

La machine math.utah.edu dispose d'une vaste collection de fichiers .bib disponibles par ftp anonyme, y compris des références pour tous les livres TeX standard et une bibliographie complète de TUGboat.
