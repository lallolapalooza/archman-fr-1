NOM

bglprof - afficher les données de profil de graphe d'appels pour les programmes Bigloo

SYNTAXE

bglprof [ options ] [ fichier_objet [ gmon.out ] ]

DESCRIPTION

bglprof est une interface pour le programme gprof. Toute option applicable à gprof convient à bglprof. bglprof lit un fichier de surveillance supplémentaire, le fichier bmon.out. Ce fichier est généré lors de l'exécution d'un programme lié par Bigloo en utilisant l'option -p. Voir le manuel de glprof pour une documentation détaillée.

OPTIONS

-v
mode verbeux.

EXEMPLE

Voici la séquence de commandes pour obtenir un profil Bigloo :

$ bigloo foo.scm -p -unsafe -O4 -c

$ bigloo foo.o -p -unsafe -O4 -c -o a.out

$ ./a.out

$ bglprof

VOIR AUSSI

bigloo(1), prof(1), gprof(1)
