NOM

B::Hooks::EndOfScope::PP - Exécuter du code après la compilation d'une portée - Implémentation PP

VERSION

version 0.28

DESCRIPTION

C'est l'implémentation pure-Perl de B::Hooks::EndOfScope basée uniquement sur les modules disponibles dans le cœur de Perl. Sa sœur plus légère, B::Hooks::EndOfScope::XS, sera automatiquement préférée si toutes les dépendances sont disponibles et que $ENV{B_HOOKS_ENDOFSCOPE_IMPLEMENTATION} n'est pas défini à 'PP'.

FONCTIONS

on_scope_end

on_scope_end { ... };
on_scope_end $code;

Enregistre $code pour qu'il soit exécuté après la compilation de la portée environnante.

Ceci est exporté par défaut. Voir Sub::Exporter sur la façon de le personnaliser.
