break(n) Commandes intégrées Tcl break(n)

NOM

break - Abandonne une commande de boucle

SYNOPSIS

break

DESCRIPTION

Cette commande est généralement invoquée à l'intérieur du corps d'une commande de boucle telle que for, foreach ou while. Elle renvoie un code de résultat 3 (TCL_BREAK), ce qui provoque une exception de rupture. L'exception provoque l'abandon du script courant jusqu'à la commande de boucle contenante la plus interne, qui interrompt alors son exécution et retourne normalement. Les exceptions de rupture sont également gérées dans quelques autres situations, telles que la commande catch, les liaisons d'événements Tk et les scripts les plus externes des corps de procédures.

EXEMPLE

Imprimer une ligne pour chaque entier de 0 à 5 :

for {set x 0} {$x<10} {incr x} {
    if {$x > 5} {
        break
    }
    puts "x est $x"
}

VOIR AUSSI

catch(n), continue(n), for(n), foreach(n), return(n), while(n)

MOTS-CLÉS

abandonner, interrompre, boucle
