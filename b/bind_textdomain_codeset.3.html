NOM

bind_textdomain_codeset - définit le jeu de caractères de sortie des traductions de messages

SYNTAXE

#include <libintl.h>

char * bind_textdomain_codeset (const char * domainname,
                                const char * codeset);

DESCRIPTION

La fonction bind_textdomain_codeset définit le jeu de caractères de sortie pour les catalogues de messages du domaine domainname.

Un domaine de messages est un ensemble de messages traduisibles msgid. Habituellement, chaque paquet logiciel a son propre domaine de messages.

Par défaut, la famille de fonctions gettext renvoie les messages traduits dans le jeu de caractères de l'environnement local, qui peut être récupéré via nl_langinfo (CODESET). Le besoin d'appeler bind_textdomain_codeset se fait sentir pour les programmes qui stockent des chaînes de caractères de manière indépendante de la locale (par exemple, UTF-8) et qui souhaitent éviter une conversion de jeu de caractères supplémentaire sur les messages traduits renvoyés.

domainname doit être une chaîne non vide.

Si codeset n'est pas NULL, il doit s'agir d'un nom d'encodage valide pouvant être utilisé pour la fonction iconv_open. La fonction bind_textdomain_codeset définit le jeu de caractères de sortie pour les catalogues de messages appartenant au domaine domainname à codeset. La fonction fait des copies des chaînes d'arguments si nécessaire.

Si codeset est NULL, la fonction renvoie le jeu de caractères précédemment défini pour le domaine domainname. La valeur par défaut est NULL, ce qui indique le jeu de caractères de l'environnement local.

VALEUR DE RETOUR

En cas de succès, la fonction bind_textdomain_codeset renvoie le jeu de caractères actuel pour le domaine domainname, après l'avoir éventuellement modifié. La chaîne résultante est valide jusqu'au prochain appel à bind_textdomain_codeset pour le même domainname et ne doit pas être modifiée ni libérée. Si une allocation de mémoire échoue, elle définit errno à ENOMEM et renvoie NULL. Si aucun jeu de caractères n'a été défini pour le domaine domainname, elle renvoie NULL.

ERREURS

Les erreurs suivantes peuvent survenir, entre autres :

ENOMEM
Pas assez de mémoire disponible.

BOGUES

Le type de retour devrait être const char *, mais il est char * pour éviter les avertissements dans le code C antérieur à ANSI C.
