NOM

bup-join - concaténer des fichiers d'un dépôt bup

SYNTAXE

bup join [-r hôte:chemin] [refs ou hachages...]

DESCRIPTION

bup join est approximativement l'opération inverse de bup-split(1). Vous pouvez l'utiliser pour récupérer le contenu d'un fichier d'un dépôt bup local ou distant.

La liste des refs ou hachages fournis peut être dans n'importe quel format accepté par git(1), y compris les noms de branches, les identifiants de commit, les identifiants d'arbre ou les identifiants de blob.

Si aucun ref ou hachage n'est donné sur la ligne de commande, bup join les lit depuis stdin à la place.

OPTIONS

-r, --remote=hôte:chemin
Récupère les objets du dépôt distant donné au lieu du dépôt local. chemin peut être vide, auquel cas le dépôt distant par défaut est utilisé. La connexion au serveur distant se fait via SSH. Si vous souhaitez spécifier le port, l'utilisateur ou la clé privée à utiliser pour la connexion SSH, nous vous recommandons d'utiliser le fichier ~/.ssh/config. Même si la source de données est distante, un dépôt bup local est toujours requis.

EXEMPLES

# découper puis joindre un fichier en utilisant son identifiant d'arbre
TREE=$(tar -cvf - /etc | bup split -t)
bup join $TREE | tar -tf -
# faire deux sauvegardes, puis obtenir la seconde plus récente.
# mybackup~1 est la notation git(1) pour le deuxième commit le plus
# récent sur la branche nommée mybackup.
tar -cvf - /etc | bup split -n mybackup
tar -cvf - /etc | bup split -n mybackup
bup join mybackup~1 | tar -tf -
