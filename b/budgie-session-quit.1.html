NOM

budgie-session-quit - Terminer la session budgie courante

SYNTAXE

budgie-session-quit [--logout|--power-off|--reboot] [--force] [--no-prompt]

DESCRIPTION

Le programme budgie-session-quit peut être utilisé pour terminer une session budgie.

OPTIONS

Les options suivantes sont prises en charge :

--logout
Demander à l'utilisateur de confirmer la déconnexion. C'est le comportement par défaut.
--power-off
Demander à l'utilisateur de confirmer l'extinction du système.
--reboot
Demander à l'utilisateur de confirmer le redémarrage du système.
--force
Ignorer tous les inhibiteurs.
--no-prompt
Terminer la session sans interaction utilisateur. Ceci ne fonctionne qu'avec --logout.

BOGUES

Si vous trouvez des bogues dans le programme budgie-session-quit, veuillez les signaler sur https://github.com/buddiesofbudgie/budgie-session.
