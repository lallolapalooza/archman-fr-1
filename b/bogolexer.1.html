BOGOLEXER(1) Manuel de référence de Bogofilter BOGOLEXER(1)

NOM

bogolexer - Programme utilitaire pour séparer les messages électroniques en jetons

SYNOPIS

bogolexer [-p] [-q] [-h] [-n] [-v] [-x flags] [-c fichier] [-C] [-D] [-I fichier] [-O fichier] [-V]

DESCRIPTION

Bogolexer fait partie du paquet de filtre anti-spam bayésien bogofilter.

Il est utilisé pour séparer les messages en jetons et pour tester les nouvelles versions du code lexer.l.

OPTIONS

L'option -p indique à bogolexer d'afficher uniquement les jetons lus depuis stdin, sans aucun message supplémentaire.

L'option -q indique à bogolexer d'afficher un décompte de jetons, sans afficher les jetons réels.

L'option -h affiche le message d'aide et quitte.

L'option -n indique à bogolexer de mapper les caractères non-ascii au point d'interrogation '?'.

L'option -v augmente le niveau de verbosité.

L'option -x flags permet de définir des indicateurs de débogage pour afficher des messages de débogage.

L'option -cnom_fichier indique à bogolexer de lire le fichier de configuration nommé.

L'option -C empêche bogolexer de lire les fichiers de configuration.

L'option -D redirige la sortie de débogage vers stdout (par défaut vers stderr).

L'option -I nom_fichier indique à bogolexer de lire son entrée depuis le fichier spécifié, plutôt que depuis stdin.

L'option -O nom_fichier indique à bogolexer d'écrire sa sortie dans le fichier spécifié, plutôt que vers stdout.

L'option -V affiche le numéro de version et quitte.

AUTEUR

L'équipe de développement de bogofilter.

Pour les mises à jour, consultez la page du projet bogofilter[1].
