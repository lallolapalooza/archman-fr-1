BSDCAT(1) Manuel des commandes générales BSDCAT(1)

NOM

bsdcat — décompresse les fichiers vers la sortie standard

SYNTAXE

bsdcat [options] [fichiers]

DESCRIPTION

bsdcat décompresse les fichiers vers la sortie standard.

OPTIONS

bsdcat prend généralement un nom de fichier en argument ou lit l'entrée standard lorsqu'il est utilisé dans un pipe. Dans les deux cas, les données décompressées sont écrites sur la sortie standard.

EXEMPLES

Pour décompresser un fichier :

bsdcat example.txt.gz > example.txt

Pour décompresser l'entrée standard dans un pipe :

cat example.txt.gz | bsdcat > example.txt

Les deux exemples obtiennent les mêmes résultats : un fichier décompressé en redirigeant la sortie.

VOIR AUSSI

bzcat(1), uncompress(1), xzcat(1), zcat(1), libarchive-formats(5)
