NOM

bibdoiadd.pl - ajouter des numéros DOI aux articles d'un fichier bib donné

SYNTAXE

bibdoiadd [-c fichier_config] [-C 1|0] [-e 1|0] [-f] [-o sortie] fichier_bib

OPTIONS

-c fichier_config
Fichier de configuration. Si ce fichier est absent, certains paramètres par défaut sont utilisés. Voir ci-dessous pour son format.
-C 1|0
Pour canonicaliser les noms dans la sortie (1) ou non (0). Par défaut, 1.
-e
Si 1 (par défaut), ajouter un DOI vide si un DOI ne peut être trouvé. Cela évite des recherches répétées pour les mêmes entrées si vous ajoutez de nouvelles entrées au fichier. L'appel de "-e 0" supprime ce comportement.
-f
Forcer la vérification du numéro DOI même si un DOI est déjà présent
-o sortie
Fichier de sortie. Si cette option n'est pas utilisée, le nom du fichier de sortie est formé en ajoutant "_doi" au fichier d'entrée

DESCRIPTION

Le script lit un fichier BibTeX. Il vérifie si les entrées ont des DOI. Sinon, il essaie de contacter http://www.crossref.org pour obtenir le DOI correspondant. Le résultat est un fichier BibTeX avec les champs "doi=..." ajoutés.

Le nom du fichier de sortie est soit défini par l'option -o, soit dérivé en ajoutant le suffixe "_doi" au fichier de sortie.

Chaque enregistrement BibTeX dans l'entrée est analysé, en utilisant BibTeX::Parser, mais seuls ceux qui n'ont pas le champ "doi" (ou "mrnumber" ou "zblnumber" pour les scripts frères) sont traités. Ces entrées sans le champ demandé sont réécrites, comme décrit dans BibTeX::Parser::Entry.

Les enregistrements bib qui ne sont pas traités (parce qu'ils ont déjà le champ demandé) sont réécrits tels quels, sans aucune reformattation.

Il y a (avait ?) deux options pour effectuer des requêtes avec Crossref : compte gratuit et adhésion payante. Dans le premier cas, vous devez toujours vous inscrire auprès de Crossref et êtes limité à un petit nombre de requêtes, voir l'accord sur "http://www.crossref.org/01company/free_services_agreement.html". Dans le second cas, vous avez un nom d'utilisateur et un mot de passe, et vous pouvez les utiliser pour des requêtes automatiques. Je ne suis pas sûr si l'utilisation de ce script est autorisée pour les détenteurs de compte gratuit. Dans tous les cas, si vous souhaitez ajouter des DOI à un grand nombre d'entrées, vous devriez vous inscrire en tant que membre payant.

FICHIER DE CONFIGURATION

Le fichier de configuration concerne les requêtes Crossref, et est principalement auto-explicatif : il contient des commentaires (commençant par "#") et des assignations sous la forme

$field = value ;

Les paramètres importants sont $mode ('free' ou 'paid'), $email (pour les utilisateurs gratuits) et $username & $password pour les membres payants.

EXEMPLES

bibdoiadd -c bibdoiadd.cfg -o - citations.bib > result.bib
bibdoiadd -c bibdoiadd.cfg -o result.bib citations.bib
