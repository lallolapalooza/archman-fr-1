NOM

buf-registry-sdk-info - Obtenir les informations SDK pour le module, le plugin et éventuellement la version spécifiés.

SYNTAXE

buf registry sdk info --module= --plugin= [indicateurs]

DESCRIPTION

Cette commande renvoie les informations de version pour un SDK généré basé sur les informations spécifiées. Pour résoudre les informations du SDK, un module et un plugin doivent être spécifiés.

Exemples :

Pour obtenir les informations SDK du dernier commit d'un module et la dernière version d'un plugin, vous devez uniquement spécifier le module et le plugin. La commande suivante résoudra les informations SDK du dernier commit du module connectrpc/eliza et de la dernière version du plugin bufbuild/es :

$ buf registry sdk info --module=buf.build/connectrpc/eliza --plugin=buf.build/connectrpc/es
Module
Owner:  connectrpc
Name:   eliza
Commit: <dernier commit sur le label par défaut>
Plugin
Owner:    bufbuild
Name:     es
Version:  <dernière version du plugin>
Revision: <dernière révision de la version du plugin>
Version: <version SDK pour le commit de module résolu et la version du plugin>

Pour obtenir les informations SDK d'un commit spécifique d'un module et/ou d'une version spécifique d'un plugin, vous pouvez spécifier le commit avec le module et/ou la version avec le plugin. La commande suivante résoudra les informations SDK du commit spécifié du module connectrpc/eliza et de la version spécifiée du plugin bufbuild/es :

$ buf registry sdk info --module=buf.build/connectrpc/eliza:d8fbf2620c604277a0ece1ff3a26f2ff --plugin=buf.build/bufbuild/es:v1.2.1
Module
Owner:  connectrpc
Name:   eliza
Commit: d8fbf2620c604277a0ece1ff3a26f2ff
Plugin
Owner:    bufbuild
Name:     es
Version:  v1.2.1
Revision: 1
Version: 1.2.1-20230727062025-d8fbf2620c60.1

Si vous avez une version SDK et que vous souhaitez connaître les informations correspondantes du commit du module et de la version du plugin pour ce SDK, vous pouvez spécifier le module et le plugin avec la chaîne de version. La commande suivante résoudra les informations SDK de la version SDK spécifiée du module connectrpc/eliza et du plugin bufbuild/es.

$ buf registry sdk --module=buf.build/connectrpc/eliza --plugin=buf.build/bufbuild/es --version=1.2.1-20230727062025-d8fbf2620c60.1
Module
Owner:  connectrpc
Name:   eliza
Commit: d8fbf2620c604277a0ece1ff3a26f2ff
Plugin
Owner:    bufbuild
Name:     es
Version:  v1.2.1
Revision: 1
Version: 1.2.1-20230727062025-d8fbf2620c60.1

Les informations de commit du module et de version du plugin sont résolues en fonction de la chaîne de version SDK spécifiée.

Si une référence de module et/ou une version de plugin sont spécifiées avec la version SDK, alors la version SDK sera validée par rapport à la référence de module et/ou la version de plugin spécifiée. En cas de disparité, cette commande générera une erreur.

$ buf registry sdk info  \
    --module=buf.build/connectrpc/eliza:8b8b971d6fde4dc8ba5d96f9fda7d53c   \
    --plugin=buf.build/bufbuild/es  \
    --version=1.2.1-20230727062025-d8fbf2620c60.1
Failure: invalid_argument: invalid SDK version v1.2.1-20230727062025-d8fbf2620c60.1 with module short commit d8fbf2620c60 for resolved module reference connectrpc/eliza:8b8b971d6fde4dc8ba5d96f9fda7d53c

Dans ce cas, la version SDK fournie résout un commit différent du commit fourni pour le module.

OPTIONS

--format="texte" Le format de sortie à utiliser. Doit être l'un des [texte,json]

-h, --help[=false] aide pour info

--module="" La référence du module pour le SDK.

--plugin="" La référence du plugin pour le SDK.

--version="" La version du SDK.

OPTIONS HÉRITÉES DES COMMANDES PARENT

--debug[=false] Activer la journalisation de débogage

--log-format="couleur" Le format du journal [texte,couleur,json]

--timeout=0s La durée avant expiration, la régler sur 0 signifie pas de délai d'attente
