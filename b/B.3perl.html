DESCRIPTIO

N

Le module "B" fournit des classes qui permettent à un programme Perl d'explorer ses propres entrailles. C'est le module utilisé pour implémenter les « backends » du compilateur Perl. L'utilisation du compilateur ne requiert pas la connaissance de ce module : voir le module O pour la partie visible par l'utilisateur. Le module "B" est utile à ceux qui souhaitent écrire de nouveaux backends de compilateur. Cette documentation suppose que le lecteur connaît une bo

nne part des entrailles de perl, y compris des choses comme les SV, les
OP et la table de symboles interne et l'arbre de syntaxe d'un programme.

APERÇ

U

Le module "B" contient un ensemble de fonctions utilitaires pour interroger l'état courant de l'interpréteur Perl ; ces fonctions retournent typiquement des objets des cla

sses B::SV et B::OP, ou de leurs classes dérivées. Ces classes définissent à leur t
our des méthodes pour interroger les objets résultants sur leur propre état interne.

overlay

Bien que l'arbre d'optimisation soit en lecture seule, il existe une fonctionnalité de superposition qui permet de remplacer les valeurs renvoyées par les différentes méthodes B::*OP pour une opération donnée. $B::overlay doit être défini pour référencer un hachage à deux niveaux : indexé par l'adresse de l'OP, puis par le nom de la méthode. Chaque fois qu'une méthode d'op est appelée, la valeur dans le hachage est renvoyée si elle existe. Cette fonctionnalité est utilisée par B::Deparse pour « annuler » certaines optimisations.
