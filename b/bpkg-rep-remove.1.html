bpkg-rep-remove - supprimer

un dépôt de la
configuration

SYNOPSI

S

bpkg rep-remove|remove [options] (rep-name|rep-loc)...
bpkg rep-remove|remove [options] --all|-a
bpkg rep-remove|remove [options] --cle

a
n

DESCRIPTIO

N

La commande rep-remove supprime les dépôts de paquets spécifiés de la configuration. Le dépôt à supprimer peut être spécifié soit par un nom de dépôt, soit par un emplacement de dépôt (URL ou chemin de répertoire)

.

Alternativement, l'option --all|-a peut être utilisée pour supprimer tous les dépôts qui ont été ajoutés précédemment (bpkg-rep-add(1)) à la

configuration.

Enfin, l'option --clean peut être utilisée pour rétablir les dépôts dans leur ét

at propre, comme s'ils avaient ét
é ajoutés mais jamais récupérés.

FICHIERS D'OPTIONS PAR

DÉFAUT

Voir bpkg-default-options-files(1) pour un aperçu des fichiers d'options par défaut. Pour la commande pkg-rep-remove, le répertoire de départ de la recherche est le répertoire de configuration. Les fichiers d'options suivants sont recherchés dans chaque répertoire et, s'ils sont trouvés, chargés dans l'ordre indiqué

: 
bpkg.options
bpkg-rep-remove.
options

Les options de commande rep-remove suivantes ne peuvent pas être spécifiées dans les fichiers d'options par défaut

: 
--directory|
