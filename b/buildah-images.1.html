NOM

buildah-images - Lister les images dans le stockage local.

SYNTAXE

buildah images [options] [image]

DESCRIPTION

Affiche les images stockées localement, leurs noms, tailles, dates de création et leurs identifiants. La date de création est affichée dans la locale temporelle de la machine locale.

OPTIONS

--all, -a

Afficher toutes les images, y compris les images intermédiaires d'une construction.

--digests

Afficher les digests d'image.

--filter, -f=[]

Filtrer la sortie en fonction des conditions fournies (par défaut []).

Filtres:

after,since=image
Filtrer sur les images créées depuis l'image donnée.

before=image
Filtrer sur les images créées avant l'image donnée.

dangling=true|false
Afficher les images "dangling" (pendants). Une image est considérée comme "dangling" si elle n'a pas de noms et d'étiquettes associés.

id=id
Afficher l'image avec cet identifiant spécifique.

intermediate=true|false
Afficher les images intermédiaires. Une image est considérée comme intermédiaire si elle est "dangling" et n'a pas de fils.

label=key[=value]
Filtrer par les étiquettes de l'image clé et/ou valeur.

readonly=true|false
Afficher uniquement les images en lecture seule ou les images en lecture/écriture. Par défaut, les deux sont affichées. Les images en lecture seule peuvent être configurées en modifiant "additionalimagestores" dans le fichier /etc/containers/storage.conf.

reference=reference
Afficher les images correspondant à la référence spécifiée. Les jokers sont pris en charge (par exemple, "reference=fedora:3").

--format="TEMPLATE"

Afficher les images de manière formatée en utilisant un modèle Go.

Les espaces réservés valides pour le modèle Go sont listés ci-dessous :

Placeholder Description
.Created Date de création en temps epoch
.CreatedAt Date de création formatée joliment
.CreatedAtRaw Date de création au format brut
.Digest Digest de l'image
.ID ID de l'image
.Name Nom de l'image
.ReadOnly Indique si l'image provient d'un magasin en lecture seule
.Size Taille de l'image
.Tag Étiquette de l'image

--history

Afficher l'historique des noms d'image.

--json

Afficher la sortie au format JSON.

--no-trunc

Ne pas tronquer la sortie.

--noheading, -n

Omettre les en-têtes de tableau de la liste des images.

--quiet, -q

Afficher uniquement les identifiants d'image.

EXEMPLE

buildah images

buildah images fedora:latest

buildah images --json

buildah images --quiet

buildah images -q --noheading --no-trunc

buildah images --quiet fedora:latest

buildah images --filter dangling=true

buildah images --format "ImageID: {{.ID}}"
