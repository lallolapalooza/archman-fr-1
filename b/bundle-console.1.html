NOM

bundle-console - Ouvre une session IRB avec le bundle pré-chargé

SYNTAXE

bundle console [GROUPE]

DESCRIPTION

Démarre une session de console Ruby interactive dans le contexte du bundle actuel.

Si aucun GROUPE n'est spécifié, toutes les gems du groupe default du fichier Gemfile(5) https://bundler.io/man/gemfile.5.html sont chargées préliminairement.

Si GROUPE est spécifié, toutes les gems du groupe donné dans le Gemfile, en plus des gems du groupe default, sont chargées. Même si le groupe donné n'existe pas dans le Gemfile, la console IRB démarre sans avertissement ni erreur.

La variable d'environnement BUNDLE_CONSOLE ou la commande bundle config set console peut être utilisée pour changer l'interpréteur de la liste suivante :

  • irb (par défaut)
  • pry (https://github.com/pry/pry)
  • ripl (https://github.com/cldwalker/ripl)

bundle console utilise irb par défaut. Un Pry ou Ripl alternatif peut être utilisé avec bundle console en ajustant le paramètre console de Bundler. Assurez-vous également que pry ou ripl est dans votre Gemfile.

EXEMPLE

$ bundle config set console pry
$ bundle console
Resolving dependencies...
[1] pry(main)>
