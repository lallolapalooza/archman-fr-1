BIO_F_MD(3ssl) OpenSSL BIO_F_MD(3ssl)

NOM

BIO_f_md, BIO_set_md, BIO_get_md, BIO_get_md_ctx - Filtre BIO de résumé de message

SYNTAXE

#include <openssl/bio.h>
#include <openssl/evp.h>
const BIO_METHOD *BIO_f_md(void);
int BIO_set_md(BIO *b, EVP_MD *md);
int BIO_get_md(BIO *b, EVP_MD **mdp);
int BIO_get_md_ctx(BIO *b, EVP_MD_CTX **mdcp);

DESCRIPTION

BIO_f_md() renvoie la méthode BIO de résumé de message. Il s'agit d'un BIO de filtrage qui résume toutes les données qui le traversent. C'est un wrapper BIO pour les routines de résumé EVP_DigestInit(), EVP_DigestUpdate() et EVP_DigestFinal().

Toutes les données écrites ou lues via un BIO de résumé en utilisant BIO_read_ex() et BIO_write_ex() sont résumées.

BIO_gets(), si son paramètre size est suffisamment grand, termine le calcul du résumé et renvoie la valeur du résumé. BIO_puts() n'est pas pris en charge.

BIO_reset() réinitialise un BIO de résumé.

BIO_set_md() définit le résumé de message du BIO b à md : cela doit être appelé pour initialiser un BIO de résumé avant que toute donnée ne le traverse. C'est une macro BIO_ctrl().

BIO_get_md() place un pointeur vers la méthode de résumé du BIO dans mdp. C'est une macro BIO_ctrl().

BIO_get_md_ctx() renvoie le contexte du BIO de résumé dans mdcp.

NOTES

Le contexte renvoyé par BIO_get_md_ctx() peut être utilisé dans les appels à EVP_DigestFinal() ainsi qu'aux routines de signature EVP_SignFinal() et EVP_VerifyFinal().

Le contexte renvoyé par BIO_get_md_ctx() est une structure de contexte interne. Les modifications apportées à ce contexte affecteront le BIO de résumé lui-même et le pointeur de contexte deviendra invalide lorsque le BIO de résumé sera libéré.

Après que le résumé a été récupéré d'un BIO de résumé, il doit être réinitialisé en appelant BIO_reset() ou BIO_set_md() avant que d'autres données ne le traversent.

Si une application a besoin d'appeler BIO_gets() ou BIO_puts() à travers une chaîne contenant des BIO de résumé, cela peut être fait en préfixant un BIO tamponné.

L'appel à BIO_get_md_ctx() renverra le contexte et initialisera l'état du BIO. Cela permet aux applications d'initialiser le contexte extérieurement si les appels standard tels que BIO_set_md() ne sont pas suffisamment flexibles.

VALEUR DE RETOUR

BIO_f_md() renvoie la méthode BIO de résumé.

BIO_set_md(), BIO_get_md() et BIO_md_ctx() renvoient 1 en cas de succès et <=0 en cas d'échec.

EXEMPLES

L'exemple suivant crée une chaîne de BIO contenant un BIO de résumé SHA1 et MD5 et y fait passer la chaîne "Hello World". La gestion des erreurs a été omise pour plus de clarté.

BIO *bio, *mdtmp;
char message[] = "Hello World";
bio = BIO_new(BIO_s_null());
mdtmp = BIO_new(BIO_f_md());
BIO_set_md(mdtmp, EVP_sha1());
/*
 * Pour BIO_push(), nous voulons ajouter le BIO récepteur et garder une note
 * du début de la chaîne.
 */
bio = BIO_push(mdtmp, bio);
mdtmp = BIO_new(BIO_f_md());
BIO_set_md(mdtmp, EVP_md5());
bio = BIO_push(mdtmp, bio);
/* Note : mdtmp peut maintenant être jeté */
BIO_write(bio, message, strlen(message));

L'exemple suivant résume les données en lisant à travers une chaîne au lieu de cela :

BIO *bio, *mdtmp;
char buf[1024];
int rdlen;
bio = BIO_new_file(file, "rb");
mdtmp = BIO_new(BIO_f_md());
BIO_set_md(mdtmp, EVP_sha1());
bio = BIO_push(mdtmp, bio);
mdtmp = BIO_new(BIO_f_md());
BIO_set_md(mdtmp, EVP_md5());
bio = BIO_push(mdtmp, bio);
do {
    rdlen = BIO_read(bio, buf, sizeof(buf));
    /* Peut-être vouloir faire quelque chose avec les données ici */
} while (rdlen > 0);

Cet exemple récupère les résumés de message d'une chaîne de BIO et les affiche. Cela pourrait être utilisé avec les exemples ci-dessus.

BIO *mdtmp;
unsigned char mdbuf[EVP_MAX_MD_SIZE];
int mdlen;
int i;
mdtmp = bio;   /* Supposons que bio a été précédemment configuré */
do {
    EVP_MD *md;
    mdtmp = BIO_find_type(mdtmp, BIO_TYPE_MD);
    if (!mdtmp)
        break;
    BIO_get_md(mdtmp, &md);
    printf("%s résumé", OBJ_nid2sn(EVP_MD_get_type(md)));
    mdlen = BIO_gets(mdtmp, mdbuf, EVP_MAX_MD_SIZE);
    for (i = 0; i < mdlen; i++) printf(":%02X", mdbuf[i]);
    printf("\n");
    mdtmp = BIO_next(mdtmp);
} while (mdtmp);
BIO_free_all(bio);

BOGUES

Le manque de prise en charge de BIO_puts() et le comportement non standard de BIO_gets() pourraient être considérés comme anormaux. On pourrait soutenir que BIO_gets() et BIO_puts() devraient être transmis au BIO suivant dans la chaîne et résumer les données transmises, et que les résumés devraient être récupérés à l'aide d'un appel BIO_ctrl() séparé.

HISTORIQUE

Avant OpenSSL 1.0.0, l'appel à BIO_get_md_ctx() ne fonctionnait que si le BIO était initialisé au préalable.
