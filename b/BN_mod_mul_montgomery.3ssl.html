BN_mod_mul_montgomery(3ssl)

Paquet: openssl

Licences: Apache-2.0

BN_MOD_MUL_MONTGOMERY(3ssl) OpenSSL BN_MOD_MUL_MONTGOMERY(3ssl)

NOM

BN_mod_mul_montgomery, BN_MONT_CTX_new, BN_MONT_CTX_free, BN_MONT_CTX_set, BN_MONT_CTX_copy, BN_from_montgomery, BN_to_montgomery - Multiplication de Montgomery

SYNTAXE

#include <openssl/bn.h>
BN_MONT_CTX *BN_MONT_CTX_new(void);
void BN_MONT_CTX_free(BN_MONT_CTX *mont);
int BN_MONT_CTX_set(BN_MONT_CTX *mont, const BIGNUM *m, BN_CTX *ctx);
BN_MONT_CTX *BN_MONT_CTX_copy(BN_MONT_CTX *to, BN_MONT_CTX *from);
int BN_mod_mul_montgomery(BIGNUM *r, BIGNUM *a, BIGNUM *b,
                          BN_MONT_CTX *mont, BN_CTX *ctx);
int BN_from_montgomery(BIGNUM *r, BIGNUM *a, BN_MONT_CTX *mont,
                       BN_CTX *ctx);
int BN_to_montgomery(BIGNUM *r, BIGNUM *a, BN_MONT_CTX *mont,
                     BN_CTX *ctx);

DESCRIPTION

Ces fonctions implémentent la multiplication de Montgomery. Elles sont utilisées automatiquement lorsque BN_mod_exp(3) est appelé avec des entrées appropriées, mais elles peuvent être utiles lorsque plusieurs opérations doivent être effectuées en utilisant le même module.

BN_MONT_CTX_new() alloue et initialise une structure BN_MONT_CTX.

BN_MONT_CTX_set() configure la structure mont à partir du module m en pré-calculant son inverse et une valeur R.

BN_MONT_CTX_copy() copie le BN_MONT_CTX from dans to.

BN_MONT_CTX_free() libère les composants du BN_MONT_CTX et, s'il a été créé par BN_MONT_CTX_new(), également la structure elle-même. Si mont est NULL, rien n'est fait.

BN_mod_mul_montgomery() calcule Mont(a,b) := a*b*R^-1 et place le résultat dans r.

BN_from_montgomery() effectue la réduction de Montgomery r = a*R^-1.

BN_to_montgomery() calcule Mont(a,R^2), c'est-à-dire a*R. Notez que a doit être positif et plus petit que le module.

Pour toutes les fonctions, ctx est un BN_CTX préalablement alloué utilisé pour les variables temporaires.

VALEURS DE RETOUR

BN_MONT_CTX_new() retourne le BN_MONT_CTX nouvellement alloué, et NULL en cas d'erreur.

BN_MONT_CTX_free() n'a pas de valeur de retour.

Pour les autres fonctions, 1 est retourné en cas de succès, 0 en cas d'erreur. Les codes d'erreur peuvent être obtenus via ERR_get_error(3).

AVERTISSEMENTS

Les entrées doivent être réduites modulo m, sinon le résultat sera en dehors de la plage attendue.

VOIR AUSSI

ERR_get_error(3), BN_add(3), BN_CTX_new(3)

HISTORIQUE

BN_MONT_CTX_init() a été supprimé dans OpenSSL 1.1.0
