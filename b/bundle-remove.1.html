NOM

bundle-remove - Supprime les gems du Gemfile

SYNTAXE

bundle remove [GEM [GEM ...]] [--install]

DESCRIPTION

Supprime les gems spécifiées du Gemfile tout en s'assurant que le Gemfile résultant est toujours valide. Si une gem ne peut pas être supprimée, un avertissement est affiché. Si une gem est déjà absente du Gemfile, une erreur est levée.

OPTIONS

--install
Exécute bundle install après la suppression des gems spécifiées du Gemfile, ce qui garantit que le fichier de verrouillage et les gems installées sur le disque sont également mis à jour pour supprimer la ou les gems spécifiées.

Exemple :

bundle remove rails

bundle remove rails rack

bundle remove rails rack --install
