BF_TAR(1) Manuel de référence Bogofilter BF_TAR(1)

NOM

bf_tar - script shell pour écrire un fichier tar d'un répertoire bogofilter sur la sortie standard

SYNTAXE

bf_tar [-r] [-R] répertoire_bogofilter

DESCRIPTION

bf_tar regroupe un répertoire de travail bogofilter au format tar et le copie sur la sortie standard (votre console, ou là où vous le redirigez, voir EXEMPLES ci-dessous).

OPTIONS

L'option -r fait en sorte que bf_tar supprime les fichiers journaux inactifs après que l'archive ait été écrite avec succès. Par défaut, les fichiers journaux sont conservés.

L'option -R fait en sorte que bf_tar supprime les fichiers journaux inactifs avant que l'archive ne soit écrite. Cela peut réduire les chances que l'archive résultante soit récupérable si elle est endommagée. L'archive peut cependant être plus petite. Par défaut, les fichiers journaux sont conservés.

STATUT DE SORTIE

Le script se termine avec le code de statut 0 si tout s'est bien passé, et non nul s'il a rencontré des problèmes.

EXEMPLES

•bf_tar ~/.bogofilter > outfile.tar

Écrit un fichier .tar standard contenant les fichiers essentiels de ~/.bogofilter dans outfile.tar.

•bf_tar ~/.bogofilter | gzip -9 -c > outfile.tar.gz

Écrit un fichier .tar.gz compressé contenant les fichiers essentiels de ~/.bogofilter dans outfile.tar.gz.

•bf_tar `pwd`/mondossier > outfile.tar

Préparez $(pwd)/ ou `pwd`/ si vous souhaitez spécifier un chemin absolu au lieu d'un chemin relatif.

NOTES

Ce script est destiné à être utilisé avec les versions de bogofilter basées sur Berkeley DB.

Ce script nécessite un utilitaire pax conforme à SUSv2.

Ce script attend un shell conforme à SUSv2. Les systèmes Solaris devraient avoir le paquet SUNWxcu4 installé (lorsque bogofilter est configuré) afin que /usr/xpg4/bin/sh puisse être utilisé.
