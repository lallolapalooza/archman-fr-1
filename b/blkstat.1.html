BLKSTAT(1) Manuel des commandes générales BLKSTAT(1)

NOM

blkstat - Afficher les détails d'une unité de données de système de fichiers (c'est-à-dire bloc ou secteur)

SYNTAXE

blkstat [-f type_fs ] [-i type_img] [-o offset_img] [-b taille_secteur_dev] [-vV] image [images] addr

DESCRIPTION

blkstat affiche l'état d'allocation de l'unité de données donnée. blkstat était appelé dstat dans les versions de TSK antérieures à 3.0.0.

ARGUMENTS

-f type_fs
Spécifier le type de système de fichiers. Utiliser '-f list' pour lister les types de systèmes de fichiers supportés. Si non spécifié, des méthodes de détection automatique sont utilisées.
-i type_img
Identifier le type de fichier image, tel que brut. Utiliser '-i list' pour lister les types supportés. Si non spécifié, des méthodes de détection automatique sont utilisées.
-o offset_img
L'offset du secteur où le système de fichiers commence dans l'image.
-b taille_secteur_dev
La taille, en octets, des secteurs du périphérique sous-jacent. Si non spécifié, la valeur dans le format de l'image est utilisée (si elle existe) ou 512 octets sont supposés.
-v
Sortie détaillée des instructions de débogage sur stderr
-V
Afficher la version
image [images]
L'image disque ou partition à lire, dont le format est donné avec '-i'. Plusieurs noms de fichiers image peuvent être donnés si l'image est divisée en plusieurs segments. Si un seul fichier image est donné, et que son nom est le premier d'une séquence (par exemple, indiqué par la fin en '.001'), les segments d'image suivants seront inclus automatiquement.
addr
Adresse à afficher les statistiques. Ceci est un fragment pour les systèmes de fichiers UNIX ou un secteur pour FAT.
