bsearch(3) Manuel des fonctions de bibliothèque bsearch(3)

NOM

bsearch - recherche binaire dans un tableau trié

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <stdlib.h>
void *bsearch(size_t n, size_t size;
              const void key[size], const void base[size * n],
              size_t n, size_t size,
              typeof(int (const void [size], const void [size]))
                  *compar);

DESCRIPTION

La fonction bsearch() recherche dans un tableau de n objets, dont le membre initial est pointé par base, un membre qui correspond à l'objet pointé par key. La taille de chaque membre du tableau est spécifiée par size.

Le contenu du tableau doit être dans un ordre trié ascendant selon la fonction de comparaison référencée par compar. La routine compar est censée avoir deux arguments qui pointent vers l'objet key et vers un membre du tableau, dans cet ordre, et doit retourner un entier inférieur, égal ou supérieur à zéro si l'objet key est, respectivement, trouvé inférieur, égal ou supérieur au membre du tableau.

VALEUR DE RETOUR

La fonction bsearch() retourne un pointeur vers un membre correspondant du tableau, ou NULL si aucune correspondance n'est trouvée. S'il y a plusieurs éléments qui correspondent à la clé, l'élément retourné est non spécifié.

EXEMPLES

L'exemple ci-dessous trie d'abord un tableau de structures à l'aide de qsort(3), puis récupère les éléments souhaités à l'aide de bsearch().

#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#define NITEMS(arr)  (sizeof((arr)) / sizeof((arr)[0]))
struct mi {
    int         nr;
    const char  *name;
};
static struct mi  months[] = {
    { 1, "jan" }, { 2, "feb" }, { 3, "mar" }, { 4, "apr" },
    { 5, "may" }, { 6, "jun" }, { 7, "jul" }, { 8, "aug" },
    { 9, "sep" }, {10, "oct" }, {11, "nov" }, {12, "dec" }
};
static int
compmi(const void *m1, const void *m2)
{
    const struct mi *mi1 = m1;
    const struct mi *mi2 = m2;
    return strcmp(mi1->name, mi2->name);
}
int
main(int argc, char *argv[])
{
    qsort(months, NITEMS(months), sizeof(months[0]), compmi);
    for (size_t i = 1; i < argc; i++) {
        struct mi key;
        struct mi *res;
        key.name = argv[i];
        res = bsearch(&key, months, NITEMS(months),
                      sizeof(months[0]), compmi);
        if (res == NULL)
            printf("'%s': unknown month\n", argv[i]);
        else
            printf("%s: month #%d\n", res->name, res->nr);
    }
    exit(EXIT_SUCCESS);
}
