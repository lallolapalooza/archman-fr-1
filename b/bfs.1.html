ACTIONS

-delete
-rm

Supprime tous les fichiers trouvés (implique -depth).
-exec command ... {} ;
Exécute une commande.
-exec command ... {} +
Exécute une commande avec plusieurs fichiers à la fois.
-ok command ... {} ;
Demande à l'utilisateur s'il faut exécuter une commande.

-execdir command ... {} ;
-execdir command ... {} +
-okdir command ... {} ;

Comme -exec/-ok, mais exécute la commande dans le même répertoire que le(s) fichier(s) trouvé(s).
-exit [STATUS]
Quitte immédiatement avec le statut donné (0 si non spécifié).

-fls FILE
-fprint FILE
-fprint0 FILE
-fprintf FILE FORMAT

Comme -ls/-print/-print0/-printf, mais écrit dans FILE au lieu de la sortie standard.
-limit N
Quitte une fois que cette action a été évaluée N fois.
-ls
Liste les fichiers comme ls -dils.
-print
Affiche le chemin du fichier trouvé.
-print0
Comme -print, mais utilise le caractère nul ('\0') comme séparateur plutôt que les sauts de ligne. Utile en conjonction avec xargs -0.
-printf FORMAT
Affiche selon une chaîne de format (voir find(1)). Les directives de format supplémentaires suivantes sont prises en charge :
%w
L'heure de création du fichier, dans le même format que %a/%c/%t.
%Wk
Champ k de l'heure de création du fichier, dans le même format que %Ak/%Ck/%Tk.
-printx
Comme -print, mais échappe les espaces et les caractères de guillemets, pour rendre la sortie sûre pour xargs(1). Envisagez plutôt d'utiliser -print0 et xargs -0 .
-prune
Ne descend pas dans ce répertoire. Cela n'a aucun effet si -depth est activé (explicitement, ou implicitement par -delete). Utilisez plutôt -exclude dans ce cas.
-quit
Quitte immédiatement.

ENVIRONNEMENT

Certaines variables d'environnement affectent le comportement de bfs.

LANG
LC_*

Spécifie la locale(7) utilisée pour diverses choses. bfs n'est pas (encore) traduit dans d'autres langues que l'anglais, mais la locale affectera toujours le format des valeurs affichées. Les invitations oui/non (par exemple depuis -ok) seront également interprétées selon la locale courante.

LS_COLORS
BFS_COLORS

Contrôle les couleurs utilisées lors de l'affichage des chemins de fichiers si -color est activé. bfs interprète LS_COLORS de la même manière que GNU ls(1) (voir dir_colors(5)). BFS_COLORS peut être utilisé pour personnaliser bfs sans affecter les autres commandes.
NO_COLOR
Fait que bfs utilise par défaut -nocolor s'il est défini (voir https://no-color.org/).
PAGER
Spécifie le visualiseur utilisé pour la sortie -help . Par défaut, c'est less(1), s'il est trouvé dans le PATHcourant, sinon more(1).
PATH
Utilisé pour résoudre les exécutables pour -exec[dir] et -ok[dir].
POSIXLY_CORRECT
Fait que bfs se conforme plus strictement à la spécification POSIX.1-2017 pour find(1). Actuellement, cela a deux effets :
  • Désactive les avertissements par défaut, car POSIX interdit l'écriture sur l'erreur standard (sauf pour l'invitation -ok ), à moins que la commande échoue également avec un statut de sortie non nul.
  • Fait que -ls et -fls utilisent des blocs de 512 octets au lieu de blocs de 1024 octets. (POSIX ne spécifie pas ces actions, mais les implémentations BSD de find(1) utilisent des blocs de 512 octets, tandis que GNU find(1) utilise des blocs de 1024 octets par défaut.)

Cela ne désactive pas bfset ses diverses extensions aux fonctionnalités POSIX de base. POSIXLY_CORRECT a les mêmes effets sur GNU find(1).

EXEMPLES

bfs
Sans arguments, bfs affiche tous les fichiers sous le répertoire courant dans l'ordre en largeur.
bfs -name '*.txt'
Affiche tous les fichiers .txt sous le répertoire courant. *.txt est entre guillemets pour s'assurer que le motif est traité par bfs plutôt que par le shell.
bfs -name access_log -L /var
Trouve tous les fichiers nommés access_log sous /var, en suivant les liens symboliques. bfs permet aux drapeaux et aux chemins d'apparaître n'importe où sur la ligne de commande.
bfs ~ -not -user $USER
Affiche tous les fichiers de votre répertoire personnel qui ne vous appartiennent pas.
bfs -xtype l
Trouve les liens symboliques cassés.
bfs -name config -exclude -name .git
Trouve tous les fichiers nommés config, en ignorant chaque répertoire .git .
bfs -type f -executable -exec strip {} +
Exécute strip(1) sur tous les fichiers exécutables qu'il trouve, en lui passant plusieurs fichiers à la fois.
