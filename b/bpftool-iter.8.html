NOM

bpftool-iter - outil pour créer des itérateurs BPF

SYNTAXE

bpftool [OPTIONS] iter COMMANDE

OPTIONS := { { -j | --json } [{ -p | --pretty }] | { -d | --debug } }

COMMANDES := { pin | help }

COMMANDES ITER

bpftool iter pin OBJ CHEMIN [map MAP]
bpftool iter help
OBJ := /un/fichier/de/bpf_iter_target.o
MAP := { id ID_MAP | pinned FICHIER }

DESCRIPTION

bpftool iter pin OBJ CHEMIN [map MAP]
Un itérateur bpf combine une itération du noyau sur des données spécifiques du noyau (par exemple, tâches, bpf_maps, etc.) et un programme bpf appelé pour chaque objet de données du noyau (par exemple, une tâche, une bpf_map, etc.). L'espace utilisateur peut *lire* la sortie de l'itérateur du noyau via l'appel système *read()*.

La commande *pin* crée un itérateur bpf à partir de *OBJ*, et le fixe à *CHEMIN*. Le *CHEMIN* doit être situé sur le montage *bpffs*. Il ne doit pas contenir de point ('.'), qui est réservé pour les futures extensions de *bpffs*.

Les itérateurs d'éléments de carte bpf nécessitent un paramètre supplémentaire *MAP* afin que le programme bpf puisse itérer sur les éléments de la carte pour cette carte. L'utilisateur peut avoir un programme bpf dans le noyau qui s'exécute avec chaque élément de carte, effectuant des vérifications, des filtrages, des agrégations, etc. sans copier de données dans l'espace utilisateur.

L'utilisateur peut ensuite *cat CHEMIN* pour voir la sortie de l'itérateur bpf.

bpftool iter help
Affiche un court message d'aide.

OPTIONS

-h, --help
Affiche un court message d'aide (similaire à bpftool help).
-V, --version
Affiche le numéro de version de bpftool (similaire à bpftool version), le numéro de version de libbpf utilisée, et les fonctionnalités optionnelles qui ont été incluses lors de la compilation de bpftool. Les fonctionnalités optionnelles incluent le lien avec LLVM ou libbfd pour fournir le désassembleur pour les programmes JIT-tés (bpftool prog dump jited) et l'utilisation de squelettes BPF (certaines fonctionnalités comme bpftool prog profile ou l'affichage des pids associés aux objets BPF peuvent en dépendre).
-j, --json
Génère une sortie JSON. Pour les commandes qui ne peuvent pas produire de JSON, cette option n'a aucun effet.
-p, --pretty
Génère une sortie JSON lisible par l'homme. Implique -j.
-d, --debug
Affiche tous les journaux disponibles, y compris les informations de niveau débogage. Cela inclut les journaux de libbpf ainsi que ceux du vérificateur, lors de la tentative de chargement des programmes.

EXEMPLES

# bpftool iter pin bpf_iter_netlink.o /sys/fs/bpf/my_netlink

Crée un itérateur bpf basé sur fichier à partir de bpf_iter_netlink.o et le fixe
à /sys/fs/bpf/my_netlink

# bpftool iter pin bpf_iter_hashmap.o /sys/fs/bpf/my_hashmap map id 20

Crée un itérateur bpf basé sur fichier à partir de bpf_iter_hashmap.o et de la carte
avec l'id 20, et le fixe à /sys/fs/bpf/my_hashmap
