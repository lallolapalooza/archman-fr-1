NOM

borg-info - Afficher les détails d'une archive tels que l'espace disque utilisé

SYNTAXE

borg [options communes] info [options] [RÉPERTOIRE_OU_ARCHIVE]

DESCRIPTION

Cette commande affiche des informations détaillées sur l'archive ou le répertoire spécifié.

Veuillez noter que les tailles dédupliquées des archives individuelles ne s'additionnent pas pour donner la taille dédupliquée du répertoire ("toutes les archives"), car les deux signifient des choses différentes :

Cette archive / taille dédupliquée = quantité de données stockées UNIQUEMENT pour cette archive = morceaux uniques de cette archive. Toutes les archives / taille dédupliquée = quantité de données stockées dans le répertoire = tous les morceaux du répertoire.

Les archives Borg ne peuvent contenir qu'une quantité limitée de métadonnées de fichiers. La taille d'une archive par rapport à cette limite dépend de plusieurs facteurs, principalement du nombre de fichiers, de la longueur des chemins et d'autres métadonnées stockées pour les fichiers. Ceci est indiqué comme utilisation de la taille maximale d'archive prise en charge.

OPTIONS

Voir borg-common(1) pour les options communes des commandes Borg.

arguments

RÉPERTOIRE_OU_ARCHIVE
répertoire ou archive dont il faut afficher les informations

options

--json
formater la sortie en JSON

Filtres d'archives

-P PREFIX, --prefix PREFIX
ne considérer que les noms d'archives commençant par ce préfixe. (obsolète)
-a GLOB, --glob-archives GLOB
ne considérer que les noms d'archives correspondant au glob. Les règles sh s'appliquent (sans utiliser réellement le préfixe sh:), voir "borg help patterns".
--sort-by CLÉS
Liste des clés de tri séparées par des virgules ; clés valides : timestamp, archive, name, id ; par défaut : timestamp
--first N
considérer les N premières archives après l'application des autres filtres
--last N
considérer les N dernières archives après l'application des autres filtres
