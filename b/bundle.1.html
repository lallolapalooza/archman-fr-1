BUNDLE(1) Manuel des commandes générales BUNDLE(1)

NOM

bundle - Gestion des dépendances Ruby

SYNTAXE

bundle COMMANDE [--no-color] [--verbose] [ARGUMENTS]

DESCRIPTION

Bundler gère systématiquement et de manière répétable les **dépendances d'une application** tout au long de sa vie sur plusieurs machines.

Consultez le site web de Bundler https://bundler.io pour des informations sur la prise en main, et Gemfile(5) pour plus d'informations sur le format du Gemfile.

OPTIONS

--no-color
Affiche toutes les sorties sans couleur
--retry, -r
Spécifie le nombre de fois où vous souhaitez tenter les commandes réseau
--verbose, -V
Affiche des informations de journalisation supplémentaires

COMMANDES BUNDLE

Nous divisons les sous-commandes de bundle en commandes principales et utilitaires :

COMMANDES PRINCIPALES

bundle install(1) bundle-install.1.html
Installe les gems spécifiées par le Gemfile ou Gemfile.lock
bundle update(1) bundle-update.1.html
Met à jour les dépendances vers leurs dernières versions
bundle cache(1) bundle-cache.1.html
Empaquette les fichiers .gem requis par votre application dans le répertoire vendor/cache (alias : bundle package, bundle pack)
bundle exec(1) bundle-exec.1.html
Exécute un script dans le bundle courant
bundle config(1) bundle-config.1.html
Spécifie et lit les options de configuration pour Bundler
bundle help(1) bundle-help.1.html
Affiche l'aide détaillée pour chaque sous-commande

UTILITAIRES

bundle add(1) bundle-add.1.html
Ajoute la gem nommée au Gemfile et exécute bundle install
bundle binstubs(1) bundle-binstubs.1.html
Génère des binstubs pour les exécutables dans une gem
bundle check(1) bundle-check.1.html
Détermine si les exigences de votre application sont installées et disponibles pour Bundler
bundle show(1) bundle-show.1.html
Affiche l'emplacement source d'une gem particulière dans le bundle
bundle outdated(1) bundle-outdated.1.html
Affiche toutes les gems obsolètes dans le bundle courant
bundle console(1) (obsolète)
Démarre une session IRB dans le bundle courant
bundle open(1) bundle-open.1.html
Ouvre une gem installée dans l'éditeur
bundle lock(1) bundle-lock.1.html
Génère un fichier de verrouillage pour vos dépendances
bundle viz(1) bundle-viz.1.html (obsolète)
Génère une représentation visuelle de vos dépendances
bundle init(1) bundle-init.1.html
Génère un simple Gemfile, placé dans le répertoire courant
bundle gem(1) bundle-gem.1.html
Crée une gem simple, adaptée au développement avec Bundler
bundle platform(1) bundle-platform.1.html
Affiche les informations de compatibilité de plateforme
bundle clean(1) bundle-clean.1.html
Nettoie les gems inutilisées dans votre répertoire Bundler
bundle doctor(1) bundle-doctor.1.html
Affiche des avertissements sur les problèmes courants
bundle remove(1) bundle-remove.1.html
Supprime les gems du Gemfile
bundle plugin(1) bundle-plugin.1.html
Gère les plugins Bundler
bundle version(1) bundle-version.1.html
Affiche les informations sur la version de Bundler

PLUGINS

Lorsque vous exécutez une commande qui n'est pas listée dans COMMANDES PRINCIPALES ou UTILITAIRES, Bundler essaiera de trouver un exécutable sur votre chemin nommé bundler-<commande> et l'exécutera, en lui passant les arguments supplémentaires.

OBSOLÈTE

Ces commandes sont obsolètes et ne devraient plus être utilisées :

•
