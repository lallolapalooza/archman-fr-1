NOM

bpkg-rep-list - lister les dépôts dans la configuration

SYNTAXE

bpkg rep-list|list [options]

DESCRIPTION

La commande rep-list liste les dépôts dans la configuration.

Pour chaque dépôt, une ligne contenant le nom du dépôt et son emplacement est imprimée sur stdout. Si les options --complements|-c et/ou --prerequisites|-p sont spécifiées, elle est suivie de la liste des dépôts complémentaires et/ou prérequis, de manière récursive.

OPTIONS REP-LIST

--complements|-c
Lister les dépôts complémentaires.
--prerequisites|-p
Lister les dépôts prérequis.
--directory|-d rep
Supposer que la configuration se trouve dans rep plutôt que dans le répertoire de travail courant.

FICHIERS OPTIONS PAR DÉFAUT

Voir bpkg-default-options-files(1) pour un aperçu des fichiers d'options par défaut. Pour la commande rep-list, le répertoire de départ de la recherche est le répertoire de configuration. Les fichiers d'options suivants sont recherchés dans chaque répertoire et, s'ils sont trouvés, chargés dans l'ordre indiqué :

bpkg.options
bpkg-rep-list.options

Les options de commande rep-list suivantes ne peuvent pas être spécifiées dans les fichiers d'options par défaut :

--directory|-d
