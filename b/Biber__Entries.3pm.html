NOM

Biber::Entries - Objets Biber::Entries

new

Initialise un objet Biber::Entries

notnull

Teste si un objet est vide

entry_exists

Valeurs booléennes pour indiquer s'il existe une entrée
pour la clé de citation passée.

entry

Renvoie un objet Biber::Entry pour une clé de citation donnée

entries

Renvoie un tableau de tous les objets Biber::Entry

del_entries

Supprime tous les objets Biber::Entry

add_entry

Ajoute un Biber::Entry à l'objet Biber::Entries

del_entry

Supprime un objet Biber::Entry pour une clé de citation donnée.
Utilisé uniquement dans les tests pour réinitialiser les données avant
la régénération avec différentes options.
