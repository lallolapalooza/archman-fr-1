NOM

BN_security_bits - retourne les bits de sécurité basés sur les nombres donnés

SYNTAXE

#include <openssl/bn.h>
int BN_security_bits(int L, int N);

DESCRIPTION

BN_security_bits() retourne le nombre de bits de sécurité fournis par un algorithme spécifique et une taille de clé particulière. Les bits de sécurité sont définis dans la NIST SP800-57. Actuellement, BN_security_bits() prend en charge deux types d'algorithmes asymétriques : la cryptographie à corps finis (FFC) et la cryptographie par factorisation d'entiers (IFC). Pour les FFC, par exemple DSA et DH, les deux paramètres L et N sont utilisés pour décider des bits de sécurité, où L est la taille de la clé publique et N est la taille de la clé privée. Pour les IFC, par exemple RSA, seul L est utilisé et il est couramment considéré comme la taille de la clé (module).

VALEURS DE RETOUR

Nombre de bits de sécurité.

NOTES

La cryptographie sur courbes elliptiques (ECC) n'est pas couverte par la fonction BN_security_bits(). Les algorithmes symétriques ne sont pas non plus couverts.

VOIR AUSSI

DH_security_bits(3), DSA_security_bits(3), RSA_security_bits(3)

HISTORIQUE

La fonction BN_security_bits() a été ajoutée dans OpenSSL 1.1.0.
