BIO_GET_DATA(3ssl) OpenSSL BIO_GET_DATA(3ssl)

NOM

BIO_set_data, BIO_get_data, BIO_set_init, BIO_get_init, BIO_set_shutdown, BIO_get_shutdown - fonctions pour la gestion des informations d'état BIO

SYNTAXE

#include <openssl/bio.h>
void BIO_set_data(BIO *a, void *ptr);
void *BIO_get_data(BIO *a);
void BIO_set_init(BIO *a, int init);
int BIO_get_init(BIO *a);
void BIO_set_shutdown(BIO *a, int shut);
int BIO_get_shutdown(BIO *a);

DESCRIPTION

Ces fonctions sont principalement utiles lors de l'implémentation d'un BIO personnalisé.

La fonction BIO_set_data() associe les données personnalisées pointées par ptr au BIO. Ces données peuvent ensuite être récupérées via un appel à BIO_get_data(). Ceci peut être utilisé par les BIO personnalisés pour stocker des informations spécifiques à l'implémentation.

La fonction BIO_set_init() définit la valeur du drapeau "init" du BIO pour indiquer si l'initialisation a été terminée pour ce BIO ou non. Une valeur non nulle indique que l'initialisation est terminée, tandis que zéro indique qu'elle ne l'est pas. Souvent, l'initialisation se termine lors de la construction initiale du BIO. Pour certains BIO cependant, l'initialisation peut ne pas se terminer avant que des étapes supplémentaires ne soient effectuées (par exemple, en appelant des contrôles personnalisés). La fonction BIO_get_init() renvoie la valeur du drapeau "init".

Les fonctions BIO_set_shutdown() et BIO_get_shutdown() définissent et récupèrent l'état du drapeau de fermeture (c'est-à-dire BIO_CLOSE) de ce BIO. S'il est défini, la ressource sous-jacente est également fermée lorsque le BIO est libéré.

VALEURS DE RETOUR

BIO_get_data() renvoie un pointeur vers les données personnalisées spécifiques à l'implémentation associées à ce BIO, ou NULL si aucune n'a été définie.

BIO_get_init() renvoie l'état du drapeau d'initialisation du BIO.

BIO_get_shutdown() renvoie l'état du drapeau de fermeture (c'est-à-dire BIO_CLOSE) du BIO.

VOIR AUSSI

bio(7), BIO_meth_new(3)

HISTORIQUE

Les fonctions décrites ici ont été ajoutées dans OpenSSL 1.1.0.
