BIO_printf(3ssl)

Paquet: openssl

Licences: Apache-2.0

BIO_PRINTF(3ssl) OpenSSL BIO_PRINTF(3ssl)

NOM

BIO_printf, BIO_vprintf, BIO_snprintf, BIO_vsnprintf - sortie formatée vers un BIO

SYNTAXE

#include <openssl/bio.h>
int BIO_printf(BIO *bio, const char *format, ...);
int BIO_vprintf(BIO *bio, const char *format, va_list args);
int BIO_snprintf(char *buf, size_t n, const char *format, ...);
int BIO_vsnprintf(char *buf, size_t n, const char *format, va_list args);

DESCRIPTION

BIO_printf() est similaire à la fonction C standard printf(), sauf que la sortie est envoyée au BIO spécifié, bio, plutôt qu'à la sortie standard. Tous les spécificateurs de format courants sont pris en charge.

BIO_vprintf() est similaire à la fonction vprintf() trouvée sur de nombreuses plateformes, la sortie est envoyée au BIO spécifié, bio, plutôt qu'à la sortie standard. Tous les spécificateurs de format courants sont pris en charge. La liste d'arguments args est une liste d'arguments stdarg.

BIO_snprintf() est pour les plateformes qui n'ont pas la fonction courante snprintf(). Elle est comme sprintf() sauf que le paramètre de taille, n, spécifie la taille du tampon de sortie.

BIO_vsnprintf() est à BIO_snprintf() ce que BIO_vprintf() est à BIO_printf().

VALEURS DE RETOUR

Toutes les fonctions renvoient le nombre d'octets écrits, ou -1 en cas d'erreur. Pour BIO_snprintf() et BIO_vsnprintf(), cela inclut le cas où le tampon de sortie est trop petit.

NOTES

Sauf lorsque n est 0, BIO_snprintf() et BIO_vsnprintf() terminent toujours leur sortie par '\0'. Cela inclut les cas où -1 est renvoyé, par exemple lorsqu'il n'y a pas assez d'espace pour sortir toute la chaîne.
