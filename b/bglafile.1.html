NOM

Bglafile - Générateur de fichier d'accès aux modules

SYNTAXE

bglafile [ options ] fichier ...

DESCRIPTION

Bglafile est un générateur de fichier d'accès aux modules. Il produit un fichier qui convient à l'option -afile de Bigloo. Un fichier d'accès aux modules est une liste scheme. Chaque élément de cette liste est une liste d'au moins deux éléments : un nom de module, le fichier qui implémente ce module. Pour que BEE (l'environnement de développement intégré de Bigloo) puisse récupérer des fichiers à partir des noms de modules, il est obligatoire que la première parenthèse de la liste globale soit laissée seule sur une ligne.

OPTIONS

fichier
Est un fichier implémentant un module. Bglafile lit ce fichier pour découvrir le nom du module implémenté.
-v
Mode verbeux.
-o <fichier>
Imprime le fichier d'accès aux modules dans fichier. Par défaut, la liste est imprimée sur la sortie standard.
-suffixe <suf>
Ajoute suf à la liste des suffixes de fichiers source de bglafile. Les suffixes par défaut sont "scm", "sch" et "bgl".

EXEMPLE

Si les trois fichiers existent et contiennent une clause de module Bigloo valide, alors :


$ bglafile foo.scm bar.scm gee.scm

pourrait imprimer une liste comme :

;; foo

;; Mar 15 Aoû 12:17:24 1998

(


(foo "foo.scm")


(bar "bar.scm")


(gee "gee.scm")

)
