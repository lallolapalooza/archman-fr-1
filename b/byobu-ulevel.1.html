NOM

byobu-ulevel - script d'aide pour les indicateurs de niveau de notification

DESCRIPTION

byobu-ulevel est un script d'aide qui peut être utilisé pour créer des graphiques d'historique avec des caractères UTF8

UTILISATION

byobu-ulevel [options] -c <num_courant>

byobu-ulevel [options] <num_courant>

byobu-ulevel <num_courant>

OPTIONS


-a : Mode accessibilité : ne produire que de l'ASCII. (Activé également si la variable '$a11y_variable' est définie).
-b : Afficher la valeur courante comme un espace si elle est nulle, plutôt que la valeur la plus basse du thème.
-c <num> : Valeur courante de votre indicateur.
-d : Activer la sortie de débogage.
-e <int> : Nombre de décimales à utiliser pour le mode accessibilité (par défaut=$default_decimal_places).
-h : Afficher cette aide.
-i : Inverser le schéma de couleurs (uniquement pour les thèmes de notation).
-l : Lister les thèmes disponibles. Si '-t' est également spécifié, afficher toutes les valeurs pour le thème spécifié.
-m <num> : Valeur minimale (par défaut=$min_default).
-n : Supprimer la sortie du caractère de nouvelle ligne.
-p : Mode permissif - si la valeur courante est hors limites, la définir à la limite la plus proche (min ou max).
-q : Supprimer les messages (nécessite '-t').
-r : Inverser le sens d'affichage (uniquement pour les thèmes de notation).
-t <thème> : Nom du thème (par défaut=$theme_default).
-u <caractères> : Spécifier un thème utilisateur (2 valeurs ou plus).
-w <int> : Largeur du thème de notation (par défaut=$width_default).
-x <num> : Valeur maximale (par défaut=$max_default).

EXEMPLES

Afficher le caractère représentant 27 % en utilisant le thème par défaut.
byobu-ulevel 27

Comme ci-dessus.
byobu-ulevel -c 27

Exemple montrant les valeurs flottantes et négatives.
byobu-ulevel -c 1.100001 -m -5.00234 -x 2.71828 -t dice_6

Utiliser le mode accessibilité pour afficher une valeur en pourcentage (arrondie au pourcentage le plus proche)
byobu-ulevel -m -22.613 -x 5.00212 -c 0.10203 -a -e 0

Afficher la valeur en utilisant un « thème de notation » (affiché de gauche à droite).
byobu-ulevel -c 83 -t stars_2

Afficher un « thème de notation » inversé, de droite à gauche.
byobu-ulevel -c 60 -t diamonds_2 -ri

Afficher tous les glyphes dans le thème « solid_numbers_a_10 ».
byobu-ulevel -l -t solid_numbers_a_10

Afficher un thème de notation spécifié par l'utilisateur, large de 10 glyphes.
byobu-ulevel -c 666.321 -m -273.15 -x 1370 -u "· ☢" -w 10

Un thème utilisateur multi-éléments (ceci imprime 'e').
byobu-ulevel -c 50 -u "a b c d e f g h i j"

NOTES

Les arguments de type « <int> » désignent une valeur entière, tandis que les arguments de type « <num> » désignent un nombre entier ou flottant.

Le suffixe « _<nombre> » dans un nom de thème désigne le nombre de glyphes qu'il contient.

Les « thèmes de notation » sont ceux qui n'ont que 2 valeurs.

L'argument <caractères> de l'option '-u' doit contenir des caractères séparés par des espaces.
