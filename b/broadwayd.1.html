BROADWAYD(1) Commandes utilisateur BROADWAYD(1)

NOM

broadwayd - Serveur d'affichage Broadway

SYNTAXE

broadwayd [--port PORT] [--address ADRESSE] [--unixsocket ADRESSE] [:AFFICHAGE]

DESCRIPTION

broadwayd est un serveur d'affichage pour le backend GDK Broadway. Il permet à plusieurs applications GTK+ d'afficher leurs fenêtres dans le même navigateur Web, en se connectant à broadwayd.

Lors de l'utilisation de broadwayd, spécifiez le numéro d'affichage à utiliser, précédé de deux points, comme pour X. Le numéro d'affichage par défaut est 0.

broadwayd :5

Puis pointez votre navigateur Web sur http://127.0.0.1:8085. Lancez vos applications comme ceci :

GDK_BACKEND=broadway BROADWAY_DISPLAY=:5 gtk3-demo

Vous pouvez ajouter une protection par mot de passe pour votre session en créant un fichier dans $XDG_CONFIG_HOME/broadway.passwd ou $HOME/.config/broadway.passwd avec un hachage de mot de passe de type crypt(3). Une manière simple de le générer est avec openssl :

openssl passwd -1  > ~/.config/broadway.passwd

OPTIONS

--port

Utilisez PORT comme port HTTP, au lieu du défaut 8080 + (AFFICHAGE - 1).

--address

Utilisez ADRESSE comme adresse HTTP, au lieu du défaut http://127.0.0.1:PORT.

--unixsocket

Utilisez ADRESSE comme adresse de socket de domaine Unix. Cette option remplace --address et --port. Elle n'est disponible que sur les systèmes de type Unix.
