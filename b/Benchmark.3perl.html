timethis ( COUNT, CODE, [ TITLE, [ STYLE ]
] )
Chronomètre COUNT itérations de CODE. CODE peut être une chaîne à évaluer ou une référence à du code ; dans les deux cas, le CODE sera exécuté dans le paquet de l'appelant. Les résultats seront imprimés sur STDOUT avec TITLE suivi des temps. TITLE vaut par défaut "timethis COUNT" si aucune valeur n'est fournie. STYLE détermine le format de la sortie, comme décrit pour timestr() ci-dessous.

COUNT peut être nul ou négatif : cela signifie le minimum de secondes CPU à exécuter. Zéro signifie la valeur par défaut de 3 secondes. Par exemple, pour exécuter au moins 10

secondes : 
timethis(-10,
$code);

ou pour exécuter deux tests de code pendant au moins 3

secondes : 
timethese(0, { test1 => '...', test2 => '...
'});

Les secondes CPU sont, en termes UNIX, le temps utilisateur plus le temps système du processus lui-même, par opposition au temps réel (horloge murale) et au temps passé par les processus enfants. Moins de 0,1 seconde n'est pas accepté (-0,01 comme count, par exemple, provoquera une exception d'exécution

fatale).

Notez que les secondes CPU sont le temps minimum : l'ordonnancement du CPU et d'autres facteurs du système d'exploitation peuvent compliquer la tentative de sorte qu'un peu plus de temps soit passé. La sortie du benchmark indiquera cependant également le nombre de $code exécutions/seconde, ce qui devrait être un nombre plus intéressant que les secondes réellement

passées.
