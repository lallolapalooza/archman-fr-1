NOM

buf-lint - Exécuter le linting sur les fichiers Protobuf

SYNTAXE

buf lint [indicateurs]

DESCRIPTION

Le premier argument est la source, le module ou l'image à analyser, qui doit être l'un des formats suivants : [binpb,dir,git,json,mod,protofile,tar,txtpb,yaml,zip]. Par défaut, c'est "." si aucun argument n'est spécifié.

OPTIONS

--config="" Le fichier buf.yaml ou les données à utiliser pour la configuration

--disable-symlinks[=false] Ne pas suivre les liens symboliques lors de la lecture des sources ou de la configuration à partir du système de fichiers local. Par défaut, les liens symboliques sont suivis dans cette CLI, mais jamais suivis sur le registre de schémas Buf.

--error-format="text" Le format des erreurs de compilation ou des violations de vérification imprimées sur la sortie standard. Doit être l'un des éléments suivants : [text,json,msvs,junit,github-actions,gitlab-code-quality,config-ignore-yaml]

--exclude-path=[] Exclure des fichiers ou répertoires spécifiques, par exemple "proto/a/a.proto", "proto/a". Si spécifié plusieurs fois, l'union est prise.

-h, --help[=false] Aide pour lint

--path=[] Limiter à des fichiers ou répertoires spécifiques, par exemple "proto/a/a.proto", "proto/a". Si spécifié plusieurs fois, l'union est prise.

OPTIONS INHERITÉS DES COMMANDES PARENT

--debug[=false] Activer la journalisation de débogage

--log-format="color" Le format du journal [text,color,json]

--timeout=0s La durée jusqu'à l'expiration, la définir à 0 signifie pas d'expiration
