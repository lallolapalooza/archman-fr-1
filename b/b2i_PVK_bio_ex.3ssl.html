b2i_PVK_bio_ex(3ssl)

Paquet: openssl

Licences: Apache-2.0

B2I_PVK_BIO(3ssl) OpenSSL B2I_PVK_BIO(3ssl)

NOM

b2i_PVK_bio, b2i_PVK_bio_ex, i2b_PVK_bio, i2b_PVK_bio_ex - Fonctions de décodage et d'encodage pour la lecture et l'écriture de clés privées au format MSBLOB

SYNTAXIS

#include <openssl/pem.h>
EVP_PKEY *b2i_PVK_bio(BIO *in, pem_password_cb *cb, void *u);
EVP_PKEY *b2i_PVK_bio_ex(BIO *in, pem_password_cb *cb, void *u,
                         OSSL_LIB_CTX *libctx, const char *propq);
int i2b_PVK_bio(BIO *out, const EVP_PKEY *pk, int enclevel,
                pem_password_cb *cb, void *u);
int i2b_PVK_bio_ex(BIO *out, const EVP_PKEY *pk, int enclevel,
                   pem_password_cb *cb, void *u,
                   OSSL_LIB_CTX *libctx, const char *propq);

DESCRIPTION

b2i_PVK_bio_ex() décode une clé privée au format MSBLOB lue depuis un BIO. Elle tente de déterminer automatiquement le type de clé. Si la clé est chiffrée, cb est appelée avec les données utilisateur u afin d'obtenir un mot de passe pour déchiffrer la clé. Le contexte de bibliothèque libctx et la chaîne de requête de propriétés propq fournis sont utilisés dans toute opération de déchiffrement.

b2i_PVK_bio() fait la même chose que b2i_PVK_bio_ex(), à l'exception près que le contexte de bibliothèque et la chaîne de requête de propriétés par défaut sont utilisés.

i2b_PVK_bio_ex() encode pk en utilisant le format MSBLOB. Si enclevel est 1, un mot de passe obtenu via pem_password_cb est utilisé pour chiffrer la clé privée. Si enclevel est 0, aucun chiffrement n'est appliqué. Les données utilisateur dans u sont passées à la fonction de rappel du mot de passe. Le contexte de bibliothèque libctx et la chaîne de requête de propriétés propq fournis sont utilisés dans toute opération de déchiffrement.

i2b_PVK_bio() fait la même chose que i2b_PVK_bio_ex(), à l'exception près que le contexte de bibliothèque et la chaîne de requête de propriétés par défaut sont utilisés.

VALEURS DE RETOUR

Les fonctions b2i_PVK_bio() et b2i_PVK_bio_ex() retournent une structure EVP_KEY valide ou NULL si une erreur survient. Le code d'erreur peut être obtenu en appelant ERR_get_error(3).

i2b_PVK_bio() et i2b_PVK_bio_ex() retournent le nombre d'octets encodés avec succès ou une valeur négative si une erreur survient. Le code d'erreur peut être obtenu en appelant ERR_get_error(3).

VOIR AUSSI

crypto(7), d2i_PKCS8PrivateKey_bio(3)

HISTORIQUE

b2i_PVK_bio_ex() et i2b_PVK_bio_ex() ont été ajoutées dans OpenSSL 3.0.
