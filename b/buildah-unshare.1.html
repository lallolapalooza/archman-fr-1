NOM

buildah-unshare - Exécute une commande à l'intérieur d'un espace de noms utilisateur modifié.

SYNOPSIS

buildah unshare [options] [--] [commande]

DESCRIPTION

Lance un processus (par défaut, $SHELL) dans un nouvel espace de noms utilisateur. L'espace de noms utilisateur est configuré de telle sorte que l'UID et le GID principal de l'utilisateur appelant apparaissent comme UID 0 et GID 0, respectivement. Toutes les plages qui correspondent à cet utilisateur et à ce groupe dans /etc/subuid et /etc/subgid sont également mappées comme elles-mêmes avec l'aide des utilitaires newuidmap(1) et newgidmap(1).

buildah unshare est utile pour le dépannage des opérations non privilégiées et pour effacer manuellement les données de stockage et autres données relatives aux images et aux conteneurs.

Il est également utile si vous souhaitez utiliser la commande buildah mount. Si un utilisateur non privilégié souhaite monter et travailler avec un conteneur, il doit exécuter buildah unshare. L'exécution de buildah mount échoue pour les utilisateurs non privilégiés à moins que l'utilisateur ne s'exécute dans une session buildah unshare.

OPTIONS

--mount, -m [VARIABLE=]nomOuIDConteneur

Monte le conteneur nomOuIDConteneur tout en exécutant la commande, et définit la variable d'environnement VARIABLE sur le chemin du point de montage. Si VARIABLE n'est pas spécifiée, elle prend par défaut la valeur nomOuIDConteneur, ce qui peut ne pas être un nom valide pour une variable d'environnement.

EXEMPLE

buildah unshare id

buildah unshare pwd

buildah unshare cat /proc/self/uid_map /proc/self/gid_map

buildah unshare rm -fr $HOME/.local/share/containers/storage /run/user/`id -u`/run

buildah unshare --mount containerID sh -c 'cat ${containerID}/etc/os-release'

buildah unshare --mount root=containerID sh -c 'cat ${root}/etc/os-release'

Si vous souhaitez utiliser buildah avec une commande 'mount', vous pouvez créer un script ressemblant à ceci :

cat > buildah-script.sh << _EOF
#!/bin/bash
ctr=$(buildah from scratch)
mnt=$(buildah mount $ctr)
dnf -y install --installroot=$mnt --use-host-config --setopt "*.countme=false" PACKAGES
dnf -y clean all --installroot=$mnt
buildah config --entrypoint="/bin/PACKAGE" --env "FOO=BAR" $ctr
buildah commit $ctr imagename
buildah unmount $ctr
_EOF
chmod +x buildah-script.sh

Puis exécutez-le avec :

buildah unshare ./buildah-script.sh
