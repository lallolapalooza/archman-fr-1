Biber__Output__base(3pm)

Paquet: biber

Licences: Artistic-2.0

Biber::Output::base(3pm) Documentation Perl fournie par les contributeurs Biber::Output::base(3pm)

NOM

Biber::Output::base - classe de base pour les modules de sortie de Biber.

new

Initialise un objet Biber::Output::base

set_output_target_file

Définit le fichier cible de sortie d'un objet Biber::Output::base
Une commodité pour set_output_target afin de pouvoir conserver une trace du
nom de fichier. Retourne un objet IO::File pour la cible.

get_output_target_file

Obtenir le nom du fichier cible de sortie

set_output_target

Définit la cible de sortie d'un objet Biber::Output::base

set_output_head

Définit l'en-tête de sortie d'un objet Biber::Output::base
$data peut être n'importe quoi - l'appelant est censé savoir.

set_output_tail

Définit la queue de sortie d'un objet Biber::Output::base
$data peut être n'importe quoi - l'appelant est censé savoir.

get_output_head

Obtenir l'en-tête de sortie d'un objet Biber::Output
$data peut être n'importe quoi - l'appelant est censé savoir.
Principalement utilisé pour le débogage.

get_output_tail

Obtenir la queue de sortie d'un objet Biber::Output
$data peut être n'importe quoi - l'appelant est censé savoir.
Principalement utilisé pour le débogage.

add_output_head

Ajouter aux données de sortie de l'en-tête d'un objet Biber::Output::base
La méthode de base ne fait qu'une concaténation de chaînes.

add_output_tail

Ajouter aux données de sortie de la queue d'un objet Biber::Output::base
La méthode de base ne fait qu'une concaténation de chaînes.

set_output_section

Enregistre l'objet section dans l'objet de sortie
Nous avons besoin de certaines informations de celui-ci lors de l'écriture de la sortie.

get_output_section

Récupérer l'objet section de sortie.

get_output_entries

Obtenir les données de sortie triées pour toutes les entrées d'une liste sous forme de tableau référence
Utilisé vraiment seulement dans les tests car il instancie les informations dynamiques de la liste afin
que nous puissions les voir dans les tests. Par conséquent, nous devons appeler NFC() sur le résultat pour imiter
la sortie réelle, car la sortie UTF-8 est supposée dans la plupart des tests.

get_output_macros

Obtenir les macros de sortie pour les tests en mode outil.

get_output_comments

Obtenir les commentaires de sortie pour les tests en mode outil.

clear_output_macros

Effacer les macros de sortie.

clear_output_comments

Effacer les commentaires de sortie.

get_output_entry

Obtenir les données de sortie pour une entrée spécifique.
Utilisé vraiment seulement dans les tests car il instancie les informations dynamiques de la liste afin
que nous puissions les voir dans les tests. Par conséquent, nous devons appeler NFC() sur le résultat pour imiter
la sortie réelle, car la sortie UTF-8 est supposée dans la plupart des tests.

set_output_entry

Ajouter une sortie d'entrée à un objet Biber::Output::base
La méthode de base ne fait qu'une décharge.

create_output_misc

Crée la sortie pour divers éléments tels que le préambule et l'appel de macro de clôture
et l'ajoute à l'objet de sortie.

create_output_section

Crée la sortie à partir des données des sections et la pousse dans
l'objet de sortie.

set_output_keyalias

Définit la sortie pour une clé qui est un alias d'une autre clé.

set_output_undefkey

Définit la sortie pour une clé non définie.

output

Méthode de sortie de base générique.
