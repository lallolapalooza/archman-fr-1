n

Définir/Obtenir la durée de la

publicité.

Le paramètre Duration configure la longueur d'une

Instance.

La valeur est en

secondes.

Une valeur de 0 indique qu'une valeur par défaut est choisie pour la

Duration.

La valeur par défaut est de 2

secondes.

Si une seule Instance de publicité a été ajoutée, la valeur Duration sera

ignorée.

Si plusieurs Instances de publicité ont été ajoutées, la valeur Duration sera utilisée pour déterminer la durée pendant laquelle chaque Instance est

diffusée.

La valeur Duration est utilisée pour calculer le nombre d'événements de publicité qui seront utilisés pour diffuser chaque

Instance.

Le nombre d'événements de publicité est calculé en divisant la valeur Duration par l'intervalle de

publicité.

L'intervalle de publicité est déterminé par les paramètres de publicité qui sont définis pour chaque Instance. L'intervalle de publicitérval est le maximum des intervalles de publicité définis pour chaque

Instance.
