br2684ctl(8) Manuel du gestionnaire système br2684ctl(8)

NOM

br2684ctl - Démon de pontage RFC1483/2684

SYNTAXE

br2684ctl [ -b ] [[ -c n ] [ -e 0|1 ] [ -p 0|1 ] [ -s sndbuf ] [ -a [itf].vpi.vci ]] ...

PARAMÈTRES

-a [itf].vpi.vci
Numéro de PVC ATM, VPI et VCI. (Requis)
-b
Met le processus en arrière-plan.
-c n
Numéro d'interface br2684 comme 0, 1, ... (Requis)
-e 0|1
Méthode d'encapsulation : 0=LLC, 1=VC mux (la valeur par défaut est 0 ou LLC)
-p 0|1
Méthode de charge utile : 0=Routé, 1=Ponté (la valeur par défaut est 1 ou Ponté)
-s sndbuf
Taille du tampon d'envoi. La valeur par défaut est 8192.

DESCRIPTION

br2684ctl gère les paquets PDUs pontés RFC1483/2684. Ceci est le plus souvent utilisé dans les scénarios ADSL où *habituellement* le trafic Ethernet des abonnés est encapsulé en ATM AAL5 (en pontant les modems ADSL) conformément à la RFC2684. Le modem ADSL côté abonné peut être externe avec un connecteur Ethernet ou une carte ADSL interne dans un PC. La RFC1483 a été obsolète par la RFC2684.

Par exemple, il est possible de configurer votre système Linux pour gérer plusieurs PVC ATM avec un pontage 1483 (parfois appelé SNAP) d'encapsulation. La pile réseau Linux peut fournir des services DHCP, de mascarade IP, de pare-feu IP, ou ponté les trames Ethernet comme si elle avait plusieurs interfaces Ethernet. En fait, elle peut avoir plusieurs interfaces Ethernet (logiques), où l'ATM est juste utilisé comme support.

UTILISATION

br2684ctl crée une nouvelle interface réseau nommée nas[n] qui est liée à un PVC ATM spécifique. Il requiert deux arguments obligatoires : -c, le numéro d'interface, et -a, le PVC ATM. Il convient de noter que l'ordre des arguments de la commande est important ; -c doit être suivi de -a. Vous pouvez créer autant d'interfaces que nécessaire en une seule fois, il suffit de faire une longue ligne de commande ;)

Par exemple, la commande suivante créera une interface nas0 qui utilise le PVC ATM avec VPI=0 et VCI=401. Vous devez configurer manuellement la connexion PVC 0.401 sur le commutateur ATM.

% br2684ctl -c 0 -a 0.401

La commande ne créera qu'une nouvelle interface nas0. La prochaine étape consiste à attribuer une adresse IP et un masque de réseau à l'interface nas0 en utilisant la commande ifconfig. En utilisant ifconfig, vous pouvez également attribuer une adresse MAC Ethernet à l'interface nas0, si nécessaire.

% ifconfig nas0 192.168.2.1 netmask 255.255.255.0

Les messages sont enregistrés dans la facilité syslog LOCAL2.

FICHIERS

/var/run/br2684ctl-<iface>.pid
