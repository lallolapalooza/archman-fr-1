NOM

byobu-ugraph - script d'aide pour les graphiques d'historique de notifications

DESCRIPTION

byobu-ugraph est un script d'aide qui peut être utilisé pour créer des graphiques d'historique.

UTILISATION

byobu-ugraph [options] [commande [arguments...]]

OPTIONS


-f <fichier> : Fichier à partir duquel lire les points de données. (uniquement requis si aucune commande n'est spécifiée).
-h : Afficher cette aide.
-m <nombre> : Valeur minimale (défaut=$min_default).
-n : Supprimer le caractère de nouvelle ligne.
-p <points> : Spécifier le nombre de points de données dans le graphique (défaut=$points_default).
-r : Ne pas faire pivoter le fichier <fichier> (par défaut, il pivote). L'option implique que le fichier <fichier> ne doit pas être écrit, donc aucune commande ne peut suivre les options du script dans ce cas.
-t <thème> : Thème 'byobu-ulevel' à utiliser (défaut=$theme_default).
-x <nombre> : Valeur maximale (défaut=$max_default).

EXEMPLES

Utilisation de byobu-ugraph pour exécuter une commande, faire pivoter le journal et afficher le graphique.

Ici, nous spécifions une commande pour afficher la mémoire disponible. Le `echo` final ajoute une nouvelle ligne requise. Notez qu'aucun nom de fichier n'est spécifié.


byobu-ugraph "(/usr/lib/byobu/mem_used | sed -e 's/% //g';echo)"

Utilisation de byobu-ugraph juste pour faire pivoter le journal et afficher le graphique


fichier=/tmp/load.dat
awk '{ print $1}' /proc/loadavg >> $fichier
# Note : nous devons spécifier ce que nous considérons comme une charge maximale "raisonnable"
byobu-ugraph -m 3.0 -f $fichier

NOTES

Si vous spécifiez 'commande', des précautions doivent être prises avec les guillemets du shell pour éviter l'expansion avant que ce script n'exécute la commande.

Si '-r' n'est pas spécifié, le fichier <fichier> sera pivoté de manière à ce qu'au maximum <points> lignes soient conservées à chaque invocation de ce script.
