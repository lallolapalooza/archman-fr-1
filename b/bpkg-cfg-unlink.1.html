DESCRIPTIO

N

La commande cfg-unlink délie la configuration bpkg spécifiée de la configuration courante (la première forme) ou supprime les rétroliens implicites orphelins (la deuxième forme). Voir bpkg-cfg-create(1) pour des informations de contexte sur les configurations

liées.

Dans la première forme, la configuration à délier peut être spécifiée soit comme répertoire de configuration (dir), nom (--name), id (--id), ou UUID (--uu

id
).

FICHIERS D'OPTIONS PAR

DÉFAUT

Voir bpkg-default-options-files(1) pour un aperçu des fichiers d'options par défaut. Pour la commande cfg-unlink, le répertoire de départ de la recherche est le répertoire de configuration. Les fichiers d'options suivants sont recherchés dans chaque répertoire et, s'ils sont trouvés, chargés dans l'ordre indiqué

: 
bpkg.options
bpkg-cfg-unlink.
options
