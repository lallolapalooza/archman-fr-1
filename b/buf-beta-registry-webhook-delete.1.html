buf-beta-registry-webhook-delete - Supprimer un webhook de dépôt

SYNTAXE

buf beta registry webhook delete [options]

DESCRIPTION

Supprimer un webhook de dépôt

OPTIONS

-h, --help[=false] aide pour delete

--id="" L'identifiant du webhook à supprimer

--remote="" Le dépôt distant auquel appartient l'identifiant du webhook

OPTIONS HÉRITÉES DES COMMANDES PARENTES

--debug[=false] Activer la journalisation de débogage

--log-format="color" Le format du journal [text,color,json]

--timeout=0s La durée jusqu'à l'expiration, régler à 0 signifie aucune expiration
