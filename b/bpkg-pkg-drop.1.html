NOM

bpkg-pkg-drop - supprimer un paquet

SYNOPSIS

bpkg pkg-drop|drop [options] <paquet>...
bpkg pkg-drop|drop [options] --all|-a
bpkg pkg-drop|drop [options] (--all-pattern <motif>)...

DESCRIPTION

La commande pkg-drop supprime de la configuration les paquets spécifiés (la première forme), tous les paquets maintenus (la seconde forme, voir bpkg-pkg-status(1)), ou tous les paquets maintenus correspondant à l'un des motifs génériques spécifiés (la troisième forme). Si les paquets supprimés ont encore des paquets dépendants, ceux-ci devront également être supprimés et une confirmation vous sera demandée. Et si les paquets supprimés ont des paquets dépendants qui ne seraient plus utilisés autrement, ils seront également supprimés, sauf si l'option --keep-unused|-K est spécifiée.

La commande pkg-drop prend également en charge plusieurs options (décrites ci-dessous) qui vous permettent de contrôler l'étendue du travail à effectuer.

OPTIONS PKG-DROP

--all|-a
Supprimer tous les paquets maintenus.
--all-pattern motif
Supprimer les paquets maintenus correspondant au motif générique spécifié. Répétez cette option pour correspondre à plusieurs motifs. Notez que vous devrez peut-être mettre le motif entre guillemets pour empêcher son expansion par votre shell.
--yes|-y
Supposer que la réponse à toutes les invitations est oui. Notez que cette option ne s'applique pas à la suppression des dépendants ; utilisez --drop-dependent pour cela.
--no|-n
Supposer que la réponse à toutes les invitations est non. N'a de sens qu'en combinaison avec --print-only|-p.
--keep-unused|-K
Ne pas supprimer les paquets dépendants qui ont été construits automatiquement mais ne seront plus utilisés.
--drop-dependent|-D
Ne pas avertir ni demander de confirmation lors de la suppression de paquets dépendants.
--keep-dependent
Émettre une erreur si l'on tente de supprimer des paquets dépendants.
--dependent-exit code
Quitter silencieusement avec le code d'erreur spécifié si l'on tente de supprimer des paquets dépendants.
--disfigure-only
Désconfigurer tous les paquets mais ne pas purger.
--print-only|-p
Afficher sur stdout ce qui serait fait sans rien faire réellement.
--plan en-tête
Afficher le plan (même si --yes est spécifié) et le commencer par la ligne en-tête (sauf si elle est vide).
--directory|-d rép
Supposer que la configuration se trouve dans rép plutôt que dans le répertoire de travail courant.

FICHIERS D'OPTIONS PAR DÉFAUT

Voir bpkg-default-options-files(1) pour un aperçu des fichiers d'options par défaut. Pour la commande pkg-drop , le répertoire de départ de la recherche est le répertoire de configuration. Les fichiers d'options suivants sont recherchés dans chaque répertoire et, s'ils sont trouvés, chargés dans l'ordre indiqué :

bpkg.options
bpkg-pkg-drop.options

Les options de commande pkg-drop suivantes ne peuvent pas être spécifiées dans les fichiers d'options par défaut :

--directory|-d
