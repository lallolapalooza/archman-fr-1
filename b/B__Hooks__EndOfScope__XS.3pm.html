B::Hooks::EndOfScope::XS(3) Documentation Perl fournie par l'utilisateur B::Hooks::EndOfScope::XS(3)

NOM

B::Hooks::EndOfScope::XS - Exécute du code après la compilation d'une portée - Implémentation XS

VERSION

version 0.28

DESCRIPTION

Ceci est l'implémentation de B::Hooks::EndOfScope basée sur Variable::Magic, qui est un module XS dépendant d'un compilateur. Il sera toujours automatiquement préféré si Variable::Magic est disponible.

FONCTIONS

on_scope_end

on_scope_end { ... };
on_scope_end $code;

Enregistre $code pour être exécuté après que la portée environnante ait été compilée.

Ceci est exporté par défaut. Voir Sub::Exporter sur comment le personnaliser.
