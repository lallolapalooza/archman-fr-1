BIO_FIND_TYPE(3ssl) OpenSSL BIO_FIND_TYPE(3ssl)

NOM

BIO_find_type, BIO_next, BIO_method_type - Parcours de chaînes BIO

SYNTAXE

#include <openssl/bio.h>
BIO *BIO_find_type(BIO *b, int bio_type);
BIO *BIO_next(BIO *b);
int BIO_method_type(const BIO *b);

DESCRIPTION

BIO_find_type() recherche un BIO d'un type donné dans une chaîne, en commençant par le BIO b. Si bio_type est un type spécifique (comme BIO_TYPE_MEM), une recherche est effectuée pour un BIO de ce type. Si bio_type est un type général (comme BIO_TYPE_SOURCE_SINK), le prochain BIO correspondant du type général donné est recherché. BIO_find_type() retourne le prochain BIO correspondant ou NULL si aucun n'est trouvé. Si bio_type est BIO_TYPE_NONE, il ne trouvera aucune correspondance.

Les types généraux suivants sont définis : BIO_TYPE_DESCRIPTOR, BIO_TYPE_FILTER, et BIO_TYPE_SOURCE_SINK.

Pour une liste des types spécifiques, voir le fichier d'en-tête <openssl/bio.h>.

BIO_next() retourne le BIO suivant dans une chaîne. Il peut être utilisé pour parcourir tous les BIOs d'une chaîne ou utilisé en conjonction avec BIO_find_type() pour trouver tous les BIOs d'un certain type.

BIO_method_type() retourne le type d'un BIO.

VALEURS DE RETOUR

BIO_find_type() retourne un BIO correspondant ou NULL en cas de non-correspondance.

BIO_next() retourne le BIO suivant dans une chaîne.

BIO_method_type() retourne le type du BIO b.

EXEMPLES

Parcourir une chaîne à la recherche de BIOs de hachage :

BIO *btmp;
btmp = in_bio; /* in_bio est la chaîne à parcourir */
do {
    btmp = BIO_find_type(btmp, BIO_TYPE_MD);
    if (btmp == NULL)
        break; /* Non trouvé */
    /* btmp est un BIO de hachage, faites quelque chose avec ...*/
    ...
    btmp = BIO_next(btmp);
} while (btmp);
