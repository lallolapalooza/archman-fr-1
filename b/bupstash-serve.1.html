bupstash-serve(1)

Paquet: bupstash

Licences: MIT

() ()

SYNTAXE

Sert le protocole bupstash sur stdin/stdout.

bupstash serve [OPTIONS] REPOSITORY

DESCRIPTION

bupstash serve sert le protocole bupstash sur stdin/stdout, permettant l'interaction avec un dépôt. La plupart des commandes bupstash fonctionnent via une instance de bupstash serve.

La commande serve a des options qui peuvent être définies pour restreindre les permissions d'accès. Par défaut, tout accès est autorisé jusqu'à ce que la première option --allow-* soit fournie. Ces options peuvent être imposées via un fichier de clés autorisées ssh, ou par des mécanismes tels que la configuration de sudo ou doas.

Les clients ayant la permission de lire des données peuvent quand même ne pas être en mesure de les déchiffrer s'ils n'ont pas la clé de déchiffrement correcte côté client.

Notez que de nombreuses erreurs sont imprimées hors bande via stderr, donc les transports alternatifs devraient considérer comment acheminer également les données stderr.

OPTIONS

--allow-init
Autorise le client à initialiser de nouveaux dépôts.
--allow-put
Autorise le client à ajouter d'autres éléments au dépôt.
--allow-list
Autorise le client à récupérer les métadonnées et les index de snapshots pour la recherche et le listage.
--allow-get
Autorise le client à récupérer des données du dépôt, implique --allow-list.
--allow-remove
Autorise le client à supprimer des éléments du dépôt, implique --allow-list.
--allow-gc
Autorise le client à exécuter le garbage collector du dépôt.
--allow-sync
Autorise le client à synchroniser des éléments dans le dépôt, c'est-à-dire à être la destination d'une synchronisation de dépôt.

EXEMPLES

Options ssh personnalisées utilisant BUPSTASH_REPOSITORY_COMMAND

$ export BUPSTASH_REPOSITORY_COMMAND="ssh -p 2020 $SERVER bupstash serve /data/repository" $ bupstash list

Configuration des contrôles d'accès SSH

Créez un utilisateur ´backups´ sur votre serveur.

Dans votre fichier de configuration sshd sur votre serveur, ajoutez la ligne :

Match User backups ForceCommand "/bin/bupstash-put-force-command.sh"

Créez /bin/bupstash-put-force-command.sh sur votre serveur :

$ echo ´exec bupstash serve --allow-put /home/backups/bupstash-backups´ > bupstash-put-force-command.sh $ sudo cp bupstash-put-force-command.sh /bin/bupstash-put-force-command.sh $ sudo chown root:root /bin/bupstash-put-force-command.sh $ sudo chmod +x /bin/bupstash-put-force-command.sh

Maintenant, tout client ayant un accès ssh à l'utilisateur ´backups´ ne pourra qu'ajouter de nouvelles sauvegardes à un seul dépôt :

$ export BUPSTASH_REPOSITORY="ssh://backups@$SERVER" $ bupstash put ./data d1659c3f56f744c7767fc57da003ee5d $ bupstash list server a désactivé la requête et la recherche pour ce client

Se connecter au serveur par d'autres moyens permettra un accès complet au dépôt de sauvegardes. Différentes permissions peuvent être configurées en utilisant des concepts similaires, associés à différentes configurations et clés ssh.
