NOM

borg-extract - Extraire le contenu d'une archive

SYNTAXE

borg [options communes] extract [options] ARCHIVE [CHEMIN...]

DESCRIPTION

Cette commande extrait le contenu d'une archive.

Par défaut, l'archive entière est extraite, mais un sous-ensemble de fichiers et de répertoires peut être sélectionné en passant une liste d'arguments CHEMIN. L'interprétation par défaut pour les chemins à extraire est pp: (préfixe littéral). Si vous souhaitez utiliser par exemple un caractère générique, vous devez sélectionner un autre style de motif tel que sh: ou fm:. Voir borg_patterns pour plus d'informations.

La sélection de fichiers peut être restreinte davantage en utilisant l'option --exclude. Pour plus d'aide sur les motifs d'inclusion/exclusion, voir la sortie de la commande borg_patterns.

En utilisant --dry-run, vous pouvez effectuer toutes les étapes d'extraction sauf l'écriture effective des données de sortie : lecture des métadonnées et des morceaux de données du dépôt, vérification du hachage/HMAC, déchiffrement et décompression.

--progress peut être plus lent qu'aucun affichage de progression, car il effectue un passage supplémentaire sur les métadonnées de l'archive.

NOTE :

Actuellement, l'extraction écrit toujours dans le répertoire de travail courant ("."), assurez-vous donc de vous placer dans le bon répertoire avant d'appeler borg extract.

Lorsque les répertoires parents ne sont pas extraits (en raison de la sélection de fichiers/répertoires ou pour toute autre raison), Borg ne peut pas restaurer les métadonnées des répertoires parents, par exemple le propriétaire, le groupe, les permissions, etc.

OPTIONS

Voir borg-common(1) pour les options communes des commandes Borg.

arguments

ARCHIVE
archive à extraire
CHEMIN
chemins à extraire ; les motifs sont supportés

options

--list
afficher une liste détaillée des éléments (fichiers, répertoires, ...)
-n, --dry-run
ne modifier aucun fichier en réalité
--numeric-owner
obsolète, utiliser --numeric-ids à la place
--numeric-ids
ne tenir compte que des identifiants numériques d'utilisateur et de groupe
--nobsdflags
obsolète, utiliser --noflags à la place
--noflags
ne pas extraire/définir les drapeaux (par ex. NODUMP, IMMUTABLE)
--noacls
ne pas extraire/définir les ACLs
--noxattrs
ne pas extraire/définir les xattrs
--stdout
écrire toutes les données extraites sur stdout
--sparse
créer des trous dans le fichier de sortie sparse à partir des blocs entièrement à zéro

options d'inclusion/exclusion

-e MOTIF, --exclude MOTIF
exclure les chemins correspondant au MOTIF
--exclude-from FICHIEREXCLUSION
lire les motifs d'exclusion depuis FICHIEREXCLUSION, un par ligne
--pattern MOTIF
inclure/exclure les chemins correspondant au MOTIF
--patterns-from FICHIERMOTIFS
lire les motifs d'inclusion/exclusion depuis FICHIERMOTIFS, un par ligne
--strip-components NOMBRE
Supprime le nombre spécifié d'éléments de chemin de début. Les chemins avec moins d'éléments seront ignorés silencieusement.

EXEMPLES

# Extraire une archive entière
$ borg extract /chemin/vers/repo::mes-fichiers
# Extraire une archive entière et lister les fichiers pendant le traitement
$ borg extract --list /chemin/vers/repo::mes-fichiers
# Vérifier si une archive pourrait être extraite avec succès, mais sans écrire de fichiers sur le disque
$ borg extract --dry-run /chemin/vers/repo::mes-fichiers
# Extraire le répertoire "src"
$ borg extract /chemin/vers/repo::mes-fichiers home/UTILISATEUR/src
# Extraire le répertoire "src" mais exclure les fichiers objet
$ borg extract /chemin/vers/repo::mes-fichiers home/UTILISATEUR/src --exclude '*.o'
# Extraire uniquement les fichiers C
$ borg extract /chemin/vers/repo::mes-fichiers 'sh:home/UTILISATEUR/src/*.c'
# Restaurer un périphérique brut (ne doit pas être actif/utilisé/monté à ce moment-là)
$ borg extract --stdout /chemin/vers/repo::mon-sdx | dd of=/dev/sdx bs=10M
