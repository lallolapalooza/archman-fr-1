NOM

bpkg-pkg-unpack - décompresser l'archive d'un paquet

SYNOPIS

bpkg pkg-unpack [options] (paquet[/version] | --existing|-e répertoire)

DESCRIPTION

Si seul le nom du paquet est spécifié, alors la commande pkg-unpack décompresse l'archive du paquet précédemment téléchargé (bpkg-pkg-fetch(1)). L'état résultant du paquet est décompressé (bpkg-pkg-status(1)).

Si la version du paquet est également spécifiée, alors le répertoire (source) d'un des dépôts basés sur des répertoires (bpkg-rep-add(1)) est utilisé tel quel, sans être copié dans le répertoire de configuration. Un tel paquet est appelé externe.

Si l'option --existing|-e est utilisée, alors au lieu du nom du paquet, pkg-unpack attend un chemin local vers un répertoire de paquet existant. Dans ce cas, bpkg utilisera le répertoire (source) tel quel, de la même manière que pour les paquets des dépôts basés sur des répertoires. De plus, à moins que l'option --purge|-p ne soit spécifiée, bpkg ne tentera pas de supprimer ce répertoire lorsque le paquet sera purgé ultérieurement avec la commande bpkg-pkg-purge(1). Un tel paquet est également externe.

Si --existing|-e est spécifié conjointement avec l'option --replace|-r, alors pkg-unpack remplacera l'archive et/ou le répertoire source d'un paquet déjà dans l'état décompressé ou téléchargé.

Un paquet externe déclenche plusieurs changements sémantiques par rapport à un paquet normal : Le répertoire (de sortie) du paquet à l'intérieur de la configuration est appelé simplement paquet plutôt que paquet-version. Il est également supposé que les informations de packaging (manifeste de paquet et fichier de verrouillage) pour de tels paquets peuvent changer sans incrémenter la version du paquet (par exemple, pendant le développement). Pour supporter cela, bpkg implémente le mécanisme d'itération de paquet qui peut aboutir à l'affichage de numéros d'itération dans la version du paquet, par exemple, 1.2.3#1 (voir Version du paquet (#package-version)).

OPTIONS PKG-UNPACK

--existing|-e
Traiter l'argument comme un chemin de répertoire de paquet existant plutôt que comme le nom du paquet à décompresser.
--purge|-p
Supprimer le répertoire de paquet existant lorsque le paquet est purgé.
--replace|-r
Remplacer le répertoire source si le paquet est déjà décompressé ou téléchargé. Ne peut être spécifié qu'avec un paquet externe.
--directory|-d rép
Supposer que la configuration se trouve dans rép plutôt que dans le répertoire de travail courant.

NAME

bpkg-pkg-unpack

extract files from a package archive

SYNOPSIS

bpkg pkg-unpack [--directory dir] [--purge] [--no-default-options] [--option-file file] [--keep-tmp] [package...]

DESCRIPTION

The bpkg pkg-unpack command extracts the contents of the specified package archives into the current directory, or into a specified directory (see --directory). The default behaviour is to extract the archives into a temporary directory and then to move the extracted files to the target directory (current directory or the one specified by --directory).

If no package is specified, then all installed packages are unpacked.

This command uses the default options files to configure its behaviour (see DEFAULT OPTIONS FILES below). It also supports all common bpkg options (see COMMON OPTIONS below).

PKG-UNPACK OPTIONS

--directory dir
The directory into which the package archive(s) are extracted. If not specified, the current directory is used.
--purge
Remove the extracted files from the package archive(s) after a successful extraction.

COMMON OPTIONS

--option-file file
Load additional options from the specified file. The options are loaded in the order they are specified.
--directory dir
The directory to load additional default options files from.
--no-default-options
Don't load default options files.
--keep-tmp
Don't remove the bpkg's temporary directory at the end of the command execution and print its path at the verbosity level 2 or higher.

DEFAULT OPTIONS FILES

See bpkg-default-options-files(1) for an overview of the default options files. For the pkg-unpack command the search start directory is the configuration directory. The following options files are searched for in each directory and, if found, loaded in the order listed:

bpkg.options
bpkg-pkg-unpack.options

The following pkg-unpack command options cannot be specified in the default options files:

--directory|-d
--purge|-p
