NOM

Biber::DataModel - objets Biber::DataModel

new

Initialise un objet Biber::DataModel
Nous passons un tableau de modèles de données car il peut y en avoir plus d'un en mode
tool - celui de biber-tool.conf et des modifications dans un .conf utilisateur
Nous les fusionnons d'abord avant d'extraire les données. En cas de conflit, le modèle de
données du .conf utilisateur a la priorité.

get_outcase

Retourne la casse originale du champ/type d'entrée du modèle de données pour la sortie

constants

Retourne une référence de tableau de noms de constantes

get_constant_type

Retourne un type de constante

get_constant_value

Retourne une valeur de constante

is_multiscript

Retourne un booléen indiquant si un champ est un champ multiscript

fieldtypes

Retourne une référence de tableau des types de champs autorisés

datatypes

Retourne une référence de tableau des types de données autorisés

is_field

Retourne un booléen indiquant si un champ est un champ autorisé.
Autorise les champs avec des marqueurs méta dont le champ marqué doit être dans
le modèle de données.

entrytypes

Retourne une référence de tableau des types d'entrées autorisés

is_entrytype

Retourne un booléen indiquant si un type d'entrée est un type d'entrée autorisé

is_field_for_entrytype

Retourne un booléen indiquant si un champ est autorisé pour un type d'entrée

entrytype_is_skipout

Retourne un booléen selon qu'un type d'entrée doit être ignoré à la sortie

get_fields_of_fieldtype

Récupère les champs d'un certain type de champ biblatex à partir du modèle de données
Retourne dans un ordre trié afin que l'ordre bbl ne change pas lorsque .bcf
change. Cela perturbe vraiment les tests autrement.

get_fields_of_fieldformat

Récupère les champs d'un certain format à partir du modèle de données
Retourne dans un ordre trié afin que l'ordre bbl ne change pas lorsque .bcf
change. Cela perturbe vraiment les tests autrement.

get_fields_of_datatype

Récupère les champs d'un certain type de données biblatex à partir du modèle de données
Retourne dans un ordre trié afin que l'ordre bbl ne change pas lorsque .bcf
change. Cela perturbe vraiment les tests autrement.

get_fields_of_type

Récupère les champs d'un certain type biblatex à partir du modèle de données
Retourne dans un ordre trié afin que l'ordre bbl ne change pas lorsque .bcf
change. Cela perturbe vraiment les tests autrement.

is_fields_of_type

Retourne un booléen indiquant si la combinaison type de champ/type de données/format donnée est valide

get_fieldtype

Retourne le type de champ d'un champ

get_datatype

Retourne le type de données d'un champ

get_fieldformat

Retourne le format d'un champ

get_dm_for_field

Retourne le type de champ, le type de données et le format d'un champ

field_is_fieldtype

Retourne un booléen selon qu'un champ est d'un certain type de champ biblatex

field_is_datatype

Retourne un booléen selon qu'un champ est d'un certain type de données biblatex

field_is_type

Retourne un booléen selon qu'un champ est d'un certain type de champ
et type de données biblatex

field_is_nullok

Retourne un booléen selon qu'un champ peut être nul

field_is_skipout

Retourne un booléen selon qu'un champ doit être ignoré à la sortie

check_mandatory_constraints

Vérifie les contraintes de type « mandatory » sur l'entrée et
retourne un tableau d'avertissements, le cas échéant

check_conditional_constraints

Vérifie les contraintes de type « conditional » sur l'entrée et
retourne un tableau d'avertissements, le cas échéant

check_data_constraints

Vérifie les contraintes de type « data » sur l'entrée et
retourne un tableau d'avertissements, le cas échéant

check_datatypes

Vérifie les types de données des champs par rapport aux champs. Ce ne sont pas des contraintes explicites
dans le modèle de données mais plutôt des vérifications du type de données des champs dans le modèle de données.

dump

Affiche l'objet Biber::DataModel

generate_bltxml_schema

Génère un schéma RelaxNG XML à partir du modèle de données pour les sources de données BibLaTeXML

generate_bblxml_schema

Génère un schéma RelaxNG XML à partir du modèle de données pour la sortie bblXML
