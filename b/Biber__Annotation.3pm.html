Biber::Annotation(3pm) Documentation Perl fournie par l'utilisateur Biber::Annotation(3pm)

NOM

Biber::Entry::Annotation - Objets Biber::Annotation

set_annotation

Enregistre une annotation pour une portée et une clé de citation

inherit_annotations

Hérite, de manière granulaire, des annotations pour un champ d'entrée donné d'une entrée à une autre pour tous les noms d'annotation, en réindexant tous les compteurs d'éléments car les annotations peuvent être copiées en raison de l'héritage xdata, ce qui peut modifier les positions des éléments des annotations.

copy_annotations

Copie toutes les annotations d'une entrée à une autre

get_annotation_names

Récupère tous les noms d'annotation pour une clé de citation et un champ

get_annotations

Récupère toutes les annotations pour une portée et une clé de citation

get_annotation

Récupère une annotation spécifique pour une portée, une clé de citation et un nom

is_literal_annotation

Vérifie si une annotation est une annotation littérale

is_annotated_field

Retourne un booléen indiquant si un champ est annoté

get_field_annotation

Récupère l'annotation de portée 'champ' pour un champ. Il n'y en aura qu'une.

get_annotated_fields

Récupère tous les champs annotés pour une portée particulière pour une clé

get_annotated_items

Récupère les compteurs d'éléments pour une portée, une clé, un champ et un nom particuliers

get_annotated_parts

Récupère les parties pour une portée, une clé, un champ, un nom et un compteur d'éléments particuliers

dump

Affiche les informations de configuration (pour le débogage)
