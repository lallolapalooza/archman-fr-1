NOM

bglmco - produit des fichiers objets de somme de contrôle de module.

SYNOPSIS

bglmco [ options ] [ fichier source ]

DESCRIPTION

bglmco lit fichier source et produit un fichier objet de somme de contrôle de module. Ce fichier bglmco est utilisé pour assurer la cohérence des modules dans les fichiers Makefiles de Bigloo.

OPTIONS

-v
Mode verbeux.
-v
Mode verbeux.
-s
Mode silencieux.
-o <fichier>
Le nom du fichier bglmco à générer.

EXEMPLE

Un bglmco est créé par ``bglmco foo.scm -o foo.mco''.

VOIR AUSSI

bigloo(1), bglafile(1), bglmake(1), bgltags(1), makedepend(1), make(1)
