BN_rand(3ssl)

Paquet: openssl

Licences: Apache-2.0

BN_RAND(3ssl) OpenSSL BN_RAND(3ssl)

NOM

BN_rand_ex, BN_rand, BN_priv_rand_ex, BN_priv_rand, BN_pseudo_rand, BN_rand_range_ex, BN_rand_range, BN_priv_rand_range_ex, BN_priv_rand_range - générer un nombre pseudo-aléatoire

SYNTAXE

#include <openssl/bn.h>
int BN_rand_ex(BIGNUM *rnd, int bits, int top, int bottom,
               unsigned int strength, BN_CTX *ctx);
int BN_rand(BIGNUM *rnd, int bits, int top, int bottom);
int BN_priv_rand_ex(BIGNUM *rnd, int bits, int top, int bottom,
                    unsigned int strength, BN_CTX *ctx);
int BN_priv_rand(BIGNUM *rnd, int bits, int top, int bottom);
int BN_rand_range_ex(BIGNUM *rnd, const BIGNUM *range, unsigned int strength,
                     BN_CTX *ctx);
int BN_rand_range(BIGNUM *rnd, const BIGNUM *range);
int BN_priv_rand_range_ex(BIGNUM *rnd, const BIGNUM *range, unsigned int strength,
                          BN_CTX *ctx);
int BN_priv_rand_range(BIGNUM *rnd, const BIGNUM *range);

Les fonctions suivantes sont dépréciées depuis OpenSSL 3.0, et peuvent être entièrement masquées en définissant OPENSSL_API_COMPAT avec une valeur de version appropriée, voir openssl_user_macros(7) :

int BN_pseudo_rand(BIGNUM *rnd, int bits, int top, int bottom);
int BN_pseudo_rand_range(BIGNUM *rnd, const BIGNUM *range);

DESCRIPTION

BN_rand_ex() génère un nombre pseudo-aléatoire cryptographiquement fort de bits de longueur et d'une force de sécurité d'au moins strength bits en utilisant le générateur de nombres aléatoires pour le contexte de la bibliothèque associé à ctx. La fonction stocke les données générées dans rnd. Le paramètre ctx peut être NULL, auquel cas le contexte de bibliothèque par défaut est utilisé. Si bits est négatif, ou trop petit pour accommoder les exigences spécifiées par les paramètres top et bottom, une erreur est retournée. Le paramètre top spécifie les exigences sur le bit le plus significatif du nombre généré. S'il est BN_RAND_TOP_ANY, il n'y a pas de contrainte. S'il est BN_RAND_TOP_ONE, le bit supérieur doit être un. S'il est BN_RAND_TOP_TWO, les deux bits les plus significatifs du nombre seront mis à 1, de sorte que le produit de deux tels nombres aléatoires aura toujours une longueur de 2*bits. Si bottom est BN_RAND_BOTTOM_ODD, le nombre sera impair ; s'il est BN_RAND_BOTTOM_ANY, il peut être pair ou impair. Si bits est 1, alors top ne peut pas non plus être BN_RAND_TOP_TWO.

BN_rand() est identique à BN_rand_ex() sauf que le contexte de bibliothèque par défaut est toujours utilisé.

BN_rand_range_ex() génère un nombre pseudo-aléatoire cryptographiquement fort rnd, d'une force de sécurité d'au moins strength bits, dans l'intervalle 0 <= rnd < range en utilisant le générateur de nombres aléatoires pour le contexte de la bibliothèque associé à ctx. Le paramètre ctx peut être NULL, auquel cas le contexte de bibliothèque par défaut est utilisé.

BN_rand_range() est identique à BN_rand_range_ex() sauf que le contexte de bibliothèque par défaut est toujours utilisé.

BN_priv_rand_ex(), BN_priv_rand(), BN_priv_rand_rand_ex() et BN_priv_rand_range() ont les mêmes sémantiques que BN_rand_ex(), BN_rand(), BN_rand_range_ex() et BN_rand_range() respectivement. Ils sont destinés à être utilisés pour générer des valeurs qui doivent rester privées, et reflètent la même différence entre RAND_bytes(3) et RAND_priv_bytes(3).

NOTES

Vérifiez toujours la valeur de retour d'erreur de ces fonctions et ne prenez pas le caractère aléatoire pour acquis : une erreur se produit si le CSPRNG n'a pas été amorcé avec suffisamment de caractère aléatoire pour garantir une séquence d'octets imprévisible.

VALEUR DE RETOUR

Les fonctions retournent 1 en cas de succès, 0 en cas d'erreur. Les codes d'erreur peuvent être obtenus par ERR_get_error(3).

VOIR AUSSI

ERR_get_error(3), RAND_add(3), RAND_bytes(3), RAND_priv_bytes(3), RAND(7), EVP_RAND(7)

HISTORIQUE

  • À partir de la version 1.1.0 d'OpenSSL, BN_pseudo_rand() est identique à BN_rand() et BN_pseudo_rand_range() est identique à BN_rand_range(). Les fonctions BN_pseudo_rand() et BN_pseudo_rand_range() ont été dépréciées dans OpenSSL 3.0.
  • Les fonctions BN_priv_rand() et BN_priv_rand_range() ont été ajoutées dans OpenSSL 1.1.1.
  • Les fonctions BN_rand_ex(), BN_priv_rand_ex(), BN_rand_range_ex() et BN_priv_rand_range_ex() ont été ajoutées dans OpenSSL 3.0.
