MODULES D'ENTRÉE Les modules d'entrée fournissent des données statistiques sur les éléments. Chaque élément se compose d'attributs qui représentent un compteur, un débit ou un pourcentage. Les éléments peuvent porter des éléments enfants supplémentaires pour représenter une hiérarchie. Chaque élément est attribué à un groupe défini par le module d'entrée. Les modules d'entrée sont interrogés à la fréquence de l'intervalle

de lecture configuré.

trée suivants so

MODULES DE

SORTIE
Les modules de sortie affichent ou exportent les données statistiques collectées par les modules d'entrée. Plusieurs modules de sortie peuvent fonctionner en même temps. bmon n'empêchera pas les conflits possibles, tels que plusieurs modules de sortie écrivant
sur la console.

Les modules de

sortie suiva
nts existent :

curse

s

Interface utilisateur texte interactive basée sur curses, fournissant des estimations de débit en temps réel et une représentation graphique de chaque attribut. Appuyez sur '?' pour afficher le guide de référence rapide. C'est le mode de sortie par

défaut.

asci

i
Sortie texte simple et programmable destinée à la lecture humaine. Capable d'imprimer des listes d'interfaces, des compteurs détaillés et des graphiques sur la
console. C'est le mode de sortie de secours par défaut si curses n'est pas disponible.
forma
t
Mode de sortie entièrement scriptable destiné à être consommé par d'autres programmes. Voir le
texte d'aide du module pour des informations supplémentaires.
nul
l
Désactive la
sortie.
Pour obtenir des informations supplémentaires sur un module, exécutez le module avec l'option "help" comme ceci
:
bmon -o
curses:help

N DES MODULES pour

CONFIGURATION DES

MODULES
La syntaxe pour configurer les modules est la suivante
:

ARGUMENT ::= mod1[:OPTS][,mod2[:OPTS]..

.
]

OPTS ::= OPTION[;OPTION...

]

OPTION ::=

Exécutez le module avec l'option "help" pour obtenir la liste des options de chaque module :
bmon -i module:help
SÉLECTION DE
L'INTERFACE

La syntaxe suivante est utilisée pour définir la politique de sélection de l'interface

:
SELECTION ::= NAME[,NAME[,..
.]
]

NAME ::= [!]

interface

Le nom de l'interface peut contenir le caractère '*' qui agira comme un caractère générique et représente un nombre quelconque de caractères de n'importe quel type, par ex. eth*, h*0, .

..
Exemples :
lo,eth0,
eth1

eth*,!eth0

EXEMPLES

Pour exécuter bmon en mode curses en surveillant les interfaces eth0

et eth1 :
bmon -p eth0,eth1 -o curses
Pour exécuter bmon en mode format, en surveillant toutes les interfaces eth*, avec une chaîne de
format
spécifiée :

bmon -p 'eth*' -o format:fmt='$(element:name) $(attr:rxrate:

packets)\n'
