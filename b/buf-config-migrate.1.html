NOM

buf-config-migrate - Migre tous les fichiers buf.yaml, buf.work.yaml, buf.gen.yaml et buf.lock dans les répertoires ou chemins spécifiés vers la version v2

SYNTAXE

buf config migrate [options]

DESCRIPTION

Si aucune option n'est spécifiée, le répertoire courant est recherché pour les fichiers buf.yamls, buf.work.yamls et buf.gen.yamls.

Les effets de cette commande peuvent changer au fil du temps.

OPTIONS

--buf-gen-yaml=[] Les chemins vers les modèles de génération buf.gen.yaml à migrer

-d, --diff[=false] Écrit une différence dans la sortie standard au lieu de migrer les fichiers sur le disque. Utile pour effectuer une exécution à blanc.

-h, --help[=false] Aide pour migrate

--module=[] Les répertoires de modules à migrer. buf.yaml et buf.lock seront migrés

--workspace=[] Les répertoires d'espace de travail à migrer. buf.work.yaml, buf.yamls et buf.locks seront migrés

OPTIONS HÉRITÉES DES COMMANDES PARENT

--debug[=false] Active la journalisation de débogage

--log-format="color" Le format du journal [text,color,json]

--timeout=0s La durée avant expiration, la régler sur 0 signifie pas d'expiration
