BINDRESVPORT(3) Manuel des fonctions de bibliothèque BINDRESVPORT(3)

NOM

bindresvport, bindresvport_sa — lier une socket à un port IP privilégié

SYNTAXE

#include <sys/types.h>
#include <rpc/rpc.h>

int
bindresvport(int sd, struct sockaddr_in *sin);

int
bindresvport_sa(int sd, struct sockaddr *sa);

DESCRIPTION

Les fonctions bindresvport() et bindresvport_sa() sont utilisées pour lier un descripteur de socket à un port IP privilégié, c'est-à-dire un numéro de port dans la plage 0-1023.

Si sin est un pointeur vers une struct sockaddr_in, alors les champs appropriés de la structure doivent être définis. Notez que sin->sin_family doit être initialisé à la famille d'adresses de la socket, passée par sd. Si sin->sin_port est ‘0’, alors un port anonyme (dans la plage 600-1023) sera choisi, et si bind(2) réussit, sin->sin_port sera mis à jour pour contenir le port alloué.

Si sin est le pointeur NULL, un port anonyme sera alloué (comme ci-dessus). Cependant, il n'y a aucun moyen pour bindresvport() de retourner le port alloué dans ce cas.

Seul root peut se lier à un port privilégié ; cet appel échouera pour tout autre utilisateur.

Le prototype de fonction de bindresvport() est orienté vers les sockets AF_INET. La fonction bindresvport_sa() se comporte exactement de la même manière, avec un prototype de fonction plus neutre. Notez que les deux fonctions se comportent exactement de la même manière, et les deux prennent en charge les sockets AF_INET6 ainsi que les sockets AF_INET.

VALEURS DE RETOUR

La fonction bindresvport() retourne la valeur 0 si elle réussit ; sinon, la valeur -1 est retournée et la variable globale errno est définie pour indiquer l'erreur.

ERREURS

[EPFNOSUPPORT]
Si le deuxième argument était fourni, et que la famille d'adresses ne correspondait pas entre les arguments.

La fonction bindresvport() peut également échouer et définir errno pour toute erreur spécifiée pour les appels bind(2), getsockopt(2), ou setsockopt(2).

DISPONIBILITÉ

La fonction bindresvport() fait partie de libtirpc.

VOIR AUSSI

bind(2), getsockopt(2), setsockopt(2)
