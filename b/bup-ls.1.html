NOM

bup-ls - lister le contenu d'un dépôt bup

SYNTAXE

bup ls [-r hôte:[chemin]] [OPTION...] <chemins...>

DESCRIPTION

bup ls liste les fichiers et répertoires de votre dépôt bup en utilisant la même hiérarchie de répertoires qu'avec bup-fuse(1).

Le répertoire de niveau supérieur contient la branche (correspondant à l'option -n de bup save), le niveau suivant est la date de la sauvegarde, et les niveaux suivants correspondent aux fichiers de la sauvegarde.

Lorsque bup ls est demandé de sortir sur un tty, et que -l n'est pas spécifié, il formate la sortie en colonnes afin de lister autant que possible en un minimum de lignes. Cependant, lorsque -l est spécifié ou que bup est demandé de sortir vers autre chose qu'un tty (par exemple, si vous redirigez la sortie vers une autre commande, ou si vous la redirigez vers un fichier), il imprimera un nom de fichier par ligne. Cela rend la liste plus facile à analyser avec des outils externes.

Notez que bup ls n’affiche pas les fichiers cachés par défaut et qu’il faut utiliser l’option -a pour les afficher. Les fichiers sont cachés lorsque leur nom commence par un point. Par exemple, au niveau le plus élevé, les répertoires spéciaux nommés .commit et .tag sont des répertoires cachés.

Une fois que vous avez identifié le fichier que vous voulez avec bup ls, vous pouvez voir son contenu en utilisant bup join ou git show.

OPTIONS

-r, --remote=hôte:[chemin]
lister les informations pour le dépôt situé à chemin sur l’hôte indiqué. Si chemin est omis, utilise le chemin par défaut sur le serveur distant (vous devez toujours inclure le ':'). La connexion au serveur distant sera établie via SSH. Si vous souhaitez spécifier le port, l'utilisateur ou la clé privée, nous vous recommandons d'utiliser le fichier ~/.ssh/config (ssh_config(5)).
-s, --hash
afficher le hachage pour chaque fichier/répertoire.
-a, --all
afficher les fichiers cachés.
-A, --almost-all
afficher les fichiers cachés, à l'exception de “.” et “..”.
-d, --directory
afficher les informations sur les répertoires eux-mêmes, plutôt que sur leur contenu, et ne pas suivre les liens symboliques.
-l
fournir une liste détaillée et longue pour chaque élément.
-F, --classify
ajouter un indicateur de type : dir/, symlink@, fifo|, socket=, et executable*.
--file-type
ajouter un indicateur de type : dir/, symlink@, fifo|, socket=.
--human-readable
afficher les tailles de fichiers dans un format lisible par l'homme (c'est-à-dire 3.9K, 4.7M).
--numeric-ids
afficher les identifiants numériques (utilisateur, groupe, etc.) plutôt que les noms.

EXEMPLES

bup ls /myserver/latest/etc/profile
bup ls -a /
