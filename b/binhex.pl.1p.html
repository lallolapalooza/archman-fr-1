NOM

binhex.pl - utiliser Convert::BinHex pour encoder des fichiers en BinHex

UTILISATION

Utilisation :

binhex.pl [options] fichier ... fichier

Où les options sont :

-o dir    Sortie dans le répertoire donné (par défaut, sortie dans le répertoire du fichier)
-v        Sortie détaillée (normalement, une seule ligne par fichier est affichée)

DESCRIPTION

Chaque fichier est converti en fichier.hqx.

AVERTISSEMENTS
