NOM

buf-breaking - Vérifie qu'aucun changement majeur n'a été effectué

SYNTAXE

buf breaking --against [flags]

DESCRIPTION

Cette commande s'assure que l'emplacement spécifié ne contient aucun changement majeur par rapport à l'autre emplacement.

Le premier argument est la source, le module ou l'image à vérifier pour les changements majeurs, qui doit être l'un des formats [binpb,dir,git,json,mod,protofile,tar,txtpb,yaml,zip]. Par défaut, il s'agit de "." si aucun argument n'est spécifié.

OPTIONS

--against="" Obligatoire, sauf si --against-registry est défini. La source, le module ou l'image par rapport auxquels vérifier. Doit être l'un des formats [binpb,dir,git,json,mod,protofile,tar,txtpb,yaml,zip]

--against-config="" Le fichier buf.yaml ou les données à utiliser pour configurer la source, le module ou l'image de comparaison.

--against-registry[=false] Exécute les vérifications de changements majeurs par rapport au dernier commit sur la branche par défaut dans le registre. Tous les modules de l'entrée doivent avoir un nom configuré, sinon cela échouera. Si un module distant n'est pas trouvé avec le nom configuré, cela échouera. Ceci ne peut pas être défini avec --against.

--config="" Le fichier buf.yaml ou les données à utiliser pour la configuration.

--disable-symlinks[=false] Ne pas suivre les liens symboliques lors de la lecture des sources ou de la configuration à partir du système de fichiers local. Par défaut, les liens symboliques sont suivis dans cette CLI, mais jamais suivis sur le Buf Schema Registry.

--error-format="text" Le format des erreurs de compilation ou des violations de vérification imprimées sur la sortie standard. Doit être l'un des [text,json,msvs,junit,github-actions,gitlab-code-quality]

--exclude-imports[=false] Exclut les importations de la détection de changements majeurs.

--exclude-path=[] Exclut des fichiers ou répertoires spécifiques, par exemple "proto/a/a.proto", "proto/a". Si spécifié plusieurs fois, l'union est prise.

-h, --help[=false] Aide pour breaking

--limit-to-input-files[=false] Exécute uniquement les vérifications de changements majeurs sur les fichiers de l'entrée. Lorsque défini, l'entrée de comparaison ne contient que les fichiers de l'entrée. Remplace --path.

--path=[] Limite à des fichiers ou répertoires spécifiques, par exemple "proto/a/a.proto", "proto/a". Si spécifié plusieurs fois, l'union est prise.

OPTIONS INHERITÉE DES COMMANDES PARENTES

--debug[=false] Active la journalisation de débogage.

--log-format="color" Le format de journalisation [text,color,json]

--timeout=0s La durée avant expiration, la définir sur 0 signifie pas d'expiration.
