NOM

basic_radius_auth - Aide à l'authentification RADIUS de Squid

SYNTAXE

basic_radius_auth -f fichier de configuration
basic_radius_auth -h " nom du serveur " [-p port ] [-i identifiant ] -w secret [-t délai d'attente ]

DESCRIPTION

basic_radius_auth permet à Squid de se connecter à un serveur RADIUS pour valider le nom d'utilisateur et le mot de passe de l'authentification HTTP de base.

OPTIONS

-f fichierconfig
Spécifie le chemin vers un fichier de configuration. Voir la section CONFIGURATION pour plus de détails sur le contenu du fichier.
-h serveur
Méthode alternative pour spécifier le serveur auquel se connecter.
-p port
Spécifie un autre port de serveur où le serveur RADIUS écoute les requêtes s'il est différent du port RADIUS par défaut. Normalement non spécifié.
-i identifiant
Identifiant unique identifiant ce proxy Squid auprès du serveur RADIUS. S'il n'est pas spécifié, l'adresse IP est utilisée pour identifier le proxy.
-w secret
Méthode alternative pour spécifier le secret partagé. L'utilisation de l'option -f avec un fichier de configuration est généralement plus sûre et recommandée.
-t delaiattente
Délai d'attente pour les requêtes RADIUS. La valeur par défaut est de 10 secondes.

CONFIGURATION

La configuration spécifie comment l'aide se connecte à RADIUS. Le fichier contient une liste de directives (une par ligne). Les lignes commençant par un # sont ignorées.

serveur serveur_radius
spécifie le nom ou l'adresse du serveur RADIUS auquel se connecter.
secret chaine_de_caracteres_secrete
spécifie le secret RADIUS partagé.
identifiant nomduserveur
spécifie le nom que le proxy doit utiliser pour s'identifier auprès du serveur RADIUS. Cette directive est facultative.
port numeroport
Spécifie le numéro de port ou le nom du service auquel l'aide doit se connecter.
delaiattente secondes
Spécifie le délai d'attente pour les requêtes RADIUS.
