NOM

bbox - imprime la boîte englobante d'une image rawppm ou rawpbm

SYNTAXE

bbox [ -l ] [ -r ] [ -h ] [ -V ] [ fichier-rawpbm ]

DESCRIPTION

bbox lit un fichier rawppm ou rawpbm et imprime la boîte englobante de l'image (sous forme de commentaire postscript et en points postscript, c'est-à-dire 1/72 dpi) ainsi que la boîte englobante haute résolution. L'entrée est lue depuis l'entrée standard si aucun nom de fichier n'est spécifié. Exemple de sortie :

%%BoundingBox: 12 253 829 837
%%HiResBoundingBox: 12.500000 253.000000 828.500000 837.00000

bbox a des exigences de mémoire très limitées car il lit l'entrée ligne par ligne et n'a donc besoin de stocker qu'une seule ligne d'image en mémoire.

OPTIONS

-h | --help
Affiche un résumé des options.
-V
Affiche la version du programme.
-r
résolution de l'image en dpi
-l
boîte englobante élargie (la boîte englobante entière est étendue d'un point, la boîte englobante haute résolution est étendue de 0,5 point)

VOIR AUSSI

ps2eps (1)

BOGUES

Bien que le code soit assez petit et que la probabilité de bogues soit maintenant faible, il peut y en avoir quelques-uns qui traînent entre les lignes. Si vous en trouvez un, veuillez envoyer une courte description avec le numéro de version de bbox à <roland@bless.de> (veuillez laisser un peu de temps pour la réponse).
