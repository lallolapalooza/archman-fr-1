B::Op_private(3perl) Guide du programmeur Perl B::Op_private(3perl)

NOM

B::Op_private - Définitions du drapeau op_private de OP

SYNTAXE

use B::Op_private;
# détails du drapeau pour le bit 7 de op_private de OP_AELEM :
my $name  = $B::Op_private::bits{aelem}{7}; # OPpLVAL_INTRO
my $value = $B::Op_private::defines{$name}; # 128
my $label = $B::Op_private::labels{$name};  # LVINTRO
# le champ de bits aux positions 5..6 de op_private de OP_AELEM :
my $bf  = $B::Op_private::bits{aelem}{6};
my $mask = $bf->{bitmask}; # etc

DESCRIPTION

Ce module fournit quatre hachages globaux :

%B::Op_private::bits
%B::Op_private::defines
%B::Op_private::labels
%B::Op_private::ops_using

qui contiennent des informations sur les significations par op des bits du champ op_private.

%bits

Ceci est indexé par le nom de l'op, puis par le numéro de bit (0..7). Pour les drapeaux de bits uniques, il renvoie le nom de la définition (s'il y en a une) pour ce bit :

$B::Op_private::bits{aelem}{7} eq 'OPpLVAL_INTRO';

Pour les champs de bits, il renvoie une référence de hachage contenant des détails sur le champ. La même référence sera renvoyée pour toutes les positions de bits qui composent le champ de bits ; ainsi, par exemple, ces deux lignes renvoient la même référence de hachage :

$bitfield = $B::Op_private::bits{aelem}{5};
$bitfield = $B::Op_private::bits{aelem}{6};

Le format général de cette référence de hachage est

{
    # La plage de bits et le masque ; ceux-ci sont toujours présents.
    bitmin        => 5,
    bitmax        => 6,
    bitmask       => 0x60,
    # (Les clés restantes sont optionnelles)
    # Les noms de toutes les définitions qui ont été demandées :
    mask_def      => 'OPpFOO_MASK',
    baseshift_def => 'OPpFOO_SHIFT',
    bitcount_def  => 'OPpFOO_BITS',
    # Si présent, Concise etc affichera la valeur avec un préfixe 'FOO='.
    # S'il est égal à '-', alors Concise traitera le champ de bits comme des bits bruts
    # et n'essaiera pas de l'interpréter.
    label         => 'FOO',
    # Si présent, spécifie les noms de certaines définitions et les
    # étiquettes d'affichage qui sont utilisées pour attribuer une signification à des
    # valeurs entières particulières dans le champ de bits ; par exemple, 3 est affiché
    # comme 'C'.
    enum          => [ qw(
                         1   OPpFOO_A  A
                         2   OPpFOO_B  B
                         3   OPpFOO_C  C
                     )],
};

%defines

Ceci donne la valeur de chaque définition "OPp", par exemple.

$B::Op_private::defines{OPpLVAL_INTRO} == 128;

%labels

Ceci donne l'étiquette d'affichage courte pour chaque définition, telle qu'utilisée par "B::Concise" et "perl -Dx", par exemple.

$B::Op_private::labels{OPpLVAL_INTRO} eq 'LVINTRO';

Si l'étiquette est égale à '-', alors Concise traitera le bit comme un bit brut et n'essaiera pas de l'afficher symboliquement.

%ops_using

Pour chaque définition, ceci donne une référence vers un tableau de noms d'ops qui utilisent le drapeau.

@ops_using_lvintro = @{ $B::Op_private::ops_using{OPp_LVAL_INTRO} };
