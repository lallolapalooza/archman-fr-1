Array3 fournit des opérations similaires à celles de Bigarray.Genarray , mais spécialisées au cas des tableaux tridimensionnels. typ

val create : ('a, 'b) Bigarray.kind -> 'c Bigarray.layout -> int -> int -> int -> ('a, 'b, 'c)

t

Array3.create kind layout dim1 dim2 dim3 renvoie un nouveau Bigarray de trois dimensions, dont la taille est dim1 dans la première dimension, dim2 dans la deuxième dimension et dim3 dans la troisième. kind et layout déterminent le type d'élément du tableau et la disposition du tableau comme décrit pour Bigarray.Genarray

.create .

val init : ('a, 'b) Bigarray.kind -> 'c Bigarray.layout -> int -> int -> int -> (int -> int -> int -> 'a) -> ('a, 'b, 'c)

t

Array3.init kind layout dim1 dim2 dim3 f renvoie un nouveau Bigarray b de trois dimensions, dont la taille est dim1 dans la première dimension, dim2 dans la deuxième dimension et dim3 dans la troisième. kind et layout déterminent le type d'élément du tableau et la disposition du tableau comme décrit pour Bigarray.Genarray

.create .

Chaque élément Array3.get b i j k du tableau est initialisé au résultat de f i j k

.

En d'autres termes, Array3.init kind layout dim1 dim2 dim3 f tabule les résultats de f appliqué aux indices d'un nouveau Bigarray dont la disposition est décrite par kind , layout , dim1 , dim2 et dim3

.

val change_layout : ('a, 'b, 'c) t -> 'd Bigarray.layout -> ('a, 'b, 'd)

t

Array3.change_layout a layout renvoie un Bigarray avec la disposition spécifiée, partageant les données avec a (et ayant donc les mêmes dimensions que a ). Aucune copie d'éléments n'est impliquée : le nouveau tableau et le tableau d'origine partagent le même espace de stockage. Les dimensions sont inversées, de sorte que get v [| a; b; c |] en disposition C devient get v [| c+1; b+1; a+1 |] en disposition

Fortran.
