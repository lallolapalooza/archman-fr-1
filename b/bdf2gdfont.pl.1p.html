NOM

bdf2gdfont.pl - Convertit les polices "BDF" de X11 dans un format de police chargeable pour GD.

SYNTAXE

% bdf2gdfont.pl courR12.bdf > courR12.fnt

DESCRIPTION

Ce script convertit les fichiers de polices X11 de style BDF dans un format qui peut être chargé par le module GD en utilisant la méthode GD::Font->load(). Il existe un certain nombre de façons d'obtenir des polices BDF.

1. La police est déjà présente sur votre système.
Certaines polices BDF peuvent être trouvées dans la distribution standard X11R6. Ce script décompressera automatiquement les fichiers de polices compressés si leur extension se termine par .gz (le programme gunzip doit être dans votre PATH).
2. Depuis un serveur de polices.
L'utilitaire "fstobdf", un utilitaire X11 standard, lira une police nommée à partir du serveur de polices de votre choix et la retournera au format BDF. Vous pouvez la rediriger vers bdf2gdfont.pl : 
fstobdf -s serveur_police:7100 -fn 8x16 | bdf2gdfont.pl > nouvelle_police.fnt

Utilisez xlsfonts pour savoir quelles polices sont disponibles. La plupart des polices auront des noms longs comme -B&H-LucidaTypewriter-Bold-R-Normal-Sans-18-180-75-75-M-110-ISO8859-10.

3. En utilisant l'utilitaire pcf2bdf.
Certaines polices ne sont disponibles qu'au format PCF (compilé). Pour les obtenir, vous pouvez soit activer un serveur de polices et suivre la recette (2), soit utiliser l'utilitaire pcf2bdf de TAGA Nayuta. Cet utilitaire est disponible à l'adresse http://www.tsg.ne.jp/GANA/S/pcf2bdf/ (la page est en japonais, mais vous pouvez y trouver le lien de téléchargement).

Limitations

Ce convertisseur de polices ne fonctionne qu'avec les polices à largeur fixe. S'il est utilisé avec une police TrueType ou proportionnelle, il se terminera avec un message d'erreur.
