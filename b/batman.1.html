BATMAN(1) Manuel général des commandes BATMAN(1)

NOM

batman - Lire les pages de manuel système (man) en utilisant bat comme formateur de pages de manuel.

DESCRIPTION

Fini le temps où l'on perdait sa place en parcourant des pages de manuel monotones. Avec bat et batman, vous pouvez lire man ifconfig avec de belles couleurs 24 bits et une coloration syntaxique.

Si vous avez fzf installé, vous pouvez même utiliser batman pour rechercher dans les pages de manuel !

UTILISATION


batman [SECTION] [ENTRÉE]

En remplacement de man

Avec bash :

bash
eval "$(batman --export-env)"

Avec fish :

fish
batman --export-env | source

ENVIRONNEMENT

Variable Description
MANPAGER Modifie le pagineur utilisé pour batman. Ceci est traité comme BAT_PAGER, mais affecte uniquement cette commande.

PERSONNALISATION

Changer le thème

Vous pouvez changer le thème de coloration syntaxique pour batman en définissant la variable d'environnement BAT_THEME avant d'appeler batman. La fonction wrapper suivante changera le thème en Solarized (dark) sans affecter aucune autre commande bat.

bash
batman() {
BAT_THEME="Solarized (dark)" batman "$@"
return $?
}

AVERTISSEMENTS

Les drapeaux ne sont pas mis en couleur :

- Cela se produit lorsque vous modifiez le thème de bat via le fichier de configuration de bat ou la variable d'environnement BAT_THEME. Tous les thèmes ne fournissent pas de couleurs pour les drapeaux, et c'est un problème connu.
- Vous pouvez remplacer le thème pour batman en l'encapsulant dans une fonction qui définit BAT_THEME.
- Les thèmes suivants prennent en charge la mise en couleur des pages de manuel :
- Monokai Extended / Monokai Extended Light
- Solarized (dark) / Solarized (light)
