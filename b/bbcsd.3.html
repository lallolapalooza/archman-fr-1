CBBCS

D

But

: 
!>
!> CBBCSD calcule la décomposition CS d'une matrice unitaire sous
!> forme de blocs bidiagonaux,
!>
!>
!>     [ B11 | B12 0  0 ]
!>     [  0  |  0 -I  0 ]
!> X = [----------------]
!>     [ B21 | B22 0  0 ]
!>     [  0  |  0  0  I ]
!>
!>                               [  C | -S  0  0 ]
!>                   [ U1 |    ] [  0 |  0 -I  0 ] [ V1 |    ]**H
!>                 = [---------] [---------------] [---------]   .
!>                   [    | U2 ] [  S |  C  0  0 ] [    | V2 ]
!>                               [  0 |  0  0  I ]
!>
!> X est de dimension M par M, son bloc supérieur gauche est de dimension
!> P par Q, et Q ne doit pas être plus grand que P, M-P, ou M-Q.
!> (Si Q n'est pas le plus petit indice, alors X doit être transposé
!> et/ou permuté. Cela peut être fait en temps constant à l'aide des
!> options TRANS et SIGNS. Voir CUNCSD pour les détails.)
!>
!> Les matrices bidiagonales B11, B12, B21 et B22 sont représentées
!> implicitement par les angles THETA(1:Q) et PHI(1:Q-1).
!>
!> Les matrices unitaires U1, U2, V1T et V2T sont en entrée/sortie.
!> Les matrices d'entrée sont pré- ou post-multipliées par les matrices
!> de vecteurs singuliers appropriées.
!
>

Paramètre

s
JOBU1 
!>          JOBU1 est de type CHARACTER
!>          = 'Y' :      U1 est mis à jour ;
!>          sinon :      U1 n'est pas mis à jour.
!
>

JOBU

2 
!>          JOBU2 est de type CHARACTER
!>          = 'Y' :      U2 est mis à jour ;
!>          sinon :      U2 n'est pas mis à jour.
!
>

JOBV1

T 
!>          JOBV1T est de type CHARACTER
!>          = 'Y' :      V1T est mis à jour ;
!>          sinon :      V1T n'est pas mis à jour.
!
>

JOBV2

T 
!>          JOBV2T est de type CHARACTER
!>          = 'Y' :      V2T est mis à jour ;
!>          sinon :      V2T n'est pas mis à jour.
!
>

TRAN

S 
!>          TRANS est de type CHARACTER
!>          = 'T' :      X, U1, U2, V1T et V2T sont stockés dans l'ordre
!>                      ligne par ligne ;
!>          sinon :      X, U1, U2, V1T et V2T sont stockés dans l'ordre
!>                      colonne par colonne.
!
>

M 
!>          M est de type INTEGER
!>          Le nombre de lignes et de colonnes de X, la matrice unitaire
!>          sous forme de blocs bidiagonaux.
!
>

P 
!>          P est de type INTEGER
!>          Le nombre de lignes du bloc supérieur gauche de X. 0 <= P <= M.
!
>

Q 
!>          Q est de type INTEGER
!>          Le nombre de colonnes du bloc supérieur gauche de X.
!>          0 <= Q <= MIN(P,M-P,M-Q).
!
>

THET

A 
!>          THETA est un tableau REAL de dimension (Q)
!>          À l'entrée, les angles THETA(1),...,THETA(Q) qui, avec
!>          PHI(1), ...,PHI(Q-1), définissent la matrice sous forme
!>          de blocs bidiagonaux. À la sortie, les angles dont les
!>          cosinus et sinus définissent les blocs diagonaux dans la
!>          décomposition CS.
!
>

PH

I 
!>          PHI est un tableau REAL de dimension (Q-1)
!>          Les angles PHI(1),...,PHI(Q-1) qui, avec THETA(1),...,
!>          THETA(Q), définissent la matrice sous forme de blocs
!>          bidiagonaux.
!
>

U

1 
!>          U1 est un tableau COMPLEX de dimension (LDU1,P)
!>          À l'entrée, une matrice P par P. À la sortie, U1 est post-multiplié
!>          par la matrice de vecteurs singuliers gauche commune à [ B11 ; 0 ] et
!>          [ B12 0 0 ; 0 -I 0 0 ].
!
>

LDU

1 
!>          LDU1 est de type INTEGER
!>          La dimension principale du tableau U1, LDU1 >= MAX(1,P).
!
>

U

2 
!>          U2 est un tableau COMPLEX de dimension (LDU2,M-P)
!>          À l'entrée, une matrice (M-P) par (M-P). À la sortie, U2 est
!>          post-multiplié par la matrice de vecteurs singuliers gauche commune à
!>          [ B21 ; 0 ] et [ B22 0 0 ; 0 0 I ].
!
>

LDU

2 
!>          LDU2 est de type INTEGER
!>          La dimension principale du tableau U2, LDU2 >= MAX(1,M-P).
!
>

V1

T 
!>          V1T est un tableau COMPLEX de dimension (LDV1T,Q)
!>          À l'entrée, une matrice Q par Q. À la sortie, V1T est pré-multiplié
!>          par la transposée conjuguée de la matrice de vecteurs singuliers
!>          droite commune à [ B11 ; 0 ] et [ B21 ; 0 ].
!
>

LDV1

T 
!>          LDV1T est de type INTEGER
!>          La dimension principale du tableau V1T, LDV1T >= MAX(1,Q).
!
>

V2

T 
!>          V2T est un tableau COMPLEX de dimension (LDV2T,M-Q)
!>          À l'entrée, une matrice (M-Q) par (M-Q). À la sortie, V2T est
!>          pré-multiplié par la transposée conjuguée de la matrice de
!>          vecteurs singuliers droite commune à [ B12 0 0 ; 0 -I 0 ] et
!>          [ B22 0 0 ; 0 0 I ].
!
>

LDV2

T 
!>          LDV2T est de type INTEGER
!>          La dimension principale du tableau V2T, LDV2T >= MAX(1,M-Q).
!
>

B11

D 
!>          B11D est un tableau REAL de dimension (Q)
!>          Lorsque CBBCSD converge, B11D contient les cosinus de THETA(1),
!>          ..., THETA(Q). Si CBBCSD ne parvient pas à converger, alors B11D
!>          contient la diagonale du bloc supérieur gauche partiellement
!>          réduit.
!
>

B11

E 
!>          B11E est un tableau REAL de dimension (Q-1)
!>          Lorsque CBBCSD converge, B11E contient des zéros. Si CBBCSD ne
!>          parvient pas à converger, alors B11E contient la surdiagonale du
!>          bloc supérieur gauche partiellement réduit.
!
>

B12

D 
!>          B12D est un tableau REAL de dimension (Q)
!>          Lorsque CBBCSD converge, B12D contient les sinus négatifs de
!>          THETA(1), ..., THETA(Q). Si CBBCSD ne converge pas, alors
!>          B12D contient la diagonale du bloc supérieur-droit partiellement
!>          réduit.
!
>

B12

E 
!>          B12E est un tableau REAL, dimension (Q-1)
!>          Lorsque CBBCSD converge, B12E contient des zéros. Si CBBCSD
!>          ne converge pas, alors B12E contient la sous-diagonale du
!>          bloc supérieur-droit partiellement réduit.
!
>

B21

D 
!>          B21D est un tableau REAL, dimension (Q)
!>          Lorsque CBBCSD converge, B21D contient les sinus négatifs de
!>          THETA(1), ..., THETA(Q). Si CBBCSD ne converge pas, alors
!>          B21D contient la diagonale du bloc inférieur-gauche
!>          partiellement réduit.
!
>

B21

E 
!>          B21E est un tableau REAL, dimension (Q-1)
!>          Lorsque CBBCSD converge, B21E contient des zéros. Si CBBCSD
!>          ne converge pas, alors B21E contient la sous-diagonale du
!>          bloc inférieur-gauche partiellement réduit.
!
>

B22

D 
!>          B22D est un tableau REAL, dimension (Q)
!>          Lorsque CBBCSD converge, B22D contient les sinus négatifs de
!>          THETA(1), ..., THETA(Q). Si CBBCSD ne converge pas, alors
!>          B22D contient la diagonale du bloc inférieur-droit
!>          partiellement réduit.
!
>

B22

E 
!>          B22E est un tableau REAL, dimension (Q-1)
!>          Lorsque CBBCSD converge, B22E contient des zéros. Si CBBCSD
!>          ne converge pas, alors B22E contient la sous-diagonale du
!>          bloc inférieur-droit partiellement réduit.
!
>

RWOR

K 
!>          RWORK est un tableau REAL, dimension (MAX(1,LRWORK))
!>          À la sortie, si INFO = 0, RWORK(1) renvoie le LRWORK optimal.
!
>

LRWOR

K 
!>          LRWORK est INTEGER
!>          La dimension du tableau RWORK. LRWORK >= MAX(1,8*Q).
!>
!>          Si LRWORK = -1, alors une interrogation d'espace de travail est
!>          supposée ; la routine calcule uniquement la taille optimale du
!>          tableau RWORK, renvoie cette valeur comme première entrée du
!>          tableau de travail, et aucun message d'erreur lié à LRWORK n'est
!>          émis par XERBLA.
!
>

INF

O 
!>          INFO est INTEGER
!>          = 0 :  sortie réussie.
!>          < 0 :  si INFO = -i, le i-ème argument avait une valeur
!>                 illégale.
!>          > 0 :  si CBBCSD n'a pas convergé, INFO spécifie le nombre
!>                 d'entrées non nulles dans PHI, et B11D, B11E, etc.,
!>                 contiennent la matrice partiellement réduite.
!
>

Paramètres internes

: 
!>  TOLMUL  REAL, par défaut = MAX(10,MIN(100,EPS**(-1/8)))
!>          TOLMUL contrôle le critère de convergence de la boucle QR.
!>          Les angles THETA(i), PHI(i) sont arrondis à 0 ou PI/2 lorsqu'ils
!>          sont à moins de TOLMUL*EPS de l'une ou l'autre limite.
!
>

Références

:
[1] Brian D. Sutton. Computing the complete CS decomposition. Numer. Algorithms, 50(1):33-65,
2009.
