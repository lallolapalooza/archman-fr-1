BUDGIE-WM(1) Commandes utilisateur BUDGIE-WM(1)

NOM

budgie-wm - wrapper autour de libmutter qui forme la gestion des fenêtres pour budgie

DESCRIPTION

Usage :

budgie-wm [OPTION?]

Options d'aide :

-h, --help
Afficher les options d'aide

Options d'application :

--sm-disable
Désactiver la connexion au gestionnaire de session
-r, --replace
Remplacer le gestionnaire de fenêtres en cours d'exécution
--sm-client-id=ID
Spécifier l'ID de gestion de session
-d, --display=DISPLAY
Affichage X à utiliser
--sm-save-file=FICHIER
Initialiser la session à partir du fichier de sauvegarde
--sync
Rendre les appels X synchrones
--wayland
Exécuter en tant que compositeur Wayland
--nested
Exécuter en tant que compositeur imbriqué
--no-x11
Exécuter le compositeur Wayland sans démarrer Xwayland
--wayland-display
Spécifier le nom d'affichage Wayland à utiliser
--display-server
Exécuter en tant que serveur d'affichage complet, plutôt qu'imbriqué
--headless
Exécuter en tant que serveur d'affichage sans tête
--virtual-monitor
Ajouter un moniteur virtuel persistant (LxH ou LxH@R)
--x11
Exécuter avec le backend X11
