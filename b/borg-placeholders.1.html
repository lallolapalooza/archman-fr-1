NOM

borg-placeholders - Détails concernant les espaces réservés

DESCRIPTION

Les URLs de dépôt (ou d'archive), les valeurs pour --prefix, --glob-archives, --comment et --remote-path supportent ces espaces réservés :

{hostname}
Le nom d'hôte (court) de la machine.
{fqdn}
Le nom de domaine complet de la machine.
{reverse-fqdn}
Le nom de domaine complet de la machine en notation inversée.
{now}
La date et l'heure locales actuelles, par défaut au format ISO-8601. Vous pouvez également fournir votre propre chaîne de format https://docs.python.org/3.10/library/datetime.html#strftime-and-strptime-behavior , par exemple {now:%Y-%m-%d_%H:%M:%S}
{utcnow}
La date et l'heure UTC actuelles, par défaut au format ISO-8601. Vous pouvez également fournir votre propre chaîne de format https://docs.python.org/3.10/library/datetime.html#strftime-and-strptime-behavior , par exemple {utcnow:%Y-%m-%d_%H:%M:%S}
{user}
Le nom d'utilisateur (ou l'UID, si aucun nom n'est disponible) de l'utilisateur exécutant borg.
{pid}
L'ID du processus actuel.
{borgversion}
La version de borg, par exemple : 1.0.8rc1
{borgmajor}
La version de borg, seulement la version majeure, par exemple : 1
{borgminor}
La version de borg, seulement les versions majeure et mineure, par exemple : 1.0
{borgpatch}
La version de borg, seulement les versions majeure, mineure et de correctif, par exemple : 1.0.8

Si des accolades littérales doivent être utilisées, doublez-les pour les échapper :

borg create /chemin/vers/repo::{{texte_literal}}

Exemples :

borg create /chemin/vers/repo::{hostname}-{user}-{utcnow} ...
borg create /chemin/vers/repo::{hostname}-{now:%Y-%m-%d_%H:%M:%S} ...
borg prune --glob-archives '{hostname}-*' ...

NOTE :

systemd utilise une syntaxe difficile et non standard pour les lignes de commande dans les fichiers d'unité (voir la page de manuel de systemd.unit(5)).

Lors de l'invocation de borg à partir de fichiers d'unité, portez une attention particulière à l'échappement, surtout lors de l'utilisation des espaces réservés now/utcnow, car systemd effectue son propre remplacement de variables basé sur % même dans du texte entre guillemets. Pour éviter l'interférence de systemd, doublez tous les signes de pourcentage ({hostname}-{now:%Y-%m-%d_%H:%M:%S} devient {hostname}-{now:%%Y-%%m-%%d_%%H:%%M:%%S}).
