NOM

biburl2doi.pl - convertir les URL pointant vers doi.org en DOI

SYNTAXE

biburl2doi [-D] [-o sortie] fichier_bib

OPTIONS

-D
Ne pas supprimer les URL converties en DOI
-o sortie
Fichier de sortie. Si cette option n'est pas utilisée, le nom du fichier de sortie est formé en ajoutant "_cleaned" au fichier d'entrée.

DESCRIPTION

Le script reconnaît les champs d'URL du type "http://dx.doi.org" et leurs variantes et les convertit en champs DOI.
