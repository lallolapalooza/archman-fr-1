BIO_socket_wait(3ssl)

Paquet: openssl

Licences: Apache-2.0

BIO_SOCKET_WAIT(3ssl) OpenSSL BIO_SOCKET_WAIT(3ssl)

NOM

BIO_socket_wait, BIO_wait, BIO_do_connect_retry - Fonctions utilitaires de connexion BIO

SYNTAXE

#include <openssl/bio.h>
#ifndef OPENSSL_NO_SOCK
int BIO_socket_wait(int fd, int for_read, time_t max_time);
#endif
int BIO_wait(BIO *bio, time_t max_time, unsigned int nap_milliseconds);
int BIO_do_connect_retry(BIO *bio, int timeout, int nap_milliseconds);

DESCRIPTION

BIO_socket_wait() attend sur le socket fd pour la lecture si for_read est différent de 0, sinon pour l'écriture, au plus jusqu'à max_time. Elle réussit immédiatement si max_time == 0 (ce qui signifie qu'aucun délai d'attente n'est donné).

BIO_wait() attend au plus jusqu'à max_time sur le bio donné (typiquement basé sur un socket), pour la lecture si le bio est censé lire, sinon pour l'écriture. Elle est utilisée par BIO_do_connect_retry() et peut être utilisée conjointement avec BIO_read(3). Elle réussit immédiatement si max_time == 0 (ce qui signifie qu'aucun délai d'attente n'est donné). Si les sockets ne sont pas disponibles, elle prend en charge le polling en réussissant après avoir dormi au plus pendant le nap_milliseconds donné afin d'éviter une boucle d'interrogation serrée. Via nap_milliseconds, l'appelant détermine la granularité du polling.

BIO_do_connect_retry() se connecte via le bio donné. Elle réessaie BIO_do_connect() autant que nécessaire pour obtenir un résultat définitif, c'est-à-dire, la connexion a réussi, le délai d'attente a été atteint, ou une erreur s'est produite. Pour les BIO non bloquants et potentiellement même non-sockets, elle sonde toutes les nap_milliseconds et dort entre-temps en utilisant BIO_wait(). Si nap_milliseconds est < 0, une valeur par défaut de 100 ms est utilisée. Si le paramètre timeout est > 0, cela indique le nombre maximal de secondes à attendre jusqu'à ce que la connexion soit établie ou qu'une erreur définitive se produise. Une valeur de 0 permet d'attendre indéfiniment (c'est-à-dire, aucun délai d'attente), tandis qu'une valeur < 0 signifie que BIO_do_connect() est tentée une seule fois. La fonction peut, directement ou indirectement, appeler ERR_clear_error().

VALEURS DE RETOUR

BIO_socket_wait(), BIO_wait() et BIO_do_connect_retry() retournent -1 en cas d'erreur, 0 en cas de délai d'attente, et 1 en cas de succès.

VOIR AUSSI

BIO_do_connect(3), BIO_read(3)

HISTORIQUE

BIO_socket_wait(), BIO_wait() et BIO_do_connect_retry() ont été ajoutées dans OpenSSL 3.0.
