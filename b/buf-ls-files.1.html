NOM

buf-ls-files - Lister les fichiers Protobuf

SYNOPIS

buf ls-files [flags]

DESCRIPTION

Le premier argument est la source, le module ou l'image à lister, qui doit être l'un des formats [binpb,dir,git,json,mod,protofile,tar,txtpb,yaml,zip]. Par défaut, il s'agit de "." si aucun argument n'est spécifié.

OPTIONS

--config="" Le fichier buf.yaml ou les données à utiliser pour la configuration

--disable-symlinks[=false] Ne pas suivre les liens symboliques lors de la lecture des sources ou de la configuration à partir du système de fichiers local. Par défaut, les liens symboliques sont suivis dans cette CLI, mais jamais suivis sur le Registre de Schémas Buf

--exclude-path=[] Exclure des fichiers ou des répertoires spécifiques, par exemple "proto/a/a.proto", "proto/a". Si spécifié plusieurs fois, l'union est prise.

--format="text" Le format dans lequel imprimer les fichiers .proto. Doit être l'un des [text,json,import]

-h, --help[=false] Aide pour ls-files

--include-importable[=false] Inclure tous les fichiers .proto qui sont importables par l'entrée. --include-imports est redondant si ceci est défini.

--include-imports[=false] Inclure les importations.

--path=[] Limiter aux fichiers ou répertoires spécifiques, par exemple "proto/a/a.proto", "proto/a". Si spécifié plusieurs fois, l'union est prise.

OPTIONS HÉRITÉES DES COMMANDES PARENTES

--debug[=false] Activer la journalisation de débogage

--log-format="color" Le format du journal [text,color,json]

--timeout=0s La durée avant expiration, la régler à 0 signifie pas d'expiration
