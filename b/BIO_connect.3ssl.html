BIO_connect(3ssl)

Paquet: openssl

Licences: Apache-2.0

BIO_CONNECT(3ssl) OpenSSL BIO_CONNECT(3ssl)

NOM

BIO_socket, BIO_bind, BIO_connect, BIO_listen, BIO_accept_ex, BIO_closesocket - Routines de configuration de la communication socket BIO

SYNOPIS

#include <openssl/bio.h>
int BIO_socket(int domain, int socktype, int protocol, int options);
int BIO_bind(int sock, const BIO_ADDR *addr, int options);
int BIO_connect(int sock, const BIO_ADDR *addr, int options);
int BIO_listen(int sock, const BIO_ADDR *addr, int options);
int BIO_accept_ex(int accept_sock, BIO_ADDR *peer, int options);
int BIO_closesocket(int sock);

DESCRIPTION

BIO_socket() crée un socket dans le domaine domain, de type socktype et protocol. Les options du socket ne sont actuellement pas utilisées, mais sont présentes pour une utilisation future.

BIO_bind() lie l'adresse source et le service à un socket et peut être utile avant d'appeler BIO_connect(). Les options peuvent inclure BIO_SOCK_REUSEADDR, qui est décrite dans "FLAGS" ci-dessous.

BIO_connect() connecte sock à l'adresse et au service fournis par addr. Les options de connexion peuvent être zéro ou toute combinaison de BIO_SOCK_KEEPALIVE, BIO_SOCK_NONBLOCK et BIO_SOCK_NODELAY. Les indicateurs sont décrits dans "FLAGS" ci-dessous.

BIO_listen() fait en sorte que sock commence à écouter sur l'adresse et le service fournis par addr. Les options de connexion peuvent être zéro ou toute combinaison de BIO_SOCK_KEEPALIVE, BIO_SOCK_NONBLOCK, BIO_SOCK_NODELAY, BIO_SOCK_REUSEADDR et BIO_SOCK_V6_ONLY. Les indicateurs sont décrits dans "FLAGS" ci-dessous.

BIO_accept_ex() attend une connexion entrante sur le socket donné accept_sock. Lorsqu'il reçoit une connexion, l'adresse et le port du pair sont stockés dans peer si celui-ci n'est pas NULL. Les options d'acceptation peuvent être zéro ou BIO_SOCK_NONBLOCK, et sont appliquées sur le socket accepté. Les indicateurs sont décrits dans "FLAGS" ci-dessous.

BIO_closesocket() ferme sock.

INDICATEURS

BIO_SOCK_KEEPALIVE
Active l'envoi régulier de messages keep-alive.
BIO_SOCK_NONBLOCK
Met le socket en mode non bloquant.
BIO_SOCK_NODELAY
Correspond à TCP_NODELAY, et désactive l'algorithme de Nagle. Avec cette option activée, toute donnée sera envoyée dès que possible au lieu d'être mise en tampon jusqu'à ce qu'il y en ait suffisamment pour que le socket puisse l'envoyer en une seule fois.
BIO_SOCK_REUSEADDR
Essaye de réutiliser la combinaison adresse et port pour un port récemment fermé.
BIO_SOCK_V6_ONLY
Lors de la création d'un socket IPv6, il ne doit écouter que les adresses IPv6 et non les adresses IPv4 mappées en IPv6.
BIO_SOCK_TFO
Active TCP Fast Open sur le socket. Utilise les API appropriées sur les systèmes d'exploitation pris en charge, y compris Linux, macOS et FreeBSD. Peut être utilisé avec BIO_connect(), BIO_set_conn_mode(), BIO_set_bind_mode() et BIO_listen(). Sur les noyaux Linux antérieurs à 4.14, utilisez BIO_set_conn_address() pour spécifier l'adresse du pair avant de démarrer la négociation TLS.

Ces indicateurs sont des indicateurs de bits, ils doivent donc être combinés avec l'opérateur "|", par exemple :

BIO_connect(sock, addr, BIO_SOCK_KEEPALIVE | BIO_SOCK_NONBLOCK);

VALEURS DE RETOUR

BIO_socket() renvoie le numéro de socket en cas de succès ou INVALID_SOCKET (-1) en cas d'erreur. Lorsqu'une erreur s'est produite, la pile d'erreurs OpenSSL contient les données d'erreur et errno contient l'erreur système.

BIO_bind(), BIO_connect() et BIO_listen() renvoient 1 en cas de succès ou 0 en cas d'erreur. Lorsqu'une erreur s'est produite, la pile d'erreurs OpenSSL contient les données d'erreur et errno contient l'erreur système.

BIO_accept_ex() renvoie le socket accepté en cas de succès ou INVALID_SOCKET (-1) en cas d'erreur. Lorsqu'une erreur s'est produite, la pile d'erreurs OpenSSL contient les données d'erreur et errno contient l'erreur système.

HISTORIQUE
