bupstash-diff(1)

Paquet: bupstash

Licences: MIT

() ()

SYNTAXE

Compare deux instantanés en imprimant le résumé sur la sortie standard.

bupstash diff [OPTIONS] REQUETE1... :: REQUETE2...

DESCRIPTION

bupstash diff récupère deux listes d'instantanés du serveur distant et les compare, imprimant la sortie de la différence ligne par ligne sur la sortie standard. À titre de cas spécial, si une requête commence par ´./´ ou ´/´, une liste temporaire est créée pour ce répertoire local pour comparaison.

bupstash diff est préférable à l'exécution de diff traditionnel sur la sortie de bupstash list-contents car il prend en compte la précision complète des horodatages et aussi le hachage de fichier stocké lors de l'opération de différence.

Bupstash prend en charge l'ignorance d'éléments dans la comparaison des différences pour aider à l'analyse. Des exemples utiles sont les valeurs de --ignore comme times pour ignorer les horodatages de modification de fichier et content pour ignorer les changements de taille et de hachage de fichier.

FORMAT DE SORTIE

La sortie est cohérente avec celle de bupstash list-contents, sauf que chaque ligne est précédée de + ou de - représentant respectivement les éléments supprimés ou ajoutés.

Spécifier --format modifie le format de sortie sous-jacent tel décrit par bupstash-list-contents(1). Les lignes sont toujours précédées de + ou de - quelle que soit la méthode de sortie.

LANGAGE DES REQUETES

Pour une documentation complète sur le langage des requêtes, voir bupstash-query-language(7).

MISE EN CACHE DES REQUETES

La commande diff utilise les mêmes mécanismes de mise en cache des requêtes que bupstash-list(1), consultez cette page pour plus d'informations sur le cache des requêtes.

OPTIONS

-r, --repository REPO
Le dépôt auquel se connecter, , peut être de la forme ssh://$SERVEUR/$CHEMIN pour les dépôts distants si l'accès ssh est configuré. Si non spécifié, est défini sur BUPSTASH_REPOSITORY.
-k, --key CLE
Clé utilisée pour déchiffrer les données et les métadonnées. Si non définie, la valeur par défaut est BUPSTASH_KEY.
--query-cache CHEMIN
Chemin vers le fichier de cache de requêtes, la valeur par défaut est l'un des éléments suivants, dans l'ordre, à condition que les variables d'environnement appropriées soient définies : $BUPSTASH_QUERY_CACHE, $XDG_CACHE_HOME/.cache/bupstash/bupstash.qcache ou $HOME/.cache/bupstash/bupstash.qcache.
-i, --ignore
Liste séparée par des virgules des attributs de fichiers à ignorer dans les comparaisons. Les éléments valides sont ´content,dev,devnos,inode,type,perms,nlink,uid,gid,times,xattrs´
--relaxed
Raccourci pour --ignore ´dev,inode,nlink,uid,gid,times,xattrs´. Cette option est utile pour comparer le contenu sans trop se soucier des métadonnées spécifiques à la machine.
--{gauche,droite}-pick CHEMIN
Effectuer la différence sur un sous-répertoire de la requête gauche/droite.
--indexer-threads N
Nombre de threads processeurs à utiliser pour le hachage de fichiers parallèle en pipeline et la lecture des métadonnées. La valeur par défaut est le nombre de processeurs.
--xattrs
Récupérer les xattrs lors de l'indexation de répertoires locaux.
--format FORMAT
Définir le format de sortie sur l'un des ´human´, ´jsonl´.
--utc-timestamps
Afficher et rechercher par rapport aux horodatages en temps UTC au lieu du temps local.
--no-progress
Supprimer les indicateurs de progression (les indicateurs de progression sont également supprimés lorsque stderr n'est pas un terminal interactif).
-q, --quiet
Soyez silencieux, implique --no-progress.

ENVIRONNEMENT

BUPSTASH_REPOSITORY
Le dépôt auquel se connecter. Peut être de la forme ssh://$SERVEUR/$CHEMIN pour les dépôts distants si l'accès ssh est configuré.
BUPSTASH_REPOSITORY_COMMAND
Une commande à exécuter pour se connecter à une instance de bupstash-serve(1). Cela permet des connexions plus complexes au dépôt pour des cas d'utilisation moins courants.
BUPSTASH_KEY
Chemin vers une clé primaire qui sera utilisée pour déchiffrer les données et les métadonnées.
BUPSTASH_KEY_COMMAND
Une commande à exécuter qui doit imprimer les données de la clé, peut être utilisée à la place de BUPSTASH_KEY pour récupérer la clé à partir d'endroits arbitraires tels que le réseau ou d'autres stockages secrets.
BUPSTASH_QUERY_CACHE
Chemin vers le fichier de cache des requêtes à utiliser.

EXEMPLES

Comparer deux instantanés par requête

$ bupstash diff id="14eb*" :: id="57de*" - -rw-r--r-- 1.1kB hello.txt + -rw-r--r-- 1.3kB goodbye.txt

Comparer un instantané et un répertoire local

$ bupstash diff --left-pick files --relaxed id="57de*" :: ./files
