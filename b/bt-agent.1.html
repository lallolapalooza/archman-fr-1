NOM

bt-agent - un agent Bluetooth

SYNTAXE

bt-agent [OPTION...]

Options d'aide :
-h, --help

Options de l'application :
-c, --capability=<capacité>
-p, --pin
-d, --daemon

DESCRIPTION

Cet utilitaire interactif est utilisé pour gérer les requêtes Bluetooth entrantes (par exemple, demande de code PIN, demande d'autorisation d'une connexion/requête de service, etc.).

OPTIONS

-h, --help
Afficher l'aide

-c, --capability <capacité>
Spécifier les capacités d'entrée et de sortie de l'agent.
`capacité` peut être l'une des suivantes :
DisplayOnly
DisplayYesNo (par défaut)
KeyboardOnly
NoInputNoOutput
(si cette option n'est pas définie, `DisplayYesNo' sera utilisé)

-p, --pin <chemin du fichier<gt>
Utiliser un fichier contenant une liste de codes d'autorisation pour chaque appareil par nom ou adresse MAC.
Le contenu du fichier doit être dans le format suivant :
AA:BB:CC:DD:EE:FF 123456
NomAppareilDistant * (accepter n'importe quel code PIN)
Si un fichier PIN est inclus, il vérifiera la clé d'appariement de l'appareil d'appariement par rapport à la clé incluse dans le fichier. Il autorisera automatiquement l'appareil si la clé correspond, sinon il demandera une autorisation manuelle à l'utilisateur.

-d, --daemon
Exécuter l'agent en tant que processus d'arrière-plan (démon).
L'agent s'appuiera sur un fichier PIN et ne demandera aucune autorisation manuelle à l'utilisateur. Tous les appareils qui tentent de s'apparier sans clé d'accès valide définie dans le fichier PIN seront automatiquement rejetés.
