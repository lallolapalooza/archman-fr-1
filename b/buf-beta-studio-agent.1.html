NOM

buf-beta-studio-agent - Exécute un serveur HTTP(S) comme agent Studio

SYNTAXE

buf beta studio-agent [indicateurs]

DESCRIPTION

Exécute un serveur HTTP(S) comme agent Studio

OPTIONS

--bind="127.0.0.1" L'adresse qui sera exposée pour accepter les requêtes HTTP

--ca-cert="" Le certificat CA à utiliser dans la configuration TLS client et serveur

--client-cert="" Le certificat à utiliser dans la configuration TLS client

--client-key="" La clé à utiliser dans la configuration TLS client

--disallowed-header=[] Les noms d'en-tête qui sont interdits par cet agent. Lorsque l'agent reçoit une requête enveloppée avec ces en-têtes définis, il renverra une erreur au lieu de transférer la requête au serveur cible. Plusieurs en-têtes sont ajoutés s'ils sont spécifiés plusieurs fois

--forward-header=[] Les en-têtes à transférer via l'agent au serveur cible. Doit être une paire clé-valeur séparée par un signe égal (comme --forward-header=fromHeader1=toHeader1). Plusieurs paires d'en-têtes sont ajoutées si elles sont spécifiées plusieurs fois

-h, --help[=false] Aide pour studio-agent

--origin="https://buf.build" L'origine autorisée pour les options CORS

--port="8080" Le port qui sera exposé pour accepter les requêtes HTTP

--private-network[=false] Utiliser l'agent avec le CORS de réseau privé

--server-cert="" Le certificat à utiliser dans la configuration TLS serveur

--server-key="" La clé à utiliser dans la configuration TLS serveur

OPTIONS HÉRITÉES DES COMMANDES PARENTALES

--debug[=false] Activer la journalisation de débogage

--log-format="color" Le format de journalisation [text,color,json]

--timeout=0s La durée avant expiration, la régler à 0 signifie pas d'expiration
