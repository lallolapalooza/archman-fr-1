NOM

buildah-containers - Liste les conteneurs de travail et leurs images de base.

SYNTAXE

buildah containers [options]

DESCRIPTION

Liste les conteneurs qui semblent être des conteneurs de travail Buildah, leurs noms et IDs, ainsi que les noms et IDs des images à partir desquelles ils ont été initialisés.

OPTIONS

--all, -a

Liste les informations sur tous les conteneurs, y compris ceux qui n'ont pas été créés par et ne sont pas utilisés par Buildah. Les conteneurs créés par Buildah sont indiqués par une '*' dans la colonne 'BUILDER'.

--filter, -f

Filtre la sortie en fonction des conditions fournies.

Les filtres valides sont listés ci-dessous :

Filtre Description
id [ID] ID du conteneur
name [Nom] Nom du conteneur
ancestor [NomImage] Image ou descendant utilisé pour créer le conteneur

--format

Affiche joliment les conteneurs en utilisant un modèle Go.

Les espaces réservés valides pour le modèle Go sont listés ci-dessous :

Espace réservé Description
.ContainerID ID du conteneur
.Builder Indique si le conteneur a été créé par buildah
.ImageID ID de l'image
.ImageName Nom de l'image
.ContainerName Nom du conteneur

--json

Affiche la sortie au format JSON.

--noheading, -n

Omis les en-têtes de table de la liste des conteneurs.

--notruncate

Ne tronque pas les IDs et les noms d'images dans la sortie.

--quiet, -q

Affiche uniquement les IDs des conteneurs.
