Bundle__Image__Info__Everything(3pm)

Paquet: perl-image-info

Licences: PerlArtistic, GPL

Bundle::Image::Info::Everything(3) Documentation Perl fournie par la communauté Bundle::Image::Info::Everything(3)

NOM

Bundle::Image::Info::Everything - support complet pour Image::Info

SYNOPSIS

perl -MCPAN -e 'install Bundle::Image::Info::Everything'

CONTENU

Image::Info - le module de base Image::Info

Compress::Zlib - tout pour le traitement PNG

XML::LibXML::Reader - tout pour le traitement SVG

XML::Simple - tout pour le traitement SVG

Image::Xbm 1.07 - tout pour le traitement XBM

Image::Xpm 1.10 - tout pour le traitement XPM

DESCRIPTION

Ce paquet installe tout ce qui est nécessaire pour Image::Info.

LISTE DES SOURCES

La liste "CONTENU" est créée en résolvant manuellement tous les contenus des fichiers Bundle suivants :

Bundle::Image::Info::PNG
Bundle::Image::Info::SVG
Bundle::Image::Info::XBM
Bundle::Image::Info::XPM

Malheureusement, le module CPAN ne peut pas gérer les paquets définis récursivement, donc cela a dû être fait.
