NAME

bandit - Security linter for Python code.

SYNOPSIS

bandit [options] [path ...]

DESCRIPTION

Bandit is a tool designed to find common security issues in Python code. It works by navigating the Abstract Syntax Tree (AST) of Python code and checking for specific patterns that indicate security vulnerabilities. Bandit can be used to analyze individual files, directories, or even entire Python packages.

Bandit checks for a wide range of security concerns, including:

  • Use of insecure functions (e.g., eval(), exec()).
  • SQL injection vulnerabilities.
  • Cross-site scripting (XSS) vulnerabilities.
  • Insecure cryptographic practices.
  • Hardcoded passwords or sensitive information.
  • Insecure deserialization.
  • And many more.

The output of Bandit provides detailed information about each identified issue, including the file name, line number, the specific check that failed, and a severity level.

OPTIONS

-r, --recursive
Recursively search for Python files in directories.
-p, --profile PROFILE
Use the specified profile for configuration. Profiles define which checks to run and how to configure them.
-l, --list-tests
List all available tests that Bandit can perform.
-x, --exclude FILE,DIR,...
Comma-separated list of files and directories to exclude from the scan.
-f, --format FORMAT
Output format. Supported formats include: text, json, csv, html, pylint.
-o, --output FILE
Write output to a file instead of stdout.
-c, --config-file FILE
Path to the Bandit configuration file. If not specified, Bandit looks for .bandit in the current directory and its parents.
--version
Show program's version number and exit.
-h, --help
Show help message and exit.

FILES

~/.bandit
Default configuration file for Bandit.
.bandit
Project-specific configuration file. If present in the current directory or a parent directory, it overrides the default configuration.

EXAMPLES

Scan a single Python file:

bandit my_script.py

Scan a directory recursively and output results in JSON format:

bandit -r my_project/ -f json

Scan a project, excluding a specific directory, and save the output to a file:

bandit -r . -x tests/ -o bandit-report.txt
