DESCRIPTIO

N

La commande pkg-install installe les paquets spécifiés (la première forme), tous les paquets retenus (la deuxième forme, voir bpkg-pkg-status(1)), ou tous les paquets retenus qui correspondent à l'un des motifs génériques spécifiés (la troisième forme). De plus, les dépendances immédiates ou toutes les dépendances de ces paquets peuvent également être installées en spécifiant les options --immediate|-i ou --recursive|-r, respectivement. En interne, cette commande ne fait pas grand-chose de plus que d'exécuter b install. Dans la première forme, les paquets spécifiés doivent avoir été préalablement configurés avec bpkg-pkg-build(1) ou bpkg-pkg-config

ure(1).

Des variables de ligne de commande supplémentaires (vars, normalement config.*) peuvent être passées au système de construction. Ces variables s'appliquent à tous les paquets spécifiés mais peuvent aussi être spécifiées pour ne s'appliquer qu'à des paquets spécifiques en utilisant le mécanisme de groupement d'arguments (voir bpkg-argument-grouping(1) pour plus de détails). En particulier, ce mécanisme peut être utilisé pour spécifier le répertoire d'installation, par exemple

: 
bpkg install config.install.root=/usr/local \
             config.install.sudo=sudo       \
             libfoo
libbar

Alternativement, le répertoire d'installation peut être spécifié une seule fois lors de la création de la configuration (bpkg-cfg-c

reate
(1)).

FICHIERS D'OPTIONS PAR

DÉFAUT

Voir bpkg-default-options-files(1) pour un aperçu des fichiers d'options par défaut. Pour la commande pkg-install, le répertoire de départ de la recherche est le répertoire de configuration. Les fichiers d'options suivants sont recherchés dans chaque répertoire et, s'ils sont trouvés, chargés dans l'ordre listé

: 
bpkg.options
bpkg-pkg-install.
options

Les options de commande pkg-install suivantes ne peuvent pas être spécifiées dans les fichiers d'options par défaut

:
