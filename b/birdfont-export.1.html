BIRDFONT-EXPORT(1) Manuel des commandes générales BIRDFONT-EXPORT(1)

NOM

birdfont-export - générer des fichiers TTF, EOT et SVG à partir de fichiers BIRDFONT

SYNTAXE

birdfont-export [options] fichier

DESCRIPTION

birdfont-export génère des polices qui peuvent être installées sur votre ordinateur ou déployées sur votre site web.

Voir https://birdfont.org pour les cas d'utilisation.

OPTIONS

--filter [caractères]
Inclure uniquement ces caractères
-h, --help
Imprimer les options de la ligne de commande.
-o, --output [répertoire]
Écrire les fichiers dans ce répertoire
-s, --svg
Écrire la police SVG
-t, --ttf
Écrire les polices TTF et EOT

AUTEUR
