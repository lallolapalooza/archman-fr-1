NOM

btrfs-property - obtenir/définir/lister les propriétés pour un objet de système de fichiers donné

SYNTAXE

btrfs property <sous-commande> <arguments>

DESCRIPTION

btrfs property est utilisé pour obtenir/définir/lister les propriétés d'un objet de système de fichiers donné. L'objet peut être un inode (fichier ou répertoire), une sous-volume ou l'ensemble du système de fichiers.

btrfs property fournit une méthode unifiée et conviviale pour régler différentes propriétés btrfs au lieu d'utiliser la méthode traditionnelle comme chattr(1) https://man7.org/linux/man-pages/man1/chattr.1.html ou lsattr(1) https://man7.org/linux/man-pages/man1/lsattr.1.html.

Types d'objets

Une propriété peut s'appliquer à plusieurs types d'objets, donc dans certains cas, il est nécessaire de le spécifier explicitement, bien que ce ne soit pas nécessaire dans le cas le plus courant de fichiers et de répertoires.

Les sous-commandes prennent le paramètre -t, utilisez la première lettre comme raccourci (f/s/d/i) du type :

  • filesystem
  • subvolume
  • device
  • inode (fichier ou répertoire)

Propriétés d'inode

compression
algorithme de compression défini pour un inode (il n'est pas possible de définir le niveau de compression de cette manière), valeurs possibles :
  • lzo
  • zlib
  • zstd
  • no ou none - désactiver la compression (équivalent à chattr +m)
  • "" (chaîne vide) - définir la valeur par défaut

Note :

Ceci a été modifié dans la version 5.18 de btrfs-progs et nécessite le noyau 5.14 ou plus récent pour fonctionner.

Propriétés de sous-volume

ro
indicateur en lecture seule de sous-volume : true ou false. Veuillez également consulter la section INDICATEURS DE SOUS-VOLUME dans btrfs-subvolume(8) <> pour les implications possibles concernant l'envoi incrémental.

Propriétés de système de fichiers

label
étiquette du système de fichiers. Pour un système de fichiers non monté, fournissez un chemin vers un périphérique bloc comme objet. Pour un système de fichiers monté, spécifiez un point de montage.

SOUS-COMMANDE

get [-t <type>] <objet> [<nom>]
Lire la valeur d'une propriété nom de l'objet btrfs du type donné, un nom vide lira toutes les propriétés.
list [-t <type>] <objet>
Lister les propriétés disponibles avec leurs descriptions pour l'objet donné.
set [-f] [-t <type>] <objet> <nom> <valeur>
Définir la valeur de la propriété nom sur un objet btrfs donné.

Options

-f
Forcer le changement. La modification de certaines propriétés peut impliquer des vérifications de sécurité ou des changements supplémentaires qui dépendent de la sémantique des propriétés.

EXEMPLES

Définir la compression sur un fichier :

$ touch fichier1
$ btrfs prop get fichier1
[ sortie vide ]
$ btrfs prop set fichier1 compression zstd
$ btrfs prop get fichier1
compression=zstd

Rendre une sous-volume inscriptible en lecture seule :

$ btrfs subvol create subvol1
[ remplir subvol1 avec des données ]
$ btrfs prop get subvol1
ro=false
$ btrfs prop set subvol1 ro true
ro=true

STATUT DE RÉTRI

btrfs property renvoie un statut de sortie nul en cas de succès. Une valeur non nulle est retournée en cas d'échec.

DISPONIBILITÉ

btrfs fait partie de btrfs-progs. Veuillez vous référer à la documentation sur https://btrfs.readthedocs.io.
