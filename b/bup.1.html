NOM

bup - Programme de sauvegarde utilisant des sommes de contrôle roulantes et les formats de fichiers git

SYNTAXE

bup [options globales...] <commande> [options...]

DESCRIPTION

bup est un programme permettant de sauvegarder vos fichiers en utilisant le format de fichiers git.

Contrairement à git(1) lui-même, bup est optimisé pour la gestion d'ensembles de données énormes, y compris des fichiers individuels très volumineux (tels que des images de machines virtuelles). Cependant, une fois qu'un ensemble de sauvegarde est créé, il peut toujours être accédé à l'aide des outils git.

Les sous-commandes sont décrits dans des pages de manuel séparées. Par exemple, bup-init(1) couvre bup init.

OPTIONS GLOBALES

--version
affiche le numéro de version de bup. Équivalent à bup version.
-d, --bup-dir=BUP_DIR
utilise le paramètre BUP_DIR spécifié comme emplacement du dépôt bup, au lieu de le lire à partir de la variable d'environnement $BUP_DIR ou d'utiliser l'emplacement par défaut ~/.bup.

SOUS-COMMANDES COURAMMENT UTILISÉES

bup-fsck(1)
Vérifie les ensembles de sauvegarde pour détecter les dommages et ajoute des informations de redondance.
bup-ftp(1)
Navigue dans les ensembles de sauvegarde à l'aide d'un client de type ftp.
bup-fuse(1)
Monte vos ensembles de sauvegarde en tant que système de fichiers.
bup-help(1)
Affiche l'aide détaillée pour la commande donnée.
bup-index(1)
Crée ou affiche l'index des fichiers à sauvegarder.
bup-on(1)
Sauvegarde une machine distante sur la machine locale.
bup-restore(1)
Extrait des fichiers d'un ensemble de sauvegarde.
bup-save(1)
Sauvegarde des fichiers dans un ensemble de sauvegarde (note : exécutez d'abord « bup index »).
bup-web(1)
Lance un serveur web pour examiner les ensembles de sauvegarde.

SOUS-COMMANDES RAREMENT UTILISÉES

bup-damage(1)
Détruit délibérément des données.
bup-drecurse(1)
Liste récursivement les fichiers de votre système de fichiers.
bup-init(1)
Initialise un dépôt bup.
bup-join(1)
Récupère un fichier sauvegardé à l'aide de bup-split(1).
bup-ls(1)
Parcourt les fichiers de vos ensembles de sauvegarde.
bup-margin(1)
Détermine à quel point votre dépôt bup est proche de l'apocalypse.
bup-memtest(1)
Teste les statistiques d'utilisation de la mémoire de bup.
bup-midx(1)
Indexe les objets pour accélérer les sauvegardes futures.
bup-newliner(1)
Assure que les messages de progression ne se chevauchent pas avec la sortie.
bup-random(1)
Génère un flux de sortie aléatoire.
bup-server(1)
Le côté serveur de la relation client-serveur de bup.
bup-split(1)
Divise un seul fichier en son propre ensemble de sauvegarde.
bup-tick(1)
Attend jusqu'à une seconde.
bup-version(1)
Rapporte le numéro de version de votre copie de bup.

ENVIRONNEMENT

BUP_ASSUME_GIT_VERSION_IS_FINE
Si défini sur true, yes, ou 1, suppose que la version de git dans le chemin est acceptable.

VOIR AUSSI

git(1) et le fichier README de la distribution bup.

La page d'accueil de bup se trouve à http://github.com/bup/bup/.
