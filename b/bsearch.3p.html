DESCRIPTIO

N

La fonctionnalité décrite sur cette page de référence est alignée avec la norme ISO C. Tout conflit entre les exigences décrites ici et la norme ISO C est involontaire. Ce volume de POSIX.1‐2017 se conforme à la norme ISO

C.

La fonction bsearch() doit rechercher dans un tableau de objets nel, dont l'élément initial est pointé par base, un élément qui correspond à l'objet pointé par key. La taille de chaque élément du tableau est spécifiée par width. Si l'argument nel a la valeur zéro, la fonction de comparaison pointée par compar ne doit pas être appelée et aucune correspondance ne doit être

trouvée.

La fonction de comparaison pointée par compar doit être appelée avec deux arguments qui pointent vers l'objet key et vers un élément du tableau, dans cet

ordre.

L'application doit s'assurer que la fonction de comparaison pointée par compar ne modifie pas le contenu du tableau. L'implémentation peut réordonner les éléments du tableau entre les appels à la fonction de comparaison, mais ne doit pas modifier le contenu d'un élément individuel

quelconque.

L'implémentation doit s'assurer que le premier argument est toujours un pointeur vers la

clé.

Lorsque les mêmes objets (constitués de width octets, indépendamment de leurs positions actuelles dans le tableau) sont passés plus d'une fois à la fonction de comparaison, les résultats doivent être cohérents entre eux. C'est-à-dire que le même objet doit toujours se comparer de la même manière avec la

clé.

L'application doit s'assurer que la fonction renvoie un entier inférieur, égal ou supérieur à 0 si l'objet key est considéré respectivement comme inférieur à, correspondant à, ou supérieur à l'élément du tableau. L'application doit s'assurer que le tableau est constitué de tous les éléments qui se comparent inférieurs à, tous les éléments qui se comparent égaux à, et tous les éléments qui se comparent supérieurs à l'objet key, dans

cet
ordre.

VALEUR

RENVOYÉE

La fonction bsearch() doit renvoyer un pointeur vers un membre correspondant du tableau, ou un pointeur nul si aucune

correspondance n'est trouvée. Si deux membres ou plus
se comparent égaux, le membre renvoyé est indéterminé.

EXEMPLE

S

L'exemple ci-dessous recherche dans un tableau contenant des pointeurs vers des nœuds constitués d'une chaîne et de sa longueur. Le tableau est trié par ordre alphabétique sur la chaîne dans le nœud pointé par chaque

entrée.

Le fragment de code ci-dessous lit des chaînes et soit trouve le nœud correspondant et affiche la chaîne et sa longueur, soit affiche un message

d'erreur. 
#include <stdio.h>
#include <stdlib.h>
#include <string.
h> 
#define TABSIZE
1000 
struct node {                  /* Ceux-ci sont stockés dans le tableau. */
    char *string;
    int length;
};
struct node table[TABSIZE];    /* Tableau à rechercher. */
    .
    .
    .
{
    struct node *node_ptr, node;
    /* Routine pour comparer 2 nœuds. */
    int node_compare(const void *, const void *);
    .
    .
    .
    while (scanf("%ms", &node.string) != EOF) {
        node_ptr = (struct node *)bsearch((void *)(&node),
               (void *)table, TABSIZE,
               sizeof(struct node), node_compare);
        if (node_ptr != NULL) {
            (void)printf("string = %20s, length = %d\n",
                node_ptr->string, node_ptr->length);
        } else {
            (void)printf("not found: %s\n", node.string);
        }
        free(node.string);
    }
}
/*
    Cette routine compare deux nœuds sur la base d'un
    ordre alphabétique du champ string.
*/
int
node_compare(const void *node1, const void *node2)
{
    return strcoll(((const struct node *)node1)->string,
        ((const struct node *)node2)->string)
;
}

UTILISATION PAR

L'APPLICATION

Les pointeurs vers la clé et l'élément à la base du tableau doivent être de type pointeur-vers-élément

.

La fonction de comparaison n'a pas besoin de comparer chaque octet, de sorte que des données arbitraires peuvent être contenues dans les éléments en plus des valeurs being

compared.

En pratique, le tableau est

généralement trié selon la
fonction de comparaison.

JUSTIFICATIO

N

L'exigence selon laquelle le deuxième argument (ci-après désigné p) de la fonction de comparaison est un pointeur vers un élément du tableau implique que pour chaque appel, toutes les expressions suivantes sont non nulles

: 
( (char *)p - (char *)base
) % width == 0 (char *)p >
= (char *)base (char *)p <
(char *)base + nel * width
