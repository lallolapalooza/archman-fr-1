BATDIFF(1) Manuel des commandes générales BATDIFF(1)

NOM

batdiff - Différencie un fichier par rapport à l'index git actuel, ou affiche la différence entre deux fichiers.

DESCRIPTION

Ce script permet d'utiliser delta comme surligneur alternatif pour les différences.

UTILISATION


batdiff [OPTIONS] FICHIER
batdiff [OPTIONS] FICHIER AUTRE_FICHIER
batdiff --staged

ENVIRONNEMENT

Variable Description
BATDIFF_USE_DELTA=true Si delta est installé, utiliser delta par défaut.

OPTIONS

Court Long Description
-C --context=[LIGNES] Le nombre de lignes à afficher avant et après les lignes différentes.
--delta Afficher les différences en utilisant delta.
--color Forcer la sortie couleur.
--no-color Forcer la désactivation de la sortie couleur.
--paging=["jamais"/"toujours"] Activer/désactiver la pagination.
--pager=[PAGER] Spécifier le paginator à utiliser.
--terminal-width=[COLONNES] Générer la sortie pour la largeur de terminal spécifiée.
--staged Afficher les changements préparés (staged).

ATTENTION

En utilisant bat comme imprimeur :

- La coloration syntaxique dans les différences entre deux fichiers n'est pas supportée.
- La coloration syntaxique dans une différence de fichier unique nécessite bat >= 0.15.

En utilisant delta comme imprimeur :

- L'option --no-color ne supprime pas toute la sortie couleur.
