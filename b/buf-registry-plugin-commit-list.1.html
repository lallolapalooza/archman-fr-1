NOM

buf-registry-plugin-commit-list - Lister les commits des plugins

SYNTAXE

buf registry plugin commit list [indicateurs]

DESCRIPTION

Cette commande liste les commits d'un plugin basé sur la référence spécifiée. Pour une référence de commit, elle liste le commit lui-même. Pour une référence d'étiquette, elle liste les commits actuels et passés associés à cette étiquette. Si aucune référence n'est spécifiée, elle liste tous les commits de ce plugin.

OPTIONS

--digest-changes-only[=faux] Seulement les commits qui ont modifié les digests. Par défaut, tous les commits sont listés

--format="texte" Le format de sortie à utiliser. Doit être l'un de [texte, json]

-h, --help[=faux] Aide pour la liste

--page-size=10 La taille de la page

--page-token="" Le jeton de page. Si plus de résultats sont disponibles, une clé "next_page" est présente dans la sortie --format=json

--reverse[=faux] Inverse les résultats. Par défaut, ils sont ordonnés avec le plus récent en premier

OPTIONS HÉRITÉES DES COMMANDES PARENT

--debug[=faux] Activer la journalisation de débogage

--log-format="couleur" Le format du journal [texte, couleur, json]

--timeout=0s La durée avant expiration, la régler à 0 signifie aucune expiration
