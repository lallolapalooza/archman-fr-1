BGLJFILE(1) Manuel des commandes générales BGLJFILE(1)

NOM

Bgljfile - un générateur de fichiers d'accès Jvm

SYNTAXE

bgljfile [ options ] fichier ...

DESCRIPTION

Bgljfile est un générateur de fichiers d'accès Jvm. Il produit des fichiers qui conviennent à l'option -bgljfile de Bigloo. Un fichier d'accès Jvm est une liste Scheme. Chaque élément de cette liste est une liste d'au moins deux éléments : un nom de module, le fichier de classe Java qui implémente ce module.

OPTIONS

fichier
Est un fichier implémentant un module. Bgljfile lit ce fichier pour découvrir le nom du module implémenté.
-base
Définit le paquet de base Jvm.
-o <fichier>
Imprime le fichier d'accès au module dans fichier. Par défaut, la liste est imprimée sur la sortie standard.
-suffixe <suf>
Ajoute suf à la liste des suffixes de fichiers source de bgljfile. Les suffixes par défaut sont "scm", "sch" et "bgl".

EXEMPLE

Si les trois fichiers existent et contiennent une clause de module Bigloo valide, alors :


$ bgljfile foo.scm bar.scm gee.scm

pourrait imprimer une liste comme :

(


(foo "./foo")


(bar "./bar")


(gee "./gee")

)
