NOM

borg-umount - démonter le système de fichiers FUSE

SYNTAXE

borg [options communes] umount [options] POINT_DE_MONTAGE

DESCRIPTION

Cette commande démonte un système de fichiers FUSE qui a été monté avec borg mount.

C'est un wrapper pratique qui appelle simplement la commande shell spécifique à la plateforme - généralement soit umount, soit fusermount -u.

OPTIONS

Voir borg-common(1) pour les options communes des commandes Borg.

arguments

POINT_DE_MONTAGE
point de montage du système de fichiers à démonter

EXEMPLES

# Monter le dépôt affiche toutes les archives.
# Les archives sont chargées à la demande, attendez un délai lorsque vous naviguez vers une archive
# pour la première fois.
$ borg mount /chemin/vers/depot /tmp/monmontage
$ ls /tmp/monmontage
root-2016-02-14 root-2016-02-15
$ borg umount /tmp/monmontage
# Monter une archive spécifique est également possible.
$ borg mount /chemin/vers/depot::root-2016-02-15 /tmp/monmontage
$ ls /tmp/monmontage
bin  boot  etc      home  lib  lib64  lost+found  media  mnt  opt
root  sbin  srv  tmp  usr  var
$ borg umount /tmp/monmontage
# La "vue versions" fusionne toutes les archives du dépôt
# et fournit une vue versionnée des fichiers.
$ borg mount -o versions /chemin/vers/depot /tmp/monmontage
$ ls -l /tmp/monmontage/home/utilisateur/doc.txt/
total 24
-rw-rw-r-- 1 utilisateur groupe 12357 août 26 21:19 doc.cda00bc9.txt
-rw-rw-r-- 1 utilisateur groupe 12204 août 26 21:04 doc.fa760f28.txt
$ borg umount /tmp/monmontage
# Les filtres d'archives sont pris en charge.
# Ils sont particulièrement utiles pour la "vue versions",
# qui ne prend pas en charge le traitement paresseux des archives.
$ borg mount -o versions --glob-archives '*-mon-home' --last 10 /chemin/vers/depot /tmp/monmontage
# Les options d'exclusion sont prises en charge.
# Elles peuvent accélérer le montage et réduire considérablement l'utilisation de la mémoire.
$ borg mount /chemin/vers/depot /tmp/monmontage seulement/ce/chemin
$ borg mount --exclude '...' /chemin/vers/depot /tmp/monmontage
# En utilisant la variable d'environnement BORG_REPO, utilisez :: comme argument positionnel :
export BORG_REPO=/chemin/vers/depot
# Monter tout le dépôt :
borg mount :: /tmp/monmontage
# Monter une archive spécifique :
borg mount ::root-2016-02-15 /tmp/monmontage

borgfs

$ echo '/mnt/sauvegarde /tmp/monrepo fuse.borgfs defaults,noauto 0 0' >> /etc/fstab
$ echo '/mnt/sauvegarde::root-2016-02-15 /tmp/monarchive fuse.borgfs defaults,noauto 0 0' >> /etc/fstab
$ mount /tmp/monrepo
$ mount /tmp/monarchive
$ ls /tmp/monrepo
root-2016-02-01 root-2016-02-15
$ ls /tmp/monarchive
bin  boot  etc      home  lib  lib64  lost+found  media  mnt  opt  root  sbin  srv  tmp  usr  var

REMARQUE :

borgfs sera automatiquement fourni si vous avez utilisé un paquet de distribution ou pip pour installer Borg. Les utilisateurs du binaire autonome devront créer manuellement un lien symbolique (voir pyinstaller-binary).
