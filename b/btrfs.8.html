NOM

btrfs - une boîte à outils pour gérer les systèmes de fichiers btrfs

SYNTAXE

btrfs [options globales] <groupe> [<groupe>...] <commande> [options] [<arguments>]

DESCRIPTION

L'utilitaire btrfs est une boîte à outils pour gérer les systèmes de fichiers btrfs. Il existe des groupes de commandes pour travailler avec les sous-volumes, les périphériques, pour le système de fichiers entier ou pour d'autres actions spécifiques. Voir la section COMMANDES.

Il existe également des outils autonomes pour certaines tâches comme btrfs-convert(8) <> ou btrfstune(8) <> qui étaient historiquement séparés et/ou n'ont pas été fusionnés dans l'utilitaire principal. Voir la section OUTILS AUTONOMES pour plus de détails.

Pour d'autres sujets (options de montage, etc.), veuillez vous référer à la page de manuel distincte btrfs(5) <>.

SYNTAXE DES COMMANDES

Le nom de toute commande peut être raccourci tant que la forme raccourcie est sans ambiguïté, cependant, il est recommandé d'utiliser les noms complets des commandes dans les scripts. Tous les groupes de commandes ont leur page de manuel nommée btrfs-<groupe>.

Par exemple : il est possible d'exécuter btrfs sub snaps au lieu de btrfs subvolume snapshot. Mais btrfs file s n'est pas permis, car file s peut être interprété à la fois comme filesystem show et comme filesystem sync.

Si le nom de la commande est ambigu, la liste des options conflictuelles est affichée.

Les *Tailles*, tant en entrée qu'en sortie, peuvent être exprimées en unités SI ou IEC-I (voir numfmt(1) https://man7.org/linux/man-pages/man1/numfmt.1.html) avec le suffixe B ajouté. Tous les nombres seront formatés selon les règles de la locale *C* (en ignorant la locale du shell, voir locale(7) https://man7.org/linux/man-pages/man7/locale.7.html).

Pour un aperçu d'une commande donnée, utilisez btrfs command --help ou btrfs [command...] help --full pour afficher toutes les options disponibles pour toutes les commandes.

Il existe des options globales qui sont passées entre *btrfs* et le nom de *groupe* et affectent le comportement non spécifique à la commande, par exemple la verbosité ou le type de sortie :

btrfs -q subvolume create ...
btrfs --dry-run subvolume create ...
--format <format>
si supporté par la commande, affiche la sortie de la sous-commande dans ce format (texte, json)
-v|--verbose
augmente la verbosité de la sous-commande
-q|--quiet
n'affiche que les erreurs
--log <niveau>
définit le niveau de journalisation (défaut, info, verbose, debug, quiet)

Les options restantes ne sont pertinentes que pour l'outil principal :

--help
affiche une aide condensée pour toutes les sous-commandes
--version
affiche la chaîne de version

COMMANDES

balance
Équilibre les blocs de fichiers btrfs entre un ou plusieurs périphériques. Voir btrfs-balance(8) <> pour plus de détails.
check
Effectue une vérification hors ligne d'un système de fichiers btrfs. Voir btrfs-check(8) <> pour plus de détails.
device
Gère les périphériques gérés par btrfs, y compris l'ajout/la suppression/le scan, etc. Voir btrfs-device(8) <> pour plus de détails.
filesystem
Gère un système de fichiers btrfs, y compris la définition/synchronisation du label, etc. Voir btrfs-filesystem(8) <> pour plus de détails.
inspect-internal
Outils de débogage pour les développeurs/hackers. Voir btrfs-inspect-internal(8) <> pour plus de détails.
property
Obtenir/définir une propriété d'un objet btrfs. Voir btrfs-property(8) <> pour plus de détails.
qgroup
Gère les groupes de quotas (qgroup) pour le système de fichiers btrfs. Voir btrfs-qgroup(8) <> pour plus de détails.
quota
Gère les quotas sur le système de fichiers btrfs, comme l'activation/la relecture, etc. Voir btrfs-quota(8) <> et btrfs-qgroup(8) <> pour plus de détails.
receive
Reçoit les données du sous-volume depuis stdin/fichier pour la restauration, etc. Voir btrfs-receive(8) <> pour plus de détails.
replace
Remplace les périphériques btrfs. Voir btrfs-replace(8) <> pour plus de détails.
rescue
Tente de récupérer un système de fichiers btrfs endommagé. Voir btrfs-rescue(8) <> pour plus de détails.
restore
Tente de restaurer des fichiers à partir d'un système de fichiers btrfs endommagé. Voir btrfs-restore(8) <> pour plus de détails.
scrub
Nettoie un système de fichiers btrfs. Voir btrfs-scrub(8) <> pour plus de détails.
send
Envoie les données du sous-volume vers stdout/fichier pour la sauvegarde, etc. Voir btrfs-send(8) <> pour plus de détails.
subvolume
Crée/supprime/liste/gère les sous-volumes btrfs. Voir btrfs-subvolume(8) <> pour plus de détails.

OUTILS AUTONOMES

De nouvelles fonctionnalités pourraient être fournies à l'aide d'un outil autonome. Si la fonctionnalité s'avère utile, l'outil autonome est déclaré obsolète et sa fonctionnalité est copiée dans l'outil principal. Les outils obsolètes sont supprimés après une longue période de dépréciation (plusieurs années).

Outils encore en usage actif sans équivalent dans btrfs :

btrfs-convert
conversion in-place des systèmes de fichiers ext2/3/4 en btrfs
btrfstune
ajuste certaines propriétés du système de fichiers sur un système de fichiers démonté
btrfs-select-super
outil de récupération pour écraser le superbloc principal à partir d'une copie de secours
btrfs-find-root
outil d'aide à la récupération pour trouver les racines d'arbre dans un système de fichiers

Pour les environnements à espace limité, il est possible de construire un binaire unique avec la fonctionnalité de plusieurs outils autonomes. Ceci suit le concept de busybox où le nom de fichier sélectionne la fonctionnalité. Cela fonctionne pour les liens symboliques ou les liens physiques. La liste complète peut être obtenue avec btrfs help --box.

STATUT DE SORTIE

btrfs retourne un statut de sortie nul en cas de succès. Une valeur non nulle est retournée en cas d'échec.

DISPONIBILITÉ

btrfs fait partie des btrfs-progs. Veuillez vous référer à la documentation sur https://btrfs.readthedocs.io.
