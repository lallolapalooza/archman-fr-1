NOM

bf_copy - script shell pour copier un répertoire de travail bogofilter

SYNTAXE

bf_copy [-c] rép_source rép_destination

DESCRIPTION

bf_copy copie un répertoire de travail bogofilter vers un autre répertoire. Actuellement, il copie les fichiers de base de données (*.db), les fichiers associés (log.*) et DB_CONFIG (s'il est présent).

OPTIONS

L'option -c permet de copier uniquement les fichiers journaux actifs, pas tous. Par défaut, tous les fichiers journaux sont copiés.

STATUT DE SORTIE

Le script se termine avec le code de statut 0 si tout s'est bien passé, et une valeur non nulle s'il a rencontré des problèmes.

BOGUES

Ce script suppose que tous les fichiers *.db dans le répertoire source sont pertinents et les copie. Cela peut ne pas correspondre à votre configuration réelle.

NOTES

Ce script est destiné à être utilisé avec les versions de bogofilter basées sur Berkeley DB et SQLite.

Ce script attend un shell conforme à SUSv2. Les systèmes Solaris devraient avoir le paquet SUNWxcu4 installé (lorsque bogofilter est configuré) afin que /usr/xpg4/bin/sh puisse être utilisé.
