bupstash-init(1)

Paquet: bupstash

Licences: MIT

() ()

SYNTAXE

Initialise un dépôt bupstash.

bupstash init [OPTIONS]

DESCRIPTION

bupstash init initialise un dépôt. Si DÉPÔT existe déjà, la commande échoue.

Il n'est actuellement pas recommandé d'utiliser bupstash sur un système de fichiers réseau.

Pour plus de détails sur le contenu du magasin de paquets après initialisation, voir bupstash-repository(7).

OPTIONS

-r, --repository REPO
Le dépôt auquel se connecter. Peut être de la forme ssh://$SERVEUR/$CHEMIN pour les dépôts distants si l'accès ssh est configuré. Si non spécifié, est défini sur BUPSTASH_REPOSITORY.
--storage SPEC
Accepte «dir» ou une spécification de stockage json. Le stockage par défaut est «dir» et stocke les blocs de données chiffrés dans un répertoire de données local du dépôt.
Voir la section des spécifications de stockage pour les spécifications json prises en charge et les exemples.

ENVIRONNEMENT

BUPSTASH_REPOSITORY
Le dépôt auquel se connecter. Peut être de la forme ssh://$SERVEUR/$CHEMIN pour les dépôts distants si l'accès ssh est configuré.
BUPSTASH_REPOSITORY_COMMAND
Une commande à exécuter pour se connecter à une instance de bupstash-serve(1). Cela permet des connexions plus complexes au dépôt pour des cas d'utilisation moins courants.

EXEMPLES

``` $ export BUPSTASH_REPOSITORY=./mon-depot $ bupstash init

$ export BUPSTASH_REPOSITORY=ssh://$SERVEUR/home/sauvegardes/depots-bupstash $ bupstash init ```

SPECIFICATIONS DE STOCKAGE JSON

Chaque spécification de stockage consiste en un identifiant de type et un ensemble de paramètres spécifiques au type.

Stockage Dir

Le stockage Dir est un alias pour --storage dir et n'est généralement pas nécessaire.

Exemple :

$ bupstash init --storage «{"Dir" : {}}»

Stockage externe

Le moteur de stockage externe stocke les données via une socket externe, la documentation est en attente de stabilisation de l'interface.

Exemple :

$ bupstash init --storage «{"External" : {"socket_path" : "/plugin/socket.sock", "path" : "chemin-specifique-plugin"}}»
