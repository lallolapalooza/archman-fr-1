BUNDLE-OUTDATED(1) Manuel des commandes générales BUNDLE-OUTDATED(1)

NOM

bundle-outdated - Lister les gems installés avec des versions plus récentes disponibles

SYNTAXE

bundle outdated [GEM] [--local] [--pre] [--source] [--filter-strict | --strict] [--update-strict] [--parseable | --porcelain] [--group=GROUP] [--groups] [--patch|--minor|--major] [--filter-major] [--filter-minor] [--filter-patch] [--only-explicit]

DESCRIPTION

Outdated liste les noms et versions des gems pour lesquels une version plus récente est disponible dans la source donnée. Appeler outdated avec [GEM [GEM]] ne vérifiera que les versions plus récentes des gems spécifiés. Les gems de pré-version sont ignorés par défaut. Si vos gems sont à jour, Bundler se terminera avec un statut de 0. Sinon, il se terminera avec 1.

OPTIONS

--local
N'essaie pas de récupérer les gems à distance et utilise le cache des gems à la place.
--pre
Vérifie les gems de pré-version plus récentes.
--source=<liste>
Vérifie par rapport à une source spécifique.
--filter-strict, --strict
Ne liste que les versions plus récentes autorisées par les exigences de votre Gemfile, en respectant également les indicateurs de mise à jour conservateurs (--patch, --minor, --major).
--update-strict
Résolution stricte et conservatrice, n'autorise aucune mise à jour de gem au-delà de la dernière --patch | --minor | --major.
--parseable, --porcelain
Utilise un formatage minimal pour une sortie plus facilement analysable.
--group=GROUP
Liste les gems d'un groupe spécifique.
--groups
Liste les gems organisés par groupes.
--minor
Préfère mettre à jour uniquement vers la prochaine version mineure.
--major
Préfère mettre à jour vers la prochaine version majeure (par défaut).
--patch
Préfère mettre à jour uniquement vers la prochaine version de correctif.
--filter-major
Ne liste que les versions majeures plus récentes.
--filter-minor
Ne liste que les versions mineures plus récentes.
--filter-patch
Ne liste que les versions de correctif plus récentes.
--only-explicit
Ne liste que les gems spécifiés dans votre Gemfile, pas leurs dépendances.

OPTIONS DE NIVEAU DE CORRECTIF

Voir bundle update(1) bundle-update.1.html pour les détails.

FILTRAGE DE LA SORTIE

Les 3 options de filtrage n'affectent pas la résolution des versions, mais seulement les versions affichées dans la sortie.

Si la sortie normale affiche ce qui suit :

* Gem       Current  Latest  Requested  Groups
* faker     1.6.5    1.6.6   ~> 1.4     development, test
* hashie    1.2.0    3.4.6   = 1.2.0    default
* headless  2.2.3    2.3.1   = 2.2.3    test

--filter-major n'afficherait que :

* Gem       Current  Latest  Requested  Groups
* hashie    1.2.0    3.4.6   = 1.2.0    default

--filter-minor n'afficherait que :

* Gem       Current  Latest  Requested  Groups
* headless  2.2.3    2.3.1   = 2.2.3    test

--filter-patch n'afficherait que :

* Gem       Current  Latest  Requested  Groups
* faker     1.6.5    1.6.6   ~> 1.4     development, test

Les options de filtre peuvent être combinées. --filter-minor et --filter-patch afficheraient :

* Gem       Current  Latest  Requested  Groups
* faker     1.6.5    1.6.6   ~> 1.4     development, test

La combinaison des trois options de filtre équivaudrait à ne fournir aucune d'entre elles.
