NOM

buildah-rmi - Supprime une ou plusieurs images.

SYNTAXE

buildah rmi [image ...]

DESCRIPTION

Supprime une ou plusieurs images stockées localement. Passer un argument image la supprime, ainsi que toutes ses images parentes orphelines (sans étiquette).

LIMITATIONS

  • Si l'image a été poussée vers un chemin de répertoire en utilisant le transport 'dir:', la commande rmi ne peut pas supprimer l'image. À la place, les commandes standard du système de fichiers doivent être utilisées.
  • Si imageID est un nom, mais n'inclut pas de nom de registre, buildah tentera de trouver et supprimer l'image nommée en utilisant le nom de registre localhost. Si aucune image de ce type n'est trouvée, il recherchera l'image prévue en essayant d'étendre le nom donné à l'aide des noms de registres fournis dans le fichier de configuration des registres du système, registries.conf.
  • Si imageID fait référence à une liste de manifestes ou à un index d'images, cette commande ne fera pas ce que vous attendez ! Cette commande supprimera les images associées à la liste de manifestes ou à l'index (pas la liste de manifestes/index d'images elle-même). Pour supprimer cela, utilisez plutôt la sous-commande buildah manifest rm.

OPTIONS

--all, -a

Toutes les images locales qui n'ont pas de conteneurs utilisant l'image comme image de référence seront supprimées du système. Un nom ou un id d'image ne peut pas être fourni lorsque cette option est utilisée. Les images en lecture seule configurées en modifiant les "additionalimagestores" dans le fichier /etc/containers/storage.conf, ne peuvent pas être supprimées.

--force, -f

Cette option forcera Buildah à supprimer tous les conteneurs qui utilisent l'image avant de supprimer l'image du système.

--prune, -p

Toutes les images locales qui n'ont pas d'étiquette et qui n'ont pas d'image enfant les référençant seront supprimées du système. Un nom ou un id d'image ne peut pas être fourni lorsque cette option est utilisée.

EXEMPLE

buildah rmi imageID

buildah rmi --all

buildah rmi --all --force

buildah rmi --prune

buildah rmi --force imageID

buildah rmi imageID1 imageID2 imageID3

FICHIERS

registries.conf (/etc/containers/registries.conf)

registries.conf est le fichier de configuration qui spécifie quels registres de conteneurs doivent être consultés lors de la complétion des noms d'images qui n'incluent pas de registre ou de partie de domaine.

storage.conf (/etc/containers/storage.conf)

storage.conf est le fichier de configuration de stockage pour tous les outils utilisant containers/storage.

Le fichier de configuration de stockage spécifie toutes les options de stockage de conteneurs disponibles pour les outils utilisant le stockage de conteneurs partagé.
