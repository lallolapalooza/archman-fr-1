NOM

bspwm - gestionnaire de fenêtres par partitionnement binaire

SYNTAXE

bspwm [-h|-v|-c CHEMIN_CONFIG]

bspc --print-socket-path

bspc DOMAINE [SELECTEUR] COMMANDES

bspc COMMANDE [OPTIONS] [ARGUMENTS]

DESCRIPTION

bspwm est un gestionnaire de fenêtres en mosaïque qui représente les fenêtres comme les feuilles d'un arbre binaire complet.

Il est contrôlé et configuré via bspc.

OPTIONS

-h

Affiche la syntaxe et quitte.

-v

Affiche la version et quitte.

-c CHEMIN_CONFIG

Utilise le fichier de configuration donné.

--print-socket-path

Affiche le chemin du socket bspwm et quitte.

DÉFINITIONS COMMUNES

DIR         := nord | ouest | sud | est
CYCLE_DIR   := suivant | precedent

SÉLECTEURS

Les sélecteurs sont utilisés pour sélectionner un nœud, un bureau ou un moniteur cible. Un sélecteur peut décrire la cible relativement ou la nommer globalement.

Les sélecteurs consistent en une référence optionnelle, un descripteur et un nombre quelconque de modificateurs non conflictuels comme suit :

[REFERENCE#]DESCRIPTEUR(.MODIFICATEUR)*

Les cibles relatives sont calculées par rapport à la référence donnée (la valeur de référence par défaut est focus).

Un point d'exclamation peut être préfixé à n'importe quel modificateur pour inverser sa signification.

Les caractères suivants ne peuvent pas être utilisés dans les noms de moniteurs ou de bureaux : #, :, ..

Le sélecteur spécial %<nom> peut être utilisé pour sélectionner un moniteur ou un bureau avec un nom invalide.

Nœud

Sélectionne un nœud.

NODE_SEL := [NODE_SEL#](DIR|CYCLE_DIR|CHEMIN|any|first_ancestor|last|newest|
                        older|newer|focused|pointed|biggest|smallest|
                        <node_id>)[.[!]focused][.[!]active][.[!]automatic][.[!]local]
                                  [.[!]leaf][.[!]window][.[!]ETAT][.[!]FLAG][.[!]COUCHELOG][.[!]TYPE_DIVISION]
                                  [.[!]same_class][.[!]descendant_of][.[!]ancestor_of]
ETAT := tiled|pseudo_tiled|floating|fullscreen
FLAG := hidden|sticky|private|locked|marked|urgent
COUCHELOG := below|normal|above
TYPE_DIVISION := horizontal|vertical
CHEMIN := @[DESKTOP_SEL:][[/]JUMP](/JUMP)*
JUMP := first|1|second|2|brother|parent|DIR

Descripteurs

DIR

Sélectionne la fenêtre dans la direction (spatiale) donnée par rapport au nœud de référence.

CYCLE_DIR

Sélectionne le nœud dans la direction (cyclique) donnée par rapport au nœud de référence, lors d'un parcours en profondeur dans l'ordre de l'arbre.

CHEMIN

Sélectionne le nœud au chemin donné.

any

Sélectionne le premier nœud qui correspond aux sélecteurs donnés.

first_ancestor

Sélectionne le premier ancêtre du nœud de référence qui correspond aux sélecteurs donnés.

last

Sélectionne le nœud précédemment focalisé par rapport au nœud de référence.

newest

Sélectionne le nœud le plus récent dans l'historique du nœud focalisé.

older

Sélectionne le nœud plus ancien que le nœud de référence dans l'historique.

newer

Sélectionne le nœud plus récent que le nœud de référence dans l'historique.

focused

Sélectionne le nœud actuellement focalisé.

pointed

Sélectionne la feuille sous le pointeur de la souris.

biggest

Sélectionne la plus grande feuille.

smallest

Sélectionne la plus petite feuille.

<node_id>

Sélectionne le nœud avec l'ID donné.

Sauts de chemin

Le nœud initial est le nœud focalisé (ou la racine si le chemin commence par /) du bureau de référence (ou le bureau sélectionné si le chemin a un préfixe DESKTOP_SEL).

1|first

Sauter au premier enfant.

2|second

Sauter au deuxième enfant.

brother

Sauter au nœud frère.

parent

Sauter au nœud parent.

DIR

Sauter au nœud tenant le bord dans la direction donnée.

Modificateurs

[!]focused

Considérer uniquement le nœud focalisé.

[!]active

Considérer uniquement les nœuds qui sont le nœud focalisé de leur bureau.

[!]automatic

Considérer uniquement les nœuds en mode d'insertion automatique. Voir également --presel-dir sous Node dans la section DOMAINES ci-dessous.

[!]local

Considérer uniquement les nœuds du bureau de référence.

[!]leaf

Considérer uniquement les nœuds feuilles.

[!]window

Considérer uniquement les nœuds qui contiennent une fenêtre.

[!](tiled|pseudo_tiled|floating|fullscreen)

Considérer uniquement les fenêtres dans l'état donné.

[!]same_class

Considérer uniquement les fenêtres ayant la même classe que la fenêtre de référence.

[!]descendant_of

Considérer uniquement les nœuds qui sont des descendants du nœud de référence.

[!]ancestor_of

Considérer uniquement les nœuds qui sont des ancêtres du nœud de référence.

[!](hidden|sticky|private|locked|marked|urgent)

Considérer uniquement les fenêtres ayant le drapeau donné défini.

[!](below|normal|above)

Considérer uniquement les fenêtres dans la couche donnée.

[!](horizontal|vertical)

Considérer uniquement les nœuds avec le type de division donné.

RÉCEPTACL

ES
Un nœud feuille qui ne contient aucune fenêtre est appelé un réceptacle. Lorsqu'un nœud est inséré sur un réceptacle en mode automatique, il remplacera le réceptacle. Un réceptacle peut être inséré sur un nœud, présélectionné et tué. Les réceptacles peuvent donc être utilisés pour construire un arbre dont les feuilles sont des réceptacles. En utilisant les règles appropriées, on peut ensuite envoyer des fenêtres sur les feuilles de cet arbre. Cette fonctionnalité est utilisée dans examples/receptacle
s

pour stocker et recréer des

dispositions.

CONFIGURATION

The configuration file is evaluated in the following order:

  1. The file specified by the $XDG_CONFIG_HOME/bspwm/bspwmrc environment variable.

  2. The file $HOME/.config/bspwm/bspwmrc.

  3. The file /etc/bspwm/bspwmrc.

The configuration file is a shell script that is executed by bspwm. All commands are sent to the bspwm message channel using the bspc utility.

The following commands are available:

General Settings

border_width

Window border width.

window_gap

Size of the gap that separates windows.

top_padding, right_padding, bottom_padding, left_padding

Padding space added at the sides of the monitor or desktop.

split_ratio

The default ratio for splitting nodes.

borderless_monocle

Remove the border of windows in monocle mode.

gapless_monocle

Remove the gaps between windows in monocle mode.

single_occlude

Do not draw the border of a window if it is occluded by another window.

focus_follows_pointer

Focus the window under the pointer.

pointer_follows_focus

When focusing a window, put the pointer at its center.

pointer_follows_monitor

When focusing a monitor, put the pointer at its center.

mapping_events_count

Handle the next mapping_events_count mapping notify events. A negative value implies that every event needs to be handled.

ignore_ewmh_focus

Ignore EWMH focus requests coming from applications.

ignore_ewmh_fullscreen

Block the fullscreen state transitions that originate from an EWMH request. The possible values are: none, all, or a comma separated list of the following values: enter, exit.

ignore_ewmh_struts

Ignore strut hinting from clients requesting to reserve space (i.e. task bars).

center_pseudo_tiled

Center pseudo tiled windows into their tiling rectangles. Defaults to true.

remove_disabled_monitors

Consider disabled monitors as disconnected.

remove_unplugged_monitors

Remove unplugged monitors.

merge_overlapping_monitors

Merge overlapping monitors (the bigger remains).

Monitor and Desktop Settings

top_padding, right_padding, bottom_padding, left_padding

Padding space added at the sides of the monitor or desktop.

Desktop Settings

window_gap

Size of the gap that separates windows.

Node Settings

border_width

Window border width.

honor_size_hints

If true, apply ICCCM window size hints to all windows. If floating, only apply them to floating and pseudo tiled windows. If tiled, only apply them to tiled windows. If false, don’t apply them. Defaults to false.

POINTER BINDINGS

click_to_focus

Focus the window (or the monitor) under the pointer if the value isn’t none.

pointer_modifier + button1

Move the window under the pointer.

pointer_modifier + button2

Resize the window under the pointer by dragging the nearest side.

pointer_modifier + button3

Resize the window under the pointer by dragging the nearest corner.

The behavior of pointer_modifier + button<n> can be modified through the pointer_action<n> setting.

REPORT FORMAT

Each report event message is composed of items separated by colons.

Each item has the form <type><value> where <type> is the first character of the item.

M<monitor_name>

Focused monitor.

m<monitor_name>

Unfocused monitor.

O<desktop_name>

Occupied focused desktop.

o<desktop_name>

Occupied unfocused desktop.

F<desktop_name>

Free focused desktop.

f<desktop_name>

Free unfocused desktop.

U<desktop_name>

Urgent focused desktop.

u<desktop_name>

Urgent unfocused desktop.

L(T|M)

Layout of the focused desktop of a monitor.

T(T|P|F|=|@)

State of the focused node of a focused desktop.

G(S?P?L?M?)

Active flags of the focused node of a focused desktop.

ENVIRONMENT VARIABLES

BSPWM_SOCKET

The path of the socket used for the communication between bspc and bspwm. If it isn’t defined, then the following path is used: /tmp/bspwm<host_name>_<display_number>_<screen_number>-socket.
