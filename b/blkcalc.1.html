BLKCALC(1) Manuel des commandes générales BLKCALC(1)

NOM

blkcalc - Convertit entre les numéros d'unité de disque non alloués et les numéros d'unité de disque réguliers.

SYNTAXE

blkcalc [-dsu unit_addr] [-vV] [-i imgtype] [-o imgoffset] [-b dev_sector_size] [-f fstype] image [images]

DESCRIPTION

blkcalc crée une correspondance des numéros d'unité de disque entre deux images, une normale et une autre qui ne contient que les unités non allouées de la première (le comportement par défaut du programme blkls(1)). Une des options -d, -s, ou -u doit être donnée. Si l'option -d est donnée, alors la valeur unit_addr est l'adresse de l'unité de disque dans l'image régulière (c'est-à-dire de dd ). Si l'unité est non allouée, son adresse dans une image non allouée est donnée. Si l'option -u est donnée, alors la valeur unit_addr est l'adresse de l'unité de disque dans l'image d'unité non allouée (c'est-à-dire de blkls(1) ). Son adresse de disque dans l'image d'origine est déterminée. Si l'option -s est donnée, alors la valeur unit_addr est l'adresse de l'unité de disque dans l'image de décalage (slack) (c'est-à-dire de blkls -s). L'image est l'image complète et originale (c'est-à-dire de dd). blkcalc s'appelait dcalc dans les versions de TSK antérieures à 3.0.0.

-f fstype
Identifie le type de système de fichiers de l'image. Utilisez '-f list' pour lister les types de systèmes de fichiers pris en charge. S'il n'est pas donné, des méthodes de détection automatique sont utilisées.
-i imgtype
Identifie le type de fichier image, tel que raw. Utilisez '-i list' pour lister les types pris en charge. S'il n'est pas donné, des méthodes de détection automatique sont utilisées.
-o imgoffset
Le décalage de secteur où le système de fichiers commence dans l'image.
-b dev_sector_size
La taille, en octets, des secteurs du périphérique sous-jacent. S'il n'est pas donné, la valeur du format d'image est utilisée (si elle existe) ou 512 octets sont supposés.
-v
Sortie détaillée vers STDERR.
-V
Affiche la version.
image [images]
L'image de disque ou de partition à lire, dont le format est donné avec '-i'. Plusieurs noms de fichiers image peuvent être donnés si l'image est divisée en plusieurs segments. Si un seul fichier image est donné, et que son nom est le premier d'une séquence (par exemple, indiqué par une terminaison '.001'), les segments d'image suivants seront inclus automatiquement.

Ceci est utile lors de la recherche par mots-clés d'une image générée par blkls. Cela permet d'identifier l'adresse d'unité d'origine et fournit une meilleure documentation.

EXEMPLE

# blkcalc -u 64 images/wd0e
