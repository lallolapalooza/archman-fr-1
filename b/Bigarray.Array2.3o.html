Bigarray.Array2 - Tableaux à deux dimensions.

MODULE

Module Bigarray.Array2

DOCUMENTATION

Module Array2
: sig end

Tableaux à deux dimensions. La structure Array2 fournit des opérations similaires à celles de Bigarray.Genarray , mais spécialisées pour le cas des tableaux à deux dimensions.

type (!'a, !'b, !'c) t

Le type des Bigarrays bidimensionnels dont les éléments ont le type OCaml 'a , le genre de représentation 'b , et la disposition mémoire 'c .

val create : ('a, 'b) Bigarray.kind -> 'c Bigarray.layout -> int -> int -> ('a, 'b, 'c) t

Array2.create kind layout dim1 dim2 renvoie un nouveau Bigarray à deux dimensions, dont la taille est dim1 dans la première dimension et dim2 dans la seconde dimension. kind et layout déterminent le genre des éléments du tableau et la disposition du tableau comme décrit pour Bigarray.Genarray.create .

val init : ('a, 'b) Bigarray.kind -> 'c Bigarray.layout -> int -> int -> (int -> int -> 'a) -> ('a, 'b, 'c) t

Array2.init kind layout dim1 dim2 f renvoie un nouveau Bigarray b à deux dimensions, dont la taille est dim1 dans la première dimension et dim2 dans la seconde dimension. kind et layout déterminent le genre des éléments du tableau et la disposition du tableau comme décrit pour Bigarray.Genarray.create .

Chaque élément Array2.get b i j du tableau est initialisé au résultat de f i j .

En d'autres termes, Array2.init kind layout dim1 dim2 f tabule les résultats de f appliqués aux indices d'un nouveau Bigarray dont la disposition est décrite par kind , layout , dim1 et dim2 .

Depuis 4.12

val dim1 : ('a, 'b, 'c) t -> int

Renvoie la première dimension du Bigarray bidimensionnel donné.

val dim2 : ('a, 'b, 'c) t -> int

Renvoie la seconde dimension du Bigarray bidimensionnel donné.

val kind : ('a, 'b, 'c) t -> ('a, 'b) Bigarray.kind

Renvoie le genre du Bigarray donné.

val layout : ('a, 'b, 'c) t -> 'c Bigarray.layout

Renvoie la disposition du Bigarray donné.

val change_layout : ('a, 'b, 'c) t -> 'd Bigarray.layout -> ('a, 'b, 'd) t

Array2.change_layout a layout renvoie un Bigarray avec la disposition spécifiée layout , partageant les données avec a (et ayant donc les mêmes dimensions que a ). Aucune copie d'éléments n'est impliquée : le nouveau tableau et le tableau original partagent le même espace de stockage. Les dimensions sont inversées, de telle sorte que get v [| a; b |] en disposition C devient get v [| b+1; a+1 |] en disposition Fortran.

Depuis 4.06

val size_in_bytes : ('a, 'b, 'c) t -> int

size_in_bytes a est le nombre d'éléments dans a multiplié par le Bigarray.kind_size_in_bytes de a .

Depuis 4.03

val get : ('a, 'b, 'c) t -> int -> int -> 'a

Array2.get a x y , également écrit a.{x,y} , renvoie l'élément de a aux coordonnées ( x , y ). x et y doivent être dans les limites de a , comme décrit pour Bigarray.Genarray.get ; sinon, Invalid_argument est levée.

val set : ('a, 'b, 'c) t -> int -> int -> 'a -> unit

Array2.set a x y v , ou alternativement a.{x,y} <- v , stocke la valeur v aux coordonnées ( x , y ) dans a . x et y doivent être dans les limites de a , comme décrit pour Bigarray.Genarray.set ; sinon, Invalid_argument est levée.

val sub_left : ('a, 'b, Bigarray.c_layout) t -> int -> int -> ('a, 'b, Bigarray.c_layout) t

Extrait un sous-tableau bidimensionnel du Bigarray bidimensionnel donné en restreignant la première dimension. Voir Bigarray.Genarray.sub_left pour plus de détails. Array2.sub_left ne s'applique qu'aux tableaux avec une disposition C.

val sub_right : ('a, 'b, Bigarray.fortran_layout) t -> int -> int -> ('a, 'b, Bigarray.fortran_layout) t

Extrait un sous-tableau bidimensionnel du Bigarray bidimensionnel donné en restreignant la seconde dimension. Voir Bigarray.Genarray.sub_right pour plus de détails. Array2.sub_right ne s'applique qu'aux tableaux avec une disposition Fortran.

val slice_left : ('a, 'b, Bigarray.c_layout) t -> int -> ('a, 'b, Bigarray.c_layout) Bigarray.Array1.t

Extrait une ligne (tranche unidimensionnelle) du Bigarray bidimensionnel donné. Le paramètre entier est l'indice de la ligne à extraire. Voir Bigarray.Genarray.slice_left pour plus de détails. Array2.slice_left ne s'applique qu'aux tableaux avec une disposition C.

val slice_right : ('a, 'b, Bigarray.fortran_layout) t -> int -> ('a, 'b, Bigarray.fortran_layout) Bigarray.Array1.t

Extrait une colonne (tranche unidimensionnelle) du Bigarray bidimensionnel donné. Le paramètre entier est l'indice de la colonne à extraire. Voir Bigarray.Genarray.slice_right pour plus de détails. Array2.slice_right ne s'applique qu'aux tableaux avec une disposition Fortran.

val blit : ('a, 'b, 'c) t -> ('a, 'b, 'c) t -> unit

Copie le premier Bigarray vers le second Bigarray. Voir Bigarray.Genarray.blit pour plus de détails.

val fill : ('a, 'b, 'c) t -> 'a -> unit

Remplit le Bigarray donné avec la valeur donnée. Voir Bigarray.Genarray.fill pour plus de détails.

val of_array : ('a, 'b) Bigarray.kind -> 'c Bigarray.layout -> 'a array array -> ('a, 'b, 'c) t

Construit un Bigarray bidimensionnel initialisé à partir du tableau de tableaux donné.

val unsafe_get : ('a, 'b, 'c) t -> int -> int -> 'a

Comme Bigarray.Array2.get , mais la vérification des limites n'est pas toujours effectuée.

val unsafe_set : ('a, 'b, 'c) t -> int -> int -> 'a -> unit

Comme Bigarray.Array2.set , mais la vérification des limites n'est pas toujours effectuée.
