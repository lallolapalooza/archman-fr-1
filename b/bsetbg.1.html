DESCRIPTIO

N

bsetbg est destiné à fournir une méthode standard pour que le gestionnaire de fenêtres Blackbox modifie l'arrière-plan de la fenêtre racine (bien qu'il fonctionne également avec tout autre gestionnaire de fenêtres). bsetbg agit comme un enveloppeur à la fois pour bsetroot et pour une variété flexible d'applications tierc

es qu'il utilise lors du trai

Si un arg-de-repli est fourni (-full, -tile, ou -center comme décrit ci-dessus), bsetbg supposera que le dernier argument est un nom de fichier. Si programme se termine avec un code non nul ou n'est pas disponible sur le système cible, bsetbg essaiera de traiter le fichier avec l'argument de

CONFIGURATIO

N

bsetbg lira ses valeurs de configuration depuis le fichier ~/.bsetbgrc s'il existe. Sinon, il parcourra le chemin système à la recherche d'une liste prédéfinie d'applications d'image à utiliser (actuellement, cette liste comprend qiv, xli, xv, wmsetbg, Esetroot, display et xsetbg). ~/.bsetbgrc doit contenir les variables suivantes

:
CENTER="chaîn
e"
Application et arguments à utiliser pour centrer une image sur la fenêtre racine lorsque l'argument -center est
spécifié.
FULL="chaîn
e"
Application et arguments à utiliser pour étirer une image afin de remplir la fenêtre racine lorsque l'argument -full est
spécifié.
TILE="chaîn
e"
Application et arguments à utiliser pour répéter une image en mosaïque sur la fenêtre racine lorsque l'argument -tile est
spécifié.
DEFAULT="chaîn
e"
Action à effectuer par défaut si aucune des options ci-dessus n'a été
spécifiée.
Les variables suivantes sont facultatives
:
NO_EXEC="boolée
n"
Si cette variable est définie, bsetbg ne modifiera jamais la fenêtre
racine.
POST_COMMAND="chaîn
e"
Cette variable spécifie une commande que bsetbg exécutera après chaque modification réussie de la fenêtre
racine.
LOG_LAST_CMD="boolée
n"
Si cette variable est définie, bsetbg conservera un fichier journal des deux dernières commandes
réussies.
LOGFILE="chaîn
e"
Cette variable peut spécifier le fichier journal à utiliser lorsque $LOG_LAST_CMD est défini. La valeur par défaut est ~/.bsetbg_last_cmd
.
Comme mentionné ci-dessus, bsetbg fonctionnera parfaitement pour la majorité des utilisateurs sans fichier de configuration. Les utilisateurs avancés qui souhaitent plus de contrôle sur le comportement de bsetbg devraient exécuter bsetbg -g et utiliser la sortie pour créer un ~/.bsetbgrc qui pourra ensuite être ajusté à la
main.
