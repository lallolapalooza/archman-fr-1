bytes(3perl) Manuel de référence du programmeur Perl bytes(3perl)

NOM

bytes - Pragma Perl pour exposer les octets individuels des caractères

AVIS

Comme le pragma bytes brise l'encapsulation (c'est-à-dire qu'il expose les détails internes de la façon dont l'exécutable Perl stocke actuellement une chaîne de caractères), les valeurs d'octets qui en résultent sont dans un encodage non spécifié.

L'utilisation de ce module à des fins autres que le débogage est fortement déconseillée. Si vous estimez que les fonctions qu'il contient pourraient être utiles pour votre application, cela indique peut-être un décalage entre votre modèle mental de l'Unicode dans Perl et la réalité actuelle. Dans ce cas, vous pourriez vouloir lire une partie de la documentation Unicode de Perl : perluniintro, perlunitut, perlunifaq et perlunicode.

SYNOPIS

use bytes;
... chr(...);       # ou bytes::chr
... index(...);     # ou bytes::index
... length(...);    # ou bytes::length
... ord(...);       # ou bytes::ord
... rindex(...);    # ou bytes::rindex
... substr(...);    # ou bytes::substr
no bytes;

DESCRIPTION

Les caractères de Perl sont stockés en interne sous forme de séquences d'un ou plusieurs octets. Ce pragma permet l'examen des octets individuels qui composent un caractère.

À l'origine, le pragma était conçu dans le but plus noble d'aider à intégrer Unicode dans Perl, mais l'approche qui l'utilisait s'est révélée défectueuse, et le seul usage légitime restant est le débogage lorsque vous avez besoin d'examiner les octets individuels des caractères sans les modifier. Il suffit d'insérer ce pragma temporairement, et de le supprimer une fois le débogage terminé.

L'usage original peut être réalisé par un encodage explicite (plutôt que par l'encodage implicite de ce pragma) en utilisant le module Encode :

use Encode qw/encode/;
my $utf8_byte_string   = encode "UTF8",   $string;
my $latin1_byte_string = encode "Latin1", $string;

Ou, si la performance est nécessaire et que vous ne vous intéressez qu'à la représentation UTF-8 :

utf8::encode(my $utf8_byte_string = $string);

"no bytes" peut être utilisé pour inverser l'effet de "use bytes" dans la portée lexicale actuelle.

Par exemple, lorsque Perl voit "$x = chr(400)", il encode le caractère en UTF-8 et le stocke dans $x. Ensuite, il est marqué comme donnée caractère, de sorte que, par exemple, "length $x" renvoie 1. Cependant, dans la portée du pragma "bytes", $x est traité comme une série d'octets - les octets qui composent l'encodage UTF8 - et "length $x" renvoie 2:

$x = chr(400);
print "La longueur est ", length $x, "\n";     # "La longueur est 1"
printf "Le contenu est %vd\n", $x;         # "Le contenu est 400"
{
    use bytes; # ou "require bytes; bytes::length()"
    print "La longueur est ", length $x, "\n"; # "La longueur est 2"
    printf "Le contenu est %vd\n", $x;     # "Le contenu est 198.144 (sur
                                         # les plateformes ASCII)"
}

chr(), ord(), substr(), index() et rindex() se comportent de manière similaire.

Pour en savoir plus sur les implications, consultez perluniintro et perlunicode.

bytes::length() est certes pratique si vous avez besoin de connaître la longueur en octets d'un scalaire Perl. Mais une méthode plus moderne est :

use Encode 'encode';
length(encode('UTF-8', $scalar))

LIMITATIONS

bytes::substr() ne fonctionne pas en tant que lvalue().

VOIR AUSSI

perluniintro, perlunicode, utf8, Encode
