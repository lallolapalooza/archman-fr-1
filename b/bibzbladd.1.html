NOM

bibzbladd.pl - ajouter des numéros Zbl aux articles dans un fichier bib donné

SYNTAXE

bibzbladd [-d] [-f] [-e 1|0] [-o sortie] fichier_bib

OPTIONS

-d
Mode de débogage
-e
Si 1 (par défaut), ajouter un zblnumber vide si un Zbl ne peut être trouvé. Cela évite les recherches répétées pour les mêmes entrées si vous ajoutez de nouvelles entrées au fichier. L'appel de "-e 0" supprime ce comportement.
-f
Forcer la recherche des numéros Zbl même si l'entrée en a déjà un.
-o sortie
Fichier de sortie. Si cette option n'est pas utilisée, le nom du fichier de sortie est formé en ajoutant "_zbl" au fichier d'entrée.

DESCRIPTION

Le script lit un fichier BibTeX. Il vérifie si les entrées ont des Zbl. Sinon, il essaie de trouver les numéros sur des sites Internet. Le résultat est un fichier BibTeX avec des champs "zblnumber=..." ajoutés.

Le nom du fichier de sortie est soit défini par l'option -o, soit dérivé en ajoutant le suffixe "_zbl" au fichier de sortie.

Voir le script "bibdoiadd" pour plus de détails sur le traitement.
