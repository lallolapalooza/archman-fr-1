BITCOIN-UTIL(1) Commandes utilisateur BITCOIN-UTIL(1)

NOM

bitcoin-util - page de manuel pour bitcoin-util v28.1.0

SYNOPIS

bitcoin-util [options] [commandes] Faire des choses

DESCRIPTION

Utilitaire Bitcoin Core bitcoin-util version v28.1.0

OPTIONS

-?

Afficher ce message d'aide et quitter

-version

Afficher la version et quitter

Options de débogage/test :

Options de sélection de chaîne :

-chain=<chaîne>

Utiliser la chaîne <chaîne> (par défaut : main). Valeurs autorisées : main, test, testnet4, signet, regtest

-signet

Utiliser la chaîne signet. Équivalent à -chain=signet. Notez que le réseau est défini par le paramètre -signetchallenge.

-signetchallenge

Les blocs doivent satisfaire le script donné pour être considérés comme valides (uniquement pour les réseaux signet ; utilise par défaut le défi global du réseau de test signet par défaut).

-signetseednode

Spécifier un nœud de départ pour le réseau signet, au format nomd'hôte[:port], par exemple sig.net:1234 (peut être utilisé plusieurs fois pour spécifier plusieurs nœuds de départ ; utilise par défaut les nœuds de départ du réseau de test signet global par défaut).

-testnet

Utiliser la chaîne testnet3. Équivalent à -chain=test. La prise en charge de testnet3 est dépréciée et sera supprimée dans une future version. Envisagez de passer dès maintenant à testnet4 en utilisant -testnet4.

-testnet4

Utiliser la chaîne testnet4. Équivalent à -chain=testnet4.

Commandes :

grind
Effectuer la preuve de travail sur une chaîne hexadécimale d'en-tête
