NOM

bitfieldExtract - extraire une plage de bits d'un entier

DÉCLARATION

genIType bitfieldExtract(genIType value, int offset, int bits);

genUType bitfieldExtract(genUType value, int offset, int bits);

PARAMÈTRES

value

Spécifie l'entier dont les bits doivent être extraits.

offset

Spécifie l'indice du premier bit à extraire.

bits

Spécifie le nombre de bits à extraire.

DESCRIPTION

bitfieldExtract extrait un sous-ensemble des bits de value et le retourne dans les bits de poids faible du résultat. La plage de bits extraits est [offset, offset + bits - 1].

Pour les types de données non signés, les bits de poids fort du résultat seront mis à zéro. Pour les types de données signés, les bits de poids fort seront mis à la valeur du bit offset + base - 1 (c'est-à-dire qu'il est signé étendu à la largeur du type de retour).

Si bits est zéro, le résultat sera zéro. Le résultat sera indéfini si offset ou bits est négatif, ou si la somme de offset et bits est supérieure au nombre de bits utilisés pour stocker l'opérande.
