BASE64URL(1) Commandes utilisateur BASE64URL(1)

NOM

base64url - Encode ou décode des données Base64Url du FICHIER, ou de l'entrée standard, vers la sortie standard.

SYNTAXE

base64url [OPTIONS]

DESCRIPTION

base64url - Encode ou décode des données Base64Url du FICHIER, ou de l'entrée standard, vers la sortie standard.

Version 0.9

Options de ligne de commande :

-d, --decode

Décode les données

-i, --ignore-garbage

lors du décodage, ignore les caractères non alphabétiques

-w, --wrap <COLS>

enroule les lignes encodées après COLS caractères (par défaut 76).
Utilisez 0 pour désactiver l'enroulement des lignes

-f, --file <NOM_FICHIER>

Encode ou décode le contenu de NOM_FICHIER - si cette option est absente, lit depuis stdin

-h, --help

affiche cette aide et quitte

-v, --version

affiche les informations de version et quitte

VOIR AUSSI

La documentation complète de base64url est maintenue sous forme de manuel Texinfo. Si les programmes info et base64url sont correctement installés sur votre site, la commande

info base64url

devrait vous donner accès au manuel complet.
