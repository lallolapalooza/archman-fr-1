NOM

bundle-fund - Liste les informations sur les gems recherchant une assistance financière

SYNTAXE

bundle fund [OPTIONS]

DESCRIPTION

bundle fund liste les informations sur les gems recherchant une assistance financière.

OPTIONS

--group=<liste>, -g=<liste>
Récupère les informations de financement pour un groupe spécifique.

EXEMPLES

# Liste les informations de financement pour tous les gems
bundle fund
# Liste les informations de financement pour un groupe spécifique
bundle fund --group=security
