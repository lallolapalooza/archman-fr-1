NOM

brltty - pilote d'afficheur braille rafraîchissable pour Linux/Unix

SYNTAXE

brltty [option ...]

DESCRIPTION

brltty est un processus d'arrière-plan (démon) qui fournit un accès à l'écran de la console (en mode texte) à une personne aveugle utilisant un afficheur braille rafraîchissable. Il pilote l'afficheur braille et offre une fonctionnalité complète de revue de l'écran. Une certaine capacité de synthèse vocale a également été intégrée.

OPTIONS

Les options peuvent être passées à brltty de plusieurs manières. De la plus influente à la moins influente, ce sont :

1.
Options de ligne de commande
2.
Paramètres de démarrage
3.
Variables d'environnement (si l'option -E (--variables-environnement) est active)
4.
Fichier de configuration
5.
Valeurs par défaut intégrées

Options de ligne de commande

Les options sont traitées séquentiellement de gauche à droite. Si une option est spécifiée plus d'une fois, ou en cas de conflit, la spécification la plus à droite a la priorité.

Les options suivantes sont prises en charge :

-a table (--table-attributs=)
Le chemin d'accès à la table des attributs. Les chemins relatifs sont ancrés à /usr/share/brltty/Attributes. L'extension .atb est optionnelle. La valeur par défaut intégrée est left_right.atb.
-b pilote,...|auto (--pilote-braille=)
Le pilote de l'afficheur braille (voir Spécification du pilote). La valeur par défaut intégrée est auto.
-c table (--table-contractions=)
Le chemin d'accès à la table des contractions. Les chemins relatifs sont ancrés à /usr/share/brltty/Contraction. L'extension .ctb est optionnelle.
-d périphérique,... (--périphérique-braille=)
Le périphérique auquel l'afficheur braille est connecté. La valeur par défaut intégrée est usb:,bluetooth:.

La forme générale d'une spécification de périphérique braille est qualificatif:donnée. Pour des raisons de compatibilité avec les versions antérieures, si le qualificatif est omis, serial: est supposé. Les types de périphériques suivants sont pris en charge :

Bluetooth
Pour un périphérique Bluetooth, spécifiez bluetooth:adresse. L'adresse doit être constituée de six nombres hexadécimaux à deux chiffres séparés par des deux-points, par exemple 01:23:45:67:89:AB.
Série
Pour un périphérique série, spécifiez serial:périphérique. Le qualificatif serial: est optionnel (pour la compatibilité ascendante). Si un chemin relatif est donné, il est ancré dans /dev/ (l'emplacement habituel où les périphériques sont définis dans un système de type Unix). Les spécifications de périphérique suivantes font toutes référence au périphérique série primaire sous Linux : serial:ttyS0, serial:/dev/ttyS0, ttyS0, /dev/ttyS0.
USB
Pour un périphérique USB, spécifiez usb:. brltty recherchera le premier périphérique USB qui correspond au pilote d'afficheur braille utilisé. Si cela est insuffisant, par exemple si vous avez plus d'un afficheur braille USB qui nécessite le même pilote, vous pouvez affiner la spécification du périphérique en lui ajoutant le numéro de série de l'afficheur, par exemple usb:12345. N.B. : la fonctionnalité « identification par numéro de série » ne fonctionne pas pour certains modèles car certains fabricants ne définissent pas du tout le descripteur de numéro de série USB ou le définissent mais pas avec une valeur unique.

Une liste de périphériques braille séparés par des virgules peut être spécifiée. Si cela est fait, la détection automatique est effectuée sur chaque périphérique listé en séquence. Cette fonctionnalité est particulièrement utile si vous avez un afficheur braille avec plus d'une interface, par exemple un port série et un port USB.

-e (--erreur-standard)
Écrit les journaux sur la sortie d'erreur standard plutôt que dans le journal du système (utile pour le débogage).
-f fichier (--fichier-configuration=)
Le chemin d'accès au fichier de configuration. Les chemins relatifs sont ancrés dans le répertoire de travail courant. La valeur par défaut intégrée est /etc/brltty.conf.
-h (--aide)
Affiche un résumé de l'utilisation de la ligne de commande (options couramment utilisées uniquement), puis quitte.
-i nom (--entrée-vocale=)
L'objet du système de fichiers (FIFO, tube nommé, socket nommé, etc.) qui donne aux autres applications l'accès au pilote vocal de brltty pour la conversion texte-parole. Il est créé au démarrage et supprimé à la terminaison. Les chemins relatifs sont ancrés dans le répertoire de travail courant. La valeur par défaut intégrée est que l'objet du système de fichiers n'est pas créé.
-k table (--table-clavier=)
Le chemin d'accès à la table du clavier. Les chemins relatifs sont ancrés dans /usr/share/brltty/Keyboard. L'extension .ktb est optionnelle.
-l niveau (--niveau-journal=)
Le niveau de gravité minimum pour les messages écrits dans le journal. N'importe lequel des nombres suivants, ou n'importe quelle abréviation de leurs noms correspondants, peut être spécifié :
0
urgence
1
alerte
2
critique
3
erreur
4
avertissement
5
notice
6
information
7
débogage

La valeur par défaut intégrée est notice.

-m périphérique (--périphérique-midi=)
Le périphérique à utiliser pour le Musical Instrument Digital Interface. Pour ALSA, c'est client:port, où chacun peut être soit un nombre, soit une sous-chaîne insensible à la casse de son nom. Pour d'autres interfaces, c'est le chemin complet vers un périphérique système approprié. La valeur par défaut intégrée est :
Linux/ALSA
le premier port de sortie MIDI disponible
Linux/OSS
/dev/sequencer
-n (--pas-de-daemon)
Rester en avant-plan (utile pour le débogage).
-o nom=valeur,... (--remplacer-préférence=)
Remplacer un paramètre de préférence. Pour l'emplacement du fichier de préférences, voir l'option -F (--fichier-préférences).
-p périphérique (--périphérique-pcm=)
Le périphérique à utiliser pour l'audio numérique. Pour ALSA, c'est nom[:argument,...]. Pour d'autres interfaces, c'est le chemin complet vers un périphérique système approprié. La valeur par défaut intégrée est :
FreeBSD
/dev/dsp
Linux/ALSA
hw:0,0
Linux/OSS
/dev/dsp
NetBSD
/dev/audio
OpenBSD
/dev/audio
Qnx
le périphérique de sortie PCM préféré
Solaris
/dev/audio
-q (--silencieux)
Supprime les messages de démarrage. Ceci est fait en réduisant le niveau de journal par défaut (voir l'option -l (--niveau-journal=)) à avertissement (information si soit -v (--verbosité)

Options de la ligne de commande

-a table (--attributes-table=)
Le chemin vers la table des attributs. Les chemins relatifs sont ancrés dans /usr/share/brltty/Attributes. L'extension .att est facultative. La valeur par défaut intégrée est en-net.
-b driver,...|auto (--braille-driver=)
Le pilote pour l'affichage braille (voir Spécification du pilote). La valeur par défaut intégrée est auto.
-c table (--contraction-table=)
Le chemin vers la table des contractions. Les chemins relatifs sont ancrés dans /usr/share/brltty/Contract. L'extension .ctb est facultative. La valeur par défaut intégrée est en-std (le code standard du braille informatique américain).
-d device,... (--braille-device=)
Le chemin d'accès au périphérique auquel l'écran braille est connecté. L'option auto est utilisée par défaut, ce qui active la détection automatique du périphérique.
-e driver,...|auto (--english-driver=)
Le pilote pour l'anglais. La valeur par défaut intégrée est auto.
-f file (--configuration-file=)
Le chemin vers le fichier de configuration. Les chemins relatifs sont ancrés dans /etc. La valeur par défaut intégrée est brltty.conf.
-g file (--keymap-file=)
Le chemin vers le fichier de mappage des touches. Les chemins relatifs sont ancrés dans /usr/share/brltty/Keymap. L'extension .keymap est facultative. La valeur par défaut intégrée est en-us.
-i file (--input-table=)
Le chemin vers la table d'entrée. Les chemins relatifs sont ancrés dans /usr/share/brltty/Input. L'extension .in est facultative. La valeur par défaut intégrée est en-std.
-k driver (--keyboard-driver=)
Le pilote pour le clavier. La valeur par défaut intégrée dépend du système d'exploitation.
-m device (--midi-device=)
Le périphérique à utiliser pour le MIDI (Musical Instrument Digital Interface).
-p device (--pcm-device=)
Le périphérique à utiliser pour l'audio numérique.
-q (--quiet)
Supprime tous les messages de démarrage. Il est également possible de supprimer les messages de démarrage avec l'option -v (--version).
-r (--release-device)
Libère le périphérique auquel l'écran braille est connecté lorsque l'écran ou la fenêtre actuelle ne peut pas être lu.
-s driver,...|auto (--speech-driver=)
Le pilote pour le synthétiseur vocal (voir Spécification du pilote). La valeur par défaut intégrée est auto.
-t table (--text-table=)
Le chemin vers la table de texte. Les chemins relatifs sont ancrés dans /usr/share/brltty/Text. L'extension .ttb est facultative. La valeur par défaut intégrée est en-nabcc.ttb (le code braille informatique nord-américain).
-v (--verify)
Affiche les messages de démarrage puis quitte. Cela inclut toujours les versions de brltty lui-même, du côté serveur de son interface de programmation d'application, et de chaque pilote braille et vocal sélectionné. Si l'option -q (--quiet) n'est pas également spécifiée, alors elle inclut également les valeurs des options après que toutes les sources aient été prises en compte. Si plus d'un pilote braille et/ou plus d'un périphérique braille ont été spécifiés, alors la détection automatique de l'écran braille est effectuée. Si plus d'un pilote vocal a été spécifié, alors la détection automatique du synthétiseur vocal est effectuée.
-x driver (--screen-driver=)
Le pilote d'écran. La valeur par défaut intégrée dépend du système d'exploitation.
-A name=value,... (--api-parameters=)
Paramètres pour l'interface de programmation d'application. Si le même paramètre est spécifié plus d'une fois, la spécification la plus à droite est utilisée. Les noms de paramètres peuvent être abrégés.
-B [driver:]name=value,... (--braille-parameters=)
Paramètres pour le pilote d'écran braille. Si le même paramètre est spécifié plus d'une fois, la spécification la plus à droite est utilisée. Les noms de paramètres peuvent être abrégés. Si une affectation de paramètre est qualifiée par un code d'identification de pilote, elle n'est traitée que si ce pilote d'écran braille est utilisé.
-D directory (--drivers-directory=)
Le chemin vers le répertoire qui contient les objets de pilotes chargeables dynamiquement. La valeur par défaut intégrée est /usr/lib/brltty.
-E (--environment-variables)
Reconnaît les variables d'environnement.
-F file (--preferences-file=)
Le chemin vers le fichier de préférences. Les chemins relatifs sont ancrés dans /var/lib/brltty. La valeur par défaut intégrée est brltty.prefs.
-H (--full-help)
Affiche un résumé de l'utilisation de la ligne de commande (toutes les options), puis quitte.
-I (--install-service)
(Windows uniquement) Installe brltty comme service BrlAPI afin qu'il démarre automatiquement au démarrage du système, et afin que les applications puissent savoir qu'un serveur BrlAPI est en cours d'exécution.
-K arg (--keyboard-properties=)
Propriétés du clavier.
-L file (--log-file=)
Le fichier dans lequel les messages de journalisation sont écrits. Les chemins relatifs sont ancrés dans le répertoire de travail actuel. Par défaut, les messages de journalisation sont envoyés au journal système.
-M csecs (--message-delay=)
Le temps de maintien des messages en centièmes de seconde. La valeur par défaut intégrée est 400 (4 secondes).
-N (--no-api)
Ne démarre pas l'interface de programmation d'application.
-P file (--pid-file=)
Le chemin complet du fichier identifiant le processus. Si cette option est fournie, brltty écrit son identifiant de processus (pid) dans le fichier spécifié au démarrage. Le fichier est supprimé lorsque brltty se termine.
-R (--remove-service)
(Windows uniquement) Supprime le service BrlAPI afin que brltty ne démarre pas automatiquement au démarrage du système, et afin que les applications puissent savoir qu'aucun serveur BrlAPI n'est en cours d'exécution.
-S [driver:]name=value,... (--speech-parameters=)
Paramètres pour le pilote du synthétiseur vocal. Si le même paramètre est spécifié plus d'une fois, la spécification la plus à droite est utilisée. Les noms de paramètres peuvent être abrégés. Si une affectation de paramètre est qualifiée par un code d'identification de pilote, elle n'est traitée que si ce pilote de synthétiseur vocal est utilisé.
-T directory (--tables-directory=)
Le chemin vers le répertoire qui contient les tables de texte, de contraction, d'attributs, de clavier et d'entrée. La valeur par défaut intégrée est /usr/share/brltty.
-U directory (--updatable-directory=)
Le chemin vers un répertoire qui contient des fichiers pouvant être mis à jour. La valeur par défaut intégrée est /var/lib/brltty.
-V (--version)
Affiche les versions de brltty lui-même, du côté serveur de son interface de programmation d'application, et des pilotes qui ont été configurés lors de la compilation, puis quitte. Si l'option -q (--quiet) n'est pas également spécifiée, alors affiche également les informations de copyright.
-W directory (--writable-directory=)
Le chemin vers un répertoire dans lequel il est possible d'écrire. La valeur par défaut intégrée est /run/brltty.
-X name=value,... (--screen-parameters=)
Paramètres pour le pilote d'écran. Si le même paramètre est spécifié plus d'une fois, la spécification la plus à droite est utilisée. Les noms de paramètres peuvent être abrégés.
-Y text (--start-message=)
Le texte à afficher lorsque le pilote braille démarre et à vocaliser lorsque le pilote vocal démarre. La valeur par défaut intégrée est BRLTTY 6.8.
-Z text (--stop-message=)
Le texte à afficher lorsque le pilote braille s'arrête. La valeur par défaut intégrée est BRLTTY stopped.

BRLTTY_BRAILLE_PARAMETERS=[driver:]name=value,...
Paramètres pour le pilote d'écran braille. Voir l'option -B (--braille-parameters=) pour plus de détails.
BRLTTY_CONFIGURATION_FILE=file

dt>

BRLTTY_SPEECH_PARAMETERS=[driver:]name=value,...

Le fichier de configuration

Les lignes vides sont ignorées. Si le caractère # apparaît sur une ligne, alors tous les caractères de celui-ci jusqu'à la fin de cette ligne sont traités comme un commentaire.

Les directives de configuration suivantes sont prises en charge :

api-parameters name=value,...
Paramètres pour l'interface de programmation d'application. Voir l'option -A (--api-parameters=) pour plus de détails.
attributes-table table
La table des attributs. Voir l'option -a (--attributes-table=) pour plus de détails.
braille-device device,...
Le périphérique auquel l'afficheur braille est connecté. Voir l'option -d (--braille-device=) pour plus de détails.
braille-driver driver,...|auto
Le pilote pour l'afficheur braille. Voir l'option -b (--braille-driver=) pour plus de détails.
braille-parameters [driver:]name=value,...
Paramètres pour le pilote de l'afficheur braille. Voir l'option -B (--braille-parameters=) pour plus de détails.
contraction-table table
La table de contractions. Voir l'option -c (--contraction-table=) pour plus de détails.
midi-device device
Le périphérique à utiliser pour le Musical Instrument Digital Interface. Voir l'option -m (--midi-device=) pour plus de détails.
pcm-device device
Le périphérique à utiliser pour l'audio numérique. Voir l'option -p (--pcm-device=) pour plus de détails.
preferences-file file
Le fichier de préférences. Voir l'option -F (--preferences-file=) pour plus de détails.
release-device on|off
Libérer le périphérique auquel l'afficheur braille est connecté lorsque l'écran ou la fenêtre courante ne peut pas être lue. Voir l'option -r (--release-device) pour plus de détails.
screen-driver driver
Le pilote d'écran. Voir l'option -x (--screen-driver=) pour plus de détails.
screen-parameters name=value,...
Paramètres pour le pilote d'écran. Voir l'option -X (--screen-parameters=) pour plus de détails.
speech-driver driver,...|auto
Le pilote pour le synthétiseur vocal. Voir l'option -s (--speech-driver=) pour plus de détails.
speech-input 0me
L'objet du système de fichiers qui donne aux autres applications accès au brltty's pilote de synthèse vocale pour la conversion texte-en-parole. Voir l'option -i (--speech-input=) pour plus de détails.
speech-parameters [driver:]name=value,...
Paramètres pour le pilote du synthétiseur vocal. Voir l'option -S (--speech-parameters=) pour plus de détails.
text-table table
La table de texte. Voir l'option -t (--text-table=) pour plus de détails.

Une liste de pilotes délimitée par des virgules peut être spécifiée. Si cela est fait, alors la détection automatique est effectuée en utilisant chaque pilote listé dans l'ordre. Vous devrez peut-être faire des expériences afin de déterminer l'ordre le plus fiable car certains pilotes se détectent mieux que d'autres.

Si le seul mot auto est spécifié, alors la détection automatique est effectuée en utilisant uniquement ces pilotes qui sont connus pour être fiables à cette fin.
