NOM

bundle-inject - Ajouter le(s) gem(s) nommé(s) avec les exigences de version à Gemfile

SYNOPSIS

bundle inject [GEM] [VERSION] [--source=SOURCE] [--group=GROUP]

DESCRIPTION

Ajoute le(s) gem(s) nommé(s) avec leurs exigences de version au [Gemfile(5)][Gemfile(5)] résolu.

Cette commande ajoutera le gem à la fois à votre [Gemfile(5)][Gemfile(5)] et à Gemfile.lock s'il n'y figure pas encore.

Exemple :

bundle install
bundle inject 'rack' '> 0'

Cela injectera le gem 'rack' avec une version supérieure à 0 dans votre [Gemfile(5)][Gemfile(5)] et Gemfile.lock.

La commande bundle inject a été dépréciée dans Bundler 2.1 et sera supprimée dans Bundler 4.0.

OPTIONS

--source=SOURCE
Installer le gem depuis la source donnée.
--group=GROUP
Installer le gem dans un groupe bundler.
