B43-FWCUTTER(1) Commandes utilisateur B43-FWCUTTER(1)

NOM

b43-fwcutter - Utilitaire pour extraire le firmware Broadcom 43xx

SYNTAXE

b43-fwcutter [OPTION] [PILOTE]

DESCRIPTION

b43-fwcutter peut extraire le firmware pour votre matériel Broadcom 43xx à partir de différents pilotes propriétaires. Le pilote b43 dépend de ces fichiers de firmware et ne peut pas fonctionner sans eux.

Actuellement, b43-fwcutter prend en charge les pilotes Apple MacOS X, Microsoft Windows et Linux, mais gardez à l'esprit que b43-fwcutter ne prend pas en charge toutes les versions de pilotes.

Exemple :

b43-fwcutter bcmwl5.sys

pour extraire le firmware de bcmwl5.sys

OPTIONS

-l|--list
Lister les versions de pilotes prises en charge
-i|--identify
Identifier uniquement le fichier du pilote (ne pas extraire)
-w|--target-dir DIR
Extraire et écrire le firmware dans DIR
-a|--alt-iv
Extraire les initvals alternatifs (uniquement 3.10.x.x)
-v|--version
Afficher la version de b43-fwcutter
-h|--help
Afficher les informations d'aide
