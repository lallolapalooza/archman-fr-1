NOM

bt_traversal - Fonctions de parcours/requête d'AST dans la bibliothèque btparse

SYNTAXE

AST * bt_next_entry (AST * entry_list, 
                     AST * prev_entry)
AST * bt_next_field  (AST * entry, AST * prev, char ** name)
AST * bt_next_value  (AST * head, 
                      AST * prev,
                      bt_nodetype_t * nodetype,
                      char ** text)
bt_metatype_t bt_entry_metatype (AST * entry)
char * bt_entry_type (AST * entry)
char * bt_entry_key   (AST * entry)
char * bt_get_text   (AST * node)

DESCRIPTION

Les fonctions décrites ici sont toutes utilisées pour parcourir et interroger les arbres syntaxiques abstraits (AST) renvoyés par les fonctions d'entrée décrites dans bt_input. Les trois fonctions "bt_next" (bt_next_entry(), bt_next_field(), et bt_next_value()) sont utilisées respectivement pour parcourir une liste d'entrées, la liste des champs d'une entrée particulière, et la liste des valeurs simples associées à un champ particulier. Les autres fonctions sont simplement utilisées pour interroger divers nœuds de l'arbre pour obtenir les informations utiles qu'ils contiennent.

Fonctions de parcours

bt_next_entry()
AST * bt_next_entry (AST * entry_list, 
                     AST * prev_entry)

Utilisé pour parcourir la liste chaînée d'entrées renvoyée par bt_parse_file() (voir bt_input). Lors du premier appel, vous devez fournir "NULL" pour "prev_entry", et un pointeur vers la tête de la liste sera renvoyé. Lors des appels suivants, passez la valeur de retour précédente comme "prev_entry" ; la fonction renvoie l'entrée suivante dans la liste, ou "NULL" s'il n'y a plus d'entrées. Renvoie également "NULL" si "entry_list" ou "prev_entry" sont incorrects.

Par exemple (en ignorant la gestion des erreurs et les déclarations de variables) :

entries = bt_parse_file (filename, options, &status);
entry = NULL;
while (entry = bt_next_entry (entries, entry))
{
   /* traiter l'entrée */
}
bt_next_field()
AST * bt_next_field  (AST * entry, AST * prev, char ** name)

Utilisé pour parcourir la liste des champs dans une définition d'entrée régulière ou de macro. (Vous devriez appeler bt_entry_metatype() pour déterminer si vous avez le bon type d'entrée avant d'appeler bt_next_field().) "entry" doit être un pointeur vers l'AST d'une seule entrée, tel que renvoyé par bt_parse_entry(), bt_parse_entry_s(), ou bt_next_entry(). Lors du premier appel, fournissez "NULL" pour "prev" ; bt_next_field() renverra un pointeur vers le premier champ dans "entry", ou "NULL" si "entry" n'a pas de champs (par exemple, si c'est une entrée de commentaire ou de préambule). Lors des appels suivants, passez la valeur de retour précédente comme "prev" ; bt_next_field() continuera à renvoyer des pointeurs vers des sous-AST de champs tant que cela est pertinent. Ces pointeurs peuvent ensuite être transmis à bt_next_value() ou bt_get_text() pour obtenir la valeur du champ.

Par exemple, le corps de la boucle dans l'exemple précédent pourrait être :

field = NULL;
while (field = bt_next_field (entry, field, &field_name))
{
   /* traiter le champ */
}
bt_next_value()
AST * bt_next_value (AST * head, 
                     AST * prev,
                     bt_nodetype_t * nodetype,
                     char ** text)

Parcourt la liste des valeurs simples qui composent la valeur d'un seul champ. (Rappelons qu'une valeur simple est soit une chaîne entre guillemets, soit une invocation de macro, soit un nombre. Une valeur composée est une liste de ceux-ci séparés par '#' dans l'entrée originale. Selon les options de post-traitement de chaîne utilisées lors de l'analyse des données, la nature de "liste de valeurs simples" des données originales peut être préservée dans l'AST que vous parcourez, auquel cas vous aurez besoin d'une boucle bt_next_value().

bt_next_value() fonctionne de manière très similaire à bt_next_entry() et bt_next_field() : lors du premier appel, vous fournissez "NULL" pour "prev", et lors des appels suivants, vous fournissez la valeur de retour précédente. Renvoie "NULL" lorsqu'il n'y a plus de valeurs simples à renvoyer. Définit également *nodetype et *text aux informations correspondantes du nœud de valeur simple. *nodetype sera l'un de "BTAST_STRING", "BTAST_MACRO", ou "BTAST_NUMBER" ; *text pointera vers la même chaîne que le nœud AST (elle n'est pas copiée pour vous), ne la modifiez donc pas.

Par exemple, le corps de la boucle dans l'exemple bt_next_field() pourrait être remplacé par :

value = NULL;
while (value = bt_next_field (field, value, &nodetype, &text))
{
   switch (nodetype)
   {
      case BTAST_STRING:    /* traiter la chaîne */
      case BTAST_MACRO:     /* traiter la macro */
      case BTAST_NUMBER:    /* traiter le nombre */
   }
}

Voir aussi "bt_get_text".

Fonctions de requête

bt_entry_metatype()
bt_metatype_t bt_entry_metatype (AST * entry)

Renvoie le métatype d'une entrée. (Rappelons que le métatype est un type énuméré dont les valeurs sont dérivées du type spécifique d'une entrée ; par exemple, une entrée @comment a le type "comment" et le métatype "BTE_COMMENT". La relation type-métatype est de même évidente pour "BTE_PREAMBLE" ; "BTE_MACRODEF" correspond aux entrées @string ; et "BTE_REGULAR" correspond à tout autre type.)

Renvoie "BTE_UNKNOWN" si "entry" est invalide (c'est-à-dire "NULL" ou pas un pointeur vers un AST d'entrée).

bt_entry_type()
char * bt_entry_type (AST * entry)

Renvoie le type d'une entrée. Rappelons que le type est le nom qui apparaît après le caractère '@' dans l'entrée originale. Renvoie "NULL" si "entry" est invalide (c'est-à-dire "NULL" ou pas un pointeur vers l'AST d'une entrée).

bt_entry_key()
char * bt_entry_key (AST * entry)

Renvoie la clé de citation d'une entrée régulière. (La clé de citation est le nom qui apparaît après le délimiteur d'ouverture de l'entrée dans une entrée régulière.) Renvoie "NULL" si "entry" est invalide (c'est-à-dire "NULL" ou pas un pointeur vers l'AST d'une entrée régulière).

bt_get_text()
char * bt_get_text (AST * node)

Effectue tout le post-traitement de chaîne

post-traitement (expansion de macro, concaténation de valeurs simples et réduction des espaces) d'une valeur composée et renvoie la chaîne qui en résulte. Peut être appelé soit sur un champ d'une entrée de définition régulière ou de macro (tel que renvoyé par bt_next_field()), soit sur une entrée de commentaire ou de préambule. Renvoie "NULL" si appelé sur un nœud AST invalide.
