BIGLOO(1) Manuel des commandes générales BIGLOO(1)

NOM

bigloo v2.3 - `un compilateur Scheme pratique'

SYNTAXE

bigloo [ options ] [ entrée ]

DESCRIPTION

Bigloo est un compilateur Scheme. Scheme est défini par la norme IEEE pour le langage de programmation Scheme, mais Bigloo ne s'y conforme pas entièrement. Le compilateur produit soit des fichiers C, soit des fichiers classe Java. Les fichiers C sont ensuite compilés par n'importe quel compilateur C ISO pour produire des fichiers .o ou des fichiers exécutables. Bigloo est un compilateur de modules, ce qui signifie qu'il est autorisé à compiler plusieurs fichiers et à les lier ensemble pour produire un exécutable unique.

OPTIONS

options
De nombreuses options sont disponibles. Tapez `bigloo -help' pour les afficher.
-jvm
Produit des fichiers classe Java au lieu de fichiers C. Cette option doit être utilisée lors de la compilation et lors de l'édition des liens.
-no-jvmjar
Désactive la production de fichiers jar lors de l'édition des liens avec -jvm.
entrée
Si un fichier d'entrée est fourni, Bigloo le compile. Sinon, l'interpréteur est lancé. L'entrée doit être un nom de fichier source Scheme reconnu (c'est-à-dire un nom de fichier avec une extension reconnue (voir l'option -suffix)).

FICHIER DE CONFIGURATION

Chaque utilisateur de Bigloo peut utiliser un fichier de configuration spécial. Ce fichier doit être nommé `~/.bigloorc'. Ce fichier permet de modifier le comportement du compilateur. Ce fichier est un fichier Scheme régulier qui contient des expressions liées dans un environnement où les paramètres du compilateur sont liés. Voir la documentation pour plus de détails.

VARIABLES D'ENVIRONNEMENT

BIGLOOHEAP
Définit la taille de la mémoire (en mégaoctets). La valeur par défaut est 4.
TMPDIR
Définit le répertoire temporaire. La valeur par défaut est `/tmp'.
BIGLOOLIB
Le chemin pour trouver la bibliothèque de Bigloo.
BIGLOOJAVAOPT
Options de la machine virtuelle Java lors de l'exécution d'une application Bigloo.

FICHIERS

/.../lib/bigloo/2.3a/bigloo.heap -- image de tas sauvegardée pour le compilateur.
/.../lib/bigloo/2.3a/bigloo.jheap -- image de tas sauvegardée pour le compilateur pour les compilations -jvm.
/.../lib/bigloo/2.3a/bigloo.h -- définitions qui sont incluses (`#include') dans le code C.
/.../lib/bigloo/2.3a/libbigloo.a -- bibliothèque.
/.../lib/bigloo/2.3a/libbigloo_u.a -- bibliothèque.
~/.bigloorc -- fichier de configuration utilisateur `runtime-command'.
/.../.bigloorc -- idem.
