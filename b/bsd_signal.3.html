bsd_signal(3) Manuel des fonctions de bibliothèque bsd_signal(3)

NOM

bsd_signal - gestion des signaux avec sémantique BSD

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNOPSIS

#include <signal.h>
typedef typeof(void (int))  *sighandler_t;
sighandler_t bsd_signal(int signum, sighandler_t handler);
Exigences pour le macro de test de fonctionnalité glibc (voir feature_test_macros(7)):

bsd_signal():

    Depuis glibc 2.26 :
        _XOPEN_SOURCE >= 500
            && ! (_POSIX_C_SOURCE >= 200809L)
    glibc 2.25 et versions antérieures :
        _XOPEN_SOURCE

DESCRIPTION

La fonction bsd_signal() prend les mêmes arguments et effectue la même tâche que signal(2).

La différence entre les deux est que bsd_signal() est garantie de fournir des sémantiques de signal fiables, c'est-à-dire : a) la disposition du signal n'est pas réinitialisée à la valeur par défaut lorsque le gestionnaire est invoqué ; b) la livraison d'autres instances du signal est bloquée pendant l'exécution du gestionnaire de signal ; et c) si le gestionnaire interrompt un appel système bloquant, alors l'appel système est automatiquement redémarré. Une application portable ne peut pas compter sur signal(2) pour fournir ces garanties.

VALEUR DE RETOUR

La fonction bsd_signal() renvoie la valeur précédente du gestionnaire de signal, ou SIG_ERR en cas d'erreur.

ERREURS

Comme pour signal(2).

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
bsd_signal () Thread safety MT-Safe

VERSIONS

L'utilisation de bsd_signal() doit être évitée ; utilisez plutôt sigaction(2).

Sur les systèmes Linux modernes, bsd_signal() et signal(2) sont équivalents. Mais sur les anciens systèmes, signal(2) fournissait des sémantiques de signal peu fiables ; voir signal(2) pour les détails.

L'utilisation de sighandler_t est une extension GNU ; ce type n'est défini que si le macro de test de fonctionnalité _GNU_SOURCE est défini.

NORMES

Aucune.

HISTORIQUE

4.2BSD, POSIX.1-2001. Supprimé dans POSIX.1-2008, recommandant l'utilisation de sigaction(2) à la place.

VOIR AUSSI

sigaction(2), signal(2), sysv_signal(3), signal(7)
