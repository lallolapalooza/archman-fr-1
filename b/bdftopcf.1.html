BDFTOPCF(1) Manuel des commandes générales BDFTOPCF(1)

NOM

bdftopcf - convertir une police X du format Bitmap Distribution Format au format Portable Compiled Format

SYNTAXE

bdftopcf [ -pn ] [ -un ] [ -m ] [ -l ] [ -M ] [ -L ] [ -t ] [ -i ] [ -o fichier_sortie ] fichier.bdf

DESCRIPTION

Bdftopcf est un compilateur de polices pour le serveur X et le serveur de polices. Les polices au format Portable Compiled Format peuvent être lues par n'importe quelle architecture, bien que le fichier soit structuré pour permettre à une architecture particulière de les lire directement sans reformatage. Cela permet une lecture rapide sur la machine appropriée, mais les fichiers sont toujours portables (mais lus plus lentement) sur d'autres machines.

OPTIONS

-pn
Définit le padding des glyphes de la police. Chaque glyphe de la police sera rembourré sur chaque ligne de balayage jusqu'à un multiple de n octets, où n est 1, 2, 4 ou 8.
-un
Définit l'unité de ligne de balayage de la police. Lorsque l'ordre des bits de la police est différent de l'ordre des octets de la police, l'unité de ligne de balayage n décrit quelle unité de données (en octets) doit être échangée ; l'unité i peut être de 1, 2 ou 4 octets.
-m
Définit l'ordre des bits de la police sur MSB (bit de poids fort) en premier. Les bits pour chaque glyphe seront placés dans cet ordre ; c'est-à-dire que le bit le plus à gauche de l'écran sera dans le bit de valeur la plus élevée de chaque unité.
-l
Définit l'ordre des bits de la police sur LSB (bit de poids faible) en premier. Le bit le plus à gauche de l'écran sera dans le bit de valeur la plus faible de chaque unité.
-M
Définit l'ordre des octets de la police sur MSB en premier. Toutes les données multioctets du fichier (métriques, bitmaps et tout le reste) seront écrites en commençant par l'octet le plus significatif.
-L
Définit l'ordre des octets de la police sur LSB en premier. Toutes les données multioctets du fichier (métriques, bitmaps et tout le reste) seront écrites en commençant par l'octet le moins significatif.
-t
Lorsque cette option est spécifiée, bdftopcf convertit les polices en polices « terminal » lorsque cela est possible. Une police terminale a chaque image de glyphe rembourrée à la même taille ; le serveur X peut généralement rendre ces types de polices plus rapidement.
-i
Cette option inhibe le calcul normal des métriques d'encre. Lorsqu'une police a des images de glyphes qui ne remplissent pas l'image bitmap (c'est-à-dire que les pixels « allumés » ne s'étendent pas jusqu'aux bords des métriques), bdftopcf calcule les métriques d'encre réelles et les place dans le fichier .pcf ; l'option -t inhibe ce comportement.
-o nom-du-fichier-sortie
Par défaut, bdftopcf écrit le fichier pcf sur la sortie standard ; cette option donne le nom d'un fichier à utiliser à la place.
-v
Affiche les informations de version et quitte.
