DESCRIPTIO

N

Ces macros opèrent sur des chaînes de

bits.

La macro bit_alloc() renvoie un pointeur de type «bitstr_t * » vers un espace suffisant pour stocker nbits bits, ou NULL si aucun espace n'est

disponible.

La macro bit_decl() alloue un espace suffisant pour stocker nbits bits sur la

pile.

La macro bitstr_size() renvoie le nombre d'éléments de type bitstr_t nécessaires pour stocker nbits bits. Ceci est utile pour copier des chaînes de

bits.

Les macros bit_clear() et bit_set() effacent ou définissent le bit numéroté à partir de zéro bit, dans la chaîne de bits name

.

Les bit_nset() et bit_nclear() macros définissent ou effacent les bits numérotés à partir de zéro de start à stop dans la chaîne de bits name

.

La macro bit_test() évalue à une valeur non nulle si le bit numéroté à partir de zéro bit de la chaîne de bits name est défini, et à zéro

sinon.

La macro bit_ffs() stocke dans l'emplacement référencé par value le numéro à partir de zéro du premier bit défini dans le tableau de nbits bits référencé par name. Si aucun bit n'est défini, l'emplacement référencé par value est défini à

-1.

La macro bit_ffc() stocke dans l'emplacement référencé par value le numéro à partir de zéro du premier bit non défini dans le tableau de nbits bits référencé par name. Si tous les bits sont définis, l'emplacement référencé par value est défini à

-1.

Les arguments de ces macros ne sont éval

ués qu'une seule fois et peuvent avo
ir des effets de bord en toute sécurité.
