NOM

"biber" — un remplacement de bibtex pour les utilisateurs de biblatex

SYNTAXE

biber [options] fichier[.bcf]
biber [options] --outil <source_de_donnees>
Crée "fichier.bbl" à l'aide du fichier de contrôle "fichier.bcf" (".bcf"
est facultatif). Normalement, l'utilisation avec biblatex ne nécessite
aucune option car elles sont toutes définies dans biblatex et transmises via
le fichier ".bcf".
En mode "outil" (voir l'option B<--outil>), prend une source de données
(par défaut la source de données "bibtex") et génère une copie de la
source de données avec les options appliquées par ligne de commande ou fichier
de configuration.
Veuillez exécuter "biber --aide" pour les détails des options.

DESCRIPTION

"biber" fournit un remplacement du processeur bibtex pour les utilisateurs de biblatex.

OPTIONS

--marqueur-annotation=[marqueur]
Définit le suffixe qui peut être ajouté au nom d'un champ d'une source de données BibTeX pour indiquer que la valeur du champ est une annotation de données. Le défaut est "+an".
--cache
S'exécute en tant que binaire PAR::Packer, affiche l'emplacement du cache et quitte.
--effacermacros
Efface tous les macros BibTeX (@STRING) entre les sections de références BibLaTeX. Cela empêche les avertissements BibTeX concernant les redéfinitions de macros si vous utilisez la même source de données plusieurs fois pour différentes sections de références.
--options-collation|-c [options]
Options à passer à l'objet "Unicode::Collate" utilisé pour le tri (par défaut "--options-collation niveau=4 --options-collation variable='non-ignorable'"). Voir "perldoc Unicode::Collate" pour les détails.
--fichier-config|-g [fichier]
Utilise fichier comme fichier de configuration pour "biber" au lieu de chercher dans les emplacements par défaut qui sont, par ordre :

* "biber.conf" ou ".biber.conf" dans le répertoire courant

* "$HOME/.biber.conf"

* "$XDG_CONFIG_HOME/biber/biber.conf"

* "$HOME/.config/biber/biber.conf"

* "$HOME/Library/biber/biber.conf" (uniquement Mac OS X)

* "$ENV{APPDATA}/biber.conf" (uniquement Windows)

* Le résultat de "kpsewhich biber.conf" (s'il est disponible sur le système).

En mode outil (--outil), le fichier biber-tool.conf installé avec Biber est toujours utilisé pour définir les options par défaut si un fichier de configuration défini par l'utilisateur n'est pas spécifié. Utilisez l'option --config-outil pour afficher l'emplacement du fichier de configuration d'outil par défaut, ce qui peut être utile comme source pour écrire le vôtre.

--convertir-controle
Convertit le fichier de contrôle .bcf en HTML à l'aide d'une transformation XSLT. Peut être utile pour le débogage. Le nom du fichier est obtenu en ajoutant ".html" au fichier .bcf.
--decodecharsset=[nom ensemble recode]
L'ensemble des caractères inclus dans la routine de conversion lors du décodage des macros LaTeX en UTF-8 (ce qui se produit lorsque --encodage-bbl|-E est défini sur UTF-8). Défini sur "plein" pour essayer plus fort avec un ensemble beaucoup plus large ou "base" pour utiliser un ensemble de base plus petit. Le défaut est "base". Vous pourriez vouloir essayer "plein" si vous avez des caractères UTF-8 moins courants dans votre source de données. Les ensembles de recodage sont définis dans le fichier de données de réencodage qui peut être personnalisé. Voir l'option --donnees-recodage et la documentation PDF. Le nom d'ensemble virtuel "null" peut être spécifié, ce qui désactive effectivement le décodage des macros.
--debug|-D
Active le débogage pour "biber".
--mourir-model-donnees
Quitte immédiatement avec une erreur si l'option "--valider-model-donnees" est utilisée et qu'une erreur de validation du modèle de données est trouvée. Le défaut est d'avertir et de continuer.
--point-inclure=section,champ,xdata,crossref,xref,related
Spécifie l'élément à inclure dans le format de sortie DOT de GraphViz si le format de sortie est 'dot'. Vous pouvez également choisir d'afficher les connexions de référence croisée, xref, xdata et/ou liées. Le défaut si non spécifié est "--point-inclure=section,xdata,crossref,xref".
--fixinits
Tente de corriger les initiales multiples brisées lorsqu'elles n'ont pas d'espace entre elles dans les sources de données BibTeX. C'est-à-dire que "A.B. Clarke" devient "A. B. Clarke" avant l'analyse des noms. Cela peut légèrement perturber des cas comme "{U.K. Government}" et d'autres cas ésotériques.
--aide|-h
Affiche ce message d'aide.
--repertoire-entree [repertoire]
Les fichiers .bcf et les fichiers de données seront recherchés en priorité dans le répertoire. Voir la documentation PDF de biber pour les autres possibilités et comment cela interagit avec l'option "--repertoire-sortie".
--encodage-entree|-e [encodage]
Spécifie l'encodage du ou des fichiers sources de données. Par défaut "UTF-8". Normalement, il n'est pas nécessaire de le définir car il est transmis via le fichier .bcf depuis l'option "bibencoding" de biblatex. Voir "perldoc Encode::Supported" pour une liste des encodages supportés. L'option héritée --encodage-bib est supportée comme alias.
--format-entree=bibtex|biblatexml
Format d'entrée Biber. Cette option n'a de sens qu'en mode outil (voir l'option outil) car normalement le format d'entrée d'une source de données est spécifié dans le fichier .bcf et donc à partir de la macro \addbibresouce dans BibLaTeX. La valeur par défaut en mode outil est 'bibtex'.

Force tous les ISBN en versions 10 chiffres en sortie. Cela convertira l'ISBN en interne en un objet ISBN qui n'aura pas de tirets en sortie. Si vous utilisez cette option et souhaitez un ISBN avec des tirets à la bonne place en sortie, utilisez l'option --normaliser-isbn.

Force tous les ISBN en versions 13 chiffres en sortie. Cela convertira l'ISBN en interne en un objet ISBN qui n'aura pas de tirets en sortie. Si vous utilisez cette option et souhaitez un ISBN avec des tirets à la bonne place en sortie, utilisez l'option --normaliser-isbn.

Normalise les ISBN avec des tirets aux bons endroits en sortie.
