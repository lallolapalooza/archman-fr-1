NOM

bpkg-pkg-checkout - extraire une version de paquet

SYNTAXE

bpkg pkg-checkout [options] paquet/version

DESCRIPTION

La commande pkg-checkout extrait la version spécifiée du paquet depuis l'un des dépôts basés sur le contrôle de version (bpkg-rep-add(1)). L'état résultant du paquet est décompressé (bpkg-pkg-status(1)).

Si l'option --output-root est passée, alors le paquet est extrait dans le répertoire spécifié plutôt que dans le répertoire de configuration. Dans ce cas, bpkg utilise le répertoire du paquet (source) en place, similaire au mode pkg-unpack --existing|-e. De plus, à moins que l'option --output-purge ne soit spécifiée, bpkg ne tentera pas de supprimer ce répertoire lorsque le paquet sera ultérieurement purgé avec la commande bpkg-pkg-purge(1). Notez également qu'un tel paquet n'est pas externe (voir bpkg-pkg-unpack(1) pour les détails).

Si l'option --replace|-r est spécifiée, alors pkg-checkout remplacera l'archive et/ou le répertoire source d'un paquet qui est déjà dans l'état décompressé ou récupéré.

OPTIONS PKG-CHECKOUT

--replace|-r
Remplace le répertoire source si le paquet est déjà récupéré ou décompressé.
--output-root dir
Extrait le paquet dans le répertoire spécifié plutôt que dans le répertoire de configuration. Notez que la source du paquet est placée dans le sous-répertoire paquet-version de ce répertoire.
--output-purge
Supprime le répertoire du paquet (source) extrait lorsque le paquet est purgé.
--directory|-d dir
Suppose que la configuration se trouve dans dir plutôt que dans le répertoire de travail courant.

NAME

bpkg-pkg-checkout - checkout package build sources

SYNOPSIS

bpkg --pkg-checkout [options] [package ...]

DESCRIPTION

The bpkg-pkg-checkout command checks out the build sources for the specified packages. If no packages are specified, then all packages in the current build are checked out.

The build sources are checked out into subdirectories of the current build directory, named after the package names.

PKG-CHECKOUT OPTIONS

The following options are specific to the pkg-checkout command:

--directory, -d
Checkout the package build sources into the specified directory.

COMMON OPTIONS

See bpkg(1) for the list of common build2 command-line options.

DEFAULT OPTIONS FILES

The bpkg(1) command initializes the build environment and imports packages. It searches for configuration files in the following order:

  1. A set of system-wide configuration files and package build directories are searched for the following files, in order, and loaded if found:

    bpkg.options
bpkg-pkg-checkout.options

  2. The following options files are searched for in each directory and, if found, loaded in the order listed:

    bpkg.options
bpkg-pkg-checkout.options

The following pkg-checkout command options cannot be specified in the default options files:

--directory|-d
