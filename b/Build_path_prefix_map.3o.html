Module Build_path_prefix_map
: sig end

Réécrire les chemins pour des builds reproductibles

Attention : ce module est instable et fait partie de Compiler_libs .

Voir la spécification BUILD_PATH_PREFIX_MAP

type path = string

type path_prefix = string

type error_message = string

val encode_prefix : path_prefix -> string

val decode_prefix : string -> (path_prefix, error_message) result

type pair = {
target : path_prefix ;
source : path_prefix ;
}

val encode_pair : pair -> string

val decode_pair : string -> (pair, error_message) result

type map = pair option list

val encode_map : map -> string

val decode_map : string -> (map, error_message) result

val rewrite_first : map -> path -> path option

rewrite_first map path essaie de trouver une source dans map qui est un préfixe du path d'entrée. Si cela réussit, il remplace ce préfixe par la cible correspondante. S'il échoue, il renvoie simplement None .

val rewrite_all : map -> path -> path list

rewrite_all map path trouve toutes les sources dans map qui sont un préfixe du path d'entrée. Pour chaque source correspondante, dans l'ordre de priorité, il remplace ce préfixe par la cible correspondante et ajoute le résultat à la liste renvoyée. S'il n'y a pas de correspondances, il renvoie simplement [] .

val rewrite : map -> path -> path

rewrite path utilise rewrite_first pour essayer de trouver un mappage pour le chemin. S'il est trouvé, il le renvoie, sinon il renvoie simplement path .
