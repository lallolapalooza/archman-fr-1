NOM

brightnessctl - lire et contrôler la luminosité des appareils

SYNTAXE

brightnessctl [options] [opération] [valeur...]

OPTIONS

-h, --help

Affiche cette aide.

-l, --list

Liste les appareils avec des contrôles de luminosité disponibles.

-q, --quiet

Supprime la sortie.

-p, --pretend

N'effectue pas les opérations d'écriture.

-m, --machine-readable

Produit une sortie lisible par machine.

-n, --min-value=VALEUR

Définit la valeur minimale de luminosité lors de l'utilisation de valeurs delta, par défaut à 1.

-e, --exponent=K

Change la courbe d'échelle des pourcentages en exponentielle (linéaire par défaut). L'exposant par défaut est 4.

Équation de pourcentage : % = [VALEUR]^[K] * [MAX] * 100^-[K].

La courbe exponentielle peut rendre les ajustements perceptuellement égaux.

-s, --save

Sauvegarde l'état dans un fichier temporaire.

-r, --restore

Restaure l'état précédemment sauvegardé.

-d, --device=APPAREIL

Spécifie le nom de l'appareil (peut être un joker).

-c, --class=CLASSE

Spécifie la classe de l'appareil.

-v, --version

Affiche la version et quitte.

OPÉRATIONS

i, info

Obtient les informations sur l'appareil.

g, get

Obtient la luminosité actuelle de l'appareil.

m, max

Obtient la luminosité maximale de l'appareil.

s, set VALEUR

Définit la luminosité de l'appareil.

VALEURS

Vous pouvez spécifier VALEUR pour la commande set sous forme absolue ou relative, et sous forme de valeur ou de delta par rapport à la valeur actuelle. Par exemple :

brightnessctl set 500

Définit la luminosité à 500.

brightnessctl set 50%

Définit la luminosité à 50% du maximum.

brightnessctl set 50-

Soustrait 50 de la luminosité actuelle.

brightnessctl set +10

Ajoute 10 à la luminosité actuelle.

brightnessctl set 50%-

Soustrait 50% du maximum de la luminosité actuelle.

brightnessctl set +10%

Ajoute 10% du maximum à la luminosité actuelle.
