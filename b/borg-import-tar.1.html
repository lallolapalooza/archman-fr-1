NOM

borg-import-tar - Créer une archive de sauvegarde à partir d'un fichier tar

SYNTAXE

borg [options communes] import-tar [options] ARCHIVE FICHIERTAR

DESCRIPTION

Cette commande crée une archive de sauvegarde à partir d'un fichier tar.

Lorsque '-' est utilisé comme chemin, Borg lira un flux tar depuis l'entrée standard.

Par défaut (--tar-filter=auto), Borg détectera si le fichier est compressé en fonction de son extension et redirigera le fichier via un filtre approprié :

  • .tar.gz ou .tgz : gzip -d
  • .tar.bz2 ou .tbz : bzip2 -d
  • .tar.xz ou .txz : xz -d
  • .tar.zstd ou .tar.zst : zstd -d
  • .tar.lz4 : lz4 -d

Alternativement, un programme --tar-filter peut être spécifié explicitement. Il doit lire les données compressées depuis stdin et afficher un flux tar décompressé sur stdout.

La plupart de la documentation de borg create s'applique. Notez que cette commande ne prend pas en charge l'exclusion de fichiers.

import-tar est une conversion avec perte : les drapeaux BSD, les ACL, les attributs étendus (xattrs), l'atime et ctime ne sont pas exportés. La résolution des horodatages est limitée aux secondes entières, et non à la résolution en nanosecondes autrement prise en charge par Borg.

Une option --sparse (comme dans borg create) n'est pas prise en charge.

import-tar lit les formats POSIX.1-1988 (ustar), POSIX.1-2001 (pax), GNU tar, UNIX V7 tar et SunOS tar avec attributs étendus.

Pour importer plusieurs fichiers tar dans une seule archive, ils peuvent simplement être concaténés (par exemple en utilisant "cat") en un seul fichier, et importés avec une option --ignore-zeros pour sauter les marqueurs d'arrêt entre eux.

OPTIONS

Voir borg-common(1) pour les options communes des commandes Borg.

arguments

ARCHIVE
nom de l'archive à créer (doit également être un nom de répertoire valide)
FICHIERTAR
fichier tar d'entrée. "-" pour lire depuis stdin.

options

--tar-filter
programme de filtrage pour rediriger les données
-s, --stats
afficher les statistiques de l'archive créée
--list
afficher la liste détaillée des éléments (fichiers, répertoires, ...)
--filter STATUSCHARS
afficher uniquement les éléments avec les caractères de statut donnés
--json
afficher les statistiques au format JSON (implique --stats)
--ignore-zeros
ignorer les blocs remplis de zéros dans le fichier tar d'entrée

Options d'archive

--comment COMMENTAIRE
ajouter un commentaire texte à l'archive
--timestamp TIMESTAMP
spécifier manuellement la date/heure de création de l'archive (UTC, format yyyy-mm-jjThh:mm:ss). Alternativement, fournir un fichier/répertoire de référence.
-c SECONDES, --checkpoint-interval SECONDES
écrire un point de contrôle toutes les SECONDES secondes (Par défaut : 1800)
--chunker-params PARAMS
spécifier les paramètres du chunker (ALGO, CHUNK_MIN_EXP, CHUNK_MAX_EXP, HASH_MASK_BITS, HASH_WINDOW_SIZE). Défaut : buzhash,19,23,21,4095
-C COMPRESSION, --compression COMPRESSION
sélectionner l'algorithme de compression, voir la sortie de la commande "borg help compression" pour les détails.
