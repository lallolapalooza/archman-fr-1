int LIBMTP_Check_Capability (LIBMTP_mtpdevice_t * device, LIBMTP_devicecap_t cap)

Cette fonction vérifie si le périphérique possède certaines capacités, afin d'éviter d'appeler des API qui pourraient perturber le périphérique.

Paramètres

device un pointeur vers le périphérique dont il faut vérifier la capacité.
cap la capacité à vérifier.

Retourne

0 si non supporté, toute autre valeur signifie que le périphérique possède la capacité demandée.

Références LIBMTP_DEVICECAP_CopyObject, LIBMTP_DEVICECAP_EditObjects, LIBMTP_DEVICECAP_GetPartialObject, LIBMTP_DEVICECAP_MoveObject, LIBMTP_DEVICECAP_SendPartialObject, et LIBMTP_mtpdevice_struct::params.

int LIBMTP_Get_Storage (LIBMTP_mtpdevice_t * device, int const

sortby)

Cette fonction met à jour tous les identifiants de stockage d'un appareil et leurs propriétés, puis crée une liste chaînée et place la tête de la liste dans la structure de l'appareil. Elle trie également cette liste de manière facultative. Si vous voulez afficher des informations de stockage dans votre application, vous devriez appeler cette fonction, puis déréférencer la structure de l'appareil (device->storage) pour obtenir des informations sur le

stockage.

Vous devez appeler ceci chaque fois que vous voulez mettre à jour la liste device->storage, par exemple chaque fois que vous devez vérifier l'espace de stockage disponible quelque

part.

AVERTISSEMENT : comme cette liste est mise à jour dynamiquement, ne référencez pas ses champs dans des applications externes par pointeur ! Par exemple, ne placez pas une référence vers un champ char *. Utilisez plutôt strncpy()

!

Paramètre

s
device un pointeur vers l'appareil pour lequel obtenir le stockage.
sortby un entier qui détermine le tri de la liste de stockage. Les méthodes de tri valides sont définies dans libmtp.h avec le préfixe LIBMTP_STORAGE_SORTBY_. 0 ou LIBMTP_STORAGE_SORTBY_NOTSORTED pour ne pas
trier.

Renvoi

e
0 en cas de succès, 1 en cas de succès mais seulement avec les identifiants de stockage, les propriétés du stockage n'ont pas pu être récupérées, et -1 signifie un
échec.
