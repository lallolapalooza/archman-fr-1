BIO_get_rpoll_descriptor(3ssl)

Paquet: openssl

Licences: Apache-2.0

BIO_GET_RPOLL_DESCRIPTOR(3ssl) OpenSSL BIO_GET_RPOLL_DESCRIPTOR(3ssl)

NOM

BIO_get_rpoll_descriptor, BIO_get_wpoll_descriptor - obtenir une structure qui peut être utilisée pour déterminer quand un objet BIO pourra être lu ou écrit à nouveau

SYNTAXE

#include <openssl/bio.h>
typedef struct bio_poll_descriptor_st {
    uint32_t type;
    union {
        int        fd;
        void       *custom;
        uintptr_t  custom_ui;
    } value;
} BIO_POLL_DESCRIPTOR;
int BIO_get_rpoll_descriptor(BIO *b, BIO_POLL_DESCRIPTOR *desc);
int BIO_get_wpoll_descriptor(BIO *b, BIO_POLL_DESCRIPTOR *desc);

DESCRIPTION

BIO_get_rpoll_descriptor() et BIO_get_wpoll_descriptor(), en cas de succès, remplissent *desc avec un descripteur de sondage (poll descriptor). Un descripteur de sondage est une union étiquetée qui représente une sorte de ressource système ou non système qui peut être utilisée pour la synchronisation sur les événements d'attente d'E/S.

BIO_get_rpoll_descriptor() produit un descripteur qui peut être utilisé pour déterminer quand le BIO peut (potentiellement) être lu à nouveau, et BIO_get_wpoll_descriptor() produit un descripteur qui peut être utilisé pour déterminer quand le BIO peut (potentiellement) être écrit à nouveau.

Il est permis à BIO_get_rpoll_descriptor() et BIO_get_wpoll_descriptor() de produire le même descripteur.

Les descripteurs de sondage peuvent représenter différents types d'informations. Un type typique de ressource qui pourrait être représentée par un descripteur de sondage est un descripteur de fichier système utilisable avec des API telles que select().

Les types de descripteurs de sondage définis par OpenSSL sont :

BIO_POLL_DESCRIPTOR_TYPE_NONE
Représente l'absence d'un descripteur de sondage valide. Il peut être utilisé par BIO_get_rpoll_descriptor() ou BIO_get_wpoll_descriptor() pour indiquer que le BIO n'est pas sondable en lecture ou en écriture respectivement.

Pour ce type, aucun champ de la valeur value de BIO_POLL_DESCRIPTOR n'est valide.

BIO_POLL_DESCRIPTOR_TYPE_SOCK_FD
Le descripteur de sondage représente une ressource de socket système. Le champ value.fd dans BIO_POLL_DESCRIPTOR est valide s'il n'est pas défini à -1.

La ressource est le type de handle utilisé par un système donné pour représenter les sockets, ce qui peut varier selon le système. Par exemple, sous Windows, la valeur est un SOCKET à utiliser avec l'API Winsock. Sur les plateformes de type POSIX, c'est un descripteur de fichier.

Lorsqu'un descripteur de sondage de ce type est produit par BIO_get_rpoll_descriptor(), il doit être sondé en lecture pour déterminer quand le BIO pourra éventuellement réussir une opération BIO_read() ; de même, lorsqu'un descripteur de sondage de ce type est produit par BIO_get_wpoll_descriptor(), il doit être sondé en écriture pour déterminer quand le BIO pourra éventuellement réussir une opération BIO_write().

BIO_POLL_DESCRIPTOR_CUSTOM_START
Les valeurs de type commençant par cette valeur (incluse) sont réservées à l'allocation par l'application pour des types de descripteurs de sondage personnalisés. N'importe quelle définition dans le champ union value peut être utilisée arbitrairement par l'application comme valeur opaque.

Étant donné que les descripteurs de sondage sont une structure d'union étiquetée, ils peuvent représenter différents types d'informations. De nouveaux types de descripteurs de sondage peuvent être définis, y compris par les applications, en fonction de leurs besoins.

VALEURS DE RETOUR

Les fonctions BIO_get_rpoll_descriptor() et BIO_get_wpoll_descriptor() retournent 1 en cas de succès et 0 en cas d'échec.

Ces fonctions peuvent réussir et initialiser *desc avec un descripteur de sondage de type BIO_POLL_DESCRIPTOR_TYPE_NONE pour indiquer que le BIO n'est pas sondable en lecture ou en écriture respectivement.

VOIR AUSSI

HISTORIQUE

Les fonctions BIO_get_rpoll_descriptor() et BIO_get_wpoll_descriptor() ont été ajoutées dans OpenSSL 3.2.
