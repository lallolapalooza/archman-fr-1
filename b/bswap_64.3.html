bswap(3) Manuel des fonctions de bibliothèque bswap(3)

NOM

bswap_16, bswap_32, bswap_64 - inverser l'ordre des octets

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <byteswap.h>
uint16_t bswap_16(uint16_t x);
uint32_t bswap_32(uint32_t x);
uint64_t bswap_64(uint64_t x);

DESCRIPTION

Ces fonctions retournent une valeur dans laquelle l'ordre des octets de leurs arguments de 2, 4 ou 8 octets est inversé.

VALEUR DE RETOUR

Ces fonctions retournent la valeur de leur argument avec les octets inversés.

ERREURS

Ces fonctions réussissent toujours.

NORMES

GNU.

EXEMPLES

Le programme ci-dessous échange les octets de l'entier 8 octets fourni comme argument de ligne de commande. La session shell suivante démontre l'utilisation du programme :


$ ./a.out 0x0123456789abcdef;
0x123456789abcdef ==> 0xefcdab8967452301

Source du programme

#include <byteswap.h>
#include <inttypes.h>
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>
int
main(int argc, char *argv[])
{
    uint64_t x;
    if (argc != 2) {
        fprintf(stderr, "Usage: %s <num>\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    x = strtoull(argv[1], NULL, 0);
    printf("%#" PRIx64 " ==> %#" PRIx64 "\n", x, bswap_64(x));
    exit(EXIT_SUCCESS);
}
