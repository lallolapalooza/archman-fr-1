NAME

bpkg-pkg-fetch - fetch package archive

SYNOPSIS

bpkg pkg-fetch [options] (pkg/ver | --existing|-e file)

DESCRIPTION

The pkg-fetch command fetches the archive for the specified package name and version from one of the archive-based repositories (bpkg-rep-add(1)). The resulting package state is fetched (bpkg-pkg-status(1)).

If the --replace|-r option is specified, then pkg-fetch will replace the archive of a package that is already in the fetched or unpacked state. Otherwise, pkg-fetch expects the package to not exist in the configuration.

If the --existing|-e option is used, then instead of the name and version arguments, pkg-fetch expects a local path to an existing package archive. In this case, bpkg will use the archive in place, without copying it into the configuration directory. Also, unless the --purge|-p option is specified, bpkg will not attempt to remove this archive when the package is later purged with the bpkg-pkg-purge(1) command.

PKG-FETCH OPTIONS

--replace|-r
Replace the archive if the package is already fetched or unpacked.
--existing|-e
Treat the argument as an existing package archive path rather than the package name/version to fetch.
--purge|-p
Remove the existing package archive when the package is purged.
--directory|-d dir
Assume configuration is in dir rather than in the current working directory.

NOM

bpkg-pkg-fetch - récupérer l'archive d'un paquet

SYNTAXE

bpkg pkg-fetch [options] (pkg/ver | --existing|-e fichier)

DESCRIPTION

La commande pkg-fetch récupère l'archive pour le nom de paquet et la version spécifiés à partir de l'un des dépôts basés sur des archives (bpkg-rep-add(1)). L'état résultant du paquet est fetched (bpkg-pkg-status(1)).

Si l'option --replace|-r est spécifiée, alors pkg-fetch remplacera l'archive d'un paquet qui est déjà dans l'état fetched ou unpacked. Sinon, pkg-fetch s'attend à ce que le paquet n'existe pas dans la configuration.

Si l'option --existing|-e est utilisée, alors au lieu des arguments de nom et de version, pkg-fetch s'attend à un chemin local vers une archive de paquet existante. Dans ce cas, bpkg utilisera l'archive sur place, sans la copier dans le répertoire de configuration. De plus, à moins que l'option --purge|-p ne soit spécifiée, bpkg n'essaiera pas de supprimer cette archive lorsque le paquet sera ultérieurement purifié avec la commande bpkg-pkg-purge(1).

OPTIONS PKG-FETCH

--replace|-r
Remplace l'archive si le paquet est déjà récupéré ou décompacté.
--existing|-e
Traite l'argument comme un chemin d'archive de paquet existant plutôt que comme le nom/version du paquet à récupérer.
--purge|-p
Supprime l'archive de paquet existante lorsque le paquet est purifié.
--directory|-d dir
Suppose que la configuration se trouve dans dir plutôt que dans le répertoire de travail actuel.
