NOM

BIO_new_CMS - BIO de filtrage en flux pour CMS

SYNTAXE

#include <openssl/cms.h>
BIO *BIO_new_CMS(BIO *out, CMS_ContentInfo *cms);

DESCRIPTION

BIO_new_CMS() renvoie une chaîne de BIO de filtrage en flux basée sur cms. La sortie du filtre est écrite dans out. Toutes les données écrites dans la chaîne sont automatiquement traduites dans une structure CMS au format BER du type approprié.

NOTES

La chaîne renvoyée par cette fonction se comporte comme un BIO de filtrage standard. Elle supporte les E/S non bloquantes. Le contenu est traité et diffusé à la volée et n'est pas conservé en mémoire simultanément : il est donc possible d'encoder de très grandes structures. Une fois tout le contenu écrit dans la chaîne, BIO_flush() doit être appelé pour finaliser la structure.

Le drapeau CMS_STREAM doit être inclus dans le paramètre flags correspondant de la fonction de création cms.

Si une application souhaite écrire des données supplémentaires dans les BIO out, les BIO doivent être retirés de la chaîne en utilisant BIO_pop() et libérés avec BIO_free() jusqu'à atteindre out. Si aucune donnée supplémentaire ne doit être écrite, BIO_free_all() peut être appelé pour libérer toute la chaîne.

Tout contenu écrit à travers le filtre est utilisé tel quel : aucune traduction canonique n'est effectuée.

Il est possible de chaîner plusieurs BIO pour, par exemple, créer une structure triple enveloppée, signée, chiffrée et signée. Dans ce cas, il incombe à l'application de définir le type de contenu interne de toute structure CMS_ContentInfo externe.

Il faut éviter un grand nombre de petites écritures dans la chaîne, car cela produirait une sortie composée de nombreuses structures OCTET STRING. Précéder d'un BIO de mise en tampon BIO_f_buffer() évitera cela.

BOGUES

Il n'existe actuellement pas de BIO inverse correspondant : c'est-à-dire un BIO qui peut décoder une structure CMS à la volée.

VALEURS DE RETOUR

BIO_new_CMS() renvoie une chaîne de BIO en cas de succès ou NULL en cas d'erreur. L'erreur peut être obtenue à partir de ERR_get_error(3).

VOIR AUSSI

ERR_get_error(3), CMS_sign(3), CMS_encrypt(3)

HISTORIQUE

La fonction BIO_new_CMS() a été ajoutée dans OpenSSL 1.0.0.
