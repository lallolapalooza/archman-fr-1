NOM

bpkg-pkg-configure - configurer un paquet

SYNOPSIS

bpkg pkg-configure [options] [cfg-var...] pkg

DESCRIPTION

La commande pkg-configure configure soit le paquet de code source précédemment décompressé (bpkg-pkg-unpack(1), bpkg-pkg-checkout(1)), soit un paquet présent dans le système.

Un paquet de code source hérite des valeurs de configuration communes de build2 qui ont été spécifiées lors de la création de la configuration (bpkg-cfg-create(1)). Des variables de configuration supplémentaires spécifiques au paquet peuvent être passées à pkg-configure (cfg-var).

Un paquet système est spécifié en utilisant la syntaxe sys:pkg[/ver]. Si la version du paquet (ver) n'est pas spécifiée, elle est considérée comme inconnue mais satisfaisant toute contrainte de dépendance. Une telle version est affichée comme *.

OPTIONS DE PKG-CONFIGURE

--directory|-d dir
Supposer que la configuration se trouve dans dir plutôt que dans le répertoire de travail courant.

-v

--quiet|-q

--stdout-format format
Format de représentation à utiliser pour l'affichage sur stdout.
--jobs|-j num

--no-result
Ne pas afficher les messages informatifs sur le résultat de l'exécution d'une commande ou de certaines de ses parties.
--structured-result fmt

--progress

--no-progress
Masquer les indicateurs de progression pour les opérations de longue durée, telles que les transferts réseau, la compilation, etc.
--diag-color
Utiliser la couleur dans les diagnostics.
--no-diag-color
Ne pas utiliser la couleur dans les diagnostics.
--build path
Le programme de build à utiliser pour compiler les paquets.
--build-option opt

--fetch-option opt

Le délai d'attente du programme de récupération et des programmes similaires (par exemple, git).
--pkg-proxy url
Serveur proxy HTTP à utiliser lors de la récupération des manifestes et des archives de paquets depuis des dépôts pkg distants.
--git path
Le programme git à utiliser pour récupérer les dépôts git.

FICHIERS D'OPTIONS PAR DÉFAUT

Voir bpkg-default-options-files(1) pour un aperçu des fichiers d'options par défaut. Pour la commande pkg-configure , le répertoire de départ de la recherche est le répertoire de configuration. Les fichiers d'options suivants sont recherchés dans chaque répertoire et, s'ils sont trouvés, chargés dans l'ordre indiqué :

bpkg.options
bpkg-pkg-configure.options

Les options de commande pkg-configure suivantes ne peuvent pas être spécifiées dans les fichiers d'options par défaut :

--directory|-d
