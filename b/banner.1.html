BANNER(1) Manuel des commandes générales BANNER(1)

NOM

banner - imprime de grandes lettres

SYNTAXE

banner [-Chlv] [-c caractère] [-f police] [-w colonnes] [--aide] [--utiliser-lettres] [--version] [--utiliser-caractere=caractere] [--police=police] [--largeur=colonnes] [texte...]

DESCRIPTION

Le programme banner est utilisé pour imprimer de grandes lettres à partir d'un texte donné. Si le texte n'est pas fourni sur la ligne de commande, il sera lu depuis l'entrée standard.

Cette implémentation de banner divise le texte en plusieurs lignes s'il est trop long pour tenir sur une seule ligne. La division se fait sur les limites de mots, si possible. Pour forcer un saut de ligne, incluez un caractère de nouvelle ligne dans le texte.

Notez que les espaces contigus sont réduits à un seul espace.

OPTIONS

-C, --centre
Centre chaque ligne du message.
-h, --aide
Affiche un message d'utilisation sur la sortie standard et quitte avec succès.
-l, --utiliser-lettres
Utilise des caractères individuels lors du dessin des lettres, c'est-à-dire : Dessine un `a' en utilisant des caractères `a', un `b' en utilisant des caractères `b', et ainsi de suite.
-V, --version
Affiche les informations de version sur la sortie standard puis quitte avec succès.
-c, --utiliser-caractere=caractere
Utilise le caractère donné lors du dessin des lettres. Le caractère par défaut est un astérisque (`*').
-f, --police=police
Sélectionne la police numéro colonnes pour dessiner les caractères. Il existe deux polices disponibles : La numéro 1 est la police par défaut. La numéro 2 est une police plus petite.
-w, --largeur=colonnes
Suppose que l'écran a une largeur de colonnes colonnes. La valeur par défaut est 75.
