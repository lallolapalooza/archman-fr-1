BPFTOOL(8) Manuel de l'administrateur système BPFTOOL(8)

NOM

BPFTOOL - outil d'inspection et de manipulation simple des programmes et des cartes eBPF

SYNTAXE

bpftool [OPTIONS] OBJET { COMMANDE | help }

bpftool batch file FICHIER

bpftool version

OBJET := { map | prog | link | cgroup | perf | net | feature | btf | gen | struct_ops | iter }

OPTIONS := { { -V | --version } | { -j | --json } [{ -p | --pretty }] | { -d | --debug } }

COMMANDES-CARTES := { show | list | create | dump | update | lookup | getnext | delete | pin | event_pipe | help }

COMMANDES-PROGS := { show | list | dump jited | dump xlated | pin | load | attach | detach | help }

COMMANDES-LIENS := { show | list | pin | detach | help }

COMMANDES-CGROUP := { show | list | attach | detach | help }

COMMANDES-PERF := { show | list | help }

COMMANDES-NET := { show | list | help }

COMMANDES-FONCTIONNALITES := { probe | help }

COMMANDES-BTF := { show | list | dump | help }

COMMANDES-GEN := { object | skeleton | min_core_btf | help }

COMMANDES-STRUCT-OPS := { show | list | dump | register | unregister | help }

COMMANDES-ITER := { pin | help }

DESCRIPTION

bpftool permet l'inspection et la modification simple des objets BPF sur le système.

Notez que le format de sortie de tous les outils n'est pas garanti stable et ne doit pas être utilisé comme dépendance.

OPTIONS

-h, --help
Affiche un bref message d'aide (similaire à bpftool help).
-V, --version
Affiche le numéro de version de bpftool (similaire à bpftool version), le numéro de version de libbpf utilisée, et les fonctionnalités optionnelles qui étaient incluses lors de la compilation de bpftool. Les fonctionnalités optionnelles incluent la liaison avec LLVM ou libbfd pour fournir le désassembleur pour les programmes JIT-ted (bpftool prog dump jited) et l'utilisation de squelettes BPF (certaines fonctionnalités comme bpftool prog profile ou l'affichage des pid associés aux objets BPF peuvent en dépendre).
-j, --json
Génère une sortie JSON. Pour les commandes qui ne peuvent pas produire de JSON, cette option n'a aucun effet.
-p, --pretty
Génère une sortie JSON lisible par l'homme. Implique -j.
-d, --debug
Affiche tous les journaux disponibles, même les informations de niveau débogage. Cela inclut les journaux de libbpf ainsi que ceux du vérificateur, lorsqu'on tente de charger des programmes.
-m, --mapcompat
Permet le chargement de cartes avec des définitions de cartes inconnues.
-n, --nomount
N'essaie pas de monter automatiquement de système de fichiers virtuel (tel que tracefs ou le système de fichiers virtuel BPF) lorsque cela est nécessaire.
