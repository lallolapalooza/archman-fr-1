DESCRIPTIO

N

bundledoc est un post-processeur pour le paquet snapshot qui regroupe l'ensemble des classes, paquets et fichiers nécessaires pour construire un document LaTeX donné. Il lit le fichier .dep que snapshot produit, trouve chacun des fichiers qui y sont mentionnés, et les regroupe dans un seul fichier d'archive (par ex., un fichier .tar.gz), adapté pour un déplacement entre systèmes, une transmission à un collègue,

etc.

Comme exemple le plus simple possible, considérons un fichier LaTeX appelé, disons, hello.t

ex : 
\RequirePackage{snapshot}       % Nécessaire pour bundledoc
\documentclass[11pt]{article}
\begin{document}
Hello, world!
\end{document}

La ligne "\RequirePackage{snapshot}" provoque la production d'un fichier hello.dep. Lorsque bundledoc reçoit ensuite le "hello.dep" en argument, il localise les fichiers dépendants -- snapshot.sty, article.cls, et size11.clo -- et les regroupe dans un seul fichier d'archive, avec hello.tex et un fichier MANIFEST (décrit dans

« OPTIONS 
», ci-dessous).

Le fichier de dépendances de snapshot ne liste pas le fichier LaTeX principal (celui qui est passé à latex). Afin que bundledoc puisse trouver et regrouper ce fichier, bundledoc suppose qu'il a le même nom que le fichier de dépendances snapshot mais avec une extension .tex. Lorsque bundledoc crée une archive (par ex., un fichier .tar ou .zip) contenant les fichiers du document, il les place tous dans un répertoire pour éviter d'encombrer le répertoire courant avec des fichiers. Si le fichier de dépendances donné est appelé somefile.dep, alors l'archive résultante stockera par défaut tous les fichiers dépendants dans un répertoire somefile. Pour changer le nom du répertoire, utilisez l'option "--directory

Bien que bundledoc archive normalement tous les fichiers nommés dans le fichier .dep, l'option "--localonly" indique à bundledoc d'exclure tous les fichiers situés dans un répertoire autre que celui du fichier .tex ou l'un de ses
sous-répertoires.

L'option "--exclude", qui peut être spécifiée à plusieurs reprises sur la ligne de commande, fait omettre de l'archive tous les fichiers dont le nom contient la chaî

L'option "--include", qui peut être spécifiée à plusieurs reprises sur la ligne de commande, indique à bundledoc d'inclure dans l'archive tous les fichiers correspondant à filespec, même s'ils ne sont pas référencés dans le fichier .

--manifest=fichier manifeste (par défaut : MANIFES
T)
En plus des fichiers dépendants, bundledoc inclut dans le fichier d'archive un fichier supplémentaire appelé, par défaut, ``MANIFEST''. MANIFEST est un fichier texte qui liste les noms de fichiers originaux de toutes les dépendances. Pour changer le nom du fichier de ``MANIFEST'' à autre chose, utilisez l'option "--manifest". Comme cas particulier, "--manifest=""" indique à bundledoc de ne pas inclure de fichier manifeste du
tout.
--listdeps=[yes|no|only|rel]...] (par défaut : « no 
»)
"--listdeps" accepte un ou plusieurs de "yes", "no", "only", ou "rel" sous forme de liste séparée par des virgules. Tant que le "no" n'apparaît pas dans cette liste, bundledoc produit toutes les dépendances du fichier LaTeX principal. Si la liste contient "rel", alors bundledoc produit la liste des dépendances avec des chemins relatifs. Si la liste contient "only", alors bundledoc se termine après l'affichage de la liste, sans produire
d'archive.

»)
Normalement, le fichier d'archive que bundledoc produit contient un seul répertoire -- et des sous-répertoires, si le document s'y réfère explicitement -- dans lequel se trouvent tous les fichiers dépendants.
