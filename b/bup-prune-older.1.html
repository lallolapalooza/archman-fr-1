NOM

bup-prune-older - supprimer les sauvegardes les plus anciennes

SYNTAXE

bup prune-older [options...] <branche...>

DESCRIPTION

bup prune-older supprime (efface définitivement) toutes les sauvegardes sauf celles conservées par les divers arguments de conservation détaillés ci-dessous. Au moins un argument de conservation doit être spécifié. Cette commande est équivalente à une invocation appropriée de bup rm suivie de bup gc.

AVERTISSEMENT : Il s'agit de l'une des rares commandes bup qui modifie votre archive de manière intentionnellement destructive. Cependant, si une tentative de join ou restore des données auxquelles vous tenez encore après le succès d'un prune-older, c'est un signe assez encourageant que les commandes ont fonctionné correctement. (La commande dev/compare-trees dans l'arborescence des sources peut être utilisée pour aider à tester les résultats avant/après.)

PERIODES DE CONSERVATION

Une période --keep (comme requis ci-dessous) doit être un entier suivi d'une échelle, ou “forever”. Par exemple, 12y spécifie une PÉRIODE de douze ans. Voici les échelles valides :

•
s indique les secondes
•
min indique les minutes (60s)
•
h indique les heures (60m)
•
d indique les jours (24h)
•
w indique les semaines (7d)
•
m indique les mois (31j)
•
y indique les années (366j)
•
forever est infiniment loin dans le passé

Comme indiqué, les PÉRIODES sont calculées par rapport à l'heure actuelle, ou à la valeur --wrt si spécifiée, et ne respectent aucun calendrier, donc --keep-dailies-for 5d signifie une période commençant exactement 5 * 24 * 60 * 60 secondes avant le point de départ.

OPTIONS

--keep-all-for PÉRIODE
lorsqu'aucune option --keep d'échelle inférieure ne s'applique, conserve toutes les sauvegardes dans la période donnée.
--keep-dailies-for PÉRIODE
lorsqu'aucune option --keep d'échelle inférieure ne s'applique, conserve la sauvegarde la plus récente pour chaque jour dans la période donnée.
--keep-monthlies-for PÉRIODE
lorsqu'aucune option --keep d'échelle inférieure ne s'applique, conserve la sauvegarde la plus récente pour chaque mois dans la période donnée.
--keep-yearlies-for PÉRIODE
lorsqu'aucune option --keep d'échelle inférieure ne s'applique, conserve la sauvegarde la plus récente pour chaque année dans la période donnée.
--wrt SECONDES_UTC
lors du calcul d'une période de conservation, place l'extrémité la plus récente de la plage à SECONDES_UTC, et toutes les sauvegardes plus récentes que cela seront conservées.
--pretend
ne fait rien, se contente de lister les actions qui seraient effectuées sur la sortie standard, une action par ligne comme ceci :
- SAUVEGARDE
+ SAUVEGARDE
...
--gc
nettoyer le dépôt après avoir supprimé les sauvegardes pertinentes. C'est le comportement par défaut, mais il peut être évité avec --no-gc.
--gc-threshold N
ne réécrire un fichier pack que s'il contient plus de N % de données inutiles ; sinon, le laisser tel quel. Le seuil par défaut est de 10 %.
-#, --compress #
définir le niveau de compression lors de la réécriture des données d'archive à # (une valeur de 0 à 9, où 9 est le plus élevé et 0 est aucune compression). La valeur par défaut est 1 (compression rapide et lâche).
-v, --verbose
augmenter la verbosité (peut être spécifié plusieurs fois).

NOTES

Lorsque --verbose est spécifié, les périodes de sauvegarde seront résumées sur la sortie d'erreur standard avec des lignes comme celles-ci :

conservation des sauvegardes mensuelles depuis 1969-07-20-201800
conservation de toutes les sauvegardes annuelles
...

Il est possible que l'implémentation actuelle ne parvienne pas à formater la date si, par exemple, elle est suffisamment ancienne. Dans ce cas, vous verrez quelque chose comme ceci :

conservation des sauvegardes annuelles depuis -30109891477 secondes avant 1969-12-31-180000
...

EXEMPLES

# Conserver toutes les sauvegardes du dernier mois, et toutes les sauvegardes mensuelles plus récentes pour
# la dernière année. Supprimer tout le reste.
$ bup prune-older --keep-all-for 1m --keep-monthlies-for 1y
# Conserver toutes les sauvegardes des 6 derniers mois et supprimer tout le reste,
# mais uniquement sur la branche semester.
$ bup prune-older --keep-all-for 6m semester
