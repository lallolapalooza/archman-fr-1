NOM

byobu-select-session - sélectionne et se connecte à une session byobu

DESCRIPTION

byobu-select-session est une application qui liste les sessions screen disponibles en cours d'exécution sur le système, et invite l'utilisateur à en sélectionner une. L'utilisateur a également la possibilité de créer une nouvelle session Byobu, ou de lancer le shell par défaut sans Byobu.

Si une sélection invalide est choisie 3 fois de suite, l'utilisateur est connecté à la session la plus récente.

Par défaut, si une seule session existe, l'utilisateur est connecté à cette session, et si aucune session n'existe, une nouvelle session est créée -- de sorte qu'il n'y ait pas d'invite interactive dans le comportement normal. Cependant, certains utilisateurs peuvent choisir d'être toujours invités en touchant le fichier $BYOBU_CONFIG_DIR/.always-select.

Notez que BYOBU_CONFIG_DIR=$HOME/.byobu.

Les sessions nommées qui commencent par un "." sont "cachées" de byobu-select-session(1). Ceci est utile, par exemple, si vous ne voulez pas qu'une session soit automatiquement sélectionnée à la connexion. Exemple :
byobu -S .hidden
