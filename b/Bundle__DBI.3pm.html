NOM

Bundle::DBI - Un paquet pour installer DBI et les modules requis.

SYNTAXE

perl -MCPAN -e 'install Bundle::DBI'

CONTENU

DBI - pour se connaître soi-même

DBI::Shell 11.91 - le shell en ligne de commande de DBI

Storable 2.06 - pour DBD::Proxy, DBI::ProxyServer, DBD::Forward

Net::Daemon 0.37 - pour DBD::Proxy et DBI::ProxyServer

RPC::PlServer 0.2016 - pour DBD::Proxy et DBI::ProxyServer

DBD::Multiplex 1.19 - traiter plusieurs identifiants de base de données comme un seul

DESCRIPTION

Ce paquet comprend tous les modules utilisés par l'interface de base de données Perl (DBI), créé par Tim Bunce.

Un Bundle est un module qui définit simplement une collection d'autres modules. Il est utilisé par le module CPAN pour automatiser le téléchargement, la compilation et l'installation des modules à partir des sites d'archives FTP de CPAN.

Ce paquet ne traite pas des divers pilotes de base de données (par exemple, DBD::Informix, DBD::Oracle, etc.), dont la plupart nécessitent des logiciels provenant de sources autres que CPAN. Vous devrez récupérer et compiler ces pilotes vous-même.
