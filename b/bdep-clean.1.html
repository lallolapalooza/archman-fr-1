DESCRIPTIO

N

La commande clean nettoie les paquets du projet dans une ou plusieurs configurations de build. De plus, les dépendances immédiates ou toutes les dépendances des paquets du projet peuvent être nettoyées en spécifiant les options --immediate|-i ou --recursive|-r,

respectivement.

En interne, clean exécute la commande bpkg-pkg-clean(1) qui n'est elle-même pas grand-chose de plus que l'opération clean du système de build (voir b(1) pour plus de détails). Par conséquent, l'utilité principale de cette commande est la capacité de référencer les configurations de build par leurs noms et les paquets du projet implicitement via le répertoire de travail courant, ainsi que de nettoyer les

dépendances.

Si aucun répertoire de projet ou de paquet n'est spécifié, le répertoire de travail courant est supposé. Si aucune configuration n'est spécifiée, les configurations par défaut sont supposées. Voir bdep-projects-configs(1) pour des détails sur la spécification des projets et des configurations. Les variables variable-config... optionnelles sont les variables de conf

iguration supplémentaires
à passer au système de build.

    bdep-clean(1)

    NOM

    bdep-clean — Nettoie le répertoire de construction d'un projet.

    SYNOPSE

    bdep-clean [OPTIONS]

    DESCRIPTION

    bdep-clean est un outil pour nettoyer le répertoire de construction d'un projet. Il supprime les fichiers générés lors de la construction, tels que les fichiers objets, les bibliothèques et les exécutables.

    OPTIONS

    Aucune option n'est prise en charge par cette version.

    EXEMPLES

    Pour nettoyer le répertoire de construction :

    bdep-clean

    BOGUES

    Aucun bogues connu.
