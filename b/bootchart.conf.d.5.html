NOM

bootchart.conf, bootchart.conf.d - Fichiers de configuration de l'outil d'analyse des performances de démarrage

SYNTAXE

/etc/systemd/bootchart.conf

/etc/systemd/bootchart.conf.d/*.conf

/run/systemd/bootchart.conf.d/*.conf

/usr/lib/systemd/bootchart.conf.d/*.conf

DESCRIPTION

Au démarrage, systemd-bootchart lira le fichier de configuration /etc/systemd/bootchart.conf, suivi des fichiers dans les répertoires bootchart.conf.d. Ces fichiers de configuration déterminent les paramètres de journalisation et la sortie graphique.

RÉPERTOIRES DE CONFIGURATION ET PRÉCÉDENCE

La configuration par défaut est définie lors de la compilation, donc un fichier de configuration n'est nécessaire que lorsqu'il est nécessaire de s'écarter de ces valeurs par défaut. Par défaut, le fichier de configuration dans /etc/systemd/ contient des entrées commentées montrant les valeurs par défaut comme guide pour l'administrateur. Ce fichier peut être modifié pour créer des substitutions locales.

Lorsque des paquets ont besoin de personnaliser la configuration, ils peuvent installer des snippets de configuration dans /usr/lib/systemd/*.conf.d/. Les fichiers dans /etc/ sont réservés à l'administrateur local, qui peut utiliser cette logique pour remplacer les fichiers de configuration installés par les paquets du vendeur. Le fichier de configuration principal est lu avant tous les répertoires de configuration, et a la plus basse précédence ; les entrées dans un fichier de l'un des répertoires de configuration remplacent les entrées dans le fichier de configuration unique. Les fichiers dans les sous-répertoires de configuration *.conf.d/ sont triés par leur nom de fichier par ordre lexicographique, indépendamment de celui de leurs sous-répertoires. Si plusieurs fichiers spécifient la même option, l'entrée du fichier portant le nom lexicographiquement le plus tardif prend la priorité. Il est recommandé de préfixer tous les noms de fichiers dans ces sous-répertoires avec un numéro à deux chiffres et un tiret, pour simplifier l'ordre des fichiers.

Pour désactiver un fichier de configuration fourni par le vendeur, la méthode recommandée consiste à placer un lien symbolique vers /dev/null dans le répertoire de configuration dans /etc/, avec le même nom de fichier que le fichier de configuration du vendeur.

OPTIONS

Samples=500

Configure la quantité d'échantillons à enregistrer au total avant que bootchart ne se termine. Chaque échantillon sera enregistré à des intervalles définis par Frequency=.

Frequency=25

Configure la fréquence d'enregistrement des échantillons. Cela peut être un nombre fractionnaire, mais doit être supérieur à 0,0. La plupart des systèmes peuvent supporter des valeurs inférieures à 25-50 sans impacter gravement le temps de démarrage.

Relative=no

Configure si l'axe gauche du graphique de sortie est égal à temps=0,0 (démarrage de CLOCK_MONOTONIC). Ceci est utile pour utiliser bootchart après le démarrage afin de profiler un système déjà démarré, sinon le graphique deviendrait extrêmement volumineux. S'il est défini sur yes, l'axe horizontal commence au premier échantillon enregistré au lieu de temps=0,0.

Filter=no

Configure si le graphique résultant doit omettre les tâches qui n'ont pas contribué de manière significative au démarrage. Les processus trop éphémères (vus dans un seul échantillon) ou qui ne consomment pas de temps CPU significatif (moins de 0,001sec) ne seront pas affichés dans le graphique de sortie.

Output=[chemin]

Configure le répertoire de sortie pour l'écriture des graphiques. Par défaut, bootchart écrit les graphiques dans /run/log.

Init=[chemin]

Configure bootchart pour exécuter un binaire non standard au lieu de /usr/lib/systemd/systemd. Cette option n'est pertinente que si bootchart a été invoqué depuis la ligne de commande du noyau avec init=/usr/lib/systemd/systemd-bootchart.

PlotMemoryUsage=no

Si défini sur yes, active la journalisation et le graphique de la consommation de mémoire PSS des processus.

PlotEntropyGraph=no

Si défini sur yes, active la journalisation et le graphique de la taille du pool d'entropie aléatoire du noyau.

ScaleX=100

Facteur d'échelle horizontal pour tous les composants variables du graphique.

ScaleY=20

Facteur d'échelle vertical pour tous les composants variables du graphique.

ControlGroup=no

Afficher le groupe de contrôle des processus.

Cmdline=no

Afficher la ligne de commande complète de chaque processus.
