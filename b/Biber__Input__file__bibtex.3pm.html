Biber::Input::file::bibtex(3pm) Documentation Perl fournie par l'utilisateur Biber::Input::file::bibtex(3pm)

init_cache

Invalide le cache de l'objet T::B. Utilisé uniquement dans les tests lorsque, par exemple, nous changeons les paramètres d'encodage et devons donc forcer une relecture des données

TBSIG

Gestionnaire de signaux pour intercepter les SEGFAULTS fatals de Text::BibTex. Il contient des bugs et nous voulons au moins dire quelque chose s'il plante

extract_entries

Routine principale d'extraction des données.
Accepte un identifiant de source de données, prétraite le fichier, puis
recherche les clés passées, créant des entrées lorsqu'elle les trouve et
renvoie un tableau des clés qu'elle n'a pas trouvées.

create_entry

Crée un objet Biber::Entry à partir d'un objet Text::BibTeX.
Soyez prudent ici, toutes les méthodes de réglage de T::B sont des frontières UTF-8/NFC,
donc faites attention à encoder(NFC()) lors des appels. Windows ne gérera pas correctement l'UTF-8
dans T::B btparse et cela plantera.

cache_data

Met en cache les données du fichier dans des objets T::B indexés par la clé
de la source de données d'origine, décodés en UTF8.

preprocess_file

Convertit le fichier en UTF-8 et décode potentiellement les macros LaTeX en UTF-8.

parse_decode

Analyse partiellement la source de données .bib et décode les contenus des données LaTeX.
Nous le faisons car le décodage LaTeX de tout le tampon est difficile car
ce décodage est basé sur des expressions régulières et comme les accolades sont utilisées pour protéger les données dans
les fichiers .bib, cela rend l'analyse difficile.

parsename

Étant donné une chaîne de nom, cette fonction renvoie un objet Biber::Entry::Name
avec toutes les parties du nom résolues selon les conventions BibTeX.
parsename('John Doe', 'author', 'key')
renvoie un objet qui ressemble en interne un peu à ceci :
{ given          => {string => 'John', initial => ['J']},
  family         => {string => 'Doe', initial => ['D']},
  prefix         => {string => undef, initial => undef},
  suffix         => {string => undef, initial => undef},
  id             => 32RS0Wuj0P,
  strip          => {'given'  => 0,
                     'family' => 0,
                     'prefix' => 0,
                     'suffix' => 0}
  }

parsename_x

Étant donné une chaîne de nom au format étendu, cette fonction renvoie un objet Biber::Entry::Name
avec toutes les parties du nom résolues selon les conventions BibTeX.
parsename_x('given=John, family=Doe')
renvoie un objet qui ressemble en interne un peu à ceci :
{ given          => {string => 'John', initial => ['J']},
  family         => {string => 'Doe', initial => ['D']},
  prefix         => {string => undef, initial => undef},
  suffix         => {string => undef, initial => undef},
  id             => 32RS0Wuj0P,
  hashid         => 'someid',
  sortingnamekeytemplatename => 'template name',
}

NOM

Biber::Input::file::bibtex - recherche une entrée dans un fichier BibTeX et la crée si elle est trouvée

DESCRIPTION

Fournit la méthode extract_entries() pour obtenir des entrées à partir d'une source de données BibTeX et instancier des objets Biber::Entry pour ce qu'elle trouve.
