bpkg-rep-info(1) Manuel des commandes générales bpkg-rep-info(1)

NOM

bpkg-rep-info - affiche les informations du dépôt

SYNTAXE

bpkg rep-info [options] loc-dépôt

DESCRIPTION

La commande rep-info affiche diverses informations sur le dépôt spécifié. Par défaut, elle affiche le nom et l'emplacement du dépôt en première ligne. Si le dépôt est signé, les informations du certificat (nom/organisation/email) sont affichées sur la ligne suivante, suivies de l'empreinte du certificat. Vient ensuite la liste des dépôts complémentaires et prérequis, suivie de la liste des paquets disponibles.

Ce format par défaut peut être modifié de diverses manières à l'aide des options listées ci-dessous. Notez également que les informations sont écrites sur stdout, pas sur stderr.

Si le répertoire de travail courant contient une configuration bpkg, alors rep-info utilisera sa base de données de certificats pour l'authentification du dépôt. C'est-à-dire qu'il fera confiance au certificat du dépôt s'il est déjà approuvé par la configuration. Sinon, il ajoutera le certificat à la configuration si vous confirmez qu'il est approuvé. Vous pouvez spécifier un répertoire de configuration alternatif avec l'option --directory|-d. Pour désactiver l'utilisation de la configuration dans le répertoire de travail courant, passez cette option avec un chemin vide.

OPTIONS_REP-INFO

--name|-n
Affiche le nom et l'emplacement du dépôt.
--cert-fingerprint
Affiche l'empreinte du certificat du dépôt ou une ligne vide si le dépôt n'est pas signé.
--cert-name
Affiche le nom commun (CN) du certificat du dépôt ou une ligne vide si le dépôt n'est pas signé.
--cert-organization
Affiche le nom de l'organisation (O) du certificat du dépôt ou une ligne vide si le dépôt n'est pas signé.
--cert-email
Affiche l'adresse e-mail du certificat du dépôt ou une ligne vide si le dépôt n'est pas signé.
--repositories|-r
Affiche la liste des dépôts complémentaires et prérequis.
--packages|-p
Affiche la liste des paquets disponibles.
--manifest
Au lieu d'afficher les informations sous forme lisible par l'homme, les écrit (sur stdout) sous forme de manifeste(s). Normalement, vous utiliserez cette option en combinaison avec --packages|-p ou --repositories|-r pour écrire uniquement l'un des manifestes. Si l'option --deep est spécifiée, alors dans le manifeste de paquets résultant, les valeurs *-file sont remplacées par le contenu des fichiers référencés et les valeurs *-build sont automatiquement ajoutées (sauf si les fichiers correspondants sont absents). Voir aussi --ignore-unknown, --repositories-file et --packages-file.
--ignore-unknown
Ignore les entrées de manifeste inconnues. Notez que cette option ignore également les contraintes de version dans les dépendances spéciales de construction d'outils. Cette option est implicite si --manifest n'est pas spécifié.
--deep
Vérifie la présence des valeurs/fichiers requis *-build et la validité des fichiers référencés par les valeurs *-file du manifeste.
--repositories-file chemin
Si --manifest est spécifié, enregistre alors le manifeste des dépôts dans le fichier spécifié au lieu de l'écrire sur stdout.
--packages-file chemin
Si --manifest est spécifié, enregistre alors le manifeste des paquets dans le fichier spécifié au lieu de l'écrire sur stdout.
--type type
Spécifie le type de dépôt avec les valeurs valides : pkg, dir et git. Référez-vous à bpkg-rep-add(1) pour plus de détails.
--directory|-d dir
Utilise la configuration dans dir pour la base de données des certificats approuvés.

FICHIERS D'OPTIONS PAR DÉFAUT

Voir bpkg-default-options-files(1) pour un aperçu des fichiers d'options par défaut. Si la commande rep-info utilise une configuration bpkg existante, alors le répertoire de départ est le répertoire de configuration. Sinon, seuls les répertoires prédéfinis (home, système, etc.) sont recherchés. Les fichiers d'options suivants sont recherchés dans chaque répertoire et, s'ils sont trouvés, chargés dans l'ordre indiqué :

bpkg.options
bpkg-rep-info.options

Les options de la commande rep-info suivantes ne peuvent pas être spécifiées dans les fichiers d'options par défaut :

--directory|-d
