NAME

Business::ISBN::Data - pack de données pour Business::ISBN

SYNOPSIS

voir Business::ISBN

DESCRIPTION

Vous n'avez pas besoin de charger ce module vous-même dans la plupart des cas. Business::ISBN le chargera lors de son chargement. Vous devez utiliser Business::ISBN 3.005 ou une version ultérieure car la structure des données a légèrement changé pour corriger un bug avec les préfixes ISBN13.

Ces données sont générées à partir du fichier RangeMessage.xml fourni par l'Agence ISBN. La version distribuée correspond à la date indiquée dans la version de ce module. Vous pouvez la récupérer vous-même à https://www.isbn-international.org/range_file_generation. Ce fichier est inclus dans la distribution et devrait être installé dans ~lib/Business/ISBN/Data/RangeMessage.xml.

Si vous souhaitez utiliser un fichier RangeMessage.xml différent, vous pouvez définir la variable d'environnement "ISBN_RANGE_MESSAGE" avec l'emplacement alternatif avant de charger "Business::ISBN". Ainsi, vous pouvez utiliser les données les plus récentes (ou même antérieures) sans avoir à installer quelque chose de nouveau ou à attendre une mise à jour de ce module.

Si le fichier RangeMessage.xml par défaut ou votre fichier alternatif n'est pas disponible, le module utilise par défaut les données incluses dans Data.pm. Cependant, ces données sont susceptibles d'être plus anciennes. S'il ne trouve pas ce fichier, il recherche RangeMessage.xml dans le répertoire courant.

Les données se trouvent dans %Business::ISBN::country_data (bien que la partie "country" soit historique). Si vous voulez voir d'où viennent les données, consultez $Business::ISBN::country_data{_source}.

Packaging de ce module

Le fichier RangeMessage.xml inclus se trouve sous lib/ au même niveau que Data.pm. Les mêmes données existent en tant que données par défaut dans le code, vous n'avez donc pas besoin de fournir le fichier RangeMessage.xml distribué. Cependant, vous pouvez inclure un fichier RangeMessage.xml plus récent.

Avec PAR, vous pouvez ajouter des fichiers supplémentaires à l'archive avec "-a". Placez le nouveau fichier quelque part où le module le trouvera (ou utilisez "ISBN_RANGE_MESSAGE" pour le guider jusqu'à là) :

pp ... -a '..../RangeMessage.xml;RangeMessage.xml'

Si vous placez le fichier RangeMessage.xml dans le répertoire de travail courant de l'application, le module devrait le trouver.

Mise à jour des données par défaut

Dans le dépôt, trouvez le programme examples/make_default_data.pl. Exécutez-le avec le dernier fichier RangeMessage.xml :

% perl -Ilib examples/make_default_data.pl RangeMessage.xml

Cela produit le code dont vous avez besoin pour remplacer dans le module. Vérifiez que ces données ne sont pas étranges : parfois les noms de groupes ont des erreurs ou des bizarreries. Le programme gère l'échappement des apostrophes et la suppression des espaces blancs.
