NOM

bup-server - le côté serveur de la relation client-serveur de bup

SYNTAXE

bup server

DESCRIPTION

bup server est le côté serveur d'une session bup à distance. Si vous utilisez bup-split(1) ou bup-save(1) avec l'option -r, ils se connecteront via ssh au serveur distant et exécuteront bup server pour recevoir les objets transmis.

Il n'y a normalement aucune raison d'exécuter bup server vous-même.

MODES

smart
Dans ce mode, le serveur vérifie chaque objet entrant par rapport aux fichiers idx de son dépôt. Si un objet existe déjà, il informe le client du fichier idx dans lequel il a été trouvé, permettant ainsi au client de télécharger ce idx et d'éviter d'envoyer des données en double. C'est le mode par défaut de bup-server.
dumb
Dans ce mode, le serveur ne vérifiera pas son index local avant d'écrire un objet. Pour éviter d'écrire des objets en double, le serveur demandera au client de télécharger tous ses fichiers .idx au début de la session. Ce mode est utile sur du matériel serveur peu puissant (par exemple, un routeur/NAS lent).

FICHIERS

$BUP_DIR/bup-dumb-server
Active le mode serveur "dumb" (idiot), comme discuté ci-dessus. Ce fichier n'est pas créé par défaut dans les nouveaux dépôts.
