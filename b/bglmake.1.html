BGLMAKE(1) Manuel des commandes générales BGLMAKE(1)

NOM

bglmake - créer ou mettre à jour des makefiles Bigloo

SYNTAXE

bglmake [ options ] [ fichier-source ]

DESCRIPTION

bglmake lit le fichier-source, calcule la fermeture transitive de la relation d'importation et génère un fichier makefile qui peut être utilisé par le programme glmake(1) pour compiler l'application ou la bibliothèque. Si aucun fichier-source n'est fourni, bglmake affiche le fichier modèle pour la génération du Makefile.

OPTIONS

-v
Mode verbeux.
-q
Empêche le chargement du fichier de configuration utilisateur ~/.bglmakerc.
-suffixe <suf>
Ajoute suf à la liste des suffixes de fichiers source de bglmake. Les suffixes par défaut sont "scm", "sch" et "bgl".
fichier
est le nom du fichier "principal" pour une application ou le nom du fichier "heap" pour une bibliothèque.
-I<chemin>
Ajoute chemin à la liste des répertoires lus pour rechercher les fichiers source Bigloo.
-X<chemin>
Exclut chemin de la liste des répertoires lus pour rechercher les fichiers source Bigloo.
-o <makefile>
Le nom du fichier makefile à mettre à jour.
-p <nom>
Le nom du projet. Ce nom est utilisé dans les entrées de sauvegarde et de versionnement.
-t <nom>
Le nom du fichier binaire cible ou le nom de la bibliothèque.
-f<modèle>
Définit un fichier modèle alternatif.
-objet <obj>
Met à jour le makefile pour ajouter obj à la liste des objets.
-source <src>
Met à jour le makefile pour ajouter src à la liste des fichiers source.
-principal <fichier>
Définit le fichier principal initial et indique à bglmake que le projet est une "application" (par opposition aux bibliothèques). Ce Fichier est le point de départ de la fermeture transitive des modules importés.
-heap <fichier>
Définit le fichier heap initial et indique à bglmake que le projet est une "bibliothèque" (par opposition aux applications). Ce Fichier est le point de départ de la fermeture transitive des modules importés.

MODÈLES

Lorsque bglmake génère un makefile, il utilise des modèles. Ces modèles peuvent être spécifiés avec une option ou être affichés. Pour cela, il suffit d'appeler bglmake sans aucun paramètre. Les fichiers modèles utilisent quelques "macros" supplémentaires. Ce sont :

$[PROJECT]
cette macro est remplacée par le nom du projet (option -p). Si aucune option -p n'est utilisée, le nom de projet par défaut est le nom du répertoire courant qui contient le fichier-source.
$[TARGET_NAME]
cette macro est remplacée par le nom de la cible (option -t). Si aucune option -t n'est utilisée, le nom de cible par défaut est le nom du répertoire courant qui contient le fichier-source.
$[MAKEFILE]
cette macro est remplacée par le nom du makefile (option -o).

EXEMPLE

Un Makefile est créé par ``bglmake foo.scm -o Makefile''. Il peut ensuite être mis à jour avec ``make updatemakefile''.
