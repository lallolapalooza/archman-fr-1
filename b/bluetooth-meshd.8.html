Nom

bluetooth-meshd - Démon de maillage Bluetooth

SYNOPSIS

bluetooth-meshd [options ...]

DESCRIPTION

Démon pour gérer les connexions Bluetooth Mesh sous Linux.

OPTIONS

-h, --help
Affiche les options de bluetooth-meshd et quitte.
-n, --nodetach
Active la journalisation en premier plan. Dirige la sortie du journal vers le terminal de contrôle en plus de syslog.
-i <type>, --io <type>
Spécifie le type d'interface d'E/S :

auto - Utilise le premier contrôleur disponible : via l'interface MGMT si le noyau le prend en charge, sinon, via un socket HCI brut.

generic:[hci]<index> - Utilise les E/S HCI génériques sur l'interface hci<index>.

unit:<fd_path> - Spécifie un descripteur de fichier ouvert pour les tests du démon.

Par défaut, si aucun type n'est spécifié, utilise l'E/S automatique sur le premier contrôleur disponible.

-c <fichier>, --config <fichier>
Spécifie un chemin de fichier de configuration explicite au lieu de s'appuyer sur le chemin par défaut (/etc/bluetooth/mesh-main.conf) pour le fichier de configuration.
-s <chemin_dir>, --storage <chemin_dir>
Spécifie un chemin de répertoire de stockage explicite au lieu du chemin par défaut (/var/lib/bluetooth/mesh) pour stocker la configuration du ou des nœuds mesh.
-d, --debug
Active la sortie de débogage.
-b, --dbus-debug
Active la sortie de débogage D-Bus.

FICHIERS

/etc/bluetooth/mesh-main.conf
Emplacement du fichier de configuration global contenant les paramètres du démon mesh.
