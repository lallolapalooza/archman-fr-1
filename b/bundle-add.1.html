BUNDLE-ADD(1) Manuel des commandes générales BUNDLE-ADD(1)

NOM

bundle-add - Ajoute une gem au Gemfile et exécute bundle install

SYNTAXE

bundle add NOM_DE_GEM [--group=GROUPE] [--version=VERSION] [--source=SOURCE] [--path=CHEMIN] [--git=GIT|--github=GITHUB] [--branch=BRANCHE] [--ref=REF] [--quiet] [--skip-install] [--strict|--optimistic]

DESCRIPTION

Ajoute la gem nommée au [Gemfile(5)][Gemfile(5)] et exécute bundle install. bundle install peut être évité en utilisant l'option --skip-install.

OPTIONS

--version=VERSION, -v=VERSION
Spécifie les exigences de version pour la gem ajoutée.
--group=GROUPE, -g=GROUPE
Spécifie le ou les groupes pour la gem ajoutée. Plusieurs groupes doivent être séparés par des virgules.
--source=SOURCE, -s=SOURCE
Spécifie la source pour la gem ajoutée.
--require=REQUIRE, -r=REQUIRE
Ajoute le chemin de require à la gem. Fournit false, ou un chemin sous forme de chaîne.
--path=CHEMIN
Spécifie le chemin du système de fichiers pour la gem ajoutée.
--git=GIT
Spécifie la source git pour la gem ajoutée.
--github=GITHUB
Spécifie la source github pour la gem ajoutée.
--branch=BRANCHE
Spécifie la branche git pour la gem ajoutée.
--ref=REF
Spécifie la référence git pour la gem ajoutée.
--glob=GLOB
Spécifie l'emplacement du fichier .gemspec d'une dépendance, développé en Ruby (guillemets simples recommandés).
--quiet
Ne pas afficher les informations de progression sur la sortie standard.
--skip-install
Ajoute la gem au Gemfile mais ne l'installe pas.
--optimistic
Ajoute une déclaration optimiste de la version.
--strict
Ajoute une déclaration stricte de la version.

EXEMPLES

1.
Vous pouvez ajouter la gem rails au Gemfile sans aucune restriction de version. La source de la gem sera la source globale.
bundle add rails
2.
Vous pouvez ajouter la gem rails avec une version supérieure à 1.1 (ne comprenant pas 1.1) et inférieure à 3.0.
bundle add rails --version "> 1.1, < 3.0"
3.
Vous pouvez utiliser la source personnalisée https://gems.example.com et assigner la gem à un groupe.
bundle add rails --version "~> 5.0.0" --source "https://gems.example.com" --group "development"
4.
La commande suivante ajoute l'entrée gem au Gemfile sans installer la gem. Vous pourrez installer les gems plus tard via bundle install.
bundle add rails --skip-install
5.
Vous pouvez assigner la gem à plus d'un groupe.
bundle add rails --group "development, test"
