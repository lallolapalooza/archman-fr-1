BOOTCHART.CONF(5) bootchart.conf BOOTCHART.CONF(5)

NOM

bootchart.conf, bootchart.conf.d - Fichiers de configuration de l'outil d'analyse des performances de démarrage

SYNTAXE

/etc/systemd/bootchart.conf

/etc/systemd/bootchart.conf.d/*.conf

/run/systemd/bootchart.conf.d/*.conf

/usr/lib/systemd/bootchart.conf.d/*.conf

DESCRIPTION

Au démarrage, systemd-bootchart lit le fichier de configuration /etc/systemd/bootchart.conf, suivi des fichiers dans les répertoires bootchart.conf.d. Ces fichiers de configuration déterminent les paramètres de journalisation et la sortie du graphique.

RÉPERTOIRES DE CONFIGURATION ET PRIORITÉ

La configuration par défaut est définie lors de la compilation, donc un fichier de configuration n'est nécessaire que lorsqu'il est nécessaire de déroger à ces valeurs par défaut. Par défaut, le fichier de configuration dans /etc/systemd/ contient des entrées commentées montrant les valeurs par défaut comme guide pour l'administrateur. Ce fichier peut être édité pour créer des remplacements locaux.

Lorsque les paquets ont besoin de personnaliser la configuration, ils peuvent installer des extraits de configuration dans /usr/lib/systemd/*.conf.d/. Les fichiers dans /etc/ sont réservés à l'administrateur local, qui peut utiliser cette logique pour remplacer les fichiers de configuration installés par les paquets du vendeur. Le fichier de configuration principal est lu avant l'un des répertoires de configuration et a la plus basse priorité ; les entrées dans un fichier d'un répertoire de configuration remplacent les entrées du fichier de configuration unique. Les fichiers des sous-répertoires de configuration *.conf.d/ sont triés par leur nom de fichier dans l'ordre lexicographique, quelle que soit la sous-répertoire dans lequel ils se trouvent. Si plusieurs fichiers spécifient la même option, l'entrée dans le fichier portant le nom lexicographiquement le plus récent prend le dessus. Il est recommandé de préfixer tous les noms de fichiers dans ces sous-répertoires avec un numéro à deux chiffres et un tiret, pour simplifier l'ordre des fichiers.

Pour désactiver un fichier de configuration fourni par le vendeur, la méthode recommandée est de placer un lien symbolique vers /dev/null dans le répertoire de configuration dans /etc/, avec le même nom de fichier que le fichier de configuration du vendeur.

OPTIONS

Samples=500

Configure le nombre d'échantillons à enregistrer au total avant que bootchart ne se termine. Chaque échantillon sera enregistré à des intervalles définis par Frequency=.

Frequency=25

Configure la fréquence d'enregistrement des échantillons. Il peut s'agir d'un nombre fractionnaire, mais doit être supérieur à 0,0. La plupart des systèmes peuvent gérer des valeurs inférieures à 25-50 sans affecter gravement le temps de démarrage.

Relative=no

Configure si l'axe gauche du graphique de sortie est égal à time=0,0 (démarrage CLOCK_MONOTONIC). Ceci est utile pour utiliser bootchart après le démarrage afin de profiler un système déjà démarré, sinon le graphique deviendrait extrêmement volumineux. Si défini sur yes, l'axe horizontal commence au premier échantillon enregistré au lieu de time=0,0.

Filter=no

Configure si le graphique résultant doit omettre les tâches qui n'ont pas contribué de manière significative au démarrage. Les processus dont la durée de vie est trop courte (vus dans un seul échantillon) ou qui ne consomment pas de temps CPU significatif (moins de 0,001 seconde) ne seront pas affichés dans le graphique de sortie.

Output=[chemin]

Configure le répertoire de sortie pour l'écriture des graphiques. Par défaut, bootchart écrit les graphiques dans /run/log.

Init=[chemin]

Configure bootchart pour exécuter un binaire non standard au lieu de /usr/lib/systemd/systemd. Cette option n'est pertinente que si bootchart a été invoqué à partir de la ligne de commande du noyau avec init=/usr/lib/systemd/systemd-bootchart.

PlotMemoryUsage=no

Si défini sur yes, active l'enregistrement et la visualisation de la consommation mémoire PSS des processus.

PlotEntropyGraph=no

Si défini sur yes, active l'enregistrement et la visualisation de la taille du pool d'entropie aléatoire du noyau.

ScaleX=100

Facteur de mise à l'échelle horizontal pour tous les composants graphiques variables.

ScaleY=20

Facteur de mise à l'échelle vertical pour tous les composants graphiques variables.

ControlGroup=no

Afficher le groupe de contrôle des processus.

Cmdline=no

Afficher la ligne de commande complète de chaque processus.
