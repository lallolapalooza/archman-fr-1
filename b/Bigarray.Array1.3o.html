Module Array1
: sig end

Tableaux unidimensionnels. La structure Array1 fournit des opérations similaires à celles de Bigarray.Genarray, mais spécialisées pour le cas des tableaux unidimensionnels. (Les structures Bigarray.Array2 et Bigarray.Array3 ci-dessous fournissent des opérations spécialisées pour les tableaux bi- et tridimensionnels.) Connaître statiquement le nombre de dimensions du tableau permet des opérations plus rapides et une vérification statique plus précise des types.

type (!'a, !'b, !'c) t

Le type des Bigarrays unidimensionnels dont les éléments ont le type OCaml 'a, le type de représentation 'b et la disposition mémoire 'c.

val create : ('a, 'b) Bigarray.kind -> 'c Bigarray.layout -> int -> ('a, 'b, 'c) t

Array1.create kind layout dim renvoie un nouveau Bigarray unidimensionnel, dont la taille est dim. kind et layout déterminent le type d'élément du tableau et la disposition du tableau comme décrit pour Bigarray.Genarray.create.

val init : ('a, 'b) Bigarray.kind -> 'c Bigarray.layout -> int -> (int -> 'a) -> ('a, 'b, 'c) t

Array1.init kind layout dim f renvoie un nouveau Bigarray b unidimensionnel, dont la taille est dim. kind et layout déterminent le type d'élément du tableau et la disposition du tableau comme décrit pour Bigarray.Genarray.create.

Chaque élément Array1.get b i du tableau est initialisé au résultat de f i.

En d'autres termes, Array1.init kind layout dimensions f tabule les résultats de f appliqués aux indices d'un nouveau Bigarray dont la disposition est décrite par kind, layout et dim.

Depuis 4.12

val dim : ('a, 'b, 'c) t -> int

Renvoie la taille (dimension) du Bigarray unidimensionnel donné.

val kind : ('a, 'b, 'c) t -> ('a, 'b) Bigarray.kind

Renvoie le type du Bigarray donné.

val layout : ('a, 'b, 'c) t -> 'c Bigarray.layout

Renvoie la disposition du Bigarray donné.

val change_layout : ('a, 'b, 'c) t -> 'd Bigarray.layout -> ('a, 'b, 'd) t

Array1.change_layout a layout renvoie un Bigarray avec la layout spécifiée, partageant les données avec a (et ayant donc la même dimension que a). Aucune copie d'éléments n'est impliquée : le nouveau tableau et le tableau d'origine partagent le même espace de stockage.

Depuis 4.06

val size_in_bytes : ('a, 'b, 'c) t -> int

size_in_bytes a est le nombre d'éléments dans a multiplié par Bigarray.kind_size_in_bytes de a.

Depuis 4.03

val get : ('a, 'b, 'c) t -> int -> 'a

Array1.get a x, ou alternativement a.{x}, renvoie l'élément de a à l'indice x. x doit être supérieur ou égal à 0 et strictement inférieur à Array1.dim a si a a une disposition C. Si a a une disposition Fortran, x doit être supérieur ou égal à 1 et inférieur ou égal à Array1.dim a. Sinon, Invalid_argument est levée.

val set : ('a, 'b, 'c) t -> int -> 'a -> unit

Array1.set a x v, aussi écrit a.{x} <- v, stocke la valeur v à l'indice x dans a. x doit être dans les limites de a comme décrit dans Bigarray.Array1.get ; sinon, Invalid_argument est levée.

val sub : ('a, 'b, 'c) t -> int -> int -> ('a, 'b, 'c) t

Extrait un sous-tableau du Bigarray unidimensionnel donné. Voir Bigarray.Genarray.sub_left pour plus de détails.

val slice : ('a, 'b, 'c) t -> int -> ('a, 'b, 'c) Bigarray.Array0.t

Extrait un scalaire (tranche zéro-dimensionnelle) du Bigarray unidimensionnel donné. Le paramètre entier est l'indice du scalaire à extraire. Voir Bigarray.Genarray.slice_left et Bigarray.Genarray.slice_right pour plus de détails.

Depuis 4.05

val blit : ('a, 'b, 'c) t -> ('a, 'b, 'c) t -> unit

Copie le premier Bigarray vers le second Bigarray. Voir Bigarray.Genarray.blit pour plus de détails.

val fill : ('a, 'b, 'c) t -> 'a -> unit

Remplit le Bigarray donné avec la valeur donnée. Voir Bigarray.Genarray.fill pour plus de détails.

val of_array : ('a, 'b) Bigarray.kind -> 'c Bigarray.layout -> 'a array -> ('a, 'b, 'c) t

Construit un Bigarray unidimensionnel initialisé à partir du tableau donné.

val unsafe_get : ('a, 'b, 'c) t -> int -> 'a

Comme Bigarray.Array1.get, mais la vérification des limites n'est pas toujours effectuée. À utiliser avec prudence et uniquement lorsque la logique du programme garantit que l'accès est dans les limites.

val unsafe_set : ('a, 'b, 'c) t -> int -> 'a -> unit

Comme Bigarray.Array1.set, mais la vérification des limites n'est pas toujours effectuée. À utiliser avec prudence et uniquement lorsque la logique du programme garantit que l'accès est dans les limites.
