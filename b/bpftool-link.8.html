BPFTOOL-LINK(8) Manuel du gestionnaire système BPFTOOL-LINK(8)

NOM

bpftool-link - outil d'inspection et de manipulation simple des liens eBPF

SYNTAXE

bpftool [OPTIONS] link COMMANDE

OPTIONS := { { -j | --json } [{ -p | --pretty }] | { -d | --debug } | { -f | --bpffs } | { -n | --nomount } }

COMMANDES := { show | list | pin | help }

COMMANDES LINK

bpftool link { show | list } [LIEN]
bpftool link pin LIEN FICHIER
bpftool link detach LIEN
bpftool link help
LIEN := { id ID_LIEN | pinned FICHIER }

DESCRIPTION

bpftool link { show | list } [LIEN]
Affiche des informations sur les liens actifs. Si LIEN est spécifié, n'affiche des informations que sur le lien donné, sinon liste tous les liens actuellement actifs sur le système.

La sortie commencera par l'identifiant du lien, suivi du type de lien et de zéro ou plusieurs attributs nommés, dont certains dépendent du type de lien.

Depuis le noyau Linux 5.8, bpftool peut découvrir des informations sur les processus qui détiennent des descripteurs de fichiers ouverts (FD) contre des liens BPF. Sur ces noyaux, bpftool émettra également automatiquement ces informations.

bpftool link pin LIEN FICHIER
Épingler le lien LIEN sous le nom de FICHIER.

Remarque : FICHIER doit être situé dans un montage bpffs. Il ne doit pas contenir de caractère point ('.'), qui est réservé pour les extensions futures de bpffs.

bpftool link detach LIEN
Détacher de force le lien LIEN. Le lien BPF et son programme BPF sous-jacent resteront valides, mais ils seront détachés du crochet BPF respectif et le lien BPF passera dans un état defunct jusqu'à ce que le dernier descripteur de fichier ouvert pour ce lien soit fermé.
bpftool link help
Affiche un court message d'aide.

OPTIONS

-h, --help
Affiche un court message d'aide (similaire à bpftool help).
-V, --version
Affiche le numéro de version de bpftool (similaire à bpftool version), le numéro de la version de libbpf utilisée et les fonctionnalités optionnelles qui ont été incluses lors de la compilation de bpftool. Les fonctionnalités optionnelles incluent la liaison avec LLVM ou libbfd pour fournir le désassembleur des programmes JIT-ted (bpftool prog dump jited) et l'utilisation de skeletons BPF (certaines fonctionnalités comme bpftool prog profile ou l'affichage des pid associés aux objets BPF peuvent en dépendre).
-j, --json
Génère une sortie JSON. Pour les commandes qui ne peuvent pas produire de JSON, cette option n'a aucun effet.
-p, --pretty
Génère une sortie JSON lisible par l'homme. Implique -j.
-d, --debug
Affiche tous les journaux disponibles, y compris les informations de niveau débogage. Cela inclut les journaux de libbpf ainsi que ceux du vérificateur, lorsque l'on tente de charger des programmes.
-f, --bpffs
Lors de l'affichage des liens BPF, affiche les noms de fichiers des liens épinglés.
-n, --nomount
N'essaie pas de monter automatiquement de système de fichiers virtuel (tel que tracefs ou le système de fichiers virtuel BPF) lorsque nécessaire.

EXEMPLES

# bpftool link show

10: cgroup  prog 25
        cgroup_id 614  attach_type egress
        pids test_progs(223)

# bpftool --json --pretty link show

[{
        "type": "cgroup",
        "prog_id": 25,
        "cgroup_id": 614,
        "attach_type": "egress",
        "pids": [{
                "pid": 223,
                "comm": "test_progs"
            }
        ]
    }
]
# bpftool link pin id 10 /sys/fs/bpf/link
# ls -l /sys/fs/bpf/
-rw------- 1 root root 0 Apr 23 21:39 link
