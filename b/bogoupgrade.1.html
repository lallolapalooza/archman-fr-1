BOGOUPGRADE(1) Manuel de référence Bogofilter BOGOUPGRADE(1)

NOM

bogoupgrade - met à jour la base de données de bogofilter à la version actuelle

SYNTAXE

bogoupgrade [-h] -d répertoire [-i fichier\_entrée] [-o fichier\_sortie] [-b chemin\_vers\_bogoutil]

DESCRIPTION

bogoupgrade est une commande pour mettre à jour les bases de données de bogofilter d'un ancien format vers le format actuel. Comme le format de la base de données change de temps en temps, l'utilitaire est conçu pour faciliter la mise à niveau.

OPTIONS

L'option -h affiche le message d'aide et quitte.

L'option -d spécifie le répertoire contenant les listes de mots à convertir. Cette option est utilisée lors de la conversion à partir de plusieurs listes de mots distinctes (spamlist.db et goodlist.db - contenant respectivement les jetons de spam et de ham) vers une liste de mots combinée (wordlist.db) qui contient à la fois les jetons de spam et de ham.

L'option -i spécifie le fichier d'entrée à convertir. Il doit s'agir d'un fichier texte contenant les comptes de messages, et éventuellement des données. S'il n'y a pas de données dans le fichier texte, il doit y avoir un fichier Berkeley DB dans le même répertoire que le fichier texte qui contient les données.

L'option -o spécifie le fichier de sortie Berkeley DB.

L'option -b donne le chemin d'accès à la commande bogoutil. Elle est par défaut 'bogoutil', en espérant que votre shell la trouvera.

MISE À NIVEAU

Suivez ces instructions pour mettre à jour les bases de données de bogofilter vers la dernière version.

1.Arrêtez toutes les instances de bogofilter. Les outils de mise à niveau verrouillent les fichiers de base de données, mais la mise à niveau peut prendre beaucoup de temps si vous avez un site très fréquenté. N'oubliez pas d'arrêter les tâches cron ou les démons qui récupèrent et traitent le courrier et pourraient lancer bogofilter.
2.Sauvegardez vos données. Supposons que vous ayez tapé : 
$ mv ~/.bogofilter ~/.bogofilter.safe
$ mkdir ~/.bogofilter
3.Si votre version de bogofilter est inférieure à 0.7, tapez : 
$ bogoupgrade -i ~/.bogofilter.safe/goodlist -o ~/.bogofilter/goodlist.db
$ bogoupgrade -i ~/.bogofilter.safe/badlist -o ~/.bogofilter/spamlist.db

Si votre version de bogofilter est 0.7 ou supérieure, tapez :

$ bogoupgrade -i ~/.bogofilter.safe/hamlist.count -o ~/.bogofilter/goodlist.db
$ bogoupgrade -i ~/.bogofilter.safe/spamlist.count -o ~/.bogofilter/spamlist.db
4.Les versions actuelles de bogofilter utilisent une liste de mots combinée qui contient à la fois les jetons de spam et de non-spam. Elle s'appelle wordlist.db. Si vous mettez à jour une version antérieure à 0.14.0 qui a des listes de mots séparées (nommées goodlist.db et spamlist.db), utilisez : 
$ bogoupgrade -d ~/.bogofilter.safe
5.Terminé. Redémarrez tous les démons, tâches cron, etc. arrêtés.
