NOM

borg-key-import - Importer la clé du dépôt à partir d'une sauvegarde

SYNTAXE

borg [options communes] key import [options] [DÉPÔT] [CHEMIN]

DESCRIPTION

Cette commande restaure une clé précédemment sauvegardée avec la commande export.

Si l'option --paper est fournie, l'importation sera un processus interactif au cours duquel chaque ligne sera vérifiée pour sa plausibilité avant de passer à la ligne suivante. Pour ce format, PATH ne doit pas être fourni.

Pour les dépôts utilisant le chiffrement par fichier de clé, le fichier de clé sur lequel borg key import écrit dépend de plusieurs facteurs. Si la variable d'environnement BORG_KEY_FILE est définie et non vide, borg key import crée ou écrase le fichier nommé par $BORG_KEY_FILE. Sinon, borg key import recherche dans le répertoire $BORG_KEYS_DIR un fichier de clé associé au dépôt. Si un fichier de clé est trouvé dans $BORG_KEYS_DIR, borg key import l'écrase ; sinon, borg key import crée un nouveau fichier de clé dans $BORG_KEYS_DIR.

OPTIONS

Voir borg-common(1) pour les options communes des commandes Borg.

arguments

DÉPÔT

CHEMIN
chemin vers la sauvegarde ('-' pour lire depuis l'entrée standard)

options

--paper
importer interactivement depuis une sauvegarde réalisée avec --paper

VOIR AUSSI

borg-common(1), borg-key-export(1)
