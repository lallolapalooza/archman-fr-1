bluetoothd(8) Commandes de gestion système bluetoothd(8)

Nom

bluetoothd - démon Bluetooth

SYNOPSIS

bluetoothd [--version] | [--help]

bluetoothd [--nodetach] [--compat] [--experimental] [--debug=<fichiers>] [--plugin=<plugins>] [--noplugin=<plugins>]

DESCRIPTION

Cette page de manuel documente brièvement le démon bluetoothd, qui gère tous les appareils Bluetooth. bluetoothd peut également fournir un certain nombre de services via le système de bus de messages D-Bus.

OPTIONS

-v, --version
Affiche la version de bluetoothd et quitte.
-h, --help
Affiche les options de bluetoothd et quitte.
-n, --nodetach
Active la journalisation en premier plan. Dirige la sortie du journal vers le terminal de contrôle en plus du syslog.
-f, --configfile
Spécifie un chemin explicite pour le fichier de configuration au lieu de s'appuyer sur le chemin par défaut (/etc/bluetooth/main.conf).
-d, --debug=<fichier1>:<fichier2>:...
Définit la quantité d'informations que bluetoothd envoie à la destination du journal (généralement le facility « daemon » de syslog). Si les options de fichier sont omises, les informations de débogage de tous les fichiers sources sont imprimées. Si des options de fichier sont présentes, seuls les messages de débogage de ce fichier source sont imprimés. L'option peut être un modèle contenant les caractères « * » et « ? ».

Exemple : --debug=src/adapter.c:src/agent.c

-p, --plugin=<plugin1>,<plugin2>,..
Charge uniquement ces plugins. L'option peut être un modèle contenant les caractères « * » et « ? ».
-P, --noplugin=<plugin1>,<plugin2>,..
Ne charge jamais ces plugins. L'option peut être un modèle contenant les caractères « * » et « ? ».
-C, --compat
Fournit des interfaces de ligne de commande obsolètes.
-E, --experimental
Active les interfaces expérimentales D-Bus. Ces interfaces ne sont pas garanties d'être compatibles ou présentes dans les futures versions.
-T, --testing
Active les interfaces de test D-Bus. Ces interfaces sont uniquement destinées à la validation des tests internes de bluetoothd et ne devraient jamais être utilisées par autre chose que cela.
-K, --kernel=<uuid1>,<uuid2>,...
Active les fonctionnalités expérimentales du noyau. Les fonctionnalités expérimentales du noyau sont considérées comme instables et peuvent être supprimées des futures versions du noyau.

FICHIERS

/etc/bluetooth/main.conf
Emplacement du fichier de configuration global.
