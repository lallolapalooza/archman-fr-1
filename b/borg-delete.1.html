NOM

borg-delete - Supprime un dépôt existant ou des archives

SYNTAXE

borg [options communes] delete [options] [DEPOT_OU_ARCHIVE] [ARCHIVE...]

DESCRIPTION

Cette commande supprime une archive du dépôt ou le dépôt complet.

Important : Lors de la suppression d'archives, l'espace disque du dépôt n'est pas libéré tant que vous n'avez pas exécuté borg compact.

Lorsque vous supprimez un dépôt complet, les informations de sécurité et le cache local associés (le cas échéant) sont également supprimés. Alternativement, vous pouvez supprimer uniquement le cache local avec l'option --cache-only, ou conserver les informations de sécurité avec l'option --keep-security-info.

En cas de doute, utilisez --dry-run --list pour voir ce qui serait supprimé.

Lorsque vous utilisez --stats, vous obtiendrez des statistiques sur la quantité de données supprimées - la taille dédupliquée des "Données supprimées" est la plus intéressante car c'est ce qui permettra de réduire la taille de votre dépôt. Veuillez noter que les statistiques "Toutes les archives" se réfèrent à l'état après la suppression.

Vous pouvez supprimer plusieurs archives en spécifiant un motif shell pour faire correspondre plusieurs archives à l'aide de l'option --glob-archives GLOB (pour plus d'informations sur ces motifs, voir borg_patterns).

Pour éviter de supprimer accidentellement des archives, en particulier lors de l'utilisation de motifs glob, il peut être utile d'utiliser --dry-run pour tester la commande sans réellement apporter de modifications au dépôt.

OPTIONS

Voir borg-common(1) pour les options communes des commandes Borg.

arguments

DEPOT_OU_ARCHIVE
dépôt ou archive à supprimer
ARCHIVE
archives à supprimer

options

-n, --dry-run
ne pas modifier le dépôt
--list
afficher une liste détaillée des archives
-s, --stats
afficher les statistiques de l'archive supprimée
--cache-only
supprimer uniquement le cache local pour le dépôt donné
--force
forcer la suppression d'archives corrompues, utilisez --force --force dans le cas où --force ne fonctionne pas.
--keep-security-info
conserver les informations de sécurité locales lors de la suppression d'un dépôt
--save-space
travailler plus lentement, mais en utilisant moins d'espace
-c SECONDES, --checkpoint-interval SECONDES
écrire un point de contrôle toutes les SECONDES secondes (Défaut: 1800)

Filtres d'archives

-P PREFIXE, --prefix PREFIXE
ne considérer que les noms d'archives commençant par ce préfixe. (obsolète)
-a GLOB, --glob-archives GLOB
ne considérer que les noms d'archives correspondant au glob. Les règles de sh s'appliquent (sans utiliser réellement le préfixe sh:), voir "borg help patterns".
--sort-by CLES
Liste de clés de tri séparées par des virgules ; clés valides : timestamp, archive, name, id ; par défaut : timestamp
--first N
considérer les N premières archives après l'application d'autres filtres
--last N
considérer les N dernières archives après l'application d'autres filtres

EXEMPLES

# supprimer une archive de sauvegarde unique :
$ borg delete /chemin/vers/repo::Lundi
# libérer réellement de l'espace disque :
$ borg compact /chemin/vers/repo
# supprimer toutes les archives dont les noms commencent par le nom d'hôte de la machine suivi d'un tiret "-"
$ borg delete --glob-archives '{hostname}-*' /chemin/vers/repo
# supprimer toutes les archives dont les noms contiennent "-2012-"
$ borg delete --glob-archives '*-2012-*' /chemin/vers/repo
# voir ce qui serait supprimé si delete était exécuté sans --dry-run
$ borg delete --list --dry-run -a '*-Mai-*' /chemin/vers/repo
# supprimer l'intégralité du dépôt et le cache local associé :
$ borg delete /chemin/vers/repo
Vous avez demandé à SUPPRIMER COMPLÈTEMENT le dépôt *y compris* toutes les archives qu'il contient :
repo                                 Lun, 2016-02-15 19:26:54
root-2016-02-15                      Lun, 2016-02-15 19:36:29
nouveau_nom                          Lun, 2016-02-15 19:50:19
Tapez 'OUI' si vous comprenez et souhaitez continuer : OUI
