B::Terse(3perl) Guide du programmeur Perl B::Terse(3perl)

NOM

B::Terse - Parcourir l'arbre de syntaxe Perl, en imprimant des informations succinctes sur les ops

SYNTAXE

perl -MO=Terse[,OPTIONS] foo.pl

DESCRIPTION

Ce module imprime le contenu de l'arbre d'analyse, mais sans autant d'informations que le module CPAN B::Debug. À titre de comparaison, "print "Hello, world."" a produit 96 lignes de sortie de B::Debug, mais seulement 6 de B::Terse.

Ce module est utile pour ceux qui écrivent leur propre backend, ou qui apprennent les internes de Perl. Il n'est pas utile au programmeur moyen.

Cette version de B::Terse n'est en réalité qu'un wrapper qui appelle B::Concise avec l'option -terse. Elle est fournie pour la compatibilité avec de vieux scripts (et habitudes), mais il est maintenant recommandé d'utiliser directement B::Concise.

Pour assurer la compatibilité avec l'ancien B::Terse, ce module ajoute également une méthode nommée "terse" aux objets B::OP et B::SV. La méthode B::SV est largement compatible avec l'ancienne, bien que les auteurs de nouveaux logiciels puissent être avisés de choisir un format de sortie plus convivial. La méthode "terse" de B::OP, cependant, ne fonctionne pas bien. Depuis que B::Terse a été écrit pour la première fois, beaucoup plus d'informations dans les OPs ont été déplacées vers la structure de données scratchpad, mais l'interface "terse" n'a aucun moyen d'accéder au pad correct. Comme solution de contournement, la nouvelle version utilisera toujours le pad du programme principal, mais pour les OPs dans les sous-routines, cela donnera la mauvaise réponse ou provoquera un crash.
