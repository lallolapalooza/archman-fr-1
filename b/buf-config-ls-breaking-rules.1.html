NOM

buf-config-ls-breaking-rules - Lister les règles de rupture

SYNTAXE

buf config ls-breaking-rules [indicateurs]

DESCRIPTION

Lister les règles de rupture

OPTIONS

--config="" Le fichier buf.yaml ou les données à utiliser pour la configuration. --configured-only doit être défini

--configured-only[=false] Lister les règles qui sont configurées au lieu de lister toutes les règles disponibles

--format="text" Le format d'affichage des règles. Doit être l'un des éléments suivants [text,json]

-h, --help[=false] Aide pour ls-breaking-rules

--include-deprecated[=false] Afficher également les règles obsolètes. N'a aucun effet si --configured-only est défini.

--module-path="" Le chemin vers le module spécifique pour lequel lister les règles configurées tel que spécifié dans le buf.yaml. Si le buf.yaml définit plus d'un module, ceci doit être défini. --configured-only doit être défini

--version="" Lister toutes les règles pour la version de configuration donnée. Par défaut, la version dans le buf.yaml du répertoire courant est utilisée, ou la dernière version sinon (actuellement v2). Ne peut pas être défini si --configured-only est défini. Doit être l'un des éléments suivants [v1beta1 v1 v2]

OPTIONS RECUEILLIES DES COMMANDES PARENTES

--debug[=false] Activer la journalisation de débogage

--log-format="color" Le format de journalisation [text,color,json]

--timeout=0s La durée avant expiration, la régler à 0 signifie pas d'expiration

VOIR AUSSI
