DESCRIPTIO

N

bat affiche le contenu coloré syntaxiquement d'une collection de FICHIERs sur le terminal. Si aucun FICHIER n'est spécifié, ou si le FICHIER est '-', il lit depuis l'entrée

standard.

bat prend en charge un grand nombre de langages de programmation et de balisage. Il communique également avec git(1) pour afficher les modifications par rapport à l'index git. bat redirige automatiquement sa sortie vers un paginateur (par défaut : less)

.

Lorsque la sortie de bat va vers un terminal non interactif, c'est-à-dire lorsque la sortie est re

dirigée vers un autre processus ou vers un fichier, bat agira comme un remplacement direct de cat(
1) et reviendra à l'impression du contenu brut du fichier, sauf si un style explicite est demandé.

--pager <com

mande>
Détermine quel paginateur est utilisé. Cette option remplacera les variables d'environnement PAGER et BAT_PAGER. Le paginateur par défaut est 'less'. Si vous fournissez '--pager=builtin', utilisez le paginateur intégré 'minus'. Pour contrôler quand le paginateur est utilisé, voir l'option '--paging'. Exemple : '--pager "less -RF"'.

Note : Par défaut, si le paginateur est défini sur 'less' (et qu'aucune option de ligne de commande n'est spécifiée), 'bat' transmettra les options de ligne de commande suivantes au paginateur : '-R'/'--RAW-CONTROL-CHARS', '-F'/'--quit-if-one-screen' et '-X'/'--no-init'. La dernière option ('-X') n'e

st utilisée que pour les versions de 'less' antérieures à 530. L'option '-R' est nécessaire pour interpréter correctement les couleurs ANSI. La deuxième option ('-F') indique à less de quitter immédiatement si la taille de la sortie est inférieure à la taille verticale du terminal. C'est pratique pour les pe
tits fichiers car vous n'avez pas à appuyer sur 'q' pour quitter le paginateur. La troisième option ('-X') est nécessaire pour corriger un bogue de la fonctionnalité '--quit-if-one-screen' dans les anciennes versions de 'less'. Malheureusement, cela casse également la prise en charge de la molette d
e la souris dans 'less'. Si vous voulez activer le défilement à la molette sur des versions plus anciennes de 'less', vous pouvez passer simplement '-R' (comme dans l'exemple ci-dessus, cela désactivera la fonctionnalité quit-if-one-screen). Pour less 530 ou plus récent, cela devrait fonctionner directement.

AJOUTER DES LANGAGES

PERSONNALISÉS

bat prend en charge les fichiers de langage Sublime Text .sublime-syntax, et peut être personnalisé pour ajouter des langages supplémentaires à votre installation locale. Pour ce faire, ajoutez les fichiers de langage .sublime-syntax à `$(bat --config-dir)/syntaxes` et exécutez `bat cache --

build`.

Exemple

:
mkdir -p "$(bat --config-dir)/syntaxes"
cd "$(bat --config-dir)/syntaxes"

# Placez les nouveaux fichiers de définition de langage '.sublime-syntax'
# dans ce dossier (ou ses sous-dossiers), par exemple :
git clone https://github.com/tellnobody1/sublime-purescript-synta

x

# Et puis construisez le cache.
bat ca

che -
-build

Une fois le cache construit, le nouveau langage sera visible dans `bat --list-languages`.
Si vous souhaitez supprimer les langages personnalisés, vous pouvez vider le cache avec `bat cache

--cl
ear`.

AJOUTER DES THÈMES

PERSONNALISÉS

De même que pour les langages personnalisés, bat prend en charge les thèmes Sublime Text .tmTheme. Ceux-ci peuvent être installés dans `$(bat --config-dir)/themes`, et sont ajoutés au cache avec `bat cach

e -
-build`.

PRÉPROCESSEUR

D'ENTRÉE

Tout comme less(1), bat prend en charge les préprocesseurs d'entrée via les variables d'environnement LESSOPEN et LESSCLOSE. De plus, bat tente d'être aussi compatible que possible avec l'implémentation du préprocesseur de

less.

:

configuration.
