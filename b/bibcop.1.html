NOM

bibcop - Vérificateur et correcteur de style de fichiers BibTeX (.bib)

SYNTAXE

bibcop [<options>] <chemin du fichier .bib>

DESCRIPTION

L'outil bibcop est un script Perl permettant de vérifier la qualité des fichiers de bibliographie BibTeX (.bib) et de corriger automatiquement les incohérences trouvées. Ce n'est pas seulement un outil en ligne de commande, mais aussi un paquet LaTeX, qui peut vérifier la qualité d'un fichier .bib pendant le rendu d'un document LaTeX. Tous les problèmes trouvés sont signalés comme des avertissements LaTeX.

OPTIONS

Diverses options s'appliquent :

--version
Affiche la version de l'outil
--help
Affiche l'écran d'introduction
--fix
Corrige automatiquement tous les problèmes et affiche le nouveau contenu dans la console
--latex
Affiche tout en format LaTeX
--verbose
Affiche également les informations de débogage
