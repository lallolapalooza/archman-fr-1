NOM

boinctui - Gestionnaire en mode texte plein écran pour le client BOINC

SYNTAXE

boinctui

DESCRIPTION

BOINC peut être configuré de nombreuses façons. Et le suivi des progrès scientifiques contribués par vos propres machines est gratifiant. Pour les machines à distance ou pour éviter de bouger les mains de votre clavier, ce paquet fournit, tout pour votre ligne de commande UNIX :
* Interface utilisateur textuelle plein écran basée sur curses
* Commutation entre plusieurs hôtes clients BOINC via une touche de raccourci
* Affichage de la liste des tâches (état d'exécution, file d'attente, suspension, etc.)
* Affichage de la liste des messages
* Suspension/Reprise/Abandon des tâches
* Mise à jour/Suspension/Reprise/Réinitialisation/Pas de nouvelles tâches/Autoriser nouvelles tâches pour les projets
* Basculement de l'état d'activité des tâches GPU et CPU
* Exécution de benchmarks
* Gestion du client BOINC sur des hôtes distants via le protocole boinc_gui
