Nom

btmgmt - outil interactif de gestion Bluetooth

SYNOPSIS

btmgmt [--options] [commandes]

DESCRIPTION

btmgmt(1) est un outil interactif de gestion Bluetooth. L'outil émet des commandes au noyau via le socket de gestion Bluetooth. Certaines commandes peuvent nécessiter la capacité net-admin pour fonctionner, car l'interface de gestion Bluetooth est considérée comme une interface de bas niveau destinée à des outils comme bluetoothd(8). Il n'est pas recommandé aux applications de l'utiliser directement, car cela pourrait entraîner un comportement inattendu.

OPTIONS

-i/--index
Spécifier l'index de l'adaptateur
-m/-monitor
Activer la sortie du moniteur
-t/--timeout
Délai en secondes pour le mode non interactif
-v/--version
Afficher la version
-i/--init-script
Fichier de script d'initialisation
-h/--help
Afficher l'aide

COMMANDES

main
Voir bluetoothctl-mgmt(1)
monitor
Voir bluetoothctl-monitor(1)

AUTOMATION

Deux méthodes courantes pour automatiser l'outil consistent à passer les commandes directement, comme dans l'exemple suivant :

btmgmt <<EOF
list
show
EOF

Ou à créer un script et à le passer comme init-script :

$ vi test-script.bt
list
show
quit
:wq
$ btmgmt --init-script=test-script
