NOM

bashbug - signaler un bogue dans bash

SYNTAXE

bashbug [--version] [--help] [adresse-email]

DESCRIPTION

bashbug est un script shell destiné à aider l'utilisateur à rédiger et envoyer des rapports de bogues concernant bash dans un format standard. bashbug invoque l'éditeur spécifié par la variable d'environnement EDITOR sur une copie temporaire du plan du rapport de bogue. L'utilisateur doit remplir les champs appropriés et quitter l'éditeur. bashbug envoie ensuite le rapport complété à bug-bash@gnu.org, ou à adresse-email. Si le rapport ne peut pas être envoyé, il est sauvegardé dans le fichier dead.bashbug dans le répertoire personnel de l'utilisateur appelant.

Le plan du rapport de bogue se compose de plusieurs sections. La première section fournit des informations sur la machine, le système d'exploitation, la version de bash et l'environnement de compilation. La deuxième section doit être remplie avec une description du bogue. La troisième section doit être une description de la manière de reproduire le bogue. La quatrième section, optionnelle, est destinée à une correction proposée. Les corrections sont encouragées.

ENVIRONNEMENT

bashbug utilisera les variables d'environnement suivantes si elles existent :

EDITOR
Spécifie l'éditeur préféré. Si EDITOR n'est pas défini, bashbug tente de localiser un certain nombre d'éditeurs alternatifs, y compris emacs. Si bashbug ne parvient à localiser aucun des éditeurs alternatifs, il tente d'exécuter vi.
HOME
Répertoire dans lequel le rapport de bogue échoué est sauvegardé si l'envoi par courrier échoue.
TMPDIR
Répertoire dans lequel créer les fichiers et répertoires temporaires.
