Biber::Input::file::biblatexml(3pm) Documentation Perl Contribuée par l'Utilisateur Biber::Input::file::biblatexml(3pm)

extract_entries

Routine principale d'extraction des données.
Accepte un identifiant de source de données (nom de fichier dans ce cas),
prétraite le fichier puis recherche les clés passées,
créant des entrées lorsqu'elle les trouve et renvoie un
tableau des clés qu'elle n'a pas trouvées.

create_entry

Crée un objet Biber::Entry à partir d'une entrée trouvée dans une source de données biblatexml

parsename

Étant donné un nœud de nom, cette fonction renvoie un objet Biber::Entry::Name
Renvoie un objet qui, en interne, ressemble à ceci :
{ given             => {string => 'John', initial => ['J']},
  family            => {string => 'Doe', initial => ['D']},
  middle            => {string => 'Fred', initial => ['F']},
  prefix            => {string => undef, initial => undef},
  suffix            => {string => undef, initial => undef},
  basenamestring    => 'Doe',
  namestring        => 'Doe, John Fred',
  nameinitstring    => 'Doe_JF',
  gender            => sm,
  useprefix         => 1,
  hashid            => 'someid',
  sortingnamekeytemplatename => 'templatename'
}

NOM

Biber::Input::file::biblatexml - recherche dans un fichier BibLaTeXML une entrée et la crée si elle est trouvée

DESCRIPTION

Fournit la méthode extract_entries() pour obtenir les entrées d'une source de données biblatexml et instancier des objets Biber::Entry pour ce qu'elle trouve
