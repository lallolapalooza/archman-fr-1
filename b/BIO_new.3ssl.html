BIO_new(3ssl)

Paquet: openssl

Licences: Apache-2.0

BIO_NEW(3ssl) OpenSSL BIO_NEW(3ssl)

NOM

BIO_new_ex, BIO_new, BIO_up_ref, BIO_free, BIO_vfree, BIO_free_all - Fonctions d'allocation et de libération de BIO

SYNTAXE

#include <openssl/bio.h>
BIO *BIO_new_ex(OSSL_LIB_CTX *libctx, const BIO_METHOD *type);
BIO *BIO_new(const BIO_METHOD *type);
int BIO_up_ref(BIO *a);
int BIO_free(BIO *a);
void BIO_vfree(BIO *a);
void BIO_free_all(BIO *a);

DESCRIPTION

La fonction BIO_new_ex() retourne un nouveau BIO utilisant la méthode type associée au contexte de librairie libctx (voir OSSL_LIB_CTX(3)). Le contexte de librairie peut être NULL pour indiquer le contexte de librairie par défaut. type NE DOIT PAS être NULL.

BIO_new() est identique à BIO_new_ex() sauf que le contexte de librairie par défaut est toujours utilisé.

BIO_up_ref() incrémente le compteur de références associé à l'objet BIO.

BIO_free() libère un seul BIO, BIO_vfree() libère également un seul BIO mais ne retourne pas de valeur. Si a est NULL, rien n'est fait. L'appel à BIO_free() peut également avoir un effet sur la structure d'E/S sous-jacente, par exemple, cela peut fermer le fichier référencé dans certaines circonstances. Pour plus de détails, voir les descriptions individuelles des BIO_METHOD.

BIO_free_all() libère une chaîne entière de BIO, elle ne s'arrête pas si une erreur survient lors de la libération d'un BIO individuel dans la chaîne. Si a est NULL, rien n'est fait.

VALEURS DE RETOUR

BIO_new_ex() et BIO_new() retournent un BIO nouvellement créé ou NULL si l'appel échoue.

BIO_up_ref() et BIO_free() retournent 1 en cas de succès et 0 en cas d'échec.

BIO_free_all() et BIO_vfree() ne retournent pas de valeurs.

NOTES

Si BIO_free() est appelé sur une chaîne de BIO, il ne libérera qu'un seul BIO, entraînant une fuite de mémoire.

Appeler BIO_free_all() sur un seul BIO a le même effet que d'appeler BIO_free() sur celui-ci, à l'exception de la valeur de retour ignorée.

HISTORIQUE

BIO_set() a été supprimé dans OpenSSL 1.1.0 car le type BIO est maintenant opaque.

BIO_new_ex() a été ajouté dans OpenSSL 3.0.

EXEMPLES

Créer un BIO mémoire :

BIO *mem = BIO_new(BIO_s_mem());
