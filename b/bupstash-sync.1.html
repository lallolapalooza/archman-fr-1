bupstash-sync(1)

Paquet: bupstash

Licences: MIT

() ()

SYNOPIS

Synchronise les éléments et les données d'un dépôt bupstash vers un autre.

bupstash sync [OPTIONS] --to $REMOTE [REQUÊTE...]

DESCRIPTION

bupstash sync copie les éléments et les données d'un dépôt vers un autre tout en essayant de minimiser l'utilisation inutile de la bande passante.

Une utilisation typique de cette commande est de sauvegarder des fichiers dans un dépôt local (par exemple, un disque externe) tout en les téléchargeant efficacement vers un emplacement hors site pour un stockage en toute sécurité.

Notez que lorsqu'aucune requête n'est spécifiée, tous les éléments sont synchronisés, même ceux qui ne correspondent pas à la clé bupstash actuelle.

LANGAGE DE REQUÊTES

Pour une documentation complète sur le langage de requêtes, consultez bupstash-query-language(7).

MISE EN CACHE DES REQUÊTES

La commande sync utilise les mêmes mécanismes de mise en cache des requêtes que bupstash-list(1), consultez cette page pour plus d'informations sur le cache des requêtes.

OPTIONS

-r, --repository REPO
Le dépôt à partir duquel synchroniser. Peut être de la forme ssh://$SERVEUR/$CHEMIN pour les dépôts distants si l'accès ssh est configuré. S'il n'est pas spécifié, il est défini sur BUPSTASH_REPOSITORY.
--to REPO
Le dépôt de destination vers lequel synchroniser les éléments. Peut être de la forme ssh://$SERVEUR/$CHEMIN pour les dépôts distants si l'accès ssh est configuré. S'il n'est pas spécifié, il est défini sur BUPSTASH_TO_REPOSITORY.
-k, --key CLE
Clé utilisée pour déchiffrer les métadonnées lors de l'exécution d'une requête. Si elle n'est pas définie, elle prend par défaut BUPSTASH_KEY.
--query-cache CHEMIN
Chemin vers le fichier de cache de requêtes, par défaut l'un des suivants, dans l'ordre, à condition que les variables d'environnement appropriées soient définies : $BUPSTASH_QUERY_CACHE, $XDG_CACHE_HOME/.cache/bupstash/bupstash.qcache ou $HOME/.cache/bupstash/bupstash.qcache.
--query-encrypted
La requête ne déchiffrera aucune métadonnée, vous permettant de lister des éléments pour lesquels vous n'avez pas de clé de déchiffrement. Cette option insère la pseudo balise de requête ´decryption-key-id´.
--ids-from-stdin
Synchronise les éléments dont les identifiants sont lus depuis stdin, un par ligne, au lieu d'exécuter une requête.
--utc-timestamps
Affiche et recherche les horodatages en heure UTC au lieu de l'heure locale.
--no-progress
Supprime les indicateurs de progression (Les indicateurs de progression sont également supprimés lorsque stderr n'est pas un terminal interactif).
-q, --quiet
Soyez silencieux, implique --no-progress.

ENVIRONNEMENT

BUPSTASH_REPOSITORY
Le dépôt à partir duquel extraire les éléments. Peut être de la forme ssh://$SERVEUR/$CHEMIN pour les dépôts distants si l'accès ssh est configuré.
BUPSTASH_REPOSITORY_COMMAND
Une commande à exécuter pour se connecter à une instance de bupstash-serve(1). Cela permet des connexions plus complexes au dépôt pour des cas d'utilisation moins courants.
BUPSTASH_TO_REPOSITORY
Le dépôt vers lequel synchroniser les éléments. Peut être de la forme ssh://$SERVEUR/$CHEMIN pour les dépôts distants si l'accès ssh est configuré.
BUPSTASH_TO_REPOSITORY_COMMAND
Une commande à exécuter pour se connecter à une instance de bupstash-serve(1). Cela permet des connexions plus complexes au dépôt pour des cas d'utilisation moins courants.
BUPSTASH_KEY
Chemin vers une clé primaire qui sera utilisée pour déchiffrer les données et les métadonnées.
BUPSTASH_KEY_COMMAND
Une commande à exécuter qui doit imprimer les données de la clé, peut être utilisée à la place de BUPSTASH_KEY pour récupérer la clé à partir d'emplacements arbitraires tels que le réseau ou d'autres stockages secrets.
BUPSTASH_QUERY_CACHE
Chemin vers le fichier de cache de requêtes à utiliser.

EXEMPLES

Pousser tous les éléments d'un dépôt local vers un dépôt distant

$ bupstash sync --repository ./depot-local --to ssh://$DISTANT

Effectuer une sauvegarde localement puis synchroniser une copie vers un dépôt distant

$ export BUPSTASH_REPOSITORY=./depot-local $ id="$(bupstash put ./quelques-fichiers)" $ bupstash sync --to ssh://$DISTANT id="$id"
