NOM

backend-spec - interface entre jw et ses backends

DESCRIPTION

jw(1) appelle des backends comme backends/html pour effectuer le travail de conversion "réel". Le backend reçoit toutes les données nécessaires via des variables d'environnement, prêtes à être utilisées.

Cette documentation décrit ces variables d'environnement.

Le backend est exécuté dans le répertoire où les fichiers de sortie doivent être créés. Il doit retourner 0 en cas de succès, et une valeur positive en cas d'échec.

VARIABLES

SGML_FILE_NAME
Le nom seul du fichier source
SGML_FILE
Le nom complet et le chemin du fichier source
SGML_JADE
Le nom de l'analyseur (généralement Jade ou OpenJade)
SGML_ARGUMENTS
La chaîne d'arguments complète pour Jade ou OpenJade
SGML_CATALOG_FILES
La liste des fichiers de catalogue nécessaires à Jade ou OpenJade
SGML_STYLESHEET
La feuille de style à utiliser
SGML_BASE_DIR
Le répertoire de base du système SGML (par défaut /usr/share/sgml)
