NOM

birdfont-import - Créer une police à partir de fichiers SVG

SYNTAXE

birdfont-import birdfont-file fichiers-svg ...

DESCRIPTION

birdfont-import générera un fichier birdfont à partir d'un ensemble d'images SVG. La commande suppose que le nom du fichier désigne soit un seul caractère, soit une valeur Unicode sous la forme U+XX où XX est le numéro Unicode au format hexadécimal.

Un dessin enregistré sous le nom "a.svg" sera ajouté à la gliffe "a" lorsque vous exécuterez : birdfont-import typeface.bf a.svg

Un dessin enregistré sous le nom "U+62.svg" sera ajouté à "b" lorsque vous exécuterez : birdfont-import typeface.bf U+62.svg

Voir aussi birdfont-export pour créer des polices SVG, EOT et TTF à partir du fichier birdfont.
