NOM

bup-daemon - écoute les connexions et exécute bup server

SYNTAXE

bup daemon [-l adresse] [-p port]

DESCRIPTION

bup daemon est un serveur bup simple qui écoute sur un socket et crée des processus fils pour les connexions via bup mux server.

OPTIONS

-l, --listen=adresse
l'adresse ou le nom d'hôte sur lequel écouter
-p, --port=port
le port sur lequel écouter

BUP

Fait partie de la suite bup(1).
