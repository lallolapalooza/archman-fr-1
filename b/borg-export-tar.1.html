NOM

borg-export-tar - Exporter le contenu d'une archive sous forme de tarball

SYNTAXE

borg [options communes] export-tar [options] ARCHIVE FICHIER [CHEMIN...]

DESCRIPTION

Cette commande crée un tarball à partir d'une archive.

Lorsque '-' est donné comme FICHIER de sortie, Borg écrira un flux tar en sortie standard.

Par défaut (--tar-filter=auto), Borg détectera si le FICHIER doit être compressé en fonction de son extension de fichier et dirigera le tarball à travers un filtre approprié avant de l'écrire dans le FICHIER :

  • .tar.gz ou .tgz : gzip
  • .tar.bz2 ou .tbz : bzip2
  • .tar.xz ou .txz : xz
  • .tar.zstd ou .tar.zst : zstd
  • .tar.lz4 : lz4

Alternativement, un programme --tar-filter peut être explicitement spécifié. Il doit lire le flux tar non compressé depuis stdin et écrire un flux tar compressé/filtré en stdout.

Le tarball généré utilise le format GNU tar.

export-tar est une conversion avec perte : les indicateurs BSD, les ACL, les attributs étendus (xattrs), atime et ctime ne sont pas exportés. La résolution des horodatages est limitée aux secondes entières, et non à la résolution nanoseconde autrement supportée par Borg.

Une option --sparse (comme trouvée dans borg extract) n'est pas supportée.

Par défaut, toute l'archive est extraite, mais un sous-ensemble de fichiers et de répertoires peut être sélectionné en passant une liste de CHEMINs comme arguments. La sélection de fichiers peut être encore restreinte en utilisant l'option --exclude.

Pour plus d'aide sur les modèles d'inclusion/exclusion, consultez la sortie de la commande borg_patterns.

--progress peut être plus lent que l'absence d'affichage de progression, car il effectue un passage supplémentaire sur les métadonnées de l'archive.

OPTIONS

Voir borg-common(1) pour les options communes des commandes Borg.

arguments

ARCHIVE
archive à exporter
FICHIER
fichier tar de sortie. « - » pour écrire en stdout à la place.
CHEMIN
chemins à extraire ; les motifs sont supportés

options

--tar-filter
programme de filtrage pour diriger les données
--list
affiche une liste détaillée des éléments (fichiers, répertoires, ...)

options d'inclusion/exclusion

-e MOTIF, --exclude MOTIF
exclut les chemins correspondant au MOTIF
--exclude-from FICHIER_EXCLUSIONS
lit les motifs d'exclusion depuis FICHIER_EXCLUSIONS, un par ligne
--pattern MOTIF
inclut/exclut les chemins correspondant au MOTIF
--patterns-from FICHIER_MOTIFS
lit les motifs d'inclusion/exclusion depuis FICHIER_MOTIFS, un par ligne
--strip-components NOMBRE
Supprime le nombre spécifié d'éléments de chemin de tête. Les chemins ayant moins d'éléments seront silencieusement ignorés.

EXEMPLES

# Exporter en tar non compressé.
$ borg export-tar /chemin/vers/repo::Lundi Lundi.tar
# Exclure certains types ; compresser avec gzip.
$ borg export-tar /chemin/vers/repo::Lundi Lundi.tar.gz --exclude '*.so'
# Utiliser un niveau de compression plus élevé avec gzip.
$ borg export-tar --tar-filter="gzip -9" testrepo::linux Lundi.tar.gz
# Exporter un tar, mais au lieu de le stocker sur disque,
# l'uploader vers un site distant en utilisant curl.
$ borg export-tar /chemin/vers/repo::Lundi - | curl --data-binary @- https://quelque-part/pour/POST
# Extraction à distance via "tarpipe".
$ borg export-tar /chemin/vers/repo::Lundi - | ssh quelque-part "cd extrait; tar x"
