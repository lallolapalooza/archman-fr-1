NOM

buildah-manifest-exists - Vérifie si la liste de manifestes donnée existe dans le stockage local

SYNTAXE

buildah manifest exists manifest

DESCRIPTION

buildah manifest exists vérifie si une liste de manifestes existe dans le stockage local. Buildah retournera un code de sortie de 0 si la liste de manifestes est trouvée. Un code de sortie de 1 sera retourné sinon. Un code de sortie de 125 indique qu'il y a eu un autre problème.

OPTIONS

--help, -h

Affiche le message d'utilisation.

EXEMPLE

Vérifie si une liste de manifestes nommée list1 existe (la liste de manifestes existe réellement).

$ buildah manifest exists list1
$ echo $?
0
$

Vérifie si un manifeste nommé mylist existe (la liste de manifestes n'existe pas réellement).

$ buildah manifest exists mylist
$ echo $?
1
$
