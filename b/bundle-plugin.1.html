NOM

bundle-plugin - Gérer les plugins Bundler

SYNOPSIS

bundle plugin install PLUGINS [--source=SOURCE] [--version=VERSION] [--git=GIT] [--branch=BRANCH|--ref=REF] [--local-git=LOCAL_GIT] [--path=PATH]
bundle plugin uninstall PLUGINS [--all]
bundle plugin list
bundle plugin help [COMMAND]

DESCRIPTION

Vous pouvez installer, désinstaller et lister les plugins pour étendre les fonctionnalités de Bundler.

SOUS-COMMANDES

install

Installe le(s) plugin(s) donné(s).

Par exemple, bundle plugin install bundler-graph installera le gem bundler-graph à partir des sources configurées globalement (par défaut RubyGems.org). Notez que la source globale spécifiée dans Gemfile est ignorée.

OPTIONS

--source=SOURCE
Installe le gem du plugin à partir d'une source spécifique, plutôt qu'à partir des sources configurées globalement.
Exemple : bundle plugin install bundler-graph --source https://example.com
--version=VERSION
Spécifie une version du gem du plugin à installer via --version.
Exemple : bundle plugin install bundler-graph --version 0.2.1
--git=GIT
Installe le gem du plugin à partir d'un dépôt Git. Vous pouvez utiliser des URL Git standard comme :
ssh://[user@]host.xz[:port]/path/to/repo.git
http[s]://host.xz[:port]/path/to/repo.git
/path/to/repo
file:///path/to/repo
Exemple : bundle plugin install bundler-graph --git https://github.com/rubygems/bundler-graph
--branch=BRANCH
Lorsque vous spécifiez --git, vous pouvez utiliser --branch pour spécifier la branche à utiliser.
--ref=REF
Lorsque vous spécifiez --git, vous pouvez utiliser --ref pour spécifier n'importe quelle étiquette (tag) ou hash de commit (révision) à utiliser.
--path=PATH
Installe le gem du plugin à partir d'un chemin local.
Exemple : bundle plugin install bundler-graph --path ../bundler-graph
--local-git=LOCAL_GIT
Installe le gem du plugin à partir d'un dépôt Git local.
Exemple : bundle plugin install bundler-graph --local-git ../bundler-graph.
Cette option est obsolète en faveur de --git.

uninstall

Désinstalle le(s) plugin(s) spécifié(s) dans PLUGINS.

OPTIONS

--all
Désinstalle tous les plugins installés. S'il n'y a aucun plugin installé, cela ne fait rien.

list

Liste les plugins installés et les commandes disponibles.

Aucune option.

help

Décrit les sous-commandes ou un sous-commande spécifique.

Aucune option.
