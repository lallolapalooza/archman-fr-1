Nom

btattach - Attacher des périphériques série à la pile BlueZ

SYNOPSIS

btattach [-B périphérique] [-A périphérique] [-P protocole] [-R]

DESCRIPTION

btattach(1) est utilisé pour attacher un UART série à la pile Bluetooth en tant qu'interface de transport.

OPTIONS

-B périphérique, --brder périphérique
Attacher un contrôleur BR/EDR
-A périphérique, --amp périphérique
Attacher un contrôleur AMP
-P protocole, --protocol protocole
Spécifier le type de protocole pour la communication avec le périphérique.

Les valeurs prises en charge sont :

protocole
h4
bcsp
3wire
h4ds
ll
ath3k
intel
bcm
qca
-S débit, --speed débit
Spécifier le débit en bauds à utiliser
-N, --noflowctl
Désactiver le contrôle de flux
-v, --version
Afficher la version
-h, --help
Afficher les options d'aide
