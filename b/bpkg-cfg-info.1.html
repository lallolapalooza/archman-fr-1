NOM

bpkg-cfg-info - afficher les informations de configuration

SYNOPSIS

bpkg cfg-info [options]

DESCRIPTION

La commande cfg-info affiche le chemin absolu, l'identifiant, le type et le nom de la configuration courante. Si les options --link et/ou --backlink sont spécifiées, ces informations sont également affichées pour chaque configuration liée et/ou rétro-liée implicitement, le cas échéant. Notez que les rétro-liens implicites pendants sont ignorés silencieusement, sauf si --dangling est spécifié, auquel cas ces informations sont également affichées pour eux. Notez que les informations sont écrites sur stdout, et non sur stderr.

Si l'option --recursive est spécifiée conjointement avec --link et/ou --backlink, alors ces informations sont affichées pour les configurations liées et/ou rétro-liées implicitement, de manière récursive.

Le format de sortie est régulier, chaque valeur étant imprimée sur une ligne séparée et préfixée par le nom de la valeur. Si les options --link, --backlink, et/ou --dangling sont spécifiées, les blocs d'informations correspondant aux configurations liées sont séparés par des lignes vides. Par exemple :

path: /path/to/cfg/
uuid: 8d439f03-7342-4502-8b1c-74b173869478
type: target
name: foo
path: /path/to/host-cfg/
uuid: 7ee4dab3-07d9-4163-81c0-3779166a7213
type: host
name: tools
path: /path/to/build2-cfg/
uuid: d453aa2a-92c4-4066-87e4-c8672eed06e1
type: build2
name: modules

OPTIONS CFG-INFO

--link
Afficher les configurations liées.
--backlink
Afficher les configurations rétro-liées implicitement.
--dangling
Afficher les rétro-liens implicites pendants.
--recursive
Afficher les configurations liées de manière récursive.
--directory|-d dir
Supposer que la configuration se trouve dans dir plutôt que dans le répertoire de travail courant.

FICHIERS D'OPTIONS PAR DÉFAUT

Voir bpkg-default-options-files(1) pour un aperçu des fichiers d'options par défaut. Pour la commande cfg-info , le répertoire de départ de la recherche est le répertoire de configuration.Les fichiers d'options suivants sont recherchés dans chaque répertoire et, s'ils sont trouvés, chargés dans l'ordre indiqué :

bpkg.options
bpkg-cfg-info.options

Les options cfg-info suivantes de la commande ne peuvent pas être spécifiées dans les fichiers d'options par défaut :

--directory|-d
