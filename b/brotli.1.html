brotli(1) Manuel utilisateur brotli(1)

NOM

brotli(1) -- brotli, unbrotli - compresser ou décompresser des fichiers

SYNTAXE

brotli [OPTION|FICHIER]...

unbrotli est équivalent à brotli --decompress

DESCRIPTION

brotli est un algorithme de compression sans perte à usage général qui compresse les données en utilisant une combinaison d'une variante moderne de l'algorithme LZ77, le codage de Huffman et la modélisation de contexte d'ordre 2, avec un ratio de compression comparable aux meilleures méthodes de compression générales actuellement disponibles. Il est similaire en vitesse à deflate mais offre une compression plus dense.

La syntaxe de la commande brotli est similaire à celle de gzip (1) et zstd (1). Contrairement à gzip (1), les fichiers sources sont conservés par défaut. Il est possible de les supprimer après traitement en utilisant l'option --rm.

Les arguments qui ressemblent à “--nom” ou “--nom=valeur” sont des options. Chaque option a une forme courte “-x” ou “-x valeur”. Plusieurs options courtes peuvent être regroupées :

•
“--decompress --stdout --suffix=.b” fonctionne de la même manière que
•
“-d -s -S .b” et
•
“-dsS .b”

brotli a 3 modes de fonctionnement :

•
le mode par défaut est la compression ;
•
l'option --decompress active le mode décompression ;
•
l'option --test passe en mode de test d'intégrité ; cette option est équivalente à “--decompress --stdout” à ceci près que les données décompressées sontDiscardées au lieu d'être écrites sur la sortie standard.

Chaque argument qui n'est pas une option est une entrée de fichier. Si aucun fichier n'est donné ou si le fichier est “-”, brotli lit depuis l'entrée standard. Tous les arguments après “--” sont des entrées de fichier.

À moins que --stdout ou --output ne soit spécifié, les fichiers sont écrits dans un nouveau fichier dont le nom est dérivé du nom du fichier source :

•
lors de la compression, un suffixe est ajouté au nom du fichier source pour obtenir le nom du fichier cible ;
•
lors de la décompression, un suffixe est supprimé du nom du fichier source pour obtenir le nom du fichier cible.

Le suffixe par défaut est .br, mais il peut être spécifié avec l'option --suffix.

Les options conflictuelles ou dupliquées ne sont pas autorisées.

OPTIONS

•
-# : niveau de compression (0-9) ; des valeurs plus grandes provoquent une compression plus dense, mais plus lente
•
-c, --stdout : écrire sur la sortie standard
•
-d, --decompress : mode décompression
•
-f, --force : forcer l'écrasement du fichier de sortie
•
-h, --help : afficher cette aide et quitter
•
-j, --rm : supprimer le(s) fichier(s) source ; comportement similaire à gzip (1)
•
-k, --keep : conserver le(s) fichier(s) source ; comportement similaire à zstd (1)
•
-n, --no-copy-stat : ne pas copier les attributs du(des) fichier(s) source
•
-o FICHIER, --output=FICHIER : fichier de sortie ; valide uniquement s'il y a une seule entrée d'entrée
•
-q NUM, --quality=NUM : niveau de compression (0-11) ; des valeurs plus grandes provoquent une compression plus dense, mais plus lente
•
-t, --test : mode test d'intégrité de fichier
•
-v, --verbose : augmenter la verbosité de la sortie
•
-w NUM, --lgwin=NUM : définir la taille de la fenêtre LZ77 (0, 10-24) (par défaut : 24) ; la taille de la fenêtre est (pow(2, NUM) - 16) ; 0 permet au compresseur de décider de la valeur optimale ; une taille de fenêtre plus grande améliore la densité ; le décodeur peut nécessiter jusqu'à la taille de la fenêtre en mémoire pour fonctionner
•
-D FICHIER, --dictionary=FICHIER : utiliser FICHIER comme dictionnaire brut (LZ77) ; le même dictionnaire DOIT être utilisé pour la compression et la décompression
•
-S SUF, --suffix=SUF : suffixe du fichier de sortie (par défaut : .br)
•
-V, --version : afficher la version et quitter
•
-Z, --best : utiliser le niveau de compression maximal (par défaut) ; équivalent à “-q 11”

VOIR AUSSI

Le format de fichier brotli est défini dans la RFC 7932 (https://www.ietf.org/rfc/rfc7932.txt).
