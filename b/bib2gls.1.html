L'application remplit deux fonctions en une : (1) sélectionne des entrées à partir de fichiers .bib selon les informations trouvées dans le auxfile (similaire à bibtex) ; (2) trie les entrées de manière hiérarchique et compile les listes d'emplacements (similaire à makeindex et xindy). L'extension .aux peut être omise dans auxfile. Le auxfile (et le fichier .log correspondant) devrait

se

trouver soit dans le répertoire courant, soit dans le répertoire spécifié par --dir. Les fichiers Bib peuvent être relatifs au répertoire dans lequel se trouve le auxfile ou dans un emplacement pouvant être trouvé par kpsewhich.
