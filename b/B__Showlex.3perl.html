B::Showlex(3perl) Guide du programmeur Perl B::Showlex(3perl)

NOM

B::Showlex - Afficher les variables lexicales utilisées dans les fonctions ou les fichiers

SYNTAXE

perl -MO=Showlex[,-OPTIONS][,SOUS-PROGRAMME] foo.pl

DESCRIPTION

Lorsqu'une liste de noms de sous-programmes séparés par des virgules est donnée comme options, Showlex affiche les variables lexicales utilisées dans ces sous-programmes. Sinon, il affiche les variables lexicales au niveau du fichier dans le fichier.

EXEMPLES

Forme traditionnelle :

$ perl -MO=Showlex -e 'my ($i,$j,$k)=(1,"foo")'
Pad of lexical names for comppadlist has 4 entries
0: (0x8caea4) undef
1: (0x9db0fb0) $i
2: (0x9db0f38) $j
3: (0x9db0f50) $k
Pad of lexical values for comppadlist has 5 entries
0: SPECIAL #1 &PL_sv_undef
1: NULL (0x9da4234)
2: NULL (0x9db0f2c)
3: NULL (0x9db0f44)
4: NULL (0x9da4264)
-e syntax OK

Forme nouvelle :

$ perl -MO=Showlex,-newlex -e 'my ($i,$j,$k)=(1,"foo")'
main Pad has 4 entries
0: (0x8caea4) undef
1: (0xa0c4fb8) "$i" = NULL (0xa0b8234)
2: (0xa0c4f40) "$j" = NULL (0xa0c4f34)
3: (0xa0c4f58) "$k" = NULL (0xa0c4f4c)
-e syntax OK

Forme nouvelle, pas de spéciaux, en dehors du framework O :

$ perl -MB::Showlex -e \
   'my ($i,$j,$k)=(1,"foo"); B::Showlex::compile(-newlex,-nosp)->()'
main Pad has 4 entries
1: (0x998ffb0) "$i" = IV (0x9983234) 1
2: (0x998ff68) "$j" = PV (0x998ff5c) "foo"
3: (0x998ff80) "$k" = NULL (0x998ff74)

Notez que cet exemple montre les valeurs des variables lexicales, alors que les autres exemples ne le faisaient pas (car elles sont uniquement au moment de la compilation).

OPTIONS

L'option "-newlex" produit un format plus lisible "nom => valeur", et est montré dans le second exemple ci-dessus.

L'option "-nosp" élimine le signalement des SPÉCIAUX, tels que "0: SPECIAL #1 &PL_sv_undef" ci-dessus. Le signalement des SPÉCIAUX peut parfois submerger vos variables lexicales déclarées.

VOIR AUSSI

B::Showlex peut également être utilisé en dehors du framework O, comme dans le troisième exemple. Voir B::Concise pour une explication plus complète des raisons.

À FAIRE

Certaines des informations rapportées, comme les adresses hexadécimales, ne sont pas particulièrement utiles. D'autres informations seraient plus utiles pour le programmeur typique, telles que les numéros de ligne, les réutilisations d'emplacements de pad, etc. Dans ce contexte, -newlex n'est pas un nom de drapeau particulièrement bon.
