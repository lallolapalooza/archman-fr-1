NOM

bib1-attr - Ensemble d'attributs Bib-1

DESCRIPTION

Cette entrée de référence liste les types et valeurs de l'ensemble d'attributs Bib-1.

TYPES

L'ensemble d'attributs Bib-1 définit six types d'attributs : Utilisation (1), Relation (2), Position (3), Structure (4), Troncation (5) et Complétude (6).
