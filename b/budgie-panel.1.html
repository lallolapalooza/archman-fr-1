BUDGIE-PANEL(1) Commandes utilisateur BUDGIE-PANEL(1)

NOM

budgie-panel - composant graphique qui affiche les widgets Budgie

DESCRIPTION

Utilisation :

budgie-panel [OPTION?] - Tableau de bord Budgie

Options de l'aide :

-h, --help
Affiche les options d'aide
--help-all
Affiche toutes les options d'aide
--help-gtk
Affiche les options GTK+

Options de l'application :

--replace
Remplace le tableau de bord en cours d'exécution
--reset
Réinitialise la configuration du tableau de bord
--display=AFFICHAGE
Affichage X à utiliser
