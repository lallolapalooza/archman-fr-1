NOM

buf-format - Formatte les fichiers Protobuf

SYNOPSIS

buf format [indicateurs]

DESCRIPTION

Par défaut, la source est le répertoire courant et le contenu formaté est écrit sur stdout.

Exemples :

Écrit le contenu formaté du répertoire courant sur stdout :

$ buf format

La plupart des utilisateurs voudront réécrire les fichiers définis dans le répertoire courant en place avec -w :

$ buf format -w

Affiche une différence entre le contenu original et formaté avec -d Écrit une différence au lieu du fichier formaté :

$ buf format simple/simple.proto -d
$ diff -u simple/simple.proto.orig simple/simple.proto
--- simple/simple.proto.orig	2022-03-24 09:44:10.000000000 -0700
+++ simple/simple.proto	2022-03-24 09:44:10.000000000 -0700
@@ -2,8 +2,7 @@
package simple;
-
message Object {
-    string key = 1;
-   bytes value = 2;
+  string key = 1;
+  bytes value = 2;
}

Utilisez l'indicateur --exit-code pour sortir avec un code de sortie non nul s'il y a une différence :

$ buf format --exit-code
$ buf format -w --exit-code
$ buf format -d --exit-code

Formate un fichier, un répertoire ou une référence de module en spécifiant une source, par exemple Écrit le fichier formaté sur stdout :

$ buf format simple/simple.proto
syntax = "proto3";
package simple;
message Object {
  string key = 1;
  bytes value = 2;
}

Écrit le répertoire formaté sur stdout :

$ buf format simple
...

Écrit la référence de module formatée sur stdout :

$ buf format buf.build/acme/petapis
...

Écrit le résultat dans un fichier ou un répertoire de sortie spécifié avec -o, par exemple :

Écrit le fichier formaté dans un autre fichier :

$ buf format simple/simple.proto -o simple/simple.formatted.proto

Écrit le répertoire formaté dans un autre répertoire, en le créant s'il n'existe pas :

$ buf format proto -o formatted

Cela fonctionne également avec les références de module :

$ buf format buf.build/acme/weather -o formatted

Réécrit les fichiers en place avec -w. Par exemple :

Réécrit un seul fichier en place :

$ buf format simple.proto -w

Réécrit un répertoire entier en place :

$ buf format proto -w

Écrit une différence et réécrit les fichiers en place :

$ buf format simple -d -w
$ diff -u simple/simple.proto.orig simple/simple.proto
...

Les indicateurs -w et -o ne peuvent pas être utilisés ensemble dans une même invocation.

OPTIONS

--config="" Le fichier buf.yaml ou les données à utiliser pour la configuration

-d, --diff[=false] Affiche les différences au lieu de réécrire les fichiers

--disable-symlinks[=false] Ne suit pas les liens symboliques lors de la lecture des sources ou de la configuration à partir du système de fichiers local. Par défaut, les liens symboliques sont suivis dans cette CLI, mais jamais suivis sur le Buf Schema Registry.

--error-format="text" Le format des erreurs de compilation imprimées sur stderr. Doit être l'un des : [text,json,msvs,junit,github-actions,gitlab-code-quality]

--exclude-path=[] Exclut des fichiers ou répertoires spécifiques, par exemple "proto/a/a.proto", "proto/a". Si spécifié plusieurs fois, l'union est prise.

--exit-code[=false] Sort avec un code de sortie non nul si les fichiers n'étaient pas déjà formatés

-h, --help[=false] Aide pour format

-o, --output="-" L'emplacement de sortie pour les fichiers formatés. Doit être l'un des formats [dir,protofile]. Si omis, le résultat est écrit sur stdout.

--path=[] Limite à des fichiers ou répertoires spécifiques, par exemple "proto/a/a.proto", "proto/a". Si spécifié plusieurs fois, l'union est prise.

-w, --write[=false] Réécrit les fichiers en place

OPTIONS HÉRITÉES DES COMMANDES PARENTES

--debug[=false] Active la journalisation de débogage

--log-format="color" Le format du journal [text,color,json]

--timeout=0s La durée avant l'expiration, la régler à 0 signifie aucune expiration
