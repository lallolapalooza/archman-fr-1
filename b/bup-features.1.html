NOM

bup-features - rapporter l'état et les capacités actuels de bup lui-même

SYNTAXE

bup features

DESCRIPTION

bup features rapporte des informations sur l'installation bup actuelle, par exemple, quelle version de l'interpréteur Python est utilisée, si l'édition de ligne de commande est prise en charge par bup ftp, ou si les ACL POSIX peuvent être sauvegardées et restaurées.

EXEMPLES

$ bup features
bup 0.31~a7ff2d5b8c12b24b97858aad1251d28c18f8c1e1
source a7ff2d5b8c12b24b97858aad1251d28c18f8c1e1 2020-07-05 14:54:06 -0500
    Python: 3.7.3
    Command line editing (e.g. bup ftp): yes
    Saving and restoring POSIX ACLs: yes
....
