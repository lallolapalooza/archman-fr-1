DESCRIPTIO

N

backtrace() renvoie une trace d'appels pour le programme appelant, dans le tableau pointé par buffer. Une trace d'appels est la série des appels de fonctions actuellement actifs pour le programme. Chaque élément du tableau pointé par buffer est de type void *, et est l' adresse de retour de la trame de pile correspondante. L'argument size spécifie le nombre maximal d'adresses qui peuvent être stockées dans buffer. Si la trace d'appels est plus grande que size, les adresses correspondant aux size appels de fonctions les plus récents sont renvoyées ; pour obtenir la trace d'appels complète, assurez-vous que buffer et size sont suffisamment

grands.

Étant donné l'ensemble d'adresses renvoyées par backtrace() dans buffer, backtrace_symbols() traduit les adresses en un tableau de chaînes de caractères qui décrivent les adresses de manière symbolique. L'argument size spécifie le nombre d'adresses dans buffer. La représentation symbolique de chaque adresse se compose du nom de la fonction (si cela peut être déterminé), d'un décalage hexadécimal dans la fonction, et de l'adresse de retour réelle (en hexadécimal). L'adresse du tableau de pointeurs de chaînes est renvoyée en tant que résultat de la fonction backtrace_symbols(). Ce tableau est alloué par backtrace_symbols(), et doit être libéré par l'appelant. (Les chaînes de caractères pointées par le tableau de pointeurs n'ont pas besoin d'être libérées et ne doivent pas l'être.

)

backtrace_symbols_fd() prend les mêmes arguments buffer et size que backtrace_symbols(), mais au lieu de renvoyer un tableau de chaînes de caractères à l'appelant, il écrit les chaînes, une par ligne, dans le descripteur de fichier fd. backtrace_symbols_fd() n'appelle pas malloc(3), et peut donc être utilisé dans des situations où

cette dernière fonction pourra
it échouer, mais voir REMARQUES.

VALEUR

RENVOYÉE

backtrace() renvoie le nombre d'adresses renvoyées dans buffer, qui n'est pas supérieur à size. Si la valeur de retour est inférieure à size, la trace d'appels complète a été stockée ; si elle est égale à size, elle a pu être tronquée, auquel cas, les adresses des trames de pile les plus anciennes ne sont pas

renvoyées.

En cas de succès, backtrace_symbols() renvoie un pointeur vers le tableau alloué par l'appel ; en cas

d'erreur, NUL
L est renvoyé.

REMARQUE

S

Ces fonctions font certaines hypothèses sur la manière dont l'adresse de retour d'une fonction est stockée sur la pile. Notez ce qui suit

:
•
L'omission des pointeurs de trame (comme impliqué par n'importe lequel des niveaux d'optimisation non nuls de gcc(1)) peut causer la violation de ces
hypothèses.
•
Les fonctions en ligne n'ont pas de trames de
pile.
•
L'optimisation des appels en queue de pile fait qu'une trame de pile remplace une
autre.
•
backtrace() et backtrace_symbols_fd() n'appellent pas malloc() explicitement, mais elles font partie de libgcc, qui est chargé dynamiquement lors de la première utilisation. Le chargement dynamique déclenche généralement un appel à malloc(3). Si vous avez besoin que certains appels à ces deux fonctions n'allouent pas de mémoire (dans des gestionnaires de signaux par exemple), vous devez vous assurer que libgcc est charg
é au pr
éalable.

Les noms de symboles peuvent ne pas être disponibles sans l'utilisation d'options spéciales de l'éditeur de liens. Pour les systèmes utilisant l'éditeur de liens GNU, il est nécessaire d'utiliser l'option de l'éditeur de liens -rdynamic. Notez que les noms des fonctions "static" ne sont p

as exposés et ne seront pas disp
onibles dans la trace d'appels.

#include <execinfo.h>
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
#define BT_BUF_SIZE 100
void
myfunc3(void)
{
    int nptrs;
    void *buffer[BT_BUF_SIZE];
    char **strings;
    nptrs = backtrace(buffer, BT_BUF_SIZE);
    printf("backtrace() returned %d addresses\n", nptrs);
    /* The call backtrace_symbols_fd(buffer, nptrs, STDOUT_FILENO)
       would produce similar output to the following: */
    strings = backtrace_symbols(buffer, nptrs);
    if (strings == NULL) {
        perror("backtrace_symbols");
        exit(EXIT_FAILURE);
    }
    for (size_t j = 0; j < nptrs; j++)
        printf("%s\n", strings[j]);
    free(strings);
}
static void   /* "static" means don't export the symbol.  */
myfunc2(void)
{
    myfunc3();
}
void
myfunc(int ncalls)
{
    if (ncalls > 1)
        myfunc(ncalls - 1);
    else
        myfunc2();
}
int
main(int argc, char *argv[])
{
    if (argc != 2) {
        fprintf(stderr, "%s num-calls\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    myfunc(atoi(argv[1]));
    exit(EXIT_SUCCESS)
;
}
