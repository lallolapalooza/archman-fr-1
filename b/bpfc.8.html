DESCRIPTIO

N

bpfc est un petit assembleur et compilateur Berkeley Packet Filter capable de traduire des mnémoniques semblables à l'assembleur BPF vers un format numérique ou de type C, qui peut être lu par des outils tels que netsniff-ng, iptables (xt_bpf) et bien d'autres. BPF est la construction de filtrage amont unique et unique utilisée en combinaison avec les sockets packet(7), mais aussi seccomp-BPF pour la mise en bac à sable des appels

système.

Le noyau Linux et aussi les noyaux BSD implémentent des constructions de type « machine virtuelle » et des compilateurs JIT qui imitent une petite machine basée sur des registres dans l'architecture BPF et exécutent du code de filtre qui est, par exemple, composé par bpfc sur un tampon de données qui est fourni par des paquets réseau. Le but de cela est de déplacer le calcul dans le temps, de sorte que le noyau puisse abandonner ou tronquer les paquets entrants le plus tôt possible sans avoir à les pouser vers l'espace utilisateur pour une analyse ultérieure. Pendant ce temps, les constructions BPF trouvent également application dans d'autres domaines tels que la communication entre l'espace utilisateur et le noyau comme la mise en bac à sable des appels

système.

Au moment de la rédaction de cette page man, le seul autre compilateur BPF disponible fait partie de la bibliothèque pcap(3) et est accessible via un langage de filtre de haut niveau qui pourrait être familier à beaucoup de gens comme des filtres de type

tcpdump.

Cependant, il est souvent utile de contourner ce compilateur et d'écrire du code optimisé qui ne peut pas être produit par le compilateur pcap(3), ou qui est mal optimisé, ou qui est défectueux volontairement afin de déboguer du code de test du noyau. De plus, une raison d'utiliser bpfc pourrait être d'essayer de nouvelles extensions BPF qui ne sont pas prises en charge par d'autres compilateurs. De plus, bpfc peut être utile pour vérifier le comportement du compilateur JIT ou pour trouver des bugs possibles qui doivent être

corrigés.

bpfc est implémenté avec l'aide de flex(1) et bison(1), tokenise le fichier source dans la première étape et analyse son contenu en un AST. En deux étapes de génération de code, il émet les opcodes cibles. bpfc prend en charge de plus les extensions BPF du noyau Linux. Plus d'informations à ce sujet peuvent être trouvées dans la section

syntaxe.

Le compilateur JIT BPF du noyau Linux est automatiquement activé si détecté par netsniff-ng. Cependant, il peut aussi être activé manuellement via la commande ''echo "1" > /proc/sys/net/core/bp

f_jit_enable'' (mode de fonctionnement normal) ou ''echo "2" > /proc/sys/net/core/bpf_jit_enable'' (mode de débogage où les opcodes émis de l'image sont imprimés dans le journal du noyau).
Un désassembleur d'image JIT BPF indépendant de l'architecture peut être trouvé dans l'arborescence des sources du noyau sous ''tools/net/bpf_jit_disasm.c'' ou dans le dépôt Git de netsniff-ng.

Un programme, qui est traduit par bpfc en ''opcodes'', est un tableau qui se compose des éléments suivants

:


o:16, jt:8, jf:8, k:

L'élément o est un opcode de 16 bits qui a une instruction particulière encodée, jt et jf sont deux cibles de saut de 8 bits, une pour la condition
''vraie'', une pour la condition ''fausse''. Enfin, l'élément k de 32 bits contient un argument divers qui peut être interprété de différentes manières en fonction de l'instruction resp. de l'opcode

donné.

Le jeu d'instructions se compose des instructions de chargement, de stockage, de branchement, ALU, diverses et de retour qui sont aussi représentées dans la syntaxe bpfc. EXEMPLE
bpfc
fubar
Compiler le fichier source ''fubar'' en opcodes BPF. Les opcodes seront dirigés vers
stdout.
bpfc -f xt_bpf -b -p -i fubar, resp. iptables -A INPUT -m bpf --bytecode `bpfc -f xt_bpf -i fubar` -j
LOG
Compiler le fichier source ''fubar'' en opcodes BPF, contourner la validation du filtre de base et émettre les opcodes dans le format lisible par xt_bpf de netfilter. Notez que le fichier source ''fubar'' est d'abord passé au préprocesseur C pour des remplacements textuels avant d'être transmis au compilateur
bpfc.
cat fubar | bpfc
-

stdout.
bpfc foo > bar && netsniff-ng -f bar
...
