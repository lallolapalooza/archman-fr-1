NOM

BN_copy, BN_dup, BN_with_flags - copier des BIGNUMs

SYNOPSIS

#include <openssl/bn.h>
BIGNUM *BN_copy(BIGNUM *to, const BIGNUM *from);
BIGNUM *BN_dup(const BIGNUM *from);
void BN_with_flags(BIGNUM *dest, const BIGNUM *b, int flags);

DESCRIPTION

BN_copy() copie from dans to. BN_dup() crée un nouveau BIGNUM contenant la valeur from.

BN_with_flags crée une copie superficielle temporaire de b dans dest. Elle impose des restrictions importantes sur les données copiées. Les applications qui ne respectent pas ces restrictions peuvent rencontrer des effets secondaires inattendus ou des plantages. Pour cette raison, l'utilisation de cette fonction est déconseillée. Les drapeaux (flags) fournis dans flags seront définis dans dest en plus de tous les drapeaux déjà définis dans b. Par exemple, cela pourrait être couramment utilisé pour créer une copie temporaire d'un BIGNUM avec le drapeau BN_FLG_CONSTTIME défini pour des opérations en temps constant. La copie temporaire dans dest partagera un état interne avec b. Pour cette raison, les restrictions suivantes s'appliquent à l'utilisation de dest :

  • dest doit être un BIGNUM nouvellement alloué obtenu par un appel à BN_new(). Il ne doit pas avoir été utilisé à d'autres fins ni avoir été initialisé d'une quelconque manière.
  • dest ne doit être utilisé que dans des opérations en "lecture seule", c'est-à-dire typiquement celles où le paramètre pertinent est déclaré "const".
  • dest doit être utilisé et libéré avant toute nouvelle utilisation ultérieure de b.

VALEURS DE RETOUR

BN_copy() renvoie to en cas de succès, NULL en cas d'erreur. BN_dup() renvoie le nouveau BIGNUM, et NULL en cas d'erreur. Les codes d'erreur peuvent être obtenus par ERR_get_error(3).
