NOM

bup-tag - marquer un commit dans le dépôt bup

SYNTAXE

bup tag

bup tag [-f] <nom du tag> <committish>

bup tag -d [-f] <nom du tag>

DESCRIPTION

bup tag liste, crée ou supprime un tag dans le dépôt bup.

Un tag est un moyen simple de récupérer un commit spécifique. Il peut être utilisé pour marquer une sauvegarde spécifique pour une récupération plus facile ultérieurement.

Lorsqu'il est appelé sans arguments, la commande liste tous les tags trouvés dans le dépôt. Lorsqu'il est appelé avec un nom de tag et un ID de commit ou un nom de référence, il crée un nouveau tag avec le nom donné, s'il n'existe pas déjà, qui pointe vers le commit donné dans le deuxième argument. Lorsqu'il est appelé avec `-d' et un nom de tag, il supprime le tag donné, s'il existe.

bup expose le contenu des sauvegardes avec les tags actuels, via toute commande qui liste ou affiche les sauvegardes. Ils peuvent être trouvés sous le répertoire /.tag. Par exemple, la commande `ftp' affichera le tag nommé `tag1' sous /.tag/tag1.

OPTIONS

-d, --delete
supprimer un tag
-f, --force
Écraser le tag nommé même s'il existe déjà. Avec -f, ne pas signaler un tag manquant comme une erreur.

EXEMPLES

$ bup tag new-puppet-version hostx-backup
$ bup tag
new-puppet-version
$ bup ftp "ls /.tag/new-puppet-version"
files..
$ bup tag -d new-puppet-version
