BUNDLE-LIST(1) Manuel des commandes générales BUNDLE-LIST(1)

NOM

bundle-list - Lister toutes les gemmes du bundle

SYNTAXE

bundle list [--name-only] [--paths] [--without-group=GROUP[ GROUP...]] [--only-group=GROUP[ GROUP...]]

DESCRIPTION

Affiche une liste de toutes les gemmes du bundle, y compris leur version.

Exemples :

bundle list --name-only

bundle list --paths

bundle list --without-group test

bundle list --only-group dev

bundle list --only-group dev test --paths

OPTIONS

--name-only
N'afficher que le nom de chaque gemme.
--paths
Afficher le chemin d'accès de chaque gemme du bundle.
--without-group=<liste>
Une liste séparée par des espaces des groupes de gemmes à ignorer lors de l'affichage.
--only-group=<liste>
Une liste séparée par des espaces des groupes de gemmes à afficher.
