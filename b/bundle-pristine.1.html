BUNDLE-PRISTINE(1) Manuel des commandes générales BUNDLE-PRISTINE(1)

NOM

bundle-pristine - Restaure les gems installées à leur état pristine

SYNTAXE

bundle pristine

DESCRIPTION

pristine restaure les gems installées dans le bundle à leur état pristine en utilisant le cache local des gems de RubyGems. Pour les gems git, un checkout forcé sera effectué.

Pour plus d'explications, bundle pristine ignore les fichiers décompressés sur disque. Autrement dit, cette commande utilise le cache local .gem ou le dépôt git de la gem comme si l'on installait à partir de zéro.

Note : la gem Bundler ne peut pas être restaurée à son état d'origine avec pristine. On ne peut pas non plus utiliser bundle pristine sur les gems ayant une option 'path' dans le Gemfile, car bundler n'a aucune copie d'origine à partir de laquelle restaurer.

Quand est-il pratique d'utiliser bundle pristine ?

C'est très utile lorsqu'un développeur débogue une gem. bundle pristine est un excellent moyen de se débarrasser des modifications expérimentales apportées à une gem que l'on ne souhaite pas conserver.

Pourquoi utiliser bundle pristine plutôt que gem pristine --all ?

Les deux commandes sont très similaires. Pour le contexte : bundle pristine, sans arguments, nettoie toutes les gems du lockfile. Pendant ce temps, gem pristine --all nettoie toutes les gems installées pour cette version de Ruby.

Si un développeur oublie quelles gems de son projet il a pu déboguer, la commande gem pristine [NOM_DE_GEM] de Rubygems peut être incommode. On peut éviter d'attendre gem pristine --all et exécuter à la place bundle pristine.
