BLKCAT(1) Manuel des commandes générales BLKCAT(1)

NOM

blkcat - Affiche le contenu d'une unité de données du système de fichiers dans une image de disque.

SYNTAXE

blkcat [-ahswvV] [-f fstype] [-u unit_size] [-i imgtype] [-o imgoffset] [-b dev_sector_size] image [images] unit_addr [num]

DESCRIPTION

blkcat affiche num unités de données (par défaut, une) à partir de l'adresse d'unité unit_addr de l'image vers la sortie standard dans différents formats (par défaut, brut). blkcat était appelé dcat dans les versions de TSK antérieures à 3.0.0.

ARGUMENTS

-a
Affiche le contenu en ASCII.
-f fstype
Spécifie le type de fichier de l'image. Si 'swap' est donné ici, l'image sera affichée par pages de 4096 octets. Si 'raw' est donné, 512 octets sont utilisés comme taille par défaut. L'indicateur '-u' peut modifier la taille par défaut. Utilisez '-f list' pour lister les types de systèmes de fichiers pris en charge. Si non spécifié, des méthodes de détection automatique sont utilisées.
-h
Affiche le contenu en format hexdump.
-s
Affiche des statistiques sur l'image (taille de l'unité, taille du bloc de fichier et nombre de fragments).
-u unit_size
Spécifie la taille de l'unité de données par défaut pour les images brutes, blkls et swap.
-i imgtype
Identifie le type de fichier image, tel que 'raw'. Utilisez '-i list' pour lister les types pris en charge. Si non spécifié, des méthodes de détection automatique sont utilisées.
-o imgoffset
Le décalage de secteur où le système de fichiers commence dans l'image.
-b dev_sector_size
La taille, en octets, des secteurs du périphérique sous-jacent. Si non spécifié, la valeur dans le format de l'image est utilisée (si elle existe) ou 512 octets sont supposés.
-v
Sortie détaillée vers stderr.
-V
Affiche la version.
-w
Affiche le contenu dans un format de tableau HTML.
image [images]
Le disque ou la partition image à lire, dont le format est spécifié avec '-i'. Plusieurs noms de fichiers image peuvent être donnés si l'image est divisée en plusieurs segments. Si un seul fichier image est donné et que son nom est le premier d'une séquence (par exemple, indiqué par une terminaison en '.001'), les segments d'image suivants seront inclus automatiquement.
unit_addr
L'adresse de l'unité de disque à afficher. La taille d'une unité sur ce système de fichiers peut être déterminée à l'aide de l'option -s.
num
Le nombre d'unités de données à afficher.

La fonctionnalité de base de blkcat peut également être obtenue à l'aide de dd. Pour déterminer quel inode a alloué une unité donnée, la commande ifind(1) peut être utilisée.

EXEMPLES

# blkcat -hw image 264 4

ou

# blkcat -hw image 264

VOIR AUSSI

ifind(1)
