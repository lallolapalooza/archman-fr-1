NOM

batcher - Mise en lots des articles pour InterNetNews

SYNTAXE

batcher [-rv] [-a articles] [-A total-articles] [-b taille] [-B taille-totale] [-i chaine] [-N lots] [-p process] [-s séparateur] hôte [entrée]

DESCRIPTION

batcher lit une liste de fichiers et prépare des lots d'articles pour l'hôte spécifié. Il est généralement utilisé pour préparer des flux UUCP, mais les lots résultants peuvent être utilisés par toute application qui utilise rnews(1) pour injecter les articles. Il est normalement invoqué par un script exécuté via cron qui utilise shlock pour verrouiller l'hôte, suivi de ctlinnd pour vider le fichier de lots. Voir send-uucp(8) pour une interface pour batcher.

batcher lit le fichier entrée, ou l'entrée standard si aucun fichier n'est donné. Si entrée est un nom de fichier relatif, il est supposé se trouver dans pathoutgoing tel que défini dans inn.conf. Les lignes vides et les lignes commençant par un signe numéro (#) sont ignorées. Toutes les autres lignes de l'entrée doivent consister en un ou deux champs séparés par un seul espace. Le premier champ est le jeton d'API de stockage d'un article. Le second champ, s'il est présent, spécifie la taille de l'article en octets.

Par défaut, les lots sont écrits sur la sortie standard (ce qui n'est pas très utile si plus d'un lot est produit), mais voir l'option -p.

OPTIONS

-a articles
Ce drapeau limite le nombre d'articles inclus dans chaque lot. La valeur par défaut est sans limite. Un nouveau lot sera démarré lorsque soit le nombre total d'octets, soit le nombre d'articles écrits dépassera les limites spécifiées.
-A total-articles
Limite le nombre total d'articles écrits pour tous les lots. Dès que le nombre total d'articles écrits dans les lots atteint ou dépasse total-articles, tous les articles supplémentaires dans l'entrée seront différés. La valeur par défaut est sans limite.
-b taille
Ce drapeau définit la limite de taille pour chaque lot ; dès qu'au moins cette quantité de données a été écrite, un nouveau lot sera démarré. La taille par défaut est de 60 Ko. L'utilisation de (-b 0) permettra des tailles de lot illimitées.
-B taille-totale
Limite le nombre total d'octets écrits pour tous les lots. Dès que le nombre total d'octets écrits dans les lots atteint ou dépasse taille-totale, tous les articles supplémentaires dans l'entrée seront différés. La valeur par défaut est sans limite.
-i chaine
Un lot commence par une ligne d'identification pour spécifier la méthode de décompression à utiliser à la réception. Lorsque ce drapeau est utilisé, chaine, suivi d'un saut de ligne, sera affiché au début de chaque lot. La valeur par défaut est de ne pas avoir de chaîne initiale (en supposant que soit le processeur spécifié avec le drapeau -p, soit un autre processus ultérieur ajoutera la ligne appropriée).
-N lots
Limite le nombre total de lots écrits. Dès que le nombre de lots écrits atteint ou dépasse lots, tous les articles supplémentaires dans l'entrée seront différés. La valeur par défaut est sans limite.
-p process
Par défaut, les lots sont écrits sur la sortie standard, ce qui n'est pas utile lorsque plus d'un lot de sortie est créé. Si cette option est donnée, chaque lot sera au lieu de cela alimenté via un pipe vers la commande shell process. L'argument process doit être une chaîne de format sprintf(3), qui peut avoir un seul paramètre %s qui sera remplacé par le nom de l'hôte.

Une valeur courante est :

( echo '#! gunbatch' ; exec gzip -c ) | uux - -r -z %s!rnews

qui génère des lots compressés gzip et les alimente vers uux.

-r
Par défaut, batcher signale les erreurs dans pathlog/errlog. Pour supprimer cette redirection et signaler les erreurs sur la sortie standard, utilisez le drapeau -r.
-s séparateur
Chaque article dans un lot commence par une ligne séparatrice qui indique la taille de l'article. séparateur doit être une chaîne sprintf(3), qui peut contenir un seul %ld dans la chaîne qui sera remplacé par la taille de l'article. Si le séparateur n'est pas vide, un saut de ligne sera également ajouté après lui lorsqu'il sera ajouté au début de chaque article.

Le séparateur par défaut est :

#! rnews %ld

et cela devrait rarement être changé.

-v
À la sortie, batcher signale des statistiques via syslog. Avec ce drapeau, les statistiques seront également affichées sur la sortie standard.

STATUT DE SORTIE

Si l'entrée est épuisée et que tous les lots sont créés avec succès, batcher se terminera avec un statut zéro.

Si l'une des limites spécifiées avec les drapeaux -A, -B, ou -N est atteinte, ou s'il y a une erreur lors de l'écriture d'un lot, batcher essaiera de mettre en file d'attente l'entrée restante en la copiant dans un fichier comme suit :

  • S'il n'y avait pas de nom de fichier d'entrée, l'entrée restante sera copiée dans pathoutgoing/hôte.
  • Si un nom de fichier d'entrée a été donné, l'entrée restante sera copiée dans un fichier temporaire nommé en ajoutant .bch à la fin de entrée (et qualifié en ajoutant pathoutgoing si entrée n'était pas un chemin entièrement qualifié). Si cela se passe avec succès, batcher essaiera ensuite de renommer ce fichier temporaire en entrée (remplaçant ainsi entrée par une copie de lui-même avec toutes les lignes des articles traités avec succès supprimées).

À la réception d'un signal d'interruption ou de terminaison, batcher terminera le traitement du lot de l'article courant, fermera le lot, puis réécrira le fichier de lot comme décrit ci-dessus.
