NOM

BUILDINFO - Fichier d'informations de construction de paquet

SYNTAXE

Cette page de manuel décrit le format d'un fichier BUILDINFO trouvé à la racine d'un paquet créé par makepkg. Le fichier contient une description de l'environnement de construction du paquet. Les informations sont formatées en paires clé-valeur séparées par un =, une valeur par ligne. Les tableaux sont représentés par plusieurs clés ayant la même valeur.

DESCRIPTION

Ceci est une description du contenu de la version 2 du format de fichier BUILDINFO.

format

Désigne la version du format de fichier, représentée par un entier positif simple.

pkgname

Le nom du paquet.

pkgbase

Le nom de base d'un paquet, généralement le même que pkgname, sauf pour les paquets divisés.

pkgver

La version du paquet incluant pkgrel et epoch.

pkgarch

L'architecture du paquet.

pkgbuild_sha256sum

Le sha256sum au format hexadécimal du PKGBUILD utilisé pour construire le paquet.

packager

Les détails de la personne ayant construit le paquet.

builddate

La date de construction du paquet en epoch.

builddir

Le répertoire où le paquet a été construit.

startdir

Le répertoire à partir duquel makepkg a été exécuté.

buildtool

Le nom de l'écosystème d'outils utilisé pour configurer l'environnement de construction. Utilisé pour définir une spécification pour des constructions reproductibles, par exemple la source du makepkg.conf(5) utilisé.

buildtoolver

La version complète de buildtool, par exemple : "$pkgver-$pkgrel-$pkgarch".

buildenv (tableau)

L'environnement de construction spécifié dans makepkg.conf.

options (tableau)

Les options définies lors de la construction du paquet.

installed (tableau)

Les paquets installés au moment de la construction, incluant les informations de version du paquet. Formaté comme "$pkgname-$pkgver-$pkgrel-$pkgarch".

VOIR AUSSI

makepkg(8), pacman(8), makepkg.conf(5)

Consultez le site web de pacman à l'adresse https://archlinux.org/pacman/ pour des informations à jour sur pacman et ses outils associés.

BOGUES

Bugs ? Vous vous moquez de nous ; il n'y a pas de bugs dans ce logiciel. Mais si nous nous trompions, veuillez les signaler à l'outil de suivi des problèmes à l'adresse https://gitlab.archlinux.org/pacman/pacman/-/issues avec des informations spécifiques telles que votre ligne de commande, la nature du bug, et même la base de données des paquets si cela peut aider.
