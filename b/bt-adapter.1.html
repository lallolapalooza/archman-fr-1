NOM

bt-adapter - un gestionnaire d'adaptateurs Bluetooth

SYNTAXE

bt-adapter [OPTION]

Options d'aide :
-h, --help

Options d'application :
-l, --list
-a, --adapter=<nom|mac>
-i, --info
-d, --discover
--set <propriété> <valeur>

DESCRIPTION

Cet utilitaire est utilisé pour gérer les adaptateurs Bluetooth. Vous pouvez lister tous les adaptateurs disponibles, afficher des informations sur un adaptateur, modifier les propriétés de l'adaptateur ou découvrir des périphériques distants.

OPTIONS

-h, --help
Afficher l'aide

-l, --list
Lister tous les adaptateurs disponibles

-a, --adapter <nom|mac>
Spécifier l'adaptateur à utiliser par son nom ou son adresse MAC
(si cette option n'est pas définie - l'adaptateur par défaut est utilisé)

-i, --info
Afficher des informations sur l'adaptateur (renvoie toutes les propriétés)

-d, --discover
Découvrir les périphériques distants (avec résolution des noms de périphériques distants)

--set <propriété> <valeur>
Modifier les propriétés de l'adaptateur (voir la section PROPRIÉTÉS DE L'ADAPTATEUR pour la liste
des propriétés disponibles)

PROPRIÉTÉS DE L'ADAPTATEUR

string Address [ro]
L'adresse de l'adaptateur Bluetooth (MAC).

string Alias [rw]
Le nom convivial de l'adaptateur Bluetooth.

uint32 Class [ro]
La classe de l'appareil Bluetooth.

boolean Powered [rw]
Allumer ou éteindre un adaptateur. Cela définira également
l'état de connexion approprié.

boolean Discoverable [rw]
Mettre un adaptateur en mode découvrable ou non découvrable
pour le rendre visible ou le masquer.

Si le DiscoverableTimeout est défini sur une valeur non nulle,
le système le réinitialisera à false après l'expiration du délai.
Dans le cas où l'adaptateur est éteint, la définition de cette
valeur échouera.

boolean Pairable [rw]
Mettre un adaptateur en mode appairable ou non appairable.

Notez que cette propriété n'affecte que les demandes d'appairage entrantes.

uint32 PaireableTimeout [rw]
Le délai d'expiration pour l'appairage en secondes. Une valeur de zéro
signifie que le délai est désactivé et qu'il restera en mode
appairable pour toujours.

uint32 DiscoverableTimeout [rw]
Le délai d'expiration pour la découvrabilité en secondes. Une valeur de zéro
signifie que le délai est désactivé et qu'il restera en mode
découvrable/limité pour toujours.

La valeur par défaut pour le délai d'expiration de la découvrabilité devrait
être de 180 secondes (3 minutes).

boolean Discovering [ro]
Indique qu'une procédure de découverte de périphérique est active.

list UUIDs [ro]
Liste des UUIDs 128 bits qui représentent les services locaux disponibles.
