bupstash-restore(1)

Paquet: bupstash

Licences: MIT

() ()

SYNOPSIS

Restaure efficacement le contenu d'un snapshot dans un répertoire local.

bupstash restore [OPTIONS] --into $CHEMIN REQUETE...

DESCRIPTION

bupstash restore effectue un ensemble efficace de changements incrémentaux sur un répertoire afin qu'il devienne identique au snapshot demandé. La nature incrémentale de bupstash restore le rend bien adapté pour alterner entre plusieurs snapshots similaires. Notez que cette opération est dangereuse car elle supprime les fichiers supplémentaires déjà présents dans le répertoire de destination.

Afin d'aider à la navigation dans les fichiers en tant qu'utilisateurs non privilégiés, bupstash restore ne tente pas de restaurer les utilisateurs, les groupes et les xattrs par défaut. Pour les définir, vous devez spécifier respectivement les options --ownership et --xattrs.

L'élément qui est extrait est choisi en fonction d'une requête simple sur les étiquettes spécifiées lors de la sauvegarde des données avec bupstash put.

LANGAGE DE REQUÊTE

Pour une documentation complète sur le langage de requête, voir bupstash-query-language(7).

MISE EN CACHE DES REQUÊTES

La commande restore utilise les mêmes mécanismes de mise en cache des requêtes que bupstash-list(1), consultez cette page pour plus d'informations sur le cache de requêtes.

FICHIERS CREUX

Si un fichier a été détecté comme creux lors de ´put´, la commande restore le restaurera comme creux, mais il convient de noter que la commande restore ne supprimera pas un fichier existant avec la bonne somme de contrôle afin de le recréer comme creux.

OPTIONS

--into CHEMIN
Répertoire dans lequel restaurer les fichiers, par défaut BUPSTASH_RESTORE_DIR.
-r, --repository REPO
Le dépôt auquel se connecter, , peut être de la forme ssh://$SERVEUR/$CHEMIN pour les dépôts distants si l'accès ssh est configuré. S'il n'est pas spécifié, est défini sur BUPSTASH_REPOSITORY.
-k, --key CLÉ
Clé qui sera utilisée pour déchiffrer les données et les métadonnées. Si non définie, par défaut à BUPSTASH_KEY.
--pick CHEMIN
Sélectionner un sous-répertoire du snapshot à restaurer.
--ownership
Définir les uid et gid.
--xattrs
Définir les xattrs.
--indexer-threads N
Nombre de threads processeurs à utiliser pour le hachage de fichiers en pipeline et les lectures de métadonnées. Par défaut au nombre de processeurs.
--query-cache CHEMIN
Chemin vers le fichier de cache de requêtes, par défaut l'un des suivants, dans l'ordre, à condition que les variables d'environnement appropriées soient définies, $BUPSTASH_QUERY_CACHE, $XDG_CACHE_HOME/.cache/bupstash/bupstash.qcache ou $HOME/.cache/bupstash/bupstash.qcache.
--utc-timestamps
Afficher et rechercher par rapport aux horodatages en temps UTC au lieu du temps local.
--no-progress
Supprimer les indicateurs de progression (Les indicateurs de progression sont également supprimés lorsque stderr n'est pas un terminal interactif).
-q, --quiet
Soyez discret, implique --no-progress.

ENVIRONNEMENT

BUPSTASH_REPOSITORY
Le dépôt auquel se connecter. Peut être de la forme ssh://$SERVEUR/$CHEMIN pour les dépôts distants si l'accès ssh est configuré.
BUPSTASH_REPOSITORY_COMMAND
Une commande à exécuter pour se connecter à une instance de bupstash-serve(1). Ceci permet des connexions plus complexes au dépôt pour des cas d'utilisation moins courants.
BUPSTASH_KEY
Chemin vers la clé qui sera utilisée pour déchiffrer les données et les métadonnées.
BUPSTASH_KEY_COMMAND
Une commande à exécuter qui doit imprimer les données de la clé, peut être utilisée à la place de BUPSTASH_KEY pour récupérer la clé à partir d'endroits arbitraires tels que le réseau ou d'autres stockages secrets.
BUPSTASH_QUERY_CACHE
Chemin vers le fichier de cache de requêtes à utiliser.
BUPSTASH_RESTORE_DIR
Chemin dans lequel restaurer, peut être utilisé à la place de l'argument --into.

EXEMPLES

Restaurer un snapshot dans un répertoire local

$ bupstash restore --into ./dir id=ad8*

Restaurer en incluant les utilisateurs et les groupes

$ bupstash restore --ownership --into ./dir id=ad8*

Restaurer un sous-répertoire du snapshot

$ bupstash restore --into ./dir --pick sous/dir id=ad8*
