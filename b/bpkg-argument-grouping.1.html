NOM

bpkg-argument-grouping - facilité de groupement d'arguments

SYNTAXE

bpkg { options }+ argument +{ options }

DESCRIPTION

Pour certaines commandes, certaines options et variables de ligne de commande peuvent être groupées pour ne s'appliquer qu'à des arguments spécifiques. Cette rubrique d'aide décrit la facilité de groupement d'arguments utilisée à cet effet.

Les groupes peuvent être spécifiés avant (précédant) et/ou après (suivant) l'argument auquel ils s'appliquent. Un groupe précédent commence par '{' et se termine par '}+' tandis qu'un groupe suivant commence par '+{' et se termine par '}'. Par exemple :

{ --foo --bar }+ arg   # 'arg' avec '--foo' '--bar'
arg +{ fox=1 baz=2 }   # 'arg' avec 'fox=1' 'baz=2'

Plusieurs groupes précédents et/ou suivants peuvent être spécifiés pour le même argument. Par exemple :

{ -f }+ { -b }+ arg +{ f=1 } +{ b=2 } # 'arg' avec '-f' 'b' 'f=1' 'b=2'

Le groupe s'applique à un seul argument, sauf si plusieurs arguments sont eux-mêmes groupés avec '{' et '}'. Par exemple :

{ --foo }+ arg1  arg2 +{ --bar }      # 'arg1' avec '--foo'
                                      # 'arg2' avec '--bar'
{ --foo }+ { arg1  arg2 } +{ --bar }  # 'arg1' avec '--foo' '--bar'
                                      # 'arg2' avec '--foo' '--bar'

Les séparateurs de groupe ('{', '}+', etc.) doivent être des arguments de ligne de commande distincts. En particulier, ils ne doivent être adjacents ni aux arguments à l'intérieur du groupe, ni à l'argument auquel ils s'appliquent. Tous ces cas seront traités comme des arguments ordinaires. Par exemple :

{--foo}+ arg   # '{--foo}+' ...
arg+{ --foo }  # 'arg+{' ...

Si l'un des séparateurs de groupe doit être spécifié comme argument littéral, il doit être échappé avec '\'. Par exemple :

}             # erreur : séparateur de groupe inattendu
}x            # '}x'
\}            # '}'
{ \}+ }+ arg  # 'arg' avec '}+'
