bigfloat(3perl) Guide de référence du programmeur Perl bigfloat(3perl)

NOM

bigfloat - prise en charge transparente des nombres à virgule flottante gros pour Perl

SYNOPSIS

use bigfloat;
$x = 2 + 4.5;                       # Math::BigFloat 6.5
print 2 ** 512 * 0.1;               # Math::BigFloat 134...09.6
print inf + 42;                     # Math::BigFloat inf
print NaN * 7;                      # Math::BigFloat NaN
print hex("0x1234567890123490");    # Perl v5.10.0 ou plus récent
{
    no bigfloat;
    print 2 ** 256;                 # un scalaire Perl normal maintenant
}
# pour les anciennes versions de Perl, importer dans le paquet courant :
use bigfloat qw/hex oct/;
print hex("0x1234567890123490");
print oct("01234567890123490");

DESCRIPTION

Tous les littéraux numériques dans la portée donnée sont convertis en objets Math::BigFloat.

Tous les opérateurs (y compris les opérations mathématiques de base) sauf l'opérateur de plage ".." sont surchargés.

Ainsi, ceci :

use bigfloat;
$x = 1234;

crée un Math::BigFloat et y stocke une référence dans $x. Cela se produit de manière transparente et derrière votre dos, pour ainsi dire.

Vous pouvez le voir avec ceci :

perl -Mbigfloat -le 'print ref(1234)'

Puisque les nombres sont en fait des objets, vous pouvez appeler toutes les méthodes habituelles de Math::BigFloat dessus. Cela fonctionne même dans une certaine mesure sur les expressions :

perl -Mbigfloat -le '$x = 1234; print $x->bdec()'
perl -Mbigfloat -le 'print 1234->copy()->binc();'
perl -Mbigfloat -le 'print 1234->copy()->binc->badd(6);'
perl -Mbigfloat -le 'print +(1234)->copy()->binc()'

(Notez que print ne fait pas ce que vous attendez si l'expression commence par '(' d'où le "+")

Vous pouvez même chaîner les opérations comme d'habitude :

perl -Mbigfloat -le 'print 1234->copy()->binc->badd(6);'
1241

Veuillez noter que ceci ne fonctionne pas comme prévu (n'imprime rien), car la surcharge de '..' n'est pas encore possible dans Perl (à partir de v5.8.0) :

perl -Mbigfloat -le 'for (1..2) { print ref($_); }'

Options

"bigfloat" reconnaît certaines options qui peuvent être passées lors de son chargement via "use". Les options suivantes existent :

a ou accuracy
Ceci définit la précision pour toutes les opérations mathématiques. L'argument doit être supérieur ou égal à zéro. Voir la méthode bround() de Math::BigInt pour les détails. 
perl -Mbigfloat=a,50 -le 'print sqrt(20)'

Notez qu'il n'est pas possible de définir la précision et l'exactitude en même temps.

p ou precision
Ceci définit la précision pour toutes les opérations mathématiques. L'argument peut être n'importe quel entier. Les valeurs négatives signifient un nombre fixe de chiffres après la virgule, tandis qu'une valeur positive arrondit au chiffre à gauche de la virgule. 0 signifie arrondir à l'entier. Voir la méthode bfround() de Math::BigInt pour les détails. 
perl -Mbigfloat=p,-50 -le 'print sqrt(20)'

Notez qu'il n'est pas possible de définir la précision et l'exactitude en même temps.

t ou trace
Ceci active un mode de traçage et est principalement destiné au débogage.
l, lib, try, ou only
Charge une bibliothèque mathématique différente, voir "Bibliothèque Mathématique". 
perl -Mbigfloat=l,GMP -e 'print 2 ** 512'
perl -Mbigfloat=lib,GMP -e 'print 2 ** 512'
perl -Mbigfloat=try,GMP -e 'print 2 ** 512'
perl -Mbigfloat=only,GMP -e 'print 2 ** 512'
hex
Remplace la méthode intégrée hex() par une version capable de gérer les grands nombres. Ceci la remplace en l'exportant dans le paquet courant. Sous Perl v5.10.0 et supérieur, ce n'est pas si nécessaire, car hex() est lexicalement remplacée dans la portée courante chaque fois que le pragma "bigfloat" est actif.
oct
Remplace la méthode intégrée oct() par une version capable de gérer les grands nombres. Ceci la remplace en l'exportant dans le paquet courant. Sous Perl v5.10.0 et supérieur, ce n'est pas si nécessaire, car oct() est lexicalement remplacée dans la portée courante chaque fois que le pragma "bigfloat" est actif.
v ou version
Ceci affiche le nom et la version des modules puis quitte. 
perl -Mbigfloat=v

Bibliothèque Mathématique

Les calculs avec les nombres sont effectués (par défaut) par un module de bibliothèque backend appelé Math::BigInt::Calc. Le défaut est équivalent à dire :

use bigfloat lib => 'Calc';

Vous pouvez changer cela en utilisant :

use bigfloat lib => 'GMP';

Ce qui suit essaierait d'abord de trouver Math::BigInt::Foo, puis Math::BigInt::Bar, et si cela échoue également, reviendrait à Math::BigInt::Calc :

use bigfloat lib => 'Foo,Math::BigInt::Bar';

Utiliser c<lib> émet un avertissement si aucune des bibliothèques spécifiées ne peut être trouvée et que Math::BigInt a dû utiliser une des bibliothèques par défaut. Pour supprimer cet avertissement, utilisez c<try> à la place :

use bigfloat try => 'GMP';

Si vous voulez que le code échoue au lieu de revenir en arrière, utilisez "only" à la place :

use bigfloat only => 'GMP';

Veuillez consulter la documentation du module respectif pour plus de détails.

Appels de méthodes

Étant donné que tous les nombres sont maintenant des objets, vous pouvez utiliser toutes les méthodes qui font partie de l'API Math::BigFloat.

Mais un avertissement est de mise. Lors de l'utilisation de ce qui suit pour faire une copie d'un nombre, seule une copie superficielle sera effectuée.

$x = 9; $y = $x;
$x = $y = 7;

L'utilisation de la copie ou de l'original avec des calculs surchargés est correcte, par exemple, ce qui suit fonctionne :

$x = 9; $y = $x;
print $x + 1, " ", $y,"\n";     # imprime 10 9

mais l'appel de toute méthode qui modifie le nombre directement entraînera la destruction de l'original et de la copie :

$x = 9; $y = $x;
print $x->badd(1), " ", $y,"\n";        # imprime 10 10
$x = 9; $y = $x;
print $x->binc(1), " ", $y,"\n";        # imprime 10 10
$x = 9; $y = $x;
print $x->bmul(2), " ", $y,"\n";        # imprime 18 18

L'utilisation de méthodes qui ne modifient pas, mais testent que le contenu fonctionne :

$x = 9; $y = $x;
$z = 9 if $x->is_zero();                # fonctionne bien

Voir la documentation sur le constructeur de copie et "=" dans overload, ainsi que la documentation dans Math::BigFloat pour plus de détails.
