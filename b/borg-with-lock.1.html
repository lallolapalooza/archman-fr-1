BORG-WITH-LOCK(1) Outil de sauvegarde borg BORG-WITH-LOCK(1)

NOM

borg-with-lock - exécute une commande spécifiée par l'utilisateur avec le verrou du dépôt maintenu

SYNTAXE

borg [options communes] with-lock [options] DEPOT COMMANDE [ARGUMENTS...]

DESCRIPTION

Cette commande exécute une commande spécifiée par l'utilisateur tout en verrouillant le dépôt. Par exemple :

$ borg with-lock /mnt/borgrepo rsync -av /mnt/borgrepo /quelque/part/ailleurs/borgrepo

Elle essaiera d'abord d'acquérir le verrou (s'assurer qu'aucune autre opération n'est en cours dans le dépôt), puis exécutera la commande donnée en tant que sous-processus et attendra sa terminaison, libérera le verrou et renverra le code de retour de la commande utilisateur comme code de retour de Borg.

NOTE :

Si vous copiez un dépôt avec le verrou maintenu, le verrou sera présent dans la copie. Ainsi, avant d'utiliser Borg sur la copie depuis un autre hôte, vous devrez utiliser "borg break-lock" sur le dépôt copié, car Borg est prudent et ne supprime pas automatiquement les verrous obsolètes créés par un autre hôte.

OPTIONS

Voir borg-common(1) pour les options communes des commandes Borg.

arguments

DEPOT
dépôt à verrouiller
COMMANDE
commande à exécuter
ARGUMENTS
arguments de la commande
