NOM

byobu-select-profile - sélectionner les couleurs de premier plan et d'arrière-plan de votre Byobu

DESCRIPTION

byobu-select-profile est une application qui modifie les couleurs de premier plan et d'arrière-plan de la barre d'état de Byobu.

OPTIONS


-l,--list lister les profils disponibles


-b,--background COULEUR définir la couleur d'arrière-plan


-f,--foreground COULEUR définir la couleur de premier plan


-h,--hostname définir les couleurs basées sur un hachage du nom d'hôte


-i,--ip définir les couleurs basées sur un hachage de l'adresse IP


-r,--random définir les couleurs aléatoirement


--help cette aide
