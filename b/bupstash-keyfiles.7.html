SYNOPSIS

Vue d'ensemble du format de clé bupstash.

DESCRIPTION

Les fichiers de clés bupstash sont encodés en PEM avec l'une des balises suivantes :

○
BUPSTASH KEY
○
BUPSTASH SUB KEY

Les données binaires après décodage des données PEM consistent en des structures de clés bare https://baremessages.org/, décrites ci-dessous.

Encodage binaire des clés :

```

type PrimaryKey { id: Data16, rollsum_key: Data32, data_hash_key_part_1: Data32, data_hash_key_part_2: Data32, data_pk: Data32, data_sk: Data32, data_psk: Data32, idx_hash_key_part_1: Data32, idx_hash_key_part_2: Data32, idx_pk: Data32, idx_sk: Data32, idx_psk: Data32, metadata_pk: Data32, metadata_sk: Data32, metadata_psk: Data32, }

type SubKey { id: Data16, primary_key_id: Data16, rollsum_key: OptionData<32>, data_hash_key_part_1: OptionData<32>, data_hash_key_part_2: OptionData<32>, data_pk: OptionData<32>, data_sk: OptionData<32>, data_psk: OptionData<32>, idx_hash_key_part_1: OptionData<32>, idx_hash_key_part_2: OptionData<32>, idx_pk: OptionData<32>, idx_sk: OptionData<32>, idx_psk: OptionData<32>, metadata_pk: OptionData<32>, metadata_sk: OptionData<32>, metadata_psk: OptionData<32>, }
