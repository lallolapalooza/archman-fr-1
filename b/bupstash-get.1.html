bupstash-get(1)

Paquet: bupstash

Licences: MIT

() ()

SYNTAXE

Récupérer des données d'un dépôt bupstash.

bupstash get [OPTIONS] REQUÊTE...

DESCRIPTION

bupstash get récupère et déchiffre les données stockées dans un dépôt bupstash, les envoyant vers la sortie standard. Si l'élément demandé a été sauvegardé comme un répertoire, la commande le convertit en un flux tar.

L'élément récupéré est choisi en fonction d'une requête simple sur les étiquettes spécifiées lors de la sauvegarde des données avec bupstash put.

LANGAGE DE REQUETES

Pour une documentation complète sur le langage de requête, voir bupstash-query-language(7).

MISE EN CACHE DES REQUETES

La commande get utilise les mêmes mécanismes de mise en cache des requêtes que bupstash-list(1), consultez cette page pour plus d'informations sur le cache des requêtes.

FICHIERS CREUX

Lors de la récupération d'un répertoire sous forme d'archive tar, les fichiers creux ne sont pas traités spécialement. Pour restaurer les fichiers creux tout en préservant les trous de fichier, utilisez plutôt bupstash restore.

OPTIONS

-r, --repository REPO
Le dépôt auquel se connecter, , peut être de la forme ssh://$SERVEUR/$CHEMIN pour les dépôts distants si l'accès ssh est configuré. S'il n'est pas spécifié, est défini sur BUPSTASH_REPOSITORY.
-k, --key CLE
Clé qui sera utilisée pour déchiffrer les données et les métadonnées. S'il n'est pas défini, prend par défaut la valeur de BUPSTASH_KEY.
--pick CHEMIN
Récupérer un fichier individuel ou un sous-répertoire à partir d'un cliché.
--query-cache CHEMIN
Chemin vers le fichier de cache des requêtes, prend par défaut l'une des valeurs suivantes, dans l'ordre, si les variables d'environnement appropriées sont définies : $BUPSTASH_QUERY_CACHE, $XDG_CACHE_HOME/.cache/bupstash/bupstash.qcache ou $HOME/.cache/bupstash/bupstash.qcache.
--utc-timestamps
Afficher et rechercher par rapport aux horodatages en temps UTC au lieu du temps local.
--no-progress
Supprimer les indicateurs de progression (les indicateurs de progression sont également supprimés lorsque stderr n'est pas un terminal interactif).
-q, --quiet
Être silencieux, implique --no-progress.

ENVIRONNEMENT

BUPSTASH_REPOSITORY
Le dépôt auquel se connecter. Peut être de la forme ssh://$SERVEUR/$CHEMIN pour les dépôts distants si l'accès ssh est configuré.
BUPSTASH_REPOSITORY_COMMAND
Une commande à exécuter pour se connecter à une instance de bupstash-serve(1). Ceci permet des connexions plus complexes au dépôt pour des cas d'utilisation moins courants.
BUPSTASH_KEY
Chemin vers la clé qui sera utilisée pour déchiffrer les données et les métadonnées.
BUPSTASH_KEY_COMMAND
Une commande à exécuter qui doit imprimer les données de la clé, peut être utilisée à la place de BUPSTASH_KEY pour récupérer la clé à partir d'emplacements arbitraires tels que le réseau ou d'autres stockages secrets.
BUPSTASH_QUERY_CACHE
Chemin vers le fichier de cache des requêtes à utiliser.

EXEMPLES

Récupérer un élément avec un identifiant spécifique

$ bupstash get id=14ebd2073b258b1f55c5bbc889c49db4 > ./data.file

Récupérer un élément par nom et horodatage

$ bupstash get name=backup.tar and timestamp=2020/19/* > ./restore.tar

Récupérer un fichier ou une sous-archive tar à partir d'un cliché de répertoire

$ bupstash get --pick=chemin/vers/fichier.txt id=$id $ bupstash get --pick=chemin/vers/repertoire id=$id | tar ...

Récupérer une archive tar

La commande put intégrée pour les répertoires crée une archive tar à partir d'un répertoire. Pour l'extraire, nous utilisons tar.

``` # Sauvegarder un répertoire. $ id=$(bupstash put ./data)$ mkdir restore $ bupstash get id=$id | tar -C ./restore -xvf - ```
