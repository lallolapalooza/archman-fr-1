Dans les termes du système de build build2 une bpk

g

configuration de build est une amalgamation qui contient des paquets en tant que sous-projets (voir bpkg-cfg-create(1) pour plus de détails).Les configurations de build peuvent être liées entre elles de sorte que, pendant qu'un paquet est compilé dans une configuration, certaines de ses dépendances peuvent être compilées dans des configurations liées (voir bpkg-cfg-create(1)pour plus de détails). Un paquet bpkgest une archive ou un répertoire (potentiellement dans un système de contrôle de version) qui contient un projet build2 plus le fichier manifeste du paquet. bpkg peut utiliser des archives/répertoires de paquets directement depuis le système de fichiers ou les récupérer à partir de dépôts. Un dépôt

bpkg

est une collection de paquets ainsi que des informations sur les dépôts prérequis et complémentaires. Les dépôts basés

sur

archives , répertoires et contrôle de version sont pris en charge. Un dépôt est identifié par son emplacement, qui peut être un chemin local du système de fichiers ou une URL. Voir bpkg-repository-types(1

)

pour plus de détails sur les structures de dépôts et les formats d'URL. Si la même version d'un paquet est disponible depuis plusieurs dépôts, on suppose qu'ils contiennent un contenu de paquet identique. Dans de tels cas, bpkg préfère les dépôts locaux aux distants et parmi les dépôts locaux, il préfère ceux avec des paquets externes (voir bpkg-pkg-unpack(1) pour plus de détails sur les paquets externes)

.

OPTIONS   COMMUNES


Les options communes sont résumées ci-dessous, une description plus détaillée étant disponible dans bpkg-common-options(1).



  
-v

  
Afficher les commandes sous-jacentes essentielles exécutées.

  
-V

  
Afficher toutes les commandes sous-jacentes exécutées.

  
--quiet|-q

  
Exécuter silencieusement, en n'affichant que les messages d'erreur.

  
--verbose
    level

  
Définir le niveau de verbosité des diagnostics à level entre 0 et 6.

  
--stdout-format
    format

  
Format de représentation à utiliser pour l'affichage sur stdout.

  
--jobs|-j
    num

  
Nombre de tâches à exécuter en parallèle.

  
--no-result

  
Ne pas afficher de messages informatifs sur le résultat de l'exécution d'une
      commande ou de certaines de ses parties.

  
--structured-result
    fmt

  
Écrire le résultat de l'exécution d'une commande sous une forme structurée.

  
--progress

  
Afficher des indicateurs de progression pour les opérations longues, telles que les transferts réseau,
      la compilation, etc.

  
--no-progress

  
Masquer les indicateurs de progression pour les opérations longues, telles que les transferts réseau,
      la compilation, etc.

  
--diag-color

  
Utiliser la couleur dans les diagnostics.

  
--no-diag-color

  
Ne pas utiliser la couleur dans les diagnostics.

  
--build
    path

  
Le programme de build à utiliser pour compiler les paquets.

  
--build-option
    opt

  
Option supplémentaire à passer au programme de build.

  
--fetch
    path

  
Le programme de récupération à utiliser pour télécharger les ressources.

  
--fetch-option
    opt

  
Option supplémentaire à passer au programme de récupération.

  
--fetch-timeout
    sec

  
Le délai d'attente du programme de récupération et des programmes similaires (par exemple git).

  
--pkg-proxy
    url

  
Serveur proxy HTTP à utiliser lors de la récupération des manifestes et archives de paquets depuis des dépôts
      distants de type pkg .

  
--git
    path

  
Le programme git à utiliser pour récupérer les dépôts git.

  
--git-option
    opt

  
Option commune supplémentaire à passer au programme git.

  
--sha256
    path

  
Le programme sha256 à utiliser pour calculer les sommes SHA256.

  
--sha256-option
    opt

  
Option supplémentaire à passer au programme sha256.

  
--tar
    path

  
Le programme tar à utiliser pour extraire les archives de paquets.

  
--tar-option
    opt

  
Option supplémentaire à passer au programme tar.

  
--openssl
    path

  
Le programme openssl à utiliser pour les opérations cryptographiques.

  
--openssl-option
    opt

  
Option supplémentaire à passer au programme openssl.

  
--auth
    type

  
Types de dépôts à authentifier.

  
--trust
    fingerprint

  
Faire confiance au certificat du dépôt avec une empreinte SHA256 fingerprint.

  
--trust-yes

  
Supposer que la réponse à toutes les demandes d'authentification est oui.

  
--trust-no

  
Supposer que la réponse à toutes les demandes d'authentification est non.

  
--git-capabilities
    up=pc

  
Capacités de protocole (pc) pour un préfixe d'URL de dépôt git (up).

  
--pager
    path

  
Le programme de pagination à utiliser pour afficher les longs textes.

  
--pager-option
    opt

  
Option supplémentaire à passer au programme de pagination.

  
--options-file
    file

  
Lire des options supplémentaires depuis file.

  
--default-options
    dir

  
Le répertoire à partir duquel charger des fichiers d'options par défaut supplémentaires.

  
--no-default-options

  
Ne pas charger les fichiers d'options par défaut.

  
--keep-tmp

  
Ne pas supprimer le bpkg's répertoire temporaire à la fin de l'exécution de la
      commande et afficher son chemin d'accès au niveau de verbosité 2 ou
    supérieur.








ENVIRONNEMENT


Les commandes exécutées par bpkg alors que les bases de données de configuration de build actuelles et liées sont ouvertes auront la
      variable d'environnement
    BPKG_OPEN_CONFIGS définie à la liste des chemins d'accès absolus et normalisés des répertoires de configuration,
      séparés par des espaces et
    "-guillemets. Cela peut être utilisé par les crochets (hooks) du système de build et/ou les programmes qu'ils
      exécutent.






CODE   DE   RETOUR



  
0

  

    

    Succès.

  
1

  

    

    Erreur fatale.

  
2

  

    

    Erreur récupérable qui disparaîtra probablement si la commande est
      réexécutée.








ENVIRONNEMENT


La BPKG_DEF_OPT variable d'environnement est utilisée pour supprimer le
    chargement des fichiers d'options par défaut dans les appels imbriqués à bpkg . Ses
    valeurs sont false ou 0 pour supprimer le chargement et true ou 1
    pour le charger.
