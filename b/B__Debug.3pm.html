Debug(3) Documentation Perl fournie par la communauté Debug(3)

NOM

B::Debug - Parcourir l'arbre syntaxique Perl, imprimer des informations de débogage sur les ops

SYNTAXE

perl -MO=Debug foo.pl
perl -MO=Debug,-exec foo.pl

DESCRIPTION

Voir ext/B/README et le plus récent B::Concise.

OPTIONS

Avec l'option -exec, parcourt l'arbre dans l'ordre d'exécution, sinon dans l'ordre de base.
