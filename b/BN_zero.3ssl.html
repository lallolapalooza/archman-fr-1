BN_zero(3ssl)

NOM

BN_zero, BN_one, BN_value_one, BN_set_word, BN_get_word - Opérations d'assignation BIGNUM

SYNTAXE

#include <openssl/bn.h>
void BN_zero(BIGNUM *a);
int BN_one(BIGNUM *a);
const BIGNUM *BN_value_one(void);
int BN_set_word(BIGNUM *a, BN_ULONG w);
unsigned BN_ULONG BN_get_word(BIGNUM *a);

DESCRIPTION

BN_ULONG est une macro qui sera un type entier non signé optimisé pour l'implémentation la plus efficace sur la plateforme locale.

BN_zero(), BN_one() et BN_set_word() définissent a respectivement aux valeurs 0, 1 et w. BN_zero() et BN_one() sont des macros.

BN_value_one() retourne une constante BIGNUM de valeur 1. Cette constante est utile pour les comparaisons et les assignations.

BN_get_word() retourne a, s'il peut être représenté comme un BN_ULONG.

VALEURS DE RETOUR

BN_get_word() retourne la valeur a, ou tous les bits à un si a ne peut pas être représenté comme un entier unique.

BN_one() et BN_set_word() retournent 1 en cas de succès, 0 sinon. BN_value_one() retourne la constante. BN_zero() ne échoue jamais et ne retourne aucune valeur.

BOGUES

Si un BIGNUM est égal à la valeur de tous les bits à un, il entrera en collision avec la condition d'erreur retournée par BN_get_word() qui utilise cela comme valeur d'erreur.

BN_ULONG devrait probablement être un typedef.

VOIR AUSSI

BN_bn2bin(3)

HISTORIQUE

Dans OpenSSL 0.9.8, BN_zero() a été modifié pour ne pas retourner de valeur ; les versions précédentes retournaient un int.
