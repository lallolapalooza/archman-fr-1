BIRDFONT(1) Manuel des commandes générales BIRDFONT(1)

NOM

birdfont - éditeur de polices

SYNTAXE

birdfont [fichier] [options]

DESCRIPTION

birdfont permet d'éditer et de créer des polices.

Voir https://birdfont.org

OPTIONS

-c, --show-coordinates
afficher les coordonnées dans la vue des glyphes
-e, --exit
quitter si un cas de test échoue
-f, --fatal-warning
traiter les avertissements comme fatals
-h, --help
afficher les options de ligne de commande
-s, --slow
attendre entre chaque commande dans la suite de tests
-t [cas de test]
exécuter des tests

AUTEUR
