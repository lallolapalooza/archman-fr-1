DESCRIPTIO

N

Cette classe est définie comme une classe enveloppe autour de la série de fonctions openSSL BN, offrant des membres pour effectuer des opérations arithmétiques sur des valeurs entières de tailles illimitées. Des membres sont offerts pour générer des nombres premiers et pour effectuer toutes sortes d'opérations arithmétiques courantes sur des objets BigInt. Des conversions vers des caractères et des types numériques standard sont également

offertes.

Ci-dessous, la phrase l'objet peut également faire référence à la valeur de l'objet. Le contexte dans lequel cela apparaît rendra clair que c'est la valeur de l'objet plutôt que l'objet en tant que tel qui est

visée.

Divers constructeurs acceptent des arguments BIGNUM. Le type BIGNUM est le type contenant un entier de précision illimitée tel que défini par OpenSSL. La définition

de 
    BIGNUM est
    typedef struct bignum_st BIGNUM;
    struct bignum_st
    {
        BN_ULONG *d;    // Pointeur vers un tableau de blocs de 'BN_BITS2' bits.
        int top;        // Index du dernier d +1 utilisé.
        // Ce qui suit est une gestion interne pour bn_expand.
        int dmax;       // Taille du tableau d.
        int neg;        // 1 si le nombre est négatif
        int flags;
    }
;

Les signes des BigInt sont traités d'une manière particulière. Qu'un BigInt soit négatif ou positif est déterminé par son drapeau de signe, et non par un bit de signe comme c'est le cas avec les valeurs de type int. Puisque les valeurs BigInt ont une précision illimitée, décaler des valeurs vers la gauche ne changera pas leurs

signes.

Les opérateurs retournent soit une référence à l'objet courant (modifié) soit un objet BigInt contenant la valeur calculée. La règle suivie ici a été d'implémenter les opérateurs de manière analogue à la façon dont les opérateurs fonctionnent sur les valeurs et variables de type int. Par exemple, operator+() retourne une valeur BigInt alors que operator+=() retourne une référence BigInt

&.

Tous les membres modifiant leurs objets retournent une référence à l'objet courant (modifié). Tous les membres ne modifiant pas l'objet courant retournent un objet BigInt. Si les deux membres existent effectuant la même fonctionnalité, le nom du membre retournant un objet BigInt se termine par un c (const) (par exemple, addMod et addMod

c).

Presque tous les opérateurs, membres et constructeurs (sauf le constructeur par défaut) lancent des exceptions Excepti

on en cas
d'échec.

BigInt operator~() :
Cet opérateur n'est pas implémenté car il ne peut pas être implémenté de manière à correspondre aux actions de cet opérateur lorsqu'il est appliqué à des valeurs de type int
;
Lorsqu'il est utilisé sur des valeurs int , cet opérateur inverse tous les bits de l' int . Par ex., ~5 représente -6, et ~-6 vaut à nouveau cinq. Le -6 est le résultat du bit de signe des valeurs int . L'implémentation évidente de BigInt::operator~() est d'inverser tous les bits de la valeur et d'inverser son bit de signe. Pour 5, cela donnerait -250 : 5, étant 101 (binaire), tient dans un octet, donc ~5 devient 11111010 (binaire), ce qui vaut 250. Son signe doit être inversé également, donc il devient -250. Cela diffère clairement de la valeur représentée par la constante int ~5 : lors de la construction de BigInt(~5) , la valeur -6 est
obtenue.
Il est possible de changer l'implémentation. Par ex., après 
        Bigint b(5);
        b =
~b; ~b pourrait être implémenté de manière à donner la valeur -6. Mais cela conduit aussi à des résultats inattendus. Alors que 5 & ~5 == 0 , cela ne serait plus vrai pour les objets BigInt : En supposant que b contient 5 , alors b & ~b se développerait en (binaire) 101 & (négatif)110 ce qui équivaut à (binaire)
100 ;
Puisque les deux implémentations produisent des résultats inattendus, BigInt::operator~() n'a pas été implémenté. À la place, deux membres sont proposés : tildeBits() , inversant tous les bits de tous les octets du BigInt et inversant son signe (de sorte que 
        Bigint b(5);
        b.tildeBits();
change la valeur de b en -250), et tildeInt() changeant la valeur de l'objet en la valeur qui aurait été obtenue si un BigInt n'était qu'un simple int (de sorte que 
        Bigint b(5);
        b.tildeInt();
change la valeur d
e b e
n -6).

MEMBRES STATIQUES

Tous les membres retournant un BigInt calculé à partir d'un ensemble d'arguments et ne nécessitant pas d'objet BigInt existant sont définis comme membres statiques. Le premier membre diophantus, retournant une valeur long long, est également un membre statique.

o
long long diophantus(long long *factor1, long long *factor2, long long value1, long long value2):
La solution entière de factor1 * value1 + factor2 * value2 = pgcd est calculée. La fonction retourne le plus grand commun diviseur (pgcd) de value1 et value2, et retourne leurs facteurs de multiplication respectivement dans *factor1 et *factor2. La solution n'est pas unique : une autre solution est obtenue en ajoutant k * value2 à factor1 et en soustrayant k * value1 de factor2. Pour les valeurs dépassant std::numeric_limits<long, long>::max(), le membre suivant peut être utilisé ;
o
BigInt diophantus(BigInt *factor1, BigInt *factor2, BigInt const &value1, BigInt const &value2):
La solution entière de factor1 * value1 + factor2 * value2 = pgcd est calculée. La fonction retourne le plus grand commun diviseur (pgcd) de value1 et value2, et retourne leurs facteurs de multiplication respectivement dans *factor1 et *factor2. La solution n'est pas unique : une autre solution est obtenue en ajoutant k * value2 à factor1 et en soustrayant k * value1 de factor2 ;
o
BigInt fromText(std::string text, int mode = 0):
Ce membre convertit une représentation textuelle d'un nombre en une valeur BigInt. La conversion continue jusqu'à la fin de text ou jusqu'à ce qu'un caractère en dehors d'une plage attendue soit rencontré ;
La plage attendue peut être prédéfinie en spécifiant mode comme ios::dec, ios::oct, ou ios::hex ou (par défaut) la plage attendue est déterminée par fromText lui-même en examinant les caractères dans text.
Par défaut, si text contient des caractères hexadécimaux, alors fromText suppose que le nombre est représenté comme une valeur hexadécimale (par exemple, "abc" est converti en la valeur (décimale) 2748) ; si text commence par 0 et ne contient que des caractères dans la plage de 0 à 7 (inclus), alors fromText suppose que le nombre est représenté comme une valeur octale (par exemple, "01234" est converti en la valeur (décimale) 668). Sinon, une valeur décimale est supposée.
Si le texte ne représente pas une valeur numérique valide (du mode d'extraction donné), une exception FBB::Exception est levée (fromText: text does not represent a BigInt value) ;
o
BigInt rand(size_t size, Msb msb = MSB_IS_ONE, Lsb lsb = ODD):
Ce membre retourne un nombre pseudo-aléatoire cryptographiquement fort de size bits. Le ou les bits les plus significatifs peuvent être contrôlés par msb (par défaut MSB_IS_ONE), le ou les bits les moins significatifs peuvent être contrôlés par lsb (par défaut ODD). Avant d'appeler ce membre en production, le générateur de nombres aléatoires doit avoir été amorcé.
Extrait de la page de manuel RAND_add(3ssl) :
OpenSSL s'assure que l'état du PRNG est unique pour chaque thread. Sur les systèmes qui fournissent /dev/urandom, le périphérique d'aléatoire est utilisé pour amorcer le PRNG de manière transparente. Cependant, sur tous les autres systèmes, l'application est responsable de l'amorçage du PRNG en appelant RAND_add(3ssl), RAND_egd(3ssl), RAND_load_file(3ssl), ou RAND_seed(3ssl) ;
o
BigInt randRange(BigInt const &max):
Ce membre retourne un nombre pseudo-aléatoire cryptographiquement fort dans l'intervalle 0 <= nombre < max. Avant d'appeler ce membre en production, le générateur de nombres aléatoires doit avoir été amorcé (voir aussi rand, décrit ci-dessus) ;
o
BigInt setBigEndian(std::string const &bytes):
Les bytes.length() octets de bytes sont utilisés pour calculer un objet BigInt qui est retourné par cette fonction. Les caractères dans bytes sont interprétés comme une série d'octets en ordre big-endian. Voir aussi la fonction membre bigEndian() ci-dessus. Le BigInt retourné a une valeur positive ;
o
BigInt prime(size_t nBits, BigInt const *mod = 0, BigInt const &rem = 0, PrimeType primeType = ANY):
Ce membre retourne un nombre premier de nBits bits. Si à la fois mod et rem sont non nuls, la condition premier % mod == rem. (Par exemple, utilisez prime % mod == 1 pour convenir à un générateur donné). Le paramètre primeType peut être ANY, (prime - 1) / 2 peut être premier ou non. S'il est SAFE, alors (prime - 1) / 2 sera un nombre premier (dit sûr) ;

Ce membre appelle simplement BigInt::rand ;

o
std::ostream &operator<<(ostream &out, BigInt const &value):
Insère value dans l'ostream fourni. Si le manipulateur hex a été inséré dans le flux avant d'insérer la valeur BigInt, la valeur sera affichée en hexadécimal (sans préfixe 0x) ; si le manipulateur oct a été inséré, la valeur sera représentée en octal (commençant par un 0).
