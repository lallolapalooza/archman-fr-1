bstring(3) Manuel des fonctions de bibliothèque bstring(3)

NOM

bcmp, bcopy, bzero, memccpy, memchr, memcmp, memcpy, memfrob, memmem, memmove, memset — opérations sur chaînes d'octets

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <string.h>
int bcmp(size_t n;
         const void s1[n], const void s2[n], size_t n);
void bcopy(size_t n;
         const void src[n], void dest[n], size_t n);
void bzero(size_t n;
         void s[n], size_t n);
void *memccpy(size_t n;
         void dest[n], const void src[n], int c, size_t n);
void *memchr(size_t n;
         const void s[n], int c, size_t n);
int memcmp(size_t n;
         const void s1[n], const void s2[n], size_t n);
void *memcpy(size_t n;
         void dest[n], const void src[n], size_t n);
void *memfrob(size_t n;
         void s[n], size_t n);
void *memmem(size_t hsize, size_t nsize;
             const void haystack[hsize], size_t hsize,
             const void needle[nsize], size_t nsize);
void *memmove(size_t n;
         void dest[n], const void src[n], size_t n);
void *memset(size_t n;
         void s[n], int c, size_t n);

DESCRIPTION

Les fonctions de chaîne d'octets effectuent des opérations sur des chaînes (tableaux d'octets) qui ne sont pas nécessairement terminées par un caractère nul. Voir les pages man individuelles pour la description de chaque fonction.

NOTES

Les fonctions bcmp() et bcopy() sont obsolètes. Utilisez memcmp() et memmove() à la place.

VOIR AUSSI

bcmp(3), bcopy(3), bzero(3), memccpy(3), memchr(3), memcmp(3), memcpy(3), memfrob(3), memmem(3), memmove(3), memset(3), string(3)
