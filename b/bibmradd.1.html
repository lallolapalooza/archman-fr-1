NOM

bibmradd.pl - ajouter des numéros MR à des articles dans un fichier bib donné

SYNTAXE

bibmradd [-d] [-f] [-e 1|0] [-o sortie] fichier_bib

OPTIONS

-d
Mode de débogage
-e
Si 1 (par défaut), ajouter un mrnumber vide si un numéro MR ne peut être trouvé. Ceci évite des recherches répétées pour les mêmes entrées si vous ajoutez de nouvelles entrées au fichier. Appeler "-e 0" supprime ce comportement.
-f
Forcer la recherche des numéros MR même si l'entrée en possède déjà un.
-o sortie
Fichier de sortie. Si cette option n'est pas utilisée, le nom du fichier de sortie est formé en ajoutant "_mr" au fichier d'entrée.

DESCRIPTION

Le script lit un fichier BibTeX. Il vérifie si les entrées ont des numéros mr. Sinon, il essaie de trouver les numéros sur des sites Internet. Le résultat est un fichier BibTeX avec des champs "mrnumber=..." ajoutés.

Le nom du fichier de sortie est soit défini par l'option -o, soit dérivé en ajoutant le suffixe "_mr" au fichier de sortie.

Voir le script "bibdoiadd" pour plus de détails sur le traitement.
