BUMBLEBEED(1) Commandes utilisateur BUMBLEBEED(1)

NOM

bumblebeed - démon bumblebee

SYNTAXE

bumblebeed [OPTION]...

DESCRIPTION

Démon pour contrôler la carte vidéo discrète nVidia sur les systèmes Optimus.

-D, --daemon
exécute en arrière-plan (daemon). Implique --use-syslog
-x, --xconf FICHIER
fichier xorg.conf à utiliser
--xconfdir RÉPERTOIRE
répertoire xorg.conf.d à utiliser
-g, --group GROUPE
autorise GROUPE à communiquer avec le démon
--driver PILOTE
le pilote à utiliser pour la carte nvidia. Les valeurs valides sont nouveau et nvidia. Cette option affecte également la section du pilote qui sera utilisée dans le fichier de configuration
-m, --module-path CHEMIN
ModulePath à utiliser pour Xorg (utile uniquement pour nvidia)
-k, --driver-module NOM
Nom du module noyau à charger s'il est différent du pilote
--pm-method MÉTHODE
méthode à utiliser pour désactiver la carte vidéo discrète, les valeurs valides sont auto, bbswitch, switcheroo et none. auto sélectionne une méthode judicieuse, bbswitch (module noyau) est disponible pour les pilotes nvidia et nouveau, switcheroo (vga_switcheroo) est généralement pour les pilotes nouveau et radeon, et none désactive complètement la gestion d'alimentation (PM)
-q, --quiet, --silent
supprime tous les messages de journalisation
-v, --verbose
augmente le niveau de verbosité des messages de journalisation. Il peut être spécifié jusqu'à deux fois (ou cinq si --quiet est utilisé)
--debug
affiche tous les messages de journalisation en réglant le niveau de verbosité au maximum
-C, --config FICHIER
récupère les paramètres pour Bumblebee depuis FICHIER
-d, --display VDISPLAY
démarre le serveur X Bumblebee sur VDISPLAY. Ne pas confondre cette option avec la variable d'environnement DISPLAY
-l, --ldpath CHEMIN
les bibliothèques comme nvidia_drv.so sont recherchées dans CHEMIN (utile pour le pilote nvidia)
-s, --socket NOMFICHIER
utilise NOMFICHIER pour la communication avec le démon
-h, --help
affiche cette aide et quitte
--version
affiche les informations de version et quitte
