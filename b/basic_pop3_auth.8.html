NOM

basic_pop3_auth - Authentificateur POP3 pour Squid

SYNTAXE

basic_pop3_auth serveur

DESCRIPTION

basic_pop3_auth authentifie les identifiants d'utilisateur auprès d'un serveur POP3.

OPTIONS

La seule option que cet assistant accepte est le nom du serveur POP3 auquel valider.
