NOM

bpkg-cfg-link - lier une configuration

SYNOPSIS

bpkg cfg-link [options] dir

DESCRIPTION

La commande cfg-link lie la configuration bpkg spécifiée avec la configuration courante. Notez qu'elle établit également un lien retour implicite de la configuration spécifiée vers la configuration courante. Voir bpkg-cfg-create(1) pour des informations de contexte sur les configurations liées. Pour délier des configurations précédemment liées, utilisez bpkg-cfg-unlink(1).

Les configurations liées sont normalement référencées par leur nom lorsqu'elles sont spécifiées sur la ligne de commande bpkg . Sauf si cela est remplacé par l'option --name , le nom original de la configuration est utilisé pour nommer le lien. Si le lien est anonyme, il peut être référencé à l'aide de l'identifiant numérique qui lui est automatiquement attribué lors de l'établissement du lien, ou à l'aide de l'UUID de la configuration.

Si le chemin de configuration spécifié est relatif, il est recalculé relativement au répertoire de configuration courant. De cette façon, lorsque les configurations liées sont déplacées ensemble, les chemins relatifs stockés restent valides. Si le chemin de répertoire spécifié est absolu, il est stocké en tant qu'absolu, sauf si l'option --relative est spécifiée, auquel cas il est également recalculé relativement au répertoire de configuration courant.

OPTIONS CFG-LINK

--name name
Nom alternatif du lien. Si cette option n'est pas spécifiée, le nom de la configuration est utilisé comme nom de lien (voir bpkg-cfg-create(1) pour plus de détails).
--relative
Recalcule le chemin absolu de la configuration liée relativement au répertoire de configuration courant.
--directory|-d dir
Supposer que la configuration se trouve dans dir plutôt que dans le répertoire de travail courant.

FICHIERS D'OPTIONS PAR DÉFAUT

Voir bpkg-default-options-files(1) pour un aperçu des fichiers d'options par défaut. Pour la commande cfg-link , le répertoire de départ de la recherche est le répertoire de configuration. Les fichiers d'options suivants sont recherchés dans chaque répertoire et, s'ils sont trouvés, chargés dans l'ordre listés :

bpkg.options
bpkg-cfg-link.options

Les options de commande cfg-link suivantes ne peuvent pas être spécifiées dans les fichiers d'options par défaut :

--directory|-d
