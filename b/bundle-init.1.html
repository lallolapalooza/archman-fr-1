NOM

bundle-init - Génère un Gemfile dans le répertoire de travail courant

SYNTAXE

bundle init [--gemspec=FICHIER]

DESCRIPTION

Init génère un fichier [Gemfile(5)][Gemfile(5)] par défaut dans le répertoire de travail courant. Lors de l'ajout d'un [Gemfile(5)][Gemfile(5)] à une gemme possédant un fichier gemspec, l'option --gemspec ajoutera automatiquement chaque dépendance listée dans le fichier gemspec au [Gemfile(5)][Gemfile(5)] nouvellement créé.

OPTIONS

--gemspec=GEMSPEC
Utilise le fichier .gemspec spécifié pour créer le [Gemfile(5)][Gemfile(5)].
--gemfile=GEMFILE
Utilise le nom spécifié pour le fichier gemfile au lieu de Gemfile.

FICHIERS

La ligne # frozen_string_literal: true est incluse dans le fichier [Gemfile(5)][Gemfile(5)] par défaut généré. Il s'agit d'un commentaire magique supporté pour la première fois dans Ruby 2.3. La présence de cette ligne entraîne le gel implicite de toutes les littéraux de chaînes de caractères dans le fichier.

VOIR AUSSI

Gemfile(5) https://bundler.io/man/gemfile.5.html
