NOM

B::COW - Assistants B supplémentaires pour vérifier le statut COW

VERSION

version 0.007

SYNOPSIS

#!perl

use strict;
use warnings;

use Test::More;    # utilisé uniquement à des fins d'illustration

use B::COW qw{:all};

if ( can_cow() ) {    # $] >= 5.020
    ok !is_cow(undef);

    my $str = "abcdef";
    ok is_cow($str);
    is cowrefcnt($str), 1;

    my @a;
    push @a, $str for 1 .. 100;

    ok is_cow($str);
    ok is_cow( $a[0] );
    ok is_cow( $a[99] );
    is cowrefcnt($str), 101;
    is cowrefcnt( $a[-1] ), 101;

    delete $a[99];
    is cowrefcnt($str), 100;
    is cowrefcnt( $a[-1] ), 100;

    {
        my %h = ( 'a' .. 'd' );
        foreach my $k ( sort keys %h ) {
            ok is_cow($k);
            is cowrefcnt($k), 0;
        }
    }

}
else {
    my $str = "abcdef";
    is is_cow($str),    undef;
    is cowrefcnt($str), undef;
    is cowrefcnt_max(), undef;
}

done_testing;

DESCRIPTION

B::COW fournit quelques assistants B supplémentaires naïfs pour vérifier le statut COW d'un SvPV.

Introduction à COW ou Copy On Write

Un SvPV COWed partage sa chaîne (le PV) avec d'autres SvPV. C'est une chaîne C (en quelque sorte) en lecture seule, qui serait copiée à l'écriture (COW).

Plusieurs SV peuvent partager le même PV, mais lorsqu'un PV a besoin de le modifier, il effectue une copie et décrémente le compteur COWREFCNT.

Un SV peut alors désactiver le drapeau COW lorsqu'il est le seul à détenir un pointeur vers le PV.

Le COWREFCNT est stocké à la fin du PV, après le "\0".

La valeur est limitée à 255. Lorsque nous atteignons 255, un nouveau PV serait créé.

FONCTIONS

can_cow()

Retourne une valeur booléenne. Vrai si votre version de Perl prend en charge le Copy On Write pour les SvPV.

is_cow( PV )

Retourne une valeur booléenne. Vrai si le SV est un SvPV câblé. (vérifie les drapeaux SV)

cowrefcnt( PV )

Retourne un entier représentant la valeur du compteur de références COW. Si la chaîne n'est pas COW, elle retournera undef.

cowrefcnt_max()

Retournera le SV_COW_REFCNT_MAX de votre Perl. (si le COW est pris en charge, cela devrait être 255 sauf personnalisation).
