NOM

bdep-help - afficher l'aide pour une commande ou un sujet d'aide

SYNTAXE

bdep help [commande | sujet]

DESCRIPTION

Affiche l'aide détaillée pour la commande ou le sujet d'aide, ou un résumé des commandes et sujets disponibles si rien n'a été spécifié.

OPTIONS COMMUNES

Les options communes sont résumées ci-dessous, avec une description plus détaillée disponible dans bdep-common-options(1).

-v
Imprime les commandes sous-jacentes essentielles exécutées.
-V
Imprime toutes les commandes sous-jacentes exécutées.
--quiet|-q
Exécuter silencieusement, en imprimant uniquement les messages d'erreur.
--verbose niveau
Définit la verbosité des diagnostics à niveau entre 0 et 6.
--stdout-format format
Format de représentation à utiliser pour l'impression sur stdout.
--jobs|-j num
Nombre de tâches à effectuer en parallèle.
--progress
Affiche les indicateurs de progression pour les opérations de longue durée, telles que les transferts réseau, la compilation, etc.
--no-progress
Supprime les indicateurs de progression pour les opérations de longue durée, telles que les transferts réseau, la compilation, etc.
--diag-color
Utilise la couleur dans les diagnostics.
--no-diag-color
N'utilise pas la couleur dans les diagnostics.
--bpkg chemin
Le programme de gestion de paquets à utiliser pour la gestion de la configuration de build.
--bpkg-option opt
Option supplémentaire à passer au programme de gestion de paquets.
--build chemin
Le programme de build à utiliser pour compiler les paquets.
--build-option opt
Option supplémentaire à passer au programme de build.
--curl chemin
Le programme curl à utiliser pour les opérations réseau.
--curl-option opt
Option supplémentaire à passer au programme curl.
--pager chemin
Le programme paginator à utiliser pour afficher du texte long.
--pager-option opt
Option supplémentaire à passer au programme paginator.
--options-file fichier
Lire les options supplémentaires à partir du fichier.
--default-options rép
Le répertoire à partir duquel charger les fichiers d'options par défaut supplémentaires.
--no-default-options
Ne pas charger les fichiers d'options par défaut.

FICHIERS OPTIONS PAR DÉFAUT

Voir bdep-default-options-files(1) pour un aperçu des fichiers d'options par défaut. Pour la commande help, les fichiers d'options suivants sont recherchés uniquement dans les répertoires prédéfinis (accueil, système, etc.) et, s'ils sont trouvés, sont chargés dans l'ordre indiqué :

bdep.options
bdep-help.options

BOGUES

Envoyez les rapports de bugs à la liste de diffusion users@build2.org.
