binops(3bobcat) Opérateurs binaires binops(3bobcat)

NOM

binops - Fonctions template pour les opérateurs binaires de type classe

SYNTAXE

#include <utility>
#include <bobcat/typetrait>
#include <bobcat/binops>

DESCRIPTION

Les classes peuvent surcharger les opérateurs binaires. Une classe nommée Class peut surcharger ces opérateurs binaires pour convenir à ses propres besoins, permettant, par exemple, d'additionner deux objets de type Class après avoir surchargé operator+. Les opérateurs pour les opérateurs binaires *, /, %, +, -, <<, >>, &, |, et ^ (dans cette page man, ils sont indiqués génériquement comme l'opérateur '@') peuvent être surchargés en définissant la fonction operator@.

Si une classe supporte la construction par copie et si elle offre des opérateurs d'assignation binaires (c'est-à-dire, si elle offre des membres de la forme operator@=), alors les opérateurs binaires correspondants peuvent tous être implémentés de manière identique. Le move-aware Class &operator@(Class &&lhs, Class const &rhs) est facilement implémenté en termes de operator@= (notez que la classe elle-même n'a pas à être `move-aware’ pour définir cette fonction). L'opérateur binaire move-aware nécessite une implémentation d'une seule ligne, et comme son implémentation ne change jamais, il peut être défini en toute sécurité inline :

Class operator@(Class &&lhs, Class const &rhs)
{
    return std::move(std::move(lhs) @= rhs);
}
L'opérateur binaire traditionnel peut être implémenté en utilisant sa forme standard : 
Class operator@(Class const &lhs, Class const &rhs)
{
    Class tmp(lhs);
    tmp @= rhs;
    return tmp;
}
L'implémentation dans bobcat/binops est légèrement plus complexe car elle permet des promotions à partir de lhs ou rhs.

Étant donné que les opérateurs binaires peuvent tous être implémentés de manière similaire, leurs définitions sont parfaitement adaptées aux templates : Une classe offrant un operator@= particulier offre alors automatiquement également les opérateurs binaires correspondants après l'inclusion de bobcat/binops. Étant donné que les templates de fonctions binaires ne sont instanciés que lorsqu'ils sont utilisés, leurs définitions peuvent être traitées par le compilateur même si une classe implémente seulement un sous-ensemble des opérateurs d'assignation binaires disponibles.

ESPACE DE NOMMAGE

Les templates de fonctions d'opérateurs binaires dans bobcat/binops ne sont pas implémentés dans un espace de nommage particulier. Cela permet aux sources d'inclure bobcat/binops dans plusieurs espaces de nommage.

Si bobcat/binops doit être utilisé dans plusieurs espaces de nommage, alors la protection d'inclusion (utilisant l'identifiant INCLUDED_BOBCAT_BINOPS_) doit être supprimée entre les inclusions de bobcat/binops dans différents espaces de nommage.

Par exemple, pour rendre les templates de fonctions d'opérateurs binaires disponibles dans un fichier source utilisant le namespace FBB et dans un fichier source utilisant l'espace de nommage par défaut, le schéma suivant peut être utilisé :

#include <utility>              // s'assurer que std::move est disponible
#include <bobcat/typetrait>     // requis par binops
namespace MON_ESPACE_DE_NOMMAGE
{
    #include <bobcat/binops>    // opérateurs binaires disponibles dans MON_ESPACE_DE_NOMMAGE
}
#undef INCLUDED_BOBCAT_BINOPS_  // supprimer la garde d'inclusion
#include <bobcat/binops>        // lire à nouveau binops afin que les opérateurs binaires
                                // puissent également être utilisés dans
                                // l'espace de nommage par défaut

OPERATEURS SURCHARGES

Les templates de fonctions dans bobcat/binops implémentent tous les opérateurs binaires arithmétiques, à la fois move-aware et les opérateurs binaires traditionnels, attendant des références lvalues constantes. Ils peuvent être utilisés si les opérateurs d'assignation binaires correspondants ont été implémentés dans les classes pour lesquelles les templates doivent être instanciés. Les opérateurs suivants sont disponibles :

Opérateurs move-aware, utilisant des objets temporaires pour leurs opérandes de gauche :

EXEMPLE

#include <iostream>
#include <utility>
#include "../../typetrait/typetrait"
#include "../binops"
class Demo
{
    friend std::ostream &operator<<(std::ostream &out, Demo const &demo);
    int d_value;
    public:
        Demo(int value = 0)
        :
            d_value(value)
        {}
        Demo(Demo const &other)
        :
            d_value(other.d_value)
        {
            std::cout << "Appel constructeur de copie Demo\n";
        }
        Demo &operator+=(Demo const &rhs)
        {
            d_value += rhs.d_value;
            return *this;
        }
};
std::ostream &operator<<(std::ostream &out, Demo const &demo)
{
    return out << demo.d_value;
}
using namespace std;
int main()
{
    Demo four(4);
    Demo five(5);
    cout << four + five << ’\n’ <<
            four + 5 << ’\n’ <<
            4  + five << ’\n’;
}
