bupstash-list-contents(1)

Paquet: bupstash

Licences: MIT

() ()

SYNOPSIS

Liste le contenu des instantanés.

bupstash list-contents [OPTIONS] QUERY...

DESCRIPTION

bupstash list-contents liste le contenu de l'élément correspondant à la requête donnée.

Les éléments créés en utilisant bupstash put sur un répertoire auront un index associé, les autres éléments ne sont pas listables.

FORMATS DE SORTIE

Humain

Lorsque --format est réglé sur human, bupstash list-contents affiche des lignes alignées composées de :

PERMS SIZE AAAA/MM/JJ HH:MM:SS CHEMIN...

La date incluse est l'heure de la dernière modification d'un fichier donné telle que rapportée par le système d'exploitation au moment de l'instantané.

Préférez l'utilisation de l'un des formats lisibles par machine et versionnés lors de la rédaction de scripts.

JSONl1

Lorsque --format est réglé sur jsonl1, bupstash list-contents affiche un objet json par ligne.

Chaque ligne correspond au schéma json suivant :

{ "path": string | [ octets... ], "mode": nombre, "size": nombre, "uid": nombre, "gid": nombre, "mtime": nombre, "mtime_nsec": nombre, "ctime": nombre, "ctime_nsec": nombre, "norm_dev": nombre, "ino": nombre, "nlink": nombre, "link_target": string | null, "dev_major": nombre | null, "dev_minor": nombre | null, "xattrs": {string : string | [octets...] ...} | null, "sparse": booléen, "data_hash": "$KIND[:$HEXBYTE]" | null }

LANGAGE DES REQUÊTES

Pour une documentation complète sur le langage des requêtes, voir bupstash-query-language(7).

MISE EN CACHE DES REQUÊTES

La commande list-contents utilise les mêmes mécanismes de mise en cache des requêtes que bupstash-list(1), consultez cette page pour plus d'informations sur le cache des requêtes.

OPTIONS

-r, --repository REPO
Le dépôt auquel se connecter, , peut être de la forme ssh://$SERVEUR/$CHEMIN pour les dépôts distants si l'accès ssh est configuré. Si non spécifié, est défini sur BUPSTASH_REPOSITORY.
-k, --key KEY
Clé utilisée pour déchiffrer les données et les métadonnées. Si non définie, par défaut à BUPSTASH_KEY.
--format FORMAT
Définit le format de sortie sur l'un des suivants : ´human´, ´jsonl´.
--query-cache PATH
Chemin vers le fichier de cache des requêtes, par défaut l'un des suivants, dans l'ordre, à condition que les variables d'environnement appropriées soient définies : $BUPSTASH_QUERY_CACHE, $XDG_CACHE_HOME/.cache/bupstash/bupstash.qcache ou $HOME/.cache/bupstash/bupstash.qcache.
--pick PATH
Liste un sous-répertoire de la requête.
--utc-timestamps
Affiche et recherche par rapport aux horodatages en heure UTC au lieu de l'heure locale.
-q, --quiet
Soyez silencieux, implique --no-progress.

ENVIRONNEMENT

BUPSTASH_REPOSITORY
Le dépôt auquel se connecter. Peut être de la forme ssh://$SERVEUR/$CHEMIN pour les dépôts distants si l'accès ssh est configuré.
BUPSTASH_REPOSITORY_COMMAND
Une commande à exécuter pour se connecter à une instance de bupstash-serve(1). Ceci permet des connexions plus complexes au dépôt pour des cas d'utilisation moins courants.
BUPSTASH_KEY
Chemin vers une clé primaire qui sera utilisée pour déchiffrer les données et les métadonnées.
BUPSTASH_KEY_COMMAND
Une commande à exécuter qui doit imprimer les données de la clé, peut être utilisée à la place de BUPSTASH_KEY pour récupérer la clé depuis des emplacements arbitraires tels que le réseau ou d'autres stockages secrets.
BUPSTASH_QUERY_CACHE
Chemin vers le fichier de cache des requêtes à utiliser.

EXEMPLES

Obtenir un élément avec un ID spécifique du dépôt

$ bupstash list-contents id="14eb*" drwxr-xr-x 0 2020/10/30 13:32:04 . -rw-r--r-- 1967 2020/10/30 13:32:04 data.txt
