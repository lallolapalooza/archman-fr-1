NOM

buildah-source - Créer, pousser, tirer et gérer des images source et les artefacts source associés

SYNTAXE

buildah source sous-commande

DESCRIPTION

Crée, pousse, tire et gère des images source et les artefacts source associés. Une image source contient tous les artefacts source avec lesquels une image OCI ordinaire a été construite. Ces artefacts peuvent être de tout type, tels que des RPM source, un arbre source entier ou des fichiers texte.

Notez que la commande buildah-source et toutes ses sous-commandes sont expérimentales et peuvent être sujettes à des changements futurs.

COMMANDES

Commande Page de manuel Description
add buildah-source-add(1) Ajoute un artefact source à une image source.
create buildah-source-create(1) Crée et initialise une image source.
pull buildah-source-pull(1) Tire une image source d'un registre vers un chemin spécifié.
push buildah-source-push(1) Pousse une image source d'un chemin spécifié vers un registre.
