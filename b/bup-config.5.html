NOM

bup-config - options de configuration de bup

DESCRIPTION

Les options suivantes peuvent être définies dans la configuration git appropriée (git-config(1)).

OPTIONS

pack.packSizeLimit
Respecté lors de l'écriture de fichiers pack (par exemple, via bup save ...). Actuellement lu depuis le dépôt auquel les fichiers pack sont écrits, à l'exception de bup on REMOTE... qui lit incorrectement la valeur depuis le dépôt REMOTE.

VOIR AUSSI

git-config(1)

BUP

Fait partie de la suite bup(1).
