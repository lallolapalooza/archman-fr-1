NOM

bup-random - génère un flux de sortie aléatoire

SYNTAXE

bup random [-S graines] [-fv] <nombre-octets>

DESCRIPTION

bup random produit un flux d'octets pseudo-aléatoires vers la sortie standard. Note : les octets ne sont *pas* générés à l'aide d'un algorithme cryptographique et ne devraient jamais être utilisés pour la sécurité.

Notez que le flux d'octets aléatoires sera identique chaque fois que bup random est exécuté, à moins que vous ne fournissiez une valeur de graines différente. Ceci est intentionnel : le but de ce programme est de pouvoir effectuer des tests reproductibles sur de grandes quantités de données, nous voulons donc des données identiques à chaque fois.

bup random génère environ 240 mégaoctets par seconde sur un système de test moderne (Intel Core2), ce qui est plus rapide que ce que vous pourriez obtenir en lisant des données à partir de la plupart des disques. Par conséquent, cela peut être utile lors de l'exécution de micro-benchmarks.

OPTIONS

<nombre-octets>
le nombre d'octets de données à générer. Peut être utilisé avec les suffixes k, M, ou G pour indiquer des kilooctets, des mégaoctets ou des gigaoctets, respectivement.
-S, --graines=graines
utilise la valeur donnée pour initialiser le générateur de nombres pseudo-aléatoires. Le flux de sortie généré sera identique pour chaque flux initialisé avec la même valeur. La graine par défaut est 1. Une valeur de graine de 0 est équivalente à 1.
-f, --forcer
génère une sortie même si la sortie standard est un tty. (Générer des données aléatoires vers un tty est généralement déconseillé, mais vous pouvez le faire si vous le souhaitez vraiment.)
-v, --verbeux
affiche un message de progression indiquant le nombre d'octets qui ont été envoyés jusqu'à présent.

EXEMPLES

$ bup random 1k | sha1sum
2108c55d0a2687c8dacf9192677c58437a55db71  -
$ bup random -S1 1k | sha1sum
2108c55d0a2687c8dacf9192677c58437a55db71  -
$ bup random -S2 1k | sha1sum
f71acb90e135d98dad7efc136e8d2cc30573e71a  -
$ time bup random 1G >/dev/null
Random: 1024 Mbytes, done.
real   0m4.261s
user   0m4.048s
sys    0m0.172s
$ bup random 1G | bup split -t --bench
Random: 1024 Mbytes, done.
bup: 1048576.00kbytes in 18.59 secs = 56417.78 kbytes/sec
1092599b9c7b2909652ef1e6edac0796bfbfc573
