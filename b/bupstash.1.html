Paquet: bupstash

SYNOPIS

Sauvegardes chiffrées et dédupliquées avec Bupstash.

Exécutez l'une des commandes bupstash suivantes.

bupstash init ...
bupstash new-key ...
bupstash new-sub-key ...
bupstash put ...
bupstash list ...
bupstash list-contents ...
bupstash diff ...
bupstash get ...
bupstash restore ...
bupstash rm ...
bupstash recover-removed ...
bupstash gc ...
bupstash sync ...
bupstash exec-with-locks ...
bupstash serve ...
bupstash help ...
bupstash version ...

DESCRIPTION

bupstash est un outil pour stocker (et récupérer) des fichiers et des données dans un bupstash-repostory(7) chiffré.

Quelques caractéristiques notables de bupstash incluent :

○
Déduplication automatique des données stockées.
○
Chiffrement côté client des données.
○
Téléversements de fichiers incrémentiels.
○
Un langage de requête basé sur des étiquettes.
○
Chiffrement optionnel basé sur les rôles et séparation des clés de déchiffrement.
○
Dépôts distants via ssh ssh.
○
Contrôles optionnels du dépôt par clé ssh.
○
Une approche multicouche de la sécurité.

L'outil bupstash lui-même est divisé en sous-commandes qui ont chacun leur propre documentation.

SOUS-COMMANDES

bupstash-init(1)
Initialiser un dépôt bupstash.
bupstash-new-key(1)
Créer une nouvelle clé primaire pour créer/lire les éléments du dépôt.
bupstash-new-sub-key(1)
Dériver une sous-clé pour un sous-ensemble d'opérations.
bupstash-put(1)
Ajouter des données à un dépôt bupstash.
bupstash-get(1)
Récupérer des données du dépôt bupstash correspondant à une requête.
bupstash-restore(1)
Restaurer un instantané dans un répertoire local.
bupstash-list(1)
Lister les éléments du dépôt correspondant à une requête donnée.
bupstash-list-contents(1)
Lister le contenu d'un instantané de répertoire.
bupstash-diff(1)
Comparer le contenu des instantanés.
bupstash-rm(1)
Supprimer les éléments du dépôt correspondant à une requête donnée.
bupstash-recover-removed(1)
Récupérer les éléments supprimés en attente de nettoyage.
bupstash-gc(1)
Récupérer de l'espace disque dans un dépôt.
bupstash-sync(1)
Synchroniser les éléments entre dépôts.
bupstash-exec-with-locks(1)
Exécuter une commande avec des verrous exclusifs sur le dépôt.
bupstash-serve(1)
Servir un dépôt sur stdin/stdout en utilisant le protocole bupstash-protocol(7).

EXEMPLES

Initialiser un dépôt et créer des clés

$ bupstash init -r ssh://$SERVEUR/home/moi/sauvegardes $ bupstash new-key -o sauvegardes.key

Dire à bupstash d'utiliser notre dépôt et notre clé par défaut

$ export BUPSTASH_REPOSITORY=ssh://$SERVEUR/home/moi/sauvegardes $ export BUPSTASH_KEY=sauvegardes.key

Instantanés de répertoires

``` $ bupstash put ./some-data ebb66f3baa5d432e9f9a28934888a23d

$ bupstash list-contents id=ebb66f3baa5d432e9f9a28934888a23d drwxr-xr-x 0 2020/11/05 10:42:48 . -rw-r--r-- 177B 2020/07/12 17:13:42 data.txt ```

Lister les éléments correspondant à une requête

$ bupstash list hostname=$(hostname) id="bcb8684e6bf5cb453e77486decf61685" name="some-file.txt" hostname="my-server" timestamp="2020-07-27 11:26:16" ...

Téléversements incrémentiels

``` $ bupstash put --send-log /var/backup.sendlog ./some-data ebb66f3baa5d432e9f9a28934888a23d$ bupstash put --send-log /var/backup.sendlog ./some-data ebb66f3baa5d432e9f9a28934888a23d ```

Capturer et sauvegarder la sortie d'une commande

# Vérifie les erreurs avant de sauvegarder un nouvel élément. $ bupstash put --exec name=database.sql pgdump mydatabase 14ebd2073b258b1f55c5bbc889c49db4

Récupérer un élément correspondant à une requête

$ bupstash get id=bcb8684e6bf5cb453e77486decf61685 some data.

Restaurer un répertoire à un instantané précédent

$ bupstash restore --to ./dir name=dir.tar

Supprimer les éléments correspondant à une requête.

$ bupstash rm name=some-data.txt

Effacer un dépôt

$ bupstash rm --allow-many id=*

Récupérer de l'espace disque

$ bupstash gc

Clés de déchiffrement hors ligne

``` # Créer une clé, une clé d'écriture uniquement, et une clé métadonnées (liste/suppression uniquement). key. $ bupstash new-key -o backups.key $ bupstash new-sub-key --put -k backups.key -o backups-put.key $ bupstash new-sub-key --list -k backups.key -o backups-metadata.key

... Copier backups.key dans un stockage hors ligne sécurisé ...$ shred backups.key

$ bupstash put -k backups-put.key ./data 14ebd2073b258b1f55c5bbc889c49db4

... Lorsque vous devez lister ou supprimer des sauvegardes, vous pouvez utiliser la clé de métadonnées ...

$ bupstash list -k backups-metadata.key ... $ bupstash rm -k backups-metadata.key

... Après une urgence, récupérez la clé de déchiffrement du stockage hors ligne ...$ bupstash get -k backups.key id=14ebd2073b258b1f55c5bbc889c49db4 | tar -C ./restore -xf - ```
