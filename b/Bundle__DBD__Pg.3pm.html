NOM

Bundle::DBD::Pg - Un ensemble pour installer tous les modules liés à DBD::Pg

SYNOPSIS

"perl -MCPAN -e 'install Bundle::DBD::Pg'"

CONTENU

DBI

DBD::Pg

DESCRIPTION

Cet ensemble inclut tous les modules nécessaires pour DBD::Pg (l'interface Perl pour le système de base de données Postgres). N'hésitez pas à demander de l'aide ou à signaler tout problème à dbd-pg@perl.org.
