NOM

buf-build - Compiler les fichiers Protobuf en une image Buf

SYNOPIS

buf build [options]

DESCRIPTION

Le premier argument est la source ou le module à compiler ou l'image à convertir, qui doit être l'un des formats [binpb,dir,git,json,mod,protofile,tar,txtpb,yaml,zip]. Ceci vaut par défaut "." si aucun argument n'est spécifié.

OPTIONS

--as-file-descriptor-set[=false] Exporter en tant que google.protobuf.FileDescriptorSet au lieu d'une image. Notez que les images sont compatibles en fil d'exécution avec les FileDescriptorSets, mais cette option supprime les métadonnées supplémentaires ajoutées pour l'utilisation de Buf.

--config="" Le fichier buf.yaml ou les données à utiliser pour la configuration.

--disable-symlinks[=false] Ne pas suivre les liens symboliques lors de la lecture des sources ou de la configuration depuis le système de fichiers local. Par défaut, les liens symboliques sont suivis dans cette CLI, mais jamais suivis sur le registre de schéma Buf.

--error-format="text" Le format des erreurs de compilation imprimées sur stderr. Doit être l'un des formats [text,json,msvs,junit,github-actions,gitlab-code-quality].

--exclude-imports[=false] Exclure les imports.

--exclude-path=[] Exclure des fichiers ou des répertoires spécifiques, par exemple "proto/a/a.proto", "proto/a". Si spécifié plusieurs fois, l'union est prise.

--exclude-source-info[=false] Exclure les informations sources.

--exclude-source-retention-options[=false] Exclure les options dont la rétention est source.

-h, --help[=false] Aide pour build.

-o, --output="/dev/null" L'emplacement de sortie pour l'image compilée. Doit être l'un des formats [binpb,json,txtpb,yaml].

--path=[] Limiter à des fichiers ou des répertoires spécifiques, par exemple "proto/a/a.proto", "proto/a". Si spécifié plusieurs fois, l'union est prise.

--type=[] Les types (paquet, message, enum, extension, service, méthode) qui doivent être inclus dans cette image. Lorsque spécifié, l'image résultante n'inclura que les descripteurs pour décrire les types demandés.

OPTIONS HÉRITÉES DES COMMANDES PARENTES

--debug[=false] Activer la journalisation de débogage.

--log-format="color" Le format de journalisation [text,color,json].

--timeout=0s La durée avant expiration, la régler à 0 signifie aucune expiration.
