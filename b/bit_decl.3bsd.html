NOM

bit_alloc, bit_clear, bit_decl, bit_ffs, bit_nclear, bit_nset, bit_set, bitstr_size, bit_test — macros de manipulation de chaînes de bits

BIBLIOTHÈQUE

bibliothèque «libbsd»

SYNOPSIS

#include <bitstring.h> (Voir libbsd(7) pour l'utilisation de l'inclusion.)
bitstr_t *
bit_alloc(int nbits);

void
bit_decl(bitstr_t *name, int nbits);

void
bit_clear(bitstr_t *name, int bit);

void
bit_ffc(bitstr_t *name, int nbits, int *value);

void
bit_ffs(bitstr_t *name, int nbits, int *value);

void
bit_nclear(bitstr_t *name, int start, int stop);

void
bit_nset(bitstr_t *name, int start, int stop);

void
bit_set(bitstr_t *name, int bit);

int
bitstr_size(int nbits);

int
bit_test(bitstr_t *name, int bit);

DESCRIPTION

Ces macros opèrent sur des chaînes de bits.

La macro bit_alloc() renvoie un pointeur de type « bitstr_t * » vers un espace suffisant pour stocker nbits bits, ou NULL si aucun espace n'est disponible.

La macro bit_decl() alloue un espace suffisant pour stocker nbits bits sur la pile.

La macro bitstr_size() renvoie le nombre d'éléments de type bitstr_t nécessaires pour stocker nbits bits. Ceci est utile pour copier des chaînes de bits.

Les macros bit_clear() et bit_set() effacent ou définissent le bit numéroté (en commençant à zéro) bit, dans la chaîne de bits name.

Les macros bit_nset() et bit_nclear() définissent ou effacent les bits numérotés (en commençant à zéro) de start à stop inclus dans la chaîne de bits name.

La macro bit_test() renvoie une valeur non nulle si le bit numéroté (en commençant à zéro) bit de la chaîne de bits name est défini, et zéro sinon.

La macro bit_ffs() stocke dans l'emplacement référencé par value le numéro (en commençant à zéro) du premier bit défini dans le tableau de nbits bits référencé par name. Si aucun bit n'est défini, l'emplacement référencé par value est mis à -1.

La macro bit_ffc() stocke dans l'emplacement référencé par value le numéro (en commençant à zéro) du premier bit non défini dans le tableau de nbits bits référencé par name. Si tous les bits sont définis, l'emplacement référencé par value est mis à -1.

Les arguments de ces macros sont évalués une seule fois et peuvent en toute sécurité avoir des effets secondaires.

EXEMPLES

#include <limits.h>
#include <bsd/bitstring.h>

...
#define	LPR_BUSY_BIT		0
#define	LPR_FORMAT_BIT		1
#define	LPR_DOWNLOAD_BIT	2
...
#define	LPR_AVAILABLE_BIT	9
#define	LPR_MAX_BITS		10

make_lpr_available()
{
	bitstr_t bit_decl(bitlist, LPR_MAX_BITS);
	...
	bit_nclear(bitlist, 0, LPR_MAX_BITS - 1);
	...
	if (!bit_test(bitlist, LPR_BUSY_BIT)) {
		bit_clear(bitlist, LPR_FORMAT_BIT);
		bit_clear(bitlist, LPR_DOWNLOAD_BIT);
		bit_set(bitlist, LPR_AVAILABLE_BIT);
	}
}
