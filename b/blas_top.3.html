Description détaillée

Les BLAS sont définis par trois articles : Basic linear algebra subprograms for {FORTRAN} usage, Lawson et al, 1979. An extended set of {FORTRAN} basic linear algebra subprograms, Dongarra et al, 1988. A set of level 3 basic linear algebra subprograms, Dongarra et al, 1990. Certaines routines de type BLAS (par exemple, csymv, crot, csum1, icmax1) existent dans LAPACK plutôt que dans les BLAS classiques. Elles ont été étendues par les Extra Precision BLAS (XBLAS, non documenté ici) https://www.netlib.org/xblas/
