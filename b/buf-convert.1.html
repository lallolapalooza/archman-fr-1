NOM

buf-convert - Convertir un message entre binaire, texte ou JSON

SYNTAXE

buf convert [flags]

DESCRIPTION

Utilisez un proto d'entrée pour interpréter un message proto/json et le convertir dans un format différent.

Exemples :

$ buf convert <input> --type=<type> --from=<payload> --to=<output>

peut être un fichier .proto local, la sortie binaire de "buf build", un module bsr ou un module buf local :

$ buf convert example.proto --type=Foo.proto --from=payload.json --to=output.binpb

Tous les , "--from" et "to" acceptent des options de formatage :

$ buf convert example.proto#format=binpb --type=buf.Foo --from=payload#format=json --to=out#format=json

Et acceptent tous deux la redirection stdin :

$ buf convert <(buf build -o -)#format=binpb --type=foo.Bar --from=<(echo "{\"one\":\"55\"}")#format=json

Redirection depuis stdin vers --from :

$ echo "{\"one\":\"55\"}" | buf convert buf.proto --type buf.Foo --from -#format=json

Redirection depuis stdin vers :

$ buf build -o - | buf convert -#format=binpb --type buf.Foo --from=payload.json

Utiliser un module sur le bsr :

$ buf convert <buf.build/owner/repository> --type buf.Foo --from=payload.json

OPTIONS

--disable-symlinks[=false] Ne pas suivre les liens symboliques lors de la lecture des sources ou de la configuration à partir du système de fichiers local. Par défaut, les liens symboliques sont suivis dans cette CLI, mais jamais suivis sur le Buf Schema Registry.

--error-format="text" Le format des erreurs de build affichées sur stderr. Doit être l'un des [text,json,msvs,junit,github-actions,gitlab-code-quality]

--from="-" L'emplacement de la charge utile à convertir. Les formats pris en charge sont [binpb,json,txtpb,yaml]

-h, --help[=false] Aide pour convert

--to="-" L'emplacement de sortie de la conversion. Les formats pris en charge sont [binpb,json,txtpb,yaml]

--type="" Le nom complet du type du message dans l'entrée (par exemple, acme.weather.v1.Units)

--validate[=false] Valider le message spécifié avec --from en appliquant les règles protovalidate. Voir https://github.com/bufbuild/protovalidate pour plus de détails.

OPTIONS HÉRITÉES DES COMMANDES PARENT

--debug[=false] Activer la journalisation de débogage

--log-format="color" Le format du journal [text,color,json]

--timeout=0s La durée avant expiration, la régler sur 0 signifie pas d'expiration
