bupstash-gc(1)

Paquet: bupstash

Licences: MIT

() ()

SYNOPIS

Exécute le garbage collector sur un dépôt, supprimant les données non référencées et libérant de l'espace disque.

bupstash gc [OPTIONS]

DESCRIPTION

bupstash gc parcourt le contenu du dépôt en tentant de trouver les blocs de données inaccessibles et de les supprimer, récupérant ainsi potentiellement de l'espace disque.

Il est sûr d'exécuter bupstash gc à tout moment, mais certaines opérations (comme bupstash-put(1)) peuvent être temporairement retardées.

Le garbage collector ne repose que sur des métadonnées non chiffrées, il n'a donc pas besoin d'accéder aux clés de déchiffrement pour fonctionner.

OPTIONS

-r, --repository REPO
Le dépôt auquel se connecter et sur lequel opérer. Peut être de la forme ssh://$SERVEUR/$CHEMIN pour les dépôts distants si l'accès ssh est configuré. S'il n'est pas spécifié, il est défini par BUPSTASH_REPOSITORY.
--no-progress
Supprime les indicateurs de progression (Les indicateurs de progression sont également supprimés lorsque stderr n'est pas un terminal interactif).
-q, --quiet
Soyez silencieux, implique --no-progress.

ENVIRONNEMENT

BUPSTASH_REPOSITORY
Le dépôt auquel se connecter. Peut être de la forme ssh://$SERVEUR/$CHEMIN pour les dépôts distants si l'accès ssh est configuré.
BUPSTASH_REPOSITORY_COMMAND
Une commande à exécuter pour se connecter à une instance de bupstash-serve(1). Cela permet des connexions plus complexes au dépôt pour des cas d'utilisation moins courants.

VOIR AUSSI

bupstash(1), bupstash-repository(7)
