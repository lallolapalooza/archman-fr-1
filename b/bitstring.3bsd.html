NOM

bit_alloc, bit_clear, bit_decl, bit_ffs, bit_nclear, bit_nset, bit_set, bitstr_size, bit_test — macros de manipulation de chaînes de bits

BIBLIOTHÉQUE

bibliothèque « libbsd »

SYNTAXE

#include <bitstring.h> (Voir libbsd(7) pour l'utilisation des inclusions.)
bitstr_t *
bit_alloc(int nbits);

void
bit_decl(bitstr_t *nom, int nbits);

void
bit_clear(bitstr_t *nom, int bit);

void
bit_ffc(bitstr_t *nom, int nbits, int *valeur);

void
bit_ffs(bitstr_t *nom, int nbits, int *valeur);

void
bit_nclear(bitstr_t *nom, int début, int fin);

void
bit_nset(bitstr_t *nom, int début, int fin);

void
bit_set(bitstr_t *nom, int bit);

int
bitstr_size(int nbits);

int
bit_test(bitstr_t *nom, int bit);

DESCRIPTION

Ces macros opèrent sur des chaînes de bits.

La macro bit_alloc() retourne un pointeur de type « bitstr_t * » vers un espace suffisant pour stocker nbits bits, ou NULL si aucun espace n'est disponible.

La macro bit_decl() alloue un espace suffisant pour stocker nbits bits sur la pile.

La macro bitstr_size() retourne le nombre d'éléments de type bitstr_t nécessaires pour stocker nbits bits. Ceci est utile pour copier des chaînes de bits.

Les macros bit_clear() et bit_set() effacent ou positionnent le bit numéroté à partir de zéro bit, dans la chaîne de bits nom.

Les macros bit_nset() et bit_nclear() positionnent ou effacent les bits numérotés à partir de zéro de début à fin dans la chaîne de bits nom.

La macro bit_test() s'évalue à non-zéro si le bit numéroté à partir de zéro bit de la chaîne de bits nom est positionné, et à zéro sinon.

La macro bit_ffs() stocke dans l'emplacement référencé par valeur le numéro (commençant à zéro) du premier bit positionné dans le tableau de nbits bits référencé par nom. Si aucun bit n'est positionné, l'emplacement référencé par valeur est mis à -1.

La macro bit_ffc() stocke dans l'emplacement référencé par valeur le numéro (commençant à zéro) du premier bit non positionné dans le tableau de nbits bits référencé par nom. Si tous les bits sont positionnés, l'emplacement référencé par valeur est mis à -1.

Les arguments de ces macros sont évalués une seule fois et peuvent en toute sécurité avoir des effets de bord.

EXEMPLES

#include <limits.h>
#include <bsd/bitstring.h>

...
#define	LPR_BUSY_BIT		0
#define	LPR_FORMAT_BIT		1
#define	LPR_DOWNLOAD_BIT	2
...
#define	LPR_AVAILABLE_BIT	9
#define	LPR_MAX_BITS		10

make_lpr_available()
{
	bitstr_t bitlist[bitstr_size(LPR_MAX_BITS)];
	...
	bit_nclear(bitlist, 0, LPR_MAX_BITS - 1);
	...
	if (!bit_test(bitlist, LPR_BUSY_BIT)) {
		bit_clear(bitlist, LPR_FORMAT_BIT);
		bit_clear(bitlist, LPR_DOWNLOAD_BIT);
		bit_set(bitlist, LPR_AVAILABLE_BIT);
	}
}
