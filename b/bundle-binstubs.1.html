BUNDLE-BINSTUBS(1) Manuel des commandes générales BUNDLE-BINSTUBS(1)

NOM

bundle-binstubs - Installer les binstubs des gems listées

SYNTAXE

bundle binstubs NOM_DE_LA_GEM [--force] [--path CHEMIN] [--standalone] [--all-platforms]

DESCRIPTION

Les binstubs sont des scripts qui encapsulent des exécutables. Bundler crée un petit fichier Ruby (un binstub) qui charge Bundler, exécute la commande et la place dans bin/. Les binstubs sont un raccourci — ou une alternative — à l'utilisation constante de bundle exec. Cela vous donne un fichier qui peut être exécuté directement, et qui exécutera toujours la version correcte de la gem utilisée par l'application.

Par exemple, si vous exécutez bundle binstubs rspec-core, Bundler créera le fichier bin/rspec. Ce fichier contiendra suffisamment de code pour charger Bundler, lui dire de charger les gems incluses, puis exécuter rspec.

Cette commande génère les binstubs pour les exécutables dans NOM_DE_LA_GEM. Les binstubs sont placés dans bin, ou dans le répertoire spécifié par --path s'il a été défini. Appeler binstubs avec [GEM [GEM]] créera des binstubs pour toutes les gems données.

OPTIONS

--force
Écrase les binstubs existants s'ils existent.
--path[=CHEMIN]
L'emplacement où installer les binstubs spécifiés. Par défaut, c'est bin.
--standalone
Crée des binstubs qui peuvent fonctionner sans dépendre de Rubygems ou Bundler à l'exécution.
--shebang=SHEBANG
Spécifie un nom d'exécutable shebang différent de celui par défaut (par défaut 'ruby')
--all
Crée des binstubs pour toutes les gems du bundle.
--all-platforms
Installe les binstubs pour toutes les plateformes.
