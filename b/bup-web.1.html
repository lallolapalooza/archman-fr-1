NOM

bup-web - Lance un serveur web pour parcourir les dépôts bup

SYNTAXE

bup web [[nom_hôte]:port]

bup web unix://chemin

DESCRIPTION

bup web démarre un serveur web qui permet de parcourir les dépôts bup. La hiérarchie des fichiers est la même que celle affichée par bup-fuse(1), bup-ls(1) et bup-ftp(1).

nom_hôte et port valent par défaut 127.0.0.1 et 8080, respectivement, et par conséquent bup web n'offrira le serveur web qu'aux clients exécutés localement. Si vous souhaitez exposer le serveur web à toute personne sur votre réseau (dangereux !), vous pouvez omettre l'adresse de liaison pour vous lier à toutes les interfaces disponibles : :8080.

Lorsque unix://chemin est spécifié, le serveur écoutera sur le socket du système de fichiers à chemin plutôt que sur un socket réseau.

Un signal SIGTERM peut être envoyé au serveur pour demander un arrêt ordonné.

OPTIONS

--lisible-par-lhumain
afficher les tailles de fichiers lisibles par l'humain (c'est-à-dire 3.9K, 4.7M)
--navigateur
ouvrir le site dans le navigateur par défaut

EXEMPLES

$ bup web
Diffusion HTTP sur 127.0.0.1:8080...
^C
Interrompu.
$ bup web :8080
Diffusion HTTP sur 0.0.0.0:8080...
^C
Interrompu.
$ bup web unix://socket &
Diffusion HTTP sur le socket du système de fichiers 'socket'
$ curl --unix-socket ./socket http://localhost/
$ fg
bup web unix://socket
^C
Interrompu.
$ bup web &
[1] 30980
Diffusion HTTP sur 127.0.0.1:8080...
$ kill -s TERM 30980
Demande d'arrêt
$ wait 30980
$ echo $?
0
