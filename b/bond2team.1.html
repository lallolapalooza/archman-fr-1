BOND2TEAM(1) Outil de conversion de bonding vers team BOND2TEAM(1)

NOM

bond2team — Convertit la configuration de bonding en team

SYNTAXE

bond2team [options]

DESCRIPTION

bond2team est un outil pour convertir les options de bonding en team en essayant autant que possible de conserver la fonctionnalité d'origine.

Les fichiers résultants sont enregistrés dans un répertoire temporaire en utilisant le style ifcfg par défaut. Dans le cas de la conversion d'un fichier ifcfg, il traduit les options de bonding en team, en conservant toutes les autres options. Dans ce cas, il convertit les fichiers ifcfg d'esclaves respectifs en ports team, en conservant également toutes leurs autres options. Dans le cas de la conversion à partir d'options de bonding données dans la ligne de commande, l'outil peut utiliser les ports spécifiés comme ports team.

OPTIONS

--master <interface>
Spécifie le nom de l'interface ou le fichier ifcfg à convertir. Si le nom de l'interface est spécifié, l'outil recherchera le fichier ifcfg respectif dans /etc/sysconfig/network-scripts/.
--rename <interface>
Ceci est une option pratique pour remplacer le nom de l'interface d'origine par le nom spécifié. Par exemple, si --master spécifie bond0, il est possible d'utiliser --rename team0 pour changer le nom de l'interface finale en team0.
--ifcfg
Définit le format de sortie sur le style de configuration ifcfg. [défaut]
--json
Définit le format de sortie sur le style JSON. Voir teamd.conf(5) pour plus de détails.
--bonding_opts '<options de bonding>'
Spécifie les options de bonding à convertir au lieu de les lire à partir du fichier ifcfg.
--port <interface>
Définit l'interface spécifiée comme port team.
--configdir <répertoire>
Change le chemin de configuration ifcfg de /etc/sysconfig/network-scripts vers le <répertoire> spécifié.
--outputdir <répertoire>
Définit le répertoire de sortie sur <répertoire>.
--stdout
Imprime le résultat à l'écran au lieu de l'écrire dans des fichiers.
--debug
Augmente le niveau de débogage.
--quiet
Interdit l'affichage de messages sur la console.
--version
Imprime la version de l'outil sur la console et quitte.
--help
Imprime le texte d'aide sur la console et quitte.
--examples
Imprime des exemples d'utilisation courants sur la console et quitte.

EXEMPLES

Pour convertir la configuration ifcfg actuelle de 'bond0' en team ifcfg:

# bond2team --master bond0

Pour convertir la configuration ifcfg actuelle de 'bond0' en team ifcfg en renommant l'interface en 'team0'. Attention : les règles de pare-feu, les interfaces alias, etc., qui pourraient être liées au nom d'interface d'origine peuvent échouer après le renommage car l'outil ne changera que le fichier ifcfg, rien d'autre.

# bond2team --master bond0 --rename team0

Pour convertir des paramètres de bonding donnés avec des ports sans aucun ifcfg:

# bond2team --bonding_opts 'mode=1 miimon=500 primary=eth1 primary_reselect=0' --port eth1 --port eth2 --port eth3 --port eth4

Pour plus d'exemples, voir l'option --examples.

AVERTISSEMENTS

L'outil ne convertira aucune autre configuration qui pourrait être liée à la configuration actuelle. Par exemple, les règles de pare-feu, les interfaces alias, les ponts, etc.
