NOM

bind8_query2dlf - convertir les logs de requêtes BIND8 en dlf

SYNTAXE

bind8_query2dlf

DESCRIPTION

Ce script convertit chaque ligne d'un log de requêtes bind8 en un enregistrement dlf de dns.

BIND génère ces logs lorsqu'une configuration similaire à celle-ci

logging {
    channel query_logging {
        file "/var/log/named_querylog"
        versions 3 size 100M;
        print-time yes;                 // horodate les entrées de log              
     };
     category queries {
         query_logging;
     };
};

est présente dans le fichier named.conf de bind. Cela permettra de sauvegarder jusqu'à trois fichiers journaux d'une taille maximale de 100 Mo dans le répertoire /var/log.

Ces fichiers journaux ressemblent à ceci :

10-Apr-2000 00:01:20.307 XX /10.2.3.4/1.2.3.in-addr.arpa/SOA/IN
10-Apr-2000 00:01:20.308 XX+/10.4.3.2/host.foo.com/A/IN

EXEMPLES

Pour traiter un log tel que produit par bind8 :

$ bind8_query2dlf < dns-query

bind8_query2dlf sera rarement utilisé seul, mais il est plus probable qu'il soit appelé par lr_log2report :

$ lr_log2report bind8_query < /var/log/dns-query
