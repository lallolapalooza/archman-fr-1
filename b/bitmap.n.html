bitmap(n) Commandes intégrées Tk bitmap(n)

NOM

bitmap - Images affichant deux couleurs

SYNTAXE

image create bitmap ?nom? ?options?
nomImage cget option
nomImage configure ?option? ?valeur option valeur ...?

DESCRIPTION

Un bitmap est une image dont les pixels peuvent afficher soit deux couleurs, soit être transparents. Une image bitmap est définie par quatre éléments : une couleur de fond, une couleur de premier plan, et deux bitmaps, appelés la source et le masque. Chacun des bitmaps spécifie des valeurs 0/1 pour un tableau rectangulaire de pixels, et les deux bitmaps doivent avoir les mêmes dimensions. Pour les pixels où le masque est zéro, l'image n'affiche rien, produisant un effet transparent. Pour les autres pixels, l'image affiche la couleur de premier plan si les données source sont un, et la couleur de fond si les données source sont zéro.

CRÉATION DE BITMAPS

Comme toutes les images, les bitmaps sont créés en utilisant la commande image create. Les bitmaps supportent les options suivantes :

-background couleur
Spécifie une couleur de fond pour l'image de l'une des manières standards acceptées par Tk. Si cette option est définie à une chaîne vide, alors les pixels de fond seront transparents. Cet effet est obtenu en utilisant le bitmap source comme bitmap de masque, ignorant toute option -maskdata ou -maskfile.
-data chaîne
Spécifie le contenu du bitmap source sous forme de chaîne. La chaîne doit adhérer au format bitmap X11 (par exemple, tel que généré par le programme bitmap). Si les deux options -data et -file sont spécifiées, l'option -data a la priorité.
-file nom
nom donne le nom d'un fichier dont le contenu définit le bitmap source. Le fichier doit adhérer au format bitmap X11 (par exemple, tel que généré par le programme bitmap).
-foreground couleur
Spécifie une couleur de premier plan pour l'image de l'une des manières standards acceptées par Tk.
-maskdata chaîne
Spécifie le contenu du masque sous forme de chaîne. La chaîne doit adhérer au format bitmap X11 (par exemple, tel que généré par le programme bitmap). Si les deux options -maskdata et -maskfile sont spécifiées, l'option -maskdata a la priorité.
-maskfile nom
nom donne le nom d'un fichier dont le contenu définit le masque. Le fichier doit adhérer au format bitmap X11 (par exemple, tel que généré par le programme bitmap).

COMMANDE IMAGE

Lorsqu'une image bitmap est créée, Tk crée également une nouvelle commande dont le nom est le même que celui de l'image. Cette commande peut être utilisée pour invoquer diverses opérations sur l'image. Elle a la forme générale suivante :

nomImage option ?arg arg ...?
Option et les args déterminent le comportement exact de la commande. Les commandes suivantes sont possibles pour les images bitmap :
nomImage cget option
Retourne la valeur actuelle de l'option de configuration donnée par option. Option peut avoir l'une des valeurs acceptées par la commande image create bitmap.
nomImage configure ?option? ?valeur option valeur ...?
Interroge ou modifie les options de configuration de l'image. Si aucune option n'est spécifiée, retourne une liste décrivant toutes les options disponibles pour nomImage (voir Tk_ConfigureInfo pour plus d'informations sur le format de cette liste). Si option est spécifiée sans valeur, alors la commande retourne une liste décrivant l'option nommée (cette liste sera identique à la sous-liste correspondante de la valeur retournée si aucune option n'est spécifiée). Si une ou plusieurs paires option-valeur sont spécifiées, alors la commande modifie les option(s) données pour leur attribuer la ou les valeurs données ; dans ce cas, la commande retourne une chaîne vide. Option peut avoir l'une des valeurs acceptées par la commande image create bitmap.
