BIO_parse_hostserv(3ssl)

Paquet: openssl

Licences: Apache-2.0

BIO_PARSE_HOSTSERV(3ssl) OpenSSL BIO_PARSE_HOSTSERV(3ssl)

NOM

BIO_hostserv_priorities, BIO_parse_hostserv - routines utilitaires pour analyser une chaîne standard hôte et service

SYNOPHIS

#include <openssl/bio.h>
enum BIO_hostserv_priorities {
    BIO_PARSE_PRIO_HOST, BIO_PARSE_PRIO_SERV
};
int BIO_parse_hostserv(const char *hostserv, char **host, char **service,
                       enum BIO_hostserv_priorities hostserv_prio);

DESCRIPTION

BIO_parse_hostserv() analysera les informations fournies dans hostserv, créera des chaînes avec le nom d'hôte et le nom du service et les renverra via host et service. Celles-ci devront être libérées après utilisation. hostserv_prio aide à déterminer si hostserv doit être interprété principalement comme un nom d'hôte ou un nom de service dans les cas ambigus.

La syntaxe reconnue par BIO_parse_hostserv() est :

hôte + ':' + service
hôte + ':' + '*'
hôte + ':'
       ':' + service
'*'  + ':' + service
hôte
service

La partie hôte peut être un nom ou une adresse IP. S'il s'agit d'une adresse IPv6, elle DOIT être entourée de crochets, comme '[::1]'.

La partie service peut être un nom de service ou son numéro de port. Un nom de service sera mappé à un numéro de port en utilisant la fonction système getservbyname().

Les valeurs renvoyées dépendront de la chaîne hostserv donnée et de hostserv_prio, comme suit :

hôte + ':' + service  => *host = "hôte", *service = "service"
hôte + ':' + '*'      => *host = "hôte", *service = NULL
hôte + ':'            => *host = "hôte", *service = NULL
       ':' + service  => *host = NULL, *service = "service"
 '*' + ':' + service  => *host = NULL, *service = "service"
en l'absence de ':' dans la chaîne, le résultat dépend de
hostserv_prio, comme suit :
quand hostserv_prio == BIO_PARSE_PRIO_HOST
hôte                 => *host = "hôte", *service non modifié
quand hostserv_prio == BIO_PARSE_PRIO_SERV
service              => *host non modifié, *service = "service"

VALEURS DE RETOUR

BIO_parse_hostserv() renvoie 1 en cas de succès ou 0 en cas d'erreur.
