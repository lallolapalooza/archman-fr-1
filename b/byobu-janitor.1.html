NOM

byobu-janitor - script pour nettoyer et mettre à niveau l'environnement après les mises à niveau

SYNTAXE

byobu-janitor

DESCRIPTION

byobu-janitor est un script destiné à nettoyer l'environnement après les mises à niveau. Il comprend plusieurs tâches dont le but est de s'assurer que l'environnement est prêt pour une nouvelle version de byobu.
