NOM

Throwable::Error - une classe facile à utiliser pour les objets d'erreur

VERSION

version 1.001

SYNOPSIS

package MyApp::Error;
# NOTE: Moo peut aussi être utilisé ici au lieu de Moose
use Moose;
extends 'Throwable::Error';
has execution_phase => (
  is  => 'ro',
  isa => 'MyApp::Phase',
  default => 'startup',
);

...et dans votre application...

MyApp::Error->throw("toutes les communications hors ligne");
# ou...
MyApp::Error->throw({
  message         => "toutes les communications hors ligne",
  execution_phase => 'shutdown',
});

DESCRIPTION

Throwable::Error est une classe de base pour les exceptions qui seront levées pour signaler des erreurs et interrompre le flux normal du programme. Throwable::Error est une alternative à Exception::Class, dont les fonctionnalités sont largement fournies par le système objet Moo sur lequel Throwable::Error est construit.

Throwable::Error exécute les rôles Throwable et StackTrace::Auto. Cela signifie que vous pouvez appeler "throw" sur celle-ci pour créer et lever un objet d'erreur en un seul appel, et que chaque objet d'erreur aura une trace de pile pour sa création.

VERSION PERL

Cette bibliothèque devrait fonctionner sur des versions Perl même très anciennes. Elle devrait fonctionner sur toute version de perl publiée au cours des cinq dernières années.

Bien qu'elle puisse fonctionner sur des versions plus anciennes de Perl, aucune garantie n'est faite que la version minimale requise ne sera pas augmentée. La version peut être augmentée pour quelque raison que ce soit, et il n'est pas garanti que des correctifs seront acceptés pour abaisser la version minimale requise de Perl.

ATTRIBUTS

message

Cet attribut doit être défini et contenir une chaîne décrivant la condition d'erreur. Cette chaîne sera imprimée en haut de la trace de pile lorsque l'erreur est convertie en chaîne.

stack_trace

Cet attribut, fourni par StackTrace::Auto, contiendra un objet de trace de pile garanti de répondre à la méthode "as_string". Pour plus d'informations sur la trace de pile et le comportement associé, consultez la documentation de StackTrace::Auto.

MÉTHODES

as_string

Cette méthode fournira une chaîne représentant l'erreur, contenant le message de l'erreur suivi de sa trace de pile.
