NAME

Thread::Queue - An object oriented, thread-safe queue.

VERSION

2.20

SYNOPSIS

  use Thread::Queue;
  my $q = Thread::Queue->new;
  $q->enqueue('item1', 'item2');
  my $item = $q->dequeue; # item1
  my @items = $q->items;
  my $empty = $q->is_empty;
  $q->replace(1, 'new_item');
  $q->insert(0, 'first_item');
  my $removed = $q->extract(1, 2); # Removes and returns 2 items starting at index 1

DESCRIPTION

This module provides an object oriented interface to a queue that is safe for use in multithreaded applications.

The queue is created using "Thread::Queue->new". The returned object supports the following methods:

QUEUE CREATION

new([ITEM,...])
Creates and returns a new queue object. Optionally, you can pass a list of items to pre-populate the queue.

BASIC METHODS

->enqueue(ITEM, ...)
Adds one or more items to the end (tail) of the queue.
->dequeue()
Removes and returns the item at the head of the queue. If the queue is empty, this method blocks until an item is available.
->dequeue_nb()
Removes and returns the item at the head of the queue. If the queue is empty, this method returns immediately with an undefined value (or an empty list if called in list context).
->is_empty()
Returns true if the queue currently contains no items, false otherwise.
->pending()
Returns the number of items currently in the queue.
->items()
Returns a list of all items currently in the queue, in order from head to tail. This method is primarily for debugging and inspection, and should not be relied upon in threaded code where the contents can change at any moment.
->clear()
Removes all items from the queue.

ADVANCED METHODS

->replace(INDEX, ITEM, ...)
Replaces the item at the specified index with the new item(s). The index is 0-based, with 0 being the head of the queue. If the index is out of bounds, the call has no effect. If multiple items are provided, they replace the single item at the specified index, effectively inserting them at that position.
->insert(INDEX, ITEM, ...)
Inserts one or more items into the queue at the specified index. The index is 0-based, with 0 being the head of the queue. Negative indices are supported, counting from the tail of the queue (-1 is the last item).

Specifying an index position greater than the number of items in the queue just adds the list to the end.

Negative index positions are supported:

$q->enqueue(1, 2, 3, 4);
$q->insert(-2, qw/foo bar/);
# Queue now contains:  1, 2, foo, bar, 3, 4

Specifying a negative index position greater than the number of items in the queue adds the list to the head of the queue.

->extract()
->extract(INDEX)
->extract(INDEX, COUNT)
Removes and returns the specified number of items (defaults to 1) from the specified index position in the queue (0 is the head of the queue). When called with no arguments, "extract" operates the same as "dequeue_nb".

This method is non-blocking, and will return only as many items as are available to fulfill the request:

$q->enqueue(1, 2, 3, 4);
my $item  = $q->extract(2)     # Returns 3
                               # Queue now contains:  1, 2, 4
my @items = $q->extract(1, 3)  # Returns (2, 4)
                               # Queue now contains:  1

Specifying an index position greater than the number of items in the queue results in "undef" or an empty list being returned.

$q->enqueue('foo');
my $nada = $q->extract(3)      # Returns undef
my @nada = $q->extract(1, 3)   # Returns ()

Negative index positions are supported. Specifying a negative index position greater than the number of items in the queue may return items from the head of the queue (similar to "dequeue_nb") if the count overlaps the head of the queue from the specified position (i.e. if queue size + index + count is greater than zero):

$q->enqueue(qw/foo bar baz/);
my @nada = $q->extract(-6, 2);  # Returns ()      - (3+(-6)+2) <= 0
my @some = $q->extract(-6, 4);  # Returns (foo)   - (3+(-6)+4) > 0
                                # Queue now contains:  bar, baz
my @rest = $q->extract(-3, 4);  # Returns (bar, baz) -
                                #                   (2+(-3)+4) > 0

NOTES

Queues created by Thread::Queue can be used in both threaded and non-threaded applications.

LIMITATIONS

Passing objects on queues may not work if the objects' classes do not support sharing. See "BUGS AND LIMITATIONS" in threads::shared for more.

Passing array/hash refs that contain objects may not work for Perl prior to 5.10.0.
