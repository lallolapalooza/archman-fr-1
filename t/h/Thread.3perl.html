METHODS

The following methods are available:

detach
"detach" indique à un thread qu'il ne sera jamais joint, c'est-à-dire que toutes les traces de son existence peuvent être supprimées une fois qu'il aura cessé de s'exécuter. Les erreurs dans les threads détachés ne seront visibles nulle part. Si vous souhaitez les intercepter, vous devriez utiliser $SIG{__DIE__} ou quelque chose de similaire.
equal
"equal" teste si deux objets de thread représentent le même thread et renvoie vrai s'ils le font.
tid
La méthode "tid" renvoie le tid d'un thread. Le tid est un entier qui augmente de manière monotone et qui est attribué lorsqu'un thread est créé. Le thread principal d'un programme aura un tid de zéro, tandis que les threads suivants auront des tids attribués à partir de un.
done
La méthode "done" renvoie vrai si le thread que vous vérifiez a terminé son exécution, et faux sinon.

DEFUNCT

Les éléments suivants étaient implémentés avec 5005threads, mais ne sont plus disponibles avec ithreads.

lock(\&sub)
Avec 5005threads, vous pouviez également "lock" une sous-routine de telle sorte que tout appel à cette sous-routine depuis un autre thread serait bloqué jusqu'à ce que le verrou soit libéré.

De plus, les sous-routines pouvaient être déclarées avec l'attribut ":locked", ce qui sérialisait l'accès à la sous-routine, mais permettait à différents threads un accès non simultané.

eval
La méthode "eval" encapsulait un "eval" autour d'un "join", attendant ainsi qu'un thread se termine, transmettant toutes les valeurs que le thread aurait pu renvoyer et plaçant toutes les erreurs dans $@.
flags
La méthode "flags" renvoyait les indicateurs (flags) pour le thread - une valeur entière correspondant aux indicateurs internes du thread.
