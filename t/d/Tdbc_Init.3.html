Tdbc_Init(3) Connectivité base de données Tcl Tdbc_Init(3)

NOM

Tdbc_Init, Tdbc_MapSqlState, Tdbc_TokenizeSql - Procédures C pour faciliter l'écriture de pilotes TDBC

SYNTAXE

#include <tdbc.h>
int
Tdbc_Init(interp)
Tcl_Obj *
Tdbc_TokenizeSql(interp, sqlcode)
const char *
Tdbc_MapSqlState(state)

ARGUMENTS

Tcl_Interp *interp (in/out)
Pointeur vers un interpréteur Tcl.
const char *state (in)
Pointeur vers une chaîne de caractères contenant un « état SQL » d'une erreur de base de données.
const char *sqlcode (in)
Pointeur vers une chaîne de caractères contenant une instruction SQL.

DESCRIPTION

La bibliothèque TDBC fournit plusieurs procédures C qui simplifient l'écriture d'un pilote TDBC. Elles incluent une procédure qui découpe en jetons une instruction SQL, localisant les variables à substituer, et une procédure qui accepte un état SQL et retourne une classe d'erreur pour les informations d'erreur de l'interpréteur.

Tdbc_Init doit être appelée avant toute autre fonction TDBC. Elle accepte un pointeur vers un interpréteur Tcl et s'arrange pour charger la bibliothèque TDBC. Elle retourne TCL_OK si la bibliothèque Tcl a été chargée avec succès, et TCL_ERROR sinon. Si TCL_ERROR est retourné, le résultat de l'interpréteur contient le message d'erreur.

Tdbc_TokenizeSql accepte un pointeur vers un interpréteur Tcl et un pointeur vers une chaîne de caractères contenant une ou plusieurs instructions SQL. Elle découpe les instructions SQL en jetons et retourne un pointeur vers un Tcl_Obj qui contient une liste des jetons qui composent l'instruction. La concaténation des jetons donnera le code SQL original. Le Tcl_Obj retourné a un compteur de références de zéro. L'appelant est responsable de la gestion du compteur de références selon les besoins. Voir JETONS ci-dessous pour une description de ce qui peut se trouver dans la liste retournée de jetons.

Tdbc_MapSqlState accepte un pointeur vers une chaîne, généralement de cinq caractères, qui est l'« état SQL » résultant d'une erreur de base de données. Elle retourne une chaîne de caractères qui convient pour être incluse comme classe d'erreur lors de la construction du code d'erreur pour une erreur dans un pilote TDBC. (Par convention, le code d'erreur est une liste ayant au moins quatre éléments : "TDBC classeErreur etatSql nomPilote details...".)

JETONS

Chaque jeton retourné par Tdbc_TokenizeSql peut être l'un des suivants :

[1]
Une variable liée, qui commence par l'un des caractères ':', '@', ou '$'. Le reste de la chaîne est le nom de la variable et sera composé de caractères alphanumériques et de soulignements. (Le caractère initial sera non numérique.)
[2]
Un point-virgule qui sépare deux instructions SQL.
[3]
Autre chose dans une instruction SQL. Le découpeur de jetons ne tente pas d'analyser le SQL ; il identifie simplement les variables liées (les distinguant des chaînes similaires apparaissant entre guillemets ou dans des commentaires) et les délimiteurs d'instruction.
