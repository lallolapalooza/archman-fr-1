TPMLIB_MainInit(3)

Paquet: libtpms

Licences: BSD-3-Clause

TPMLIB_MainInit(3) TPMLIB_MainInit(3)

NOM

TPMLIB_MainInit - Initialise le TPM

TPMLIB_Terminate - Termine le TPM

BIBLIOTHÈQUE

Bibliothèque TPM (libtpms, -ltpms)

SYNOPSIS

#include <libtpms/tpm_types.h>

#include <libtpms/tpm_library.h>

#include <libtpms/tpm_error.h>

TPM_RESULT TPMLIB_MainInit(void);

TPM_RESULT TPMLIB_Terminate(void);

DESCRIPTION

Les fonctions TPMLIB_MainInit() et TPMLIB_Terminate() sont utilisées pour initialiser et terminer respectivement le TPM. La fonction TPMLIB_MainInit() doit être appelée avant que le TPM ne traite une commande TPM. La fonction TPMLIB_Terminate() est appelée pour libérer toutes les ressources internes (allocations mémoire) utilisées par le TPM et doit être appelée après le traitement de la dernière commande TPM par le TPM. La fonction TPMLIB_MainInit() peut ensuite être appelée à nouveau.

Utilisez TPMLIB_RegisterCallbacks() pour définir des fonctions de rappel pour l'initialisation, l'écriture et la restauration de l'état interne dans un format portable.

ERREURS

TPM_SUCCESS
La fonction s'est terminée avec succès.
TPM_FAIL
Échec général.

Pour une liste complète des codes d'erreur TPM, veuillez consulter le fichier d'inclusion libtpms/tpm_error.h

EXEMPLE

#include <stdio.h>
#include <libtpms/tpm_types.h>
#include <libtpms/tpm_library.h>
#include <libtpms/tpm_error.h>
int main(void) {
    TPM_RESULT res;
    unsigned char *respbuffer = NULL;
    uint32_t resp_size = 0;
    uint32_t respbufsize = 0;
    unsigned char *command;
    uint32_t command_size;
    [...]
    if (TPMLIB_MainInit() != TPM_SUCCESS) {
        fprintf(stderr, "Impossible de démarrer le TPM.\n");
        return 1;
    }
    [...]
    /* construire la commande TPM */
    [...]
    res = TPMLIB_Process(&respbuffer, &resp_size,
                         &respbufsize,
                         command, command_size);
    [...]
    TPMLIB_Terminate();
    return 0;
}
