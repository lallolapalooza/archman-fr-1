TPMLIB_WasManufactured(3) TPMLIB_WasManufactured(3)

NOM

TPMLIB_WasManufactured - Vérifier si une nouvelle instance a été créée

BIBLIOTHÈQUE

TPM library (libtpms, -ltpms)

SYNTAXE

#include <libtpms/tpm_types.h>

#include <libtpms/tpm_library.h>

#include <libtpms/tpm_error.h>

TPM_BOOL TPMLIB_WasManufactured(void);

DESCRIPTION

TPMLIB_WasManufactured() est utilisée pour vérifier si une nouvelle instance de TPM a été créée à l'aide de TPMLIB_MainInit() plutôt qu'une instance existante a été redémarrée. Cette fonction ne retournera un résultat valide que si elle est appelée après TPMLIB_MainInit().

Cette fonction s'applique uniquement à un TPM 2 et pour un TPM 1.2, elle retournera toujours FALSE.

VOIR AUSSI

TPMLIB_ChooseTPMVersion, TPMLIB_MainInit(3)
