TPMLIB_GetInfo(3)

Paquet: libtpms

Licences: BSD-3-Clause

TPMLIB_GetInfo(3) TPMLIB_GetInfo(3)

NOM

TPMLIB_GetInfo - Obtenir des informations sur l'implémentation du TPM

BIBLIOTHÈQUE

Bibliothèque TPM (libtpms, -ltpms)

SYNTAXE

#include <libtpms/tpm_library.h>

char *TPMLIB_GetInfo(TPMLIB_InfoFlags flags);

DESCRIPTION

La fonction TPMLIB_GetInfo() permet de consulter des spécificités de l'implémentation du TPM et d'obtenir une chaîne JSON en retour. Les données qui doivent être retournées peuvent être spécifiées dans le paramètre flags, qui peut être une concaténation logique avec l'opérateur 'ou' des indicateurs. Si les indicateurs passés ne sont pas supportés, rien n'est retourné. Si 0 est passé, un objet JSON vide '{}' est retourné.

Les indicateurs suivants sont définis et retournent des objets JSON comme montré :

TPMLIB_INFO_TPMSPECIFICATION
{"TPMSpecification":{"family":"1.2","level":2,"revision":116}}
TPMLIB_INFO_TPMATTRIBUTES
{"TPMAttributes":{"manufacturer":"id:00001014","version":"id:00740001","model":"swtpm"}}
TPMLIB_INFO_TPMFEATURES (depuis v0.8.0)
{"TPMFeatures":{"RSAKeySizes":[1024,2048,3072]}}

Cet objet JSON pourra être étendu à l'avenir.

TPMLIB_INFO_RUNTIME_ALGORITHMS (depuis v0.10.0)
{
  "RuntimeAlgorithms": {
    "Implemented": "rsa,rsa-min-size=1024,tdes,tdes-min-size=128,sha1,hmac," \
                   "aes,aes-min-size=128,mgf1,keyedhash,xor,sha256,sha384," \
                   "sha512,null,rsassa,rsaes,rsapss,oaep,ecdsa,ecdh,ecdaa," \
                   "sm2,ecschnorr,ecmqv,kdf1-sp800-56a,kdf2,kdf1-sp800-108," \
                   "ecc,ecc-min-size=192,ecc-nist,ecc-bn,ecc-nist-p192," \
                   "ecc-nist-p224,ecc-nist-p256,ecc-nist-p384," \
                   "ecc-nist-p521,"ecc-bn-p256,ecc-bn-p638,ecc-sm2-p256," \
                   "symcipher,camellia,camellia-min-size=128,cmac,ctr,ofb," \
                   "cbc,cfb,ecb",
    "CanBeDisabled": "tdes,sha1,sha512,rsassa,rsaes,rsapss,ecmqv,ecc-nist," \
                     "ecc-bn,ecc-nist-p192,ecc-nist-p224,ecc-nist-p521," \
                     "ecc-bn-p256,ecc-bn-p638,ecc-sm2-p256,camellia,cmac," \
                     "ctr,ofb,cbc,ecb",
    "Enabled": "rsa,rsa-min-size=1024,hmac,aes,aes-min-size=128,mgf1," \
               "keyedhash,xor,sha256,sha384,null,oaep,ecdsa,ecdh,ecdaa," \
               "sm2,ecschnorr,kdf1-sp800-56a,kdf2,kdf1-sp800-108,ecc," \
               "ecc-min-size=192,ecc-bn,ecc-nist-p192,ecc-nist-p224," \
               "ecc-nist-p256,ecc-nist-p384,ecc-nist-p521,ecc-bn-p256," \
               "ecc-bn-p638,ecc-sm2-p256,symcipher,camellia," \
               "camellia-min-size=128,cmac,ctr,ofb,cbc,ecb",
    "Disabled": "tdes,sha1,sha512,rsassa,rsaes,rsapss,ecmqv,ecc-nist"
  }
}

Cet objet JSON énumère tous les algorithmes implémentés ainsi que les courbes cryptographiques elliptiques (ECC) supportées. Ces verbes énumérés sous CanBeDisabled représentent les algorithmes et les courbes ECC qu'un utilisateur peut omettre d'un profil, les rendant ainsi indisponibles aux applications. Les verbes énumérés sous Enabled et Disabled représentent les algorithmes qui sont activés et désactivés dans le profil actuellement actif.

Les verbes ecc-nist et ecc-bn sont des raccourcis permettant d'activer toutes les courbes ECC NIST implémentées actuellement (ecc-nist-p192, ecc-nist-p256, ...) et les courbes BN (Baretto-Naehrig) (ecc-bn-p256, ecc-bn-p638). Si omis, les courbes individuelles peuvent toujours être énumérées individuellement pour les activer. Comme ecc-nist-p256 et ecc-nist-p384 ne peuvent pas être désactivées, elles doivent être énumérées si le raccourci ecc-nist n'est pas utilisé.

Les tailles minimales de clé pour rsa, ecc, tdes, aes et camellia sont également décrites.

Lorsque de nouveaux algorithmes et courbes ECC seront ajoutés au TPM à l'avenir, cet objet JSON retournera davantage d'algorithmes.

Cet objet JSON énumère toutes les commandes implémentées par leurs numéros hexadécimaux et indique lesquelles peuvent être désactivées, lesquelles sont actuellement activées et lesquelles sont désactivées.

TPMLIB_INFO_ACTIVE_PROFILE (depuis v0.10.0)
Cet objet JSON montre le profil actuellement actif. 
{
  "ActiveProfile": {
    "Name": "null",
    "StateFormatLevel": 1,
    "Commands": "0x11f-0x122,0x124-0x12e,0x130-0x140,0x142-0x159," \
                "0x15b-0x15e,0x160-0x165,0x167-0x174,0x176-0x178," \
                "0x17a-0x193,0x197",
    "Algorithms": "rsa,rsa-min-size=1024,tdes,tdes-min-size=128,sha1,hmac," \
                  "aes,aes-min-size=128,mgf1,keyedhash,xor,sha256,sha384," \
                  "sha512,null,rsassa,rsaes,rsapss,oaep,ecdsa,ecdh,ecdaa," \
                  "sm2,ecschnorr,ecmqv,kdf1-sp800-56a,kdf2,kdf1-sp800-108," \
                  "ecc,ecc-min-size=192,ecc-nist,ecc-bn,symcipher,camellia," \
                  "camellia-min-size=128,cmac,ctr,ofb,cbc,cfb,ecb",
    "Description": "Le profil active les commandes et algorithmes qui " \
                   "étaient activés dans libtpms v0.9. Ce profil est " \
                   "automatiquement utilisé lorsque l'état n'a pas de " \
                   "profil, par exemple lorsqu'il a été créé par " \
                   "libtpms v0.9 ou avant."
  }
}

Le profil ci-dessus est le profil 'null'. Si le profil null est utilisé, l'état sera à nouveau lisible par libtpms v0.9.

Les futures versions de libtpms pourront énumérer d'autres profils.

VALEUR RENVOYÉE

Cette fonction retourne une chaîne JSON en cas de succès et un pointeur NULL en cas d'échec d'allocation mémoire.
