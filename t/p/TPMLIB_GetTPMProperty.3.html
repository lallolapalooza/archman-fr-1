TPMLIB_GetTPMProperty(3) TPMLIB_GetTPMProperty(3)

NOM

TPMLIB_GetTPMProperty - Obtenir une propriété d'exécution du TPM

BIBLIOTHÈQUE

Bibliothèque TPM (libtpms, -ltpms)

SYNOPSIS

#include <libtpms/tpm_library.h>

TPM_RESULT TPMLIB_GetTPMProperty(enum TPMLIB_TPMProperty, int *result);

DESCRIPTION

L'appel TPMLIB_GetTPMProperty() est utilisé pour récupérer les paramètres d'exécution du TPM tels que le nombre de sessions d'autorisation qu'il peut détenir ou les tailles maximales des blobs d'état permanent, d'état sauvegardé (savestate) ou d'état volatil.

Cette fonction peut être appelée avant ou après la création du TPM. L'implémentation actuelle de libtpms retournera la même valeur avant et après le démarrage du TPM.

Avec l'introduction de la fonction TPMLIB_ChooseTPMVersion(), l'appel à cette fonction doit être exécuté après le choix de la version du TPM. La raison est que différentes versions de TPM peuvent retourner des valeurs différentes.

Les propriétés suivantes ont été définies :

TPMPROP_TPM_RSA_KEY_LENGTH_MAX
La taille maximale d'une clé RSA.
TPMPROP_TPM_BUFFER_MAX
Les tailles maximales des tampons de commande et de résultat du TPM.
TPMPROP_TPM_KEY_HANDLES
Le nombre d'emplacements de clés.
TPMPROP_TPM_OWNER_EVICT_KEY_HANDLES
Le nombre de clés à évincer par le propriétaire.
TPMPROP_TPM_MIN_AUTH_SESSIONS
Le nombre de sessions d'autorisation.
TPMPROP_TPM_MIN_TRANS_SESSIONS
Le nombre de sessions de transport.
TPMPROP_TPM_MIN_DAA_SESSIONS
Le nombre de sessions DAA.
TPMPROP_TPM_MIN_SESSION_LIST
La taille de la liste de sessions.
TPMPROP_TPM_MIN_COUNTERS
Le nombre de compteurs monotones.
TPMPROP_TPM_NUM_FAMILY_TABLE_ENTRY_MIN
Le nombre d'entrées de famille.
TPMPROP_TPM_NUM_DELEGATE_TABLE_ENTRY_MIN
Le nombre d'entrées de délégués.
TPMPROP_TPM_SPACE_SAFETY_MARGIN
La marge de sécurité d'espace utilisée pour les tailles dans le pire des cas des blobs d'état sauvegardé et d'état volatil. Cette marge de sécurité n'est pas utilisée pour la taille du blob de données permanent.
TPMPROP_TPM_MAX_NV_SPACE
La taille maximale du blob de données permanent.
TPMPROP_TPM_MAX_SAVESTATE_SPACE
La taille maximale du blob d'état sauvegardé (inclut la marge de sécurité d'espace).
TPMPROP_TPM_MAX_VOLATILESTATE_SPACE
La taille maximale du blob d'état volatil (inclut la marge de sécurité d'espace).

ERREURS

TPM_SUCCESS
La fonction s'est terminée avec succès.
TPM_FAIL
Une propriété indéfinie a été interrogée.

Pour une liste complète des codes d'erreur TPM, veuillez consulter le fichier d'en-tête libtpms/tpm_error.h

EXEMPLE

#include <stdio.h>
#include <libtpms/tpm_library.h>
#include <libtpms/tpm_error.h>
int main(void) {
    TPM_RESULT res;
    int result;
    int rc = 0;
    if (TPMLIB_MainInit() != TPM_SUCCESS) {
        fprintf(stderr, "Impossible de démarrer le TPM.\n");
        return 1;
    }
    if (TPMLIB_GetTPMProperty(TPMPROP_TPM_RSA_KEY_LENGTH_MAX, &result)
        != TPM_SUCCESS) {
        fprintf(stderr, "Impossible de lire la taille max. des clés RSA.\n");
        goto err_exit;
    }
    fprintf(stdout, "Taille max. des clés RSA : %d\n", result);
err_exit:
    TPMLIB_Terminate();
    return 0;
}
