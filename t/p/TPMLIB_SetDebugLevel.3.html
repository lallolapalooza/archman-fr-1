TPMLIB_SetDebugLevel(3)

Paquet: libtpms

Licences: BSD-3-Clause

TPMLIB_SetDebugFD(3) TPMLIB_SetDebugFD(3)

NOM

TPMLIB_SetDebugFD - Définit le descripteur de fichier vers lequel envoyer la sortie de débogage

TPMLIB_SetDebugLevel - Définit le niveau de débogage

TPMLIB_SetDebugPrefix - Définit le préfixe pour chaque ligne de débogage

BIBLIOTHEQUE

TPM library (libtpms, -ltpms)

SYNOPSIS

#include <libtpms/tpm_library.h>

uint32_t TPMLIB_SetDebugFD(int fd);

uint32_t TPMLIB_SetDebugLevel(unsigned int level);

uint32_t TPMLIB_SetDebugPrefix(const char *prefix);

DESCRIPTION

TPMLIB_SetDebugFD() permet de définir le descripteur de fichier vers lequel envoyer la sortie de débogage.

TPMLIB_SetDebugLevel() permet de définir le niveau de débogage. Seuls les niveaux de débogage supérieurs à 1 produiront une sortie. Le niveau d'indentation d'une ligne déterminera si elle est imprimée. Les lignes avec une indentation de 0 seront imprimées au niveau de débogage 1, une espace d'indentation au niveau de débogage 2, et ainsi de suite.

TPMLIB_SetDebugPrefix() permet de définir un préfixe qui sera imprimé devant chaque ligne de sortie de débogage. Le préfixe peut être utilisé pour une indentation supplémentaire.
