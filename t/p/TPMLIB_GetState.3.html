TPMLIB_GetState(3)

Paquet: libtpms

Licences: BSD-3-Clause

TPMLIB_SetState(3) TPMLIB_SetState(3)

NOM

TPMLIB_SetState - Définir l'état volatile, permanent ou enregistré du TPM

TPMLIB_GetState - Obtenir l'état volatile, permanent ou enregistré du TPM

BIBLIOTHÈQUE

Bibliothèque TPM (libtpms, -ltpms)

SYNOPSIS

#include <libtpms/tpm_library.h>

TPM_RESULT TPMLIB_SetState(enum TPMLIB_StateType st,
const unsigned char *buffer, uint32_t buflen);

TPM_RESULT TPMLIB_GetState(enum TPMLIB_StateType st,
unsigned char **buffer, uint32_t *buflen);

DESCRIPTION

La fonction TPMLIB_SetState() permet de définir l'un des blocs d'état du TPM. Le bloc d'état passé est vérifié pour s'assurer qu'il peut être accepté, et un code d'erreur TPM est retourné s'il ne peut pas être accepté. En cas d'acceptation, le bloc d'état sera transmis au TPM lors de l'appel à TPM_MainInit(). La définition d'un bloc d'état masque un fichier qui pourrait contenir le même type de bloc et qui serait lu autrement. Il est obligatoire d'appeler cette fonction avec un pointeur NULL pour le paramètre buffer afin de masquer un bloc d'état dans un fichier.

Il n'est possible de définir les blocs d'état qu'après avoir appelé TPMLIB_ChooseTPMVersion(). Tous les blocs d'état sont effacés lorsqu'une version différente de TPM est choisie en utilisant TPMLIB_ChooseTPMVersion ou lorsqu'un appel à TPMLIB_SetState() échoue parce qu'un bloc d'état n'a pas pu être accepté.

L'ordre dans lequel les blocs d'état sont définis est important. Le premier bloc d'état doit être celui qui représente l'état permanent du TPM. Ce n'est qu'après cela que les blocs d'état volatile ou enregistré peuvent être définis.

La fonction TPMLIB_GetState() permet d'obtenir l'état actuel du TPM. Tant que le TPM n'a pas été démarré, cette fonction retourne soit le bloc d'état précédemment défini avec TPMLIB_SetState(), soit l'état est lu à partir d'un fichier. Une fois que le TPM a été démarré, l'état du TPM en cours d'exécution est retourné.

Le type d'état TPM TPMLIB_STATE_SAVE_STATE (état enregistré) peut être défini avec cette fonction. Le même bloc d'état sera retourné jusqu'à ce que TPM_Startup(ST_STATE) ait été appelé, après quoi un bloc vide sera retourné. Ce bloc ne peut également être lu qu'après que TPM_SaveState() ait été envoyé au TPM.

VOIR AUSSI

TPMLIB_ChooseTPMVersion(3), TPMLIB_MainInit(3), TPMLIB_Terminate(3)
