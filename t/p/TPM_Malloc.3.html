TPM_Malloc(3)

Paquet: libtpms

Licences: BSD-3-Clause

TPM_Malloc(3) TPM_Malloc(3)

NOM

TPM_Malloc - Allouer de la mémoire

TPM_Realloc - Réallouer de la mémoire

TPM_Free - Libérer de la mémoire

SYNTAXE

#include <libtpms/tpm_types.h>

#include <libtpms/tpm_memory.h>

#include <libtpms/tpm_error.h>

TPM_RESULT TPM_Malloc(unsigned char **buffer,
uint32_t size);

TPM_RESULT TPM_Realloc(unsigned char **buffer,
uint32_t size);

void TPM_Free(unsigned char *buffer);

DESCRIPTION

La fonction TPM_Malloc() est utilisée pour allouer un tampon de la taille donnée. Le tampon alloué sera retourné dans le paramètre buffer.

La fonction TPM_Realloc() est utilisée pour redimensionner un tampon. La nouvelle taille du tampon est indiquée dans le paramètre size. Le tampon réalloué contiendra les données du tampon original.

Les deux fonctions ont la restriction que la taille du tampon qu'elles peuvent allouer est limitée à TPM_ALLOC_MAX (64 Ko). Cette taille est suffisante pour tous les tampons nécessaires au TPM.

En cas de succès, les fonctions retournent TPM_SUCCESS. Si le tampon demandé dépasse la limite, TPM_SIZE sera retourné. Voir d'autres codes d'erreur possibles ci-dessous.

La fonction TPM_Free() libère la mémoire précédemment allouée à l'aide de TPM_Malloc() ou TPM_Realloc().

ERREURS

TPM_SUCCESS
La fonction s'est terminée avec succès.
TPM_SIZE
La taille du tampon demandé dépasse la limite ou le système manque de mémoire.
TPM_FAIL
Le tampon demandé a une taille de 0.

Pour une liste complète des codes d'erreur TPM, veuillez consulter le fichier d'inclusion libtpms/tpm_error.h
