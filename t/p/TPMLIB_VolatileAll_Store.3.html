TPMLIB_VolatileAll_Store(3)

Paquet: libtpms

Licences: BSD-3-Clause

TPMLIB_VolatileAll_Store(3) TPMLIB_VolatileAll_Store(3)

NOM

TPMLIB_VolatileAll_Store - stocker tout l'état volatile du TPM dans un tampon

BIBLIOTHÈQUE

Bibliothèque TPM (libtpms, -ltpms)

SYNOPSIS

#include <libtpms/tpm_library.h>

#include <libtpms/tpm_error.h>

TPM_RESULT TPMLIB_VolatileAll_Store(unsigned char **buffer,
uint32_t *buflen);

DESCRIPTION

La fonction TPMLIB_VolatileAll_Store() est utilisée pour obtenir l'état volatile du TPM. La fonction allouera un buffer et renverra le nombre d'octets d'informations d'état dans la variable buflen.

ERREURS

TPM_SUCCESS
La fonction s'est terminée avec succès.
TPM_FAIL
Échec général.

Pour une liste complète des codes d'erreur TPM, veuillez consulter le fichier d'inclusion libtpms/tpm_error.h

VOIR AUSSI

TPMLIB_MainInit(3), TPMLIB_Terminate(3), TPMLIB_RegisterCallbacks(3)
