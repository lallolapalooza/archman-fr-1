TPMLIB_Process(3)

Paquet: libtpms

Licences: BSD-3-Clause

TPMLIB_Process(3) TPMLIB_Process(3)

NOM

TPMLIB_Process - traite une commande TPM

BIBLIOTHÈQUE

Bibliothèque TPM (libtpms, -ltpms)

SYNTAXE

#include <libtpms/tpm_library.h>

#include <libtpms/tpm_error.h>

TPM_RESULT TPMLIB_Process(unsigned char **respbuffer,
uint32_t *resp_size,
uint32_t *respbufsize,
unsigned char *command,
uint32_t command_size);

DESCRIPTION

La fonction TPMLIB_Process() est utilisée pour envoyer des commandes TPM au TPM et recevoir les résultats.

Le paramètre command fournit le tampon pour la commande TPM et command_size le nombre d'octets de commande TPM valides dans ce tampon.

Le paramètre respbuffer est un pointeur vers un tampon où le TPM renverra son résultat. Si aucun tampon n'est fourni (respbuffer est NULL), le TPM allouera un tampon. Le paramètre resp_size renvoie le nombre d'octets de réponse TPM valides dans le tampon. Le nombre d'octets valides dans la réponse ne dépassera jamais la taille maximale du tampon d'E/S. Utilisez l'API TPMLIB_GetTPMProperty() avec le paramètre TPMPROP_TPM_BUFFER_MAX pour obtenir la taille maximale. L'utilisateur doit indiquer la taille d'un tampon fourni avec le paramètre respbufsize. Si le tampon n'est pas assez grand pour la réponse, le TPM libérera le tampon fourni et en allouera un de taille suffisante et adaptera respbufsize. Le tampon renvoyé n'est soumis qu'aux restrictions de taille expliquées pour TPM_Malloc().

ERREURS

TPM_SUCCESS
La fonction s'est terminée avec succès.
TPM_FAIL
Échec général.

Pour une liste complète des codes d'erreur TPM, veuillez consulter le fichier d'inclusion libtpms/tpm_error.h

EXEMPLE

#include <stdio.h>
#include <libtpms/tpm_types.h>
#include <libtpms/tpm_library.h>
#include <libtpms/tpm_error.h>
static unsigned char TPM_Startup_ST_CLEAR[] = {
    0x00, 0xC1, 0x00, 0x00, 0x00, 0x0C, 0x00, 0x00, 0x00, 0x99,
    0x00, TPM_ST_CLEAR
};
int main(void) {
    TPM_RESULT res;
    unsigned char *respbuffer = NULL;
    uint32_t resp_size = 0;
    uint32_t respbufsize = 0;
    unsigned char *command;
    uint32_t command_size;
    [...]
    if (TPMLIB_MainInit() != TPM_SUCCESS) {
         fprintf(stderr, "Impossible de démarrer le TPM.\n");
         return 1;
    }
    [...]
    /* construire la commande TPM */
    command = TPM_Startup_ST_CLEAR;
    command_size = sizeof(TPM_Startup_ST_CLEAR);
    [...]
    res = TPMLIB_Process(&respbuffer, &resp_size,
                         &respbufsize,
                         command, command_size);
    [...]
    TPMLIB_Terminate();
    return 0;
}
