NOM

TPMLIB_ValidateState - Valider les blobs d'état du TPM

BIBLIOTHÈQUE

Bibliothèque TPM (libtpms, -ltpms)

SYNOPSIS

#include <libtpms/tpm_library.h>

uint32_t TPMLIB_ValidateState(TPMLIB_StateType st,
unsigned int flags);

DESCRIPTION

La fonction TPMLIB_ValidateState() permet de valider les blobs d'état que le TPM lirait lors de TPMLIB_MainInit() ou une fois la commande TPM_Startup envoyée.

Cette fonction est utile pour la migration d'état du TPM entre différentes versions de libtpms. Ici, la version cible de libtpms doit pouvoir déterminer si elle peut prendre en charge la version des blobs qui ont été migrés et, si ce n'est pas le cas, l'appelant peut refuser la migration.

Le paramètre tpmlib_state peut être un 'ou' logique d'un ou plusieurs des éléments suivants : TPMLIB_STATE_PERMANENT, TPMLIB_STATE_VOLATILE, ou TPMLIB_STATE_SAVE_STATE. Le paramètre flags n'est actuellement pas utilisé et doit être défini à 0.

Le premier blob d'état à charger est l'état permanent, car par exemple l'état volatile nécessite sa disponibilité pour la validation.

Cette fonction doit être appelée avant l'invocation de TPMLIB_MainInit().

VOIR AUSSI

TPMLIB_MainInit(3), TPMLIB_Terminate(3)
