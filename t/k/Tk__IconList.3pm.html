Paquet: perl-tk

Licences: PerlArtistic, GPL, custom

IconList(3) Documentation Perl fournie par la communauté IconList(3)

NOM

Tk::IconList - un widget de liste d'icônes

SYNTAXE

use Tk::IconList;
$il = $mw->IconList(-browsecmd => sub { ... },
                    -command   => sub { ... })->pack;
$il->Add($icon1, $text1);
$il->Add($icon2, $text2);
$il->Arrange;
...
$il->DeleteAll;

DESCRIPTION

OPTIONS

-browsecmd
-command
-font
-item -foreground|-fg

MÉTHODES

DeleteAll
Supprime tous les éléments du sous-widget canvas et réinitialise l'état de l'IconList.
Add($image, $text)
Ajoute une icône dans l'IconList avec l'image et le texte désignés.
Arrange
Dispose les icônes selon un arrangement par colonnes.
Get
Retourne l'élément sélectionné.
Invoke
Est appelé lorsque l'utilisateur invoque l'IconList (généralement par un double-clic ou en appuyant sur la touche Retour) (méthode interne).
See($tag)
Si l'élément n'est pas (complètement) visible, fait défiler le canvas pour le rendre visible (méthode interne).
