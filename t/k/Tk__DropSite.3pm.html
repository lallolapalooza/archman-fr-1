DropSite(3) Documentation Perl/Tk DropSite(3)

NOM

Tk::DropSite - Côté réception de l'abstraction Glisser & Déposer

SYNTAXE

use Tk::DropSite qw(...);
$widget->DropSite(-entercommand => ...,
                  -dropcommand  => ...,
                  -motioncommand  => ...,
                  -dropcommand  => ...,
                 );

DESCRIPTION

"DropSite" crée un objet qui représente un emplacement sur lequel des éléments peuvent être "déposés".

Un DropSite fournit les méthodes suivantes :

$site->Enter($token,$event)
$site->Leave($token,$event)
$site->Motion($token,$event)
$site->Drop($token,$event)
