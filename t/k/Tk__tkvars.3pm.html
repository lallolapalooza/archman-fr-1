NOM

Tk::tkvars - Variables utilisées ou définies par Tk

DESCRIPTION

Les variables perl suivantes sont soit définies, soit utilisées par Tk à différents moments de son exécution. (Pour une liste des variables utilisées par perl, voir perlvar.)

$Tk::library
Cette variable contient le nom de fichier d'un répertoire contenant les modules liés à Tk. Ces modules incluent un fichier d'initialisation qui est normalement traité chaque fois qu'une application Tk démarre, ainsi que d'autres fichiers contenant des procédures qui implémentent les comportements par défaut pour les widgets. La valeur initiale de $Tk::library est définie lorsque Tk est ajouté à un interpréteur ; ceci est fait en recherchant un répertoire nommé Tk dans le répertoire où se trouve le fichier Tk.pm, ou le premier répertoire Tk dans @INC.

La variable d'environnement TK_LIBRARY utilisée par Tcl/Tk n'est pas supportée par perl/Tk. Veuillez utiliser @INC pour changer où les modules sont recherchés.

Note : Ceci est un vestige de Tcl. Avec perl, il est plus logique d'utiliser @INC et %INC).

$Tk::patchLevel
Contient un entier décimal donnant le niveau de correction actuel pour Tk. Le niveau de correction est incrémenté pour chaque nouvelle version ou correction, et il identifie de manière unique une version officielle de Tk.

Note : ceci est un vestige de Tcl. Avec perl, il est plus logique d'utiliser $Tk::VERSION décrit ci-dessous.

$Tk::strictMotif
Cette variable est définie à zéro par défaut. Si une application la définit à un, alors Tk tente d'adhérer autant que possible aux normes d'apparence de Motif. Par exemple, les éléments actifs tels que les boutons et les curseurs des barres de défilement ne changeront pas de couleur lorsque le pointeur passera dessus.
$Tk::VERSION
La variable contient le numéro de version actuel de la version perl/Tk sous la forme majeure.mineure. Majeure et mineure sont des entiers.

Le numéro de version majeure indique sur quelle version Tcl/Tk la version perl/Tk est basée. Par exemple, 402 signifie basé sur Tk 4.2 de Tcl. (Les niveaux de correction de Tk de Tcl ne sont pas incorporés car perl/Tk avait tendance à être « en avance » sur certaines corrections et en retard sur d'autres. Le premier chiffre de la version majeure augmente dans toute version de Tk qui inclut des changements non rétrocompatibles (c'est-à-dire chaque fois que les applications et scripts perl/Tk existants peuvent devoir être modifiés pour fonctionner avec la nouvelle version).

La version mineure dépend uniquement de perl/Tk. Elle utilise le schéma « pair »=« stable », « impair »=« expérimental » que linux utilise :

.0xx  - intrinsèquement 'alpha'
.1xx  - 'beta' expérimental
.2xx  - stable
.3xx  - expérimental
.4xx  - stable
...

Le numéro de version mineure augmente avec chaque nouvelle version de Tk, sauf qu'il est remis à zéro chaque fois que le numéro de version majeure change.

$Tk::version
La variable contient le numéro de version actuel de la bibliothèque Tk sous la forme majeure.mineure. Majeure et mineure sont des entiers. Le numéro de version majeure augmente dans toute version de Tk qui inclut des changements non rétrocompatibles (c'est-à-dire chaque fois que les applications et scripts Tk existants peuvent devoir être modifiés pour fonctionner avec la nouvelle version). Le numéro de version mineure augmente avec chaque nouvelle version de Tk, sauf qu'il est remis à zéro chaque fois que le numéro de version majeure change.

Note : ceci est un vestige de Tcl. Avec perl, il est plus logique d'utiliser $Tk::VERSION décrit ci-dessus.
