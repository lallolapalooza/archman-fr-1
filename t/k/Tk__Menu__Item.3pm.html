NOM

Tk::Menu::Item - Classe de base pour les éléments de menu

SYNTAXE

require Tk::Menu::Item;
my $but = $menu->Button(...);
$but->configure(...);
my $what = $but->cget();
package Whatever;
require Tk::Menu::Item;
@ISA = qw(Tk::Menu::Item);
sub PreInit
{
 my ($class,$menu,$info) = @_;
 $info->{'-xxxxx'} = ...
 my $y = delete $info->{'-yyyy'};
}

DESCRIPTION

Tk::Menu::Item est la classe de base à partir de laquelle Tk::Menu::Button, Tk::Menu::Cascade, Tk::Menu::Radiobutton et Tk::Menu::Checkbutton sont dérivées. Il existe également un Tk::Menu::Separator.

Les constructeurs sont déclarés de telle sorte que $menu->Button(...) etc. fassent ce que vous attendez.

L'option "-label" est pré-traitée, permettant de préfixer ~ au caractère pour dériver une valeur "-underline". Ainsi,

$menu->Button(-label => 'Goto ~Home',...)
est équivalent à
$menu->Button(-label => 'Goto Home', -underline => 6, ...)

L'élément de menu "Cascade" crée un sous-menu et accepte les options suivantes :

-menuitems
Une liste d'éléments pour le sous-menu. Dans cette liste (qui est également acceptée par Menu et Menubutton), les deux premiers éléments de chaque élément doivent être le nom du « constructeur » et l'étiquette : 
-menuitems => [
               [Button      => '~Quit', -command => [destroy => $mw]],
               [Checkbutton => '~Oil',  -variable => \$oil],
              ]
-postcommand
Un rappel à exécuter avant de poster le menu.
-tearoff
Spécifie si le sous-menu peut être détaché ou non.
-menuvar
Un référence scalaire qui sera défini sur le sous-menu nouvellement créé.

L'objet retourné est actuellement une référence bénie vers un tableau de deux éléments : le Menu parent et l'« étiquette ». Les méthodes "configure" et "cget" sont mappées sur les méthodes sous-jacentes "entryconfigure" et "entrycget".

Le but principal de l'interface OO est de permettre la définition de classes d'éléments dérivées qui pré-configurent les options utilisées pour créer un élément plus basique.

BOGUES

Cette interface OO est très nouvelle. Utiliser l'étiquette comme « clé » pose problème pour les éléments séparateurs qui n'en ont pas. L'alternative serait d'utiliser un index dans le menu, mais cela pose problème si des éléments sont supprimés (ou insérés autre part qu'à la fin).

Il devrait probablement y avoir également un point d'entrée PostInit, ou une configuration différée plus proche de celle des widgets.
