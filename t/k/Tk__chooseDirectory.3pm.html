NOM

Tk::chooseDirectory - affiche une boîte de dialogue pour que l'utilisateur sélectionne un répertoire.

SYNTAXE

$widget->chooseDirectory( ?option valeur ...? );

DESCRIPTION

La méthode chooseDirectory est implémentée comme une enveloppe perl du "commande" noyau de tk tk_chooseDirectory, et $widget est passé comme argument à l'option cachée -parent.

La méthode chooseDirectory affiche une boîte de dialogue pour que l'utilisateur sélectionne un répertoire. Les paires option-valeur suivantes sont possibles en tant qu'arguments en ligne de commande :

-initialdir nom_répertoire
Spécifie que les répertoires dans répertoire doivent être affichés lorsque la boîte de dialogue apparaît. Si ce paramètre n'est pas spécifié, alors les répertoires du répertoire de travail courant sont affichés. Si le paramètre spécifie un chemin relatif, la valeur de retour convertira le chemin relatif en un chemin absolu. Cette option peut ne pas fonctionner toujours sur Macintosh. Ce n'est pas un bug. Plutôt, le panneau de contrôle General Controls sur Mac permet à l'utilisateur final de remplacer le répertoire par défaut de l'application.
-parent $widget
Fait de $widget le parent logique de la boîte de dialogue. La boîte de dialogue est affichée par-dessus la fenêtre de son parent.
-title chaîne_titre
Spécifie une chaîne à afficher comme titre de la boîte de dialogue. Si cette option n'est pas spécifiée, alors un titre par défaut sera affiché.
-mustexist booléen
Spécifie si l'utilisateur peut spécifier des répertoires inexistants. Si ce paramètre est vrai, alors l'utilisateur ne peut sélectionner que des répertoires qui existent déjà. La valeur par défaut est faux.

MISES EN GARDE

Perl n'a pas encore de concept de systèmes de fichiers encodés. Cela signifie que les opérations sur les noms de fichiers comme "opendir" et "open" utilisent toujours des sémantiques d'octets. Tk utilise cependant des sémantiques de caractères en interne, ce qui signifie que vous pouvez obtenir des noms de fichiers avec le drapeau UTF-8 défini dans des fonctions comme "chooseDirectory", "getOpenFile" et similaires. Il incombe à l'utilisateur de déterminer l'encodage du système de fichiers sous-jacent et de convertir le résultat en octets, par exemple :

use Encode;
...
my $dir = $mw->chooseDirectory;
$dir = encode("windows-1252", $dir);
opendir DIR, $dir or die $!;
...

Voir aussi « When Unicode Does Not Happen » dans perlunicode et « Unicode in Filenames » dans perltodo.

EXEMPLE

my $dir = $mw->chooseDirectory(-initialdir => '~',
                               -title => 'Choisir un répertoire');
if (!defined $dir) {
    warn 'Aucun répertoire sélectionné';
} else {
    warn "Sélectionné $dir";
}
