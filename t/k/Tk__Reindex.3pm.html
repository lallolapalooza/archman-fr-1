NOM

Tk::Reindex - changer l'index de base des widgets de type Text

SYNOPSIS

use Tk::ReindexedText;
$t1=$w->ReindexedText(-linestart => 2);
use Tk::ReindexedROText;
$t2=$w->ReindexedROText(-linestart => 0);

DESCRIPTION

Crée une nouvelle classe de widget basée sur les widgets de type Text qui peut redéfinir la base des numéros de ligne (normalement les widgets Text commencent la numérotation des lignes à 1), ou potentiellement d'autres manipulations d'index.

OPTIONS STANDARD

Le widget nouvellement défini accepte toutes les mêmes options que le widget de base, qui par défaut est Text.

OPTIONS SPÉCIFIQUES AU WIDGET

Nom : lineStart
Classe : LineStart
Commutateur : -linestart
Définit le numéro de ligne de la première ligne dans le widget Text. Les -toindexcmd et -fromindexcmd par défaut utilisent cette option de configuration.

- Nom de l'élément : toIndexCmd fromIndexCmd

- Classe de l'élément : ToIndexCmd FromIndexCmd

- Commutateur de l'élément : -toindexcmd -fromindexcmd

Ces deux options spécifient des rappels (callbacks) qui sont appelés avec une liste d'index et sont responsables de leur traduction vers/depuis des index que le widget Text de base peut comprendre. Le rappel reçoit le widget suivi d'une liste d'index, et doit retourner une liste d'index traduits. -toindexcmd doit traduire les index 'utilisateur' en index 'natifs' compatibles Text, et -fromindexcmd doit traduire les index 'natifs' en index 'utilisateur'.

Les rappels par défaut ajoutent/soustrait simplement le décalage donné par l'option -linestart pour tous les index au format 'ligne.caractère'.

Il serait probablement judicieux de rendre ces fonctions inverses l'une de l'autre.

MÉTHODES DE CLASSE

import
Pour créer de nouveaux widgets Reindex, cette fonction doit être appelée via use avec le nom de la classe de base de type Text que vous étendez avec la capacité "Reindex". 'use base(Tk::Reindex Tk::nameofbasewidget)' doit également être spécifié pour ce widget.

BOGUES

J'ai utilisé le mot "indexes" au lieu de "indices" dans toute la documentation.

Tout le code intégré pour les liaisons de widgets et les méthodes utilisera les nouveaux index 'utilisateur'. Ce qui signifie que toute cette manipulation d'index pourrait casser le code qui essaie d'analyser/manipuler les index. Ou même supposer que '1.0' est l'index de début. Tk::Text::Contents vient à l'esprit.
