NOM

Tk::Submethods - ajouter des alias pour les sous-commandes tk

SYNTAXE

use Tk::Submethods ( 'commande1' => [qw(sub1 sub2 sub3)],
                     'commande2' => [qw(sub1 sub2 sub3)]);

DESCRIPTION

Crée "->commandeSub(...)" comme un alias pour "->commande('sub',...)" par exemple "->grabRelease" pour "->grab('release')".

Pour chaque paire commande/sous-commande, cela crée une fermeture avec la commande et la sous-commande comme variables lexicales liées et assigne une référence à celle-ci à un 'glob' dans le package appelant.

Peut-être que les sous-commandes seront créées directement dans le code C un jour.
