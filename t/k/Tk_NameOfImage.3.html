NOM

Tk_NameOfImage - Retourne le nom d'une image.

SYNTAXE

#include <tk.h>

const char *
Tk_NameOfImage(imageMaster)

ARGUMENTS

Tk_ImageMaster imageMaster (entrée)
Jeton de l'image, qui a été passé au createProc du gestionnaire d'images lors de la création de l'image.

DESCRIPTION

Cette procédure est appelée par les gestionnaires d'images pour connaître le nom d'une image. Étant donné le jeton de l'image, elle retourne le nom sous forme de chaîne de caractères de l'image.

Tk_ImageModel est un synonyme de Tk_ImageMaster

MOTS-CLÉS

gestionnaire d'images, nom d'image

4.0 Tk
