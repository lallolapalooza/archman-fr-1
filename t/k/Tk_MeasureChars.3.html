Tk_MeasureChars(3)

Paquet: tk

Licences: TCL

Tk_MeasureChars(3) Procédures de la bibliothèque Tk Tk_MeasureChars(3)

NOM

Tk_MeasureChars, Tk_TextWidth, Tk_DrawChars, Tk_UnderlineChars - routines pour mesurer et afficher des chaînes simples monocatégorie.

SYNTAXE

#include <tk.h>

int
Tk_MeasureChars(tkfont, string, numBytes, maxPixels, flags, lengthPtr)

int
Tk_TextWidth(tkfont, string, numBytes)

Tk_DrawChars(display, drawable, gc, tkfont, string, numBytes, x, y)

Tk_UnderlineChars(display, drawable, gc, tkfont, string, x, y, firstByte, lastByte)

ARGUMENTS

Tk_Font tkfont (en entrée)
Jeton pour la police dans laquelle le texte doit être dessiné ou mesuré. Doit avoir été retourné par un appel précédent à Tk_GetFont.
const char *string (en entrée)
Texte à mesurer ou à afficher. N'a pas besoin d'être terminé par null. Tous les caractères non imprimables de la chaîne (tels que les tabulations, les sauts de ligne, et les autres caractères de contrôle) seront mesurés ou affichés de manière dépendante de la plateforme.
int numBytes (en entrée)
Nombre maximum d'octets à considérer lors de la mesure ou de l'affichage de string. Doit être supérieur ou égal à 0.
int maxPixels (en entrée)
Si maxPixels est >= 0, il spécifie la longueur maximale autorisée d'une ligne en pixels. Les caractères de string sont traités uniquement jusqu'à ce que ce nombre de pixels ait été couvert. Si maxPixels est < 0, alors la longueur de la ligne est illimitée et l'argument flags est ignoré.
int flags (en entrée)
Divers bits de drapeau OR-és ensemble : TK_PARTIAL_OK signifie inclure un caractère tant qu'une partie de celui-ci rentre dans la longueur donnée par maxPixels ; sinon, un caractère doit rentrer complètement pour être considéré. TK_WHOLE_WORDS signifie s'arrêter à une limite de mot, si possible. Si TK_AT_LEAST_ONE est défini, cela signifie retourner au moins un caractère même si aucun caractère n'a pu rentrer dans la longueur donnée par maxPixels. Si TK_AT_LEAST_ONE est défini et que TK_WHOLE_WORDS est également défini, cela signifie que si même pas un mot ne rentre sur la ligne, retourner les premières lettres du mot qui rentrait ; si pas même une lettre du mot ne rentrait, alors la première lettre sera quand même retournée.
int *lengthPtr (en sortie)
Rempli avec le nombre de pixels occupés par le nombre de caractères retournés comme résultat de Tk_MeasureChars.
Display *display (en entrée)
Affichage sur lequel dessiner.
Drawable drawable (en entrée)
Fenêtre ou pixmap dans lequel dessiner.
GC gc (en entrée)
Contexte graphique pour dessiner les caractères. La police sélectionnée dans ce GC doit être la même que tkfont.
int x, y (en entrée)
Coordonnées auxquelles placer le bord gauche de la ligne de base lors de l'affichage de string.
int firstByte (en entrée)
L'indice du premier octet du premier caractère à souligner dans la string. Le soulignement commence au bord gauche de ce caractère.
int lastByte (en entrée)
L'indice du premier octet du dernier caractère jusqu'auquel le soulignement sera dessiné. Le caractère spécifié par lastByte ne sera pas lui-même souligné.

DESCRIPTION

Ces routines servent à mesurer et afficher des chaînes simples, avec une seule police et sur une seule ligne. Pour mesurer et afficher du texte justifié, sur plusieurs lignes et avec une seule police, référez-vous à la documentation de Tk_ComputeTextLayout. Il n'y a pas d'interface de programmation dans le cœur de Tk qui supporte le texte multi-polices, multi-lignes ; le support de ce comportement doit être construit au-dessus des couches plus simples. Notez que les interfaces décrites ici sont orientées octets et non caractères, donc les valeurs d'indice provenant de scripts Tcl doivent être converties en décalages d'octets en utilisant Tcl_UtfAtIndex et les routines associées.

Un glyphe est l'image affichable d'une lettre, d'un nombre, ou d'un autre symbole. Tous les codes de caractères dans une police donnée n'ont pas de glyphe. Les caractères tels que les tabulations, les sauts de ligne/retours, et les caractères de contrôle qui n'ont pas de glyphe sont mesurés et affichés par ces procédures d'une manière dépendante de la plateforme ; sous X, ils sont remplacés par des séquences d'échappement barrées, tandis que sous Windows et Macintosh des boîtes creuses ou pleines peuvent être substituées. Référez-vous à la documentation de Tk_ComputeTextLayout pour une interface de programmation qui supporte l'expansion indépendante de la plateforme des caractères de tabulation en colonnes et des sauts de ligne/retours en texte multiligne.

Tk_MeasureChars est utilisé à la fois pour calculer la longueur d'une chaîne donnée et pour calculer combien de caractères d'une chaîne tiennent dans un espace donné. La valeur de retour est le nombre d'octets de string qui tiennent dans l'espace spécifié par maxPixels sous réserve des conditions décrites par flags. Si tous les caractères rentrent, la valeur de retour sera numBytes. *lengthPtr est rempli avec la largeur calculée, en pixels, de la partie de la chaîne qui a été mesurée. Par exemple, si la valeur de retour est 5, alors *lengthPtr est rempli avec la distance entre le bord gauche de string[0] et le bord droit de string[4].

Tk_TextWidth est une fonction enveloppe qui fournit une interface plus simple à la fonction Tk_MeasureChars. La valeur de retour est l'espace en pixels dont la string donnée a besoin.

Tk_DrawChars dessine la string à l'emplacement donné dans le drawable donné.

Tk_UnderlineChars souligne la plage de caractères donnée dans la string donnée. Elle ne dessine pas les caractères (qui sont supposés avoir été précédemment affichés par Tk_DrawChars) ; elle dessine simplement le soulignement. Cette procédure est utilisée pour souligner quelques caractères sans avoir à construire une police soulignée. Pour produire du texte nativement souligné, la police soulignée appropriée doit être construite et utilisée.
