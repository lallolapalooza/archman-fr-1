NOM

Tk::Labelframe - Créer et manipuler des widgets Labelframe

SYNOPSIS

$labelframe = $parent->Labelframe(?options?);

-borderwidth -highlightbackground -pady
-cursor      -highlightcolor      -relief
-font        -highlightthickness  -takefocus
-foreground  -padx                -text

OPTIONS SPÉCIFIQUES AU WIDGET

Option : -background
Nom : background
Classe : Background
Cette option est identique à l'option standard background, sauf que sa valeur peut également être spécifiée sous forme de chaîne vide. Dans ce cas, le widget n'affichera ni arrière-plan ni bordure, et aucune couleur ne sera consommée depuis sa table de couleurs pour son arrière-plan et sa bordure.
Option : -class
Nom : class
Classe : Class
Spécifie une classe pour la fenêtre. Cette classe sera utilisée lors de l'interrogation de la base de données d'options pour les autres options de la fenêtre, et elle sera également utilisée plus tard à d'autres fins telles que les liaisons. L'option class ne peut pas être modifiée avec la méthode configure.
Option : -colormap
Nom : colormap
Classe : Colormap
Spécifie une table de couleurs à utiliser pour la fenêtre. La valeur peut être soit new, auquel cas une nouvelle table de couleurs est créée pour la fenêtre et ses enfants, soit le nom d'une autre fenêtre (qui doit être sur le même écran et avoir le même visuel que $widget), auquel cas la nouvelle fenêtre utilisera la table de couleurs de la fenêtre spécifiée. Si l'option colormap n'est pas spécifiée, la nouvelle fenêtre utilise la même table de couleurs que son parent. Cette option ne peut pas être modifiée avec la méthode configure.
Option : -container
Nom : container
Classe : Container
La valeur doit être un booléen. Si vrai, cela signifie que cette fenêtre sera utilisée comme conteneur dans lequel une autre application sera intégrée (par exemple, un toplevel Tk peut être intégré à l'aide de l'option -use). La fenêtre prendra en charge les protocoles de gestionnaire de fenêtres appropriés pour des choses comme les demandes de géométrie. La fenêtre ne doit pas avoir d'enfants propres dans cette application. Cette option ne peut pas être modifiée avec la méthode configure.
Option : -height
Nom : height
Classe : Height
Spécifie la hauteur souhaitée pour la fenêtre sous l'une des formes acceptables par Tk_GetPixels. Si cette option est inférieure ou égale à zéro, la fenêtre ne demandera aucune taille du tout.
Option : -labelanchor
Nom : labelAnchor
Classe : LabelAnchor
Spécifie où placer l'étiquette. Une étiquette n'est affichée que si l'option -text n'est pas la chaîne vide. Les valeurs valides pour cette option sont (en les listant dans le sens horaire) nw, n, ne, en, e, es, se, s, sw, ws, w et wn. La valeur par défaut est nw.
Option : -labelwidget
Nom : labelWidget
Classe : LabelWidget
Spécifie un widget à utiliser comme étiquette. Cela remplace toute option -text. Le widget doit exister avant d'être utilisé comme -labelwidget et s'il n'est pas un descendant de cette fenêtre, il sera élevé au-dessus d'elle dans l'ordre d'empilement.
Option : -visual
Nom : visual
Classe : Visual
Spécifie les informations visuelles pour la nouvelle fenêtre sous l'une des formes acceptées par Tk_GetVisual. Si cette option n'est pas spécifiée, la nouvelle fenêtre utilisera le même visuel que son parent. L'option visual ne peut pas être modifiée avec la méthode configure.
Option : -width
Nom : width
Classe : Width
Spécifie la largeur souhaitée pour la fenêtre sous l'une des formes acceptables par Tk_GetPixels. Si cette option est inférieure ou égale à zéro, la fenêtre ne demandera aucune taille du tout.

DESCRIPTION

La méthode Labelframe crée une nouvelle fenêtre (donnée par l'argument $labelframe) et en fait un widget Labelframe. Des options supplémentaires, décrites ci-dessus, peuvent être spécifiées sur la ligne de commande ou dans la base de données d'options pour configurer des aspects du Labelframe tels que sa couleur d'arrière-plan et son relief.

Un Labelframe est un widget simple. Son objectif principal est de servir d'espaceur ou de conteneur pour des dispositions de fenêtres complexes. Il possède les fonctionnalités d'un Frame plus la capacité d'afficher une étiquette.

MÉTHODES DU WIDGET

La méthode Labelframe peut être utilisée pour invoquer diverses opérations sur le widget. Elle a la forme générale suivante :

$widget->method(?arg arg ...?);

Les méthodes suivantes sont possibles pour les widgets Labelframe :

$widget->cget(option);
Renvoie la valeur actuelle de l'option de configuration donnée par option. Option peut avoir n'importe laquelle des valeurs acceptées par la commande Labelframe.
$widget->configure(?option?, ?value, option, value, ...?);
Interroge ou modifie les options de configuration du widget. Si aucune option n'est spécifiée, renvoie une liste décrivant toutes les options disponibles pour $widget (voir Tk::configure pour des informations sur le format de cette liste). Si option est spécifiée sans value, alors la commande renvoie une liste décrivant l'option nommée (cette liste sera identique à la sous-liste correspondante de la valeur renvoyée si aucune option n'est spécifiée). Si une ou plusieurs paires option-valeur sont spécifiées, alors la commande modifie la ou les options du widget donné pour avoir la ou les valeurs données ; dans ce cas la commande renvoie une chaîne vide. Option peut avoir n'importe laquelle des valeurs acceptées par la commande Labelframe.

LIAISONS

Lorsqu'un nouveau Labelframe est créé, il n'a aucune liaison d'événement par défaut : les Labelframes ne sont pas destinés à être interactifs.
