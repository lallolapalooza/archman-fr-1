Tk::Event - Toolkit pour les Événements

SYNTAXE

use Tk::Event;
Tk::Event->fileevent(\*FH, 'readable' => callback);

$SIG{'INT'} = callback;

QueueEvent(callback [, position])

DESCRIPTION

C'est mieux que rien mais toujours difficile à utiliser. La plupart des scripts veulent un résultat de plus haut niveau (une ligne, un "bloc" de données, etc.)

Il m'est donc apparu que nous pouvions utiliser les TIEHANDLE nouveaux/récents ainsi :

my $obj = tie SOMEHANDLE,Tk::Event::IO;

while (<SOMEHANDLE>)
 {
 }

Alors la routine READLINE enregistre une fonction de rappel (callback) et ressemble à ceci :

sub READLINE
 {
  my $obj = shift;
  Event->io(*$obj,'readable',sub { sysread(*$obj,${*$obj},1,length(${*$obj}) });
  my $pos;
  while (($pos = index(${*$obj},$/) < 0)
   {
    DoOneEvent();
   }
  Event->io(*$obj,'readable',''); # désenregistrer
  $pos += length($/);
  my $result = substr(${*$obj},0,$pos);
  substr(${*$obj},0,$pos) = '';
  return $result;
 }

Ceci utilise la partie scalaire du glob représentant l'IO _interne_ comme un tampon dans lequel accumuler les caractères.
