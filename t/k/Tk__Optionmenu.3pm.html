NOM

Tk::Optionmenu - Permet à l'utilisateur de sélectionner une des valeurs d'option prédéfinies

SYNOPSIS

use Tk::Optionmenu;
$opt = $w->Optionmenu(
                    -options => RÉFÉRENCE_À_LISTE_OPTIONS,
                    -command => CALLBACK,
                    -variable => RÉF_SCALAIRE,
                    );
$opt->addOptions( LISTE_OPTIONS );
# LISTE_OPTIONS est
#   a)  $val1, $val2, $val3,...
#   b)  [ $lab1=>$val1], [$lab2=>val2], ... ]
#   c)  combinaison de a) et b), par exemple
#       val1, [$lab2=>val2], val3, val4, [...], ...

DESCRIPTION

Le widget Optionmenu permet à l'utilisateur de choisir parmi un ensemble d'options donné.

Si l'utilisateur doit pouvoir modifier les options disponibles, regardez du côté de Tk::BrowseEntry.

OPTIONS

-options
(Ré)initialise la liste des options présentées.
-command
Définit le rappel qui est invoqué lorsqu'une nouvelle option est sélectionnée.
-variable
Référence à un scalaire qui contient la valeur actuelle de l'option sélectionnée.
-textvariable
Référence à un scalaire qui contient le libellé de la valeur actuelle de l'option sélectionnée.

MÉTHODES

addOptions
Ajoute LISTE_OPTIONS aux options déjà disponibles.

EXEMPLE

use Tk;
my $mw = MainWindow->new();
my ($var, $tvar);
my $opt = $mw->Optionmenu(
       -options => [[jan=>1], [feb=>2], [mar=>3], [apr=>4]],
       -command => sub { print "a reçu : ", shift, "\n" },
       -variable => \$var,
       -textvariable => \$tvar
      )->pack;
$opt->addOptions([may=>5],[jun=>6],[jul=>7],[aug=>8]);
my $f = $mw->Frame(-relief=>'groove', -borderwidth => 2)->pack;
$f->Label(-textvariable=>\$tvar)->pack(-side => 'left');
$f->Label(-text => " -> ")->pack(-side => 'left');
$f->Label(-textvariable=>\$var)->pack(-side => 'left');
$mw->Button(-text=>'Quitter', -command=>sub{$mw->destroy})->pack;
MainLoop;

VOIR AUSSI

Tk::Menubutton, Tk::BrowseEntry
