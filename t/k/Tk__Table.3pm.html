NOM

Tk::Table - Tableau Tk de widgets 2D défilant

SYNTAXE

use Tk::Table;
$table = $parent->Table(-rows => nombre,
                        -columns => nombre,
                        -scrollbars => ancre,
                        -fixedrows => nombre,
                        -fixedcolumns => nombre,
                        -takefocus => booléen);
$widget = $table->Button(...);
$ancien = $table->put($ligne,$col,$widget);
$ancien = $table->put($ligne,$col,"Texte");  # simple Label
$widget = $table->get($ligne,$col);
$cols = $table->totalColumns;
$rows = $table->totalRows;
$table->see($widget);
$table->see($ligne,$col);
($ligne,$col) = $table->Posn($widget);

DESCRIPTION

Tk::Table est un gestionnaire de widgets/géométrie entièrement en Perl qui permet d'afficher un tableau 2D de widgets perl/Tk arbitraires.

Les entrées du tableau sont simplement des widgets perl/Tk ordinaires. Ils doivent être créés avec le Tableau comme parent. Les widgets sont positionnés dans le tableau en utilisant :

$table->put($ligne,$col,$widget)

Si $widget n'est pas une référence, il est traité comme une chaîne de caractères, et un widget Label est créé avec cette chaîne comme texte.

Tous les widgets de chaque colonne ont la même largeur - la largeur demandée du widget le plus large de la colonne. De même, tous les widgets de chaque ligne ont la même hauteur - la hauteur demandée du widget le plus haut de la ligne.

Un certain nombre de lignes et/ou de colonnes peuvent être marqués comme 'fixes' - et ainsi servir d'en-têtes' pour le reste des lignes qui sont défilantes.

La taille demandée du tableau dans son ensemble est telle que le nombre de lignes spécifié par -rows (par défaut 10) et le nombre de colonnes spécifié par -columns (par défaut 10) peuvent être affichés.

Si le Tableau peut recevoir le focus clavier, alors les touches curseur et de défilement font défiler les widgets affichés.

"-scrollbars". Par défaut, des barres de défilement seront ajoutées "nw". Pour désactiver les barres de défilement, définissez "-scrollbars" à une chaîne vide :

$table = $parent->Table(-scrollbars => '', ...);

Le tableau peut être vidé en utilisant

$table->clear

les widgets qui étaient dans le tableau sont détruits.

Le widget Tk::Table est dérivé d'un Tk::Frame, il hérite donc de toutes ses options de configuration.

Le parcours de focus par défaut ne donne le focus qu'au widget Tableau dans son ensemble. Pour activer le parcours de focus dans les cellules du tableau (par exemple, s'il y a des widgets d'entrée intégrés), alors l'option "-takefocus" doit être définie à 0.

BOGUES / PROBLÈMES / Améliorations possibles

  • Les très grands Tableaux consomment beaucoup de fenêtres X.
  • Pas d'équivalent aux options -anchor/-pad etc. de pack.

VOIR AUSSI

Tk::grid, Tk::HList, Tk::TableMatrix, Tk::MListbox, Tk::Columns
