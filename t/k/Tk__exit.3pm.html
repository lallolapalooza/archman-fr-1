NOM

Tk::exit - Termine l'application

SYNTAXE

use Tk qw(exit);
...
exit?(code_retour)?;

DESCRIPTION

Termine le processus, retournant code_retour au système comme statut de sortie. Si code_retour n'est pas spécifié, il vaut par défaut 0.

Si l'appel à "exit" provient de code invoqué via une fonction de rappel Tk, alors cette version Tk de "exit" nettoie de manière plus fiable que l'utilisation du "exit" de Perl.

CAVEATS

L'utilisation de "exit" à partir d'un processus issu d'un fork terminera à la fois le processus enfant et le processus parent. Comme "Tk::exit" est importé par défaut, il faut utiliser "CORE::exit" dans le processus issu du fork à la place.
