NOM

Tk_GetVRootGeometry - Obtenir la position et la taille de la racine virtuelle d'une fenêtre

SYNTAXE

#include <tk.h>

Tk_GetVRootGeometry(tkwin, xPtr, yPtr, widthPtr, heightPtr)

ARGUMENTS

Tk_Window tkwin (entrée)
Jeton de la fenêtre dont la racine virtuelle doit être interrogée.
int xPtr (sortie)
Pointe vers le mot dans lequel stocker le décalage x de la racine virtuelle.
int yPtr (sortie)
Pointe vers le mot dans lequel stocker le décalage y de la racine virtuelle.
int widthPtr (sortie)
Pointe vers le mot dans lequel stocker la largeur de la racine virtuelle.
int heightPtr (sortie)
Pointe vers le mot dans lequel stocker la hauteur de la racine virtuelle.

DESCRIPTION

Tk_GetVRootGeometry retourne des informations de géométrie sur la fenêtre racine virtuelle associée à tkwin. La racine virtuelle « associée » est celle dans laquelle l'ancêtre le plus proche de tkwin (ou tkwin lui-même s'il s'agit d'une fenêtre de niveau supérieur) a été reparenté par le gestionnaire de fenêtres. Cette fenêtre est identifiée par une propriété __SWM_ROOT ou __WM_ROOT placée sur la fenêtre de niveau supérieur par le gestionnaire de fenêtres. Si tkwin n'est pas associé à une racine virtuelle (par exemple, parce que le gestionnaire de fenêtres n'utilise pas de racines virtuelles), alors *xPtr et *yPtr seront mis à 0 et *widthPtr et *heightPtr seront mis aux dimensions de l'écran contenant tkwin.
