messageBox(3) Documentation Perl fournie par l'utilisateur messageBox(3)

NOM

Tk::messageBox - afficher une fenêtre de message et attendre la réponse de l'utilisateur.

SYNTAXE

    $response = $widget->messageBox(-option => valeur, ... );

DESCRIPTION

Cette méthode utilise Tk::Dialog pour créer rapidement plusieurs boîtes de dialogue courantes. Un widget de dialogue se compose d'un message, d'une icône et d'un ensemble de boutons (voir l'option -type). Une fois la fenêtre de message affichée, messageBox attend que l'utilisateur sélectionne l'un des boutons et retourne le texte du bouton (notez qu'il est préférable de vérifier la valeur retournée de manière insensible à la casse). NOTE : contrairement à Tk::Dialog qui crée son widget une fois et peut être utilisé plusieurs fois, la fenêtre messageBox est créée à chaque utilisation.

Les paires option/valeur suivantes sont prises en charge :

-default
Le nom symbolique sensible à la casse du bouton par défaut pour cette fenêtre de message ('Ok', 'Cancel', etc.). Voir -type pour une liste des noms symboliques. Si la boîte de message n'a qu'un seul bouton, il deviendra automatiquement le bouton par défaut, sinon si cette option n'est pas spécifiée, il n'y aura pas de bouton par défaut.
-icon
Spécifie une icône à afficher. Sur X11, n'importe quel bitmap Tk intégré peut être spécifié. Sous Windows, seuls error, info, question ou warning sont pris en charge.
-message
Spécifie le message à afficher.
-title
Spécifie une chaîne de caractères à afficher comme titre.
-type
Spécifie un ensemble prédéfini de boutons à afficher. Les valeurs suivantes sont possibles : 'AbortRetryIgnore', 'Ok', 'OkCancel', 'RetryCancel', 'YesNo' ou 'YesNoCancel'.

EXEMPLE

$response = $mw->messageBox(-icon => 'question', -message => 'Bonjour le monde !', -title => 'Mon titre', -type => 'AbortRetryIgnore', -default => 'Retry');
