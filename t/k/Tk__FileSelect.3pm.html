NOM

Tk::FileSelect - un widget pour choisir des fichiers

SYNTAXE

use Tk::FileSelect;
$FSref = $top->FileSelect(-directory => $start_dir);
              $top            - une référence de fenêtre, par ex. MainWindow->new
              $start_dir      - le point de départ pour FileSelect
$file = $FSref->Show;
              Exécute le sélecteur de fichiers jusqu'à ce qu'un nom de fichier soit
              accepté ou que l'utilisateur clique sur Annuler. Renvoie le nom du fichier
              ou une chaîne vide, respectivement, et démappe le
              FileSelect.
$FSref->configure(option => valeur[, ...])
              Veuillez consulter la sous-routine Populate car la liste de configuration
              change rapidement.

DESCRIPTION

Ce module affiche une boîte de dialogue de sélection de fichiers, avec une entrée de répertoire en haut, une liste de répertoires dans le répertoire actuel, une liste de fichiers dans le répertoire actuel, une entrée pour saisir/modifier un nom de fichier, un bouton d'acceptation et un bouton d'annulation.

Vous pouvez saisir un répertoire de départ dans l'entrée de répertoire. Après avoir appuyé sur Entrée, les boîtes de liste sont mises à jour. Un double clic sur un répertoire affiche son contenu respectif. Un simple clic sur un fichier le place dans l'entrée de fichier pour considération ultérieure, un double clic sur un fichier fait disparaître le sélecteur de fichiers et appelle la commande optionnelle avec le chemin complet du fichier sélectionné. Appuyer sur Entrée dans la boîte de sélection de fichiers ou appuyer sur le bouton d'acceptation fonctionnera également. *NOTE* la boîte de sélection de fichiers ne sera détruite que si le nom du fichier n'est pas vide. Si vous voulez vous en charger vous-même, modifiez le if(length(.. dans la sous-routine accept_file.

17.10.95, SOL, LUCC. lusol@Lehigh.EDU

  • Permettre l'acceptation des noms de fichiers ou de répertoires.
  • Exiger un double clic pour entrer dans un nouveau répertoire au lieu d'un simple clic. Cela permet à un simple clic de sélectionner un nom de répertoire afin qu'il puisse être accepté.
  • Ajouter l'option de liste -verify afin que les opérateurs de test de fichiers standard de Perl (comme -d et -x) puissent être spécifiés pour une validation nominale supplémentaire. La valeur par défaut est la valeur spéciale '!-d' (pas un répertoire), donc tout nom peut être sélectionné tant qu'il ne s'agit pas d'un répertoire - après tout, ceci EST FileSelect !

    Par exemple :

    $fs->configure(-verify => ['-d', [\&verify_code, $P1, $P2, ... $Pn]]);

    garantit que le nom sélectionné est un répertoire. De plus, si un élément de la liste est une référence de tableau, le premier élément est une référence de code vers une sous-routine et les éléments optionnels restants sont ses paramètres. La sous-routine est appelée comme suit :

    &verify_code($cd, $leaf, $P1, $P2, ... $Pn);

    où $cd est le répertoire courant, $leaf est un nom de répertoire ou de fichier, et $P1 .. $Pn sont vos paramètres optionnels. La sous-routine doit renvoyer TRUE en cas de succès ou FALSE en cas d'échec.

08.10.96 -- derf@ti.com :

À la demande de Jim Stern <js@world.northgrum.com> et Brad Vance <bvance@ti.com>, j'ai mis à jour les fonctions Accept et Show pour supporter la sélection de plusieurs fichiers. J'ai également corrigé une faute de frappe dans le code -verify.
