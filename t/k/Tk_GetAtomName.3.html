Tk_GetAtomName(3)

Paquet: tk

Licences: TCL

Tk_InternAtom(3) Procédures de la bibliothèque Tk Tk_InternAtom(3)

NOM

Tk_InternAtom, Tk_GetAtomName - gérer le cache des atomes X

SYNOPSIS

#include <tk.h>

Atom
Tk_InternAtom(tkwin, name)

const char *
Tk_GetAtomName(tkwin, atom)

ARGUMENTS

Tk_Window tkwin (en entrée)
Jeton de fenêtre. Utilisé pour mapper un atome ou un nom par rapport à un affichage spécifique.
const char *name (en entrée)
Nom de chaîne pour lequel l'atome est souhaité.
Atom atom (en entrée)
Atome pour lequel le nom de chaîne correspondant est souhaité.

DESCRIPTION

Ces procédures sont similaires aux procédures Xlib XInternAtom et XGetAtomName. Tk_InternAtom retourne l'identifiant d'atome associé à la chaîne donnée par name ; l'identifiant d'atome n'est valide que pour l'affichage associé à tkwin. Tk_GetAtomName retourne la chaîne associée à atom sur l'affichage de tkwin. La chaîne retournée par Tk_GetAtomName se trouve dans le stockage de Tk : l'appelant n'a pas besoin de libérer cet espace une fois qu'il a fini avec la chaîne, et l'appelant ne doit pas modifier le contenu de la chaîne retournée. S'il n'y a pas d'atome atom sur l'affichage de tkwin, alors Tk_GetAtomName retourne la chaîne “?bad atom?”.

Tk met en cache les informations retournées par Tk_InternAtom et Tk_GetAtomName afin que les appels futurs pour les mêmes informations puissent être traités depuis le cache sans contacter le serveur. Ainsi, Tk_InternAtom et Tk_GetAtomName sont généralement beaucoup plus rapides que leurs homologues Xlib, et ils devraient être utilisés à la place des procédures Xlib.
