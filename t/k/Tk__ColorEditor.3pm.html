NOM

Tk::ColorEditor - un éditeur de couleurs Tk à usage général

SYNOPSIS

use Tk::ColorEditor;
$cref = $mw->ColorEditor(-title => $title, -cursor => @cursor);
$cref->Show;

DESCRIPTION

ColorEditor est implémenté comme un objet avec diverses méthodes, décrites ci-dessous. D'abord, créez votre objet ColorEditor lors de l'initialisation du programme (un devrait suffire), puis configurez-le en spécifiant une liste de widgets Tk à coloriser. Lorsqu'il est temps d'utiliser l'éditeur, appelez la méthode Show().

ColorEditor permet une certaine personnalisation : vous pouvez modifier le menu d'attributs de couleur en ajoutant et/ou en supprimant des éléments de menu et/ou des séparateurs, activer ou désactiver la fenêtre d'état, modifier la liste des widgets de couleur du configurateur, ou même fournir votre propre rappel de configurateur de couleur personnalisé.

1.
Appelez le constructeur pour créer l'objet éditeur, qui retourne une référence bénie vers le nouvel objet : 
use Tk::ColorEditor;
$cref = $mw->ColorEditor(
    -title  => $title,
    -cursor => @cursor,
);
   mw     - une référence de fenêtre, généralement le résultat d'un appel
            MainWindow->new. En tant que racine par défaut d'un arbre de
            widgets, $mw et tous les widgets descendants au moment de la
            création de l'objet sont configurés par la procédure de
            configurateur de couleur par défaut. (Vous voudrez probablement
            changer cela cependant, sinon vous pourriez finir par coloriser
            ColorEditor !)
   title  - titre Toplevel, par défaut = ' '.
   cursor - une spécification de '-cursor' Tk valide (par défaut est
            'top_left_arrow'). Ce curseur est utilisé sur tous les "points
            chauds" de ColorEditor.
2.
Appelez la méthode configure() pour modifier les caractéristiques de l'éditeur : 
$cref->configure(-option => value, ..., -option-n => value-n);
   options:
     -command             : un rappel vers un remplacement de `set_colors'.
     -widgets             : une référence vers une liste de références de
                            widgets pour le configurateur de couleur.
     -display_status      : TRUE SI et SEULEMENT SI afficher la fenêtre d'état
                            de ColorEditor lors de l'application des couleurs.
     -add_menu_item       : 'SEP', ou un élément de menu d'attribut de couleur.
     -delete_menu_item    : 'SEP', un élément de menu d'attribut de couleur, ou
                            l'ordinal de l'attribut de couleur du menu.
Par exemple:
   $cref->configure(-delete_menu_item   => 3,
       -delete_menu_item   => 'disabledforeground',
       -add_menu_item      => 'SEP',
       -add_menu_item      => 'Nouvel attribut de couleur',
       -widgets            => [$ce, $qu, $f2b2],
       -widgets            => [$f2->Descendants],
       -command            => [\&my_special_configurator, some, args ]
   );
3.
Appelez la méthode Show() sur l'objet éditeur, par exemple, par un appui sur un bouton ou un menu : 
$cref->Show;
4.
La méthode cget(-widgets) retourne une référence vers une liste de widgets qui sont colorisés par le configurateur. Typiquement, vous ajoutez de nouveaux widgets à cette liste puis vous l'utilisez dans un appel configure() ultérieur pour étendre votre liste de couleurs. 
$cref->configure(
    -widgets => [
        @{$Filesystem_ref->cget(-widgets)}, @{$cref->cget(-widgets)},
    ]
);
5.
La méthode delete_widgets() attend une référence vers une liste de widgets qui sont ensuite supprimés de la liste de couleurs actuelle. 
$cref->delete_widgets($OBJTABLE{$objname}->{'-widgets'})
