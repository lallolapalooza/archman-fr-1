Tk_SetClass(3) Procédures de la bibliothèque Tk Tk_SetClass(3)

NOM

Tk_SetClass, Tk_Class - définir ou récupérer la classe d'une fenêtre

SYNOPSIS

#include <tk.h>

Tk_SetClass(tkwin, class)

Tk_Uid
Tk_Class(tkwin)

ARGUMENTS

Tk_Window tkwin (entrée)
Jeton de la fenêtre.
char *class (entrée)
Nouveau nom de classe pour la fenêtre.

DESCRIPTION

Tk_SetClass est appelée pour associer une classe à une fenêtre particulière. La chaîne de caractères class identifie le type de la fenêtre ; toutes les fenêtres ayant le même type général de comportement (bouton, menu, etc.) doivent avoir la même classe. Par convention, tous les noms de classe commencent par une lettre majuscule, et il existe une commande Tcl qui porte le même nom que chaque classe (sauf si tout est en minuscules) et qui peut être utilisée pour créer et manipuler des fenêtres de cette classe. La chaîne de classe d'une fenêtre est initialisée à NULL lors de la création de la fenêtre.

Pour les fenêtres principales, Tk propage automatiquement le nom et la classe à la propriété WM_CLASS utilisée par les gestionnaires de fenêtres. Cela se produit soit lorsque la fenêtre principale est effectivement créée (par exemple, dans Tk_MakeWindowExist), soit lorsque Tk_SetClass est appelée, selon ce qui se produit le plus tard. Si une fenêtre principale n'a pas reçu de classe, Tk ne définira pas la propriété WM_CLASS pour la fenêtre.

Tk_Class est une macro qui renvoie la valeur actuelle de la classe de tkwin. La valeur est renvoyée sous forme de Tk_Uid, qui peut être utilisé comme un pointeur de chaîne, mais qui possède également les propriétés d'un identifiant unique (voir la page de manuel de Tk_GetUid pour plus de détails). Si tkwin n'a pas encore reçu de classe, Tk_Class renverra NULL.
