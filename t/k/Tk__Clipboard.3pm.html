NOM

Tk::clipboard - Manipuler le presse-papiers Tk

SYNTAXE

$widget->clipboardOption?(args)?

DESCRIPTION

Cette commande fournit une interface au presse-papiers Tk, qui stocke des données pour une récupération ultérieure à l'aide du mécanisme de sélection. Afin de copier des données dans le presse-papiers, il faut appeler clipboardClear, suivi d'une séquence d'un ou plusieurs appels à clipboardAppend. Pour garantir que le presse-papiers soit mis à jour de manière atomique, toutes les ajoutes doivent être terminées avant de revenir à la boucle d'événements.

Les méthodes suivantes sont actuellement prises en charge :

$widget->clipboardClear
Revendique la propriété du presse-papiers sur l'affichage de $widget et supprime tout contenu précédent. Renvoie une chaîne vide.
$widget->clipboardAppend(?-format=>format?,?-type=>type?,?--?,data)
Ajoute data au presse-papiers sur l'affichage de $widget dans la forme donnée par type avec la représentation donnée par format et revendique la propriété du presse-papiers sur l'affichage de $widget.
Type spécifie la forme sous laquelle la sélection doit être renvoyée (la « cible » de conversion souhaitée, en terminologie ICCCM), et doit être un nom d'atome tel que STRING ou FILE_NAME ; consulter le Inter-Client Communication Conventions Manual pour plus de détails. Type a par défaut la valeur STRING.

L'argument format spécifie la représentation qui doit être utilisée pour transmettre la sélection au demandeur (la deuxième colonne du Tableau 2 de l'ICCCM), et a par défaut la valeur STRING. Si format est STRING, la sélection est transmise sous forme de caractères ASCII 8 bits. Consulter la documentation de Tk::Selection pour une explication de ce qui se passe si format n'est pas STRING. Noter que les arguments passés à clipboardAppend sont concaténés avant la conversion, le programme appelant doit donc prendre soin d'assurer des espaces appropriés entre les chaînes. Tous les éléments ajoutés au presse-papiers avec le même type doivent avoir le même format.

Un argument -- peut être spécifié pour marquer la fin des options : le prochain argument sera toujours utilisé comme data. Cette fonctionnalité peut être pratique si, par exemple, data commence par un -.

$widget->clipboardGet( ?-type? );
Récupère les données du presse-papiers sur l'affichage de widget. -type spécifie la forme sous laquelle les données doivent être renvoyées et doit être un nom d'atome tel que STRING ou FILE_NAME. Type a par défaut la valeur STRING. Cette commande est équivalente à "SelectionGet( -selection => 'CLIPBOARD' )".
