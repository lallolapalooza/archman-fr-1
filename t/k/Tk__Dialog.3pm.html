NOM

Tk::Dialog - Crée une boîte de dialogue modale et attend une réponse.

SYNTAXE

    $dialog = $parent->Dialog(-option => valeur, ... );

DESCRIPTION

Cette procédure fait partie de la bibliothèque de scripts Tk - ses arguments décrivent une boîte de dialogue. Après avoir créé une boîte de dialogue, Dialog attend que l'utilisateur sélectionne l'un des Boutons soit en cliquant sur le Bouton avec la souris, soit en tapant Entrée pour invoquer le Bouton par défaut (le cas échéant). Ensuite, elle renvoie la chaîne de texte du Bouton sélectionné.

En attendant la réponse de l'utilisateur, Dialog définit une capture locale. Cela empêche l'utilisateur d'interagir avec l'application de quelque manière que ce soit, sauf pour invoquer la boîte de dialogue. Voir la méthode Show().

OPTIONS

Les paires option/valeur suivantes sont prises en charge :

-title
Texte à afficher dans la barre de titre du gestionnaire de fenêtres pour la boîte de dialogue.
-text
Message à afficher dans la partie supérieure de la boîte de dialogue.
-bitmap
Si non vide, spécifie un bitmap à afficher dans la partie supérieure de la boîte de dialogue, à gauche du texte. Si ceci est une chaîne vide, aucun bitmap n'est affiché dans la boîte de dialogue.
-default_button
Chaîne de caractères du libellé du Bouton qui affiche l'anneau par défaut.
-buttons
Une référence à une liste de chaînes de caractères de libellés de Boutons. Chaque chaîne spécifie le texte à afficher dans un Bouton, dans l'ordre de gauche à droite.

MÉTHODES

$réponse = $dialog->Show(?-global?);
Cette méthode affiche la boîte de dialogue, attend la réponse de l'utilisateur et stocke la chaîne de texte du Bouton sélectionné dans $réponse. Si -global est spécifié, une capture globale (plutôt que locale) est effectuée.

La boîte de dialogue réelle est affichée à l'aide de la méthode Popup. Toutes les autres options fournies à Show sont passées à Popup et peuvent être utilisées pour positionner la boîte de dialogue à l'écran. Veuillez lire Tk::Popup pour plus de détails.

WIDGETS ANNONCÉS

Comme Tk::Dialog est une sous-classe de Tk::DialogBox, il hérite de tous les sous-widgets annoncés de sa superclasse : par exemple, "B_bouton-texte", où 'bouton-texte' est la valeur du -text d'un Bouton. De plus, Tk::Dialog annonce :

message
Le widget Label de la boîte de dialogue contenant le texte du message.
bitmap
Le widget Label de la boîte de dialogue contenant l'image bitmap.

EXEMPLE

$dialog = $mw->Dialog(-text => 'Sauvegarder le fichier ?', -bitmap => 'question', -title => 'Boîte de dialogue Sauvegarder le fichier', -default_button => 'Oui', -buttons => [qw/Oui Non Annuler/]);

MOTS_CLÉS

bitmap, boîte de dialogue, modale, messageBox
