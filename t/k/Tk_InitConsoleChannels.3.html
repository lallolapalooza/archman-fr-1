NOM

Tk_InitConsoleChannels - Installe les canaux de console comme canaux standards

SYNOPIS

#include <tk.h>

Tk_InitConsoleChannels(interp)

ARGUMENTS

Tcl_Interp *interp (entree)
Interpréteur dans lequel les canaux de console sont créés.

DESCRIPTION

Tk_InitConsoleChannels est appelée pour créer un ensemble de canaux de console et les installer comme canaux standards. Toutes les E/S sur ces canaux seront ignorées jusqu'à ce que Tk_CreateConsoleWindow soit appelée pour attacher la console à un widget texte.

Cette fonction est destinée à être utilisée par les applications shell basées sur Tk, comme wish, sur les plateformes qui n'ont pas de canaux standards en mode graphique, comme Win32.

L'argument interp est l'interpréteur dans lequel créer et installer les canaux de console.

NOTE : Si cette fonction est utilisée, elle doit être appelée avant le premier appel à Tcl_RegisterChannel, directement ou indirectement par d'autres fonctions de canal. Sinon, les canaux standards seront déjà initialisés avec les valeurs par défaut du système, ce qui sera absurde dans le cas pour lequel Tk_InitConsoleChannels est prévue.
