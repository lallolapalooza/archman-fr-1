NOM

Tk::TList — Créer et manipuler des widgets Tix Tabular List

SYNOPIS

    $tlist = $parent ->TList(?options?);

CLASSE SUPERIEURE

Aucune.

OPTIONS STANDARDS

-background -borderwidth -class -cursor -foreground -font -height -highlightcolor -highlightthickness -relief -selectbackground -selectforeground -xscrollcommand -yscrollcommand -width

Voir Tk::options pour plus de détails sur les options standards.

OPTIONS SPECIFIQUES AU WIDGET

Nom : browsecmd
Classe : BrowseCmd
Commutateur : -browsecmd
Spécifie un callback perl/Tk à exécuter lorsque l'utilisateur parcourt les entrées du widget TList.
Nom : command
Classe : Command
Commutateur : -command
Spécifie le callback perl/Tk à exécuter lorsque l'utilisateur déclenche une entrée de liste dans le widget TList. Normalement, l'utilisateur déclenche une entrée de liste en double-cliquant dessus ou en appuyant sur la touche Retour.
Nom : foreground
Classe : Foreground
Commutateur : -foreground
Alias : -fg
Spécifie la couleur de premier plan par défaut pour les entrées de liste.
Nom : height
Classe : Height
Commutateur : -height
Spécifie la hauteur souhaitée pour la fenêtre en nombre de caractères.
Nom : itemType
Classe : ItemType
Commutateur : -itemtype
Spécifie le type d'élément d'affichage par défaut pour ce widget TList. Lorsque vous appelez les méthodes insert, des éléments d'affichage de ce type seront créés si l'option -itemtype n'est pas spécifiée.
Nom : orient
Classe : Orient
Commutateur : -orient
Spécifie l'ordre de tabulation des entrées de liste. Lorsque réglé sur "vertical", les entrées sont disposées en colonne, de haut en bas. Si les entrées ne peuvent pas tenir dans une seule colonne, les entrées restantes iront dans la colonne suivante, et ainsi de suite. Lorsque réglé sur "horizontal", les entrées sont disposées en ligne, de gauche à droite. Si les entrées ne peuvent pas tenir dans une seule ligne, les entrées restantes iront dans la ligne suivante, et ainsi de suite.
Nom : padX
Classe : Pad
Commutateur : -padx
Le remplissage horizontal par défaut pour les entrées de liste.
Nom : padY
Classe : Pad
Commutateur : -padx
Le remplissage vertical par défaut pour les entrées de liste.
Nom : selectBackground
Classe : SelectBackground
Commutateur : -selectbackground
Spécifie la couleur d'arrière-plan pour les entrées de liste sélectionnées.
Nom : selectBorderWidth
Classe : BorderWidth
Commutateur : -selectborderwidth
Spécifie une valeur non négative indiquant la largeur de la bordure 3D à dessiner autour des éléments sélectionnés. La valeur peut avoir l'une des formes acceptées par Tk_GetPixels.
Nom : selectForeground
Classe : SelectForeground
Commutateur : -selectforeground
Spécifie la couleur de premier plan pour les entrées de liste sélectionnées.
Nom : selectMode
Classe : SelectMode
Commutateur : -selectmode
Spécifie l'un des plusieurs styles de manipulation de la sélection. La valeur de l'option peut être arbitraire, mais les liaisons par défaut s'attendent à ce qu'elle soit single, browse, multiple ou extended ; la valeur par défaut est single.
Nom : sizeCmd
Classe : SizeCmd
Commutateur : -sizecmd
Spécifie un callback perl/Tk à appeler chaque fois que le widget TList change de taille. Cette commande peut être utile pour implémenter des fonctionnalités de type "barres de défilement utilisateur au besoin".
Nom : state
Classe : State
Commutateur : -state
Spécifie si la commande TList doit réagir aux actions de l'utilisateur. Lorsqu'il est réglé sur "normal", le TList réagit aux actions de l'utilisateur de la manière normale. Lorsqu'il est réglé sur "disabled", le TList ne peut être défilé, mais ses entrées ne peuvent pas être sélectionnées ou activées.
Nom : width
Classe : Width
Commutateur : -width
Spécifie la largeur souhaitée pour la fenêtre en caractères.

DESCRIPTION

La méthode TList crée une nouvelle fenêtre (fournie par l'argument $widget) et la transforme en widget TList. Des options supplémentaires, décrites ci-dessus, peuvent être spécifiées en ligne de commande ou dans la base de données d'options pour configurer des aspects du widget TList tels que son curseur et son relief.

Le widget TList peut être utilisé pour afficher des données dans un format tabulaire. Les entrées de liste d'un widget TList sont similaires aux entrées du widget listbox de Tk. Les principales différences sont (1) le widget TList peut afficher les entrées de liste dans un format bidimensionnel et (2) vous pouvez utiliser des images graphiques ainsi que plusieurs couleurs et polices pour les entrées de liste.

Chaque entrée de liste est identifiée par un index, qui peut être sous les formes suivantes :

nombre
Un entier indiquant la position de l'entrée dans la liste. 0 signifie la première position, 1 la deuxième position, et ainsi de suite.
end

ÉLÉMENTS D'AFFICHAGE

Chaque entrée de liste dans un widget TList est associée à un élément d'affichage. L'élément d'affichage détermine quelles informations visuelles doivent être affichées pour cette entrée de liste. Veuillez consulter Tk::DItem pour une liste de tous les éléments d'affichage.

Lorsqu'une entrée de liste est créée par la commande insert, le type de son élément d'affichage est déterminé par l'option -itemtype passée à ces commandes. Si l'option -itemtype est omise, alors par défaut, le type spécifié par l'option -itemtype de ce widget TList est utilisé.

MÉTHODES DU WIDGET

La méthode TList crée un objet widget.

Cet objet prend en charge les méthodes configure et cget décrites dans Tk::options, qui peuvent être utilisées pour interroger et modifier les options décrites ci-dessus. Le widget hérite également de toutes les méthodes fournies par la classe générique Tk::Widget.

Les méthodes supplémentaires suivantes sont disponibles pour les widgets TList :

$tlist->anchorSet(index)
Définit l'ancre à l'entrée de liste identifiée par index. L'ancre est l'extrémité de la sélection qui est fixe lors du glisser-déposer avec la souris.
$tlist->anchorClear
Supprime l'ancre, le cas échéant, de ce widget TList. Ceci ne supprime que les surlignages de l'entrée d'ancre et n'affecte pas son état de sélection.
$tlist->delete(from, ?to?)
Supprime une ou plusieurs entrées de liste entre les deux entrées spécifiées par les indices from et to. Si to n'est pas spécifié, supprime l'unique entrée spécifiée par from.
$tlist->dragsiteSet(index)
Définit le site de glisser-déposer (dragsite) à l'entrée de liste identifiée par index. Le dragsite est utilisé pour indiquer la source d'une action de glisser-déposer. La fonctionnalité de glisser-déposer n'a pas encore été implémentée dans Tix.
$tlist->dragsiteClear
Supprime le site de glisser-déposer (dragsite), le cas échéant, de ce widget TList. Ceci ne supprime que les surlignages de l'entrée de dragsite et n'affecte pas son état de sélection.
$tlist->dropsiteSet(index)
Définit le site de dépôt (dropsite) à l'entrée de liste identifiée par index. Le dropsite est utilisé pour indiquer la cible d'une action de glisser-déposer. La fonctionnalité de glisser-déposer n'a pas encore été implémentée dans Tix.
$tlist->dropsiteClear
Supprime le site de dépôt (dropsite), le cas échéant, de ce widget TList. Ceci ne supprime que les surlignages de l'entrée de dropsite et n'affecte pas son état de sélection.
$tlist->entrycget(index, option)
Retourne la valeur actuelle de l'option de configuration donnée par option pour l'entrée identifiée par index. Option peut avoir l'une des valeurs acceptées par la méthode insert.
$tlist->entryconfigure(index, ?option?, ?value, option, value, ...?)
Interroge ou modifie les options de configuration de l'entrée de liste identifiée par index. Si aucune option n'est spécifiée, retourne une liste décrivant toutes les options disponibles pour index (voir Tk_ConfigureInfo pour des informations sur le format de cette liste). Si une option est spécifiée sans value, la méthode retourne une liste décrivant l'option nommée (cette liste sera identique à la sous-liste correspondante de la valeur retournée si aucune option n'est spécifiée). Si une ou plusieurs paires option-valeur sont spécifiées, la commande modifie les options données pour leur attribuer les valeurs données ; dans ce cas, la méthode retourne une chaîne vide. Option peut avoir l'une des valeurs acceptées par la méthode insert. L'ensemble exact des options dépend de la valeur de l'option -itemtype passée à la méthode insert lors de la création de cette entrée de liste.
$tlist->insert(index, ?option, value, ...?)
Crée une nouvelle entrée de liste à la position indiquée par index. Les options de configuration suivantes peuvent être fournies pour configurer l'entrée de liste :
-itemtype => type
Spécifie le type d'élément d'affichage à afficher pour la nouvelle entrée de liste. type doit être un type d'élément d'affichage valide. Actuellement, les types d'éléments d'affichage disponibles sont image, imagetext, text et $widget. Si cette option n'est pas spécifiée, alors par défaut, le type spécifié par l'option -itemtype de ce widget TList est utilisé.
-state => state
Spécifie si cette entrée peut être sélectionnée ou invoquée par l'utilisateur. Doit être normal ou disabled.
-data => data
Données arbitraires à associer à l'entrée (une valeur scalaire perl).

La méthode insert accepte des options de configuration supplémentaires pour configurer l'élément d'affichage associé à cette entrée de liste. L'ensemble des options de configuration supplémentaires dépend du type de l'élément d'affichage donné par l'option -itemtype. Veuillez consulter Tk::DItem pour une liste des options de configuration pour chacun des types d'éléments d'affichage.

$tlist->info(option, arg, ...)
Interroge des informations sur le widget TList. option peut être l'une des suivantes :
$tlist->info(anchor, index)
Retourne l'indice de l'ancre actuelle, le cas échéant, du widget TList. Si l'ancre n'est pas définie, retourne une chaîne vide.
$tlist->info(dragsite, index)
Retourne l'indice du site de glisser-déposer (dragsite) actuel, le cas échéant, du widget TList. Si le dragsite n'est pas défini, retourne une chaîne vide.
$tlist->info(dropsite, index)
Retourne l'indice du site de dépôt (dropsite) actuel, le cas échéant, du widget TList. Si le dropsite n'est pas défini, retourne une chaîne vide.
$tlist->info(selection)
Retourne une liste des éléments sélectionnés dans le widget TList. Si aucune entrée n'est sélectionnée, retourne une chaîne vide.
$tlist->nearest(x, y)
Étant donné une coordonnée (x,y) dans la fenêtre TList, cette commande retourne l'indice de l'élément TList le plus proche de cette coordonnée.
$tlist->see(index)
Ajuste la vue dans la TList afin que l'entrée donnée par index soit visible. Si l'entrée est déjà visible, la commande n'a aucun effet ; sinon, TList fait défiler pour amener l'élément dans la vue, au bord le plus proche.
$tlist->selection(option, arg, ...)
Cette commande est utilisée pour ajuster la sélection dans un widget TList. Elle a plusieurs formes, en fonction de option :
$tlist->selectionClear(?from?, ?to?)
Lorsque aucun argument supplémentaire n'est donné, désélectionne toutes les entrées de liste dans ce widget TList. Lorsque seul from est donné, seule l'entrée de liste identifiée par from est désélectionnée. Lorsque from et to sont tous deux donnés, désélectionne toutes les entrées de liste entre from et to, incluses, sans affecter l'état de sélection des entrées en dehors de cette plage.
$tlist->selectionIncludes(index)
Retourne 1 si l'entrée de liste indiquée par index est actuellement sélectionnée ; retourne 0 sinon.
$tlist->selectionSet(from, ?to?)
Sélectionne toutes les entrées de liste entre from et to, incluses, sans affecter l'état de sélection des entrées en dehors de cette plage. Lorsque seul from est donné, seule l'entrée de liste identifiée par from est sélectionnée.
$tlist->xview(args)
Cette commande est utilisée pour interroger et modifier la position horizontale des informations dans la fenêtre du widget. Elle peut prendre l'une des formes suivantes :
$tlist->xview
Retourne une liste contenant deux éléments. Chaque élément est une fraction réelle comprise entre 0 et 1 ; ensemble, ils décrivent la portée horizontale visible dans la fenêtre. Par exemple, si le premier élément est 0.2 et le second est 0.6, 20% de l'entrée TList est hors écran à gauche, les 40% du milieu sont visibles dans la fenêtre, et 40% de l'entrée sont hors écran à droite. Ce sont les mêmes valeurs qui sont passées aux barres de défilement via l'option -xscrollcommand.
$tlist->xview(index)
Ajuste la vue dans la fenêtre afin que l'entrée de liste identifiée par index soit alignée sur le bord gauche de la fenêtre.
$tlist->xviewMoveto(fraction)
Ajuste la vue dans la fenêtre afin que fraction de la largeur totale du TList soit hors écran à gauche. fraction doit être une fraction comprise entre 0 et 1.
$tlist->xviewScroll(number, what)
Cette commande décale la vue dans la fenêtre vers la gauche ou vers la droite en fonction de number et what. Number doit être un entier. What doit être soit units, soit pages, soit une abréviation de l'un de ceux-ci. Si what est units, la vue s'ajuste vers la gauche ou vers la droite de number unités de caractère (la largeur du caractère 0) à l'écran ; si c'est pages, la vue s'ajuste de number écrans. Si number est négatif, les caractères plus à gauche deviennent visibles ; s'il est positif, les caractères plus à droite deviennent visibles.
$tlist->yview(?args?)
Cette commande est utilisée pour interroger et modifier la position verticale des entrées dans la fenêtre du widget. Elle peut prendre l'une des formes suivantes :
$tlist->yview
Retourne une liste contenant deux éléments, tous deux étant une
re fractions réelles entre 0 et 1. Le premier élément donne la position de l'élément de la liste en haut de la fenêtre, par rapport à la TList dans son ensemble (0.5 signifie qu'il est à mi-chemin de la TList, par exemple). Le deuxième élément donne la position de l'entrée de la liste juste après la dernière dans la fenêtre, par rapport à la TList dans son ensemble. Ce sont les mêmes valeurs qui sont transmises aux barres de défilement via l'option -yscrollcommand.
$tlist->yview(index)
Ajuste la vue dans la fenêtre de sorte que l'entrée de la liste donnée par index soit affichée en haut de la fenêtre.
$tlist->yviewMoveto(fraction)
Ajuste la vue dans la fenêtre de sorte que l'entrée de la liste donnée par fraction apparaisse en haut de la fenêtre. Fraction est une fraction comprise entre 0 et 1 ; 0 indique la première entrée de la TList, 0.33 indique l'entrée située à un tiers de la TList, etc.
$tlist->yviewScroll(nombre, quoi)
Cette commande ajuste la vue dans la fenêtre vers le haut ou vers le bas en fonction de nombre et quoi. Nombre doit être un entier. Quoi doit être soit units soit pages. Si quoi est units, la vue s'ajuste vers le haut ou vers le bas de nombre lignes ; si c'est pages, la vue s'ajuste de nombre écrans. Si nombre est négatif, des entrées antérieures deviennent visibles ; s'il est positif, des entrées ultérieures deviennent visibles.

LIAISONS

[1]
Si -selectmode est "browse", lorsque l'utilisateur déplace le pointeur de la souris sur les entrées de la liste, l'entrée sous le pointeur sera mise en surbrillance et la procédure -browsecmd sera appelée avec un paramètre, l'index de l'entrée mise en surbrillance. Une seule entrée peut être mise en surbrillance à la fois. La procédure -command sera appelée lorsque l'utilisateur double-cliquera sur une entrée de la liste.
[2]
Si -selectmode est "single", les entrées ne seront mises en surbrillance que par les événements de souris <ButtonRelease-1>. Lorsqu'une nouvelle entrée de liste est mise en surbrillance, la procédure -browsecmd sera appelée avec un paramètre indiquant l'entrée de liste mise en surbrillance. La procédure -command sera appelée lorsque l'utilisateur double-cliquera sur une entrée de la liste.
[3]
Si -selectmode est "multiple", lorsque l'utilisateur déplace le pointeur de la souris sur les entrées de la liste, toutes les entrées sous le pointeur seront mises en surbrillance. Cependant, seule une région contiguë d'entrées de liste peut être sélectionnée. Lorsque la zone mise en surbrillance est modifiée, la procédure -browsecmd sera appelée avec un paramètre non défini. Il incombe à la procédure -browsecmd de trouver la sélection exactement mise en surbrillance dans la TList. La procédure -command sera appelée lorsque l'utilisateur double-cliquera sur une entrée de la liste.
[4]
Si -selectmode est "extended", lorsque l'utilisateur déplace le pointeur de la souris sur les entrées de la liste, toutes les entrées sous le pointeur seront mises en surbrillance. L'utilisateur peut également faire des sélections disjointes en utilisant <Control-ButtonPress-1>. Lorsque la zone mise en surbrillance est modifiée, la procédure -browsecmd sera appelée avec un paramètre non défini. Il incombe à la procédure -browsecmd de trouver la sélection exactement mise en surbrillance dans la TList. La procédure -command sera appelée lorsque l'utilisateur double-cliquera sur une entrée de la liste.

EXEMPLE

Cet exemple montre comment utiliser une TList pour stocker une liste de nombres :

use strict;
use Tk ();
use Tk::TList;
my $mw = Tk::MainWindow->new();
my $image = $mw->Getimage('folder');
my $tlist = $mw->TList(-orient => 'vertical');
for my $text ( qw/one two three four five six seven eight nine/ ) {
    $tlist->insert('end',
             -itemtype=>'imagetext', -image=>$image, -text=>$text);
}
$tlist->pack(-expand=>'yes', -fill=>'both');
Tk::MainLoop;
