NOM

Tk::IO - interface de haut niveau pour le mécanisme 'fileevent' de Tk

SYNOPSIS

my $fh = Tk::IO->new(-linecommand => callback, -childcommand => callback);
$fh->exec("command")
$fh->wait
$fh->kill

AVERTISSEMENT

LES INTERFACES DE CE MODULE PEUVENT CHANGER AU FUR ET À MESURE QUE L'IO DE PERL ÉVOLUE ET AVEC LE PORTAGE DE TK4.1

DESCRIPTION

Tk::IO est maintenant superposé à la classe IO::Handle de Perl. Les interfaces ont changé et sont toujours en évolution.

En théorie, les méthodes C qui activent l'IO non bloquante comme dans les versions précédentes de Tk-b* sont toujours là. Je ne les ai pas modifiées pour utiliser les informations de configuration supplémentaires de Perl, ni beaucoup testées.

On suppose que exec est utilisé pour créer un processus enfant et qu'un rappel (callback) est appelé chaque fois qu'une ligne complète arrive par le tuyau implicite.

"line" devrait probablement être défini en termes du séparateur d'enregistrement d'entrée de Perl mais ne l'est pas encore.

Le rappel -childcommand est appelé lorsqu'une fin de fichier se produit.

$fh->wait peut être utilisé pour attendre le processus enfant tout en traitant d'autres événements Tk.

$fh->kill peut être utilisé pour envoyer un signal au processus enfant.

BOGUES

Pas encore terminé. L'idée est d'utiliser "exec" pour émuler "system" de manière non bloquante.
