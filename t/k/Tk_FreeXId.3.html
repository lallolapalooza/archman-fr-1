Tk_FreeXId(3) Procédures de la bibliothèque Tk Tk_FreeXId(3)

NOM

Tk_FreeXId - rendre un identifiant de ressource X disponible pour réutilisation

SYNOPIS

#include <tk.h>

Tk_FreeXId(display, id)

ARGUMENTS

Display *display (in)
Affichage pour lequel id a été alloué.
XID id (in)
Identifiant de ressource X (fenêtre, police, pixmap, curseur, contexte graphique, ou palette de couleurs) qui n'est plus utilisé.

DESCRIPTION

L'allocateur par défaut pour les identifiants de ressources fourni par Xlib est très simple et ne permet pas la réutilisation des identifiants de ressources. Si une application de longue durée atteint la fin de l'espace d'identifiants de ressources, elle générera une erreur de protocole X et plantera. Tk remplace l'allocateur d'identifiants par défaut par son propre allocateur, qui permet la réutilisation des identifiants. Pour que cela fonctionne, Tk_FreeXId doit être appelé pour informer l'allocateur des ressources qui ont été libérées. Tk appelle automatiquement Tk_FreeXId chaque fois qu'il libère une ressource, donc si vous utilisez des procédures comme Tk_GetFont, Tk_GetGC, et Tk_GetPixmap, vous n'avez pas besoin d'appeler Tk_FreeXId. Cependant, si vous allouez des ressources directement depuis Xlib, par exemple en appelant XCreatePixmap, alors vous devriez appeler Tk_FreeXId lorsque vous appelez la procédure de libération Xlib correspondante, telle que XFreePixmap. Si vous n'appelez pas Tk_FreeXId, l'identifiant de ressource sera perdu, ce qui pourrait causer des problèmes si l'application s'exécute assez longtemps pour perdre tous les identifiants disponibles.
