NOM

Tk::Mwm - Communiquer avec le gestionnaire de fenêtres Motif(tm).

SYNOPIS

    use Tk::Mwm;

    $toplevel->mwmOption?(args)?

    $toplevel->mwm(option ?,args?)

DESCRIPTION

Interface vers des extensions spéciales prises en charge par mwm.

MÉTHODES

$toplevel->mwmDecoration?(?option??=>value? ?,...?)?
Lorsque aucune option n'est fournie, cette méthode renvoie les valeurs de toutes les options de décoration pour la fenêtre de premier niveau $toplevel. Lorsque seule une option est fournie sans spécifier la valeur, la valeur actuelle de cette option est renvoyée. Lorsque plusieurs paires "option-valeur" sont passées à cette méthode, les valeurs spécifiées seront attribuées aux options correspondantes. En conséquence, l'apparence des décorations Motif autour de la fenêtre de premier niveau sera modifiée. Les options possibles sont : -border, -menu, -maximize, -minimize, -resizeh et -title. La valeur doit être une valeur booléenne. Les valeurs renvoyées par cette commande sont indéfinies lorsque la fenêtre n'est pas gérée par mwm.
$toplevel->mwmIsmwmrunning
Cette valeur renvoyée est vraie si mwm est en cours d'exécution sur l'écran où se trouve la fenêtre spécifiée, faux sinon.
$toplevel->mwmProtocol
Lorsque aucune option supplémentaire n'est fournie, cette méthode renvoie tous les protocoles associés à cette fenêtre de premier niveau.
$toplevel->mwmProtocol(activate => protocol_name)
Active le message du protocole mwm dans le menu de mwm.
$toplevel->MwmProtocol(add => protocol_name, menu_message)
Ajoute un nouveau message de protocole mwm pour cette fenêtre de premier niveau. Le message est identifié par le nom de chaîne spécifié dans protocol_name. Un élément de menu sera ajouté au menu de mwm comme spécifié par menu_message. Une fois qu'un nouveau message de protocole mwm est ajouté à une fenêtre de premier niveau, il peut être intercepté par la méthode protocol de TK. Voici un exemple :

    $toplevel->mwmProtocol('add' => 'MY_PRINT_HELLO', '"Print Hello" _H Ctrl<Key>H');

    $toplevel->protocol('MY_PRINT_HELLO' => sub {print "Hello"});

$toplevel->mwmProtocol('deactivate' => protocol_name)
Désactive le message du protocole mwm dans le menu de mwm.
$toplevel->mwmProtocol('delete' => protocol_name)
Supprime le message du protocole mwm du menu de mwm. Veuillez noter que le gestionnaire de protocole du gestionnaire de fenêtres associé à ce protocole (par la méthode protocol) n'est pas supprimé automatiquement. Vous devez supprimer le descripteur de protocole explicitement. Par exemple :

    $mw->mwmProtocol('delete' => 'MY_PRINT_HELLO');

    $mw->protocol('MY_PRINT_HELLO' => '');

BOGUES

Il s'agit d'une extension Tix que perl/Tk a adoptée. Elle n'a pas été testée car l'auteur de perl/Tk n'a pas eu le temps d'installer un gestionnaire de fenêtres Motif.

Sur certaines versions de mwm, la bordure -border ne disparaîtra pas à moins que le redimensionnement -resizeh ne soit désactivé. De plus, le titre -title ne disparaîtra que si toutes les options -title, -menu, -maximize et -minimize sont désactivées.
