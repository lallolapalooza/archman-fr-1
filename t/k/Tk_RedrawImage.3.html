Tk_GetImage(3) Procédures de la bibliothèque Tk Tk_GetImage(3)

NOM

Tk_GetImage, Tk_RedrawImage, Tk_SizeOfImage, Tk_FreeImage - utiliser une image dans un widget

SYNOPSIS

#include <tk.h>

Tk_Image
Tk_GetImage(interp, tkwin, name, changeProc, clientData)

Tk_RedrawImage(image, imageX, imageY, width, height, drawable, drawableX, drawableY)

Tk_SizeOfImage(image, widthPtr, heightPtr)

Tk_FreeImage(image)

ARGUMENTS

Tcl_Interp *interp (entrée)
Endroit où laisser le message d'erreur.
Tk_Window tkwin (entrée)
Fenêtre dans laquelle l'image sera utilisée.
const char *name (entrée)
Nom de l'image.
Tk_ImageChangedProc *changeProc (entrée)
Procédure que Tk doit appeler chaque fois que le contenu ou la taille de l'image change.
ClientData clientData (entrée)
Valeur d'un mot à passer par Tk à changeProc.
Tk_Image image (entrée)
Jeton pour l'instance de l'image ; doit avoir été retourné par un appel précédent à Tk_GetImage.
int imageX (entrée)
Coordonnée X du coin supérieur gauche de la région de l'image à redessiner (mesurée en pixels à partir du coin supérieur gauche de l'image).
int imageY (entrée)
Coordonnée Y du coin supérieur gauche de la région de l'image à redessiner (mesurée en pixels à partir du coin supérieur gauche de l'image).
int width ((entrée))
Largeur de la région de l'image à redessiner.
int height ((entrée))
Hauteur de la région de l'image à redessiner.
Drawable drawable (entrée)
Où afficher l'image. Doit être soit la fenêtre spécifiée à Tk_GetImage, soit un pixmap compatible avec cette fenêtre.
int drawableX (entrée)
Où afficher l'image dans drawable : c'est la coordonnée x dans drawable où la coordonnée x imageX de l'image doit être affichée.
int drawableY (entrée)
Où afficher l'image dans drawable : c'est la coordonnée y dans drawable où la coordonnée y imageY de l'image doit être affichée.
int widthPtr (sortie)
Stocke la largeur de image (en pixels) ici.
int heightPtr (sortie)
Stocke la hauteur de image (en pixels) ici.

DESCRIPTION

Ces procédures sont appelées par les widgets qui souhaitent afficher des images. Tk_GetImage est appelée par un widget lorsqu'il décide pour la première fois d'afficher une image. name donne le nom de l'image désirée et tkwin identifie la fenêtre où l'image sera affichée. Tk_GetImage recherche l'image dans la table des images existantes et retourne un jeton pour une nouvelle instance de l'image. Si l'image n'existe pas, Tk_GetImage retourne NULL et laisse un message d'erreur dans le résultat de l'interpréteur interp.

Lorsqu'un widget souhaite effectivement afficher une image, il doit appeler Tk_RedrawImage, en identifiant l'image (image), une région dans l'image à redessiner (imageX, imageY, width, et height), et un endroit pour afficher l'image (drawable, drawableX, et drawableY). Tk appellera alors le gestionnaire d'images approprié, qui affichera la partie demandée de l'image avant de retourner.

Un widget peut connaître les dimensions d'une image en appelant Tk_SizeOfImage : la largeur et la hauteur seront stockées aux emplacements indiqués par widthPtr et heightPtr, respectivement.

Lorsqu'un widget a fini avec une image (par exemple, le widget est en cours de suppression ou il va utiliser une image différente au lieu de l'actuelle), il doit appeler Tk_FreeImage pour libérer l'instance de l'image. Le widget ne doit plus jamais utiliser le jeton de l'image après l'avoir passé à Tk_FreeImage. Il doit y avoir exactement un appel à Tk_FreeImage pour chaque appel à Tk_GetImage.

Si le contenu ou la taille d'une image change, tous les widgets utilisant l'image devront être informés des changements afin qu'ils puissent se redessiner. Les arguments changeProc et clientData de Tk_GetImage sont utilisés à cet effet. changeProc sera appelé par Tk chaque fois qu'un changement survient dans l'image ; il doit correspondre au prototype suivant :

typedef void Tk_ImageChangedProc(
        ClientData clientData,
        int x,
        int y,
        int width,
        int height,
        int imageWidth,
        int imageHeight);
L'argument clientData de changeProc est le même que l'argument clientData de Tk_GetImage. Il s'agit généralement d'un pointeur vers l'enregistrement du widget pour le widget ou une autre structure de données gérée par le widget. Les arguments x, y, width, et height identifient une région de l'image qui doit être redessinée ; ils sont spécifiés en pixels mesurés à partir du coin supérieur gauche de l'image. Les arguments imageWidth et imageHeight donnent la (nouvelle) taille de l'image.
