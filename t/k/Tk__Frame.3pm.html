Tk__Frame(3pm)

Paquet: perl-tk

Licences: PerlArtistic, GPL, custom

Frame(3) Documentation Perl fournie par l'utilisateur Frame(3)

NOM

Tk::Frame - Créer et manipuler des widgets Frame

SYNOPSIS

    $frame = $parent->Frame(?options?);

OPTIONS STANDARD

-borderwidth -highlightbackground -highlightthickness -takefocus -class -highlightcolor -relief -cursor

Voir Tk::options pour les détails des options standard.

OPTIONS SPÉCIFIQUES AU WIDGET

Nom: background
Classe: Background
Commutateur: -background
Cette option est identique à l'option standard background, sauf qu'elle peut aussi être spécifiée comme une valeur indéfinie. Dans ce cas, le widget n'affichera ni arrière-plan ni bordure, et aucune couleur ne sera consommée de sa palette pour son arrière-plan et sa bordure.
Nom: colormap
Classe: Colormap
Commutateur: -colormap
Spécifie une palette de couleurs à utiliser pour la fenêtre. La valeur peut être soit new, auquel cas une nouvelle palette est créée pour la fenêtre et ses enfants, soit le nom d'une autre fenêtre (qui doit être sur le même écran et avoir la même visualisation que $widget), auquel cas la nouvelle fenêtre utilisera la palette de l'autre fenêtre. Si l'option colormap n'est pas spécifiée, la nouvelle fenêtre utilise la même palette que sa parente. Cette option ne peut pas être modifiée avec la méthode configure.
Nom: container
Classe: Container
Commutateur: -container
La valeur doit être booléenne. Si vraie, cela signifie que cette fenêtre sera utilisée comme conteneur dans lequel une autre application sera intégrée (par exemple, une fenêtre de niveau supérieur Tk peut être intégrée en utilisant l'option -use). La fenêtre supportera les protocoles du gestionnaire de fenêtres appropriés pour les requêtes de géométrie, etc. La fenêtre ne doit pas avoir ses propres enfants dans cette application. Cette option ne peut pas être modifiée avec la méthode configure.
Nom: height
Classe: Height
Commutateur: -height
Spécifie la hauteur désirée pour la fenêtre dans n'importe quelle forme acceptable par Tk_GetPixels. Si cette option est inférieure ou égale à zéro, la fenêtre ne demandera aucune taille.
Nom: visual
Classe: Visual
Commutateur: -visual
Spécifie les informations de visualisation pour la nouvelle fenêtre dans n'importe quelle forme acceptable par Tk_GetVisual. Si cette option n'est pas spécifiée, la nouvelle fenêtre utilisera la même visualisation que sa parente. L'option visual ne peut pas être modifiée avec la méthode configure.
Nom: width
Classe: Width
Commutateur: -width
Spécifie la largeur désirée pour la fenêtre dans n'importe quelle forme acceptable par Tk_GetPixels. Si cette option est inférieure ou égale à zéro, la fenêtre ne demandera aucune taille.

DESCRIPTION

La méthode Frame crée une nouvelle fenêtre (fournie par l'argument $widget) et en fait un widget frame. Des options supplémentaires, décrites ci-dessus, peuvent être spécifiées sur la ligne de commande ou dans la base de données d'options pour configurer des aspects de la frame tels que sa couleur d'arrière-plan et son relief. La commande frame renvoie le nom de chemin de la nouvelle fenêtre.

Une frame est un widget simple. Son but principal est d'agir comme espaceur ou conteneur pour des mises en page de fenêtres complexes. Les seules caractéristiques d'une frame sont sa couleur d'arrière-plan et une bordure 3D optionnelle pour donner à la frame un aspect surélevé ou enfoncé.

MÉTHODES DE WIDGET

La méthode Frame crée un objet widget. Cet objet supporte les méthodes configure et cget décrites dans Tk::options qui peuvent être utilisées pour interroger et modifier les options décrites ci-dessus. Le widget hérite également de toutes les méthodes fournies par la classe générique Tk::Widget.

ASSOCIATIONS

Lorsqu'une nouvelle frame est créée, elle n'a pas d'associations d'événements par défaut : les frames ne sont pas destinées à être interactives.

MOTS-CLÉS

frame, widget
