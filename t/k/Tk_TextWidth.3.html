Paquet: tk

Tk_MeasureChars(3) Procédures de la bibliothèque Tk Tk_MeasureChars(3)

NOM

Tk_MeasureChars, Tk_TextWidth, Tk_DrawChars, Tk_UnderlineChars - routines pour mesurer et afficher de simples chaînes de caractères sur une seule ligne.

SYNOPIS

#include <tk.h>

int
Tk_MeasureChars(tkfont, string, numBytes, maxPixels, flags, lengthPtr)

int
Tk_TextWidth(tkfont, string, numBytes)

Tk_DrawChars(display, drawable, gc, tkfont, string, numBytes, x, y)

Tk_UnderlineChars(display, drawable, gc, tkfont, string, x, y, firstByte, lastByte)

ARGUMENTS

Tk_Font tkfont (entrée)
Jeton pour la police dans laquelle le texte doit être dessiné ou mesuré. Doit avoir été renvoyé par un appel précédent à Tk_GetFont.
const char *string (entrée)
Texte à mesurer ou à afficher. N'a pas besoin d'être terminé par null. Tous les caractères non imprimables dans la chaîne (tels que les tabulations, les sauts de ligne et autres caractères de contrôle) seront mesurés ou affichés de manière dépendant de la plateforme.
int numBytes (entrée)
Le nombre maximum d'octets à considérer lors de la mesure ou de l'affichage de string. Doit être supérieur ou égal à 0.
int maxPixels (entrée)
Si maxPixels est >= 0, il spécifie la longueur maximale autorisée de la ligne en pixels. Les caractères de string sont traités uniquement jusqu'à ce que ce nombre de pixels ait été couvert. Si maxPixels est < 0, alors la longueur de la ligne est illimitée et l'argument flags est ignoré.
int flags (entrée)
Divers bits de drapeaux combinés par OR : TK_PARTIAL_OK signifie inclure un caractère tant qu'une partie de celui-ci rentre dans la longueur donnée par maxPixels ; sinon, un caractère doit tenir complètement pour être pris en compte. TK_WHOLE_WORDS signifie s'arrêter à une frontière de mot, si possible. Si TK_AT_LEAST_ONE est défini, cela signifie renvoyer au moins un caractère même si aucun caractère ne rentre dans la longueur donnée par maxPixels. Si TK_AT_LEAST_ONE est défini et TK_WHOLE_WORDS est également défini, cela signifie que si même un mot ne rentre pas sur la ligne, renvoyer les premières lettres du mot qui est rentré ; si même une lettre du mot ne rentre pas, alors la première lettre sera toujours renvoyée.
int *lengthPtr (sortie)
Rempli avec le nombre de pixels occupés par le nombre de caractères renvoyé comme résultat de Tk_MeasureChars.
Display *display (entrée)
Affichage sur lequel dessiner.
Drawable drawable (entrée)
Fenêtre ou pixmap dans laquelle dessiner.
GC gc (entrée)
Contexte graphique pour dessiner les caractères. La police sélectionnée dans ce GC doit être la même que tkfont.
int x, y (entrée)
Coordonnées auxquelles placer le bord gauche de la ligne de base lors de l'affichage de string.
int firstByte (entrée)
L'index du premier octet du premier caractère à souligner dans string. Le soulignement commence au bord gauche de ce caractère.
int lastByte (entrée)
L'index du premier octet du dernier caractère jusqu'auquel le soulignement sera dessiné. Le caractère spécifié par lastByte ne sera pas souligné lui-même.

DESCRIPTION

Ces routines servent à mesurer et afficher de simples chaînes de caractères sur une seule police et une seule ligne. Pour mesurer et afficher du texte justifié sur une seule police et plusieurs lignes, référez-vous à la documentation de Tk_ComputeTextLayout. Il n'existe pas d'interface de programmation dans le cœur de Tk qui prenne en charge le texte multi-polices et multi-lignes ; la prise en charge de ce comportement doit être construite par-dessus des couches plus simples. Notez que les interfaces décrites ici sont orientées octets et non caractères, de sorte que les valeurs d'index provenant des scripts Tcl doivent être converties en décalages d'octets en utilisant Tcl_UtfAtIndex et les routines associées.

Un glyphe est l'image affichable d'une lettre, d'un nombre ou d'un autre symbole. Tous les codes de caractères d'une police donnée n'ont pas de glyphe. Les caractères tels que les tabulations, les sauts de ligne/retours chariot, et les caractères de contrôle qui n'ont pas de glyphe sont mesurés et affichés par ces procédures d'une manière dépendante de la plateforme ; sous X, ils sont remplacés par des séquences d'échappement barrées, tandis que sous Windows et Macintosh, des boîtes creuses ou pleines peuvent être substituées. Référez-vous à la documentation de Tk_ComputeTextLayout pour une interface de programmation qui prend en charge l'expansion indépendante de la plateforme des caractères de tabulation en colonnes et des sauts de ligne/retours chariot en texte multi-lignes.

Tk_MeasureChars est utilisé à la fois pour calculer la longueur d'une chaîne donnée et pour calculer combien de caractères d'une chaîne tiennent dans un espace donné. La valeur de retour est le nombre d'octets de string qui tiennent dans l'espace spécifié par maxPixels sous réserve des conditions décrites par flags. Si tous les caractères rentrent, la valeur de retour sera numBytes. *lengthPtr est rempli avec la largeur calculée, en pixels, de la partie de la chaîne qui a été mesurée. Par exemple, si la valeur de retour est 5, alors *lengthPtr est rempli avec la distance entre le bord gauche de string[0] et le bord droit de string[4].

Tk_TextWidth est une fonction enveloppe qui fournit une interface plus simple à la fonction Tk_MeasureChars. La valeur de retour est l'espace en pixels dont la chaîne donnée string a besoin.

Tk_DrawChars dessine la chaîne string à l'emplacement donné dans le drawable spécifié.

Tk_UnderlineChars souligne la plage de caractères donnée dans la chaîne string. Elle ne dessine pas les caractères (qui sont supposés avoir été précédemment affichés par Tk_DrawChars) ; elle dessine uniquement le soulignement. Cette procédure est utilisée pour souligner quelques caractères sans avoir à construire une police soulignée. Pour produire du texte naturellement souligné, la police soulignée appropriée doit être construite et utilisée.
