NOM

Tk_DrawFocusHighlight - dessiner l'anneau de mise en évidence de parcours pour un widget

SYNTAXE

#include <tk.h>

Tk_DrawFocusHighlight(tkwin, gc, width, drawable)

ARGUMENTS

Tk_Window tkwin (en entrée)
Fenêtre pour laquelle la mise en évidence est dessinée. Utilisée pour récupérer les dimensions de la fenêtre, entre autres choses.
GC gc (en entrée)
Contexte graphique à utiliser pour dessiner la mise en évidence.
int width (en entrée)
Largeur de l'anneau de mise en évidence, en pixels.
Drawable drawable (en entrée)
Dessinable dans lequel dessiner la mise en évidence ; généralement une pixmap hors écran pour le double tamponnage.

DESCRIPTION

Tk_DrawFocusHighlight est une procédure utilitaire qui dessine l'anneau de mise en évidence de parcours pour un widget. Elle est généralement invoquée par les widgets lors du réaffichage.

MOTS-CLÉS

focus, mise en évidence de parcours
