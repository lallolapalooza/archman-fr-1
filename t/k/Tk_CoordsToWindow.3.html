NOM

Tk_CoordsToWindow - Trouver la fenêtre contenant un point

SYNOPIS

#include <tk.h>

Tk_Window
Tk_CoordsToWindow(rootX, rootY, tkwin)

ARGUMENTS

int rootX (en)
Coordonnée X (en coordonnées de la fenêtre racine).
int rootY (en)
Coordonnée Y (en coordonnées de la fenêtre racine).
Tk_Window tkwin (en)
Jeton pour la fenêtre qui identifie l'application.

DESCRIPTION

Tk_CoordsToWindow localise la fenêtre qui contient un point donné. Le point est spécifié en coordonnées de la fenêtre racine avec rootX et rootY (si un gestionnaire de fenêtres à racine virtuelle est utilisé, alors rootX et rootY sont dans le système de coordonnées de la fenêtre racine virtuelle). La valeur de retour de la procédure est un jeton pour la fenêtre qui contient le point donné. Si le point n'est dans aucune fenêtre, ou si la fenêtre contenant le point n'appartient pas à la même application que tkwin, alors NULL est retourné.

La fenêtre contenant le point est décidée en utilisant les mêmes règles qui déterminent quelle fenêtre contient le curseur de la souris : si un parent et un enfant contiennent tous deux le point, alors l'enfant a la préférence, et si deux frères et sœurs contiennent tous deux le point, alors celui le plus haut dans l'ordre d'empilement (c'est-à-dire celui qui est visible à l'écran) a la préférence.
