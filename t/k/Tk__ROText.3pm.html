ROText(3) Documentation Perl fournie par l'utilisateur ROText(3)

NOM

Tk::ROText - widget Text Perl/Tk 'en lecture seule'

SYNOPIS

use Tk::ROText;
...
$ro = $mw->ROText(?options,...?);

DESCRIPTION

Ceci 'EST UN' widget texte avec toutes les liaisons retirées qui altéreraient le contenu du widget texte. Le contenu peut toujours être modifié via des appels de méthode.

LIAISONS

Seules les liaisons en lecture seule de Tk::Text sont disponibles dans Tk::ROText. De plus, les liaisons suivantes sont définies :

<espace>
Déplace le curseur d'un écran vers l'avant.
<Retour arrière>
Déplace le curseur d'un écran vers l'arrière.

MOTS-CLÉS

widget, texte, lecture seule
