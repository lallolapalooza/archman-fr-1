NOM

Créer et manipuler des widgets de liste hiérarchique Tix

SYNOPSIS

$hlist = $parent->HList(?options?);

OPTIONS STANDARD

-background -borderwidth -cursor -exportselection -foreground -font -height -highlightcolor -highlightthickness -relief -selectbackground -selectforeground -xscrollcommand -yscrollcommand -width

Voir Tk::options pour les détails des options standard.

DESCRIPTION

Le widget HList affiche une liste d'éléments dans une structure hiérarchique. Chaque élément de la liste peut avoir des enfants, qui seront affichés en retrait par rapport à l'élément parent. Les entrées HList sont identifiées par un chemin d'accès qui spécifie l'emplacement de l'entrée dans la hiérarchie.

La méthode HList de la classe Tk::widgets est utilisée pour créer un nouveau widget HList.

$hlist(?options?)
Crée un nouveau widget HList avec les options spécifiées.

MÉTHODES

$hlist->add(entryPath, ?options?);
Ajoute une nouvelle entrée sous le chemin spécifié par entryPath. Si entryPath est vide, l'entrée est ajoutée à la racine de la hiérarchie. La nouvelle entrée est identifiée par le chemin d'accès de son parent, suivi d'un slash, suivi du nom de la nouvelle entrée. Par exemple, si vous ajoutez une entrée nommée "foo" sous la racine, le chemin d'accès sera "/foo". Si vous ajoutez une entrée nommée "bar" sous "/foo", le chemin d'accès sera "/foo/bar".

Les options valides incluent celles de itemCreate ainsi que les suivantes :

-label
Le texte à afficher pour cette entrée. Si cette option est omise, le nom de l'entrée (la dernière partie de son chemin d'accès) sera utilisé comme étiquette.
-window
Une fenêtre enfant à associer à cette entrée. Cette fenêtre sera affichée à droite de l'étiquette de l'entrée.
$hlist->addchild(parentPath, ?options?);
Ajoute une nouvelle entrée sous l'entrée spécifiée par parentPath. C'est un raccourci pour add où entryPath est dérivé de parentPath.
$hlist->clear(?entryPath?);
Supprime toutes les entrées sous entryPath. Si entryPath est omis, toutes les entrées du widget HList sont supprimées.
$hlist->collapse(entryPath);
Plie l'entrée spécifiée par entryPath, de sorte que ses enfants ne soient plus visibles.
$hlist->cols(n);
Retourne le nombre de colonnes dans le widget HList.
$hlist->configure(?optionName?, ?value? ...);
Configure les options du widget HList. Voir OPTIONS STANDARD et OPTIONS SPÉCIFIQUES AU WIDGET.
$hlist->delete(entryPath);
Supprime l'entrée spécifiée par entryPath et tous ses enfants.
$hlist->depth(entryPath);
Retourne la profondeur de l'entrée spécifiée par entryPath.
$hlist->exists(entryPath);
Retourne vrai si l'entrée spécifiée par entryPath existe, faux sinon.
$hlist->expand(entryPath);
Développe l'entrée spécifiée par entryPath, de sorte que ses enfants soient visibles.
$hlist->header(?options?);
Crée une fenêtre d'en-tête au-dessus du widget HList. Les options valides sont les mêmes que pour les options standard du widget, plus les suivantes :

-itemcreate
Une référence de tableau spécifiant les options à utiliser lors de la création des éléments de l'en-tête. Le format est similaire à l'option -itemcreate du widget HList lui-même.

Si aucun argument n'est fourni, un nouveau widget d'en-tête vide est créé. Sinon, les options spécifiées sont utilisées pour configurer l'en-tête.

$hlist->info(option, ?entryPath?);
Retourne des informations sur le widget HList. Les options valides sont :

-rows
Retourne le nombre de lignes visibles dans le widget.
-width
Retourne la largeur du widget en pixels.
-height
Retourne la hauteur du widget en pixels.
-anchor
Retourne le point d'ancrage de l'entrée spécifiée par entryPath.
-bbox
Retourne la boîte englobante de l'entrée spécifiée par entryPath sous la forme (x y width height).
-depth
Retourne la profondeur de l'entrée spécifiée par entryPath.
-parent
Retourne le chemin d'accès de l'élément parent de l'entrée spécifiée par entryPath.
-text
Retourne le texte de l'entrée spécifiée par entryPath.
-window
Retourne la fenêtre enfant associée à l'entrée spécifiée par entryPath.
-imageline
Retourne le chemin d'accès de l'image de ligne de l'entrée spécifiée par entryPath.
-itemtype
Retourne le type d'élément de l'entrée spécifiée par entryPath.
-state
Retourne l'état de l'entrée spécifiée par entryPath (normal, disabled).
-underline
Retourne l'index du caractère de soulignement pour l'entrée spécifiée par entryPath.
$hlist->insert(entryPath, ?options?);
Similaire à add, mais insère la nouvelle entrée à une position spécifique dans la liste des enfants de son parent. L'option entryPath spécifie la position. Si entryPath commence par un slash, il est traité comme un chemin absolu.

Par exemple, $hlist->insert("/foo/bar", -label => "baz") insère une nouvelle entrée nommée "baz" comme enfant de "/foo", juste avant "/foo/bar".

$hlist->itemCreate(entryPath, ?options?);
Crée un nouvel élément dans le widget HList sous l'entrée spécifiée par entryPath. Les options valides sont :

-itemtype
Le type d'élément à créer (par exemple, text, bitmap, image, window). Le type par défaut est text.
-text
Le texte à afficher pour l'élément.
-bitmap
Le bitmap à afficher pour l'élément.
-image
L'image à afficher pour l'élément.
-window
La fenêtre enfant à afficher pour l'élément.
-underline
L'index du caractère à souligner dans le texte de l'élément.
-anchor
Le point d'ancrage de l'élément.
-side
Le côté où l'élément doit être placé (gauche ou droite).
-fill
Indique si l'élément doit remplir l'espace alloué (x, y, both, none).
-expand
Indique si l'élément doit s'étendre pour occuper l'espace supplémentaire.
$hlist->move(srcPath, destPath);
Déplace l'entrée spécifiée par srcPath vers destPath. Les enfants de srcPath seront également déplacés.
$hlist->see(entryPath);
Fait défiler le widget HList pour rendre l'entrée spécifiée par entryPath visible.
$hlist->set(entryPath, ?value?);
Définit la valeur de l'entrée spécifiée par entryPath. Si value est omis, la valeur actuelle est retournée.
$hlist->show(?entryPath?);
Affiche l'entrée spécifiée par entryPath. Si entryPath est omis, toutes les entrées visibles sont affichées. C'est l'inverse de la méthode hide.
$hlist->showPath(entryPath);
Développe récursivement toutes les entrées parents de entryPath pour le rendre visible.
Switch: -sizecmd
Spécifie un rappel Perl/Tk à exécuter chaque fois que le widget HList change de taille. Cette méthode peut être utile pour implémenter des fonctionnalités de type « barres de défilement utilisateur si nécessaire ».
Nom: separator
Classe: Separator
Switch: -separator
Spécifie le caractère à utiliser comme séparateur lors de l'interprétation des noms de chemin des entrées de la liste. Par défaut, le caractère « . » est utilisé.
Nom: width
Classe: Width
Switch: -width
Spécifie la largeur souhaitée pour la fenêtre en caractères.

DESCRIPTION

La méthode HList crée une nouvelle fenêtre (fournie par l'argument $widget) et en fait un widget HList. Des options supplémentaires, décrites ci-dessus, peuvent être spécifiées sur la ligne de commande ou dans la base de données d'options pour configurer des aspects du widget HList tels que son curseur et son relief.

Le widget HList peut être utilisé pour afficher des données ayant une structure hiérarchique, par exemple, des arbres de répertoires du système de fichiers. Les entrées de la liste sont indentées et connectées par des lignes de branche selon leur place dans la hiérarchie.

Chaque entrée de liste est identifiée par un entryPath. L'entryPath est une séquence de noms d'entrée séparés par le caractère séparateur (spécifié par l'option -separator). Un nom d'entrée peut être toute chaîne qui ne contient pas le caractère séparateur, ou une chaîne qui ne contient qu'un seul caractère séparateur.

Par exemple, lorsque « . » est utilisé comme caractère séparateur, « one.two.three » est l'entryPath d'une entrée de liste dont le parent est « one.two », dont le parent est « one », qui est une entrée de niveau supérieur (n'a pas de parent).

Autre exemple : « .two.three » est l'entryPath d'une entrée de liste dont le parent est « .two », dont le parent est « . », qui est une entrée de niveau supérieur.

ÉLÉMENTS D'AFFICHAGE

Chaque entrée de liste dans un widget HList est associée à un élément d'affichage (display item). L'élément d'affichage détermine quelles informations visuelles doivent être affichées pour cette entrée de liste. Veuillez consulter Tk::DItem pour une liste de tous les éléments d'affichage. Lorsqu'une entrée de liste est créée par les méthodes de widget itemCreate, add ou addchild, le type de son élément d'affichage est déterminé par l'option -itemtype passée à ces méthodes. Si l'option -itemtype est omise, alors par défaut le type spécifié par l'option -itemtype de ce widget HList est utilisé.

MÉTHODES DE WIDGET

La méthode HList crée un objet widget. Cet objet supporte les méthodes configure et cget décrites dans Tk::options, qui peuvent être utilisées pour interroger et modifier les options décrites ci-dessus. Le widget hérite également de toutes les méthodes fournies par la classe générique Tk::Widget.

Les méthodes supplémentaires suivantes sont disponibles pour les widgets HList :

$hlist->add($entryPath ?,option=>value, ...?)
Crée une nouvelle entrée de liste avec le chemin d'accès $entryPath. Une entrée de liste doit être créée après la création de son parent (sauf si cette entrée est une entrée de niveau supérieur, qui n'a pas de parent). Voir également « BUGS » ci-dessous. Cette méthode renvoie l'entryPath de la nouvelle entrée de liste créée. Les options de configuration suivantes peuvent être fournies pour configurer l'entrée de liste :
-at => position
Insère la nouvelle entrée de liste à la position donnée par position. position doit être un entier valide. La position 0 indique la première position, 1 indique la deuxième position, et ainsi de suite.
-after => afterWhich
Insère la nouvelle entrée de liste après l'entrée identifiée par afterWhich. afterWhich doit être une entrée de liste valide et elle doit avoir le même parent que la nouvelle entrée de liste.
-before => beforeWhich
Insère la nouvelle entrée de liste avant l'entrée identifiée par beforeWhich. beforeWhich doit être une entrée de liste valide et elle doit avoir le même parent que la nouvelle entrée de liste.
-data => string
Spécifie une chaîne à associer à cette entrée de liste. Cette chaîne peut être interrogée par la méthode info. Le programmeur d'application peut utiliser l'option -data pour associer l'entrée de liste aux données qu'elle représente.
-itemtype => type
Spécifie le type d'élément d'affichage à afficher pour la nouvelle entrée de liste. type doit être un type d'élément d'affichage valide. Les types d'éléments d'affichage actuellement disponibles sont imagetext, text, et $widget. Si cette option n'est pas spécifiée, alors par défaut le type spécifié par l'option -itemtype de ce widget HList est utilisé.
-state => state
Spécifie si cette entrée peut être sélectionnée ou invoquée par l'utilisateur. Doit être normal ou disabled.

La méthode add accepte des options de configuration supplémentaires pour configurer l'élément d'affichage associé à cette entrée de liste. L'ensemble des options de configuration supplémentaires dépend du type de l'élément d'affichage donné par l'option -itemtype. Veuillez consulter Tk::DItem pour une liste des options de configuration pour chacun des types d'éléments d'affichage.

$hlist->addchild($parentPath, ?option, value, ..., ?)
Ajoute une nouvelle entrée enfant à la liste des enfants de l'entrée de liste identifiée par $parentPath. Ou, si $parentPath est défini comme étant la chaîne vide, crée alors une nouvelle entrée de niveau supérieur. Le nom de la nouvelle entrée de liste sera un nom unique généré automatiquement par le widget HList. Généralement, si $parentPath est foo, alors l'entryPath de la nouvelle entrée sera foo.0, foo.1, etc. Cette méthode renvoie l'entryPath de la nouvelle entrée de liste créée. option peut être n'importe quelle option de la méthode add. Voir également « BUGS » ci-dessous.
$hlist->anchorSet($entryPath)
Définit l'ancre sur l'entrée de liste identifiée par $entryPath. L'ancre est l'extrémité de la sélection qui reste fixe pendant que l'utilisateur fait glisser la souris pour étendre une sélection.
$hlist->anchorClear
Supprime l'ancre, s'il y en a une, de ce widget HList. Ceci ne supprime que les surlignages autour de l'entrée d'ancre et n'affecte pas son statut de sélection.
$hlist->columnWidth($col?, -char?, ?width?)
Interroge ou définit la largeur de la colonne $col dans le widget HList. La valeur de $col est basée sur zéro : 0 représente la première colonne, 1 la deuxième, et ainsi de suite. Si aucun paramètre supplémentaire n'est fourni, renvoie la largeur actuelle de cette colonne (en nombre de pixels). Des paramètres supplémentaires peuvent être fournis pour définir la largeur de cette colonne :
$hlist->columnWidth($col, '')
Une chaîne vide indique que la largeur de la colonne doit être juste suffisante pour afficher l'élément le plus large dans cette colonne. Dans ce cas, la largeur de cette colonne peut changer suite à la modification de la taille des éléments de cette colonne.
$hlist->columnWidth($col, width)
width doit être dans un format accepté par Tk_GetPixels.
$hlist->columnWidth($col, -char, nChars)
La largeur est définie pour être la largeur moyenne occupée par nChars caractères de la police spécifiée par l'option -font de ce widget HList.
$hlist->delete(option, $entryPath)
Supprime une ou plusieurs entrées de liste. option peut être l'une des suivantes :
all
Supprime toutes les entrées de la HList. Dans ce cas, $entryPath n'a pas besoin d'être spécifié.
entry
Supprime l'entrée spécifiée par $entryPath et tous ses descendants, le cas échéant.
offsprings
Supprime tous les descendants, le cas échéant, de l'entrée spécifiée par $entryPath. Cependant, $entryPath lui-même n'est pas supprimé.
siblings
Supprime toutes les entrées de liste qui partagent le même parent que l'entrée spécifiée par $entryPath. Cependant, $entryPath lui-même n'est pas supprimé.
$hlist->dragsiteSet($entryPath)
Définit le site de glisser (dragsite) sur l'entrée de liste identifiée par $entryPath. Le dragsite est utilisé pour indiquer la source d'une action de glisser-déposer. La fonctionnalité de glisser-déposer n'a actuellement pas été implémentée dans Tix.
$hlist->dragsiteClear
Supprime le dragsite, s'il y en a un, de ce widget HList. Ceci ne supprime que les surlignages autour de l'entrée dragsite et n'affecte pas son statut de sélection.
$hlist->dropsiteSet($entryPath)
Définit le site de dépôt sur l'entrée de la liste identifiée par $entryPath. Le site de dépôt est utilisé pour indiquer la cible d'une action glisser-déposer. Actuellement, la fonctionnalité de glisser-déposer n'a pas encore été implémentée dans Tix.
$hlist->dropsiteClear
Supprime le site de dépôt, s'il existe, du widget HList. Ceci ne fait que supprimer les surlignages environnants de l'entrée du site de dépôt et n'affecte pas son état de sélection.
$hlist->entrycget($entryPath, option)
Retourne la valeur actuelle de l'option de configuration donnée par option pour l'entrée identifiée par $entryPath. Option peut avoir l'une des valeurs acceptées par la méthode add.
$hlist->entryconfigure($entryPath ?,option?, ?value=>option, ...?)
Interroge ou modifie les options de configuration de l'entrée de liste identifiée par $entryPath. Si aucune option n'est spécifiée, retourne une liste décrivant toutes les options disponibles pour $entryPath (voir Tk::options pour des informations sur le format de cette liste.) Si option est spécifiée sans value, alors la méthode retourne une liste décrivant l'option nommée unique (cette liste sera identique à la sous-liste correspondante de la valeur retournée si aucune option n'est spécifiée). Si une ou plusieurs paires option-valeur sont spécifiées, alors la méthode modifie l'option(s) donnée(s) pour avoir la (les) valeur(s) donnée(s) ; dans ce cas, la méthode retourne une chaîne vide. Option peut avoir l'une des valeurs acceptées par la méthode add ou addchild. L'ensemble exact des options dépend de la valeur de l'option -itemtype passée à la méthode add ou addchild lors de la création de cette entrée de liste.
$hlist->header(option, $col ?,args, ...?)
Manipule les éléments d'en-tête de ce widget HList. Si l'option -header de ce widget HList est définie à vrai, alors un élément d'en-tête est affiché en haut de chaque colonne. L'argument $col pour cette méthode doit être un entier valide. 0 indique la première colonne, 1 la deuxième colonne, ... et ainsi de suite. Cette méthode prend en charge les options suivantes :
$hlist->header(cget, $col, option)
Si la colonne $col possède un élément d'affichage d'en-tête, retourne la valeur de l'option spécifiée de l'élément d'en-tête. Si l'en-tête n'existe pas, retourne une erreur.
$hlist->header(configure, $col, ?option?, ?value, option, value, ...?)
Interroge ou modifie les options de configuration de l'élément d'affichage d'en-tête de la colonne $col. L'élément d'en-tête doit exister, sinon une erreur sera générée. Si aucune option n'est spécifiée, retourne une liste décrivant toutes les options disponibles pour l'élément d'affichage d'en-tête (voir Tk::options pour des informations sur le format de cette liste.) Si option est spécifiée sans value, alors la méthode retourne une liste décrivant l'option nommée unique (cette liste sera identique à la sous-liste correspondante de la valeur retournée si aucune option n'est spécifiée). Si une ou plusieurs paires option-value sont spécifiées, alors la méthode modifie l'option(s) donnée(s) pour avoir la (les) valeur(s) donnée(s) ; dans ce cas, la méthode retourne une chaîne vide. Option peut avoir l'une des valeurs acceptées par la méthode header create. L'ensemble exact des options dépend de la valeur de l'option -itemtype passée à la méthode header create lors de la création de cet élément d'affichage.
$hlist->header(create, $col, ?-itemtype type? ?option value ...?)
Crée un nouvel élément d'affichage comme en-tête pour la colonne $col. Voir aussi "BUGS" ci-dessous. Si un élément d'affichage d'en-tête existe déjà pour cette colonne, il sera remplacé par le nouvel élément. Un paramètre optionnel -itemtype peut être utilisé pour spécifier le type d'élément d'affichage à créer. Si -itemtype n'est pas donné, alors par défaut le type spécifié par l'option -itemtype de ce widget HList est utilisé. Des paramètres supplémentaires, sous forme de paires option-valeur, peuvent être passés pour configurer l'apparence de l'élément d'affichage. Chaque paire option-valeur doit être une option valide pour ce type d'élément d'affichage ou l'une des suivantes :
-borderwidth => color
Spécifie la largeur de la bordure de cet élément d'en-tête.
-headerbackground => color
Spécifie la couleur de fond de cet élément d'en-tête.
-relief => type
Spécifie le type de relief de la bordure de cet élément d'en-tête.
$hlist->header(delete, $col)
Supprime l'élément d'affichage d'en-tête pour la colonne $col.
$hlist->header(exists, $col)
Retourne vrai si un élément d'affichage d'en-tête existe pour la colonne $col ; sinon, retourne faux.
$hlist->header(size, $col)
Si un élément d'affichage d'en-tête existe pour la colonne $col, retourne sa taille en pixels dans une liste à deux éléments (width, height) ; retourne une erreur si l'élément d'affichage d'en-tête n'existe pas.
$hlist->hide(option ?,$entryPath?)
Rend certaines entrées invisibles sans les supprimer. Option peut être l'une des suivantes :
entry
Masque l'entrée de liste identifiée par $entryPath.

Actuellement, seule l'option entry est prise en charge. D'autres options seront ajoutées dans la prochaine version.

$hlist->indicator(option, $entryPath, ?args, ...?)
Manipule l'indicateur sur les entrées de liste. Un indicateur est généralement un petit élément d'affichage (tel qu'une image) qui est affiché à gauche d'une entrée pour indiquer l'état de cette entrée. Par exemple, il peut être utilisé pour indiquer si un répertoire est ouvert ou fermé. Option peut être l'une des suivantes :
$hlist->indicator(cget, $entryPath, option)
Si l'entrée de liste donnée par $entryPath a un indicateur, retourne la valeur de l'option spécifiée de l'indicateur. Si l'indicateur n'existe pas, retourne une erreur.
$hlist->indicator(configure, $entryPath, ?option?, ?value, option, value, ...?)
Interroge ou modifie les options de configuration de l'élément d'affichage de l'indicateur de l'entrée spécifiée par $entryPath. L'élément indicateur doit exister, sinon une erreur sera générée. Si aucune option n'est spécifiée, retourne une liste décrivant toutes les options disponibles pour l'élément d'affichage de l'indicateur (voir Tk::options pour des informations sur le format de cette liste). Si option est spécifiée sans value, alors la méthode retourne une liste décrivant l'option nommée unique (cette liste sera identique à la sous-liste correspondante de la valeur retournée si aucune option n'est spécifiée). Si une ou plusieurs paires option-value sont spécifiées, alors la méthode modifie l'option(s) donnée(s) pour avoir la (les) valeur(s) donnée(s) ; dans ce cas, la méthode retourne une chaîne vide. Option peut avoir l'une des valeurs acceptées par la méthode indicator create. L'ensemble exact des options dépend de la valeur de l'option -itemtype passée à la méthode indicator create lors de la création de cet élément d'affichage.
$hlist->indicator(create, $entryPath, ?, -itemtype type? ?option value ...?)
Crée un nouvel élément d'affichage comme indicateur pour l'entrée spécifiée par $entryPath. Si un élément d'affichage indicateur existe déjà pour cette entrée, il sera remplacé par le nouvel élément. Un paramètre optionnel -itemtype peut être utilisé pour spécifier le type d'élément d'affichage à créer. Si -itemtype n'est pas donné, alors par défaut le type spécifié par l'option -itemtype de ce widget HList est utilisé. Des paramètres supplémentaires, sous forme de paires option-valeur, peuvent être passés pour configurer l'apparence de l'élément d'affichage. Chaque paire option-valeur doit être une option valide pour ce type d'élément d'affichage.
$hlist->indicator(delete, $entryPath)
Supprime l'élément d'affichage indicateur pour l'entrée donnée par $entryPath.
$hlist->indicator(exists, $entryPath)
Retourne vrai si un élément d'affichage indicateur existe pour l'entrée donnée par $entryPath ; sinon, retourne faux.
$hlist->indicator(size, $entryPath)
Si un élément d'affichage indicateur existe pour l'entrée donnée par $entryPath, retourne sa taille dans une liste à deux éléments de la forme {width height} ; retourne une erreur si l'élément d'affichage indicateur n'existe pas.
$hlist->info(option, arg, ...)
Interroge des informations sur le widget HList. option peut être l'une des suivantes :
$hlist->info(anchor)
Retourne le chemin d'entrée de l'ancre actuelle, s'il y en a une, du widget HList. Si l'ancre n'est pas définie, retourne la chaîne vide.
$hlist->infoBbox($entryPath)

OPTIONS SPÉCIFIQUES AU WIDGET

-browsecmd ?cmd?
Commande à exécuter lorsque l'élément sélectionné change. L'élément sélectionné sera passé comme argument à la commande. Voir la section BINDINGS pour plus de détails.
-closecmd ?cmd?
Commande à exécuter lorsque le widget HList est détruit. Elle est appelée sans argument.
-command ?cmd?
Commande à exécuter lorsque l'utilisateur double-clique sur un élément. L'élément double-cliqué sera passé comme argument à la commande. Voir la section BINDINGS pour plus de détails.
-confine ?boolean?
Si cette option est activée, la fenêtre HList ne peut pas être déplacée au-delà des limites de la fenêtre parente.
-height ?amount?
Spécifie la hauteur du widget HList en lignes. La valeur par défaut est 10.
-hscrollcommand ?cmd?
Commande à exécuter lorsque le contenu du HList est défilé horizontalement. Elle est appelée avec une liste de deux chaînes, représentant les positions de début et de fin du contenu visible. Typiquement, cela est utilisé pour mettre à jour un widget de barre de défilement horizontal.
-itemtype ?type?
Spécifie le type des éléments de la liste. La valeur par défaut est "text". Les autres types possibles sont "bitmap", "image" et "window".
-padx ?amount?
Espace supplémentaire à ajouter horizontalement autour des éléments.
-pady ?amount?
Espace supplémentaire à ajouter verticalement autour des éléments.
-relief ?relief?
Spécifie le style de bordure du widget. Les valeurs possibles sont "flat", "groove", "raised", "ridge", "solid".
-selectmode ?mode?
Spécifie le mode de sélection. Les valeurs possibles sont "browse", "single", "multiple", "extended". La valeur par défaut est "browse".
-setfocus ?boolean?
Si défini à vrai, le widget HList recevra le focus lorsqu'il est cliqué.
-separator ?sepChar?
Le caractère séparateur utilisé pour construire les chemins d'éléments hiérarchiques. La valeur par défaut est ".".
-takefocus ?value?
Indique si le widget doit accepter le focus du clavier. La valeur par défaut est "true".
-width ?amount?
Spécifie la largeur du widget HList en caractères. La valeur par défaut est 10.
-xscrollcommand ?cmd?
Commande à exécuter lorsque le contenu du HList est défilé horizontalement. Elle est appelée avec une liste de deux chaînes, représentant les positions de début et de fin du contenu visible. Typiquement, cela est utilisé pour mettre à jour un widget de barre de défilement horizontal.
-yscrollcommand ?cmd?
Commande à exécuter lorsque le contenu du HList est défilé verticalement. Elle est appelée avec une liste de deux chaînes, représentant les positions de début et de fin du contenu visible. Typiquement, cela est utilisé pour mettre à jour un widget de barre de défilement vertical.

DESCRIPTION

Le widget Tk::HList est un widget de liste hiérarchique qui permet d'afficher des données sous forme d'arbre. Il prend en charge l'imbrication d'éléments, la sélection, et peut être lié à des barres de défilement.

ÉLÉMENTS D'AFFICHAGE

Chaque entrée dans un HList est composée d'un chemin d'accès et d'un ou plusieurs éléments d'affichage. Le chemin d'accès est une chaîne qui identifie de manière unique l'entrée dans la structure hiérarchique. Les éléments d'affichage sont ce qui est réellement visible à l'écran.

Le widget HList prend en charge plusieurs colonnes d'affichage. Chaque colonne peut avoir un type d'élément différent (texte, bitmap, image, fenêtre). Les éléments sont ajoutés à une entrée à l'aide de la méthode item.

$hlist->add(PATH, -opt => value, ...)
Ajoute une nouvelle entrée avec le chemin PATH. Si PATH est vide, une entrée racine est créée. Sinon, elle est ajoutée comme enfant du chemin spécifié par le séparateur.
$hlist->addchild(PATH, -opt => value, ...)
Ajoute une nouvelle entrée comme enfant du PATH spécifié.
$hlist->delete(PATH, ...)
Supprime les entrées spécifiées par PATH.
$hlist->exists(PATH)
Renvoie vrai si l'entrée PATH existe, faux sinon.
$hlist->info(PATH)
Renvoie une liste de valeurs associées à l'entrée PATH.
$hlist->item(PATH, -opt => value, ...)
Configure ou récupère les options d'un élément d'affichage associé à PATH.
$hlist->move(FROM, TO, ...)
Déplace les entrées spécifiées par FROM vers la position TO.
$hlist->movechild(PARENT, FROM, TO, ...)
Déplace les enfants de PARENT spécifiés par FROM vers la position TO.
$hlist->see(PATH)
Fait défiler le widget pour rendre l'entrée PATH visible.
$hlist->setfocus
Donne le focus au widget HList.
$hlist->setvalue(PATH, value)
Définit la valeur associée à l'entrée PATH.
$hlist->sourcelist(PATH, LIST)
Associe une liste d'éléments à l'entrée PATH.
$hlist->set(PATH, pos)
Définit la position de l'entrée PATH dans la liste de ses frères et sœurs.
$hlist->setchildren(PATH, ARRAY)
Définit les enfants de l'entrée PATH à partir du tableau ARRAY.
$hlist->setpivot(PATH)
Définit l'élément pivot pour l'expansion/réduction de la hiérarchie.

MÉTHODES DU WIDGET

Les méthodes suivantes contrôlent la vue du widget HList.

$hlist->xview(...)
Contrôle le défilement horizontal du widget.
$hlist->yview(...)
Contrôle le défilement vertical du widget.
$hlist->yview
Renvoie une liste contenant deux éléments, tous deux fractions réelles entre 0 et 1. Le premier élément donne la position de l'élément de liste en haut de la fenêtre, par rapport au HList dans son ensemble (0.5 signifie qu'il est à mi-chemin du HList, par exemple). Le second élément donne la position de l'entrée de liste juste après la dernière dans la fenêtre, par rapport au HList dans son ensemble. Ce sont les mêmes valeurs passées aux barres de défilement via l'option -yscrollcommand.
$hlist->yview($entryPath)
Ajuste la vue dans la fenêtre de sorte que l'entrée de liste donnée par $entryPath soit affichée en haut de la fenêtre.
$hlist->yview(moveto => fraction)
Ajuste la vue dans la fenêtre de sorte que l'entrée de liste donnée par fraction apparaisse en haut de la fenêtre. Fraction est une fraction entre 0 et 1 ; 0 indique la première entrée du HList, 0.33 indique l'entrée située un tiers du chemin dans le HList, et ainsi de suite.
$hlist->yview(scroll => nombre, quoi)
Cette méthode ajuste la vue dans la fenêtre vers le haut ou vers le bas en fonction de nombre et quoi. Nombre doit être un entier. Quoi doit être soit units soit pages. Si quoi est units, la vue s'ajuste vers le haut ou vers le bas de nombre lignes ; si c'est pages, la vue s'ajuste de nombre écrans. Si nombre est négatif, les entrées précédentes deviennent visibles ; s'il est positif, les entrées suivantes deviennent visibles.

LIAISONS

[1]
Si le -selectmode est "browse", lorsque l'utilisateur fait glisser le pointeur de la souris sur les entrées de la liste, l'entrée sous le pointeur sera mise en surbrillance et la commande -browsecmd sera appelée avec un paramètre, le chemin de l'entrée en surbrillance. Une seule entrée peut être en surbrillance à la fois. La commande -command sera appelée lorsque l'utilisateur double-clique sur une entrée de liste.
[2]
Si le -selectmode est "single", les entrées ne seront mises en surbrillance que par les événements <ButtonRelease-1> de la souris. Lorsqu'une nouvelle entrée de liste est mise en surbrillance, la commande -browsecmd sera appelée avec un paramètre indiquant l'entrée de liste mise en surbrillance. La commande -command sera appelée lorsque l'utilisateur double-clique sur une entrée de liste.
[3]
Si le -selectmode est "multiple", lorsque l'utilisateur fait glisser le pointeur de la souris sur les entrées de la liste, toutes les entrées sous le pointeur seront mises en surbrillance. Cependant, seule une région contiguë d'entrées de liste peut être sélectionnée. Lorsque la zone de surbrillance est modifiée, la commande -browsecmd sera appelée avec un paramètre indéfini. Il incombe à la commande -browsecmd de trouver la sélection exacte en surbrillance dans le HList. La commande -command sera appelée lorsque l'utilisateur double-clique sur une entrée de liste.
[4]
Si le -selectmode est "extended", lorsque l'utilisateur fait glisser le pointeur de la souris sur les entrées de la liste, toutes les entrées sous le pointeur seront mises en surbrillance. L'utilisateur peut également effectuer des sélections disjointes à l'aide de <Control-ButtonPress-1>. Lorsque la zone de surbrillance est modifiée, la commande -browsecmd sera appelée avec un paramètre indéfini. Il incombe à la commande -browsecmd de trouver la sélection exacte en surbrillance dans le HList. La commande -command sera appelée lorsque l'utilisateur double-clique sur une entrée de liste.
[5]
Liaisons des touches fléchées : La touche flèche <Up> déplace le point d'ancrage vers l'élément juste au-dessus de l'élément d'ancrage actuel. La touche flèche <Down> déplace le point d'ancrage vers l'élément juste en dessous de l'élément d'ancrage actuel. La touche flèche <Left> déplace l'ancre vers l'élément parent de l'élément d'ancrage actuel. La touche <Right> déplace l'ancre vers le premier enfant de l'élément d'ancrage actuel. Si l'élément d'ancrage actuel n'a pas d'enfants, il déplace l'ancre vers l'élément juste en dessous de l'élément d'ancrage actuel.

EXEMPLE

Cet exemple montre comment utiliser un HList pour stocker la structure d'un répertoire de fichiers et répondre aux événements de parcours de l'utilisateur :

use strict;
use Tk;
use Tk::Label;
use Tk::HList;
my $mw = MainWindow->new();
my $label = $mw->Label(-width=>15);
my $hlist = $mw->HList(
                    -itemtype   => 'text',
                    -separator  => '/',
                    -selectmode => 'single',
                    -browsecmd  => sub {
                              my $file = shift;
                              $label->configure(-text=>$file);
                           }
                    );
foreach ( qw(/ /home /home/ioi /home/foo /usr /usr/lib) ) {
    $hlist->add($_, -text=>$_);
}
$hlist->pack;
$label->pack;
MainLoop;

BOGUES

Le fait que l'élément d'affichage de la colonne 0 soit implicitement associé à toute l'entrée est probablement un bug de conception. Cela a été fait pour des raisons de compatibilité ascendante. Le résultat est un grand chevauchement entre la méthode item et les méthodes add, addchild, entrycget et entryconfigure. Chaque fois qu'il existe plusieurs colonnes, le programmeur ne devrait utiliser QUE la méthode item pour créer et configurer les éléments d'affichage dans chaque colonne ; les méthodes add, addchild, entrycget et entryconfigure ne devraient être utilisées QUE pour créer et configurer les entrées.
