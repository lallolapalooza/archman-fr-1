NOM

Tk::Panedwindow - Créer et manipuler des widgets Panedwindow

SYNTAXE

$panedwindow = $parent->Panedwindow(?options?);

-background    -height  -width
-borderwidth   -orient
-cursor        -relief

OPTIONS SP&#200;CIFIQUES AU WIDGET

Option: -handlepad
Nom: handlePad
Classe: HandlePad
Lors du traçage des poignées de réglage, spécifie la distance à partir de l'extrémité de la barre de réglage (selon l'orientation du widget) à laquelle la poignée doit être tracée. Peut être toute valeur acceptée par Tk_GetPixels.
Option: -handlesize
Nom: handleSize
Classe: HandleSize
Spécifie le côté de la taille d'une poignée de réglage. Les poignées sont toujours dessinées comme des carrés. Peut être toute valeur acceptée par Tk_GetPixels.
Option: -opaqueresize
Nom: opaqueResize
Classe: OpaqueResize
Spécifie si les panneaux doivent être redimensionnés lorsque la barre de réglage est déplacée (vrai), ou si le redimensionnement doit être différé jusqu'à ce que la barre de réglage soit placée (faux).
Option: -sashcursor
Nom: sashCursor
Classe: SashCursor
Curseur de souris à utiliser lorsque la souris survole une barre de réglage. S'il est nul, sb_h_double_arrow sera utilisé pour les panneaux à orientation horizontale et sb_v_double_arrow pour les panneaux à orientation verticale.
Option: -sashpad
Nom: sashPad
Classe: SashPad
Spécifie la quantité de marge à laisser de chaque côté d'une barre de réglage. Peut être toute valeur acceptée par Tk_GetPixels.
Option: -sashrelief
Nom: sashRelief
Classe: SashRelief
Relief à utiliser lors du dessin d'une barre de réglage. Peut être toute valeur de relief standard Tk.
Option: -sashwidth
Nom: sashWidth
Classe: SashWidth
Spécifie la largeur de chaque barre de réglage. Peut être toute valeur acceptée par Tk_GetPixels.
Option: -showhandle
Nom: showHandle
Classe: ShowHandle
Spécifie si les poignées de réglage doivent être affichées. Peut être toute valeur booléenne valide.

DESCRIPTION

La méthode Panedwindow crée une nouvelle fenêtre (donnée par l'argument $panedwindow) et en fait un widget Panedwindow. D'autres options, décrites ci-dessus, peuvent être spécifiées sur la ligne de commande ou dans la base d'options pour configurer des aspects du widget, tels que la couleur d'arrière-plan par défaut et le relief.

Un widget Panedwindow contient un nombre quelconque de panneaux, disposés horizontalement ou verticalement selon la valeur de l'option -orient. Chaque panneau contient un widget, et chaque paire de panneaux est séparée par une barre de réglage mobile (cette barre est déplacée par des mouvements de souris). Le déplacement d'une barre de réglage provoque le redimensionnement des widgets de chaque côté de la barre.

M&#201;THODES DU WIDGET

La méthode Panedwindow peut invoquer plusieurs opérations sur le widget. Elle a la forme générale suivante :

$widget->method(?arg arg ...?);

Les commandes suivantes sont possibles pour les widgets Panedwindow :

$widget->add(?window ...? ?option value ...?);
Ajoute une ou plusieurs fenêtres à un panneau Panedwindow, chacune dans un panneau différent. Les arguments consistent en le nom d'une ou plusieurs fenêtres suivis de paires d'arguments spécifiant comment gérer les fenêtres. Option peut avoir toute valeur acceptée par la sous-commande configure.
$widget->cget(option);
Renvoie la valeur actuelle de l'option de configuration donnée par option. Option peut avoir toute valeur acceptée par la commande Panedwindow.
$widget->configure(?option?, ?value, option, value, ...?);
Interroge ou modifie les options de configuration du widget. Si option n'est pas spécifié, une liste décrivant toutes les options disponibles pour $widget est renvoyée (voir Tk::configure pour des informations sur le format de cette liste). Si option est spécifié avec une valeur value seule, alors une liste décrivant l'option nommée est renvoyée (cette liste sera identique à la sous-liste correspondante de la valeur renvoyée si option n'est pas spécifié). Si une ou plusieurs paires option-valeur sont spécifiées, alors la commande modifie les options données dans le widget avec les valeurs données ; dans ce cas, la commande renvoie une chaîne vide. Option peut avoir toute valeur acceptée par la commande Panedwindow.
$widget->forget(?window ...?);
Supprime du Panedwindow le panneau qui contient $widget. Toutes les options de gestion de géométrie pour $widget seront oubliées.
$widget->identify(x, y);
Identifie le composant Panedwindow sous le point donné par x et y, dans les coordonnées de la fenêtre. Si le point se trouve sur une barre de réglage ou une poignée de réglage, le résultat est une liste à deux éléments contenant l'index de la barre de réglage ou de la poignée et un mot indiquant s'il s'agit d'une barre de réglage ou d'une poignée, comme [0, 'sash'] ou [2, 'handle']. Si le point se trouve sur toute autre partie du Panedwindow, le résultat est une liste vide.
$widget->proxy(?args?);
Cette commande est utilisée pour interroger et modifier la position du proxy, utilisé pour redimensionner les panneaux de style "rubberband". Elle peut prendre l'une des formes suivantes :
$widget->proxyCoord;
Renvoie une liste contenant les coordonnées x et y de la dernière position du proxy.
$widget->proxyForget;
Supprime le proxy de l'affichage.
$widget->proxyPlace(x, y);
Place le proxy aux coordonnées données par x et y.
$widget->sash(?args?);
Cette commande est utilisée pour interroger et modifier la position des barres de réglage dans le Panedwindow. Elle peut prendre l'une des formes suivantes :
$widget->sashCoord(index);
Renvoie les coordonnées x et y actuelles de la barre de réglage donnée par index. Index doit être un entier compris entre 0 et 1 moins que le nombre de panneaux dans le Panedwindow. Les coordonnées données sont celles du coin supérieur gauche de la zone contenant la barre de réglage. $widget->sashDragto(index, x, y) Cette commande calcule la différence entre les coordonnées données et les coordonnées données lors de la dernière commande sash coord pour la barre de réglage donnée. Elle déplace ensuite cette barre de la différence calculée. La valeur renvoyée est une chaîne vide.
$widget->sashMark(index, x, y);
Enregistre x et y pour la barre de réglage donnée par index ; utilisé conjointement avec les commandes ultérieures de dragto pour déplacer la barre de réglage.

$widget->sashPlace(index, x, y);
Place le sash donné par l'index aux coordonnées spécifiées.
$widget->panecget(option);
Récupère une option de gestion pour $widget. Option peut être n'importe quelle valeur acceptée par la sous-commande paneconfigure.
$widget->paneconfigure(?option? ?value option value ...?);
Récupère ou modifie les options de gestion pour $widget. Si option n'est pas spécifié, renvoie une liste décrivant toutes les options disponibles pour $widget (voir Tk::configure pour des informations sur le format de cette liste). Si option est spécifié sans value, renvoie une liste décrivant l'option nommée (cette liste sera identique à la sous-liste correspondante de la valeur renvoyée si option n'est pas spécifié). Si une ou plusieurs paires option-valeur sont spécifiées, la commande modifie les options du widget donné avec les valeurs fournies ; dans ce cas, elle renvoie une chaîne vide. Les options suivantes sont acceptées :
-after => $widget
Insère la fenêtre après la fenêtre spécifiée. $widget doit être le nom d'une fenêtre déjà gérée par $widget.
-before => $widget
Insère la fenêtre avant la fenêtre spécifiée. $widget doit être le nom d'une fenêtre déjà gérée par $widget.
-height => size
Définit une hauteur pour la fenêtre. La hauteur sera la dimension externe de la fenêtre incluant sa bordure, si elle existe. Si size est une chaîne vide ou si -height n'est pas spécifié, les dimensions demandées par la fenêtre seront utilisées initialement ; la hauteur peut être ajustée ultérieurement en déplaçant les sashs dans le Panedwindow. Size peut être toute valeur acceptée par Tk_GetPixels.
-minsize => n
Indique que la taille de la fenêtre ne peut pas être inférieure à n. Cette restriction n'affecte que la taille du widget dans la dimension paned — la dimension x pour les paned horizontaux, la dimension y pour les paned verticaux. Peut être toute valeur acceptée par Tk_GetPixels.
-padx => n
Définit une valeur non négative indiquant la quantité d'espace supplémentaire à laisser de chaque côté de la fenêtre dans la direction x. La valeur peut avoir l'un des formats acceptés par Tk_GetPixels.
-pady => n
Définit une valeur non négative indiquant la quantité d'espace supplémentaire à laisser de chaque côté de la fenêtre dans la direction y. La valeur peut avoir l'un des formats acceptés par Tk_GetPixels.
-sticky => style
Si le pane d'une fenêtre est plus grand que les dimensions demandées par la fenêtre, cette option peut être utilisée pour positionner (ou étirer) la fenêtre dans son pane. Style est une chaîne contenant 0 ou plusieurs des caractères n, s, e ou w. La chaîne peut éventuellement contenir des espaces ou des virgules, mais ils sont ignorés. Chaque lettre fait référence à une direction (nord, sud, est ou ouest) à laquelle la fenêtre est "accrochée". Si n et s (ou e et w) sont spécifiés, la fenêtre est étirée pour remplir toute la hauteur (ou largeur) de sa cavité.
-width => size
Définit une largeur pour la fenêtre. La largeur sera la dimension externe de la fenêtre incluant sa bordure, si elle existe. Si size est une chaîne vide ou si -width n'est pas spécifié, les largeurs demandées par la fenêtre seront utilisées initialement ; la largeur peut être ajustée ultérieurement en déplaçant les sashs dans le Panedwindow. Size peut être toute valeur acceptée par Tk_GetPixels.
$widget->panes;
Renvoie une liste ordonnée des widgets gérés par $widget.

RESIZING PANES

Un pane est redimensionné en tirant le sash (ou la barre de sash s'il y en a une) et en déplaçant la souris. Ceci est réalisé par les liaisons de mouvement du widget. Lorsqu'un sash est déplacé, les tailles des paned de chaque côté du sash, et donc les widgets dans ces paned, sont ajustées.

Lorsqu'un pane est redimensionné de l'extérieur (par exemple, il est packé pour s'étendre et remplir et le conteneur toplevel est redimensionné), de l'espace est ajouté à la fin (droite ou bas) du pane dans la fenêtre.

KEYWORDS
