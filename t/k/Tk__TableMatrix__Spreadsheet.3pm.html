NOM

Tk::TableMatrix::Spreadsheet - Affichage de table avec liaisons de type feuille de calcul.

SYNOPSIS

use Tk;
use Tk::TableMatrix::Spreadsheet;
my $t = $top->Scrolled('Spreadsheet',
  -rows => 21, -cols => 11, 
  -width => 6, -height => 6,
  -titlerows => 1, -titlecols => 1,
  -variable => $arrayVar,
  -selectmode => 'extended',
  -bg => 'white',
);

DESCRIPTION

Tk::TableMatrix::Spreadsheet est un widget dérivé de Tk::TableMatrix qui implémente certaines liaisons pour que le widget résultant se comporte davantage comme une feuille de calcul.

Liaisons ajoutées :

  • Des poignées de redimensionnement de lignes/colonnes apparaissent lorsque le curseur est placé sur une ligne de bordure de ligne/colonne dans la zone des titres de lignes/colonnes.

    Faire glisser ces poignées redimensionnera la ligne ou la colonne. Si plusieurs lignes ou colonnes sont sélectionnées, alors la nouvelle taille de ligne/colonne s'appliquera à toutes les lignes/colonnes sélectionnées.

    Note : Avec le Tk::TableMatrix de base, il est possible de redimensionner les lignes/colonnes en faisant glisser sur n'importe quelle bordure de cellule. Pour être plus semblable à une feuille de calcul, Tk::TableMatrix::Spreadsheet active par défaut le redimensionnement des lignes/colonnes uniquement via le glissement des titres de lignes/colonnes. Pour outrepasser ce comportement par défaut, définissez l'option -resizeborder à 'both' au démarrage.

  • Un menu contextuel pour insérer/supprimer des lignes/colonnes apparaît lorsque la souris est cliquée avec le bouton droit dans les zones des titres de lignes/colonnes.
  • Les cellules s'activent (c'est-à-dire que leur contenu devient éditable) uniquement lorsque la cellule est double-cliquée ou que la touche F2 est pressée. Le comportement par défaut de Tk::TableMatrix est que la cellule soit activée lors d'un clic simple.
  • La touche Échap annule les modifications apportées à une cellule et efface la sélection actuelle.
  • La touche Entrée fait descendre la cellule actuelle.
  • La touche Tab (ou Maj+Tab) déplace la cellule actuelle vers la droite (gauche).
  • La touche Suppr supprimera la sélection actuelle, si aucune cellule n'est active.
  • Le bouton 2 de la souris (bouton du milieu) colle à partir de PRIMARY. (Ctrl+V colle à partir du presse-papiers).

Informations supplémentaires

Les méthodes de widget, les options, etc., sont héritées du widget Tk::TableMatrix. Consultez sa documentation pour des informations supplémentaires.
