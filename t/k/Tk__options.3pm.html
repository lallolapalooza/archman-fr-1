NOM

Tk::options - Options standards supportées par les widgets et leur manipulation

SYNOPSIS

    $valeur = $widget->cget('-option');

    $widget->configure(-option=>valeur ?,-option=>valeur ...?);

    @liste = $widget->configure('-option');

    @lol = $widget->configure;

DESCRIPTION

Tous les widgets et images ont un mécanisme standard pour définir et interroger les attributs ou options. Le mécanisme repose sur deux méthodes : configure et cget. Le comportement de ces méthodes est le suivant :

$widget->configure(-option=>valeur ?,-option=>valeur ...?);
Définit les valeurs de -option à valeur pour chaque paire -option=>valeur. La méthode interne new effectue un configure implicite sous cette forme avec les options passées lors de la création du widget.
$widget->configure('-option')
En contexte de tableau, retourne une liste de cinq ou deux éléments. Si -option est un alias pour une autre option, elle retourne une liste constituée de l'option alias et du nom de l'option pour laquelle elle est un alias, par exemple "('-bg', 'background')". Si -option n'est pas un alias, la liste retournée a les cinq éléments suivants :
Nom de l'Option
La valeur de -option, par exemple, -background.
Nom
Le nom de l'option dans la base de données des options, par exemple, "background".
Classe
La valeur de classe de l'option dans la base de données des options, par exemple, "Background".
Défaut
La valeur par défaut pour l'option si elle n'est pas spécifiée ou dans la base de données des options, par exemple, "grey".
Valeur
La valeur actuelle (telle que retournée par cget), par exemple, "white".
$widget->configure
Retourne une liste de listes pour toutes les options supportées par $widget. Chaque sous-liste est sous la forme retournée par configure('-option'). (Ce mécanisme est utilisé par la classe Tk::Derived pour déterminer les options disponibles de la classe de base.)
$widget->cget('-option')
Retourne la valeur actuelle de -option pour $widget.

cget('-option') est maladroit avec la nécessité de '' en raison des règles d'analyse de Perl. Quelque chose de plus subtil utilisant `tie` pourrait être mieux.

Les paragraphes suivants décrivent les options de configuration communes supportées par les widgets de la boîte à outils Tk. Chaque widget ne supporte pas nécessairement toutes les options (voir les entrées de documentation pour les widgets individuels pour une liste des options standard supportées par ce widget), mais si un widget supporte une option avec l'un des noms listés ci-dessous, alors l'option a exactement l'effet décrit ci-dessous.

Dans les descriptions ci-dessous, « Nom » fait référence au nom de l'option dans la base de données des options. « Classe » fait référence à la valeur de classe de l'option dans la base de données des options. « Commutateur » fait référence au commutateur utilisé dans la création de widget et les méthodes de widget configure pour définir cette valeur. Par exemple, si l'option de configuration d'une option est -foreground et qu'il existe un widget $widget, alors l'appel :

    $widget->configure(-foreground=>'black')

peut être utilisé pour spécifier la valeur black pour l'option dans le widget $widget. Les options de configuration peuvent être abrégées, tant que l'abréviation est sans ambiguïté (l'abréviation est dépréciée dans perl/Tk).

Options de création : Nom et Classe du Widget

Les options Nom et -class ne peuvent être spécifiées que lors de la création d'un widget, et ne peuvent pas être modifiées avec configure. Ces options déterminent l'identité du widget et la manière dont Tk applique les valeurs de ressources de la base de données des options (voir Tk::option), et ne peuvent donc pas être assignées par la base de données des options.

Nom : nom
Commutateur : Name
Spécifie l'élément de chemin pour le widget. Les noms commencent généralement par une lettre minuscule.

Chaque widget a un chemin d'accès unique qui suit la hiérarchie de la MainWindow au widget lui-même. Étant donné que le PathName du widget est utilisé pour attribuer des options de la base de données des options, il est important de spécifier un Nom distinctif pour tout widget qui aura des options non par défaut. Voir Tk::option pour les détails.

Nom : classe
Commutateur : -class
Spécifie une classe pour la fenêtre. Les classes commencent généralement par une lettre majuscule.

Cette classe sera utilisée lors de la consultation de la base de données des options pour les autres options de la fenêtre (voir Tk::options), et sera également utilisée ultérieurement à d'autres fins telles que les liaisons. On attribue généralement une classe à un TopLevel ou à un Frame afin que la classe s'applique à tous les enfants de ce widget.

Options reconfigurables

Ces options peuvent être définies à la création du widget ou modifiées ultérieurement via configure.

Nom : activeBackground
Classe : Foreground
Commutateur : -activebackground
Spécifie la couleur d'arrière-plan à utiliser lors du dessin des éléments actifs. Un élément (un widget ou une partie d'un widget) est actif si le curseur de la souris est positionné sur l'élément et que l'appui sur un bouton de la souris entraîne une action. Si la conformité stricte à Motif a été demandée en définissant la variable $Tk::strictMotif, cette option sera normalement ignorée ; la couleur d'arrière-plan normale sera utilisée à la place. Pour certains éléments sur les systèmes Windows et Macintosh, la couleur active ne sera utilisée que lorsque le bouton de la souris 1 est enfoncé sur l'élément.
Nom : activeBorderWidth
Classe : BorderWidth
Commutateur : -activeborderwidth
Spécifie une valeur non négative indiquant la largeur de la bordure 3D dessinée autour des éléments actifs. Voir ci-dessus pour la définition des éléments actifs. La valeur peut prendre l'une des formes acceptables par Tk_GetPixels. Cette option n'est généralement disponible que dans les widgets affichant plus d'un élément à la fois (par exemple, les menus mais pas les boutons).
Nom : activeForeground
Classe : Background
Commutateur : -activeforeground
Spécifie la couleur de premier plan à utiliser lors du dessin des éléments actifs. Voir ci-dessus pour la définition des éléments actifs.
Nom : activetile
Classe : Tile
>
Switch: -activetile
Spécifie l'image utilisée pour l'affichage dans les éléments actifs du widget. Voir ci-dessus pour la définition des éléments actifs.
Name: anchor
Class: Anchor
Switch: -anchor
Spécifie comment les informations contenues dans un widget (par exemple, du texte ou un bitmap) doivent être affichées dans le widget. Doit être l'une des valeurs n, ne, e, se, s, sw, w, nw, ou center. Par exemple, nw signifie afficher les informations de manière à ce que leur coin supérieur gauche soit au coin supérieur gauche du widget.
Name: background
Class: Background
Switch: -background
Alias: -bg
Spécifie la couleur de fond normale à utiliser lors de l'affichage du widget.
Name: bitmap
Class: Bitmap
Switch: -bitmap
Spécifie un bitmap à afficher dans le widget, sous l'une des formes acceptables par Tk_GetBitmap. La manière exacte dont le bitmap est affiché peut être affectée par d'autres options telles que -anchor ou -justify. Généralement, si cette option est spécifiée, elle remplace les autres options qui spécifient une valeur textuelle à afficher dans le widget ; l'option -bitmap peut être réinitialisée à une chaîne vide pour réactiver un affichage textuel. Dans les widgets qui prennent en charge les options -bitmap et -image, -image l'emporte généralement sur -bitmap.
Name: borderWidth
Class: BorderWidth
Switch: -borderwidth
Alias: -bd
Spécifie une valeur non négative indiquant la largeur de la bordure 3D à dessiner autour du widget (si une telle bordure est dessinée ; l'option -relief détermine généralement cela). La valeur peut également être utilisée lors du dessin d'effets 3D à l'intérieur du widget. La valeur peut avoir l'une des formes acceptables par Tk_GetPixels.
Name: compound
Class: Compound
Switch: -compound
Spécifie si le widget doit afficher du texte et des bitmaps/images en même temps, et si oui, où le bitmap/image doit être placé par rapport au texte. Doit être l'une des valeurs none, bottom, top, left, right, ou center. Par exemple, la valeur (par défaut) none spécifie que le bitmap ou l'image doit être (s'il est défini) affiché à la place du texte, la valeur left spécifie que le bitmap ou l'image doit être affiché à gauche du texte, et la valeur center spécifie que le bitmap ou l'image doit être affiché par-dessus le texte.
Name: cursor
Class: Cursor
Switch: -cursor
Spécifie le curseur de souris à utiliser pour le widget. La valeur peut avoir l'une des formes acceptables par Tk_GetCursor.
Name: dash
Class: Dash
Switch: -dash
La valeur peut avoir l'une des formes acceptées par Tk_GetDash, telles que 4, [6,4], ., -, -., ou -...
Name: dashoffset
Class: Dashoffset
Switch: -dashoffset
Spécifie le décalage dans la liste des tirets où commence le dessin.
Name: disabledForeground
Class: DisabledForeground
Switch: -disabledforeground
Spécifie la couleur de premier plan à utiliser lors du dessin d'un élément désactivé. Si l'option est spécifiée comme une chaîne vide (ce qui est généralement le cas sur les affichages monochromes), les éléments désactivés sont dessinés avec la couleur de premier plan normale mais ils sont estompés en les dessinant avec un motif de remplissage hachuré.
Name: disabledtile
Class: Tile
Switch: -disabledtile
Spécifie l'image à utiliser lors du dessin d'un élément désactivé.
Name: exportSelection
Class: ExportSelection
Switch: -exportselection
Spécifie si une sélection dans le widget doit également être la sélection X. La valeur peut avoir l'une des formes acceptées par Tcl_GetBoolean, telles que true, false, 0, 1, yes, ou no. Si la sélection est exportée, alors sélectionner dans le widget désélectionne la sélection X actuelle, sélectionner en dehors du widget désélectionne toute sélection du widget, et le widget répondra aux requêtes de récupération de sélection lorsqu'il aura une sélection. La valeur par défaut est généralement que les widgets exportent les sélections.
Name: font
Class: Font
Switch: -font
Spécifie la police à utiliser lors du dessin de texte à l'intérieur du widget.
Name: foreground
Class: Foreground
Switch: -foreground
Alias: -fg
Spécifie la couleur de premier plan normale à utiliser lors de l'affichage du widget.
Name: highlightBackground
Class: HighlightBackground
Switch: -highlightbackground
Spécifie la couleur à afficher dans la région de surbrillance de parcours lorsque le widget n'a pas le focus d'entrée.
Name: highlightColor
Class: HighlightColor
Switch: -highlightcolor
Spécifie la couleur à utiliser pour le rectangle de surbrillance de parcours qui est dessiné autour du widget lorsqu'il a le focus d'entrée.
Name: highlightThickness
Class: HighlightThickness
Switch: -highlightthickness
Spécifie une valeur non négative indiquant la largeur du rectangle de surbrillance à dessiner autour du widget lorsqu'il a le focus d'entrée. La valeur peut avoir l'une des formes acceptables par Tk_GetPixels. Si la valeur est zéro, aucune surbrillance de focus n'est dessinée autour du widget.
Name: image
Class: Image
Switch: -image
Spécifie une image à afficher dans le widget, qui doit avoir été créée avec une création d'image. (Voir Tk::Image pour les détails de la création d'image.) Généralement, si l'option -image est spécifiée, elle remplace les autres options qui spécifient un bitmap ou une valeur textuelle à afficher dans le widget ; l'option -image peut être réinitialisée à une chaîne vide pour réactiver l'affichage d'un bitmap ou de texte.
Name: insertBackground
Class: Foreground
Switch: -insertbackground
Spécifie la couleur à utiliser comme fond dans la zone couverte par le curseur d'insertion. Cette couleur remplacera normalement soit le fond normal du widget (soit le fond de sélection si le curseur d'insertion se trouve dans la sélection).
Name: insertBorderWidth
Class: BorderWidth
Switch: -insertborderwidth
Spécifie une valeur non négative indiquant la largeur de la bordure 3D à dessiner autour du curseur d'insertion. La valeur peut avoir l'une des formes acceptables par Tk_GetPixels.
Name: insertOffTime
Class: OffTime
Switch: -insertofftime
Spécifie une valeur entière non négative indiquant le nombre de millisecondes pendant lesquelles le curseur d'insertion doit rester ``éteint'' à chaque cycle de clignotement. Si cette option est zéro, le curseur ne clignote pas : il est allumé en permanence.
Nom : insertOnTime
Classe : OnTime
Option : -insertontime
Spécifie une valeur entière non négative indiquant le nombre de millisecondes pendant lesquelles le curseur d'insertion doit rester ``allumé'' dans chaque cycle de clignotement.
Nom : insertWidth
Classe : InsertWidth
Option : -insertwidth
Spécifie une valeur indiquant la largeur totale du curseur d'insertion. La valeur peut avoir l'une des formes acceptées par Tk_GetPixels. Si une bordure a été spécifiée pour le curseur d'insertion (en utilisant l'option insertBorderWidth), la bordure sera dessinée à l'intérieur de la largeur spécifiée par l'option insertWidth.
Nom : jump
Classe : Jump
Option : -jump
Pour les widgets dont le curseur peut être déplacé pour ajuster une valeur, tels que les barres de défilement, cette option détermine quand des notifications sont faites concernant les changements de valeur. La valeur de l'option doit être un booléen du type accepté par Tcl_GetBoolean. Si la valeur est fausse, les mises à jour sont effectuées en continu pendant que le curseur est déplacé. Si la valeur est vraie, les mises à jour sont retardées jusqu'à ce que le bouton de la souris soit relâché pour terminer le glissement ; à ce moment-là, une seule notification est faite (la valeur ``saute'' plutôt que de changer progressivement).
Nom : justify
Classe : Justify
Option : -justify
Lorsqu'il y a plusieurs lignes de texte affichées dans un widget, cette option détermine comment les lignes s'alignent les unes par rapport aux autres. Doit être l'une des valeurs suivantes : left, center ou right. Left signifie que les bords gauches des lignes s'alignent tous, center signifie que les centres des lignes sont alignés, et right signifie que les bords droits des lignes s'alignent.
Nom : offset
Classe : Offset
Option : -offset
Spécifie le décalage des carreaux (voir aussi l'option -tile). Il peut avoir deux formats différents : -offset x,y ou -offset side, où side peut être n, ne, e, se, s, sw, w, nw, ou center. Dans le premier cas, l'origine est l'origine de la fenêtre de plus haut niveau de la fenêtre actuelle. Pour le canevas lui-même et les objets du canevas, l'origine est l'origine du canevas, mais mettre un # devant la paire de coordonnées indique d'utiliser l'origine de la fenêtre de plus haut niveau à la place. Pour les objets du canevas, l'option -offset est également utilisée pour le remplissage en pointillé. Pour les éléments de ligne et de polygone du canevas, vous pouvez également spécifier un index comme argument, qui relie l'origine du remplissage en pointillé ou du carreau à l'un des points de coordonnées de la ligne/du polygone.
Nom : orient
Classe : Orient
Option : -orient
Pour les widgets qui peuvent se disposer avec une orientation horizontale ou verticale, comme les barres de défilement, cette option spécifie quelle orientation doit être utilisée. Doit être soit horizontal soit vertical, ou une abréviation de l'un de ces termes.
Nom : padX
Classe : Pad
Option : -padx
Spécifie une valeur non négative indiquant la quantité d'espace supplémentaire à demander pour le widget dans la direction X. La valeur peut avoir l'une des formes acceptables par Tk_GetPixels. Lors du calcul de la taille d'une fenêtre dont il a besoin, le widget ajoutera ce montant à la largeur dont il aurait normalement besoin (déterminée par la largeur des éléments affichés dans le widget) ; si le gestionnaire de géométrie peut satisfaire cette demande, le widget aura un espace interne supplémentaire à gauche et/ou à droite de ce qu'il affiche à l'intérieur. La plupart des widgets utilisent cette option uniquement pour le remplissage de texte : s'ils affichent une image bitmap ou une image, ils ignorent généralement les options de remplissage.
Nom : padY
Classe : Pad
Option : -pady
Spécifie une valeur non négative indiquant la quantité d'espace supplémentaire à demander pour le widget dans la direction Y. La valeur peut avoir l'une des formes acceptables par Tk_GetPixels. Lors du calcul de la taille d'une fenêtre dont il a besoin, le widget ajoutera ce montant à la hauteur dont il aurait normalement besoin (déterminée par la hauteur des éléments affichés dans le widget) ; si le gestionnaire de géométrie peut satisfaire cette demande, le widget aura un espace interne supplémentaire au-dessus et/ou en dessous de ce qu'il affiche à l'intérieur. La plupart des widgets utilisent cette option uniquement pour le remplissage de texte : s'ils affichent une image bitmap ou une image, ils ignorent généralement les options de remplissage.
Nom : relief
Classe : Relief
Option : -relief
Spécifie l'effet 3D souhaité pour le widget. Les valeurs acceptables sont raised, sunken, flat, ridge, solid, et groove. La valeur indique comment l'intérieur du widget doit apparaître par rapport à son extérieur ; par exemple, raised signifie que l'intérieur du widget doit sembler saillir de l'écran, par rapport à l'extérieur du widget.
Nom : repeatDelay
Classe : RepeatDelay
Option : -repeatdelay
Spécifie le nombre de millisecondes pendant lesquelles un bouton ou une touche doit être maintenu enfoncé avant qu'il ne commence à se répéter automatiquement. Utilisé, par exemple, sur les flèches haut et bas des barres de défilement.
Nom : repeatInterval
Classe : RepeatInterval
Option : -repeatinterval
Utilisé en conjonction avec repeatDelay : une fois que la répétition automatique commence, cette option détermine le nombre de millisecondes entre chaque répétition automatique.
Nom : selectBackground
Classe : Foreground
Option : -selectbackground
Spécifie la couleur d'arrière-plan à utiliser lors de l'affichage des éléments sélectionnés.
Nom : selectBorderWidth
Classe : BorderWidth
Option : -selectborderwidth
Spécifie une valeur non négative indiquant la largeur de la bordure 3D à dessiner autour des éléments sélectionnés. La valeur peut avoir l'une des formes acceptables par Tk_GetPixels.
Nom : selectForeground
Classe : Background
Option : -selectforeground
Spécifie la couleur d'avant-plan à utiliser lors de l'affichage des éléments sélectionnés.
Nom : setGrid
Classe : SetGrid
Option : -setgrid
Spécifie une valeur booléenne qui détermine si ce widget contrôle la grille de redimensionnement de sa fenêtre de plus haut niveau. Cette option est généralement utilisée dans les widgets texte, où les informations contenues dans le widget ont une taille naturelle (la taille d'un caractère) et il est logique que les dimensions de la fenêtre soient des nombres entiers de ces unités. Ces tailles de fenêtre naturelles forment une grille. Si l'option setGrid est définie sur vrai, le widget communiquera avec le gestionnaire de fenêtres afin que, lorsque l'utilisateur redimensionne interactivement la fenêtre de plus haut niveau contenant le widget, les dimensions de la fenêtre soient affichées à l'utilisateur en unités de grille et que la taille de la fenêtre soit contrainte à des nombres entiers d'unités de grille. Voir "GRIDDED GEOMETRY MANAGEMENT" dans Tk::Wm pour plus de détails.
Nom : takeFocus
Classe : TakeFocus
Option : -takefocus
Détermine si la fenêtre accepte le focus lors du parcours au clavier (par exemple, Tab et Shift-Tab). Avant de définir le focus sur une fenêtre, les scripts de parcours consultent la valeur de l'option takeFocus. Une valeur de 0 signifie que la fenêtre doit être complètement ignorée lors du parcours au clavier. 1 signifie que la fenêtre doit recevoir le focus d'entrée tant qu'elle est visible (elle et tous ses ancêtres sont affichés). Une valeur vide pour l'option signifie que les scripts de parcours prennent la décision de se concentrer ou non sur la fenêtre : l'algorithme actuel consiste à ignorer la fenêtre si elle est désactivée, si elle n'a pas de liaisons de touches, ou si elle n'est pas visible. Si la valeur a une autre forme, les scripts de parcours prennent la valeur, y ajoutent le nom de la fenêtre (avec un espace comme séparateur) et évaluent la chaîne résultante comme un rappel (Callback). Le script doit retourner 0, 1, ou une chaîne vide : une valeur de 0 ou 1 spécifie si la fenêtre recevra le focus d'entrée, et une chaîne vide entraîne la décision par défaut décrite ci-dessus. Note : cette interprétation de l'option est entièrement définie
par les Callbacks qui implémentent le parcours : les implémentations de widgets ignorent l'option entièrement, vous pouvez donc changer sa signification si vous redéfinissez les scripts de parcours au clavier.
Nom : texte
Classe : Texte
Commutateur : -texte
Spécifie une chaîne de caractères à afficher à l'intérieur du widget. La manière dont la chaîne est affichée dépend du widget particulier et peut être déterminée par d'autres options, telles que ancre ou justification.
Nom : variableTexte
Classe : Variable
Commutateur : -variabletexte
Spécifie le nom d'une variable. La valeur de la variable est une chaîne de caractères à afficher à l'intérieur du widget ; si la valeur de la variable change, le widget se mettra automatiquement à jour pour refléter la nouvelle valeur. La manière dont la chaîne est affichée dans le widget dépend du widget particulier et peut être déterminée par d'autres options, telles que ancre ou justification.
Nom : carreau
Classe : Carreau
Commutateur : -carreau
Spécifie l'image utilisée pour afficher le widget. Si l'image est une chaîne vide, la couleur de fond normale est affichée.
Nom : couleurGouttiere
Classe : Fond
Commutateur : -couleurgouttiere
Spécifie la couleur à utiliser pour les zones rectangulaires de gouttière dans les widgets tels que les barres de défilement et les curseurs.
Nom : carreauGouttiere
Classe : Carreau
Commutateur : -carreaudegouttiere
Spécifie l'image utilisée pour afficher dans les zones rectangulaires de gouttière dans les widgets tels que les barres de défilement et les curseurs.
Nom : souligne
Classe : Souligné
Commutateur : -souligne
Spécifie l'index entier d'un caractère à souligner dans le widget. Cette option est utilisée par les liaisons par défaut pour implémenter le parcours au clavier pour les boutons de menu et les entrées de menu. 0 correspond au premier caractère du texte affiché dans le widget, 1 au caractère suivant, et ainsi de suite.
Nom : longueurRetourLigne
Classe : LongueurRetourLigne
Commutateur : -longueurretourlignee
Pour les widgets qui peuvent effectuer un retour à la ligne automatique, cette option spécifie la longueur maximale de ligne. Les lignes qui dépasseraient cette longueur sont renvoyées à la ligne suivante, de sorte qu'aucune ligne ne soit plus longue que la longueur spécifiée. La valeur peut être spécifiée dans n'importe laquelle des formes standard pour les distances d'écran. Si cette valeur est inférieure ou égale à 0, aucun retour à la ligne n'est effectué : les lignes ne seront coupées qu'aux caractères de nouvelle ligne du texte.
Nom : commandeXDebord
Classe : CommandeDebord
Commutateur : -commandexdebord
Spécifie un callback utilisé pour communiquer avec les barres de défilement horizontales. Lorsque la vue dans la fenêtre du widget change (ou lorsque quoi que ce soit d'autre se produit qui pourrait changer l'affichage dans une barre de défilement, comme un changement dans la taille totale du contenu du widget), le widget effectuera un callback en passant deux arguments numériques en plus de ceux spécifiés dans le callback. Chacun des nombres est une fraction comprise entre 0 et 1, qui indique une position dans le document. 0 indique le début du document, 1 indique la fin, .333 indique une position à un tiers du document, et ainsi de suite. La première fraction indique la première information du document qui est visible dans la fenêtre, et la seconde fraction indique l'information juste après la dernière partie visible. Typiquement, l'option commandeXDebord consiste en l'objet widget de la barre de défilement et la méthode ``set'' c'est-à-dire [set => $sb] : cela provoquera la mise à jour de la barre de défilement chaque fois que la vue dans la fenêtre change. Si cette option n'est pas spécifiée, aucune commande ne sera exécutée.
Nom : commandeYDebord
Classe : CommandeDebord
Commutateur : -commandeYDebord
Spécifie un callback utilisé pour communiquer avec les barres de défilement verticales. Cette option est traitée de la même manière que l'option commandeXDebord, sauf qu'elle est utilisée pour les barres de défilement verticales et est fournie par les widgets qui prennent en charge le défilement vertical. Voir la description de commandeXDebord pour plus de détails sur la manière dont cette option est utilisée.
