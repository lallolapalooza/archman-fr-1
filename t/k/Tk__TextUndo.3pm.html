NOM

Tk::TextUndo - widget texte perl/tk avec liaisons pour annuler les modifications.

SYNOPSIS

    use Tk::TextUndo;

    $testundo = $parent->TextUndo(?-option=>valeur, ...?);

DESCRIPTION

Ceci EST-UN widget texte avec un historique d'annulation illimité mais sans capacité de ré-annulation.

Liaisons

Le widget "TextUndo" a les mêmes liaisons que le widget Text. De plus, il y a les liaisons suivantes :

Événement <L4> <<Undo>>
annule la dernière modification. Appuyer plusieurs fois sur <L4> annule pas à pas les modifications apportées au widget texte.

Méthodes

Le widget "TextUndo" a les mêmes méthodes que le widget "Text". Les méthodes supplémentaires pour le widget "TextUndo" sont :

$text->Load($nom_fichier);
Charge le contenu du $nom_fichier dans le widget texte. Load() supprime le contenu précédent du widget texte ainsi que son historique d'annulation du fichier précédent.
$text->Save(?$autre_nom_fichier?)
Sauvegarde le contenu du widget texte dans un fichier. Si $autre_nom_fichier n'est pas spécifié, le widget texte écrit le fichier du $nom_fichier utilisé lors du dernier appel à Load(). Si aucun fichier n'a été précédemment chargé avec Load(), un message d'erreur apparaît. Le nom de fichier par défaut du dernier appel à Load() n'est pas écrasé par $autre_nom_fichier.
$text->FileName(?$autre_nom_fichier?)
Si un argument est passé, il définit le nom du fichier associé au document chargé. Renvoie le nom de fichier actuel associé au document.

CLÉS
