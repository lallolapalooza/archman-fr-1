Tk_GetCapStyle(3) Procédures de la bibliothèque Tk Tk_GetCapStyle(3)

NOM

Tk_GetCapStyle, Tk_NameOfCapStyle - traduire entre les chaînes et les styles d'extrémités

SYNTAXE

#include <tk.h>

int
Tk_GetCapStyle(interp, string, capPtr)

const char *
Tk_NameOfCapStyle(cap)

ARGUMENTS

Tcl_Interp *interp (in)
Interpréteur à utiliser pour signaler les erreurs.
const char *string (in)
Chaîne contenant le nom du style d'extrémité - l'un de “butt”, “projecting”, ou “round” - ou une abréviation unique de l'un d'eux.
int *capPtr (out)
Pointeur vers l'emplacement où stocker le style d'extrémité X correspondant à string.
int cap (in)
Style d'extrémité : l'un de CapButt, CapProjecting, ou CapRound.

DESCRIPTION

Tk_GetCapStyle place dans *capPtr le style d'extrémité X correspondant à string. Ce sera l'une des valeurs CapButt, CapProjecting, ou CapRound. Les styles d'extrémités sont généralement utilisés dans les contextes graphiques X pour indiquer comment les points d'extrémité des lignes doivent être terminés. Voir la documentation X pour plus d'informations sur ce que chaque style implique.

Dans des circonstances normales, la valeur de retour est TCL_OK et interp est inutilisé. Si string ne contient pas un style d'extrémité valide ou une abréviation de l'un de ces noms, alors un message d'erreur est stocké dans le résultat de l'interpréteur interp, TCL_ERROR est retourné, et *capPtr n'est pas modifié.

Tk_NameOfCapStyle est l'inverse logique de Tk_GetCapStyle. Étant donné un style d'extrémité tel que CapButt, il retourne une chaîne allouée statiquement correspondant à cap. Si cap n'est pas un style d'extrémité valide, alors “unknown cap style” est retourné.

MOTS-CLÉS

butt, style d'extrémité, projecting, round
