Tk_SetAppName(3) Procédures de la bibliothèque Tk Tk_SetAppName(3)

NOM

Tk_SetAppName - Définir le nom d'une application pour les commandes 'send'

SYNTAXE

#include <tk.h>

const char *
Tk_SetAppName(tkwin, name)

ARGUMENTS

Tk_Window tkwin (in)
Jeton de la fenêtre dans l'application. Utilisé uniquement pour sélectionner une application particulière.
const char *name (in)
Nom sous lequel enregistrer l'application.

DESCRIPTION

Tk_SetAppName associe un nom à une application donnée et enregistre cette association sur l'écran contenant la fenêtre principale de l'application. Après l'appel de cette procédure, d'autres applications sur l'écran pourront utiliser la commande send pour invoquer des opérations dans l'application. Si name est déjà utilisé par une autre application sur l'écran, un nouveau nom sera généré en ajoutant « #2 » à name ; si ce nom est également utilisé, le nombre sera incrémenté jusqu'à ce qu'un nom inutilisé soit trouvé. La valeur de retour de la procédure est un pointeur vers le nom réellement utilisé.

Si l'application a déjà un nom lorsque Tk_SetAppName est appelé, le nouveau nom remplace l'ancien nom.

Tk_SetAppName ajoute également une commande send à l'interpréteur de l'application, qui peut être utilisée pour envoyer des commandes depuis cette application vers d'autres sur n'importe lequel des écrans où l'application a des fenêtres.

L'enregistrement du nom de l'application persiste jusqu'à ce que l'interpréteur soit supprimé ou que la commande send soit supprimée de interp, moment auquel le nom est automatiquement désenregistré et l'application devient inaccessible via send. L'application peut être rendue accessible à nouveau en appelant Tk_SetAppName.

Tk_SetAppName est appelée automatiquement par Tk_Init, les applications n'ont donc normalement pas besoin de l'appeler explicitement.

La commande tk appname fournit un accès au niveau Tcl à la fonctionnalité de Tk_SetAppName.
