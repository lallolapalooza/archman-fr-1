Tk_GetAnchor(3)

Paquet: tk

Licences: TCL

Tk_GetAnchorFromObj(3) Procédures de la bibliothèque Tk Tk_GetAnchorFromObj(3)

NOM

Tk_GetAnchorFromObj, Tk_GetAnchor, Tk_NameOfAnchor - traduire entre chaînes de caractères et positions d'ancrage

SYNTAXE

#include <tk.h>

int
Tk_GetAnchorFromObj(interp, objPtr, anchorPtr)

int
Tk_GetAnchor(interp, string, anchorPtr)

const char *
Tk_NameOfAnchor(anchor)

ARGUMENTS

Tcl_Interp *interp (entrée)
Interpréteur à utiliser pour le rapport d'erreurs, ou NULL.
Tcl_Obj *objPtr (entrée/sortie)
La valeur de chaîne contient le nom du point d'ancrage : « n », « ne », « e », « se », « s », « sw », « w », « nw », ou « center » ; la représentation interne sera modifiée pour mettre en cache le Tk_Anchor correspondant. Dans le cas de « center » en entrée, une abréviation non vide de celui-ci peut également être utilisée en entrée.
const char *string (entrée)
Identique à objPtr sauf que la description du point d'ancrage est passée sous forme de chaîne de caractères.
int *anchorPtr (sortie)
Pointeur vers l'emplacement où stocker la position d'ancrage correspondant à objPtr ou string.
Tk_Anchor anchor (entrée)
Position d'ancrage, par exemple TCL_ANCHOR_CENTER.

DESCRIPTION

Tk_GetAnchorFromObj place dans *anchorPtr une position d'ancrage (type énuméré Tk_Anchor) correspondant à la valeur de objPtr. Le résultat sera l'un des éléments suivants : TK_ANCHOR_N, TK_ANCHOR_NE, TK_ANCHOR_E, TK_ANCHOR_SE, TK_ANCHOR_S, TK_ANCHOR_SW, TK_ANCHOR_W, TK_ANCHOR_NW, ou TK_ANCHOR_CENTER. Les positions d'ancrage sont généralement utilisées pour indiquer un point sur un objet qui sera utilisé pour positionner l'objet, par exemple TK_ANCHOR_N signifie positionner le point central supérieur de l'objet à un endroit donné.

Dans des circonstances normales, la valeur de retour est TCL_OK et interp est inutilisé. Si string ne contient pas de position d'ancrage valide ou une abréviation de l'un de ces noms, TCL_ERROR est retourné, *anchorPtr n'est pas modifié et un message d'erreur est stocké dans le résultat d'interp si interp n'est pas NULL. Tk_GetAnchorFromObj met en cache les informations sur la valeur de retour dans objPtr, ce qui accélère les appels futurs à Tk_GetAnchorFromObj avec le même objPtr.

Tk_GetAnchor est identique à Tk_GetAnchorFromObj sauf que la description de l'ancrage est spécifiée avec une chaîne de caractères au lieu d'un objet. Cela empêche Tk_GetAnchor de mettre en cache la valeur de retour, donc Tk_GetAnchor est moins efficace que Tk_GetAnchorFromObj.

Tk_NameOfAnchor est l'inverse logique de Tk_GetAnchor. Étant donné une position d'ancrage telle que TK_ANCHOR_N, il renvoie une chaîne de caractères allouée statiquement correspondant à anchor. Si anchor n'est pas une valeur d'ancrage valide, alors « unknown anchor position » est retourné.
