Paquet: perl-tk

Licences: PerlArtistic, GPL, custom

LabFrame(3) Documentation Perl fournie par l'utilisateur LabFrame(3)

NOM

Tk::LabFrame - cadre étiqueté.

SYNTAXE

    use Tk::LabFrame;

    $f = $parent->LabFrame(?-label=>texte, -labelside=>où, ...?);

DESCRIPTION

LabFrame est exactement comme Frame et permet en plus d'ajouter une étiquette au cadre.

OPTIONS DU WIDGET

LabFrame supporte les mêmes options que le widget Frame.

Options supplémentaires de LabFrame :

-font => police
Spécifie la police de l'étiquette.
-foreground => couleur
Spécifie la couleur de premier plan de l'étiquette.
-label => texte
Le texte de l'étiquette à placer avec le Frame.
-labelside => où
Où peut être l'un de left, right, top, bottom ou acrosstop. Les quatre premiers fonctionnent comme prévu et placent l'étiquette respectivement à gauche, à droite, au-dessus ou en dessous du cadre. acrosstop crée un cadre rainuré autour du cadre central et place l'étiquette près du coin nord-ouest de manière à ce qu'elle semble "recouvrir" la rainure.
-labelvariable => ref_scalaire
Spécifie une référence à une variable et est utilisé comme alternative à -label. Si la valeur de la variable change, le widget sera automatiquement mis à jour pour refléter le changement. Utilisé comme -textvariable.

SOUS-WIDGETS ANNÉCÉS

Voir "Subwidget" dans Tk::mega comment utiliser les widgets annoncés.

border
Frame utilisé pour afficher la bordure
frame
Frame utilisé pour créer de nouveaux enfants LabFrame.
label
Label utilisé pour afficher du texte

EXEMPLE

Exécutez le programme de test suivant pour le voir en action :

use strict;
use Tk;
require Tk::LabFrame;
require Tk::LabEntry;
my $test = 'Testons ceci';
my $mw = Tk::MainWindow->new;
my $f = $mw->LabFrame(-label => "Ceci est une étiquette",
                       -labelside => "acrosstop");
$f->LabEntry(-label => "Test", -textvariable => \$test)->pack;
$f->pack;
Tk::MainLoop;

BOGUES

Peut-être que LabFrame devrait être intégré dans le mécanisme générique de widget étiqueté de pTk.
