Tk_NameOfJoinStyle(3)

Paquet: tk

Tk_GetJoinStyle(3) Procédures de la bibliothèque Tk Tk_GetJoinStyle(3)

NOM

Tk_GetJoinStyle, Tk_NameOfJoinStyle - traduire entre des chaînes et des styles de jointure

SYNOPHIS

#include <tk.h>

int
Tk_GetJoinStyle(interp, string, joinPtr)

const char *
Tk_NameOfJoinStyle(join)

ARGUMENTS

Tcl_Interp *interp (en entrée)
Interpréteur à utiliser pour le rapport d'erreurs.
const char *string (en entrée)
Chaîne contenant le nom du style de jointure - l'un des “bevel”, “miter”, ou “round” - ou une abréviation unique de l'un d'eux.
int *joinPtr (en sortie)
Pointeur vers l'emplacement où stocker le style de jointure X correspondant à string.
int join (en entrée)
Style de jointure : l'un des JoinBevel, JoinMiter, JoinRound.

DESCRIPTION

Tk_GetJoinStyle place dans *joinPtr le style de jointure X correspondant à string, qui sera l'un des JoinBevel, JoinMiter, ou JoinRound. Les styles de jointure sont typiquement utilisés dans les contextes graphiques X pour indiquer comment les segments de ligne adjacents doivent être joints ensemble. Voir la documentation X pour des informations sur ce que chaque style implique.

Dans des circonstances normales, la valeur de retour est TCL_OK et interp n'est pas utilisé. Si string ne contient pas un style de jointure valide ou une abréviation de l'un de ces noms, alors un message d'erreur est stocké dans le résultat de l'interpréteur interp, TCL_ERROR est retourné, et *joinPtr n'est pas modifié.

Tk_NameOfJoinStyle est l'inverse logique de Tk_GetJoinStyle. Étant donné un style de jointure tel que JoinBevel, il retourne une chaîne allouée statiquement correspondant à join. Si join n'est pas un style de jointure valide, alors “unknown join style” est retourné.

MOTS-CLÉS

biseauté, style de jointure, onglet, rond
