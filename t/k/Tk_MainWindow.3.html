Tk_MainWindow(3) Procédures de la bibliothèque Tk Tk_MainWindow(3)

NOM

Tk_MainWindow, Tk_GetNumMainWindows - fonctions pour interroger les informations des fenêtres principales

SYNTAXE

#include <tk.h>

Tk_Window
Tk_MainWindow(interp)

int
Tk_GetNumMainWindows()

ARGUMENTS

Tcl_Interp *interp (entrée/sortie)
Interpréteur associé à l'application.

DESCRIPTION

Une fenêtre principale est un type spécial de fenêtre de plus haut niveau utilisé comme fenêtre externe dans une application.

Si interp est associé à une application Tk, alors Tk_MainWindow retourne la fenêtre principale de l'application. S'il n'y a pas d'application Tk associée à interp, alors Tk_MainWindow retourne NULL et laisse un message d'erreur dans le résultat de l'interpréteur interp.

Tk_GetNumMainWindows retourne le nombre de fenêtres principales actuellement ouvertes dans le thread courant.

MOTS-CLÉS

application, fenêtre principale
