NOM

Tk::Button - Créer et manipuler des widgets Bouton

SYNOPIS

$bouton = $parent->Button(?options?);

OPTIONS STANDARD

-activebackground -activeforeground -anchor -background -bitmap -borderwidth -compound -cursor -disabledforeground -font -foreground -highlightbackground -highlightcolor -highlightthickness -image -justify -padx -pady -relief -repeatdelay -repeatinterval -takefocus -text -textvariable -underline -wraplength

Voir Tk::options pour les détails des options standard.

OPTIONS SPÉCIFIQUES AU WIDGET

Nom : command
Classe : Command
Commutateur : -command
Spécifie une fonction de rappel Perl/Tk à associer au bouton. Cette commande est généralement appelée lorsque le bouton 1 de la souris est relâché sur la fenêtre du bouton.
Nom de ligne de commande : -compound
Nom de base : compound
Classe de base : Compound
Spécifie si le bouton doit afficher à la fois une image et du texte, et si oui, où l'image doit être placée par rapport au texte. Les valeurs valides pour cette option sont bottom, center, left, none, right et top. La valeur par défaut est none, ce qui signifie que le bouton affichera soit une image, soit du texte, en fonction des valeurs des options -image et -bitmap.
Nom : default
Classe : Default
Commutateur : -default
Spécifie l'un des trois états pour l'anneau de valeur par défaut : normal, active ou disabled. En état actif, le bouton est affiché avec l'apparence spécifique à la plateforme pour un bouton par défaut. En état normal, le bouton est affiché avec l'apparence spécifique à la plateforme pour un bouton non par défaut, laissant suffisamment d'espace pour afficher l'apparence du bouton par défaut. Les états normal et actif entraîneront des boutons de la même taille. En état désactivé, le bouton est affiché avec l'apparence du bouton non par défaut sans laisser d'espace pour l'apparence par défaut. L'état désactivé peut entraîner un bouton plus petit que l'état actif. anneau.
Nom : height
Classe : Height
Commutateur : -height
Spécifie une hauteur souhaitée pour le bouton. Si une image ou un bitmap est affiché dans le bouton, la valeur est en unités d'écran (c'est-à-dire sous toute forme acceptable par Tk_GetPixels) ; pour du texte, elle est en lignes de texte. Si cette option n'est pas spécifiée, la hauteur souhaitée du bouton est calculée à partir de la taille de l'image, du bitmap ou du texte qui y est affiché.
Nom de ligne de commande : -overrelief
Nom de base : overRelief
Classe de base : OverRelief
Spécifie un relief alternatif pour le bouton, à utiliser lorsque le curseur de la souris se trouve sur le widget. Cette option peut être utilisée pour créer des boutons de barre d'outils, en configurant -relief flat -overrelief raised. Si la valeur de cette option est une chaîne vide, aucun relief alternatif n'est utilisé lorsque le curseur de la souris se trouve sur le bouton. La chaîne vide est la valeur par défaut.
Nom : state
Classe : State
Commutateur : -state
Spécifie l'un des trois états du bouton : normal, active ou disabled. En état normal, le bouton est affiché en utilisant les options foreground et background. L'état actif est généralement utilisé lorsque le pointeur est sur le bouton. En état actif, le bouton est affiché en utilisant les options activeForeground et activeBackground. L'état désactivé signifie que le bouton doit être inactif : les liaisons par défaut refuseront d'activer le widget et ignoreront les pressions sur les boutons de la souris. Dans cet état, les options disabledForeground et background déterminent comment le bouton est affiché.
Nom : width
Classe : Width
Commutateur : -width
Spécifie une largeur souhaitée pour le bouton. Si une image ou un bitmap est affiché dans le bouton, la valeur est en unités d'écran (c'est-à-dire sous toute forme acceptable par Tk_GetPixels) ; pour du texte, elle est en caractères. Si cette option n'est pas spécifiée, la largeur souhaitée du bouton est calculée à partir de la taille de l'image, du bitmap ou du texte qui y est affiché.

DESCRIPTION

La méthode Button crée une nouvelle fenêtre (fournie par l'argument $widget) et en fait un widget bouton. Des options supplémentaires, décrites ci-dessus, peuvent être spécifiées sur la ligne de commande ou dans la base d'options pour configurer des aspects du bouton tels que ses couleurs, sa police, son texte et son relief initial. La commande button retourne son argument $widget. Au moment où cette commande est invoquée, aucune fenêtre nommée $widget ne doit exister, mais le parent de $widget doit exister.

Un bouton est un widget qui affiche une chaîne de caractères, un bitmap ou une image. Si du texte est affiché, il doit être dans une seule police, mais il peut occuper plusieurs lignes à l'écran (s'il contient des nouvelles lignes ou si un retour à la ligne se produit à cause de l'option -wraplength) et l'un des caractères peut éventuellement être souligné à l'aide de l'option -underline. Il peut s'afficher de trois manières différentes, selon l'option -state ; il peut être rendu comme relevé, enfoncé ou plat ; et il peut être fait pour clignoter. Lorsqu'un utilisateur déclenche le bouton (en appuyant sur le bouton 1 de la souris avec le curseur sur le bouton), la fonction de rappel perl/Tk spécifiée dans l'option -command est appelée.

MÉTHODES DU WIDGET

La méthode Button crée un objet widget. Cet objet prend en charge les méthodes configure et cget décrites dans Tk::options qui peuvent être utilisées pour interroger et modifier les options décrites ci-dessus. Le widget hérite également de toutes les méthodes fournies par la classe générique Tk::Widget.

Les méthodes supplémentaires suivantes sont disponibles pour les widgets bouton :

$bouton->flash
Faire clignoter le bouton. Ceci est réalisé en réaffichant le bouton plusieurs fois, en alternant entre les couleurs active et normale. À la fin du clignotement, le bouton reste dans le même état normal/actif qu'au moment où la commande a été invoquée. Cette commande est ignorée si l'état du bouton est disabled.
$bouton->invoke
Appeler la fonction de rappel associée à l'option -command du bouton, s'il y en a une. La valeur de retour est la valeur de retour de la fonction de rappel, ou la valeur indéfinie s'il n'y a pas de fonction de rappel associée au bouton. Cette commande est ignorée si l'état du bouton est disabled.

LIAISONS PAR DÉFAUT

Tk crée automatiquement des liaisons de classe pour les boutons qui leur donnent un comportement par défaut :

[1]
Un bouton s'active chaque fois que
la souris passe dessus et désactive chaque fois que la souris quitte le bouton. Sous Windows, cette liaison est uniquement active lorsque le bouton 1 de la souris a été pressé sur le bouton.
[2]
Le relief d'un bouton est changé en enfoncé chaque fois que le bouton 1 de la souris est pressé sur le bouton, et le relief est restauré à sa valeur d'origine lorsque le bouton 1 est relâché plus tard.
[3]
Si le bouton 1 de la souris est pressé sur un bouton et relâché plus tard sur le bouton, le bouton est invoqué. Cependant, si la souris n'est pas sur le bouton lorsque le bouton 1 est relâché, aucune invocation ne se produit.
[4]
Lorsque qu'un bouton a le focus d'entrée, la barre d'espace provoque l'invocation du bouton.

Si l'état du bouton est désactivé, aucune des actions ci-dessus ne se produit : le bouton est complètement insensible.

Le comportement des boutons peut être modifié en définissant de nouvelles liaisons pour des widgets individuels ou en redéfinissant les liaisons de classe.
