NOM

Tk::TableMatrix::SpreadsheetHideRows - Affichage de table avec masquage/affichage sélectionnable des lignes

SYNOPSIS

use Tk;
use Tk::TableMatrix::SpreadsheetHideRows
my $t = $top->Scrolled('SpreadsheetHideRows', 
  -selectorCol => 3,
  -expandData => $hashRef,
  -rows => 21, -cols => 11, 
  -width => 6, -height => 6,
  -titlerows => 1, -titlecols => 1,
  -variable => $arrayVar,
  -selectmode => 'extended',
  -resizeborders => 'both',
  -bg => 'white',
);

DESCRIPTION

Tk::TableMatrix::SpreadsheetHideRows est un widget dérivé de Tk::TableMatrix::Spreadsheet qui implémente un affichage de type tableur pour les informations tabulaires, où certaines lignes de la table peuvent être développées/masquées en cliquant sur un sélecteur '+/-' dans la ligne. Ceci peut être utilisé pour afficher des informations de haut niveau dans une table, tout en permettant à l'utilisateur de développer certaines lignes de la table pour afficher des informations de niveau détail.

Voir demos/SpreadsheetHideRows dans la distribution source pour un exemple simple de ce widget.

Options spécifiques au widget

En plus des options standard du widget Tk::TableMatrix. Les options suivantes sont implémentées :

-selectorCol
Numéro de colonne où apparaîtra le sélecteur +/-. Cliquer sur le sélecteur +/- développera/masquera les informations de détail dans la table pour une ligne particulière.
-selectorColWidth
Largeur de la colonne utilisée pour afficher le sélecteur +/-. Par défaut à 2.
-expandData
Référence de hachage définissant les données de niveau détail affichées lorsqu'une ligne est développée (en cliquant sur le sélecteur +/-). Cette référence de hachage doit avoir la structure suivante : 
$expandData = {  
      ligne1 => {  tag  => 'detailDataTag',
                 data => $detailData,
                 spans=> $spanData,
                 expandData => $subLevelData
              },
      ligne2 => { 
         .
         .
}

Où : 
  ligne1, ligne2, ...         Numéros de lignes qui seront développables.
  tag => 'detailDataTag'  Nom de balise qui sera appliqué aux données de détail.
                          (optionnel)
  $detailData              Tableau 2D de données de détail à afficher lorsque 
                           la ligne est développée.
                           par ex. [ [ r1c1, r1c2, r1c3 ],
                                  [ r2c1, r2c2, r2,c3] ]
  $spans                   Tableau 1D d'informations de span (optionnel) à 
                           utiliser pour l'affichage des informations de détail.
                           par ex.  [ col2 =>  "lignes,colonnes", col4 =>  "lignes,colonnes", ... ]
  $subLevelData            Optionnel expandData récursif utilisé pour contenir
                           les données de détail des données de détail.

DONNÉES MEMBRE

Les éléments suivants sont stockés comme données membre :

defaultCursor
Nom du curseur de souris utilisé pour les cellules normales (c.-à-d. non-titre, non-indicateur) du widget. Ceci est défini à la valeur de l'option $widget->cget(-cursor) lors de la création du widget.
indRowCols
Référence de hachage des index de lignes/colonnes où se trouvent des indicateurs. Il s'agit d'une table de correspondance rapide construite à partir de _expandData.
_expandData
Version interne du hachage expandData. Toutes les données de sous-détail (c'est-à-dire les données d'expansion qui se trouvent à des niveaux inférieurs de expandData) qui sont visibles sont placées au niveau supérieur de ce hachage, pour suivre les expandData visibles.

Méthodes du widget

En plus de la méthode standard du widget Tk::TableMatrix. Les méthodes suivantes sont implémentées :

showDetail

Affiche (c'est-à-dire développe la table) les données de détail pour une ligne donnée. Cette méthode est appelée lorsqu'un utilisateur clique sur un indicateur qui n'est pas déjà développé.

Utilisation :

$widget->showDetail($ligne);  

# Affiche les données de détail pour la ligne numéro $ligne

hideDetail

Masque les données de détail pour une ligne donnée. Cette méthode est appelée lorsqu'un utilisateur clique sur un indicateur qui est déjà développé.

Utilisation :

$widget->hideDetail($ligne);  

# Masque les données de détail pour la ligne numéro $ligne
