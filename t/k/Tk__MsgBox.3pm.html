NOM

Tk::MsgBox - créer et manipuler une boîte de dialogue de message

SYNTAXE

use Tk::MsgBox
...
$d = $top->MsgBox(-title => "Titre", -type => "okcancel");
...
$button = $d->Show;

DESCRIPTION

MsgBox est une boîte de dialogue simple avec des boutons prédéfinis.

OPTIONS

Les options reconnues par MsgBox sont les suivantes :

-icon
Spécifie l'icône de la MsgBox. Les valeurs valides sont error, info, question, ou warning.
-type
Spécifie le type de la MsgBox. Les valeurs valides sont abortretryignore, ok, okcancel, retrycancel, yesno, ou yesnocancel. Le type détermine les boutons à afficher.
-default
Spécifie le bouton par défaut. Il doit s'agir de abort, retry, ignore, ok, cancel, yes, ou no, en fonction du type de MsgBox précédemment spécifié.
-detail
Spécifie le texte pour la région de détail de la MsgBox.
-message
Spécifie le texte du message de la MsgBox.
-title
Spécifie le titre de la MsgBox.

MÉTHODES

MsgBox ne prend en charge qu'une seule méthode pour le moment :

Show()
Affiche la MsgBox jusqu'à ce que l'utilisateur sélectionne l'un des boutons. Renvoie le nom du bouton sélectionné.
