NOM

Tk::Bitmap - Images qui affichent deux couleurs

SYNTAXE

    $image = $widget->Bitmap?(nom??,options?)

DESCRIPTION

Un bitmap est une image dont les pixels peuvent afficher l'une des deux couleurs ou être transparents. Une image bitmap est définie par quatre choses : une couleur d'arrière-plan, une couleur de premier plan et deux bitmaps, appelées la source et le masque. Chacun des bitmaps spécifie des valeurs 0/1 pour un tableau rectangulaire de pixels, et les deux bitmaps doivent avoir les mêmes dimensions. Pour les pixels où le masque est zéro, l'image n'affiche rien, produisant un effet transparent. Pour les autres pixels, l'image affiche la couleur de premier plan si la donnée source est un et la couleur d'arrière-plan si la donnée source est zéro.

CRÉATION DES BITMAPS

Les bitmaps sont créés en utilisant $widget->Bitmap. Les bitmaps prennent en charge les options suivantes :

-arriere-plan => couleur
Spécifie une couleur d'arrière-plan pour l'image de l'une des manières standard acceptées par Tk. Si cette option est définie sur une chaîne vide, les pixels d'arrière-plan seront transparents. Cet effet est obtenu en utilisant le bitmap source comme bitmap masque, ignorant toute option -masquedata ou -masquefichier.
-donnees => chaine
Spécifie le contenu du bitmap source sous forme de chaîne. La chaîne doit respecter le format bitmap X11 (par exemple, tel que généré par le programme bitmap). Si les options -donnees et -fichier sont toutes deux spécifiées, l'option -donnees prend la priorité.
-fichier => nom
nom donne le nom d'un fichier dont le contenu définit le bitmap source. Le fichier doit respecter le format bitmap X11 (par exemple, tel que généré par le programme bitmap).
-premier-plan => couleur
Spécifie une couleur de premier plan pour l'image de l'une des manières standard acceptées par Tk.
-masquedonnees => chaine
Spécifie le contenu du masque sous forme de chaîne. La chaîne doit respecter le format bitmap X11 (par exemple, tel que généré par le programme bitmap). Si les options -masquedonnees et -masquefichier sont toutes deux spécifiées, l'option -masquedonnees prend la priorité.
-masquefichier => nom
nom donne le nom d'un fichier dont le contenu définit le masque. Le fichier doit respecter le format bitmap X11 (par exemple, tel que généré par le programme bitmap).

MÉTHODES IMAGE

Lorsqu'une image bitmap est créée, Tk crée également un nouvel objet. Cet objet prend en charge les méthodes configure et cget décrites dans Tk::options qui peuvent être utilisées pour interroger et modifier les options décrites ci-dessus.
