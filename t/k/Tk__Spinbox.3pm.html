OPTIONS SPÉCIFIQUES AU WIDGET

Option: -buttonbackground
Nom: buttonBackground
Classe: Background
La couleur d'arrière-plan à utiliser pour les boutons de la boîte de sélection.
Option: -buttoncursor
Nom: buttonCursor
Classe: Cursor
Le curseur à utiliser lorsqu'il se trouve sur les boutons de la boîte de sélection. S'il est vide (par défaut), un curseur par défaut sera utilisé.
Option: -buttondownrelief
Nom: buttonDownRelief
Classe: Relief
Le relief à utiliser pour le bouton de la boîte de sélection supérieur.
Option: -buttonuprelief
Nom: buttonUpRelief
Classe: Relief
Le relief à utiliser pour le bouton de la boîte de sélection inférieur.
Option: -command
Nom: command
Classe: Command
Spécifie une fonction de rappel Perl/Tk à appeler chaque fois qu'un bouton de sélection est activé. La fonction de rappel reçoit ces deux arguments *ajoutés* à tout argument de rappel existant : la valeur actuelle du widget et la direction de la pression du bouton (up ou down).
Option: -disabledbackground
Nom: disabledBackground
Classe: DisabledBackground
Spécifie la couleur d'arrière-plan à utiliser lorsque la boîte de sélection est désactivée. Si cette option est une chaîne vide, la couleur d'arrière-plan normale est utilisée.
Option: -disabledforeground
Nom: disabledForeground
Classe: DisabledForeground
Spécifie la couleur du premier plan à utiliser lorsque la boîte de sélection est désactivée. Si cette option est une chaîne vide, la couleur du premier plan normale est utilisée.
Option: -format
Nom: format
Classe: Format
Spécifie un format alternatif à utiliser lors de la définition de la valeur de chaîne lorsque les options -from et -to sont utilisées. Il doit s'agir d'un spécificateur de format de la forme %<padding>.<padding>f, car il formatera un nombre à virgule flottante.
Option: -from
Nom: from
Classe: From
Une valeur en virgule flottante correspondant à la valeur la plus basse pour une boîte de sélection, à utiliser en conjonction avec -to et -increment. Lorsque toutes sont spécifiées correctement, la boîte de sélection utilisera ces valeurs pour contrôler son contenu. Cette valeur doit être inférieure à l'option -to. Si -values est spécifié, il remplace cette option.
Option: -invalidcommand
Alias: -invcmd
Nom: invalidCommand
Classe: InvalidCommand
Spécifie un script à évaluer lorsque validateCommand renvoie 0. Le définir sur une chaîne vide désactive cette fonctionnalité (par défaut). La meilleure utilisation de cette option est de la définir sur bell. Voir Validation ci-dessous pour plus d'informations.
Option: -increment
Nom: increment
Classe: Increment
Une valeur en virgule flottante spécifiant l'incrément. Lorsqu'elle est utilisée avec -from et -to, la valeur dans le widget sera ajustée de -increment lorsqu'un bouton de sélection est pressé (haut ajoute la valeur, bas soustrait la valeur).
Option: -readonlybackground
Nom: readonlyBackground
Classe: ReadonlyBackground
Spécifie la couleur d'arrière-plan à utiliser lorsque la boîte de sélection est en lecture seule. Si cette option est une chaîne vide, la couleur d'arrière-plan normale est utilisée.
Option: -state
Nom: state
Classe: State
Spécifie l'un des trois états de la boîte de sélection : normal, disabled (désactivé) ou readonly (lecture seule). Si la boîte de sélection est en lecture seule, la valeur ne peut pas être modifiée à l'aide de méthodes et aucun curseur d'insertion ne sera affiché, même si le focus d'entrée se trouve dans le widget ; le contenu du widget peut toujours être sélectionné. Si la boîte de sélection est désactivée, la valeur ne peut pas être modifiée, aucun curseur d'insertion ne sera affiché, le contenu ne sera pas sélectionnable et la boîte de sélection peut être affichée dans une couleur différente, en fonction des valeurs des options -disabledforeground et -disabledbackground.

Nom: to
Classe: To

Si -values est spécifié, il remplace cette option.

DESCRIPTION

La méthode Spinbox crée une nouvelle fenêtre (fournie par l'argument $spinbox) et la transforme en un widget Spinbox. D'autres options, décrites ci-dessus, peuvent être spécifiées sur la ligne de commande ou dans la base d'options pour configurer des aspects du Spinbox tels que ses couleurs, sa police et son relief.

Un Spinbox est un widget étendu de Entry qui permet à l'utilisateur de parcourir, ou de "faire tourner", un ensemble fixe de valeurs ascendantes ou descendantes, telles que les heures ou les dates, en plus de modifier la valeur, comme dans une entry. Lors de la première création d'un Spinbox, sa chaîne est vide. Une partie du Spinbox peut être sélectionnée comme décrit ci-dessous. Si un Spinbox exporte sa sélection (voir l'option exportSelection), il observera alors les protocoles standard pour gérer la sélection ; les sélections de Spinbox sont disponibles sous le type STRING. Les Spinbox respectent également les règles standard de Tk pour le traitement du focus d'entrée. Lorsqu'un Spinbox a le focus d'entrée, il affiche un curseur d'insertion pour indiquer où les nouveaux caractères seront insérés.

Les Spinbox peuvent afficher des chaînes trop longues pour tenir entièrement dans la fenêtre du widget. Dans ce cas, seule une partie de la chaîne sera affichée ; les commandes décrites ci-dessous peuvent être utilisées pour changer la vue dans la fenêtre. Les Spinbox utilisent le mécanisme standard -xscrollcommand pour interagir avec les barres de défilement (voir la description de l'option -xscrollcommand pour plus de détails). Ils supportent également la lecture, comme décrit ci-dessous.

VALIDATION

La validation fonctionne en définissant l'option validateCommand sur un callback qui sera évalué selon l'option validate de la manière suivante :

none
Par défaut. Cela signifie qu'aucune validation ne sera effectuée.
focus
validateCommand est appelé lorsque le Spinbox reçoit ou perd le focus.
focusin
validateCommand est appelé lorsque le Spinbox reçoit le focus.
focusout
validateCommand est appelé lorsque le Spinbox perd le focus.
key
validateCommand est appelé lorsque le Spinbox est modifié.
all
validateCommand est appelé pour toutes les conditions précédentes.

Les callbacks validateCommand et invalidCommand sont invoqués avec au moins 5 arguments positionnels, qui sont *ajoutés* à tout argument existant :

  • 1

    La valeur proposée de l'entrée. Si vous configurez le widget entry pour avoir une nouvelle textVariable, ce sera la valeur de cette textVariable.

  • 2

    Les caractères à ajouter (ou supprimer). Ce sera "undef" si la validation est due au focus, à un appel explicite à validate ou si la modification est due à un changement de "-textvariable".

  • 3

    La valeur actuelle de l'entrée, c'est-à-dire avant le changement proposé.

  • 4

    L'index de la chaîne à ajouter/supprimer, s'il existe. Sinon, -1.

  • 5

    Type d'action. 1 == INSERT, 0 == DELETE, -1 s'il s'agit d'une validation forcée ou d'un changement de textVariable.

En général, textVariable et validateCommand peuvent être dangereuses à mélanger. Tous les problèmes ont été résolus pour que l'utilisation de validateCommand n'interfère pas avec le comportement traditionnel du widget Spinbox. L'utilisation de textVariable à des fins de lecture ne pose jamais de problème. La menace survient lorsque l'on essaie de définir textVariable sur quelque chose que validateCommand n'accepte pas, ce qui fait que validate devient *none* (et invalidCommand ne s'exécute pas). Il en va de même lorsqu'une erreur se produit lors de l'évaluation de validateCommand.

Principalement, une erreur se produira lorsque validateCommand ou invalidCommand rencontrera une erreur dans son script lors de l'évaluation ou lorsque validateCommand ne renverra pas une valeur booléenne valide. L'option validate sera également définie sur none lorsque le widget Spinbox sera modifié depuis l'intérieur de validateCommand ou de invalidCommand. De telles modifications outrepasseront celle qui était en cours de validation. Si vous souhaitez modifier la valeur du widget pendant la validation et conserver validate défini, vous devrez inclure la commande :

my $val = $spinbox->cget(-validate);
$spinbox->configure(-validate => $val);

dans validateCommand ou invalidCommand (selon lequel vous modifiez le widget Spinbox). Il est également conseillé de ne pas définir une textVariable associée pendant la validation, car cela pourrait amener le widget Spinbox à dévier de la textVariable.

MÉTHODES_WIDGET

La commande Spinbox crée un objet widget dont le nom est $widget. Cette commande peut être utilisée pour invoquer diverses opérations sur le widget. Elle a la forme générale suivante :

$widget->method(?arg arg ...?);

Beaucoup de méthodes pour Spinbox prennent des indices comme arguments. Un index spécifie un caractère particulier dans la chaîne du Spinbox, sous l'une des formes suivantes :

number
Est l'index numérique du caractère, où 0 correspond au premier caractère de la chaîne.
anchor
Indique le point d'ancrage de la sélection, qui est défini par les méthodes select from et select adjust.
end
Indique le caractère juste après le dernier de la chaîne du Spinbox. Ceci est équivalent à spécifier un index numérique égal à la longueur de la chaîne du Spinbox.
insert
Indique le caractère adjacent au curseur d'insertion et juste après lui.
sel.first
Indique le premier caractère de la sélection. Il est erroné d'utiliser cette forme si la sélection n'est pas dans la fenêtre du Spinbox.
sel.last
Indique le caractère juste après le dernier de la sélection. Il est erroné d'utiliser cette forme si la sélection n'est pas dans la fenêtre du Spinbox.
@number
Dans cette forme, number est traité comme une coordonnée x dans la fenêtre du Spinbox ; le caractère utilisé est celui qui se trouve à cette coordonnée x. Par exemple, ``@0'' indique le caractère le plus à gauche dans la fenêtre.

Des abréviations peuvent être utilisées pour l'une des formes ci-dessus, comme ``e'' ou ``sel.f''. En général, les indices hors limites sont automatiquement arrondis à la valeur valide la plus proche.

Les commandes suivantes sont possibles pour les widgets Spinbox :

$widget->bbox(index);
Renvoie une liste de quatre nombres décrivant la boîte englobante du caractère donné par index. Les deux premiers éléments de la liste donnent les coordonnées x et y du coin supérieur gauche de la zone d'écran couverte par le caractère (en pixels par rapport au widget) et les deux derniers éléments donnent la largeur et la hauteur du caractère, en pixels. La boîte englobante peut faire référence à une zone en dehors de la zone visible de la fenêtre.
$widget->cget(option);
Renvoie la valeur actuelle de l'option de configuration donnée par option. Option peut avoir n'importe quelle valeur acceptée par la commande Spinbox.
$widget->configure(?option?, ?value, option, value, ...?);
Interroge ou modifie les options de configuration du widget. Si option n'est pas spécifiée, renvoie une liste décrivant toutes les options disponibles pour $widget (voir Tk::configure pour des informations sur le format de cette liste). Si option est spécifiée sans valeur, alors la commande renvoie une liste décrivant l'option nommée (cette liste sera identique à la sous-liste correspondante de la valeur renvoyée si option n'est pas spécifiée). Si une ou plusieurs paires option-valeur sont spécifiées, alors la commande modifie les options données du widget pour leur donner les valeurs spécifiées ; dans ce cas, la commande renvoie une chaîne vide. Option peut avoir n'importe quelle valeur acceptée par les valeurs.
Mantén toda la estructura del archivo.
Le Spinbox accepte la commande Spinbox.
$widget->delete(first, ?last?);
Supprime un ou plusieurs caractères du Spinbox. first est l'indice du premier caractère à supprimer, et last est l'indice du caractère juste après le dernier à supprimer. Si last n'est pas spécifié, il se comporte comme first+1, c'est-à-dire qu'un seul caractère est supprimé. Cette commande retourne une valeur vide.
$widget->get;
Retourne le texte du Spinbox.
$widget->icursor(index);
Configure le curseur d'insertion à afficher juste avant le caractère donné par index. Retourne une valeur vide.
$widget->identify(x, y);
Retourne le nom de l'élément de la fenêtre correspondant aux coordonnées x et y dans le Spinbox. La valeur retournée peut être : none, buttondown, buttonup, entry.
$widget->index(index);
Retourne l'indice numérique correspondant à index.
$widget->insert(index, string);
Insertion des caractères de string juste avant le caractère indiqué par index. Retourne une valeur vide.
$widget->invoke(element);
Provoque l'invocation de l'élément spécifié, qui peut être buttondown ou buttonup, déclenchant l'action associée.
$widget->scan(option, args);
Cette commande est utilisée pour implémenter le scan dans les Spinbox. Elle a deux formes selon option :
$widget->scanMark(x);
Enregistre x et l'état actuel de la vue dans la fenêtre du Spinbox ; est utilisé en conjonction avec les commandes ultérieures scan dragto. Cette commande est généralement associée à un clic du bouton de la souris sur le widget. Retourne une valeur vide.
$widget->scanDragto(x);
Calcule la différence entre le x de cette commande et le x de la dernière commande scan mark du widget. Ensuite, ajuste la vue vers la gauche ou vers la droite 10 fois la différence en coordonnées x. Cette commande est généralement associée aux événements de mouvement de la souris sur le widget, pour produire l'effet de faire glisser rapidement le Spinbox dans la fenêtre. La valeur retournée est une valeur vide.
$widget->selection(option, arg);
Cette commande est utilisée pour ajuster la sélection dans le Spinbox. Elle a plusieurs formes selon option :
$widget->selectionAdjust(index);
Localise l'extrémité de la sélection la plus proche du caractère donné par index, et ajuste cette extrémité à index (c'est-à-dire en incluant mais sans dépasser index). L'autre extrémité de la sélection devient le point d'ancrage pour les commandes select to futures. Si la sélection n'est pas dans le Spinbox, une nouvelle sélection est créée qui inclut les caractères entre index et le dernier point d'ancrage, y compris index. Retourne une valeur vide.
$widget->selectionClear;
Supprime la sélection si elle est active dans ce widget. Si elle n'est pas active, la commande n'a aucun effet. Retourne une valeur vide.
$widget->selectionElement(?element?);
Définit ou obtient l'élément actuellement sélectionné. Si un élément de spinbutton est spécifié, il sera affiché dans un état enfoncé.
$widget->selectionFrom(index);
Définit le point d'ancrage de la sélection juste avant le caractère donné par index. Ne modifie pas la sélection. Retourne une valeur vide.
$widget->selectionPresent;
Retourne 1 s'il y a des caractères sélectionnés dans le Spinbox, 0 s'il n'y a pas de sélection.
$widget->selectionRange(start, end);
Définit la sélection pour inclure les caractères situés à la position indiquée par start et avant end. Si end fait référence au même caractère que start ou à un caractère précédent, la sélection du Spinbox est effacée.
$widget->selectionTo(index);
Si index est avant le point d'ancrage, la sélection est définie de index jusqu'au point d'ancrage inclus mais sans le dépasser. Si index est égal au point d'ancrage, rien ne se passe. Si index est après le point d'ancrage, la sélection est définie du point d'ancrage jusqu'à index inclus mais sans le dépasser. Le point d'ancrage est déterminé par la dernière commande select from ou select adjust sur ce widget. Si la sélection n'est pas sur ce widget, une nouvelle sélection est créée en utilisant le dernier point d'ancrage spécifié pour le widget. Retourne une valeur vide.
$widget->set(?string?);
Si string est spécifié, le Spinbox tentera de le définir à cette valeur, sinon il retourne uniquement le texte du Spinbox. Si la validation est active, la mise à jour est effectuée lorsque le texte est défini.
$widget->validate;
Cette commande est utilisée pour forcer l'évaluation de validateCommand indépendamment des conditions spécifiées par l'option validate. Ceci est réalisé en définissant temporairement l'option validate sur all. Retourne 0 ou 1.
$widget->xview(args);
Cette commande est utilisée pour interroger et modifier la position horizontale du texte dans la fenêtre du widget. Elle peut prendre l'une des formes suivantes :
$widget->xview;
Retourne une liste de deux éléments. Chaque élément est une fraction réelle comprise entre 0 et 1 ; ensemble, ils décrivent la plage horizontale visible dans la fenêtre. Par exemple, si le premier élément est .2 et le second .6, 20% du texte du Spinbox est hors de vue à gauche, les 40% du milieu sont visibles dans la fenêtre, et 40% du texte est hors de vue à droite. Ces valeurs sont les mêmes que celles passées aux barres de défilement via l'option -xscrollcommand.
$widget->xview(index);
Ajuste la vue dans la fenêtre de manière à ce que le caractère donné par index apparaisse sur le côté gauche de la fenêtre.
$widget->xviewMoveto(fraction);
Ajuste la vue dans la fenêtre de manière à ce que le caractère situé à la fraction fraction du texte apparaisse sur le côté gauche de la fenêtre. Fraction doit être une fraction comprise entre 0 et 1.
$widget->xviewScroll(number, what);
Cette commande fait défiler la vue dans la fenêtre vers la gauche ou vers la droite selon number et what. Number doit être un entier. What doit être units, pages ou une abréviation de l'un de ceux-ci. Si what est units, la vue est ajustée vers la gauche ou vers la droite de number caractères moyens à l'écran ; si c'est pages, elle est ajustée de number pages. Si number est négatif, les caractères les plus à gauche sont affichés ; s'il est positif, les caractères les plus à droite sont affichés.

NOM

Tk::Spinbox - Un widget de contrôle de valeur.

SYNOPSIS

    use Tk;

    my $spinbox = $mw->Spinbox(

DESCRIPTION

Le widget Spinbox est une extension du widget Entry qui permet à l'utilisateur de sélectionner une valeur à partir d'une liste prédéfinie ou de saisir une valeur personnalisée. Il combine un champ de texte avec deux boutons (généralement des flèches) qui permettent de faire défiler les valeurs prédéfinies.

VALIDATION

Le widget Spinbox prend en charge la validation des entrées. Les options -validate, -validatecommand et -invalidcommand peuvent être utilisées pour spécifier le comportement de validation.

[1]

[2]
La méthode -setvalue permet de définir la valeur du widget Spinbox. Elle prend la nouvelle valeur comme argument.
[3]
La méthode -insert insère une chaîne de caractères à la position spécifiée dans le champ d'entrée du Spinbox.
[4]
La méthode -delete supprime une partie du texte du champ d'entrée du Spinbox. Elle prend deux arguments: l'indice de début et l'indice de fin de la suppression.
[5]
La méthode -icursor déplace le curseur d'insertion à la position spécifiée.
[6]
La méthode -selection permet de définir ou d'obtenir la sélection actuelle dans le champ d'entrée du Spinbox. Sans argument, elle renvoie la sélection. Avec deux arguments, elle définit la sélection.
[7]
La méthode -xview et -yview contrôlent le défilement du contenu du Spinbox.
[8]

[11]
