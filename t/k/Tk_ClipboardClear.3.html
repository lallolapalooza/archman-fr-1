Tk_ClipboardClear(3) Procédures de la bibliothèque Tk Tk_ClipboardClear(3)

NOM

Tk_ClipboardClear, Tk_ClipboardAppend - Gérer le presse-papiers

SYNOPSIS

#include <tk.h>

int
Tk_ClipboardClear(interp, tkwin)

int
Tk_ClipboardAppend(interp, tkwin, target, format, buffer)

ARGUMENTS

Tcl_Interp *interp (entrée)
Interpréteur à utiliser pour signaler les erreurs.
Tk_Window tkwin (entrée)
Fenêtre qui détermine quel écran de presse-papiers manipuler.
Atom target (entrée)
Type de conversion pour cet élément du presse-papiers ; a le même sens que l'argument target de Tk_CreateSelHandler.
Atom format (entrée)
Représentation à utiliser lors de la récupération des données ; a le même sens que l'argument format de Tk_CreateSelHandler.
const char *buffer (entrée)
Chaîne de caractères terminée par un caractère nul contenant les données à ajouter au presse-papiers.

DESCRIPTION

Ces deux procédures gèrent le presse-papiers pour Tk. Le presse-papiers est généralement géré en appelant Tk_ClipboardClear une fois, puis en appelant Tk_ClipboardAppend pour ajouter des données pour n'importe quel nombre de cibles.

Tk_ClipboardClear revendique la sélection CLIPBOARD et libère tous les éléments de données précédemment stockés dans le presse-papiers de cette application. Elle renvoie normalement TCL_OK, mais si une erreur se produit, elle renvoie TCL_ERROR et laisse un message d'erreur dans le résultat de l'interpréteur interp. Tk_ClipboardClear doit être appelée avant qu'une séquence d'appels à Tk_ClipboardAppend ne puisse être émise.

Tk_ClipboardAppend ajoute un tampon de données au presse-papiers. Le premier tampon pour une target donnée détermine le format pour cette target. Toutes les additions successives pour cette target doivent avoir le même format, sinon une erreur sera renvoyée. Tk_ClipboardAppend renvoie TCL_OK si le tampon est copié avec succès dans le presse-papiers. Si le presse-papiers n'est pas actuellement possédé par l'application, soit parce que Tk_ClipboardClear n'a pas été appelé, soit parce que la propriété du presse-papiers a changé depuis le dernier appel à Tk_ClipboardClear, Tk_ClipboardAppend renvoie TCL_ERROR et laisse un message d'erreur dans le résultat de l'interpréteur interp.

Afin de garantir l'atomicité, aucun traitement d'événements ne devrait se produire entre Tk_ClipboardClear et les appels suivants à Tk_ClipboardAppend (sinon quelqu'un pourrait récupérer un presse-papiers partiellement complété ou revendiquer la propriété loin de cette application).

Tk_ClipboardClear peut invoquer des rappels, y compris des scripts Tcl arbitraires, à la suite de la perte de la sélection CLIPBOARD, de sorte que toute fonction appelante doit prendre soin d'être réentrante au point où Tk_ClipboardClear est invoquée.
