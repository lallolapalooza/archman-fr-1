Tk_Init(3) Procédures de la bibliothèque Tk Tk_Init(3)

NOM

Tk_Init, Tk_SafeInit - ajouter Tk à un interpréteur et créer une nouvelle application Tk.

SYNOPIS

#include <tk.h>

int
Tk_Init(interp)

int
Tk_SafeInit(interp)

ARGUMENTS

Tcl_Interp *interp (entrée)
Interpréteur dans lequel charger Tk. Tk ne doit pas être déjà chargé dans cet interpréteur.

DESCRIPTION

Tk_Init est la procédure d'initialisation du paquet pour Tk. Elle est normalement appelée par la procédure Tcl_AppInit d'une application ou par la commande load. Tk_Init ajoute toutes les commandes de Tk à interp et crée une nouvelle application Tk, y compris sa fenêtre principale. Si l'initialisation réussit, Tk_Init retourne TCL_OK ; en cas d'erreur, elle retourne TCL_ERROR. Tk_Init laisse également un résultat ou un message d'erreur dans le résultat de l'interpréteur interp.

S'il existe une variable argv dans interp, Tk_Init traite le contenu de cette variable comme une liste d'options pour la nouvelle application Tk. Les options peuvent avoir l'une des formes documentées pour l'application wish (en fait, wish utilise Tk_Init pour traiter ses arguments de ligne de commande).

Tk_SafeInit est identique à Tk_Init sauf qu'elle supprime toutes les commandes Tk considérées comme non sécurisées. Ces commandes et les raisons de leur exclusion sont les suivantes :

bell
La sonnerie continue de la cloche est une nuisance.
clipboard
Un script malveillant pourrait remplacer le contenu du presse-papiers par la chaîne “rm -r *” et entraîner des surprises lors du collage du contenu du presse-papiers.
grab
La saisie peut être utilisée pour empêcher l'utilisateur d'utiliser d'autres applications.
menu
Les menus peuvent être utilisés pour couvrir tout l'écran et voler l'entrée de l'utilisateur.
selection
Voir presse-papiers.
send
L'envoi peut être utilisé pour faire exécuter des commandes par des interpréteurs non sécurisés.
tk
La commande tk recrée la commande send, qui n'est pas sécurisée.
tkwait
Tkwait peut bloquer le processus conteneur indéfiniment.
toplevel
Les fenêtres de niveau supérieur peuvent être utilisées pour couvrir tout l'écran et voler l'entrée de l'utilisateur.
wm
Si des fenêtres de niveau supérieur sont autorisées, wm peut être utilisé pour supprimer les décorations, déplacer les fenêtres, etc.
