Tk_CreateSelHandler(3) Procédures de la bibliothèque Tk Tk_CreateSelHandler(3)

NOM

Tk_CreateSelHandler, Tk_DeleteSelHandler - organiser la gestion des demandes de sélection

SYNTAXE

#include <tk.h>

Tk_CreateSelHandler(tkwin, selection, target, proc, clientData, format)

Tk_DeleteSelHandler(tkwin, selection, target)

ARGUMENTS

Tk_Window tkwin (en entrée)
Fenêtre pour laquelle proc fournira des informations de sélection.
Atom selection (en entrée)
Le nom de la sélection pour laquelle proc fournira des informations de sélection.
Atom target (en entrée)
Le format dans lequel proc peut fournir la sélection (par exemple, STRING ou FILE_NAME). Correspond aux arguments type dans les commandes selection.
Tk_SelectionProc *proc (en entrée)
Procédure à appeler chaque fois que la sélection est détenue par tkwin et que le contenu de la sélection est demandé dans le format spécifié par target.
ClientData clientData (en entrée)
Valeur arbitraire d'un mot à passer à proc.
Atom format (en entrée)
Si le demandeur de sélection ne se trouve pas dans ce processus, format détermine la représentation utilisée pour transmettre la sélection à son demandeur.

DESCRIPTION

Tk_CreateSelHandler organise l'appel d'une procédure spécifique (proc) chaque fois que selection est détenue par tkwin et que le contenu de la sélection est demandé dans le format spécifié par target. Target doit être l'une des entrées définies dans la colonne de gauche du Tableau 2 du Manuel des Conventions de Communication Inter-Client X (ICCCM) ou tout autre format dans lequel une application est disposée à présenter la sélection. Le format le plus courant est STRING.

Proc doit avoir des arguments et un résultat correspondant au type Tk_SelectionProc :

typedef int Tk_SelectionProc(
        ClientData clientData,
        int offset,
        char *buffer,
        int maxBytes);
Le paramètre clientData de proc est une copie de l'argument clientData fourni à Tk_CreateSelHandler. Typiquement, clientData pointe vers une structure de données contenant des informations spécifiques à l'application nécessaires pour récupérer la sélection. Offset spécifie une position de décalage dans la sélection, buffer spécifie un emplacement où copier les informations concernant la sélection, et maxBytes spécifie la quantité d'espace disponible dans buffer. Proc doit placer une chaîne terminée par NULL dans buffer contenant maxBytes caractères ou moins (sans inclure le NULL de fin), et doit retourner le nombre de caractères non-NULL stockés dans buffer. Si la sélection n'existe plus (par exemple, elle existait auparavant mais l'utilisateur a supprimé la plage de caractères qui la contenait), alors proc doit retourner -1.

Lors du transfert de grandes sélections, Tk les divisera en plus petits morceaux (généralement quelques milliers d'octets chacun) pour une transmission plus efficace. Il le fera en appelant proc une ou plusieurs fois, en utilisant des valeurs d'offset successivement plus élevées pour récupérer des portions successives de la sélection. Si proc retourne un nombre inférieur à maxBytes, cela signifie que tout le reste de la sélection a été retourné. Si la valeur de retour de proc est maxBytes, cela signifie qu'il peut y avoir des informations supplémentaires dans la sélection, Tk doit donc faire un autre appel à proc pour récupérer la partie suivante.

Proc retourne toujours des informations de sélection sous forme de chaîne de caractères. Cependant, l'ICCCM permet de transmettre des informations du propriétaire de la sélection au demandeur de la sélection dans plusieurs formats, tels qu'une chaîne, un tableau d'atomes, un tableau d'entiers, etc. L'argument format de Tk_CreateSelHandler indique quel format doit être utilisé pour transmettre la sélection à son demandeur (voir la colonne du milieu du Tableau 2 de l'ICCCM pour des exemples). Si format n'est pas STRING, alors Tk prendra la valeur retournée par proc et la divisera en champs séparés par des espaces blancs. Si format est ATOM, alors Tk retournera la sélection comme un tableau d'atomes, chaque champ du résultat de proc étant traité comme le nom d'un atome. Pour toute autre valeur de format, Tk retournera la sélection comme un tableau de valeurs 32 bits où chaque champ du résultat de proc est traité comme un nombre et traduit en une valeur 32 bits. Dans tous les cas, l'atome format est retourné au demandeur de sélection avec le contenu de la sélection.

Si Tk_CreateSelHandler est appelé alors qu'il existe déjà un gestionnaire pour selection et target sur tkwin, le gestionnaire existant est remplacé par un nouveau.

Tk_DeleteSelHandler supprime le gestionnaire spécifié par tkwin, selection et target, s'il en existe un. S'il n'en existe pas, elle n'a aucun effet.
