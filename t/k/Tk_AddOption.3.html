Tk_AddOption(3) Procédures de la bibliothèque Tk Tk_AddOption(3)

NOM

Tk_AddOption - Ajouter une option à la base de données d'options

SYNTAXE

#include <tk.h>

void
Tk_AddOption(tkwin, name, value, priority)

ARGUMENTS

Tk_Window tkwin (entree)
Jeton de la fenêtre.
const char *name (entree)
Nom multi-éléments de l'option.
const char *value (entree)
Valeur de l'option.
int priority (entree)
Niveau de priorité global à utiliser pour l'option.

DESCRIPTION

Cette procédure est appelée pour ajouter une option à la base de données associée à la fenêtre principale de tkwin. Name contient l'option spécifiée et se compose de noms et/ou de classes séparés par des astérisques ou des points, dans le format X habituel. Value contient la chaîne de caractères à associer à name ; cette valeur sera retournée dans les appels à Tk_GetOption. Priority spécifie la priorité de la valeur ; lorsque les options sont interrogées à l'aide de Tk_GetOption, la valeur ayant la priorité la plus élevée est retournée. Priority doit être compris entre 0 et TK_MAX_PRIO (100). Quelques valeurs de priorité courantes sont :

TK_WIDGET_DEFAULT_PRIO
Utilisé pour les valeurs par défaut codées en dur dans les widgets.
TK_STARTUP_FILE_PRIO
Utilisé pour les options spécifiées dans les fichiers de démarrage spécifiques à l'application.
TK_USER_DEFAULT_PRIO
Utilisé pour les options spécifiées dans les fichiers de configuration par défaut de l'utilisateur, tels que .Xdefaults, les bases de données de ressources chargées dans le serveur X, ou les fichiers de démarrage spécifiques à l'utilisateur.
TK_INTERACTIVE_PRIO
Utilisé pour les options spécifiées de manière interactive après le démarrage de l'application.
