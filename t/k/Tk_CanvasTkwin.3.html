Tk_CanvasTkwin(3) Procédures de la bibliothèque Tk Tk_CanvasTkwin(3)

NOM

Tk_CanvasTkwin, Tk_CanvasGetCoord, Tk_CanvasDrawableCoords, Tk_CanvasSetStippleOrigin, Tk_CanvasWindowCoords, Tk_CanvasEventuallyRedraw, Tk_CanvasTagsOption - procédures utilitaires pour les gestionnaires de type de canevas

SYNTAXE

#include <tk.h>

Tk_Window
Tk_CanvasTkwin(canvas)

int
Tk_CanvasGetCoord(interp, canvas, string, doublePtr)

Tk_CanvasDrawableCoords(canvas, x, y, drawableXPtr, drawableYPtr)

Tk_CanvasSetStippleOrigin(canvas, gc)

Tk_CanvasWindowCoords(canvas, x, y, screenXPtr, screenYPtr)

Tk_CanvasEventuallyRedraw(canvas, x1, y1, x2, y2)

Tk_OptionParseProc *Tk_CanvasTagsParseProc;

Tk_OptionPrintProc *Tk_CanvasTagsPrintProc;

ARGUMENTS

Tk_Canvas canvas (in)
Un jeton qui identifie un widget canevas.
Tcl_Interp *interp (in/out)
Interpréteur à utiliser pour la signalisation d'erreurs.
const char *string (in)
Description textuelle d'une coordonnée de canevas.
double *doublePtr (out)
Pointeur vers l'emplacement où stocker une coordonnée convertie.
double x (in)
Une coordonnée x dans l'espace du canevas.
double y (in)
Une coordonnée y dans l'espace du canevas.
short *drawableXPtr (out)
Pointeur vers un emplacement où stocker une coordonnée x dans l'espace du élément dessinable actuellement utilisé pour redessiner le canevas.
short *drawableYPtr (out)
Pointeur vers un emplacement où stocker une coordonnée y dans l'espace du élément dessinable actuellement utilisé pour redessiner le canevas.
GC gc (out)
Contexte graphique à modifier.
short *screenXPtr (out)
Pointeur vers un emplacement où stocker la coordonnée écran dans la fenêtre du canevas qui correspond à x.
short *screenYPtr (out)
Pointeur vers un emplacement où stocker la coordonnée écran dans la fenêtre du canevas qui correspond à y.
int x1 (in)
Bord gauche de la région qui doit être redessinée. Seuls les pixels à cette coordonnée ou à sa droite doivent être redessinés.
int y1 (in)
Bord supérieur de la région qui doit être redessinée. Seuls les pixels à cette coordonnée ou en dessous doivent être redessinés.
int x2 (in)
Bord droit de la région qui doit être redessinée. Seuls les pixels à gauche de cette coordonnée doivent être redessinés.
int y2 (in)
Bord inférieur de la région qui doit être redessinée. Seuls les pixels au-dessus de cette coordonnée doivent être redessinés.

DESCRIPTION

Ces procédures sont appelées par les gestionnaires de type de canevas pour effectuer diverses fonctions utilitaires.

Tk_CanvasTkwin renvoie la Tk_Window associée à un canevas particulier.

Tk_CanvasGetCoord traduit une spécification de coordonnée textuelle (comme 2p ou 1.6c) en une coordonnée de canevas en double précision. Si string est une description de coordonnée valide, alors Tk_CanvasGetCoord stocke la coordonnée de canevas correspondante à *doublePtr et renvoie TCL_OK. Sinon, elle stocke un message d'erreur dans le résultat de l'interpréteur et renvoie TCL_ERROR.

Tk_CanvasDrawableCoords est appelée par les gestionnaires de type lors du redessin pour calculer où dessiner les choses. Étant donné les coordonnées x et y dans l'espace du canevas, Tk_CanvasDrawableCoords calcule le pixel correspondant dans l'élément dessinable actuellement utilisé pour le redessin ; elle renvoie ces coordonnées dans *drawableXPtr et *drawableYPtr. Cette procédure ne doit pas être invoquée sauf pendant le redessin.

Tk_CanvasSetStippleOrigin est également utilisée pendant le redessin. Elle définit l'origine du pointillé dans gc afin que les pointillés dessinés avec gc dans la pixmap hors écran actuelle s'alignent avec les pointillés dessinés avec l'origine (0,0) dans la fenêtre réelle du canevas. Tk_CanvasSetStippleOrigin est nécessaire pour garantir que les motifs de pointillés s'alignent correctement lorsque le canevas est redessiné en petites portions. Les redessins sont effectués en mode double tampon où une portion du canevas est redessinée dans une pixmap hors écran, puis copiée sur l'écran. Dans cette approche, les origines des pointillés dans les contextes graphiques doivent être ajustées lors de chaque redessin pour compenser la position de la pixmap hors écran par rapport à la fenêtre. Si un élément est dessiné avec des pointillés, son gestionnaire de type appelle généralement Tk_CanvasSetStippleOrigin juste avant d'utiliser gc pour dessiner quelque chose ; après avoir terminé le dessin, le gestionnaire de type appelle XSetTSOrigin pour restaurer l'origine dans gc à (0,0) (la restauration est nécessaire car les contextes graphiques sont partagés, ils ne peuvent donc pas être modifiés de manière permanente).

Tk_CanvasWindowCoords est similaire à Tk_CanvasDrawableCoords sauf qu'elle renvoie les coordonnées dans la fenêtre du canevas à l'écran, au lieu de coordonnées dans une pixmap hors écran.

Tk_CanvasEventuallyRedraw peut être invoquée par un gestionnaire de type pour informer Tk qu'une portion d'un canevas doit être redessinée. Les arguments x1, y1, x2 et y2 spécifient la région qui doit être redessinée, en coordonnées de canevas. Les gestionnaires de type ont rarement besoin d'invoquer Tk_CanvasEventuallyRedraw, car Tk peut normalement déterminer quand un élément a changé et faire la demande de redessin en son nom (cela se produit, par exemple, chaque fois que Tk appelle une configureProc ou une scaleProc). Le seul moment où un gestionnaire de type doit appeler Tk_CanvasEventuallyRedraw est si un élément a changé de lui-même sans avoir été invoqué par l'une des procédures de son Tk_ItemType ; cela pourrait se produire, par exemple, dans un élément image si l'image est modifiée à l'aide des commandes d'image.

Tk_CanvasTagsParseProc et Tk_CanvasTagsPrintProc sont des procédures qui gèrent l'option -tags pour les éléments de canevas. Le code d'un gestionnaire de type de canevas n'appellera pas ces procédures directement, mais utilisera leurs adresses pour créer une structure Tk_CustomOption pour l'option -tags. Le code ressemble typiquement à ceci :

static const Tk_CustomOption tagsOption = {Tk_CanvasTagsParseProc,
    Tk_CanvasTagsPrintProc, NULL
};
static const Tk_ConfigSpec configSpecs[] = {
    ...
    {TK_CONFIG_CUSTOM, "-tags", NULL, NULL,
        NULL, 0, TK_CONFIG_NULL_OK, &tagsOption},
    ...
};
