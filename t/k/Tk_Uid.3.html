Tk_GetUid(3) Procédures de la bibliothèque Tk Tk_GetUid(3)

NOM

Tk_GetUid, Tk_Uid - convertir une chaîne en identifiant unique

SYNTAXE

#include <tk.h>

Tk_Uid
Tk_GetUid(string)

ARGUMENTS

char *string (in)
Chaîne pour laquelle l'identifiant unique correspondant est souhaité.

DESCRIPTION

Tk_GetUid renvoie l'identifiant unique correspondant à string. Les identifiants uniques sont similaires aux atomes en Lisp, et sont utilisés dans Tk pour accélérer les comparaisons et les recherches. Un identifiant unique (type Tk_Uid) est un pointeur de chaîne et peut être utilisé partout où une variable de type “char *” pourrait être utilisée. Cependant, il est garanti qu'il n'existe qu'un seul identifiant unique pour chaque valeur de chaîne donnée. Si Tk_GetUid est appelée deux fois, une fois avec la chaîne a et une fois avec la chaîne b, et si a et b ont la même valeur de chaîne (strcmp(a, b) == 0), alors Tk_GetUid renverra exactement la même valeur Tk_Uid pour chaque appel (Tk_GetUid(a) == Tk_GetUid(b)). Cela signifie que les variables de type Tk_Uid peuvent être comparées directement (x == y) sans avoir à appeler strcmp. De plus, la valeur de retour de Tk_GetUid aura la même valeur de chaîne que son argument (strcmp(Tk_GetUid(a), a) == 0).
