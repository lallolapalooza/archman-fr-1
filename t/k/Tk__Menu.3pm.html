Une entrée de menu radiobutton se comporte de manière similaire à un widget radiobutton. Les entrées radiobutton sont organisées en groupes dont une seule entrée peut être sélectionnée à la fois. Chaque fois qu'une entrée particulière devient sélectionnée, elle stocke une valeur particulière dans une variable globale particulière (telle que déterminée par les options -value et -variable de l'entrée). Cette action provoque la désélection de toute entrée précédemment sélectionnée dans le même groupe. Une fois qu'une entrée est devenue sélectionnée, toute modification de la variable associée à l'entrée provoquera sa désélection. Le regroupement des entrées radiobutton est déterminé par leurs variables associées : si deux entrées ont la même variable associée, alors elles appartiennent au même groupe. Un indicateur en forme de diamant est affiché à gauche du libellé de chaque entrée radiobutton. Si l'entrée est sélectionnée, le centre de l'indicateur est affiché dans la couleur donnée par l'option -selectcolor de l'entrée ; sinon, le centre de l'indicateur est affiché dans la couleur de fond du menu. Si une option -command est spécifiée pour une entrée radiobutton, alors sa valeur est évaluée chaque fois que l'entrée est appelée ; cela se produit après la sélection de l'entrée.

ENTRÉES CASCADE

Une entrée cascade est une entrée avec un menu associé (déterminé par l'option -menu). Les entrées cascade permettent la construction de menus en cascade. La méthode postcascade peut être utilisée pour afficher et masquer le menu associé juste à côté de l'entrée cascade. Le menu associé doit être un enfant du menu contenant l'entrée cascade (cela est nécessaire pour que la traversée du menu fonctionne correctement).

Une entrée cascade affiche son menu associé en appelant

$menu->post(x,y)

où menu est le nom du chemin du menu associé, et x et y sont les coordonnées de la fenêtre racine du coin supérieur droit de l'entrée cascade. Sur Unix, le menu de niveau inférieur est désaffiché en exécutant

$menu->unpost

où menu est le nom du menu associé. Sur d'autres plateformes, le code natif de la plateforme se charge de désafficher le menu.

Si une option -command est spécifiée pour une entrée cascade, elle est évaluée chaque fois que l'entrée est appelée. Ceci n'est pas pris en charge sous Windows.

ENTRÉES TEAR-OFF

Une entrée tear-off apparaît en haut du menu si elle est activée avec l'option tearOff. Elle ne ressemble pas aux autres entrées de menu car elle ne peut pas être créée avec la méthode add et ne peut pas être supprimée avec la méthode delete. Lorsqu'une entrée tear-off est créée, elle apparaît comme une ligne pointillée en haut du menu. Sous les liaisons par défaut, l'appel de l'entrée tear-off provoque la création d'une copie "arrachée" du menu et de tous ses sous-menus.

BARRES DE MENUS

Tout menu peut être défini comme une barre de menus pour une fenêtre de niveau supérieur (voir le constructeur Toplevel pour la syntaxe). Sur Macintosh, chaque fois que la fenêtre de niveau supérieur est au premier plan, les éléments en cascade de ce menu apparaissent dans la barre de menus en haut de l'écran principal. Sous Windows et Unix, les éléments de ce menu sont affichés dans une barre de menus en haut de la fenêtre. Ces menus se comporteront conformément aux directives d'interface de leurs plateformes. Pour chaque menu défini comme barre de menus, un menu clone est créé. Voir "CLONES" pour plus d'informations.

Comme mentionné, les barres de menus peuvent se comporter différemment selon les plateformes. Un exemple de cela concerne la gestion des cases à cocher et des boutons radio dans le menu. Bien qu'il soit permis de placer ces éléments de menu dans les barres de menus, ils peuvent ne pas être dessinés avec des indicateurs sur certaines plateformes, en raison de restrictions système.

MENUS SPÉCIAUX DANS LES BARRES DE MENUS

Certains menus dans une barre de menus seront traités spécialement. Sur Macintosh, l'accès aux menus spéciaux Apple et Aide est fourni. Sous Windows, l'accès au menu Système Windows de chaque fenêtre est fourni. Sous X Windows, un menu d'aide spécial aligné à droite est fourni. Dans tous les cas, ces menus doivent être créés avec le nom de commande du menu de la barre de menus concaténé avec le nom spécial. Ainsi, pour une barre de menus nommée .menubar, sur Macintosh, les menus spéciaux seraient .menubar.apple et .menubar.help ; sous Windows, le menu spécial serait .menubar.system ; sous X Windows, le menu d'aide serait .menubar.help.

Lorsque Tk rencontre un menu Apple sur Macintosh, le contenu de ce menu constitue les premiers éléments du menu Apple à l'écran lorsque la fenêtre contenant la barre de menus est au premier plan. Le menu est le premier que l'utilisateur voit et a un titre qui est un logo Apple. Après tous les éléments définis par Tk, le menu aura un séparateur, suivi de tous les éléments du dossier Apple Menu Items de l'utilisateur. Comme le système utilise une procédure de définition de menu différente pour le menu Apple que celle que Tk utilise pour ses menus, et que les API système ne prennent pas entièrement en charge tout ce que Tk essaie de faire, l'élément de menu n'affichera que son texte. Aucuns attributs de police, images, bitmaps ou couleurs ne seront affichés. De plus, un menu avec un élément tearoff affichera l'élément tearoff sous la forme "(TearOff)".

Lorsque Tk rencontre un menu d'aide sur Macintosh, le contenu du menu est ajouté au menu d'aide standard à droite de la barre de menus de l'utilisateur lorsque la barre de menus de l'utilisateur est au premier plan. Les premiers éléments du menu sont fournis par Apple. Similaire au menu Apple, la personnalisation de ce menu est limitée à ce que le système fournit.

Lorsque Tk rencontre un menu Système sous Windows, ses éléments sont ajoutés au menu système auquel la barre de menus est attachée. Ce menu a une icône représentant une barre d'espace et peut être appelé avec la souris ou en tapant Alt+Barre d'espace. En raison des limitations de l'API Windows, tout changement de police, couleurs, images, bitmaps ou images tearoff n'apparaîtra pas dans le menu système.

Lorsque Tk rencontre un menu d'aide sous X Windows, le menu est déplacé pour être le dernier dans la barre de menus et est justifié à droite.

CLONES

Lorsqu'un menu est défini comme barre de menus pour une fenêtre de niveau supérieur, ou lorsqu'un menu est arraché (tear-off), un clone du menu est créé. Ce clone est un widget menu à part entière, mais il est enfant de l'original. Les modifications de la configuration de l'original se reflètent dans le clone. De plus, toutes les cascades auxquelles il est fait référence sont également clonées afin que la traversée du menu fonctionne correctement. Les clones sont détruits lorsque le tear-off ou la barre de menus disparaît, ou lorsque le menu original est détruit.

MÉTHODES DU WIDGET

La méthode Menu crée un objet widget. Cet objet prend en charge les méthodes configure et cget décrites dans Tk::options, qui peuvent être utilisées pour interroger et modifier les options décrites ci-dessus. Le widget hérite également de toutes les méthodes fournies par la classe générique Tk::Widget, ainsi que par Tk::Wm.

Plusieurs des méthodes d'un menu prennent comme argument un indicateur indiquant sur quel élément du menu opérer. Ces indicateurs sont appelés index et peuvent être spécifiés sous l'une des formes suivantes :

nombre
Spécifie l'élément numériquement, où 0 correspond à l'élément le plus haut du menu, 1 à l'élément en dessous, et ainsi de suite.
active
Indique l'élément actuellement actif. Si aucun élément n'est actif, alors cette forme est équivalente à none. Cette forme ne peut pas être abrégée.
end
Indique l'élément le plus bas du menu. S'il n'y a pas d'éléments dans le menu, alors cette forme est équivalente à none. Cette forme ne peut pas être abrégée.
last
Identique à end.
none
Indique "aucun élément" ; ceci est le plus souvent utilisé avec l'option activate pour désactiver tous les éléments du menu. Dans la plupart des cas, la spécification de none n'a aucun effet sur la méthode. Cette forme ne peut pas être abrégée.
@nombre
Dans cette forme, nombre est traité comme une coordonnée y dans la fenêtre du menu ; l'élément le plus proche de cette coordonnée y est utilisé. Par exemple, "@0" indique l'élément le plus haut dans la fenêtre.
motif
Si l'index ne correspond à aucune des formes ci-dessus, alors cette forme est utilisée. Motif est mis en correspondance avec le libellé de chaque élément du menu, en partant du haut, jusqu'à ce qu'un élément correspondant soit trouvé. (En perl/Tk, la correspondance est en cours d'examen, mais une correspondance exacte devrait fonctionner.)

Les méthodes suivantes sont possibles pour les widgets de menu :

$menu->activate(index)
Change l'état de l'élément indiqué par index en active et le redessine en utilisant ses couleurs actives. Tout élément précédemment actif est désactivé. Si index est spécifié comme none, ou si l'élément spécifié est désactivé, alors le menu se retrouve sans élément actif. Retourne une chaîne vide.
$menu->add(type, ?option, valeur, option, valeur, ...?)
Ajoute un nouvel élément au bas du menu. Le type du nouvel élément est donné par type et doit être l'un de cascade, checkbutton, command, radiobutton, ou separator, ou une abréviation unique d'un des éléments ci-dessus. Si des arguments supplémentaires sont présents, ils spécifient l'une des options suivantes :
-activebackground => valeur
Spécifie une couleur d'arrière-plan à utiliser pour afficher cet élément lorsqu'il est actif. Si cette option est spécifiée comme une chaîne vide (par défaut), alors l'option activeBackground du menu global est utilisée. Si la variable $Tk::strictMotif a été définie pour demander une conformité stricte avec Motif, alors cette option est ignorée et l'option -background est utilisée à sa place. Cette option n'est pas disponible pour les entrées séparateur ou tear-off.
-activeforeground => valeur
Spécifie une couleur de premier plan à utiliser pour afficher cet élément lorsqu'il est actif. Si cette option est spécifiée comme une chaîne vide (par défaut), le
n l'option activeForeground pour le menu global est utilisée. Cette option n'est pas disponible pour les entrées de type séparateur ou détachable.
-accelerator => valeur
Spécifie une chaîne de caractères à afficher sur le côté droit de l'entrée de menu. Décrit normalement une séquence de touches d'accélérateur qui peuvent être tapées pour invoquer la même fonction que l'entrée de menu. Cette option n'est pas disponible pour les entrées de type séparateur ou détachable.
-background => valeur
Spécifie une couleur d'arrière-plan à utiliser pour afficher cette entrée lorsqu'elle est dans l'état normal (ni active, ni désactivée). Si cette option est spécifiée comme une chaîne de caractères vide (par défaut), alors l'option background du menu global est utilisée. Cette option n'est pas disponible pour les entrées de type séparateur ou détachable.
-bitmap => valeur
Spécifie un bitmap à afficher dans le menu au lieu d'une étiquette textuelle, sous l'une des formes acceptées par Tk_GetBitmap. Cette option remplace l'option -label mais peut être réinitialisée à une chaîne de caractères vide pour permettre l'affichage d'une étiquette textuelle. Si une option -image a été spécifiée, elle remplace -bitmap. Cette option n'est pas disponible pour les entrées de type séparateur ou détachable.
-columnbreak => valeur
Lorsque cette option est à zéro, l'entrée apparaît sous l'entrée précédente. Lorsque cette option est à un, l'entrée apparaît en haut d'une nouvelle colonne dans le menu.
-compound => valeur
Spécifie si le bouton doit afficher à la fois une image et du texte, et si oui, où l'image doit être placée par rapport au texte. Les valeurs valides pour cette option sont bottom, center, left, none, right et top. La valeur par défaut est none, ce qui signifie que le bouton affichera soit une image, soit du texte, en fonction des valeurs des options -image et -bitmap.
-command => valeur
Pour les entrées de type commande, case à cocher (checkbutton) et bouton radio (radiobutton), spécifie un rappel à exécuter lorsque l'entrée de menu est invoquée. Pour les entrées de type cascade, spécifie un rappel à exécuter lorsque l'entrée est activée (c'est-à-dire juste avant que son sous-menu ne soit affiché). Non disponible pour les entrées de type séparateur ou détachable.
-font => valeur
Spécifie la police à utiliser lors du dessin de l'étiquette ou de la chaîne d'accélérateur dans cette entrée. Si cette option est spécifiée comme une chaîne de caractères vide (par défaut), alors l'option font du menu global est utilisée. Cette option n'est pas disponible pour les entrées de type séparateur ou détachable.
-foreground => valeur
Spécifie une couleur de premier plan à utiliser pour afficher cette entrée lorsqu'elle est dans l'état normal (ni active, ni désactivée). Si cette option est spécifiée comme une chaîne de caractères vide (par défaut), alors l'option foreground du menu global est utilisée. Cette option n'est pas disponible pour les entrées de type séparateur ou détachable.
-hidemargin => valeur
Spécifie si les marges standard doivent être dessinées pour cette entrée de menu. Ceci est utile lors de la création de palettes contenant des images, par exemple, des palettes de couleurs, des palettes de motifs, etc. 1 indique que la marge de l'entrée est masquée ; 0 signifie que la marge est utilisée.
-image => valeur
Spécifie une image à afficher dans le menu au lieu d'une chaîne de texte ou d'un bitmap. L'image doit avoir été créée par une invocation précédente de image create. Cette option remplace les options -label et -bitmap mais peut être réinitialisée à une chaîne de caractères vide pour permettre l'affichage d'une étiquette textuelle ou bitmap. Cette option n'est pas disponible pour les entrées de type séparateur ou détachable.
-indicatoron => valeur
Disponible uniquement pour les entrées de type case à cocher (checkbutton) et bouton radio (radiobutton). Valeur est un booléen qui détermine si l'indicateur doit être affiché ou non.
-label => valeur
Spécifie une chaîne de caractères à afficher comme étiquette d'identification dans l'entrée de menu. Non disponible pour les entrées de type séparateur ou détachable.
-menu => valeur
Disponible uniquement pour les entrées de type cascade. Spécifie le nom du chemin du sous-menu associé à cette entrée. Le sous-menu doit être un enfant du menu.
-offvalue => valeur
Disponible uniquement pour les entrées de type case à cocher (checkbutton). Spécifie la valeur à stocker dans la variable associée à l'entrée lorsqu'elle est désélectionnée.
-onvalue => valeur
Disponible uniquement pour les entrées de type case à cocher (checkbutton). Spécifie la valeur à stocker dans la variable associée à l'entrée lorsqu'elle est sélectionnée.
-selectcolor => valeur
Disponible uniquement pour les entrées de type case à cocher (checkbutton) et bouton radio (radiobutton). Spécifie la couleur à afficher dans l'indicateur lorsque l'entrée est sélectionnée. Si la valeur est une chaîne de caractères vide (par défaut), alors l'option selectColor du menu détermine la couleur de l'indicateur.
-selectimage => valeur
Disponible uniquement pour les entrées de type case à cocher (checkbutton) et bouton radio (radiobutton). Spécifie une image à afficher dans l'entrée (à la place de l'option -image) lorsqu'elle est sélectionnée. Valeur est le nom d'une image, qui doit avoir été créée par une invocation précédente de image create. Cette option est ignorée à moins que l'option -image n'ait été spécifiée.
-state => valeur
Spécifie l'un des trois états de l'entrée : normal, active, ou disabled. Dans l'état normal, l'entrée est affichée en utilisant l'option foreground du menu et l'option background de l'entrée ou du menu. L'état actif est typiquement utilisé lorsque le pointeur est sur l'entrée. Dans l'état actif, l'entrée est affichée en utilisant l'option activeForeground du menu ainsi que l'option activebackground de l'entrée. L'état désactivé signifie que l'entrée doit être insensible : les liaisons par défaut refuseront d'activer ou d'invoquer l'entrée. Dans cet état, l'entrée est affichée selon l'option disabledForeground du menu et l'option background de l'entrée. Cette option n'est pas disponible pour les entrées de type séparateur.
-underline => valeur
Spécifie l'indice entier d'un caractère à souligner dans l'entrée. Cette option est également interrogée par les liaisons par défaut et utilisée pour implémenter la navigation au clavier. 0 correspond au premier caractère du texte affiché dans l'entrée, 1 au caractère suivant, et ainsi de suite. Si un bitmap ou une image est affiché dans l'entrée, cette option est ignorée. Cette option n'est pas disponible pour les entrées de type séparateur ou détachable.
-value => valeur
Disponible uniquement pour les entrées de type bouton radio (radiobutton). Spécifie la valeur à stocker dans la variable associée à l'entrée lorsqu'elle est sélectionnée. Si une chaîne de caractères vide est spécifiée, alors l'option -label de l'entrée est utilisée comme valeur à stocker dans la variable.
-variable => valeur
Disponible uniquement pour les entrées de type case à cocher (checkbutton) et bouton radio (radiobutton). Spécifie le nom d'une variable globale à définir lorsque l'entrée est sélectionnée. Pour les entrées de type case à cocher, la variable est également définie lorsque l'entrée est désélectionnée. Pour les entrées de type bouton radio, la modification de la variable entraîne la désélection de l'entrée actuellement sélectionnée.

La méthode add renvoie une chaîne de caractères vide.

$menu->clone($parent ?, cloneType?)
Crée un clone du menu actuel en tant qu'enfant de $parent. Ce clone est un menu à part entière, mais toute modification apportée au clone est propagée au menu original et vice versa. cloneType peut être normal, menubar, ou tearoff. Ne devrait normalement pas être appelé en dehors de la bibliothèque Tk. Voir la section "CLONES" pour plus d'informations.
$menu->delete(index1?, index2?)
Supprime toutes les entrées de menu entre index1 et index2 inclus. Si index2 est omis, il prend par défaut la valeur de index1. Les tentatives de suppression d'une entrée de menu détachable sont ignorées (au lieu de cela, vous devez modifier l'option tearOff pour supprimer l'entrée détachable).
$menu->entrycget(index, option)
Retourne la valeur actuelle d'une option de configuration pour l'entrée donnée par index. Option peut avoir l'une des valeurs acceptées par la méthode add.
$menu->entryconfigure(index ?,options?)
Cette méthode est similaire à la méthode configure, sauf qu'elle s'applique aux options d'une entrée individuelle, tandis que configure s'applique aux options du menu dans son ensemble. Options peut avoir l'une des valeurs acceptées par la méthode add. Si options sont spécifiées, les options sont modifiées comme indiqué dans l'appel de méthode et la méthode renvoie une chaîne de caractères vide. Si aucune options n'est spécifiée, renvoie une liste décrivant les options actuelles de l'entrée index (voir Tk::options pour des informations sur le format de cette liste).
$menu->index(index)
Retourne l'indice numérique correspondant à index, ou none si index a été spécifié comme none.
$menu->insert(index, type?, -option=>valeur, ...?)
Identique à la méthode add, sauf qu'elle insère la nouvelle entrée juste avant l'entrée donnée par index, au lieu de l'ajouter à la fin du menu. Le type, les arguments -option et valeur ont la même interprétation que pour la méthode de widget add. Il n'est pas possible d'insérer de nouvelles entrées de menu avant l'entrée détachable, si le menu en possède une.
