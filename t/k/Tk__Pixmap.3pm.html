NOM

Tk::Pixmap - Crée des images couleur à partir de fichiers XPM.

SYNOPSIS

    $widget->Pixmap?(nom?,options?)?

DESCRIPTION

XPM est un format de fichier d'image populaire pour X Window, utilisé pour stocker des icônes couleur. Le type d'image Pixmap peut être utilisé pour créer des images couleur à partir de fichiers XPM.

Les pixmaps prennent en charge les options suivantes :

-data => chaîne
Spécifie le contenu de la pixmap source sous forme de chaîne. La chaîne doit respecter le format de fichier XPM (par exemple, comme généré par le programme pixmap(1)). Si les options -data et -file sont spécifiées, l'option -data a la priorité. Veuillez noter que le code d'analyse des fichiers XPM de la bibliothèque xpm est quelque peu fragile. La première ligne de la chaîne doit être "/* XPM */" sinon une erreur de segmentation sera causée.
-file => nom
nom donne le nom d'un fichier dont le contenu définit la pixmap source. Le fichier doit respecter le format de fichier XPM (par exemple, comme généré par le programme pixmap(1)).

MÉTHODES IMAGE

Lorsqu'une image pixmap est créée, Tk crée également un nouvel objet. Cet objet prend en charge les méthodes configure et cget décrites dans Tk::options, qui peuvent être utilisées pour interroger et modifier les options décrites ci-dessus.
