NOM

Tk::DirTree - Créer et manipuler des widgets DirTree

SYNTAXE

    use Tk::DirTree;

    $dirtree = $parent->DirTree(?options?);

CLASSE PARENT

La classe DirTree est dérivée de la classe Tree et hérite de toutes les méthodes, options et sous-widgets de sa classe parente.

OPTIONS STANDARD

Tree prend en charge toutes les options standard d'un widget Tree. Voir Tk::options pour les détails sur les options standard.

OPTIONS SPÉCIFIQUES AU WIDGET

Nom: browseCmd
Classe: BrowseCmd
Option: -browsecmd
Spécifie une fonction de rappel à appeler chaque fois que l'utilisateur navigue dans un répertoire (généralement en cliquant sur le nom du répertoire). La fonction de rappel est appelée avec un argument, le chemin d'accès complet du répertoire.
Nom: command
Classe: Command
Option: -command
Spécifie la fonction de rappel à appeler lorsque l'utilisateur active un répertoire (généralement en double-cliquant sur le nom du répertoire). La fonction de rappel est appelée avec un argument, le chemin d'accès complet du répertoire.
Nom: dircmd
Classe: DirCmd
Option: -dircmd
Spécifie la fonction de rappel à appeler lorsqu'une liste de répertoires est nécessaire pour un répertoire particulier. Si cette option n'est pas spécifiée, par défaut le widget DirTree tentera de lire le répertoire comme un répertoire Unix. Dans des cas particuliers, le programmeur de l'application peut vouloir fournir une méthode spéciale pour lire les répertoires : par exemple, lorsqu'il a besoin de lister des répertoires distants. Dans ce cas, l'option -dircmd peut être utilisée. La fonction de rappel spécifiée accepte deux arguments : le premier est le nom du répertoire à lister ; le second est une valeur booléenne indiquant si les sous-répertoires cachés doivent être listés. Cette fonction de rappel renvoie une liste de noms des sous-répertoires de ce répertoire. Par exemple : 
sub read_dir {
    my( $dir, $showhidden ) = @_;
    return( qw/DOS NORTON WINDOWS/ ) if $dir eq "C:\\";
    return();
}
Nom: showHidden
Classe: ShowHidden
Option: -showhidden
Spécifie si les répertoires cachés doivent être affichés. Par défaut, un nom de répertoire commençant par un point "." est considéré comme un répertoire caché. Cette règle peut être contournée en fournissant une option -dircmd alternative.
Nom: directory
Classe: Directory
Option: -directory
Alias: -value
Spécifie le nom du répertoire courant affiché dans le widget DirTree.

DESCRIPTION

La méthode constructeur DirTree crée une nouvelle fenêtre (fournie par l'argument $dirtree) et en fait un widget DirTree. Des options supplémentaires, décrites ci-dessus, peuvent être spécifiées dans la ligne de commande ou dans la base d'options pour configurer les aspects du DirTree tels que son curseur et son relief. Le widget DirTree affiche une vue en liste d'un répertoire, de ses répertoires précédents et de ses sous-répertoires. L'utilisateur peut choisir l'un des répertoires affichés dans la liste ou changer pour un autre répertoire.

MÉTHODES DE WIDGET

La méthode DirTree crée un objet widget. Cet objet prend en charge les méthodes configure et cget décrites dans Tk::options qui peuvent être utilisées pour interroger et modifier les options décrites ci-dessus. Le widget hérite également de toutes les méthodes fournies par la classe générique Tk::Widget.

Les méthodes supplémentaires suivantes sont disponibles pour les widgets DirTree :

$dirtree->chdir(dir)
Change le répertoire courant vers dir.

AUTRES MÉTHODES

Ces méthodes doivent être documentées ou rendues privées :

LIAISONS

Les liaisons souris et clavier du widget DirTree sont identiques aux liaisons du widget Tree.
