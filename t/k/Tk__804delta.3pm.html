NOM

Tk::804delta - ce qui est nouveau pour perl/Tk 804

DESCRIPTION

Ce document décrit les différences entre les séries Tk800 et Tk804.

Changements incompatibles

Dans Tk804.028, il y a quelques changements incompatibles supplémentaires :

Les valeurs de retour de certaines méthodes Tk::Wm (par exemple, aspect, wmGrid, iconposition, resizable ...) ont été modifiées de listes tclish (par exemple, "1 2 3 4") à des listes perl (1,2,3,4).

Tk::Wm::wmTracing nécessite un argument pour l'activer/désactiver, sans argument, il renvoie simplement la valeur actuelle.

Toutes les versions Tk804 comportent les changements incompatibles suivants :

Tk804 ne fonctionne qu'avec perl 5.8.0 et supérieur. Pour les versions plus anciennes de perl, recherchez Tk800.025.

curselection de Tk::Listbox renvoie maintenant une référence de tableau dans un contexte scalaire. Cela signifie que vous devez écrire

my(@selected) = $listbox->curselection

ou

my(@selected) = @{ $listbox->curselection }

maintenant.

La méthode fontActual renvoie maintenant la valeur en pixels au lieu de la valeur en points pour -size. Les valeurs en pixels sont exprimées sous forme de nombres négatifs.

Certaines améliorations des correctifs "dash" sont perdues pour le moment (c'est-à-dire -tile, -troughtile ...).

L'option -state n'est plus disponible pour les balises de Tk::Text. Utilisez plutôt -elide.

Améliorations

Tk804 est compatible Unicode.

Il est possible de compiler Tk avec le support Xft sur X11. Ceci est fortement recommandé si vous prévoyez d'utiliser les capacités de rendu Unicode de Tk. Cela offre également des polices anti-aliasées pour le texte normal (si vous avez des polices TrueType ou Type1 et qu'elles sont dans votre fichier de configuration fontconfig).

La nouvelle méthode chooseDirectory est disponible comme sélecteur de répertoire standard.

Tk::PNG et Tk::JPEG sont maintenant inclus dans la distribution perl/Tk, offrant un support pour les formats d'image png et jpeg.

Améliorations de Tk::Listbox : nouvelle option -activestyle, nouvelles méthodes itemconfigure et itemcget, nouveau événement virtuel <<ListboxSelect>>.

Plus de tests.
