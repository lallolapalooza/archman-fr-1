Tk_CanvasPs(3) Procédures de la bibliothèque Tk Tk_CanvasPs(3)

NOM

Tk_CanvasPsY, Tk_CanvasPsBitmap, Tk_CanvasPsColor, Tk_CanvasPsFont, Tk_CanvasPsPath, Tk_CanvasPsStipple - procédures utilitaires pour générer du Postscript pour les canevas

SYNOPIS

#include <tk.h>

double
Tk_CanvasPsY(canvas, canvasY)

int
Tk_CanvasPsBitmap(interp, canvas, bitmap, x, y, width, height)

int
Tk_CanvasPsColor(interp, canvas, colorPtr)

int
Tk_CanvasPsFont(interp, canvas, tkFont)

Tk_CanvasPsPath(interp, canvas, coordPtr, numPoints)

int
Tk_CanvasPsStipple(interp, canvas, bitmap)

ARGUMENTS

Tk_Canvas canvas (entrée)
Un jeton qui identifie un widget canevas pour lequel du Postscript est généré.
double canvasY (entrée)
Coordonnée Y dans l'espace du canevas.
Tcl_Interp *interp (entrée/sortie)
Un interpréteur Tcl ; du Postscript est ajouté à son résultat, ou le résultat peut être remplacé par un message d'erreur.
Pixmap bitmap (entrée)
Bitmap à utiliser pour générer du Postscript.
int x (entrée)
Coordonnée X dans le bitmap de la bordure gauche de la région à sortir.
int y (entrée)
Coordonnée Y dans le bitmap du bord supérieur de la région à sortir.
int width (entrée)
Largeur de la région de bitmap à sortir, en pixels.
int height (entrée)
Hauteur de la région de bitmap à sortir, en pixels.
XColor *colorPtr (entrée)
Informations sur la valeur de couleur à définir en Postscript.
Tk_Font tkFont (entrée)
Police pour laquelle le Postscript doit être généré.
double *coordPtr (entrée)
Pointeur vers un tableau de coordonnées pour un ou plusieurs points spécifiés en coordonnées de canevas. L'ordre des valeurs dans coordPtr est x1, y1, x2, y2, x3, y3, et ainsi de suite.
int numPoints (entrée)
Nombre de points à coordPtr.

DESCRIPTION

Ces procédures sont appelées par les gestionnaires de types de canevas pour effectuer des fonctions courantes liées à la génération de Postscript. La plupart des procédures prennent un argument canvas, qui fait référence à un widget canevas pour lequel du Postscript est généré.

Tk_CanvasPsY prend comme argument une coordonnée Y dans l'espace d'un canevas et retourne la valeur qui devrait être utilisée pour ce point dans le Postscript actuellement généré pour canvas. Les coordonnées Y nécessitent une transformation car Postscript utilise une origine en bas à gauche, tandis que X utilise une origine en haut à gauche. Les coordonnées X du canevas peuvent être utilisées directement en Postscript sans transformation.

Tk_CanvasPsBitmap génère du Postscript pour décrire une région d'une bitmap. Le Postscript est généré dans un format de données image approprié pour Postscript, c'est-à-dire sous forme de données entre crochets angulaires, un bit par pixel. Le Postscript est ajouté au résultat de l'interpréteur interp et TCL_OK est retourné sauf si une erreur se produit, auquel cas TCL_ERROR est retourné et le résultat de l'interpréteur est écrasé par un message d'erreur.

Tk_CanvasPsColor génère du Postscript pour définir la couleur courante afin qu'elle corresponde à son argument colorPtr, en tenant compte de toute palette de couleurs spécifiée dans la commande postscript. Elle ajoute le Postscript au résultat de l'interpréteur interp et retourne TCL_OK sauf si une erreur se produit, auquel cas TCL_ERROR est retourné et le résultat de l'interpréteur est écrasé par un message d'erreur.

Tk_CanvasPsFont génère du Postscript qui définit la police courante pour qu'elle corresponde au mieux à tkFont. Tk_CanvasPsFont prend en compte toute carte de polices spécifiée dans la commande postscript, et elle fait de son mieux pour mapper les polices X aux polices Postscript. Elle ajoute le Postscript au résultat de l'interpréteur interp et retourne TCL_OK sauf si une erreur se produit, auquel cas TCL_ERROR est retourné et le résultat de l'interpréteur est écrasé par un message d'erreur.

Tk_CanvasPsPath génère du Postscript pour définir le chemin courant vers l'ensemble de points donnés par coordPtr et numPoints. Elle ajoute le Postscript résultant au résultat de l'interpréteur interp.

Tk_CanvasPsStipple génère du Postscript qui remplira le chemin courant en utilisant un motif de trame. Elle utilise bitmap comme motif de trame et la couleur Postscript courante ; les uns dans la bitmap de trame sont dessinés dans la couleur courante, et les zéros ne sont pas dessinés du tout. Le Postscript est ajouté au résultat de l'interpréteur interp et TCL_OK est retourné, sauf si une erreur se produit, auquel cas TCL_ERROR est retourné et le résultat de l'interpréteur est écrasé par un message d'erreur.
