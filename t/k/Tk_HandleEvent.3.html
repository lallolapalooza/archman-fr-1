Tk_HandleEvent(3) Procédures de la bibliothèque Tk Tk_HandleEvent(3)

NOM

Tk_HandleEvent - invoque les gestionnaires d'événements pour les événements du système de fenêtrage

SYNTAXE

#include <tk.h>

Tk_HandleEvent(eventPtr)

ARGUMENTS

XEvent *eventPtr (entrée)
Pointeur vers l'événement X à distribuer aux gestionnaires pertinents. Il est important que tous les champs non utilisés de la structure soient mis à zéro.

DESCRIPTION

Tk_HandleEvent est une procédure de bas niveau qui traite les événements de fenêtre. Elle est appelée par Tcl_ServiceEvent (et indirectement par Tcl_DoOneEvent), et dans quelques autres cas au sein de Tk. Elle effectue des rappels à tous les gestionnaires d'événements de fenêtre (créés par des appels à Tk_CreateEventHandler) qui correspondent à eventPtr, puis retourne. Dans certains cas, il peut être utile pour une application de contourner la file d'attente d'événements Tk et d'appeler Tk_HandleEvent directement au lieu d'appeler Tcl_QueueEvent suivi de Tcl_ServiceEvent.

Cette procédure peut être invoquée de manière récursive. Par exemple, il est possible d'invoquer Tk_HandleEvent récursivement depuis un gestionnaire appelé par Tk_HandleEvent. Ce type d'opération est utile dans certaines situations modales, par exemple lorsqu'une notification a été affichée et qu'une application souhaite attendre que l'utilisateur clique sur un bouton dans la notification avant de faire quoi que ce soit d'autre.
