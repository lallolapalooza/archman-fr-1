Tk_ManageGeometry(3) Procédures de la bibliothèque Tk Tk_ManageGeometry(3)

NOM

Tk_ManageGeometry - gérer les requêtes de géométrie pour une fenêtre

SYNOPIS

#include <tk.h>

Tk_ManageGeometry(tkwin, mgrPtr, clientData)

ARGUMENTS

Tk_Window tkwin (entrée)
Jeton de la fenêtre à gérer.
const Tk_GeomMgr *mgrPtr (entrée)
Pointeur vers la structure de données contenant les informations sur le gestionnaire de géométrie, ou NULL pour indiquer que la géométrie de tkwin ne doit plus être gérée. La structure de données pointée par mgrPtr doit être statique : Tk conserve une référence à celle-ci tant que la fenêtre est gérée.
ClientData clientData (entrée)
Valeur arbitraire d'un mot à passer aux rappels du gestionnaire de géométrie.

DESCRIPTION

Tk_ManageGeometry organise un gestionnaire de géométrie particulier, décrit par l'argument mgrPtr, pour contrôler la géométrie d'une fenêtre de contenu particulière, donnée par tkwin. Si tkwin était précédemment gérée par un autre gestionnaire de géométrie, le gestionnaire précédent perd le contrôle au profit du nouveau. Si mgrPtr est NULL, la gestion de la géométrie est annulée pour tkwin.

La structure pointée par mgrPtr contient des informations sur le gestionnaire de géométrie :

typedef struct {
    const char *name;
    Tk_GeomRequestProc *requestProc;
    Tk_GeomLostSlaveProc *lostSlaveProc;
} Tk_GeomMgr;
Le champ name est le nom textuel du gestionnaire de géométrie, tel que pack ou place ; cette valeur sera retournée par la commande winfo manager.

requestProc est une procédure du gestionnaire de géométrie qui sera appelée chaque fois que Tk_GeometryRequest est appelée par la fenêtre de contenu pour modifier sa géométrie souhaitée. requestProc doit avoir des arguments et des résultats qui correspondent au type Tk_GeomRequestProc :

typedef void Tk_GeomRequestProc(
        ClientData clientData,
        Tk_Window tkwin);
Les paramètres de requestProc seront identiques aux paramètres correspondants passés à Tk_ManageGeometry. clientData pointe généralement vers une structure de données contenant des informations spécifiques à l'application sur la manière de gérer la géométrie de tkwin.

Le champ lostSlaveProc de mgrPtr pointe vers une autre procédure du gestionnaire de géométrie. Tk appellera lostSlaveProc si un autre gestionnaire appelle Tk_ManageGeometry pour réclamer tkwin au gestionnaire de géométrie actuel. lostSlaveProc n'est pas appelé si Tk_ManageGeometry est appelé avec une valeur NULL pour mgrPtr (probablement le gestionnaire de géométrie actuel a fait cet appel, il sait donc déjà que la fenêtre n'est plus gérée), et il n'est pas non plus appelé si mgrPtr est identique au gestionnaire de géométrie actuel de la fenêtre. lostSlaveProc doit avoir des arguments et des résultats qui correspondent au prototype suivant :

typedef void Tk_GeomLostSlaveProc(
        ClientData clientData,
        Tk_Window tkwin);
Les paramètres de lostSlaveProc seront identiques aux paramètres correspondants passés à Tk_ManageGeometry.
