NOM

Tk::Scrolled - Créer un widget avec des barres de défilement attachées

SYNOPIS

    $quelconque = $parent->Scrolled(Quelconque ?,-barres_de_defilement=>où? ?,...?);

DESCRIPTION

Pour arrêter un flot de widgets ScrlWhatever, Perl/Tk a introduit le constructeur spécial Scrolled. Scrolled crée un widget du type de classe Quelconque donné avec des barres de défilement attachées.

OPTIONS

Toutes les options, à l'exception de -barres_de_defilement décrite ci-dessous, sont passées au constructeur du widget Quelconque.

-barres_de_defilement
Attend comme argument la position où les barres de défilement doivent être créées : w, e ou n, s ou une combinaison de celles-ci. Si une ou les deux positions sont précédées de o, la barre de défilement n'apparaîtra que s'il y a un besoin 'réel' de défilement.

SOUS_WIDGETS annoncés

Voir "Subwidget" dans Tk::mega pour savoir comment utiliser les widgets annoncés.

défilé
le widget défilé
widget
identique à défilé ci-dessus. widget est le type de widget passé à défilé comme premier argument, en minuscules.
scrollbar_x
le widget Scrollbar utilisé pour le défilement horizontal (s'il existe)
scrollbar_y
le widget Scrollbar utilisé pour le défilement vertical (s'il existe)
coin
un cadre dans le coin entre la barre de défilement verticale et horizontale

BOGUES

Si un widget ne prend pas en charge les options -{x,y}scrollcommand, Scrolled ne se plaint pas si la classe de widget spécifiée ne les prend pas en charge. Par exemple,

    $parent->Scrolled('Button', ...)

On n'obtient pas de message d'erreur ou d'avertissement lorsqu'on essaie de configurer les barres de défilement après la construction du widget :

    $ascrolled->configure(-barres_de_defilement => 'e');
