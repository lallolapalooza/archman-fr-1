NAME

Tk::Listbox - Créer et manipuler des widgets Listbox

SYNOPSIS

$listbox = $parent->Listbox(?options?);

OPTIONS STANDARD

-background -borderwidth -cursor -disabledforeground -exportselection -font -foreground -height -highlightbackground -highlightcolor -highlightthickness -offset -relief -selectbackground -selectborderwidth -selectforeground -setgrid -state -takefocus -tile -width -xscrollcommand -yscrollcommand

Voir Tk::options pour les détails des options standard.

OPTIONS SPÉCIFIQUES AU WIDGET

Nom: activeStyle
Classe: ActiveStyle
Commutateur: -activestyle
Définit le style dans lequel l'élément actif est dessiné. Il doit être l'un des dotbox (montre une bordure autour de l'élément actif), none (aucun indicateur spécial pour l'élément actif) ou underline (souligne l'élément actif). La valeur par défaut est underline.
Nom: height
Classe: Height
Commutateur: -height
Définit la hauteur souhaitée du widget en lignes. Si elle est nulle ou négative, la hauteur souhaitée du widget est définie pour être suffisante pour contenir tous les éléments de la liste.
Nom: listVariable
Classe: Variable
Commutateur: -listvariable
Partiellement implémenté dans Perl/Tk :

Définit la référence d'une variable. La valeur de la variable est un tableau qui est affiché dans le widget ; si la valeur de la variable change, le widget est automatiquement mis à jour pour refléter la nouvelle valeur. Tenter d'affecter une variable avec une valeur non valide comme -listvariable provoquera une erreur. Tenter de désactiver une variable en cours d'utilisation comme -listvariable échouera mais ne générera pas d'erreur.

Nom: selectMode
Classe: SelectMode
Commutateur: -selectmode
Définit l'un des différents styles de manipulation de la sélection. La valeur du paramètre peut être arbitraire, mais les liaisons par défaut s'attendent à ce qu'elle soit single, browse, multiple ou extended ; la valeur par défaut est browse.
Nom: state
Classe: State
Commutateur: -state
Définit l'un des deux états pour la listbox : normal ou disabled. Si la listbox est désactivée, les éléments ne peuvent pas être insérés ou supprimés, sont dessinés dans la couleur -disabledforeground et la sélection ne peut pas être modifiée ou affichée (bien que les informations de sélection soient conservées).
Nom: width
Classe: Width
Commutateur: -width
Définit la largeur souhaitée du widget en caractères. Si la police n'a pas de largeur uniforme, le caractère ``0'' est utilisé pour convertir des unités de caractère en unités d'écran. Si elle est nulle ou négative, la largeur souhaitée du widget est définie pour être suffisante pour contenir tous les éléments de la liste.

DESCRIPTION

La méthode Listbox crée un nouveau widget (fourni par l'argument $widget) et le transforme en un widget de listbox. D'autres options, décrites ci-dessus, peuvent être spécifiées sur la ligne de commande ou dans la base d'options pour configurer des aspects tels que les couleurs, la police, le texte et le relief de la liste. La méthode listbox renvoie son argument $widget. Lorsqu'on appelle cette méthode, aucune fenêtre nommée $widget ne doit exister, mais le parent de $widget doit exister.

Une liste est un widget qui affiche une liste de chaînes de caractères, une par ligne. Lorsqu'elle est créée pour la première fois, une nouvelle liste ne contient aucun élément. Les éléments peuvent être ajoutés ou supprimés à l'aide des méthodes décrites ci-dessous. De plus, un ou plusieurs éléments peuvent être sélectionnés comme décrit ci-dessous. Si la liste exporte sa sélection (voir l'option exportSelection), alors le protocole X11 standard pour la gestion de la sélection sera observé. Les sélections de listbox sont disponibles sous le type STRING ; la valeur de la sélection sera le texte des éléments sélectionnés, avec des sauts de ligne séparant les éléments.

Il n'est pas nécessaire que tous les éléments soient affichés dans la fenêtre de liste ; les commandes décrites ci-dessous peuvent être utilisées pour changer la vue dans la fenêtre. Les listbox prennent en charge le défilement dans les deux sens grâce aux options standard xScrollCommand et yScrollCommand. Ils prennent également en charge la recherche, comme décrit ci-dessous.

INDEX

Plusieurs des méthodes de listbox prennent un ou plusieurs index comme arguments. Un index spécifie un élément particulier de la liste, sous l'une des formes suivantes :

nombre
Spécifie l'élément sous forme d'index numérique, où 0 correspond au premier élément de la liste.
active
Spécifie l'élément qui a le curseur de localisation. Cet élément sera affiché avec un soulignement lorsque la liste a le focus du clavier, et il est spécifié avec la méthode activate.
anchor
Spécifie le point d'ancrage de la sélection, qui est défini avec la méthode selection anchor.
end
Spécifie la fin de la liste. Pour la plupart des commandes, cela fait référence au dernier élément de la liste, mais pour des commandes comme index et insert, cela fait référence à l'élément juste après le dernier.
@x,y
Spécifie l'élément qui couvre le point dans la fenêtre de liste spécifié par x et y (en coordonnées de pixels). S'il n'y a pas d'élément qui couvre ce point, l'élément le plus proche sera utilisé.

Dans les descriptions des méthodes ci-dessous, les arguments nommés index, first et last contiennent toujours des index textuels sous l'une des formes mentionnées ci-dessus.

MÉTHODES DU WIDGET

La méthode Listbox crée un objet widget. Cet objet prend en charge les méthodes configure et cget décrites dans Tk::options, qui peuvent être utilisées pour interroger et modifier les options décrites ci-dessus. Le widget hérite également de toutes les méthodes fournies par la classe générique Tk::Widget.

Les méthodes supplémentaires suivantes sont disponibles pour les widgets de listbox :

$listbox->activate(index)
Définit l'élément actif comme celui spécifié par index. Si index est en dehors de la plage des éléments de la liste, l'élément le plus proche sera activé. L'élément actif est dessiné avec un soulignement lorsque le widget a le focus d'entrée, et son index peut être récupéré avec la méthode active.
$listbox->bbox(index)
Renvoie une liste de quatre nombres décrivant le rectangle de délimitation des caractères de l'élément donné par index. Les deux premiers éléments de la liste donnent les coordonnées x et y du bord supérieur du texte.
per-coin de gauche de la zone d'écran couverte par le texte (spécifié en pixels par rapport au widget) et les deux derniers éléments donnent la largeur et la hauteur de la zone, en pixels. Si aucune partie de l'élément donné par index n'est visible à l'écran, ou si index fait référence à un élément inexistant, le résultat est une chaîne vide ; si l'élément est partiellement visible, le résultat donne toute la zone de l'élément, y compris les parties qui ne sont pas visibles.
$listbox->curselection
Retourne une liste contenant les indices numériques de tous les éléments de la listbox actuellement sélectionnés. S'il n'y a aucun élément sélectionné dans la listbox, une chaîne vide est retournée.
$listbox->delete(first, ?last?)
Supprime un ou plusieurs éléments de la listbox. First et last sont des indices spécifiant le premier et le dernier élément de la plage à supprimer. Si last n'est pas spécifié, il prend par défaut la valeur de first, c'est-à-dire qu'un seul élément est supprimé.
$listbox->get(first, ?last?)
Si last est omis, retourne le contenu de l'élément de la listbox indiqué par first, ou une chaîne vide si first fait référence à un élément inexistant. Si last est spécifié, la commande retourne une liste dont les éléments sont tous les éléments de la listbox entre first et last, inclus. First et last peuvent avoir l'une des formes standard pour les indices.
$listbox->index(index)
Retourne la valeur de l'indice entier qui correspond à index. Si index est end, la valeur de retour est le nombre d'éléments dans la listbox (pas l'indice du dernier élément).
$listbox->insert(index, ?element, element, ...?)
Insère zéro ou plusieurs nouveaux éléments dans la liste juste avant l'élément donné par index. Si index est spécifié comme end, les nouveaux éléments sont ajoutés à la fin de la liste. Retourne une chaîne vide.
$listbox->itemcget(index, option)
Retourne la valeur actuelle de l'option de configuration de l'élément donnée par option. Option peut avoir l'une des valeurs acceptées par la commande itemconfigure de la listbox.
$listbox->itemconfigure(index, ?option, value, option, value, ...?)
Interroge ou modifie les options de configuration d'un élément de la listbox. Si aucune option n'est spécifiée, retourne une liste décrivant toutes les options disponibles pour l'élément (voir Tk_ConfigureInfo pour des informations sur le format de cette liste). Si une option est spécifiée sans valeur, la commande retourne une liste décrivant l'option nommée (cette liste sera identique à la sous-liste correspondante de la valeur retournée si aucune option n'est spécifiée). Si une ou plusieurs paires option-valeur sont spécifiées, la commande modifie l'option (ou les options) du widget spécifiée(s) pour lui (leur) donner la (les) valeur(s) donnée(s) ; dans ce cas, la commande retourne une chaîne vide. Les options suivantes sont actuellement prises en charge pour les éléments :
-background => color
Color spécifie la couleur d'arrière-plan à utiliser lors de l'affichage de l'élément. Elle peut avoir l'une des formes acceptées par Tk_GetColor.
-foreground => color
Color spécifie la couleur de premier plan à utiliser lors de l'affichage de l'élément. Elle peut avoir l'une des formes acceptées par Tk_GetColor.
-selectbackground => color
Color spécifie la couleur d'arrière-plan à utiliser lors de l'affichage de l'élément lorsqu'il est sélectionné. Elle peut avoir l'une des formes acceptées par Tk_GetColor.
-selectforeground => color
Color spécifie la couleur de premier plan à utiliser lors de l'affichage de l'élément lorsqu'il est sélectionné. Elle peut avoir l'une des formes acceptées par Tk_GetColor.
$listbox->nearest(y)
Étant donné une coordonnée y dans la fenêtre de la listbox, cette commande retourne l'indice de l'élément de la listbox (visible) le plus proche de cette coordonnée y.
$listbox->scan(option, args)
Cette commande est utilisée pour implémenter le balayage sur les listboxes. Elle a deux formes, selon option :
$listbox->scanMark(x, y)
Enregistre x et y ainsi que la vue actuelle dans la fenêtre de la listbox ; utilisé en conjonction avec les commandes scan dragto ultérieures. Typiquement, cette commande est associée à un clic de bouton de souris dans le widget. Elle retourne une chaîne vide.
$listbox->scanDragto(x, y.)
Cette commande calcule la différence entre ses arguments x et y et les arguments x et y de la dernière commande scan mark pour le widget. Elle ajuste ensuite la vue de 10 fois la différence des coordonnées. Cette commande est typiquement associée aux événements de mouvement de la souris dans le widget, pour produire l'effet de faire glisser la liste à grande vitesse dans la fenêtre. La valeur de retour est une chaîne vide.
$listbox->see(index)
Ajuste la vue dans la listbox afin que l'élément donné par index soit visible. Si l'élément est déjà visible, la commande n'a aucun effet ; si l'élément se trouve près d'un bord de la fenêtre, la listbox défile pour amener l'élément dans la vue au bord ; sinon, la listbox défile pour centrer l'élément.
$listbox->selection(option, arg)
Cette commande est utilisée pour ajuster la sélection dans une listbox. Elle a plusieurs formes, selon option :
$listbox->selectionAnchor(index)
Définit l'ancre de sélection à l'élément donné par index. Si index fait référence à un élément inexistant, l'élément le plus proche est utilisé. L'ancre de sélection est l'extrémité de la sélection qui est fixe lors du déplacement de la souris pour étendre une sélection. L'indice anchor peut être utilisé pour faire référence à l'élément d'ancre.
$listbox->selectionClear(first, ?last?)
Si l'un des éléments entre first et last (inclus) est sélectionné, il est désélectionné. L'état de la sélection n'est pas modifié pour les éléments en dehors de cette plage.
$listbox->selectionIncludes(index)
Retourne 1 si l'élément indiqué par index est actuellement sélectionné, 0 sinon.
$listbox->selectionSet(first, ?last?)
Sélectionne tous les éléments de la plage entre first et last, inclus, sans affecter l'état de sélection des éléments en dehors de cette plage.
$listbox->size
Retourne une chaîne décimale indiquant le nombre total d'éléments dans la listbox.
$listbox->xview(args)
Cette commande est utilisée pour interroger et modifier la position horizontale des informations dans la fenêtre du widget. Elle peut prendre l'une des formes suivantes :
$listbox->xview
Retourne une liste contenant deux éléments. Chaque élément est une fraction réelle comprise entre 0 et 1 ; ensemble, ils décrivent la plage horizontale qui est visible dans la fenêtre. Par exemple, si le premier élément est .2 et le deuxième élément est .6, 20% du texte de la listbox est hors écran vers la gauche, les 40% du milieu sont visibles dans la fenêtre, et 40% du texte sont hors écran vers la droite. Ce sont les mêmes valeurs passées aux barres de défilement via l'option -xscrollcommand.
$listbox->xview(index)
Ajuste la vue dans la fenêtre de sorte que la position de caractère donnée par index soit affichée sur le bord gauche de la fenêtre. Les positions de caractères sont définies par la largeur du caractère 0.
$listbox->xviewMoveto( fraction );
Ajuste la vue dans la fenêtre de sorte que fraction de la largeur totale du texte de la listbox soit hors écran vers la gauche. Fraction doit être une fraction comprise entre 0 et 1.
$listbox->xviewScroll( number, what );
Cette commande décale la vue dans la fenêtre vers la gauche ou vers la droite selon number et what. Number doit être un entier. What doit être soit units, soit pages, soit une abréviation de l'un de ceux-ci. Si what est units, la vue s'ajuste vers la gauche ou la droite de number unités de caractères (la largeur du caractère 0) sur l'affichage ; si c'est pages, la vue s'ajuste de number écrans. Si number est négatif, les caractères plus à gauche deviennent visibles ; s'il est positif, les caractères plus à droite deviennent visibles.
$listbox->yview(?args?)
Cette commande est utilisée pour interroger et modifier la position verticale du texte dans la fenêtre du widget. Elle peut prendre l'une des formes suivantes :
$listbox->yview
Retourne une liste contenant deux éléments, qui sont tous deux des fractions réelles comprises entre 0 et 1. Le premier élément donne la position de l'élément de la listbox en haut de la fenêtre, par rapport à la listbox dans son ensemble (0.5 signifie qu'il est à mi-chemin dans la listbox, par exemple). Le deuxième élément donne la position de l'élément de la listbox juste après le dernier dans la fenêtre, par rapport à la listbox dans son ensemble. Ce sont les mêmes valeurs passées aux barres de défilement via l'option -yscrollcommand.
$listbox->yview(index)
Ajuste la vue dans la fenêtre de sorte que l'élément donné par index soit affiché en haut de la fenêtre.
$listbox->yviewMoveto( fraction );
Ajuste la vue dans la fenêtre de sorte que l'élément donné par fraction apparaisse en haut de la fenêtre. Fraction est une fraction comprise entre 0 et 1 ; 0 indique le premier élément de la listbox, 0.33 indique l'élément situé au tiers de la listbox, et ainsi de suite.
$listbox->yviewScroll( number, what );
Cette commande ajuste la vue dans la fenêtre vers le haut ou vers le bas selon number et what. Number doit être un entier. What doit être soit units, soit pages. Si what est units, la vue s'ajuste vers le haut ou vers le bas de number lignes ; si c'est
pages puis la vue s'ajuste par nombre écrans. Si nombre est négatif, les éléments précédents deviennent visibles ; s'il est positif, les éléments suivants deviennent visibles.

LI SIONS PAR DFAUT

Tk crée automatiquement des liaisons de classe pour les listboxes qui leur donnent un comportement de type Motif. Une grande partie du comportement d'une listbox est déterminée par son option selectMode, qui sélectionne l'une des quatre façons de gérer la sélection.

Si le mode de sélection est single ou browse, au plus un élément peut être sélectionné dans la listbox à la fois. Dans les deux modes, cliquer sur le bouton 1 sur un élément le sélectionne et désélectionne tout autre élément sélectionné. En mode browse, il est également possible de faire glisser la sélection avec le bouton 1.

Si le mode de sélection est multiple ou extended, n'importe quel nombre d'éléments peut être sélectionné à la fois, y compris des plages discontinues. En mode multiple, cliquer sur le bouton 1 sur un élément inverse son état de sélection sans affecter les autres éléments. En mode extended, appuyer sur le bouton 1 sur un élément le sélectionne, désélectionne tout le reste et définit le point d'ancrage sur l'élément sous la souris ; faire glisser la souris avec le bouton 1 enfoncé étend la sélection pour inclure tous les éléments entre le point d'ancrage et l'élément sous la souris, inclus.

La plupart des gens voudront probablement utiliser le mode browse pour les sélections uniques et le mode extended pour les sélections multiples ; les autres modes ne semblent utiles que dans des situations particulières.

Chaque fois que la sélection change dans la listbox, l'événement virtuel <<ListboxSelect>> est généré. Il est plus facile de se lier à cet événement pour être informé de tout changement dans la sélection de la listbox.

En plus du comportement ci-dessus, le comportement supplémentaire suivant est défini par les liaisons par défaut :

[1]
En mode extended, la plage sélectionnée peut être ajustée en appuyant sur le bouton 1 avec la touche Maj enfoncée : cela modifie la sélection pour inclure les éléments entre le point d'ancrage et l'élément sous la souris, inclus. L'extrémité non ancrée de cette nouvelle sélection peut également être déplacée avec le bouton enfoncé.
[2]
En mode extended, appuyer sur le bouton 1 avec la touche Ctrl enfoncée démarre une opération d'inversion : le point d'ancrage est défini sur l'élément sous la souris, et son état de sélection est inversé. L'état de sélection des autres éléments n'est pas modifié. Si la souris est déplacée avec le bouton 1 enfoncé, alors l'état de sélection de tous les éléments entre le point d'ancrage et l'élément sous la souris est défini pour correspondre à celui de l'élément d'ancrage ; l'état de sélection de tous les autres éléments reste celui qu'il était avant le début de l'opération d'inversion.
[3]
Si la souris quitte la fenêtre de la listbox avec le bouton 1 enfoncé, la fenêtre défile à l'opposé de la souris, rendant visibles les informations qui étaient auparavant hors écran du côté de la souris. Le défilement continue jusqu'à ce que la souris rentre dans la fenêtre, que le bouton soit relâché ou que la fin de la listbox soit atteinte.
[4]
Le bouton de souris 2 peut être utilisé pour le balayage. S'il est enfoncé et déplacé sur la listbox, le contenu de la listbox défile à grande vitesse dans la direction où la souris se déplace.
[5]
Si la touche Haut ou Bas est enfoncée, le curseur de position (élément actif) se déplace vers le haut ou vers le bas d'un élément. Si le mode de sélection est browse ou extended, le nouvel élément actif est également sélectionné et tous les autres éléments sont désélectionnés. En mode extended, le nouvel élément actif devient le point d'ancrage de la sélection.
[6]
En mode extended, Maj-Haut et Maj-Bas déplacent le curseur de position (élément actif) vers le haut ou vers le bas d'un élément et étendent également la sélection à cet élément, de manière similaire au glissement avec le bouton de souris 1.
[7]
Les touches Gauche et Droite font défiler la vue de la listbox vers la gauche et vers la droite de la largeur du caractère 0. Ctrl-Gauche et Ctrl-Droite font défiler la vue de la listbox vers la gauche et vers la droite de la largeur de la fenêtre. Ctrl-PagePréc et Ctrl-PageSuiv font également défiler vers la gauche et vers la droite de la largeur de la fenêtre.
[8]
Les touches PagePréc et PageSuiv font défiler la vue de la listbox vers le haut et vers le bas d'une page (la hauteur de la fenêtre).
[9]
Les touches Début et Fin font défiler la listbox horizontalement vers les bords gauche et droit, respectivement.
[10]
Ctrl-Début place le curseur de position sur le premier élément de la listbox, sélectionne cet élément et désélectionne tout le reste dans la listbox.
[11]
Ctrl-Fin place le curseur de position sur le dernier élément de la listbox, sélectionne cet élément et désélectionne tout le reste dans la listbox.
[12]
En mode extended, Ctrl-Maj-Début étend la sélection au premier élément de la listbox et Ctrl-Maj-Fin étend la sélection au dernier élément.
[13]
En mode multiple, Ctrl-Maj-Début déplace le curseur de position vers le premier élément de la listbox et Ctrl-Maj-Fin déplace le curseur de position vers le dernier élément.
[14]
Les touches Espace et Sélection créent une sélection à la position du curseur (élément actif) comme si le bouton de souris 1 avait été pressé sur cet élément.
[15]
En mode extended, Ctrl-Maj-Espace et Maj-Sélection étendent la sélection à l'élément actif comme si le bouton 1 avait été pressé avec la touche Maj enfoncée.
[16]
En mode extended, la touche Échap annule la dernière sélection effectuée et restaure tous les éléments de la plage sélectionnée à leur état de sélection précédent.
[17]
Ctrl-barre oblique sélectionne tout dans le widget, sauf en modes single et browse, où il sélectionne l'élément actif et désélectionne tout le reste.
[18]
Ctrl-antislash désélectionne tout dans le widget, sauf en mode browse où il n'a aucun effet.
[19]
La touche F16 (étiquetée Copier sur de nombreux postes de travail Sun) ou Meta-w copie la sélection dans le widget dans le presse-papiers, s'il y a une sélection.

Le comportement des listboxes peut être modifié en définissant de nouvelles liaisons pour des widgets individuels ou en redéfinissant les liaisons de classe.

INTERFACE LIÉE

Le widget Tk::Listbox peut également être lié à une variable scalaire ou de tableau, avec un comportement différent selon le type de variable, à l'aide des commandes de liaison suivantes :

use Tk;
my ( @array, $scalar, $other );
my %options = ( ReturnType => "index" );
my $MW = MainWindow->new();
my $lbox = $MW->Listbox()->pack();
my @list = ( "a", "b", "c", "d", "e", "f" );
$lbox->insert('end', @list );
tie @array, "Tk::Listbox", $lbox
tie $scalar, "Tk::Listbox", $lbox;
tie $other, "Tk::Listbox", $lbox, %options;

actuellement, un seul modificateur est implémenté, un indicateur à 3 voies pour les scalaires liés : "ReturnType", qui peut avoir les valeurs "element", "index" ou "both". La valeur par défaut est "element".

Tableaux liés
Si vous liez un tableau à la Listbox, vous pouvez manipuler les éléments contenus dans la boîte de la même manière qu'un tableau normal, par exemple : 
print @array;
push(@array, @list);
my $popped = pop(@array);
my $shifted = shift(@array);
unshift(@array, @list);
delete $array[$index];
print $string if exists $array[$i];
@array = ();
splice @array, $offset, $length, @list

La fonction delete est implémentée légèrement différemment de l'implémentation standard des tableaux. Au lieu de définir l'élément à cet index sur undef, elle le supprime physiquement de la Listbox. Cela a pour effet de modifier les indices du tableau, de sorte que, par exemple, si vous aviez une liste d'indices non continus que vous souhaitiez supprimer de la Listbox, vous devriez trier la liste par ordre décroissant, puis appliquer la fonction delete, par exemple :

my @list = ( 1, 2, 4, 12, 20 );
my @remove = reverse sort { $a <=> $b } @list;
delete @array[@remove];

supprimerait en toute sécurité les indices 20, 12, 4, 2 et 1 de la Listbox sans problème. Il convient également de noter qu'un avertissement similaire s'applique à la fonction splice (qui serait normalement utilisée dans ce contexte pour accomplir le même travail).

Scalaires liés
Contrairement aux tableaux liés, si vous liez un scalaire à la Listbox, vous pouvez récupérer les éléments actuellement sélectionnés dans la boîte sous forme de tableau référencé par le scalaire, par exemple : 
my @list = ( "a", "b", "c", "d", "e", "f" );
$lbox->insert('end', sort @list );
$lbox->selectionSet(1);

insère @list comme éléments dans une listbox déjà existante et sélectionne l'élément à l'index 1, qui est "b". Si nous faisons ensuite

print @$selected;

cela renverra les éléments actuellement sélectionnés, dans ce cas "b".

Cependant, si l'argument "ReturnType" est passé lors de la liaison de la Listbox au scalaire avec la valeur "index", alors les indices des éléments sélectionnés seront renvoyés au lieu des éléments eux-mêmes, c'est-à-dire dans ce cas "1". Cela peut être utile lors de la manipulation simultanée du contenu et des éléments sélectionnés dans la Listbox.

Il est important de noter que si une valeur "both" est donnée, le scalaire ne sera pas lié à un tableau, mais à une table de hachage, avec les clés étant les indices et les valeurs étant les éléments à ces indices.

Vous pouvez également manipuler les éléments sélectionnés à l'aide du scalaire. Égaler le scalaire à une référence de tableau sélectionnera tous les éléments qui correspondent aux éléments de la Listbox, les éléments ne correspondant pas sont ignorés, par exemple :

my @list = ( "a", "b", "c", "d", "e", "f" );
$lbox->insert('end', sort @list );
$lbox->selectionSet(1);

insérera le tableau @list dans une Listbox déjà existante et sélectionnera l'élément à l'index 1, c'est-à-dire "b"

@array = ( "a", "b", "f" );
$selected = \@array;

sélectionnera les éléments "a", "b" et "f" dans la Listbox.

Là encore, si l'"index" nous indique que nous voulons utiliser les indices dans la table de hachage des options, alors les indices sont utilisés au lieu des éléments, par exemple :

@array = ( 0, 1, 5 );
$selected = \@array;

aura le même effet, sélectionnant les éléments "a", "b" et "f" si la variable $selected était liée avec l'option L

SYNOPIS

OPTIONS STANDARDS

ReturnType

OPTIONS PROPRES AU WIDGET

DESCRIPTION

Si nous retournons "both", c'est-à-dire que le scalaire lié pointe vers une hash, la clé et la valeur doivent correspondre, par exemple.

%hash = ( 0 => "a", 1 => "b", 5 => "f" );
$selected = \%hash;

aurait le même effet que les exemples précédents.

Il convient de noter que, bien qu'il s'agisse d'une référence à un tableau (ou éventuellement à une hash), vous ne pouvez toujours pas copier la variable liée sans qu'elle soit déliée ; vous devez plutôt passer une référence au scalaire lié entre les sous-routines.
