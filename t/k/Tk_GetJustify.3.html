Tk_GetJustify(3)

Paquet: tk

Licences: TCL

Tk_GetJustifyFromObj(3) Procédures de la bibliothèque Tk Tk_GetJustifyFromObj(3)

NOM

Tk_GetJustifyFromObj, Tk_GetJustify, Tk_NameOfJustify - traduire entre chaînes de caractères et styles d'alignement

SYNTAXE

#include <tk.h>

int
Tk_GetJustifyFromObj(interp, objPtr, justifyPtr)

int
Tk_GetJustify(interp, string, justifyPtr)

const char *
Tk_NameOfJustify(justify)

ARGUMENTS

Tcl_Interp *interp (entree)
Interpréteur à utiliser pour signaler les erreurs, ou NULL.
Tcl_Obj *objPtr (entree/sortie)
La valeur de la chaîne contient le nom du style d'alignement - l'un de “left”, “right” ou “center” - ou une abréviation unique de l'un d'eux. La représentation interne sera modifiée pour mettre en cache la valeur d'alignement correspondante.
const char *string (entree)
Identique à objPtr sauf que la description du style d'alignement est passée sous forme de chaîne de caractères.
int *justifyPtr (sortie)
Pointeur vers l'emplacement où stocker la valeur d'alignement correspondant à objPtr ou string.
Tk_Justify justify (entree)
Style d'alignement (l'une des valeurs listées ci-dessous).

DESCRIPTION

Tk_GetJustifyFromObj place dans *justifyPtr la valeur d'alignement correspondant à la valeur de objPtr. Cette valeur sera l'une des suivantes :

TK_JUSTIFY_LEFT
Signifie que le texte de chaque ligne doit commencer sur le bord gauche de la ligne ; par conséquent, les bords droits des lignes peuvent être irréguliers.
TK_JUSTIFY_RIGHT
Signifie que le texte de chaque ligne doit se terminer sur le bord droit de la ligne ; par conséquent, les bords gauches des lignes peuvent être irréguliers.
TK_JUSTIFY_CENTER
Signifie que le texte de chaque ligne doit être centré ; par conséquent, les bords gauches et droits des lignes peuvent être irréguliers.

Dans des circonstances normales, la valeur de retour est TCL_OK et interp n'est pas utilisé. Si objPtr ne contient pas un style d'alignement valide ou une abréviation de l'un de ces noms, TCL_ERROR est retourné, *justifyPtr n'est pas modifié et un message d'erreur est stocké dans le résultat de interp si interp n'est pas NULL. Tk_GetJustifyFromObj met en cache des informations sur la valeur de retour dans objPtr, ce qui accélère les appels futurs à Tk_GetJustifyFromObj avec le même objPtr.

Tk_GetJustify est identique à Tk_GetJustifyFromObj sauf que la description de l'alignement est spécifiée avec une chaîne de caractères au lieu d'un objet. Cela empêche Tk_GetJustify de mettre en cache la valeur de retour, de sorte que Tk_GetJustify est moins efficace que Tk_GetJustifyFromObj.

Tk_NameOfJustify est l'inverse logique de Tk_GetJustify. Étant donné une valeur d'alignement, elle retourne une chaîne de caractères allouée statiquement correspondant à justify. Si justify n'est pas une valeur d'alignement valide, alors “unknown justification style” est retourné.
