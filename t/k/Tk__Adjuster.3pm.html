NOM

Tk::Adjuster - Permet à la taille des widgets empaquetés d'être ajustée par l'utilisateur

SYNOPSIS

use Tk::Adjuster;

$ajusteur = $widget->Adjuster(?options?);

OPTIONS SPÉCIFIQUES AU WIDGET

Nom : restore
Classe : Restore
Commutateur : -restore
Spécifie une valeur booléenne qui détermine si l'ajusteur doit tenter de manière forcée de faire de la place pour lui-même (en réduisant la taille de son widget géré) lorsqu'il est non mappé (par exemple, en raison d'un changement de taille dans une fenêtre de niveau supérieur). La valeur par défaut est 1.
Nom : side
Classe : Side
Commutateur : -side
Spécifie le côté sur lequel se trouve le widget géré par rapport à l'ajusteur. En conjonction avec le gestionnaire de géométrie `pack`, cela se rapporte au côté du maître contre lequel le widget géré et l'ajusteur sont empaquetés. Doit être left, right, top, ou bottom. Par défaut, top.
Nom : widget
Classe : Widget
Commutateur : -widget
Spécifie le widget qui doit être géré par l'ajusteur.

DESCRIPTION

Tk::Adjuster est un Frame contenant une "ligne" et un "blob".

Faire glisser avec le Bouton-1 de la souris entraîne le glissement d'une ligne pour indiquer la nouvelle taille. Relâcher le Bouton-1 soumet des GeometryRequests au nom du widget géré, ce qui amène le packer à changer la taille du widget.

Si le glisser-déposer est effectué avec la touche Maj enfoncée, alors les GeometryRequests sont faites en "temps réel" afin que les effets de flux de texte puissent être vus, mais comme beaucoup plus de travail est effectué, le comportement peut être lent.

Si le widget est empaqueté avec -side => left ou -side => right, la largeur est ajustée. S'il est empaqueté -side => top ou -side => bottom, la hauteur est ajustée.

packPropagate est désactivé pour la fenêtre maître afin d'éviter que l'ajustement ne modifie la taille globale de la fenêtre. De même, packPropagate est désactivé pour le widget géré s'il contient des éléments empaquetés. Ceci afin que les GeometryRequests effectuées par Tk::Adjuster ne soient pas remplacées par `pack`.

De plus, le widget géré est rendu non extensible pour empêcher le gestionnaire de géométrie de réallouer l'espace libéré dans le maître au widget géré. Notez cependant que l'extension n'est désactivée qu'après le mappage de l'Ajusteur, ce qui permet au widget géré de s'étendre naturellement lors de la création de la fenêtre.

La méthode de widget Tk, packAdjust, appelle `pack` sur le widget, puis crée une instance de Tk::Adjuster et l'empaquette "après" le widget. Son utilisation présente cependant deux inconvénients : le widget Ajusteur n'est pas mis à la disposition de l'appelant, et les options ne peuvent pas être définies sur l'Ajusteur. Pour ces raisons, la méthode Tk::Adjuster, packAfter, est préférée, mais packAdjust est conservée pour des raisons de compatibilité ascendante.

MÉTHODES DE WIDGET

$ajusteur->packAfter(widget_géré, ?options_pack?)
Cette commande configure respectivement les options -widget et -side de l'Ajusteur à widget_géré et à la valeur -side spécifiée dans options_pack (top si non spécifié). Elle empaquette ensuite l'Ajusteur après le widget_géré, avec -fill défini sur x ou y selon le cas.
$ajusteur->packForget?(booléen)?
Cette commande appelle Tk::Widget::packForget sur l'Ajusteur. Si un paramètre est fourni et qu'il a une valeur booléenne vraie, alors packForget est également appelé sur le widget géré.
$ajusteur->slave
Cette commande renvoie la valeur $ajusteur->cget('-widget'), c'est-à-dire la référence au widget géré.

EXEMPLES

Utilisation d'un Ajusteur pour séparer deux widgets, où le widget de gauche est géré, et le widget de droite s'étend pour remplir l'espace lors du redimensionnement de la fenêtre

a) Utilisation de packAfter (interface préférée)

use Tk;
use Tk::Adjuster;
my $f = MainWindow->new;
my $lst1 = $f->Listbox();
my $adj1 = $f->Adjuster();
my $lst2 = $f->Listbox();
my $side = 'left';
$lst1->pack(-side => $side, -fill => 'both', -expand => 1);
$adj1->packAfter($lst1, -side => $side);
$lst2->pack(-side => $side, -fill => 'both', -expand => 1);
MainLoop;

b) Utilisation de packAdjust

use Tk;
use Tk::Adjuster;
my $f = MainWindow->new;
my $lst1 = $f->Listbox();
my $lst2 = $f->Listbox();
my $side = 'left';
$lst1->packAdjust(-side => $side, -fill => 'both');
$lst2->pack      (-side => $side, -fill => 'both', -expand => 1);
MainLoop;

c) Utilisation de Tk::Widget::pack standard

use Tk;
use Tk::Adjuster;
my $f = MainWindow->new;
my $side = 'left';
my $lst1 = $f->Listbox();
my $adj  = $f->Adjuster(-widget => $lst1, -side => $side);
my $lst2 = $f->Listbox();
$lst1->pack(-side => $side, -fill => 'both', -expand => 1);
$adj->pack (-side => $side, -fill => 'y');
$lst2->pack(-side => $side, -fill => 'both', -expand => 1);
MainLoop;

Modifier les exemples ci-dessus pour que $side ait la valeur 'right' signifie que le widget de gauche s'étend pour remplir l'espace lors du redimensionnement de la fenêtre.

Modifier les exemples ci-dessus pour que $side ait la valeur 'top' produit un cas de test avec un Ajusteur horizontal. Ici, le widget du bas s'étend pour remplir l'espace lors du redimensionnement de la fenêtre. L'empaquetage vers le 'bottom' fait que le widget du haut s'étend pour remplir l'espace lors du redimensionnement de la fenêtre.

Utilisation de -restore => 0 pour plusieurs colonnes

Dans le cas de plusieurs colonnes (ou lignes), la fonctionnalité de "restauration" de l'Ajusteur peut être gênante. Lorsque l'utilisateur ajuste la largeur d'une colonne et en fait sortir l'Ajusteur d'une autre colonne de la fenêtre, cet ajusteur tente de se restaurer en réduisant la taille de son widget géré. Cela a pour effet que les largeurs de colonne diminuent ; et la taille d'origine n'est pas restaurée lorsque l'utilisateur inverse le changement d'origine. L'option -restore peut être utilisée pour désactiver cette fonctionnalité. (Il est cependant logique de laisser -restore activé pour le premier Ajusteur empaqueté, de sorte qu'au moins un Ajusteur reste toujours visible.)

use Tk;
use Tk::Adjuster;
my $f = MainWindow->new;
my $lst1 = $f->Listbox();
my $adj1 = $f->Adjuster();
my $lst2 = $f->Listbox();
my $adj2 = $f->Adjuster(-restore => 0);
my $lst3 = $f->Listbox();
my $side = 'left';
$lst1->pack(-side => $side, -fill => 'both', -expand => 1);
$adj1->packAfter($lst1, -side => $side);
$lst2->pack(-side => $side, -fill => 'both', -expand => 1);
$adj2->packAfter($lst2, -side => $side);
$lst3->pack(-side => $side, -fill => 'both', -expand => 1);
MainLoop;

BOGUES

Il n'est actuellement pas possible de configurer l'apparence de l'Ajusteur. Il serait souhaitable de pouvoir définir la largeur et le relief de la "ligne" de l'Ajusteur ainsi que la présence/absence du "blob" sur l'Ajusteur.

Tk::Adjuster fonctionne théoriquement avec le gestionnaire de géométrie `grid`, mais il existe actuellement des problèmes qui semblent être dus à des bogues dans `grid` :

a) Il n'y a jamais d'événement Unmap pour l'ajusteur, donc la fonctionnalité
   "restore" n'a aucun effet.
b) Après l'ajustement, les widgets dépassent dans la bordure du maître.
c) grid('Propagate', 0) sur MainWindow n'a aucun effet - la fenêtre se rétrécit/s'agrandit
   quand les widgets sont ajustés.
d) Les widgets se repositionnent pour corriger leur position au démarrage
