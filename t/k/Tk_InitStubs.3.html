Tk_InitStubs(3) Procédures de la bibliothèque Tk Tk_InitStubs(3)

NOM

Tk_InitStubs - initialise le mécanisme de stubs Tk

SYNTAXE

#include <tk.h>

const char *
Tk_InitStubs(interp, version, exact)

ARGUMENTS

Tcl_Interp *interp (entrée)
Handle de l'interpréteur Tcl.
char *version (entrée)
Une chaîne de version composée d'un ou plusieurs nombres décimaux séparés par des points.
int exact (entrée)
Si non nul, seule la version Tk spécifiée par version est acceptable. Si nul, les versions plus récentes que version sont également acceptables tant qu'elles ont le même numéro de version majeure que version.

INTRODUCTION

Le mécanisme de stubs Tcl définit une manière de lier dynamiquement les extensions à une implémentation Tcl particulière au moment de l'exécution. Le mécanisme de stubs ne nécessite aucune modification des applications incorporant des interpréteurs Tcl/Tk. Seuls les développeurs créant des extensions Tcl/Tk basées sur C doivent prendre des mesures pour utiliser le mécanisme de stubs avec leurs extensions. Voir la page Tcl_InitStubs pour plus d'informations.

L'activation du mécanisme de stubs pour une extension Tcl/Tk nécessite les étapes suivantes :

1)
Appeler Tcl_InitStubs dans l'extension avant d'appeler toute autre fonction Tcl.
2)
Appeler Tk_InitStubs dans l'extension avant d'appeler toute autre fonction Tk.
2)
Définir les symboles USE_TCL_STUBS et USE_TK_STUBS. Typiquement, vous incluriez les drapeaux -DUSE_TCL_STUBS et -DUSE_TK_STUBS lors de la compilation de l'extension.
3)
Lier l'extension avec les bibliothèques de stubs Tcl et Tk au lieu des bibliothèques Tcl et Tk standard. Sur les plateformes Unix, les noms de bibliothèques sont libtclstub8.4.a et libtkstub8.4.a ; sur les plateformes Windows, les noms de bibliothèques sont tclstub84.lib et tkstub84.lib. Adaptez les noms de bibliothèques avec le numéro de version approprié, mais notez que l'extension ne peut être utilisée qu'avec des versions de Tcl/Tk ayant ce numéro de version ou une version supérieure.

DESCRIPTION

Tk_InitStubs tente d'initialiser les pointeurs de la table de stubs Tk et de s'assurer que la version correcte de Tk est chargée. En plus d'un handle d'interpréteur, elle accepte comme arguments un numéro de version et un indicateur booléen indiquant si l'extension requiert une correspondance exacte de version ou non. Si exact est 0, alors l'extension indique que les versions plus récentes de Tk sont acceptables tant qu'elles ont le même numéro de version majeure que version ; non nul signifie que seule la version spécifiée est acceptable. Tcl_InitStubs retourne une chaîne contenant la version réelle de Tk satisfaisant la requête, ou NULL si la version Tk n'est pas acceptable, ne prend pas en charge le mécanisme de stubs, ou si une autre condition d'erreur s'est produite.
