Tk_GetPixmap(3) Procédures de la bibliothèque Tk Tk_GetPixmap(3)

NOM

Tk_GetPixmap, Tk_FreePixmap - allouer et libérer des pixmaps

SYNOPSIS

#include <tk.h>

Pixmap
Tk_GetPixmap(display, d, width, height, depth)

Tk_FreePixmap(display, pixmap)

ARGUMENTS

Display *display (in)
Affichage X pour la pixmap.
Drawable d (in)
Pixmap ou fenêtre où la nouvelle pixmap sera utilisée pour le dessin.
int width (in)
Largeur de la pixmap.
int height (in)
Hauteur de la pixmap.
int depth (in)
Nombre de bits par pixel dans la pixmap.
Pixmap pixmap (in)
Pixmap à détruire.

DESCRIPTION

Ces procédures sont identiques aux procédures Xlib XCreatePixmap et XFreePixmap, à l'exception qu'elles contiennent un code supplémentaire pour gérer les identifiants de ressources X afin que les identifiants des pixmaps supprimées puissent être réutilisés à l'avenir. Il est important que les applications Tk utilisent ces procédures plutôt que XCreatePixmap et XFreePixmap ; sinon, les applications à longue durée de vie pourraient manquer d'identifiants de ressources.

Tk_GetPixmap crée une pixmap adaptée au dessin dans d, avec des dimensions données par width, height et depth, et retourne son identifiant. Tk_FreePixmap détruit la pixmap donnée par pixmap et rend son identifiant de ressource disponible pour réutilisation.

MOTS-CLÉS

pixmap, identifiant de ressource
