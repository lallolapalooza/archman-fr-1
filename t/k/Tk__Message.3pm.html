NOM

Tk::Message - Créer et manipuler des widgets Message

SYNOPIS

use Tk::Message;
...
my $message = $parent->Message(
    -text => 'un texte de message un peu long',
    -aspect => 100,
    -justify => 'left',
)->pack();

OPTIONS STANDARDS

-anchor -font -highlightthickness -takefocus -background -foreground -padx -text -borderwidth -highlightbackground -pady -textvariable -cursor -highlightcolor -relief -width

Voir Tk::options pour plus de détails sur les options standard.

OPTIONS SPÉCIFIQUES AU WIDGET

Nom: aspect
Classe: Aspect
Commutateur: -aspect
Spécifie une valeur entière non négative indiquant le rapport d'aspect désiré pour le texte. Le rapport d'aspect est spécifié comme 100*largeur/hauteur. 100 signifie que le texte doit être aussi large que haut, 200 signifie que le texte doit être deux fois plus large que haut, 50 signifie que le texte doit être deux fois plus haut que large, et ainsi de suite. Utilisé pour choisir la longueur de ligne du texte si l'option width n'est pas spécifiée. La valeur par défaut est 150.
Nom: justify
Classe: Justify
Commutateur: -justify
Spécifie comment justifier les lignes de texte. Doit être l'une des valeurs left, center, ou right. La valeur par défaut est left. Cette option fonctionne avec les options anchor, aspect, padX, padY et width pour offrir une variété d'arrangements du texte dans la fenêtre. Les options aspect et width déterminent l'espace d'écran nécessaire pour afficher le texte. Les options anchor, padX et padY déterminent où cette zone rectangulaire est affichée dans la fenêtre du widget, et l'option justify détermine comment chaque ligne est affichée dans cette région rectangulaire. Par exemple, si anchor est e et justify est left, et que la fenêtre de message est beaucoup plus grande que nécessaire pour le texte, le texte sera affiché de telle sorte que les bords gauches de toutes les lignes soient alignés et que le bord droit de la ligne la plus longue soit à padX du bord droit de la fenêtre ; l'ensemble du bloc de texte sera centré dans la zone verticale de la fenêtre.
Nom: width
Classe: Width
Commutateur: -width
Spécifie la longueur des lignes dans la fenêtre. La valeur peut avoir l'une des formes acceptées par Tk_GetPixels. Si cette option a une valeur supérieure à zéro, alors l'option aspect est ignorée et l'option width détermine la longueur de la ligne. Si cette option a une valeur inférieure ou égale à zéro, alors l'option aspect détermine la longueur de la ligne.

DESCRIPTION

La méthode Message crée une nouvelle fenêtre (donnée par l'argument $widget) et en fait un widget de message. Des options supplémentaires, décrites ci-dessus, peuvent être spécifiées sur la ligne de commande ou dans la base de données d'options pour configurer des aspects du message tels que ses couleurs, sa police, son texte et son relief initial. La commande message renvoie son argument $widget. Au moment où cette commande est invoquée, il ne doit pas exister de fenêtre nommée $widget, mais le parent de $widget doit exister.

Un message est un widget qui affiche une chaîne de caractères. Un widget de message possède trois caractéristiques spéciales. Premièrement, il découpe sa chaîne en lignes afin de produire un rapport d'aspect donné pour la fenêtre. Les sauts de ligne sont choisis aux frontières des mots autant que possible (si même un seul mot ne rentre pas sur une ligne, alors le mot sera divisé sur plusieurs lignes). Les caractères de nouvelle ligne dans la chaîne forceront des sauts de ligne ; ils peuvent être utilisés, par exemple, pour laisser des lignes vides dans l'affichage.

La deuxième caractéristique d'un widget de message est la justification. Le texte peut être affiché justifié à gauche (chaque ligne commence sur le bord gauche de la fenêtre), centré ligne par ligne, ou justifié à droite (chaque ligne se termine sur le bord droit de la fenêtre).

La troisième caractéristique d'un widget de message est qu'il gère les caractères de contrôle et les caractères non imprimables de manière spéciale. Les caractères de tabulation sont remplacés par suffisamment d'espaces pour s'aligner sur la prochaine limite de 8 caractères. Les nouvelles lignes provoquent des sauts de ligne. D'autres caractères de contrôle (code ASCII inférieur à 0x20) et les caractères non définis dans la police sont affichés sous forme d'une séquence de quatre caractères \xhh où hh est le nombre hexadécimal à deux chiffres correspondant au caractère. Dans le cas inhabituel où la police ne contient pas tous les caractères de ``0123456789abcdef\x'', alors les caractères de contrôle et les caractères indéfinis ne sont pas affichés du tout.

MÉTHODES DU WIDGET

La méthode Message crée un objet widget. Cet objet prend en charge les méthodes configure et cget décrites dans Tk::options qui peuvent être utilisées pour interroger et modifier les options décrites ci-dessus. Le widget hérite également de toutes les méthodes fournies par la classe générique Tk::Widget.

LIAISONS PAR DÉFAUT

Lorsqu'un nouveau message est créé, il n'a pas de liaisons d'événements par défaut : les messages sont destinés uniquement à des fins de sortie.

BOGUES

Les tabulations ne fonctionnent pas très bien avec le texte centré ou justifié à droite. Le résultat le plus courant est que la ligne est mal justifiée.
