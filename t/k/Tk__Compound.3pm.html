NOM

Tk::Compound - Créer des images composées multilignes.

SYNTAXE

use Tk::Compound;
$image = $widget->Compound(nom,options);
$image->Line(options);
$image->Text(options);
$image->Bitmap(options);
$image->Image(options);
$image->Space(options);

DESCRIPTION

Les types d'images composées peuvent être utilisés pour créer des images constituées de plusieurs lignes horizontales ; chaque ligne est composée d'une série d'éléments (textes, bitmaps, images ou espaces) disposés de gauche à droite. Les images composées sont principalement utilisées pour intégrer des dessins complexes dans des widgets qui supportent l'option -image. Comme le montre la section EXEMPLE ci-dessous, une image composée peut être utilisée pour afficher simultanément un bitmap et une chaîne de texte dans un widget Button de Tk.

Les images composées ne peuvent être utilisées que sur des fenêtres du même écran que, et avec la même profondeur de pixels et le même visuel que le $widget utilisé pour les créer.

CRÉATION DES IMAGES COMPOSÉES

Les composés sont créés à l'aide de $widget->Compound. Les composés supportent les options suivantes :

-background => couleur
Spécifie la couleur d'arrière-plan de l'image composée. Cette couleur est également utilisée comme couleur d'arrière-plan par défaut pour les éléments bitmap de l'image composée.
-borderwidth => pixels
Spécifie une valeur non négative indiquant la largeur de la bordure 3D dessinée autour de l'image composée.
-font => police
Spécifie la police par défaut pour les éléments de texte de l'image composée.
-foreground => couleur
Spécifie la couleur d'avant-plan par défaut pour les éléments bitmap et texte de l'image composée.
-padx => valeur
Spécifie une valeur non négative indiquant l'espace supplémentaire à demander pour l'image composée dans la direction X. La valeur peut avoir l'une des formes acceptables par Tk_GetPixels(3).
-pady => valeur
Spécifie une valeur non négative indiquant l'espace supplémentaire à demander pour l'image composée dans la direction Y.
-relief => valeur
Spécifie l'effet 3D désiré pour l'arrière-plan de l'image composée. Les valeurs acceptables sont raised, sunken, flat, ridge et groove.
-showbackground => valeur
Spécifie si l'arrière-plan et les bordures 3D doivent être dessinés. Doit être une valeur booléenne valide. Par défaut, l'arrière-plan n'est pas dessiné et l'image composée semble avoir un arrière-plan transparent.

COMMANDE IMAGE

Lorsqu'une image composée est créée, Tk crée également un nouvel objet. Cet objet supporte les méthodes configure et cget décrites dans Tk::options qui peuvent être utilisées pour interroger et modifier les options décrites ci-dessus.

L'objet supporte également les méthodes suivantes :

$compound->Line?(option = valeur ...>)?
Crée une nouvelle ligne en bas de l'image composée. Les lignes supportent les options suivantes :
-anchor valeur
Spécifie comment la ligne doit être alignée le long de l'axe horizontal. Lorsque les valeurs sont w, sw ou nw, la ligne est alignée à gauche. Lorsque les valeurs sont c, s ou n, la ligne est alignée au milieu. Lorsque les valeurs sont e, se ou ne, la ligne est alignée à droite.
-padx => valeur
Spécifie une valeur non négative indiquant l'espace supplémentaire à demander pour cette ligne dans la direction X.
$compound->TypeItem?(option = valeur ...>)?
Crée un nouvel élément du type TypeItem à la fin de la dernière ligne de l'image composée. Tous les types d'éléments supportent les options communes suivantes :
-anchor valeur
Spécifie comment l'élément doit être aligné le long de l'axe vertical. Lorsque les valeurs sont n, nw ou ne, l'élément est aligné en haut de la ligne. Lorsque les valeurs sont c, w ou e, l'élément est aligné au milieu de la ligne. Lorsque les valeurs sont s, se ou sw, l'élément est aligné en bas de la ligne.
-padx => valeur
Spécifie une valeur non négative indiquant l'espace supplémentaire à demander pour cet élément dans la direction X.
-pady => valeur
Spécifie une valeur non négative indiquant l'espace supplémentaire à demander pour cet élément dans la direction Y.
type-element peut être l'un des suivants :
$compound->Bitmap?(option = valeur ...>)?
Crée un nouvel élément bitmap à la fin de la dernière ligne de l'image composée. Les options supplémentaires acceptées par le type bitmap sont :
-background => couleur
Spécifie la couleur d'arrière-plan de l'élément bitmap.
-bitmap => nom
Spécifie un bitmap à afficher dans cet élément, sous l'une des formes acceptables par Tk_GetBitmap(3).
-foreground => couleur
Spécifie la couleur d'avant-plan de l'élément bitmap.
$compound->Image?(option = valeur ...>)?
Crée un nouvel élément image à la fin de la dernière ligne de l'image composée. Les options supplémentaires acceptées par le type image sont :
-image => nom
Spécifie une image à afficher dans cet élément. nom doit avoir été créé avec la commande image create.
$compound->Space?(option = valeur ...>)?
Crée un nouvel élément espace à la fin de la dernière ligne de l'image composée. Les éléments espace n'affichent rien. Ils agissent simplement comme des espaces réservés qui ajoutent des espaces supplémentaires entre les éléments à l'intérieur d'une image composée. Les options supplémentaires acceptées par le type image sont :
-width => valeur
Spécifie la largeur de cet espace. La valeur peut avoir l'une des formes acceptables par Tk_GetPixels(3).
-height => valeur
Spécifie la hauteur de cet espace. La valeur peut avoir l'une des formes acceptables par Tk_GetPixels(3).
$compound->Text?(option = valeur ...>)?
Crée un nouvel élément texte à la fin de la dernière ligne de l'image composée. Les options supplémentaires acceptées par le type texte sont :
-background => couleur
Spécifie la couleur d'arrière-plan de l'élément texte.
-font => nom
Spécifie la police à utiliser pour cet élément texte.
lass="permalink" href="#foreground~3">-premier-plan => couleur
Spécifie la couleur de premier plan du texte. Ce texte est affiché dans un élément de texte.
-justifier valeur
Lorsqu'il y a plusieurs lignes de texte affichées dans un élément de texte, cette option détermine comment les lignes s'alignent les unes avec les autres. valeur doit être l'un de gauche, centre, ou droite. Gauche signifie que les bords gauches des lignes s'alignent tous, centre signifie que les centres des lignes sont alignés, et droite signifie que les bords gauches des lignes s'alignent.
-texte => chaîne
Spécifie une chaîne de caractères à afficher dans cet élément de texte.
-souligner valeur
Spécifie l'indice entier d'un caractère à souligner dans l'élément de texte. 0 correspond au premier caractère du texte affiché dans l'élément de texte, 1 au caractère suivant, et ainsi de suite.
-longueur-de-ligne valeur
Cette option spécifie la longueur maximale de ligne de la chaîne de label sur cet élément de texte. Si la longueur de ligne de la chaîne de label dépasse cette longueur, elle est renvoyée à la ligne suivante, de sorte qu'aucune ligne ne soit plus longue que la longueur spécifiée. La valeur peut être spécifiée dans n'importe laquelle des formes standard pour les distances d'écran. Si cette valeur est inférieure ou égale à 0, aucune coupure n'est effectuée : les lignes ne seront coupées qu'aux caractères de nouvelle ligne du texte.

EXEMPLE

L'exemple suivant crée une image composite avec un bitmap et une chaîne de texte et place cette image dans un widget Button(n). Notez que l'image doit être créée à l'aide du widget dans lequel elle réside.

my $b = $parent->Button;
my $c = $b->Compound;
$b->configure(-image => $c);
$c->Line;
$c->Bitmap(-bitmap => 'warning');
$c->Space(-width => 8);
$c->Text(-text => "Avertissement", -souligner => 0);
$b->pack;
