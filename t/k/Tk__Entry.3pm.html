NOM

Tk::Entry - Créer et manipuler des widgets Entry

SYNTAXE

    $entree = $parent->Entry(?options?);

OPTIONS STANDARD

-background -highlightbackground -insertontime -selectforeground -borderwidth -highlightcolor -insertwidth -takefocus -cursor -highlightthickness -justify -textvariable -exportselection -insertbackground -relief -xscrollcommand -font -insertborderwidth -selectbackground -foreground -insertofftime -selectborderwidth

OPTIONS SPÉCIFIQUES AU WIDGET

Nom de ligne de commande : -disabledbackground
Nom de base de données : disabledBackground
Classe de base de données : DisabledBackground
Spécifie la couleur d'arrière-plan à utiliser lorsque l'entrée est désactivée. Si cette option est une chaîne vide, la couleur d'arrière-plan normale est utilisée.
Nom de ligne de commande : -disabledforeground
Nom de base de données : disabledForeground
Classe de base de données : DisabledForeground
Spécifie la couleur de premier plan à utiliser lorsque l'entrée est désactivée. Si cette option est une chaîne vide, la couleur de premier plan normale est utilisée.
Nom: invalidCommand
Classe: InvalidCommand
Commutateur: -invalidcommand
Alias: -invcmd
Spécifie un script à évaluer lorsque validateCommand renvoie 0. La définir sur <undef> désactive cette fonctionnalité (par défaut). La meilleure utilisation de cette option est de la définir sur bell. Voir Validation ci-dessous pour plus d'informations.
Nom de ligne de commande : -readonlybackground
Nom de base de données : readonlyBackground
Classe de base de données : ReadonlyBackground
Spécifie la couleur d'arrière-plan à utiliser lorsque l'entrée est en lecture seule. Si cette option est une chaîne vide, la couleur d'arrière-plan normale est utilisée.
Nom: show
Classe: Show
Commutateur: -show
Si cette option est spécifiée, le contenu réel de l'entrée n'est pas affiché dans la fenêtre. Au lieu de cela, chaque caractère de la valeur de l'entrée sera affiché comme le premier caractère de la valeur de cette option, tel que ``*''. Ceci est utile, par exemple, si l'entrée doit être utilisée pour saisir un mot de passe. Si des caractères de l'entrée sont sélectionnés et copiés ailleurs, les informations copiées seront ce qui est affiché, et non le contenu réel de l'entrée.
Nom: state
Classe: State
Commutateur: -state
Spécifie l'un des trois états de l'entrée : normal, disabled, ou readonly. Si l'entrée est readonly, la valeur ne peut pas être modifiée à l'aide des commandes du widget et aucun curseur d'insertion ne sera affiché, même si le focus d'entrée est dans le widget ; le contenu du widget peut toujours être sélectionné. Si l'entrée est disabled, la valeur ne peut pas être modifiée, aucun curseur d'insertion ne sera affiché, le contenu ne sera pas sélectionnable, et l'entrée peut être affichée dans une couleur différente, en fonction des valeurs des options -disabledforeground et -disabledbackground.
Nom: validate
Classe: Validate
Commutateur: -validate
Spécifie le mode dans lequel la validation doit opérer : none, focus, focusin, focusout, key, ou all. La valeur par défaut est none. Lorsque vous souhaitez une validation, vous devez explicitement indiquer le mode souhaité. Voir Validation ci-dessous pour plus.
Nom: validateCommand
Classe: ValidateCommand
Commutateur: -validatecommand
Alias: -vcmd
Spécifie un script à évaluer lorsque vous souhaitez valider la saisie dans le widget d'entrée. La définir sur "undef" désactive cette fonctionnalité (par défaut). Cette commande doit renvoyer une valeur booléenne valide. Si elle renvoie 0 (ou son équivalent booléen valide), cela signifie que vous rejetez la nouvelle édition et qu'elle n'aura pas lieu, et que invalidCommand sera évalué s'il est défini. Si elle renvoie 1, la nouvelle édition a lieu. Voir Validation ci-dessous pour plus d'informations.
Nom: width
Classe: Width
Commutateur: -width
Spécifie une valeur entière indiquant la largeur souhaitée de la fenêtre d'entrée, en caractères de taille moyenne de la police du widget. Si la valeur est inférieure ou égale à zéro, le widget choisit une taille juste assez grande pour contenir son texte actuel.

DESCRIPTION

La méthode Entry crée une nouvelle fenêtre (fournie par l'$entree argument) et en fait un widget d'entrée. Des options supplémentaires, décrites ci-dessus, peuvent être spécifiées en ligne de commande ou dans la base de données d'options pour configurer des aspects de l'entrée tels que ses couleurs, sa police et son relief. La commande entry renvoie son argument $entree. Au moment où cette commande est invoquée, il ne doit pas exister de fenêtre nommée $entree, mais le parent de $entree doit exister.

Une entrée est un widget qui affiche une chaîne de caractères sur une seule ligne et permet de modifier cette chaîne à l'aide des méthodes décrites ci-dessous, qui sont généralement associées à des frappes au clavier et des actions de souris. Lors de sa création, la chaîne d'une entrée est vide. Une partie de l'entrée peut être sélectionnée comme décrit ci-dessous. Si une entrée exporte sa sélection (voir l'option exportSelection), elle respectera les protocoles X11 standard pour la gestion de la sélection ; les sélections d'entrée sont disponibles sous le type STRING. Les entrées respectent également les règles standard de Tk pour la gestion du focus d'entrée. Lorsqu'une entrée a le focus d'entrée, elle affiche un curseur d'insertion pour indiquer où les nouveaux caractères seront insérés.

Les entrées sont capables d'afficher des chaînes trop longues pour tenir entièrement dans la fenêtre du widget. Dans ce cas, seule une partie de la chaîne sera affichée ; les méthodes décrites ci-dessous peuvent être utilisées pour changer la vue dans la fenêtre. Les entrées utilisent le mécanisme standard xScrollCommand pour interagir avec les barres de défilement (voir la description de l'option -xscrollcommand pour plus de détails). Elles prennent également en charge le balayage, comme décrit ci-dessous.

VALIDATION

La validation des widgets d'entrée est dérivée en partie du correctif écrit par jhobbs@cs.uoregon.edu. Cela fonctionne en définissant l'option validateCommand sur un rappel qui sera évalué conformément à l'option validate comme suit :

none
Défaut. Cela signifie qu'aucune validation n'aura lieu.
focus
validateCommand sera appelé lorsque l'entrée recevra ou perdra le focus.
focusin
validateCommand sera appelé lorsque l'entrée recevra le focus.
focusout
validateCommand sera appelé lorsque l'entrée perdra le focus.
key
validateCommand sera appelé lorsque l'entrée sera modifiée.
all
validateCommand sera appelé pour toutes les conditions ci-dessus.

Les validateCommand et invalidCommand sont appelés avec les arguments suivants :

  • La valeur proposée pour l'entrée. Si vous configurez le widget d'entrée pour avoir un nouveau textvariable, ce sera la valeur de ce textvariable.
  • Les caractères à ajouter (ou supprimer). Ce sera "undef" si la validation est due au focus, un appel explicite à validate ou si le changement est dû à la modification de "-textvariable".
  • La valeur actuelle de l'entrée, c'est-à-dire avant le changement proposé.
  • L'index de la chaîne de caractères à ajouter/supprimer, le cas échéant. -1 sinon
  • Le type d'action. 1 == INSERT, 0 == DELETE, -1 s'il s'agit d'une validation forcée ou d'une validation textvariable

En général, il peut être dangereux de mélanger textVariable et validateCommand. Si vous essayez de définir textVariable sur quelque chose que validateCommand n'acceptera pas, il sera rétabli à la valeur du widget d'entrée. L'utilisation de textVariable à des fins de lecture seule ne causera jamais de problèmes.

Le validateCommand s'désactivera lui-même en définissant validate sur none lorsqu'une erreur se produit, par exemple lorsque le validateCommand ou invalidCommand rencontre une erreur dans son script lors de l'évaluation, ou lorsque validateCommand ne renvoie pas une valeur booléenne valide.

Avec la version perl/Tk, l'option validate est censée être "suspendue" lors de l'exécution de validateCommand ou de invalidCommand. C'est expérimental, mais en théorie, chaque rappel peut "corriger" la valeur du widget et remplacer le changement proposé. (validateCommand devrait toujours renvoyer false pour empêcher le changement de se produire lorsqu'il renvoie.)

MÉTHODES DE WIDGET

La méthode Entry crée un objet widget. Cet objet prend en charge les méthodes configure et cget décrites dans Tk::options, qui peuvent être utilisées pour interroger et modifier les options décrites ci-dessus. Le widget hérite également de toutes les méthodes fournies par la classe générique Tk::Widget.

Plusieurs des méthodes supplémentaires pour les entrées prennent un ou plusieurs indices comme arguments. Un indice spécifie un caractère particulier dans la chaîne de l'entrée, de l'une des manières suivantes :

number
Spécifie le caractère comme un indice numérique, où 0 correspond au premier caractère de la chaîne.
anchor
Indique le point d'ancrage de la sélection, qui est défini avec les méthodes selectionFrom et selectionAdjust.
end
Indique le caractère juste après le dernier caractère de la chaîne de l'entrée. Ceci équivaut à spécifier un indice numérique égal à la longueur de la chaîne de l'entrée.
insert
Indique le caractère adjacent et immédiatement suivant le curseur d'insertion.
sel.first
Indique le premier caractère de la sélection. C'est une erreur d'utiliser cette forme si la sélection n'est pas dans la fenêtre d'entrée.
sel.last
Indique le caractère juste après le dernier caractère de la sélection. C'est une erreur d'utiliser cette forme si la sélection n'est pas dans la fenêtre d'entrée.
@number
Dans cette forme, number est traité comme une coordonnée x dans la fenêtre d'entrée ; le caractère qui englobe cette coordonnée x est utilisé. Par exemple, ``@0'' indique le caractère le plus à gauche de la fenêtre.

Des abréviations peuvent être utilisées pour l'une des formes ci-dessus, par exemple ``e'' ou ``sel.f''. En général, les indices hors limites sont automatiquement arrondis à la valeur légale la plus proche.

Les méthodes supplémentaires suivantes sont disponibles pour les widgets d'entrée :

$entry->bbox(index)
Renvoie une liste de quatre nombres décrivant la boîte englobante du caractère donné par index. Les deux premiers éléments de la liste donnent les coordonnées x et y du coin supérieur gauche de la zone d'écran couverte par le caractère (en pixels par rapport au widget) et les deux derniers éléments donnent la largeur et la hauteur du caractère, en pixels. La boîte englobante peut faire référence à une région située en dehors de la zone visible de la fenêtre.
$entry->cget(?option?)
Renvoie la valeur actuelle de l'option de configuration donnée par option. Option peut avoir l'une des valeurs acceptées par la commande entry.
$entry->configure(?option?, ?valeur, option, valeur, ...?)
Interroge ou modifie les options de configuration du widget. Si aucune option n'est spécifiée, renvoie une liste décrivant toutes les options disponibles pour $entry (voir Tk::configure pour des informations sur le format de cette liste). Si option est spécifiée sans valeur, la commande renvoie une liste décrivant l'option nommée (cette liste sera identique à la sous-liste correspondante de la valeur renvoyée si aucune option n'est spécifiée). Si une ou plusieurs paires option-valeur sont spécifiées, la commande modifie les options du widget données pour qu'elles aient les valeurs données ; dans ce cas, la commande renvoie une chaîne vide. Option peut avoir l'une des valeurs acceptées par la commande entry.
$entry->delete(first, ?last?)
Supprime un ou plusieurs éléments de l'entrée. First est l'indice du premier caractère à supprimer, et last est l'indice du caractère juste après le dernier à supprimer. Si last n'est pas spécifié, il vaut par défaut first+1, c'est-à-dire qu'un seul caractère est supprimé. Cette méthode renvoie une chaîne vide.
$entry->get
Renvoie la chaîne de l'entrée.
$entry->icursor(index)
Arrange pour que le curseur d'insertion soit affiché juste avant le caractère donné par index. Renvoie une chaîne vide.
$entry->index(index)
Renvoie l'indice numérique correspondant à index.
$entry->insert(index, string)
Insère les caractères de string juste avant le caractère indiqué par index. Renvoie une chaîne vide.
$entry->scan(option, args)
$entry->scanOption(args)
Cette méthode est utilisée pour implémenter le balayage sur les entrées. Elle a deux formes, selon Option :
$entry->scanMark(x)
Enregistre x et la vue actuelle dans le widget d'entrée ; utilisé en conjonction avec les méthodes scanDragto ultérieures. Généralement, cette méthode est associée à un clic de bouton de souris dans le widget. Elle renvoie une chaîne vide.
$entry->scanDragto(x)
Cette méthode calcule la différence entre son argument x et l'argument x de la dernière méthode scanMark pour le widget. Elle ajuste ensuite la vue vers la gauche ou la droite par 10 fois la différence des coordonnées x. Cette méthode est généralement associée aux événements de mouvement de la souris dans le widget, pour produire l'effet de faire glisser l'entrée à grande vitesse dans le widget. La valeur de retour est une chaîne vide.
$entry->selection(option, arg)
$entry->selectionOption(arg)
Cette méthode est utilisée pour ajuster la sélection dans une entrée. Elle a plusieurs formes, selon Option :
$entry->selectionAdjust(index)
Localise l'extrémité de la sélection la plus proche du caractère donné par index, et ajuste cette extrémité de la sélection à index (c'est-à-dire en incluant mais sans dépasser index). L'autre extrémité de la sélection devient le point d'ancrage pour les futures méthodes selectionTo. Si la sélection n'est actuellement pas dans l'entrée, alors une nouvelle sélection est créée pour inclure les caractères entre index et le point d'ancrage de sélection le plus récent, inclus. Renvoie une chaîne vide.
$entry->selectionClear
Efface la sélection si elle se trouve actuellement dans ce widget. Si la sélection n'est pas dans ce widget, la méthode n'a aucun effet. Renvoie une chaîne vide.
$entry->selectionFrom(index)
Définit le point d'ancrage de la sélection juste avant le caractère donné par index. Ne modifie pas la sélection. Renvoie une chaîne vide.
$entry->selectionPresent
Renvoie 1 s'il y a des caractères sélectionnés dans l'entrée, 0 sinon.
$entry->selectionRange(start, end)
Définit la sélection pour inclure les caractères commençant par celui indexé par start et se terminant par celui juste avant end. Si end fait référence au même caractère que start ou à un caractère précédent, alors la sélection de l'entrée est effacée.
$entry->selectionTo(index)
Si index est avant le point d'ancrage, définit la sélection sur les caractères de index jusqu'au point d'ancrage (exclus). Si index est identique au point d'ancrage, ne fait rien. Si index est après le point d'ancrage, définit la sélection sur les caractères du point d'ancrage jusqu'à index (exclus). Le point d'ancrage est déterminé par la méthode selectionFrom ou selectionAdjust la plus récente dans ce widget. Si la sélection n'est pas dans ce widget, une nouvelle sélection est créée en utilisant le point d'ancrage le plus récent spécifié pour le widget. Renvoie une chaîne vide.
$entry->validate
Cette commande est utilisée pour forcer une évaluation de la commande validateCommand indépendamment des conditions spécifiées par l'option validate. Elle retourne 0 ou 1.
$entry->xview(args)
Cette commande est utilisée pour interroger et modifier la position horizontale du texte dans la fenêtre du widget. Elle peut prendre l'une des formes suivantes :
$entry->xview
Retourne une liste contenant deux éléments. Chaque élément est une fraction réelle entre 0 et 1 ; ensemble, ils décrivent la portée horizontale visible dans la fenêtre. Par exemple, si le premier élément est .2 et le second .7, 20 % du texte de l'entrée est hors écran à gauche, les 50 % du milieu sont visibles dans la fenêtre, et 30 % du texte est hors écran à droite. Ce sont les mêmes valeurs passées aux barres de défilement via l'option -xscrollcommand.
$entry->xview(index)
Ajuste la vue dans la fenêtre de sorte que le caractère donné par index soit affiché sur le bord gauche de la fenêtre.
$entry->xviewMoveto(fraction)
Ajuste la vue dans la fenêtre de sorte que le caractère situé à la fraction fraction du texte apparaisse sur le bord gauche de la fenêtre. Fraction doit être une fraction entre 0 et 1.
$entry->xviewScroll(nombre, quoi)
Cette méthode déplace la vue dans la fenêtre vers la gauche ou vers la droite selon nombre et quoi. Nombre doit être un entier. Quoi doit être soit units soit pages, soit une abréviation de l'un d'eux. Si quoi est units, la vue s'ajuste vers la gauche ou vers la droite de nombre caractères de largeur moyenne à l'écran ; si c'est pages, la vue s'ajuste de nombre écrans. Si nombre est négatif, des caractères plus à gauche deviennent visibles ; s'il est positif, des caractères plus à droite deviennent visibles.

LIAISONS PAR DÉFAUT

Tk crée automatiquement des liaisons de classe pour les entrées qui leur donnent le comportement par défaut suivant. Dans les descriptions ci-dessous, "mot" fait référence à un groupe contigu de lettres, de chiffres ou de caractères "_" ou à tout caractère unique autre que ceux-ci.

[1]
Cliquer sur le bouton de la souris 1 positionne le curseur d'insertion juste avant le caractère sous le curseur de la souris, définit le focus d'entrée sur ce widget et efface toute sélection dans le widget. Faire glisser avec le bouton de la souris 1 sélectionne la zone entre le curseur d'insertion et le caractère sous la souris.
[2]
Double-cliquer avec le bouton de la souris 1 sélectionne le mot sous la souris et positionne le curseur d'insertion au début du mot. Faire glisser après un double clic sélectionnera des mots entiers.
[3]
Triple-cliquer avec le bouton de la souris 1 sélectionne tout le texte de l'entrée et positionne le curseur d'insertion avant le premier caractère.
[4]
Les extrémités de la sélection peuvent être ajustées en faisant glisser avec le bouton de la souris 1 pendant que la touche Maj est enfoncée ; cela ajustera l'extrémité de la sélection la plus proche du curseur de la souris lorsque le bouton 1 a été pressé. Si le bouton est double-cliqué avant de faire glisser, la sélection sera ajustée par mots entiers.
[5]
Cliquer sur le bouton de la souris 1 avec la touche Contrôle enfoncée positionnera le curseur d'insertion dans l'entrée sans affecter la sélection.
[6]
Si des caractères imprimables normaux sont tapés dans une entrée, ils sont insérés à la position du curseur d'insertion.
[7]
La vue dans l'entrée peut être ajustée en faisant glisser avec le bouton de la souris 2. Si le bouton de la souris 2 est cliqué sans déplacer la souris, la sélection est copiée dans l'entrée à la position du curseur de la souris.
[8]
Si la souris sort de l'entrée par les côtés gauche ou droit pendant que le bouton 1 est enfoncé, l'entrée défilera automatiquement pour rendre plus de texte visible (s'il y a plus de texte hors écran du côté où la souris a quitté la fenêtre).
[9]
Les touches Gauche et Droite déplacent le curseur d'insertion d'un caractère vers la gauche ou la droite ; elles effacent également toute sélection dans l'entrée et définissent l'ancre de sélection. Si Gauche ou Droite est tapé avec la touche Maj enfoncée, le curseur d'insertion se déplace et la sélection s'étend pour inclure le nouveau caractère. Contrôle-Gauche et Contrôle-Droite déplacent le curseur d'insertion par mots, et Contrôle-Maj-Gauche et Contrôle-Maj-Droite déplacent le curseur d'insertion par mots et étendent également la sélection. Contrôle-b et Contrôle-f se comportent de la même manière que Gauche et Droite, respectivement. Meta-b et Meta-f se comportent de la même manière que Contrôle-Gauche et Contrôle-Droite, respectivement.
[10]
La touche Début, ou Contrôle-a, déplacera le curseur d'insertion au début de l'entrée et effacera toute sélection dans l'entrée. Maj-Début déplace le curseur d'insertion au début de l'entrée et étend également la sélection jusqu'à ce point.
[11]
La touche Fin, ou Contrôle-e, déplacera le curseur d'insertion à la fin de l'entrée et effacera toute sélection dans l'entrée. Maj-Fin déplace le curseur à la fin et étend la sélection jusqu'à ce point.
[12]
La touche Sélection et Contrôle-Espace définissent l'ancre de sélection à la position du curseur d'insertion. Elles n'affectent pas la sélection actuelle. Maj-Sélection et Contrôle-Maj-Espace ajustent la sélection à la position actuelle du curseur d'insertion, sélectionnant de l'ancre au curseur d'insertion s'il n'y avait pas de sélection auparavant.
[13]
Contrôle-/ sélectionne tout le texte dans l'entrée.
[14]
Contrôle-\ efface toute sélection dans l'entrée.
[15]
La touche F16 (appelée Copier sur de nombreux postes de travail Sun) ou Meta-w copie la sélection dans le widget dans le presse-papiers, s'il y a une sélection.
[16]
La touche F20 (appelée Couper sur de nombreux postes de travail Sun) ou Contrôle-w copie la sélection dans le widget dans le presse-papiers et supprime la sélection. S'il n'y a pas de sélection dans le widget, ces touches n'ont aucun effet.
[17]
La touche F18 (appelée Coller sur de nombreux postes de travail Sun) ou Contrôle-y insère le contenu du presse-papiers à la position du curseur d'insertion.
[18]
La touche Suppr supprime la sélection, s'il y en a une dans l'entrée. S'il n'y a pas de sélection, elle supprime le caractère à droite du curseur d'insertion.
[19]
La touche Retour arrière et Contrôle-h suppriment la sélection, s'il y en a une dans l'entrée. S'il n'y a pas de sélection, elle supprime le caractère à gauche du curseur d'insertion.
[20]
Contrôle-d supprime le caractère à droite du curseur d'insertion.
[21]
Meta-d supprime le mot à droite du curseur d'insertion.
[22]
Contrôle-k supprime tous les caractères à droite du curseur d'insertion.
[23]
Contrôle-t inverse l'ordre des deux caractères à droite du curseur d'insertion.

Si l'entrée est désactivée à l'aide de l'option -state, la vue de l'entrée peut toujours être ajustée et le texte de l'entrée peut toujours être sélectionné, mais aucun curseur d'insertion ne sera affiché et aucune modification de texte n'aura lieu.

Le comportement des entrées peut être modifié en définissant de nouvelles liaisons pour des widgets individuels ou en redéfinissant les liaisons de classe.
