NOM

Tk::DItem - Éléments d'affichage Tix

SYNOPSIS

DESCRIPTION

Les éléments d'affichage et les types d'éléments d'affichage de Tix sont conçus pour résoudre un problème général : de nombreux widgets Tix (existants et prévus) affichent de nombreux éléments de nombreux types simultanément.

Par exemple, un widget de liste hiérarchique (voir Tk::HList) peut afficher des éléments d'images, de texte brut et de sous-fenêtres sous forme de hiérarchie. Un autre widget, le widget de liste tabulaire (voir Tk::TList), affiche également des éléments des mêmes types, bien qu'il organise les éléments sous forme de tableau. Encore un autre widget, le widget tableur (voir Tk::TixGrid), affiche également des éléments de types similaires, mais dans un format encore différent.

Dans ces exemples, les éléments d'affichage dans différents widgets ne diffèrent que par la façon dont ils sont arrangés par le widget hôte. Dans Tix, les éléments d'affichage sont clairement séparés des widgets hôtes. L'avantage est double : premièrement, la création et la configuration des éléments d'affichage deviennent uniformes sur les différents widgets hôtes. Deuxièmement, de nouveaux types d'éléments d'affichage peuvent être ajoutés sans avoir à modifier les widgets hôtes existants.

D'une certaine manière, les éléments d'affichage Tix sont similaires aux éléments du widget canvas de Tk. Cependant, contrairement aux éléments du canvas de Tix, les éléments du canvas ne sont pas indépendants du widget canvas ; cela rend impossible l'utilisation des éléments du canvas dans d'autres types de widgets TK.

L'apparence d'un élément d'affichage est contrôlée par un ensemble d'attributs. On observe que chaque attribut appartient généralement à l'une des deux catégories : « individuel » ou « collectif ». Par exemple, les éléments textuels d'un widget HList peuvent afficher chacun une chaîne de caractères différente ; cependant, dans la plupart des cas, les éléments textuels partagent la même couleur, la même police et le même espacement. Au lieu de conserver une version dupliquée des mêmes attributs dans chaque élément d'affichage, il serait avantageux de placer les attributs collectifs dans un objet spécial appelé style d'affichage. Premièrement, il y a la question de l'espace : un widget hôte peut avoir des milliers d'éléments ; conserver des attributs dupliqués serait très coûteux. Deuxièmement, lorsqu'il devient nécessaire de modifier un attribut collectif, tel que le changement de la couleur de premier plan de tous les éléments textuels en rouge, il sera plus efficace de ne modifier que l'objet de style d'affichage plutôt que de modifier tous les éléments textuels un par un.

Les attributs d'un élément d'affichage sont donc stockés à deux endroits : il possède un ensemble d'options d'élément pour stocker ses attributs individuels. Chaque élément d'affichage est également associé à un style d'affichage, qui spécifie les attributs collectifs de tous les éléments qui lui sont associés.

La division entre les attributs individuels et collectifs est fixe et ne peut être modifiée. Ainsi, lorsqu'il devient nécessaire que certains éléments diffèrent dans leurs attributs collectifs, deux styles d'affichage ou plus peuvent être utilisés. Par exemple, supposez que vous souhaitiez afficher deux colonnes d'éléments textuels dans un widget HList, une colonne en rouge et l'autre en bleu. Vous pouvez créer un objet TextStyle appelé « $red » qui définit un premier plan rouge, et un autre appelé « $blue », qui définit un premier plan bleu. Vous pouvez ensuite associer tous les éléments textuels de la première colonne à « $red » et ceux de la deuxième colonne à « $blue ».

TYPES D'ÉLÉMENTS D'AFFICHAGE ET OPTIONS

Actuellement, il existe trois types d'éléments d'affichage : texte, imagetext et fenêtre.

ÉLÉMENTS IMAGETEXT

Les éléments d'affichage de type imagetext sont utilisés pour afficher une image ainsi qu'une chaîne de texte. Les éléments Imagetext prennent en charge les options suivantes :

Options d'élément Imagetext

Nom : bitmap
Classe : Bitmap
Commutateur : -bitmap
Spécifie le bitmap à afficher dans l'élément.
Nom : image
Classe : Image
Commutateur : -image
Spécifie l'image à afficher dans l'élément. Lorsque les options -bitmap et -image sont spécifiées, seule l'image sera affichée.
Nom : imageTextStyle
Classe : ImageTextStyle
Commutateur : -style
Spécifie le style d'affichage à utiliser pour cet élément. Doit être le nom d'un style d'affichage imagetext qui a déjà été créé avec ItemStyle.
Nom : showImage
Classe : ShowImage
Commutateur : -showimage
Une valeur booléenne qui spécifie si l'image/le bitmap doit être affiché(e).
Nom : showText
Classe : ShowText
Commutateur : -showtext
Une valeur booléenne qui spécifie si la chaîne de texte doit être affichée.
Nom : text
Classe : Text
Commutateur : -text
Spécifie la chaîne de texte à afficher dans l'élément.
Nom : underline
Classe : Underline
Commutateur : -underline
Spécifie l'index entier d'un caractère à souligner dans la chaîne de texte de l'élément. 0 correspond au premier caractère du texte affiché dans le widget, 1 au caractère suivant, et ainsi de suite.

Options de style Imagetext

Les informations de style des éléments imagetext sont stockées dans le style d'affichage imagetext. Les options suivantes sont prises en charge :

OPTIONS STANDARD

-activebackground -activeforeground -anchor -background -disabledbackground -disabledforeground -foreground -font -justify -padx -pady -selectbackground -selectforeground -wraplength

Voir Tk::options pour les détails des options standard.

OPTIONS SPÉCIFIQUES AU STYLE

Nom : gap
Classe : Gap
Commutateur : -gap
Spécifie la distance entre le bitmap/image et la chaîne de texte, en pixels.
Nom : textAnchor
Classe : TextAnchor
Commutateur : -textanchor
La position d'ancrage sur l'image à laquelle la partie texte est attachée. Ceci est une addition de perl/Tk. Par défaut, c'est e pour la compatibilité avec Tix standard. Les cas intéressants sont
n
Le texte est centré au-dessus de l'image.
s
Le texte est centré en dessous de l'image.
e
Le texte est centré à droite de l'image.
w
Le texte est centré à gauche de l'image.
c
Le texte est centré sur l'image.

NAME

Tk::DisplayItem - Display items and styles in Tk widgets

SYNOPSIS

   $widget->ItemStyle(itemType ?,-stylename=>name? ?,-refwindow=>pathName? ?,option=>value, ...?);

   $styleObject->configure(?,option=>value,?)

   $styleObject->cget(option)

   $styleObject->delete;

   $hostWidget->itemCreate(parent, index, -itemtype=>type, ?,option=>value, ...?);

   $hostWidget->itemConfigure(item, ?,option=>value,?)

   $hostWidget->itemCget(item, option)

   $hostWidget->itemDelete(item, ...)

DESCRIPTION

Display items are used to display various kinds of information within Tk widgets that support them, such as HList, TableList, etc. This man page describes the different types of display items, their options, and how to create and manipulate them.

A display item is a component within a Tk widget that displays some content. Examples include text, images, or even other Tk widgets.

A display style defines the appearance and behavior of a display item. You can create and manage display styles using the ItemStyle method.

DISPLAY ITEM TYPES AND OPTIONS

Tk provides several built-in display item types. Each type supports a set of options that control its appearance and behavior.

STANDARD OPTIONS

Most display item types support the following standard Tk options:

-activebackground, -activeforeground, -anchor, -background, -disabledbackground, -disabledforeground, -foreground, -font, -justify, -padx, -pady, -selectbackground, -selectforeground, -wraplength.

Refer to the Tk::options documentation for a detailed description of these standard options.

IMAGETEXT ITEMS

Display items of type imagetext are used to display a text string with an optional image to its left. ImageText items support the following options:

ImageText Item Options

Name: textStyle
Class: TextStyle
Switch: -style
Specifies the display style to use for this imagetext item. Must be the name of a text display style that has already been created with ItemStyle.
Name: text
Class: Text
Switch: -text
Specifies the text string to display in the item.
Name: underline
Class: Underline
Switch: -underline
Specifies the integer index of a character to underline in the item. 0 corresponds to the first character of the text displayed in the widget, 1 to the next character, and so on.
Name: image
Class: Image
Switch: -image
Specifies the image to display to the left of the text. The value must be a Tk image object.
Name: compound
Class: Compound
Switch: -compound
Specifies how the image and text should be displayed together. Valid values are bottom, center, left, right, top. Default is left.
Name: imageBorder
Class: Border
Switch: -imageborder
Specifies the border width around the image.
Name: imageSpace
Class: Space
Switch: -imagespace
Specifies the amount of space between the image and the text.

ImageText Style Options

STANDARD OPTIONS

-activebackground, -activeforeground, -anchor, -background, -disabledbackground, -disabledforeground, -foreground, -font, -justify, -padx, -pady, -selectbackground, -selectforeground, -wraplength.

Note that the options -anchor, -justify and -wraplength apply to the text part of the item. The image is usually anchored to the left of the text.

The combination of -anchor and -justify can sometimes lead to unexpected results. For example, specifying -anchor as e and -justify as right for the text part, while the image is displayed to the left of the text, may result in the text being drawn in an odd position.

To get items to line up correctly it will usually be necessary to specify -anchor as well. e.g. with default e then anchoring item as a whole w lines images up down left with text stuck to right side.

TEXT ITEMS

Display items of the type text are used to display a text string in a widget. Text items support the following options:

Text Item Options

Name: textStyle
Class: TextStyle
Switch: -style
Specifies the display style to use for this text item. Must be the name of a text display style that has already be created with ItemStyle.
Name: text
Class: Text
Switch: -text
Specifies the text string to display in the item.
Name: underline
Class: Underline
Switch: -underline
Specifies the integer index of a character to underline in the item. 0 corresponds to the first character of the text displayed in the widget, 1 to the next character, and so on.

Text Style Options

STANDARD OPTIONS

-activebackground -activeforeground -anchor -background -disabledbackground -disabledforeground -foreground -font -justify -padx -pady -selectbackground -selectforeground -wraplength

See Tk::options for details of the standard options.

WINDOW ITEMS

Display items of the type window are used to display a sub-window in a widget. Window items support the following options:

Window Item Options

Name: windowStyle
Class: WindowStyle
Switch: -style
Specifies the display style to use for this window item. Must be the name of a window display style that has already be created with the ItemStyle method.
Name: window
Class: Window
Switch: -window
Alias: -widget
Specifies the sub-window to display in the item.

Window Style Options

STYLE STANDARD OPTIONS

-anchor -padx -pady

See Tk::options for details of the standard options.

CREATING DISPLAY ITEMS

Display items do not exist on their own and thus they cannot be created independently of the widgets they reside in. As a rule, display items are created by special methods of their "host" widgets. For example, the HList widget has a method itemCreate which can be used to create new display items. The following code creates a new text item at the third column of the entry 'foo' inside an HList widget:

my $hlist = $parent->HList(-columns=>3);
$hlist->add('foo');
$hlist->itemCreate('foo', 2, -itemtype=>'text', -text=>'Hello');

The itemCreate method of the HList widget accepts a variable number of arguments. The special argument -itemtype specifies which type of display item to create. Options that are valid for this type of display items can then be specified by one or more option-value pairs.

After the display item is created, it can then be configured or destroyed using the methods provided by the host widget. For example, the HList widget has the methods itemConfigure, itemCget and itemDelete for accessing the display items.

CREATING AND MANIPULATING ITEM STYLES

Item styles are created with ItemStyle:

SYNOPSIS

   $widget->ItemStyle(itemType ?,-stylename=>name? ?,-refwindow=>pathName? ?,option=>value, ...>?);

itemType must be one of the existing display items types such as text, imagetext, window or any new types added by the user. Additional arguments can be given in one or more option-value pairs. option can be any of the valid option for this display style or any of the following:

-stylename => name
Specifies a name for this style. If unspecified, then a default name will be chosen for this style.
-refwindow => $otherwidget
Specifies a window to use for determine the default values of the display type. If unspecified, the $widget will be used. Default values for the display types can be set via the options database. The following example sets the -disablebackground and -disabledforeground options of a text display style via the option database: 
$widget->optionAdd('*table.list*disabledForeground' => 'blue');
$widget->optionAdd('*table.list*disabledBackground' => 'darkgray');
$widget->ItemStyle('text', -refwindow => $table_list, -fg => 'red');

By using the option database to set the options of the display styles, we can avoid hard-coding the option values and give the user more flexibility in customization. See Tk::option for a detailed description of the option database.

STYLE METHODS

The ItemStyle method creates an object. This object supports the configure and cget methods described in Tk::options which can be used to enquire and modify the options described above.

The following additional methods are available for item styles:

$style->delete
Destroy this display style object.

EXAMPLE

The following example creates two columns of data in a HList widget. The first column is in red and the second column in blue. The colors of the columns are controlled by two different text styles. Also, the anchor and font of the second column is chosen so that the income data is aligned properly.

use strict;
use Tk;
use Tk::HList;
use Tk::ItemStyle;
my $mw = MainWindow->new();
my $hlist = $mw->HList(-columns=>2)->pack;
my $red  = $hlist->ItemStyle('text', -foreground=>'#800000');
my $blue = $hlist->ItemStyle('text', -foreground=>'#000080', -anchor=>'e');
my $e;
foreach ([Joe => '$10,000'], [Peter => '$20,000'],
         [Raj => '$90,000'],  [Zinh => '$0']) {
    $e = $hlist->addchild("");
    $hlist->itemCreate($e, 0, -itemtype=>'text',
             -text=>$_->[0], -style=>$red );
    $hlist->itemCreate($e, 1, -itemtype=>'text',
             -text=>$_->[1], -style=>$blue);
}
Tk::MainLoop;
