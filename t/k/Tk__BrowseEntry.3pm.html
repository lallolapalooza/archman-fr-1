NOM

Tk::BrowseEntry - widget d'entrée avec choix contextuels.

SYNTAXE

use Tk::BrowseEntry;
$b = $frame->BrowseEntry(-label => "Libellé", -variable => \$var);
$b->insert("end", "opt1");
$b->insert("end", "opt2");
$b->insert("end", "opt3");
...
$b->pack;

CLASSE SUPÉRIEURE

La classe "BrowseEntry" est dérivée de la classe "Frame" et hérite de toutes les méthodes, options et sous-widgets de sa classe supérieure. Par défaut, les options et méthodes sont déléguées au sous-widget d'entrée.

DESCRIPTION

BrowseEntry est le ComboBox du pauvre. Il peut être considéré comme une version améliorée de LabEntry qui fournit un bouton pour afficher les choix des valeurs possibles que l'entrée peut prendre. BrowseEntry supporte toutes les options que LabEntry supporte à l'exception de -textvariable. Celle-ci est remplacée par -variable. Les autres options supportées par BrowseEntry sont :

-arrowimage
Spécifie l'image à utiliser dans le bouton flèche à côté du widget d'entrée. Par défaut, il s'agit d'une image de flèche vers le bas dans le fichier cbxarrow.xbm.
-autolimitheight
Si défini à une valeur vraie, la hauteur de la listbox sera au maximum le nombre d'entrées dans la liste. Le maximum global de "-listheight" s'applique toujours.
-autolistwidth
Si défini à une valeur vraie, la largeur de la listbox correspondra à la largeur de l'entrée la plus grande.
-browsecmd
Spécifie une fonction à appeler lorsqu'une sélection est faite dans la listbox affichée. Elle reçoit le widget et le texte de l'entrée sélectionnée. Cette fonction est appelée après que la variable d'entrée ait reçu la valeur.
-browse2cmd
Comme "-browsecmd", mais le callback est appelé avec l'index de la listbox au lieu de la valeur sélectionnée.
-buttontakefocus
Définit l'option "-takefocus" du sous-widget bouton.
-choices
Spécifie la liste des choix à afficher. Il s'agit d'une référence vers un tableau de chaînes de caractères spécifiant les choix.
-colorstate
L'état du widget est reflété par la couleur. Une entrée non éditable aura un fond gris clair, tandis qu'une entrée éditable sera presque blanche. [Ceci peut changer]
-listcmd
Spécifie la fonction à appeler lorsque le bouton à côté de l'entrée est pressé pour afficher les choix dans la listbox. Ceci est appelé avant d'afficher la listbox, et peut donc être utilisé pour remplir les entrées de la listbox.
-listheight
Définit la hauteur de la listbox. Voir aussi "-autolimitheight".
-listwidth
Spécifie la largeur de la listbox contextuelle.
-state
Spécifie l'un des trois états du widget : normal, readonly, ou disabled. Si le widget est désactivé, la valeur ne peut pas être changée et le bouton flèche ne s'activera pas. Si le widget est en lecture seule (readonly), l'entrée ne peut pas être éditée, mais elle peut être modifiée en choisissant une valeur dans la listbox contextuelle. normal est l'état par défaut.
-style
Définit le "style" du widget. Les valeurs permises sont "MSWin32" et "unix". Par défaut, "-style" est défini sur la plateforme actuelle. Les widgets avec le style "unix" ressembleront à un widget "BrowseEntry" normal, tandis qu'avec le style "MSWin32" la flèche ressemblera au widget combobox standard de Windows, tandis que le survol des entrées les mettra en surbrillance, et inclura probablement d'autres modifications.
-variable
Spécifie la variable dans laquelle la valeur entrée doit être stockée.

MÉTHODES

insert(index, string)
Insère le texte de string à l' index spécifié. Cette chaîne devient alors disponible comme l'un des choix.
delete(index1, index2)
Supprime les éléments de index1 à index2.
get
La méthode get est déléguée à la listbox des choix.

WIDGETS ANNONCÉS

Les widgets suivants sont annoncés :

entry
Le widget d'entrée.
arrow
Le bouton avec l'image de flèche.
choices
Le widget de niveau supérieur contenant la listbox de choix.
slistbox
La listbox défilante avec les choix.

SOUS-CLASSEMENT

Pour faciliter le sous-classement, les méthodes suivantes peuvent être redéfinies pour utiliser d'autres widgets standards dans la composition du méga-widget :

LabEntryWidget
Une classe de widget compatible avec Tk::LabEntry utilisée pour l'entrée.
ButtonWidget
Une classe de widget compatible avec Tk::Button utilisée pour le bouton flèche.
ListboxWidget
Une classe de widget compatible avec Tk::Listbox utilisée pour la listbox de choix.

Par exemple, pour utiliser un widget "NumEntry" (de la distribution CPAN Tk-GBARR) au lieu du widget "Entry" normal :

package Tk::NumBrowseEntry;
use base qw(Tk::BrowseEntry);
use Tk::NumEntry;
Construct Tk::Widget 'NumBrowseEntry';
sub LabEntryWidget { "NumEntry" }

BOGUES

BrowseEntry devrait vraiment fournir plus d'options de ComboBox.
