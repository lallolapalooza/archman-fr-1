NOM

Tk::chooseColor - affiche une boîte de dialogue pour que l'utilisateur sélectionne une couleur.

SYNTAXE

    $couleur = $widget->chooseColor?(-option=>valeur, ...)?;

DESCRIPTION

La méthode chooseColor est implémentée comme une enveloppe Perl pour la commande Tk "native" tk_chooseColor, et $widget est passée comme argument à l'option cachée -parent. L'implémentation interne de tk_chooseColor est spécifique à la plateforme : sous Win32, c'est une boîte de dialogue native, et sous UNIX/X11, elle est implémentée à l'aide de Tk::ColorEditor.

La méthode chooseColor affiche une boîte de dialogue pour que l'utilisateur sélectionne une couleur. Les paires option-valeur suivantes sont possibles comme arguments de ligne de commande :

-initialcolor=>couleur
Spécifie la couleur à afficher dans la boîte de dialogue de couleur lorsqu'elle apparaît. couleur doit être dans un format acceptable pour la fonction Tk_GetColor.
-parent=>$widget
Fait de $widget le parent logique de la boîte de dialogue de couleur. La boîte de dialogue de couleur s'affiche au-dessus de sa fenêtre parente.
-title=>chaîneTitre
Spécifie une chaîne de caractères à afficher comme titre de la boîte de dialogue. Si cette option n'est pas spécifiée, un titre par défaut sera affiché.

Si l'utilisateur sélectionne une couleur, tk_chooseColor retournera le nom de la couleur dans un format acceptable pour Tk_GetColor. Si l'utilisateur annule l'opération, la commande retournera undef.

EXEMPLE

$widget->configure(-fg => $parent->chooseColor(-initialcolor => 'gray',
                                               -title => "Choisir une couleur"));

MOTS-CLÉS

boîte de dialogue de sélection de couleur
