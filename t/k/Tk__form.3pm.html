DESCRIPTION

Tk::form est une classe de boîte de dialogue générique qui permet de créer facilement des boîtes de dialogue de formulaire standard. Le formulaire gère l'alignement automatique des widgets et le positionnement en fonction des attributs des widgets eux-mêmes.

SPÉCIFICATION DES PIÈCES JOINTES

Chaque widget ajouté au formulaire a une liste de "pièces jointes" qui spécifient comment il doit être positionné et ancré par rapport aux autres widgets et aux bords du formulaire.

Les pièces jointes sont spécifiées sous forme de liste de paires -side et -fill.

  • -side : spécifie le côté du widget auquel il est attaché. Les valeurs possibles sont top, bottom, left, right.
  • -fill : spécifie comment le widget doit se remplir s'il y a de l'espace supplémentaire. Les valeurs possibles sont none, x, y, both.

Par exemple :


                    $form->add( 'button', -text => 'OK', -side => 'left', -fill => 'x' );
                    $form->add( 'button', -text => 'Annuler', -side => 'right', -fill => 'x' );

Ceci ajoutera deux boutons, "OK" et "Annuler", attachés respectivement aux côtés gauche et droit du formulaire, et s'étendant horizontalement.

UTILISATION DES RESSORTS

Les "ressorts" sont utilisés pour contrôler l'espace flexible entre les widgets. Vous pouvez ajouter un ressort à un côté d'un widget pour lui permettre de s'étirer et de pousser les autres widgets.

Pour ajouter un ressort, utilisez l'option -expand lors de l'ajout d'un widget :


                    $form->add( 'label', -text => 'Nom:', -side => 'left' );
                    $form->add( 'entry', -side => 'left', -expand => 'x' );

Dans cet exemple, le widget entry s'étirera horizontalement pour occuper tout l'espace disponible, repoussant le widget label vers la gauche.

ALGORITHME DU FORMULAIRE

Le formulaire utilise un algorithme de disposition basé sur la contrainte. Il analyse les relations entre les widgets et leurs attachements pour calculer les positions et les tailles finales.

L'ordre dans lequel les widgets sont ajoutés est important, car il peut affecter le résultat final lorsque des dépendances complexes sont présentes.

DÉPENDANCE CIRCULAIRE

Des dépendances circulaires peuvent survenir si les règles d'attachement des widgets créent une boucle. Par exemple, si le widget A est attaché au côté gauche du widget B, et que le widget B est attaché au côté droit du widget A.

Le formulaire tentera de résoudre les dépendances circulaires dans la mesure du possible, mais dans certains cas, cela peut entraîner un comportement inattendu ou une erreur.
