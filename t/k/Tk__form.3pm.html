NOM

Tk::form - Gestionnaire de géométrie basé sur des règles d'attachement

SYNOPSIS

    $widget->form?(args)?

    $widget->formOption?(args)?

DESCRIPTION

La méthode form est utilisée pour communiquer avec le gestionnaire de géométrie form, un gestionnaire de géométrie qui dispose la géométrie des enfants dans une fenêtre parente selon des règles d'attachement. Le gestionnaire de géométrie form est très flexible et puissant ; il peut être utilisé pour émuler toutes les fonctionnalités existantes des gestionnaires de géométrie packer et placer de Tk (voir pack, place). La méthode form peut prendre plusieurs formes, selon Option :

$slave->form?(options)?
Définit ou ajuste les valeurs d'attachement de la fenêtre esclave selon les paires d'arguments -option=>valeur.
-b => attachment
Abréviation de l'option -bottom.
-bottom => attachment
Spécifie un attachement pour le bord inférieur de la fenêtre esclave. L'attachement doit être spécifié conformément à « SPÉCIFICATION DES ATTACHEMENTS » ci-dessous.
-bottomspring => weight
Spécifie le poids du ressort au bord inférieur de la fenêtre esclave. Voir « UTILISATION DES RESSORTS » ci-dessous.
-bp => value
Abréviation de l'option -padbottom.
-bs => weight
Abréviation de l'option -bottomspring.
-fill => style
Spécifie les remplissages lorsque des ressorts sont utilisés pour ce widget. La valeur doit être x, y, both ou none.
-in => $master
Place la fenêtre esclave dans la fenêtre $master spécifiée. Si l'esclave était à l'origine dans une autre fenêtre maître, toutes les valeurs d'attachement par rapport à la fenêtre maître d'origine sont ignorées. Même si les valeurs d'attachement sont les mêmes que dans la fenêtre maître d'origine, elles doivent être spécifiées à nouveau. L'indicateur -in, lorsqu'il est nécessaire, doit apparaître comme premier indicateur de options. Sinon, une erreur est générée.
-l => attachment
Abréviation de l'option -left.
-left => attachment
Spécifie un attachement pour le bord gauche de la fenêtre esclave. L'attachement doit être spécifié conformément à « SPÉCIFICATION DES ATTACHEMENTS » ci-dessous.
-leftspring => weight
Spécifie le poids du ressort au bord gauche de la fenêtre esclave. Voir « UTILISATION DES RESSORTS » ci-dessous.
-lp => value
Abréviation de l'option -padleft.
-ls => weight
Abréviation de l'option -leftspring.
-padbottom => value
Spécifie la quantité de remplissage externe à laisser du côté inférieur de l'esclave. La valeur peut prendre l'une des formes acceptables pour Tk_GetPixels.
-padleft => value
Spécifie la quantité de remplissage externe à laisser du côté gauche de l'esclave.
-padright => value
Spécifie la quantité de remplissage externe à laisser du côté droit de l'esclave.
-padtop => value
Spécifie la quantité de remplissage externe à laisser du côté supérieur de l'esclave.
-padx => value
Spécifie la quantité de remplissage externe à laisser à la fois du côté gauche et du côté droit de l'esclave.
-pady => value
Spécifie la quantité de remplissage externe à laisser à la fois du côté supérieur et du côté inférieur de l'esclave.
-r => attachment
Abréviation de l'option -right.
-right => attachment
Spécifie un attachement pour le bord droit de la fenêtre esclave. L'attachement doit être spécifié conformément à « SPÉCIFICATION DES ATTACHEMENTS » ci-dessous.
-rightspring => weight
Spécifie le poids du ressort au bord droit de la fenêtre esclave. Voir « UTILISATION DES RESSORTS » ci-dessous.
-rp => value
Abréviation de l'option -padright.
-rs => weight
Abréviation de l'option -rightspring.
-t => attachment
Abréviation de l'option -top.
-top => attachment
Spécifie un attachement pour le bord supérieur de la fenêtre esclave. L'attachement doit être spécifié conformément à « SPÉCIFICATION DES ATTACHEMENTS » ci-dessous.
-topspring => weight
Spécifie le poids du ressort au bord supérieur de la fenêtre esclave. Voir « UTILISATION DES RESSORTS » ci-dessous.
-tp => value
Abréviation de l'option -padtop.
-ts => weight
Abréviation de l'option -topspring.
$master->formCheck
Cette méthode vérifie s'il existe une dépendance circulaire dans les attachements des esclaves du maître (voir « DÉPENDANCE CIRCULAIRE » ci-dessous). Elle renvoie la valeur booléenne TRUE si elle découvre une dépendance circulaire et FALSE sinon.
$slave->formForget
Retire l'esclave de son maître et démarque sa fenêtre. L'esclave ne sera plus géré par form. Toutes les valeurs d'attachement par rapport à sa fenêtre maître sont ignorées. Si un autre esclave est attaché à cet esclave, alors l'attachement de l'autre esclave sera changé en attachement à la grille basé sur sa géométrie.
$master->formGrid?(x_size, y_size)?
Lorsque x_size et y_size sont donnés, cette méthode renvoie le nombre de grilles de la fenêtre $master sous la forme d'une paire d'entiers de la forme (x_size, y_size). Lorsque x_size et y_size sont tous deux donnés, cette méthode modifie le nombre de grilles horizontales et verticales sur la fenêtre maître.
$slave->formInfo?(-option)?
Interroge les options d'attachement d'une fenêtre esclave. -option peut être l'une des options acceptées par la méthode form. Si -option est donné, seule la valeur de cette option est renvoyée. Sinon, cette méthode renvoie une liste dont les éléments sont l'état de configuration actuel de l'esclave donné sous la même forme option-valeur qui pourrait être spécifiée à form. Les deux premiers éléments de cette liste sont « -in=>$master » où $master est la fenêtre maître de l'esclave.
$master->formSlaves
Renvoie une liste de tous les esclaves de la fenêtre maître. L'ordre des esclaves dans la liste est le même que leur ordre dans l'ordre d'empilement. Si le maître n'a pas d'esclaves, une chaîne vide est renvoyée.

DESCRIPTION

Tk::form est une classe de boîte de dialogue générique qui permet de créer facilement des boîtes de dialogue de formulaire standard. Le formulaire gère l'alignement automatique des widgets et le positionnement en fonction des attributs des widgets eux-mêmes.

SPÉCIFICATION DES PIÈCES JOINTES

Chaque widget ajouté au formulaire a une liste de "pièces jointes" qui spécifient comment il doit être positionné et ancré par rapport aux autres widgets et aux bords du formulaire.

Les pièces jointes sont spécifiées sous forme de liste de paires -side et -fill.

  • -side : spécifie le côté du widget auquel il est attaché. Les valeurs possibles sont top, bottom, left, right.
  • -fill : spécifie comment le widget doit se remplir s'il y a de l'espace supplémentaire. Les valeurs possibles sont none, x, y, both.

Par exemple :


                    $form->add( 'button', -text => 'OK', -side => 'left', -fill => 'x' );
                    $form->add( 'button', -text => 'Annuler', -side => 'right', -fill => 'x' );

Ceci ajoutera deux boutons, "OK" et "Annuler", attachés respectivement aux côtés gauche et droit du formulaire, et s'étendant horizontalement.

UTILISATION DES RESSORTS

Les "ressorts" sont utilisés pour contrôler l'espace flexible entre les widgets. Vous pouvez ajouter un ressort à un côté d'un widget pour lui permettre de s'étirer et de pousser les autres widgets.

Pour ajouter un ressort, utilisez l'option -expand lors de l'ajout d'un widget :


                    $form->add( 'label', -text => 'Nom:', -side => 'left' );
                    $form->add( 'entry', -side => 'left', -expand => 'x' );

Dans cet exemple, le widget entry s'étirera horizontalement pour occuper tout l'espace disponible, repoussant le widget label vers la gauche.

ALGORITHME DU FORMULAIRE

Le formulaire utilise un algorithme de disposition basé sur la contrainte. Il analyse les relations entre les widgets et leurs attachements pour calculer les positions et les tailles finales.

L'ordre dans lequel les widgets sont ajoutés est important, car il peut affecter le résultat final lorsque des dépendances complexes sont présentes.

DÉPENDANCE CIRCULAIRE

Des dépendances circulaires peuvent survenir si les règles d'attachement des widgets créent une boucle. Par exemple, si le widget A est attaché au côté gauche du widget B, et que le widget B est attaché au côté droit du widget A.

Le formulaire tentera de résoudre les dépendances circulaires dans la mesure du possible, mais dans certains cas, cela peut entraîner un comportement inattendu ou une erreur.
