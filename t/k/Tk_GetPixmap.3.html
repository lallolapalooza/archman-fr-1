Tk_GetPixmap(3) Procédures de la bibliothèque Tk Tk_GetPixmap(3)

NOM

Tk_GetPixmap, Tk_FreePixmap - allouer et libérer des pixmaps

SYNTAXE

#include <tk.h>

Pixmap
Tk_GetPixmap(display, d, width, height, depth)

Tk_FreePixmap(display, pixmap)

ARGUMENTS

Display *display (en entrée)
Affichage X pour la pixmap.
Drawable d (en entrée)
Pixmap ou fenêtre où la nouvelle pixmap sera utilisée pour le dessin.
int width (en entrée)
Largeur de la pixmap.
int height (en entrée)
Hauteur de la pixmap.
int depth (en entrée)
Nombre de bits par pixel dans la pixmap.
Pixmap pixmap (en entrée)
Pixmap à détruire.

DESCRIPTION

Ces procédures sont identiques aux procédures Xlib XCreatePixmap et XFreePixmap, à la différence qu'elles disposent de code supplémentaire pour gérer les identifiants de ressources X afin que les identifiants des pixmaps supprimées puissent être réutilisés à l'avenir. Il est important que les applications Tk utilisent ces procédures plutôt que XCreatePixmap et XFreePixmap ; sinon, les applications de longue durée pourraient manquer d'identifiants de ressources.

Tk_GetPixmap crée une pixmap adaptée au dessin dans d, avec les dimensions spécifiées par width, height et depth, et retourne son identifiant. Tk_FreePixmap détruit la pixmap spécifiée par pixmap et rend son identifiant de ressource disponible pour réutilisation.

MOTS-CLÉS

pixmap, identifiant de ressource

4.0 Tk
