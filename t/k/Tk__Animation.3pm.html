NOM

Tk::Animation - Affiche une séquence d'images Tk::Photo

SYNOPSIS

use Tk::Animation
my $img = $widget->Animation('-format' => 'gif', -file => 'somefile.gif');
$img->add_frame(@images);
$img->start_animation;
$img->start_animation( $period );
$img->next_image;
$img->prev_image;
$img->set_image( 0 .. $#frames );
$img->pause_animation;
$img->resume_animation( $period );
$img->fast_forward( $multiplier );
$img->fast_reverse( $multiplier );
$img->stop_animation;
$img->set_disposal_method( $boolean );

DESCRIPTION

Dans le cas simple où "Animation" reçoit un GIF de style GIF89 avec plusieurs « images », il construira un tableau interne d'images "Photo".

La méthode "add_frame" ajoute des images à la séquence. Elle est fournie pour permettre la construction d'animations à partir d'images distinctes. Toutes les images doivent être des "Photo" et avoir toutes la même taille.

start_animation($period) initie alors une "repeat" avec la période spécifiée $period pour séquencer ces images. Comme pour les "repeat" bruts, $period est en millisecondes, pour un moniteur 50Hz, il devrait être d'au moins 20 ms. Si $period est omis, il est déterminé à partir des métadonnées du GIF (voir ci-dessous), ou s'il est impossible de le faire, il vaut par défaut 100 millisecondes.

"stop_animation" annule la "repeat" et réinitialise l'image à la première image de la séquence.

Pour un contrôle plus précis, "next_image" et "prev_image" se déplacent d'une image vers l'avant ou l'arrière. "set_image" positionne aléatoirement l'animation à une image particulière.

"pause_animation" met le film en pause et "resume_animation" continue depuis le point de pause.

"fast_forward" et "fast_reverse" accélèrent le film, soit vers l'avant, soit vers l'arrière. $multiplier spécifie à quel point l'animation est plus rapide.

Si Image::Info est installé, alors le temps de répétition et la méthode d'élimination des animations GIF sont déterminés directement à partir des métadonnées du GIF. Sinon, la méthode d'élimination doit être définie manuellement en utilisant "set_disposal_method" (1 pour effacer les images précédentes, 0 pour laisser les images précédentes telles quelles). Le temps de répétition peut être spécifié dans la méthode "start_animation".

NOTES

"set_disposal_method" était anciennement connue sous le nom de méthode "blank", mais le nom de cette méthode était une erreur.

Si la méthode d'élimination n'est pas définie correctement, soit par "set_disposal_method", soit par dérivation des métadonnées du GIF, alors ce qui suit peut se produire : Par défaut, Animation laisse l'image précédente du film dans la photo de l'animation. Souvent, la superposition des images suivantes produit un composite qui semble flou.

BOGUES

Ce module ne devrait pas dépendre d'un module qui n'est pas déclaré comme dépendance (Image::Info).

Les délais entre les images peuvent varier dans une animation GIF. Ce module ne peut pas encore le gérer.

La gestion des différentes méthodes d'élimination n'est pas correcte.
