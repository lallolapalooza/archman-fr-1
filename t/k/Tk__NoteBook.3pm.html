Tk__NoteBook(3pm)

Paquet: perl-tk

Licences: PerlArtistic, GPL, custom

NoteBook(3) Documentation Perl fournie par l'utilisateur NoteBook(3)

NOM

Tk::NoteBook - affiche plusieurs fenêtres dans un espace limité avec la métaphore d'un carnet.

SYNOPIS

use Tk::NoteBook;
...
$w = $frame->NoteBook();
$page1 = $w->add("page1", options);
$page2 = $w->add("page2", options);
...
$page2 = $w->add("page2", options);

DESCRIPTION

Le widget NoteBook fournit une métaphore de carnet pour afficher plusieurs fenêtres dans un espace limité. Le carnet est divisé en une pile de pages dont une seule est affichée à la fois. Les autres pages peuvent être sélectionnées en choisissant les "onglets" visuels en haut du widget. De plus, la touche <Tab> peut être utilisée pour parcourir les pages. Si -underline est utilisé, les liaisons Alt- fonctionneront également.

Le widget accepte toutes les options d'un Frame. De plus, il prend en charge les options suivantes :

-dynamicgeometry
Si défini à false (par défaut et recommandé), la taille du NoteBook correspondra à la taille de la plus grande page. Sinon, la taille correspondra à la taille de la page actuelle, provoquant un changement de taille du NoteBook lors de la sélection de pages de tailles différentes.
-ipadx
La quantité de remplissage horizontal interne autour des pages.
-ipady
La quantité de remplissage vertical interne autour des pages.
-backpagecolor
La couleur de fond des onglets et de la page arrière.
-disabledforeground
XXX
-focuscolor
La couleur de la bordure de focus autour des onglets.
-font
La police des étiquettes des onglets.
-inactivebackground
XXX
-tabpadx
Le remplissage horizontal autour de l'étiquette de l'onglet.
-tabpady
Le remplissage vertical autour de l'étiquette de l'onglet.

MÉTHODES

Les méthodes suivantes peuvent être utilisées avec un objet NoteBook en plus des méthodes standard.

add(nomPage, options)
Ajoute une page nommée nomPage au carnet. Retourne un objet de type Frame. Les options reconnues sont :
-anchor
Spécifie comment les informations d'un onglet doivent être affichées. Doit être l'une de n, ne, e, se, s, sw, w, nw ou center.
-bitmap
Spécifie un bitmap à afficher sur l'onglet de cette page. Le bitmap est affiché uniquement si aucune des options -label ou -image n'est spécifiée.
-image
Spécifie une image à afficher sur l'onglet de cette page. L'image est affichée uniquement si l'option -label n'est pas spécifiée.
-label
Spécifie la chaîne de texte à afficher sur l'onglet de cette page.
-justify
Lorsqu'il y a plusieurs lignes de texte affichées dans un onglet, cette option détermine la justification des lignes.
-createcmd
Spécifie une fonction de rappel à appeler la première fois que la page est affichée à l'écran. Cette option peut être utilisée pour retarder la création du contenu d'une page jusqu'à ce qu'elle soit nécessaire. Elle peut être utile dans des situations où il y a un grand nombre de pages dans un widget NoteBook ; avec -createcmd, vous n'avez pas à faire attendre l'utilisateur jusqu'à ce que toutes les pages soient construites avant d'afficher la première page.
-raisecmd
Spécifie une fonction de rappel à appeler chaque fois que cette page est affichée par l'utilisateur.
-state
Spécifie si cette page peut être affichée par l'utilisateur. Doit être normal ou disabled.
-underline
Spécifie l'index entier d'un caractère à souligner dans l'onglet. Cette option est utilisée par les liaisons par défaut pour implémenter la navigation au clavier pour les boutons de menu et les entrées de menu. 0 correspond au premier caractère du texte affiché sur le widget, 1 au caractère suivant, et ainsi de suite.
-wraplength
Cette option spécifie la longueur maximale de ligne de la chaîne d'étiquette sur cet onglet. Si la longueur de ligne de la chaîne d'étiquette dépasse cette longueur, elle est renvoyée à la ligne suivante de sorte qu'aucune ligne ne dépasse la longueur spécifiée. La valeur peut être spécifiée dans toutes les formes standard pour les distances d'écran. Si cette valeur est inférieure ou égale à 0, aucun renvoi à la ligne n'est effectué : les lignes ne seront coupées qu'aux caractères de nouvelle ligne dans le texte.
delete(nomPage)
Supprime la page identifiée par nomPage.
pagecget(nomPage, -option)
Retourne la valeur actuelle de l'option de configuration donnée par -option dans la page donnée par nomPage. Option peut avoir l'une des valeurs acceptées dans la méthode add.
pageconfigure(nomPage, options)
Comme configure pour la page indiquée par nomPage. Options peut être l'une des options acceptées par la méthode add.
pages
Retourne une liste contenant les noms de toutes les pages actuellement définies, c'est-à-dire celles créées avec la méthode add.
page_widget(nomPage)
Retourne la page nommée nomPage.
raise(nomPage)
Affiche la page identifiée par nomPage.
raised()
Retourne le nom de la page actuellement affichée.
geometryinfo
Retourne les dimensions de la zone des onglets.
identify(x,y)
Identifie le nom de la page de l'onglet sous les coordonnées spécifiées. Retourne une chaîne vide s'il n'y a pas d'onglet.
info("pages")
Retourne une liste de toutes les pages.
info("focus")
Retourne le nom de la page de l'onglet qui a le focus actuel.
info("focusnext")
Retourne le nom de la page de l'onglet qui recevrait le prochain focus.
info("focusprev")
Retourne le nom de la page de l'onglet qui avait le focus précédent.
info("active")
Retourne le nom de la page de l'onglet actif.

BOGUES

Les options "-width" et "-height" ne fonctionnent pas.
