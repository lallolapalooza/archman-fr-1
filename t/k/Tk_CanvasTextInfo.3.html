NOM

Tk_CanvasTextInfo - informations supplémentaires pour la gestion des éléments de texte dans les canevas

SYNOPIS

#include <tk.h>

Tk_CanvasTextInfo *
Tk_CanvasGetTextInfo(canvas)

ARGUMENTS

Tk_Canvas canvas (entrée)
Un jeton qui identifie un canevas particulier.

DESCRIPTION

La gestion des éléments textuels de canevas est un peu plus complexe que celle des autres éléments, en raison de choses comme la sélection et le focus d'entrée. Tk_CanvasGetTextInfo peut être appelé par un gestionnaire de type pour obtenir des informations supplémentaires nécessaires aux éléments qui affichent du texte. La valeur de retour de Tk_CanvasGetTextInfo est un pointeur vers une structure partagée entre Tk et tous les éléments qui affichent du texte. La structure a la forme suivante :

typedef struct Tk_CanvasTextInfo {
    Tk_3DBorder selBorder;
    int selBorderWidth;
    XColor *selFgColorPtr;
    Tk_Item *selItemPtr;
    int selectFirst;
    int selectLast;
    Tk_Item *anchorItemPtr;
    int selectAnchor;
    Tk_3DBorder insertBorder;
    int insertWidth;
    int insertBorderWidth;
    Tk_Item *focusItemPtr;
    int gotFocus;
    int cursorOn;
} Tk_CanvasTextInfo;
Le champ selBorder identifie un Tk_3DBorder qui doit être utilisé pour dessiner l'arrière-plan sous le texte sélectionné. selBorderWidth donne la largeur de la bordure en relief autour du texte sélectionné, en pixels. selFgColorPtr pointe vers un XColor qui décrit la couleur de premier plan à utiliser lors du dessin du texte sélectionné. selItemPtr pointe vers l'élément actuellement sélectionné, ou NULL s'il n'y a pas d'élément sélectionné ou si le canevas n'a pas la sélection. selectFirst et selectLast donnent les indices des premiers et derniers caractères sélectionnés dans selItemPtr, tels que retournés par le indexProc pour cet élément. anchorItemPtr pointe vers l'élément qui détient actuellement l'ancre de sélection ; ce n'est pas nécessairement le même que selItemPtr. selectAnchor est un indice qui identifie la position de l'ancre dans anchorItemPtr. insertBorder contient un Tk_3DBorder à utiliser lors du dessin du curseur d'insertion ; insertWidth donne la largeur totale du curseur d'insertion en pixels, et insertBorderWidth donne la largeur de la bordure en relief autour du curseur d'insertion. focusItemPtr identifie l'élément qui détient actuellement le focus d'entrée, ou NULL s'il n'y a pas d'élément de ce type. gotFocus est 1 si le widget canevas a le focus d'entrée et 0 sinon. cursorOn est 1 si le curseur d'insertion doit être dessiné dans focusItemPtr et 0 s'il ne doit pas être dessiné ; ce champ est activé et désactivé par Tk pour faire clignoter le curseur.

La structure retournée par Tk_CanvasGetTextInfo est partagée entre Tk et les gestionnaires de type ; généralement, le gestionnaire de type appelle Tk_CanvasGetTextInfo une fois lors de la création d'un élément et enregistre ensuite le pointeur dans l'enregistrement de l'élément. Tk mettra à jour les informations dans le Tk_CanvasTextInfo ; par exemple, une commande de widget configure peut modifier le champ selBorder, ou une commande de widget select peut modifier le champ selectFirst, ou Tk peut modifier cursorOn afin de faire clignoter le curseur d'insertion lors des redessins successifs.

Les gestionnaires de type doivent traiter tous les champs de la structure Tk_CanvasTextInfo comme étant en lecture seule, à l'exception de selItemPtr, selectFirst, selectLast et selectAnchor. Les gestionnaires de type peuvent modifier selectFirst, selectLast et selectAnchor pour s'adapter aux insertions et suppressions dans l'élément (mais seulement si l'élément est le propriétaire actuel de la sélection ou de l'ancre, tel que déterminé par selItemPtr ou anchorItemPtr). Si tout le texte sélectionné dans l'élément est supprimé, l'élément doit définir selItemPtr à NULL pour indiquer qu'il n'y a plus de sélection.
