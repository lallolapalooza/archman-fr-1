Tk_QueueWindowEvent(3) Procédures de la bibliothèque Tk Tk_QueueWindowEvent(3)

NOM

Tk_CollapseMotionEvents, Tk_QueueWindowEvent - Ajouter un événement de fenêtre à la file d'attente d'événements Tcl

SYNOPIS

#include <tk.h>

int
Tk_CollapseMotionEvents(display, collapse)

Tk_QueueWindowEvent(eventPtr, position)

ARGUMENTS

Display *display (in)
Affichage pour lequel contrôler la condensation des événements de mouvement.
int collapse (in)
Indique si les événements de mouvement doivent être condensés ou non.
XEvent *eventPtr (in)
Un événement à ajouter à la file d'attente des événements. Il est important que tous les champs inutilisés de la structure soient mis à zéro.
Tcl_QueuePosition position (in)
Où ajouter le nouvel événement dans la file d'attente : TCL_QUEUE_TAIL, TCL_QUEUE_HEAD, ou TCL_QUEUE_MARK.

DESCRIPTION

Tk_QueueWindowEvent place un événement de fenêtre dans la file d'attente d'événements interne de Tcl pour un traitement ultérieur. Il crée une structure Tcl_Event, copie l'événement dans cette structure et appelle Tcl_QueueEvent pour ajouter l'événement à la file d'attente. Lorsque l'événement est finalement retiré de la file d'attente, il est traité comme tous les autres événements de fenêtre.

Lorsque plusieurs événements de mouvement sont reçus pour la même fenêtre en succession rapide, ils sont condensés par défaut. Ce comportement peut être contrôlé avec Tk_CollapseMotionEvents. Tk_CollapseMotionEvents renvoie toujours la valeur précédente du comportement de condensation pour l'affichage display.

L'argument position de Tk_QueueWindowEvent a la même signification que pour Tcl_QueueEvent ; voir la documentation de Tcl_QueueEvent pour plus de détails.
