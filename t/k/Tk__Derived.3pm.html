NOM

Tk::Derived - Classe de base pour les widgets dérivés d'autres

SYNOPSIS

 package Tk::MonNouveauWidget;
 use Tk::widgets qw/ BaseWidget, liste des widgets Tk /;
 use base qw/ Tk::Derived Tk::BaseWidget /;
 Construct Tk::Widget 'MonNouveauWidget';
 sub ClassInit {
     my( $class, $mw ) = @_;
     #... par exemple, liaisons de classe ici ...
     $class->SUPER::ClassInit( $mw );
 }
 sub Populate {
     my( $self, $args ) = @_;
     my $flag = delete $args->{-flag};
     if( defined $flag ) {
         # gérer -flag => xxx qui ne peut être fait qu'à la création
         # la suppression ci-dessus garantit que new() n'essaie pas
         # de faire $self->configure( -flag => xxx );
     }
     $self->SUPER::Populate( $args );
     $self = $self->Component( ... );
     $self->Delegates( ... );
     $self->ConfigSpecs(
         '-cursor'    => [ SELF, 'cursor', 'Cursor',   undef ],
         '-something' => [ METHOD, dbName,  dbClass, default ],
         '-text'      => [ $label, dbName,  dbClass, default ],
         '-heading'   => [ {-text => $head},
                             heading, Heading,  'Mon Titre' ],
    ); 
}
sub something {
    my( $self, $value) = @_;
    if ( @_ > 1 ) {
       # le définir
    }
    return # valeur actuelle
}

DESCRIPTION

Tk::Derived est utilisé avec l'héritage multiple de Perl pour remplacer certaines méthodes normalement héritées de Tk::Widget.

Tk::Derived doit précéder tout widget Tk dans la définition de la classe de base de la classe.

Le but principal de Tk::Derived est d'appliquer des wrappers aux méthodes "configure" et "cget" des widgets pour permettre au widget dérivé d'ajouter ou de modifier le comportement des options de configuration supportées par le widget de base.

La classe dérivée devrait normalement surcharger la méthode "Populate" fournie par Tk::Derived et appeler "ConfigSpecs" pour déclarer les options de configuration.

Les méthodes publiques fournies par Tk::Derived sont les suivantes :

->ConfigSpecs(-key => [kind, name, Class, default], ...)
