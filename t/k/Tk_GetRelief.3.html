Tk_GetRelief(3)

Paquet: tk

Licences: TCL

Tk_GetReliefFromObj(3) Procédures de la bibliothèque Tk Tk_GetReliefFromObj(3)

NOM

Tk_GetReliefFromObj, Tk_GetRelief, Tk_NameOfRelief - traduire entre chaînes et valeurs de relief

SYNOPSIS

#include <tk.h>

int
Tk_GetReliefFromObj(interp, objPtr, reliefPtr)

int
Tk_GetRelief(interp, name, reliefPtr)

const char *
Tk_NameOfRelief(relief)

ARGUMENTS

Tcl_Interp *interp (entrée)
Interpréteur à utiliser pour la gestion des erreurs.
Tcl_Obj *objPtr (entrée/sortie)
La valeur de la chaîne contient le nom du relief, l'un des “flat”, “groove”, “raised”, “ridge”, “solid”, ou “sunken” (ou toute abréviation unique de ceux-ci en entrée) ; la représentation interne sera modifiée pour mettre en cache la valeur de relief correspondante.
const char *name (entrée)
Identique à objPtr sauf que la description du relief est passée sous forme de chaîne.
int *reliefPtr (sortie)
Pointeur vers l'emplacement où stocker la valeur du relief correspondant à objPtr ou name.
int relief (entrée)
Valeur du relief (l'un des TK_RELIEF_FLAT, TK_RELIEF_RAISED, TK_RELIEF_SUNKEN, TK_RELIEF_GROOVE, TK_RELIEF_SOLID, ou TK_RELIEF_RIDGE).

DESCRIPTION

Tk_GetReliefFromObj place dans *reliefPtr la valeur du relief correspondant à la valeur de objPtr. Cette valeur sera l'une des TK_RELIEF_FLAT, TK_RELIEF_RAISED, TK_RELIEF_SUNKEN, TK_RELIEF_GROOVE, TK_RELIEF_SOLID, ou TK_RELIEF_RIDGE. Dans des circonstances normales, la valeur de retour est TCL_OK et interp n'est pas utilisée. Si objPtr ne contient pas l'un des noms de relief valides ou une abréviation de ceux-ci, alors TCL_ERROR est retournée, *reliefPtr n'est pas modifiée, et un message d'erreur est stocké dans le résultat de interp si interp n'est pas NULL. Tk_GetReliefFromObj met en cache les informations sur la valeur de retour dans objPtr, ce qui accélère les appels futurs à Tk_GetReliefFromObj avec le même objPtr.

Tk_GetRelief est identique à Tk_GetReliefFromObj sauf que la description du relief est spécifiée avec une chaîne au lieu d'un objet. Cela empêche Tk_GetRelief de mettre en cache la valeur de retour, donc Tk_GetRelief est moins efficace que Tk_GetReliefFromObj.

Tk_NameOfRelief est l'inverse logique de Tk_GetRelief. Étant donné une valeur de relief, elle renvoie la chaîne correspondante (flat, raised, sunken, groove, solid, ou ridge). Si relief n'est pas une valeur de relief légale, alors “unknown relief” est retournée.
