tixWm(3) Documentation Perl fournie par l'utilisateur tixWm(3)

NOM

Tk::tixWm - Addition de Tix à la commande standard TK wm.

SYNTAXE

    $widget->wmCapture

    $widget->wmRelease

DESCRIPTION

Les méthodes wmCapture et wmRelease modifient l'attribut toplevel des widgets Tk.

MÉTHODES

$widget->wmCapture
Convertit la fenêtre toplevel spécifiée par $widget en un widget non-toplevel. Normalement, cette commande est appelée pour convertir un widget Toplevel en un widget Frame. Le widget frame nouvellement converti est désaffiché de l'écran. Pour le faire apparaître à l'intérieur de son parent, vous devez appeler explicitement un gestionnaire de géométrie (par exemple, grid ou pack).
$widget->wmRelease
Transforme la fenêtre non-toplevel spécifiée par $widget en un widget toplevel. Normalement, cette commande est appelée pour convertir un widget Frame en un widget Toplevel, mais elle peut aussi être utilisée sur n'importe quel widget non-toplevel (par exemple, label). La nouvelle fenêtre toplevel convertie est dans un état withdrawn. Pour la faire apparaître à l'écran, vous devez appeler deiconify après avoir appelé wmRelease.

Toutes les données associées à $widget via les méthodes wm (icône, protocole, commande, etc.) sont libérées et doivent être rétablissement si la fenêtre est ultérieurement recapturée.

BOGUES

wmCapture n'existe pas dans le code du gestionnaire de fenêtres Win32.

La façon dont ces méthodes interagissent avec la hiérarchie des classes de perl/Tk n'est pas encore claire. En particulier, une fenêtre wmReleased n'héritera pas automatiquement des méthodes Tk::Wm, cependant une fenêtre wmCaptured le fera toujours. (Un Label released pourrait être un bon candidat pour une Icon.)
