NOM

Tk::MainWindow - Racine d'un arbre de widgets

SYNTAXE

use Tk;
my $mw = MainWindow->new( ... options ... );
my $this = $mw->ThisWidget -> pack ;
my $that = $mw->ThatWidget;
...
MainLoop;

DESCRIPTION

Les applications Perl/Tk (qui ont des fenêtres associées) créent une ou plusieurs MainWindows qui servent de conteneurs et de parents pour les autres widgets.

Tk::MainWindow est un type spécial de widget Toplevel. C'est la racine d'un arbre de widgets. Par conséquent, "$mw->Parent" retourne "undef".

Le titre par défaut d'une MainWindow est le nom de base du script (en fait le nom de la classe utilisé pour la recherche d'options, c'est-à-dire le nom de base avec la première lettre en majuscule) ou 'Ptk' comme valeur de repli. S'il y a plus d'une MainWindow créée ou si plusieurs instances du script sont exécutées en même temps, la chaîne " #n" est ajoutée, où le nombre "n" est défini pour obtenir une valeur unique.

Contrairement au Tcl/Tk standard (wish), perl/Tk vous permet de créer plusieurs MainWindows. Lorsque la *dernière* MainWindow est détruite, la boucle d'événements Tk se termine (la boucle d'événements est entrée par l'appel de "MainLoop"). Diverses ressources (liaisons, polices, images, couleurs) sont maintenues ou mises en cache pour chaque MainWindow, donc chaque MainWindow consomme plus de ressources qu'un Toplevel. Cependant, plusieurs MainWindows peuvent avoir du sens lorsque l'utilisateur peut les détruire indépendamment.

MÉTHODES

Vous pouvez appliquer toutes les méthodes qu'un widget Toplevel accepte.

La méthode $w->MainWindow appliquée à n'importe quel widget retournera la MainWindow à laquelle le widget appartient (la MainWindow appartient à elle-même).

MANQUANT

La documentation est incomplète. Voici *quelques* éléments manquants qui devraient être expliqués plus en détail :

  • Le nouveau mécanisme pour les MainWindows est légèrement différent des autres widgets.
  • Il n'y a pas d'explication sur les ressources qui sont liées à une MainWindow (par exemple, ClassInit fait par MainWindow).
  • Transmission des options de la ligne de commande pour remplacer ou compléter les arguments de la méthode "new" (voir Tk::CmdLine).
