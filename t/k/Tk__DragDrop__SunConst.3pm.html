NOM

Tk::DragDrop::SunConst - Constantes pour le protocole Drag&Drop de Sun

DESCRIPTION

Ce module définit des sous-programmes à nom symbolique pour les constantes numériques qui composent le protocole Drag&Drop de Sun. Ils se trouvent dans ce module avec Exporter car ils sont partagés entre les deux moitiés (Dropper et Receiver) du protocole.
