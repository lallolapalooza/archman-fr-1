$checkbutton = $parent->Checkbutton(?options?);

OPTIONS STANDARDS

-activebackground -activeforeground -anchor -background -bitmap -borderwidth -compound -cursor -disabledforeground -font -foreground -highlightbackground -highlightcolor -highlightthickness -image -justify -padx -pady -relief -takefocus -text -textvariable -underline -wraplength

Voir Tk::options pour les détails des options standards.

OPTIONS SPÉCIFIQUES AU WIDGET

Nom : command
Classe : Command
Commutateur : -command
Spécifie un callback perl/Tk à associer au bouton. Cette commande est typiquement invoquée lorsque le bouton de la souris 1 est relâché sur la fenêtre du bouton. La variable globale du bouton (option -variable) sera mise à jour avant l'invocation de la commande.
Nom : height
Classe : Height
Commutateur : -height
Spécifie une hauteur désirée pour le bouton. Si une image ou un bitmap est affiché(e) dans le bouton, la valeur est en unités d'écran (c'est-à-dire toute forme acceptable par Tk_GetPixels) ; pour le texte, elle est en lignes de texte. Si cette option n'est pas spécifiée, la hauteur désirée du bouton est calculée à partir de la taille de l'image ou du bitmap ou du texte qui y est affiché.
Nom : indicatorOn
Classe : IndicatorOn
Commutateur : -indicatoron
Spécifie si l'indicateur doit être dessiné ou non. Doit être une valeur booléenne valide. Si faux, l'option relief est ignorée et le relief du widget est toujours enfoncé si le widget est sélectionné et relevé sinon.
Nom de ligne de commande : -offrelief
Nom de base de données : offRelief
Classe de base de données : OffRelief
Spécifie le relief pour le bouton de coche lorsque l'indicateur n'est pas dessiné et que le bouton de coche est désactivé. La valeur par défaut est raised. En définissant cette option sur flat et en définissant -indicatoron false -overrelief raised, on obtient l'effet d'avoir un bouton plat qui se relève au survol de la souris et qui est enfoncé lorsqu'il est activé. C'est le comportement typiquement présenté par les boutons de coche Gras, Italique et Souligné sur la barre d'outils d'un traitement de texte, par exemple.
Nom : offValue
Classe : Value
Commutateur : -offvalue
Spécifie la valeur à stocker dans la variable associée au bouton lorsque ce bouton est désélectionné. Par défaut, c'est ``0''.
Nom : onValue
Classe : Value
Commutateur : -onvalue
Spécifie la valeur à stocker dans la variable associée au bouton lorsque ce bouton est sélectionné. Par défaut, c'est ``1''.
Nom de ligne de commande : -overrelief
Nom de base de données : overRelief
Classe de base de données : OverRelief
Spécifie un relief alternatif pour le bouton, à utiliser lorsque le curseur de la souris est sur le widget. Cette option peut être utilisée pour créer des boutons de barre d'outils, en configurant -relief flat -overrelief raised. Si la valeur de cette option est une chaîne vide, alors aucun relief alternatif n'est utilisé lorsque le curseur de la souris est sur le bouton. La chaîne vide est la valeur par défaut.
Nom : selectColor
Classe : Background
Commutateur : -selectcolor
Spécifie une couleur de fond à utiliser lorsque le bouton est sélectionné. Si indicatorOn est vrai, la couleur s'applique à l'indicateur. Sous Windows, cette couleur est utilisée comme arrière-plan de l'indicateur, quel que soit l'état de sélection. Si indicatorOn est faux, cette couleur est utilisée comme arrière-plan de l'ensemble du widget, à la place de background ou activeBackground, chaque fois que le widget est sélectionné. Si spécifié comme une chaîne vide, aucune couleur spéciale n'est utilisée pour l'affichage lorsque le widget est sélectionné.
Nom : selectImage
Classe : SelectImage
Commutateur : -selectimage
Spécifie une image à afficher (à la place de l'option image) lorsque le bouton de coche est sélectionné. Cette option est ignorée sauf si l'option image a été spécifiée.
Nom : state
Classe : State
Commutateur : -state
Spécifie l'un des trois états du bouton de coche : normal, active ou disabled. En état normal, le bouton de coche est affiché en utilisant les options foreground et background. L'état actif est typiquement utilisé lorsque le pointeur se trouve sur le bouton de coche. En état actif, le bouton de coche est affiché en utilisant les options activeForeground et activeBackground. L'état désactivé signifie que le bouton de coche doit être insensible : les liaisons par défaut refuseront d'activer le widget et ignoreront les clics de bouton de souris. Dans cet état, les options disabledForeground et background déterminent comment le bouton de coche est affiché.
Nom : variable
Classe : Variable
Commutateur : -variable
Spécifie une référence à une variable à définir pour indiquer si ce bouton est sélectionné ou non. Par défaut, il s'agit du membre "$widget->{'Value'}" du hash du widget. En général, les variables perl sont "undef" à moins d'être initialisées spécifiquement, ce qui ne correspondra à ni à la valeur par défaut -onvalue ni à la valeur par défaut -offvalue.
Nom : width
Classe : Width
Commutateur : -width
Spécifie une largeur désirée pour le bouton. Si une image ou un bitmap est affiché(e) dans le bouton, la valeur est en unités d'écran (c'est-à-dire toute forme acceptable par Tk_GetPixels) ; pour le texte, elle est en caractères. Si cette option n'est pas spécifiée, la largeur désirée du bouton est calculée à partir de la taille de l'image ou du bitmap ou du texte qui y est affiché.

Tk::Checkbutton(3pm) — Checkbutton widget

NOM

Tk::Checkbutton — crée un widget bouton-à-cocher

SYNOPIS

    use Tk;
    use Tk::widgets qw(Checkbutton);

    my $checkbutton = $parent->Checkbutton(
        -command     => \&callback,
        -text        => "Click Me",
        -variable    => \$var,
        -onvalue     => 1,
        -offvalue    => 0,
        %options
    );
    $checkbutton->pack();

OPTIONS

Le widget Checkbutton prend en charge les options standards suivantes :

-activebackground, -bg, -bd, -font, -foreground, -height, -highlightbackground, -highlightcolor, -highlightthickness, -image, -justify, -orient, -relief, -takefocus, -textvariable, -underline, -width
Voir la page de manuel Tk::options pour la description de ces options standard. Les options spécifiques aux boutons :
-activeforeground
La couleur du texte (ou de l'image) lorsque le bouton est actif (par exemple, lorsque le curseur de la souris se trouve dessus). Si cette option n'est pas définie, la couleur du texte actif sera la même que la couleur du texte lorsque le bouton est dans son état normal.
-command
Spécifie une procédure à appeler lorsque le bouton est activé. La procédure est appelée avec la nouvelle valeur du bouton comme unique argument.
-disabledforeground
Couleur pour le texte lorsque le bouton est désactivé. Si cette option n'est pas définie, l'affichage par défaut sera utilisé.
-image
Spécifie une image à afficher à la place du texte. Les images peuvent être créées avec Tk::Bitmap ou Tk::Photo. Si cette option est utilisée, les options -text et -font sont ignorées.
-insertbackground, -insertborderwidth, -insertofftime, -insertontime, -insertwidth
Ces options contrôlent l'apparence et le comportement du curseur d'insertion qui peut apparaître dans l'indicateur des boutons à cocher sur certains systèmes.
-offvalue
La valeur qui sera stockée dans la variable associée au bouton lorsque le bouton est désélectionné. La valeur par défaut est 0.
-onvalue
La valeur qui sera stockée dans la variable associée au bouton lorsque le bouton est sélectionné. La valeur par défaut est 1.
-selectcolor
La couleur à utiliser pour le fond de l'indicateur du bouton à cocher lorsqu'il est sélectionné. L'option -bg est utilisée pour le fond lorsqu'il n'est pas sélectionné.
-selectimage
Similaire à -image, mais cette image est utilisée lorsque le bouton est sélectionné. L'option -image est utilisée lorsqu'il n'est pas sélectionné.
-state
Spécifie si le bouton doit être normal, active ou disabled. Par défaut, il est normal.
-subarray
Identique à l'option -subarray de Tk::Radiobutton.
-text
Chaîne de caractères à afficher sur le bouton. Si l'option -image est utilisée, cette option est ignorée.
-tickinterval
Indique la fréquence de clignotement du bouton. Si cette option est définie, le bouton clignotera lorsque la souris passe dessus.
-underline
L'index (base 0) d'un caractère dans le texte de l'option -text qui doit être souligné. Ce caractère deviendra un raccourci clavier : lorsque le bouton a le focus, appuyer sur ce caractère le déclenchera.
-variable
Le nom d'une variable Tcl (par exemple, \$var) qui sera associée au bouton à cocher. Lorsque le bouton est sélectionné, sa valeur est définie sur -onvalue ; lorsqu'il est désélectionné, sa valeur est définie sur -offvalue. Si cette option n'est pas spécifiée, une variable sera créée automatiquement.
-when
Identique à l'option -when de Tk::Radiobutton.

Les options suivantes sont spécifiques à l'apparence du widget bouton à cocher :

-indicatoron
Si vrai (la valeur par défaut), un indicateur carré sera dessiné à gauche du texte. Si faux, aucun indicateur ne sera dessiné.
-offrelief
Le style de relief à utiliser lorsque le bouton n'est pas sélectionné. Peut être raised (par défaut), sunken, flat, ridge, solid, ou groove.
-selectrelief
Le style de relief à utiliser lorsque le bouton est sélectionné. Par défaut, il est identique à -offrelief.

Le widget Checkbutton prend également en charge toutes les options de configuration du widget Button.

DESCRIPTION

Un bouton à cocher est un widget qui affiche une chaîne de caractères, un bitmap ou une image, ainsi qu'un indicateur carré. L'indicateur peut être affiché ou non, en fonction de l'option -indicatoron. Le bouton à cocher se comporte comme un bouton simple, c'est-à-dire qu'il peut changer d'apparence en fonction de son état (normal, actif, désactivé) et qu'il invoque une procédure de rappel lorsque l'on clique dessus avec le bouton principal de la souris.

En plus de ces comportements, un bouton à cocher peut être sélectionné ou désélectionné. Lorsqu'il est sélectionné, l'indicateur prend une apparence spécifique (par exemple, une coche sous Windows, un relief enfoncé sous Unix) et une variable Tcl associée est définie sur la valeur spécifiée par l'option -onvalue. Lorsqu'il est désélectionné, l'indicateur prend une apparence désélectionnée et la variable est définie sur la valeur de l'option -offvalue.

La variable associée est spécifiée par l'option -variable. Si cette option n'est pas fournie, une variable Tcl sera créée portant le même nom que le widget lui-même. Le comportement par défaut fait que le bouton à cocher se sélectionne et se désélectionne à chaque clic de souris. De plus, le bouton à cocher surveille sa variable associée et se met à jour automatiquement lorsque la valeur de cette variable change pour correspondre à -onvalue ou -offvalue.

MÉTHODES DU WIDGET

La méthode Checkbutton crée un objet widget. Cet objet prend en charge les méthodes configure et cget décrites dans Tk::options, qui permettent de consulter et modifier les options décrites ci-dessus. Le widget hérite également de toutes les méthodes fournies par la classe générique Tk::Widget.

Les méthodes supplémentaires suivantes sont disponibles pour les widgets bouton à cocher :

$bouton_a_cocher->deselect
Désélectionne le bouton à cocher et définit la variable associée sur sa valeur « off ».
$bouton_a_cocher->flash
Fait clignoter le bouton à cocher. Cela est réalisé en redessinant le bouton à plusieurs reprises, en alternant entre les couleurs active et normale. À la fin du clignotement, le bouton reste dans le même état normal/actif qu'au moment où la commande a été invoquée. Cette commande est ignorée si l'état du bouton à cocher est disabled.
$bouton_a_cocher->invoke
Fait exactement ce qui se passerait si l'utilisateur invoquait le bouton à cocher avec la souris : bascule l'état de sélection du bouton et appelle la procédure de rappel perl/Tk associée au bouton à cocher, s'il y en a une. La valeur de retour est la valeur de retour de la procédure de rappel perl/Tk, ou une chaîne vide s'il n'y a pas de commande associée au bouton à cocher. Cette commande est ignorée si l'état du bouton à cocher est disabled.
$bouton_a_cocher->select
Sélectionne le bouton à cocher et définit la variable associée sur sa valeur « on ».
$bouton_a_cocher->toggle
Bascule l'état de sélection du bouton, le redessine et modifie sa variable associée pour refléter le nouvel état.

LIAISONS

Tk crée automatiquement des liaisons de classe pour les boutons à cocher qui leur donnent le comportement par défaut suivant :

[1]
Sur les systèmes Unix, un bouton à cocher s'active lorsque la souris passe dessus et se désactive lorsque la souris quitte le bouton à cocher. Sur les systèmes Mac et Windows, lorsque le bouton 1 de la souris est enfoncé sur un bouton à cocher, le bouton s'active lorsque le pointeur de la souris se trouve à l'intérieur du bouton, et se désactive lorsque le pointeur de la souris quitte le bouton.
[2]
Lorsque le bouton 1 de la souris est enfoncé sur un bouton à cocher, il est invoqué (son état de sélection est basculé et la commande associée au bouton est appelée, s'il y en a une).
[3]
Lorsqu'un bouton à cocher a le focus d'entrée, la touche espace provoque l'invocation du bouton à cocher. Sous Windows, il existe des liaisons clavier supplémentaires ; plus (+) et égal (=) sélectionnent le bouton, et moins (-) désélectionnent le bouton.

Si l'état du bouton à cocher est disabled, aucune des actions ci-dessus ne se produit : le bouton à cocher est complètement non réactif.

Le comportement des boutons à cocher peut être modifié en définissant de nouvelles liaisons pour des widgets individuels ou en redéfinissant les liaisons de classe.
