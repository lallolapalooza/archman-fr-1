Tk_Main(3) Procédures de la bibliothèque Tk Tk_Main(3)

NOM

Tk_Main - programme principal pour les applications basées sur Tk

SYNTAXE

#include <tk.h>

Tk_Main(argc, argv, appInitProc)

ARGUMENTS

int argc (entrée)
Nombre d'éléments dans argv.
char *argv[] (entrée)
Tableau de chaînes contenant les arguments de la ligne de commande. Sous Windows, lorsque vous utilisez -DUNICODE, le type du paramètre change en wchar_t *.
Tcl_AppInitProc *appInitProc (entrée)
Adresse d'une procédure d'initialisation spécifique à l'application. La valeur de cet argument est généralement Tcl_AppInit.

DESCRIPTION

Tk_Main agit comme le programme principal pour la plupart des applications basées sur Tk. À partir de Tk 4.0, elle n'est plus appelée main car elle fait partie de la bibliothèque Tk et avoir une fonction main dans une bibliothèque (en particulier une bibliothèque partagée) pose des problèmes sur de nombreux systèmes. Avoir main dans la bibliothèque Tk rendrait également difficile l'utilisation de Tk dans des programmes C++, car les programmes C++ doivent avoir des fonctions main C++ spéciales.

Normalement, chaque application contient une petite fonction main qui ne fait rien d'autre qu'invoquer Tk_Main. Tk_Main effectue alors tout le travail de création et d'exécution d'une application de type wish.

Lorsqu'elle a terminé sa propre initialisation, mais avant de traiter les commandes, Tk_Main appelle la procédure fournie par l'argument appInitProc. Cette procédure fournit un « crochet » pour que l'application effectue sa propre initialisation, comme la définition de commandes spécifiques à l'application. La procédure doit avoir une interface correspondant au type Tcl_AppInitProc :

typedef int Tcl_AppInitProc(
        Tcl_Interp *interp);
AppInitProc est presque toujours un pointeur vers Tcl_AppInit ; pour plus de détails sur cette procédure, voir la documentation de Tcl_AppInit.

Tk_Main fonctionne de manière très similaire à Tcl_Main. En particulier, Tk_Main prend en charge à la fois un mode interactif et un mode script de démarrage, le nom de fichier et l'encodage d'un script de démarrage étant contrôlés par les routines Tcl_SetStartupScript et Tcl_GetStartupScript. Cependant, elle appelle Tk_MainLoop après avoir traité tout script fourni, et en mode interactif, elle utilise les événements enregistrés avec Tcl_CreateFileHandler pour traiter les entrées utilisateur.
