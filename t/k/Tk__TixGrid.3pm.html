NOM

Tk::TixGrid - Créer et manipuler des widgets Tix Grid

SYNTAXE

    $tixgrid = $parent->TixGrid?(options)?;

DESCRIPTION

Ce widget est destiné à servir de base aux interfaces de type "tableur". Le widget affiche son contenu dans une grille bidimensionnelle de cellules. Chaque cellule peut contenir un élément d'affichage Tix, qui peut être sous forme de texte, de graphiques ou d'autres formats. Voir Tk::DItem pour plus d'informations sur les éléments d'affichage Tix. Comme ces "éléments" ne sont pas nécessairement des "fenêtres", de grandes grilles peuvent être traitées sans consommer des ressources excessives du système d'affichage.

Les cellules individuelles, ou les groupes de cellules, peuvent être formatées avec un large éventail d'attributs, tels que leur couleur, leur relief et leur bordure. Cependant, comme le widget est destiné à gérer de grandes grilles, les mécanismes pour y parvenir sont de bas niveau et plus orientés vers les appels de rappel que pour d'autres widgets. L'hypothèse est que, pour éviter de stocker les détails d'affichage d'un grand nombre de cellules, les données seront recalculées au besoin.

Le portage du code C de Tix et une partie des liaisons vers perl/Tk sont faits mais nécessitent encore un travail supplémentaire. Dans plusieurs endroits, l'intention du code Tix n'est pas encore comprise. Par exemple, l'interface d'édition est clairement destinée à l'édition du contenu des cellules de type tableur dans un widget "d'entrée" auxiliaire ou similaire, mais comment cela devrait fonctionner n'est pas encore clair.

La méthode TixGrid crée une nouvelle fenêtre TixGrid et retourne une référence bénie de ce widget TixGrid. Des options supplémentaires, décrites ci-dessous, peuvent être spécifiées en ligne de commande ou dans la base de données d'options pour configurer des aspects du widget TixGrid.

OPTIONS STANDARD

-background -borderwidth -cursor -font -foreground -height -highlightbackground -highlightcolor -highlightthickness -padx -pady -relief -selectbackground -selectborderwidth -selectforeground -state -takefocus -width -xscrollcommand -yscrollcommand

Voir Tk::options pour les détails des options standard.

Classe : BrowseCmd
Commutateur : -browsecmd
Si défini, fournit un rappel perl/Tk à exécuter lorsque l'utilisateur parcourt une cellule de la grille (C'est normalement le cas lorsque l'utilisateur clique sur une entrée). Lorsque ce rappel est appelé, il est passé avec deux paramètres supplémentaires : x y, où (x,y) est la position de la cellule qui vient d'être cliquée.
Nom : Command
Classe : Command

Nom : editNotifyCmd
Classe : EditNotifyCmd
Commutateur : -editnotifycmd
Si défini, fournit un rappel perl/Tk à exécuter lorsque l'utilisateur tente d'éditer une cellule de la grille. Lorsque ce rappel est appelé, il est passé avec deux paramètres supplémentaires : x y, où (x,y) est la position de la cellule. Ce rappel doit retourner une valeur booléenne : vrai indique que la cellule est éditable et faux sinon.

Classe : FormatCmd
Commutateur : -formatcmd
Si défini, fournit un rappel perl/Tk à exécuter lorsque les cellules de la grille doivent être affichées à l'écran. Son objectif principal est de dessiner l'arrière-plan de la région avant que les cellules ne soient rendues par-dessus. Ceci est normalement réalisé en appelant formatGrid ou formatBorder (voir ci-dessous). Cependant, d'autres utilisations peuvent être faites de ce rappel de bas niveau. Par exemple, il peut être utilisé pour remplir la grille de manière "paresseuse" en appelant la méthode set uniquement lorsque les cellules entrent dans le champ de vision.

main
Le corps principal, c'est-à-dire toutes les cellules qui n'appartiennent pas aux trois types ci-dessus.

MÉTHODES DU WIDGET

La méthode TixGrid crée un widget TixGrid et retourne une référence baptisée de ce widget TixGrid. Cette référence peut être utilisée pour invoquer diverses opérations sur le widget. Elle a la forme générale suivante :

    $tixgrid->méthode?(arg, arg, ...)?

Les args déterminent le comportement exact de la méthode.

Cet objet prend en charge les méthodes configure et cget décrites dans Tk::options, qui peuvent être utilisées pour interroger et modifier les options décrites ci-dessus. Le widget hérite également de toutes les méthodes fournies par la classe générique Tk::Widget.

Les méthodes supplémentaires suivantes sont possibles pour les widgets TixGrid :

$tixgrid->anchorGet(x, y)
$tixgrid->anchorSet(x, y)
$tixgrid->anchorClear
Manipule la cellule d'ancrage du widget TixGrid. La cellule d'ancrage est l'extrémité de la sélection qui est fixe pendant que l'utilisateur étire une sélection avec la souris.
($bd,$col,$row) = $tixgrid->bdtype(x,y ?,xDelta,yDelta?)
Détermine si la position écran (pixel) x,y se trouve dans une bordure. Ceci est utile pour changer le curseur de la souris lorsque l'utilisateur pointe vers une bordure - par exemple, pour indiquer que la bordure peut être ajustée interactivement.

Si elle se trouve dans une bordure, retourne une liste de trois éléments. Le premier élément est 'xy', 'x' ou 'y', les deux éléments suivants sont des entiers. (La valeur de ceux-ci n'est pas comprise, semble indiquer à quelle colonne et quelle ligne de la bordure correspond la position de l'écran ?)

Si elle ne se trouve pas dans une bordure, retourne une liste vide.

$tixgrid->delete(dim, from?, to?)
$tixgrid->deleteColumn(from?, to?)
$tixgrid->deleteRow(from?, to?)
Dim peut être row ou column. Si to n'est pas donné, supprime une seule ligne (ou colonne) à la position from. Si to est donné, supprime la plage de lignes (ou de colonnes) de la position from à to inclus.
$tixgrid->dragsite(option, x, y)
$tixgrid->dropsite(option, x, y)
Tcl/Tix a (ou allait avoir) un support Drag&Drop. La signification pour perl/Tk n'est pas encore claire.
$tixgrid->editApply
Si une cellule est en cours d'édition, désélectionne la cellule et applique les modifications.
$tixgrid->editSet(x, y)
Met en surbrillance la cellule à (x,y) pour l'édition, si la fonction de rappel -editnotify retourne vrai pour cette cellule.
$tixgrid->entrycget(x, y, '-option')
$tixgrid->entryconfigure(x, y?, -option??=>value, -option=>value, ...?)
Fournit une interface de configuration aux cellules de la grille. Les -options dépendent du type d'élément de la cellule.
$tixgrid->formatBorder(x1,y1, x2,y2, options);
$tixgrid->formatGrid(x1,y1, x2,y2, options);
Les méthodes formatBorder et formatGrid ne peuvent être appelées que par la fonction de rappel -formatcmd du widget tixGrid. Elles dessinent l'arrière-plan de la région décrite par x1,y1, x2,y2 selon les options fournies. Un appel à la fonction de rappel -formatcmd peut effectuer plusieurs appels à formatBorder et/ou formatGrid pour différentes sous-régions.

formatBorder dessine l'arrière-plan en utilisant le style de relief Tk, formatGrid dessine également des lignes de grille entre les cellules. Il est seulement logique d'appeler l'une ou l'autre pour une sous-région donnée, car l'une écrasera l'autre.

Les options autorisées sont :

-background / -bg
-borderwidth / -bd
-filled
-relief
-selectbackground
-xoff
-xon
-yoff
-yon

Les options -xon/-xoff et -yon/-yoff sont obscures. Si quelqu'un peut trouver comment faire quelque chose d'intéressant étant donné ce que pTk/tixGrFmt.c en fait, qu'il le fasse savoir à Nick !.

$tixgrid->geometryinfo(?width, height?)
Retourne une liste de quatre valeurs - deux ensembles de deux nombres à virgule flottante. Le premier ensemble représente les fractions de défilement pour la direction x, le second ensemble représente les fractions de défilement pour la direction y. Si width et height sont spécifiés, les fractions sont basées comme si la fenêtre avait la taille spécifiée (en pixels, mais sans autoriser les unités normales de GetPixels). Sinon, les fractions sont basées sur la taille actuelle de la fenêtre.

Utilisation obscure.

$tixgrid->index(xcoord, ycoord)
Retourne (x, y) de l'entrée à la position ($coordx, $coordy). L'une ou l'autre coordonnée peut être 'max', qui correspond à la plus grande entrée existante dans cette direction, 'end', qui correspond à un au-delà de la plus grande entrée existante, ou un nombre. (C'est ainsi que l'on découvre la taille de la grille.)
$tixgrid->infoBbox(x,y)
Retourne la boîte englobante en pixels de la cellule à x,y.
$tixgrid->infoExists(x,y)
Retourne vrai s'il y a un élément dans la cellule à x,y. Lève une exception (s'arrête) si x,y est en dehors de la grille - cela pourrait changer (Nick n'aime pas ça).
$tixgrid->move(dim, from, to, offset)
$tixgrid->moveColumn(from, to, offset)
$tixgrid->moveRow(from, to, offset)
Dim peut être row ou column. Déplace la plage de lignes (ou de colonnes) de la position from à to par la distance indiquée par offset. Par exemple, $tixgrid->moveRow(2, 4, 1) déplace les lignes 2,3,4 vers les lignes 3,4,5.
$tixgrid->nearest(x, y)
Traduction de la position écran (pixels) vers l'entrée (nx,ny).
$tixgrid->selectionAdjust(x1, y1 ?,x2, y2?)
$tixgrid->selectionClear(x1, y1 ?,x2, y2?)
$tixgrid->selectionIncludes(x1, y1 ?,x2, y2?)
$tixgrid->selectionSet(x1, y1 ?,x2, y2?)
$tixgrid->selectionToggle(x1, y1 ?,x2, y2?)
Méthodes de support de sélection - probablement buggées.

x1 (y1) ne doit pas être supérieur à x2 (y2), mais seuls x2 et y2 peuvent être 'max'.

BUG : selectionIncludes : n'a aucun effet visible (comme dans Tix). Hein ???

BUG : selectionClear : ne fonctionne que pour 0, 0, max, max (comme dans Tix). Hein ???

Lorsque x2, y2 ne sont pas donnés, ils prennent par défaut x1, y1 respectivement.

$tixgrid->set(x, y?, -itemtype=>type??, -option=>value, ...?)
Crée un nouvel élément d'affichage dans la cellule à (x,y). Le paramètre facultatif -itemtype donne le type de l'élément d'affichage. Une liste supplémentaire de paires option-valeur spécifie les options de l'élément d'affichage. Si un élément d'affichage existe déjà dans cette cellule, l'ancien élément sera automatiquement supprimé.
$tixgrid->size(dim, index?, -option??=>value, ...?)
$tixgrid->sizeColumn(index?, -option??=>value, ...?)
$tixgrid->sizeRow(index?, -option??=>value, ...?)
Interroge ou définit la taille de la ligne ou de la colonne donnée par dim et index. Dim peut être row ou column. Index peut être tout entier non négatif qui donne la position d'une ligne (ou colonne) donnée. Index peut aussi être la chaîne default ; dans ce cas, cette méthode interroge ou définit la valeur par défaut

NAME

Tk::TixGrid - a widget that displays data in a grid format

SYNOPSIS

use Tk;
use Tk::TixGrid;

my $grid = $mainwindow->Scrolled(qw/TixGrid/);
$grid->pack(-fill => 'both', -expand => 1);

# ... configure grid options and add items ...

DESCRIPTION

The TixGrid widget provides a convenient way to display data in a grid format, similar to a spreadsheet. It supports features like scrolling, cell spanning, and item configuration.

STANDARD OPTIONS

The TixGrid widget supports the standard Tk widget options such as -background, -borderwidth, -cursor, -font, -foreground, -height, -highlight color, -highlightthickness, -padx, -pady, -relief, -takefocus, and -width.

WIDGET-SPECIFIC OPTIONS

The TixGrid widget also supports the following options:

-color0 => color
Specifies the background color for cells that are not explicitly configured.
-color1 => color
Specifies the background color for alternating rows.
-cursor => cursorName
Specifies the cursor to be displayed when the mouse pointer is over the widget.
-itemcreate => script
Specifies a script to be executed when a new item is created in the grid.
-itemdelete => script
Specifies a script to be executed when an item is deleted from the grid.
-itemmenu => menuName
Specifies a menu to be displayed when an item is right-clicked.
-selectmode => mode
Specifies the selection mode. Can be browse, extended, or none.
-showcellorigins => boolean
If set to true, displays cell origin indicators (e.g., row and column headers).

WIDGET METHODS

The TixGrid widget provides the following methods:

$tixgrid->cell(x, y, ?option-value ...?)
Returns or modifies the options for the cell at the specified coordinates (x, y).
$tixgrid->colwidth(col, ?option-value ...?)
Returns or modifies the width of the specified column. If no option-value pair is given, this method returns the current size setting of the given column. When option-value pairs are given, the corresponding options of the size setting of the given column are changed. -option may be one of the following:
-pad0 => pixels
Specifies the padding to the left of a column.
-pad1 => pixels
Specifies the padding to the right of a column.
-size => val
Specifies the width of a column. Val may be: auto -- the width of the column is set to the widest cell in the column; a valid Tk screen distance unit (see Tk_GetPixels); or a real number followed by the word chars (e.g. 3.4chars) that sets the width of the column to the given number of characters.
$tixgrid->rowheight(row, ?option-value ...?)
Returns or modifies the height of the specified row. If no option-value pair is given, this method returns the current size setting of the given row. When option-value pairs are given, the corresponding options of the size setting of the given row are changed. -option may be one of the following:
-pad0 => pixels
Specifies the padding to the top of a row.
-pad1 => pixels
Specifies the padding to the bottom of a row.
-size => val
Specifies the height of a row. Val may be: auto -- the height of the row is set to the tallest cell in the row; a valid Tk screen distance unit (see Tk_GetPixels); or a real number followed by the word chars (e.g. 3.4chars) that sets the height of the row to the given number of characters.
$tixgrid->sort(dimension, start, end, ?args ...?)
?docu here? (not supported on Win* OSs up to now)
$tixgrid->unset(x, y)
Clears the cell at (x,y) by removing its display item.
$tixgrid->xview
Normal horizontal scrollbar method.
$tixgrid->yview
Normal vertical scrollbar method.
