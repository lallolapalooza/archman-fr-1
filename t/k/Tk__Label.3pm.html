NOM

Tk::Label - Créer et manipuler des widgets Label

SYNOPIS

$label = $parent->Label(?options?);

OPTIONS STANDARDS

-activebackground -activeforeground -anchor -background -bitmap -borderwidth -compound -cursor -disabledforeground -font -foreground -highlightbackground -highlightcolor -highlightthickness -image -justify -padx -pady -relief -takefocus -text -textvariable -underline -wraplength

Voir Tk::options pour les détails des options standards.

OPTIONS SPECIFIQUES AU WIDGET

Nom: height
Classe: Height
Commutateur: -height
Spécifie une hauteur désirée pour le label. Si une image ou un bitmap est affiché dans le label, la valeur est en unités d'écran (c'est-à-dire toute forme acceptable par Tk_GetPixels); pour du texte, c'est en lignes de texte. Si cette option n'est pas spécifiée, la hauteur désirée du label est calculée à partir de la taille de l'image ou du bitmap ou du texte qui y est affiché.
Nom: state
Classe: State
Commutateur: -state
Spécifie l'un des trois états pour le label : normal, active, ou disabled. En état normal, le label est affiché en utilisant les options foreground et background. En état actif, le label est affiché en utilisant les options activeForeground et activeBackground. En état désactivé, les options disabledForeground et background déterminent comment le bouton est affiché.
Nom: width
Classe: Width
Commutateur: -width
Spécifie une largeur désirée pour le label. Si une image ou un bitmap est affiché dans le label, la valeur est en unités d'écran (c'est-à-dire toute forme acceptable par Tk_GetPixels); pour du texte, c'est en caractères. Si cette option n'est pas spécifiée, la largeur désirée du label est calculée à partir de la taille de l'image ou du bitmap ou du texte qui y est affiché.

DESCRIPTION

La méthode Label crée une nouvelle fenêtre (donnée par l'argument $widget) et en fait un widget label. Des options supplémentaires, décrites ci-dessus, peuvent être spécifiées sur la ligne de commande ou dans la base de données d'options pour configurer des aspects du label tels que ses couleurs, sa police, son texte et son relief initial. La commande label retourne son argument $widget. Au moment où cette commande est invoquée, aucune fenêtre nommée $widget ne doit exister, mais le parent de $widget doit exister.

Un label est un widget qui affiche une chaîne de caractères textuelle, un bitmap ou une image. Si du texte est affiché, il doit être entièrement dans une seule police, mais il peut occuper plusieurs lignes à l'écran (s'il contient des sauts de ligne ou s'il y a un retour à la ligne dû à l'option wrapLength) et l'un des caractères peut éventuellement être souligné en utilisant l'option underline. Le label peut être manipulé de quelques manières simples, comme changer son relief ou son texte, en utilisant les commandes décrites ci-dessous.

MÉTHODES DU WIDGET

La méthode Label crée un objet widget. Cet objet supporte les méthodes configure et cget décrites dans Tk::options qui peuvent être utilisées pour interroger et modifier les options décrites ci-dessus. Le widget hérite également de toutes les méthodes fournies par la classe générique Tk::Widget.

LIAISONS

Lors de la création d'un nouveau label, il n'a pas de liaisons d'événements par défaut : les labels ne sont pas destinés à être interactifs.
