NOM

Tk::WinPhoto - Charger une image Photo depuis une fenêtre

SYNTAXE

use Tk;
use Tk::WinPhoto;
my $image = $mw->Photo(-format => 'Window', -data => oct($mw->id));
$image->write($path_name, -format => 'BMP|PPM|XPM');

DESCRIPTION

Ceci est une extension pour Tk800.* qui chargera une image Photo à partir d'une capture d'écran d'une fenêtre X spécifiée par l'option -data.

La fenêtre doit exister et être visible. Comme le code vous permet de capturer des fenêtres qui n'appartiennent pas à Tk, il n'essaie pas de l'imposer. Si vous capturez l'une des fenêtres de Tk, utilisez "$w->update".

Si la fenêtre est mappée, mais obscurcie par d'autres fenêtres, ce qui est capturé est le rectangle qu'occuperait la fenêtre. Cela peut être considéré comme une fonctionnalité. Pour les fenêtres appartenant à Tk, "$w->raise" peut être utilisé pour amener la fenêtre au premier plan.

Une fois la Photo chargée, elle peut être enregistrée en utilisant "$image->write(-format => ...)" en utilisant l'un des formats qui supportent l'écriture.
