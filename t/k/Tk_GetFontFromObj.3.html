Tk_AllocFontFromObj(3) Procédures de la bibliothèque Tk Tk_AllocFontFromObj(3)

NOM

Tk_AllocFontFromObj, Tk_GetFont, Tk_GetFontFromObj, Tk_NameOfFont, Tk_FreeFontFromObj, Tk_FreeFont - maintenir la base de données des polices

SYNOPIS

#include <tk.h>

Tk_Font
Tk_AllocFontFromObj(interp, tkwin, objPtr)

Tk_Font
Tk_GetFont(interp, tkwin, string)

Tk_Font
Tk_GetFontFromObj(tkwin, objPtr)

const char *
Tk_NameOfFont(tkfont)

Tk_Font
Tk_FreeFontFromObj(tkwin, objPtr)

void
Tk_FreeFont(tkfont)

ARGUMENTS

Tcl_Interp *interp (in)
Interpréteur à utiliser pour le rapport d'erreurs. Si NULL, alors aucun message d'erreur n'est laissé après les erreurs.
Tk_Window tkwin (in)
Jeton de la fenêtre dans laquelle la police sera utilisée.
Tcl_Obj *objPtr (in/out)
Donne le nom ou la description de la police. Voir la documentation de la commande font pour les détails sur les formats acceptables. La représentation interne sera modifiée pour mettre en cache la Tk_Font correspondante.
const char *string (in)
Identique à objPtr sauf que la description de la police est passée sous forme de chaîne de caractères et que la Tk_Font résultante n'est pas mise en cache.
Tk_Font tkfont (in)
Jeton opaque de police.

DESCRIPTION

Tk_AllocFontFromObj trouve la police indiquée par objPtr et renvoie un jeton qui représente la police. La valeur de retour peut être utilisée dans des appels ultérieurs à des procédures telles que Tk_GetFontMetrics, Tk_MeasureChars et Tk_FreeFont. Le jeton Tk_Font restera valide jusqu'à ce que Tk_FreeFontFromObj ou Tk_FreeFont soit appelé pour le libérer. ObjPtr peut contenir un nom symbolique ou une description de police ; voir la documentation de la commande font pour une description des formats valides. Si Tk_AllocFontFromObj échoue (parce que, par exemple, objPtr ne contenait pas une spécification de police valide), elle renvoie NULL et laisse un message d'erreur dans le résultat de interp si interp n'est pas NULL. Tk_AllocFontFromObj met en cache les informations sur la valeur de retour dans objPtr, ce qui accélère les appels futurs à des procédures telles que Tk_AllocFontFromObj et Tk_GetFontFromObj.

Tk_GetFont est identique à Tk_AllocFontFromObj sauf que la description de la police est spécifiée avec une chaîne de caractères au lieu d'un objet. Cela empêche Tk_GetFont de mettre en cache la Tk_Font correspondante, donc Tk_GetFont est moins efficace que Tk_AllocFontFromObj.

Tk_GetFontFromObj renvoie le jeton d'une police existante, étant donné la fenêtre et la description utilisées pour créer la police. Tk_GetFontFromObj ne crée pas réellement la police ; la police doit avoir déjà été créée avec un appel précédent à Tk_AllocFontFromObj ou Tk_GetFont. La valeur de retour est mise en cache dans objPtr, ce qui accélère les appels futurs à Tk_GetFontFromObj avec le même objPtr et tkwin.

Tk_AllocFontFromObj et Tk_GetFont maintiennent une base de données de toutes les polices qu'elles ont allouées. Si la même police est demandée plusieurs fois (par exemple, par différentes fenêtres ou à des fins différentes), alors une seule Tk_Font sera partagée pour toutes les utilisations. Les ressources sous-jacentes seront libérées automatiquement lorsqu'elles ne seront plus utilisées par personne.

La procédure Tk_NameOfFont est à peu près l'inverse de Tk_GetFont. Étant donné une tkfont qui a été créée par Tk_GetFont (ou Tk_AllocFontFromObj), la valeur de retour est l'argument string qui a été passé à Tk_GetFont pour créer la police. La chaîne de caractères renvoyée par Tk_NameOfFont n'est garantie de persister que jusqu'à ce que la tkfont soit supprimée. L'appelant ne doit pas modifier cette chaîne de caractères.

Lorsqu'une police n'est plus nécessaire, Tk_FreeFontFromObj ou Tk_FreeFont doit être appelée pour la libérer. Pour Tk_FreeFontFromObj, la police à libérer est spécifiée avec les mêmes informations que celles utilisées pour la créer ; pour Tk_FreeFont, la police à libérer est spécifiée avec son jeton Tk_Font. Il doit y avoir exactement un appel à Tk_FreeFontFromObj ou Tk_FreeFont pour chaque appel à Tk_AllocFontFromObj ou Tk_GetFont.
