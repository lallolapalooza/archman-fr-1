NOM

Tk::InputO - Créer et manipuler les widgets TIX InputO

SYNTAXE

$inputonly = $parent->InputO(?options?);

OPTIONS STANDARD

Seules les trois options standard suivantes sont supportées par InputO:

cursor width height

Voir Tk::options pour les détails des options standard.

OPTIONS SPÉCIFIQUES AU WIDGET

InputO n'a pas d'options spécifiques au widget.

DESCRIPTION

La méthode InputO crée une nouvelle fenêtre (fournie par l'argument $widget) et en fait un widget InputO. Des options supplémentaires, décrites ci-dessus, peuvent être spécifiées sur la ligne de commande ou dans la base de données d'options pour configurer des aspects de InputO tels que son curseur ou sa largeur.

Les widgets InputO ne sont pas visibles par l'utilisateur. Le seul but des widgets InputO est d'accepter les entrées de l'utilisateur, ce qui peut être fait avec la méthode bind.

MÉTHODES DE WIDGET

La méthode InputO crée un objet widget. Cet objet supporte les méthodes configure et cget décrites dans Tk::options qui peuvent être utilisées pour interroger et modifier les options décrites ci-dessus. Le widget hérite également de toutes les méthodes fournies par la classe générique Tk::Widget.

LIAISONS

Les widgets InputO n'ont pas de liaisons par défaut.
