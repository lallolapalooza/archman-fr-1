Tk_GetHINSTANCE(3) Procédures de la bibliothèque Tk Tk_GetHINSTANCE(3)

NOM

Tk_GetHINSTANCE - récupérer le handle d'instance de l'application globale

SYNTAXE

#include <tkPlatDecls.h>

HINSTANCE
Tk_GetHINSTANCE()

DESCRIPTION

Tk_GetHINSTANCE renvoie le handle d'instance de l'application Windows pour l'application Tk. Cette fonction n'est disponible que sur les plateformes Windows.
