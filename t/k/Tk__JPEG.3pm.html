NOM

Tk::JPEG - Chargeur JPEG pour Tk::Photo

SYNTAXE

use Tk;
use Tk::JPEG;
my $image = $widget->Photo('-format' => 'jpeg', -file => 'quelquechose.jpg');

DESCRIPTION

Ceci est une extension pour Tk qui fournit un chargeur de format JPEG pour le type d'image Photo.

L'accès JPEG se fait via la release 5 du logiciel gratuit JPEG du Groupe Indépendant JPEG (IJG).

HISTORIQUE

Cette extension fonctionne pour Tk800.015 et versions ultérieures et est incluse par défaut avec Perl/Tk depuis Tk804.
