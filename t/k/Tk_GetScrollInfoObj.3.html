Tk_GetScrollInfoObj(3)

Paquet: tk

Tk_GetScrollInfo(3) Procédures de la bibliothèque Tk Tk_GetScrollInfo(3)

NOM

Tk_GetScrollInfoObj, Tk_GetScrollInfo - analyser les arguments pour les commandes de défilement

SYNTAXE

#include <tk.h>

int
Tk_GetScrollInfoObj(interp, objc, objv, fractionPtr, stepsPtr)

int
Tk_GetScrollInfo(interp, argc, argv, fractionPtr, stepsPtr)

ARGUMENTS

Tcl_Interp *interp (entrée)
Interpréteur à utiliser pour signaler les erreurs.
int objc (entrée)
Nombre de Tcl_Obj dans le tableau objv.
Tcl_Obj *const * objv (entrée)
Objets arguments. Ceux-ci représentent la commande complète du widget, dont le premier mot est généralement le nom du widget et le deuxième mot est généralement xview ou yview.
int argc (entrée)
Nombre de chaînes dans le tableau argv.
const char ** argv (entrée)
Chaînes d'arguments. Celles-ci représentent la commande complète du widget, dont le premier mot est généralement le nom du widget et le deuxième mot est généralement xview ou yview.
double *fractionPtr (sortie)
Rempli avec la fraction de l'option moveto, le cas échéant.
int *stepsPtr (sortie)
Rempli avec le nombre de lignes ou de pages de l'option scroll, le cas échéant. La valeur peut être négative.

DESCRIPTION

Tk_GetScrollInfoObj analyse les arguments attendus par les commandes de défilement de widgets telles que xview et yview. Elle reçoit la liste complète des mots qui composent une commande de widget et analyse les mots à partir de objv[2]. Les mots à partir de objv[2] doivent avoir l'une des formes suivantes :

moveto fraction
scroll number units
scroll number pages

Les mots-clés moveto, scroll, units et pages peuvent être abrégés. Si objv a la forme moveto, TK_SCROLL_MOVETO est retourné comme résultat et *fractionPtr est rempli avec l'argument fraction de la commande, qui doit être une valeur réelle valide. Si objv a la forme scroll, TK_SCROLL_UNITS ou TK_SCROLL_PAGES est retourné et *stepsPtr est rempli avec la valeur number, qui doit être un entier valide. Si une erreur se produit lors de l'analyse des arguments, TK_SCROLL_ERROR est retourné et un message d'erreur est laissé dans le résultat de l'interpréteur interp.

Tk_GetScrollInfo est identique en fonction à Tk_GetScrollInfoObj. Cependant, Tk_GetScrollInfo accepte des arguments sous forme de chaînes de caractères, ce qui la rend plus adaptée à une utilisation avec des widgets hérités.

MOTS-CLÉS

analyser, barre de défilement, commande de défilement, xview, yview
