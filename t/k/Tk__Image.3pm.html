NOM

Tk::Image - Créer et manipuler des images

SYNOPSIS

$image = $widget->type(?arg arg ...?)

$image->method(?arg arg ...?)

DESCRIPTION

Les constructeurs et méthodes image sont utilisés pour créer, supprimer et interroger des images. Ils peuvent prendre plusieurs formes différentes, en fonction du type.

Les constructeurs nécessitent un $widget pour être appelés, celui-ci est utilisé pour localiser une MainWindow. (Ceci est dû au fait que le code Tk sous-jacent enregistre les images dans la structure de données de la MainWindow.)

Les formes légales sont :

$widget->type?(?nom?,?option=>valeur ...)?
Crée une nouvelle image et retourne un objet. type spécifie le type de l'image, qui doit être l'un des types actuellement définis (par exemple, Bitmap). nom spécifie le nom de l'image ; s'il est omis, Tk choisit un nom de la forme imagex, où x est un entier. Il peut y avoir un nombre quelconque de paires option=>valeur, qui fournissent des options de configuration pour la nouvelle image. L'ensemble légal d'options est défini séparément pour chaque type d'image ; voir ci-dessous pour les détails sur les options des types d'images intégrés. Si une image existe déjà sous le nom donné, elle est remplacée par la nouvelle image et toutes les instances de cette image seront réaffichées avec le nouveau contenu.
$image->delete
Supprime l'image $image et retourne une chaîne vide. S'il y a des instances de l'image affichées dans des widgets, l'image ne sera pas réellement supprimée tant que toutes les instances ne seront pas libérées. Cependant, l'association entre les instances et le gestionnaire d'images sera rompue. Les instances existantes conserveront leurs dimensions mais seront réaffichées comme des zones vides. Si une image supprimée est recréée (avec le même nom), les instances existantes utiliseront la nouvelle image.
$image->height
Retourne une chaîne décimale donnant la hauteur de l'image nom en pixels.
$image->inuse
Retourne une valeur booléenne indiquant si l'image est utilisée ou non par des widgets.
$widget->imageNames
Retourne une liste contenant toutes les images existantes pour la MainWindow de $widget.
$image->type
Retourne le type de $image (la valeur de la méthode type lors de la création de l'image).
$widget->imageTypes
Retourne une liste dont les éléments sont tous les types d'images valides (c'est-à-dire toutes les valeurs qui peuvent être fournies pour le type lors de la création d'une image).
$image->width
Retourne une chaîne décimale donnant la largeur de l'image nom en pixels.

TYPES D'IMAGE INTÉGRÉS

Les types d'images suivants sont définis par Tk, ils seront donc disponibles dans toute application Tk. Des applications ou extensions individuelles peuvent définir des types supplémentaires.

Bitmap
Chaque pixel de l'image affiche une couleur de premier plan, une couleur d'arrière-plan, ou rien. Voir Tk::Bitmap pour plus d'informations.
Pixmap
Pixmap est légèrement plus général que Bitmap, chaque pixel peut être de n'importe quelle couleur disponible ou "transparent" (rendu comme la couleur d'arrière-plan dans laquelle l'image est affichée). Pixmap est préférable pour les icônes et autres graphiques simples avec seulement quelques couleurs.

Pixmap est dérivé de Tix. Voir Tk::Pixmap pour plus d'informations.

Photo
Affiche une variété d'images en couleurs, en utilisant la tramage pour approximer les couleurs sur les écrans avec des capacités de couleur limitées. Voir la documentation Tk::Photo pour plus d'informations.

AVERTISSEMENTS

Il est nécessaire d'utiliser la méthode "delete" pour supprimer un objet image et libérer la mémoire qui y est associée. Le simple fait d'utiliser une variable lexicale pour stocker l'objet image et de laisser la variable sortir de sa portée ou de la définir sur "undef" n'est pas suffisant.

VOIR AUSSI

Tk::Bitmap Tk::Pixmap Tk::Photo
