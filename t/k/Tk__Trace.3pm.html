NOM

Tk::Trace - émuler les fonctions de traçage Tcl/Tk.

SYNTAXE

use Tk::Trace
$mw->traceVariable(\$v, 'wru' => [\&update_meter, $scale]);
%vinfo = $mw->traceVinfo(\$v);
print "Infos de traçage :\n  ", join("\n  ", @{$vinfo{-legible}}), "\n";
$mw->traceVdelete(\$v);

DESCRIPTION

Ce module de classe émule la famille de commandes Tcl/Tk trace en liant des sous-routines de votre conception à des variables Perl en utilisant les fonctionnalités simples de Tie::Watch.

Le format de rappel est calqué sur le schéma Perl/Tk : fournissez soit une référence de code, soit une référence de tableau et passez la référence de code de rappel dans le premier élément du tableau, suivie des arguments de rappel.

Les rappels utilisateur reçoivent ces arguments :

$_[0]        = undef pour un scalaire, index/clé pour un tableau/hash
$_[1]        = valeur actuelle (lecture), nouvelle (écriture), finale (undef) de la variable
$_[2]        = opération (r, w, ou u)
$_[3 .. $#_] = arguments optionnels du rappel utilisateur

En tant qu'utilisateur de Trace, vous avez une responsabilité importante lors de la rédaction de votre rappel, car vous contrôlez la valeur finale attribuée à la variable. Un rappel typique pourrait ressembler à ceci :

sub callback {
   my($index, $value, $op, @args) = @_;
   return if $op eq 'u';
   # .... code qui utilise $value ...
   return $value;     # valeur finale de la variable
}

Notez que la valeur de retour du rappel devient la valeur finale de la variable, pour les traces de lecture ou d'écriture.

Pour les opérations d'écriture, la variable est mise à jour avec sa nouvelle valeur avant que le rappel ne soit invoqué.

Plusieurs rappels de lecture, d'écriture et d'undef peuvent être attachés à une variable, qui sont invoqués dans l'ordre inverse de leur création.

MÉTHODES

$mw->traceVariable(refVar, op => callback);
refVar est une référence à la variable scalaire, tableau ou hash que vous souhaitez tracer. op est l'opération de traçage, et peut être toute combinaison de r pour lecture, w pour écriture, et u pour undef. callback est un rappel Perl/Tk standard, et est invoqué, en fonction de la valeur de op, chaque fois que la variable est lue, écrite ou détruite.
%vinfo = $mw->traceVinfo(refVar);
Retourne un hash détaillant les internes de l'objet Trace, avec ces clés : 
%vinfo = (
    -variable =>  refVar
    -debug    =>  '0'
    -shadow   =>  '1'
    -value    =>  'BONJOUR SCALAR'
    -destroy  =>  callback
    -fetch    =>  callback
    -store    =>  callback
    -legible  =>  données formatées ci-dessus sous forme de liste de chaînes, pour impression
);

Pour les objets Trace de tableau et de hash, la clé -value est remplacée par une clé -ptr qui est une référence au tableau ou hash parallèle. De plus, pour un tableau ou un hash, il y a des paires clé/valeur pour tous les rappels spécifiques à la variable.

$mw->traceVdelete(\$v);
Arrêter de tracer la variable.

EXEMPLES

# Tracer la variable d'un Scale et déplacer un indicateur à l'unisson.
use Tk;
use Tk::widgets qw/Trace/;
$pi = 3.1415926;
$mw = MainWindow->new;
$c = $mw->Canvas( qw/-width 200 -height 110 -bd 2 -relief sunken/ )->grid;
$c->createLine( qw/100 100 10 100 -tag meter -arrow last -width 5/ );
$s = $mw->Scale( qw/-orient h -from 0 -to 100 -variable/ => \$v )->grid;
$mw->Label( -text => 'Faites-moi glisser pendant 5 secondes' )->grid;
$mw->traceVariable( \$v, 'w' => [ \&update_meter, $s ] );
$mw->after( 5000 => sub {
    print "Temps de dé-traçage ...\n";
    %vinfo = $s->traceVinfo( \$v );
    print "Infos de suivi  :\n  ", join("\n  ", @{$vinfo{-legible}}), "\n";
    $c->traceVdelete( \$v );
});
MainLoop;
sub update_meter {
    my( $index, $value, $op, @args ) = @_;
    return if $op eq 'u';
    $min = $s->cget( -from );
    $max = $s->cget( -to );
    $pos = $value / abs( $max - $min );
    $x = 100.0 - 90.0 * ( cos( $pos * $pi ) );
    $y = 100.0 - 90.0 * ( sin( $pos * $pi ) );
    $c->coords( qw/meter 100 100/, $x, $y );
    return $value;
}
# Entrée avec texte prédictif.
use Tk;
use Tk::widgets qw/ LabEntry Trace /;
use strict;
my @words =  qw/radio television telephone turntable microphone/;
my $mw = MainWindow->new;
my $e = $mw->LabEntry(
    qw/ -label Chose -width 40 /,
    -labelPack    => [ qw/ -side left / ],
    -textvariable => \my $thing,
);
my $t = $mw->Text( qw/ -height 10 -width 50 / );;
$t->pack( $e, qw/ -side top / );
$e->focus;
$e->traceVariable( \$thing, 'w', [ \&trace_thing, $e, $t ] );
foreach my $k ( 1 .. 12 ) {
    $e->bind( "<F${k}>" => [ \&ins, $t, Ev('K') ] );
}
$e->bind( '<Return>' =>
          sub {
              print "$thing\n";
              $_[0]->delete( 0, 'end' );
          }
);
MainLoop;
sub trace_thing {
    my( $index, $value, $op, $e, $t ) = @_;
    return unless $value;
    $t->delete( qw/ 1.0 end / );
    foreach my $w ( @words ) {
        if ( $w =~ /^$value/ ) {
            $t->insert( 'end', "$w\n" );
        }
    }
    return $value;
} # end trace_thing
sub ins {
    my( $e, $t, $K ) = @_;
    my( $index ) = $K =~ /^F(\d+)$/;
    $e->delete( 0, 'end' );
    $e->insert( 'end', $t->get( "$index.0", "$index.0 lineend" ) );
    $t->delete( qw/ 1.0 end / );
} # end ins
