Tk_GetOption(3) Procédures de la bibliothèque Tk Tk_GetOption(3)

NOM

Tk_GetOption - récupérer une option dans la base de données d'options

SYNOPSIS

#include <tk.h>

Tk_Uid
Tk_GetOption(tkwin, name, class)

ARGUMENTS

Tk_Window tkwin (entrée)
Jeton pour la fenêtre.
const char *name (entrée)
Nom de l'option désirée.
const char *class (entrée)
Classe de l'option désirée. La valeur NULL signifie qu'il n'y a pas de classe pour cette option ; la recherche se fait uniquement par nom.

DESCRIPTION

Cette procédure est appelée pour récupérer une option dans la base de données associée à la fenêtre principale de tkwin. S'il existe une option pour tkwin qui correspond au name ou à la class donnés, elle est retournée sous forme de Tk_Uid. Si plusieurs options correspondent à name et class, la plus prioritaire est retournée. Si aucune option ne correspond, NULL est retourné.

Tk_GetOption met en cache les options relatives à tkwin de sorte que les appels successifs pour le même tkwin s'exécutent beaucoup plus rapidement que les appels successifs pour des fenêtres différentes.
