NOM

Tk::FBox - une boîte de dialogue de fichier

SYNTAXE

use Tk::FBox;
$file = $mw->FBox(...)->Show;

DESCRIPTION

"Tk::FBox" est l'implémentation de la boîte de dialogue derrière les appels de méthode "getOpenFile", "getSaveFile" et "chooseDirectory" dans le monde Unix/X11. À ce titre, il prend en charge toutes les options de ces méthodes et supplémentairement :

-sortcmd => sub { $_[0] cmp $_[1] }
Spécifie un rappel pour modifier le tri des icônes dans le widget "IconList". Par défaut, l'opérateur "cmp" de Perl sera utilisé.

Du code source :

# Utiliser -sortcmd est vraiment étrange :-(
# $top->getOpenFile(-sortcmd => sub { package Tk::FBox; uc $b cmp uc $a});
# ou, non-perlish, mais utilisable (maintenant activé dans le code) :
# $top->getOpenFile(-sortcmd => sub { uc $_[1] cmp uc $_[0]});

Ceci est une option expérimentale !

-type => $type
Le type doit être "open" pour choisir des fichiers existants à ouvrir (par défaut), "save" pour choisir des fichiers existants ou non existants à enregistrer, ou "dir" pour choisir des répertoires.
-filter => $glob
Un motif glob de fichier pour restreindre les fichiers affichés. Ceci n'est actif si aucun -filetypes n'est défini.
-force => $bool
Si vrai, alors il n'y aura pas de boîte de dialogue si un fichier existe déjà.
