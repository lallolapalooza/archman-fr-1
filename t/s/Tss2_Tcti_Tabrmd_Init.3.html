Tss2_Tcti_Tabrmd_Init(3)

Paquet: tpm2-abrmd

TSS2_TCTI_TABRMD_INIT(3) TPM2 Software Stack TSS2_TCTI_TABRMD_INIT(3)

NOM

Tss2_Tcti_Tabrmd_Init - Fonction d'initialisation de la bibliothèque TCTI tpm2-abrmd.

SYNOPIS

La fonction Tss2_Tcti_Tabrmd_Init() est utilisée pour initialiser un contexte TCTI pour la communication avec tpm2-abrmd(8).

#include <tcti/tcti-tabrmd.h>

TSS2_RC Tss2_Tcti_Tabrmd_Init (TSS2_TCTI_CONTEXT *tcti_context, size_t *size, const char *conf);

DESCRIPTION

Tss2_Tcti_Tabrmd_Init() tente d'initialiser un tcti_context alloué par l'appelant, de taille size, avec la configuration spécifiée dans la chaîne de configuration conf. Comme le tcti_context doit être un tampon alloué par l'appelant, ce dernier doit connaître la taille requise par la bibliothèque TCTI. La taille minimale de ce contexte peut être découverte en fournissant NULL pour tcti_context et un paramètre size non nul. La fonction d'initialisation remplira alors le paramètre size avec la taille minimale du tampon tcti_context. L'appelant peut alors allouer un tampon de cette taille (ou plus grande) et appeler à nouveau tss2_Tcti_Tabrmd_Init () en fournissant le tcti_context nouvellement alloué et la taille de ce contexte dans le paramètre size. Ce modèle est commun à toutes les fonctions d'initialisation TCTI. Nous fournissons un exemple de ce modèle en utilisant la fonction Tss2_Tcti_Tabrmd_Init() dans la section intitulée EXEMPLE.

Le paramètre conf est une chaîne de paires clé/valeur décrivant les propriétés de connexion souhaitées pour le TCTI. Si l'appelant fournit une chaîne conf NULL, les valeurs par défaut correspondant à celles de tpm2-abrmd (8) seront utilisées. Ceci est équivalent à fournir la chaîne conf : "bus_name=com.intel.tss2.Tabrmd,bus_type=system". Les clés et les valeurs sont séparées par le caractère '=', tandis que chaque paire clé/valeur est séparée par le caractère ','. Les clés et les valeurs prises en charge sont :

•
bus_name - le nom dbus détenu par le démon. Voir l'option --dbus-name de tpm2-abrmd (8).
•
bus_type - le type de bus utilisé pour la connexion avec le démon. La valeur associée à cette clé peut être "system" ou "session".

Une fois initialisé, le contexte TCTI renvoyé expose l'API définie par le Trusted Computing Group (TCG) pour la communication de plus bas niveau avec le TPM. En utilisant cette API, l'appelant peut échanger (envoyer/recevoir) des buffers de commandes et de réponses TPM2 avec le tpm2-abrmd (8). Dans la quasi-totalité des cas, cependant, l'appelant initialisera un contexte en utilisant cette fonction avant de passer le contexte à une API de plus haut niveau comme l'API Système (SAPI), et ne la touchera plus jamais.

Pour une discussion plus approfondie de l'API TCTI, consultez la spécification “TSS System Level API and TPM Command Transmission Interface Specification” publiée par le TCG : https://trustedcomputinggroup.org/tss-system-level-api-tpm-command-transmission-interface-specification/

VALEUR DE RETOUR

Un appel réussi à Tss2_Tcti_Tabrmd_Init() retournera TSS2_RC_SUCCESS. Un appel infructueux produira un code de réponse décrit dans la section ERREURS.

ERREURS

TSS2_TCTI_RC_BAD_VALUE est retourné si le paramètre size est NULL.

TSS2_TCTI_RC_NO_CONNECTION est retourné lorsque la communication avec tpm2-abrmd (8) échoue.

TSS2_TCTI_RC_GENERAL_FAILURE est retourné pour toutes les autres erreurs.

EXEMPLE

#include <inttypes.h>
#include <stdlib.h>
#include <stdio.h>
#include <tcti/tcti-tabrmd.h>
TSS2_RC rc;
TSS2_TCTI_CONTEXT *tcti_context;
size_t size;
rc = tss2_tcti_tabrmd_init (NULL, &size, NULL,
if (rc != TSS2_RC_SUCCESS) {
    fprintf (stderr, "Failed to get allocation size for tabrmd TCTI "
             " context: 0x%" PRIx32 "0, rc);
    exit (EXIT_FAILURE);
}
tcti_context = calloc (1, size);
if (tcti_context == NULL) {
    fprintf (stderr, "Allocation for TCTI context failed: %s0,
             strerror (errno));
    exit (EXIT_FAILURE);
}
rc = tss2_tcti_tabrmd_init (tcti_context, &size, NULL);
if (rc != TSS2_RC_SUCCESS) {
    fprintf (stderr, "Failed to initialize tabrmd TCTI context: "
             "0x%" PRIx32 "0, rc);
    free (tcti_context);
    exit (EXIT_FAILURE);
}
exit (EXIT_SUCCESS);
