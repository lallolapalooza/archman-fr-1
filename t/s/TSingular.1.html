NOM

TSingular - page de manuel pour TSingular 4.0.0

DESCRIPTION

TSingular : Programme qui démarre Singular dans une fenêtre de terminal, pour la version 4.0.0 de Singular — un CAS pour les calculs polynômiaux. Utilisation :

TSingular [options] [fichier]

OPTIONS

- --xterm=XTERM
Utiliser XTERM comme programme de terminal pour exécuter Singular
- --singular=PROG
Démarrer PROG comme programme Singular dans emacs
- --no-call
Ne pas démarrer le programme. Afficher l'appel en sortie standard
toutes les autres options sont transmises à Singular.

Pour plus d'informations, tapez `help;' depuis Singular ou visitez https://www.singular.uni-kl.de ou consultez le manuel de Singular (disponible sous forme d'informations en ligne ou de manuel html).

VOIR AUSSI

La documentation complète de Singular est maintenue sous forme de manuel Texinfo. Si les programmes info et Singular sont correctement installés sur votre site, la commande

info Singular

devrait vous donner accès au manuel complet.
