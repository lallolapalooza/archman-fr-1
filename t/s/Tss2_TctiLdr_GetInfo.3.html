Tss2_TctiLdr_GetInfo(3) Manuel des fonctions de bibliothèque Tss2_TctiLdr_GetInfo(3)

NOM

Tss2_TctiLdr_GetInfo - Interroger la bibliothèque TctiLdr pour la structure TSS2_TCTI_INFO associée à une bibliothèque TCTI.

SYNOPSIS

#include <tss2/tss2_tctildr.h>

TSS2_RC Tss2_TctiLdr_GetInfo (constchar *nom, TSS2_TCTI_INFO **info);

DESCRIPTION

La fonction Tss2_TctiLdr_GetInfo() tente d'instancier une structure TSS2_TCTI_INFO appropriée pour la bibliothèque TCTI associée au nom fourni. La référence TSS2_TCTI_INFO* retournée par cette fonction doit être libérée par la fonction Tss2_TctiLdr_FreeInfo ().

Le paramètre nom est une chaîne C. Si cette chaîne est NULL, la bibliothèque sélectionnera un TCTI par défaut pour l'appelant. Il s'agit de la même bibliothèque TCTI qui sera utilisée pour initialiser le contexte retourné par Tss2_TctiLdr_Initialize lorsqu'un nom NULL lui est passé. Si non-NULL, Tss2_TctiLdr_GetInfo () utilise le même algorithme pour mapper la chaîne au nom d'une bibliothèque TCTI installée que la fonction Tss2_TctiLdr_Initialize ().

Le paramètre info est une référence vers un TSS2_TCTI_INFO*. La référence retournée sera allouée par la fonction et devra être libérée par l'appelant.

VALEUR DE RETOUR

Un appel réussi à cette fonction retournera TSS2_RC_SUCCESS. Un appel infructueux à cette fonction retournera un code de réponse décrit ci-dessous dans la section ERREURS.

ERREURS

TSS2_TCTI_RC_MEMORY est retourné si l'allocation mémoire échoue.

TSS2_TCTI_RC_NOT_SUPPORTED est retourné lorsque le chargeur ne parvient pas à localiser une bibliothèque TCTI avec le nom fourni.

TSS2_TCTI_RC_IO_ERROR est retourné si une erreur se produit dans le mécanisme de chargement de bibliothèque sous-jacent.

TSS2_TCTI_RC_BAD_REFERENCE est retourné si le paramètre info est NULL.

EXEMPLE

Exemple de code.

#include <inttypes.h>
#include <stdlib.h>
#include <stdio.h>
#include <tss2/tss2_tctildr.h>
TSS2_TCTI_INFO *info = NULL;
TSS2_RC rc = Tss2_TctiLdr_GetInfo (NULL, &info);
if (rc != TSS2_RC_SUCCESS) {
    fprintf (stderr, "L'initialisation du contexte TCTI par défaut a échoué avec le "
             "code de réponse : 0x%" PRIx32 ", rc);
    exit (EXIT_FAILURE);
}
if (info != NULL) {
    Tss2_TctiLdr_FreeInfo (info);
    info = NULL;
}
exit (EXIT_SUCCESS);
