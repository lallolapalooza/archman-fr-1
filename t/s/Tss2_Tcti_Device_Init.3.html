Tss2_Tcti_Device_Init(3) Manuel des fonctions de bibliothèque Tss2_Tcti_Device_Init(3)

NOM

Tss2_Tcti_Device_init - Fonction d'initialisation de la bibliothèque TCTI de périphérique.

SYNTAXE

#include <tcti/tcti_device.h>

TSS2_RC Tss2_Tcti_Device_Init (TSS2_TCTI_CONTEXT *tctiContext, size_t *size, const char *conf);

La fonction Tss2_Tcti_Device_Init() initialise un contexte TCTI utilisé pour communiquer avec le pilote de périphérique TPM.

DESCRIPTION

Tss2_Tcti_Device_Init() tente d'initialiser un tctiContext alloué par l'appelant de taille size . Comme le tctiContext doit être un tampon alloué par l'appelant, l'appelant doit connaître la taille requise par la bibliothèque TCTI. La taille minimale de ce contexte peut être découverte en fournissant NULL pour tctiContext et un paramètre size non- NULL . La fonction d'initialisation remplira alors le paramètre size avec la taille minimale du tampon tctiContext . L'appelant doit alors allouer un tampon de cette taille (ou plus grande) et appeler à nouveau Tss2_Tcti_Device_Init () en fournissant le tctiContext nouvellement alloué et la taille de ce contexte dans le paramètre size . Ce modèle est commun à toutes les fonctions d'initialisation TCTI. Nous fournissons un exemple de ce modèle en utilisant la fonction Tss2_Tcti_Device_Init() dans la section intitulée EXEMPLE.

Le paramètre conf est une chaîne de caractères C. Si cette chaîne est NULL , la bibliothèque utilisera une chaîne de configuration par défaut pour l'appelant. Alternativement, l'appelant peut fournir une chaîne de configuration qui doit contenir le chemin vers le nœud de périphérique exposé par le pilote de périphérique TPM.

Une fois initialisé, le contexte TCTI renvoyé expose l'API définie par le Trusted Computing Group (TCG) pour la communication de plus bas niveau avec le périphérique TPM. En utilisant cette API, l'appelant peut échanger (envoyer / recevoir) des tampons de commande et de réponse TPM2 avec le pilote de périphérique TPM. Dans presque tous les cas cependant, l'appelant initialisera un contexte en utilisant cette fonction avant de passer le contexte à une API de niveau supérieur comme l'API Système (SAPI), et ne le touchera plus jamais.

Spécification de l'API TCG TSS 2.0 TPM Command Transmission Interface (TCTI)

Pour une discussion plus approfondie de l'API TCTI, voir la « Spécification de l'API TCG TSS 2.0 TPM Command Transmission Interface (TCTI) » publiée par le TCG : https://trustedcomputinggroup.org/wp-content/uploads/TSS_TCTI_Version-1.0_Revision-05_Review_END030918.pdf

VALEUR DE RETOUR

Un appel réussi à Tss2_Tcti_Device_Init() retournera TSS2_RC_SUCCESS. Un appel infructueux produira un code de réponse décrit dans la section ERREURS.

ERREURS

TSS2_TCTI_RC_BAD_VALUE est retourné si des paramètres contiennent des valeurs inattendues. TSS2_TCTI_RC_BAD_REFERENCE est retourné si des paramètres sont NULL alors qu'ils ne devraient pas l'être. TSS2_TCTI_RC_BAD_CONTEXT est retourné si la taille du tctiContext fourni est insuffisante.

EXEMPLE

Fragment d'initialisation TCTI :

#include <inttypes.h>
#include <stdlib.h>
#include <stdio.h>
#include <tcti/tcti_device.h>
TSS2_RC rc;
TSS2_TCTI_CONTEXT *tcti_context;
size_t size;
char *conf = "/dev/tpm0",
rc = Tss2_Tcti_Device_Init (NULL, &size, NULL);
if (rc != TSS2_RC_SUCCESS) {
    fprintf (stderr, "Impossible d'obtenir la taille d'allocation pour le
             contexte TCTI de périphérique : 0x%" PRIx32 "0, rc);
    exit (EXIT_FAILURE);
}
tcti_context = calloc (1, size);
if (tcti_context == NULL) {
    fprintf (stderr, "Allocation du contexte TCTI échouée : %s0,
             strerror (errno));
    exit (EXIT_FAILURE);
}
rc = Tss2_Tcti_Device_Init (&tcti_context, &size, &conf);
if (rc != TSS2_RC_SUCCESS) {
    fprintf (stderr, "Échec de l'initialisation du contexte TCTI de
             périphérique : 0x%" PRIx32 "0, rc);
    free (tcti_context);
    exit (EXIT_FAILURE);
}
exit (EXIT_SUCCESS);
