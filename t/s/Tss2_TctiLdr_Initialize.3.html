Tss2_TctiLdr_Initialize(3) Manuel des fonctions de bibliothèque Tss2_TctiLdr_Initialize(3)

NOM

Tss2_TctiLdr_Initialize, Tss2_TctiLdr_Initialize_Ex - Instancier et initialiser un contexte TCTI.

SYNOPSIS

#include <tss2/tss2_tctildr.h>

TSS2_RC Tss2_TctiLdr_Initialize (const char *nameConf, TSS2_TCTI_CONTEXT **context);

TSS2_RC Tss2_TctiLdr_Initialize_Ex (const char *name, const char *conf, TSS2_TCTI_CONTEXT **context);

DESCRIPTION

Les fonctions Tss2_TctiLdr_Initialize() et Tss2_TctiLdr_Initialize_Ex() initialisent un contexte TCTI utilisé pour communiquer avec le TPM2 ou un composant intermédiaire dans la pile logicielle TCG TPM2.

Tss2_TctiLdr_Initialize() prend une seule chaîne qui encode à la fois le nom de la bibliothèque TCTI que l'appelant souhaite instancier et sa configuration souhaitée dans le paramètre nameConf. nameConf est une chaîne composée de deux sous-chaînes : les paramètres name et conf respectivement. Ces sous-chaînes sont combinées avec name en premier, séparées par un seul caractère ':' / deux-points : 'nom:conf'. Consultez la section intitulée CONFIGURATION TCTI pour obtenir des informations sur l'encodage de ces chaînes. Le paramètre context est utilisé pour retourner une référence au contexte TCTI créé par la fonction.

Tss2_TctiLdr_Initialize_Ex() se comporte de manière identique à la fonction Tss2_TctiLdr_Initialize() à l'exception près que le nom et la configuration du TCTI sont passés sous forme de chaînes séparées. L'encodage de ces chaînes est décrit dans la section CONFIGURATION TCTI.

CONFIGURATION TCTI

Si la chaîne name est NULL ou vide, les fonctions d'initialisation sélectionneront un TCTI par défaut approprié à la plateforme. Sous Linux, cela signifie d'abord essayer de charger une bibliothèque nommée libtss2-tcti-default.so. Ceci est un espace réservé pour que les distributions fournissent un défaut spécifique à la distribution. Il est recommandé que ce soit un lien symbolique vers une autre bibliothèque TCTI installée. Si les tentatives de chargement de cet objet partagé échouent, l'implémentation tentera les TCTI connus dans l'ordre suivant :

•
libtss2-tcti-tabrmd.so.0
•
libtss2-tcti-device.so.0
•
libtss2-tcti-mssim.so.0

Lorsque la chaîne name n'est ni NULL ni vide, l'implémentation tentera de dlopen une bibliothèque portant le nom donné. Si cela échoue, l'implémentation suppose qu'un nom abrégé a été passé et tentera de charger les bibliothèques par nom avec les permutations suivantes :

•
<name>
•
libtss2-tcti-<name>.so.0
•
libtss2-tcti-<name>.so

La chaîne config n'est pas interprétée par les fonctions d'initialisation TctiLdr et est passée telle quelle à la fonction d'initialisation du TCTI sélectionné. Le format de cette chaîne est spécifique au TCTI.

La fonction Tss2_TctiLdr_Initialize reçoit les chaînes name et conf sous forme d'un seul paramètre. Dans ce cas, les chaînes name et conf sont concaténées avec un seul caractère ':' / deux-points les séparant.

Pour une discussion plus approfondie de l'API TCTILDR, consultez le « TCG TSS 2.0 TPM Command Transmission Interface (TCTI) API Specification ».

VALEUR RENVOYÉE

Un appel réussi à cette fonction retournera TSS2_RC_SUCCESS. Un appel infructueux produira un code de retour décrit dans la section ERREURS.

ERREURS

TSS2_TCTI_RC_MEMORY est renvoyé si l'allocation mémoire échoue

TSS2_TCTI_RC_NOT_SUPPORTED est renvoyé lorsque le chargeur ne parvient pas à localiser une bibliothèque TCTI avec le name fourni

TSS2_TCTI_RC_IO_ERROR est renvoyé si un échec survient dans le mécanisme de chargement de bibliothèque sous-jacent

TSS2_TCTI_RC_BAD_REFERENCE est renvoyé si le paramètre tctiContext est NULL

EXEMPLE

Code d'exemple.

#include <inttypes.h>
#include <stdlib.h>
#include <stdio.h>
#include <tss2/tss2_tctildr.h>
TSS2_TCTI_CONTEXT *ctx = NULL;
TSS2_RC rc = Tss2_TctiLdr_Initialize (NULL, &ctx);
if (rc != TSS2_RC_SUCCESS) {
    fprintf (stderr, "L'initialisation du contexte TCTI par défaut a échoué avec le "
             "code de retour : 0x%" PRIx32 ", rc);
    exit (EXIT_FAILURE);
}
exit (EXIT_SUCCESS);
