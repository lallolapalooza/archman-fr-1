Tss2_Tcti_Cmd_Init(3) Manuel des fonctions de bibliothèque Tss2_Tcti_Cmd_Init(3)

NOM

Tss2_Tcti_Cmd_Init - Fonction d'initialisation de la bibliothèque TCTI Cmd.

SYNTAXE

#include <tss2/tss2_tcti_cmd.h>

TSS2_RC Tss2_Tcti_Cmd_Init (TSS2_TCTI_CONTEXT *tctiContext, size_t *contextSize, const char *conf);

La fonction Tss2_Tcti_Cmd_Init() initialise un contexte TCTI utilisé pour communiquer avec un sous-processus spécifié dans la chaîne conf. L'envoi et la réception du TCTI utilisent respectivement les flux stdin et stdout du sous-processus.

DESCRIPTION

Tss2_Tcti_Cmd_Init() tente d'initialiser un tcti_context alloué par l'appelant, d'une taille de size, en utilisant la chaîne de configuration conf fournie par l'appelant. Puisque le tcti_context doit être un tampon alloué par l'appelant, l'appelant doit connaître la taille du tampon requise par la bibliothèque TCTI. La taille minimale de ce contexte peut être découverte en fournissant NULL pour le paramètre tcti_context et un paramètre size non NULL. La fonction d'initialisation remplira alors le paramètre size avec la taille minimale du tampon tcti_context. L'appelant doit ensuite allouer un tampon de cette taille (ou plus grande) et appeler à nouveau Tss2_Tcti_Cmd_Init() en fournissant le tcti_context nouvellement alloué et la taille de ce contexte dans le paramètre size. Ce schéma est courant pour toutes les fonctions d'initialisation TCTI. Nous fournissons un exemple de ce schéma en utilisant la fonction Tss2_Tcti_Cmd_Init() dans la section intitulée EXEMPLE.

Le paramètre conf est une chaîne C utilisée pour configurer le contexte TCTI. Cette chaîne de configuration est la commande utilisée pour popen(3). La chaîne conf ne peut pas être NULL pour ce TCTI.

Une fois initialisé, le contexte TCTI renvoyé expose l'API définie par le Trusted Computing Group (TCG) pour la communication de plus bas niveau avec le TPM. En utilisant cette API, l'appelant peut échanger (envoyer / recevoir) des buffers de commande et de réponse TPM2 avec un service capable d'échanger des buffers de commande et de réponse TPM2. Dans presque tous les cas cependant, l'appelant initialisera un contexte en utilisant cette fonction avant de passer le contexte à une API de plus haut niveau comme l'API Système (SAPI), l'API Système Améliorée (ESAPI) ou l'API Fonctionnalités (FAPI) et ne la touchera plus jamais.

Pour une discussion plus approfondie de l'API TCTI, voir la “TSS System Level API and TPM Command Transmission Interface Specification” telle que publiée par le TCG : https://trustedcomputinggroup.org/tss-system-level-api-tpm-command-transmission-interface-specification/

VALEUR DE RETOUR

Un appel réussi à Tss2_Tcti_Cmd_Init() retournera TSS2_RC_SUCCESS. Un appel non réussi produira un code de réponse décrit dans la section ERREURS.

ERREURS

TSS2_TCTI_RC_BAD_VALUE est retourné si les paramètres tcti_context et size sont tous deux NULL, ou si le paramètre config est NULL.

EXEMPLE

Fragment d'initialisation TCTI :

#include <inttypes.h>
#include <stdlib.h>
#include <stdio.h>
#include <tcti/tcti_mssim.h>
TSS2_RC rc;
TSS2_TCTI_CONTEXT *tcti_context;
size_t size;
const char *conf = "XXX TODO SAMPLE"
rc = Tss2_Tcti_Cmd_Init (NULL, &size, NULL);
if (rc != TSS2_RC_SUCCESS) {
    fprintf (stderr, "Échec de l'obtention de la taille d'allocation pour le contexte TCTI mssim "
             ": 0x%" PRIx32 ", rc);
    exit (EXIT_FAILURE);
}
tcti_context = calloc (1, size);
if (tcti_context == NULL) {
    fprintf (stderr, "Échec de l'allocation du contexte TCTI : %s",
             strerror (errno));
    exit (EXIT_FAILURE);
}
rc = Tss2_Tcti_Cmd_Init (&tcti_context, &size, conf);
if (rc != TSS2_RC_SUCCESS) {
    fprintf (stderr, "Échec de l'initialisation du contexte TCTI mssim : "
             "0x%" PRIx32 ", rc);
    free (tcti_context);
    exit (EXIT_FAILURE);
}
