NOM

TopLevelShell — La classe de widget TopLevelShell

SYNOPIS

#include <Xm/Xm.h>
#include <X11/Shell.h>

DESCRIPTION

TopLevelShell est utilisé pour les fenêtres de niveau supérieur normales, telles que tout widget de niveau supérieur supplémentaire dont une application pourrait avoir besoin.

Classes

TopLevelShell hérite du comportement et des ressources de Core, Composite, Shell, WMShell et VendorShell.

Le pointeur de classe est topLevelShellWidgetClass.

Le nom de la classe est TopLevelShell.

Nouvelles Ressources

Le tableau suivant définit un ensemble de ressources de widgets utilisées par le programmeur pour spécifier des données. Le programmeur peut également définir les valeurs des ressources pour les classes héritées afin de définir les attributs de ce widget. Pour faire référence à une ressource par son nom ou sa classe dans un fichier .Xdefaults, supprimez le préfixe XmN ou XmC et utilisez les lettres restantes. Pour spécifier l'une des valeurs définies pour une ressource dans un fichier .Xdefaults, supprimez le préfixe Xm et utilisez les lettres restantes (en minuscules ou en majuscules, mais incluez les tirets bas entre les mots). Les codes dans la colonne d'accès indiquent si la ressource donnée peut être définie au moment de la création (C), définie en utilisant XtSetValues (S), récupérée en utilisant XtGetValues (G), ou n'est pas applicable (N/A).

XmNiconic
Si True lors de la création du widget, spécifie que le widget doit commencer sous forme d'icône lorsqu'il est réalisé. Une valeur False indique que le widget ne doit pas être réalisé sous forme d'icône. Cette ressource ne remplacera la ressource XmNinitialState que lorsqu'elle est spécifiée dans l'appel qui crée le widget.
XmNiconName
Spécifie la forme courte du nom de l'application à afficher par le gestionnaire de fenêtres lorsque l'application est iconifiée. Lorsque XtGetValues est appelé sur cette ressource, la valeur renvoyée est un pointeur vers la valeur réelle de la ressource et ne doit pas être libérée.
XmNiconNameEncoding
Spécifie un type de propriété représentant le codage de la chaîne XmNiconName. Si une procédure de langue a été définie, la valeur par défaut est None; sinon, la valeur par défaut est XA_STRING. Lorsque le widget est réalisé, si la valeur est None, le nom correspondant est supposé être dans la locale courante. Le nom est passé à XmbTextListToTextProperty avec un style de codage XStdICCTextStyle. Le codage résultant est STRING si le nom est entièrement convertible en STRING, sinon COMPOUND_TEXT. Les valeurs des ressources de codage ne sont pas modifiées; elles restent None.
