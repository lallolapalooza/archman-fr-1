NOM

Text::BibTeX::BibSort - génère des clés de tri pour les entrées bibliographiques

SYNTAXE

# En supposant que $entry provient d'une base de données de la structure 'Bib'
# (c'est-à-dire qu'elle est bénie dans la classe BibEntry, qui hérite
# de la méthode sort_key de BibSort) :
$sort_key = $entry->sort_key;

DESCRIPTION

"Text::BibTeX::BibSort" est une classe de base de "Text::BibTeX::BibEntry" pour générer des clés de tri à partir d'entrées bibliographiques. Elle pourrait, en principe (et, un jour peut-être, offrira) une large gamme de générateurs de clés de tri hautement personnalisables. Actuellement, cependant, elle ne fournit qu'une seule méthode ("sort_key") à usage public, et cette méthode ne tient compte que d'une seule option de structure, "sortby".

MÉTHODES

sort_key ()
Génère une clé de tri pour une seule entrée bibliographique. Suppose que cette entrée est conforme à la structure de la base de données "Bib". La nature de cette clé de tri est contrôlée par l'option "sortby", qui peut être "name" ou "year". (Le "namestyle" joue également un rôle, pour déterminer comment les noms d'auteurs/éditeurs sont formatés pour inclusion dans la clé de tri.)

Pour le tri par nom (qui est la manière dont les styles standard de BibTeX fonctionnent), la clé de tri se compose de l'un des champs "author", "editor", "organization", ou "key" (selon le type d'entrée et les champs effectivement présents), suivi de l'année et du titre. Tous les champs sont drastiquement simplifiés pour produire la clé de tri : les lettres non anglaises sont impitoyablement anglicisées, les caractères non alphabétiques sont supprimés, et tout est forcé en minuscules. (Les deux premières étapes sont effectuées par la routine "purify_string" ; voir « Fonctions génériques de traitement de chaînes » dans Text::BibTeX pour une brève description, et la description de la fonction C bt_purify_string() dans bt_misc pour tous les détails gores.)
