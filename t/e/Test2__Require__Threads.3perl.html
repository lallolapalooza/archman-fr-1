Test2::Require::Threads(3perl) Guide du programmeur Perl Test2::Require::Threads(3perl)

NOM

Test2::Require::Threads - Ignorer un fichier de test sauf si le système prend en charge les threads

DESCRIPTION

Il est assez courant d'écrire des tests qui nécessitent l'utilisation de threads. Tous les systèmes ne prennent pas en charge les threads. Cette bibliothèque effectue le travail difficile de vérifier si les threads sont pris en charge sur le système actuel. Si les threads ne sont pas pris en charge, cela ignorera tous les tests et renverra vrai.

SYNTAXE

use Test2::Require::Threads;
... Code qui utilise des threads ...

EXPLICATION

Vérifier si le système actuel prend en charge les threads n'est pas simple, voici un exemple de la façon de le faire :

use Config;
sub CAN_THREAD {
    # Les threads ne sont pas fiables avant 5.008001
    return 0 unless $] >= 5.008001;
    return 0 unless $Config{'useithreads'};
    # Devel::Cover interrompt actuellement les threads
    return 0 if $INC{'Devel/Cover.pm'};
    return 1;
}

Dupliquer ce code non trivial dans tous les tests qui nécessitent l'utilisation de threads est source d'erreurs. Il est facile d'oublier des éléments ou de se tromper. En plus de ces vérifications, vous devez également indiquer au gestionnaire que aucun test ne doit être exécuté et pourquoi.

VOIR AUSSI

Test2
