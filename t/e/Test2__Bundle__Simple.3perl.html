Test2::Bundle::Simple(3perl) Guide du programmeur Perl Test2::Bundle::Simple(3perl)

NOM

Test2::Bundle::Simple - PRESQUE un remplacement direct de Test::Simple.

DESCRIPTION

Ce bundle est destiné à être un remplacement (principalement) direct de Test::Simple. Voir "DIFFÉRENCES CLÉS PAR RAPPORT à Test::Simple" pour plus de détails.

SYNTAXE

use Test2::Bundle::Simple;
ok(1, "réussite");
done_testing;

PLUGINS

Charge Test2::Plugin::ExitSummary.

OUTILS

Ceux-ci proviennent tous de Test2::Tools::Basic.

ok($bool, $nom)
Exécute un test. Si bool est vrai, le test réussit. Si bool est faux, il échoue.
plan($count)
Indique au système combien de tests attendre.
skip_all($reason)
Indique au système de sauter tous les tests (cela quittera le script).
done_testing();
Indique au système que tous les tests sont terminés. Vous pouvez l'utiliser à la place de définir un plan.

DIFFÉRENCES CLÉS PAR RAPPORT à Test::Simple

Vous ne pouvez pas planifier lors de l'importation.
Ceci **NE fonctionnera PAS** : 
use Test2::Bundle::Simple tests => 5;

Au lieu de cela, vous devez planifier dans une instruction distincte :

use Test2::Bundle::Simple;
plan 5;
Trois sous-routines sont importées pour la planification
Utilisez plan($compte), skip_all($raison), ou done_testing() pour votre planification.
