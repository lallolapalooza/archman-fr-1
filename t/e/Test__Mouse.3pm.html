NOM

Test::Mouse - Fonctions de test pour les fonctionnalités spécifiques à Mouse

SYNTAXE

use Test::More plan => 1;
use Test::Mouse;
meta_ok($class_or_obj, "... Foo a un ->meta");
does_ok($class_or_obj, $role, "... Foo fait le rôle Baz");
has_attribute_ok($class_or_obj, $attr_name, "... Foo a l'attribut 'bar'");

DESCRIPTION

Ce module fournit quelques fonctions de test utiles pour les classes basées sur Mouse. Il s'agit d'une première version expérimentale, donc les commentaires et suggestions sont très appréciés.

FONCTIONS EXPORTÉES

meta_ok ($class_or_object)
Teste si une classe ou un objet a une métaclasse.
does_ok ($class_or_object, $role, ?$message)
Teste si une classe ou un objet implémente un rôle donné, similaire à ce que fait "isa_ok" pour la méthode "isa".
has_attribute_ok($class_or_object, $attr_name, ?$message)
Teste si une classe ou un objet possède un attribut donné, similaire à ce que fait "can_ok" pour les méthodes.
with_immutable { CODE } @class_names
Exécute *CODE (qui doit contenir des tests normaux) deux fois, et rend chaque classe dans @class_names immuable entre les deux exécutions.
