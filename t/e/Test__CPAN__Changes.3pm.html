NOM

Test::CPAN::Changes - Validation du fichier Changes dans une distribution CPAN

SYNOPSIS

# dans xt/author/cpan-changes.t
use Test::More;
use Test::CPAN::Changes;
changes_ok;
# vérification d'une version spécifique
use My::Module;
use Test::More;
use Test::CPAN::Changes;
changes_ok({ version => My::Module->VERSION });

DESCRIPTION

Ce module permet aux auteurs CPAN d'écrire des tests automatisés pour s'assurer que leurs journaux de modifications correspondent à la spécification.

SOUSROUTINES

changes_ok( \%args )

Wrapper simple autour de "changes_file_ok". Déclare un plan de test et utilise le nom de fichier par défaut "Changes".

changes_file_ok( $filename, \%arg )

Vérifie le contenu du fichier Changes par rapport à la spécification. Aucun plan n'est déclaré et si le nom de fichier est indéfini, "Changes" est utilisé.

Quatre tests sont effectués. Le fichier doit être analysable, doit contenir des versions, et les versions et dates listées doivent être valides.

%arg peut inclure une entrée version, auquel cas deux tests supplémentaires sont effectués. L'entrée pour cette version doit exister et avoir du contenu. Ceci est utile pour s'assurer que la version actuellement publiée a des modifications documentées.
