NOM

Template::Plugin::Date - Plugin pour générer des chaînes de date formatées

SYNTAXE

[% USE date %]
# utiliser l'heure actuelle et le format par défaut
[% date.format %]
# spécifier le temps comme secondes depuis l'époque
# ou comme une chaîne 'h:m:s j-m-a' ou 'a-m-j h:m:s'
[% date.format(960973980) %]
[% date.format('4:20:36 21/12/2000') %]
[% date.format('2000/12/21 4:20:36') %]
# spécifier le format
[% date.format(mytime, '%H:%M:%S') %]
# spécifier la locale
[% date.format(date.now, '%a %d %b %y', 'en_GB') %]
# paramètres nommés
[% date.format(mytime, format = '%H:%M:%S') %]
[% date.format(locale = 'en_GB') %]
[% date.format(time       = date.now,
               format     = '%H:%M:%S',
               locale     = 'en_GB'
               use_offset = 1) %]
# spécifier le format par défaut au plugin
[% USE date(format = '%H:%M:%S', locale = 'de_DE') %]
[% date.format %]
...

DESCRIPTION

Le plugin "Date" fournit un moyen facile de générer des chaînes de temps et de date formatées en déléguant à la routine strftime() de "POSIX".

Le plugin peut être chargé via la directive USE familière.

[% USE date %]

Ceci crée un objet plugin avec le nom par défaut de '"date"'. Un nom alternatif peut être spécifié comme suit :

[% USE myname = date %]

Le plugin fournit la méthode format() qui accepte une valeur de temps, une chaîne de format et un nom de locale. Tous ces paramètres sont optionnels, l'heure système actuelle, le format par défaut ('"%H:%M:%S %d-%b-%Y"') et la locale actuelle étant utilisés respectivement, s'ils ne sont pas définis. Les valeurs par défaut pour l'heure, le format et/ou la locale peuvent être spécifiées en tant que paramètres nommés dans la directive "USE".

[% USE date(format = '%a %d-%b-%Y', locale = 'fr_FR') %]

Lorsqu'elle est appelée sans aucun paramètre, la méthode format() renvoie une chaîne représentant l'heure système actuelle, formatée par strftime() selon le format par défaut et pour la locale par défaut (qui peut ne pas être l'actuelle, si la locale est définie dans la directive "USE").

[% date.format %]

Le plugin permet de spécifier une heure/date comme secondes depuis l'époque, tel que retourné par time().

Fichier modifié le : [% date.format(filemod_time) %]

L'heure/date peut également être spécifiée comme une chaîne de la forme "h:m:s j/m/a" ou "a/m/j h:m:s". N'importe lequel des caractères : / - ou espace peut être utilisé pour délimiter les champs.

[% USE day = date(format => '%A', locale => 'en_GB') %]
[% day.format('4:20:00 9-13-2000') %]

Sortie :

Tuesday

Une chaîne de format peut également être passée à la méthode format(), et une spécification de locale peut suivre celle-ci.

[% date.format(filemod, '%d-%b-%Y') %]
[% date.format(filemod, '%d-%b-%Y', 'en_GB') %]

Un quatrième paramètre vous permet de forcer la sortie en GMT, dans le cas d'une entrée en secondes depuis l'époque :

[% date.format(filemod, '%d-%b-%Y', 'en_GB', 1) %]

Notez que dans ce cas, si l'heure locale n'est pas GMT, alors spécifier également '%Z' (fuseau horaire) dans le paramètre de format mènera à un résultat extrêmement trompeur.

Pour maintenir la compatibilité ascendante, l'utilisation du placeholder %z dans la chaîne de format (pour afficher le décalage UTC) nécessite actuellement que le paramètre "use_offset" soit défini à une valeur vraie. Ceci peut également être passé comme cinquième paramètre à format (mais le précédent sera probablement plus clair).

N'importe lequel de ces paramètres, ou tous, peuvent être nommés. Les paramètres positionnels doivent toujours être dans l'ordre "($time, $format, $locale)".

[% date.format(format => '%H:%M:%S') %]
[% date.format(time => filemod, format => '%H:%M:%S') %]
[% date.format(mytime, format => '%H:%M:%S') %]
[% date.format(mytime, format => '%H:%M:%S', locale => 'fr_FR') %]
[% date.format(mytime, format => '%H:%M:%S', gmt => 1) %]
...etc...

La méthode now() renvoie l'heure système actuelle en secondes depuis l'époque.

[% date.format(date.now, '%A') %]

La méthode calc() peut être utilisée pour créer une interface vers le module "Date::Calc" (s'il est installé sur votre système).

[% calc = date.calc %]
[% calc.Monday_of_Week(22, 2001).join('/') %]

La méthode manip() peut être utilisée pour créer une interface vers le module "Date::Manip" (s'il est installé sur votre système).

[% manip = date.manip %]
[% manip.UnixDate("Noon Yesterday","%Y %b %d %H:%M") %]
