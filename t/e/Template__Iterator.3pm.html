NOM

Template::Iterator - Itérateur de données utilisé par la directive FOREACH

SYNTAXE

my $iter = Template::Iterator->new(\@data, \%options);

DESCRIPTION

Le module "Template::Iterator" définit un itérateur de données générique destiné à être utilisé par la directive "FOREACH".

Il peut servir de classe de base pour des itérateurs personnalisés.

MÉTHODES PUBLIQUES

new($data)

Méthode constructeur. Une référence à une liste de valeurs est passée comme premier paramètre. Les appels ultérieurs à get_first() et get_next() retourneront chaque élément de la liste.

my $iter = Template::Iterator->new([ 'foo', 'bar', 'baz' ]);

Le constructeur accepte également une référence à un tableau associatif et le développera en une liste dans laquelle chaque entrée est un tableau associatif contenant des éléments '"key"' et '"value"', triés selon les clés du tableau associatif.

my $iter = Template::Iterator->new({
    foo => 'Foo Item',
    bar => 'Bar Item',
});

Ceci est équivalent à :

my $iter = Template::Iterator->new([
    { key => 'bar', value => 'Bar Item' },
    { key => 'foo', value => 'Foo Item' },
]);

Lorsqu'un seul élément qui n'est pas une référence de tableau est passé, le constructeur créera automatiquement une liste contenant cet élément unique.

my $iter = Template::Iterator->new('foo');

Ceci est équivalent à :

my $iter = Template::Iterator->new([ 'foo' ]);

Notez qu'un seul élément qui est un objet basé sur une référence de tableau blessée ne sera PAS traité comme un tableau et sera replié dans une liste contenant cette seule référence d'objet.

my $list = bless [ 'foo', 'bar' ], 'MyListClass';
my $iter = Template::Iterator->new($list);

équivalent à :

my $iter = Template::Iterator->new([ $list ]);

Si l'objet fournit une méthode as_list(), alors le constructeur Template::Iterator appellera cette méthode pour retourner la liste de données. Par exemple :

package MyListObject;
sub new {
    my $class = shift;
    bless [ @_ ], $class;
}
package main;
my $list = MyListObject->new('foo', 'bar');
my $iter = Template::Iterator->new($list);

Ceci est alors fonctionnellement équivalent à :

my $iter = Template::Iterator->new([ $list ]);

L'itérateur ne retournera qu'un seul élément, une référence à l'objet "MyListObject", $list.

En ajoutant une méthode as_list() à la classe "MyListObject", nous pouvons forcer le constructeur "Template::Iterator" à traiter l'objet comme une liste et à utiliser les données qu'il contient.

package MyListObject;
...
sub as_list {
    my $self = shift;
    return $self;
}
package main;
my $list = MyListObject->new('foo', 'bar');
my $iter = Template::Iterator->new($list);

L'itérateur retournera maintenant les deux éléments, '"foo"' et '"bar"', que "MyObjectList" encapsule.

get_first()

Retourne une paire "($valeur, $erreur)" pour le premier élément de l'ensemble de l'itérateur. Le $erreur retourné peut être zéro ou indéfini pour indiquer qu'une donnée valide a été retournée avec succès. Retourne une erreur de "STATUS_DONE" si la liste est vide.

get_next()

Retourne une paire "($valeur, $erreur)" pour le prochain élément de l'ensemble de l'itérateur. Retourne une erreur de "STATUS_DONE" si tous les éléments de la liste ont été visités.

get_all()

Retourne une paire "(\@valeurs, $erreur)" pour tous les éléments restants de l'ensemble de l'itérateur. Retourne une erreur de "STATUS_DONE" si tous les éléments de la liste ont été visités.

size()

Retourne la taille de l'ensemble de données ou undef si inconnue.

max()

Retourne l'indice maximal (c'est-à-dire l'indice du dernier élément) qui est équivalent à size() - 1.

index()

Retourne l'indice courant dans la plage 0 à max().

count()

Retourne le nombre d'itérations courant dans la plage 1 à size(). Ceci est équivalent à index() + 1.

first()

Retourne une valeur booléenne pour indiquer si l'itérateur est actuellement sur la première itération de l'ensemble.

last()

Retourne une valeur booléenne pour indiquer si l'itérateur est actuellement sur la dernière itération de l'ensemble.

prev()

Retourne l'élément précédent dans l'ensemble de données, ou "undef" si l'itérateur est sur le premier élément.

next()

Retourne l'élément suivant dans l'ensemble de données ou "undef" si l'itérateur est sur le dernier élément.

number()

Ceci est un alias pour 'count' pour assurer la compatibilité descendante. Voir count.

parity()

Retourne la chaîne de caractères "even" ou "odd" pour indiquer la parité du compte d'itération courant (commençant à 1). Ceci est typiquement utilisé pour créer des tableaux rayés zébrés.

<table>
[% FOREACH name IN ['Arthur', 'Ford', 'Trillian'] -%]
  <tr class="[% loop.parity %]">
    <td>[% name %]</td>
  </tr>
[% END %]
</table>

Ceci produira la sortie suivante :

<table>
  <tr class="odd">
    <td>Arthur</td>
  </tr>
  <tr class="even">
    <td>Ford</td>
  </tr>
  <tr class="odd">
    <td>Trillian</td>
  </tr>
</table>

Vous pouvez ensuite styliser les éléments "tr.odd" et "tr.even" en utilisant CSS :

tr.odd td {
    background-color: black;
    color: white;
}
tr.even td {
    background-color: white;
    color: black;
}

odd()

Retourne une valeur booléenne (0/1) pour indiquer si le compte courant de l'itérateur (commençant à 1) est un nombre impair. Autrement dit, ceci retournera une valeur vraie pour la première itération, la troisième, la cinquième, et ainsi de suite.

even()

Retourne une valeur booléenne (0/1) pour indiquer si le compte courant de l'itérateur (commençant à 1) est un nombre pair. Autrement dit, ceci retournera une valeur vraie pour la deuxième itération, la quatrième, la sixième, et ainsi de suite.

NAME

Template::Iterator - Iterator interface for Template Toolkit

SYNOPSIS

The Template::Iterator class provides an interface to iterate over lists of items, such as those generated by the Template::Provider and Template::Grammar classes.

    use Template::Iterator;

    my $iterator = Template::Iterator->new(
        items   => [ 'apple', 'banana', 'cherry' ],
        context => $context,
        name    => 'fruits',
    );

    while ( my $item = $iterator->next ) {
        # Process $item
    }

DESCRIPTION

The Template::Iterator class provides a simple, consistent interface for iterating over a list of items. This is particularly useful within the Template Toolkit engine where it's used to manage the processing of lists within template files.

When a template directive like FOREACH is encountered, it typically creates a new Template::Iterator object to handle the iteration.

The iterator is initialized with a list of items and optionally a name. The context parameter is used to provide access to the Template Toolkit runtime environment, allowing the iterator to access variables and other context-specific information.

The next() method returns the next item in the list or undef when the iteration is complete. The current item is also made available via the stash.

PUBLIC METHODS

  • new( %args )

    Constructor for the Template::Iterator class. Accepts the following arguments:

    • items: A reference to the list of items to iterate over.

    • context: The Template::Context object.

    • name: (Optional) The name of the iterator, typically used for naming the loop variable in the stash.

    • index: (Optional) The starting index for the iteration (default is 0).

  • next()

    Returns the next item in the list. Updates the iterator's internal state and the stash with the current item and its index. Returns undef if there are no more items.

  • current()

    Returns the current item being processed by the iterator.

  • index()

    Returns the current index of the item being processed.

  • name()

    Returns the name of the iterator.

  • count()

    Returns the total number of items in the list.

  • defined()

    Returns true if the iterator has been defined (i.e., initialized).

  • empty()

    Returns true if the list of items is empty.
