Template::Modules - Modules du Template Toolkit

Modules du Template Toolkit

Cette documentation fournit un aperçu des différents modules qui composent le Template Toolkit.

Template

Le module Template est la façade du Template Toolkit pour les programmeurs Perl.

use Template;
my $tt = Template->new();
$tt->process('hello.html', message => 'Bonjour le monde');

Template::Base

Le module Template::Base implémente une classe de base dont les autres modules du Template Toolkit dérivent. Il implémente des fonctionnalités communes pour la création d'objets, le reporting d'erreurs, le débogage, etc.

Template::Config

Le module Template::Config définit la configuration du Template Toolkit pour votre système. C'est un exemple de module usine qui est responsable de l'instanciation des différents autres modules utilisés dans le Template Toolkit.

Par exemple, le module Template::Config définit la variable package $STASH qui indique quelle version de Template::Stash vous utilisez par défaut. Si vous avez choisi d'utiliser le stash XS plus rapide lors de l'installation du Template Toolkit, alors il sera défini comme suit :

$STASH = 'Template::Stash::XS';

Sinon, vous obtiendrez le stash Perl régulier :

$STASH = 'Template::Stash';

Cette approche signifie que d'autres parties du Template Toolkit n'ont pas à se soucier du stash que vous utilisez. Elles demandent simplement au module Template::Config de créer un stash du bon type.

Template::Constants

Template::Constants définit un certain nombre de constantes utilisées par le Template Toolkit.

Par exemple, le jeu de tags ":chomp" définit les constantes "CHOMP_???" qui peuvent être utilisées avec les options de configuration "PRE_CHOMP" et "POST_CHOMP".

use Template::Constants ':chomp';
my $tt = Template->new({
    PRE_CHOMP => CHOMP_COLLAPSE,
});

Template::Context

Le module Template::Context définit un contexte d'exécution dans lequel les templates sont traités. Un contexte conserve toutes les informations sur les templates, variables, plugins et autres ressources disponibles (directement ou via des objets délégués) et fournit des méthodes pour les récupérer, les stocker et effectuer diverses opérations dessus.

Template::Document

Le module Template::Document implémente un objet de template compilé. Ceci est généré par le module Template::Parser.

Template::Exception

Le module Template::Exception implémente un objet d'exception qui est utilisé pour le reporting d'erreurs d'exécution.

Template::Filters

Le module Template::Filters implémente un fournisseur de filtres. Il inclut la collection de base des filtres qui peuvent être utilisés via la directive "FILTER".

Template::Iterator

Le module Template::Iterator implémente un itérateur de données qui parcourt chaque élément d'une liste à tour de rôle. Il est utilisé par la directive "FOREACH". Dans un bloc "FOREACH", la variable "loop" fait toujours référence à l'objet itérateur courant.

[%  FOREACH item IN list;
      IF loop.first;
         # premier élément de la boucle
      ELSIF loop.last;
         # dernier élément de la boucle
      ELSE;
         # autre élément de la boucle
      END;
    END
%]

Template::Namespace::Constants

Le module Template::Namespace::Constants est utilisé en interne pour représenter des constantes. Celles-ci peuvent être résolues immédiatement au moment de la compilation d'un template.

Template::Parser

Le module Template::Parser est utilisé pour analyser un template source et le transformer en code Perl exécutable.

Template::Plugin

Le module Template::Plugin est une classe de base pour les plugins du Template Toolkit qui peuvent être chargés à la demande depuis un template via la directive "USE".

Template::Plugins

Le module Template::Plugins est le fournisseur de plugins. Il charge et prépare les plugins au fur et à mesure qu'ils sont demandés depuis un template.

Template::Provider

Le module Template::Provider est responsable du chargement, de la compilation et de la mise en cache des templates.

Template::Service

Le module Template::Service implémente une couche de service qui se trouve juste derrière le module Template, et juste devant un Template::Context. Il gère chaque requête de traitement d'un template (transmise par le module Template). Il ajoute les en-têtes et/ou pieds de page (spécifiés via les options "PRE_PROCESS" et "POST_PROCESS"), applique tout wrapper (l'option "WRAPPER") et intercepte toute erreur retournée (l'option "ERRORS").

Template::Stash

Le module Template::Stash est utilisé pour récupérer et stocker les variables de template. Il implémente toute la magie associée à l'opérateur point.

Template::Stash::XS

Le module Template::Stash::XS est une implémentation haute vitesse de Template::Stash écrite en C.

Template::Test

Le module Template::Test est utilisé pour automatiser les scripts de test du Template Toolkit.
