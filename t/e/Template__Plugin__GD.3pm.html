NOM

Template::Plugin::GD - Plugin(s) GD pour le Template Toolkit

SYNOPSIS

[% USE GD;

   # créer une image
   img = GD.image(width, height)
   # allouer des couleurs
   black = img.colorAllocate(0,   0,   0);
   red   = img.colorAllocate(255, 0,   0);
   blue  = img.colorAllocate(0,   0, 255);
   # dessiner un ovale bleu
   img.arc(50, 50, 95, 75, 0, 360, blue);
   # le remplir en rouge
   img.fill(50, 50, red);
   # sortie de l'image binaire au format PNG
   img.png | redirect('example.png');
%]

DESCRIPTION

La distribution Template-GD fournit plusieurs modules de plugin pour le Template Toolkit afin d'interfacer avec les modules GD de Lincoln Stein. Ceux-ci fournissent à leur tour une interface à la bibliothèque graphique GD de Thomas Boutell.

Ces plugins étaient distribués dans le cadre du Template Toolkit jusqu'à la version 2.15 publiée en février 2006. À ce moment-là, ils ont été extraits dans cette distribution séparée.

Pour des informations générales sur le Template Toolkit, consultez la documentation du module Template ou http://template-toolkit.org. Pour des informations sur l'utilisation des plugins, consultez Template::Plugins et "USE" dans Template::Manual::Directives.

MÉTHODES

Le module plugin GD fournit plusieurs méthodes pour créer divers autres objets GD. Mais vous devez d'abord charger le plugin GD.

[% USE GD %]

Vous pouvez ensuite appeler les objets suivants à partir de celui-ci.

image(width, height)

Crée un nouvel objet GD::Image.

[% image = GD.image(100, 200) %]

polygon()

Crée un nouvel objet GD::Polygon.

[% poly = GD.polygon;
   poly.addPt(50,0);
   poly.addPt(99,99);
   poly.addPt(0,99);
   image.filledPolygon(poly, blue);
%]

text()

Crée un nouvel objet GD::Text.

[%  text = GD.text;
    text.set_text('Some text');
%]

PLUGINS GD

Ce sont les plugins GD fournis dans cette distribution.

Template::Plugin::GD

Module frontal pour la collection de plugins GD.

Template::Plugin::GD::Image

Interface de plugin fournissant un accès direct au module GD::Image.

[% USE image = GD.Image %]

Template::Plugin::GD::Polygon

Interface de plugin fournissant un accès direct au module GD::Polygon.

[% USE poly = GD.Polygon;
   poly.addPt(50,0);
   poly.addPt(99,99);
   poly.addPt(0,99);
   image.filledPolygon(poly, blue);
%]

Template::Plugin::GD::Text

Interface de plugin fournissant un accès direct au module GD::Text.

[%  USE text = GD.Text;
    text.set_text('Some text');
%]

Template::Plugin::GD::Text::Align

Interface de plugin pour le module GD::Text::Align pour créer du texte aligné.

Template::Plugin::GD::Text::Wrap

Interface de plugin pour le module GD::Text::Wrap pour créer du texte renvoyé.

Template::Plugin::GD::Graph::area

Interface de plugin pour le module GD::Graph::area pour créer des graphiques en aires avec axes et légendes.

Template::Plugin::GD::Graph::bars3d

Interface de plugin pour le module GD::Graph::bars3d pour créer des graphiques à barres 3D avec axes et légendes.

Template::Plugin::GD::Graph::bars

Interface de plugin pour le module GD::Graph::bars pour créer des graphiques à barres avec axes et légendes.

Template::Plugin::GD::Graph::lines3d

Interface de plugin pour le module GD::Graph::lines3d pour créer des graphiques linéaires 3D avec axes et légendes.

Template::Plugin::GD::Graph::lines

Interface de plugin pour le module GD::Graph::lines pour créer des graphiques linéaires avec axes et légendes.

Template::Plugin::GD::Graph::linespoints

Interface de plugin pour le module GD::Graph::linespoints pour créer des graphiques linéaires/ponctuels avec axes et légendes

Template::Plugin::GD::Graph::mixed

Interface de plugin pour le module GD::Graph::mixed pour créer des graphiques mixtes avec axes et légendes.

Template::Plugin::GD::Graph::pie3d

Interface de plugin pour le module GD::Graph::pie3d pour créer des diagrammes circulaires 3D avec légendes.

Template::Plugin::GD::Graph::pie

Interface de plugin pour le module GD::Graph::pie pour créer des diagrammes circulaires avec légendes.

Template::Plugin::GD::Graph::points

Interface de plugin pour le module GD::Graph::points pour créer des graphiques ponctuels avec axes et légendes

Template::Plugin::GD::Constants

Fournit l'accès à diverses constantes GD.

[% USE gdc = GD.Constants;
   font = gdc.gdLargeFont
%]
