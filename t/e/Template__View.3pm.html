NOM

Template::View - vue personnalisée d'un contexte de traitement de modèle

SYNTAXE

# définir une vue
[% VIEW view
        # arguments standard
        prefix        => 'mon_',
        suffix        => '.tt2',
        notfound      => 'fichier_introuvable'
        ...
        # toute autre donnée
        title         => 'Titre de ma vue'
        other_item    => 'Données aléatoires de Joe'
        ...
%]
   # ajouter de nouvelles définitions de données, via la référence auto 'my'
   [% my.author = "$abw.name <$abw.email>" %]
   [% my.copy   = "&copy; Copyright 2000 $my.author" %]
   # définir un bloc local
   [% BLOCK header %]
   Ceci est le bloc d'en-tête, titre : [% title or my.title %]
   [% END %]
[% END %]
# accéder aux éléments de données pour la vue
[% view.title %]
[% view.other_item %]
# accéder directement aux blocs ('include_naked' option, définie par défaut)
[% view.header %]
[% view.header(title => 'Nouveau Titre') %]
# les modèles non locaux ont le préfixe/suffixe attaché
[% view.footer %]           # => [% INCLUDE mon_footer.tt2 %]
# forme plus verbeuse d'accès aux blocs
[% view.include( 'header', title => 'Le Titre de lEn-tête' ) %]
[% view.include_header( title => 'Le Titre de lEn-tête' ) %]
# forme très courte de ce qui précède ('include_naked' option, définie par défaut)
[% view.header( title => 'Le Titre de lEn-tête' ) %]
# les modèles non locaux ont le préfixe/suffixe attaché
[% view.footer %]           # => [% INCLUDE mon_footer.tt2 %]
# retour sur le modèle 'notfound' ('mon_fichier_introuvable.tt2')
# si le modèle est introuvable
[% view.include('manquant') %]
[% view.include_manquant %]
[% view.manquant %]
# print() inclut un modèle pertinent pour le type d'argument
[% view.print("du texte") %]     # type=TEXT, modèle='texte'
[% BLOCK mon_texte.tt2 %]           # 'texte' avec préfixe/suffixe
   Texte : [% item %]
[% END %]
# maintenant imprimer() une référence de hachage, mappée au modèle 'hash'
[% view.print(some_hash_ref) %]   # type=HASH, modèle='hash'
[% BLOCK mon_hash.tt2 %]           # 'hash' avec préfixe/suffixe
   clés du hash : [% item.keys.sort.join(', ')
[% END %]
# maintenant imprimer() une référence de liste, mappée au modèle 'list'
[% view.print(mon_liste_ref) %]     # type=ARRAY, modèle='list'
[% BLOCK mon_list.tt2 %]           # 'list' avec préfixe/suffixe
   liste : [% item.join(', ') %]
[% END %]
# print() mappe 'My::Object' à 'My_Object'
[% view.print(monobjet) %]
[% BLOCK mon_Mon_Objet.tt2 %]
   [% item.this %], [% item.that %]
[% END %]
# mettre à jour la table de mappage
[% view.map.ARRAY = 'mon_modele_liste' %]
[% view.map.TEXT  = 'mon_bloc_texte'    %]
# changer le préfixe, le suffixe, le nom de l'élément, etc.
[% view.prefix = 'votre_' %]
[% view.default = 'objetquelconque' %]
...

MÉTHODES

new($contexte, \%config)

Crée une nouvelle vue Template::View présentant une vue personnalisée de l'objet $contexte spécifié.

Une référence à un tableau de hachage d'options de configuration peut être passée comme second argument.

prefix
Préfixe ajouté à tous les noms de modèles. 
[% USE view(prefix => 'mon_') %]
[% view.view('foo', a => 20) %]     # => mon_foo
suffix
Suffixe ajouté à tous les noms de modèles. 
[% USE view(suffix => '.tt2') %]
[% view.view('foo', a => 20) %]     # => foo.tt2
map
Tableau de hachage mappant les types de références aux noms de modèles. La méthode print() utilise cela pour déterminer quel modèle utiliser pour présenter un élément donné. Les éléments TEXT, HASH et ARRAY utilisent par défaut 'test', 'hash' et 'list' respectivement. 
[% USE view(map => { ARRAY   => 'ma_liste',
                     HASH    => 'votre_hash',
                     Mon::Foo => 'mon_foo', } ) %]
[% view.print(texte_quelconque) %]         # => texte
[% view.print(une_liste) %]            # => ma_liste
[% view.print(un_hash) %]            # => votre_hash
[% view.print(un_foo) %]             # => mon_foo
[% BLOCK texte %]
   Texte : [% item %]
[% END %]
[% BLOCK ma_liste %]
   liste : [% item.join(', ') %]
[% END %]
[% BLOCK votre_hash %]
   clés du hash : [% item.keys.sort.join(', ')
[% END %]
[% BLOCK mon_foo %]
   Foo : [% item.this %], [% item.that %]
[% END %]
method
Nom d'une méthode que les objets passés à print() peuvent fournir pour se présenter à la vue. Si aucune entrée de mappage spécifique ne peut être trouvée pour une référence d'objet et qu'elle prend en charge la méthode (par défaut: 'present'), alors la méthode sera appelée, passant la vue comme argument. L'objet peut alors faire des rappels contre la vue pour se présenter. 
package Foo;
sub present {
    my ($self, $view) = @_;
    return "une vue normale d'un Foo\n";
}
sub debug {
    my ($self, $view) = @_;
    return "une vue de débogage d'un Foo\n";
}

Dans un modèle :

[% USE view %]
[% view.print(mon_objet_foo) %]     # une vue normale d'un Foo
[% USE view(method => 'debug') %]
[% view.print(mon_objet_foo) %]     # une vue de débogage d'un Foo
default
Modèle par défaut à utiliser si aucune entrée de mappage spécifique n'est trouvée pour un élément. 
[% USE view(default => 'mon_objet') %]
[% view.print(objref) %]            # => mon_objet

Si aucun mappage ou défaut n'est fourni, la vue tentera de construire un nom de modèle à partir de la classe de l'objet, en substituant toute séquence de caractères non alphabétiques par des traits de soulignement simples, par exemple :

# 'fubar' est un objet de classe Foo::Bar
[% view.print(fubar) %]             # => Foo_Bar

Tout préfixe et suffixe actuel sera ajouté au nom du modèle par défaut et à tout nom construit à partir de la classe de l'objet.

notfound
Modèle de repli à utiliser si un autre modèle n'est pas trouvé.
item
Nom de la variable de modèle à laquelle la méthode print() assigne l'élément courant. Par défaut 'item'. 
[% USE view %]
[% BLOCK list %]
   [% item.join(', ') %]
[% END %]
[% view.print(une_liste) %]
[% USE view(item => 'chose') %]
[% BLOCK list %]
   [% chose.join(', ') %]
[% END %]
[% view.print(une_liste) %]
view_prefix
Préfixe des méthodes qui devraient être mappées à view() par AUTOLOAD. Par défaut 'view_'. 
[% USE view %]
[% view.view_header() %]                    # => view('header')
[% USE view(view_prefix => 'montre_moi_le_' %]
[% view.montre_moi_le_header() %]             # => view('header')
view_naked
Indicateur pour déterminer si une tentative doit être faite pour mapper les noms de méthodes aux noms de modèles lorsqu'ils ne correspondent pas au préfixe_vue. Par défaut 0. 
[% USE view(view_naked => 1) %]
[% view.header() %]                 # => view('header')
