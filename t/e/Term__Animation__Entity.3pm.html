Term::Animation::Entity(3) Documentation Perl Contribuée par l'Utilisateur Term::Animation::Entity(3)

NOM

Term::Animation::Entity

SYNOPSIS

use Term::Animation::Entity;
# Constructeur
my $entity = Term::Animation::Entity->new(
    shape         => ';-)',
    position      => [ 1, 2, 3 ],
    callback_args => [ 0, 1, 0, 0 ],
);

RÉSUMÉ

Un objet sprite à utiliser avec Term::Animation

DESCRIPTION

Term::Animation::Entity est utilisé par Term::Animation pour représenter un unique sprite à l'écran.

PARAMÈTRES

name < SCALAR >
      Une chaîne identifiant de manière unique cet objet
shape < REF >
      L'art ASCII pour cet objet. Il peut être fourni comme :
                1) Une seule chaîne de texte multi-lignes (pas d'animation)
                2) Un tableau de chaînes de texte multi-lignes, où chaque
                   élément est une image d'animation unique
                3) Un tableau de tableaux 2D. Chaque élément du tableau externe
                   est une image d'animation unique.
      Si vous fournissez un tableau, chaque élément est une image d'animation.
      Si vous fournissez 1) ou 2), une seule nouvelle ligne sera supprimée
      du début de chaque chaîne. 3) est ce que le module utilise en interne.
auto_trans < BOOLEAN >
      Indique s'il faut automatiquement rendre transparents les espaces au début de chaque ligne.
      Défaut : 0
position < ARRAY_REF >
      Une liste spécifiant les coordonnées initiales x,y et z
      Défaut : [ 0, 0, 0 ]
callback < SUBROUTINE_REF >
      Routine de rappel pour cette entité. Défaut : I<move_entity()>
callback_args < REF >
      Arguments pour la routine de rappel.
curr_frame < INTEGER >
      Image d'animation pour commencer. Défaut : 0
wrap < BOOLEAN >
      Indique si cette entité doit revenir au bord de l'écran. Défaut : 0
transparent < SCALAR >
      Caractère utilisé pour indiquer la transparence. Défaut : ?
die_offscreen < BOOLEAN >
      Indique si cette entité doit être supprimée si
      elle sort de l'écran. Défaut : 0
die_entity < ENTITY >
      Spécifie une entité (réf ou nom). Lorsque l'entité nommée
      meurt, cette entité doit également mourir. Défaut : undef
die_time < INTEGER >
      L'heure à laquelle cette entité doit être supprimée. Ce
      devrait être un temps d'époque UNIX, tel que retourné
      par I<time>. Défaut : undef
die_frame < INTEGER >
      Spécifie le nombre d'images qui doivent être affichées
      avant que cette entité ne soit supprimée. Défaut : undef
death_cb < SUBROUTINE_REF >
      Routine de rappel utilisée lorsque cette entité meurt
dcb_args < REF >
      Arguments pour la routine de rappel de mort d'entité
color
      Masque de couleur. Suit le même format que 'shape'.
      Voir la section 'COULEUR' ci-dessous pour plus de détails.
default_color < SCALAR >
      Une couleur par défaut à utiliser pour l'entité. Voir la section 'COULEUR'
      pour plus de détails.
data < REF >
      Stocke des données sur cette entité. Elles ne sont pas utilisées par le module.
      Vous pouvez les utiliser pour stocker des informations d'état sur cette entité.

MÉTHODES

new
my $entity = Term::Animation::Entity->new(
    shape         => ';-)',
    position      => [ 1, 2, 3 ],
    callback_args => [ 0, 1, 0, 0 ],
);

Crée une instance Term::Animation::Entity. Voir la section PARAMÈTRES pour les détails.

physical
$entity->physical( 1 );
$state = $entity->physical();

Active ou désactive la détection de collision pour cette entité.

auto_trans
$entity->auto_trans( 1 );
$state = $entity->auto_trans();

Active ou désactive la transparence automatique pour le sprite de cette entité. Ceci n'affectera que les appels ultérieurs à shape, le sprite actuel ne sera pas modifié.

transparent
$entity->transparent( '*' );
$trans_char = $entity->transparent();

Récupère ou définit le caractère transparent pour le sprite de cette entité. Ceci n'affectera que les appels ultérieurs à shape, le sprite actuel ne sera pas modifié.

wrap
$entity->wrap( 1 );
$wrap = $entity->wrap;

Récupère ou définit le booléen qui indique si cette entité doit faire le tour lorsqu'elle atteint le bord de l'écran.

data
$entity->data( $stuff );
$data = $entity->data();

Récupère ou définit les 'données' associées à l'entité. Il doit s'agir d'un seul scalaire ou d'une seule référence. Cela peut être ce que vous voulez, il n'est pas utilisé par le module et est fourni par commodité.

name
$name = $entity->name();

Retourne le nom de l'entité.

type
$entity->type( 'this_type' );
$type = $entity->type();

Récupère ou définit le 'type' de l'entité. Le type peut être n'importe quelle chaîne et n'est pas utilisé par l'animation elle-même.

frame
$entity->frame( 3 );
$current_frame = $entity->frame();

Récupère ou définit l'image d'animation actuelle de l'entité.

width
my $width = $entity->width();

Retourne la largeur (colonnes) de l'entité.

height
my $height = $entity->height();

Retourne la hauteur (lignes) de l'entité.

depth
my $depth = $entity->depth();

Retourne la profondeur de l'entité.

size
my ($width, $height, $depth) = $entity->size();

Retourne les dimensions X / Y / Z de l'entité.

position
my ($x, $y, $z) = $entity->position();
$entity->position($x, $y, $z);

Récupère ou définit les coordonnées X / Y / Z de l'entité. Vous pouvez également accéder à chaque coordonnée individuellement.

my $x = $entity->x;
$entity->x(5);

Notez que vous devriez normalement positionner une entité en utilisant sa routine de rappel, au lieu d'appeler l'une de ces méthodes.

callback_args
$entity->callback_args( $args );
$args = $entity->callback_args();

Récupère ou définit les arguments de la routine de rappel de l'entité. Cela devrait être soit un scalaire unique, soit une référence unique.

callback
$entity->callback( \&callback_routine );
$callback_routine = $entity->callback();

Récupère ou définit la routine de rappel pour l'entité

death_cb
$entity->death_cb( \&death_callback_routine );
$death_callback_routine = $entity->death_cb();

Récupère ou définit la routine de rappel qui est appelée lorsque l'entité meurt. Réglez-la sur undef si vous ne voulez rien appeler.

die_offscreen
$entity->die_offscreen( 1 );
$die_offscreen = $entity->die_offscreen;

Récupère ou définit le drapeau qui indique si cette entité doit mourir lorsqu'elle est entièrement hors de l'écran.

die_frame
$entity->die_frame( 1 );
$die_frame = $entity->die_frame;

Récupère ou définit l'image dans laquelle cette entité doit mourir, en comptant à partir du moment où die_frame est appelé. Réglez sur undef pour désactiver.

die_time
$entity->die_time( time() + 20 );
$die_time = $entity->die_time;

Récupère ou définit l'heure à laquelle cette entité doit mourir

Term::Animation::Entity(3pm) — Perl manual page

NAME

Term::Animation::Entity - represent an animated entity

SYNOPSIS

    use Term::Animation;

    my $animation = Term::Animation->new(
        rows    => 24,
        cols    => 80,
        delay   => 0.05,
        colors  => 16,
    );

    my $entity = $animation->new_entity(
        x       => 10,
        y       => 5,
        shape   => [
            "  O  ",
            " /|\\ ",
            " / \\ ",
        ],
        callback => \&my_callback,
        name    => "player",
    );

    # ... later ...

    my $animation_cycle = $animation->animation_cycle();

ABSTRACT

A Term::Animation::Entity represents a single object within a Term::Animation.

DESCRIPTION

This class represents a single animated entity. It contains state information about the entity, such as its position, shape, color, and callback information.

The entity is created and managed by a Term::Animation object. You should not create Term::Animation::Entity objects directly.

PARAMETERS

The following parameters can be passed to new_entity() when creating an entity:

x
The starting x-coordinate of the entity.
y
The starting y-coordinate of the entity.
shape
A reference to an array of strings defining the entity's shape. Each string represents a row of the entity. The shape can be changed later using the shape() method.
color
The default color of the entity. This can be a single character (like 'R', 'G', 'B') or the full name of the color (like 'red', 'green', 'blue'). This can be changed later using the default_color() method.
callback
A reference to a subroutine that will be called during each animation cycle. This subroutine is responsible for updating the entity's state (position, shape, etc.). The callback receives two arguments: the entity object itself and the animation object. It should return a value that indicates whether the entity should be kept or removed (typically 1 to keep, 0 to remove).
name
An optional name for the entity. This can be used to retrieve the entity later from the animation object using get_entity_by_name().
die_on_collision
If set to a string which is the name of another entity, this entity will be removed from the animation when the named entity is removed. Setting to undef will disable this.
die_on_collision_time
The UNIX epoch time after which this entity should die. Set to undef to disable.
die_entity
Get or set an entity whose death will cause the death of this entity. Either an entity name or Term::Animation::Entity reference are accepted, but an entity name is always returned. Set to undef to disable.

METHODS

x
$entity->x($new_x);
$x = $entity->x();

Get or set the x-coordinate of the entity.

y
$entity->y($new_y);
$y = $entity->y();

Get or set the y-coordinate of the entity.

name
$entity->name($new_name);
$name = $entity->name();

Get or set the name of the entity.

callback
$entity->callback(\&new_callback);
$cb = $entity->callback();

Get or set the callback subroutine for the entity.

die_on_collision
$entity->die_on_collision($other_entity_name);
$other_entity_name = $entity->die_on_collision();

Get or set the name of the entity that will cause this entity to die. Set to undef to disable.

die_on_collision_time
$entity->die_on_collision_time($unix_epoch_time);
$time = $entity->die_on_collision_time();

Get or set the time (UNIX epoch time) after which this entity should die. Set to undef to disable.

die_entity
$entity->die_entity( $other_entity );
$other_entity = $entity->die_entity;

Get or set an entity whose death will cause the death of this entity. Either an entity name or Term::Animation::Entity reference are accepted, but an entity name is always returned. Set to undef to disable.

shape
$entity->shape($new_shape);

Set the sprite image for the entity. See the "shape" argument to new for details.

collisions
$collisions = $entity->collisions();

Returns a reference to a list of entities that this entity collided with during this animation cycle.

animation
$entity->animation( $anim );
$anim = $entity->animation();

Get or set the Term::Animation object that this entity is part of.

default_color
$entity->default_color( 'blue' );
$def_color = $entity->default_color();

Get or set the default color for the entity. The color can be either a single character or the full name of the color.

color_mask
$entity->color_mask( $mask );

Set the color mask for the entity. See the Term::Animation/COLOR section of Term::Animation for details.

move_entity
The default callback. You can also call this from your own callback to do the work of moving and animating the entity after you have done whatever other processing you want to do. 
sub my_callback {
  my ($entity, $animation) = @_;

  # do something here

  return $entity->move_object($animation);
}
kill
$entity->kill();

Remove this entity from the animation. This is equivilent to:

$animation->del_entity($entity);

This does not destroy the object, so you can still readd it later (or put it in a different animation) as long as you have a reference to it.

Kirk Baucom <kbaucom@schizoid.com>

NOM

Term::Animation::Entity - représente une entité animée

SYNOPIS

    use Term::Animation;

    my $animation = Term::Animation->new(
        rows    => 24,
        cols    => 80,
        delay   => 0.05,
        colors  => 16,
    );

    my $entity = $animation->new_entity(
        x       => 10,
        y       => 5,
        shape   => [
            "  O  ",
            " /|\\ ",
            " / \\ ",
        ],
        callback => \&my_callback,
        name    => "player",
    );

    # ... plus tard ...

    my $animation_cycle = $animation->animation_cycle();

ABSTRAIT

Une Term::Animation::Entity représente un objet unique au sein d'une Term::Animation.

DESCRIPTION

Cette classe représente une seule entité animée. Elle contient des informations d'état sur l'entité, telles que sa position, sa forme, sa couleur et les informations de rappel.

L'entité est créée et gérée par un objet Term::Animation. Vous ne devriez pas créer d'objets Term::Animation::Entity directement.

PARAMETRES

Les paramètres suivants peuvent être passés à new_entity() lors de la création d'une entité :

x
La coordonnée x de départ de l'entité.
y
La coordonnée y de départ de l'entité.
forme
Une référence à un tableau de chaînes définissant la forme de l'entité. Chaque chaîne représente une ligne de l'entité. La forme peut être modifiée plus tard en utilisant la méthode forme().
couleur
La couleur par défaut de l'entité. Il peut s'agir d'un seul caractère (comme 'R', 'G', 'B') ou du nom complet de la couleur (comme 'rouge', 'vert', 'bleu'). Cela peut être modifié plus tard en utilisant la méthode couleur_par_defaut().
rappel
Une référence à une sous-routine qui sera appelée lors de chaque cycle d'animation. Cette sous-routine est responsable de la mise à jour de l'état de l'entité (position, forme, etc.). Le rappel reçoit deux arguments : l'objet entité lui-même et l'objet animation. Il doit retourner une valeur indiquant si l'entité doit être conservée ou supprimée (typiquement 1 pour conserver, 0 pour supprimer).
nom
Un nom optionnel pour l'entité. Ceci peut être utilisé pour récupérer l'entité plus tard de l'objet animation en utilisant get_entity_by_name().
mourir_en_collision
Si défini sur une chaîne qui est le nom d'une autre entité, cette entité sera supprimée de l'animation lorsque l'entité nommée sera supprimée. Le définir sur undef désactivera ceci.
temps_mourir_en_collision
L'horodatage de l'époque UNIX après lequel cette entité doit mourir. Défini sur undef pour désactiver.
mourir_entite
Obtenir ou définir une entité dont la mort provoquera la mort de cette entité. Soit un nom d'entité, soit une référence Term::Animation::Entity sont acceptés, mais un nom d'entité est toujours retourné. Défini sur undef pour désactiver.

METHODES

x
$entity->x($nouvel_x);
$x = $entity->x();

Obtenir ou définir la coordonnée x de l'entité.

y
$entity->y($nouvel_y);
$y = $entity->y();

Obtenir ou définir la coordonnée y de l'entité.

nom
$entity->name($nouveau_nom);
$nom = $entity->name();

Obtenir ou définir le nom de l'entité.

rappel
$entity->callback(\&nouveau_rappel);
$cb = $entity->callback();

Obtenir ou définir la sous-routine de rappel pour l'entité.

mourir_en_collision
$entity->die_on_collision($nom_autre_entite);
$nom_autre_entite = $entity->die_on_collision();

Obtenir ou définir le nom de l'entité qui provoquera la mort de cette entité. Défini sur undef pour désactiver.

temps_mourir_en_collision
$entity->die_on_collision_time($temps_epoque_unix);
$temps = $entity->die_on_collision_time();

Obtenir ou définir le temps (temps époque UNIX) après lequel cette entité devrait mourir. Défini sur undef pour désactiver.

mourir_entite
$entity->die_entity( $autre_entite );
$autre_entite = $entity->die_entity;

Obtenir ou définir une entité dont la mort provoquera la mort de cette entité. Soit un nom d'entité, soit une référence Term::Animation::Entity sont acceptés, mais un nom d'entité est toujours retourné. Défini sur undef pour désactiver.

forme
$entity->shape($nouvelle_forme);

Définir l'image sprite pour l'entité. Voir l'argument "forme" pour new pour les détails.

collisions
$collisions = $entity->collisions();

Retourne une référence vers une liste d'entités avec lesquelles cette entité est entrée en collision pendant ce cycle d'animation.

animation
$entity->animation( $anim );
$anim = $entity->animation();

Obtenir ou définir l'objet Term::Animation dont cette entité fait partie.

couleur_par_defaut
$entity->default_color( 'bleu' );
$couleur_def = $entity->default_color();

Obtenir ou définir la couleur par défaut pour l'entité. La couleur peut être soit un seul caractère, soit le nom complet de la couleur.

masque_couleur
$entity->color_mask( $masque );

Définir le masque de couleur pour l'entité. Voir la section Term::Animation/COLOR de Term::Animation pour les détails.

deplacer_entite
Le rappel par défaut. Vous pouvez également l'appeler depuis votre propre rappel pour effectuer le travail de déplacement et d'animation de l'entité après avoir effectué tout autre traitement que vous souhaitez faire. 
sub my_callback {
  my ($entity, $animation) = @_;

  # faire quelque chose ici

  return $entity->move_object($animation);
}
tuer
$entity->kill();

Supprimer cette entité de l'animation. Ceci est équivalent à:

$animation->del_entity($entity);

Ceci ne détruit pas l'objet, vous pouvez donc toujours le réajouter plus tard (ou le placer dans une autre animation) tant que vous avez une référence à celui-ci.
