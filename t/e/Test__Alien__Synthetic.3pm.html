Test::Alien::Synthetic(3) Documentation Perl fournie par l'utilisateur Test::Alien::Synthetic(3)

NOM

Test::Alien::Synthetic - Un objet fantôme pour les tests

VERSION

version 2.84

SYNOPSIS

use Test2::V0;
use Test::Alien;

my $alien = synthetic {
  cflags => '-I/foo/bar/include',
  libs   => '-L/foo/bar/lib -lbaz',
};

alien_ok $alien;

done_testing;

DESCRIPTION

Cette classe est utilisée pour modéliser une classe Alien synthétique qui implémente l'interface minimale Alien::Base requise par Test::Alien.

Cela peut être utile si vous avez une distribution Alien non basée sur Alien::Base que vous devez tester.

NOTE: Le nom de cette classe peut changer à l'avenir, donc ne vous référez pas directement à ce nom de classe. Créez plutôt des instances de cette classe en utilisant la fonction Test::Alien#synthetic.

ATTRIBUTS

cflags

Chaîne contenant les indicateurs du compilateur

cflags_static

Chaîne contenant les indicateurs du compilateur statiques

libs

Chaîne contenant les indicateurs de l'éditeur de liens et des bibliothèques

libs_static

Chaîne contenant les indicateurs statiques de l'éditeur de liens et des bibliothèques

dynamic_libs

Référence de liste contenant les bibliothèques dynamiques.

bin_dir

Répertoire des binaires d'outils.

runtime_prop

Propriétés d'exécution.

EXEMPLE

Voici un exemple complet utilisant Alien::Libarchive, qui est une distribution Alien non basée sur Alien::Base.

use strict;
use warnings;
use Test2::V0;
use Test::Alien;
use Alien::Libarchive;

my $real = Alien::Libarchive->new;
my $alien = synthetic {
  cflags       => scalar $real->cflags,
  libs         => scalar $real->libs,
  dynamic_libs => [$real->dlls],
};

alien_ok $alien;

xs_ok do { local $/; <DATA> }, with_subtest {
  my($module) = @_;
  my $ptr = $module->archive_read_new;
  like $ptr, qr{^[0-9]+$};
  $module->archive_read_free($ptr);
};

ffi_ok { symbols => [qw( archive_read_new )] }, with_subtest {
  my($ffi) = @_;
  my $new  = $ffi->function(archive_read_new => [] => 'opaque');
  my $free = $ffi->function(archive_read_close => ['opaque'] => 'void');
  my $ptr = $new->();
  like $ptr, qr{^[0-9]+$};
  $free->($ptr);
};

done_testing;
