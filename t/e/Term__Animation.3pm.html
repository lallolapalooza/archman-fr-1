NOM

Term::Animation - Framework pour les animations d'art ASCII

SYNOPIS

use Term::Animation;
# Constructeur
$anim = Term::Animation->new();
$anim = Term::Animation->new($curses_window);

ABSTRAIT

Un framework pour produire des animations d'art ASCII.

DESCRIPTION

Ce module fournit un framework pour produire des animations d'art ASCII. Chaque "sprite" d'art ASCII se voit attribuer une ou plusieurs images, et est placé dans l'animation en tant qu'"objet d'animation". Un objet d'animation peut avoir une routine de rappel qui contrôle la position et l'image de l'objet.

Si le constructeur ne reçoit aucun argument, il suppose qu'il fonctionne en plein écran et se comporte comme tel. Alternativement, il peut accepter une fenêtre curses (créée avec l'appel newwin de Curses) comme argument, et sera dessiné dans cette fenêtre.

EXEMPLES

Cet exemple déplace un petit objet de gauche à droite.

use Term::Animation;
use Curses;
$anim = Term::Animation->new();
# définit le délai pour getch
halfdelay(2);
# crée une forme simple que nous pouvons déplacer
$shape = "<=O=>";
# transforme notre forme en objet d'animation
$anim->new_entity(
             shape         => $shape,        # objet forme
             position      => [3, 7, 10],    # ligne / colonne / profondeur
             callback_args => [1, 0, 0, 0],  # la routine de rappel par défaut
                                             # prend une liste de deltas x,y,z,frame
             wrap          => 1              # active le retour à la ligne de l'écran
);
# boucle d'animation
while(1) {
  # exécute et affiche une image d'animation
  $anim->animate();
  # utilise getch pour contrôler le taux d'images, et obtenir l'entrée en même temps.
  # (ce n'est pas une bonne idée si vous attendez beaucoup d'entrées)
  my $input = getch();
  if($input eq 'q') { last; }
}
# termine l'animation proprement, pour éviter que le terminal de l'utilisateur ne soit ruiné
$anim->end();

Cet exemple illustre comment dessiner votre animation dans une fenêtre curses existante.

use Term::Animation;
use Curses;
# Term::Animation n'appellera pas initscr s'il reçoit une fenêtre
initscr();
$win = newwin(5,10,8,7);
$anim = Term::Animation->new($win);

Tout le reste serait identique à l'exemple précédent.

MÉTHODES

new
$anim = Term::Animation->new();
$anim = Term::Animation->new($curses_window);

Le constructeur. Peut éventuellement accepter une fenêtre curses existante dans laquelle dessiner.

new_entity
$anim->new_entity(
      shape         => $shape,
      position      => [ 1, 2, 3 ],
      callback_args => [ 1, 0, 0 ]
);

Crée un objet Term::Animation::Entity et l'ajoute à l'animation. C'est identique à :

my $entity = Term::Animation::Entity->new(...);
$anim->add_entity($entity);

Voir Term::Animation::Entity/PARAMETERS et Term::Animation::Entity/new pour les détails sur la manière d'appeler cette méthode.

color_name
$name = $anim->color_name( $color );

Renvoie le nom complet d'une couleur, étant donné un nom complet ou une abréviation de caractère.

color_id
$id = $anim->color_id( $color );

Renvoie l'abréviation de caractère pour une couleur, étant donné un nom complet ou une abréviation.

is_valid_color
my $is_valid = $anim->is_valid_color($color_name);

Renvoie vrai si le texte fourni est un nom de couleur valide ('blue') ou un identifiant de couleur valide ('b').

color
my $state = $anim->color();
$anim->color($new_state);

Active ou désactive la couleur ANSI. Ceci doit être appelé immédiatement après la création de l'objet d'animation si vous souhaitez de la couleur, car l'appel à start_color doit être effectué immédiatement. Vous pouvez ensuite activer et désactiver la couleur quand vous le souhaitez.

background
$anim->background( $color );

Change la couleur de fond. La couleur de fond par défaut est le noir. Vous ne pouvez avoir qu'une seule couleur de fond pour l'ensemble de la fenêtre curses utilisée par l'animation.

animate
$anim->animate();

Exécute une passe d'animation. Effectue tous les rappels, détecte les collisions et met à jour l'écran.

track_framerate
$anim->track_framerate(1);
$tracking_framerate = $anim->track_framerate();

Obtient ou définit le drapeau indiquant si le module doit suivre le taux d'images de l'animation. Ceci est activé par défaut.

framerate
$frames_per_second = $anim->framerate();

Renvoie le nombre approximatif d'images affichées par seconde, tel qu'indiqué par les appels à la méthode animate.

screen_size
my ($width, $height, $assumed_size) = $anim->screen_size();

Renvoie la largeur et la hauteur de l'écran. La troisième valeur renvoyée est un booléen indiquant si la taille par défaut de l'écran a été utilisée, car la taille n'a pas pu être déterminée.

update_term_size
$anim->update_term_size();

Appelez cette méthode si vous suspectez que la taille du terminal a changé (par exemple, si vous recevez un signal SIGWINCH). Appelez remove_all_entities après cette méthode si vous souhaitez recréer votre animation à partir de zéro.

add_entity
$anim->add_entity( $entity1, $entity2, $entity3 );

Ajoute une ou plusieurs entités d'animation à l'animation.

del_entity
$anim->del_entity( $entity_name );
$anim->del_entity( $entity_ref );

Supprime une entité de l'animation. Un nom d'entité ou une référence à l'entité est accepté.

remove_all_entities
$anim->remove_all_entities();

Supprime toutes les entités d'animation. Utile si vous souhaitez redémarrer l'animation (par exemple, après un changement de taille d'écran).

entity_count
$number_of_entities = $anim->entity_count();

Renvoie le nombre d'entités dans l'animation.

get_entities
$entity_list = $anim->get_entities();

Renvoie une référence à une liste de toutes les entités de l'animation.

get_entities_of_type
$entity_list = $anim->get_entities_of_type( $type );

Renvoie une référence à une liste de toutes les entités de l'animation qui ont le type spécifié.

is_living
my $is_living = $anim->is_living( $entity );

Renvoie 1 si le nom ou la référence de l'entité est dans l'animation et n'est pas planifiée pour être supprimée. Renvoie 0 sinon.

entity
$entity_ref = $anim->entity( $entity_name );

NOM

Term::Animation - créer des animations dans un terminal

SYNOPIS

    use Term::Animation;

    # Créer un nouvel objet d'animation
    my $anim = Term::Animation->new(
        lines_per_frame => 5, # 5 lignes par image
        animation_delay => 0.1, # 0.1 seconde entre chaque image
        full_screen     => 1, # utiliser tout l'écran
    );

    # Créer une entité animée
    my $entity = $anim->new_entity(
        name          => "MonEntite",
        shape         => [ "Frame1", "Frame2" ], # Forme de l'entité
        position      => [ 5, 10, 0 ], # X, Y, Z
        callback      => \&mon_callback, # routine de rappel personnalisée
        callback_args => [ "argument1", "argument2" ], # arguments pour la routine de rappel
    );

    # Lancer l'animation
    $anim->animate();

    # Arrêter l'animation et restaurer le terminal
    $anim->end();

RÉSUMÉ

Ce module vous permet de créer des animations complexes dans le terminal en utilisant le module Curses.

DESCRIPTION

Term::Animation est une classe qui vous permet de gérer des animations complexes dans le terminal. Elle utilise le module Curses de Perl pour contrôler l'affichage et les mouvements des entités à l'écran. Vous pouvez définir plusieurs entités, chacune avec sa propre forme, position, et comportement (via des routines de rappel).

EXEMPLES

Pour des exemples d'utilisation, voir la section des méthodes ci-dessous.

MÉTHODES

new( %OPTIONS )
my $anim = Term::Animation->new(
        lines_per_frame => 5,
        animation_delay => 0.1,
        full_screen     => 1,
        # ... autres options
    );

Crée et initialise un nouvel objet Term::Animation. Les options disponibles sont :

  • lines_per_frame : Le nombre de lignes à afficher pour chaque image de l'animation. Par défaut, 1.
  • animation_delay : Le délai en secondes entre chaque image de l'animation. Par défaut, 0.1.
  • full_screen : Si défini à vrai, l'animation utilisera tout l'écran et restaurera le terminal à la fin. Si défini à faux (ou si une fenêtre Curses existante est passée au constructeur), l'animation sera dessinée dans la zone spécifiée de la fenêtre existante. Par défaut, vrai.
  • window : Une référence vers un objet Curses existant. Si non spécifié, une nouvelle fenêtre sera créée.
  • color_pairs : Le nombre de paires de couleurs disponibles. Par défaut, 0.
new_entity( %OPTIONS )
my $entity = $anim->new_entity(
        name          => "MonEntite",
        shape         => [ "Frame1", "Frame2" ],
        position      => [ 5, 10, 0 ],
        callback      => \&mon_callback,
        callback_args => [ "argument1", "argument2" ],
        color         => $mask,
        default_color => "BLUE",
    );

Crée une nouvelle entité animée. Les options disponibles sont :

  • name : Un nom unique pour l'entité.
  • shape : Une référence à un tableau contenant les différentes formes (chaînes de caractères multilignes) de l'animation de l'entité.
  • position : Un tableau contenant les coordonnées X, Y et Z initiales de l'entité.
  • callback : Un pointeur vers une sous-routine qui sera appelée à chaque image pour déterminer le comportement de l'entité. Si non spécifié, la routine par défaut move_entity sera utilisée.
  • callback_args : Une référence à un tableau contenant les arguments à passer à la routine de rappel. Ces arguments peuvent être utilisés pour stocker l'état de l'entité entre les appels de rappel.
  • color : Un masque de couleurs pour spécifier les couleurs de l'entité. Voir la section COLOR pour plus de détails.
  • default_color : La couleur par défaut pour l'entité. Voir la section COLOR pour plus de détails.

Retourne un objet représentant l'entité créée.

animate
$anim->animate();

Démarre la boucle principale de l'animation. Cette méthode bloque jusqu'à ce que l'animation soit terminée ou interrompue.

get_entity( $name )
my $entity = $anim->get_entity("MonEntite");

Retourne une référence à l'entité portant le nom spécifié. Retourne undef si aucune entité avec ce nom n'est trouvée.

update_term_size
$anim->update_term_size();

Met à jour la taille de la fenêtre du terminal. Ceci est utile si la taille du terminal a changé pendant l'exécution de l'animation. Il est recommandé d'appeler redraw_screen après avoir appelé cette méthode.

width
$width = $anim->width();

Retourne la largeur de l'écran.

height
$height = $anim->height();

Retourne la hauteur de l'écran.

size()
$size = $anim->size();

Retourne le nombre de caractères dans la fenêtre curses (largeur * hauteur).

redraw_screen
$anim->redraw_screen();

Efface tout de l'écran et redessine ce qui devrait y être. Ceci devrait être appelé après update_term_size, ou si l'utilisateur indique que l'écran doit être redessiné pour supprimer les artefacts.

gen_path
# gen_path (x,y,z, x,y,z, [ pattern_frames ], [ etapes ])
$anim->gen_path( $x1, $y1, $z1, $x2, $y2, $z2, [ 1, 2, 0, 2 ], 'longest' );

Étant donné les points de départ et d'arrivée, cela retournera un chemin que l'entité pourra suivre et qui pourra être donné à la routine de rappel par défaut, move_entity. Le premier ensemble de coordonnées x,y,z est le point de départ de l'entité, le second ensemble est le point d'arrivée.

Vous pouvez éventuellement fournir une liste d'images à parcourir. La liste sera répétée autant de fois que nécessaire pour terminer le chemin. Si aucune liste d'images n'est fournie, seule la première image sera utilisée.

Vous pouvez également demander le nombre d'étapes que l'entité doit effectuer pour terminer le chemin. La valeur par défaut est 'shortest'. Les arguments valides sont :
longest La plus grande distance entre X et Y
shortest La plus petite distance entre X et Y
X,Y ou Z La distance X, Y ou Z
<nombre> Spécifie explicitement le nombre d'étapes à effectuer

end
$anim->end();

Exécute la fonction Curses endwin pour restaurer votre terminal à son mode normal. Ceci est appelé automatiquement lorsque l'objet est détruit si l'animation est en cours d'exécution en plein écran (si vous n'avez pas passé une fenêtre Curses existante au constructeur).

ROUTINES DE RAPPEL

Les routines de rappel pour toutes les entités sont appelées à chaque fois que animate est appelée. Une routine de rappel par défaut est fournie, move_entity, qui est suffisante pour la plupart des mouvements de base. Si vous souhaitez créer une entité qui présente un comportement plus complexe, vous devrez écrire une routine de rappel personnalisée pour elle.

Les routines de rappel prennent deux arguments, une référence vers l'objet Term::Animation::Entity sur lequel elles doivent agir, et une référence vers l'instance Term::Animation qui les a appelées. Tous les arguments nécessaires pour indiquer à la routine de rappel quoi faire avec l'objet, ou tout état qui doit être maintenu, doivent être placés dans l'élément callback_args de l'objet. callback_args est uniquement référencé par la routine de rappel, et peut donc contenir toute structure de données qui vous semble utile.

Voici un exemple de routine de rappel personnalisée qui fera bouger une entité aléatoirement sur l'écran :

sub random_movement {
    my ($entity, $anim) = @_;
    # obtenir la position actuelle de l'entité
    my ($x, $y, $z) = $entity->position();
    # nous utiliserons callback_args pour stocker le dernier axe sur lequel nous avons bougé
    my $last_move = $entity->callback_args();
    # si nous avons bougé en x la dernière fois, bougeons en y cette fois
    if($last_move eq 'x') {
        $entity->callback_args('y');
        # bouge de -1, 0 ou 1
        $y += int(rand(3)) - 1; 
    } else {
        $entity->callback_args('x');
        $x += int(rand(3)) - 1; 
    }
    # retourne les coordonnées x,y,z absolues vers lesquelles se déplacer
    return ($x, $y, $z);
}

La valeur de retour de votre routine de rappel doit être de la forme :

return ($x, $y, $z, $frame)

$x, $y et $z représentent les coordonnées X, Y et Z vers lesquelles l'objet doit se déplacer. $frame est le numéro de l'image que l'objet doit afficher, s'il a plusieurs images d'animation. Toutes les valeurs qui ne sont pas spécifiées ou sont undef resteront inchangées.

Vous pouvez également appeler la routine de rappel par défaut depuis votre routine de rappel, si vous souhaitez qu'elle gère le mouvement pour vous. Par exemple, si votre routine de rappel est simplement utilisée pour décider quand une entité doit mourir :

sub wait_for_file {
    my ($entity, $anim) = @_;
    # tuer cette entité si un certain fichier apparaît
    if(-e "/path/to/file") {
        $entity->kill();
        return();
    }
    # utiliser la routine de rappel par défaut pour gérer le mouvement réel
    return $entity->move_entity($anim);
}

Si vous utilisez ceci, soyez conscient que move_entity repose sur callback_args, vous ne pouvez donc pas l'utiliser pour stocker vos propres données arbitraires.

COULEUR

La couleur ANSI est disponible pour les terminaux qui la prennent en charge. Une seule couleur d'arrière-plan peut être utilisée pour la fenêtre (cela aurait un très mauvais rendu dans la plupart des cas de toute façon). Les couleurs pour les entités sont spécifiées en utilisant un 'masque' qui indique la couleur pour chaque caractère. Par exemple, supposons que nous ayons une seule image d'un oiseau :

$bird = q#
---. .-. .---
  --\'v'/--
     \ /
     " "
#;

Pour indiquer les couleurs que vous souhaitez utiliser pour l'oiseau, créez un masque correspondant, avec la première lettre de chaque couleur à la position appropriée (sauf le noir, qui est 'k'). Passez ce masque comme paramètre color.

$mask = q#
BBBB BBB BBBB
  BBBWYWBBB
     B B
     Y Y
#;

Lors de la spécification d'une couleur, l'utilisation de majuscules indique que la couleur doit être en gras. Ainsi, 'BLUE' ou 'B' signifie bleu en gras, et 'blue' ou 'b' signifie bleu non gras. 'Blue' signifie que vous obtenez un message d'erreur.

Vous pouvez également fournir une couleur par défaut avec le paramètre default_color. Cette couleur sera utilisée pour tout caractère qui n'a pas d'entrée dans le masque. Si vous voulez que toute l'entité soit d'une seule couleur, vous pouvez simplement fournir une couleur par défaut sans masque.

Les couleurs disponibles sont : red, green, blue, cyan, magenta, yellow, black et white.

Voici un exemple d'appel à build_object pour l'oiseau ci-dessus.

$anim->new_entity (
          name              => "Bird",
          shape             => $bird,
          position          => [ 5, 8, 7 ],
          callback_args     => [ 1, 2, 0, 0 ],
          color             => $mask,
          default_color     => "BLUE"
);
