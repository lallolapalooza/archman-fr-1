Test2::Event::Generic(3perl) Guide du programmeur Perl Test2::Event::Generic(3perl)

NOM

Test2::Event::Generic - Type d'événement générique.

DESCRIPTION

Il s'agit d'un événement générique qui vous permet de personnaliser tous les champs de l'API des événements. Ceci est utile si vous avez besoin d'un type d'événement personnalisé qui n'a pas de sens en tant que sous-classe d'événement réutilisable publiée.

SYNTAXE

use Test2::API qw/context/;
sub send_custom_fail {
    my $ctx = shift;
    $ctx->send_event('Generic', causes_fail => 1, summary => 'Le ciel nous tombe sur la tête');
    $ctx->release;
}
send_custom_fail();

MÉTHODES

$e->facet_data($data)
$data = $e->facet_data
Obtenir ou définir les données de facette (voir Test2::Event). Si aucune donnée de facette n'est définie, "Test2::Event->facet_data" sera appelée pour produire des facettes à partir des autres données.
$e->callback($hub)
Appeler la fonction de rappel personnalisée si elle est définie, sinon cela ne fait rien.
$e->set_callback(sub { ... })
Définir la fonction de rappel personnalisée. La fonction de rappel personnalisée doit être un coderef. Le premier argument de votre fonction de rappel sera l'événement lui-même, le second sera le Test2::Event::Hub qui utilise la fonction de rappel.
$bool = $e->causes_fail
$e->set_causes_fail($bool)
Obtenir/définir l'attribut "causes_fail". Il vaut par défaut 0.
$bool = $e->diagnostics
$e->set_diagnostics($bool)
Obtenir/définir l'attribut "diagnostics". Il vaut par défaut 0.
$bool_or_undef = $e->global
@bool_or_empty = $e->global
$e->set_global($bool_or_undef)
Obtenir/définir l'attribut "diagnostics". Il vaut par défaut une liste vide qui est indéfinie en contexte scalaire.
$bool = $e->increments_count
$e->set_increments_count($bool)
Obtenir/définir l'attribut "increments_count". Il vaut par défaut 0.
$bool = $e->no_display
$e->set_no_display($bool)
Obtenir/définir l'attribut "no_display". Il vaut par défaut 0.
@plan = $e->sets_plan
Obtenir le plan si cet événement en définit un. Le plan est une liste allant jusqu'à 3 éléments : "($count, $directive, $reason)". $count doit être défini, les autres peuvent être indéfinis, ou peuvent ne pas exister du tout.
$e->set_sets_plan(\@plan)
Définir le plan. Vous devez passer un tableau avec jusqu'à 3 éléments.
$summary = $e->summary
$e->set_summary($summary_or_undef)
Obtenir/définir le résumé. Il vaut par défaut le nom du paquet d'événement 'Test2::Event::Generic'. Vous pouvez le définir à n'importe quelle valeur. Définir cela à "undef" le réinitialisera à la valeur par défaut.
$int_or_undef = $e->terminate
@int_or_empty = $e->terminate
$e->set_terminate($int_or_undef)
Ceci obtiendra/définira l'attribut "terminate". Il vaut par défaut indéfini en contexte scalaire, ou une liste vide en contexte de liste. Le définir à indéfini le supprimera complètement. Il doit être défini à un entier positif (0 ou plus).
