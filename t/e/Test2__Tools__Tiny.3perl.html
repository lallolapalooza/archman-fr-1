Test2::Tools::Tiny(3perl) Guide du programmeur Perl Test2::Tools::Tiny(3perl)

NOM

Test2::Tools::Tiny - Petit ensemble d'outils pour les âmes malchanceuses qui ne peuvent pas utiliser Test2::Suite.

DESCRIPTION

Vous devriez vraiment regarder Test2::Suite. Ce paquet contient quelques outils essentiels très basiques implémentés en utilisant Test2. Il n'existe que pour que Test2 et d'autres outils requis par Test2::Suite puissent être testés. C'est le paquet que Test2 utilise pour se tester lui-même.

UTILISER Test2::Suite À LA PLACE

Utilisez Test2::Suite si c'est possible.

EXPORTATIONS

ok($bool, $name)
ok($bool, $name, @diag)
Exécute une assertion simple.
is($got, $want, $name)
is($got, $want, $name, @diag)
Affirme que 2 chaînes sont identiques.
isnt($got, $do_not_want, $name)
isnt($got, $do_not_want, $name, @diag)
Affirme que 2 chaînes ne sont pas identiques.
like($got, $regex, $name)
like($got, $regex, $name, @diag)
Vérifie que la chaîne d'entrée correspond à l'expression régulière.
unlike($got, $regex, $name)
unlike($got, $regex, $name, @diag)
Vérifie que la chaîne d'entrée ne correspond pas à l'expression régulière.
is_deeply($got, $want, $name)
is_deeply($got, $want, $name, @diag)
Compare 2 structures de données. Veuillez noter qu'il s'agit d'une implémentation BASIQUE qui compare la sortie de Data::Dumper aux deux structures.
diag($msg)
Émet un message de diagnostic vers STDERR.
note($msg)
Émet un message de diagnostic vers STDOUT.
skip_all($reason)
Ignore tous les tests.
todo $reason => sub { ... }
Exécute un bloc en mode TODO.
plan($count)
Définit le plan.
done_testing()
Définit le plan au nombre actuel de tests.
$warnings = warnings { ... }
Capture un tableau d'avertissements provenant du bloc.
$exception = exception { ... }
Capture une exception.
tests $name => sub { ... }
Exécute un sous-test.
$output = capture { ... }
Capture la sortie STDOUT et STDERR.

Le résultat ressemble à ceci :

{
    STDOUT => "...",
    STDERR => "...",
}
