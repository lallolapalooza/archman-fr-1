NOM

Template::Plugin::GD::Graph::pie3d - Créer des diagrammes circulaires 3D avec légendes

SYNTAXE

[% USE g = GD.Graph.pie3d(x_size, y_size); %]

EXEMPLES

[% FILTER null;
    data = [
        ["1er","2ème","3ème","4ème","5ème","6ème"],
        [    4,    2,    3,    4,    3,  3.5]
    ];
    USE my_graph = GD.Graph.pie3d( 250, 200 );
    my_graph.set(
            title => 'Un diagramme circulaire',
            label => 'Étiquette',
            axislabelclr => 'black',
            pie_height => 36,
            transparent => 0,
    );
    my_graph.plot(data).png | stdout(1);
   END;
-%]

DESCRIPTION

Le plugin GD.Graph.pie3d fournit une interface à la classe GD::Graph::pie3d définie par le module GD::Graph. Il permet de tracer un jeu de données (x,y) sous forme de diagramme circulaire 3D. Les valeurs x sont typiquement des chaînes de caractères.

Notez que GD::Graph::pie produit déjà un effet 3D, donc GD::Graph::pie3d n'est qu'un wrapper autour de GD::Graph::pie. De même, le plugin GD.Graph.pie3d est effectivement le même que le plugin GD.Graph.pie.

Voir GD::Graph3d pour plus de détails.
