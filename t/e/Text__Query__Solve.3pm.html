NOM

Text::Query::Solve - Classe de base pour la résolution de requêtes

SYNOPIS

package Text::Query::SolveSource;
use Text::Query::Parse;

use vars qw(@ISA);
@ISA = qw(Text::Query::Solve);

DESCRIPTION

Ce module fournit une classe de base virtuelle pour la résolution de requêtes.

Il définit les méthodes "match" et "matchscalar" qui sont appelées par l'objet "Text::Query" pour appliquer une requête sur une source de données.

MÉTHODES

match (EXPR [TARGET])
Si "TARGET" est un scalaire, "match" renvoie une valeur vraie si la source de données spécifiée par "TARGET" correspond à l'expression de requête "EXPR". Si "TARGET" n'est pas donné, la correspondance est faite avec $_.

Si "TARGET" est un tableau, "match" renvoie une liste (éventuellement vide) de tous les éléments correspondants. Si les éléments du tableau sont des références à des sous-tableaux, la correspondance est faite avec le premier élément de chaque sous-tableau. Cela permet d'associer des informations arbitraires (par exemple, des noms de fichiers) à chaque source de données à comparer.

Si "TARGET" est une référence à un tableau, "match" renvoie une référence à une liste (éventuellement vide) de tous les éléments correspondants.

matchscalar (EXPR [TARGET])
Se comporte comme "MATCH" lorsque "TARGET" est un scalaire ou n'est pas donné.
