NOM

Test::Mock::Guard - Bibliothèque de tests de mock simple utilisant RAII.

SYNOPSIS

use Test::More;
use Test::Mock::Guard qw(mock_guard);
package Some::Class;
sub new { bless {} => shift }
sub foo { "foo" }
sub bar { 1; }
package main;
{
    my $guard = mock_guard( 'Some::Class', { foo => sub { "bar" }, bar => 10 } );
    my $obj = Some::Class->new;
    is( $obj->foo, "bar" );
    is( $obj->bar, 10 );
}
my $obj = Some::Class->new;
is( $obj->foo, "foo" );
is( $obj->bar, 1 );
done_testing;

DESCRIPTION

Test::Mock::Guard est une bibliothèque de tests de mock utilisant RAII. Ce module est capable de modifier le comportement des méthodes pour chaque portée. Voir le code exemple du SYNOPSIS.

FONCTION EXPORTÉE

mock_guard( @class_defs )

@class_defs a le format suivant.

clé
Nom de la classe ou objet à mocker.
valeur
Référence de hachage. Les clés sont les noms des méthodes ; les valeurs sont des références de code ou des scalaires. Si la valeur est une référence de code, elle est utilisée comme méthode. Si la valeur est un scalaire, la méthode retournera la valeur spécifiée.

Vous pouvez mocker des méthodes d'instance ainsi que des méthodes de classe (cette fonctionnalité a été fournie par cho45) :

use Test::More;
use Test::Mock::Guard qw(mock_guard);
package Some::Class;
sub new { bless {} => shift }
sub foo { "foo" }
package main;
my $obj1 = Some::Class->new;
my $obj2 = Some::Class->new;
{
    my $obj2 = Some::Class->new;
    my $guard = mock_guard( $obj2, { foo => sub { "bar" } } );
    is ($obj1->foo, "foo", "obj1 n'a pas changé" );
    is( $obj2->foo, "bar", "obj2 est mocké" );
}
is( $obj1->foo, "foo", "obj1" );
is( $obj2->foo, "foo", "obj2" );
done_testing;

MÉTHODES

new( @class_defs )

Voir la définition de "mock_guard".

nombre_d_appels( $nom_de_classe_ou_objet, $nom_de_méthode )

Retourne le nombre d'appels de $nom_de_méthode sur $nom_de_classe_ou_objet.
