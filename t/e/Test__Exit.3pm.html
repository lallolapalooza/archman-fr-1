NOM

Test::Exit - Tester que du code appelle exit() sans terminer les tests

VERSION

version 0.11

SYNOPSIS

use Test::More tests => 4;
use Test::Exit;

is exit_code { exit 75; }, 75, "procmail not found";
exits_ok { exit 1; } "exiting exits";
never_exits_ok { print "Hi!"; } "not exiting doesn't exit"l
exits_zero { exit 0; } "exited with success";
exits_nonzero { exit 42; } "exited with failure";

DESCRIPTION

Test::Exit fournit des outils simples pour tester du code qui pourrait appeler exit(), en vous fournissant le code de statut sans quitter le fichier de test.

Le seul critère testé est que le code fourni appelle ou n'appelle pas exit(). Si le code lève une exception, l'exception sera propagée et vous devrez la gérer vous-même. die() n'est pas considéré comme un exit() pour ces tests.

Contrairement aux versions précédentes de ce module, la version actuelle n'utilise pas d'exceptions pour effectuer son travail, donc même si vous appelez exit() à l'intérieur d'un "eval", tout devrait fonctionner.

FONCTIONS

exit_code

Exécute le code donné. Si le code appelle exit(), alors "exit_code" retournera un nombre, qui est le statut avec lequel exit() serait sorti. Si le code n'appelle jamais exit(), retourne "undef". C'est l'interface similaire à Test::Fatal. Toutes les autres fonctions sont des enveloppes pour celle-ci, conservées à des fins de compatibilité.

exits_ok

Teste que le code fourni appelle exit() à un moment donné.

exits_nonzero

Teste que le code fourni appelle exit() avec une valeur non nulle.

exits_zero

Teste que le code fourni appelle exit() avec une valeur nulle (succès).

never_exits_ok

Teste que le code fourni se termine sans appeler exit().
