NOM

Template::Plugin::Image - Plugin pour accéder aux dimensions des images

SYNTAXE

[% USE Image(filename) %]
[% Image.width %]
[% Image.height %]
[% Image.size.join(', ') %]
[% Image.attr %]
[% Image.tag %]

DESCRIPTION

Ce plugin fournit une interface pour les modules Image::Info ou Image::Size afin de déterminer les dimensions des fichiers images.

Vous pouvez spécifier le nom du plugin comme '"Image"' ou '"image"'. L'objet plugin créé aura le même nom. Le nom du fichier image doit être spécifié comme argument positionnel ou nommé.

[% # tous ces exemples sont valides, faites votre choix %]
[% USE Image('foo.gif') %]
[% USE image('bar.gif') %]
[% USE Image 'ping.gif' %]
[% USE image(name='baz.gif') %]
[% USE Image name='pong.gif' %]

Un paramètre '"root"' peut être utilisé pour spécifier l'emplacement du fichier image :

[% USE Image(root='/path/to/root', name='images/home.png') %]
# chemin du fichier: /path/to/root/images/home.png
# src: images/home.png

Dans les cas où le chemin du fichier et l'URL de l'image ne correspondent pas, spécifiez-les directement :

[% USE Image(file='/path/to/home.png', name='/images/home.png') %]

Le paramètre '"alt"' peut être utilisé pour spécifier un texte alternatif pour l'image, utile pour la construction d'une balise XHTML (voir la méthode tag() ci-dessous).

[% USE Image('home.png', alt="Accueil") %]

Vous pouvez également fournir un nom alternatif pour l'objet plugin '"Image"'.

[% USE img1 = image 'foo.gif' %]
[% USE img2 = image 'bar.gif' %]

La méthode '"name"' renvoie le nom du fichier image.

[% img1.name %]     # foo.gif

Les méthodes '"width"' et '"height"' renvoient la largeur et la hauteur de l'image, respectivement. La méthode '"size"' renvoie une référence à une liste de 2 éléments contenant la largeur et la hauteur.

[% USE image 'foo.gif' %]
largeur: [% image.width %]
hauteur: [% image.height %]
taille: [% image.size.join(', ') %]

La méthode '"modtime"' renvoie la date de modification du fichier concerné, utile pour une utilisation avec le plugin Date, par exemple :

[% USE image 'foo.gif' %]
[% USE date %]
[% date.format(image.modtime, "%B, %e %Y") %]

La méthode '"attr"' renvoie les valeurs de largeur et de hauteur sous forme d'attributs HTML/XML.

[% USE image 'foo.gif' %]
[% image.attr %]

La sortie typique est :

width="60" height="20"

La méthode '"tag"' renvoie une balise XHTML complète faisant référence à l'image.

[% USE image 'foo.gif' %]
[% image.tag %]

La sortie typique est :

<img src="foo.gif" width="60" height="20" alt="" />

Vous pouvez fournir des attributs supplémentaires qui devraient être ajoutés à la balise XHTML.

[% USE image 'foo.gif' %]
[% image.tag(class="logo" alt="Logo") %]

La sortie typique est :

<img src="foo.gif" width="60" height="20" alt="Logo" class="logo" />

Remarque : L'attribut '"alt"' est obligatoire dans une balise '"img"' XHTML stricte (même s'il est vide), il est donc toujours ajouté même s'il n'est pas spécifié explicitement. Vous pouvez le faire comme montré dans l'exemple ci-dessus, ou comme argument de la méthode '"tag").

[% USE image('foo.gif', alt='Logo') %]

GESTION DES ERREURS

Si le fichier image ne peut pas être trouvé, les méthodes ci-dessus lèveront une erreur '"Image"'. Vous pouvez encapsuler les appels à ces méthodes dans un bloc '"TRY...CATCH"' pour capturer toute erreur potentielle.

[% TRY;
     image.width;
   CATCH;
     error;      # imprime l'erreur
   END
%]

UTILISATION DE Image::Info

Lors de l'exécution, le plugin tente de charger Image::Info avant Image::Size. Si Image::Info est trouvé, quelques fonctions supplémentaires sont incluses, en plus de '"size"', '"width"', '"height"', '"attr"' et '"tag"'. Ces fonctions supplémentaires sont nommées d'après les éléments qu'Image::Info récupère de l'image. Les types de fonctions disponibles dépendent du type d'image (voir Image::Info pour plus de détails). Ces fonctions supplémentaires incluent toujours les suivantes :

file_media_type

Ceci est le type MIME approprié pour le format donné du fichier. La valeur correspondante est une chaîne comme : ""image/png"" ou ""image/jpeg"".

file_ext

Ceci est le nom d'extension suggéré pour un fichier d'un format donné. La valeur est une chaîne de 3 lettres en minuscules comme ""png"", ""jpg"".

color_type

Ceci est une courte chaîne décrivant quel type de valeurs codent les pixels. La valeur peut être l'une des suivantes :

Gray
GrayA
RGB
RGBA
CMYK
YCbCr
CIELab

Ces noms peuvent également être préfixés par ""Indexed-"" si l'image est composée d'indices dans une table de couleurs. Parmi ceux-ci, seul ""Indexed-RGB"" est susceptible d'apparaître.

(C'est similaire au champ TIFF PhotometricInterpretation, mais ce nom était jugé trop long, nous utilisons donc le terme du type PNG à la place.)

resolution

La valeur de ce champ donne normalement la taille physique de l'image à l'écran ou sur papier. Lorsque le spécificateur d'unité n'est pas présent, ce champ indique la proportion des pixels dans l'image.

La syntaxe de ce champ est :

<res> <unit>
<xres> "/" <yres> <unit>
<xres> "/" <yres>

Les champs <res>, <xres> et <yres> sont des nombres. L'<unit> est une chaîne comme "dpi", "dpm" ou "dpcm" (indiquant "dots per inch/cm/meter").

SamplesPerPixel

Ceci indique combien de canaux il y a dans l'image. Pour certains formats d'image, ce nombre peut être supérieur au nombre implicite de "color_type".

BitsPerSample

Ceci indique combien de bits sont utilisés pour coder chaque échantillon. La valeur est une référence à un tableau de nombres. Le nombre d'éléments dans le tableau doit être le même que la valeur de "SamplesPerPixel".

Comment

Commentaires textuels trouvés dans le fichier. La valeur est une référence à un tableau si plusieurs commentaires sont trouvés.

Interlace

Si l'image est entrelacée, alors ceci renvoie le type d'entrelacement.

Compression

Ceci renvoie le nom de l'algorithme de compression utilisé.

Gamma

Ceci indique combien de bits sont utilisés pour coder chaque échantillon. La valeur est une référence à un tableau de nombres. Le nombre d'éléments dans le tableau doit être le même que la valeur de "SamplesPerPixel".

"Pp">Un nombre indiquant la courbe gamma de l'image (par exemple, 2.2)
