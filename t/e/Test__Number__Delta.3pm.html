Test::Number::Delta(3) Documentation Perl fournie par l'utilisateur Test::Number::Delta(3)

NOM

Test::Number::Delta - Compare la différence entre des nombres par rapport à une tolérance donnée

VERSION

version 1.06

SYNOP

# Importer les fonctions de test
use Test::Number::Delta;
# Test d'égalité avec tolérance par défaut
delta_ok( 1e-5, 2e-5, 'les valeurs sont dans 1e-6');
# Test d'inégalité avec tolérance par défaut
delta_not_ok( 1e-5, 2e-5, 'les valeurs ne sont pas dans 1e-6');
# Fournir une tolérance spécifique
delta_within( 1e-3, 2e-3, 1e-4, 'les valeurs sont dans 1e-4');
delta_not_within( 1e-3, 2e-3, 1e-4, 'les valeurs ne sont pas dans 1e-4');
# Comparer des tableaux ou des matrices
@a = ( 3.14, 1.41 );
@b = ( 3.15, 1.41 );
delta_ok( \@a, \@b, 'comparer @a et @b' );
# Définir une tolérance par défaut différente
use Test::Number::Delta within => 1e-5;
delta_ok( 1.1e-5, 2e-5, 'les valeurs sont dans 1e-5'); # ok
# Définir une tolérance relative
use Test::Number::Delta relative => 1e-3;
delta_ok( 1.01, 1.0099, 'les valeurs sont dans 1.01e-3');

DESCRIPTION

À un moment donné ou à un autre, la plupart des programmeurs se retrouvent à devoir comparer des nombres à virgule flottante pour l'égalité. L'idiome typique consiste à vérifier si la valeur absolue de la différence des nombres est dans une tolérance désirée, généralement appelée epsilon. Ce module fournit une telle fonction pour être utilisée avec Test::More. L'utilisation est similaire à d'autres fonctions de test décrites dans Test::More. Sémantiquement, la fonction "delta_within" remplace ce type de construction :

ok ( abs($p - $q) < $epsilon, '$p est égal à $q' ) or
    diag "$p n'est pas égal à $q à moins de $epsilon";

Bien qu'il n'y ait rien de mal avec cette construction, elle est pénible à taper de manière répétée dans un script de test. Ce module fait la même chose avec un seul appel de fonction. La fonction "delta_ok" est similaire, mais utilise soit une valeur par défaut globale pour epsilon, soit calcule un epsilon 'relatif' à la volée, de sorte qu'epsilon est automatiquement mis à l'échelle à la taille des arguments de "delta_ok". Les deux fonctions sont exportées automatiquement.

Étant donné que la vérification de l'égalité des nombres à virgule flottante n'est pas toujours fiable, il n'est pas possible de vérifier la limite 'égale à' de 'inférieur ou égal à epsilon'. Par conséquent, Test::Number::Delta compare uniquement si la valeur absolue de la différence est inférieure à epsilon (pour les tests d'égalité) ou supérieure à epsilon (pour les tests d'inégalité).

UTILISATION

use Test::Number::Delta;

Sans arguments, epsilon vaut par défaut 1e-6. (Un choix arbitraire de l'auteur.)

use Test::Number::Delta within => 1e-9;

Pour spécifier une valeur par défaut différente pour epsilon, fournissez un paramètre "within" lors de l'importation du module. La valeur doit être non nulle.

use Test::Number::Delta relative => 1e-3;

Alternativement à l'utilisation d'une valeur fixe pour epsilon, fournissez un paramètre "relative" lors de l'importation du module. Cela indique que "delta_ok" doit tester l'égalité avec un epsilon qui est mis à l'échelle de la taille des arguments. Epsilon est calculé comme la valeur relative multipliée par la valeur absolue de l'argument ayant la plus grande magnitude. Mathématiquement, pour les arguments 'x' et 'y' :

epsilon = relative * max( abs(x), abs(y) )

Par exemple, une valeur relative de "0.01" signifierait que les arguments sont égaux s'ils diffèrent de moins de 1% de la plus grande des deux valeurs. Une valeur relative de 1e-6 signifie que les arguments doivent différer de moins d'un millionième de la valeur la plus grande. La valeur relative doit être non nulle.

Combinaison avec un plan de test

use Test::Number::Delta 'no_plan';
# ou
use Test::Number::Delta within => 1e-9, tests => 1;

Si un plan de test n'a pas déjà été spécifié, le paramètre optionnel pour Test::Number::Delta peut être suivi d'un plan de test (voir Test::More pour les détails). Si un paramètre pour Test::Number::Delta est donné, il doit venir en premier.

FONCTIONS

delta_within

delta_within(  $p,  $q, $epsilon, '$p et $q sont égaux à moins de $epsilon' );
delta_within( \@p, \@q, $epsilon, '@p et @q sont égaux à moins de $epsilon' );

Cette fonction teste l'égalité à moins d'une valeur donnée d'epsilon. Le test est vrai si la valeur absolue de la différence entre $p et $q est inférieure à epsilon. Si le test est vrai, elle affiche une déclaration "OK" pour utilisation dans les tests. Si le test n'est pas vrai, cette fonction affiche un rapport d'échec et des diagnostics. Epsilon doit être non nul.

Les valeurs à comparer peuvent être des scalaires ou des références à des tableaux. Si les valeurs sont des références à des tableaux, la comparaison est effectuée par paires pour chaque valeur d'indice du tableau. La comparaison par paires est récursive, donc les matrices peuvent également être comparées.

Par exemple, cet extrait de code compare deux matrices :

my @a = (   [ 3.14, 6.28 ],
            [ 1.41, 2.84 ]   );
my @b = (   [ 3.14, 6.28 ],
            [ 1.42, 2.84 ]   );
delta_within( \@a, \@b, 1e-6, 'comparer @a et @b' );

L'extrait affiche ceci :

not ok 1 - comparer @a et @b
# À [1][0] : 1.4100000 et 1.4200000 ne sont pas égaux à moins de 0.000001

delta_ok

delta_ok(  $p,  $q, '$p et $q sont suffisamment proches pour être égaux' );
delta_ok( \@p, \@q, '@p et @q sont suffisamment proches pour être égaux' );

Cette fonction teste l'égalité dans une valeur epsilon par défaut. Voir "UTILISATION" pour les détails sur la modification de la valeur par défaut. Sinon, cette fonction fonctionne de la même manière que "delta_within".

delta_not_within

delta_not_within(  $p,  $q, '$p et $q sont différents' );
delta_not_within( \@p, \@q, $epsilon, '@p et @q sont différents' );

Ce test compare l'inégalité excédant une valeur donnée d'epsilon. Le test est vrai si la valeur absolue de la différence entre $p et $q est supérieure à epsilon. Pour les comparaisons de tableaux ou de matrices, le test est vrai si une paire quelconque de valeurs diffère de plus qu'epsilon. Sinon, cette fonction fonctionne de la même manière que "delta_within".

delta_not_ok

delta_not_ok(  $p,  $q, '$p et $q sont différents' );
delta_not_ok( \@p, \@q, '@p et @q sont différents' );

Cette fonction teste l'inégalité excédant une valeur epsilon par défaut. Voir "UTILISATION" pour les détails sur la modification de la valeur par défaut. Sinon, cette fonction fonctionne de la même manière que "delta_not_within".

Test::Number::Delta 1.06 - Perl manual page

NAME

Test::Number::Delta - Test for numbers within a delta

VERSION

1.06

SYNOPSIS

 use Test::More tests => 1;
 use Test::Number::Delta { delta_ok };

 delta_ok( $actual, $expected, $message );

DESCRIPTION

This module provides a test function, delta_ok, which tests that two numbers are within a specified delta of each other.

 delta_ok( $actual, $expected, $message );

The delta is determined by the relative difference between the two numbers. The test passes if the absolute difference between the two numbers is less than or equal to the delta. The delta is calculated as:

 $delta = $expected * $fractional_delta

Where $fractional_delta is a value between 0 and 1.

USAGE

Import the delta_ok function from the module.

 use Test::Number::Delta { delta_ok };

Then use it in your tests:

 my $calculated_value = 1.000001;
 my $expected_value = 1.0;
 delta_ok( $calculated_value, $expected_value, "Calculated value is close to expected" );

FUNCTIONS

delta_ok
 delta_ok( $actual, $expected, $message )

Tests if $actual is within a delta of $expected. The delta is calculated based on the relative difference between the two numbers.
