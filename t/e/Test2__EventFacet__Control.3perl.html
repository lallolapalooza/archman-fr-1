Test2::EventFacet::Control(3perl) Guide du programmeur Perl Test2::EventFacet::Control(3perl)

NOM

Test2::EventFacet::Control - Facette pour les actions et comportements du hub.

DESCRIPTION

Cette facette est utilisée lorsque l'événement doit donner des instructions aux internes de Test2.

CHAMPOS

$string = $control->{details}
$string = $control->details()
Explication lisible par l'homme pour le comportement spécial.
$bool = $control->{global}
$bool = $control->global()
Vrai si l'événement est de nature globale et doit être vu par tous les hubs.
$exit = $control->{terminate}
$exit = $control->terminate()
Défini si le test doit se terminer immédiatement, la valeur est le code de sortie et peut être 0.
$bool = $control->{halt}
$bool = $control->halt()
Vrai si tous les tests doivent être interrompus immédiatement.
$bool = $control->{has_callback}
$bool = $control->has_callback()
Vrai si la méthode callback($hub) de l'événement doit être appelée.
$encoding = $control->{encoding}
$encoding = $control->encoding()
Ceci peut être utilisé pour changer l'encodage à partir de cet événement.
$phase = $control->{phase}
$phase = $control->phase()
Utilisé pour signaler qu'un changement de phase s'est produit. Actuellement, seule la phase END de perl est signalée.
