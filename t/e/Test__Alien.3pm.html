NOM

Test::Alien - Outils de test pour les modules Alien

VERSION

version 2.84

SYNOPIS

Tester les commandes qui accompagnent votre Alien :

use Test2::V0;
use Test::Alien;
use Alien::patch;

alien_ok 'Alien::patch';
run_ok([ 'patch', '--version' ])
  ->success
  # nous n'acceptons que la version écrite
  # par Larry ...
  ->out_like(qr{Larry Wall});

done_testing;

Tester que votre bibliothèque fonctionne avec "XS" :

use Test2::V0;
use Test::Alien;
use Alien::Editline;

alien_ok 'Alien::Editline';
my $xs = do { local $/; <DATA> };
xs_ok $xs, with_subtest {
  my($module) = @_;
  ok $module->version;
};

done_testing;

__DATA__

#include "EXTERN.h"
#include "perl.h"
#include "XSUB.h"
#include <editline/readline.h>

const char *
version(const char *class)
{
  return rl_library_version;
}

MODULE = TA_MODULE PACKAGE = TA_MODULE

const char *version(class);
    const char *class;

Tester que votre bibliothèque fonctionne avec FFI::Platypus :

use Test2::V0;
use Test::Alien;
use Alien::LibYAML;

alien_ok 'Alien::LibYAML';
ffi_ok { symbols => ['yaml_get_version'] }, with_subtest {
  my($ffi) = @_;
  my $get_version = $ffi->function(yaml_get_version => ['int*','int*','int*'] => 'void');
  $get_version->call(\my $major, \my $minor, \my $patch);
  like $major, qr{[0-9]+};
  like $minor, qr{[0-9]+};
  like $patch, qr{[0-9]+};
};

done_testing;

DESCRIPTION

Ce module fournit des outils pour tester les modules Alien. Il dispose de points d'intégration pour fonctionner facilement avec les modules basés sur Alien::Base, mais peut également être utilisé via l'interface synthétique pour tester des modules Alien non basés sur Alien::Base. Il a des prérequis très modestes.

Avant ce module, la meilleure façon de tester un module Alien était via Test::CChecker. Le principal inconvénient de ce module est qu'il est fortement influencé par et utilise ExtUtils::CChecker, qui est un outil pour vérifier à l'installation diverses choses concernant votre compilateur. Il a également été écrit avant que Alien::Base ne devienne aussi stable qu'il l'est aujourd'hui. En particulier, Test::CChecker effectue ses tests en créant un exécutable et en le lançant. Malheureusement, Perl utilise des extensions en créant des bibliothèques dynamiques et en les liant au processus Perl, ce qui est différent de manière subtile et sujette aux erreurs. Ce module tente de tester les bibliothèques de la manière dont elles seront réellement utilisées, via "XS" ou FFI::Platypus. Il fournit également un mécanisme pour tester les binaires fournis par les différents modules Alien (par exemple Alien::gmake et Alien::patch).

Les modules Alien peuvent être utilisables sans compilateur, ou sans FFI::Platypus (par exemple, si la bibliothèque est fournie par le système et que vous utilisez FFI::Platypus, ou si vous construisez à partir des sources et que vous utilisez "XS"), donc les tests avec des prérequis manquants sont automatiquement ignorés. Par exemple, "xs_ok" s'ignorera automatiquement si un compilateur n'est pas trouvé, et "ffi_ok" s'ignorera automatiquement si FFI::Platypus n'est pas installé.

FONCTIONS

alien_ok

alien_ok $alien, $message;
alien_ok $alien;

Charge l'instance ou la classe Alien donnée. Vérifie que l'instance ou la classe respecte la même interface que Alien::Base. Sera utilisée par les tests suivants. Le module $alien doit seulement fournir ces méthodes afin de respecter l'interface Alien::Base :

cflags
Chaîne contenant les indicateurs du compilateur
libs
Chaîne contenant les indicateurs de l'éditeur de liens et de la bibliothèque
dynamic_libs
Liste des bibliothèques dynamiques. Retourne une liste vide si le module Alien ne fournit pas ceci.
bin_dir
Répertoire contenant les binaires des outils. Retourne une liste vide si le module Alien ne fournit pas ceci.

Si votre module Alien ne respecte pas cette interface, vous pouvez créer un module Alien synthétique en utilisant la fonction "synthetic".

synthetic

my $alien = synthetic \%config;

Crée un module Alien synthétique qui peut être passé à "alien_ok". "\%config" peut contenir ces clés (toutes facultatives) :

cflags
Chaîne contenant les indicateurs du compilateur.
cflags_static
Chaîne contenant les indicateurs statiques du compilateur (facultatif).
libs
Chaîne contenant les indicateurs de l'éditeur de liens et de la bibliothèque.
libs_static
Chaîne contenant les indicateurs statiques de l'éditeur de liens (facultatif).
dynamic_libs
Référence de liste contenant les bibliothèques dynamiques.
bin_dir
Répertoire des binaires des outils.
runtime_prop
Propriétés d'exécution.

Voir Test::Alien::Synthetic pour plus de détails.

run_ok

my $run = run_ok $command;
my $run = run_ok $command, $message;

Exécute la commande donnée, en utilisant en fallback tous les méthodes "Alien::Base#bin_dir" fournis par les modules Alien spécifiés avec "alien_ok".

$command peut être soit une chaîne, soit une référence de tableau.

Ne échoue que si la commande ne peut pas être trouvée, ou si elle est terminée par un signal ! Retourne un objet Test::Alien::Run, que vous pouvez utiliser pour tester le code de sortie, la sortie standard et la sortie d'erreur.

Retourne toujours une instance de Test::Alien::Run, même si la commande n'a pas pu être trouvée.

xs_ok

xs_ok $xs;
xs_ok $xs, $message;

Compile, lie le code "XS" donné et l'attache à Perl.

Si vous utilisez le nom de module spécial "TA_MODULE" dans votre code "XS", il sera remplacé par un nom de paquet généré automatiquement. Cela peut être utile si vous souhaitez passer le même code "XS" à plusieurs appels de "xs_ok" sans que les appels ultérieurs ne remplacent les précédents.

$xs peut être soit une chaîne contenant le code "XS", soit une référence de hachage avec ces clés :

xs
Le code XS. C'est le seul élément requis.
pxs
Arguments supplémentaires ExtUtils::ParseXS passés sous forme de référence de hachage.
cbuilder_check
La vérification de compilation qui devrait être effectuée avant de tenter de construire. Doit être l'un de "have_compiler" ou "have_cplusplus". Par défaut, "have_compiler".
cbuilder_config
Hachage pour remplacer les valeurs normalement fournies par "Config".
cbuilder_compile
Arguments supplémentaires ExtUtils::CBuilder passés sous forme de référence de hachage.
cbuilder_link
Arguments supplémentaires ExtUtils::CBuilder passés sous forme de référence de hachage.
verbose
Afficher des informations de débogage abondantes via une note de test.

NOM

Test::Alien

VERSION

Test::Alien - Test des modules Alien

SYNOPSIS

Utilisez Test::Alien pour tester les modules Alien.

DESCRIPTION

Test::Alien est un module Perl qui vous permet de tester les modules Alien. Il fournit un ensemble de fonctions pour tester la fonctionnalité des modules Alien, y compris la correction du code, la présence de certaines fonctions et la gestion de différents types de données.

FONCTIONS

Voici les fonctions fournies par Test::Alien:

ENVIRONNEMENT

"TEST_ALIEN_ALWAYS_KEEP"
Si ceci est défini, cela remplacera la logique par défaut qui décide si les fichiers temporaires générés par "xs_ok" doivent être conservés à la fin du fichier de test. Si défini à vrai, les fichiers générés seront toujours conservés. Si défini à faux, ils seront toujours supprimés.
"TEST_ALIEN_ALIENS_MISSING"
Par défaut, ce module émettra un avertissement si des outils sont utilisés sans appeler d'abord "alien_ok". C'est généralement une erreur, mais si vous souhaitez réellement utiliser l'un de ces outils sans charger d'aliens, vous pouvez définir cette variable d'environnement à faux.
