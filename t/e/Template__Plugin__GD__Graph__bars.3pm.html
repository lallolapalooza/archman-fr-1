NOM

Template::Plugin::GD::Graph::bars - Créer des diagrammes à barres avec axes et légendes

SYNTAXE

[% USE g = GD.Graph.bars(taille_x, taille_y); %]

EXEMPLES

[% FILTER null;
    donnees = [  
        ["1er","2ème","3ème","4ème","5ème","6ème","7ème", "8ème", "9ème"],
        [    1,    2,    5,    6,    3,  1.5,    1,     3,     4],
    ];

    USE mon_graphique = GD.Graph.bars();

    mon_graphique.set(
        etiquette_x         => 'Étiquette X',
        etiquette_y         => 'Étiquette Y',
        titre           => 'Un simple diagramme à barres',
        y_max_valeur     => 8,
        y_nombre_graduations => 8, 
        y_saut_etiquette    => 2,
        # ombres
        espacement_barres     => 8,
        profondeur_ombre    => 4, 
        couleur_ombre       => 'dred',
        transparent     => 0,
    );      
    mon_graphique.plot(donnees).png | stdout(1);
   END;
-%]

DESCRIPTION

Le plugin GD.Graph.bars fournit une interface à la classe GD::Graph::bars définie par le module GD::Graph. Il permet de tracer un ou plusieurs ensembles de données (x,y) avec chaque point représenté par une barre, en plus des axes et des légendes.

Voir GD::Graph pour plus de détails.
