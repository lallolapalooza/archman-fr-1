Template::Plugins(3) Documentation Perl fournie par l'utilisateur Template::Plugins(3)

NOM

Template::Plugins - Module fournisseur de plugins

SYNOPSIS

use Template::Plugins;
$plugin_provider = Template::Plugins->new(\%options);
($plugin, $error) = $plugin_provider->fetch($name, @args);

DESCRIPTION

Le module "Template::Plugins" définit une classe de fournisseur qui peut être utilisée pour charger et instancier des modules de plugins du Template Toolkit.

MÉTHODES

new(\%params)

Méthode constructeur qui instancie et retourne une référence vers un objet "Template::Plugins". Une référence vers un tableau associatif d'éléments de configuration peut être passée en paramètre. Ceux-ci sont décrits ci-dessous.

Notez que le module frontal Template crée un fournisseur "Template::Plugins", en passant tous les éléments de configuration. Ainsi, les exemples montrés ci-dessous sous la forme :

$plugprov = Template::Plugins->new({
    PLUGIN_BASE => 'MyTemplate::Plugin',
    LOAD_PERL   => 1,
    ...
});

peuvent aussi être utilisés via le module Template comme :

$ttengine = Template->new({
    PLUGIN_BASE => 'MyTemplate::Plugin',
    LOAD_PERL   => 1,
    ...
});

ainsi que la forme plus explicite :

$plugprov = Template::Plugins->new({
    PLUGIN_BASE => 'MyTemplate::Plugin',
    LOAD_PERL   => 1,
    ...
});
$ttengine = Template->new({
    LOAD_PLUGINS => [ $plugprov ],
});

fetch($name, @args)

Appelée pour demander la fourniture d'un plugin d'un nom donné. Le module pertinent est d'abord chargé (si nécessaire) et la méthode de classe load() est appelée pour retourner le nom de la classe usine (généralement le même nom de package) ou un objet usine (un prototype). La méthode new() est ensuite appelée comme méthode de classe ou d'objet contre l'usine, en passant tous les paramètres restants.

Retourne une référence vers un nouvel objet plugin ou "($error, STATUS_ERROR)" en cas d'erreur. Peut aussi retourner "(undef, STATUS_DECLINED)" pour refuser de servir la requête. Si "TOLERANT" est défini, toutes les erreurs seront retournées comme des refus.

OPTIONS DE CONFIGURATION

La liste suivante résume les options de configuration qui peuvent être fournies au constructeur new() de "Template::Plugins". Veuillez consulter Template::Manual::Config pour plus de détails et d'exemples sur chaque option de configuration.

PLUGINS

L'option PLUGINS peut être utilisée pour fournir une référence à un tableau associatif qui mappe des noms de plugins à des noms de modules Perl.

my $plugins = Template::Plugins->new({
    PLUGINS => {
        cgi => 'MyOrg::Template::Plugin::CGI',
        foo => 'MyOrg::Template::Plugin::Foo',
        bar => 'MyOrg::Template::Plugin::Bar',
    },
});

PLUGIN_BASE

Si un plugin n'est pas défini dans le tableau PLUGINS, alors PLUGIN_BASE est utilisé pour tenter de construire un nom de module Perl correct qui pourra être chargé avec succès.

# PLUGIN_BASE à valeur unique
my $plugins = Template::Plugins->new({
    PLUGIN_BASE => 'MyOrg::Template::Plugin',
});
# PLUGIN_BASE à valeurs multiples
my $plugins = Template::Plugins->new({
    PLUGIN_BASE => [   'MyOrg::Template::Plugin',
                       'YourOrg::Template::Plugin'  ],
});

LOAD_PERL

L'option LOAD_PERL peut être définie pour vous permettre de charger des modules Perl réguliers (c'est-à-dire ceux qui ne résident pas dans "Template::Plugin" ou un autre espace de noms défini par l'utilisateur) comme plugins.

Si un plugin ne peut pas être chargé en utilisant les approches PLUGINS ou PLUGIN_BASE, alors, si LOAD_PERL est défini, le fournisseur fera une dernière tentative pour charger le module sans préfixer le chemin du module.

Contrairement aux plugins réguliers, les modules chargés en utilisant LOAD_PERL ne reçoivent pas une référence Template::Context comme premier argument de la méthode constructeur new().

TOLERANT

Le drapeau TOLERANT peut être défini pour indiquer que le module "Template::Plugins" doit ignorer toute erreur rencontrée lors du chargement d'un plugin et retourner à la place "STATUS_DECLINED".

DEBUG

L'option DEBUG peut être utilisée pour activer les messages de débogage pour le module "Template::Plugins" en la définissant pour inclure la valeur "DEBUG_PLUGINS".

use Template::Constants qw( :debug );
my $template = Template->new({
    DEBUG => DEBUG_FILTERS | DEBUG_PLUGINS,
});

PLUGINS TEMPLATE TOOLKIT

Veuillez consulter Template::Manual::Plugins pour une liste complète de tous les modules de plugins distribués avec le Template Toolkit.
