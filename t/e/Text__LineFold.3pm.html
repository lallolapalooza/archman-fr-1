NOM

Text::LineFold - Pliage de lignes pour texte brut

SYNOPSIS

use Text::LineFold;
$lf = Text::LineFold->new();

# Plier les lignes
$folded = $lf->fold($string, 'PLAIN');
$indented = $lf->fold(' ' x 8, ' ' x 4, $string);
# Déplier les lignes
$unfolded = $lf->unfold($string, 'FIXED');

DESCRIPTION

Text::LineFold plie ou déplie les lignes de texte brut. Comme il se concentre principalement sur les messages électroniques en texte brut, le format "flowed" RFC 3676 est également pris en charge.

Interface Publique

new ([CLE => VALEUR, ...])
Constructeur. Pour les paires CLE => VALEUR, voir la méthode config.
$self->config (CLE)
$self->config ([CLE => VAL, ...])
Méthode d'instance. Obtient ou met à jour la configuration. Les paires CLE => VALEUR suivantes peuvent être spécifiées.
Charset => CHARSET
Jeu de caractères utilisé pour encoder la chaîne. Il peut s'agir d'une chaîne ou d'un objet MIME::Charset. La valeur par défaut est "UTF-8".
Language => LANGUAGE
En plus de l'option Charset, ceci peut être utilisé pour définir le contexte linguistique/régional. La valeur par défaut est "XX". Voir aussi "Context" dans l'option Unicode::LineBreak.
Newline => STRING
Chaîne à utiliser pour la séquence de nouvelle ligne. La valeur par défaut est "\n".
OutputCharset => CHARSET
Jeu de caractères utilisé pour encoder le résultat de fold()/unfold(). Il peut s'agir d'une chaîne ou d'un objet MIME::Charset. Si une valeur spéciale "_UNICODE_" est spécifiée, le résultat sera une chaîne Unicode. La valeur par défaut est celle de l'option Charset.
TabSize => NUMBER
Largeur en colonnes des tabulations. Lorsque 0 est spécifié, les tabulations sont ignorées. La valeur par défaut est 8.

$self->fold (CHAÎNE, [MÉTHODE])
$self->fold (TABULATION_INITIALE, TABULATION_SUBSÉQUENTE, CHAÎNE, ...)
Méthode d'instance. fold() plie les lignes de la chaîne CHAÎNE et la retourne. Les espaces excédentaires et les tabulations horizontales en fin de ligne sont supprimés, les séquences de nouvelle ligne sont remplacées par celle spécifiée par l'option Newline et une nouvelle ligne est ajoutée à la fin du texte si elle n'existe pas. Les tabulations horizontales sont traitées comme des tabulations selon l'option TabSize.

Avec le premier style, les options suivantes peuvent être spécifiées pour l'argument MÉTHODE.

"FIXED"
Les lignes précédées de ">" ne seront pas pliées. Les paragraphes sont séparés par une ligne vide.
"FLOWED"
Formatage "Format=Flowed; DelSp=Yes" défini par la RFC 3676.
"PLAIN"
Méthode par défaut. Toutes les lignes sont pliées.

Le second style est similaire à "wrap()" dans Text::Wrap. Toutes les lignes sont pliées. INITIAL_TAB est inséré au début des paragraphes et SUBSEQUENT_TAB au début des autres lignes coupées.

$self->unfold (CHAÎNE, MÉTHODE)
Conjoncte les paragraphes pliés de la chaîne CHAÎNE et la retourne.

Les options suivantes peuvent être spécifiées pour l'argument MÉTHODE.

"FIXED"
Méthode par défaut. Les lignes précédées de ">" ne seront pas conjointes. Traite la ligne vide comme séparateur de paragraphe.
"FLOWED"
Déplie le formatage "Format=Flowed; DelSp=Yes" défini par la RFC 3676.
"FLOWEDSP"
Déplie le formatage "Format=Flowed; DelSp=No" défini par la RFC 3676.
