Paquet: perl-text-roman

Licences: PerlArtistic, GPL

Text::Roman(3) Documentation Perl fournie par l'utilisateur Text::Roman(3)

NOM

Text::Roman - Permet la conversion entre les algorithmes romains et arabes.

VERSION

version 3.5

SYNOPSIS

#!/usr/bin/env perl
use strict;
use warnings;
use Text::Roman qw(:all);
print int2roman(123), "\n";
my $roman = "XXXV";
print roman2int($roman), "\n" if isroman($roman);
my $milhar = 'L_X_XXIII'; # = 60,023
print milhar2int($milhar), "\n" if ismilhar($milhar);

DESCRIPTION

Ce paquet prend en charge à la fois les algorithmes romains conventionnels (qui vont de 1 à 3999) et les Romains Milhar, une variation qui utilise une barre sur l'algorithme pour indiquer la multiplication par 1 000. Aux fins de ce module, la syntaxe acceptable consiste en un tiret bas suffixant l'algorithme, par exemple IV_V = 4 005. Le terme Milhar dérive apparemment du mot portugais pour "milliers" et la gamme de cette notation étend la gamme des nombres romains à 3999 * 1000 + 3999 = 4 002 999.

Note : les fonctions de ce paquet traitent les algorithmes romains de manière insensible à la casse, de sorte que "VI" == "vI" == "Vi" == "vi".

Les fonctions suivantes peuvent être importées dans le paquet appelant par nom :

FONCTIONS

isroman

Teste si une chaîne est un algorithme romain valide. Renvoie une valeur booléenne.

int2roman

Convertit un entier exprimé en chiffres arabes en son algorithme romain correspondant. Si l'entier fourni est hors de la plage exprimable en notation romaine, un undef est renvoyé.

roman2int

Fait l'inverse de "int2roman", convertissant un algorithme romain en sa valeur entière.

ismilhar

Détermine si une chaîne correspond à un algorithme romain Milhar.

milhar2int

Convertit un algorithme romain Milhar en un entier.

ismroman/mroman2int/roman

Ces fonctions appartiennent à l'ancienne interface du module et sont considérées comme obsolètes. Ne les utilisez pas dans du nouveau code et elles seront éventuellement supprimées ; elles correspondent comme suit :

  • ismroman => ismilhar
  • mroman2int => milhar2int
  • roman => int2roman

CHANGEMENTS

Quelques changements notables par rapport à l'incarnation précédente de ce module :

importations de namespace
L'appel à use doit maintenant demander explicitement les noms de fonctions importées dans son namespace.
arguments par défaut/contexte vide
Toutes les fonctions opéreront maintenant sur $_ lorsqu'aucun argument n'est passé, et définiront $_ lorsqu'elles seront appelées dans un contexte vide. Cela permet d'écrire du code comme : 
@x = qw/V III XI IV/;
roman2int() for @x;
print join("-", @x);

au lieu du plus laid :

@x = qw/V III XI IV/;
$_ = roman2int($_) for @x;
print join("-", @x);

SPÉCIFICATION

Les algorithmes romains peuvent être décrits en utilisant la formule de type BNF suivante :

a   = I{1,3}
b   = V\a?|IV|\a
e   = X{1,3}\b?|X{0,3}IX|\b
ee  = IX|\b
f   = L\e?|XL\ee?|\e
g   = C{1,3}\f?|C{0,3}XC\ee?|\f
gg  = XC\ee?|\f
h   = D\g?|CD\gg?|\g
j   = M{1,3}\h?|M{0,3}CM\gg?|\h
