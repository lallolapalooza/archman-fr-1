NOM

Text::Query::SolveAdvancedString - Applique une expression de requête sur des chaînes de caractères

SYNOPSIS

use Text::Query;
my $q=new Text::Query('hello and world',
                      -parse => 'Text::Query::ParseAdvanced',
                      -solve => 'Text::Query::SolveAdvancedString',
                      -build => 'Text::Query::BuildAdvancedString');
$q->match('this hello is a world')

DESCRIPTION

Applique une expression construite par "Text::Query::BuildAdvancedString" à une liste de chaînes de caractères.

MÉTHODES

match ([TARGET])
Si "TARGET" est un scalaire, "match" renvoie une valeur vraie si la chaîne spécifiée par "TARGET" correspond à l'expression de requête de l'objet. Si "TARGET" n'est pas fourni, la correspondance est faite avec $_.

Si "TARGET" est un tableau, "match" renvoie une liste (éventuellement vide) de tous les éléments correspondants. Si les éléments du tableau sont des références à des sous-tableaux, la correspondance est effectuée sur le premier élément de chaque sous-tableau. Ceci permet d'associer des informations arbitraires (par exemple, des noms de fichiers) à chaque chaîne à faire correspondre.

Si "TARGET" est une référence à un tableau, "match" renvoie une référence à une liste (éventuellement vide) de tous les éléments correspondants.

matchscalar ([TARGET])
Se comporte comme "MATCH" lorsque "TARGET" est un scalaire ou n'est pas fourni. Est légèrement plus rapide que "MATCH" dans ces circonstances.
