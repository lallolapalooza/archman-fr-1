NOM

Text::Diff::Table - Plugin Text::Diff pour générer une sortie au format "tableau"

SYNTAXE

use Text::Diff;

diff \@a, $b, { STYLE => "Table" };

DESCRIPTION

Il s'agit d'un formatteur de sortie pour le plugin Text::Diff qui génère des diffs au style "tableau" :

+--+----------------------------------+--+------------------------------+
|  |../Test-Differences-0.2/MANIFEST  |  |../Test-Differences/MANIFEST  |
|  |Thu Dec 13 15:38:49 2001          |  |Sat Dec 15 02:09:44 2001      |
+--+----------------------------------+--+------------------------------+
|  |                                  * 1|Changes                       *
| 1|Differences.pm                    | 2|Differences.pm                |
| 2|MANIFEST                          | 3|MANIFEST                      |
|  |                                  * 4|MANIFEST.SKIP                 *
| 3|Makefile.PL                       | 5|Makefile.PL                   |
|  |                                  * 6|t/00escape.t                  *
| 4|t/00flatten.t                     | 7|t/00flatten.t                 |
| 5|t/01text_vs_data.t                | 8|t/01text_vs_data.t            |
| 6|t/10test.t                        | 9|t/10test.t                    |
+--+----------------------------------+--+------------------------------+

Ce format s'efforce également de mettre en évidence les caractères "invisibles" sur les éléments différents en échappant sélectivement les espaces blancs. Chaque élément est divisé en trois segments (espaces blancs de début, corps, espaces blancs de fin). Si les espaces blancs diffèrent dans un segment, ce segment est échappé pour les espaces blancs.

Voici un exemple d'espacement blanc sélectif.

+--+--------------------------+--------------------------+
|  |demo_ws_A.txt             |demo_ws_B.txt             |
|  |Fri Dec 21 08:36:32 2001  |Fri Dec 21 08:36:50 2001  |
+--+--------------------------+--------------------------+
| 1|identical                 |identical                 |
* 2|        spaced in         |        also spaced in    *
* 3|embedded space            |embedded        tab       *
| 4|identical                 |identical                 |
* 5|        spaced in         |\ttabbed in               *
* 6|trailing spaces\s\s\n     |trailing tabs\t\t\n       *
| 7|identical                 |identical                 |
* 8|lf line\n                 |crlf line\r\n             *
* 9|embedded ws               |embedded\tws              *
+--+--------------------------+--------------------------+

Voici pourquoi les lignes ont ou n'ont pas d'espaces blancs échappés :

lignes 1, 4, 7 ne diffèrent pas, pas besoin.
lignes 2, 3 diffèrent sur des caractères non-espaces blancs, pas besoin.
lignes 5, 6, 8, 9 ont toutes des changements subtils d'espaces blancs.

La question de savoir si la ligne 3 doit ou non avoir ce caractère de tabulation échappé est une décision subjective ; jusqu'à présent, je choisis de ne pas le faire.

UNICODE

Pour afficher les caractères unicode bruts, consultez la documentation de Text::Diff::Config. Vous pouvez définir la variable d'environnement "DIFF_OUTPUT_UNICODE" à 1 pour l'afficher en ligne de commande. Pour plus d'informations, consultez ce bug : https://rt.cpan.org/Ticket/Display.html?id=54214.

LIMITATIONS

Le formatage en tableau nécessite de mettre en mémoire tampon l'intégralité du diff pour calculer les largeurs de colonne. Ce format ne devrait être utilisé que pour des diffs plus petits.

Suppose des arrêts de tabulation tous les 8 caractères, comme l'a prévu $DIETY.

Suppose que tous les codes de caractères >= 127 doivent être échappés sous forme de codes hexadécimaux, c'est-à-dire que le terminal de l'utilisateur est ASCII, et même pas capable d'"ASCII à haut bit". Cela peut être rendu optionnel si le besoin se fait sentir.

Suppose que les codes de contrôle (codes de caractères 0..31) qui n'ont pas d'échappements slash-lettre ("\n", "\r", etc.) dans Perl sont mieux présentés sous forme d'échappements hexadécimaux ("\x01") plutôt qu'octaux ("\001") ou de codes de contrôle ("\cA").
