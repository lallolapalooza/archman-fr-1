NOM

Test::Memory::Cycle - Vérifier les fuites de mémoire et les références de mémoire circulaires

VERSION

Version 1.06

SYNOPSIS

Le garbage collector de Perl a un gros problème : les références circulaires ne peuvent pas être nettoyées. Une référence circulaire peut être aussi simple que deux références qui se référencent mutuellement :

my $mom = {
    name => "Marilyn Lester",
};
my $me = {
    name => "Andy Lester",
    mother => $mom,
};
$mom->{son} = $me;

"Test::Memory::Cycle" est basé sur "Devel::Cycle" pour vous offrir un moyen simple de vérifier ces références circulaires.

use Test::Memory::Cycle;
my $object = new MyObject;
# Faire des choses avec l'objet.
memory_cycle_ok( $object );

Vous pouvez également utiliser memory_cycle_exists() pour vous assurer que vous avez un cycle là où vous vous attendez à en avoir un.

FONCTIONS

"memory_cycle_ok( $reference, $msg )"

Vérifie que $reference n'a pas de références de mémoire circulaires.

"memory_cycle_exists( $reference, $msg )"

Vérifie que $reference a des références de mémoire circulaires.

"weakened_memory_cycle_ok( $reference, $msg )"

Vérifie que $reference n'a pas de références de mémoire circulaires, mais contrairement à "memory_cycle_ok", cela vérifiera également les cycles affaiblis produits avec "weaken" de Scalar::Util.

"weakened_memory_cycle_exists( $reference, $msg )"

Vérifie que $reference a des références de mémoire circulaires, mais contrairement à "memory_cycle_exists", cela vérifiera également les cycles affaiblis produits avec "weaken" de Scalar::Util.
