NOM

Text::BibTeX::File - interface pour les fichiers BibTeX entiers

SYNOPIS

use Text::BibTeX::File;
$bib = Text::BibTeX::File->new("foo.bib") or die "foo.bib: $!\n";
# ou :
$bib =  Text::BibTeX::File->new;
$bib->open("foo.bib", {binmode => 'utf-8', normalization => 'NFC'}) || die "foo.bib: $!\n";
$bib->set_structure ($structure_name,
                     $option1 => $value1, ...);
$at_eof = $bib->eof;
$bib->close;

DESCRIPTION

"Text::BibTeX::File" fournit une interface orientée objet aux fichiers BibTeX. Son objectif le plus évident est de suivre un nom de fichier et un descripteur de fichier ensemble pour une utilisation par le module "Text::BibTeX::Entry" (qui est beaucoup plus intéressant). De plus, il vous permet de spécifier certaines options qui s'appliquent à une base de données entière (fichier), plutôt que de devoir les spécifier pour chaque entrée du fichier. Actuellement, vous pouvez spécifier la structure de la base de données et quelques options de structure. Ces concepts sont entièrement documentés dans Text::BibTeX::Structure.

MÉTHODES

Création d’objet, opérations sur les fichiers

new ([NOMFICHIER], [OPTIONS])
Crée un nouvel objet "Text::BibTeX::File". Si NOMFICHIER est fourni, il est passé à la méthode "open" (avec OPTIONS). Si "open" échoue, "new" échoue et renvoie false ; si "open" réussit (ou si NOMFICHIER n'est pas fourni), "new" renvoie la référence du nouvel objet.
open (NOMFICHIER [OPTIONS])
Ouvre le fichier spécifié par NOMFICHIER. OPTIONS est un hashref qui peut avoir les valeurs suivantes :
MODE
mode tel que spécifié par IO::File
PERMS
permissions telles que spécifiées par IO::File. Ne peut être utilisé qu'en conjonction avec "MODE"
BINMODE
Par défaut, Text::BibTeX utilise directement les octets. Ainsi, vous devez encoder les chaînes en conséquence avec l'encodage des fichiers que vous lisez. Vous pouvez également sélectionner UTF-8. Dans ce cas, Text::BibTeX renverra des chaînes UTF-8 en mode NFC. Notez qu'à l'heure actuelle, les fichiers avec BOM ne sont pas pris en charge.

Les valeurs valides sont 'raw/bytes' ou 'utf-8'.

NORMALIZATION
Par défaut, Text::BibTeX produit de l'UTF-8 sous forme NFC. Vous pouvez changer cela en passant le nom d'une forme différente.

Les valeurs valides sont celles supportées par le module Unicode::Normalize ('NFD', 'NFDK' etc.)

RESET_MACROS
Par défaut, Text::BibTeX accumule les macros. Cela signifie que lorsque vous ouvrez un deuxième fichier, les macros définies par le premier sont toujours disponibles. Cela peut entraîner des avertissements de redéfinition de macros.

Cette option peut être utilisée pour forcer Text::BibTeX à nettoyer toutes les définitions de macros (sauf les macros de mois).

close ()
Ferme le descripteur de fichier associé à l'objet. S'il n'y a pas de tel descripteur de fichier (c'est-à-dire si "open" n'a jamais été appelé sur l'objet), ne fait rien.
eof ()
Renvoie l'état de fin de fichier du descripteur de fichier associé à l'objet : une valeur vraie signifie que nous sommes à la fin du fichier.

Propriétés de l’objet

set_structure (STRUCTURE [, OPTION => VALEUR, ...])
Définit la structure de la base de données pour un fichier BibTeX. Au niveau le plus simple, cela signifie que les entrées du fichier sont censées se conformer à certaines exigences de champs telles que spécifiées par le module de structure. Cela vous donne également un accès complet aux méthodes de la classe d'entrée structurée particulière pour cette structure, vous permettant d'effectuer des opérations spécifiques à ce type de base de données. Voir "INTERACTIONS DE CLASSE" dans Text::BibTeX::Structure pour toutes les conséquences de la définition de la structure de la base de données pour un objet "Text::BibTeX::File".
structure ()
Renvoie le nom de la structure de la base de données associée à l'objet (tel que défini par "set_structure").
preserve_values ([PRESERVE])
Définit le drapeau "préserver les valeurs", pour contrôler toutes les analyses futures des entrées de ce fichier. Si PRESERVE n'est pas fourni, renvoie l'état actuel du drapeau. Voir Text::BibTeX::Value pour les détails sur l'analyse en mode "préservation des valeurs".

VOIR AUSSI

Text::BibTeX, Text::BibTeX::Entry, Text::BibTeX::Structure
