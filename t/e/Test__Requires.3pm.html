NOM

Test::Requires - Vérifie si le module peut être chargé

SYNOPIS

# dans votre Makefile.PL
use inc::Module::Install;
test_requires 'Test::Requires';
# dans votre test
use Test::More tests => 10;
use Test::Requires {
    'HTTP::MobileAttribute' => 0.01, # saute tout si HTTP::MobileAttribute n'est pas installé
};
isa_ok HTTP::MobileAttribute->new, 'HTTP::MobileAttribute::NonMobile';
# ou
use Test::More tests => 10;
use Test::Requires qw( 
    HTTP::MobileAttribute
);
isa_ok HTTP::MobileAttribute->new, 'HTTP::MobileAttribute::NonMobile';
# ou
use Test::More tests => 10;
use Test::Requires;
test_requires 'Some::Optional::Test::Required::Modules';
isa_ok HTTP::MobileAttribute->new, 'HTTP::MobileAttribute::NonMobile';

DESCRIPTION

Test::Requires vérifie si le module peut être chargé.

Si cela échoue, plutôt que de faire échouer les tests, cela saute tous les tests.

Test::Requires peut également être utilisé pour exiger une version minimale de Perl :

use Test::Requires "5.010";  # la mise entre guillemets est nécessaire !!

# ou
use Test::Requires "v5.10";
