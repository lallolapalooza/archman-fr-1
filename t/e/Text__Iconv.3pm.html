NOM

Text::Iconv - Interface Perl pour la fonction de conversion de jeux de caractères iconv()

SYNTAXE

use Text::Iconv;
$converter = Text::Iconv->new("fromcode", "tocode");
$converted = $converter->convert("Texte à convertir");

DESCRIPTION

Le module Text::Iconv fournit une interface Perl à la fonction iconv() telle que définie par la Single UNIX Specification.

La méthode convert() convertit le codage des caractères de la chaîne d'entrée du jeu de caractères fromcode vers le jeu de caractères tocode, et retourne le résultat.

Les réglages de fromcode et tocode, ainsi que leurs combinaisons permises, dépendent de l'implémentation. Les valeurs valides sont spécifiées dans la documentation du système ; l'utilitaire iconv(1) devrait également fournir une option -l qui liste tous les jeux de caractères pris en charge.

Méthodes utilitaires

Les objets Text::Iconv fournissent également les méthodes suivantes :

retval() retourne la valeur de retour de la fonction sous-jacente iconv() pour la dernière conversion ; selon la Single UNIX Specification, cette valeur indique "le nombre de conversions non identiques effectuées". Notez cependant que les implémentations de iconv varient considérablement dans l'interprétation de cette spécification.

Cette méthode peut être appelée après l'appel à convert(), par ex. :

$result = $converter->convert("lorem ipsum dolor sit amet");
$retval = $converter->retval;

Lorsqu'elle est appelée avant le premier appel à convert(), ou si une erreur s'est produite pendant la conversion, retval() retourne undef.

get_attr() : Cette méthode n'est disponible qu'avec GNU libiconv, sinon elle lève une exception. La méthode get_attr() vous permet d'interroger divers attributs qui influencent le comportement de convert(). Les attributs actuellement pris en charge sont trivialp, transliterate, et discard_ilseq, par ex. :

$state = $converter->get_attr("transliterate");

Voir iconvctl(3) pour plus de détails. Pour assurer la portabilité vers d'autres implémentations d'iconv, vous devriez d'abord vérifier la disponibilité de cette méthode en utilisant eval {}, par ex. :

eval { $conv->get_attr("trivialp") };
if ($@)
{
  # get_attr() n'est pas disponible
}
else
{
  # get_attr() est disponible
}

Cette méthode doit être considérée comme expérimentale.

set_attr() : Cette méthode n'est disponible qu'avec GNU libiconv, sinon elle lève une exception. La méthode set_attr() vous permet de définir divers attributs qui influencent le comportement de convert(). Les attributs actuellement pris en charge sont transliterate et discard_ilseq, par ex. :

$state = $converter->set_attr("transliterate");

Voir iconvctl(3) pour plus de détails. Pour assurer la portabilité vers d'autres implémentations d'iconv, vous devriez d'abord vérifier la disponibilité de cette méthode en utilisant eval {}, cf. la description de set_attr() ci-dessus.

Cette méthode doit être considérée comme expérimentale.

ERREURS

Si la conversion ne peut pas être initialisée, une exception est levée (en utilisant croak()).

Gestion des erreurs de conversion

Text::Iconv fournit un attribut de classe raise_error et une méthode de classe correspondante pour définir et obtenir sa valeur. La gestion des erreurs pendant la conversion dépend du réglage de cet attribut. Si raise_error est défini sur une valeur vraie, une exception est levée ; sinon, la méthode convert() retourne seulement undef. Par défaut, raise_error est faux. Exemple d'utilisation :

Text::Iconv->raise_error(1);     # Les erreurs de conversion lèvent des exceptions
Text::Iconv->raise_error(0);     # Les erreurs de conversion retournent undef
$a = Text::Iconv->raise_error(); # Obtenir le réglage actuel

Gestion des erreurs de conversion par objet

En tant que fonctionnalité expérimentale, Text::Iconv fournit également un attribut d'instance raise_error et une méthode correspondante pour définir et obtenir sa valeur. Si raise_error est undef, les réglages au niveau de la classe s'appliquent. Si raise_error est 1 ou 0 (vrai ou faux), les réglages de l'objet remplacent les réglages au niveau de la classe.

Consultez iconv(3) pour les détails sur les erreurs qui peuvent survenir.

Conversion de undef

La conversion de undef, par ex. :

$converted = $converter->convert(undef);

retourne toujours undef. Ce n'est pas considéré comme une erreur.

NOTES

Les jeux de caractères pris en charge, leurs noms, les conversions prises en charge et la qualité des conversions dépendent tous du système.
