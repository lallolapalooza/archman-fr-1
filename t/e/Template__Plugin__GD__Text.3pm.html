NOM

Template::Plugin::GD::Text - Utilitaires de texte à utiliser avec GD

SYNOPSIS

[% USE gd_text = GD.Text %]

EXEMPLES

[%
    USE gd_c = GD.Constants;
    USE t = GD.Text;
    x = t.set_text('Some text');
    r = t.get('width', 'height', 'char_up', 'char_down');
    r.join(":"); "\n";     # retourne 54:13:13:0.
-%]
[%
    USE gd_c = GD.Constants;
    USE t = GD.Text(text => 'FooBar Banana', font => gd_c.gdGiantFont);
    t.get('width'); "\n";  # retourne 117.
-%]

DESCRIPTION

Le plugin GD.Text fournit une interface au module GD::Text. Il permet de calculer des attributs de chaînes de caractères comme la largeur et la hauteur en pixels.

Voir GD::Text pour plus de détails. Voir Template::Plugin::GD::Text::Align et Template::Plugin::GD::Text::Wrap pour des plugins qui permettent de rendre du texte aligné ou mis en forme dans des images GD.
