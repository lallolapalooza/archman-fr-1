Test2::Manual::Tooling::Plugin::ToolStarts(3perl) Guide du programmeur Perl Test2::Manual::Tooling::Plugin::ToolStarts(3perl)

NOM

Test2::Manual::Tooling::Plugin::ToolStarts - Comment ajouter des comportements qui se produisent lorsqu'un outil démarre son travail.

DESCRIPTION

Ce tutoriel vous aidera à écrire des plugins qui ont un comportement au démarrage d'un outil. Tous les outils devraient commencer par acquérir un objet de contexte. Ce tutoriel vous montre les crochets que vous pouvez utiliser pour profiter de l'acquisition du contexte.

CODE COMPLET ANTICIPÉ

package Test2::Plugin::MyPlugin;
use Test2::API qw{
    test2_add_callback_context_init
    test2_add_callback_context_acquire
};
sub import {
    my $class = shift;
    # Informez-nous à chaque fois qu'un outil demande un contexte, et donnez-nous une
    # occasion de modifier les paramètres avant que nous le trouvions.
    test2_add_callback_context_acquire(sub {
        my $params_ref = shift;
        print "Un outil a demandé le contexte\n";
    });
    # Appel de rappel à chaque fois qu'un nouveau contexte est créé, non appelé si un
    # contexte existant est trouvé.
    test2_add_callback_context_init(sub {
        my $ctx_ref = shift;
        print "Un nouveau contexte a été créé\n";
    });
}
1;

LIGNE PAR LIGNE

use Test2::API qw{test2_add_callback_context_init test2_add_callback_context_acquire};
Ceci importe les rappels test2_add_callback_context_init() et test2_add_callback_context_acquire().
test2_add_callback_context_acquire(sub { ... })
C'est ici que nous ajoutons notre rappel pour l'acquisition du contexte. Chaque fois que Test2::API::context() est appelé, le rappel sera exécuté.
my $params_ref = shift
Dans les rappels de test2_add_callback_context_acquire(), nous recevons exactement 1 argument, une référence aux paramètres que context() utilisera pour trouver le contexte.
print "Un outil a demandé le contexte\n"
Imprime une notification chaque fois qu'un outil demande un contexte.
test2_add_callback_context_init(sub { ... })
Ajoute notre rappel d'initialisation de contexte. Ces rappels sont déclenchés chaque fois qu'un nouveau contexte est créé. Ceci n'est pas appelé si un contexte existant est trouvé. En bref, ceci ne se déclenche que pour l'outil de niveau supérieur, pas pour les outils imbriqués.
my $ctx_ref = shift
Les références de code pour test2_add_callback_context_init() recevront exactement 1 argument, le contexte nouvellement créé.
print "Un nouveau contexte a été créé\n"
Imprime une notification chaque fois qu'un nouveau contexte est créé.
