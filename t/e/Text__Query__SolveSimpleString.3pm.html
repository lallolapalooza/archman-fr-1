NOM

Text::Query::SolveSimpleString - Applique une expression de requête sur des chaînes

SYNOPIS

use Text::Query;
my $q=new Text::Query('+hello +world',
                      -parse => 'Text::Query::ParseSimple',
                      -solve => 'Text::Query::SolveSimpleString',
                      -build => 'Text::Query::BuildSimpleString');
$q->match('this hello is a world')

DESCRIPTION

Applique une expression construite par "Text::Query::BuildSimpleString" à une liste de chaînes.

MÉTHODES

match ([TARGET])
Si "TARGET" est un scalaire, "match" renvoie une valeur vraie si la chaîne spécifiée par "TARGET" correspond à l'expression de requête de l'objet. Si "TARGET" n'est pas fourni, la correspondance est faite avec $_.

Si "TARGET" est un tableau, "match" renvoie une liste (éventuellement vide) de tous les éléments correspondants. Si les éléments du tableau sont des références à des sous-tableaux, la correspondance est faite sur le premier élément de chaque sous-tableau. Cela permet d'associer des informations arbitraires (par exemple, des noms de fichiers) à chaque chaîne à faire correspondre.

Si "TARGET" est une référence à un tableau, "match" renvoie une référence à une liste (éventuellement vide) de tous les éléments correspondants.

matchscalar ([TARGET])
Se comporte de la même manière que "MATCH" lorsque "TARGET" est un scalaire ou n'est pas fourni. Légèrement plus rapide que "MATCH" dans ces circonstances.
