NOM

Test::Without::Module - Teste le comportement de repli en l'absence de modules

SYNTAXE

use Test::Without::Module qw( Mon::Module );
# Désormais, le chargement de Mon::Module échoue :
eval { require Mon::Module; };
warn $@ if $@;
# Maintenant, cela fonctionne à nouveau
eval q{ no Test::Without::Module qw( Mon::Module ) };
eval { require Mon::Module; };
print "Trouvé Mon::Module" unless $@;

DESCRIPTION

Ce module vous permet de masquer délibérément des modules à un programme même s'ils sont installés. Ceci est principalement utile pour tester des modules qui ont un comportement de repli lorsqu'un module de dépendance spécifique n'est pas installé.

EXPORT

Aucun. Toute la magie s'effectue via "use Test::Without::Module LIST" et "no Test::Without::Module LIST".

Test::Without::Module::get_forbidden_list

Cette fonction retourne une référence à une copie du hachage actuel des modules interdits ou un hachage vide si aucun n'est actuellement interdit. Ceci est pratique si vous testez et/ou déboguez ce module.

UNE LIGNE

Une astuce astucieuse pour utiliser ce module depuis la ligne de commande m'a été signalée par NUFFIN et Jerrad Pierce :

perl -MTest::Without::Module=Some::Module -w -Iblib/lib t/SomeModule.t

De cette façon, vous pouvez facilement observer comment votre module ou fichier de test se comporte lorsqu'un module spécifique est indisponible.

BUGS

•
Il n'y a pas de portée lexicale

CRÉDITS

Une grande partie des améliorations est à remercier à Aristotle de PerlMonks, il m'a montré une méthode beaucoup moins compliquée pour simuler un module à l'adresse https://perlmonks.org?node=192635.

J'ai également discuté avec lui d'une manière encore plus élégante de remplacer CORE::GLOBAL::require, mais l'analyse de la sous-routine remplacée ne s'est pas déroulée comme je le souhaitais - CORE::require ne reconnaissait plus les barewords comme tels.

NUFFIN et Jerrad Pierce ont signalé l'utilisation pratique depuis la ligne de commande pour observer interactivement le comportement de la suite de tests et du module en l'absence d'un module.
