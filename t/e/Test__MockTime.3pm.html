Test::MockTime(3) Documentation Perl fournie par l'utilisateur Test::MockTime(3)

NOM

Test::MockTime - Remplace le temps réel par un temps simulé

VERSION

Version 0.17

SYNOPSIS

use Test::MockTime qw( :all );
set_relative_time(-600);
# effectuez quelques tests dépendant de l'augmentation du temps depuis 600 secondes
set_absolute_time(0);
# effectuez d'autres tests dépendant du temps commençant à l'époque
# l'époque peut varier selon la plateforme. voir perlport.
set_fixed_time(CORE::time());
# effectuez d'autres tests dépendant du temps restant à l'heure actuelle réelle
set_absolute_time('1970-01-01T00:00:00Z');
# effectuez des tests dépendant du temps commençant à l'heure de l'époque Unix
set_fixed_time('01/01/1970 00:00:00', '%m/%d/%Y %H:%M:%S');
# effectuez des tests dépendant du temps restant à l'heure de l'époque Unix
restore_time();
# reprenez le service normal

DESCRIPTION

Ce module a été créé pour permettre aux suites de tests de tester du code à des moments spécifiques. Plus précisément, il remplace localtime, gmtime et time au moment de la compilation, puis s'appuie sur l'utilisateur pour fournir un temps simulé via set_relative_time, set_absolute_time ou set_fixed_time afin de modifier les appels futurs à gmtime, time ou localtime.

SOUS-ROUTINES/METHODES

set_absolute_time
Si un seul argument numérique est donné, l'argument est un temps absolu (par exemple, si 0 est fourni, le temps absolu sera l'époque) et calcule le décalage pour permettre aux appels ultérieurs de time, gmtime et localtime de refléter cela.

par exemple, dans le code suivant

Test::MockTime::set_absolute_time(0);
my ($start) = time;
sleep 2;
my ($end) = time;

La variable $end devrait contenir 2 secondes après l'époque ;

Si deux arguments sont donnés, le premier argument est considéré comme un temps absolu dans un certain format de chaîne (par exemple, "01/01/1970 00:00:00"). Le second argument est considéré comme une chaîne de format "strptime" (par exemple, "%m/%d/%Y %H:%M:%S"). Si un seul argument est donné, mais qu'il n'est pas numérique, une chaîne de format "strptime" de "%Y-%m-%dT%H:%M:%SZ" est supposée.

par exemple, dans le code suivant

Test::MockTime::set_absolute_time('1970-01-01T00:00:00Z');
my ($start) = time;
sleep 2;
my ($end) = time;

La variable $end devrait contenir 2 secondes après l'époque Unix ;

set_relative_time($relative)
prend comme argument une valeur relative par rapport au temps actuel (par exemple, si -10 est fourni, le temps actuel sera converti en temps machine réel - 10 secondes) et calcule le décalage pour permettre aux appels ultérieurs de time, gmtime et localtime de refléter cela.

par exemple, dans le code suivant

my ($start) = time;
Test::MockTime::set_relative_time(-600);
sleep 600;
my ($end) = time;

La variable $end devrait contenir des valeurs identiques ou très similaires à la variable $start.

set_fixed_time
Si un seul argument numérique est donné, l'argument est un temps absolu (par exemple, si 0 est fourni, le temps absolu sera l'époque). Tous les appels ultérieurs à gmtime, localtime et time retourneront cette valeur.

par exemple, dans le code suivant

Test::MockTime::set_fixed_time(time)
my ($start) = time;
sleep 3;
my ($end) = time;

la variable $end et la variable $start contiendront les mêmes résultats

Si deux arguments sont donnés, le premier argument est considéré comme un temps absolu dans un certain format de chaîne (par exemple, "01/01/1970 00:00:00"). Le second argument est considéré comme une chaîne de format "strptime" (par exemple, "%m/%d/%Y %H:%M:%S"). Si un seul argument est donné, mais qu'il n'est pas numérique, une chaîne de format "strptime" de "%Y-%m-%dT%H:%M:%SZ" est supposée.

restore()
restaure les valeurs de gestion du temps par défaut. "restore_time" est un alias. Lorsqu'il est exporté avec la balise 'all', cette sous-routine est exportée sous le nom "restore_time".

CONFIGURATION ET ENVIRONNEMENT

Test::MockTime ne nécessite aucun fichier de configuration ni variable d'environnement.

DÉPENDANCES

Test::MockTime dépend des modules Perl non essentiels suivants.

•
Time::Piece 1.08 ou supérieur
