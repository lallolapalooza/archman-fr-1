NOM

Text::Kakasi - interface perl pour kakasi

SYNTAXE

use Text::Kakasi;
# fonctionnel
$res = Text::Kakasi::getopt_argv('-JJ', '-c', '-w');
$str = Text::Kakasi::do_kakasi($texte_japonais);
# orienté objet
$obj = Text::Kakasi->new('-JJ', '-c', '-w');
$str = $obj->get($texte_japonais);

DESCRIPTION

Ce module fournit une interface à kakasi (inverseur simple kanji kana). kakasi est un ensemble de programmes et de bibliothèques qui font en sens inverse ce que font les méthodes de saisie japonaises. Vous donnez du japonais et kakasi le convertit en sa représentation phonétique. kakasi peut également être utilisé pour la tokenisation du texte japonais. Pour en savoir plus sur kakasi, voir http://kakasi.namazu.org/.

Text::Kakasi propose désormais des API fonctionnelles et orientées objet. Les API fonctionnelles sont 100% compatibles avec la version 1.05. Mais pour profiter des « Fonctionnalités de Perl 5.8 », vous devriez plutôt utiliser les API OOP.

Voir Text::Kakasi::JP pour la version japonaise de ce document.

API Fonctionnelles

Notez que "Text::Kakasi::" est omis. Text::Kakasi n'exporte pas ces fonctions par défaut. Vous pouvez importer ces fonctions comme suit ;

use Text::Kakasi qw/getopt_argv do_kakasi/;
$err = getopt_argv($arg1, $arg2, ...)
initialise kakasi avec des options. Les options sont les mêmes que la commande "kakasi". Voici un résumé tel qu'il était pour kakasi 2.3.4. 
-a[jE] -j[aE] -g[ajE] -k[ajKH]
-E[aj] -K[ajkH] -H[ajkK] -J[ajkKH]
-i{oldjis,newjis,dec,euc,sjis}
 -o{oldjis,newjis,dec,euc,sjis}
-r{hepburn,kunrei} -p -s -f -c"chars" 
 [jisyo1, jisyo2,,,]
Jeux de caractères :
     a: ascii  j: jisroman  g: graphic  k: kana 
     (j,k     définis dans jisx0201)
     E: kigou  K: katakana  H: hiragana J: kanji
     (E,K,H,J définis dans jisx0208)
Options :
  -i : système de codage d'entrée    -o : système de codage de sortie
  -r : système de conversion romaji
  -p : lister toutes les lectures (avec l'option -J)
  -s : insérer des caractères séparateurs (avec l'option -J)
  -f : mode furigana (avec l'option -J)
  -c : ignorer les caractères dans jukugo
      (avec l'option -J : par défaut TAB CR LF ESPACE)
  -C : Romaji Capitalize (avec l'option -Ja ou -Jj)
  -U : Romaji Upcase     (avec l'option -Ja ou -Jj)
  -u : appeler fflush() après la sortie d'1 caractère
  -w : mode wakatigaki

Retourne 0 en cas de succès et une valeur non nulle en cas d'échec.

Contrairement à la version 1.x où vous deviez commencer le premier argument avec "kakasi", vous pouvez l'omettre dans la version 2.x (ajouter "kakasi" ne nuit pas, donc la compatibilité est préservée).

$result_str = do_kakasi($str)
applique kakasi à $str et retourne le résultat. Si quelque chose tourne mal, il retourne "undef".
close_kanwadic()
ferme les fichiers du dictionnaire qui sont implicitement ouverts. Cette fonction est uniquement pour la compatibilité ascendante et vous ne devriez jamais avoir à l'utiliser aujourd'hui.

API Orientées Objet

Depuis la version 2.0, Text::Kakasi offre également des API OOP.

$k = Text::Kakasi->new($args ...)
Construit un objet. Lorsque des arguments sont fournis, c'est équivalent à "Text::Kakasi->new->set($args ...)"
$k->set($args ...)
Interface OOP pour "getopt_argv". 
my $k = Text::Kakasi->new;
$k->set('-w'); # Text::Kakasi::getopt_argv('-w');

Contrairement à getopt_argv() qui retourne l'état, "set" retourne l'objet lui-même, vous pouvez donc faire ceci ;

my $tokenized = $k->set('-w')->get($raw_japanese);

Pour obtenir l'état de "$k->set", utilisez "$k->error".

Voir aussi « Fonctionnalités de Perl 5.8 ».

$k->error
retourne l'état de la dernière méthode.
$result = $k->get($raw_japanese);
Interface OOP pour "do_kakasi". Les codes suivants sont équivalents. 
# Fonctionnel
getopt_argv('-w'); $result = do_kakasi($raw_japanese);
# OOP
$k->set('-w')->get($raw_japanese);

Fonctionnalités de Perl 5.8

Perl 5.8 introduit le module Encode qui transcodes divers encodages. Ce module tire parti de cette fonctionnalité, mais pour maintenir la compatibilité ascendante avec la version 1.x, cette fonctionnalité n'est activée que lorsque vous utilisez l'interface OOP (la version 1.x ne fournissait que des API fonctionnelles).

Sur Perl 5.8 et supérieur, "-iencoding" et "-oencoding" sont gérés par le module Encode, vous pouvez donc utiliser des encodages que Kakasi ne supporte pas, comme utf8. En d'autres termes,

$result = $k->set(qw/-iutf8 -outf8 -w/)->get($utf8);

Est analogue à :

$euc = encode('eucjp' => $utf8);
getopt_argv('-w');
$tmp = do_kakasi($euc);
$result = decode('eucjp' => $tmp);

Lorsque vous spécifiez "-outf8", "$k->get" retournera la chaîne avec le drapeau utf8 activé.

Vous pouvez désactiver cette fonctionnalité en réglant $Text::Kakasi::HAS_ENCODE à 0, auquel cas cette fonctionnalité ne sera pas utilisée.
