Test2::Util::Times(3perl) Guide de référence du programmeur Perl Test2::Util::Times(3perl)

NOM

Test2::Util::Times - Formate les informations de chronométrage/benchmarking.

DESCRIPTION

Ce module exporte des outils pour rendre les données de chronométrage à la fin des tests.

EXPORTATIONS

Toutes les exportations sont optionnelles. Vous devez spécifier les subs à importer.

$str = render_bench($start, $end, $user, $system, $cuser, $csystem)
$str = render_bench($start, time(), times())
Ceci produira une chaîne comme l'une des suivantes (Notez que ces nombres sont complètement inventés). La chaîne utilisée dépend du temps écoulé. 
0.12345s sur horloge murale (0.05 usr 0.00 sys + 0.00 cusr 0.00 csys = 0.05 CPU)
11.1234s sur horloge murale (0.05 usr 0.00 sys + 0.00 cusr 0.00 csys = 0.05 CPU)
01m:54.45s sur horloge murale (0.05 usr 0.00 sys + 0.00 cusr 0.00 csys = 0.05 CPU)
18h:22m:54.45s sur horloge murale (0.05 usr 0.00 sys + 0.00 cusr 0.00 csys = 0.05 CPU)
04j:18h:22m:54.45s sur horloge murale (0.05 usr 0.00 sys + 0.00 cusr 0.00 csys = 0.05 CPU)

Les 2 premiers arguments sont les temps $start et $end en secondes (tels que retournés par time() ou Time::HiRes::time()).

Les 4 derniers arguments sont des informations de chronométrage telles que retournées par la fonction times().
