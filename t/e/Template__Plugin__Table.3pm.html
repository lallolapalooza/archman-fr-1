NOM

Template::Plugin::Table - Plugin pour afficher des données sous forme de tableau

SYNOPIS

[% USE table(list, rows=n, cols=n, overlap=n, pad=0) %]
[% FOREACH item IN table.row(n) %]
   [% item %]
[% END %]
[% FOREACH item IN table.col(n) %]
   [% item %]
[% END %]
[% FOREACH row IN table.rows %]
   [% FOREACH item IN row %]
      [% item %]
   [% END %]
[% END %]
[% FOREACH col IN table.cols %]
   [% col.first %] - [% col.last %] ([% col.size %] entrées)
[% END %]

DESCRIPTION

Le plugin « Table » permet de formater une liste de données sous forme de tableau virtuel. Lors de la création d'un plugin « Table » via la directive « USE », vous passez simplement une référence à une liste comme premier paramètre, puis spécifiez un nombre fixe de lignes ou de colonnes.

[% USE Table(list, rows=5) %]
[% USE table(list, cols=5) %]

Le nom du plugin « Table » peut également être spécifié en minuscules, comme dans l'exemple ci-dessous. Vous pouvez également spécifier un nom alternatif pour le plugin, comme dans la syntaxe standard de Template Toolkit.

[% USE mydata = table(list, rows=5) %]

Le plugin présente alors une vue tabulaire basée sur l'ensemble de données. Les données ne sont pas réellement réorganisées, mais sont accessibles via les méthodes row(), col(), rows() et cols(), comme si elles avaient été formatées dans un tableau bidimensionnel de "n" lignes x "n" colonnes.

Ainsi, si nous avions une liste d'exemple « alphabet » contenant les lettres « a » à « z », les directives « USE » ci-dessus créeraient des plugins représentant les vues suivantes de l'alphabet.

[% USE table(alphabet, ... %]
rows=5                  cols=5
a  f  k  p  u  z        a  g  m  s  y
b  g  l  q  v           b  h  n  t  z
c  h  m  r  w           c  i  o  u
d  i  n  s  x           d  j  p  v
e  j  o  t  y           e  k  q  w
                        f  l  r  x

Nous pouvons demander une ligne ou une colonne spécifique via les méthodes row() et col().

[% USE table(alphabet, rows=5) %]
[% FOREACH item = table.row(0) %]
   # [% item %] est défini sur chacun de [ a f k p u z ]
[% END %]
[% FOREACH item = table.col(2) %]
   # [% item %] est défini sur chacun de [ m n o p q r ]
[% END %]

Les données dans les lignes sont retournées de gauche à droite, les colonnes de haut en bas. La première ligne/colonne est 0. Par défaut, les lignes ou colonnes contenant des valeurs vides sont remplies avec la valeur undefined afin de correspondre à la même taille que les autres lignes ou colonnes.

Par exemple, la dernière ligne (ligne 4) dans le premier exemple contiendrait les valeurs « [ e j o t y undef ] ». Template Toolkit acceptera probablement ces valeurs undefined et affichera une chaîne vide. Vous pouvez également utiliser la directive IF pour tester si la valeur est définie.

[% FOREACH item = table.row(4) %]
   [% IF item %]
      Item: [% item %]
   [% END %]
[% END %]

Vous pouvez explicitement désactiver l'option « pad » lors de la création du plugin afin de retourner des lignes/colonnes courtes là où les données sont vides.

[% USE table(alphabet, cols=5, pad=0) %]
[% FOREACH item = table.col(4) %]
   # [% item %] est défini sur 'y z'
[% END %]

La méthode rows() retourne toutes les lignes/colonnes du tableau sous forme de référence à une liste de lignes (mêmes références de liste). La méthode row() lorsqu'elle est appelée sans argument appelle la méthode rows() pour retourner toutes les lignes du tableau.

Il en va de même pour cols() et col().

[% USE table(alphabet, cols=5) %]
[% FOREACH row = table.rows %]
   [% FOREACH item = row %]
      [% item %]
   [% END %]
[% END %]

Template Toolkit fournit les méthodes virtuelles "first", "last" et "size" qui peuvent être appelées sur des références de liste pour retourner le premier/dernier élément ou le nombre d'éléments dans une liste. L'exemple suivant montre comment nous pourrions utiliser cela pour fournir un index alphabétique divisé en 3 parties égales.

[% USE table(alphabet, cols=3, pad=0) %]
[% FOREACH group = table.col %]
   [ [% group.first %] - [% group.last %] ([% group.size %] lettres) ]
[% END %]

Ceci produit la sortie suivante :

[ a - i (9 lettres) ]
[ j - r (9 lettres) ]
[ s - z (8 lettres) ]

Nous pouvons également utiliser la méthode virtuelle générale "join" qui joint les éléments de la liste avec la chaîne de connexion spécifiée.

[% USE table(alphabet, cols=5) %]
[% FOREACH row = table.rows %]
   [% row.join(' - ') %]
[% END %]

Les données du tableau sont triées vers le bas au lieu de la droite, mais peuvent facilement être transformées pour la sortie. Par exemple, pour formater nos données en 5 colonnes avec l'ordre des données vers la droite au lieu du bas, nous spécifions « rows=5 » pour trier les données comme ceci :

a  f  .  .
b  g  .
c  h
d  i
e  j

puis nous itérons vers le bas dans chaque colonne (a-e, f-j, etc.) en imprimant les données vers la droite.

a  b  c  d  e
f  g  h  i  j
.  .
.

Le code d'exemple pour faire cela serait très similaire à ce qui suit :

[% USE table(alphabet, rows=3) %]
[% FOREACH cols = table.cols %]
  [% FOREACH item = cols %]
    [% item %]
  [% END %]
[% END %]

Sortie :

a  b  c
d  e  f
g  h  i
j  .  .
.

En plus d'une référence à une liste, le constructeur du plugin « Table » peut passer une référence à un objet Template::Iterator ou à une classe dérivée. La méthode get_all() de l'itérateur est appelée en premier pour retourner tous les éléments restants. Ceux-ci sont ensuite disponibles via l'interface normale du plugin.

[% USE DBI(dsn,user,pass) -%]
# query() retourne un itérateur
[% results = DBI.query('SELECT * FROM alphabet ORDER BY letter') %]
# passe dans le plugin Table
[% USE table(results, rows=8 overlap=1 pad=0) -%]
[% FOREACH row = table.cols -%]
   [% row.first.letter %] - [% row.last.letter %]:
      [% row.join(', ') %]
[% END %]
