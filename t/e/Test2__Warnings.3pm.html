Test2::Warnings(3) Documentation Perl fournie par l'utilisateur Test2::Warnings(3)

NOM

Test2::Warnings - Tester les avertissements et leur absence

VERSION

version 0.038

SYNOPSIS

use Test2::V0;
use Test::Warnings;
pass('yay!');
done_testing;

génère TAP:

ok 1 - yay!
ok 2 - pas (d'avertissements inattendus) (via done_testing)
1..2

et:

use Test::More tests => 3;
use Test::Warnings 0.005 ':all';
pass('yay!');
like(warning { warn "oh noes!" }, qr/^oh noes/, 'nous avons averti');

génère TAP:

ok 1 - yay!
ok 2 - nous avons averti
ok 3 - pas (d'avertissements inattendus) (via bloc END)
1..3

DESCRIPTION

Voir Test::Warnings pour la documentation complète.

Pour l'instant, il s'agit d'un simple wrapper autour de Test::Warnings, mais il est prévu d'en faire un port complet et d'éliminer toute compatibilité ancienne avec Test::Builder et d'utiliser correctement la suite Test2.
