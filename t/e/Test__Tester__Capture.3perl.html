NOM

Test::Tester::Capture - Aide au test des modules de test construits avec Test::Builder

DESCRIPTION

Ceci est une sous-classe de Test::Builder qui surcharge de nombreuses méthodes afin qu'elles ne génèrent aucune sortie. Elle conserve également sa propre collection de résultats de tests, vous permettant ainsi d'utiliser des modules basés sur Test::Builder pour effectuer des tests sur d'autres modules basés sur Test::Builder.

AUTEUR

La plupart du code ici a été extrait directement de Test::Builder puis des parties ont été supprimées par Fergal Daly <fergal@esatclear.ie>.
