Test::Alien::Run(3) Documentation Perl fournie par l'utilisateur Test::Alien::Run(3)

NOM

Test::Alien::Run - Objet d'exécution

VERSION

version 2.84

SYNOPSIS

use Test2::V0;
use Test::Alien;

run_ok([ $^X, -e => 'print "some output"; exit 22'])
  ->exit_is(22)
  ->out_like(qr{some});

DESCRIPTION

Cette classe stocke les informations sur une exécution de processus telle qu'effectuée par Test::Alien#run_ok. Cette fonction est la *seule* façon de créer une instance de cette classe.

ATTRIBUTS

out

my $str = $run->out;

La sortie standard de l'exécution.

err

my $str = $run->err;

L'erreur standard de l'exécution.

exit

my $int = $run->exit;

La valeur de sortie de l'exécution.

signal

my $int = $run->signal;

Le signal qui a terminé l'exécution, ou zéro si le processus a été terminé normalement.

MÉTHODES

Ces méthodes retournent l'objet d'exécution lui-même, de sorte qu'elles puissent être enchaînées, comme dans la synopsie ci-dessus.

success

$run->success;
$run->success($message);

Réussit si le processus s'est terminé normalement avec une valeur de sortie de 0.

exit_is

$run->exit_is($exit);
$run->exit_is($exit, $message);

Réussit si le processus s'est terminé avec la valeur de sortie donnée.

exit_isnt

$run->exit_isnt($exit);
$run->exit_isnt($exit, $message);

Réussit si le processus s'est terminé avec une valeur de sortie autre que celle donnée.

out_like

$run->out_like($regex);
$run->out_like($regex, $message);

Réussit si la sortie de l'exécution correspond au motif donné.

out_unlike

$run->out_unlike($regex);
$run->out_unlike($regex, $message);

Réussit si la sortie de l'exécution ne correspond pas au motif donné.

err_like

$run->err_like($regex);
$run->err_like($regex, $message);

Réussit si l'erreur standard de l'exécution correspond au motif donné.

err_unlike

$run->err_unlike($regex);
$run->err_unlike($regex, $message);

Réussit si l'erreur standard de l'exécution ne correspond pas au motif donné.

note

$run->note;

Envoie la sortie et l'erreur standard comme note de test.

diag

$run->diag;

Envoie la sortie et l'erreur standard comme diagnostic de test.
