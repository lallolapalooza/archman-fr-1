Template::Manual::VMethods - Méthodes virtuelles

Méthodes virtuelles scalaires

chunk(taille)

Divise la valeur en une liste de morceaux d'une certaine taille.

[% ccard_no = "1234567824683579";
   ccard_no.chunk(4).join
%]

Sortie :

1234 5678 2468 3579

Si la taille est spécifiée comme un nombre négatif, le texte sera découpé de droite à gauche. Cela donne le bon regroupement pour les nombres, par exemple.

[% number = 1234567;
   number.chunk(-3).join(',')
%]

Sortie :

1,234,567

collapse

Retourne le texte avec les espaces blancs de début et de fin supprimés et les séquences d'espaces blancs internes converties en un seul espace.

[% text = "  Le\n  singe\n  est le\n  mot" %]
[% text.collapse %]       # Le singe est le mot

defined

Retourne vrai si la valeur est définie.

[% user = get_user(uid) IF uid.defined %]

dquote

Retourne le texte avec les guillemets doubles échappés avec un préfixe antislash. Tous les caractères de nouvelle ligne dans le texte seront remplacés par "\n".

[% quote = 'Il a dit "Oh vraiment ?"' %]
[% quote.dquote %]        # Il a dit \"Oh vraiment ?\"

hash

Retourne la valeur sous forme de référence de hachage contenant une seule entrée avec la clé "value" indiquant la valeur scalaire d'origine. Comme avec la méthode virtuelle "list", cela est généralement utilisé pour aider à transformer les données dans différents formats.

lcfirst

Retourne le texte avec la première lettre convertie en minuscule.

[% word = 'OISEAU' %]
[% word.lcfirst %]        # oISEAU

length

Retourne la longueur de la représentation textuelle de l'élément :

[% IF password.length < 8 %]
   Mot de passe trop court, imbécile !
[% END %]

empty

Retourne vrai si la chaîne est vide :

[% IF details.empty %]
   Aucun détail spécifié
[% END %]

list

Retourne la valeur sous forme de liste à un seul élément. Cela peut être utile si vous avez une variable qui peut contenir un seul élément ou une liste et que vous souhaitez les traiter de manière égale. La méthode "list" peut être appelée sur une référence de liste et retournera simplement la référence d'origine, ce qui est effectivement une opération nulle.

[% thing.list.size %]     # thing peut être un scalaire ou une liste

lower

Retourne le texte en minuscules.

[% word = 'OISEAU' %]
[% word.lower %]          # oiseau

match(pattern, global)

Effectue une correspondance d'expression régulière sur la chaîne à l'aide du motif passé en argument. Si le motif correspond à la chaîne, la méthode retourne une référence à une liste de toutes les chaînes capturées entre parenthèses dans le motif.

[% name = 'Larry Wall' %]
[% matches = name.match('(\w+) (\w+)') %]
[% matches.1 %], [% matches.0 %]    # Wall, Larry

Si le motif ne correspond pas, la méthode retourne faux, plutôt que de retourner une liste vide que Perl et le Template Toolkit considèrent comme une valeur vraie. Cela vous permet d'écrire des expressions comme celle-ci.

[% "Nous ne sommes pas dignes !" IF name.match('Larry Wall') %]
[% IF (matches = name.match('(\w+) (\w+)')) %]
   Les motifs correspondent : [% matches.join(', ') %]
[% ELSE %]
   Les motifs ne correspondent pas
[% END %]

Tous les modificateurs regex, comme "/s", doivent être ajoutés dans le regex en utilisant la syntaxe "(?s)". Par exemple, pour modifier le regex afin d'ignorer les espaces blancs (le commutateur "/x"), utilisez :

[% re = '(?x)
           (\w+)
           [ ]
           (\w+)
         ';
  matches = name.match(re);
%]

Pour effectuer une recherche globale afin de faire correspondre le motif autant de fois qu'il apparaît dans la chaîne source, fournissez une valeur vraie pour l'argument "global" après le motif.

[% text = 'bandanna';
   text.match('an+', 1).join(', ')      # an, ann
%]

repeat(n)

Répète la chaîne un nombre spécifié de fois.

[% name = 'foo' %]
[% name.repeat(3) %]                # foofoofoo

replace(search, replace)

Affiche la chaîne avec toutes les instances du premier argument (spécifié comme une expression régulière Perl) remplacées par le second.

[% name = 'foo, bar & baz' %]
[% name.replace('\W+', '_') %]        # foo_bar_baz

Vous pouvez utiliser $1, $2, etc., pour faire référence aux parties capturées (entre parenthèses) dans l'expression régulière. Faites juste attention à guillemeter simplement la chaîne de remplacement. Si vous utilisez des guillemets doubles, TT essaiera d'interpoler les variables avant de passer la chaîne à la méthode virtuelle "replace".

[% name = 'FooBarBaz' %]
[% name.replace('([A-Z])', ' $1') %]  # Foo Bar Baz

remove(pattern)

Affiche la chaîne avec toutes les instances du motif (spécifié comme une expression régulière Perl) supprimées.

[% name = 'foo, bar & baz' %]
[% name.remove('\W+') %]    # foobarbaz

search(pattern)

Effectue une fonction similaire à match mais retourne simplement vrai si la chaîne correspond au motif d'expression régulière passé en argument.

[% name = 'foo bar baz' %]
[% name.search('bar') ? 'bar' : 'pas de bar' %]     # bar

Cette méthode virtuelle est maintenant obsolète au profit de match. Passez votre chemin, il n'y a plus rien à voir ici.

size

Retourne toujours 1 pour les valeurs scalaires. Cette méthode est fournie pour la cohérence avec les méthodes de taille de hachage et de liste.

split(pattern)

Appelle la fonction split() de Perl pour diviser une chaîne en une liste de chaînes.

[% FOREACH dir IN mypath.split(':') %]
   [% dir %]
[% END %]

substr(offset, length, replacement)

Retourne une sous-chaîne commençant à "offset", pendant "length" caractères.

[% str 'foo bar baz wiz waz woz') %]
[% str.substr(4, 3) %]    # bar

Si "length" n'est pas spécifié, il retourne tout de "offset" jusqu'à la fin de la chaîne.

[% str.substr(12) %]      # wiz waz woz

Si "length" et "replacement" sont spécifiés, la méthode remplace tout de "offset" sur "length" caractères par $replacement. La sous-chaîne retirée de la chaîne est ensuite retournée.

[% str.substr(0, 11, 'FOO') %]   # foo bar baz
[% str %]                        # FOO wiz waz woz

squote

Retourne le texte avec les apostrophes échappées avec un préfixe antislash.

[% tim = "Tim O'Reilly" %]
[% tim.squote %]          # Tim O\'Reilly

trim

Renvoie le texte avec les espaces blancs du début et de la fin supprimés.

[% text = '  hello  world  ' %]
[% text.trim %]           # hello  world

ucfirst

Renvoie le texte avec la première lettre mise en majuscule.

[% word = 'bird' %]
[% word.ucfirst %]        # Bird

upper

Renvoie le texte en majuscules.

[% word = 'bird' %]
[% word.upper %]          # BIRD

Méthodes virtuelles Hash

keys

Renvoie une liste de clés du hash. Celles-ci ne sont pas renvoyées dans un ordre particulier, mais l'ordre est le même que celui des méthodes correspondantes des valeurs.

[% FOREACH key IN hash.keys %]
   * [% key %]
[% END %]

Si vous souhaitez obtenir les clés dans un ordre trié, utilisez la méthode sort.

[% FOREACH key IN hash.keys.sort %]
   * [% key %]
[% END %]

Une fois que vous avez obtenu les clés dans un ordre trié, vous pouvez utiliser l'interpolation de variables pour récupérer la valeur. Ceci est illustré dans l'exemple par l'utilisation de $key pour récupérer l'élément du hash dont la clé est stockée dans la variable key.

[% FOREACH key IN hash.keys.sort %]
   * [% key %] = [% hash.$key %]
[% END %]

Alternativement, vous pouvez utiliser la méthode pairs pour obtenir une liste de paires clé-valeur dans un ordre trié.

values

Renvoie une liste des valeurs du hash. Comme pour la méthode keys, elles ne sont pas renvoyées dans un ordre particulier, bien que l'ordre soit le même que celui renvoyé pour les clés.

[% hash.values.join(', ') %]

items

Renvoie une liste des clés et des valeurs étendues en une seule liste.

[% hash = {
      a = 10
      b = 20
   };
   hash.items.join(', ')    # a, 10, b, 20
%]

each

Cette méthode renvoie actuellement la même chose que la méthode items.

Cependant, notez que cette méthode changera dans la prochaine version majeure de Template Toolkit (v3) pour renvoyer la même chose que la méthode pairs. Cela sera fait dans le but de rendre ces méthodes virtuelles plus cohérentes entre elles et avec le fonctionnement de Perl.

En prévision de cela, nous vous recommandons d'arrêter d'utiliser hash.each et d'utiliser hash.items à la place.

pairs

Cette méthode renvoie une liste de paires clé-valeur. Celles-ci sont renvoyées dans un ordre trié par les clés.

[% FOREACH pair IN product.pairs %]
   * [% pair.key %] est [% pair.value %]
[% END %]

list

Renvoie le contenu du hash sous forme de liste. Un argument peut être passé pour indiquer les éléments souhaités dans la liste : keys pour obtenir une liste de clés (identique à hash.keys), values pour obtenir une liste de valeurs (identique à hash.values), each pour obtenir une liste de clés et de valeurs (identique à hash.each), ou pairs pour obtenir une liste de paires clé-valeur (identique à hash.pairs).

[% keys   = hash.list('keys') %]
[% values = hash.list('values') %]
[% items  = hash.list('each') %]
[% pairs  = hash.list('pairs') %]

Lorsqu'elle est appelée sans argument, elle renvoie actuellement la même chose que la méthode pairs. Cependant, notez que cette méthode changera dans la prochaine version majeure de Template Toolkit (v3) pour renvoyer une référence à une liste contenant uniquement la référence au hash (comme c'est le cas avec la méthode scalar.list).

En prévision de cela, nous vous recommandons d'arrêter d'utiliser hash.list et d'utiliser hash.pairs à la place.

sort, nsort

Renvoie une liste de clés, triées alphabétiquement (sort) ou numériquement (nsort) selon les valeurs correspondantes du hash.

[% FOREACH n IN phones.sort %]
   [% phones.$n %] est [% n %],
[% END %]

import

La méthode import peut être appelée sur un tableau de hash pour importer le contenu d'un autre tableau de hash.

[% hash1 = {
     foo = 'Foo'
     bar = 'Bar'
   }
   hash2 = {
       wiz = 'Wiz'
       woz = 'Woz'
   }
%]
[% hash1.import(hash2) %]
[% hash1.wiz %]             # Wiz

Vous pouvez également appeler la méthode import() elle-même pour importer un tableau de hash dans l'espace de portée actuel.

[% user = { id => 'lwall', name => 'Larry Wall' } %]
[% import(user) %]
[% id %]: [% name %]        # lwall: Larry Wall

defined, exists

Renvoie une valeur vraie ou fausse si l'élément dénoté par la clé passée comme argument dans le hash est défini ou existe, respectivement.

[% hash.defined('somekey') ? 'yes' : 'no' %]
[% hash.exists('somekey') ? 'yes' : 'no' %]

Lorsqu'elle est appelée sans argument, hash.defined renvoie vrai si le hash lui-même est défini (par exemple, le même effet que scalar.defined).

delete

Supprime un ou plusieurs éléments du hash.

[% hash.delete('foo', 'bar') %]

size

Renvoie le nombre de paires clé-valeur dans le hash.

empty

Renvoie vrai si le hash est vide :

[% IF config.empty %]
   Aucune configuration trouvée
[% END %]

item

Renvoie un élément du hash en utilisant une clé passée comme argument.

[% hash.item('foo') %]  # identique à hash.foo

Méthodes virtuelles List

first, last

Renvoie le premier/dernier élément de la liste. L'élément n'est pas supprimé de la liste.

[% results.first %] à [% results.last %]

Si un argument numérique n est passé, elles renvoient les n premiers ou derniers éléments :

Les 5 premiers résultats sont [% results.first(5).join(", ") %].

size, max

Renvoie la taille d'une liste (nombre d'éléments) et le nombre d'index maximum (taille - 1), respectivement.

[% results.size %] résultats de recherche correspondent à votre requête

empty

Renvoie vrai si la liste est vide :

[% IF results.empty %]
   Aucun résultat trouvé
[% END %]

defined

Renvoie une valeur vraie ou fausse si l'élément de la liste dénoté par l'argument est défini.

[% list.defined(3) ? 'yes' : 'no' %]

Lorsqu'elle est appelée sans argument, list.defined renvoie vrai si la liste elle-même est définie (par exemple, le même effet que scalar.defined).

reverse

Renvoie les éléments de la liste dans l'ordre inverse.

[% FOREACH s IN scores.reverse %]
   ...
[% END %]

join

Joint les éléments de la liste en une seule chaîne, en utilisant la fonction join() de Perl.

[% items.join(', ') %]

grep

Renvoie une liste des éléments de la liste qui correspondent à un modèle d'expression régulière.

[% FOREACH directory.files.grep('\.txt$') %]
   ...
[% END %]

sort, nsort

Renvoie les éléments de la liste dans un ordre alphabétique (sort) ou numérique (nsort) selon la valeur correspondante du hash.

[% library = books.sort %]

Un argument peut être fourni pour spécifier la clé de tri. Si un élément de la liste est une référence à un hash, la clé sera utilisée pour récupérer une valeur du hash, qui sera utilisée comme valeur de comparaison. Si un élément est un objet qui implémente une méthode de ce nom, la méthode sera appelée pour obtenir la valeur de comparaison.

[% library = books.sort('author') %]

Dans l'exemple, books peut contenir des références à des hash avec une clé author ou des objets avec une méthode author.

Vous pouvez également spécifier plusieurs clés de tri.

[% library = books.sort('author', 'title') %]

Dans ce cas, les livres seront triés d'abord par auteur. Si deux livres ou plus ont des auteurs portant le même nom, ils seront triés par titre.

unshift(item), push(item)

La méthode push() ajoute un élément ou des éléments à la fin de la liste.

Promotion automatique du scalaire en liste pour les méthodes virtuelles

En plus des méthodes virtuelles scalaires listées dans la section précédente, vous pouvez également appeler n'importe quelle méthode virtuelle d'une liste sur un scalaire. L'élément sera automatiquement converti en une liste contenant un seul élément et la méthode virtuelle correspondante sera appelée.

Un avantage particulier de cette situation se produit lorsque vous appelez des sous-routines ou des méthodes d'objets qui renvoient une liste d'éléments, plutôt qu'une référence préférée à une liste d'éléments. Dans ce cas, le Template Toolkit fusionne automatiquement les éléments retournés en une liste.

Le résultat est que vous pouvez continuer à utiliser des modules existants ou du code qui renvoie des listes d'éléments sans avoir à les refactoriser pour satisfaire Template Toolkit (en retournant des références à des listes). Le module "Class::DBI" est un exemple de module particulièrement utile qui renvoie des valeurs de cette manière.

Si un seul élément est retourné par une sous-routine, le Template Toolkit suppose que vous vouliez renvoyer une valeur unique (plutôt qu'une liste à un seul élément) et la laisse telle quelle. Si vous exécutez une requête de base de données, par exemple, vous pourriez obtenir un seul élément ou plusieurs qui seront ensuite fusionnés en une liste.

La directive "FOREACH" accepte à la fois une liste et un seul élément qui sera traité comme une liste. Par conséquent, il est sûr d'écrire des directives comme celle-ci, en supposant que la variable "something" est liée à une sous-routine qui peut renvoyer un ou plusieurs éléments :

[% FOREACH item IN something %]
   ...
[% END %]

La promotion automatique des scalaires en listes ne s'applique qu'à un seul élément, ce qui signifie que vous pouvez également utiliser en toute sécurité les méthodes virtuelles de liste, même si un seul élément est retourné. Par exemple :

[% something.first %]
[% something.join %]
[% something.reverse.join(', ') %]

Remarque : il s'agit d'une stratégie de dernier recours. Si le seul élément retourné est un objet ayant une méthode "first", par exemple, la méthode "first" sera appelée de préférence à la méthode virtuelle de liste.

Définition de méthodes virtuelles personnalisées

Vous pouvez définir vos propres méthodes virtuelles pour les scalaires, les listes et les tableaux associatifs. Les variables $SCALAR_OPS, $LIST_OPS et $HASH_OPS de Template::Stash sont des références à des tableaux associatifs qui définissent ces méthodes virtuelles. Les fonctions "HASH_OPS" et "LIST_OPS" sont des sous-routines qui acceptent une référence à un tableau ou un tableau associatif comme premier argument. Les fonctions "SCALAR_OPS" sont des sous-routines qui acceptent une valeur scalaire comme premier argument. Tous les autres arguments spécifiés lors de l'appel de la méthode sont transmis à la sous-routine.

# charger Template::Stash pour montrer les tables de méthodes
use Template::Stash;
# définir une méthode de liste qui renvoie une nouvelle liste de nombres impairs
$Template::Stash::LIST_OPS->{ odd } = sub {
    my $list = shift;
    return [ grep { $_ % 2 } @$list ];
};

Un exemple de modèle :

[% primes = [ 2, 3, 5, 7, 9 ] %]
[% primes.odd.join(', ') %]         # 3, 5, 7, 9
