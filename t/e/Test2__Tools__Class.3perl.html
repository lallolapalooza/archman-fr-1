Test2::Tools::Class(3perl) Guide de référence du programmeur Perl Test2::Tools::Class(3perl)

NOM

Test2::Tools::Class - Implémentation Test2 des outils pour tester les classes.

DESCRIPTION

Outils basés sur Test2 pour valider les classes et les objets. Ceux-ci sont similaires à certains outils de Test::More, mais ils ont une interface plus cohérente.

SYNTAXE

use Test2::Tools::Class;
isa_ok($CLASSE_OU_INSTANCE, $CLASSE_PARENTE1, $CLASSE_PARENTE2, ...);
isa_ok($CLASSE_OU_INSTANCE, [$CLASSE_PARENTE1, $CLASSE_PARENTE2, ...], "Nom du test");
can_ok($CLASSE_OU_INSTANCE, $METHODE1, $METHODE2, ...);
can_ok($CLASSE_OU_INSTANCE, [$METHODE1, $METHODE2, ...], "Nom du test");
DOES_ok($CLASSE_OU_INSTANCE, $ROLE1, $ROLE2, ...);
DOES_ok($CLASSE_OU_INSTANCE, [$ROLE1, $ROLE2, ...], "Nom du test");

EXPORTATIONS

Toutes les sous-routines sont exportées par défaut.

can_ok($objet, @méthodes)
can_ok($objet, \@méthodes, $nom_test)
Ceci vérifie que $objet (soit un nom de classe, soit une instance bénie) possède les méthodes spécifiées.

Si le deuxième argument est une référence de tableau, elle sera utilisée comme liste de méthodes, laissant le troisième argument être le nom du test.

isa_ok($objet, @classes)
isa_ok($objet, \@classes, $nom_test)
Ceci vérifie que $objet (soit un nom de classe, soit une instance bénie) est ou hérite des classes spécifiées.

Si le deuxième argument est une référence de tableau, elle sera utilisée comme liste de classes, laissant le troisième argument être le nom du test.

DOES_ok($objet, @rôles)
DOES_ok($objet, \@rôles, $nom_test)
Ceci vérifie que $objet (soit un nom de classe, soit une instance bénie) implémente les rôles spécifiés.

Si le deuxième argument est une référence de tableau, elle sera utilisée comme liste de rôles, laissant le troisième argument être le nom du test.

Note 1 : Ceci utilise la méthode "$class->DOES(...)", pas la méthode does() fournie par Moose.

Note 2 : Tous les interpréteurs Perl n'ont pas la méthode DOES(). Si vous l'utilisez sur ces interpréteurs, le test sera sauté.
