Test2::Compare::Delta(3perl) Guide du programmeur Perl Test2::Compare::Delta(3perl)

NOM

Test2::Compare::Delta - Représentation des différences entre des structures de données imbriquées.

DESCRIPTION

Ceci est utilisé par Test2::Compare. Lorsque les structures de données sont comparées, un delta sera retourné. Les deltas sont une structure de données arborescente qui représente toutes les différences entre deux autres structures de données.

MÉTHODES

MÉTHODES DE CLASSE

$class->add_column($NOM => sub { ... })
$class->add_column($NOM, %PARAMÈTRES)
Ceci peut être utilisé pour ajouter des colonnes au tableau qu'il produit lorsqu'une comparaison échoue. Le premier argument doit toujours être le nom de la colonne, qui doit être unique.

La première forme prend simplement un coderef qui produit la valeur qui doit être affichée dans la colonne pour un delta donné. Les arguments passés au sous sont le delta et l'identifiant de la ligne.

Test2::Compare::Delta->add_column(
    Foo => sub {
        my ($delta, $id) = @_;
        return $delta->... ? 'foo' : 'bar'
    },
);

La deuxième forme vous permet quelques options supplémentaires. La clé 'valeur' est requise et doit être un coderef. Toutes les autres clés sont optionnelles.

Test2::Compare::Delta->add_column(
    'Foo',    # nom de la colonne
    value => sub { ... },    # comment obtenir la valeur de la cellule
    alias       => 'FOO',    # Nom d'affichage (utilisé dans l'en-tête du tableau)
    no_collapse => $bool,    # Afficher la colonne même si elle n'a pas de valeurs ?
);
$bool = $class->remove_column($NOM)
Ceci supprimera la colonne spécifiée. Ceci retournera vrai si la colonne existait et a été supprimée. Ceci retournera faux si la colonne n'existait pas. Aucune exception n'est levée. Si une colonne manquante est un problème, vous devez vérifier vous-même le retour.
$class->set_column_alias($NOM, $ALIAS)
Ceci peut être utilisé pour changer l'en-tête du tableau, en remplaçant les noms de colonnes par défaut par de nouveaux.

ATTRIBUTS

$bool = $delta->verified
$delta->set_verified($bool)
Ceci sera vrai si le delta lui-même correspondait, si le delta correspondait alors le problème se trouve dans les enfants du delta, pas dans le delta lui-même.
$aref = $delta->id
$delta->set_id([$type, $nom])
ID pour le delta, utilisé pour produire le chemin dans la structure de données. Un exemple est "['HASH' => 'foo']" ce qui signifie que le delta se trouve dans le chemin "...->{'foo'}". Les types valides sont "HASH", "ARRAY", "SCALAR", "META", et "METHOD".
$val = $delta->got
$delta->set_got($val)
Les deltas sont produits en comparant une structure de données reçue 'got' à une structure de données de vérification 'check'. L'attribut 'got' contient la valeur qui a été reçue pour la comparaison.
$check = $delta->chk
$check = $delta->check
$delta->set_chk($check)
$delta->set_check($check)
Les deltas sont produits en comparant une structure de données reçue 'got' à une structure de données de vérification 'check'. L'attribut 'check' contient la valeur qui était attendue dans la comparaison.

"check" et "chk" sont des alias pour le même attribut.

$aref = $delta->children
$delta->set_children([$delta1, $delta2, ...])
Un Delta peut avoir des deltas enfants. S'il en a, c'est un arrayref avec ces enfants.
$dne = $delta->dne
$delta->set_dne($dne)
Parfois, une comparaison aboutit à ce qu'un côté ou l'autre n'existe pas du tout, auquel cas ceci est défini sur le nom de l'attribut qui n'existe pas. Ceci peut être défini sur 'got' ou 'check'.
$e = $delta->exception
$delta->set_exception($e)
Ceci sera défini sur l'exception dans les cas où la comparaison a échoué en raison d'une exception levée.

AUTRE

$string = $delta->render_got
Rend la chaîne qui doit être utilisée dans un tableau pour représenter la valeur reçue dans une comparaison.
$string = $delta->render_check
Rend la chaîne qui doit être utilisée dans un tableau pour représenter la valeur attendue dans une comparaison.
$bool = $delta->should_show
Ceci retournera vrai si le delta doit être affiché dans le tableau. Ceci est normalement vrai pour tout delta non vérifié. Ceci sera également vrai pour les deltas qui contiennent des informations de débogage supplémentaires utiles.
$aref = $delta->filter_visible
Ceci produira un arrayref de "[ $chemin => $delta ]" pour tous les deltas qui doivent être affichés dans le tableau.
$aref = $delta->table_header
Ceci retourne un arrayref des en-têtes du tableau.
$string = $delta->table_op
Ceci retourne l'opérateur qui doit être affiché dans le tableau.
$string = $delta->table_check_lines
Ceci retourne les lignes définies (informations de débogage supplémentaires) qui doivent être affichées.
$string = $delta->table_got_lines
Ceci retourne les lignes générées (informations de débogage supplémentaires) qui doivent être affichées.
$aref = $delta->table_rows
Ceci retourne un arrayref de lignes de tableau, chaque ligne est elle-même un arrayref.
@table_lines = $delta->table
Retourne toutes les lignes du tableau qui doivent être affichées.
