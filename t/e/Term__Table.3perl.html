Term::Table(3perl) Manuel du programmeur Perl Term::Table(3perl)

NOM

Term::Table - Formater une en-tête et des lignes dans un tableau

DESCRIPTION

Ce module est utilisé pour fournir des diagnostics sur ce qui s'est mal passé dans des tests qui ont échoué. Ce module peut formater des lignes de données en tableaux.

SYNOPIS

use Term::Table;
my $table = Term::Table->new(
    max_width      => 80,    # Par défaut, la largeur maximale est celle du terminal
    pad            => 4,     # Espace supplémentaire entre le tableau et la largeur maximale (par défaut 4)
    allow_overflow => 0,     # Par défaut 0, une exception est levée si le tableau est trop grand
    collapse       => 1,     # Ne pas afficher les colonnes vides
    header => ['name', 'age', 'hair color'],
    rows   => [
        ['Fred Flintstone',  2000000, 'black'],
        ['Wilma Flintstone', 1999995, 'red'],
        ...
    ],
);
say $_ for $table->render;

Ceci affiche un tableau similaire à ceci :

+------------------+---------+------------+
| name             | age     | hair color |
+------------------+---------+------------+
| Fred Flintstone  | 2000000 | black      |
| Wilma Flintstone | 1999995 | red        |
| ...              | ...     | ...        |
+------------------+---------+------------+

INTERFACE

use Term::Table;
my $table = Term::Table->new(...);

Options

header => [ ... ]
Si vous souhaitez un en-tête, spécifiez-le ici. Ceci prend un arrayref avec chaque en-tête de colonne.
rows => [ [...] ]
Devrait être un arrayref contenant un arrayref pour chaque ligne.
collapse => $bool
Utilisez cette option si vous souhaitez masquer les colonnes vides, c'est-à-dire toute colonne qui n'a pas de données dans aucune ligne. Un en-tête de colonne n'affecte pas le collapse.
max_width => $num
Définit la largeur maximale du tableau, le tableau peut ne pas être aussi grand, mais ne sera pas plus grand que cette valeur. Si non spécifié, il tentera de trouver la largeur du terminal et de l'utiliser, sinon elle sera fixée à la largeur du terminal ou à 80.
pad => $num
Par défaut, c'est 4, un espace supplémentaire pour les calculs de largeur de ligne. La valeur par défaut est pour la compatibilité ascendante. Réglez ceci à 0 pour désactiver l'espacement.
allow_overflow => $bool
Par défaut, c'est 0. Si désactivé, une exception sera levée si le tableau ne peut pas tenir dans la largeur maximale. S'il est réglé sur 1, le tableau sera rendu même s'il est plus grand que la largeur maximale, à condition qu'il ne soit pas possible de rester dans cette limite. En d'autres termes, cela transforme la largeur maximale en une limite stricte plutôt qu'en une recommandation douce.
sanitize => $bool
Ceci assainira toutes les données du tableau, remplaçant les caractères de nouvelle ligne, les caractères de contrôle et les espaces blancs sauf l'ASCII 20 ' par des séquences d'échappement. Cela empêche les caractères de nouvelle ligne, les tabulations et les espaces blancs similaires de perturber le tableau.

Remarque : Les caractères de nouvelle ligne seront marqués comme "\n", mais un nouveau caractère de ligne sera également inséré dans les données afin qu'il s'affiche de manière utile pour l'humain.

Exemple :

my $field = "foo\nbar\nbaz\n";
print join "\n" => table(
    sanitize => 1,
    rows => [
        [$field,      'col2'     ],
        ['row2 col1', 'row2 col2']
    ]
);

Affiche :

+-----------------+-----------+
| foo\n           | col2      |
| bar\n           |           |
| baz\n           |           |
|                 |           |
| row2 col1       | row2 col2 |
+-----------------+-----------+

Ainsi, il marque les nouveaux caractères de ligne avec des séquences d'échappement, mais affiche également les données sur plusieurs lignes selon leur normalité d'affichage.

mark_tail => $bool
Remplacera le dernier caractère d'espacement dans tout espace blanc de fin par sa séquence d'échappement. Cela permet de repérer plus facilement les espaces blancs lors de la comparaison de valeurs.
show_header => $bool
Définissez ceci sur false pour masquer l'en-tête. Par défaut, il est vrai si l'en-tête est spécifié, faux si aucun n'est fourni.
auto_columns => $bool
Définissez ceci sur true pour ajouter automatiquement des colonnes non nommées dans l'en-tête. Par défaut, il est faux s'il y a un en-tête, et par défaut, il est vrai s'il n'y a pas d'en-tête.
no_collapse => [ $col_num_a, $col_num_b, ... ]
no_collapse => [ $col_name_a, $col_name_b, ... ]
no_collapse => { $col_num_a => 1, $col_num_b => 1, ... }
no_collapse => { $col_name_a => 1, $col_name_b => 1, ... }
Définit (par numéro et/ou nom) les colonnes qui ne doivent pas être supprimées lorsqu'elles sont vides. Le formulaire "nom" ne fonctionne que lorsque l'en-tête est spécifié. Il n'y a actuellement aucune protection pour s'assurer que les noms que vous spécifiez sont réellement dans l'en-tête ; les noms invalides sont ignorés, et les correctifs pour résoudre cela seront acceptés sans problème.

NOTE SUR LES CARACTÈRES UNICODE/CARACTÈRES LARGES

Certains caractères Unicode, tels que "婧" ("U+5A67"), sont plus larges que d'autres. Ceux-ci s'afficheront correctement si "use utf8;" est utilisé et si Unicode::GCString est installé, bien que s'il n'est pas installé, il y aura des anomalies dans le tableau :

+-----+-----+---+
| a   | b   | c |
+-----+-----+---+
| 婧 | x   | y |
| x   | y   | z |
| x   | 婧 | z |
+-----+-----+---+
