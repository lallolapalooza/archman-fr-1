NOM

Test::Base::Filter - Classe de filtre par défaut pour Test::Base

SYNTAXE

package MonTestSuite;
use Test::Base -Base;
... code de test réutilisable ...
package MonTestSuite::Filter;
use Test::Base::Filter -Base;
sub mon_filtre1 {
    ...
}

DESCRIPTION

Les filtres sont la clé pour écrire des tests efficaces basés sur des données avec Test::Base. Test::Base::Filter est une classe contenant un grand ensemble par défaut de filtres génériques. Vous pouvez facilement la sous-classer pour ajouter/remplacer des fonctionnalités.

FILTRES

Voici une liste des filtres de stock par défaut (par ordre alphabétique) :

"append"
liste => liste

Ajoute une chaîne à chaque élément d'une liste.

--- numbers lines chomp append=-#\n join
one
two
three
"array"
liste => scalaire

Transforme une liste de valeurs en une référence d'array anonyme.

"base64_decode"
scalaire => scalaire

Décode les données base64. Utile pour les tests binaires.

"base64_encode"
scalaire => scalaire

Encode les données base64. Utile pour les tests binaires.

"chomp"
liste => liste

Supprime le saut de ligne final de chaque valeur de chaîne dans une liste.

"chop"

liste => liste

Supprime le dernier caractère de chaque valeur de chaîne dans une liste.
"dumper"
scalaire => liste

Prend une structure de données (vraisemblablement issue d'un autre filtre comme eval) et utilise Data::Dumper pour la déverser de manière canonique.

"escape"
scalaire => scalaire

Déséchappe tous les caractères échappés par une barre oblique inverse.

"eval"
scalaire => liste

Exécute la commande "eval" de Perl contre les données et utilise la valeur retournée comme données.

"eval_all"
scalaire => liste

Exécute la commande "eval" de Perl contre les données et retourne une liste de 4 valeurs :

1) La valeur de retour
2) L'erreur dans $@
3) STDOUT capturé
4) STDERR capturé
"eval_stderr"
scalaire => scalaire

Exécute la commande "eval" de Perl contre les données et retourne STDERR capturé.

"eval_stdout"
scalaire => scalaire

Exécute la commande "eval" de Perl contre les données et retourne STDOUT capturé.

"exec_perl_stdout"
liste => scalaire

Le code Perl d'entrée est écrit dans un fichier temporaire et exécuté. STDOUT est capturé et retourné.

"flatten"
scalaire => liste

Prend une référence de hash ou d'array et la transforme en une liste.

"get_url"
scalaire => scalaire

Le texte est tronqué et considéré comme une URL. Ensuite, LWP::Simple::get est utilisé pour récupérer le contenu de l'URL.

"hash"
liste => scalaire

Transforme une liste de paires clé/valeur en une référence de hash anonyme.

"head[=nombre]"
liste => liste

Prend une liste et retourne un certain nombre d'éléments du début. Le nombre par défaut est un.

"join"
liste => scalaire

Joint une liste de chaînes en un scalaire.

"Join"
Joint les chaînes d'une liste de références d'arrays et retourne les chaînes à la place des références d'arrays.
"lines"
scalaire => liste

Sépare les données en un tableau anonyme de lignes. Chaque ligne (sauf peut-être la dernière si le filtre "chomp" est apparu en premier) aura un saut de ligne à la fin.

"norm"
scalaire => scalaire

Normalise les données. Change les fins de ligne non Unix en fins de ligne Unix.

"prepend=chaîne"
liste => liste

Ajoute une chaîne au début de chaque chaîne d'une liste de chaînes.

"read_file"
scalaire => scalaire

Lit le fichier nommé par le contenu actuel et retourne le contenu du fichier.

"regexp[=xism]"
scalaire => scalaire

Le filtre "regexp" transformera votre section de données en un objet d'expression régulière. Vous pouvez passer des drapeaux supplémentaires après un signe égal.

Si le texte contient plus d'une ligne et qu'aucun drapeau n'est spécifié, les drapeaux 'xism' sont supposés.

"reverse"
liste => liste

Inverse les éléments d'une liste.

"Reverse"
liste => liste

Inverse la liste de chaînes à l'intérieur d'une liste de références d'arrays.

"slice=x[,y]"
liste => liste

Retourne l'élément numéro x à l'élément numéro y d'une liste.

"sort"
liste => liste

Trie les éléments d'une liste en ordre de tri de caractères.

"Sort"
liste => liste

Trie la liste de chaînes à l'intérieur d'une liste de références d'arrays.

"split[=chaîne|motif]"
scalaire => liste

Divise une chaîne en une liste. Prend une chaîne ou une expression régulière facultative comme paramètre. Par défaut, utilise s+. Identique à "split" de Perl.

"Split[=chaîne|motif]"
liste => liste

Divise chaque chaîne d'une liste et les transforme en références d'arrays.

"strict"
scalaire => scalaire

Ajoute la chaîne :

use strict;
use warnings;

au texte du bloc.

"tail[=nombre]"
liste => liste

Retourne un certain nombre d'éléments de la fin d'une liste. Le nombre par défaut est un.

"trim"
liste => liste

Supprime les lignes vides supplémentaires du début et de la fin des données. Cela vous permet de séparer visuellement vos données de test avec des lignes vides.

"unchomp"
liste => liste

Ajoute un saut de ligne à chaque valeur de chaîne dans une liste.

"write_file[=nom_fichier]"
scalaire => scalaire

Écrit le contenu de la section dans le fichier nommé. Retourne le nom du fichier.

"yaml"
scalaire => liste

Applique la fonction YAML::Load au bloc de données et utilise la structure résultante. Nécessite YAML.pm.
