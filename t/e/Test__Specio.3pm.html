Test::Specio(3) Documentation Perl fournie par l'utilisateur Test::Specio(3)

NOM

Test::Specio - Assistants de test pour Specio

VERSION

version 0.53

SYNOPSIS

use Test::Specio qw( test_constraint :vars );
test_constraint(
    t('Foo'), {
        accept => [ 'foo', 'bar' ],
        reject => [ 42,    {}, $EMPTY_STRING, $HASH_REF ],
    }
);

DESCRIPTION

Ce paquet fournit des fonctions et variables utilitaires pour tester les types Specio.

EXPORTS

Ce module fournit les exports suivants :

test_constraint( $type, $tests, [ $describer ] )

Cette sous-routine accepte deux arguments. Le premier doit être un objet de type Specio. Le second est un hashref qui peut contenir les clés "accept" et "reject". Chaque clé doit contenir un arrayref de valeurs que le type accepte ou rejette.

Le troisième argument est optionnel. C'est une référence de sous-routine qui sera appelée pour générer une description de la valeur testée. Ceci appelle par défaut la sous-routine "describe" de ce paquet, mais vous pouvez fournir la vôtre.

describe($value)

Étant donné une valeur, cette sous-routine retourne une chaîne décrivant cette valeur de manière utile pour la sortie de test. Elle connaît les différentes classes utilisées pour les variables exportées par ce paquet et fera quelque chose d'intelligent avec une telle variable.

builtins_tests( $GLOB, $GLOB_OVERLOAD, $GLOB_OVERLOAD_FH )

Cette sous-routine retourne un hashref contenant des variables de test pour tous les types intégrés. Le hashref a une forme comme celle-ci :

{
    Bool => {
        accept => [
            $ZERO,
            $ONE,
            $BOOL_OVERLOAD_TRUE,
            $BOOL_OVERLOAD_FALSE,
            ...,
        ],
        reject => [
            $INT,
            $NEG_INT,
            $NUM,
            $NEG_NUM,
            ...,
            $OBJECT,
        ],
    },
    Maybe => {...},
}

Vous devez passer un glob, un objet qui surcharge la globification, et un objet qui surcharge la globification pour retourner un handle de fichier ouvert. Voir ci-dessous pour plus de détails sur la façon de créer ces éléments.

create_BAR_handle_code()

Retourne une chaîne que vous pouvez "eval" pour créer un handle de fichier bar nommé "BAR". Ceci doit être utilisé comme suit :

local *BAR;
{
    local $@;
    eval create_BAR_handle_code();
    die $@ if $@;
}

Variables

Ce module exporte également de nombreuses variables contenant des valeurs utiles pour tester les contraintes. Notez que les références sont toujours vides sauf indication contraire. Vous pouvez importer ces variables individuellement ou toutes les importer avec le tag d'importation ":vars".

  • $ZERO
  • $ONE
  • $INT

    Un entier positif arbitraire.

  • $NEG_INT

    Un entier négatif arbitraire.

  • $NUM

    Un nombre positif non entier arbitraire.

  • $NEG_NUM

    Un nombre négatif non entier arbitraire.

  • $EMPTY_STRING
  • $STRING

    Une chaîne non vide arbitraire.

  • $NUM_IN_STRING

    Une chaîne arbitraire contenant un nombre.

  • $INT_WITH_NL1

    Une chaîne contenant un entier suivi d'un saut de ligne.

  • $INT_WITH_NL2

    Une chaîne contenant un saut de ligne suivi d'un entier.

  • $SCALAR_REF
  • $SCALAR_REF_REF

    Une référence contenant une référence à un scalaire.

  • $ARRAY_REF
  • $HASH_REF
  • $CODE_REF
  • $GLOB_REF
  • $FH

    Un handle de fichier ouvert.

  • $FH_OBJECT

    Un objet IO::File ouvert.

  • $REGEX

    Une regex créée avec "qr//".

  • $REGEX_OBJ

    Une regex créée avec "qr//" qui a ensuite été bénie dans une classe.

  • $FAKE_REGEX

    Une non-regex bénie dans la classe "Regexp" que Perl utilise en interne pour les objets "qr//".

  • $OBJECT

    Un objet arbitraire.

  • $UNDEF
  • $CLASS_NAME

    Une chaîne contenant le nom d'un paquet chargé.

  • $BOOL_OVERLOAD_TRUE

    Un objet qui surcharge la booléanisation pour retourner vrai.

  • $BOOL_OVERLOAD_FALSE

    Un objet qui surcharge la booléanisation pour retourner faux.

  • $STR_OVERLOAD_EMPTY

    Un objet qui surcharge la stringification pour retourner une chaîne vide.

  • $STR_OVERLOAD_FULL

    Un objet qui surcharge la stringification pour retourner une chaîne non vide.

  • $STR_OVERLOAD_CLASS_NAME

    Un objet qui surcharge la stringification pour retourner le nom d'un paquet chargé.

  • $NUM_OVERLOAD_ZERO
  • $NUM_OVERLOAD_ONE
  • $NUM_OVERLOAD_NEG
  • $NUM_OVERLOAD_DECIMAL
  • $NUM_OVERLOAD_NEG_DECIMAL
  • $CODE_OVERLOAD
  • $SCALAR_OVERLOAD

    Un objet qui surcharge le déréférencement scalaire pour retourner une chaîne non vide.

  • $ARRAY_OVERLOAD

    Un objet qui surcharge le déréférencement de tableau pour retourner un tableau non vide.

  • $HASH_OVERLOAD

    Un objet qui surcharge le déréférencement de hachage pour retourner un hachage non vide.

Globs et le package _T::GlobOverload

Pour créer un glob à passer pour les tests, utilisez ce code :

my $GLOB = do {
    no warnings 'once';
    *SOME_GLOB;
};

Le package "_T::GlobOverload" est défini lorsque vous chargez "Test::Specio" afin que vous puissiez créer vos propres objets surchargeant les globs. Ces objets ne peuvent pas être exportés car le glob qu'ils retournent ne se transfère pas correctement entre les packages.

Vous pouvez créer une telle variable comme suit :

local *FOO;
my $GLOB_OVERLOAD = _T::GlobOverload->new( \*FOO );

Si vous souhaitez créer un objet surchargeant un glob qui retourne un handle de fichier, faites ceci :

local *BAR;
open BAR, '<', $some_file or die $!;
my $GLOB_OVERLOAD_FH = _T::GlobOverload->new( \*BAR );
