Test2::Tools::Grab(3perl) Guide du programmeur Perl Test2::Tools::Grab(3perl)

NOM

Test2::Tools::Grab - Intercepter temporairement tous les événements sans ajouter de niveau de portée.

DESCRIPTION

Ce paquet fournit une fonction qui renvoie un objet qui capture tous les événements. Une fois que l'objet est détruit, les événements seront à nouveau envoyés au hub principal.

SYNTAXE

use Test2::Tools::Grab;
my $grab = grab();
# Générer quelques événements, ils sont interceptés.
ok(1, "pass");
ok(0, "fail");
my $events_a = $grab->flush;
# Générer quelques événements supplémentaires, ils sont interceptés.
ok(1, "pass");
ok(0, "fail");
my $events_b = $grab->finish;

EXPORTATIONS

$grab = grab()
Cela vous permet d'intercepter tous les événements pour une section de code sans ajouter quoi que ce soit à votre pile d'appels. Ceci est utile pour les choses qui sont sensibles aux changements de profondeur de la pile. 
my $grab = grab();
    ok(1, 'foo');
    ok(0, 'bar');
my $events = $grab->finish;
is(@$events, 2, "2 événements capturés.");

Si l'objet $grab est détruit sans appeler finish(), il se nettoiera automatiquement et restaurera le hub parent.

{
    my $grab = grab();
    # Les choses sont capturées
}
# Les choses reviennent à la normale

Par défaut, le hub utilisé a "no_ending" défini sur vrai. Cela empêchera le hub d'appliquer l'exigence que vous ayez émis un plan et exécuté au moins 1 test. Vous pouvez réactiver l'application comme ceci :

$grab->hub->set_no_ending(0);

Avec "no_ending" désactivé, "finish" exécutera les vérifications post-test pour appliquer le plan et que des tests aient été exécutés. Dans de nombreux cas, cela se traduira par des événements supplémentaires dans votre tableau d'événements.

VOIR AUSSI

Test2::Util::Grabber - L'objet construit et renvoyé par cet outil.
