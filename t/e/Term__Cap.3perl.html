Term::Cap(3perl) Guide du programmeur Perl Term::Cap(3perl)

NOM

Term::Cap - Interface Perl pour termcap

SYNOPSIS

require Term::Cap;
$terminal = Term::Cap->Tgetent({ TERM => undef, OSPEED => $ospeed });
$terminal->Trequire(qw/ce ku kd/);
$terminal->Tgoto('cm', $col, $row, $FH);
$terminal->Tputs('dl', $count, $FH);
$terminal->Tpad($string, $count, $FH);

DESCRIPTION

Ce sont des fonctions de bas niveau pour extraire et utiliser les capacités d'une base de données de capacités de terminal (termcap).

Plus d'informations sur les capacités de terminal se trouvent dans la page de manuel termcap sur la plupart des systèmes Unix.

MÉTHODES

Les chaînes de sortie pour Tputs sont mises en cache pour des comptes de 1 pour des raisons de performance. Tgoto et Tpad ne mettent pas en cache. "$self->{_xx}" sont les données termcap brutes et "$self->{xx}" sont les données mises en cache.

print $terminal->Tpad($self->{_xx}, 1);

Tgoto, Tputs et Tpad retournent la chaîne et l'afficheront également sur $FH si spécifié.

Tgetent
Retourne une référence d'objet bénie que l'utilisateur peut ensuite utiliser pour envoyer les chaînes de contrôle au terminal en utilisant Tputs et Tgoto.

La fonction extrait l'entrée du type de terminal spécifié TERM (par défaut la variable d'environnement TERM) de la base de données.

Elle recherchera dans l'environnement une variable TERMCAP. Si elle est trouvée, et que la valeur ne commence pas par un slash, et que le nom du type de terminal est le même que la chaîne d'environnement TERM, la chaîne TERMCAP est utilisée à la place de la lecture d'un fichier termcap. Si elle commence par un slash, la chaîne est utilisée comme nom de chemin du fichier termcap à rechercher. Si TERMCAP ne commence pas par un slash et que le nom est différent de TERM, Tgetent recherche les fichiers $HOME/.termcap, /etc/termcap, et /usr/share/misc/termcap, dans cet ordre, à moins que la variable d'environnement TERMPATH n'existe, auquel cas elle spécifie une liste de noms de fichiers (séparés par des espaces ou des deux-points) à rechercher **à la place**. Chaque fois que plusieurs fichiers sont recherchés et qu'un champ tc apparaît dans l'entrée demandée, l'entrée qu'il nomme doit être trouvée dans le même fichier ou dans l'un des fichiers suivants. S'il y a un ":tc=...:" dans la chaîne d'environnement TERMCAP, la recherche continuera dans les fichiers comme ci-dessus.

L'entrée termcap extraite est disponible dans l'objet sous "$self->{TERMCAP}".

Elle prend une référence de hachage comme argument avec deux clés optionnelles :

OSPEED
Le débit binaire de sortie du terminal (souvent appelé à tort débit en bauds) pour ce terminal - si non défini, un avertissement sera généré et la valeur par défaut sera 9600. OSPEED peut être spécifié soit comme des vitesses termios POSIX/termio SYSV (où 9600 est égal à 9600) soit comme une ancienne vitesse de style DSD (où 13 est égal à 9600).
TERM
Le type de terminal dont l'entrée termcap sera utilisée - si non fourni, elle utilisera par défaut $ENV{TERM} : si ce dernier n'est pas défini, Tgetent échouera (croak).

Elle appelle "croak" en cas d'échec.

Tpad
Affiche une chaîne littérale avec le remplissage approprié pour le terminal actuel.

Elle prend trois arguments :

$string
La chaîne littérale à afficher. Si elle commence par un nombre et un '*' optionnel, alors le remplissage sera augmenté d'un montant relatif à ce nombre. Si le '*' est présent, alors ce montant sera multiplié par $cnt. Cette partie de $string est supprimée avant l'affichage.
$cnt
Sera utilisé pour modifier le remplissage appliqué à la chaîne comme décrit ci-dessus.
$FH
Un descripteur de fichier optionnel (ou IO::Handle) vers lequel la sortie sera imprimée.

La chaîne $string remplie est retournée.

Tputs
Affiche la chaîne pour la capacité donnée, remplie de manière appropriée, sans aucune substitution de paramètre.

Elle prend trois arguments :

$cap
La capacité dont la chaîne doit être affichée.
$cnt
Un compte passé à Tpad pour modifier le remplissage appliqué à la chaîne de sortie. Si $cnt est zéro ou un, alors la chaîne résultante sera mise en cache.
$FH
Un descripteur de fichier optionnel (ou IO::Handle) vers lequel la sortie sera imprimée.

La chaîne appropriée pour la capacité sera retournée.

Tgoto
Tgoto décode une chaîne d'adressage de curseur avec les paramètres donnés.

Il y a quatre arguments :

$cap
Le nom de la capacité à afficher.
$col
La première valeur à substituer dans la chaîne de sortie (généralement la colonne dans une capacité d'adressage de curseur).
$row
La deuxième valeur à substituer dans la chaîne de sortie (généralement la ligne dans les capacités d'adressage de curseur).
$FH
Un descripteur de fichier optionnel (ou IO::Handle) vers lequel la chaîne de sortie sera imprimée.

Les substitutions sont effectuées avec $col et $row dans la chaîne de sortie avec les formats de ligne **sprintf()** suivants :

%%   affiche `%'
%d   affiche la valeur comme dans printf %d
%2   affiche la valeur comme dans printf %2d
%3   affiche la valeur comme dans printf %3d
%.   affiche la valeur comme dans printf %c
%+x  ajoute x à la valeur, puis fait %.
%>xy si la valeur > x alors ajoute y, aucune sortie
%r   inverse l'ordre des deux paramètres, aucune sortie
%i   incrémente de un, aucune sortie
%B   BCD (16*(valeur/10)) + (valeur%10), aucune sortie
%n   fait un OU exclusif de tous les paramètres avec 0140 (Datamedia 2500)
%D   Code inversé (valeur - 2*(valeur%16)), aucune sortie (Delta Data)

La chaîne de sortie sera retournée.

Trequire
Prend une liste de capacités comme argument et échouera (croak) si l'une d'elles n'est pas trouvée.

EXEMPLES

use Term::Cap;
# Obtenir la vitesse de sortie du terminal
require POSIX;
my $termios = POSIX::Termios->new;
$termios->getattr;
my $ospeed = $termios->getospeed;
# Code ioctl ancien style pour obtenir ospeed :
#     require 'ioctl.pl';
#     ioctl(TTY,$TIOCGETP,$sgtty);
#     ($ispeed,$ospeed) = unpack('cc',$sgtty);
# allouer et initialiser une structure de terminal
my $terminal = Term::Cap->Tgetent({ TERM => undef, OSPEED => $ospeed });
# requérir certaines capacités pour qu'elles soient disponibles
$terminal->Trequire(qw/ce ku kd/);
# Routines d'affichage, si $FH est indéfini, elles retournent juste la chaîne
# Tgoto effectue les expansions % avec les arguments donnés
$terminal->Tgoto('cm', $col, $row, $FH);
# Tputs n'effectue aucune expansion %.
$terminal->Tputs('dl', $count = 1, $FH);
