Test2::Tools::Tester(3perl) Guide du programmeur Perl Test2::Tools::Tester(3perl)

NOM

Test2::Tools::Tester - Outils pour vous aider à tester d'autres outils de test.

DESCRIPTION

Ceci est une collection d'outils utiles lors du test d'autres outils de test.

SYNTAXE

use Test2::Tools::Tester qw/event_groups filter_events facets/;
use Test2::Tools::Basic qw/plan pass ok/;
use Test2::Tools::Compare qw/is like/;
my $events = intercept {
    plan 11;
    pass('pass');
    ok(1, 'pass');
    is(1, 1, "pass");
    like(1, 1, "pass");
};
# Récupérer les événements générés par les outils de Test2::Tools::Basic
my $basic = filter $events => 'Test2::Tools::Basic';
# Récupérer les événements générés par Test2::Tools::Basic ;
my $compare = filter $events => 'Test2::Tools::Compare';
# Récupérer les événements générés par les outils nommés 'ok'.
my $oks = filter $events => qr/.*::ok$/;
my $grouped = group_events $events;
# Répartit les événements dans cette structure :
{
    '__NA__' => [ ... ],
    'Test2::Tools::Basic' => {
        '__ALL__' => [ $events->[0], $events->[1], $events->[2] ],
        plan => [ $events->[0] ],
        pass => [ $events->[1] ],
        ok => [ $events->[2] ],
    },
    Test2::Tools::Compare => { ... },
}
# Obtenir un tableau de toutes les facettes d'assertion de la liste d'événements.
my $assert_facets = facets assert => $events;
# [
#   bless({ details => 'pass', pass => 1}, 'Test2::EventFacet::Assert'),
#   bless({ details => 'pass', pass => 1}, 'Test2::EventFacet::Assert'),
# ]
# Idem, mais pour les facettes d'information
my $info_facets = facets info => $events;

EXPORTATIONS

Aucune sous-routine n'est exportée par défaut.

$array_ref = filter $events => $PAQUET
$array_ref = filter $events => $PAQUET1, $PAQUET2
$array_ref = filter $events => qr/correspondance/
$array_ref = filter $events => qr/correspondance/, $PAQUET
Cette fonction prend en premier argument un tableau d'événements. Tous les arguments supplémentaires doivent être soit un nom de paquet, soit une expression régulière. Tout événement généré par un outil d'un des paquets, ou par un outil correspondant à l'une des expressions régulières, sera retourné dans un tableau.
$grouped = group_events($events)
Cette fonction itère sur tous les événements du tableau d'arguments et les divise en groupes. La structure de données résultante est : 
{ PAQUET => { NOM_SOUS_PROG => [ $EVENT1, $EVENT2, ... ]}}

Si le paquet d'un événement n'est pas connu, il sera placé dans un tableau sous la clé '__NA__' à la racine de la structure. Si un nom de sous-programme n'est pas connu, il sera généralement placé sous la clé '__ANON__' sous le nom du paquet.

De plus, il existe une clé '__ALL__' sous chaque paquet qui stocke tous les événements triés dans ce groupe.

Un exemple plus complet :

{
    '__NA__' => [ $event->[3] ],
    'Test2::Tools::Basic' => {
        '__ALL__' => [ $events->[0], $events->[1], $events->[2] ],
        plan => [ $events->[0] ],
        pass => [ $events->[1] ],
        ok => [ $events->[2] ],
    },
}
$arrayref = facets TYPE => $events
Cette fonction compilera une liste de toutes les facettes du type spécifié qui sont trouvées dans le tableau d'événements. Si la facette a un paquet "Test2::EventFacet::TYPE" disponible, la facette sera construite en une instance de la classe, sinon elle restera un hashref. L'ordre des facettes est préservé. 
my $assert_facets = facets assert => $events;
# [
#   bless({ details => 'pass', pass => 1}, 'Test2::EventFacet::Assert'),
#   bless({ details => 'pass', pass => 1}, 'Test2::EventFacet::Assert'),
# ]
