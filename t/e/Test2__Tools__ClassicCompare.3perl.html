NAME

Test2::Tools::ClassicCompare - Outils de comparaison classiques (style Test::More).

DESCRIPTION

Ceci offre des fonctions de comparaison qui se comportent comme celles qui existaient dans Test::More, plutôt que les plugins Test2::Tools::Compare qui ont modifié ceux-ci.

SYNOPSIS

use Test2::Tools::ClassicCompare qw/is is_deeply isnt like unlike cmp_ok/;
is($got, $expect, "These are the same when stringified");
isnt($got, $unexpected, "These are not the same when stringified");
like($got, qr/.../, "'got' matches the pattern");
unlike($got, qr/.../, "'got' does not match the pattern");
is_deeply($got, $expect, "These structures are same when checked deeply");
cmp_ok($GOT, $OP, $WANT, 'Compare these items using the specified operatr');

EXPORTS

$bool = is($got, $expect)
$bool = is($got, $expect, $name)
$bool = is($got, $expect, $name, @diag)
Compare les deux arguments par une comparaison de chaînes. Si les deux arguments sont identiques après sérialisation, le test réussit. Le test réussit également si les deux sont indéfinis.

Le test $name est optionnel.

Le test @diag est optionnel, il contient des messages de diagnostic supplémentaires qui seront affichés si le test échoue. Les messages de diagnostic sont ignorés si le test réussit.

Il est important de noter que cet outil considère "1" et "1.0" comme non identiques, car il utilise une comparaison de chaînes.

Voir Test2::Tools::Compare si vous souhaitez une fonction is() qui tente d'être plus intelligente pour vous.

$bool = isnt($got, $dont_expect)
$bool = isnt($got, $dont_expect, $name)
$bool = isnt($got, $dont_expect, $name, @diag)
L'inverse de is(), réussit lorsque les chaînes ne sont pas identiques.
$bool = like($got, $pattern)
$bool = like($got, $pattern, $name)
$bool = like($got, $pattern, $name, @diag)
Vérifie si $got correspond au motif spécifié. Échoue s'il ne correspond pas.

Le test $name est optionnel.

Le test @diag est optionnel. Il contient des messages de diagnostic supplémentaires qui seront affichés si le test échoue. Les messages de diagnostic sont ignorés si le test réussit.

$bool = unlike($got, $pattern)
$bool = unlike($got, $pattern, $name)
$bool = unlike($got, $pattern, $name, @diag)
L'inverse de like(). Échoue si $got correspond à $pattern.
$bool = is_deeply($got, $expect)
$bool = is_deeply($got, $expect, $name)
$bool = is_deeply($got, $expect, $name, @diag)
Effectue une comparaison approfondie, en comparant les structures dans $got à celles dans $expect. Elle récursive dans les tableaux, les hachages et les références scalaires. Toutes les autres valeurs sont sérialisées et comparées comme des chaînes. Il est important de noter que cet outil considère "1" et "1.0" comme non identiques, car il utilise une comparaison de chaînes.

Ceci est le même que Test2::Tools::Compare::is()

cmp_ok($got, $op, $expect)
cmp_ok($got, $op, $expect, $name)
cmp_ok($got, $op, $expect, $name, @diag)
Compare $got à $expect en utilisant l'opérateur spécifié dans $op. Ceci est effectivement un "eval "\$got $op \$expect"" avec un peu plus de magie pour le rendre plus simple. Il est utile pour comparer des nombres, des objets surchargés, etc.

Note sur la surcharge : Votre entrée est passée telle quelle à la comparaison. Si une comparaison entre deux objets surchargés échoue, les messages de diagnostic tenteront d'afficher la forme surchargée qui a été utilisée dans les comparaisons. Il est possible que les messages de diagnostic soient incorrects, bien qu'ils aient été améliorés depuis Test::More.

Exceptions : Si le résultat de la comparaison génère une exception, le test échouera et affichera l'exception.

cmp_ok() a une liste interne d'opérateurs qu'il prend en charge. Si vous lui fournissez un opérateur non pris en charge, il émettra un avertissement. Vous pouvez ajouter des opérateurs au hash %Test2::Tools::ClassicCompare::OPS, la clé étant l'opérateur et la valeur étant 'str' pour les comparaisons de chaînes, 'num' pour les opérateurs numériques, ou toute valeur vraie pour les autres opérateurs.

Opérateurs pris en charge :

== (num)
!= (num)
>= (num)
<= (num)
> (num)
< (num)
<=> (num)
eq (str)
ne (str)
gt (str)
lt (str)
ge (str)
le (str)
cmp (str)
!~ (str)
=~ (str)
&&
||
xor
or
and
//
&
|
~~
