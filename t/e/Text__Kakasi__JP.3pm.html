Text::Kakasi::JP(3) Documentation Perl fournie par l'utilisateur Text::Kakasi::JP(3)

NOM

Text::Kakasi::JP - Text::Kakasi convertisseur Kanji-Kana

SYNOPIS

use Text::Kakasi;
# fonctionnel
$res = Text::Kakasi::getopt_argv('kakasi', '-ieuc', '-w');
$str = Text::Kakasi::do_kakasi($texte_japonais);
# orienté objet
$obj = Text::Kakasi->new('-ieuc','-w');
$str = $obj->get($texte_japonais);

DESCRIPTION

Text::Kakasi est une interface Perl pour kakasi (kanji kana simple inverter), un programme qui convertit les kanji en kana, les kana en romaji, et les kanji en romaji. Il est utile pour la conversion automatique de textes japonais. Il est conçu pour être aussi simple que possible, et il fait souvent un meilleur travail que les méthodes de saisie habituelles pour convertir des textes japonais. Kakasi est le programme d'origine, et cette interface est un portage en Perl de ce programme.

Pour plus d'informations, consultez la page d'accueil de kakasi : http://kakasi.namazu.org/

Text::Kakasi est écrit en tant que module Perl, et il est fourni avec une implémentation entièrement en Perl des fonctionnalités de kakasi version 1.05, par souci de compatibilité et de facilité d'installation. Il est compatible avec Perl 5.8 et est fortement recommandé pour les utilisateurs qui ne peuvent pas installer les programmes externes de kakasi. Ce module Perl peut être installé sans dépendances externes.

APIS FONCTIONNELLES

Ces fonctions sont fournies par le module "Text::Kakasi::" et sont disponibles pour une utilisation directe. Ces fonctions sont exportées par défaut par le module Text::Kakasi. Si vous souhaitez ne pas les importer automatiquement, vous pouvez spécifier les fonctions à importer avec use Text::Kakasi qw/getopt_argv do_kakasi/.

$err = getopt_argv($arg1, $arg2, ...)
Initialise le programme kakasi avec les arguments fournis. Les arguments sont les mêmes que ceux utilisés en ligne de commande pour kakasi 2.3.4 et les versions antérieures. Les arguments possibles sont : 
-a[jE] -j[aE] -g[ajE] -k[ajKH]
-E[aj] -K[ajkH] -H[ajkK] -J[ajkKH]
-i{oldjis,newjis,dec,euc,sjis}
 -o{oldjis,newjis,dec,euc,sjis}
-r{hepburn,kunrei} -p -s -f -c"chars" 
 [jisyo1, jisyo2,,,]
Jeux de caractères :
     a: ascii  j: jisroman  g: graphic  k: kana 
     (j,k     définis dans jisx0201)
     E: kigou  K: katakana  H: hiragana J: kanji
     (E,K,H,J définis dans jisx0208)
Options :
  -i: système de codage d'entrée    -o: système de codage de sortie
  -r: système de conversion romaji
  -p: lister toutes les lectures (avec l'option -J)
  -s: insérer des caractères séparés (avec l'option -J)
  -f: mode furigana (avec l'option -J)
  -c: ignorer les caractères à l'intérieur des jukugo
      (avec l'option -J : par défaut TAB CR LF ESPACE)
  -C: romaji Capitalisation (avec l'option -Ja ou -Jj)
  -U: romaji Majuscules     (avec l'option -Ja ou -Jj)
  -u: appeler fflush() après la sortie d'un caractère
  -w: mode wakatigaki (segmentation de mots)

Retourne 0 en cas de succès, et une chaîne d'erreur en cas d'échec de l'initialisation.

$processed_str = do_kakasi($str)
Applique la conversion kakasi à la chaîne $str en utilisant les options précédemment définies par getopt_argv. Retourne la chaîne traitée. Si une erreur se produit lors du traitement, la fonction retourne "undef".

Remarque : La version 1.x du module ne prend pas en charge la saisie d'arguments directement dans la fonction "kakasi" ; ces options doivent être définies à l'aide de getopt_argv au préalable.

close_kanwadic()
Ferme le dictionnaire de kanji ouvert lors de l'initialisation. Ce n'est pas nécessaire de l'appeler explicitement car le module le fait automatiquement à la fin du script, mais il est possible de le faire soi-même.

Text::Kakasi::JP(3pm)

This module is a Perl interface to the Kakasi library.

Kakasi (Kanji to Kana translation) is a Japanese text processing library that converts Kanji, Hiragana, and Katakana characters into various forms.

DESCRIPTION

This module provides an object-oriented interface to the Kakasi library. It allows you to configure Kakasi and convert Japanese text.

SYNOPSIS

use Text::Kakasi::JP;

my $kakasi = Text::Kakasi::JP->new(
    {'DescriptiveName' => 'kakasi'},
    '-i', 'jis', '-o', 'jis',
    '-p', 'latin', '-H', 'HV', '-J', 'a', '-K', 'a',
);

my $result = $kakasi->convert("これはテストです");

use Data::Dumper;
print Dumper($result);

METHODS

new(%options)

Creates a new Text::Kakasi::JP object. The options are passed directly to the Kakasi library's initialization.

convert($text)

Converts the given text using the configured Kakasi settings. Returns a reference to a hash containing the converted text in different formats.

set($option, $value)

Sets a Kakasi option. See Kakasi documentation for available options.

get($option)

Gets the value of a Kakasi option.

strerror()

Returns the last error message from Kakasi.

OPTIONS

The options passed to new() or set() correspond to the command-line options of the Kakasi utility. Some common options include:

  • -i <encoding>: Input encoding (e.g., jis, utf8).
  • -o <encoding>: Output encoding.
  • -p <mode>: Parsing mode (e.g., latin, romaji).
  • -H <mode>: Hiragana conversion mode (e.g., HV).
  • -J <mode>: Katakana conversion mode.
  • -K <mode>: Kanji conversion mode.

Refer to the Kakasi documentation for a complete list of options.

Object-Oriented APIs

This module provides an object-oriented interface, allowing you to create multiple Kakasi instances with different configurations.

Perl 5.8 Features

This module is compatible with Perl 5.8 and later.
