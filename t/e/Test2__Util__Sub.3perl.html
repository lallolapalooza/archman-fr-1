Test2::Util::Sub(3perl) Guide du programmeur Perl Test2::Util::Sub(3perl)

NOM

Test2::Util::Sub - Outils pour inspecter et manipuler les sous-programmes.

DESCRIPTION

Utilitaires utilisés par Test2::Tools pour inspecter et manipuler les sous-programmes.

EXPORTATIONS

Toutes les exportations sont optionnelles, vous devez spécifier les sous-programmes à importer.

$nom = sub_name(\&sub)
Obtenir le nom du sous-programme.
my $hr = sub_info(\&code)
Ceci renvoie un hashref avec des informations sur le sous-programme : 
{
    ref        => \&code,
    cobj       => $cobj,
    name       => "Some::Mod::code",
    file       => "Some/Mod.pm",
    package    => "Some::Mod",
    # Note : Ces éléments ont été ajustés sur la base d'hypothèses.
    start_line => 22,
    end_line   => 42,
    lines      => [22, 42],
    # Ce n'est pas un bug, ces lignes sont différentes !
    all_lines  => [23, 25, ..., 39, 41],
};
$info->{ref} => \&code
C'est le sous-programme original passé à sub_info().
$info->{cobj} => $cobj
C'est la représentation objet C du coderef.
$info->{name} => "Some::Mod::code"
C'est le nom du coderef. Pour les coderefs anonymes, cela peut se terminer par '__ANON__'. Notez également que le paquet 'main' est spécial et que 'main::' peut être omis.
$info->{file} => "Some/Mod.pm"
Le fichier dans lequel le sous-programme a été défini.
$info->{package} => "Some::Mod"
Le paquet dans lequel le sous-programme a été défini.
$info->{start_line} => 22
$info->{end_line} => 42
$info->{lines} => [22, 42]
Ces trois champs sont la ligne de début, la ligne de fin et le tableau contenant les deux, **ajustés**. Il est important de noter que ces lignes ont été ajustées et peuvent ne pas être précises.

Les lignes sont obtenues en parcourant les ops. Ainsi, la première ligne est la ligne de la première instruction, et la dernière ligne est la ligne de la dernière instruction. Cela signifie que dans les sous-programmes multi-lignes, les lignes sont généralement décalées de 1. Les lignes de ces clés seront ajustées pour vous si un sous-programme multi-lignes est détecté.

$info->{all_lines} => [23, 25, ..., 39, 41]
Il s'agit d'un tableau contenant les lignes de chaque instruction du sous-programme. Contrairement aux autres champs de ligne, ceux-ci n'ont pas été ajustés pour vous.
