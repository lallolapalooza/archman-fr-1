NOM

Test::Alien::Diag - Affiche le diagnostic standard pour les Aliens lors de l'étape de test.

VERSION

version 2.84

SYNTAXE

use Test2::V0;
use Test::Alien::Diag qw( alien_diag );

DESCRIPTION

Ce module fournit une méthode "alien_diag" qui affiche des diagnostics utiles pour cpantesters et d'autres rapports de bug, donnant un résumé rapide des paramètres importants comme les "cflags" et les "libs".

FONCTIONS

alien_diag

alien_diag @aliens;

affiche des diagnostics pour chaque alien donné. Chaque alien doit être le nom de classe d'un alien.

[version 2.68]

alien_diag @aliens, \%options;

À partir d'Alien::Build 2.68, vous pouvez fournir une table d'options pour ajuster le comportement de "alien_diag". Les options valides sont :

properties
Propriétés supplémentaires à afficher dans le diagnostic. Utile lorsque vous avez un Alien avec des propriétés personnalisées définies dans la sous-classe.
list_properties
Propriétés supplémentaires retournées sous forme de liste à afficher dans le diagnostic. Utile lorsque vous avez un Alien avec des propriétés personnalisées qui retournent une liste.
