Test2::Manual::Testing::Todo(3perl) Guide de référence pour programmeurs Perl Test2::Manual::Testing::Todo(3perl)

NOM

Test2::Manual::Testing::Todo - Tutoriel pour marquer des tests comme TODO.

DESCRIPTION

Ce tutoriel couvre le processus de marquage des tests comme TODO. Il décrit également comment TODO fonctionne en interne.

L'OUTIL

use Test2::Tools::Basic qw/todo/;

BLOC TODO

Cette forme est à faible magie. Tous les tests à l'intérieur du bloc sont marqués comme TODO, les tests à l'extérieur du bloc ne sont pas TODO. Vous n'avez pas besoin de gérer les variables. Le défaut de cette forme est qu'elle ajoute quelques niveaux à la pile, ce qui peut casser certains tests à haute magie.

Dans l'ensemble, c'est la forme préférée, sauf si vous avez un cas spécial qui nécessite la forme variable.

todo "Raison du TODO" => sub {
    ok(0, "échec mais TODO");
    ...
};

VARIABLE TODO

Cette forme maintient la portée TODO pour la durée de la variable. Ceci est utile pour les tests sensibles aux changements de portée. Cela imite étroitement le style de Test::More qui localisait la variable du paquet $TODO. Une fois la variable détruite (définie à undef, fin de portée, etc.), l'état TODO se termine.

my $todo = todo "Raison du TODO";
ok(0, "échec mais TODO");
...
$todo = undef;

ÉVÉNEMENTS MANUELS TODO

use Test2::API qw/context/;
sub todo_ok {
    my ($bool, $name, $todo) = @_;
    my $ctx = context();
    $ctx->send_event('Ok', pass => $bool, effective_pass => 1, todo => $todo);
    $ctx->release;
    return $bool;
}

L'événement Test2::Event::Ok possède un champ "todo" qui doit contenir la raison du TODO. L'événement possède également les champs "pass" et "effective_pass". Le champ "pass" est la valeur réelle de réussite/échec. Le champ "effective_pass" est utilisé pour déterminer si l'événement est un échec réel (doit toujours être défini sur vrai avec TODO).

COMMENT LES OUTILS TODO FONCTIONNENT EN INTERNE

La bibliothèque Test2::Todo obtient l'instance Test2::Hub actuelle et ajoute un filtre. Le filtre ajouté définit les champs "todo" et "effective_pass" sur tous les événements Test2::Event::Ok qui passent par le hub. Le filtre convertit également les événements Test2::Event::Diag en événements Test2::Event::Note.
