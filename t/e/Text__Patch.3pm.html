NOM

Text::Patch - Applique des corrections à un texte donné

SYNTAXE

use Text::Patch;
$output = patch( $source, $diff, STYLE => "Unified" );
use Text::Diff;
$src  = ...
$dst  = ...
$diff = diff( \$src, \$dst, { STYLE => 'Unified' } );
$out  = patch( $src, $diff, { STYLE => 'Unified' } );
print "Correction réussie" if $out eq $dst;

DESCRIPTION

Text::Patch combine un texte source avec les données de différence fournies. Les données de différence sont produites par le module Text::Diff ou par l'utilitaire diff standard (man diff, voir l'option -u).

patch( $source, $diff, options... )
Le premier argument est le texte source (original). Le second sont les données de différence. Le troisième argument peut être une référence de hachage avec des options ou tous les autres arguments seront considérés comme des options de patch : 
$output = patch( $source, $diff, STYLE => "Unified", ... );
$output = patch( $source, $diff, { STYLE => "Unified", ... } );

Les options sont :

STYLE => 'Unified'

STYLE peut être 'Unified', 'Context' ou 'OldStyle'.
