NOM

Test::TypeTiny - fonctions utiles pour tester l'efficacité des contraintes de type

SYNOPSIS

use strict;
use warnings;
use Test::More;
use Test::TypeTiny;

use Types::Mine qw(Integer Number);

should_pass(1, Integer);
should_pass(-1, Integer);
should_pass(0, Integer);
should_fail(2.5, Integer);

ok_subtype(Number, Integer);

done_testing;

STATUT

Ce module est couvert par la politique de stabilité de Type-Tiny.

DESCRIPTION

Test::TypeTiny fournit quelques fonctions pratiques pour tester les contraintes de type.

Fonctions

"should_pass($valeur, $type, $nom_test)"
"should_pass($valeur, $type)"
Teste que le test réussit si et seulement si $valeur réussit le test "$type->check".
"should_fail($valeur, $type, $nom_test)"
"should_fail($valeur, $type)"
Teste que le test réussit si et seulement si $valeur échoue le test "$type->check".
"ok_subtype($type, @sous_types)"
Teste que le test réussit si et seulement si tous les @sous_types sont des sous-types de $type.
"EXTENDED_TESTING"
Constante booléenne exportable.
matchfor(@choses)
Assistant pour faire correspondre les exceptions. Non exporté par défaut. Voir aussi Test::Fatal::matchfor.

ENVIRONNEMENT

Si la variable d'environnement "EXTENDED_TESTING" est définie à vrai, ce module promouvra chaque test "should_pass" ou "should_fail" en un sous-test et testera la contrainte de type de manière intégrée et non intégrée.

Cette variable doit être définie au moment de la compilation (c'est-à-dire avant le chargement de ce module).

BOGUES

Veuillez signaler tout bogue à https://github.com/tobyink/p5-type-tiny/issues.

VOIR AUSSI

Type::Tiny.

Pour une alternative à "should_pass", voir Test::Deep::Type qui acceptera volontiers une contrainte de type Type::Tiny au lieu d'une contrainte MooseX::Types.
