NOM

Template::Stash - Stockage magique pour les variables de modèle

SYNOPIS

use Template::Stash;
my $stash = Template::Stash->new(\%vars);
# obtenir les valeurs des variables
$value = $stash->get($variable);
$value = $stash->get(\@compound);
# définir la valeur d'une variable
$stash->set($variable, $value);
$stash->set(\@compound, $value);
# valeur par défaut d'une variable
$stash->set($variable, $value, 1);
$stash->set(\@compound, $value, 1);
# définir des valeurs de variables en masse
$stash->update(\%new_vars)
# méthodes pour (dé-)localiser des variables
$stash = $stash->clone(\%new_vars);
$stash = $stash->declone();

DESCRIPTION

Le module "Template::Stash" définit une classe d'objet qui est utilisée pour stocker les valeurs des variables pour l'utilisation à l'exécution du processeur de modèles. Les valeurs des variables sont stockées en interne dans une référence de hachage (qui est elle-même "blessed" pour créer l'objet) et sont accessibles via les méthodes get() et set().

Les variables peuvent référencer des tableaux de hachage, des listes, des sous-routines et des objets ainsi que des valeurs simples. Le stash effectue automatiquement la bonne magie lors du traitement des variables, appelant du code ou des méthodes d'objet, indexant dans des listes, des hachages, etc.

Le stash possède des méthodes clone() et declone() qui sont utilisées par le processeur de modèles pour faire des copies temporaires du stash afin de localiser les modifications apportées aux variables.

MÉTHODES PUBLIQUES

new(\%params)

La méthode constructeur new() crée et retourne une référence vers un nouvel objet "Template::Stash".

my $stash = Template::Stash->new();

Une référence de hachage peut être passée pour fournir des variables et des valeurs qui devraient être utilisées pour initialiser le stash.

my $stash = Template::Stash->new({ var1 => 'value1',
                                   var2 => 'value2' });

get($variable)

La méthode get() récupère la variable nommée par le premier paramètre.

$value = $stash->get('var1');

Les variables composées séparées par des points peuvent être récupérées en spécifiant les éléments de la variable par référence à une liste. Chaque nœud de la variable occupe deux entrées dans la liste. La première donne le nom de l'élément de la variable, la seconde est une référence à une liste d'arguments pour cet élément, ou 0 si aucun.

[% foo.bar(10).baz(20) %]
$stash->get([ 'foo', 0, 'bar', [ 10 ], 'baz', [ 20 ] ]);

set($variable, $value, $default)

La méthode set() assigne le nom de la variable dans le premier paramètre à la valeur spécifiée dans le second.

$stash->set('var1', 'value1');

Si le troisième paramètre est évalué à une valeur vraie, la variable est définie uniquement si elle n'avait pas de valeur vraie auparavant.

$stash->set('var2', 'default_value', 1);

Les variables composées séparées par des points peuvent être spécifiées comme pour get() ci-dessus.

[% foo.bar = 30 %]
$stash->set([ 'foo', 0, 'bar', 0 ], 30);

La variable magique '"IMPORT"' peut être spécifiée, dont la valeur correspondante doit être une référence de hachage. Le contenu du tableau de hachage est copié (c'est-à-dire importé) dans l'espace de noms courant.

# foo.bar = baz, foo.wiz = waz
$stash->set('foo', { 'bar' => 'baz', 'wiz' => 'waz' });
# importer 'foo' dans l'espace de noms principal : bar = baz, wiz = waz
$stash->set('IMPORT', $stash->get('foo'));

update($variables)

Cette méthode peut être utilisée pour définir ou mettre à jour plusieurs variables en une seule fois.

$stash->update({
    foo => 10,
    bar => 20,
});

getref($variable)

Cette fonctionnalité non documentée retourne une fermeture qui peut être appelée pour obtenir la valeur d'une variable. Elle est utilisée pour implémenter des références de variables qui sont évaluées de manière paresseuse.

[% x = \foo.bar.baz %]          # x est une référence à foo.bar.baz
[% x %]                         # évalue foo.bar.baz

clone(\%params)

La méthode clone() crée et retourne un nouvel objet "Template::Stash" qui représente une copie localisée du stash parent. Les variables peuvent être mises à jour librement dans le stash cloné et lorsque declone() est appelé, le stash d'origine est retourné avec tous ses membres intacts et dans le même état qu'ils étaient avant l'appel de clone().

Pour plus de commodité, une référence de hachage de paramètres peut être passée à clone(), qui est utilisée pour mettre à jour toute variable simple (c'est-à-dire celles qui ne contiennent aucun élément d'espace de noms comme "foo" et "bar", mais pas "foo.bar") lors du clonage du stash. Pour ajouter et mettre à jour des variables complexes, la méthode set() doit être utilisée après l'appel de "clone()." Cela résoudra et/ou créera correctement tous les hachages d'espace de noms nécessaires.

Un stash cloné maintient une référence au stash dont il a été copié dans son membre "_PARENT".

declone()

La méthode declone() retourne la référence "_PARENT" et peut être utilisée pour restaurer l'état d'un stash comme décrit ci-dessus.

define_vmethod($type, $name, $code)

Cette méthode peut être utilisée pour définir de nouvelles méthodes virtuelles. Le premier argument doit être soit "scalar" soit "item" pour définir une méthode virtuelle scalaire, "hash" pour définir des méthodes virtuelles de hachage, ou soit "array" soit "list" pour des méthodes virtuelles de liste. Le deuxième argument doit être le nom de la nouvelle méthode. Le troisième argument doit être une référence à une sous-routine implémentant la méthode. L'élément de données sur lequel la méthode virtuelle est appelée est passé à la sous-routine comme premier argument.

$stash->define_vmethod(
    item => ucfirst => sub {
        my $text = shift;
        return ucfirst $text
    }
);

MÉTHODES INTERNES

dotop($root, $item, \@args, $lvalue)

C'est la méthode principale de l'opération "point" qui évalue les éléments des variables par rapport à leur racine.

undefined($ident, $args)

Cette méthode est appelée lorsque get() rencontre une valeur indéfinie. Si l'option STRICT est activée, elle lèvera une exception indiquant l'utilisation d'une valeur indéfinie. Sinon, elle retournera silencieusement une chaîne vide.

La méthode peut être redéfinie dans une sous-classe pour implémenter un traitement alternatif des valeurs indéfinies.
