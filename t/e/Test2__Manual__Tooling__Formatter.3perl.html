Test2::Manual::Tooling::Formatter(3perl) Guide du programmeur Perl Test2::Manual::Tooling::Formatter(3perl)

NOM

Test2::Manual::Tooling::Formatter - Comment écrire un formateur personnalisé, dans notre cas un formateur JSONL.

DESCRIPTION

Ce tutoriel explique un formateur minimal qui affiche chaque événement comme une chaîne JSON sur sa propre ligne. Un véritable formateur sera probablement beaucoup plus compliqué, mais cela vous donnera les bases nécessaires pour commencer.

CODE COMPLET ANTICIPÉ

package Test2::Formatter::MyFormatter;
use strict;
use warnings;
use JSON::MaybeXS qw/encode_json/;
use base qw/Test2::Formatter/;
sub new { bless {}, shift }
sub encoding {};
sub write {
    my ($self, $e, $num, $f) = @_;
    $f ||= $e->facet_data;
    print encode_json($f), "\n";
}
1;

LIGNE PAR LIGNE

use base qw/Test2::Formatter/;
Tous les formateurs doivent hériter de Test2::Formatter.
sub new { bless {}, shift }
Les formateurs doivent être des objets instanciables, voici une méthode new() minimale.
sub encoding {};
Pour cet exemple, nous laissons cette sous-routine vide. En général, vous devriez implémenter cette sous-routine pour vous assurer de respecter les situations où l'encodage est défini. Test2::V0 lui-même essaiera de définir l'encodage sur UTF8.
sub write { ... }
La méthode write() est la plus importante, chaque événement y est envoyé.
my ($self, $e, $num, $f) = @_;
La méthode write() reçoit 3 ou 4 arguments, le quatrième est optionnel.
$self
Le formateur lui-même.
$e
L'événement en cours d'écriture.
$num
Le numéro de la dernière assertion. Si l'événement traité est une assertion, ce numéro sera incrémenté de 1 depuis le dernier appel à write. Pour les non-assertions, ce numéro est défini sur la dernière assertion.
$f
Ceci PEUT être un hashref contenant toutes les données de facette de l'événement. Le plus souvent, ce sera indéfini. Ceci n'est défini que si les données de facette étaient nécessaires au hub, et elles ne le sont généralement pas.
$f ||= $e->facet_data;
Nous voulons afficher les données de facette de l'événement. Ceci définira $f sur les données de facette à moins que nous n'ayons déjà les données de facette.
print encode_json($f), "\n";
Cette ligne imprime les données de facette encodées en JSON, et un saut de ligne.
