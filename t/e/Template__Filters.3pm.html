Template::Filters(3) Documentation Perl fournie par l'utilisateur Template::Filters(3)

NOM

Template::Filters - Filtres de post-traitement pour blocs de modèles

SYNOPIS

use Template::Filters;
$filtres = Template::Filters->new(\%config);
($filtre, $erreur) = $filtres->fetch($nom, \@args, $contexte);
if ($filtre) {
    print &$filtre("du texte");
}
else {
    print "Impossible de récupérer le filtre $nom : $erreur\n";
}

DESCRIPTION

Le module "Template::Filters" implémente un fournisseur pour créer des sous-routines qui implémentent les filtres standard. Des filtres personnalisés supplémentaires peuvent être fournis via l'option de configuration FILTERS.

MÉTHODES

new(\%params)

Méthode constructeur qui instancie et renvoie une référence vers un objet "Template::Filters". Une référence vers un tableau associatif d'éléments de configuration peut être passée en paramètre. Ceux-ci sont décrits ci-dessous.

my $filtres = Template::Filters->new({
    FILTERS => { ... },
});
my $template = Template->new({
    LOAD_FILTERS => [ $filtres ],
});

Un module "Template::Filters" par défaut est créé par le module Template si l'option LOAD_FILTERS n'est pas spécifiée. Tous les paramètres de configuration sont transmis au constructeur.

$template = Template->new({
    FILTERS => { ... },
});

fetch($name, \@args, $context)

Appelée pour demander la fourniture d'un filtre d'un nom donné. Le nom du filtre doit être spécifié comme premier paramètre. Il doit s'agir de l'un des filtres standard ou d'un filtre spécifié dans la table de configuration FILTERS. Le deuxième argument doit être une référence vers un tableau contenant les paramètres de configuration du filtre. Il peut être spécifié comme 0 ou undef si aucun paramètre n'est fourni. Le troisième argument doit être une référence vers l'objet Template::Context actuel.

La méthode renvoie une référence vers une sous-routine de filtre en cas de succès. Elle peut également renvoyer "(undef, STATUS_DECLINE)" pour décliner la demande, afin de permettre la délégation à d'autres fournisseurs de filtres dans la chaîne de responsabilité LOAD_FILTERS. En cas d'erreur, "($error, STATUS_ERROR)" est renvoyé, où $error est un message d'erreur ou un objet Template::Exception indiquant l'erreur survenue.

Lorsque l'option "TOLERANT" est définie, les erreurs sont automatiquement déclassées en une réponse "STATUS_DECLINE".

use_html_entities()

Cette méthode de classe peut être appelée pour configurer le filtre "html_entity" afin qu'il utilise le module HTML::Entities. Une erreur sera levée s'il n'est pas installé sur votre système.

use Template::Filters;
Template::Filters->use_html_entities();

use_apache_util()

Cette méthode de classe peut être appelée pour configurer le filtre "html_entity" afin qu'il utilise le module Apache::Util. Une erreur sera levée s'il n'est pas installé sur votre système.

use Template::Filters;
Template::Filters->use_apache_util();

use_rfc2732()

Cette méthode de classe peut être appelée pour configurer les filtres "uri" et "url" afin d'utiliser l'ancien standard RFC2732 pour la correspondance des caractères non sécurisés.

use_rfc3986()

Cette méthode de classe peut être appelée pour configurer les filtres "uri" et "url" afin d'utiliser le nouveau standard RFC3986 pour la correspondance des caractères non sécurisés.

OPTIONS DE CONFIGURATION

La liste suivante résume les options de configuration qui peuvent être fournies au constructeur new() de "Template::Filters". Veuillez consulter Template::Manual::Config pour plus d'informations sur chaque option.

FILTERS

L'option FILTERS peut être utilisée pour spécifier des filtres personnalisés qui peuvent ensuite être utilisés avec la directive FILTER comme les autres. Ils sont ajoutés aux filtres standard disponibles par défaut.

$filtres = Template::Filters->new({
    FILTERS => {
        'sfilt1' =>   \&filtre_statique,
        'dfilt1' => [ \&fabrique_filtre_dynamique, 1 ],
    },
});

TOLÉRANT

Le drapeau TOLERANT peut être défini pour indiquer que le module "Template::Filters" doit ignorer toutes les erreurs et renvoyer à la place "STATUS_DECLINED".

DEBUG

L'option DEBUG peut être utilisée pour activer les messages de débogage pour le module Template::Filters en la définissant pour inclure la valeur "DEBUG_FILTERS".

use Template::Constants qw( :debug );
my $template = Template->new({
    DEBUG => DEBUG_FILTERS | DEBUG_PLUGINS,
});

FILTRES STANDARD

Veuillez consulter Template::Manual::Filters pour une liste des filtres fournis avec le Template Toolkit, accompagnée d'exemples d'utilisation.
