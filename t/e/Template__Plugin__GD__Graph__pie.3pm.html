NOM

Template::Plugin::GD::Graph::pie - Créer des diagrammes circulaires avec légende

SYNOPSIS

[% USE g = GD.Graph.pie(x_size, y_size); %]

EXEMPLES

[% FILTER null;
    data = [
        ["1er","2ème","3ème","4ème","5ème","6ème"],
        [    4,    2,    3,    4,    3,  3.5]
    ];
    USE my_graph = GD.Graph.pie( 250, 200 );
    my_graph.set(
            title => 'Un diagramme circulaire',
            label => 'Étiquette',
            axislabelclr => 'black',
            pie_height => 36,
            transparent => 0,
    );
    my_graph.plot(data).png | stdout(1);
   END;
-%]

DESCRIPTION

Le plugin GD.Graph.pie fournit une interface à la classe GD::Graph::pie définie par le module GD::Graph. Il permet de tracer un jeu de données (x,y) sous forme de diagramme circulaire. Les valeurs x sont typiquement des chaînes de caractères.

Voir GD::Graph pour plus de détails.
