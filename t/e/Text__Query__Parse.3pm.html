NOM

Text::Query::Parse - Classe de base pour les analyseurs de requêtes

SYNOPIS

package Text::Query::ParseThisSyntax;
use Text::Query::Parse;

use vars qw(@ISA);
@ISA = qw(Text::Query::Parse);

DESCRIPTION

Ce module fournit une classe de base virtuelle pour les analyseurs de requêtes.

Il définit la méthode "prepare" qui est appelée par l'objet "Text::Query" pour compiler la chaîne de requête.

MEMBRES

-build Pointeur vers un objet Text::Query::Build.
scope Pile de portée. Définit le contexte dans lequel la requête doit être résolue.
token Le jeton courant. Détruit par "prepare".
tokens Une référence à la liste de tous les jetons. Remplie par parse_tokens. Détruit par "prepare".
parseopts Une référence à une table de hachage contenant tous les paramètres donnés à la fonction "prepare".
-verbose Entier indiquant le niveau de verbosité souhaité.

MÉTHODES

prepare (QSTRING [OPTIONS])
Compile l'expression de requête dans "QSTRING" sous forme interne et définit les options. Appelle d'abord "build_init" pour réinitialiser le constructeur et détruire les membres "token" et "tokens". Ensuite, appelle "parse_tokens" pour remplir le membre "tokens". Ensuite, appelle "expression" pour utiliser les jetons de "tokens". L'"expression" est censée appeler les fonctions "build_*" pour construire l'expression compilée. Enfin, appelle "build_final_expression" avec le résultat de "expression".

Un analyseur dérivé doit redéfinir cette fonction pour définir les valeurs par défaut pour des options spécifiques.

expression ()
Doit être redéfinie par le paquet dérivé. Renvoie la forme interne de la question construite à partir des fonctions "build_*" en utilisant les "tokens".
parse_tokens (QSTRING)
Doit être redéfinie par le paquet dérivé. Analyse le scalaire "QSTRING" et remplit le membre "tokens" avec des unités lexicales.
build_*
Raccourcis vers la fonction correspondante de l'objet Text::Query::Build trouvé dans le membre "-build".

OPTIONS

Ce sont les options de la méthode "prepare" et du constructeur.

-quotes vaut par défaut \'\"
Définit les caractères de guillemets.
-case vaut par défaut 0
Si vrai, effectue une correspondance sensible à la casse.
-litspace vaut par défaut 0
Si vrai, correspond aux espaces (sauf entre les opérateurs) dans "QSTRING" littéralement. Si faux, correspond aux espaces comme "\s+".
-regexp vaut par défaut 0
Si vrai, traite les motifs dans "QSTRING" comme des expressions régulières plutôt que comme du texte littéral.
-whole vaut par défaut 0
Si vrai, ne correspond qu'aux mots entiers, pas aux sous-chaînes de mots.
