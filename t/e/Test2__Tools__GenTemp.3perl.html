NOM

Test2::Tools::GenTemp - Outil pour générer un répertoire temporaire rempli.

DESCRIPTION

Ceci exporte un outil qui vous aide à créer un répertoire temporaire, avec des sous-répertoires et des fichiers texte à l'intérieur.

SYNTAXE

use Test2::Tools::GenTemp qw/gen_temp/;
my $dir = gen_temp(
    a_file => "Contenu de a_file",
    a_dir  => {
        'a_file' => 'Contenu de a_dir/afile',
        a_nested_dir => { ... },
    },
    ...
);
done_testing;

EXPORTATIONS

Toutes les sous-routines sont exportées par défaut.

gen_temp(fichier => 'contenu', sous_repertoire => [ sous_fichier_repertoire => 'contenu', ...], ...)
gen_temp(-tempdir => \@ARGUMENTS_TEMPDIR, fichier => 'contenu', sous_repertoire => [ sous_fichier_repertoire => 'contenu', ...], ...)
Ceci générera un nouveau répertoire temporaire avec tous les fichiers et sous-répertoires que vous spécifiez, de manière récursive. Le répertoire temporaire initial est créé à l'aide de File::Temp::tempdir(), vous pouvez passer des arguments à tempdir en utilisant l'argument "-tempdir => [...]".
