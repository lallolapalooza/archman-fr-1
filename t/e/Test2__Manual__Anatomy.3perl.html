Test2::Manual::Anatomy(3perl) Guide du programmeur Perl Test2::Manual::Anatomy(3perl)

NOM

Test2::Manual::Anatomy - Le hub pour la documentation du fonctionnement interne des composants de Test2.

DESCRIPTION

Cette section couvre les aspects internes de l'architecture Test2. C'est une information utile pour les constructeurs d'outils, mais une information essentielle pour les mainteneurs de Test2 lui-même.

DU DÉBUT À LA FIN

Le document Test2::Manual::Anatomy::EndToEnd est un aperçu de Test2 depuis le chargement jusqu'à la fin.

ÉVÉNEMENTS

Le document Test2::Manual::Anatomy::Event explique le fonctionnement interne des événements.

LE CONTEXTE

Le document Test2::Manual::Anatomy::Context explique le fonctionnement de l'objet Test2::API::Context.

L'API ET L'INSTANCE API

Le document Test2::Manual::Anatomy::API explique le fonctionnement interne de l'API Test2.

HUBS

Le document Test2::Manual::Anatomy::Hubs explique le fonctionnement interne de la pile de hubs Test2, et les hubs qui s'y trouvent.

LE SYSTÈME IPC

Le document Test2::Manual::Anatomy::IPC décrit le système IPC.

UTILITAIRES INTERNES

Le document Test2::Manual::Anatomy::Utilities décrit divers utilitaires fournis par le système Test2.

VOIR AUSSI

Test2::Manual - Index principal du manuel.

SOURCE

Le dépôt de code source de Test2-Manual se trouve à l'adresse https://github.com/Test-More/test-more/.
