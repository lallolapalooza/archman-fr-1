NOM

Term::ExtendedColor - Couleur de sortie de l'écran en utilisant 256 couleurs

SYNOPSIS

use Term::ExtendedColor qw(:all);
# Ou utilisez la balise 'attributes' pour importer uniquement les fonctions de configuration
# des attributs.
# Ceci importera les fonctions suivantes :
# fg(), bg(), bold(), underline(), inverse(), italic(), clear()
use Term::ExtendedColor ':attributes';
## Couleurs de premier plan
my $texte_rouge = fg('red2', 'ceci est en rouge');
my $printemps   = fg('springgreen3', 'ceci est vert');
## Couleurs d'arrière-plan
print bg('red5', "Texte par défaut sur fond rouge foncé"), "\n";
my $rouge_sur_vert = fg('red3', bg('green12', 'Texte rouge sur fond vert'));
print "$rouge_sur_vert\n";
## Attributs en cascade
Term::ExtendedColor::autoreset(0);
my $gras  = fg('bold', 'Ceci est en gras');
my $rouge   = fg('red2', 'Ceci est rouge... et gras');
my $vert = bg('green28', 'Ceci est rouge gras sur fond vert');
# Assurez-vous de tout effacer lorsque autoreset est désactivé,
# sinon le shell de l'utilisateur sera corrompu.
my $effacer = clear();
print "$gras\n";
print "$rouge\n";
print "$vert $effacer\n";
## Attributs non-couleurs
# Réactiver autoreset
Term::ExtendedColor::autoreset(1);
for(qw(italic underline blink reverse bold)) {
  print fg($_, $_), "\n";
}
# Pour plus de commodité
my $en_gras = bold("Texte en gras !");
my $italique = italic("Texte en italique !");
## Supprimer tous les attributs des données d'entrée
my @colores;
push(@colores, fg('bold', fg('red2', 'Gras et rouge')));
push(@colores, fg('green13', fg('italic', 'Vert, italique')));
print "$_\n" for @colores;
print "$_\n" for uncolor(@colores);

DESCRIPTION

Term::ExtendedColor fournit des fonctions pour envoyer des séquences d'échappement dites étendues au terminal. Ceci doit être utilisé avec un terminal compatible 256 couleurs ; consultez la section NOTES pour une matrice des émulateurs de terminaux supportant actuellement cela.

EXPORTS

Aucun par défaut.

Deux balises sont fournies pour plus de commodité :

# Importer toutes les fonctions
use Term::ExtendedColor qw(:all);
# Importer les fonctions de configuration des attributs
# fg(), bg(), bold(), italic(), underline(), inverse(), clear()
use Term::ExtendedColor qw(:attributes);

FONCTIONS

fg($couleur, $chaine)

my $vert = fg('green2', 'premier plan vert');
my @bleu  = fg('blue4',  ['accepte également les tableaux références']);
my $couleur_x = fg('mediumorchid1', 'Utilisation des correspondances de rgb.txt X11');
my $seq_brute = fg('38;5;197;48;5;53;1;3;4;5;7', 'ceci fonctionne aussi');

Configure les couleurs et attributs de premier plan.

Voir "COULEURS ET ATTRIBUTS" pour les premiers arguments valides. De plus, les couleurs peuvent être spécifiées en utilisant leur indice :

my $jaune = fg(220, 'Jaune');

Si la variable interne $AUTORESET est supérieure à zéro (par défaut), chaque élément de la liste de chaînes sera enveloppé dans des séquences d'échappement de telle sorte que les attributs demandés soient définis avant la chaîne et réinitialisés aux valeurs par défaut après la chaîne.

Les attributs en cascade peuvent être activés en définissant $AUTORESET à une valeur fausse.

Term::ExtendedColor::autoreset( 0 );
my $rouge   = fg('red1', 'Rouge');
my $vert = fg('green1', 'Vert');
print "Texte après $rouge est rouge jusqu'à $vert\n";
print "Le texte est toujours vert, ", bold('et maintenant gras aussi !');
# Si vous sortez maintenant sans réinitialiser les couleurs et attributs, il y a de fortes chances
# que votre invite soit corrompue.
clear(); # Tout redevient normal

Si un attribut invalide est passé, les données originales seront renvoyées non modifiées.

Si aucun attribut n'est passé, lance une exception.

bg($couleur, $chaine)

my $fond_vert = bg('green4', 'fond vert');
my @fond_bleu  = bg('blue6',  ['fond bleu']);

Comme fg(), mais configure la couleur d'arrière-plan.

uncolor($chaine) | uncolour($chaine)

my $decors_supprimes = uncolor($donnees_colorees);
my @pas_de_couleur = uncolor(\@colores);
my @pas_de_couleur = uncolor(@colores);

Supprime toutes les séquences d'échappement d'attributs et de couleurs de l'entrée.

Voir uncolor pour un utilitaire en ligne de commande utilisant cette fonction.

get_colors() | get_colours()

my $couleurs = get_colors();

Retourne une référence de hachage avec tous les attributs et couleurs disponibles.

clear()

Lorsqu'elle est appelée en contexte scalaire, renvoie la séquence d'échappement qui réinitialise tous les attributs à leurs valeurs par défaut.

Lorsqu'elle est appelée en contexte vide, l'imprime directement.

autoreset()

Active/désactive la réinitialisation automatique. Activé par défaut.

Term::ExtendedColor::autoreset( 0 ); # Désactive la réinitialisation automatique

bold(\@donnees)

Fonction pratique qui peut être utilisée à la place de "fg('bold', \@donnees)";

Lorsqu'elle est appelée sans arguments, renvoie une chaîne qui désactive l'attribut gras.

italic(\@donnees)

Fonction pratique qui peut être utilisée à la place de "fg('italic', \@donnees)";

Lorsqu'elle est appelée sans arguments, renvoie une chaîne qui désactive l'attribut italique.

underline(\@donnees)

Fonction pratique qui peut être utilisée à la place de "fg('underline', \@donnees)";

Lorsqu'elle est appelée sans arguments, renvoie une chaîne qui désactive l'attribut souligné.

inverse(\@donnees)

Vidéo inversée / inverse. Fonction pratique qui peut être utilisée à la place de "fg('inverse', \@donnees)";

Lorsqu'elle est appelée sans arguments, renvoie une chaîne qui désactive l'attribut inversé.

NOTES

Les codes générés par ce module sont conformes à l'extension du standard de couleurs ANSI implémentée pour la première fois dans xterm en 1999. Les 16 premières couleurs d'index (0 - 15) sont les couleurs ANSI régulières, tandis que les index 16 à 255 sont l'extension. Tous les émulateurs de terminaux ne supportent pas cette extension, bien que j'aie eu du mal à en trouver un qui ne le fasse pas. :)

Terminal    256 couleurs
----------------------
aterm               non
eterm              oui
gnome-terminal     oui
konsole            oui
lxterminal         oui
mrxvt              oui
roxterm            oui
rxvt                non
rxvt-unicode       oui *
sakura             oui
terminal           oui
terminator         oui
vte                oui
xterm              oui
iTerm2             oui
Terminal.app        non
GNU Screen         oui
tmux               oui
TTY/VC              non

* Nécessitait auparavant un patch. Le support complet a été ajouté dans la version 9.09.

Il n'y a aucun moyen de donner des noms significatifs à ces couleurs étendues.

Notre première idée a été de les faire correspondre à des noms de couleurs standards, comme ceux de la spécification HTML 4.0 ou celle de SVG. Ils ne correspondaient pas.

Par conséquent, elles sont nommées par leur couleur de base (rouge, vert, magenta) plus un indice ; le premier indice (toujours 1) est la teinte la plus vive de cette couleur particulière, tandis que le dernier indice est la plus foncée.

Il est également possible d'utiliser certains noms de couleurs X, tels que définis dans "rgb.txt". Notez que les valeurs de couleur ne correspondent pas exactement ; ce n'est qu'une approximation.

Une liste complète des couleurs disponibles peut être obtenue avec get_colors(). Voir "COULEURS ET ATTRIBUTS" pour la liste complète. Toutes les couleurs mappées peuvent également être obtenues par programmation avec get_colors().

DESCRIPTION

This module provides a simple interface for the extended ANSI color and attribute codes. It allows you to use colors beyond the basic 16 colors, and to combine multiple attributes.

FUNCTIONS

color($spec)
Returns the ANSI escape code for the given color specification. The specification can be a color name, a color number, or a more complex string specifying foreground and background colors, and attributes.
reset()
Returns the ANSI escape code to reset all attributes and colors.
attribute($attr)
Returns the ANSI escape code for the given attribute.
fg($spec)
Returns the ANSI escape code for the given foreground color specification.
bg($spec)
Returns the ANSI escape code for the given background color specification.
reverse()
Returns the ANSI escape code for reverse video.
bold()
Returns the ANSI escape code for bold text.
underline()
Returns the ANSI escape code for underlined text.
italic()
Returns the ANSI escape code for italic text.
blink()
Returns the ANSI escape code for blinking text.
conceal()
Returns the ANSI escape code for concealed text.
faint()
Returns the ANSI escape code for faint text.
clear()
Alias for reset().
normal()
Alias for reset().
bright()
Alias for bold().
underscore()
Alias for underline().
inverse()
Alias for reverse().
cursive()
Alias for italic().
blink_ms()
Returns the ANSI escape code for rapid blinking text (MS DOS only).
negative()
Alias for reverse().

The color, fg, and bg functions can accept various types of specifications:

  • Color names: A standard X11 color name (e.g., "red", "blue", "aquamarine1").
  • Color numbers: A number from 0 to 255, representing the 256 ANSI colors.
  • RGB specification: A string in the format "rgb:XX/XX/XX", where XX is a hexadecimal number from 00 to FF.
  • Attributes: A comma-separated string of attributes and color specifications. For example: 
    bold;fg;red;bg;blue
    italic;fg;rgb:FF/00/00;bg;rgb:00/00/FF
    underline;blink;fg;255;bg;0
    The attributes are bold, faint, italic, underline, blink, reverse, conceal, fg, and bg. The fg and bg specifiers can be followed by a color name, color number, or RGB specification.

If no color specification is given, the default is to reset all attributes and colors.

The module also supports 24-bit color (TrueColor) if the terminal supports it.

The color, fg, and bg functions also accept raw SGR (Select Graphic Rendition) parameters as a semicolon-separated string.

my $foo = color('1;31;42'); # Bold, Red foreground, Green background
my $bar = fg('1;31');       # Bold, Red foreground
my $baz = bg('42');         # Green background

NOTES

The availability of certain colors and attributes depends on the terminal's capabilities. For example, not all terminals support blinking or faint attributes.

The 256-color palette is based on the xterm color scheme. The standard color map provides a mapping from common color names to these numbers.

italic, cursive             italic or cursive
underline, underscore       underline

blink_ms                    rapid blink (only supported in MS DOS)
reverse, inverse, negative  reverse video
conceal                     conceal, or hide (not widely supported)
