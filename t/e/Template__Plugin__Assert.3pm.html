NOM

Template::Plugin::Assert - intercepter les valeurs non définies

SYNTAXE

[% USE assert %]
# déclenche une erreur si des valeurs non définies sont retournées
[% object.assert.method %]
[% hash.assert.key %]
[% list.assert.item %]

DESCRIPTION

Ce plugin définit la méthode virtuelle "assert" qui peut être utilisée pour lancer automatiquement des erreurs lorsque des valeurs non définies sont utilisées.

Par exemple, considérez cette ligne d'accès aux données:

[% user.name %]

Si "user.name" est une valeur non définie, TT l'ignorera silencieusement et n'affichera rien. Si vous "USE" le plugin "assert", vous pouvez ajouter la méthode virtuelle "assert" entre les éléments "user" et "name", comme ceci:

[% user.assert.name %]

Maintenant, si "user.name" est une valeur non définie, une exception sera déclenchée:

erreur d'assertion - valeur non définie pour le nom
