Test2::Compare::Object(3perl) Guide du programmeur Perl Test2::Compare::Object(3perl)

NOM

Test2::Compare::Object - Représentation d'un objet lors d'une comparaison profonde.

DESCRIPTION

Cette classe vous permet de spécifier un objet attendu dans une comparaison profonde. Vous pouvez vérifier les champs/éléments de la référence sous-jacente, appeler des méthodes pour vérifier les résultats et effectuer des vérifications méta sur le type d'objet et le type de référence.

MÉTHODES

$class = $obj->meta_class
La méta-classe à utiliser lors de la vérification du type d'objet. Ceci est principalement listé car il est utile de le remplacer pour les sous-classes d'objets spécialisées.

Ceci retourne normalement juste Test2::Compare::Meta.

$class = $obj->object_base
La classe de base attendue lors de la vérification du type d'objet. Ceci est principalement listé car il est utile de le remplacer pour les sous-classes d'objets spécialisées.

Ceci retourne normalement juste 'UNIVERSAL'.

$obj->add_prop(...)
Ajoute une méta-propriété à vérifier, voir Test2::Compare::Meta. Cette méthode délègue simplement.
$obj->add_field(...)
Ajoute un champ de hash à vérifier, voir Test2::Compare::Hash. Cette méthode délègue simplement.
$obj->add_item(...)
Ajoute un élément de tableau à vérifier, voir Test2::Compare::Array. Cette méthode délègue simplement.
$obj->add_call($method, $check)
$obj->add_call($method, $check, $name)
$obj->add_call($method, $check, $name, $context)
Ajoute une vérification d'appel de méthode. Cela appellera la méthode spécifiée sur votre objet et vérifiera le résultat. $method peut être un nom de méthode, une référence à un tableau ou un code référence.

S'il s'agit d'une référence à un tableau, le premier élément doit être le nom de la méthode, et les autres sont les arguments qui lui seront passés.

Dans le cas d'un code référence, il peut être utile de fournir un nom alternatif. Lorsqu'aucun nom n'est fourni, le nom est soit $method soit la chaîne '\&CODE'.

Si $context est 'list', la méthode sera appelée dans un contexte de liste, et le résultat sera une référence à un tableau.

Si $context est 'hash', la méthode sera appelée dans un contexte de liste, et le résultat sera une référence à un hash (cela générera un avertissement si la méthode retourne un nombre impair de valeurs).
