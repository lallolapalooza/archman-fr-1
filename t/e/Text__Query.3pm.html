NOM

Text::Query - Framework de traitement de requêtes

SYNTAXE

use Text::Query;

# Constructeur
$query = Text::Query->new([CHAINE_REQ] [OPTIONS]);
# Méthodes
$query->prepare(CHAINE_REQ [OPTIONS]);
$query->match([CIBLE]);
$query->matchscalar([CIBLE]);

DESCRIPTION

Ce module fournit un objet qui compare une source de données à une expression de requête.

Les expressions de requête sont compilées en une forme interne lorsqu'un nouvel objet est créé ou lorsque la méthode "prepare" est appelée ; elles ne sont pas recompilées à chaque comparaison.

La classe fournie par ce module utilise quatre paquets pour traiter la requête. L'analyseur de requête analyse la question et appelle un générateur d'expression de requête (forme interne de la question). L'optimiseur est ensuite appelé pour réduire la complexité de l'expression. Le solveur applique l'expression sur une source de données.

Les analyseurs suivants sont fournis :

Text::Query::ParseAdvanced
Text::Query::ParseSimple

Les générateurs suivants sont fournis :

Text::Query::BuildAdvancedString
Text::Query::BuildSimpleString

Le solveur suivant est fourni :

Text::Query::SolveSimpleString
Text::Query::SolveAdvancedString

EXEMPLES

use Text::Query;
my $q=new Text::Query('hello and world',
                      -parse => 'Text::Query::ParseAdvanced',
                      -solve => 'Text::Query::SolveAdvancedString',
                      -build => 'Text::Query::BuildAdvancedString');
die "mauvaise expression de requête" if not defined $q;
print if $q->match;

CONSTRUCTEUR

new ([CHAINE_REQ] [OPTIONS])
C'est le constructeur pour un nouvel objet Text::Query. Si une "CHAINE_REQ" est fournie, elle sera compilée en forme interne.

"OPTIONS" sont passées sous forme de hachage, en utilisant des paires clé-valeur. Les options possibles sont :

-parse - Nom du paquet de l'analyseur. Par défaut, il s'agit de Text::Query::ParseSimple.

-build - Nom du paquet du générateur. Par défaut, il s'agit de Text::Query::Build.

-optimize - Nom du paquet de l'optimiseur. Par défaut, il s'agit de Text::Query::Optimize.

-solve - Nom du paquet du solveur. Par défaut, il s'agit de Text::Query::Solve.

-mode - Nom d'un groupe prédéfini de paquets à utiliser. Les options sont
actuellement "simple_text" et "advanced_text".

Ces options sont gérées par la méthode "configure".

Toutes les autres options sont passées à la fonction "prepare" de l'analyseur. Voir les pages du manuel correspondantes pour une description.

Si "CHAINE_REQ" est indéfini, la fonction prepare n'est pas appelée.

Le constructeur plantera si une "CHAINE_REQ" a été fournie et présentait une syntaxe illégale.

MÉTHODES

configure ([OPTIONS])
Définit les paquets "parse", "build", "optimize" ou "solve". Voir la description du "CONSTRUCTEUR" pour les explications.
prepare (CHAINE_REQ [OPTIONS])
Compile l'expression de requête dans "CHAINE_REQ" en forme interne et définit les options (identiques à celles du constructeur). "prepare" peut être utilisée pour changer l'expression de requête et les options d'un objet de requête existant. Si "OPTIONS" sont omises, les options définies par un appel précédent à "prepare" sont persistantes.

L'optimiseur (-optimize) est appelé avec le résultat de l'analyseur (-parse). L'analyseur utilise le générateur (-build) pour construire la forme interne.

Cette méthode renvoie une référence à l'objet de requête si la syntaxe de l'expression était légale, ou plante sinon.

match ([CIBLE])
Appelle la méthode match du solveur (-solve).
matchscalar ([CIBLE])
Appelle la méthode matchscalar du solveur (-solve).
