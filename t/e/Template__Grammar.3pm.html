NOM

Template::Grammar - Tables d'état/règles pour la grammaire TT

SYNOPIS

# aucune partie utilisable par l'utilisateur à l'intérieur

DESCRIPTION

Ce module définit les tables d'état et de règles que le module Template::Parser utilise pour analyser les modèles. Il est généré à partir d'une grammaire de type YACC à l'aide du module "Parse::Yapp". Le sous-répertoire parser de la distribution source de Template Toolkit contient la grammaire et les autres fichiers nécessaires pour générer ce module.

Mais vous n'avez pas à vous soucier de tout cela, sauf si vous envisagez de modifier le langage de Template Toolkit.
