NOM

Test2::Tools::Subtest - Outils pour écrire des sous-tests

DESCRIPTION

Ce paquet exporte des sous-programmes qui vous permettent d'écrire des sous-tests.

Il existe deux types de sous-tests, mis en mémoire tampon (buffered) et diffusés (streamed). Les sous-tests diffusés imitent les sous-tests de Test::More en ce sens qu'ils rendent tous les événements dès qu'ils sont produits. Les sous-tests mis en mémoire tampon attendent que le sous-test se termine avant de rendre tous les résultats.

La principale différence est que les sous-tests diffusés sont illisibles lorsqu'ils sont combinés avec la concurrence. Les sous-tests mis en mémoire tampon ont l'air corrects avec n'importe quel nombre de threads et de processus concurrents.

SYNOPIS

MIS EN MÉMOIRE TAMPON

use Test2::Tools::Subtest qw/subtest_buffered/;
subtest_buffered my_test => sub {
    ok(1, "événement de sous-test A");
    ok(1, "événement de sous-test B");
};

Cela produira une sortie comme celle-ci:

ok 1 - my_test {
    ok 1 - événement de sous-test A
    ok 2 - événement de sous-test B
    1..2
}

DIFFUSÉ

L'option par défaut est 'buffered'. Si vous souhaitez des sous-tests diffusés, à la manière de Test::Builder, utilisez ceci:

use Test2::Tools::Subtest qw/subtest_streamed/;
subtest_streamed my_test => sub {
    ok(1, "événement de sous-test A");
    ok(1, "événement de sous-test B");
};

Cela produira une sortie comme celle-ci:

# Sous-test : my_test
    ok 1 - événement de sous-test A
    ok 2 - événement de sous-test B
    1..2
ok 1 - Sous-test : my_test

NOTE IMPORTANTE

Vous pouvez utiliser "bail_out" ou "skip_all" dans un sous-test, mais pas dans un bloc BEGIN ou une instruction "use". Ceci est dû à la façon dont le contrôle de flux fonctionne dans un bloc BEGIN. Ce n'est normalement pas un problème, mais cela peut arriver dans des conditions rares utilisant eval, ou des fichiers script comme sous-tests.

EXPORTATIONS

subtest_streamed $nom => $sub
subtest_streamed($nom, $sub, @args)
subtest_streamed $nom => \%params, $sub
subtest_streamed($nom, \%params, $sub, @args)
Exécute le coderef du sous-test, diffuse les événements au fur et à mesure qu'ils se produisent.

"\%params" est un hashref avec tous les arguments que vous souhaitez passer à la construction du hub.

subtest_buffered $nom => $sub
subtest_buffered($nom, $sub, @args)
subtest_buffered $nom => \%params, $sub
subtest_buffered($nom, \%params, $sub, @args)
Exécute le coderef du sous-test, rend tous les événements en une fois une fois le sous-test terminé.

"\%params" est un hashref avec tous les arguments que vous souhaitez passer à la construction du hub.
