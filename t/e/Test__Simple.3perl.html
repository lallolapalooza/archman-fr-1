Test::Simple(3perl) Guide de référence pour les développeurs Perl Test::Simple(3perl)

NOM

Test::Simple - Utilitaires de base pour écrire des tests.

SYNTAXE

use Test::Simple tests => 1;
ok( $foo eq $bar, 'foo est égal à bar' );

DESCRIPTION

** Si vous ne connaissez pas les tests, lisez d'abord Test::Tutorial ! **

Ce module est extrêmement simple et basique, idéal pour écrire des tests appropriés pour les modules CPAN et autres projets. Si vous voulez faire des tests plus compliqués, utilisez le module Test::More (un remplacement direct pour ce module).

L'unité de base du test en Perl est le ok. Pour chaque chose que vous voulez tester, il imprimera "ok" ou "not ok" pour indiquer un succès ou un échec. Vous faites cela avec la fonction ok() (voir ci-dessous).

La seule autre contrainte est que vous devez pré-déclarer combien de tests vous prévoyez d'exécuter. Ceci est pour les cas où quelque chose tourne mal pendant le test et que votre programme de test s'arrête, ou sort de la boucle, ou quoi que ce soit. Vous faites cela comme suit :

use Test::Simple tests => 23;

Vous devez avoir un plan.

ok
ok( $foo eq $bar, $name );
ok( $foo eq $bar );

ok() prend une expression (dans ce cas "$foo eq $bar"). Si elle est vraie, le test a réussi. Si elle est fausse, il a échoué. C'est tout.

ok() imprimera "ok" ou "not ok" ainsi que le numéro du test (il s'en chargera pour vous).

# Produit "ok 1 - Hell not yet frozen over" (ou not ok)
ok( get_temperature($hell) > 0, 'L\'enfer n\'a pas encore gelé' );

Si vous lui donnez un $name, celui-ci sera imprimé avec "ok/not ok" pour faciliter la localisation de votre test en cas d'échec (recherchez par nom). Il est également plus facile pour la personne suivante de comprendre quel test vous effectuez. L'utilisation de noms de tests est encouragée.

Tous les tests sont exécutés dans un contexte scalaire. Donc, ceci :

ok( @stuff, 'J\'ai quelques trucs' );

fera ce que vous voulez (échouera si la liste est vide).

Test::Simple commencera par imprimer le nombre de tests exécutés dans le format "1..M" (donc "1..5" signifie que vous allez exécuter 5 tests). Ce format est délibérément choisi pour que Test::Harness sache combien de tests vous prévoyez d'exécuter en cas de problème.

Si tous vos tests ont réussi, Test::Simple se terminera avec un code de sortie zéro (normal). Si quelque chose a échoué, il se terminera avec le nombre d'échecs. Si vous exécutez moins (ou plus) de tests que prévu, les tests manquants (ou supplémentaires) seront considérés comme des échecs. Si aucun test n'est exécuté, Test::Simple affichera un avertissement et se terminera avec 255. Si le test se termine prématurément, même si tout s'est déroulé correctement, cela est considéré comme un échec et le programme se termine avec 255.

Par conséquent, les codes de sortie sont...

0                   tous les tests ont réussi
255                 le test s'est terminé prématurément ou tous les tests ont réussi mais le nombre de tests est incorrect
tout autre nombre    combien ont échoué (y compris les échecs manquants ou supplémentaires)

Si vous échouez à plus de 254 tests, cela sera rapporté comme 254.

Ce module n'a pas pour but d'être un système de test complet. Il vise simplement à vous aider à démarrer. Une fois que vous vous serez familiarisé, il est recommandé de regarder Test::More.

EXEMPLE

Voici un exemple de fichier .t pour le module fictif Film.

use Test::Simple tests => 5;
use Film;  # Ce que vous testez.
my $btaste = Film->new({ Title    => 'Bad Taste',
                         Director => 'Peter Jackson',
                         Rating   => 'R',
                         NumExplodingSheep => 1
                       });
ok( defined($btaste) && ref $btaste eq 'Film',     'new() fonctionne' );
ok( $btaste->Title      eq 'Bad Taste',     'Title() récupéré'    );
ok( $btaste->Director   eq 'Peter Jackson', 'Director() récupéré' );
ok( $btaste->Rating     eq 'R',             'Rating() récupéré'   );
ok( $btaste->NumExplodingSheep == 1,        'NumExplodingSheep() récupéré' );

Cela produira une sortie comme celle-ci :

1..5
ok 1 - new() fonctionne
ok 2 - Title() récupéré
ok 3 - Director() récupéré
not ok 4 - Rating() récupéré
#   Test échoué 'Rating() récupéré'
#   à t/film.t ligne 14.
ok 5 - NumExplodingSheep() récupéré
# Il semble que vous ayez échoué 1 test sur 5

Indiquant que la méthode Film::Rating() est défectueuse.

MISES EN GARDE

Test::Simple ne signale qu'un maximum de 254 échecs dans son code de sortie. Si cela pose problème, vous avez probablement un script de test très volumineux. Divisez-le en plusieurs fichiers. (Vous devriez blâmer les utilisateurs Unix pour avoir utilisé un entier non signé comme code de sortie).

Comme les codes de sortie VMS sont très différents du reste de l'univers, et que Perl fait un mauvais travail avec eux, m'empêchant de faire la différence, cela fonctionne comme suit sur VMS :

0     SS$_NORMAL        tous les tests ont réussi
4     SS$_ABORT         quelque chose s'est mal passé

Cependant, je ne peux pas faire de distinction plus fine.

NOTES

Test::Simple est explicitement testé depuis perl 5.6.0.

Test::Simple est thread-safe dans perl 5.8.1 et supérieur.

HISTORIQUE

Ce module a été conçu lors d'une conversation avec Tony Bowden dans sa cuisine à propos des problèmes qu'ils rencontraient lors de l'écriture d'une fonctionnalité compliquée dans le nouveau module de test. Il a fait remarquer que le problème principal n'était pas de gérer ces cas limites, mais que les gens détestaient écrire des tests du tout. Ce dont on avait besoin, c'était d'un module magique si simple qu'il éliminerait la corvée des tests et serait si facile à apprendre. Paul Johnson a eu cette idée (bien qu'il ne fût pas dans la cuisine de Tony). Voici le résultat.

VOIR AUSSI

Test::More
Plus de fonctions de test ! Une fois que vous aurez dépassé Test::Simple, regardez Test::More. Test::Simple est 100% compatible avec Test::More (c'est-à-dire que vous pouvez utiliser Test::More à la place de Test::Simple dans vos programmes et tout continuera de fonctionner).

Voir également la section SEE_ALSO de Test::More pour plus de modules de test.
