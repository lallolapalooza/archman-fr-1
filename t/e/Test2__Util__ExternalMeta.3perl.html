Test2::Util::ExternalMeta(3perl) Guide du programmeur Perl Test2::Util::ExternalMeta(3perl)

NOM

Test2::Util::ExternalMeta - Permet aux outils tiers d'attacher des métadonnées à vos instances en toute sécurité.

DESCRIPTION

Ce paquet permet de définir un moyen clair et cohérent pour que les outils tiers attachent des métadonnées à vos instances. Si votre objet consomme ce paquet et importe ses méthodes, les métadonnées tierces y trouveront un endroit sûr.

SYNTAXE

package My::Object;
use strict;
use warnings;
use Test2::Util::ExternalMeta qw/meta get_meta set_meta delete_meta/;
...

Pour l'utiliser maintenant :

my $inst = My::Object->new;
$inst->set_meta(foo => 'bar');
my $val = $inst->get_meta('foo');

OÙ LES DONNÉES SONT-ELLES STOCKÉES ?

Ce paquet suppose que vos instances sont des hachages bénis (blessed hashrefs), il ne fonctionnera pas si ce n'est pas le cas. Il stockera toutes les métadonnées sous la clé "_meta" sur le hachage de votre objet. Si votre objet utilise déjà la clé "_meta" dans son hachage sous-jacent, il y a un conflit et vous ne pouvez pas utiliser ce paquet.

EXPORTATIONS

$val = $obj->meta($key)
$val = $obj->meta($key, $default)
Ceci obtiendra la valeur pour une $key de méta spécifiée. Normalement, cela renverra "undef" lorsqu'il n'y a pas de valeur pour la $key, cependant vous pouvez spécifier une valeur $default à définir lorsqu'aucune valeur n'est déjà définie.
$val = $obj->get_meta($key)
Ceci obtiendra la valeur pour une $key de méta spécifiée. Ceci n'a pas le surcoût de $default que possède meta().
$val = $obj->delete_meta($key)
Ceci supprimera la valeur d'une $key de méta spécifiée. L'$val précédent sera retourné.
$obj->set_meta($key, $val)
Définir la valeur d'une $key de méta spécifiée.

RESTRICTIONS SUR LES CLÉS DE MÉTA

Les clés de méta doivent être définies et doivent être vraies lorsqu'elles sont utilisées comme booléen. Les clés ne peuvent pas être des références. Vous êtes libre de stringifier une référence "$ref" pour l'utiliser comme clé, mais ce paquet ne la stringifiera pas pour vous.
