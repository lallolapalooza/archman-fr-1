NOM

Template::Plugin::GD::Polygon - Interface avec la classe Polygon du module GD

SYNTAXE

[% USE poly = GD.Polygon;
   poly.addPt(50,0);
   poly.addPt(99,99);
%]

EXEMPLES

[% FILTER null;
    USE im   = GD.Image(100,100);
    USE c    = GD.Constants;
    # allouer des couleurs
    white = im.colorAllocate(255,255,255);
    black = im.colorAllocate(0,  0,  0);
    red   = im.colorAllocate(255,0,  0);
    blue  = im.colorAllocate(0,  0,255);
    green = im.colorAllocate(0,  255,0);
    # rendre le fond transparent et entrelacé
    im.transparent(white);
    im.interlaced('true');
    # Placer un cadre noir autour de l'image
    im.rectangle(0,0,99,99,black);
    # Dessiner une forme ovale bleue
    im.arc(50,50,95,75,0,360,blue);
    # Et la remplir en rouge
    im.fill(50,50,red);
    # Dessiner un triangle bleu en définissant un polygone
    USE poly = GD.Polygon;
    poly.addPt(50,0);
    poly.addPt(99,99);
    poly.addPt(0,99);
    im.filledPolygon(poly, blue);
    # Sortie de l'image binaire au format PNG
    im.png | stdout(1);
   END;
-%]

DESCRIPTION

Le plugin GD.Polygon fournit une interface à la classe GD::Polygon de GD.pm.

Voir GD pour une description complète de la bibliothèque GD et de toutes les méthodes qui peuvent être appelées via le plugin GD.Polygon. Voir Template::Plugin::GD::Image pour l'interface principale des fonctions GD. Voir Template::Plugin::GD::Constants pour un plugin qui vous donne accès aux constantes de GD.pm.
