NOM

Text::Soundex - Implémentation de l'algorithme soundex.

SYNTAXE

use Text::Soundex;
# Algorithme original.
$code = soundex($name);    # Obtient le code soundex d'un nom.
@codes = soundex(@names);  # Obtient la liste des codes pour une liste de noms.
# Variante américaine de Soundex (NARA) - Utilisée pour les données du recensement américain.
$code = soundex_nara($name);    # Obtient le code soundex d'un nom.
@codes = soundex_nara(@names);  # Obtient la liste des codes pour une liste de noms.
# Redéfinir la valeur que soundex() retournera si la chaîne d'entrée
# ne contient aucun son identifiable.
$Text::Soundex::nocode = 'Z000';

DESCRIPTION

Soundex est un algorithme phonétique pour indexer des noms en fonction de leur prononciation en anglais. L'objectif est que les noms ayant la même prononciation soient encodés dans la même représentation afin qu'ils puissent être mis en correspondance malgré de légères différences d'orthographe. Soundex est le plus connu de tous les algorithmes phonétiques et est souvent utilisé (à tort) comme synonyme d'"algorithme phonétique". Les améliorations apportées à Soundex sont à la base de nombreux algorithmes phonétiques modernes. (Wikipedia, 2007)

Ce module implémente l'algorithme soundex original développé par Robert Russell et Margaret Odell, breveté en 1918 et 1922, ainsi qu'une variante appelée "American Soundex" utilisée pour les données du recensement américain, et actuellement maintenue par les National Archives and Records Administration (NARA).

L'algorithme soundex peut être reconnu dans The Art of Computer Programming de Donald Knuth. L'algorithme décrit par Knuth est l'algorithme NARA.

La valeur retournée pour les chaînes qui n'ont pas d'encodage soundex est définie à l'aide de $Text::Soundex::nocode. La valeur par défaut est "undef", bien que des valeurs telles que 'Z000' soient des alternatives couramment utilisées.

Pour la compatibilité descendante avec les anciennes versions de ce module, $Text::Soundex::nocode est exporté dans l'espace de noms de l'appelant sous le nom de $soundex_nocode.

En contexte scalaire, soundex() retourne le code soundex de son premier argument. En contexte de liste, une liste est retournée dans laquelle chaque élément est le code soundex pour l'argument correspondant passé à soundex(). Par exemple, le code suivant attribue à @codes la valeur "('M200', 'S320')" :

@codes = soundex qw(Mike Stok);

Pour utiliser "Text::Soundex" pour générer des codes qui peuvent être utilisés pour rechercher dans l'un des recensements américains publiquement disponibles, une variante de l'algorithme soundex doit être utilisée :

use Text::Soundex;
$code = soundex_nara($name);

Un exemple de la différence entre ces algorithmes suit :

use Text::Soundex;
print soundex("Ashcraft"), "\n";       # affiche : A226
print soundex_nara("Ashcraft"), "\n";  # affiche : A261

EXEMPLES

Les exemples de Donald Knuth de noms et de leurs codes soundex correspondants sont listés ci-dessous :

Euler, Ellery -> E460
Gauss, Ghosh -> G200
Hilbert, Heilbronn -> H416
Knuth, Kant -> K530
Lloyd, Ladd -> L300
Lukasiewicz, Lissajous -> L222

donc :

$code = soundex 'Knuth';         # $code contient 'K530'
@list = soundex qw(Lloyd Gauss); # @list contient 'L300', 'G200'

LIMITATIONS

Comme l'algorithme soundex a été utilisé il y a longtemps aux États-Unis, il ne prend en compte que l'alphabet et la prononciation anglaises. En particulier, les caractères non ASCII seront ignorés. La méthode recommandée pour traiter les caractères accentués ou autres caractères Unicode est d'utiliser le module Text::Unidecode disponible sur CPAN. Utilisez soit le module explicitement :

use Text::Soundex;
use Text::Unidecode;
print soundex(unidecode("Fran\xE7ais")), "\n"; # Affiche "F652\n"

Soit utilisez la routine enveloppe pratique :

use Text::Soundex 'soundex_unicode';
print soundex_unicode("Fran\xE7ais"), "\n";    # Affiche "F652\n"

Étant donné que l'algorithme soundex mappe un grand espace (chaînes de longueur arbitraire) sur un petit espace (une seule lettre plus 3 chiffres), aucune inférence ne peut être faite sur la similarité de deux chaînes qui aboutissent au même code soundex. Par exemple, "Hilbert" et "Heilbronn" aboutissent tous deux à un code soundex de "H416".

HISTORIQUE

La version 3 est une mise à jour importante pour prendre en charge les versions de Perl postérieures à Perl 5.004. En particulier, la version XS de la sous-routine soundex() comprend les chaînes encodées en UTF-8 (chaînes unicode).

La version 2 de ce module a été réécrite par Mark Mielke ("mark@mielke.cc") pour améliorer la vitesse des sous-routines. La version XS de la sous-routine soundex() a été introduite dans la version 2.00.

La version 1 de ce module a été écrite par Mike Stok ("mike@stok.co.uk") et a été incluse dans le jeu de bibliothèques principales de Perl.

Dave Carlsen ("dcarlsen@csranet.com") a fait la demande pour l'inclusion de l'algorithme NARA. La page soundex NARA peut être consultée à l'adresse : "http://www.archives.gov/research/census/soundex.html"

Ian Phillips ("ian@pipex.net") et Rich Pinder ("rpinder@hsc.usc.edu") ont fourni des idées et repéré des erreurs pour la v1.x.
