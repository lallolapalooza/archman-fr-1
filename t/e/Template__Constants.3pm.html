NOM

Template::Constants - Définit les constantes pour le Template Toolkit

SYNTAXE

use Template::Constants qw( :status :error :all );

DESCRIPTION

Le module "Template::Constants" définit, et exporte optionnellement dans l'espace de noms de l'appelant, un certain nombre de constantes utilisées par le paquet Template.

Les constantes peuvent être utilisées en spécifiant explicitement le paquet "Template::Constants" :

use Template::Constants;
print Template::Constants::STATUS_DECLINED;

Les constantes peuvent être importées dans l'espace de noms de l'appelant en les nommant comme options dans l'instruction "use Template::Constants" :

use Template::Constants qw( STATUS_DECLINED );
print STATUS_DECLINED;

Alternativement, l'un des identificateurs de jeux d'étiquettes suivants peut être spécifié pour importer des ensembles de constantes : '":status"', '":error"', '":all"'.

use Template::Constants qw( :status );
print STATUS_DECLINED;

Consultez la documentation du module "Exporter" pour plus d'informations sur l'exportation de variables.

JEUX D'ÉTIQUETTES EXPORTABLES

Les jeux d'étiquettes et les constantes associées suivants sont définis :

:status
    STATUS_OK             # aucun problème, continuer
    STATUS_RETURN         # fin du bloc courant puis continuer (ok)
    STATUS_STOP           # arrêt contrôlé (ok)
    STATUS_DONE           # l'itérateur est terminé (ok)
    STATUS_DECLINED       # le fournisseur a refusé de traiter la demande (ok)
    STATUS_ERROR          # condition d'erreur générale (pas ok)
:error
    ERROR_RETURN          # retourner un code d'état (par ex. 'stop')
    ERROR_FILE            # erreur de fichier : E/S, analyse, récursion
    ERROR_UNDEF           # valeur de variable indéfinie utilisée
    ERROR_PERL            # erreur dans le bloc [% PERL %]
    ERROR_FILTER          # erreur de filtre
    ERROR_PLUGIN          # erreur de plugin
:chomp                  # pour PRE_CHOMP et POST_CHOMP
    CHOMP_NONE            # ne pas supprimer les espaces blancs
    CHOMP_ONE             # supprimer les espaces blancs jusqu'à la nouvelle ligne
    CHOMP_ALL             # ancien nom pour CHOMP_ONE (obsolète)
    CHOMP_COLLAPSE        # réduire les espaces blancs à un seul espace
    CHOMP_GREEDY          # supprimer tous les espaces blancs, y compris les nouvelles lignes
:debug
    DEBUG_OFF             # ne rien faire
    DEBUG_ON              # indicateur de débogage basique
    DEBUG_UNDEF           # lancer undef en cas de variables indéfinies
    DEBUG_VARS            # débogage général des variables
    DEBUG_DIRS            # débogage des directives
    DEBUG_STASH           # débogage général du stash
    DEBUG_CONTEXT         # débogage du contexte
    DEBUG_PARSER          # débogage de l'analyseur
    DEBUG_PROVIDER        # débogage du fournisseur
    DEBUG_PLUGINS         # débogage des plugins
    DEBUG_FILTERS         # débogage des filtres
    DEBUG_SERVICE         # débogage du contexte
    DEBUG_ALL             # tout
    DEBUG_CALLER          # ajouter les informations de fichier/ligne de l'appelant
    DEBUG_FLAGS           # bitmap utilisé en interne
:all
    Toutes les constantes ci-dessus.
