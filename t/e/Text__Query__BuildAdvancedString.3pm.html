NOM

Text::Query::BuildAdvancedString - Constructeur pour Text::Query::ParseAdvanced afin de construire des expressions régulières

SYNTAXE

use Text::Query;
my $q=new Text::Query('hello and world',
                      -parse => 'Text::Query::ParseAdvanced',
                      -solve => 'Text::Query::SolveAdvancedString',
                      -build => 'Text::Query::BuildAdvancedString');

DESCRIPTION

Construit une expression régulière pour correspondre à la requête avancée analysée par Text::Query::ParseAdvanced. Les mots de la requête peuvent être des expressions régulières et fourniront le résultat attendu si l'option "-regexp" est définie.
