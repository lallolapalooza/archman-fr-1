NOM

Template::Plugin::Datafile - Plugin pour construire des enregistrements à partir d'un fichier de données simple

SYNOPSIS

[% USE mydata = datafile('/chemin/vers/fichier_de_donnees') %]
[% USE mydata = datafile('/chemin/vers/fichier_de_donnees', delim = '|') %]
[% USE mydata = datafile('/chemin/vers/fichier_de_donnees', encoding = 'UTF-8') %]
[% FOREACH record = mydata %]
   [% record.ceci %]  [% record.cela %]
[% END %]

DESCRIPTION

Ce plugin fournit une facilité simple pour construire une liste de références de hachage, dont chacune représente un enregistrement de données de structure connue, à partir d'un fichier de données.

[% USE datafile(filename) %]

Un nom de fichier absolu doit être spécifié (pour cette implémentation initiale au moins - dans une version future, il pourrait également utiliser le "INCLUDE_PATH"). Un paramètre optionnel "delim" peut également être fourni pour spécifier un caractère délimiteur alternatif. Le paramètre optionnel "encoding" peut être utilisé pour spécifier l'encodage du fichier d'entrée.

[% USE userlist = datafile('/chemin/vers/fichier/utilisateurs')     %]
[% USE things   = datafile('items', delim = '|') %]

Le format du fichier est intentionnellement simple. La première ligne définit les noms des champs, délimités par des deux-points avec des espaces blancs facultatifs autour. Les lignes suivantes définissent ensuite des enregistrements contenant des éléments de données, également délimités par des deux-points. par exemple.

id : nom : email : tel
abw : Andy Wardley : abw@tt2.org : 555-1234
sam : Simon Matthews : sam@tt2.org : 555-9876

Chaque ligne est lue, divisée en champs composites, puis utilisée pour initialiser un tableau de hachage contenant les noms des champs comme clés pertinentes. Le plugin renvoie une référence de liste bénie contenant les références de hachage dans l'ordre défini dans le fichier.

[% FOREACH user = userlist %]
   [% user.id %]: [% user.name %]
[% END %]

La première ligne du fichier doit contenir les définitions de champs. Après la première ligne, les lignes vides seront ignorées, ainsi que les lignes de commentaire qui commencent par un '"#"'.

BOGUES

Devrait gérer les noms de fichiers relatifs à "INCLUDE_PATH". Ne permet pas l'utilisation de '":"' dans un champ. Un mécanisme d'échappement est requis.
