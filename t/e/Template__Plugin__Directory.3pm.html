Paquet: perl-template-toolkit

Licences: PerlArtistic

Template::Plugin::Directory(3) Documentation Perl fournie par l'utilisateur Template::Plugin::Directory(3)

NOM

Template::Plugin::Directory - Plugin pour générer des listes de répertoires

SYNOPIS

[% USE dir = Directory(dirpath) %]
# files renvoie la liste des fichiers réguliers
[% FOREACH file = dir.files %]
   [% file.name %] [% file.path %] ...
[% END %]
# dirs renvoie la liste des sous-répertoires
[% FOREACH subdir = dir.dirs %]
   [% subdir.name %] [% subdir.path %] ...
[% END %]
# list renvoie les deux entrelacés dans l'ordre
[% FOREACH item = dir.list %]
   [% IF item.isdir %]
      Répertoire : [% item.name %]
   [% ELSE %]
      Fichier : [% item.name %]
   [% END %]
[% END %]
# définir une VUE pour afficher les répertoires/fichiers
[% VIEW myview %]
   [% BLOCK file %]
   Fichier : [% item.name %]
   [% END %]
   [% BLOCK directory %]
   Répertoire : [% item.name %]
   [% item.content(myview) | indent -%]
   [% END %]
[% END %]
# afficher le contenu du répertoire en utilisant la vue
[% myview.print(dir) %]

DESCRIPTION

Ce plugin Template Toolkit fournit une interface simple pour les listes de répertoires. Il est dérivé du module Template::Plugin::File et utilise des instances d'objets Template::Plugin::File pour représenter les fichiers dans un répertoire. Les sous-répertoires dans un répertoire sont représentés par d'autres instances de "Template::Plugin::Directory".

Le constructeur attend un nom de répertoire comme argument.

[% USE dir = Directory('/tmp') %]

Il fournit ensuite l'accès aux fichiers et sous-répertoires contenus dans le répertoire.

# fichiers réguliers (pas des répertoires)
[% FOREACH file IN dir.files %]
   [% file.name %]
[% END %]
# répertoires seulement
[% FOREACH file IN dir.dirs %]
   [% file.name %]
[% END %]
# fichiers et/ou répertoires
[% FOREACH file IN dir.list %]
   [% file.name %] ([% file.isdir ? 'répertoire' : 'fichier' %])
[% END %]

Le constructeur du plugin lèvera une erreur "Directory" si le chemin spécifié n'existe pas, n'est pas un répertoire ou échoue à stat() (voir Template::Plugin::File). Sinon, il analysera le répertoire et créera des listes nommées '"files"' contenant les fichiers, '"dirs"' contenant les répertoires et '"list"' contenant les deux combinés. L'option "nostat" peut être définie pour désactiver toutes les vérifications de fichiers/répertoires et l'analyse du répertoire.

Chaque fichier dans le répertoire sera représenté par une instance d'objet Template::Plugin::File, et chaque répertoire par un autre "Template::Plugin::Directory". Si le drapeau "recurse" est défini, alors ces répertoires conteniront d'autres entrées imbriquées, et ainsi de suite. Avec le drapeau "recurse" non défini, comme c'est le cas par défaut, alors chacun est juste un marqueur de position pour le répertoire et ne contient aucun contenu supplémentaire à moins que sa méthode scan() ne soit explicitement appelée. Le drapeau "isdir" peut être testé par rapport aux fichiers et/ou répertoires, retournant vrai si l'élément est un répertoire ou faux s'il s'agit d'un fichier régulier.

[% FOREACH file = dir.list %]
   [% IF file.isdir %]
      * Répertoire : [% file.name %]
   [% ELSE %]
      * Fichier : [% file.name %]
   [% END %]
[% END %]

Cet exemple montre comment parcourir une arborescence de répertoires, affichant le contenu au fur et à mesure. Avec le drapeau de récursivité désactivé, comme c'est le cas par défaut, nous devons appeler explicitement la méthode scan() sur chaque répertoire, pour le forcer à rechercher les fichiers et les sous-répertoires supplémentaires qu'il contient.

[% USE dir = Directory(dirpath) %]
* [% dir.path %]
[% INCLUDE showdir %]
[% BLOCK showdir -%]
  [% FOREACH file = dir.list -%]
    [% IF file.isdir -%]
    * [% file.name %]
      [% file.scan -%]
      [% INCLUDE showdir dir=file FILTER indent(4) -%]
    [% ELSE -%]
    - [% f.name %]
    [% END -%]
  [% END -%]
 [% END %]

Cet exemple est adapté (avec quelques reformations pour plus de clarté) d'un test dans t/directry.t qui produit la sortie suivante :

* test/dir
    - file1
    - file2
    * sub_one
        - bar
        - foo
    * sub_two
        - waz.html
        - wiz.html
    - xyzfile

Le drapeau "recurse" peut être défini (désactivé par défaut) pour que le constructeur récursive automatiquement dans tous les sous-répertoires, créant un nouvel objet "Template::Plugin::Directory" pour chacun et le remplissant avec tout contenu supplémentaire. Dans ce cas, il n'est pas nécessaire d'appeler explicitement la méthode scan().

[% USE dir = Directory(dirpath, recurse=1) %]
   ...
    [% IF file.isdir -%]
    * [% file.name %]
      [% INCLUDE showdir dir=file FILTER indent(4) -%]
    [% ELSE -%]
       ...

Le plugin de répertoire fournit également une prise en charge des vues. Une vue peut être définie comme un bloc "VIEW ... END" et doit contenir des définitions de "BLOCK" pour les fichiers ('"file"') et les répertoires ('"directory"').

[% VIEW myview %]
[% BLOCK file %]
   - [% item.name %]
[% END %]
[% BLOCK directory %]
   * [% item.name %]
     [% item.content(myview) FILTER indent %]
[% END %]
[% END %]

La méthode print() de la vue peut ensuite être appelée, en passant l'objet "Directory" comme argument.

[% USE dir = Directory(dirpath, recurse=1) %]
[% myview.print(dir) %]

Lorsqu'un répertoire est présenté à une vue, que ce soit via "[% myview.print(dir) %]" ou "[% dir.present(view) %]", le bloc "directory" dans la vue "myview" est traité. La variable "item" sera définie pour aliaser l'objet "Directory".

[% BLOCK directory %]
   * [% item.name %]
     [% item.content(myview) FILTER indent %]
[% END %]

Dans cet exemple, le nom du répertoire est d'abord affiché et la méthode content(view) est ensuite appelée pour présenter chaque élément du répertoire à la vue. Les répertoires supplémentaires seront mappés au bloc "directory", et les fichiers seront mappés au bloc "file".

Avec l'option de récursivité désactivée, comme c'est le cas par défaut, le bloc "directory" doit explicitement appeler un scan() sur chaque répertoire.

[% VIEW myview %]
[% BLOCK file %]
   - [% item.name %]
[% END %]
[% BLOCK directory %]
   * [% item.name %]
     [% item.scan %]
     [% item.content(myview) FILTER indent %]
[% END %]
[% END %]
[% USE dir = Directory(dirpath) %]
[% myview.print(dir) %]
