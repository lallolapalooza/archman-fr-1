NOM

Template::Plugin::GD::Text::Align - Dessine des chaînes alignées dans des images GD

SYNOPIS

[% USE align = GD.Text.Align(gd_image); %]

EXEMPLES

[% FILTER null;
    USE im  = GD.Image(100,100);
    USE gdc = GD.Constants;
    # allouer quelques couleurs
    black = im.colorAllocate(0,   0, 0);
    red   = im.colorAllocate(255,0,  0);
    blue  = im.colorAllocate(0,  0,  255);
    # Dessiner un ovale bleu
    im.arc(50,50,95,75,0,360,blue);
    USE a = GD.Text.Align(im);
    a.set_font(gdc.gdLargeFont);
    a.set_text("Bonjour");
    a.set(colour => red, halign => "center");
    a.draw(50,70,0);
    # Afficher l'image au format PNG
    im.png | stdout(1);
   END;
-%]

DESCRIPTION

Le plugin GD.Text.Align fournit une interface au module GD::Text::Align. Il permet de dessiner du texte dans des images GD avec divers alignements et orientations.

Voir GD::Text::Align pour plus de détails. Voir Template::Plugin::GD::Text::Wrap pour un plugin qui permet de rendre du texte en retour à la ligne dans des images GD.
