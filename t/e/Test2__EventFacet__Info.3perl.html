Test2::EventFacet::Info(3perl) Guide du programmeur Perl Test2::EventFacet::Info(3perl)

NOM

Test2::EventFacet::Info - Facette d'informations dont un développeur peut se soucier.

DESCRIPTION

Cette facette représente des messages destinés aux humains qui les aideront soit à comprendre un résultat, soit à diagnostiquer une défaillance.

NOTES

Cette facette apparaît dans une liste au lieu d'être un élément unique.

CHAMPS

$string_or_structure = $info->{details}
$string_or_structure = $info->details()
Chaîne de caractères lisible par l'homme ou structure de données, il s'agit des informations à afficher. Les formateurs sont libres de rendre les structures comme bon leur semble. Cela peut contenir un objet béni.

Si l'attribut "table" (voir ci-dessous) est défini, un moteur de rendu peut choisir d'afficher le tableau au lieu des détails.

$structure = $info->{table}
$structure = $info->table()
Si les données que la facette "info" doit transmettre peuvent être représentées sous forme de tableau, les données peuvent être placées dans cet attribut sous une forme plus brute pour un meilleur affichage. Les données doivent également être représentées dans l'attribut "details" pour les moteurs de rendu qui ne prennent pas en charge le rendu direct des tableaux.

La structure du tableau :

my %table = {
    header => [ 'en-tête colonne 1', 'en-tête colonne 2', ... ], # Optionnel
    rows => [
        ['colonne 1 ligne 1', 'colonne 2 ligne 1', ... ],
        ['colonne 1 ligne 2', 'colonne 2 ligne 2', ... ],
        ...
    ],
    # Permet au moteur de rendu de masquer les colonnes vides si vrai, Optionnel
    collapse => $BOOL,
    # Liste par nom ou numéro des colonnes qui ne doivent jamais être masquées
    no_collapse => \@LIST,
}
$short_string = $info->{tag}
$short_string = $info->tag()
Balise courte pour catégoriser l'information. Elle est généralement de 10 caractères ou moins, les formateurs peuvent tronquer les balises plus longues.
$bool = $info->{debug}
$bool = $info->debug()
Définissez cette valeur sur vrai si le message est critique, ou explique une défaillance. Il s'agit d'informations qui devraient être affichées par les formateurs, même dans des modes moins verbeux.

Lorsqu'il est faux, l'information n'est pas considérée comme critique et peut ne pas être rendue dans des modes moins verbeux.

$bool = $info->{important}
$bool = $info->important
Ceci doit être défini pour les messages non de débogage qui sont néanmoins suffisamment importants pour être affichés lorsqu'un formateur est en mode silencieux. Un formateur devrait envoyer ceux-ci à STDOUT et non à STDERR, mais devrait les afficher même en mode non verbeux.
