NOM

Template::Plugin::GD::Graph::bars3d - Créer des graphiques à barres 3D avec axes et légendes

SYNTAXE

[% USE g = GD.Graph.bars3d(x_size, y_size); %]

EXEMPLES

[% FILTER null;
    data = [
        ["Jan", "Fev", "Mar", "Avr", "Mai", "Juin", "Juil", "Août",
                                     "Sep", "Oct", "Nov", "Dec", ],
        [-5, -4, -3, -3, -1,  0,  2,  1,  3,  4,  6,  7],
        [4,   3,  5,  6,  3,1.5, -1, -3, -4, -6, -7, -8],
        [1,   2,  2,  3,  4,  3,  1, -1,  0,  2,  3,  2],
    ];

    USE my_graph = GD.Graph.bars3d();

    my_graph.set( 
            x_label => 'Mois',
            y_label => 'Mesure de succès',
            title => 'Un graphique à barres 3D',
            y_max_value => 8,
            y_min_value => -8,
            y_tick_number => 16,
            y_label_skip => 2,
            box_axis => 0,
            line_width => 3,
            zero_axis_only => 1,
            x_label_position => 1,  
            y_label_position => 1,  

            x_label_skip => 3,
            x_tick_offset => 2,

            transparent => 0,
    );      
    my_graph.set_legend("Nous", "Eux", "Autres");
    my_graph.plot(data).png | stdout(1);
   END;
-%]

DESCRIPTION

Le plugin GD.Graph.bars3d fournit une interface à la classe GD::Graph::bars3d définie par le module GD::Graph3d. Il permet de tracer un ou plusieurs ensembles de données (x,y) sous forme de barres y en fonction de x avec une apparence tridimensionnelle, accompagnées d'axes et de légendes.

Voir GD::Graph3d pour plus de détails.
