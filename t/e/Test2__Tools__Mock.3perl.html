Test2::Tools::Mock(3perl) Guide de référence des programmeurs Perl Test2::Tools::Mock(3perl)

NOM

Test2::Tools::Mock - Mocking de classes/instances pour Test2.

DESCRIPTION

Le mocking est souvent essentiel pour les tests. Cette bibliothèque couvre certains des besoins les plus courants en matière de mocking. Ce plugin est fortement influencé par Mock::Quick, mais avec une API améliorée. Ce plugin est également conçu pour bien fonctionner avec d'autres plugins d'une manière que Mock::Quick ne pourrait pas.

SYNOPIS

my $mock = mock 'Some::Class' => (
    track => $BOOL, # Activer/Désactiver le suivi sur les subs définies ci-dessous
    add => [
        new_method => sub { ... },
    ],
    override => [
        replace_method => sub { ... },
    ],
    set => [
        replace_or_inject => sub { ... },
    ],
    track => $bool, # Activer/désactiver le suivi à nouveau pour affecter les mocks créés après ce point
    ..., # Les clés d'arguments peuvent être répétées
);
Some::Class->new_method();        # Appelle la méthode nouvellement injectée
Some::Class->replace_method();    # Appelle notre méthode de remplacement.
$mock->override(...) # Remplace quelques méthodes supplémentaires
$mock = undef; # Annule tout le mocking, restaurant toutes les méthodes originales.
my $simple_mock = mock {} => (
    add => [
        is_active => sub { ... }
    ]
);
$simple_mock->is_active();        # Appelle notre méthode nouvellement mockée.

EXPORTATIONS

PAR DÉFAUT

mock
C'est une fonction tout-en-un qui délègue à l'une des autres méthodes en fonction de la façon dont elle est utilisée. Si vous n'êtes pas à l'aise avec une fonction qui a beaucoup de comportements potentiels, vous pouvez utiliser directement l'une des autres fonctions.
@mocks = mocked($objet)
@mocks = mocked($classe)
Vérifie si un objet ou une classe est mocké. S'il est mocké, les objets $mock (Test2::Mock) seront retournés.
$mock = mock $classe => ( ... );
$mock = mock $instance => ( ... )
$mock = mock 'classe', $classe => ( ... )
Ces formes délèguent à mock_class() pour mocker un paquet. La troisième forme permet d'être explicite sur le type de mocking que vous souhaitez.
$obj = mock()
$obj = mock { ... }
$obj = mock 'obj', ...;
Ces formes délèguent à mock_obj() pour créer des instances de paquets anonymes où les méthodes sont vivifiées au besoin.
mock $mock => sub { ... }
mock $method => ( ... )
Ces formes vont ensemble, la première forme définira $mock comme le build de mock actuel, puis exécutera le sub. Dans le sub, vous pouvez déclarer des spécifications de mock en utilisant la seconde forme. La première forme délègue à mock_build().

La seconde forme appelle la méthode spécifiée sur le build actuel. Cette seconde forme délègue à mock_do().

SUR DEMANDE

DÉFINITION DES MOCKS

$obj = mock_obj( ... )
$obj = mock_obj { ... } => ( ... )
$obj = mock_obj sub { ... }
$obj = mock_obj { ... } => sub { ... }
Cette méthode vous permet de générer rapidement un objet béni. L'objet sera une instance d'un nom de paquet généré aléatoirement. Les méthodes seront vivifiées en tant qu'accesseurs en lecture/écriture au besoin.

Les arguments peuvent être n'importe quelle méthode disponible pour Test2::Mock suivie d'un argument. Si le tout premier argument est un hashref, il sera béni en tant que votre nouvel objet.

Si vous fournissez un coderef au lieu de paires clé/valeur, le coderef sera exécuté pour construire le mock. (Voir la section "CONSTRUCTION DES MOCKS").

$mock = mock_class $class => ( ... )
$mock = mock_class $instance => ( ... )
$mock = mock_class ... => sub { ... }
Cela créera une nouvelle instance de Test2::Mock pour contrôler le paquet spécifié. Si vous lui donnez une référence bénie, il utilisera la classe de l'instance.

Les arguments peuvent être n'importe quelle méthode disponible pour Test2::Mock suivie d'un argument. Si le tout premier argument est un hashref, il sera béni en tant que votre nouvel objet.

Si vous fournissez un coderef au lieu de paires clé/valeur, le coderef sera exécuté pour construire le mock. (Voir la section "CONSTRUCTION DES MOCKS").

CONSTRUCTION DES MOCKS

mock_build $mock => sub { ... }
Définit $mock comme le build actuel, puis exécute le code spécifié. $mock ne sera plus le build actuel une fois le sub terminé.
$mock = mock_building()
Récupère l'objet $mock actuellement en cours de construction.
mock_do $method => $args
Exécute la méthode spécifiée sur l'objet actuellement en cours de construction.

GÉNÉRATEURS DE MÉTHODES

$sub = mock_accessor $field
Génère un accesseur en lecture/écriture pour le champ spécifié. Cela générera un sub comme suit : 
$sub = sub {
    my $self = shift;
    ($self->{$field}) = @_ if @_;
    return $self->{$field};
};
$sub = mock_getter $field
Génère un accesseur en lecture seule pour le champ spécifié. Cela générera un sub comme suit : 
$sub = sub {
    my $self = shift;
    return $self->{$field};
};
$sub = mock_setter $field
Génère un accesseur en écriture pour le champ spécifié. Cela générera un sub comme suit : 
$sub = sub {
    my $self = shift;
    ($self->{$field}) = @_;
};
%pairs = mock_accessors(qw/nom1 nom2 nom3/)
Génère plusieurs accesseurs en lecture/écriture à la fois, retourne des paires clé/valeur où la clé est le nom du champ et la valeur est le coderef.
%pairs = mock_getters(qw/nom1 nom2 nom3/)
Génère plusieurs accesseurs en lecture seule à la fois, retourne des paires clé/valeur où la clé est le nom du champ et la valeur est le coderef.
%pairs = mock_setters(qw/nom1 nom2 nom3/)
Génère plusieurs accesseurs en écriture à la fois, retourne des paires clé/valeur où la clé est le nom du champ et la valeur est le coderef.

my $mock = mock(...);
