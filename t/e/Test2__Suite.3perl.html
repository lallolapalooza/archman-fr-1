Test2::Suite(3perl) Manuel des programmeurs Perl Test2::Suite(3perl)

NOM

Test2::Suite - Une distribution contenant une grande variété d'outils construits sur le framework de test de Perl.

DESCRIPTION

Une grande variété d'outils, plugins, bundles, etc., construits sur le framework de test de Perl. Si vous êtes intéressé par l'écriture de tests, c'est la distribution qu'il vous faut.

Qu'est-ce que les outils, les plugins et les bundles ?

OUTILS
Les outils sont des paquets qui exportent des fonctions à utiliser dans les fichiers de test. Ces fonctions génèrent généralement des événements. Les outils ne devraient PAS altérer le comportement d'autres outils ou du système en général.
PLUGINS
Les plugins sont des paquets qui produisent des effets ou altèrent le comportement d'autres outils. Un exemple serait un plugin qui fait sauter le test après le premier échec. Les plugins ne devraient PAS exporter quoi que ce soit.
BUNDLES
Les bundles sont des collections d'outils et de plugins. Un bundle doit charger et re-exporter des fonctions depuis des paquets d'outils. Un bundle peut également charger et configurer n'importe quel nombre de plugins.

Si vous voulez écrire quelque chose qui exporte de nouvelles fonctions et affecte le comportement, vous devriez écrire une distribution d'outils, une distribution de plugins, et un bundle qui charge les deux. Ceci est important car cela aide à éviter le problème où un paquet exporte les outils désirés, mais produit également des effets non désirés.

BUNDLES INCLUS

Test2::V0
Ceux-ci ne vivent pas dans l'espace de noms des bundles car ce sont les principales façons d'utiliser Test2::Suite.

La dernière version actuelle est Test2::V0.

use Test2::V0;
# strict et warnings sont maintenant actifs pour vous.
ok(...);
# Note: is fait une vérification approfondie, différente de ce que fait 'is' dans Test::More.
is(...);
...
done_testing;

Ce bundle inclut tous les outils listés dans les "OUTILS INCLUS" suivants, à l'exception de Test2::Tools::ClassicCompare. Ce bundle fournit presque tout ce dont vous avez besoin lorsque vous écrivez des tests. C'est également la distribution préférée de l'auteur de Test2.

Voir Test2::V0 pour une documentation complète.

use Test2::Bundle::Extended;

ok(...);

Ce bundle inclut tous les outils listés dans les "OUTILS INCLUS" suivants, à l'exception de Test2::Tools::ClassicCompare. Ce bundle fournit presque tout ce dont vous avez besoin lorsque vous écrivez des tests. C'est également la distribution préférée de l'auteur de Test2.

Voir Test2::Bundle::Extended pour une documentation complète.

More
use Test2::Bundle::More;
use strict;
use warnings;
plan 3; # Ou vous pouvez utiliser done_testing à la fin
ok(...);
is(...); # Note: comparaison de chaînes
is_deeply(...);
...
done_testing; # Utiliser à la place de plan

Ce bundle est conçu pour être une substitution presque immédiate de Test::More. Il y a quelques différences notables auxquelles vous devriez faire attention. Certaines exportations sont manquantes : "eq_array", "eq_hash", "eq_set", $TODO, "explain", "use_ok", "require_ok". De plus, il n'est plus possible de définir le plan à l'importation : "use .. tests => 5". $TODO a été remplacé par la fonction todo(). La planification se fait en utilisant "plan", "skip_all", ou "done_testing".

Voir Test2::Bundle::More pour une documentation complète.

Simple
use Test2::Bundle::Simple;
use strict;
use warnings;
plan 1;
ok(...);

Ce bundle est conçu pour être une substitution presque immédiate de Test::Simple. Voir Test2::Bundle::Simple pour une documentation complète.

OUTILS INCLUS

Basic
Basic fournit presque tous les outils trouvés précédemment dans Test::More. Cependant, il n'exporte aucun outil utilisé pour la comparaison. Les fonctions de base "pass", "fail", "ok" sont présentes, ainsi que des fonctions pour la planification.

Voir Test2::Tools::Basic pour une documentation complète.

Compare
Ceci fournit "is", "like", "isnt", "unlike", et plusieurs aides supplémentaires. Note : Ce sont tous des comparateurs approfondis et ils fonctionnent comme une combinaison de "is" de Test::More et "is_deeply".

Voir Test2::Tools::Compare pour une documentation complète.

ClassicCompare
Ceci fournit les "is", "like", "isnt", "unlike", et "is_deeply" de Test::More. Il fournit également "cmp_ok".

Voir Test2::Tools::ClassicCompare pour une documentation complète.

Class
Ceci fournit des fonctions pour tester des objets et des classes, comme "isa_ok".

Voir Test2::Tools::Class pour une documentation complète.

Defer
Ceci fournit des fonctions pour écrire des fonctions de test à un endroit, mais les exécuter plus tard. C'est utile pour tester des choses qui s'exécutent dans un état modifié.

Voir Test2::Tools::Defer pour une documentation complète.

Encoding
Ceci exporte une seule fonction qui peut être utilisée pour changer l'encodage de tous vos résultats de test.

Voir Test2::Tools::Encoding pour une documentation complète.

Exports
Ceci fournit des outils pour vérifier les exportations. Vous pouvez vérifier que des fonctions ont été importées, ou qu'elles n'ont pas été importées.

Voir Test2::Tools::Exports pour une documentation complète.

Mock
Ceci fournit des outils pour mocker des objets et des classes. Ceci est basé sur Mock::Quick, mais plusieurs améliorations d'interface ont été ajoutées qui ne peuvent pas être ajoutées à Mock::Quick sans casser la compatibilité ascendante.

Voir Test2::Tools::Mock pour une documentation complète.

Ref
Ceci exporte des outils pour valider et comparer des références.

Voir Test2::Tools::Ref pour une documentation complète.

Spec
Ceci est une implémentation de RSPEC avec prise en charge de la concurrence.

Voir Test2::Tools::Spec pour plus de détails.

Subtest
Ceci exporte des outils pour exécuter des sous-tests.

Voir Test2::Tools::Subtest pour une documentation complète.

Target
Ceci vous permet de charger les paquets que vous souhaitez tester, et de les aliaser en constantes/variables de paquet.

Voir Test2::Tools::Target pour une documentation complète.

Test2::Suite(3pm)

NAME

Test2::Suite - The Test2 Testing Framework

DESCRIPTION

Test2 is a test framework designed to be used by all perl projects. It is designed to be the last test framework you will ever need.

This distribution is the main driver for the Test2 framework. It includes the basic test tools, and provides a way to include other plugins and requirement checkers.

INCLUDED BUNDLES

Test2::Bundle::Classic
This is the classic bundle. It includes many of the plugins that are considered standard for most testing. This includes the bail out, summary, and utf8 plugins.

INCLUDED TOOLS

Test2::API
The core API for Test2. This is what most plugins and tools will use to interface with the testing framework.
Test2::Tester
The main tool for running tests. This is what your test files will typically use to construct tests.
Test2::Harness
This is the command line tool for running your tests. It discovers test files and runs them using Test2::Tester.

INCLUDED PLUGINS

BailOnFail
The "bail out on first failure" plugin. When this plugin is loaded, any failure will cause the test to bail out immediately.

See Test2::Plugin::BailOnFail for complete documentation.

DieOnFail
The much requested "die on first failure" plugin. When this plugin is loaded, any failure will cause the test to die immediately.

See Test2::Plugin::DieOnFail for complete documentation.

ExitSummary
This plugin gives you statistics and diagnostics at the end of your test in the event of a failure.

See Test2::Plugin::ExitSummary for complete documentation.

SRand
Use this to set the random seed to a specific seed, or to the current date.

See Test2::Plugin::SRand for complete documentation.

UTF8
Turn on utf8 for your testing. This sets the current file to be utf8, it also sets STDERR, STDOUT, and your formatter to all output utf8.

See Test2::Plugin::UTF8 for complete documentation.

INCLUDED REQUIREMENT CHECKERS

AuthorTesting
Using this package will cause the test file to be skipped unless the AUTHOR_TESTING environment variable is set.

See Test2::Require::AuthorTesting for complete documentation.

EnvVar
Using this package will cause the test file to be skipped unless a custom environment variable is set.

See Test2::Require::EnvVar for complete documentation.

Fork
Using this package will cause the test file to be skipped unless the system is capable of forking (including emulated forking).

See Test2::Require::Fork for complete documentation.

RealFork
Using this package will cause the test file to be skipped unless the system is capable of true forking.

See Test2::Require::RealFork for complete documentation.

Module
Using this package will cause the test file to be skipped unless the specified module is installed (and optionally at a minimum version).

See Test2::Require::Module for complete documentation.

Perl
Using this package will cause the test file to be skipped unless the specified minimum perl version is met.

See Test2::Require::Perl for complete documentation.

Threads
Using this package will cause the test file to be skipped unless the system has threading enabled.

Note: This will not turn threading on for you.

See Test2::Require::Threads for complete documentation.

SEE ALSO

See the Test2 documentation for a namespace map. Everything in this distribution uses Test2.
