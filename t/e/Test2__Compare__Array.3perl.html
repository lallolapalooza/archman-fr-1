Test2::Compare::Array(3perl) Guide du programmeur Perl Test2::Compare::Array(3perl)

NOM

Test2::Compare::Array - Représentation interne d'une comparaison de tableau.

DESCRIPTION

Ce module est une représentation interne d'un tableau à des fins de comparaison.

MÉTHODES

$ref = $arr->inref()
Si l'instance a été construite à partir d'un tableau réel, cela retournera la référence de ce tableau.
$bool = $arr->ending
$arr->set_ending($bool)
Définissez ceci sur vrai si vous souhaitez échouer lorsque le tableau validé a plus d'éléments que la vérification. C'est-à-dire, si vous vérifiez les index 0-3 mais que le tableau a des valeurs pour les index 0-4, cela échouera et listera le dernier élément du tableau comme inattendu. Si défini sur faux, il est supposé que vous ne vous souciez pas des éléments supplémentaires.
$hashref = $arr->items()
Retourne le hashref des paires "clé => valeur" à vérifier dans le tableau.
$arr->set_items($hashref)
Accepte un hashref pour permettre de sauter des index si désiré.

Note : il n'y a pas de validation lors de l'utilisation de "set_items", il est préférable d'utiliser l'interface "add_item".

$arrayref = $arr->order()
Retourne un arrayref de tous les index qui seront vérifiés, dans l'ordre.
$arr->set_order($arrayref)
Définit l'ordre dans lequel les index seront vérifiés.

Note : il n'y a pas de validation lors de l'utilisation de "set_order", il est préférable d'utiliser l'interface "add_item".

$name = $arr->name()
Retourne toujours la chaîne "<ARRAY>".
$bool = $arr->verify(got => $got, exists => $bool)
Vérifie si $got est une référence de tableau ou non.
$idx = $arr->top_index()
Retourne l'index le plus élevé qui est vérifié. Cela retournera undef s'il n'y a pas d'éléments, ou 0 s'il n'y a qu'un seul élément.
$arr->add_item($item)
Ajoute un élément à la liste des valeurs à vérifier.
$arr->add_item($idx => $item)
Ajoute un élément à la liste des valeurs à vérifier à l'index spécifié.
$arr->add_filter(sub { ... })
Ajoute un sous-programme de filtre. Le filtre reçoit toutes les valeurs restantes du tableau en cours de vérification et doit retourner les valeurs qui doivent encore être vérifiées. Le filtre sera exécuté entre le dernier élément ajouté et le prochain élément ajouté.
@deltas = $arr->deltas(got => $got, convert => \&convert, seen => \%seen)
Trouve les différences entre les valeurs attendues du tableau et celles du tableau de référence $got.
