NOM

Template::Plugin::String - Interface orientée objet pour la manipulation de chaînes

SYNOPIS

# créer des objets String via la directive USE
[% USE String %]
[% USE String 'texte initial' %]
[% USE String text => 'texte initial' %]
# ou depuis une String existante via new()
[% newstring = String.new %]
[% newstring = String.new('nouveau texte') %]
[% newstring = String.new( text => 'nouveau texte' ) %]
# ou depuis une String existante via copy()
[% newstring = String.copy %]
# ajouter du texte à la chaîne
[% String.append('texte à ajouter') %]
# formater à gauche, à droite ou centré, avec remplissage
[% String.left(20) %]
[% String.right(20) %]
[% String.center(20) %]   # orthographe américaine
[% String.centre(20) %]   # orthographe européenne
# et diverses autres méthodes...

DESCRIPTION

Ce module implémente une classe "String" pour effectuer des opérations sur le texte de manière orientée objet.

Vous pouvez créer un objet "String" via la directive "USE", en ajoutant toute valeur de texte initiale comme argument ou comme paramètre nommé "text".

[% USE String %]
[% USE String 'texte initial' %]
[% USE String text='texte initial' %]

L'objet créé sera référencé comme "String" par défaut, mais vous pouvez fournir un nom de variable différent pour que l'objet y soit assigné :

[% USE greeting = String 'Hello World' %]

Une fois que vous avez un objet "String", vous pouvez l'utiliser comme prototype pour créer d'autres objets "String" avec la méthode new().

[% USE String %]
[% greeting = String.new('Hello World') %]

La méthode new() accepte également une chaîne de texte initiale comme argument ou le paramètre nommé "text".

[% greeting = String.new( text => 'Hello World' ) %]

Vous pouvez également appeler copy() pour créer une nouvelle "String" comme copie de l'originale.

[% greet2 = greeting.copy %]

L'objet "String" possède une méthode text() pour retourner le contenu de la chaîne.

[% greeting.text %]

Cependant, il suffit d'imprimer la chaîne et de laisser l'opérateur de stringification surchargé appeler automatiquement la méthode text() pour vous.

[% greeting %]

Ainsi, vous pouvez traiter les objets "String" pratiquement comme n'importe quel morceau de texte normal, en les interpolant dans d'autres chaînes, par exemple :

[% msg = "Il a imprimé '$greeting' puis a dumpé le noyau\n" %]

Vous bénéficiez également de nombreuses autres méthodes pour manipuler la chaîne.

[% msg.append("PS Ne mangez pas la neige jaune") %]

Notez que toutes les méthodes opèrent sur la chaîne elle-même et en modifient le contenu. Si vous souhaitez opérer sur une copie de la chaîne, il suffit d'en prendre une copie d'abord :

[% msg.copy.append("PS Ne mangez pas la neige jaune") %]

Ces méthodes retournent une référence à l'objet "String" lui-même. Cela vous permet de chaîner plusieurs méthodes.

[% msg.copy.append('foo').right(72) %]

Cela signifie également que dans les exemples ci-dessus, la "String" est retournée, ce qui provoque l'appel de la méthode text(), résultant en l'impression de la nouvelle valeur de la chaîne. Pour supprimer l'impression de la chaîne, vous pouvez utiliser la directive "CALL".

[% foo = String.new('foo') %]
[% foo.append('bar') %]         # imprime "foobar"
[% CALL foo.append('bar') %]    # rien

MÉTHODES CONSTRUCTEURS

Ces méthodes sont utilisées pour créer de nouveaux objets "String".

new()

Crée une nouvelle chaîne en utilisant une valeur initiale passée comme argument positionnel ou comme paramètre nommé "text".

[% USE String %]
[% msg = String.new('Hello World') %]
[% msg = String.new( text => 'Hello World' ) %]

copy()

Crée un nouvel objet "String" qui contient une copie de la chaîne d'origine.

[% msg2 = msg.copy %]

MÉTHODES D'INSPECTION

Ces méthodes sont utilisées pour examiner la chaîne.

text()

Retourne la valeur interne de la chaîne. L'opérateur de stringification est surchargé pour appeler cette méthode. Ainsi, les instructions suivantes sont équivalentes :

[% msg.text %]
[% msg %]

length()

Retourne la longueur de la chaîne.

[% USE String("foo") %]
[% String.length %]   # => 3

search($pattern)

Recherche dans la chaîne l'expression régulière spécifiée par $pattern, retournant vrai si trouvée ou faux sinon.

[% item = String.new('foo bar baz wiz waz woz') %]
[% item.search('wiz') ? 'WIZZY! :-)' : 'pas wizzy :-(' %]

split($pattern, $limit)

Divise la chaîne en fonction du délimiteur $pattern et du $limit optionnel. Délègue à la fonction interne split() de Perl, donc les paramètres sont exactement les mêmes.

[% FOREACH item.split %]
     ...
[% END %]
[% FOREACH item.split('baz|waz') %]
     ...
[% END %]

MÉTHODES MUTATRICES

Ces méthodes modifient la valeur interne de la chaîne. Par exemple :

[% USE str=String('foobar') %]
[% str.append('.html') %]   # str => 'foobar.html'

La valeur de "str" est maintenant '"foobar.html"'. Si vous ne souhaitez pas modifier la chaîne, prenez simplement une copie au préalable.

[% str.copy.append('.html') %]

Ces méthodes retournent toutes une référence à l'objet "String" lui-même. Cela présente deux avantages importants. Le premier est que, lorsqu'il est utilisé comme ci-dessus, l'objet "String" '"str"' retourné par la méthode append() sera stringifié avec un appel à sa méthode text(). Cela retournera le contenu de la chaîne nouvellement modifié. En d'autres termes, une directive comme :

[% str.append('.html') %]

mettra à jour la chaîne et imprimera également la nouvelle valeur. Si vous souhaitez seulement mettre à jour la chaîne sans imprimer la nouvelle valeur, utilisez "CALL".

[% CALL str.append('.html') %]

L'autre avantage de ces méthodes retournant une référence à la "String" est que vous pouvez chaîner autant d'appels de méthodes différents que vous le souhaitez. Par exemple :

[% String.append('.html').trim.format(href) %]

Voici les méthodes :

push($suffix, ...) / append($suffix, ...)

Ajoute tous les arguments à la fin de la chaîne. La méthode append() est fournie comme alias pour push().

[% msg.push('foo', 'bar') %]
[% msg.append('foo', 'bar') %]

pop($suffix)

Supprime le suffixe passé en argument de la fin de la chaîne.

Ce site n'est en aucun cas associé à Arch Linux ni affilié à ce projet. Le contenu est uniquement une traduction des pages de manuel d'Arch publiées sur man.archlinux.org.

unshift($prepend)

Adds the arguments passed to the start of the String.

[% msg = String('bar baz') %]
[% msg.unshift('foo ', 'bar ') %]   # => 'foo bar bar baz'

This method is aliased to prepend().

[% msg.unshift('foo ', 'bar ') %]
[% msg.prepend('foo ', 'bar ') %]

shift($prefix)

Retire le préfixe passé comme argument du début de la String.

[% USE String 'foo bar' %]
[% String.shift('foo ') %]   # => 'bar'

left($pad)

Si la longueur de la chaîne est inférieure à $pad, la chaîne est formatée à gauche et complétée avec des espaces pour atteindre la longueur $pad.

[% msg.left(20) %]

right($pad)

Comme pour left() mais formate la "String" à droite en complétant avec des espaces pour atteindre une longueur de $pad.

[% msg.right(20) %]

center($pad) / centre($pad)

Comme pour left() et right() mais formate la "String" pour qu'elle soit centrée dans une chaîne remplie d'espaces d'une longueur de $pad. La méthode centre() est fournie comme alias pour center().

[% msg.center(20) %]    # Orthographe américaine
[% msg.centre(20) %]    # Orthographe européenne

format($format)

Applique un formatage dans le style de sprintf() à la chaîne.

[% USE String("world") %]
[% String.format("Hello %s\n") %]  # => "Hello World\n"

upper()

Convertit la chaîne en majuscules.

[% USE String("foo") %]
[% String.upper %]  # => 'FOO'

lower()

Convertit la chaîne en minuscules.

[% USE String("FOO") %]
[% String.lower %]  # => 'foo'

capital()

Convertit le premier caractère de la chaîne en majuscule.

[% USE String("foo") %]
[% String.capital %]  # => 'Foo'

Le reste de la chaîne n'est pas modifié. Pour forcer la chaîne à être entièrement en minuscules, à l'exception de la première lettre qui est en majuscule, vous pouvez faire ceci :

[% USE String("FOO") %]
[% String.lower.capital %]  # => 'Foo'

chop()

Supprime le dernier caractère de la chaîne.

[% USE String("foop") %]
[% String.chop %]   # => 'foo'

chomp()

Supprime le retour à la ligne final de la chaîne.

[% USE String("foo\n") %]
[% String.chomp %]  # => 'foo'

trim()

Supprime tous les espaces blancs de début et de fin de la chaîne.

[% USE String("   foo   \n\n ") %]
[% String.trim %]   # => 'foo'

collapse()

Supprime tous les espaces blancs de début et de fin et réduit toutes les séquences d'espaces blancs multiples à un seul espace.

[% USE String(" \n\r  \t  foo   \n \n bar  \n") %]
[% String.collapse %]   # => "foo bar"

truncate($length, $suffix)

Tronque la chaîne à $length caractères.

[% USE String('long string') %]
[% String.truncate(4) %]  # => 'long'

Si $suffix est spécifié, il sera ajouté à la chaîne tronquée. Dans ce cas, la chaîne sera raccourcie davantage de la longueur du suffixe pour garantir que la nouvelle chaîne, complète avec son suffixe, ait exactement $length caractères.

[% USE msg = String('Hello World') %]
[% msg.truncate(8, '...') %]   # => 'Hello...'

replace($search, $replace)

Remplace toutes les occurrences de $search dans la chaîne par $replace.

[% USE String('foo bar foo baz') %]
[% String.replace('foo', 'wiz')  %]  # => 'wiz bar wiz baz'

remove($search)

Supprime toutes les occurrences de $search dans la chaîne.

[% USE String('foo bar foo baz') %]
[% String.remove('foo ')  %]  # => 'bar baz'

repeat($count)

Répète la chaîne $count fois.

[% USE String('foo ') %]
[% String.repeat(3)  %]  # => 'foo foo foo '
