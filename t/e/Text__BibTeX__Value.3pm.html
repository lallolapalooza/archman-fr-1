NOM

Text::BibTeX::Value - interfaces pour les valeurs BibTeX et les valeurs simples

SYNTAXE

use Text::BibTeX;
$entry = Text::BibTeX::Entry->new;
# définir le drapeau 'preserve_values' à 1 pour cette analyse
$entry->parse ($filename, $filehandle, 1);
# la méthode 'get' renvoie maintenant un objet Text::BibTeX::Value
# au lieu d'une chaîne de caractères
$value = $entry->get ($field);
# interroger l'objet `Value' (liste d'objets SimpleValue)
@all_values = $value->values;
$first_value = $value->value (0);
$last_value = $value->value (-1);
# interroger les objets de valeur simple -- le type sera l'un de BTAST_STRING,
# BTAST_MACRO, ou BTAST_NUMBER
use Text::BibTex (':nodetypes');   # importer les constantes de "type de nœud"
$is_macro = ($first_value->type == BTAST_MACRO);
$text = $first_value->text;

DESCRIPTION

Le module "Text::BibTeX::Value" fournit deux classes, "Text::BibTeX::Value" et "Text::BibTeX::SimpleValue", qui vous donnent respectivement accès aux "valeurs composites" et aux "valeurs simples" de BibTeX. Rappelez-vous que chaque valeur de champ dans une entrée BibTeX est la concaténation d'une ou plusieurs valeurs simples, et que chacune de ces valeurs simples peut être une chaîne de caractères littérale, une macro (abréviation) ou un nombre. Normalement avec "Text::BibTeX", les valeurs de champ sont "entièrement traitées", de sorte que vous n'avez accès qu'à la chaîne résultante de l'expansion des macros, de la conversion des nombres en chaînes, de la concaténation de toutes les sous-chaînes et de l'effacement des espaces dans la chaîne résultante.

Par exemple, dans l'entrée suivante :

@article{homer97,
  author = "Homer Simpson" # and # "Ned Flanders",
  title = {Territorial Imperatives in Modern Suburbia},
  journal = jss,
  year = 1997
}

nous voyons toute la gamme des options. Le champ "author" se compose de trois valeurs simples : une chaîne, une macro ("and") et une autre chaîne. Le champ "title" est une seule chaîne, et les champs "journal" et "year" sont, respectivement, une seule macro et un seul nombre. Si vous analysez cette entrée de la manière habituelle :

$entry = Text::BibTeX::Entry->new($entry_text);

alors la méthode "get" sur $entry renverrait des chaînes simples. En supposant que la macro "and" est définie comme " and ", alors

$entry->get ('author')

renverrait la chaîne Perl "Homer Simpson and Ned Flanders".

Cependant, vous pouvez également demander à la bibliothèque de préserver les valeurs d'entrée dans vos entrées, c'est-à-dire de ne pas perdre les informations sur quelles valeurs utilisent des macros, quelles valeurs sont composées de plusieurs valeurs simples, etc. Il y a deux façons de faire cette requête : par fichier et par entrée. Pour une requête par fichier, utilisez la méthode "preserve_values" sur votre objet "File" :

$bibfile = Text::BibTeX::File->new($filename);
$bibfile->preserve_values (1);
$entry = Text::BibTeX::Entry->new($bibfile);
$entry->get ($field);        # renvoie un objet Value
$bibfile->preserve_values (0);
$entry = Text::BibTeX::Entry->new($bibfile);
$entry->get ($field);        # renvoie une chaîne

Si vous n'utilisez pas d'objet "File", ou si vous voulez contrôler les choses à une échelle plus fine, alors vous devez passer le drapeau "preserve_values" lors de l'appel de "read", "parse", ou "parse_s" sur vos objets "Entry" :

# pas d'objet File, analyse à partir d'une chaîne
$entry = Text::BibTeX::Entry->new;
$entry->parse_s ($entry_text, 0);  # preserve_values=0 (par défaut)
$entry->get ($field);        # renvoie une chaîne
$entry->parse_s ($entry_text, 1);
$entry->get ($field);        # renvoie un objet Value
# utilisation d'un objet File, mais volonté de contrôle plus fin
$entry->read ($bibfile, 0);  # maintenant get renverra des chaînes (par défaut)
$entry->read ($bibfile, 1);  # maintenant get renverra des objets Value

Une valeur composite, généralement appelée simplement valeur, est simplement une liste de valeurs simples. La classe "Text::BibTeX::Value" (ci-après abrégée en "Value") fournit une interface simple à cette liste ; vous pouvez demander la liste entière, ou un membre individuel de la liste. La classe "SimpleValue" vous donne accès aux détails de chaque valeur simple, qui consistent en le type et le texte. Le type vous dit simplement si cette valeur simple est une chaîne, une macro ou un nombre ; il est représenté en utilisant la traduction Perl de l'énumération des "types de nœuds" en C. Les types possibles sont "BTAST_STRING", "BTAST_NUMBER" et "BTAST_MACRO". Le texte est simplement ce qui apparaît dans le texte de l'entrée d'origine, qu'il s'agisse d'une chaîne, d'un nombre ou d'une macro.

Par exemple, nous pourrions analyser l'entrée ci-dessus en mode "préserver les valeurs" comme suit :

$entry->parse_s ($entry_text, 1);   # preserve_values est 1

Ensuite, en utilisant la méthode "get" sur $entry, on obtiendrait non pas une chaîne, mais un objet "Value". Nous pouvons obtenir la liste de toutes les valeurs simples en utilisant la méthode "values", ou une seule valeur en utilisant "value" :

$author = $entry->get ('author');   # maintenant un objet Text::BibTeX::Value
@all_values = $author->values;      # tableau de Text::BibTeX::SimpleValue
$second = $author->value (1);       # identique à $all_values[1]

Les valeurs simples peuvent être interrogées en utilisant les méthodes "Text::BibTeX::SimpleValue", "type" et "text" :

$all_values[0]->type;               # renvoie BTAST_STRING
$second->type;                      # renvoie BTAST_MACRO
$all_values[0]->text;               # "Homer Simpson"
$second->text;                      # "and" (PAS l'expansion de la macro !)
$entry->get ('year')->value (0)->text;   # "1997"

MÉTHODES

Normalement, vous n'aurez pas besoin de créer d'objets "Value" ou "SimpleValue" --- ils seront créés pour vous lorsqu'une entrée sera analysée, et renvoyés par la méthode "get" de la classe "Entry". Ainsi, les méthodes de requête ("values" et "value" pour la classe "Value", "type" et "text" pour "SimpleValue") sont probablement tout ce dont vous avez besoin de vous soucier. Si vous le souhaitez, cependant, vous pouvez créer de nouvelles valeurs et de nouvelles valeurs simples en utilisant les constructeurs respectifs des deux classes. Vous pouvez également réinsérer des objets "Value" nouvellement créés dans un objet "Entry" existant en utilisant la méthode "set" de l'entrée ; peu importe comment l'entrée a été analysée, ceci est acceptable à tout moment.

Méthodes Text::BibTeX::Value

new (SVAL, ...)
Crée un nouvel objet "Value" à partir d'une liste de valeurs simples. Chaque valeur simple, SVAL, peut être soit un objet "SimpleValue", soit une référence à une liste de deux éléments contenant le type et le texte de la valeur simple. Par exemple, une façon de recréer le champ "author" de l'exemple d'entrée dans "DESCRIPTION" serait : 
$and_macro = Text::BibTeX::SimpleValue->new (BTAST_MACRO, 'and');
$value = Text::BibTeX::Value->new
   ([BTAST_STRING, 'Homer Simpson'],
    $and_macro,
    [BTAST_STRING, 'Ned Flanders']);

L'objet "Value" résultant pourrait alors être installé dans une entrée en utilisant la méthode "set" de l'objet "Entry".

Text::BibTeX::SimpleValue

NOM

Text::BibTeX::SimpleValue

SYNOPSIS

use Text::BibTeX::SimpleValue;

DESCRIPTION

Text::BibTeX::SimpleValue est une classe qui représente une valeur simple en BibTeX. Elle fournit des méthodes pour créer, accéder et manipuler des valeurs simples.

MÉTHODES

new (TYPE, TEXT)
Crée un nouvel objet "SimpleValue" avec le TYPE et le TEXT spécifiés. TYPE doit être l'un des types autorisés pour les valeurs simples BibTeX, c'est-à-dire "BTAST_STRING", "BTAST_NUMBER", ou "BTAST_MACRO". Vous voudrez probablement importer ces constantes depuis "Text::BibTeX" en utilisant la balise d'exportation "nodetypes" : 
use Text::BibTeX qw(:nodetypes);

TEXT peut être n'importe quelle chaîne de caractères. Notez que si TYPE est "BTAST_NUMBER" et que TEXT n'est pas une chaîne de chiffres, l'objet "SimpleValue" sera créé de toute façon, mais un avertissement sera émis. Aucun avertissement n'est émis concernant les macros inexistantes.

type ()
Retourne le type d'une valeur simple. Ce sera l'un des "types de nœuds" autorisés, comme décrit sous "new" ci-dessus.
text ()
Retourne le texte d'une valeur simple. C'est simplement le texte qui apparaît dans l'entrée originale — nom de macro non développé, ou nombre non converti. (Bien sûr, convertir des nombres ne fait aucune différence du point de vue de Perl ; en fait, tout est pareil en C aussi, car le code C conserve simplement les nombres sous forme de chaînes de chiffres. Il s'agit simplement de savoir si la chaîne de chiffres est représentée comme une chaîne ou un nombre, ce que vous pourriez vouloir savoir si vous voulez préserver autant que possible la structure de l'entrée.)

VOIR AUSSI

Text::BibTeX, Text::BibTeX::File, Text::BibTeX::Entry
