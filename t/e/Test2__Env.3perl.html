Test2::Env(3perl) Guide de référence du programmeur Perl Test2::Env(3perl)

NOM

Test2::Env - Documentation pour les variables d'environnement utilisées ou définies par Test2.

DESCRIPTION

Ceci est une liste des variables d'environnement qui sont soit définies par, soit lues par Test2.

TESTS_AUTEUR

Cette variable d'environnement est lue par Test2. Lorsqu'elle est définie, Test2 exécutera les tests qui sont normalement ignorés, sauf si un auteur de module effectue des tests supplémentaires spécifiques à l'auteur.

TESTS_AUTOMATISÉS

Cette variable d'environnement est lue par Test2. Lorsqu'elle est définie, cela indique que les tests sont exécutés par un système automatisé et qu'aucune interaction humaine n'est possible.

Voir Test2::Require::AuthorTesting.

TESTS_ÉTENDUS

Cette variable d'environnement est lue par Test2. Lorsqu'elle est définie, elle indique que certains tests étendus qui devraient normalement être ignorés seront exécutés.

Voir Test2::Require::ExtendedTesting.

HARNESS_ACTIVE

Cette variable d'environnement est lue par Test2. Elle est généralement définie par "prove" (Test::Harness) ou "yath" (App::Yath).

TESTS_NON_INTERACTIFS

Cette variable d'environnement est lue par Test2. Lorsqu'elle est définie, cela indique que les tests ne seront pas interactifs.

Voir Test2::Require::NonInteractiveTesting.

TESTS_PUBLICATION

Cette variable d'environnement est lue par Test2. Lorsqu'elle est définie, cela indique que les tests de publication sont en cours, ce qui peut entraîner l'exécution de tests supplémentaires par rapport à la normale.

Voir Test2::Require::ReleaseTesting.

T2_FORMATTER

Ceci peut être utilisé pour définir le formateur que Test2 utilisera. S'il est défini sur une chaîne sans préfixe '+', alors 'Test2::Formatter::' sera ajouté au début du nom du module. Si '+' est présent, il sera retiré et aucune autre modification ne sera apportée au nom du module.

T2_IN_PRELOAD

Test2 définit cette variable lorsque le mode de préchargement est actif. Ceci est principalement utilisé par App::Yath et des outils similaires qui préchargent Test2, puis font un fork pour exécuter les tests.

TABLE_TERM_SIZE

Ceci est utilisé pour définir une largeur de terminal pour les tables de messages de diagnostic, par exemple.

TEST2_ACTIVE

Test2 définit cette variable lorsque les tests sont en cours d'exécution.

TEST2_ENABLE_PLUGINS

Ceci peut être utilisé pour forcer le chargement des plugins lorsque l'API Test2 est chargée. Il prend une liste d'un ou plusieurs noms de plugins séparés par des virgules. Si le nom du module n'a pas de '+' devant lui, l'espace de noms "Test2::Plugin::" est supposé et ajouté. Si un '+' est présent au début d'un nom de module, il sera retiré et aucune autre modification ne sera apportée.

Exemples:

TEST2_ENABLE_PLUGINS=BailOnFail
Test2_ENABLE_PLUGINS=SRand,+My::Plugin::Name

TEST_ACTIVE

Défini par Test2 lorsque les tests sont en cours d'exécution.

TS_MAX_DELTA

Utilisé pour déterminer le nombre maximum de lignes de sortie qui seront fournies lorsque is() trouvera une incohérence de structure de données profonde.
