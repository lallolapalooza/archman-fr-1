NOM

Template::Base - Module de classe de base implémentant des fonctionnalités communes

SYNOPSIS

package My::Module;
use base qw( Template::Base );
sub _init {
    my ($self, $config) = @_;
    $self->{ doodah } = $config->{ doodah }
        || return $self->error("Aucun 'doodah' spécifié");
    return $self;
}
package main;
my $object = My::Module->new({ doodah => 'foobar' })
    || die My::Module->error();

DESCRIPTION

Module de classe de base qui implémente un constructeur et des fonctionnalités de rapport d'erreurs pour divers modules de Template Toolkit.

MÉTHODES PUBLIQUES

new(\%config)

Méthode constructeur qui accepte une référence à un tableau de hachage ou une liste de paramètres "nom => valeur" qui sont regroupés dans un hachage. La méthode _init() est ensuite appelée, passant le hachage de configuration et doit retourner vrai/faux pour indiquer le succès ou l'échec. Une référence au nouvel objet est retournée, ou undef en cas d'erreur. Tout message d'erreur soulevé peut être examiné via la méthode de classe error() ou directement via la variable de paquet $ERROR dans la classe dérivée.

my $module = My::Module->new({ ... })
    || die My::Module->error(), "\n";
my $module = My::Module->new({ ... })
    || die "erreur constructeur: $My::Module::ERROR\n";

error($msg, ...)

Peut être appelée comme méthode d'objet pour obtenir/définir le membre interne "_ERROR" ou comme méthode de classe pour obtenir/définir la variable $ERROR dans le paquet de la classe dérivée.

my $module = My::Module->new({ ... })
    || die My::Module->error(), "\n";
$module->do_something()
    || die $module->error(), "\n";

Lorsqu'elle est appelée avec des paramètres (plusieurs paramètres sont concaténés), cette méthode définira la variable pertinente et retournera undef. Ceci est le plus souvent utilisé dans les méthodes d'objet pour signaler des erreurs à l'appelant.

package My::Module;
sub foobar {
    my $self = shift;
    # autre code...
    return $self->error('une sorte d\'erreur...')
        if $some_condition;
}

debug($msg, ...)

Génère un message de débogage en concaténant tous les arguments passés en une chaîne et en l'imprimant sur "STDERR". Un préfixe est ajouté pour indiquer le module de l'appelant.

package My::Module;
sub foobar {
    my $self = shift;
    $self->debug('foobar() appelé');
    # autre code...
}

Lorsque la méthode foobar() est appelée, le message suivant est envoyé à "STDERR" :

[My::Module] foobar() appelé

Les objets peuvent définir une valeur interne "DEBUG" que la méthode debug() examinera. Si cette valeur définit les bits pertinents pour indiquer "DEBUG_CALLER", alors le nom de fichier et le numéro de ligne de l'appelant seront ajoutés au message.

use Template::Constants qw( :debug );
my $module = My::Module->new({
    DEBUG => DEBUG_SERVICE | DEBUG_CONTEXT | DEBUG_CALLER,
});
$module->foobar();

Ceci génère un message d'erreur tel que :

[My::Module] foobar() appelé à My/Module.pm ligne 6

module_version()

Retourne le numéro de version d'un module, tel que défini par la variable de paquet $VERSION.
