NOM

Test2::Compare::OrderedSubset - Représentation interne d'un sous-ensemble ordonné.

DESCRIPTION

Ce module est utilisé pour s'assurer qu'un tableau contient tous les éléments attendus dans le bon ordre. Il ignore les éléments inattendus mélangés dans le tableau. Il se soucie uniquement que toutes les valeurs attendues soient présentes, et dans l'ordre, tout le reste est du bruit.

MÉTHODES

$ref = $arr->inref()
Si l'instance a été construite à partir d'un tableau réel, elle contiendra la référence de ce tableau.
$arrayref = $arr->items()
$arr->set_items($arrayref)
Tous les éléments attendus, dans l'ordre.
$name = $arr->name()
Retourne toujours la chaîne "<ORDERED SUBSET>".
$bool = $arr->verify(got => $got, exists => $bool)
Vérifie si $got est une référence de tableau ou non.
$arr->add_item($item)
Ajoute un élément à la liste des valeurs à vérifier.
@deltas = $arr->deltas(got => $got, convert => \&convert, seen => \%seen)
Trouve les différences entre les valeurs attendues du tableau et celles du tableau référence $got.
