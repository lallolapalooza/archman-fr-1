NOM

Text::Query::ParseAdvanced - Syntaxe de requête avancée AltaVista de analyseur

SYNTAXE

use Text::Query;
my $q=new Text::Query('bonjour et monde',
                      -parse => 'Text::Query::ParseAdvanced',
                      -solve => 'Text::Query::SolveAdvancedString',
                      -build => 'Text::Query::BuildAdvancedString');

DESCRIPTION

Ce module fournit un objet qui analyse une chaîne contenant une expression de requête booléenne similaire à une "requête avancée" AltaVista.

Sa classe parente est Text::Query::Parse;

Les expressions de requête se composent de chaînes littérales (ou d'expressions régulières) reliées par les opérateurs suivants, par ordre de priorité du plus bas au plus élevé :

OU, |
ET, &
PRES, ~
NON, !

Les noms d'opérateurs ne sont pas sensibles à la casse. Notez que si vous souhaitez utiliser un "|" dans une expression régulière, vous devez le précéder d'une barre oblique inverse pour éviter qu'il ne soit interprété comme un opérateur de requête. Les sous-expressions peuvent être entourées de guillemets simples ou doubles pour correspondre littéralement à "and", "or", ou "not", et peuvent être groupées entre parenthèses ("(, )") pour modifier la priorité d'évaluation.

Une sous-expression entre parenthèses peut également être concaténée avec d'autres sous-expressions pour correspondre à des séquences : "(Perl ou Python) interpréteur" correspondrait soit à "Perl interpréteur" soit à "Python interpréteur". La concaténation a une priorité supérieure à NOT mais inférieure à AND. La juxtaposition de mots simples a la plus haute priorité de tous.

OPTIONS

Ce sont les options supplémentaires de la méthode "prepare" et du constructeur.

-near vaut par défaut 10
Définit le nombre de mots pouvant séparer deux expressions pour satisfaire l'opérateur PRES.
-operateurs vaut par défaut et, ou, non, pres
Définit les noms des opérateurs. L'argument de l'option est un pointeur vers une table de hachage associant les noms par défaut aux noms désirés. Par exemple : 
{
    'ou' => 'or',
    'et' => 'and',
    'pres' => 'near',
    'non' => 'not',
}
-scope_map vaut par défaut {}
Associe les noms de portée à d'autres noms. Si une portée est spécifiée comme "portee:", la carte est recherchée pour une entrée dont la clé est "portee" et "portee" est remplacé par la valeur scalaire trouvée. Par exemple : 
{
    'portee' => 'autreportee'
}
