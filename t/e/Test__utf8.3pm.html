NOM

Test::utf8 - tests pratiques pour les caractères UTF-8

SYNOPIS

# vérifier qu'une chaîne est valide
is_valid_string($string);   # vérifier qu'une chaîne est valide
is_sane_utf8($string);      # vérifier qu'elle n'est pas mal encodée en UTF-8
# vérifier que la chaîne a certaines caractéristiques
is_flagged_utf8($string1);   # a le flag UTF-8 activé
is_within_ascii($string2);   # ne contient que des caractères ASCII
is_not_within_ascii($string3); # contient des caractères hors de la plage ASCII
is_within_latin_1($string4); # ne contient que des caractères latin-1
is_not_within_latin_1($string5); # contient des caractères hors de la plage latin-1

DESCRIPTION

Ce module est une collection de tests utiles pour manipuler les chaînes UTF-8 en Perl.

Ce module propose deux types de tests : les tests de validité qui vérifient si une chaîne est valide et non corrompue, et les tests de caractéristiques qui vérifient que la chaîne possède certaines caractéristiques.

Tests de Validité

is_valid_string($string, $testname)
Vérifie si la chaîne est « valide », c'est-à-dire qu'elle passe et renvoie vrai si elle n'a pas le flag UTF-8 activé dans un scénario qui n'est pas une séquence d'octets UTF-8 valide.
is_sane_utf8($string, $name)
Ce test échoue si la chaîne contient quelque chose qui semble mal encodé en UTF-8, c'est-à-dire qu'elle contient quelque chose qui ressemble à une séquence multi-octets d'un caractère latin-1 mais que Perl n'a pas été indiqué pour le traiter comme tel. Les chaînes non-UTF-8 passent toujours automatiquement.

Quelques exemples peuvent aider :

# passe comme chaîne latin-1 normale
is_sane_utf8("Hello L\x{e9}eon");
# échoue car \x{c3}\x{a9} ressemble à la séquence UTF-8 pour é-accentaigu
my $string = "Hello L\x{c3}\x{a9}on";
is_sane_utf8($string);
# passe car l'UTF-8 est interprété correctement
Encode::_utf8_on($string)
is_sane_utf8($string);

Évidemment, ce n'est pas fiable à 100 %. Le cas d'erreur est lorsque la chaîne contient des séquences UTF-8 et n'est pas marquée comme UTF-8 (ce qui signifie généralement que vous l'avez obtenue d'une source externe, comme une bibliothèque C ; lorsque Perl doit stocker une chaîne en interne en tant qu'UTF-8, il le fait de manière transparente).

Tests de Caractéristiques de Chaîne

Ces routines vous permettent de vérifier la plage de caractères dans une chaîne. Note : ces routines ignorent l'encodage interne utilisé par Perl pour stocker les caractères, elles vérifient seulement si la chaîne contient uniquement des caractères représentables dans l'encodage nommé :

is_within_ascii
Vérifie qu'une chaîne ne contient que des caractères appartenant à l'ensemble de caractères ASCII.
is_within_latin_1
Vérifie qu'une chaîne ne contient que des caractères appartenant à latin-1.

Vérifie simplement si un scénario est marqué ou non comme UTF-8 par Perl en interne :

is_flagged_utf8($string, $name)
Renvoie vrai si la chaîne est marquée en interne par Perl comme UTF-8, sinon faux.
is_not_flagged_utf8($string,$name)
L'inverse de "is_flagged_utf8", renvoie vrai si et seulement si la chaîne n'est pas marquée comme UTF-8 par Perl en interne.

Note : vous pouvez faire référence à cette fonction sous le nom de "is_not_flagged_utf8" si vous le souhaitez.
