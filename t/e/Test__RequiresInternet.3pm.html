NOM

Test::RequiresInternet - Tester facilement la connectivité réseau

VERSION

version 0.05

SYNOPSIS

use Test::More;
use Test::RequiresInternet ('www.example.com' => 80, 'foobar.io' => 25);
# si vous arrivez ici, les sockets se sont connectés avec succès aux hôtes/ports ci-dessus
plan tests => 1;
ok(do_that_internet_thing());

APERÇU

Ce module est destiné à tester facilement la connectivité réseau avant que les tests fonctionnels ne commencent sur des ressources Internet non locales. Il ne nécessite aucun module au-delà de ceux fournis dans le noyau Perl.

Si vous ne spécifiez pas une paire hôte/port, le module utilise par défaut "www.google.com" sur le port 80.

Vous pouvez éventuellement spécifier le port par son nom, comme "http" ou "ldap". Si vous faites cela, le module de test tentera de rechercher le numéro de port en utilisant "getservbyname".

Si vous spécifiez un hôte et un port, ils doivent être spécifiés en paires. Omettre l'un ou l'autre est une erreur fatale.

Si la variable d'environnement "NO_NETWORK_TESTING" est définie, les tests seront ignorés sans tenter de connexions socket.

Si les sockets ne peuvent pas se connecter aux hôtes et ports spécifiés, l'exception est interceptée, signalée et les tests sont ignorés.
