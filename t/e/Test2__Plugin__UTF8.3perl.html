NOM

Test2::Plugin::UTF8 - Plugin Test2 pour tester avec utf8.

DESCRIPTION

Lorsqu'il est utilisé, ce plugin permet aux tests de fonctionner avec utf8. Cela inclut l'activation du pragma utf8 et la mise à jour du formatteur de sortie de Test2 pour utiliser utf8.

SYNOPSIS

use Test2::Plugin::UTF8;

Ceci est similaire à :

use utf8;
BEGIN {
    require Test2::Tools::Encoding;
    Test2::Tools::Encoding::set_encoding('utf8');
}

Vous pouvez également désactiver l'importation de utf8 en utilisant 'encoding_only' pour activer uniquement l'encodage utf8 sur le format de sortie.

use Test2::Plugin::UTF8 qw(encoding_only);

options d'import

encoding_only

N'importe pas utf8 dans votre test et active uniquement le mode d'encodage sur la sortie.

NOTES

Ce module configure actuellement les descripteurs de sortie pour avoir la couche de sortie ':utf8'. Certains pourraient préférer ':encoding(utf-8)' qui est plus strict quant à la vérification des caractères. Il y a un débat pour savoir si l'encodage en utf8 à partir des internes de Perl peut jamais échouer, donc cela pourrait ne pas avoir d'importance. Ceci a également été choisi car l'alternative provoque des segfaults de threads, voir perlbug 31923 https://rt.perl.org/Public/Bug/Display.html?id=31923.

SOURCE

Le dépôt de code source de Test2-Suite peut être trouvé à l'adresse https://github.com/Test-More/test-more/.
