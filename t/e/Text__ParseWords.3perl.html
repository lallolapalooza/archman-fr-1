Text::ParseWords(3perl) Guide du programmeur Perl Text::ParseWords(3perl)

NOM

Text::ParseWords - analyser du texte en un tableau de jetons ou un tableau de tableaux

SYNTAXE

use Text::ParseWords;
@listes = nested_quotewords($delim, $garder, @lignes);
@mots = quotewords($delim, $garder, @lignes);
@mots = shellwords(@lignes);
@mots = parse_line($delim, $garder, $ligne);
@mots = old_shellwords(@lignes); # OBSOLÈTE !

DESCRIPTION

nested_quotewords() et quotewords() acceptent un délimiteur (qui peut être une expression régulière) et une liste de lignes, puis décomposent ces lignes en une liste de mots en ignorant les délimiteurs qui apparaissent à l'intérieur de guillemets. quotewords() retourne tous les jetons dans une seule longue liste, tandis que nested_quotewords() retourne une liste de listes de jetons correspondant aux éléments de @lignes. parse_line() effectue une analyse en jetons sur une seule chaîne. Les fonctions *quotewords() appellent simplement parse_line(), donc si vous ne divisez qu'une seule ligne, vous pouvez appeler parse_line() directement et économiser un appel de fonction.

Le paramètre $garder contrôle ce qui se passe avec les délimiteurs et les caractères spéciaux :

vrai
Si vrai, les jetons sont séparés par le délimiteur spécifié, mais tous les autres caractères (y compris les guillemets et les barres obliques inverses) sont conservés dans les jetons.
faux
Si $garder est faux, les fonctions *quotewords() suppriment tous les guillemets et barres obliques inverses qui ne sont pas eux-mêmes échappés par une barre oblique inverse ou à l'intérieur de guillemets simples (c'est-à-dire que quotewords() essaie d'interpréter ces caractères comme le fait le shell Bourne). NB : ces sémantiques sont significativement différentes de la version originale de ce module fournie avec Perl 5.000 à 5.004.
"délimiteurs"
En tant que fonctionnalité supplémentaire, $garder peut être le mot-clé "délimiteurs", ce qui fait que les fonctions conservent les délimiteurs de chaque chaîne comme jetons dans les listes de jetons, en plus de conserver les caractères de guillemets et de barres obliques inverses.

shellwords() est écrit comme un cas particulier de quotewords(), et il effectue une analyse en jetons avec les espaces comme délimiteurs, similaire à la plupart des shells Unix.

EXEMPLES

Le programme d'exemple :

use Text::ParseWords;
@mots = quotewords('\s+', 0, q{this   is "a test" of\ quotewords \"for you});
$i = 0;
foreach (@mots) {
    print "$i: <$_>\n";
    $i++;
}

produit :

0: <this>
1: <is>
2: <a test>
3: <of quotewords>
4: <"for>
5: <you>

démontrant :

0
un mot simple
1
plusieurs espaces sont ignorés à cause de notre $delim
2
utilisation de guillemets pour inclure un espace dans un mot
3
utilisation d'une barre oblique inverse pour inclure un espace dans un mot
4
utilisation d'une barre oblique inverse pour supprimer la signification spéciale d'un guillemet double
5
un autre mot simple (notez l'absence d'effet du guillemet double échappé par une barre oblique inverse)

Remplacer "quotewords('\s+', 0, q{this is...})" par "shellwords(q{this is...})" est une manière plus simple d'accomplir la même chose.
