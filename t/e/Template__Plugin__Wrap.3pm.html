NOM

Template::Plugin::Wrap - Interface de plugin pour Text::Wrap

SYNOPIS

[% USE wrap %]
# appel de la sous-routine wrap
[% wrap(mytext, width, initial_tab,  subsequent_tab) %]
# ou utilisation du filtre wrap
[% mytext FILTER wrap(width, initital_tab, subsequent_tab) %]

DESCRIPTION

Ce plugin fournit une interface au module Text::Wrap qui permet une mise en forme simple de paragraphes.

Il définit une sous-routine "wrap" qui peut être appelée en passant le texte d'entrée et des paramètres optionnels supplémentaires pour spécifier la largeur de page (par défaut : 72), et les caractères de tabulation pour la première ligne et les lignes suivantes (pas de défauts).

[% USE wrap %]
[% text = BLOCK %]
First, attach the transmutex multiplier to the cross-wired
quantum homogeniser.
[% END %]
[% wrap(text, 40, '* ', '  ') %]

Sortie :

* First, attach the transmutex
  multiplier to the cross-wired quantum
  homogeniser.

Il enregistre également un filtre "wrap" qui accepte les trois mêmes arguments optionnels mais prend le texte d'entrée directement via l'entrée du filtre.

Exemple 1 :

[% FILTER bullet = wrap(40, '* ', '  ') -%]
First, attach the transmutex multiplier to the cross-wired quantum
homogeniser.
[%- END %]

Sortie :

* First, attach the transmutex
  multiplier to the cross-wired quantum
  homogeniser.

Exemple 2 :

[% FILTER bullet -%]
Then remodulate the shield to match the harmonic frequency, taking
care to correct the phase difference.
[% END %]

Sortie :

* Then remodulate the shield to match
  the harmonic frequency, taking
  care to correct the phase difference.
