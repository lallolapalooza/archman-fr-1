Text::Wrap(3perl) Guide du programmeur Perl Text::Wrap(3perl)

NOM

Text::Wrap - mise en forme de lignes pour créer des paragraphes simples

SYNTAXE

Exemple 1

use Text::Wrap;
$initial_tab = "\t";    # Tabulation avant la première ligne
$subsequent_tab = "";   # Toutes les autres lignes alignées à gauche
print wrap($initial_tab, $subsequent_tab, @text);
print fill($initial_tab, $subsequent_tab, @text);
$lines = wrap($initial_tab, $subsequent_tab, @text);
@paragraphs = fill($initial_tab, $subsequent_tab, @text);

Exemple 2

use Text::Wrap qw(wrap $columns $huge);
$columns = 132;         # Coupe à 132 caractères
$huge = 'die';
$huge = 'wrap';
$huge = 'overflow';

Exemple 3

use Text::Wrap;
$Text::Wrap::columns = 72;
print wrap('', '', @text);

DESCRIPTION

Text::Wrap::wrap() est un formateur de paragraphe très simple. Il formate un paragraphe à la fois en coupant les lignes aux limites des mots. L'indentation est contrôlée pour la première ligne ($initial_tab) et toutes les lignes subséquentes ($subsequent_tab) indépendamment. Notez bien : $initial_tab et $subsequent_tab sont les chaînes littérales qui seront utilisées : il est peu probable que vous vouliez passer un nombre.

Text::Wrap::fill() est un formateur simple pour plusieurs paragraphes. Il formate chaque paragraphe séparément puis les joint ensemble une fois terminé. Il détruira tout espace blanc dans le texte original. Il découpe le texte en paragraphes en cherchant des espaces après un saut de ligne. Pour le reste, il se comporte comme wrap().

wrap() compresse les espaces blancs finaux en un seul saut de ligne, et fill() supprime tous les espaces blancs finaux.

Les deux fonctions, wrap() et fill(), retournent une seule chaîne.

Contrairement à l'utilitaire Unix fmt(1) d'origine, ce module prend correctement en compte tous les caractères de combinaison Unicode (tels que les diacritiques) qui peuvent apparaître dans chaque ligne pour l'expansion et la non-expansion. Ce sont des caractères de surimpression qui n'augmentent pas la position logique. Assurez-vous que les paramètres Unicode appropriés sont activés.

SUBSTITUTIONS

Text::Wrap::wrap() possède un certain nombre de variables qui contrôlent son comportement. Comme d'autres modules pourraient utiliser Text::Wrap::wrap(), il est suggéré de laisser ces variables tranquilles ! Si vous ne pouvez pas faire cela, alors utilisez "local($Text::Wrap::VARIABLE) = VOTREVALEUR" lorsque vous changez les valeurs afin que la valeur originale soit restaurée. Cette astuce local() ne fonctionnera pas si vous importez la variable dans votre propre espace de noms.

Les lignes sont coupées à $Text::Wrap::columns colonnes (valeur par défaut : 76). $Text::Wrap::columns devrait être défini à la largeur totale de votre périphérique de sortie. En fait, chaque ligne résultante aura une longueur maximale de "$columns - 1".

Il est possible de contrôler quels caractères terminent les mots en modifiant $Text::Wrap::break. Définissez-le à une chaîne telle que '[\s:]' (pour couper avant les espaces ou les deux-points) ou une regexp pré-compilée telle que "qr/[\s']/" (pour couper avant les espaces ou les apostrophes). Par défaut, c'est simplement '\s' ; c'est-à-dire que les mots sont terminés par des espaces. (Cela signifie, entre autres choses, que la ponctuation finale telle que les points ou les virgules reste avec le mot auquel elle est "attachée".) Définir $Text::Wrap::break à une expression régulière qui ne consomme aucun caractère (peut-être juste une assertion lookahead) provoquera des avertissements.

Note pour débutants : Dans l'exemple 2, ci-dessus, $columns est importé dans l'espace de noms local et défini localement. Dans l'exemple 3, $Text::Wrap::columns est défini dans son propre espace de noms sans être importé.

Text::Wrap::wrap() commence son travail en développant toutes les tabulations de son entrée en espaces. La dernière chose qu'il fait est de reconvertir les espaces en tabulations. Si vous ne voulez pas de tabulations dans vos résultats, définissez $Text::Wrap::unexpand à une valeur fausse. De même, si vous ne voulez pas utiliser des tabulations de 8 caractères, définissez $Text::Wrap::tabstop au nombre de caractères que vous souhaitez pour vos tabulations.

Si vous souhaitez séparer vos lignes par autre chose qu'un "\n", définissez $Text::Wrap::separator à votre préférence. Cela remplace tous les sauts de ligne par $Text::Wrap::separator. Si vous voulez simplement préserver les sauts de ligne existants mais ajouter de nouvelles coupures avec autre chose, définissez $Text::Wrap::separator2 à la place.

Lorsque des mots plus longs que $columns sont rencontrés, ils sont coupés. wrap() ajoute un "\n" à la colonne $columns. Ce comportement peut être outrepassé en définissant $huge à 'die' ou à 'overflow'. Lorsqu'il est défini à 'die', les mots longs provoqueront l'appel de die(). Lorsqu'il est défini à 'overflow', les mots longs seront laissés intacts.

Notes historiques : 'die' était auparavant la valeur par défaut de $huge. Maintenant, 'wrap' est la valeur par défaut.

EXEMPLES

Code :

print wrap("\t","",<<END);
This is a bit of text that forms 
a normal book-style indented paragraph
END

Résultat :

"     This is a bit of text that forms
a normal book-style indented paragraph   
"

Code :

$Text::Wrap::columns=20;
$Text::Wrap::separator="|";
print wrap("","","This is a bit of text that forms a normal book-style paragraph");

Résultat :

"This is a bit of|text that forms a|normal book-style|paragraph"

VOIR AUSSI

Pour la gestion correcte des caractères est-asiatiques demi- et pleine-chasse, voir Text::WrapI18N. Pour des contrôles plus détaillés : Text::Format.
