Template::Tools - Outils en ligne de commande pour le Template Toolkit

Outils Template

Le Template Toolkit inclut les outils en ligne de commande suivants pour traiter les gabarits.

tpage

Le script tpage peut être utilisé pour traiter un seul gabarit à l'aide du Template Toolkit.

$ tpage --define msg="Bonjour le monde" greeting.tt2

Utilisez l'option "-h" pour obtenir un résumé des options :

$ tpage -h

Consultez la documentation Template::Tools::tpage pour plus d'informations et d'exemples d'utilisation.

ttree

Le script ttree peut être utilisé pour traiter un répertoire entier de gabarits.

$ ttree --src /chemin/vers/les/gabarits --dest /chemin/vers/la/sortie

Utilisez l'option "-h" pour obtenir un résumé des options :

$ ttree -h

Consultez la documentation Template::Tools::ttree pour plus d'informations et d'exemples d'utilisation.
