Test2::Compare(3perl) Guide du programmeur Perl Test2::Compare(3perl)

NOM

Test2::Compare - Extension Test2 pour écrire des outils de comparaison approfondie.

DESCRIPTION

Cette bibliothèque est le moteur des outils de comparaison approfondie tels que Test2::Tools::Compare::is() et Test2::Tools::ClassicCompare::is_deeply().

SYNOPSIS

package Test2::Tools::MyCheck;
use Test2::Compare::MyCheck;
use Test2::Compare qw/compare/;
sub MyCheck {
    my ($got, $exp, $name, @diag) = @_;
    my $ctx = context();
    my $delta = compare($got, $exp, \&convert);
    if ($delta) {
        $ctx->fail($name, $delta->diag, @diag);
    }
    else {
        $ctx->ok(1, $name);
    }
    $ctx->release;
    return !$delta;
}
sub convert {
    my $thing = shift;
    return $thing if blessed($thing) && $thing->isa('Test2::Compare::MyCheck');
    return Test2::Compare::MyCheck->new(stuff => $thing);
}

Voir Test2::Compare::Base pour les détails sur l'écriture d'une vérification personnalisée.

EXPORT

$delta = compare($got, $expect, \&convert)
Cela comparera les structures dans $got avec celles dans $expect. La sous-routine de conversion doit convertir les structures simples à l'intérieur de $expect en vérifications. En cas de différences dans les structures, elles seront rapportées sous forme d'arbre Test2::Compare::Delta.
$build = get_build()
Obtient la construction globale actuelle, le cas échéant.
push_build($build)
Définit la construction globale actuelle.
$build = pop_build($build)
Annule la définition de la construction globale actuelle. Cela lèvera une exception si la construction passée est différente de la globale actuelle.
build($class, sub { ... })
Exécute le bloc de code fourni avec une nouvelle instance de $class comme construction actuelle. Renvoie la nouvelle construction.
$check = convert($thing)
$check = convert($thing, $config)
Cette fonction de conversion est utilisée en interne par strict_convert() et relaxed_convert(). Elle peut également servir de base pour d'autres fonctions de conversion.

Si vous souhaitez l'utiliser avec une configuration personnalisée, vous devriez l'encapsuler dans une autre sous-routine comme suit :

sub my_convert {
    my $thing_to_convert = shift;
    return convert(
        $thing_to_convert,
        { ... }
    );
}

Ou la variante courte :

sub my_convert { convert($_[0], { ... }) }

Il existe plusieurs options de configuration, les voici avec le paramètre par défaut indiqué en premier :

implicit_end => 1
Cette option contrôle les limites des tableaux/hashes. Si elle est vraie, aucune clé de hash ou index de tableau supplémentaire ne sera autorisée. Ce réglage affecte les objets de comparaison générés ainsi que ceux qui sont passés.
use_regex => 1
Cette option contrôle la correspondance des expressions régulières. Lorsque vrai (par défaut), les expressions régulières sont converties en vérifications de manière à ce que les valeurs correspondent à l'expression régulière. Lorsque faux, les expressions régulières seront comparées pour voir si ce sont des expressions régulières identiques.
use_code => 0
Cette option contrôle la correspondance du code. Lorsque faux (par défaut), les références de sous-routines dans les structures doivent être les mêmes références que celles spécifiées. Lorsqu'elles sont vraies, les références de sous-routines seront exécutées pour vérifier la valeur contrôlée.
$check = strict_convert($thing)
Convertit $thing en un objet Test2::Compare::*. Ceci se comportera strictement, ce qui signifie qu'il utilise les réglages suivants :
implicit_end => 1
Les limites des tableaux seront vérifiées lorsque cet objet est utilisé dans une comparaison. Aucune clé de hash inattendue ne peut être présente.
use_code => 0
Les références de sous-routines seront comparées comme des références (c'est-à-dire sont-elles les mêmes références de sous-routines ?)
use_regex => 0
Les expressions régulières seront comparées directement (c'est-à-dire sont-elles les mêmes expressions régulières ?)
$compare = relaxed_convert($thing)
Convertit $thing en un objet Test2::Compare::*. Ce sera détendu, ce qui signifie qu'il utilise les réglages suivants :
implicit_end => 0
Les limites des tableaux ne seront pas vérifiées lorsque cet objet est utilisé dans une comparaison. Des clés de hash inattendues peuvent être présentes.
use_code => 1
Les références de sous-routines seront exécutées pour vérifier une valeur.
use_regex => 1
Les valeurs seront vérifiées par rapport aux expressions régulières fournies.

ÉCRIRE UNE VARIANT DE IS/LIKE

use Test2::Compare qw/compare convert/;
sub my_like($$;$@) {
    my ($got, $exp, $name, @diag) = @_;
    my $ctx = context();
    # Un convertisseur personnalisé qui fait la même chose que celui utilisé par like()
    my $convert = sub {
        my $thing = shift;
        return convert(
            $thing,
            {
                implicit_end => 0,
                use_code     => 1,
                use_regex    => 1,
            }
        );
    };
    my $delta = compare($got, $exp, $convert);
    if ($delta) {
        $ctx->fail($name, $delta->diag, @diag);
    }
    else {
        $ctx->ok(1, $name);
    }
    $ctx->release;
    return !$delta;
}

Le travail d'un outil de comparaison est effectué par 3 entités :

compare()
La fonction compare() prend la structure que vous avez obtenue, la spécification à vérifier, et une sous-routine "\&convert" qui convertira tout ce qui n'est pas une instance d'une sous-classe d'Test2::Compare::Base en une.

Cet outil utilisera la fonction "\&convert" sur la spécification, puis produira une structure Test2::Compare::Delta qui décrira toutes les manières dont la structure obtenue dévie de la spécification.

\&convert
Convertit tout ce qui n'est pas une instance d'une sous-classe d'Test2::Compare::Base, et en fait une. Les objets qu'elle produit sont capables de vérifier qu'une structure correspond à une spécification.
$delta
Une instance de Test2::Compare::Delta est finalement renvoyée. Cet objet représente toutes les manières dont la structure obtenue dévie de la spécification. Le delta est un arbre et peut contenir des deltas enfants pour les structures imbriquées.

Le delta est capable de se représenter sous forme de tableau, utilisez "@lines = $delta->diag" pour obtenir le tableau (les lignes dans @lines ne seront pas terminées par "\n").

La fonction convert() fournie par ce paquet contient tout le comportement de spécification de like() et is(). Elle est destinée à être encapsulée dans une sous-routine qui passe un hash de configuration, ce qui vous permet de contrôler le comportement.

Vous êtes libre d'écrire votre propre fonction "$check = compare($thing)", elle doit simplement accepter un seul argument et produire une seule instance d'une sous-classe d'Test2::Compare::Base.
