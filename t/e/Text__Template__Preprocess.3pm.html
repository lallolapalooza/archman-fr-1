Text::Template::Preprocess(3) Documentation Perl Contribuée par les Utilisateurs Text::Template::Preprocess(3)

NOM

Text::Template::Preprocess - Étendre le texte de modèle avec du Perl intégré

VERSION

version 1.61

SYNOPSIS

use Text::Template::Preprocess;
my $t = Text::Template::Preprocess->new(...);  # identique à Text::Template
# Remplir le modèle, mais prétraiter chaque fragment de code avec pp().
my $result = $t->fill_in(..., PREPROCESSOR => \&pp);
my $old_pp = $t->preprocessor(\&new_pp);

DESCRIPTION

"Text::Template::Preprocess" fournit une nouvelle option "PREPROCESSOR" à "fill_in". Si l'option "PREPROCESSOR" est fournie, elle doit être une référence à une sous-routine de prétraitement. Lors du remplissage d'un modèle, "Text::Template::Preprocessor" utilisera cette sous-routine pour prétraiter le fragment de programme avant d'évaluer le code.

La sous-routine de prétraitement sera appelée de manière répétée, une fois pour chaque fragment de programme. Le fragment de programme sera dans $_. La sous-routine doit modifier le contenu de $_ et retourner. "Text::Template::Preprocess" exécutera alors le contenu de $_ et insérera le résultat dans la partie appropriée du modèle.

"Text::Template::Preprocess" prend également en charge une méthode utilitaire, preprocessor(), qui définit un nouveau prétraiteur pour l'objet. Ce prétraiteur est utilisé pour tous les appels ultérieurs à "fill_in", sauf s'il est remplacé par une option explicite "PREPROCESSOR". preprocessor() retourne la fonction de prétraitement par défaut précédente, ou indéfini s'il n'y en avait pas. Lorsqu'elle est appelée sans arguments, preprocessor() retourne la fonction de prétraitement par défaut actuelle de l'objet sans la modifier.

À tous autres égards, "Text::Template::Preprocess" est identique à "Text::Template".

POURQUOI ?

Un usage possible : si vos fichiers contiennent beaucoup de JavaScript, comme ceci :

Texte brut ici...
{ code perl }
<script language=JavaScript>
      if (br== "n3") { 
          // etc.
      }
</script>
{ plus de code perl }
Plus de texte brut...

Vous ne voulez pas que "Text::Template" confonde les accolades du programme JavaScript avec du code Perl exécutable. Une stratégie :

sub quote_scripts {
  s(<script(.*?)</script>)(q{$1})gsi;
}

Utilisez ensuite "PREPROCESSOR => \&quote_scripts". Cela transformera
