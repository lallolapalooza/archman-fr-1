NOM

Text::BibTeX::Bib - définit la structure de base de données "Bib"

SYNOPIS

$bibfile = Text::BibTeX::File $filename->new;
$bibfile->set_structure ('Bib',
                         # Valeurs d'options par défaut :
                         sortby => 'name',
                         namestyle => 'full'
                         nameorder => 'first',
                         atitle => 1,
                         labels => 'numeric');
# Valeurs d'options alternatives :
$bibfile->set_option (sortby => 'year');
$bibfile->set_option (namestyle => 'nopunct');
$bibfile->set_option (namestyle => 'nospace');
$bibfile->set_option (nameorder => 'last');
$bibfile->set_option (atitle => 0);   
$bibfile->set_option (labels => 'alpha');   # pas encore implémenté !
# analyse une entrée à partir de $bibfile et en fait automatiquement une BibEntry
$entry = Text::BibTeX::Entry->new($bibfile);
# ou obtient une entrée d'ailleurs qui est codée en dur pour être
# une BibEntry
$entry = Text::BibTeX::BibEntry->new(...);
$sortkey = $entry->sort_key;
@blocks = $entry->format;

DESCRIPTION

(NOTE ! Ne croyez pas tout ce que vous lisez dans ce document. Les classes décrites ici ne sont pas terminées et ont été peu testées. L'implémentation actuelle est une preuve de principe, pour me convaincre moi-même (et quiconque pourrait être intéressé) qu'il est réellement possible de réimplémenter BibTeX 0.99 en Perl en utilisant les classes principales de "Text::BibTeX" ; ce principe est vaguement démontré par les modules actuels "Bib*", mais pas vraiment prouvé. De nombreuses fonctionnalités importantes nécessaires pour réimplémenter les styles standards de BibTeX 0.99 sont manquantes, même si ce document peut l'affirmer avec arrogance. Si vous êtes intéressé par l'utilisation de ces classes, vous devriez commencer par lire et comprendre le code, et contribuer les éléments manquants dont vous avez besoin.)

"Text::BibTeX::Bib" implémente la structure de base de données pour les bibliographies telle que définie par les styles standards de BibTeX 0.99. Il le fait en fournissant deux classes, "BibStructure" et "BibEntry" (le préfixe "Text::BibTeX" est implicite, et sera omis pour le reste de ce document). Ces deux classes, étant spécifiques aux données bibliographiques, sont en dehors de la hiérarchie de classes principale de "Text::BibTeX", mais sont distribuées avec elle car elles fournissent un exemple canonique d'une structure de base de données spécifique utilisant des classes dérivées de la hiérarchie principale.

"BibStructure", qui dérive de la classe "Structure", traite de la structure dans son ensemble : elle gère les options de structure et décrit tous les types et champs qui composent la structure de la base de données. Si vous êtes intéressé par l'écriture de vos propres modules de structure de base de données, l'interface standard pour les deux est décrite dans Text::BibTeX::Structure ; si vous êtes simplement intéressé par la structure exacte de la base de données ou par les options prises en charge par la structure "Bib", vous êtes au bon endroit. (Cependant, vous devrez peut-être parcourir un peu de verbiage excessif en raison du double objectif de ce module : premièrement, réimplémenter les styles standards de BibTeX 0.99, et deuxièmement, fournir un exemple pour d'autres programmeurs souhaitant implémenter de nouveaux modules de structure de base de données ou des modules dérivés.)

"BibEntry" dérive de la classe "StructuredEntry" et fournit des méthodes qui opèrent sur des entrées individuelles présumées provenir d'une base de données conforme à la structure définie par la classe "BibStructure". (En fait, pour être totalement précis, "BibEntry" hérite de deux classes intermédiaires, "BibSort" et "BibFormat". Ces deux classes existent simplement pour réduire la quantité de code dans le module "Bib", et grâce à la magie de l'héritage, leur existence est généralement sans importance. Mais vous pourriez vouloir consulter ces deux classes si vous êtes intéressé par les détails complexes du tri et du formatage des entrées des bases de données bibliographiques de type BibTeX 0.99.)

OPTIONS DE STRUCTURE

"BibStructure" gère plusieurs "options de structure" fournies par l'utilisateur et des méthodes pour les traiter. Les options actuellement prises en charge par la structure de base de données "Bib", et les valeurs autorisées pour elles, sont :

"sortby"
Comment trier les entrées. Valeurs valides : "name" (trier par noms d'auteurs, année et titre), "year" (trier par année, noms d'auteurs et titre). Le tri par "noms d'auteurs" est un peu plus compliqué que la simple utilisation du champ "author" ; voir Text::BibTeX::BibSort pour les détails. Valeur par défaut : "name".
"namestyle"
Comment imprimer les noms d'auteurs (et d'éditeurs) : "full" pour les prénoms non abrégés, "abbrev" pour les prénoms abrégés avec des points, "nopunct" pour les prénoms abrégés avec un espace mais sans points, et "nospace" pour abréger sans espace ni points. Valeur par défaut : "full".
"nameorder"
L'ordre dans lequel imprimer les noms : "first" pour l'ordre "prénom von nom jr", et "last" pour l'ordre "von nom jr prénom". Valeur par défaut : "first".
"atitle_lower"
Une option booléenne : si vrai, les titres autres que ceux des livres seront mis en "capitalisation de phrase :" les mots suivant les deux-points et la ponctuation de fin de phrase seront capitalisés, et tout le reste à la profondeur d'accolade zéro sera mis en minuscules. Valeur par défaut : vrai.
"labels"
Le type d'étiquettes bibliographiques à générer : "numeric" ou "alpha". (Les étiquettes alphabétiques ne sont pas encore implémentées, donc cette option est actuellement ignorée.) Valeur par défaut : "numeric".

De plus, plusieurs "options de balisage" sont prises en charge. Les options de balisage sont distinctes car elles ne modifient pas la façon dont le texte est extrait des entrées de la base de données et ensuite traité ; plutôt, elles fournissent des fragments de balisage qui entourent le texte dérivé de la base de données. Les options de balisage sont toujours des listes à deux éléments : le premier pour "activer" une fonctionnalité du langage de balisage, et le second pour la désactiver. Par exemple, si votre langage cible est LaTeX2e et que vous souhaitez mettre en évidence les noms de revues, vous fourniriez une référence de liste "['\emph{','}']" pour l'option "journal_mkup". Si vous génériez plutôt du HTML, vous pourriez fournir "['<emph>','</emph>']". Pour maintenir le module de structure général par rapport aux langages de balisage, toutes les options de balisage sont vides par défaut. (Ou, plus précisément, elles sont toutes des références à des listes composées de deux chaînes vides.)

"name_mkup"
Balisage à ajouter autour de la liste des noms d'auteurs.
"atitle_mkup"
Balisage à ajouter autour des titres autres que ceux des livres (articles).
"btitle_mkup"
Balisage à ajouter autour des titres de livres.
"journal_mkup"
Balisage à ajouter autour des noms de revues.

Méthodes d'option

Comme requis par le module "Text::BibTeX::Structure", "Text::BibTeX::Bib" fournit deux méthodes pour gérer les options : "known_option" et "default_option". (Les deux autres méthodes d'option, "set_options" et "get_options", sont simplement héritées de "Text::BibTeX::Structure".)

known_option (OPTION)
Retourne vrai si OPTION est l'une des options de la liste ci-dessus.
default_option (OPTION)
Retourne la valeur par défaut de OPTION.

NAME

Text::BibTeX::Bib - The BibTeX database structure

SYNOPSIS

    use Text::BibTeX;
    my $entry = Text::BibTeX::BibEntry->new(
        type    => 'article',
        key     => 'smith97',
        author  => 'Smith, John Q.',
        title   => 'An Interesting Paper',
        journal => 'Journal of Things',
        year    => 1997,
    );
    print $entry->format('plain');
    print $entry->sort_key();

DESCRIPTION

This module implements the standard BibTeX database structure. It provides a class "BibEntry" that represents a single BibTeX entry, and defines the recognized entry types and fields.

This module is intended primarily as an internal component of the Text::BibTeX module. For most users, importing Text::BibTeX should be sufficient.

METHODS

default_option( OPTION )
Returns the default value of OPTION, or "croak"s if OPTION is not a supported option.

DATABASE STRUCTURE

The other purpose of a structure class is to provide a method, "describe_entry", that lists the allowed entry types and the known fields for the structure. Programmers wishing to write their own database structure module should consult Text::BibTeX::Structure for the conventions and requirements of this method; the purpose of the present document is to describe the "Bib" database structure.

The allowed entry types, and the fields recognized for them, are:

"article"
Required fields: "author", "title", "journal", "year". Optional fields: "volume", "number", "pages", "month", "note".
"book"
Required fields: "title", "publisher", "year". Optional fields: "series", "address", "edition", "month", "note". Constrained fields: exactly one of "author", "editor"; at most one of "volume", "number".
"booklet"
Required fields: "title". Optional fields: "author", "howpublished", "address", "month", "year", "note".
"inbook"
Required fields: "publisher", "year". Optional fields: "series", "type", "address", "edition", "month", "note". Constrained fields: exactly one of "author", "editor"; at least one of "chapter", "pages"; at most one of "volume", "number".
"incollection"
Required fields: "author", "title", "booktitle", "publisher", "year". Optional fields: "editor", "series", "type", "chapter", "pages", "address", "edition", "month", "note". Constrained fields: at most one of "volume", "number".
"inproceedings"
"conference"
Required fields: "author", "title", "booktitle", "year". Optional fields: "editor", "series", "pages", "address", "month", "organization", "publisher", "note". Constrained fields: at most one of "volume", "number".
"manual"
Required fields: "title". Optional fields: "author", "organization", "address", "edition", "month", "year", "note".
"mastersthesis"
Required fields: "author", "title", "school", "year". Optional fields: "type", "address", "month", "note".
"misc"
Required fields: none. Optional fields: "author", "title", "howpublished", "month", "year", "note".
"phdthesis"
Required fields: "author", "title", "school", "year". Optional fields: "type", "address", "month", "note".
"proceedings"
Required fields: "title", "year". Optional fields: "editor", "series", "address", "month", "organization", "publisher", "note". Constrained fields: at most one of "volume", "number".
"techreport"
Required fields: "author", "title", "institution", "year". Optional fields: "type", "number", "address", "month", "note".
"unpublished"
Required fields: "author", "title", "note". Optional fields: "month", "year".

STRUCTURED ENTRY CLASS

The second class provided by the "Text::BibTeX::Bib" module is "BibEntry" (again, a leading "Text::BibTeX" is implied). This being a structured entry class, it derives from "StructuredEntry". The conventions and requirements for such a class are documented in Text::BibTeX::Structure for the benefit of programmers implementing their own structure modules.

If you wish to write utilities making use of the "Bib" database structure, then you should call one of the "officially supported" methods provided by the "BibEntry" class. Currently, there are only two of these: "sort_key" and "format". These are actually implemented in the "BibSort" and "BibFormat" classes, respectively, which are base classes of "BibEntry". Thus, see Text::BibTeX::BibSort and Text::BibTeX::BibFormat for details on these two methods.

SEE ALSO

Text::BibTeX::Structure, Text::BibTeX::BibSort, Text::BibTeX::BibFormat.

DESCRIPTION

Cette page de manuel décrit l'interface de programmation de Text::BibTeX::Bib, une classe Perl conçue pour manipuler des fichiers BibTeX.

Text::BibTeX::Bib fournit des méthodes pour lire, écrire et modifier des entrées dans des fichiers BibTeX. Il permet de parser la structure d'un fichier BibTeX et de la représenter sous forme d'objets Perl manipulables.

STRUCTURE OPTIONS

La classe Text::BibTeX::Bib et ses classes associées prennent en charge diverses options de configuration pour contrôler le comportement lors de la lecture et de l'écriture des fichiers BibTeX. Ces options peuvent inclure la gestion des erreurs, le formatage de sortie, et la prise en charge de champs spécifiques.

Parmi les options courantes, on peut trouver :

  • CaseSensitive : Pour gérer la sensibilité à la casse des clés d'entrée.
  • HandleDuplicates : Pour spécifier comment gérer les entrées dupliquées.
  • SortOrder : Pour définir l'ordre de tri des entrées.

Ces options sont généralement passées lors de l'instanciation de l'objet Bib ou lors de l'appel de méthodes spécifiques.

STRUCTURE DE BASE DE DONNÉES

Un fichier BibTeX est essentiellement une collection d'entrées. Chaque entrée est définie par un type (par exemple, @article, @book) suivi d'une clé unique et d'une liste de paires champ-valeur.

Text::BibTeX::Bib représente cette structure comme un objet qui contient une liste d'entrées. Chaque entrée est elle-même un objet (généralement une instance de Text::BibTeX::Entry) qui stocke le type, la clé et les champs de l'entrée BibTeX.

La structure de données interne peut être vue comme :

BibTeX::Bib Object
  - List of BibTeX::Entry Objects
    - BibTeX::Entry Object
      - Type (e.g., "article")
      - Key (e.g., "smith2023")
      - Hash of Fields
        - Field Name (e.g., "title")
        - Field Value (e.g., "A Study on Perl")

CLASSE D'ENTRÉE STRUCTURÉE

La classe principale pour représenter une seule entrée BibTeX est généralement Text::BibTeX::Entry. Chaque objet Entry encapsule les informations d'une entrée BibTeX, y compris :

  • Le type de l'entrée (par exemple, article, book, inproceedings).
  • La clé d'une entrée (l'identifiant unique utilisé pour référencer l'entrée).
  • Un ensemble de champs et leurs valeurs correspondantes (par exemple, author, title, year, publisher).

Des méthodes sont fournies pour accéder et modifier ces composants. Par exemple, vous pouvez récupérer le titre d'une entrée en appelant une méthode comme $entry->{'title'} ou $entry->title(), selon l'implémentation spécifique.
