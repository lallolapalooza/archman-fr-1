NOM

Template::Plugin::Procedural - Classe de base pour les plugins procéduraux

SYNTAXE

package Template::Plugin::LWPSimple;
use base qw(Template::Plugin::Procedural);
use LWP::Simple;  # exporte 'get'
1;
[% USE LWPSimple %]
[% LWPSimple.get("http://www.tt2.org/") %]

DESCRIPTION

"Template::Plugin::Procedural" est une classe de base pour les plugins de Template Toolkit qui provoque l'appel direct des sous-routines définies plutôt que comme une méthode. Essentiellement, cela signifie que les sous-routines ne recevront pas le nom de classe ou l'objet comme premier argument.

Ceci est particulièrement utile lors de la création de plugins pour des modules qui fonctionnent normalement en exportant des sous-routines qui ne s'attendent pas à de tels arguments supplémentaires.

Malgré le fait que les sous-routines ne seront pas appelées de manière OO, l'héritage fonctionne normalement. Une classe qui utilise "Template::Plugin::Procedural" peut être sous-classée et les sous-routines définies dans la sous-classe ainsi que les sous-routines définies dans la classe d'origine seront disponibles pour le Template Toolkit et seront appelées sans l'argument classe/objet.
