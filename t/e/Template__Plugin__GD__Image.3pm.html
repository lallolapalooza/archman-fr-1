NOM

Template::Plugin::GD::Image - Interface à la bibliothèque graphique GD

SYNTAXE

[% USE im = GD.Image(largeur, hauteur) %]

EXEMPLES

[% FILTER null;
    USE gdc = GD.Constants;
    USE im  = GD.Image(200,100);
    noir = im.colorAllocate(0  ,0,  0);
    rouge   = im.colorAllocate(255,0,  0);
    r = im.string(gdc.gdLargeFont, 10, 10, "Texte rouge grand", rouge);
    im.png | stdout(1);
   END;
-%]
[% FILTER null;
    USE im = GD.Image(100,100);
    # allouer quelques couleurs
    noir = im.colorAllocate(0,   0, 0);
    rouge   = im.colorAllocate(255,0,  0);
    bleu  = im.colorAllocate(0,  0,  255);
    # Dessiner un ovale bleu
    im.arc(50,50,95,75,0,360,bleu);
    # Et le remplir en rouge
    im.fill(50,50,rouge);
    # Sortie de l'image binaire au format PNG
    im.png | stdout(1);
   END;
-%]
[% FILTER null;
    USE im   = GD.Image(100,100);
    USE c    = GD.Constants;
    USE poly = GD.Polygon;
    # allouer quelques couleurs
    blanc = im.colorAllocate(255,255,255);
    noir = im.colorAllocate(0,  0,  0);
    rouge   = im.colorAllocate(255,0,  0);
    bleu  = im.colorAllocate(0,  0,255);
    vert = im.colorAllocate(0,  255,0);
    # rendre l'arrière-plan transparent et entrelacé
    im.transparent(blanc);
    im.interlaced('true');
    # Mettre un cadre noir autour de l'image
    im.rectangle(0,0,99,99,noir);
    # Dessiner un ovale bleu
    im.arc(50,50,95,75,0,360,bleu);
    # Et le remplir en rouge
    im.fill(50,50,rouge);
    # Dessiner un triangle bleu
    poly.addPt(50,0);
    poly.addPt(99,99);
    poly.addPt(0,99);
    im.filledPolygon(poly, bleu);
    # Sortie de l'image binaire au format PNG
    im.png | stdout(1);
   END;
-%]

DESCRIPTION

Le plugin GD.Image fournit une interface à la classe GD::Image de GD.pm. La classe GD::Image est l'interface principale de GD.pm.

Il est très important qu'aucune sortie de modèle superflue n'apparaisse avant ou après l'image. Comme certaines méthodes retournent des valeurs qui apparaîtraient autrement dans la sortie, il est recommandé d'envelopper le code GD.Image dans un filtre null. Les méthodes qui produisent la sortie finale (par exemple, png, jpeg, gd, etc.) peuvent alors explicitement faire apparaître leur sortie en utilisant le filtre stdout, avec un argument non nul pour forcer le mode binaire (requis pour les systèmes d'exploitation non modernes).

Voir GD pour une description complète de la bibliothèque GD et de toutes les méthodes qui peuvent être appelées via le plugin GD.Image. Voir Template::Plugin::GD::Constants pour un plugin qui vous donne accès aux constantes de GD.pm.
