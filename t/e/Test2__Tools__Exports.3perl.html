Test2::Tools::Exports(3perl) Guide de référence des programmeurs Perl Test2::Tools::Exports(3perl)

NOM

Test2::Tools::Exports - Outils pour valider les exportateurs.

DESCRIPTION

Ce sont des outils pour vérifier que des symboles ont été importés dans votre espace de noms.

SYNTAXE

use Test2::Tools::Exports
use Data::Dumper;
imported_ok qw/Dumper/;
not_imported_ok qw/dumper/;

EXPORTATIONS

Toutes les sous-routines sont exportées par défaut.

imported_ok(@SYMBOLS)
Vérifie que les symboles spécifiés existent dans le paquet courant. Ceci ne trouvera pas les sous-routines héritées. Ceci ne trouvera que les symboles dans la table des symboles du paquet courant. Ceci ne confirmera **PAS** que les symboles ont été définis en dehors du paquet lui-même. 
imported_ok( '$scalaire', '@tableau', '%hash', '&sub', 'une_autre_sub' );

@SYMBOLS peut contenir n'importe quel nombre de symboles. Chaque élément du tableau doit être une chaîne de caractères. La chaîne doit être le nom d'un symbole. Si un sigil est présent, il recherchera ce type spécifié, sinon il sera utilisé comme nom de sous-routine.

not_imported_ok(@SYMBOLS)
Vérifie que les symboles spécifiés n'existent pas dans le paquet courant. Ceci ne trouvera pas les sous-routines héritées. Ceci ne regardera que les symboles dans la table des symboles du paquet courant. 
not_imported_ok( '$scalaire', '@tableau', '%hash', '&sub', 'une_autre_sub' );

@SYMBOLS peut contenir n'importe quel nombre de symboles. Chaque élément du tableau doit être une chaîne de caractères. La chaîne doit être le nom d'un symbole. Si un sigil est présent, il recherchera ce type spécifié. S'il n'y a pas de sigil, il sera utilisé comme nom de sous-routine.

ATTENTION

Avant Perl 5.10, il est très difficile de distinguer entre un scalaire de paquet non déclaré et un scalaire déclaré et indéfini. Actuellement, "imported_ok" et "not_imported_ok" ne peuvent pas voir les scalaires de paquet déclarés en utilisant "our $var", sauf si la variable s'est vu attribuer une valeur définie.

Ceci passera sur les versions récentes de Perl, mais échouera sur les versions plus anciennes que 5.10 :

use Test2::Tools::Exports;
our $foo;
# Échoue sur Perl plus ancien que 5.10
imported_ok(qw/$foo/);

Si $foo est importé d'un autre module, ou importé en utilisant "use vars qw/$foo/;" alors cela fonctionnera sur toutes les versions de Perl prises en charge.

use Test2::Tools::Exports;
use vars qw/$foo/;
use Some::Module qw/$bar/;
# Fonctionne toujours
imported_ok(qw/$foo $bar/);
