Test2::EventFacet::Trace(3perl) Guide de référence du programmeur Perl Test2::EventFacet::Trace(3perl)

NOM

Test2::EventFacet::Trace - Informations de débogage pour les événements

DESCRIPTION

L'objet Test2::API::Context, ainsi que tous les types d'événements Test2::Event, doivent avoir accès aux informations sur l'endroit où ils ont été créés. Cet objet représente ces informations.

SYNTAXE D'EMPLOI

use Test2::EventFacet::Trace;
my $trace = Test2::EventFacet::Trace->new(
    frame => [$package, $file, $line, $subname],
);

CHAMP FACETTE

$string = $trace->{details}
$string = $trace->details()
Utilisé comme un message de trace personnalisé qui sera utilisé À LA PLACE de "at <FILE> line <LINE>" lors de l'appel de "$trace->debug".
$frame = $trace->{frame}
$frame = $trace->frame()
Récupère le tableau d'appel. 
[$package, $file, $line, $subname]
$int = $trace->{pid}
$int = $trace->pid()
L'identifiant du processus dans lequel l'événement a été généré.
$int = $trace->{tid}
$int = $trace->tid()
L'identifiant du thread dans lequel l'événement a été généré.
$id = $trace->{cid}
$id = $trace->cid()
L'identifiant du contexte qui a été utilisé pour créer l'événement.
$uuid = $trace->{uuid}
$uuid = $trace->uuid()
L'UUID du contexte qui a été utilisé pour créer l'événement. (Si le marquage UUID était activé)
($pkg, $file, $line, $subname) = $trace->call
Récupère les informations d'appel de base sous forme de liste.
@caller = $trace->full_call
Récupère les résultats complets de caller(N).
$warning_bits = $trace->warning_bits
Récupère l'index 9 des informations complètes de caller. C'est le champ warnings_bits.

La valeur de ceci n'est pas portable entre les versions de Perl ni même entre les processus. Cependant, elle peut être utilisée dans le processus qui l'a généré pour reproduire les paramètres d'avertissement dans un nouveau périmètre.

eval <<EOT;
BEGIN { ${^WARNING_BITS} = $trace->warning_bits };
... les paramètres d'avertissement du contexte s'appliquent ici ...
EOT

CHAMPS DU HUB DÉCONSEILLÉS

Ces champs n'étaient pas toujours correctement définis par les outils. Ils sont EN GRANDE PARTIE obsolètes par les facettes Test2::EventFacet::Hub. Ces champs ne sont pas obligatoires et peuvent seulement refléter le hub qui était courant lors de la création de l'événement, ce qui n'est pas nécessairement le même que le hub à travers lequel l'événement a été envoyé.

Certains outils ont fait un bon travail en définissant ces champs pour qu'ils correspondent au bon hub, mais vous ne pouvez pas toujours vous y fier. Utilisez plutôt la liste de facettes 'hubs'.

$hid = $trace->{hid}
$hid = $trace->hid()
L'identifiant du hub qui était courant lors de la création de l'événement.
$huuid = $trace->{huuid}
$huuid = $trace->huuid()
L'UUID du hub qui était courant lors de la création de l'événement. (Si le marquage UUID était activé).
$int = $trace->{nested}
$int = $trace->nested()
Le niveau d'imbrication de l'événement.
$bool = $trace->{buffered}
$bool = $trace->buffered()
Vrai si l'événement a été mis en mémoire tampon et non envoyé au formateur indépendamment d'un parent (Ceci ne devrait jamais être défini lorsque nested est 0 ou "undef").

MÉTHODES

Note: Tous les cadres de facette sont également des méthodes.

$trace->set_detail($msg)
$msg = $trace->detail
Utilisé pour obtenir/définir un message de trace personnalisé qui sera utilisé À LA PLACE de "at <FILE> line <LINE>" lors de l'appel de "$trace->debug".

detail() est un alias du champ de facette "details" pour la compatibilité ascendante.

$str = $trace->debug
Retourne typiquement la chaîne "at <FILE> line <LINE>". Si "detail" est défini, sa valeur sera retournée à la place.
$trace->alert($MESSAGE)
Ceci émet un avertissement au niveau du cadre (nom de fichier et numéro de ligne où les erreurs doivent être signalées).
$trace->throw($MESSAGE)
Ceci lève une exception au niveau du cadre (nom de fichier et numéro de ligne où les erreurs doivent être signalées).
($package, $file, $line, $subname) = $trace->call()
Récupère les détails de l'appel pour les informations de débogage. C'est là que les erreurs doivent être signalées.
$pkg = $trace->package
Récupère le package d'informations de débogage.
$file = $trace->file
Récupère le nom de fichier des informations de débogage.
$line = $trace->line
Récupère le numéro de ligne des informations de débogage.
$subname = $trace->subname
Récupère le nom de la sous-routine des informations de débogage.
$sig = trace->signature
Récupère une chaîne de signature qui identifie cette trace. Ceci est utilisé pour vérifier si plusieurs événements sont liés. La signature comprend le PID, le TID, le fichier, le numéro de ligne et le CID.
