NOM

Term::UI::History - fonction d'historique

SYNTAXE

use Term::UI::History qw[history];
history("Un message");
### récupérer l'historique sous forme imprimable
$hist  = Term::UI::History->history_as_string;
### rediriger la sortie
local $Term::UI::History::HISTORY_FH = \*STDERR;

DESCRIPTION

Ce module fournit la fonction "history" pour "Term::UI", imprimant et sauvegardant toutes les interactions de "UI".

Consultez la page de manuel "Term::UI" pour les détails sur l'utilisation depuis "Term::UI".

Ce module hérite de "Log::Message::Simple". Consultez sa page de manuel pour des fonctionnalités supplémentaires disponibles via ce paquet.

FONCTIONS

history("chaine message" [,VERBEUX])

Enregistre un message dans la pile, et l'imprime sur "STDOUT" (ou en fait $HISTORY_FH, voir la section "VARIABLES GLOBALES" ci-dessous), si l'option "VERBEUX" est vraie.

L'option "VERBEUX" est vraie par défaut.

VARIABLES GLOBALES

$HISTORY_FH
C'est le descripteur de fichier sur lequel tous les messages envoyés à history() sont imprimés. Cela vaut *STDOUT par défaut.

Voir aussi

"Log::Message::Simple", "Term::UI"
