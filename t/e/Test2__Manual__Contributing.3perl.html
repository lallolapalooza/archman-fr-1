NOM

Test2::Manual::Contributing - Comment contribuer au projet Test2.

DESCRIPTION

Ceci est une courte page de manuel dédiée à aider les personnes qui souhaitent contribuer au projet Test2.

FAÇONS D'AIDÉES

SIGNALEZ LES BOGUES

La façon la plus simple d'aider est de signaler les bogues lorsque vous en trouvez. Les bogues sont une réalité lors de l'écriture ou de l'utilisation de logiciels. Si vous utilisez Test2 suffisamment longtemps, vous êtes susceptible de trouver un bogue. Lorsque vous trouvez un tel bogue, cela nous aiderait si vous soumettiez un ticket.

SUIVEURS DE BOGUES

Essayez toujours de trouver le suiveur de bogues préféré pour le module qui a le bogue. Voici les 3 principaux pour le projet principal Test2 :

Test2/Test-Builder/Test-More/test-more
https://github.com/Test-More/test-more/issues
Test2-Harness
https://github.com/Test-More/Test2-Harness/issues

SOUMETTEZ DES PATCHS

Vous êtes invité à corriger les bogues que vous trouvez, ou ceux du suiveur. Nous acceptons également souvent des patchs qui ajoutent de nouvelles fonctionnalités ou mettent à jour la documentation. La méthode préférée pour soumettre des patchs est une pull request github, cela dit nous acceptons également des patchs par e-mail.

AJOUTEZ/METTEZ À JOUR LA DOCUMENTATION

La documentation peut être erronée tout comme le code. La documentation peut également devenir obsolète. Si vous voyez une documentation incorrecte, ou une documentation manquante, nous serions ravis de recevoir un patch pour la corriger !

RÉPONDEZ AUX QUESTIONS SUR IRC/SLACK

Nous sommes toujours présents sur <irc://irc.perl.org>, les canaux #perl-qa et #toolchain sont de bons endroits pour nous trouver.

Il existe également un canal Slack Test2 : https://perl-test2.slack.com.

ÉCRIVEZ DE NOUVEAUX OUTILS UTILISANT TEST2

Écrire un nouvel outil utilisant Test2 est toujours une bonne façon de contribuer. Lorsque vous écrivez un outil que vous jugez utile, il est agréable de le partager en le mettant sur CPAN.

PORTEZ LES VIEUX OUTILS SUR TEST2

L'espace de noms "Test::*" existe depuis longtemps, et il contient BEAUCOUP d'outils. L'espace de noms "Test2::Tools::*" est assez jeune, et contient moins d'outils. Trouver un vieil outil utile sans équivalent moderne, et écrire un port est une très bonne utilisation de votre temps.
