Test__MinimumVersion(3pm)

Paquet: perl-test-minimumversion

Licences: PerlArtistic

Test::MinimumVersion(3pm) Documentation Perl fournie par l'utilisateur Test::MinimumVersion(3pm)

NOM

Test::MinimumVersion - votre code nécessite-t-il une version de Perl plus récente que vous ne le pensez ?

VERSION

version 0.101083

SYNOPSIS

Exemple de fichier minimum-perl.t :

#!perl
use Test::MinimumVersion;
all_minimum_version_ok('5.008');

VERSION PERL

Cette bibliothèque devrait fonctionner sur des versions de Perl publiées même très longtemps auparavant. Elle devrait fonctionner sur toute version de Perl publiée au cours des dix dernières années.

Bien qu'elle puisse fonctionner sur des versions plus anciennes de Perl, aucune garantie n'est faite que la version minimale requise ne sera pas augmentée. La version peut être augmentée pour quelque raison que ce soit, et il n'est pas promis que des correctifs seront acceptés pour abaisser la version minimale requise de Perl.

FONCTIONS

minimum_version_ok

minimum_version_ok($fichier, $version);

Ce test réussit si le fichier donné ne semble pas nécessiter de version de Perl plus récente que $version, qui peut être donnée sous forme de chaîne de version ou d'objet de version.

all_minimum_version_ok

all_minimum_version_ok($version, \%arg);

Étant donné une chaîne de version ou un objet de version, cette routine produit un plan de test (s'il n'y a pas de plan) et teste chaque fichier pertinent avec "minimum_version_ok".

Les fichiers pertinents sont trouvés par File::Find::Rule::Perl.

"\%arg" est facultatif. Les arguments valides sont :

paths   - dans quels chemins rechercher les fichiers ; par défaut (bin, script, t, lib,
          xt/smoke, et tous les fichiers .pm ou .PL dans le répertoire de travail actuel)
          s'il contient des fichiers, ils seront vérifiés
no_plan - ne pas planifier les tests à exécuter
skip    - fichiers à ignorer ; cela peut être utile dans des cas particuliers comme des fichiers gigantesques,
          des fichiers faussement détectés comme Perl, ou du code qui utilise un filtre source ;
          ceci devrait être un arborescence de noms de fichiers

all_minimum_version_from_metayml_ok

all_minimum_version_from_metayml_ok(\%arg);

Cette routine vérifie META.yml pour une entrée dans requires pour perl. Si aucun fichier META.yml ou aucune version de Perl n'est trouvée, tous les tests sont ignorés. Si une version est trouvée, le test se poursuit comme si "all_minimum_version_ok" avait été appelée avec cette version.
