Test2::Tools::Warnings(3perl) Guide de référence du programmeur Perl Test2::Tools::Warnings(3perl)

NOM

Test2::Tools::Warnings - Outils pour vérifier les avertissements.

DESCRIPTION

Ceci est une collection d'outils qui peuvent être utilisés pour tester du code qui génère des avertissements.

SYNOPSIS

use Test2::Tools::Warnings qw/warns warning warnings no_warnings/;
ok(warns { warn 'a' }, "le code émet un avertissement");
ok(!warns { 1 }, "Le code n'émet pas d'avertissement");
is(warns { warn 'a'; warn 'b' }, 2, "2 avertissements reçus");
ok(no_warnings { ... }, "le code n'a pas émis d'avertissement");
like(
    warning { warn 'xxx' },
    qr/xxx/,
    "Avertissement attendu reçu"
);
is(
    warnings { warn "a\n"; warn "b\n" },
    [
        "a\n",
        "b\n",
    ],
    "2 avertissements spécifiques reçus"
);

EXPORTS

Toutes les sous-routines sont exportées par défaut.

$count = warns { ... }
Retourne le nombre d'avertissements produits par le bloc. Ceci retournera toujours 0 ou un entier positif.
$warning = warning { ... }
Retourne le premier avertissement généré par le bloc. Si le bloc produit plus d'un avertissement, ils seront tous affichés comme des notes, et un avertissement réel vous en informera.
$warnings_ref = warnings { ... }
Retourne une référence de tableau avec tous les avertissements produits par le bloc. Ceci retournera toujours une référence de tableau. S'il n'y a pas d'avertissements, ceci retournera une référence de tableau vide.
$bool = no_warnings { ... }
Retourne vrai si le bloc n'a pas d'avertissements. Retourne faux s'il y a des avertissements.
