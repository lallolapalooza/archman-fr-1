NOM

Template::Plugin::Scalar - appeler des méthodes d'objet dans un contexte scalaire

SYNTAXE

[% USE scalar %]
# TT2 appelle les méthodes d'objet dans un contexte de tableau par défaut
[% object.method %]
# forcer l'utilisation du contexte scalaire
[% object.scalar.method %]
# fonctionne aussi avec les références de sous-routines
[% scalar.my_sub_ref %]

DESCRIPTION

Le Template Toolkit appelle les sous-routines et méthodes d'objet définies par l'utilisateur en utilisant le contexte de tableau de Perl par défaut. Ce module de plugin fournit un moyen pour vous d'appeler des sous-routines et des méthodes dans un contexte scalaire.
