Test2::Tools::Defer(3perl) Guide du programmeur Perl Test2::Tools::Defer(3perl)

NOM

Test2::Tools::Defer - Écrire des tests qui seront exécutés plus tard

DESCRIPTION

Parfois, vous avez besoin de tester des choses AVANT de charger les fonctions nécessaires. Ce module vous permet de le faire. Vous pouvez écrire des tests, puis les faire exécuter plus tard, une fois que "Test2" est chargé. Vous lui indiquez quelle fonction de test exécuter et quels arguments lui donner. Le nom de la fonction et les arguments seront stockés pour être exécutés plus tard. Lorsque vous êtes prêt, exécutez do_def() pour les lancer une fois les fonctions définies.

SYNTAXE

use strict;
use warnings;
use Test2::Tools::Defer;
BEGIN {
    def ok => (1, 'pass');
    def is => ('foo', 'foo', 'runs is');
    ...
}
use Test2::Tools::Basic;
do_def(); # Exécuter les tests
# Déclarer d'autres tests à exécuter plus tard :
def ok => (1, "another pass");
...
do_def(); # exécuter les nouveaux tests
done_testing;

EXPORTATIONS

fonction def => @args;
Ceci stockera le nom de la fonction et les arguments à exécuter plus tard. Notez que chaque paquet a un stockage séparé des tests à exécuter.
do_def()
Ceci exécutera tous les tests stockés. Il réinitialisera également la liste pour qu'elle soit vide, vous permettant ainsi d'ajouter d'autres tests à exécuter encore plus tard.
