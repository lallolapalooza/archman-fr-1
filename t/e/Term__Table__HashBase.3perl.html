Term::Table::HashBase(3perl) Guide de référence du programmeur Perl Term::Table::HashBase(3perl)

NOM

Term::Table::HashBase - Construire des classes basées sur des hashs.

SYNOPSIS

Une classe :

package My::Class;
use strict;
use warnings;
# Générer 3 accesseurs
use Term::Table::HashBase qw/foo -bar ^baz <bat >ban +boo/;
# Occasion de définir des valeurs par défaut
sub init {
    my $self = shift;    # Pas d'autres arguments
    $self->{+FOO} ||= "foo";
    $self->{+BAR} ||= "bar";
    $self->{+BAZ} ||= "baz";
    $self->{+BAT} ||= "bat";
    $self->{+BAN} ||= "ban";
    $self->{+BOO} ||= "boo";
}
sub print {
    print join ", " => map { $self->{$_} } FOO, BAR, BAZ, BAT, BAN, BOO;
}

Sous-classez-la

package My::Subclass;
use strict;
use warnings;
# Note, vous devriez sous-classer avant de charger HashBase.
use base 'My::Class';
use Term::Table::HashBase qw/bub/;
sub init {
    my $self = shift;
    # Nous obtenons les constantes de la classe parente gratuitement.
    $self->{+FOO} ||= 'SubFoo';
    $self->{+BUB} ||= 'bub';
    $self->SUPER::init();
}

Utilisez-la :

package main;
use strict;
use warnings;
use My::Class;
# Ce sont toutes des fonctionnalités identiques
my $one   = My::Class->new(foo => 'MyFoo', bar => 'MyBar');
my $two   = My::Class->new({foo => 'MyFoo', bar => 'MyBar'});
my $three = My::Class->new(['MyFoo', 'MyBar']);
# Lecteurs !
my $foo = $one->foo;    # 'MyFoo'
my $bar = $one->bar;    # 'MyBar'
my $baz = $one->baz;    # Défini par défaut à : 'baz'
my $bat = $one->bat;    # Défini par défaut à : 'bat'
# '>ban' signifie uniquement un setter, pas de lecteur
# '+boo' signifie aucun setter ni lecteur, juste la constante BOO
# Setters !
$one->set_foo('Un Foo');
#'-bar' signifie lecture seule, donc le setter lèvera une exception (mais est défini).
$one->set_bar('Un bar');
# '^baz' signifie setter obsolète, cela émettra un avertissement indiquant que le setter est
# obsolète.
$one->set_baz('Un Baz');
# '<bat' ne définit aucun setter
# '+boo' signifie aucun setter ni lecteur, juste la constante BOO
$one->{+FOO} = 'xxx';

DESCRIPTION

Ce paquet est utilisé pour générer des classes basées sur des hashrefs. L'utilisation de cette classe vous fournira une méthode new(), ainsi que la génération des accesseurs que vous demandez. Les accesseurs générés seront des getters, des setters "set_ACCESSEUR" seront également générés pour vous. Vous obtenez également des constantes pour chaque accesseur (en majuscules) qui retournent la clé du hash pour cet accesseur. L'héritage simple est également supporté.

MÉTHODES

FOURNI PAR HASH BASE

$it = $class->new(%PAIRS)
$it = $class->new(\%PAIRS)
$it = $class->new(\@VALEURS_ORDONNÉES)
Crée une nouvelle instance.

HashBase n'exportera pas new() s'il existe déjà une méthode new() dans la chaîne d'héritage de votre package.

Si vous ne voulez pas de cette méthode, vous pouvez définir la vôtre il suffit de la déclarer avant de charger Term::Table::HashBase.

package My::Package;
# pré-déclarer new() afin que HashBase ne nous en fournisse pas une.
sub new;
use Term::Table::HashBase qw/foo bar baz/;
# Maintenant, nous définissons notre propre méthode new.
sub new { ... }

Cela permet à HashBase de voir que vous avez votre propre méthode new(). Alternativement, vous pouvez définir la méthode avant de charger HashBase au lieu de simplement la déclarer, mais cela disperse vos instructions `use`.

La manière la plus courante de créer un objet est de passer des paires clé/valeur où chaque clé est un attribut et chaque valeur est ce que vous voulez assigner à cet attribut. Aucune vérification n'est effectuée pour confirmer la validité des attributs ou des valeurs, vous pouvez le faire dans init() si désiré.

Si vous le souhaitez, vous pouvez passer un hashref au lieu de paires. Lorsque vous le faites, le hashref sera copié, et la copie sera retournée en tant qu'objet béni. Il n'y a aucun moyen de demander à HashBase de bénir un hashref spécifique.

Dans certains cas, un objet peut n'avoir que 1 ou 2 attributs, auquel cas un hashref peut être trop verbeux à votre goût. Dans ces cas, vous pouvez passer un arrayref avec seulement des valeurs. Les valeurs seront attribuées aux attributs dans l'ordre où les attributs ont été listés. Lorsque l'héritage est impliqué, les attributs des classes parentes viendront avant les sous-classes.

ACCROCHES

$self->init()
Cela vous donne la possibilité de définir des valeurs par défaut pour vos champs. Le seul argument est $self avec ses index déjà définis par le constructeur.

Note : Term::Table::HashBase vérifie la présence de `init` en utilisant "$class->can('init')" lors de la construction. Il n'appelle PAS can() sur l'objet créé. Notez également que le résultat de la vérification est mis en cache ; il n'est vérifié qu'une seule fois, la première fois qu'une instance de votre classe est créée. Cela signifie que l'ajout d'une méthode init() APRÈS la première construction entraînera son ignorance.

ACCESSEURS

LECTURE/ÉCRITURE

Pour générer des accesseurs, listez-les lors de l'utilisation du module :

use Term::Table::HashBase qw/foo/;

Cela générera les sous-routines suivantes dans votre espace de noms :

foo()
Getter, utilisé pour obtenir la valeur du champ "foo".
set_foo()
Setter, utilisé pour définir la valeur du champ "foo".
FOO()
Constante, retourne la clé du champ "foo" dans le hash de la classe. Les sous-classes recevront également cette fonction comme une constante, pas simplement une méthode ; cela signifie qu'elle est copiée dans l'espace de noms de la sous-classe.

La principale raison d'utiliser ces constantes est d'aider à éviter les fautes d'orthographe et les erreurs de frappe similaires. Cela ne vous aidera pas si vous oubliez de préfixer le '+' cependant.

LECTURE SEULE

use Term::Table::HashBase qw/-foo/;
set_foo()
Lève une exception indiquant que l'attribut est en lecture seule. Ceci est exporté pour remplacer tout setter actif pour l'attribut dans une classe parente.

SETTER OBSOLÈTE

use Term::Table::HashBase qw/^foo/;
set_foo()
Ceci définira la valeur, mais vous avertira également que la méthode est obsolète.

PAS DE SETTER

use Term::Table::HashBase qw/<foo/;

Ne fournit qu'un lecteur, aucune méthode "set_foo" n'est définie du tout.

PAS DE LECTEUR

use Term::Table::HashBase qw/>foo/;

Ne fournit qu'un setter ("set_foo"), aucune méthode "foo" n'est définie du tout.

CONSTANTE UNIQUEMENT

use Term::Table::HashBase qw/+foo/;

Cela ne crée aucune méthode pour vous, cela ajoute simplement la constante "FOO".

MÉTHODES

Term::Table::HashBase fournit une fonction pour récupérer une liste d'attributs pour une classe Term::Table::HashBase.

@list = Term::Table::HashBase::attr_list($class)
@list = $class->Term::Table::HashBase::attr_list()
L'une ou l'autre forme ci-dessus fonctionnera. Ceci retournera une liste d'attributs définis sur l'objet. Cette liste est retournée dans l'ordre de définition des attributs, les attributs de la classe parente sont listés avant les attributs de la sous-classe. Les attributs dupliqués seront supprimés avant que la liste ne soit retournée.
