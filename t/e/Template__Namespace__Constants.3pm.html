NOM

Template::Namespace::Constants - Pliage de constantes au moment de la compilation

SYNOPSIS

# manière simple de définir des constantes
use Template;
my $tt = Template->new({
    CONSTANTS => {
        pi => 3.14,
        e  => 2.718,
    },
});
# manière plus fine, plus concrète
use Template::Namespace::Constants;
my $tt = Template->new({
    NAMESPACE => {
        constants => Template::Namespace::Constants->new({
            pi => 3.14,
            e  => 2.718,
        },
    },
});

DESCRIPTION

Le module "Template::Namespace::Constants" implémente un gestionnaire d'espace de noms qui est intégré au module compilateur "Template::Directive". Il effectue alors un pliage de constantes au moment de la compilation des variables dans un espace de noms particulier.

MÉTHODES

new(\%constantes)

La méthode constructeur new() crée et retourne une référence à un nouvel objet Template::Namespace::Constants. Elle crée une réserve interne pour stocker les définitions de variables constantes passées en arguments.

my $handler = Template::Namespace::Constants->new({
    pi => 3.14,
    e  => 2.718,
});

ident(\@ident)

Méthode appelée pour résoudre un identifiant de variable en une forme compilée. Dans ce cas, la méthode récupère la valeur constante correspondante de sa réserve interne et la retourne.
