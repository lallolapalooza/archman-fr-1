Test2::Util::Grabber(3perl) Guide de référence du programmeur Perl Test2::Util::Grabber(3perl)

NOM

Test2::Util::Grabber - Objet utilisé pour intercepter temporairement tous les événements.

DESCRIPTION

Une fois créé, cet objet interceptera et stockera tous les événements envoyés à l'objet Test2::Hub partagé. Une fois l'objet détruit, les événements seront à nouveau envoyés au hub partagé.

SYNTAXE

use Test2 qw/Core Grab/;
my $grab = grab();
# Génère des événements, ils sont interceptés.
ok(1, "réussite");
ok(0, "échec");
my $events_a = $grab->flush;
# Génère d'autres événements, ils sont interceptés.
ok(1, "réussite");
ok(0, "échec");
# Identique à flush, sauf qu'il détruit l'objet grab.
my $events_b = $grab->finish;

Après avoir appelé finish(), l'objet grab est détruit et $grab est mis à undef. $events_a est un arrayref contenant les deux premiers événements. $events_b est un arrayref contenant les deux derniers événements.

EXPORTATIONS

$grab = grab()
Ceci vous permet d'intercepter tous les événements pour une section de code sans ajouter quoi que ce soit à votre pile d'appels. Ceci est utile pour les choses sensibles aux changements de profondeur de pile. 
my $grab = grab();
    ok(1, 'foo');
    ok(0, 'bar');
# $grab est magiquement undef après cela.
my $events = $grab->finish;
is(@$events, 2, "deux événements interceptés.");

Lorsque vous appelez finish(), l'objet $grab se mettra automagiquement à undef, mais uniquement pour la référence utilisée dans l'appel de méthode. Si vous avez d'autres références à l'objet $grab, elles ne seront pas mises à undef.

Si l'objet $grab est détruit sans appeler finish(), il se nettoiera automatiquement et restaurera le hub parent.

{
    my $grab = grab();
    # Les choses sont interceptées
}
# Les choses reviennent à la normale

Par défaut, le hub utilisé a "no_ending" défini sur vrai. Cela empêchera le hub d'exiger que vous ayez émis un plan et exécuté au moins un test. Vous pouvez réactiver la vérification comme ceci :

$grab->hub->set_no_ending(0);

Avec "no_ending" désactivé, "finish" exécutera les vérifications post-test pour appliquer le plan et s'assurer que des tests ont été exécutés. Dans de nombreux cas, cela entraînera des événements supplémentaires dans votre tableau d'événements.

MÉTHODES

$grab = $class->new()
Crée un nouvel objet grab, commence immédiatement à intercepter les événements.
$ar = $grab->flush()
Obtient un arrayref de tous les événements jusqu'à présent, vidant la liste interne de l'objet grab.
$ar = $grab->events()
Obtient un arrayref de tous les événements jusqu'à présent. Ne vide pas la liste interne.
$ar = $grab->finish()
Obtient un arrayref de tous les événements, puis détruit l'objet grab.
$hub = $grab->hub()
Obtient le hub utilisé par l'événement grab.
