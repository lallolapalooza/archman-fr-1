NOM

Template::Toolkit - Système de Traitement de Modèles

Introduction

Le Template Toolkit est une collection de modules Perl qui implémentent un système de traitement de modèles rapide, flexible, puissant et extensible.

Il est "agnostique à l'entrée" et peut être utilisé aussi bien pour traiter n'importe quel type de document texte : HTML, XML, CSS, Javascript, code Perl, texte brut, etc. Cependant, il est le plus souvent utilisé pour générer du contenu web statique et dynamique, c'est donc sur cela que nous allons nous concentrer ici.

Bien que le Template Toolkit soit écrit en Perl, vous n'avez pas besoin d'être un programmeur Perl pour l'utiliser. Il a été conçu pour permettre aux non-programmeurs de créer et de maintenir facilement des sites web basés sur des modèles sans avoir à s'embêter à écrire du code Perl ou à devenir fou avec le copier-coller.

Cependant, le Template Toolkit est également conçu pour être extrêmement flexible et extensible. Si vous êtes un programmeur Perl, ou si vous connaissez quelqu'un qui l'est, vous pouvez facilement intégrer le Template Toolkit à votre code existant, vos données, vos bases de données et vos applications web. De plus, vous pouvez facilement étendre le Template Toolkit grâce à son mécanisme de plugins et à d'autres API pour développeurs.

Quel que soit le contexte dans lequel vous l'utilisez, le but premier du Template Toolkit est de vous permettre de créer une séparation claire entre les éléments de présentation de votre site web et tout le reste.

Si vous générez des pages web statiques, vous pouvez l'utiliser pour séparer les éléments d'interface utilisateur couramment répétés sur chaque page (en-têtes, menus, pieds de page, etc.) du contenu principal. Si vous générez des pages web dynamiques pour le front-end d'une application web, vous l'utiliserez également pour maintenir le code Perl back-end entièrement séparé des modèles HTML front-end. Dans tous les cas, une séparation claire des préoccupations vous permet de vous concentrer sur une chose à la fois sans que les autres choses ne vous gênent. Et c'est tout l'intérêt du Template Toolkit.

Documentation

La documentation du Template Toolkit est organisée en cinq sections.

Le Template::Manual contient des informations détaillées sur l'utilisation du Template Toolkit. Il donne des exemples d'utilisation et inclut une référence complète du langage de modèle, des options de configuration, des filtres, des plugins et d'autres composants.

La page Template::Modules liste les modules Perl qui composent le Template Toolkit. Elle donne une brève explication de ce que chacun fait et fournit un lien vers la documentation complète de chaque module pour plus d'informations. Si vous êtes un programmeur Perl cherchant à utiliser le Template Toolkit depuis vos programmes Perl, cette section est susceptible de vous intéresser.

La plupart, sinon toutes, les informations dont vous avez besoin pour appeler le Template Toolkit depuis Perl se trouvent dans la documentation du module Template. Vous n'avez vraiment besoin de commencer à penser aux autres modules que si vous souhaitez étendre ou modifier le Template Toolkit d'une manière ou d'une autre, ou si vous êtes intéressé à regarder sous le capot pour voir comment tout cela fonctionne.

La documentation de chaque module est intégrée sous forme de POD dans chaque module, vous pouvez donc toujours utiliser "perldoc" depuis la ligne de commande pour lire la documentation d'un module. Par exemple :

$ perldoc Template
$ perldoc Template::Context
  ...etc...

Il convient de noter que toute la documentation, y compris le manuel d'utilisation, est disponible sous forme de POD. Par exemple :

$ perldoc Template::Manual
$ perldoc Template::Manual::Config
  ...etc...

La section Template::Tools contient la documentation de Template::Tools::tpage et Template::Tools::ttree. Ce sont deux programmes en ligne de commande distribués avec le Template Toolkit. tpage est utilisé pour traiter un seul fichier modèle, ttree pour traiter des répertoires entiers de fichiers modèles.

La section Template::Tutorial contient deux tutoriels d'introduction à l'utilisation du Template Toolkit. Le premier est Template::Tutorial::Web sur la génération de contenu web. Le second est Template::Tutorial::Datafile sur l'utilisation du Template Toolkit pour générer d'autres formats de données, y compris XML.

La dernière section du manuel est Template::FAQ qui contient des réponses à certaines des questions fréquemment posées sur le Template Toolkit.

Vous pouvez lire la documentation au format HTML soit en ligne sur le site web du Template Toolkit, http://template-toolkit.org/, soit en téléchargeant la version HTML de la documentation depuis http://template-toolkit.org/download/index.html#html_docs et en la décompressant sur votre machine locale.
