NOM

Text::BibTeX - interface pour lire et analyser les fichiers BibTeX

SYNOPSIS

use Text::BibTeX;
my $bibfile = Text::BibTeX::File->new("foo.bib");
my $newfile = Text::BibTeX::File->new(">newfoo.bib");
while ($entry = Text::BibTeX::Entry->new($bibfile))
{
   next unless $entry->parse_ok;
      .             # manipuler le contenu de $entry, en utilisant diverses
      .             # méthodes Text::BibTeX::Entry
      .
   $entry->write ($newfile);
}

DESCRIPTION

Le module "Text::BibTeX" sert principalement d'introduction de haut niveau à la bibliothèque "Text::BibTeX", à des fins de code comme de documentation. Le code charge les deux modules fondamentaux pour le traitement des fichiers BibTeX ("Text::BibTeX::File" et "Text::BibTeX::Entry"), et cette documentation donne un large aperçu de toute la bibliothèque qui n'est pas disponible dans la documentation des modules individuels qui la composent.

De plus, le module "Text::BibTeX" fournit un certain nombre de fonctions diverses qui sont utiles pour traiter les données BibTeX (en particulier celles provenant de bibliographies telles que définies par BibTeX 0.99, plutôt que des fichiers de base de données génériques). Ces fonctions ne s'intègrent généralement pas dans la hiérarchie des classes centrée autour de la classe "Text::BibTeX::Entry", principalement parce qu'elles sont spécifiques aux données bibliographiques et opèrent sur des chaînes génériques (plutôt que d'être liées à une entrée BibTeX particulière). Elles sont également documentées ici, dans "FONCTIONS DIVERSES".

Notez que chaque module décrit ici commence par le préfixe "Text::BibTeX". Par souci de concision, j'ai supprimé ce préfixe de la plupart des noms de classes et de modules dans le reste de cette page de manuel (et dans la plupart des autres pages de manuel de la bibliothèque).

MODULES ET CLASSES

La bibliothèque "Text::BibTeX" inclut un certain nombre de modules, dont beaucoup fournissent des classes. Habituellement, la relation est simple et évidente : un module fournit une classe du même nom---par exemple, le module "Text::BibTeX::Entry" fournit la classe "Text::BibTeX::Entry". Il existe cependant quelques exceptions : plus évidemment, le module "Text::BibTeX" ne fournit aucune classe lui-même, il charge simplement deux modules ("Text::BibTeX::Entry" et "Text::BibTeX::File") qui le font. Les autres exceptions sont mentionnées dans les descriptions ci-dessous, et discutées en détail dans la documentation des modules respectifs.

Les modules sont présentés grossièrement dans l'ordre de spécialisation croissante : les trois premiers sont essentiels pour tout programme qui traite des fichiers de données BibTeX, quel que soit le type de données qu'ils contiennent. Les modules suivants sont spécialisés pour une utilisation avec des bases de données bibliographiques, et servent à la fois à émuler les styles standards de BibTeX 0.99 et à donner un exemple de la manière de définir une structure de base de données par de tels modules spécialisés. Chaque module est entièrement documenté dans sa page de manuel respective.

"Text::BibTeX"
Charge les deux modules fondamentaux ("Entry" et "File"), et fournit un certain nombre de fonctions diverses qui ne rentrent nulle part dans la hiérarchie des classes.
"Text::BibTeX::File"
Fournit une interface orientée objet aux fichiers de base de données BibTeX. En plus des attributs évidents de nom de fichier et de descripteur de fichier, l'abstraction "fichier" gère des propriétés telles que la structure de la base de données et les options pour celle-ci.
"Text::BibTeX::Entry"
Fournit une interface orientée objet aux entrées BibTeX, qui peuvent être analysées à partir d'objets "File", de descripteurs de fichiers arbitraires ou de chaînes. Gère toutes les propriétés d'une seule entrée : type, clé, champs et valeurs. Sert également de classe de base pour les *classes d'entrées structurées* (décrites en détail dans Text::BibTeX::Structure).
"Text::BibTeX::Value"
Fournit une interface orientée objet aux *valeurs* et *valeurs simples*, des constructions de haut niveau qui peuvent être utilisées pour représenter les chaînes associées à chaque champ d'une entrée. Normalement, les valeurs des champs sont renvoyées simplement sous forme de chaînes Perl, avec les macros développées et les chaînes multiples "collées" ensemble. Si désiré, vous pouvez demander à "Text::BibTeX" de retourner des objets "Text::BibTeX::Value", qui vous donnent accès à la forme originale des données.
"Text::BibTeX::Structure"
Fournit les classes "Structure" et "StructuredEntry", qui servent principalement de classes de base pour les deux types de classes qui définissent les structures de base de données. Lisez cette page de manuel pour une description complète du mécanisme d'implémentation de classes Perl analogues aux "fichiers de style" BibTeX.
"Text::BibTeX::Bib"
Fournit les classes "BibStructure" et "BibEntry", qui remplissent deux objectifs : elles jouent le même rôle que les fichiers de style standard de BibTeX 0.99, et elles donnent un exemple de la manière d'écrire de nouvelles structures de base de données. Celles-ci dérivent ultimement des classes "Structure" et "StructuredEntry" fournies par le module "Structure", respectivement.
"Text::BibTeX::BibSort"
Une des classes de base de la classe "BibEntry" : gère la génération de clés de tri pour le tri avant la mise en forme de la sortie.
"Text::BibTeX::BibFormat"
Une des classes de base de la classe "BibEntry" : gère la mise en forme des données bibliographiques pour la sortie dans un langage de balisage tel que LaTeX.
"Text::BibTeX::Name"
Une classe utilisée par la structure "Bib" et spécifique aux données bibliographiques telles que définies par BibTeX lui-même : analyse les noms d'auteurs individuels en parties "prénom", "von", "nom" et "jr".
"Text::BibTeX::NameFormat"
Également spécifique aux données bibliographiques : rassemble les noms divisés (tels qu'analysés par la classe "Name") d'une manière personnalisée.

Pour une première lecture de la bibliothèque, vous voudrez probablement limiter votre lecture à Text::BibTeX::File et Text::BibTeX::Entry. Les autres modules vous seront utiles éventuellement, surtout si vous avez besoin d'émuler BibTeX de manière assez détaillée (par exemple, analyse de noms, génération de clés de tri). Mais pour les manipulations simples de bases de données qui constituent le pain et le beurre de la bibliothèque "Text::BibTeX", les classes "File" et "Entry" constituent la majeure partie de ce dont vous aurez besoin. Vous trouverez peut-être également utiles certains des éléments de cette page de manuel, notamment "VALEURS CONSTANTES" et "FONCTIONS UTILITAIRES".

EXPORTS

Le module "Text::BibTeX" a un certain nombre d'exportations optionnelles, la plupart étant des valeurs constantes décrites dans "VALEURS CONSTANTES" ci-dessous. Les exportations par défaut sont un sous-ensemble de ces valeurs constantes qui sont particulièrement souvent utilisées, les "métatypes d'entrée" (également accessibles via le tag d'exportation "metatypes"). Ainsi, les deux lignes suivantes sont équivalentes :

use Text::BibTeX;
use Text::BibTeX qw(:metatypes);

Certaines des diverses sous-routines fournies par le module sont également exportables. "bibloop", "split_list", "purify_string", et "change_case" sont toutes utiles dans le traitement quotidien des données BibTeX, mais ne rentrent pas vraiment nulle part dans la hiérarchie des classes. Elles peuvent être importées de "Text::BibTeX" en utilisant le tag d'exportation "subs". "check_class" et "display_list" sont également exportables, mais uniquement par nom ; elles ne sont pas incluses dans

any export tag. (Ces deux existent principalement pour être utilisés par d'autres modules de la bibliothèque.) Par exemple, pour utiliser "Text::BibTeX" et importer les constantes de métatype d'entrée et les sous-routines communes :

use Text::BibTeX qw(:metatypes :subs);

Un autre groupe de sous-routines existe pour la manipulation directe de la table des macros gérée par la bibliothèque C sous-jacente. Ces fonctions (voir « Fonctions de la table des macros », ci-dessous) vous permettent de définir, supprimer et interroger la valeur des macros BibTeX (ou « abréviations »). Elles peuvent être importées *en masse* en utilisant la "macrosubs" export tag :

use Text::BibTeX qw(:macrosubs);

VALEURS CONSTANTES

Le module "Text::BibTeX" rend disponibles un certain nombre de valeurs constantes. Celles-ci correspondent aux valeurs de divers types énumérés dans la bibliothèque C sous-jacente, btparse, et leurs significations sont expliquées plus en détail dans la documentation de btparse.

Chaque groupe de constantes est exportable en option à l'aide d'une balise d'exportation donnée dans les descriptions ci-dessous.

Métatypes d'entrée
"BTE_UNKNOWN", "BTE_REGULAR", "BTE_COMMENT", "BTE_PREAMBLE", "BTE_MACRODEF". La méthode "metatype" dans la classe "Entry" renvoie toujours l'une de ces valeurs. Les trois dernières décrivent respectivement les entrées "comment", "preamble" et "string" ; "BTE_REGULAR" décrit tous les autres types d'entrée. "BTE_UNKNOWN" ne devrait jamais être vu (il est principalement utile pour le code C qui pourrait avoir à détecter des structures de données mal formées). Voir aussi btparse. Balise d'exportation : "metatypes".
Types de nœuds AST
"BTAST_STRING", "BTAST_MACRO", "BTAST_NUMBER". Utilisé pour distinguer les trois sortes de valeurs simples — chaînes de caractères, macros et nombres. La méthode "type" de la classe "SimpleValue" renvoie toujours l'une de ces trois valeurs. Voir aussi Text::BibTeX::Value, btparse. Balise d'exportation : "nodetypes".
Parties de nom
"BTN_FIRST", "BTN_VON", "BTN_LAST", "BTN_JR", "BTN_NONE". Utilisé pour spécifier les diverses parties d'un nom après qu'il ait été divisé. Ils sont principalement utiles lors de l'utilisation de la classe "NameFormat". Voir aussi bt_split_names et bt_format_names. Balise d'exportation : "nameparts".
Méthodes de jointure
"BTJ_MAYTIE", "BTJ_SPACE", "BTJ_FORCETIE", "BTJ_NOTHING". Utilisé pour indiquer à la classe "NameFormat" comment joindre les jetons adjacents ; voir Text::BibTeX::NameFormat et bt_format_names. Balise d'exportation : "joinmethods".

FONCTIONS UTILITAIRES

"Text::BibTeX" fournit plusieurs fonctions qui opèrent en dehors de la hiérarchie de classes normale. Parmi celles-ci, seule "bibloop" sera probablement d'une grande utilité pour vous dans l'écriture de programmes quotidiens de manipulation de BibTeX ; les deux autres ("check_class" et "display_list") sont principalement fournies pour l'utilisation par d'autres modules de la bibliothèque. Elles sont documentées ici principalement par souci d'exhaustivité, mais aussi parce qu'elles pourraient éventuellement être utiles dans d'autres circonstances.

bibloop (ACTION, FILES [, DEST])
Itère sur toutes les entrées d'un ensemble de fichiers BibTeX, effectuant une action fournie par l'appelant sur chaque entrée. FILES doit être une référence à la liste des noms de fichiers à traiter, et ACTION une référence à une sous-routine qui sera appelée sur chaque entrée. DEST, s'il est fourni, doit être un objet "Text::BibTeX::File" (ouvert en écriture) auquel les entrées peuvent être imprimées.

La sous-routine référencée par ACTION est appelée avec exactement un argument : l'objet "Text::BibTeX::Entry" représentant l'entrée en cours de traitement. Des informations sur l'entrée elle-même et le fichier d'où elle provient sont disponibles via cet objet ; voir Text::BibTeX::Entry. La sous-routine ACTION n'est appelée que si l'entrée a été analysée avec succès ; toute erreur de syntaxe entraînera l'impression d'un message d'avertissement et le saut de cette entrée. Notez que *toutes* les entrées analysées avec succès sont passées à la sous-routine ACTION, y compris les entrées "preamble", "string" et "comment". Pour ignorer ces pseudo-entrées et ne traiter que les entrées « régulières », votre sous-routine d'action devrait ressembler à ceci :

sub action {
   my $entry = shift;
   return unless $entry->metatype == BTE_REGULAR;
   # traiter $entry ...
}

Si votre sous-routine d'action a besoin d'arguments supplémentaires, vous pouvez simplement créer une fermeture (sous-routine anonyme) comme enveloppe, et la passer à "bibloop" :

sub action {
   my ($entry, $extra_stuff) = @_;
   # ...
}
my $extra = ...;
Text::BibTeX::bibloop (sub { &action ($_[0], $extra) }, \@files);

Si la sous-routine ACTION renvoie une valeur vraie et que DEST a été fourni, alors l'entrée traitée sera écrite dans DEST.

check_class (PACKAGE, DESCRIPTION, SUPERCLASS, METHODS)
Assure qu'un PACKAGE implémente une classe répondant à certaines exigences. Premièrement, il inspecte les tables de symboles de Perl pour s'assurer qu'un package nommé PACKAGE existe réellement. Ensuite, il s'assure que la classe nommée par PACKAGE dérive de SUPERCLASS (en utilisant la méthode universelle "isa"). Cette dérivation peut se faire par héritage multiple, ou par plusieurs générations d'une hiérarchie de classes ; la seule exigence est que SUPERCLASS se trouve quelque part dans l'arbre des classes de base de PACKAGE. Enfin, il vérifie que PACKAGE fournit chaque méthode listée dans METHODS (une référence à une liste de noms de méthodes). Ceci est fait avec la méthode universelle "can", donc les méthodes peuvent provenir de l'une des classes de base de PACKAGE.

DESCRIPTION doit être une courte chaîne décrivant la classe qui était censée être fournie par PACKAGE. Elle est utilisée pour générer des messages d'avertissement si l'une des exigences de classe n'est pas satisfaite.

Ceci est principalement utilisé par le code de supervision dans "Text::BibTeX::Structure", pour s'assurer que les modules de structure fournis par l'utilisateur respectent les règles qui leur sont imposées.

display_list (LIST, QUOTE)
Convertit une liste de chaînes de caractères selon les conventions grammaticales d'une langue humaine (actuellement, seules les règles anglaises sont prises en charge). LIST doit être une référence à une liste de chaînes de caractères. Si cette liste est vide, la chaîne vide est renvoyée. Si elle a un élément, alors cet élément seul est renvoyé. Si elle a deux éléments, alors ils sont joints avec la chaîne " and " et la chaîne résultante est renvoyée. Sinon, la liste a *N* éléments pour *N* >= 3 ; les éléments 1 à *N*-1 sont joints avec des virgules, et le dernier élément est ajouté avec un intercalaire ", and ".

Si QUOTE est vrai, alors chaque chaîne est encadrée d'apostrophes avant toute autre opération.

Ceci est utilisé ailleurs dans la bibliothèque pour deux objectifs très distincts : pour générer des messages d'avertissement décrivant des listes de champs qui devraient être présents ou qui sont contradictoires dans une entrée, et pour générer des listes de noms d'auteurs dans des bibliographies formatées.

FONCTIONS DIVERSES

En plus de charger les modules "File" et "Entry", "Text::BibTeX" charge le code XSUB qui fait le pont entre les modules Perl et la bibliothèque C sous-jacente, btparse. Ce code XSUB fournit un certain nombre de fonctions utilitaires diverses, dont la plupart sont placées dans d'autres packages de la famille "Text::BibTeX" pour être utilisées par les classes correspondantes. (Par exemple, le code XSUB chargé par "Text::BibTeX" fournit une fonction "Text::BibTeX::Entry::parse", qui est en fait documentée comme la méthode "parse" de la classe "Text::BibTeX::Entry"---voir Text::BibTeX::Entry. Cependant, par souci d'exhaustivité, cette fonction---et toutes les autres fonctions qui deviennent disponibles lorsque vous "use Text::BibTeX"---sont au moins mentionnées ici. Les seules fonctions de ce groupe que vous utiliserez probablement sont décrites dans « Fonctions génériques de traitement de chaînes ».
