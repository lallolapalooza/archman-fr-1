Test2::Bundle::Extended(3perl) Guide du programmeur Perl Test2::Bundle::Extended(3perl)

NOM

Test2::Bundle::Extended - Ancien nom pour Test2::V0

*** OBSOLÈTE ***

Ce bundle a été renommé en Test2::V0, dans lequel la balise ':v1' a été supprimée car inutile.

DESCRIPTION

C'est le bundle de référence. Ce bundle inclut presque tous les outils, et plusieurs plugins, que l'auteur de Test2 utilise. Ce bundle est largement utilisé pour tester Test2::Suite lui-même.

EXEMPLE

use Test2::Bundle::Extended ':v1';
ok(1, "réussite");
...
done_testing;

RÉSOLUTION DES CONFLITS AVEC MOOSE

use Test2::Bundle::Extended '!meta';

Moose et Test2::Bundle::Extended exportent tous deux des sous-routines meta() très différentes. L'ajout de '!meta' aux arguments d'importation empêchera l'exportation de la sous-routine. Ce bundle exporte également la sous-routine sous le nom meta_check() afin que vous puissiez utiliser cette orthographe comme alternative.

BALISES

:v1
:DEFAULT
Les éléments suivants sont tous identiques : 
use Test2::Bundle::Extended;
use Test2::Bundle::Extended ':v1';
use Test2::Bundle::Extended ':DEFAULT';

RENOMMAGE À L'IMPORTATION

use Test2::Bundle::Extended ':v1', '!ok', ok => {-as => 'mon_ok'};

Ce bundle utilise Importer pour l'exportation, par conséquent vous pouvez utiliser tous les arguments qu'il accepte.

Explication :

:v1
Utilise la balise par défaut, toutes les exportations par défaut.
'!ok'
N'exporte pas ok()
ok => {-as => 'mon_ok'}
En fait, importe ok() mais sous le nom mon_ok().

Si vous n'aviez pas ajouté l'argument '!ok', vous auriez à la fois ok() et mon_ok().

PRAGMAS

Tous ces éléments peuvent être désactivés via des arguments d'importation individuels, ou via l'argument "-no_pragmas".

use Test2::Bundle::Extended -no_pragmas => 1;

STRICT

strict est activé pour vous. Vous pouvez le désactiver avec les arguments d'importation "-no_strict" ou "-no_pragmas" :

use Test2::Bundle::Extended -no_strict => 1;

WARNINGS

warnings est activé pour vous. Vous pouvez le désactiver avec les arguments d'importation "-no_warnings" ou "-no_pragmas" :

use Test2::Bundle::Extended -no_warnings => 1;

UTF8

Ceci est en fait fait via le plugin Test2::Plugin::UTF8, voir la section « PLUGINS » pour les détails.

Note : "-no_pragmas => 1" désactivera le plugin entier.

PLUGINS

SRAND

Voir Test2::Plugin::SRand.

Ceci réglera la graine aléatoire sur la date du jour. Vous pouvez fournir une graine alternative avec l'option d'importation "-srand" :

use Test2::Bundle::Extended -srand => 1234;

UTF8

Voir Test2::Plugin::UTF8.

Ceci réglera le fichier et toutes les sorties (y compris les sorties du formateur) en utf8. Ceci activera le pragma utf8 pour la portée actuelle.

Ceci peut être désactivé en utilisant les arguments d'importation "-no_utf8 => 1" ou "-no_pragmas => 1".

use Test2::Bundle::Extended -no_utf8 => 1;

RÉSUMÉ DE SORTIE

Voir Test2::Plugin::ExitSummary.

Ce plugin n'a pas de configuration.

FONCTIONS API

Voir Test2::API pour celles-ci

$ctx = context()
$events = intercept { ... }

OUTILS

CIBLE

Voir Test2::Tools::Target.

Vous pouvez spécifier une classe cible avec l'argument d'importation "-target". Si vous ne fournissez pas de cible, alors $CLASS et CLASS() ne seront pas importés.

use Test2::Bundle::Extended -target => 'Ma::Classe';
print $CLASS;  # Ma::Classe
print CLASS(); # Ma::Classe

Ou vous pouvez spécifier des noms :

use Test2::Bundle::Extended -target => { pkg => 'Quelque::Package' };
pkg()->xxx; # Appel de 'xxx' sur Quelque::Package
$pkg->xxx;  # Identique
$CLASS
Variable de paquet contenant le nom de la classe cible.
$class = CLASS()
Fonction constante qui renvoie le nom de la classe cible.

Voir Test2::Tools::Defer.
