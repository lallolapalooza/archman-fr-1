NOM

Text::Tabs - expansion et contraction des tabulations comme les utilitaires unix expand(1) et unexpand(1)

SYNTAXE

use Text::Tabs;
$tabstop = 4;  # par défaut = 8
@lignes_sans_tabulations = expand(@lignes_avec_tabulations);
@lignes_avec_tabulations = unexpand(@lignes_sans_tabulations);

DESCRIPTION

Text::Tabs fait la plupart de ce que font les utilitaires unix expand(1) et unexpand(1). Étant donnée une ligne avec des tabulations, "expand" les remplace par le nombre approprié d'espaces. Étant donnée une ligne avec ou sans tabulations, "unexpand" ajoute des tabulations lorsqu'elles peuvent économiser des octets, comme la commande "unexpand -a".

Contrairement aux anciens utilitaires unix, ce module prend correctement en compte les caractères de combinaison Unicode (tels que les diacritiques) qui peuvent survenir dans chaque ligne, pour l'expansion et la contraction. Ce sont des caractères de surimpression qui n'augmentent pas la position logique. Assurez-vous que les paramètres Unicode appropriés sont activés.

EXPORT

Les éléments suivants sont exportés :

expand
unexpand
$tabstop
La variable $tabstop contrôle l'espacement entre les taquets de tabulation. La valeur par défaut est 8.

Veuillez noter que local($tabstop) n'a pas le comportement attendu et si vous souhaitez utiliser "local" pour outrepasser $tabstop, vous devez utiliser local($Text::Tabs::tabstop).

EXEMPLE

#!perl
# unexpand -a
use Text::Tabs;
while (<>) {
  print unexpand $_;
}

Au lieu de la commande "expand" du shell, utilisez :

perl -MText::Tabs -n -e 'print expand $_'

Au lieu de la commande "unexpand -a" du shell, utilisez :

perl -MText::Tabs -n -e 'print unexpand $_'

BOGUES

Text::Tabs ne traite que les tabulations ("\t") et les caractères de combinaison ("/\pM/"). Il ne compte pas à rebours pour les retours arrière ("\t"), n'omet pas les autres caractères de contrôle non imprimables ("/\pC/"), ni ne gère autrement les caractères de largeur nulle, demi-largeur et pleine largeur.
