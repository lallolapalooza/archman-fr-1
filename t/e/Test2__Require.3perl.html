Test2::Require(3perl) Guide du programmeur Perl Test2::Require(3perl)

NOM

Test2::Require - Classe de base et documentation pour les paquets de tests du type skip-unless.

DESCRIPTION

Les paquets Test2::Require::* sont des paquets que vous chargez pour vous assurer que votre fichier de test est ignoré à moins qu'une exigence spécifique ne soit satisfaite. Les modules de cet espace de noms peuvent hériter de Test2::Require s'ils le souhaitent, mais ce n'est pas strictement nécessaire.

COMMENT ÉCRIRE UN MODULE 'REQUIRE' ?

EN TANT QUE SOUS-CLASSE

package Test2::Require::Widget;
use strict;
use warnings;
use base 'Test2::Require';
sub HAVE_WIDGETS { ... };
sub skip {
    my $class = shift;
    my @import_args = @_;
    if (HAVE_WIDGETS()) {
        # Nous avons des widgets, ne pas ignorer
        return undef;
    }
    else {
        # Pas de widgets, ignorer le test
        return "Ignoré car il n'y a pas de widgets" unless HAVE_WIDGETS();
    }
}
1;

Une sous-classe de Test2::Require a simplement besoin d'implémenter une méthode skip(). Cette méthode recevra tous les arguments d'importation. Cette méthode doit retourner undef si le test doit s'exécuter, et doit retourner une raison d'ignorance si le test doit être ignoré.

AUTONOME

Si vous ne souhaitez pas hériter de Test2::Require, vous devriez écrire une méthode import() :

package Test2::Require::Widget;
use strict;
use warnings;
use Test2::API qw/context/;
sub HAVE_WIDGETS { ... };
sub import {
    my $class = shift;
    # Avoir des widgets, devrait s'exécuter.
    return if HAVE_WIDGETS();
    # Utiliser l'objet contexte pour créer l'événement
    my $ctx = context();
    $ctx->plan(0, SKIP => "Ignoré car il n'y a pas de widgets");
    $ctx->release;
}
1;
