Test::Most::Exception(3) Documentation Perl fournie par la communauté Test::Most::Exception(3)

NOM

Test::Most::Exception - Classe d'exception interne

VERSION

Version 0.38

SYNOPSIS

C'est l'exception levée par "die_on_fail" de "Test::Most".

EXPORT

Nous exportons une seule fonction :

"throw_failure"

C'est l'exception pour "die_on_fail".
