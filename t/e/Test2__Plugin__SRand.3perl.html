NOM

Test2::Plugin::SRand - Contrôler la graine aléatoire pour des environnements de test plus contrôlés.

DESCRIPTION

Ce module vous donne le contrôle sur la graine aléatoire utilisée pour vos tests unitaires. Dans certains environnements de test, la graine aléatoire peut jouer un rôle majeur dans les résultats.

La configuration par défaut de ce module initialisera srand avec la date locale. Utiliser la date comme graine signifie que chaque jour, la graine aléatoire sera toujours la même, ce qui signifie que le comportement ne changera pas d'une exécution à l'autre le même jour. Cependant, la graine est différente d'un jour à l'autre, vous permettant de vous assurer que le code fonctionne toujours avec une aléatoire réelle.

La graine vous est imprimée en cas d'échec, ou lorsque le système de test est verbeux. Vous pouvez utiliser la variable d'environnement "T2_RAND_SEED" pour spécifier la graine. Vous pouvez également fournir une graine spécifique comme argument de chargement au plugin.

SYNOPSIS

Charger le plugin est facile, et les valeurs par défaut sont raisonnables :

use Test2::Plugin::SRand;

Graine personnalisée :

use Test2::Plugin::SRand seed => 42;

NOTE SUR L'ORDRE DE CHARGEMENT

Si vous utilisez ce plugin, vous voudrez probablement l'utiliser comme premier plugin, ou près du début. "srand" n'est appelé qu'une fois le plugin chargé, donc d'autres plugins chargés avant pourraient déjà utiliser des nombres aléatoires avant que votre graine ne prenne effet.

MISE EN GARDE

Lorsque srand est activé (par défaut), cela peut causer des problèmes avec des choses comme File::Temp qui finiront par tenter d'utiliser les mêmes noms de fichiers "aléatoires" pour chaque processus de test démarré un jour donné (ou partageant la même graine).
