NOM

Template::Plugin::File - Plugin fournissant des informations sur les fichiers

SYNTAXE

[% USE File(chemin_fichier) %]
[% File.path %]         # chemin complet
[% File.name %]         # nom de fichier
[% File.dir %]          # répertoire

DESCRIPTION

Ce plugin fournit une abstraction d'un fichier. Il peut être utilisé pour récupérer des détails sur des fichiers du système de fichiers, ou pour représenter des fichiers abstraits (par exemple, lors de la création d'une page d'index) qui peuvent ou non exister sur un système de fichiers.

Un nom de fichier ou un chemin doit être spécifié comme argument du constructeur. Par exemple :

[% USE File('foo.html') %]
[% USE File('foo/bar/baz.html') %]
[% USE File('/foo/bar/baz.html') %]

Le fichier doit exister sur le système de fichiers actuel (sauf si l'option "nostat" est définie, voir ci-dessous) en tant que fichier absolu lorsqu'il est spécifié avec un '"/"' initial comme dans '"/foo/bar/baz.html"', ou sinon comme un chemin relatif au répertoire de travail courant. Le constructeur effectue un stat() sur le fichier et rend les 13 éléments renvoyés disponibles en tant qu'éléments du plugin :

dev ino mode nlink uid gid rdev size
atime mtime ctime blksize blocks

Par exemple :

[% USE File('/foo/bar/baz.html') %]
[% File.mtime %]
[% File.mode %]
...

De plus, les éléments "user" et "group" sont définis pour contenir les noms d'utilisateur et de groupe tels que renvoyés par les appels à getpwuid() et getgrgid() pour les éléments "uid" et "gid" du fichier, respectivement. Sur les plateformes Win32 pour lesquelles getpwuid() et getgrid() ne sont pas disponibles, ces valeurs sont indéfinies.

[% USE File('/tmp/foo.html') %]
[% File.uid %]      # par exemple, 500
[% File.user %]     # par exemple, abw

Cette recherche d'utilisateur/groupe peut être désactivée en définissant l'option "noid".

[% USE File('/tmp/foo.html', noid=1) %]
[% File.uid %]      # par exemple, 500
[% File.user %]     # rien

Le drapeau "isdir" sera défini si le fichier est un répertoire.

[% USE File('/tmp') %]
[% File.isdir %]    # 1

Si le stat() sur le fichier échoue (par exemple, fichier inexistant, mauvaise permission, etc.), le constructeur lèvera une exception de type "File". Cela peut être capturé dans un bloc "TRY...CATCH".

[% TRY %]
   [% USE File('/tmp/monfichier') %]
   Le fichier existe !
[% CATCH File %]
   Erreur de fichier : [% error.info %]
[% END %]

Notez la capitalisation du type d'exception, '"File"', pour indiquer une erreur levée par le plugin "File", afin de la distinguer d'une exception régulière "file" levée par le Template Toolkit.

Notez que le plugin "File" peut également être référencé par le nom en minuscules '"file"'. Cependant, les exceptions sont toujours levées de type "File", quelle que soit la capitalisation du nom du plugin utilisé.

[% USE file('foo.html') %]
[% file.mtime %]

Comme pour tout autre plugin du Template Toolkit, un nom alternatif peut être spécifié pour l'objet créé.

[% USE foo = file('foo.html') %]
[% foo.mtime %]

L'option "nostat" peut être spécifiée pour empêcher le constructeur du plugin d'effectuer un stat() sur le fichier spécifié. Dans ce cas, le fichier n'a pas besoin d'exister dans le système de fichiers, aucune tentative ne sera faite pour vérifier son existence, et aucune erreur ne sera levée s'il n'existe pas. Les entrées pour les éléments habituellement renvoyés par stat() seront définies comme vides.

[% USE file('/quelque/part/au-dessus/de/l/arc-en-ciel.html', nostat=1)
[% file.mtime %]     # rien

MÉTHODES

Tous les plugins "File", quelle que soit l'option "nostat", ont défini un certain nombre d'éléments relatifs au chemin d'origine spécifié.

path

Le chemin d'accès complet et original spécifié au constructeur.

[% USE file('/foo/bar.html') %]
[% file.path %]     # /foo/bar.html

name

Le nom du fichier sans aucun répertoire en préfixe.

[% USE file('/foo/bar.html') %]
[% file.name %]     # bar.html

dir

L'élément répertoire du chemin avec le nom de fichier retiré.

[% USE file('/foo/bar.html') %]
[% file.name %]     # /foo

ext

L'extension du fichier, le cas échéant, apparaissant à la fin du chemin après un '"."' (non incluse dans l'extension).

[% USE file('/foo/bar.html') %]
[% file.ext %]      # html

home

Ceci contient une chaîne de la forme '"../.."' pour représenter le chemin ascendant depuis un fichier jusqu'à son répertoire racine.

[% USE file('bar.html') %]
[% file.home %]     # rien
[% USE file('foo/bar.html') %]
[% file.home %]     # ..
[% USE file('foo/bar/baz.html') %]
[% file.home %]     # ../..

root

L'élément "root" peut être spécifié comme argument du constructeur, indiquant un répertoire racine dans lequel réside le fichier nommé. Il est par ailleurs défini comme vide.

[% USE file('foo/bar.html', root='/tmp') %]
[% file.root %]     # /tmp

abs

Ceci renvoie le chemin d'accès absolu au fichier en construisant un chemin à partir des options "root" et "path".

[% USE file('foo/bar.html', root='/tmp') %]
[% file.path %]     # foo/bar.html
[% file.root %]     # /tmp
[% file.abs %]      # /tmp/foo/bar.html

rel(path)

Ceci renvoie un chemin relatif depuis le fichier actuel vers un autre chemin spécifié comme argument. Il est construit en ajoutant le chemin à l'élément '"home"'.

[% USE file('foo/bar/baz.html') %]
[% file.rel('wiz/waz.html') %]      # ../../wiz/waz.html

EXEMPLES

[% USE file('/foo/bar/baz.html') %]
[% file.path  %]      # /foo/bar/baz.html
[% file.dir   %]      # /foo/bar
[% file.name  %]      # baz.html
[% file.home  %]      # ../..
[% file.root  %]      # ''
[% file.abs   %]      # /foo/bar/baz.html
[% file.ext   %]      # html
[% file.mtime %]      # 987654321
[% file.atime %]      # 987654321
[% file.uid   %]      # 500
[% file.user  %]      # abw
[% USE file('foo.html') %]
[% file.path %]           # foo.html
[% file.dir  %]       # ''
[% file.name %]           # foo.html
[% file.root %]       # ''
[% file.home %]       # ''
[% file.abs  %]       # foo.html
[% USE file('foo/bar/baz.html') %]
[% file.path %]           # foo/bar/baz.html
[% file.dir  %]       # foo/bar
[% file.name %]           # baz.html
[% file.root %]       # ''
[% file.home %]       # ../..
[% file.abs  %]       # foo/bar/baz.html
[% USE file('foo/bar/baz.html', root='/tmp') %]
[% file.path %]           # foo/bar/baz.html
[% file.dir  %]       # foo/bar
[% file.name %]           # baz.html
[% file.root %]       # /tmp
[% file.home %]       # ../..
[% file.abs  %]       # /tmp/foo/bar/baz.html
# calculer d'autres chemins de fichiers relatifs à ce fichier et à sa racine
[% USE file('foo/bar/baz.html', root => '/tmp/tt2') %]
[% file.path('baz/qux.html') %]         # ../../baz/qux.html
[% file.dir('wiz/woz.html')  %]     # ../../wiz/woz.html
