Term::Table::Util(3perl) Guide de référence du programmeur Perl Term::Table::Util(3perl)

NOM

Term::Table::Util - Utilitaires pour Term::Table.

DESCRIPTION

Ce paquet exporte certains outils utilisés par Term::Table.

EXPORTATIONS

CONSTANTES

$bool = USE_GCS
Vrai si Unicode::GCString est installé.
$bool = USE_TERM_READKEY
Vrai si Term::ReadKey est installé.

UTILITAIRES

$largeur = term_size()
Obtenir la largeur du terminal.

Si la variable d'environnement $TABLE_TERM_SIZE est définie, cette valeur sera retournée.

La valeur par défaut sera 80 s'il n'y a pas de moyen fiable d'obtenir la taille, ou si la taille est déraisonnablement petite.

Si Term::ReadKey est installé, il sera utilisé.

$largeur = uni_length($chaine)
Obtenir la largeur (en colonnes) de la chaîne spécifiée. Lorsque Unicode::GCString est installé, cela fonctionnera sur les chaînes Unicode, sinon il utilisera simplement length($chaine).
