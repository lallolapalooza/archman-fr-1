Test2::EventFacet::Assert(3perl) Guide du programmeur Perl Test2::EventFacet::Assert(3perl)

NOM

Test2::EventFacet::Assert - Facette représentant une assertion.

DESCRIPTION

La facette d'assertion est fournie par tout événement représentant une assertion qui a été faite.

CHAMPS

$string = $assert->{details}
$string = $assert->details()
Description de l'assertion lisible par l'homme.
$bool = $assert->{pass}
$bool = $assert->pass()
Vrai si l'assertion a réussi.
$bool = $assert->{no_debug}
$bool = $assert->no_debug()
Définissez ceci sur vrai si vous avez fourni des diagnostics personnalisés et ne souhaitez pas que les valeurs par défaut soient affichées.
$int = $assert->{number}
$int = $assert->number()
(Optionnel) Numéro d'assertion. Ceci peut être omis ou ignoré. Ceci est généralement utile uniquement lors de l'analyse/traitement de TAP.

Note: Ceci n'est pas défini par le système Test2, le numéro d'assertion n'est connu qu'APRES que l'assertion ait été traitée. Cet attribut fait partie de la spécification uniquement pour les harnais.

SOURCE
