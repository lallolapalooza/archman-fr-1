NOM

Text::Wrap - mise en forme simple de paragraphes avec retour à la ligne

SYNTAXE

Exemple 1

use Text::Wrap;
$initial_tab = "\t";    # Tab avant la première ligne
$subsequent_tab = "";   # Lignes suivantes alignées à gauche
print wrap($initial_tab, $subsequent_tab, @text);
print fill($initial_tab, $subsequent_tab, @text);
$lines = wrap($initial_tab, $subsequent_tab, @text);
@paragraphs = fill($initial_tab, $subsequent_tab, @text);

Exemple 2

use Text::Wrap qw(wrap $columns $huge);
$columns = 132;         # Aligner à 132 caractères
$huge = 'die';
$huge = 'wrap';
$huge = 'overflow';

Exemple 3

use Text::Wrap;
$Text::Wrap::columns = 72;
print wrap('', '', @text);

DESCRIPTION

wrap() est un formatteur de paragraphes très simple. Il gère la mise en forme d'un seul paragraphe à la fois, en coupant les lignes aux limites de mots. L'indentation de la première ligne ($initial_tab) et de toutes les lignes suivantes ($subsequent_tab) est contrôlée indépendamment. Veuillez noter : $initial_tab et $subsequent_tab sont les chaînes littérales à utiliser : il est peu probable que vous souhaitiez y passer un nombre.

fill() est un formatteur de paragraphes simple. Il gère la mise en forme de chaque paragraphe séparément, puis joint les paragraphes une fois terminé. Il détruira tout blanc dans le texte d'origine. Il divise le texte en paragraphes en recherchant des blancs après un saut de ligne. À d'autres égards, il agit comme wrap().

wrap() compresse l'espace à la fin d'une ligne en une nouvelle ligne, et fill() supprime tout espace à la fin.

Les deux fonctions wrap() et fill() renvoient une seule chaîne.

Bien que l'ancienne utilité Unix fmt(1) ne le fasse pas, ce module s'assure de considérer correctement tout caractère Unicode combiné (comme les diacritiques) qui peut apparaître sur chaque ligne pour l'expansion et la construction. Ce sont des caractères de surimpression qui n'augmentent pas la position logique. Assurez-vous d'avoir une configuration Unicode appropriée pour votre système.

SOBREESCRITURES

wrap() a plusieurs variables qui contrôlent son comportement. Étant donné que d'autres modules pourraient utiliser wrap(), il est suggéré de laisser ces variables dans leur état d'origine. Si vous ne pouvez pas, utilisez local($Text::Wrap::VARIABLE) = YOURVALUE lorsque vous modifiez les valeurs afin que la valeur d'origine soit restaurée. Cette astuce local() ne fonctionnera pas si vous importez la variable dans votre propre espace de noms.

Les lignes sont coupées sur $Text::Wrap::columns colonnes (valeur par défaut : 76). $Text::Wrap::columns doit être défini sur la largeur totale de votre périphérique de sortie. En fait, chaque ligne résultante ne dépassera pas "$columns - 1" caractères.

Il est possible de contrôler quels caractères terminent les mots en modifiant $Text::Wrap::break. Définissez ceci sur une chaîne comme '[\s:]' (pour couper avant les espaces ou les deux-points) ou sur un motif de recherche précompilé comme qr/[\s']/ (pour couper avant les espaces ou les apostrophes). La valeur par défaut est simplement '\s' ; c'est-à-dire que les mots se terminent par des espaces. (Cela signifie, entre autres, que les signes de ponctuation finaux comme les virgules ou les points resteront attachés au mot auquel ils sont liés.) La définition de $Text::Wrap::break sur un motif de recherche qui n'élimine aucun caractère (éventuellement un lookahead assertif) générera un avertissement.

Note aux débutants : Dans l'exemple 2, $columns est importé dans l'espace de noms local et défini localement. Dans l'exemple 3, $Text::Wrap::columns est défini dans son espace de noms sans être importé.

wrap() commence son travail en développant tous les tabulateurs de son entrée en espaces. La dernière étape consiste à reconvertir les espaces en tabulateurs. Si vous ne souhaitez pas de tabulateurs dans vos résultats, définissez $Text::Wrap::unexpand sur une valeur fausse. Si vous ne souhaitez pas utiliser des tabulateurs de 8 caractères, définissez $Text::Wrap::tabstop sur le nombre de caractères souhaité pour vos tabulateurs.

Si vous souhaitez séparer vos lignes par autre chose que "\n", définissez $Text::Wrap::separator selon vos préférences. Ceci remplace tous les sauts de ligne par $Text::Wrap::separator. Si vous souhaitez préserver les sauts de ligne existants mais ajouter de nouveaux retours à la ligne, définissez $Text::Wrap::separator2 à la place.

Lorsqu'on rencontre des mots plus longs que $columns, ils sont coupés. wrap() insère un "\n" à la colonne $columns. Cette action peut être surécrite en définissant $huge sur 'die' ou 'overflow'. Lorsqu'elle est définie sur 'die', les mots longs provoqueront l'appel à die(). Lorsqu'elle est définie sur 'overflow', les mots longs seront laissés intacts.

Notes historiques : 'die' était la valeur par défaut de $huge. Maintenant, 'wrap' est la valeur par défaut.

EXEMPLES

Code :

print wrap("\t","",<<END);
This is a bit of text that forms 
a normal book-style indented paragraph
END

Résultat :

"     This is a bit of text that forms
a normal book-style indented paragraph   
"

Code :

$Text::Wrap::columns=20;
$Text::Wrap::separator="|";
print wrap("","","This is a bit of text that forms a normal book-style paragraph");

Résultat :

"This is a bit of|text that forms a|normal book-style|paragraph"

VOIR AUSSI

Pour la gestion correcte des caractères de demi-largeur et de pleine largeur d'Asie, voir Text::WrapI18N. Pour un contrôle plus détaillé, voir Text::Format.

Text::Wrap(3pm)

Le module Text::Wrap fournit une fonction pour envelopper des paragraphes de texte de manière agréable.

Description

Cette fonction prend un morceau de texte et le retourne avec des sauts de ligne insérés de manière à ce que chaque ligne ne dépasse pas une longueur spécifiée. Le module essaie de couper les mots aux espaces si possible, mais il peut également couper des mots longs au milieu si nécessaire.

Synopsis

use Text::Wrap;

my $text = "Ceci est un très long paragraphe de texte qui doit être enveloppé pour qu'il tienne dans une largeur spécifiée.";
my $wrapped_text = wrap($text, width => 60);
print $wrapped_text;

Fonctions

wrap(TEXT, OPTIONS)

Enveloppe le texte donné selon les options spécifiées. Les options courantes incluent :

  • width : La largeur maximale de chaque ligne.
  • subsequent_indent : La chaîne à ajouter au début de chaque ligne suivante après la première.
  • initial_indent : La chaîne à ajouter au début de la première ligne.

Exemple

use Text::Wrap;

my $paragraphe = "Un autre exemple de texte qui est un peu plus long et qui va nécessiter un peu plus d'enveloppement pour être lisible sur une console plus étroite.";
my $enveloppe = wrap($paragraphe, width => 40, subsequent_indent => "  ");
print $enveloppe;
