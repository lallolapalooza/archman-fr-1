NOM

Test::Output - Outils pour tester les messages de STDOUT et STDERR.

SYNOPIS

 use Test::More tests => 4;
 use Test::Output;
 sub writer {
   print "Write out.\n";
   print STDERR "Error out.\n";
 }
 stdout_is(\&writer,"Write out.\n",'Test STDOUT');
 stderr_isnt(\&writer,"No error out.\n",'Test STDERR');
 combined_is(
             \&writer,
             "Write out.\nError out.\n",
             'Test STDOUT & STDERR combined'
            );
 output_is(
           \&writer,
           "Write out.\n",
           "Error out.\n",
           'Test STDOUT & STDERR'
         );
# Utilisation de blocs sans nom.
stdout_is { print "test" } "test", "Test STDOUT";
stderr_isnt { print "bad test" } "test", "Test STDERR";
output_is { print 'STDOUT'; print STDERR 'STDERR' }
  "STDOUT", "STDERR", "Test output";

DESCRIPTION

Test::Output fournit une interface simple pour tester les messages STDOUT ou STDERR. Une variété d'outils sont inclus pour être aussi flexible que possible pour le testeur.

De plus, Capture::Tiny offre un mécanisme de capture plus robuste sans la comparaison avec l'original Test::Output::Tie.

TESTS

STDOUT

stdout_is
stdout_isnt
stdout_is  ( $coderef, $expected, 'description' );
stdout_is    { ... } $expected, 'description';
stdout_isnt( $coderef, $expected, 'description' );
stdout_isnt  { ... } $expected, 'description';

stdout_is() capture le message STDOUT de $coderef et le compare à $expected. Le test réussit s'ils sont égaux.

stdout_isnt() réussit si STDOUT n'est pas égal à $expected.

stdout_like
stdout_unlike
stdout_like  ( $coderef, qr/$expected/, 'description' );
stdout_like    { ... } qr/$expected/, 'description';
stdout_unlike( $coderef, qr/$expected/, 'description' );
stdout_unlike  { ... } qr/$expected/, 'description';

stdout_like() capture le message STDOUT de $coderef et le compare à l'expression régulière dans $expected. Le test réussit si l'expression régulière correspond.

stdout_unlike() réussit si STDOUT ne correspond pas à l'expression régulière.

STDERR

stderr_is
stderr_isnt
stderr_is  ( $coderef, $expected, 'description' );
stderr_is    {... } $expected, 'description';
stderr_isnt( $coderef, $expected, 'description' );
stderr_isnt  {... } $expected, 'description';

stderr_is() est similaire à stdout_is(), mais capture le message STDERR. Le test réussit si STDERR de $coderef est égal à $expected.

stderr_isnt() réussit si STDERR n'est pas égal à $expected.

stderr_like
stderr_unlike
stderr_like  ( $coderef, qr/$expected/, 'description' );
stderr_like   { ...} qr/$expected/, 'description';
stderr_unlike( $coderef, qr/$expected/, 'description' );
stderr_unlike  { ...} qr/$expected/, 'description';

stderr_like() est similaire à stdout_like(), mais compare l'expression régulière dans $expected avec le STDERR capturé de $coderef. Le test réussit si l'expression régulière correspond.

stderr_unlike() réussit si STDERR ne correspond pas à l'expression régulière.

SORTIE COMBINÉE

combined_is
combined_isnt
combined_is   ( $coderef, $expected, 'description' );
combined_is   {... } $expected, 'description';
combined_isnt ( $coderef, $expected, 'description' );
combined_isnt {... } $expected, 'description';

combined_is() redirige STDERR vers STDOUT et capture STDOUT. Ceci est équivalent à l'instruction UNIX "2>&1". Le test réussit si la sortie combinée de STDOUT et STDERR de $coderef est égale à $expected.

combined_isnt() réussit si la sortie combinée de STDOUT et STDERR n'est pas égale à $expected.

combined_like
combined_unlike
combined_like   ( $coderef, qr/$expected/, 'description' );
combined_like   { ...} qr/$expected/, 'description';
combined_unlike ( $coderef, qr/$expected/, 'description' );
combined_unlike { ...} qr/$expected/, 'description';

combined_like() est similaire à combined_is(), mais compare une expression régulière ("$expected)" avec la sortie STDOUT et STDERR capturée de $coderef. Le test réussit si l'expression régulière correspond.

combined_unlike() réussit si la sortie combinée STDOUT et STDERR ne correspond pas à l'expression régulière.

OUTPUT

output_is
output_isnt
output_is  ( $coderef, $expected_stdout, $expected_stderr, 'description' );
output_is    {... } $expected_stdout, $expected_stderr, 'description';
output_isnt( $coderef, $expected_stdout, $expected_stderr, 'description' );
output_isnt  {... } $expected_stdout, $expected_stderr, 'description';

La fonction output_is() est une combinaison des fonctions stdout_is() et stderr_is(). Par exemple:

output_is(sub {print "foo"; print STDERR "bar";},'foo','bar');

est fonctionnellement équivalent à

stdout_is(sub {print "foo";},'foo')
  && stderr_is(sub {print STDERR "bar";},'bar');

bien que $coderef ne soit exécuté qu'une seule fois.

Contrairement à stdout_is() et stderr_is(), qui ignorent respectivement STDERR et STDOUT, output_is() requiert à la fois STDOUT et STDERR.

La fonction output_is() capture les messages STDOUT et STDERR de $coderef et compare chacun d'eux à $expected_stdout et $expected_stderr, respectivement.

an> pour correspondre afin de passer. Définir $expected_stdout ou $expected_stderr à "undef" ignore "STDOUT" ou "STDERR" respectivement.

output_is(sub {print "foo"; print STDERR "bar";},'foo',undef);

est la même chose que

stdout_is(sub {print "foo";},'foo')

output_isnt() fournit la fonction opposée de output_is(). C'est une combinaison de stdout_isnt() et stderr_isnt().

output_isnt(sub {print "foo"; print STDERR "bar";},'bar','foo');

est fonctionnellement équivalent à

stdout_isnt(sub {print "foo";},'bar')
  && stderr_isnt(sub {print STDERR "bar";},'foo');

Comme avec output_is(), définir $expected_stdout ou $expected_stderr à "undef" ignore la sortie vers cette installation.

output_isnt(sub {print "foo"; print STDERR "bar";},undef,'foo');

est la même chose que

stderr_is(sub {print STDERR "bar";},'foo')
output_like
output_unlike
output_like  ( $coderef, $regex_stdout, $regex_stderr, 'description' );
output_like  { ... } $regex_stdout, $regex_stderr, 'description';
output_unlike( $coderef, $regex_stdout, $regex_stderr, 'description' );
output_unlike { ... } $regex_stdout, $regex_stderr, 'description';

output_like() et output_unlike() suivent les mêmes principes que output_is() et output_isnt(), sauf qu'ils utilisent une expression régulière pour la correspondance.

output_like() tente de faire correspondre $regex_stdout et $regex_stderr avec "STDOUT" et "STDERR" produits par $coderef. Le test réussit si les deux correspondent.

output_like(sub {print "foo"; print STDERR "bar";},qr/foo/,qr/bar/);

Le test ci-dessus est réussi.

Comme output_is(), définir $regex_stdout ou $regex_stderr à "undef" ignore la sortie vers cette installation.

output_like(sub {print "foo"; print STDERR "bar";},qr/foo/,undef);

est la même chose que

stdout_like(sub {print "foo"; print STDERR "bar";},qr/foo/);

output_unlike() le test réussit si la sortie de $coderef ne correspond pas à $regex_stdout et $regex_stderr.

EXPORTATIONS

Par défaut, toutes les sous-routines sont exportées par défaut.

  • :stdout - les sous avec "stdout" dans le nom.
  • :stderr - les sous avec "stderr" dans le nom.
  • :functions - les sous avec "_from" à la fin.
  • :output - les sous avec "output" dans le nom.
  • :combined - les sous avec "combined" dans le nom.
  • :tests - tout ce qui produit du TAP
  • :all - tout (ce qui est la même chose que le défaut)

FONCTIONS

stdout_from

my $stdout = stdout_from($coderef)
my $stdout = stdout_from { ... };

stdout_from() exécute $coderef et capture STDOUT.

stderr_from

my $stderr = stderr_from($coderef)
my $stderr = stderr_from { ... };

stderr_from() exécute $coderef et capture "STDERR".

output_from

my ($stdout, $stderr) = output_from($coderef)
my ($stdout, $stderr) = output_from {...};

output_from() exécute $coderef une fois en capturant à la fois "STDOUT" et "STDERR".

combined_from

my $combined = combined_from($coderef);
my $combined = combined_from {...};

combined_from() exécute $coderef une fois, combine "STDOUT" et "STDERR", et les capture. combined_from() est équivalent à utiliser "2>&1" sous UNIX.
