Template::Exception(3) Documentation Perl fournie par l'utilisateur Template::Exception(3)

NOM

Template::Exception - module de classe de gestion d'exceptions

SYNTAXE

use Template::Exception;
my $exception = Template::Exception->new($type, $info);
$type = $exception->type;
$info = $exception->info;
($type, $info) = $exception->type_info;
print $exception->as_string();
$handler = $exception->select_handler(\@candidates);

DESCRIPTION

Le module "Template::Exception" définit une classe d'objets pour représenter les exceptions dans le cycle de traitement des templates. Les exceptions peuvent être levées par les modules dans la Template Toolkit, ou peuvent être générées et retournées par du code utilisateur lié à des variables de template.

Les exceptions peuvent être levées dans un template en utilisant la directive "THROW",

[% THROW user.login 'no user id: please login' %]

ou en appelant la méthode throw() sur l'objet Template::Context courant,

$context->throw('user.passwd', 'Incorrect Password');
$context->throw('Incorrect Password');    # type 'undef'

ou depuis du code Perl en appelant die() avec un objet "Template::Exception",

die (Template::Exception->new('user.denied', 'Invalid User ID'));

ou en appelant simplement die() avec une chaîne d'erreur. Ceci est automatiquement intercepté et converti en une exception de type '"undef"' (c'est la chaîne littérale '"undef"' plutôt que la valeur indéfinie de Perl) qui peut ensuite être traitée de la manière habituelle.

die "I'm sorry Dave, I can't do that";

Chaque exception est définie par son type et un composant d'information (par exemple, un message d'erreur). Le type peut être n'importe quelle chaîne d'identification et peut contenir des composants pointés (par exemple, '"foo"', '"foo.bar"', '"foo.bar.baz"'). Les types d'exceptions sont considérés comme hiérarchiques, de sorte que '"foo.bar"' serait un type spécifique du type plus général '"foo"'.

MÉTHODES

type()

Retourne le type d'exception.

info()

Retourne l'information d'exception.
