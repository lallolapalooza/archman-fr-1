NOM

Template::Plugin::Math - Plugin fournissant des fonctions mathématiques

SYNTAXE

[% USE Math %]
[% Math.sqrt(9) %]

DESCRIPTION

Le plugin Math fournit de nombreuses fonctions mathématiques utilisables au sein des templates.

MÉTHODES

"Template::Plugin::Math" rend disponibles les fonctions suivantes du cœur de Perl :

abs
atan2
cos
exp
hex
int
log
oct
rand
sin
sqrt
srand

De plus, si le module Math::Trig peut être chargé, les fonctions suivantes sont également disponibles :

pi
tan
csc
cosec
sec
cot
cotan
asin
acos
atan
acsc
acosec
asec
acot
acotan
sinh
cosh
tanh
csch
cosech
sech
coth
cotanh
asinh
acosh
atanh
acsch
acosech
asech
acoth
acotanh
rad2deg
rad2grad
deg2rad
deg2grad
grad2rad
grad2deg

Si le module Math::TrulyRandom est disponible, et que vous avez le temps d'attendre, la méthode "truly_random_number" est disponible :

[% Math.truly_random_number %]
