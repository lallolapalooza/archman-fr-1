NOM

Text::Query::BuildSimpleString - Constructeur pour Text::Query::ParseSimple pour construire des expressions régulières

SYNOPIS

use Text::Query;
my $q=new Text::Query('+hello +world',
                      -parse => 'Text::Query::ParseSimple',
                      -solve => 'Text::Query::SolveSimpleString',
                      -build => 'Text::Query::BuildSimpleString');

DESCRIPTION

Construit une expression régulière pour faire correspondre la requête simple analysée par Text::Query::ParseSimple. Les mots de la requête peuvent être des expressions régulières et fourniront le résultat attendu si l'option "-regexp" est définie.
