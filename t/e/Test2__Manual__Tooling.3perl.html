Test2::Manual::Tooling(3perl) Guide de référence des programmeurs Perl Test2::Manual::Tooling(3perl)

NOM

Test2::Manual::Tooling - Page man pour les auteurs d'outils.

DESCRIPTION

Cette section couvre la création de nouveaux outils, plugins et autres composants de Test2.

TUTORIELS OUTILS

PREMIER OUTIL

Test2::Manual::Tooling::FirstTool - Introduction à la création d'outils en clonant ok().

MIGRER DEPUIS Test::Builder

Test2::Manual::Tooling::TestBuilder - Cette section fait correspondre les méthodes de Test::Builder aux concepts de Test2.

EMBOÎTEMENT DES OUTILS

Test2::Manual::Tooling::Nesting - Comment appeler d'autres outils depuis votre outil.

OUTILS AVEC SOUS-TESTS

Test2::Manual::Tooling::Subtest - Comment écrire des outils qui utilisent des sous-tests.

TESTER VOS OUTILS DE TEST

Test2::Manual::Tooling::Testing - Comment écrire des tests pour vos outils de test.

TUTORIELS PLUGINS

AGIR LORSQU'UN NOUVEL OUTIL DÉMARRE

Test2::Manual::Tooling::Plugin::ToolStarts - Comment ajouter des comportements qui se produisent lorsqu'un outil commence son travail.

AGIR APRÈS QU'UN OUTIL EST TERMINÉ

Test2::Manual::Tooling::Plugin::ToolCompletes - Comment ajouter des comportements qui se produisent lorsqu'un outil a terminé son travail.

AGIR À LA FIN DES TESTS

Test2::Manual::Tooling::Plugin::TestingDone - Comment ajouter des comportements qui se produisent lorsque les tests sont terminés (c'est-à-dire done_testing, ou fin du test).

AGIR JUSTE AVANT LA SORTIE

Test2::Manual::Tooling::Plugin::TestExit - Comment ajouter en toute sécurité des comportements avant la sortie.

ÉCRIRE UN FORMATTEUR JSONL SIMPLE

Test2::Manual::Tooling::Formatter - Comment écrire un formateur personnalisé, dans notre cas un formateur JSONL.

OÙ TROUVER DES HOOKS ET DES APIS

API globale
Test2::API est l'API globale. Elle est principalement utilisée par les plugins qui fournissent un comportement global.
Dans les hubs
Test2::Hub est la classe de base pour tous les hubs. C'est là que se trouvent les hooks pour manipuler les événements ou exécuter des choses à la fin des tests.

VOIR AUSSI

Test2::Manual - Index principal du manuel.
