NOM

Test::use::ok - Alternative à Test::More::use_ok

SYNTAXE

use ok 'Some::Module';

DESCRIPTION

Selon la documentation de Test::More, il est recommandé d'exécuter use_ok() dans un bloc "BEGIN", afin que les fonctions soient exportées au moment de la compilation et que les prototypes soient correctement respectés.

C'est-à-dire, au lieu d'écrire ceci :

use_ok( 'Some::Module' );
use_ok( 'Other::Module' );

Il faut écrire ceci :

BEGIN { use_ok( 'Some::Module' ); }
BEGIN { use_ok( 'Other::Module' ); }

Cependant, les gens oublient souvent d'ajouter "BEGIN", ou groupent par erreur "use_ok" avec d'autres tests dans un seul bloc "BEGIN", ce qui peut créer des différences subtiles dans l'ordre d'exécution.

Avec ce module, il suffit de changer tous les "use_ok" dans les scripts de test en "use ok", et ils seront exécutés au moment de "BEGIN". L'espace explicite après "use" rend clair qu'il s'agit d'une seule action au moment de la compilation.
