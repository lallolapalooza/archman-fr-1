NOM

Template::Plugin::Dumper - Interface de plugin pour Data::Dumper

SYNTAXE

[% USE Dumper %]

[% Dumper.dump(variable) %]
[% Dumper.dump_html(variable) %]

DESCRIPTION

C'est une interface de plugin très simple du Template Toolkit pour le module Data::Dumper. Un objet "Dumper" sera instancié via la directive suivante :

[% USE Dumper %]

En tant que plugin standard, vous pouvez également spécifier son nom en minuscules :

[% USE dumper %]

Les options "Pad", "Indent" et "Varname" de "Data::Dumper" sont prises en charge en tant qu'arguments constructeurs pour affecter la sortie générée. Voir Data::Dumper pour plus de détails.

[% USE dumper(Indent=0, Pad="<br>") %]

Ces options peuvent également être spécifiées en minuscules.

[% USE dumper(indent=0, pad="<br>") %]

MÉTHODES

Deux méthodes sont prises en charge par l'objet "Dumper". Chacune produira dans le template le contenu des variables passées à la méthode de l'objet.

dump()

Génère une sortie brute en texte de la ou des structures de données passées.

[% USE Dumper %]
[% Dumper.dump(myvar) %]
[% Dumper.dump(myvar, yourvar) %]

dump_html()

Génère une sortie des structures de données, comme pour dump(), mais avec les caractères <, > et & convertis en leurs entités HTML équivalentes et les sauts de ligne convertis en <br>.

[% USE Dumper %]
[% Dumper.dump_html(myvar) %]
