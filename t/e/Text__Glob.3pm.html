Paquet: perl-text-glob

Text::Glob(3) Documentation Perl fournie par l'utilisateur Text::Glob(3)

NOM

Text::Glob - faire correspondre des motifs de globbing à du texte

SYNOPIS

use Text::Glob qw( match_glob glob_to_regex );
print "correspond\n" if match_glob( "foo.*", "foo.bar" );
# affiche foo.bar et foo.baz
my $regex = glob_to_regex( "foo.*" );
for ( qw( foo.bar foo.baz foo bar ) ) {
    print "correspond : $_\n" if /$regex/;
}

DESCRIPTION

Text::Glob implémente la correspondance de style glob(3) qui peut être utilisée pour faire correspondre du texte, plutôt que de récupérer des noms dans un système de fichiers. Si vous souhaitez effectuer un globbing complet de fichiers, utilisez plutôt le module File::Glob.

Rotines

match_glob( $glob, @choses_a_tester )
Retourne la liste des éléments qui correspondent au glob à partir de la liste source.
glob_to_regex( $glob )
Retourne une expression régulière compilée qui est l'équivalent du modèle de globbing.
glob_to_regex_string( $glob )
Retourne une chaîne d'expression régulière qui est l'équivalent du modèle de globbing.

SYNTAXE

Les métacaractères et les règles suivants sont respectés.

"*" - correspond à zéro caractère ou plus
"a*" correspond à "a", "aa", "aaaa" et bien d'autres.
"?" - correspond à exactement un caractère
"a?" correspond à "aa", mais pas à "a", ou "aaa"
Ensembles/plages de caractères
"example.[ch]" correspond à "example.c" et "example.h"

"demo.[a-c]" correspond à "demo.a", "demo.b", et "demo.c"

alternation
"example.{foo,bar,baz}" correspond à "example.foo", "example.bar", et "example.baz"
le point au début doit être explicitement correspondu
"*.foo" ne correspond pas à ".bar.foo". Pour cela, vous devez soit spécifier le point initial dans le modèle de globbing (".*.foo"), soit définir $Text::Glob::strict_leading_dot à une valeur fausse lors de la compilation de l'expression régulière.
"*" et "?" ne correspondent pas au séparateur (c'est-à-dire qu'ils ne correspondent pas à "/")
"*.foo" ne correspond pas à "bar/baz.foo". Pour cela, vous devez soit correspondre explicitement au / dans le glob ("*/*.foo"), soit définir $Text::Glob::strict_wildcard_slash à une valeur fausse lors de la compilation de l'expression régulière, soit changer le séparateur utilisé par Text::Glob en définissant $Text::Glob::seperator à une valeur alternative lors de la compilation de l'expression régulière.

BOGUES

Le code utilise qr// pour produire des expressions régulières compilées, par conséquent ce module nécessite la version perl 5.005_03 ou plus récente.
