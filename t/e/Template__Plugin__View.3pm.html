NOM

Template::Plugin::View - Plugin pour créer des vues (Template::View)

SYNOPSIS

[% USE view(
        prefix = 'splash/'          # préfixe/suffixe du modèle
        suffix = '.tt2'
        bgcol  = '#ffffff'          # et toutes autres variables que
        style  = 'Fancy HTML'       # vous souhaitez définir comme métadonnées de vue,
        items  = [ foo, bar.baz ]   # y compris des données complexes et
        foo    = bar ? baz : x.y.z  # des expressions
%]
[% view.title %]                    # accéder aux métadonnées de la vue
[% view.header(title = 'Foo!') %]   # les "méthodes" de la vue traitent les blocs ou
[% view.footer %]                   # les modèles avec le préfixe/suffixe ajouté

DESCRIPTION

Ce module plugin crée des objets Template::View. Les vues sont une fonctionnalité expérimentale et sont susceptibles de changer dans un avenir proche. En attendant, veuillez consulter Template::View pour plus d'informations.
