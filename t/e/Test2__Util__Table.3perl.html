Test2::Util::Table(3perl) Guide de référence du programmeur Perl Test2::Util::Table(3perl)

NOM

Test2::Util::Table - Formater un en-tête et des lignes en tableau

DESCRIPTION

Ceci est utilisé par certains tests échoués pour fournir des diagnostics sur ce qui a mal tourné. Ce module est capable de formater génériquement des lignes de données en tableaux.

SYNTAXE

use Test2::Util::Table qw/table/;
my @table = table(
    max_width => 80,
    collapse => 1, # Ne pas afficher les colonnes vides
    header => [ 'nom', 'age', 'couleur des cheveux' ],
    rows => [
        [ 'Fred Pierrafeu',  2000000, 'noir' ],
        [ 'Dé baku', 1999995, 'rouge' ],
        ...,
    ],
);
# Le tableau @table contient chaque ligne du tableau, sans sauts de ligne ajoutés.
say $_ for @table;

Ceci imprime un tableau comme suit:

+-----------------+---------+------------+
| nom             | age     | couleur des cheveux |
+-----------------+---------+------------+
| Fred Pierrafeu  | 2000000 | noir       |
| Dé baku | 1999995 | rouge      |
| ...             | ...     | ...        |
+-----------------+---------+------------+

EXPORTATIONS

@lignes = table(...)

La fonction retourne une liste de lignes, les lignes n'ont pas le caractère de saut de ligne "\n" ajouté.

Options:

header => [ ... ]
Si vous voulez un en-tête, spécifiez-le ici. Ceci prend un tableau référencé avec l'en-tête de chaque colonne.
rows => [ [...], [...], ... ]
Ceci devrait être un tableau référencé contenant un tableau référencé par ligne.
collapse => $bool
Utilisez ceci si vous voulez masquer les colonnes vides, c'est-à-dire toute colonne qui n'a pas de données dans aucune ligne. Avoir un en-tête pour la colonne n'affectera pas l'effondrement.
max_width => $num
Définit la largeur maximale du tableau, le tableau peut ne pas être aussi grand, mais il ne sera pas plus grand. Si aucun n'est spécifié, il tentera de trouver la largeur de votre terminal et l'utilisera, sinon il se rabattra sur 80.
sanitize => $bool
Ceci assainira toutes les données du tableau de sorte que les sauts de ligne, les caractères de contrôle et tous les espaces blancs sauf l'ASCII 20 ' ' soient remplacés par des séquences d'échappement. Ceci empêche les sauts de ligne, les tabulations et les espaces similaires de perturber le tableau.

Note : les sauts de ligne sont marqués comme « \n », mais un saut de ligne est également inséré dans les données afin qu'elles s'affichent généralement d'une manière utile aux humains.

Exemple :

my $field = "foo\nbar\nbaz\n";
print join "\n" => table(
    sanitize => 1,
    rows => [
        [$field,      'col2'     ],
        ['ligne2 col1', 'ligne2 col2']
    ]
);

Imprime :

+-----------------+-----------+
| foo\n           | col2      |
| bar\n           |           |
| baz\n           |           |
|                 |           |
| ligne2 col1       | ligne2 col2 |
+-----------------+-----------+

Ainsi, il marque les sauts de ligne en insérant la séquence d'échappement, mais il affiche également les données sur autant de lignes qu'elles s'afficheraient normalement.

mark_tail => $bool
Ceci remplacera le dernier caractère d'espacement de tout espacement final par sa séquence d'échappement. Cela permet de repérer plus facilement les espacements finaux lors de la comparaison des valeurs.

mes $cols = term_size()

Tente de trouver la largeur en colonnes (caractères) du terminal actuel. Retourne 80 comme pari sûr s'il ne peut pas le trouver autrement.

NOTE SUR LES CARACTÈRES UNICODE/LARGES

Certains caractères unicode, tels que "婧" ("U+5A67") sont plus larges que d'autres. Ils s'afficheront correctement si vous "use utf8;" comme nécessaire, et que Unicode::GCString est installé, cependant si le module n'est pas installé, il y aura des anomalies dans le tableau :

+-----+-----+---+
| a   | b   | c |
+-----+-----+---+
| 婧 | x   | y |
| x   | y   | z |
| x   | 婧 | z |
+-----+-----+---+
