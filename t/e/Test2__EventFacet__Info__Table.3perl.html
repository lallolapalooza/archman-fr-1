Test2::EventFacet::Info::Table(3perl) Guide du programmeur Perl Test2::EventFacet::Info::Table(3perl)

NOM

Test2::EventFacet::Info::Table - Représentation intermédiaire d'un tableau.

DESCRIPTION

Représentation intermédiaire d'un tableau à utiliser dans des méthodes spécialisées de Test::API::Context qui génèrent des facettes Test2::EventFacet::Info.

SYNTAXE

use Test2::EventFacet::Info::Table;
use Test2::API qw/context/;
sub my_tool {
    my $ctx = context();
    ...
    $ctx->fail(
        $name,
        "message de diagnostic d'échec",
        Test2::EventFacet::Info::Table->new(
            # Requis
            rows => [['a', 'b'], ['c', 'd'], ...],
            # Fortement recommandé
            as_string => "... chaîne à afficher quand le tableau ne peut être rendu ...",
            # Optionnel
            header => ['col1', 'col2'],
            collapse => $bool,
            no_collapse => ['col1', ...],
        ),
    );
    ...
    $ctx->release;
}
my_tool();

ATTRIBUTS

$header_aref = $t->header()
$rows_aref = $t->rows()
$bool = $t->collapse()
$aref = $t->no_collapse()
Les attributs ci-dessus sont directement liés à la structure de hachage du tableau décrite dans Test2::EventFacet::Info.
$str = $t->as_string()
Renvoie la forme chaîne du tableau s'il a été défini, sinon renvoie la chaîne "<TABLEAU NON AFFICHÉ>".
$href = $t->as_hash()
Renvoie la structure de données utilisée pour les tableaux par Test2::EventFacet::Info.
%args = $t->info_args()
Renvoie les arguments qui devraient être utilisés pour construire la structure Test2::EventFacet::Info appropriée. 
return (table => $t->as_hash(), details => $t->as_string());
