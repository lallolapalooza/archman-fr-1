NOM

Text::Query::Build - Classe de base pour les constructeurs de requêtes

SYNOPIS

package Text::Query::BuildMy;
use Text::Query::Build;

use vars qw(@ISA);
@ISA = qw(Text::Query::Build);

DESCRIPTION

Ce module fournit une classe de base virtuelle pour les constructeurs de requêtes.

Les constructeurs de requêtes sont appelés par la logique de l'analyseur. Un ensemble donné de fonctions est fourni par le constructeur pour faire correspondre une logique booléenne. Toutes les méthodes retournent un scalaire correspondant au code qui exécute les options spécifiées.

Les paramètres Q1 et Q2 sont du même type scalaire que les valeurs de retour.

MÉTHODES

matchstring()
Retourne une chaîne qui représente la dernière expression construite. Deux expressions identiques devraient générer la même chaîne. Ceci est à des fins de test.

MÉTHODES DE GÉNÉRATION DE CODE

build_init()
Appelée avant la construction de l'expression. Une occasion d'initialiser les données de l'objet.
build_final_expression(Q1)
Effectue tout traitement final pour générer du code afin de faire correspondre une expression de niveau supérieur. La valeur de retour n'est PAS nécessairement d'un type qui peut être passé aux autres méthodes de génération de code.
build_expression(Q1,Q2)
Génère du code pour faire correspondre "Q1" OU "Q2"
build_expression_finish(Q1)
Génère tout code nécessaire pour encapsuler une expression.
build_conj(Q1,Q2,F)
Génère le code nécessaire pour faire correspondre "Q1" ET "Q2". F sera vrai si c'est la première fois que cette méthode est appelée dans une séquence de plusieurs conjonctions.
build_near(Q1,Q2)
Génère le code nécessaire pour faire correspondre "Q1" PROCHE "Q2".
build_concat(Q1,Q2)
Génère le code nécessaire pour faire correspondre "Q1" immédiatement suivi par "Q2".
build_negation(Q1)
Génère le code nécessaire pour faire correspondre NON "Q1".
build_literal(Q1)
Génère du code pour faire correspondre "Q1" comme une littérale.
build_scope_start($scope)
Génère du code pour entrer dans le contexte de requête $scope.
build_scope_end($scope,Q1)
Génère le code nécessaire pour faire correspondre "Q1" dans le contexte $scope.
build_mandatory(Q1)
Génère du code pour faire correspondre "Q1" (pensez à + dans la syntaxe AltaVista).
build_forbiden(Q1)
Génère du code pour faire correspondre NON "Q1" (pensez à - dans la syntaxe AltaVista).
