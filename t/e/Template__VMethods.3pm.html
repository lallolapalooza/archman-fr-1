NOM

Template::VMethods - Méthodes virtuelles pour les variables

DESCRIPTION

Le module "Template::VMethods" implémente les méthodes virtuelles qui peuvent être appliquées aux variables.

Veuillez consulter Template::Manual::VMethods pour plus d'informations.
