NOM

Test2::Compare::EventMeta - Classe méta pour les événements dans les comparaisons approfondies

DESCRIPTION

Ceci est utilisé dans les comparaisons approfondies d'objets d'événement. Vous ne devriez probablement jamais l'utiliser directement.

VÉRIFICATIONS DÉFINIES

fichier
Fichier qui a généré l'événement.
ligne
Ligne où l'événement a été généré.
paquet
Paquet qui a généré l'événement.
nom_de_la_fonction
Nom de l'outil qui a généré l'événement.
débogage
Les informations de débogage qui seront imprimées en cas d'échec.
tid
Identifiant du thread qui a généré l'événement.
pid
Identifiant du processus qui a généré l'événement.
