Test2::EventFacet::Error(3perl) Guide du programmeur Perl Test2::EventFacet::Error(3perl)

NOM

Test2::EventFacet::Error - Facette pour les erreurs qui doivent être affichées.

DESCRIPTION

Cette facette est utilisée lorsqu'un événement doit transmettre des erreurs.

NOTES

Cette facette a la clé de hachage 'errors', et est une liste de facettes au lieu d'un seul élément.

CHAMPS

$string = $error->{details}
$string = $error->details()
Explication de l'erreur, ou l'erreur elle-même (comme une exception). En Perl, les exceptions peuvent être des objets bénis, donc ce champ peut contenir un objet béni.
$short_string = $error->{tag}
$short_string = $error->tag()
Étiquette courte pour catégoriser l'erreur. Elle est généralement de 10 caractères ou moins, les formateurs peuvent tronquer les étiquettes plus longues.
$bool = $error->{fail}
$bool = $error->fail()
Toutes les erreurs ne sont pas fatales, certaines sont affichées après avoir déjà été traitées. Définissez cette valeur à vrai si vous souhaitez que l'erreur provoque l'échec du test. Sans cela, l'erreur est simplement un message de diagnostic qui n'a aucun effet sur le résultat global pass/fail.

SOURCE

Le référentiel de code source de Test2 peut être trouvé à https://github.com/Test-More/test-more/.
