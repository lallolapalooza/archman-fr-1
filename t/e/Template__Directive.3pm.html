NOM

Template::Directive - Générateur de code Perl pour les directives de modèle

SYNTAXE

# aucune partie utilisable par l'utilisateur à l'intérieur

DESCRIPTION

Le module "Template::Directive" définit un certain nombre de méthodes qui génèrent du code Perl pour la représentation d'exécution des diverses directives de Template Toolkit.

Il est utilisé en interne par le module Template::Parser.
