Test2::Tools::Encoding(3perl) Guide du programmeur Perl Test2::Tools::Encoding(3perl)

NOM

Test2::Tools::Encoding - Outils pour gérer l'encodage des tests basés sur Test2.

DESCRIPTION

Ce module exporte une fonction qui permet de modifier dynamiquement l'encodage de sortie à volonté.

SYNTAXE

use Test2::Tools::Encoding;
set_encoding('utf8');

EXPORTATIONS

Toutes les sous-routines sont exportées par défaut.

set_encoding($encoding)
Ceci définit l'encodage à celui que vous spécifiez. Cela n'affectera que la sortie du formateur courant, qui est généralement votre formateur de sortie TAP.
