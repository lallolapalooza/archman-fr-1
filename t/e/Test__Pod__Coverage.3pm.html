Test::Pod::Coverage(3) Documentation contribuée par Perl Test::Pod::Coverage(3)

NOM

Test::Pod::Coverage - Vérifier la couverture de pod dans votre distribution.

VERSION

Version 1.10

SYNTAXE

Dans l'un de vos fichiers de test de distribution (par exemple, "t/pod-coverage.t"):

use Test::Pod::Coverage tests=>1;
pod_coverage_ok( "Foo::Bar", "Foo::Bar is covered" );

DESCRIPTION

Test::Pod::Coverage est utilisé pour créer un test pour votre distribution, afin de s'assurer que tous les fichiers pertinents de votre distribution sont correctement documentés en pod.

Il peut également être appelé avec des paramètres de Pod::Coverage.

use Test::Pod::Coverage tests=>1;
pod_coverage_ok(
    "Foo::Bar",
    { also_private => [ qr/^[A-Z_]+$/ ], },
    "Foo::Bar, avec des fonctions de caractères majuscules comme privés",
);

Les paramètres de Pod::Coverage sont également utiles pour les classes filles qui ne documentent pas les méthodes de la classe parente. Voici un exemple de Mail::SRS.

pod_coverage_ok( "Mail::SRS" ); # Aucune exception
# Définir les trois méthodes surchargées.
my $trustme = { trustme => [qr/^(new|parse|compile)$/] };
pod_coverage_ok( "Mail::SRS::DB", $trustme );
pod_coverage_ok( "Mail::SRS::Guarded", $trustme );
pod_coverage_ok( "Mail::SRS::Reversable", $trustme );
pod_coverage_ok( "Mail::SRS::Shortcut", $trustme );

Alternativement, vous pourriez utiliser Pod::Coverage::CountParents, qui permet toujours à une classe fille de réimplémenter les méthodes de ses parents sans avoir à les redocumenter. Par exemple :

my $trustparents = { coverage_class => 'Pod::Coverage::CountParents' };
pod_coverage_ok( "IO::Handle::Frayed", $trustparents );

(Le paramètre "coverage_class" n'est pas passé à la classe de couverture avec d'autres paramètres.)

Si vous souhaitez avoir une couverture de pod pour votre module, mais que vous ne souhaitez pas faire de Test::Pod::Coverage une exigence pour son installation, créez le fichier suivant dans t/pod-coverage.t :

use Test::More;
eval "use Test::Pod::Coverage";
plan skipAll => "Test::Pod::Coverage est nécessaire pour tester la couverture de pod" if $@;
plan tests => 1;
pod_coverage_ok( "Pod::Master::Html");

Enfin, les auteurs de modules peuvent inclure ce qui suit dans un fichier t/pod-coverage.t et faire en sorte que "Test::Pod::Coverage" trouve et vérifie automatiquement tous les modules de la distribution de modules :

use Test::More;
eval "use Test::Pod::Coverage 1.00";
plan skipAll => "Test::Pod::Coverage 1.00 est nécessaire pour tester la couverture de pod" if $@;
all_pod_coverage_ok();

FONCTIONS

Toutes les fonctions décrites ci-dessous sont exportées dans l'espace de noms de l'appelant.

all_pod_coverage_ok( [$parms, ] $msg )

Vérifie que le code de pod dans tous les modules de la distribution a une couverture adéquate.

Si le hashref $parms est passé comme paramètre, il est transmis à l'objet "Pod::Coverage" que la fonction utilise. Voir la documentation de Pod::Coverage pour connaître les paramètres possibles.

L'exception est le paramètre "coverage_class", qui spécifie la classe à utiliser pour le test de couverture. Sa valeur par défaut est "Pod::Coverage".

pod_coverage_ok( $module, [$parms, ] $msg )

Vérifie que le code de pod dans $module a une couverture adéquate.

Si le hashref $parms est passé comme paramètre, il est transmis à l'objet "Pod::Coverage" que la fonction utilise. Voir la documentation de Pod::Coverage pour connaître les paramètres possibles.

L'exception est le paramètre "coverage_class", qui spécifie la classe à utiliser pour le test de couverture. Sa valeur par défaut est "Pod::Coverage".

all_modules( [@dirs] )

Renvoie une liste de tous les modules dans $dir et les répertoires en dessous. Si aucun répertoire n'est spécifié, la valeur par défaut est blib si blib existe, sinon lib.

Note : Les modules sont listés comme "Foo::Bar", et non comme "Foo/Bar.pm".

L'ordre des fichiers renvoyés dépend du système. Si vous souhaitez les trier, vous devrez le faire vous-même.

SYNOPSIS

use Test::Pod::Coverage;
all_pod_coverage_ok();

DESCRIPTION

Test::Pod::Coverage est un module Perl qui fournit des tests de couverture pour la documentation POD (Plain Old Documentation). Il vérifie si la documentation POD de vos modules Perl est adéquate et couvre toutes les fonctionnalités importantes.

FUNCTIONS

all_pod_coverage_ok()
Vérifie la couverture POD de tous les modules inclus dans le package actuel. Si des problèmes de couverture sont détectés, les tests échouent.
pod_coverage_ok($module, %options)
Vérifie la couverture POD d'un module spécifique. Les options peuvent inclure :
  • coverage_threshold : Le pourcentage minimum de couverture requis.
  • skip_modules : Une liste de modules à ignorer.
  • skip_ appellees : Une liste de fonctionnalités à ignorer.
