NOM

Text::Query::ParseSimple - Analyser la syntaxe de requête simple d'AltaVista

SYNOPIS

use Text::Query;
my $q=new Text::Query('hello and world',
                      -parse => 'Text::Query::ParseSimple',
                      -solve => 'Text::Query::SolveSimpleString',
                      -build => 'Text::Query::BuildSimpleString');

DESCRIPTION

Ce module fournit un objet qui analyse une chaîne contenant une expression de requête booléenne similaire à une « requête simple » d'AltaVista. Les éléments de l'expression de requête peuvent se voir attribuer des poids.

Sa classe de base est Text::Query::Parse.

Les expressions de requête sont compilées dans une forme interne lors de la création d'un nouvel objet ou lors de l'appel de la méthode "prepare" ; elles ne sont pas recompilées à chaque correspondance.

Les expressions de requête sont constituées de mots (séquences de caractères non blancs) ou de phrases (chaînes entre guillemets) séparés par des espaces blancs. Les mots ou phrases précédés d'un "+" doivent être présents pour que l'expression corresponde ; les mots ou phrases précédés d'un "-" doivent être absents pour que l'expression corresponde.

Les mots ou phrases peuvent éventuellement être suivis d'un nombre entre parenthèses (aucun espace blanc n'est autorisé entre le mot ou la phrase et le nombre entre parenthèses). Ce nombre spécifie le poids attribué au mot ou à la phrase. Si aucun poids n'est donné, un poids de 1 est supposé.
