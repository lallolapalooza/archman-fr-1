Test2::Util::HashBase(3perl) Guide du programmeur Perl Test2::Util::HashBase(3perl)

NOM

Test2::Util::HashBase - Construire des classes basées sur des hash.

SYNTAXE

Une classe :

package My::Class;
use strict;
use warnings;
# Génère 3 accesseurs
use Test2::Util::HashBase qw/foo -bar ^baz <bat >ban +boo/;
# Chance d'initialiser les valeurs par défaut
sub init {
    my $self = shift;    # Pas d'autres arguments
    $self->{+FOO} ||= "foo";
    $self->{+BAR} ||= "bar";
    $self->{+BAZ} ||= "baz";
    $self->{+BAT} ||= "bat";
    $self->{+BAN} ||= "ban";
    $self->{+BOO} ||= "boo";
}
sub print {
    print join ", " => map { $self->{$_} } FOO, BAR, BAZ, BAT, BAN, BOO;
}

Hériter d'elle :

package My::Subclass;
use strict;
use warnings;
# Note, vous devriez hériter avant de charger HashBase.
use base 'My::Class';
use Test2::Util::HashBase qw/bub/;
sub init {
    my $self = shift;
    # Nous obtenons les constantes de la classe parente gratuitement.
    $self->{+FOO} ||= 'SubFoo';
    $self->{+BUB} ||= 'bub';
    $self->SUPER::init();
}

L'utiliser :

package main;
use strict;
use warnings;
use My::Class;
# Elles sont toutes fonctionnellement identiques
my $one   = My::Class->new(foo => 'MyFoo', bar => 'MyBar');
my $two   = My::Class->new({foo => 'MyFoo', bar => 'MyBar'});
my $three = My::Class->new(['MyFoo', 'MyBar']);
# Lecteurs !
my $foo = $one->foo;    # 'MyFoo'
my $bar = $one->bar;    # 'MyBar'
my $baz = $one->baz;    # Valeur par défaut : 'baz'
my $bat = $one->bat;    # Valeur par défaut : 'bat'
# '>ban' signifie mutateur uniquement, pas lecteur
# '+boo' signifie pas de mutateur ni de lecteur, juste la constante BOO
# Mutateurs !
$one->set_foo('A Foo');
#'-bar' signifie lecture seule, donc le mutateur lèvera une exception (mais est défini).
$one->set_bar('A bar');
# '^baz' signifie mutateur obsolète, cela affichera un avertissement indiquant que le mutateur est
# obsolète.
$one->set_baz('A Baz');
# '<bat' signifie qu'aucun mutateur n'est défini du tout
# '+boo' signifie pas de mutateur ni de lecteur, juste la constante BOO
$one->{+FOO} = 'xxx';

DESCRIPTION

Ce paquet est utilisé pour générer des classes basées sur des hashrefs. L'utilisation de cette classe vous fournira une méthode new(), ainsi que la génération des accesseurs que vous demandez. Les accesseurs générés seront des lecteurs, des mutateurs "set_ACCESSEUR" seront également générés pour vous. Vous obtenez également des constantes pour chaque accesseur (en majuscules) qui renvoient la clé du hash pour cet accesseur. L'héritage simple est également pris en charge.

MÉTHODES

FOURNI PAR HASH BASE

$it = $class->new(%PAIRS)
$it = $class->new(\%PAIRS)
$it = $class->new(\@VALEURS_ORDONNÉES)
Crée une nouvelle instance.

HashBase n'exportera pas new() s'il existe déjà une méthode new() dans la chaîne d'héritage de votre paquet.

Si vous ne souhaitez pas cette méthode, vous pouvez définir la vôtre, il suffit de la déclarer avant de charger Test2::Util::HashBase.

package My::Package;
# Prédéclarer new() afin que HashBase ne nous en fournisse pas une.
sub new;
use Test2::Util::HashBase qw/foo bar baz/;
# Maintenant nous définissons notre propre méthode new.
sub new { ... }

Cela permet à HashBase de constater que vous avez votre propre méthode new(). Alternativement, vous pouvez définir la méthode avant de charger HashBase au lieu de simplement la déclarer, mais cela disperse vos instructions d'utilisation.

La façon la plus courante de créer un objet est de passer des paires clé/valeur où chaque clé est un attribut et chaque valeur est ce que vous souhaitez assigner à cet attribut. Aucune vérification n'est effectuée pour confirmer que les attributs ou les valeurs sont valides, vous pouvez le faire dans init() si désiré.

Si vous le souhaitez, vous pouvez passer un hashref au lieu de paires. Lorsque vous le faites, le hashref sera copié, et la copie sera renvoyée bénie en tant qu'objet. Il n'y a aucun moyen de demander à HashBase de bénir un hashref spécifique.

Dans certains cas, un objet peut n'avoir qu'un ou deux attributs, auquel cas un hashref peut être trop verbeux à votre goût. Dans ces cas, vous pouvez passer un tableau référencé avec uniquement des valeurs. Les valeurs seront assignées aux attributs dans l'ordre où les attributs ont été listés. En cas d'héritage, les attributs des classes parentes précéderont ceux des sous-classes.

CROCHETS

$self->init()
Cela vous donne la possibilité de définir des valeurs par défaut pour vos champs. Le seul argument est $self avec ses index déjà définis par le constructeur.

Remarque : Test2::Util::HashBase recherche un init en utilisant "$class->can('init')" lors de la construction. Il N'appelle PAS can() sur l'objet créé. Notez également que le résultat de la vérification est mis en cache, il n'est vérifié qu'une seule fois, la première fois qu'une instance de votre classe est créée. Cela signifie que l'ajout d'une méthode init() APRÈS la première construction entraînera son ignoration.

ACCESSEURS

LECTURE/ÉCRITURE

Pour générer des accesseurs, listez-les lors de l'utilisation du module :

use Test2::Util::HashBase qw/foo/;

Cela générera les sous-routines suivantes dans votre espace de noms :

foo()
Lecteur, utilisé pour obtenir la valeur du champ "foo".
set_foo()
Mutateur, utilisé pour définir la valeur du champ "foo".
FOO()
Constante, renvoie la clé du champ "foo" dans le hash de la classe. Les sous-classes obtiendront également cette fonction comme constante, et non simplement comme méthode, ce qui signifie qu'elle est copiée dans l'espace de noms de la sous-classe.

La principale raison d'utiliser ces constantes est d'aider à éviter les erreurs d'orthographe et les fautes de frappe similaires. Elles ne vous aideront pas si vous oubliez de préfixer le '+' cependant.

LECTURE SEULE

use Test2::Util::HashBase qw/-foo/;
set_foo()
Lève une exception indiquant que l'attribut est en lecture seule. Ceci est exporté pour remplacer tout mutateur actif pour l'attribut dans une classe parente.

MUTATEUR OBSOLÈTE

use Test2::Util::HashBase qw/^foo/;
set_foo()
Cela définira la valeur, mais vous avertira également que la méthode est obsolète.

AUCUN MUTATEUR

use Test2::Util::HashBase qw/<foo/;

Ne fournit qu'un lecteur, aucune méthode "set_foo" n'est définie du tout.

AUCUN LECTEUR

use Test2::Util::HashBase qw/>foo/;

Ne fournit qu'un mutateur ("set_foo"), aucune méthode "foo" n'est définie du tout.

CONSTANTE UNIQUEMENT

use Test2::Util::HashBase qw/+foo/;

Cela ne crée aucune méthode pour vous, cela ajoute simplement la constante "FOO".
