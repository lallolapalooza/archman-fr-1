Test2::Compare::Bag(3perl) Guide de référence des programmeurs Perl Test2::Compare::Bag(3perl)

NOM

Test2::Compare::Bag - Représentation interne d'un sac de comparaison.

DESCRIPTION

Ce module est une représentation interne d'un sac à des fins de comparaison.

MÉTHODES

$bool = $arr->ending
$arr->set_ending($bool)
Mettez ceci à vrai si vous souhaitez échouer lorsque le tableau validé a plus d'éléments que la vérification. C'est-à-dire, si vous vérifiez 4 éléments mais que le tableau a 5 valeurs, cela échouera et listera cet élément non correspondant dans le tableau comme inattendu. S'il est réglé sur faux, on suppose que les éléments supplémentaires ne vous intéressent pas.
$arrayref = $arr->items()
Retourne la référence du tableau des valeurs à vérifier dans le tableau.
$arr->set_items($arrayref)
Accepte une référence de tableau.

Note : il n'y a pas de validation lors de l'utilisation de "set_items", il est préférable d'utiliser l'interface "add_item".

$name = $arr->name()
Retourne toujours la chaîne "<BAG>".
$bool = $arr->verify(got => $got, exists => $bool)
Vérifie si $got est une référence de tableau ou non.
$arr->add_item($item)
Ajoute un élément à la liste des valeurs à vérifier.
@deltas = $arr->deltas(got => $got, convert => \&convert, seen => \%seen)
Trouve les différences entre les valeurs attendues du sac et celles de la référence de tableau $got.
