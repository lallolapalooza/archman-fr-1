Test2::Manual(3perl) Guide de référence des programmeurs Perl Test2::Manual(3perl)

NOM

Test2::Manual - Hub de documentation pour Test2 et Test2-Suite.

DESCRIPTION

Ceci est le hub pour la documentation de Test2 et Test2::Suite.

ÉCRIRE DES TESTS

Le POD Test2::Manual::Testing est le hub pour la documentation relative à l'écriture de tests.

ÉCRIRE DES OUTILS

Le POD Test2::Manual::Tooling est le hub pour la documentation relative à l'écriture de nouveaux outils.

DÉTAILS ET FONCTIONNEMENT INTERNE

Le POD Test2::Manual::Anatomy est le hub pour la documentation du fonctionnement interne des composants de Test2.

UNE NOTE SUR LA CONCURRENCE (PRISE EN CHARGE DU FORK ET DU THREADING)

Le POD Test2::Manual::Concurrency documente la politique de prise en charge de la concurrence pour Test2.

CONTRIBUER

Le POD Test2::Manual::Contributing s'adresse aux personnes qui souhaitent contribuer directement à Test2 ou Test2::Suite.

VOIR AUSSI

Test2 - Test2 lui-même.

Test2::Suite - Premiers outils construits à l'aide de Test2.

SOURCE

Le dépôt de code source de Test2-Manual se trouve à l'https://github.com/Test-More/test-more/.
