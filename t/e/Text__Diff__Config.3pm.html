NOM

Text::Diff::Config - configuration globale pour Text::Diff (en tant que module séparé).

SYNTAXE

use Text::Diff::Config;

$Text::Diff::Config::Output_Unicode = 1;

DESCRIPTION

Ce module configure Text::Diff et ses modules associés. Il contient actuellement une seule variable globale $Text::Diff::Config::Output_Unicode qui est un indicateur booléen, qui si activé, affiche les caractères unicode tels quels sans les échapper sous la forme " \x{HHHH} " au préalable.

Il est initialisé à la valeur de $ENV{DIFF_OUTPUT_UNICODE} , mais peut être défini à une valeur différente à l'exécution, y compris en utilisant local.
