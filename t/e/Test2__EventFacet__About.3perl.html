Test2::EventFacet::About(3perl) Guide de référence du programmeur Perl Test2::EventFacet::About(3perl)

NOM

Test2::EventFacet::About - Facette avec les détails de l'événement.

DESCRIPTION

Cette facette contient des informations sur l'événement, comme le paquet de l'événement.

CHAMPS

$chaîne = $about->{details}
$chaîne = $about->details()
Résumé de l'événement.
$paquet = $about->{package}
$paquet = $about->package()
Nom du paquet de l'événement.
$bool = $about->{no_display}
$bool = $about->no_display()
Vrai si l'événement doit être ignoré par les formateurs.
$uuid = $about->{uuid}
$uuid = $about->uuid()
Sera défini sur un uuid si le marquage uuid a été activé.
$uuid = $about->{eid}
$uuid = $about->eid()
Un identifiant unique (pour le travail de test) pour l'événement.

SOURCE
