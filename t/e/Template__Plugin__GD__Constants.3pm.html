NOM

Template::Plugin::GD::Constants - Interface aux constantes du module GD

SYNTAXE

[% USE gdc = GD.Constants %]
# --> les constantes gdc.gdBrushed, gdc.gdSmallFont, gdc.GD_CMP_IMAGE
#     sont maintenant disponibles

EXEMPLES

[% FILTER null;
    USE gdc = GD.Constants;
    USE im  = GD.Image(200,100);
    black = im.colorAllocate(0  ,0,  0);
    red   = im.colorAllocate(255,0,  0);
    r = im.string(gdc.gdLargeFont, 10, 10, "Texte Rouge Large", red);
    im.png | stdout(1);
   END;
-%]

DESCRIPTION

Le plugin GD.Constants fournit l'accès aux différentes constantes du module GD (telles que gdBrushed, gdSmallFont, gdTransparent, GD_CMP_IMAGE etc.). Lorsque GD.pm est utilisé en Perl, il exporte diverses constantes dans l'espace de noms de l'appelant. Ce plugin rend ces constantes exportées disponibles en tant que variables de template.

Voir Template::Plugin::GD::Image et GD pour des exemples et des détails supplémentaires.
