Test2::Event::V2(3perl) Guide de référence des programmeurs Perl Test2::Event::V2(3perl)

NOM

Test2::Event::V2 - Événement de deuxième génération.

DESCRIPTION

C'est le type d'événement qui devrait être utilisé à la place de Test2::Event ou de ses sous-classes héritées.

SYNTAXE

UTILISATION D'UN CONTEXTE

use Test2::API qw/context/;
sub my_tool {
    my $ctx = context();
    my $event = $ctx->send_ev2(info => [{tag => 'NOTE', details => "Ceci est une note"}]);
    $ctx->release;
    return $event;
}

UTILISATION DU CONSTRUCTEUR

use Test2::Event::V2;
my $e = Test2::Event::V2->new(
    trace => {frame => [$PKG, $FILE, $LINE, $SUBNAME]},
    info  => [{tag => 'NOTE', details => "Ceci est une note"}],
);

MÉTHODES

Cette classe hérite de Test2::Event.

$fd = $e->facet_data()
Ceci retournera un hashref de données de facette. Chaque hash de facette sera une copie superficielle de l'original.
$about = $e->about()
Ceci retournera le hashref de la facette 'about'.

NOTE : Ceci retournera le hashref interne, pas une copie.

$trace = $e->trace()
Ceci retournera la facette 'trace', normalement bénie (mais ce n'est pas imposé lorsque la trace est définie en utilisant set_trace().

NOTE : Ceci retournera la trace interne, pas une copie.

MUTATION

$e->add_amnesty({...})
Hérité de Test2::Event. Ceci peut être utilisé pour ajouter des facettes 'amnesty' à un événement existant. Chaque nouvel élément est ajouté à la FIN de la liste.

NOTE : Les éléments SONT bénis lorsqu'ils sont ajoutés.

$e->add_hub({...})
Hérité de Test2::Event. Ceci est utilisé par les hubs pour marquer les événements au fur et à mesure qu'ils passent. Les nouveaux éléments sont ajoutés au DÉBUT de la liste.

NOTE : Les éléments NE SONT PAS bénis lorsqu'ils sont ajoutés.

$e->set_uuid($UUID)
Hérité de Test2::Event, surchargé pour également vivifier/muter la facette 'about'.
$e->set_trace($trace)
Hérité de Test2::Event qui vous permet de changer la trace.

Note : Cette méthode ne bénit/clone pas la trace pour vous. De nombreuses choses s'attendront à ce que la trace soit bénie, vous devriez donc probablement le faire.

MÉTHODES DE SUPPORT LEGACY

Ceux-ci sont tous importés de Test2::Util::Facets2Legacy, voir ce module ou Test2::Event pour la documentation sur ce qu'ils font.

causes_fail
diagnostics
global
increments_count
no_display
sets_plan
subtest_id
summary
terminate

MÉTA-DONNÉES TIERS

Cet objet consomme Test2::Util::ExternalMeta qui fournit un moyen cohérent pour vous d'attacher des méta-données aux instances de cette classe. Ceci est utile pour les outils, les plugins et autres extensions.
