NOM

Test2::EventFacet::Render - Facette qui dicte comment rendre un événement.

DESCRIPTION

Cette facette est utilisée pour dicter comment l'événement doit être rendu par les outils de rendu standard de test2. Si cette facette est présente, alors SEULEMENT ce qui y est spécifié sera rendu. On suppose que tout ce qui est important ou digne d'être mentionné s'y trouve, aucune autre facette ne sera prise en compte pour le rendu/affichage.

Cette facette est de type liste, vous pouvez ajouter autant d'éléments que nécessaire.

CHAMPS

$string = $render->[#]->{details}
$string = $render->[#]->details()
Texte lisible par l'homme pour l'affichage.
$string = $render->[#]->{tag}
$string = $render->[#]->tag()
Balise qui doit préfixer/identifier le texte principal.
$string = $render->[#]->{facet}
$string = $render->[#]->facet()
Optionnel, si le texte d'affichage a été généré à partir d'une autre facette, cela doit indiquer de quelle facette il provenait.
$mode = $render->[#]->{mode}
$mode = $render->[#]->mode()
calculé
Calculé signifie que la facette a été générée à partir d'une autre facette. Les facettes calculées peuvent être effacées et régénérées chaque fois que l'état de l'événement change.
remplacer
Remplacer signifie que la facette est destinée à remplacer le rendu normal de l'événement.
