NOM

Test2::Hub::Subtest - Hub utilisé par les sous-tests

DESCRIPTION

Les sous-tests utilisent ce hub pour acheminer les événements.

OPTIONS

$bool = $hub->manual_skip_all
$hub->set_manual_skip_all($bool)
La valeur par défaut est false.

Normalement, un événement de plan de saut ('skip-all') entraînera l'arrêt de l'exécution d'un sous-test. Ceci est réalisé via "last LABEL" vers une étiquette dans le code du sous-test. La plupart du temps, cela convient parfaitement. Il existe cependant des cas où ce contrôle de flux provoque des problèmes.

Cette option vous permet de désactiver la logique d'abandon pour le hub. Lorsque cette option est activée (true), vous êtes responsable de vous assurer qu'aucun événement supplémentaire n'est généré.
