NOM

Template::Plugin::GD::Graph::mixed - Créer des graphiques mixtes avec axes et légendes

SYNTAXE

[% USE g = GD.Graph.mixed(x_size, y_size); %]

EXEMPLES

[% FILTER null;
    data = [
        ["1er","2ème","3ème","4ème","5ème","6ème","7ème", "8ème", "9ème"],
        [    1,    2,    5,    6,    3,  1.5,   -1,    -3,    -4],
        [   -4,   -3,    1,    1,   -3, -1.5,   -2,    -1,     0],
        [    9,    8,    9,  8.4,  7.1,  7.5,    8,     3,    -3],
        [  0.1,  0.2,  0.5,  0.4,  0.3,  0.5,  0.1,     0,   0.4],
        [ -0.1,    2,    5,    4,   -3,  2.5,  3.2,     4,    -4],
    ];  

    USE my_graph = GD.Graph.mixed();

    my_graph.set(
        types => ['lignes', 'lignes', 'points', 'zone', 'lignespoints'],
        default_type => 'points',
    );  

    my_graph.set(

        x_label         => 'Étiquette X',
        y_label         => 'Étiquette Y',
        title           => 'Un Graphique de Type Mixte',
        y_max_value     => 10, 
        y_min_value     => -5,
        y_tick_number   => 3,
        y_label_skip    => 0,
        x_plot_values   => 0,
        y_plot_values   => 0,

        long_ticks      => 1, 
        x_ticks         => 0,  

        legend_marker_width => 24,
        line_width      => 3,
        marker_size     => 5,
        bar_spacing     => 8,
        transparent     => 0,
    );

    my_graph.set_legend('un', 'deux', 'trois', 'quatre', 'cinq', 'six');
    my_graph.plot(data).png | stdout(1);
   END;
-%]

DESCRIPTION

Le plugin GD.Graph.mixed fournit une interface à la classe GD::Graph::mixed définie par le module GD::Graph. Il permet de tracer un ou plusieurs ensembles de données (x,y) avec divers styles (lignes, points, barres, aires, etc.).

Voir GD::Graph pour plus de détails.
