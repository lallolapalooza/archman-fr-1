NOM

Test::Alien::Build - Outils pour tester Alien::Build + alienfile

VERSION

version 2.84

SYNOPSIS

use Test2::V0;
use Test::Alien::Build;

# renvoie une instance de Alien::Build.
my $build = alienfile_ok q{
  use alienfile;

  plugin 'My::Plugin' => (
    foo => 1,
    bar => 'string',
    ...
  );
};

alien_build_ok 'construit correctement.';

done_testing;

DESCRIPTION

Ce module fournit des outils pour tester Alien::Build et alienfile. En dehors du développement de base d'Alien::Build, il est probablement plus utile pour les développeurs de plugins Alien::Build.

Ce module désactive également un certain nombre de variables d'environnement spécifiques à Alien::Build, afin de rendre les tests reproductibles même lorsque des remplacements sont définis dans différents environnements. Donc, si vous souhaitez tester ces variables dans divers états, vous devriez les définir explicitement dans votre script de test. Ces variables sont désactivées si elles sont définies : "ALIEN_BUILD_PRELOAD" "ALIEN_BUILD_POSTLOAD" "ALIEN_INSTALL_TYPE".

FONCTIONS

alienfile

my $build = alienfile;
my $build = alienfile q{ use alienfile ... };
my $build = alienfile filename => 'alienfile';

Crée une instance de Alien::Build à partir de l'alienfile donné. Les deux premières formes sont des abréviations.

my $build = alienfile;
# est la même chose que
my $build = alienfile filename => 'alienfile';

et

my $build = alienfile q{ use alienfile ... };
# est la même chose que
my $build = alienfile source => q{ use alienfile ... };

Sauf que la deuxième forme abrégée définit le numéro de ligne avant de fournir la source à Alien::Build afin que vous obteniez des diagnostics avec les numéros de ligne corrects.

source
La source de l'alienfile sous forme de chaîne. Vous devez spécifier l'un des arguments "source" ou "filename".
filename
Le nom de fichier de l'alienfile. Vous devez spécifier l'un des arguments "source" ou "filename".
root
La racine de construction (build root).
stage
La zone de staging pour la construction.
prefix
Le préfixe d'installation pour la construction.

alienfile_ok

my $build = alienfile_ok;
my $build = alienfile_ok q{ use alienfile ... };
my $build = alienfile_ok filename => 'alienfile';
my $build = alienfile_ok $build;

Identique à "alienfile" ci-dessus, sauf qu'elle s'exécute comme un test et ne génère pas d'exception en cas d'échec (elle renvoie undef à la place).

[version 1.49]

À partir de la version 1.49, vous pouvez également passer une instance d'Alien::Build déjà formée. Cela vous permet de faire quelque chose comme ceci :

subtest 'un sous-test' => sub {
  my $build = alienfile q{ use alienfile; ... };
  alienfile_skip_if_missing_prereqs; # saute si les prérequis de l'alienfile sont manquants
  alienfile_ok $build;  # validation/échec différé de la compilation de l'alienfile
};

alienfile_skip_if_missing_prereqs

alienfile_skip_if_missing_prereqs;
alienfile_skip_if_missing_prereqs $phase;

Saute le test ou le sous-test si les prérequis de l'alienfile sont manquants. Si $phase n'est pas donné, alors soit "share", soit "system" sera détecté.

alien_install_type_is

alien_install_type_is $type;
alien_install_type_is $type, $name;

Test simple pour vérifier si le type d'installation est celui attendu. $type doit être l'un des "system" ou "share".

alien_download_ok

my $file = alien_download_ok;
my $file = alien_download_ok $name;

Effectue une tentative de téléchargement et vérifie qu'un fichier ou un répertoire en résulte. Renvoie le fichier ou le répertoire en cas de succès. Renvoie "undef" sinon.

alien_extract_ok

my $dir = alien_extract_ok;
my $dir = alien_extract_ok $archive;
my $dir = alien_extract_ok $archive, $name;
my $dir = alien_extract_ok undef, $name;

Effectue une tentative d'extraction et vérifie qu'un répertoire en résulte. Renvoie le répertoire en cas de succès. Renvoie "undef" sinon.

alien_build_ok

my $alien = alien_build_ok;
my $alien = alien_build_ok $name;
my $alien = alien_build_ok { class => $class };
my $alien = alien_build_ok { class => $class }, $name;

Exécute les étapes de téléchargement et de construction. Valide si la construction réussit. Renvoie une instance de Alien::Base qui peut être passée à "alien_ok" de Test::Alien. Renvoie "undef" si le test échoue.

Options

class
La classe de base à utiliser pour votre alien. Il s'agit de Alien::Base par défaut. Doit être une sous-classe de Alien::Base, ou au moins adhérer à son API.

alien_build_clean

alien_build_clean;

Supprime tous les fichiers de la construction actuelle, à l'exception du préfixe d'exécution. Ceci aide à tester que l'installation finale ne dépendra pas des fichiers de construction.

alien_clean_install

alien_clean_install;

Exécute "$build->clean_install", et vérifie que cela n'a pas planté.

alien_checkpoint_ok

alien_checkpoint_ok;
alien_checkpoint_ok $test_name;

Teste le point de contrôle (checkpoint) d'une construction.

alien_resume_ok

alien_resume_ok;
alien_resume_ok $test_name;

Teste la reprise (resume) d'une construction sauvegardée à un point de contrôle.

alien_rc

alien_rc $code;

Crée le fichier "rc.pl" dans un répertoire temporaire et définit ALIEN_BUILD_RC. Utile pour tester des plugins qui devraient être appelés depuis "~/.alienbuild/rc.pl". Notez qu'en raison de la nature de la façon dont le fichier "~/.alienbuild/rc.pl" fonctionne, vous ne pouvez l'utiliser qu'une seule fois !

alien_subtest

alien_subtest $test_name => sub {
  ...
};

Efface l'objet de construction et l'objet de construction avant et après le sous-test.
