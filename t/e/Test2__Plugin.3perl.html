NOM

Test2::Plugin - Documentation pour les plugins

DESCRIPTION

Les plugins sont des paquets qui provoquent des changements de comportement, ou d'autres effets secondaires pour le fichier de test qui les charge. Ils ne devraient pas exporter de fonctions, ni fournir d'outils. Les plugins devraient être des unités de fonctionnalité distinctes.

Si vous souhaitez combiner des changements de comportement avec des outils, vous devriez écrire un plugin, un module d'outils et un bundle qui les charge tous les deux.

FAQ

Devrais-je sous-classer Test2::Plugin?
Non. Actuellement, cette classe est vide. Il est possible que nous voulions ajouter des comportements à l'avenir, auquel cas nous ne voulons pas que quiconque la sous-classe déjà.

COMMENT ÉCRIRE UN PLUGIN?

Écrire un plugin n'est pas aussi simple qu'écrire un Test2::Bundle, ou qu'écrire des Test2::Tools. Les plugins modifient les comportements ou provoquent des effets secondaires souhaitables. Pour y parvenir, vous avez généralement besoin d'une méthode import() personnalisée qui appelle une ou plusieurs fonctions fournies par le paquet Test2::API.

Si vous souhaitez écrire un plugin, vous devriez examiner les plugins existants, ainsi que la documentation de Test2::API et Test2::Hub. Il n'y a pas de formule pour un plugin, ils sont généralement uniques, cependant les règles cohérentes sont qu'ils ne devraient pas charger d'autres plugins, ni exporter de fonctions.
