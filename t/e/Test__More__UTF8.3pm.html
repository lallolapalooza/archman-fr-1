NOM

Test::More::UTF8 - Amélioration de Test::More pour les projets basés sur UTF8

SYNTHÈSE

use Test::More;
use Test::More::UTF8;
# maintenant nous pouvons facilement utiliser des chaînes marquées sans avertissements comme "Wide character in print ..."
is("\x{410}","\x{420}"); # obtenu un message d'échec sans avertissements

LIMITATIONS

Ce module n'a de raison d'être que pour perl 5.8 et supérieur

FONCTIONNALITÉS

Ce module active également par défaut le pragma utf8. Pour désactiver cela, ajoutez l'option "-utf8"

use Test::More::UTF8 qw(-utf8);

Par défaut, la fonction binmode ':utf8' sera appliquée à tous les descripteurs de fichiers de sortie : failure_output, todo_output, output. Il est possible de choisir seulement certains d'entre eux

use Test::More::UTF8 qw(failure); # active :utf8 uniquement sur failure_output
use Test::More::UTF8 qw(todo); # active :utf8 uniquement sur todo_output
use Test::More::UTF8 qw(out); # active :utf8 uniquement sur output
