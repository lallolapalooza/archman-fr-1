NOM

Template::Plugin::HTML - Plugin pour créer des éléments HTML

SYNTAXE

[% USE HTML %]
[% HTML.escape("if (a < b && c > d) ..." %]
[% HTML.element(table => { border => 1, cellpadding => 2 }) %]
[% HTML.attributes(border => 1, cellpadding => 2) %]

DESCRIPTION

Le plugin "HTML" est un plugin très basique, implémentant quelques méthodes utiles pour générer du HTML.

MÉTHODES

escape(text)

Retourne le texte source avec les caractères réservés HTML tels que "<", ">", etc., correctement échappés en leurs équivalents d'entités.

attributes(hash)

Retourne les éléments du tableau associatif passé par référence correctement formatés (par exemple, les valeurs citées et correctement échappées) comme attributs pour un élément HTML.

add_attribute(attributes)

Ceci fournit un moyen d'ajouter progressivement des attributs à l'objet. Les valeurs passées sont stockées dans l'objet. Appeler element avec juste une balise ou des attributs sans paramètres utilisera les attributs sauvegardés.

USE tag = HTML;
tag.add_attributes( { class => 'navbar' } );
tag.add_attributes( { id => 'foo' } );
tag.add_attributes( { class => 'active' } );
tag.element( 'li' ); # <li class="navbar active" id="foo">

Cette méthode a deux alias : add_attribute() et add().

replace_attribute(attributes)

Ceci remplacera une valeur d'attribut au lieu de l'ajouter à l'existant.

USE tag = HTML;
tag.add_attributes( { class => 'navbar' } );
tag.add_attributes( { id => 'foo' } );
tag.replace_attributes( { class => 'active' } );
tag.element( 'li' ); # <li class="active" id="foo">

Cette méthode a deux alias : replace_attribute() et replace().

clear_attributes

Efface tous les attributs sauvegardés

element(type, attributes)

Génère un élément HTML du type spécifié et avec les attributs fournis sous forme de référence de tableau associatif optionnelle comme deuxième argument ou sous forme d'arguments nommés.

[% HTML.element(table => { border => 1, cellpadding => 2 }) %]
[% HTML.element('table', border=1, cellpadding=2) %]
[% HTML.element(table => attribs) %]

DEBUGGING

Le plugin HTML accepte une option "sorted" comme argument du constructeur qui, lorsqu'elle est définie sur une valeur vraie, fait que les attributs générés par la méthode attributes() (directement ou via element()) sont retournés dans un ordre trié. L'ordre des attributs n'a pas d'importance en HTML, mais ceci est principalement fourni à des fins de débogage où il est utile d'avoir les attributs générés dans un ordre déterministe plutôt que dans l'ordre dans lequel le hash a eu envie de retourner les clés.

[% USE HTML(sorted=1) %]
[% HTML.element( foo => { charlie => 1, bravo => 2, alpha => 3 } ) %]

génère :

<foo alpha="3" bravo="2" charlie="1">
