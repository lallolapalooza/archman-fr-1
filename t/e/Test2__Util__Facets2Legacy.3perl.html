Test2::Util::Facets2Legacy(3perl) Guide de référence des programmeurs Perl Test2::Util::Facets2Legacy(3perl)

NOM

Test2::Util::Facets2Legacy - Convertir des données de facettes en API d'événements héritée.

DESCRIPTION

Ce module exporte plusieurs sous-routines de l'ancienne API d'événements (voir Test2::Event). Ces sous-routines peuvent être utilisées comme méthodes sur tout objet fournissant une méthode personnalisée facet_data(). Ces sous-routines peuvent également être utilisées comme fonctions prenant un hachage de données de facettes comme arguments.

SYNOPIS

EN TANT QUE MÉTHODES

package My::Event;
use Test2::Util::Facets2Legacy ':ALL';
sub facet_data { return { ... } }

Puis pour l'utiliser :

my $e = My::Event->new(...);
my $causes_fail = $e->causes_fail;
my $summary     = $e->summary;
....

EN TANT QUE FONCTIONS

use Test2::Util::Facets2Legacy ':ALL';
my $f = {
    assert => { ... },
    info => [{...}, ...],
    control => {...},
    ...
};
my $causes_fail = causes_fail($f);
my $summary     = summary($f);

NOTE SUR LES CYCLES

Lorsqu'elles sont utilisées comme méthodes, toutes ces sous-routines appellent "$e->facet_data()". La méthode par défaut facet_data() dans Test2::Event repose sur les méthodes héritées que ce module émule pour fonctionner. En conséquence, il est très facile de créer des bugs de récursion infinie.

Ces méthodes disposent d'une détection de cycles et lèveront une exception tôt si un cycle est détecté. uuid() est actuellement la seule sous-routine de cette bibliothèque à avoir un comportement de repli lorsque des cycles sont détectés.

EXPORTATIONS

Rien n'est exporté par défaut. Vous devez spécifier quelles méthodes importer, ou utiliser la balise ':ALL'.

$bool = $e->causes_fail()
$bool = causes_fail($f)
Vérifie si l'événement ou les facettes résultent en un état d'échec.
$bool = $e->diagnostics()
$bool = diagnostics($f)
Vérifie si l'événement ou les facettes contiennent des informations de diagnostic.
$bool = $e->global()
$bool = global($f)
Vérifie si l'événement ou les facettes doivent être traités globalement.
$bool = $e->increments_count()
$bool = increments_count($f)
Vérifie si l'événement ou les facettes effectuent une assertion.
$bool = $e->no_display()
$bool = no_display($f)
Vérifie si l'événement ou les facettes doivent être affichés ou masqués.
($max, $directive, $reason) = $e->sets_plan()
($max, $directive, $reason) = sets_plan($f)
Vérifie si l'événement ou les facettes définissent un plan, et renvoie les détails du plan.
$id = $e->subtest_id()
$id = subtest_id($f)
Obtient l'ID du sous-test, s'il existe.
$string = $e->summary()
$string = summary($f)
Obtient le résumé de l'événement ou du hachage de facettes, s'il existe.
$undef_or_int = $e->terminate()
$undef_or_int = terminate($f)
Vérifie si l'événement ou les facettes doivent entraîner la terminaison du processus, si c'est le cas, le code de sortie est renvoyé (qui pourrait être 0). undef est renvoyé si aucune terminaison n'est demandée.
$uuid = $e->uuid()
$uuid = uuid($f)
Obtient l'UUID des facettes ou de l'événement.

Note : Cela se rabattra sur "$e->SUPER::uuid()" si un cycle est détecté et qu'un événement est utilisé comme argument.
