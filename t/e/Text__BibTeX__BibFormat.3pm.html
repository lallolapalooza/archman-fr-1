NOM

Text::BibTeX::BibFormat - formate les entrées de bibliographie

SYNTAXE

# En supposant que $entry provient d'une base de données de structure 'Bib'
# (c'est-à-dire qu'elle est bénie dans la classe BibEntry, qui hérite
# de la méthode format de BibFormat) :
@blocs = $entry->format;

DESCRIPTION

La classe "Text::BibTeX::BibFormat" est une classe de base de "Text::BibTeX::BibEntry" pour formater les entrées de bibliographie. Elle effectue ainsi le travail principal de tout programme qui espérerait supplanter BibTeX lui-même ; l'autre travail important (le tri) est géré par sa classe associée, "Text::BibTeX::BibSort".

"BibFormat" (le préfixe "Text::BibTeX" sera omis par souci de brièveté) prend en compte presque toutes les options de structure décrites dans Text::BibTeX::Bib ; elle ignore seulement celles qui couvrent le tri, actuellement juste "sortby". En particulier, toutes les options de "balisage" contrôlent quel langage est généré par "BibFormat" ; si aucune de ces options n'est définie, alors elle générera du texte simple, sans balisage.

La seule méthode dans l'interface documentée de "BibFormat" (jusqu'à présent) est "format". (La classe définit de nombreuses autres méthodes, mais celles-ci ne devraient pas être nécessaires aux personnes extérieures, elles sont donc non documentées et sujettes à changement.)

MÉTHODES

format ()
Formate une seule entrée pour inclusion dans la bibliographie d'un document. Le traitement exact effectué dépend fortement du type d'entrée et des champs présents ; en général, vous devriez pouvoir joindre les sorties de "format" pour créer un paragraphe unique à inclure dans un document, quel que soit le langage de balisage avec lequel vous travaillez.

Renvoie une liste de "blocs", qui peuvent soit être assemblés comme des phrases (pour une bibliographie traditionnelle "serrée") soit imprimés sur des lignes séparées (pour un format de bibliographie "ouverte"). Chaque bloc est une référence à une liste de phrases ; les phrases doivent être jointes avec une période intercalée. Chaque phrase est soit une seule chaîne, soit une liste de propositions ; les propositions doivent être jointes avec une virgule intercalée. Chaque proposition est juste une simple chaîne.

Voir le code source de "btformat" pour un exemple sur la façon d'utiliser la sortie de "format".

VOIR AUSSI

Text::BibTeX::Structure, Text::BibTeX::Bib, Text::BibTeX::BibSort
