Test2::Tools::Exception(3perl) Guide de référence du programmeur Perl Test2::Tools::Exception(3perl)

NOM

Test2::Tools::Exception - Outils basés sur Test2 pour tester les exceptions

DESCRIPTION

Ceci est l'implémentation Test2 du code utilisé pour tester les exceptions. Ceci est similaire à Test::Fatal, mais il fait intentionnellement beaucoup moins.

SYNTAXE

use Test2::Tools::Exception qw/dies lives/;
like(
    dies { die 'xxx' },
    qr/xxx/,
    "Got exception"
);
ok(lives { ... }, "did not die") or note($@);

EXPORTATIONS

Toutes les subs sont exportées par défaut.

$e = dies { ... }
Ceci piègera toute exception lancée par le bloc de code. Si aucune exception n'est lancée, la sub retournera undef. Si une exception est lancée, elle sera retournée. Cette fonction préserve $@, elle ne sera pas modifiée par rapport à sa valeur avant l'appel de la sub.
$bool = lives { ... }
Ceci piègera toute exception lancée dans le bloc de code. Il retournera vrai lorsqu'il n'y a pas d'exception, et faux lorsqu'il y en a une. $@ est préservé de avant l'appel de la sub lorsqu'il n'y a pas d'exception. Lorsqu'une exception est interceptée, $@ contiendra l'exception afin que vous puissiez l'examiner.
$bool = try_ok { ... }
$bool = try_ok { ... } "Description du test"
Ceci exécutera le bloc de code en interceptant toute exception. S'il n'y a pas d'exception, un événement de réussite sera émis. Si le test échoue, un événement d'échec sera émis, et l'exception sera rapportée comme diagnostic.

Note : Cette fonction ne préserve pas $@ en cas d'échec, elle sera définie à l'exception que le bloc de code lance, ceci est intentionnel afin que vous puissiez obtenir l'exception si vous le souhaitez.

DIFFÉRENCES AVEC TEST::FATAL

Test::Fatal définit $Test::Builder::Level de telle sorte que les tests échoués à l'intérieur du bloc d'exception rapportent la ligne où exception() est appelée. Je suis en désaccord avec cela, et je pense que la ligne réelle du test échoué est plus importante. Finalement, bien que Test::Fatal ne puisse pas être modifié, les gens dépendent probablement déjà de ce comportement.
