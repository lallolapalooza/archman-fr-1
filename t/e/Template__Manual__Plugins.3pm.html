Template::Manual::Plugins - Plugins standards

PLUGINS DU TEMPLATE TOOLKIT

Les modules de plugins suivants sont distribués avec le Template Toolkit. Certains plugins sont des interfaces vers des modules externes (détaillés ci-dessous) qui doivent être téléchargés depuis n'importe quel site CPAN et installés avant d'utiliser le plugin.

Assert

De nouveau disponible dans la version 2.20 ! Le plugin Assert ajoute une méthode virtuelle "assert" que vous pouvez utiliser pour intercepter les valeurs indéfinies.

Par exemple, considérez ce bout de template :

[% user.name %]

Si "user.name" est une valeur indéfinie, TT l'ignorera silencieusement et n'affichera rien. Si vous "USE"z le plugin "assert", vous pouvez insérer la méthode "assert" entre les éléments "user" et "name", comme ceci :

[% user.assert.name %]

Maintenant, si "user.name" est une valeur indéfinie, une exception sera levée :

erreur d'assertion - valeur indéfinie pour name

CGI

Le plugin CGI est un wrapper pour la librairie CGI.pm de Lincoln Stein. Le plugin est distribué avec le Template Toolkit (voir Template::Plugin::CGI) et le module CGI lui-même est distribué avec les versions récentes de Perl ou est disponible sur CPAN.

[% USE CGI %]
[% CGI.param('nom_parametre') %]
[% CGI.start_form %]
[% CGI.popup_menu( Nom   => 'couleur',
                   Valeurs => [ 'Vert', 'Brun' ] ) %]
[% CGI.end_form %]

Datafile

Il offre une interface pour lire des données stockées dans un fichier texte au format simple, délimité par des virgules. La première ligne du fichier spécifie les noms des champs qui doivent être séparés par toute séquence de caractères non alphanumériques. Les lignes suivantes définissent les données en utilisant le même délimiteur que dans la première ligne. Les lignes vides et les commentaires (lignes commençant par #) sont ignorés. Voir Template::Plugin::Datafile pour plus de détails.

/tmp/mesdonnees:

# définir les noms pour chaque champ
id : email : nom : tel
# voici les données
fred : fred@ici.com : Fred Smith : 555-1234
bill : bill@ici.com : Bill White : 555-5678

Exemple :

[% USE liste_utilisateurs = datafile('/tmp/mesdonnees') %]
[% POUR utilisateur DANS liste_utilisateurs %]
   [% utilisateur.nom %] ([% utilisateur.id %])
[% FIN %]

Date

Le plugin Date fournit un moyen simple de générer des chaînes de date et d'heure formatées en déléguant à la routine POSIX strftime(). Voir Template::Plugin::Date et POSIX pour plus de détails.

[% USE date %]
[% date.format %]           # heure/date actuelle
Dernière modification : [% date.format(template.modtime) %]

Directory

Le plugin Directory fournit une interface simple pour un répertoire et ses fichiers. Voir Template::Plugin::Directory pour plus de détails.

[% USE dir = Directory('/tmp') %]
[% POUR fichier DANS dir.files %]
    # tous les fichiers simples du répertoire
[% FIN %]
[% POUR fichier DANS dir.dirs %]
    # tous les sous-répertoires
[% FIN %]

DBI

Le plugin "DBI" n'est plus distribué dans le cadre du Template Toolkit (depuis la version 2.15). Il est maintenant disponible en tant que distribution indépendante Template::DBI sur CPAN.

Dumper

Le plugin Dumper fournit une interface vers le module Data::Dumper. Voir Template::Plugin::Dumper et Data::Dumper pour plus de détails.

[% USE dumper(indent=0, pad="<br>") %]
[% dumper.dump(mavariable, taVariable) %]

File

Le plugin File fournit une généralisation des fichiers et peut être utilisé pour obtenir des informations sur des fichiers spécifiques dans un système de fichiers. Voir Template::Plugin::File pour plus de détails.

[% USE File('/tmp/foo.html') %]
[% File.name %]     # foo.html
[% File.dir %]      # /tmp
[% File.mtime %]    # temps de modification

Filter

Ce module implémente une classe de plugin de base qui peut être héritée pour créer vos propres modules définissant et installant de nouveaux filtres.

package MonOrg::Template::Plugin::MonFiltre;
use Template::Plugin::Filter;
use base qw( Template::Plugin::Filter );
sub filter {
    my ($self, $text) = @_;
    # ... modifier $text ...
    return $text;
}

Exemple d'utilisation :

# maintenant le charger...
[% USE MonFiltre %]
# ... et utiliser l'objet retourné comme filtre
[% FILTER $MonFiltre %]
  ...
[% FIN %]

Voir Template::Plugin::Filter pour plus de détails.

Format

Le plugin Format fournit un moyen simple de formater du texte selon un format similaire à la fonction printf(). Voir Template::Plugin::Format pour plus de détails.

[% USE gras = format('<b>%s</b>') %]
[% gras('Bonjour') %]

GD

Les plugins "GD" ne font plus partie de la distribution principale du Template Toolkit. Ils sont maintenant disponibles sur CPAN sous la forme d'une distribution indépendante Template::GD.

HTML

Le plugin HTML est très basique, implémentant quelques méthodes utiles pour la génération HTML. Il sera probablement étendu à l'avenir ou intégré à un projet plus vaste pour générer des éléments HTML de manière générale.

[% USE HTML %]
[% HTML.escape("if (a < b && c > d) ..." %]
[% HTML.attributes(border => 1, cellpadding => 2) %]
[% HTML.element(table => { border => 1, cellpadding => 2 }) %]

Voir Template::Plugin::HTML pour plus de détails.

Iterator

Le plugin Iterator fournit un moyen de créer un objet Template::Iterator pour parcourir un ensemble de données. Un itérateur est créé automatiquement par la directive "FOREACH" et est aliasé à la variable "loop". Ce plugin permet de créer un itérateur explicitement avec un nom donné, ou le nom par défaut "iterator". Voir Template::Plugin::Iterator pour plus de détails.

[% USE iterator(liste, args) %]
[% POUR element DANS iterator %]
   [% '<ul>' SI iterator.first %]
   <li>[% element %]
   [% '</ul>' SI iterator.last %]
[% FIN %]

Pod

Ce plugin fournit une interface vers le module Pod::POM qui analyse les documents POD en un modèle objet interne qui peut ensuite être parcouru et présenté à l'aide du Template Toolkit.

[% USE Pod(fichier.pod) %]
[% POUR titre1 DANS Pod.titre1;
     POUR titre2 DANS titre1/titre2;
       ...
     FIN;
   FIN
%]

Scalar

Le Template Toolkit appelle les sous-routines définies par l'utilisateur et les méthodes d'objet en utilisant le contexte de tableau par défaut. Le module plugin Scalar fournit un moyen d'appeler des sous-routines et des méthodes dans le contexte scalaire.

# TT2 appelle les méthodes dans le contexte de tableau par défaut
[% objet.methode %]

Ce module fournit un moyen d'appeler des sous-routines et des méthodes dans le contexte scalaire.

[% USE scalaire %]
# forcer le contexte scalaire
[% objet.scalaire.methode %]
# fonctionne aussi avec les références de sous-routines
[% scalaire.ma_ref_sub %]

String

Le plugin String implémente une interface orientée objet pour manipuler les chaînes de caractères. Voir Template::Plugin::String pour plus de détails.

[% USE Chaine 'Bonjour' %]
[% Chaine.append(' le Monde') %]
[% msg = Chaine.new('Une autre chaîne') %]
[% msg.replace('chaîne', 'texte') %]
La chaîne "[% msg %]" a "[% msg.longueur %] " caractères.

Table

Le plugin Table permet de formater une liste de données en un tableau virtuel en spécifiant

un nombre fixe de lignes ou de colonnes, avec un chevauchement facultatif. Voir Template::Plugin::Table pour plus de détails.

[% USE table(list, rows=10, overlap=1) %]
[% FOREACH item = table.col(3) %]
   [% item %]
[% END %]

URL

Le plugin URL fournit un moyen simple de construire des URLs à partir d'une partie de base et d'un ensemble variable de paramètres. Voir Template::Plugin::URL pour plus de détails.

[% USE mycgi = url('/cgi-bin/bar.pl', debug=1) %]
[% mycgi %]
   # ==> /cgi/bin/bar.pl?debug=1
[% mycgi(mode='submit') %]
   # ==> /cgi/bin/bar.pl?mode=submit&debug=1

Wrap

Le plugin Wrap utilise le module Text::Wrap pour fournir un formatage de paragraphe simple. Voir Template::Plugin::Wrap et Text::Wrap pour plus de détails.

[% USE wrap %]
[% wrap(mytext, 40, '* ', '  ') %]  # utiliser la sous-routine wrap
[% mytext FILTER wrap(40) -%]       # ou le filtre wrap

Le module "Text::Wrap" est disponible sur CPAN :

http://www.cpan.org/modules/by-module/Text/

XML

Les plugins "XML::DOM", "XML::RSS", "XML::Simple" et "XML::XPath" ne sont plus distribués avec le Template Toolkit depuis la version 2.15.

Ils sont maintenant disponibles dans une distribution séparée Template::XML.
