Template__Stash__XS(3pm)

Paquet: perl-template-toolkit

Licences: PerlArtistic

Template::Stash::XS(3) Documentation Perl fournie par la communauté Template::Stash::XS(3)

NOM

Template::Stash::XS - Dépôt de variables haute vitesse écrit en C

SYNTAXE

use Template;
use Template::Stash::XS;
my $stash = Template::Stash::XS->new(\%vars);
my $tt2   = Template->new({ STASH => $stash });

DESCRIPTION

Le module Template:Stash::XS est une implémentation de Template::Stash écrite en C. Le « XS » dans le nom fait référence au système d'extension XS de Perl pour interagir Perl avec du code C. Il fonctionne de la même manière que l'implémentation Perl normale de Template::Stash, mais il est environ deux fois plus rapide.

La manière la plus simple d'utiliser le stash XS est de configurer le Template Toolkit pour qu'il l'utilise par défaut. Vous pouvez le faire au moment de l'installation (lorsque vous exécutez "perl Makefile.PL") en répondant 'y' aux questions :

Do you want to build the XS Stash module?      y
Do you want to use the XS Stash by default?    y

Voir le fichier INSTALL distribué avec le Template Toolkit pour plus de détails sur l'installation.

Si vous n'avez pas choisi d'utiliser le stash XS par défaut, vous devriez utiliser l'élément de configuration "STASH" lorsque vous créez un nouvel objet Template. Cela devrait référencer un objet stash XS que vous avez créé manuellement.

use Template;
use Template::Stash::XS;
my $stash = Template::Stash::XS->new(\%vars);
my $tt2   = Template->new({ STASH => $stash });

Alternativement, vous pouvez définir la variable de paquet $Template::Config::STASH comme suit :

use Template;
use Template::Config;
$Template::Config::STASH = 'Template::Stash::XS';
my $tt2 = Template->new();

Le stash XS sera alors automatiquement utilisé.

Si vous voulez utiliser le stash XS par défaut et ne pas réinstaller le Template Toolkit, vous pouvez modifier manuellement le module "Template/Config.pm" près de la ligne 42 pour lire :

$STASH = 'Template::Stash::XS';
