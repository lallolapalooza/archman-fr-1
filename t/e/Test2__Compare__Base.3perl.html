Test2::Compare::Base(3perl) Guide du programmeur Perl Test2::Compare::Base(3perl)

NOM

Test2::Compare::Base - Classe de base pour les classes de comparaison.

DESCRIPTION

Toutes les classes de comparaison pour Test2::Compare devraient hériter de cette classe de base.

SYNOPIS

package Test2::Compare::MyCheck;
use strict;
use warnings;
use base 'Test2::Compare::Base';
use Test2::Util::HashBase qw/stuff/;
sub name { 'STUFF' }
sub operator {
    my $self = shift;
    my ($got) = @_;
    return 'eq';
}
sub verify {
    my $self = shift;
    my $params = @_;
    # Toujours vérifier si $got existe ! Cette méthode doit retourner faux s'il n'y
    # a aucune valeur du tout qui a été reçue.
    return 0 unless $params{exists};
    my $got = $params{got};
    # Retourne vrai si les deux valeurs correspondent. Ceci inclut undef, 0, et
    # d'autres valeurs fausses !
    return $got eq $self->stuff;
}

MÉTHODES

Certaines de ces méthodes doivent être surchargées, d'autres peuvent l'être.

$dclass = $check->delta_class
Retourne la sous-classe delta qui devrait être utilisée. Par défaut, Test2::Compare::Delta est utilisée.
@deltas = $check->deltas(id => $id, exists => $bool, got => $got, convert => \&convert, seen => \%seen)
Devrait retourner les deltas enfants.
@lines = $check->got_lines($got)
C'est votre chance de fournir des numéros de ligne pour les erreurs dans la structure $got.
$op = $check->operator()
$op = $check->operator($got)
Retourne l'opérateur qui a été utilisé pour comparer la vérification avec les données reçues dans $got. S'il n'y avait pas de valeur pour got, alors il n'y aura pas d'arguments, undef ne sera un argument que si undef a été vu dans $got. C'est ainsi que vous pouvez faire la différence entre une valeur manquante et une valeur indéfinie.
$bool = $check->verify(id => $id, exists => $bool, got => $got, convert => \&convert, seen => \%seen)
Retourne vrai s'il y a une correspondance superficielle, c'est-à-dire que les deux éléments sont des tableaux références, que les deux éléments sont la même chaîne de caractères ou le même nombre, etc. Cela ne devrait pas récursivement, car les vérifications profondes sont effectuées dans "$check->deltas()".
$name = $check->name
Obtenir le nom de la vérification.
$display = $check->render
Ce qui devrait être affiché dans un tableau pour cette vérification, généralement le nom ou la valeur.
$delta = $check->run(id => $id, exists => $bool, got => $got, convert => \&convert, seen => \%seen)
C'est ici que la vérification est effectuée, d'abord une vérification superficielle en utilisant "$check->verify", puis la vérification de "$check->deltas()". "\%seen" est utilisé pour éviter les cycles.
