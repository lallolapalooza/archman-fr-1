DESCRIPTION

Ces procédures permettent d'accéder à la fonctionnalité de multiples interpréteurs depuis des programmes C. Elles permettent de gérer plusieurs interpréteurs dans une relation hiérarchique, et la gestion des alias, des commandes qui, lorsqu'elles sont invoquées dans un interpréteur, exécutent une commande dans un autre interpréteur. La valeur retournée pour les procédures qui retournent un int est TCL_OK ou TCL_ERROR. Si TCL_ERROR est retourné, alors le résultat de l'interpréteur contient un message d'erreur.

Tcl_CreerFils crée un nouvel interpréteur en tant que fils de interpréteur. Elle crée également une commande fils nommée nom dans interpréteur qui permet à interpréteur de manipuler le nouveau fils. Si estSûr est zéro, la commande crée un fils fiable dans lequel le code Tcl a accès à toutes les commandes Tcl. Si c'est 1, la commande crée un fils "sûr" dans lequel le code Tcl n'a accès qu'à un ensemble de commandes Tcl définies comme "Tcl sûr". Voir l'entrée du manuel pour la commande Tcl interp pour plus de détails. Si la création du nouvel interpréteur fils échoue, NULL est retourné.

Tcl_CreerFilsSûr est un synonyme de Tcl_CreerFils.

Tcl_GererSûr marque interpréteur comme "sûr", de sorte que les futurs appels à Tcl_EstSûr retournent 1. Elle supprime également de interpréteur toute fonctionnalité potentiellement dangereuse (commandes et variables). Cependant, elle ne peut pas savoir quelles parties d'une extension ou d'une application sont sûres et ne fait aucune tentative pour supprimer ces parties, donc la sécurité n'est pas garantie après avoir appelé Tcl_GererSûr. Les utilisateurs doivent être prudents lors de l'utilisation de Tcl_GererSûr pour éviter de fausses affirmations de sécurité. Pour de nombreux cas, Tcl_CreerFils peut être une meilleure option car elle crée des interpréteurs dans un état sûr connu.

Tcl_ObtenirFils retourne un pointeur vers un interpréteur fils de interpréteur. L'interpréteur fils est identifié par nom. S'il n'existe pas un tel fils, NULL est retourné.

Tcl_ObtenirFilsSûr est un synonyme de Tcl_ObtenirFils.

Tcl_ObtenirParent retourne un pointeur vers l'interpréteur parent de interpréteur. Si interpréteur n'a pas de parent (c'est-à-dire, c'est un interpréteur de niveau supérieur), NULL est retourné.

Tcl_ObtenirParent est un synonyme de Tcl_ObtenirMaître.

Tcl_ObtenirCheminInterpréteur stocke dans le résultat de interpréteur le chemin relatif entre interpréteur et filsInterpréteur; filsInterpréteur doit être un fils de interpréteur. Si le calcul du chemin relatif réussit, TCL_OK est retourné, sinon TCL_ERROR est retourné et un message d'erreur est stocké dans le résultat de interpréteur.

Tcl_CreerAlias crée une commande nommée filsCommande dans filsInterpréteur qui, lorsqu'elle est invoquée, entraînera l'invocation de la commande cibleCommande dans cibleInterpréteur. Les arguments spécifiés par les chaînes dans argv sont toujours ajoutés à tous les arguments fournis lors de l'invocation de filsCommande et sont passés à cibleCommande. Si ce processus réussit, TCL_OK est retourné, sinon TCL_ERROR est retourné et un message d'erreur est stocké dans la valeur résultat de filsInterpréteur. Note : il n'y a aucune restriction sur la relation d'ascendance (telle que créée par Tcl_CreerFils) entre filsInterpréteur et cibleInterpréteur. Deux interpréteurs quelconques peuvent être utilisés sans restriction quant à la manière dont ils sont liés.

Tcl_CreerAliasObjet est similaire à Tcl_CreerAlias sauf qu'elle prend un tableau de valeurs à passer comme arguments supplémentaires au lieu d'un tableau de chaînes.

Tcl_ObtenirAliasObjet retourne des informations sous la forme d'un pointeur vers un tableau de structures Tcl_Obj concernant un alias nomAlias dans interpréteur. N'importe lequel des champs de résultat peut être NULL, auquel cas les données correspondantes ne sont pas retournées. Si un champ de résultat n'est pas NULL, le pointeur indiqué est défini sur les données correspondantes. Par exemple, si cibleCommandePtr n'est pas NULL, il est défini sur un pointeur vers la chaîne contenant le nom de la commande cible.

Tcl_ObtenirAlias est similaire à Tcl_ObtenirAliasObjet sauf qu'elle retourne un pointeur vers un tableau de chaînes au lieu d'un tableau de structures Tcl_Obj. Tcl_ObtenirAlias est obsolète
