Tcl_NREvalObj(3)

Paquet: tcl

Licences: TCL

NOM Procédures de la bibliothèque Tcl NOM

NOM

Tcl_NRCreateCommand, Tcl_NRCallObjProc, Tcl_NREvalObj, Tcl_NREvalObjv, Tcl_NRCmdSwap, Tcl_NRExprObj, Tcl_NRAddCallback - Évaluation non récursive (sans pile) de scripts Tcl.

SYNTAXE

#include <tcl.h>

Tcl_Command
Tcl_NRCreateCommand(interp, cmdName, proc, nreProc, clientData,
                    deleteProc)

int
Tcl_NRCallObjProc(interp, nreProc, clientData, objc, objv)

int
Tcl_NREvalObj(interp, objPtr, flags)

int
Tcl_NREvalObjv(interp, objc, objv, flags)

int
Tcl_NRCmdSwap(interp, cmd, objc, objv, flags)

int
Tcl_NRExprObj(interp, objPtr, resultPtr)

void
Tcl_NRAddCallback(interp, postProcPtr, data0, data1, data2, data3)

ARGUMENTS

Tcl_Interp *interp (in)
L'interpréteur pertinent.
const char *cmdName (in)
Nom de la commande à créer.
Tcl_ObjCmdProc *proc (in)
Est appelé pour évaluer une commande. C'est généralement un petit wrapper qui utilise Tcl_NRCallObjProc pour appeler nreProc avec un nouveau trampoline. Il agit de la même manière que l'argument proc dans Tcl_CreateObjCommand(3) (voir).
Tcl_ObjCmdProc *nreProc (in)
Est appelé à la place de proc lorsqu'un trampoline est déjà utilisé.
ClientData clientData (in)
Valeur arbitraire d'une seule mot, transmise à proc, nreProc, deleteProc et objProc.
Tcl_CmdDeleteProc *deleteProc (in/out)
Est appelé avant que cmdName ne soit supprimé de l'interpréteur, permettant un nettoyage spécifique à la commande. Peut être NULL.
int objc (in)
Nombre d'éléments dans objv.
Tcl_Obj **objv (in)
Mots de la commande.
Tcl_Obj *objPtr (in)
Un script ou une expression à évaluer.
int flags (in)
Comme décrit pour Tcl_EvalObjv.
Tcl_Command cmd (in)
Jeton à utiliser au lieu d'un jeton dérivé du premier élément de objv pour évaluer une commande.
Tcl_Obj *resultPtr (out)
Un objet Tcl non partagé où le résultat de l'évaluation est stocké si le code de retour est TCL_OK.
Tcl_NRPostProc *postProcPtr (in)
Une fonction à pousser.
ClientData data0 (in)
...
ClientData data1 (in)
...
ClientData data2 (in)
...
ClientData data3 (in)
data0 à data3 sont quatre valeurs d'un seul mot qui seront transmises à la fonction désignée par postProcPtr lorsqu'elle est appelée.

DESCRIPTION

Ces fonctions fournissent une interface à la pile de fonctions qu'un interpréteur parcourt pour évaluer des commandes. La fonction sous-jacente à une commande est implémentée par une fonction initiale et toute fonction supplémentaire que la routine ajoute à la pile pendant son exécution. L'interpréteur lui-même ajoute des fonctions à la pile pour réagir à la fin d'une routine et pour exercer des formes de contrôle comme le passage de la pile en cours à l'évaluation de scripts supplémentaires sans ajouter de cadre à la pile C. Pour exécuter une routine, la fonction initiale de la routine est d'abord appelée, puis les fonctions de la pile sont exécutées de manière itérative, en appelant chacune, en utilisant la valeur de la dernière appelée comme valeur de la routine.

Tcl_NRCallObjProc appelle nreProc en utilisant un nouveau trampoline.

Tcl_NRCreateCommand, une alternative à Tcl_CreateObjCommand, résout cmdName, qui peut contenir des qualificateurs d'espace de noms, crée une commande sous ce nom et renvoie un jeton pour la commande qui peut être utilisé dans des appels ultérieurs à Tcl_GetCommandName. Sauf dans certains cas mentionnés ci-dessous, toute commande existante portant le même nom est d'abord supprimée. Si interp est en cours de suppression, Tcl_NRCreateCommand ne crée aucune commande, ne supprime aucune commande et renvoie NULL.

Tcl_NREvalObj pousse une fonction similaire à Tcl_EvalObjEx mais qui ne consomme pas d'espace sur la pile C.

Tcl_NREvalObjv pousse une fonction similaire à Tcl_EvalObjv mais qui ne consomme pas d'espace sur la pile C.

Tcl_NRCmdSwap est similaire à Tcl_NREvalObjv, mais utilise cmd, un jeton précédemment renvoyé par Tcl_CreateObjCommand ou Tcl_GetCommandFromObj, au lieu de résoudre le premier élément de objv.

Tcl_NRExprObj pousse une fonction qui évalue objPtr comme une expression de la même manière que Tcl_ExprObj, mais sans consommer d'espace sur la pile C.

Toutes les fonctions renvoient TCL_OK si l'évaluation du script, de la commande ou de l'expression a été planifiée avec succès. Sinon (par exemple, si le nom de la commande ne peut pas être résolu), elles renvoient TCL_ERROR et stockent un message comme résultat de l'interpréteur.

Tcl_NRAddCallback pousse postProcPtr. La signature de Tcl_NRPostProc est :

typedef int
Tcl_NRPostProc(
        ClientData data[],
        Tcl_Interp *interp,
        int result);

data est un pointeur vers un tableau contenant data0 à data3. result est la valeur renvoyée par la fonction précédente implémentant une partie de la routine.

EXEMPLE

L'instruction suivante utilise Tcl_EvalObjEx, qui consomme de l'espace sur la pile C, pour évaluer un script :

int
TheCmdOldObjProc(
    ClientData clientData,
    Tcl_Interp *interp,
    int objc,
    Tcl_Obj *const objv[])
{
    int result;
    Tcl_Obj *objPtr;
    ... préparation ...
    result = Tcl_EvalObjEx(interp, objPtr, 0);
    ... post-traitement ...
    return result;
}
Tcl_CreateObjCommand(interp, "theCommand",
        TheCmdOldObjProc, clientData, TheCmdDeleteProc);

Pour éviter de consommer de l'espace sur la pile C, TheCmdOldObjProc est renommé en TheCmdNRObjProc et l'étape de post-traitement est divisée en une fonction distincte, TheCmdPostProc, qui est poussée dans la pile de fonctions. Tcl_EvalObjEx est remplacé par Tcl_NREvalObj, qui utilise un trampoline au lieu de consommer de l'espace sur la pile C. Une nouvelle version de TheCmdOldObjProc n'est qu'un wrapper qui utilise Tcl_NRCallObjProc pour appeler TheCmdNRObjProc :

int
TheCmdOldObjProc(
    ClientData clientData,
    Tcl_Interp *interp,
    int objc,
    Tcl_Obj *const objv[])
{
    return Tcl_NRCallObjProc(interp, TheCmdNRObjProc,
            clientData, objc, objv);
}
int
TheCmdNRObjProc
    ClientData clientData,
    Tcl_Interp *interp,
    int objc,
    Tcl_Obj *const objv[])
{
    Tcl_Obj *objPtr;
    ... préparation ...
    Tcl_NRAddCallback(interp, TheCmdPostProc,
            data0, data1, data2, data3);
    /* data0 .. data3 sont quatre éléments d'un seul mot qui seront passés à la fonction de post-traitement */
    return Tcl_NREvalObj(interp, objPtr, 0);
}
int
TheCmdNRPostProc(
    ClientData data[],
    Tcl_Interp *interp,
    int result)
{
    /* data[0] .. data[3] sont les quatre éléments de données passés à Tcl_NRAddCallback */
    ... post-traitement ...
    return result;
}

Toute fonction composant une routine peut pousser d'autres fonctions, permettant ainsi de mettre en œuvre des structures de contrôle comme des boucles et des séquences en utilisant la pile de fonctions.

Tcl_NREvalObj(3)

NAME

Tcl_NREvalObj - evaluate Tcl commands, with special handling for Tcl_Obj values

SYNOPSIS

#include <tcl.h>
int
Tcl_NREvalObj(interp, objPtr, optionsPtr)
Tcl_Interp *interp;
Tcl_Obj *objPtr;
Tcl_NREvalOptions *optionsPtr;

ARGUMENTS

interp (in)
Tcl interpreter to use for evaluation.
objPtr (in)
Pointer to a Tcl_Obj containing the script to evaluate.
optionsPtr (in)
Pointer to a Tcl_NREvalOptions structure that specifies options for the evaluation. If NULL, default options are used.

DESCRIPTION

The Tcl_NREvalObj function is similar to Tcl_EvalObjEx, but it allows for special handling of Tcl_Obj values. The Tcl_NREvalOptions structure can be used to specify options such as whether to return an error if the script contains Tcl_Obj values that cannot be evaluated or if the script should be compiled before evaluation.

EXAMPLE

Tcl_Interp *interp;
Tcl_Obj *scriptObj;
Tcl_NREvalOptions options;

/* Initialize interpreter and create script object */
interp = Tcl_CreateInterp();
scriptObj = Tcl_NewStringObj("puts {Hello, world!}", -1);

/* Set options (optional) */
Tcl_NREvalOptionsInit(&options);
options.flags = TCL_NR_EVAL_COMPILED; /* Compile the script before evaluation */

/* Evaluate the script */
if (Tcl_NREvalObj(interp, scriptObj, &options) != TCL_OK) {
    fprintf(stderr, "Error: %s\n", Tcl_GetStringResult(interp));
}

/* Clean up */
Tcl_DecrRefCount(scriptObj);
Tcl_DeleteInterp(interp);

Tcl_NREvalObj(3)

NOM

Tcl_NREvalObj - évaluer des commandes Tcl, avec gestion spéciale des valeurs Tcl_Obj

SYNOPIS

#include <tcl.h>
int
Tcl_NREvalObj(interp, objPtr, optionsPtr)
Tcl_Interp *interp;
Tcl_Obj *objPtr;
Tcl_NREvalOptions *optionsPtr;

ARGUMENTS

interp (entrée)
Interpréteur Tcl à utiliser pour l'évaluation.
objPtr (entrée)
Pointeur vers un Tcl_Obj contenant le script à évaluer.
optionsPtr (entrée)
Pointeur vers une structure Tcl_NREvalOptions qui spécifie les options pour l'évaluation. Si NULL, les options par défaut sont utilisées.

DESCRIPTION

La fonction Tcl_NREvalObj est similaire à Tcl_EvalObjEx, mais elle permet une gestion spéciale des valeurs Tcl_Obj. La structure Tcl_NREvalOptions peut être utilisée pour spécifier des options telles que le retour d'une erreur si le script contient des valeurs Tcl_Obj qui ne peuvent pas être évaluées ou si le script doit être compilé avant l'évaluation.

EXEMPLE

Tcl_Interp *interp;
Tcl_Obj *scriptObj;
Tcl_NREvalOptions options;

/* Initialisation de l'interpréteur et création de l'objet script */
interp = Tcl_CreateInterp();
scriptObj = Tcl_NewStringObj("puts {Bonjour, le monde !}", -1);

/* Définition des options (facultatif) */
Tcl_NREvalOptionsInit(&options);
options.flags = TCL_NR_EVAL_COMPILED; /* Compiler le script avant l'évaluation */

/* Évaluation du script */
if (Tcl_NREvalObj(interp, scriptObj, &options) != TCL_OK) {
    fprintf(stderr, "Erreur : %s\n", Tcl_GetStringResult(interp));
}

/* Nettoyage */
Tcl_DecrRefCount(scriptObj);
Tcl_DeleteInterp(interp);

VOIR AUSSI
