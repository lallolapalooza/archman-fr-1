NOM

Tcl_RecordAndEvalObj - enregistre la commande dans la liste d'historique avant son évaluation

SYNOPIS

#include <tcl.h>

int
Tcl_RecordAndEvalObj(interp, cmdPtr, flags)

ARGUMENTS

Tcl_Interp *interp (entrée)
Interpréteur Tcl dans lequel évaluer la commande.
Tcl_Obj *cmdPtr (entrée)
Pointeur vers une valeur Tcl contenant une commande (ou une séquence de commandes) à exécuter.
int flags (entrée)
Une combinaison OR de bits d'indicateurs. TCL_NO_EVAL signifie enregistrer la commande mais ne pas l'évaluer. TCL_EVAL_GLOBAL signifie évaluer la commande au niveau global au lieu du niveau de pile actuel.

DESCRIPTION

Tcl_RecordAndEvalObj est appelée pour enregistrer une commande comme un événement dans la liste d'historique, puis pour l'exécuter en utilisant Tcl_EvalObjEx (ou Tcl_GlobalEvalObj si le bit TCL_EVAL_GLOBAL est défini dans flags). Elle retourne un code d'achèvement tel que TCL_OK, tout comme Tcl_EvalObjEx, ainsi qu'une valeur de résultat contenant des informations supplémentaires (une valeur de résultat ou un message d'erreur) qui peuvent être récupérées en utilisant Tcl_GetObjResult. Si vous ne souhaitez pas que la commande soit enregistrée dans la liste d'historique, vous devriez appeler Tcl_EvalObjEx à la place de Tcl_RecordAndEvalObj. Normalement, Tcl_RecordAndEvalObj est uniquement appelée avec des commandes de niveau supérieur tapées par l'utilisateur, car le but de l'historique est de permettre à l'utilisateur de réémettre des commandes récemment invoquées. Si l'argument flags contient le bit TCL_NO_EVAL, alors la commande est enregistrée sans être évaluée.

VOIR AUSSI

Tcl_EvalObjEx, Tcl_GetObjResult
