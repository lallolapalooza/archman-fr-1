Tcl_PkgRequire(3) Procédures de bibliothèque Tcl Tcl_PkgRequire(3)

NOM

Tcl_PkgRequire, Tcl_PkgRequireEx, Tcl_PkgRequireProc, Tcl_PkgPresent, Tcl_PkgPresentEx, Tcl_PkgProvide, Tcl_PkgProvideEx - contrôle de version des paquets

SYNOPIS

#include <tcl.h>

const char *
Tcl_PkgRequire(interp, name, version, exact)

const char *
Tcl_PkgRequireEx(interp, name, version, exact, clientDataPtr)

int
Tcl_PkgRequireProc(interp, name, objc, objv, clientDataPtr)

const char *
Tcl_PkgPresent(interp, name, version, exact)

const char *
Tcl_PkgPresentEx(interp, name, version, exact, clientDataPtr)

int
Tcl_PkgProvide(interp, name, version)

int
Tcl_PkgProvideEx(interp, name, version, clientData)

ARGUMENTS

Tcl_Interp *interp (entrée)
Interpréteur où le paquet est nécessaire ou disponible.
const char *name (entrée)
Nom du paquet.
const char *version (entrée)
Une chaîne de spécification de version telle que décrite pour package require.
int exact (entrée)
Différent de zéro signifie que seule la version particulière spécifiée par version est acceptable. Zéro signifie que les versions plus récentes que version sont également acceptables tant qu'elles ont le même numéro de version majeure que version.
const void *clientData (entrée)
Valeur arbitraire à associer au paquet.
void *clientDataPtr (sortie)
Pointeur vers l'emplacement où stocker la valeur associée au paquet correspondant. Il n'est modifié que si le pointeur n'est pas NULL et si la fonction s'est terminée avec succès. Le stockage peut être de n'importe quel type de pointeur de la même taille qu'un pointeur void.
int objc (entrée)
Nombre d'exigences.
Tcl_Obj* objv[] (entrée)
Tableau d'exigences.

DESCRIPTION

Ces procédures fournissent des interfaces au niveau C aux installations de gestion des paquets et des versions de Tcl.

Tcl_PkgRequire est équivalent à la commande package require, Tcl_PkgPresent est équivalent à la commande package present, et Tcl_PkgProvide est équivalent à la commande package provide.

Consultez la documentation des commandes Tcl pour connaître les détails de ce que font ces procédures.

Si Tcl_PkgPresent ou Tcl_PkgRequire se terminent avec succès, elles renvoient un pointeur vers la chaîne de version de la version du paquet qui est fournie dans l'interpréteur (qui peut être différente de version) ; si une erreur se produit, elles renvoient NULL et laissent un message d'erreur dans le résultat de l'interpréteur.

Tcl_PkgProvide renvoie TCL_OK si elle se termine avec succès ; si une erreur se produit, elle renvoie TCL_ERROR et laisse un message d'erreur dans le résultat de l'interpréteur.

Tcl_PkgProvideEx, Tcl_PkgPresentEx et Tcl_PkgRequireEx permettent la définition et la récupération des données client associées au paquet. À tous autres égards, elles sont équivalentes aux fonctions correspondantes.

Tcl_PkgRequireProc est la forme de package require qui gère plusieurs exigences. Les autres formes sont présentes pour des raisons de compatibilité descendante et traduisent leurs invocations vers cette forme.
