DESCRIPTION

Ces fonctions sont conçues pour accéder à la fonctionnalité de plusieurs interpréteurs Tcl depuis des programmes C. Elles permettent de gérer plusieurs interpréteurs dans une relation hiérarchique, et la gestion des alias, des commandes qui, lorsqu'elles sont invoquées dans un interpréteur, exécutent une commande dans un autre interpréteur. La valeur retournée par les fonctions qui retournent un int est TCL_OK ou TCL_ERROR. Si TCL_ERROR est retourné, le résultat de l'interpréteur contient un message d'erreur.

Tcl_CreerInterpreteurFils crée un nouvel interpréteur comme fils de interp. Elle crée également une commande fils nommée nom dans interp qui permet à interp de manipuler le nouveau fils. Si estConfiant est nul, la commande crée un fils fiable dans lequel le code Tcl a accès à toutes les commandes Tcl. S'il est 1, la commande crée un fils « sécurisé » dans lequel le code Tcl n'a accès qu'à un ensemble de commandes Tcl définies comme « Tcl sécurisé » ; voir l'entrée du manuel pour la commande Tcl interp pour plus de détails. Si la création du nouvel interpréteur fils échoue, NULL est retourné.

Tcl_CreerInterpreteurFilsAutre est un synonyme de Tcl_CreerInterpreteurFils.

Tcl_Obtenir retourne 1 si interp est « sécurisé » (créé avec le flag TCL_SAFE_INTERPRETER spécifié), 0 sinon.

Tcl_Montrer marque interp comme « sécurisé », ce qui signifie que les futurs appels à Tcl_Obtenir retourneront 1. Elle supprime également de interp tous les composants potentiellement dangereux (commandes et variables). Cependant, elle ne peut pas connaître quelles parties d'une extension ou d'une application sont sécurisées et ne tente pas de les supprimer, donc la sécurité n'est pas garantie après avoir appelé Tcl_Montrer. Les utilisateurs doivent être prudents avec l'utilisation de Tcl_Montrer pour éviter de fausses affirmations de sécurité. Dans de nombreux cas, Tcl_CreerInterpreteurFils peut être une meilleure option, car elle crée des interpréteurs dans un état sécurisé connu.

Tcl_ObtenirInterpreteurFils retourne un pointeur vers un fils de interp. L'interpréteur fils est identifié par nom. S'il n'existe pas de tel fils, NULL est retourné.

Tcl_Obtenir est un synonyme de Tcl_ObtenirInterpreteurFils.

Tcl_ObtenirInterpreteurParent retourne un pointeur vers l'interpréteur parent de interp. Si interp n'a pas de parent (c'est-à-dire qu'il s'agit d'un interpréteur de niveau supérieur), NULL est retourné.

Tcl_ObtenirChemin stocke dans le résultat de interp le chemin relatif entre interp et filsInterp ; filsInterp doit être un fils de interp. Si le calcul du chemin relatif réussit, TCL_OK est retourné, sinon TCL_ERROR est retourné et un message d'erreur est laissé comme résultat de interp.

Tcl_CreerAlias crée une commande nommée commande dans filsInterp qui, lorsqu'elle est invoquée, provoquera l'invocation de la commande cibleCommande dans cibleInterp. Les arguments spécifiés par les chaînes de caractères dans argv sont toujours préparés pour être précédés de tous les arguments fournis lors de l'invocation de commande et passés à cibleCommande. Cette opération retourne TCL_OK si elle réussit, ou TCL_ERROR si elle échoue ; dans ce cas, un message d'erreur est laissé dans la valeur de résultat de filsInterp. Notez qu'il n'y a aucune restriction sur la relation d'ascendance (telle que créée par Tcl_CreerInterpreteurFils) entre filsInterp et cibleInterp. Deux interpréteurs quelconques peuvent être utilisés sans restriction sur la manière dont ils sont liés.

Tcl_CreerAliasAutre est similaire à Tcl_CreerAlias sauf qu'elle prend un tableau de valeurs à passer comme arguments supplémentaires au lieu d'un tableau de chaînes de caractères.

Tcl_ObtenirAliasAutre retourne des informations sous forme de pointeur vers un tableau de structures Tcl_Obj sur un alias nomAlias dans interp. N'importe lequel des champs de résultat peut être NULL, auquel cas les données correspondantes ne sont pas retournées. Si un champ de résultat n'est pas NULL, l'adresse indiquée est définie sur la donnée correspondante. Par exemple, si cibleCommandePtr n'est pas NULL, il est défini sur un pointeur vers la chaîne contenant le nom de la commande cible.

Tcl_ObtenirAlias est similaire à Tcl_ObtenirAliasAutre sauf qu'elle retourne un pointeur vers un tableau de chaînes de caractères au lieu d'un tableau de structures Tcl_Obj. Tcl_Obtenir est obsolète.
