Tcl_SplitList(3) Procédures de bibliothèque Tcl Tcl_SplitList(3)

NOM

Tcl_SplitList, Tcl_Merge, Tcl_ScanElement, Tcl_ConvertElement, Tcl_ScanCountedElement, Tcl_ConvertCountedElement - manipuler des listes Tcl

SYNOPSIS

#include <tcl.h>

int
Tcl_SplitList(interp, list, argcPtr, argvPtr)

char *
Tcl_Merge(argc, argv)

int
Tcl_ScanElement(src, flagsPtr)

int
Tcl_ScanCountedElement(src, length, flagsPtr)

int
Tcl_ConvertElement(src, dst, flags)

int
Tcl_ConvertCountedElement(src, length, dst, flags)

ARGUMENTS

Tcl_Interp *interp (out)
Interpréteur à utiliser pour le signalement des erreurs. Si NULL, aucun message d'erreur n'est laissé.
const char *list (in)
Pointeur vers une chaîne de caractères avec une structure de liste correcte.
int *argcPtr (out)
Rempli avec le nombre d'éléments dans list.
const char ***argvPtr (out)
*argvPtr sera rempli avec l'adresse d'un tableau de pointeurs vers les chaînes qui sont les éléments extraits de list. Il y aura *argcPtr entrées valides dans le tableau, suivies d'une entrée NULL.
int argc (in)
Nombre d'éléments dans argv.
const char *const *argv (in)
Tableau de chaînes à fusionner en une seule liste. Chaque chaîne deviendra un élément distinct de la liste.
const char *src (in)
Chaîne de caractères qui doit devenir un élément d'une liste.
int *flagsPtr (in)
Pointeur vers un mot à remplir avec des informations sur src. La valeur de *flagsPtr doit être passée à Tcl_ConvertElement.
int length (in)
Nombre d'octets dans la chaîne src.
char *dst (in)
Endroit où copier l'élément de liste converti. Doit contenir suffisamment de caractères pour accueillir la chaîne convertie.
int flags (in)
Informations sur src. Doit être la valeur retournée par un appel précédent à Tcl_ScanElement, potentiellement OR-ée avec TCL_DONT_USE_BRACES.

DESCRIPTION

Ces procédures peuvent être utilisées pour désassembler et réassembler des listes Tcl. Tcl_SplitList décompose une liste en ses éléments constitutifs, retournant un tableau de pointeurs vers les éléments en utilisant argcPtr et argvPtr. Lors de l'extraction des arguments, Tcl_SplitList respecte les règles habituelles de substitution par antislash et d'utilisation des accolades. La zone mémoire pointée par *argvPtr est allouée dynamiquement ; en plus du tableau de pointeurs, elle contient également des copies de tous les éléments de la liste. Il incombe à l'appelant de libérer tout ce stockage. Par exemple, supposez que vous ayez appelé Tcl_SplitList avec le code suivant :

int argc, code;
char *string;
char **argv;
...
code = Tcl_SplitList(interp, string, &argc, &argv);

Alors vous devriez éventuellement libérer le stockage avec un appel comme le suivant :

Tcl_Free((char *) argv);

Tcl_SplitList retourne normalement TCL_OK, ce qui signifie que la liste a été analysée avec succès. S'il y avait une erreur de syntaxe dans list, alors TCL_ERROR est retourné et le résultat de l'interpréteur pointera vers un message d'erreur décrivant le problème (si interp n'était pas NULL). Si TCL_ERROR est retourné, aucune mémoire n'est allouée et *argvPtr n'est pas modifié.

Tcl_Merge est l'inverse de Tcl_SplitList : il prend une collection de chaînes de caractères fournies par argc et argv et génère une chaîne de résultat ayant une structure de liste correcte. Cela signifie que des commandes comme index peuvent être utilisées pour extraire à nouveau les éléments d'origine. De plus, si le résultat de Tcl_Merge est passé à Tcl_Eval, il sera analysé en argc mots dont les valeurs seront identiques aux chaînes argv passées à Tcl_Merge. Tcl_Merge modifiera les éléments de la liste avec des accolades et/ou des antislashs afin de produire une structure de liste Tcl correcte. La chaîne de résultat est allouée dynamiquement en utilisant Tcl_Alloc ; l'appelant doit éventuellement libérer l'espace en utilisant Tcl_Free.

Si le résultat de Tcl_Merge est passé à Tcl_SplitList, les éléments retournés par Tcl_SplitList seront identiques à ceux passés à Tcl_Merge. Cependant, le contraire n'est pas vrai : si Tcl_SplitList est passé une chaîne donnée, et que les argc et argv résultants sont passés à Tcl_Merge, la chaîne résultante peut ne pas être la même que la chaîne d'origine passée à Tcl_SplitList. En effet, Tcl_Merge peut utiliser des antislashs et des accolades différemment de la chaîne d'origine.

Tcl_ScanElement et Tcl_ConvertElement sont les procédures qui font tout le travail réel de Tcl_Merge. Tcl_ScanElement analyse son argument src et détermine comment utiliser les antislashs et les accolades lors de sa conversion en élément de liste. Il retourne une estimation supérieure du nombre de caractères requis pour représenter src en tant qu'élément de liste, et il stocke des informations dans *flagsPtr qui sont nécessaires à Tcl_ConvertElement.

Tcl_ConvertElement est une procédure compagnon de Tcl_ScanElement. Elle effectue la conversion réelle d'une chaîne en élément de liste. Son argument flags doit être identique à la valeur retournée par Tcl_ScanElement. Tcl_ConvertElement écrit un élément de liste correct dans la mémoire à partir de *dst et retourne le nombre total de caractères écrits, qui ne dépassera pas la valeur retournée par Tcl_ScanElement. Tcl_ConvertElement n'écrit que l'élément de liste réel sans espaces initiaux ou finaux : il appartient à l'appelant d'inclure des espaces entre les éléments de liste adjacents.

Tcl_ConvertElement utilise l'une des deux approches différentes pour gérer les caractères spéciaux dans src. Dans la mesure du possible, elle gère les caractères spéciaux en entourant la chaîne d'accolades. Cela produit une sortie claire, mais ne peut pas être utilisé dans certaines situations, comme lorsque src contient des accolades non appariées. Dans ces situations, Tcl_ConvertElement gère les caractères spéciaux en générant des séquences d'antislashs pour eux. L'appelant peut insister sur la deuxième approche en OR-ant la valeur de drapeau retournée par Tcl_ScanElement avec TCL_DONT_USE_BRACES. Bien que cela produise un résultat moins esthétique, c'est utile dans certaines situations spéciales, comme lorsque Tcl_ConvertElement est utilisé pour générer une partie d'un argument pour une commande Tcl. Dans ce cas, entourer src d'accolades ferait que la commande ne serait pas correctement analysée.

Par défaut, Tcl_ConvertElement utilisera la mise en guillemets dans sa sortie pour s'assurer que le premier caractère d'un élément n'est pas le caractère dièse (“#”). Ceci afin de s'assurer que le premier élément de toute liste passée à eval ne soit pas mal interprété comme le début d'un commentaire. Lorsqu'un élément de liste n'est pas le premier élément d'une liste, cette mise en guillemets n'est pas nécessaire. Lorsque l'appelant peut s'assurer que l'élément n'est pas le premier élément d'une liste, il peut désactiver la mise en guillemets du caractère dièse initial en OR-ant la valeur de drapeau retournée par Tcl_ScanElement avec TCL_DONT_QUOTE_HASH.

Tcl_ScanCountedElement et Tcl_ConvertCountedElement sont identiques à Tcl_ScanElement et Tcl_ConvertElement, sauf que la longueur de la chaîne src est spécifiée par l'argument length, et que la chaîne peut contenir des caractères nulles intégrés.
