ARGUMENTS

Tcl_Interp *interp (entrée)
Si une erreur se produit lors de la conversion d'une valeur en valeur de dictionnaire, un message d'erreur est laissé dans la valeur de résultat de l'interpréteur, à moins que interp ne soit nul.
Tcl_Obj *dictPtr (entrée/sortie)
Pointe vers une valeur de dictionnaire à manipuler. Si dictPtr ne pointe pas déjà vers une valeur de dictionnaire, une tentative sera faite pour le convertir en une.
Tcl_Obj *keyPtr (entrée)
Pointe vers la clé de la paire clé/valeur à manipuler dans la valeur du dictionnaire.
Tcl_Obj **keyPtrPtr (sortie)
Pointe vers une variable qui contiendra la clé d'une paire clé/valeur placée dedans. Peut être nul pour indiquer que l'appelant ne s'intéresse pas à la clé.
Tcl_Obj *valuePtr (entrée)
Pointe vers la valeur de la paire clé/valeur à manipuler dans la valeur du dictionnaire (ou sous-valeur dans le cas de Tcl_DictObjPutKeyList).
Tcl_Obj **valuePtrPtr (sortie)
Pointe vers une variable qui contiendra la valeur d'une paire clé/valeur placée dedans. Pour Tcl_DictObjFirst et Tcl_DictObjNext, peut être nul pour indiquer que l'appelant ne s'intéresse pas à la valeur.
int *sizePtr (sortie)
Pointe vers une variable qui contiendra le nombre de paires clé/valeur contenues dans le dictionnaire.
Tcl_DictSearch *searchPtr (entrée/sortie)
Pointeur vers un enregistrement pour suivre la progression lors de l'énumération de toutes les paires clé/valeur dans un dictionnaire. Le contenu de l'enregistrement est initialisé par l'appel à Tcl_DictObjFirst. Si l'énumération doit se terminer avant que toutes les valeurs du dictionnaire aient été retournées, l'enregistrement de recherche doit être passé à Tcl_DictObjDone pour libérer les verrous internes.
int *donePtr (sortie)
Pointeur vers une variable qui contiendra une valeur non nulle lorsque l'énumération des paires clé/valeur dans un dictionnaire sera terminée, et zéro sinon.
int keyc (entrée)
Indique le nombre de clés à fournir dans le tableau keyv.
Tcl_Obj *const *keyv (entrée)
Tableau de keyc pointeurs vers des valeurs que Tcl_DictObjPutKeyList et Tcl_DictObjRemoveKeyList utiliseront pour localiser la paire clé/valeur à manipuler dans les sous-dictionnaires de la valeur principale du dictionnaire.

DESCRIPTION

Les valeurs de dictionnaire Tcl ont une représentation interne qui permet un mappage efficace des clés aux valeurs et garantit que l'ordre des clés au sein du dictionnaire est préservé, sauf si des clés sont supprimées ou ajoutées (celles qui sont supprimées sont retirées de l'ordre, et celles qui sont ajoutées sont ajoutées à la fin de l'ordre). Si interprétées comme une liste, les valeurs aux indices pairs de la liste seront les clés du dictionnaire, et chacune sera suivie (à l'indice impair) par la valeur associée à cette clé.

Les procédures décrites dans cette page de manuel sont utilisées pour créer, modifier, indexer et itérer sur les valeurs de dictionnaire à partir du code C.

Tcl_NewDictObj crée une nouvelle valeur de dictionnaire vide. La représentation chaîne de caractères de la valeur sera invalide, et le compteur de références de la valeur sera zéro.

Tcl_DictObjGet recherche la clé donnée dans le dictionnaire et écrit un pointeur vers la valeur associée à cette clé dans la variable pointée par valuePtrPtr, ou une valeur nulle s'il n'y a pas de mappage pour cette clé. Le résultat de cette opération est TCL_OK, ou TCL_ERROR si dictPtr ne peut pas être converti en un dictionnaire.

Tcl_DictObjPut met à jour le dictionnaire de manière à ce que la clé donnée corresponde à la valeur donnée ; chaque clé peut exister dans un dictionnaire une seule fois. Le dictionnaire ne doit pas être partagé, mais la clé et la valeur le peuvent. Cette opération peut incrémenter le compteur de références de la clé et de la valeur si elles doivent être stockées. Ni la clé ni la valeur ne doivent être nulles. Le résultat de cette opération est TCL_OK, ou TCL_ERROR si dictPtr ne peut pas être converti en un dictionnaire.

Tcl_DictObjRemove met à jour le dictionnaire de manière à ce que la clé donnée ne corresponde à aucune valeur. Le dictionnaire ne doit pas être partagé, mais la clé peut l'être. La clé stockée dans le dictionnaire verra son compteur de références décrémenté si elle était présente. Ce n'est pas une erreur si la clé n'existait pas auparavant. Le résultat de cette opération est TCL_OK, ou TCL_ERROR si dictPtr ne peut pas être converti en un dictionnaire.

Tcl_DictObjSize met à jour la variable donnée avec le nombre de paires clé/valeur actuelles dans le dictionnaire. Le résultat de cette opération est TCL_OK, ou TCL_ERROR si dictPtr ne peut pas être converti en un dictionnaire.

Tcl_DictObjFirst démarre une itération sur toutes les paires clé/valeur du dictionnaire, plaçant la clé et la valeur dans les variables pointées par keyPtrPtr et valuePtrPtr (qui peuvent être nulles pour indiquer que l'appelant ne s'intéresse pas à la clé ou à la valeur respectivement). La paire clé/valeur suivante dans le dictionnaire peut être obtenue avec Tcl_DictObjNext. Les modifications concurrentes de la représentation interne du dictionnaire ne modifieront pas le traitement de l'itération, sauf si le dictionnaire n'est pas partagé, ce qui provoquera l'interruption prématurée de l'itération (ce que les scripts Tcl ne peuvent pas provoquer avec la commande dict). L'argument searchPtr pointe vers un contexte utilisé pour identifier quelle itération est en cours, et est initialisé par l'appel à Tcl_DictObjFirst. L'argument donePtr pointe vers une variable qui sera mise à zéro s'il reste des paires clé/valeur à itérer, ou à une valeur non nulle si l'itération est terminée. L'ordre de l'itération est implicitement défini. Si dictPtr ne peut pas être converti en un dictionnaire, Tcl_DictObjFirst retourne TCL_ERROR et l'itération ne commencera pas, sinon il retourne TCL_OK.

Lorsqu'un appel à Tcl_DictObjFirst est effectué sur un dictionnaire, un verrou est placé sur le dictionnaire afin qu'il puisse être itéré en toute sécurité, même si le dictionnaire est modifié pendant l'itération. Pour cette raison, une fois que l'itération sur les clés d'un dictionnaire est terminée (soit parce que la dernière valeur a été itérée, indiqué par l'argument donePtr mis à un, soit parce qu'aucune autre valeur n'est requise), la fonction Tcl_DictObjDone doit être appelée avec le même searchPtr qui a été utilisé dans Tcl_DictObjFirst pour libérer les verrous internes. Une fois qu'un searchPtr particulier a été passé à Tcl_DictObjDone, le passer à nouveau à Tcl_DictObjNext (sans l'avoir d'abord initialisé avec Tcl_DictObjFirst) entraînera la production d'aucune valeur et l'argument donePtr sera mis à un. Il est sûr d'appeler Tcl_DictObjDone plusieurs fois sur le même searchPtr pour chaque appel à Tcl_DictObjFirst.

Les procédures Tcl_DictObjPutKeyList et Tcl_DictObjRemoveKeyList sont des analogies proches de Tcl_DictObjPut et Tcl_DictObjRemove respectivement, sauf qu'elles fonctionnent non pas avec un seul dictionnaire, mais sont conçues pour fonctionner sur une structure arborescente de dictionnaires imbriqués, avec les dictionnaires internes stockés comme valeurs à l'intérieur des dictionnaires externes. Les arguments keyc et keyv spécifient une liste de clés (avec les clés externes en premier) qui agissent comme un chemin vers la paire clé/valeur à affecter. Remarque : il n'existe pas d'opération correspondante pour lire une valeur à partir d'un chemin de clés.

NOM

TCL

SYNTAXE

Tcl_DictObjGet, Tcl_DictObjPutKeyList, Tcl_DictObjRemoveKeyList

ARGUMENTS

interp, objPtr, search, key, value, done

DESCRIPTION

Utiliser Tcl_DictObjGet de manière répétée pour construire ce fichier est facile. Avec Tcl_DictObjPutKeyList, les dictionnaires imbriqués sont créés pour les clés non terminales où elles n'existent pas encore. Avec Tcl_DictObjRemoveKeyList, toutes les clés non terminales doivent exister et avoir des valeurs de dictionnaire.

EXEMPLE

Utilisation de l'interface d'itération du dictionnaire pour vérifier si une clé existe et est mappée à elle-même :

Tcl_DictSearch search;
Tcl_Obj *key, *value;
int done;
/*
 * Nous supposons que interp et objPtr sont des paramètres. C'est la façon idiomatique de commencer une itération sur le dictionnaire ; cela crée un verrou sur la représentation interne qui garantit qu'il n'y aura pas de problèmes de modification concurrente lorsque la gestion normale des références est également utilisée. Le verrou est automatiquement libéré lorsque l'itération se termine, mais il doit être libéré manuellement si le cycle est quitté de manière exceptionnelle. Cependant, il est sûr de tenter de libérer le verrou même si nous avons terminé l'itération sur le cycle.
 */
if (Tcl_DictObjFirst(interp, objPtr, &search,
        &key, &value, &done) != TCL_OK) {
    return TCL_ERROR;
}
for (; !done ; Tcl_DictObjNext(&search, &key, &value, &done)) {
    /*
     * Note : strcmp() n'est pas une bonne façon de comparer des valeurs et est utilisé ici uniquement à des fins de démonstration.
     */
    if (!strcmp(Tcl_GetString(key), Tcl_GetString(value))) {
        break;
    }
}
Tcl_DictObjDone(&search);
Tcl_SetObjResult(interp, Tcl_NewBooleanObj(!done));
return TCL_OK;
