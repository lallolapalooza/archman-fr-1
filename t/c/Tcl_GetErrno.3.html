Tcl_SetErrno(3) Procédures de bibliothèque Tcl Tcl_SetErrno(3)

NOM

Tcl_SetErrno, Tcl_GetErrno, Tcl_ErrnoId, Tcl_ErrnoMsg - manipuler errno pour stocker et récupérer les codes d'erreur

SYNOPIS

#include <tcl.h>

void
Tcl_SetErrno(errorCode)

int
Tcl_GetErrno()

const char *
Tcl_ErrnoId()

const char *
Tcl_ErrnoMsg(errorCode)

ARGUMENTS

int errorCode (entrée)
Un code d'erreur POSIX tel que ENOENT.

DESCRIPTION

Tcl_SetErrno et Tcl_GetErrno fournissent un accès portable à la variable errno, qui est utilisée pour enregistrer un code d'erreur POSIX après les appels système et d'autres opérations telles que Tcl_Gets. Ces procédures sont nécessaires car les accès aux variables globales ne peuvent pas être effectués à travers les limites de modules sur certaines plateformes.

Tcl_SetErrno définit la variable errno à la valeur de l'argument errorCode. Les procédures C qui souhaitent retourner des informations d'erreur à leurs appelants via errno devraient appeler Tcl_SetErrno plutôt que de définir errno directement.

Tcl_GetErrno retourne la valeur actuelle de errno. Les procédures souhaitant accéder à errno devraient appeler cette procédure au lieu d'accéder directement à errno.

Tcl_ErrnoId et Tcl_ErrnoMsg retournent des représentations textuelles des valeurs de errno. Tcl_ErrnoId retourne un identifiant textuel lisible par machine tel que “EACCES” qui correspond à la valeur actuelle de errno. Tcl_ErrnoMsg retourne une chaîne lisible par l'homme telle que “permission denied” qui correspond à la valeur de son argument errorCode. L'argument errorCode est généralement la valeur retournée par Tcl_GetErrno. Les chaînes retournées par ces fonctions sont allouées statiquement et l'appelant ne doit pas les libérer ou les modifier.
