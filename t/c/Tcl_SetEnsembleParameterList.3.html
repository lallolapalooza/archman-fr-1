ARGUMENTS

Tcl_Interp *interp (in/out)
L'interpréteur dans lequel l'ensemble doit être créé ou trouvé. C'est aussi là que les messages d'erreur sont écrits. Les fonctions dont le nom commence par Tcl_GetEnsemble peuvent avoir NULL pour interp, mais toutes les autres fonctions ne doivent pas.
const char *name (in)
Le nom de la commande d'ensemble à créer.
Tcl_Namespace *namespacePtr (in)
L'espace de noms auquel la commande d'ensemble doit être liée, ou NULL pour l'espace de noms courant.
int ensFlags (in)
Un ensemble OU'é de bits d'indicateurs décrivant la configuration de base de l'ensemble. Actuellement, seul un bit a un sens, TCL_ENSEMBLE_PREFIX, qui est présent lorsque la commande d'ensemble doit également correspondre aux préfixes non ambigus des sous-commandes.
Tcl_Obj *cmdNameObj (in)
Une valeur contenant le nom de la commande d'ensemble à rechercher.
int flags (in)
Un ensemble OU'é de bits d'indicateurs contrôlant le comportement de Tcl_FindEnsemble. Actuellement, seul TCL_LEAVE_ERR_MSG est pris en charge.
Tcl_Command token (in)
Un jeton de commande normal qui fait référence à une commande d'ensemble, ou que vous souhaitez utiliser pour tester comme une commande d'ensemble dans Tcl_IsEnsemble.
int *ensFlagsPtr (out)
Pointeur vers une variable dans laquelle écrire les bits d'indicateurs actuels de l'ensemble ; actuellement, seul le bit TCL_ENSEMBLE_PREFIX est défini.
Tcl_Obj *dictObj (in)
Une valeur de dictionnaire à utiliser pour la cartographie du nom de sous-commande au préfixe de commande d'implémentation dans l'ensemble. Peut être NULL si le dictionnaire de cartographie doit être supprimé.
Tcl_Obj **dictObjPtr (out)
Pointeur vers une variable dans laquelle écrire le dictionnaire actuel de cartographie de l'ensemble.
Tcl_Obj *listObj (in)
Une valeur de liste à utiliser pour la liste des paramètres formels avant la sous-commande, la liste définie des sous-commandes dans le dictionnaire ou le préfixe de commande du gestionnaire de sous-commande inconnue. Peut être NULL si la liste des sous-commandes ou le gestionnaire inconnu doivent être supprimés.
Tcl_Obj **listObjPtr (out)
Pointeur vers une variable dans laquelle écrire la liste actuelle des paramètres formels avant la sous-commande, la liste définie des sous-commandes ou le préfixe actuel du gestionnaire inconnu.
Tcl_Namespace **namespacePtrPtr (out)
Pointeur vers une variable dans laquelle écrire le handle de l'espace de noms auquel l'ensemble est lié.

DESCRIPTION

Un ensemble est une commande, liée à un espace de noms, qui se compose d'une collection de sous-commandes implémentées par d'autres commandes Tcl. Le premier argument de la commande d'ensemble est toujours interprété comme un sélecteur qui indique quelle sous-commande exécuter.

Les ensembles sont créés en utilisant Tcl_CreateEnsemble, qui prend quatre arguments : l'interpréteur dans lequel travailler, le nom de l'ensemble à créer, l'espace de noms dans l'interpréteur auquel lier l'ensemble, et l'ensemble par défaut d'indicateurs d'ensemble. Le résultat de la fonction est le jeton de commande pour l'ensemble, qui peut être utilisé pour configurer davantage l'ensemble en utilisant l'API décrite ci-dessous dans PROPRIÉTÉS DE L'ENSEMBLE.

Étant donné le nom d'une commande d'ensemble, le jeton de cette commande peut être récupéré en utilisant Tcl_FindEnsemble. Si le nom de commande donné (dans cmdNameObj) ne fait pas référence à une commande d'ensemble, le résultat de la fonction est NULL et (si le bit TCL_LEAVE_ERR_MSG est défini dans flags) un message d'erreur est laissé dans le résultat de l'interpréteur.

Un jeton de commande peut être vérifié pour voir s'il fait référence à un ensemble en utilisant Tcl_IsEnsemble. Cela renvoie 1 si le jeton fait référence à un ensemble, ou 0 sinon.

PROPRIÉTÉS DE L'ENSEMBLE

Chaque ensemble a quatre propriétés en lecture-écriture et une propriété en lecture seule. Les propriétés sont :

indicateurs (lecture-écriture)
L'ensemble des indicateurs pour l'ensemble, exprimé comme un champ de bits. Actuellement, seul l'indicateur public TCL_ENSEMBLE_PREFIX existe, qui est défini lorsque les préfixes non ambigus des sous-commandes sont autorisés à être résolus en implémentations, ainsi que les correspondances exactes. Les indicateurs peuvent être lus et écrits en utilisant Tcl_GetEnsembleFlags et Tcl_SetEnsembleFlags respectivement. Le résultat de ces deux fonctions est un code de résultat Tcl (TCL_OK, ou TCL_ERROR si le jeton ne fait pas référence à un ensemble).
dictionnaire de cartographie (lecture-écriture)
Un dictionnaire contenant une cartographie des noms de sous-commandes vers des listes de mots à utiliser comme préfixe de commande (remplaçant les deux premiers mots de la commande qui sont la commande d'ensemble elle-même et le nom de la sous-commande), ou NULL si chaque sous-commande doit être mappée à la commande du même nom non qualifié dans l'espace de noms lié de l'ensemble. Par défaut à NULL. Peut être lu et écrit en utilisant Tcl_GetEnsembleMappingDict et Tcl_SetEnsembleMappingDict respectivement. Le résultat de ces deux fonctions est un code de résultat Tcl (TCL_OK, ou TCL_ERROR si le jeton ne fait pas référence à un ensemble) et le dictionnaire obtenu de Tcl_GetEnsembleMappingDict doit toujours être traité comme immuable, même s'il n'est pas partagé. Tous les noms de commandes dans les préfixes définis via Tcl_SetEnsembleMappingDict doivent être entièrement qualifiés.
liste formelle des paramètres avant la sous-commande (lecture-écriture)
Une liste de noms de paramètres formels (les noms n'étant utilisés que lors de la génération de messages d'erreur) qui viennent à l'invocation de l'ensemble entre le nom de l'ensemble et l'argument de sous-commande. NULL (par défaut) est équivalent à la liste vide. Peut être lu et écrit en utilisant Tcl_GetEnsembleParameterList et Tcl_SetEnsembleParameterList respectivement. Le résultat de ces deux fonctions est un code de résultat Tcl (TCL_OK, ou TCL_ERROR si le jeton ne fait pas référence à un ensemble) et le dictionnaire obtenu de Tcl_GetEnsembleParameterList doit toujours être traité comme immuable, même s'il n'est pas partagé.
liste des sous-commandes (lecture-écriture)
Une liste de tous les noms de sous-commandes pour l'ensemble, ou NULL si cela doit être dérivé soit des clés du dictionnaire de cartographie (voir ci-dessus) soit (si cela est également NULL) de l'ensemble des commandes exportées par l'espace de noms lié. Peut être lu et écrit en utilisant Tcl_GetEnsembleSubcommandList et Tcl_SetEnsembleSubcommandList respectivement. Le résultat de ces deux fonctions est un code de résultat Tcl (TCL_OK, ou TCL_ERROR si le jeton ne fait pas référence à un ensemble) et la liste obtenue de Tcl_GetEnsembleSubcommandList doit toujours être traitée comme immuable, même si elle n'est pas partagée.
préfixe de commande du gestionnaire de sous-commande inconnue (lecture-écriture)
Une liste de mots à ajouter au début de toute sous-commande lorsque la sous-commande est inconnue de l'ensemble (conformément à la gestion actuelle des préfixes.

NOM

Tcl_SetEnsembleParameterList

SYNTAXE

Tcl_SetEnsembleParameterList(ensemble, parameter_list)

ARGUMENTS

ensemble - ensemble

parameter_list - liste_paramètres

DESCRIPTION

Associe une liste_paramètres à un ensemble. L'ensemble est une collection de commandes qui peuvent être exécutées avec des paramètres. La liste_paramètres est utilisée pour spécifier les paramètres qui peuvent être passés lors de l'exécution des commandes de l'ensemble.
