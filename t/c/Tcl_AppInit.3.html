Tcl_AppInit(3) Procédures de bibliothèque Tcl Tcl_AppInit(3)

NOM

Tcl_AppInit - effectue l'initialisation spécifique à l'application

SYNTAXE

#include <tcl.h>

int
Tcl_AppInit(interp)

ARGUMENTS

Tcl_Interp *interp (entrée)
Interpréteur pour l'application.

DESCRIPTION

Tcl_AppInit est une procédure « hook » (point d'accroche) qui est appelée par les programmes principaux pour les applications Tcl telles que tclsh et wish. Son but est de permettre la création de nouvelles applications Tcl sans modifier les programmes principaux fournis dans le cadre de Tcl et Tk. Pour créer une nouvelle application, vous écrivez une nouvelle version de Tcl_AppInit pour remplacer la version par défaut fournie par Tcl, puis vous liez votre nouveau Tcl_AppInit avec la bibliothèque Tcl.

Tcl_AppInit est appelée par Tcl_Main et Tk_Main après leur propre initialisation et avant d'entrer dans la boucle principale pour traiter les commandes. Voici quelques exemples de ce que Tcl_AppInit pourrait faire :

[1]
Appeler les procédures d'initialisation pour divers paquets utilisés par l'application. Chaque procédure d'initialisation ajoute de nouvelles commandes à interp pour son paquet et effectue d'autres initialisations spécifiques au paquet.
[2]
Traiter les arguments de la ligne de commande, qui sont accessibles à partir des variables Tcl argv et argv0 dans interp.
[3]
Invoquer un script de démarrage pour initialiser l'application.
[4]
Utiliser les routines Tcl_SetStartupScript et Tcl_GetStartupScript pour définir ou interroger le fichier et l'encodage que la routine active Tcl_Main ou Tk_Main utilisera comme script de démarrage.

Tcl_AppInit retourne TCL_OK ou TCL_ERROR. Si elle retourne TCL_ERROR, elle doit laisser un message d'erreur dans le résultat de l'interpréteur ; sinon, le résultat est ignoré.

En plus de Tcl_AppInit, votre application doit également contenir une procédure main qui appelle Tcl_Main comme suit :

Tcl_Main(argc, argv, Tcl_AppInit);

Le troisième argument de Tcl_Main donne l'adresse de la procédure d'initialisation spécifique à l'application à invoquer. Cela signifie que vous n'avez pas à utiliser le nom Tcl_AppInit pour la procédure, mais en pratique, le nom est presque toujours Tcl_AppInit (dans les versions antérieures à Tcl 7.4, le nom Tcl_AppInit était implicite ; il n'y avait aucun moyen de spécifier explicitement la procédure). La meilleure façon de commencer est de faire une copie du fichier tclAppInit.c de la bibliothèque Tcl ou du répertoire source. Il contient déjà une procédure main et un modèle pour Tcl_AppInit que vous pouvez modifier pour votre application.
