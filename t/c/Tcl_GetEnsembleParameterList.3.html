ARGUMENTS

Tcl_Interp *interp (in/out)
L'interpréteur dans lequel l'ensemble doit être créé ou trouvé. C'est aussi là que les messages d'erreur sont écrits. Les fonctions dont le nom commence par Tcl_GetEnsemble peuvent avoir NULL pour interp, mais toutes les autres fonctions ne le peuvent pas.
const char *name (in)
Le nom de la commande d'ensemble à créer.
Tcl_Namespace *namespacePtr (in)
L'espace de noms auquel la commande d'ensemble doit être liée, ou NULL pour l'espace de noms courant.
int ensFlags (in)
Un ensemble OR'é de bits de drapeaux décrivant la configuration de base de l'ensemble. Actuellement, un seul bit a une signification, TCL_ENSEMBLE_PREFIX, qui est présent lorsque la commande d'ensemble doit également correspondre aux préfixes non ambigus des sous-commandes.
Tcl_Obj *cmdNameObj (in)
Une valeur contenant le nom de la commande d'ensemble à rechercher.
int flags (in)
Un ensemble OR'é de bits de drapeaux contrôlant le comportement de Tcl_FindEnsemble. Actuellement, seul TCL_LEAVE_ERR_MSG est pris en charge.
Tcl_Command token (in)
Un jeton de commande normal qui fait référence à une commande d'ensemble, ou que vous souhaitez utiliser pour tester comme commande d'ensemble dans Tcl_IsEnsemble.
int *ensFlagsPtr (out)
Pointeur vers une variable dans laquelle écrire les bits de drapeaux d'ensemble actuels ; actuellement, seul le bit TCL_ENSEMBLE_PREFIX est défini.
Tcl_Obj *dictObj (in)
Une valeur de dictionnaire à utiliser pour le mappage de la sous-commande au préfixe de commande d'implémentation dans l'ensemble. Peut être NULL si le dictionnaire de mappage doit être supprimé.
Tcl_Obj **dictObjPtr (out)
Pointeur vers une variable dans laquelle écrire le dictionnaire de mappage d'ensemble actuel.
Tcl_Obj *listObj (in)
Une valeur de liste à utiliser pour la liste des paramètres formels de pré-sous-commande, la liste définie des sous-commandes dans le dictionnaire ou le préfixe de commande du gestionnaire de sous-commandes inconnues. Peut être NULL si la liste des sous-commandes ou le gestionnaire inconnu doivent être supprimés.
Tcl_Obj **listObjPtr (out)
Pointeur vers une variable dans laquelle écrire la liste actuelle des paramètres formels de pré-sous-commande, la liste définie des sous-commandes ou le préfixe de commande inconnu actuel.
Tcl_Namespace **namespacePtrPtr (out)
Pointeur vers une variable dans laquelle écrire le handle de l'espace de noms auquel l'ensemble est lié.

DESCRIPTION

Un ensemble est une commande, liée à un espace de noms, qui consiste en une collection de sous-commandes implémentées par d'autres commandes Tcl. Le premier argument de la commande d'ensemble est toujours interprété comme un sélecteur qui indique quelle sous-commande exécuter.

Les ensembles sont créés à l'aide de Tcl_CreateEnsemble, qui prend quatre arguments : l'interpréteur dans lequel travailler, le nom de l'ensemble à créer, l'espace de noms dans l'interpréteur auquel lier l'ensemble, et l'ensemble de drapeaux par défaut. Le résultat de la fonction est le jeton de commande pour l'ensemble, qui peut être utilisé pour configurer davantage l'ensemble à l'aide de l'API décrite ci-dessous dans PROPRIÉTÉS DE L'ENSEMBLE.

Étant donné le nom d'une commande d'ensemble, le jeton de cette commande peut être récupéré à l'aide de Tcl_FindEnsemble. Si le nom de commande donné (dans cmdNameObj) ne fait pas référence à une commande d'ensemble, le résultat de la fonction est NULL et (si le bit TCL_LEAVE_ERR_MSG est défini dans flags) un message d'erreur est laissé dans le résultat de l'interpréteur.

Un jeton de commande peut être vérifié pour voir s'il fait référence à un ensemble à l'aide de Tcl_IsEnsemble. Cela renvoie 1 si le jeton fait référence à un ensemble, ou 0 sinon.

PROPRIÉTÉS DE L'ENSEMBLE

Chaque ensemble a quatre propriétés en lecture/écriture et une propriété en lecture seule. Les propriétés sont :

drapeaux (lecture/écriture)
L'ensemble des drapeaux pour l'ensemble, exprimé sous forme de champ de bits. Actuellement, le seul drapeau public est TCL_ENSEMBLE_PREFIX qui est défini lorsque les préfixes non ambigus des sous-commandes sont autorisés à être résolus en implémentations, ainsi que les correspondances exactes. Les drapeaux peuvent être lus et écrits à l'aide de Tcl_GetEnsembleFlags et Tcl_SetEnsembleFlags respectivement. Le résultat de ces deux fonctions est un code de résultat Tcl (TCL_OK, ou TCL_ERROR si le jeton ne fait pas référence à un ensemble).
dictionnaire de mappage (lecture/écriture)
Un dictionnaire contenant un mappage des noms de sous-commandes à des listes de mots à utiliser comme préfixe de commande (remplaçant les deux premiers mots de la commande qui sont la commande d'ensemble elle-même et le nom de la sous-commande), ou NULL si chaque sous-commande doit être mappée à la commande ayant le même nom non qualifié dans l'espace de noms lié de l'ensemble. Par défaut à NULL. Peut être lu et écrit à l'aide de Tcl_GetEnsembleMappingDict et Tcl_SetEnsembleMappingDict respectivement. Le résultat de ces deux fonctions est un code de résultat Tcl (TCL_OK, ou TCL_ERROR si le jeton ne fait pas référence à un ensemble) et le dictionnaire obtenu de Tcl_GetEnsembleMappingDict doit toujours être traité comme immuable même s'il est non partagé. Tous les noms de commande dans les préfixes définis via Tcl_SetEnsembleMappingDict doivent être entièrement qualifiés.
liste des paramètres formels de pré-sous-commande (lecture/écriture)
Une liste de noms de paramètres formels (les noms n'étant utilisés que lors de la génération de messages d'erreur) qui se situent à l'invocation de l'ensemble entre le nom de l'ensemble et l'argument de la sous-commande. NULL (par défaut) équivaut à la liste vide. Peut être lu et écrit à l'aide de Tcl_GetEnsembleParameterList et Tcl_SetEnsembleParameterList respectivement. Le résultat de ces deux fonctions est un code de résultat Tcl (TCL_OK, ou TCL_ERROR si le jeton ne fait pas référence à un ensemble) et le dictionnaire obtenu de Tcl_GetEnsembleParameterList doit toujours être traité comme immuable même s'il est non partagé.
liste des sous-commandes (lecture/écriture)
Une liste de tous les noms de sous-commandes pour l'ensemble, ou NULL si cela doit être dérivé soit des clés du dictionnaire de mappage (voir ci-dessus), soit (si celui-ci est également NULL) de l'ensemble des commandes exportées par l'espace de noms lié. Peut être lu et écrit à l'aide de Tcl_GetEnsembleSubcommandList et Tcl_SetEnsembleSubcommandList respectivement. Le résultat de ces deux fonctions est un code de résultat Tcl (TCL_OK, ou TCL_ERROR si le jeton ne fait pas référence à un ensemble) et la liste obtenue de Tcl_GetEnsembleSubcommandList doit toujours être traitée comme immuable même si elle est non partagée.
préfixe de commande du gestionnaire de sous-commandes inconnues (lecture/écriture)

Si NULL, le comportement par défaut - générer un message d'erreur approprié - sera utilisé lorsqu'une sous-commande inconnue est rencontrée. Peut être lu et écrit en utilisant respectivement Tcl_GetEnsembleUnknownHandler et Tcl_SetEnsembleUnknownHandler.
