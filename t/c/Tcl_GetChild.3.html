ARGUMENTS

Tcl_Interp *interp (in)
Interpréteur dans lequel la commande spécifiée sera exécutée.

Nom du nouvel interpréteur Tcl enfant à créer ou à manipuler.
int isSafe (in)
Si différent de zéro, un enfant "sécurisé" est créé, adapté à l'exécution de code non fiable ; sinon, un enfant fiable est créé.
Tcl_Interp *childInterp (in)

Nom de la commande cible pour l'alias dans targetInterp.

Nombre d'arguments supplémentaires à passer à la commande alias.
const char *const *argv (in)
Tableau de chaînes, les arguments supplémentaires à passer à la commande alias. La mémoire est détenue par l'appelant.
int objc (in)
Nombre d'arguments de valeur supplémentaires à passer à la commande alias.
Tcl_Obj **objv (in)
Tableau de structures Tcl_Obj, les arguments de valeur supplémentaires à passer à la commande alias. La mémoire est détenue par l'appelant.
Tcl_Interp **targetInterpPtr (in)
Pointeur vers l'emplacement où sera stocké l'interpréteur contenant la commande cible pour un alias.

Pointeur vers l'emplacement où sera stocké le nom de la commande cible pour un alias.
int *argcPtr (out)
Pointeur vers l'emplacement où sera stocké le nombre d'arguments supplémentaires à passer à l'alias. L'emplacement se trouve dans une mémoire détenue par l'appelant.
const char ***argvPtr (out)
Pointeur vers l'emplacement où sera stocké un tableau de chaînes, les arguments supplémentaires à passer à l'alias. L'emplacement se trouve dans une mémoire détenue par l'appelant, le tableau de chaînes est détenu par l'appelant.
int *objcPtr (out)
Pointeur vers l'emplacement où sera stocké le nombre d'arguments de valeur supplémentaires à passer à l'alias. L'emplacement se trouve dans une mémoire détenue par l'appelant.
Tcl_Obj ***objvPtr (out)
Pointeur vers l'emplacement où sera stocké un tableau de structures Tcl_Obj, les arguments de valeur supplémentaires à passer à l'alias. L'emplacement se trouve dans une mémoire détenue par l'appelant, le tableau de structures Tcl_Obj est détenu par l'appelant.
const char *cmdName (in)
Nom d'une commande exposée à cacher ou à créer.
const char *hiddenCmdName (in)
Nom sous lequel une commande cachée est stockée et avec lequel elle peut être exposée ou appelée.

DESCRIPTION

Ces fonctions sont destinées à accéder à la capacité de gestion de plusieurs interpréteurs à partir de programmes C. Elles permettent de gérer plusieurs interpréteurs dans une relation hiérarchique et de gérer les alias, commandes qui, lorsqu'elles sont appelées dans un interpréteur, exécutent une commande dans un autre interpréteur. La valeur retournée par les fonctions qui retournent un int est soit TCL_OK, soit TCL_ERROR. Si TCL_ERROR est retourné, alors le résultat de l'interpréteur contient un message d'erreur.

Tcl_CreateSlave crée un nouvel interpréteur comme enfant de interp. Il crée également une commande enfant nommée childName dans interp qui permet à interp de manipuler le nouvel enfant. Si isSafe est zéro, la commande crée un enfant fiable dans lequel le code Tcl a accès à toutes les commandes Tcl. Si c'est 1, la commande crée un enfant "sécurisé" dans lequel le code Tcl n'a accès qu'à un ensemble de commandes Tcl définies comme "Safe Tcl". Voir l'entrée de manuel Tcl interp pour plus de détails. Si la création du nouvel enfant interpréteur échoue, NULL est retourné.

Tcl_CreateChild est un alias pour Tcl_CreateSlave.

Tcl_IsSafe renvoie 1 si interp est "sécurisé" (créé avec le drapeau TCL_SAFE_INTERPRETER spécifié), 0 sinon.

Tcl_MakeSafe marque interp comme "sécurisé", de sorte que les appels futurs à Tcl_IsSafe renverront 1. Il supprime également de interp toute fonctionnalité connue qui pourrait être dangereuse (commandes et variables). Cependant, il ne peut pas savoir quelles parties d'une extension ou d'une application sont sécurisées et ne fait aucun effort pour supprimer ces parties, donc la sécurité n'est pas garantie après avoir appelé Tcl_MakeSafe. Les utilisateurs doivent être prudents lors de l'utilisation de Tcl_MakeSafe pour éviter les fausses affirmations de sécurité. Dans de nombreux cas, Tcl_CreateSlave peut être une meilleure option, car il crée des interpréteurs dans un état sécurisé connu.

Tcl_GetSlave renvoie un pointeur vers un interpréteur enfant de interp. L'interpréteur enfant est identifié par childName. S'il n'existe pas d'interpréteur enfant de ce nom, NULL est retourné.

Tcl_GetChild est un alias pour Tcl_GetSlave.

Tcl_GetMaster renvoie un pointeur vers l'interpréteur parent de interp. Si interp n'a pas de parent (c'est-à-dire qu'il s'agit d'un interpréteur de niveau supérieur), NULL est retourné.

Tcl_GetParent est un alias pour Tcl_GetMaster.

Tcl_GetInterpPath stocke dans le résultat de interp le chemin relatif entre interp et childInterp ; childInterp doit être un enfant de interp. Si le calcul du chemin relatif réussit, TCL_OK est retourné, sinon TCL_ERROR et un message d'erreur est stocké comme résultat de interp.

Tcl_CreateAlias crée une commande nommée childCmd dans childInterp qui, lorsqu'elle est appelée, provoquera l'appel de la commande targetCmd dans targetInterp. Les arguments spécifiés par les chaînes de caractères dans argv sont toujours ajoutés à tous les arguments fournis lors de l'appel de childCmd et sont passés à targetCmd. Cette opération renvoie TCL_OK si elle réussit, sinon TCL_ERROR et un message d'erreur est stocké dans la valeur de résultat de childInterp. Notez qu'il n'y a aucune restriction sur la relation d'ancêtre (créée par Tcl_CreateSlave) entre childInterp et targetInterp. Deux interpréteurs quelconques peuvent être utilisés sans restriction quant à la manière dont ils sont liés.

Tcl_CreateAliasObj est similaire à Tcl_CreateAlias à l'exception qu'il prend un tableau de valeurs à passer comme arguments supplémentaires au lieu d'un tableau de chaînes.

Tcl_GetAliasObj renvoie des informations sous la forme d'un pointeur vers un tableau de structures Tcl_Obj sur un alias aliasName dans interp. N'importe lequel des champs de résultat peut être NULL, auquel cas les données correspondantes ne sont pas retournées. Si un champ de résultat n'est pas NULL, l'adresse indiquée est définie sur les données correspondantes. Par exemple, si targetCmdPtr n'est pas NULL, il est défini sur un pointeur vers la chaîne contenant le nom de la commande cible.

Tcl_GetAlias renvoie des informations sous la forme d'un pointeur vers un tableau de chaînes au lieu d'un tableau de structures Tcl_Obj, contrairement à Tcl_GetAliasObj. Tcl_GetAlias est déprécié.

NOM

Tcl_ExposeCommand, Tcl_HideCommand - rendre ou cacher des commandes Tcl

SYNTAXIS

#include <tcl.h>

int
Tcl_ExposeCommand(interp, hiddenCmdName, cmdName)
    Tcl_Interp *interp;
    const char *hiddenCmdName;
    const char *cmdName;
int
Tcl_HideCommand(interp, cmdName, hiddenCmdName)
    Tcl_Interp *interp;
    const char *cmdName;
    const char *hiddenCmdName;

ARGUMENTS

?interp?
Interpréteur Tcl dans lequel effectuer l'opération.
?hiddenCmdName?
Nom de la commande dans le jeu des commandes cachées.
?cmdName?
Nom de la commande dans le jeu des commandes exposées.

DESCRIPTION

Les fonctions Tcl_ExposeCommand et Tcl_HideCommand permettent de déplacer des commandes entre le jeu des commandes cachées et le jeu des commandes exposées dans un interpréteur Tcl donné.

Tcl_ExposeCommand déplace la commande nommée hiddenCmdName du jeu des commandes cachées vers le jeu des commandes exposées, en la renommant cmdName. HiddenCmdName doit être le nom d'une commande cachée existante, sinon l'opération retournera TCL_ERROR et laissera un message d'erreur dans le résultat de interp. Si une commande exposée nommée cmdName existe déjà, l'opération retournera TCL_ERROR et laissera un message d'erreur dans le résultat de interp. Si l'opération réussit, elle retournera TCL_OK. Après l'exécution de cette commande, les tentatives d'utilisation de cmdName dans tout mécanisme d'évaluation de script réussiront à nouveau.

Tcl_HideCommand déplace la commande nommée cmdName du jeu des commandes exposées vers le jeu des commandes cachées, sous le nom hiddenCmdName. CmdName doit être le nom d'une commande exposée existante, sinon l'opération retournera TCL_ERROR et laissera un message d'erreur dans le résultat de interp. Actuellement, ni cmdName ni hiddenCmdName ne doivent contenir de qualificateurs de namespace, sinon l'opération retournera TCL_ERROR et laissera un message d'erreur dans le résultat de interp. CmdName sera recherché dans le namespace global, et non par rapport au namespace courant, même si le namespace courant n'est pas le global. Si une commande cachée dont le nom est hiddenCmdName existe déjà, l'opération retournera également TCL_ERROR et un message d'erreur sera laissé dans le résultat de interp. Si l'opération réussit, elle retournera TCL_OK. Après l'exécution de cette commande, les tentatives d'utilisation de cmdName dans tout mécanisme d'évaluation de script échoueront.

Pour une description de l'interface Tcl pour plusieurs interpréteurs, voir interp(n).
