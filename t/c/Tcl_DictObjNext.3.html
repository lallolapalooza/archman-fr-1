Tcl_DictObj(3) Procédures de la bibliothèque Tcl Tcl_DictObj(3)

ARGUMENTS

Tcl_Interp *interp (in)
Si une erreur se produit lors de la conversion d'une valeur en valeur de dictionnaire, un message d'erreur est stocké dans la valeur de résultat de l'interpréteur, sauf si interp est nul.
Tcl_Obj *dictPtr (in/out)
Pointe vers la valeur de dictionnaire à manipuler. Si dictPtr ne pointe pas déjà vers une valeur de dictionnaire, une tentative de conversion sera effectuée.
Tcl_Obj *keyPtr (in)
Pointe vers la clé de la paire clé/valeur à manipuler dans la valeur de dictionnaire.
Tcl_Obj **keyPtrPtr (out)
Pointe vers une variable qui contiendra la clé d'une paire clé/valeur ; peut être nul pour indiquer que l'appelant ne s'intéresse pas à la clé.
Tcl_Obj *valuePtr (in)
Pointe vers la valeur de la paire clé/valeur à manipuler dans la valeur de dictionnaire (ou sous-valeur dans le cas de Tcl_DictObjPutKeyList).
Tcl_Obj **valuePtrPtr (out)
Pointe vers une variable qui contiendra la valeur d'une paire clé/valeur ; pour Tcl_DictObjFirst et Tcl_DictObjNext, peut être nul pour indiquer que l'appelant ne s'intéresse pas à la valeur.
int *sizePtr (out)
Pointe vers une variable qui contiendra le nombre de paires clé/valeur dans le dictionnaire.
Tcl_DictSearch *searchPtr (in/out)
Pointeur vers une structure qui est utilisée pour suivre la progression dans l'énumération de toutes les paires clé/valeur d'un dictionnaire. Le contenu de la structure est initialisé par un appel à Tcl_DictObjFirst. Si l'énumération doit être arrêtée avant que toutes les valeurs du dictionnaire n'aient été renvoyées, la structure de recherche doit être passée à Tcl_DictObjDone pour libérer les verrous internes.
int *donePtr (out)
Pointe vers une variable qui contiendra une valeur non nulle lorsque l'énumération des paires clé/valeur d'un dictionnaire est terminée, et zéro sinon.
int keyc (in)
Indique le nombre de clés à fournir dans le tableau keyv.
Tcl_Obj *const *keyv (in)
Tableau de keyc pointeurs vers des valeurs que Tcl_DictObjPutKeyList et Tcl_DictObjRemoveKeyList utiliseront pour localiser la paire clé/valeur à manipuler dans les sous-dictionnaires de la valeur principale du dictionnaire.

DESCRIPTION

Les valeurs de dictionnaire Tcl ont une représentation interne qui permet une cartographie efficace des clés aux valeurs et garantit que l'ordre des clés dans le dictionnaire reste le même, même si des clés sont supprimées ou ajoutées (les clés supprimées sont déplacées de l'ordre, celles ajoutées sont ajoutées à la fin de l'ordre). Si interprétées comme une liste, les valeurs aux indices pairs de la liste seront les clés du dictionnaire, et chacune sera suivie (à l'indice impair) de la valeur associée à cette clé.

Les procédures décrites dans cette page de manuel sont utilisées pour créer, modifier, indexer et itérer sur des valeurs de dictionnaire à partir de code C.

Tcl_NewDictObj crée une nouvelle valeur de dictionnaire vide. La représentation string de la valeur sera invalide et le compteur de références de la valeur sera zéro.

Tcl_DictObjGet recherche une clé donnée dans le dictionnaire et écrit un pointeur vers la valeur associée à cette clé dans la variable indiquée par valuePtrPtr, ou un pointeur nul s'il n'y a pas de mappage pour la clé. Le résultat de cette opération est TCL_OK, ou TCL_ERROR si dictPtr ne peut pas être converti en dictionnaire.

Tcl_DictObjPut met à jour le dictionnaire pour que la clé donnée mappe à la valeur donnée ; il peut y avoir plusieurs clés dans un dictionnaire. Le dictionnaire ne doit pas être partagé, mais les clés et les valeurs le peuvent. Cette opération peut incrémenter le compteur de références de la clé et de la valeur si nécessaire pour les stocker. Ni la clé ni la valeur ne doivent être NULL. Le résultat de cette opération est TCL_OK, ou TCL_ERROR si dictPtr ne peut pas être converti en dictionnaire.

Tcl_DictObjRemove met à jour le dictionnaire pour que la clé donnée ne mappe à aucune valeur. Le dictionnaire ne doit pas être partagé, mais la clé le peut. La clé stockée dans le dictionnaire aura son compteur de références décrémenté si elle était présente auparavant. Ce n'est pas une erreur si la clé n'existait pas auparavant. Le résultat de cette opération est TCL_OK, ou TCL_ERROR si dictPtr ne peut pas être converti en dictionnaire.

Tcl_DictObjSize met à jour la variable indiquée avec le nombre actuel de paires clé/valeur dans le dictionnaire. Le résultat de cette opération est TCL_OK, ou TCL_ERROR si dictPtr ne peut pas être converti en dictionnaire.

Tcl_DictObjFirst commence une itération sur toutes les paires clé/valeur du dictionnaire, plaçant la clé et la valeur dans les variables indiquées par keyPtrPtr et valuePtrPtr (qui peuvent être nulles pour indiquer que l'appelant ne s'intéresse ni à la clé ni à la valeur respectivement). La paire clé/valeur suivante dans le dictionnaire peut être obtenue avec Tcl_DictObjNext. Les mises à jour concurrentes de la représentation interne du dictionnaire ne modifient pas la progression de l'itération, à moins que le dictionnaire ne soit pas partagé, ce qui entraînera la fin prématurée de l'itération (ce qui ne peut pas être provoqué par la commande dict de Tcl). L'argument searchPtr pointe vers un contexte utilisé pour identifier quelle itération particulière est en cours, et est initialisé par un appel à Tcl_DictObjFirst. L'argument donePtr pointe vers une variable qui est mise à zéro s'il reste des paires clé/valeur à itérer, ou à une valeur non nulle si l'itération est terminée. L'ordre d'itération est défini par l'implémentation. Si dictPtr ne peut pas être converti en dictionnaire, Tcl_DictObjFirst renvoie TCL_ERROR et l'itération n'est pas démarrée ; sinon, il renvoie TCL_OK.

Lorsqu'un dictionnaire est passé à Tcl_DictObjFirst, un bloc de contrôle est placé sur le dictionnaire pour garantir qu'il puisse être itéré en toute sécurité, quelle que soit la modification du dictionnaire pendant l'itération. Pour cette raison, une fois que l'itération sur les clés d'un dictionnaire est terminée (soit parce que toutes les valeurs ont été itérées, indiqué par la variable pointée par donePtr étant mise à un, soit parce qu'aucune valeur supplémentaire n'est nécessaire), le bloc de contrôle doit être passé à Tcl_DictObjDone pour libérer les verrous internes. Une fois qu'un bloc de contrôle particulier est passé à Tcl_DictObjDone, le passer à Tcl_DictObjNext (sans l'avoir d'abord initialisé avec Tcl_DictObjFirst) entraînera la production de zéro valeur et la variable pointée par donePtr sera mise à un. Il est sûr d'appeler Tcl_DictObjDone plusieurs fois sur le même searchPtr pour chaque appel à Tcl_DictObjFirst.

Les procédures Tcl_DictObjPutKeyList et Tcl_DictObjRemoveKeyList sont des analogues proches de Tcl_DictObjPut et Tcl_DictObjRemove, sauf qu'elles travaillent avec un seul dictionnaire et sont conçues pour opérer sur un arbre de dictionnaires imbriqués, où les dictionnaires internes sont stockés comme valeurs dans des dictionnaires externes. Les arguments keyc et keyv indiquent une liste de clés (les clés les plus externes en premier) qui agit comme un chemin vers la clé/valeur à affecter. Note : il n'y a pas d'opération correspondante pour lire une valeur.

EXEMPLE

Utilisation de l'interface d'itération de dictionnaire pour rechercher et déterminer s'il existe une clé qui se mappe à elle-même :

Tcl_DictSearch search;
Tcl_Obj *key, *value;
int done;
/*
 * Supposons que interp et objPtr sont des paramètres. C'est
 * la manière idiomatique de commencer une itération sur le dictionnaire ; elle
 * verrouille la représentation interne, garantissant qu'il n'y a pas de problèmes
 * de modification concurrente lorsque la gestion normale du compteur de références
 * est également utilisée. Le verrou est automatiquement libéré lorsque la boucle est terminée,
 * mais doit être libéré manuellement en cas de sortie exceptionnelle de la boucle.
 * Cependant, il est sûr d'essayer de libérer le verrou même si nous avons terminé
 * l'itération de la boucle.
 */
if (Tcl_DictObjFirst(interp, objPtr, &search,
        &key, &value, &done) != TCL_OK) {
    return TCL_ERROR;
}
for (; !done ; Tcl_DictObjNext(&search, &key, &value, &done)) {
    /*
     * Notez que strcmp() n'est pas une bonne façon de comparer
     * les valeurs et est juste utilisé ici à des fins de démonstration.
     */
    if (!strcmp(Tcl_GetString(key), Tcl_GetString(value))) {
        break;
    }
}
Tcl_DictObjDone(&search);
Tcl_SetObjResult(interp, Tcl_NewBooleanObj(!done));
return TCL_OK;
