Tcl_CreateMathFunc(3) Procédures de la bibliothèque Tcl Tcl_CreateMathFunc(3)

NOM

Tcl_CreateMathFunc, Tcl_GetMathFuncInfo, Tcl_ListMathFuncs - Définir, interroger et énumérer les fonctions mathématiques pour les expressions

AVIS DE DEPRECATION EVENTUELLE

Les fonctions Tcl_CreateMathFunc et Tcl_GetMathFuncInfo sont rendues quelque peu obsolètes par la capacité de créer des fonctions pour les expressions en plaçant des commandes dans l'espace de noms tcl::mathfunc, comme décrit dans la page de manuel mathfunc; l'API décrite sur cette page n'est pas censée être maintenue indéfiniment.

SYNTAXE

#include <tcl.h>

void
Tcl_CreateMathFunc(interp, name, numArgs, argTypes, proc, clientData)

int
Tcl_GetMathFuncInfo(interp, name, numArgsPtr, argTypesPtr, procPtr,
                    clientDataPtr)

Tcl_Obj *
Tcl_ListMathFuncs(interp, pattern)

ARGUMENTS

Tcl_Interp *interp (in)
Interpréteur dans lequel la nouvelle fonction sera définie.
const char *name (in)
Nom de la nouvelle fonction.
int numArgs (in)
Nombre d'arguments de la nouvelle fonction; donne également la taille du tableau argTypes.
Tcl_ValueType *argTypes (in)
Pointe vers un tableau donnant les types autorisés pour chaque argument de la fonction.
Tcl_MathProc *proc (in)
Procédure qui implémente la fonction.
ClientData clientData (in)
Valeur arbitraire d'un mot à passer à proc lorsqu'elle est appelée.
int *numArgsPtr (out)
Pointe vers une variable qui sera définie pour contenir le nombre d'arguments de la fonction.
Tcl_ValueType **argTypesPtr (out)
Pointe vers une variable qui sera définie pour contenir un pointeur vers un tableau donnant les types autorisés pour chaque argument de la fonction, qui devra être libéré à l'aide de Tcl_Free.
Tcl_MathProc **procPtr (out)
Pointe vers une variable qui sera définie pour contenir un pointeur vers le code d'implémentation de la fonction (ou NULL si la fonction est implémentée directement en bytecode).
ClientData *clientDataPtr (out)
Pointe vers une variable qui sera définie pour contenir l'argument clientData passé à Tcl_CreateMathFunc lors de la création de la fonction si celle-ci n'est pas implémentée directement en bytecode.
const char *pattern (in)
Motif à faire correspondre aux noms de fonctions pour les filtrer (en le passant à Tcl_StringMatch), ou NULL pour ne pas appliquer de filtre.

DESCRIPTION

Tcl permet d'utiliser un certain nombre de fonctions mathématiques dans les expressions, telles que sin, cos et hypot. Ces fonctions sont représentées par des commandes dans l'espace de noms tcl::mathfunc. La fonction Tcl_CreateMathFunc est une manière obsolète pour les applications d'ajouter des fonctions supplémentaires à celles déjà fournies par Tcl ou de remplacer des fonctions existantes. Elle ne doit pas être utilisée par de nouvelles applications, qui devraient créer des fonctions mathématiques en utilisant Tcl_CreateObjCommand pour créer une commande dans l'espace de noms tcl::mathfunc.

Dans l'interface Tcl_CreateMathFunc, name est le nom de la fonction tel qu'il apparaîtra dans les expressions. Si name n'existe pas déjà dans l'espace de noms ::tcl::mathfunc, une nouvelle commande est alors créée dans cet espace de noms. Si name existe, la fonction existante est remplacée. numArgs et argTypes décrivent les arguments de la fonction. Chaque entrée dans le tableau argTypes doit être soit TCL_INT, TCL_DOUBLE, TCL_WIDE_INT, soit TCL_EITHER pour indiquer si l'argument correspondant doit être un entier, une valeur flottante double précision, un entier large (64 bits) ou n'importe quoi, respectivement.

Chaque fois que la fonction est appelée dans une expression, Tcl appellera proc. Proc doit avoir des arguments et un résultat qui correspondent au type Tcl_MathProc:

typedef int Tcl_MathProc(
        ClientData clientData,
        Tcl_Interp *interp,
        Tcl_Value *args,
        Tcl_Value *resultPtr);

Lorsque proc est appelée, les arguments clientData et interp seront les mêmes que ceux passés à Tcl_CreateMathFunc. Args pointera vers un tableau de numArgs structures Tcl_Value, qui décrivent les arguments réels de la fonction:

typedef struct Tcl_Value {
    Tcl_ValueType type;
    long intValue;
    double doubleValue;
    Tcl_WideInt wideValue;
} Tcl_Value;

Le champ type indique le type de l'argument et est l'un de TCL_INT, TCL_DOUBLE ou TCL_WIDE_INT. Il correspondra à la valeur argTypes spécifiée pour la fonction, sauf si la valeur argTypes était TCL_EITHER. Tcl convertit l'argument fourni dans l'expression au type demandé dans argTypes, si cela est nécessaire. En fonction de la valeur du champ type, le champ intValue, doubleValue ou wideValue contiendra la valeur réelle de l'argument.

Proc doit calculer son résultat et le stocker soit comme un entier dans resultPtr->intValue, soit comme une valeur flottante dans resultPtr->doubleValue. Il doit également définir resultPtr->type à l'un de TCL_INT, TCL_DOUBLE ou TCL_WIDE_INT pour indiquer quelle valeur a été définie. Dans des circonstances normales, proc doit retourner TCL_OK. Si une erreur se produit pendant l'exécution de la fonction, proc doit retourner TCL_ERROR et laisser un message d'erreur dans le résultat de l'interpréteur.

Tcl_GetMathFuncInfo récupère les valeurs associées à la fonction name qui ont été passées à un appel précédent de Tcl_CreateMathFunc. Normalement, le code de retour est TCL_OK, mais si la fonction nommée n'existe pas, TCL_ERROR est retourné et un message d'erreur est placé dans le résultat de l'interpréteur.

Si aucune erreur ne s'est produite, la référence de tableau placée dans la variable pointée par argTypesPtr est nouvellement allouée et doit être libérée en la passant à Tcl_Free. Certaines fonctions (l'ensemble standard implémenté dans le noyau, et celles définies en plaçant des commandes dans l'espace de noms tcl::mathfunc) n'ont pas d'informations sur les types d'arguments; tenter de récupérer des valeurs pour elles provoque l'écriture de NULL dans la variable pointée par procPtr* et la variable pointée par clientDataPtr* ne sera pas modifiée. La variable pointée par numArgsPointer* contiendra -1, et aucun type d'argument ne sera stocké dans la variable pointée par argTypesPointer*.

Tcl_ListMathFuncs retourne une valeur Tcl contenant une liste de toutes les fonctions mathématiques définies dans l'interpréteur dont le nom correspond à pattern. La valeur retournée a un compteur de références de zéro.
