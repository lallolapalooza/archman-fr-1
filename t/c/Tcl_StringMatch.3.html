Tcl_StringMatch(3) Procédures de bibliothèque Tcl Tcl_StringMatch(3)

NOM

Tcl_StringMatch, Tcl_StringCaseMatch - tester si une chaîne correspond à un motif

SYNOPSIS

#include <tcl.h>

int
Tcl_StringMatch(str, pattern)

int
Tcl_StringCaseMatch(str, pattern, flags)

ARGUMENTS

const char *str (en entrée)
Chaîne à tester.
const char *pattern (en entrée)
Motif à faire correspondre avec la chaîne. Peut contenir des caractères spéciaux des ensembles *?\[].
int flags (en entrée)
Combinaison OU d'indicateurs de correspondance, actuellement seulement TCL_MATCH_NOCASE. 0 spécifie une recherche sensible à la casse.

DESCRIPTION

Cette procédure utilitaire détermine si une chaîne correspond à un motif donné. Si c'est le cas, Tcl_StringMatch renvoie 1. Sinon, Tcl_StringMatch renvoie 0. L'algorithme utilisé pour la correspondance est le même que celui utilisé par la commande Tcl string match et est similaire à l'algorithme utilisé par le C-shell pour la correspondance des noms de fichiers ; voir l'entrée du manuel Tcl pour plus de détails.

Dans Tcl_StringCaseMatch, l'algorithme est le même, mais vous avez la possibilité de rendre la correspondance insensible à la casse. Si vous choisissez cela (en passant TCL_MATCH_NOCASE), alors la chaîne et le motif sont essentiellement comparés en minuscules.

MOTS-CLÉS
