Tcl_GetInt(3)

Paquet: tcl

Licences: TCL

Tcl_GetInt(3) Procédures de bibliothèque Tcl Tcl_GetInt(3)

NOM

Tcl_GetInt, Tcl_GetDouble, Tcl_GetBoolean - convertir de chaîne en entier, double, ou booléen

SYNTAXE

#include <tcl.h>

int
Tcl_GetInt(interp, src, intPtr)

int
Tcl_GetDouble(interp, src, doublePtr)

int
Tcl_GetBoolean(interp, src, intPtr)

ARGUMENTS

Tcl_Interp *interp (in)
Interpréteur à utiliser pour le rapport d'erreurs.
const char *src (in)
Valeur textuelle à convertir.
int *intPtr (out)
Pointeur vers l'emplacement où stocker la valeur entière convertie à partir de src.
double *doublePtr (out)
Pointeur vers l'emplacement où stocker la valeur en virgule flottante double précision convertie à partir de src.

DESCRIPTION

Ces procédures convertissent des chaînes en nombres entiers ou en nombres en virgule flottante double précision ou en booléens (représentés par des entiers valant 0 ou 1). Chacune des procédures prend un argument src, le convertit dans une forme interne d'un type particulier, et stocke la valeur convertie à l'emplacement indiqué par le troisième argument de la procédure. Si tout se passe bien, chacune des procédures renvoie TCL_OK. Si src n'a pas la syntaxe appropriée pour le type désiré, alors TCL_ERROR est renvoyé, un message d'erreur est laissé dans le résultat de l'interpréteur, et rien n'est stocké dans *intPtr ou *doublePtr.

Tcl_GetInt attend que src consiste en une collection de chiffres entiers, éventuellement signés et éventuellement précédés et suivis d'espaces blancs. Si les deux premiers caractères de src après les espaces blancs et le signe optionnels sont “0x” alors src est attendu en forme hexadécimale ; sinon, si les deux premiers caractères de ce type sont “0o” alors src est attendu en forme octale ; sinon, si les deux premiers caractères de ce type sont “0b” alors src est attendu en forme binaire ; sinon, si le premier caractère de ce type est “0” alors src est attendu en forme octale ; sinon, src est attendu en forme décimale.

Tcl_GetDouble attend que src consiste en un nombre en virgule flottante, qui est : des espaces blancs ; un signe ; une séquence de chiffres ; un point décimal “.” ; une séquence de chiffres ; la lettre “e” ; un exposant décimal signé ; et plus d'espaces blancs. N'importe lequel des champs peut être omis, à condition que les chiffres avant ou après le point décimal soient présents et que si le “e” est présent, il doit être suivi du nombre de l'exposant. S'il n'y a aucun champ à part le signe et la séquence initiale de chiffres (c'est-à-dire, pas de point décimal ni d'indicateur d'exposant), cette séquence initiale de chiffres doit prendre l'une des formes que Tcl_GetInt supporte, décrites ci-dessus. L'utilisation de “,” comme point décimal n'est pas supportée, ni aucun autre type de séparateur inter-chiffres ne devrait être présent.

Tcl_GetBoolean attend que src spécifie une valeur booléenne. Si src est l'un de 0, false, no, ou off, alors Tcl_GetBoolean stocke une valeur zéro dans *intPtr. Si src est l'un de 1, true, yes, ou on, alors 1 est stocké dans *intPtr. N'importe laquelle de ces valeurs peut être abrégée, et les orthographes en majuscules sont aussi acceptables.
