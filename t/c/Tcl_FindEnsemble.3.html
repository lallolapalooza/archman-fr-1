ARGUMENTS

Tcl_Interp *interp (entrée/sortie)
L'interpréteur dans lequel l'ensemble doit être créé ou trouvé. Également l'endroit où les messages d'erreur de résultat sont écrits. Les fonctions dont le nom commence par Tcl_GetEnsemble peuvent avoir NULL pour l'interpréteur, mais toutes les autres fonctions ne le peuvent pas.
const char *name (entrée)
Le nom de la commande d'ensemble à créer.
Tcl_Namespace *namespacePtr (entrée)
L'espace de noms dans lequel la commande d'ensemble doit être liée, ou NULL pour l'espace de noms actuel.
int ensFlags (entrée)
Un ensemble OR'ed de bits de drapeau décrivant la configuration de base de l'ensemble. Actuellement, un seul bit a du sens, TCL_ENSEMBLE_PREFIX, qui est présent lorsque la commande d'ensemble doit également correspondre à des préfixes univoques de sous-commandes.
Tcl_Obj *cmdNameObj (entrée)
Une valeur contenant le nom de la commande d'ensemble à rechercher.
int flags (entrée)
Un ensemble OR'ed de bits contrôlant le comportement de Tcl_FindEnsemble. Actuellement, seul TCL_LEAVE_ERR_MSG est pris en charge.
Tcl_Command token (entrée)
Un jeton de commande normal faisant référence à une commande d'ensemble, ou que vous souhaitez utiliser pour tester comme une commande d'ensemble dans Tcl_IsEnsemble.
int *ensFlagsPtr (sortie)
Un pointeur vers une variable où les bits de drapeau actuels de l'ensemble sont écrits ; actuellement, seul le bit TCL_ENSEMBLE_PREFIX est défini.
Tcl_Obj *dictObj (entrée)
Un objet dictionnaire utilisé pour la correspondance préfixe de commande de l'implémentation du sous-commande dans l'ensemble. Peut être NULL si le dictionnaire de correspondance préfixe doit être supprimé.
Tcl_Obj **dictObjPtr (sortie)
Un pointeur vers une variable où le dictionnaire de correspondance préfixe actuel de l'ensemble est écrit.
Tcl_Obj *listObj (entrée)
Un objet liste utilisé pour la liste des paramètres formels de pré-sous-commande, l'ensemble des sous-commandes définis dans le dictionnaire ou le préfixe de la commande de sous-commande inconnue. Peut être NULL si l'ensemble de sous-commandes ou le préfixe de gestion des sous-commandes ne doivent pas être supprimés.
Tcl_Obj **listObjPtr (sortie)
Un pointeur vers une variable où la liste des paramètres formels de pré-sous-commande, l'ensemble des sous-commandes définis ou le préfixe de gestion des sous-commandes inconnue actuel est écrit.
Tcl_Namespace **namespacePtrPtr (sortie)
Un pointeur vers une variable où l'identifiant de l'espace de noms dans lequel l'ensemble est lié est écrit.

DESCRIPTION

Un ensemble est une commande, liée à un espace de noms, qui consiste en une collection de sous-commandes implémentées par d'autres commandes Tcl. Le premier argument de la commande d'ensemble est toujours interprété comme un sélecteur indiquant quel sous-commande doit être exécutée.

Les ensembles sont créés à l'aide de Tcl_CreateEnsemble, qui prend quatre arguments : l'interpréteur dans lequel l'ensemble doit être créé, le nom de l'ensemble à créer, l'espace de noms dans l'interpréteur dans lequel l'ensemble doit être lié, et l'ensemble de drapeaux par défaut de l'ensemble. Le résultat de la fonction est le jeton de commande pour l'ensemble, qui peut être utilisé pour configurer l'ensemble à l'aide de l'API décrite ci-dessous dans PROPRIÉTÉS DE L'ENSEMBLE.

Étant donné le nom d'une commande d'ensemble, le jeton de cette commande peut être récupéré à l'aide de Tcl_FindEnsemble. Si le nom donné (dans cmdNameObj) ne fait pas référence à une commande d'ensemble, le résultat de la fonction est NULL et, si le bit TCL_LEAVE_ERR_MSG est défini dans flags, un message d'erreur est laissé dans le résultat de l'interpréteur.

Un jeton de commande peut être vérifié pour voir s'il fait référence à un ensemble à l'aide de Tcl_IsEnsemble. Ceci retourne 1 si le jeton fait référence à un ensemble, ou 0 sinon.

PROPRIÉTÉS DE L'ENSEMBLE

Chaque ensemble a quatre propriétés en lecture/écriture et une propriété en lecture seule. Les propriétés sont :

drapeaux (lecture/écriture)
L'ensemble des drapeaux pour l'ensemble, exprimé comme un champ de bits. Actuellement, le seul drapeau public est TCL_ENSEMBLE_PREFIX, qui est défini lorsque des préfixes univoques de sous-commandes sont autorisés à correspondre à des implémentations ainsi qu'à des correspondances exactes. Les drapeaux peuvent être lus et écrits à l'aide de Tcl_GetEnsembleFlags et Tcl_SetEnsembleFlags respectivement. Le résultat des deux fonctions est un code de résultat Tcl (TCL_OK, ou TCL_ERROR si le jeton ne fait pas référence à un ensemble).
dictionnaire de correspondance (lecture/écriture)
Un dictionnaire contenant une correspondance de noms de sous-commandes à des listes de mots utilisées comme préfixe de commande (remplaçant les deux premiers mots de la commande qui sont le nom de l'ensemble et le nom du sous-commande), ou NULL si chaque sous-commande doit être mappée à une commande avec le nom non qualifié de l'espace de noms de l'ensemble. La valeur par défaut est NULL. Peut être lu et écrit à l'aide de Tcl_GetEnsembleMappingDict et Tcl_SetEnsembleMappingDict respectivement. Le résultat des deux fonctions est un code de résultat Tcl (TCL_OK, ou TCL_ERROR si le jeton ne fait pas référence à un ensemble) et le dictionnaire obtenu de Tcl_GetEnsembleMappingDict doit toujours être traité comme immuable, même s'il n'est pas partagé. Tous les noms de commandes dans les préfixes définis via Tcl_SetEnsembleMappingDict doivent être entièrement qualifiés.
liste des paramètres formels de pré-sous-commande (lecture/écriture)
Une liste de noms de paramètres formels (utilisés uniquement lors de la génération de messages d'erreur) qui sont invoqués entre le nom de l'ensemble et l'argument du sous-commande. NULL (par défaut) équivaut à une liste vide. Peut être lu et écrit à l'aide de Tcl_GetEnsembleParameterList et Tcl_SetEnsembleParameterList respectivement. Le résultat des deux fonctions est un code de résultat Tcl (TCL_OK, ou TCL_ERROR si le jeton ne fait pas référence à un ensemble) et le dictionnaire obtenu de Tcl_GetEnsembleParameterList doit toujours être traité comme immuable, même s'il n'est pas partagé.
liste des sous-commandes (lecture/écriture)
Une liste de tous les noms de sous-commandes pour l'ensemble, ou NULL si elle est dérivée des clés du dictionnaire de correspondance (voir ci-dessus) ou (si cela est également NULL) des commandes exportées par l'espace de noms lié. Peut être lu et écrit à l'aide de Tcl_GetEnsembleSubcommandList et Tcl_SetEnsembleSubcommandList respectivement. Le résultat des deux fonctions est un code de résultat Tcl (TCL_OK, ou TCL_ERROR si le jeton ne fait pas référence à un ensemble) et la liste obtenue de Tcl_GetEnsembleSubcommandList doit toujours être traitée comme immuable, même si elle n'est pas partagée.
préfixe de commande du gestionnaire de sous-commandes inconnues (lecture/écriture)
Une liste de mots à ajouter au début de toute sous-commande lorsque la sous-commande est inconnue de l'ensemble (selon la règle actuelle de gestion des préfixes). Voir GESTION DES PRÉFIXES pour plus d'informations.

NOM

SYNTAXE

ARGUMENTS

token

DESCRIPTION

La commande namespace ensemble pour plus de détails. Si NULL, le comportement par défaut - générer un message d'erreur approprié si un sous-commande inconnue est trouvée - sera utilisé. Elle peut être lue et écrite en utilisant respectivement Tcl_GetEnsembleUnknownHandler et Tcl_SetEnsembleUnknownHandler. Le résultat des deux fonctions est un code de résultat Tcl (TCL_OK, ou TCL_ERROR si le jeton ne se réfère pas à un ensemble) et la liste obtenue de Tcl_GetEnsembleUnknownHandler doit toujours être traitée comme immuable, même si elle n'est pas partagée.
