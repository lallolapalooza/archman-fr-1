Tcl_ListObj(3) Procédures de bibliothèque Tcl Tcl_ListObj(3)

NOM

Tcl_ListObjAppendList, Tcl_ListObjAppendElement, Tcl_NewListObj, Tcl_SetListObj, Tcl_ListObjGetElements, Tcl_ListObjLength, Tcl_ListObjIndex, Tcl_ListObjReplace - manipuler les valeurs Tcl comme des listes

SYNOPIS

#include <tcl.h>

int
Tcl_ListObjAppendList(interp, listPtr, elemListPtr)

int
Tcl_ListObjAppendElement(interp, listPtr, objPtr)

Tcl_Obj *
Tcl_NewListObj(objc, objv)

Tcl_SetListObj(objPtr, objc, objv)

int
Tcl_ListObjGetElements(interp, listPtr, objcPtr, objvPtr)

int
Tcl_ListObjLength(interp, listPtr, lengthPtr)

int
Tcl_ListObjIndex(interp, listPtr, index, objPtrPtr)

int
Tcl_ListObjReplace(interp, listPtr, first, count, objc, objv)

ARGUMENTS

Tcl_Interp *interp (in)
Si une erreur survient lors de la conversion d'une valeur en valeur de liste, un message d'erreur est laissé dans la valeur de résultat de l'interpréteur sauf si interp est NULL.
Tcl_Obj *listPtr (in/out)
Pointe vers la valeur de liste à manipuler. Si listPtr ne pointe pas déjà vers une valeur de liste, une tentative sera faite pour la convertir en une.
Tcl_Obj *elemListPtr (in/out)
Pour Tcl_ListObjAppendList, pointe vers une valeur de liste contenant des éléments à ajouter à listPtr. Chaque élément de *elemListPtr deviendra un nouvel élément de listPtr. Si *elemListPtr n'est pas NULL et ne pointe pas déjà vers une valeur de liste, une tentative sera faite pour le convertir en une.
Tcl_Obj *objPtr (in)
Pour Tcl_ListObjAppendElement, pointe vers la valeur Tcl qui sera ajoutée à listPtr. Pour Tcl_SetListObj, pointe vers la valeur Tcl qui sera convertie en une valeur de liste contenant les objc éléments du tableau référencé par objv.
int *objcPtr (in)
Pointe vers l'emplacement où Tcl_ListObjGetElements stocke le nombre d'éléments dans listPtr.
Tcl_Obj ***objvPtr (out)
Un emplacement où Tcl_ListObjGetElements stocke un pointeur vers un tableau de pointeurs vers les éléments de listPtr.
int objc (in)
Le nombre de valeurs Tcl que Tcl_NewListObj insérera dans une nouvelle valeur de liste, et que Tcl_ListObjReplace insérera dans listPtr. Pour Tcl_SetListObj, le nombre de valeurs Tcl à insérer dans objPtr.
Tcl_Obj *const objv[] (in)
Un tableau de pointeurs vers des valeurs. Tcl_NewListObj insérera ces valeurs dans une nouvelle valeur de liste et Tcl_ListObjReplace les insérera dans un listPtr existant. Chaque valeur deviendra un élément de liste distinct.
int *lengthPtr (out)
Pointe vers l'emplacement où Tcl_ListObjLength stocke la longueur de la liste.
int index (in)
L'index de l'élément de liste que Tcl_ListObjIndex doit retourner. Le premier élément a l'index 0.
Tcl_Obj **objPtrPtr (out)
Pointe vers l'emplacement où Tcl_ListObjIndex doit stocker un pointeur vers la valeur de l'élément de liste résultant.
int first (in)
L'index du premier élément de liste que Tcl_ListObjReplace doit remplacer. Le premier élément de la liste a l'index 0.
int count (in)
Le nombre d'éléments que Tcl_ListObjReplace doit remplacer.

DESCRIPTION

Les valeurs de liste Tcl ont une représentation interne qui permet une indexation et une adjonction efficaces. Les procédures décrites dans cette page man sont utilisées pour créer, modifier, indexer et ajouter des valeurs Tcl à partir du code C.

Tcl_ListObjAppendList et Tcl_ListObjAppendElement ajoutent toutes deux une ou plusieurs valeurs à la fin de la valeur de liste référencée par listPtr. Tcl_ListObjAppendList ajoute chaque élément de la valeur de liste référencée par elemListPtr tandis que Tcl_ListObjAppendElement ajoute la valeur unique référencée par objPtr. Les deux procédures convertiront la valeur référencée par listPtr en une valeur de liste si nécessaire. Si une erreur survient pendant la conversion, les deux procédures retournent TCL_ERROR et laissent un message d'erreur dans la valeur de résultat de l'interpréteur si interp n'est pas NULL. De même, si elemListPtr ne fait pas déjà référence à une valeur de liste, Tcl_ListObjAppendList tentera de la convertir en une et si une erreur survient pendant la conversion, retournera TCL_ERROR et laissera un message d'erreur dans la valeur de résultat de l'interpréteur si interp n'est pas NULL. Les deux procédures invalident toute ancienne représentation textuelle de listPtr et, si elle a été convertie en une valeur de liste, libèrent toute ancienne représentation interne. De même, Tcl_ListObjAppendList libère toute ancienne représentation interne de elemListPtr si elle la convertit en une valeur de liste. Après avoir ajouté chaque élément de elemListPtr, Tcl_ListObjAppendList incrémente le compteur de références de l'élément puisque listPtr y fait également référence. Pour la même raison, Tcl_ListObjAppendElement incrémente le compteur de références de objPtr. Si aucune erreur ne survient, les deux procédures retournent TCL_OK après avoir ajouté les valeurs.

Tcl_NewListObj et Tcl_SetListObj créent une nouvelle valeur ou modifient une valeur existante pour contenir les objc éléments du tableau référencé par objv où chaque élément est un pointeur vers une valeur Tcl. Si objc est inférieur ou égal à zéro, elles retournent une valeur vide. Si objv est NULL, la liste résultante contient 0 éléments, avec un espace réservé dans une représentation interne pour objc éléments supplémentaires (pour éviter sa réallocation ultérieure). La représentation textuelle de la nouvelle valeur est laissée invalide. Les deux procédures incrémentent les compteurs de références des éléments dans objc puisque la valeur de liste y fait maintenant référence. La nouvelle valeur de liste retournée par Tcl_NewListObj a un compteur de références de zéro.

Tcl_ListObjGetElements retourne un compte et un pointeur vers un tableau des éléments d'une valeur de liste. Elle retourne le compte en le stockant à l'adresse objcPtr. De même, elle retourne le pointeur du tableau en le stockant à l'adresse objvPtr. La mémoire pointée est gérée par Tcl et ne doit pas être libérée ou modifiée par l'appelant. Si la liste est vide, 0 est stocké à objcPtr et NULL à objvPtr. Si listPtr n'est pas déjà une valeur de liste, Tcl_ListObjGetElements tentera de la convertir en une ; si la conversion échoue, elle retourne TCL_ERROR et laisse un message d'erreur dans la valeur de résultat de l'interpréteur si interp n'est pas NULL. Sinon, elle retourne TCL_OK après avoir stocké le compte et le pointeur du tableau.

Tcl_ListObjLength retourne le nombre d'éléments dans la valeur de liste référencée par listPtr. Elle retourne ce compte en stockant un entier à l'adresse lengthPtr. Si la valeur n'est pas déjà une valeur de liste, Tcl_ListObjLength tentera de la convertir en une ; si la conversion échoue, elle retourne TCL_ERROR et laisse un message d'erreur dans la valeur de résultat de l'interpréteur si interp n'est pas NULL. Sinon, elle retourne TCL_OK après avoir stocké la longueur de la liste.

La procédure Tcl_ListObjIndex retourne un pointeur vers la valeur à l'élément index dans la liste référencée par listPtr. Elle retourne cette valeur en stockant un pointeur vers celle-ci à l'adresse objPtrPtr. Si listPtr ne fait pas déjà référence à une valeur de liste, Tcl_ListObjIndex tentera de la convertir en une ; si la conversion échoue, elle retourne TCL_ERROR et laisse un message d'erreur dans la valeur de résultat de l'interpréteur si interp n'est pas NULL. Si l'index est hors limites, c'est-à-dire si index est négatif ou supérieur ou égal au nombre d'éléments de la liste, Tcl_ListObjIndex stocke un NULL dans objPtrPtr et retourne TCL_OK. Sinon, elle retourne TCL_OK après avoir stocké le pointeur vers la valeur de l'élément. Le compteur de références de l'élément de liste n'est pas incrémenté ; l'appelant doit le faire s'il a besoin de conserver un pointeur vers l'élément.

Tcl_ListObjReplace remplace zéro ou plusieurs éléments de la liste référencée par listPtr par les objc valeurs du tableau référencé par objv. Si listPtr ne pointe pas vers une valeur de liste, Tcl_ListObjReplace tentera de la convertir en une ; si la conversion échoue, elle retourne TCL_ERROR et laisse un message d'erreur dans la valeur de résultat de l'interpréteur si interp n'est pas NULL. Sinon, elle retourne TCL_OK après avoir remplacé les valeurs. Si objv est NULL, aucun nouvel élément n'est ajouté. Si l'argument first est zéro ou négatif, il fait référence au premier élément. Si first est supérieur ou égal au nombre d'éléments de la liste, alors tous les éléments sont ajoutés.

Tcl_ListObjReplace

NAME

Tcl_ListObjReplace – replace elements in a list

SYNOPSIS

#include <tcl.h>

int
Tcl_ListObjReplace(interp, listPtr, first, count, objc, objv)
    Tcl_Interp *interp;
    Tcl_Obj *listPtr;
    int first;
    int count;
    int objc;
    const Tcl_Obj *const objv[];

ARGUMENTS

Tcl_Interp *interp (in)
Interpreter to use for error reporting.
Tcl_Obj *listPtr (in)
Points to the list object to modify.
int first (in)
Index of the first element to replace. May be negative to indicate position relative to the end of the list.
int count (in)
Number of elements to replace. If count is zero or negative, no elements are deleted.
int objc (in)
Number of new elements to insert. Must be non-negative.
const Tcl_Obj *const objv[] (in)
Array of pointers to the new elements to insert. If objc is 0, this argument is ignored (and may be NULL).

DESCRIPTION

This procedure modifies the list object referenced by listPtr by replacing count elements starting at index first with the objc elements referenced by the array objv. The new elements are inserted before the element designated by first. If count is negative, it is treated as zero; if objc is negative, it is treated as zero. If first is negative, it is treated as an index relative to the end of the list, i.e., an index of -1 refers to the last element, -2 to the second-to-last element and so on. If first is greater than the length of the list, it is treated as equal to the length of the list, and if first is less than 0, it is treated as 0.

If count is greater than the number of elements available starting at index first, then all elements from first to the end of the list are replaced. If objc is zero then no elements are inserted.

The listPtr argument must be a Tcl value that is currently a list. If listPtr is not a list, an error will be returned. The procedure handles updating the internal representation of the list and its string representation. It also manages the reference counts of the objects involved. The reference count of listPtr is not modified.

If count is zero or negative then no elements are deleted; the new elements are simply inserted before the one designated by first. If objc is zero then no elements are inserted.

Tcl_ListObjReplace invalidates listPtr's old string representation. The reference counts of any elements inserted from objv are incremented since the resulting list now refers to them. Similarly, the reference counts for any replaced values are decremented.

Because Tcl_ListObjReplace combines both element insertion and deletion, it can be used to implement a number of list operations. For example, the following code inserts the objc values referenced by the array of value pointers objv just before the element index of the list referenced by listPtr:

result = Tcl_ListObjReplace(interp, listPtr, index, 0,
        objc, objv);

Similarly, the following code appends the objc values referenced by the array objv to the end of the list listPtr:

result = Tcl_ListObjLength(interp, listPtr, &length);
if (result == TCL_OK) {
    result = Tcl_ListObjReplace(interp, listPtr, length, 0,
            objc, objv);
}

The count list elements starting at first can be deleted by simply calling Tcl_ListObjReplace with a NULL objvPtr:

result = Tcl_ListObjReplace(interp, listPtr, first, count,
        0, NULL);
