ARGUMENTS

Tcl_Interp *interp (in/out)
L'interpréteur dans lequel l'ensemble est créé ou trouvé. C'est aussi là où les messages d'erreur de résultat sont écrits. Les fonctions dont le nom commence par Tcl_GetEnsemble peuvent avoir un interp NULL, mais toutes les autres fonctions ne le peuvent pas.
const char *name (in)
Le nom de la commande d'ensemble à créer.
Tcl_Namespace *namespacePtr (in)
L'espace de noms auquel la commande d'ensemble sera liée, ou NULL pour l'espace de noms courant.
int ensFlags (in)
Un ensemble OR'ed de bits de drapeau décrivant la configuration de base de l'ensemble. Actuellement, un seul bit a un sens, TCL_ENSEMBLE_PREFIX, qui est activé lorsque la commande d'ensemble doit également faire correspondre les préfixes de sous-commandes non ambigus.
Tcl_Obj *cmdNameObj (in)
Une valeur contenant le nom de la commande d'ensemble à rechercher.
int flags (in)
Un ensemble OR'ed de bits contrôlant le comportement de Tcl_FindEnsemble. Actuellement, seul TCL_LEAVE_ERR_MSG est pris en charge.
Tcl_Command token (in)
Un jeton de commande normal faisant référence à une commande d'ensemble, ou que vous souhaitez tester comme une commande d'ensemble dans Tcl_IsEnsemble.
int *ensFlagsPtr (out)
Un pointeur vers une variable dans laquelle les bits de drapeau actuels de l'ensemble sont écrits ; actuellement, seul le bit TCL_ENSEMBLE_PREFIX est défini.
Tcl_Obj *dictObj (in)
Une valeur de dictionnaire à utiliser comme dictionnaire de mappage de préfixe de commande d'implémentation pour la commande d'ensemble. Peut être NULL si le dictionnaire de mappage doit être supprimé.
Tcl_Obj **dictObjPtr (out)
Un pointeur vers une variable dans laquelle le dictionnaire de mappage de préfixe de commande d'ensemble est écrit.
Tcl_Obj *listObj (in)
Une valeur de liste à utiliser comme liste de paramètres formels des sous-commandes, la liste des sous-commandes définies dans le dictionnaire, ou le préfixe de commande des sous-commandes non définies. Peut être NULL si la liste des sous-commandes ou le préfixe de commande des sous-commandes non définies doivent être supprimés.
Tcl_Obj **listObjPtr (out)
Un pointeur vers une variable dans laquelle la liste des paramètres formels des sous-commandes, la liste des sous-commandes définies, ou le préfixe actuel de la commande des sous-commandes non définies est écrit.
Tcl_Namespace **namespacePtrPtr (out)
Un pointeur vers une variable dans laquelle le descripteur de l'espace de noms auquel l'ensemble est lié est écrit.

DESCRIPTION

Un ensemble est une commande, liée à un espace de noms, qui consiste en une collection de sous-commandes implémentées par d'autres commandes Tcl. Le premier argument de la commande d'ensemble est toujours interprété comme un sélecteur indiquant quelle sous-commande exécuter.

Les ensembles sont créés à l'aide de Tcl_CreateEnsemble, qui prend quatre arguments : l'interpréteur sur lequel travailler, le nom de l'ensemble à créer, l'espace de noms dans l'interpréteur auquel l'ensemble sera lié, et l'ensemble de drapeaux par défaut de l'ensemble. Le résultat de la fonction est le jeton de commande pour l'ensemble, qui peut être utilisé pour configurer l'ensemble à l'aide de l'API décrite dans PROPRIÉTÉS DE L'ENSEMBLE.

Étant donné le nom d'une commande d'ensemble, le jeton de cette commande peut être récupéré à l'aide de Tcl_FindEnsemble. Si le nom donné (dans cmdNameObj) ne fait pas référence à une commande d'ensemble, le résultat de la fonction est NULL et (si le bit TCL_LEAVE_ERR_MSG est défini dans flags) un message d'erreur est laissé dans le résultat de l'interpréteur.

Un jeton de commande peut être vérifié pour voir s'il fait référence à un ensemble à l'aide de Tcl_IsEnsemble. Celle-ci renvoie 1 si le jeton fait référence à un ensemble, ou 0 sinon.

PROPRIÉTÉS DE L'ENSEMBLE

Chaque ensemble a quatre propriétés en lecture/écriture et une propriété en lecture seule. Les propriétés sont :

flags (lecture/écriture)
L'ensemble de drapeaux pour l'ensemble, exprimé sous forme de champ de bits. Actuellement, le seul drapeau public est TCL_ENSEMBLE_PREFIX, qui est défini lorsque les préfixes non ambigus des sous-commandes peuvent être résolus en implémentations ainsi que les correspondances exactes. Les drapeaux peuvent être lus et écrits à l'aide respectivement de Tcl_GetEnsembleFlags et Tcl_SetEnsembleFlags. Le résultat des deux fonctions est un code de résultat Tcl (TCL_OK, ou TCL_ERROR si le jeton ne fait pas référence à un ensemble).
dictionnaire de mappage (lecture/écriture)
Un dictionnaire contenant une carte des noms de sous-commandes à des listes de mots qui seront utilisés comme préfixe de commande (remplaçant les deux premiers mots de la commande, qui sont la commande d'ensemble et le nom de la sous-commande), ou NULL si chaque sous-commande doit être mappée à une commande avec le nom non qualifié dans l'espace de noms de l'ensemble. La valeur par défaut est NULL. Peut être lu et écrit à l'aide respectivement de Tcl_GetEnsembleMappingDict et Tcl_SetEnsembleMappingDict. Le résultat des deux fonctions est un code de résultat Tcl (TCL_OK, ou TCL_ERROR si le jeton ne fait pas référence à un ensemble) et le dictionnaire obtenu de Tcl_GetEnsembleMappingDict doit toujours être traité comme immuable, même s'il n'est pas partagé. Tous les noms de commande dans les préfixes définis via Tcl_SetEnsembleMappingDict doivent être entièrement qualifiés.
liste de paramètres formels pré-sous-commande (lecture/écriture)
Une liste de noms de paramètres formels (utilisés uniquement lors de la génération de messages d'erreur) qui sont appelés entre le nom de l'ensemble et l'argument de la sous-commande. NULL (la valeur par défaut) équivaut à la liste vide. Peut être lu et écrit à l'aide respectivement de Tcl_GetEnsembleParameterList et Tcl_SetEnsembleParameterList. Le résultat des deux fonctions est un code de résultat Tcl (TCL_OK, ou TCL_ERROR si le jeton ne fait pas référence à un ensemble) et le dictionnaire obtenu de Tcl_GetEnsembleParameterList doit toujours être traité comme immuable, même s'il n'est pas partagé.
liste de sous-commandes (lecture/écriture)
Une liste de tous les noms de sous-commandes pour l'ensemble, ou NULL s'ils doivent être dérivés des clés du dictionnaire de mappage (voir ci-dessus) ou (si cela est également NULL) des commandes exportées par l'espace de noms lié. Peut être lu et écrit à l'aide respectivement de Tcl_GetEnsembleSubcommandList et Tcl_SetEnsembleSubcommandList. Le résultat des deux fonctions est un code de résultat Tcl (TCL_OK, ou TCL_ERROR si le jeton ne fait pas référence à un ensemble) et la liste obtenue de Tcl_GetEnsembleSubcommandList doit toujours être traitée comme immuable, même si elle n'est pas partagée.
préfixe de commande du gestionnaire de sous-commande inconnue (lecture/écriture)
Une liste de mots qui sont préfixés devant toute sous-commande lorsqu'elle n'est pas connue de l'ensemble (selon le traitement actuel des préfixes). Peut être NULL si le préfixe de commande des sous-commandes non définies doit être supprimé. Le préfixe doit être utilisé pour générer des messages d'erreur.

NOM

Tcl_GetEnsembleUnknownHandler

SYNTAXE

Tcl_GetEnsembleUnknownHandler(3)

ARGUMENTS

Tcl_GetEnsembleUnknownHandler

DESCRIPTION

L'ensemble fait référence à un ensemble de commandes qui peuvent être exécutées dans un contexte spécifique. Certaines caractéristiques comprennent :

unknown
Est utilisé lorsque l'on tente d'exécuter une commande qui n'est pas définie. Cette valeur peut être lue et écrite en utilisant respectivement Tcl_GetEnsembleUnknownHandler et Tcl_SetEnsembleUnknownHandler. Le résultat des deux fonctions est un code de résultat Tcl (TCL_OK, ou TCL_ERROR si le jeton ne fait pas référence à un ensemble) et la liste obtenue de Tcl_GetEnsembleUnknownHandler doit toujours être traitée comme immuable même si elle n'est pas partagée.
espace de noms lié
L'espace de noms auquel l'ensemble est lié ; lorsque l'espace de noms est supprimé, l'ensemble le sera aussi, et cet espace de noms est également l'espace de noms dont la liste des commandes exportées est utilisée si le dictionnaire de mappage et les propriétés de sous-commande sont tous deux nuls. Peut être lu en utilisant Tcl_GetEnsembleNamespace, qui renvoie un code de résultat Tcl (TCL_OK, ou TCL_ERROR si le jeton ne fait pas référence à un ensemble).
