Tcl_ExprLong(3) Procédures de bibliothèque Tcl Tcl_ExprLong(3)

NOM

Tcl_ExprLong, Tcl_ExprDouble, Tcl_ExprBoolean, Tcl_ExprString - évaluer une expression

SYNTAXE

#include <tcl.h>

int
Tcl_ExprLong(interp, expr, longPtr)

int
Tcl_ExprDouble(interp, expr, doublePtr)

int
Tcl_ExprBoolean(interp, expr, booleanPtr)

int
Tcl_ExprString(interp, expr)

ARGUMENTS

Tcl_Interp *interp (entrée)
Interpréteur dans le contexte duquel évaluer expr.
const char *expr (entrée)
Expression à évaluer.
long *longPtr (sortie)
Pointeur vers l'emplacement où stocker la valeur entière de l'expression.
int *doublePtr (sortie)
Pointeur vers l'emplacement où stocker la valeur à virgule flottante de l'expression.
int *booleanPtr (sortie)
Pointeur vers l'emplacement où stocker la valeur booléenne 0/1 de l'expression.

DESCRIPTION

Ces quatre procédures évaluent toutes l'expression fournie par l'argument expr et retournent le résultat sous l'une des quatre formes différentes. L'expression peut avoir l'une des formes acceptées par la commande expr. Notez que ces procédures ont été largement remplacées par les procédures basées sur les valeurs Tcl_ExprLongObj, Tcl_ExprDoubleObj, Tcl_ExprBooleanObj, et Tcl_ExprObj. Ces procédures basées sur les valeurs évaluent une expression contenue dans une valeur Tcl au lieu d'une chaîne. L'argument valeur peut conserver une représentation interne plus efficace à exécuter.

L'argument interp fait référence à un interpréteur utilisé pour évaluer l'expression (par exemple, pour les variables et les commandes Tcl imbriquées) et pour retourner les informations d'erreur.

Pour toutes ces procédures, la valeur de retour est un résultat Tcl standard : TCL_OK signifie que l'expression a été évaluée avec succès, et TCL_ERROR signifie qu'une erreur s'est produite lors de l'évaluation de l'expression. Si TCL_ERROR est retourné, le résultat de l'interpréteur contiendra un message décrivant l'erreur. Si une erreur se produit lors de l'exécution d'une commande Tcl intégrée dans l'expression, cette erreur sera retournée.

Si l'expression est évaluée avec succès, sa valeur est retournée sous l'une des quatre formes, en fonction de la procédure appelée. Tcl_ExprLong stocke une valeur entière à *longPtr. Si la valeur réelle de l'expression est un nombre à virgule flottante, elle est tronquée en un entier. Si la valeur réelle de l'expression est une chaîne non numérique, une erreur est retournée.

Tcl_ExprDouble stocke une valeur à virgule flottante à *doublePtr. Si la valeur réelle de l'expression est un entier, elle est convertie en virgule flottante. Si la valeur réelle de l'expression est une chaîne non numérique, une erreur est retournée.

Tcl_ExprBoolean stocke une valeur entière 0/1 à *booleanPtr. Si la valeur réelle de l'expression est un entier ou un nombre à virgule flottante, alors elles stockent 0 à *booleanPtr si la valeur était zéro et 1 sinon. Si la valeur réelle de l'expression est une chaîne non numérique, elle doit être l'une des valeurs acceptées par Tcl_GetBoolean, comme “yes” ou “no”, sinon une erreur se produit.

Tcl_ExprString retourne la valeur de l'expression sous forme de chaîne stockée dans le résultat de l'interpréteur.

VOIR AUSSI

Tcl_ExprLongObj, Tcl_ExprDoubleObj, Tcl_ExprBooleanObj, Tcl_ExprObj
