Tcl_GetDoubleFromObj(3)

Paquet: tcl

Licences: TCL

Tcl_DoubleObj(3) Procédures de bibliothèque Tcl Tcl_DoubleObj(3)

NOM

Tcl_NewDoubleObj, Tcl_SetDoubleObj, Tcl_GetDoubleFromObj - manipuler les valeurs Tcl comme des valeurs à virgule flottante

SYNTAXE

#include <tcl.h>

Tcl_Obj *
Tcl_NewDoubleObj(doubleValue)

Tcl_SetDoubleObj(objPtr, doubleValue)

int
Tcl_GetDoubleFromObj(interp, objPtr, doublePtr)

ARGUMENTS

double doubleValue (entrée)
Une valeur à virgule flottante double précision utilisée pour initialiser ou définir une valeur Tcl.
Tcl_Obj *objPtr (entrée/sortie)
Pour Tcl_SetDoubleObj, ceci pointe vers la valeur dans laquelle stocker une valeur double. Pour Tcl_GetDoubleFromObj, ceci fait référence à la valeur à partir de laquelle récupérer une valeur double.
Tcl_Interp *interp (entrée/sortie)
Lorsqu'il n'est pas NULL, un message d'erreur est laissé ici lorsque la récupération de la valeur double échoue.
double *doublePtr (sortie)
Pointe vers l'emplacement où stocker la valeur double obtenue à partir de objPtr.

DESCRIPTION

Ces procédures sont utilisées pour créer, modifier et lire des valeurs Tcl qui contiennent des valeurs à virgule flottante double précision.

Tcl_NewDoubleObj crée et retourne une nouvelle valeur Tcl initialisée à la valeur double doubleValue. La valeur Tcl retournée n'est pas partagée.

Tcl_SetDoubleObj définit la valeur d'une valeur Tcl existante pointée par objPtr à la valeur double doubleValue. L'argument objPtr doit pointer vers une valeur Tcl non partagée. Toute tentative de définir la valeur d'une valeur Tcl partagée viole la politique de copie à la modification de Tcl. Toute représentation sous forme de chaîne ou représentation interne existante dans la valeur Tcl non partagée sera libérée à la suite de la définition de la nouvelle valeur.

Tcl_GetDoubleFromObj tente de récupérer une valeur double à partir de la valeur Tcl objPtr. Si la tentative réussit, alors TCL_OK est retourné, et la valeur double est écrite dans le stockage pointé par doublePtr. Si la tentative échoue, alors TCL_ERROR est retourné, et si interp n'est pas NULL, un message d'erreur est laissé dans interp. Le Tcl_ObjType de objPtr peut être modifié pour rendre les appels ultérieurs à Tcl_GetDoubleFromObj plus efficaces.

Tcl_NewObj, Tcl_DecrRefCount, Tcl_IncrRefCount, Tcl_GetObjResult
