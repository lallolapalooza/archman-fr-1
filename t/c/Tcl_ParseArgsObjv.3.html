Tcl_ParseArgsObjv(3) Procédures de la bibliothèque Tcl Tcl_ParseArgsObjv(3)

NOM

Tcl_ParseArgsObjv - analyse les arguments selon une description tabulaire

SYNTAXE

#include <tcl.h>

int
Tcl_ParseArgsObjv(interp, argTable, objcPtr, objv, remObjv)

ARGUMENTS

Tcl_Interp *interp (out)
Où stocker les messages d'erreur.
const Tcl_ArgvInfo *argTable (in)
Pointeur vers le tableau de descripteurs d'options.
int *objcPtr (in/out)
Un pointeur vers une variable contenant le nombre d'arguments dans objv. Sera modifié pour contenir le nombre d'arguments restants dans la liste d'arguments non traités stockée dans remObjv.
Tcl_Obj *const *objv (in)
Le tableau d'arguments à analyser.
Tcl_Obj ***remObjv (out)
Pointeur vers une variable qui contiendra le tableau d'arguments non traités. Doit être NULL si aucun retour d'arguments non traités n'est requis. Si objcPtr est mis à jour avec une valeur non nulle, le tableau retourné par ce biais doit être libéré à l'aide de ckfree.

DESCRIPTION

La fonction Tcl_ParseArgsObjv fournit un système pour analyser les listes d'arguments de la forme “-nomOption valeurOption ...”. Ces listes d'arguments se retrouvent couramment dans les arguments d'un programme ainsi que dans les arguments d'une commande Tcl individuelle. Cet analyseur suppose que l'ordre des arguments n'a pas d'importance, sauf dans la mesure où les copies ultérieures d'une option dupliquée remplacent les précédentes.

Le tableau d'arguments est décrit par les paramètres objcPtr et objv, et un tableau d'arguments non traités est retourné via les paramètres objcPtr et remObjv ; si aucun retour d'arguments non traités n'est souhaité, le paramètre remObjv doit être NULL. En cas de problème, y compris si l'option “générer aide” est sélectionnée, un message d'erreur est laissé dans le résultat de l'interpréteur et TCL_ERROR est retourné. Sinon, le résultat de l'interpréteur est laissé inchangé et TCL_OK est retourné.

L'ensemble des arguments à analyser est décrit par le paramètre argTable. Celui-ci pointe vers un tableau de structures de descripteurs qui est terminé par une entrée dont le champ type est défini à TCL_ARGV_END. Par commodité, les entrées prototypiques suivantes sont fournies :

TCL_ARGV_AUTO_HELP
Permet au processeur d'arguments de fournir une aide lorsqu'il reçoit l'argument “-help”.
TCL_ARGV_AUTO_REST
Indique au processeur d'arguments que les arguments suivant “--” doivent être laissés non traités.
TCL_ARGV_TABLE_END
Marque la fin du tableau de descripteurs d'arguments.

ENTRÉES DE DESCRIPTEUR D'ARGUMENT

Chaque entrée du tableau de descripteurs d'arguments doit être une structure de type Tcl_ArgvInfo. La structure est définie comme suit :

typedef struct {
    int type;
    const char *keyStr;
    void *srcPtr;
    void *dstPtr;
    const char *helpStr;
    ClientData clientData;
} Tcl_ArgvInfo;

Le champ keyStr contient le nom de l'option ; par convention, il commencera normalement par un caractère “-”. Les champs type, srcPtr, dstPtr et clientData décrivent l'interprétation de la valeur de l'argument, comme décrit ci-dessous. Le champ helpStr donne un texte qui est utilisé pour fournir de l'aide aux utilisateurs lorsqu'ils la demandent.

Comme indiqué ci-dessus, le champ type est utilisé pour décrire l'interprétation de la valeur de l'argument. Les valeurs suivantes sont des valeurs acceptables pour type :

TCL_ARGV_CONSTANT
L'argument ne prend pas d'argument de valeur suivant. Si cet argument est présent, la valeur (entière) du champ srcPtr est copiée dans la variable pointée par le champ dstPtr. Le champ clientData est ignoré.
TCL_ARGV_END
Cette valeur marque la fin de tous les descripteurs d'options dans le tableau. Tous les autres champs sont ignorés.
TCL_ARGV_FLOAT
Cet argument prend une valeur flottante suivante. La valeur (une fois analysée par Tcl_GetDoubleFromObj) sera stockée sous forme de valeur en virgule flottante double précision dans la variable pointée par le champ dstPtr. Les champs srcPtr et clientData sont ignorés.
TCL_ARGV_FUNC
Cet argument prend éventuellement un argument de valeur suivant ; il appartient à la fonction de rappel gestionnaire passée dans srcPtr de décider. Cette fonction aura la signature suivante :
typedef int (Tcl_ArgvFuncProc)(
        ClientData clientData,
        Tcl_Obj *objPtr,
        void *dstPtr);

Le résultat est une valeur booléenne indiquant s'il faut consommer l'argument suivant. Le clientData est la valeur de l'entrée du tableau, le objPtr est la valeur qui représente l'argument suivant ou NULL s'il n'y a pas d'arguments suivants du tout, et l'argument dstPtr de la Tcl_ArgvFuncProc est l'emplacement où écrire la valeur analysée.

TCL_ARGV_GENFUNC
Cet argument prend zéro ou plusieurs arguments suivants ; la fonction de rappel gestionnaire passée dans srcPtr retourne combien (ou un nombre négatif pour signaler une erreur, auquel cas elle doit également définir le résultat de l'interpréteur). La fonction aura la signature suivante :
typedef int (Tcl_ArgvGenFuncProc)(
        ClientData clientData,
        Tcl_Interp *interp,
        int objc,
        Tcl_Obj *const *objv,
        void *dstPtr);

Le clientData est la valeur de l'entrée du tableau, l'interp est l'endroit où stocker les messages d'erreur, objc et objv décrivent un tableau de tous les arguments restants, et l'argument dstPtr de la Tcl_ArgvGenFuncProc est l'emplacement où écrire la ou les valeurs analysées.

TCL_ARGV_HELP
Cet argument spécial ne prend pas d'argument de valeur suivant, mais provoque au lieu de cela la génération par Tcl_ParseArgsObjv d'un message d'erreur décrivant les arguments supportés. Tous les autres champs sauf le champ helpStr sont ignorés.
TCL_ARGV_INT
Cet argument prend un argument de valeur entier suivant. La valeur (une fois analysée par Tcl_GetIntFromObj) sera stockée sous forme d'entier dans la variable pointée par le champ dstPtr. Le champ srcPtr est ignoré.
TCL_ARGV_REST
Cet argument spécial ne prend pas d'argument de valeur suivant, mais marque au lieu de cela que tous les arguments suivants doivent être laissés non traités. Les champs srcPtr, dstPtr et clientData sont ignorés.
TCL_ARGV_STRING
Cet argument prend un argument de valeur de chaîne de caractères suivant. Un pointeur vers la chaîne sera stocké à dstPtr ; la chaîne interne aura une durée de vie liée à la durée de vie de la représentation de chaîne de la valeur de l'argument dont elle provient, et doit donc être copiée si elle doit être conservée. Les champs srcPtr et clientData sont ignorés.
