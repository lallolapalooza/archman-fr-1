ARGUMENTS

Tcl_Interp *interp (entrée)
Interpréteur dans lequel la commande spécifiée sera exécutée.
const char *name (entrée)
Nom du nouvel interpréteur enfant à créer ou à manipuler.
int isSafe (entrée)
Si différent de zéro, un enfant "sûr" est créé, adapté à l'exécution de code non fiable, sinon un enfant fiable est créé.
Tcl_Interp *childInterp (entrée)
Interpréteur à utiliser pour créer la commande source d'un alias (voir ci-dessous).
const char *childCmd (entrée)
Nom de la commande source de l'alias.
Tcl_Interp *targetInterp (entrée)
Interpréteur qui contient la commande cible de l'alias.
const char *targetCmd (entrée)
Nom de la commande cible de l'alias dans targetInterp.
int argc (entrée)
Nombre d'arguments supplémentaires à passer à la commande alias.
const char *const *argv (entrée)
Tableau de chaînes de caractères, les arguments supplémentaires à passer à la commande alias. La mémoire est la propriété de l'appelant.
int objc (entrée)
Nombre d'arguments de valeur supplémentaires à passer à la commande alliée.
Tcl_Obj **objv (entrée)
Tableau de structures Tcl_Obj, les arguments de valeur supplémentaires à passer à la commande alliée. La mémoire est la propriété de l'appelant.
Tcl_Interp **targetInterpPtr (sortie)
Pointeur vers l'emplacement où sera stocké l'interpréteur contenant la commande cible de l'alias.
const char **targetCmdPtr (sortie)
Pointeur vers l'emplacement où sera stocké le nom de la commande cible de l'alias.
int *argcPtr (sortie)
Pointeur vers l'emplacement où sera stocké le nombre d'arguments supplémentaires à passer à la commande alias. L'emplacement est dans la mémoire propriété de l'appelant.
const char ***argvPtr (sortie)
Pointeur vers l'emplacement où sera stocké un tableau de chaînes de caractères, les arguments supplémentaires à passer à la commande alias. L'emplacement est dans la mémoire propriété de l'appelant, le tableau de chaînes de caractères est propriété de l'appelant.
int *objcPtr (sortie)
Pointeur vers l'emplacement où sera stocké le nombre d'arguments de valeur supplémentaires à passer à la commande alias. L'emplacement est dans la mémoire propriété de l'appelant.
Tcl_Obj ***objvPtr (sortie)
Pointeur vers l'emplacement où sera stocké un tableau de structures Tcl_Obj, les arguments de valeur supplémentaires à passer à la commande alias. L'emplacement est dans la mémoire propriété de l'appelant, le tableau de structures Tcl_Obj est propriété de l'appelant.
const char *cmdName (entrée)
Nom d'une commande exposée pour la masquer ou la créer.
const char *hiddenCmdName (entrée)
Nom sous lequel une commande cachée est stockée et par lequel elle peut être exposée ou appelée.

DESCRIPTION

Ces fonctions sont pour l'accès à la fonctionnalité de multiples interpréteurs Tcl depuis des programmes C. Elles permettent de gérer plusieurs interpréteurs dans une relation hiérarchique et la gestion d'alias, des commandes qui, lorsqu'elles sont invoquées dans un interpréteur, exécutent une commande dans un autre interpréteur. La valeur de retour des fonctions qui renvoient un entier est soit TCL_OK soit TCL_ERROR. Si TCL_ERROR est retourné, le résultat de l'interpréteur contient un message d'erreur.

Tcl_CreateSlave crée un nouvel interpréteur comme enfant de interp. Il crée également une commande enfant nommée childName dans interp, qui permet à interp de manipuler le nouvel enfant. Si isSafe est zéro, la commande crée un enfant fiable dans lequel le code Tcl a accès à toutes les commandes Tcl. S'il vaut 1, la commande crée un enfant "sûr" dans lequel le code Tcl n'a accès qu'à un ensemble de commandes Tcl définies comme "Safe Tcl" ; voir le manuel de la commande Tcl interp pour plus de détails. Si la création du nouvel interpréteur enfant échoue, NULL est retourné.

Tcl_CreateChild est un synonyme de Tcl_CreateSlave.

Tcl_IsSafe renvoie 1 si interp est "sûr" (a été créé avec le flag TCL_SAFE_INTERPRETER spécifié), 0 sinon.

Tcl_MakeSafe marque interp comme "sûr", de sorte que les futurs appels à Tcl_IsSafe renvoient 1. Il supprime également de interp toute fonctionnalité connue qui pourrait être dangereuse (commandes et variables). Cependant, il ne peut pas savoir quelles parties d'une extension ou d'une application sont sûres et ne tente pas de supprimer ces parties, donc la sécurité n'est pas garantie après un appel à Tcl_MakeSafe. Les utilisateurs doivent faire attention à l'utilisation de Tcl_MakeSafe pour éviter de fausses affirmations de sécurité. Dans de nombreux cas, Tcl_CreateSlave peut être une meilleure option, car il crée des interpréteurs dans un état sûr connu.

Tcl_GetSlave renvoie un pointeur vers un interpréteur enfant de interp. L'interpréteur enfant est identifié par childName. Si aucun interpréteur enfant de ce nom n'existe, NULL est renvoyé.

Tcl_GetChild est un synonyme de Tcl_GetSlave.

Tcl_GetMaster renvoie un pointeur vers l'interpréteur maître de interp. Si interp n'a pas de maître (c'est-à-dire qu'il s'agit d'un interpréteur de niveau supérieur), NULL est renvoyé.

Tcl_GetParent est un synonyme de Tcl_GetMaster.

Tcl_GetInterpPath stocke dans le résultat de interp le chemin relatif entre interp et childInterp; childInterp doit être un enfant de interp. Si le calcul du chemin relatif est effectué avec succès, TCL_OK est retourné, sinon TCL_ERROR est retourné et un message d'erreur est stocké dans le résultat de interp.

Tcl_CreateAlias crée une commande nommée childCmd dans childInterp qui, lorsqu'elle est invoquée, provoquera l'invocation de la commande targetCmd dans targetInterp. Les arguments spécifiés par les chaînes de caractères dans argv sont toujours ajoutés à l'argument d'invocation de childCmd et passés à targetCmd. Cette procédure renvoie TCL_OK si elle réussit, sinon elle renvoie TCL_ERROR et un message d'erreur est laissé dans la valeur du résultat de childInterp. Remarque : il n'y a aucune restriction sur la relation d'ancêtre (créée par Tcl_CreateSlave) entre childInterp et targetInterp. Deux interpréteurs quelconques peuvent être utilisés sans restriction sur la manière dont ils sont liés.

Tcl_CreateAliasObj est similaire à Tcl_CreateAlias sauf qu'elle prend un tableau de valeurs à passer comme arguments supplémentaires au lieu d'un tableau de chaînes de caractères.

Tcl_GetAliasObj renvoie des informations sous forme de pointeur vers un tableau de structures Tcl_Obj sur un alias aliasName dans interp. Tout champ de résultat peut être NULL, auquel cas les données correspondantes ne sont pas retournées. Si un champ de résultat n'est pas NULL, le pointeur indiqué est défini sur les données correspondantes. Par exemple, si targetCmdPtr n'est pas NULL, il est défini sur un pointeur vers le nom de la commande cible.

Tcl_GetAlias est similaire à Tcl_GetAliasObj sauf qu'elle renvoie un pointeur vers un tableau de chaînes de caractères au lieu d'un tableau de structures Tcl_Obj. Tcl_GetAlias est obsolète

NOM

TCL_ExposeCommand

 SYNTAXIS

Tcl_ExposeCommand

 ARGUMENTS

hiddenCmdName

 DESCRIPTION

Tcl_ExposeCommand déplace la commande nommée hiddenCmdName de l'ensemble des commandes cachées vers l'ensemble des commandes exposées, en la plaçant sous le nom cmdName. HiddenCmdName doit être le nom d'une commande existante, ou l'opération retournera TCL_ERROR et laissera un message d'erreur dans le résultat de interp. Si une commande exposée portant le nom cmdName existe déjà, l'opération retournera TCL_ERROR et laissera un message d'erreur dans le résultat de interp. Si l'opération réussit, elle retournera TCL_OK. Après l'exécution de cette commande, les tentatives d'utilisation de cmdName dans tout mécanisme d'évaluation de script réussiront.
