Tcl_SplitList(3) Procédures de la bibliothèque Tcl Tcl_SplitList(3)

NAME

Tcl_SplitList, Tcl_Merge, Tcl_ScanElement, Tcl_ConvertElement, Tcl_ScanCountedElement, Tcl_ConvertCountedElement - manipuler des listes Tcl

SYNOPSIS

#include <tcl.h>

int
Tcl_SplitList(interp, list, argcPtr, argvPtr)

char *
Tcl_Merge(argc, argv)

int
Tcl_ScanElement(src, flagsPtr)

int
Tcl_ScanCountedElement(src, length, flagsPtr)

int
Tcl_ConvertElement(src, dst, flags)

int
Tcl_ConvertCountedElement(src, length, dst, flags)

ARGUMENTS

Tcl_Interp *interp (out)
Interpréteur à utiliser pour le signalement des erreurs. Si NULL, aucun message d'erreur n'est généré.
const char *list (in)
Pointeur vers une chaîne de caractères ayant une structure de liste valide.
int *argcPtr (out)
Valeur remplie avec le nombre d'éléments dans list.
const char ***argvPtr (out)
*argvPtr sera rempli avec le pointeur vers un tableau de pointeurs vers les chaînes de caractères qui sont les éléments extraits de list. Il y aura *argcPtr entrées valides dans le tableau, suivies d'une entrée NULL.
int argc (in)
Nombre d'éléments dans argv.
const char *const *argv (in)
Tableau de chaînes de caractères à fusionner pour former une liste. Chaque chaîne deviendra un élément de la liste.
const char *src (in)
Chaîne de caractères à convertir en élément de liste.
int *flagsPtr (in)
Pointeur vers un entier qui sera rempli avec des informations sur src. La valeur de flagsPtr doit être passée à Tcl_ConvertElement.
int length (in)
Nombre d'octets dans la chaîne src.
char *dst (in)
Emplacement où la chaîne élément de liste convertie est copiée. Doit contenir suffisamment de caractères pour stocker la chaîne convertie.
int flags (in)
Informations sur src. Doit être la valeur retournée par un appel précédent à Tcl_ScanElement, éventuellement combinée avec TCL_DONT_USE_BRACES.

DESCRIPTION

Ces procédures peuvent être utilisées pour démonter et assembler des listes Tcl. Tcl_SplitList divise une liste en ses éléments constitutifs, retournant un tableau de pointeurs vers les éléments via argcPtr et argvPtr. Lors de l'extraction des arguments, Tcl_SplitList suit les règles habituelles de substitution des backslash et des accolades. La zone mémoire pointée par *argvPtr est réservée dynamiquement ; en plus d'un tableau de pointeurs, elle contient également des copies de tous les éléments de la liste. Il est de la responsabilité de l'appelant de libérer cet espace. Par exemple, si Tcl_SplitList a été appelée avec le code suivant :

int argc, code;
char *string;
char **argv;
...
code = Tcl_SplitList(interp, string, &argc, &argv);

L'espace doit alors être libéré par un appel tel que :

Tcl_Free((char *) argv);

Tcl_SplitList retourne normalement TCL_OK, ce qui signifie que la liste a été correctement analysée. S'il y a une erreur de syntaxe dans list, alors TCL_ERROR est retourné et le résultat de l'interpréteur pointera vers un message d'erreur (si interp n'est pas NULL). Si TCL_ERROR est retourné, aucune mémoire n'est allouée et *argvPtr n'est pas modifié.

Tcl_Merge est l'inverse de Tcl_SplitList : il prend un ensemble de chaînes donné par argc et argv et génère une chaîne résultante avec une structure de liste valide. Cela signifie que des commandes comme index peuvent être utilisées pour extraire à nouveau les éléments d'origine. De plus, si le résultat de Tcl_Merge est passé à Tcl_Eval, il sera analysé en argc mots dont les valeurs seront les mêmes que celles des chaînes argv passées à Tcl_Merge. Tcl_Merge modifie les éléments de liste avec des accolades et/ou des backslash pour produire une structure de liste valide. La chaîne résultante est réservée dynamiquement en utilisant Tcl_Alloc ; l'appelant doit libérer l'espace avec Tcl_Free.

Si le résultat de Tcl_Merge est passé à Tcl_SplitList, les éléments retournés par Tcl_SplitList seront identiques aux chaînes passées à Tcl_Merge. Cependant, l'inverse n'est pas vrai : si Tcl_SplitList est passé une chaîne donnée, et que les résultats de Tcl_SplitList sont passés à Tcl_Merge, le résultat peut ne pas être le même que la chaîne d'origine passée à Tcl_SplitList. Ceci est dû au fait que Tcl_Merge peut utiliser les backslash et les accolades différemment de la chaîne d'origine.

Tcl_ScanElement et Tcl_ConvertElement sont les procédures qui effectuent le travail réel de Tcl_Merge. Tcl_ScanElement analyse son argument src et détermine comment utiliser les backslash et les accolades lors de sa conversion en élément de liste. Il retourne le nombre supplémentaire de caractères nécessaires pour représenter src en tant qu'élément de liste, et stocke des informations dans *flagsPtr qui sont nécessaires pour Tcl_ConvertElement.

Tcl_ConvertElement est une procédure associée à Tcl_ScanElement. Elle effectue le travail de conversion d'une chaîne en un élément de liste. Son argument flags doit être la même valeur que celle retournée par Tcl_ScanElement. Tcl_ConvertElement écrit un élément de liste valide dans la mémoire à partir de *dst et retourne le nombre total de caractères écrits, qui ne sera pas supérieur au résultat retourné par Tcl_ScanElement. Tcl_ConvertElement n'écrit que l'élément de liste réel sans espaces au début ou à la fin, et c'est à l'appelant d'inclure des espaces entre les éléments de liste adjacents.

Tcl_ConvertElement utilise l'une des deux approches différentes pour gérer les caractères spéciaux dans src. Si possible, elle les gère en entourant la chaîne d'accolades. Cela produit une sortie propre, mais ne peut pas être utilisé dans certains cas, comme lorsque src contient des accolades non appariées. Dans ces cas, Tcl_ConvertElement gère les caractères spéciaux en générant des séquences de backslash. L'appelant peut insister sur la deuxième approche en combinant avec la valeur de Tcl_ScanElement et TCL_DONT_USE_BRACES. Bien que cela produise un résultat moins soigné, c'est utile dans certains cas spéciaux, comme lorsque Tcl_ConvertElement est utilisé pour générer une partie d'un argument pour une commande Tcl. Dans ce cas, entourer src d'accolades ferait que la commande ne serait pas correctement analysée.

Par défaut, Tcl_ConvertElement utilise la détection d'espaces blancs pour s'assurer que le premier caractère d'un élément n'est pas le caractère dièse ('#'). Ceci afin de s'assurer que le premier élément de toute liste passée à eval ne soit pas mal interprété comme le début d'un commentaire. Lorsque l'élément n'est pas le premier élément d'une liste, cette détection d'espaces blancs n'est pas nécessaire. Lorsque l'appelant peut garantir que l'élément n'est pas le premier élément d'une liste, il peut désactiver la détection d'espaces blancs pour le caractère dièse en combinant avec la valeur de Tcl_ScanElement et TCL_DONT_QUOTE_HASH.

Tcl_ScanCountedElement et Tcl_ConvertCountedElement sont identiques à Tcl_ScanElement et Tcl_ConvertElement, sauf que la longueur de la chaîne src est spécifiée par l'argument length, et la chaîne peut contenir des caractères nuls incorporés.
