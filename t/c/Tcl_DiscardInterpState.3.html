Tcl_SaveResult(3) Procédures de bibliothèque Tcl Tcl_SaveResult(3)

NOM

Tcl_SaveInterpState, Tcl_RestoreInterpState, Tcl_DiscardInterpState, Tcl_SaveResult, Tcl_RestoreResult, Tcl_DiscardResult - sauvegarder et restaurer l'état d'un interpréteur

SYNOPSIS

#include <tcl.h>

Tcl_InterpState
Tcl_SaveInterpState(interp, status)

int
Tcl_RestoreInterpState(interp, state)

Tcl_DiscardInterpState(state)

Tcl_SaveResult(interp, savedPtr)

Tcl_RestoreResult(interp, savedPtr)

Tcl_DiscardResult(savedPtr)

ARGUMENTS

Tcl_Interp *interp (in)
Interpréteur dont l'état doit être sauvegardé.
int status (in)
Valeur du code de retour à sauvegarder dans le cadre de l'état de l'interpréteur.
Tcl_InterpState state (in)
Jeton d'état sauvegardé à restaurer ou à ignorer.
Tcl_SavedResult *savedPtr (in)
Pointeur vers l'emplacement où le résultat de l'interpréteur doit être sauvegardé ou restauré.

DESCRIPTION

Ces routines permettent à une procédure C de prendre un instantané de l'état actuel d'un interpréteur afin qu'il puisse être restauré après un appel à Tcl_Eval ou à une autre routine qui modifie l'état de l'interpréteur. Il existe deux triplets de routines destinées à fonctionner ensemble.

Le premier triplet stocke l'instantané de l'état de l'interpréteur dans un token opaque retourné par Tcl_SaveInterpState. La valeur de ce token peut ensuite être renvoyée à l'une des routines Tcl_RestoreInterpState ou Tcl_DiscardInterpState, selon que l'état de l'interpréteur doit être restauré ou non. Tant que l'une des deux dernières routines est appelée, Tcl prendra en charge la gestion de la mémoire.

Le second triplet stocke un instantané du seul résultat de l'interpréteur (pas son état complet) dans la mémoire allouée par l'appelant. Ces routines reçoivent un pointeur vers Tcl_SavedResult qui est utilisé pour stocker suffisamment d'informations pour restaurer le résultat de l'interpréteur. Tcl_SavedResult peut être alloué sur la pile de la procédure appelante. Ces routines ne sauvegardent pas l'état des informations d'erreur dans l'interpréteur (par exemple, les options de retour -errorcode ou -errorinfo, lorsqu'une erreur est en cours).

Étant donné que les routines Tcl_SaveInterpState, Tcl_RestoreInterpState et Tcl_DiscardInterpState effectuent un superset des fonctions fournies par les autres routines, tout nouveau code ne devrait utiliser que les routines les plus puissantes. Les routines plus anciennes et moins puissantes, Tcl_SaveResult, Tcl_RestoreResult et Tcl_DiscardResult, continuent d'exister uniquement pour le bénéfice des programmes existants qui les utilisent déjà.

Tcl_SaveInterpState prend un instantané des parties de l'état de l'interpréteur qui constituent le résultat complet de l'évaluation du script. Cela inclut le résultat de l'interpréteur, le code de retour (passé comme argument status, et toutes les options de retour, y compris -errorinfo et -errorcode lorsqu'une erreur est en cours. Cet instantané est retourné sous forme de token opaque de type Tcl_InterpState. L'appel à Tcl_SaveInterpState ne modifie pas lui-même l'état de l'interpréteur. Contrairement à Tcl_SaveResult, il ne réinitialise pas l'interpréteur.

Tcl_RestoreInterpState accepte un token Tcl_InterpState précédemment retourné par Tcl_SaveInterpState et restaure l'état de l'interpréteur à l'état détenu dans cet instantané. La valeur de retour de Tcl_RestoreInterpState est la valeur de statut initialement passée à Tcl_SaveInterpState lors de la création du token d'instantané.

Tcl_DiscardInterpState est appelé pour libérer un token Tcl_InterpState précédemment retourné par Tcl_SaveInterpState lorsque cet instantané ne doit pas être restauré dans un interpréteur.

Le token Tcl_InterpState retourné par Tcl_SaveInterpState doit éventuellement être passé soit à Tcl_RestoreInterpState, soit à Tcl_DiscardInterpState pour éviter une fuite de mémoire. Une fois que le token Tcl_InterpState est passé à l'une d'elles, le token n'est plus valide et ne doit plus être utilisé.

Tcl_SaveResult déplace les résultats de type chaîne et valeur de interp vers l'emplacement spécifié par statePtr. Tcl_SaveResult efface le résultat pour interp et laisse le résultat dans son état initialisé vide normal.

Tcl_RestoreResult déplace les résultats de type chaîne et valeur de statePtr vers interp. Tout résultat ou erreur déjà présent dans l'interpréteur sera effacé. Le statePtr est laissé dans un état non initialisé et ne peut pas être utilisé avant un autre appel à Tcl_SaveResult.

Tcl_DiscardResult libère l'état sauvegardé de l'interpréteur stocké à statePtr. La structure d'état est laissée dans un état non initialisé et ne peut pas être utilisée avant un autre appel à Tcl_SaveResult.

Une fois que Tcl_SaveResult est appelé pour sauvegarder le résultat de l'interpréteur, soit Tcl_RestoreResult, soit Tcl_DiscardResult doit être appelé pour nettoyer correctement la mémoire associée à l'état sauvegardé.
