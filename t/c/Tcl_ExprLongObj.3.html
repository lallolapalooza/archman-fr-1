Paquet: tcl

Tcl_ExprLongObj(3) Procédures de bibliothèque Tcl Tcl_ExprLongObj(3)

NOM

Tcl_ExprLongObj, Tcl_ExprDoubleObj, Tcl_ExprBooleanObj, Tcl_ExprObj - évaluer une expression

SYNOPIS

#include <tcl.h>

int
Tcl_ExprLongObj(interp, objPtr, longPtr)

int
Tcl_ExprDoubleObj(interp, objPtr, doublePtr)

int
Tcl_ExprBooleanObj(interp, objPtr, booleanPtr)

int
Tcl_ExprObj(interp, objPtr, resultPtrPtr)

ARGUMENTS

Tcl_Interp *interp (entrée)
Interpréteur dans le contexte duquel évaluer objPtr.
Tcl_Obj *objPtr (entrée)
Pointeur vers une valeur contenant l'expression à évaluer.
long *longPtr (sortie)
Pointeur vers l'emplacement où stocker la valeur entière de l'expression.
int *doublePtr (sortie)
Pointeur vers l'emplacement où stocker la valeur en virgule flottante de l'expression.
int *booleanPtr (sortie)
Pointeur vers l'emplacement où stocker la valeur booléenne 0/1 de l'expression.
Tcl_Obj **resultPtrPtr (sortie)
Pointeur vers l'emplacement où stocker un pointeur vers la valeur qui est le résultat de l'expression.

DESCRIPTION

Ces quatre procédures évaluent toutes une expression, renvoyant le résultat sous l'une des quatre formes différentes. L'expression est fournie par l'argument objPtr, et elle peut avoir l'une des formes acceptées par la commande expr.

L'argument interp fait référence à un interpréteur utilisé pour évaluer l'expression (par exemple, pour les variables et les commandes Tcl imbriquées) et pour renvoyer les informations d'erreur.

Pour toutes ces procédures, la valeur de retour est un résultat Tcl standard : TCL_OK signifie que l'expression a été évaluée avec succès, et TCL_ERROR signifie qu'une erreur s'est produite lors de l'évaluation de l'expression. Si TCL_ERROR est renvoyé, un message décrivant l'erreur peut être récupéré en utilisant Tcl_GetObjResult. Si une erreur se produit lors de l'exécution d'une commande Tcl intégrée à l'expression, cette erreur sera renvoyée.

Si l'expression est évaluée avec succès, sa valeur est renvoyée sous l'une des quatre formes, en fonction de la procédure invoquée. Tcl_ExprLongObj stocke une valeur entière à *longPtr. Si la valeur réelle de l'expression est un nombre à virgule flottante, elle est tronquée en un entier. Si la valeur réelle de l'expression est une chaîne non numérique, une erreur est renvoyée.

Tcl_ExprDoubleObj stocke une valeur en virgule flottante à *doublePtr. Si la valeur réelle de l'expression est un entier, elle est convertie en virgule flottante. Si la valeur réelle de l'expression est une chaîne non numérique, une erreur est renvoyée.

Tcl_ExprBooleanObj stocke une valeur entière 0/1 à *booleanPtr. Si la valeur réelle de l'expression est un entier ou un nombre à virgule flottante, alors elles stockent 0 à *booleanPtr si la valeur était zéro et 1 sinon. Si la valeur réelle de l'expression est une chaîne non numérique, elle doit être l'une des valeurs acceptées par Tcl_GetBoolean, telle que « yes » ou « no », sinon une erreur se produit.

Si Tcl_ExprObj évalue avec succès l'expression, elle stocke un pointeur vers la valeur Tcl contenant la valeur de l'expression à *resultPtrPtr. Dans ce cas, l'appelant est responsable d'appeler Tcl_DecrRefCount pour décrémenter le compteur de références de la valeur lorsqu'il a fini avec la valeur.
