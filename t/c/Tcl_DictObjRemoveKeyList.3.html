Tcl_DictObj(3) Procédures de la bibliothèque Tcl Tcl_DictObj(3)

NAME

Tcl_NewDictObj, Tcl_DictObjGet, Tcl_DictObjPut, Tcl_DictObjRemove, Tcl_DictObjSize, Tcl_DictObjFirst, Tcl_DictObjNext, Tcl_DictObjDone, Tcl_DictObjPutKeyList, Tcl_DictObjRemoveKeyList - manipuler des valeurs Tcl comme des dictionnaires

#include <tcl.h>

Tcl_Obj *
Tcl_NewDictObj()

int
Tcl_DictObjGet(interp, dictPtr, keyPtr, valuePtrPtr)

int
Tcl_DictObjPut(interp, dictPtr, keyPtr, valuePtr)

int
Tcl_DictObjRemove(interp, dictPtr, keyPtr)

int
Tcl_DictObjSize(interp, dictPtr, sizePtr)

int
Tcl_DictObjFirst(interp, dictPtr, searchPtr,
                 keyPtrPtr, valuePtrPtr, donePtr)

void
Tcl_DictObjNext(searchPtr, keyPtrPtr, valuePtrPtr, donePtr)

void
Tcl_DictObjDone(searchPtr)

int
Tcl_DictObjPutKeyList(interp, dictPtr, keyc, keyv, valuePtr)

int
Tcl_DictObjRemoveKeyList(interp, dictPtr, keyc, keyv)

ARGUMENTS

Tcl_Interp *interp (in)
En cas d'erreur lors de la conversion d'une valeur en une valeur de dictionnaire, un message d'erreur est laissé dans la valeur de résultat de l'interpréteur, pas si interp est NULL.
Tcl_Obj *dictPtr (in/out)
Pointe vers la valeur de dictionnaire à manipuler. Si dictPtr ne pointe pas déjà vers une valeur de dictionnaire, une tentative sera faite pour la convertir.
Tcl_Obj *keyPtr (in)
Pointe vers la clé pour la paire clé/valeur à manipuler dans la valeur de dictionnaire.
Tcl_Obj **keyPtrPtr (out)
Pointe vers une variable qui contiendra la clé d'une paire clé/valeur. Peut être NULL pour indiquer que l'appelant n'est pas intéressé par la clé.
Tcl_Obj *valuePtr (in)
Pointe vers la valeur de la paire clé/valeur à manipuler dans la valeur de dictionnaire (ou sous-valeur dans le cas de Tcl_DictObjPutKeyList).
Tcl_Obj **valuePtrPtr (out)
Pointe vers une variable qui contiendra la valeur d'une paire clé/valeur. Pour Tcl_DictObjFirst et Tcl_DictObjNext, peut être NULL pour indiquer que l'appelant n'est pas intéressé par la valeur.
int *sizePtr (out)
Pointe vers une variable qui contiendra le nombre de paires clé/valeur dans le dictionnaire.
Tcl_DictSearch *searchPtr (in/out)
Pointe vers le contexte utilisé pour suivre l'itération de toutes les paires clé/valeur dans un dictionnaire. Le contenu du contexte est initialisé par un appel à Tcl_DictObjFirst. Si l'itération doit se terminer avant que toutes les valeurs du dictionnaire aient été retournées, le contexte de recherche doit être passé à Tcl_DictObjDone pour libérer les verrous internes.
int *donePtr (out)
Pointe vers une variable qui contiendra une valeur non nulle lorsque l'itération des paires clé/valeur du dictionnaire est terminée, et zéro dans le cas contraire.
int keyc (in)
Indique le nombre de clés à fournir dans le tableau keyv.
Tcl_Obj *const *keyv (in)
Tableau de keyc pointeurs vers des valeurs que Tcl_DictObjPutKeyList et Tcl_DictObjRemoveKeyList utiliseront pour localiser la paire clé/valeur à manipuler dans les sous-dictionnaires de la valeur principale du dictionnaire.

DESCRIPTION

Les valeurs de dictionnaire Tcl ont une représentation interne qui prend en charge un mappage efficace des clés aux valeurs et garantit que l'ordre des clés dans le dictionnaire reste le même, même si des entrées sont supprimées ou ajoutées (ce qui les déplace dans l'ordre).

Les procédures décrites dans cette page de manuel sont utilisées pour créer, modifier, indexer et itérer sur des valeurs de dictionnaire à partir de code C.

Tcl_NewDictObj crée une nouvelle valeur de dictionnaire vide. La représentation en chaîne de caractères de la valeur sera invalide et le compteur de références de la valeur sera de zéro.

Tcl_DictObjGet recherche la clé donnée dans le dictionnaire et écrit un pointeur vers la valeur associée à cette clé dans la variable indiquée par valuePtrPtr, ou NULL s'il n'y a pas de mappage pour cette clé. Le résultat de cette opération sera TCL_OK, ou TCL_ERROR si dictPtr ne peut pas être converti en un dictionnaire.

Tcl_DictObjPut met à jour le dictionnaire de sorte que la clé donnée mappe à la valeur donnée ; chaque clé ne peut exister qu'une seule fois dans un dictionnaire. Le dictionnaire ne doit pas être partagé, mais les clés et les valeurs peuvent l'être. Cette opération peut incrémenter le compteur de références des clés et des valeurs si elles doivent être stockées. Ni la clé ni la valeur ne doivent être NULL. Le résultat de cette opération sera TCL_OK, ou TCL_ERROR si dictPtr ne peut pas être converti en un dictionnaire.

Tcl_DictObjRemove met à jour le dictionnaire de sorte que la clé donnée ne mappe plus à aucune valeur. Le dictionnaire ne doit pas être partagé, mais la clé peut l'être. La clé stockée dans le dictionnaire verra son compteur de références décrémenté s'il existait précédemment. Ce n'est pas une erreur si la clé n'existait pas auparavant. Le résultat de cette opération sera TCL_OK, ou TCL_ERROR si dictPtr ne peut pas être converti en un dictionnaire.

Tcl_DictObjSize met à jour la variable indiquée avec le nombre de paires clé/valeur actuellement dans le dictionnaire. Le résultat de cette opération sera TCL_OK, ou TCL_ERROR si dictPtr ne peut pas être converti en un dictionnaire.

Tcl_DictObjFirst commence l'itération sur toutes les paires clé/valeur dans le dictionnaire, plaçant la clé et la valeur dans les variables indiquées par keyPtrPtr et valuePtrPtr (qui peuvent être NULL pour indiquer que l'appelant n'est pas intéressé par la clé ou la valeur respectivement). La paire clé/valeur suivante dans le dictionnaire peut être obtenue avec Tcl_DictObjNext. Les mises à jour concurrentes de la représentation interne du dictionnaire ne modifieront pas la progression de l'itération, sauf si le dictionnaire n'est pas partagé, auquel cas l'itération se terminera prématurément (ce qui ne peut pas être provoqué par la commande dict dans les scripts Tcl). L'argument searchPtr pointe vers un contexte qui est utilisé pour identifier quelle itération spécifique est en cours, et est initialisé par un appel à Tcl_DictObjFirst. L'argument donePtr pointe vers une variable qui est mise à jour à zéro s'il reste des paires clé/valeur à itérer, ou à une valeur non nulle si l'itération est terminée. L'ordre d'itération est implicitement défini. Si dictPtr ne peut pas être converti en un dictionnaire, Tcl_DictObjFirst renvoie TCL_ERROR et l'itération ne commencera pas, sinon il renvoie TCL_OK.

Lorsque Tcl_DictObjFirst est appelé sur un dictionnaire, un verrou est placé sur le dictionnaire pour permettre l'itération sécurisée sur les clés du dictionnaire, que le dictionnaire soit modifié pendant l'itération ou non. Pour cette raison, une fois que l'itération sur les clés d'un dictionnaire est terminée (soit parce que le nombre de valeurs itérées est complet, indiqué par l'argument donePtr réglé sur 1, soit parce qu'aucune valeur supplémentaire n'est requise), il est impératif d'appeler Tcl_DictObjDone avec le même searchPtr qui a été utilisé pour Tcl_DictObjFirst afin de libérer les verrous internes. Une fois qu'un searchPtr spécifique est passé à Tcl_DictObjDone, le passer à Tcl_DictObjNext (sans l'avoir initialisé avec Tcl_DictObjFirst) produira aucune valeur et la variable indiquée par donePtr sera réglée sur 1. Il est sûr d'appeler Tcl_DictObjDone plusieurs fois sur le même searchPtr pour chaque appel à Tcl_DictObjFirst.

Les procédures Tcl_DictObjPutKeyList et Tcl_DictObjRemoveKeyList sont les analogues fermés de Tcl_DictObjPut et Tcl_DictObjRemove, sauf qu'elles travaillent avec des arbres de dictionnaires imbriqués, avec des dictionnaires internes stockés comme valeurs dans des dictionnaires externes. Les arguments keyc et keyv spécifient une liste de clés (avec les clés externes en premier) qui agissent comme un chemin vers la paire clé/valeur à modifier. Notez qu'il n'existe pas d'opération correspondante pour lire une valeur.

NOM

Tcl_DictObjRemoveKeyList

SYNOPIS

Utilisez Tcl_DictObjRemoveKeyList pour supprimer des clés non finales.

ARGUMENTS

interp, objPtr, search, key, value, done

DESCRIPTION

Avec Tcl_DictObjRemoveKeyList, les dictionnaires imbriqués sont créés pour les clés non finales où elles n'existent pas encore. Avec Tcl_DictObjPutKeyList, les dictionnaires imbriqués sont créés pour les clés non finales où elles n'existent pas encore. Avec Tcl_DictObjGet, un chemin peut être facilement construit à partir de l'utilisation répétée de Tcl_DictObjGet.

EXEMPLE

Utilisation de l'interface d'itération de dictionnaire pour vérifier si une clé existe qui correspond à elle-même :

Tcl_DictSearch search;
    Tcl_Obj *key, *value;
    int done;
    /*
     * Supposons que interp et objPtr sont des paramètres. Ceci est le mode idiomatique pour commencer une itération sur le dictionnaire ; il établit un verrou sur la représentation interne qui garantit qu'il n'y aura pas de problèmes de modification concurrente lors de l'utilisation d'une gestion de référence par compte normal. Le verrou est automatiquement libéré lorsque l'itération est terminée, mais il doit être libéré manuellement lorsque l'on quitte la boucle de manière exceptionnelle. Il est cependant sûr de tenter de libérer le verrou même si nous avons terminé l'itération sur la boucle.
     */
    if (Tcl_DictObjFirst(interp, objPtr, &search,
            &key, &value, &done) != TCL_OK) {
        return TCL_ERROR;
    }
    for (; !done ; Tcl_DictObjNext(&search, &key, &value, &done)) {
        /*
         * Remarque : strcmp() n'est pas une bonne façon de comparer des valeurs et n'est utilisé ici qu'à des fins d'illustration.
         */
        if (!strcmp(Tcl_GetString(key), Tcl_GetString(value))) {
            break;
        }
    }
    Tcl_DictObjDone(&search);
    Tcl_SetObjResult(interp, Tcl_NewBooleanObj(!done));
    return TCL_OK;
