Tcl_UpVar(3) Procédures de bibliothèque Tcl Tcl_UpVar(3)

NOM

Tcl_UpVar, Tcl_UpVar2 - Lier une variable à une autre

SYNOPIS

#include <tcl.h>

int
Tcl_UpVar(interp, frameName, sourceName, destName, flags)

int
Tcl_UpVar2(interp, frameName, name1, name2, destName, flags)

ARGUMENTS

Tcl_Interp *interp (in)
Interpréteur contenant les variables ; également utilisé pour le signalement d'erreurs.
const char *frameName (in)
Identifie la pile d'appels contenant la variable source. Peut avoir l'une des formes acceptées par la commande upvar, telles que #0 ou 1.
const char *sourceName (in)
Nom de la variable source, dans la pile d'appels spécifiée par frameName. Peut faire référence à une variable scalaire ou à une variable tableau avec un indice entre parenthèses.
const char *destName (in)
Nom de la variable destination, qui doit être liée à la variable source afin que les références à destName pointent vers l'autre variable. Ne doit pas exister actuellement, sauf en tant que variable liée via upvar.
int flags (in)
L'une des valeurs TCL_GLOBAL_ONLY, TCL_NAMESPACE_ONLY ou 0 ; si non nul, alors destName est une variable globale ou de namespace ; sinon, elle est locale à la procédure courante (ou au namespace courant si aucune procédure n'est active).
const char *name1 (in)
Première partie du nom de la variable source (nom scalaire, ou nom de tableau sans l'indice du tableau).
const char *name2 (in)
Si la variable source est un élément d'un tableau, donne l'indice de l'élément. Pour les variables sources scalaires, est NULL.

DESCRIPTION

Tcl_UpVar et Tcl_UpVar2 fournissent la même fonctionnalité que la commande upvar : elles créent un lien d'une variable source vers une variable destination, de sorte que les références à la destination soient transmises de manière transparente à la source. Le nom de la variable source peut être spécifié soit sous forme d'une chaîne unique telle que xyx ou a(24) (en appelant Tcl_UpVar), soit en deux parties où le nom du tableau a été séparé du nom de l'élément (en appelant Tcl_UpVar2). Le nom de la variable destination est spécifié sous forme d'une chaîne unique ; il ne peut pas s'agir d'un élément de tableau.

Les deux procédures retournent soit TCL_OK, soit TCL_ERROR, et elles laissent un message d'erreur dans le résultat de l'interpréteur en cas d'erreur.

Comme avec la commande upvar, la variable source n'a pas besoin d'exister ; si elle existe, la désaffecter plus tard ne détruit pas le lien. La variable destination peut exister au moment de l'appel, mais si c'est le cas, elle doit exister en tant que variable liée.
