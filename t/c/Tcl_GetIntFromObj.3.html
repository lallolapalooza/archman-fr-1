Tcl_GetIntFromObj(3)

Tcl_IntObj(3) Procédures de la bibliothèque Tcl Tcl_IntObj(3)

NAME

Tcl_NewIntObj, Tcl_NewLongObj, Tcl_NewWideIntObj, Tcl_SetIntObj, Tcl_SetLongObj, Tcl_SetWideIntObj, Tcl_GetIntFromObj, Tcl_GetLongFromObj, Tcl_GetWideIntFromObj, Tcl_NewBignumObj, Tcl_SetBignumObj, Tcl_GetBignumFromObj, Tcl_TakeBignumFromObj - manipuler les valeurs Tcl comme des entiers

SYNOPSIS

#include <tcl.h>

                            Tcl_Obj *
                            Tcl_NewIntObj(intValue)

                            Tcl_Obj *
                            Tcl_NewLongObj(longValue)

                            Tcl_Obj *
                            Tcl_NewWideIntObj(wideValue)

                            Tcl_Obj *
                            Tcl_SetIntObj(objPtr, intValue)

                            Tcl_Obj *
                            Tcl_SetLongObj(objPtr, longValue)

                            Tcl_Obj *
                            Tcl_SetWideIntObj(objPtr, wideValue)

                            int
                            Tcl_GetIntFromObj(interp, objPtr, intPtr)

                            int
                            Tcl_GetLongFromObj(interp, objPtr, longPtr)

                            int
                            Tcl_GetWideIntFromObj(interp, objPtr, widePtr)


                            #include <tclTomMath.h>

                            Tcl_Obj *
                            Tcl_NewBignumObj(bigValue)

                            Tcl_Obj *
                            Tcl_SetBignumObj(objPtr, bigValue)

                            int
                            Tcl_GetBignumFromObj(interp, objPtr, bigValue)

                            int
                            Tcl_TakeBignumFromObj(interp, objPtr, bigValue)

                            int
                            Tcl_InitBignumFromDouble(interp, doubleValue, bigValue)

ARGUMENTS

int intValue (in)
La valeur entière utilisée pour initialiser ou définir une valeur Tcl.
long longValue (in)
La valeur entière longue utilisée pour initialiser ou définir une valeur Tcl.
Tcl_WideInt wideValue (in)
La valeur entière large utilisée pour initialiser ou définir une valeur Tcl.
Tcl_Obj *objPtr (in/out)
Pour Tcl_SetIntObj, Tcl_SetLongObj, Tcl_SetWideIntObj et Tcl_SetBignumObj, ceci pointe vers la valeur dans laquelle une valeur entière est stockée. Pour Tcl_GetIntFromObj, Tcl_GetLongFromObj, Tcl_GetWideIntFromObj, Tcl_GetBignumFromObj et Tcl_TakeBignumFromObj, ceci fait référence à la valeur à partir de laquelle une valeur entière est obtenue.
Tcl_Interp *interp (in/out)
Lorsqu'il n'est pas nul, un message d'erreur y est laissé lorsque la récupération d'une valeur entière échoue.
int *intPtr (out)
Stocke la valeur entière obtenue à partir de objPtr.
long *longPtr (out)
Stocke la valeur entière longue obtenue à partir de objPtr.
Tcl_WideInt *widePtr (out)
Stocke la valeur entière large obtenue à partir de objPtr.
mp_int *bigValue (in/out)
Pointe vers une structure d'entier multi-précision déclarée par la bibliothèque LibTomMath.
double doubleValue (in)
La valeur double à partir de laquelle la partie entière est déterminée et utilisée pour initialiser une valeur entière multi-précision. La partie entière de la valeur double doit être utilisée pour initialiser l'entier multi-précision.

DESCRIPTION

Ces fonctions sont utilisées pour créer, modifier et lire des valeurs Tcl contenant des valeurs entières.

Différentes routines existent pour s'adapter aux différents types d'entiers C avec lesquels des valeurs peuvent être échangées. Les routines d'échange de valeurs pour les types d'entiers C sont int, long int, Tcl_WideInt et mp_int. Les types int et long int sont fournis par la norme du langage C. Le type Tcl_WideInt est un typedef qui correspond à tout type d'entier signé couvrant au moins la plage d'entiers de 64 bits (-9223372036854775808 à 9223372036854775807). Selon le système d'exploitation et le compilateur C, le type réel peut être long int, long long int, __int64 ou quelque chose de similaire. Le type mp_int est un type d'entier multi-précision défini par la bibliothèque multi-précision LibTomMath.

Les routines Tcl_NewIntObj, Tcl_NewLongObj, Tcl_NewWideIntObj et Tcl_NewBignumObj créent et renvoient chacune une valeur Tcl initialisée à partir de la valeur entière de l'argument. La valeur renvoyée n'est pas partagée.

Les routines Tcl_SetIntObj, Tcl_SetLongObj, Tcl_SetWideIntObj et Tcl_SetBignumObj définissent chacune la valeur d'une valeur Tcl existante pointée par objPtr à la valeur entière fournie par l'autre argument. L'argument objPtr doit pointer vers une valeur Tcl non partagée. Toute tentative de définir la valeur d'une valeur partagée viole la politique de copie en écriture de Tcl. Toute représentation interne ou chaîne externe dans la valeur non partagée sera libérée lors de la définition de la nouvelle valeur.

Les routines Tcl_GetIntFromObj, Tcl_GetLongFromObj, Tcl_GetWideIntFromObj, Tcl_GetBignumFromObj et Tcl_TakeBignumFromObj tentent de récupérer une valeur entière à partir de la représentation Tcl objPtr du type approprié. Si la tentative réussit, TCL_OK est renvoyé et la valeur est écrite dans le stockage fourni par l'appelant. La tentative peut échouer si objPtr ne contient pas une valeur entière ou si la valeur dépasse la plage du type cible. Si la tentative échoue, TCL_ERROR est renvoyé et si interp n'est pas nul, un message d'erreur y est laissé. Le type Tcl_ObjType de objPtr peut être changé pour rendre les appels suivants à la même routine plus efficaces. Bien que d'autres fonctions, Tcl_TakeBignumFromObj puisse définir le contenu de la valeur Tcl objPtr en une chaîne vide pendant le processus de récupération de la valeur entière multi-précision.

Le choix entre Tcl_GetBignumFromObj et Tcl_TakeBignumFromObj est régi par la manière dont l'utilisateur continuera à utiliser objPtr. Si après avoir récupéré la valeur mp_int de objPtr, l'utilisateur n'utilisera plus objPtr, alors l'utilisation de Tcl_TakeBignumFromObj permet à Tcl de détecter quand une valeur non partagée objPtr permet de déplacer la valeur au lieu de la copier, ce qui devrait être plus efficace. Si pour une raison quelconque après que objPtr soit requis pour continuer à contenir la même valeur, alors Tcl_GetBignumFromObj doit être utilisé.

La routine Tcl_InitBignumFromDouble est une routine utilitaire qui extrait la partie entière de la valeur double de doubleValue et stocke cette valeur entière dans la valeur mp_int bigValue.
