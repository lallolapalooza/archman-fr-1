Tcl_GetCwd(3) Procédures de bibliothèque Tcl Tcl_GetCwd(3)

NOM

Tcl_GetCwd, Tcl_Chdir - manipuler le répertoire de travail courant

SYNOPIS

#include <tcl.h>

char *
Tcl_GetCwd(interp, bufferPtr)

int
Tcl_Chdir(dirName)

ARGUMENTS

Tcl_Interp *interp (in)
Interpréteur dans lequel signaler une erreur, le cas échéant.
Tcl_DString *bufferPtr (in/out)
Cette chaîne dynamique est utilisée pour stocker le répertoire de travail courant. Au moment de l'appel, elle doit être non initialisée ou libre. L'appelant doit éventuellement appeler Tcl_DStringFree pour libérer tout ce qui est stocké ici.
const char *dirName (in)
Chemin de fichier au format UTF-8.

DESCRIPTION

Ces procédures peuvent être utilisées pour manipuler le répertoire de travail courant de l'application. Elles fournissent un accès au niveau C à la même fonctionnalité que la commande Tcl pwd.

Tcl_GetCwd retourne un pointeur vers une chaîne spécifiant le répertoire courant, ou NULL si le répertoire courant n'a pas pu être déterminé. Si NULL est retourné, un message d'erreur est laissé dans le résultat de l'interp. L'espace pour la chaîne de résultat est alloué dans bufferPtr ; l'appelant doit appeler Tcl_DStringFree() lorsque le résultat n'est plus nécessaire. Le format du chemin est UTF-8.

Tcl_Chdir change le répertoire de travail courant de l'application à la valeur spécifiée dans dirName. Le format de la chaîne passée doit être UTF-8. La fonction retourne -1 en cas d'erreur ou 0 en cas de succès.
