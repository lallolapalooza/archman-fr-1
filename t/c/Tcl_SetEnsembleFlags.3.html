ARGUMENTS

Tcl_Interp *interp (in/out)
L'interpreteur dans lequel l'ensemble doit etre cree ou trouve. Il contient egalement les messages d'erreur. Les fonctions dont le nom commence par Tcl_GetEnsemble peuvent avoir NULL pour interp, mais toutes les autres fonctions ne le peuvent pas.
const char *name (in)
Le nom de la commande d'ensemble a creer.
Tcl_Namespace *namespacePtr (in)
L'espace de noms auquel la commande d'ensemble doit etre liee, ou NULL pour l'espace de noms courant.
int ensFlags (in)
Un ensemble de bits de drapeaux OR'es decrivant la configuration de base de l'ensemble. Actuellement, seul un bit a un sens, TCL_ENSEMBLE_PREFIX, qui est present lorsque la commande d'ensemble doit egalement correspondre a des prefixes non ambigus de sous-commandes.
Tcl_Obj *cmdNameObj (in)
Une valeur contenant le nom de la commande d'ensemble a rechercher.
int flags (in)
Un ensemble de bits de drapeaux OR'es controlant le comportement de Tcl_FindEnsemble. Actuellement, seul TCL_LEAVE_ERR_MSG est pris en charge.
Tcl_Command token (in)
Un token de commande normal qui fait reference a une commande d'ensemble, ou lequel vous souhaitez utiliser pour tester comme une commande d'ensemble dans Tcl_IsEnsemble.
int *ensFlagsPtr (out)
Pointeur vers une variable dans laquelle ecrire les bits de drapeaux actuels de l'ensemble ; actuellement seul le bit TCL_ENSEMBLE_PREFIX est defini.
Tcl_Obj *dictObj (in)
Une valeur de dictionnaire a utiliser pour le mappage du sous-commande au prefijo de commande d'implementation dans l'ensemble. Peut etre NULL si le dictionnaire de mappage doit etre supprime.
Tcl_Obj **dictObjPtr (out)
Pointeur vers une variable dans laquelle ecrire le dictionnaire de mappage actuel de l'ensemble.
Tcl_Obj *listObj (in)
Une valeur de liste a utiliser pour la liste des parametres formels avant la sous-commande, la liste definie des sous-commandes dans le dictionnaire ou le prefijo de commande du gestionnaire de sous-commande inconnu. Peut etre NULL si la liste des sous-commandes ou le gestionnaire inconnu doivent etre supprimes.
Tcl_Obj **listObjPtr (out)
Pointeur vers une variable dans laquelle ecrire la liste actuelle des parametres formels avant la sous-commande, la liste definie des sous-commandes ou le prefijo de commande actuel du gestionnaire inconnu.
Tcl_Namespace **namespacePtrPtr (out)
Pointeur vers une variable dans laquelle ecrire le handle de l'espace de noms auquel l'ensemble est lie.

DESCRIPTION

Un ensemble est une commande, liee a un espace de noms, qui consiste en une collection de sous-commandes implementees par d'autres commandes Tcl. Le premier argument de la commande d'ensemble est toujours interprete comme un selecteur indiquant quelle sous-commande executer.

Les ensembles sont crees a l'aide de Tcl_CreateEnsemble, qui prend quatre arguments : l'interpreteur dans lequel l'ensemble doit etre cree ou trouve, le nom de l'ensemble a creer, l'espace de noms dans l'interpreteur auquel l'ensemble doit etre lie, et l'ensemble de drapeaux par defaut pour l'ensemble. Le resultat de la fonction est le token de commande pour l'ensemble, qui peut etre utilise pour configurer l'ensemble via l'API decrite dans PROPRIETES DES ENSEMBLES.

Etant donne le nom d'une commande d'ensemble, le token pour cette commande peut etre obtenu en utilisant Tcl_FindEnsemble. Si le nom donne (dans cmdNameObj) ne fait pas reference a une commande d'ensemble, le resultat de la fonction est NULL et, si le bit TCL_LEAVE_ERR_MSG est definit dans flags, un message d'erreur est laisse dans le resultat de l'interpreteur.

Un token de commande peut etre verifie pour voir s'il fait reference a un ensemble en utilisant Tcl_IsEnsemble. Celle-ci renvoie 1 si le token fait reference a un ensemble, ou 0 sinon.

PROPRIETES DES ENSEMBLES

Chaque ensemble a quatre proprietes en lecture/ecriture et une propriete en lecture seule. Les proprietes sont :

flags (lecture/ecriture)
L'ensemble des drapeaux pour l'ensemble, exprime sous forme de champ de bits. Actuellement, le seul drapeau public est TCL_ENSEMBLE_PREFIX, qui est definit lorsque des prefixes de sous-commandes clairs peuvent etre resolus en implementations ainsi que des correspondances exactes. Les drapeaux peuvent etre lus et ecrits respectivement en utilisant Tcl_GetEnsembleFlags et Tcl_SetEnsembleFlags. Le resultat des deux fonctions est un code de resultat Tcl (TCL_OK, ou TCL_ERROR si le token ne fait pas reference a un ensemble).
dictionnaire de mappage (lecture/ecriture)
Un dictionnaire contenant un mappage des noms de sous-commandes a des listes de mots qui sont utilisees comme prefixe de commande (remplacant les deux premiers mots de la commande, qui sont la commande d'ensemble et le nom de la sous-commande), ou NULL si chaque sous-commande est mappee a une commande avec le meme nom non qualifie dans l'espace de noms de l'ensemble. La valeur par defaut est NULL. Peut etre lu et ecrit respectivement en utilisant Tcl_GetEnsembleMappingDict et Tcl_SetEnsembleMappingDict. Le resultat des deux fonctions est un code de resultat Tcl (TCL_OK, ou TCL_ERROR si le token ne fait pas reference a un ensemble) et le dictionnaire obtenu de Tcl_GetEnsembleMappingDict doit toujours etre traite comme immuable meme s'il n'est pas partage. Tous les noms de commande dans les prefixes definis par Tcl_SetEnsembleMappingDict doivent etre entierement qualifies.
liste formelle des parametres avant sous-commande (lecture/ecriture)
Une liste de noms de parametres formels (seulement utilises lors de la generation de messages d'erreur) qui sont invoques entre le nom de l'ensemble et l'argument de sous-commande. NULL (la valeur par defaut) est equivalent a une liste vide. Peut etre lu et ecrit respectivement en utilisant Tcl_GetEnsembleParameterList et Tcl_SetEnsembleParameterList. Le resultat des deux fonctions est un code de resultat Tcl (TCL_OK, ou TCL_ERROR si le token ne fait pas reference a un ensemble) et le dictionnaire obtenu de Tcl_GetEnsembleParameterList doit toujours etre traite comme immuable meme s'il n'est pas partage.
liste des sous-commandes (lecture/ecriture)
Une liste de tous les noms de sous-commandes pour l'ensemble, ou NULL si ceux-ci doivent etre derives des noms de clefs du dictionnaire de mappage (voir ci-dessus) ou (si cela est egalement NULL) des commandes exportees par l'espace de noms lie. Peut etre lu et ecrit respectivement en utilisant Tcl_GetEnsembleSubcommandList et Tcl_SetEnsembleSubcommandList. Le resultat des deux fonctions est un code de resultat Tcl (TCL_OK, ou TCL_ERROR si le token ne fait pas reference a un ensemble) et la liste obtenue de Tcl_GetEnsembleSubcommandList doit toujours etre traitee comme immuable meme si elle n'est pas partagee.
pref ixe de commande du gestionnaire de sous-commande inconnu (lecture/ecriture)
Une liste de mots qui sont places au debut de toute sous-commande lorsqu'elle est inconnue de l'ensemble (selon la regle actuelle de traitement des prefixes). La valeur par defaut est NULL. Peut etre lu et ecrit respectivement en utilisant Tcl_GetEnsembleUnknownHandler et Tcl_SetEnsembleUnknownHandler. Le resultat des deux fonctions est un code de resultat Tcl (TCL_OK, ou TCL_ERROR si le token ne fait pas reference a un ensemble)

Peut être lu et écrit en utilisant respectivement Tcl_GetEnsembleUnknownHandler et Tcl_SetEnsembleUnknownHandler. Le résultat des deux fonctions est un code de résultat Tcl (TCL_OK, ou TCL_ERROR si le jeton ne se réfère pas à un ensemble) et la liste obtenue de Tcl_GetEnsembleUnknownHandler doit toujours être traitée comme immuable même si elle n'est pas partagée.
bound namespace (lecture seule)
Le namespace auquel l'ensemble est lié ; lorsque le namespace est supprimé, l'ensemble l'est aussi, et ce namespace est également le namespace dont la liste de commandes exportées est utilisée si le dictionnaire de mappage et les propriétés de liste de sous-commandes sont NULL. Peut être lu en utilisant Tcl_GetEnsembleNamespace qui renvoie un code de résultat Tcl (TCL_OK, ou TCL_ERROR si le jeton ne se réfère pas à un ensemble).
