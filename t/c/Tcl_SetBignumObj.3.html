NAME

Tcl_NewIntObj, Tcl_NewLongObj, Tcl_NewWideIntObj, Tcl_SetIntObj, Tcl_SetLongObj, Tcl_SetWideIntObj, Tcl_GetIntFromObj, Tcl_GetLongFromObj, Tcl_GetWideIntFromObj, Tcl_GetBignumFromObj, Tcl_TakeBignumFromObj - manipuler des valeurs Tcl en tant qu'entiers

ARGUMENTS

int intValue (in)
La valeur entière utilisée pour initialiser ou définir une valeur Tcl.
long longValue (in)
La valeur entière longue utilisée pour initialiser ou définir une valeur Tcl.
Tcl_WideInt wideValue (in)
La valeur entière large utilisée pour initialiser ou définir une valeur Tcl.
Tcl_Obj *objPtr (in/out)
Pour Tcl_SetIntObj, Tcl_SetLongObj, Tcl_SetWideIntObj, et Tcl_SetBignumObj, ceci pointe vers la valeur dans laquelle une valeur entière sera stockée. Pour Tcl_GetIntFromObj, Tcl_GetLongFromObj, Tcl_GetWideIntFromObj, Tcl_GetBignumFromObj, et Tcl_TakeBignumFromObj, ceci fait référence à la valeur à partir de laquelle une valeur entière est obtenue.
Tcl_Interp *interp (in/out)
Si non nul, un message d'erreur est laissé ici lorsque la tentative de récupération de la valeur entière échoue.
int *intPtr (out)
Stocke la valeur entière obtenue à partir de objPtr.
long *longPtr (out)
Stocke la valeur entière longue obtenue à partir de objPtr.
Tcl_WideInt *widePtr (out)
Stocke la valeur entière large obtenue à partir de objPtr.
mp_int *bigValue (in/out)
Pointe vers une structure d'entier multiprécision définie par la bibliothèque LibTomMath.
double doubleValue (in)
La valeur double à partir de laquelle la partie entière est déterminée et utilisée pour initialiser une valeur entière multiprécision.

DESCRIPTION

Ces fonctions sont utilisées pour créer, modifier et lire des valeurs Tcl contenant des valeurs entières.

Il existe différentes routines pour correspondre aux différents types d'entiers C avec lesquels les valeurs peuvent être échangées. Les routines d'échange de valeurs pour les types d'entiers C sont int, long int, Tcl_WideInt et mp_int. Les types int et long int sont fournis par la norme C. Le type Tcl_WideInt est un typedef qui est défini comme le type intégral signé qui couvre au moins la plage de 64 bits (-9223372036854775808 à 9223372036854775807). Selon la plateforme et le compilateur C, le type réel peut être long int, long long int, __int64 ou quelque chose de similaire. Le type mp_int est un type multiprécision défini par la bibliothèque multiprécision LibTomMath.

Les routines Tcl_NewIntObj, Tcl_NewLongObj, Tcl_NewWideIntObj et Tcl_NewBignumObj créent et retournent une nouvelle valeur Tcl initialisée à la valeur entière de l'argument. La valeur Tcl retournée n'est pas partagée.

Les routines Tcl_SetIntObj, Tcl_SetLongObj, Tcl_SetWideIntObj et Tcl_SetBignumObj définissent la valeur d'une valeur Tcl existante pointée par objPtr à la valeur entière fournie par l'autre argument. L'argument objPtr doit pointer vers une valeur Tcl non partagée. Toute tentative de définir la valeur d'une valeur partagée viole la politique de copie sur écriture de Tcl. Toute représentation de chaîne ou interne dans la valeur non partagée sera libérée à la suite de la définition de la nouvelle valeur.

Les routines Tcl_GetIntFromObj, Tcl_GetLongFromObj, Tcl_GetWideIntFromObj, Tcl_GetBignumFromObj et Tcl_TakeBignumFromObj tentent de récupérer une valeur entière du type approprié à partir de la valeur Tcl pointée par objPtr. Si la tentative réussit, TCL_OK est retourné, et la valeur est écrite dans le stockage fourni par l'appelant. La tentative peut échouer si objPtr ne contient pas de valeur entière, ou si la valeur dépasse la plage du type cible. Si la tentative échoue, TCL_ERROR est retourné, et si interp n'est pas nul, un message d'erreur est laissé dans interp. Le type Tcl_ObjType de objPtr peut changer pour rendre les appels ultérieurs plus efficaces. Contrairement aux autres fonctions, Tcl_TakeBignumFromObj peut définir le contenu de la valeur Tcl objPtr sur une chaîne vide pendant le processus de récupération de la valeur entière multiprécision.

Le choix entre Tcl_GetBignumFromObj et Tcl_TakeBignumFromObj est régi par la manière dont l'appelant utilisera objPtr par la suite. Si après avoir récupéré la valeur mp_int de objPtr, l'appelant n'utilisera plus objPtr, alors l'utilisation de Tcl_TakeBignumFromObj permet à Tcl de détecter quand une valeur non partagée objPtr permet de déplacer la valeur au lieu de la copier, ce qui devrait être plus efficace. Si une partie ultérieure de l'appelant nécessite que objPtr continue de conserver la même valeur, alors Tcl_GetBignumFromObj doit être utilisé.

La routine Tcl_InitBignumFromDouble est une routine utilitaire qui extrait la partie entière de doubleValue et stocke cette valeur entière dans la valeur mp_int bigValue.
