ARGUMENTS

Tcl_Interp *interp (in)
Interpréteur contenant la variable.
const char *name1 (in)
Contient le nom d'une variable de tableau (si name2 est non nul) ou (si name2 est nul) le nom d'une variable scalaire ou un nom complet incluant à la fois le nom de la variable et l'indice. Peut inclure :: pour spécifier une variable dans un espace de noms particulier.
const char *name2 (in)
S'il n'est pas nul, donne le nom de l'élément dans un tableau ; dans ce cas, name1 doit faire référence à une variable de tableau.
Tcl_Obj *newValuePtr (in)
Fait référence à une valeur Tcl contenant la nouvelle valeur de la variable.
int flags (in)
OR de bits fournissant des informations supplémentaires. Voir ci-dessous pour les valeurs valides.
const char *varName (in)
Nom de la variable. Peut inclure :: pour spécifier une variable dans un espace de noms particulier. Peut faire référence à une variable scalaire ou à un élément de tableau.
const char *newValue (in)
Nouvelle valeur de la variable, spécifiée sous forme de chaîne terminée par null. Une copie de cette valeur est stockée dans la variable.
Tcl_Obj *part1Ptr (in)
Fait référence à une valeur Tcl contenant le nom de la variable. Le nom peut inclure un ensemble de :: pour spécifier une variable dans un espace de noms particulier. Peut faire référence à une variable scalaire ou à un élément d'une variable de tableau.
Tcl_Obj *part2Ptr (in)
S'il n'est pas nul, fait référence à une valeur contenant le nom d'un élément dans un tableau et part1Ptr doit faire référence à une variable de tableau.

DESCRIPTION

Ces procédures sont utilisées pour créer, modifier, lire et supprimer des variables Tcl à partir du code C.

Tcl_SetVar2Ex, Tcl_SetVar, Tcl_SetVar2 et Tcl_ObjSetVar2 créeront une nouvelle variable ou modifieront une existante. Ces procédures définiront la valeur donnée par newValuePtr ou newValue dans la variable donnée et retourneront un pointeur vers la nouvelle valeur de la variable, qui est stockée dans la structure de variable Tcl. Tcl_SetVar2Ex et Tcl_ObjSetVar2 reçoivent la nouvelle valeur sous forme d'objet Tcl_Obj et retournent un pointeur vers un Tcl_Obj. Tcl_SetVar et Tcl_SetVar2 reçoivent la nouvelle valeur sous forme de chaîne et retournent une chaîne ; ils sont généralement moins efficaces que Tcl_ObjSetVar2. Notez que la valeur renvoyée peut être différente de l'argument newValuePtr ou newValue, en raison des modifications apportées par les traçages d'écriture. En cas d'erreur lors de la définition de la variable (par exemple, référencer un tableau sans spécifier d'indice), NULL est renvoyé et un message d'erreur est laissé dans le résultat de interp si le bit TCL_LEAVE_ERR_MSG est activé.

Tcl_GetVar2Ex, Tcl_GetVar, Tcl_GetVar2 et Tcl_ObjGetVar2 retournent la valeur actuelle d'une variable. Les arguments de ces procédures sont traités de la même manière que les arguments des procédures décrites ci-dessus. Normalement, la valeur renvoyée est un pointeur vers la valeur de la variable. Pour Tcl_GetVar2Ex et Tcl_ObjGetVar2, la valeur est renvoyée sous forme de pointeur vers un Tcl_Obj. Pour Tcl_GetVar et Tcl_GetVar2, la valeur est renvoyée sous forme de chaîne ; c'est généralement moins efficace, donc Tcl_GetVar2Ex ou Tcl_ObjGetVar2 sont préférables. En cas d'erreur lors de la lecture de la variable (par exemple, la variable n'existe pas ou un élément de tableau est spécifié pour une variable scalaire), NULL est renvoyé et un message d'erreur est laissé dans le résultat de interp si le bit TCL_LEAVE_ERR_MSG est activé.

Tcl_UnsetVar et Tcl_UnsetVar2 peuvent être utilisés pour supprimer une variable, de sorte que les futures tentatives de lecture retourneront une erreur. Les arguments de ces procédures sont traités de la même manière que les arguments des procédures ci-dessus. Si la variable est supprimée avec succès, TCL_OK est renvoyé. Si la variable n'existe pas et ne peut pas être supprimée, TCL_ERROR est renvoyé et un message d'erreur est laissé dans le résultat de interp si le bit TCL_LEAVE_ERR_MSG est activé. Si un élément de tableau est spécifié, l'élément donné est supprimé mais le tableau reste. Si un nom de tableau sans indice est spécifié, le tableau entier est supprimé.

Le nom d'une variable peut être spécifié à ces procédures de quatre manières différentes :

[1]
Si Tcl_SetVar, Tcl_GetVar ou Tcl_UnsetVar sont appelés, le nom de la variable est fourni sous forme d'une seule chaîne, varName. Si varName contient une parenthèse ouvrante et se termine par une parenthèse fermante, la valeur entre les parenthèses est traitée comme un indice (n'importe quelle valeur de chaîne) et les caractères avant la première parenthèse sont traités comme le nom d'une variable de tableau. Si varName n'a pas de parenthèses comme décrit, la valeur complète est traitée comme le nom d'une variable scalaire.
[2]
Si les arguments name1 et name2 sont fournis et que name2 n'est pas nul, un élément de tableau est spécifié et le nom du tableau et l'indice ont été séparés par l'appelant : name1 contient le nom et name2 contient l'indice. Une erreur est générée si name1 contient une parenthèse ouvrante et se termine par une parenthèse fermante (élément de tableau) et name2 n'est pas nul.
[3]
Si name2 est nul, name1 est traité comme le nom de la variable dans le cas [1] ci-dessus (il peut s'agir d'une variable scalaire ou de tableau).

L'argument flags peut être utilisé pour spécifier l'une des options suivantes aux procédures. Il consiste en une combinaison OR des bits suivants :

TCL_GLOBAL_ONLY
Normalement, les procédures recherchent les variables comme suit. S'il y a un appel de procédure actif dans interp, la variable est recherchée au niveau d'appel de procédure actuel. Sinon, elle est recherchée d'abord dans l'espace de noms actuel, puis dans l'espace global. Cependant, si le bit est défini dans flags, la variable est recherchée uniquement dans l'espace global, même s'il y a un appel de procédure actif dans interp. Si TCL_GLOBAL_ONLY et TCL_NAMESPACE_ONLY sont tous deux donnés, TCL_GLOBAL_ONLY est ignoré.
TCL_NAMESPACE_ONLY
Si ce bit est défini dans flags, la variable est recherchée uniquement dans l'espace de noms actuel ; s'il y a un appel de procédure actif, ses variables sont ignorées, et l'espace global est également ignoré, sauf s'il s'agit de l'espace de noms actuel.
TCL_LEAVE_ERR_MSG
Si une erreur est renvoyée et que ce bit est défini dans flags, un message d'erreur sera laissé dans le résultat de l'interpréteur, d'où il pourra être récupéré à l'aide de Tcl_GetObjResult ou Tcl_GetStringResult. Si ce bit n'est pas activé, aucun message d'erreur ne sera laissé et le résultat de l'interpréteur ne sera pas modifié.
TCL_APPEND_VALUE
Si ce bit est défini, la valeur de newValuePtr ou newValue est ajoutée à la valeur actuelle au lieu de la remplacer. Si la variable est actuellement indéfinie, le bit est ignoré. Ce bit n'est utilisé que par les procédures Tcl_Set*.
TCL_LIST_ELEMENT
Si ce bit est défini, la valeur de newValue est convertie en un élément de liste Tcl valide avant de définir (ou d'ajouter) la variable. Un espace séparateur est ajouté avant le nouveau l
element de liste à moins que l'élément de liste ne soit le premier élément d'une liste ou d'une sous-liste (c'est-à-dire que la valeur actuelle de la variable est vide, ou contient le caractère unique “{”, ou se termine par “ }”). Lors de l'ajout, la valeur d'origine de la variable doit également être une liste valide, de sorte que l'opération soit l'ajout d'un nouvel élément de liste à une liste.

Tcl_GetVar et Tcl_GetVar2 renvoient la valeur actuelle d'une variable. Les arguments de ces procédures sont traités de la même manière que les arguments de Tcl_SetVar et Tcl_SetVar2. Dans des circonstances normales, la valeur de retour est un pointeur vers la valeur de la variable (qui est stockée dans la structure de variables de Tcl et ne changera pas avant le prochain appel à Tcl_SetVar ou Tcl_SetVar2). Tcl_GetVar et Tcl_GetVar2 utilisent les bits d'indicateur TCL_GLOBAL_ONLY et TCL_LEAVE_ERR_MSG, qui ont tous deux la même signification que pour Tcl_SetVar. Si une erreur se produit lors de la lecture de la variable (par exemple, la variable n'existe pas ou un élément de tableau est spécifié pour une variable scalaire), alors NULL est renvoyé.

Tcl_UnsetVar et Tcl_UnsetVar2 peuvent être utilisés pour supprimer une variable, de sorte que les appels futurs à Tcl_GetVar ou Tcl_GetVar2 pour cette variable renvoient une erreur. Les arguments de ces procédures sont traités de la même manière que les arguments de Tcl_GetVar et Tcl_GetVar2. Si la variable est supprimée avec succès, TCL_OK est renvoyé. Si la variable ne peut pas être supprimée car elle n'existe pas, TCL_ERROR est renvoyé. Si un élément de tableau est spécifié, l'élément donné est supprimé mais le tableau reste. Si un nom de tableau est spécifié sans indice, alors le tableau entier est supprimé.
