Tcl_Cancel(3) Procédures de la bibliothèque Tcl Tcl_Cancel(3)

NOM

Tcl_CancelEval, Tcl_Canceled - annuler les scripts Tcl

SYNOPSIS

#include <tcl.h>
int
Tcl_CancelEval(interp, resultObjPtr, clientData, flags)

int
Tcl_Canceled(interp, flags)

ARGUMENTS

Tcl_Interp *interp (in)
Interpréteur dans lequel annuler le script.
Tcl_Obj *resultObjPtr (in)
Message d'erreur à utiliser lors de l'annulation, ou NULL pour utiliser un message par défaut. S'il n'est pas NULL, son compteur de références sera décrémenté avant le retour de Tcl_CancelEval.
int flags (in)
Combinaison OU des bits de drapeaux spécifiant des options supplémentaires. Pour Tcl_CancelEval, seul TCL_CANCEL_UNWIND est actuellement pris en charge. Pour Tcl_Canceled, seuls TCL_LEAVE_ERR_MSG et TCL_CANCEL_UNWIND sont actuellement pris en charge.
ClientData clientData (in)
Actuellement réservé pour une utilisation future. Il doit être défini à NULL.

DESCRIPTION

Tcl_CancelEval annule ou déroule le script en cours peu après la prochaine invocation des gestionnaires asynchrones, provoquant le retour de TCL_ERROR pour ce script. Cette fonction est thread-safe et peut être appelée depuis n'importe quel thread du processus.

Tcl_Canceled vérifie si le script en cours a été annulé et renvoie TCL_ERROR s'il l'a été. Sinon, il renvoie TCL_OK. Les extensions peuvent utiliser cette fonction pour vérifier si elles doivent abandonner une commande longue durée. Cette fonction est sensible aux threads et ne peut être appelée que depuis le thread dans lequel l'interpréteur a été créé.

BITS DE DRAPEAU

Toute combinaison OU des valeurs suivantes peut être utilisée pour l'argument flags des procédures telles que Tcl_CancelEval:

TCL_CANCEL_UNWIND
Ce drapeau est utilisé par Tcl_CancelEval et Tcl_Canceled. Pour Tcl_CancelEval, si ce drapeau est défini, le script en cours est annulé et la pile d'évaluation de l'interpréteur est déroulée. Pour Tcl_Canceled, si ce drapeau est défini, le script en cours est considéré comme annulé uniquement si la pile d'évaluation de l'interpréteur est en cours de déroulement.
TCL_LEAVE_ERR_MSG
Ce drapeau est uniquement utilisé par Tcl_Canceled; il est ignoré par les autres procédures. Si une erreur est renvoyée et que ce bit est défini dans flags, alors un message d'erreur sera laissé dans le résultat de l'interpréteur, où il peut être récupéré avec Tcl_GetObjResult ou Tcl_GetStringResult. Si ce bit de drapeau n'est pas défini, aucun message d'erreur n'est laissé et le résultat de l'interpréteur ne sera pas modifié.
