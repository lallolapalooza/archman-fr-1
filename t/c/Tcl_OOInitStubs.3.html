Tcl_OOInitStubs(3) Fonctions de la bibliothèque TclOO Tcl_OOInitStubs(3)

NOM

Tcl_OOInitStubs - initialiser l'accès à la bibliothèque aux fonctionnalités TclOO

SYNTAXE

#include <tclOO.h>

const char *
Tcl_OOInitStubs(interp)

ARGUMENTS

Tcl_Interp *interp (entrée)
L'interpréteur Tcl auquel l'API TclOO est intégrée et dont l'interface C va être utilisée.

DESCRIPTION

Lorsqu'une bibliothèque d'extension doit utiliser l'interface C exposée par TclOO, elle devrait utiliser Tcl_OOInitStubs pour initialiser son accès à cette interface depuis sa fonction *_Init (ou *_SafeInit), en lui passant l' interp qui a été passé à cette routine comme contexte. Si le résultat de l'appel à Tcl_OOInitStubs est NULL, l'initialisation a échoué et un message d'erreur aura été laissé dans le résultat de l'interpréteur. Sinon, l'initialisation a réussi et l'API TclOO peut être utilisée par la suite ; la version de l'API TclOO est retournée.

Lors de l'utilisation de cette fonction, soit le symbole C #define USE_TCLOO_STUBS doit être défini et votre code de bibliothèque lié à la bibliothèque de stubs Tcl, soit ce symbole #define ne doit pas être défini et votre code de bibliothèque doit être lié directement à la bibliothèque principale Tcl.

NOTE DE COMPATIBILITÉ ASCENDANTE

Si vous liez contre le package de compatibilité ascendante Tcl 8.5 pour TclOO, seule la configuration avec stubs est prise en charge et vous devriez également lier contre la bibliothèque de stubs indépendante TclOO ; cette bibliothèque fait partie intégrante de la bibliothèque de stubs principale dans Tcl 8.6.
