NOM

Tcl_RecordAndEval - enregistre une commande dans la liste d'historique avant de l'évaluer

SYNOPIS

#include <tcl.h>

int
Tcl_RecordAndEval(interp, cmd, flags)

ARGUMENTS

Tcl_Interp *interp (entree)
Interpréteur Tcl dans lequel évaluer la commande.
const char *cmd (entree)
Commande (ou séquence de commandes) à exécuter.
int flags (entree)
Une combinaison OR des bits d'indicateurs. TCL_NO_EVAL signifie enregistrer la commande sans l'évaluer. TCL_EVAL_GLOBAL signifie évaluer la commande au niveau global au lieu du niveau de pile actuel.

DESCRIPTION

Tcl_RecordAndEval est appelée pour enregistrer une commande comme un événement dans la liste d'historique, puis l'exécuter en utilisant Tcl_Eval (ou Tcl_GlobalEval si le bit TCL_EVAL_GLOBAL est défini dans flags). Elle renvoie un code d'achèvement tel que TCL_OK, tout comme Tcl_Eval, et laisse des informations dans le résultat de l'interpréteur. Si vous ne souhaitez pas que la commande soit enregistrée dans la liste d'historique, vous devriez appeler Tcl_Eval à la place de Tcl_RecordAndEval. Normalement, Tcl_RecordAndEval n'est appelée qu'avec des commandes de haut niveau tapées par l'utilisateur, car le but de l'historique est de permettre à l'utilisateur de réémettre des commandes récemment invoquées. Si l'argument flags contient le bit TCL_NO_EVAL, la commande est alors enregistrée sans être évaluée.

Notez que Tcl_RecordAndEval a été largement remplacée par la procédure basée sur les valeurs Tcl_RecordAndEvalObj. Cette procédure basée sur les valeurs enregistre et exécute optionnellement une commande détenue par une valeur Tcl au lieu d'une chaîne.
