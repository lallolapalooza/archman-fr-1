Tcl_BackgroundError(3) Procédures de la bibliothèque Tcl Tcl_BackgroundError(3)

NOM

Tcl_BackgroundException, Tcl_BackgroundError - signaler une exception Tcl survenue lors d'un traitement en arrière-plan

SYNOPIS

#include <tcl.h>

Tcl_BackgroundException(interp, code)

Tcl_BackgroundError(interp)

ARGUMENTS

Tcl_Interp *interp (en entrée)
Interpréteur dans lequel l'exception s'est produite.
int code (en entrée)
Le code de retour exceptionnel à signaler.

DESCRIPTION

Cette procédure est généralement appelée lorsqu'une exception Tcl (tout code de retour autre que TCL_OK) se produit pendant un « traitement en arrière-plan », comme l'exécution d'un gestionnaire d'événements. Lorsque une telle exception se produit, la condition est signalée à Tcl, à un widget ou à un autre code C, et il n'y a généralement aucun moyen évident pour ce code de signaler l'exception à l'utilisateur. Dans ces cas, le code appelle Tcl_BackgroundException avec un argument interp identifiant l'interpréteur dans lequel l'exception s'est produite, et un argument code contenant la valeur du code de retour de l'exception. L'état de l'interpréteur, y compris tout message d'erreur dans le résultat de l'interpréteur, et les valeurs de toutes les entrées dans le dictionnaire des options de retour, est capturé et sauvegardé. Tcl_BackgroundException fait en sorte que la boucle d'événements invoque à un moment donné ultérieur la commande enregistrée dans cet interpréteur pour gérer les erreurs d'arrière-plan par la commande interp bgerror, en passant les valeurs capturées comme arguments. La commande de gestion est destinée à signaler l'exception d'une manière propre à l'application. La commande de gestion reçoit deux arguments, le résultat de l'interpréteur et les options de retour de l'interpréteur au moment où l'erreur s'est produite. Si l'application n'enregistre aucune commande de gestion, la commande de gestion par défaut tentera d'appeler bgerror pour signaler l'erreur. Si une condition d'erreur survient lors de l'invocation de la commande de gestion, alors Tcl_BackgroundException signale elle-même l'erreur en affichant un message sur le fichier d'erreur standard.

Tcl_BackgroundException n'invoque pas la commande de gestion immédiatement, car cela pourrait potentiellement interférer avec les scripts en cours au moment où l'erreur s'est produite. Au lieu de cela, elle invoque la commande de gestion plus tard sous forme de rappel inactif.

Il est possible que de nombreuses exceptions d'arrière-plan s'accumulent avant que la commande de gestion ne soit appelée. Lorsque cela se produit, chacune des exceptions est traitée dans l'ordre. Cependant, si la commande de gestion renvoie une exception de rupture, tous les rapports d'erreur restants pour l'interpréteur sont ignorés.

La routine Tcl_BackgroundError est une interface plus ancienne et plus simple, utile lorsque le code d'exception signalé est TCL_ERROR. Elle est équivalente à :

Tcl_BackgroundException(interp, TCL_ERROR);

MOTS-CLÉS

arrière-plan, bgerror, erreur, interp
