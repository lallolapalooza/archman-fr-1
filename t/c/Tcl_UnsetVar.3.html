ARGUMENTS

Tcl_Interp *interp (entrée)
Interpréteur contenant la variable.
const char *name1 (entrée)
Nom d'une variable de tableau (si name2 est non nul) ou (si name2 est nul) nom d'une variable scalaire ou nom complet incluant le nom de la variable et l'indice. Peut inclure :: pour spécifier une variable dans un espace de noms particulier.
const char *name2 (entrée)
S'il n'est pas nul, donne le nom de l'élément dans le tableau ; dans ce cas, name1 doit faire référence à une variable de tableau.
Tcl_Obj *newValuePtr (entrée)
Pointeur vers une valeur Tcl contenant la nouvelle valeur de la variable.
int flags (entrée)
OR bit à bit fournissant des informations supplémentaires. Voir ci-dessous pour les valeurs valides.
const char *varName (entrée)
Nom de la variable. Peut inclure :: pour spécifier une variable dans un espace de noms particulier. Peut faire référence à une variable scalaire ou à un élément de tableau.
const char *newValue (entrée)
Nouvelle valeur de la variable, spécifiée sous forme de chaîne se terminant par un nul. Une copie de cette valeur est stockée dans la variable.
Tcl_Obj *part1Ptr (entrée)
Pointeur vers une valeur Tcl contenant le nom de la variable. Le nom peut inclure une série de :: pour spécifier une variable dans un espace de noms particulier. Peut faire référence à une variable scalaire ou à un élément d'une variable de tableau.
Tcl_Obj *part2Ptr (entrée)
S'il n'est pas nul, pointe vers une valeur contenant le nom d'un élément dans un tableau et part1Ptr doit faire référence à une variable de tableau.

DESCRIPTION

Ces procédures sont utilisées pour créer, modifier, lire et supprimer des variables Tcl à partir de code C.

Tcl_SetVar2Ex, Tcl_SetVar, Tcl_SetVar2 et Tcl_ObjSetVar2 créent une nouvelle variable ou modifient une variable existante. Ces procédures définissent la valeur donnée par newValuePtr ou newValue dans la variable et retournent un pointeur vers la valeur de la nouvelle variable, qui est stockée dans la structure de variables de Tcl. Tcl_SetVar2Ex et Tcl_ObjSetVar2 utilisent la nouvelle valeur comme Tcl_Obj et retournent un pointeur vers un Tcl_Obj. Tcl_SetVar et Tcl_SetVar2 utilisent la nouvelle valeur comme chaîne et retournent une chaîne ; ils sont généralement plus lents que Tcl_ObjSetVar2. Remarque : la valeur retournée peut différer des arguments newValuePtr ou newValue, en raison des modifications apportées par les traçages d'écriture. S'il y a une erreur lors de la définition de la variable (par exemple, une référence à un tableau sans indice spécifié), NULL est retourné et un message d'erreur est laissé dans le résultat de interp si le bit TCL_LEAVE_ERR_MSG est défini.

Tcl_GetVar2Ex, Tcl_GetVar, Tcl_GetVar2 et Tcl_ObjGetVar2 retournent la valeur actuelle d'une variable. Les arguments de ces procédures sont traités de manière similaire aux arguments des procédures décrites ci-dessus. Dans des circonstances normales, la valeur retournée est un pointeur vers la valeur de la variable. Pour Tcl_GetVar2Ex et Tcl_ObjGetVar2, la valeur est retournée comme un pointeur vers un Tcl_Obj. Pour Tcl_GetVar et Tcl_GetVar2, la valeur est retournée comme une chaîne ; ceci est généralement moins efficace, donc Tcl_GetVar2Ex ou Tcl_ObjGetVar2 est préféré. S'il y a une erreur lors de la lecture de la variable (par exemple, la variable n'existe pas ou un élément de tableau est spécifié pour une variable scalaire), NULL est retourné et un message d'erreur est laissé dans le résultat de interp si le bit TCL_LEAVE_ERR_MSG est défini.

Tcl_UnsetVar et Tcl_UnsetVar2 peuvent être utilisés pour désaffecter une variable, ce qui signifie que les tentatives futures de lecture échoueront. Les arguments de ces procédures sont traités de manière similaire aux arguments des procédures ci-dessus. Si la variable est désaffectée avec succès, TCL_OK est retourné. Si la variable ne peut pas être désaffectée car elle n'existe pas, TCL_ERROR est retourné et un message d'erreur est laissé dans le résultat de interp si le bit TCL_LEAVE_ERR_MSG est défini. Si un élément de tableau est spécifié, l'élément donné est désaffecté mais le tableau est conservé. Si un nom de tableau sans indice est spécifié, le tableau entier est désaffecté.

Le nom d'une variable peut être spécifié à ces procédures de quatre manières :

[1]
Si Tcl_SetVar, Tcl_GetVar ou Tcl_UnsetVar est appelé, le nom de la variable est donné sous forme de chaîne unique, varName. Si varName contient une parenthèse ouvrante et se termine par une parenthèse fermante, la valeur entre parenthèses est traitée comme un indice (qui peut avoir n'importe quelle valeur de chaîne) et les caractères avant la première parenthèse sont traités comme le nom d'une variable de tableau. Si varName n'a pas de parenthèses comme décrit ci-dessus, l'entier est traité comme le nom d'une variable scalaire.
[2]
Si name1 et name2 sont fournis et que name2 n'est pas nul, un élément de tableau est spécifié et le nom du tableau et l'indice ont déjà été séparés par l'appelant : name1 contient le nom et name2 contient l'indice. Une erreur est générée si name1 contient une parenthèse ouvrante et se termine par une parenthèse fermante (élément de tableau) et name2 n'est pas nul.
[3]
Si name2 est nul, name1 est traité comme le nom d'une variable scalaire ou d'un élément de tableau, comme dans le cas [1] ci-dessus.

L'argument flags peut être utilisé pour spécifier l'une des options suivantes aux procédures. Il s'agit d'une combinaison OR des bits suivants :

TCL_GLOBAL_ONLY
Normalement, les procédures recherchent les variables de la manière suivante. S'il y a un appel de procédure actif dans interp, la variable est recherchée au niveau d'appel de procédure actuel. Sinon, elle est recherchée d'abord dans l'espace de noms actuel, puis dans l'espace global. Cependant, si le bit est défini dans flags, la variable est recherchée uniquement dans l'espace global, même s'il y a un appel actif. Si TCL_GLOBAL_ONLY et TCL_NAMESPACE_ONLY sont tous deux spécifiés, TCL_GLOBAL_ONLY est ignoré.
TCL_NAMESPACE_ONLY
Si ce bit est défini dans flags, la variable est recherchée uniquement dans l'espace de noms actuel ; s'il y a un appel actif, ses variables sont ignorées, et l'espace global est également ignoré, à moins qu'il ne soit l'espace de noms actuel.
TCL_LEAVE_ERR_MSG
Si une erreur est retournée et que ce bit est défini dans flags, un message d'erreur est laissé dans le résultat de l'interpréteur, où il peut être récupéré avec Tcl_GetObjResult ou Tcl_GetStringResult. Si ce bit n'est pas défini, aucun message d'erreur n'est laissé et le résultat de l'interpréteur n'est pas modifié.
TCL_APPEND_VALUE
Si ce bit est défini, newValuePtr ou newValue est ajouté à la valeur actuelle de la variable au lieu de la remplacer. Si la variable est actuellement indéfinie, ce bit est ignoré. Ce bit n'est utilisé que par les procédures Tcl_Set*.
TCL_LIST_ELEMENT
Si ce bit est défini, newValue est converti en un élément de liste Tcl valide avant de définir (ou d'ajouter à) la variable. Un espace séparateur est ajouté avant le nouvel élément.

NOM

Tcl_GetVar, Tcl_GetVar2, Tcl_UnsetVar, Tcl_UnsetVar2

SYNTAXIS

Tcl_GetVar var name default flags

Tcl_GetVar2 var name default flags

Tcl_UnsetVar var name

Tcl_UnsetVar2 var name

ARGUMENTS

var: la variable à lire ou à écrire

name: le nom de la variable

default: la valeur par défaut à utiliser si la variable n'existe pas

flags: drapeaux pour l'opération

DESCRIPTION

Tcl_GetVar et Tcl_GetVar2 retournent la valeur actuelle d'une variable. Les arguments de ces procédures sont traités de la même manière que les arguments de Tcl_SetVar et Tcl_SetVar2. Dans des circonstances normales, la valeur de retour est un pointeur vers la valeur de la variable (qui est stockée dans la structure de variable de Tcl et ne changera pas avant le prochain appel à Tcl_SetVar ou Tcl_SetVar2). Tcl_GetVar et Tcl_GetVar2 utilisent les bits de drapeau TCL_GLOBAL_ONLY et TCL_LEAVE_ERR_MSG, qui ont tous deux la même signification que pour Tcl_SetVar. Si une erreur se produit lors de la lecture de la variable (par exemple, la variable n'existe pas ou un élément de tableau est spécifié pour une variable scalaire), NULL est retourné.

Tcl_UnsetVar et Tcl_UnsetVar2 peuvent être utilisés pour supprimer une variable, de sorte que les appels futurs à Tcl_GetVar ou Tcl_GetVar2 pour cette variable renvoient une erreur. Les arguments de ces procédures sont traités de la même manière que les arguments de Tcl_GetVar et Tcl_GetVar2. Si la variable est supprimée avec succès, TCL_OK est retourné. Si la variable ne peut pas être supprimée car elle n'existe pas, TCL_ERROR est retourné. Si un élément de tableau est spécifié, l'élément donné est supprimé mais le tableau reste. Si un nom de tableau est spécifié sans index, alors le tableau entier est supprimé.
