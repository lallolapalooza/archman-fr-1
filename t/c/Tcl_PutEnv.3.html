Tcl_PutEnv(3) Procédures de la bibliothèque Tcl Tcl_PutEnv(3)

NOM

Tcl_PutEnv - procédures pour manipuler l'environnement

SYNTAXE

#include <tcl.h>

int
Tcl_PutEnv(assignment)

ARGUMENTS

const char *assignment (entrée)
Informations sur la variable d'environnement au format « NOM=valeur ». L'argument assignment est dans le codage système.

DESCRIPTION

Tcl_PutEnv définit une variable d'environnement. Les informations sont passées dans une seule chaîne de la forme « NOM=valeur ». Cette procédure est destinée à remplacer l'appel système putenv de UNIX. Toutes les applications basées sur Tcl utilisant putenv devraient la redéfinir en Tcl_PutEnv afin qu'elles s'interfacent correctement avec le runtime Tcl.
