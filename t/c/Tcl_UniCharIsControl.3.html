DESCRIPTION

Toutes les routines décrites examinent les caractères Unicode et renvoient une valeur booléenne. Une valeur de retour non nulle signifie que le caractère appartient bien à la classe de caractères associée à la routine appelée. Le reste de ce document décrit simplement les classes de caractères associées aux différentes routines.

CLASSES DE CARACTERES

Tcl_UniCharIsAlnum teste si le caractère est un caractère Unicode alphanumérique.

Tcl_UniCharIsAlpha teste si le caractère est un caractère Unicode alphabétique.

Tcl_UniCharIsControl teste si le caractère est un caractère de contrôle Unicode.

Tcl_UniCharIsDigit teste si le caractère est un caractère numérique Unicode.

Tcl_UniCharIsGraph teste si le caractère est un caractère Unicode imprimable, à l'exception de l'espace.

Tcl_UniCharIsLower teste si le caractère est un caractère Unicode en minuscule.

Tcl_UniCharIsPrint teste si le caractère est un caractère Unicode imprimable.

Tcl_UniCharIsPunct teste si le caractère est un caractère de ponctuation Unicode.

Tcl_UniCharIsSpace teste si le caractère est un caractère blanc Unicode.

Tcl_UniCharIsUpper teste si le caractère est un caractère Unicode en majuscule.

Tcl_UniCharIsWordChar teste si le caractère est alphanumérique ou une marque de ponctuation de connexion.
