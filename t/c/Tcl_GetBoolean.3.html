Tcl_GetInt(3) Procédures de bibliothèque Tcl Tcl_GetInt(3)

NOM

Tcl_GetInt, Tcl_GetDouble, Tcl_GetBoolean - conversion de chaînes en entiers, doubles ou booléens

SYNTAXE

#include <tcl.h>

int
Tcl_GetInt(interp, src, intPtr)

int
Tcl_GetDouble(interp, src, doublePtr)

int
Tcl_GetBoolean(interp, src, intPtr)

ARGUMENTS

Tcl_Interp *interp (entrée)
Interpréteur à utiliser pour le rapport d'erreurs.
const char *src (entrée)
Valeur textuelle à convertir.
int *intPtr (sortie)
Pointe vers l'emplacement où stocker la valeur entière convertie à partir de src.
double *doublePtr (sortie)
Pointe vers l'emplacement où stocker la valeur à virgule flottante en double précision convertie à partir de src.

DESCRIPTION

Ces procédures convertissent des chaînes en entiers ou en valeurs à virgule flottante en double précision ou en booléens (représentés par des entiers valant 0 ou 1). Chacune des procédures prend un argument src, le convertit dans une forme interne d'un type particulier, et stocke la valeur convertie à l'emplacement indiqué par le troisième argument de la procédure. Si tout se passe bien, chacune des procédures retourne TCL_OK. Si src n'a pas la syntaxe appropriée pour le type désiré, alors TCL_ERROR est retourné, un message d'erreur est laissé dans le résultat de l'interpréteur, et rien n'est stocké à *intPtr ou *doublePtr.

Tcl_GetInt s'attend à ce que src soit constitué d'une collection de chiffres entiers, éventuellement signés et éventuellement précédés et suivis d'espaces blancs. Si les deux premiers caractères de src après les espaces blancs et le signe optionnels sont « 0x » alors src est attendu en format hexadécimal ; sinon, si les deux premiers caractères de ce type sont « 0o » alors src est attendu en format octal ; sinon, si les deux premiers caractères de ce type sont « 0b » alors src est attendu en format binaire ; sinon, si le premier caractère de ce type est « 0 » alors src est attendu en format octal ; sinon, src est attendu en format décimal.

Tcl_GetDouble s'attend à ce que src soit constitué d'un nombre à virgule flottante, qui est : des espaces blancs ; un signe ; une séquence de chiffres ; un point décimal « . » ; une séquence de chiffres ; la lettre « e » ; un exposant décimal signé ; et plus d'espaces blancs. N'importe lequel des champs peut être omis, sauf que les chiffres avant ou après le point décimal doivent être présents et si le « e » est présent alors il doit être suivi du nombre exposant. S'il n'y a aucun champ à part le signe et la séquence initiale de chiffres (c'est-à-dire aucun point décimal ou indicateur d'exposant), cette séquence initiale de chiffres doit prendre l'une des formes que Tcl_GetInt supporte, décrites ci-dessus. L'utilisation de « , » comme point décimal n'est pas supportée, ni aucun autre type de séparateur inter-chiffres ne doit être présent.

Tcl_GetBoolean s'attend à ce que src spécifie une valeur booléenne. Si src est 0, false, no, ou off, alors Tcl_GetBoolean stocke une valeur nulle à *intPtr. Si src est 1, true, yes, ou on, alors 1 est stocké à *intPtr. N'importe laquelle de ces valeurs peut être abrégée, et les orthographes en majuscules sont également acceptables.
