Tcl_Panic(3) Procédures de bibliothèque Tcl Tcl_Panic(3)

NOM

Tcl_Panic, Tcl_PanicVA, Tcl_SetPanicProc - signaler une erreur fatale et abandonner

SYNTAXE

#include <tcl.h>

void
Tcl_Panic(format, arg, arg, ...)

void
Tcl_PanicVA(format, argList)

void
Tcl_SetPanicProc(panicProc)

ARGUMENTS

const char* format (entrée)
Une chaîne de formatage de style printf.
arg (entrée)
Arguments correspondant à la chaîne de formatage.
va_list argList (entrée)
Une liste d'arguments correspondant à la chaîne de formatage. Doit avoir été initialisée à l'aide de va_start, et effacée à l'aide de va_end.
Tcl_PanicProc *panicProc (entrée)
Procédure pour signaler un message d'erreur fatale et abandonner.

DESCRIPTION

Lorsque la bibliothèque Tcl détecte que ses structures de données internes sont dans un état incohérent, ou que ses procédures C ont été appelées d'une manière incohérente avec leur documentation, elle appelle Tcl_Panic pour afficher un message décrivant l'erreur et abandonner le processus. L'argument format est une chaîne de formatage décrivant comment formater les arguments restants arg en un message d'erreur, selon les mêmes règles de formatage utilisées par la famille de fonctions printf. Les mêmes règles de formatage sont également utilisées par la commande Tcl intégrée format.

Dans une bibliothèque Tcl fraîchement chargée, Tcl_Panic imprime le message d'erreur formaté sur le flux d'erreur standard du processus, puis appelle abort pour terminer le processus. Tcl_Panic ne retourne pas. Sous Windows, lorsqu'un débogueur est en cours d'exécution, le message d'erreur formaté est envoyé au débogueur à la place. Si l'exécutable Windows n'a pas de canal stderr (par exemple, wish.exe), une boîte de dialogue système est utilisée pour afficher le message de panique.

Tcl_SetPanicProc peut être utilisé pour modifier le comportement de Tcl_Panic. L'argument panicProc doit correspondre au type Tcl_PanicProc :

typedef void Tcl_PanicProc(
        const char *format,
        arg, arg,...);

Après le retour de Tcl_SetPanicProc, tout appel futur à Tcl_Panic appellera panicProc, en passant les arguments format et arg. panicProc doit éviter de faire des appels dans la bibliothèque Tcl, ou dans d'autres bibliothèques qui pourraient appeler la bibliothèque Tcl, car l'appel original à Tcl_Panic indique que la bibliothèque Tcl n'est pas dans un état de fonctionnement fiable.

L'utilisation typique de Tcl_SetPanicProc consiste à organiser l'affichage ou le signalement du message d'erreur d'une manière plus adaptée à l'application ou à la plateforme.

Bien que les principaux appelants de Tcl_Panic soient les procédures de la bibliothèque Tcl, Tcl_Panic est une fonction publique et peut être appelée par toute extension ou application qui souhaite abandonner le processus et faire afficher un message de panique de la même manière que les messages de panique de Tcl seront affichés.

Tcl_PanicVA est identique à Tcl_Panic, sauf qu'au lieu de prendre un nombre variable d'arguments, elle prend une liste d'arguments.
