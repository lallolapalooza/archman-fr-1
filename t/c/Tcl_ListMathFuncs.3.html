Tcl_CreateMathFunc(3) Procédures de bibliothèque Tcl Tcl_CreateMathFunc(3)

NOM

Tcl_CreateMathFunc, Tcl_GetMathFuncInfo, Tcl_ListMathFuncs — Définir, interroger et énumérer les fonctions mathématiques pour les expressions

NOTIFICATION DE DÉPRÉCATION ÉVENTUELLE

Les fonctions Tcl_CreateMathFunc et Tcl_GetMathFuncInfo sont quelque peu obsolètes en raison de la possibilité de créer des fonctions pour les expressions en plaçant des commandes dans l'espace de noms tcl::mathfunc, comme décrit dans la page de manuel tcl::mathfunc ; l'API décrite sur cette page ne sera pas maintenue indéfiniment.

SYNOPSIS

#include <tcl.h>

void
Tcl_CreateMathFunc(interp, name, numArgs, argTypes, proc, clientData)

int
Tcl_GetMathFuncInfo(interp, name, numArgsPtr, argTypesPtr, procPtr,
                    clientDataPtr)

Tcl_Obj *
Tcl_ListMathFuncs(interp, pattern)

ARGUMENTS

Tcl_Interp *interp (in)
Interpréteur dans lequel la nouvelle fonction sera définie.
const char *name (in)
Nom de la nouvelle fonction.
int numArgs (in)
Nombre d'arguments pour la nouvelle fonction ; indique également la taille du tableau argTypes.
Tcl_ValueType *argTypes (in)
Pointe vers un tableau donnant les types autorisés pour chaque argument de la fonction.
Tcl_MathProc *proc (in)
Procédure qui implémente la fonction.
ClientData clientData (in)
Valeur arbitraire de taille fixe qui est transmise à proc lors de l'invocation.
int *numArgsPtr (out)
Pointe vers une variable qui sera définie pour contenir le nombre d'arguments de la fonction.
Tcl_ValueType **argTypesPtr (out)
Pointe vers une variable qui sera définie pour contenir un pointeur vers un tableau donnant les types autorisés pour chaque argument de la fonction, qui doit être libéré en utilisant Tcl_Free.
Tcl_MathProc **procPtr (out)
Pointe vers une variable qui sera définie pour contenir un pointeur vers l'implémentation de la fonction (ou NULL si la fonction est implémentée directement en bytecode).
ClientData *clientDataPtr (out)
Pointe vers une variable qui sera définie pour contenir l'argument clientData passé à Tcl_CreateMathFunc lors de la création de la fonction si celle-ci n'est pas implémentée directement en bytecode.
const char *pattern (in)
Modèle pour rechercher les noms des fonctions tel que passé à Tcl_StringMatch, ou NULL pour ne pas appliquer de filtre.

DESCRIPTION

Tcl permet un certain nombre de fonctions mathématiques à utiliser dans les expressions, telles que sin, cos et hypot. Ces fonctions sont représentées par des commandes dans l'espace de noms tcl::mathfunc. La fonction Tcl_CreateMathFunc est une méthode obsolète pour ajouter de nouvelles fonctions à celles déjà fournies par Tcl ou pour remplacer des fonctions existantes. Elle ne doit pas être utilisée par de nouvelles applications, qui devraient créer des fonctions mathématiques en utilisant Tcl_CreateObjCommand pour créer une commande dans l'espace de noms tcl::mathfunc.

Dans l'interface Tcl_CreateMathFunc, name est le nom de la fonction tel qu'il apparaîtra dans les expressions. Si name n'existe pas encore dans l'espace de noms ::tcl::mathfunc, une nouvelle fonction est créée dans cet espace. Si name existe déjà, la fonction existante est remplacée. numArgs et argTypes décrivent les arguments de la fonction. Chaque entrée dans le tableau argTypes doit être TCL_INT, TCL_DOUBLE, TCL_WIDE_INT ou TCL_EITHER pour indiquer si l'argument correspondant doit être un entier, une valeur à virgule flottante double précision, un entier 64 bits ou toute valeur, respectivement.

Lorsque la fonction est invoquée dans une expression, Tcl invoquera proc. Proc doit avoir des arguments et des résultats qui correspondent au type Tcl_MathProc :

typedef int Tcl_MathProc(
        ClientData clientData,
        Tcl_Interp *interp,
        Tcl_Value *args,
        Tcl_Value *resultPtr);

Lorsque proc est invoqué, les arguments clientData et interp seront les mêmes que ceux passés à Tcl_CreateMathFunc. Args pointera vers un tableau de numArgs structures Tcl_Value, qui décrivent les arguments réels de la fonction :

typedef struct Tcl_Value {
    Tcl_ValueType type;
    long intValue;
    double doubleValue;
    Tcl_WideInt wideValue;
} Tcl_Value;

Le champ type indique le type de l'argument et est l'un de TCL_INT, TCL_DOUBLE ou TCL_WIDE_INT. Si la valeur de argTypes était TCL_EITHER, le champ type ne correspondra pas à la valeur de argTypes spécifiée pour la fonction. Tcl convertira l'argument fourni dans l'expression au type demandé dans argTypes, si nécessaire. Selon la valeur du champ type, le champ intValue, doubleValue ou wideValue contiendra la valeur réelle de l'argument.

Proc doit calculer son résultat et le stocker dans resultPtr->intValue ou en tant que valeur flottante dans resultPtr->doubleValue. Il doit également définir resultPtr->type à l'un de TCL_INT, TCL_DOUBLE ou TCL_WIDE_INT pour indiquer quelle valeur a été définie. Normalement, proc devrait retourner TCL_OK. Si une erreur se produit lors de l'exécution de la fonction, proc doit retourner TCL_ERROR et laisser un message d'erreur dans le résultat de l'interpréteur.

Tcl_GetMathFuncInfo récupère les valeurs associées à la fonction name qui ont été passées à un appel précédent de Tcl_CreateMathFunc. Normalement, le code de retour est TCL_OK, mais si la fonction nommée n'existe pas, TCL_ERROR est retourné et un message d'erreur est placé dans le résultat de l'interpréteur.

Si aucune erreur ne s'est produite, le tableau référencé dans la variable pointée par argTypesPtr est nouvellement créé et doit être libéré en le passant à Tcl_Free. Certaines fonctions (les fonctions standard implémentées dans le noyau, et celles définies en plaçant des commandes dans l'espace de noms tcl::mathfunc) n'ont pas d'informations sur les types d'arguments ; tenter de récupérer des valeurs pour celles-ci entraîne l'écriture de NULL dans la variable pointée par procPtr et les valeurs pointées par clientDataPtr ne sont pas modifiées. La valeur pointée par numArgsPointer contiendra -1, et aucun type d'argument ne sera stocké dans la valeur pointée par argTypesPointer.

Tcl_ListMathFuncs renvoie une valeur Tcl contenant une liste de toutes les fonctions mathématiques définies dans l'interpréteur dont le nom correspond au pattern. La valeur renvoyée a un compteur de références nul.

    NOM

    Tcl_ListMathFuncs - Fonctions mathématiques pour les listes Tcl

    SYNTAXE

    
#include <tcl.h>

int
Tcl_ListMathFuncs(interp, list, count, funcs, results)
    Tcl_Interp *interp;
    Tcl_Obj *list;
    int count;
    const char **funcs;
    Tcl_Obj *results;

    DESCRIPTION

    La fonction Tcl_ListMathFuncs applique une liste de fonctions mathématiques à chaque élément d'une liste Tcl donnée. Elle est conçue pour être utilisée par les implémentations des commandes Tcl qui nécessitent des opérations mathématiques sur des listes.

    Les arguments sont les suivants :

    • interp : Un pointeur vers l'interpréteur Tcl dans lequel les opérations seront effectuées.
    • list : Un pointeur vers l'objet Tcl représentant la liste d'entrée. Chaque élément de cette liste sera traité.
    • count : Le nombre de fonctions mathématiques à appliquer.
    • funcs : Un tableau de chaînes de caractères, où chaque chaîne représente le nom d'une fonction mathématique à appliquer. Les fonctions prises en charge incluent des opérations arithmétiques de base, des fonctions trigonométriques, etc.
    • results : Un pointeur vers un objet Tcl dans lequel les résultats de l'application des fonctions seront stockés sous forme de liste.

    La fonction parcourt la liste d'entrée. Pour chaque élément, elle applique séquentiellement chaque fonction spécifiée dans le tableau funcs. Le résultat de chaque fonction appliquée est utilisé comme entrée pour la fonction suivante. Le résultat final de l'application de toutes les fonctions à un élément de la liste d'entrée est ajouté à la liste results.

    Si une erreur se produit lors de l'évaluation d'une fonction ou si un élément de la liste n'est pas un nombre valide, la fonction échouera et retournera TCL_ERROR, et un message d'erreur sera défini dans l'interpréteur interp. Sinon, elle retournera TCL_OK.
