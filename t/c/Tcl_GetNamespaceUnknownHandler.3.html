Tcl_GetNamespaceUnknownHandler(3)

Paquet: tcl

Tcl_Namespace(3) Procédures de la bibliothèque Tcl Tcl_Namespace(3)

int
Tcl_ForgetImport(interp, nsPtr, pattern)

Tcl_Namespace *
Tcl_GetCurrentNamespace(interp)

Tcl_Namespace *
Tcl_GetGlobalNamespace(interp)

ARGUMENTS

Tcl_Interp *interp (in/out)
L'interpréteur dans lequel l'espace de noms existe et où les recherches de noms sont effectuées. C'est également là que les messages de résultat d'erreur sont écrits.
const char *name (in)
Le nom de l'espace de noms ou de la commande à créer ou à accéder.
ClientData clientData (in)
Un pointeur de contexte fourni par le créateur de l'espace de noms. Il n'est pas interprété par Tcl.
Tcl_NamespaceDeleteProc *deleteProc (in)
Un pointeur vers une fonction qui est appelée lorsque l'espace de noms est supprimé, ou NULL s'il n'y a pas de rappel.
Tcl_Namespace *nsPtr (in)
L'espace de noms à manipuler, ou NULL (pour les fonctions autres que Tcl_DeleteNamespace) pour manipuler l'espace de noms actuel.
Tcl_Obj *objPtr (out)
Une référence à une valeur non partagée dans laquelle le résultat de la fonction sera écrit.
const char *pattern (in)
Le motif de type glob (voir Tcl_StringMatch) qui décrit les commandes à importer ou à exporter.
int resetListFirst (in)
Si la liste des motifs d'exportation doit être réinitialisée avant d'ajouter le motif courant.
int allowOverwrite (in)
Si les commandes nouvelles créées par cette action d'importation peuvent écraser des commandes existantes.
Tcl_Namespace *contextNsPtr (in)
L'emplacement dans l'arborescence des espaces de noms où rechercher un espace de noms ou une commande, relativement au cas où le terme de recherche n'est pas dans l'espace de noms global. NULL indique l'espace de noms actuel.
int flags (in)
Une combinaison OR de bits qui contrôlent comment la recherche sera effectuée. Les indicateurs suivants sont pris en charge : TCL_GLOBAL_ONLY (indique que la recherche est toujours effectuée par rapport à l'espace de noms global), TCL_NAMESPACE_ONLY (uniquement pour Tcl_FindCommand ; indique que la recherche est toujours effectuée par rapport à l'espace de noms de contexte), et TCL_LEAVE_ERR_MSG (indique qu'un message d'erreur doit être laissé dans l'interpréteur si la recherche échoue.)
Tcl_Obj *handlerPtr (in)
Un fragment de script qui est installé comme gestionnaire de commandes inconnues pour l'espace de noms, ou NULL pour réinitialiser le gestionnaire à sa valeur par défaut.

DESCRIPTION

Les espaces de noms sont des contextes de noms hiérarchiques qui peuvent contenir des commandes et des variables. Ils maintiennent également une liste de motifs décrivant quelles commandes sont exportées, et peuvent importer des commandes qui ont été exportées par d'autres espaces de noms. Les espaces de noms peuvent également être manipulés via la commande Tcl namespace.

La structure Tcl_Namespace encapsule un espace de noms, et il est garanti qu'elle a les champs suivants : name (le nom local de l'espace de noms, sans caractères séparateurs d'espace de noms, avec une chaîne vide dénotant l'espace de noms global), fullName (le nom complet de l'espace de noms), clientData, deleteProc (les valeurs spécifiées lors de l'appel à Tcl_CreateNamespace), et parentPtr (un pointeur vers l'espace de noms parent, ou NULL pour l'espace de noms global.)

Tcl_CreateNamespace crée un nouvel espace de noms. Le deleteProc aura la signature de type suivante :

typedef void Tcl_NamespaceDeleteProc(
        ClientData clientData);

Tcl_DeleteNamespace supprime un espace de noms, en appelant le deleteProc défini pour l'espace de noms (s'il existe).

Tcl_AppendExportList récupère les motifs d'exportation d'un espace de noms donné et les ajoute (en tant qu'éléments de liste) à objPtr.

Tcl_Export définit et ajoute aux motifs d'exportation d'un espace de noms. Les motifs sont ajoutés à moins que resetListFirst ne soit vrai.

Tcl_Import importe les commandes correspondant à un motif dans un espace de noms. Remarque : le motif doit inclure le nom de l'espace de noms à partir duquel importer. Cette fonction renvoie TCL_ERROR si l'on tente d'importer une commande sur une commande existante, à moins que allowOverwrite ne soit défini.

Tcl_ForgetImport supprime les importations correspondant à un motif.

Tcl_GetCurrentNamespace renvoie l'espace de noms actuel pour un interpréteur.

Tcl_GetGlobalNamespace renvoie l'espace de noms global pour un interpréteur.

Tcl_FindNamespace recherche un espace de noms portant le nom name dans le contexte de l'espace de noms contextNsPtr. S'il ne peut pas être trouvé, NULL est renvoyé.

Tcl_FindCommand recherche une commande portant le nom name dans le contexte de l'espace de noms contextNsPtr. S'il ne peut pas être trouvé, NULL est renvoyé.

Tcl_GetNamespaceUnknownHandler renvoie le gestionnaire de commandes inconnues pour l'espace de noms, ou NULL s'il n'est pas configuré.

Tcl_SetNamespaceUnknownHandler définit le gestionnaire de commandes inconnues pour l'espace de noms. Si handlerPtr est NULL, le gestionnaire est réinitialisé à sa valeur par défaut.
