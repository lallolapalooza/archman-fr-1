Tcl_SignalId(3) Procédures de la bibliothèque Tcl Tcl_SignalId(3)

NOM

Tcl_SignalId, Tcl_SignalMsg - Convertir les codes de signal

SYNOPSIS

#include <tcl.h>

const char *
Tcl_SignalId(sig)

const char *
Tcl_SignalMsg(sig)

ARGUMENTS

int sig (entrée)
Un numéro de signal POSIX tel que SIGPIPE.

DESCRIPTION

Tcl_SignalId et Tcl_SignalMsg renvoient une représentation textuelle du numéro de signal fourni (sig). Tcl_SignalId renvoie un identifiant textuel lisible par machine tel que « SIGPIPE ». Tcl_SignalMsg renvoie une chaîne de caractères lisible par l'homme telle que « bus error ». Les chaînes renvoyées par ces fonctions sont allouées statiquement et l'appelant ne doit pas les libérer ni les modifier.
