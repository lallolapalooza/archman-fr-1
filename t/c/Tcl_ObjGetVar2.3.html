ARGUMENTS

Tcl_Interp *interp (in)
Interpréteur contenant la variable.
const char *name1 (in)
Contient le nom d'une variable tableau (si name2 est non-NULL) ou (si name2 est NULL) soit le nom d'une variable scalaire, soit un nom complet incluant le nom de la variable et l'indice. Peut inclure des qualificatifs de namespace :: pour spécifier une variable dans un namespace particulier.
const char *name2 (in)
S'il n'est pas NULL, donne le nom de l'élément dans le tableau ; dans ce cas, name1 doit faire référence à une variable tableau.
Tcl_Obj *newValuePtr (in)
Pointe vers une valeur Tcl contenant la nouvelle valeur de la variable.
int flags (in)
Combinaison OR-ée de bits fournissant des informations supplémentaires. Voir ci-dessous pour les valeurs valides.
const char *varName (in)
Nom de la variable. Peut inclure des qualificatifs de namespace :: pour spécifier une variable dans un namespace particulier. Peut faire référence à une variable scalaire ou à un élément d'un tableau.
const char *newValue (in)
Nouvelle valeur de la variable, spécifiée sous forme de chaîne de caractères se terminant par un caractère nul. Une copie de cette valeur est stockée dans la variable.
Tcl_Obj *part1Ptr (in)
Pointe vers une valeur Tcl contenant le nom de la variable. Le nom peut inclure une série de qualificatifs de namespace :: pour spécifier une variable dans un namespace particulier. Peut faire référence à une variable scalaire ou à un élément d'une variable tableau.
Tcl_Obj *part2Ptr (in)
S'il n'est pas NULL, pointe vers une valeur contenant le nom d'un élément dans un tableau et part1Ptr doit faire référence à une variable tableau.

DESCRIPTION

Ces procédures sont utilisées pour créer, modifier, lire et supprimer des variables Tcl à partir de code C.

Tcl_SetVar2Ex, Tcl_SetVar, Tcl_SetVar2 et Tcl_ObjSetVar2 créeront une nouvelle variable ou modifieront une existante. Ces procédures définissent la variable donnée à la valeur fournie par newValuePtr ou newValue et retournent un pointeur vers la nouvelle valeur de la variable, qui est stockée dans la structure de variable de Tcl. Tcl_SetVar2Ex et Tcl_ObjSetVar2 prennent la nouvelle valeur sous forme de Tcl_Obj et retournent un pointeur vers un Tcl_Obj. Tcl_SetVar et Tcl_SetVar2 prennent la nouvelle valeur sous forme de chaîne de caractères et retournent une chaîne de caractères ; elles sont généralement moins efficaces que Tcl_ObjSetVar2. Notez que la valeur de retour peut être différente de l'argument newValuePtr ou newValue, en raison des modifications apportées par les traces d'écriture. Si une erreur survient lors de la définition de la variable (par exemple, une variable tableau est référencée sans fournir d'indice au tableau), NULL est retourné et un message d'erreur est laissé dans le résultat de interp si le bit de flag TCL_LEAVE_ERR_MSG est défini.

Tcl_GetVar2Ex, Tcl_GetVar, Tcl_GetVar2 et Tcl_ObjGetVar2 retournent la valeur actuelle d'une variable. Les arguments de ces procédures sont traités de la même manière que les arguments des procédures décrites ci-dessus. Dans des circonstances normales, la valeur de retour est un pointeur vers la valeur de la variable. Pour Tcl_GetVar2Ex et Tcl_ObjGetVar2, la valeur est retournée sous forme de pointeur vers un Tcl_Obj. Pour Tcl_GetVar et Tcl_GetVar2, la valeur est retournée sous forme de chaîne de caractères ; c'est généralement moins efficace, donc Tcl_GetVar2Ex ou Tcl_ObjGetVar2 sont préférés. Si une erreur survient lors de la lecture de la variable (par exemple, la variable n'existe pas ou un élément de tableau est spécifié pour une variable scalaire), alors NULL est retourné et un message d'erreur est laissé dans le résultat de interp si le bit de flag TCL_LEAVE_ERR_MSG est défini.

Tcl_UnsetVar et Tcl_UnsetVar2 peuvent être utilisées pour supprimer une variable, de sorte que les tentatives futures de lecture de la variable retourneront une erreur. Les arguments de ces procédures sont traités de la même manière que les arguments des procédures ci-dessus. Si la variable est supprimée avec succès, alors TCL_OK est retourné. Si la variable ne peut pas être supprimée car elle n'existe pas, alors TCL_ERROR est retourné et un message d'erreur est laissé dans le résultat de interp si le bit de flag TCL_LEAVE_ERR_MSG est défini. Si un élément de tableau est spécifié, l'élément donné est supprimé mais le tableau reste. Si un nom de tableau est spécifié sans indice, alors tout le tableau est supprimé.

Le nom d'une variable peut être spécifié à ces procédures de quatre manières :

[1]
Si Tcl_SetVar, Tcl_GetVar ou Tcl_UnsetVar est appelée, le nom de la variable est donné sous forme d'une seule chaîne, varName. Si varName contient une parenthèse ouvrante et se termine par une parenthèse fermante, alors la valeur entre les parenthèses est traitée comme un indice (qui peut avoir n'importe quelle valeur de chaîne) et les caractères avant la première parenthèse ouvrante sont traités comme le nom d'une variable tableau. Si varName n'a pas de parenthèses comme décrit ci-dessus, alors toute la chaîne est traitée comme le nom d'une variable scalaire.
[2]
Si les arguments name1 et name2 sont fournis et que name2 n'est pas NULL, alors un élément de tableau est spécifié et le nom du tableau et l'indice ont déjà été séparés par l'appelant : name1 contient le nom et name2 contient l'indice. Une erreur est générée si name1 contient une parenthèse ouvrante et se termine par une parenthèse fermante (élément de tableau) et que name2 n'est pas NULL.
[3]
Si name2 est NULL, name1 est traité de la même manière que varName dans le cas [1] ci-dessus (il peut s'agir soit d'un nom de variable scalaire, soit d'un nom de variable élément de tableau).

L'argument flags peut être utilisé pour spécifier l'une des plusieurs options aux procédures. Il est constitué d'une combinaison OR-ée des bits suivants.

TCL_GLOBAL_ONLY
Dans des circonstances normales, les procédures recherchent les variables comme suit. Si un appel de procédure est actif dans interp, la variable est recherchée au niveau actuel de l'appel de procédure. Sinon, la variable est recherchée d'abord dans le namespace courant, puis dans le namespace global. Cependant, si ce bit est défini dans flags, la variable est recherchée uniquement dans le namespace global, même si un appel de procédure est actif. Si TCL_GLOBAL_ONLY et TCL_NAMESPACE_ONLY sont tous deux fournis, TCL_GLOBAL_ONLY est ignoré.
TCL_NAMESPACE_ONLY
Si ce bit est défini dans flags, la variable est recherchée uniquement dans le namespace courant ; si une procédure est active, ses variables sont ignorées, et le namespace global est également ignoré sauf s'il s'agit du namespace courant.
TCL_LEAVE_ERR_MSG
Si une erreur est retournée et que ce bit est défini dans flags, alors un message d'erreur sera laissé dans le résultat de l'interpréteur, où il pourra être récupéré avec Tcl_GetObjResult ou Tcl_GetStringResult. Si ce bit de flag n'est pas défini, aucun message d'erreur n'est laissé et le résultat de l'interpréteur ne sera pas modifié.
TCL_APPEND_VALUE
Si ce bit est défini, alors newValuePtr ou newValue est ajouté à la valeur actuelle au lieu de la remplacer. Si la variable n'est actuellement pas définie, alors le bit est ignoré. Ce bit est uniquement utilisé par les procédures Tcl_Set*.
TCL_LIST_ELEMENT

Tcl_GetVar et Tcl_GetVar2 retournent la valeur actuelle d'une variable. Les arguments de ces procédures sont traités de la même manière que les arguments de Tcl_SetVar et Tcl_SetVar2. Dans des circonstances normales, la valeur de retour est un pointeur vers la valeur de la variable (qui est stockée dans la structure de variable de Tcl et ne changera pas avant le prochain appel à Tcl_SetVar ou Tcl_SetVar2). Tcl_GetVar et Tcl_GetVar2 utilisent les bits de drapeau TCL_GLOBAL_ONLY et TCL_LEAVE_ERR_MSG, qui ont la même signification que pour Tcl_SetVar. Si une erreur se produit lors de la lecture de la variable (par exemple, la variable n'existe pas ou un élément de tableau est spécifié pour une variable scalaire), NULL est retourné.

Tcl_UnsetVar et Tcl_UnsetVar2 peuvent être utilisés pour supprimer une variable, de sorte que les appels futurs à Tcl_GetVar ou Tcl_GetVar2 pour la variable renvoient une erreur. Les arguments de ces procédures sont traités de la même manière que les arguments de Tcl_GetVar et Tcl_GetVar2. Si la variable est supprimée avec succès, TCL_OK est retourné. Si la variable ne peut pas être supprimée parce qu'elle n'existe pas, alors TCL_ERROR est retourné. Si un élément de tableau est spécifié, l'élément donné est supprimé mais le tableau reste. Si un nom de tableau est spécifié sans index, alors le tableau entier est supprimé.
