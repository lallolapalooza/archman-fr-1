ARGUMENTS

Tcl_Interp *interp (in)
Si une erreur survient lors de la conversion d'une valeur en une valeur de dictionnaire, un message d'erreur sera laissé dans la valeur de résultat de l'interpréteur, sauf si interp est NULL.
Tcl_Obj *dictPtr (in/out)
Pointe vers la valeur de dictionnaire à manipuler. Si dictPtr ne pointe pas déjà vers une valeur de dictionnaire, une tentative sera faite pour le convertir.
Tcl_Obj *keyPtr (in)
Pointe vers la clé de la paire clé-valeur à manipuler dans la valeur du dictionnaire.
Tcl_Obj **keyPtrPtr (out)
Pointe vers une variable qui contiendra la clé d'une paire clé-valeur. Peut être NULL pour indiquer que l'appelant ne s'intéresse pas à la clé.
Tcl_Obj *valuePtr (in)
Pointe vers la valeur de la paire clé-valeur à manipuler dans la valeur du dictionnaire (ou sous-valeur dans le cas de Tcl_DictObjPutKeyList).
Tcl_Obj **valuePtrPtr (out)
Pointe vers une variable qui contiendra la valeur d'une paire clé-valeur. Pour Tcl_DictObjFirst et Tcl_DictObjNext, cela peut être NULL pour indiquer que l'appelant ne s'intéresse pas à la valeur.
int *sizePtr (out)
Pointe vers une variable qui contiendra le nombre de paires clé-valeur dans le dictionnaire.
Tcl_DictSearch *searchPtr (in/out)
Pointeur vers une structure pour suivre la progression dans l'énumération de toutes les paires clé-valeur d'un dictionnaire. Le contenu de la structure est initialisé par l'appel à Tcl_DictObjFirst. Si l'énumération doit être terminée avant que toutes les valeurs du dictionnaire aient été renvoyées, la structure de recherche doit être passée à Tcl_DictObjDone pour libérer les verrous internes.
int *donePtr (out)
Pointe vers une variable qui contiendra une valeur non nulle si le processus d'énumération des paires clé-valeur du dictionnaire est terminé, et zéro sinon.
int keyc (in)
Indique le nombre de clés à fournir dans le tableau keyv.
Tcl_Obj *const *keyv (in)
Tableau de keyc pointeurs vers des valeurs que Tcl_DictObjPutKeyList et Tcl_DictObjRemoveKeyList utiliseront pour localiser la paire clé-valeur à manipuler dans les sous-dictionnaires de la valeur principale du dictionnaire.

DESCRIPTION

Les valeurs de dictionnaire Tcl ont une représentation interne qui permet un mappage efficace des clés aux valeurs et garantit que l'ordre des clés dans le dictionnaire reste le même, sauf lorsque des clés sont supprimées ou ajoutées (ce qui les retire de leur position ou les ajoute à la fin de l'ordre). Si elles sont interprétées comme une liste, les valeurs aux indices pairs de la liste seront les clés du dictionnaire, et chacune sera suivie (à l'indice impair) par la valeur associée à cette clé.

Les procédures décrites dans cette page de manuel sont utilisées pour créer, modifier, indexer et itérer sur les valeurs de dictionnaire à partir du code C.

Tcl_NewDictObj crée une nouvelle valeur de dictionnaire vide. La représentation string de la valeur sera invalide et le compteur de références de la valeur sera de zéro.

Tcl_DictObjGet recherche la clé donnée dans le dictionnaire et écrit un pointeur vers la valeur associée à cette clé dans la variable indiquée par valuePtrPtr, ou NULL s'il n'y a pas de mappage de clé dans le dictionnaire. Le résultat de cette opération est TCL_OK, ou TCL_ERROR si dictPtr ne peut pas être converti en un dictionnaire.

Tcl_DictObjPut met à jour le dictionnaire de manière à ce que la clé donnée mappe à la valeur donnée ; une clé peut exister dans le dictionnaire au maximum une fois. Le dictionnaire ne doit pas être partagé, mais la clé et la valeur le peuvent. Cette procédure peut incrémenter le compte de références de la clé et de la valeur si nécessaire pour les stocker. Ni la clé ni la valeur ne doivent être NULL. Le résultat de cette opération est TCL_OK, ou TCL_ERROR si dictPtr ne peut pas être converti en un dictionnaire.

Tcl_DictObjRemove met à jour le dictionnaire de manière à ce que la clé donnée ne mappe plus à aucune valeur. Le dictionnaire ne doit pas être partagé, mais la clé le peut. La clé réellement stockée dans le dictionnaire verra son compte de références décrémenté s'il existait. Ce n'est pas une erreur si la clé n'existait pas auparavant. Le résultat de cette opération est TCL_OK, ou TCL_ERROR si dictPtr ne peut pas être converti en un dictionnaire.

Tcl_DictObjSize met à jour la variable donnée avec le nombre de paires clé-valeur actuellement dans le dictionnaire. Le résultat de cette opération est TCL_OK, ou TCL_ERROR si dictPtr ne peut pas être converti en un dictionnaire.

Tcl_DictObjFirst démarre une itération sur toutes les paires clé-valeur du dictionnaire, plaçant la clé et la valeur dans les variables indiquées par keyPtrPtr et valuePtrPtr (qui peuvent être NULL pour indiquer que l'appelant ne s'y intéresse pas). La paire clé-valeur suivante dans le dictionnaire peut être obtenue avec Tcl_DictObjNext. Les mises à jour concurrentes de la représentation interne du dictionnaire ne modifieront pas le processus d'itération, sauf si le dictionnaire n'est pas partagé, auquel cas cela provoquera la fin anticipée du processus d'itération (ce qui ne peut pas être provoqué par la commande dict dans les scripts Tcl). L'argument searchPtr pointe vers un contexte utilisé pour identifier l'itération particulière en cours, et est initialisé par l'appel à Tcl_DictObjFirst. L'argument donePtr pointe vers une variable qui est mise à zéro s'il reste des paires clé-valeur à itérer, ou à une valeur non nulle si l'itération est complète. L'ordre d'itération est défini par l'implémentation. Si dictPtr ne peut pas être converti en un dictionnaire, Tcl_DictObjFirst renvoie TCL_ERROR et l'itération ne commencera pas, sinon il renvoie TCL_OK.

Lorsque Tcl_DictObjFirst est appelé sur un dictionnaire, un verrou est placé sur le dictionnaire pour permettre à ce dictionnaire d'être itéré en toute sécurité, indépendamment du fait que le dictionnaire soit modifié pendant l'itération. Par conséquent, une fois que l'itération sur les clés d'un dictionnaire est terminée (soit parce que la dernière valeur a été itérée, indiqué par l'argument donePtr mis à un, soit parce qu'aucune autre valeur n'est requise), Tcl_DictObjDone doit être appelé avec le même searchPtr qui a été passé à Tcl_DictObjFirst pour libérer les verrous internes. Une fois qu'un searchPtr particulier est passé à Tcl_DictObjDone, passer à Tcl_DictObjNext (sans l'avoir initialisé avec Tcl_DictObjFirst) produira zéro valeur et la variable indiquée par donePtr sera mise à un. Il est sûr d'appeler Tcl_DictObjDone plusieurs fois sur le même searchPtr pour chaque appel à Tcl_DictObjFirst

Les procédures Tcl_DictObjPutKeyList et Tcl_DictObjRemoveKeyList sont des analogues proches de Tcl_DictObjPut et Tcl_DictObjRemove, sauf qu'elles fonctionnent avec un seul dictionnaire, conçu pour opérer sur une structure arborescente de dictionnaires imbriqués, où les dictionnaires internes sont stockés en tant que valeurs dans les dictionnaires externes. Les arguments keyc et keyv spécifient une liste de clés (avec les clés externes en premier) qui agit comme un chemin vers la paire clé-valeur à affecter. EXEMPLE

Utilisation de l'interface d'itération de dictionnaire pour rechercher et déterminer s'il existe une clé qui se mappe à elle-même :

Tcl_DictSearch search;
Tcl_Obj *key, *value;
int done;
/*
 * Supposez que interp et objPtr sont des paramètres. C'est la manière
 * idiomatique de commencer une itération sur le dictionnaire ; elle
 * verrouille la représentation interne, garantissant qu'il n'y a pas de problèmes
 * de modification concurrente lorsque la gestion normale des compteurs de références
 * est également utilisée. Le verrou est automatiquement libéré lorsque la boucle est terminée,
 * mais doit être libéré manuellement en cas de sortie exceptionnelle de la boucle.
 * Cependant, il est sûr d'essayer de libérer le verrou même si nous avons fini
 * d'itérer sur la boucle.
 */
if (Tcl_DictObjFirst(interp, objPtr, &search,
        &key, &value, &done) != TCL_OK) {
    return TCL_ERROR;
}
for (; !done ; Tcl_DictObjNext(&search, &key, &value, &done)) {
    /*
     * Notez que strcmp() n'est pas une bonne façon de comparer
     * les valeurs et est juste utilisé ici à des fins de démonstration.
     */
    if (!strcmp(Tcl_GetString(key), Tcl_GetString(value))) {
        break;
    }
}
Tcl_DictObjDone(&search);
Tcl_SetObjResult(interp, Tcl_NewBooleanObj(!done));
return TCL_OK;
