NOM

Tcl_GetOpenFile - Retourne un FILE* pour un canal enregistré dans l'interpréteur donné (Unix uniquement)

SYNTAXE

#include <tcl.h>

int
Tcl_GetOpenFile(interp, chanID, write, checkUsage, filePtr)

ARGUMENTS

Tcl_Interp *interp (entrée)
Interpréteur Tcl à partir duquel le descripteur de fichier doit être obtenu.
const char *chanID (entrée)
Chaîne identifiant le canal, tel que stdin ou file4.
int write (entrée)
Non nul si le fichier sera utilisé en écriture, nul s'il sera utilisé en lecture.
int checkUsage (entrée)
Si non nul, une erreur sera générée si le fichier n'a pas été ouvert pour l'accès indiqué par write.
ClientData *filePtr (sortie)
Pointe vers un mot dans lequel stocker le pointeur vers la structure FILE du fichier donné par chanID.

DESCRIPTION

Tcl_GetOpenFile prend comme argument un identificateur de fichier de la forme retournée par la commande open et retourne à *filePtr un pointeur vers la structure FILE du fichier. L'argument write indique si le pointeur FILE sera utilisé pour la lecture ou l'écriture. Dans certains cas, comme un canal qui se connecte à un pipeline de sous-processus, différents pointeurs FILE seront retournés pour la lecture et l'écriture. Tcl_GetOpenFile retourne normalement TCL_OK. Si une erreur survient dans Tcl_GetOpenFile (par exemple, chanID n'avait aucun sens ou checkUsage était activé et le fichier n'a pas été ouvert pour l'accès spécifié par write), alors TCL_ERROR est retourné et le résultat de l'interpréteur contiendra un message d'erreur. Dans l'implémentation actuelle, checkUsage est ignoré et les vérifications de cohérence sont toujours effectuées.

Notez que cette interface n'est prise en charge que sur la plateforme Unix.
