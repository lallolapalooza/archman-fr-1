Tcl_Namespace(3) Procédures de la bibliothèque Tcl Tcl_Namespace(3)

NAME

Tcl_AppendExportList, Tcl_CreateNamespace, Tcl_DeleteNamespace, Tcl_Export, Tcl_FindCommand, Tcl_FindNamespace, Tcl_ForgetImport, Tcl_GetCurrentNamespace, Tcl_GetGlobalNamespace, Tcl_GetNamespaceUnknownHandler, Tcl_Import, Tcl_SetNamespaceUnknownHandler - manipuler les espaces de noms

Tcl_DeleteNamespace(nsPtr)

int
Tcl_AppendExportList(interp, nsPtr, objPtr)

int
Tcl_Export(interp, nsPtr, pattern, resetListFirst)

int
Tcl_Import(interp, nsPtr, pattern, allowOverwrite)

int
Tcl_ForgetImport(interp, nsPtr, pattern)

Tcl_Namespace *
Tcl_GetCurrentNamespace(interp)

Tcl_Namespace *
Tcl_GetGlobalNamespace(interp)

Tcl_Namespace *
Tcl_FindNamespace(interp, name, contextNsPtr, flags)

Tcl_Command
Tcl_FindCommand(interp, name, contextNsPtr, flags)

Tcl_Obj *
Tcl_GetNamespaceUnknownHandler(interp, nsPtr)

int
Tcl_SetNamespaceUnknownHandler(interp, nsPtr, handlerPtr)

ARGUMENTS

Tcl_Interp *interp (in/out)
L'interpréteur dans lequel l'espace de noms existe et où les recherches de noms sont effectuées. C'est aussi là que les messages de résultat d'erreur sont écrits.
const char *name (in)
Le nom de l'espace de noms ou de la commande à créer ou à accéder.
ClientData clientData (in)
Un pointeur de contexte fourni par le créateur de l'espace de noms. Non interprété par Tcl.
Tcl_NamespaceDeleteProc *deleteProc (in)
Un pointeur vers une fonction qui sera appelée lorsque l'espace de noms sera supprimé, ou NULL si aucun rappel n'est souhaité.
Tcl_Namespace *nsPtr (in)
L'espace de noms à manipuler, ou NULL (pour des fonctions autres que Tcl_DeleteNamespace).
Tcl_Obj *objPtr (out)
Une référence vers une valeur non partagée dans laquelle le résultat de la fonction sera écrit.
const char *pattern (in)
Le modèle de type glob (voir Tcl_StringMatch) qui décrit les commandes à importer ou à exporter.
int resetListFirst (in)
Si la liste des modèles d'exportation doit être réinitialisée avant d'y ajouter le modèle courant.
int allowOverwrite (in)
Si les nouvelles commandes créées par cette action d'importation peuvent écraser des commandes existantes.
Tcl_Namespace *contextNsPtr (in)
L'endroit dans la hiérarchie des espaces de noms où l'espace de noms ou la commande doit être recherché lorsque le terme de recherche n'est pas ancré dans l'espace de noms global. NULL indique l'espace de noms courant.
int flags (in)
OR bit à bit qui contrôle comment la recherche sera effectuée. Les drapeaux suivants sont compatibles : TCL_GLOBAL_ONLY (indique que la recherche est toujours effectuée dans l'espace de noms global), TCL_NAMESPACE_ONLY (uniquement pour Tcl_FindCommand ; indique que la recherche est toujours effectuée dans l'espace de noms de contexte), et TCL_LEAVE_ERR_MSG (indique qu'un message d'erreur doit être laissé dans l'interpréteur si la recherche échoue).
Tcl_Obj *handlerPtr (in)
Un fragment de script à installer comme gestionnaire de commandes inconnues pour l'espace de noms, ou NULL pour réinitialiser le gestionnaire à sa valeur par défaut.

DESCRIPTION

Les espaces de noms sont des contextes de nommage hiérarchiques qui peuvent contenir des commandes et des variables. Ils maintiennent également une liste de modèles décrivant quelles commandes sont exportées, et peuvent importer des commandes qui ont été exportées par d'autres espaces de noms. Les espaces de noms peuvent également être manipulés via la commande Tcl namespace.

La structure Tcl_Namespace encapsule un espace de noms, et il est garanti qu'elle contient les champs suivants : name (le nom local de l'espace de noms, sans les caractères séparateurs d'espaces de noms, vide dénotant l'espace de noms global), fullName (le nom complètement spécifié de l'espace de noms), clientData, deleteProc (les valeurs spécifiées dans l'appel à Tcl_CreateNamespace), et parentPtr (un pointeur vers l'espace de noms parent, ou NULL pour l'espace de noms global).

Tcl_CreateNamespace crée un nouvel espace de noms. Le deleteProc aura la signature de type suivante :

typedef void Tcl_NamespaceDeleteProc(
        ClientData clientData);

Tcl_DeleteNamespace supprime un espace de noms, en appelant le deleteProc défini pour celui-ci (s'il existe).

Tcl_AppendExportList récupère les modèles d'exportation d'un espace de noms donné et les ajoute (en tant qu'éléments de liste) à objPtr.

Tcl_Export définit et ajoute aux modèles d'exportation d'un espace de noms. Les modèles sont ajoutés sauf si resetListFirst est actif.

Tcl_Import importe les commandes correspondant à un modèle dans un espace de noms. Note : le modèle doit inclure le nom de l'espace de noms à partir duquel importer. Cette fonction renvoie TCL_ERROR si l'on tente d'importer une commande sur une existante, sauf si allowOverwrite est actif.

Tcl_ForgetImport supprime les importations correspondant à un modèle.

Tcl_GetCurrentNamespace renvoie l'espace de noms courant pour un interpréteur.

Tcl_GetGlobalNamespace renvoie l'espace de noms global pour un interpréteur.

Tcl_FindNamespace recherche un espace de noms nommé name dans le contexte de l'espace de noms contextNsPtr. Si l'espace de noms n'est pas trouvé, NULL est renvoyé.

Tcl_FindCommand recherche une commande nommée name dans le contexte de l'espace de noms contextNsPtr. Si la commande n'est pas trouvée, NULL est renvoyé.

Tcl_GetNamespaceUnknownHandler renvoie le gestionnaire de commandes inconnues pour l'espace de noms, ou NULL s'il n'est pas défini.

Tcl_SetNamespaceUnknownHandler définit le gestionnaire de commandes inconnues pour l'espace de noms. Si handlerPtr est NULL, le gestionnaire est réinitialisé à sa valeur par défaut.
