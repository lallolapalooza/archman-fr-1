Tcl_GetGlobalNamespace(3) Procédures de la bibliothèque Tcl Tcl_GetGlobalNamespace(3)

NAME

Tcl_AppendExportList, Tcl_CreateNamespace, Tcl_DeleteNamespace, Tcl_Export, Tcl_FindCommand, Tcl_FindNamespace, Tcl_ForgetImport, Tcl_GetCurrentNamespace, Tcl_GetGlobalNamespace, Tcl_GetNamespaceUnknownHandler, Tcl_Import, Tcl_SetNamespaceUnknownHandler - manipulation des espaces de noms

int
Tcl_Export(interp, nsPtr, pattern, resetListFirst)

int
Tcl_Import(interp, nsPtr, pattern, allowOverwrite)

int
Tcl_ForgetImport(interp, nsPtr, pattern)

Tcl_Namespace *
Tcl_GetCurrentNamespace(interp)

Tcl_Namespace *
Tcl_GetGlobalNamespace(interp)

Tcl_Namespace *
Tcl_FindNamespace(interp, name, contextNsPtr, flags)

Tcl_Command

Tcl_Obj *
Tcl_GetNamespaceUnknownHandler(interp, nsPtr)

int
Tcl_SetNamespaceUnknownHandler(interp, nsPtr, handlerPtr)

ARGUMENTS

Tcl_Interp *interp (in/out)
L'interpréteur dans lequel l'espace de noms existe et où les recherches de noms sont effectuées. C'est également l'endroit où les messages d'erreur de résultat sont écrits.
const char *name (in)
Le nom de l'espace de noms ou de la commande à créer ou à accéder.
ClientData clientData (in)
Un pointeur de contexte fourni par le créateur de l'espace de noms. Il n'est pas interprété par Tcl.
Tcl_NamespaceDeleteProc *deleteProc (in)
Un pointeur vers une fonction qui est appelée lorsque l'espace de noms est supprimé, ou NULL si aucune fonction de rappel ne doit être exécutée.
Tcl_Namespace *nsPtr (in)
L'espace de noms à manipuler, ou NULL (pour les autres que Tcl_DeleteNamespace) pour manipuler l'espace de noms actuel.
Tcl_Obj *objPtr (out)
Une référence à une valeur non partagée vers laquelle la sortie de la fonction sera écrite.
const char *pattern (in)
Le motif de style glob (voir Tcl_StringMatch) qui décrit les commandes à importer ou à exporter.
int resetListFirst (in)
Faut-il réinitialiser la liste des motifs d'exportation avant d'y ajouter le motif actuel ?
int allowOverwrite (in)
Les nouvelles commandes créées par cette action d'importation peuvent-elles écraser des commandes existantes ?
Tcl_Namespace *contextNsPtr (in)
L'endroit dans l'arborescence des espaces de noms où rechercher l'espace de noms ou la commande, par rapport au cas où le terme de recherche n'est pas racine dans l'espace de noms global. NULL indique l'espace de noms actuel.
int flags (in)
La combinaison OR de bits contrôlant la manière dont la recherche sera effectuée. Les drapeaux suivants sont pris en charge : TCL_GLOBAL_ONLY (indique que la recherche est toujours effectuée par rapport à l'espace de noms global), TCL_NAMESPACE_ONLY (uniquement pour Tcl_FindCommand ; indique que la recherche est toujours effectuée par rapport à l'espace de noms de contexte), et TCL_LEAVE_ERR_MSG (indique qu'un message d'erreur doit être laissé dans l'interpréteur si la recherche échoue).
Tcl_Obj *handlerPtr (in)
Un fragment de code de script à installer comme gestionnaire de commandes inconnues pour l'espace de noms, ou NULL pour réinitialiser le gestionnaire à sa valeur par défaut.

DESCRIPTION

Les espaces de noms sont des contextes de noms hiérarchiques qui peuvent contenir des commandes et des variables. Ils maintiennent également une liste de motifs décrivant quelles commandes sont exportées, et peuvent importer des commandes qui ont été exportées par d'autres espaces de noms. Les espaces de noms peuvent également être manipulés via la commande Tcl namespace.

La structure Tcl_Namespace encapsule un espace de noms, et il est garanti qu'elle contient les champs suivants : name (le nom local de l'espace de noms, sans séparateur d'espace de noms, une chaîne vide indiquant l'espace de noms global), fullName (le nom complet de l'espace de noms), clientData, deleteProc (les valeurs spécifiées lors de l'appel à Tcl_CreateNamespace), et parentPtr (un pointeur vers l'espace de noms conteneur, ou NULL pour l'espace de noms global).

Tcl_CreateNamespace crée un nouvel espace de noms. Le deleteProc aura la signature de type suivante :

typedef void Tcl_NamespaceDeleteProc(
        ClientData clientData);

Tcl_DeleteNamespace supprime un espace de noms, en appelant le deleteProc défini pour l'espace de noms (s'il existe).

Tcl_AppendExportList récupère les motifs d'exportation pour un espace de noms donné et les ajoute (en tant qu'éléments de liste) à objPtr.

Tcl_Export définit et ajoute des motifs d'exportation à un espace de noms. Les motifs sont ajoutés, sauf si resetListFirst est vrai.

Tcl_Import importe les commandes correspondant à un motif dans un espace de noms. Il convient de noter que le motif doit inclure le nom de l'espace de noms à partir duquel l'importation est effectuée. Cette fonction retourne TCL_ERROR si une tentative d'importation d'une commande sur une commande existante est effectuée, sauf si allowOverwrite est activé.

Tcl_ForgetImport supprime les importations correspondant à un motif.

Tcl_GetCurrentNamespace renvoie l'espace de noms actuel pour un interpréteur.

Tcl_GetGlobalNamespace renvoie l'espace de noms global pour un interpréteur.

Tcl_FindNamespace recherche un espace de noms nommé name dans le contexte de l'espace de noms contextNsPtr. Si l'espace de noms n'est pas trouvé, NULL est renvoyé.

Tcl_FindCommand recherche une commande nommée name dans le contexte de l'espace de noms contextNsPtr. Si la commande n'est pas trouvée, NULL est renvoyé.

Tcl_GetNamespaceUnknownHandler renvoie le gestionnaire de commandes inconnues pour l'espace de noms, ou NULL si aucun n'est configuré.

Tcl_SetNamespaceUnknownHandler définit le gestionnaire de commandes inconnues pour l'espace de noms. Si handlerPtr est NULL, le gestionnaire est réinitialisé à sa valeur par défaut.
