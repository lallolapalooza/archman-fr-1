ARGUMENTS

Tcl_Interp *interp (in)
Si une erreur survient lors de la conversion d'une valeur à utiliser comme valeur de dictionnaire, un message d'erreur est laissé dans le résultat de l'interpréteur, sauf si interp est NULL.
Tcl_Obj *dictPtr (in/out)
Pointe vers la valeur de dictionnaire à manipuler. Si dictPtr ne pointe pas déjà vers une valeur de dictionnaire, une tentative sera faite pour la convertir.
Tcl_Obj *keyPtr (in)
Pointe vers la clé pour la paire clé/valeur manipulée dans la valeur de dictionnaire.
Tcl_Obj **keyPtrPtr (out)
Pointe vers une variable qui recevra la clé d'une paire clé/valeur. Peut être NULL pour indiquer que l'appelant ne s'intéresse pas à la clé.
Tcl_Obj *valuePtr (in)
Pointe vers la valeur de la paire clé/valeur manipulée dans la valeur de dictionnaire (ou sous-valeur, dans le cas de Tcl_DictObjPutKeyList.)
Tcl_Obj **valuePtrPtr (out)
Pointe vers une variable qui recevra la valeur d'une paire clé/valeur. Pour Tcl_DictObjFirst et Tcl_DictObjNext, ceci peut être NULL pour indiquer que l'appelant ne s'intéresse pas à la valeur.
int *sizePtr (out)
Pointe vers une variable qui recevra le nombre de paires clé/valeur contenues dans le dictionnaire.
Tcl_DictSearch *searchPtr (in/out)
Pointeur vers l'enregistrement à utiliser pour suivre la progression dans l'énumération de toutes les paires clé/valeur d'un dictionnaire. Le contenu de l'enregistrement sera initialisé par l'appel à Tcl_DictObjFirst. Si l'énumération doit être terminée avant que toutes les valeurs du dictionnaire aient été renvoyées, l'enregistrement de recherche doit être passé à Tcl_DictObjDone pour permettre la libération des verrous internes.
int *donePtr (out)
Pointe vers une variable qui recevra une valeur non nulle lorsque l'énumération des paires clé/valeur d'un dictionnaire sera terminée, et zéro sinon.
int keyc (in)
Indique le nombre de clés qui seront fournies dans le tableau keyv.
Tcl_Obj *const *keyv (in)
Tableau de keyc pointeurs vers des valeurs que Tcl_DictObjPutKeyList et Tcl_DictObjRemoveKeyList utiliseront pour localiser la paire clé/valeur à manipuler dans les sous-dictionnaires de la valeur de dictionnaire principale qui leur est passée.

DESCRIPTION

Les valeurs de dictionnaire Tcl ont une représentation interne qui prend en charge le mappage efficace des clés aux valeurs et qui garantit que l'ordre particulier des clés dans le dictionnaire reste le même modulo les clés qui sont supprimées (ce qui les retire de l'ordre) ou ajoutées (ce qui les ajoute à la fin de l'ordre). Si réinterprétées comme une liste, les valeurs aux indices pairs de la liste seront les clés du dictionnaire, et chacune sera suivie (à l'indice impair) de la valeur associée à cette clé.

Les procédures décrites dans cette page de manuel sont utilisées pour créer, modifier, indexer et itérer sur les valeurs de dictionnaire à partir du code C.

Tcl_NewDictObj crée une nouvelle valeur de dictionnaire vide. La représentation textuelle de la valeur sera invalide, et le compteur de références de la valeur sera zéro.

Tcl_DictObjGet recherche la clé donnée dans le dictionnaire donné et écrit un pointeur vers la valeur associée à cette clé dans la variable pointée par valuePtrPtr, ou NULL si la clé n'a pas de correspondance dans le dictionnaire. Le résultat de cette procédure est TCL_OK, ou TCL_ERROR si dictPtr ne peut pas être converti en dictionnaire.

Tcl_DictObjPut met à jour le dictionnaire donné de sorte que la clé donnée mappe à la valeur donnée ; chaque clé peut exister au maximum une fois dans un dictionnaire particulier. Le dictionnaire ne doit pas être partagé, mais la clé et la valeur le peuvent. Cette procédure peut augmenter le compteur de références de la clé et de la valeur s'il s'avère nécessaire de les stocker. Ni la clé ni la valeur ne doivent être NULL. Le résultat de cette procédure est TCL_OK, ou TCL_ERROR si dictPtr ne peut pas être converti en dictionnaire.

Tcl_DictObjRemove met à jour le dictionnaire donné de sorte que la clé donnée n'ait aucune correspondance avec une valeur. Le dictionnaire ne doit pas être partagé, mais la clé peut l'être. La clé réellement stockée dans le dictionnaire aura son compteur de références décrémenté si elle était présente. Ce n'est pas une erreur si la clé n'existait pas auparavant. Le résultat de cette procédure est TCL_OK, ou TCL_ERROR si dictPtr ne peut pas être converti en dictionnaire.

Tcl_DictObjSize met à jour la variable donnée avec le nombre de paires clé/valeur actuellement dans le dictionnaire donné. Le résultat de cette procédure est TCL_OK, ou TCL_ERROR si dictPtr ne peut pas être converti en dictionnaire.

Tcl_DictObjFirst commence une itération sur toutes les paires clé/valeur du dictionnaire donné, plaçant la clé et la valeur dans les variables pointées par les arguments keyPtrPtr et valuePtrPtr (qui peuvent être NULL pour indiquer que l'appelant ne s'intéresse pas à la clé ou à la variable respectivement.) La paire clé/valeur suivante dans le dictionnaire peut être récupérée avec Tcl_DictObjNext. Les mises à jour concurrentes de la représentation interne du dictionnaire ne modifieront pas le traitement de l'itération, sauf si le dictionnaire n'est pas partagé, auquel cas cela déclenchera une terminaison prématurée de l'itération (ce que les scripts Tcl ne peuvent pas déclencher via la commande dict.) L'argument searchPtr pointe vers un bloc de contexte utilisé pour identifier quelle itération particulière est en cours, et est initialisé par l'appel à Tcl_DictObjFirst. L'argument donePtr pointe vers une variable qui est mise à jour à zéro s'il y a d'autres paires clé/valeur à itérer, ou à non-zéro si l'itération est complète. L'ordre d'itération est défini par l'implémentation. Si l'argument dictPtr ne peut pas être converti en dictionnaire, Tcl_DictObjFirst renvoie TCL_ERROR et l'itération n'est pas commencée, sinon elle renvoie TCL_OK.

Lorsque Tcl_DictObjFirst est appelé sur un dictionnaire, un verrou est placé sur le dictionnaire pour permettre à ce dictionnaire d'être itéré en toute sécurité sans tenir compte des modifications apportées au dictionnaire pendant l'itération. Pour cette raison, une fois que l'itération sur les clés d'un dictionnaire est terminée (soit parce que toutes les valeurs ont été itérées, comme indiqué par la mise à jour de la variable indiquée par l'argument donePtr à un, soit parce qu'aucune valeur supplémentaire n'est requise), la fonction Tcl_DictObjDone doit être appelée avec le même searchPtr que celui passé à Tcl_DictObjFirst afin que les verrous internes puissent être libérés. Une fois qu'un searchPtr particulier est passé à Tcl_DictObjDone, le passer à Tcl_DictObjNext (sans l'avoir d'abord initialisé avec Tcl_DictObjFirst) entraînera la production d'aucune valeur et la mise à zéro de la variable pointée par donePtr. Il est sûr d'appeler Tcl_DictObjDone plusieurs fois sur le même searchPtr pour chaque appel à Tcl_DictObjFirst.

Les procédures Tcl_DictObjPutKeyList et Tcl_DictObjRemoveKeyList sont les analogues directs de Tcl_DictObjPut et Tcl_DictObjRemove respectivement, sauf qu'au lieu de travailler avec un seul dictionnaire, elles sont conçues pour fonctionner sur un arbre imbriqué de dictionnaires, avec des dictionnaires internes stockés comme valeurs à l'intérieur de dictionnaires externes. Les arguments keyc et keyv spécifient une liste de clés (avec les clés les plus externes en premier) qui agit comme un chemin vers la paire clé/valeur à affecter. Notez qu'il n'y a pas d'opération correspondante pour lire une valeur pour un chemin de clés.

NOM

Tcl_DictObjFirst

SYNTAXE

Tcl_DictObjFirst(interp, objPtr, search, key, value, done)

ARGUMENTS

interp - Interpréteur

objPtr - Objet dictionnaire

search - Objet de recherche de dictionnaire

key - Clé

value - Valeur

done - Booléen

DESCRIPTION

Tcl_DictObjFirst retourne la première paire clé-valeur du dictionnaire. L'objet de recherche est initialisé avec la première clé et la première valeur. Le verrou est automatiquement libéré lorsque la boucle est terminée, mais doit être libéré manuellement en cas de sortie exceptionnelle de la boucle. Cependant, il est sûr d'essayer de libérer le verrou même si nous avons terminé l'itération de la boucle.

EXEMPLE

Utilisation de l'interface d'itération de dictionnaire pour rechercher et déterminer s'il existe une clé qui correspond à elle-même :

Tcl_DictSearch search;
Tcl_Obj *key, *value;
int done;
/*
 * Supposons que interp et objPtr sont des paramètres. C'est la
 * manière idiomatique de commencer une itération sur le dictionnaire ; cela
 * place un verrou sur la représentation interne qui garantit
 * qu'il n'y a pas de problèmes de modification concurrente lorsque la gestion
 * normale du compteur de références est également utilisée. Le verrou est
 * automatiquement libéré lorsque la boucle est terminée, mais doit
 * être libéré manuellement en cas de sortie exceptionnelle de la boucle.
 * Cependant, il est sûr d'essayer de libérer le verrou
 * même si nous avons terminé l'itération de la boucle.
 */
if (Tcl_DictObjFirst(interp, objPtr, &search,
        &key, &value, &done) != TCL_OK) {
    return TCL_ERROR;
}
for (; !done ; Tcl_DictObjNext(&search, &key, &value, &done)) {
    /*
     * Notez que strcmp() n'est pas une bonne façon de comparer
     * les valeurs et est juste utilisé ici à des fins de démonstration.
     */
    if (!strcmp(Tcl_GetString(key), Tcl_GetString(value))) {
        break;
    }
}
Tcl_DictObjDone(&search);
Tcl_SetObjResult(interp, Tcl_NewBooleanObj(!done));
return TCL_OK;
