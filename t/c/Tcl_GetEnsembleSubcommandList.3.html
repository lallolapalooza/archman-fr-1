ARGUMENTS

Tcl_Interp *interp (in/out)
L'interpréteur dans lequel la commande d'ensemble sera créée ou trouvée. C'est également là que les messages de résultat d'erreur seront écrits. Les fonctions commençant par Tcl_GetEnsemble peuvent avoir un interp nul, mais toutes les autres fonctions ne le peuvent pas.
const char *name (in)
Le nom de la commande d'ensemble à créer.
Tcl_Namespace *namespacePtr (in)
L'espace de noms dans lequel la commande d'ensemble sera liée, ou NULL pour l'espace de noms actuel.
int ensFlags (in)
Un ensemble d'indicateurs OR-és qui décrivent la configuration de base de l'ensemble. Actuellement, un seul indicateur est significatif, TCL_ENSEMBLE_PREFIX, qui est présent lorsque la commande d'ensemble doit également correspondre aux préfixes ambigus des sous-commandes.
Tcl_Obj *cmdNameObj (in)
Une valeur contenant le nom de la commande d'ensemble à rechercher.
int flags (in)
Un ensemble d'indicateurs OR-és qui contrôlent le comportement de Tcl_FindEnsemble. Actuellement, seul TCL_LEAVE_ERR_MSG est pris en charge.
Tcl_Command token (in)
Un jeton de commande normal qui fait référence à une commande d'ensemble, ou qui doit être testé comme une commande d'ensemble dans Tcl_IsEnsemble.
int *ensFlagsPtr (out)
Un pointeur vers une variable dans laquelle les indicateurs actuels de l'ensemble sont écrits ; actuellement, seul l'indicateur TCL_ENSEMBLE_PREFIX est défini.
Tcl_Obj *dictObj (in)
Un objet dictionnaire utilisé pour le mappage des sous-commandes à la chaîne de préfixe de commande d'implémentation dans l'ensemble. Peut être NULL si le dictionnaire de mappage doit être supprimé.
Tcl_Obj **dictObjPtr (out)
Un pointeur vers une variable dans laquelle le dictionnaire de mappage de sous-commandes actuel est écrit.
Tcl_Obj *listObj (in)
Un objet liste utilisé pour la liste des paramètres formels des sous-commandes, la liste définie des sous-commandes dans le dictionnaire, ou la chaîne de préfixe de commande pour la gestion des sous-commandes inconnus. Peut être NULL si la liste des sous-commandes ou la gestion des sous-commandes inconnus doit être supprimée.
Tcl_Obj **listObjPtr (out)
Un pointeur vers une variable dans laquelle la liste des paramètres formels des sous-commandes, la liste définie des sous-commandes, ou le préfixe actuel de gestion des sous-commandes inconnus est écrit.
Tcl_Namespace **namespacePtrPtr (out)
Un pointeur vers une variable dans laquelle le handle de l'espace de noms dans lequel l'ensemble est lié est écrit.

DESCRIPTION

Un ensemble est une commande, liée à un espace de noms, qui se compose d'une collection de sous-commandes implémentées par d'autres commandes Tcl. Le premier argument de la commande d'ensemble est toujours interprété comme un sélecteur indiquant quelle sous-commande exécuter.

Les ensembles sont créés à l'aide de Tcl_CreateEnsemble, qui prend quatre arguments : l'interpréteur dans lequel opérer, le nom de l'ensemble à créer, l'espace de noms dans l'interpréteur auquel lier l'ensemble, et l'ensemble d'indicateurs par défaut pour l'ensemble. Le résultat de la fonction est le jeton de commande pour l'ensemble, qui peut être utilisé pour configurer l'ensemble à l'aide de l'API décrite dans PROPRIÉTÉS DE L'ENSEMBLE.

Étant donné le nom d'une commande d'ensemble, le jeton de cette commande peut être récupéré à l'aide de Tcl_FindEnsemble. Si le nom donné (dans cmdNameObj) ne fait pas référence à une commande d'ensemble, le résultat de la fonction est NULL et, si l'indicateur TCL_LEAVE_ERR_MSG est défini dans flags, un message d'erreur est laissé dans le résultat de l'interpréteur.

Un jeton de commande peut être vérifié pour voir s'il fait référence à un ensemble à l'aide de Tcl_IsEnsemble. Cela renvoie 1 si le jeton fait référence à un ensemble, ou 0 sinon.

PROPRIÉTÉS DE L'ENSEMBLE

Chaque ensemble a quatre propriétés en lecture/écriture et une propriété en lecture seule. Les propriétés sont :

indicateurs (lecture/écriture)
L'ensemble d'indicateurs représentant les drapeaux de l'ensemble, exprimés sous forme de champ de bits. Actuellement, le seul drapeau public est TCL_ENSEMBLE_PREFIX, qui est défini lorsque les préfixes ambigus des sous-commandes sont autorisés à être résolus en implémentations ainsi qu'en correspondances exactes. Les indicateurs peuvent être lus et écrits à l'aide de Tcl_GetEnsembleFlags et Tcl_SetEnsembleFlags respectivement. Le résultat de ces deux fonctions est un code de résultat Tcl (TCL_OK, ou TCL_ERROR si le jeton ne fait pas référence à un ensemble).
dictionnaire de mappage (lecture/écriture)
Un dictionnaire contenant un mappage des noms de sous-commandes à des listes de mots qui sont utilisés comme préfixe de commande (remplaçant les deux premiers mots de la commande, qui sont la commande d'ensemble et le nom de sous-commande), ou NULL si chaque sous-commande est mappée à une commande du même nom non qualifié dans l'espace de noms de l'ensemble. Par défaut, il est NULL. Il peut être lu et écrit à l'aide de Tcl_GetEnsembleMappingDict et Tcl_SetEnsembleMappingDict respectivement. Le résultat de ces deux fonctions est un code de résultat Tcl (TCL_OK, ou TCL_ERROR si le jeton ne fait pas référence à un ensemble) et le dictionnaire obtenu de Tcl_GetEnsembleMappingDict doit toujours être traité comme immuable, même s'il n'est pas partagé. Tous les noms de commande dans les préfixes définis via Tcl_SetEnsembleMappingDict doivent être entièrement qualifiés.
liste des paramètres formels des sous-commandes (lecture/écriture)
Une liste de noms de paramètres formels (utilisés uniquement lors de la génération de messages d'erreur) qui sont invoqués entre le nom de l'ensemble et l'argument de sous-commande. NULL (par défaut) équivaut à une liste vide. Il peut être lu et écrit à l'aide de Tcl_GetEnsembleParameterList et Tcl_SetEnsembleParameterList respectivement. Le résultat de ces deux fonctions est un code de résultat Tcl (TCL_OK, ou TCL_ERROR si le jeton ne fait pas référence à un ensemble) et le dictionnaire obtenu de Tcl_GetEnsembleParameterList doit toujours être traité comme immuable, même s'il n'est pas partagé.
liste des noms de sous-commandes (lecture/écriture)
Une liste de tous les noms de sous-commandes pour l'ensemble, ou NULL si celle-ci est dérivée des clés du dictionnaire de mappage (voir ci-dessus) ou (si cela est également NULL) des commandes exportées par l'espace de noms lié. Elle peut être lue et écrite à l'aide de Tcl_GetEnsembleSubcommandList et Tcl_SetEnsembleSubcommandList respectivement. Le résultat de ces deux fonctions est un code de résultat Tcl (TCL_OK, ou TCL_ERROR si le jeton ne fait pas référence à un ensemble) et la liste obtenue de Tcl_GetEnsembleSubcommandList doit toujours être traitée comme immuable, même si elle n'est pas partagée.
préfixe de commande pour gérer les sous-commandes inconnus (lecture/écriture)
Une liste de mots qui sont ajoutés au début de toute sous-commande lorsqu'elle est inconnue de l'ensemble (selon le préfixe de gestion actuel). Elle peut être lue et écrite à l'aide de Tcl_GetEnsembleUnknownHandler et Tcl_SetEnsembleUnknownHandler respectivement. Le résultat de ces deux fonctions est un code de résultat Tcl (TCL_OK, ou TCL_ERROR si le jeton ne fait pas référence à un ensemble).

NOM

Tcl_GetEnsembleSubcommandList

SYNTAXE

Tcl_GetEnsembleSubcommandList(ensemble, sous-commande, liste)

ARGUMENTS

ensemble sous-commande liste

DESCRIPTION

Récupère la liste des sous-commandes pour l'ensemble spécifié. Si la liste est NULL, le comportement par défaut - générer un message d'erreur approprié - sera utilisé lorsqu'une sous-commande inconnue est rencontrée. Peut être lu et écrit respectivement à l'aide de Tcl_GetEnsembleSubcommandList et Tcl_SetEnsembleSubcommandList. Le résultat des deux fonctions est un code de résultat Tcl (TCL_OK, ou TCL_ERROR si le jeton ne fait pas référence à un ensemble) et la liste obtenue à partir de Tcl_GetEnsembleSubcommandList doit toujours être traitée comme immuable, même si elle n'est pas partagée.
