DESCRIPTION

Les objets sont des entités typées qui ont un ensemble d'opérations ("méthodes") associées. Les classes sont des objets qui peuvent fabriquer des objets. Chaque classe peut être vue comme un objet en soi ; la vue objet peut être récupérée en utilisant Tcl_GetClassAsObject qui renvoie toujours l'objet lorsqu'elle est appliquée à une classe non détruite, et un objet peut être vu comme une classe avec l'aide de Tcl_GetObjectAsClass (qui renvoie soit la classe, soit NULL si l'objet n'est pas une classe). Un objet peut être recherché en utilisant la fonction Tcl_GetObjectFromObj, qui renvoie soit un objet, soit NULL (avec un message d'erreur dans le résultat de l'interpréteur) si l'objet ne peut être trouvé. La manière correcte de rechercher une classe par son nom est de rechercher l'objet portant ce nom, puis d'utiliser Tcl_GetObjectAsClass.

Chaque objet a sa propre commande et son propre espace de noms qui lui sont associés. La commande peut être récupérée en utilisant la fonction Tcl_GetObjectCommand, le nom de l'objet (et donc le nom de la commande) avec Tcl_GetObjectName, et l'espace de noms peut être récupéré en utilisant la fonction Tcl_GetObjectNamespace. Notez que la référence Tcl_Obj renvoyée par Tcl_GetObjectName est une référence partagée. Vous pouvez également savoir si l'objet a été marqué pour suppression avec Tcl_ObjectDeleted (il renvoie vrai si la suppression de l'objet a commencé) ; ceci peut être utile lors du traitement des méthodes.

Les instances de classes sont créées en utilisant Tcl_NewObjectInstance, qui crée un objet à partir de n'importe quelle classe (et qui est appelée en interne par les méthodes create et new de la classe oo::class). Elle prend des paramètres qui spécifient éventuellement le nom de l'objet et de l'espace de noms à créer, et qui décrivent les arguments à passer au constructeur de la classe (le cas échéant). Le résultat de la fonction sera soit une référence au nouvel objet créé, soit NULL si la création a échoué (auquel cas un message d'erreur sera laissé dans le résultat de l'interpréteur). De plus, les objets peuvent être copiés en utilisant Tcl_CopyObjectInstance qui crée une copie d'un objet sans exécuter de constructeurs.

Notez que la gestion de la durée de vie des objets est gérée en interne par TclOO, et n'utilise pas Tcl_Preserve. Il n'est pas sûr de placer une poignée Tcl_Object dans une structure C dont la durée de vie est différente de celle de l'objet ; vous devriez utiliser le nom de la commande de l'objet (tel que récupéré avec Tcl_GetObjectName) à la place. Il est sûr d'utiliser une poignée Tcl_Object pendant la durée de vie d'un appel de méthode sur cet objet ; les poignées ne deviennent pas invalides tant qu'il y a un appel en cours sur leur objet (même si la seule opération garantie d'être sûre sur elles est Tcl_ObjectDeleted ; les autres opérations ne sont garanties de fonctionner que sur les objets non détruits).

MÉTA-DONNÉES OBJET ET CLASSE

Chaque objet et chaque classe peuvent avoir des quantités arbitraires de métadonnées qui y sont attachées, auxquelles l'objet ou la classe n'attribue aucune signification au-delà de ce qui est décrit dans une instance de structure Tcl_ObjectMetadataType. Les métadonnées à attacher sont décrites par le type des métadonnées (donné dans l'argument metaTypePtr) et un pointeur arbitraire (l'argument metadata) qui sont donnés à Tcl_ObjectSetMetadata et Tcl_ClassSetMetadata, et un morceau particulier de métadonnées peut être récupéré en lui donnant son type en utilisant Tcl_ObjectGetMetadata et Tcl_ClassGetMetadata. Si le paramètre metadata de Tcl_ObjectSetMetadata ou Tcl_ClassSetMetadata est NULL, les métadonnées sont supprimées si elles étaient attachées, et les résultats de Tcl_ObjectGetMetadata et Tcl_ClassGetMetadata sont NULL si le type de métadonnées donné n'était pas attaché. Ce n'est pas une erreur de demander ou de supprimer un élément de métadonnées qui n'était pas attaché.

STRUCTURE TCL_OBJECTMETADATATYPE

Le contenu de la structure Tcl_ObjectMetadataType est le suivant :

typedef const struct {
    int version;
    const char *name;
    Tcl_ObjectMetadataDeleteProc *deleteProc;
    Tcl_CloneProc *cloneProc;
} Tcl_ObjectMetadataType;

Le champ version permet une expansion future de la structure, et doit toujours être déclaré égal à TCL_OO_METADATA_VERSION_CURRENT. Le champ name fournit un nom lisible par l'homme pour le type, et est réservé au débogage.

Le champ deleteProc donne une fonction de type Tcl_ObjectMetadataDeleteProc qui est utilisée pour supprimer un morceau de métadonnées particulier, et est appelée lorsque les métadonnées attachées sont remplacées ou supprimées ; le champ ne doit pas être NULL.

Le champ cloneProc donne une fonction qui est utilisée pour copier un morceau de métadonnées (utilisé lorsqu'une copie d'un objet est créée en utilisant Tcl_CopyObjectInstance) ; si NULL, les métadonnées seront simplement copiées directement.
