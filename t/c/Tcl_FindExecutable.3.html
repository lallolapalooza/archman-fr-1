Paquet: tcl

Licences: TCL

Tcl_FindExecutable(3) Procédures de la bibliothèque Tcl Tcl_FindExecutable(3)

NOM

Tcl_FindExecutable, Tcl_GetNameOfExecutable - identifier ou retourner le nom du fichier binaire contenant l'application

SYNOPHIS

#include <tcl.h>

void
Tcl_FindExecutable(argv0)

const char *
Tcl_GetNameOfExecutable()

ARGUMENTS

char *argv0 (entrée)
Le premier argument de ligne de commande du programme, qui donne le nom de l'application.

DESCRIPTION

La procédure Tcl_FindExecutable calcule le chemin complet du fichier exécutable à partir duquel l'application a été invoquée et le sauvegarde pour l'utilisation interne de Tcl. Le nom du chemin de l'exécutable est nécessaire à plusieurs fins dans Tcl. Par exemple, il est nécessaire sur certaines plateformes dans l'implémentation de la commande load. Il est également retourné par la commande info nameofexecutable.

Sur les plateformes UNIX, cette procédure est généralement invoquée dès la première chose dans le programme principal de l'application ; elle doit recevoir argv[0] comme argument. Il est important de ne pas changer le répertoire de travail avant l'invocation. Tcl_FindExecutable utilise argv0 ainsi que la variable d'environnement PATH pour trouver l'exécutable de l'application, si possible. S'il ne parvient pas à trouver le binaire, les appels futurs à info nameofexecutable retourneront une chaîne vide.

Sur les plateformes Windows, cette procédure est généralement invoquée dès la première chose dans le programme principal de l'application ; son argument argv[0] est uniquement utilisé pour indiquer si l'exécutable a un canal stderr (toute valeur non nulle) ou non (la valeur nulle). Si Tcl_SetPanicProc n'est jamais appelé et qu'aucun débogueur n'est en cours d'exécution, cela détermine si le message de panique est envoyé à stderr ou à une boîte de dialogue système standard.

Tcl_GetNameOfExecutable retourne simplement un pointeur vers le nom de chemin complet interne du fichier exécutable tel que calculé par Tcl_FindExecutable. Cet appel de procédure est l'équivalent API C de la commande info nameofexecutable. NULL est retourné si le nom de chemin complet interne n'a pas été calculé ou est inconnu.
