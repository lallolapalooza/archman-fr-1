Tcl_SplitList(3) Procédures de la Bibliothèque Tcl Tcl_SplitList(3)

NOM

Tcl_SplitList, Tcl_Merge, Tcl_ScanElement, Tcl_ConvertElement, Tcl_ScanCountedElement, Tcl_ConvertCountedElement - manipulation de listes Tcl

SYNOPSIS

#include <tcl.h>

int
Tcl_SplitList(interp, list, argcPtr, argvPtr)

char *
Tcl_Merge(argc, argv)

int
Tcl_ScanElement(src, flagsPtr)

int
Tcl_ScanCountedElement(src, length, flagsPtr)

int
Tcl_ConvertElement(src, dst, flags)

int
Tcl_ConvertCountedElement(src, length, dst, flags)

ARGUMENTS

Tcl_Interp *interp (out)
Interpréteur à utiliser pour le rapport d'erreurs. S'il est NULL, aucun message d'erreur n'est laissé.
const char *list (in)
Pointeur vers une chaîne avec une structure de liste correcte.
int *argcPtr (out)
rempli avec le nombre d'éléments dans list.
const char ***argvPtr (out)
*argvPtr sera rempli avec l'adresse d'un tableau de pointeurs vers les chaînes qui sont les éléments extraits de list. Il y a *argcPtr entrées valides dans le tableau, suivies d'un NULL.
int argc (in)
Nombre d'éléments dans argv.
const char *const *argv (in)
Tableau de chaînes à fusionner pour former une liste. Chaque chaîne deviendra un élément de la liste.
const char *src (in)
Chaîne à convertir en un élément de liste.
int *flagsPtr (in)
Pointeur vers une variable entière à remplir avec des informations sur src. La valeur de *flagsPtr doit être passée à Tcl_ConvertElement.
int length (in)
Nombre d'octets dans la chaîne src.
char *dst (in)
Emplacement où copier l'élément de liste converti. Il doit contenir suffisamment de caractères pour stocker la chaîne convertie.
int flags (in)
Informations sur src. Il doit s'agir de la valeur retournée par un appel précédent à Tcl_ScanElement, éventuellement OR'ée avec TCL_DONT_USE_BRACES.

DESCRIPTION

Ces procédures peuvent être utilisées pour désassembler et réassembler des listes Tcl. Tcl_SplitList décompose une liste en ses éléments constitutifs, retournant un tableau de pointeurs vers les éléments en utilisant argcPtr et argvPtr. Lors de l'extraction des arguments, Tcl_SplitList suit les règles normales de substitution de backslash et d'accolades. La zone mémoire pointée par *argvPtr est dynamique ; en plus du tableau de pointeurs, elle contient également des copies de tous les éléments de la liste. Il incombe à l'appelant de libérer cet espace. Par exemple, si Tcl_SplitList a été appelée avec le code suivant :

int argc, code;
char *string;
char **argv;
...
code = Tcl_SplitList(interp, string, &argc, &argv);

Vous devez libérer l'espace avec un appel similaire au suivant :

Tcl_Free((char *) argv);

Tcl_SplitList retourne normalement TCL_OK, ce qui signifie que la liste a été analysée avec succès. S'il y a une erreur de syntaxe dans list, TCL_ERROR est retourné et le résultat de l'interpréteur pointera vers un message d'erreur décrivant le problème (si interp n'est pas NULL). Si TCL_ERROR est retourné, aucune mémoire n'est allouée et *argvPtr n'est pas modifié.

Tcl_Merge est l'inverse de Tcl_SplitList : elle prend un ensemble de chaînes données par argc et argv et génère une chaîne résultante correctement structurée en tant que liste. Cela signifie que des commandes telles que index peuvent être utilisées à nouveau pour extraire les éléments d'origine. De plus, si le résultat de Tcl_Merge est passé à Tcl_Eval, il sera analysé en argc mots dont les valeurs seront identiques aux chaînes argv passées à Tcl_Merge. Tcl_Merge modifiera les éléments de liste avec des accolades et/ou des backslashes pour produire une structure de liste correcte. La chaîne résultante est stockée dynamiquement avec Tcl_Alloc ; l'appelant doit libérer l'espace avec Tcl_Free.

Si le résultat de Tcl_Merge est passé à Tcl_SplitList, les éléments retournés par Tcl_SplitList seront identiques à ceux passés à Tcl_Merge. Cependant, l'inverse n'est pas vrai : si Tcl_SplitList est passée une chaîne donnée et que les résultats argc et argv sont passés à Tcl_Merge, la chaîne résultante peut ne pas être identique à celle passée à l'origine à Tcl_SplitList. Cela est dû au fait que Tcl_Merge peut gérer les backslashes et les accolades différemment de la chaîne d'origine.

Tcl_ScanElement et Tcl_ConvertElement sont les procédures qui effectuent tout le travail de Tcl_Merge. Tcl_ScanElement analyse son argument src et détermine comment utiliser les backslashes et les accolades lorsqu'il le convertit en élément de liste. Il retourne une estimation du nombre de caractères nécessaires pour représenter src en tant qu'élément de liste, et stocke des informations dans *flagsPtr qui sont nécessaires à Tcl_ConvertElement.

Tcl_ConvertElement est une procédure compagnon de Tcl_ScanElement. Elle effectue le travail réel de conversion d'une chaîne en élément de liste. Son argument flags doit être identique à la valeur retournée par Tcl_ScanElement. Tcl_ConvertElement écrit un élément de liste correct dans la mémoire à partir de *dst et retourne le nombre total de caractères écrits, qui ne sera pas supérieur au résultat retourné par Tcl_ScanElement. Tcl_ConvertElement n'écrit que l'élément de liste réel sans espaces au début ou à la fin : c'est à l'appelant d'inclure les espaces entre les éléments de liste adjacents.

Tcl_ConvertElement utilise l'une des deux approches différentes pour gérer les caractères spéciaux dans src. Si possible, elle gère cela en encadrant la chaîne avec des accolades. Cela produit une sortie propre, mais ne peut pas être utilisé dans certaines situations, comme lorsque src contient des accolades non équilibrées. Dans ces cas, Tcl_ConvertElement gère les caractères spéciaux en générant des séquences de backslash. L'appelant peut insister sur la seconde approche en OR'ant la valeur de retour de Tcl_ScanElement avec TCL_DONT_USE_BRACES. Bien que cela produise un résultat plus laid, c'est utile dans certaines situations spéciales, comme lorsque Tcl_ConvertElement est utilisé pour générer une partie d'un argument pour une commande Tcl. Dans ce cas, encadrer src avec des accolades ferait que la commande ne serait pas analysée correctement.

Par défaut, Tcl_ConvertElement utilisera le guillemet pour s'assurer que le premier caractère d'un élément n'est pas le caractère dièse (“#”). Ceci est pour s'assurer que le premier élément de toute liste passée à eval ne soit pas mal interprété comme le début d'un commentaire. Lorsqu'un élément de liste n'est pas le premier élément d'une liste, ces guillemets ne sont pas nécessaires. Lorsque l'appelant peut s'assurer que l'élément n'est pas le premier élément d'une liste, il peut désactiver le guillemet du caractère dièse en OR'ant la valeur retournée par Tcl_ScanElement avec TCL_DONT_QUOTE_HASH.

Tcl_ScanCountedElement et Tcl_ConvertCountedElement sont identiques à Tcl_ScanElement et Tcl_ConvertElement, sauf que la longueur de la chaîne src est spécifiée par l'argument length, et que la chaîne peut contenir des zéros au milieu.
