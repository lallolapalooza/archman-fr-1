Tcl_ValidateAllMemory(3)

Paquet: tcl

Licences: TCL

Tcl_DumpActiveMemory(3) Procédures de bibliothèque Tcl Tcl_DumpActiveMemory(3)

NOM

Tcl_DumpActiveMemory, Tcl_InitMemory, Tcl_ValidateAllMemory - Interface d'allocation de mémoire validée

SYNOPIS

#include <tcl.h>

int
Tcl_DumpActiveMemory(fileName)

void
Tcl_InitMemory(interp)

void
Tcl_ValidateAllMemory(fileName, line)

ARGUMENTS

Tcl_Interp *interp (in)
Interpréteur Tcl dans lequel ajouter des commandes.
const char *fileName (in)
Pour Tcl_DumpActiveMemory, nom du fichier vers lequel les informations de mémoire seront écrites. Pour Tcl_ValidateAllMemory, nom du fichier d'où provient l'appel (normalement __FILE__).
int line (in)
Numéro de ligne auquel l'appel à Tcl_ValidateAllMemory est effectué (normalement __LINE__).

DESCRIPTION

Ces fonctions fournissent l'accès aux informations de débogage de la mémoire Tcl. Elles ne sont fonctionnelles que lorsque Tcl a été compilé avec TCL_MEM_DEBUG défini au moment de la compilation. Lorsque TCL_MEM_DEBUG n'est pas défini, ces fonctions sont toutes des opérations nulles.

Tcl_DumpActiveMemory générera une liste de toute la mémoire actuellement allouée vers le fichier spécifié. Les informations générées pour chaque bloc de mémoire alloué sont : adresses de début et de fin (excluant la zone de garde), taille, fichier source où ckalloc a été appelé pour allouer le bloc et numéro de ligne dans ce fichier. Il est particulièrement utile d'appeler Tcl_DumpActiveMemory après la suppression de l'interpréteur Tcl.

Tcl_InitMemory ajoute la commande memory Tcl à l'interpréteur fourni par interp. Tcl_InitMemory est appelée par Tcl_Main.

Tcl_ValidateAllMemory force une validation des zones de garde de tous les blocs de mémoire actuellement alloués. Normalement, la validation d'un bloc se produit lorsqu'il est libéré, sauf si la validation complète est activée, auquel cas la validation de tous les blocs se produit lorsque ckalloc et ckfree sont appelés. Cette fonction force la validation à se produire à tout moment.
