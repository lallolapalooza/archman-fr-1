ARGUMENTS

Tcl_Interp *interp (entrée/sortie)
L'interpréteur dans lequel l'ensemble doit être créé ou trouvé. C'est aussi là que les messages d'erreur sont écrits. Les fonctions dont le nom commence par Tcl_GetEnsemble peuvent avoir un NULL pour interp, mais toutes les autres fonctions ne le peuvent pas.
const char *name (entrée)
Le nom de la commande d'ensemble à créer.
Tcl_Namespace *namespacePtr (entrée)
L'espace de noms auquel la commande d'ensemble doit être liée, ou NULL pour l'espace de noms courant.
int ensFlags (entrée)
Un ensemble de bits de drapeaux OR'és décrivant la configuration de base de l'ensemble. Actuellement, seul un bit a une signification, TCL_ENSEMBLE_PREFIX, qui est présent lorsque la commande d'ensemble doit également correspondre aux préfixes non ambigus des sous-commandes.
Tcl_Obj *cmdNameObj (entrée)
Une valeur contenant le nom de la commande d'ensemble à rechercher.
int flags (entrée)
Un ensemble de bits de drapeaux OR'és contrôlant le comportement de Tcl_FindEnsemble. Actuellement, seul TCL_LEAVE_ERR_MSG est pris en charge.
Tcl_Command token (entrée)
Un jeton de commande normal qui fait référence à une commande d'ensemble, ou que vous souhaitez utiliser pour tester comme commande d'ensemble dans Tcl_IsEnsemble.
int *ensFlagsPtr (sortie)
Pointeur vers une variable dans laquelle écrire les bits de drapeaux d'ensemble actuels ; actuellement, seul le bit TCL_ENSEMBLE_PREFIX est défini.
Tcl_Obj *dictObj (entrée)
Une valeur de dictionnaire à utiliser pour le mappage de la sous-commande au préfixe de commande d'implémentation dans l'ensemble. Peut être NULL si le dictionnaire de mappage doit être supprimé.
Tcl_Obj **dictObjPtr (sortie)
Pointeur vers une variable dans laquelle écrire le dictionnaire de mappage d'ensemble actuel.
Tcl_Obj *listObj (entrée)
Une valeur de liste à utiliser pour la liste des paramètres formels avant la sous-commande, la liste définie des sous-commandes dans le dictionnaire ou le préfixe de commande du gestionnaire de sous-commandes inconnu. Peut être NULL si la liste des sous-commandes ou le gestionnaire inconnu doivent être supprimés.
Tcl_Obj **listObjPtr (sortie)
Pointeur vers une variable dans laquelle écrire la liste actuelle des paramètres formels avant la sous-commande, la liste définie des sous-commandes ou le préfixe du gestionnaire inconnu actuel.
Tcl_Namespace **namespacePtrPtr (sortie)
Pointeur vers une variable dans laquelle écrire le handle de l'espace de noms auquel l'ensemble est lié.

DESCRIPTION

Un ensemble est une commande, liée à un certain espace de noms, qui consiste en une collection de sous-commandes implémentées par d'autres commandes Tcl. Le premier argument de la commande d'ensemble est toujours interprété comme un sélecteur qui indique quelle sous-commande exécuter.

Les ensembles sont créés à l'aide de Tcl_CreateEnsemble, qui prend quatre arguments : l'interpréteur dans lequel travailler, le nom de l'ensemble à créer, l'espace de noms dans l'interpréteur auquel lier l'ensemble, et l'ensemble par défaut des drapeaux d'ensemble. Le résultat de la fonction est le jeton de commande pour l'ensemble, qui peut être utilisé pour configurer davantage l'ensemble à l'aide de l'API décrite ci-dessous sous PROPRIÉTÉS DE L'ENSEMBLE.

Étant donné le nom d'une commande d'ensemble, le jeton de cette commande peut être récupéré à l'aide de Tcl_FindEnsemble. Si le nom de commande donné (dans cmdNameObj) ne fait pas référence à une commande d'ensemble, le résultat de la fonction est NULL et (si le bit TCL_LEAVE_ERR_MSG est défini dans flags) un message d'erreur est laissé dans le résultat de l'interpréteur.

Un jeton de commande peut être vérifié pour voir s'il fait référence à un ensemble à l'aide de Tcl_IsEnsemble. Cela renvoie 1 si le jeton fait référence à un ensemble, ou 0 sinon.

PROPRIÉTÉS DE L'ENSEMBLE

Chaque ensemble a quatre propriétés en lecture-écriture et une propriété en lecture seule. Les propriétés sont :

drapeaux (lecture-écriture)
L'ensemble des drapeaux pour l'ensemble, exprimé sous forme de champ de bits. Actuellement, le seul drapeau public est TCL_ENSEMBLE_PREFIX qui est défini lorsque les préfixes non ambigus des sous-commandes sont autorisés à être résolus en implémentations, ainsi que les correspondances exactes. Les drapeaux peuvent être lus et écrits à l'aide de Tcl_GetEnsembleFlags et Tcl_SetEnsembleFlags respectivement. Le résultat de ces deux fonctions est un code de résultat Tcl (TCL_OK, ou TCL_ERROR si le jeton ne fait pas référence à un ensemble).
dictionnaire de mappage (lecture-écriture)
Un dictionnaire contenant un mappage des noms de sous-commandes aux listes de mots à utiliser comme préfixe de commande (remplaçant les deux premiers mots de la commande qui sont la commande d'ensemble elle-même et le nom de la sous-commande), ou NULL si chaque sous-commande doit être mappée à la commande du même nom non qualifié dans l'espace de noms lié de l'ensemble. Par défaut, NULL. Peut être lu et écrit à l'aide de Tcl_GetEnsembleMappingDict et Tcl_SetEnsembleMappingDict respectivement. Le résultat de ces deux fonctions est un code de résultat Tcl (TCL_OK, ou TCL_ERROR si le jeton ne fait pas référence à un ensemble) et le dictionnaire obtenu de Tcl_GetEnsembleMappingDict doit toujours être traité comme immuable même s'il n'est pas partagé. Tous les noms de commandes dans les préfixes définis via Tcl_SetEnsembleMappingDict doivent être entièrement qualifiés.
liste de paramètres formels avant la sous-commande (lecture-écriture)
Une liste de noms de paramètres formels (les noms n'étant utilisés que lors de la génération de messages d'erreur) qui se trouvent à l'invocation de l'ensemble entre le nom de l'ensemble et l'argument de sous-commande. NULL (par défaut) équivaut à la liste vide. Peut être lu et écrit à l'aide de Tcl_GetEnsembleParameterList et Tcl_SetEnsembleParameterList respectivement. Le résultat de ces deux fonctions est un code de résultat Tcl (TCL_OK, ou TCL_ERROR si le jeton ne fait pas référence à un ensemble) et le dictionnaire obtenu de Tcl_GetEnsembleParameterList doit toujours être traité comme immuable même s'il n'est pas partagé.
liste des sous-commandes (lecture-écriture)
Une liste de tous les noms de sous-commandes pour l'ensemble, ou NULL si cela doit être dérivé soit des clés du dictionnaire de mappage (voir ci-dessus), soit (si celui-ci est également NULL) de l'ensemble des commandes exportées par l'espace de noms lié. Peut être lu et écrit à l'aide de Tcl_GetEnsembleSubcommandList et Tcl_SetEnsembleSubcommandList respectivement. Le résultat de ces deux fonctions est un code de résultat Tcl (TCL_OK, ou TCL_ERROR si le jeton ne fait pas référence à un ensemble) et la liste obtenue de Tcl_GetEnsembleSubcommandList doit toujours être traitée comme immuable même si elle n'est pas partagée.
préfixe de commande du gestionnaire de sous-commandes inconnu (lecture-écriture)
Une liste de mots à préfixer au début de toute sous-commande lorsque la sous-commande est inconnue de l'ensemble (selon la règle actuelle de gestion des préfixes)

ENSEMBLE_UNSPECIFIED_UNKNOWN_HANDLER

Dans le cas où une sous-commande inconnue est invoquée, elle peut être traitée en appelant le gestionnaire inconnu spécifié par cette propriété. Si cette propriété est NULL (la valeur par défaut), alors une sous-commande inconnue déclenche une erreur standard.

Le gestionnaire inconnu est généralement une commande Tcl. L'invocation de celle-ci se fait en lui passant la liste des mots définie dans la propriété, et en sus les mots qui composent le reste de la commande qui n'a pas pu être résolue. Si le gestionnaire inconnu réussit, le résultat de celui-ci est le résultat de la commande d'ensemble.

Les fonctions Tcl_GetEnsembleUnknownHandler et Tcl_SetEnsembleUnknownHandler sont utilisées pour lire et écrire cette propriété. Le résultat de ces deux fonctions est un code de résultat Tcl (TCL_OK, ou TCL_ERROR si le jeton ne fait pas référence à un ensemble) et la liste obtenue de Tcl_GetEnsembleUnknownHandler doit toujours être traitée comme immuable même si elle n'est pas partagée.

La dernière propriété est la seule propriété en lecture seule :

espace de noms (lecture seule)
Ceci est l'espace de noms auquel l'ensemble est lié. La fonction Tcl_GetEnsembleNamespace permet de lire cette propriété.

NOM

Tcl_GetEnsembleNamespace.3

SYNTAXE

Tcl_GetEnsembleNamespace

ARGUMENTS

token

DESCRIPTION

Le namespace lié est le namespace auquel l'ensemble est lié ; lorsque le namespace est supprimé, l'ensemble le sera aussi, et ce namespace est également celui dont la liste des commandes exportées est utilisée si le dictionnaire de mappage et la liste des sous-commandes sont NULL. Peut être lu en utilisant Tcl_GetEnsembleNamespace qui renvoie un code de résultat Tcl (TCL_OK, ou TCL_ERROR si le token ne fait pas référence à un ensemble).

VOIR AUSSI

namespace(n), Tcl_DeleteCommandFromToken(3)
