Tcl_NuevoObjetoInt(3) Procédures de la bibliothèque Tcl Tcl_NuevoObjetoInt(3)

NAME

Tcl_NuevoObjetoInt, Tcl_NuevoLongObj, Tcl_NuevoObjetoIntEspecífico, Tcl_SetIntObj, Tcl_SetLongObj, Tcl_SetObjetoIntEspecífico, Tcl_GetIntFromObj, Tcl_GetLongFromObj, Tcl_GetObjetoIntEspecífico, Tcl_NuevoObjetoBignum, Tcl_SetObjetoBignum, Tcl_GetObjetoBignumFromObj, Tcl_TomarObjetoBignumFromObj - manipuler les valeurs Tcl comme des entiers

SYNOPSIS

#include <tcl.h>

Tcl_Obj *
Tcl_NuevoObjetoInt(intValue)

Tcl_Obj *
Tcl_NuevoLongObj(longValue)

Tcl_Obj *
Tcl_NuevoObjetoIntEspecífico(wideValue)

Tcl_SetLongObj(objPtr, longValue)

Tcl_SetObjetoIntEspecífico(objPtr, wideValue)

int
Tcl_GetIntFromObj(interp, objPtr, intPtr)

int
Tcl_GetLongFromObj(interp, objPtr, longPtr)

int
Tcl_GetObjetoIntEspecífico(interp, objPtr, widePtr)


#include <tclTomMath.h>

Tcl_Obj *
Tcl_NuevoObjetoBignum(bigValue)

Tcl_SetObjetoBignum(objPtr, bigValue)

int
Tcl_GetObjetoBignumFromObj(interp, objPtr, bigValue)

int
Tcl_TomarObjetoBignumFromObj(interp, objPtr, bigValue)

int
Tcl_InicializarBignumDesdeDoble(interp, doubleValue, bigValue)

ARGUMENTS

int intValue (en)
Valeur entière utilisée pour initialiser ou définir une valeur Tcl.
long longValue (en)
Valeur entière de 64 bits utilisée pour initialiser ou définir une valeur Tcl.
Tcl_WideInt wideValue (en)
Valeur entière de 32 bits utilisée pour initialiser ou définir une valeur Tcl.
Tcl_Obj *objPtr (in/out)
Pour Tcl_SetIntObj, Tcl_SetLongObj, Tcl_SetObjetoIntEspecífico, et Tcl_SetObjetoBignum, ceci pointe vers la valeur dans laquelle une valeur entière sera stockée. Pour Tcl_GetIntFromObj, Tcl_GetLongFromObj, Tcl_GetObjetoIntEspecífico, Tcl_GetObjetoBignumFromObj, et Tcl_TomarObjetoBignumFromObj, ceci fait référence à la valeur à partir de laquelle une valeur entière est obtenue.
Tcl_Interp *interp (in/out)
Lorsqu'il n'est pas NULL, un message d'erreur y est laissé lorsque la récupération de la valeur entière échoue.
int *intPtr (out)
Pointe vers l'emplacement où la valeur entière obtenue à partir de objPtr est stockée.
long *longPtr (out)
Pointe vers l'emplacement où la valeur entière de 64 bits obtenue à partir de objPtr est stockée.
Tcl_WideInt *widePtr (out)
Pointe vers l'emplacement où la valeur entière de 32 bits obtenue à partir de objPtr est stockée.
mp_int *bigValue (in/out)
Pointe vers une structure d'entiers multi-précision déclarée par la bibliothèque LibTomMath.
double doubleValue (en)
Valeur double dont la partie entière est déterminée et utilisée pour initialiser une valeur entière multi-précision.

DESCRIPTION

Ces fonctions sont utilisées pour créer, modifier et lire des valeurs Tcl contenant des valeurs entières.

Différentes routines sont fournies pour s'adapter aux différents types d'entiers C avec lesquels les valeurs peuvent être échangées. Les routines d'échange de valeurs pour les types d'entiers C sont int, long int, Tcl_WideInt et mp_int. Les types int et long int sont fournis par la norme du langage C. Le type Tcl_WideInt est un alias défini pour tout type d'entier signé qui couvre au moins la plage des entiers 64 bits (-9223372036854775808 à 9223372036854775807). Selon la plateforme et le compilateur C, le type réel peut être long int, long long int, __int64 ou quelque chose de similaire. Le type mp_int est un type d'entier multi-précision défini par la bibliothèque multi-précision LibTomMath.

Les routines Tcl_NuevoObjetoInt, Tcl_NuevoLongObj, Tcl_NuevoObjetoIntEspecífico et Tcl_NuevoObjetoBignum créent et retournent une nouvelle valeur Tcl initialisée avec la valeur entière de l'argument. La valeur retournée n'est pas partagée.

Les routines Tcl_SetIntObj, Tcl_SetLongObj, Tcl_SetObjetoIntEspecífico et Tcl_SetObjetoBignum définissent la valeur d'une valeur Tcl existante pointée par objPtr aux valeurs entières fournies par l'autre argument. L'argument objPtr doit pointer vers une valeur Tcl non partagée. Toute tentative de définir la valeur d'une valeur partagée viole la politique de copie à l'écriture de Tcl. La valeur de la représentation interne ou de la représentation chaîne de la valeur non partagée sera libérée suite à la définition de la nouvelle valeur.

Les routines Tcl_GetIntFromObj, Tcl_GetLongFromObj, Tcl_GetObjetoIntEspecífico, Tcl_GetObjetoBignumFromObj et Tcl_TomarObjetoBignumFromObj tentent de récupérer une valeur entière d'un type approprié à partir de la valeur Tcl objPtr. Si la tentative réussit, TCL_OK est retourné et la valeur est écrite dans le stockage fourni par l'appelant. La tentative peut échouer si objPtr ne contient pas de valeur entière ou si la valeur dépasse la plage du type de destination. Si la tentative échoue, TCL_ERROR est retourné et si interp n'est pas NULL, un message d'erreur est laissé dans interp. Le type Tcl_ObjType de objPtr peut être modifié pour rendre les appels ultérieurs à la même routine plus efficaces. Différente des autres fonctions, Tcl_TomarObjetoBignumFromObj peut définir le contenu de la valeur Tcl objPtr en une chaîne vide pendant le processus de récupération de la valeur entière multi-précision.

Le choix entre Tcl_GetObjetoBignumFromObj et Tcl_TomarObjetoBignumFromObj est guidé par la manière dont l'utilisateur utilisera objPtr par la suite. Si, après avoir récupéré la valeur mp_int de objPtr, l'utilisateur n'utilisera plus objPtr, alors l'utilisation de Tcl_TomarObjetoBignumFromObj permet à Tcl de détecter quand une valeur non partagée objPtr permet de déplacer la valeur au lieu de la copier, ce qui devrait être plus efficace. Si une partie ultérieure dans l'utilisateur nécessite que objPtr continue de maintenir la même valeur, alors Tcl_GetObjetoBignumFromObj doit être utilisée.

La routine Tcl_InicializarBignumDesdeDoble est une routine utilitaire qui extrait la partie entière de la valeur doubleValue et stocke cette valeur entière dans la valeur mp_int bigValue.
