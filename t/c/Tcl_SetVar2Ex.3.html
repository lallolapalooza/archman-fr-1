ARGUMENTS

Tcl_Interp *interp (in)
Interpréteur contenant la variable.
const char *name1 (in)
Contient le nom d'une variable de tableau (si name2 n'est pas nul) ou (si name2 est nul) le nom d'une variable scalaire ou un nom complet incluant à la fois le nom de la variable et l'index. Peut inclure :: pour spécifier une variable dans un espace de noms particulier.
const char *name2 (in)
S'il n'est pas nul, donne le nom de l'élément dans le tableau ; dans ce cas, name1 doit faire référence à une variable de tableau.
Tcl_Obj *newValuePtr (in)
Pointeur vers une valeur Tcl contenant la nouvelle valeur de la variable.
int flags (in)
OU au niveau du bit fournissant des informations supplémentaires. Voir ci-dessous pour les valeurs valides.
const char *varName (in)
Nom de la variable. Peut inclure :: pour spécifier une variable dans un espace de noms particulier. Peut faire référence à une variable scalaire ou à un élément de tableau.
const char *newValue (in)
Nouvelle valeur de la variable, spécifiée sous forme de chaîne terminée par null. Une copie de cette valeur sera stockée dans la variable.
Tcl_Obj *part1Ptr (in)
Pointeur vers une valeur Tcl contenant le nom de la variable. Le nom peut inclure une série de :: pour spécifier une variable dans un espace de noms particulier. Peut faire référence à une variable scalaire ou à un élément d'une variable de tableau.
Tcl_Obj *part2Ptr (in)
S'il n'est pas nul, pointe vers une valeur contenant le nom d'un élément dans un tableau et part1Ptr doit faire référence à une variable de tableau.

DESCRIPTION

Ces procédures sont utilisées pour créer, modifier, lire et supprimer des variables Tcl à partir du code C.

Tcl_SetVar2Ex, Tcl_SetVar, Tcl_SetVar2 et Tcl_ObjSetVar2 créeront une nouvelle variable ou modifieront une existante. Ces procédures définissent la valeur donnée par newValuePtr ou newValue dans la variable et renvoient un pointeur vers la nouvelle valeur de la variable, qui est stockée dans la structure de variables Tcl. Tcl_SetVar2Ex et Tcl_ObjSetVar2 reçoivent la nouvelle valeur sous forme de Tcl_Obj et renvoient un pointeur vers un Tcl_Obj. Tcl_SetVar et Tcl_SetVar2 reçoivent la nouvelle valeur sous forme de chaîne et renvoient une chaîne ; elles sont généralement moins efficaces que Tcl_ObjSetVar2. Notez que la valeur renvoyée peut être différente des arguments newValuePtr ou newValue, en raison des modifications apportées par les traceurs d'écriture. Si une erreur se produit lors de la définition de la variable (par exemple, référence à un tableau sans spécifier d'index), NULL est renvoyé et un message d'erreur est laissé dans le résultat de interp si le bit TCL_LEAVE_ERR_MSG est activé.

Tcl_GetVar2Ex, Tcl_GetVar, Tcl_GetVar2 et Tcl_ObjGetVar2 renvoient la valeur actuelle d'une variable. Les arguments de ces procédures sont traités de la même manière que les arguments des procédures décrites ci-dessus. Normalement, la valeur renvoyée est un pointeur vers la valeur de la variable. Pour Tcl_GetVar2Ex et Tcl_ObjGetVar2, la valeur est renvoyée sous forme de pointeur vers un Tcl_Obj. Pour Tcl_GetVar et Tcl_GetVar2, la valeur est renvoyée sous forme de chaîne ; c'est généralement moins efficace, donc Tcl_GetVar2Ex ou Tcl_ObjGetVar2 sont préférés. Si une erreur se produit lors de la lecture de la variable (par exemple, la variable n'existe pas ou un élément de tableau est spécifié pour une variable scalaire), NULL est renvoyé et un message d'erreur est laissé dans le résultat de interp si le bit TCL_LEAVE_ERR_MSG est activé.

Tcl_UnsetVar et Tcl_UnsetVar2 peuvent être utilisés pour supprimer une variable, ce qui entraînera une erreur lors des futures tentatives de lecture. Les arguments de ces procédures sont traités de la même manière que les arguments des procédures précédentes. Si la variable est supprimée avec succès, TCL_OK est renvoyé. Si la variable ne peut pas être supprimée car elle n'existe pas, TCL_ERROR est renvoyé et un message d'erreur est laissé dans le résultat de interp si le bit TCL_LEAVE_ERR_MSG est activé. Si un élément de tableau est spécifié, l'élément donné est supprimé mais le tableau reste. Si un nom de tableau est spécifié sans index, le tableau entier est supprimé.

Le nom d'une variable peut être spécifié à ces procédures de quatre manières :

[1]
Si Tcl_SetVar, Tcl_GetVar ou Tcl_UnsetVar est appelé, le nom de la variable est passé sous forme d'une seule chaîne, varName. Si varName contient une parenthèse ouvrante et se termine par une parenthèse fermante, la valeur entre les parenthèses est traitée comme un index (toute chaîne) et les caractères avant la première parenthèse sont traités comme le nom d'une variable de tableau. Si varName ne contient pas de parenthèses comme décrit ci-dessus, l'ensemble est considéré comme le nom d'une variable scalaire.
[2]
Si name1 et name2 sont fournis et que name2 n'est pas nul, un élément de tableau est spécifié et le nom du tableau et l'index sont déjà séparés par l'appelant : name1 contient le nom et name2 contient l'index. Une erreur se produit si name1 contient une parenthèse ouvrante et se termine par une parenthèse fermante (élément de tableau) et que name2 n'est pas nul.
[3]
Si name2 est nul, name1 est traité comme le nom de la variable dans le cas [1] ci-dessus (peut être une variable scalaire ou un nom d'élément de tableau).

L'argument flags peut être utilisé pour spécifier l'une des plusieurs options aux procédures. Il se compose d'une combinaison OR des bits suivants.

TCL_GLOBAL_ONLY
Normalement, les procédures recherchent les variables comme suit. S'il y a un appel de procédure actif dans interp, la variable est recherchée au niveau d'appel de procédure actuel. Sinon, elle est recherchée d'abord dans l'espace de noms actuel, puis dans l'espace global. Cependant, si ce bit est défini dans flags, la variable est recherchée uniquement dans l'espace global même s'il y a un appel de procédure actif. Si TCL_GLOBAL_ONLY et TCL_NAMESPACE_ONLY sont tous deux donnés, TCL_GLOBAL_ONLY est ignoré.
TCL_NAMESPACE_ONLY
Si ce bit est défini dans flags, la variable est recherchée uniquement dans l'espace de noms actuel ; s'il y a un appel de procédure actif, ses variables sont ignorées et l'espace global est également ignoré, sauf si c'est l'espace de noms actuel.
TCL_LEAVE_ERR_MSG
Si une erreur est renvoyée et que ce bit est défini dans flags, un message d'erreur sera laissé dans le résultat de l'interpréteur, où il pourra être récupéré avec Tcl_GetObjResult ou Tcl_GetStringResult. Si ce bit n'est pas défini, aucun message d'erreur ne sera laissé et le résultat de l'interpréteur ne sera pas modifié.
TCL_APPEND_VALUE
Si ce bit est défini, newValuePtr ou newValue est ajouté à la valeur actuelle au lieu de la remplacer. Si la variable n'est actuellement pas définie, le bit est ignoré. Ce bit est utilisé uniquement par les procédures Tcl_Set*.
TCL_LIST_ELEMENT
Si ce bit est défini, newValue est converti en un élément de liste Tcl valide avant de définir (ou d'ajouter à) la variable. Un espace séparateur sera ajouté avant le nouvel élément.

Dans des circonstances normales, la valeur de retour est un pointeur vers la valeur de la variable (qui est stockée dans la structure de variable de Tcl et ne changera pas avant le prochain appel à Tcl_SetVar ou Tcl_SetVar2). Si la variable ne peut pas être supprimée car elle n'existe pas, TCL_ERROR est retourné. Si un élément de tableau est spécifié, l'élément donné est supprimé mais le tableau reste.
