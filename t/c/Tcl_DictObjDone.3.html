ARGUMENTS

Tcl_Interp *interp (in)
Si une erreur se produit lors de la conversion d'une valeur en une valeur de dictionnaire, un message d'erreur est laissé dans la valeur de résultat de l'interpréteur, à moins que interp ne soit NULL.
Tcl_Obj *dictPtr (in/out)
Pointe vers une valeur de dictionnaire à manipuler. Si dictPtr ne pointe pas déjà vers une valeur de dictionnaire, une tentative sera faite pour la convertir.
Tcl_Obj *keyPtr (in)
Pointe vers la clé de la paire clé/valeur à manipuler dans la valeur du dictionnaire.
Tcl_Obj **keyPtrPtr (out)
Pointe vers une variable qui contiendra la clé d'une paire clé/valeur. Peut être NULL pour indiquer que l'appelant n'est pas intéressé par la clé.
Tcl_Obj *valuePtr (in)
Pointe vers la valeur de la paire clé/valeur à manipuler dans la valeur du dictionnaire (ou sous-valeur, dans le cas de Tcl_DictObjPutKeyList).
Tcl_Obj **valuePtrPtr (out)
Pointe vers une variable qui contiendra la valeur d'une paire clé/valeur. Pour Tcl_DictObjFirst et Tcl_DictObjNext, ceci peut être NULL pour indiquer que l'appelant n'est pas intéressé par la valeur.
int *sizePtr (out)
Pointe vers une variable qui contiendra le nombre de paires clé/valeur dans le dictionnaire.
Tcl_DictSearch *searchPtr (in/out)
Pointe vers un enregistrement utilisé pour suivre la progression dans l'énumération de toutes les paires clé/valeur d'un dictionnaire. Le contenu de l'enregistrement est initialisé par l'appel à Tcl_DictObjFirst. Si l'énumération doit se terminer avant que toutes les valeurs du dictionnaire aient été retournées, l'enregistrement de recherche doit être passé à Tcl_DictObjDone pour libérer les verrous internes.
int *donePtr (out)
Pointe vers une variable qui contiendra une valeur non nulle lorsqu'elle sera écrite lorsque l'énumération des paires clé/valeur dans un dictionnaire est terminée, et zéro sinon.
int keyc (in)
Indique le nombre de clés à utiliser dans le tableau keyv.
Tcl_Obj *const *keyv (in)
Tableau de keyc pointeurs vers des valeurs que Tcl_DictObjPutKeyList et Tcl_DictObjRemoveKeyList utiliseront pour localiser la paire clé/valeur à manipuler dans les sous-dictionnaires de la valeur principale du dictionnaire.

DESCRIPTION

Les valeurs de dictionnaire Tcl ont une représentation interne qui permet une cartographie efficace des clés aux valeurs et garantit que l'ordre des clés dans le dictionnaire reste le même, sauf si les clés sont supprimées (elles sont retirées de l'ordre) ou ajoutées (elles sont ajoutées à la fin de l'ordre). Si elles sont interprétées comme une liste, les valeurs aux indices pairs de la liste seront les clés du dictionnaire, et chacune sera suivie (à l'indice impair) par la valeur associée à cette clé.

Les procédures décrites dans cette page de manuel sont utilisées pour créer, modifier, indexer et itérer sur les valeurs de dictionnaire à partir du code C.

Tcl_NewDictObj crée une nouvelle valeur de dictionnaire vide. La représentation sous forme de chaîne de la valeur sera invalide, et le compteur de références de la valeur sera zéro.

Tcl_DictObjGet recherche la clé donnée dans le dictionnaire donné et écrit un pointeur vers la valeur associée à cette clé dans la variable pointée par valuePtrPtr, ou une valeur NULL s'il n'y a pas de correspondance pour cette clé dans le dictionnaire. Le résultat de cette opération est TCL_OK, ou TCL_ERROR si le dictPtr ne peut pas être converti en dictionnaire.

Tcl_DictObjPut met à jour le dictionnaire de sorte que la clé donnée corresponde à la valeur donnée ; une clé donnée ne peut exister qu'une seule fois dans un dictionnaire donné. Le dictionnaire ne doit pas être partagé, mais la clé et la valeur peuvent l'être. Cette procédure peut incrémenter les compteurs de références de la clé et de la valeur si nécessaire pour les stocker. Ni la clé ni la valeur ne doivent être NULL. Le résultat de cette opération est TCL_OK, ou TCL_ERROR si le dictPtr ne peut pas être converti en dictionnaire.

Tcl_DictObjRemove met à jour le dictionnaire de sorte que la clé donnée ne corresponde à aucune valeur. Le dictionnaire ne doit pas être partagé, mais la clé peut l'être. La clé réellement stockée dans le dictionnaire aura son compteur de références décrémenté si elle était présente. Ce n'est pas une erreur si la clé n'existait pas auparavant. Le résultat de cette opération est TCL_OK, ou TCL_ERROR si le dictPtr ne peut pas être converti en dictionnaire.

Tcl_DictObjSize met à jour la variable donnée avec le nombre de paires clé/valeur actuellement présentes dans le dictionnaire donné. Le résultat de cette opération est TCL_OK, ou TCL_ERROR si le dictPtr ne peut pas être converti en dictionnaire.

Tcl_DictObjFirst commence une itération sur toutes les paires clé/valeur du dictionnaire donné, plaçant la clé et la valeur dans les arguments keyPtrPtr et valuePtrPtr (qui peuvent être NULL pour indiquer que l'appelant n'est pas intéressé par la clé ou la valeur respectivement). La paire clé/valeur suivante dans le dictionnaire peut être obtenue avec Tcl_DictObjNext. Les mises à jour concurrentes de la représentation interne du dictionnaire ne modifieront pas la progression de l'itération, sauf si le dictionnaire n'est pas partagé, auquel cas cela provoquera une terminaison prématurée de l'itération (ce qui ne peut pas être provoqué par la commande dict des scripts Tcl). L'argument searchPtr pointe vers un contexte utilisé pour identifier quelle itération spécifique est en cours, et est initialisé par l'appel à Tcl_DictObjFirst. L'argument donePtr pointe vers une variable mise à jour à zéro lorsqu'il reste des paires clé/valeur à itérer, ou à une valeur non nulle si l'itération est terminée. L'ordre d'itération est défini par le système. Si l'argument dictPtr ne peut pas être converti en dictionnaire, Tcl_DictObjFirst retourne TCL_ERROR et l'itération ne commence pas, et sinon retourne TCL_OK.

Lorsque Tcl_DictObjFirst est appelé sur un dictionnaire, un verrou est placé sur le dictionnaire afin que vous puissiez itérer sur ses clés en toute sécurité, peu importe si le dictionnaire est modifié pendant l'itération. Pour cette raison, une fois que l'itération sur les clés d'un dictionnaire est terminée (soit parce que la valeur indiquée par l'argument donePtr est définie à un, soit parce qu'aucune valeur supplémentaire n'est nécessaire), la fonction Tcl_DictObjDone doit être appelée avec le même searchPtr qui a été passé à Tcl_DictObjFirst pour libérer les verrous internes. Une fois qu'un searchPtr particulier a été passé à Tcl_DictObjDone, le lui passer comme argument à Tcl_DictObjNext (sans d'abord l'initialiser avec Tcl_DictObjFirst) entraînera la production d'aucune valeur et le variable pointé par donePtr sera défini à un. Il est sûr d'appeler Tcl_DictObjDone plusieurs fois sur le même searchPtr pour chaque appel à Tcl_DictObjFirst.

Les procédures Tcl_DictObjPutKeyList et Tcl_DictObjRemoveKeyList sont des analogies proches de Tcl_DictObjPut et Tcl_DictObjRemove respectivement, sauf qu'elles travaillent avec un seul dictionnaire, conçu pour fonctionner sur une structure d'arbres de dictionnaires profondément imbriqués, avec des dictionnaires internes stockés comme valeurs dans des dictionnaires externes. Les arguments keyc et keyv spécifient une liste de clés (avec les clés les plus externes en premier) qui agissent comme un chemin vers la paire clé/valeur à affecter. Notez qu'il n'y a pas d'opération correspondante pour lire une valeur d'un dictionnaire.

Tcl_DictObjDone

ARGUMENTS

Tcl_Obj *search

DESCRIPTION

Tcl_DictObjDone

EXEMPLE

Utilisation de l'interface d'itération de dictionnaire pour rechercher si une clé existe et est associée à elle-même :

Tcl_DictSearch search;
Tcl_Obj *key, *value;
int done;
/*
 * Supposons que interp et objPtr sont des paramètres. C'est la
 * manière idiomatique de commencer une itération sur le dictionnaire ; elle
 * place un verrou sur la représentation interne qui garantit qu'il
 * n'y a pas de problèmes de modification concurrente lorsque la gestion normale
 * des références est également utilisée. Le verrou est
 * libéré automatiquement lorsque la boucle est terminée, mais doit
 * être libéré manuellement lorsqu'une sortie exceptionnelle de la boucle
 * est effectuée. Cependant, il est sûr d'essayer de libérer le verrou
 * même si nous avons terminé l'itération sur la boucle.
 */
if (Tcl_DictObjFirst(interp, objPtr, &search,
        &key, &value, &done) != TCL_OK) {
    return TCL_ERROR;
}
for (; !done ; Tcl_DictObjNext(&search, &key, &value, &done)) {
    /*
     * Notez que strcmp() n'est pas une bonne méthode pour comparer
     * des valeurs et est juste utilisée ici à des fins de démonstration.
     */
    if (!strcmp(Tcl_GetString(key), Tcl_GetString(value))) {
        break;
    }
}
Tcl_DictObjDone(&search);
Tcl_SetObjResult(interp, Tcl_NewBooleanObj(!done));
return TCL_OK;
