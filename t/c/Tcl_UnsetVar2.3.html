Tcl_SetVar(3) Procédures de bibliothèque Tcl Tcl_SetVar(3)

NOM

Tcl_SetVar2Ex, Tcl_SetVar, Tcl_SetVar2, Tcl_ObjSetVar2, Tcl_GetVar2Ex, Tcl_GetVar, Tcl_GetVar2, Tcl_ObjGetVar2, Tcl_UnsetVar, Tcl_UnsetVar2 - manipuler les variables Tcl

SYNOPIS

#include <tcl.h>

Tcl_Obj *
Tcl_SetVar2Ex(interp, name1, name2, newValuePtr, flags)

const char *
Tcl_SetVar(interp, varName, newValue, flags)

const char *
Tcl_SetVar2(interp, name1, name2, newValue, flags)

Tcl_Obj *
Tcl_ObjSetVar2(interp, part1Ptr, part2Ptr, newValuePtr, flags)

Tcl_Obj *
Tcl_GetVar2Ex(interp, name1, name2, flags)

const char *
Tcl_GetVar(interp, varName, flags)

const char *
Tcl_GetVar2(interp, name1, name2, flags)

Tcl_Obj *
Tcl_ObjGetVar2(interp, part1Ptr, part2Ptr, flags)

int
Tcl_UnsetVar(interp, varName, flags)

int
Tcl_UnsetVar2(interp, name1, name2, flags)

ARGUMENTS

Tcl_Interp *interp (en entrée)
Interpréteur contenant la variable.
const char *name1 (en entrée)
Contient le nom d'une variable de type tableau (si name2 n'est pas NULL) ou (si name2 est NULL) soit le nom d'une variable scalaire, soit un nom complet incluant le nom de la variable et son index. Peut inclure des qualifiants de namespace :: pour spécifier une variable dans un namespace particulier.
const char *name2 (en entrée)
S'il n'est pas NULL, donne le nom de l'élément au sein du tableau ; dans ce cas, name1 doit faire référence à une variable de type tableau.
Tcl_Obj *newValuePtr (en entrée)
Pointe vers une valeur Tcl contenant la nouvelle valeur de la variable.
int flags (en entrée)
Combinaison OR-bit à bit de bits fournissant des informations supplémentaires. Voir ci-dessous pour les valeurs valides.
const char *varName (en entrée)
Nom de la variable. Peut inclure des qualifiants de namespace :: pour spécifier une variable dans un namespace particulier. Peut faire référence à une variable scalaire ou à un élément de tableau.
const char *newValue (en entrée)
Nouvelle valeur pour la variable, spécifiée sous forme de chaîne terminée par un null. Une copie de cette valeur est stockée dans la variable.
Tcl_Obj *part1Ptr (en entrée)
Pointe vers une valeur Tcl contenant le nom de la variable. Le nom peut inclure une série de qualifiants de namespace :: pour spécifier une variable dans un namespace particulier. Peut faire référence à une variable scalaire ou à un élément d'une variable de tableau.
Tcl_Obj *part2Ptr (en entrée)
S'il n'est pas NULL, pointe vers une valeur contenant le nom d'un élément au sein d'un tableau et part1Ptr doit faire référence à une variable de type tableau.

DESCRIPTION

Ces procédures sont utilisées pour créer, modifier, lire et supprimer des variables Tcl à partir du code C.

Tcl_SetVar2Ex, Tcl_SetVar, Tcl_SetVar2, et Tcl_ObjSetVar2 créeront une nouvelle variable ou modifieront une existante. Ces procédures définissent la variable donnée à la valeur donnée par newValuePtr ou newValue et renvoient un pointeur vers la nouvelle valeur de la variable, qui est stockée dans la structure de variables de Tcl. Tcl_SetVar2Ex et Tcl_ObjSetVar2 prennent la nouvelle valeur sous forme de Tcl_Obj et renvoient un pointeur vers un Tcl_Obj. Tcl_SetVar et Tcl_SetVar2 prennent la nouvelle valeur sous forme de chaîne et renvoient une chaîne ; elles sont généralement moins efficaces que Tcl_ObjSetVar2. Notez que la valeur de retour peut être différente de l'argument newValuePtr ou newValue, en raison des modifications apportées par les traces d'écriture. Si une erreur survient lors de la définition de la variable (par exemple, une variable de tableau est référencée sans fournir d'index au tableau), NULL est renvoyé et un message d'erreur est laissé dans le résultat de interp si le bit d'indicateur TCL_LEAVE_ERR_MSG est défini.

Tcl_GetVar2Ex, Tcl_GetVar, Tcl_GetVar2, et Tcl_ObjGetVar2 renvoient la valeur actuelle d'une variable. Les arguments de ces procédures sont traités de la même manière que les arguments des procédures décrites ci-dessus. Dans des circonstances normales, la valeur de retour est un pointeur vers la valeur de la variable. Pour Tcl_GetVar2Ex et Tcl_ObjGetVar2, la valeur est renvoyée sous forme de pointeur vers un Tcl_Obj. Pour Tcl_GetVar et Tcl_GetVar2, la valeur est renvoyée sous forme de chaîne ; c'est généralement moins efficace, donc Tcl_GetVar2Ex ou Tcl_ObjGetVar2 sont préférées. Si une erreur survient lors de la lecture de la variable (par exemple, la variable n'existe pas ou un élément de tableau est spécifié pour une variable scalaire), NULL est renvoyé et un message d'erreur est laissé dans le résultat de interp si le bit d'indicateur TCL_LEAVE_ERR_MSG est défini.

Tcl_UnsetVar et Tcl_UnsetVar2 peuvent être utilisées pour supprimer une variable, afin que les tentatives futures de lecture de la variable renvoient une erreur. Les arguments de ces procédures sont traités de la même manière que les arguments des procédures ci-dessus. Si la variable est supprimée avec succès, TCL_OK est renvoyé. Si la variable ne peut pas être supprimée car elle n'existe pas, TCL_ERROR est renvoyé et un message d'erreur est laissé dans le résultat de interp si le bit d'indicateur TCL_LEAVE_ERR_MSG est défini. Si un élément de tableau est spécifié, l'élément donné est supprimé mais le tableau reste. Si un nom de tableau est spécifié sans index, alors le tableau entier est supprimé.

Le nom d'une variable peut être spécifié à ces procédures de quatre manières :

[1]
Si Tcl_SetVar, Tcl_GetVar, ou Tcl_UnsetVar est invoqué, le nom de la variable est donné sous forme de chaîne unique, varName. Si varName contient une parenthèse ouvrante et se termine par une parenthèse fermante, alors la valeur entre les parenthèses est traitée comme un index (qui peut avoir n'importe quelle valeur de chaîne) et les caractères avant la première parenthèse ouvrante sont traités comme le nom d'une variable de tableau. Si varName n'a pas de parenthèses comme décrit ci-dessus, alors la chaîne entière est traitée comme le nom d'une variable scalaire.
[2]
Si les arguments name1 et name2 sont fournis et que name2 n'est pas NULL, alors un élément de tableau est spécifié et le nom du tableau et l'index ont déjà été séparés par l'appelant : name1 contient le nom et name2 contient l'index. Une erreur est générée si name1 contient une parenthèse ouvrante et se termine par une parenthèse fermante (élément de tableau) et name2 n'est pas NULL.
[3]
Si name2 est NULL, name1 est traité de la même manière que varName dans le cas [1] ci-dessus (il peut s'agir d'un nom de variable scalaire ou d'un élément de tableau).

L'argument flags peut être utilisé pour spécifier l'une des plusieurs options aux procédures. Il se compose d'une combinaison OR-bit à bit des bits suivants.

TCL_GLOBAL_ONLY
Dans des circonstances normales, les procédures recherchent les variables comme suit. Si un appel de procédure est actif dans interp, la variable est recherchée au niveau actuel de l'appel de procédure. Sinon, la variable est recherchée d'abord dans le namespace courant, puis dans le namespace global. Cependant, si ce bit est défini dans flags, la variable est recherchée uniquement dans le namespace global, même si un appel de procédure est actif. Si TCL_GLOBAL_ONLY et TCL_NAMESPACE_ONLY sont tous deux donnés, TCL_GLOBAL_ONLY est ignoré.
TCL_NAMESPACE_ONLY
Si ce bit est défini dans flags, la variable est recherchée uniquement dans le namespace courant ; si une procédure est active, ses variables sont ignorées, et le namespace global est également ignoré, sauf s'il s'agit du namespace courant.
TCL_LEAVE_ERR_MSG
Si une erreur est renvoyée et que ce bit est défini dans flags, un message d'erreur sera laissé dans le résultat de l'interpréteur, où il pourra être récupéré avec Tcl_GetObjResult ou Tcl_GetStringResult. Si ce bit d'indicateur n'est pas défini, aucun message d'erreur n'est laissé et le résultat de l'interpréteur ne sera pas modifié.
TCL_APPEND_VALUE
Si ce bit est défini, newValuePtr ou newValue est ajouté à la valeur actuelle au lieu de la remplacer. Si la variable est actuellement indéfinie, le bit est ignoré. Ce bit est uniquement utilisé par les procédures Tcl_Set*.
TCL_LIST_ELEMENT
Si ce bit est défini, newValue est converti en un élément de liste Tcl valide avant de définir (ou d'ajouter à) la variable. Un espace séparateur est ajouté avant le nouve

Tcl_UnsetVar2(3) — Tcl

NAME

Tcl_SetVar, Tcl_SetVar2, Tcl_GetVar, Tcl_GetVar2, Tcl_UnsetVar, Tcl_UnsetVar2 — set, get, and unset variables

SYNOPSIS

#include <tcl.h>

int
Tcl_SetVar(interp, name, value, flags);
int
Tcl_SetVar2(interp, name1, name2, value, flags);
char *
Tcl_GetVar(interp, name, flags);
char *
Tcl_GetVar2(interp, name1, name2, flags);
int
Tcl_UnsetVar(interp, name, flags);
int
Tcl_UnsetVar2(interp, name1, name2, flags);

ARGUMENTS

Tcl_Interp interp
Interpreter in which to access the variable.
const char name
Name of the variable (for Tcl_SetVar, Tcl_GetVar, Tcl_UnsetVar).
const char name1
First part of the variable name (for Tcl_SetVar2, Tcl_GetVar2, Tcl_UnsetVar2). May be NULL if name2 is used to specify the entire name.
const char name2
Second part of the variable name (for Tcl_SetVar2, Tcl_GetVar2, Tcl_UnsetVar2). May be NULL if name1 is used to specify the entire name.
const char value
The value to store in the variable.
int flags
A bitmask of zero or more of the following bits: TCL_GLOBAL_ONLY, TCL_LEAVE_ERR_MSG, TCL_APPEND_VALUE, TCL_LIST_ELEMENT. (See FLAGS.)

DESCRIPTION

These procedures provide access to variables within a Tcl interpreter. Tcl_SetVar and Tcl_SetVar2 are used to store a value in a variable, Tcl_GetVar and Tcl_GetVar2 are used to retrieve the value of a variable, and Tcl_UnsetVar and Tcl_UnsetVar2 are used to remove variables.

The Tcl_SetVar2 procedure is a more general version of Tcl_SetVar, and is also more general than the Tcl set command. It allows variables to be specified by two strings. For example, if name1 is the name of an array and name2 is an index into the array, then Tcl_SetVar2 sets an array element. If name2 is NULL, then the variable is treated as a scalar variable whose name is given by name1. The Tcl_SetVar procedure is equivalent to calling Tcl_SetVar2 with name1 set to the name argument and name2 set to NULL.

In addition to setting scalar variables and array elements, Tcl_SetVar and Tcl_SetVar2 can be used to append to existing variables, or to append elements to lists. The behavior is controlled by the flags argument.

The Tcl_GetVar and Tcl_GetVar2 procedures are the C-level equivalents of the Tcl set command. They retrieve the current value of a variable. The Tcl_GetVar2 procedure is the more general form, allowing variables to be specified by two strings, as described for Tcl_SetVar2. Tcl_GetVar is equivalent to calling Tcl_GetVar2 with name1 set to the name argument and name2 set to NULL.

Under normal circumstances, the return value from Tcl_GetVar and Tcl_GetVar2 is a pointer to the variable's value string. This value is stored internally by Tcl and is guaranteed not to change until the next call to a Tcl command that modifies the variable or until the interpreter is deleted. If an error occurs (e.g. the variable does not exist, or an array element is specified for a scalar variable), then NULL is returned and an error message is left in the interpreter's result.

The Tcl_UnsetVar and Tcl_UnsetVar2 procedures remove a variable from an interpreter. Once a variable has been unset, any attempt to read it using Tcl_GetVar or Tcl_GetVar2 will result in an error (unless the variable is subsequently recreated). The Tcl_UnsetVar2 procedure is the more general form, and Tcl_UnsetVar is equivalent to calling Tcl_UnsetVar2 with name1 set to the name argument and name2 set to NULL.

If Tcl_UnsetVar* successfully removes the variable, it returns TCL_OK. If the variable does not exist, it returns TCL_ERROR. If an array element is specified, only that element is removed, and the array itself remains. If an array name is specified without an index, the entire array and all its elements are removed.

FLAGS

TCL_GLOBAL_ONLY
If this flag is set, the variable is looked up only in the global scope, even if the C code is called from within a procedure. If the flag is not set, the variable is looked up in the current scope (local scope if inside a procedure, global scope otherwise).
TCL_LEAVE_ERR_MSG
If this flag is set, Tcl will not automatically leave an error message in the interpreter's result if an error occurs. This is useful when the caller intends to report the error in a different way.
TCL_APPEND_VALUE
Causes the value to be appended to the existing value of the variable. The variable must already exist and contain a string value. If the variable does not exist, an error will be generated.
TCL_LIST_ELEMENT
Causes the value to be appended as a new element to the list stored in the variable. The variable must already exist and contain a valid Tcl list. If the variable does not exist or does not contain a valid list, an error will be generated. Note that this flag is intended for appending to lists, not for setting individual list elements. It may be used in combination with TCL_APPEND_VALUE.

The TCL_APPEND_VALUE and TCL_LIST_ELEMENT flags may be used together. In this case, the value is appended as a new element to the list in the variable. The original variable must be a valid list, and the appended value will become the last element of the new list. It is important to note that TCL_LIST_ELEMENT implies that the variable must already be a list. It is not used to add the first element to a variable unless the variable's current value is empty, or the single character '{', or ends in ' }'. When appending, the original value of the variable must also be a valid list, so that the operation is the appending of a new list element onto a list.

Tcl_GetVar and Tcl_GetVar2 return the current value of a variable. The arguments to these procedures are treated in the same way as the arguments to Tcl_SetVar and Tcl_SetVar2. Under normal circumstances, the return value is a pointer to the variable's value (which is stored in Tcl's variable structure and will not change before the next call to Tcl_SetVar or Tcl_SetVar2). Tcl_GetVar and Tcl_GetVar2 use the flag bits TCL_GLOBAL_ONLY and TCL_LEAVE_ERR_MSG, both of which have the same meaning as for Tcl_SetVar. If an error occurs in reading the variable (e.g. the variable does not exist or an array element is specified for a scalar variable), then NULL is returned.

Tcl_UnsetVar and Tcl_UnsetVar2 may be used to remove a variable, so that future calls to Tcl_GetVar or Tcl_GetVar2 for the variable will return an error. The arguments to these procedures are treated in the same way as the arguments to Tcl_GetVar and Tcl_GetVar2. If the variable is successfully removed then TCL_OK is returned. If the variable cannot be removed because it does not exist then TCL_ERROR is returned. If an array element is specified, the given element is removed but the array remains. If an array name is specified without an index, then the entire array is removed.
