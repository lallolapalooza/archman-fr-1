DESCRIPTION

Les objets sont des entités typées ayant un ensemble d'opérations ("méthodes") associées. Les classes sont des objets pouvant fabriquer des objets. Chaque classe peut être vue comme un objet ; le mode objet d'une classe peut être obtenu en utilisant Tcl_GetClassAsObject, qui renvoie toujours l'objet lors de l'application à une classe non détruite, et un objet peut être vu comme une classe à l'aide de Tcl_GetObjectAsClass (qui renvoie la classe, ou NULL si l'objet n'est pas une classe). Un objet peut être recherché en utilisant la fonction Tcl_GetObjectFromObj, qui renvoie un objet ou NULL (avec un message d'erreur dans le résultat de l'interpréteur) si l'objet ne peut pas être trouvé. La manière correcte de rechercher une classe par nom est de rechercher l'objet avec ce nom, puis d'utiliser Tcl_GetObjectAsClass.

Chaque objet possède sa propre commande et son propre espace de noms associés. La commande peut être obtenue en utilisant la fonction Tcl_GetObjectCommand, le nom de l'objet (et donc le nom de la commande) avec Tcl_GetObjectName, et l'espace de noms peut être obtenu avec la fonction Tcl_GetObjectNamespace. Notez que la référence d'objet renvoyée par Tcl_GetObjectName est une référence partagée. Vous pouvez également déterminer si l'objet a été marqué pour suppression avec Tcl_ObjectDeleted (renvoie vrai si la suppression de l'objet a commencé) ; ceci peut être utile lors du traitement des méthodes.

Les objets de classes sont créés en utilisant Tcl_NewObjectInstance, qui crée un objet de n'importe quelle classe (et est appelée en interne par les méthodes create et new de oo::class). Les paramètres fournissent optionnellement le nom de l'objet et l'espace de noms à créer, et décrivent les arguments à passer au constructeur de la classe (s'il y en a). Le résultat de la fonction sera une référence au nouvel objet créé, ou NULL si la création a échoué (auquel cas un message d'erreur sera laissé dans le résultat de l'interpréteur). De plus, les objets peuvent être copiés en utilisant Tcl_CopyObjectInstance, qui crée une copie d'un objet sans exécuter de constructeur.

Notez que la gestion de la durée de vie des objets est gérée en interne dans TclOO et n'utilise pas Tcl_Preserve. Il n'est pas sûr de placer une poignée Tcl_Object dans une structure C avec une durée de vie différente de celle de l'objet ; il faut utiliser le nom de commande de l'objet (obtenu via Tcl_GetObjectName) plutôt que les poignées. Il est sûr d'utiliser une poignée Tcl_Object pendant la durée d'un appel de méthode sur cet objet ; les poignées ne deviennent pas invalides tant qu'il y a un appel en cours sur leur objet (bien que la seule opération garantie sûre sur celles-ci soit Tcl_ObjectDeleted ; les autres opérations garantissent seulement qu'elles fonctionneront sur des objets non détruits).

MÉTADONNÉES OBJET ET CLASSE

Chaque objet et chaque classe peut avoir une quantité arbitraire de métadonnées associées, dont la signification n'est comprise que par l'objet ou la classe elle-même, tel que décrit par une instance de structure Tcl_ObjectMetadataType. Les métadonnées à associer sont décrites par le type des métadonnées (fourni dans l'argument metaTypePtr) et un pointeur arbitraire (l'argument metadata) qui sont fournis à Tcl_ObjectSetMetadata et Tcl_ClassSetMetadata, et des métadonnées particulières peuvent être obtenues par leur type avec Tcl_ObjectGetMetadata et Tcl_ClassGetMetadata. Si le paramètre metadata à Tcl_ObjectSetMetadata ou Tcl_ClassSetMetadata est NULL, les métadonnées associées sont supprimées, et les résultats de Tcl_ObjectGetMetadata et Tcl_ClassGetMetadata sont NULL si le type de métadonnées donné n'était pas associé. Il n'est pas erroné de demander ou de supprimer des métadonnées qui n'ont pas été associées.

STRUCTURE TCL_OBJECTMETADATATYPE

Le contenu de la structure Tcl_ObjectMetadataType est le suivant :

typedef const struct {
    int version;
    const char *name;
    Tcl_ObjectMetadataDeleteProc *deleteProc;
    Tcl_CloneProc *cloneProc;
} Tcl_ObjectMetadataType;

Le champ version permet une expansion future de la structure, et doit toujours être déclaré comme étant égal à TCL_OO_METADATA_VERSION_CURRENT. Le champ name fournit un nom lisible par l'homme pour le type, et est réservé au débogage.

Le champ deleteProc fournit une fonction de type Tcl_ObjectMetadataDeleteProc qui est utilisée pour supprimer un bloc de métadonnées donné, et est appelée lorsque les métadonnées associées sont remplacées ou supprimées ; le champ ne doit pas être NULL.

Le champ cloneProc fournit une fonction qui est utilisée pour copier un bloc de métadonnées (utilisé lors de la création d'une copie d'un objet avec Tcl_CopyObjectInstance) ; si NULL, les métadonnées seront copiées directement.

SYNTHÈSE

Voici un résumé de la fonctionnalité de TclOO :

typedef int Tcl_GetObjectAsClass(
        Tcl_Interp *interp,
        Tcl_Obj *obj);

ARGUMENTS

L'argument interp est un pointeur vers un interpréteur Tcl. L'argument obj est un objet Tcl. L'argument class est un pointeur vers une classe Tcl. L'argument name est un pointeur vers un objet Tcl.

DESCRIPTION

Cette fonction renvoie un pointeur vers une classe Tcl en fonction du nom fourni. Le nom peut être spécifié sous forme de chaîne de caractères ou d'objet Tcl. Si le nom est une chaîne de caractères, il doit être passé comme argument name. Si le nom est un objet Tcl, il doit être passé comme argument obj.
