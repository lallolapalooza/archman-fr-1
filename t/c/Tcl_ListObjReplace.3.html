Tcl_ListObj(3) Procédures de la bibliothèque Tcl Tcl_ListObj(3)

NOM

Tcl_ListObjAppendList, Tcl_ListObjAppendElement, Tcl_NewListObj, Tcl_SetListObj, Tcl_ListObjGetElements, Tcl_ListObjLength, Tcl_ListObjIndex, Tcl_ListObjReplace - manipuler les valeurs Tcl sous forme de listes

SYNOPSIS

#include <tcl.h>

int
Tcl_ListObjAppendList(interp, listPtr, elemListPtr)

int
Tcl_ListObjAppendElement(interp, listPtr, objPtr)

Tcl_Obj *
Tcl_NewListObj(objc, objv)

Tcl_SetListObj(objPtr, objc, objv)

int
Tcl_ListObjGetElements(interp, listPtr, objcPtr, objvPtr)

int
Tcl_ListObjLength(interp, listPtr, lengthPtr)

int
Tcl_ListObjIndex(interp, listPtr, index, objPtrPtr)

int
Tcl_ListObjReplace(interp, listPtr, first, count, objc, objv)

ARGUMENTS

Tcl_Interp *interp (entrée)
Si une erreur se produit lors de la conversion d'une valeur pour qu'elle soit une valeur de liste, un message d'erreur est laissé dans la valeur de résultat de l'interpréteur, sauf si interp est NULL.
Tcl_Obj *listPtr (entrée/sortie)
Pointe vers la valeur de liste à manipuler. Si listPtr ne pointe pas déjà vers une valeur de liste, une tentative sera faite pour la convertir.
Tcl_Obj *elemListPtr (entrée/sortie)
Pour Tcl_ListObjAppendList, pointe vers une valeur de liste contenant les éléments à ajouter à listPtr. Chaque élément de *elemListPtr deviendra un nouvel élément de listPtr. Si *elemListPtr n'est pas NULL et ne pointe pas déjà vers une valeur de liste, une tentative sera faite pour la convertir.
Tcl_Obj *objPtr (entrée)
Pour Tcl_ListObjAppendElement, pointe vers la valeur Tcl qui sera ajoutée à listPtr. Pour Tcl_SetListObj, pointe vers la valeur Tcl qui sera convertie en une valeur de liste contenant les objc éléments du tableau référencé par objv.
int *objcPtr (entrée)
Pointe vers l'emplacement où Tcl_ListObjGetElements stocke le nombre de valeurs d'éléments dans listPtr.
Tcl_Obj ***objvPtr (sortie)
Un emplacement où Tcl_ListObjGetElements stocke un pointeur vers un tableau de pointeurs vers les valeurs d'éléments de listPtr.
int objc (entrée)
Le nombre de valeurs Tcl que Tcl_NewListObj insérera dans une nouvelle valeur de liste, et que Tcl_ListObjReplace insérera dans listPtr. Pour Tcl_SetListObj, le nombre de valeurs Tcl à insérer dans objPtr.
Tcl_Obj *const objv[] (entrée)
Un tableau de pointeurs vers des valeurs. Tcl_NewListObj insérera ces valeurs dans une nouvelle valeur de liste et Tcl_ListObjReplace les insérera dans une listPtr existante. Chaque valeur deviendra un élément de liste distinct.
int *lengthPtr (sortie)
Pointe vers l'emplacement où Tcl_ListObjLength stocke la longueur de la liste.
int index (entrée)
Index de l'élément de liste que Tcl_ListObjIndex doit retourner. Le premier élément a l'index 0.
Tcl_Obj **objPtrPtr (sortie)
Pointe vers l'emplacement où Tcl_ListObjIndex doit stocker un pointeur vers la valeur résultante de l'élément de liste.
int first (entrée)
Index de l'élément de liste de départ que Tcl_ListObjReplace doit remplacer. Le premier élément de la liste a l'index 0.
int count (entrée)
Le nombre d'éléments que Tcl_ListObjReplace doit remplacer.

DESCRIPTION

Les valeurs de liste Tcl ont une représentation interne qui prend en charge l'indexation et l'ajout efficaces. Les procédures décrites dans cette page man sont utilisées pour créer, modifier, indexer et ajouter à des valeurs de liste Tcl à partir du code C.

Tcl_ListObjAppendList et Tcl_ListObjAppendElement ajoutent toutes deux une ou plusieurs valeurs à la fin de la valeur de liste référencée par listPtr. Tcl_ListObjAppendList ajoute chaque élément de la valeur de liste référencée par elemListPtr tandis que Tcl_ListObjAppendElement ajoute la valeur unique référencée par objPtr. Les deux procédures convertiront la valeur référencée par listPtr en une valeur de liste si nécessaire. Si une erreur se produit pendant la conversion, les deux procédures retournent TCL_ERROR et laissent un message d'erreur dans la valeur de résultat de l'interpréteur si interp n'est pas NULL. De même, si elemListPtr ne fait pas déjà référence à une valeur de liste, Tcl_ListObjAppendList tentera de la convertir et si une erreur se produit pendant la conversion, retournera TCL_ERROR et laissera un message d'erreur dans la valeur de résultat de l'interpréteur si interp n'est pas NULL. Les deux procédures invalident toute ancienne représentation sous forme de chaîne de listPtr et, si elle a été convertie en valeur de liste, libèrent toute ancienne représentation interne. De même, Tcl_ListObjAppendList libère toute ancienne représentation interne de elemListPtr si elle la convertit en valeur de liste. Après avoir ajouté chaque élément de elemListPtr, Tcl_ListObjAppendList incrémente le compteur de références de l'élément car listPtr y fait maintenant aussi référence. Pour la même raison, Tcl_ListObjAppendElement incrémente le compteur de références de objPtr. Si aucune erreur ne se produit, les deux procédures retournent TCL_OK après avoir ajouté les valeurs.

Tcl_NewListObj et Tcl_SetListObj créent une nouvelle valeur ou modifient une valeur existante pour contenir les objc éléments du tableau référencé par objv où chaque élément est un pointeur vers une valeur Tcl. Si objc est inférieur ou égal à zéro, elles retournent une valeur vide. Si objv est NULL, la liste résultante contient 0 éléments, avec de l'espace réservé dans une représentation interne pour objc éléments supplémentaires (pour éviter sa réallocation ultérieure). La représentation sous forme de chaîne de la nouvelle valeur est laissée invalide. Les deux procédures incrémentent les compteurs de références des éléments de objc car la valeur de liste y fait maintenant référence. La nouvelle valeur de liste retournée par Tcl_NewListObj a un compteur de références de zéro.

Tcl_ListObjGetElements retourne un nombre et un pointeur vers un tableau des éléments d'une valeur de liste. Elle retourne le nombre en le stockant à l'adresse objcPtr. De même, elle retourne le pointeur du tableau en le stockant à l'adresse objvPtr. La mémoire pointée est gérée par Tcl et ne doit pas être libérée ou modifiée par l'appelant. Si la liste est vide, 0 est stocké à objcPtr et NULL à objvPtr. Si listPtr n'est pas déjà une valeur de liste, Tcl_ListObjGetElements tentera de la convertir ; si la conversion échoue, elle retourne TCL_ERROR et laisse un message d'erreur dans la valeur de résultat de l'interpréteur si interp n'est pas NULL. Sinon, elle retourne TCL_OK après avoir stocké le nombre et le pointeur du tableau.

Tcl_ListObjLength retourne le nombre d'éléments dans la valeur de liste référencée par listPtr. Elle retourne ce nombre en stockant un entier à l'adresse lengthPtr. Si la valeur n'est pas déjà une valeur de liste, Tcl_ListObjLength tentera de la convertir ; si la conversion échoue, elle retourne TCL_ERROR et laisse un message d'erreur dans la valeur de résultat de l'interpréteur si interp n'est pas NULL. Sinon, elle retourne TCL_OK après avoir stocké la longueur de la liste.

La procédure Tcl_ListObjIndex retourne un pointeur vers la valeur à l'index index dans la liste référencée par listPtr. Elle retourne cette valeur en stockant un pointeur vers elle à l'adresse objPtrPtr. Si listPtr ne fait pas déjà référence à une valeur de liste, Tcl_ListObjIndex tentera de la convertir ; si la conversion échoue, elle retourne TCL_ERROR et laisse un message d'erreur dans la valeur de résultat de l'interpréteur si interp n'est pas NULL. Si l'index est hors limites, c'est-à-dire si index est négatif ou supérieur ou égal au nombre d'éléments dans la liste, Tcl_ListObjIndex stocke un NULL dans objPtrPtr et retourne TCL_OK. Sinon, elle retourne TCL_OK après avoir stocké le pointeur de la valeur de l'élément. Le compteur de références pour l'élément de liste n'est pas incrémenté ; l'appelant doit le faire s'il a besoin de conserver un pointeur vers l'élément.

Tcl_ListObjReplace remplace zéro ou plusieurs éléments de la liste référencée par listPtr par les objc valeurs du tableau référencé par objv. Si listPtr ne pointe pas vers une valeur de liste, Tcl_ListObjReplace tentera de la convertir ; si la conversion échoue, elle retourne TCL_ERROR et laisse un message d'erreur dans la valeur de résultat de l'interpréteur si interp n'est pas NULL. Sinon, elle retourne TCL_OK après avoir remplacé les valeurs. Si objv est NULL, aucun nouvel élément n'est ajouté. Si l'argument first est zéro ou négatif, il fait référence au premier élément. Si first est supérieur ou égal au

nombre d'éléments dans la liste, aucun élément n'est supprimé ; les nouveaux éléments sont ajoutés à la fin de la liste. count indique le nombre d'éléments à remplacer. Si count est zéro ou négatif, aucun élément n'est supprimé ; les nouveaux éléments sont simplement insérés avant celui désigné par first. Tcl_ListObjReplace invalide la représentation textuelle précédente de listPtr. Les compteurs de références des éléments insérés depuis objv sont incrémentés car la liste résultante y fait maintenant référence. De même, les compteurs de références des valeurs remplacées sont décrémentés.

Étant donné que Tcl_ListObjReplace combine l'insertion et la suppression d'éléments, il peut être utilisé pour implémenter un certain nombre d'opérations sur les listes. Par exemple, le code suivant insère les valeurs objc référencées par le tableau de pointeurs de valeurs objv juste avant l'élément index de la liste référencée par listPtr :

result = Tcl_ListObjReplace(interp, listPtr, index, 0,
        objc, objv);

De même, le code suivant ajoute les valeurs objc référencées par le tableau objv à la fin de la liste listPtr :

result = Tcl_ListObjLength(interp, listPtr, &length);
if (result == TCL_OK) {
    result = Tcl_ListObjReplace(interp, listPtr, length, 0,
            objc, objv);
}

Les count éléments de la liste commençant à first peuvent être supprimés en appelant simplement Tcl_ListObjReplace avec un objvPtr à NULL :

result = Tcl_ListObjReplace(interp, listPtr, first, count,
        0, NULL);
