Tcl_AllowExceptions(3) Procédures de bibliothèque Tcl Tcl_AllowExceptions(3)

NOM

Tcl_AllowExceptions - autoriser toutes les exceptions lors de la prochaine évaluation de script

SYNOPIS

#include <tcl.h>

Tcl_AllowExceptions(interp)

ARGUMENTS

Tcl_Interp *interp (en entrée)
Interpréteur dans lequel le script sera évalué.

DESCRIPTION

Si un script est évalué au niveau supérieur (c'est-à-dire qu'aucun autre script n'est en attente d'évaluation lorsque le script est appelé), et si le script se termine avec un code de complétion autre que TCL_OK, TCL_ERROR ou TCL_RETURN, Tcl convertit normalement cela en un code de retour TCL_ERROR avec un message approprié. Les procédures d'évaluation de script de Tcl qui agissent de cette manière sont Tcl_EvalObjEx, Tcl_EvalObjv, Tcl_Eval, Tcl_EvalEx, Tcl_GlobalEval, Tcl_GlobalEvalObj, Tcl_VarEval et Tcl_VarEvalVA.

Cependant, si Tcl_AllowExceptions est appelée immédiatement avant l'une de ces procédures, des codes de complétion arbitraires sont autorisés pour le script, et ils sont retournés sans modification. Ceci est utile dans les cas où l'appelant peut traiter des exceptions telles que TCL_BREAK ou TCL_CONTINUE de manière significative.

MOTS-CLÉS

continue, break, exception, interpréteur
