Tcl_Init(3) Procédures de bibliothèque Tcl Tcl_Init(3)

NOM

Tcl_Init - trouver et sourcer le script d'initialisation

SYNTAXE

#include <tcl.h>

int
Tcl_Init(interp)

ARGUMENTS

Tcl_Interp *interp (entrée)
Interpréteur à initialiser.

DESCRIPTION

Tcl_Init est une procédure d'aide qui trouve et source le script init.tcl, lequel doit exister quelque part dans le chemin de bibliothèque de Tcl.

Tcl_Init est généralement appelée à partir des procédures Tcl_AppInit.

VOIR AUSSI

Tcl_AppInit, Tcl_Main

MOTS CLÉS

application, initialisation, interpréteur
