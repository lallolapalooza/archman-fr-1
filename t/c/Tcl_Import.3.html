ARGUMENTS

Tcl_Interp *interp (in/out)
L'interpréteur dans lequel l'espace de noms existe et où les recherches de noms sont effectuées. C'est également là que les messages d'erreur sont écrits.
const char *name (in)
Le nom de l'espace de noms ou de la commande à créer ou à accéder.
ClientData clientData (in)
Un pointeur client fourni par le créateur de l'espace de noms. Pas interprété par Tcl du tout.
Tcl_NamespaceDeleteProc *deleteProc (in)
Un pointeur vers une fonction à appeler lorsque l'espace de noms est supprimé, ou NULL s'il n'y a pas de rappel de ce type à effectuer.
Tcl_Namespace *nsPtr (in)
L'espace de noms à manipuler, ou NULL (pour d'autres que Tcl_DeleteNamespace) pour manipuler l'espace de noms courant.
Tcl_Obj *objPtr (out)
Une référence vers une valeur non partagée dans laquelle la sortie de la fonction sera écrite.
const char *pattern (in)
Le motif de style glob (voir Tcl_StringMatch) qui décrit les commandes à importer ou exporter.
int resetListFirst (in)
Indique si la liste des motifs d'exportation doit être réinitialisée avant d'y ajouter le motif courant.
int allowOverwrite (in)
Indique si les nouvelles commandes créées par cette action d'importation peuvent écraser des commandes existantes.
Tcl_Namespace *contextNsPtr (in)
L'emplacement dans la hiérarchie des espaces de noms où la recherche d'un espace de noms ou d'une commande doit être effectuée par rapport à lorsque le terme de recherche n'est pas ancré dans l'espace de noms global. NULL indique l'espace de noms courant.
int flags (in)
Combinaison OU des bits contrôlant comment la recherche doit être effectuée. Les drapeaux suivants sont supportés : TCL_GLOBAL_ONLY (indique que la recherche doit toujours être effectuée par rapport à l'espace de noms global), TCL_NAMESPACE_ONLY (uniquement pour Tcl_FindCommand ; indique que la recherche doit toujours être effectuée par rapport à l'espace de noms de contexte), et TCL_LEAVE_ERR_MSG (indique qu'un message d'erreur doit être laissé dans l'interpréteur si la recherche échoue).
Tcl_Obj *handlerPtr (in)
Un fragment de script à installer comme gestionnaire de commande inconnue pour l'espace de noms, ou NULL pour réinitialiser le gestionnaire à sa valeur par défaut.

DESCRIPTION

Les espaces de noms sont des contextes de nommage hiérarchiques qui peuvent contenir des commandes et des variables. Ils maintiennent également une liste de motifs qui décrivent quelles commandes sont exportées, et peuvent importer des commandes qui ont été exportées par d'autres espaces de noms. Les espaces de noms peuvent également être manipulés via la commande Tcl namespace.

La structure Tcl_Namespace encapsule un espace de noms, et contient nécessairement les champs suivants : name (le nom local de l'espace de noms, sans caractères séparateurs d'espace de noms, une chaîne vide représentant l'espace de noms global), fullName (le nom complet de l'espace de noms), clientData, deleteProc (les valeurs spécifiées dans l'appel à Tcl_CreateNamespace), et parentPtr (un pointeur vers l'espace de noms contenant, ou NULL pour l'espace de noms global.)

Tcl_CreateNamespace crée un nouvel espace de noms. Le deleteProc aura la signature de fonction suivante :

typedef void Tcl_NamespaceDeleteProc(
        ClientData clientData);

Tcl_DeleteNamespace supprime un espace de noms, en appelant le deleteProc défini pour cet espace de noms (le cas échéant).

Tcl_AppendExportList récupère les motifs d'exportation d'un espace de noms donné et les ajoute (en tant qu'éléments de liste) à objPtr.

Tcl_Export définit et ajoute des motifs à la liste des motifs d'exportation d'un espace de noms. Les motifs sont ajoutés sauf si le drapeau resetListFirst est vrai.

Tcl_Import importe des commandes correspondant à un motif dans un espace de noms. Notez que le motif doit inclure le nom de l'espace de noms d'où importer. Cette fonction retourne TCL_ERROR si une tentative d'importation d'une commande par-dessus une commande existante est faite, sauf si le drapeau allowOverwrite a été défini.

Tcl_ForgetImport supprime les importations correspondant à un motif.

Tcl_GetCurrentNamespace retourne l'espace de noms courant pour un interpréteur.

Tcl_GetGlobalNamespace retourne l'espace de noms global pour un interpréteur.

Tcl_FindNamespace recherche un espace de noms nommé name dans le contexte de l'espace de noms contextNsPtr. Si l'espace de noms ne peut être trouvé, NULL est retourné.

Tcl_FindCommand recherche une commande nommée name dans le contexte de l'espace de noms contextNsPtr. Si la commande ne peut être trouvée, NULL est retourné.

Tcl_GetNamespaceUnknownHandler retourne le gestionnaire de commande inconnue pour l'espace de noms, ou NULL si aucun n'est défini.

Tcl_SetNamespaceUnknownHandler définit le gestionnaire de commande inconnue pour l'espace de noms. Si handlerPtr est NULL, alors le gestionnaire est réinitialisé à sa valeur par défaut.
