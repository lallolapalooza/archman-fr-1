NOM

Tcl_CommandComplete - Vérifie les accolades non appariées dans une commande Tcl

SYNOPSIS

#include <tcl.h>

int
Tcl_CommandComplete(cmd)

ARGUMENTS

const char *cmd (entrée)
Chaîne de commande à tester pour son complétude.

DESCRIPTION

Tcl_CommandComplete prend une chaîne de commande Tcl comme argument et détermine si elle contient une ou plusieurs commandes complètes (c'est-à-dire qu'il n'y a pas de guillemets, d'accolades, de crochets ou de références de variables non fermés). Si la chaîne de commande est complète, elle renvoie 1 ; sinon, elle renvoie 0.

MOTS-CLÉS

commande complète, commande partielle
