NOM

Tcl_Backslash - analyse une séquence antislash

SYNTAXE

#include <tcl.h>

char
Tcl_Backslash(src, countPtr)

ARGUMENTS

const char *src (entrée)
Pointeur vers une chaîne commençant par un antislash.
int *countPtr (sortie)
Si countPtr n'est pas NULL, *countPtr est rempli avec le nombre de caractères de la séquence antislash, y compris le caractère antislash.

DESCRIPTION

L'utilisation de Tcl_Backslash est obsolète au profit de Tcl_UtfBackslash.

Il s'agit d'une procédure utilitaire fournie pour des raisons de compatibilité ascendante avec les extensions Tcl non internationalisées. Elle analyse une séquence antislash et retourne l'octet de poids faible du caractère Unicode correspondant à la séquence. Tcl_Backslash modifie *countPtr pour contenir le nombre de caractères dans la séquence antislash.

Consultez l'entrée du manuel Tcl pour plus d'informations sur les séquences antislash valides. Toutes les séquences décrites dans l'entrée du manuel Tcl sont prises en charge par Tcl_Backslash.

VOIR AUSSI

Tcl(n), Tcl_UtfBackslash(3)
