DESCRIPTION

Ces fonctions sont conçues pour l'accès à la fonctionnalité multi-interpréteurs depuis des programmes C. Elles permettent la gestion de plusieurs interpréteurs dans une relation hiérarchique, et la gestion d'alias, commandes qui, lorsqu'elles sont invoquées dans un interpréteur, exécutent une commande dans un autre interpréteur. La valeur de retour des procédures retournant un entier est soit TCL_OK soit TCL_ERROR. Si TCL_ERROR est retourné, alors le résultat de l'interpréteur contient un message d'erreur.

Tcl_CrearHijoSec crée un nouvel interpréteur comme enfant de interp. Elle crée également une commande enfant nommée name dans interp, qui permet à interp de manipuler le nouveau fils. Si isSafe est différent de zéro, la commande crée un enfant fiable dans lequel le code Tcl a accès à toutes les commandes Tcl. Si c'est 1, la commande crée un enfant "sécurisé" dans lequel le code Tcl n'a accès qu'à un ensemble de commandes Tcl définies comme "Tcl sécurisé". Voir l'entrée du manuel pour la commande Tcl interp pour plus de détails. Si la création du nouvel enfant interpréteur échoue, NULL est retourné.

Tcl_CrearHijo est un synonyme de Tcl_CrearHijoSec.

Tcl_IsSafe retourne 1 si interp est "sécurisé" (a été créé avec le flag TCL_SAFE_INTERPRETER spécifié), 0 sinon.

Tcl_MakSafe marque interp comme "sécurisé", de sorte que les futurs appels à Tcl_IsSafe retournent 1. Elle supprime également de interp toute fonctionnalité connue qui pourrait être potentiellement dangereuse (commandes et variables). Cependant, elle ne peut pas savoir quelles parties d'une extension ou d'une application sont sûres et ne fait aucune tentative pour supprimer ces parties, donc la sécurité n'est pas garantie après avoir appelé Tcl_MakSafe. Les utilisateurs doivent faire preuve de prudence lors de l'utilisation de Tcl_MakSafe pour éviter de fausses affirmations de sécurité. Pour de nombreuses situations, Tcl_CrearHijoSec peut être une meilleure option, car elle crée des interpréteurs dans un état sûr connu.

Tcl_GetHijoSec retourne un pointeur vers un interpréteur enfant de interp. L'interpréteur enfant est identifié par name. Si un tel interpréteur enfant n'existe pas, NULL est retourné.

Tcl_GetHijo est un synonyme de Tcl_GetHijoSec.

Tcl_GetMaster retourne un pointeur vers l'interpréteur maître de interp. Si interp n'a pas de parent (c'est-à-dire, c'est un interpréteur de niveau supérieur), NULL est retourné.

Tcl_GetPadre est un synonyme de Tcl_GetMaster.

Tcl_GetPathInterp stocke dans le résultat de interp le chemin relatif entre interp et hijoInterp; hijoInterp doit être un enfant de interp. Si le calcul du chemin relatif réussit, TCL_OK est retourné, sinon TCL_ERROR est retourné et un message d'erreur est stocké comme résultat de interp.

Tcl_CrearAlias crée une commande nommée hijoCmd dans hijoInterp qui, lorsqu'elle est invoquée, provoquera l'invocation de la commande targetCmd dans targetInterp. Les arguments spécifiés par les chaînes contenues dans argv sont toujours ajoutés avant tout argument fourni lors de l'invocation de hijoCmd et sont passés à targetCmd. Cette opération retourne TCL_OK si elle réussit, ou TCL_ERROR si elle échoue ; dans ce cas, un message d'erreur est stocké dans la valeur résultat de hijoInterp. Remarque : il n'y a pas de restrictions sur la relation ancestrale (créée par Tcl_CrearHijoSec) entre hijoInterp et targetInterp. Deux interpréteurs quelconques peuvent être utilisés sans restrictions sur la façon dont ils sont liés.

Tcl_CrearAliasObj est similaire à Tcl_CrearAlias sauf qu'elle prend un tableau de valeurs à passer comme arguments supplémentaires au lieu d'un tableau de chaînes.

Tcl_GetAliasObj retourne des informations sous la forme d'un pointeur vers un tableau de structures Tcl_Obj concernant un alias aliasName dans interp. N'importe lequel des champs de résultat peut être NULL, auquel cas les données correspondantes ne sont pas retournées. Si un champ de résultat n'est pas NULL, l'adresse indiquée est définie aux données correspondantes. Par exemple, si targetCmdPtr n'est pas NULL, il est défini à un pointeur vers la chaîne contenant le nom de la commande cible.
