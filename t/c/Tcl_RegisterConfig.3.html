Tcl_RegisterConfig(3) Procédures de bibliothèque Tcl Tcl_RegisterConfig(3)

NOM

Tcl_RegisterConfig - procédures pour enregistrer des informations de configuration embarquées

SYNTAXE

#include <tcl.h>

void
Tcl_RegisterConfig(interp, pkgName, configuration, valEncoding)

ARGUMENTS

Tcl_Interp *interp (entrée)
Se réfère à l'interpréteur pour lequel les informations de configuration embarquées sont enregistrées. Ne doit pas être NULL.
const char *pkgName (entrée)
Contient le nom du paquet enregistrant la configuration embarquée sous forme de chaîne ASCII. Cela signifie que ces informations sont également en UTF-8. Ne doit pas être NULL.
const Tcl_Config *configuration (entrée)
Se réfère à un tableau d'entrées Tcl_Config contenant les informations embarquées dans la bibliothèque binaire. Ne doit pas être NULL. La fin du tableau est signalée soit par une clé identique à NULL, soit par une clé faisant référence à une chaîne vide.
const char *valEncoding (entrée)
Contient le nom de l'encodage utilisé pour stocker les valeurs de configuration sous forme de chaîne ASCII. Cela signifie que ces informations sont également en UTF-8. Ne doit pas être NULL.

DESCRIPTION

La fonction décrite ici est basée sur TIP 59 et fournit aux extensions un support pour l'embarquement d'informations de configuration dans leur bibliothèque binaire et la génération d'une interface au niveau Tcl pour interroger ces informations.

Pour embarquer des informations de configuration dans leur bibliothèque binaire, une extension doit définir un tableau non volatil d'entrées Tcl_Config dans l'un de ses fichiers source, puis appeler Tcl_RegisterConfig pour enregistrer ces informations.

Tcl_RegisterConfig prend quatre arguments ; premièrement, une référence à l'interpréteur pour lequel nous enregistrons les informations, deuxièmement, le nom du paquet enregistrant ses informations de configuration, troisièmement, un pointeur vers un tableau de structures, et quatrièmement, une chaîne déclarant l'encodage utilisé par les valeurs de configuration.

La chaîne valEncoding contient le nom d'un encodage connu de Tcl. Tous ces noms n'utilisent que des caractères du sous-ensemble ASCII de UTF-8 et sont donc implicitement dans l'encodage UTF-8. On s'attend à ce que les clés soient du texte lisible en anglais et utilisent donc le sous-ensemble ASCII de UTF-8. En d'autres termes, on s'attend à ce qu'elles soient également en UTF-8. Les valeurs associées aux clés peuvent cependant être n'importe quelle chaîne. Pour celles-ci, le contenu de valEncoding définit quel encodage a été utilisé pour représenter les caractères des chaînes.

Chaque élément du tableau configuration se réfère à deux chaînes contenant la clé et la valeur associées à cette clé. La fin du tableau est signalée soit par une clé vide, soit par une clé identique à NULL. La fonction ne fait **pas** de copie du tableau configuration. Cela signifie que l'appelant doit s'assurer que la mémoire contenant ce tableau n'est jamais libérée. C'est le sens du mot non volatil utilisé précédemment. La manière la plus simple d'y parvenir est de définir un tableau global statique d'entrées Tcl_Config. Voir le fichier « generic/tclPkgConfig.c » dans les sources du noyau Tcl pour un exemple.

Lorsqu'elle est appelée, Tcl_RegisterConfig va

(1)
créer un espace de noms ayant le pkgName fourni, s'il n'existe pas encore.
(2)
créer la commande pkgconfig dans cet espace de noms et la lier aux informations fournies afin que les clés de configuration et leurs valeurs associées puissent être récupérées via des appels à pkgconfig.

La commande pkgconfig fournira deux sous-commandes, list et get :

::pkgName::pkgconfig list
Renvoie une liste contenant les noms de toutes les clés définies.
::pkgName::pkgconfig get key
Renvoie la valeur de configuration associée à la clé spécifiée.

TCL_CONFIG

La structure Tcl_Config contient les champs suivants :

typedef struct Tcl_Config {
    const char *key;
    const char *value;
} Tcl_Config;
