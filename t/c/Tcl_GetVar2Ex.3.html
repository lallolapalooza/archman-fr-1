ARGUMENTS

Tcl_Interp *interp (entree)
Interpréteur contenant la variable.
const char *name1 (entree)
Contient le nom d'une variable tableau (si name2 n'est pas NULL) ou (si name2 est NULL) soit le nom d'une variable scalaire, soit un nom complet incluant le nom de la variable et l'index. Peut inclure des qualificateurs d'espace de noms :: pour spécifier une variable dans un espace de noms particulier.
const char *name2 (entree)
Si non-NULL, donne le nom de l'élément dans le tableau; dans ce cas, name1 doit faire référence à une variable tableau.
Tcl_Obj *newValuePtr (entree)
Pointe vers une valeur Tcl contenant la nouvelle valeur de la variable.
int flags (entree)
Combinaison OR-ed de bits fournissant des informations supplémentaires. Voir ci-dessous pour les valeurs valides.
const char *varName (entree)
Nom de la variable. Peut inclure des qualificateurs d'espace de noms :: pour spécifier une variable dans un espace de noms particulier. Peut faire référence à une variable scalaire ou à un élément d'un tableau.
const char *newValue (entree)
Nouvelle valeur pour la variable, spécifiée comme une chaîne terminée par un caractère nul. Une copie de cette valeur est stockée dans la variable.
Tcl_Obj *part1Ptr (entree)
Pointe vers une valeur Tcl contenant le nom de la variable. Le nom peut inclure une série de qualificateurs d'espace de noms :: pour spécifier une variable dans un espace de noms particulier. Peut faire référence à une variable scalaire ou à un élément d'une variable tableau.
Tcl_Obj *part2Ptr (entree)
Si non-NULL, pointe vers une valeur contenant le nom d'un élément dans un tableau et part1Ptr doit faire référence à une variable tableau.

DESCRIPTION

Ces procédures sont utilisées pour créer, modifier, lire et supprimer des variables Tcl à partir du code C.

Tcl_SetVar2Ex, Tcl_SetVar, Tcl_SetVar2 et Tcl_ObjSetVar2 créeront une nouvelle variable ou modifieront une existante. Ces procédures définissent la variable donnée à la valeur fournie par newValuePtr ou newValue et retournent un pointeur vers la nouvelle valeur de la variable, qui est stockée dans la structure de variable de Tcl. Tcl_SetVar2Ex et Tcl_ObjSetVar2 prennent la nouvelle valeur comme un Tcl_Obj et retournent un pointeur vers un Tcl_Obj. Tcl_SetVar et Tcl_SetVar2 prennent la nouvelle valeur comme une chaîne et retournent une chaîne ; elles sont généralement moins efficaces que Tcl_ObjSetVar2. Notez que la valeur de retour peut être différente de l'argument newValuePtr ou newValue, en raison des modifications apportées par les traces d'écriture. Si une erreur se produit lors de la définition de la variable (par exemple, une variable tableau est référencée sans fournir d'index au tableau), NULL est retourné et un message d'erreur est laissé dans le résultat de interp si le bit de flag TCL_LEAVE_ERR_MSG est défini.

Tcl_GetVar2Ex, Tcl_GetVar, Tcl_GetVar2 et Tcl_ObjGetVar2 retournent la valeur actuelle d'une variable. Les arguments de ces procédures sont traités de la même manière que les arguments des procédures décrites ci-dessus. Dans des circonstances normales, la valeur de retour est un pointeur vers la valeur de la variable. Pour Tcl_GetVar2Ex et Tcl_ObjGetVar2, la valeur est retournée sous forme de pointeur vers un Tcl_Obj. Pour Tcl_GetVar et Tcl_GetVar2, la valeur est retournée sous forme de chaîne ; c'est généralement moins efficace, donc Tcl_GetVar2Ex ou Tcl_ObjGetVar2 sont préférés. Si une erreur se produit lors de la lecture de la variable (par exemple, la variable n'existe pas ou un élément de tableau est spécifié pour une variable scalaire), alors NULL est retourné et un message d'erreur est laissé dans le résultat de interp si le bit de flag TCL_LEAVE_ERR_MSG est défini.

Tcl_UnsetVar et Tcl_UnsetVar2 peuvent être utilisés pour supprimer une variable, de sorte que les tentatives futures de lecture de la variable retournent une erreur. Les arguments de ces procédures sont traités de la même manière que les arguments des procédures ci-dessus. Si la variable est supprimée avec succès, TCL_OK est retourné. Si la variable ne peut pas être supprimée car elle n'existe pas, TCL_ERROR est retourné et un message d'erreur est laissé dans le résultat de interp si le bit de flag TCL_LEAVE_ERR_MSG est défini. Si un élément de tableau est spécifié, l'élément donné est supprimé mais le tableau reste. Si un nom de tableau est spécifié sans index, alors l'ensemble du tableau est supprimé.

Le nom d'une variable peut être spécifié à ces procédures de quatre manières :

[1]
Si Tcl_SetVar, Tcl_GetVar ou Tcl_UnsetVar est appelé, le nom de la variable est donné sous forme d'une seule chaîne, varName. Si varName contient une parenthèse ouvrante et se termine par une parenthèse fermante, alors la valeur entre les parenthèses est traitée comme un index (qui peut avoir n'importe quelle valeur chaîne) et les caractères avant la première parenthèse ouvrante sont traités comme le nom d'une variable tableau. Si varName n'a pas de parenthèses comme décrit ci-dessus, alors la chaîne entière est traitée comme le nom d'une variable scalaire.
[2]
Si les arguments name1 et name2 sont fournis et que name2 n'est pas NULL, alors un élément de tableau est spécifié et le nom du tableau et l'index ont déjà été séparés par l'appelant : name1 contient le nom et name2 contient l'index. Une erreur est générée si name1 contient une parenthèse ouvrante et se termine par une parenthèse fermante (élément de tableau) et name2 n'est pas NULL.
[3]
Si name2 est NULL, name1 est traité exactement comme varName dans le cas [1] ci-dessus (il peut s'agir d'un nom de variable scalaire ou d'un nom d'élément de tableau).

L'argument flags peut être utilisé pour spécifier l'une des plusieurs options aux procédures. Il se compose d'une combinaison OR-ed des bits suivants.

TCL_GLOBAL_ONLY
Dans des circonstances normales, les procédures recherchent les variables comme suit. Si un appel de procédure est actif dans interp, la variable est recherchée au niveau actuel de l'appel de procédure. Sinon, la variable est recherchée d'abord dans l'espace de noms courant, puis dans l'espace de noms global. Cependant, si ce bit est défini dans flags, alors la variable est recherchée uniquement dans l'espace de noms global, même si un appel de procédure est actif. Si TCL_GLOBAL_ONLY et TCL_NAMESPACE_ONLY sont tous deux donnés, TCL_GLOBAL_ONLY est ignoré.
TCL_NAMESPACE_ONLY
Si ce bit est défini dans flags, alors la variable est recherchée uniquement dans l'espace de noms courant ; si une procédure est active, ses variables sont ignorées, et l'espace de noms global est également ignoré à moins qu'il ne soit l'espace de noms courant.
TCL_LEAVE_ERR_MSG
Si une erreur est retournée et que ce bit est défini dans flags, alors un message d'erreur sera laissé dans le résultat de l'interpréteur, où il pourra être récupéré avec Tcl_GetObjResult ou Tcl_GetStringResult. Si ce bit de drapeau n'est pas défini, aucun message d'erreur n'est laissé et le résultat de l'interpréteur ne sera pas modifié.
TCL_APPEND_VALUE
Si ce bit est défini, alors newValuePtr ou newValue est ajouté à la valeur actuelle au lieu de la remplacer. Si la variable est actuellement indéfinie, alors le bit est ignoré. Ce bit est uniquement utilisé par les procédures Tcl_Set*.
TCL_LIST_ELEMENT
Si ce bit est défini, alors newValue est converti en un élément de liste Tcl valide avant de définir (ou d'ajouter à) la variable. Un espace séparateur est ajouté avant le nouveau

NAME

Tcl_GetVar, Tcl_GetVar2, Tcl_SetVar, Tcl_SetVar2, Tcl_UnsetVar, Tcl_UnsetVar2 — get, set, and unset variables

SYNOPSIS

int
Tcl_SetVar(interp, name, value, flags)
int
Tcl_SetVar2(interp, name1, name2, value, flags)
char *
Tcl_GetVar(interp, name, flags)
char *
Tcl_GetVar2(interp, name1, name2, flags)
int
Tcl_UnsetVar(interp, name, flags)
int
Tcl_UnsetVar2(interp, name1, name2, flags)

ARGUMENTS

Tcl_Interp *interp
Interpréteur Tcl à utiliser.
const char *name
Nom de la variable (un nom ou un nom de tableau et un index).
const char *name1
Pour Tcl_SetVar2 et Tcl_GetVar2, ceci est le nom de la variable et
name2
pour les tableaux, l'index. Pour les variables scalaires,
name2 est NULL.
const char *value
Nouvelle valeur pour la variable.
int flags
Combinaison de bits des drapeaux suivants :
TCL_GLOBAL_ONLY
Ne regarder que dans l'espace de noms global, même si le nom est qualifié avec ::.
TCL_NAMESPACE_ONLY
Ne regarder que dans l'espace de noms actuel, même si le nom est qualifié avec ::.
TCL_APPEND_VALUE
Ajouter value à la valeur existante de la variable au lieu de la remplacer.
TCL_LIST_ELEMENT
Traiter la variable comme une liste, et ajouter value comme un nouvel élément à la fin de la liste. Ceci est similaire à TCL_APPEND_VALUE, sauf qu'il gère la mise en quotation des éléments pour éviter les problèmes de fragmentation de la liste si les éléments contiennent des espaces blancs ou des caractères spéciaux. Toutefois, il ne faut pas utiliser cet indicateur pour ajouter le premier élément d'une liste ou d'une sous-liste (c'est-à-dire que la valeur actuelle de la variable est vide, ou contient le caractère unique “{”, ou se termine par “ }”). Lors de l'ajout, la valeur originale de la variable doit également être une liste valide, de sorte que l'opération soit l'ajout d'un nouvel élément de liste à une liste.
TCL_LEAVE_ERR_MSG
Si une erreur se produit, laisser le message d'erreur dans la mémoire tampon d'erreur de l'interpréteur au lieu de l'effacer. Ceci est utile si l'appelant veut examiner le message d'erreur avant de le remplacer par le sien.
TCL_PARSE_ROOT_VALUE
Pour les opérations d'obtention uniquement : si la variable est une liste, retourner une référence à la valeur de l'objet sous-jacent Tcl plutôt qu'une chaîne de caractères.

DESCRIPTION

Les procédures Tcl_SetVar et Tcl_SetVar2 définissent la valeur d'une variable Tcl. Le nom de la variable peut être un simple nom scalaire ou un nom de tableau suivi d'un index entre crochets, tel que array(index). Si name2 est utilisé (pour Tcl_SetVar2 et Tcl_GetVar2), il est combiné avec name1 pour former le nom complet de la variable. Pour les variables scalaires, name1 contient le nom de la variable et name2 est NULL. Pour les tableaux, name1 contient le nom du tableau et name2 contient l'index.

Lorsque l'indicateur TCL_APPEND_VALUE est utilisé, la nouvelle valeur est ajoutée à la fin de la valeur existante de la variable, séparée par un espace. Lorsque l'indicateur TCL_LIST_ELEMENT est utilisé, la nouvelle valeur est ajoutée comme un nouvel élément de liste à la fin de la variable. Cela est similaire à l'utilisation de la commande Tcl lappend. Le dernier élément ajouté ne sera pas mis entre guillemets sauf si nécessaire pour conserver des caractères spéciaux ou des espaces blancs. Cet indicateur ne doit pas être utilisé pour ajouter le premier élément à une liste ou sous-liste (c'est-à-dire que la valeur actuelle de la variable est vide, contient le caractère unique “{”, ou se termine par “ }”). Lors de l'ajout, la valeur originale de la variable doit également être une liste valide, afin que l'opération soit l'ajout d'un nouvel élément de liste à une liste.

Tcl_GetVar et Tcl_GetVar2 retournent la valeur actuelle d'une variable. Les arguments de ces procédures sont traités de la même manière que les arguments de Tcl_SetVar et Tcl_SetVar2. Dans des circonstances normales, la valeur de retour est un pointeur vers la valeur de la variable (qui est stockée dans la structure de variable de Tcl et ne changera pas avant le prochain appel à Tcl_SetVar ou Tcl_SetVar2). Tcl_GetVar et Tcl_GetVar2 utilisent les bits d'indicateurs TCL_GLOBAL_ONLY et TCL_LEAVE_ERR_MSG, qui ont tous deux la même signification que pour Tcl_SetVar. Si une erreur se produit lors de la lecture de la variable (par exemple, la variable n'existe pas ou un élément de tableau est spécifié pour une variable scalaire), alors NULL est retourné.

Tcl_UnsetVar et Tcl_UnsetVar2 peuvent être utilisés pour supprimer une variable, de sorte que les appels futurs à Tcl_GetVar ou Tcl_GetVar2 pour cette variable retourneront une erreur. Les arguments de ces procédures sont traités de la même manière que les arguments de Tcl_GetVar et Tcl_GetVar2. Si la variable est supprimée avec succès, TCL_OK est retourné. Si la variable ne peut pas être supprimée parce qu'elle n'existe pas, TCL_ERROR est retourné. Si un élément de tableau est spécifié, l'élément donné est supprimé mais le tableau reste. Si un nom de tableau est spécifié sans index, alors le tableau entier est supprimé.
