Tcl_Cancel(3) Procédures de bibliothèque Tcl Tcl_Cancel(3)

NOM

Tcl_CancelEval, Tcl_Canceled - annuler des scripts Tcl

SYNTAXE

#include <tcl.h>
int
Tcl_CancelEval(interp, resultObjPtr, clientData, flags)

int
Tcl_Canceled(interp, flags)

ARGUMENTS

Tcl_Interp *interp (entrée)
Interpréteur dans lequel annuler le script.
Tcl_Obj *resultObjPtr (entrée)
Message d'erreur à utiliser pour l'annulation, ou NULL pour utiliser un message par défaut. S'il n'est pas NULL, le compteur de références de cet objet sera décrémenté avant le retour de Tcl_CancelEval.
int flags (entrée)
Combinaison OR de bits d'indicateurs spécifiant des options supplémentaires. Pour Tcl_CancelEval, seul TCL_CANCEL_UNWIND est actuellement supporté. Pour Tcl_Canceled, seuls TCL_LEAVE_ERR_MSG et TCL_CANCEL_UNWIND sont actuellement supportés.
ClientData clientData (entrée)
Actuellement réservé pour une utilisation future. Il doit être défini à NULL.

DESCRIPTION

Tcl_CancelEval annule ou déroule le script en cours peu après la prochaine invocation des gestionnaires asynchrones, provoquant un code de retour TCL_ERROR pour ce script. Cette fonction est thread-safe et peut être appelée depuis n'importe quel thread du processus.

Tcl_Canceled vérifie si le script en cours a été annulé et renvoie TCL_ERROR s'il l'a été. Sinon, TCL_OK est renvoyé. Les extensions peuvent utiliser cette fonction pour vérifier si elles doivent abandonner une commande longue. Cette fonction est sensible aux threads et ne peut être appelée que depuis le thread dans lequel l'interpréteur a été créé.

BITS DES INDICATEURS

Toute combinaison OR des valeurs suivantes peut être utilisée pour l'argument flags des procédures telles que Tcl_CancelEval :

TCL_CANCEL_UNWIND
Cet indicateur est utilisé par Tcl_CancelEval et Tcl_Canceled. Pour Tcl_CancelEval, si cet indicateur est défini, le script en cours est annulé et la pile d'évaluation de l'interpréteur est déroulée. Pour Tcl_Canceled, si cet indicateur est défini, le script en cours n'est considéré comme annulé que si la pile d'évaluation de l'interpréteur est déroulée.
TCL_LEAVE_ERR_MSG
Cet indicateur est uniquement utilisé par Tcl_Canceled ; il est ignoré par d'autres procédures. Si une erreur est renvoyée et que ce bit est défini dans flags, un message d'erreur sera laissé dans le résultat de l'interpréteur, où il pourra être récupéré avec Tcl_GetObjResult ou Tcl_GetStringResult. Si ce bit d'indicateur n'est pas défini, aucun message d'erreur n'est laissé et le résultat de l'interpréteur ne sera pas modifié.
