Tcl_DoOneEvent(3) Procédures de bibliothèque Tcl Tcl_DoOneEvent(3)

NOM

Tcl_DoOneEvent - attendre les événements et appeler les gestionnaires d'événements

SYNTAXE

#include <tcl.h>

int
Tcl_DoOneEvent(flags)

ARGUMENTS

int flags (entrée)
Ce paramètre est normalement zéro. Il peut être une combinaison OR de n'importe laquelle des bits de drapeau suivants : TCL_WINDOW_EVENTS, TCL_FILE_EVENTS, TCL_TIMER_EVENTS, TCL_IDLE_EVENTS, TCL_ALL_EVENTS, ou TCL_DONT_WAIT.

DESCRIPTION

Cette procédure est le point d'entrée de la boucle d'événements de Tcl ; elle est responsable de l'attente des événements et de la distribution des gestionnaires d'événements créés avec des procédures telles que Tk_CreateEventHandler, Tcl_CreateFileHandler, Tcl_CreateTimerHandler, et Tcl_DoWhenIdle. Tcl_DoOneEvent vérifie si des événements sont déjà présents dans la file d'attente d'événements Tcl ; si c'est le cas, elle appelle le(s) gestionnaire(s) du premier (plus ancien) événement, le retire de la file d'attente, et retourne. S'il n'y a pas d'événements prêts à être traités, alors Tcl_DoOneEvent vérifie les nouveaux événements de toutes les sources possibles. Si des événements sont trouvés, elle les ajoute tous à la file d'attente d'événements Tcl, appelle les gestionnaires pour le premier événement de la file, et retourne. Si aucun événement n'est trouvé, Tcl_DoOneEvent vérifie les rappels Tcl_DoWhenIdle ; si des rappels sont trouvés, elle les invoque tous et retourne. Enfin, si aucun événement ou rappel inactif n'a été trouvé, alors Tcl_DoOneEvent se met en veille jusqu'à ce qu'un événement se produise ; elle ajoute ensuite tous les nouveaux événements à la file d'attente d'événements Tcl, appelle les gestionnaires pour le premier événement, et retourne. La valeur de retour normale est 1 pour signaler qu'un événement a été traité (voir ci-dessous pour d'autres alternatives).

Si le paramètre flags de Tcl_DoOneEvent est non nul, il restreint les types d'événements qui seront traités par Tcl_DoOneEvent. Flags peut être une combinaison OR de n'importe lequel des bits suivants :

TCL_WINDOW_EVENTS -
Traiter les événements du système de fenêtrage.
TCL_FILE_EVENTS -
Traiter les événements de fichiers.
TCL_TIMER_EVENTS -
Traiter les événements de minuteur.
TCL_IDLE_EVENTS -
Traiter les rappels inactifs.
TCL_ALL_EVENTS -
Traiter tous les types d'événements : équivalent à OR-er tous les indicateurs ci-dessus ou à ne spécifier aucun d'entre eux.
TCL_DONT_WAIT -
Ne pas dormir : traiter uniquement les événements qui sont prêts au moment de l'appel.

Si l'un des indicateurs TCL_WINDOW_EVENTS, TCL_FILE_EVENTS, TCL_TIMER_EVENTS, ou TCL_IDLE_EVENTS est défini, alors les seuls événements considérés seront ceux pour lesquels les indicateurs sont définis. Ne pas définir ces indicateurs est équivalent à la valeur TCL_ALL_EVENTS, qui provoque le traitement de tous les types d'événements. Si une application a défini des sources d'événements supplémentaires avec Tcl_CreateEventSource, alors des valeurs d'indicateurs supplémentaires peuvent également être valides, en fonction de ces sources d'événements.

L'indicateur TCL_DONT_WAIT fait que Tcl_DoOneEvent ne met pas le processus en veille : il vérifie les événements mais si aucun n'est trouvé, il retourne immédiatement avec une valeur de retour de 0 pour indiquer qu'aucun travail n'a été effectué. Tcl_DoOneEvent retournera également 0 sans rien faire si la seule alternative est de bloquer indéfiniment (cela peut arriver, par exemple, si flags est TCL_IDLE_EVENTS et qu'il n'y a pas de rappels Tcl_DoWhenIdle en attente, ou s'il n'existe aucun gestionnaire d'événements ou gestionnaire de minuteur).

Tcl_DoOneEvent peut être invoqué récursivement. Par exemple, il est possible d'invoquer Tcl_DoOneEvent récursivement à partir d'un gestionnaire appelé par Tcl_DoOneEvent. Ce type d'opération est utile dans certaines situations modales, comme lorsqu'une boîte de dialogue de notification a été ouverte et qu'une application souhaite attendre que l'utilisateur clique sur un bouton dans la boîte de dialogue avant de faire quoi que ce soit d'autre.
