Tcl_ByteArrayObj(3) Procédures de bibliothèque Tcl Tcl_ByteArrayObj(3)

NOM

Tcl_NewByteArrayObj, Tcl_SetByteArrayObj, Tcl_GetByteArrayFromObj, Tcl_SetByteArrayLength - manipuler les valeurs Tcl comme des tableaux d'octets

SYNOPSIS

#include <tcl.h>

Tcl_Obj *
Tcl_NewByteArrayObj(bytes, length)

void
Tcl_SetByteArrayObj(objPtr, bytes, length)

unsigned char *
Tcl_GetByteArrayFromObj(objPtr, lengthPtr)

unsigned char *
Tcl_SetByteArrayLength(objPtr, length)

ARGUMENTS

const unsigned char *bytes (entrée)
Le tableau d'octets utilisé pour initialiser ou définir une valeur de type tableau d'octets. Peut être NULL même si length est non nul.
int length (entrée)
La longueur du tableau d'octets. Doit être >= 0.
Tcl_Obj *objPtr (entrée/sortie)
Pour Tcl_SetByteArrayObj, pointe vers la valeur à convertir en type tableau d'octets. Pour Tcl_GetByteArrayFromObj et Tcl_SetByteArrayLength, pointe vers la valeur à partir de laquelle obtenir la valeur de type tableau d'octets ; si objPtr ne pointe pas déjà vers une valeur de type tableau d'octets, elle sera convertie.
int *lengthPtr (sortie)
Si non NULL, rempli avec la longueur du tableau d'octets dans la valeur.

DESCRIPTION

Ces procédures sont utilisées pour créer, modifier et lire des valeurs Tcl de type tableau d'octets à partir du code C. Les valeurs de type tableau d'octets sont généralement utilisées pour contenir les résultats des opérations d'E/S binaires ou les structures de données créées avec la commande binary. Dans Tcl, un tableau d'octets n'est pas équivalent à une chaîne. Conceptuellement, une chaîne est un tableau de caractères Unicode, tandis qu'un tableau d'octets est un tableau de quantités de 8 bits sans signification implicite. Des fonctions d'accès sont fournies pour obtenir la représentation sous forme de chaîne d'un tableau d'octets ou pour convertir une valeur arbitraire en tableau d'octets. L'obtention de la représentation sous forme de chaîne d'une valeur de type tableau d'octets (en appelant Tcl_GetStringFromObj) produit une séquence UTF-8 correctement formée avec un mappage univoque entre les octets de la représentation interne et les caractères UTF-8 de la représentation sous forme de chaîne.

Tcl_NewByteArrayObj et Tcl_SetByteArrayObj créeront une nouvelle valeur de type tableau d'octets ou modifieront une valeur existante pour qu'elle soit de type tableau d'octets. Ces deux procédures définissent le type de la valeur sur tableau d'octets et sa représentation interne sur une copie du tableau d'octets fourni par bytes. Tcl_NewByteArrayObj retourne un pointeur vers une valeur nouvellement allouée avec un compteur de références de zéro. Tcl_SetByteArrayObj invalide toute ancienne représentation sous forme de chaîne et, si la valeur n'est pas déjà de type tableau d'octets, libère toute ancienne représentation interne. Si bytes est NULL, le nouveau tableau d'octets contient des valeurs arbitraires.

Tcl_GetByteArrayFromObj convertit une valeur Tcl en type tableau d'octets et retourne un pointeur vers la nouvelle représentation interne de la valeur sous forme de tableau d'octets. La longueur de ce tableau est stockée dans lengthPtr si lengthPtr n'est pas NULL. Le stockage pour le tableau d'octets est possédé par la valeur et ne doit pas être libéré. Le contenu du tableau peut être modifié par l'appelant uniquement si la valeur n'est pas partagée et que l'appelant invalide la représentation sous forme de chaîne.

Tcl_SetByteArrayLength convertit la valeur Tcl en type tableau d'octets et modifie la longueur de la représentation interne de la valeur sous forme de tableau d'octets. Si length est supérieur à l'espace actuellement alloué pour le tableau, le tableau est réalloué à la nouvelle longueur ; les octets nouvellement alloués à la fin du tableau ont des valeurs arbitraires. Si length est inférieur à l'espace actuellement alloué pour le tableau, la longueur du tableau est réduite à la nouvelle longueur. La valeur de retour est un pointeur vers le nouveau tableau d'octets de la valeur.
