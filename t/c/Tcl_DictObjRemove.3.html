ARGUMENTS

Tcl_Interp *interp (in)
Si une erreur se produit lors de la conversion d'une valeur en valeur de type dictionnaire, un message d'erreur est laissé dans la valeur de résultat de l'interpréteur, sauf si interp est nul.
Tcl_Obj *dictPtr (in/out)
Pointe vers la valeur de type dictionnaire à manipuler. Si dictPtr ne pointe pas déjà vers une valeur de type dictionnaire, une tentative sera faite pour la convertir.
Tcl_Obj *keyPtr (in)
Pointe vers la clé de la paire clé-valeur en cours de manipulation dans la valeur de type dictionnaire.
Tcl_Obj **keyPtrPtr (out)
Pointe vers une variable qui contiendra la clé d'une paire clé-valeur qui y sera placée. Peut être NULL pour indiquer que l'appelant ne s'intéresse pas à la clé.
Tcl_Obj *valuePtr (in)
Pointe vers la valeur de la paire clé-valeur en cours de manipulation dans la valeur de type dictionnaire (ou sous-valeur, dans le cas de Tcl_DictObjPutKeyList).
Tcl_Obj **valuePtrPtr (out)
Pointe vers une variable qui contiendra la valeur d'une paire clé-valeur qui y sera placée. Pour Tcl_DictObjFirst et Tcl_DictObjNext, cela peut être NULL pour indiquer que l'appelant ne s'intéresse pas à la valeur.
int *sizePtr (out)
Pointe vers une variable qui contiendra le nombre de paires clé-valeur contenues dans le dictionnaire.
Tcl_DictSearch *searchPtr (in/out)
Pointeur vers un enregistrement utilisé pour suivre la progression dans l'énumération de toutes les paires clé-valeur d'un dictionnaire. Le contenu de l'enregistrement est initialisé par l'appel à Tcl_DictObjFirst. Si l'énumération doit se terminer avant que toutes les valeurs du dictionnaire n'aient été renvoyées, l'enregistrement de recherche doit être passé à Tcl_DictObjDone pour libérer les poignées internes.
int *donePtr (out)
Pointe vers une variable qui contiendra une valeur non nulle lorsque l'énumération de toutes les paires clé-valeur du dictionnaire sera terminée, et zéro sinon.
int keyc (in)
Indique le nombre de clés qui seront fournies dans le tableau keyv.
Tcl_Obj *const *keyv (in)
Tableau de keyc pointeurs vers des valeurs que Tcl_DictObjPutKeyList et Tcl_DictObjRemoveKeyList utiliseront pour trouver la paire clé-valeur à manipuler dans les sous-dictionnaires de la valeur principale du dictionnaire.

DESCRIPTION

Les valeurs de type dictionnaire Tcl ont une représentation interne qui supporte le mappage efficace des clés aux valeurs et garantit que l'ordre des clés dans le dictionnaire reste le même, sauf si elles sont supprimées (ce qui les retire de l'ordre) ou ajoutées (ce qui les ajoute à la fin de l'ordre). Si elles sont réinterprétées comme une liste, les valeurs aux indices pairs de la liste seront les clés du dictionnaire, et chacune sera suivie (à l'indice impair) par la valeur associée à cette clé.

Les procédures décrites dans cette page de manuel sont utilisées pour créer, modifier, indexer et itérer sur des valeurs de type dictionnaire à partir du code C.

Tcl_NewDictObj crée une nouvelle valeur de type dictionnaire vide. La représentation chaîne de la valeur sera invalide, et le compteur de références de la valeur sera zéro.

Tcl_DictObjGet recherche la clé donnée dans le dictionnaire et écrit un pointeur vers la valeur associée à cette clé dans la variable indiquée par valuePtrPtr, ou NULL s'il n'y a pas de mappage pour cette clé dans le dictionnaire. Le résultat de cette opération est TCL_OK, ou TCL_ERROR si dictPtr ne peut pas être converti en dictionnaire.

Tcl_DictObjPut met à jour le dictionnaire de telle sorte que la clé donnée mappe à la valeur donnée ; chaque clé ne peut exister qu'une seule fois dans un dictionnaire donné. Le dictionnaire ne doit pas être partagé, mais les clés et les valeurs le peuvent. Cette opération peut incrémenter le compteur de références de la clé et de la valeur si elles doivent être stockées. Ni la clé ni la valeur ne doivent être NULL. Le résultat de cette opération est TCL_OK, ou TCL_ERROR si dictPtr ne peut pas être converti en dictionnaire.

Tcl_DictObjRemove met à jour le dictionnaire de telle sorte que la clé donnée ne mappe à aucune valeur. Le dictionnaire ne doit pas être partagé, mais la clé le peut. La clé réellement présente dans le dictionnaire verra son compteur de références décrémenté si elle était présente. Ce n'est pas une erreur si la clé n'existait pas auparavant. Le résultat de cette opération est TCL_OK, ou TCL_ERROR si dictPtr ne peut pas être converti en dictionnaire.

Tcl_DictObjSize met à jour la variable indiquée avec le nombre de paires clé-valeur actuellement dans le dictionnaire. Le résultat de cette opération est TCL_OK, ou TCL_ERROR si dictPtr ne peut pas être converti en dictionnaire.

Tcl_DictObjFirst initie une itération sur toutes les paires clé-valeur du dictionnaire, en plaçant la clé et la valeur dans les variables indiquées par keyPtrPtr et valuePtrPtr (qui peuvent être NULL pour indiquer que l'appelant ne s'y intéresse pas). La paire clé-valeur suivante dans le dictionnaire peut être obtenue avec Tcl_DictObjNext. Les mises à jour concurrentes de la représentation interne du dictionnaire ne modifieront pas la progression de l'itération, sauf si le dictionnaire n'est pas partagé, auquel cas l'itération se terminera prématurément (ce qui ne peut pas arriver avec la commande dict dans les scripts Tcl). L'argument searchPtr pointe vers un contexte utilisé pour identifier quelle itération spécifique est en cours, et est initialisé par l'appel à Tcl_DictObjFirst. L'argument donePtr pointe vers une variable qui est mise à zéro s'il reste des paires clé-valeur à itérer, ou à une valeur non nulle si l'itération est terminée. L'ordre de l'itération est défini par l'implémentation. Si l'argument dictPtr ne peut pas être converti en dictionnaire, Tcl_DictObjFirst renvoie TCL_ERROR et l'itération n'est pas démarrée, et renvoie sinon TCL_OK.

Lorsqu'une valeur de dictionnaire est passée à Tcl_DictObjFirst, un bloc de contrôle est placé sur le dictionnaire pour permettre son itération sécurisée, indépendamment du fait que le dictionnaire soit modifié pendant l'itération. Pour cette raison, une fois que l'itération sur les clés d'un dictionnaire est terminée (soit parce que le nombre de valeurs itérées est complet, indiqué par l'argument donePtr mis à un, soit parce que plus aucune valeur n'est nécessaire), Tcl_DictObjDone doit être appelée avec le même searchPtr que celui utilisé dans Tcl_DictObjFirst pour libérer les poignées internes. Une fois qu'un searchPtr particulier a été passé à Tcl_DictObjDone, le passer à Tcl_DictObjNext (sans l'avoir préalablement initialisé avec Tcl_DictObjFirst) entraînera la non-production de valeurs et la variable indiquée par donePtr sera mise à un. Il est sûr d'appeler Tcl_DictObjDone plusieurs fois avec le même searchPtr pour chaque appel à Tcl_DictObjFirst.

Les procédures Tcl_DictObjPutKeyList et Tcl_DictObjRemoveKeyList sont des analogies proches de Tcl_DictObjPut et Tcl_DictObjRemove respectivement, sauf qu'elles opèrent sur un seul dictionnaire et sont conçues pour fonctionner sur une hiérarchie de dictionnaires internes, avec des dictionnaires internes stockés comme valeurs dans des dictionnaires externes. Les arguments keyc et keyv spécifient une liste de clés (avec les clés externes en premier) qui agit comme un chemin vers la paire clé-valeur à modifier. Notez qu'il n'existe pas d'opération correspondante pour lire une valeur.

NOM

Tcl_DictObjRemove

SYNOPIS

Tcl_DictObjRemove(interp, objPtr, search, key, value)

ARGUMENTS

interp Interpréteur Tcl
objPtr Tcl_Obj
search Tcl_DictObjSearch
key Tcl_Obj
value Tcl_Obj

DESCRIPTION

Tcl_DictObjRemove supprime une clé d'un dictionnaire. La clé est supprimée du dictionnaire si c'est une clé non terminale, ou si c'est la seule clé du dictionnaire. Si la clé est une clé terminale, elle est supprimée du dictionnaire. La clé est supprimée du dictionnaire uniquement s'il s'agit d'une clé non terminale. EXEMPLE

Utilisation de l'interface d'itération de dictionnaire pour rechercher et déterminer s'il existe une clé qui se mappe à elle-même :

Tcl_DictSearch search;
Tcl_Obj *key, *value;
int done;
/*
 * Supposons que interp et objPtr soient des paramètres. C'est la
 * manière idiomatique de démarrer une itération sur le dictionnaire ; cela
 * verrouille la représentation interne, garantissant
 * qu'il n'y a pas de problèmes de modification concurrente lorsque la gestion
 * normale des comptes de référence est également utilisée. Le verrou est
 * libéré automatiquement une fois la boucle terminée, mais doit
 * être libéré manuellement en cas de sortie exceptionnelle de la boucle.
 * Cependant, il est sûr de tenter de libérer le verrou
 * même si nous avons terminé l'itération.
 */
if (Tcl_DictObjFirst(interp, objPtr, &search,
        &key, &value, &done) != TCL_OK) {
    return TCL_ERROR;
}
for (; !done ; Tcl_DictObjNext(&search, &key, &value, &done)) {
    /*
     * Notez que strcmp() n'est pas une bonne méthode pour comparer
     * les valeurs et est seulement utilisé ici à des fins de démonstration.
     */
    if (!strcmp(Tcl_GetString(key), Tcl_GetString(value))) {
        break;
    }
}
Tcl_DictObjDone(&search);
Tcl_SetObjResult(interp, Tcl_NewBooleanObj(!done));
return TCL_OK;
