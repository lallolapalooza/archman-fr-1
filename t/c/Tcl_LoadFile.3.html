Tcl_LoadFile(3)

Paquet: tcl

Licences: TCL

Load(3) Procédures de bibliothèque Tcl Load(3)

NOM

Tcl_LoadFile, Tcl_FindSymbol - chargement de bibliothèques dynamiques indépendant de la plateforme

SYNOPSIS

#include <tcl.h>

int
Tcl_LoadFile(interp, pathPtr, symbols, flags, procPtrs, loadHandlePtr)

void *
Tcl_FindSymbol(interp, loadHandle, symbol)

ARGUMENTS

Tcl_Interp *interp (en entrée)
Interpréteur à utiliser pour rapporter les messages d'erreur.
Tcl_Obj *pathPtr (en entrée)
Le nom du fichier à charger. S'il s'agit d'un nom unique, le chemin de recherche des bibliothèques de l'environnement actuel sera utilisé pour le résoudre.
const char *const symbols[] (en entrée)
Tableau de noms de symboles à résoudre lors du chargement de la bibliothèque, ou NULL si aucun symbole ne doit être résolu. Si un tableau est donné, la dernière entrée du tableau doit être NULL.
int flags (en entrée)
La valeur devrait normalement être 0, mais TCL_LOAD_GLOBAL ou TCL_LOAD_LAZY ou une combinaison des deux est également autorisée.
void *procPtrs (en sortie)
Pointe vers un tableau qui contiendra les adresses des fonctions décrites dans l'argument symbols. Devrait être NULL si aucun symbole ne doit être résolu.
Tcl_LoadHandle *loadHandlePtr (en sortie)
Pointe vers une variable qui contiendra le handle du jeton abstrait décrivant la bibliothèque qui a été chargée.
Tcl_LoadHandle loadHandle (en entrée)
Jeton abstrait décrivant la bibliothèque dans laquelle chercher un symbole.
const char *symbol (en entrée)
Le nom du symbole à rechercher.

DESCRIPTION

Tcl_LoadFile charge un fichier depuis le système de fichiers (y compris potentiellement tout système de fichiers virtuel qui a été installé) et fournit un handle pour celui-ci qui peut être utilisé pour d'autres opérations. Le tableau symbols, s'il n'est pas NULL, fournit un ensemble de noms de symboles (typiquement des fonctions) qui doivent être résolus à partir de la bibliothèque et qui seront stockés dans le tableau indiqué par procPtrs. Si l'un des symboles n'est pas résolu, le chargement du fichier échouera avec un message d'erreur laissé dans l'interpréteur (si celui-ci n'est pas NULL). Le résultat de Tcl_LoadFile est un code d'erreur Tcl standard. La bibliothèque peut être déchargée avec Tcl_FSUnloadFile.

Tcl_FindSymbol localise un symbole dans une bibliothèque chargée et le retourne. Si le symbole ne peut pas être trouvé, il retourne NULL et définit un message d'erreur dans l'interp donné (s'il n'est pas NULL). Notez qu'il est dangereux d'utiliser cette opération sur un handle qui a été passé à Tcl_FSUnloadFile.
