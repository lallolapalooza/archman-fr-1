Tcl_ListObjAppendList(3)

Paquet: tcl

Licences: TCL

Tcl_ListObj(3) Procédures de la bibliothèque Tcl Tcl_ListObj(3)

NOM

Tcl_ListObjAppendList, Tcl_ListObjAppendElement, Tcl_NewListObj, Tcl_SetListObj, Tcl_ListObjGetElements, Tcl_ListObjLength, Tcl_ListObjIndex, Tcl_ListObjReplace - manipuler des valeurs Tcl sous forme de listes

SYNTAXE

#include <tcl.h>

int
Tcl_ListObjAppendList(interp, listPtr, elemListPtr)

int
Tcl_ListObjAppendElement(interp, listPtr, objPtr)

Tcl_Obj *
Tcl_NewListObj(objc, objv)

Tcl_SetListObj(objPtr, objc, objv)

int
Tcl_ListObjGetElements(interp, listPtr, objcPtr, objvPtr)

int
Tcl_ListObjLength(interp, listPtr, lengthPtr)

int
Tcl_ListObjIndex(interp, listPtr, index, objPtrPtr)

int
Tcl_ListObjReplace(interp, listPtr, first, count, objc, objv)

ARGUMENTS

Tcl_Interp *interp (in)
Si une erreur se produit lors de la conversion d'une valeur en liste, un message d'erreur sera laissé dans la valeur de résultat de l'interpréteur, sauf si interp est NULL.
Tcl_Obj *listPtr (in/out)
Désigne la valeur de liste à manipuler. Si listPtr ne pointe pas déjà vers une liste, une tentative sera faite pour le convertir en liste.
Tcl_Obj *elemListPtr (in/out)
Pour Tcl_ListObjAppendList, pointe vers une valeur de liste contenant des éléments à ajouter à listPtr. Chaque élément de elemListPtr sera converti en un élément de listPtr. Si elemListPtr n'est pas NULL et ne pointe pas déjà vers une liste, une tentative sera faite pour le convertir en liste.
Tcl_Obj *objPtr (in)
Pour Tcl_ListObjAppendElement, pointe vers la valeur Tcl à ajouter à listPtr. Pour Tcl_SetListObj, pointe vers la valeur Tcl à convertir en liste avec les éléments du tableau référencé par objv.
int *objcPtr (in)
Pointe vers l'emplacement où Tcl_ListObjGetElements stocke le nombre de valeurs d'élément dans listPtr.
Tcl_Obj ***objvPtr (out)
Un emplacement où Tcl_ListObjGetElements stocke un pointeur vers un tableau de pointeurs vers les valeurs d'élément de listPtr.
int objc (in)
Le nombre de valeurs Tcl que Tcl_NewListObj insérera dans une nouvelle valeur de liste, et que Tcl_ListObjReplace insérera dans listPtr. Pour Tcl_SetListObj, le nombre de valeurs Tcl à insérer dans objPtr.
Tcl_Obj *const objv[] (in)
Un tableau de pointeurs vers des valeurs. Tcl_NewListObj insérera ces valeurs dans une nouvelle valeur de liste, et Tcl_ListObjReplace insérera dans un listPtr existant. Chaque valeur sera convertie en un élément de liste distinct.
int *lengthPtr (out)
Pointe vers l'emplacement où Tcl_ListObjLength stocke la longueur de la liste.
int index (in)
Indice de l'élément de liste que Tcl_ListObjIndex retournera. Le premier élément a l'indice 0.
Tcl_Obj **objPtrPtr (out)
Pointe vers l'emplacement où Tcl_ListObjIndex stocke un pointeur vers la valeur de l'élément de liste résultant.
int first (in)
Indice du premier élément de liste que Tcl_ListObjReplace remplacera. Le premier élément a l'indice 0.
int count (in)
Le nombre d'éléments que Tcl_ListObjReplace remplacera.

DESCRIPTION

Les valeurs de liste Tcl ont une représentation interne qui prend en charge l'indexation et l'ajout efficaces. Les fonctions décrites dans cette page de manuel sont utilisées pour créer, modifier, indexer et ajouter à des valeurs de liste Tcl à partir du code C.

Tcl_ListObjAppendList et Tcl_ListObjAppendElement ajoutent une ou plusieurs valeurs à la valeur de liste référencée par listPtr. Tcl_ListObjAppendList ajoute chaque élément de la valeur de liste référencée par elemListPtr tandis que Tcl_ListObjAppendElement ajoute la valeur unique référencée par objPtr. Les deux procédures convertiront la valeur référencée par listPtr en liste si nécessaire. Si une erreur se produit pendant la conversion, les deux procédures retourneront TCL_ERROR et laisseront un message d'erreur dans la valeur de résultat de l'interpréteur si interp n'est pas NULL. De même, si elemListPtr ne pointe pas déjà vers une liste, Tcl_ListObjAppendList tentera de le convertir en liste et si une erreur se produit pendant la conversion, retournera TCL_ERROR et laissera un message d'erreur dans la valeur de résultat de l'interpréteur si interp n'est pas NULL. Les deux procédures invalident toute représentation précédente de listPtr et, si elle a été convertie en liste, libéreront toute représentation interne précédente. De même, Tcl_ListObjAppendList libère toute représentation interne précédente de elemListPtr si elle est convertie en liste. Après avoir ajouté chaque élément dans elemListPtr, Tcl_ListObjAppendList incrémente le compteur de références de chaque élément car listPtr pointe désormais également vers eux. Pour la même raison, Tcl_ListObjAppendElement incrémente le compteur de références de objPtr. S'il n'y a pas d'erreur, les deux procédures retournent TCL_OK après avoir ajouté les valeurs.

Tcl_NewListObj et Tcl_SetListObj créent une nouvelle valeur ou modifient une valeur existante pour contenir les objc éléments du tableau référencé par objv où chaque élément est un pointeur vers une valeur Tcl. Si objc est inférieur ou égal à zéro, elles retournent une valeur vide. Si objv est NULL, le résultat contient 0 élément, avec de l'espace réservé dans la représentation interne pour objc éléments supplémentaires (pour éviter une réallocation plus tard). La nouvelle valeur a une représentation chaîne invalide. Les deux procédures incrémentent les compteurs de références des éléments dans objc car la valeur de liste pointe désormais vers eux. La nouvelle valeur retournée par Tcl_NewListObj a un compteur de références nul.

Tcl_ListObjGetElements retourne un compte et un pointeur vers un tableau des éléments d'une valeur de liste. Le compte est stocké à l'adresse objcPtr. De même, elle stocke le pointeur vers les éléments à l'adresse objvPtr. La mémoire pointée est gérée par Tcl et ne doit pas être libérée ou modifiée par l'appelant. Si la liste est vide, 0 est stocké dans objcPtr et NULL dans objvPtr. Si listPtr ne représente pas déjà une liste, Tcl_ListObjGetElements tentera de le convertir en liste ; si la conversion échoue, elle retourne TCL_ERROR et laisse un message d'erreur dans la valeur de résultat de l'interpréteur si interp n'est pas NULL. Sinon, elle retourne TCL_OK après avoir stocké le compte et le pointeur vers les éléments.

Tcl_ListObjLength retourne le nombre d'éléments dans la valeur de liste référencée par listPtr. Le compte est stocké à l'adresse lengthPtr. Si la valeur ne représente pas déjà une liste, Tcl_ListObjLength tentera de la convertir en liste ; si la conversion échoue, elle retourne TCL_ERROR et laisse un message d'erreur dans la valeur de résultat de l'interpréteur si interp n'est pas NULL. Sinon, elle retourne TCL_OK après avoir stocké la longueur de la liste.

La procédure Tcl_ListObjIndex retourne un pointeur vers la valeur à l'élément index de la liste référencée par listPtr. La valeur est stockée à l'adresse objPtrPtr en tant que pointeur vers la valeur. Si listPtr ne pointe pas déjà vers une liste, Tcl_ListObjIndex tentera de le convertir en liste ; si la conversion échoue, elle retourne TCL_ERROR et laisse un message d'erreur dans la valeur de résultat de l'interpréteur si interp n'est pas NULL. Si l'indice est hors limites, c'est-à-dire, si index est négatif ou supérieur au nombre d'éléments dans la liste, Tcl_ListObjIndex stocke NULL dans objPtrPtr et retourne TCL_OK. Sinon, elle retourne TCL_OK après avoir stocké le pointeur vers la valeur de l'élément. Le compteur de références de l'élément de liste n'est pas incrémenté ; l'appelant doit le faire s'il a besoin de conserver un pointeur vers celui-ci.

Tcl_ListObjReplace remplace zéro ou plusieurs éléments de la liste référencée par listPtr par les objc valeurs du tableau référencé par objv. Si listPtr ne pointe pas vers une liste, Tcl_ListObjReplace tentera de le convertir en liste ; si la conversion échoue, elle retourne TCL_ERROR et laisse un message d'erreur dans la valeur de résultat de l'interpréteur si interp n'est pas NULL. Sinon, elle retourne TCL_OK après avoir remplacé les valeurs. Si objv est NULL, aucun nouvel élément n'est ajouté. Si l'argument first est zéro ou négatif, il fait référence au premier élément. Si first est supérieur ou égal au nombre d'éléments de la liste, les valeurs sont remplacées.

Tcl_ListObjReplace

NAME

Tcl_ListObjReplace – replace a range of elements in a list with new elements

SYNOPSIS

#include <tcl.h>

int
Tcl_ListObjReplace(Tcl_Interp *interp, Tcl_Obj *listPtr,
        int first, int count, int objc,
        const Tcl_Obj *const objv[]);

ARGUMENTS

Tcl_Interp *interp
Interpreter to use for error reporting.
Tcl_Obj *listPtr
Object whose list value is to be modified.
int first
Index of the first element to replace. This is a 0-based index. If negative, it is interpreted as an offset from the end of the list.
int count
Number of elements to replace. If count is 0 or negative, then no elements are deleted, and the new elements are inserted before the one designated by first. If count is larger than the number of elements remaining in the list starting from first, then only the remaining elements are deleted.
int objc
Number of new elements to insert.
const Tcl_Obj *const objv[]
Array of objc elements to insert. If objv is NULL and objc is non-zero, it is an error. If objc is zero, then objv must be NULL or have zero length.

DESCRIPTION

Tcl_ListObjReplace modifies the list value of the object listPtr. The operation replaces the count elements starting at index first with the objc elements from the array objv. The index first is interpreted similarly to the index argument in Tcl commands such as lreplace: a value of 0 refers to the first element, a value of 1 refers to the second, and so on. If first is negative, then it is interpreted as an offset from the end of the list, e.g. -1 refers to the last element, -2 to the second-to-last element. If the calculated index is out of bounds, it is clamped to the nearest valid index (0 or end of list).

If count is zero or negative, no elements are deleted. The new elements from objv are inserted into the list just before the element at index first. If count is larger than the number of elements remaining in the list starting from first, then all elements from first to the end of the list are deleted, and the new elements from objv are appended.

If objc is zero, no elements are added. If count is also zero or negative, the operation has no effect. If count is positive, then the count elements starting at index first are deleted. This is equivalent to calling Tcl_ListObjReplace with a NULL objvPtr and objc equal to 0.

The result is TCL_OK if the replacement was successful, and TCL_ERROR otherwise. If an error occurred, then the error message is left in the interpreter's result.

Tcl_ListObjReplace invalidates listPtr's old string representation. The reference counts of any elements inserted from objv are incremented since the resulting list now refers to them. Similarly, the reference counts for any replaced values are decremented.

Because Tcl_ListObjReplace combines both element insertion and deletion, it can be used to implement a number of list operations. For example, the following code inserts the objc values referenced by the array of value pointers objv just before the element index of the list referenced by listPtr:

result = Tcl_ListObjReplace(interp, listPtr, index, 0,
                                objc, objv);

Similarly, the following code appends the objc values referenced by the array objv to the end of the list listPtr:

result = Tcl_ListObjLength(interp, listPtr, &length);
if (result == TCL_OK) {
    result = Tcl_ListObjReplace(interp, listPtr, length, 0,
            objc, objv);
}

The count list elements starting at first can be deleted by simply calling Tcl_ListObjReplace with a NULL objvPtr:

result = Tcl_ListObjReplace(interp, listPtr, first, count,
                                0, NULL);
