ARGUMENTS

Tcl_Interp *interp (entrée/sortie)
L'interpréteur dans lequel l'espace de noms existe et où les recherches de noms sont effectuées. Les messages d'erreur sont également écrits ici.
const char *name (entrée)
Le nom de l'espace de noms ou de la commande à créer ou à accéder.
ClientData clientData (entrée)
Un pointeur de contexte fourni par le créateur de l'espace de noms. Non interprété par Tcl.
Tcl_NamespaceDeleteProc *deleteProc (entrée)
Un pointeur vers la fonction à appeler lors de la suppression de l'espace de noms, ou NULL s'il n'y a pas de rappel à effectuer.
Tcl_Namespace *nsPtr (entrée)
L'espace de noms à manipuler, ou NULL (pour les fonctions autres que Tcl_DeleteNamespace) pour manipuler l'espace de noms courant.
Tcl_Obj *objPtr (sortie)
Une référence à une valeur non partagée sur laquelle la sortie de la fonction sera écrite.
const char *pattern (entrée)
Le modèle de style glob (voir Tcl_StringMatch) décrivant les commandes à importer ou exporter.
int resetListFirst (entrée)
Indique si la liste des modèles d'exportation doit être réinitialisée avant d'y ajouter le modèle courant.
int allowOverwrite (entrée)
Indique si les nouvelles commandes créées par cette action d'importation peuvent écraser les commandes existantes.
Tcl_Namespace *contextNsPtr (entrée)
L'emplacement dans la hiérarchie des espaces de noms où la recherche d'un espace de noms ou d'une commande doit être effectuée par rapport au terme de recherche lorsqu'il n'est pas ancré dans l'espace de noms global. NULL indique l'espace de noms courant.
int flags (entrée)
Combinaison OR des bits contrôlant la manière dont la recherche doit être effectuée. Les indicateurs suivants sont pris en charge : TCL_GLOBAL_ONLY (indique que la recherche doit toujours être effectuée par rapport à l'espace de noms global), TCL_NAMESPACE_ONLY (uniquement pour Tcl_FindCommand ; indique que la recherche doit toujours être effectuée par rapport à l'espace de noms de contexte), et TCL_LEAVE_ERR_MSG (indique qu'un message d'erreur doit être laissé dans l'interpréteur si la recherche échoue).
Tcl_Obj *handlerPtr (entrée)
Un fragment de script à installer comme gestionnaire de commande inconnue pour l'espace de noms, ou NULL pour réinitialiser le gestionnaire par défaut.

DESCRIPTION

Les espaces de noms sont des contextes de nommage hiérarchiques qui peuvent contenir des commandes et des variables. Ils maintiennent également une liste de modèles décrivant les commandes exportées et peuvent importer des commandes exportées par d'autres espaces de noms. Les espaces de noms peuvent également être manipulés via la commande Tcl namespace.

La structure Tcl_Namespace encapsule un espace de noms et est garantie d'avoir les champs suivants : name (le nom local de l'espace de noms, sans caractères de séparation d'espace de noms, vide dénotant l'espace de noms global), fullName (le nom complet de l'espace de noms), clientData, deleteProc (les valeurs spécifiées lors de l'appel à Tcl_CreateNamespace), et parentPtr (un pointeur vers l'espace de noms contenant, ou NULL pour l'espace de noms global).

Tcl_CreateNamespace crée un nouvel espace de noms. Le deleteProc aura la signature de type suivante :

typedef void Tcl_NamespaceDeleteProc(
        ClientData clientData);

Tcl_DeleteNamespace supprime un espace de noms, en appelant le deleteProc défini pour l'espace de noms (le cas échéant).

Tcl_AppendExportList récupère les modèles d'exportation d'un espace de noms donné et les ajoute (en tant qu'éléments de liste) à objPtr.

Tcl_Export définit et ajoute aux modèles d'exportation d'un espace de noms. Les modèles sont ajoutés sauf si l'indicateur resetListFirst est vrai.

Tcl_Import importe les commandes correspondant à un modèle dans un espace de noms. Notez que le modèle doit inclure le nom de l'espace de noms à importer. Cette fonction renvoie TCL_ERROR si une tentative d'importation d'une commande par-dessus une commande existante est effectuée, sauf si l'indicateur allowOverwrite a été défini.

Tcl_ForgetImport supprime les importations correspondant à un modèle.

Tcl_GetCurrentNamespace renvoie l'espace de noms courant pour un interpréteur.

Tcl_GetGlobalNamespace renvoie l'espace de noms global pour un interpréteur.

Tcl_FindNamespace recherche un espace de noms nommé name dans le contexte de l'espace de noms contextNsPtr. Si l'espace de noms ne peut pas être trouvé, NULL est renvoyé.

Tcl_FindCommand recherche une commande nommée name dans le contexte de l'espace de noms contextNsPtr. Si la commande ne peut pas être trouvée, NULL est renvoyé.

Tcl_GetNamespaceUnknownHandler renvoie le gestionnaire de commande inconnue pour l'espace de noms, ou NULL s'il n'est pas défini.

Tcl_SetNamespaceUnknownHandler définit le gestionnaire de commande inconnue pour l'espace de noms. Si handlerPtr est NULL, alors le gestionnaire est réinitialisé à son état par défaut.
