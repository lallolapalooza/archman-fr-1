FIONREAD(2const) FIONREAD(2const)

NOM

FIONREAD, TIOCINQ, TIOCOUTQ, TCFLSH, TIOCSERGETLSR - nombre d'octets dans le tampon et vidage

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <asm/termbits.h>  /* Définition des constantes */
#include <sys/ioctl.h>
int ioctl(int fd, FIONREAD, int *argp);
int ioctl(int fd, TIOCINQ, int *argp);
int ioctl(int fd, TIOCOUTQ, int *argp);
int ioctl(int fd, TCFLSH, int arg);
int ioctl(int fd, TIOCSERGETLSR, int *argp);

DESCRIPTION

FIONREAD
Obtenir le nombre d'octets dans le tampon d'entrée.
TIOCINQ
Identique à FIONREAD.
TIOCOUTQ
Obtenir le nombre d'octets dans le tampon de sortie.
TCFLSH
Équivalent à tcflush(fd, arg).
Voir tcflush(3) pour les valeurs d'argument TCIFLUSH, TCOFLUSH, TCIOFLUSH.
TIOCSERGETLSR
Obtenir le registre d'état de la ligne. Le registre d'état a le bit TIOCSER_TEMT positionné lorsque le tampon de sortie est vide et que l'émetteur matériel est également physiquement vide.
Ne doit pas nécessairement être pris en charge par tous les pilotes de tty série.
tcdrain(3) ne bloque pas et retourne immédiatement lorsque le bit TIOCSER_TEMT est positionné.

VALEUR RENVOYÉE

En cas de succès, 0 est retourné. En cas d'erreur, -1 est retourné, et errno est positionné pour indiquer l'erreur.

VOIR AUSSI

ioctl(2), ioctl_tty(2), tcflush(3), termios(3)
