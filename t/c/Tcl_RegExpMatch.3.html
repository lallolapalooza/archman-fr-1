SYNOPSIS

#include <tcl.h>

int
Tcl_RegExpMatchObj(interp, textObj, patObj)

int
Tcl_RegExpMatch(interp, text, pattern)

Tcl_RegExp
Tcl_RegExpCompile(interp, pattern)

int
Tcl_RegExpExec(interp, regexp, text, start)

void
Tcl_RegExpRange(regexp, index, startPtr, endPtr)

Tcl_RegExp
Tcl_GetRegExpFromObj(interp, patObj, cflags)

int
Tcl_RegExpExecObj(interp, regexp, textObj, offset, nmatches, eflags)

void
Tcl_RegExpGetInfo(regexp, infoPtr)

ARGUMENTS

Tcl_Interp *interp (in)
Interpréteur Tcl à utiliser pour le signalement des erreurs. L'interpréteur peut être NULL si aucun signalement d'erreur n'est souhaité.
Tcl_Obj *textObj (in/out)
Pointe vers la valeur à partir de laquelle le texte à rechercher est obtenu. La représentation interne de la valeur peut être convertie dans une forme efficace pour la recherche.
Tcl_Obj *patObj (in/out)
Pointe vers la valeur à partir de laquelle l'expression régulière est obtenue. L'expression régulière compilée est stockée dans la valeur.
const char *text (in)
Texte pour rechercher une correspondance avec une expression régulière.
const char *pattern (in)
Texte sous forme de motif d'expression régulière.
Tcl_RegExp regexp (in)
Expression régulière compilée. Elle doit avoir été précédemment retournée par Tcl_GetRegExpFromObj ou Tcl_RegExpCompile.
const char *start (in)
Si text n'est qu'une partie d'un autre texte, cet argument identifie le début du texte plus grand. S'il n'est pas le même que text, alors les correspondances de ^ ne seront pas autorisées.
int index (in)
Indique la plage souhaitée : 0 signifie la plage de la correspondance complète, 1 ou plus signifie la plage qui correspond à une sous-expression imbriquée.
const char **startPtr (out)
L'adresse du premier caractère de la plage est stockée ici, ou NULL s'il n'existe pas de telle plage.
const char **endPtr (out)
L'adresse du caractère juste après le dernier caractère de la plage est stockée ici, ou NULL s'il n'existe pas de telle plage.
int cflags (in)
OR des indicateurs de compilation TCL_REG_ADVANCED, TCL_REG_EXTENDED, TCL_REG_BASIC, TCL_REG_EXPANDED, TCL_REG_QUOTE, TCL_REG_NOCASE, TCL_REG_NEWLINE, TCL_REG_NLSTOP, TCL_REG_NLANCH, TCL_REG_NOSUB, et TCL_REG_CANMATCH. Voir plus d'informations ci-dessous.
int offset (in)
Le décalage du caractère dans le texte où la correspondance doit commencer. La valeur du décalage n'a aucun impact sur les correspondances de ^. Ce comportement est contrôlé par eflags.
int nmatches (in)
Le nombre de sous-expressions correspondantes qui doivent être mémorisées pour une utilisation ultérieure. Si cette valeur est 0, aucune information de sous-expression correspondante ne sera calculée. Si la valeur est -1, toutes les sous-expressions correspondantes seront mémorisées. Toute autre valeur sera considérée comme le nombre maximum de sous-expressions correspondantes à mémoriser.
int eflags (in)
OR des indicateurs d'exécution TCL_REG_NOTBOL et TCL_REG_NOTEOL. Voir plus d'informations ci-dessous.
Tcl_RegExpInfo *infoPtr (out)
L'adresse de l'emplacement où les informations d'une correspondance précédente doivent être stockées par Tcl_RegExpGetInfo.

DESCRIPTION

Tcl_RegExpMatch détermine si son argument pattern correspond à regexp, où regexp est interprété comme une expression régulière en utilisant les règles de la page de référence re_syntax. S'il y a une correspondance, Tcl_RegExpMatch retourne 1. S'il n'y a pas de correspondance, elle retourne 0. Si une erreur survient pendant le processus de correspondance (par exemple, pattern n'est pas une expression régulière valide), Tcl_RegExpMatch retourne -1 et laisse un message d'erreur dans le résultat de l'interpréteur. Tcl_RegExpMatchObj est similaire à Tcl_RegExpMatch mais opère sur les valeurs Tcl textObj et patObj au lieu de chaînes UTF. Tcl_RegExpMatchObj est généralement plus efficace que Tcl_RegExpMatch, c'est donc l'interface préférée.

Tcl_RegExpCompile, Tcl_RegExpExec et Tcl_RegExpRange fournissent un accès de plus bas niveau au module de motifs d'expressions régulières. Tcl_RegExpCompile compile une chaîne de motif d'expression régulière dans la forme interne pour une recherche efficace. La valeur de retour est un jeton pour cette forme compilée, qui peut être utilisé dans des appels ultérieurs à Tcl_RegExpExec ou Tcl_RegExpRange. Si une erreur survient lors de la compilation de l'expression régulière, Tcl_RegExpCompile retourne NULL et laisse un message d'erreur dans le résultat de l'interpréteur. Note : la valeur de retour de Tcl_RegExpCompile est valide jusqu'au prochain appel à Tcl_RegExpCompile ; il n'est pas sûr de conserver ces valeurs pendant longtemps.

Tcl_RegExpExec exécute le module de motif d'expression régulière. Il retourne 1 si text contient une plage de caractères qui correspond à regexp, 0 s'il n'y a pas de correspondance, et -1 si une erreur survient. En cas d'erreur, Tcl_RegExpExec laisse un message d'erreur dans le résultat de l'interpréteur. Lors de la recherche d'un texte pour plusieurs correspondances d'un motif, il est important de distinguer entre le début du texte d'origine et le début de la recherche actuelle. Par exemple, lors de la recherche de la deuxième occurrence d'une correspondance, l'argument text peut pointer vers le caractère juste après la première correspondance ; cependant, il est important pour le module de motif de savoir que ce n'est pas le début du texte complet, donc les atomes ^ dans le motif ne seront pas autorisés. L'argument start fournit cette information en pointant vers le début du texte complet contenant text. Start sera inférieur ou égal à text ; s'il est inférieur à text, les correspondances de ^ ne seront pas autorisées.

Tcl_RegExpRange peut être appelé après que Tcl_RegExpExec a retourné ; il fournit des informations détaillées sur la plage de la chaîne qui correspondait à quelle partie du motif. Tcl_RegExpRange retourne une paire de pointeurs dans *startPtr et *endPtr qui identifient une plage de caractères dans la chaîne source de l'appel le plus récent à Tcl_RegExpExec. Index indique quelle plage parmi plusieurs est souhaitée : si index est 0, des informations sur la plage générale de caractères qui correspondait au motif complet sont retournées ; sinon, des informations sur la plage de caractères qui correspondait à la sous-expression index-ième dans le motif sont retournées. S'il n'y a pas de plage correspondant à index, NULL est stocké dans *startPtr et *endPtr.

Tcl_GetRegExpFromObj, Tcl_RegExpExecObj et Tcl_RegExpGetInfo sont des interfaces de valeur qui fournissent le contrôle le plus direct de la bibliothèque d'expressions régulières de Henry Spencer. Pour les utilisateurs qui ont besoin de modifier directement les options de compilation et d'exécution, il est recommandé d'utiliser ces interfaces plutôt que d'appeler les fonctions internes de regexp. Ces interfaces gèrent les conversions UTF vers Unicode et offrent de meilleures performances en mettant en cache les motifs et les chaînes de caractères.

Tcl_GetRegExpFromObj tente de retourner une expression régulière compilée à partir de patObj. Si la valeur ne contient pas déjà une expression régulière compilée, elle tente d'en créer une à partir de la chaîne contenue dans la valeur et de l'attribuer à la représentation interne de patObj. La valeur de retour de cette fonction est de type Tcl_RegExp. La valeur de retour est un jeton pour cette forme compilée, qui peut être utilisé dans des appels ultérieurs à Tcl_RegExpExecObj ou Tcl_RegExpGetInfo. Si une erreur survient lors de la compilation de l'expression régulière, Tcl_GetRegExpFromObj retourne NULL et laisse un message d'erreur dans le résultat de l'interpréteur. Le jeton d'expression régulière peut être utilisé tant que la représentation interne de patObj pointe vers la forme compilée. L'argument cflags est un OR de zéro ou plusieurs des indicateurs suivants qui contrôlent la compilation de patObj :

TCL_REG_ADVANCED
Indicateur de compilation avancé.

SYNTAXE

Tcl_RegExpMatch(3) - Correspondance d'expressions régulières

ARGUMENTS

Tcl_RegExpMatch(3) prend les arguments suivants :

TCL_REG_MATCH
Correspondance d'une expression régulière avec une chaîne de caractères.

DESCRIPTION

Tcl_RegExpMatch(3) effectue une correspondance d'expressions régulières. L'expression régulière est comparée à la chaîne de caractères. L'argument objPtr pointe vers la chaîne à faire correspondre. L'argument regexp est l'expression régulière à faire correspondre. L'argument offset spécifie l'indice du caractère de départ dans la chaîne. L'argument length spécifie le nombre de caractères à faire correspondre. L'argument nmatches spécifie le nombre de sous-expressions à faire correspondre. L'argument eflags spécifie les indicateurs pour la correspondance. L'argument match spécifie le résultat de la correspondance.
