Tcl_InitStubs(3) Procédures de la bibliothèque Tcl Tcl_InitStubs(3)

NOM

Tcl_InitStubs - initialise le mécanisme de stub Tcl

SYNTAXE

#include <tcl.h>

const char *
Tcl_InitStubs(interp, version, exact)

ARGUMENTS

Tcl_Interp *interp (entrée)
Handle de l'interpréteur Tcl.
const char *version (entrée)
Une chaîne de version composée d'un ou plusieurs nombres décimaux séparés par des points.
int exact (entrée)
Une valeur non nulle signifie que seule la version spécifiée par version est acceptable. Une valeur nulle signifie que les versions plus récentes que version sont également acceptables tant qu'elles ont le même numéro de version majeure que version.

INTRODUCTION

Le mécanisme de stub Tcl définit une manière de lier dynamiquement des extensions à une implémentation Tcl particulière au moment de l'exécution. Cela offre deux avantages significatifs aux utilisateurs de Tcl :

1)
Les extensions qui utilisent le mécanisme de stub peuvent être chargées dans plusieurs versions de Tcl sans être recompilées ou relinkées.
2)
Les extensions qui utilisent le mécanisme de stub peuvent être chargées dynamiquement dans des applications Tcl liées statiquement.

Le mécanisme de stub y parvient en exportant des tables de fonctions qui définissent une interface avec l'API Tcl. L'extension accède alors à l'API Tcl via des décalages dans la table de fonctions, de sorte qu'il n'y a pas de références directes à aucun des symboles de la bibliothèque Tcl. Cette redirection est transparente pour l'extension, de sorte qu'un auteur d'extension peut continuer à utiliser toutes les fonctions publiques de Tcl telles que documentées.

Le mécanisme de stub ne nécessite aucune modification des applications intégrant des interpréteurs Tcl. Seuls les développeurs créant des extensions Tcl basées sur C doivent prendre des mesures pour utiliser le mécanisme de stub avec leurs extensions.

L'activation du mécanisme de stub pour une extension nécessite les étapes suivantes :

1)
Appeler Tcl_InitStubs dans l'extension avant d'appeler toute autre fonction Tcl.
2)
Définir le symbole USE_TCL_STUBS. Typiquement, vous incluriez le flag -DUSE_TCL_STUBS lors de la compilation de l'extension.
3)
Lier l'extension avec la bibliothèque de stub Tcl au lieu de la bibliothèque Tcl standard. Par exemple, pour utiliser l'ABI Tcl 8.6 sur les plateformes Unix, le nom de la bibliothèque est libtclstub8.6.a ; sur les plateformes Windows, le nom de la bibliothèque est tclstub86.lib.

Si l'extension nécessite également l'API Tk, elle doit également appeler Tk_InitStubs pour initialiser l'interface de stub Tk et être liée avec les bibliothèques de stub Tk. Voir la page Tk_InitStubs pour plus d'informations.

DESCRIPTION

Tcl_InitStubs tente d'initialiser les pointeurs de table de stub et de s'assurer que la version correcte de Tcl est chargée. En plus d'un handle d'interpréteur, elle accepte comme arguments un numéro de version et un flag booléen indiquant si l'extension nécessite une correspondance exacte de version ou non. Si exact est 0, alors l'extension indique que les versions plus récentes de Tcl sont acceptables tant qu'elles ont le même numéro de version majeure que version ; une valeur non nulle signifie que seule la version spécifiée est acceptable. Tcl_InitStubs retourne une chaîne contenant la version réelle de Tcl satisfaisant la demande, ou NULL si la version Tcl n'est pas acceptable, ne prend pas en charge les stubs, ou si une autre condition d'erreur s'est produite.
