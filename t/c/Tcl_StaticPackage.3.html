Tcl_StaticPackage(3) Procédures de bibliothèque Tcl Tcl_StaticPackage(3)

NOM

Tcl_StaticPackage - rendre un paquet lié statiquement disponible via la commande 'load'

SYNTAXE

#include <tcl.h>

Tcl_StaticPackage(interp, prefix, initProc, safeInitProc)

ARGUMENTS

Tcl_Interp *interp (entrée)
Si ce n'est pas NULL, pointe vers un interpréteur dans lequel le paquet a déjà été chargé (c'est-à-dire, l'appelant a déjà invoqué la procédure d'initialisation appropriée). NULL signifie que le paquet n'a pas encore été incorporé dans un interpréteur.
const char *prefix (entrée)
Préfixe pour la fonction d'initialisation de la bibliothèque ; doit être correctement capitalisé (première lettre majuscule, toutes les autres minuscules).
Tcl_PackageInitProc *initProc (entrée)
Procédure à invoquer pour incorporer ce paquet dans un interpréteur de confiance.
Tcl_PackageInitProc *safeInitProc (entrée)
Procédure à appeler pour incorporer ce paquet dans un interpréteur sécurisé (un qui exécutera des scripts non fiables). NULL signifie que le paquet ne peut pas être utilisé dans les interpréteurs sécurisés.

DESCRIPTION

Cette procédure peut être invoquée pour annoncer qu'un paquet a été lié statiquement avec une application Tcl et, éventuellement, qu'il a déjà été chargé dans un interpréteur. Une fois que Tcl_StaticPackage a été invoqué pour un paquet, il peut être chargé dans des interpréteurs en utilisant la commande load. Tcl_StaticPackage n'est normalement invoqué que par la procédure Tcl_AppInit pour l'application, et non par les paquets eux-mêmes (Tcl_StaticPackage ne devrait être invoqué que pour les paquets liés statiquement, et le code dans le paquet lui-même ne devrait pas avoir besoin de savoir si le paquet est chargé dynamiquement ou statiquement).

Lorsque la commande load est utilisée ultérieurement pour charger le paquet dans un interpréteur, l'une des procédures initProc et safeInitProc sera invoquée, en fonction de si l'interpréteur cible est sécurisé ou non. initProc et safeInitProc doivent tous deux correspondre au prototype suivant :

typedef int Tcl_PackageInitProc(
        Tcl_Interp *interp);

L'argument interp identifie l'interpréteur dans lequel le paquet doit être chargé. La procédure d'initialisation doit retourner TCL_OK ou TCL_ERROR pour indiquer si elle s'est terminée avec succès ou non ; en cas d'erreur, elle doit définir le résultat de l'interpréteur pour pointer vers un message d'erreur. Le résultat ou l'erreur de la procédure d'initialisation sera retourné comme résultat de la commande load qui a provoqué l'invocation de la procédure d'initialisation.
