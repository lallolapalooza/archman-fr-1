NOM

Tcl_PrintDouble - Convertir une valeur flottante en chaîne de caractères

SYNOPSIS

#include <tcl.h>

Tcl_PrintDouble(interp, value, dst)

ARGUMENTS

Tcl_Interp *interp (entrée)
Avant Tcl 8.0, la variable tcl_precision de cet interpréteur contrôlait la conversion. Depuis Tcl 8.0, cet argument est ignoré et la conversion est contrôlée par la variable tcl_precision qui est maintenant partagée par tous les interpréteurs.
double value (entrée)
Valeur flottante à convertir.
char *dst (sortie)
Emplacement où stocker la chaîne représentant value. Doit disposer d'un espace d'au moins TCL_DOUBLE_SPACE caractères.

DESCRIPTION

Tcl_PrintDouble génère une chaîne de caractères qui représente la valeur de value et la stocke dans la mémoire à l'emplacement indiqué par dst. Elle utilise le format %g pour générer la chaîne, avec une particularité : la chaîne contiendra nécessairement un “.” ou un “e” afin qu'elle ne ressemble pas à un entier. Lorsque %g générerait un entier sans point décimal, Tcl_PrintDouble ajoute “.0”.

Si la valeur de tcl_precision est non nulle, le résultat aura précisément ce nombre de chiffres de signification. Si la valeur est nulle (par défaut), le résultat aura le minimum de chiffres nécessaires pour représenter le nombre de telle sorte que Tcl_NewDoubleObj générera le même nombre lorsqu'on lui présentera la chaîne donnée. Les sémantiques IEEE d'arrondi au pair s'appliquent à la conversion.

MOTS-CLÉS

conversion, double précision, virgule flottante, chaîne de caractères
