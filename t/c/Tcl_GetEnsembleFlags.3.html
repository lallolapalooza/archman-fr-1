ARGUMENTS

Tcl_Interp *interp (in/out)
L'interpréteur dans lequel l'ensemble est créé ou trouvé. C'est également là que les messages d'erreur de résultat sont écrits. Les fonctions dont le nom commence par Tcl_GetEnsemble peuvent avoir un interp NULL, mais toutes les autres fonctions ne le peuvent pas.
const char *name (in)
Le nom de la commande d'ensemble à créer.
Tcl_Namespace *namespacePtr (in)
L'espace de noms dans lequel la commande d'ensemble sera liée, ou NULL pour l'espace de noms actuel.
int ensFlags (in)
Un ensemble OR'ed de bits d'indicateurs décrivant la configuration de base de l'ensemble. Actuellement, un seul bit a du sens, TCL_ENSEMBLE_PREFIX, qui est présent lorsque la commande d'ensemble doit également correspondre à des préfixes clairs de sous-commandes.
Tcl_Obj *cmdNameObj (in)
Une valeur contenant le nom de la commande d'ensemble à trouver.
int flags (in)
Un ensemble OR'ed de bits contrôlant le comportement de Tcl_FindEnsemble. Actuellement, seul TCL_LEAVE_ERR_MSG est pris en charge.
Tcl_Command token (in)
Un jeton de commande normal faisant référence à une commande d'ensemble, ou que vous souhaitez utiliser pour tester comme commande d'ensemble dans Tcl_IsEnsemble.
int *ensFlagsPtr (out)
Un pointeur vers une variable dans laquelle les bits des indicateurs actuels de l'ensemble sont écrits ; actuellement, seul le bit TCL_ENSEMBLE_PREFIX est défini.
Tcl_Obj *dictObj (in)
Une valeur de dictionnaire à utiliser comme dictionnaire de mappage des préfixes de sous-commandes dans l'ensemble. Peut être NULL si le dictionnaire de mappage doit être supprimé.
Tcl_Obj **dictObjPtr (out)
Un pointeur vers une variable dans laquelle le dictionnaire de mappage actuel de l'ensemble est écrit.
Tcl_Obj *listObj (in)
Une valeur de liste à utiliser comme liste de paramètres formels de pré-sous-commande, la liste définie dans le dictionnaire, ou le préfixe des sous-commandes non définies. Peut être NULL si la liste de sous-commandes ou le préfixe de gestion des sous-commandes non définies doit être supprimé.
Tcl_Obj **listObjPtr (out)
Un pointeur vers une variable dans laquelle la liste de paramètres formels de pré-sous-commande, la liste définie dans le dictionnaire, ou le préfixe actuel de gestion des sous-commandes non définies est écrit.
Tcl_Namespace **namespacePtrPtr (out)
Un pointeur vers une variable dans laquelle le handle de l'espace de noms dans lequel la commande d'ensemble est liée est écrit.

DESCRIPTION

Un ensemble est une commande, liée à un espace de noms, qui consiste en une collection de sous-commandes implémentées par d'autres commandes Tcl. Le premier argument de la commande d'ensemble est toujours interprété comme un sélecteur indiquant quelle sous-commande sera exécutée.

Les ensembles sont créés à l'aide de Tcl_CreateEnsemble, qui prend quatre arguments : l'interpréteur avec lequel travailler, le nom de l'ensemble à créer, l'espace de noms au sein de l'interpréteur dans lequel l'ensemble est lié, et l'ensemble d'indicateurs par défaut de l'ensemble. Le résultat de la fonction est le jeton de commande de l'ensemble, qui peut être utilisé pour configurer l'ensemble via l'API décrit dans PROPRIÉTÉS DE L'ENSEMBLE.

Étant donné le nom d'une commande d'ensemble, le jeton de cette commande peut être récupéré à l'aide de Tcl_FindEnsemble. Si le nom donné (dans cmdNameObj) ne fait pas référence à une commande d'ensemble, le résultat de la fonction est NULL et si le bit TCL_LEAVE_ERR_MSG est défini dans flags, un message d'erreur est laissé dans le résultat de l'interpréteur.

Un jeton de commande peut être vérifié pour voir s'il fait référence à un ensemble à l'aide de Tcl_IsEnsemble. Ceci renvoie 1 si le jeton fait référence à un ensemble, ou 0 sinon.

PROPRIÉTÉS DE L'ENSEMBLE

Chaque ensemble a quatre propriétés en lecture/écriture et une propriété en lecture seule. Les propriétés sont :

indicateurs (lecture/écriture)
L'ensemble des indicateurs pour l'ensemble, exprimé sous forme de champ de bits. Actuellement, le seul indicateur public est TCL_ENSEMBLE_PREFIX qui est défini lorsque des préfixes clairs de sous-commandes peuvent être résolus en implémentations ainsi que des correspondances exactes. Les indicateurs peuvent être lus et écrits à l'aide de Tcl_GetEnsembleFlags et Tcl_SetEnsembleFlags respectivement. Le résultat des deux fonctions est un code de résultat Tcl (TCL_OK, ou TCL_ERROR si le jeton ne fait pas référence à un ensemble).
dictionnaire de mappage (lecture/écriture)
Un dictionnaire contenant un mappage des noms de sous-commandes à des listes de mots qui sont utilisés comme préfixes de commandes (remplaçant les deux premiers mots de la commande, qui sont la commande d'ensemble et le nom de la sous-commande), ou NULL si toutes les sous-commandes sont mappées à des commandes portant le même nom sans espace qualifié dans l'espace de noms de l'ensemble. La valeur par défaut est NULL. Peut être lu et écrit à l'aide de Tcl_GetEnsembleMappingDict et Tcl_SetEnsembleMappingDict respectivement. Le résultat des deux fonctions est un code de résultat Tcl (TCL_OK, ou TCL_ERROR si le jeton ne fait pas référence à un ensemble) et le dictionnaire obtenu de Tcl_GetEnsembleMappingDict doit toujours être traité comme immuable, même s'il n'est pas partagé. Tous les noms de commandes dans les préfixes définis avec Tcl_SetEnsembleMappingDict doivent être entièrement qualifiés.
liste de paramètres formels de pré-sous-commande (lecture/écriture)
Une liste de noms de paramètres formels (utilisés uniquement lorsque un message d'erreur est généré) qui sont invoqués entre le nom de l'ensemble et l'argument de sous-commande. NULL (la valeur par défaut) équivaut à une liste vide. Peut être lu et écrit à l'aide de Tcl_GetEnsembleParameterList et Tcl_SetEnsembleParameterList respectivement. Le résultat des deux fonctions est un code de résultat Tcl (TCL_OK, ou TCL_ERROR si le jeton ne fait pas référence à un ensemble) et le dictionnaire obtenu de Tcl_GetEnsembleParameterList doit toujours être traité comme immuable, même s'il n'est pas partagé.
liste de sous-commandes (lecture/écriture)
Une liste de tous les noms de sous-commandes pour l'ensemble, ou NULL si celle-ci est dérivée des clés du dictionnaire de mappage (voir ci-dessus) ou (si celui-ci est également NULL) des commandes exportées par l'espace de noms lié. Peut être lu et écrit à l'aide de Tcl_GetEnsembleSubcommandList et Tcl_SetEnsembleSubcommandList respectivement. Le résultat des deux fonctions est un code de résultat Tcl (TCL_OK, ou TCL_ERROR si le jeton ne fait pas référence à un ensemble) et la liste obtenue de Tcl_GetEnsembleSubcommandList doit toujours être traitée comme immuable, même si elle n'est pas partagée.
préfixe de commandes de gestion des sous-commandes inconnues (lecture/écriture)

NOM

Tcl_GetEnsembleFlags

SYNOPSIS

Tcl_GetEnsembleFlags(interp, flags)

ARGUMENTS

interp -- l'interpréteur Tcl

flags -- indicateurs pour l'ensemble

DESCRIPTION

La commande Tcl_GetEnsembleFlags renvoie les indicateurs de l'ensemble. Les indicateurs sont utilisés pour déterminer comment l'ensemble est traité. Les indicateurs peuvent être définis en utilisant la commande Tcl_SetEnsembleFlags.

VOIR AUSSI

ensemble(n), Tcl_DeleteCommandFromToken(3)

MOTS CLÉS

indicateurs, ensemble
