ARGUMENTS

Tcl_Interp *interp (in)
Interpréteur contenant la variable.
const char *name1 (in)
Nom d'une variable de tableau (si name2 est non nul) ou (si name2 est nul) nom d'une variable scalaire ou nom complet incluant le nom de la variable et l'index. Peut inclure :: pour spécifier une variable dans un espace de noms particulier.
const char *name2 (in)
S'il n'est pas nul, donne le nom de l'élément dans un tableau; dans ce cas, name1 doit faire référence à une variable de tableau.
Tcl_Obj *newValuePtr (in)
Pointeur vers une valeur Tcl contenant la nouvelle valeur de la variable.
int flags (in)
OR bit à bit fournissant des informations supplémentaires. Voir ci-dessous pour les valeurs valides.
const char *varName (in)
Nom de la variable. Peut inclure :: pour spécifier une variable dans un espace de noms particulier. Peut faire référence à une variable scalaire ou à un élément de tableau.
const char *newValue (in)
Nouvelle valeur pour la variable, spécifiée sous forme de chaîne terminée par un caractère nul. Une copie de cette valeur sera stockée dans la variable.
Tcl_Obj *part1Ptr (in)
Pointeur vers une valeur Tcl contenant le nom de la variable. Le nom peut inclure une série de :: pour spécifier une variable dans un espace de noms particulier. Peut faire référence à une variable scalaire ou à un élément d'une variable de tableau.
Tcl_Obj *part2Ptr (in)
S'il n'est pas nul, pointe vers une valeur contenant le nom d'un élément dans un tableau et part1Ptr doit faire référence à une variable de tableau.

DESCRIPTION

Ces procédures sont utilisées pour créer, modifier, lire et supprimer des variables Tcl à partir du code C.

Tcl_SetVar2Ex, Tcl_SetVar, Tcl_SetVar2 et Tcl_ObjSetVar2 créeront une nouvelle variable ou modifieront une existante. Ces procédures définissent la valeur donnée par newValuePtr ou newValue dans la variable donnée et retournent un pointeur vers sa nouvelle valeur, qui est stockée dans la structure de variable Tcl. Tcl_SetVar2Ex et Tcl_ObjSetVar2 utilisent la valeur Tcl_Obj comme nouvelle valeur et retournent un pointeur vers un Tcl_Obj. Tcl_SetVar et Tcl_SetVar2 utilisent la valeur donnée comme chaîne et retournent une chaîne; elles sont généralement moins efficaces que Tcl_ObjSetVar2. Note : la valeur retournée peut être différente de l'argument newValuePtr ou newValue, en raison des modifications apportées par les traces d'écriture. Si une erreur survient lors de la définition de la variable (par exemple, une variable de tableau est référencée sans spécifier d'index), NULL est retourné et un message d'erreur est laissé dans interp si le bit TCL_LEAVE_ERR_MSG est activé.

Tcl_GetVar2Ex, Tcl_GetVar, Tcl_GetVar2 et Tcl_ObjGetVar2 retournent la valeur actuelle d'une variable. Les arguments de ces procédures sont traités de la même manière que les arguments des procédures décrites ci-dessus. Dans des conditions normales, la valeur retournée est un pointeur vers la valeur de la variable. Pour Tcl_GetVar2Ex et Tcl_ObjGetVar2, la valeur est retournée sous forme de pointeur vers un Tcl_Obj. Pour Tcl_GetVar et Tcl_GetVar2, la valeur est retournée sous forme de chaîne; c'est généralement moins efficace, il est donc recommandé d'utiliser Tcl_GetVar2Ex ou Tcl_ObjGetVar2. Si une erreur survient lors de la lecture de la variable (par exemple, la variable n'existe pas ou un élément de tableau est spécifié pour une variable scalaire), NULL est retourné et un message d'erreur est laissé dans interp si le bit TCL_LEAVE_ERR_MSG est activé.

Tcl_UnsetVar et Tcl_UnsetVar2 peuvent être utilisés pour supprimer une variable, de sorte que les tentatives futures de la lire renverront une erreur. Les arguments de ces procédures sont traités de la même manière que les arguments des procédures précédentes. Si la variable est supprimée avec succès, TCL_OK est retourné. Si la variable ne peut pas être supprimée car elle n'existe pas, TCL_ERROR est retourné et un message d'erreur est laissé dans interp si le bit TCL_LEAVE_ERR_MSG est activé. Si un élément de tableau est spécifié, l'élément donné est supprimé mais le tableau est conservé. Si un nom de tableau sans index est spécifié, l'entier est supprimé.

Le nom d'une variable peut être spécifié à ces procédures de quatre manières différentes:

[1]
Si Tcl_SetVar, Tcl_GetVar ou Tcl_UnsetVar est appelé, le nom de la variable est passé sous forme d'une seule chaîne, varName. Si varName contient une parenthèse et se termine par une parenthèse fermante, la valeur entre les parenthèses est traitée comme un index (toute valeur de chaîne) et les caractères avant la première parenthèse sont traités comme le nom d'une variable de tableau. Si varName n'a pas de parenthèses comme décrit ci-dessus, l'entier est traité comme le nom d'une variable scalaire.
[2]
Si name1 et name2 sont fournis et que name2 n'est pas nul, un élément de tableau est spécifié et le nom du tableau et l'index ont déjà été séparés par l'appelant: name1 contient le nom et name2 contient l'index. Une erreur est générée si name1 contient une parenthèse et se termine par une parenthèse fermante (élément de tableau) et que name2 n'est pas nul.
[3]
Si name2 est nul, name1 est traité comme varName dans le cas [1] ci-dessus (peut être un nom de variable scalaire ou de tableau).

L'argument flags peut être utilisé pour spécifier l'une des plusieurs options aux procédures. Il est composé d'une combinaison OR des bits suivants:

TCL_GLOBAL_ONLY
Normalement, les procédures recherchent les variables comme suit. S'il y a un appel actif dans interp, la variable est recherchée dans le niveau d'appel de procédure actuel. Sinon, elle est recherchée d'abord dans l'espace de noms actuel, puis dans l'espace global. Cependant, si le bit est activé dans flags, la variable est recherchée uniquement dans l'espace global, même s'il y a un appel actif. Si TCL_GLOBAL_ONLY et TCL_NAMESPACE_ONLY sont tous deux fournis, TCL_GLOBAL_ONLY est ignoré.
TCL_NAMESPACE_ONLY
Si ce bit est activé dans flags, la variable est recherchée uniquement dans l'espace de noms actuel; s'il y a un appel actif, ses variables sont ignorées, et l'espace global est également ignoré, sauf s'il s'agit de l'espace de noms actuel.
TCL_LEAVE_ERR_MSG
Si une erreur est retournée et que ce bit est activé, un message d'erreur est laissé dans le résultat de l'interpréteur, où il peut être récupéré avec Tcl_GetObjResult ou Tcl_GetStringResult. Si ce bit n'est pas activé, aucun message d'erreur n'est laissé et le résultat de l'interpréteur n'est pas modifié.
TCL_APPEND_VALUE
Si ce bit est activé, newValuePtr ou newValue est ajouté à la valeur actuelle de la variable au lieu de la remplacer. Si la variable n'est actuellement pas définie, ce bit est ignoré. Ce bit est utilisé uniquement par les procédures Tcl_Set*.
TCL_LIST_ELEMENT
Si ce bit est activé, newValue est converti en un élément de liste Tcl valide avant de définir (ou d'ajouter) la variable. Un espace séparateur est ajouté avant le nouvel élément de liste. Si le nom de la variable est un élément de liste, la valeur spécifiée est utilisée.

Tcl_GetVar et Tcl_GetVar2 retournent la valeur actuelle d'une variable. Les arguments de ces procédures sont traités de la même manière que les arguments de Tcl_SetVar et Tcl_SetVar2. Dans des circonstances normales, la valeur de retour est un pointeur vers la valeur de la variable (qui est stockée dans la structure de variables de Tcl et ne changera pas avant le prochain appel à Tcl_SetVar ou Tcl_SetVar2). Tcl_GetVar et Tcl_GetVar2 utilisent les bits d'indicateur TCL_GLOBAL_ONLY et TCL_LEAVE_ERR_MSG, qui ont tous deux la même signification que pour Tcl_SetVar. Si une erreur se produit lors de la lecture de la variable (par exemple, la variable n'existe pas ou un élément de tableau est spécifié pour une variable scalaire), NULL est retourné.

Tcl_UnsetVar et Tcl_UnsetVar2 peuvent être utilisés pour supprimer une variable, de sorte que les appels futurs à Tcl_GetVar ou Tcl_GetVar2 pour cette variable retourneront une erreur. Les arguments de ces procédures sont traités de la même manière que les arguments de Tcl_GetVar et Tcl_GetVar2. Si la variable est supprimée avec succès, TCL_OK est retourné. Si la variable ne peut pas être supprimée car elle n'existe pas, TCL_ERROR est retourné. Si un élément de tableau est spécifié, l'élément donné est supprimé mais le tableau reste. Si un nom de tableau est spécifié sans index, alors le tableau entier est supprimé.
