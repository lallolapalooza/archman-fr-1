ARGUMENTS

Tcl_Interp *interp (in/out)
L'interpréteur dans lequel l'ensemble est créé ou trouvé. C'est aussi là que les messages d'erreur de résultat sont écrits. Les fonctions commençant par Tcl_GetEnsemble peuvent avoir une valeur NULL pour interp, mais les autres ne le peuvent pas.
const char *name (in)
Le nom de la commande d'ensemble à créer.
Tcl_Namespace *namespacePtr (in)
L'espace de noms dans lequel la commande d'ensemble sera liée, ou NULL pour l'espace de noms courant.
int ensFlags (in)
Un ensemble OR'ed de bits de drapeau décrivant la configuration de base de l'ensemble. Actuellement, un seul bit est pertinent, TCL_ENSEMBLE_PREFIX, qui est présent lorsque la commande d'ensemble doit également correspondre aux préfixes des sous-commandes claires.
Tcl_Obj *cmdNameObj (in)
Une valeur d'objet contenant le nom de la commande d'ensemble à rechercher.
int flags (in)
Un ensemble OR'ed de bits contrôlant le comportement de Tcl_FindEnsemble. Actuellement, seul TCL_LEAVE_ERR_MSG est supporté.
Tcl_Command token (in)
Un jeton de commande normal faisant référence à une commande d'ensemble, ou que vous souhaitez utiliser comme une commande d'ensemble dans Tcl_IsEnsemble.
int *ensFlagsPtr (out)
Un pointeur vers une variable dans laquelle les bits de drapeau actuels de l'ensemble sont écrits ; actuellement, seul le bit TCL_ENSEMBLE_PREFIX est défini.
Tcl_Obj *dictObj (in)
Une valeur de dictionnaire pour le dictionnaire de mappage des sous-commandes à la liste des commandes d'implémentation du sous-commande dans l'ensemble. Peut être NULL si le dictionnaire de mappage doit être supprimé.
Tcl_Obj **dictObjPtr (out)
Un pointeur vers une variable dans laquelle le dictionnaire de mappage des sous-commandes actuel de l'ensemble est écrit.
Tcl_Obj *listObj (in)
Une valeur de liste pour la liste des paramètres formels des sous-commandes, la liste définie dans le dictionnaire ou le préfixe des commandes de gestion des sous-commandes inconnues. Peut être NULL si la liste des sous-commandes ou le préfixe de gestion des sous-commandes inconnues doit être supprimé.
Tcl_Obj **listObjPtr (out)
Un pointeur vers une variable dans laquelle la liste des paramètres formels des sous-commandes, la liste définie dans le dictionnaire ou le préfixe actuel des commandes de gestion des sous-commandes inconnues est écrit.
Tcl_Namespace **namespacePtrPtr (out)
Un pointeur vers une variable dans laquelle le handle de l'espace de noms auquel l'ensemble est lié est écrit.

DESCRIPTION

Un ensemble est une commande, liée à un espace de noms, qui se compose d'une collection de sous-commandes implémentées par d'autres commandes Tcl. Le premier argument de la commande d'ensemble est toujours interprété comme un sélecteur indiquant quelle sous-commande exécuter.

Les ensembles sont créés à l'aide de Tcl_CreateEnsemble, qui prend quatre arguments : l'interpréteur sur lequel travailler, le nom de l'ensemble à créer, l'espace de noms dans l'interpréteur auquel l'ensemble sera lié, et l'ensemble de drapeaux par défaut de l'ensemble. Le résultat de la fonction est le jeton de commande pour l'ensemble, qui peut être utilisé pour configurer l'ensemble à l'aide de l'API décrite ci-dessous dans PROPRIÉTÉS DE L'ENSEMBLE.

Étant donné le nom d'une commande d'ensemble, le jeton de cette commande peut être récupéré à l'aide de Tcl_FindEnsemble. Si le nom donné (dans cmdNameObj) ne fait pas référence à une commande d'ensemble, le résultat de la fonction est NULL et (si le bit TCL_LEAVE_ERR_MSG est défini dans flags) un message d'erreur est laissé dans le résultat de l'interpréteur.

Un jeton de commande peut être vérifié pour voir s'il fait référence à un ensemble à l'aide de Tcl_IsEnsemble. Cette fonction renvoie 1 si le jeton fait référence à un ensemble, ou 0 sinon.

PROPRIÉTÉS DE L'ENSEMBLE

Chaque ensemble possède quatre propriétés en lecture/écriture et une propriété en lecture seule. Les propriétés sont :

drapeaux (lecture/écriture)
L'ensemble des drapeaux de l'ensemble, exprimé sous forme de champ de bits. Actuellement, le seul drapeau public est TCL_ENSEMBLE_PREFIX, qui est défini lorsque les préfixes clairs des sous-commandes sont autorisés à être résolus en implémentations ainsi qu'en correspondances exactes. Les drapeaux peuvent être lus et écrits respectivement à l'aide de Tcl_GetEnsembleFlags et Tcl_SetEnsembleFlags. Le résultat des deux fonctions est un code de résultat Tcl (TCL_OK, ou TCL_ERROR si le jeton ne fait pas référence à un ensemble).
dictionnaire de mappage (lecture/écriture)
Un dictionnaire contenant un mappage des noms de sous-commandes à des listes de mots qui servent de préfixe aux commandes (remplaçant les deux premiers mots de la commande, qui sont la commande d'ensemble elle-même et le nom de la sous-commande), ou NULL si chaque sous-commande est mappée au même nom de commande dans l'espace de noms de l'ensemble. Par défaut, il est NULL. Il peut être lu et écrit respectivement à l'aide de Tcl_GetEnsembleMappingDict et Tcl_SetEnsembleMappingDict. Le résultat des deux fonctions est un code de résultat Tcl (TCL_OK, ou TCL_ERROR si le jeton ne fait pas référence à un ensemble) et le dictionnaire obtenu de Tcl_GetEnsembleMappingDict doit toujours être traité comme immuable même s'il n'est pas partagé. Tous les noms de commandes dans les préfixes définis par Tcl_SetEnsembleMappingDict doivent être entièrement qualifiés.
liste des paramètres formels des sous-commandes (lecture/écriture)
Une liste de noms de paramètres formels (utilisés uniquement lors de la génération de messages d'erreur) qui sont appelés entre le nom de l'ensemble et l'argument de la sous-commande. NULL (la valeur par défaut) équivaut à une liste vide. Elle peut être lue et écrite respectivement à l'aide de Tcl_GetEnsembleParameterList et Tcl_SetEnsembleParameterList. Le résultat des deux fonctions est un code de résultat Tcl (TCL_OK, ou TCL_ERROR si le jeton ne fait pas référence à un ensemble) et le dictionnaire obtenu de Tcl_GetEnsembleParameterList doit toujours être traité comme immuable même s'il n'est pas partagé.
liste des sous-commandes (lecture/écriture)
Une liste de tous les noms de sous-commandes de l'ensemble, ou NULL si celle-ci est dérivée des clés du dictionnaire de mappage (voir ci-dessus) ou (si elle est également NULL) des commandes exportées par l'espace de noms lié. Elle peut être lue et écrite respectivement à l'aide de Tcl_GetEnsembleSubcommandList et Tcl_SetEnsembleSubcommandList. Le résultat des deux fonctions est un code de résultat Tcl (TCL_OK, ou TCL_ERROR si le jeton ne fait pas référence à un ensemble) et la liste obtenue de Tcl_GetEnsembleSubcommandList doit toujours être traitée comme immuable même si elle n'est pas partagée.
préfixe des commandes de gestion des sous-commandes inconnues (lecture/écriture)
Une liste de mots qui sont placés devant toute sous-commande lorsque celle-ci n'est pas reconnue par l'ensemble (selon le critère de résolution du préfixe actuel). Elle peut être lue et écrite respectivement à l'aide de Tcl_GetEnsembleUnknownHandler et Tcl_SetEnsembleUnknownHandler. Le résultat des deux fonctions est un code de résultat Tcl (TCL_OK, ou TCL_ERROR si le jeton ne fait pas référence à un ensemble).

Si NULL, le comportement par défaut - générer un message d'erreur approprié - sera utilisé lorsqu'un sous-commande inconnue est rencontrée. Peut être lu et écrit en utilisant Tcl_GetEnsembleUnknownHandler et Tcl_SetEnsembleUnknownHandler respectivement. Le résultat des deux fonctions est un code de résultat Tcl (TCL_OK, ou TCL_ERROR si le jeton ne fait pas référence à un ensemble) et la liste obtenue de Tcl_GetEnsembleUnknownHandler doit toujours être traitée comme immuable même si elle n'est pas partagée.
bound namespace (lecture seule)
L'espace de noms auquel l'ensemble est lié ; lorsque l'espace de noms est supprimé, l'ensemble le sera également, et cet espace de noms est également l'espace de noms dont la liste des commandes exportées est utilisée si le dictionnaire de mappage et les propriétés de la liste de sous-commandes sont tous deux NULL. Peut être lu en utilisant Tcl_GetEnsembleNamespace qui renvoie un code de résultat Tcl (TCL_OK, ou TCL_ERROR si le jeton ne fait pas référence à un ensemble).
