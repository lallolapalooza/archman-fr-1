ARGUMENTS

Tcl_Interp *interp (entree)
Si une erreur se produit lors de la conversion d'une valeur pour qu'elle soit une valeur de dictionnaire, un message d'erreur est laissé dans la valeur de résultat de l'interpréteur, sauf si interp est NULL.
Tcl_Obj *dictPtr (entree/sortie)
Pointe vers la valeur du dictionnaire à manipuler. Si dictPtr ne pointe pas déjà vers une valeur de dictionnaire, une tentative sera faite pour la convertir.
Tcl_Obj *keyPtr (entree)
Pointe vers la clé pour la paire clé/valeur manipulée dans la valeur du dictionnaire.
Tcl_Obj **keyPtrPtr (sortie)
Pointe vers une variable qui contiendra la clé d'une paire clé/valeur. Peut être NULL pour indiquer que l'appelant n'est pas intéressé par la clé.
Tcl_Obj *valuePtr (entree)
Pointe vers la valeur de la paire clé/valeur manipulée dans la valeur du dictionnaire (ou sous-valeur, dans le cas de Tcl_DictObjPutKeyList.)
Tcl_Obj **valuePtrPtr (sortie)
Pointe vers une variable qui contiendra la valeur d'une paire clé/valeur. Pour Tcl_DictObjFirst et Tcl_DictObjNext, cela peut être NULL pour indiquer que l'appelant n'est pas intéressé par la valeur.
int *sizePtr (sortie)
Pointe vers une variable qui contiendra le nombre de paires clé/valeur contenues dans le dictionnaire.
Tcl_DictSearch *searchPtr (entree/sortie)
Pointeur vers l'enregistrement à utiliser pour suivre la progression dans l'énumération de toutes les paires clé/valeur d'un dictionnaire. Le contenu de l'enregistrement sera initialisé par l'appel à Tcl_DictObjFirst. Si l'énumération doit être terminée avant que toutes les valeurs du dictionnaire aient été retournées, l'enregistrement de recherche doit être passé à Tcl_DictObjDone pour permettre la libération des verrous internes.
int *donePtr (sortie)
Pointe vers une variable qui contiendra une valeur non nulle lorsque l'énumération des paires clé/valeur d'un dictionnaire sera terminée, et zéro sinon.
int keyc (entree)
Indique le nombre de clés qui seront fournies dans le tableau keyv.
Tcl_Obj *const *keyv (entree)
Tableau de keyc pointeurs vers des valeurs que Tcl_DictObjPutKeyList et Tcl_DictObjRemoveKeyList utiliseront pour localiser la paire clé/valeur à manipuler dans les sous-dictionnaires de la valeur du dictionnaire principal qui leur est passé.

DESCRIPTION

Les valeurs de dictionnaire Tcl ont une représentation interne qui prend en charge un mappage efficace des clés aux valeurs et qui garantit que l'ordre particulier des clés au sein du dictionnaire reste le même modulo les clés qui sont supprimées (ce qui les retire de l'ordre) ou ajoutées (ce qui les ajoute à la fin de l'ordre). Si réinterprétées comme une liste, les valeurs aux indices pairs de la liste seront les clés du dictionnaire, et chacune sera suivie (à l'indice impair) de la valeur associée à cette clé.

Les procédures décrites dans cette page de manuel sont utilisées pour créer, modifier, indexer et itérer sur des valeurs de dictionnaire à partir du code C.

Tcl_NewDictObj crée une nouvelle valeur de dictionnaire vide. La représentation textuelle de la valeur sera invalide et le compteur de références de la valeur sera à zéro.

Tcl_DictObjGet recherche la clé donnée dans le dictionnaire donné et écrit un pointeur vers la valeur associée à cette clé dans la variable pointée par valuePtrPtr, ou NULL si la clé n'a pas de mappage dans le dictionnaire. Le résultat de cette procédure est TCL_OK, ou TCL_ERROR si dictPtr ne peut pas être converti en dictionnaire.

Tcl_DictObjPut met à jour le dictionnaire donné afin que la clé donnée mappe à la valeur donnée ; chaque clé peut exister au maximum une fois dans un dictionnaire particulier. Le dictionnaire ne doit pas être partagé, mais la clé et la valeur peuvent l'être. Cette procédure peut augmenter le compteur de références de la clé et de la valeur s'il s'avère nécessaire de les stocker. Ni la clé ni la valeur ne doivent être NULL. Le résultat de cette procédure est TCL_OK, ou TCL_ERROR si dictPtr ne peut pas être converti en dictionnaire.

Tcl_DictObjRemove met à jour le dictionnaire donné afin que la clé donnée n'ait plus de mappage vers aucune valeur. Le dictionnaire ne doit pas être partagé, mais la clé peut l'être. La clé réellement stockée dans le dictionnaire verra son compteur de références décrémenté si elle était présente. Ce n'est pas une erreur si la clé n'existait pas auparavant. Le résultat de cette procédure est TCL_OK, ou TCL_ERROR si dictPtr ne peut pas être converti en dictionnaire.

Tcl_DictObjSize met à jour la variable donnée avec le nombre de paires clé/valeur actuellement dans le dictionnaire donné. Le résultat de cette procédure est TCL_OK, ou TCL_ERROR si dictPtr ne peut pas être converti en dictionnaire.

Tcl_DictObjFirst commence une itération sur toutes les paires clé/valeur du dictionnaire donné, plaçant la clé et la valeur dans les variables pointées par les arguments keyPtrPtr et valuePtrPtr (qui peuvent être NULL pour indiquer que l'appelant ne s'intéresse pas à la clé ou à la variable respectivement.) La paire clé/valeur suivante dans le dictionnaire peut être récupérée avec Tcl_DictObjNext. Les mises à jour concurrentes de la représentation interne du dictionnaire ne modifieront pas le traitement de l'itération, sauf si le dictionnaire n'est pas partagé, auquel cas cela déclenchera une terminaison prématurée de l'itération (que les scripts Tcl ne peuvent pas déclencher via la commande dict.) L'argument searchPtr pointe vers un élément de contexte utilisé pour identifier quelle itération particulière est en cours, et est initialisé par l'appel à Tcl_DictObjFirst. L'argument donePtr pointe vers une variable qui est mise à jour à zéro s'il reste des paires clé/valeur à itérer, ou à une valeur non nulle sinon. L'ordre d'itération est défini par l'implémentation. Si l'argument dictPtr ne peut pas être converti en dictionnaire, Tcl_DictObjFirst retourne TCL_ERROR et l'itération n'est pas commencée, sinon elle retourne TCL_OK.

Lorsque Tcl_DictObjFirst est appelé sur un dictionnaire, un verrou est placé sur le dictionnaire pour permettre à ce dictionnaire d'être itéré en toute sécurité, sans tenir compte du fait que le dictionnaire est modifié pendant l'itération. Pour cette raison, une fois que l'itération sur les clés d'un dictionnaire est terminée (soit parce que toutes les valeurs ont été itérées, comme indiqué par la variable pointée par l'argument donePtr mise à un, soit parce qu'aucune valeur supplémentaire n'est requise), la fonction Tcl_DictObjDone doit être appelée avec le même searchPtr que celui passé à Tcl_DictObjFirst afin que les verrous internes puissent être libérés. Une fois qu'un searchPtr particulier est passé à Tcl_DictObjDone, le passer à Tcl_DictObjNext (sans l'avoir d'abord initialisé avec Tcl_DictObjFirst) entraînera la production d'aucune valeur et la variable pointée par donePtr sera mise à un. Il est sûr d'appeler Tcl_DictObjDone plusieurs fois sur le même searchPtr pour chaque appel à Tcl_DictObjFirst.

Les procédures Tcl_DictObjPutKeyList et Tcl_DictObjRemoveKeyList sont les analogues proches de Tcl_DictObjPut et Tcl_DictObjRemove respectivement, sauf qu'au lieu de travailler avec un seul dictionnaire, elles sont conçues pour opérer sur une arborescence imbriquée de dictionnaires, avec des dictionnaires internes stockés comme valeurs à l'intérieur de dictionnaires externes. Les arguments keyc et keyv spécifient une liste de clés (avec les clés les plus externes en premier) qui agit comme un chemin vers la paire clé/valeur à affecter. Tcl_DictObjPut, Tcl_DictObjPutKeyList, Tcl_DictObjRemoveKeyList, Tcl_DictObjGet, Tcl_DictObjByKey, Tcl_DictObjNext, Tcl_DictObjDone, Tcl_DictSearch – dictionary object manipulation

ARGUMENTS

Tcl_Interp *interp
The current interpreter.
Tcl_Obj *dictPtr
Points to the dictionary object.
Tcl_Obj *keyPtr
Points to the key object.
Tcl_Obj *valuePtr
Points to the value object.
Tcl_Obj *keyList[]
Array of key objects specifying a path to a nested value.
int numKeys
The number of elements in the keyList array.
Tcl_Obj **valuePtrPtr
Location to store a pointer to the value object associated with the key.
int *donePtr
Location to store a boolean that is true when iteration is finished.
Tcl_DictSearch *searchPtr
A structure used to hold state during iteration over a dictionary.

DESCRIPTION

These functions provide an interface to manipulate Tcl dictionary objects. A dictionary object is a value that maps keys to values.

Tcl_DictObjPut inserts a key-value pair into the dictionary object *dictPtr. If the key already exists, its value is replaced. The key and value are specified by keyPtr and valuePtr. The dictionary object *dictPtr is modified in-place if possible, otherwise a new dictionary is created and the result is stored in *dictPtr.

Tcl_DictObjPutKeyList is similar to Tcl_DictObjPut but provides for insertion into nested dictionaries. The key path is given by the array keyList and its length numKeys. If intermediate dictionaries in the path do not exist, they are created. If the path refers to a non-dictionary value, an error is returned.

Tcl_DictObjRemoveKeyList removes the key-value pair specified by keyList and numKeys from the dictionary object *dictPtr. All intermediate dictionaries in the path must exist and have dictionaries as their values, otherwise an error is returned.

Tcl_DictObjGet retrieves the value associated with the key *keyPtr from the dictionary object *dictPtr. The result is stored in **valuePtrPtr. If the key does not exist, *valuePtrPtr is set to NULL and TCL_OK is returned.

Tcl_DictSearch and Tcl_DictObjFirst initialize a dictionary search. Tcl_DictSearch is a simplified version that searches for a specific key. Tcl_DictObjFirst starts an iteration over all key-value pairs in the dictionary. It returns the first key and value in *keyPtrPtr and *valuePtrPtr, respectively. The initial call sets *donePtr to false. Subsequent calls to Tcl_DictObjNext retrieve the next key-value pair. When the end of the dictionary is reached, *donePtr is set to true. Tcl_DictObjDone should be called to clean up the search structure when iteration is complete or is terminated prematurely.

The dictionary iteration interface is easy to construct from repeated use of Tcl_DictObjGet. With Tcl_DictObjPutKeyList, nested dictionaries are created for non-terminal keys where they do not already exist. With Tcl_DictObjRemoveKeyList, all non-terminal keys must exist and have dictionaries as their values.

EXAMPLE

Using the dictionary iteration interface to search determine if there is a key that maps to itself:

Tcl_DictSearch search;
Tcl_Obj *key, *value;
int done;
/*
 * Assume interp and objPtr are parameters.  This is the
 * idiomatic way to start an iteration over the dictionary; it
 * sets a lock on the internal representation that ensures that
 * there are no concurrent modification issues when normal
 * reference count management is also used.  The lock is
 * released automatically when the loop is finished, but must
 * be released manually when an exceptional exit from the loop
 * is performed. However it is safe to try to release the lock
 * even if we've finished iterating over the loop.
 */
if (Tcl_DictObjFirst(interp, objPtr, &search,
        &key, &value, &done) != TCL_OK) {
    return TCL_ERROR;
}
for (; !done ; Tcl_DictObjNext(&search, &key, &value, &done)) {
    /*
     * Note that strcmp() is not a good way of comparing
     * values and is just used here for demonstration
     * purposes.
     */
    if (!strcmp(Tcl_GetString(key), Tcl_GetString(value))) {
        break;
    }
}
Tcl_DictObjDone(&search);
Tcl_SetObjResult(interp, Tcl_NewBooleanObj(!done));
return TCL_OK;

DESCRIPTION

Ces fonctions fournissent une interface pour manipuler les objets dictionnaires Tcl. Un objet dictionnaire est une valeur qui associe des clés à des valeurs.

Tcl_DictObjPut insère une paire clé-valeur dans l'objet dictionnaire *dictPtr. Si la clé existe déjà, sa valeur est remplacée. La clé et la valeur sont spécifiées par keyPtr et valuePtr. L'objet dictionnaire *dictPtr est modifié sur place si possible, sinon un nouveau dictionnaire est créé et le résultat est stocké dans *dictPtr.

Tcl_DictObjPutKeyList est similaire à Tcl_DictObjPut mais permet l'insertion dans des dictionnaires imbriqués. Le chemin de clé est donné par le tableau keyList et sa longueur numKeys. Si des dictionnaires intermédiaires dans le chemin n'existent pas, ils sont créés. Si le chemin fait référence à une valeur non-dictionnaire, une erreur est retournée.

Tcl_DictObjRemoveKeyList supprime la paire clé-valeur spécifiée par keyList et numKeys de l'objet dictionnaire *dictPtr. Tous les dictionnaires intermédiaires dans le chemin doivent exister et avoir des dictionnaires comme valeurs, sinon une erreur est retournée.

Tcl_DictObjGet récupère la valeur associée à la clé *keyPtr de l'objet dictionnaire *dictPtr. Le résultat est stocké dans **valuePtrPtr. Si la clé n'existe pas, *valuePtrPtr est mis à NULL et TCL_OK est retourné.

Tcl_DictSearch et Tcl_DictObjFirst initialisent une recherche dans un dictionnaire. Tcl_DictSearch est une version simplifiée qui recherche une clé spécifique. Tcl_DictObjFirst démarre une itération sur toutes les paires clé-valeur du dictionnaire. Elle retourne la première clé et valeur dans *keyPtrPtr et *valuePtrPtr, respectivement. L'appel initial met *donePtr à faux. Les appels ultérieurs à Tcl_DictObjNext récupèrent la paire clé-valeur suivante. Lorsque la fin du dictionnaire est atteinte, *donePtr est mis à vrai. Tcl_DictObjDone doit être appelée pour nettoyer la structure de recherche lorsque l'itération est terminée ou interrompue prématurément.

L'interface d'itération sur les dictionnaires est facile à construire à partir d'une utilisation répétée de Tcl_DictObjGet. Avec Tcl_DictObjPutKeyList, des dictionnaires imbriqués sont créés pour les clés non terminales là où elles n'existent pas encore. Avec Tcl_DictObjRemoveKeyList, toutes les clés non terminales doivent exister et avoir des dictionnaires comme valeurs.

EXEMPLE

Utilisation de l'interface d'itération sur les dictionnaires pour déterminer s'il existe une clé qui se mappe à elle-même :

Tcl_DictSearch search;
Tcl_Obj *key, *value;
int done;
/*
 * Supposons que interp et objPtr sont des paramètres. C'est la
 * manière idiomatique de commencer une itération sur le dictionnaire ; elle
 * verrouille la représentation interne, garantissant qu'il n'y a pas de problèmes
 * de modification concurrente lorsque la gestion normale des compteurs de
 * références est également utilisée. Le verrou est
 * libéré automatiquement lorsque la boucle est terminée, mais doit
 * être libéré manuellement en cas de sortie exceptionnelle de la boucle.
 * Cependant, il est sûr d'essayer de libérer le verrou
 * même si nous avons terminé l'itération sur la boucle.
 */
if (Tcl_DictObjFirst(interp, objPtr, &search,
        &key, &value, &done) != TCL_OK) {
    return TCL_ERROR;
}
for (; !done ; Tcl_DictObjNext(&search, &key, &value, &done)) {
    /*
     * Notez que strcmp() n'est pas une bonne façon de comparer
     * les valeurs et est utilisé ici uniquement à des fins de démonstration.
     */
    if (!strcmp(Tcl_GetString(key), Tcl_GetString(value))) {
        break;
    }
}
Tcl_DictObjDone(&search);
Tcl_SetObjResult(interp, Tcl_NewBooleanObj(!done));
return TCL_OK;
