Tcl_GetVersion(3) Procédures de la bibliothèque Tcl Tcl_GetVersion(3)

NOM

Tcl_GetVersion - obtenir la version de la bibliothèque au moment de l'exécution

SYNTAXE

#include <tcl.h>

Tcl_GetVersion(major, minor, patchLevel, type)

ARGUMENTS

int *major (sortie)
Numéro de version majeure de la bibliothèque Tcl.
int *minor (sortie)
Numéro de version mineure de la bibliothèque Tcl.
int *patchLevel (sortie)
Le niveau de correctif de la bibliothèque Tcl (ou numéro alpha ou bêta).
Tcl_ReleaseType *type (sortie)
Le type de publication, indique également le type de niveau de correctif. Peut être l'un de TCL_ALPHA_RELEASE, TCL_BETA_RELEASE, ou TCL_FINAL_RELEASE.

DESCRIPTION

Tcl_GetVersion doit être utilisé pour interroger le numéro de version de la bibliothèque Tcl au moment de l'exécution. Ceci est utile lors de l'utilisation d'une bibliothèque Tcl chargée dynamiquement ou lors de l'écriture d'une extension compatible avec les stubs. Par exemple, si vous écrivez une extension liée à la bibliothèque de stubs Tcl, elle pourrait être chargée dans un programme lié à une version de Tcl plus ancienne que prévu. Utilisez Tcl_GetVersion pour vérifier ce fait et éventuellement pour modifier le comportement de votre extension.

Tcl_GetVersion accepte NULL pour l'un des arguments. Par exemple, si vous ne vous souciez pas du patchLevel de la bibliothèque, passez un NULL pour l'argument patchLevel.

MOTS-CLÉS

version, patchlevel, major, minor, alpha, beta, release
