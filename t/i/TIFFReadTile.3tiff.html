TIFFREADTILE(3tiff) LibTIFF TIFFREADTILE(3tiff)

NOM

TIFFReadTile - lire et décoder une tuile de données d'un fichier TIFF ouvert

SYNTAXE

#include <tiffio.h>
tsize_t TIFFReadTile(TIFF *tif, tdata_t buf, uint32_t x, uint32_t y, uint32_t z, tsample_t sample)

DESCRIPTION

Retourne les données de la tuile *contenant* les coordonnées spécifiées. Les données placées dans buf sont retournées décompressées et, typiquement, dans l'ordre des octets et des bits natifs, mais sont autrement compactées (voir plus loin). Le tampon doit être suffisamment grand pour contenir une tuile de données entière. Les applications doivent appeler la routine TIFFTileSize() pour connaître la taille (en octets) d'un tampon de tuile. Les paramètres x et y sont toujours utilisés par TIFFReadTile(). Le paramètre z est utilisé si l'image est plus profonde que 1 tranche (ImageDepth > 1). Le paramètre sample est utilisé uniquement si les données sont organisées en plans séparés (PlanarConfiguration = 2).

NOTES

La bibliothèque tente de masquer les différences d'ordre des bits et des octets entre l'image et la machine native en convertissant les données dans l'ordre de la machine native. L'inversion des bits est effectuée si la balise FillOrder est opposée à l'ordre des bits de la machine native. Les échantillons de 16 et 32 bits sont automatiquement échangés si le fichier a été écrit avec un ordre d'octets opposé à l'ordre d'octets de la machine native.

VALEURS DE RETOUR

TIFFReadTile() retourne -1 en cas d'erreur ; sinon, le nombre d'octets dans la tuile décodée est retourné.

DIAGNOSTICS

Tous les messages d'erreur sont dirigés vers la routine TIFFErrorExtR().
