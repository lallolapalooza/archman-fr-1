TIFFREADENCODEDSTRIP(3tiff) LibTIFF TIFFREADENCODEDSTRIP(3tiff)

NOM

TIFFReadEncodedStrip - lit et décode une bande de données d'un fichier TIFF ouvert

SYNTAXE

#include <tiffio.h>
tmsize_t TIFFReadEncodedStrip(TIFF *tif, uint32_t strip, void *buf, tmsize_t size)

DESCRIPTION

Lit la bande de données spécifiée et place jusqu'à size octets d'informations décompressées dans le tampon de données (fourni par l'utilisateur).

NOTES

La valeur de strip est un numéro de bande « brut ». C'est-à-dire que l'appelant doit tenir compte du fait que les données sont organisées en plans séparés (PlanarConfiguration = 2) ou non. Pour lire une bande complète de données, le tampon de données doit généralement être au moins aussi grand que le nombre retourné par TIFFStripSize(). Si -1 est passé dans le paramètre size, la bande entière sera lue. Vous devez vous assurer que vous avez suffisamment d'espace alloué pour le tampon.

La bibliothèque tente de masquer les différences d'ordre des bits et des octets entre l'image et la machine native en convertissant les données dans l'ordre de la machine native. L'inversion des bits est effectuée si le tag FillOrder est différent de l'ordre des bits de la machine native. Les échantillons de 16 et 32 bits sont automatiquement échangés d'octets si le fichier a été écrit avec un ordre d'octets différent de celui de la machine native.

VALEURS DE RETOUR

Le nombre réel d'octets de données placés dans buf est retourné ; TIFFReadEncodedStrip() renvoie -1 si une erreur est rencontrée.

DIAGNOSTICS

Tous les messages d'erreur sont dirigés vers la routine TIFFErrorExtR().
