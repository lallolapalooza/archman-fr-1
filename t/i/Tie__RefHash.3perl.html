Tie::RefHash(3perl) Guide du programmeur Perl Tie::RefHash(3perl)

NOM

Tie::RefHash - Utiliser des références comme clés de hachage

VERSION

version 1.41

SYNTAXE

require 5.004;
use Tie::RefHash;
tie HASHVARIABLE, 'Tie::RefHash', LIST;
tie HASHVARIABLE, 'Tie::RefHash::Nestable', LIST;
untie HASHVARIABLE;

DESCRIPTION

Ce module permet d'utiliser des références comme clés de hachage si vous avez d'abord "tie" (lié) la variable de hachage à ce module. Normalement, seules les clés du hachage lié lui-même sont préservées en tant que références ; pour utiliser des références comme clés dans des hachages imbriqués, utilisez Tie::RefHash::Nestable, inclus dans Tie::RefHash.

Il est implémenté en utilisant l'interface standard TIEHASH de Perl. Veuillez consulter l'entrée "tie" dans perlfunc(1) et perltie(1) pour plus d'informations.

La version imbriquée fonctionne en recherchant les références de hachage stockées et en les convertissant en hachages liés afin qu'elles puissent également avoir des références comme clés. Cela se produira sans avertissement chaque fois que vous stockerez une référence à l'un de vos propres hachages dans le hachage lié.

EXEMPLE

use Tie::RefHash;
tie %h, 'Tie::RefHash';
$a = [];
$b = {};
$c = \*main;
$d = \"gunk";
$e = sub { 'foo' };
%h = ($a => 1, $b => 2, $c => 3, $d => 4, $e => 5);
$a->[0] = 'foo';
$b->{foo} = 'bar';
for (keys %h) {
   print ref($_), "\n";
}
tie %h, 'Tie::RefHash::Nestable';
$h{$a}->{$b} = 1;
for (keys %h, keys %{$h{$a}}) {
   print ref($_), "\n";
}

SUPPORT DES THREADS

Tie::RefHash supporte entièrement les threads en utilisant la méthode "CLONE".

SUPPORT DES OBJETS STOCKABLES

Des hooks Storable sont fournis pour une sérialisation et un clonage sémantiquement corrects des refhashes liés.
