Time::Seconds(3perl) Guide de référence des programmeurs Perl Time::Seconds(3perl)

NOM

Time::Seconds - une API simple pour convertir des secondes en d'autres valeurs de date

SYNOPSIS

use Time::Piece;
use Time::Seconds;

my $t = localtime;
$t += ONE_DAY;

my $t2 = localtime;
my $s = $t - $t2;

print "La différence est : ", $s->days, "\n";

DESCRIPTION

Ce module fait partie de la distribution Time::Piece. Il permet à l'utilisateur de connaître le nombre de minutes, d'heures, de jours, de semaines ou d'années dans un nombre donné de secondes. Il est retourné par Time::Piece lorsque vous calculez la différence entre deux objets Time::Piece.

Time::Seconds exporte également les constantes suivantes :

ONE_DAY
ONE_WEEK
ONE_HOUR
ONE_MINUTE
ONE_MONTH
ONE_YEAR
ONE_MONTH_FINANCIER
ANNEE_BISSEXTILE
ANNEE_NON_BISSEXTILE

Comme Perl ne prend pas (encore ?) en charge les objets constants, ces constantes sont uniquement en secondes. Vous ne pouvez donc pas, par exemple, faire ceci : "print ONE_WEEK->minutes;"

MÉTHODES

Les méthodes suivantes sont disponibles :

my $val = Time::Seconds->new(SECONDS)
$val->seconds;
$val->minutes;
$val->hours;
$val->days;
$val->weeks;
$val->months;
$val->financial_months; # 30 jours
$val->years;
$val->pretty; # donne une représentation en anglais de la différence

L'arithmétique habituelle (+, -, +=, -=) est également disponible sur les objets.

Les méthodes supposent qu'il y a 24 heures dans une journée, 7 jours dans une semaine, 365,24225 jours dans une année et 12 mois dans une année. (provenant de The Calendar FAQ à http://www.tondering.dk/claus/calendar.html)
