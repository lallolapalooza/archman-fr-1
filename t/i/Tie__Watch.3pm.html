NOM

Tie::Watch - placer des points d'observation sur les variables Perl.

SYNOPSIS

use Tie::Watch;
$watch = Tie::Watch->new(
    -variable => \$frog,
    -debug    => 1,
    -shadow   => 0,                      
    -fetch    => [\&fetch, 'arg1', 'arg2', ..., 'argn'],
    -store    => \&store,
    -destroy  => sub {print "Valeur finale=$frog.\n"},
}
%vinfo = $watch->Info;
$args  = $watch->Args(-fetch);
$val   = $watch->Fetch;
print "val=", $watch->Say($val), ".\n";
$watch->Store('Hello');
$watch->Unwatch;

DESCRIPTION

Ce module de classe associe une ou plusieurs sous-routines de votre création à une variable Perl. Toutes les variables peuvent avoir des callbacks FETCH, STORE et DESTROY. De plus, les tableaux peuvent définir des callbacks CLEAR, DELETE, EXISTS, EXTEND, FETCHSIZE, POP, PUSH, SHIFT, SPLICE, STORESIZE et UNSHIFT, et les hachages peuvent définir des callbacks CLEAR, DELETE, EXISTS, FIRSTKEY et NEXTKEY. Si ces termes vous sont inconnus, je vous suggère *vraiment* de lire perltie.

Avec Tie::Watch vous pouvez :

. modifier la valeur d'une variable
. empêcher la modification de la valeur d'une variable
. invoquer un callback Perl/Tk lorsqu'une variable change
. tracer les références vers une variable

Le format du callback est calqué sur celui de Perl/Tk : fournissez soit une référence de code, soit une référence de tableau contenant la référence de code du callback dans son premier élément, suivie des arguments du callback. (Voir les exemples dans le Synopsis, ci-dessus.)

Tie::Watch fournit des callbacks par défaut pour ceux que vous ne spécifiez pas. Mis à part impacter négativement les performances, ils effectuent l'action standard que vous attendez, de sorte que la variable se comporte "normalement". Une fois que vous remplacez un callback par défaut, peut-être pour insérer du code de débogage comme des instructions print, votre callback se termine normalement en appelant la méthode sous-jacente (remplacée). Mais vous n'êtes pas obligé !

Pour mapper un nom de méthode lié à un nom de callback par défaut, il suffit de mettre le nom de la méthode liée en minuscules et de mettre en majuscule sa première lettre. Ainsi, FETCH devient Fetch, NEXTKEY devient Nextkey, etc.

Voici deux callbacks pour un scalaire. Le callback FETCH (lecture) ne fait rien d'autre qu'illustrer le fait qu'il renvoie la valeur à attribuer à la variable. Le callback STORE (écriture) met la variable en majuscules et la renvoie. Dans tous les cas, le callback *doit* renvoyer la valeur de lecture ou d'écriture correcte - généralement, il le fait en invoquant la méthode sous-jacente.

my $fetch_scalar = sub {
    my($self) = @_;
    $self->Fetch;
};
my $store_scalar = sub {
    my($self, $new_val) = @_;
    $self->Store(uc $new_val);
};

Voici des callbacks FETCH et STORE pour un tableau ou un hachage. Ils font essentiellement la même chose que les callbacks scalaires, mais fournissent un peu plus d'informations.

my $fetch = sub {
    my($self, $key) = @_;
    my $val = $self->Fetch($key);
    print "Dans le callback fetch, key=$key, val=", $self->Say($val);
    my $args = $self->Args(-fetch);
    print ", args=('", join("', '",  @$args), "')" if $args;
    print ".\n";
    $val;
};
my $store = sub {
    my($self, $key, $new_val) = @_;
    my $val = $self->Fetch($key);
    $new_val = uc $new_val;
    $self->Store($key, $new_val);
    print "Dans le callback store, key=$key, val=", $self->Say($val),
      ", new_val=", $self->Say($new_val);
    my $args = $self->Args(-store);
    print ", args=('", join("', '",  @$args), "')" if $args;
    print ".\n";
    $new_val;
};

Dans tous les cas, le premier paramètre est une référence à l'objet Watch, utilisé pour invoquer les méthodes de classe suivantes.

MÉTHODES

$watch = Tie::Watch->new(-options => values);
La méthode constructeur de point d'observation qui accepte des paires option/valeur pour créer et configurer l'objet Watch. L'unique option requise est -variable.

-variable est une *référence* vers un scalaire, un tableau ou un hachage.

-debug (défaut 0) est 1 pour activer les instructions d'impression de débogage internes à Tie::Watch.

-shadow (défaut 1) est 0 pour désactiver l'ombrage des tableaux et hachages. Pour éviter une récursion infinie, Tie::Watch maintient des variables parallèles pour les tableaux et hachages. Lorsque le point d'observation est créé, la variable d'ombre parallèle est initialisée avec le contenu de la variable observée, et lorsque le point d'observation est supprimé, la variable d'ombre est copiée vers la variable d'origine. Ainsi, les modifications apportées pendant le processus d'observation ne sont pas perdues. L'ombrage est activé par défaut. Si vous désactivez l'ombrage, toutes les modifications apportées à un tableau ou à un hachage sont perdues lorsque le point d'observation est supprimé.

Spécifiez n'importe lequel des paramètres de callback pertinents suivants, dans le format décrit ci-dessus : -fetch, -store, -destroy. De plus, pour les tableaux : -clear, -extend, -fetchsize, -pop, -push, -shift, -splice, -storesize et -unshift. De plus, pour les hachages : -clear, -delete, -exists, -firstkey et -nextkey.

$args = $watch->Args(-fetch);
Renvoie une référence vers une liste d'arguments pour le callback spécifié, ou indéfini s'il n'y en a pas.
$watch->Fetch(); $watch->Fetch($key);
Renvoie la valeur actuelle d'une variable. $key est requis pour un tableau ou un hachage.
%vinfo = $watch->Info();
Renvoie un hachage détaillant les éléments internes de l'objet Watch, avec ces clés : 
%vinfo = {
    -variable =>  SCALAR(0x200737f8)
    -debug    =>  '0'
    -shadow   =>  '1'
    -value    =>  'HELLO SCALAR'
    -destroy  =>  ARRAY(0x200f86cc)
    -fetch    =>  ARRAY(0x200f8558)
    -store    =>  ARRAY(0x200f85a0)
    -legible  =>  ci-dessus les données formatées comme une liste de chaînes, pour l'impression
}

Pour les objets Watch de tableaux ou de hachages, la clé -value est remplacée par une clé -ptr qui est une référence vers le tableau ou hachage parallèle. De plus, pour un tableau ou un hachage, il existe des paires clé/valeur pour tous les callbacks spécifiques à la variable.

$watch->Say($val);
Utilisé principalement pour le débogage, il renvoie $val entre guillemets si nécessaire, ou la chaîne "undefined" pour les valeurs indéfinies.
$watch->Store($new_val); $watch->Store($key, $new_val);
Stocke la nouvelle valeur d'une variable. $key est requis pour un tableau ou un hachage.
$watch->Unwatch();
Arrête d'observer la variable.

CONSIDÉRATIONS D'EFFICIENCY

Si vous pouvez vous contenter d'utiliser les méthodes de classe fournies, faites-le s'il vous plaît. Vous pouvez manipuler directement le hachage objet et améliorer les performances d'observation, au risque que votre code ne fonctionne plus à l'avenir.
