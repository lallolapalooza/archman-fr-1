NOM

TIFFquery - routines de requête

SYNTAXE

#include <tiffio.h>
tdir_t TIFFCurrentDirectory(TIFF *tif)
uint64_t TIFFCurrentDirOffset(TIFF *tif)
int TIFFLastDirectory(TIFF *tif)
tdir_t TIFFNumberOfDirectories(TIFF *tif)
uint32_t TIFFCurrentRow(TIFF *tif)
tstrip_t TIFFCurrentStrip(TIFF *tif)
ttile_t TIFFCurrentTile(TIFF *tif)
int TIFFFileno(TIFF *tif)
char *TIFFFileName(TIFF *tif)
int TIFFGetMode(TIFF *tif)
int TIFFIsTiled(TIFF *tif)
int TIFFIsBigEndian(TIFF *tif)
int TIFFIsBigTIFF(TIFF *tif)
int TIFFIsByteSwapped(TIFF *tif)
int TIFFIsMSB2LSB(TIFF *tif)
int TIFFIsUpSampled(TIFF *tif)
const char *TIFFGetVersion(void)

DESCRIPTION

Les routines de requête suivantes renvoient des informations sur la structure des répertoires d'un fichier TIFF ouvert.

TIFFCurrentDirectory() renvoie l'index du répertoire courant (les répertoires sont numérotés à partir de 0). Ce nombre est approprié pour l'utilisation avec la routine TIFFSetDirectory(). Si le répertoire n'a pas encore été écrit dans le fichier après son ouverture, 65535 (répertoire inexistant) est renvoyé.

TIFFCurrentDirOffset() renvoie la position du fichier du répertoire courant (plutôt qu'un index). Cette position est appropriée pour l'utilisation avec la routine TIFFSetSubDirectory(). Ceci est nécessaire pour accéder aux répertoires référencés par un tag SubIFD.

TIFFLastDirectory() renvoie une valeur non nulle si le répertoire courant est le dernier dans le fichier ; sinon, il renvoie zéro.

TIFFNumberOfDirectories() renvoie le nombre de répertoires dans un fichier. Il faut noter que les nouveaux répertoires, qui n'ont pas encore été écrits dans le fichier, ne sont pas comptabilisés.

NOTE:

Veuillez noter que la valeur renvoyée par les routines de requête de répertoire ci-dessus n'est pas valide avant que le répertoire n'ait été écrit dans le fichier et qu'il n'ait été relu, par exemple, via TIFFSetDirectory() ou TIFFReadDirectory().

Les routines de requête suivantes renvoient des informations sur un fichier TIFF ouvert et ses données d'image.

TIFFCurrentRow(), TIFFCurrentStrip() et TIFFCurrentTile() renvoient la ligne, la bande (strip) et la tuile (tile) respectivement, qui sont en cours de lecture ou d'écriture. Ces valeurs sont mises à jour chaque fois qu'une opération de lecture ou d'écriture est effectuée.

TIFFFileno() renvoie le descripteur de fichier sous lequel l'image TIFF est accessible dans le système de fichiers.

TIFFFileName() renvoie le nom de répertoire qui a été passé à TIFFOpen() ou TIFFFdOpen()

TIFFGetMode() renvoie le mode dans lequel le fichier a été ouvert. Sur les systèmes UNIX, ceci correspond à la valeur passée à l'appel de la fonction open() (2).

TIFFIsTiled() renvoie une valeur non nulle si les données d'image sont organisées en tuiles. Zéro est renvoyé si les données d'image sont organisées en bandes.

TIFFIsBigEndian() renvoie une valeur non nulle si le fichier est en BigEndian et zéro s'il est en LittleEndian.

TIFFIsBigTIFF() renvoie une valeur non nulle si le fichier est au format BigTIFF.

TIFFIsByteSwapped() renvoie une valeur non nulle si l'ordre des octets des données d'image est différent de celui du système hôte. Zéro est renvoyé si le fichier TIFF et le système hôte ont le même ordre des octets. Il faut noter que les routines TIFFReadTile(), TIFFReadEncodedStrip() et TIFFReadScanline() effectuent normalement déjà l'échange d'ordre des octets vers l'ordre de l'hôte si nécessaire.

TIFFIsMSB2LSB() renvoie une valeur non nulle si les données d'image sont renvoyées avec le bit 0 comme bit de poids fort.

TIFFIsUpSampled() renvoie une valeur non nulle si les données d'image renvoyées par les routines de lecture sont suréchantillonnées. Ceci peut être utile pour les applications qui souhaitent calculer la taille du buffer d'E/S pour refléter cette utilisation (bien que les routines usuelles de taille de bande et de tuile le fassent déjà).

TIFFGetVersion() renvoie une chaîne ASCII contenant une estampille de version du logiciel de la bibliothèque TIFF.
