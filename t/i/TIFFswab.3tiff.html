NOM

TIFFswab - routines d'échange d'octets et de bits

SYNTAXE

#include <tiffio.h>
const unsigned char *TIFFGetBitRevTable(int reversed)
void TIFFReverseBits(u_char *data, unsigned long nbytes)
void TIFFSwabShort(uint16_t *data)
void TIFFSwabLong(uint32_t *data)
void TIFFSwabLong8(uint64_t *lp)
void TIFFSwabFloat(float *fp)
void TIFFSwabDouble(double *dp)
void TIFFSwabArrayOfShort(uint16_t *wp, tmsize_t n)
void TIFFSwabArrayOfTriples(uint8_t *tp, tmsize_t n)
void TIFFSwabArrayOfLong(uint32_t *lp, tmsize_t n)
void TIFFSwabArrayOfLong8(uint64_t *lp, tmsize_t n)
void TIFFSwabArrayOfFloat(float *fp, tmsize_t n)
void TIFFSwabArrayOfDouble(double *dp, tmsize_t n)

DESCRIPTION

Les routines suivantes sont utilisées par la bibliothèque pour échanger les données de 16, 32 et 64 bits et pour inverser l'ordre des bits dans les octets.

TIFFSwabShort(), TIFFSwabLong() et TIFFSwabFloat() échangent les octets dans un seul élément de 16 et 32 bits, respectivement.

TIFFSwabLong8() et TIFFSwabDouble() échangent les octets dans un seul élément de 64 bits.

TIFFSwabArrayOfTriples() échange le premier et le troisième octet de chaque triplet (trois octets) dans le tableau d'octets. Le deuxième octet de chaque triplet reste inchangé.

TIFFSwabArrayOfShort() et TIFFSwabArrayOfLong(), TIFFSwabArrayOfFloat() échangent les octets dans un tableau d'éléments de 16 et 32 bits, respectivement.

TIFFSwabArrayOfLong8() et TIFFSwabArrayOfDouble() échangent les octets dans un tableau d'éléments de 64 bits.

TIFFReverseBits() remplace chaque octet de data par la valeur inversée de ses bits équivalente. Cette opération est effectuée avec une table de consultation, qui est renvoyée à l'aide de la fonction TIFFGetBitRevTable(). Le paramètre reversed spécifie quelle table doit être renvoyée. Fournissez 1 si vous souhaitez la table d'inversion de bits. Fournissez 0 pour obtenir la table qui n'inverse pas les valeurs de bits. Il s'agit d'une table de consultation qui peut être utilisée comme une fonction « identité » ; c'est-à-dire TIFFNoBitRevTable[n] == n.
