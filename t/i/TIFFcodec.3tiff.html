NOM

TIFFcodec - routines utilitaires liées aux codecs

SYNOPSIS

#include <tiffio.h>
const TIFFCodec *TIFFFindCODEC(uint16_t scheme)
TIFFCodec *TIFFRegisterCODEC(uint16_t scheme, const char *method, TIFFInitMethod init)
void TIFFUnRegisterCODEC(TIFFCodec *codec)
int TIFFIsCODECConfigured(uint16_t scheme)
TIFFCodec *TIFFGetConfiguredCODECs(uint16_t scheme)
int TIFFSetCompressionScheme(TIFF *tif, int scheme)

DESCRIPTION

libtiff prend en charge une variété de schémas de compression implémentés par des codecs logiciels. Chaque codec adhère à une interface modulaire qui permet le décodage et le codage des données d'image ; ainsi que d'autres méthodes d'initialisation, de configuration, de nettoyage et de contrôle des tailles de bande et de tuile par défaut. Les codecs sont identifiés par la valeur associée à la balise Compression TIFF ; par exemple, 5 pour la compression LZW.

La routine TIFFRegisterCODEC() peut être utilisée pour compléter ou remplacer l'ensemble des codecs disponibles pour une application. Si le scheme spécifié a déjà un codec enregistré, il est remplacé et toutes les images dont les données sont codées avec ce schéma de compression seront décodées à l'aide du codec fourni.

TIFFIsCODECConfigured() renvoie 1 si le codec est configuré et fonctionne. Sinon, 0 sera renvoyé.

TIFFGetConfiguredCODECs() récupère la liste des codecs configurés, intégrés et enregistrés par l'utilisateur. La fonction renvoie un tableau d'enregistrements TIFFCodec (le dernier enregistrement doit être NULL) ou NULL si la fonction a échoué. L'appelant est responsable de libérer cette structure.

DIAGNOSTICS

Pas assez d'espace pour enregistrer le schéma de compression %s :

TIFFRegisterCODEC() n'a pas pu allouer de mémoire pour les structures de données nécessaires à l'enregistrement d'un codec.

Impossible de supprimer le schéma de compression %s ; non enregistré :

TIFFUnRegisterCODEC() n'a pas trouvé le codec spécifié dans la table des schémas de compression enregistrés.
