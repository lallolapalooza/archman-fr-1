Time::Format(3) Documentation Perl Contribuée par l'Utilisateur Time::Format(3)

NOM

Time::Format - Formatage facile des dates/heures.

VERSION

Ceci est la version 1.16 de Time::Format, le 19 février 2020.

SYNOPSIS

use Time::Format qw(%time %strftime %manip);
$time{$format}
$time{$format, $unixtime}
print "Aujourd'hui c'est le $time{'yyyy/mm/jj'}\n";
print "Hier c'était le $time{'yyyy/mm/jj', time-24*60*60}\n";
print "Il est $time{'hh:mm:ss'}\n";
print "Une autre heure est $time{'H:mm am tz', $une_autre_heure}\n";
print "Timestamp : $time{'yyyymmdd.hhmmss.mmm'}\n";

%time accepte également les chaînes Date::Manip et les objets DateTime :

$dm = Date::Manip::ParseDate('lundi dernier');
print "Lundi dernier c'était $time{'Month d, yyyy', $dm}";
$dt = DateTime->new (....);
print "Voici une autre date : $time{'m/j/aa', $dt}";

Il accepte également la plupart des chaînes de date/heure ISO-8601 :

$t = '2005/10/31T17:11:09';   # séparateur de date : / ou - ou .
$t = '2005-10-31 17.11.09';   # séparateur intermédiaire : T ou _ ou espace
$t = '20051031_171109';       # séparateur d'heure : : ou .
$t = '20051031171109';        # les séparateurs peuvent être omis
$t = '2005/10/31';            # date seule est acceptable
$t = '17:11:09';              # heure seule est acceptable
# Mais pas :
$t = '20051031';              # date seule sans séparateurs
$t = '171109';                # heure seule sans séparateurs
# ...car ceux-ci ressemblent à des nombres d'époque.

%strftime fonctionne comme le "strftime" de POSIX, si vous aimez ces formats "%".

$strftime{$format}
$strftime{$format, $unixtime}
$strftime{$format, $sec,$min,$hour, $mday,$mon,$year, $wday,$yday,$isdst}
print "POSIXish : $strftime{'%A, %B %d, %Y', 0,0,0,12,11,95,2}\n";
print "POSIXish : $strftime{'%A, %B %d, %Y', 1054866251}\n";
print "POSIXish : $strftime{'%A, %B %d, %Y'}\n";       # heure actuelle

%manip fonctionne comme la fonction "UnixDate" de Date::Manip.

$manip{$format};
$manip{$format, $when};
print "Date::Manip : $manip{'%m/%d/%Y'}\n";            # heure actuelle
print "Date::Manip : $manip{'%m/%d/%Y','mardi dernier'}\n";

Celles-ci peuvent également être utilisées comme des fonctions autonomes :

use Time::Format qw(time_format time_strftime time_manip);
print "Aujourd'hui c'est ", time_format('yyyy/mm/jj', $un_certain_temps), "\n";
print "POSIXish : ", time_strftime('%A %B %d, %Y',$un_certain_temps), "\n";
print "Date::Manip : ", time_manip('%m/%d/%Y',$un_certain_temps), "\n";

DESCRIPTION

Ce module crée des pseudo-variables globales qui formatent les dates et heures, selon les codes de formatage que vous leur passez dans des chaînes.

Les codes de formatage %time sont conçus pour être faciles à retenir et à utiliser, et pour prendre autant de caractères que possible que la valeur de sortie de l'heure. Par exemple, le code pour l'année à quatre chiffres est ""yyyy"", l'abréviation du mois à trois lettres est ""Mon"".

L'avantage d'avoir une interface de type variable au lieu d'appels de fonction est que les valeurs peuvent être utilisées à l'intérieur de chaînes (ainsi qu'à l'extérieur de chaînes dans des expressions ordinaires). Les dates sont fréquemment utilisées dans des chaînes (messages de journal, sorties, enregistrements de données, etc.), donc la possibilité de les interpoler directement est pratique.

Perl autorise des expressions arbitraires entre accolades d'une table de hachage, même lorsque cette table de hachage est interpolée dans une chaîne. Cela vous permet d'effectuer des calculs à la volée tout en formatant les heures et en les insérant dans des chaînes. Voir l'exemple "hier" ci-dessus.

Les chaînes de format sont conçues en pensant aux programmeurs. De quoi avez-vous le plus besoin fréquemment ? Année à 4 chiffres, mois, jour, heure basée sur 24h, minute, seconde -- généralement avec des zéros en tête. Ces six sont les formats les plus faciles à utiliser et à retenir dans Time::Format : "yyyy", "mm", "jj", "hh", "mm", "ss". Les variantes de ces formats suivent une formule simple et cohérente. Ce module s'adresse à tous ceux qui en ont assez d'essayer de se souvenir des codes obscurs de strftime(3), ou d'écrire sans cesse "$t[4]++; $t[5]+=1900" pour formater manuellement les dates et heures.

Notez que "mm" (et les codes associés) sont utilisés à la fois pour les mois et les minutes. C'est une fonctionnalité. %time résout l'ambiguïté en examinant d'autres codes de formatage voisins. S'il est dans le contexte d'une année ou d'un jour, "mois" est supposé. S'il est dans le contexte d'une heure ou d'une seconde, "minute" est supposé.

Les chaînes de format ne sont pas destinées à couvrir tous les besoins en matière de date/heure jamais imaginés. Mais à quelle fréquence avez-vous besoin du jour de l'année (strftime %j) ou du numéro de semaine (strftime %W) ?

Pour les fonctionnalités que %time ne fournit pas, %strftime fournit une interface à "strftime" de POSIX, et %manip fournit une interface à la fonction "UnixDate" du module Date::Manip.

Si le module compagnon Time::Format_XS est également installé, Time::Format le détectera et l'utilisera. Cela entraînera une augmentation significative de la vitesse pour %time et "time_format".

VARIABLES

time
$time{$format}
$time{$format,$time_value};

Formate un nombre de temps Unix (secondes depuis l'époque), un objet DateTime, un DateTime en chaîne, une chaîne Date::Manip, ou une chaîne ISO-8601, selon le format spécifié. Si l'expression temporelle est omise, l'heure actuelle est utilisée. La chaîne de format peut contenir l'un des éléments suivants :

yyyy       année à 4 chiffres
yy         année à 2 chiffres
m          mois à 1 ou 2 chiffres, 1-12
mm         mois à 2 chiffres, 01-12
?m         mois avec espace initial si < 10
Month      nom complet du mois, casse mixte
MONTH      nom complet du mois, majuscules
month      nom complet du mois, minuscules
Mon        abréviation du mois à 3 lettres, casse mixte
MON  mon   identique, versions majuscules et minuscules
d          numéro du jour, 1-31
dd         numéro du jour, 01-31
?d         jour avec espace initial si < 10
th         suffixe du jour (st, nd, rd, ou th)
TH         suffixe majuscule
Weekday    nom du jour de la semaine, casse mixte
WEEKDAY    nom du jour de la semaine, majuscules
weekday    nom du jour de la semaine, minuscules
Day        nom du jour de la semaine à 3 lettres, casse mixte
DAY  day   identique, versions majuscules et minuscules
h          heure, 0-23
hh         heure, 00-23
?h         heure, 0-23 avec espace initial si < 10
H          heure, 1-12
HH         heure, 01-12
?H         heure, 1-12 avec espace initial si < 10
m          minute, 0-59
mm         minute, 00-59
?m         minute, 0-59 avec espace initial si < 10
s          seconde, 0-59
ss         seconde, 00-59
?s         seconde, 0-59 avec espace initial si < 10
mmm        milliseconde, 000-999
uuuuuu     microseconde, 000000-999999
am   a.m.  La chaîne "am" ou "pm" (deuxième forme avec des points)
pm   p.m.  identique à "am" ou "a.m."
AM   A.M.  identique à "am" ou "a.m." mais en majuscules
PM   P.M.  identique à "AM" ou "A.M."
tz         abréviation du fuseau horaire

Les millisecondes et microsecondes nécessitent Time::HiRes, sinon elles seront toujours à zéro. Le fuseau horaire nécessite POSIX, sinon ce sera une chaîne vide. Les codes de seconde ("s", "ss", "?s") peuvent être 60 ou 61 dans de rares circonstances (secondes intercalaires, si votre système prend en charge cela).

Tout ce qui se trouve dans la chaîne de format autre que les motifs ci-dessus est laissé intact. Tout caractère précédé d'une barre oblique inverse est laissé tel quel et n'est utilisé pour aucune partie d'un code de format. Voir la section "QUOTING" pour plus de détails.

Pour la plupart, chacun des codes de formatage ci-dessus prend autant de place que la chaîne de sortie qu'il génère. Les exceptions sont les codes dont la sortie a une longueur variable : "Weekday", "Month", le fuseau horaire, et les codes à caractère unique.

Les "Month", "Mon", "Weekday" en casse mixte

;, et les codes "Day" renvoient le nom du mois ou du jour de la semaine dans la casse préférée pour la locale actuellement en vigueur. Ainsi, dans une locale anglophone, le septième mois serait "July" (lettre initiale majuscule, reste en minuscules) ; tandis que dans une locale francophone, ce serait "juillet" (tout en minuscules). Voir la section "QUOTING" pour les moyens de contrôler la casse des noms de mois/jours de la semaine.

Notez que les formats ""mm"", ""m"", et ""?m"" sont ambigus. %time essaie de deviner si vous vouliez dire "mois" ou "minute" en fonction des caractères voisins dans la chaîne de format. Ainsi, un format de ""yyyy/mm/dd hh:mm:ss"" est correctement interprété comme "année mois jour, heure minute seconde". Si %time ne peut pas déterminer si vous vouliez dire "mois" ou "minute", il laisse les codes "mm", "m", ou "?m" non traduits. Pour lever l'ambiguïté, vous pouvez utiliser les codes suivants :

m{on}        mois, 1-12
mm{on}       mois, 01-12
?m{on}       mois, 1-12 avec un espace en tête si < 10
m{in}        minute, 0-59
mm{in}       minute, 00-59
?m{in}       minute, 0-59 avec un espace en tête si < 10

En d'autres termes, ajoutez ""{on}"" ou ""{in}"" pour rendre ""m"", ""mm"", ou ""?m"" non ambigus.

strftime
$strftime{$format, $sec,$min,$hour, $mday,$mon,$year, $wday,$yday,$isdst}
$strftime{$format, $unixtime}
$strftime{$format}

Pour ceux qui préfèrent les formats % étranges de strftime, ou qui ont besoin de conformité POSIX, ou qui ont besoin de numéros de semaine ou d'autres fonctionnalités que %time ne fournit pas.

manip
$manip{$format};
$manip{$format,$when};

Fournit une interface au module Date::Manip et à sa fonction "UnixDate". Cette fonction est plutôt lente, mais peut analyser une très grande variété d'entrées de date. Voir le module Date::Manip pour les détails sur les entrées acceptées.

Si vous souhaitez utiliser les codes de %time, mais que vous avez besoin de la flexibilité d'entrée de %manip, vous pouvez utiliser la fonction "ParseDate" de Date::Manip :

print "$time{'yyyymmdd', ParseDate('last sunday')}";

FONCTIONS

time_format
time_format($format);
time_format($format, $unix_time);

C'est une interface de fonction à %time. Elle accepte les mêmes codes de formatage et tout le reste. Ceci est fourni pour les personnes qui veulent que leurs appels de fonction ressemblent à des appels de fonction, pas à des hachages. :-) Les deux exemples suivants sont équivalents :

$x = $time{'yyyy/mm/dd'};
$x = time_format('yyyy/mm/dd');
time_strftime
time_strftime($format, $sec,$min,$hour, $mday,$mon,$year, $wday,$yday,$isdst);
time_strftime($format, $unixtime);
time_strftime($format);

C'est une interface de fonction à %strftime. Elle appelle simplement POSIX::"strftime", mais elle offre un léger avantage par rapport à l'appel direct de "strftime", dans le sens où vous pouvez passer le temps sous forme de temps Unix (secondes depuis l'époque), ou l'omettre pour obtenir l'heure actuelle.

time_manip
manip($format);
manip($format,$when);

C'est une interface de fonction à %manip. Elle appelle Date::Manip::"UnixDate" en interne. Elle n'offre pas un grand avantage par rapport à l'appel direct de "UnixDate", si ce n'est que vous pouvez omettre le paramètre $when pour obtenir l'heure actuelle.

MISE ENTRE GUILLEMETS

Cette section s'applique uniquement aux chaînes de format utilisées par %time et "time_format".

Il est parfois nécessaire de supprimer l'expansion de certains caractères de format dans une chaîne de format. Par exemple :

$time{'Hour: hh; Minute: mm{in}; Second: ss'};

Dans l'expression ci-dessus, le "H" dans "Hour" serait développé, tout comme le "d" dans "Second". Le résultat serait quelque chose comme :

8our: 08; Minute: 10; Secon17: 30

Ce ne serait pas une bonne solution de diviser l'instruction ci-dessus en trois appels à %time :

"Hour: $time{hh}; Minute: $time{'mm{in}'}; Second: $time{ss}"

car l'heure pourrait changer d'un appel à l'autre, ce qui poserait un problème lorsque les nombres débordent (par exemple, une fraction de seconde après 7:59:59).

Pour cette raison, vous pouvez échapper des codes de format individuels avec une barre oblique inverse :

$time{'\Hour: hh; Minute: mm{in}; Secon\d: ss'};

Notez qu'avec les chaînes entre guillemets doubles (et qq//), la barre oblique inverse doit être doublée, car Perl interprète d'abord la chaîne :

$time{"\\Hour: hh; Minute: mm{in}; Secon\\d: ss"};

Pour plus de commodité, Time::Format simule les opérateurs d'échappement inline \Q et \E intégrés de Perl. Tout ce qui se trouve dans une chaîne entre \Q et \E ne sera pas interpolé comme faisant partie d'un code de formatage :

$time{'\QHour:\E hh; \QMinute:\E mm{in}; \QSecond:\E ss'};

Encore une fois, dans les chaînes interpolées, la barre oblique inverse doit être doublée, sinon Perl interprétera et supprimera la séquence \Q...\E avant que Time::Format ne la reçoive :

$time{"\\QHour:\\E hh; \\QMinute:\\E mm{in}; \\QSecond\\E: ss"};

Time::Format reconnaît et simule également les séquences \U, \L, \u et \l. Ceci est vraiment utile pour un contrôle plus fin des formats Month, Mon, Weekday et Day. Par exemple, dans certaines locales, les noms de mois sont conventionnellement tout en minuscules. Au début d'une phrase, vous pourriez vouloir vous assurer que le premier caractère est en majuscule :

$time{'\uMonth \Qis the finest month of all.'};

Encore une fois, assurez-vous d'utiliser \Q, et assurez-vous de doubler les barres obliques inverses dans les chaînes interpolées, sinon vous obtiendrez quelque chose de laid comme :

July i37 ste fine37t july of all.

EXEMPLES

$time{'Weekday Month d, yyyy'}   Thursday June 5, 2003
$time{'Day Mon d, yyyy'}         Thu Jun 5, 2003
$time{'dd/mm/yyyy'}              05/06/2003
$time{yymmdd}                    030605
$time{'yymmdd',time-86400}       030604
$time{'dth of Month'}            5th of June
$time{'H:mm:ss am'}              1:02:14 pm
$time{'hh:mm:ss.uuuuuu'}         13:02:14.171447
$time{'yyyy/mm{on}/dd hh:mm{in}:ss.mmm'}  2003/06/05 13:02:14.171
$time{'yyyy/mm/dd hh:mm:ss.mmm'}          2003/06/05 13:02:14.171
$time{"It's H:mm."}              It'14 1:02.    # OUPS !
$time{"It'\\s H:mm."}            It's 1:02.     # La barre oblique inverse corrige cela.
                                                                              .
                                                                              .
# Renommer un fichier en fonction de la date du jour :
rename $file, "${file}_$time{yyyymmdd}";
# Renommer un fichier en fonction de sa date de dernière modification :
rename $file, "${file}_$time{'yyyymmdd',(stat $file)[9]}";
# Exemples strftime
$strftime{'%A %B %d, %Y'}                 Thursday June 05, 2003
$strftime{'%A %B %d, %Y',time+86400}      Friday June 06, 2003
# Exemples manip
$manip{'%m/%d/%Y'}                                   06/05/2003
$manip{'%m/%d/%Y','yesterday'}                       06/04/2003
$manip{'%m/%d/%Y','first monday in November 2000'}   11/06/2000

INTERNATIONALISATION

Si le module I18N::Langinfo est disponible, Time::Format retournera les noms des jours de la semaine et des mois dans la langue appropriée pour la locale actuelle. Sinon, les noms anglais seront utilisés.

Les programmeurs dans des locales non anglaises peuvent vouloir fournir un alias à %time dans leur propre langue préférée. Cela peut être fait en assignant "\%time" à un typeglob :

# Français
use Time::Format;
use vars '%temps';  *temps = \%time;
print "C'est aujourd'hui le $temps{'d Month'}\n";
# Allemand
use Time::Format;
use vars '%zeit';   *zeit = \%time;
print "Heutiger Tag ist $zeit{'d.m.yyyy'}\n";

EXPORTATIONS

Les symboles suivants sont exportés dans votre espace de noms par défaut :

%time
time_format

Les symboles suivants sont disponibles pour l'importation dans votre espace de noms :

%strftime
%manip
time_strftime
time_manip

La balise ":all" importera tous ces éléments dans votre espace de noms. Exemple :

use Time::Format ':all';

LIMITATIONS

La chaîne de format utilisée par %time ne doit contenir la sous-chaîne $; nulle part. $; (par défaut, le caractère ASCII 28, ou 1C hexadécimal) est utilisé pour séparer les valeurs passées à la table de hachage liée, et donc Time::Format interprétera votre chaîne de format comme étant deux arguments ou plus si elle contient $;. La fonction "time_format" n'a pas cette limitation.

EXIGENCES

Time::Local
I18N::Langinfo, si vous voulez que les locales non anglaises fonctionnent.
POSIX, si vous choisissez d'utiliser %strftime ou si vous voulez que le format C<tz> fonctionne.
Time::HiRes, si vous voulez que les formats de temps C<mmm> et C<uuuuuu> fonctionnent.
Date::Manip, si vous choisissez d'utiliser %manip.
Time::Format_XS est facultatif mais rendra C<%time> et C<time_format>
    beaucoup plus rapides. La version de Time::Format_XS installée doit correspondre
    à la version de Time::Format installée ; sinon, Time::Format ne l'utilisera pas
    (et émettra un avertissement).
