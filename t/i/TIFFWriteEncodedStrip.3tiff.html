TIFFWRITEENCODEDSTRIP(3tiff) LibTIFF TIFFWRITEENCODEDSTRIP(3tiff)

NOM

TIFFWriteEncodedStrip - compresse et écrit une bande de données dans un fichier TIFF ouvert

SYNTAXE

#include <tiffio.h>
tsize_t TIFFWriteEncodedStrip(TIFF *tif, tstrip_t strip, tdata_t buf, tsize_t size)

DESCRIPTION

Compresse size octets de données brutes à partir de buf et écrit le résultat dans la bande spécifiée ; remplaçant toute donnée écrite précédemment. Notez que la valeur de strip est un numéro de bande « brut ». C'est-à-dire, l'appelant doit tenir compte du fait que les données soient organisées en plans séparés (PlanarConfiguration = 2).

NOTES

La bibliothèque écrit les données encodées en utilisant l'ordre des octets natif de la machine. Les lecteurs TIFF correctement implémentés sont censés effectuer tout échange d'octets nécessaire pour traiter correctement les données d'image avec plus de 8 BitsPerSample.

Le numéro de bande doit être valide selon les paramètres actuels des tags ImageLength et RowsPerStrip. Une image peut être agrandie dynamiquement en augmentant la valeur de ImageLength avant chaque appel à TIFFWriteEncodedStrip.

VALEUR DE RETOUR

-1 est retourné si une erreur a été rencontrée. Sinon, la valeur de size est retournée.

DIAGNOSTICS

Tous les messages d'erreur sont dirigés vers la routine TIFFErrorExtR().

%s: File not open for writing:

Le fichier a été ouvert en lecture, pas en écriture.

Can not write scanlines to a tiled image:

L'image est supposée être organisée en tuiles car les tags TileWidth et TileLength ont été définis avec TIFFSetField().

%s: Must set "ImageWidth" before writing data\fP:

La largeur de l'image n'a pas été définie avant la première écriture. Voir TIFFSetField() pour savoir comment faire.

%s: Must set "PlanarConfiguration" before writing data:

L'organisation des données n'a pas été définie avant la première écriture. Voir TIFFSetField() pour savoir comment faire.

%s: No space for strip arrays":

Il n'y avait pas assez d'espace pour les tableaux qui contiennent les offsets des bandes et les décomptes d'octets.
