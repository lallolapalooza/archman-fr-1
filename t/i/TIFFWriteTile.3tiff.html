NOM

TIFFWriteTile - encode et écrit une tuile de données dans un fichier TIFF ouvert

SYNTAXE

#include <tiffio.h>

TIFFWriteTile - encode et écrit une tuile de données dans un fichier TIFF ouvert

tsize_t TIFFWriteTile(TIFF *tif, tdata_t buf, uint32_t x, uint32_t y, uint32_t z, tsample_t sample)

DESCRIPTION

Écrit les données pour la tuile *contenant* les coordonnées spécifiées. Les données dans buf sont (potentiellement) compressées, et écrites dans le fichier indiqué, en général ajoutées à la fin du fichier. Le tampon doit contenir une tuile de données entière. Les applications doivent appeler la routine TIFFTileSize() pour connaître la taille (en octets) d'un tampon de tuile. Les paramètres x et y sont toujours utilisés par TIFFWriteTile(). Le paramètre z est utilisé si l'image a une profondeur supérieure à 1 tranche (ImageDepth > 1). Le paramètre sample est utilisé uniquement si les données sont organisées en plans séparés (PlanarConfiguration = 2).

VALEURS DE RETOUR

TIFFWriteTile() renvoie -1 si une erreur est détectée ; sinon, le nombre d'octets dans la tuile est renvoyé.

DIAGNOSTICS

Tous les messages d'erreur sont dirigés vers la routine TIFFErrorExtR().
