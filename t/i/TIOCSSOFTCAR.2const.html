TIOCSSOFTCAR(2const) TIOCSSOFTCAR(2const)

NOM

TIOCGSOFTCAR, TIOCSSOFTCAR - marquer une ligne comme locale

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <asm/termbits.h>  /* Définition des constantes TIOC*SOFTCAR */
#include <sys/ioctl.h>
int ioctl(int fd, TIOCGSOFTCAR, int *argp);
int ioctl(int fd, TIOCSSOFTCAR, const int *argp);

DESCRIPTION

TIOCGSOFTCAR
("Obtenir le drapeau de porteuse logicielle") Récupère l'état du drapeau CLOCAL dans le champ c_cflag de la structure termios.
TIOCSSOFTCAR
("Définir le drapeau de porteuse logicielle") Définit le drapeau CLOCAL dans la structure termios lorsque *argp est non nul, et l'efface sinon.

Si le drapeau CLOCAL d'une ligne est désactivé, le signal matériel de détection de porteuse (DCD) est significatif, et un open(2) du terminal correspondant bloquera jusqu'à ce que DCD soit asserté, à moins que le drapeau O_NONBLOCK ne soit spécifié. Si CLOCAL est activé, la ligne se comporte comme si DCD était toujours asserté. Le drapeau de porteuse logicielle est généralement activé pour les périphériques locaux, et désactivé pour les lignes avec modem.

VALEUR RETOURNÉE

En cas de succès, 0 est retourné. En cas d'erreur, -1 est retourné, et errno est défini pour indiquer l'erreur.

VOIR AUSSI

ioctl(2), ioctl_tty(2)
