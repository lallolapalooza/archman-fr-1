NOM

TIFFReadRawTile - renvoie une tuile de données non décodée d'un fichier TIFF ouvert

SYNTAXE

#include <tiffio.h>
tsize_t TIFFReadRawTile(TIFF *tif, ttile_t tile, tdata_t buf, tsize_t size)

DESCRIPTION

Lit le contenu de la tuile spécifiée dans le tampon de données (fourni par l'utilisateur). Notez que la valeur de tile est un « numéro de tuile brut ». C'est-à-dire que l'appelant doit tenir compte du fait que les données sont organisées en plans séparés ou non (PlanarConfiguration = 2). TIFFComputeTile() fait cela automatiquement lors de la conversion d'un quadruplet de coordonnées (x,y,z,échantillon) en un numéro de tuile. Pour lire une tuile de données complète, le tampon de données devrait typiquement être au moins aussi grand que la valeur renvoyée par TIFFTileSize().

VALEURS DE RETOUR

Le nombre réel d'octets de données placés dans buf est renvoyé ; TIFFReadRawTile() renvoie -1 si une erreur a été rencontrée.

DIAGNOSTICS

Tous les messages d'erreur sont dirigés vers la routine TIFFErrorExtR().

VOIR AUSSI
