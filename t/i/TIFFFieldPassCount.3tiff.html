TIFFFIELDPASSCOUNT(3tiff) LibTIFF TIFFFIELDPASSCOUNT(3tiff)

NOM

TIFFFieldPassCount - savoir s'il faut passer un décompte à TIFFGetField/TIFFSetField

SYNOPSIS

#include <tiffio.h>
int TIFFFieldPassCount(const TIFFField *fip)

DESCRIPTION

TIFFFieldPassCount() retourne vrai (non nul) si TIFFGetField() et TIFFSetField() attendent une valeur de count à passer avant le pointeur de données réel.

fip est un pointeur d'informations de champ précédemment retourné par TIFFFindField(), TIFFFieldWithTag(), TIFFFieldWithName().

Lorsqu'un count est requis, il sera de type uint32_t si TIFFFieldReadCount() renvoie TIFF_VARIABLE2, et de type uint16_t sinon. Utilisez TIFFFieldWriteCount() pour TIFFSetField(), respectivement. (Cette distinction est essentielle pour l'utilisation de TIFFGetField(), mais normalement pas pour l'utilisation de TIFFSetField().)

Une fonction alternative pour la détermination de la valeur de count est TIFFFieldSetGetCountSize().

VALEUR DE RETOUR

TIFFFieldPassCount() retourne un entier qui est toujours 1 (vrai) ou 0 (faux).

VOIR AUSSI

TIFFFieldDataType (3tiff), TIFFFieldName (3tiff), TIFFFieldQuery (3tiff), TIFFFieldReadCount (3tiff), TIFFFieldTag (3tiff), TIFFFieldWriteCount (3tiff), libtiff
