NAME

Tie::Array - classe de base pour les tableaux liés

SYNOPSIS

package Tie::NewArray;
use Tie::Array;
@ISA = ('Tie::Array');
# méthodes obligatoires
sub TIEARRAY { ... }
sub FETCH { ... }
sub FETCHSIZE { ... }
sub STORE { ... }       # obligatoire si les éléments peuvent être écrits
sub STORESIZE { ... }   # obligatoire si les éléments peuvent être ajoutés ou supprimés
sub EXISTS { ... }      # obligatoire si exists() doit fonctionner
sub DELETE { ... }      # obligatoire si delete() doit fonctionner
# méthodes optionnelles - pour l'efficacité
sub CLEAR { ... }
sub PUSH { ... }
sub POP { ... }
sub SHIFT { ... }
sub UNSHIFT { ... }
sub SPLICE { ... }
sub EXTEND { ... }
sub DESTROY { ... }
package Tie::NewStdArray;
use Tie::Array;
@ISA = ('Tie::StdArray');
# toutes les méthodes fournies par défaut
package main;
$object = tie @somearray,'Tie::NewArray';
$object = tie @somearray,'Tie::StdArray';
$object = tie @somearray,'Tie::NewStdArray';

DESCRIPTION

Ce module fournit des méthodes pour les classes de tableaux liés. Voir perltie pour une liste des fonctions requises pour lier un tableau à un paquet. La classe de base Tie::Array fournit des méthodes squelettes "DESTROY" et "EXTEND" qui ne font rien, des méthodes squelettes "DELETE" et "EXISTS" qui croak() si les fonctions intégrées delete() ou exists() sont appelées sur le tableau lié, et des implémentations de "PUSH", "POP", "SHIFT", "UNSHIFT", "SPLICE" et "CLEAR" en termes des fonctions de base "FETCH", "STORE", "FETCHSIZE" et "STORESIZE".

La classe Tie::StdArray fournit des méthodes efficaces pour les tableaux liés qui sont implémentés comme des références à un tableau Perl « intérieur ». Elle hérite de Tie::Array et doit faire en sorte que les tableaux liés se comportent exactement comme des tableaux standard, permettant la redéfinition sélective des méthodes.

Pour les développeurs qui souhaitent écrire leurs propres tableaux liés, les méthodes requises sont brièvement définies ci-dessous. Voir la section perltie pour des informations plus détaillées, ainsi que des exemples de code :

TIEARRAY classe, liste
La méthode de classe est invoquée par la commande "tie @array, classe". Elle associe un objet d'instance de tableau à la classe spécifiée. "LIST" représente des arguments supplémentaires (comme dans AnyDBM_File et ses semblables) nécessaires pour compléter l'association. La méthode doit renvoyer un objet de classe qui fournit les méthodes décrites ci-dessous.
STORE this, index, value
Stocke la valeur value à l'indice index du tableau lié associé à l'objet this. Si cela rend le tableau plus long, le mappage de "undef" de la classe doit renvoyer la valeur pour les nouvelles positions.
FETCH this, index
Récupère la valeur à l'indice index du tableau lié associé à l'objet this.
FETCHSIZE this
Renvoie le nombre total d'éléments dans le tableau lié associé à l'objet this. (Équivalent à scalar(@array)).
STORESIZE this, count
Définit le nombre total d'éléments dans le tableau lié associé à l'objet this à count. Si cela rend le tableau plus long, le mappage de "undef" de la classe doit renvoyer la valeur pour les nouvelles positions. Si le tableau est raccourci, les éléments après le compte doivent être supprimés.
EXTEND this, count
Un appel informatif indiquant que le tableau va probablement croître pour avoir count éléments. Peut être utilisé pour optimiser l'allocation. Cette méthode ne fait rien.
EXISTS this, key
Vérifie si l'élément à la position key existe dans le tableau lié this.

L'implémentation de Tie::Array est un stub qui fait simplement un croak.

DELETE this, key
Supprime l'élément à la position key du tableau lié this.

L'implémentation de Tie::Array est un stub qui fait simplement un croak.

CLEAR this
Supprime (enlève, efface, ...) toutes les valeurs des éléments du tableau lié associé à l'objet this.
DESTROY this
Méthode de destructuration normale.
PUSH this, LIST
Ajoute les éléments de LIST au tableau.
POP this
Supprime le dernier élément du tableau et le renvoie.
SHIFT this
Supprime le premier élément du tableau (en décalant les autres éléments vers le bas) et le renvoie.
UNSHIFT this, LIST
Insère les éléments de LIST au début du tableau, en décalant les éléments existants vers le haut pour faire de la place.
SPLICE this, offset, length, LIST
Effectue ce que fait la commande "splice" sur le tableau.

La valeur offset est facultative et par défaut à 0 ; les valeurs négatives comptent à partir de la fin du tableau.

La valeur length est facultative et par défaut au reste du tableau.

La valeur LIST peut être vide.

Renvoie une liste des length premiers éléments à la position offset.

CAVEATS

Il n'y a actuellement aucun support pour les tableaux liés @ISA. Il y a un conflit potentiel entre les enregistrements magiques nécessaires pour remarquer la définition de @ISA et ceux nécessaires pour implémenter 'tie'.
