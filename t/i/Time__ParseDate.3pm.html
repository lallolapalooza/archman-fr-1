NOM

Time::ParseDate -- analyse de dates, relatives et absolues

SYNTAXE

use Time::ParseDate;
$secondes_depuis_1jan1970 = parsedate("12/11/94 14h", NO_RELATIVE => 1)
$secondes_depuis_1jan1970 = parsedate("12/11/94 14h", %options)

OPTIONS

L'analyse des dates peut également utiliser des options. Les options sont les suivantes :

FUZZY   -> il est acceptable de ne pas analyser toute la chaîne de date
NOW     -> l'heure "actuelle" pour les temps relatifs (par défaut à time())
ZONE    -> fuseau horaire local (par défaut à $ENV{TZ})
WHOLE   -> toute la chaîne d'entrée doit être analysée
GMT     -> l'heure d'entrée est supposée être GMT, pas l'heure locale
UK      -> préférer le style de date britannique (jj/mm au lieu de mm/jj)
DATE_REQUIRED -> ne pas utiliser la date par défaut
TIME_REQUIRED -> ne pas utiliser l'heure par défaut
NO_RELATIVE -> l'heure d'entrée n'est pas relative à NOW
TIMEFIRST -> essayer d'analyser l'heure avant la date [pas par défaut]
PREFER_PAST -> lorsque l'année ou le jour de la semaine est ambigu, supposer le passé
PREFER_FUTURE -> lorsque l'année ou le jour de la semaine est ambigu, supposer le futur
SUBSECOND -> analyser les fractions de seconde
VALIDATE -> n'accepter que les valeurs normales pour HHMMSS, YYMMDD. Sinon
        des jours comme -1 peuvent donner le dernier jour du mois précédent.

DESCRIPTION

Ce module reconnaît les formats de date/heure ci-dessus. Généralement, une date et une heure sont spécifiées. Il existe de nombreuses options pour contrôler ce qui est reconnu ou non.

Le code de retour est toujours l'heure en secondes depuis le 1er janvier 1970, ou undef si l'analyse de l'heure a échoué.

Si un fuseau horaire est spécifié, il doit être après l'heure. Les spécifications d'année peuvent être ajoutées à la fin des heures absolues.

Si parsedate() est appelé en contexte de tableau, il renverra deux éléments. En cas d'analyse réussie, il renverra les secondes et ce qui reste de la chaîne d'entrée. En cas d'échec de l'analyse, il renverra "undef" et une chaîne d'erreur.

EXEMPLES

$secondes = parsedate("Lun Jan  2 04:24:27 1995");
$secondes = parsedate("Mar Apr 4 00:22:12 PDT 1995");
$secondes = parsedate("04.04.95 00:22", ZONE => PDT);
$secondes = parsedate("Jan 1 1999 11:23:34.578", SUBSECOND => 1);
$secondes = parsedate("122212 950404", ZONE => PDT, TIMEFIRST => 1);
$secondes = parsedate("+3 secs", NOW => 796978800);
$secondes = parsedate("2 mois", NOW => 796720932);
$secondes = parsedate("mardi dernier");
$secondes = parsedate("dimanche avant le dernier");
($secondes, $reste) = parsedate("aujourd'hui est le jour");
($secondes, $erreur) = parsedate("aujourd'hui est", WHOLE=>1);
