TIFFWriteDirectory(3tiff) LibTIFF TIFFWriteDirectory(3tiff)

NOM

TIFFWriteDirectory - Écrit le répertoire courant dans un fichier TIFF ouvert

SYNOPSIS

#include <tiffio.h>
int TIFFWriteDirectory(TIFF *tif)
int TIFFRewriteDirectory(TIFF *tif)
int TIFFCheckpointDirectory(TIFF *tif)
void TIFFSetWriteOffset(TIFF *tif, toff_t off)
int TIFFWriteCheck(TIFF *tif, int tiles, const char *module)

DESCRIPTION

TIFFWriteDirectory() écrira le contenu du répertoire courant (IFD) dans le fichier et préparera la création d'un nouveau répertoire (IFD) en utilisant TIFFCreateDirectory(). Les applications n'ont besoin d'appeler TIFFWriteDirectory() que lors de l'écriture de plusieurs sous-fichiers (images) dans un seul fichier TIFF. Ceci est appelé "TIFF multi-pages" ou "TIFF multi-images" (voir Multi Page / Multi Image TIFF). TIFFWriteDirectory() est appelé automatiquement par TIFFClose() et TIFFFlush() pour écrire un répertoire modifié si le fichier est ouvert en écriture.

La fonction TIFFRewriteDirectory() fonctionne de manière similaire à TIFFWriteDirectory(), mais peut être appelée avec des répertoires précédemment lus ou écrits qui ont déjà un emplacement établi dans le fichier. Ceci réécrira le répertoire, mais au lieu de le placer à son ancien emplacement (comme le ferait TIFFWriteDirectory()), il le placera à la fin du fichier, corrigeant le pointeur du répertoire précédent ou de l'en-tête du fichier pour pointer vers son nouvel emplacement. Ceci est particulièrement important dans les cas où la taille du répertoire et les données auxquelles il pointe ont augmenté, ce qui ne tiendrait pas dans l'espace disponible à son ancien emplacement.

La fonction TIFFCheckpointDirectory() écrit l'état actuel du répertoire TIFF dans le fichier pour rendre ce qui est dans le fichier lisible. Contrairement à TIFFWriteDirectory(), TIFFCheckpointDirectory() ne libère pas les structures de données du répertoire en mémoire, elles peuvent donc être mises à jour (comme les bandes/tuiles qui sont écrites) et réécrites. En lisant un fichier partiel ainsi, vous obtiendrez une erreur de lecture TIFF pour la première bande/tuile incomplète, mais vous obtiendrez au moins toutes les données valides dans le fichier avant cela. Lorsque le fichier est complet, vous ne devriez utiliser que TIFFWriteDirectory() comme d'habitude pour le terminer proprement.

La fonction TIFFSetWriteOffset() définit le décalage d'écriture courant. Ceci ne doit être utilisé que pour définir le décalage à un emplacement connu précédent (avec soin), ou à 0 pour que la prochaine écriture soit ajoutée à la fin du fichier.

La fonction TIFFWriteCheck() vérifie que le fichier est accessible en écriture et que les informations du répertoire sont correctement configurées. En faisant cette dernière, elle "libère" également l'état du répertoire afin que des informations importantes ne soient pas modifiées.

VALEURS DE RETOUR

1 est renvoyé lorsque le contenu est écrit avec succès dans le fichier. Sinon, 0 est renvoyé si une erreur s'est produite lors de l'écriture du contenu du répertoire.

DIAGNOSTIQUES

Tous les messages d'erreur sont dirigés vers la routine TIFFErrorExtR().

"Error post-encoding before directory write":

Avant d'écrire le contenu du répertoire courant, toutes les données en attente sont fermées. Ce message indique qu'une erreur s'est produite pendant ce processus.

"Error flushing data before directory write":

Avant d'écrire le contenu du répertoire courant, toutes les données en attente sont fermées. Ce message indique qu'une erreur s'est produite pendant ce processus.

"Cannot write directory, out of space":

Il n'y a pas assez d'espace pour héberger une zone temporaire pour le répertoire à écrire.

"Error writing directory count":

Une erreur s'est produite lors de l'écriture du compteur de champs du répertoire.

"Error writing directory contents":

Une erreur s'est produite lors de l'écriture des champs du répertoire.

"Error writing directory link":

Une erreur s'est produite lors de l'écriture du lien vers le répertoire suivant.

Error writing data for field "%s":

Une erreur s'est produite lors de l'écriture de données indirectes pour le champ spécifié.

"Error writing TIFF header":

Une erreur s'est produite lors de la réécriture de l'en-tête au début du fichier.

"Error fetching directory count":

Une erreur s'est produite lors de la lecture du champ de compteur du répertoire précédent. Ceci peut se produire lors de l'établissement d'un lien vers le répertoire en cours d'écriture.

"Error fetching directory link":

Une erreur s'est produite lors de la lecture du champ de lien du répertoire précédent. Ceci peut se produire lors de l'établissement d'un lien vers le répertoire en cours d'écriture.
