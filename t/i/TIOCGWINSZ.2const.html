TIOCSWINSZ(2const) TIOCSWINSZ(2const)

NOM

TIOCGWINSZ, TIOCSWINSZ - obtenir et définir la taille de la fenêtre

BIBLIOTHEQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <asm/termbits.h>  /* Définition des constantes TIOC*WINSZ */
#include <sys/ioctl.h>
int ioctl(int fd, TIOCGWINSZ, struct winsize *argp);
int ioctl(int fd, TIOCSWINSZ, const struct winsize *argp);
#include <asm/termios.h>
struct winsize {
    unsigned short ws_row;
    unsigned short ws_col;
    unsigned short ws_xpixel;  /* inutilisé */
    unsigned short ws_ypixel;  /* inutilisé */
};

DESCRIPTION

Les tailles de fenêtre sont conservées dans le noyau, mais ne sont pas utilisées par celui-ci (sauf dans le cas des consoles virtuelles, où le noyau mettra à jour la taille de la fenêtre lorsque celle-ci change, par exemple en chargeant une nouvelle police).

TIOCGWINSZ
Obtenir la taille de la fenêtre.
TIOCSWINSZ
Définir la taille de la fenêtre.

Lorsque la taille de la fenêtre change, un signal SIGWINCH est envoyé au groupe de processus de premier plan.

VALEUR DE RETOUR

En cas de succès, 0 est retourné. En cas d'erreur, -1 est retourné et errno est définie pour indiquer l'erreur.

VOIR AUSSI

ioctl(2), ioctl_tty(2const)
