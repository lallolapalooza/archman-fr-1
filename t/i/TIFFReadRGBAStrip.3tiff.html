TIFFREADRGBASTRIP(3tiff) LibTIFF TIFFREADRGBASTRIP(3tiff)

NOM

TIFFReadRGBAStrip - lit et décode une bande d'image dans un raster au format fixe

SYNTAXE

#include <tiffio.h>
int TIFFReadRGBAStrip(TIFF *tif, uint32_t row, uint32_t *raster)
int TIFFReadRGBAStripExt(TIFF *tif, uint32_t row, uint32_t *raster, int stop_on_error)

DESCRIPTION

TIFFReadRGBAStrip() lit une seule bande d'une image basée sur des bandes en mémoire, stockant le résultat dans le raster RGBA fourni par l'utilisateur. Le raster est supposé être un tableau de ImageWidth × RowsPerStrip entrées de 32 bits, où ImageWidth est la largeur de l'image (TIFFTAG_IMAGEWIDTH) et RowsPerStrip est le nombre maximal de lignes dans une bande (TIFFTAG_ROWSPERSTRIP).

TIFFReadRGBAStripExt() fournit le paramètre stop_on_error. Son comportement est décrit dans TIFFReadRGBAImage.

La valeur row doit être la ligne de la première ligne de la bande (bande × RowsPerStrip, indexée à partir de zéro).

Notez que le raster est supposé être organisé de telle sorte que le pixel à la localisation (x, y) soit raster [ y × width + x ]; avec l'origine du raster dans le coin inférieur gauche de la bande. C'est-à-dire une organisation du bas vers le haut. Lors de la lecture d'une dernière bande partielle dans le fichier, la dernière ligne de l'image commencera au début du tampon.

Les pixels du raster sont des échantillons rouge, vert, bleu, alpha compressés sur 8 bits. Les macros TIFFGetR, TIFFGetG, TIFFGetB et TIFFGetA doivent être utilisées pour accéder aux échantillons individuels. Les images sans informations de matting alpha associé ont un Alpha constant de 1.0 (255).

Voir la page TIFFRGBAImage pour plus de détails sur la manière dont divers types d'images sont convertis en valeurs RGBA.

NOTES

Les échantillons doivent être de 1, 2, 4, 8 ou 16 bits. Les échantillons colorimétriques par pixel doivent être de 1, 3 ou 4 (c'est-à-dire SamplesPerPixel - ExtraSamples).

Les tables de couleurs d'images en palette qui semblent incorrectement écrites comme des valeurs de 8 bits sont automatiquement mises à l'échelle à 16 bits.

TIFFReadRGBAStrip() n'est qu'un wrapper autour des facilités plus générales de TIFFRGBAImage. Son principal avantage par rapport à la fonction similaire TIFFReadRGBAImage() est que pour les grandes images, un seul tampon capable de contenir toute l'image n'a pas besoin d'être alloué, seulement suffisamment pour une bande. La fonction TIFFReadRGBATile() effectue une opération similaire pour les images carrelées.

VALEURS DE RETOUR

1 est retourné si l'image a été lue et convertie avec succès. Sinon, 0 est retourné si une erreur a été rencontrée.

DIAGNOSTICS

Tous les messages d'erreur sont dirigés vers la routine TIFFErrorExtR().

"Désolé, impossible de traiter des images %d bits":

L'image avait BitsPerSample différent de 1, 2, 4, 8 ou 16.

"Désolé, impossible de traiter des images à %d canaux":

L'image avait SamplesPerPixel différent de 1, 3 ou 4.

Manque la balise "PhotometricInterpretation" requise:

L'image n'avait pas de balise décrivant comment afficher les données.

Aucune balise "PhotometricInterpretation", supposition RGB:

L'image était dépourvue d'une balise décrivant comment l'afficher, mais parce qu'elle a 3 ou 4 échantillons par pixel, elle est supposée être RGB.

Aucune balise "PhotometricInterpretation", supposition min-est-noir\fP:

L'image était dépourvue d'une balise décrivant comment l'afficher, mais parce qu'elle a 1 échantillon par pixel, elle est supposée être une image en niveaux de gris ou bileille.

"Pas d'espace pour la table de conversion photométrique":

Il n'y avait pas assez de mémoire pour une table utilisée pour convertir les échantillons d'image en RVB 8 bits.

Manque la balise "Colormap" requise:

Une image en palette n'avait pas la balise Colormap requise.

"Pas d'espace pour le tampon de tuile":

Il n'y avait pas assez de mémoire pour allouer un tampon d'entrée/sortie.

"Pas d'espace pour le tampon de bande":

Il n'y avait pas assez de mémoire pour allouer un tampon d'entrée/sortie.

"Impossible de traiter le format":

L'image a un format (combinaison de BitsPerSample, SamplesPerPixel et PhotometricInterpretation) que TIFFReadRGBAImage() ne peut pas gérer.

"Pas d'espace pour la table de mappage B&W":

Il n'y avait pas assez de mémoire pour allouer une table utilisée pour mapper les données en niveaux de gris vers le RVB.

"Pas d'espace pour la table de mappage de palette":

Il n'y avait pas assez de mémoire pour allouer une table utilisée pour mapper les données vers le RVB 8 bits.
