NOM

TIFFSetTagExtender - enregistrer la fonction de fusion pour les balises définies par l'utilisateur en tant que rappel d'extension avec libtiff

SYNTAXE

#include <tiffio.h>
TIFFExtendProc TIFFSetTagExtender(TIFFExtendProc extender)

DESCRIPTION

TIFFSetTagExtender() est utilisé pour enregistrer la fonction de fusion des balises définies par l'utilisateur en tant que rappel d'extension avec libtiff. Une brève description peut être trouvée dans Defining Application Tags.

NOTE :

TIFFSetTagExtender() ne peut pas être utilisé pour étendre des répertoires personnalisés (par exemple, EXIF, GPS ou d'autres répertoires personnalisés). Seul le répertoire TIFF peut être étendu avec des balises supplémentaires.
