NOM

TIFFWarning - interface d'avertissement de la bibliothèque

SYNTAXE

#include <tiffio.h>
#include <stdarg.h>
void TIFFWarning(const char *module, const char *fmt, ...)
void TIFFWarningExt(thandle_t fd, const char *module, const char *fmt, ...)
void TIFFWarningExtR(TIFF *tif, const char *module, const char *fmt, ...)
typedef void (*TIFFWarningHandler)(const char *module, const char *fmt, va_list ap)
typedef void (*TIFFWarningHandlerExt)(thandle_t fd, const char *module, const char *fmt, va_list ap)
typedef int (*TIFFWarningHandlerExtR)(TIFF *tif, void *user_data, const char *module, const char *fmt, va_list ap)
TIFFWarningHandler TIFFSetWarningHandler(TIFFWarningHandler handler)
TIFFWarningHandlerExt TIFFSetWarningHandlerExt(TIFFWarningHandlerExt handler)

DESCRIPTION

TIFFWarning() invoque la fonction de gestionnaire d'avertissement de la bibliothèque pour écrire (normalement) un message d'avertissement sur stderr. Le paramètre fmt est une chaîne de format printf(), et des arguments peuvent être fournis. Le paramètre module est interprété comme une chaîne qui, si non nulle, doit être imprimée avant le message ; il est typiquement utilisé pour identifier le module logiciel dans lequel un avertissement est détecté.

Les applications qui souhaitent intercepter le contrôle en cas d'avertissement doivent utiliser TIFFSetWarningHandler() pour remplacer le gestionnaire d'avertissement par défaut. Un gestionnaire d'avertissement NULL (0) peut être installé pour supprimer les messages d'avertissement.

Deux autres rappels de gestionnaires d'avertissement spécifiques à l'application sont disponibles, chacun avec des paramètres d'appel différents et transmettant des paramètres au gestionnaire. Chaque gestionnaire est également lié à une fonction de message d'avertissement, c'est-à-dire TIFFWarningExt() et TIFFWarningExtR() si l'application a l'intention d'appeler le gestionnaire avec ces paramètres étendus.

TIFFWarningExt() fournit un descripteur de fichier comme paramètre. Dans libtiff, TIFFWarningExt() est appelé en passant tif->tif_clientdata comme fd, qui représente le descripteur de fichier TIFF. Le gestionnaire spécifique à l'application et global pour TIFFWarningExt() est configuré avec TIFFSetWarningHandlerExt().

TIFFWarningExtR() (introduit avec libtiff 4.5) est appelé avec son descripteur TIFF et fournit ainsi l'accès à un gestionnaire d'avertissement par descripteur TIFF (réentrable). Cela signifie que pour différents descripteurs TIFF, différents gestionnaires d'avertissement peuvent être configurés. Ce gestionnaire spécifique à l'application peut être configuré lorsqu'un fichier TIFF est ouvert avec l'une des fonctions suivantes : TIFFOpenExt(), TIFFOpenWExt(), TIFFFdOpenExt() ou TIFFClientOpenExt(). De plus, une structure de données définie par l'utilisateur user_data pour le gestionnaire d'avertissement peut être fournie.

NOTE

Les deux fonctions TIFFWarning() et TIFFWarningExt() tentent chacune d'appeler les deux fonctions de gestionnaire si elles sont définies. D'abord, TIFFWarningHandler() est appelé, puis TIFFWarningHandlerExt(). Cependant, TIFFWarning() passe un "0" comme descripteur de fichier à TIFFWarningHandlerExt().

TIFFWarningExtR() essaie d'abord d'appeler le gestionnaire d'avertissement défini par descripteur TIFF. Si TIFFWarningHandlerExtR() n'est pas défini ou renvoie 0, TIFFWarningHandler() puis TIFFWarningHandlerExt() sont appelés. À partir de libtiff 4.5, TIFFWarningExtR() est utilisé dans la bibliothèque libtiff.

VALEURS DE RETOUR

TIFFSetWarningHandler() et TIFFSetWarningHandlerExt() retournent une référence à la fonction de gestionnaire d'avertissement précédente.

TIFFWarningHandlerExtR() renvoie un entier comme "arrêt" pour contrôler l'appel d'autres fonctions de gestionnaire d'avertissement dans TIFFWarningExtR() :

  • 0 : les deux fonctions TIFFWarningHandler() et TIFFWarningHandlerExt() sont appelées.
  • non nul : aucune autre fonction de message d'avertissement n'est appelée.
