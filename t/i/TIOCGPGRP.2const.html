TIOCSPGRP(2const) TIOCSPGRP(2const)

NOM

TIOCGPGRP, TIOCSPGRP, TIOCGSID - identifiant de groupe de processus et de session

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <asm/termbits.h>  /* Définition des constantes TIOC* */
#include <sys/ioctl.h>
int ioctl(int fd, TIOCGPGRP, pid_t *argp);
int ioctl(int fd, TIOCSPGRP, const pid_t *argp);
int ioctl(int fd, TIOCGSID, pid_t *argp);

DESCRIPTION

TIOCGPGRP
En cas de succès, équivalent à *argp = tcgetpgrp(fd).
Obtient l'identifiant du groupe de processus du groupe de processus de premier plan sur ce terminal.
TIOCSPGRP
Équivalent à tcsetpgrp(fd, *argp).
Définit l'identifiant du groupe de processus de premier plan de ce terminal.
TIOCGSID
En cas de succès, équivalent à *argp = tcgetsid(fd).
Obtient l'identifiant de session du terminal donné. Cela échoue avec l'erreur ENOTTY si le terminal n'est pas un pseudoterminal maître et n'est pas notre terminal de contrôle. Étrange.

VALEUR RENVOYÉE

En cas de succès, 0 est retourné. En cas d'erreur, -1 est retourné et errno est défini pour indiquer l'erreur.

ERREURS

ENOTTY
Le terminal n'est pas un pseudoterminal maître et n'est pas notre terminal de contrôle.
EPERM
Permission insuffisante.

VOIR AUSSI

ioctl(2), ioctl_tty(2), tcgetpgrp(3), tcsetpgrp(3), tcgetsid(3)
