TIFFGETFIELD(3tiff) LibTIFF TIFFGETFIELD(3tiff)

NOM

TIFFGetField - obtenir la ou les valeurs d'une balise dans un fichier TIFF ouvert

SYNTAXE

#include <tiffio.h>
#include <stdarg.h>
int TIFFGetField(TIFF *tif, ttag_t tag, ...)
int TIFFVGetField(TIFF *tif, ttag_t tag, va_list ap)
int TIFFGetFieldDefaulted(TIFF *tif, ttag_t tag, ...)
int TIFFVGetFieldDefaulted(TIFF *tif, ttag_t tag, va_list ap)

DESCRIPTION

TIFFGetField() renvoie la valeur d'une balise ou d'une pseudo-balise associée au répertoire courant du fichier TIFF ouvert tif. (Une pseudo-balise est un paramètre utilisé pour contrôler le fonctionnement de la bibliothèque TIFF mais dont la valeur n'est ni lue ni écrite dans le fichier sous-jacent.) Le fichier doit avoir été préalablement ouvert avec TIFFOpen(). La balise est identifiée par tag, une des valeurs définies dans le fichier d'en-tête tiff.h (voir également le tableau ci-dessous). Le type et le nombre de valeurs renvoyées dépendent de la balise demandée. L'interface de programmation utilise une liste d'arguments variable comme spécifié par l'interface stdarg.h. Les valeurs renvoyées ne doivent être interprétées que si TIFFGetField() renvoie 1.

TIFFVGetField() est fonctionnellement équivalent à TIFFGetField(), à la différence qu'il prend un pointeur vers une liste d'arguments variable. TIFFVGetField() est utile pour superposer des interfaces sur la fonctionnalité fournie par TIFFGetField().

TIFFGetFieldDefaulted() et TIFFVGetFieldDefaulted() sont identiques à TIFFGetField() et TIFFVGetField(), respectivement, sauf que si une balise n'est pas définie dans le répertoire courant et qu'elle possède une valeur par défaut, alors cette valeur par défaut est renvoyée.

Les balises comprises par libtiff, le nombre de valeurs paramètres et les types des valeurs renvoyées sont présentés ci-dessous. Les types de données sont spécifiés comme en C et correspondent aux types utilisés pour spécifier les valeurs de balise à TIFFSetField(). N'oubliez pas que TIFFGetField() renvoie des valeurs de paramètres, donc tous les types de données listés sont des pointeurs vers le stockage où les valeurs doivent être renvoyées. Consultez la spécification TIFF (ou la spécification industrielle pertinente) pour obtenir des informations sur la signification de chaque balise et leurs valeurs possibles.

TAGS_AUTOENREGISTRÉS

Si vous ne trouvez pas la balise dans le tableau ci-dessus, cela signifie qu'il s'agit d'une balise non prise en charge et qu'elle n'est pas directement prise en charge par la bibliothèque libtiff. Bien que vous ne puissiez pas lire sa valeur directement, vous pourrez toujours la lire si vous connaissez le type de données de cette balise. Par exemple, si vous souhaitez lire la valeur LONG de la balise 33424 et la chaîne ASCII de la balise 36867, vous pouvez utiliser le code suivant :

uint32_t  count;
void    *data;
TIFFGetField(tiff, 33424, &count, &data);
printf("Tag %d: %d, count %d\n", 33424, *(uint32_t *)data, count);
TIFFGetField(tiff, 36867, &count, &data);
printf("Tag %d: %s, count %d\n", 36867, (char *)data, count);

VALEURS_DE_RETOUR

1 est renvoyé si la balise est définie dans le répertoire actuel ; sinon, 0 est renvoyé.

DIAGNOSTICS

Tous les messages d'erreur sont dirigés vers la routine TIFFErrorExtR().

Champ non reconnu, balise 0x%x :

Une balise inconnue a été fournie.

VOIR_AUSSI

TIFFOpen (3tiff), TIFFSetField (3tiff), TIFFSetDirectory (3tiff), TIFFReadDirectory (3tiff), TIFFWriteDirectory (3tiff), libtiff (3tiff)
