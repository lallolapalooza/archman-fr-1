NOM

TIFFFieldQuery - routines pour interroger les informations de champ TIFF

SYNTAXE

#include <tiffio.h>
const TIFFField *TIFFFieldWithName(TIFF *tif, const char *field_name)
const TIFFField *TIFFFieldWithTag(TIFF *tif, uint32_t tag)
const TIFFField *TIFFFindField(TIFF *tif, uint32_t tag, TIFFDataType dt)
int TIFFFieldIsAnonymous(const TIFFField *fip)
int TIFFFieldSetGetSize(const TIFFField *fip)
int TIFFFieldSetGetCountSize(const TIFFField *fip)

DESCRIPTION

TIFFFieldWithName() et TIFFFieldWithTag() retournent un pointeur vers la structure d'information de champ TIFF fip par le nom du tag (field_name) ou son numéro de tag.

TIFFFindField() recherche la structure d'information de champ TIFF fip pour un numéro de tag donné et un TIFFDataType dt spécifique. Avec dt== TIFF_ANY le comportement est le même que pour TIFFFieldWithTag().

Toutes les trois fonctions retournent NULL si le tag n'est pas enregistré dans libtiff (voir également Default Tag Auto-registration ).

Une recherche dépendante de TIFFDataType comme celle-ci pourrait être utile lorsque le même tag est défini deux fois mais avec des types de données différents, ce qui est vrai dans de rares cas comme TIFFTAG_XCLIPPATHUNITS. Cependant, libtiff ne supporte actuellement pas les définitions multiples du même tag.

Les routines suivantes retournent des informations sur l'état des champs TIFF.

fip est un pointeur d'information de champ retourné précédemment par TIFFFindField(), TIFFFieldWithTag(), TIFFFieldWithName().

TIFFFieldIsAnonymous() retourne vrai (non nul) si le champ, lu à partir du fichier, est inconnu de libtiff et qu'un champ anonyme a été auto-enregistré. Le retour est zéro “0” si le champ est connu de libtiff. Voir Default Tag Auto-registration pour plus d'informations.

TIFFFieldSetGetSize() retourne la taille des données en octets du type de données du champ utilisé pour le stockage interne de libtiff. C'est aussi la taille des données du paramètre à fournir à TIFFSetField() et TIFFGetField(). Les valeurs TIFF_RATIONAL personnalisées peuvent être stockées en interne soit comme float soit comme double. TIFFFieldSetGetSize() retournerait alors “4” ou “8”, respectivement.

TIFFFieldSetGetCountSize() retourne la taille du paramètre count de TIFFSetField() et TIFFGetField() et aussi s'il est requis: 0=aucun, 2= uint16_t, 4= uint32_t. Voir aussi la description de TIFFFieldReadCount().
