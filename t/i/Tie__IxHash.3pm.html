Tie::IxHash(3) Documentation Perl contribuée par l'utilisateur Tie::IxHash(3)

NOM

Tie::IxHash - tableaux associatifs ordonnés pour Perl

SYNOPIS

# usage simple
use Tie::IxHash;
tie HASHVARIABLE, 'Tie::IxHash' [, LIST];
# interface OO avec des fonctionnalités plus puissantes
use Tie::IxHash;
TIEOBJECT = Tie::IxHash->new( [LIST] );
TIEOBJECT->Splice( OFFSET [, LENGTH [, LIST]] );
TIEOBJECT->Push( LIST );
TIEOBJECT->Pop;
TIEOBJECT->Shift;
TIEOBJECT->Unshift( LIST );
TIEOBJECT->Keys( [LIST] );
TIEOBJECT->Values( [LIST] );
TIEOBJECT->Indices( LIST );
TIEOBJECT->Delete( [LIST] );
TIEOBJECT->Replace( OFFSET, VALUE, [KEY] );
TIEOBJECT->Reorder( LIST );
TIEOBJECT->SortByKey;
TIEOBJECT->SortByValue;
TIEOBJECT->Length;

DESCRIPTION

Ce module Perl implémente des hachages Perl qui conservent l'ordre dans lequel les éléments du hachage ont été ajoutés. L'ordre n'est pas affecté lorsque les valeurs correspondant aux clés existantes dans IxHash sont modifiées. Les éléments peuvent également être définis dans n'importe quel ordre arbitraire fourni. Les opérations de tableau Perl familières peuvent également être effectuées sur IxHash.

Interface standard "TIEHASH"

Le mécanisme standard "TIEHASH" est disponible. Cette interface est recommandée pour des utilisations simples, car l'utilisation est exactement la même que celle des hachages Perl réguliers après la déclaration du "tie".

Interface objet

Ce module fournit également une interface orientée objet étendue qui peut être utilisée pour des opérations plus puissantes avec IxHash. Les méthodes suivantes sont disponibles :

FETCH, STORE, DELETE, EXISTS
Ces méthodes standard "TIEHASH" requises par Perl peuvent être utilisées directement. Voir l'entrée "tie" dans perlfunc(1) pour plus de détails.
Push, Pop, Shift, Unshift, Splice
Ces méthodes supplémentaires ressemblant aux fonctions Perl sont disponibles pour opérer sur les paires clé-valeur dans IxHash. Le comportement est le même que celui des fonctions Perl correspondantes, sauf lorsqu'une clé de hachage fournie existe déjà dans le hachage. Dans ce cas, la valeur existante est mise à jour mais son ordre n'est pas affecté. Pour modifier inconditionnellement l'ordre d'une paire clé-valeur fournie, "DELETE" d'abord l'élément IxHash.
Keys
Retourne un tableau de clés d'éléments IxHash correspondant à la liste des indices fournis. Retourne un tableau de toutes les clés si appelé sans arguments. Notez que la valeur de retour est principalement utile lorsqu'elle est utilisée dans un contexte de liste (car Perl la convertira en nombre d'éléments du tableau dans un contexte scalaire, et cela peut ne pas être très utile).

Si un seul argument est donné, retourne la clé unique correspondant à l'indice. Ceci est utilisable dans un contexte scalaire ou de liste.

Values
Retourne un tableau de valeurs d'éléments IxHash correspondant à la liste des indices fournis. Retourne un tableau de toutes les valeurs si appelé sans arguments. Notez que la valeur de retour est principalement utile lorsqu'elle est utilisée dans un contexte de liste (car Perl la convertira en nombre d'éléments du tableau dans un contexte scalaire, et cela peut ne pas être très utile).

Si un seul argument est donné, retourne la valeur unique correspondant à l'indice. Ceci est utilisable dans un contexte scalaire ou de liste.

Indices
Retourne un tableau d'indices correspondant à la liste de clés fournie. Notez que la valeur de retour est principalement utile lorsqu'elle est utilisée dans un contexte de liste (car Perl la convertira en nombre d'éléments du tableau dans un contexte scalaire, et cela peut ne pas être très utile).

Si un seul argument est donné, retourne l'indice unique correspondant à la clé. Ceci est utilisable dans un contexte scalaire ou de liste.

Delete
Supprime les éléments avec les clés fournies de IxHash.
Replace
Remplace l'élément IxHash à l'indice spécifié par la paire valeur-clé fournie. Si une clé n'est pas fournie, remplace simplement la valeur à l'indice par la valeur fournie. Si un élément avec la clé fournie existe déjà, il sera d'abord supprimé de IxHash.
Reorder
Cette méthode peut être utilisée pour manipuler l'ordre interne des éléments IxHash en fournissant une liste de clés dans l'ordre désiré. Notez cependant que tous les éléments IxHash dont les clés ne sont pas dans la liste seront supprimés de IxHash.
Length
Retourne le nombre d'éléments IxHash.
SortByKey
Réordonne les éléments IxHash par comparaison textuelle des clés.
SortByValue
Réordonne les éléments IxHash par comparaison textuelle des valeurs.
Clear
Réinitialise IxHash à son état initial : sans aucun élément.

EXEMPLE

use Tie::IxHash;
# interface simple
$t = tie(%myhash, 'Tie::IxHash', 'a' => 1, 'b' => 2);
%myhash = (first => 1, second => 2, third => 3);
$myhash{fourth} = 4;
@keys = keys %myhash;
@values = values %myhash;
print("y") if exists $myhash{third};
# interface OO
$t = Tie::IxHash->new(first => 1, second => 2, third => 3);
$t->Push(fourth => 4); # équivalent à $myhash{'fourth'} = 4;
($k, $v) = $t->Pop;    # $k est 'fourth', $v est 4
$t->Unshift(neg => -1, zeroth => 0); 
($k, $v) = $t->Shift;  # $k est 'neg', $v est -1
@oneandtwo = $t->Splice(1, 2, foo => 100, bar => 101);
@keys = $t->Keys;
@values = $t->Values;
@indices = $t->Indices('foo', 'zeroth');
@itemkeys = $t->Keys(@indices);
@itemvals = $t->Values(@indices);
$t->Replace(2, 0.3, 'other');
$t->Delete('second', 'zeroth');
$len = $t->Length;     # nombre de paires clé-valeur
$t->Reorder(reverse @keys);
$t->SortByKey;
$t->SortByValue;

BOGUES

Vous ne pouvez pas spécifier une longueur négative à "Splice". Les indices négatifs sont cependant acceptés.

NOTE

L'indexation commence toujours à 0 (malgré le paramètre $[ actuel) pour toutes les fonctions.

AMÉLIORATIONS PRÉVUES

L'ajout d'éléments avec des clés qui existent déjà à la fin de IxHash doit être contrôlé par un commutateur.

Fournir une interface "TIEARRAY" lorsqu'elle sera stabilisée dans Perl.

Réécrire en utilisant des XSUBs pour l'efficacité.
