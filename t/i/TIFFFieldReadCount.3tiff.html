TIFFFIELDREADCOUNT(3tiff) LibTIFF TIFFFIELDREADCOUNT(3tiff)

NOM

TIFFFieldReadCount - obtenir le nombre de valeurs à lire à partir d'un champ

SYNTAXE

#include <tiffio.h>
int TIFFFieldReadCount(const TIFFField *fip)

DESCRIPTION

TIFFFieldReadCount() renvoie le nombre de valeurs disponibles à lire à partir du champ TIFF spécifié ; c'est-à-dire le nombre d'arguments qui doivent être fournis à TIFFGetField(). Pour la plupart des types de champs, il s'agit d'un petit entier positif, généralement 1 ou 2, mais il existe des valeurs spéciales :

  • TIFF_VARIABLE = -1 indique qu'un nombre variable de valeurs est possible ; dans ce cas, un argument de type uint16_t count et un argument de pointeur data doivent être fournis à TIFFGetField().
  • TIFF_VARIABLE2 = -3 est identique à TIFF_VARIABLE, sauf que l'argument count doit être de type uint32_t.
  • TIFF_SPP = -2 indique que le nombre d'arguments est égal au nombre d'échantillons par pixel de l'image.

fip est un pointeur d'informations de champ renvoyé précédemment par TIFFFindField(), TIFFFieldWithTag() ou TIFFFieldWithName().

VALEURS DE RETOUR

TIFFFieldReadCount() renvoie un entier.

VOIR AUSSI
