NOM

TIFFWriteEncodedTile - compresse et écrit une tuile de données dans un fichier TIFF ouvert

SYNTAXE

#include <tiffio.h>
tsize_t TIFFWriteEncodedTile(TIFF *tif, ttile_t tile, tdata_t buf, tsize_t size)

DESCRIPTION

Compresse size octets de données brutes à partir de buf et ajoute le résultat à la fin de la tuile spécifiée. Notez que la valeur de tile est un numéro de tuile « brut ». C'est-à-dire que l'appelant doit tenir compte du fait que les données soient organisées en plans séparés (PlanarConfiguration = 2). TIFFComputeTile() s'en charge automatiquement lors de la conversion d'un quadruplet de coordonnées (x,y,z,sample) en numéro de tuile.

NOTES

La bibliothèque écrit les données encodées en utilisant l'ordre des octets de la machine native. Les lecteurs TIFF correctement implémentés sont censés effectuer toute permutation d'octets nécessaire pour traiter correctement les données d'image avec BitsPerSample supérieur à 8.

VALEURS DE RETOUR

-1 est retourné si une erreur a été rencontrée. Sinon, la valeur de size est retournée.

DIAGNOSTICS

Tous les messages d'erreur sont dirigés vers la routine TIFFErrorExtR().

%s : Fichier non ouvert en écriture :

Le fichier a été ouvert en lecture, pas en écriture.

Impossible d'écrire des tuiles dans une image strippée :

L'image est supposée être organisée en bandes car ni les tags TileWidth ni TileLength n'ont été définis avec TIFFSetField().

%s : Doit définir "ImageWidth" avant d'écrire des données :

La largeur de l'image n'a pas été définie avant la première écriture. Voir TIFFSetField() pour savoir comment faire ceci.

%s : Doit définir "PlanarConfiguration" avant d'écrire des données :

L'organisation des données n'a pas été définie avant la première écriture. Voir TIFFSetField() pour savoir comment faire ceci.

%s : Pas d'espace pour les tableaux de tuiles :

Il n'y avait pas assez d'espace pour les tableaux qui contiennent les décalages de tuiles et les comptes d'octets.
