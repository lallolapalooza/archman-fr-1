TIOCMSET(2const) TIOCMSET(2const)

NOM

TIOCMGET, TIOCMSET, TIOCMBIC, TIOCMBIS, TIOCMIWAIT, TIOCGICOUNT - contrôle du modem

BIBLIOTHÉQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <asm/termbits.h>  /* Définition des constantes TIOC* */
#include <sys/ioctl.h>
int ioctl(int fd, TIOCMGET, int *argp);
int ioctl(int fd, TIOCMSET, const int *argp);
int ioctl(int fd, TIOCMBIC, const int *argp);
int ioctl(int fd, TIOCMBIS, const int *argp);
int ioctl(int fd, TIOCMIWAIT, int arg);
int ioctl(int fd, TIOCGICOUNT, struct serial_icounter_struct *argp);
#include <linux/serial.h>
struct serial_icounter_struct;

DESCRIPTION

TIOCMGET
Obtenir l'état des bits du modem.
TIOCMSET
Définir l'état des bits du modem.
TIOCMBIC
Effacer les bits du modem indiqués.
TIOCMBIS
Définir les bits du modem indiqués.

Les bits suivants sont utilisés par les ioctls ci-dessus :

TIOCM_LE DSR (data set ready/line enable)
TIOCM_DTR DTR (data terminal ready)
TIOCM_RTS RTS (request to send)
TIOCM_ST TXD secondaire (transmission)
TIOCM_SR RXD secondaire (réception)
TIOCM_CTS CTS (clear to send)
TIOCM_CAR DCD (data carrier detect)
TIOCM_CD voir TIOCM_CAR
TIOCM_RNG RNG (ring)
TIOCM_RI voir TIOCM_RNG
TIOCM_DSR DSR (data set ready)
TIOCMIWAIT
Attendre qu'un des 4 bits du modem (DCD, RI, DSR, CTS) change. Les bits d'intérêt sont spécifiés comme un masque de bits dans arg, en faisant un OU logique des valeurs de bits TIOCM_RNG, TIOCM_DSR, TIOCM_CD, et TIOCM_CTS. L'appelant doit utiliser TIOCGICOUNT pour voir quel bit a changé.
TIOCGICOUNT
Obtenir les compteurs des interruptions de ligne série entrantes (DCD, RI, DSR, CTS). Les compteurs sont écrits dans la structure serial_icounter_struct pointée par argp.
Note : les transitions 1->0 et 0->1 sont comptées, sauf pour RI, où seules les transitions 0->1 sont comptées.

VALEUR DE RETOUR

En cas de succès, 0 est retourné. En cas d'erreur, -1 est retourné, et errno est positionné pour indiquer l'erreur.

EXEMPLES

Vérifier l'état de DTR sur le port série.

#include <asm/termbits.h>
#include <fcntl.h>
#include <stdio.h>
#include <sys/ioctl.h>
#include <unistd.h>
int
main(void)
{
    int fd, serial;
    fd = open("/dev/ttyS0", O_RDONLY);
    ioctl(fd, TIOCMGET, &serial);
    if (serial & TIOCM_DTR)
        puts("TIOCM_DTR est défini");
    else
        puts("TIOCM_DTR n'est pas défini");
    close(fd);
}

VOIR AUSSI
