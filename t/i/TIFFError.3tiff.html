NOM

TIFFError - interface de gestion des erreurs de la bibliothèque

SYNTAXE

#include <tiffio.h>
#include <stdarg.h>
void TIFFError(const char *module, const char *fmt, ...)
void TIFFErrorExt(thandle_t fd, const char *module, const char *fmt, ...)
void TIFFErrorExtR(TIFF *tif, const char *module, const char *fmt, ...)
typedef void (*TIFFErrorHandler)(const char *module, const char *fmt, va_list ap)
typedef void (*TIFFErrorHandlerExt)(thandle_t fd, const char *module, const char *fmt, va_list ap)
typedef int (*TIFFErrorHandlerExtR)(TIFF *tif, void *user_data, const char *module, const char *fmt, va_list ap)
TIFFErrorHandler TIFFSetErrorHandler(TIFFErrorHandler handler)
TIFFErrorHandlerExt TIFFSetErrorHandlerExt(TIFFErrorHandlerExt handler)

DESCRIPTION

TIFFError() invoque la fonction de gestion des erreurs au niveau de la bibliothèque pour écrire (normalement) un message d'erreur sur stderr. Le paramètre fmt est une chaîne de formatage printf(), et des arguments supplémentaires peuvent être fournis. Le paramètre module est interprété comme une chaîne qui, si elle n'est pas nulle, doit être affichée avant le message ; il est typiquement utilisé pour identifier le module logiciel dans lequel une erreur est détectée.

Les applications qui souhaitent reprendre le contrôle en cas d'erreur devraient utiliser TIFFSetErrorHandler() pour remplacer le gestionnaire d'erreurs par défaut. Une fonction de gestionnaire d'erreurs NULL (0) peut être installée pour supprimer les messages d'erreur.

Deux autres rappels de gestionnaire d'erreurs spécifiques à l'application sont disponibles, chacun avec des paramètres d'appel différents et passant des paramètres au gestionnaire. Chaque gestionnaire est également lié à une fonction de message d'erreur, c'est-à-dire TIFFErrorExt() et TIFFErrorExtR() si l'application a l'intention d'appeler le gestionnaire avec ces paramètres étendus.

TIFFErrorExt() fournit un descripteur de fichier comme paramètre. Dans libtiff, TIFFErrorExt() est appelée en passant tif->tif_clientdata comme fd, qui représente le descripteur de fichier TIFF (descripteur de fichier). Le gestionnaire spécifique à l'application et au niveau de la bibliothèque pour TIFFErrorExt() est configuré avec TIFFSetErrorHandlerExt().

TIFFErrorExtR() (introduit avec libtiff 4.5) est appelée avec son descripteur TIFF et fournit ainsi un accès à un gestionnaire d'erreurs par descripteur TIFF (réentrant). Cela signifie que pour différents descripteurs TIFF, différents gestionnaires d'erreurs peuvent être configurés. Ce gestionnaire spécifique à l'application peut être configuré lorsqu'un fichier TIFF est ouvert avec l'une des fonctions suivantes : TIFFOpenExt(), TIFFOpenWExt(), TIFFFdOpenExt() ou TIFFClientOpenExt(). De plus, une structure de données définie par l'utilisateur user_data pour le gestionnaire d'erreurs peut être fournie.

NOTE

Les deux fonctions TIFFError() et TIFFErrorExt() tentent d'appeler les deux fonctions de gestionnaire si elles sont définies. D'abord, TIFFErrorHandler() est appelée, puis TIFFErrorHandlerExt(). Cependant, TIFFError() passe un '0' comme descripteur de fichier à TIFFErrorHandlerExt().

TIFFErrorExtR() tente d'abord d'appeler le gestionnaire d'erreurs défini par descripteur TIFF. Si TIFFErrorHandlerExtR() n'est pas défini ou retourne 0, TIFFErrorHandler() puis TIFFErrorHandlerExt() sont appelées. À partir de libtiff 4.5, TIFFErrorExtR() est utilisée dans la bibliothèque libtiff où le descripteur TIFF est disponible. Sinon, TIFFErrorExt() est utilisée !

VALEURS DE RETOUR

TIFFSetErrorHandler() et TIFFSetErrorHandlerExt() renvoient une référence à la fonction de gestionnaire d'erreurs précédente.

TIFFErrorHandlerExtR() renvoie un entier comme 'stop' pour contrôler l'appel des fonctions de gestionnaire d'erreurs ultérieures dans TIFFErrorExtR() :

  • 0 : les deux fonctions TIFFErrorHandler() et TIFFErrorHandlerExt() sont appelées.
  • non nul : aucune autre fonction de message d'erreur n'est appelée.
