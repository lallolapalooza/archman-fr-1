TIOCEXCL(2const) TIOCEXCL(2const)

NOM

TIOCEXCL, TIOCGEXCL, TIOCNXCL - mode exclusif

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <asm/termbits.h>  /* Définition des constantes TIOC*XCL */
#include <sys/ioctl.h>
int ioctl(int fd, TIOCEXCL);
int ioctl(int fd, TIOCGEXCL, int *argp);
int ioctl(int fd, TIOCNXCL);

DESCRIPTION

TIOCEXCL
Met le terminal en mode exclusif. Aucune autre opération d'open(2) sur le terminal n'est permise. (Elles échouent avec EBUSY, sauf pour un processus disposant de la capacité CAP_SYS_ADMIN.)
TIOCGEXCL
Si le terminal est actuellement en mode exclusif, place une valeur non nulle dans l'emplacement pointé par argp ; sinon, place zéro dans *argp.
TIOCNXCL
Désactive le mode exclusif.

VALEUR RETOURNÉE

En cas de succès, 0 est retourné. En cas d'erreur, -1 est retourné, et errno est défini pour indiquer l'erreur.

HISTORIQUE

TIOCGEXCL
Linux 3.8.

VOIR AUSSI

ioctl(2), ioctl_tty(2)
