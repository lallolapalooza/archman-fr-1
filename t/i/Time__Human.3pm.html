NOM

Time::Human - Convertir le format localtime() en heure de « horloge parlante »

SYNTAXE

use Time::Human;
print "Il est maintenant ", humanize(localtime());

DESCRIPTION

Ce module fournit un rendu « vague » de l'heure en langage naturel ; il est initialement destiné aux applications de synthèse vocale et autres interfaces vocales.

Il est entièrement internationalisé : si vous regardez le code, vous verrez une variable globale appelée %Time::Human::templates, que vous pouvez remplir pour d'autres langues. Si vous le multinationalisez, envoyez-moi des modèles pour d'autres langues afin qu'ils soient ajoutés aux futures versions. Vous pouvez définir la langue par défaut via la variable globale $Time::Human::Language.

$Time::Human::Evening et $Time::Human::Night décident des heures auxquelles l'après-midi devient le soir et le soir devient la nuit dans votre culture. Par exemple, les Grecs voudront peut-être que le soir commence à 23h ; pour les hackers, le soir peut commencer à 3h du matin.

UTILISATION

Paramètres d'importation

Ce module n'accepte aucun argument à sa méthode "import" (en fait, il n'a même pas de "méthode" d'importation).

Exportations

Ce module exporte un seul *symbole*, la fonction "humanize".
