NOM

Tie::Hash::NamedCapture - Tampons de capture nommés pour les expressions régulières

SYNTAXE

tie my %hash, "Tie::Hash::NamedCapture";
# %hash se comporte maintenant comme %+
tie my %hash, "Tie::Hash::NamedCapture", all => 1;
# %hash accède maintenant aux tampons de $qr comme avec %-

DESCRIPTION

Ce module est utilisé pour implémenter les hachages spéciaux "%+" et "%-", mais il peut être utilisé pour lier d'autres variables comme vous le souhaitez.

Lorsque le paramètre "all" est fourni, les éléments du hachage lié seront des références de tableaux listant le contenu de chaque tampon de capture dont le nom est identique à la clé de hachage associée. Si aucun de ces tampons n'a été impliqué dans la correspondance, le contenu de ce tableau sera autant de valeurs "undef" qu'il y a de tampons de capture portant ce nom. En d'autres termes, le hachage lié se comportera comme "%-".

Lorsque le paramètre "all" est omis ou faux, les éléments du hachage lié seront le contenu du tampon le plus à gauche défini avec le nom de la clé de hachage associée. En d'autres termes, le hachage lié se comportera comme "%+".

Les clés des hachages de type "%-" correspondent à tous les noms de tampons trouvés dans l'expression régulière ; les clés des hachages de type "%+" listent uniquement les noms des tampons qui ont capturé (et qui sont donc associés à des valeurs définies).

Cette implémentation a été déplacée dans l'exécutable principal, mais vous pouvez toujours charger ce module pour des raisons de compatibilité ascendante.
