TIFFReadRGBAImage(3tiff) LibTIFF TIFFReadRGBAImage(3tiff)

NOM

TIFFReadRGBAImage - lire et décoder une image dans un raster fixe

SYNOPSIS

#include <tiffio.h>
TIFFGetR(abgr)
((abgr)&0xff)
TIFFGetG(abgr)
(((abgr) >> 8) & 0xff)
TIFFGetB(abgr)
(((abgr) >> 16) & 0xff)
TIFFGetA(abgr)
(((abgr) >> 24) & 0xff)
int TIFFReadRGBAImage(TIFF *tif, uint32_t width, uint32_t height, uint32_t *raster, int stopOnError)
int TIFFReadRGBAImageOriented(TIFF *tif, uint32_t width, uint32_t height, uint32_t *raster, int orientation, int stopOnError)

DESCRIPTION

TIFFReadRGBAImage() lit une image basée sur des bandes ou des tuiles en mémoire, stockant le résultat dans le raster fourni par l'utilisateur. Le raster est supposé être un tableau de width × height entrées de 32 bits, où width doit être inférieur ou égal à la largeur de l'image (height peut être n'importe quelle taille positive). Si les dimensions du raster sont inférieures à celles de l'image, les données de l'image sont coupées aux limites du raster. Si la hauteur du raster est supérieure à celle de l'image, les données de l'image sont placées en bas du raster. (Note: le raster est supposé être organisé de telle sorte que le pixel à la position (x, y) soit raster[y × width + x]; avec l'origine du raster dans le coin inférieur gauche.)

TIFFReadRGBAImageOriented() fonctionne comme TIFFReadRGBAImage(), sauf que l'utilisateur peut spécifier la position de l'origine du raster avec le paramètre orientation. Quatre orientations sont supportées :

  • ORIENTATION_TOPLEFT : origine dans le coin supérieur gauche,
  • ORIENTATION_TOPRIGHT : origine dans le coin supérieur droit,
  • ORIENTATION_BOTLEFT : origine dans le coin inférieur gauche
  • ORIENTATION_BOTRIGHT : origine dans le coin inférieur droit.

Si vous choisissez ORIENTATION_BOTLEFT, le résultat sera le même que celui retourné par TIFFReadRGBAImage().

Les pixels du raster sont des échantillons de 8 bits de rouge, vert, bleu et alpha. Les macros TIFFGetR, TIFFGetG, TIFFGetB et TIFFGetA doivent être utilisées pour accéder aux échantillons individuels. Les images sans information de mathématique alpha ont une valeur alpha constante de 1.0 (255).

TIFFReadRGBAImage() convertit les images non-8 bits en mettant à l'échelle les valeurs des échantillons. Les images en palette, en niveaux de gris, bile-vel, CMJN et YCbCr sont converties en RVB de manière transparente. Les pixels du raster sont retournés sans ajustement pour toute information de colorimétrie présente dans le répertoire.

Le paramètre stopOnError spécifie comment agir en cas d'erreur lors de la lecture de l'image. Si stopOnError est non nul, une erreur arrêtera l'opération ; sinon, TIFFReadRGBAImage() continuera à traiter les données jusqu'à ce que toutes les données possibles dans l'image aient été demandées.

NOTES

En C++, le paramètre stopOnError vaut par défaut 0.

SamplesPerPixel doit être de 1, 2, 4, 8 ou 16 bits. Les échantillons de colorimétrie par pixel doivent être de 1, 3 ou 4 (c'est-à-dire SamplesPerPixel moins ExtraSamples).

Les cartes de couleurs des images qui semblent mal écrites comme valeurs de 8 bits sont automatiquement mises à l'échelle à 16 bits.

IFFReadRGBAImage() n'est qu'un wrapper des fonctionnalités plus générales de TIFFRGBAImage.

VALEURS DE RETOUR

1 est retourné si l'image a été lue et convertie correctement. Sinon, 0 est retourné si une erreur s'est produite et que stopOnError est 0.

DIAGNOSTICS

Tous les messages d'erreur sont acheminés vers la routine TIFFErrorExtR().

"Sorry, can not handle %d-bit pictures" :

L'image avait BitsPerSample différent de 1, 2, 4, 8 ou 16.

"Sorry, can not handle %d-channel images" :

L'image avait SamplesPerPixel différent de 1, 3 ou 4.

Missing needed "PhotometricInterpretation" tag :

L'image n'avait pas de tag décrivant comment afficher les données.

No "PhotometricInterpretation" tag, assuming RGB :

L'image n'avait pas de tag décrivant comment l'afficher, mais comme elle a 3 ou 4 échantillons/pixel, elle est supposée être RVB.

No "PhotometricInterpretation" tag, assuming min-is-black :

L'image n'avait pas de tag décrivant comment l'afficher, mais comme elle a 1 échantillon/pixel, elle est supposée être une image en niveaux de gris ou bile-vel.

"No space for photometric conversion table" :

Il n'y avait pas assez de mémoire pour allouer une table utilisée pour convertir les échantillons d'image en RVB 8 bits.

Missing required "Colormap" tag :

Une image en carte de couleurs n'avait pas de tag Colormap requis.

"No space for tile buffer" :

Il n'y avait pas assez de mémoire pour allouer un tampon d'E/S.

"No space for strip buffer" :

Il n'y avait pas assez de mémoire pour allouer un tampon d'E/S.

"Can not handle format" :

L'image a un format (combinaison de BitsPerSample, SamplesPerPixel et PhotometricInterpretation) que TIFFReadRGBAImage() ne peut pas gérer.

"No space for B&W mapping table" :

Il n'y avait pas assez de mémoire pour allouer une table utilisée pour mapper les données en niveaux de gris en RVB.

"No space for Palette mapping table" :

Il n'y avait pas assez de mémoire pour allouer une table utilisée pour mapper les données en RVB 8 bits.
