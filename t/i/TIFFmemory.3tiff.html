TIFFMEMORY(3tiff) LibTIFF TIFFMEMORY(3tiff)

NOM

TIFFmemory - fonctions relatives à la gestion de la mémoire à utiliser avec les fichiers TIFF

SYNTAXE

#include <tiffio.h>
tdata_t _TIFFmalloc(tsize_t size)
tdata_t _TIFFrealloc(tdata_t buffer, tsize_t size)
void _TIFFfree(tdata_t buffer)
void _TIFFmemset(tdata_t s, int c, tsize_t n)
void _TIFFmemcpy(tdata_t dest, const tdata_t src, tsize_t n)
int _TIFFmemcmp(const tdata_t s1, const tdata_ts2, tsize_t n)
void *_TIFFCheckMalloc(TIFF *tif, tmsize_t nmemb, tmsize_t elem_size, const char *what)
void *_TIFFCheckRealloc(TIFF *tif, void *buffer, tmsize_t nmemb, tmsize_t elem_size, const char *what)

DESCRIPTION

Ces routines sont fournies pour écrire des logiciels portables qui utilisent libtiff ; elles masquent les problèmes liés à la gestion de la mémoire, tels que la gestion des architectures segmentées trouvées sur les machines 16 bits.

_TIFFmalloc() et _TIFFrealloc() sont utilisées pour allouer et réallouer dynamiquement la mémoire utilisée par libtiff ; par exemple, la mémoire passée aux routines d'E/S. La mémoire allouée via ces interfaces est libérée du système en utilisant la routine _TIFFfree().

La mémoire allouée via l'une des interfaces ci-dessus peut être initialisée à une valeur connue à l'aide de _TIFFmemset(), copiée vers un autre emplacement mémoire à l'aide de _TIFFmemcpy(), ou comparée pour vérifier l'égalité à l'aide de _TIFFmemcmp(). Ces routines sont conformes aux routines C équivalentes : memset(), memcpy(), memcmp(), respectivement.

_TIFFCheckMalloc() et _TIFFCheckRealloc() vérifient le dépassement d'entier avant d'appeler _TIFFmalloc() et _TIFFrealloc(), respectivement.
