TIFFBUFFER(3tiff) LibTIFF TIFFBUFFER(3tiff)

NOM

TIFFbuffer - routines de contrôle de mise en mémoire tampon des E/S

SYNTAXE

#include <tiffio.h>
int TIFFReadBufferSetup(TIFF *tif, tdata_t buffer, tsize_t size)
int TIFFWriteBufferSetup(TIFF *tif, tdata_t buffer, tsize_t size)

DESCRIPTION

Les routines suivantes sont fournies pour le contrôle par le client des tampons d'E/S utilisés par la bibliothèque. Les applications n'ont jamais besoin d'utiliser ces routines ; elles sont fournies uniquement pour les "clients intelligents" qui souhaitent optimiser l'utilisation de la mémoire et/ou éliminer les opérations de copie potentielles qui peuvent survenir lors du travail avec des images dont les données sont stockées sans compression.

TIFFReadBufferSetup() configure le tampon de données utilisé pour lire les données brutes (encodées) d'un fichier. Si le pointeur spécifié est NULL (zéro), alors un tampon de taille appropriée est alloué. Sinon, l'appelant doit garantir que le tampon est suffisamment grand pour contenir chaque bande de données brutes. TIFFReadBufferSetup() renvoie une valeur non nulle si la configuration a réussi et zéro sinon.

TIFFWriteBufferSetup() configure le tampon de données utilisé pour écrire les données brutes (encodées) dans un fichier. Si la taille spécifiée est -1, alors la taille du tampon est sélectionnée pour contenir une tuile ou une bande complète, ou au moins 8 kilo-octets, le plus grand des deux. Si le tampon spécifié est NULL (zéro), alors un tampon de taille appropriée est alloué dynamiquement. TIFFWriteBufferSetup() renvoie une valeur non nulle si la configuration a réussi et zéro sinon.

DIAGNOSTICS

%s : Pas d'espace pour le tampon de données à la ligne d'analyse %ld :

TIFFReadBufferSetup() n'a pas pu allouer dynamiquement d'espace pour un tampon de données.

%s : Pas d'espace pour le tampon de sortie :

TIFFWriteBufferSetup() n'a pas pu allouer dynamiquement d'espace pour un tampon de données.
