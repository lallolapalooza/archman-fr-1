NOM

Time::Zone -- routines diverses de manipulation de fuseaux horaires

SYNOPSIS

use Time::Zone;
print tz2zone();
print tz2zone($ENV{'TZ'});
print tz2zone($ENV{'TZ'}, time());
print tz2zone($ENV{'TZ'}, undef, $isdst);
$offset = tz_local_offset();
$offset = tz_offset($TZ);

DESCRIPTION

Ceci est une collection de routines diverses de manipulation de fuseaux horaires.

tz2zone() analyse la variable d'environnement TZ et retourne une chaîne de fuseau horaire appropriée pour l'inclusion dans une sortie de type date(1). Elle prend éventuellement une chaîne de fuseau horaire, une heure et un indicateur d'heure d'été.

tz_local_offset() détermine le décalage par rapport à l'heure GMT en secondes. Le calcul n'est effectué qu'une seule fois.

tz_offset() détermine le décalage par rapport à l'heure GMT en secondes d'un fuseau horaire spécifié.

tz_name() détermine le nom du fuseau horaire en fonction de son décalage.
