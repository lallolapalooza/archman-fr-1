TIFFSTRIP(3tiff) LibTIFF TIFFSTRIP(3tiff)

NOM

TIFFstrip - routines utilitaires liées aux bandes

SYNTAXE

#include <tiffio.h>
uint32_t TIFFDefaultStripSize(TIFF *tif, uint32_t estimate)
tmsize_t TIFFStripSize(TIFF *tif)
uint64_t TIFFStripSize64(TIFF *tif)
tmsize_t TIFFVStripSize(TIFF *tif, uint32_t nrows)
uint64_t TIFFVStripSize64(TIFF *tif, uint32_t nrows)
tmsize_t TIFFRawStripSize(TIFF *tif, uint32_t strip)
uint64_t TIFFRawStripSize64(TIFF *tif, uint32_t strip)
tstrip_t TIFFComputeStrip(TIFF *tif, uint32_t row, tsample_t sample)
tstrip_t TIFFNumberOfStrips(TIFF *tif)
int TIFFSetupStrips(TIFF *tif)

DESCRIPTION

TIFFDefaultStripSize() renvoie le nombre de lignes pour une bande de taille raisonnable selon les paramètres actuels des balises ImageWidth, BitsPerSample et SamplesPerPixel, ainsi que les exigences spécifiques à la compression. Si le paramètre estimate, s'il est non nul, est alors pris comme une estimation de la taille de bande souhaitée et ajusté selon les exigences spécifiques à la compression. La valeur renvoyée par cette fonction est généralement utilisée pour définir la balise RowsPerStrip. En l'absence d'exigences inhabituelles, TIFFDefaultStripSize essaie de créer des bandes d'environ 8 kilo-octets de données non compressées.

TIFFStripSize() renvoie la taille équivalente d'une bande de données telle qu'elle serait renvoyée lors d'un appel à TIFFReadEncodedStrip() ou telle qu'elle serait attendue dans un appel à TIFFWriteEncodedStrip(). En cas d'erreur, 0 est renvoyé.

TIFFStripSize64() renvoie la taille équivalente d'une bande de données sous forme de uint64_t. En cas d'erreur, 0 est renvoyé.

TIFFVStripSize() renvoie le nombre d'octets dans une bande avec nrows lignes de données. En cas d'erreur, 0 est renvoyé.

TIFFVStripSize64() renvoie le nombre d'octets dans une bande avec nrows lignes de données sous forme de uint64_t. En cas d'erreur, 0 est renvoyé.

TIFFRawStripSize() renvoie le nombre d'octets dans une bande brute (c'est-à-dire non décodée). En cas d'erreur, 0xFFFFFFFF (=(tmsize_t(-1)) est renvoyé.

TIFFRawStripSize64() renvoie le nombre d'octets dans une bande brute sous forme de uint64_t. En cas d'erreur, 0xFFFFFFFF (=(uint64_t(-1)) est renvoyé.

TIFFComputeStrip() renvoie la bande qui contient les coordonnées spécifiées. Une bande valide est toujours renvoyée; les valeurs de coordonnées hors limites sont ramenées aux limites de l'image. Le paramètre row est toujours utilisé dans le calcul d'une bande. Le paramètre sample n'est utilisé que si les données sont organisées en plans séparés (PlanarConfiguration = 2).

TIFFNumberOfStrips() renvoie le nombre de bandes dans l'image.

TIFFSetupStrips() configure ou réinitialise les paramètres des bandes et la mémoire du tableau des bandes.
