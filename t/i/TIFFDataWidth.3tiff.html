NOM

TIFFDataWidth - obtenir la taille des types de données TIFF

SYNTAXE

#include <tiffio.h>
int TIFFDataWidth(TIFFDataType type)

DESCRIPTION

TIFFDataWidth() renvoie la taille de type dans le fichier TIFF en octets. Actuellement, les types de données suivants sont pris en charge :

  • TIFF_BYTE
  • TIFF_ASCII
  • TIFF_SBYTE
  • TIFF_UNDEFINED
  • TIFF_SHORT
  • TIFF_SSHORT
  • TIFF_LONG
  • TIFF_SLONG
  • TIFF_FLOAT
  • TIFF_IFD
  • TIFF_RATIONAL
  • TIFF_SRATIONAL
  • TIFF_DOUBLE
  • TIFF_LONG8
  • TIFF_SLONG8
  • TIFF_IFD8

VALEUR DE RETOUR

TIFFDataWidth() renvoie le nombre d'octets occupés par l'élément du type donné dans le fichier TIFF. 0 est renvoyé lorsqu'un type de données inconnu est fourni.
