NAME

TIFFSetField - définir la ou les valeurs d'une balise dans un fichier TIFF ouvert en écriture

SYNOPSIS

#include <tiffio.h>
#include <stdarg.h>"
int TIFFSetField(TIFF *tif, ttag_t tag, ...)
int TIFFVSetField(TIFF *tif, ttag_t tag, va_list ap)
int TIFFUnsetField(TIFF *tif, uint32_t tag)

DESCRIPTION

TIFFSetField() définit la valeur d'un champ ou d'une pseudo-balise dans le répertoire courant associé au fichier TIFF ouvert tif. (Une pseudo-balise est un paramètre utilisé pour contrôler le fonctionnement de la bibliothèque TIFF mais dont la valeur n'est ni lue ni écrite dans le fichier sous-jacent.) Pour définir la valeur d'un champ, le fichier doit avoir été préalablement ouvert en écriture avec TIFFOpen(). Les pseudo-balises peuvent être définies que le fichier ait été ouvert en lecture ou en écriture. Le champ est identifié par tag, une des valeurs définies dans le fichier d'inclusion tiff.h (voir aussi le tableau ci-dessous). La valeur réelle est spécifiée à l'aide d'une liste d'arguments variables, conformément à l'interface stdarg.h.

TIFFVSetField() est fonctionnellement équivalent à TIFFSetField(), à la seule différence qu'il prend un pointeur vers une liste d'arguments variables. TIFFVSetField() est utile pour écrire des routines qui s'appuient sur la fonctionnalité fournie par TIFFSetField().

TIFFUnsetField() efface le contenu du champ dans la structure interne. S'il s'agit d'un champ personnalisé, il est supprimé de la liste des balises connues.

Les balises comprises par libtiff, le nombre de valeurs de paramètres et les types attendus pour les valeurs de paramètres sont indiqués ci-dessous. Les types de données sont :

TAG TYPES DE DONNÉES

Type Description
char* une chaîne de caractères terminée par un nul correspondant au type de données ASCII
uint16_t une valeur non signée de 16 bits
uint32_t une valeur non signée de 32 bits ;
uint16_t* un tableau de valeurs non signées de 16 bits.
void* un tableau de valeurs de données de type non spécifié.

Consultez la spécification TIFF pour des informations sur la signification de chaque balise.

† Les champs marqués d'un astérisque sont des champs obligatoires pour les fichiers conformes.

Notez que pour des valeurs de paramètres multiples, la bibliothèque libtiff s'attend à ce que vous fournissiez un pointeur vers le premier élément du tableau. Par exemple, pour définir la balise TIFFTAG_COLORMAP, vous devez passer un pointeur vers le premier des trois tableaux uint16_t.

Pour définir des valeurs pour des balises non prises en charge, libtiff autorise la définition de balises personnalisées. Pour ce faire, il suffit de faire précéder la balise numérique par TIFF_SET_CUSTOM_TAG. Par exemple, pour définir une balise personnalisée 40000, le code devrait ressembler à ceci:

result = TIFFSetField(tif, TIFF_SET_CUSTOM_TAG(40000), value);

Les appels qui réussissent renvoient 1 et ceux qui échouent renvoient 0.

VALEURS DE RETOUR

1 est retourné si l'opération a réussi. Sinon, 0 est retourné si une erreur a été détectée.

DIAGNOSTICS

Tous les messages d'erreur sont dirigés vers la routine TIFFErrorExtR().

%s: Impossible de modifier le tag "%s" en écrivant:

Des données ont déjà été écrites dans le fichier, la valeur du tag spécifié ne peut donc pas être modifiée. Cette restriction s'applique à tous les tags qui affectent le format des données écrites.

%d: Valeur incorrecte pour "%s":

Une valeur invalide a été fournie pour le tag nommé.
