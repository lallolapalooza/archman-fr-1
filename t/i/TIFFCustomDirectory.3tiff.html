TIFFCUSTOMDIRECTORY(3tiff) LibTIFF TIFFCUSTOMDIRECTORY(3tiff)

NOM

TIFFCustomDirectory - routines pour créer un répertoire personnalisé

SYNOPIS

#include <tiffio.h>
int TIFFCreateCustomDirectory(TIFF *tif, const TIFFFieldArray *infoarray)
int TIFFCreateEXIFDirectory(TIFF *tif)
int TIFFCreateGPSDirectory(TIFF *tif)
int TIFFWriteCustomDirectory(TIFF *tif, uint64 *pdiroff)
int TIFFReadCustomDirectory(TIFF *tif, toff_t diroff, const TIFFFieldArray *infoarray)
int TIFFReadEXIFDirectory(TIFF *tif, toff_t diroff)
int TIFFReadGPSDirectory(TIFF *tif, toff_t diroff)
const TIFFFieldArray *_TIFFGetExifFields(void)
const TIFFFieldArray *_TIFFGetGpsFields(void)

DESCRIPTION

Les routines suivantes créent un répertoire personnalisé et récupèrent des informations sur les répertoires dans un fichier TIFF ouvert.

TIFFCreateCustomDirectory(), TIFFCreateEXIFDirectory(), TIFFCreateGPSDirectory() configureront un répertoire personnalisé ou l'un des répertoires prédéfinis EXIF ou GPS et définiront le contexte du descripteur TIFF tif à ce répertoire personnalisé pour des fonctions comme TIFFSetField().

TIFFWriteCustomDirectory() écrira le contenu du répertoire personnalisé actuel dans le fichier et retournera le décalage vers ce répertoire dans pdiroff. Ce décalage doit être écrit dans l'IFD principal :

 /* Revenir au premier répertoire et ajouter le pointeur EXIFIFD. */
TIFFSetDirectory(tif, 0);
TIFFSetField(tif, TIFFTAG_EXIFIFD, pdiroff);

TIFFReadCustomDirectory() lira le répertoire personnalisé à partir du décalage arbitraire dans le infoarray et définira le contexte du descripteur TIFF tif à ce répertoire personnalisé pour des fonctions comme TIFFReadField(). Le TIFFFieldArray infoarray doit être conforme à la structure du répertoire personnalisé. Pour les répertoires prédéfinis EXIF et GPS, les définitions pertinentes du TIFFFieldArray sont cachées dans les fonctions TIFFReadEXIFDirectory() et TIFFReadGPSDirectory(). Le code est très similaire à TIFFReadDirectory(). Le décalage vers le répertoire personnalisé diroff doit d'abord être lu à partir du tag TIFF relatif.

_TIFFGetExifFields() et _TIFFGetGpsFields() renverront un pointeur vers la liste de définition interne de libtiff des tags EXIF et GPS, respectivement.

NOTES

Soyez conscient

  • que tant qu'un répertoire n'a pas été écrit dans le fichier ET relu, les fonctions de requête ne récupéreront pas les bonnes informations !
  • que le nouveau répertoire créé n'existera pas dans le fichier tant que TIFFWriteDirectory(), TIFFCheckpointDirectory(), TIFFFlush() ou TIFFClose() n'auront pas été appelés.
  • que TIFFCreateDirectory() et TIFFWriteDirectory() créent un nouveau répertoire, libèrent la structure *tif et en configurent une nouvelle.
  • que contrairement à TIFFWriteDirectory(), TIFFCheckpointDirectory() ne libère pas les structures de données du répertoire en mémoire.
  • que LibTiff ne prend pas en charge les chaînes de répertoires personnalisées (NextIFD pointant vers un autre IFD). NextIFD des répertoires personnalisés est toujours mis à zéro et doit être zéro lors de la lecture.

Malheureusement, pour créer ou lire des répertoires personnalisés avec des champs prédéfinis, il est nécessaire d'inclure le fichier privé tif_dir.h. Cependant, pour les répertoires EXIF et GPS, qui ont un schéma prédéfini dans libtiff, cela n'est pas nécessaire. Il existe quelques programmes de test qui démontrent brièvement la création et la lecture des répertoires EXIF, GPS et personnalisés. Voir test/custom_dir.c et test/custom_dir_EXIF_231.c

ASTUCES ET INSTRUCTIONS DÉTAILLÉES

L'écriture de fichiers TIFF avec plus d'un répertoire (IFD) n'est pas facile car certains effets secondaires doivent être connus.

Le point principal ici est qu'il ne peut y avoir qu'une seule structure tif en mémoire principale pour un fichier, qui ne peut contenir les tags que d'un seul répertoire à la fois. Il est inutile de travailler avec deux pointeurs différents tiffOut1, tiffOut2, car il n'y a qu'UN SEUL objet TIFF (répertoire TIFF) dans libtiff. Si vous voulez adresser un second répertoire dans le fichier, les tags du répertoire courant doivent d'abord être sauvegardés dans le fichier, sinon ils seront perdus (écrasés ou mélangés). Ensuite, la structure tif en mémoire principale doit être nettoyée, sinon les anciens tags seront inclus dans le nouveau répertoire. Cela peut être fait soit en créant une nouvelle structure tif vide, soit en lisant un répertoire précédemment sauvegardé dans le fichier.

Une séquence pour gérer un second (ou troisième) répertoire TIFF - dans ce cas, l'IFD GPS - est la suivante :

1.
Créer le fichier TIFF
2.
Compléter les métadonnées "normales"
3.
Définir le tag pour le répertoire personnalisé avec une valeur "factice" afin de réserver le tag. La valeur finale sera insérée plus tard. Cela empêche le répertoire principal d'être réécrit dans le fichier à un endroit supplémentaire, laissant la première zone mémoire inutilisée :
TIFFSetField(tiffOut, TIFFTAG_GPSIFD, dir_offset);
4.
Sauvegarder le répertoire TIFF courant dans le fichier. Sinon, il sera perdu. Mémoriser également le numéro du répertoire courant :
TIFFWriteDirectory(tiffOut);
dirNum = TIFFCurrentDirectory(tiffOut);
5.
Créer le second répertoire TIFF (par exemple, répertoire personnalisé) et définir ses champs. Le tableau TIFFFieldArray infoarray doit être spécifié au préalable quelque part dans vos fichiers d'inclusion privés. Un exemple est donné pour le répertoire EXIF dans tif_dirinfo.c
TIFFCreateCustomDirectory(tiffOut, infoarray);        /* pour un vrai répertoire personnalisé */
/* ou alternativement, utiliser GPS ou EXIF avec une structure de champ IFD TIFFFieldArray prédéfinie */
TIFFCreateGPSDirectory(tiffOut);
TIFFSetField(tiffOut, GPSTAG_VERSIONID, gpsVersion);  /* définir les champs du répertoire personnalisé */

Soyez conscient que chaque appel à TIFFCreateDirectory() ou TIFFWriteDirectory() libère apparemment la structure *tif et en configure une nouvelle !

6.
Écrire le répertoire personnalisé dans le fichier. Le décalage vers ce répertoire dans le fichier est retourné dans dir_offset.
TIFFWriteCustomDirectory(tiffOut, &dir_offset);
7.
Recharger le premier répertoire (c'est-à-dire le répertoire TIFF d'origine). Apparemment, cela lit les données depuis le fichier.
TIFFSetDirectory(tiffOut, dirNum);
8.
Définir la valeur correcte du décalage du tag IFD du répertoire personnalisé et sauvegarder ces modifications dans le fichier.
TIFFSetField(tiffOut, TIFFTAG_GPSIFD, dir_offset);
TIFFWriteDirectory(tiffOut);

VALEURS DE RETOUR

Les routines retournent 1 en cas de succès et 0 en cas d'erreur.

VOIR AUSSI

libtiff(7), TIFFReadDirectory(3tiff), TIFFSetDirectory(3tiff), TIFFSetField(3tiff), TIFFReadField(3tiff)

LIBRAIRIE C

DIAGNOSTICS

Tous les messages d'erreur sont dirigés vers la routine TIFFErrorExtR(). De même, les messages d'avertissement sont dirigés vers la routine TIFFWarningExtR().
