NOM

TIFFClose - fermer un fichier TIFF préalablement ouvert

SYNTAXE

#include <tiffio.h>
void TIFFClose(TIFF *tif)
void TIFFCleanup(TIFF *tif)

DESCRIPTION

TIFFClose() ferme un fichier qui a été préalablement ouvert avec TIFFOpen(). Toute donnée en mémoire tampon est écrite dans le fichier, y compris le contenu du répertoire courant (s'il a été modifié); et toutes les ressources sont libérées. TIFFClose() appelle TIFFCleanup() puis la fonction associée pour fermer le descripteur de fichier.

TIFFCleanup() est une fonction auxiliaire pour libérer la structure TIFF. La structure donnée sera complètement libérée, vous devriez donc sauvegarder le descripteur de fichier ouvert et le pointeur vers la procédure de fermeture dans des variables externes avant d'appeler TIFFCleanup(), si vous avez besoin de ces derniers pour fermer le fichier.

DIAGNOSTICS

Tous les messages d'erreur sont dirigés vers la routine TIFFErrorExtR(). De même, les messages d'avertissement sont dirigés vers la routine TIFFWarningExtR().

VOIR AUSSI

libtiff (3tiff), TIFFOpen (3tiff), TIFFError (3tiff)
