NOM

Time::tm - objet interne utilisé par Time::gmtime et Time::localtime

SYNTAXE

N'utilisez pas ce module directement.

DESCRIPTION

Ce module est utilisé en interne comme classe de base pour les fonctions Time::localtime et Time::gmtime. Il crée un objet structuré Time::tm auquel on peut accéder de la même manière que la structure tm de C dans time.h ; à savoir avec sec, min, hour, mday, mon, year, wday, yday et isdst.

Cette classe est une interface interne uniquement.
