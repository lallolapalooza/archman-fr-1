TIFFPRINTDIRECTORY(3tiff) LibTIFF TIFFPRINTDIRECTORY(3tiff)

NOM

TIFFPrintDirectory - imprimer une description d'un répertoire TIFF

SYNTAXE

#include <tiffio.h>
void TIFFPrintDirectory(TIFF *tif, FILE *fd, long flags)

DESCRIPTION

TIFFPrintDirectory() imprime une description du répertoire courant dans le fichier TIFF spécifié vers le flux de sortie standard fd. Le paramètre flags est utilisé pour contrôler le “niveau de détail” des informations imprimées ; il s'agit d'un OU binaire des drapeaux définis dans tiffio.h :

Nom Valeur Description
TIFFPRINT_NONE 0x0 aucune information supplémentaire
TIFFPRINT_STRIPS 0x1 informations sur les bandes/tuiles
TIFFPRINT_CURVES 0x2 courbes de réponse couleur/gris
TIFFPRINT_COLORMAP 0x4 table de couleurs
TIFFPRINT_JPEGQTABLES 0x100 matrices Q JPEG
TIFFPRINT_JPEGACTABLES 0x200 tables AC JPEG
TIFFPRINT_JPEGDCTABLES 0x200 tables DC JPEG

NOTES

En C++, le paramètre flags vaut 0 par défaut.

VALEURS DE RETOUR

Aucune.

DIAGNOSTICS

Aucun.
