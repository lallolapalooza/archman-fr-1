TIFFREADFROMUSERBUFFER(3tiff) LibTIFF TIFFREADFROMUSERBUFFER(3tiff)

NOM

TIFFReadFromUserBuffer - décode les données en utilisant un tampon défini par l'utilisateur

SYNTAXE

#include <tiffio.h>
int TIFFReadFromUserBuffer(TIFF *tif, uint32_t strile, void *inbuf, tmsize_t insize, void *outbuf, tmsize_t outsize)

DESCRIPTION

Utilise le tampon d'entrée fourni (inbuf, insize) et le décompresse dans (outbuf, outsize). Cette fonction remplace l'utilisation de TIFFReadEncodedStrip() / TIFFReadEncodedTile() lorsque l'utilisateur peut fournir le tampon pour les données d'entrée, par exemple s'il souhaite éviter que libtiff ne lise les valeurs d'offset/nombre de bandes à partir des tableaux StripOffsets / StripByteCounts ou TileOffsets / TileByteCounts. Le contenu de inbuf doit être inscriptible (si une inversion de bits est nécessaire).

VALEURS DE RETOUR

Retourne 1 en cas de succès, 0 sinon.

DIAGNOSTICS

Tous les messages d'erreur sont dirigés vers la routine TIFFErrorExtR().

VOIR AUSSI

TIFFOpen (3tiff), TIFFReadRawStrip (3tiff), TIFFReadScanline (3tiff), TIFFReadEncodedStrip (3tiff), TIFFReadEncodedTile (3tiff), libtiff (3tiff),
