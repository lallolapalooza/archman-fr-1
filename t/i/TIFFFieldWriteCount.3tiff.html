NOM

TIFFFieldWriteCount - obtenir le nombre de valeurs à écrire pour un champ

SYNTAXE

#include <tiffio.h>
int TIFFFieldWriteCount(const TIFFField *fip)

DESCRIPTION

TIFFFieldWriteCount() renvoie le nombre de valeurs à écrire dans le champ TIFF spécifié ; c'est-à-dire le nombre d'arguments qui doivent être fournis à TIFFSetField(). Pour la plupart des types de champs, il s'agit d'un petit entier positif, généralement 1 ou 2, mais il existe des valeurs spéciales :

  • TIFF_VARIABLE indique qu'un nombre variable de valeurs est possible ; dans ce cas, un argument de type uint16_t count et un argument pointeur data doivent être fournis à TIFFSetField().
  • TIFF_VARIABLE2 est identique à TIFF_VARIABLE à la différence près que l'argument count doit être de type uint32_t. (Sur la plupart des machines modernes, cela ne fait aucune différence pratique, et l'argument count peut simplement être un int dans les deux cas.)
  • TIFF_SPP indique que le nombre d'arguments doit être égal au nombre d'échantillons par pixel de l'image.

fip est un pointeur d'informations de champ renvoyé précédemment par TIFFFindField(), TIFFFieldWithTag(), ou TIFFFieldWithName().

Pour la plupart des types de champs, TIFFFieldWriteCount() renvoie la même valeur que TIFFFieldReadCount(), mais il existe des exceptions.

VALEURS RENVOYÉES

TIFFFieldWriteCount() renvoie un entier.
