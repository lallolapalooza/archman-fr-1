NOM

TIFFWriteRawStrip - écrit une bande de données brutes dans un fichier TIFF ouvert

SYNTAXE

#include <tiffio.h>
tsize_t TIFFWriteRawStrip(TIFF *tif, tstrip_t strip, tdata_t buf, tsize_t size)

DESCRIPTION

Ajoute size octets de données brutes à la bande spécifiée.

NOTES

Le numéro de bande doit être valide selon les réglages courants des balises ImageLength et RowsPerStrip. Une image peut être agrandie dynamiquement en augmentant la valeur de ImageLength avant chaque appel à TIFFWriteRawStrip().

VALEURS DE RETOUR

-1 est retourné si une erreur s'est produite. Sinon, la valeur de size est retournée.

DIAGNOSTICS

Tous les messages d'erreur sont dirigés vers la routine TIFFErrorExtR().

%s : Fichier non ouvert en écriture :

Le fichier a été ouvert en lecture, pas en écriture.

Impossible d'écrire des lignes de balayage dans une image tuilée :

L'image est supposée être organisée en tuiles car les balises TileWidth et TileLength ont été définies avec TIFFSetField().

%s : Il faut définir "ImageWidth" avant d'écrire des données :

La largeur de l'image n'a pas été définie avant la première écriture. Voir TIFFSetField() pour des informations sur la façon de faire.

%s : Il faut définir "PlanarConfiguration" avant d'écrire des données :

L'organisation des données n'a pas été définie avant la première écriture. Voir TIFFSetField() pour des informations sur la façon de faire.

%s : Pas d'espace pour les tableaux de bandes" :

Il n'y avait pas assez d'espace pour les tableaux qui contiennent les décalages et les décomptes d'octets des bandes.

%s : Bande %d hors limites, max %d :

La bande spécifiée n'est pas une bande valide selon les dimensions d'image actuellement spécifiées.
