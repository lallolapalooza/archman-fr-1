TIFFREADENCODEDTILE(3tiff) LibTIFF TIFFREADENCODEDTILE(3tiff)

NOM

TIFFReadEncodedTile - lire et décoder une dalle de données à partir d'un fichier TIFF ouvert

SYNTAXE

#include <tiffio.h>
int TIFFReadEncodedTile(TIFF *tif, ttile_t tile, tdata_t buf, tsize_t size)

DESCRIPTION

Lit la dalle de données spécifiée et place jusqu'à size octets d'informations décompressées dans le tampon de données (fourni par l'utilisateur).

NOTES

La valeur de tile est un « numéro de dalle brut ». C'est-à-dire que l'appelant doit tenir compte si les données sont organisées en plans séparés (PlanarConfiguration = 2) ou non. TIFFComputeTile() s'en occupe automatiquement lors de la conversion d'un quadruplet de coordonnées (x,y,z,sample) en numéro de dalle. Pour lire une dalle de données complète, le tampon de données doit être au moins aussi grand que la valeur retournée par TIFFTileSize().

La bibliothèque tente de masquer les différences d'ordre de bits et d'octets entre l'image et la machine native en convertissant les données dans l'ordre de la machine native. L'inversion des bits est effectuée si le tag FillOrder est opposé à l'ordre des bits de la machine native. Les échantillons de 16 et 32 bits sont automatiquement échangés d'octets si le fichier a été écrit avec un ordre d'octets opposé à l'ordre d'octets de la machine native.

VALEURS DE RETOUR

Le nombre réel d'octets de données qui ont été placés dans buf est retourné ; TIFFReadEncodedTile() retourne -1 si une erreur a été rencontrée.

DIAGNOSTICS

Tous les messages d'erreur sont dirigés vers la routine TIFFErrorExtR().
