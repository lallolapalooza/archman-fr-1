NOM

TIFFtile - routines utilitaires liées aux tuiles

SYNTAXE

#include <tiffio.h>
void TIFFDefaultTileSize(TIFF *tif, uint32_t *tw, uint32_t *th)
tsize_t TIFFTileSize(TIFF *tif)
uint64_t TIFFTileSize64(TIFF *tif)
tsize_t TIFFTileRowSize(TIFF *tif)
uint64_t TIFFTileRowSize64(TIFF *tif)
tsize_t TIFFVTileSize(TIFF *tif, uint32_t nrows)
uint64_t TIFFVTileSize64(TIFF *tif, uint32_t nrows)
ttile_t TIFFComputeTile(TIFF *tif, uint32_t x, uint32_t y, uint32_t z, tsample_t sample)
int TIFFCheckTile(TIFF *tif, uint32_t x, uint32_t y, uint32_t z, tsample_t sample)
ttile_t TIFFNumberOfTiles(TIFF *tif)

DESCRIPTION

TIFFDefaultTileSize() renvoie la largeur et la hauteur en pixels d'une tuile de taille raisonnable; appropriée pour définir les balises TileWidth et TileLength. Si les valeurs tw et th passées sont non nulles, elles sont ajustées pour refléter les exigences spécifiques à la compression. La largeur et la hauteur renvoyées sont contraintes pour être un multiple de 16 pixels afin de se conformer à la spécification TIFF.

TIFFTileSize() renvoie la taille équivalente pour une tuile de données telle qu'elle serait retournée dans un appel à TIFFReadTile() ou telle qu'elle serait attendue dans un appel à TIFFWriteTile(). TIFFTileSize64() renvoie un nombre uint64_t. En cas d'erreur, 0 est renvoyé.

TIFFVTileSize() renvoie le nombre d'octets dans une tuile alignée sur une ligne avec nrows de données. TIFFVTileSize64() renvoie un nombre uint64_t. En cas d'erreur, 0 est renvoyé.

TIFFTileRowSize() renvoie le nombre d'octets d'une ligne de données dans une tuile. TIFFTileRowSize64() renvoie un nombre uint64_t. En cas d'erreur, 0 est renvoyé.

TIFFComputeTile() renvoie la tuile qui contient les coordonnées spécifiées. Une tuile valide est toujours renvoyée; les valeurs de coordonnées hors limites sont limitées aux limites de l'image. Les paramètres x et y sont toujours utilisés pour calculer une tuile. Le paramètre z est utilisé si l'image est plus profonde qu'une seule tranche (ImageDepth > 1). Le paramètre sample est utilisé uniquement si les données sont organisées en plans séparés (PlanarConfiguration = 2).

TIFFCheckTile() renvoie une valeur non nulle si les coordonnées fournies sont dans les limites de l'image et zéro sinon. Le paramètre x est vérifié par rapport à la valeur de la balise ImageWidth. Le paramètre y est vérifié par rapport à la valeur de la balise ImageLength. Le paramètre z est vérifié par rapport à la valeur de la balise ImageDepth (si définie). Le paramètre sample est vérifié par rapport à la valeur du paramètre SamplesPerPixel si les données sont organisées en plans séparés.

TIFFNumberOfTiles() renvoie le nombre de tuiles dans l'image.
