NOM

TIFFDeferStrileArrayWriting - reporter l'écriture des tableaux de bandes

SYNTAXE

#include <tiffio.h>
int TIFFDeferStrileArrayWriting(TIFF *tif)
int TIFFForceStrileArrayWriting(TIFF *tif)

DESCRIPTION

TIFFDeferStrileArrayWriting() est une fonction d'écriture avancée qui doit être utilisée dans une séquence particulière, et généralement avec TIFFForceStrileArrayWriting(), pour obtenir son effet voulu. Leur objectif est de contrôler quand et où les tableaux StripOffsets / StripByteCounts ou TileOffsets / TileByteCounts sont écrits dans le fichier.

Le but est de générer des fichiers ‘cloud-optimized geotiff’ où le premier KB du fichier ne contient que les entrées IFD sans les tableaux de bandes potentiellement volumineux. Ceux-ci sont écrits après.

Plus précisément, lorsque TIFFWriteCheck() est appelé, les entrées de balises pour ces tableaux seront écrites avec type = count = offset = 0 comme valeur temporaire.

Son effet n'est valide que pour le répertoire courant, et avant que TIFFWriteDirectory() ne soit appelé pour la première fois, et sera réinitialisé lors du changement de répertoire.

La séquence typique d'appels est :

TIFFOpen()
/* ou TIFFCreateDirectory(tif) */
/* Définir les champs avec des appels à TIFFSetField(tif, ...) */
TIFFDeferStrileArrayWriting(tif)
TIFFWriteCheck(tif, ...)
TIFFWriteDirectory(tif)
/* ... potentiellement créer d'autres répertoires et revenir au répertoire ci-dessus */
TIFFForceStrileArrayWriting(tif) /* émettre les tableaux à la fin du fichier */

RETOUR

1 en cas de succès, 0 sinon.

DIAGNOSTICS

Tous les messages d'erreur sont dirigés vers la routine TIFFErrorExtR(). De même, les messages d'avertissement sont dirigés vers la routine TIFFWarningExtR().
