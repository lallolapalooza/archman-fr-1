NOM

Tie::Handle - définitions de classes de base pour les descripteurs liés

SYNOPIS

package NouveauHandle;
require Tie::Handle;
@ISA = qw(Tie::Handle);
sub READ { ... }            # Fournir une méthode nécessaire
sub TIEHANDLE { ... }       # Remplacer la méthode héritée
package main;
tie *FH, 'NouveauHandle';

DESCRIPTION

Ce module fournit des méthodes squelettiques pour les classes de liaison de descripteurs. Voir perltie pour une liste des fonctions requises pour lier un descripteur à un paquet. Le paquet de base Tie::Handle fournit une méthode "new", ainsi que les méthodes "TIEHANDLE", "PRINT", "PRINTF" et "GETC".

Pour les développeurs souhaitant écrire leurs propres classes de descripteurs liés, les méthodes sont résumées ci-dessous. La section perltie documente non seulement celles-ci, mais contient également des exemples de code :

TIEHANDLE nom_classe, LISTE
La méthode invoquée par la commande "tie *glob, nom_classe". Associe une nouvelle instance de glob à la classe spécifiée. "LISTE" représenterait des arguments supplémentaires (dans le style de AnyDBM_File et ses compatriotes) nécessaires pour finaliser l'association.
WRITE ceci, scalaire, longueur, décalage
Écrit longueur octets de données depuis scalaire en commençant à décalage.
PRINT ceci, LISTE
Imprime les valeurs de la LISTE
PRINTF ceci, format, LISTE
Imprime les valeurs de la LISTE en utilisant le format
READ ceci, scalaire, longueur, décalage
Lit longueur octets de données dans scalaire en commençant à décalage.
READLINE ceci
Lit une seule ligne
GETC ceci
Obtient un seul caractère
CLOSE ceci
Ferme le descripteur
OPEN ceci, nom_fichier
Ouvre (rouvre) le descripteur
BINMODE ceci
Spécifie que le contenu est binaire
EOF ceci
Teste la fin de fichier.
TELL ceci
Retourne la position dans le fichier.
SEEK ceci, décalage, origine
Positionne le fichier.

Teste la fin de fichier.

DESTROY ceci
Libère l'espace mémoire associé au descripteur lié référencé par ceci. Ceci est rarement nécessaire, car Perl gère très bien sa mémoire. Mais l'option existe, si une classe souhaite effectuer des actions spécifiques lors de la destruction d'une instance.

COMPATIBILITÉ

Cette version de Tie::Handle n'est ni liée ni compatible avec le module Tie::Handle (3.0) disponible sur CPAN. C'est par accident que deux modules portant le même nom sont apparus. Le conflit de noms a été résolu en faveur de ce module qui fait partie du cœur de Perl depuis septembre 2000 et en conséquence le numéro de version a été augmenté à 4.0.
