NOM

TIFFClientInfo - fournit une méthode pour transmettre des données définies par l'utilisateur d'une routine à une autre

SYNOPSIS

#include <tiffio.h>
void *TIFFGetClientInfo(TIFF *tif, const char *name)
void TIFFSetClientInfo(TIFF *tif, void *data, const char *name)

DESCRIPTION

La liste chaînée clientinfo fournit une méthode pour transmettre des données définies par l'utilisateur d'une routine à une autre via le stockage interne tif de la bibliothèque libtiff.

TIFFGetClientInfo() retourne un pointeur vers les données de l'entrée nommée dans la liste clientinfo. Si le nom n'est pas trouvé, NULL est retourné.

TIFFSetClientInfo() ajoute ou remplace une entrée dans la liste clientinfo avec le nom et le pointeur vers les données fournis par l'appelant.
