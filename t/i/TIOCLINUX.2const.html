TIOCLINUX(2const) TIOCLINUX(2const)

NOM

TIOCLINUX - ioctls pour le terminal et les consoles virtuelles

SYNTAXE

#include <linux/tiocl.h>  /* Définitions des constantes TIOCL_* */
#include <sys/ioctl.h>
int ioctl(int fd, TIOCLINUX, void *argp);

DESCRIPTION

Les ioctls suivants dépendent du premier octet dans la structure pointée par argp, appelée ici sous-code. Ceux-ci ne sont valides que pour le superutilisateur ou le propriétaire du terminal actuel.

sous-code=0
Afficher l'écran. Obsolète depuis Linux 1.1.92. (Avec Linux 1.1.92 ou plus récent, il est lu depuis /dev/vcs ou /dev/vcsa).
sous-code=1
Obtenir des informations sur la tâche. Obsolète depuis Linux 1.1.92.
sous-code=TIOCL_SETSEL
Définir la sélection. argp pointe vers une

structure {
    char  sous_code;
    short xs, ys, xe, ye;
    short sel_mode;
};

xs et ys sont les colonnes et lignes de départ. xe et ye sont les colonnes et lignes de fin. (Le coin supérieur gauche est ligne=colonne=1.) sel_mode peut être l'une des opérations suivantes :
TIOCL_SELCHAR
Sélection caractère par caractère. Les caractéristiques d'écran indiquées sont mises en surbrillance et stockées dans un tampon du noyau.
Depuis Linux 6.7, l'utilisation de ce mode de sélection nécessite la capacité CAP_SYS_ADMIN.
TIOCL_SELWORD
Sélection mot par mot, étendant la sélection pour s'aligner sur les lignes de mots. Les caractéristiques d'écran indiquées sont mises en surbrillance et stockées dans un tampon du noyau.
Depuis Linux 6.7, l'utilisation de ce mode de sélection nécessite la capacité CAP_SYS_ADMIN.
TIOCL_SELLINE
Sélection ligne par ligne, étendant la sélection pour sélectionner des lignes entières. Les caractéristiques d'écran indiquées sont mises en surbrillance et stockées dans un tampon du noyau.
Depuis Linux 6.7, l'utilisation de ce mode de sélection nécessite la capacité CAP_SYS_ADMIN.
TIOCL_SELPOINTER
Afficher le pointeur à la position (xs,ys) ou (xe,ye), selon la position de texte la plus avancée.
TIOCL_SELCLEAR
Supprimer la mise en surbrillance actuelle de la console qui contient la sélection.
Ceci n'affecte pas le texte précédemment sélectionné.
TIOCL_SELMOUSEREPORT
Le terminal signale (xs,ys) comme position de la souris en utilisant le protocole de souris xterm(1) (voir console_codes(4)). Les 4 derniers bits de sel_mode (TIOCL_SELBUTTONMASK) indiquent la pression des boutons et les touches de contrôle pour l'événement de souris.
Si la souris n'est pas rapportée par le terminal, cette opération renvoie une erreur EINVAL.
Depuis Linux 6.7, l'utilisation de ce mode de sélection nécessite la capacité CAP_SYS_ADMIN.
sous-code=TIOCL_PASTESEL
Insérer la sélection. Les caractères du tampon de sélection sont écrits dans fd.
Depuis Linux 6.7, l'utilisation de ce sous-code nécessite la capacité CAP_SYS_ADMIN.
sous-code=TIOCL_UNBLANKSCREEN
Déverrouiller l'écran.
sous-code=TIOCL_SELLOADLUT
Définit le contenu d'une table de recherche de 256 octets qui spécifie les caractères dans un "mot", pour la sélection mot par mot. (Depuis Linux 1.1.32.)
Depuis Linux 6.7, l'utilisation de ce sous-code nécessite la capacité CAP_SYS_ADMIN.
sous-code=TIOCL_GETSHIFTSTATE
argp pointe vers un octet qui est défini à la valeur de la variable du noyau shift_state. (Depuis Linux 1.1.32.)
sous-code=TIOCL_GETMOUSEREPORTING
argp pointe vers un octet qui est défini à la valeur de la variable du noyau report_mouse. (Depuis Linux 1.1.33.)
sous-code=8
Afficher la largeur et la hauteur de l'écran, la position du curseur et toutes les paires de caractéristiques de caractères. (Linux 1.1.67 à Linux 1.1.91). Avec Linux 1.1.92 ou plus récent, lu depuis /dev/vcsa*
sous-code=9
Restaurer la largeur et la hauteur de l'écran, la position du curseur et toutes les paires de caractéristiques de caractères. (Linux 1.1.67 à Linux 1.1.91). Avec Linux 1.1.92 ou plus récent, écrit dans /dev/vcsa*
sous-code=TIOCL_SETVESABLANK
Gère le mode d'extinction d'écran des nouveaux moniteurs. Le mode d'extinction d'écran VESA est défini dans argp[1], qui régule le type d'extinction que le moniteur effectue :
0
L'extinction du moniteur est désactivée.
1
Les registres de l'adaptateur vidéo actuels sont sauvegardés, puis le pilote est programmé pour éteindre les impulsions de synchronisation verticale. Ceci met le moniteur en mode "standby". Si votre moniteur a une minuterie Off_Mode, il s'éteindra de lui-même.
2
Les réglages actuels sont sauvegardés, puis les impulsions de synchronisation verticale et horizontale sont éteintes. Ceci met le moniteur en mode "off". Si votre moniteur n'a pas de minuterie Off_Mode ou si vous voulez que le moniteur s'éteigne immédiatement à l'expiration de la minuterie blank_timer, choisissez cette option. (Attention : une extinction fréquente peut endommager le moniteur.) (Depuis Linux 1.1.76.)
sous-code=TIOCL_SETKMSGREDIRECT
Change la destination des messages du noyau ("console") : par défaut, et si ce sous-code est défini à 0, les messages sont écrits sur le VT actuel. Le VT d'écriture est un octet suivant le sous-code. (Depuis Linux 2.5.36.)
sous-code=TIOCL_GETFGCONSOLE
Renvoie le numéro du VT au premier plan. (Depuis Linux 2.5.36.)
sous-code=TIOCL_SCROLLCONSOLE
Fait défiler le VT au premier plan du nombre de lignes spécifié vers le bas, ou la moitié de l'écran si 0. lines est *(((int32_t *)&sous_code) + 1). (Depuis Linux 2.5.67.)
sous-code=TIOCL_BLANKSCREEN
Éteint le VT au premier plan, ignorant les "pokes" (frappes clavier) : ne peut être désactivé explicitement (par exemple, en changeant de VT, en mode texte, etc.). (Depuis Linux 2.5.71.)
sous-code=TIOCL_BLANKEDSCREEN
Renvoie le nombre de VTs actuellement éteints, 0 si aucun. (Depuis Linux 2.5.71.)
sous-code=16
Non utilisé.
sous-code=TIOCL_GETKMSGREDIRECT
Renvoie la destination des messages du noyau. (Depuis Linux 2.6.17.)
sous-code=TIOCL_GETBRACKETEDPASTE
Renvoie 1 si l'application a annoncé la compatibilité avec le texte brut collé au terminal, 0 sinon. (Depuis Linux 6.16.)

VALEUR DE RETOUR

En cas de succès, 0 est retourné (sauf indication contraire). En cas d'échec, -1 est retourné, et errno est défini pour indiquer l'erreur.

ERREURS

EINVAL
argp est invalide.
EPERM
Autorisation insuffisante.

NORMES

Linux.

VOIR AUSSI

ioctl(2), ioctl_console(2)
