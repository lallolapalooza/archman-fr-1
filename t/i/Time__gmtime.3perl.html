Time::gmtime(3perl) Guide du programmeur Perl Time::gmtime(3perl)

NOM

Time::gmtime - interface par nom à la fonction intégrée gmtime() de Perl

SYNTAXE

use Time::gmtime;
$gm = gmtime();
printf "Le jour à Greenwich est %s\n", 
   (qw(Dim Lun Mar Mer Jeu Ven Sam Dim))[ $gm->wday() ];
use Time::gmtime qw(:FIELDS);
gmtime();
printf "Le jour à Greenwich est %s\n", 
   (qw(Dim Lun Mar Mer Jeu Ven Sam Dim))[ $tm_wday ];
$now = gmctime();
use Time::gmtime;
use File::stat;
$date_string = gmctime(stat($file)->mtime);

DESCRIPTION

L'exportation par défaut de ce module surcharge la fonction intégrée gmtime() de Perl, la remplaçant par une version qui renvoie des objets "Time::tm". Cet objet possède des méthodes qui renvoient le champ nommé de la structure C tm de time.h ; à savoir sec, min, hour, mday, mon, year, wday, yday et isdst.

Vous pouvez également importer tous les champs de la structure directement dans votre espace de noms sous forme de variables normales en utilisant la balise d'importation :FIELDS. (Notez que cela surcharge toujours les fonctions de base.) Accédez à ces champs en tant que variables nommées avec un préfixe "tm_" avant leurs noms de méthodes. Ainsi, "$tm_obj->mday()" correspond à $tm_mday si vous importez les champs.

La fonction gmctime() offre un moyen d'accéder au sens scalaire de la fonction originale CORE::gmtime().

Pour accéder à cette fonctionnalité sans surcharger les fonctions de base, passez une liste d'importation vide à "use", puis accédez aux fonctions avec leurs noms complets qualifiés. Par ailleurs, les fonctions intégrées sont toujours disponibles via le pseudo-paquet "CORE::".

NOTE

Bien que cette classe soit actuellement implémentée en utilisant le module Class::Struct pour construire une classe similaire à une structure, vous ne devriez pas vous y fier.
