TIOCSSOFTCAR(2const) TIOCSSOFTCAR(2const)

NOM

TIOCGSOFTCAR, TIOCSSOFTCAR - marquer une ligne comme locale

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <asm/termbits.h>  /* Définition des constantes TIOC*SOFTCAR */
#include <sys/ioctl.h>
int ioctl(int fd, TIOCGSOFTCAR, int *argp);
int ioctl(int fd, TIOCSSOFTCAR, const int *argp);

DESCRIPTION

TIOCGSOFTCAR
("Obtenir le drapeau logiciel de porteuse") Récupère le statut du drapeau CLOCAL dans le champ c_cflag de la structure termios.
TIOCSSOFTCAR
("Définir le drapeau logiciel de porteuse") Définit le drapeau CLOCAL dans la structure termios lorsque *argp est non nul, et le dégage sinon.

Si le drapeau CLOCAL d'une ligne est désactivé, le signal matériel de détection de porteuse (DCD) est significatif, et un open(2) du terminal correspondant bloquera jusqu'à ce que DCD soit asserté, sauf si le drapeau O_NONBLOCK est donné. Si CLOCAL est défini, la ligne se comporte comme si DCD était toujours asserté. Le drapeau logiciel de porteuse est généralement activé pour les périphériques locaux, et désactivé pour les lignes avec modem.

VALEUR RETOUR

En cas de succès, 0 est retourné. En cas d'erreur, -1 est retourné, et errno est défini pour indiquer l'erreur.

VOIR AUSSI

ioctl(2), ioctl_tty(2)
