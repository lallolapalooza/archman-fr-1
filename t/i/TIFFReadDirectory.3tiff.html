TIFFREADDIRECTORY(3tiff) LibTIFF TIFFREADDIRECTORY(3tiff)

NOM

TIFFReadDirectory - récupérer le contenu du répertoire suivant dans un fichier TIFF ouvert

SYNTAXE

#include <tiffio.h>
int TIFFReadDirectory(TIFF *tif)

DESCRIPTION

Lit le répertoire suivant dans le fichier spécifié et en fait le répertoire courant. Les applications n'ont besoin d'appeler TIFFReadDirectory() que pour lire plusieurs sous-fichiers dans un seul fichier TIFF (le premier répertoire d'un fichier est automatiquement lu lorsque TIFFOpen() est appelé.

NOTES

Si la bibliothèque est compilée avec STRIPCHOP_SUPPORT activé, les images qui ont une seule bande ou une seule tuile de données non compressées sont automatiquement traitées comme si elles étaient composées de plusieurs bandes ou tuiles d'environ 8 kilo-octets chacune. Cette opération est effectuée uniquement en mémoire ; elle ne modifie pas le contenu du fichier. Cependant, la construction des « bandes coupées » est visible par l'application à travers le nombre de bandes [tuiles] renvoyé par TIFFNumberOfStrips() [TIFFNumberOfTiles()].

VALEURS DE RETOUR

Si le répertoire suivant a été lu avec succès, 1 est renvoyé. Sinon, 0 est renvoyé si une erreur a été rencontrée, ou s'il n'y a plus de répertoires à lire.

DIAGNOSTICS

Tous les messages d'erreur sont dirigés vers la routine TIFFErrorExtR(). De même, les messages d'avertissement sont dirigés vers la routine TIFFWarningExtR().

Erreur de recherche lors de l'accès au répertoire TIFF :

Une erreur s'est produite lors du positionnement à l'emplacement du répertoire.

Type de données incorrect %d pour le champ « %s » :

L'entrée de balise dans le répertoire avait un type de données incorrect. Par exemple, une balise ImageDescription avec un type de données SHORT.

Répertoire TIFF manquant du champ obligatoire « %s » :

La balise spécifiée est requise par la spécification TIFF 5.0, mais elle est manquante. Le répertoire est (généralement) inutilisable.

%s : rationnel avec dénominateur zéro :

Une balise de répertoire a une valeur RATIONAL dont le dénominateur est zéro.

Nombre incorrect %d pour le champ « %s » (%lu, attendu %lu) ; balise ignorée :

Le champ de comptage de la balise spécifiée est erroné. Par exemple, un nombre différent de 1 pour une balise SubFileType.

Impossible de gérer des valeurs différentes par échantillon pour le champ « %s » :

La balise a des valeurs SamplesPerPixel et elles ne sont pas toutes identiques ; par exemple BitsPerSample. La bibliothèque ne peut pas gérer les images de ce type.

Incompatibilité de comptage pour le champ « %s » ; attendu %d, obtenu %d :

Le champ de comptage d'une balise n'est pas conforme au nombre attendu par la bibliothèque. Cela ne devrait jamais arriver, donc si cela se produit, la bibliothèque refuse de lire le répertoire.

Répertoire TIFF invalide ; les balises ne sont pas triées par ordre croissant :

Les balises du répertoire ne sont pas correctement triées comme spécifié dans la spécification TIFF 5.0. Cette erreur n'est pas fatale.

Ignoré champ inconnu avec la balise %d (0x%x) :

Une balise inconnue a été rencontrée dans le répertoire ; la bibliothèque ignore toutes ces balises.

Répertoire TIFF manquant du champ obligatoire « ImageLength » :

L'image viole la spécification en n'ayant pas un champ nécessaire. Il n'y a aucun moyen pour la bibliothèque de récupérer de cette erreur.

Répertoire TIFF manquant du champ obligatoire « PlanarConfig » :

L'image viole la spécification en n'ayant pas un champ nécessaire. Il n'y a aucun moyen pour la bibliothèque de récupérer de cette erreur.

Répertoire TIFF manquant du champ obligatoire « StripOffsets » :

L'image a plusieurs bandes, mais il manque la balise qui spécifie le décalage de fichier vers chaque bande de données. Il n'y a aucun moyen pour la bibliothèque de récupérer de cette erreur.

Répertoire TIFF manquant du champ obligatoire « TileOffsets » :

L'image a plusieurs tuiles, mais il manque la balise qui spécifie le décalage de fichier vers chaque tuile de données. Il n'y a aucun moyen pour la bibliothèque de récupérer de cette erreur.

Répertoire TIFF manquant du champ obligatoire « StripByteCounts » :

L'image a plusieurs bandes, mais il manque la balise qui spécifie la taille de chaque bande de données. Il n'y a aucun moyen pour la bibliothèque de récupérer de cette erreur.

Répertoire TIFF manquant du champ obligatoire « StripByteCounts », calcul à partir de imagelength :

L'image viole la spécification en n'ayant pas un champ nécessaire. Cependant, lorsque l'image est composée d'une seule bande ou tuile, la bibliothèque estimera la valeur manquante en fonction de la taille du fichier.

Champ « StripByteCounts » invalide, ignoré et calcul à partir de imagelength :

Certains vendeurs violent la spécification en écrivant zéro pour la balise StripByteCounts lorsqu'ils souhaitent laisser la valeur non spécifiée. Si l'image a une seule bande, la bibliothèque estimera la valeur manquante en fonction de la taille du fichier.
