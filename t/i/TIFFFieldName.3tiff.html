NOM

TIFFFieldName - obtenir le nom d'un champ TIFF à partir des informations du champ

SYNOPIS

#include <tiffio.h>
const char *TIFFFieldName(const TIFFField *fip)

DESCRIPTION

TIFFFieldName() renvoie le nom textuel d'un champ TIFF. fip est un pointeur d'informations de champ renvoyé précédemment par TIFFFindField(), TIFFFieldWithTag(), ou TIFFFieldWithName().

VALEURS DE RETOUR

TIFFFieldName() renvoie une chaîne C constante.

VOIR AUSSI

TIFFFieldDataType (3tiff), TIFFFieldPassCount (3tiff), TIFFFieldQuery (3tiff), TIFFFieldReadCount (3tiff), TIFFFieldTag (3tiff), TIFFFieldWriteCount (3tiff), libtiff (3tiff)
