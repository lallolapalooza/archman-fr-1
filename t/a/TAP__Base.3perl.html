TAP::Base(3perl) Guide du programmeur Perl TAP::Base(3perl)

NOM

TAP::Base - Classe de base fournissant des fonctionnalités communes à TAP::Parser et TAP::Harness

VERSION

Version 3.50

SYNOPSIS

package TAP::Whatever;
use base 'TAP::Base';
# ... plus tard ...

my $thing = TAP::Whatever->new();

$thing->callback( event => sub {
    # faire quelque chose d'intéressant
} );

DESCRIPTION

"TAP::Base" fournit la gestion des rappel.

MÉTHODES

Méthodes de classe

"callback"

Installe un rappel pour un événement nommé.

"get_time"

Retourne l'heure actuelle en utilisant Time::HiRes si disponible.

"time_is_hires"

Retourne vrai si l'heure renvoyée par get_time est en haute résolution (c'est-à-dire si Time::HiRes est disponible).

"get_times"

Retourne une référence de tableau de la liste à quatre éléments des secondes CPU, comme avec "times" dans perlfunc.
