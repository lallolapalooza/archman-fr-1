NOM

TAP::Parser::Result::Version - Jeton de version de la syntaxe TAP.

VERSION

Version 3.50

DESCRIPTION

Ceci est une sous-classe de TAP::Parser::Result. Un jeton de cette classe sera retourné si une ligne de version est rencontrée.

TAP version 13
ok 1
not ok 2

La première version de TAP à inclure un numéro de version explicite est la 13.
