TAP::Parser::Result(3perl) Guide du programmeur Perl TAP::Parser::Result(3perl)

NOM

TAP::Parser::Result - Classe de base pour les objets de sortie de TAP::Parser

VERSION

Version 3.50

SYNOPSIS

# classe abstraite - non destinée à être utilisée directement
# voir TAP::Parser::ResultFactory pour une utilisation préférée
# directement:
use TAP::Parser::Result;
my $token  = {...};
my $result = TAP::Parser::Result->new( $token );

DESCRIPTION

Ceci est une classe de base simple utilisée par TAP::Parser pour stocker des objets qui représentent la partie actuelle des données de sortie de test de TAP (généralement une seule ligne). À moins que vous ne sous-classiez, vous n'aurez probablement pas besoin d'utiliser ce module directement.

MÉTHODES

"new"

# voir TAP::Parser::ResultFactory pour une utilisation préférée
# pour utiliser directement:
my $result = TAP::Parser::Result->new($token);

Retourne une instance de la classe appropriée pour le jeton de test passé.

Méthodes booléennes

Les méthodes suivantes retournent toutes une valeur booléenne et doivent être remplacées dans la sous-classe appropriée.

  • "is_plan"

    Indique si c'est la ligne de plan de test.

    1..3
  • "is_pragma"

    Indique si c'est une ligne de pragma.

    pragma +strict
  • "is_test"

    Indique si c'est une ligne de test.

    ok 1 Is OK!
  • "is_comment"

    Indique si c'est un commentaire.

    # ceci est un commentaire
  • "is_bailout"

    Indique si c'est une ligne de sortie (bailout).

    Bail out! We're out of dilithium crystals.
  • "is_version"

    Indique si c'est une ligne de version TAP.

    TAP version 4
  • "is_unknown"

    Indique si la ligne actuelle a pu être analysée.

    ... this line is junk ...
  • "is_yaml"

    Indique si c'est un bloc YAML.

"raw"

print $result->raw;

Retourne la ligne de texte originale qui a été analysée.

"type"

my $type = $result->type;

Retourne le « type » d'un jeton, comme "comment" ou "test".

"as_string"

print $result->as_string;

Affiche une représentation sous forme de chaîne du jeton. Ce ne sera peut-être pas la sortie exacte, cependant. Les tests auront des numéros de test ajoutés s'ils sont absents, les directives TODO et SKIP seront capitalisées et, en général, les choses seront nettoyées. Si vous avez besoin du texte original du jeton, voir la méthode "raw".

"is_ok"

if ( $result->is_ok ) { ... }

Indique si un résultat donné a réussi. Tout ce qui n'est **pas** un résultat de test retourne vrai. Ceci est simplement fourni comme un raccourci pratique.

"passed"

Obsolète. Veuillez utiliser "is_ok" à la place.

"has_directive"

if ( $result->has_directive ) {
   ...
}

Indique si le résultat donné a une directive TODO ou SKIP.

"has_todo"

if ( $result->has_todo ) {
    ...
}

Indique si le résultat donné a une directive TODO.

"has_skip"

if ( $result->has_skip ) {
    ...
}

Indique si le résultat donné a une directive SKIP.

"set_directive"

Définit la directive associée à ce jeton. Utilisé en interne pour simuler des tests TODO.

SOUS CLASSES

Voir « SOUS CLASSES » dans TAP::Parser pour un aperçu de la sous-classification.

N'oubliez pas : si vous voulez que votre sous-classe soit automatiquement utilisée par l'analyseur, vous devrez l'enregistrer avec « register_type » dans TAP::Parser::ResultFactory.

Si vous créez un tout nouveau type de résultat, vous devrez probablement également sous-classer TAP::Parser::Grammar, sinon il ne sera jamais utilisé.

Exemple

package MyResult;
use strict;
use base 'TAP::Parser::Result';
# enregistrer auprès de la fabrique:
TAP::Parser::ResultFactory->register_type( 'my_type' => __PACKAGE__ );
sub as_string { 'My results all look the same' }
