DESCRIPTION

Ces macros définissent et opèrent sur des files de queue doublement chaînées.

Dans les définitions de macros, TYPE est le nom d'une structure définie par l'utilisateur, qui doit contenir un champ de type TAILQ_ENTRY, nommé NOM. L'argument NOM_QUEUE est le nom d'une structure définie par l'utilisateur qui doit être déclarée en utilisant la macro TAILQ_HEAD().

Création

Une file de queue est dirigée par une structure définie par la macro TAILQ_HEAD(). Cette structure contient une paire de pointeurs, l'un vers le premier élément de la queue et l'autre vers le dernier élément de la queue. Les éléments sont doublement chaînés de sorte qu'un élément arbitraire puisse être supprimé sans parcourir la queue. De nouveaux éléments peuvent être ajoutés à la queue après un élément existant, avant un élément existant, en tête de la queue ou à la fin de la queue. Une structure TAILQ_HEAD est déclarée comme suit :


TAILQ_HEAD(NOM_QUEUE, TYPE) queue;

où struct NOM_QUEUE est la structure à définir, et struct TYPE est le type des éléments à lier dans la queue. Un pointeur vers la tête de la queue peut ensuite être déclaré comme :


struct NOM_QUEUE *pointeur_queue;

(Les noms queue et pointeur_queue sont sélectionnables par l'utilisateur.)

TAILQ_ENTRY() déclare une structure qui relie les éléments de la queue.

TAILQ_HEAD_INITIALIZER() évalue à un initialiseur pour la queue queue.

TAILQ_INIT() initialise la queue référencée par

TAILQ_EMPTY() évalue à vrai s'il n'y a pas d'éléments dans la queue. queue.

Insertion

TAILQ_INSERT_HEAD() insère le nouvel élément elt en tête de la queue.

TAILQ_INSERT_TAIL() insère le nouvel élément elt à la fin de la queue.

TAILQ_INSERT_BEFORE() insère le nouvel élément elt avant l'élément elt_liste.

TAILQ_INSERT_AFTER() insère le nouvel élément elt après l'élément elt_liste.

Parcours

TAILQ_FIRST() renvoie le premier élément de la queue, ou NULL si la queue est vide.

TAILQ_LAST() renvoie le dernier élément de la queue. Si la queue est vide, la valeur de retour est NULL.

TAILQ_PREV() renvoie l'élément précédent dans la queue, ou NULL si cet élément est le premier.

TAILQ_NEXT() renvoie l'élément suivant dans la queue, ou NULL si cet élément est le dernier.

TAILQ_FOREACH() parcourt la queue référencée par queue dans le sens avant, attribuant chaque élément à tour de rôle à var. var est mis à NULL si la boucle se termine normalement, ou s'il n'y avait pas d'éléments.

TAILQ_FOREACH_REVERSE() parcourt la queue référencée par queue dans le sens inverse, attribuant chaque élément à tour de rôle à var.

Suppression

TAILQ_REMOVE() supprime l'élément elt de la queue.

Autres fonctionnalités

TAILQ_CONCAT() concatène la queue dirigée par queue2 à la fin de celle dirigée par queue1, en supprimant toutes les entrées de la première.

VALEUR DE RETOUR

TAILQ_EMPTY() renvoie une valeur non nulle si la queue est vide, et zéro si la queue contient au moins une entrée.

TAILQ_FIRST(), TAILQ_LAST(), TAILQ_PREV(), et TAILQ_NEXT() renvoient un pointeur vers la structure TYPE première, dernière, précédente ou suivante, respectivement.

TAILQ_HEAD_INITIALIZER() renvoie un initialiseur qui peut être assigné à la queue queue.

NORMES

BSD.

HISTORIQUE

4.4BSD.

LIMITATIONS

TAILQ_FOREACH() et TAILQ_FOREACH_REVERSE() ne permettent pas de supprimer ou de libérer var pendant la boucle, car cela interférerait avec le parcours. TAILQ_FOREACH_SAFE() et TAILQ_FOREACH_REVERSE_SAFE(), qui sont présents sur les BSD mais pas dans glibc, corrigent cette limitation en permettant à var d'être supprimé en toute sécurité de la liste et libéré à partir de la boucle sans interférer avec le parcours.

EXEMPLES

#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>
struct entree {
    int donnees;
    TAILQ_ENTRY(entree) entrees;             /* File de queue */
};
TAILQ_HEAD(queue_tail, entree);
int
main(void)
{
    struct entree *n1, *n2, *n3, *np;
    struct queue_tail tete;                   /* Tête de la file de queue */
    int i;
    TAILQ_INIT(&tete);                      /* Initialisation de la queue */
    n1 = malloc(sizeof(struct entree));      /* Insertion en tête */
    TAILQ_INSERT_HEAD(&tete, n1, entrees);
    n1 = malloc(sizeof(struct entree));      /* Insertion en fin */
    TAILQ_INSERT_TAIL(&tete, n1, entrees);
    n2 = malloc(sizeof(struct entree));      /* Insertion après */
    TAILQ_INSERT_AFTER(&tete, n1, n2, entrees);
    n3 = malloc(sizeof(struct entree));      /* Insertion avant */
    TAILQ_INSERT_BEFORE(n2, n3, entrees);
    TAILQ_REMOVE(&tete, n2, entrees);       /* Suppression */
    free(n2);
                                            /* Parcours avant */
    i = 0;
    TAILQ_FOREACH(np, &tete, entrees)
        np->donnees = i++;
                                            /* Parcours inverse */
    TAILQ_FOREACH_REVERSE(np, &tete, queue_tail, entrees)
        printf("%i\n", np->donnees);
                                            /* Suppression de la file */
