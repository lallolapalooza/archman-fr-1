NOM

Task::Weaken - Assure que la plateforme dispose du support de weaken

VERSION

version 1.06

DESCRIPTION

Un problème récurrent dans les modules qui utilisent la fonction "weaken" de Scalar::Util est qu'elle n'est pas présente dans la variante pure-Perl.

Bien que ce ne soit pas nécessairement toujours un problème dans un environnement Perl basé sur CPAN, certaines distributions de systèmes d'exploitation n'incluent que les versions pure-Perl, n'incluent pas la version XS, et donc weaken est alors "manquant" de la plateforme, malgré une dépendance réussie sur Scalar::Util.

Notamment cela concerne RedHat Linux au moment de la rédaction, mais d'autres viennent et partent et font la même chose, d'où le "problème récurrent".

La solution normale est d'écrire manuellement des tests dans chaque distribution pour s'assurer que "weaken" est disponible.

Ceci restaure le test de fonctionnalité à une dépendance que vous faites une fois dans votre Makefile.PL, plutôt que quelque chose que vous devez écrire des tests supplémentaires chaque fois que vous écrivez un module.

Cela devrait également aider les générateurs de paquets pour les divers systèmes d'exploitation à mieux fonctionner, car cela introduit une dépendance pour laquelle ils doivent avoir un weaken approprié pour fonctionner.

Comment cette Tâche fonctionne

Une partie du problème semble provenir du fait que certaines distributions continuent d'inclure des modules même s'ils échouent à certains de leurs tests.

Pour contourner cela pour ce module, il utilisera quelques astuces sales.

Si Scalar::Util n'est pas disponible du tout, il émettra une dépendance normale sur le module. Cependant, si Scalar::Util est relativement nouveau ( il est >= 1.19 ) et que le module n'a pas weaken, l'installation échouera complètement avec une longue erreur encourageant l'utilisateur à chercher du support auprès de son fournisseur (ce problème se produit le plus souvent dans les versions de Perl fournies par le vendeur).

Cette distribution contient également des tests pour s'assurer que weaken est disponible en utilisant des méthodes plus normales.

Donc, si votre module utilise "weaken", vous pouvez simplement ajouter ceci à votre Makefile.PL basé sur Module::Install (ou équivalent).

requires 'Task::Weaken' => 0;
