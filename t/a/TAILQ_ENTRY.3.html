DESCRIPTION

Ces macros définissent et manipulent une liste doublement chaînée à double extrémité.

Dans les définitions de macro, TYPE est le nom d'une structure définie par l'utilisateur qui doit contenir un champ de type TAILQ_ENTRY, nommé NAME. L'argument HEADNAME est le nom d'une structure définie par l'utilisateur qui doit être déclarée avec la macro TAILQ_HEAD().

Création

Une liste chaînée est définie par une structure déclarée à l'aide de la macro TAILQ_HEAD(). Cette structure contient une paire de pointeurs, l'un vers le premier élément de la liste et l'autre vers le dernier élément. Les éléments sont doublement chaînés, ce qui permet de supprimer n'importe quel élément sans parcourir la liste. De nouveaux éléments peuvent être ajoutés à la liste après un élément existant, avant un autre, à la tête de la liste ou à la queue. Une structure TAILQ_HEAD est déclarée comme suit :


TAILQ_HEAD(HEADNAME, TYPE) head;

où struct HEADNAME est la structure à définir et struct TYPE est le type des éléments chaînés dans la liste. Un pointeur vers la tête de la liste peut être déclaré plus tard comme suit :


struct HEADNAME *headp;

(Les noms head et headp sont choisissables par l'utilisateur.)

TAILQ_ENTRY() déclare une structure qui relie les éléments de la liste.

TAILQ_HEAD_INITIALIZER() renvoie un initialiseur pour la liste head.

TAILQ_INIT() initialise la liste référencée par head. TAILQ_EMPTY() renvoie vrai si la liste ne contient aucun élément.

Insertion

TAILQ_INSERT_HEAD() insère le nouvel élément elm à la tête de la liste.

TAILQ_INSERT_TAIL() insère le nouvel élément elm à la queue de la liste.

TAILQ_INSERT_BEFORE() insère le nouvel élément elm avant l'élément listelm.

TAILQ_INSERT_AFTER() insère le nouvel élément elm après l'élément listelm.

Parcours

TAILQ_FIRST() renvoie le premier élément de la liste, ou NULL si la liste est vide.

TAILQ_LAST() renvoie le dernier élément de la liste. Si la liste est vide, la valeur renvoyée est NULL.

TAILQ_PREV() renvoie l'élément précédent dans la liste, ou NULL si c'est le premier.

TAILQ_NEXT() renvoie l'élément suivant dans la liste, ou NULL si c'est le dernier.

TAILQ_FOREACH() parcourt la liste référencée par head dans l'ordre croissant, affectant chaque élément à var. var est mis à NULL si la boucle se termine normalement, ou s'il n'y a pas d'éléments.

TAILQ_FOREACH_REVERSE() parcourt la liste référencée par head dans l'ordre décroissant, affectant chaque élément à var.

Suppression

TAILQ_REMOVE() supprime l'élément elm de la liste.

Autres fonctionnalités

TAILQ_CONCAT() concatène la liste head2 à la fin de la liste head1, vidant la première liste.

VALEUR DE RETOUR

TAILQ_EMPTY() renvoie une valeur non nulle si la liste est vide, et zéro s'il y a au moins un élément.

TAILQ_FIRST(), TAILQ_LAST(), TAILQ_PREV() et TAILQ_NEXT() renvoient un pointeur vers la structure TYPE du premier, dernier, précédent ou suivant élément, respectivement.

TAILQ_HEAD_INITIALIZER() renvoie un initialiseur qui peut être assigné à la liste head.

NORMES

BSD.

HISTORIQUE

4.4BSD.

AVERTISSEMENTS

TAILQ_FOREACH() et TAILQ_FOREACH_REVERSE() ne permettent pas de supprimer ou de libérer la valeur var à l'intérieur de la boucle, car cela pourrait interférer avec le parcours. TAILQ_FOREACH_SAFE() et TAILQ_FOREACH_REVERSE_SAFE(), qui sont présents sur les systèmes BSD mais pas sur glibc, corrigent cette limitation en permettant à var d'être supprimé et libéré à l'intérieur de la boucle sans interférer avec le parcours.

EXEMPLE

#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>
struct entry {
    int data;
    TAILQ_ENTRY(entry) entries;             /* Chaîne d'entrée de liste */
};
TAILQ_HEAD(tailhead, entry);
int
main(void)
{
    struct entry *n1, *n2, *n3, *np;
    struct tailhead head;                   /* Tête de liste */
    int i;
    TAILQ_INIT(&head);                      /* Initialise la liste */
    n1 = malloc(sizeof(struct entry));      /* Insertion à la tête */
    TAILQ_INSERT_HEAD(&head, n1, entries);
    n1 = malloc(sizeof(struct entry));      /* Insertion à la queue */
    TAILQ_INSERT_TAIL(&head, n1, entries);
    n2 = malloc(sizeof(struct entry));      /* Insertion après */
    TAILQ_INSERT_AFTER(&head, n1, n2, entries);
    n3 = malloc(sizeof(struct entry));      /* Insertion avant */
    TAILQ_INSERT_BEFORE(n2, n3, entries);
    TAILQ_REMOVE(&head, n2, entries);       /* Suppression */
    free(n2);
                                            /* Parcours ascendant */
    i = 0;
    TAILQ_FOREACH(np, &head, entries)
        np->data = i++;
                                            /* Parcours descendant */
    TAILQ_FOREACH_REVERSE(np, &head, tailhead, entries)
        printf("%i\n", np->data);
                                            /* Suppression de la liste */
    n

DESCRIPTION

These macros provide a facility for managing lists of arbitrary data structures. A list is the simplest general-purpose data structure. It is a collection of elements, each of which contains data and a pointer to the next element in the list. A tail queue is a doubly linked list of arbitrary data structures. It is similar to a singly linked list, except that it also maintains a pointer to the last element in the list.

The following macros are provided:

TAILQ_ENTRY(type)
Declares a structure named type that contains the necessary pointers to link elements into a tail queue. The structure will contain two pointers, tqe_next and tqe_prev.
TAILQ_HEAD(headname, type)
Declares a structure named headname that defines the head of a tail queue. The structure will contain two pointers, tqh_first and tqh_last. The type argument must be the name of the structure declared by TAILQ_ENTRY.
TAILQ_INIT(head)
Initializes the tail queue specified by head. This must be called for every list that is initialized.
TAILQ_EMPTY(head)
Returns true if the tail queue head is empty.
TAILQ_FIRST(head)
Returns a pointer to the first element in the tail queue head. Returns NULL if the queue is empty.
TAILQ_LAST(head, field)
Returns a pointer to the last element in the tail queue head. field is the name of the tail queue head structure. Returns NULL if the queue is empty.
TAILQ_NEXT(elm, field)
Returns a pointer to the next element in the tail queue. elm is a pointer to an element in the queue, and field is the name of the tail queue entry structure.
TAILQ_PREV(elm, field)
Returns a pointer to the previous element in the tail queue. elm is a pointer to an element in the queue, and field is the name of the tail queue entry structure.
TAILQ_INSERT_HEAD(head, elm, field)
Inserts the element elm at the head of the tail queue head. field is the name of the tail queue entry structure.
TAILQ_INSERT_TAIL(head, elm, field)
Inserts the element elm at the tail of the tail queue head. field is the name of the tail queue entry structure.
TAILQ_INSERT_AFTER(head, listelm, elm, field)
Inserts the element elm after the element listelm in the tail queue head. field is the name of the tail queue entry structure.
TAILQ_INSERT_BEFORE(listelm, elm, field)
Inserts the element elm before the element listelm in the tail queue. field is the name of the tail queue entry structure.
TAILQ_REMOVE(head, elm, field)
Removes the element elm from the tail queue head. field is the name of the tail queue entry structure.
TAILQ_REPLACE(head, oldelm, newelm, field)
Replaces the element oldelm with the element newelm in the tail queue head. field is the name of the tail queue entry structure.
TAILQ_FOREACH(var, head, field)
Iterates over the elements in the tail queue head. In each iteration, var is assigned the current element. field is the name of the tail queue entry structure.
TAILQ_FOREACH_REVERSE(var, head, field)
Iterates over the elements in the tail queue head in reverse order. In each iteration, var is assigned the current element. field is the name of the tail queue entry structure.
TAILQ_SWAP(head1, head2, type)
Swaps the contents of the two tail queues head1 and head2. The type argument must be the name of the tail queue head structure.

RETURN VALUE

TAILQ_FIRST and TAILQ_LAST return a pointer to the first and last element of the queue, respectively, or NULL if the queue is empty. TAILQ_NEXT and TAILQ_PREV return a pointer to the next and previous element of the queue, respectively, or NULL if there is no next or previous element. TAILQ_EMPTY returns non-zero if the queue is empty, and zero otherwise.

STANDARDS

The tail queue macros are derived from the BSD operating system.

HISTORY

The tail queue macros first appeared in 4.4BSD.

CAVEATS

The TAILQ_FOREACH and TAILQ_FOREACH_REVERSE macros are not reentrant. If the code that iterates over the list modifies the list, the behavior is undefined. For example, calling TAILQ_REMOVE inside the loop is problematic.

The TAILQ_REMOVE macro can be used safely within a loop if the next element is saved before the removal, as shown in the following example:

    n1 = TAILQ_FIRST(&head);
    while (n1 != NULL) {
        n2 = TAILQ_NEXT(n1, entries);
        free(n1);
        n1 = n2;
    }
    TAILQ_INIT(&head);
    exit(EXIT_SUCCESS);
}

EXAMPLES

The following example demonstrates how to use the tail queue macros to create and traverse a list of integers:

#include <stdio.h>
#include <stdlib.h>
#include <bsd/stdlib.h>

typedef struct IntEntry {
    int value;
    TAILQ_ENTRY(IntEntry) entries;
} IntEntry;

TAILQ_HEAD(IntListHead, IntEntry) IntListHead;

int
main(void) {
    IntListHead head;
    IntEntry *entry, *tmp;
    int i;

    TAILQ_INIT(&head);

    /* Add elements to the list */
    for (i = 0; i < 5; i++) {
        entry = malloc(sizeof(IntEntry));
        if (entry == NULL) {
            perror("malloc");
            exit(EXIT_FAILURE);
        }
        entry->value = i;
        TAILQ_INSERT_TAIL(&head, entry, entries);
    }

    /* Traverse the list */
    printf("Forward traversal:\n");
    TAILQ_FOREACH(entry, &head, entries) {
        printf("%d ", entry->value);
    }
    printf("\n");

    /* Traverse the list in reverse */
    printf("Reverse traversal:\n");
    TAILQ_FOREACH_REVERSE(entry, &head, entries) {
        printf("%d ", entry->value);
    }
    printf("\n");

    /* Remove elements from the list and free memory */
    TAILQ_FOREACH_SAFE(entry, &head, entries, tmp) {
        TAILQ_REMOVE(&head, entry, entries);
        free(entry);
    }

    return 0;
}
