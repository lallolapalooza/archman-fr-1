DESCRIPTION

Ces macros définissent et opèrent sur une file doublement chaînée à queue finale.

Dans les définitions de macro, TYPE est le nom d'une structure définie par l'utilisateur qui doit contenir un champ de type TAILQ_ENTRY, nommé NAME. L'argument HEADNAME est le nom d'une structure définie par l'utilisateur qui doit être déclarée en utilisant la macro TAILQ_HEAD().

Création

Une file d'éléments est définie par la macro TAILQ_HEAD(). Cette structure contient une paire de pointeurs, l'un vers le premier élément de la file et l'autre vers le dernier élément de la file. Les éléments sont doublement chaînés de sorte que n'importe quel élément puisse être retiré sans parcourir la file. De nouveaux éléments peuvent être ajoutés à la file après un élément existant, avant un autre, au début de la file, ou à la fin de la file. Une structure TAILQ_HEAD est déclarée ainsi:


TAILQ_HEAD(HEADNAME, TYPE) head;

où struct HEADNAME est la structure à définir, et struct TYPE est le type des éléments qui seront chaînés dans la file. Une adresse de pointeur vers la tête de la file peut ensuite être déclarée comme:


struct HEADNAME *headp;

(Les noms head et headp sont choisissables par l'utilisateur.)

TAILQ_ENTRY() déclare une structure qui relie les éléments de la file.

TAILQ_HEAD_INITIALIZER() évalue à un initialiseur pour la file head.

TAILQ_INIT() initialise la file référencée par

TAILQ_EMPTY() évalue à vrai si la file ne contient aucun élément. head.

Insertion

TAILQ_INSERT_HEAD() insère le nouvel élément elm au début de la file.

TAILQ_INSERT_TAIL() insère le nouvel élément elm à la fin de la file.

TAILQ_INSERT_BEFORE() insère le nouvel élément elm avant l'élément listelm.

TAILQ_INSERT_AFTER() insère le nouvel élément elm après l'élément listelm.

Parcours

TAILQ_FIRST() renvoie le premier élément de la file, ou NULL si la file est vide.

TAILQ_LAST() renvoie le dernier élément de la file. Si la file est vide, la valeur renvoyée est NULL.

TAILQ_PREV() renvoie l'élément précédent dans la file, ou NULL s'il s'agit du premier.

TAILQ_NEXT() renvoie l'élément suivant dans la file, ou NULL s'il s'agit du dernier.

TAILQ_FOREACH() parcourt la file référencée par head dans le sens direct, assignant chaque élément à var. var est mis à NULL si la boucle se termine normalement, ou s'il n'y a aucun élément.

TAILQ_FOREACH_REVERSE() parcourt la file référencée par head dans le sens inverse, assignant chaque élément à var.

Suppression

TAILQ_REMOVE() supprime l'élément elm de la file.

Autres fonctionnalités

TAILQ_CONCAT() concatène la file head2 à la fin de la file head1, en supprimant tous les éléments de la première.

VALEUR DE RETOUR

TAILQ_EMPTY() renvoie une valeur non nulle si la file est vide, et zéro s'il y a au moins un élément.

TAILQ_FIRST(), TAILQ_LAST(), TAILQ_PREV() et TAILQ_NEXT() renvoient un pointeur vers la structure TYPE première, dernière, précédente ou suivante, respectivement.

TAILQ_HEAD_INITIALIZER() renvoie un initialiseur qui peut être assigné à la file head.

STANDARDS

BSD.

HISTORIQUE

4.4BSD.

ERREURS OBSERVÉES

TAILQ_FOREACH() et TAILQ_FOREACH_REVERSE() n'autorisent pas la suppression ou la libération de var à l'intérieur de la boucle, car cela pourrait interférer avec le parcours. TAILQ_FOREACH_SAFE() et TAILQ_FOREACH_REVERSE_SAFE(), qui sont disponibles sous BSD mais pas dans glibc, ont corrigé cette limite en permettant à var d'être supprimé en toute sécurité de la liste et libéré à l'intérieur de la boucle sans interférer avec le parcours.

EXEMPLES

#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>
struct entry {
    int data;
    TAILQ_ENTRY(entry) entries;             /* File doublement chaînée */
};
TAILQ_HEAD(tailhead, entry);
int
main(void)
{
    struct entry *n1, *n2, *n3, *np;
    struct tailhead head;                   /* Tête de la file */
    int i;
    TAILQ_INIT(&head);                      /* Initialiser la file */
    n1 = malloc(sizeof(struct entry));      /* Insertion en tête */
    TAILQ_INSERT_HEAD(&head, n1, entries);
    n1 = malloc(sizeof(struct entry));      /* Insertion en queue */
    TAILQ_INSERT_TAIL(&head, n1, entries);
    n2 = malloc(sizeof(struct entry));      /* Insertion après */
    TAILQ_INSERT_AFTER(&head, n1, n2, entries);
    n3 = malloc(sizeof(struct entry));      /* Insertion avant */
    TAILQ_INSERT_BEFORE(n2, n3, entries);
    TAILQ_REMOVE(&head, n2, entries);       /* Suppression */
    free(n2);
                                            /* Parcours en avant */
    i = 0;
    TAILQ_FOREACH(np, &head, entries)
        np->data = i++;
                                            /* Parcours en arrière */
    TAILQ_FOREACH_REVERSE(np, &head, tailhead, entries)
        printf("%i\n", np->data);
                                            /* Suppression de la file */

DESCRIPTION

These macros provide an implementation of lists that are doubly linked at both the head and the tail. They are implemented using the macros found in queue(3). The data structure for the list head is defined using TAILQ_HEAD.

The TAILQ_ENTRY macro defines the structure that is used to link the elements together. This structure must be a member of the structure that is being added to the list.

The TAILQ_HEAD_INITIALIZER macro can be used to initialize a tail queue.

The TAILQ_INIT macro initializes the tail queue pointed to by head.

The TAILQ_INSERT_HEAD macro inserts the element elm at the head of the list.

The TAILQ_INSERT_TAIL macro inserts the element elm at the tail of the list.

The TAILQ_INSERT_AFTER macro inserts the element elm after the element listelm in the list.

The TAILQ_INSERT_BEFORE macro inserts the element elm before the element listelm in the list.

The TAILQ_REMOVE macro removes the element elm from the list.

The TAILQ_REPLACE macro replaces the element elm with the element elm2 in the list.

The TAILQ_PREPEND macro prepends the element elm to the list.

The TAILQ_CONCAT macro concatenates the list pointed to by head2 onto the end of the list pointed to by head1.

The TAILQ_SWAP macro swaps the contents of the two lists head1 and head2.

The TAILQ_FIRST macro returns the first element in the list.

The TAILQ_LAST macro returns the last element in the list.

The TAILQ_NEXT macro returns the next element in the list.

The TAILQ_PREV macro returns the previous element in the list.

The TAILQ_EMPTY macro returns true if the list is empty.

The TAILQ_FOREACH macro iterates over the list from the first to the last element.

The TAILQ_FOREACH_SAFE macro is similar to TAILQ_FOREACH, but it is safe to use within the loop body to remove the current element.

The TAILQ_FOREACH_REVERSE macro iterates over the list from the last to the first element.

The TAILQ_FOREACH_REVERSE_SAFE macro is similar to TAILQ_FOREACH_REVERSE, but it is safe to use within the loop body to remove the current element.

The macros TAILQ_GET_TRANSPLANT_HEAD, TAILQ_GET_TRANSPLANT_TAIL, TAILQ_MOVE, TAILQ_SWAP_TRANSPLANT, and TAILQ_TRANSPLANT are used for transplanting lists and list elements. These are only available if __BSD_VISIBLE is defined.

TAILQ_GET_TRANSPLANT_HEAD returns a pointer to the head of the list that will be used for transplantation.

TAILQ_GET_TRANSPLANT_TAIL returns a pointer to the tail of the list that will be used for transplantation.

TAILQ_MOVE moves the element elm from the list pointed to by head1 to the list pointed to by head2.

TAILQ_SWAP_TRANSPLANT swaps the elements elm1 and elm2 between the lists head1 and head2.

TAILQ_TRANSPLANT transplants the element elm from the list head1 to the list head2 before the element elm2.

RETURN VALUE

The TAILQ_FIRST, TAILQ_LAST, TAILQ_NEXT, and TAILQ_PREV macros return a pointer to the requested element, or NULL if the list is empty or the requested element is not found.

The TAILQ_EMPTY macro returns 0 if the list is not empty, and 1 if it is empty.

STANDARDS

These macros are compatible with the BSD operating systems.

HISTORY

The list functions first appeared in 4.4BSD.

CAVEATS

When removing an element from a list using TAILQ_REMOVE, the entry_name parameter must be the same name as used when inserting the element.

EXAMPLES

The following example demonstrates the usage of TAILQ_HEAD, TAILQ_ENTRY, TAILQ_INIT, TAILQ_INSERT_TAIL, TAILQ_FOREACH, and TAILQ_REMOVE:

#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>

struct my_list_entry {
    int data;
    TAILQ_ENTRY(my_list_entry) entries;
};

// Define the list head
TAILQ_HEAD(my_list_head, my_list_entry);

int
main()
{
    struct my_list_head head; // List head
    struct my_list_entry *n1, *n2; // List entries

    // Initialize the list head
    TAILQ_INIT(&head);

    // Create and insert elements into the list
    n1 = malloc(sizeof(struct my_list_entry));
    n1->data = 10;
    TAILQ_INSERT_TAIL(&head, n1, entries);

    n1 = malloc(sizeof(struct my_list_entry));
    n1->data = 20;
    TAILQ_INSERT_TAIL(&head, n1, entries);

    n1 = malloc(sizeof(struct my_list_entry));
    n1->data = 30;
    TAILQ_INSERT_TAIL(&head, n1, entries);

    // Iterate through the list and print elements
    printf("List elements:\n");
    TAILQ_FOREACH(n1, &head, entries) {
        printf("%d\n", n1->data);
    }

    // Remove and free elements from the list
    printf("\nRemoving elements:\n");
    n1 = TAILQ_FIRST(&head);
    while (n1 != NULL) {
        n2 = TAILQ_NEXT(n1, entries); // Get the next element before freeing the current one
        printf("Removing %d\n", n1->data);
        TAILQ_REMOVE(&head, n1, entries);
        free(n1);
        n1 = n2; // Move to the next element
    }

    // Verify the list is empty
    if (TAILQ_EMPTY(&head)) {
        printf("\nList is now empty.\n");
    }

    // Example of freeing the entire list at the end (if TAILQ_INIT was used to clear it)
    // If TAILQ_INIT is called after the loop, it resets the head pointers.
    // The elements themselves must be freed individually as shown above.
    // TAILQ_INIT(&head);

    exit(EXIT_SUCCESS);
}
