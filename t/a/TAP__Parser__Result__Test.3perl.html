TAP::Parser::Result::Test(3perl) Guide de référence du programmeur Perl TAP::Parser::Result::Test(3perl)

NOM

TAP::Parser::Result::Test - Jeton de résultat de test.

VERSION

Version 3.50

DESCRIPTION

Ceci est une sous-classe de TAP::Parser::Result. Un jeton de cette classe sera retourné si une ligne de test est rencontrée.

1..1
ok 1 - woo hooo!

MÉTHODES SUBSITUÉES

Cette classe est le cheval de bataille du système TAP::Parser. La plupart des lignes TAP seront des lignes de test et si "$result->is_test", alors vous avez un ensemble de méthodes à votre disposition.

Méthodes d'instance

"ok"

my $ok = $result->ok;

Retourne le texte littéral du statut "ok" ou "not ok".

"number"

my $test_number = $result->number;

Retourne le numéro du test, même si la sortie TAP originale ne fournissait pas ce numéro.

"description"

my $description = $result->description;

Retourne la description du test, le cas échéant. C'est la partie après le numéro du test mais avant la directive.

"directive"

my $directive = $result->directive;

Retourne soit "TODO" soit "SKIP" si l'une de ces directives était présente pour une ligne de test.

"explanation"

my $explanation = $result->explanation;

Si un test avait une directive "TODO" ou "SKIP", cette méthode retournera l'explication associée, le cas échéant.

not ok 17 - 'Pigs can fly' # TODO not enough acid

Pour la ligne ci-dessus, l'explication est _not enough acid_.

"is_ok"

if ( $result->is_ok ) { ... }

Retourne une valeur booléenne indiquant si le test a réussi ou non. N'oubliez pas que pour les tests TODO, le test réussit toujours.

Si le test n'est pas planifié, cette méthode retournera toujours faux. Voir "is_unplanned".

"is_actual_ok"

if ( $result->is_actual_ok ) { ... }

Retourne une valeur booléenne indiquant si le test a réussi ou non, quel que soit son statut TODO.

"actual_passed"

Obsolète. Veuillez utiliser "is_actual_ok" à la place.

"todo_passed"

if ( $test->todo_passed ) {
   # test a réussi de manière inattendue
}

S'il s'agit d'un test TODO et d'une ligne 'ok', cette méthode retourne vrai. Sinon, elle retournera toujours faux (indépendamment du statut de succès des tests non-todo).

Ceci est utilisé pour suivre les tests qui ont réussi de manière inattendue.

"todo_failed"

# obsolète au profit de 'todo_passed'. Cette méthode était horriblement mal nommée.

C'était une méthode mal nommée. Elle indique quels tests TODO ont réussi de manière inattendue. Elle émettra maintenant un avertissement et appellera "todo_passed".

"has_skip"

if ( $result->has_skip ) { ... }

Retourne une valeur booléenne indiquant si ce test a une directive SKIP.

"has_todo"

if ( $result->has_todo ) { ... }

Retourne une valeur booléenne indiquant si ce test a une directive TODO.

"as_string"

print $result->as_string;

Cette méthode imprime le test sous forme de chaîne de caractères. Elle sera probablement similaire, mais pas nécessairement identique, à la ligne de test originale. Les directives sont en majuscules, certains espaces peuvent être tronqués et un numéro de test sera ajouté s'il était absent de la ligne originale. Si vous avez besoin du texte original de la ligne de test, utilisez la méthode "raw".

"is_unplanned"

if ( $test->is_unplanned ) { ... }
$test->is_unplanned(1);

Si un numéro de test est supérieur au nombre de tests planifiés, cette méthode retournera vrai. Les tests non planifiés retourneront *toujours* faux pour "is_ok", indépendamment du fait que le test "has_todo".

Notez que si les tests ont un plan final, il n'est pas possible de définir cette propriété pour les tests non planifiés car nous ne savons pas qu'ils ne sont pas planifiés avant d'atteindre le plan :

print <<'END';
ok 1
ok 2
1..1
END
