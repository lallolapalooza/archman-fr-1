NOM

TAP::Parser::Iterator::Array - Itérateur pour les sources TAP basées sur des tableaux

VERSION

Version 3.50

SYNOPIS

use TAP::Parser::Iterator::Array;
my @data = ('foo', 'bar', baz');
my $it   = TAP::Parser::Iterator::Array->new(\@data);
my $line = $it->next;

DESCRIPTION

C'est un simple wrapper d'itérateur pour les tableaux de contenu scalaire, utilisé par TAP::Parser. Sauf si vous écrivez un plugin ou une sous-classe, vous n'aurez probablement pas besoin d'utiliser ce module directement.

MÉTHODES

Méthodes de classe

"new"

Crée un itérateur. Prend un argument : un $array_ref

Méthodes d'instance

"next"

Itère à travers, bien sûr.

"next_raw"

Itère sur l'entrée brute sans appliquer de corrections pour une syntaxe d'entrée particulière.

"wait"

Obtenir le statut d'attente pour cet itérateur. Pour un itérateur de tableau, ce sera toujours zéro.

"exit"

Obtenir le statut de sortie pour cet itérateur. Pour un itérateur de tableau, ce sera toujours zéro.

ATTRIBUTION

Initialement ripé de Test::Harness.

VOIR AUSSI

TAP::Object, TAP::Parser, TAP::Parser::Iterator,
