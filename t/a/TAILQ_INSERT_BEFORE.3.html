TAILQ_INSERT_BEFORE(3)

TAILQ(3) Manuel des fonctions de bibliothèque TAILQ(3)

DESCRIPTION

Ces macros définissent et opèrent sur des files d'attente doublement chaînées.

Dans les définitions de macros, TYPE est le nom d'une structure définie par l'utilisateur, qui doit contenir un champ de type TAILQ_ENTRY, nommé NAME. L'argument HEADNAME est le nom d'une structure définie par l'utilisateur qui doit être déclarée à l'aide de la macro TAILQ_HEAD().

Création

Une file d'attente est dirigée par une structure définie par la macro TAILQ_HEAD(). Cette structure contient une paire de pointeurs, l'un vers le premier élément de la file d'attente et l'autre vers le dernier élément de la file d'attente. Les éléments sont doublement chaînés afin qu'un élément arbitraire puisse être supprimé sans parcourir la file d'attente. De nouveaux éléments peuvent être ajoutés à la file d'attente après un élément existant, avant un élément existant, au début de la file d'attente ou à la fin de la file d'attente. Une structure TAILQ_HEAD est déclarée comme suit :


TAILQ_HEAD(HEADNAME, TYPE) head;

où struct HEADNAME est la structure à définir, et struct TYPE est le type des éléments à lier dans la file d'attente. Un pointeur vers la tête de la file d'attente peut être déclaré ultérieurement comme suit :


struct HEADNAME *headp;

(Les noms head et headp sont sélectionnables par l'utilisateur.)

TAILQ_ENTRY() déclare une structure qui relie les éléments de la file d'attente.

TAILQ_HEAD_INITIALIZER() évalue à un initialiseur pour la file d'attente head.

TAILQ_INIT() initialise la file d'attente référencée par

TAILQ_EMPTY() évalue à vrai s'il n'y a aucun élément dans la file d'attente. head.

Insertion

TAILQ_INSERT_HEAD() insère le nouvel élément elm au début de la file d'attente.

TAILQ_INSERT_TAIL() insère le nouvel élément elm à la fin de la file d'attente.

TAILQ_INSERT_BEFORE() insère le nouvel élément elm avant l'élément listelm.

TAILQ_INSERT_AFTER() insère le nouvel élément elm après l'élément listelm.

Parcours

TAILQ_FIRST() renvoie le premier élément de la file d'attente, ou NULL si la file d'attente est vide.

TAILQ_LAST() renvoie le dernier élément de la file d'attente. Si la file d'attente est vide, la valeur renvoyée est NULL.

TAILQ_PREV() renvoie l'élément précédent dans la file d'attente, ou NULL si cet élément est le premier.

TAILQ_NEXT() renvoie l'élément suivant dans la file d'attente, ou NULL si cet élément est le dernier.

TAILQ_FOREACH() parcourt la file d'attente référencée par head dans le sens avant, en attribuant successivement chaque élément à var. var est mis à NULL si la boucle se termine normalement, ou s'il n'y avait aucun élément.

TAILQ_FOREACH_REVERSE() parcourt la file d'attente référencée par head dans le sens inverse, en attribuant successivement chaque élément à var.

Suppression

TAILQ_REMOVE() supprime l'élément elm de la file d'attente.

Autres fonctionnalités

TAILQ_CONCAT() concatène la file d'attente dirigée par head2 à la fin de celle dirigée par head1, supprimant toutes les entrées de la première.

VALEUR RENVOYÉE

TAILQ_EMPTY() renvoie une valeur non nulle si la file d'attente est vide, et zéro si la file d'attente contient au moins une entrée.

TAILQ_FIRST(), TAILQ_LAST(), TAILQ_PREV(), et TAILQ_NEXT() renvoient un pointeur vers la structure TYPE première, dernière, précédente ou suivante, respectivement.

TAILQ_HEAD_INITIALIZER() renvoie un initialiseur qui peut être assigné à la tête head de la file d'attente.

NORMES

BSD.

HISTORIQUE

4.4BSD.

MISE EN GARDE

TAILQ_FOREACH() et TAILQ_FOREACH_REVERSE() ne permettent pas la suppression ou la libération de var dans la boucle, car cela interférerait avec le parcours. TAILQ_FOREACH_SAFE() et TAILQ_FOREACH_REVERSE_SAFE(), qui sont présents sur les BSD mais pas dans glibc, corrigent cette limitation en permettant à var d'être retiré en toute sécurité de la liste et libéré à partir de la boucle sans interférer avec le parcours.

#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>
struct entry {
    int data;
    TAILQ_ENTRY(entry) entries;             /* File d'attente */
};
TAILQ_HEAD(tailhead, entry);
int
main(void)
{
    struct entry *n1, *n2, *n3, *np;
    struct tailhead head;                   /* Tête de la file d'attente */
    int i;
    TAILQ_INIT(&head);                      /* Initialiser la file */
    n1 = malloc(sizeof(struct entry));      /* Insertion au début */
    TAILQ_INSERT_HEAD(&head, n1, entries);
    n1 = malloc(sizeof(struct entry));      /* Insertion à la fin */
    TAILQ_INSERT_TAIL(&head, n1, entries);
    n2 = malloc(sizeof(struct entry));      /* Insertion après */
    TAILQ_INSERT_AFTER(&head, n1, n2, entries);
    n3 = malloc(sizeof(struct entry));      /* Insertion avant */
    TAILQ_INSERT_BEFORE(n2, n3, entries);
    TAILQ_REMOVE(&head, n2, entries);       /* Suppression */
    free(n2);
