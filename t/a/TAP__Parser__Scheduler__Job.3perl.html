TAP::Parser::Scheduler::Job(3perl) Guide du programmeur Perl TAP::Parser::Scheduler::Job(3perl)

NOM

TAP::Parser::Scheduler::Job - Un travail de test unique.

VERSION

Version 3.50

SYNTAXE

use TAP::Parser::Scheduler::Job;

DESCRIPTION

Représente un 'travail' de test unique.

MÉTHODES

Méthodes de classe

«new»

my $job = TAP::Parser::Scheduler::Job->new(
    $filename, $description
);

Étant donné le nom de fichier et la description d'un test sous forme de scalaires, renvoie un nouvel objet TAP::Parser::Scheduler::Job.

Méthodes d'instance

«on_finish»

$self->on_finish(\&method).

Enregistre une fermeture à appeler lorsque ce travail est détruit. Le rappel recevra l'objet "TAP::Parser::Scheduler::Job" comme unique argument.

«finish»

$self->finish;

Appelée lorsqu'un travail est terminé pour le déverrouiller. Si un rappel a été enregistré avec "on_finish", il l'appelle. Sinon, il ne fait rien.

Attributs

$self->filename;
$self->description;
$self->context;

Ce sont tous des « getters » qui renvoient les données définies pour ces attributs lors de la construction de l'objet.

«filename»

«description»

«context»

«as_array_ref»

Pour la compatibilité descendante dans les rappels.

«is_spinner»

$self->is_spinner;

Renvoie faux, indiquant qu'il s'agit d'un vrai travail plutôt que d'un 'spinner'. Les spinners sont renvoyés lorsque le planificateur a encore des travaux en attente mais ne peut pas en renvoyer un (en raison du verrouillage) pour le moment.
