TAP::Parser::Iterator(3perl) Guide du programmeur Perl TAP::Parser::Iterator(3perl)

NOM

TAP::Parser::Iterator - Classe de base pour les itérateurs de analyseur TAP

VERSION

Version 3.50

SYNOPIS

# pour sous-classer :
use TAP::Parser::Iterator ();
use base 'TAP::Parser::Iterator';
sub _initialize {
  # voir TAP::Object...
}
sub next_raw { ... }
sub wait     { ... }
sub exit     { ... }

DESCRIPTION

Ceci est une classe d'itérateur de base simple qui définit l'API de l'itérateur de TAP::Parser. Les itérateurs sont généralement créés à partir de TAP::Parser::SourceHandlers.

MÉTHODES

Méthodes de classe

"new"

Crée un itérateur. Fourni par TAP::Object.

Méthodes d'instance

"next"

while ( my $item = $iter->next ) { ... }

Itère à travers, bien sûr.

"next_raw"

Note : cette méthode est abstraite et doit être remplacée.

while ( my $item = $iter->next_raw ) { ... }

Itère sur l'entrée brute sans appliquer de correctifs pour une syntaxe d'entrée particulière.

"handle_unicode"

Si nécessaire, basculez le flux d'entrée pour gérer l'unicode. Cela n'a d'effet que pour les flux basés sur des descripteurs de fichiers.

L'implémentation par défaut ne fait rien.

"get_select_handles"

Retourne une liste de descripteurs de fichiers qui peuvent être utilisés en amont dans un appel select() pour signaler que cet itérateur est prêt. Les itérateurs qui ne sont pas basés sur des descripteurs de fichiers devraient retourner une liste vide.

L'implémentation par défaut ne fait rien.

"wait"

Note : cette méthode est abstraite et doit être remplacée.

my $wait_status = $iter->wait;

Retourne le statut "wait" pour cet itérateur.

"exit"

Note : cette méthode est abstraite et doit être remplacée.

my $wait_status = $iter->exit;

Retourne le statut "exit" pour cet itérateur.

SOUSCLASSEMENT

Veuillez consulter "SOUSCLASSEMENT" dans TAP::Parser pour un aperçu du sous-classement.

Vous devez remplacer les méthodes abstraites comme indiqué ci-dessus.

Exemple

TAP::Parser::Iterator::Array est probablement l'exemple le plus facile à suivre. Il n'y a pas grand intérêt à le répéter ici.
