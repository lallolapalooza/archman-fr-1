NOM

DESCRIPTION

Ces macros définissent et opèrent sur des files de fin doublement chaînées.

Dans les définitions de macros, TYPE est le nom d'une structure définie par l'utilisateur, qui doit contenir un champ de type TAILQ_ENTRY, nommé NAME. L'argument HEADNAME est le nom d'une structure définie par l'utilisateur qui doit être déclarée en utilisant la macro TAILQ_HEAD().

Création

Une file de fin est dirigée par une structure définie par la macro TAILQ_HEAD(). Cette structure contient une paire de pointeurs, l'un vers le premier élément de la file et l'autre vers le dernier élément de la file. Les éléments sont doublement chaînés de sorte qu'un élément arbitraire puisse être retiré sans parcourir la file. De nouveaux éléments peuvent être ajoutés à la file après un élément existant, avant un élément existant, en tête de la file ou à la fin de la file. Une structure TAILQ_HEAD est déclarée comme suit :


TAILQ_HEAD(HEADNAME, TYPE) head;

où struct HEADNAME est la structure à définir, et struct TYPE est le type des éléments à lier dans la file. Un pointeur vers la tête de la file peut ensuite être déclaré comme :


struct HEADNAME *headp;

(Les noms head et headp sont sélectionnables par l'utilisateur.)

TAILQ_ENTRY() déclare une structure qui relie les éléments de la file.

TAILQ_HEAD_INITIALIZER() évalue à un initialiseur pour la file head.

TAILQ_INIT() initialise la file référencée par

TAILQ_EMPTY() évalue à vrai s'il n'y a pas d'éléments dans la file. head.

Insertion

TAILQ_INSERT_HEAD() insère le nouvel élément elm en tête de la file.

TAILQ_INSERT_TAIL() insère le nouvel élément elm en fin de la file.

TAILQ_INSERT_BEFORE() insère le nouvel élément elm avant l'élément listelm.

TAILQ_INSERT_AFTER() insère le nouvel élément elm après l'élément listelm.

Parcours

TAILQ_FIRST() renvoie le premier élément de la file, ou NULL si la file est vide.

TAILQ_LAST() renvoie le dernier élément de la file. Si la file est vide, la valeur de retour est NULL.

TAILQ_PREV() renvoie l'élément précédent de la file, ou NULL si cet élément est le premier.

TAILQ_NEXT() renvoie l'élément suivant de la file, ou NULL si cet élément est le dernier.

TAILQ_FOREACH() parcourt la file référencée par head dans le sens avant, attribuant à tour de rôle chaque élément à var. var est mis à NULL si la boucle se termine normalement, ou s'il n'y avait aucun élément.

TAILQ_FOREACH_REVERSE() parcourt la file référencée par head dans le sens inverse, attribuant à tour de rôle chaque élément à var.

Suppression

TAILQ_REMOVE() retire l'élément elm de la file.

Autres fonctionnalités

TAILQ_CONCAT() concatène la file dirigée par head2 à la fin de celle dirigée par head1, en retirant toutes les entrées de la première.

VALEUR DE RETOUR

TAILQ_EMPTY() renvoie non nul si la file est vide, et zéro si la file contient au moins une entrée.

TAILQ_FIRST(), TAILQ_LAST(), TAILQ_PREV(), et TAILQ_NEXT() renvoient un pointeur vers la structure TYPE première, dernière, précédente ou suivante, respectivement.

TAILQ_HEAD_INITIALIZER() renvoie un initialiseur qui peut être assigné à la file head.

NORMES

BSD.

HISTORIQUE

4.4BSD.

ATTENTION

TAILQ_FOREACH() et TAILQ_FOREACH_REVERSE() ne permettent pas de retirer ou de libérer var pendant la boucle, car cela interférerait avec le parcours. TAILQ_FOREACH_SAFE() et TAILQ_FOREACH_REVERSE_SAFE(), qui sont présents sur les systèmes BSD mais ne sont pas présents dans glibc, corrigent cette limitation en permettant de retirer et de libérer var en toute sécurité de la liste depuis la boucle sans interférer avec le parcours.

EXEMPLES

#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>
struct entry {
    int data;
    TAILQ_ENTRY(entry) entries;             /* File de fin */
};
TAILQ_HEAD(tailhead, entry);
int
main(void)
{
    struct entry *n1, *n2, *n3, *np;
    struct tailhead head;                   /* Tête de la file de fin */
    int i;
    TAILQ_INIT(&head);                      /* Initialiser la file */
    n1 = malloc(sizeof(struct entry));      /* Insertion en tête */
    TAILQ_INSERT_HEAD(&head, n1, entries);
    n1 = malloc(sizeof(struct entry));      /* Insertion en fin */
    TAILQ_INSERT_TAIL(&head, n1, entries);
    n2 = malloc(sizeof(struct entry));      /* Insertion après */
    TAILQ_INSERT_AFTER(&head, n1, n2, entries);
    n3 = malloc(sizeof(struct entry));      /* Insertion avant */
    TAILQ_INSERT_BEFORE(n2, n3, entries);
    TAILQ_REMOVE(&head, n2, entries);       /* Suppression */
    free(n2);
                                            /* Parcours avant */
    i = 0;
    TAILQ_FOREACH(np, &head, entries)
        np->data = i++;
                                            /* Parcours inverse */
    TAILQ_FOREACH_REVERSE(np, &head, tailhead, entries)
        printf("%i\n", np->data);
                                            /* Suppression de file de fin */
    n
