DESCRIPTION

Ces macros définissent et opèrent sur des files de queues doublement chaînées.

Dans les définitions des macros, TYPE est le nom d'une structure définie par l'utilisateur, qui doit contenir un champ de type TAILQ_ENTRY, nommé NOM. L'argument NOM_QUEUE est le nom d'une structure définie par l'utilisateur qui doit être déclarée en utilisant la macro TAILQ_HEAD().

Création

Une file de queues est dirigée par une structure définie par la macro TAILQ_HEAD(). Cette structure contient une paire de pointeurs, l'un vers le premier élément de la file et l'autre vers le dernier élément de la file. Les éléments sont doublement chaînés afin qu'un élément arbitraire puisse être supprimé sans parcourir la file. De nouveaux éléments peuvent être ajoutés à la file après un élément existant, avant un élément existant, en tête de la file, ou à la fin de la file. Une structure TAILQ_HEAD est déclarée comme suit :


TAILQ_HEAD(NOM_QUEUE, TYPE) queue;

où struct NOM_QUEUE est la structure à définir, et struct TYPE est le type des éléments à lier dans la file. Un pointeur vers la tête de la file peut ensuite être déclaré comme :


struct NOM_QUEUE *pointeur_queue;

(Les noms queue et pointeur_queue sont sélectionnables par l'utilisateur.)

TAILQ_ENTRY() déclare une structure qui connecte les éléments de la file.

TAILQ_HEAD_INITIALIZER() évalue à un initialiseur pour la file queue.

TAILQ_INIT() initialise la file référencée par

TAILQ_EMPTY() évalue à vrai s'il n'y a pas d'éléments dans la file. queue.

Insertion

TAILQ_INSERT_HEAD() insère le nouvel élément elt en tête de la file.

TAILQ_INSERT_TAIL() insère le nouvel élément elt à la fin de la file.

TAILQ_INSERT_BEFORE() insère le nouvel élément elt avant l'élément elt_liste.

TAILQ_INSERT_AFTER() insère le nouvel élément elt après l'élément elt_liste.

Parcours

TAILQ_FIRST() retourne le premier élément de la file, ou NULL si la file est vide.

TAILQ_LAST() retourne le dernier élément de la file. Si la file est vide, la valeur de retour est NULL.

TAILQ_PREV() retourne l'élément précédent dans la file, ou NULL si cet élément est le premier.

TAILQ_NEXT() retourne l'élément suivant dans la file, ou NULL si cet élément est le dernier.

TAILQ_FOREACH() parcourt la file référencée par queue dans le sens avant, assignant chaque élément tour à tour à var. var est mis à NULL si la boucle se termine normalement, ou s'il n'y avait aucun élément.

TAILQ_FOREACH_REVERSE() parcourt la file référencée par queue dans le sens inverse, assignant chaque élément tour à tour à var.

Suppression

TAILQ_REMOVE() supprime l'élément elt de la file.

Autres fonctionnalités

TAILQ_CONCAT() concatène la file dirigée par queue2 à la fin de celle dirigée par queue1, supprimant toutes les entrées de la première.

VALEUR DE RETOUR

TAILQ_EMPTY() retourne non nul si la file est vide, et zéro si la file contient au moins une entrée.

TAILQ_FIRST(), TAILQ_LAST(), TAILQ_PREV(), et TAILQ_NEXT() retournent un pointeur vers la structure TYPE première, dernière, précédente ou suivante, respectivement.

TAILQ_HEAD_INITIALIZER() retourne un initialiseur qui peut être assigné à la file queue.

NORMES

BSD.

HISTORIQUE

4.4BSD.

MISE EN GARDE

TAILQ_FOREACH() et TAILQ_FOREACH_REVERSE() ne permettent pas que var soit supprimé ou libéré dans la boucle, car cela interférerait avec le parcours. TAILQ_FOREACH_SAFE() et TAILQ_FOREACH_REVERSE_SAFE(), qui sont présents sur les BSD mais ne sont pas présents dans glibc, corrigent cette limitation en permettant à var d'être supprimé en toute sécurité de la liste et libéré à partir de la boucle sans interférer avec le parcours.

EXEMPLES

#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>
struct entry {
    int data;
    TAILQ_ENTRY(entry) entries;             /* File de queues */
};
TAILQ_HEAD(tailhead, entry);
int
main(void)
{
    struct entry *n1, *n2, *n3, *np;
    struct tailhead head;                   /* Tête de la file de queues */
    int i;
    TAILQ_INIT(&head);                      /* Initialisation de la file */
    n1 = malloc(sizeof(struct entry));      /* Insertion en tête */
    TAILQ_INSERT_HEAD(&head, n1, entries);
    n1 = malloc(sizeof(struct entry));      /* Insertion à la fin */
    TAILQ_INSERT_TAIL(&head, n1, entries);
    n2 = malloc(sizeof(struct entry));      /* Insertion après */
    TAILQ_INSERT_AFTER(&head, n1, n2, entries);
    n3 = malloc(sizeof(struct entry));      /* Insertion avant */
    TAILQ_INSERT_BEFORE(n2, n3, entries);
    TAILQ_REMOVE(&head, n2, entries);       /* Suppression */
    free(n2);
                                            /* Parcours avant */
    i = 0;
    TAILQ_FOREACH(np, &head, entries)
        np->data = i++;
                                            /* Parcours inverse */
    TAILQ_FOREACH_REVERSE(np, &head, tailhead, entries)
        printf("%i\n", np->data);
                                            /* Suppression de la file de queues */

TAILQ

TAILQ

TAILQ

TAILQ est une structure de données utilisée pour gérer une file d'éléments, généralement sous forme de liste chaînée.

Les fonctions fournies dans cette section permettent l'insertion, la suppression et la gestion des éléments dans une file.

Les fonctions sont implémentées en C et font partie de la documentation des pages de manuel Linux.

DESCRIPTION

La macro TAILQ_INIT initialise une file d'attente doublement chaînée. La macro TAILQ_ENTRY définit un élément de liste doublement chaînée. La macro TAILQ_FIRST renvoie le premier élément de la file. La macro TAILQ_NEXT renvoie l'élément suivant dans la file. La macro TAILQ_INSERT_TAIL insère un nouvel élément à la fin de la file. La macro TAILQ_REMOVE supprime un élément de la file. La macro TAILQ_FOREACH_SAFE itère sur les éléments d'une file, en fournissant un moyen sûr de supprimer des éléments pendant l'itération.

    n1 = TAILQ_FIRST(&head);
    while (n1 != NULL) {
        n2 = TAILQ_NEXT(n1, entries);
        free(n1);
        n1 = n2;
    }
    TAILQ_INIT(&head);
    exit(EXIT_SUCCESS);
