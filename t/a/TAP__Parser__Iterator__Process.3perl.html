TAP::Parser::Iterator::Process(3perl) Guide de référence du programmeur Perl TAP::Parser::Iterator::Process(3perl)

NOM

TAP::Parser::Iterator::Process - Itérateur pour les sources TAP basées sur des processus

VERSION

Version 3.50

SYNOPSIS

use TAP::Parser::Iterator::Process;
my %args = (
 command  => ['python', 'setup.py', 'test'],
 merge    => 1,
 setup    => sub { ... },
 teardown => sub { ... },
);
my $it   = TAP::Parser::Iterator::Process->new(\%args);
my $line = $it->next;

DESCRIPTION

Ceci est un wrapper simple pour exécuter des processus externes, utilisé par TAP::Parser. Sauf si vous écrivez un plugin ou une sous-classe, vous n'aurez probablement pas besoin d'utiliser ce module directement.

MÉTHODES

Méthodes de classe

"new"

Crée un itérateur. Attend un argument contenant un hash de la forme :

command  => \@command_to_execute
merge    => $tentative_merge_stderr_et_stdout?
setup    => $callback_pour_configurer_la_commande
teardown => $callback_pour_terminer_la_commande

Tente d'utiliser IPC::Open3 & IO::Select pour communiquer avec le processus lancé s'ils sont disponibles. Reviendra à open().

Méthodes d'instance

"next"

Itère à travers la sortie du processus, bien sûr.

"next_raw"

Itère sur l'entrée brute sans appliquer de corrections pour une syntaxe d'entrée particulière.

"wait"

Obtient le statut d'attente pour le processus de cet itérateur.

"exit"

Obtient le statut de sortie pour le processus de cet itérateur.

"handle_unicode"

Met à niveau le flux d'entrée pour gérer UTF8.

"get_select_handles"

Retourne une liste de descripteurs de fichiers qui peuvent être utilisés en amont dans un appel select() pour signaler que cet itérateur est prêt. Les itérateurs qui ne sont pas basés sur des descripteurs retournent une liste vide.

ATTRIBUTION

Initialement copié de Test::Harness.
