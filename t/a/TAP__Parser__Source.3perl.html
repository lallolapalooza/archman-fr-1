TAP::Parser::Source(3perl) Guide de programmation Perl TAP::Parser::Source(3perl)

NOM

TAP::Parser::Source - source TAP et métadonnées s'y rapportant

VERSION

Version 3.50

SYNOPSIS

use TAP::Parser::Source;
my $source = TAP::Parser::Source->new;
$source->raw( \'référence vers la source TAP brute' )
       ->config( \%config )
       ->merge( $booléen )
       ->switches( \@switches )
       ->test_args( \@args )
       ->assemble_meta;
do { ... } if $source->meta->{is_file};
# voir assemble_meta pour la liste complète des données disponibles

DESCRIPTION

Une source TAP est quelque chose qui produit un flux TAP pour que le parser puisse le consommer, comme un fichier exécutable, un fichier texte, une archive, un descripteur d'E/S, une base de données, etc. "TAP::Parser::Source" encapsule ces sources brutes et fournit des métadonnées utiles à leur sujet. Elles sont utilisées par TAP::Parser::SourceHandlers, qui fait ce qui est nécessaire pour produire & capturer un flux TAP depuis la source brute, et l'empaqueter dans un TAP::Parser::Iterator pour que le parser puisse le consommer.

À moins que vous n'écriviez un nouveau TAP::Parser::SourceHandler, un plugin ou que vous ne sous-classiez TAP::Parser, vous n'aurez probablement pas besoin d'utiliser ce module directement.

MÉTHODES

Méthodes de classe

"new"

my $source = TAP::Parser::Source->new;

Retourne un nouvel objet "TAP::Parser::Source".

Méthodes d'instance

"raw"

my $raw = $source->raw;
$source->raw( $quelque_valeur );

Accesseur/mutateur en chaînage pour la source TAP brute. C'est une référence, car elle peut contenir de grandes quantités de données (par ex. TAP brut).

"meta"

my $meta = $source->meta;
$source->meta({ %quelque_valeur });

Accesseur/mutateur en chaînage pour les métadonnées concernant la source. Cela vaut par défaut un hashref vide. Voir "assemble_meta" pour plus d'informations.

"has_meta"

Vrai si la source a des métadonnées.

"config"

my $config = $source->config;
$source->config({ %quelque_valeur });

Accesseur/mutateur en chaînage pour la configuration de la source, si elle a été fournie par l'utilisateur. Son utilisation dépend de vous. Cela vaut par défaut un hashref vide. Voir "config_for" pour plus d'informations.

"merge"

my $merge = $source->merge;
$source->config( $bool );

Accesseur/mutateur en chaînage pour le drapeau qui dicte si STDOUT et STDERR doivent être fusionnés (lorsque c'est pertinent). La valeur par défaut est undef.

"switches"

my $switches = $source->switches;
$source->config([ @switches ]);

Accesseur/mutateur en chaînage pour la liste des options de ligne de commande qui devraient être passées à la source (lorsque c'est pertinent). La valeur par défaut est undef.

"test_args"

my $test_args = $source->test_args;
$source->config([ @test_args ]);

Accesseur/mutateur en chaînage pour la liste des arguments de ligne de commande qui devraient être passés à la source (lorsque c'est pertinent). La valeur par défaut est undef.

"assemble_meta"

my $meta = $source->assemble_meta;

Collecte les métadonnées de la source "brute", les stocke dans "meta" et les retourne sous forme de hashref. Ceci est fait afin que les TAP::Parser::SourceHandlers n'aient pas à répéter les vérifications courantes. Actuellement, cela inclut :

  is_scalar => $bool,
  is_hash   => $bool,
  is_array  => $bool,
  # pour les scalaires :
  length => $n
  has_newlines => $bool
  # seulement si le scalaire ressemble à un nom de fichier
  is_file => $bool,
  is_dir  => $bool,
  is_symlink => $bool,
  file => {
      # seulement si le scalaire ressemble à un nom de fichier
      basename => $string, # incluant l'extension
      dir      => $string,
      ext      => $string,
      lc_ext   => $string,
      # vérifications système
      exists  => $bool,
      stat    => [ ... ], # perldoc -f stat
      empty   => $bool,
      size    => $n,
      text    => $bool,
      binary  => $bool,
      read    => $bool,
      write   => $bool,
      execute => $bool,
      setuid  => $bool,
      setgid  => $bool,
      sticky  => $bool,
      is_file => $bool,
      is_dir  => $bool,
      is_symlink => $bool,
      # seulement si le fichier est un lien symbolique
      lstat      => [ ... ], # perldoc -f lstat
      # seulement si le fichier est un fichier texte lisible
      shebang => $first_line,
  }
# pour les tableaux :
size => $n,

"shebang"

Obtenir la ligne shebang pour un fichier script.

my $shebang = TAP::Parser::Source->shebang( $un_script );

Peut être appelée comme méthode de classe

"config_for"

my $config = $source->config_for( $classe );

Retourne la configuration "config" pour la $classe donnée. Les noms de classe peuvent être complètement qualifiés ou abrégés, par exemple :

# ces lignes sont équivalentes
$source->config_for( 'Perl' );
$source->config_for( 'TAP::Parser::SourceHandler::Perl' );

Si une $classe complètement qualifiée est fournie, sa version abrégée est vérifiée en premier.
