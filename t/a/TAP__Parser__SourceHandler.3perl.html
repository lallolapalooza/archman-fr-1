TAP::Parser::SourceHandler(3perl) Guide du programmeur Perl TAP::Parser::SourceHandler(3perl)

NOM

TAP::Parser::SourceHandler - Classe de base pour les gestionnaires de source TAP

VERSION

Version 3.50

SYNOPSIS

# classe abstraite - ne pas utiliser directement !
# voir TAP::Parser::IteratorFactory pour l'utilisation générale
# doit être sous-classé pour être utilisé
package MySourceHandler;
use base 'TAP::Parser::SourceHandler';
sub can_handle    { return $level_de_confiance }
sub make_iterator { return $iterateur }
# voir l'exemple ci-dessous pour plus de détails

DESCRIPTION

Ceci est une classe de base abstraite pour les gestionnaires de source TAP::Parser / gestionnaires.

Un "TAP::Parser::SourceHandler" fait tout ce qui est nécessaire pour produire et capturer un flux TAP à partir de la source *brute*, et l'empaqueter dans un TAP::Parser::Iterator pour que le parseur puisse le consommer.

"SourceHandlers" doivent implémenter l'interface de *détection et de gestion de source* utilisée par TAP::Parser::IteratorFactory. Avec 2 méthodes, l'interface est assez simple : "can_handle" et "make_source".

Sauf si vous écrivez un nouveau TAP::Parser::SourceHandler, un plugin, ou que vous sous-classez TAP::Parser, vous n'aurez probablement pas besoin d'utiliser ce module directement.

MÉTHODES

Méthodes de classe

"can_handle"

Méthode abstraite.

my $vote = $classe->can_handle( $source );

$source est un TAP::Parser::Source.

Retourne un nombre entre 0 et 1 reflétant la confiance avec laquelle la source brute peut être traitée. Par exemple, 0 signifie que la source ne peut pas la traiter, 0.5 signifie qu'elle pourrait être capable de le faire, et 1 signifie qu'elle le peut définitivement. Voir "detect_source" dans TAP::Parser::IteratorFactory pour plus de détails sur la façon dont cela est utilisé.

"make_iterator"

Méthode abstraite.

my $iterateur = $classe->make_iterator( $source );

$source est un TAP::Parser::Source.

Retourne un nouvel objet TAP::Parser::Iterator à utiliser par le TAP::Parser. "croak" en cas d'erreur.

SOUSCLASSEMENT

Veuillez consulter "SUBCLASSING" dans TAP::Parser pour un aperçu du sous-classement, et l'une des sous-classes qui accompagnent ce module comme exemple. Ce qui suit est un bref aperçu.

Commencez par vous familiariser avec TAP::Parser::Source et TAP::Parser::IteratorFactory. TAP::Parser::SourceHandler::RawTAP est la sous-classe la plus facile à utiliser comme exemple.

Il est important de souligner que si vous souhaitez que votre sous-classe soit automatiquement utilisée par TAP::Parser, vous devrez vous assurer qu'elle est chargée d'une manière ou d'une autre. Si vous utilisez prove, vous pouvez écrire un plugin App::Prove. Si vous utilisez TAP::Parser ou TAP::Harness directement (par exemple, via un script personnalisé, ExtUtils::MakeMaker ou Module::Build), vous pouvez utiliser l'option "config" qui amènera "load_sources" dans TAP::Parser::IteratorFactory à charger votre sous-classe).

N'oubliez pas d'enregistrer votre classe avec "register_handler" dans TAP::Parser::IteratorFactory.

Exemple

package MySourceHandler;
use strict;
use MySourceHandler; # voir TAP::Parser::SourceHandler
use TAP::Parser::IteratorFactory;
use base 'TAP::Parser::SourceHandler';
TAP::Parser::IteratorFactory->register_handler( __PACKAGE__ );
sub can_handle {
    my ( $class, $src ) = @_;
    my $meta   = $src->meta;
    my $config = $src->config_for( $class );
    if ($config->{accept_all}) {
        return 1.0;
    } elsif (my $file = $meta->{file}) {
        return 0.0 unless $file->{exists};
        return 1.0 if $file->{lc_ext} eq '.tap';
        return 0.9 if $file->{shebang} && $file->{shebang} =~ /^#!.+tap/;
        return 0.5 if $file->{text};
        return 0.1 if $file->{binary};
    } elsif ($meta->{scalar}) {
        return 0.8 if $$raw_source_ref =~ /\d\.\.\d/;
        return 0.6 if $meta->{has_newlines};
    } elsif ($meta->{array}) {
        return 0.8 if $meta->{size} < 5;
        return 0.6 if $raw_source_ref->[0] =~ /foo/;
        return 0.5;
    } elsif ($meta->{hash}) {
        return 0.6 if $raw_source_ref->{foo};
        return 0.2;
    }
    return 0;
}
sub make_iterator {
    my ($class, $source) = @_;
    # c'est ici que vous manipulez la source et
    # capturez le flux TAP dans un itérateur
    # soit choisissez un TAP::Parser::Iterator::* soit écrivez le vôtre...
    my $iterateur = TAP::Parser::Iterator::Array->new([ 'foo', 'bar' ]);
    return $iterateur;
}
1;
