NOM

TAP::Formatter::Color - Exécute des scripts de test Perl avec couleur

VERSION

Version 3.50

DESCRIPTION

Notez que ce système d'exécution est *expérimental*. Vous pourriez ne pas aimer les couleurs que j'ai choisies et je n'ai pas encore fourni de moyen facile de les remplacer.

Ce système d'exécution de tests est le même que TAP::Harness, mais les résultats des tests sont affichés en couleur. Les tests réussis sont affichés en vert. Les tests échoués sont en rouge. Les tests ignorés sont bleus sur fond blanc et les tests TODO sont affichés en blanc.

Si Term::ANSIColor ne peut pas être trouvé (et Win32::Console::ANSI si en cours d'exécution sous Windows), les tests seront exécutés sans couleur.

SYNOPIS

use TAP::Formatter::Color;
my $harness = TAP::Formatter::Color->new( \%args );
$harness->runtests(@tests);

MÉTHODES

Méthodes de classe

"new"

Le constructeur retourne un nouvel objet "TAP::Formatter::Color". Si Term::ANSIColor n'est pas installé, retourne undef.

"can_color"

Test::Formatter::Color->can_color()

Retourne une valeur booléenne indiquant si ce module peut réellement générer une sortie colorée. Ce sera faux s'il n'a pas pu charger les modules nécessaires pour la plateforme actuelle.

"set_color"

Définit la couleur de sortie.
