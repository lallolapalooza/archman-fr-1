TAP::Parser::SourceHandler::Handle(3perl) Guide du programmeur Perl TAP::Parser::SourceHandler::Handle(3perl)

NOM

TAP::Parser::SourceHandler::Handle - Diffuse du TAP à partir d'un IO::Handle ou d'un GLOB.

VERSION

Version 3.50

SYNOPSIS

use TAP::Parser::Source;
use TAP::Parser::SourceHandler::Executable;
my $source = TAP::Parser::Source->new->raw( \*TAP_FILE );
$source->assemble_meta;
my $class = 'TAP::Parser::SourceHandler::Handle';
my $vote  = $class->can_handle( $source );
my $iter  = $class->make_iterator( $source );

DESCRIPTION

Ceci est une classe TAP::Parser::SourceHandler pour le *TAP brut stocké dans un Handle IO*. Elle a 2 tâches :

1. Déterminer si le TAP::Parser::Source qu'elle reçoit est un IO::Handle ou un GLOB contenant une sortie TAP brute ("can_handle").

2. Créer un itérateur pour les IO::Handle et les globs ("make_iterator").

À moins que vous n'écriviez un plugin ou que vous n'héritiez de TAP::Parser, vous n'aurez probablement pas besoin d'utiliser ce module directement.

MÉTHODES

Méthodes de classe

"can_handle"

my $vote = $class->can_handle( $source );

Jette les votes suivants :

0.9 si $source est un IO::Handle
0.8 si $source est un glob

"make_iterator"

my $iterator = $class->make_iterator( $source );

Retourne un nouveau TAP::Parser::Iterator::Stream pour la source.

"iterator_class"

La classe de l'itérateur à utiliser, à redéfinir si vous sous-classez. Par défaut, TAP::Parser::Iterator::Stream.

SOUS-CLASSEMENT

Veuillez consulter "SUBCLASSING" dans TAP::Parser pour un aperçu du sous-classement.
