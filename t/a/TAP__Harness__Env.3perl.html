TAP::Harness::Env(3perl) Guide de référence pour programmeurs Perl TAP::Harness::Env(3perl)

NOM

TAP::Harness::Env - Analyse les variables d'environnement liées au harnais lorsque cela est approprié

VERSION

Version 3.50

SYNOPSIS

my $harness = TAP::Harness::Env->create(\%extra_args)

DESCRIPTION

Ce module implémente les variables d'environnement que Test::Harness utilise avec TAP::Harness, et instancie la classe appropriée avec les arguments appropriés.

MÉTHODES

•
create( \%args )

Cette fonction lit l'environnement et génère une table d'arguments appropriée à partir de celui-ci. Si des arguments sont fournis dans %extra_args, ceux-ci remplaceront les valeurs par défaut de l'environnement. Elle accepte "harness_class" (qui par défaut est "TAP::Harness"), et tout argument que la classe de harnais accepte.

VARIABLES D'ENVIRONNEMENT

"HARNESS_PERL_SWITCHES"
Définir ceci ajoute des commutateurs de ligne de commande Perl à chaque fichier de test exécuté.

Par exemple, "HARNESS_PERL_SWITCHES=-T" activera le mode taint. "HARNESS_PERL_SWITCHES=-MDevel::Cover" exécutera "Devel::Cover" pour chaque test.

"HARNESS_VERBOSE"
Si vrai, "TAP::Harness" affichera les résultats détaillés de l'exécution de ses tests.
"HARNESS_SUBCLASS"
Spécifie une sous-classe de TAP::Harness à utiliser à la place de TAP::Harness.
"HARNESS_OPTIONS"
Fournit des options supplémentaires au harnais. Les options actuellement supportées sont :
"j<n>"
Exécute <n> (par défaut 9) travaux parallèles.
"c"
Essaye de coloriser la sortie. Voir "new" dans TAP::Formatter::Base.
"a<fichier.tgz>"
Utilisera TAP::Harness::Archive comme classe de harnais, et sauvegardera le TAP dans "fichier.tgz"
"fPackage-With-Dashes"
Définit le formatter_class du harnais en cours d'exécution. Puisque "HARNESS_OPTIONS" est séparé par ":", nous utilisons "-" à la place.

Plusieurs options peuvent être séparées par des deux-points :

HARNESS_OPTIONS=j9:c make test
"HARNESS_TIMER"
Définir ceci à vrai fera afficher au harnais le nombre de millisecondes que chaque test a pris. Vous pouvez également utiliser le commutateur "--timer" de prove.
"HARNESS_COLOR"
Tenter de produire une sortie colorée.
"HARNESS_IGNORE_EXIT"
Si défini à une valeur vraie, cela indique à "TAP::Parser" d'ignorer le statut de sortie et d'attente des scripts de test.
