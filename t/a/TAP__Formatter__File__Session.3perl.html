NOM

TAP::Formatter::File::Session - délégué de sortie pour la sortie fichier

VERSION

Version 3.50

DESCRIPTION

Ceci fournit un formatage de sortie orienté fichier pour TAP::Harness. Il est particulièrement important lors de l'exécution de tests parallèles, car il garantit que les résultats des tests ne sont pas entrelacés, même lorsqu'ils sont exécutés de manière verbeuse.

MÉTHODES

result

Stocke les résultats pour une sortie ultérieure, tous ensemble.

close_test

Lorsque le fichier de test se termine, affiche le résumé, tous ensemble.
