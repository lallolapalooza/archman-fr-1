TAP::Parser::Multiplexer(3perl) Guide de référence des programmeurs Perl TAP::Parser::Multiplexer(3perl)

NOM

TAP::Parser::Multiplexer - Multiplexer plusieurs TAP::Parsers

VERSION

Version 3.50

SYNOPSIS

use TAP::Parser::Multiplexer;
my $mux = TAP::Parser::Multiplexer->new;
$mux->add( $parser1, $stash1 );
$mux->add( $parser2, $stash2 );
while ( my ( $parser, $stash, $result ) = $mux->next ) {
    # faire des choses
}

DESCRIPTION

"TAP::Parser::Multiplexer" recueille des entrées provenant de plusieurs TAP::Parsers. Il appelle internement select sur les descripteurs de fichiers d'entrée de ces analyseurs pour attendre qu'un ou plusieurs d'entre eux aient des entrées disponibles.

Voir TAP::Harness pour un exemple d'utilisation.

MÉTHODES

Méthodes de classe

"new"

my $mux = TAP::Parser::Multiplexer->new;

Retourne un nouvel objet "TAP::Parser::Multiplexer".

Méthodes d'instance

"add"

$mux->add( $parser, $stash );

Ajoute un TAP::Parser au multiplexeur. $stash est une référence opaque optionnelle qui sera retournée par "next" avec le parser et le prochain résultat.

"parsers"

my $count   = $mux->parsers;

Retourne le nombre de parsers. Les parsers sont retirés du multiplexeur lorsque leur entrée est épuisée.

"next"

Retourne un résultat du prochain parser disponible. Retourne une liste contenant le parser d'où provient le résultat, le stash qui correspond à ce parser et le résultat.

my ( $parser, $stash, $result ) = $mux->next;

Si $result est indéfini, le parser correspondant a atteint la fin de son entrée (et sera automatiquement retiré du multiplexeur).

Lorsque tous les parsers sont épuisés, une liste vide sera retournée.

if ( my ( $parser, $stash, $result ) = $mux->next ) {
    if ( ! defined $result ) {
        # Fin de ce parser
    }
    else {
        # Traiter le résultat
    }
}
else {
    # Tous les parsers sont terminés
}
