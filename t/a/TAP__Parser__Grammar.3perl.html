TAP::Parser::Grammar(3perl) Guide de référence des programmeurs Perl TAP::Parser::Grammar(3perl)

NOM

TAP::Parser::Grammar - Une grammaire pour le protocole Test Anything Protocol.

VERSION

Version 3.50

SYNOPSIS

use TAP::Parser::Grammar;
my $grammar = $self->make_grammar({
  iterator => $tap_parser_iterator,
  parser   => $tap_parser,
  version  => 12,
});
my $result = $grammar->tokenize;

DESCRIPTION

"TAP::Parser::Grammar" analyse en tokens les lignes d'un TAP::Parser::Iterator et construit des sous-classes TAP::Parser::Result pour représenter les tokens.

N'essayez pas d'utiliser cette classe directement. Cela n'aurait pas de sens. Elle est principalement présente pour garantir que nous pourrons avoir des grammaires interchangeables lorsque TAP sera étendu à l'avenir (de plus, ce code encombrait déjà l'analyseur).

MÉTHODES

Méthodes de classe

"new"

my $grammar = TAP::Parser::Grammar->new({
    iterator => $iterator,
    parser   => $parser,
    version  => $version,
});

Retourne un objet grammaire TAP::Parser qui analysera le flux TAP depuis l'itérateur spécifié. Les arguments "iterator" et "parser" sont requis. Si "version" n'est pas défini, il prend par défaut la valeur 12 (voir "set_version" pour plus de détails).

Méthodes d'instance

"set_version"

$grammar->set_version(13);

Indique à la grammaire quelle version de la syntaxe TAP supporter. La version la plus basse supportée est 12. Bien que 'TAP version' ne soit pas une syntaxe valide en version 12, elle est acceptée afin que les nombres de version plus élevés puissent être analysés.

"tokenize"

my $token = $grammar->tokenize;

Cette méthode retournera un objet TAP::Parser::Result représentant la ligne TAP actuelle.

"token_types"

my @types = $grammar->token_types;

Retourne les différents types de tokens que cette grammaire peut analyser.

"syntax_for"

my $syntax = $grammar->syntax_for($token_type);

Retourne une expression régulière pré-compilée qui correspondra à un morceau de TAP correspondant au type de token. Par exemple (sans que vous deviez vraiment y prêter attention, "$grammar->syntax_for('comment')" retournera "qr/^#(.*)/".

"handler_for"

my $handler = $grammar->handler_for($token_type);

Retourne une référence de code qui, lorsqu'on lui passe une ligne TAP appropriée, retourne le token analysé correspondant à cette ligne. Par conséquent, la boucle d'analyse TAP de base ressemble à ceci :

my @tokens;
my $grammar = TAP::Grammar->new;
LINE: while ( defined( my $line = $parser->_next_chunk_of_tap ) ) {
    for my $type ( $grammar->token_types ) {
        my $syntax  = $grammar->syntax_for($type);
        if ( $line =~ $syntax ) {
            my $handler = $grammar->handler_for($type);
            push @tokens => $grammar->$handler($line);
            next LINE;
        }
    }
    push @tokens => $grammar->_make_unknown_token($line);
}

GRAMMAIRE TAP

NOTE : Cette grammaire est légèrement obsolète. Il y a encore des discussions à son sujet et une nouvelle sera fournie lorsque les choses seront mieux définies.

TAP::Parser n'utilise pas de grammaire formelle car TAP est essentiellement un protocole basé sur des flux. En fait, il est tout à fait légal d'avoir un flux infini. Pour la même raison que nous n'appliquons pas de regex aux flux, nous n'utilisons pas de grammaire formelle ici. Au lieu de cela, nous analysons le TAP ligne par ligne.

Aux fins de compatibilité ascendante, tout résultat qui ne correspond pas à la grammaire suivante est actuellement appelé TAP::Parser::Result::Unknown. Ce n'est *pas* une erreur d'analyse.

Une grammaire formelle ressemblerait à ceci :

(*
    Pour l'instant, je triche sur l'EBNF en autorisant
    certains termes à être définis par des classes de caractères POSIX en
    utilisant la syntaxe suivante :
      chiffre ::= [:chiffre:]
    Autant que je sache, ce n'est pas de l'EBNF valide.  Poursuivez-moi.  Je
    ne savais pas comment écrire "caractère" autrement (problèmes Unicode).
    Suggestions bienvenues.
*)
tap            ::= version? { commentaire | inconnu } plan_debut lignes
                   |
                   lignes plan_fin {commentaire}
version        ::= 'TAP version ' entier_positif {entier_positif} "\n"
plan_debut   ::= plan directive_saut? "\n"
plan_fin       ::= plan "\n"
plan           ::= '1..' entier_non_negatif
lignes         ::= ligne {ligne}
ligne          ::= (commentaire | test | inconnu | abandon ) "\n"
test           ::= statut entier_positif? description? directive?
statut         ::= 'not '? 'ok '
description    ::= (caractere - (chiffre | '#')) {caractere - '#'}
directive      ::= directive_todo | directive_saut
directive_todo ::= dièse 'TODO' ' ' {caractere}
directive_saut ::= dièse 'SKIP' ' ' {caractere}
commentaire    ::= dièse {caractere}
dièse          ::= '#' {' '}
abandon        ::= 'Bail out!' {caractere}
inconnu        ::= { (caractere - "\n") }
(* Classes de caractères POSIX et autres terminaux *)
chiffre              ::= [:digit:]
caractere            ::= ([:print:] - "\n")
entier_positif       ::= ( chiffre - '0' ) {chiffre}
entier_non_negatif   ::= chiffre {chiffre}
