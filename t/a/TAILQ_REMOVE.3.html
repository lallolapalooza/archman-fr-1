NOM

TAILQ_CONCAT, TAILQ_EMPTY, TAILQ_ENTRY, TAILQ_FIRST, TAILQ_FOREACH, TAILQ_FOREACH_REVERSE, TAILQ_HEAD, TAILQ_HEAD_INITIALIZER, TAILQ_INIT, TAILQ_INSERT_AFTER, TAILQ_INSERT_BEFORE, TAILQ_INSERT_HEAD, TAILQ_INSERT_TAIL, TAILQ_LAST, TAILQ_NEXT, TAILQ_REMOVE - implémentation d'une liste doublement chaînée par la queue

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNOPSIS

#include <sys/queue.h>
TAILQ_ENTRY(TYPE);
TAILQ_HEAD(HEADNAME, TYPE);
TAILQ_HEAD TAILQ_HEAD_INITIALIZER(TAILQ_HEAD head);

void TAILQ_INSERT_HEAD(TAILQ_HEAD *head,
                         struct TYPE *elm, TAILQ_ENTRY NAME);
void TAILQ_INSERT_TAIL(TAILQ_HEAD *head,
                         struct TYPE *elm, TAILQ_ENTRY NAME);
void TAILQ_INSERT_BEFORE(struct TYPE *listelm,
                         struct TYPE *elm, TAILQ_ENTRY NAME);
void TAILQ_INSERT_AFTER(TAILQ_HEAD *head, struct TYPE *listelm,
                         struct TYPE *elm, TAILQ_ENTRY NAME);
struct TYPE *TAILQ_FIRST(TAILQ_HEAD *head);
struct TYPE *TAILQ_LAST(TAILQ_HEAD *head, HEADNAME);
struct TYPE *TAILQ_PREV(struct TYPE *elm, HEADNAME, TAILQ_ENTRY NAME);

TAILQ_FOREACH(struct TYPE *var, TAILQ_HEAD *head,

void TAILQ_CONCAT(TAILQ_HEAD *head1, TAILQ_HEAD *head2,

DESCRIPTION

Ces macros définissent et manipulent une liste doublement chaînée par la queue.

Dans les définitions de macros, TYPE est le nom d'une structure définie par l'utilisateur, qui doit contenir un champ de type TAILQ_ENTRY, nommé NAME. L'argument HEADNAME est le nom d'une structure définie par l'utilisateur, qui doit être déclarée à l'aide de la macro TAILQ_HEAD().

Création

Une liste par la queue est dirigée par une structure définie par la macro TAILQ_HEAD(). Cette structure contient une paire de pointeurs, l'un vers le premier élément de la liste et l'autre vers le dernier élément de la liste. Les éléments sont doublement chaînés, ce qui permet de supprimer n'importe quel élément sans avoir à parcourir la liste. De nouveaux éléments peuvent être ajoutés à la liste après un élément existant, avant un autre, au début de la liste ou à la fin de la liste. Une structure TAILQ_HEAD est déclarée ainsi :


TAILQ_HEAD(HEADNAME, TYPE) head;

où struct HEADNAME est la structure à définir, et struct TYPE est le type des éléments qui sont chaînés dans la liste. Plus tard, un pointeur vers la tête de la liste peut être déclaré comme suit :


struct HEADNAME *headp;

(Les noms head et headp sont choisissables par l'utilisateur.)

TAILQ_ENTRY() déclare une structure qui relie les éléments de la liste.

TAILQ_HEAD_INITIALIZER() évalue à un initialiseur pour la liste head.

TAILQ_INIT() initialise la liste référencée par head. TAILQ_EMPTY() renvoie vrai si la liste ne contient aucun élément.

Insertion

TAILQ_INSERT_HEAD() insère le nouvel élément elm au début de la liste.

TAILQ_INSERT_TAIL() insère le nouvel élément elm à la fin de la liste.

TAILQ_INSERT_BEFORE() insère le nouvel élément elm avant l'élément listelm.

TAILQ_INSERT_AFTER() insère le nouvel élément elm après l'élément listelm.

Parcours

TAILQ_FIRST() renvoie le premier élément de la liste, ou NULL si la liste est vide.

TAILQ_LAST() renvoie le dernier élément de la liste. Si la liste est vide, la valeur renvoyée est NULL.

TAILQ_PREV() renvoie l'élément précédent de la liste, ou NULL si c'est le premier.

TAILQ_NEXT() renvoie l'élément suivant de la liste, ou NULL si c'est le dernier.

TAILQ_FOREACH() parcourt la liste référencée par head dans le sens forward, assignant chaque élément à var. var est mis à NULL si la boucle se termine normalement, ou s'il n'y a aucun élément.

TAILQ_FOREACH_REVERSE() parcourt la liste référencée par head dans le sens inverse, assignant chaque élément à var.

Suppression

TAILQ_REMOVE() supprime l'élément elm de la liste.

Autres caractères

TAILQ_CONCAT() concatène la liste head2 à la fin de la liste head1, vidant la première.

VALEUR DE RETOUR

TAILQ_EMPTY() renvoie non nul si la liste est vide, et zéro s'il y a au moins un élément.

TAILQ_FIRST(), TAILQ_LAST(), TAILQ_PREV(), et TAILQ_NEXT() renvoient un pointeur vers la structure TYPE correspondante, ou NULL.

TAILQ_HEAD_INITIALIZER() renvoie un initialiseur qui peut être assigné à la tête de liste head.

NORMES

BSD.

HISTORIQUE

4.4BSD.

ATTENTION

TAILQ_FOREACH() et TAILQ_FOREACH_REVERSE() ne permettent pas de supprimer ou libérer var à l'intérieur de la boucle, car cela interférerait avec le parcours. TAILQ_FOREACH_SAFE() et TAILQ_FOREACH_REVERSE_SAFE(), qui sont présents dans les systèmes BSD mais pas dans glibc, corrigent cette limitation en permettant à var d'être supprimé en toute sécurité de la liste et libéré à l'intérieur de la boucle sans interférer avec le parcours.

EXEMPLES

#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>
struct entry {
    int data;
    TAILQ_ENTRY(entry) entries;             /* Chaînon de la liste */
};
TAILQ_HEAD(tailhead, entry);
int
main(void)
{
    struct entry *n1, *n2, *n3, *np;
    struct tailhead head;                   /* Tête de liste */
    int i;
    TAILQ_INIT(&head);                      /* Initialiser la liste */
    n1 = malloc(sizeof(struct entry));      /* Insérer au début */
    TAILQ_INSERT_HEAD(&head, n1, entries);
    n1 = malloc(sizeof(struct entry));      /* Insérer à la fin */
    TAILQ_INSERT_TAIL(&head, n1, entries);
    n2 = malloc(sizeof(struct entry));      /* Insérer après */
    TAILQ_INSERT_AFTER(&head, n1, n2, entries);
    n3 = malloc(sizeof(struct entry));      /* Insérer avant */
    TAILQ_INSERT_BEFORE(n2, n3, entries);
    TAILQ_REMOVE(&head, n2, entries);       /* Suppression */
    free(n2);
                                            /* Parcours en avant */
    i = 0;
    TAILQ_FOREACH(np, &head, entries)
        np->data = i++;
                                            /* Parcours en arrière */
    TAILQ_FOREACH_REVERSE(np, &head, tailhead, entries)
        printf("%i\n", np->data);
                                            /* Suppression de la liste */
    while (!TAILQ_EMPTY(&head)) {
        np = TAILQ_FIRST(&head);
        TAILQ_REMOVE(&head, np, entries);
        free(np);
    }
    return 0;
}

TAILQ_REMOVE(3bsd) — Linux manual pages

NAME

TAILQ_REMOVE, TAILQ_INSERT_HEAD, TAILQ_INSERT_TAIL, TAILQ_INSERT_AFTER, TAILQ_INSERT_BEFORE, TAILQ_PREPEND - macros for manipulating singly linked lists

LIBRARY

libbsd

SYNOPSIS

#include <sys/queue.h>

/*
 * Macro definitions
 */
#define TAILQ_HEAD(name, type)
#define TAILQ_ENTRY(type)
#define TAILQ_INIT(head)
#define TAILQ_INSERT_HEAD(head, elm, field)
#define TAILQ_INSERT_TAIL(head, elm, field)
#define TAILQ_INSERT_AFTER(head, listelm, elm, field)
#define TAILQ_INSERT_BEFORE(head, listelm, elm, field)
#define TAILQ_REMOVE(head, elm, field)
#define TAILQ_PREPEND(head, elm, field)
#define TAILQ_FIRST(head)
#define TAILQ_LAST(head, headname)
#define TAILQ_NEXT(elm, field)
#define TAILQ_PREV(elm, headname, field)
#define TAILQ_EMPTY(head)
#define TAILQ_FOREACH(var, head, field)
#define TAILQ_FOREACH_REVERSE(var, head, headname, field)
#define TAILQ_CONCAT(head1, head2, field)
#define TAILQ_SWAP(head1, head2, type)

/*
 * Type definitions
 */
typedef struct { ... } TAILQ_HEAD(headname, typename);
typedef struct { ... } TAILQ_ENTRY(typename);

/*
 * Variables
 */
struct_type *
    struct_ptr;

struct_type **
    struct_ptr_ptr;

struct_type *
    struct_ptr_array[ARRAY_SIZE];

DESCRIPTION

TAILQ_HEAD defines a macro for the head of a tail queue. TAILQ_ENTRY defines a macro for the entries in a tail queue. These macros provide a way to implement a tail queue, which is a doubly linked list where the last element can be accessed in constant time.

A tail queue is a doubly linked list. It is similar to a list implemented using LIST_head(3bsd), except that the tailq_t structure has an additional pointer to the last element, allowing for constant time insertion and deletion at the end of the list.

TAILQ_HEAD(name, type) declares a structure name that contains a pointer to the first element in the tail queue. TAILQ_ENTRY(type) declares a structure that contains two pointers, le_next and le_prev, which are used to link the elements of the tail queue.

TAILQ_INIT(head) initializes the tail queue pointed to by head. This macro should be called before any other operations are performed on the tail queue.

TAILQ_INSERT_HEAD(head, elm, field) inserts the element elm at the head of the tail queue pointed to by head. The macro field is the name of the TAILQ_ENTRY structure within the element structure.

TAILQ_INSERT_TAIL(head, elm, field) inserts the element elm at the tail of the tail queue pointed to by head. The macro field is the name of the TAILQ_ENTRY structure within the element structure.

TAILQ_INSERT_AFTER(head, listelm, elm, field) inserts the element elm after the element listelm in the tail queue pointed to by head. The macro field is the name of the TAILQ_ENTRY structure within the element structure.

TAILQ_INSERT_BEFORE(head, listelm, elm, field) inserts the element elm before the element listelm in the tail queue pointed to by head. The macro field is the name of the TAILQ_ENTRY structure within the element structure.

TAILQ_REMOVE(head, elm, field) removes the element elm from the tail queue pointed to by head. The macro field is the name of the TAILQ_ENTRY structure within the element structure.

TAILQ_PREPEND(head, elm, field) inserts the element elm at the head of the tail queue pointed to by head. This is equivalent to TAILQ_INSERT_HEAD.

TAILQ_FIRST(head) returns a pointer to the first element in the tail queue pointed to by head. If the tail queue is empty, it returns NULL.

TAILQ_LAST(head, headname) returns a pointer to the last element in the tail queue pointed to by head. The headname argument is the name of the TAILQ_HEAD structure. If the tail queue is empty, it returns NULL.

TAILQ_NEXT(elm, field) returns a pointer to the next element in the tail queue after the element elm. If elm is the last element in the tail queue, it returns NULL.

TAILQ_PREV(elm, headname, field) returns a pointer to the previous element in the tail queue before the element elm. The headname argument is the name of the TAILQ_HEAD structure. If elm is the first element in the tail queue, it returns NULL.

TAILQ_EMPTY(head) returns true if the tail queue pointed to by head is empty, and false otherwise.

TAILQ_FOREACH(var, head, field) iterates over the elements in the tail queue pointed to by head. In each iteration, the variable var is set to point to the current element. The macro field is the name of the TAILQ_ENTRY structure within the element structure.

TAILQ_FOREACH_REVERSE(var, head, headname, field) iterates over the elements in the tail queue pointed to by head in reverse order. In each iteration, the variable var is set to point to the current element. The macro headname is the name of the TAILQ_HEAD structure, and field is the name of the TAILQ_ENTRY structure within the element structure.

TAILQ_CONCAT(head1, head2, field) concatenates the tail queue pointed to by head2 to the end of the tail queue pointed to by head1. The tail queue head2 becomes empty after the operation. The macro field is the name of the TAILQ_ENTRY structure within the element structure.

TAILQ_SWAP(head1, head2, type) swaps the contents of the tail queues pointed to by head1 and head2. The macro type is the name of the TAILQ_HEAD structure.

RETURN VALUE

TAILQ_FIRST, TAILQ_LAST, TAILQ_NEXT, and TAILQ_PREV return pointers to elements in the tail queue, or NULL if the tail queue is empty or the end of the list is reached. TAILQ_EMPTY returns a boolean value.

STANDARDS

These macros are intended to be compatible with BSD. They are described in the BSD systems manual.

HISTORY

The tail queue macros first appeared in 4.4BSD.

CAVEATS

When removing an element from a tail queue, the element must not be NULL. The TAILQ_REMOVE macro does not check for this condition.

When iterating over a tail queue using TAILQ_FOREACH or TAILQ_FOREACH_REVERSE, it is not safe to remove elements from the tail queue within the loop. If an element needs to be removed, it should be saved in a separate variable and removed after the loop has finished.

EXAMPLES

The following example demonstrates how to use the TAILQ_REMOVE macro to remove all elements from a tail queue:

#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>

struct my_entry {
    int data;
    TAILQ_ENTRY(my_entry) entries;
};

TAILQ_HEAD(my_list_head, my_entry) head;

int
main(void) {
    struct my_entry *n1, *n2;

    TAILQ_INIT(&head);

    /* ... add some elements to the tail queue ... */

    n1 = TAILQ_FIRST(&head);
    while (n1 != NULL) {
        n2 = TAILQ_NEXT(n1, entries);
        free(n1);
        n1 = n2;
    }
    TAILQ_INIT(&head);
    exit(EXIT_SUCCESS);
}

NOM

TAILQ_REMOVE, TAILQ_INSERT_HEAD, TAILQ_INSERT_TAIL, TAILQ_INSERT_AFTER, TAILQ_INSERT_BEFORE, TAILQ_PREPEND - macros pour manipuler des listes chaînées

BIBLIOTHÈQUE

libbsd

SYNTAXE

#include <sys/queue.h>

/*
 * Définitions de macros
 */
#define TAILQ_HEAD(name, type)
#define TAILQ_ENTRY(type)
#define TAILQ_INIT(head)
#define TAILQ_INSERT_HEAD(head, elm, field)
#define TAILQ_INSERT_TAIL(head, elm, field)
#define TAILQ_INSERT_AFTER(head, listelm, elm, field)
#define TAILQ_INSERT_BEFORE(head, listelm, elm, field)
#define TAILQ_REMOVE(head, elm, field)
#define TAILQ_PREPEND(head, elm, field)
#define TAILQ_FIRST(head)
#define TAILQ_LAST(head, headname)
#define TAILQ_NEXT(elm, field)
#define TAILQ_PREV(elm, headname, field)
#define TAILQ_EMPTY(head)
#define TAILQ_FOREACH(var, head, field)
#define TAILQ_FOREACH_REVERSE(var, head, headname, field)
#define TAILQ_CONCAT(head1, head2, field)
#define TAILQ_SWAP(head1, head2, type)

/*
 * Définitions de types
 */
typedef struct { ... } TAILQ_HEAD(headname, typename);
typedef struct { ... } TAILQ_ENTRY(typename);

/*
 * Variables
 */
struct_type *
    struct_ptr;

struct_type **
    struct_ptr_ptr;

struct_type *
    struct_ptr_array[ARRAY_SIZE];

DESCRIPTION

TAILQ_HEAD définit une macro pour la tête d'une file en queue (tail queue). TAILQ_ENTRY définit une macro pour les entrées d'une file en queue. Ces macros fournissent un moyen d'implémenter une file en queue, qui est une liste doublement chaînée où le dernier élément est accessible en temps constant.

Une file en queue est une liste doublement chaînée. Elle est similaire à une liste implémentée en utilisant LIST_head(3bsd), à l'exception que la structure tailq_t possède un pointeur supplémentaire vers le dernier élément, permettant une insertion et une suppression en temps constant à la fin de la liste.

TAILQ_HEAD(name, type) déclare une structure name qui contient un pointeur vers le premier élément de la file en queue. TAILQ_ENTRY(type) déclare une structure qui contient deux pointeurs, le_next et le_prev, qui sont utilisés pour chaîner les éléments de la file en queue.

TAILQ_INIT(head) initialise la file en queue pointée par head. Cette macro doit être appelée avant toute autre opération effectuée sur la file en queue.

TAILQ_INSERT_HEAD(head, elm, field) insère l'élément elm en tête de la file en queue pointée par head. La macro field est le nom de la structure TAILQ_ENTRY au sein de la structure de l'élément.

TAILQ_INSERT_TAIL(head, elm, field) insère l'élément elm en fin de la file en queue pointée par head. La macro field est le nom de la structure TAILQ_ENTRY au sein de la structure de l'élément.

TAILQ_INSERT_AFTER(head, listelm, elm, field) insère l'élément elm après l'élément listelm dans la file en queue pointée par head. La macro field est le nom de la structure TAILQ_ENTRY au sein de la structure de l'élément.

TAILQ_INSERT_BEFORE(head, listelm, elm, field) insère l'élément elm avant l'élément listelm dans la file en queue pointée par head. La macro field est le nom de la structure TAILQ_ENTRY au sein de la structure de l'élément.

TAILQ_REMOVE(head, elm, field) supprime l'élément elm de la file en queue pointée par head. La macro field est le nom de la structure TAILQ_ENTRY au sein de la structure de l'élément.

TAILQ_PREPEND(head, elm, field) insère l'élément elm en tête de la file en queue pointée par head. Ceci est équivalent à TAILQ_INSERT_HEAD.

TAILQ_FIRST(head) renvoie un pointeur vers le premier élément de la file en queue pointée par head. Si la file en queue est vide, elle renvoie NULL.

TAILQ_LAST(head, headname) renvoie un pointeur vers le dernier élément de la file en queue pointée par head. L'argument headname est le nom de la structure TAILQ_HEAD. Si la file en queue est vide, elle renvoie NULL.

TAILQ_NEXT(elm, field) renvoie un pointeur vers l'élément suivant dans la file en queue après l'élément elm. Si elm est le dernier élément de la file en queue, elle renvoie NULL.

TAILQ_PREV(elm, headname, field) renvoie un pointeur vers l'élément précédent dans la file en queue avant l'élément elm. L'argument headname est le nom de la structure TAILQ_HEAD. Si elm est le premier élément de la file en queue, elle renvoie NULL.

TAILQ_EMPTY(head) renvoie vrai si la file en queue pointée par head est vide, et faux sinon.

TAILQ_FOREACH(var, head, field) itère sur les éléments de la file en queue pointée par head. À chaque itération, la variable var est définie pour pointer vers l'élément courant. La macro field est le nom de la structure TAILQ_ENTRY au sein de la structure de l'élément.

TAILQ_FOREACH_REVERSE(var, head, headname, field) itère sur les éléments de la file en queue pointée par head en ordre inverse. À chaque itération, la variable var est définie pour pointer vers l'élément courant. La macro headname est le nom de la structure TAILQ_HEAD, et field est le nom de la structure TAILQ_ENTRY au sein de la structure de l'élément.

TAILQ_CONCAT(head1, head2, field) concatène la file en queue pointée par head2 à la fin de la file en queue pointée par head1. La file en queue head2 devient vide après l'opération. La macro field est le nom de la structure TAILQ_ENTRY au sein de la structure de l'élément.

TAILQ_SWAP(head1, head2, type) échange le contenu des files en queue pointées par head1 et head2. La macro type est le nom de la structure TAILQ_HEAD.

VALEUR DE RETOUR

TAILQ_FIRST, TAILQ_LAST, TAILQ_NEXT, et TAILQ_PREV renvoient des pointeurs vers des éléments dans la file en queue, ou NULL si la file en queue est vide ou si la fin de la liste est atteinte. TAILQ_EMPTY renvoie une valeur booléenne.

NORMES

Ces macros sont destinées à être compatibles avec BSD. Elles sont décrites dans le manuel système BSD.

HISTORIQUE

Les macros de file en queue sont apparues pour la première fois dans 4.4BSD.

MISE EN GARDE

Lors de la suppression d'un élément d'une file en queue, l'élément ne doit pas être NULL. La macro TAILQ_REMOVE ne vérifie pas cette condition.

Lors de l'itération sur une file en queue en utilisant TAILQ_FOREACH ou TAILQ_FOREACH_REVERSE, il n'est pas sûr de supprimer des éléments de la file en queue pendant la boucle. Si un élément doit être supprimé, il doit être sauvegardé dans une variable séparée et supprimé après la fin de la boucle.

EXEMPLES

L'exemple suivant montre comment utiliser la macro TAILQ_REMOVE pour supprimer tous les éléments d'une file en queue :

#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>

struct my_entry {
    int data;
    TAILQ_ENTRY(my_entry) entries;
};

TAILQ_HEAD(my_list_head, my_entry) head;

int
main(void) {
    struct my_entry *n1, *n2;

    TAILQ_INIT(&head);

    /* ... ajouter des éléments à la file en queue ... */

    n1 = TAILQ_FIRST(&head);
    while (n1 != NULL) {
        n2 = TAILQ_NEXT(n1, entries);
        free(n1);
        n1 = n2;
    }
    TAILQ_INIT(&head);
    exit(EXIT_SUCCESS);
}
