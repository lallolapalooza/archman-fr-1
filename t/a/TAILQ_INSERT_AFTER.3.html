TAILQ(3) Manuel des fonctions standard TAILQ(3)

NAME

TAILQ_CONCAT, TAILQ_EMPTY, TAILQ_ENTRY, TAILQ_FIRST, TAILQ_FOREACH, TAILQ_FOREACH_REVERSE, TAILQ_HEAD, TAILQ_HEAD_INITIALIZER, TAILQ_INIT, TAILQ_INSERT_AFTER, TAILQ_INSERT_BEFORE, TAILQ_INSERT_HEAD, TAILQ_INSERT_TAIL, TAILQ_LAST, TAILQ_NEXT, TAILQ_REMOVE - implémentation d'une liste double chaînée en queue (tail queue)

LIBRARY

Bibliothèque C standard (libc, -lc)

SYNOPSIS

#include <sys/queue.h>
TAILQ_ENTRY(TYPE);
TAILQ_HEAD(HEADNAME, TYPE);
TAILQ_HEAD TAILQ_HEAD_INITIALIZER(TAILQ_HEAD head);
void TAILQ_INIT(TAILQ_HEAD *head);
int TAILQ_EMPTY(TAILQ_HEAD *head);
void TAILQ_INSERT_HEAD(TAILQ_HEAD *head,
                         struct TYPE *elm, TAILQ_ENTRY NAME);
void TAILQ_INSERT_TAIL(TAILQ_HEAD *head,
                         struct TYPE *elm, TAILQ_ENTRY NAME);
void TAILQ_INSERT_BEFORE(struct TYPE *listelm,
                         struct TYPE *elm, TAILQ_ENTRY NAME);
void TAILQ_INSERT_AFTER(TAILQ_HEAD *head, struct TYPE *listelm,
                         struct TYPE *elm, TAILQ_ENTRY NAME);
struct TYPE *TAILQ_FIRST(TAILQ_HEAD *head);
struct TYPE *TAILQ_LAST(TAILQ_HEAD *head, HEADNAME);
struct TYPE *TAILQ_PREV(struct TYPE *elm, HEADNAME, TAILQ_ENTRY NAME);
struct TYPE *TAILQ_NEXT(struct TYPE *elm, TAILQ_ENTRY NAME);
TAILQ_FOREACH(struct TYPE *var, TAILQ_HEAD *head,
                         TAILQ_ENTRY NAME);
TAILQ_FOREACH_REVERSE(struct TYPE *var, TAILQ_HEAD *head, HEADNAME,
                         TAILQ_ENTRY NAME);
void TAILQ_REMOVE(TAILQ_HEAD *head, struct TYPE *elm,
                         TAILQ_ENTRY NAME);
void TAILQ_CONCAT(TAILQ_HEAD *head1, TAILQ_HEAD *head2,
                         TAILQ_ENTRY NAME);

DESCRIPTION

Ces macros définissent et opèrent sur une liste double chaînée en queue (tail queue).

Dans les définitions de macros, TYPE est le nom d'une structure définie par l'utilisateur, qui doit contenir un champ de type TAILQ_ENTRY, nommé NAME. L'argument HEADNAME est le nom d'une structure définie par l'utilisateur qui doit être déclarée en utilisant la macro TAILQ_HEAD().

Création

Une liste double chaînée est représentée par une structure déclarée avec la macro TAILQ_HEAD(). Cette structure contient une paire de pointeurs, l'un vers le premier élément de la liste et l'autre vers le dernier élément. Les éléments sont chaînés de telle sorte qu'un élément arbitraire peut être retiré sans avoir à parcourir la liste. De nouveaux éléments peuvent être ajoutés à la liste après un élément existant, avant un élément existant, au début de la liste ou à la fin de la liste. Une structure TAILQ_HEAD est déclarée ainsi :


TAILQ_HEAD(HEADNAME, TYPE) head;

où struct HEADNAME est la structure à définir, et struct TYPE est le type des éléments chaînés dans la liste. Un pointeur vers la tête de la liste peut être déclaré plus tard ainsi :


struct HEADNAME *headp;

(Les noms head et headp sont choisissables par l'utilisateur.)

TAILQ_ENTRY() déclare une structure qui relie les éléments de la liste.

TAILQ_HEAD_INITIALIZER() est évalué à un initialiseur pour la liste head.

TAILQ_INIT() initialise la liste référencée par head.

TAILQ_EMPTY() est évalué à vrai si la liste est vide. head.

Insertion

TAILQ_INSERT_HEAD() insère le nouvel élément elm au début de la liste.

TAILQ_INSERT_TAIL() insère le nouvel élément elm à la fin de la liste.

TAILQ_INSERT_BEFORE() insère le nouvel élément elm avant l'élément listelm.

TAILQ_INSERT_AFTER() insère le nouvel élément elm après l'élément listelm.

Parcours

TAILQ_FIRST() renvoie le premier élément de la liste, ou NULL si la liste est vide.

TAILQ_LAST() renvoie le dernier élément de la liste. Si la liste est vide, la valeur renvoyée est NULL.

TAILQ_PREV() renvoie l'élément précédent dans la liste, ou NULL si c'est le premier.

TAILQ_NEXT() renvoie l'élément suivant dans la liste, ou NULL si c'est le dernier.

TAILQ_FOREACH() parcourt la liste référencée par head dans le sens avant, assignant chaque élément à var tour à tour. var est mis à NULL si la boucle se termine normalement, ou s'il n'y a pas d'éléments.

TAILQ_FOREACH_REVERSE() parcourt la liste référencée par head dans le sens arrière, assignant chaque élément à var.

Suppression

TAILQ_REMOVE() supprime l'élément elm de la liste.

Autres_avantages

TAILQ_CONCAT() concatène la liste dont la tête est head2 à la fin de la liste dont la tête est head1, vidant la première.

VALEUR_RETOURNEE

TAILQ_EMPTY() renvoie une valeur non nulle si la liste est vide, et zéro s'il y a au moins un élément.

TAILQ_FIRST(), TAILQ_LAST(), TAILQ_PREV() et TAILQ_NEXT() renvoient un pointeur vers la structure TYPE du premier, dernier, précédent ou suivant élément, respectivement.

TAILQ_HEAD_INITIALIZER() renvoie un initialiseur qui peut être assigné à la liste head.

STANDARDS

BSD.

HISTORY

4.4BSD.

CAVEATS

TAILQ_FOREACH() et TAILQ_FOREACH_REVERSE() ne permettent pas la suppression de var ou sa libération dans la boucle, car cela pourrait interférer avec le parcours. TAILQ_FOREACH_SAFE() et TAILQ_FOREACH_REVERSE_SAFE(), qui sont présents dans les BSDs mais pas dans glibc, corrigent cette limitation en permettant que var puisse être retiré de la liste et libéré dans la boucle sans interférer avec le parcours.

EXEMPLES

#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>
struct entry {
    int data;
    TAILQ_ENTRY(entry) entries;             /* Queue double chaînée */
};
TAILQ_HEAD(tailhead, entry);
int
main(void)
{
    struct entry *n1, *n2, *n3, *np;
    struct tailhead head;                   /* Tête de la liste */
    int i;
    TAILQ_INIT(&head);                      /* Initialise la liste */
    n1 = malloc(sizeof(struct entry));      /* Insertion en tête */
    TAILQ_INSERT_HEAD(&head, n1, entries);
    n1 = malloc(sizeof(struct entry));      /* Insertion en queue */
    TAILQ_INSERT_TAIL(&head, n1, entries);
    n2 = malloc(sizeof(struct entry));      /* Insertion après */
    TAILQ_INSERT_AFTER(&head, n1, n2, entries);
    n3 = malloc(sizeof(struct entry));      /* Insertion avant */
    TAILQ_INSERT_BEFORE(n2, n3, entries);
    TAILQ_REMOVE(&head, n2, entries);       /* Suppression */
    free(n2);
                                            /* Parcours avant */
    i = 0;
    TAILQ_FOREACH(np, &head, entries)
        np->data = i++;
                                            /* Parcours arrière */
    TAILQ_FOREACH_REVERSE(np, &head, tailhead, entries)
        printf("%i\n", np->data);
                                            /* Suppression de la liste */
n1 = TAILQ_FIRST(&head); while (n1 != NULL) { n2 = TAILQ_NEXT(n1, entries); free(n1); n1 = n2; } TAILQ_INIT(&head); exit(EXIT_SUCCESS);

NOM

TAILQ est une structure de données de file double implémentée sous forme de liste chaînée. Cette page de manuel décrit l'API de insque(3).

BIBLIOTHÈQUE

Cette bibliothèque est implémentée dans le noyau du système d'exploitation Linux et se trouve dans le répertoire /usr/include.

SYNTAXE

n1 = TAILQ_FIRST(&head);
while (n1 != NULL) {
    n2 = TAILQ_NEXT(n1, entries);
    free(n1);
    n1 = n2;
}
TAILQ_INIT(&head);
exit(EXIT_SUCCESS);

DESCRIPTION

Le code libère les nœuds de la file double insque(3) et initialise la file queue(7).

VALEUR DE RETOUR

La valeur de retour est 0.
