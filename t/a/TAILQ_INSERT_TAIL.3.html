TAILQ(3) Manuel des fonctions de bibliothèque TAILQ(3)

NOM

TAILQ_CONCAT, TAILQ_EMPTY, TAILQ_ENTRY, TAILQ_FIRST, TAILQ_FOREACH, TAILQ_FOREACH_REVERSE, TAILQ_HEAD, TAILQ_HEAD_INITIALIZER, TAILQ_INIT, TAILQ_INSERT_AFTER, TAILQ_INSERT_BEFORE, TAILQ_INSERT_HEAD, TAILQ_INSERT_TAIL, TAILQ_LAST, TAILQ_NEXT, TAILQ_PREV, TAILQ_REMOVE - implémentation d'une file d'attente doublement chaînée

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNOPSIS

#include <sys/queue.h>
TAILQ_ENTRY(TYPE);
TAILQ_HEAD(HEADNAME, TYPE);
TAILQ_HEAD TAILQ_HEAD_INITIALIZER(TAILQ_HEAD head);
void TAILQ_INIT(TAILQ_HEAD *head);
int TAILQ_EMPTY(TAILQ_HEAD *head);
void TAILQ_INSERT_HEAD(TAILQ_HEAD *head,
                         struct TYPE *elm, TAILQ_ENTRY NAME);
void TAILQ_INSERT_TAIL(TAILQ_HEAD *head,
                         struct TYPE *elm, TAILQ_ENTRY NAME);
void TAILQ_INSERT_BEFORE(struct TYPE *listelm,
                         struct TYPE *elm, TAILQ_ENTRY NAME);
void TAILQ_INSERT_AFTER(TAILQ_HEAD *head, struct TYPE *listelm,
                         struct TYPE *elm, TAILQ_ENTRY NAME);
struct TYPE *TAILQ_FIRST(TAILQ_HEAD *head);
struct TYPE *TAILQ_LAST(TAILQ_HEAD *head, HEADNAME);
struct TYPE *TAILQ_PREV(struct TYPE *elm, HEADNAME, TAILQ_ENTRY NAME);
struct TYPE *TAILQ_NEXT(struct TYPE *elm, TAILQ_ENTRY NAME);
TAILQ_FOREACH(struct TYPE *var, TAILQ_HEAD *head,
                         TAILQ_ENTRY NAME);
TAILQ_FOREACH_REVERSE(struct TYPE *var, TAILQ_HEAD *head, HEADNAME,
                         TAILQ_ENTRY NAME);
void TAILQ_REMOVE(TAILQ_HEAD *head, struct TYPE *elm,
                         TAILQ_ENTRY NAME);
void TAILQ_CONCAT(TAILQ_HEAD *head1, TAILQ_HEAD *head2,
                         TAILQ_ENTRY NAME);

DESCRIPTION

Ces macros définissent et opèrent sur des files d'attente doublement chaînées.

Dans les définitions de macro, TYPE est le nom d'une structure définie par l'utilisateur, qui doit contenir un champ de type TAILQ_ENTRY, nommé NAME. L'argument HEADNAME est le nom d'une structure définie par l'utilisateur qui doit être déclarée en utilisant la macro TAILQ_HEAD().

Création

Une file d'attente est dirigée par une structure définie par la macro TAILQ_HEAD(). Cette structure contient une paire de pointeurs, l'un vers le premier élément de la file et l'autre vers le dernier élément de la file. Les éléments sont doublement chaînés de sorte qu'un élément arbitraire peut être retiré sans parcourir la file. De nouveaux éléments peuvent être ajoutés à la file après un élément existant, avant un élément existant, en tête de la file ou à la fin de la file. Une structure TAILQ_HEAD est déclarée comme suit :


TAILQ_HEAD(HEADNAME, TYPE) head;

où struct HEADNAME est la structure à définir, et struct TYPE est le type des éléments à lier dans la file. Un pointeur vers la tête de la file peut ensuite être déclaré comme suit :


struct HEADNAME *headp;

(Les noms head et headp sont sélectionnables par l'utilisateur.)

TAILQ_ENTRY() déclare une structure qui relie les éléments de la file.

TAILQ_HEAD_INITIALIZER() évalue à un initialiseur pour la file head.

TAILQ_INIT() initialise la file référencée par

TAILQ_EMPTY() évalue à vrai s'il n'y a aucun élément dans la file. head.

Insertion

TAILQ_INSERT_HEAD() insère le nouvel élément elm en tête de la file.

TAILQ_INSERT_TAIL() insère le nouvel élément elm à la fin de la file.

TAILQ_INSERT_BEFORE() insère le nouvel élément elm avant l'élément listelm.

TAILQ_INSERT_AFTER() insère le nouvel élément elm après l'élément listelm.

Parcours

TAILQ_FIRST() retourne le premier élément de la file, ou NULL si la file est vide.

TAILQ_LAST() retourne le dernier élément de la file. Si la file est vide, la valeur retournée est NULL.

TAILQ_PREV() retourne l'élément précédent dans la file, ou NULL si cet élément est le premier.

TAILQ_NEXT() retourne l'élément suivant dans la file, ou NULL si cet élément est le dernier.

TAILQ_FOREACH() parcourt la file référencée par head dans le sens avant, attribuant successivement chaque élément à var. var est défini à NULL si la boucle se termine normalement, ou s'il n'y avait aucun élément.

TAILQ_FOREACH_REVERSE() parcourt la file référencée par head dans le sens inverse, attribuant successivement chaque élément à var.

Suppression

TAILQ_REMOVE() retire l'élément elm de la file.

Autres fonctionnalités

TAILQ_CONCAT() concatène la file dirigée par head2 à la fin de celle dirigée par head1, en retirant toutes les entrées de la première.

VALEUR DE RETOUR

TAILQ_EMPTY() retourne une valeur non nulle si la file est vide, et zéro si la file contient au moins une entrée.

TAILQ_FIRST(), TAILQ_LAST(), TAILQ_PREV(), et TAILQ_NEXT() retournent un pointeur vers la structure TYPE première, dernière, précédente ou suivante, respectivement.

TAILQ_HEAD_INITIALIZER() retourne un initialiseur qui peut être assigné à la file head.

NORMES

BSD.

HISTORIQUE

4.4BSD.

ATTENTION

TAILQ_FOREACH() et TAILQ_FOREACH_REVERSE() ne permettent pas de retirer ou de libérer var dans la boucle, car cela interférerait avec le parcours. TAILQ_FOREACH_SAFE() et TAILQ_FOREACH_REVERSE_SAFE(), qui sont présents sur les systèmes BSD mais ne sont pas présents dans glibc, corrigent cette limitation en permettant à var d'être retiré en toute sécurité de la liste et libéré depuis la boucle sans interférer avec le parcours.

EXEMPLES

#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>
struct entry {
    int data;
    TAILQ_ENTRY(entry) entries;             /* File d'attente */
};
TAILQ_HEAD(tailhead, entry);
int
main(void)
{
    struct entry *n1, *n2, *n3, *np;
    struct tailhead head;                   /* Tête de file d'attente */
    int i;
    TAILQ_INIT(&head);                      /* Initialiser la file */
    n1 = malloc(sizeof(struct entry));      /* Insérer en tête */
    TAILQ_INSERT_HEAD(&head, n1, entries);
    n1 = malloc(sizeof(struct entry));      /* Insérer à la fin */
    TAILQ_INSERT_TAIL(&head, n1, entries);
    n2 = malloc(sizeof(struct entry));      /* Insérer après */
    TAILQ_INSERT_AFTER(&head, n1, n2, entries);
    n3 = malloc(sizeof(struct entry));      /* Insérer avant */
    TAILQ_INSERT_BEFORE(n2, n3, entries);
    TAILQ_REMOVE(&head, n2, entries);       /* Suppression */
    free(n2);
                                            /* Parcours avant */
    i = 0;
    TAILQ_FOREACH(np, &head, entries)
        np->data = i++;
                                            /* Parcours arrière */
    TAILQ_FOREACH_REVERSE(np, &head, tailhead, entries)
        printf("%i\n", np->data);
                                            /* Suppression de file d'attente */

TAILQ_INSERT_TAIL(3bsd) — Manuel Linux

NOM

TAILQ_INSERT_TAIL — insérer un élément à la fin d'une file d'attente à double chaîne

BIBLIOTHQUE

Bibliothèque C standard (libc), pour les listes chaînées de noyau (libbsd, à partir de FreeBSD 3.0)

SYNTAXE

#include <sys/queue.h>

void
TAILQ_INSERT_TAIL(TAILQ_HEAD_T *head, ENTRY_T *elm, TAILQ_FIELD_T field);

DESCRIPTION

Les macros TAILQ_INSERT_TAIL sont utilisées pour insérer un nouvel élément, elm, à la fin d'une file d'attente à double chaîne définie par head. Le champ field est le nom du membre du champ de liaison de la structure.

La macro TAILQ_INSERT_TAIL est une macro de haut niveau qui utilise la macro TAILQ_INSERT_TAIL. Il est cependant déconseillé d'utiliser TAILQ_INSERT_TAIL directement.

EXEMPLE

Supprimer tous les éléments d'une file d'attente et la libérer.

    TAILQ_HEAD(my_list, entry) head = TAILQ_HEAD_INITIALIZER(head);
    struct entry *n1, *n2;
    ...
    /* Insérer des éléments dans la liste */
    ...
    n1 = TAILQ_FIRST(&head);
    while (n1 != NULL) {
        n2 = TAILQ_NEXT(n1, entries);
        free(n1);
        n1 = n2;
    }
    TAILQ_INIT(&head);
    exit(EXIT_SUCCESS);
