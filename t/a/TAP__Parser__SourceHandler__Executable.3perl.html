TAP::Parser::SourceHandler::Executable(3perl) Guide de référence du programmeur Perl TAP::Parser::SourceHandler::Executable(3perl)

NOM

TAP::Parser::SourceHandler::Executable - Diffuse la sortie d'une source TAP exécutable

VERSION

Version 3.50

SYNOPIS

use TAP::Parser::Source;
use TAP::Parser::SourceHandler::Executable;
my $source = TAP::Parser::Source->new->raw(['/usr/bin/ruby', 'mytest.rb']);
$source->assemble_meta;
my $class = 'TAP::Parser::SourceHandler::Executable';
my $vote  = $class->can_handle( $source );
my $iter  = $class->make_iterator( $source );

DESCRIPTION

Ceci est un TAP::Parser::SourceHandler exécutable - il a 2 tâches :

1. Déterminer si le TAP::Parser::Source qu'il reçoit est une commande exécutable ("can_handle").

2. Créer un itérateur pour les commandes exécutables ("make_iterator").

À moins que vous n'écriviez un plugin ou que vous ne sous-classiez TAP::Parser, vous n'aurez probablement pas besoin d'utiliser ce module directement.

MÉTHODES

Méthodes de classe

"can_handle"

my $vote = $class->can_handle( $source );

Ne vote que si $source ressemble à un fichier exécutable. Lance les votes suivants :

0.9  s'il s'agit d'un hash avec une clé 'exec'
0.8  s'il s'agit d'un fichier .bat
0.75 s'il a un bit d'exécution défini

"make_iterator"

my $iterator = $class->make_iterator( $source );

Retourne un nouveau TAP::Parser::Iterator::Process pour la source. "$source->raw" doit être dans l'une des formes suivantes :

{ exec => [ @exec ] }
[ @exec ]
$file

"croak" en cas d'erreur.

"iterator_class"

La classe d'itérateur à utiliser, à surcharger si vous sous-classez. Par défaut, TAP::Parser::Iterator::Process.

SOUS-CLASSEMENT

Veuillez consulter "SUBCLASSING" dans TAP::Parser pour un aperçu du sous-classement.

Exemple

package MyRubySourceHandler;
use strict;
use Carp qw( croak );
use TAP::Parser::SourceHandler::Executable;
use base 'TAP::Parser::SourceHandler::Executable';
# attend $handler->(['mytest.rb', 'cmdline', 'args']);
sub make_iterator {
  my ($self, $source) = @_;
  my @test_args = @{ $source->test_args };
  my $rb_file   = $test_args[0];
  croak("erreur: fichier Ruby '$rb_file' non trouvé !") unless (-f $rb_file);
  return $self->SUPER::raw_source(['/usr/bin/ruby', @test_args]);
}
