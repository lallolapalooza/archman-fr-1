TAP::Parser::SourceHandler::File(3perl) Guide de référence des programmeurs Perl TAP::Parser::SourceHandler::File(3perl)

NOM

TAP::Parser::SourceHandler::File - Flux TAP depuis un fichier texte.

VERSION

Version 3.50

SYNOPIS

use TAP::Parser::Source;
use TAP::Parser::SourceHandler::File;
my $source = TAP::Parser::Source->new->raw( \'file.tap' );
$source->assemble_meta;
my $class = 'TAP::Parser::SourceHandler::File';
my $vote  = $class->can_handle( $source );
my $iter  = $class->make_iterator( $source );

DESCRIPTION

C'est un TAP::Parser::SourceHandler pour un fichier contenant du TAP brut - il a 2 missions :

1. Déterminer si la source brute qu'on lui donne est un fichier contenant une sortie TAP brute. Voir TAP::Parser::IteratorFactory pour plus de détails.

2. Prend le TAP brut du fichier texte donné et le convertit en un itérateur.

À moins que vous n'écriviez un plugin ou ne sous-classiez TAP::Parser, vous n'aurez probablement pas besoin d'utiliser ce module directement.

MÉTHODES

Méthodes de classe

"can_handle"

my $vote = $class->can_handle( $source );

Ne vote que si $source ressemble à un fichier régulier. Lance les votes suivants :

0.9 si c'est un fichier .tap
0.9 si il a une extension correspondant à celles données dans la configuration utilisateur.

"make_iterator"

my $iterator = $class->make_iterator( $source );

Retourne un nouveau TAP::Parser::Iterator::Stream pour la source. "croak" en cas d'erreur.

"iterator_class"

La classe d'itérateur à utiliser, à redéfinir si vous sous-classez. Par défaut, c'est TAP::Parser::Iterator::Stream.

CONFIGURATION

{
 extensions => [ @case_insensitive_exts_to_match ]
}

SOUS-CLASSEMENT

Veuillez consulter "SUBCLASSING" dans TAP::Parser pour un aperçu du sous-classement.
