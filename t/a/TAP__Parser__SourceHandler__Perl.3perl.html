TAP::Parser::SourceHandler::Perl(3perl) Guide de référence du programmeur Perl TAP::Parser::SourceHandler::Perl(3perl)

NOM

TAP::Parser::SourceHandler::Perl - Flux TAP depuis un exécutable Perl

VERSION

Version 3.50

SYNTAXE

use TAP::Parser::Source;
use TAP::Parser::SourceHandler::Perl;
my $source = TAP::Parser::Source->new->raw( \'script.pl' );
$source->assemble_meta;
my $class = 'TAP::Parser::SourceHandler::Perl';
my $vote  = $class->can_handle( $source );
my $iter  = $class->make_iterator( $source );

DESCRIPTION

Ceci est un handler TAP::Parser::SourceHandler pour Perl - il a 2 tâches :

1. Déterminer si le TAP::Parser::Source qu'il reçoit est bien un script Perl ("can_handle").

2. Créer un itérateur pour les sources Perl ("make_iterator").

À moins que vous n'écriviez un plugin ou une sous-classe de TAP::Parser, vous n'aurez probablement pas besoin d'utiliser ce module directement.

MÉTHODES

Méthodes de classe

"can_handle"

my $vote = $class->can_handle( $source );

Ne vote que si $source ressemble à un fichier. Lance les votes suivants :

0.9  s'il y a un shebang de type "#!...perl"
0.3  s'il y a un quelconque shebang
0.8  s'il s'agit d'un fichier .t
0.9  s'il s'agit d'un fichier .pl
0.75 s'il se trouve dans un répertoire 't'
0.25 par défaut (rétrocompatibilité)

"make_iterator"

my $iterator = $class->make_iterator( $source );

Construit et retourne un nouveau TAP::Parser::Iterator::Process pour la source. Suppose que "$source->raw" contient une référence au script perl. Fait un "croak" si le fichier n'a pas pu être trouvé.

La commande à exécuter est construite comme suit :

$perl @switches $perl_script @test_args

La commande Perl à utiliser est déterminée par "get_perl". La commande générée garantit la préservation :

PERL5LIB
PERL5OPT
Mode Taint, s'il est défini dans le shebang du script

Note : la commande générée ne respectera pas la ligne shebang définie dans votre script Perl. Ce n'est problématique que si vous avez compilé une version personnalisée de Perl ou si vous souhaitez utiliser une version spécifique de Perl pour un test et une autre version pour un autre, par exemple :

#!/path/to/a/custom_perl --some --args
#!/usr/local/perl-5.6/bin/perl -w

Actuellement, vous devez écrire un plugin pour contourner cela.

"get_taint"

Décode les commutateurs de taint d'une ligne shebang Perl.

# $taint sera 't'
my $taint = TAP::Parser::SourceHandler::Perl->get_taint( '#!/usr/bin/perl -t' );
# $untaint sera indéfini
my $untaint = TAP::Parser::SourceHandler::Perl->get_taint( '#!/usr/bin/perl' );

"get_perl"

Obtient la version de Perl qui exécute actuellement la suite de tests.

SOUS-CLASSEMENT

Veuillez consulter "SUBCLASSING" dans TAP::Parser pour un aperçu du sous-classement.

Exemple

package MyPerlSourceHandler;
use strict;
use TAP::Parser::SourceHandler::Perl;
use base 'TAP::Parser::SourceHandler::Perl';
# utilise la version de perl de la ligne shebang dans le fichier de test
sub get_perl {
    my $self = shift;
    if (my $shebang = $self->shebang( $self->{file} )) {
        $shebang =~ /^#!(.*\bperl.*?)(?:(?:\s)|(?:$))/;
        return $1 if $1;
    }
    return $self->SUPER::get_perl(@_);
}
