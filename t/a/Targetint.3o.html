Module Targetint
: sig end

Nombres entiers du processeur natif.

Ce module fournit des opérations sur les entiers signés de 32 bits (sur les plateformes cibles 32 bits) ou les entiers signés de 64 bits (sur les plateformes cibles 64 bits). Ce type d'entier a exactement la même largeur que le type pointeur dans le compilateur C. Toutes les opérations arithmétiques sur le type sont effectuées modulo 2^32 ou 2^64 selon la taille du mot de l'architecture cible.

Attention : ce module est instable et fait partie de Compiler_libs.

type t

Le type des entiers natifs cibles.

val zero : t

L'entier natif cible 0.

val one : t

L'entier natif cible 1.

val minus_one : t

L'entier natif cible -1.

val neg : t -> t

Négation unaire.

val add : t -> t -> t

Addition.

val sub : t -> t -> t

Soustraction.

val mul : t -> t -> t

Multiplication.

val div : t -> t -> t

Division entière. Lève Division_by_zero si le deuxième argument est zéro. Cette division arrondit le quotient réel de ses arguments vers zéro, comme spécifié pour l'opérateur (/).

val unsigned_div : t -> t -> t

Identique à Targetint.div, sauf que les arguments et le résultat sont interprétés comme des entiers non signés.

val rem : t -> t -> t

Reste entier. Si y n'est pas zéro, le résultat de Targetint.rem x y satisfait les propriétés suivantes : Targetint.zero <= Targetint.rem x y < Targetint.abs y et x = Targetint.add (Targetint.mul (Targetint.div x y) y)
(Targetint.rem x y) . Si y = 0 , Targetint.rem x y lève Division_by_zero.

val unsigned_rem : t -> t -> t

Identique à Targetint.rem, sauf que les arguments et le résultat sont interprétés comme des entiers non signés.

val succ : t -> t

Successeur. Targetint.succ x est Targetint.add x Targetint.one.

val pred : t -> t

Prédécesseur. Targetint.pred x est Targetint.sub x Targetint.one.

val abs : t -> t

abs x est la valeur absolue de x. Sur min_int, c'est min_int lui-même et il reste donc négatif.

val size : int

Le nombre de bits dans un entier natif cible.

val max_int : t

Le plus grand entier représentable sur la cible, qui est 2^31 - 1 sur une plateforme 32 bits ou 2^63 - 1 sur une plateforme 64 bits.

val min_int : t

Le plus petit entier représentable sur la cible, qui est -2^31 sur une plateforme 32 bits ou -2^63 sur une plateforme 64 bits.

val logand : t -> t -> t

ET logique bit à bit.

val logor : t -> t -> t

OU logique bit à bit.

val logxor : t -> t -> t

XOR logique bit à bit.

val lognot : t -> t

Négation logique bit à bit.

val shift_left : t -> int -> t

Targetint.shift_left x y décale x vers la gauche de y bits. Le résultat est indéterminé si y < 0 ou y >= bitsize, où bitsize est 32 sur une plateforme 32 bits et 64 sur une plateforme 64 bits.

val shift_right : t -> int -> t

Targetint.shift_right x y décale x vers la droite de y bits. Il s'agit d'un décalage arithmétique : le bit de signe de x est répété et inséré dans les bits vides. Le résultat est indéterminé si y < 0 ou y >= bitsize.

val shift_right_logical : t -> int -> t

Targetint.shift_right_logical x y décale x vers la droite de y bits. Il s'agit d'un décalage logique : des zéros sont insérés dans les bits vides, indépendamment du signe de x. Le résultat est indéterminé si y < 0 ou y >= bitsize.

val of_int : int -> t

Convertit l'entier donné (type int) en un entier natif cible (type t), modulo la taille du mot de la cible.

val of_int_exn : int -> t

Convertit l'entier donné (type int) en un entier natif cible (type t). Lève une erreur fatale si la conversion n'est pas exacte.

val to_int : t -> int

Convertit l'entier donné (type t) en un entier (type int). Le bit de poids fort est perdu lors de la conversion.

val of_float : float -> t

Convertit un nombre à virgule flottante donné en un entier natif cible, en ignorant la partie fractionnaire (arrondi vers zéro). Le résultat de la conversion est indéfini si, après l'arrondi, le nombre est hors de la plage [ Targetint.min_int, Targetint.max_int ].

val to_float : t -> float

Convertit un entier donné en un nombre à virgule flottante.

val of_int32 : int32 -> t

Convertit l'entier donné (type int32) en un entier natif cible.

val to_int32 : t -> int32

Convertit l'entier donné (type t) en un entier 32 bits (type int32). Sur les plateformes 64 bits, l'entier natif 64 bits est pris modulo 2^32, c'est-à-dire que les 32 bits de poids fort sont perdus. Sur les plateformes 32 bits, la conversion est exacte.

val of_int64 : int64 -> t

Convertit l'entier donné (type int64) en un entier natif cible.

val to_int64 : t -> int64

Convertit l'entier donné (type t) en un entier 64 bits (type int64).

val of_string : string -> t

Convertit une chaîne donnée en un entier natif cible. La chaîne est lue en décimal (par défaut) ou en hexadécimal, octal ou binaire si elle commence par 0x, 0o ou 0b. Lève Failure "int_of_string" si la chaîne donnée n'est pas une représentation valide d'un entier ou si l'entier représenté dépasse la plage des entiers représentables dans le type nativeint.

val to_string : t -> string

Retourne la représentation en chaîne de son argument, en décimal.

val compare : t -> t -> int

La fonction de comparaison pour les entiers natifs cibles, avec la même spécification que compare. Avec le type t, cette fonction compare permet de passer le module Targetint en argument aux foncteurs Set.Make et Map.Make.

val unsigned_compare : t -> t -> int

Identique à Targetint.compare, sauf que les arguments sont interprétés comme des entiers non signés.

val equal : t -> t -> bool

La fonction d'égalité pour les entiers natifs cibles.

type repr =
| Int32 of int32
| Int64 of int64

val repr : t -> repr

La représentation concrète d'un entier natif.

val print : Format.formatter -> t -> unit

Imprime un entier natif cible dans un formateur.
