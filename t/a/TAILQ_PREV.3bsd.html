DESCRIPTION

Ces macros définissent et opèrent sur quatre types de structures de données qui peuvent être utilisées en C et C++ :

  1. Liste
  2. Liste doublement enchaînée
  3. Liste doublement enchaînée comme file d'attente
  4. File d'attente
Les quatre structures prennent en charge la fonctionnalité suivante :
  1. Insertion d'un nouvel élément en tête de liste.
  2. Insertion d'un nouvel élément après n'importe quel élément de la liste.
  3. Suppression en temps O(1) d'un élément en tête de liste.
  4. Parcours de la liste dans le sens avant.
  5. Échange du contenu de deux listes.

Les listes simplement chaînées sont les plus simples des quatre structures de données et ne prennent en charge que la fonctionnalité ci-dessus. Les listes simplement chaînées sont idéales pour les applications comportant de grands ensembles de données avec peu ou pas de suppressions, ou pour implémenter une pile LIFO. Les listes simplement chaînées ajoutent la fonctionnalité suivante :

  1. Suppression en temps O(n) de n'importe quel élément de la liste.
  2. Concaténation en temps O(n) de deux listes.

Les listes simplement chaînées comme file d'attente ajoutent la fonctionnalité suivante :

  1. Insertion d'un nouvel élément à la fin d'une liste.
  2. Suppression en temps O(n) de n'importe quel élément de la liste.
  3. Peuvent être concaténées.

Cependant :

  1. Toutes les insertions dans la liste doivent spécifier le début de la liste.
  2. Chaque entrée d'en-tête nécessite deux pointeurs au lieu d'un seul.
  3. La taille du code est environ 15 % plus grande et les opérations s'exécutent environ 20 % plus lentement que celles des listes simplement chaînées.

Les listes simplement chaînées comme file d'attente sont idéales pour les applications comportant de grands ensembles de données avec peu ou pas de suppressions, ou pour implémenter une file FIFO.

Toutes les structures de données doublement chaînées (listes et files d'attente) ajoutent en outre :

  1. Insertion d'un nouvel élément avant n'importe quel élément de la liste.
  2. Suppression en temps O(1) de n'importe quel élément de la liste.

Cependant :

  1. Chaque élément nécessite deux pointeurs au lieu d'un seul.
  2. La taille du code et le temps d'exécution des opérations (à l'exception des suppressions) sont environ le double de ceux des structures simplement chaînées.

Les listes sont les plus simples des structures de données doublement chaînées. Elles augmentent la fonctionnalité par rapport à ce qui précède :

  1. Concaténation en temps O(n) de deux listes.
  2. Peuvent être parcourues en sens inverse.

Cependant :

  1. Pour parcourir en sens inverse, il faut spécifier l'élément à partir duquel la traversée commence et la liste dans laquelle il se trouve.

Les files d'attente ajoutent la fonctionnalité suivante :

  1. Insertion d'un élément à la fin d'une liste.
  2. Peuvent être parcourues en sens inverse, de la fin vers le début.
  3. Peuvent être concaténées.

Cependant :

  1. Toute insertion dans une liste ou suppression doit spécifier le début de la liste.
  2. Chaque entrée d'en-tête nécessite deux pointeurs au lieu d'un seul.
  3. La taille du code est environ 15 % plus grande et les opérations s'exécutent environ 20 % plus lentement que celles des listes simplement chaînées.

Dans les définitions de macros, TYPE est le nom d'une structure définie par l'utilisateur. La structure doit contenir un champ nommé NAME de type SLIST_ENTRY, STAILQ_ENTRY, LIST_ENTRY ou TAILQ_ENTRY. Dans les définitions de macros, CLASSTYPE est le nom d'une classe définie par l'utilisateur. La classe doit contenir un champ nommé NAME de type SLIST_CLASS_ENTRY, STAILQ_CLASS_ENTRY, LIST_CLASS_ENTRY ou TAILQ_CLASS_ENTRY. L'argument HEADNAME est le nom d'une structure définie par l'utilisateur qui doit être déclarée à l'aide des macros SLIST_HEAD, SLIST_CLASS_HEAD, STAILQ_HEAD, STAILQ_CLASS_HEAD, LIST_HEAD, LIST_CLASS_HEAD, TAILQ_HEAD ou TAILQ_CLASS_HEAD. Voir les exemples ci-dessous pour une explication plus détaillée de la manière dont ces macros sont utilisées.

LISTES SIMPLEMENT ENCHAÎNÉES

Une liste simplement chaînée est définie par la macro SLIST_HEAD. Cette structure contient un seul pointeur vers le premier élément de la liste. Les éléments sont simplement chaînés pour minimiser l'espace et la surcharge de manipulation des pointeurs, mais au prix de O(n) pour la suppression d'éléments arbitraires. De nouveaux éléments peuvent être ajoutés à la liste après un élément existant ou en tête de liste. Une structure SLIST_HEAD est déclarée comme suit :

SLIST_HEAD(HEADNAME, TYPE) head;

où HEADNAME est le nom de la structure à définir, et TYPE est le type des éléments de la liste. Un pointeur vers la tête de la liste peut être déclaré ultérieurement comme suit :

struct HEADNAME *headp;

(Les noms head et headp sont sélectionnables par l'utilisateur.)

La macro SLIST_HEAD_INITIALIZER évalue à un initialiseur pour la liste head.

La macro SLIST_CONCAT concatène la liste pointée par head2 à la fin de la liste pointée par head1, vidant la première liste. Son utilisation doit être évitée dans les chemins de code à forte utilisation ou lors de l'opération sur de longues listes. Une liste simplement chaînée comme file d'attente doit être utilisée si cette macro est nécessaire dans les chemins de code à forte utilisation ou lors de l'opération sur de longues listes.

La macro SLIST_EMPTY évalue à vrai si la liste ne contient aucun élément.

La macro SLIST_ENTRY déclare une structure qui relie les éléments de la liste.

La macro SLIST_FIRST renvoie le premier élément de la liste ou NULL si la liste est vide.

La macro SLIST_FOREACH parcourt la liste pointée par head dans le sens avant, attribuant chaque élément à var.

La macro SLIST_FOREACH_FROM se comporte de manière identique à SLIST_FOREACH lorsque var est NULL, sinon elle traite var comme un élément précédemment trouvé dans la liste pointée par head et commence la boucle à partir de var au lieu du premier élément de la liste pointée par head.

La macro SLIST_FOREACH_SAFE parcourt la liste pointée par head dans le sens avant, attribuant chaque élément à var. Cependant, contrairement à SLIST_FOREACH(), il est permis de supprimer var et de le libérer à l'intérieur de la boucle en toute sécurité sans interférer avec la traversée.

La macro SLIST_FOREACH_FROM_SAFE se comporte de manière identique à SLIST_FOREACH_SAFE lorsque var est NULL, sinon elle traite var comme un élément précédemment trouvé dans la liste pointée par head et commence la boucle à partir de var au lieu du premier élément de la liste pointée par head.

La macro SLIST_INIT initialise la liste pointée par head.

La macro SLIST_INSERT_HEAD insère le nouvel élément elm en tête de liste.

La macro SLIST_INSERT_AFTER insère le nouvel élément elm après l'élément listelm dans la liste.

ss="Fa">listeelm.

La macro SLIST_NEXT renvoie l'élément suivant dans la liste.

La macro SLIST_REMOVE_AFTER supprime l'élément qui suit elm de la liste. Contrairement à SLIST_REMOVE, cette macro ne parcourt pas toute la liste.

La macro SLIST_REMOVE_HEAD supprime l'élément elm de la tête de la liste. Pour une efficacité optimale, les éléments supprimés de la tête de la liste doivent utiliser explicitement cette macro plutôt que la macro générique SLIST_REMOVE.

La macro SLIST_REMOVE supprime l'élément elm de la liste. L'utilisation de cette macro doit être évitée car elle parcourt toute la liste. Une liste doublement chaînée devrait être utilisée si cette macro est nécessaire dans des chemins de code à usage intensif ou pour opérer sur de longues listes.

La macro SLIST_SWAP échange le contenu de head1 et head2.

EXEMPLE DE LISTE CHAÎNÉE SIMPLEMENT

SLIST_HEAD(slisthead, entry) head =
    SLIST_HEAD_INITIALIZER(head);
struct slisthead *headp;		/* Tête de liste chaînée simplement. */
struct entry {
	...
	SLIST_ENTRY(entry) entries;	/* Liste chaînée simplement. */
	...
} *n1, *n2, *n3, *np;

SLIST_INIT(&head);			/* Initialisation de la liste. */

n1 = malloc(sizeof(struct entry));	/* Insertion à la tête. */
SLIST_INSERT_HEAD(&head, n1, entries);

n2 = malloc(sizeof(struct entry));	/* Insertion après. */
SLIST_INSERT_AFTER(n1, n2, entries);

SLIST_REMOVE(&head, n2, entry, entries);/* Suppression. */
free(n2);

n3 = SLIST_FIRST(&head);
SLIST_REMOVE_HEAD(&head, entries);	/* Suppression de la tête. */
free(n3);
					/* Parcours avant. */
SLIST_FOREACH(np, &head, entries)
	np-> ...
					/* Parcours avant sûr. */
SLIST_FOREACH_SAFE(np, &head, entries, np_temp) {
	np->do_stuff();
	...
	SLIST_REMOVE(&head, np, entry, entries);
	free(np);
}

while (!SLIST_EMPTY(&head)) {		/* Suppression de la liste. */
	n1 = SLIST_FIRST(&head);
	SLIST_REMOVE_HEAD(&head, entries);
	free(n1);
}

FILES D'ATTENTE À QUEUE SIMPLEMENT CHAÎNÉES

Une file d'attente à queue simplement chaînée est dirigée par une structure définie par la macro STAILQ_HEAD. Cette structure contient une paire de pointeurs, l'un vers le premier élément de la file d'attente à queue et l'autre vers le dernier élément de la file d'attente à queue. Les éléments sont chaînés simplement pour minimiser l'espace et la manipulation des pointeurs, au détriment d'une suppression en O(n) pour les éléments arbitraires. De nouveaux éléments peuvent être ajoutés à la file d'attente à queue après un élément existant, en tête de la file d'attente à queue, ou à la fin de la file d'attente à queue. Une structure STAILQ_HEAD est déclarée comme suit :

STAILQ_HEAD(HEADNAME, TYPE) head;

où HEADNAME est le nom de la structure à définir, et TYPE est le type des éléments à chaîner dans la file d'attente à queue. Un pointeur vers la tête de la file d'attente à queue peut ensuite être déclaré comme :

struct HEADNAME *headp;

(Les noms head et headp sont sélectionnables par l'utilisateur.)

La macro STAILQ_HEAD_INITIALIZER évalue à un initialiseur pour la file d'attente à queue head.

La macro STAILQ_CONCAT concatène la file d'attente à queue dirigée par head2 à la fin de celle dirigée par head1, en supprimant toutes les entrées de la première.

La macro STAILQ_EMPTY évalue à vrai s'il n'y a pas d'éléments dans la file d'attente à queue.

La macro STAILQ_ENTRY déclare une structure qui relie les éléments de la file d'attente à queue.

La macro STAILQ_FIRST renvoie le premier élément de la file d'attente à queue ou NULL si la file d'attente à queue est vide.

La macro STAILQ_FOREACH parcourt la file d'attente à queue référencée par head dans le sens avant, en assignant chaque élément à tour de rôle à var.

La macro STAILQ_FOREACH_FROM se comporte identiquement à STAILQ_FOREACH lorsque var est NULL, sinon elle traite var comme un élément STAILQ précédemment trouvé et commence la boucle à var au lieu du premier élément dans le STAILQ référencé par head.

La macro STAILQ_FOREACH_SAFE parcourt la file d'attente à queue référencée par head dans le sens avant, en assignant chaque élément à tour de rôle à var. Cependant, contrairement à STAILQ_FOREACH() il est permis ici de supprimer var ainsi que de le libérer depuis l'intérieur de la boucle en toute sécurité sans interférer avec le parcours.

La macro STAILQ_FOREACH_FROM_SAFE se comporte identiquement à STAILQ_FOREACH_SAFE lorsque var est NULL, sinon elle traite var comme un élément STAILQ précédemment trouvé et commence la boucle à var au lieu du premier élément dans le STAILQ référencé par head.

La macro STAILQ_INIT initialise la file d'attente à queue référencée par head.

La macro STAILQ_INSERT_HEAD insère le nouvel élément elm en tête de la file d'attente à queue.

La macro STAILQ_INSERT_TAIL insère le nouvel élément elm à la fin de la file d'attente à queue.

La macro STAILQ_INSERT_AFTER insère le nouvel élément elm après l'élément listelm.

La macro STAILQ_LAST renvoie le dernier élément de la file d'attente à queue. Si la file d'attente à queue est vide, la valeur de retour est NULL.

La macro STAILQ_NEXT renvoie le prochain élément de la file d'attente à queue, ou NULL si cet élément est le dernier.

La macro STAILQ_REMOVE_AFTER supprime l'élément qui suit elm de la file d'attente à queue. Contrairement à STAILQ_REMOVE, cette macro ne parcourt pas toute la file d'attente à queue.

La macro STAILQ_REMOVE_HEAD supprime l'élément en tête de la file d'attente à queue. Pour une efficacité optimale, les éléments supprimés de la tête de la file d'attente à queue doivent utiliser explicitement cette macro plutôt que la macro générique STAILQ_REMOVE.

La macro STAILQ_REMOVE supprime l'élément elm de la file d'attente à queue. L'utilisation de cette macro doit être évitée car elle parcourt toute la liste. Une file d'attente à queue doublement chaînée devrait être utilisée si cette macro est nécessaire dans des chemins de code à usage intensif ou pour opérer sur de longues files d'attente à queue.

La macro STAILQ_SWAP échange le contenu de head1 et head2.

EXEMPLE DE FILE D'ATTENTE À QUEUE SIMPLEMENT CHAÎNÉE

STAILQ_HEAD(stailhead, entry) head =
    STAILQ_HEAD_INITIALIZER(head);
struct stailhead *headp;		/* Tête de file d'attente à queue simplement chaînée. */
struct entry {
	...
	STAILQ_ENTRY(entry) entries;	/* File d'attente à queue. */
	...
} *n1, *n2, *n3, *np;

STAILQ_INIT(&head);			/* Initialisation de la file. */

n1 = malloc(sizeof(struct entry));	/* Insertion à la tête. */
STAILQ_INSERT_HEAD(&head, n1, entries);

n1 = malloc(sizeof(struct entry));	/* Insertion à la queue. */
STAILQ_INSERT_TAIL(&head, n1, entries);

n2 = malloc(sizeof(struct entry));	/* Insertion après. */
STAILQ_INSERT_AFTER(&head, n1, n2, entries);
					/* Suppression. */
STAILQ_REMOVE(&head, n2, entry, entries);
free(n2);
					/* Suppression de la tête. */
n3 = STAILQ_FIRST(&head);
STAILQ_REMOVE_HEAD(&head, entries);
free(n3);
					/* Parcours avant. */
STAILQ_FOREACH(np, &head, entries)
	np-> ...
					/* Parcours avant sûr. */
STAILQ_FOREACH_SAFE(np, &head, entries, np_temp) {
	np->do_stuff();
	...
	STAILQ_REMOVE(&head, np, entry, entries);
	free(np);
}
					/* Suppression de la TailQ. */
while (!STAILQ_EMPTY(&head)) {
	n1 = STAILQ_FIRST(&head);
	STAILQ_REMOVE_HEAD(&head, entries);
	free(n1);
}
					/* Suppression plus rapide de la TailQ. */
n1 = STAILQ_FIRST(&head);
while (n1 != NULL) {
	n2 = STAILQ_NEXT(n1, entries);
	free(n1);
	n1 = n2;
}
STAILQ_INIT(&head);

LISTES

Une liste est dirigée par une structure définie par la macro LIST_HEAD. Cette structure contient un seul pointeur vers le premier élément de la liste. Les éléments sont doublement chaînés de manière à ce qu'un élément arbitraire puisse être supprimé sans parcourir la liste. De nouveaux éléments peuvent être ajoutés à la liste après un élément existant, avant un élément existant, ou en tête de la liste. Une structure LIST_HEAD est déclarée comme suit :

LIST_HEAD(HEADNAME, TYPE) head;

où HEADNAME est le nom de la structure à définir, et TYPE est le type des éléments à chaîner dans la liste. Un pointeur vers la tête de la liste peut ensuite être déclaré comme :

struct HEADNAME *headp;

(Les noms head et headp sont sélectionnables par l'utilisateur.)

La macro LIST_HEAD_INITIALIZER évalue à un initialiseur pour la liste head.

La macro LIST_CONCAT concatène la liste dirigée par head2 à la fin de celle dirigée par head1, en supprimant toutes les entrées de la première. L'utilisation de cette macro doit être évitée car elle parcourt la totalité de la liste head1. Une file d'attente à queue devrait être utilisée si cette macro est nécessaire dans des chemins de code à usage intensif ou pour opérer sur de longues listes.

La macro LIST_EMPTY évalue à vrai s'il n'y a aucun élément dans la liste.

La macro LIST_ENTRY déclare une structure qui relie les éléments de la liste.

La macro LIST_FIRST renvoie le premier élément de la liste ou NULL si la liste est vide.

La macro LIST_FOREACH parcourt la liste référencée par head en direction avant.

LISTS

Una lista está definida por la macro LIST_HEAD. Esta estructura contiene un puntero al primer elemento de la lista. Los elementos de la lista son enlazados doblemente de modo que se puede remover un elemento arbitrario sin tener que recorrer la lista. Se pueden insertar nuevos elementos al frente de la lista o después de un elemento existente. Una estructura LIST_HEAD se declara así:

LIST_HEAD(HEADNAME, TYPE) head;

donde HEADNAME es el nombre de la estructura a definir y TYPE es el tipo de los elementos enlazados en la lista. Un puntero al cabezal de la lista puede ser declarado posteriormente así:

struct HEADNAME *headp;

(Los nombres head y headp son seleccionables por el usuario.)

La macro LIST_HEAD_INITIALIZER evalúa a un inicializador para la lista head.

La macro LIST_EMPTY evalúa a verdadero si no hay elementos en la lista.

La macro LIST_ENTRY declara una estructura que conecta los elementos de la lista.

La macro LIST_FIRST devuelve el primer elemento de la lista, o NULL si la lista está vacía.

La macro LIST_FOREACH recorre la lista referida a head en la dirección forward, asignando cada elemento en su orden a var.

El macro LIST_FOREACH_FROM comporta identicamente a LIST_FOREACH cuando var es NULL, sino trata var como un elemento previamente encontrado en la lista referida a head y empieza el bucle en var en lugar del primer elemento de la lista referida a head.

El macro LIST_FOREACH_SAFE recorre la lista referida a head en la dirección forward, asignando cada elemento en su orden a var. Sin embargo, a diferencia de LIST_FOREACH() aquí es permitido ambos remover var y liberar de forma segura var dentro del bucle sin interferir con la trayectoria.

El macro LIST_FOREACH_FROM_SAFE comporta identicamente a LIST_FOREACH_SAFE cuando var es NULL, sino trata var como un elemento previamente encontrado en la lista referida a head y empieza el bucle en var en lugar del primer elemento de la lista referida a head.

El macro LIST_INIT inicializa la lista referida a head.

El macro LIST_INSERT_HEAD inserta el elemento nuevo elm al frente de la lista.

El macro LIST_INSERT_AFTER inserta el elemento nuevo elm después del elemento listelm.

El macro LIST_INSERT_BEFORE inserta el elemento nuevo elm antes del elemento listelm.

El macro LIST_NEXT devuelve el siguiente elemento en la lista, o NULL si este es el último.

El macro LIST_PREV devuelve el elemento anterior en la lista, o NULL si este es el primero. La lista head debe contener el elemento elm.

El macro LIST_REMOVE elimina el elemento elm de la lista.

El macro LIST_SWAP intercambia los contenidos de head1 y head2.

LIST EXAMPLE

LIST_HEAD(listhead, entry) head =
    LIST_HEAD_INITIALIZER(head);
struct listhead *headp;			/* List head. */
struct entry {
	...
	LIST_ENTRY(entry) entries;	/* List. */
	...
} *n1, *n2, *n3, *np, *np_temp;

LIST_INIT(&head);			/* Initialize the list. */

n1 = malloc(sizeof(struct entry));	/* Insert at the head. */
LIST_INSERT_HEAD(&head, n1, entries);

n2 = malloc(sizeof(struct entry));	/* Insert after. */
LIST_INSERT_AFTER(n1, n2, entries);

n3 = malloc(sizeof(struct entry));	/* Insert before. */
LIST_INSERT_BEFORE(n2, n3, entries);

LIST_REMOVE(n2, entries);		/* Deletion. */
free(n2);
					/* Forward traversal. */
LIST_FOREACH(np, &head, entries)
	np-> ...

					/* Safe forward traversal. */
LIST_FOREACH_SAFE(np, &head, entries, np_temp) {
	np->do_stuff();
	...
	LIST_REMOVE(np, entries);
	free(np);
}

while (!LIST_EMPTY(&head)) {		/* List Deletion. */
	n1 = LIST_FIRST(&head);
	LIST_REMOVE(n1, entries);
	free(n1);
}

n1 = LIST_FIRST(&head);			/* Faster List Deletion. */
while (n1 != NULL) {
	n2 = LIST_NEXT(n1, entries);
	free(n1);
	n1 = n2;
}

TAIL QUEUES

Una cola de cola final está definida por la macro TAILQ_HEAD. Esta estructura contiene un par de punteros, uno al primer elemento en la cola de cola final y otro al último elemento en la cola de cola final. Los elementos son ligados doblemente de modo que un elemento arbitrario puede ser removido sin tener que recorrer la cola de cola final. Se pueden agregar nuevos elementos a la cola de cola final después de un elemento existente, antes de un elemento existente, al frente de la cola de cola final, o al final de la cola de cola final. Una estructura TAILQ_HEAD se declara así:

TAILQ_HEAD(HEADNAME, TYPE) head;

donde HEADNAME es el nombre de la estructura a definir y TYPE es el tipo de los elementos ligados a la cola de cola final. Un puntero al cabezal de la cola de cola final puede ser posteriormente declarado así:

struct HEADNAME *headp;

(Los nombres head y headp son seleccionables por el usuario.)

La macro TAILQ_HEAD_INITIALIZER evalúa a un inicializador para la cola de cola head.

La macro TAILQ_CONCAT concatená la cola de cola final dirigida por head2 al final de la cola de cola final dirigida por head1 eliminando todos los elementos de la anterior.

La macro TAILQ_EMPTY evalúa a verdadero si no hay elementos en la cola de cola.

La macro TAILQ_ENTRY declara una estructura que conecta los elementos de la cola de cola.

La macro TAILQ_FIRST devuelve el primer elemento de la cola de cola o NULL si la cola de cola está vacía.

La macro TAILQ_FOREACH recorre la cola de cola referida a head en la dirección forward, asignando cada elemento en su orden a var. var es establecido a NULL si el bucle termina normalmente, o si no hay elementos.

La macro TAILQ_FOREACH_FROM comporta identicamente a TAILQ_FOREACH cuando var es NULL, sino trata var como un elemento previamente encontrado en la cola de cola y empieza el bucle en var en lugar del primer elemento de la cola de cola referida a head.

La macro TAILQ_FOREACH_REVERSE recorre la cola de cola referida a head en la dirección reversa, asignando cada elemento en su orden a var.

La macro TAILQ_FOREACH_REVERSE_FROM comporta identicamente a TAILQ_FOREACH_REVERSE cuando var es NULL, sino trata var como un elemento previamente encontrado en la cola de cola y empieza el bucle en var en lugar del último elemento de la cola de cola referida a head.

Las macros TAILQ_FOREACH_SAFE y TAILQ_FOREACH_REVERSE_SAFE recorren la lista referida a head en la dirección forward o reversa respectivamente, asignando cada elemento en su orden a var. Sin embargo, a diferencia de sus contrarios seguros, TAILQ_FOREACH y TAILQ_FOREACH_REVERSE permiten tanto remover como liberar de forma segura var dentro del bucle sin interferir con la trayectoria.

La macro TAILQ_FOREACH_FROM_SAFE comporta identicamente a TAILQ_FOREACH_SAFE cuando var es NULL, sino trata var como un elemento previamente encontrado en la cola de cola y empieza el bucle en var en lugar del primer elemento de la cola de cola referida a head.

La macro TAILQ_FOREACH_REVERSE_FROM_SAFE comporta identicamente a TAILQ_FOREACH_REVERSE_SAFE cuando var es NULL, sino trata var como un elemento previamente encontrado en la cola de cola y empieza el bucle en var en lugar del último elemento de la cola de cola referida a head.

La macro TAILQ_INIT inicializa la cola de cola referida a head.

La macro TAILQ_INSERT_HEAD inserta el elemento nuevo elm al frente de la cola de cola.

La macro TAILQ_INSERT_TAIL inserta el elemento nuevo elm al final de la cola de cola.

La macro TAILQ_INSERT_AFTER inserta el elemento nuevo elm después del elemento listelm.

La macro TAILQ_INSERT_BEFORE inserta el elemento nuevo elm antes del elemento listelm.

La macro TAILQ_LAST devuelve el último elemento de la cola de cola. Si la cola de cola está vacía, el valor devuelto es NULL.

La macro TAILQ_NEXT devuelve el siguiente elemento de la cola de cola, o NULL si este es el último.

La macro TAILQ_PREV devuelve el elemento anterior de la cola de cola, o NULL si este es el primero.

La macro TAILQ_REMOVE elimina el elemento elm de la cola de cola.

La macro TAILQ_SWAP intercambia los contenidos de head1 y head2.

queue(3)






BIBLIOTHÈQUE


libbsd






SYNTAXE


queue(3)






DESCRIPTION


La queue est un ensemble de fonctions qui permettent de manipuler des listes chaînées de manière efficace, avec la capacité de détecter une utilisation après la suppression d'éléments.






LISTES SIMPLEMENT CHAÎNÉES


Les fonctions queue(3) sont basées sur des listes chaînées simples, où chaque élément possède un pointeur vers l'élément suivant. Pour éviter qu'un élément ne soit supprimé de la liste, il faut s'assurer que le pointeur vers l'élément suivant pointe vers un élément qui n'est pas dans la liste.






EXEMPLE DE LISTE SIMPLEMENT CHAÎNÉE


L'exemple suivant montre comment les listes chaînées simples sont gérées :


struct node {
    struct node *next;
    void *data;
};

int main() {
    struct node *n1 = malloc(sizeof(struct node));
    struct node *n2 = malloc(sizeof(struct node));
    n1->next = n2;
    n2->next = NULL;
    n1 = n2;
}
TAILQ_INIT(&head);







FILES À QUEUE SIMPLEMENT CHAÎNÉES


Les fonctions queue(3) peuvent également être utilisées pour implémenter efficacement des files à queue. Dans cette implémentation, le pointeur vers l'élément suivant est aligné avec le pointeur vers l'élément suivant dans la file.






EXEMPLE DE FILE À QUEUE SIMPLEMENT CHAÎNÉE


L'exemple suivant montre comment les files à queue sont gérées efficacement :


struct node {
    struct node *next;
    void *data;
};

int main() {
    struct node *n1 = malloc(sizeof(struct node));
    struct node *n2 = malloc(sizeof(struct node));
    n1->next = n2;
    n2->next = NULL;
    n1 = n2;
}
TAILQ_INIT(&head);

DIAGNOSTICS


Lors du débogage de queue(3), il peut être utile de tracer les modifications apportées à la file. Pour activer le traçage, définissez la macro QUEUE_MACRO_DEBUG_TRACE lors de la compilation.


Il peut également être utile de tracer les pointeurs qui ont été détachés d'une file, afin de détecter une utilisation après suppression. Pour activer le traçage des pointeurs, définissez la macro QUEUE_MACRO_DEBUG_TRASH lors de la compilation. La macro QMD_IS_TRASHED(void *ptr) renvoie vrai si ptr a été tracé par l'option QUEUE_MACRO_DEBUG_TRASH.
