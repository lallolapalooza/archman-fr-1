NOM

TransientShell — La classe de widget TransientShell

SYNTAXIS

#include <Xm/Xm.h>
#include <X11/Shell.h>

DESCRIPTION

TransientShell est utilisé pour les fenêtres shell qui peuvent être manipulées par le gestionnaire de fenêtres, mais qui ne sont pas autorisées à être iconifiées séparément. Par exemple, les DialogBoxes n'ont pas de sens sans leur application associée. Elles sont iconifiées par le gestionnaire de fenêtres uniquement si le shell d'application principal est iconifié.

Classes

TransientShell hérite des comportements et des ressources de Core, Composite, Shell, WMShell et VendorShell.

Le pointeur de classe est transientShellWidgetClass.

Le nom de la classe est TransientShell.

Nouvelles Ressources

Le tableau suivant définit un ensemble de ressources de widgets utilisées par le programmeur pour spécifier des données. Le programmeur peut également définir les valeurs des ressources pour les classes héritées afin de définir les attributs de ce widget. Pour faire référence à une ressource par son nom ou par sa classe dans un fichier .Xdefaults, supprimez le préfixe XmN ou XmC et utilisez les lettres restantes. Pour spécifier l'une des valeurs définies pour une ressource dans un fichier .Xdefaults, supprimez le préfixe Xm et utilisez les lettres restantes (en minuscules ou en majuscules, mais incluez les underscores entre les mots). Les codes dans la colonne d'accès indiquent si la ressource donnée peut être définie au moment de la création (C), définie à l'aide de XtSetValues (S), récupérée à l'aide de XtGetValues (G), ou si elle n'est pas applicable (N/A).

En plus de ces nouvelles ressources, TransientShell remplace la ressource XmNsaveUnder de Shell et la ressource XmNtransient de WMShell.
