DESCRIPCIÓN

Estas macros definen constantes y nombres de función para pruebas y operaciones de CBLAS.

Define valores para estados de prueba (PASSED, FAILED, INVALID, UNDEFINED), la paridad de la matriz (TEST_ROW_MJR, TEST_COL_MJR), y constantes lógicas (TRUE, FALSE).

También incluye definiciones de macros para las funciones Fortran de CBLAS, utilizando la macro `F77_GLOBAL` para manejar las convenciones de nomenclatura específicas de Fortran.

Se proporciona documentación detallada para cada macro individualmente.
