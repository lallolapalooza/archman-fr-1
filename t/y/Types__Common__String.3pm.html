Types::Common::String(3) Documentation Perl fournie par l'utilisateur Types::Common::String(3)

NOM

Types::Common::String - remplacement à chaud pour MooseX::Types::Common::String

STATUT

Ce module est couvert par la politique de stabilité de Type-Tiny.

DESCRIPTION

Un remplacement à chaud pour MooseX::Types::Common::String.

Types

Les types suivants sont similaires à ceux décrits dans MooseX::Types::Common::String.

  • SimpleStr
  • NonEmptySimpleStr
  • NumericCode
  • LowerCaseSimpleStr
  • UpperCaseSimpleStr
  • Password
  • StrongPassword
  • NonEmptyStr
  • LowerCaseStr
  • UpperCaseStr

Ce module définit également certaines contraintes de type supplémentaires non présentes dans MooseX::Types::Common::String.

  • StrLength[`min, `max]

    Contrainte de type pour une chaîne de caractères d'une longueur comprise entre min et max. Par exemple :

    StrLength[4, 20]

    Il est parfois utile de combiner ceci avec une autre contrainte de type dans une intersection.

    (LowerCaseStr) & (StrLength[4, 20])

    La longueur maximale peut être omise.

    StrLength[10]   # au moins 10 caractères

    Les longueurs sont inclusives.

  • DelimitedStr[`delimiter, `type, `min, `max, `ws]

    Contrainte paramétrée pour les chaînes délimitées, telles que les chaînes délimitées par des virgules.

    DelimitedStr[",", Int, 1, 3] autorisera entre 1 et 3 entiers, séparés par des virgules. Ainsi, "1,42,-999" réussira la contrainte de type, mais "Hello,45" échouera.

    Le paramètre ws autorise les espaces blancs facultatifs entourant les délimiteurs, ainsi que les espaces blancs en début et fin de chaîne.

    Les paramètres type, min, max et ws sont facultatifs.

    Les contraintes de type paramétrées DelimitedStr auront automatiquement une coercion à partir de ArrayRef[`type] qui utilise "join" pour joindre par le délimiteur. La contrainte de type non paramétrée DelimitedStr a une coercion à partir de ArrayRef[Str] qui joint les chaînes en utilisant le séparateur de liste $" (qui est un espace par défaut).
