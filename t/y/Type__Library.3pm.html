NOM

Type::Library - petites bibliothèques de types compatibles avec Moo(se)

SYNOPSIS

package Types::Mine {
   use Scalar::Util qw(looks_like_number);
   use Type::Library -base;
   use Type::Tiny;

   my $NUM = "Type::Tiny"->new(
      name       => "Nombre",
      constraint => sub { looks_like_number($_) },
      message    => sub { "$_ n'est pas un nombre" },
   );

   __PACKAGE__->meta->add_type($NUM);

   __PACKAGE__->meta->make_immutable;
}

package Ermintrude {
   use Moo;
   use Types::Mine qw(Nombre);
   has nombre_prefere => (is => "ro", isa => Nombre);
}

package Bullwinkle {
   use Moose;
   use Types::Mine qw(Nombre);
   has nombre_prefere => (is => "ro", isa => Nombre);
}

package Maisy {
   use Mouse;
   use Types::Mine qw(Nombre);
   has nombre_prefere => (is => "ro", isa => Nombre);
}

STATUT

Ce module est couvert par la politique de stabilité de Type-Tiny.

DESCRIPTION

Type::Library est une petite classe pour créer des bibliothèques de types de type MooseX::Types, compatibles avec Moo, Moose et Mouse.

Si vous lisez ceci parce que vous voulez créer une bibliothèque de types, vous feriez probablement mieux de lire Type::Tiny::Manual::Libraries.

Méthodes de bibliothèque de types

Une bibliothèque de types est une classe singleton. Utilisez la méthode "meta" pour obtenir un objet béni auquel d'autres méthodes peuvent être appelées. Par exemple:

Types::Mine->meta->add_type($foo);
add_type($type) ou add_type(%opts)
Ajoute un type à la bibliothèque. Si %opts est fourni, cette méthode appelle "Type::Tiny->new(%opts)" d'abord, et ajoute le type résultant.

L'ajout d'un type nommé "Foo" à la bibliothèque définira automatiquement quatre fonctions dans l'espace de noms de la bibliothèque:

"Foo"
Retourne l'objet Type::Tiny.
is_Foo($value)
Retourne vrai si $value passe la contrainte de type.
assert_Foo($value)
Retourne $value si $value passe la contrainte de type. Meurt sinon.
to_Foo($value)
Coercit la valeur vers le type.
get_type($name)
Récupère l'objet "Type::Tiny" correspondant au nom.
has_type($name)
Booléen ; retourne vrai si le type existe dans la bibliothèque.
"type_names"
Liste tous les types définis par la bibliothèque.
add_coercion($c) ou add_coercion(%opts)
Ajoute une coercition autonome à la bibliothèque. Si %opts est fourni, cette méthode appelle "Type::Coercion->new(%opts)" d'abord, et ajoute la coercition résultante.

L'ajout d'une coercition nommée "FooFromBar" à la bibliothèque définira automatiquement une fonction dans l'espace de noms de la bibliothèque:

"FooFromBar"
Retourne l'objet Type::Coercion.
get_coercion($name)
Récupère l'objet "Type::Coercion" correspondant au nom.
has_coercion($name)
Booléen ; retourne vrai si la coercition existe dans la bibliothèque.
"coercion_names"
Liste toutes les coercitions autonomes définies par la bibliothèque.
import(@args)
Les bibliothèques basées sur Type::Library sont des exportateurs.
"make_immutable"
Empêche l'ajout de nouvelles contraintes de type et de coercitions à la bibliothèque, et appelle également "$type->coercion->freeze" sur chaque contrainte de type de la bibliothèque.

(Avant Type::Library v2, "make_immutable" appelait "$type->coercion->freeze" sur chaque contrainte de la bibliothèque, mais n'empêchait pas l'ajout de nouvelles contraintes de type et de coercitions à la bibliothèque.)

Fonctions exportées par la bibliothèque de types

Les bibliothèques de types sont des exportateurs. Aux fins des exemples suivants, supposez que la bibliothèque "Types::Mine" définit les types "Nombre" et "Chaîne".

# N'exporte rien.
# 
use Types::Mine;

# Exporte une fonction "Chaîne" qui est une constante retournant
# la contrainte de type Chaîne.
#
use Types::Mine qw( Chaîne );

# Exporte Chaîne et Nombre comme ci-dessus.
#
use Types::Mine qw( Chaîne Nombre );

# Identique.
#
use Types::Mine qw( :types );

# Exporte "coerce_Chaîne" et "coerce_Nombre", ainsi que toute autre
# coercition.
#
use Types::Mine qw( :coercions );

# Exporte une sous-routine "is_Chaîne" de sorte que "is_Chaîne($foo)"
# soit équivalent à "Chaîne->check($foo)".
#
use Types::Mine qw( is_Chaîne );

# Exporte "is_Chaîne" et "is_Nombre".
#
use Types::Mine qw( :is );

# Exporte une sous-routine "assert_Chaîne" de sorte que "assert_Chaîne($foo)"
# soit équivalent à "Chaîne->assert_return($foo)".
#
use Types::Mine qw( assert_Chaîne );

# Exporte "assert_Chaîne" et "assert_Nombre".
#
use Types::Mine qw( :assert );

# Exporte une sous-routine "to_Chaîne" de sorte que "to_Chaîne($foo)"
# soit équivalent à "Chaîne->coerce($foo)".
#
use Types::Mine qw( to_Chaîne );

# Exporte "to_Chaîne" et "to_Nombre".
#
use Types::Mine qw( :to );

# Exporte "Chaîne", "is_Chaîne", "assert_Chaîne" et "coerce_Chaîne".
#
use Types::Mine qw( +Chaîne );

# Exporte tout.
#
use Types::Mine qw( :all );

Les bibliothèques de types héritent automatiquement d'Exporter::Tiny ; consultez la documentation de ce module pour des astuces et des conseils sur l'importation depuis des bibliothèques.

Méthodes de Type::Library

Les sections ci-dessus décrivent les caractéristiques des bibliothèques créées avec Type::Library. Les méthodes suivantes sont disponibles sur Type::Library lui-même.

"setup_type_library( $package, $utils, \@extends )"
Configure un paquet pour être une bibliothèque de types. $utils est un booléen indiquant s'il faut importer Type::Utils dans le paquet. @extends est une liste de bibliothèques de types existantes que le paquet doit étendre.
