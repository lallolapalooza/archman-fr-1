NOM

Type::Tiny::Manual::AllTypes - liste alphabétique de tous les types de contraintes regroupés avec Type::Tiny

MANUEL

Ce qui suit est une liste des contraintes de type regroupées avec Type::Tiny, avec des descriptions très brèves. Pour plus d'informations, voir la documentation de la bibliothèque de types, et les cas de test dans "t/21-types/".

Lien GitHub : https://github.com/tobyink/p5-type-tiny/tree/master/t/21-types.

  • Any dans Types::Standard

    N'importe quoi. Absolument n'importe quoi.

  • ArrayLike [paramétrable] dans Types::TypeTiny

    Références de tableau et objets surchargeant la conversion en tableau.

  • ArrayRef [paramétrable] dans Types::Standard

    Références de tableau.

  • Bool [a une coercition] dans Types::Standard

    Booléens ; les nombres ou chaînes "0" et "1", la chaîne vide, ou undef.

  • BoolLike dans Types::TypeTiny

    Similaire à Bool, mais sans coercitions, et accepte les objets surchargeant "bool".

  • ClassName dans Types::Standard

    Tout nom de paquet chargé.

  • CodeLike dans Types::TypeTiny

    Références de code et objets surchargeant la conversion en référence de code.

  • CodeRef dans Types::Standard

    Références de code.

  • ConsumerOf [paramétrable] dans Types::Standard

    Un objet qui FAIT un rôle particulier.

  • CycleTuple [paramétrable] dans Types::Standard

    Une référence de tableau avec un motif répétitif de contraintes sur ses valeurs.

  • Defined dans Types::Standard

    Toute valeur autre que undef.

  • DelimitedStr [paramétrable] dans Types::Common::String

    Une chaîne délimitée par des virgules ou autre.

  • Dict [paramétrable] dans Types::Standard

    Une référence de hachage avec des contraintes sur chacune de ses valeurs.

  • Enum [paramétrable] dans Types::Standard

    Une chaîne parmi un ensemble autorisé de chaînes.

  • _ForeignTypeConstraint dans Types::TypeTiny

    Une référence de code ou un objet que Type::Tiny sait convertir en instance de Type::Tiny. (Oui, le nom de ce type commence par un underscore.)

  • FileHandle dans Types::Standard

    Une référence pour laquelle Scalar::Util::openhandle renvoie vrai, ou un objet béni dans la classe IO::Handle.

  • GlobRef dans Types::Standard

    Références glob.

  • HashLike [paramétrable] dans Types::TypeTiny

    Références de hachage et objets surchargeant la conversion en référence de hachage.

  • HashRef [paramétrable] dans Types::Standard

    Références de hachage.

  • HasMethods [paramétrable] dans Types::Standard

    Un objet capable d'exécuter des méthodes particulières.

  • InstanceOf [paramétrable] dans Types::Standard

    Un objet qui est d'une classe particulière.

  • Int dans Types::Standard

    Un nombre entier, positif, négatif ou nul.

  • IntRange [paramétrable] dans Types::Common::Numeric

    Un entier dans une plage numérique particulière.

  • Item dans Types::Standard

    N'importe quel élément unique ; effectivement identique à Any.

  • LaxNum dans Types::Standard

    Un nombre ; contrainte relâchée qui autorise "inf".

  • LowerCaseSimpleStr [a une coercition] dans Types::Common::String

    Une chaîne de moins de 256 caractères sans sauts de ligne ni lettres majuscules.

  • LowerCaseStr [a une coercition] dans Types::Common::String

    Une chaîne sans lettres majuscules.

  • Map [paramétrable] dans Types::Standard

    Une référence de hachage avec une contrainte pour les valeurs et les clés.

  • Maybe [paramétrable] dans Types::Standard

    Lorsqu'il est paramétré, identique à son paramètre, mais autorise également undef.

  • NegativeInt dans Types::Common::Numeric

    Un entier inférieur à 0.

  • NegativeNum dans Types::Common::Numeric

    Un nombre inférieur à 0.

  • NegativeOrZeroInt dans Types::Common::Numeric

    Un entier inférieur à 0, ou 0.

  • NegativeOrZeroNum dans Types::Common::Numeric

    Un nombre inférieur à 0, ou 0.

  • NonEmptySimpleStr dans Types::Common::String

    Une chaîne de plus de 0 mais moins de 256 caractères sans sauts de ligne.

  • NonEmptyStr dans Types::Common::String

    Une chaîne de plus de 0 caractère.

  • Num dans Types::Standard

    Identique à LaxNum ou StrictNum selon l'environnement.

  • NumericCode [a une coercition] dans Types::Common::String

    Une chaîne ne contenant que des chiffres.

  • NumRange [paramétrable] dans Types::Common::Numeric

    Un nombre dans une plage numérique particulière.

  • Object dans Types::Standard

    Un objet béni.

  • Optional [paramétrable] dans Types::Standard

    Utilisé conjointement avec Dict, Tuple, ou CycleTuple.

  • OptList dans Types::Standard

    Une référence de tableau de références de tableau, où chacune des références de tableau internes contient deux valeurs, la première étant une chaîne.

  • Overload [paramétrable] dans Types::Standard

    Un objet surchargé.

  • Password dans Types::Common::String

    Une chaîne d'au moins 4 caractères et de moins de 256 caractères sans sauts de ligne.

  • PositiveInt dans Types::Common::Numeric

    Un entier supérieur à 0.

  • PositiveNum dans Types::Common::Numeric

    Un nombre supérieur à 0.

  • PositiveOrZeroInt dans Types::Common::Numeric

    Un entier supérieur à 0, ou 0.

  • PositiveOrZeroNum dans Types::Common::Numeric

    Un nombre supérieur à 0, ou 0.

  • Ref [paramétrable] dans Types::Standard

    N'importe quelle référence.

  • RegexpRef dans Types::Standard

    Une expression régulière.

  • RoleName dans Types::Standard

    Tout nom de paquet chargé pour lequel il n'existe pas de méthode `new`.

  • ScalarRef [paramétrable] dans Types::Standard

    Références scalaires.

  • SimpleStr dans Types::Common::String

    Une chaîne de moins de 256 caractères sans sauts de ligne.

  • SingleDigit dans Types::Common::Numeric

    Un nombre à un seul chiffre. Cela inclut les nombres négatifs à un seul chiffre !

  • Slurpy [paramétrable] dans Types::Standard

    Utilisé conjointement avec Dict ou Tuple.

  • Str dans Types::Standard

    Une chaîne.

  • StrictNum dans Types::Standard

    Un nombre ; contrainte stricte.

  • StringLike dans Types::TypeTiny

    Chaînes et objets surchargeant la conversion en chaîne.

  • StrLength [paramétrable] dans Types::Common::String

    Une chaîne dont la longueur se situe dans une plage particulière.

  • StrMatch [paramétrable] dans Types::Standard

    Une chaîne correspondant à une expression régulière particulière.

  • StrongPassword dans Types::Common::String

    Une chaîne d'au moins 4 caractères et de moins de 256 caractères sans sauts de ligne et comportant au moins un caractère non alphabétique.

  • Tied [paramétrable] dans Types::Standard

    Une référence à une variable liée.

  • Tuple [paramétrable] dans Types::Standard

    Une référence de tableau avec des contraintes sur ses valeurs.

  • TypeTiny [a une coercition] dans Types::TypeTiny

    Objets bénis de la classe Type::Tiny.

  • Undef dans Types::Standard

    undef.

  • UpperCaseSimpleStr [a une coercition] dans Types::Common::String

    Une chaîne de moins de 256 caractères sans sauts de ligne ni lettres minuscules.

  • UpperCaseStr [a une coercition] dans Types::Common::String

    Une chaîne sans lettres minuscules.

  • Value dans Types::Standard

    Toute valeur non-référencée, y compris undef.

Le module Types::Common incorpore tout ce qui précède.
