NOM

Type::Tiny::Manual - un aperçu de Type::Tiny

SYNOPSIS

Type::Tiny est une petite classe Perl http://www.perl.org/ pour écrire des contraintes de type, inspirée par l'API de contraintes de type de Moose et MooseX::Types. Elle n'a qu'une seule dépendance non essentielle (et même celle-ci est simplement un module qui était auparavant distribué dans le cadre de Type::Tiny mais qui a depuis été séparé), et peut être utilisée avec Moose, Mouse, ou Moo (ou aucun des précédents).

Type::Tiny est utilisée par plus de 1000 distributions Perl sur le CPAN (Comprehensive Perl Archive Network) et peut être considérée comme un framework stable et mature pour appliquer efficacement et de manière fiable les types de données.

Type::Tiny est groupé avec Type::Library, un framework pour organiser les contraintes de type en collections. Également groupé, Types::Standard, une bibliothèque de contraintes de type utiles inspirée de Moose. Type::Params est également fourni, pour permettre une vérification et une coercion très rapides des paramètres de fonctions et de méthodes.

L'exemple suivant vous donne une idée de certaines des fonctionnalités de ces modules. Si vous ne comprenez pas tout, ce n'est pas grave ; c'est à cela que sert le reste du manuel. Bien que l'exemple utilise Moo, le "use Moo" pourrait être remplacé par "use Moose" ou "use Mouse" et cela fonctionnerait toujours.

use v5.36;

package Horse {
  use Moo;
  use Types::Standard qw( Str Int Enum ArrayRef InstanceOf );
  use Type::Params qw( signature_for );
  use namespace::autoclean;

  has name => (
    is       => 'ro',
    isa      => Str,
    required => 1,
  );

  has gender => (
    is       => 'ro',
    isa      => Enum[qw( f m )],
  );

  has age => (
    is       => 'rw',
    isa      => Int->where( '$_ >= 0' ),
  );

  has children => (
    is       => 'ro',
    isa      => ArrayRef[ InstanceOf['Horse'] ],
    default  => sub { return [] },
  );

  signature_for add_child => (
    method     => Object,
    positional => [ InstanceOf['Horse'] ],
  );

  sub add_child ( $self, $child ) {
    push $self->children->@*, $child;
    return $self;
  }
}

package main;

my $boldruler = Horse->new(
  name    => "Bold Ruler",
  gender  => 'm',
  age     => 16,
);

my $secretariat = Horse->new(
  name    => "Secretariat",
  gender  => 'm',
  age     => 0,
);

$boldruler->add_child( $secretariat );

use Types::Standard qw( is_Object assert_Object );

# is_Object retournera un booléen
#
if ( is_Object $boldruler ) {
  say $boldruler->name;
}

# assert_Object retournera $secretariat ou mourra
#
say assert_Object( $secretariat )->name;

MANUEL

Même si vous utilisez Type::Tiny avec d'autres kits d'outils de programmation orientée objet (tels que Moose ou Mouse), vous devriez commencer par les sections Moo du manuel. La plupart des informations sont directement transférables et les sections Moose et Mouse du manuel listent les différences mineures entre l'utilisation de Type::Tiny avec Moo et avec eux.

En général, ce manuel suppose que vous utilisez Perl 5.36 ou une version ultérieure et peut utiliser des exemples qui ne fonctionneront pas sur des versions antérieures de Perl. Type::Tiny fonctionne sur des versions antérieures de Perl, mais tous les exemples et fonctionnalités du manuel ne s'exécuteront pas sans ajustement. (Par exemple, vous pourriez avoir besoin de remplacer les variables "state" par des variables lexicales, d'éviter la syntaxe "package NAME { BLOCK }", de décompresser @_ au lieu d'utiliser des signatures de sous-routine, etc.)

  • Type::Tiny::Manual::Installation

    Comment installer Type::Tiny. Si Type::Tiny est déjà installé, vous pouvez ignorer cette section.

  • Type::Tiny::Manual::UsingWithMoo

    Utilisation basique de Type::Tiny avec Moo, y compris les contraintes de type d'attribut, les contraintes de type paramétrées, les coercions et la vérification des paramètres de méthode.

  • Type::Tiny::Manual::UsingWithMoo2

    Utilisation avancée de Type::Tiny avec Moo, y compris les unions et les intersections, "stringifies_to", "numifies_to", "with_attribute_values" et "where".

  • Type::Tiny::Manual::UsingWithMoo3

    Il y a plus d'une façon de faire les choses ! Façons alternatives d'utiliser Type::Tiny, y compris les registres de types, les fonctions exportées et "dwim_type".

  • Type::Tiny::Manual::Libraries

    Définir vos propres bibliothèques de types, y compris l'extension des bibliothèques existantes, la définition de nouveaux types, l'ajout de coercions, la définition de types paramétrables et le style déclaratif.

  • Type::Tiny::Manual::UsingWithMoose

    Comment utiliser Type::Tiny avec Moose, y compris les avantages de Type::Tiny par rapport aux contraintes de type intégrées, et les fonctionnalités spécifiques à Moose.

  • Type::Tiny::Manual::UsingWithMouse

    Comment utiliser Type::Tiny avec Mouse, y compris les avantages de Type::Tiny par rapport aux contraintes de type intégrées, et les fonctionnalités spécifiques à Mouse.

  • Type::Tiny::Manual::UsingWithMite

    Comment utiliser Type::Tiny avec Mite, y compris comment écrire un projet Perl entier en utilisant du code propre de type Moose sans dépendances non essentielles. (Même pas de dépendances sur Mite ou Type::Tiny !)

  • Type::Tiny::Manual::UsingWithClassTiny

    Y compris comment utiliser Type::Tiny dans la méthode "BUILD" de votre objet, et des shims tiers entre Type::Tiny et Class::Tiny.

  • Type::Tiny::Manual::UsingWithOther

    Utiliser Type::Tiny avec Class::InsideOut, Params::Check et Object::Accessor.

  • Type::Tiny::Manual::UsingWithTestMore

    Type::Tiny pour les suites de tests.

  • Type::Tiny::Manual::Params

    Informations avancées sur Type::Params, et utilisation de Type::Tiny avec d'autres modules de signature comme Function::Parameters et Kavorka.

  • Type::Tiny::Manual::NonOO

    Type::Tiny dans du code non orienté objet.

  • Type::Tiny::Manual::Optimization

    Optimiser au maximum votre CPU.

  • Type::Tiny::Manual::Coercions

    Informations avancées sur les coercions.

  • Type::Tiny::Manual::AllTypes

    Une liste alphabétique de toutes les contraintes de type groupées avec Type::Tiny.

  • Type::Tiny::Manual::Policies

    Politiques relatives au développement de Type::Tiny.

  • Type::Tiny::Manual::Contributing

    Contribuer au développement de Type::Tiny.
