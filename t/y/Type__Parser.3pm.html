NOM

Type::Parser - analyser les chaînes de contraintes de type

SYNTAXE

use v5.10;
use strict;
use warnings;

use Type::Parser qw( eval_type );
use Type::Registry;

my $reg = Type::Registry->for_me;
$reg->add_types("Types::Standard");

my $type = eval_type("Int | ArrayRef[Int]", $reg);

$type->check(10);        # vrai
$type->check([1..4]);    # vrai
$type->check({foo=>1});  # faux

STATUT

Ce module est couvert par la politique de stabilité de Type-Tiny.

DESCRIPTION

D'une manière générale, vous ne voudrez probablement pas utiliser ce module directement. Utilisez plutôt la méthode "lookup" de Type::Registry qui l'encapsule.

Fonctions

parse($string)
Analyse la chaîne de contrainte de type en quelque chose comme un AST.

Si appelée dans un contexte de liste, retourne également toute "queue" trouvée dans la chaîne d'origine.

"extract_type($string, $registry)"
Compile une chaîne de contrainte de type en un objet Type::Tiny.

Si appelée dans un contexte de liste, retourne également toute "queue" trouvée dans la chaîne d'origine.

"eval_type($string, $registry)"
Compile une chaîne de contrainte de type en un objet Type::Tiny.

Lève une erreur si la "queue" contient des caractères autres que des espaces blancs.
