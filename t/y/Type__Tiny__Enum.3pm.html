Type::Tiny::Enum(3) Documentation Perl fournie par l'utilisateur Type::Tiny::Enum(3)

NOM

Type::Tiny::Enum - contraintes de type énumérées sous forme de chaînes

SYNOPSIS

Utilisation via Types::Standard :

package Horse {
  use Moo;
  use Types::Standard qw( Str Enum );

  has name    => ( is => 'ro', isa => Str );
  has status  => ( is => 'ro', isa => Enum[ 'alive', 'dead' ] );

  sub neigh {
    my ( $self ) = @_;
    return if $self->status eq 'dead';
    ...;
  }
}

Utilisation de la fonction d'export de Type::Tiny::Enum :

package Horse {
  use Moo;
  use Types::Standard qw( Str );
  use Type::Tiny::Enum Status => [ 'alive', 'dead' ];

  has name    => ( is => 'ro', isa => Str );
  has status  => ( is => 'ro', isa => Status, default => STATUS_ALIVE );

  sub neigh {
    my ( $self ) = @_;
    return if $self->status eq STATUS_DEAD;
    ...;
  }
}

Utilisation de l'interface orientée objet de Type::Tiny::Enum :

package Horse {
  use Moo;
  use Types::Standard qw( Str );
  use Type::Tiny::Enum;

  my $Status = Type::Tiny::Enum->new(
    name   => 'Status',
    values => [ 'alive', 'dead' ],
  );

  has name    => ( is => 'ro', isa => Str );
  has status  => ( is => 'ro', isa => $Status, default => $Status->[0] );

  sub neigh {
    my ( $self ) = @_;
    return if $self->status eq $Status->[0];
    ...;
  }
}

STATUT

Ce module est couvert par la politique de stabilité de Type-Tiny.

DESCRIPTION

Contraintes de type énumérées.

Ce package hérite de Type::Tiny ; voir celui-ci pour la plupart des documentations. Les principales différences sont listées ci-dessous :

Constructeurs

Le constructeur "new" de Type::Tiny fonctionne toujours, bien sûr. Mais il y a aussi :

"new_union( type_constraints => \@enums, %opts )"
Crée une nouvelle contrainte de type énumérée qui est l'union des contraintes de type énumérées existantes.
"new_intersection( type_constraints => \@enums, %opts )"
Crée une nouvelle contrainte de type énumérée qui est l'intersection des contraintes de type énumérées existantes.

Attributs

"values"
Tableau des chaînes de caractères autorisées. Les valeurs non-chaînes (par exemple, des objets avec surcharge) seront converties en chaînes dans le constructeur.
"constraint"
Contrairement à Type::Tiny, vous ne pouvez pas passer un coderef de contrainte au constructeur. Reposez-vous plutôt sur la valeur par défaut.
"inlined"
Contrairement à Type::Tiny, vous ne pouvez pas passer un coderef d'insertion en ligne au constructeur. Reposez-vous plutôt sur la valeur par défaut.
"parent"
Le parent est toujours Types::Standard::Str et ne peut pas être passé au constructeur.
"unique_values"
La liste des "values" mais triée et sans doublons. Cela ne peut pas être passé au constructeur.
"coercion"
Si "coercion => 1" est passé au constructeur, le type aura une coercition utilisant la méthode "closest_match".

Méthodes

"as_regexp"
Retourne l'énumération sous forme d'expression régulière contre laquelle les chaînes peuvent être vérifiées. Si vous vérifiez beaucoup de chaînes, utiliser cette expression régulière pourrait être plus rapide que de vérifier chaque chaîne contre 
my $enum  = Type::Tiny::Enum->new(...);
my $check = $enum->compiled_check;
my $re    = $enum->as_regexp;

# rapide
my @valid_tokens = grep $enum->check($_), @all_tokens;

# plus rapide
my @valid_tokens = grep $check->($_), @all_tokens;

# le plus rapide
my @valid_tokens = grep /$re/, @all_tokens;

Vous pouvez obtenir une expression régulière insensible à la casse en utilisant "$enum->as_regexp('i')".

"closest_match"
Retourne la correspondance la plus proche dans l'énumération pour une chaîne. 
my $enum = Type::Tiny::Enum->new(
  values => [ qw( foo bar baz quux ) ],
);

say $enum->closest_match("FO");   # ==> foo

Il essaiera d'abord de trouver une correspondance exacte, puis une correspondance insensible à la casse. S'il ne trouve toujours pas, il essaiera de trouver une correspondance en préfixe, et enfin, s'il reçoit un entier, il l'utilisera comme indice.

my $enum = Type::Tiny::Enum->new(
  values => [ qw( foo bar baz quux ) ],
);

say $enum->closest_match(  0 );  # ==> foo
say $enum->closest_match(  1 );  # ==> bar
say $enum->closest_match(  2 );  # ==> baz
say $enum->closest_match( -1 );  # ==> quux
"is_word_safe"
Retourne vrai si aucune des valeurs de l'énumération ne contient de caractère non alphanumérique. Les caractères alphanumériques incluent les lettres, les chiffres et les underscores, mais pas la plupart des ponctuations ou des espaces.

Exports

Type::Tiny::Enum peut être utilisé comme exportateur.

use Type::Tiny::Enum Status => [ 'dead', 'alive' ];

Cela exportera les fonctions suivantes dans votre espace de noms :

"Status"
is_Status( $value )
assert_Status( $value )
to_Status( $value )
"STATUS_DEAD"
"STATUS_ALIVE"

Plusieurs énumérations peuvent être exportées simultanément :

use Type::Tiny::Enum (
  Status    => [ 'dead', 'alive' ],
  TaxStatus => [ 'paid', 'pending' ],
);

Surcharge

•
La transformation en tableau appelle "values".
