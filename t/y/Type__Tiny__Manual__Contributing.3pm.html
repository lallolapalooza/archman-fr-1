NOM

Type::Tiny::Manual::Contributing - contribuer au développement de Type::Tiny.

MANUEL

Rapports de bugs

Les rapports de bugs (y compris les demandes de fonctionnalités) peuvent être soumis sur GitHub.

https://github.com/tobyink/p5-type-tiny/issues.

Les cas de test écrits avec Test::More sont toujours appréciés.

Correction des bugs

Si quelque chose ne fonctionne pas comme documenté, ou provoque des plantages inattendus, et que vous savez comment le corriger, veuillez joindre un patch au rapport de bug (voir ci-dessus) ou une demande d'extraction (pull request) au projet sur GitHub.

https://github.com/tobyink/p5-type-tiny.

Veuillez essayer de suivre le style de codage utilisé dans le reste du projet. (Indentation avec des tabulations, espaces pour l'alignement, orthographe en anglais britannique, Pod à la fin du code mais au début des cas de test, etc.)

https://github.com/tobyink/misc-development-tools/blob/master/bin/my-perltidy

Ajout de cas de test

De nouveaux cas de test pour la suite de tests Type::Tiny sont toujours les bienvenus. La page Coveralls pour Type::Tiny devrait révéler quelles parties du code nécessitent le plus de bons cas de test. Tous les fichiers avec une couverture inférieure à 95% sont prioritaires.

https://coveralls.io/github/tobyink/p5-type-tiny.

Type::Tiny est maintenant également sur Codecov, qui comptabilise la couverture différemment, en donnant des objectifs plus stricts à atteindre.

https://codecov.io/gh/tobyink/p5-type-tiny

Type::Tiny::XS

Je ne suis pas vraiment un programmeur C, ni très familier avec les mécanismes internes de Perl, donc toute aide avec Type::Tiny::XS est toujours appréciée. Il existe certaines contraintes de type dans Types::Standard, Types::Common::String et Types::Common::Numeric qui n'ont pas d'implémentations XS.

Écriture de bibliothèques de types

Bien qu'il soit peu probable que j'intègre de nombreuses autres bibliothèques de types dans cette distribution, le téléchargement de vos propres bibliothèques de types sur CPAN renforcera l'écosystème Type::Tiny.

Donner

Si vous ou votre organisation utilisez Type::Tiny et que vous souhaitez contribuer financièrement, vous devriez trouver des liens pour faire un don sur le site web de Type::Tiny à l'adresse https://typetiny.toby.ink/.

Veuillez noter que je ne suggère pas que vous devez le faire pour que je continue à travailler sur Type::Tiny et les modules associés.
