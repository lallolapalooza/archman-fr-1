NOM

Types::Common - le guichet unique

STATUT

Ce module est couvert par la politique de stabilité de Type-Tiny.

CHANGEMENTS FUTURS PRÉVUS

À l'avenir, ce module pourrait également exporter "signature_for_func" et "signature_for_method".

DESCRIPTION

Types::Common ne fournit aucun type ni aucune fonction de son propre chef. Il s'agit plutôt d'un module unique qui ré-exporte :

  • Tous les types de Types::Standard.
  • Tous les types de Types::Common::Numeric et Types::Common::String.
  • Tous les types de Types::TypeTiny.
  • La balise "-sigs" de Type::Params.
  • La fonction t() de Type::Registry.

Si vous importez t(), elle sera également préchargée avec toutes les contraintes de type offertes par Types::Common.

EXPORT

"use Types::Common qw( -types -sigs t )" pourrait être un bon point de départ.

"use Types::Common -all" vous donne tout.

Si vous avez Perl 5.37.2+, alors "use Types::Common qw( -lexical -all )" ne polluera pas votre espace de noms.
