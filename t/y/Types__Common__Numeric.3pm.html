Types::Common::Numeric(3) Documentation Perl fournie par l'utilisateur Types::Common::Numeric(3)

NOM

Types::Common::Numeric - remplacement "drop-in" pour MooseX::Types::Common::Numeric

STATUT

Ce module est couvert par la politique de stabilité de Type-Tiny.

DESCRIPTION

Un remplacement "drop-in" pour MooseX::Types::Common::Numeric.

Types

Les types suivants sont similaires à ceux décrits dans MooseX::Types::Common::Numeric.

  • PositiveNum
  • PositiveOrZeroNum
  • PositiveInt
  • PositiveOrZeroInt
  • NegativeNum
  • NegativeOrZeroNum
  • NegativeInt
  • NegativeOrZeroInt
  • SingleDigit

    "SingleDigit" accepte curieusement les nombres -9 à -1 ; pas seulement 0 à 9.

Ce module définit également une paire supplémentaire de contraintes de type introuvables dans MooseX::Types::Common::Numeric.

  • IntRange[`min, `max]

    Contrainte de type pour un entier entre min et max. Par exemple :

    IntRange[1, 10]

    Le maximum peut être omis.

    IntRange[10]   # au moins 10

    Le minimum et le maximum sont inclusifs.

  • NumRange[`min, `max]

    Contrainte de type pour un nombre entre min et max. Par exemple :

    NumRange[0.1, 10.0]

    Comme avec IntRange, le maximum peut être omis, et le minimum et le maximum sont inclusifs.

    Les intervalles exclusifs peuvent être utiles pour les valeurs non entières, de sorte que des paramètres supplémentaires peuvent être donnés pour rendre le minimum et le maximum exclusifs.

    NumRange[0.1, 10.0, 0, 0]  # les deux inclusifs
NumRange[0.1, 10.0, 0, 1]  # maximum exclusif, donc 10.0 est invalide
NumRange[0.1, 10.0, 1, 0]  # minimum exclusif, donc 0.1 est invalide
NumRange[0.1, 10.0, 1, 1]  # les deux exclusifs

    Rendre une des limites exclusive signifie qu'un opérateur "<" ou ">" sera utilisé à la place des opérateurs "<=" ou ">=" habituels.
