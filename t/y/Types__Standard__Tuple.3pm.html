NOM

Types::Standard::Tuple - utilitaire d'exportation pour la contrainte de type Tuple

SYNOPIS

use Types::Standard -types;

# Façon normale de valider une paire d'entiers.
#
Tuple->of( Int, Int )->assert_valid( [ 7, 49 ] );

use Types::Standard::Tuple IntPair => { of => [ Int, Int ] },

# Raccourci exporté
#
assert_IntPair [ 7, 49 ];

STATUT

Ce module n'est pas couvert par la politique de stabilité de Type-Tiny.

DESCRIPTION

Il s'agit principalement de code interne, mais il peut également agir en tant qu'utilitaire d'exportation.

Exportations

Types::Standard::Tuple peut être utilisé expérimentalement en tant qu'exportateur.

use Types::Standard 'Int';
use Types::Standard::Tuple IntPair => { of => [ Int, Int ] };

Cela exportera les fonctions suivantes dans votre espace de noms :

"IntPair"
is_IntPair( $value )
assert_IntPair( $value )
to_IntPair( $value )

Plusieurs types peuvent être exportés en même temps :

use Types::Standard -types;
use Types::Standard::HashRef (
  IntPair  => { of => [ Int, Int ] },
  StrInt   => { of => [ Str, Int ] },
);

assert_StrInt [ two => 2 ];   # ne devrait pas planter

Il est possible de contraindre davantage le tuple en utilisant "where" :

use Types::Standard::Tuple MyThing => { of => [ ... ], where => sub { ... } };
