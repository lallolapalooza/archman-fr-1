Type::Params::Alternatives(3) Documentation Perl fournie par l'utilisateur Type::Params::Alternatives(3)

NOM

Type::Params::Alternatives - sous-classe de Type::Params::Signature pour les signatures "multi"

STATUT

Ce module n'est pas couvert par la politique de stabilité de Type-Tiny.

DESCRIPTION

Il s'agit principalement de code interne, mais il peut être utilisé pour fournir une introspection basique des signatures.

Ce module est une sous-classe de Type::Parameters::Signature, il hérite donc des attributs et méthodes de celle-ci.

Constructeur

new(%attributs)

Attributs

Tous les attributs sont en lecture seule.

"base_options" HashRef
"alternatives" ArrayRef[HashRef|ArrayRef|CodeRef]
"sig_class" ClassName
"meta_alternatives" ArrayRef[HashRef]
Construit automatiquement à partir de "alternatives" ; ne le définissez pas vous-même.
"parameters" ArrayRef
Redéfini de la classe parente pour toujours retourner un arrayref vide.
"message" Str
Message d'erreur à lancer lorsqu'aucune des alternatives ne correspond. Il s'agit d'un attribut nu sans méthode d'accesseur.
