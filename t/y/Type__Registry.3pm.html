Type::Registry(3) Documentation Perl fournie par l'utilisateur Type::Registry(3)

NOM

Type::Registry - un hashref glorifié pour la recherche de contraintes de type

SYNOPSIS

package Foo::Bar;

use Type::Registry;

my $reg = "Type::Registry"->for_me;  # un registre pour Foo::Bar

# Enregistre tous les types de Types::Standard
$reg->add_types(-Standard);

# Enregistre un seul type de Types::XSD
$reg->add_types(-XSD => ["NonNegativeInteger"]);

# Enregistre tous les types de MyApp::Types
$reg->add_types("MyApp::Types");

# Crée un alias de type
$reg->alias_type("NonNegativeInteger" => "Count");

# Recherche une contrainte de type
my $type = $reg->lookup("ArrayRef[Count]");

$type->check([1, 2, 3.14159]);  # croaks

Alternativement :

package Foo::Bar;

use Type::Registry qw( t );

# Enregistre tous les types de Types::Standard
t->add_types(-Standard);

# Enregistre un seul type de Types::XSD
t->add_types(-XSD => ["NonNegativeInteger"]);

# Enregistre tous les types de MyApp::Types
t->add_types("MyApp::Types");

# Crée un alias de type
t->alias_type("NonNegativeInteger" => "Count");

# Recherche une contrainte de type
my $type = t("ArrayRef[Count]");

$type->check([1, 2, 3.14159]);  # croaks

STATUT

Ce module est couvert par la politique de stabilité de Type-Tiny.

DESCRIPTION

Un registre de types est essentiellement un hashref mappant des noms de types à des objets de contrainte de type.

Constructeurs

"new"
Crée un nouveau hashref glorifié.
for_class($class)
Crée ou retourne le hashref glorifié existant associé à la classe donnée.

Notez que toute contrainte de type que vous avez importée à partir de bibliothèques de types basées sur Type::Library sera automatiquement disponible dans le registre de votre classe.

"for_me"
Crée ou retourne le hashref glorifié existant associé à l'appelant.

Méthodes

add_types(@libraries)
La liste des bibliothèques est traitée comme une "optlist" (à la manière de Data::OptList).

Les chaînes de caractères sont les noms des bibliothèques de types ; si le premier caractère est un tiret, il est étendu avec le préfixe "Types::". S'il est suivi d'un arrayref, c'est la liste des types à importer de cette bibliothèque. Sinon, importe tous les types de la bibliothèque.

use Type::Registry qw(t);

t->add_types(-Standard);  # OU : t->add_types("Types::Standard");

t->add_types(
   -TypeTiny => ['HashLike'],
   -Standard => ['HashRef' => { -as => 'RealHash' }],
);

Les bibliothèques MooseX::Types (et expérimentalement, MouseX::Types) peuvent également être ajoutées de cette manière, mais ne peuvent pas être suivies d'un arrayref de types à importer.

"add_type($type, $name)"
La forme singulière tant attendue de "add_types". Étant donné un objet de contrainte de type, l'ajoute au registre avec un nom donné. Le nom peut être omis, auquel cas "$type->name" est appelé, et Type::Registry lèvera une erreur si $type est anonyme. Si un nom est explicitement donné, Type::Registry ne se soucie pas du tout si la contrainte de type est anonyme.

Cette méthode peut même ajouter des contraintes de type MooseX::Types et MouseX::Types ; en fait, tout ce qui peut être géré par la fonction "to_TypeTiny" de Types::TypeTiny. (Gardez à l'esprit que to_TypeTiny résulte toujours en une contrainte de type anonyme, donc $name sera requis.)

"alias_type($oldname, $newname)"
Crée un alias pour un type existant.
simple_lookup($name)
Recherche un type dans le registre par son nom.

Retourne undef s'il n'est pas trouvé.

foreign_lookup($name)
Comme "simple_lookup", mais si le nom du type contient "::", tentera de le charger à partir d'une bibliothèque de types. (Et tentera de charger ce module.)
lookup($name)
Recherche par nom, avec un DSL. 
t->lookup("Int|ArrayRef[Int]")

Le DSL peut être résumé comme suit :

X               type de ce registre
My::Lib::X      type d'une bibliothèque de types
~X              type complémentaire
X | Y           union
X & Y           intersection
X[...]          type paramétré
slurpy X        type slurpy
Foo::Bar::      type de classe

Croaks s'il n'est pas trouvé.

make_union(@constraints), make_intersection(@constraints), make_class_type($class), make_role_type($role)
Méthodes de commodité pour créer certaines contraintes de type courantes.
"AUTOLOAD"
Surchargé pour appeler "lookup". 
$registry->Str;  # comme $registry->lookup("Str")
"get_parent", set_parent($reg), "clear_parent", "has_parent"
Matière avancée. Permet à un registre d'avoir un registre "parent" dont il hérite des contraintes de type.

Fonctions

"t"
Cette classe peut exporter une fonction "t" qui agit comme ""Type::Registry"->for_class($importing_class)".

    NOM

    Type::Registry - Enregistrement de classes de type

    SYNOPIS

    
package Type::Registry;

use strict;
use warnings;

our $VERSION = '1.001002';

use Scalar::Util qw(blessed);

sub register { ... }
sub get_type { ... }
sub get_scalar_type { ... }
sub get_array_type { ... }
sub get_hash_type { ... }
sub get_subref_type { ... }
sub get_type_for_value { ... }
sub unregister { ... }
sub reset { ... }

1;

    DESCRIPTION

    Cette classe fournit un mécanisme pour enregistrer et récupérer des « types » de Perl. Les types sont généralement des noms de classes (comme « Foo::Bar »), mais ils peuvent également être des noms de packages vides (comme «                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               

    Le module Type::Registry fournit une API pour enregistrer et récupérer des classes de type. Il est utilisé par d'autres modules pour fournir une manière cohérente de gérer les types.

    MÉTHODES

    Les méthodes suivantes sont fournies par ce module :

    register(@types)
    Enregistre les classes de type fournies. Chaque argument doit être un nom de package valide.
    get_type($type)
    Récupère le nom de type enregistré pour le type donné. Si le type n'est pas trouvé, une exception est levée.
    get_scalar_type($value)
    Récupère le type enregistré pour une valeur scalaire donnée. Si la valeur n'est pas d'un type enregistré, une exception est levée.
    get_array_type($value)
    Récupère le type enregistré pour une valeur de tableau donnée. Si la valeur n'est pas d'un type enregistré, une exception est levée.
    get_hash_type($value)
    Récupère le type enregistré pour une valeur de hachage donnée. Si la valeur n'est pas d'un type enregistré, une exception est levée.
    get_subref_type($value)
    Récupère le type enregistré pour une valeur de sous-routine donnée. Si la valeur n'est pas d'un type enregistré, une exception est levée.
    get_type_for_value($value)
    Détermine et retourne le type enregistré pour une valeur donnée. Cette méthode essaie de deviner le type le plus approprié.
    unregister(@types)
    Supprime les types enregistrés spécifiés du registre.
    reset()
    Supprime tous les types enregistrés du registre. À utiliser principalement à des fins de test.

    Aucun bogage connu pour le moment.
