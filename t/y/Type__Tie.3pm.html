NOM

Type::Tie - lier une variable à une contrainte de type

SYNOPIS

Type::Tie est une réponse à ce genre de problème...

use strict;
use warnings;

{
   package Local::Testing;
   use Moose;
   has numbers => ( is => "ro", isa => "ArrayRef[Num]" );
}

# Belle liste de nombres.
my @N = ( 1, 2, 3, 3.14159 );

# Créer un objet avec une référence à cette liste.
my $object = Local::Testing->new(numbers => \@N);

# Tout va bien jusqu'ici...

# Regardez maintenant ceci !
push @N, "Monkey!";
print $object->dump;

# Houston, nous avons un problème !

Il suffit de déclarer @N comme ceci :

use Type::Tie;
use Types::Standard qw( Num );

ttie my @N, Num, ( 1, 2, 3, 3.14159 );

Désormais, toute tentative d'ajout d'une valeur non numérique à @N entraînera une erreur.

DESCRIPTION

Ce module exporte une seule fonction : "ttie". "ttie" lie une variable à une contrainte de type, assurant que les valeurs stockées dans la variable sont conformes à la contrainte de type. Si la contrainte de type possède des coercions, celles-ci seront utilisées si nécessaire pour s'assurer que les valeurs attribuées à la variable sont conformes.

use Type::Tie;
use Types::Standard qw( Int Num );

ttie my $count, Int->plus_coercions(Num, 'int $_'), 0;

print tied($count)->type, "\n";   # 'Int'

$count++;            # ok
$count = 2;          # ok
$count = 3.14159;    # ok, coercé en 3
$count = "Monkey!";  # erreur

Bien que les exemples dans la documentation (et la suite de tests) montrent des contraintes de type de Types::Standard, toutes les contraintes de type prenant en charge les interfaces de Type::API devraient fonctionner. Cela inclut :

  • Moose::Meta::TypeConstraint / MooseX::Types
  • Mouse::Meta::TypeConstraint / MouseX::Types
  • Specio
  • Type::Tiny

Cependant, avec Type::Tiny, vous n'avez même pas besoin de "use Type::Tie".

use Types::Standard qw( Int Num );

tie my $count, Int->plus_coercions(Num, 'int $_'), 0;

print tied($count)->type, "\n";   # 'Int'

$count++;            # ok
$count = 2;          # ok
$count = 3.14159;    # ok, coercé en 3
$count = "Monkey!";  # erreur

Clonage des variables liées

Si vous clonez des variables liées avec "dclone" de Storable, le clone sera également lié. Le module Clone est également capable de cloner avec succès les variables liées. Avec d'autres techniques de clonage, votre niveau de succès peut varier.
