NOM

Types::Standard::ScalarRef - utilitaire d'exportation pour la contrainte de type ScalarRef

SYNOPIS

use Types::Standard -types;

# Manière normale de valider une référence à une chaîne.
#
ScalarRef->of( Str )->assert_valid( \ "foo" );

use Types::Standard::ScalarRef StrRef => { of => Str },

# Raccourci exporté
#
assert_StrRef \ "foo";

STATUT

Ce module n'est pas couvert par la politique de stabilité de Type-Tiny.

DESCRIPTION

Ceci est principalement du code interne, mais peut également agir comme un utilitaire d'exportation.

Exportations

Types::Standard::ScalarRef peut être utilisé expérimentalement comme un exportateur.

use Types::Standard 'Str';
use Types::Standard::ScalarRef StrRef => { of => Str };

Ceci exportera les fonctions suivantes dans votre espace de noms :

"StrRef"
is_StrRef( $valeur )
assert_StrRef( $valeur )
to_StrRef( $valeur )

Plusieurs types peuvent être exportés en même temps :

use Types::Standard -types;
use Types::Standard::ScalarRef (
  IntRef  => { of => Int },
  StrRef  => { of => Str },
);

assert_IntRef \42;   # ne devrait pas mourir

Il est possible de contraindre davantage la référence en utilisant "where" :

use Types::Standard::ScalarRef MyThing => { of => Str, where => sub { ... } };
