Type::Params::Parameter(3) Documentation Perl contribuée par les utilisateurs Type::Params::Parameter(3)

NOM

Type::Params::Parameter - représentation interne d'un paramètre dans la signature d'une fonction

STATUT

Ce module n'est pas couvert par la politique de stabilité de Type-Tiny.

DESCRIPTION

Il s'agit principalement de code interne, mais il peut être utilisé pour fournir une introspection de base des signatures.

Constructeur

new(%attributs)

Attributs

Tous les attributs sont en lecture seule.

"type" TypeTiny
Contrainte de type pour le paramètre.
"default" CodeRef|ScalarRef|Ref|Str|Undef
Une valeur par défaut pour le paramètre : soit un coderef pour générer une valeur, une référence à une chaîne de code Perl pour générer la valeur, une référence à un tableau vide ou à une hash vide, une chaîne littérale à utiliser comme valeur par défaut, ou un undef littéral à utiliser comme valeur par défaut.
"strictness" Bool|ScalarRef
Un booléen indiquant s'il faut être plus strict avec les vérifications de type, ou une référence à une chaîne de code Perl nommant une variable Perl ou une constante qui contrôle le comportement strict.
"clone" Bool
La méthode d'accès est appelée "should_clone" pour aucune raison particulière.
"coerce" Bool
Vaut vrai par défaut si "type" a une coercition.
"optional" Bool
Vaut vrai par défaut s'il y a une "default" ou si "type" est un sous-type de Optional.
"in_list" Bool
Booléen utilisé uniquement lorsque la signature a la fonctionnalité "list_to_named" activée.
"default_on_undef" Bool
La valeur par défaut doit-elle être déclenchée si l'appelant passe un undef explicite ?

Attributs liés aux paramètres nommés

"name" Str
"alias" ArrayRef[Str]
"getter" Str
"predicate" Str

Méthodes

Prédicats

Les méthodes prédicats retournent vrai/faux pour indiquer la présence ou l'absence d'attributs.

"has_type"
"has_default"
"has_strictness"
"has_name"
"has_alias"

Autres méthodes

"might_supply_new_value"
Indique que le paramètre ne peut pas être simplement référencé dans @_ car une valeur par défaut pourrait être utilisée, la valeur donnée pourrait être coercée, ou la valeur donnée pourrait être clonée à l'aide de Storable.
