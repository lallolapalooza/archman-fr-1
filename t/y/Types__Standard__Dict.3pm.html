Types::Standard::Dict(3) Documentation Perl fournie par l'utilisateur Types::Standard::Dict(3)

NOM

Types::Standard::Dict - utilitaire d'exportation et fonctions utilitaires pour la contrainte de type Dict

STATUT

Ce module n'est pas couvert par la politique de stabilité de Type-Tiny.

DESCRIPTION

Il s'agit principalement de code interne, mais il contient une fonction destinée au public.

Fonction

Types::Standard::Dict::combine(@dicts)
Crée une contrainte de type combinée, en essayant d'être permissive.

Les deux types suivants devraient être équivalents :

my $type1 = Types::Standard::Dict::combine(
  Dict[ name => Str ],
  Dict[ age => Int, Slurpy[HashRef[Int]] ],
  Dict[ id => Str, name => ArrayRef, Slurpy[ArrayRef] ],
);

my $type2 = Dict[
  name => Str|ArrayRef,
  age => Int,
  id => Str,
  Slurpy[ HashRef[Int] | ArrayRef ],
];

Notez qu'un hashref satisfaisant le type combiné ne satisferait aucune des contraintes Dict individuelles, ni vice versa !

Cette fonction peut être exportée :

use Types::Standard -types;
use Types::Standard::Dict combine => { -as => 'combine_dicts' };

my $type1 = combine_dicts(
  Dict[ name => Str ],
  Dict[ age => Int, Slurpy[HashRef[Int]] ],
  Dict[ id => Str, name => ArrayRef, Slurpy[ArrayRef] ],
);

Exportations

Types::Standard::Dict peut être utilisé expérimentalement comme exportateur.

use Types::Standard 'Str';
use Types::Standard::Dict Credentials => { of => [
  username => Str,
  password => Str,
] };

Cela exportera les fonctions suivantes dans votre espace de noms :

"Credentials"
is_Credentials( $value )
assert_Credentials( $value )
to_Credentials( $value )

Plusieurs types peuvent être exportés simultanément :

use Types::Standard -types;

use Types::Standard::Dict (
  Credentials => { of => [
    username => Str,
    password => Str,
  ] },
  Headers => { of => [
    'Content-Type' => Optional[Str],
    'Accept'       => Optional[Str],
    'User-Agent'   => Optional[Str],
  ] },
);

# Exportation séparée pour pouvoir utiliser les types définis par
# la première exportation.
use Types::Standard::Dict (
  HttpRequestData => { of => [
    credentials => Credentials,
    headers     => Headers,
    url         => Str,
    method      => Enum[ qw( OPTIONS HEAD GET POST PUT DELETE PATCH ) ],
  ] },
);

assert_HttpRequestData( {
  credentials => { username => 'bob', password => 's3cr3t' },
  headers     => { 'Accept' => 'application/json' },
  url         => 'http://example.net/api/v1/stuff',
  method      => 'GET',
} );

Il est possible de contraindre davantage le hashref en utilisant "where" :

use Types::Standard::Dict MyThing => { of => [ ... ], where => sub { ... } };
