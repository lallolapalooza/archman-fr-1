NOM

Type::Tiny::_DeclaredType - contrainte de type semi-définie

STATUT

Ce module est considéré comme faisant partie des détails internes de Type-Tiny. Il n'est pas couvert par la politique de stabilité de Type-Tiny.

DESCRIPTION

Ceci n'est pas considéré comme faisant partie de l'API publique de Type::Tiny.

C'est une classe représentant une contrainte de type déclarée mais non définie. Elle hérite de Type::Tiny.

Constructeur

new(%options)
