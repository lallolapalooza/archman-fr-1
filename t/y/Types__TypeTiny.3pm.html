Types::TypeTiny(3) Documentation Perl fournie par l'utilisateur Types::TypeTiny(3)

NOM

Types::TypeTiny - contraintes de type utilisées en interne par Type::Tiny

STATUT

Ce module est couvert par la politique de stabilité de Type-Tiny.

Le type BoolLike est actuellement instable.

DESCRIPTION

Autodogfooding (utilisation de son propre code).

Ce n'est pas une véritable bibliothèque de types basée sur Type::Library ; cela impliquerait trop de circularité. Mais il exporte quelques contraintes de type qui, bien que conçues pour être utilisées au sein de Type::Tiny, peuvent être plus utiles de manière générale.

Types

  • StringLike

    Accepte des chaînes et des objets surchargeant la conversion en chaîne.

  • BoolLike

    Accepte undef, "", 0, 1 ; accepte tout objet blessé qui surcharge "bool" ; accepte tout objet blessé qui surcharge "0+" pour retourner 0 ou 1. (Il faut réellement appeler l'opération surchargée pour le vérifier.) Accepte également tout objet qui hérite de "boolean" ou le signale en tant que rôle ("DOES").

    Attention : un objet qui surcharge "0+" sans activer également les remplacements de surcharge (fallbacks) peut en réalité être inutile en tant que booléen pratique. Mais certains objets courants comme les booléens de JSON::PP surchargent "0+" au lieu de surcharger "bool" (heureusement avec les remplacements activés !), nous devons donc le supporter.

    L'intention de ce type est d'être une version de Bool qui accepte également les objets booléens courants tels que JSON::PP::Boolean. Il est actuellement instable et la définition exacte du type peut changer pour mieux implémenter cette fonctionnalité prévue.

  • HashLike[`a]

    Accepte les hashrefs et les objets surchargeant la conversion en hash.

    Depuis Types::TypeTiny 1.012, peut être paramétré avec une autre contrainte de type comme HashLike[Int].

  • ArrayLike[`a]

    Accepte les arrayrefs et les objets surchargeant la conversion en tableau.

    Depuis Types::TypeTiny 1.012, peut être paramétré avec une autre contrainte de type comme ArrayLike[Int].

  • CodeLike

    Accepte les coderefs et les objets surchargeant la conversion en code.

  • TypeTiny

    Accepte les objets Type::Tiny blessés.

  • _ForeignTypeConstraint

    Toute référence que to_TypeTiny reconnaît comme quelque chose qui peut être converti en un objet Type::Tiny.

    Oui, le tiret bas est inclus.

Fonctions de coercition

to_TypeTiny($constraint)
Promeut (ou "dégrade" si vous préférez) une contrainte de type "étrangère" en un objet Type::Tiny. Peut gérer :
  • Les types Moose (y compris les objets Moose::Meta::TypeConstraint et les objets MooseX::Types::TypeDecorator).
  • Les types Mouse (y compris les objets Mouse::Meta::TypeConstraint).
  • Les objets Validation::Class et Validation::Class::Simple.
  • Les types construits à l'aide de Type::Library::Compiler.
  • Tout objet qui fournit les méthodes "check" et "get_message". (Cela inclut les types Specio et Type::Nano.) Si l'objet fournit "has_coercion" et les méthodes de coercition, celles-ci seront utilisées pour gérer la mise entre guillemets. Si l'objet fournit les méthodes "can_be_inlined" et "inline_check", celles-ci seront utilisées pour gérer l'inlining. Si l'objet fournit une méthode "name", celle-ci sera supposée retourner le nom du type.
  • Les coderefs (mais pas les coderefs blessés ou les objets surchargeant "&{}" à moins qu'ils ne fournissent les méthodes décrites ci-dessus !). Les coderefs sont censés retourner vrai si et seulement si $_ passe la contrainte. Si $_ échoue à la contrainte de type, ils peuvent soit retourner faux, soit mourir avec un message d'erreur utile.
  • Les coderefs activés par Sub::Quote. Ils sont traités de la même manière que ci-dessus, mais Type::Tiny consultera Sub::Quote pour déterminer s'ils peuvent être inlinés.

Méthodes

Celles-ci sont implémentées pour que "Types::TypeTiny->meta->get_type($foo)" fonctionne, pour une compatibilité approximative avec une véritable bibliothèque de types Type::Library.

"meta"
"type_names"
get_type($name)
has_type($name)
"coercion_names"
get_coercion($name)
has_coercion($name)
