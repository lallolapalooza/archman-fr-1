Type__Tiny__Role(3pm)

Paquet: perl-type-tiny

Licences: PerlArtistic, GPL

Type::Tiny::Role(3) Documentation Perl fournie par la communauté Type::Tiny::Role(3)

NOM

Type::Tiny::Role - contraintes de type basées sur la méthode "DOES"

SYNTHÈSE

Utilisation via Types::Standard :

package Local::Horse {
  use Moo;
  use Types::Standard qw( Str ConsumerOf );

  has name => (
    is       => 'ro',
    isa      => Str,
  );

  has owner => (
    is       => 'ro',
    isa      => ConsumerOf[ 'Local::Traits::DoesOwnership' ],
    default  => sub { Local::Person->new },
  );
}

Utilisation de la fonctionnalité d'export de Type::Tiny::Class :

package Local::Horse {
  use Moo;
  use Types::Standard qw( Str );
  use Type::Tiny::Role (
    Owner => { role => 'Local::Traits::DoesOwnership' },
  );

  has name => (
    is       => 'ro',
    isa      => Str,
  );

  has owner => (
    is       => 'ro',
    isa      => Owner,
    default  => sub { Local::Person->new },
  );
}

Utilisation de l'interface orientée objet de Type::Tiny::Role :

package Local::Horse {
  use Moo;
  use Types::Standard qw( Str );
  use Type::Tiny::Class;

  my $Owner = Type::Tiny::Role->new(
    role => 'Local::Traits::DoesOwnership',
  );

  has name => (
    is       => 'ro',
    isa      => Str,
  );

  has owner => (
    is       => 'ro',
    isa      => $Owner,
    default  => sub { Local::Person->new },
  );
}

Utilisation de l'interface fonctionnelle de Type::Utils :

package Local::Horse {
  use Moo;
  use Types::Standard qw( Str );
  use Type::Utils;

  my $Owner = role_type 'Local::Traits::DoesOwnership';

  has name => (
    is       => 'ro',
    isa      => Str,
  );

  has owner => (
    is       => 'ro',
    isa      => $Owner,
    default  => sub { Local::Person->new },
  );
}

STATUT

Ce module est couvert par la politique de stabilité de Type-Tiny.

DESCRIPTION

Contraintes de type de forme générale "{ $_->DOES("Some::Role") }".

Ce package hérite de Type::Tiny ; voir celui-ci pour la plupart des documentations. Les principales différences sont listées ci-dessous :

Attributs

"role"
Le rôle pour la contrainte.

Notez que ce package ne souscrit à aucune saveur particulière de rôles (Moose::Role, Mouse::Role, Moo::Role, Role::Tiny, etc.). Il fait simplement confiance à la méthode "DOES" de l'objet (voir UNIVERSAL).

"constraint"
Contrairement à Type::Tiny, vous ne pouvez pas passer une sous-routine de contrainte au constructeur. Fiez-vous plutôt à la valeur par défaut.
"inlined"
Contrairement à Type::Tiny, vous ne pouvez pas passer une sous-routine d'intégration au constructeur. Fiez-vous plutôt à la valeur par défaut.
"parent"
Le parent est toujours Types::Standard::Object, et ne peut pas être passé au constructeur.

Méthodes

stringifies_to($constraint)
Voir Type::Tiny::ConstrainedObject.
numifies_to($constraint)
Voir Type::Tiny::ConstrainedObject.
"with_attribute_values($attr1 => $constraint1, ...)"
Voir Type::Tiny::ConstrainedObject.

Exportations

Type::Tiny::Role peut être utilisé comme un exportateur.

use Type::Tiny::Role 'MyApp::Printable';

Ceci exportera les fonctions suivantes dans votre espace de noms :

"MyAppPrintable"
is_MyAppPrintable( $value )
assert_MyAppPrintable( $value )
to_MyAppPrintable( $value )

Plusieurs types peuvent être exportés en même temps :

use Type::Tiny::Role qw( MyApp::Printable MyApp::Sendable );
