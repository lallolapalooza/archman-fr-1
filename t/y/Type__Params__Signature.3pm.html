NOM

Type::Params::Signature - représentation interne d'une signature de fonction

STATUT

Ce module n'est pas couvert par la politique de stabilité de Type-Tiny.

DESCRIPTION

Il s'agit principalement de code interne, mais il peut être utilisé pour fournir une introspection basique des signatures.

Constructeurs

new(%attributs)
"new_from_compile($style, %attributs)"
new_from_v2api(\%attributs)

Attributs

Tous les attributs sont en lecture seule.

"package" NomClasse
Le paquet pour lequel nous fournissons une signature. Sera utilisé pour rechercher tous les noms de types sous forme de chaînes.
"subname" Str
La sous-routine pour laquelle nous fournissons une signature.
"description" Str
"method" ArrayRef[InstanceOf['Type::Params::Parameter']]
"head" ArrayRef[InstanceOf['Type::Params::Parameter']]
"tail" ArrayRef[InstanceOf['Type::Params::Parameter']]
"parameters" ArrayRef[InstanceOf['Type::Params::Parameter']]
"slurpy" InstanceOf['Type::Params::Parameter']
"on_die" CodeRef
"strictness" Bool|ScalarRef
"next" CodeRef
"goto_next" CodeRef
Alias pour "next".
"can_shortcut" Bool
Indique si la signature n'a aucun potentiel de modification de @_, permettant son retour sans copie si les vérifications de type réussissent. Généralement, vous ne devriez pas fournir ceci au constructeur et laisser Type::Params::Signature le déterminer.
"coderef" InstanceOf['Eval::TypeTiny::CodeAccumulator']
Vous ne voudrez probablement pas fournir ceci au constructeur. Le but de ce module est de le construire pour vous !

Attributs liés aux paramètres nommés

"is_named" Bool
"allow_dash" Bool
"bless" Bool|ClassName
"class" ClassName
"constructor" Str
"class_attributes" HashRef
HashRef adapté à être passé à la méthode "import" de Class::XSAccessor. Un défaut sera généré basé sur "parameters".
"named_to_list" ArrayRef
Peut être transformé à partir d'un booléen basé sur "parameters".
"list_to_named" Bool
"oo_trace" Bool
Par défaut à vrai. Indique si les hashrefs $arg "blessés" créés par la signature incluront une clé '~~caller'.

Attributs bruts

Ces attributs peuvent être passés aux constructeurs et peuvent avoir un effet, mais aucune méthode n'est fournie pour accéder aux valeurs ultérieurement.

"positional" ou "pos" ArrayRef
"named" ArrayRef
"multiple" ou "multi" ArrayRef
"returns" Bool
Raccourci pour définir simultanément "returns_scalar" et "returns_list".
"want_source" Bool
"want_details" Bool
"want_object" Bool
"rationalize_slurpies" Bool

Méthodes

Prédicats

Les méthodes prédicats retournent vrai/faux pour indiquer la présence ou l'absence d'attributs.

"has_description"
"has_head"
"has_tail"
"has_parameters"
"has_slurpy"
"has_on_die"
"has_strictness"
"has_returns_scalar"
"has_returns_list"

Méthodes de création de classe

Ces méthodes seront appelées automatiquement lors de la construction de l'objet et ne devraient généralement pas être appelées. Ce sont des méthodes publiques au cas où il serait souhaitable de sous-classer Type::Params::Signature.

"make_class_pp"
Construit la classe spécifiée dans "bless" en évaluant du code Perl.
"make_class_xs"
Construit la classe spécifiée dans "bless" en utilisant Class::XSAccessor.
"make_class"
Appelle soit "make_class_pp", soit "make_class_xs".
"make_class_pp_code"
Génère le code pour "make_class_pp".

Autres méthodes

"BUILD"
Appelée par les constructeurs. Vous ne devriez pas l'appeler.
"return_wanted"
Retourne normalement le coderef de signature, sauf si "want_source", "want_details", ou "want_object" ont été fournis au constructeur, auquel cas il retournera le code source du coderef, un hashref de détails, ou $self.

ENVIRONNEMENT

"PERL_TYPE_PARAMS_XS"
Affecte la construction des accesseurs pour les objets $arg. S'il est défini à vrai, utilise Class::XSAccessor. S'il est défini à faux, utilise du Perl pur. Si cette variable d'environnement n'existe pas, utilise Class::XSAccessor.

Si Class::XSAccessor n'est pas installé ou est trop ancien, du Perl pur sera toujours utilisé comme solution de repli.
