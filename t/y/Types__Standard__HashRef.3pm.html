NOM

Types::Standard::HashRef - utilitaire d'exportation pour la contrainte de type HashRef

SYNOPSIS

use Types::Standard -types;

# Manière normale de valider un hashref d'entiers.
#
HashRef->of( Int )->assert_valid( { one => 1 } );

use Types::Standard::HashRef IntHash => { of => Int },

# Raccourci exporté
#
assert_IntHash { one => 1 };

STATUT

Ce module n'est pas couvert par la politique de stabilité de Type-Tiny.

DESCRIPTION

Il s'agit principalement d'un code interne, mais il peut également servir d'utilitaire d'exportation.

Exportations

Types::Standard::HashRef peut être utilisé expérimentalement comme un exportateur.

use Types::Standard 'Int';
use Types::Standard::HashRef IntHash => { of => Int };

Cela exportera les fonctions suivantes dans votre espace de noms :

"IntHash"
is_IntHash( $valeur )
assert_IntHash( $valeur )
to_IntHash( $valeur )

Plusieurs types peuvent être exportés en même temps :

use Types::Standard -types;
use Types::Standard::HashRef (
  IntHash  => { of => Int },
  NumHash  => { of => Num },
  StrHash  => { of => Str },
);

assert_IntHash { two => 2 };   # ne devrait pas échouer

Il est possible de contraindre davantage le hashref en utilisant "where" :

use Types::Standard::HashRef MyThing => { of => Int, where => sub { ... } };
