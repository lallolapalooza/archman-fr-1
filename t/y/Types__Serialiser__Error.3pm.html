Types::Serialiser::Error - module factice pour Types::Serialiser

SYNOPSIS

# n'utilisez pas vous-même

DESCRIPTION

Ce module existe uniquement pour fournir une résolution de surcharge pour Storable et des modules similaires qui supposent que le nom de la classe est égal au nom du module. Voir Types::Serialiser pour plus d'informations sur cette classe.
