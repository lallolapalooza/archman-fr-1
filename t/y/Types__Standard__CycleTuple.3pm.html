NOM

Types::Standard::CycleTuple - utilitaire d'exportation pour la contrainte de type CycleTuple

SYNTAXE

use Types::Standard -types;

# Façon normale de valider une liste de paires d'entiers.
#
CycleTuple->of( Int, Int )->assert_valid( [ 7, 49, 8, 64 ] );

use Types::Standard::CycleTuple IntPairs => { of => [ Int, Int ] },

# Raccourci exporté
#
assert_IntPairs [ 7, 49, 8, 64 ];

STATUT

Ce module n'est pas couvert par la politique de stabilité de Type-Tiny.

DESCRIPTION

Il s'agit principalement de code interne, mais il peut également servir d'utilitaire d'exportation.

Exportations

Types::Standard::CycleTuple peut être utilisé expérimentalement comme exportateur.

use Types::Standard 'Int';
use Types::Standard::CycleTuple IntPairs => { of => [ Int, Int ] };

Ceci exportera les fonctions suivantes dans votre espace de noms :

"IntPairs"
is_IntPairs( $valeur )
assert_IntPairs( $valeur )
to_IntPairs( $valeur )

Plusieurs types peuvent être exportés en même temps :

use Types::Standard -types;
use Types::Standard::CycleTuple (
  IntIntPairs   => { of => [ Int, Int ] },
  StrIntPairs   => { of => [ Str, Int ] },
);

assert_StrIntPairs [ one => 1, two => 2 ];   # ne devrait pas mourir

Il est possible de contraindre davantage le cycletuple en utilisant "where" :

use Types::Standard::CycleTuple MyThing => { of => [ ... ], where => sub { ... } };
