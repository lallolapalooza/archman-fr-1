MANUEL

Politique de Stabilité de Type::Tiny

Type::Tiny 1.000000+ est considéré stable. Tout changement de l'API suffisamment important pour nécessiter des changements dans la suite de tests sera précédé d'une période de préavis de six mois, à l'exception suivante :

  • Tous les changements nécessaires pour maintenir la compatibilité avec les nouvelles versions de Moose, Moo et autres logiciels avec lesquels Type::Tiny doit s'intégrer.
  • Changements pour maintenir la compatibilité avec les futures versions de Perl.
  • Lorsqu'un changement corrige une contradiction entre l'implémentation et la documentation de Type::Tiny.
  • Lorsqu'une fonctionnalité est explicitement documentée comme "expérimentale" ou "instable".
  • Améliorations du texte des messages d'erreur.

Fonctionnalités Expérimentales et Instables de Type::Tiny

La liste suivante n'est pas exhaustive pour le moment.

•
Les résultats des vérifications de type suivantes peuvent varier en fonction de votre version de Perl et si Type::Tiny::XS est installé. Leur résultat est actuellement considéré comme indéfini, et peut changer dans les futures versions.
  • Utiliser Object et des vérifications de type similaires sur des références d'expressions régulières non bénies, le résultat est indéfini.
  • Sur toutes les versions actuelles de Perl, la valeur fausse ("!!0") se stringifie en chaîne vide (mais en utilisant Devel::Peek, vous pouvez faire la différence entre cette valeur et une chaîne vide normale), donc Int et ses sous-types ne la considèrent pas comme un entier. Si le comportement de Perl venait à changer, vous ne pourriez pas compter sur ce résultat. La valeur vraie ("!!1") se stringifie en "1", elle est donc considérée comme un entier.
  • Un glob (pas un globref mais un vrai glob) passe actuellement la contrainte de type StringLike mais pas la contrainte de type Str.
  • Le type BoolLike est destiné à étendre Bool pour couvrir les objets booléens surchargés, mais le mécanisme exact qu'il utilise pourrait changer.
  • L'attribut "my_methods" de Type::Tiny et la fonctionnalité qu'il fournit sont expérimentaux.
  • L'API de coercition paramétrable est susceptible de changer.
  • L'interaction entre les coercitions profondes et les coercitions mutables entraîne actuellement un comportement mal défini. Cela pourrait changer à tout moment.
  • La capacité de Type::Registry à importer les bibliothèques de types MooseX::Types et MouseX::Types est expérimentale.
  • Les mots-clés "signature_for_func" et "signature_for_method" fournis par Type::Params pourraient légèrement modifier leur comportement à l'avenir. Une fois stables, ils devraient être ajoutés aux exportations de Types::Common.
  • La fonction "Types::Standard::Dict::combine".
  • Ces modules sont considérés comme faisant partie des internes de Type::Tiny, et ne sont pas couverts par la politique de stabilité : Devel::TypeTiny::Perl58Compat, Type::Coercion::FromMoose, Type::Params::Alternatives, Type::Params::Parameter, Type::Params::Signature, Type::Tiny::_HalfOp, Types::Standard::ArrayRef, Types::Standard::CycleTuple, Types::Standard::Dict, Types::Standard::HashRef, Types::Standard::Map, Types::Standard::ScalarRef, Types::Standard::StrMatch, Types::Standard::Tied, et Types::Standard::Tuple.
  • L'utilisation de certains modules de la liste précédente comme exportateurs de raccourcis pour les types paramétrés n'est pas encore stable.
  • Reply::Plugin::TypeTiny n'est pas couvert par la politique de stabilité.

Politique de Versionnement de Type::Tiny

Depuis la version 1.000000, cette distribution suit un schéma de versionnement similaire à Moo, basé sur un numéro de version à trois composantes de type semver http://semver.org/, mais avec les deux dernières composantes représentées chacune par trois chiffres décimaux dans la partie fractionnaire du numéro de version. Ainsi, la version 1.003002 du logiciel représente "1.3.2".

De plus, les versions où la deuxième composante est un nombre impair seront considérées comme des versions instables/d'essai. (Celles-ci incluront également un trait d'union dans le numéro de version, conformément à la convention habituelle de CPAN.)

Support des Versions de Perl

Type::Tiny 0.000_01 à Type::Tiny 0.015_04 nécessitait Perl 5.8.1.

Type::Tiny 0.015_05+ et Type::Tiny 1.000000+ nécessitent Perl 5.6.1.

Type::Tiny 2.000000+ nécessitera Perl 5.8.1.
