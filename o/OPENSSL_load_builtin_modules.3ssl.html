OPENSSL_load_builtin_modules(3ssl)

OPENSSL_LOAD_BUILTIN_MODULES(3ssl) OpenSSL OPENSSL_LOAD_BUILTIN_MODULES(3ssl)

NOM

OPENSSL_load_builtin_modules, ASN1_add_oid_module, ENGINE_add_conf_module - ajouter des modules de configuration standard

SYNOPSIS

#include <openssl/conf.h>
void OPENSSL_load_builtin_modules(void);
void ASN1_add_oid_module(void);
void ENGINE_add_conf_module(void);

DESCRIPTION

La fonction OPENSSL_load_builtin_modules() ajoute tous les modules de configuration OpenSSL standard à la liste interne. Ils peuvent ensuite être utilisés par le code de configuration OpenSSL.

ASN1_add_oid_module() ajoute uniquement le module ASN1 OBJECT.

ENGINE_add_conf_module() ajoute uniquement le module de configuration ENGINE.

NOTES

Si la fonction de configuration simple OPENSSL_config() est appelée, alors OPENSSL_load_builtin_modules() est appelée automatiquement.

Les applications qui utilisent les fonctions de configuration directement devront appeler OPENSSL_load_builtin_modules() elles-mêmes avant tout autre code de configuration.

Les applications devraient appeler OPENSSL_load_builtin_modules() pour charger tous les modules de configuration au lieu d'ajouter des modules sélectivement : sinon des fonctionnalités pourraient manquer à l'application au fur et à mesure que de nouveaux modules sont ajoutés.

VALEURS DE RETOUR

Aucune des fonctions ne retourne de valeur.

VOIR AUSSI

config(5), OPENSSL_config(3)

HISTORIQUE

ENGINE_add_conf_module() a été déprécié dans OpenSSL 3.0.
