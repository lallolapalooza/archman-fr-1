NOM

OPENSSL_VERSION_MAJOR, OPENSSL_VERSION_MINOR, OPENSSL_VERSION_PATCH, OPENSSL_VERSION_PRE_RELEASE, OPENSSL_VERSION_BUILD_METADATA, OPENSSL_VERSION_TEXT, OPENSSL_VERSION_PREREQ, OPENSSL_version_major, OPENSSL_version_minor, OPENSSL_version_patch, OPENSSL_version_pre_release, OPENSSL_version_build_metadata, OpenSSL_version, OPENSSL_VERSION_NUMBER, OpenSSL_version_num, OPENSSL_info - obtenir le numéro de version d'OpenSSL et autres informations

SYNTAXIS

#include <openssl/opensslv.h>
#define OPENSSL_VERSION_MAJOR  x
#define OPENSSL_VERSION_MINOR  y
#define OPENSSL_VERSION_PATCH  z
/* Les définitions ci-dessous sont typiques pour une version release */
#define OPENSSL_VERSION_PRE_RELEASE ""
#define OPENSSL_VERSION_BUILD_METADATA ""
#define OPENSSL_VERSION_TEXT "OpenSSL x.y.z xx XXX xxxx"
#define OPENSSL_VERSION_PREREQ(maj,min)
#include <openssl/crypto.h>
unsigned int OPENSSL_version_major(void);
unsigned int OPENSSL_version_minor(void);
unsigned int OPENSSL_version_patch(void);
const char *OPENSSL_version_pre_release(void);
const char *OPENSSL_version_build_metadata(void);
const char *OpenSSL_version(int t);
const char *OPENSSL_info(int t);
/* depuis openssl/opensslv.h */
#define OPENSSL_VERSION_NUMBER 0xnnnnnnnnL
/* depuis openssl/crypto.h */
unsigned long OpenSSL_version_num();

DESCRIPTION

Macros

Les trois macros OPENSSL_VERSION_MAJOR, OPENSSL_VERSION_MINOR et OPENSSL_VERSION_PATCH représentent les trois parties d'un identifiant de version, MAJOR.MINOR.PATCH.

La macro OPENSSL_VERSION_PRE_RELEASE est un bit supplémentaire qui indique qu'il s'agit d'une version préliminaire, comme "-dev" pour une capture de développement en cours ou "-alpha3" pour une version alpha. La valeur doit être une chaîne de caractères.

La macro OPENSSL_VERSION_BUILD_METADATA est une information supplémentaire, réservée à d'autres, comme "+fips" ou "+vendor.1". La société OpenSSL ne changera pas cette macro (elle la laissera comme une chaîne vide). La valeur doit être une chaîne de caractères.

OPENSSL_VERSION_STR est une macro de commodité pour obtenir l'identifiant de version court, "MAJOR.MINOR.PATCH".

OPENSSL_FULL_VERSION_STR est une macro de commodité pour obtenir l'identifiant de version plus long, qui combine OPENSSL_VERSION_STR, OPENSSL_VERSION_PRE_RELEASE et OPENSSL_VERSION_BUILD_METADATA.

OPENSSL_VERSION_TEXT est une macro de commodité pour obtenir un texte descriptif complet, qui inclut OPENSSL_FULL_VERSION_STR et la date de sortie.

OPENSSL_VERSION_PREREQ est une macro utile pour vérifier si la version d'OpenSSL dans les headers utilisés est au moins la pré-requis spécifié (maj, min) ou non. Elle sera évaluée comme vraie si le numéro de version du header (OPENSSL_VERSION_MAJOR.OPENSSL_VERSION_MINOR) est supérieur ou égal à maj.min.

OPENSSL_VERSION_NUMBER est une combinaison des versions majeure, mineure et patch d'OpenSSL en un seul entier 0xMNN00PP0L, où :

M
est le numéro de OPENSSL_VERSION_MAJOR, en notation hexadécimale
NN
est le numéro de OPENSSL_VERSION_MINOR, en notation hexadécimale
PP
est le numéro de OPENSSL_VERSION_PATCH, en notation hexadécimale

Fonctions

OPENSSL_version_major(), OPENSSL_version_minor(), OPENSSL_version_patch(), OPENSSL_version_pre_release(), et OPENSSL_version_build_metadata() retournent les valeurs des macros ci-dessus pour la compilation de la bibliothèque, respectivement.

OpenSSL_version() renvoie différentes chaînes de caractères en fonction de t :

OPENSSL_VERSION
la valeur de OPENSSL_VERSION_TEXT
OPENSSL_VERSION_STRING
la valeur de OPENSSL_VERSION_STR
OPENSSL_FULL_VERSION_STRING
la valeur de OPENSSL_FULL_VERSION_STR
OPENSSL_CFLAGS
les indicateurs de compilation définis pour le processus de compilation sous la forme "compiler: ..." s'ils sont disponibles, ou "compiler: information non disponible" sinon.
OPENSSL_BUILT_ON
la date de compilation sous la forme "compilé le : ..." si elle est disponible, ou "compilé le : date non disponible" sinon. La date ne sera pas disponible dans une compilation reproductible, par exemple.
OPENSSL_PLATFORM
la cible de configuration de la bibliothèque sous la forme "plateforme : ..." si elle est disponible, ou "plateforme : information non disponible" sinon.
OPENSSL_DIR
la configuration de OPENSSLDIR sous la forme "OPENSSLDIR : "..."" si elle est disponible, ou "OPENSSLDIR : N/A" sinon.
OPENSSL_ENGINES_DIR
la configuration de ENGINESDIR sous la forme "ENGINESDIR : "..."" si elle est disponible, ou "ENGINESDIR : N/A" sinon. Cette option est obsolète dans OpenSSL 3.0.
OPENSSL_MODULES_DIR
la configuration de MODULESDIR sous la forme "MODULESDIR : "..."" si elle est disponible, ou "MODULESDIR : N/A" sinon.
OPENSSL_CPU_INFO
les configurations actuelles des ressources du processeur d'OpenSSL. C'est la configuration actuelle des capacités des indicateurs du processeur. Elle est généralement configurée automatiquement mais peut être définie par une variable d'environnement. La valeur a la même syntaxe que la variable d'environnement. Pour x86, le texte ressemble à "CPUINFO : OPENSSL_ia32cap=0x123:0x456" ou "CPUINFO : N/A" si elle n'est pas disponible.
OPENSSL_WINCTX
le contexte d'installation de Windows. Le contexte d'installation de Windows est utilisé pour calculer le nom de la clé de registre d'OpenSSL sous Windows. Le nom complet de la clé est "SOFTWARE\WOW6432Node\OpenSSL-{major}.{minor}-{context}", où "{major}", "{minor}" et "{context}" sont le numéro de version majeure d'OpenSSL, la version mineure et le contexte d'installation de Windows, respectivement.

Pour une valeur de t inconnue, "non disponible" est retourné.

OPENSSL_info() renvoie également différentes chaînes de caractères en fonction de t :

OPENSSL_INFO_CONFIG_DIR
l'emplacement configuré de "OPENSSLDIR", qui est l'emplacement par défaut pour les fichiers de configuration d'OpenSSL.
OPENSSL_INFO_ENGINES_DIR
l'emplacement configuré de "ENGINESDIR", qui est l'emplacement par défaut pour les moteurs OpenSSL.
OPENSSL_INFO_MODULES_DIR
l'emplacement configuré de "MODULESDIR", qui est l'emplacement par défaut pour les modules dynamiques OpenSSL.

Une valeur de t inconnue renvoie "non disponible".

HISTORIQUE

Les macros et fonctions décrites ici ont été ajoutées dans OpenSSL 3.0, à l'exception de OPENSSL_VERSION_NUMBER et OPENSSL_version_num()

BOGUES

Il y avait une divergence entre ce manuel et le commentaire + code dans <openssl/opensslv.h>, où ce dernier suggérait que les quatre bits les moins significatifs de OPENSSL_VERSION_NUMBER pouvaient être 0x0f dans les versions d'OpenSSL publiées.
