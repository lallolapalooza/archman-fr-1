Documentation de l'énumération membre

enum OpenDBX::Stmt::Type

Objets de requête qui peuvent être créés. Actuellement, seul le traitement simple des requêtes est pris en charge, ce qui signifie que la requête envoyée au serveur de base de données se compose de la requête et des paramètres sous forme textuelle. Plus tard, des requêtes préparées seront également disponibles, ce qui séparera l'analyse et l'exécution avec des paramètres différents.

Documentation du constructeur et du destructeur

OpenDBX::Stmt::Stmt () [inline], [protégé]

Constructeur par défaut. Le constructeur par défaut ne fait pas partie de l'interface publique car l'objet ne doit pas être créé manuellement. Au lieu de cela, la méthode Conn::create() est une fabrique pour les instances de la classe Stmt.

Instance de requête

OpenDBX::Stmt::Stmt (Stmt_Iface * impl) [protégé]

Crée une instance de requête. Le constructeur ne fait pas partie de l'interface publique car l'objet ne doit pas être créé manuellement. Au lieu de cela, la méthode Conn::create() est une fabrique pour les instances de la classe Stmt.

Instance de requête

OpenDBX::Stmt::~Stmt ()

Détruit l'instance de requête s'il n'y a plus de références. Chaque objet de requête utilise un compteur de références pour se souvenir si les variables internes sont partagées avec d'autres objets. Si ce n'est pas le cas ou si cet objet est le dernier à référencer les variables, l'objet est nettoyé et la mémoire allouée est libérée.

OpenDBX::Stmt::Stmt (const Stmt & ref)

Constructeur de copie. Permet le transfert de l'état interne d'un objet ref du même type vers cet objet. Les deux objets partagent les mêmes variables et le compteur de références par la suite. Le compteur de références est incrémenté chaque fois qu'un objet est copié et sera décrémenté lorsqu'il est détruit.

Paramètres

ref Instance de requête originale

Documentation des fonctions membres

Result OpenDBX::Stmt::execute ()

Exécute une requête et renvoie une instance Result. Envoie les données nécessaires au serveur de base de données qui exécutera la requête et renverra un ou plusieurs jeux de résultats par la suite. Les jeux de résultats peuvent être récupérés via l'objet Result renvoyé.

Renvoie

Instance Result
