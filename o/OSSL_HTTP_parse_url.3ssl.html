OSSL_HTTP_parse_url(3ssl)

Paquet: openssl

Licences: Apache-2.0

OSSL_HTTP_PARSE_URL(3ssl) OpenSSL OSSL_HTTP_PARSE_URL(3ssl)

NOM

OSSL_HTTP_adapt_proxy, OSSL_parse_url, OSSL_HTTP_parse_url, OCSP_parse_url - fonctions utilitaires http

SYNTAXE

#include <openssl/http.h>
const char *OSSL_HTTP_adapt_proxy(const char *proxy, const char *no_proxy,
                                  const char *server, int use_ssl);
int OSSL_parse_url(const char *url, char **pscheme, char **puser, char **phost,
                   char **pport, int *pport_num,
                   char **ppath, char **pquery, char **pfrag);
int OSSL_HTTP_parse_url(const char *url,
                        int *pssl, char **puser, char **phost,
                        char **pport, int *pport_num,
                        char **ppath, char **pquery, char **pfrag);

Les fonctions suivantes sont dépréciées depuis OpenSSL 3.0, et peuvent être entièrement masquées en définissant OPENSSL_API_COMPAT avec une valeur de version appropriée, voir openssl_user_macros(7):

int OCSP_parse_url(const char *url, char **phost, char **pport, char **ppath,
                   int *pssl);

DESCRIPTION

OSSL_HTTP_adapt_proxy() prend un nom d'hôte de proxy optionnel proxy et le retourne transformé selon le paramètre optionnel no_proxy, server, use_ssl, et la variable d'environnement applicable, comme suit. Si proxy est NULL, prend toute valeur par défaut de la variable d'environnement "http_proxy", ou de "https_proxy" si use_ssl est non nul. Si cela ne produit toujours pas de nom d'hôte de proxy, prend toute valeur par défaut supplémentaire de la variable d'environnement "HTTP_PROXY", ou de "HTTPS_PROXY" si use_ssl est non nul. Si no_proxy est NULL, prend toute valeur d'exclusion par défaut de la variable d'environnement "no_proxy", ou sinon de "NO_PROXY". Retourne l'hôte de proxy déterminé à moins que la valeur d'exclusion, qui est une liste d'hôtes de proxy séparés par "," et/ou des espaces blancs, ne contienne server. Sinon retourne NULL. Lorsque server est une chaîne délimitée par "[" et "]", qui sont utilisés pour les adresses IPv6, les délimiteurs "[" et "]" sont supprimés avant la comparaison.

OSSL_parse_url() analyse sa chaîne d'entrée url comme une URL de la forme "[scheme://][userinfo@]host[:port][/path][?query][#fragment]" et la divise en composantes schéma, informations utilisateur, hôte, port, chemin, requête et fragment. La composante hôte (ou serveur) peut être un nom DNS ou une adresse IP où les adresses IPv6 doivent être entourées de crochets "[" et "]". La composante port est optionnelle et vaut par défaut 0. Si elle est donnée, elle doit être en format décimal. Si l'argument pport_num n'est pas NULL, la valeur entière du numéro de port est assignée à *pport_num en cas de succès. La composante chemin est également optionnelle et vaut par défaut "/". Chaque argument pointeur de résultat non NULL pscheme, puser, phost, pport, ppath, pquery et pfrag, se voit assigner la composante d'URL respective. Toute adresse IPv6 dans *phost est entourée de "[" et "]". En cas de succès, ils sont garantis de contenir des pointeurs de chaîne non-NULL, sinon NULL. Il incombe à l'appelant de les libérer en utilisant OPENSSL_free(3). Si pquery est NULL, toute composante de requête donnée est traitée comme partie du chemin. Une chaîne retournée via *ppath est garantie de commencer par le caractère "/". Pour les composantes schéma, informations utilisateur, port, requête et fragment absentes, une chaîne vide est fournie.

OSSL_HTTP_parse_url() est une forme spéciale de OSSL_parse_url() où le schéma, s'il est donné, doit être "http" ou "https". Si pssl n'est pas NULL, *pssl est assigné 1 si l'analyse a réussi et que le schéma est "https", sinon 0. La composante port est optionnelle et vaut par défaut 443 si le schéma est "https", sinon 80. Notez que les chemins relatifs doivent être donnés avec un "/" de tête, sinon le premier élément de chemin est interprété comme l'hôte.

Appeler la fonction dépréciée OCSP_parse_url(url, host, port, path, ssl) est équivalent à OSSL_HTTP_parse_url(url, ssl, NULL, host, port, NULL, path, NULL, NULL).

VALEUR DE RETOUR

OSSL_HTTP_adapt_proxy() retourne NULL si aucun proxy ne doit être utilisé, sinon une chaîne de nom d'hôte de proxy constante, qui est soit le nom du proxy fourni, soit une valeur de variable d'environnement.

OSSL_parse_url(), OSSL_HTTP_parse_url() et OCSP_parse_url() retournent 1 en cas de succès, 0 en cas d'erreur.

VOIR AUSSI

OSSL_HTTP_transfer(3)

HISTORIQUE

OSSL_HTTP_adapt_proxy(), OSSL_parse_url() et OSSL_HTTP_parse_url() ont été ajoutées dans OpenSSL 3.0. OCSP_parse_url() a été dépréciée dans OpenSSL 3.0.
