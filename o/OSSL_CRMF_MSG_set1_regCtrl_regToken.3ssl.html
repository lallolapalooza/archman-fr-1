DESCRIPTION

Chacune des fonctions OSSL_CRMF_MSG_get0_regCtrl_X() retourne le contrôle X respectif dans le msg donné, s'il est présent.

OSSL_CRMF_MSG_set1_regCtrl_regToken() définit le contrôle regToken dans le msg donné en copiant tok comme valeur. Voir RFC 4211, section 6.1.

OSSL_CRMF_MSG_set1_regCtrl_authenticator() définit le contrôle d'authentification dans le msg donné en copiant auth comme valeur. Voir RFC 4211, section 6.2.

OSSL_CRMF_MSG_PKIPublicationInfo_push0_SinglePubInfo() pousse le spi donné vers si. Consomme le pointeur spi.

OSSL_CRMF_MSG_set0_SinglePubInfo() définit dans SinglePubInfo spi donné la méthode method et le lieu de publication, sous la forme d'un GeneralName, nm. Le lieu de publication est facultatif, et donc nm peut être NULL. La fonction consomme le pointeur nm s'il est présent. Les méthodes disponibles sont :
# define OSSL_CRMF_PUB_METHOD_DONTCARE 0
# define OSSL_CRMF_PUB_METHOD_X500 1
# define OSSL_CRMF_PUB_METHOD_WEB 2
# define OSSL_CRMF_PUB_METHOD_LDAP 3

OSSL_CRMF_MSG_set_PKIPublicationInfo_action() définit l'action dans pi donné en utilisant action comme valeur. Voir RFC 4211, section 6.3. Les actions disponibles sont :
# define OSSL_CRMF_PUB_ACTION_DONTPUBLISH 0
# define OSSL_CRMF_PUB_ACTION_PLEASEPUBLISH 1

OSSL_CRMF_MSG_set1_regCtrl_pkiPublicationInfo() définit le contrôle pkiPublicationInfo dans le msg donné en copiant tok comme valeur. Voir RFC 4211, section 6.3.

OSSL_CRMF_MSG_set1_regCtrl_protocolEncrKey() définit le contrôle protocolEncrKey dans le msg donné en copiant pubkey comme valeur. Voir RFC 4211 section 6.6.

OSSL_CRMF_MSG_set1_regCtrl_oldCertID() définit le contrôle de jeton d'enregistrement oldCertID dans le msg donné en copiant cid comme valeur. Voir RFC 4211, section 6.5.

OSSL_CRMF_CERTID_gen produit une structure OSSL_CRMF_CERTID_gen en copiant le nom issuer et le numéro serial donnés.

VALEUR DE RETOUR

Toutes les fonctions OSSL_CRMF_MSG_get0_*() retournent la valeur du pointeur respectif ou NULL s'il n'est pas présent et en cas d'erreur.

Toutes les fonctions OSSL_CRMF_MSG_set1_*() retournent 1 en cas de succès, 0 en cas d'erreur.

OSSL_CRMF_CERTID_gen() retourne un pointeur vers la structure résultante ou NULL en cas d'erreur.

NOTES

Une fonction OSSL_CRMF_MSG_set1_regCtrl_pkiArchiveOptions() pour définir un contrôle d'options d'archivage n'est pas encore implémentée en raison du manque de fonctionnalités pour créer le contenu OSSL_CRMF_PKIARCHIVEOPTINS nécessaire.
