NAME

OPENSSL_riscvcap - le vecteur de capacités du processeur RISC-V

SYNOPSIS

env OPENSSL_riscvcap=... <application>

DESCRIPTION

libcrypto prend en charge les extensions d'ensembles d'instructions RISC-V. Ces extensions sont désignées par des noms d'extensions individuels dans le vecteur de capacités. Pour le système d'exploitation Linux, lorsque libcrypto est initialisé, les résultats renvoyés par l'appel système hwprobe du matériel (RISC-V) (hwprobe) sont stockés dans le vecteur. Sinon, toutes les capacités sont désactivées.

Pour remplacer l'ensemble d'instructions disponible pour une application, vous pouvez définir la variable d'environnement OPENSSL_riscvcap avant de démarrer l'application.

La variable d'environnement est similaire à la chaîne d'ensemble d'instructions RISC-V définie dans le manuel des instructions RISC-V. Elle est insensible à la casse. Bien qu'en raison de la limitation de l'analyseur de variable d'environnement dans libcrypto, une extension doive être préfixée par un trait de soulignement pour être reconnue. Cela s'applique également à l'extension Vector.

OPENSSL_riscvcap="rv64gc_v_zba_zbb_zbs..."

Remarque : l'implication des extensions n'est actuellement pas implémentée. Par exemple, lorsque "rv64gc_b" est fourni en tant que variable d'environnement, zba/zbb/zbs ne seront pas impliqués dans le vecteur de capacités.

Actuellement, seules ces extensions sont reconnues :

ZBA
Génération d'adresses

Peut être détecté à l'aide de hwprobe pour les noyaux Linux >= 6.5

ZBB
Manipulation de bits de base

Peut être détecté à l'aide de hwprobe pour les noyaux Linux >= 6.5

ZBC
Multiplication sans retenue

Peut être détecté à l'aide de hwprobe pour les noyaux Linux >= 6.8

ZBS
Instructions sur un seul bit

Peut être détecté à l'aide de hwprobe pour les noyaux Linux >= 6.5

ZBKB
Manipulation de bits pour la cryptographie

Peut être détecté à l'aide de hwprobe pour les noyaux Linux >= 6.8

ZBKC
Multiplication sans retenue pour la cryptographie

Peut être détecté à l'aide de hwprobe pour les noyaux Linux >= 6.8

ZBKX
Permutations croisées

Peut être détecté à l'aide de hwprobe pour les noyaux Linux >= 6.8

ZKND
-suite NIST : décodage AES

Peut être détecté à l'aide de hwprobe pour les noyaux Linux >= 6.8

ZKNE
-suite NIST : chiffrement AES

Peut être détecté à l'aide de hwprobe pour les noyaux Linux >= 6.8

ZKNH
-suite NIST : instructions de fonction de hachage

Peut être détecté à l'aide de hwprobe pour les noyaux Linux >= 6.8

ZKSED
-suite ShangMi : instructions de chiffrement par bloc SM4

Peut être détecté à l'aide de hwprobe pour les noyaux Linux >= 6.8

ZKSH
-suite ShangMi : instructions de hachage SM3

Peut être détecté à l'aide de hwprobe pour les noyaux Linux >= 6.8

ZKR
Extension de source d'entropie
ZKT
Latence d'exécution indépendante des données

Peut être détecté à l'aide de hwprobe pour les noyaux Linux >= 6.8

V
Extension du processeur d'application : Vectoriel

Peut être détecté à l'aide de hwprobe pour les noyaux Linux >= 6.5

ZVBB
Manipulation de bits vectoriels de base

VALEURS DE RETOUR

Non applicable.

EXEMPLES

Afficher les capacités actuellement détectées

$ openssl info -cpusettings
OPENSSL_riscvcap=ZBA_ZBB_ZBC_ZBS_V

Désactiver toutes les extensions d'instructions :

OPENSSL_riscvcap="rv64gc"

Activer uniquement l'extension vectorielle :

OPENSSL_riscvcap="rv64gc_v"
