OSSL_INDICATOR_SET_CALLBACK(3ssl) OpenSSL OSSL_INDICATOR_SET_CALLBACK(3ssl)

NOM

OSSL_INDICATOR_set_callback, OSSL_INDICATOR_get_callback - spécifier un rappel pour les indicateurs FIPS

SYNOPIS

#include <openssl/indicator.h>

typedef int (OSSL_INDICATOR_CALLBACK)(const char *type, const char *desc,
const OSSL_PARAM params[]);

void OSSL_INDICATOR_set_callback(OSSL_LIB_CTX *libctx,
                                 OSSL_INDICATOR_CALLBACK *cb);
void OSSL_INDICATOR_get_callback(OSSL_LIB_CTX *libctx,
                                 OSSL_INDICATOR_CALLBACK **cb);

DESCRIPTION

OSSL_INDICATOR_set_callback() définit une fonction de rappel utilisataire cb associée à un libctx qui sera appelée lorsqu'une opération FIPS non approuvée est détectée.

Le rappel de l'utilisateur peut être déclenché plusieurs fois lors d'une opération d'algorithme pour indiquer que différentes vérifications en mode approuvé ont échoué.

Les opérations non approuvées ne peuvent survenir que si l'utilisateur a délibérément choisi de le faire (soit en définissant une option de configuration FIPS globale, soit via une option dans le contexte d'opération d'un algorithme).

Le rappel de l'utilisateur OSSL_INDICATOR_CALLBACK type et desc contiennent le type d'algorithme et l'opération qui ne sont pas approuvés. params n'est actuellement pas utilisé.

Si le rappel de l'utilisateur renvoie 0, une erreur se produira chez l'appelant. Ceci peut être utilisé à des fins de test.

VALEURS DE RETOUR

OSSL_INDICATOR_get_callback() renvoie la fonction de rappel qui a été définie via OSSL_INDICATOR_set_callback() pour le contexte de bibliothèque libctx donné, ou NULL si aucune fonction de rappel n'est actuellement définie.

EXEMPLES

Une fonction de rappel d'indicateur simple pour enregistrer les opérations FIPS non approuvées

 static int indicator_cb(const char *type, const char *desc,
                         const OSSL_PARAM params[])
 {
     if (type != NULL && desc != NULL)
         fprintf(stdout, "%s %s n'est pas approuvé\n", type, desc);
end:
     /* Pour des fins de test, vous pourriez retourner 0 ici pour provoquer une erreur */
     return 1;
 }
 OSSL_INDICATOR_set_callback(libctx, indicator_cb);
