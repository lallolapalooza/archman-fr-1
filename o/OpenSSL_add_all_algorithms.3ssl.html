OpenSSL_add_all_algorithms(3ssl)

Paquet: openssl

Licences: Apache-2.0

OPENSSL_ADD_ALL_ALGORITHMS(3ssl) OpenSSL OPENSSL_ADD_ALL_ALGORITHMS(3ssl)

NOM

OpenSSL_add_all_algorithms, OpenSSL_add_all_ciphers, OpenSSL_add_all_digests, EVP_cleanup - ajouter des algorithmes à la table interne

SYNTAXE

#include <openssl/evp.h>

Les fonctions suivantes ont été dépréciées depuis OpenSSL 1.1.0, et peuvent être entièrement masquées en définissant OPENSSL_API_COMPAT avec une valeur de version appropriée, voir openssl_user_macros(7) :

void OpenSSL_add_all_algorithms(void);
void OpenSSL_add_all_ciphers(void);
void OpenSSL_add_all_digests(void);
void EVP_cleanup(void);

DESCRIPTION

OpenSSL conserve une table interne d'algorithmes de hachage et de chiffrements. Elle utilise cette table pour rechercher des chiffrements via des fonctions telles que EVP_get_cipher_byname().

OpenSSL_add_all_digests() ajoute tous les algorithmes de hachage à la table.

OpenSSL_add_all_algorithms() ajoute tous les algorithmes à la table (hachages et chiffrements).

OpenSSL_add_all_ciphers() ajoute tous les algorithmes de chiffrement à la table, y compris les algorithmes de chiffrement basés sur mot de passe.

Dans les versions antérieures à 1.1.0, EVP_cleanup() retirait tous les chiffrements et hachages de la table. Elle n'a plus aucun effet dans OpenSSL 1.1.0.

VALEURS DE RETOUR

Aucune des fonctions ne retourne de valeur.

VOIR AUSSI

evp(7), EVP_DigestInit(3), EVP_EncryptInit(3)

HISTORIQUE

Les fonctions OpenSSL_add_all_algorithms(), OpenSSL_add_all_ciphers(), OpenSSL_add_all_digests() et EVP_cleanup() ont été dépréciées dans OpenSSL 1.1.0 par OPENSSL_init_crypto() et ne doivent pas être utilisées.
