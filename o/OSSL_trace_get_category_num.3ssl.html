OSSL_trace_get_category_num(3ssl)

Paquet: openssl

Licences: Apache-2.0

OSSL_TRACE_GET_CATEGORY_NUM(3ssl) OpenSSL OSSL_TRACE_GET_CATEGORY_NUM(3ssl)

NOM

OSSL_trace_get_category_num, OSSL_trace_get_category_name - Fonctions d'information de traçage OpenSSL

SYNTAXE

#include <openssl/trace.h>
int OSSL_trace_get_category_num(const char *name);
const char *OSSL_trace_get_category_name(int num);

DESCRIPTION

OSSL_trace_get_category_num() donne le numéro de catégorie correspondant au "name" donné.

OSSL_trace_get_category_name() donne le nom de catégorie correspondant au "num" donné.

VALEURS DE RETOUR

OSSL_trace_get_category_num() retourne le numéro de catégorie si le "name" donné est un nom de catégorie reconnu, sinon -1.

OSSL_trace_get_category_name() retourne le nom de catégorie si le "num" donné est un numéro de catégorie reconnu, sinon NULL.

HISTORIQUE

L'API de traçage OpenSSL a été ajoutée à OpenSSL 3.0.
