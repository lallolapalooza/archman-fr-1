OPENSSL_LH_stats(3ssl)

Paquet: openssl

Licences: Apache-2.0

OPENSSL_LH_STATS(3ssl) OpenSSL OPENSSL_LH_STATS(3ssl)

NOM

OPENSSL_LH_STATS, OPENSSL_LH_node_stats, OPENSSL_LH_node_usage_stats, OPENSSL_LH_stats_bio, OPENSSL_LH_node_stats_bio, OPENSSL_LH_node_usage_stats_bio - Statistiques LHASH

SYNTAXE

#include <openssl/lhash.h>

Les fonctions suivantes ont été dépréciées depuis OpenSSL 3.1, et peuvent être complètement masquées en définissant OPENSSL_API_COMPAT avec une valeur de version appropriée, voir openssl_user_macros(7):

void OPENSSL_LH_node_stats(LHASH *table, FILE *out);
void OPENSSL_LH_node_usage_stats(LHASH *table, FILE *out);
void OPENSSL_LH_node_stats_bio(LHASH *table, BIO *out);
void OPENSSL_LH_node_usage_stats_bio(LHASH *table, BIO *out);
void OPENSSL_LH_stats(LHASH *table, FILE *out);
void OPENSSL_LH_stats_bio(LHASH *table, BIO *out);

DESCRIPTION

La structure LHASH enregistre des statistiques sur la plupart des aspects d'accès à la table de hachage.

OPENSSL_LH_stats() affiche des statistiques sur la taille de la table de hachage et le nombre d'entrées qu'elle contient. Pour des raisons historiques, cette fonction affiche également un certain nombre de statistiques supplémentaires, mais le suivi de ces statistiques n'est plus pris en charge et ces statistiques sont toujours rapportées comme étant zéro.

OPENSSL_LH_node_stats() affiche le nombre d'entrées pour chaque "bucket" (compartiment) dans la table de hachage.

OPENSSL_LH_node_usage_stats() affiche un bref résumé de l'état de la table de hachage. Elle affiche la "charge" et la "charge réelle". La charge est le nombre moyen d'éléments de données par "bucket" dans la table de hachage. La "charge réelle" est le nombre moyen d'éléments par "bucket", mais uniquement pour les "buckets" qui contiennent des entrées. Ainsi, la "charge réelle" est le nombre moyen de recherches qui devront trouver un élément dans la table de hachage, tandis que la "charge" est le nombre moyen qui sera effectué pour enregistrer une absence.

OPENSSL_LH_stats_bio(), OPENSSL_LH_node_stats_bio() et OPENSSL_LH_node_usage_stats_bio() sont identiques aux fonctions ci-dessus, à l'exception du fait que la sortie est dirigée vers un **BIO**.

Ces fonctions sont dépréciées et ne devraient plus être utilisées.

VALEURS DE RETOUR

Ces fonctions ne renvoient aucune valeur.

NOTE

Ces appels doivent être effectués sous un verrou de lecture. Se référer à la "NOTE" dans OPENSSL_LH_COMPFUNC(3) pour plus de détails sur les verrous requis lors de l'utilisation de la structure de données LHASH.

VOIR AUSSI

bio(7), OPENSSL_LH_COMPFUNC(3)

HISTORIQUE

Ces fonctions ont été dépréciées dans la version 3.1.
