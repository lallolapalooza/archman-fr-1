NOM

OCSP_request_add1_nonce, OCSP_basic_add1_nonce, OCSP_check_nonce, OCSP_copy_nonce - Fonctions nonce OCSP

SYNOPIS

#include <openssl/ocsp.h>
int OCSP_request_add1_nonce(OCSP_REQUEST *req, unsigned char *val, int len);
int OCSP_basic_add1_nonce(OCSP_BASICRESP *resp, unsigned char *val, int len);
int OCSP_copy_nonce(OCSP_BASICRESP *resp, OCSP_REQUEST *req);
int OCSP_check_nonce(OCSP_REQUEST *req, OCSP_BASICRESP *resp);

DESCRIPTION

OCSP_request_add1_nonce() ajoute un nonce de valeur val et de longueur len à la requête OCSP req. Si val est NULL, un nonce aléatoire est utilisé. Si len est zéro ou négatif, une longueur par défaut sera utilisée (actuellement 16 octets).

OCSP_basic_add1_nonce() est identique à OCSP_request_add1_nonce() sauf qu'elle ajoute un nonce à la réponse OCSP basique resp.

OCSP_check_nonce() compare les valeurs des nonces dans req et resp.

OCSP_copy_nonce() copie toute valeur de nonce présente dans req vers resp.

VALEURS DE RETOUR

OCSP_request_add1_nonce() et OCSP_basic_add1_nonce() retournent 1 en cas de succès et 0 en cas d'échec.

OCSP_copy_nonce() retourne 1 si un nonce a été copié avec succès, 2 si aucun nonce n'était présent dans req et 0 si une erreur s'est produite.

OCSP_check_nonce() retourne le résultat de la comparaison des nonces entre req et resp. La valeur de retour indique le résultat de la comparaison. Si les nonces sont présents et égaux, 1 est retourné. Si les nonces sont absents, 2 est retourné. Si un nonce est présent uniquement dans la réponse, 3 est retourné. Si les nonces sont présents et inégaux, 0 est retourné. Si le nonce est présent uniquement dans la requête, -1 est retourné.

NOTES

Pour la plupart des usages, la valeur du nonce dans une requête est définie à une valeur aléatoire, donc le paramètre val dans OCSP_request_add1_nonce() est généralement NULL.

Un nonce OCSP est généralement ajouté à une requête OCSP pour déjouer les attaques par rejeu en vérifiant que la même valeur de nonce apparaît dans la réponse.

Certains répondeurs peuvent inclure un nonce dans toutes les réponses même si aucun n'est fourni.

Certains répondeurs mettent en cache les réponses OCSP et ne signent pas chaque réponse pour des raisons de performance. Par conséquent, ils ne prennent pas en charge les nonces.

Les valeurs de retour de OCSP_check_nonce() peuvent être vérifiées pour couvrir chaque cas. Une valeur de retour positive indique effectivement un succès : les nonces sont présents et correspondent, tous deux absents, ou présents uniquement dans la réponse. Une valeur de retour non nulle couvre également le cas où le nonce est présent uniquement dans la requête : cela se produira si le répondeur ne prend pas en charge les nonces. Une valeur de retour nulle indique des nonces présents et non correspondants : cela doit être traité comme une condition d'erreur.
