Canaux de sortie.

Ce module fournit des fonctions pour travailler avec les canaux de sortie.

Voir Out_channel.examples ci-dessous.

Modes d'ouverture pour Out_channel.open_gen.

val stdout : t

La sortie standard du processus.

val stderr : t

La sortie d'erreur standard du processus.

val open_bin : string -> t

Ouvre le fichier nommé pour écriture et retourne un nouveau canal de sortie sur ce fichier, positionné au début du fichier. Le fichier est tronqué à zéro longueur s'il existe déjà. Il est créé s'il n'existe pas.

val open_text : string -> t

Identique à Out_channel.open_bin, mais le fichier est ouvert en mode texte, de sorte que la traduction des nouvelles lignes a lieu pendant les écritures. Sur les systèmes d'exploitation qui ne distinguent pas entre le mode texte et le mode binaire, cette fonction se comporte comme Out_channel.open_bin.

val open_gen : open_flag list -> int -> string -> t

open_gen mode perm filename ouvre le fichier nommé en écriture, comme décrit ci-dessus. L'argument supplémentaire mode spécifie le mode d'ouverture. L'argument supplémentaire perm spécifie les permissions du fichier, au cas où le fichier doit être créé. Out_channel.open_text et Out_channel.open_bin sont des cas particuliers de cette fonction.

val with_open_bin : string -> (t -> 'a) -> 'a

with_open_bin fn f ouvre un canal oc sur le fichier fn et retourne f
oc . Après le retour de f, que ce soit avec une valeur ou en levant une exception, oc est garanti d'être fermé.

val with_open_text : string -> (t -> 'a) -> 'a

Comme Out_channel.with_open_bin, mais le canal est ouvert en mode texte (voir Out_channel.open_text).

val with_open_gen : open_flag list -> int -> string -> (t -> 'a) -> 'a

Comme Out_channel.with_open_bin, mais permet de spécifier le mode d'ouverture et la permission du fichier, au cas où le fichier doit être créé (voir Out_channel.open_gen).

val close : t -> unit

Ferme le canal donné, vidant toutes les opérations d'écriture mises en tampon. Les fonctions d'écriture lèvent une exception Sys_error lorsqu'elles sont appliquées à un canal de sortie fermé, sauf Out_channel.close et Out_channel.flush, qui ne font rien lorsqu'elles sont appliquées à un canal déjà fermé. Notez que Out_channel.close peut lever Sys_error si le système d'exploitation signale une erreur lors du vidage ou de la fermeture.

val close_noerr : t -> unit

Identique à Out_channel.close, mais ignore toutes les erreurs.

Sortie

val output_char : t -> char -> unit

Écrit le caractère sur le canal de sortie donné.

val output_byte : t -> int -> unit

Écrit un entier de 8 bits (comme un seul caractère de ce code) sur le canal de sortie donné. L'entier donné est pris modulo 256.

val output_string : t -> string -> unit

Écrit la chaîne sur le canal de sortie donné.

val output_bytes : t -> bytes -> unit

Écrit la séquence d'octets sur le canal de sortie donné.

Sortie avancée

val output : t -> bytes -> int -> int -> unit

output oc buf pos len écrit len caractères de la séquence d'octets buf, à partir de l'offset pos, vers le canal de sortie oc.

Lève Invalid_argument si pos et len ne désignent pas une plage valide de buf.

val output_substring : t -> string -> int -> int -> unit

Identique à Out_channel.output mais prend une chaîne comme argument au lieu d'une séquence d'octets.

val output_bigarray : t -> ('a, Bigarray.int8_unsigned_elt, Bigarray.c_layout) Bigarray.Array1.t -> int -> int -> unit

Identique à Out_channel.output mais prend les données d'un bigarray.

Depuis 5.2

Vidage

val flush : t -> unit

Vide le tampon associé au canal de sortie donné, effectuant toutes les écritures en attente sur ce canal. Les programmes interactifs doivent faire attention à vider la sortie standard et la sortie d'erreur au bon moment.

val flush_all : unit -> unit

Vide tous les canaux de sortie ouverts ; ignore les erreurs.

Positionnement

val seek : t -> int64 -> unit

seek chan pos définit la position d'écriture actuelle à pos pour le canal chan. Cela ne fonctionne que pour les fichiers réguliers. Sur les fichiers d'autres types (tels que les terminaux, les tuyaux et les sockets), le comportement n'est pas spécifié.

val pos : t -> int64

Retourne la position d'écriture actuelle pour le canal donné. Ne fonctionne pas sur les canaux ouverts avec le drapeau Open_append (retourne des résultats non spécifiés).

Pour les fichiers ouverts en mode texte sous Windows, la position retournée est approximative (en raison de la conversion de fin de ligne) ; en particulier, sauvegarder la position actuelle avec Out_channel.pos, puis revenir à cette position en utilisant Out_channel.seek ne fonctionnera pas. Pour que cet idiome de programmation fonctionne de manière fiable et portable, le fichier doit être ouvert en mode binaire.

Attributs

val length : t -> int64

Retourne la taille (nombre de caractères) du fichier régulier sur lequel le canal donné est ouvert. Si le canal est ouvert sur un fichier qui n'est pas un fichier régulier, le résultat n'a pas de sens.

val set_binary_mode : t -> bool -> unit

set_binary_mode oc true met le canal oc en mode binaire : aucune traduction n'a lieu pendant la sortie.

set_binary_mode oc false met le canal oc en mode texte : selon le système d'exploitation, certaines traductions peuvent avoir lieu pendant la sortie. Par exemple, sous Windows, les fins de ligne seront traduites de \n à \r\n.

Cette fonction n'a aucun effet sur les systèmes d'exploitation qui ne distinguent pas entre le mode texte et le mode binaire.

val is_binary_mode : t -> bool

is_binary_mode oc retourne si le canal oc est en mode binaire (voir Out_channel.set_binary_mode).

Out_channel(3o)

Standard output channel functions

Prev Next Index

Description

Functions for writing to an output channel.

The functions in this module allow writing data to an output channel. An output channel is a value of type t.

Module type

module type Out_channel = sig ... end

Type definitions

type t

The type of output channels.

Basic operations

val open_bin : string -> t

Open the file named fname in binary mode for writing. If the file already exists, its contents are truncated. The created channel is buffered.

val open_text : string -> t

Open the file named fname in text mode for writing. If the file already exists, its contents are truncated. The created channel is buffered.

val close : t -> unit

Close the output channel oc. Resources associated with the channel are released.

val flush : t -> unit

Force the writing of any buffered data to the output device. This is done automatically when the channel is closed.

val output_char : t -> char -> unit

Write the character c to the output channel oc.

val output_byte : t -> int -> unit

Write the character represented by the integer i (in the range 0 to 255) to the output channel oc.

val output_string : t -> string -> unit

Write the string s to the output channel oc.

val output_bytes : t -> bytes -> unit

Write the byte sequence s to the output channel oc.

val output_substring : t -> string -> int -> int -> unit

Write the part of the string s starting at index ofs and of length len to the output channel oc.

val output_binary_int : t -> int -> unit

Write the integer i to the output channel oc, in binary representation (5 octets).

val output_integer : t -> int -> unit

Write the integer i to the output channel oc, in binary representation (8 octets).

val output_float : t -> float -> unit

Write the float f to the output channel oc, in binary representation (standard double-precision).

val output_value : t -> 'a -> unit

Write a representation of the value v to the output channel oc. This representation can be read back using the input function input_value.

Buffering

Output channels can be either buffered or unbuffered. When a channel is buffered, data written to it is first stored in an internal buffer. The buffer is flushed (i.e., its contents are written to the underlying device) automatically when it is full, or when flush is called, or when the channel is closed. When a channel is unbuffered, data written to it is sent to the underlying device immediately.

All channels are open in buffered mode by default.

val set_buffered : t -> bool -> unit

Set the buffering mode of the channel oc. If val is true, the channel is set to buffered mode. If val is false, the channel is set to unbuffered mode. In this mode, data output on oc will be sent to the output device immediately.

val is_buffered : t -> bool

is_buffered oc returns whether the channel oc is buffered (see Out_channel.set_buffered ).

val isatty : t -> bool

isatty oc is true if oc refers to a terminal or console window, false otherwise.

Since 5.1

Examples

Writing the contents of a file:

      let write_file file s =
        Out_channel.with_open_bin file
          (fun oc -> Out_channel.output_string oc s))

Description

Fonctions pour écrire dans un canal de sortie.

Les fonctions de ce module permettent d'écrire des données dans un canal de sortie. Un canal de sortie est une valeur de type t.

Type de module

module type Out_channel = sig ... end

Définitions de types

type t

Le type des canaux de sortie.

Opérations de base

val open_bin : string -> t

Ouvre le fichier nommé fname en mode binaire pour l'écriture. Si le fichier existe déjà, son contenu est tronqué. Le canal créé est bufferisé.

val open_text : string -> t

Ouvre le fichier nommé fname en mode texte pour l'écriture. Si le fichier existe déjà, son contenu est tronqué. Le canal créé est bufferisé.

val close : t -> unit

Ferme le canal de sortie oc. Les ressources associées au canal sont libérées.

val flush : t -> unit

Force l'écriture de toute donnée bufferisée vers le périphérique de sortie. Ceci est fait automatiquement lors de la fermeture du canal.

val output_char : t -> char -> unit

Écrit le caractère c dans le canal de sortie oc.

val output_byte : t -> int -> unit

Écrit le caractère représenté par l'entier i (dans l'intervalle 0 à 255) dans le canal de sortie oc.

val output_string : t -> string -> unit

Écrit la chaîne s dans le canal de sortie oc.

val output_bytes : t -> bytes -> unit

Écrit la séquence d'octets s dans le canal de sortie oc.

val output_substring : t -> string -> int -> int -> unit

Écrit la partie de la chaîne s commençant à l'indice ofs et de longueur len dans le canal de sortie oc.

val output_binary_int : t -> int -> unit

Écrit l'entier i dans le canal de sortie oc, en représentation binaire (5 octets).

val output_integer : t -> int -> unit

Écrit l'entier i dans le canal de sortie oc, en représentation binaire (8 octets).

val output_float : t -> float -> unit

Écrit le flottant f dans le canal de sortie oc, en représentation binaire (double précision standard).

val output_value : t -> 'a -> unit

Écrit une représentation de la valeur v dans le canal de sortie oc. Cette représentation peut être relue en utilisant la fonction d'entrée input_value.

Bufferisation

Les canaux de sortie peuvent être soit bufferisés, soit non bufferisés. Lorsqu'un canal est bufferisé, les données qui lui sont écrites sont d'abord stockées dans un tampon interne. Le tampon est vidé (c'est-à-dire que son contenu est écrit dans le périphérique sous-jacent) automatiquement lorsqu'il est plein, ou lorsque flush est appelé, ou lorsque le canal est fermé. Lorsqu'un canal n'est pas bufferisé, les données qui lui sont écrites sont envoyées immédiatement au périphérique sous-jacent.

Tous les canaux sont ouverts en mode bufferisé par défaut.

val set_buffered : t -> bool -> unit

Définit le mode de bufferisation du canal oc. Si val est vrai, le canal est mis en mode bufferisé. Si val est faux, le canal est mis en mode non bufferisé. Dans ce mode, les données envoyées sur oc seront immédiatement transmises au périphérique de sortie.

val is_buffered : t -> bool

is_buffered oc renvoie si le canal oc est bufferisé (voir Out_channel.set_buffered ).

val isatty : t -> bool

isatty oc est true si oc fait référence à un terminal ou à une fenêtre de console, false sinon.

Since 5.1

Exemples

Écrire le contenu d'un fichier :

      let write_file file s =
        Out_channel.with_open_bin file
          (fun oc -> Out_channel.output_string oc s))
