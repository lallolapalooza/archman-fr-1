DESCRIPTION

ITAV est un raccourci pour InfoTypeAndValue.

OSSL_CMP_ITAV_new_caCerts() crée une structure OSSL_CMP_ITAV de type caCerts et la remplit avec une copie de la liste de certificats fournie. L'argument caCerts peut être NULL ou contenir n'importe quel nombre de certificats.

OSSL_CMP_ITAV_get0_caCerts() requiert que itav soit de type caCerts. S'il n'y a pas de certificats dans itav, elle affecte NULL à *out. Sinon, elle renvoie un pointeur interne vers la structure STACK_OF(X509) contenant les certificats.

OSSL_CMP_ITAV_new_rootCaCert() crée une nouvelle structure OSSL_CMP_ITAV de type rootCaCert qui inclut le certificat optionnellement donné.

OSSL_CMP_ITAV_get0_rootCaCert() requiert que itav soit de type rootCaCert. S'il n'y a pas de certificat dans itav, elle affecte NULL à *out. Sinon, elle renvoie un pointeur interne vers le certificat contenu dans le champ infoValue.

OSSL_CMP_ITAV_new_rootCaKeyUpdate() crée une nouvelle structure OSSL_CMP_ITAV de type rootCaKeyUpdate qui inclut une structure optionnelle RootCaKeyUpdateContent avec les certificats newWithNew, newWithOld et oldWithNew. Une structure RootCaKeyUpdateContent n'est incluse que si newWithNew n'est pas NULL.

OSSL_CMP_ITAV_get0_rootCaKeyUpdate() requiert que itav ait le type d'information rootCaKeyUpdate. S'il y a une mise à jour d'un certificat racine, elle affecte à *newWithNew le pointeur interne vers le certificat contenu dans le sous-champ newWithNew de itav. Si newWithOld n'est pas NULL, elle affecte à *newWithOld le pointeur interne vers le certificat contenu dans le sous-champ newWithOld de itav. Si oldWithNew n'est pas NULL, elle affecte à *oldWithNew le pointeur interne vers le certificat contenu dans le sous-champ oldWithNew de itav. Chacun de ces pointeurs sera mis à NULL s'il n'y a pas de mise à jour de certificat racine ou si le sous-champ respectif n'est pas inclus.

OSSL_CMP_CRLSTATUS_new1() alloue une nouvelle structure de type CRLSTATUS qui contient une copie du nom du point de distribution dpn ou de l'émetteur issuer, mais les deux sont des erreurs. Si fournie, elle inclut également une copie du temps d'émission du CRL thisUpdate.

OSSL_CMP_CRLSTATUS_create() est une variante de haut niveau de OSSL_CMP_CRLSTATUS_new1(). Elle remplit le champ thisUpdate avec une copie du champ thisUpdate de crl s'il est présent. Elle remplit le champ CRLSource avec une copie du premier élément trouvé en utilisant les paramètres crl et/ou cert, en suivant la règle suivante : tout nom de point de distribution est préféré aux noms d'émetteurs. Les données de cert, si présentes, sont préférées aux données de crl. S'il n'y a pas de noms de points de distribution, les noms d'émetteurs sont utilisés en fonction des sources suivantes, dans l'ordre de priorité :

la liste des points de distribution dans l'extension cert
le champ issuer de la clé de signature d'autorité dans cert
le DN de l'émetteur de cert
le champ issuer de la clé de signature d'autorité dans crl
le DN de l'émetteur de crl

Si only_DN est défini, les noms d'émetteurs de type GENERAL_NAMES ne sont acceptés que s'ils contiennent exactement un nom de type directoryName.

OSSL_CMP_CRLSTATUS_get0() lit les champs de crlstatus et affecte les valeurs à *dpn, *issuer et *thisUpdate. *thisUpdate n'est affecté que si l'argument thisUpdate n'est pas NULL. Selon la présence, *dpn ou *issuer sera choisi, mais un seul d'entre eux sera NULL. *thisUpdate peut également être NULL si le champ n'est pas présent.

OSSL_CMP_ITAV_new0_crlStatusList() crée une nouvelle structure OSSL_CMP_ITAV de type crlStatusList qui inclut la liste optionnelle de données d'état de CRL, chacune étant de type OSSL_CMP_CRLSTATUS.

OSSL_CMP_ITAV_get0_crlStatusList() en cas de succès affecte à *out un pointeur interne vers la liste des données d'état de CRL dans le champ infoValue de itav. Le pointeur peut être NULL s'il n'y a pas de données d'état de CRL incluses. C'est une erreur si le type d'information de itav n'est pas crlStatusList.

OSSL_CMP_ITAV_new_crls() crée une nouvelle structure OSSL_CMP_ITAV de type crls qui inclut une liste vide de CRL si l'argument crl est NULL ou inclut une liste singleton avec une copie optionnelle du CRL fourni.

OSSL_CMP_ITAV_get0_crls() en cas de succès affecte à *out un pointeur interne vers la liste des CRL contenus dans le champ infoValue de itav. Le pointeur peut être NULL s'il n'y a pas de CRL inclus. C'est une erreur si le type d'information de itav n'est pas crls.

OSSL_CMP_ITAV_new0_certReqTemplate() crée une structure OSSL_CMP_ITAV de type certReqTemplate. Si certTemplate est NULL, keySpec doit également être NULL, et le résultat peut être utilisé dans un message genm pour obtenir les exigences de PKI concernant le modèle de certificat utilisé pour demander des certificats, ou dans un message genp indiquant qu'il n'y a pas de telles exigences. Sinon, le résultat inclut une structure CertReqTemplateValue avec certTemplate de type OSSL_CRMF_CERTTEMPLATE et une liste optionnelle de spécifications de clé keySpec, chacune de type OSSL_CMP_ATAV, et le résultat peut être utilisé dans un message genp pour fournir les exigences.

OSSL_CMP_ITAV_get1_certReqTemplate() requiert que itav soit de type certReqTemplate. S'il n'y a pas de structure OSSL_CRMF_CERTTEMPLATE avec une valeur de modèle dans itav, elle affecte NULL à *certTemplate. Sinon, elle affecte une copie de la valeur du champ certTemplate.
