#include <openssl/store.h>
typedef struct ossl_store_search_st OSSL_STORE_SEARCH;
OSSL_STORE_SEARCH *OSSL_STORE_SEARCH_by_name(X509_NAME *name);

OSSL_STORE_SEARCH *OSSL_STORE_SEARCH_by_alias(const char *alias);
void OSSL_STORE_SEARCH_free(OSSL_STORE_SEARCH *search);

DESCRIPTION

Ces fonctions sont utilisées pour spécifier des critères de recherche afin d'aider à rechercher des objets spécifiques par d'autres noms que celui de l'URI fourni à OSSL_STORE_open(). Par exemple, cela peut être utile pour une application qui a reçu une URI et qui souhaite ensuite ajouter des critères de recherche de manière uniforme et prise en charge.

Types

OSSL_STORE_SEARCH est un type opaque qui contient le critère de recherche construit, et qui peut être donné à un contexte OSSL_STORE avec OSSL_STORE_find().

L'application appelante est toujours propriétaire de l'allocation d'un OSSL_STORE_SEARCH, et doit donc veiller à ne pas le désallouer avant que OSSL_STORE_close() n'ait été appelé pour le contexte OSSL_STORE auquel il a été donné.

Fonctions d'application

OSSL_STORE_SEARCH_by_name(), OSSL_STORE_SEARCH_by_issuer_serial(), OSSL_STORE_SEARCH_by_key_fingerprint(), et OSSL_STORE_SEARCH_by_alias() sont utilisées pour créer un OSSL_STORE_SEARCH à partir d'un nom de sujet, d'une paire nom d'émetteur et numéro de série, d'une empreinte de clé, et d'un alias (par exemple un nom convivial). Les paramètres fournis ne sont pas copiés, seulement référencés dans un critère, ils doivent donc avoir au moins la même durée de vie que le OSSL_STORE_SEARCH créé.

OSSL_STORE_SEARCH_free() est utilisée pour libérer le OSSL_STORE_SEARCH. Si l'argument est NULL, rien n'est fait.

Fonctions de chargeur

OSSL_STORE_SEARCH_get_type() renvoie le type de critère pour le OSSL_STORE_SEARCH donné.

OSSL_STORE_SEARCH_get0_name(), OSSL_STORE_SEARCH_get0_serial(), OSSL_STORE_SEARCH_get0_bytes(), OSSL_STORE_SEARCH_get0_string(), et OSSL_STORE_SEARCH_get0_digest() sont utilisées pour récupérer différentes données à partir d'un OSSL_STORE_SEARCH, selon ce qui est disponible pour chaque type. Pour plus d'informations, voir "TYPES DE CRITÈRES SUPPORTÉS" ci-dessous.

TYPES DE CRITÈRES SUPPORTÉS

Les types de critères actuellement supportés sont :

OSSL_STORE_SEARCH_BY_NAME
Ce critère supporte une recherche par correspondance exacte du nom du sujet. Le nom du sujet lui-même est un pointeur X509_NAME. Un critère de ce type est créé avec OSSL_STORE_SEARCH_by_name(), et le nom du sujet réel est récupéré avec OSSL_STORE_SEARCH_get0_name().
OSSL_STORE_SEARCH_BY_ISSUER_SERIAL
Ce critère supporte une recherche par correspondance exacte du nom de l'émetteur et du numéro de série. Le nom de l'émetteur lui-même est un pointeur X509_NAME, et le numéro de série est un pointeur ASN1_INTEGER. Un critère de ce type est créé avec OSSL_STORE_SEARCH_by_issuer_serial() et le nom de l'émetteur et le numéro de série réels sont récupérés avec OSSL_STORE_SEARCH_get0_name() et OSSL_STORE_SEARCH_get0_serial().
OSSL_STORE_SEARCH_BY_KEY_FINGERPRINT
Ce critère supporte une recherche par correspondance exacte de l'empreinte de clé. L'empreinte de clé elle-même est une chaîne d'octets et sa longueur, ainsi que l'algorithme utilisé pour calculer l'empreinte. Le digest peut être laissé non spécifié (NULL), et dans ce cas, le chargeur doit décider d'un digest par défaut et comparer les empreintes en conséquence. Un critère de ce type est créé avec OSSL_STORE_SEARCH_by_key_fingerprint() et l' empreinte réelle et sa longueur peuvent être récupérées avec OSSL_STORE_SEARCH_get0_bytes(). Le digest peut être récupéré avec OSSL_STORE_SEARCH_get0_digest().
OSSL_STORE_SEARCH_BY_ALIAS
Ce critère supporte une recherche par correspondance d'un alias de quelque sorte. L' alias lui-même est une simple chaîne C. Un critère de ce type est créé avec OSSL_STORE_SEARCH_by_alias() et l'alias réel est récupéré avec OSSL_STORE_SEARCH_get0_string().

VALEURS DE RETOUR

OSSL_STORE_SEARCH_by_name(), OSSL_STORE_SEARCH_by_issuer_serial(), OSSL_STORE_SEARCH_by_key_fingerprint(), et OSSL_STORE_SEARCH_by_alias() renvoient un pointeur OSSL_STORE_SEARCH en cas de succès, ou NULL en cas d'échec.

OSSL_STORE_SEARCH_get_type() renvoie le type de critère du OSSL_STORE_SEARCH donné. Il n'y a pas de valeur d'erreur.

OSSL_STORE_SEARCH_get0_name() renvoie un pointeur X509_NAME en cas de succès, ou NULL lorsque le OSSL_STORE_SEARCH donné était d'un type différent.

OSSL_STORE_SEARCH_get0_serial() renvoie un pointeur ASN1_INTEGER en cas de succès, ou NULL lorsque le OSSL_STORE_SEARCH donné était d'un type différent.

OSSL_STORE_SEARCH_get0_bytes() renvoie un pointeur const unsigned char et définit *length à la longueur de la chaîne en cas de succès, ou NULL lorsque le OSSL_STORE_SEARCH donné était d'un type différent.

OSSL_STORE_SEARCH_get0_string() renvoie un pointeur const char en cas de succès, ou NULL lorsque le OSSL_STORE_SEARCH donné était d'un type différent.

OSSL_STORE_SEARCH_get0_digest() renvoie un pointeur const EVP_MD. NULL est une valeur valide et signifie que la valeur par défaut du chargeur de magasin sera utilisée le cas échéant.
