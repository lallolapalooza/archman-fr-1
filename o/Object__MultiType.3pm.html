NOM

Object::MultiType - Objets Perl comme Hash, Tableau, Scalaire, Code et Glob en même temps.

SYNOPSIS

use Object::MultiType ;
my $scalar = 'abc' ;
my @array  = qw(x y z);
my %hash   = (A => 1 , B => 2) ;
my $obj = Object::MultiType->new(
scalar => \$scalar ,
array  => \@array ,
hash   => \%hash ,
code   => sub{ return("Je suis une référence de sous-routine !") ; }
glob   => \*STDOUT ,
) ;

print "Moi en tant que scalaire : $obj\n" ;

my $array_1 = $obj->[1] ;
print "$array_1\n" ;

my $hash_B = $obj->{B} ;
print "$hash_B\n" ;

my $hash = $$obj->hash ;
foreach my $Key (sort keys %$hash ) {
  print "$Key = $$hash{$Key}\n" ;
}

&$obj(args) ;

DESCRIPTION

Ce module retourne un objet qui fonctionne comme un objet Hash, Tableau, Scalaire, Code et Glob en même temps.

La manière habituelle est de l'appeler depuis votre module à new() :

package FOO ;

use Object::MultiType ;
use vars qw(@ISA) ;
@ISA = qw(Object::MultiType) ; ## Il est bon que 'Object::MultiType' soit le dernier dans @ISA !

sub new {
  my $class = shift ;
  my $this = Object::MultiType->new() ;
  bless($this,$class) ;
}

MÉTHODES

** Voir aussi les méthodes de Saver.

new

Arguments :

bool
La référence *booléenne*. Défaut : undef
boolcode|boolsub
Définit la sous-routine/fonction (référence CODE) qui retournera/générera la valeur *booléenne*.
scalar
La référence SCALAR. Si aucune n'est fournie, un SCALAR vide sera créé.
scalarcode|scalarsub
Définit la sous-routine/fonction (référence CODE) qui retournera/générera les données scalaires de l'objet.
array
La référence ARRAY. Si aucune n'est fournie, un ARRAY vide sera créé.
hash
La référence HASH. Si aucune n'est fournie, un HASH vide sera créé.
code
La référence CODE. Si aucune n'est fournie, une sous-routine vide {} sera créée.

Avec cela, votre objet peut être utilisé comme une référence de sous-routine :

my $multi = Object::MultiType->new( code => sub { print "Args: @_\n" ;} ) ;
&$multi();

Notez que le premier argument passé à la sous-routine est l'objet ($multi).

glob
La référence GLOB (HANDLE). Si aucune n'est fournie, une GLOB vide sera créée.

** Notez que vous ne pouvez pas utiliser la GLOB par défaut (vide) créée lorsque vous ne fournissez pas cet argument ! Puisque tous les objets la partageront, elle était là juste pour éviter les erreurs !

tiearray
Nom du paquet pour créer un TIEARRAY. L'argument $$this est passé à tie().

tie() est appelé comme ceci :

tie(@array,$args{tiearray},$$this) ;

Notez qu'il est difficile d'implémenter les méthodes tie pour PUSH, POP, SHIFT, UNSHIFT, SPLICE... À moins que vous ne créiez simplement un alias vers un autre tableau via les méthodes tie.

** Voir aussi tiehash.

tiehash
Nom du paquet pour créer un TIEHASH. L'argument $$this est passé à tie().

tie() est appelé comme ceci :

tie(%hash,$args{tiehash},$$this) ;

** $$this (le Saver) est passé, et non $this, pour éviter de casser DESTROY (référence automatique).

** $$this est une référence à l'objet Saver qui sauvegarde le SCALAR, l'ARRAY, le HASH, le CODE et le GLOB.

sub TIEHASH {
  my $class = shift ;
  my $multi = shift ; ## $$this
  my $scalarref = $multi->scalar ; ## \${*$multi}
  my $arrayref  = $multi->array  ; ## \@{*$multi}
  my $hashref   = $multi->hash   ; ## \%{*$multi}

  my $this = { s => $scalarref , a => $arrayref , h => $hashref } ;
  bless($this,$class) ;
}
tiehandle
Fait en sorte que l'objet fonctionne comme un glob lié (TIEHANDLE).

S'il est utilisé avec glob, il sera lié par tie(). Si glob n'est pas fourni, un GLOB NULL est utilisé :

my $multi = Object::MultiType->new(
glob      => \*MYOUT ,               ## 'glob' est optionnel.
tiehandle => 'TieHandlePack' ,
) ;
tieonuse
La référence n'est liée que lorsqu'elle est utilisée ! Ainsi, le HASH, l'ARRAY ou le GLOB (handle) ne sont liés que s'ils sont accédés.
nodefault
S'il est défini à vrai, indique de ne pas créer les références par défaut à l'intérieur du Saver, et il n'aura que les références fournies (scalar, array, hash, code, glob).

** Ceci est bon pour économiser de la mémoire.

is_saver

Retourne 0. Utile pour savoir si ce que vous avez est le Saver ou l'objet MultiType.

SAVER

L'objet MultiType a un objet Saver (Object::MultiType::Saver) qui sauvegarde toutes les différentes types de données (références). Ce saver peut être accédé depuis l'objet principal :

my $multi = Object::MultiType->new() ;

my $saver = $$multi ;
print $saver->scalar ;

Si vous voulez sauvegarder des attributs dans votre objet et que vous utilisez tiehash, **vous ne pouvez pas définir les attributs directement dans l'objet MultiType ! :

sub new {
  my $class = shift ;
  my $this = Object::MultiType->new(tiehash => 'TieHashPack') ;
  ## Ne faites pas ça ! Cela appellera STORE() à TIEHASH, et ne le sauvegardera pas dans l'objet :
  $this->{flagx} = 1 ;

  bless($this,$class) ;
}

Donc, si vous utilisez tiehash et que vous voulez sauvegarder des attributs (en dehors de tie), utilisez ceci :

## Cela sauvegarde l'attribut à l'intérieur du Saver :
$$this->{flagx} = 1 ;

Notez que cela définit un attribut dans le saver, et il a ses propres attributs !

## $saver = $$this ;
$saver->{s} ## la référence scalaire.
$saver->{a} ## la référence tableau.
$saver->{h} ## la référence hash.
$saver->{c} ## la référence code.  
$saver->{g} ## la référence glob.

** Voir "Accès direct aux types de données".

DESTROY

Lorsque l'objet est DÉTRUIT, le Saver à l'intérieur est nettoyé, de sorte que les objets liés peuvent également être DÉTRUITS automatiquement.

Accès direct aux types de données

Pour accéder directement aux références des différents types de données (SCALAR, ARRAY, HASH, CODE & GLOB), utilisez :

my $multi = Object::MultiType->new() ;
my $saver = $$multi ;
my $scalarref = $saver->scalar ; ## $saver->{s}
my $arrayref  = $saver->array  ; ## $saver->{a}
my $hashref   = $saver->hash   ; ## $saver->{h}
my $coderef   = $saver->code   ; ## $saver->{c}
my $globeref  = $saver->glob   ; ## $saver->{g}

## Vous pouvez accéder directement au Saver depuis l'objet principal :
$$multi->hash  ;

Définition des données :

$saver->set_bool( 1 ) ;
$saver->set_scalar( 'xyz' ) ;
$saver->set_array( [qw(x y z)] ) ;
$saver->set_hash( {X => 1} ) ;
$saver->set_code( sub{ print "XYZ\n" ; } ) ;
$saver->set_glob( \*STDOUT ) ;

En tant que SCALAR

Vous pouvez l'utiliser comme SCALAR lorsque vous le mettez entre guillemets ou en créez une copie :

my $multi = Object::MultiType->new( scalar => 'Foo' ) ;
## Guillemets :
print "Moi en tant que scalaire : $multi\n" ;

## Copie :
my $str = $multi ;
$str .= '_x' ; ## Copie effectuée lorsque vous le modifiez ! Jusqu'à ce moment, $str fonctionne comme $multi.
print "$str\n" ;

En utilisant l'argument scalarsub, vous pouvez utiliser une fonction qui générera les données scalaires, à la place d'une référence à un SCALAR :

my $multi = Object::MultiType->new(scalarsub => sub{ return 'données générées' ;} ) ;

print "Mon scalaire contient $multi!\n" ;

En tant que TABLEAU

Vous pouvez utiliser l'objet comme un TABLEAU.

Exemples :

my @list = $obj->[1,2,3] ; ## Récupère les éléments d'indices 1, 2 et 3.
my $e  = $obj->[0] ; ## Récupère l'élément d'indice 0.

$obj->[0] = 'new value' ; ## Modifie l'élément d'indice 0.
$obj->[1,2] = qw(a b) ; ## Modifie les éléments d'indices 1 et 2.

push @$obj, 'new element' ; ## Ajoute un élément à la fin.
unshift @$obj, 'first element' ; ## Ajoute un élément au début.

my $last = pop @$obj ; ## Récupère et retire le dernier élément.
my $first = shift @$obj ; ## Récupère et retire le premier élément.

my @removed = splice(@$obj, 1, 2, qw(x y z)) ; ## Utilise splice.

Vous pouvez utiliser un bloc de code pour générer les données du tableau :

my $multi = Object::MultiType->new( array => [1,2,3] ) ;
my $multi = Object::MultiType->new( array = 'GenerateMyArray' ) ; ## Génère le tableau depuis une autre classe.

## Ou vous pouvez utiliser une sous-routine qui retourne une référence tableau :
my $multi = Object::MultiType->new(
  arrayref => sub {
    my $key = shift ; ## $key est le nom de l'attribut (par défaut 'array').
    ## Retourne une référence tableau.
    return [1,2,3] ;
  }
) ;

En tant que HASH

Vous pouvez utiliser l'objet comme un HASH.

Exemples :

my $value = $obj->{key} ; ## Récupère la valeur associée à la clé.
$obj->{key} = 'new value' ; ## Définit une nouvelle valeur pour la clé.

my $hashref = $obj->hash ; ## Récupère une référence au hash interne.
foreach my $key (keys %$obj) {
  print "$key => $obj->{$key}\n" ;
}

Vous pouvez utiliser un bloc de code pour générer les données du hash :

my $multi = Object::MultiType->new( hash => {a => 1, b => 2} ) ;
my $multi = Object::MultiType->new( hash => 'GenerateMyHash' ) ; ## Génère le hash depuis une autre classe.

## Ou vous pouvez utiliser une sous-routine qui retourne une référence hash :
my $multi = Object::MultiType->new(
  hashref => sub {
    my $key = shift ; ## $key est le nom de l'attribut (par défaut 'hash').
    ## Retourne une référence hash.
    return {a => 1, b => 2} ;
  }
) ;

En tant que CODE

Vous pouvez utiliser l'objet comme une référence de sous-routine.

my $result = $obj->(); ## Appelle la sous-routine interne.
my $result = $obj->(arg1, arg2) ; ## Appelle la sous-routine interne avec des arguments.
my $result = &$obj(arg1, arg2) ; ## Idem.

Vous pouvez utiliser un bloc de code pour définir la sous-routine interne :

my $multi = Object::MultiType->new(
  code => sub {
    my $obj_ref = shift ; ## C'est l'objet MultiType lui-même.
    my @args = @_ ;
    print "Objet: $obj_ref\n" ;
    print "Args: @args\n" ;
    return "Retour de la sous-routine" ;
  }
) ;
my $ret = $multi->('un', 'deux') ;
print "Retour : $ret\n" ;

En tant que GLOB

Vous pouvez utiliser l'objet comme un handle de fichier (GLOB).

my $multi = Object::MultiType->new( glob => \*STDOUT ) ;

print $multi "Ceci sera imprimé sur STDOUT\n" ;
my $line = <$multi> ; ## Lecture depuis le handle.

Si vous utilisez tiehandle, l'objet sera lié à un handle de fichier.

my $multi = Object::MultiType->new(
  glob      => \*MY_HANDLE ,
  tiehandle => 'MyTieHandlePackage' ,
) ;

OPÉRATIONS BOOLÉENNES

L'objet retourne une valeur booléenne lorsqu'il est utilisé dans un contexte booléen (par exemple, dans un `if`).

Par défaut, la valeur booléenne est déterminée par la valeur de l'objet scalaire. Vous pouvez fournir une sous-routine pour générer la valeur booléenne.

my $multi = Object::MultiType->new(
  scalar => 'quelque chose' ,
  boolsub => sub {
    my $obj_ref = shift ; ## L'objet MultiType
    ## Retourne une valeur booléenne basée sur la référence scalaire interne
    return( length($obj_ref->scalar) > 0 ) ;
  }
) ;

if ($multi) {
  print "L'objet est considéré comme vrai.\n" ;
} else {
  print "L'objet est considéré comme faux.\n" ;
}

Vous pouvez également définir directement une valeur booléenne :

my $multi = Object::MultiType->new( bool => 1 ) ;
if ($multi) { ... }

ACCESO DIRECTO A LOS DATOS DE TIPO

Acceso directo a los tipos de datos

AS SCALAR

Puedes usarlo como SCALAR directamente desde el objeto:

my $scalar = $multi->{key} ;

AS ARRAY

Puedes usarlo como ARRAY directamente desde el objeto:

my $array_0 = $multi->[0] ;

AS HASH

Puedes usarlo como HASH directamente desde el objeto:

my $k = $multi->{key} ;

CON TIE

Para usar tu parte ARRAY y HASH "tie-d", puedes pegar la referencia ya "tie-d" de HASH o ARRAY, o usar los argumentos tiehash y tiearray en new():

## Usando la referencia:
my %hash ;
tie(%hash,'TieHash') ;
my $multi = Object::MultiType->new(hash => \%hash) ;

## O usando directamente el argumento:
my $multi = Object::MultiType->new(tiehash => 'TieHashPack') ;

Ten en cuenta que usar tiehash o tiearray es mejor, ya que tu HASH o ARRAY "tie-d" puede ver el objeto Saver y el otro tipo de dato que contiene. Consulta el método new() y sus argumentos.
