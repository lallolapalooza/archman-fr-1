OCSP_response_status(3ssl)

Paquet: openssl

Licences: Apache-2.0

OCSP_response_status(3ssl) OpenSSL OCSP_response_status(3ssl)

NOM

OCSP_response_status, OCSP_response_get1_basic, OCSP_response_create, OCSP_RESPONSE_free, OCSP_RESPID_set_by_name, OCSP_RESPID_set_by_key_ex, OCSP_RESPID_set_by_key, OCSP_RESPID_match_ex, OCSP_RESPID_match, OCSP_basic_sign, OCSP_basic_sign_ctx - Fonctions de réponse OCSP

SYNOPSIS

#include <openssl/ocsp.h>
int OCSP_response_status(OCSP_RESPONSE *resp);
OCSP_BASICRESP *OCSP_response_get1_basic(OCSP_RESPONSE *resp);
OCSP_RESPONSE *OCSP_response_create(int status, OCSP_BASICRESP *bs);
void OCSP_RESPONSE_free(OCSP_RESPONSE *resp);
int OCSP_RESPID_set_by_name(OCSP_RESPID *respid, X509 *cert);
int OCSP_RESPID_set_by_key_ex(OCSP_RESPID *respid, X509 *cert,
                              OSSL_LIB_CTX *libctx, const char *propq);
int OCSP_RESPID_set_by_key(OCSP_RESPID *respid, X509 *cert);
int OCSP_RESPID_match_ex(OCSP_RESPID *respid, X509 *cert, OSSL_LIB_CTX *libctx,
                         const char *propq);
int OCSP_RESPID_match(OCSP_RESPID *respid, X509 *cert);
int OCSP_basic_sign(OCSP_BASICRESP *brsp, X509 *signer, EVP_PKEY *key,
                    const EVP_MD *dgst, STACK_OF(X509) *certs,
                    unsigned long flags);
int OCSP_basic_sign_ctx(OCSP_BASICRESP *brsp, X509 *signer, EVP_MD_CTX *ctx,
                        STACK_OF(X509) *certs, unsigned long flags);

DESCRIPTION

OCSP_response_status() retourne l'état de la réponse OCSP de resp. Il retourne l'une des valeurs suivantes : OCSP_RESPONSE_STATUS_SUCCESSFUL, OCSP_RESPONSE_STATUS_MALFORMEDREQUEST, OCSP_RESPONSE_STATUS_INTERNALERROR, OCSP_RESPONSE_STATUS_TRYLATER OCSP_RESPONSE_STATUS_SIGREQUIRED, ou OCSP_RESPONSE_STATUS_UNAUTHORIZED.

OCSP_response_get1_basic() décode et retourne la structure OCSP_BASICRESP contenue dans resp.

OCSP_response_create() crée et retourne une structure OCSP_RESPONSE pour status et incluant optionnellement la réponse basique bs.

OCSP_RESPONSE_free() libère la mémoire de la réponse OCSP resp. Si l'argument est NULL, rien n'est fait.

OCSP_RESPID_set_by_name() définit le nom de l'OCSP_RESPID pour qu'il soit le même que le nom du certificat cert de la réponse OCSP responder.

OCSP_RESPID_set_by_key_ex() définit la clé de l'OCSP_RESPID pour qu'elle soit la même que la clé du certificat cert de la réponse OCSP responder. La clé est stockée comme un hash SHA1. Pour calculer le hash, l'algorithme SHA1 est récupéré en utilisant le contexte libctx et la requête de propriété propq (voir « ALGORITHM FETCHING » dans crypto(7) pour plus d'informations).

OCSP_RESPID_set_by_key() fait la même chose que OCSP_RESPID_set_by_key_ex() sauf que le contexte par défaut est utilisé avec une requête de propriété vide.

Note : un OCSP_RESPID peut avoir seulement un nom ou une clé définie. Appeler OCSP_RESPID_set_by_name() ou OCSP_RESPID_set_by_key() effacera toute valeur précédente.

OCSP_RESPID_match_ex() vérifie si l'OCSP_RESPID donné dans respid correspond au certificat cert basé sur le hash SHA1. Pour calculer le hash, l'algorithme SHA1 est récupéré en utilisant le contexte libctx et la requête de propriété propq (voir « ALGORITHM FETCHING » dans crypto(7) pour plus d'informations).

OCSP_RESPID_match() fait la même chose que OCSP_RESPID_match_ex() sauf que le contexte par défaut est utilisé avec une requête de propriété vide.

OCSP_basic_sign() signe la réponse OCSP brsp en utilisant le certificat signer, la clé privée key, l'algorithme de hachage dgst et les certificats supplémentaires certs. Si l'option flags est définie sur OCSP_NOCERTS, aucun certificat n'est inclus dans la réponse. Si l'option flags est définie sur OCSP_RESPID_KEY, le répondant est identifié par l'ID de clé au lieu du nom. OCSP_basic_sign_ctx() signe également la réponse OCSP brsp mais utilise les paramètres contenus dans le contexte de hachage ctx.

VALEURS DE RETOUR

OCSP_RESPONSE_status() retourne une valeur d'état.

OCSP_response_get1_basic() retourne une structure OCSP_BASICRESP ou NULL en cas d'erreur.

OCSP_response_create() retourne une structure OCSP_RESPONSE ou NULL en cas d'erreur.

OCSP_RESPONSE_free() ne retourne aucune valeur.

OCSP_RESPID_set_by_name(), OCSP_RESPID_set_by_key(), OCSP_basic_sign() et OCSP_basic_sign_ctx() retournent 1 en cas de succès ou 0 en cas d'erreur.

OCSP_RESPID_match() retourne 1 si l'OCSP_RESPID et le certificat cert correspondent, ou 0 sinon.

NOTES

OCSP_response_get1_basic() est appelée seulement si l'état d'une réponse est OCSP_RESPONSE_STATUS_SUCCESSFUL.

HISTORIQUE

Les fonctions OCSP_RESPID_set_by_name(), OCSP_RESPID_set_by_key() et OCSP_RESPID_match() ont été ajoutées dans OpenSSL 1.1.0a.

La fonction OCSP_basic_sign_ctx() a été ajoutée dans OpenSSL 1.1.1.
