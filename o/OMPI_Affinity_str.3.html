Paquet: openmpi

OMPI_AFFINITY_STR(3) Open MPI OMPI_AFFINITY_STR(3)

OMPI_Affinity_str - Obtenir des chaînes de caractères joliment formatées pour les informations d'affinité du processeur pour ce processus

SYNTAXE

Syntaxe C

#include <mpi.h>
#include <mpi-ext.h>
int OMPI_Affinity_str(ompi_affinity_fmt_type_t fmt_type,
                      char ompi_bound[OMPI_AFFINITY_STRING_MAX],
                      char current_binding[OMPI_AFFINITY_STRING_MAX],
                      char exists[OMPI_AFFINITY_STRING_MAX])

Syntaxe Fortran

Il n'y a pas de liaison Fortran pour cette fonction.

Syntaxe Fortran 2008

Il n'y a pas de liaison Fortran 2008 pour cette fonction.

Syntaxe C++

Il n'y a pas de liaison C++ pour cette fonction.

PARAMÈTRES ENTRANTS

  • fmt_type: Une énumération indiquant comment formater les chaînes ompi_bound et current_binding retournées. OMPI_AFFINITY_RSRC_STRING_FMT retourne la chaîne sous forme de noms de ressources lisibles par l'homme, tels que « socket 0, core 0 ».
  • OMPI_AFFINITY_LAYOUT_FMT retourne une ASCII art représentant où ce processus MPI: est lié par rapport à la disposition des ressources de la machine. Par exemple « [. B][. .] » montre que le processus qui a appelé la routine est lié au socket 0, cœur 1 dans un système avec 2 sockets, chacun contenant 2 cœurs.
  • Voir ci-dessous pour plus d'exemples de sortie.:

PARAMÈTRES SORTANTS

  • ompi_bound: Une chaîne joliment formatée décrivant à quel(s) processeur(s) Open MPI a lié ce processus, ou une chaîne indiquant qu'Open MPI n'a pas lié ce processus.
  • current_binding: Une chaîne joliment formatée décrivant à quel(s) processeur(s) ce processus est actuellement lié, ou une chaîne indiquant que le processus est lié à tous les processeurs disponibles (et est donc considéré comme « non lié »).
  • exists: Une chaîne joliment formatée décrivant les sockets et les cœurs disponibles sur cet hôte.

DESCRIPTION

Open MPI peut lier un processus à des sockets et/ou des cœurs spécifiques au moment du lancement du processus. Cet appel de fonction non standard d'Open MPI retourne des informations joliment formatées sur trois choses :

Où Open MPI a lié ce processus.
La chaîne retournée dans ompi_bound indiquera soit qu'Open MPI n'a lié ce processus à rien, soit elle contiendra une description joliment formatée du (des) processeur(s) auquel (auxquels) Open MPI a lié ce processus.
Où ce processus est actuellement lié.
Indépendamment du fait qu'Open MPI ait lié ce processus ou non, une autre entité peut l'avoir lié. La chaîne retournée dans current_binding indiquera le lien *actuel* de ce processus, indépendamment de ce qu'Open MPI a pu faire précédemment. La chaîne retournée indiquera soit que le processus n'est pas lié (signifiant qu'il est lié à tous les processeurs disponibles), soit elle contiendra une description joliment formatée des sockets et des cœurs auxquels le processus est actuellement lié.
Quels processeurs existent.
Par commodité pour l'utilisateur, la chaîne exists contiendra une description joliment formatée des sockets et des cœurs que ce processus peut voir (ce qui correspond *généralement* à tous les processeurs du système).

EXEMPLES

Exemple 1 : Afficher les liens des processus en utilisant le format de chaîne de ressources.

int rank;
char ompi_bound[OMPI_AFFINITY_STRING_MAX];
char current_binding[OMPI_AFFINITY_STRING_MAX];
char exists[OMPI_AFFINITY_STRING_MAX];
MPI_Init(&argc, &argv);
MPI_Comm_rank(MPI_COMM_WORLD, &rank);
OMPI_Affinity_str(OMPI_AFFINITY_RSRC_STRING_FMT,
                  ompi_bound, current_binding, exists);
printf("rang %d: \n"
       "       ompi_bound: %s\n"
       "  current_binding: %s\n"
       "           exists: %s\n",
       rank, ompi_bound, current_binding, exists);
...

Sortie de mpirun -n 2 -bind-to-core a.out :

rang 0:
       ompi_bound: socket 0[core 0]
  current_binding: socket 0[core 0]
           exists: socket 0 a 4 cœurs
rang 1:
       ompi_bound: socket 0[core 1]
  current_binding: socket 0[core 1]
           exists: socket 0 a 4 cœurs

Sortie de mpirun -n 2 -bind-to-socket a.out :

rang 0:
       ompi_bound: socket 0[core 0-3]
  current_binding: Non lié (ou lié à tous les processeurs disponibles)
           exists: socket 0 a 4 cœurs
rang 1:
       ompi_bound: socket 0[core 0-3]
  current_binding: Non lié (ou lié à tous les processeurs disponibles)
           exists: socket 0 a 4 cœurs
Exemple 2 : Afficher les liens des processus en utilisant le format de chaîne de disposition.
int rank;
char ompi_bound[OMPI_AFFINITY_STRING_MAX];
char current_binding[OMPI_AFFINITY_STRING_MAX];
char exists[OMPI_AFFINITY_STRING_MAX];
MPI_Init(&argc, &argv);
MPI_Comm_rank(MPI_COMM_WORLD, &rank);
OMPI_Affinity_str(OMPI_AFFINITY_LAYOUT_FMT,
                  ompi_bound, current_binding, exists);
printf("rang %d: \n"
       "       ompi_bound: %s\n"
       "  current_binding: %s\n"
       "           exists: %s\n",
       rank, ompi_bound, current_binding, exists);
...

Sortie de mpirun -n 2 -bind-to-core a.out :

rang 0:
       ompi_bound: [B . . .]
  current_binding: [B . . .]
           exists: [. . . .]
rang 1:
       ompi_bound: [. B . .]
  current_binding: [. B . .]
           exists: [. . . .]

Sortie de mpirun -n 2 -bind-to-socket a.out :

rang 0:
       ompi_bound: [B B B B]
  current_binding: [B B B B]
           exists: [. . . .]
rang 1:
       ompi_bound: [B B B B]
  current_binding: [B B B B]
           exists: [. . . .]
