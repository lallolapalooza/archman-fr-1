OSSL_CMP_HDR_get0_transactionID(3ssl)

Paquet: openssl

Licences: Apache-2.0

OSSL_CMP_HDR_GET0_TRANSACTIONID(3ssl) OpenSSL OSSL_CMP_HDR_GET0_TRANSACTIONID(3ssl)

NOM

OSSL_CMP_HDR_get0_transactionID, OSSL_CMP_HDR_get0_recipNonce, OSSL_CMP_HDR_get0_geninfo_ITAVs - Fonctions de manipulation des en-têtes de messages CMP

SYNTAXE

 #include <openssl/cmp.h>
 ASN1_OCTET_STRING *OSSL_CMP_HDR_get0_transactionID(const
                                                    OSSL_CMP_PKIHEADER *hdr);
 ASN1_OCTET_STRING *OSSL_CMP_HDR_get0_recipNonce(const
                                                 OSSL_CMP_PKIHEADER *hdr);
 STACK_OF(OSSL_CMP_ITAV)
    *OSSL_CMP_HDR_get0_geninfo_ITAVs(const OSSL_CMP_PKIHEADER *hdr);

DESCRIPTION

OSSL_CMP_HDR_get0_transactionID retourne l'identifiant de transaction du PKIHeader donné.

OSSL_CMP_HDR_get0_recipNonce retourne le nonce du destinataire du PKIHeader donné.

OSSL_CMP_HDR_get0_geninfo_ITAVs() retourne la liste des ITAVs dans le champ generalInfo du PKIHeader donné.

NOTES

CMP est défini dans la RFC 4210.

VALEUR DE RETOUR

Les fonctions retournent le pointeur désiré comme décrit ci-dessus ou NULL si l'entrée correspondante n'existe pas et en cas d'erreur.

HISTORIQUE

Le support CMP d'OpenSSL a été ajouté dans OpenSSL 3.0.

OSSL_CMP_HDR_get0_geninfo_ITAVs() a été ajouté dans OpenSSL 3.3.
