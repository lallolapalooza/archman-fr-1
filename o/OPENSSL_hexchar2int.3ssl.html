OPENSSL_hexchar2int(3ssl)

Paquet: openssl

Licences: Apache-2.0

OPENSSL_hexchar2int(3ssl) OpenSSL OPENSSL_hexchar2int(3ssl)

NOM

OPENSSL_hexchar2int, OPENSSL_hexstr2buf_ex, OPENSSL_hexstr2buf, OPENSSL_buf2hexstr_ex, OPENSSL_buf2hexstr - Fonctions d'encodage et décodage hexadécimal

SYNTAXE

#include <openssl/crypto.h>
int OPENSSL_hexchar2int(unsigned char c);
int OPENSSL_hexstr2buf_ex(unsigned char *buf, size_t buf_n, long *buflen,
                          const char *str, const char sep);
unsigned char *OPENSSL_hexstr2buf(const char *str, long *len);
int OPENSSL_buf2hexstr_ex(char *str, size_t str_n, size_t *strlength,
                          const unsigned char *buf, long buflen,
                          const char sep);
char *OPENSSL_buf2hexstr(const unsigned char *buf, long buflen);

DESCRIPTION

OPENSSL_hexchar2int() convertit un caractère hexadécimal en sa valeur numérique équivalente.

OPENSSL_hexstr2buf_ex() décode la chaîne hexadécimale str et place la chaîne d'octets résultante dans buf. Le caractère sep est le séparateur entre les octets, le régler à '\0' signifie qu'il n'y a pas de séparateur. buf_n donne la taille du tampon. Si buflen n'est pas NULL, il est rempli avec la longueur du résultat. Pour savoir quelle sera la taille du résultat, appelez cette fonction avec NULL pour buf. Les deux-points entre des "octets" hexadécimaux de deux caractères sont acceptés et ignorés. Un nombre impair de chiffres hexadécimaux est une erreur.

OPENSSL_hexstr2buf() fait la même chose que OPENSSL_hexstr2buf_ex(), mais alloue l'espace pour le résultat et retourne le résultat. Il utilise ':' comme séparateur par défaut. La mémoire est allouée en appelant OPENSSL_malloc() et doit être libérée en appelant OPENSSL_free().

OPENSSL_buf2hexstr_ex() encode le contenu du buf donné avec la longueur buflen et place la chaîne de caractères hexadécimaux résultante dans str. Le caractère sep est le séparateur entre les octets, le régler à '\0' signifie qu'il n'y a pas de séparateur. str_n donne la taille du tampon de chaîne. Si strlength n'est pas NULL, il est rempli avec la longueur du résultat. Pour savoir quelle sera la taille du résultat, appelez cette fonction avec NULL pour str.

OPENSSL_buf2hexstr() fait la même chose que OPENSSL_buf2hexstr_ex(), mais alloue l'espace pour le résultat et retourne le résultat. Il utilise ':' comme séparateur par défaut. La mémoire est allouée en appelant OPENSSL_malloc() et doit être libérée en appelant OPENSSL_free().

VALEURS DE RETOUR

OPENSSL_hexchar2int retourne la valeur d'un caractère hexadécimal décodé, ou -1 en cas d'erreur.

OPENSSL_buf2hexstr() et OPENSSL_hexstr2buf() retournent un pointeur vers la mémoire allouée, ou NULL en cas d'erreur.

OPENSSL_buf2hexstr_ex() et OPENSSL_hexstr2buf_ex() retournent 1 en cas de succès, ou 0 en cas d'erreur.
