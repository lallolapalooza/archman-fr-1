DESCRIPTION

Encoder un objet d'entrée vers un type d'encodage désiré peut être réalisé avec une chaîne d'implémentations d'encodeurs, ce qui signifie que le résultat d'un encodeur peut être utilisé comme entrée pour le suivant dans la chaîne. Le OSSL_ENCODER_CTX stocke toutes les données relatives à ces encodeurs. Cela permet d'avoir des encodeurs génériques comme DER vers PEM, ainsi que des encodeurs plus spécialisés comme RSA vers DER.

Le type de sortie final doit être spécifié, et une chaîne d'encodeurs doit se terminer par une implémentation qui produit ce type de sortie.

Au démarrage du processus d'encodage, un constructeur fourni par l'utilisateur est appelé pour s'assurer qu'il existe un objet approprié côté fournisseur pour commencer. Le constructeur est défini avec OSSL_ENCODER_CTX_set_construct().

OSSL_ENCODER_INSTANCE est une structure opaque contenant des données sur l'encodeur à utiliser, et peut être utile pour le constructeur. Il existe quelques fonctions pour extraire des données de ce type, décrites dans la section "Constructeur" ci-dessous.

Fonctions

OSSL_ENCODER_CTX_new() crée un OSSL_ENCODER_CTX.

OSSL_ENCODER_settable_ctx_params() retourne un tableau de descripteurs de paramètres OSSL_PARAM(3).

OSSL_ENCODER_CTX_set_params() tente de définir les paramètres spécifiés avec un tableau de OSSL_PARAM(3) params. Les paramètres que l'implémentation ne reconnaît pas doivent être ignorés.

OSSL_ENCODER_CTX_free() libère le contexte ctx. Si l'argument est NULL, rien ne se passe.

OSSL_ENCODER_CTX_add_encoder() remplit le OSSL_ENCODER_CTX ctx avec un encodeur, à utiliser pour encoder un objet d'entrée.

OSSL_ENCODER_CTX_add_extra() trouve les encodeurs qui transforment davantage la sortie des encodeurs déjà ajoutés, et les ajoute également. Ceci est utilisé pour construire des chaînes d'encodeurs.

OSSL_ENCODER_CTX_set_output_type() définit le type de sortie final. Cela doit être spécifié et détermine si une chaîne complète d'encodeurs est disponible.

OSSL_ENCODER_CTX_set_output_structure() définit le type de structure désiré. Cela peut être utilisé pour déterminer quelles implémentations d'encodeurs peuvent être utilisées. Selon le type d'objet à encoder, le type de structure peut ne pas être pertinent.

OSSL_ENCODER_CTX_get_num_encoders() récupère le nombre d'encodeurs actuellement ajoutés au contexte ctx.

OSSL_ENCODER_CTX_set_construct() définit le constructeur construct.

OSSL_ENCODER_CTX_set_construct_data() définit les données du constructeur qui sont passées à chaque appel du constructeur.

OSSL_ENCODER_CTX_set_cleanup() définit les données de nettoyage du constructeur cleanup. Celles-ci sont appelées par OSSL_ENCODER_CTX_free(3).

Constructeur

Un OSSL_ENCODER_CONSTRUCT reçoit les arguments suivants :

encoder_inst
Le OSSL_ENCODER_INSTANCE pour l'encodeur à partir duquel le constructeur obtient ses données.
construct_data
Le pointeur qui a été défini avec OSSL_ENCODE_CTX_set_construct_data().

Le constructeur est censé retourner un pointeur valide (non NULL) vers un objet natif du fournisseur qui peut être utilisé comme entrée d'une chaîne d'encodage, ou NULL s'il y a eu une erreur.

Ces fonctions utilitaires peuvent être utilisées par un constructeur :

OSSL_ENCODER_INSTANCE_get_encoder() peut être utilisée pour obtenir l'implémentation de l'encodeur de l'instanciateur encoder_inst.

OSSL_ENCODER_INSTANCE_get_encoder_ctx() peut être utilisée pour obtenir le contexte du fournisseur de l'implémentation de l'encodeur de l'instanciateur encoder_inst.

OSSL_ENCODER_INSTANCE_get_output_type() peut être utilisée pour obtenir le type de sortie de l'implémentation de l'encodeur de l'instanciateur encoder_inst. Ceci ne sera jamais NULL.

OSSL_ENCODER_INSTANCE_get_output_structure() peut être utilisée pour obtenir le type de structure de sortie de l'implémentation de l'encodeur de l'instanciateur encoder_inst. Ceci peut être NULL.

VALEUR DE RETOUR

OSSL_ENCODER_CTX_new() retourne un pointeur vers un OSSL_ENCODER_CTX, ou NULL si le contexte n'a pas pu être alloué.

OSSL_ENCODER_settable_ctx_params() retourne un tableau de OSSL_PARAM(3), ou NULL s'il n'y en a pas de disponible.

OSSL_ENCODER_CTX_set_params() retourne 1 si tous les paramètres reconnus étaient valides, ou 0 si l'un d'entre eux était invalide ou a causé une erreur dans l'implémentation.

OSSL_ENCODER_CTX_add_encoder(), OSSL_ENCODER_CTX_add_extra(), OSSL_ENCODER_CTX_set_construct(), OSSL_ENCODER_CTX_set_construct_data() et OSSL_ENCODER_CTX_set_cleanup() retournent 1 en cas de succès, ou 0 en cas d'échec.

OSSL_ENCODER_CTX_get_num_encoders() retourne le nombre actuel d'encodeurs. Retourne 0 si ctx est NULL.

OSSL_ENCODER_INSTANCE_get_encoder() retourne un OSSL_ENCODER en cas de succès, ou NULL en cas d'échec.

OSSL_ENCODER_INSTANCE_get_encoder_ctx() retourne un pointeur vers un contexte fournisseur en cas de succès, ou NULL en cas d'échec.

OSSL_ENCODER_INSTANCE_get_output_type() retourne une chaîne avec le nom du type d'entrée, si pertinent. NULL est une valeur valide retournée.

OSSL_ENCODER_INSTANCE_get_output_type() retourne une chaîne avec le nom du type de sortie.

OSSL_ENCODER_INSTANCE_get_output_structure() retourne une chaîne avec le nom du type de structure de sortie.
