OSSL_QUIC_client_method(3ssl)

OSSL_QUIC_CLIENT_METHOD(3ssl) OpenSSL OSSL_QUIC_CLIENT_METHOD(3ssl)

NOM

OSSL_QUIC_client_method, OSSL_QUIC_client_thread_method, OSSL_QUIC_server_method - Fournir des objets SSL_METHOD pour les fonctions activées pour QUIC

SYNTAXE

#include <openssl/quic.h>
const SSL_METHOD *OSSL_QUIC_client_method(void);
const SSL_METHOD *OSSL_QUIC_client_thread_method(void);
const SSL_METHOD *OSSL_QUIC_server_method(void);

DESCRIPTION

Les fonctions OSSL_QUIC_client_method(), OSSL_QUIC_client_thread_method() et OSSL_QUIC_server_method() fournissent des méthodes pour la fonction SSL_CTX_new_ex(3) afin d'offrir le support du protocole QUIC.

La fonction OSSL_QUIC_client_thread_method() utilise des threads pour permettre un mode de fonctionnement bloquant et éviter de devoir redonner le contrôle à la bibliothèque OpenSSL pour le traitement des événements basés sur le temps. La fonction OSSL_QUIC_client_method() n'utilise pas de threads et dépend d'un mode de fonctionnement non bloquant et des appels périodiques aux fonctions SSL par l'application.

La fonction OSSL_QUIC_server_method() fournit le support du protocole QUIC côté serveur et doit être utilisée avec l'API SSL_new_listener(3). Tenter d'utiliser OSSL_QUIC_server_method() avec SSL_new(3) entraînera une erreur.

VALEURS DE RETOUR

Ces fonctions retournent des pointeurs vers les objets méthode constants.

VOIR AUSSI

SSL_CTX_new_ex(3), SSL_new_listener(3)

HISTORIQUE

OSSL_QUIC_client_method() et OSSL_QUIC_client_thread_method() ont été ajoutées dans OpenSSL 3.2.

OSSL_QUIC_server_method() a été ajoutée dans OpenSSL 3.5.
