OCSP_sendreq_new(3ssl)

Paquet: openssl

Licences: Apache-2.0

OCSP_SENDREQ_NEW(3ssl) OpenSSL OCSP_SENDREQ_NEW(3ssl)

NOM

OCSP_REQ_CTX, OCSP_sendreq_new, OCSP_sendreq_nbio, OCSP_sendreq_bio, OCSP_REQ_CTX_i2d, OCSP_REQ_CTX_add1_header, OCSP_REQ_CTX_free, OCSP_set_max_response_length, OCSP_REQ_CTX_set1_req - fonctions de requête de répondeur OCSP

SYNOPSIS

#include <openssl/ocsp.h>
OSSL_HTTP_REQ_CTX *OCSP_sendreq_new(BIO *io, const char *path,
                                    const OCSP_REQUEST *req, int buf_size);
OCSP_RESPONSE *OCSP_sendreq_bio(BIO *io, const char *path, OCSP_REQUEST *req);

Les fonctions suivantes sont dépréciées depuis OpenSSL 3.0, et peuvent être entièrement masquées en définissant OPENSSL_API_COMPAT avec une valeur de version appropriée, voir openssl_user_macros(7):

typedef OSSL_HTTP_REQ_CTX OCSP_REQ_CTX;
int OCSP_sendreq_nbio(OCSP_RESPONSE **presp, OSSL_HTTP_REQ_CTX *rctx);
int OCSP_REQ_CTX_i2d(OCSP_REQ_CT *rctx, const ASN1_ITEM *it, ASN1_VALUE *req);
int OCSP_REQ_CTX_add1_header(OCSP_REQ_CT *rctx,
                             const char *name, const char *value);
void OCSP_REQ_CTX_free(OCSP_REQ_CTX *rctx);
void OCSP_set_max_response_length(OCSP_REQ_CT *rctx, unsigned long len);
int OCSP_REQ_CTX_set1_req(OCSP_REQ_CTX *rctx, const OCSP_REQUEST *req);

DESCRIPTION

Ces fonctions effectuent un transfert de requête/réponse POST OCSP sur HTTP, en utilisant les fonctions de requête HTTP décrites dans OSSL_HTTP_REQ_CTX(3).

La fonction OCSP_sendreq_new() construit une structure OSSL_HTTP_REQ_CTX complète avec le BIO io à utiliser pour les requêtes et réponses, le chemin d'URL path, éventuellement la requête OCSP req, et une longueur maximale de ligne d'en-tête de réponse de buf_size. Si buf_size est zéro, une valeur par défaut de 4 Kio est utilisée. Le req peut être mis à NULL et fourni plus tard en utilisant OCSP_REQ_CTX_set1_req() ou OSSL_HTTP_REQ_CTX(3). Les arguments io et path de OCSP_sendreq_new() correspondent aux composants de l'URL. Par exemple, si l'URL du répondeur est "http://example.com/ocspreq", le BIO io aurait dû être connecté à l'hôte "example.com" sur le port 80 et path devrait être défini sur "/ocspreq".

OCSP_sendreq_nbio() tente d'envoyer la requête préparée dans rctx et de collecter la réponse via HTTP, en utilisant le BIO io et path qui ont été donnés lors de l'appel à OCSP_sendreq_new(). Si l'opération est terminée, elle assigne la réponse, un pointeur vers une structure OCSP_RESPONSE, dans *presp. La fonction peut avoir besoin d'être appelée à nouveau si son résultat est -1, ce qui indique BIO_should_retry(3). Dans un tel cas, il est conseillé de dormir un peu entre les appels, en utilisant BIO_wait(3) sur le BIO de lecture pour éviter une boucle d'interrogation.

OCSP_sendreq_bio() combine OCSP_sendreq_new() avec autant d'appels de OCSP_sendreq_nbio() que nécessaire, puis OCSP_REQ_CTX_free(), avec une longueur maximale de ligne d'en-tête de réponse de 4 Kio. Elle attend indéfiniment une réponse. Elle ne prend pas en charge la définition d'un délai d'attente ou l'ajout d'en-têtes et est conservée pour des raisons de compatibilité ; utilisez plutôt OSSL_HTTP_transfer(3).

OCSP_REQ_CTX_i2d(rctx, it, req) est équivalent à ce qui suit :

OSSL_HTTP_REQ_CTX_set1_req(rctx, "application/ocsp-request", it, req)

OCSP_REQ_CTX_set1_req(rctx, req) est équivalent à ce qui suit :

OSSL_HTTP_REQ_CTX_set1_req(rctx, "application/ocsp-request",
                           ASN1_ITEM_rptr(OCSP_REQUEST),
                           (const ASN1_VALUE *)req)

Le type déprécié et les fonctions dépréciées restantes ont été remplacés par les équivalents suivants : OCSP_REQ_CTX par OSSL_HTTP_REQ_CTX(3), OCSP_REQ_CTX_add1_header() par OSSL_HTTP_REQ_CTX_add1_header(3), OCSP_REQ_CTX_free() par OSSL_HTTP_REQ_CTX_free(3), et OCSP_set_max_response_length() par OSSL_HTTP_REQ_CTX_set_max_response_length(3).

VALEUR DE RETOUR

OCSP_sendreq_new() renvoie une structure OSSL_HTTP_REQ_CTX valide ou NULL si une erreur s'est produite.

OCSP_sendreq_nbio() renvoie 1 en cas de succès, 0 en cas d'erreur, -1 si une nouvelle tentative est nécessaire.

OCSP_sendreq_bio() renvoie la structure OCSP_RESPONSE envoyée par le répondeur ou NULL si une erreur s'est produite.
