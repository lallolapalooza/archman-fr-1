OSSL_DECODER_CTX_NEW_FOR_PKEY(3ssl) OpenSSL OSSL_DECODER_CTX_NEW_FOR_PKEY(3ssl)

NOM

OSSL_DECODER_CTX_new_for_pkey, OSSL_DECODER_CTX_set_passphrase, OSSL_DECODER_CTX_set_pem_password_cb, OSSL_DECODER_CTX_set_passphrase_ui, OSSL_DECODER_CTX_set_passphrase_cb - Routines de décodage pour décoder des EVP_PKEYs

SYNOPSIS

#include <openssl/decoder.h>
OSSL_DECODER_CTX *
OSSL_DECODER_CTX_new_for_pkey(EVP_PKEY **pkey,
                              const char *input_type,
                              const char *input_struct,
                              const char *keytype, int selection,
                              OSSL_LIB_CTX *libctx, const char *propquery);
int OSSL_DECODER_CTX_set_passphrase(OSSL_DECODER_CTX *ctx,
                                    const unsigned char *kstr,
                                    size_t klen);
int OSSL_DECODER_CTX_set_pem_password_cb(OSSL_DECODER_CTX *ctx,
                                         pem_password_cb *cb,
                                         void *cbarg);
int OSSL_DECODER_CTX_set_passphrase_ui(OSSL_DECODER_CTX *ctx,
                                       const UI_METHOD *ui_method,
                                       void *ui_data);
int OSSL_DECODER_CTX_set_passphrase_cb(OSSL_DECODER_CTX *ctx,
                                       OSSL_PASSPHRASE_CALLBACK *cb,
                                       void *cbarg);

DESCRIPTION

OSSL_DECODER_CTX_new_for_pkey() est une fonction utilitaire qui crée un OSSL_DECODER_CTX, trouve toutes les implémentations de décodeur applicables et les configure, de sorte que tout ce que l'appelant doit faire ensuite est d'appeler des fonctions comme OSSL_DECODER_from_bio(3). L'appelant peut utiliser les paramètres optionnels input_type, input_struct, keytype et selection pour spécifier ce que l'entrée est censée contenir. Le paramètre pkey doit référencer une variable EVP_PKEY * qui sera définie sur le EVP_PKEY nouvellement créé lors du décodage réussi. La variable référencée doit être initialisée à NULL avant d'appeler la fonction.

En interne, OSSL_DECODER_CTX_new_for_pkey() recherche toutes les implémentations EVP_KEYMGMT(3) disponibles, puis construit une liste de toutes les implémentations de décodeur potentielles qui peuvent être capables de traiter l'entrée encodée en données adaptées aux EVP_PKEYs. Toutes ces implémentations sont implicitement récupérées en utilisant libctx et propquery.

La recherche des implémentations de décodeur peut être limitée avec input_type et input_struct qui spécifient un type d'entrée et une structure d'entrée de départ. NULL est valide pour les deux et signifie que les implémentations de décodeur découvriront elles-mêmes le type d'entrée. Ils sont définis avec OSSL_DECODER_CTX_set_input_type(3) et OSSL_DECODER_CTX_set_input_structure(3). Voir "Types d'entrée" et "Structures d'entrée" ci-dessous pour plus d'informations.

La recherche des implémentations de décodeur peut également être limitée avec keytype et selection, qui spécifient le type de clé résultant attendu et son contenu. NULL et zéro sont valides et signifient que les implémentations de décodeur découvriront elles-mêmes le type de clé et le contenu de la clé à partir des entrées qu'elles reçoivent.

Si aucune implémentation de décodeur appropriée n'est trouvée, OSSL_DECODER_CTX_new_for_pkey() crée toujours un OSSL_DECODER_CTX, mais sans décodeur associé (OSSL_DECODER_CTX_get_num_decoders(3) renvoie zéro). Cela aide l'appelant à distinguer entre une erreur lors de la création du OSSL_ENCODER_CTX et une implémentation de décodeur manquante, et lui permet d'agir en conséquence.

OSSL_DECODER_CTX_set_passphrase() fournit à l'implémentation une phrase de passe à utiliser lors du déchiffrement de la clé privée encodée. Alternativement, une fonction de rappel pour la phrase de passe peut être spécifiée avec les fonctions suivantes.

OSSL_DECODER_CTX_set_pem_password_cb(), OSSL_DECODER_CTX_set_passphrase_ui() et OSSL_DECODER_CTX_set_passphrase_cb() configurent une méthode de rappel que l'implémentation peut utiliser pour demander une phrase de passe, donnant à l'appelant le choix de la forme préférée de la fonction de rappel pour la phrase de passe. Celles-ci sont appelées indirectement, via une fonction interne OSSL_PASSPHRASE_CALLBACK(3).

La fonction interne OSSL_PASSPHRASE_CALLBACK(3) met en cache la phrase de passe, pour être réutilisée dans tous les décodages effectués dans la même exécution de décodage (par exemple, dans un seul appel à OSSL_DECODER_from_bio(3)).

Types d'entrée

Les types d'entrée disponibles dépendent des implémentations que les fournisseurs disponibles proposent, et la documentation du fournisseur devrait fournir les détails.

Parmi les types d'entrée connus que les implémentations de décodeur OpenSSL offrent pour les EVP_PKEYs figurent "DER", "PEM", "MSBLOB" et "PVK". Voir openssl-glossary(7) pour plus d'informations sur ce que signifient ces types d'entrée.

Structures d'entrée

Les structures d'entrée disponibles dépendent des implémentations que les fournisseurs disponibles proposent, et la documentation du fournisseur devrait fournir les détails.

Parmi les structures d'entrée connues que les implémentations de décodeur OpenSSL offrent pour les EVP_PKEYs figurent "pkcs8" et "SubjectPublicKeyInfo".

Les implémentations de décodeur OpenSSL prennent également en charge la structure d'entrée "type-specific". C'est la structure utilisée pour les clés encodées selon des spécifications spécifiques au type de clé. Par exemple, les clés RSA encodées selon PKCS#1.

Sélections

selection peut être l'une des valeurs décrites dans "Selections" dans EVP_PKEY_fromdata(3). De plus, selection peut également être défini à 0 pour indiquer que le code détectera automatiquement la sélection.

VALEURS DE RETOUR

OSSL_DECODER_CTX_new_for_pkey() renvoie un pointeur vers un OSSL_DECODER_CTX, ou NULL s'il n'a pas pu être créé.

OSSL_DECODER_CTX_set_passphrase(), OSSL_DECODER_CTX_set_pem_password_cb(), OSSL_DECODER_CTX_set_passphrase_ui() et OSSL_DECODER_CTX_set_passphrase_cb() renvoient tous 1 en cas de succès, ou 0 en cas d'échec.

OSSL_DECODER_CTX_new_for_pkey(3ssl)

Nom

OSSL_DECODER_CTX_new_for_pkey
OSSL_DECODER_CTX_new_for_pkey - Crée un nouveau contexte de décodeur pour une clé publique.

Synopsis

#include <openssl/decoder.h>
OSSL_DECODER_CTX *OSSL_DECODER_CTX_new_for_pkey(OSSL_DECODER_CTX *ctx, const OSSL_PROVIDER *provider, const char *propq);

Description

OSSL_DECODER_CTX_new_for_pkey() crée un nouveau contexte de décodeur qui est configuré pour la sélection et le chargement de décodeurs de clés publiques.
Le paramètre ctx peut être utilisé pour passer un contexte existant. Si ctx est NULL, un nouveau contexte est alloué.
Le paramètre provider spécifie le fournisseur à utiliser. S'il est NULL, le fournisseur par défaut est utilisé.
Le paramètre propq spécifie la chaîne de propriétés à utiliser pour la sélection des décodeurs.
La fonction renvoie un pointeur vers le nouveau contexte de décodeur, ou NULL en cas d'échec.

Valeurs de retour

OSSL_DECODER_CTX *
Un pointeur vers le nouveau contexte de décodeur, ou NULL en cas d'échec.
