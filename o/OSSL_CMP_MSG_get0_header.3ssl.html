NOM

OSSL_CMP_MSG_get0_header, OSSL_CMP_MSG_get_bodytype, OSSL_CMP_MSG_get0_certreq_publickey, OSSL_CMP_MSG_update_transactionID, OSSL_CMP_MSG_update_recipNonce, OSSL_CMP_CTX_setup_CRM, OSSL_CMP_MSG_read, OSSL_CMP_MSG_write, d2i_OSSL_CMP_MSG_bio, i2d_OSSL_CMP_MSG_bio - fonction(s) manipulant les messages CMP

SYNOPSIS

#include <openssl/cmp.h>
OSSL_CMP_PKIHEADER *OSSL_CMP_MSG_get0_header(const OSSL_CMP_MSG *msg);
int OSSL_CMP_MSG_get_bodytype(const OSSL_CMP_MSG *msg);
X509_PUBKEY *OSSL_CMP_MSG_get0_certreq_publickey(const OSSL_CMP_MSG *msg);
int OSSL_CMP_MSG_update_transactionID(OSSL_CMP_CTX *ctx, OSSL_CMP_MSG *msg);
int OSSL_CMP_MSG_update_recipNonce(OSSL_CMP_CTX *ctx, OSSL_CMP_MSG *msg);
OSSL_CRMF_MSG *OSSL_CMP_CTX_setup_CRM(OSSL_CMP_CTX *ctx, int for_KUR, int rid);
OSSL_CMP_MSG *OSSL_CMP_MSG_read(const char *file, OSSL_LIB_CTX *libctx, const char *propq);
int OSSL_CMP_MSG_write(const char *file, const OSSL_CMP_MSG *msg);
OSSL_CMP_MSG *d2i_OSSL_CMP_MSG_bio(BIO *bio, OSSL_CMP_MSG **msg);
int i2d_OSSL_CMP_MSG_bio(BIO *bio, const OSSL_CMP_MSG *msg);

DESCRIPTION

OSSL_CMP_MSG_get0_header() retourne l'en-tête du message CMP donné.

OSSL_CMP_MSG_get_bodytype() retourne le type de corps du message CMP donné.

OSSL_CMP_MSG_get0_certreq_publickey() s'attend à ce que msg soit un message de demande de certificat et retourne la clé publique dans son modèle de certificat s'il est présent.

OSSL_CMP_MSG_update_transactionID() met à jour le champ transactionID dans l'en-tête du message donné conformément au CMP_CTX. Si ctx ne contient pas d'ID de transaction, un nouvel ID est créé au préalable. Le message est re-protégé (si la protection des requêtes est requise).

OSSL_CMP_MSG_update_recipNonce() met à jour le champ recipNonce dans l'en-tête du message donné conformément au CMP_CTX. Le message est re-protégé (si la protection des requêtes est requise).

OSSL_CMP_CTX_setup_CRM() crée un message de demande de certificat CRMF à partir de diverses informations fournies dans l'argument de contexte CMP ctx pour inclusion dans un message de requête CMP basé sur les détails contenus dans ctx. L'argument rid définit l'identifiant de requête à utiliser, qui est généralement 0.

Le nom distinctif du sujet inclus dans le modèle de certificat est la première valeur disponible parmi celles-ci :

n'importe quel nom de sujet dans ctx défini via OSSL_CMP_CTX_set1_subjectName(3) - s'il s'agit du NULL-DN (c'est-à-dire une séquence vide de RDN), aucun sujet n'est inclus,
le champ sujet de tout CSR PKCS#10 défini dans ctx via OSSL_CMP_CTX_set1_p10CSR(3),
le champ sujet de tout certificat de référence donné dans ctx (voir OSSL_CMP_CTX_set1_oldCert(3)), mais seulement si for_KUR est non nul ou si le ctx n'inclut pas de nom alternatif du sujet.

La clé publique incluse est la première valeur disponible parmi celles-ci :

la clé publique dérivée de toute clé définie via OSSL_CMP_CTX_set0_newPkey(3),
la clé publique de tout CSR PKCS#10 donné dans ctx,
la clé publique de tout certificat de référence donné dans ctx (voir OSSL_CMP_CTX_set1_oldCert(3)),
la clé publique dérivée de la clé privée de tout client définie via OSSL_CMP_CTX_set1_pkey(3).

L'ensemble des extensions X.509 à inclure est calculé comme suit. Si un CSR PKCS#10 est présent dans ctx, les extensions par défaut en sont tirées, sinon l'ensemble vide est pris comme valeur initiale. S'il y a un certificat de référence dans ctx et qu'il contient des noms alternatifs du sujet (SAN) et que OSSL_CMP_OPT_SUBJECTALTNAME_NODEFAULT n'est pas défini, ceux-ci remplacent tout SAN du CSR PKCS#10. Les extensions sont en outre augmentées ou remplacées par toute extension avec les mêmes OID incluse dans ctx via OSSL_CMP_CTX_set0_reqExtensions(3). Les SAN sont en outre remplacés par tout SAN inclus dans ctx via OSSL_CMP_CTX_push1_subjectAltName(3). Enfin, les politiques sont remplacées par toute politique incluse dans ctx via OSSL_CMP_CTX_push0_policy(3).

OSSL_CMP_CTX_setup_CRM() définit également le contrôle regToken oldCertID pour les messages KUR en utilisant le nom de l'émetteur et le numéro de série du certificat de référence, s'il est présent.

OSSL_CMP_MSG_read() charge un OSSL_CMP_MSG codé en DER depuis file.

OSSL_CMP_MSG_write() enregistre l'OSSL_CMP_MSG donné dans file en encodage DER.

d2i_OSSL_CMP_MSG_bio() analyse un OSSL_CMP_MSG encodé en ASN.1 à partir du BIO bio. Il attribue un pointeur vers la nouvelle structure à *msg si msg n'est pas NULL.

i2d_OSSL_CMP_MSG_bio() écrit l'OSSL_CMP_MSG msg en encodage ASN.1 dans le BIO bio.

NOTES

CMP est défini dans la RFC 4210.

VALEUR DE RETOUR

OSSL_CMP_MSG_get0_header() retourne le pointeur prévu tel que décrit ci-dessus ou NULL si l'entrée correspondante n'existe pas et en cas d'erreur.

OSSL_CMP_MSG_get_bodytype() retourne le type de corps ou -1 en cas d'erreur.

OSSL_CMP_MSG_get0_certreq_publickey() retourne une clé publique ou NULL en cas d'erreur.

OSSL_CMP_CTX_setup_CRM() retourne un pointeur vers un OSSL_CRMF_MSG en cas de succès, NULL en cas d'erreur.

d2i_OSSL_CMP_MSG_bio() retourne le message analysé ou NULL en cas d'erreur.

OSSL_CMP_MSG_read() et d2i_OSSL_CMP_MSG_bio() retournent le message CMP analysé ou NULL en cas d'erreur.

OSSL_CMP_MSG_write() retourne le nombre d'octets encodés avec succès ou une valeur négative en cas d'erreur.

i2d_OSSL_CMP_MSG_bio(), OSSL_CMP_MSG_update_transactionID(), et OSSL_CMP_MSG_update_recipNonce() retournent 1 en cas de succès, 0 en cas d'erreur.

OSSL_CMP_MSG_get0_header(3ssl)

NAME

OSSL_CMP_MSG_get0_header - Récupère l'en-tête d'un message CMP. (Not available in the current release.)

SYNOPSIS

#include <openssl/cmp.h>
OSSL_CMP_MSG_HEADER *OSSL_CMP_MSG_get0_header(const OSSL_CMP_MSG *msg);

DESCRIPTION

La fonction OSSL_CMP_MSG_get0_header() récupère l'en-tête du message CMP du paramètre msg.

La valeur de retour est un pointeur vers un OSSL_CMP_MSG_HEADER, ou NULL si msg est NULL ou si le message msg ne contient pas d'en-tête valide.

Le pointeur retourné est valide tant que msg est valide et que la structure OSSL_CMP_MSG n'est pas modifiée.

NOTES

Cette fonction n'est pas encore disponible dans la version actuelle.

RETURN VALUES

La fonction OSSL_CMP_MSG_get0_header() retourne un pointeur vers l'en-tête du message CMP s'il réussit, et NULL en cas d'échec.

SEE ALSO

OSSL_CMP_MSG_new(3ssl), OSSL_CMP_MSG_free(3ssl).

HISTORY

La fonction OSSL_CMP_MSG_get0_header() a été ajoutée dans OpenSSL 3.2.
