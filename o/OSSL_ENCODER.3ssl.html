OSSL_ENCODER(3ssl) OpenSSL OSSL_ENCODER(3ssl)

NOM

OSSL_ENCODER, OSSL_ENCODER_fetch, OSSL_ENCODER_up_ref, OSSL_ENCODER_free, OSSL_ENCODER_get0_provider, OSSL_ENCODER_get0_properties, OSSL_ENCODER_is_a, OSSL_ENCODER_get0_name, OSSL_ENCODER_get0_description, OSSL_ENCODER_do_all_provided, OSSL_ENCODER_names_do_all, OSSL_ENCODER_gettable_params, OSSL_ENCODER_get_params - Routines de méthodes d'encodeur

SYNOPIS

#include <openssl/encoder.h>
typedef struct ossl_encoder_st OSSL_ENCODER;
OSSL_ENCODER *OSSL_ENCODER_fetch(OSSL_LIB_CTX *ctx, const char *name,
                                 const char *properties);
int OSSL_ENCODER_up_ref(OSSL_ENCODER *encoder);
void OSSL_ENCODER_free(OSSL_ENCODER *encoder);
const OSSL_PROVIDER *OSSL_ENCODER_get0_provider(const OSSL_ENCODER *encoder);
const char *OSSL_ENCODER_get0_properties(const OSSL_ENCODER *encoder);
int OSSL_ENCODER_is_a(const OSSL_ENCODER *encoder, const char *name);
const char *OSSL_ENCODER_get0_name(const OSSL_ENCODER *encoder);
const char *OSSL_ENCODER_get0_description(const OSSL_ENCODER *encoder);
void OSSL_ENCODER_do_all_provided(OSSL_LIB_CTX *libctx,
                                  void (*fn)(OSSL_ENCODER *encoder, void *arg),
                                  void *arg);
int OSSL_ENCODER_names_do_all(const OSSL_ENCODER *encoder,
                              void (*fn)(const char *name, void *data),
                              void *data);
const OSSL_PARAM *OSSL_ENCODER_gettable_params(OSSL_ENCODER *encoder);
int OSSL_ENCODER_get_params(OSSL_ENCODER_CTX *ctx, const OSSL_PARAM params[]);

DESCRIPTION

OSSL_ENCODER est une méthode pour les encodeurs, qui savent comment encoder un objet d'un certain type dans une forme encodée, comme PEM, DER, ou même du texte lisible par l'homme.

OSSL_ENCODER_fetch() recherche un algorithme au sein du fournisseur qui a été chargé dans le OSSL_LIB_CTX donné par ctx, ayant le nom donné par name et les propriétés données par properties. Le name détermine le type d'objet que la méthode d'encodeur récupérée est censée pouvoir encoder, et les propriétés sont utilisées pour déterminer le type de sortie attendu. Pour les propriétés connues et les valeurs qu'elles peuvent avoir, veuillez consulter "Noms et propriétés" dans provider-encoder(7).

OSSL_ENCODER_up_ref() incrémente le compteur de références pour le encoder donné.

OSSL_ENCODER_free() décrémente le compteur de références pour le encoder donné, et lorsque le compteur atteint zéro, le libère. Si l'argument est NULL, rien n'est fait.

OSSL_ENCODER_get0_provider() retourne le fournisseur du encoder donné.

OSSL_ENCODER_get0_properties() retourne la définition de propriété associée au encoder donné.

OSSL_ENCODER_is_a() vérifie si encoder est une implémentation d'un algorithme identifiable par name.

OSSL_ENCODER_get0_name() retourne le nom utilisé pour récupérer le encoder donné.

OSSL_ENCODER_get0_description() retourne une description du loader, destinée à l'affichage et à la consommation humaine. La description est à la discrétion de l'implémentation du loader.

OSSL_ENCODER_names_do_all() parcourt tous les noms du encoder donné, et appelle fn avec chaque nom et data comme arguments.

OSSL_ENCODER_do_all_provided() parcourt toutes les implémentations d'encodeurs par tous les fournisseurs activés dans le contexte de bibliothèque libctx, et pour chacune des implémentations, appelle fn avec la méthode d'implémentation et arg comme arguments.

OSSL_ENCODER_gettable_params() retourne un tableau OSSL_PARAM(3) de descripteurs de paramètres.

OSSL_ENCODER_get_params() tente de récupérer les paramètres spécifiés avec un tableau OSSL_PARAM(3) params. Les paramètres que l'implémentation ne reconnaît pas doivent être ignorés.

VALEUR DE RETOUR

OSSL_ENCODER_fetch() retourne un pointeur vers l'implémentation de gestion de clés représentée par un objet OSSL_ENCODER, ou NULL en cas d'erreur.

OSSL_ENCODER_up_ref() retourne 1 en cas de succès, ou 0 en cas d'erreur.

OSSL_ENCODER_free() ne retourne aucune valeur.

OSSL_ENCODER_get0_provider() retourne un pointeur vers un objet fournisseur, ou NULL en cas d'erreur.

OSSL_ENCODER_get0_properties() retourne un pointeur vers une chaîne de définition de propriétés, ou NULL en cas d'erreur.

OSSL_ENCODER_is_a() retourne 1 si encoder était identifiable, sinon 0.

OSSL_ENCODER_get0_name() retourne le nom de l'algorithme provenant de l'implémentation fournie pour le encoder donné. Notez que le encoder peut avoir plusieurs synonymes associés. Dans ce cas, le premier nom de la définition de l'algorithme est retourné. La propriété de la chaîne retournée est conservée par l'objet encoder et ne doit pas être libérée par l'appelant.

OSSL_ENCODER_get0_description() retourne un pointeur vers une description, ou NULL s'il n'y en a pas.

OSSL_ENCODER_names_do_all() retourne 1 si la fonction de rappel a été appelée pour tous les noms. Une valeur de retour de 0 signifie que la fonction de rappel n'a été appelée pour aucun nom.
