Object::Accessor(3) Documentation Perl fournie par l'utilisateur Object::Accessor(3)

NOM

Object::Accessor - interface pour créer des accesseurs par objet

SYNTAXE

### utilisation de l'objet
$obj = Object::Accessor->new;        # créer un objet
$obj = Object::Accessor->new(@list); # créer un objet avec des accesseurs
$obj = Object::Accessor->new(\%h);   # créer un objet avec des accesseurs
                                     # et leurs gestionnaires d'autorisation
$bool   = $obj->mk_accessors('foo'); # créer des accesseurs
$bool   = $obj->mk_accessors(        # créer des accesseurs avec validation
           {foo => GESTIONNAIRE_AUTORISATION} ); # d'entrée
$bool   = $obj->mk_aliases(          # créer un alias vers une méthode
            nom_alias => 'méthode'); # existante
$clone  = $obj->mk_clone;            # créer une copie de l'objet original
                                     # sans données
$bool   = $obj->mk_flush;            # effacer toutes les données
@list   = $obj->ls_accessors;        # récupère une liste de tous
                                     # les accesseurs de cet objet
$bar    = $obj->foo('bar');          # définir 'foo' à 'bar'
$bar    = $obj->foo();               # récupérer à nouveau 'bar'
$sub    = $obj->can('foo');          # récupérer le coderef pour
                                     # l'accesseur 'foo'
$bar    = $sub->('bar');             # définir 'foo' via coderef
$bar    = $sub->();                  # récupérer 'bar' par coderef
### utilisation de l'objet comme classe de base
package Ma::Classe;
use base 'Object::Accessor';
$obj    = Ma::Classe->new;               # créer un objet de base
$bool   = $obj->mk_accessors('foo');    # créer des accesseurs, etc...
### rendre fatale toute tentative d'accès à des accesseurs inexistants
### (par défaut à false)
$Object::Accessor::FATAL = 1;
### activer le débogage
$Object::Accessor::DEBUG = 1;
### utilisation avancée -- rappels (callbacks)
{   my $obj = Object::Accessor->new('foo');
    $obj->register_callback( sub { ... } );
    $obj->foo( 1 ); # ces appels invoquent le rappel que vous avez enregistré
    $obj->foo()     # qui vous permet de modifier le comportement
                    # get/set et ce qui est retourné à l'appelant.
}
### utilisation avancée -- attributs lvaleur
{   my $obj = Object::Accessor::Lvalue->new('foo');
    print $obj->foo = 1;            # affichera 1
}
### utilisation avancée -- valeurs d'attributs limitées à la portée
{   my $obj = Object::Accessor->new('foo');
    $obj->foo( 1 );
    print $obj->foo;                # affichera 1
    ### lier la portée de la valeur de l'attribut 'foo'
    ### à la portée de '$x' -- lorsque $x sortira de
    ### la portée, la valeur précédente de 'foo' sera restaurée
    {   $obj->foo( 2 => \my $x );
        print $obj->foo, ' ', $x;   # affichera '2 2'
    }
    print $obj->foo;                # affichera 1
}

DESCRIPTION

"Object::Accessor" fournit une interface pour créer des accesseurs par objet (par opposition aux accesseurs par "Classe", comme, par exemple, "Class::Accessor" en fournit).

Vous pouvez choisir soit d'hériter de ce module, et donc d'utiliser ses accesseurs dans votre propre module, soit de stocker un objet "Object::Accessor" à l'intérieur de votre propre objet, et d'accéder aux accesseurs à partir de là. Voir la "SYNTAXE" pour des exemples.

MÉTHODES

$objet = Object::Accessor->new( [ARGS] );

Crée un nouvel objet (et vide) "Object::Accessor". Cette méthode est héritable.

Tous les arguments donnés à "new" sont passés directement à "mk_accessors".

Si vous souhaitez pouvoir assigner à vos accesseurs comme s'ils étaient des "lvalues", vous devriez plutôt créer votre objet dans le namespace "Object::Accessor::Lvalue". Voir la section sur les "ACCESSEURS LVALUE" ci-dessous.

$bool = $objet->mk_accessors( @ACCESSEURS | \%MAP_ACCESSEURS );

Crée une liste d'accesseurs pour cet objet (et "PAS" pour les autres de la même classe !). Ne corrompra pas les données existantes, donc si un accesseur existe déjà, demander de le recréer est effectivement un "no-op".

Lorsque vous fournissez une "hashref" en argument, plutôt qu'une liste normale, vous pouvez spécifier une liste de paires clé/valeur d'accesseurs et de leurs validateurs d'entrée respectifs. Les validateurs peuvent être tout ce que la fonction "allow" de "Params::Check" accepte. Veuillez consulter sa page de manuel pour plus de détails.

Par exemple :

$objet->mk_accessors( {
    foo     => qr/^\d+$/,       # seulement des chiffres
    bar     => [0,1],           # booléens
    zot     => \&ma_sub         # une sous-routine de vérification personnalisée
} );

Retourne vrai en cas de succès, faux en cas d'échec.

Les accesseurs qui sont appelés sur un objet, et qui n'existent pas, retournent "undef" par défaut, mais vous pouvez en faire une erreur fatale en définissant la variable globale $FATAL à vrai. Voir la section sur les "VARIABLES GLOBALLES" pour les détails.

Notez que vous pouvez lier les valeurs des attributs à une portée. Cela vous permet de changer "temporairement" la valeur d'un attribut, et de faire restaurer sa valeur originale à la fin de la portée de sa variable liée ;

Par exemple, dans cet extrait de code, l'attribut "foo" sera temporairement défini à 2, jusqu'à la fin de la portée de $x, moment auquel la valeur originale de 1 sera restaurée.

my $obj = Object::Accessor->new;
$obj->mk_accessors('foo');
$obj->foo( 1 );
print $obj->foo;                # affichera 1
### lier la portée de la valeur de l'attribut 'foo'
### à la portée de '$x' -- lorsque $x sortira de
### la portée, la valeur précédente de 'foo' sera restaurée
{   $obj->foo( 2 => \my $x );
    print $obj->foo, ' ', $x;   # affichera '2 2'
}
print $obj->foo;                # affichera 1

Notez que tous les accesseurs sont en lecture/écriture pour tout le monde. Voir la section "TODO" pour les détails.

@liste = $self->ls_accessors;

Retourne une liste d'accesseurs supportés par l'objet actuel. Les coderefs correspondants peuvent être récupérés en passant cette liste un par un à la méthode "can".

$ref = $self->ls_allow(CLEF)

Retourne le gestionnaire d'autorisation pour la clé donnée, qui peut être utilisé avec le gestionnaire allow() de "Params::Check". S'il n'y avait pas de gestionnaire d'autorisation spécifié, un gestionnaire d'autorisation qui retourne toujours vrai sera retourné.

$bool = $self->mk_aliases( alias => méthode, [alias2 => méthode2, ...] );

Crée un alias pour un nom de méthode donné. À toutes fins utiles, ces deux accesseurs sont maintenant identiques pour cet objet. Ceci est similaire à faire ceci au niveau de la table des symboles :

*alias = *method

Cela vous permet de faire ce qui suit :

$self->mk_accessors('foo');
$self->mk_aliases( bar => 'foo' );
$self->bar( 42 );
print $self->foo;     # affichera 42

$clone = $self->mk_clone;

Crée une copie de l'objet actuel, qui aura exactement les mêmes accesseurs que l'objet actuel, mais sans les données qui y sont stockées.

$bool = $self->mk_flush;

Efface toutes les données de l'objet actuel ; tous les accesseurs seront remis dans leur état par défaut de "undef".

Retourne vrai en cas de succès et faux en cas d'échec.

$bool = $self->mk_verify;

Vérifie si toutes les valeurs de l'objet actuel sont conformes

NOM

Object::Accessor - Méthodes d'accesseur

SYNOPIS

use Object::Accessor;

Ce module fournit des méthodes d'accesseur pour les objets.

DESCRIPTION

Object::Accessor fournit des méthodes pour accéder et modifier les attributs d'un objet. Ces méthodes vous permettent de créer des accesseurs personnalisés qui peuvent être utilisés pour contrôler la façon dont les attributs sont accédés et modifiés.

MÉTHODES

Les méthodes suivantes sont disponibles :

  • register_callback(subroutine): Enregistre un rappel qui est appelé chaque fois qu'un accesseur est appelé.

  • can(METHOD_NAME): Remplace UNIVERSAL::can pour fournir des coderefs aux accesseurs chargés à la demande. Retourne une méthode de classe si elle existe, ou une fermeture pointant vers un accesseur valide de cet objet particulier.

  • ___get(METHOD_NAME): Accède directement à la valeur de l'accesseur donné dans l'objet. Contourne tous les appels pour permettre les vérifications, les rappels, etc.

  • ___set(METHOD_NAME => VALUE): Définit directement la valeur de l'accesseur donné dans l'objet. Contourne tous les appels pour permettre les vérifications, les rappels, etc.

  • ___alias(ALIAS => METHOD): Crée directement un alias d'un accesseur à un autre pour cet objet. Contourne toutes les vérifications de cohérence, etc.

ACCESSEURS LVALUE

Object::Accessor prend également en charge les attributs lvalue. Pour les activer, créez vos objets dans l'espace de noms désigné, Object::Accessor::Lvalue. Par exemple :

my $obj = Object::Accessor::Lvalue->new('foo');
$obj->foo += 1;
print $obj->foo;

imprimera réellement 1 et fonctionnera comme prévu. Comme il s'agit d'une fonctionnalité facultative, elle n'est pas souhaitable dans tous les cas, vous devez donc utiliser explicitement la classe Object::Accessor::Lvalue.

Faire la même chose sur la classe standard Object::Accessor générerait le code et les erreurs suivants :

my $obj = Object::Accessor->new('foo');
$obj->foo += 1;
Can't modify non-lvalue subroutine call

Notez que le support lvalue sur les routines AUTOLOAD est une fonctionnalité de perl 5.8.x. Voir perldoc perl58delta pour plus de détails.

AVERTISSEMENTS

  • Gestionnaires d'autorisation

    En raison de la nature des sous-programmes lvalue, nous n'avons jamais accès à la valeur que vous assignez, nous ne pouvons donc pas la vérifier par rapport à votre gestionnaire d'autorisation. Les gestionnaires d'autorisation ne sont donc pas pris en charge dans les conditions lvalue.

    Voir perldoc perlsub pour plus de détails.

  • Rappels

    En raison de la nature des sous-programmes lvalue, nous n'avons jamais accès à la valeur que vous assignez, nous ne pouvons donc pas la fournir à votre rappel. De plus, nous ne pouvons pas distinguer un appel get d'un appel set. Les rappels ne sont donc pas pris en charge dans les conditions lvalue.

    Voir perldoc perlsub pour plus de détails.

VARIABLES GLOBALES

$Object::Accessor::FATAL

Définissez cette variable à vrai pour que toutes les tentatives d'accès à des accesseurs inexistants soient fatales. La valeur par défaut est faux.

$Object::Accessor::DEBUG

Définissez cette variable pour activer la sortie de débogage. La valeur par défaut est faux.

À FAIRE

Créer des accesseurs en lecture seule

Actuellement, tous les accesseurs sont en lecture/écriture pour tout le monde. Peut-être qu'une future version permettra d'avoir des accesseurs en lecture seule également.

AVERTISSEMENTS

Si vous utilisez des références de code pour vos gestionnaires d'autorisation, vous ne pourrez pas "figer" les structures de données en utilisant Storable.

En raison d'un bug dans storable (au moins jusqu'à la version 2.15), les expressions régulières compilées qr// ne se désérialisent pas non plus correctement. Bien que ce bug ait été signalé, vous devez être conscient de ce problème lors de la sérialisation de vos objets.

Vous pouvez suivre le bug ici :

http://rt.cpan.org/Ticket/Display.html?id=1827
