#include <openssl/objects.h>
ASN1_OBJECT *OBJ_nid2obj(int n);

int OBJ_sn2nid(const char *sn);
int OBJ_txt2nid(const char *s);
ASN1_OBJECT *OBJ_txt2obj(const char *s, int no_name);
int OBJ_obj2txt(char *buf, int buf_len, const ASN1_OBJECT *a, int no_name);
int i2t_ASN1_OBJECT(char *buf, int buf_len, const ASN1_OBJECT *a);
int OBJ_cmp(const ASN1_OBJECT *a, const ASN1_OBJECT *b);
ASN1_OBJECT *OBJ_dup(const ASN1_OBJECT *o);
int OBJ_create(const char *oid, const char *sn, const char *ln);
size_t OBJ_length(const ASN1_OBJECT *obj);

Les fonctions suivantes sont obsolètes depuis OpenSSL 1.1.0 et peuvent être complètement masquées en définissant OPENSSL_API_COMPAT avec une valeur appropriée, voir openssl_user_macros(7).

void OBJ_cleanup(void);

DESCRIPTION

Les fonctions utilitaires pour les structures ASN1_OBJECT traitent les structures ASN1_OBJECT qui représentent le type ASN1_OBJECT IDENTIFIER (OID). Pour plus de commodité, les OID sont généralement représentés par des identifiants numériques ou NID. OpenSSL possède une table interne d'OID générés au moment de la construction de la bibliothèque, et leurs NID correspondants sont disponibles sous forme de constantes définies. Pour les fonctions suivantes, le code applicatif doit traiter toutes les valeurs retournées — OID, NID ou noms — comme des constantes.

OBJ_nid2obj(), OBJ_nid2ln() et OBJ_nid2sn() convertissent le NID n en une structure ASN1_OBJECT, son nom long et son nom court, ou NULL si une erreur s'est produite.

OBJ_obj2nid(), OBJ_ln2nid(), OBJ_sn2nid() et OBJ_txt2nid() retournent le NID correspondant pour l'objet o, le nom long ln ou le nom court sn, ou NID_undef en cas d'erreur.

OBJ_txt2nid() retourne le NID correspondant à la chaîne de texte s. s peut être un nom long, un nom court ou la représentation numérique d'un objet.

OBJ_txt2obj() convertit la chaîne de texte s en une structure ASN1_OBJECT. Si no_name est 0, les noms longs et courts ainsi que les formes numériques sont interprétés. Si no_name est 1, seule la forme numérique est acceptée.

OBJ_obj2txt() convertit la structure ASN1_OBJECT a en une représentation textuelle. Le nom buf n'est pas utilisé si est NULL, la représentation est écrite comme une chaîne terminée par NUL dans buf, où jusqu'à buf_len octets sont écrits, tronquant le résultat si nécessaire. Dans tous les cas, elle retourne la longueur totale de la chaîne, sans le caractère NUL, requise pour une représentation non tronquée, ou -1 en cas d'erreur. Si no_name est 0, si l'objet a un nom long ou court, ce nom sera utilisé, sinon la forme numérique sera utilisée. Si no_name est 1, la forme numérique sera toujours utilisée.

i2t_ASN1_OBJECT() est identique à OBJ_obj2txt() avec no_name défini à zéro.

OBJ_cmp() compare a et b. S'ils sont égaux, retourne 0.

OBJ_dup() retourne une copie de o.

OBJ_create() ajoute un nouvel objet à la table interne. oid est la forme numérique de l'objet, sn le nom court et ln le nom long. En cas de succès, un nouveau NID est retourné pour l'objet créé, et NID_undef en cas d'erreur. N'importe lequel des oid, sn ou ln peut être NULL, mais pas tous en même temps.

OBJ_length() retourne la taille en octets des contenus de obj.

OBJ_get0_data() retourne un pointeur vers les contenus en octets de obj. Le pointeur retourné est un pointeur interne qui ne doit pas être libéré.

OBJ_add_sigid() crée un nouveau composite « Signature Algorithm » qui associe un NID à deux autres NID — l'un représentant l'algorithme de signature sous-jacent et l'autre représentant un algorithme de hachage à utiliser conjointement avec celui-ci. signid représente le NID pour le composite « Signature Algorithm », dig_id est le NID pour l'algorithme de hachage et pkey_id est le NID pour l'algorithme de signature sous-jacent. Comme il existe des algorithmes de signature qui ne nécessitent pas de hachage, NID_undef est valide comme dig_id.

OBJ_cleanup() libère les ressources allouées lors de la création de nouveaux objets.

NOTES

Les objets OpenSSL peuvent avoir un nom court, un nom long et un identifiant numérique (NID) associé. Un ensemble standard d'objets est représenté dans une table interne. Les valeurs appropriées sont définies dans le fichier d'en-tête objects.h.

Par exemple, l'OID pour commonName a les définitions suivantes :

#define SN_commonName                   "CN"
#define LN_commonName                   "commonName"
#define NID_commonName                  13

De nouveaux objets peuvent être ajoutés en appelant OBJ_create().

Les objets de table ont certains avantages par rapport aux autres objets : par exemple, leurs NID peuvent être utilisés dans une instruction C switch. Ce sont également des structures statiques constantes partagées : c'est-à-dire qu'il n'y a qu'une seule structure constante pour chaque objet de table.

Les objets qui ne sont pas dans la table ont la valeur NID_undef.

Les objets n'ont pas besoin d'être dans les tables internes pour être traités, les fonctions OBJ_txt2obj() et OBJ_obj2txt() peuvent traiter la forme numérique d'un OID.

Certains objets sont utilisés pour représenter des algorithmes qui n'ont pas de codage OBJECT IDENTIFIER correspondant (par exemple, il n'existe actuellement pas d'OID pour un algorithme particulier). Par conséquent, ils ne peuvent pas être encodés ou décodés dans le cadre de structures ASN.1. Les applications peuvent déterminer s'il existe une correspondance OBJECT IDENTIFIER en appelant OBJ_length() et en vérifiant qu'elle n'est pas nulle.

Ces fonctions ne peuvent pas retourner const car un ASN1_OBJECT peut représenter à la fois un OID interne constant et un OID créé dynamiquement. Ce dernier ne peut pas être constant car il doit être libéré après utilisation.

Ces fonctions n'étaient pas sûres dans OpenSSL 3.0 et versions antérieures.

VALEURS DE RETOUR

OBJ_nid2obj() retourne une structure ASN1_OBJECT ou NULL en cas d'erreur.

OBJ_nid2ln() et OBJ_nid2sn() retournent une chaîne valide ou NULL en cas d'erreur.

OBJ_obj2nid(), OBJ_ln2nid(), OBJ_sn2nid() et OBJ_txt2nid() retournent un NID ou NID_undef en cas d'erreur.

OBJ_add_sigid() retourne 1 en cas de succès ou 0 en cas d'erreur.

i2t_ASN1_OBJECT() retourne -1 en cas d'erreur, et retourne la longueur de la chaîne écrite dans buf si buf n'est pas NULL et buf_len est suffisamment grand, sinon elle retourne la longueur totale de la chaîne. Note : ceci ne compte pas le caractère NUL final.

EXEMPLES

Créer un objet pour commonName :

ASN1_OBJECT *o = OBJ_nid2obj(NID_commonName);

Vérifier si un objet est commonName

if (OBJ_obj2nid(obj) == NID_commonName)
    /* Faire quelque chose */

Créer un nouveau NID et initialiser un objet à partir de celui-ci :

int new_nid = OBJ_create("1.2.3.4", "NewOID", "New Object Identifier");
ASN1_OBJECT *obj = OBJ_nid2obj(new_nid);

Créer un objet directement :

obj = OBJ_txt2obj("1.2.3.4", 1);

NAME

OBJ_nid2obj, OBJ_obj2nid, OBJ_nid2ln, OBJ_ln2nid, OBJ_txt2nid, OBJ_nid2txt, OBJ_obj2txt, OBJ_txt2obj - ASN.1 object functions

SYNOPSIS

#include <openssl/objects.h>

ASN1_OBJECT *OBJ_nid2obj(int nid);
int OBJ_obj2nid(const ASN1_OBJECT *o);
const char *OBJ_nid2ln(int nid);
int OBJ_ln2nid(const char *ln);
int OBJ_txt2nid(const char *s);
const char *OBJ_nid2txt(int nid, const char *fmt, int crit);
char *OBJ_obj2txt(const ASN1_OBJECT *o, char *buf, int buf_len, int crit);

DESCRIPTION

The OpenSSL library provides a large number of ASN.1 objects, such as algorithm identifiers and signature algorithms. Each object has a unique Object Identifier (OID), a short name, and a long name. These functions allow conversion between these different representations.

OBJ_nid2obj() converts an integer NID (Numeric Identifier) nid into an ASN1_OBJECT structure. If the NID is not known, NULL is returned.

OBJ_obj2nid() converts an ASN1_OBJECT structure o into its corresponding NID. If the object is not known, or if the NID is not numeric (e.g. it's an OID string), -1 is returned.

OBJ_nid2ln() returns the long name for the NID nid. This is typically a descriptive string like "rsaEncryption". If the NID is not known, NULL is returned.

OBJ_ln2nid() returns the NID for the long name ln. The comparison is case-insensitive. If the long name is not known, -1 is returned.

OBJ_txt2nid() converts a text string s into its NID. The string can be an OID (e.g. "1.2.3.4"), a short name (e.g. "rsa") or a long name (e.g. "rsaEncryption"). The comparison is case-insensitive. If the string is not known, -1 is returned.

OBJ_nid2txt() converts the NID nid into a text string. If fmt is not NULL, it specifies a format string for the output. If crit is non-zero, it indicates a critical extension. The function returns a pointer to a static buffer containing the text string, or NULL on error. The caller should not free the returned pointer.

OBJ_obj2txt() converts the ASN1_OBJECT structure o into a text string. If buf is not NULL, the output is written into the buffer buf of size buf_len. If buf is NULL, then sufficient space is allocated. If crit is non-zero, it indicates a critical extension. The function returns a pointer to the buffer containing the text string, or NULL on error. If a buffer was allocated, the caller must free it using OPENSSL_free().

NOTES

These functions are part of the OpenSSL crypto library, which is the core cryptographic library used by various applications, including the openssl command-line tool.

The NIDs are integer constants defined in OpenSSL that represent known ASN.1 objects. They are used internally by OpenSSL to refer to these objects efficiently.

The short names are typically acronyms (e.g., "rsa", "sha256"), while the long names are more descriptive (e.g., "rsaEncryption", "sha256WithRSAEncryption").

OID strings are dot-separated numerical representations of objects (e.g., "1.3.14.3.2.29" for id-sha1).

When converting to a text string using OBJ_nid2txt() or OBJ_obj2txt(), the crit parameter is typically used for extension objects, where it indicates whether the extension is critical.

RETURN VALUES

See the DESCRIPTION section for details on return values for each function.

EXAMPLES

Convert a NID to an object and then back to a NID:

#include <stdio.h>
        #include <openssl/objects.h>

        int main() {
            int nid = NID_sha256; // Example NID for SHA256
            ASN1_OBJECT *obj = OBJ_nid2obj(nid);
            if (obj) {
                int back_nid = OBJ_obj2nid(obj);
                printf("Original NID: %d\n", nid);
                printf("Converted back NID: %d\n", back_nid);
                // Free the allocated object
                ASN1_OBJECT_free(obj);
            } else {
                fprintf(stderr, "Failed to convert NID to object\n");
            }
            return 0;
        }

Convert a string to a NID:

#include <stdio.h>
        #include <openssl/objects.h>

        int main() {
            const char *obj_str = "sha256WithRSAEncryption";
            int nid = OBJ_txt2nid(obj_str);
            if (nid != -1) {
                printf("NID for '%s': %d\n", obj_str, nid);
            } else {
                fprintf(stderr, "Unknown object: %s\n", obj_str);
            }
            return 0;
        }
