OSSL_CMP_STATUSINFO_new(3ssl)

Paquet: openssl

Licences: Apache-2.0

OSSL_CMP_STATUSINFO_NEW(3ssl) OpenSSL OSSL_CMP_STATUSINFO_NEW(3ssl)

NOM

OSSL_CMP_STATUSINFO_new, OSSL_CMP_snprint_PKIStatusInfo, OSSL_CMP_CTX_snprint_PKIStatus - fonction(s) pour la gestion du statut PKI CMP

SYNTAXE

#include <openssl/cmp.h>
OSSL_CMP_PKISI *OSSL_CMP_STATUSINFO_new(int status, int fail_info,
                                        const char *text);
char *OSSL_CMP_snprint_PKIStatusInfo(const OSSL_CMP_PKISI *statusInfo,
                                     char *buf, size_t bufsize);
char *OSSL_CMP_CTX_snprint_PKIStatus(const OSSL_CMP_CTX *ctx, char *buf,
                                     size_t bufsize);

DESCRIPTION

Ceci est l'API PKIStatus pour utiliser CMP (Certificate Management Protocol) avec OpenSSL.

OSSL_CMP_STATUSINFO_new() crée une nouvelle structure PKIStatusInfo et la remplit avec les valeurs données. Elle définit le champ status à status, copie text (sauf s'il est NULL) dans statusString, et interprète fail_info comme un motif de bits pour le champ failInfo.

OSSL_CMP_snprint_PKIStatusInfo() place une chaîne de caractères lisible par l'homme représentant le statusInfo donné dans le tampon donné, avec la longueur maximale spécifiée.

OSSL_CMP_CTX_snprint_PKIStatus() place une chaîne de caractères lisible par l'homme représentant les composants PKIStatusInfo du contexte CMP ctx dans le tampon donné, avec la longueur maximale spécifiée.

NOTES

CMP est défini dans la RFC 4210 (et CRMF dans la RFC 4211).

VALEURS DE RETOUR

OSSL_CMP_STATUSINFO_new() retourne un pointeur vers la structure en cas de succès, ou NULL en cas d'erreur.

OSSL_CMP_snprint_PKIStatusInfo() et OSSL_CMP_CTX_snprint_PKIStatus() retournent une copie du pointeur du tampon contenant la chaîne ou NULL en cas d'erreur.

HISTORIQUE

Le support CMP d'OpenSSL a été ajouté dans OpenSSL 3.0.
