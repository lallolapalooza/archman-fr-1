Module Ephemeron
: sig end

Éphémère avec arité arbitraire et non typé

type obj_t = Obj.t

alias pour Obj.t

type t

un éphémère cf Obj.Ephemeron

val create : int -> t

create n retourne un éphémère avec n clés. Toutes les clés et les données sont initialement vides. L'argument n doit être compris entre zéro et Obj.Ephemeron.max_ephe_length (bornes incluses).

val length : t -> int

retourne le nombre de clés
