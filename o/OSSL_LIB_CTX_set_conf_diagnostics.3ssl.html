OSSL_LIB_CTX_SET_CONF_DIAGNOSTICS(3ssl) OpenSSL OSSL_LIB_CTX_SET_CONF_DIAGNOSTICS(3ssl)

NOM

OSSL_LIB_CTX_set_conf_diagnostics, OSSL_LIB_CTX_get_conf_diagnostics - Définir et obtenir les diagnostics de configuration

SYNTAXE

#include <openssl/crypto.h>
void OSSL_LIB_CTX_set_conf_diagnostics(OSSL_LIB_CTX *ctx, int value);
int OSSL_LIB_CTX_get_conf_diagnostics(OSSL_LIB_CTX *ctx);

DESCRIPTION

OSSL_LIB_CTX_set_conf_diagnostics() définit la valeur du drapeau de diagnostic de configuration. Si value est différent de zéro, l'analyse et l'application ultérieures des données de configuration peuvent signaler des erreurs qui seraient autrement ignorées. En particulier, toute erreur dans le module de configuration ssl provoquera un échec des appels de fonction SSL_CTX_new(3) et SSL_CTX_new_ex(3). Le drapeau de diagnostic de configuration peut également être défini lors du chargement d'un fichier de configuration dans OSSL_LIB_CTX avec OSSL_LIB_CTX_load_config(3). Si la configuration définit une valeur de config_diagnostics telle que décrite dans config(5), elle remplacera la valeur définie par OSSL_LIB_CTX_set_conf_diagnostics() avant de charger le fichier de configuration.

OSSL_LIB_CTX_get_conf_diagnostics() renvoie la valeur actuelle du drapeau de diagnostic de configuration.

VALEURS DE RETOUR

OSSL_LIB_CTX_get_conf_diagnostics() renvoie 0 si les diagnostics de configuration ne doivent pas être effectués, une valeur non nulle sinon.

VOIR AUSSI

SSL_CTX_new(3), OSSL_LIB_CTX_load_config(3), config(5)
