NOM

OSSL_ITEM - Type principal OpenSSL pour les données génériques itemisées

SYNTAXE

#include <openssl/core.h>
typedef struct ossl_item_st OSSL_ITEM;
struct ossl_item_st {
    unsigned int id;
    void *ptr;
};

DESCRIPTION

Ce type est un tuple d'entier et de pointeur. C'est un type générique utilisé comme descripteur générique, dont la signification exacte est définie par la façon dont il est utilisé. Des tableaux de ce type sont passés entre les bibliothèques OpenSSL et les fournisseurs (providers), et doivent être terminés par un tuple où l'entier est zéro et le pointeur NULL.

Ceci est actuellement principalement utilisé pour la valeur de retour du tableau de chaînes de raisons d'erreur du fournisseur, voir "Provider Functions" dans provider-base(7).

VOIR AUSSI

crypto(7), provider-base(7), openssl-core.h(7)
