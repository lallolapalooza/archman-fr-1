NOM

SYNTAXIS

#include <openssl/cmp.h>
typedef OSSL_CRMF_ATTRIBUTETYPEANDVALUE OSSL_CMP_ATAV;
OSSL_CMP_ATAV *OSSL_CMP_ATAV_create(ASN1_OBJECT *type, ASN1_TYPE *value);
void OSSL_CMP_ATAV_set0(OSSL_CMP_ATAV *atav, ASN1_OBJECT *type,
                        ASN1_TYPE *value);
ASN1_OBJECT *OSSL_CMP_ATAV_get0_type(const OSSL_CMP_ATAV *atav);
ASN1_TYPE *OSSL_CMP_ATAV_get0_value(const OSSL_CMP_ATAV *atav);
OSSL_CMP_ATAV *OSSL_CMP_ATAV_new_algId(const X509_ALGOR *alg);
X509_ALGOR *OSSL_CMP_ATAV_get0_algId(const OSSL_CMP_ATAV *atav);
OSSL_CMP_ATAV *OSSL_CMP_ATAV_new_rsaKeyLen(int len);
int OSSL_CMP_ATAV_get_rsaKeyLen(const OSSL_CMP_ATAV *atav);
typedef STACK_OF(OSSL_CRMF_ATTRIBUTETYPEANDVALUE) OSSL_CMP_ATAVS;
int OSSL_CMP_ATAV_push1(OSSL_CMP_ATAVS **sk_p, const OSSL_CMP_ATAV *atav);
void OSSL_CMP_ATAV_free(OSSL_CMP_ATAV *atav);

DESCRIPTION

OSSL_CMP_ATAV est un raccourci pour OSSL_CRMF_ATTRIBUTETYPEANDVALUE, défini dans la RFC 4211 Annexe B. Il est typiquement utilisé dans les structures CertRequest, mais aussi dans les structures CertReqTemplateContent pour les spécifications de clé.

OSSL_CMP_ATAV_create() crée une nouvelle structure OSSL_CMP_ATAV et la remplit. Elle combine OSSL_CMP_ATAV_new() et OSSL_CMP_ATAV_set0().

OSSL_CMP_ATAV_set0() définit le atav avec un type d'information (infoType) type et une valeur d'information (infoValue) value. Les pointeurs type et value peuvent être NULL, sinon ils ne doivent **pas** être libérés après l'appel car leur propriété est transférée à atav. Le pointeur itav ne doit pas être NULL.

OSSL_CMP_ATAV_get0_type() retourne un pointeur direct vers le type d'information dans le atav, sauf s'il est NULL.

OSSL_CMP_ATAV_get0_value() retourne un pointeur direct vers la valeur d'information dans le atav en tant que pointeur générique ASN1_TYPE, sauf si atav est NULL.

OSSL_CMP_ATAV_new_algId() crée une nouvelle structure OSSL_CMP_ATAV de type algId et la remplit avec une copie du alg donné.

OSSL_CMP_ATAV_get0_algId() retourne un pointeur direct vers la valeur d'information algId dans le atav de type X509_ALGOR ou NULL si atav est NULL ou ne contient pas d'algId.

OSSL_CMP_ATAV_new_rsaKeyLen() crée une nouvelle structure OSSL_CMP_ATAV de type rsaKeyLen et la remplit avec le len donné, qui doit être positif.

OSSL_CMP_ATAV_get_rsaKeyLen() retourne la longueur de clé RSA dans la valeur d'information rsaKeyLen du atav, -1 si atav est NULL ou ne contient pas de rsaKeyLen ou ne peut pas être analysé, ou -2 si la valeur est inférieure à 1 ou supérieure à INT_MAX.

OSSL_CMP_ATAV_push1() ajoute une copie de atav à la pile de OSSL_CMP_ATAV pointée par *sk_p. Elle crée une nouvelle pile si *sk_p pointe vers NULL.

OSSL_CMP_ATAV_free() désalloue atav. Elle est définie comme une macro.

NOTES

CMP est défini dans la RFC 4210. CRMF est défini dans la RFC 4211.

VALEUR DE RETOUR

OSSL_CMP_ATAV_create(), OSSL_CMP_ATAV_new_algId(), et OSSL_CMP_ATAV_new_rsaKeyLen() retournent un pointeur vers la structure ATAV en cas de succès, ou NULL en cas d'erreur.

OSSL_CMP_ATAV_set0() et OSSL_CMP_ATAV_free() ne retournent pas de valeur.

OSSL_CMP_ATAV_get0_type(), OSSL_CMP_ATAV_get0_value(), et OSSL_CMP_ATAV_get0_algId() retournent le pointeur respectif ou NULL si leur entrée est NULL.

OSSL_CMP_ATAV_get_rsaKeyLen() retourne une longueur de clé en bits ou < 0 en cas d'erreur.

OSSL_CMP_ATAV_push1() retourne 1 en cas de succès, 0 en cas d'erreur.
