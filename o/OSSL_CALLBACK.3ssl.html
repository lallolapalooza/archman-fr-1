NOM

OSSL_CALLBACK, OSSL_PASSPHRASE_CALLBACK - Type de base OpenSSL pour définir des rappels

SYNTAXE

#include <openssl/core.h>
typedef int (OSSL_CALLBACK)(const OSSL_PARAM params[], void *arg);
typedef int (OSSL_PASSPHRASE_CALLBACK)(char *pass, size_t pass_size,
                                       size_t *pass_len,
                                       const OSSL_PARAM params[],
                                       void *arg);

DESCRIPTION

Pour certains événements ou activités, la fonctionnalité du fournisseur peut avoir besoin de l'aide de l'application ou des bibliothèques OpenSSL appelantes elles-mêmes. Par exemple, la saisie utilisateur ou la sortie utilisateur directe (éventuellement facultative) pourraient être implémentées de cette manière.

Les fonctions de rappel elles-mêmes sont toujours fournies par ou via les bibliothèques OpenSSL appelantes, avec un pointeur générique vers les données arg. En ce qui concerne la fonction recevant le pointeur vers le pointeur de fonction et arg, les données auxquelles pointe arg sont opaques, et le pointeur doit simplement être renvoyé à la fonction de rappel lorsqu'elle est appelée.

OSSL_CALLBACK
Il s'agit d'une fonction de rappel générique. Lors de l'appel de cette fonction de rappel, l'appelant est censé construire un tableau OSSL_PARAM(3) de données qu'il souhaite ou est censé renvoyer, et le passer comme params, ainsi que le pointeur de données opaque qu'il a reçu, comme arg.
OSSL_PASSPHRASE_CALLBACK
Il s'agit d'une fonction de rappel spécialisée, utilisée spécifiquement pour demander un mot de passe à l'utilisateur. Lors de l'appel de cette fonction de rappel, un tampon pour stocker le mot de passe doit être fourni avec pass, et sa taille avec pass_size. La longueur du mot de passe demandé sera retournée dans *pass_len.

Des paramètres supplémentaires peuvent être passés avec le tableau OSSL_PARAM(3) params.

VALEURS DE RETOUR

Les fonctions de type OSSL_CALLBACK et OSSL_PASSPHRASE_CALLBACK doivent retourner 1 en cas de succès et 0 en cas d'échec.
