OSSL_SELF_TEST_new(3ssl)

Paquet: openssl

Licences: Apache-2.0

OSSL_SELF_TEST_NEW(3ssl) OpenSSL OSSL_SELF_TEST_NEW(3ssl)

NOM

OSSL_SELF_TEST_new, OSSL_SELF_TEST_free, OSSL_SELF_TEST_onbegin, OSSL_SELF_TEST_oncorrupt_byte, OSSL_SELF_TEST_onend - fonctionnalités pour déclencher un rappel lors d'un auto-test

SYNTAXE

#include <openssl/self_test.h>
OSSL_SELF_TEST *OSSL_SELF_TEST_new(OSSL_CALLBACK *cb, void *cbarg);
void OSSL_SELF_TEST_free(OSSL_SELF_TEST *st);
void OSSL_SELF_TEST_onbegin(OSSL_SELF_TEST *st, const char *type,
                            const char *desc);
int OSSL_SELF_TEST_oncorrupt_byte(OSSL_SELF_TEST *st, unsigned char *bytes);
void OSSL_SELF_TEST_onend(OSSL_SELF_TEST *st, int ret);

DESCRIPTION

Ces méthodes sont destinées à être utilisées par les implémenteurs de fournisseurs, pour afficher des informations de diagnostic pendant les auto-tests.

OSSL_SELF_TEST_new() alloue un objet opaque OSSL_SELF_TEST auquel un rappel et un argument de rappel sont associés.

Le rappel cb peut être déclenché plusieurs fois par un auto-test pour indiquer différentes phases.

OSSL_SELF_TEST_free() libère l'espace alloué par OSSL_SELF_TEST_new(). Si l'argument est NULL, rien n'est fait.

OSSL_SELF_TEST_onbegin() peut être inséré au début d'un bloc de code d'auto-test. Il peut être utilisé à des fins de diagnostic. Si cette méthode est appelée, le rappel cb recevra l'objet OSSL_PARAM(3) suivant.

"st-phase" (OSSL_PROV_PARAM_SELF_TEST_PHASE) <chaîne UTF8>
La valeur est la chaîne "Start"

OSSL_SELF_TEST_oncorrupt_byte() peut être inséré juste après le calcul de la réponse connue, mais avant que l'auto-test ne compare le résultat. Le premier octet du tableau bytes passé sera corrompu si le rappel retourne 0, sinon il laissera le tableau inchangé. Il peut être utilisé pour les tests d'échec. Les valeurs type et desc peuvent être utilisées pour identifier un auto-test individuel à cibler pour les tests d'échec. Si cette méthode est appelée, le rappel cb recevra l'objet OSSL_PARAM(3) suivant.

"st-phase" (OSSL_PROV_PARAM_SELF_TEST_PHASE) <chaîne UTF8>
La valeur est la chaîne "Corrupt"

OSSL_SELF_TEST_onend() peut être inséré à la fin d'un bloc de code d'auto-test juste avant le nettoyage pour indiquer si le test a réussi ou échoué. Il peut être utilisé à des fins de diagnostic. Si cette méthode est appelée, le rappel cb recevra l'objet OSSL_PARAM(3) suivant.

"st-phase" (OSSL_PROV_PARAM_SELF_TEST_PHASE) <chaîne UTF8>
La valeur de la chaîne est "Pass" si ret est non nul, sinon elle a la valeur "Fail".

Après que le rappel cb a été appelé, les valeurs qui ont été définies par OSSL_SELF_TEST_onbegin() pour type et desc sont définies à la valeur "None".

Si OSSL_SELF_TEST_onbegin(), OSSL_SELF_TEST_oncorrupt_byte() ou OSSL_SELF_TEST_onend() est appelé, les OSSL_PARAM(3) supplémentaires suivants sont passés au rappel.

"st-type" (OSSL_PROV_PARAM_SELF_TEST_TYPE) <chaîne UTF8>
La valeur est configurée par le type passé à OSSL_SELF_TEST_onbegin(). Cela permet au rappel d'identifier le type de test en cours d'exécution.
"st-desc" (OSSL_PROV_PARAM_SELF_TEST_DESC) <chaîne UTF8>
La valeur est configurée par le type passé à OSSL_SELF_TEST_onbegin(). Cela permet au rappel d'identifier la sous-catégorie du test en cours d'exécution.

VALEURS DE RETOUR

OSSL_SELF_TEST_new() retourne l'objet OSSL_SELF_TEST alloué, ou NULL en cas d'échec.

OSSL_SELF_TEST_oncorrupt_byte() retourne 1 si une corruption se produit, sinon il retourne 0.

EXEMPLES

Un seul auto-test pourrait être configuré de la manière suivante :

  OSSL_SELF_TEST *st = NULL;
  OSSL_CALLBACK *cb;
  void *cbarg;
  int ok = 0;
  unsigned char out[EVP_MAX_MD_SIZE];
  unsigned int out_len = 0;
  EVP_MD_CTX *ctx = EVP_MD_CTX_new();
  EVP_MD *md = EVP_MD_fetch(libctx, t->algorithm, NULL);
  /*
   * Récupère le rappel - sera NULL s'il n'a pas été défini par l'application via
   * OSSL_SELF_TEST_set_callback().
   */
  OSSL_SELF_TEST_get_callback(libctx, &cb, &cbarg);
  st = OSSL_SELF_TEST_new(cb, cb_arg);
  /* Déclenche le rappel optionnel */
  OSSL_SELF_TEST_onbegin(st, OSSL_SELF_TEST_TYPE_KAT_DIGEST,
                         OSSL_SELF_TEST_DESC_MD_SHA2);
  if (!EVP_DigestInit_ex(ctx, md, NULL)
      || !EVP_DigestUpdate(ctx, pt, pt_len)
      || !EVP_DigestFinal(ctx, out, &out_len))
      goto err;
  /* Corruption optionnelle - Si le rappel de l'application retourne 0 */
  OSSL_SELF_TEST_oncorrupt_byte(st, out);
  if (out_len != t->expected_len
      || memcmp(out, t->expected, out_len) != 0)
      goto err;
  ok = 1;
err:
  OSSL_SELF_TEST_onend(st, ok);
  EVP_MD_free(md);
  EVP_MD_CTX_free(ctx);

Plusieurs auto-tests peuvent être configurés de manière similaire en répétant le schéma OSSL_SELF_TEST_onbegin(), OSSL_SELF_TEST_oncorrupt_byte(), OSSL_SELF_TEST_onend() pour chaque test.
