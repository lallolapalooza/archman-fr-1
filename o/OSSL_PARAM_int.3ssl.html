DESCRIPTION

Une collection de fonctions utilitaires qui simplifient et ajoutent une sécurité de type aux tableaux OSSL_PARAM(3). Les noms **TYPE** suivants sont pris en charge :

  • double
  • int
  • int32 (int32_t)
  • int64 (int64_t)
  • long int (long)
  • time_t
  • size_t
  • uint32 (uint32_t)
  • uint64 (uint64_t)
  • unsigned int (uint)
  • unsigned long int (ulong)

OSSL_PARAM_TYPE() sont une série de macros conçues pour aider à initialiser un tableau de structures OSSL_PARAM(3). Chacune de ces macros définit un paramètre du TYPE spécifié avec la clé et l'adresse de la variable de paramètre fournies.

OSSL_PARAM_utf8_string(), OSSL_PARAM_octet_string(), OSSL_PARAM_utf8_ptr(), OSSL_PARAM_octet_ptr(), OSSL_PARAM_BN() sont des macros qui fournissent une prise en charge pour la définition de chaînes UTF8, de chaînes OCTET et de grands nombres. Un paramètre portant le nom key est défini. Le stockage pour ce paramètre se trouve à l'adresse address et occupe size octets.

OSSL_PARAM_END fournit un marqueur de fin de liste de paramètres. Ceci doit terminer tous les tableaux OSSL_PARAM(3).

La macro OSSL_PARAM_DEFN() offre la possibilité de construire une seule structure OSSL_PARAM(3) (typiquement utilisée dans la construction de tableaux OSSL_PARAM). Les arguments key, type, addr et sz correspondent aux champs key, data_type, data et data_size de la structure OSSL_PARAM(3) tels que décrits dans la page OSSL_PARAM(3).

OSSL_PARAM_construct_TYPE() sont une série de fonctions qui créent des enregistrements OSSL_PARAM(3) dynamiquement. Un paramètre avec le nom key est créé. Le paramètre utilisera le stockage pointé par buf et la taille de retour sera ret.

OSSL_PARAM_construct_BN() est une fonction qui construit une structure OSSL_PARAM(3) pour un grand nombre. Un paramètre avec le nom key, le stockage buf, la taille bsize et la taille de retour rsize est créé.

OSSL_PARAM_construct_utf8_string() est une fonction qui construit une structure OSSL_PARAM(3) de chaîne UTF8. Un paramètre avec le nom key, le stockage buf et la taille bsize est créé. Si bsize est zéro, la longueur de la chaîne est déterminée en utilisant strlen(3). En général, passez zéro pour bsize au lieu d'appeler vous-même strlen(3).

OSSL_PARAM_construct_octet_string() est une fonction qui construit une structure OSSL_PARAM(3) de chaîne OCTET. Un paramètre avec le nom key, le stockage buf et la taille bsize est créé.

OSSL_PARAM_construct_utf8_ptr() est une fonction qui construit une structure de pointeur de chaîne UTF8 OSSL_PARAM(3). Un paramètre avec le nom key, le pointeur de stockage *buf et la taille bsize est créé.

OSSL_PARAM_construct_octet_ptr() est une fonction qui construit une structure de pointeur de chaîne OCTET OSSL_PARAM(3). Un paramètre avec le nom key, le pointeur de stockage *buf et la taille bsize est créé.

OSSL_PARAM_construct_end() est une fonction qui construit la structure OSSL_PARAM(3) de terminaison.

OSSL_PARAM_locate() est une fonction qui recherche dans un tableau de paramètres celui qui correspond au nom key.

OSSL_PARAM_locate_const() se comporte exactement comme OSSL_PARAM_locate() à l'exception de la présence de const pour l'argument array et sa valeur de retour.

VALEURS DE RETOUR

OSSL_PARAM_construct_TYPE(), OSSL_PARAM_construct_BN(), OSSL_PARAM_construct_utf8_string(), OSSL_PARAM_construct_octet_string(), OSSL_PARAM_construct_utf8_ptr() et OSSL_PARAM_construct_octet_ptr() retournent une structure OSSL_PARAM(3) remplie.

OSSL_PARAM_locate() et OSSL_PARAM_locate_const() retournent un pointeur vers un objet OSSL_PARAM(3) correspondant. En cas d'erreur ou si aucun objet ne correspond à key dans le array, ils retournent NULL.

OSSL_PARAM_modified() retourne 1 si le paramètre param a été défini, et 0 sinon.

Toutes les autres fonctions retournent 1 en cas de succès et 0 en cas d'échec.

NOTES

Les types natifs ne seront convertis que si la valeur est exactement représentable par le type cible ou le paramètre. Sauf indication contraire, les fonctions doivent être utilisées de manière appropriée pour le type attendu du paramètre.

OSSL_PARAM_get_BN() et OSSL_PARAM_set_BN() ne supportent que les BIGNUM non négatifs lorsque le type souhaité est OSSL_PARAM_UNSIGNED_INTEGER. OSSL_PARAM_construct_BN() construit actuellement un OSSL_PARAM(3) avec le type OSSL_PARAM_UNSIGNED_INTEGER.

Pour OSSL_PARAM_construct_utf8_ptr() et OSSL_PARAM_construct_octet_ptr(), bsize n'est pas pertinent si le but est d'envoyer le OSSL_PARAM(3) à un responder, c'est-à-dire pour obtenir des données de paramètres. Dans ce cas, bsize peut être mis à zéro en toute sécurité. Voir la section "DESCRIPTION" de OSSL_PARAM(3) pour plus d'informations sur les utilisations possibles.

EXEMPLES

En réutilisant les exemples de OSSL_PARAM(3) pour montrer comment les tableaux OSSL_PARAM(3) peuvent être gérés à l'aide des macros et fonctions définies ici.

Exemple 1

Cet exemple est utilisé pour définir des paramètres dans un objet quelconque :

#include <openssl/core.h>
const char *foo = "some string";
size_t foo_l = strlen(foo);
const char bar[] = "some other string";
const OSSL_PARAM set[] = {
    OSSL_PARAM_utf8_ptr("foo", &foo, foo_l),
    OSSL_PARAM_utf8_string("bar", bar, sizeof(bar) - 1),
    OSSL_PARAM_END
};

Exemple 2

Cet exemple est utilisé pour demander des paramètres dans un objet quelconque et montre que le demandeur n'est pas obligé de demander tous les paramètres disponibles :

const char *foo = NULL;
char bar[1024];
OSSL_PARAM request[] = {
    OSSL_PARAM_utf8_ptr("foo", &foo, 0),
    OSSL_PARAM_utf8_string("bar", bar, sizeof(bar)),
    OSSL_PARAM_END
};

Un responder qui reçoit ce tableau (comme "params" dans cet exemple) pourrait remplir les paramètres comme suit :

/* OSSL_PARAM *params */
OSSL_PARAM *p;
if ((p = OSSL_PARAM_locate(params, "foo")) != NULL)
    OSSL_PARAM_set_utf8_ptr(p, "foo value");
if ((p = OSSL_PARAM_locate(params, "bar")) != NULL)
    OSSL_PARAM_set_utf8_string(p, "bar value");
if ((p = OSSL_PARAM_locate(params, "cookie")) != NULL)
    OSSL_PARAM_set_utf8_ptr(p, "cookie value");

Exemple 3

Cet exemple montre un cas particulier où -Wincompatible-pointer-types-discards-qualifiers peut être défini lors de la compilation. La valeur pour buf ne peut pas être une chaîne const char *. Une alternative dans ce cas serait d'utiliser la macro OSSL_PARAM pour des appels plus concis que ceux spécifiques à l'appelant, ce qui permet de définir l'argument SHA1 comme un tableau de caractères standard (char[]).

Par exemple, ce code :

OSSL_PARAM params[2];
params[0] = OSSL_PARAM_construct_utf8_string("digest", "SHA1", 0);
params[1] = OSSL_PARAM_construct_end();

peut être rendu compatible avec la version suivante :

char sha1[] = "SHA1"; /* sha1 est défini comme char[] dans ce cas */
OSSL_PARAM params[2];
params[0] = OSSL_PARAM_construct_utf8_string("digest", sha1, 0);
params[1] = OSSL_PARAM_construct_end();
