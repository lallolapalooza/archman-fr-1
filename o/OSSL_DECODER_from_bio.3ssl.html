OSSL_DECODER_from_bio(3ssl)

Paquet: openssl

Licences: Apache-2.0

OSSL_DECODER_FROM_BIO(3ssl) OpenSSL OSSL_DECODER_FROM_BIO(3ssl)

NOM

OSSL_DECODER_from_data, OSSL_DECODER_from_bio, OSSL_DECODER_from_fp - Routines pour effectuer un décodage

SYNOPIS

#include <openssl/decoder.h>
int OSSL_DECODER_from_bio(OSSL_DECODER_CTX *ctx, BIO *in);
int OSSL_DECODER_from_fp(OSSL_DECODER_CTX *ctx, FILE *fp);
int OSSL_DECODER_from_data(OSSL_DECODER_CTX *ctx, const unsigned char **pdata,
                           size_t *pdata_len);

Macros de disponibilité des fonctionnalités :

OSSL_DECODER_from_fp() n'est disponible que lorsque OPENSSL_NO_STDIO est défini.

DESCRIPTION

OSSL_DECODER_from_data() exécute le processus de décodage pour le contexte ctx, avec l'entrée provenant de *pdata, d'une longueur de *pdata_len octets. *pdata et *pdata_len doivent tous deux être non-NULL. Lorsque OSSL_DECODER_from_data() retourne, *pdata est mis à jour pour pointer à l'emplacement après ce qui a été décodé, et *pdata_len pour contenir le nombre d'octets restants.

OSSL_DECODER_from_bio() exécute le processus de décodage pour le contexte ctx, avec l'entrée provenant du BIO in. Si cela fait une différence, il est recommandé d'avoir le BIO défini en mode binaire plutôt qu'en mode texte.

OSSL_DECODER_from_fp() fait la même chose que OSSL_DECODER_from_bio(), sauf que l'entrée provient du FILE fp.

VALEURS DE RETOUR

OSSL_DECODER_from_bio(), OSSL_DECODER_from_data() et OSSL_DECODER_from_fp() retournent 1 en cas de succès, ou 0 en cas d'échec.

EXEMPLES

Pour décoder une clé RSA encodée en PEM à partir d'un bio :

OSSL_DECODER_CTX *dctx;
EVP_PKEY *pkey = NULL;
const char *format = "PEM";   /* NULL pour tout format */
const char *structure = NULL; /* toute structure */
const char *keytype = "RSA";  /* NULL pour toute clé */
const unsigned char *pass = "mon mot de passe";
dctx = OSSL_DECODER_CTX_new_for_pkey(&pkey, format, structure,
                                     keytype,
                                     OSSL_KEYMGMT_SELECT_KEYPAIR,
                                     NULL, NULL);
if (dctx == NULL) {
    /* erreur : aucun décodeur potentiel approprié trouvé */
}
if (pass != NULL)
    OSSL_DECODER_CTX_set_passphrase(dctx, pass, strlen(pass));
if (OSSL_DECODER_from_bio(dctx, bio)) {
    /* pkey est créé avec les données décodées du bio */
} else {
    /* échec du décodage */
}
OSSL_DECODER_CTX_free(dctx);

Pour décoder une clé EC encodée en DER à partir d'un tampon :

OSSL_DECODER_CTX *dctx;
EVP_PKEY *pkey = NULL;
const char *format = "DER";   /* NULL pour tout format */
const char *structure = NULL; /* toute structure */
const char *keytype = "EC";   /* NULL pour toute clé */
const unsigned char *pass = NULL
const unsigned char *data = buffer;
size_t datalen = sizeof(buffer);
dctx = OSSL_DECODER_CTX_new_for_pkey(&pkey, format, structure,
                                     keytype,
                                     OSSL_KEYMGMT_SELECT_KEYPAIR
                                     | OSSL_KEYMGMT_SELECT_DOMAIN_PARAMETERS,
                                     NULL, NULL);
if (dctx == NULL) {
    /* erreur : aucun décodeur potentiel approprié trouvé */
}
if (pass != NULL)
    OSSL_DECODER_CTX_set_passphrase(dctx, pass, strlen(pass));
if (OSSL_DECODER_from_data(dctx, &data, &datalen)) {
    /* pkey est créé avec les données décodées du tampon */
} else {
    /* échec du décodage */
}
OSSL_DECODER_CTX_free(dctx);
