ASN1_TYPE *OSSL_CMP_ITAV_get0_value(const OSSL_CMP_ITAV *itav);
int OSSL_CMP_ITAV_push0_stack_item(STACK_OF(OSSL_CMP_ITAV) **itav_sk_p,
                                   OSSL_CMP_ITAV *itav);
OSSL_CMP_ITAV
*OSSL_CMP_ITAV_new0_certProfile(STACK_OF(ASN1_UTF8STRING) *certProfile);
int OSSL_CMP_ITAV_get0_certProfile(const OSSL_CMP_ITAV *itav,
                                   STACK_OF(ASN1_UTF8STRING) **out);

DESCRIPTION

ITAV est l'acronyme de InfoTypeAndValue. Ce type est défini dans la section 5.3.19 et l'annexe F de la RFC 4210. Il est utilisé à divers endroits dans les messages CMP, par exemple dans le champ generalInfo de PKIHeader, pour contenir une paire clé-valeur.

OSSL_CMP_ITAV_create() crée une nouvelle structure OSSL_CMP_ITAV et la remplit. Elle combine OSSL_CMP_ITAV_new() et OSSL_CMP_ITAV_set0().

OSSL_CMP_ITAV_set0() définit itav avec un type d'information (infoType) de type et une valeur d'information (infoValue) de value. Cette fonction utilise les pointeurs type et value en interne, ils ne doivent donc pas être libérés après l'appel.

OSSL_CMP_ITAV_get0_type() retourne un pointeur direct vers le type d'information dans itav.

OSSL_CMP_ITAV_get0_value() retourne un pointeur direct vers la valeur d'information dans itav sous forme de pointeur générique ASN1_TYPE.

OSSL_CMP_ITAV_push0_stack_item() ajoute itav à la pile pointée par *itav_sk_p. Elle crée une nouvelle pile si *itav_sk_p pointe vers NULL.

OSSL_CMP_ITAV_new0_certProfile() crée une nouvelle structure OSSL_CMP_ITAV de type certProfile qui inclut la liste optionnelle des noms de profils. En cas de succès, la propriété de la liste est transférée à la nouvelle structure OSSL_CMP_ITAV.

OSSL_CMP_ITAV_get0_certProfile(), en cas de succès, assigne à *out un pointeur interne vers la liste des noms de profils de certificats contenus dans le champ infoValue de itav. Le pointeur peut être NULL s'il n'y a pas de nom de profil inclus. C'est une erreur si le type d'information de itav n'est pas certProfile.

NOTES

CMP est défini dans la RFC 4210 et la RFC 9480 (et CRMF dans la RFC 4211).

Les OID à utiliser comme types dans OSSL_CMP_ITAV peuvent être trouvés à https://datatracker.ietf.org/doc/html/rfc9480#section-4.2.2. Les NID OpenSSL respectifs, tels que NID_id_it_certProfile, sont définis dans le fichier d'en-tête <openssl/obj_mac.h>.

VALEURS DE RETOUR

OSSL_CMP_ITAV_create() et OSSL_CMP_ITAV_new0_certProfile() retournent un pointeur vers une structure ITAV en cas de succès, ou NULL en cas d'erreur.

OSSL_CMP_ITAV_set0() ne retourne pas de valeur.

OSSL_CMP_ITAV_get0_type() et OSSL_CMP_ITAV_get0_value() retournent le pointeur respectif ou NULL si leur entrée est NULL.

OSSL_CMP_ITAV_push0_stack_item() et OSSL_CMP_ITAV_get0_certProfile() retournent 1 en cas de succès, 0 en cas d'erreur.

EXEMPLES

Le code suivant crée et définit une structure représentant une séquence InfoTypeAndValue générique, en utilisant un OID créé à partir de texte comme type, et un entier comme valeur. Ensuite, elle est ajoutée au OSSL_CMP_CTX pour être incluse plus tard dans le champ genInfo du PKIHeader des requêtes.

ASN1_OBJECT *type = OBJ_txt2obj("1.2.3.4.5", 1);
if (type == NULL) ...
ASN1_INTEGER *asn1int = ASN1_INTEGER_new();
if (asn1int == NULL || !ASN1_INTEGER_set(asn1int, 12345)) ...
ASN1_TYPE *val = ASN1_TYPE_new();
if (val == NULL) ...
ASN1_TYPE_set(val, V_ASN1_INTEGER, asn1int);
OSSL_CMP_ITAV *itav = OSSL_CMP_ITAV_create(type, val);
if (itav == NULL) ...
if (!OSSL_CMP_CTX_push0_geninfo_ITAV(ctx, itav)) {
    OSSL_CMP_ITAV_free(itav); /* libère aussi type et val */
    ...
}
...
OSSL_CMP_CTX_free(ctx); /* libère aussi itav */
