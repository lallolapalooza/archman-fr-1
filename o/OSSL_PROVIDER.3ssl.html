DESCRIPTION

OSSL_PROVIDER est un type qui stocke des informations internes sur les implémentations de fournisseurs (voir provider(7) pour des informations sur ce qu'est un fournisseur). Un fournisseur peut être intégré à l'application ou aux bibliothèques OpenSSL, ou il peut s'agir d'un module chargeable. Les fonctions décrites ici gèrent les deux types.

Certaines de ces fonctions opèrent dans un contexte de bibliothèque, voir OSSL_LIB_CTX(3) pour plus de détails.

Fonctions

OSSL_PROVIDER_set_default_search_path() spécifie le chemin de recherche par défaut à utiliser pour trouver les fournisseurs dans le contexte spécifié libctx. S'il n'est pas spécifié, une valeur d'environnement et une valeur de repli par défaut seront utilisées.

OSSL_PROVIDER_get0_default_search_path() récupère le chemin de recherche par défaut à utiliser pour trouver les fournisseurs dans le contexte spécifié libctx. En cas de succès, il renvoie le chemin ou une chaîne vide ; le chemin est valide jusqu'à ce que le contexte soit libéré ou que OSSL_PROVIDER_set_default_search_path() soit appelé.

OSSL_PROVIDER_add_builtin() est utilisé pour ajouter un fournisseur intégré à la base de données des fournisseurs dans le contexte donné, associant un nom de fournisseur à une fonction d'initialisation du fournisseur. Ce nom peut ensuite être utilisé avec OSSL_PROVIDER_load().

OSSL_PROVIDER_load() charge et initialise un fournisseur. Cela peut simplement initialiser un fournisseur qui a été précédemment ajouté avec OSSL_PROVIDER_add_builtin() et exécuter sa fonction d'initialisation, ou charger un module fournisseur avec le nom donné et exécuter son point d'entrée fournisseur, "OSSL_provider_init". Le nom du fournisseur peut être un chemin vers un module fournisseur, auquel cas le nom du fournisseur tel que renvoyé par OSSL_PROVIDER_get0_name() sera le chemin. Les chemins relatifs sont considérés comme dépendant du système et sont relatifs au répertoire configuré "MODULESDIR" ou au chemin défini dans la variable d'environnement OPENSSL_MODULES s'il est défini.

OSSL_PROVIDER_try_load() fonctionne de manière similaire à OSSL_PROVIDER_load(), sauf qu'il ne désactive pas les fournisseurs de repli si le fournisseur ne peut pas être chargé et initialisé ou si retain_fallbacks est supérieur à zéro. Si le fournisseur est chargé avec succès et que retain_fallbacks est zéro, les fournisseurs de repli sont désactivés.

OSSL_PROVIDER_load_ex() et OSSL_PROVIDER_try_load_ex() sont des variantes des fonctions ci-dessus qui acceptent un tableau "OSSL_PARAM" de paramètres utilisés comme configuration pour le fournisseur chargé. Les paramètres de tout type sauf "OSSL_PARAM_UTF8_STRING" sont ignorés silencieusement. Si des paramètres sont fournis, ils remplacent tous les paramètres spécifiés dans le fichier de configuration.

OSSL_PROVIDER_unload() désinitialise le fournisseur donné. Pour un fournisseur ajouté avec OSSL_PROVIDER_add_builtin(), cela exécute simplement sa fonction de désinitialisation.

OSSL_PROVIDER_available() vérifie si un fournisseur portant le nom spécifié est disponible pour utilisation.

OSSL_PROVIDER_do_all() itère sur tous les fournisseurs chargés, appelant cb pour chacun, avec le fournisseur actuel dans provider et le cbdata obtenu de l'appelant. S'il n'y a pas d'autre fournisseur chargé avant d'appeler cette fonction, le fournisseur par défaut est toujours disponible en tant que repli. Voir OSSL_PROVIDER-default(7) pour plus d'informations sur ce comportement de repli.

OSSL_PROVIDER_gettable_params() est utilisé pour obtenir un descripteur de paramètres de fournisseur qui est spécifié comme un tableau constant OSSL_PARAM(3).

OSSL_PROVIDER_get_params() est utilisé pour obtenir les valeurs des paramètres du fournisseur. L'appelant doit préparer le tableau OSSL_PARAM(3) avant d'appeler cette fonction, et les valeurs agissent comme des tampons pour ce tableau de paramètres doivent être remplis de données lorsqu'il renvoie avec succès.

OSSL_PROVIDER_add_conf_parameter() définit le paramètre de configuration du fournisseur name à value. Les paramètres de configuration du fournisseur sont gérés par le noyau OpenSSL et sont normalement définis dans le fichier de configuration, mais peuvent également être définis tôt dans le programme principal avant qu'un fournisseur ne soit utilisé par plusieurs threads. Les paramètres qui n'affectent que l'initialisation du fournisseur doivent, pour l'instant, être définis dans le fichier de configuration, et n'ont d'effet que lorsqu'ils sont définis via cette interface ; les paramètres qui sont également interrogés plus tard ont un certain effet. Seuls les paramètres textuels peuvent être passés, et c'est au fournisseur de les interpréter.

OSSL_PROVIDER_get_conf_parameters() collecte les paramètres de configuration globaux associés à prov. Ces paramètres de configuration sont stockés par le noyau OpenSSL pour chaque fournisseur, et non par le fournisseur lui-même ; les paramètres gérés par le fournisseur sont interrogés via OSSL_PROVIDER_get_params() décrit ci-dessus. Les paramètres sont renvoyés par référence, et non sous forme de copies, de sorte que les éléments du tableau param doivent avoir OSSL_PARAM_UTF8_PTR comme leur data_type.

OSSL_PROVIDER_conf_get_bool() analyse le paramètre de configuration global name associé au fournisseur prov comme une valeur booléenne, renvoyant une valeur par défaut defval si le paramètre ne peut pas être obtenu ou analysé. Les valeurs de paramètre égales (en comparaison de chaîne insensible à la casse) à 1, "on", "yes" ou "true" produisent un résultat vrai (non nul). Les valeurs de paramètre égales à "true" sont considérées comme vraies.

DESCRIPTION

OSSL_PROVIDER is a module that provides functions to manage and load providers for the OpenSSL library. The functions described here are used to load providers, perform self-tests, retrieve information about providers, and manage configuration parameters.

The OSSL_PROVIDER_load_ex and OSSL_PROVIDER_try_load_ex functions are used to load providers with optional arguments. The OSSL_PROVIDER_self_test function runs self-tests on a provider. The OSSL_PROVIDER_get0_provider_ctx function returns the provider context for a given provider. The OSSL_PROVIDER_get0_name function returns the name of a provider. The OSSL_PROVIDER_get0_dispatch function returns the dispatch table of a provider. The OSSL_PROVIDER_get0_default_search_path function returns the default search path for a provider. The OSSL_PROVIDER_load and OSSL_PROVIDER_try_load functions load providers. The OSSL_PROVIDER_do_all function runs callbacks for all providers. The OSSL_PROVIDER_available function checks if a provider is available. The OSSL_PROVIDER_gettable_params function returns parameters for a provider. The OSSL_PROVIDER_get_params function retrieves parameters for a provider. The OSSL_PROVIDER_query_operation function queries operations for a provider. The OSSL_PROVIDER_unquery_operation function unqueries operations for a provider.

VALEURS DE RETOUR

The functions described here return 1 on success, or 0 on error.

The OSSL_PROVIDER_get0_default_search_path function returns a pointer to a path on success, or NULL on error or if the path has not previously been set.

The OSSL_PROVIDER_load and OSSL_PROVIDER_try_load functions return a pointer to a provider object on success, or NULL on error.

The OSSL_PROVIDER_do_all function returns 1 if the callback returns 1 for every provider, or 0 if any provider callback returns 0. Callback processing stops at the first provider that returns 0.

The OSSL_PROVIDER_available function returns 1 if the named provider is available, otherwise 0.

The OSSL_PROVIDER_gettable_params function returns a pointer to an array of constant OSSL_PARAM(3), or NULL if none is provided.

The OSSL_PROVIDER_get_params function returns 1 on success, or 0 on error.

The OSSL_PROVIDER_query_operation function returns an array of OSSL_ALGORITHM or NULL on error.

The OSSL_PROVIDER_self_test function returns 1 if the self tests pass, or 0 on error.

EXEMPLES

This demonstrates how to load the provider module "foo" and ask for its build information.

#include <openssl/params.h>
#include <openssl/provider.h>
#include <openssl/err.h>
OSSL_PROVIDER *prov = NULL;
const char *build = NULL;
OSSL_PARAM request[] = {
    { "buildinfo", OSSL_PARAM_UTF8_PTR, &build, 0, 0 },
    { NULL, 0, NULL, 0, 0 }
};
if ((prov = OSSL_PROVIDER_load(NULL, "foo")) != NULL
    && OSSL_PROVIDER_get_params(prov, request))
    printf("Provider 'foo' buildinfo: %s\n", build);
else
    ERR_print_errors_fp(stderr);
