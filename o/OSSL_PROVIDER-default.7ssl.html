NOM

OSSL_PROVIDER-default - Fournisseur par défaut d'OpenSSL

DESCRIPTION

Le fournisseur par défaut d'OpenSSL fournit la majorité des implémentations d'algorithmes diverses d'OpenSSL. Si une application ne spécifie rien d'autre explicitement (par exemple dans l'application ou via la configuration), alors c'est ce fournisseur qui sera utilisé comme solution de repli : il est chargé automatiquement la première fois qu'un algorithme est récupéré d'un fournisseur ou qu'une fonction agissant sur des fournisseurs est appelée et qu'aucun autre fournisseur n'a encore été chargé.

Si une tentative de chargement d'un fournisseur a déjà été effectuée (qu'elle ait réussi ou non), le fournisseur par défaut ne sera pas chargé automatiquement. Par conséquent, si le fournisseur par défaut doit être utilisé conjointement avec d'autres fournisseurs, il doit être chargé explicitement. Le chargement automatique du fournisseur par défaut ne se produit qu'une seule fois au maximum ; si le fournisseur par défaut est explicitement déchargé, il ne sera pas rechargé automatiquement.

Propriétés

Les implémentations de ce fournisseur ont spécifiquement cette propriété définie :

"provider=default"

Elle peut être utilisée dans une chaîne de requête de propriétés avec des fonctions de récupération telles que EVP_MD_fetch(3) ou EVP_CIPHER_fetch(3), ainsi qu'avec d'autres fonctions qui acceptent une chaîne de requête de propriétés, telle que EVP_PKEY_CTX_new_from_name(3).

Il n'est pas obligatoire de rechercher cette propriété, sauf pour s'assurer d'obtenir les implémentations de ce fournisseur et aucune autre.

Certaines implémentations peuvent définir des propriétés supplémentaires. Les informations exactes sont listées ci-dessous

HISTORIQUE

L'algorithme RIPEMD160 a été ajouté au fournisseur par défaut dans OpenSSL 3.0.7.

Les algorithmes HKDF-SHA256, HKDF-SHA384 et HKDF-SHA512 ont été ajoutés dans OpenSSL 3.6.

Toutes les autres fonctionnalités ont été ajoutées dans OpenSSL 3.0.
