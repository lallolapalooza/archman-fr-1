OPENSSL_FILE(3ssl)

Paquet: openssl

Licences: Apache-2.0

OPENSSL_FILE(3ssl) OpenSSL OPENSSL_FILE(3ssl)

NOM

OPENSSL_FILE, OPENSSL_LINE, OPENSSL_FUNC, OPENSSL_MSTR, OPENSSL_MSTR_HELPER - macros utilitaires génériques de programmation C

SYNTAXE

#include <openssl/macros.h>
#define OPENSSL_FILE /* typiquement : __FILE__ */
#define OPENSSL_LINE /* typiquement : __LINE__ */
#define OPENSSL_FUNC /* typiquement : __func__ */
#define OPENSSL_MSTR_HELPER(x) #x
#define OPENSSL_MSTR(x) OPENSSL_MSTR_HELPER(x)

DESCRIPTION

Les macros OPENSSL_FILE et OPENSSL_LINE renvoient généralement le nom du fichier et le numéro de ligne actuels lors de la compilation C. Lorsque OPENSSL_NO_FILENAMES est défini, elles renvoient "" et 0, respectivement.

La macro OPENSSL_FUNC tente de renvoyer le nom de la fonction C en cours de compilation, dans la mesure où les versions du langage et du compilateur le permettent. Sinon, elle renvoie "(fonction inconnue)".

La macro OPENSSL_MSTR renvoie le développement de la macro donnée en argument, ce qui est utile pour la concaténation avec des constantes de chaîne. La macro OPENSSL_MSTR_HELPER est une macro auxiliaire à cet effet.
