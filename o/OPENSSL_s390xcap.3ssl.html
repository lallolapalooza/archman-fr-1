NOM

OPENSSL_s390xcap - le vecteur de capacités du processeur z d'IBM

SYNTAXE

env OPENSSL_s390xcap=... <application>

DESCRIPTION

libcrypto prend en charge les extensions d'ensemble d'instructions z/Architecture. Ces extensions sont désignées par des bits individuels dans le vecteur de capacités. Lors de l'initialisation de libcrypto, les bits renvoyés par l'instruction STFLE et par les fonctions QUERY sont stockés dans le vecteur.

Pour modifier l'ensemble d'instructions disponible pour un programme, vous pouvez définir la variable d'environnement OPENSSL_s390xcap avant de lancer le programme. Après initialisation, le vecteur de capacités est logiquement combiné par un AND avec un masque dérivé de la variable d'environnement.

La variable d'environnement est une liste de jetons séparés par des points-virgules, traités de gauche à droite (les espaces blancs sont ignorés) :

OPENSSL_s390xcap="<jeton1>;<jeton2>;…"

Il existe quatre types de jetons :

<chaîne>
Le nom d'une génération de processeur. Un bit dans le masque de la variable d'environnement est défini sur 1 si et seulement si la génération de processeur spécifiée implémente l'extension d'instruction correspondante. Les valeurs possibles sont z900, z990, z9, z10, z196, zEC12, z13, z14, z15, z16 et z17.
<chaîne>:<masque>:<masque>
Le nom d'une instruction suivi de deux masques de 64 bits. La partie du masque de la variable d'environnement correspondant à l'instruction spécifiée est définie sur le masque de 128 bits spécifié. Les valeurs possibles sont kimd, klmd, km, kmc, kmac, kmctr, kmo, kmf, prno, kma, pcc et kdsa.
stfle:<masque>:<masque>:<masque>
Store-facility-list-extended (stfle) suivi de trois masques de 64 bits. La partie du masque de la variable d'environnement correspondant à l'instruction stfle est définie sur le masque de 192 bits spécifié.
nocex
Désactive le déploiement de l'exponentiation modulaire et des opérations CRT sur les adaptateurs Crypto Express.

Les masques de 64 bits sont spécifiés en notation hexadécimale. Le préfixe 0x est facultatif. Préfixez un masque avec un tilde, "~", pour désigner une opération NOT logique.

VALEURS DE RETOUR

Non disponible.

EXEMPLES

Désactiver toutes les extensions d'instruction que le processeur z196 n'implémente pas :

OPENSSL_s390xcap="z196"

Désactiver la fonctionnalité vectorielle :

OPENSSL_s390xcap="stfle:~0:~0:~0x4000000000000000"

Désactiver les fonctionnalités KM-XTS-AES et KIMD-SHAKE :

OPENSSL_s390xcap="km:~0x2800:~0;kimd:~0xc000000:~0"
