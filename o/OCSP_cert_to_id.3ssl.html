OCSP_cert_to_id(3ssl)

OCSP_cert_to_id(3ssl) OpenSSL OCSP_cert_to_id(3ssl)

NOM

OCSP_cert_to_id, OCSP_cert_id_new, OCSP_CERTID_free, OCSP_id_issuer_cmp, OCSP_id_cmp, OCSP_id_get0_info - Fonctions utilitaires d'identifiant de certificat OCSP

SYNTAXE

#include <openssl/ocsp.h>
OCSP_CERTID *OCSP_cert_to_id(const EVP_MD *dgst,
                             X509 *subject, X509 *issuer);
OCSP_CERTID *OCSP_cert_id_new(const EVP_MD *dgst,
                              X509_NAME *issuerName,
                              ASN1_BIT_STRING *issuerKey,
                              ASN1_INTEGER *serialNumber);
void OCSP_CERTID_free(OCSP_CERTID *id);
int OCSP_id_issuer_cmp(const OCSP_CERTID *a, const OCSP_CERTID *b);
int OCSP_id_cmp(const OCSP_CERTID *a, const OCSP_CERTID *b);
int OCSP_id_get0_info(ASN1_OCTET_STRING **piNameHash, ASN1_OBJECT **pmd,
                      ASN1_OCTET_STRING **pikeyHash,
                      ASN1_INTEGER **pserial, OCSP_CERTID *cid);

DESCRIPTION

OCSP_cert_to_id() crée et retourne une nouvelle structure OCSP_CERTID en utilisant le digest de message dgst pour le certificat subject avec l'émetteur issuer. Si dgst est NULL, SHA1 est utilisé.

OCSP_cert_id_new() crée et retourne une nouvelle OCSP_CERTID en utilisant dgst, le nom de l'émetteur issuerName, le hash de la clé de l'émetteur issuerKey et le numéro de série serialNumber.

OCSP_CERTID_free() libère id. Si l'argument est NULL, rien n'est fait.

OCSP_id_cmp() compare OCSP_CERTID a et b.

OCSP_id_issuer_cmp() compare uniquement le nom de l'émetteur de OCSP_CERTID a et b.

OCSP_id_get0_info() retourne le hash du nom de l'émetteur, l'OID du hash, le hash de la clé de l'émetteur et le numéro de série contenus dans cid. Si certaines des valeurs ne sont pas requises, le paramètre correspondant peut être mis à NULL.

VALEUR DE RETOUR

OCSP_cert_to_id() et OCSP_cert_id_new() retournent soit un pointeur vers une structure OCSP_CERTID valide, soit NULL en cas d'erreur.

OCSP_id_cmp() et OCSP_id_issuer_cmp() retournent zéro en cas de correspondance et une valeur non nulle sinon.

OCSP_CERTID_free() ne retourne pas de valeur.

OCSP_id_get0_info() retourne 1 en cas de succès et 0 en cas d'échec.

NOTES

Les clients OCSP n'utiliseront généralement que OCSP_cert_to_id() ou OCSP_cert_id_new() : les autres fonctions sont utilisées par les applications de réponse.

Les valeurs retournées par OCSP_id_get0_info() sont des pointeurs internes et NE DOIVENT PAS être libérées par une application : elles seront libérées lorsque la structure OCSP_CERTID correspondante sera libérée.
