OSSL_STORE_EXPECT(3ssl) OpenSSL OSSL_STORE_EXPECT(3ssl)

NOM

OSSL_STORE_expect, OSSL_STORE_supports_search, OSSL_STORE_find - Spécifier le type d'objet attendu

SYNTAXE

#include <openssl/store.h>
int OSSL_STORE_expect(OSSL_STORE_CTX *ctx, int expected_type);
int OSSL_STORE_supports_search(OSSL_STORE_CTX *ctx, int criterion_type);
int OSSL_STORE_find(OSSL_STORE_CTX *ctx, OSSL_STORE_SEARCH *search);

DESCRIPTION

OSSL_STORE_expect() aide les applications à filtrer ce que OSSL_STORE_load() retourne en spécifiant un type OSSL_STORE_INFO. Par défaut, aucune attente sur les types d'objets à charger n'est faite. expected_type peut être 0 pour indiquer explicitement qu'aucune attente n'est faite, ou il peut s'agir de l'un des types d'objets connus (voir "OBJETS PRIS EN CHARGE" dans OSSL_STORE_INFO(3)) à l'exception de OSSL_STORE_INFO_NAME. Par exemple, si "file:/foo/bar/store.pem" contient plusieurs objets de types différents et que seuls les certificats sont intéressants, l'application peut simplement indiquer qu'elle attend le type OSSL_STORE_INFO_CERT.

OSSL_STORE_find() aide les applications à spécifier un critère pour une recherche plus fine des objets.

OSSL_STORE_supports_search() vérifie si le chargeur du contexte OSSL_STORE donné prend en charge le type de recherche donné. Voir "TYPES DE CRITÈRES PRIS EN CHARGE" dans OSSL_STORE_SEARCH(3) pour des informations sur les types de critères de recherche pris en charge.

OSSL_STORE_expect() et OSSL_STORE_find doivent être appelés avant le premier OSSL_STORE_load() d'une session donnée, sinon ils échoueront.

NOTES

Si un filtre plus élaboré est requis par l'application, un meilleur choix serait d'utiliser une fonction de post-traitement. Voir OSSL_STORE_open(3) pour plus d'informations.

Cependant, certains chargeurs peuvent tirer parti de la connaissance d'un type attendu pour rendre la récupération des objets plus efficace, donc si un seul type est attendu, cette méthode est généralement préférable.

VALEURS DE RETOUR

OSSL_STORE_expect() retourne 1 en cas de succès, ou 0 en cas d'échec.

OSSL_STORE_supports_search() retourne 1 si le critère est pris en charge, ou 0 sinon.

OSSL_STORE_find() retourne 1 en cas de succès, ou 0 en cas d'échec.

VOIR AUSSI

ossl_store(7), OSSL_STORE_INFO(3), OSSL_STORE_SEARCH(3), OSSL_STORE_load(3)

HISTORIQUE

OSSL_STORE_expect(), OSSL_STORE_supports_search() et OSSL_STORE_find() ont été ajoutés dans OpenSSL 1.1.1.
