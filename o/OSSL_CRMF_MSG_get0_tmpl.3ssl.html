DESCRIPTION

OSSL_CRMF_MSG_get0_tmpl() récupère le modèle de certificat de crm.

OSSL_CRMF_CERTTEMPLATE_get0_publicKey() récupère la clé publique du modèle de certificat tmpl.

OSSL_CRMF_CERTTEMPLATE_get0_subject() récupère le nom du sujet du modèle de certificat tmpl.

OSSL_CRMF_CERTTEMPLATE_get0_issuer() récupère le nom de l'émetteur du modèle de certificat tmpl.

OSSL_CRMF_CERTTEMPLATE_get0_serialNumber() récupère le numéro de série du modèle de certificat tmpl.

OSSL_CRMF_CERTTEMPLATE_get0_extensions() récupère les extensions X.509 du modèle de certificat tmpl, ou NULL s'il n'est pas présent.

OSSL_CRMF_CERTID_get0_serialNumber récupère le numéro de série du CertId cid.

OSSL_CRMF_CERTID_get0_issuer récupère le nom de l'émetteur du CertId cid, qui doit être de type ASN.1 GEN_DIRNAME.

OSSL_CRMF_ENCRYPTEDKEY_get1_encCert() déchiffre le certificat donné dans la clé privée pkey, avec le contexte de bibliothèque libctx et la requête de propriété propq (voir OSSL_LIB_CTX(3)). Ceci est nécessaire pour la méthode POPO indirecte comme dans RFC 4210 section 5.2.8.2. La fonction retourne le certificat déchiffré sous forme de copie, laissant sa propriété à l'appelant, qui est responsable de sa libération.

OSSL_CRMF_ENCRYPTEDKEY_get1_pkey() déchiffre la clé privée dans encryptedKey. Si encryptedKey n'est pas de type OSSL_CRMF_ENCRYPTEDKEY_ENVELOPEDDATA, elle la déchiffre avec la clé privée pkey. Le contexte de bibliothèque libctx et la requête de propriété propq sont utilisés normalement. Le reste de ce paragraphe n'est pertinent que si le support CMS n'est pas désactivé dans la compilation d'OpenSSL et que encryptedKey est de type OSSL_CRMF_ENCRYPTEDKEY_ENVELOPEDDATA. Elle la déchiffre avec le paramètre secret s'il n'est pas NULL ; sinon, elle utilise la clé privée pkey et le certificat cert associé à pkey, où cert est recommandé de le passer s'il est disponible. En cas de succès, il vérifie les données déchiffrées comme données signées, en utilisant le magasin de confiance ts et tous les certificats non fiables dans extra. Ceci vérifie dans le but "CMP Key Generation Authority" (cmKGA).

OSSL_CRMF_ENCRYPTEDKEY_init_envdata() renvoie OSSL_CRMF_ENCRYPTEDKEY, initialisé avec les données enveloppées envdata.

OSSL_CRMF_ENCRYPTEDVALUE_decrypt() déchiffre la valeur chiffrée dans enc, en utilisant la clé privée pkey, le contexte de bibliothèque libctx et la requête de propriété propq (voir OSSL_LIB_CTX(3)).

OSSL_CRMF_ENCRYPTEDVALUE_get1_encCert() déchiffre le certificat dans ecert, en utilisant la clé privée pkey, le contexte de bibliothèque libctx et la requête de propriété propq (voir OSSL_LIB_CTX(3)). Ceci est nécessaire pour la méthode POPO indirecte comme dans RFC 4210 section 5.2.8.2. La fonction retourne le certificat déchiffré sous forme de copie, laissant sa propriété à l'appelant, qui est responsable de sa libération.

OSSL_CRMF_MSG_get_certReqId() récupère l'identifiant de la demande de certificat crm.

OSSL_CRMF_MSG_centralkeygen_requested() renvoie 1 si la génération de clé centrale est demandée, c'est-à-dire si la clé publique dans la demande de certificat (crm est pris si non NULL, sinon p10cr) est NULL ou a une valeur de clé vide (de longueur zéro). Dans le cas où crm n'est pas NULL, il est vérifié pour la cohérence avec son champ popo (doit être NULL si et seulement si la génération de clé centrale est demandée). Sinon, il renvoie 0, et en cas d'erreur, il renvoie une valeur négative.

VALEUR DE RETOUR

OSSL_CRMF_MSG_get_certReqId() renvoie l'identifiant de la demande de certificat sous forme d'un nombre non négatif ou -1 en cas d'erreur.

OSSL_CRMF_MSG_centralkeygen_requested() renvoie 1 si la génération de clé centrale est demandée, 0 si elle n'est pas demandée, et une valeur négative en cas d'erreur.

Toutes les autres fonctions renvoient un pointeur avec le résultat attendu ou NULL en cas d'erreur.

VOIR AUSSI

RFC 4211

HISTORIQUE

La prise en charge de CRMF dans OpenSSL a été ajoutée dans OpenSSL 3.0.

OSSL_CRMF_CERTTEMPLATE_get0_publicKey() a été ajouté dans OpenSSL 3.2.

OSSL_CRMF_ENCRYPTEDKEY_get1_encCert(), OSSL_CRMF_ENCRYPTEDKEY_get1_pkey(), OSSL_CRMF_ENCRYPTEDKEY_init_envdata(), OSSL_CRMF_ENCRYPTEDVALUE_decrypt() et OSSL_CRMF_MSG_centralkeygen_requested() ont été ajoutés dans OpenSSL 3.5.
