OSSL_DECODER(3ssl) OpenSSL OSSL_DECODER(3ssl)

NOM

OSSL_DECODER, OSSL_DECODER_fetch, OSSL_DECODER_up_ref, OSSL_DECODER_free, OSSL_DECODER_get0_provider, OSSL_DECODER_get0_properties, OSSL_DECODER_is_a, OSSL_DECODER_get0_name, OSSL_DECODER_get0_description, OSSL_DECODER_do_all_provided, OSSL_DECODER_names_do_all, OSSL_DECODER_gettable_params, OSSL_DECODER_get_params - Routines de méthodes de décodeur

SYNOPSIS

#include <openssl/decoder.h>
typedef struct ossl_decoder_st OSSL_DECODER;
OSSL_DECODER *OSSL_DECODER_fetch(OSSL_LIB_CTX *ctx, const char *name,
                                 const char *properties);
int OSSL_DECODER_up_ref(OSSL_DECODER *decoder);
void OSSL_DECODER_free(OSSL_DECODER *decoder);
const OSSL_PROVIDER *OSSL_DECODER_get0_provider(const OSSL_DECODER *decoder);
const char *OSSL_DECODER_get0_properties(const OSSL_DECODER *decoder);
int OSSL_DECODER_is_a(const OSSL_DECODER *decoder, const char *name);
const char *OSSL_DECODER_get0_name(const OSSL_DECODER *decoder);
const char *OSSL_DECODER_get0_description(const OSSL_DECODER *decoder);
void OSSL_DECODER_do_all_provided(OSSL_LIB_CTX *libctx,
                                  void (*fn)(OSSL_DECODER *decoder, void *arg),
                                  void *arg);
int OSSL_DECODER_names_do_all(const OSSL_DECODER *decoder,
                              void (*fn)(const char *name, void *data),
                              void *data);
const OSSL_PARAM *OSSL_DECODER_gettable_params(OSSL_DECODER *decoder);
int OSSL_DECODER_get_params(OSSL_DECODER_CTX *ctx, const OSSL_PARAM params[]);

DESCRIPTION

OSSL_DECODER est une méthode pour les décodeurs, qui savent comment décoder des données encodées dans un objet d'un certain type que le reste d'OpenSSL sait gérer.

OSSL_DECODER_fetch() recherche un algorithme dans le fournisseur qui a été chargé dans le OSSL_LIB_CTX donné par ctx, ayant le nom donné par name et les propriétés données par properties. Le name détermine quel type d'objet la méthode de décodeur récupérée est censée pouvoir décoder, et les propriétés sont utilisées pour déterminer le type de sortie attendu. Pour les propriétés connues et les valeurs qu'elles peuvent avoir, veuillez consulter "Noms et propriétés" dans provider-encoder(7).

OSSL_DECODER_up_ref() incrémente le compteur de références pour le decoder donné.

OSSL_DECODER_free() décrémente le compteur de références pour le decoder donné, et lorsque le compteur atteint zéro, le libère. Si l'argument est NULL, rien n'est fait.

OSSL_DECODER_get0_provider() renvoie le fournisseur du decoder donné.

OSSL_DECODER_get0_properties() renvoie la définition de propriétés associée au decoder donné.

OSSL_DECODER_is_a() vérifie si decoder est une implémentation d'un algorithme identifiable par name.

OSSL_DECODER_get0_name() renvoie le nom utilisé pour récupérer le decoder donné.

OSSL_DECODER_get0_description() renvoie une description du decoder, destinée à l'affichage et à la consommation humaine. La description est à la discrétion de l'implémentation du decoder.

OSSL_DECODER_names_do_all() parcourt tous les noms du decoder donné, et appelle fn avec chaque nom et data comme arguments.

OSSL_DECODER_do_all_provided() parcourt toutes les implémentations de décodeurs par tous les fournisseurs activés dans le contexte de bibliothèque libctx, et pour chacune des implémentations, appelle fn avec la méthode d'implémentation et arg comme arguments.

OSSL_DECODER_gettable_params() renvoie un tableau d'OSSL_PARAM(3) de descripteurs de paramètres.

OSSL_DECODER_get_params() tente de récupérer les paramètres spécifiés avec un tableau d'OSSL_PARAM(3) params. Les paramètres que l'implémentation ne reconnaît pas doivent être ignorés.

VALEURS DE RETOUR

OSSL_DECODER_fetch() renvoie un pointeur vers un objet OSSL_DECODER, ou NULL en cas d'erreur.

OSSL_DECODER_up_ref() renvoie 1 en cas de succès, ou 0 en cas d'erreur.

OSSL_DECODER_free() ne renvoie aucune valeur.

OSSL_DECODER_get0_provider() renvoie un pointeur vers un objet fournisseur, ou NULL en cas d'erreur.

OSSL_DECODER_get0_properties() renvoie un pointeur vers une chaîne de définition de propriétés, ou NULL en cas d'erreur.

OSSL_DECODER_is_a() renvoie 1 si decoder était identifiable, sinon 0.

OSSL_DECODER_get0_name() renvoie le nom de l'algorithme à partir de l'implémentation fournie pour le decoder donné. Notez que le decoder peut avoir plusieurs synonymes associés. Dans ce cas, le premier nom de la définition de l'algorithme est renvoyé. La propriété de la chaîne renvoyée est conservée par l'objet decoder et ne doit pas être libérée par l'appelant.

OSSL_DECODER_get0_description() renvoie un pointeur vers une description, ou NULL s'il n'y en a pas.

OSSL_DECODER_names_do_all() renvoie 1 si la fonction de rappel a été appelée pour tous les noms. Une valeur de retour de 0 signifie que la fonction de rappel n'a été appelée pour aucun nom.

NOTES

OSSL_DECODER_fetch() peut être appelé implicitement par d'autres fonctions de récupération, en utilisant le même contexte de bibliothèque et les mêmes propriétés. Toute autre API qui utilise des clés fera typiquement cela.

EXEMPLES

Pour lister tous les décodeurs d'un fournisseur dans un bio_out :

static void collect_decoders(OSSL_DECODER *decoder, void *stack)
{
    STACK_OF(OSSL_DECODER) *decoder_stack = stack;
    sk_OSSL_DECODER_push(decoder_stack, decoder);
    OSSL_DECODER_up_ref(decoder);
}
void print_name(const char *name, void *vdata)
{
    BIO *bio = vdata;
    BIO_printf(bio, "%s ", name);
}
STACK_OF(OSSL_DECODER) *decoders;
int i;
decoders = sk_OSSL_DECODER_new_null();
BIO_printf(bio_out, "DECODERs provided by %s:\n", provider);
OSSL_DECODER_do_all_provided(NULL, collect_decoders,
                             decoders);
for (i = 0; i < sk_OSSL_DECODER_num(decoders); i++) {
    OSSL_DECODER *decoder = sk_OSSL_DECODER_value(decoders, i);
    if (strcmp(OSSL_PROVIDER_get0_name(OSSL_DECODER_get0_provider(decoder)),
               provider) != 0)
        continue;
    if (OSSL_DECODER_names_do_all(decoder, print_name, bio_out))
           BIO_printf(bio_out, "\n");
}
sk_OSSL_DECODER_pop_free(decoders, OSSL_DECODER_free);

NAME

ossl_decoder - OpenSSL decoder interface

SYNOPSIS

#include <openssl/decoder.h>

DESCRIPTION

The OSSL_DECODER API provides a mechanism to decode data structures from a given format into an internal OpenSSL representation. This is typically used for loading keys, certificates, and other cryptographic objects from various file formats like PEM or DER.

The core of the API revolves around the OSSL_DECODER structure, which represents a decoder object. Decoders are obtained through functions like OSSL_DECODER_fetch, which finds and initializes a decoder based on specified criteria (e.g., object type, format).

Once a decoder is obtained, data can be decoded using functions like OSSL_DECODER_decode. This function takes the decoder, the input data (as an OSSL_PROVIDER_CTX or similar), and an optional configuration object. It produces a decoded object, which can then be used by other parts of OpenSSL.

The process generally involves:

  1. Identifying the type of object to decode (e.g., a private key, a certificate).
  2. Specifying the desired input format (e.g., PEM, DER).
  3. Fetching an appropriate decoder using OSSL_DECODER_fetch.
  4. Providing the encoded data to the decoder using OSSL_DECODER_decode.
  5. Freeing the decoder and any allocated resources when done.

RETURN VALUES

Functions within the OSSL_DECODER API return values indicating success or failure. Typically, success is indicated by a non-NULL pointer or a return value of 1, while failure is indicated by NULL or 0, respectively. Error details can be retrieved using ERR_get_error.

NOTES

The OSSL_DECODER API is part of the OpenSSL provider framework. Decoders are implemented by OpenSSL providers. To use a specific decoder, the corresponding provider must be loaded and available.

The API is designed to be extensible, allowing new formats and object types to be supported by adding new providers or updating existing ones.

EXAMPLES

The following is a simplified example of how one might decode a private key from PEM format:

#include <openssl/decoder.h>
#include <openssl/evp.h>
#include <openssl/pem.h>
#include <openssl/err.h>

// ... assume key_data is a buffer containing PEM encoded private key ...
// ... assume key_len is the length of key_data ...

OSSL_DECODER *decoder = NULL;
OSSL_DECODER_CTX *decoder_ctx = NULL;
EVP_PKEY *pkey = NULL;
OSSL_PARAM params[2];

// Fetch a decoder for a private key in PEM format
decoder = OSSL_DECODER_fetch(NULL, "privatekey", "pem");
if (decoder == NULL) {
    // Handle error
    goto err;
}

// Set up parameters for decoding
params[0] = OSSL_PARAM_construct_utf8_string("input", (char *)key_data, key_len);
params[1] = OSSL_PARAM_construct_end();

// Create a decoder context and decode
decoder_ctx = OSSL_DECODER_CTX_new(decoder, NULL, NULL, NULL, NULL);
if (decoder_ctx == NULL) {
    // Handle error
    goto err;
}

pkey = OSSL_DECODER_decode_object(decoder_ctx, params);
if (pkey == NULL) {
    // Handle error
    goto err;
}

// Use the decoded EVP_PKEY object...

err:
    OSSL_DECODER_free(decoder);
    OSSL_DECODER_CTX_free(decoder_ctx);
    EVP_PKEY_free(pkey); // If an error occurred before pkey was assigned
    // Handle OpenSSL errors...
    return 0; // Or appropriate return code
