OSSL_STORE_ATTACH(3ssl) OpenSSL OSSL_STORE_ATTACH(3ssl)

NOM

OSSL_STORE_attach - Fonctions pour lire des objets depuis un BIO

SYNTAXE

#include <openssl/store.h>
OSSL_STORE_CTX *OSSL_STORE_attach(BIO *bio, const char *scheme,
                                  OSSL_LIB_CTX *libctx, const char *propq,
                                  const UI_METHOD *ui_method, void *ui_data,
                                  const OSSL_PARAM params[],
                                  OSSL_STORE_post_process_info_fn post_process,
                                  void *post_process_data);

DESCRIPTION

OSSL_STORE_attach() fonctionne comme OSSL_STORE_OPEN(3), sauf qu'elle prend un BIO bio au lieu d'un uri, ainsi qu'un scheme pour déterminer quel chargeur doit être utilisé pour traiter les données. Le compteur de références de l'objet BIO est augmenté de 1 si l'appel réussit.

VALEURS DE RETOUR

OSSL_STORE_attach() retourne un pointeur vers un OSSL_STORE_CTX en cas de succès, ou NULL en cas d'échec.

VOIR AUSSI

ossl_store(7), OSSL_STORE_OPEN(3)

HISTORIQUE

OSSL_STORE_attach() a été ajoutée dans OpenSSL 3.0.
