NOM

OSSL_PROVIDER-base - Fournisseur de base d'OpenSSL

DESCRIPTION

Le fournisseur de base d'OpenSSL fournit le chiffrement pour le chiffrement asymétrique d'OpenSSL.

Propriétés

Les implémentations de ce fournisseur ont spécifiquement cette propriété définie :

"provider=base"

Elle peut être utilisée dans une chaîne de propriétés pour interroger les fonctions de récupération.

Il n'est pas obligatoire d'interroger cette propriété, sauf pour s'assurer d'obtenir des implémentations de ce fournisseur et aucune autre.

"type=parameters"
"type=private"
"type=public"

Elles peuvent être utilisées dans une chaîne de propriétés pour interroger les fonctions de récupération afin de sélectionner les données à chiffrer. Le matériel de clé privée, le matériel de clé publique ou les paramètres de domaine peuvent être sélectionnés.

"format=der"
"format=pem"
"format=text"

Elles peuvent être utilisées dans une chaîne de propriétés pour interroger les fonctions de récupération afin de sélectionner le format de sortie du chiffrement. DER, PEM et text sont actuellement autorisés.

OPÉRATIONS ET ALGORITHMES

Le fournisseur de base d'OpenSSL prend en charge ces opérations et algorithmes :

Génération de nombres aléatoires

SEED-SRC, voir EVP_RAND-SEED-SRC(7)
JITTER, voir EVP_RAND-JITTER(7)

En plus du fournisseur lui-même, les algorithmes SEED-SRC et JITTER sont également disponibles dans le fournisseur par défaut.
