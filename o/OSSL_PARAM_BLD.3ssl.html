OSSL_PARAM_BLD(3ssl)

OSSL_PARAM_BLD(3ssl) OpenSSL OSSL_PARAM_BLD(3ssl)

NOM

OSSL_PARAM_BLD, OSSL_PARAM_BLD_new, OSSL_PARAM_BLD_to_param, OSSL_PARAM_BLD_free, OSSL_PARAM_BLD_push_int, OSSL_PARAM_BLD_push_uint, OSSL_PARAM_BLD_push_long, OSSL_PARAM_BLD_push_ulong, OSSL_PARAM_BLD_push_int32, OSSL_PARAM_BLD_push_uint32, OSSL_PARAM_BLD_push_int64, OSSL_PARAM_BLD_push_uint64, OSSL_PARAM_BLD_push_size_t, OSSL_PARAM_BLD_push_time_t, OSSL_PARAM_BLD_push_double, OSSL_PARAM_BLD_push_BN, OSSL_PARAM_BLD_push_BN_pad, OSSL_PARAM_BLD_push_utf8_string, OSSL_PARAM_BLD_push_utf8_ptr, OSSL_PARAM_BLD_push_octet_string, OSSL_PARAM_BLD_push_octet_ptr - fonctions pour aider à la création de tableaux de OSSL_PARAM

SYNOPIS

#include <openssl/param_build.h>
typedef struct OSSL_PARAM_BLD;
OSSL_PARAM_BLD *OSSL_PARAM_BLD_new(void);
OSSL_PARAM *OSSL_PARAM_BLD_to_param(OSSL_PARAM_BLD *bld);
void OSSL_PARAM_BLD_free(OSSL_PARAM_BLD *bld);
int OSSL_PARAM_BLD_push_TYPE(OSSL_PARAM_BLD *bld, const char *key, TYPE val);
int OSSL_PARAM_BLD_push_BN(OSSL_PARAM_BLD *bld, const char *key,
                           const BIGNUM *bn);
int OSSL_PARAM_BLD_push_BN_pad(OSSL_PARAM_BLD *bld, const char *key,
                               const BIGNUM *bn, size_t sz);
int OSSL_PARAM_BLD_push_utf8_string(OSSL_PARAM_BLD *bld, const char *key,
                                    const char *buf, size_t bsize);
int OSSL_PARAM_BLD_push_utf8_ptr(OSSL_PARAM_BLD *bld, const char *key,
                                 char *buf, size_t bsize);
int OSSL_PARAM_BLD_push_octet_string(OSSL_PARAM_BLD *bld, const char *key,
                                     const void *buf, size_t bsize);
int OSSL_PARAM_BLD_push_octet_ptr(OSSL_PARAM_BLD *bld, const char *key,
                                  void *buf, size_t bsize);

DESCRIPTION

Une collection de fonctions utilitaires qui simplifient la création de tableaux de OSSL_PARAM. Les noms de TYPE sont conformes à OSSL_PARAM_int(3).

OSSL_PARAM_BLD_new() alloue et initialise une nouvelle structure OSSL_PARAM_BLD, de sorte que des valeurs puissent y être ajoutées. Les valeurs existantes sont nettoyées.

OSSL_PARAM_BLD_free() libère l'espace alloué par OSSL_PARAM_BLD_new(). Si l'argument est NULL, rien n'est fait.

OSSL_PARAM_BLD_to_param() convertit une structure OSSL_PARAM_BLD bld en un tableau d'OSSL_PARAM alloué. Le tableau d'OSSL_PARAM et tous les espaces associés doivent être libérés en appelant OSSL_PARAM_free() avec la valeur retournée par la fonction. OSSL_PARAM_BLD_free() peut être appelée à tout moment après cette fonction.

OSSL_PARAM_BLD_push_TYPE() est une série de fonctions qui créeront des objets OSSL_PARAM de taille et de type corrects pour l'argument val. val est stocké par valeur et une expression ou une variable automatique peut être utilisée.

Lorsque TYPE désigne un type entier, les types entiers signés obtiennent normalement le type OSSL_PARAM OSSL_PARAM_INTEGER. Lorsque TYPE désigne un type entier non signé, il obtient le type OSSL_PARAM OSSL_PARAM_UNSIGNED_INTEGER.

OSSL_PARAM_BLD_push_BN() est une fonction qui créera un objet OSSL_PARAM contenant le nombre entier spécifié par bn. Lorsque bn est zéro ou positif, son type OSSL_PARAM sera OSSL_PARAM_UNSIGNED_INTEGER. Lorsque bn est négatif, son type OSSL_PARAM sera OSSL_PARAM_INTEGER. Si bn est marqué comme étant stocké en toute sécurité, sa représentation OSSL_PARAM sera également stockée en toute sécurité. L'argument bn est stocké par référence et l'objet BIGNUM sous-jacent doit exister jusqu'à ce que OSSL_PARAM_BLD_to_param() ait été appelé.

OSSL_PARAM_BLD_push_BN_pad() est une fonction qui créera un objet OSSL_PARAM contenant le nombre entier spécifié par bn. L'objet sera rempli pour occuper exactement sz octets, et s'il n'y a pas assez de place, une erreur sera générée. Lorsque bn est zéro ou positif, son type OSSL_PARAM sera OSSL_PARAM_UNSIGNED_INTEGER. Lorsque bn est négatif, son type OSSL_PARAM sera OSSL_PARAM_INTEGER. Si bn est marqué comme étant stocké en toute sécurité, sa représentation OSSL_PARAM sera également stockée en toute sécurité. L'argument bn est stocké par référence et l'objet BIGNUM sous-jacent doit exister jusqu'à ce que OSSL_PARAM_BLD_to_param() ait été appelé.

OSSL_PARAM_BLD_push_utf8_string() est une fonction qui créera un objet OSSL_PARAM référençant la chaîne UTF8 spécifiée par buf. La longueur de la chaîne bsize ne doit pas inclure le caractère nul de fin. Si elle est zéro, elle sera calculée automatiquement. La chaîne référencée par buf est stockée par référence et doit être conservée dans le scope jusqu'à ce que OSSL_PARAM_BLD_to_param() ait été appelé.

OSSL_PARAM_BLD_push_octet_string() est une fonction qui créera un objet OSSL_PARAM référençant la chaîne d'octets spécifiée par buf et bsize. L'espace référencé par buf est stocké par référence et doit être conservé dans le scope jusqu'à ce que OSSL_PARAM_BLD_to_param() ait été appelé.

OSSL_PARAM_BLD_push_utf8_ptr() est une fonction qui créera un objet OSSL_PARAM référençant la chaîne UTF8 spécifiée par buf. La longueur de la chaîne bsize ne doit pas inclure le caractère nul de fin. Si elle est zéro, elle sera calculée automatiquement. La chaîne référencée par buf est stockée par référence et doit être conservée dans le scope jusqu'à ce que OSSL_PARAM_BLD_to_param() ait été appelé.

OSSL_PARAM_BLD_push_octet_ptr() est une fonction qui créera un objet OSSL_PARAM référençant la chaîne d'octets spécifiée par buf. L'espace référencé par buf est stocké par référence et doit être conservé dans le scope jusqu'à ce que OSSL_PARAM_BLD_to_param() ait été appelé.

VALEURS DE RETOUR

OSSL_PARAM_BLD_new() retourne la structure OSSL_PARAM_BLD allouée, ou NULL en cas d'erreur.

OSSL_PARAM_BLD_to_param() retourne le tableau d'OSSL_PARAM alloué, ou NULL en cas d'erreur.

Toutes les fonctions OSSL_PARAM_BLD_push_TYPE retournent 1 en cas de succès et 0 en cas d'erreur.

NOTES

OSSL_PARAM_BLD_push_BN() et OSSL_PARAM_BLD_push_BN_pad() ne prennent en charge que les nombres entiers non négatifs. Ils retournent une erreur lorsque le nombre entier est négatif. Pour passer des nombres entiers négatifs, utilisez OSSL_PARAM_BLD_push_signed_BN().

EXEMPLES

Les deux exemples créent un tableau d'OSSL_PARAM contenant une clé RSA privée. Pour les deux, les variables clés prédéfinies sont :

BIGNUM *n;           /* module */
unsigned int e;      /* exposant public */
BIGNUM *d;           /* exposant privé */
BIGNUM *p, *q;       /* deux premiers facteurs premiers */
BIGNUM *dmp1, *dmq1; /* deux premiers exposants CRT */
BIGNUM *iqmp;        /* premier coefficient CRT

Exemple 1

Cet exemple montre comment créer un tableau d'OSSL_PARAM contenant une clé RSA privée.

OSSL_PARAM_BLD *bld = OSSL_PARAM_BLD_new();
OSSL_PARAM *params = NULL;
if (bld == NULL
    || !OSSL_PARAM_BLD_push_BN(bld, "n", n)
    || !OSSL_PARAM_BLD_push_uint(bld, "e", e)
    || !OSSL_PARAM_BLD_push_BN(bld, "d", d)
    || !OSSL_PARAM_BLD_push_BN(bld, "rsa-factor1", p)
    || !OSSL_PARAM_BLD_push_BN(bld, "rsa-factor2", q)
    || !OSSL_PARAM_BLD_push_BN(bld, "rsa-exponent1", dmp1)
    || !OSSL_PARAM_BLD_push_BN(bld, "rsa-exponent2", dmq1)
    || !OSSL_PARAM_BLD_push_BN(bld, "rsa-coefficient1", iqmp)
    || (params = OSSL_PARAM_BLD_to_param(bld)) == NULL)
    goto err;
OSSL_PARAM_BLD_free(bld);
/* Utiliser params */
...
OSSL_PARAM_free(params);

Exemple 2

Cet exemple montre comment créer un tableau d'OSSL_PARAM contenant une clé RSA publique.

OSSL_PARAM_BLD *bld = OSSL_PARAM_BLD_new();
OSSL_PARAM *params = NULL;
if (nld == NULL
    || !OSSL_PARAM_BLD_push_BN(bld, "n", n)
    || !OSSL_PARAM_BLD_push_uint(bld, "e", e)
    || (params = OSSL_PARAM_BLD_to_param(bld)) == NULL)
    goto err;
OSSL_PARAM_BLD_free(bld);
/* Utiliser params */
...
OSSL_PARAM_free(params);
