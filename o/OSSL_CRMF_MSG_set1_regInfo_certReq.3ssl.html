OSSL_CRMF_MSG_set1_regInfo_certReq(3ssl)

Paquet: openssl

Licences: Apache-2.0

OSSL_CRMF_MSG_SET1_REGINFO_CERTREQ(3ssl) OpenSSL OSSL_CRMF_MSG_SET1_REGINFO_CERTREQ(3ssl)

NOM

OSSL_CRMF_MSG_get0_regInfo_utf8Pairs, OSSL_CRMF_MSG_set1_regInfo_utf8Pairs, OSSL_CRMF_MSG_get0_regInfo_certReq, OSSL_CRMF_MSG_set1_regInfo_certReq - fonctions d'obtention ou de définition des informations d'enregistrement CRMF

SYNOPSIS

#include <openssl/crmf.h>
ASN1_UTF8STRING
    *OSSL_CRMF_MSG_get0_regInfo_utf8Pairs(const OSSL_CRMF_MSG *msg);
int OSSL_CRMF_MSG_set1_regInfo_utf8Pairs(OSSL_CRMF_MSG *msg,
                                         const ASN1_UTF8STRING *utf8pairs);
OSSL_CRMF_CERTREQUEST
    *OSSL_CRMF_MSG_get0_regInfo_certReq(const OSSL_CRMF_MSG *msg);
int OSSL_CRMF_MSG_set1_regInfo_certReq(OSSL_CRMF_MSG *msg,
                                       const OSSL_CRMF_CERTREQUEST *cr);

DESCRIPTION

OSSL_CRMF_MSG_get0_regInfo_utf8Pairs() retourne la première infogroup utf8Pairs dans le msg donné, si elle est présente.

OSSL_CRMF_MSG_set1_regInfo_utf8Pairs() ajoute une copie de la valeur utf8pairs donnée en tant qu'infogroup utf8Pairs au msg donné. Voir RFC 4211 section 7.1.

OSSL_CRMF_MSG_get0_regInfo_certReq() retourne la première infogroup certReq dans le msg donné, si elle est présente.

OSSL_CRMF_MSG_set1_regInfo_certReq() ajoute une copie de la valeur cr donnée en tant qu'infogroup certReq au msg donné. Voir RFC 4211 section 7.2.

VALEURS DE RETOUR

Toutes les fonctions get0_*() retournent la valeur du pointeur respectif, NULL s'il n'est pas présent.

Toutes les fonctions set1_*() retournent 1 en cas de succès, 0 en cas d'erreur.

NOTES

L'appel des fonctions set1_*() plusieurs fois ajoute plusieurs instances du contrôle respectif à la structure regInfo du msg donné. Alors que la RFC 4211 attend plusieurs utf8Pairs dans une structure regInfo, elle n'autorise pas plusieurs certReq.

VOIR AUSSI

RFC 4211

HISTORIQUE

Le support CRMF d'OpenSSL a été ajouté dans OpenSSL 3.0.
