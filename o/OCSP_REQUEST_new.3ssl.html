OCSP_REQUEST_new(3ssl)

Paquet: openssl

OCSP_REQUEST_NEW(3ssl) OpenSSL OCSP_REQUEST_NEW(3ssl)

NOM

OCSP_REQUEST_new, OCSP_REQUEST_free, OCSP_request_add0_id, OCSP_request_sign, OCSP_request_add1_cert, OCSP_request_onereq_count, OCSP_request_onereq_get0 - Fonctions de requête OCSP

SYNTAXE

#include <openssl/ocsp.h>
OCSP_REQUEST *OCSP_REQUEST_new(void);
void OCSP_REQUEST_free(OCSP_REQUEST *req);
OCSP_ONEREQ *OCSP_request_add0_id(OCSP_REQUEST *req, OCSP_CERTID *cid);
int OCSP_request_sign(OCSP_REQUEST *req,
                      X509 *signer, EVP_PKEY *key, const EVP_MD *dgst,
                      STACK_OF(X509) *certs, unsigned long flags);
int OCSP_request_add1_cert(OCSP_REQUEST *req, X509 *cert);
int OCSP_request_onereq_count(OCSP_REQUEST *req);
OCSP_ONEREQ *OCSP_request_onereq_get0(OCSP_REQUEST *req, int i);

DESCRIPTION

OCSP_REQUEST_new() alloue et retourne une structure OCSP_REQUEST vide.

OCSP_REQUEST_free() libère la structure de requête req. Si l'argument est NULL, rien n'est fait.

OCSP_request_add0_id() ajoute l'identifiant de certificat cid à req. Elle retourne la structure OCSP_ONEREQ ajoutée afin qu'une application puisse ajouter des extensions supplémentaires à la requête. Le paramètre id ne doit **PAS** être libéré après l'opération.

OCSP_request_sign() signe la requête OCSP req en utilisant le certificat signer, la clé privée key, le digest dgst et les certificats supplémentaires certs. Si l'option flags OCSP_NOCERTS est définie, aucun certificat ne sera inclus dans la requête.

OCSP_request_add1_cert() ajoute le certificat cert à la requête req. L'application est responsable de libérer cert après utilisation.

OCSP_request_onereq_count() retourne le nombre total de structures OCSP_ONEREQ dans req.

OCSP_request_onereq_get0() retourne un pointeur interne vers l'OCSP_ONEREQ contenu dans req d'indice i. La valeur de l'indice i va de 0 à OCSP_request_onereq_count(req) - 1.

VALEURS DE RETOUR

OCSP_REQUEST_new() retourne une structure OCSP_REQUEST vide ou NULL si une erreur s'est produite.

OCSP_request_add0_id() retourne la structure OCSP_ONEREQ contenant cid ou NULL si une erreur s'est produite.

OCSP_request_sign() et OCSP_request_add1_cert() retournent 1 en cas de succès et 0 en cas d'échec.

OCSP_request_onereq_count() retourne le nombre total de structures OCSP_ONEREQ dans req et -1 en cas d'erreur.

OCSP_request_onereq_get0() retourne un pointeur vers une structure OCSP_ONEREQ ou NULL si l'indice est hors limites.

NOTES

Une structure de requête OCSP contient une ou plusieurs structures OCSP_ONEREQ correspondant à chaque certificat.

OCSP_request_onereq_count() et OCSP_request_onereq_get0() sont principalement utilisées par les répondeurs OCSP.

EXEMPLES

Créer une structure OCSP_REQUEST pour le certificat cert avec l'émetteur issuer :

OCSP_REQUEST *req;
OCSP_ID *cid;
req = OCSP_REQUEST_new();
if (req == NULL)
   /* erreur */
cid = OCSP_cert_to_id(EVP_sha1(), cert, issuer);
if (cid == NULL)
   /* erreur */
if (OCSP_REQUEST_add0_id(req, cid) == NULL)
   /* erreur */
/* Faire quelque chose avec req, par ex. interroger le répondeur */
OCSP_REQUEST_free(req);
