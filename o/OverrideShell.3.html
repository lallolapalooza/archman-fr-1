NAME

OverrideShell - Classe de widgets OverrideShell

SYNOPSIS

#include <Xm/Xm.h>
#include <X11/Shell.h>

DESCRIPTION

OverrideShell est utilisé pour les fenêtres shell qui contournent complètement le gestionnaire de fenêtres, par exemple les fenêtres de menu contextuel.

Classes

OverrideShell hérite du comportement et des ressources de Core, Composite et Shell.

Le pointeur de classe est overrideShellWidgetClass.

Le nom de la classe est OverrideShell.

Nouvelles Ressources

OverrideShell ne définit aucune nouvelle ressource, mais il surcharge les ressources XmNoverrideRedirect et XmNsaveUnder de la classe Shell.

Ressources Héritées

OverrideShell hérite du comportement et des ressources des superclasses suivantes. Pour une description complète de chaque ressource, consultez la page de référence de chaque classe.

Le tableau suivant définit un ensemble de ressources de widget utilisées par le programmeur pour spécifier des données. Le programmeur peut également définir les valeurs des ressources pour les classes héritées afin de configurer les attributs de ce widget. Pour faire référence à une ressource par son nom ou sa classe dans un fichier .Xdefaults, supprimez le préfixe XmN ou XmC et utilisez les caractères restants. Pour spécifier l'une des valeurs définies pour une ressource dans un fichier .Xdefaults, supprimez le préfixe Xm et utilisez les caractères restants (en minuscules ou majuscules, mais incluez les traits d'union entre les mots). Les codes dans la colonne d'accès indiquent si la ressource peut être définie à la création (C), via XtSetValues (S), via XtGetValues (G), ou si elle n'est pas applicable (N/A).

SYNOPSIS

int OverrideShell (int fd, const char *name, const char *path, const char *shell);

DESCRIPTION

La fonction OverrideShell permet de modifier le chemin d'accès à un shell spécifique pour un utilisateur donné. Le paramètre fd est le descripteur de fichier du fichier passwd. Le paramètre name est le nom de l'utilisateur. Le paramètre path est le nouveau chemin d'accès au shell. Le paramètre shell est le nom du shell à modifier.
