DESCRIPTION

Ces fonctions sont principalement utiles pour les applications afin de récupérer les objets pris en charge à partir des objets OSSL_STORE_INFO et pour les chargeurs spécifiques au schéma afin de créer des conteneurs OSSL_STORE_INFO.

Types

OSSL_STORE_INFO est un type opaque qui n'est qu'un conteneur intermédiaire pour les objets qui ont été récupérés par OSSL_STORE_load() et des fonctions similaires. Les objets de type OpenSSL pris en charge peuvent être extraits à l'aide de STORE_INFO_get0_<TYPE>() où <TYPE> peut être NAME, PARAMS, PKEY, CERT ou CRL. La durée de vie de cet objet extrait est aussi longue que la durée de vie de l'objet OSSL_STORE_INFO dont il a été extrait, il faut donc veiller à ne pas libérer ce dernier trop tôt. Alternativement, STORE_INFO_get1_<TYPE>() extrait une copie (ou le même objet dont le compteur de références est augmenté), qui peut être utilisée après que l'objet OSSL_STORE_INFO contenant a été libéré. L'objet renvoyé par STORE_INFO_get1_<TYPE>() doit être libéré séparément par l'appelant. Voir "OBJETS PRIS EN CHARGE" pour plus d'informations sur les types pris en charge.

Fonctions

OSSL_STORE_INFO_get_type() prend un OSSL_STORE_INFO et renvoie le numéro de type STORE pour l'objet qu'il contient.

STORE_INFO_type_string() prend un numéro de type STORE et renvoie une courte chaîne de caractères le décrivant.

OSSL_STORE_INFO_get0_NAME(), OSSL_STORE_INFO_get0_NAME_description(), OSSL_STORE_INFO_get0_PARAMS(), OSSL_STORE_INFO_get0_PUBKEY(), OSSL_STORE_INFO_get0_PKEY(), OSSL_STORE_INFO_get0_CERT(), OSSL_STORE_INFO_get0_CRL() prennent tous un OSSL_STORE_INFO et renvoient l'objet qu'il contient si le type de OSSL_STORE_INFO (tel que renvoyé par OSSL_STORE_INFO_get_type()) correspond à la fonction, sinon NULL.

OSSL_STORE_INFO_get1_NAME(), OSSL_STORE_INFO_get1_NAME_description(), OSSL_STORE_INFO_get1_PARAMS(), OSSL_STORE_INFO_get1_PUBKEY(), OSSL_STORE_INFO_get1_PKEY(), OSSL_STORE_INFO_get1_CERT() et OSSL_STORE_INFO_get1_CRL() prennent tous un OSSL_STORE_INFO et renvoient une copie de l'objet qu'il contient si le type de OSSL_STORE_INFO (tel que renvoyé par OSSL_STORE_INFO_get_type()) correspond à la fonction, sinon NULL.

OSSL_STORE_INFO_free() libère un OSSL_STORE_INFO et son type contenu. Si l'argument est NULL, rien n'est fait.

OSSL_STORE_INFO_new_NAME(), OSSL_STORE_INFO_new_PARAMS(), OSSL_STORE_INFO_new_PUBKEY(), OSSL_STORE_INFO_new_PKEY(), OSSL_STORE_INFO_new_CERT() et OSSL_STORE_INFO_new_CRL() créent un objet OSSL_STORE_INFO pour contenir l'objet d'entrée donné. En cas de succès, l'objet d'entrée est consommé.

De plus, pour les objets OSSL_STORE_INFO_NAME, OSSL_STORE_INFO_set0_NAME_description() peut être utilisé pour ajouter une description supplémentaire. Cette description est destinée à être lisible par l'homme et doit être utilisée pour l'affichage d'informations.

OSSL_STORE_INFO_new() crée un OSSL_STORE_INFO avec un numéro de type type arbitraire et une structure de données data. Il incombe à l'appelant de définir des numéros de type autres que ceux définis par <openssl/store.h>, et de gérer la libération de la structure de données associée par lui-même. L'utilisation de numéros de type définis par <openssl/store.h> peut entraîner des comportements indéfinis, y compris des plantages.

OSSL_STORE_INFO_get0_data() renvoie le pointeur de données qui a été passé à OSSL_STORE_INFO_new() si type correspond au numéro de type dans info.

OSSL_STORE_INFO_new() et OSSL_STORE_INFO_get0_data() peuvent être utiles pour les applications qui définissent leurs propres données STORE, mais doivent être utilisées avec précaution.

OBJETS PRIS EN CHARGE

Les types d'objets actuellement pris en charge sont :

OSSL_STORE_INFO_NAME
Un nom est exactement cela, un nom. C'est comme un nom dans un répertoire, mais formaté comme une URI complète. Par exemple, le chemin dans l'URI "file:/foo/bar/" pourrait inclure un fichier nommé "cookie.pem", et dans ce cas, l'objet OSSL_STORE_INFO_NAME renvoyé aurait l'URI "file:/foo/bar/cookie.pem", qui peut être utilisé par l'application pour obtenir les objets de ce fichier. Ceci peut être appliqué à tous les schémas qui peuvent prendre en charge une liste d'URI d'objets d'une manière ou d'une autre.

Pour les URI "file:" qui sont utilisées sans le schéma explicite, le nom renvoyé sera le chemin de chaque objet, donc si "/foo/bar" a été donné et que ce chemin contient le fichier "cookie.pem", le nom "/foo/bar/cookie.pem" sera renvoyé.

L'URI renvoyé est considéré comme canonique et doit être unique et permanent pour le stockage où réside l'objet (ou la collection d'objets). Chaque chargeur est responsable de s'assurer qu'il ne renvoie que des URI canoniques. Cependant, il est possible que certains schémas permettent à un objet (ou à une collection de ceux-ci) d'être atteint avec des URI alternatives ; ce n'est pas parce qu'un URI est canonique que d'autres variantes ne peuvent pas être utilisées.

À la discrétion du chargeur utilisé pour obtenir ces noms, une description supplémentaire peut également être jointe.

OSSL_STORE_INFO_PARAMS
Paramètres de clé.
OSSL_STORE_INFO_PKEY
Une paire de clés ou juste une clé privée (éventuellement avec des paramètres de clé).
OSSL_STORE_INFO_PUBKEY
Une clé pu

DESCRIPTION

The OSSL_STORE functions deal with loading and storing cryptographic objects. These functions are used for the objects that are loaded.

OSSL_STORE_INFO is an opaque structure that holds a loaded object. The type of the loaded object can be determined using OSSL_STORE_INFO_get_type(). The possible return values are:

OSSL_STORE_INFO_UNSUPPORTED
An unsupported object type.
OSSL_STORE_INFO_NAME
A name, as a stack of strings.
OSSL_STORE_INFO_PUBKEY
A public key (possibly with key parameters).
OSSL_STORE_INFO_CERT
An X.509 certificate.
OSSL_STORE_INFO_CRL
A X.509 certificate revocation list.

RETURN VALUES

OSSL_STORE_INFO_get_type() returns the STORE type number of the given OSSL_STORE_INFO. There is no error value.

OSSL_STORE_INFO_get0_NAME(), OSSL_STORE_INFO_get0_NAME_description(), OSSL_STORE_INFO_get0_PARAMS(), OSSL_STORE_INFO_get0_PKEY(), OSSL_STORE_INFO_get0_CERT() and OSSL_STORE_INFO_get0_CRL() all return a pointer to the OpenSSL object on success, NULL otherwise.

OSSL_STORE_INFO_get1_NAME(), OSSL_STORE_INFO_get1_NAME_description(), OSSL_STORE_INFO_get1_PARAMS(), OSSL_STORE_INFO_get1_PKEY(), OSSL_STORE_INFO_get1_CERT() and OSSL_STORE_INFO_get1_CRL() all return a pointer to a duplicate of the OpenSSL object on success, NULL otherwise.

OSSL_STORE_INFO_type_string() returns a string on success, or NULL on failure.

OSSL_STORE_INFO_new_NAME(), OSSL_STORE_INFO_new_PARAMS(), OSSL_STORE_INFO_new_PKEY(), OSSL_STORE_INFO_new_CERT() and OSSL_STORE_INFO_new_CRL() return a OSSL_STORE_INFO pointer on success, or NULL on failure.

OSSL_STORE_INFO_set0_NAME_description() returns 1 on success, or 0 on failure.
