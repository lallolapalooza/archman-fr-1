NOM

Object — La classe de widget Object

SYNTAXE

#include <Xm/Xm.h>

DESCRIPTION

Object n'est jamais instancié. Son seul but est de servir de superclasse de support pour d'autres classes de widgets.

Classes

Le pointeur de classe est objectClass.

Le nom de classe est Object.

Nouvelles Ressources

Le tableau suivant définit un ensemble de ressources de widget utilisées par le programmeur pour spécifier des données. Le programmeur peut également définir les valeurs des ressources pour les classes héritées afin de spécifier les attributs de ce widget. Pour référencer une ressource par son nom ou par sa classe dans un fichier .Xdefaults, supprimez le préfixe XmN ou XmC et utilisez les lettres restantes. Pour spécifier l'une des valeurs définies pour une ressource dans un fichier .Xdefaults, supprimez le préfixe Xm et utilisez les lettres restantes (en minuscules ou en majuscules, mais incluez les éventuels tirets bas entre les mots). Les codes dans la colonne d'accès indiquent si la ressource donnée peut être définie au moment de la création (C), définie à l'aide de XtSetValues (S), récupérée à l'aide de XtGetValues (G), ou si elle n'est pas applicable (N/A).
