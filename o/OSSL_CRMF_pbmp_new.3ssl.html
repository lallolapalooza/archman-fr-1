OSSL_CRMF_pbmp_new(3ssl)

Paquet: openssl

Licences: Apache-2.0

OSSL_CRMF_PBMP_NEW(3ssl) OpenSSL OSSL_CRMF_PBMP_NEW(3ssl)

NOM

OSSL_CRMF_pbm_new, OSSL_CRMF_pbmp_new - fonctions pour produire un MAC basé sur un mot de passe (PBM)

SYNTAXE

#include <openssl/crmf.h>
int OSSL_CRMF_pbm_new(OSSL_LIB_CTX *libctx, const char *propq,
                      const OSSL_CRMF_PBMPARAMETER *pbmp,
                      const unsigned char *msg, size_t msglen,
                      const unsigned char *sec, size_t seclen,
                      unsigned char **mac, size_t *maclen);
OSSL_CRMF_PBMPARAMETER *OSSL_CRMF_pbmp_new(OSSL_LIB_CTX *libctx, size_t saltlen,
                                           int owfnid, size_t itercnt,
                                           int macnid);

DESCRIPTION

OSSL_CRMF_pbm_new() génère un PBM (MAC basé sur un mot de passe) basé sur les paramètres PBM donnés pbmp, le message msg, et le secret sec, ainsi que les longueurs respectives msglen et seclen. Les paramètres optionnels de contexte de bibliothèque libctx et propq peuvent être utilisés pour influencer la sélection de l'algorithme MAC référencé dans pbmp ; voir « ALGORITHME DE RÉCUPÉRATION » dans crypto(7) pour plus d'informations. En cas de succès, écrit l'adresse du nouveau MAC alloué via le paramètre de référence mac et écrit la longueur via le paramètre de référence maclen, sauf si celui-ci est NULL.

OSSL_CRMF_pbmp_new() initialise et retourne une nouvelle structure PBMParameter avec un nouveau sel aléatoire de longueur donnée saltlen, le NID de la fonction à sens unique (OWF) owfnid, le compteur d'itérations de l'OWF itercnt, et le NID du MAC macnid. Le paramètre de contexte de bibliothèque libctx peut être utilisé pour sélectionner le fournisseur pour la génération de nombres aléatoires (DRBG) et peut être NULL pour utiliser le défaut.

NOTES

Les algorithmes pour l'OWF (fonction à sens unique) et pour le MAC (code d'authentification de message) peuvent être n'importe quel NID défini dans <openssl/objects.h>. Comme spécifié par la RFC 4210, ceux-ci devraient inclure NID_hmac_sha1.

La RFC 4210 recommande que le sel SOIT d'au moins 8 octets (64 bits) de long, 16 octets étant courant.

Le nombre d'itérations doit être d'au moins 100, comme stipulé par la RFC 4211, et est limité à 100000 au maximum pour éviter les dénis de service par une entrée manipulée ou malformée.

VALEURS DE RETOUR

OSSL_CRMF_pbm_new() retourne 1 en cas de succès, 0 en cas d'erreur.

OSSL_CRMF_pbmp_new() retourne une structure OSSL_CRMF_PBMPARAMETER nouvelle et initialisée, ou NULL en cas d'erreur.

EXEMPLES

OSSL_CRMF_PBMPARAMETER *pbm = NULL;
unsigned char *msg = "Hello";
unsigned char *sec = "SeCrEt";
unsigned char *mac = NULL;
size_t maclen;
if ((pbm = OSSL_CRMF_pbmp_new(16, NID_sha256, 500, NID_hmac_sha1) == NULL))
    goto err;
if (!OSSL_CRMF_pbm_new(pbm, msg, 5, sec, 6, &mac, &maclen))
    goto err;

RFC 4211 section 4.4
