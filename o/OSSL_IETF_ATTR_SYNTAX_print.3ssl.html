OSSL_IETF_ATTR_SYNTAX_print(3ssl)

Paquet: openssl

Licences: Apache-2.0

OSSL_IETF_ATTR_SYNTAX_PRINT(3ssl) OpenSSL OSSL_IETF_ATTR_SYNTAX_PRINT(3ssl)

NOM

OSSL_IETF_ATTR_SYNTAX_print - Affichage de OSSL_IETF_ATTR_SYNTAX

SYNTAXE

#include <openssl/x509_acert.h>
int OSSL_IETF_ATTR_SYNTAX_print(BIO *bp, OSSL_IETF_ATTR_SYNTAX *a,
                                int indent);

DESCRIPTION

OSSL_IETF_ATTR_SYNTAX_print() affiche une version lisible par l'homme de a dans le BIO bp. Chaque ligne de sortie est indentée par indent espaces.

VALEURS DE RETOUR

OSSL_IETF_ATTR_SYNTAX_print() retourne 1 en cas de succès ou 0 en cas d'échec.

VOIR AUSSI

ASN1_STRING_print_ex(3)

HISTORIQUE

OSSL_IETF_ATTR_SYNTAX_print() a été ajouté dans OpenSSL 3.4.
