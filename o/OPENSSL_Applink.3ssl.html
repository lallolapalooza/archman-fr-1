NOM

OPENSSL_Applink - pont entre le BIO OpenSSL et le runtime du compilateur Win32

SYNTAXE

__declspec(dllexport) void **OPENSSL_Applink();

DESCRIPTION

OPENSSL_Applink est une interface côté application qui fournit un pont entre la couche BIO d'OpenSSL et l'environnement d'exécution du compilateur Win32. Bien qu'elle apparaisse côté application, il s'agit essentiellement d'une interface privée d'OpenSSL. Pour cette raison, les développeurs d'applications ne sont pas censés l'implémenter, mais plutôt compiler le module fourni avec le compilateur de leur choix et le lier à l'application cible. Le module référencé est disponible sous le nom applink.c, situé à côté des fichiers d'en-tête publics (uniquement sur les plateformes où cela est applicable).
