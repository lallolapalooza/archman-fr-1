OSSL_ENCODER_to_bio(3ssl)

Paquet: openssl

Licences: Apache-2.0

OSSL_ENCODER_TO_BIO(3ssl) OpenSSL OSSL_ENCODER_TO_BIO(3ssl)

NOM

OSSL_ENCODER_to_data, OSSL_ENCODER_to_bio, OSSL_ENCODER_to_fp - Routines pour effectuer un encodage

SYNTAXE

#include <openssl/encoder.h>
int OSSL_ENCODER_to_data(OSSL_ENCODER_CTX *ctx, unsigned char **pdata,
                         size_t *pdata_len);
int OSSL_ENCODER_to_bio(OSSL_ENCODER_CTX *ctx, BIO *out);
int OSSL_ENCODER_to_fp(OSSL_ENCODER_CTX *ctx, FILE *fp);

Macros de disponibilité des fonctionnalités :

OSSL_ENCODER_to_fp() n'est disponible que lorsque OPENSSL_NO_STDIO est non défini.

DESCRIPTION

OSSL_ENCODER_to_data() exécute le processus d'encodage pour le contexte ctx, avec la sortie dirigée vers *pdata et *pdata_len. Si *pdata est NULL lorsque OSSL_ENCODER_to_data() est appelé, un tampon sera alloué en utilisant OPENSSL_zalloc(3), et *pdata sera défini pour pointer vers le début de ce tampon, et *pdata_len recevra sa longueur lorsque OSSL_ENCODER_to_data() retournera. Si *pdata n'est pas NULL lorsque OSSL_ENCODER_to_data() est appelé, *pdata_len est supposé avoir sa taille. Dans ce cas, *pdata sera défini pour pointer après les octets encodés, et *pdata_len recevra le nombre d'octets restants.

OSSL_ENCODER_to_bio() exécute le processus d'encodage pour le contexte ctx, avec la sortie dirigée vers le BIO out.

OSSL_ENCODER_to_fp() fait la même chose que OSSL_ENCODER_to_bio(), sauf que la sortie est dirigée vers le FILE fp.

Pour OSSL_ENCODER_to_bio() et OSSL_ENCODER_to_fp(), l'application est tenue de configurer correctement le BIO ou le FILE, par exemple pour qu'il soit en mode texte ou binaire comme il convient au type de sortie de l'encodeur.

VALEURS DE RETOUR

OSSL_ENCODER_to_bio(), OSSL_ENCODER_to_fp() et OSSL_ENCODER_to_data() retournent 1 en cas de succès, ou 0 en cas d'échec.

EXEMPLES

Pour encoder une clé pkey en PKCS#8 au format PEM dans un bio :

OSSL_ENCODER_CTX *ectx;
const char *format = "PEM";
const char *structure = "PrivateKeyInfo"; /* Structure PKCS#8 */
const unsigned char *pass = "mon mot de passe";
ectx = OSSL_ENCODER_CTX_new_for_pkey(pkey,
                                     OSSL_KEYMGMT_SELECT_KEYPAIR
                                     | OSSL_KEYMGMT_SELECT_DOMAIN_PARAMETERS,
                                     format, structure,
                                     NULL);
if (ectx == NULL) {
    /* erreur: aucun encodeur potentiel approprié trouvé */
}
if (pass != NULL)
    OSSL_ENCODER_CTX_set_passphrase(ectx, pass, strlen(pass));
if (OSSL_ENCODER_to_bio(ectx, bio)) {
    /* la clé pkey a été encodée avec succès dans le bio */
} else {
    /* échec de l'encodage */
}
OSSL_ENCODER_CTX_free(ectx);

Pour encoder une clé pkey en PKCS#8 au format DER chiffrée avec AES-256-CBC dans un tampon :

OSSL_ENCODER_CTX *ectx;
const char *format = "DER";
const char *structure = "PrivateKeyInfo"; /* Structure PKCS#8 */
const unsigned char *pass = "mon mot de passe";
unsigned char *data = NULL;
size_t datalen;
ectx = OSSL_ENCODER_CTX_new_for_pkey(pkey,
                                     OSSL_KEYMGMT_SELECT_KEYPAIR
                                     | OSSL_KEYMGMT_SELECT_DOMAIN_PARAMETERS,
                                     format, structure,
                                     NULL);
if (ectx == NULL) {
    /* erreur: aucun encodeur potentiel approprié trouvé */
}
if (pass != NULL) {
    OSSL_ENCODER_CTX_set_passphrase(ectx, pass, strlen(pass));
    OSSL_ENCODER_CTX_set_cipher(ctx, "AES-256-CBC", NULL);
}
if (OSSL_ENCODER_to_data(ectx, &data, &datalen)) {
    /*
     * la clé pkey a été encodée avec succès dans un
     * tampon de données nouvellement alloué
     */
} else {
    /* échec de l'encodage */
}
OSSL_ENCODER_CTX_free(ectx);
