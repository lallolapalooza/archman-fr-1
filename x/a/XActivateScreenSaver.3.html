XSetScreenSaver(3) FONCTIONS XLIB XSetScreenSaver(3)

NOM

XSetScreenSaver, XForceScreenSaver, XActivateScreenSaver, XResetScreenSaver, XGetScreenSaver - manipuler l'économiseur d'écran

SYNTAXE

int XSetScreenSaver(Display *display, int timeout, int interval, int prefer_blanking, int allow_exposures);

int XForceScreenSaver(Display *display, int mode);

int XActivateScreenSaver(Display *display);

int XResetScreenSaver(Display *display);

int XGetScreenSaver(Display *display, int *timeout_return, int *interval_return, int *prefer_blanking_return, int *allow_exposures_return);

ARGUMENTS

allow_exposures
Spécifie les valeurs de contrôle de l'économiseur d'écran. Vous pouvez passer DontAllowExposures, AllowExposures, ou DefaultExposures.
allow_exposures_return
Retourne la valeur de contrôle actuelle de l'économiseur d'écran (DontAllowExposures, AllowExposures, ou DefaultExposures).
display
Spécifie la connexion au serveur X.
interval
Spécifie l'intervalle, en secondes, entre les modifications de l'économiseur d'écran.
interval_return
Retourne l'intervalle entre les invocations de l'économiseur d'écran.
mode
Spécifie le mode à appliquer. Vous pouvez passer ScreenSaverActive ou ScreenSaverReset.
prefer_blanking
Spécifie comment activer le blanc d'écran. Vous pouvez passer DontPreferBlanking, PreferBlanking, ou DefaultBlanking.
prefer_blanking_return
Retourne la préférence actuelle de blanc d'écran (DontPreferBlanking, PreferBlanking, ou DefaultBlanking).
timeout
Spécifie le délai d'attente, en secondes, avant que l'économiseur d'écran ne s'active.
timeout_return
Retourne le délai d'attente, en secondes, avant que l'économiseur d'écran ne s'active.

DESCRIPTION

Le délai d'attente et l'intervalle sont spécifiés en secondes. Un délai d'attente de 0 désactive l'économiseur d'écran (mais un économiseur d'écran activé n'est pas désactivé), et un délai d'attente de -1 restaure la valeur par défaut. Les autres valeurs négatives génèrent une erreur BadValue. Si la valeur du délai d'attente est non nulle, XSetScreenSaver active l'économiseur d'écran. Un intervalle de 0 désactive le mouvement aléatoire des motifs. Les deux valeurs sont limitées à une plage d'entiers signés de 16 bits par le protocole réseau, malgré le prototype C. Si aucune entrée des périphériques (clavier, souris, etc.) n'est générée pendant le nombre spécifié de secondes de délai d'attente une fois l'économiseur d'écran activé, l'économiseur d'écran est activé.

Pour chaque écran, si le blanc est préféré et que le matériel supporte le blanc vidéo, l'écran devient simplement blanc. Sinon, si les expositions sont autorisées ou si l'écran peut être régénéré sans envoyer d'événements Expose aux clients, l'écran est rempli d'une mosaïque du fond de la fenêtre racine dont l'origine est aléatoirement modifiée toutes les secondes d'intervalle. Sinon, les états de l'écran ne changent pas et l'économiseur d'écran n'est pas activé. L'économiseur d'écran est désactivé et tous les états de l'écran sont restaurés lors de la prochaine entrée du clavier ou du pointeur, ou lors du prochain appel à XForceScreenSaver avec le mode ScreenSaverReset.

Si la méthode d'économiseur d'écran spécifique au serveur supporte un changement périodique, l'argument interval sert d'indice quant à la durée de la période de changement, et zéro suggère qu'aucun changement périodique ne doit être effectué. Les exemples de changements d'écran incluent le brouillage de la palette de couleurs périodiquement, le déplacement d'une icône à l'écran périodiquement, ou le remplissage de l'écran avec la mosaïque du fond de la fenêtre racine dont l'origine est aléatoirement modifiée périodiquement.

XSetScreenSaver peut générer une erreur BadValue.

Si le mode spécifié est ScreenSaverActive et que l'économiseur d'écran est actuellement désactivé, XForceScreenSaver active l'économiseur d'écran même s'il avait été désactivé avec un délai d'attente de zéro. Si le mode spécifié est ScreenSaverReset et que l'économiseur d'écran est actuellement activé, XForceScreenSaver désactive l'économiseur d'écran s'il était activé, et le minuteur d'activation est réinitialisé à son état initial (comme si une entrée de périphérique avait été reçue).

XForceScreenSaver peut générer une erreur BadValue.

La fonction XActivateScreenSaver active l'économiseur d'écran.

La fonction XResetScreenSaver réinitialise l'économiseur d'écran.

La fonction XGetScreenSaver récupère les valeurs actuelles de l'économiseur d'écran.

DIAGNOSTICS

BadValue
Une valeur numérique se situe en dehors de la plage de valeurs acceptées par la requête. Sauf si une plage spécifique est indiquée pour un argument, la plage complète définie par le type de l'argument est acceptée. Tout argument défini comme un ensemble d'alternatives peut générer cette erreur.
