NOM

XChangeSaveSet, XAddToSaveSet, XRemoveFromSaveSet - changer l'ensemble de sauvegarde d'un client

SYNTAXE

int XChangeSaveSet(Display *display, Window w, int change_mode);

int XAddToSaveSet(Display *display, Window w);

int XRemoveFromSaveSet(Display *display, Window w);

ARGUMENTS

change_mode
Spécifie le mode. Vous pouvez passer SetModeInsert ou SetModeDelete.
display
Spécifie la connexion au serveur X.
w
Spécifie la fenêtre que vous souhaitez ajouter ou supprimer de l'ensemble de sauvegarde du client.

DESCRIPTION

Selon le mode spécifié, XChangeSaveSet insère ou supprime la fenêtre spécifiée de l'ensemble de sauvegarde du client. La fenêtre spécifiée doit avoir été créée par un autre client, sinon une erreur BadMatch se produit.

XChangeSaveSet peut générer les erreurs BadMatch, BadValue et BadWindow.

La fonction XAddToSaveSet ajoute la fenêtre spécifiée à l'ensemble de sauvegarde du client. La fenêtre spécifiée doit avoir été créée par un autre client, sinon une erreur BadMatch se produit.

XAddToSaveSet peut générer les erreurs BadMatch et BadWindow.

La fonction XRemoveFromSaveSet supprime la fenêtre spécifiée de l'ensemble de sauvegarde du client. La fenêtre spécifiée doit avoir été créée par un autre client, sinon une erreur BadMatch se produit.

XRemoveFromSaveSet peut générer les erreurs BadMatch et BadWindow.

DIAGNOSTICS

BadMatch
Un argument ou une paire d'arguments a le bon type et la bonne portée, mais ne correspond pas d'une autre manière requise par la requête.
BadValue
Une valeur numérique est en dehors de la plage de valeurs acceptées par la requête. Sauf si une plage spécifique est indiquée pour un argument, la plage complète définie par le type de l'argument est acceptée. Tout argument défini comme un ensemble d'alternatives peut générer cette erreur.
BadWindow
Une valeur pour un argument de type Window ne nomme pas une fenêtre définie.
