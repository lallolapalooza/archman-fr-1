XAnyEvent(3) FONCTIONS XLIB XAnyEvent(3)

NOM

XAnyEvent, XEvent - structures d'événements X génériques

STRUCTURES

Toutes les structures d'événements déclarées dans <X11/Xlib.h> ont les membres communs suivants :

typedef struct {
        int type;
        unsigned long serial;   /* # de la dernière requête traitée par le serveur */
        Bool send_event;        /* vrai si cela provient d'une requête SendEvent */
        Display *display;       /* Affichage à partir duquel l'événement a été lu */
        Window window;
} XAnyEvent;

Le membre type est défini à la constante nommée du type d'événement qui l'identifie de manière unique. Par exemple, lorsque le serveur X rapporte un événement GraphicsExpose à une application cliente, il envoie une structure XGraphicsExposeEvent avec le membre type défini à GraphicsExpose. Le membre display est défini à un pointeur vers l'affichage sur lequel l'événement a été lu. Le membre send_event est défini à True si l'événement provient d'une requête de protocole SendEvent. Le membre serial est défini à partir du numéro de série rapporté dans le protocole, mais étendu des 16 bits de poids faible à une valeur complète de 32 bits. Le membre window est défini à la fenêtre la plus utile aux dispatchers de toolkit.

La structure XEvent est une union des structures individuelles déclarées pour chaque type d'événement :

typedef union _XEvent {
        int type;       /* ne doit pas être modifié */
        XAnyEvent xany;
        XKeyEvent xkey;
        XButtonEvent xbutton;
        XMotionEvent xmotion;
        XCrossingEvent xcrossing;
        XFocusChangeEvent xfocus;
        XExposeEvent xexpose;
        XGraphicsExposeEvent xgraphicsexpose;
        XNoExposeEvent xnoexpose;
        XVisibilityEvent xvisibility;
        XCreateWindowEvent xcreatewindow;
        XDestroyWindowEvent xdestroywindow;
        XUnmapEvent xunmap;
        XMapEvent xmap;
        XMapRequestEvent xmaprequest;
        XReparentEvent xreparent;
        XConfigureEvent xconfigure;
        XGravityEvent xgravity;
        XResizeRequestEvent xresizerequest;
        XConfigureRequestEvent xconfigurerequest;
        XCirculateEvent xcirculate;
        XCirculateRequestEvent xcirculaterequest;
        XPropertyEvent xproperty;
        XSelectionClearEvent xselectionclear;
        XSelectionRequestEvent xselectionrequest;
        XSelectionEvent xselection;
        XColormapEvent xcolormap;
        XClientMessageEvent xclient;
        XMappingEvent xmapping;
        XErrorEvent xerror;
        XKeymapEvent xkeymap;
        long pad[24];
} XEvent;

La première entrée d'une structure XEvent est toujours le membre type, qui est défini au type d'événement. Le deuxième membre est toujours le numéro de série de la requête de protocole qui a généré l'événement. Le troisième membre est toujours send_event, qui est un Bool indiquant si l'événement a été envoyé par un autre client. Le quatrième membre est toujours un display, qui est l'affichage à partir duquel l'événement a été lu. À l'exception des événements keymap, le cinquième membre est toujours une fenêtre, qui a été soigneusement sélectionnée pour être utile aux dispatchers de toolkit. Pour éviter de casser les toolkits, l'ordre de ces cinq premières entrées ne changera pas. La plupart des événements contiennent également un membre time, qui est l'heure à laquelle un événement s'est produit. De plus, un pointeur vers l'événement générique doit être casté avant d'être utilisé pour accéder à toute autre information dans la structure.
