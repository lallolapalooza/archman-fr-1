NOM

XAllowEvents - libérer les événements en file d'attente

SYNTAXE

int XAllowEvents(Display *display, int event_mode, Time time);

ARGUMENTS

display
Spécifie la connexion au serveur X.
event_mode
Spécifie le mode d'événement. Vous pouvez passer AsyncPointer, SyncPointer, AsyncKeyboard, SyncKeyboard, ReplayPointer, ReplayKeyboard, AsyncBoth, ou SyncBoth.
time
Spécifie l'heure. Vous pouvez passer un horodatage ou CurrentTime.

DESCRIPTION

La fonction XAllowEvents libère certains événements mis en file d'attente si le client a provoqué le gel d'un périphérique. Elle n'a aucun effet si l'heure spécifiée est antérieure à l'heure de la dernière prise de contrôle de la prise de contrôle active la plus récente pour le client ou si l'heure spécifiée est postérieure à l'heure actuelle du serveur X.

XAllowEvents peut générer une erreur BadValue.

DIAGNOSTICS

BadValue
Une valeur numérique tombe en dehors de la plage de valeurs acceptées par la requête. Sauf si une plage spécifique est spécifiée pour un argument, la plage complète définie par le type de l'argument est acceptée. Tout argument défini comme un ensemble d'alternatives peut générer cette erreur.
