NOM

Bibliothèque Xau : XauFileName, XauReadAuth, XauLockAuth, XauUnlockAuth, XauWriteAuth, XauDisposeAuth, XauGetAuthByAddr, XauGetBestAuthByAddr - routines de la base de données d'autorisation X

SYNOPIS

#include <X11/Xauth.h>
typedef struct xauth {
        unsigned short  family;
        unsigned short  address_length;
        char    *address;
        unsigned short  number_length;
        char    *number;
        unsigned short  name_length;
        char    *name;
        unsigned short  data_length;
        char    *data;
} Xauth;
char *XauFileName (void);
Xauth *XauReadAuth (FILE *auth_file);
int XauWriteAuth (FILE *auth_file, Xauth *auth);
Xauth *XauGetAuthByAddr (unsigned short family, unsigned short
address_length, const char *address, unsigned short
number_length, const char *number, unsigned short
name_length, const char *name);
Xauth *XauGetBestAuthByAddr (unsigned short family, unsigned short
address_length, const char *address, unsigned short
number_length, const char *number, int types_length,
char **types, const int *type_lengths);
int XauLockAuth (const char *file_name, int retries, int
timeout, long dead);
int XauUnlockAuth (const char *file_name);
int XauDisposeAuth (Xauth *auth);

DESCRIPTION

XauFileName génère le nom du fichier d'autorisation par défaut en vérifiant d'abord la variable d'environnement XAUTHORITY si elle est définie, sinon il retourne $HOME/.Xauthority. Ce nom est alloué statiquement et ne doit pas être libéré.

XauReadAuth lit la prochaine entrée de auth_file. L'entrée n'est pas allouée statiquement et doit être libérée en appelant XauDisposeAuth.

XauWriteAuth écrit une entrée d'autorisation dans auth_file. Elle retourne 1 en cas de succès, 0 en cas d'échec.

XauGetAuthByAddr recherche une entrée qui correspond à la paire adresse réseau/numéro d'affichage donnée. L'entrée n'est pas allouée statiquement et doit être libérée en appelant XauDisposeAuth.

XauGetBestAuthByAddr est similaire à XauGetAuthByAddr, sauf qu'une liste de méthodes d'authentification acceptables est spécifiée. Xau choisira l'entrée de fichier qui correspond à la première entrée de cette liste (par exemple, la méthode d'authentification la plus sécurisée). L'argument types est un tableau de chaînes de caractères, une chaîne pour chaque méthode d'authentification. types_length spécifie le nombre d'éléments dans le tableau types. types_lengths est un tableau d'entiers représentant la longueur de chaque chaîne.

XauLockAuth effectue le travail nécessaire pour mettre à jour synchrone un fichier d'autorisation. D'abord, elle crée deux noms de fichier, l'un avec ``-c'' ajouté à file_name, l'autre avec ``-l'' ajouté. Si le fichier ``-c'' existe déjà et a plus de dead secondes, XauLockAuth le supprime ainsi que le fichier ``-l'' associé. Pour éviter d'éventuels problèmes de synchronisation avec NFS, une valeur de dead nulle force la suppression des fichiers. XauLockAuth fait retries tentatives pour créer et lier les noms de fichiers, en faisant une pause de timeout secondes entre chaque tentative. XauLockAuth retourne une collection de valeurs en fonction des résultats :

LOCK_ERROR
Une erreur système s'est produite, soit un nom de fichier trop long, soit un échec inattendu d'un appel système. errno peut être utile.
LOCK_TIMEOUT
Les retries tentatives ont échoué
LOCK_SUCCESS
Le verrouillage a réussi.

XauUnlockAuth annule le travail de XauLockAuth en supprimant les deux noms de fichiers ``-c'' et ``-l''.

XauDisposeAuth libère le stockage alloué pour contenir une entrée d'autorisation.
