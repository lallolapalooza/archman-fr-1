XCreateImage(3) FONCTIONS XLIB XCreateImage(3)

NOM

XInitImage, XCreateImage, XGetPixel, XPutPixel, XSubImage, XAddPixel, XDestroyImage - utilitaires d'image

SYNTAXE

Status XInitImage(XImage *image);

XImage *XCreateImage(Display *display, Visual *visual, unsigned int depth, int format, int offset, char *data, unsigned int width, unsigned int height, int bitmap_pad, int bytes_per_line);

unsigned long XGetPixel(XImage *ximage, int x, int y);

int XPutPixel(XImage *ximage, int x, int y, unsigned long pixel);

XImage *XSubImage(XImage *ximage, int x, int y, unsigned int subimage_width, unsigned int subimage_height);

int XAddPixel(XImage *ximage, long value);

int XDestroyImage(XImage *ximage);

ARGUMENTS

bitmap_pad
Spécifie le quantum d'une ligne de balayage (8, 16 ou 32). En d'autres termes, le début d'une ligne de balayage est séparé dans la mémoire client du début de la ligne de balayage suivante par un multiple entier de ce nombre de bits.
bytes_per_line
Spécifie le nombre d'octets dans l'image client entre le début d'une ligne de balayage et le début de la ligne de balayage suivante.
data
Spécifie les données de l'image.
depth
Spécifie la profondeur de l'image.
display
Spécifie la connexion au serveur X.
format
Spécifie le format de l'image. Vous pouvez passer XYBitmap, XYPixmap ou ZPixmap.
height
Spécifie la hauteur de l'image, en pixels.
offset
Spécifie le nombre de pixels à ignorer au début de la ligne de balayage.
pixel
Spécifie la nouvelle valeur de pixel.
subimage_height
Spécifie la hauteur de la nouvelle sous-image, en pixels.
subimage_width
Spécifie la largeur de la nouvelle sous-image, en pixels.
value
Spécifie la valeur constante qui doit être ajoutée.
visual
Spécifie la structure Visual.
width
Spécifie la largeur de l'image, en pixels.
ximage
Spécifie l'image.
x

y
Spécifient les coordonnées x et y.

DESCRIPTION

La fonction XInitImage initialise les routines de manipulation d'image internes d'une structure d'image, en se basant sur les valeurs des différents membres de la structure. Tous les champs, à l'exception des routines de manipulation, doivent déjà être initialisés. Si le membre bytes_per_line est zéro, XInitImage suppose que les données de l'image sont contiguës en mémoire et définit le membre bytes_per_line à une valeur appropriée basée sur les autres membres ; sinon, la valeur de bytes_per_line n'est pas modifiée. Toutes les routines de manipulation sont initialisées à des fonctions dont les autres fonctions de manipulation d'image Xlib ont besoin pour opérer sur le type d'image spécifié par le reste de la structure.

Cette fonction doit être appelée pour toute image construite par le client avant de la passer à toute autre fonction Xlib. Les structures d'image créées ou retournées par Xlib n'ont pas besoin d'être initialisées de cette manière.

Cette fonction retourne un statut non nul si l'initialisation de la structure est réussie. Elle retourne zéro si elle a détecté une erreur ou une incohérence dans la structure, auquel cas l'image n'est pas modifiée.

La fonction XCreateImage alloue la mémoire nécessaire pour une structure XImage pour l'affichage spécifié mais n'alloue pas d'espace pour l'image elle-même. Plutôt, elle initialise les valeurs d'ordre des octets, d'ordre des bits et d'unité de bitmap de la structure à partir de l'affichage et retourne un pointeur vers la structure XImage. Les valeurs des masques rouge, vert et bleu sont définies uniquement pour les images au format Z et sont dérivées de la structure Visual passée. D'autres valeurs sont également passées. L'offset permet l'affichage rapide de l'image sans nécessiter le décalage de chaque ligne de balayage en position. Si vous passez une valeur nulle dans bytes_per_line, Xlib suppose que les lignes de balayage sont contiguës en mémoire et calcule elle-même la valeur de bytes_per_line.

Notez que lorsque l'image est créée en utilisant XCreateImage, XGetImage ou XSubImage, la procédure de destruction que la fonction XDestroyImage appelle libère à la fois la structure de l'image et les données pointées par la structure de l'image.

Les fonctions de base utilisées pour obtenir un pixel, définir un pixel, créer une sous-image et ajouter une valeur constante à une image sont définies dans l'objet image. Les fonctions de cette section sont en réalité des invocations de macros des fonctions de l'objet image et sont définies dans X11/Xutil.h.

La fonction XGetPixel retourne le pixel spécifié de l'image nommée. La valeur du pixel est retournée dans un format normalisé (c'est-à-dire que l'octet le moins significatif du long est l'octet le moins significatif du pixel). L'image doit contenir les coordonnées x et y.

La fonction XPutPixel écrase le pixel dans l'image nommée avec la valeur de pixel spécifiée. La valeur de pixel d'entrée doit être dans un format normalisé (c'est-à-dire que l'octet le moins significatif du long est l'octet le moins significatif du pixel). L'image doit contenir les coordonnées x et y.

La fonction XSubImage crée une nouvelle image qui est une sous-section d'une image existante. Elle alloue la mémoire nécessaire pour la nouvelle structure XImage et retourne un pointeur vers la nouvelle image. Les données sont copiées de l'image source, et l'image doit contenir le rectangle défini par x, y, subimage_width et subimage_height.

La fonction XAddPixel ajoute une valeur constante à chaque pixel d'une image. Elle est utile lorsque vous avez une valeur de pixel de base provenant de l'allocation de ressources de couleur et que vous devez manipuler l'image pour qu'elle corresponde à ce format.

La fonction XDestroyImage désalloue la mémoire associée à la structure XImage.
