XAllocWMHints(3) FONCTIONS XLIB XAllocWMHints(3)

NOM

XAllocWMHints, XSetWMHints, XGetWMHints, XWMHints - allouer une structure d'indices pour le gestionnaire de fenêtres et définir ou lire la propriété WM_HINTS d'une fenêtre

SYNTAXE

XWMHints *XAllocWMHints(void);

int XSetWMHints(Display *display, Window w, XWMHints *wmhints);

XWMHints *XGetWMHints(Display *display, Window w);

ARGUMENTS

display
Spécifie la connexion au serveur X.
w
Spécifie la fenêtre.
wmhints
Spécifie la structure XWMHints à utiliser.

DESCRIPTION

La fonction XAllocWMHints alloue et retourne un pointeur vers une structure XWMHints. Notez que tous les champs de la structure XWMHints sont initialement définis à zéro. Si une mémoire insuffisante est disponible, XAllocWMHints retourne NULL. Pour libérer la mémoire allouée à cette structure, utilisez XFree.

La fonction XSetWMHints définit les indices du gestionnaire de fenêtres qui incluent des informations et un emplacement pour l'icône, l'état initial de la fenêtre, et si l'application s'appuie sur le gestionnaire de fenêtres pour recevoir l'entrée clavier.

XSetWMHints peut générer des erreurs BadAlloc et BadWindow.

La fonction XGetWMHints lit les indices du gestionnaire de fenêtres et retourne NULL s'il n'y avait pas de propriété WM_HINTS définie sur la fenêtre, ou retourne un pointeur vers une structure XWMHints si elle réussit. Une fois les données traitées, libérez l'espace utilisé en appelant XFree.

XGetWMHints peut générer une erreur BadWindow.

PROPRIÉTÉS

WM_HINTS
Indices supplémentaires définis par le client pour être utilisés par le gestionnaire de fenêtres. Le type C de cette propriété est XWMHints.

STRUCTURES

La structure XWMHints contient :

/* Bits du masque des indices du gestionnaire de fenêtres */

#define InputHint (1L << 0)
#define StateHint (1L << 1)
#define IconPixmapHint (1L << 2)
#define IconWindowHint (1L << 3)
#define IconPositionHint (1L << 4)
#define IconMaskHint (1L << 5)
#define WindowGroupHint (1L << 6)
#define XUrgencyHint (1L << 8)
#define AllHints (InputHint| StateHint| IconPixmapHint| IconWindowHint| IconPositionHint| IconMaskHint| WindowGroupHint) 
/* Valeurs */
typedef struct {
        long flags;     /* indique quels champs de cette structure sont définis */
        Bool input;     /* cette application s'appuie-t-elle sur le gestionnaire de
                        fenêtres pour recevoir l'entrée clavier ? */
        int initial_state;      /* voir ci-dessous */
        Pixmap icon_pixmap;     /* pixmap à utiliser comme icône */
        Window icon_window;     /* fenêtre à utiliser comme icône */
        int icon_x, icon_y;     /* position initiale de l'icône */
        Pixmap icon_mask;       /* pixmap à utiliser comme masque pour icon_pixmap */
        XID window_group;       /* id du groupe de fenêtres apparentées */
        /* cette structure pourra être étendue dans le futur */
} XWMHints;

Le membre input est utilisé pour communiquer au gestionnaire de fenêtres le modèle d'entrée utilisé par l'application. Les applications qui attendent une entrée mais qui ne définissent jamais explicitement le focus sur aucune de leurs sous-fenêtres (c'est-à-dire, utilisent le modèle "push" de gestion du focus), comme les applications de style X Version 10 qui utilisent le focus dirigé par l'espace réel, devraient définir ce membre à True. De même, les applications qui définissent le focus d'entrée sur leurs sous-fenêtres uniquement lorsqu'il est donné à leurs fenêtres de premier niveau par un gestionnaire de fenêtres devraient également définir ce membre à True. Les applications qui gèrent leur propre focus d'entrée en définissant explicitement le focus sur l'une de leurs sous-fenêtres chaque fois qu'elles souhaitent une entrée clavier (c'est-à-dire, utilisent le modèle "pull" de gestion du focus) devraient définir ce membre à False. Les applications qui n'attendent jamais aucune entrée clavier devraient également définir ce membre à False.

Les gestionnaires de fenêtres du modèle "pull" devraient rendre possible pour les applications du modèle "push" d'obtenir une entrée en définissant le focus d'entrée sur les fenêtres de premier niveau des applications dont le membre input est True. Les gestionnaires de fenêtres du modèle "push" devraient s'assurer que les applications du modèle "pull" ne les perturbent pas en redéfinissant le focus d'entrée sur PointerRoot lorsque c'est approprié (par exemple, chaque fois qu'une application dont le membre input est False définit le focus d'entrée sur l'une de ses sous-fenêtres).

Les définitions pour le drapeau initial_state sont :

#define WithdrawnState 0
#define NormalState 1 /* la plupart des applications démarrent ainsi */
#define IconicState 3 /* l'application souhaite démarrer en icône */
Le masque icon_mask spécifie quels pixels de l'icon_pixmap doivent être utilisés comme icône. Ceci permet des icônes non rectangulaires. icon_pixmap et icon_mask doivent tous deux être des bitmaps. L'icon_window permet à une application de fournir une fenêtre à utiliser comme icône pour les gestionnaires de fenêtres qui prennent en charge une telle utilisation. Le window_group vous permet de spécifier que cette fenêtre appartient à un groupe d'autres fenêtres. Par exemple, si une seule application manipule plusieurs fenêtres de premier niveau, cela vous permet de fournir suffisamment d'informations pour qu'un gestionnaire de fenêtres puisse iconifier toutes les fenêtres plutôt qu'une seule.

Le drapeau UrgencyHint, s'il est défini dans le champ flags, indique que le client juge le contenu de la fenêtre comme urgent, nécessitant une réponse rapide de l'utilisateur. Le gestionnaire de fenêtres fera des efforts pour attirer l'attention de l'utilisateur sur cette fenêtre tant que ce drapeau est défini. Le client doit fournir un moyen par lequel l'utilisateur peut faire effacer le drapeau d'urgence (soit en atténuant la condition qui a rendu la fenêtre urgente, soit simplement en éteignant l'alarme) ou retirer la fenêtre.

DIAGNOSTICS

BadAlloc
Le serveur n'a pas pu allouer la ressource demandée ou la mémoire du serveur.
BadWindow
Une valeur pour un argument Window ne nomme pas une fenêtre définie.

NOM

XAllocWMHints, XFreeWMHints - alloue et libère des structures WMHints

SYNTAXE

Bool XAllocWMHints(XWMHints *wmHints_return);
void XFreeWMHints(XWMHints *wmHints);

ARGUMENTS

dpy

Spécifie la connexion au serveur X.

wmHints_return

Pointeur vers la structure XWMHints où seront retournées les valeurs. Le champ size_of_WMHints sera initialisé à la taille de la structure XWMHints.

wmHints

Pointeur vers la structure XWMHints à libérer.

DESCRIPTION

La fonction XAllocWMHints alloue une structure XWMHints vide pour la fenêtre spécifiée. Elle renseigne le champ size_of_WMHints avec la taille de la structure, le champ flags avec 0, et les autres champs avec des valeurs sans signification. L'appelant doit ensuite définir les champs appropriés et utiliser XSetWMHints pour définir les indices de la fenêtre.

La fonction XFreeWMHints libère la structure XWMHints spécifiée.

PROPRIÉTÉS

Aucune.

STRUCTURES

Les structures XWMHints sont définies comme suit dans <X11/Xatom.h> :

typedef struct {
    long flags;
    int x, y;
    int width, height;
    int min_width, min_height;
    int max_width, max_height;
    int width_inc, height_inc;
    struct {
        Time set_time;
        Window base;
        Pixmap tile;
    } initial_state;
    Pixmap icon;
    int icon_x, icon_y;
    Pixmap icon_mask;
    XID window_group;
} XWMHints;

DIAGNOSTICS

La fonction XAllocWMHints renvoie True si la structure a été allouée avec succès, et False en cas d'échec.
