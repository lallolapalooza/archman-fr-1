XGetClassHint(3)

Paquet: libx11

Licences: MIT AND X11

XAllocClassHint(3) FONCTIONS XLIB XAllocClassHint(3)

NOM

XAllocClassHint, XSetClassHint, XGetClassHint, XClassHint - allouer une structure de sous-entendus de classe et définir ou lire la propriété WM_CLASS d'une fenêtre

SYNTAXE

XClassHint *XAllocClassHint(void);

XSetClassHint(Display *display, Window w, XClassHint *class_hints);

Status XGetClassHint(Display *display, Window w, XClassHint *class_hints_return);

ARGUMENTS

display
Spécifie la connexion au serveur X.
class_hints
Spécifie la structure XClassHint à utiliser.
class_hints_return
Retourne la structure XClassHint.
w
Spécifie la fenêtre.

DESCRIPTION

La fonction XAllocClassHint alloue et retourne un pointeur vers une structure XClassHint. Notez que les champs pointeurs dans la structure XClassHint sont initialisés à NULL. Si la mémoire disponible est insuffisante, XAllocClassHint retourne NULL. Pour libérer la mémoire allouée à cette structure, utilisez XFree.

La fonction XSetClassHint définit le sous-entendu de classe pour la fenêtre spécifiée. Si les chaînes ne sont pas dans l'encodage de caractères portable hôte (Host Portable Character Encoding), le résultat dépend de l'implémentation.

XSetClassHint peut générer des erreurs BadAlloc et BadWindow.

La fonction XGetClassHint retourne le sous-entendu de classe de la fenêtre spécifiée aux membres de la structure fournie. Si les données retournées par le serveur sont dans l'encodage de caractères portable latin (Latin Portable Character Encoding), alors les chaînes retournées sont dans l'encodage de caractères portable hôte. Sinon, le résultat dépend de l'implémentation. Elle retourne un statut non nul en cas de succès ; sinon, elle retourne un statut zéro. Pour libérer res_name et res_class une fois terminé avec les chaînes, utilisez XFree sur chacun individuellement.

XGetClassHint peut générer une erreur BadWindow.

PROPRIÉTÉS

WM_CLASS
Défini par les programmes d'application pour permettre aux gestionnaires de fenêtres et de sessions d'obtenir les ressources de l'application à partir de la base de données des ressources.

STRUCTURES

La structure XClassHint contient :

typedef struct {
        char *res_name;
        char *res_class;
} XClassHint;
Le membre res_name contient le nom de l'application,
et le membre res_class contient la classe de l'application.
Notez que le nom défini dans cette propriété peut différer du nom défini comme WM_NAME.
C'est-à-dire que WM_NAME spécifie ce qui doit être affiché dans la barre de titre et,
par conséquent, peut contenir des informations temporelles (par exemple, le nom d'un
fichier actuellement dans le tampon d'un éditeur).
En revanche,
le nom spécifié dans le cadre de WM_CLASS est le nom formel de l'application
qui doit être utilisé lors de la récupération des ressources de l'application à partir
de la base de données des ressources.

DIAGNOSTICS

BadAlloc
Le serveur n'a pas pu allouer la ressource ou la mémoire serveur demandée.
BadWindow
Une valeur pour un argument Window ne nomme pas une Window définie.
