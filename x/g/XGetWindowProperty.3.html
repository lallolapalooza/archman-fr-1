XGetWindowProperty(3)

Paquet: libx11

Licences: MIT AND X11

XGetWindowProperty(3) FONCTIONS XLIB XGetWindowProperty(3)

NOM

XGetWindowProperty, XListProperties, XChangeProperty, XRotateWindowProperties, XDeleteProperty - obtenir et modifier les propriétés de fenêtre

SYNTAXE

int XGetWindowProperty(Display *display, Window w, Atom property, long long_offset, long long_length, Bool delete, Atom req_type, Atom *actual_type_return, int *actual_format_return, unsigned long *nitems_return, unsigned long *bytes_after_return, unsigned char **prop_return);

Atom *XListProperties(Display *display, Window w, int *num_prop_return);

int XChangeProperty(Display *display, Window w, Atom property, Atom type, int format, int mode, _Xconst unsigned char *data, int nelements);

int XRotateWindowProperties(Display *display, Window w, Atom properties[], int num_prop, int npositions);

int XDeleteProperty(Display *display, Window w, Atom property);

ARGUMENTS

actual_format_return
Retourne le format réel de la propriété.
actual_type_return
Retourne l'identifiant d'atome qui définit le type réel de la propriété.
bytes_after_return
Retourne le nombre d'octets restants à lire dans la propriété si une lecture partielle a été effectuée.
data
Spécifie les données de la propriété.
delete
Spécifie une valeur booléenne qui détermine si la propriété est supprimée.
display
Spécifie la connexion au serveur X.
format
Spécifie si les données doivent être vues comme une liste d'éléments de 8 bits, 16 bits ou 32 bits. Les valeurs possibles sont 8, 16 et 32. Ces informations permettent au serveur X d'effectuer correctement les opérations d'échange d'octets si nécessaire. Si le format est 16 bits ou 32 bits, vous devez explicitement caster votre pointeur de données en (unsigned char *) lors de l'appel à XChangeProperty.
long_length
Spécifie la longueur en multiples de 32 bits des données à récupérer.
long_offset
Spécifie le décalage dans la propriété spécifiée (en quantités de 32 bits) où les données doivent être récupérées.
mode
Spécifie le mode de l'opération. Vous pouvez passer PropModeReplace, PropModePrepend, ou PropModeAppend.
nelements
Spécifie le nombre d'éléments du format de données spécifié.
nitems_return
Retourne le nombre réel d'éléments de 8 bits, 16 bits ou 32 bits stockés dans les données de prop_return.
num_prop
Spécifie la longueur du tableau de propriétés.
num_prop_return
Retourne la longueur du tableau de propriétés.
npositions
Spécifie le montant de la rotation.
prop_return
Retourne les données dans le format spécifié. Si le format retourné est 8, les données retournées sont représentées comme un tableau char. Si le format retourné est 16, les données retournées sont représentées comme un tableau de type short int et doivent être castées dans ce type pour obtenir les éléments. Si le format retourné est 32, les données de la propriété seront stockées sous forme de tableau de longs (qui dans une application 64 bits seront des valeurs 64 bits dont les 4 octets supérieurs sont complétés).
property
Spécifie le nom de la propriété.
properties
Spécifie le tableau des propriétés à faire pivoter.
req_type
Spécifie l'identifiant d'atome associé au type de propriété ou AnyPropertyType.
type
Spécifie le type de la propriété. Le serveur X n'interprète pas le type mais le renvoie à une application qui appellera ultérieurement XGetWindowProperty.
w
Spécifie la fenêtre dont vous voulez obtenir, modifier, faire pivoter ou supprimer la propriété.

DESCRIPTION

La fonction XGetWindowProperty retourne le type réel de la propriété ; le format réel de la propriété ; le nombre d'éléments de 8 bits, 16 bits ou 32 bits transférés ; le nombre d'octets restants à lire dans la propriété ; et un pointeur vers les données réellement retournées. XGetWindowProperty définit les arguments de retour comme suit :

  • Si la propriété spécifiée n'existe pas pour la fenêtre spécifiée, XGetWindowProperty retourne None à actual_type_return et la valeur zéro à actual_format_return et bytes_after_return. L'argument nitems_return est vide. Dans ce cas, l'argument delete est ignoré.
  • Si la propriété spécifiée existe mais que son type ne correspond pas au type spécifié, XGetWindowProperty retourne le type réel de la propriété à actual_type_return, le format réel de la propriété (jamais zéro) à actual_format_return, et la longueur de la propriété en octets (même si actual_format_return est 16 ou 32) à bytes_after_return. Elle ignore également l'argument delete. L'argument nitems_return est vide.
  • Si la propriété spécifiée existe et que vous assignez AnyPropertyType à l'argument req_type ou que le type spécifié correspond au type réel de la propriété, XGetWindowProperty retourne le type réel de la propriété à actual_type_return et le format réel de la propriété (jamais zéro) à actual_format_return. Elle retourne également une valeur à bytes_after_return et nitems_return, en définissant les valeurs suivantes :
N = longueur réelle de la propriété stockée en octets
     (même si le format est 16 ou 32)
I = 4 * long_offset
T = N - I
L = MINIMUM(T, 4 * long_length)
A = N - (I + L)
La valeur retournée commence à l'index d'octet I dans la propriété (indexation à partir de zéro), et sa longueur en octets est L. Si la valeur de long_offset rend L négative, une erreur BadValue se produit. La valeur de bytes_after_return est A, donnant le nombre d'octets non lus restants dans la propriété stockée.

Si le format retourné est 8, les données retournées sont représentées comme un tableau char. Si le format retourné est 16, les données retournées sont représentées comme un tableau short et doivent être castées dans ce type pour obtenir les éléments. Si le format retourné est 32, les données retournées sont représentées comme un tableau long et doivent être castées dans ce type pour obtenir les éléments.

XGetWindowProperty alloue toujours un octet supplémentaire dans prop_return (même si la propriété est de longueur zéro) et le définit à zéro afin que les propriétés simples constituées de caractères n'aient pas à être copiées dans une autre chaîne avant utilisation.

Si delete est True et bytes_after_return est zéro, XGetWindowProperty supprime la propriété de la fenêtre et génère un événement PropertyNotify sur la fenêtre.

La fonction retourne Success si elle s'exécute correctement. Pour libérer les données résultantes, utilisez XFree.

XGetWindowProperty peut générer des erreurs BadAtom, BadValue et BadWindow.

La fonction XListProperties retourne un pointeur vers un tableau de propriétés d'atomes qui sont définies pour la fenêtre spécifiée ou retourne NULL si aucune propriété n'a été trouvée. Pour libérer la mémoire allouée par cette fonction, utilisez XFree.

XListProperties peut générer une erreur BadWindow.

La fonction XChangeProperty modifie la propriété pour la fenêtre spécifiée et provoque l'émission d'un événement PropertyNotify par le serveur X.

XGetWindowProperty(3) — libX11 — X Version 11

NOM

XChangeProperty, XDeleteProperty, XRotateWindowProperties - changer ou supprimer des propriétés de fenêtre

SYNTAX

#include <X11/Xlib.h>

int XChangeProperty(
    Display *display,
    Window w,
    Atom property,
    Atom type,
    int format,
    int mode,
    const unsigned char *data,
    int nelements
);
int XDeleteProperty(
    Display *display,
    Window w,
    Atom property
);
int XRotateWindowProperties(
    Display *display,
    Window w,
    Atom *properties,
    int num_properties,
    int npositions
);

ARGUMENTS

display
Spécifie le connection au serveur X.
w
Spécifie la fenêtre sur laquelle la propriété doit être changée.
property
Spécifie la propriété à changer.
type
Spécifie le type de données de la propriété.
format
Spécifie le format des données de la propriété. Il doit être 8, 16, ou 32.
mode
Spécifie comment la nouvelle donnée doit être écrite par rapport aux données existantes. Il peut être PropModeReplace, PropModePrepend ou PropModeAppend.
data
Spécifie un pointeur vers les données de la propriété.
nelements
Spécifie le nombre d'éléments de données à écrire.
properties
Spécifie un tableau de noms de propriétés à faire pivoter.
num_properties
Spécifie le nombre de propriétés dans le tableau properties.
npositions
Spécifie le nombre de positions à faire pivoter les propriétés.

DESCRIPTION

La fonction XChangeProperty écrit les données spécifiées dans la propriété spécifiée sur la fenêtre spécifiée. Elle peut également générer des événements sur cette fenêtre. XChangeProperty effectue les opérations suivantes :

  • Si le mode est PropModeReplace, XChangeProperty ignore la valeur précédente de la propriété et stocke les nouvelles données.
  • Si le mode est PropModePrepend ou PropModeAppend, XChangeProperty insère les données spécifiées avant le début des données existantes ou à la fin des données existantes, respectivement. Le type et le format doivent correspondre à la valeur de la propriété existante, sinon une erreur BadMatch est générée. Si la propriété n'est pas définie, elle est traitée comme étant définie avec le type et le format corrects avec des données de longueur zéro.

Si le format spécifié est 8, les données de la propriété doivent être un tableau de char. Si le format spécifié est 16, les données de la propriété doivent être un tableau de short. Si le format spécifié est 32, les données de la propriété doivent être un tableau de long.

La durée de vie d'une propriété n'est pas liée au client qui la stocke. Les propriétés restent jusqu'à ce qu'elles soient explicitement supprimées, jusqu'à ce que la fenêtre soit détruite, ou jusqu'à ce que le serveur soit réinitialisé. Pour une discussion sur ce qui se passe lorsque la connexion au serveur X est fermée, voir la section 2.6. La taille maximale d'une propriété dépend du serveur et peut varier dynamiquement en fonction de la quantité de mémoire disponible pour le serveur. (S'il n'y a pas assez d'espace, une erreur BadAlloc est générée.)

XChangeProperty peut générer des erreurs BadAlloc, BadAtom, BadMatch, BadValue et BadWindow.

La fonction XRotateWindowProperties permet de faire pivoter des propriétés sur une fenêtre et provoque la génération d'événements PropertyNotify par le serveur X. Si les noms de propriétés dans le tableau properties sont considérés comme étant numérotés à partir de zéro et s'il y a num_properties noms de propriétés dans la liste, alors la valeur associée au nom de propriété I devient la valeur associée au nom de propriété (I + npositions) mod N pour tout I de zéro à N - 1. L'effet est de faire pivoter les états de npositions positions autour du cercle virtuel des noms de propriétés (vers la droite pour npositions positif, vers la gauche pour npositions négatif). Si npositions mod N est non nul, le serveur X génère un événement PropertyNotify pour chaque propriété dans l'ordre où elles sont listées dans le tableau. Si un atome apparaît plus d'une fois dans la liste ou si aucune propriété portant ce nom n'est définie pour la fenêtre, une erreur BadMatch est générée. Si une erreur BadAtom ou BadMatch est générée, aucune propriété n'est modifiée.

XRotateWindowProperties peut générer des erreurs BadAtom, BadMatch et BadWindow.

La fonction XDeleteProperty supprime la propriété spécifiée uniquement si la propriété était définie sur la fenêtre spécifiée et provoque la génération d'un événement PropertyNotify par le serveur X sur la fenêtre, à moins que la propriété n'existe pas.

XDeleteProperty peut générer des erreurs BadAtom et BadWindow.

DIAGNOSTICS

BadAlloc
Le serveur n'a pas réussi à allouer la ressource ou la mémoire serveur demandée.
BadAtom
Une valeur pour un argument Atom ne nomme pas un Atome défini.
BadValue
Une valeur numérique se situe en dehors de la plage des valeurs acceptées par la requête. Sauf si une plage spécifique est spécifiée pour un argument, la plage complète définie par le type de l'argument est acceptée. Tout argument défini comme un ensemble d'alternatives peut générer cette erreur.
BadWindow
Une valeur pour un argument Window ne nomme pas une Window définie.
