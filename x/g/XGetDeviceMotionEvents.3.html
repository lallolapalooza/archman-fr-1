XGETDEVICEMOTIONEVEN(3)   XGETDEVICEMOTIONEVEN(3)

NOM

XGetDeviceMotionEvents, XDeviceTimeCoord - obtenir l'historique des mouvements d'un périphérique

SYNTAXE

#include <X11/extensions/XInput.h>
XDeviceTimeCoord *XGetDeviceMotionEvents( Display *display,
                                          XDevice *device,
                                          Time start,
                                          Time stop,
                                          int *nevents_return,
                                          int *mode_return,
                                          int *axis_count_return);
display
       Spécifie la connexion au serveur X.
device
       Spécifie le périphérique dont l'historique des mouvements est à interroger.
start, stop
       Spécifient l'intervalle de temps pendant lequel les événements sont retournés depuis le tampon d'historique des mouvements. Vous pouvez passer un horodatage ou CurrentTime.
nevents_return
       Retourne le nombre d'événements du tampon d'historique des mouvements.
mode_return
       Retourne le mode du périphérique (Absolu ou Relatif).
axis_count_return
       Retourne le nombre d'axes rapportés.

DESCRIPTION

Le serveur peut conserver l'historique récent des mouvements du périphérique et ce, avec une granularité plus fine que celle rapportée par les événements DeviceMotionNotify. La requête XGetDeviceMotionEvents rend cet historique disponible.
La requête XGetDeviceMotionEvents retourne tous les événements du tampon d'historique des mouvements qui tombent entre les heures de début et de fin spécifiées, incluses. Si l'heure de début est postérieure à l'heure de fin ou si l'heure de début est dans le futur, aucun événement n'est retourné. Si l'heure de fin est dans le futur, elle est équivalente à la spécification de CurrentTime.
Le mode indique si le périphérique rapporte des données de position absolue (mode = Absolute) ou des données de mouvement relatif (mode = Relative). Certains périphériques permettent de changer leur mode via la requête XSetDeviceMode. Ces constantes sont définies dans le fichier XI.h. axis_count retourne le nombre d'axes ou de vals rapportés par le périphérique.
XGetDeviceMotionEvents peut générer une erreur BadDevice ou BadMatch.

Structures

La structure XDeviceTimeCoord contient :
typedef struct {
    Time time;
    int *data;
} XDeviceTimeCoord;
Le membre time est défini à l'heure, en millisecondes. Le membre data est un pointeur vers un tableau d'entiers. Ces entiers sont définis aux valeurs de chaque vals ou axe rapporté par le périphérique. Il y a un élément dans le tableau par axe de mouvement rapporté par le périphérique. La valeur des éléments du tableau dépend du mode du périphérique. Si le mode est Absolute, les valeurs sont les valeurs brutes générées par le périphérique. Celles-ci peuvent être mises à l'échelle par les programmes clients en utilisant les valeurs maximales que le périphérique peut générer. La valeur maximale pour chaque axe du périphérique est rapportée dans le champ max_val de XAxisInfo retourné par la requête XListInputDevices. Si le mode est Relative, les valeurs data sont les valeurs relatives générées par le périphérique.
Vous devez utiliser XFreeDeviceMotionEvents pour libérer les données retournées par cette requête.
Erreurs retournées par cette requête : BadDevice, BadMatch.

DIAGNOSTICS

BadDevice
       Un périphérique invalide a été spécifié. Le périphérique spécifié n'existe pas ou n'a pas été ouvert par ce client via XOpenInputDevice. Cette erreur peut également survenir si le périphérique spécifié est le clavier X ou le pointeur X.
BadMatch
       Cette erreur peut survenir si une requête XGetDeviceMotionEvents est effectuée en spécifiant un périphérique qui n'a pas de vals et ne rapporte aucun axe de mouvement.
