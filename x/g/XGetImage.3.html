XPutImage(3) FONCTIONS XLIB XPutImage(3)

NOM

XPutImage, XGetImage, XGetSubImage - transférer des images

SYNTAXE

int XPutImage(Display *display, Drawable d, GC gc, XImage *image, int src_x, int src_y, int dest_x, int dest_y, unsigned int width, unsigned int height);

XImage *XGetImage(Display *display, Drawable d, int x, int y, unsigned int width, unsigned int height, unsigned long plane_mask, int format);

XImage *XGetSubImage(Display *display, Drawable d, int x, int y, unsigned int width, unsigned int height, unsigned long plane_mask, int format, XImage *dest_image, int dest_x, dest_y);

ARGUMENTS

d
Spécifie le drawable.
dest_image
Spécifie l'image de destination.
dest_x

dest_y
Spécifient les coordonnées x et y, qui sont relatives à l'origine du drawable et sont les coordonnées de la sous-image ou qui sont relatives à l'origine du rectangle de destination, spécifient son coin supérieur gauche, et déterminent où la sous-image est placée dans l'image de destination.
display
Spécifie la connexion au serveur X.
format
Spécifie le format de l'image. Vous pouvez passer XYPixmap ou ZPixmap.
gc
Spécifie le GC.
image
Spécifie l'image que vous souhaitez combiner avec le rectangle.
plane_mask
Spécifie le masque de plan.
src_x
Spécifie le décalage en X depuis le bord gauche de l'image définie par la structure XImage.
src_y
Spécifie le décalage en Y depuis le bord supérieur de l'image définie par la structure XImage.
width

height
Spécifient la largeur et la hauteur de la sous-image, qui définissent les dimensions du rectangle.
x

y
Spécifient les coordonnées x et y, qui sont relatives à l'origine du drawable et définissent le coin supérieur gauche du rectangle.

DESCRIPTION

La fonction XPutImage combine une image avec un rectangle du drawable spécifié. La section de l'image définie par les arguments src_x, src_y, width et height est dessinée sur la partie spécifiée du drawable. Si le format XYBitmap est utilisé, la profondeur de l'image doit être de un, sinon une erreur BadMatch se produit. Le pixel de premier plan du GC définit la source pour les bits à un de l'image, et le pixel d'arrière-plan définit la source pour les bits à zéro. Pour XYPixmap et ZPixmap, la profondeur de l'image doit correspondre à la profondeur du drawable, sinon une erreur BadMatch se produit.

Si les caractéristiques de l'image (par exemple, byte_order et bitmap_unit) diffèrent de ce que le serveur requiert, XPutImage effectue automatiquement les conversions appropriées.

Cette fonction utilise les composants GC suivants : function, plane-mask, subwindow-mode, clip-x-origin, clip-y-origin et clip-mask. Elle utilise également ces composants dépendant du mode GC : foreground et background.

XPutImage peut générer des erreurs BadDrawable, BadGC, BadMatch et BadValue.

La fonction XGetImage renvoie un pointeur vers une structure XImage. Cette structure vous fournit le contenu du rectangle spécifié du drawable dans le format que vous spécifiez. Si l'argument format est XYPixmap, l'image contient uniquement les plans de bits que vous avez transmis à l'argument plane_mask. Si l'argument plane_mask ne demande qu'un sous-ensemble des plans de l'écran, la profondeur de l'image retournée sera le nombre de plans demandés. Si l'argument format est ZPixmap, XGetImage renvoie à zéro les bits de tous les plans non spécifiés dans l'argument plane_mask. La fonction n'effectue aucune vérification de plage sur les valeurs de plane_mask et ignore les bits superflus.

XGetImage renvoie la profondeur de l'image au membre depth de la structure XImage. La profondeur de l'image est telle que spécifiée lors de la création du drawable, sauf lors de l'obtention d'un sous-ensemble des plans au format XYPixmap, où la profondeur est donnée par le nombre de bits mis à 1 dans plane_mask.

Si le drawable est un pixmap, le rectangle donné doit être entièrement contenu dans le pixmap, sinon une erreur BadMatch se produit. Si le drawable est une fenêtre, la fenêtre doit être visible, et il doit être vrai que s'il n'y avait pas d'inférieurs ou de fenêtres chevauchantes, le rectangle spécifié de la fenêtre serait entièrement visible à l'écran et entièrement contenu dans les bords extérieurs de la fenêtre, sinon une erreur BadMatch se produit. Notez que les bordures de la fenêtre peuvent être incluses et lues avec cette requête. Si la fenêtre a un backing-store, le contenu du backing-store est renvoyé pour les régions de la fenêtre qui sont occultées par des fenêtres non inférieures. Si la fenêtre n'a pas de backing-store, le contenu renvoyé de ces régions occultées est indéfini. Le contenu renvoyé des régions visibles des inférieurs d'une profondeur différente de celle de la fenêtre spécifiée est également indéfini. L'image du curseur pointeur n'est pas incluse dans le contenu renvoyé. Si un problème survient, XGetImage renvoie NULL.

XGetImage peut générer des erreurs BadDrawable, BadMatch et BadValue.

La fonction XGetSubImage met à jour dest_image avec la sous-image spécifiée de la même manière que XGetImage. Si l'argument format est XYPixmap, l'image contient uniquement les plans de bits que vous avez transmis à l'argument plane_mask. Si l'argument format est ZPixmap, XGetSubImage renvoie à zéro les bits de tous les plans non spécifiés dans l'argument plane_mask. La fonction n'effectue aucune vérification de plage sur les valeurs de plane_mask et ignore les bits superflus. Par commodité, XGetSubImage renvoie un pointeur vers la même structure XImage spécifiée par dest_image.

La profondeur de la structure XImage de destination doit être la même que celle du drawable. Si la sous-image spécifiée ne rentre pas à l'emplacement spécifié dans l'image de destination, les bords droit et inférieur sont coupés. Si le drawable est un pixmap, le rectangle donné doit être entièrement contenu dans le pixmap, sinon une erreur BadMatch se produit. Si le drawable est une fenêtre, la fenêtre doit être visible, et il doit être vrai que s'il n'y avait pas d'inférieurs ou de fenêtres chevauchantes, le rectangle spécifié de la fenêtre serait entièrement visible à l'écran et entièrement contenu dans les bords extérieurs de la fenêtre, sinon une erreur BadMatch se produit. Si la fenêtre a un backing-store, le contenu du backing-store est renvoyé pour les régions de la fenêtre qui sont occultées par des fenêtres non inférieures. Si la fenêtre n'a pas de backing-store, le contenu renvoyé de ces régions occultées est indéfini. Le contenu renvoyé des régions visibles des inférieurs d'une profondeur différente de celle de la fenêtre spécifiée est également indéfini. Si un problème survient, XGetSubImage renvoie NULL.

XGetSubImage peut générer des erreurs BadDrawable, BadGC, BadMatch et BadValue.

Une valeur pour un argument Drawable ne nomme pas une Fenêtre ou un Pixmap défini.
BadGC
Une valeur pour un argument GContext ne nomme pas un GContext défini.
BadMatch
Une fenêtre InputOnly est utilisée comme Drawable.
BadMatch

XGetImage 3

NAME

XGetImage — get an image from an X server

SYNTAX

      XImage *XGetImage(Display *dpy, Drawable d, int x, int y, unsigned int width, unsigned int height, unsigned long line_mask, int format)

      XImage *XGetSubImage(Display *dpy, Drawable d, int x, int y, unsigned int width, unsigned int height, unsigned long line_mask, int format)

ARGUMENTS

-- dpy Specifies the connection to the X server.

-- d Specifies the drawable (a window or a pixmap).

-- x, y Specify the coordinates of the upper-left corner of the rectangle to be read.

-- width, height Specify the width and height of the rectangle to be read.

-- line_mask Specifies a mask that is ANDed with the line mask of the image. This is used to extract the most significant bits of the red, green, and blue components. Usually, this is set to the ZPixmap.

-- format Specifies the format of the image. This can be XYPixmap or ZPixmap.

DESCRIPTION

The XGetImage function returns an XImage structure containing the pixel data from the specified window or pixmap. The image is a rectangular region defined by the coordinates x, y, width, and height. The line_mask argument is used to extract specific bits from the pixel data, and the format argument specifies the format of the returned image data.

The XGetSubImage function is similar to XGetImage, but it returns only a portion of the specified image. The x, y, width, and height arguments specify the sub-image to be retrieved.

After you are finished with the XImage structure, you should free the memory associated with it using XDestroyImage.

DIAGNOSTICS

BadDrawable
A value for a drawable argument does not exist or is not a valid drawable.
BadMatch
Some argument has the correct type and range but fails to match in some other way required by the request.
BadValue
Some numeric value falls outside the range of values accepted by the request. Unless a specific range is specified for an argument, the full range defined by the argument's type is accepted. Any argument defined as a set of alternatives can generate this error.
