XGetMotionEvents(3)

Paquet: libx11

Licences: MIT AND X11

XSendEvent(3) FONCTIONS XLIB XSendEvent(3)

NOM

XSendEvent, XDisplayMotionBufferSize, XGetMotionEvents, XTimeCoord - envoyer des événements et structure de l'historique des mouvements du pointeur

SYNTAXE

Status XSendEvent(Display *display, Window w, Bool propagate, long event_mask, XEvent *event_send);

unsigned long XDisplayMotionBufferSize(Display *display);

XTimeCoord *XGetMotionEvents(Display *display, Window w, Time start, Time stop, int *nevents_return);

ARGUMENTS

display
Spécifie la connexion au serveur X.
event_mask
Spécifie le masque d'événements.
event_send
Spécifie l'événement qui doit être envoyé.
nevents_return
Retourne le nombre d'événements du tampon d'historique des mouvements.
propagate
Spécifie une valeur booléenne.
start

stop
Spécifient l'intervalle de temps pendant lequel les événements sont renvoyés depuis le tampon d'historique des mouvements. Vous pouvez passer un horodatage ou CurrentTime. PointerWindow, ou InputFocus.
w
Spécifie la fenêtre à laquelle l'événement doit être envoyé.

DESCRIPTION

La fonction XSendEvent identifie la fenêtre de destination, détermine quels clients doivent recevoir les événements spécifiés et ignore toutes les saisies actives. Cette fonction nécessite que vous passiez un masque d'événements. Pour une discussion sur les noms de masques d'événements valides, voir la section 10.3. Cette fonction utilise l'argument w pour identifier la fenêtre de destination comme suit :

  • Si w est PointerWindow, la fenêtre de destination est la fenêtre qui contient le pointeur.
  • Si w est InputFocus et si la fenêtre de focus contient le pointeur, la fenêtre de destination est la fenêtre qui contient le pointeur ; sinon, la fenêtre de destination est la fenêtre de focus.

Pour déterminer quels clients doivent recevoir les événements spécifiés, XSendEvent utilise l'argument propagate comme suit :

  • Si event_mask est l'ensemble vide, l'événement est envoyé au client qui a créé la fenêtre de destination. Si ce client n'existe plus, aucun événement n'est envoyé.
  • Si propagate est False, l'événement est envoyé à chaque client qui sélectionne sur la destination l'un des types d'événements de l'argument event_mask.
  • Si propagate est True et qu'aucun client n'a sélectionné sur la destination l'un des types d'événements de event-mask, la destination est remplacée par l'ancêtre le plus proche de la destination pour lequel un client a sélectionné un type dans event-mask et pour lequel aucune fenêtre intermédiaire n'a ce type dans son masque do-not-propagate-mask. Si aucune fenêtre de ce type n'existe ou si la fenêtre est un ancêtre de la fenêtre de focus et que InputFocus était initialement spécifié comme destination, l'événement n'est envoyé à aucun client. Sinon, l'événement est rapporté à chaque client qui sélectionne sur la destination finale l'un des types spécifiés dans event_mask.

L'événement dans la structure XEvent doit être l'un des événements principaux ou l'un des événements définis par une extension (ou une erreur BadValue en résulte) afin que le serveur X puisse correctement permuter les octets du contenu si nécessaire. Le contenu de l'événement reste sinon inchangé et non vérifié par le serveur X, sauf pour forcer send_event à True dans l'événement transféré et pour définir correctement le numéro de série dans l'événement ; par conséquent, ces champs et le champ display sont ignorés par XSendEvent.

XSendEvent retourne zéro si la conversion au format du protocole filaire a échoué et retourne une valeur non nulle sinon. XSendEvent peut générer des erreurs BadValue et BadWindow.

Le serveur peut conserver l'historique récent du mouvement du pointeur et le faire avec une granularité plus fine que celle rapportée par les événements MotionNotify. La fonction XGetMotionEvents rend cet historique disponible.

La fonction XGetMotionEvents retourne tous les événements du tampon d'historique des mouvements qui tombent entre les temps de début et de fin spécifiés, inclus, et dont les coordonnées se trouvent dans la fenêtre spécifiée (y compris ses bordures) à son placement actuel. Si le serveur ne prend pas en charge l'historique des mouvements, si le temps de début est postérieur au temps de fin, ou si le temps de début est dans le futur, aucun événement n'est renvoyé ; XGetMotionEvents retourne NULL. Si le temps de fin est dans le futur, il est équivalent à spécifier CurrentTime. XGetMotionEvents peut générer une erreur BadWindow.

STRUCTURES

La structure XTimeCoord contient :

typedef struct {
        Time time;
        short x, y;
} XTimeCoord;

Le membre time est défini sur l'heure, en millisecondes. Les membres x et y sont définis sur les coordonnées du pointeur et sont rapportés par rapport à l'origine de la fenêtre spécifiée.

DIAGNOSTICS

BadValue
Une valeur numérique tombe en dehors de la plage des valeurs acceptées par la requête. Sauf si une plage spécifique est spécifiée pour un argument, la plage complète définie par le type de l'argument est acceptée. Tout argument défini comme un ensemble d'alternatives peut générer cette erreur.
BadWindow
Une valeur pour un argument Window ne nomme pas une Window définie.
