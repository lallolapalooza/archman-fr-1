XPutImage(3) FONCTIONS XLIB XPutImage(3)

NOM

XPutImage, XGetImage, XGetSubImage - transférer des images

SYNTAXE

int XPutImage(Display *display, Drawable d, GC gc, XImage *image, int src_x, int src_y, int dest_x, int dest_y, unsigned int width, unsigned int height);

XImage *XGetImage(Display *display, Drawable d, int x, int y, unsigned int width, unsigned int height, unsigned long plane_mask, int format);

XImage *XGetSubImage(Display *display, Drawable d, int x, int y, unsigned int width, unsigned int height, unsigned long plane_mask, int format, XImage *dest_image, int dest_x, dest_y);

ARGUMENTS

d
Spécifie le drawable.
dest_image
Spécifie l'image de destination.
dest_x

dest_y
Spécifient les coordonnées x et y, qui sont relatives à l'origine du drawable et sont les coordonnées de la sous-image ou qui sont relatives à l'origine du rectangle de destination, spécifient son coin supérieur gauche et déterminent où la sous-image est placée dans l'image de destination.
display
Spécifie la connexion au serveur X.
format
Spécifie le format de l'image. Vous pouvez passer XYPixmap ou ZPixmap.
gc
Spécifie le GC.
image
Spécifie l'image que vous souhaitez combiner avec le rectangle.
plane_mask
Spécifie le masque de plan.
src_x
Spécifie le décalage en X depuis le bord gauche de l'image définie par la structure XImage.
src_y
Spécifie le décalage en Y depuis le bord supérieur de l'image définie par la structure XImage.
width

height
Spécifient la largeur et la hauteur de la sous-image, qui définissent les dimensions du rectangle.
x

y
Spécifient les coordonnées x et y, qui sont relatives à l'origine du drawable et définissent le coin supérieur gauche du rectangle.

DESCRIPTION

La fonction XPutImage combine une image avec un rectangle du drawable spécifié. La section de l'image définie par les arguments src_x, src_y, width et height est dessinée sur la partie spécifiée du drawable. Si le format XYBitmap est utilisé, la profondeur de l'image doit être un, sinon une erreur BadMatch se produit. Le pixel de premier plan dans le GC définit la source pour les bits un de l'image, et le pixel d'arrière-plan définit la source pour les bits zéro. Pour XYPixmap et ZPixmap, la profondeur de l'image doit correspondre à la profondeur du drawable, sinon une erreur BadMatch se produit.

Si les caractéristiques de l'image (par exemple, byte_order et bitmap_unit) diffèrent de ce que le serveur requiert, XPutImage effectue automatiquement les conversions appropriées.

Cette fonction utilise les composants GC suivants : function, plane-mask, subwindow-mode, clip-x-origin, clip-y-origin et clip-mask. Elle utilise également ces composants dépendant du mode GC : foreground et background.

XPutImage peut générer des erreurs BadDrawable, BadGC, BadMatch et BadValue.

La fonction XGetImage renvoie un pointeur vers une structure XImage. Cette structure vous fournit le contenu du rectangle spécifié du drawable dans le format que vous spécifiez. Si l'argument format est XYPixmap, l'image ne contient que les plans de bits que vous avez passés à l'argument plane_mask. Si l'argument plane_mask ne demande qu'un sous-ensemble des plans de l'écran, la profondeur de l'image renvoyée sera le nombre de plans demandés. Si l'argument format est ZPixmap, XGetImage renvoie à zéro les bits de tous les plans non spécifiés dans l'argument plane_mask. La fonction n'effectue aucune vérification de plage sur les valeurs de plane_mask et ignore les bits supplémentaires.

XGetImage renvoie la profondeur de l'image au membre depth de la structure XImage. La profondeur de l'image est celle spécifiée lors de la création du drawable, sauf lors de l'obtention d'un sous-ensemble des plans au format XYPixmap, où la profondeur est donnée par le nombre de bits définis à 1 dans plane_mask.

Si le drawable est un pixmap, le rectangle donné doit être entièrement contenu dans le pixmap, sinon une erreur BadMatch se produit. Si le drawable est une fenêtre, la fenêtre doit être visible, et il doit être vrai que s'il n'y avait pas d'inférieurs ou de fenêtres chevauchantes, le rectangle spécifié de la fenêtre serait entièrement visible à l'écran et entièrement contenu dans les bords extérieurs de la fenêtre, sinon une erreur BadMatch se produit. Notez que les bordures de la fenêtre peuvent être incluses et lues avec cette requête. Si la fenêtre a un backing-store, le contenu du backing-store est renvoyé pour les régions de la fenêtre qui sont obstruées par des fenêtres non inférieures. Si la fenêtre n'a pas de backing-store, le contenu renvoyé de telles régions obstruées est indéfini. Le contenu renvoyé des régions visibles d'inférieurs d'une profondeur différente de celle de la fenêtre spécifiée est également indéfini. L'image du curseur pointeur n'est pas incluse dans le contenu renvoyé. Si un problème survient, XGetImage renvoie NULL.

XGetImage peut générer des erreurs BadDrawable, BadMatch et BadValue.

La fonction XGetSubImage met à jour dest_image avec la sous-image spécifiée de la même manière que XGetImage. Si l'argument format est XYPixmap, l'image ne contient que les plans de bits que vous avez passés à l'argument plane_mask. Si l'argument format est ZPixmap, XGetSubImage renvoie à zéro les bits de tous les plans non spécifiés dans l'argument plane_mask. La fonction n'effectue aucune vérification de plage sur les valeurs de plane_mask et ignore les bits supplémentaires. Par souci de commodité, XGetSubImage renvoie un pointeur vers la même structure XImage spécifiée par dest_image.

La profondeur de la structure XImage de destination doit être la même que celle du drawable. Si la sous-image spécifiée ne rentre pas à l'emplacement spécifié dans l'image de destination, les bords droit et inférieur sont rognés. Si le drawable est un pixmap, le rectangle donné doit être entièrement contenu dans le pixmap, sinon une erreur BadMatch se produit. Si le drawable est une fenêtre, la fenêtre doit être visible, et il doit être vrai que s'il n'y avait pas d'inférieurs ou de fenêtres chevauchantes, le rectangle spécifié de la fenêtre serait entièrement visible à l'écran et entièrement contenu dans les bords extérieurs de la fenêtre, sinon une erreur BadMatch se produit. Si la fenêtre a un backing-store, alors le contenu du backing-store est renvoyé pour les régions de la fenêtre qui sont obstruées par des fenêtres non inférieures. Si la fenêtre n'a pas de backing-store, le contenu renvoyé de telles régions obstruées est indéfini. Le contenu renvoyé des régions visibles d'inférieurs d'une profondeur différente de celle de la fenêtre spécifiée est également indéfini. Si un problème survient, XGetSubImage renvoie NULL.

XGetSubImage peut générer des erreurs BadDrawable, BadGC, BadMatch et BadValue.

DIAGNOSTICS

BadDrawable
Une valeur pour un argument Drawable ne nomme pas une Fenêtre ou un Pixmap défini.
BadGC
Une valeur pour un argument GContext ne nomme pas un GContext défini.
BadMatch
Une fenêtre InputOnly est utilisée comme Drawable.
BadMatch
Un argument ou une paire d'arguments

XGetSubImage(3)

libX11 1.8.12

NAME

XGetSubImage, XGetImage, XGetPixel - get image data or pixel values from an X server

SYNTAX

    XImage *XGetImage
    (Display *display,
    Drawable d,
    int x,
    int y,
    unsigned int width,
    unsigned int height,
    long plane_mask,
    int format);

    XImage *XGetSubImage
    (Display *display,
    Drawable d,
    int x,
    int y,
    unsigned int width,
    unsigned int height,
    long plane_mask,
    int format);

    unsigned long XGetPixel(XImage *image,
    int x,
    int y);

ARGUMENTS

display
Specifies the connection to the X server.
d
Specifies the drawable (a Window or Pixmap).
x
Specifies the x-coordinate of the upper-left corner of the desired image.
y
Specifies the y-coordinate of the upper-left corner of the desired image.
width
Specifies the width of the desired image.
height
Specifies the height of the desired image.
plane_mask
Specifies the plane mask. Only the specified planes are read. For RGB or XYPixmap images, the plane mask should be 0. For ZPixmap images, the plane mask must be 0. The plane_mask is not supported for windows. Use 0 for the plane_mask when reading from a window.
format
Specifies the format of the returned XImage structure. You can pass XYPixmap or ZPixmap or XYBitmap.
image
Specifies the image structure.

For XYBitmap format, the data is returned as a single plane of bits. The plane_mask argument is ignored.

For XYPixmap format, the data is returned with non-contiguous planes. The plane_mask argument specifies which planes to read.

For ZPixmap format, the data is returned in a contiguous, non-interleaved format. The plane_mask argument must be 0.

The XGetImage() function returns an XImage structure containing a screen image. XGetSubImage() is similar to XGetImage() but returns only a portion of the image.

The XGetPixel() function returns the pixel value at the specified x and y coordinates within the image structure.

Note: The XGetImage() function can only be used on windows that have the DoRed and DoBlue substructure redirect attribute set. It is generally not useful for window drawables.

x
y

DESCRIPTION

The XGetImage function returns an XImage(3) structure containing a screen image. XGetSubImage(3) is similar to XGetImage(3) but returns only a portion of the image.

The XGetPixel function returns the pixel value at the specified x and y coordinates within the XImage(3) structure.

Note: The XGetImage(3) function can only be used on windows that have the DoRed and DoBlue substructure redirect attribute set. It is generally not useful for window drawables.

DIAGNOSTICS

BadDrawable
A value for a Drawable argument does not exist.
BadMatch
Some parameter matches no existing visual, or some parameter matches no existing screen, or some subfunction requires that the type and type of the arguments match. If a value is specified for an argument that is outside the range of valid values for that argument, the behavior is implementation-dependent.
BadValue
Some numeric value falls outside the range of values accepted by the request. Unless a specific range is specified for an argument, the full range defined by the argument's type is accepted. Any argument defined as a set of alternatives can generate this error.
