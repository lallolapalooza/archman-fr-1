XGravityEvent(3) FONCTIONS XLIB XGravityEvent(3)

NOM

XGravityEvent - Structure de l'événement GravityNotify

STRUCTURES

La structure pour les événements GravityNotify contient :

typedef struct {
        int type;       /* GravityNotify */
        unsigned long serial;   /* # de la dernière requête traitée par le serveur */
        Bool send_event;        /* true si ceci provient d'une requête SendEvent */
        Display *display;       /* Display à partir duquel l'événement a été lu */
        Window event;
        Window window;
        int x, y;
} XGravityEvent;

Lorsque vous recevez cet événement, les membres de la structure sont définis comme suit.

Le membre type est défini à la constante du nom de type d'événement qui l'identifie de manière unique. Par exemple, lorsque le serveur X rapporte un événement GraphicsExpose à une application cliente, il envoie une structure XGraphicsExposeEvent avec le membre type défini à GraphicsExpose. Le membre display est défini à un pointeur vers le display sur lequel l'événement a été lu. Le membre send_event est défini à True si l'événement provient d'une requête de protocole SendEvent. Le membre serial est défini à partir du numéro de série rapporté dans le protocole mais développé à partir des 16 bits les moins significatifs vers une valeur complète de 32 bits. Le membre window est défini à la fenêtre la plus utile pour les gestionnaires de dispatching de toolkits.

Le membre event est défini soit à la fenêtre qui a été déplacée, soit à son parent, selon que StructureNotify ou SubstructureNotify a été sélectionné. Le membre window est défini à la fenêtre enfant qui a été déplacée. Les membres x et y sont définis aux coordonnées relatives à l'origine de la nouvelle fenêtre parente et indiquent la position du coin supérieur gauche extérieur de la fenêtre.
