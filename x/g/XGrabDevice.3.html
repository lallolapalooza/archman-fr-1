XGRABDEVICE(3)   XGRABDEVICE(3)

NOM

XGrabDevice, XUngrabDevice - saisir/relâcher le périphérique d'extension spécifié

SYNTAXE

#include <X11/extensions/XInput.h>
int XGrabDevice( Display *display,
                 XDevice* device,
                 Window grab_window,
                 Bool owner_events,
                 int event_count,
                 XEventClass *event_list,
                 int this_device_mode,
                 int other_devices_mode,
                 Time time);
int XUngrabDevice( Display *display,
                   XDevice *device,
                   Time time);
display
       Spécifie la connexion au serveur X.
device
       Spécifie le périphérique à saisir ou relâcher.
grab_window
       Spécifie l'identifiant d'une fenêtre à associer au
       périphérique.
owner_events
       Spécifie une valeur booléenne indiquant si les
       événements du périphérique doivent être rapportés comme
       d'habitude ou rapportés par rapport à la fenêtre de saisie
       s'ils sont sélectionnés par la liste d'événements.
event_count
       Spécifie le nombre d'éléments dans le tableau event_list.
event_list
       Spécifie un pointeur vers une liste de classes d'événements
       indiquant quels événements le client souhaite recevoir.
       Ces classes d'événements doivent avoir été obtenues en
       spécifiant le périphérique saisi.
this_device_mode
       Spécifie le traitement supplémentaire des événements de ce
       périphérique. Vous pouvez passer GrabModeSync ou
       GrabModeAsync.
other_devices_mode
       Spécifie le traitement supplémentaire des événements des
       autres périphériques. Vous pouvez passer GrabModeSync ou
       GrabModeAsync.
time
       Spécifie l'heure. Vous pouvez passer un horodatage ou
       CurrentTime.

DESCRIPTION

La requête XGrabDevice saisit activement le contrôle du
périphérique et génère des événements DeviceFocusIn et
DeviceFocusOut. Les événements de périphérique ultérieurs ne sont
rapportés qu'au client qui saisit. XGrabDevice remplace toute saisie
de périphérique active par ce client. event_list est un pointeur vers une
liste de classes d'événements. Cette liste indique quels événements le
client souhaite recevoir pendant que la saisie est active. Si
owner_events est Faux, tous les événements de périphérique générés sont
rapportés par rapport à grab_window s'ils sont sélectionnés. Si
owner_events est Vrai et si un événement de périphérique généré est
normalement rapporté à ce client, il est rapporté normalement ; sinon,
l'événement est rapporté par rapport à grab_window, et n'est rapporté que
s'il est spécifié dans event_list.
Si l'argument this_device_mode est GrabModeAsync, le traitement des
événements du périphérique continue normalement. Si le périphérique est
actuellement gelé par ce client, le traitement des événements du
périphérique reprend. Si l'argument this_device_mode est GrabModeSync,
l'état du périphérique (tel que vu par les applications clientes) semble
se figer, et le serveur X ne génère aucun événement de périphérique
supplémentaire jusqu'à ce que le client qui saisit émette un appel
XAllowDeviceEvents de libération ou jusqu'à ce que la saisie du
périphérique soit relâchée. Les changements réels du périphérique ne sont
pas perdus pendant que le périphérique est gelé ; ils sont simplement mis
en file d'attente dans le serveur pour un traitement ultérieur.
Si other_devices_mode est GrabModeAsync, le traitement des événements
des autres périphériques n'est pas affecté par l'activation de la
saisie. Si other_devices_mode est GrabModeSync, l'état de tous les
périphériques sauf le périphérique saisi (tel que vu par les applications
clientes) semble se figer, et le serveur X ne génère aucun événement
supplémentaire de ces périphériques jusqu'à ce que le client qui saisit
émette un appel XAllowDeviceEvents de libération ou jusqu'à ce que la saisie
du périphérique soit relâchée. Les événements réels ne sont pas perdus
pendant que les périphériques sont gelés ; ils sont simplement mis en file
d'attente dans le serveur pour un traitement ultérieur.
Si le périphérique est activement saisi par un autre client,
XGrabDevice échoue et retourne AlreadyGrabbed. Si grab_window n'est pas
visible, il échoue et retourne GrabNotViewable. Si le périphérique est
gelé par une saisie active d'un autre client, il échoue et retourne
GrabFrozen. Si l'heure spécifiée est antérieure à la dernière heure de
saisie du périphérique ou postérieure à l'heure actuelle du serveur X,
il échoue et retourne GrabInvalidTime. Sinon, la dernière heure de saisie
du périphérique est définie à l'heure spécifiée (CurrentTime est remplacé par
l'heure actuelle du serveur X).
Si un périphérique saisi est fermé par un client alors qu'une saisie
active par ce client est en vigueur, la saisie active est relâchée. Si le
périphérique n'est gelé que par une saisie active du client demandeur, il est
dégelé.
XGrabDevice peut générer des erreurs BadClass, BadDevice, BadValue et
BadWindow.
La requête XUngrabDevice relâche le périphérique et tous les événements
mis en file d'attente si ce client le tient activement saisi par
XGrabDevice ou XGrabDeviceKey. Si d'autres périphériques sont gelés par la
saisie, XUngrabDevice les dégèle. XUngrabDevice ne relâche pas le
périphérique et les événements mis en file d'attente si l'heure spécifiée est
antérieure à la dernière heure de saisie du périphérique ou est postérieure
à l'heure actuelle du serveur X. Elle génère également des événements
DeviceFocusIn et DeviceFocusOut. Le serveur X effectue automatiquement une
requête UngrabDevice si la fenêtre d'événement d'une saisie de périphérique
active devient non visible.
XUngrabDevice peut générer une erreur BadDevice.

DIAGNOSTICS

BadDevice
       Un périphérique invalide a été spécifié. Le périphérique
       spécifié n'existe pas ou n'a pas été ouvert par ce client
       via XOpenInputDevice. Cette erreur peut également se
       produire si le périphérique spécifié est le clavier X ou
       le pointeur X.
BadValue
       Une valeur numérique tombe en dehors de la plage de valeurs
       acceptées par la requête. Sauf si une plage spécifique est
       indiquée pour un argument, la plage complète définie par le
       type de l'argument est acceptée. Tout argument défini comme
       un ensemble d'alternatives peut générer cette erreur.
BadWindow
       Une valeur pour un argument Window ne nomme pas une Window
       définie.
