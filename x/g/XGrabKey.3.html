XGrabKey(3) FONCTIONS XLIB XGrabKey(3)

NOM

XGrabKey, XUngrabKey - Saisir les touches du clavier

SYNTAXE

int XGrabKey(Display *display, int keycode, unsigned int modifiers, Window grab_window, Bool owner_events, int pointer_mode, int keyboard_mode);

int XUngrabKey(Display *display, int keycode, unsigned int modifiers, Window grab_window);

ARGUMENTS

display
Spécifie la connexion au serveur X.
grab_window
Spécifie la fenêtre de saisie.
keyboard_mode
Spécifie le traitement ultérieur des événements clavier. Vous pouvez passer GrabModeSync ou GrabModeAsync.
keycode
Spécifie le KeyCode ou AnyKey.
modifiers
Spécifie l'ensemble des masques de touches ou AnyModifier. Le masque est l'OU bit à bit inclusif des bits de masques de touches valides.
owner_events
Spécifie une valeur booléenne indiquant si les événements clavier doivent être rapportés comme d'habitude.
pointer_mode
Spécifie le traitement ultérieur des événements du pointeur. Vous pouvez passer GrabModeSync ou GrabModeAsync.

DESCRIPTION

La fonction XGrabKey établit une saisie passive sur le clavier. À l'avenir, le clavier est activement saisi (comme pour XGrabKeyboard), l'heure de la dernière saisie clavier est définie à l'heure à laquelle la touche a été pressée (telle que transmise dans l'événement KeyPress), et l'événement KeyPress est rapporté si toutes les conditions suivantes sont vraies :

  • Le clavier n'est pas saisi et la touche spécifiée (qui peut elle-même être une touche modifiatrice) est logiquement enfoncée lorsque les touches modificatrices spécifiées sont logiquement enfoncées, et aucune autre touche modificatrice n'est logiquement enfoncée.
  • Soit la fenêtre de saisie est un ancêtre de (ou est) la fenêtre de focus, soit la fenêtre de saisie est un descendant de la fenêtre de focus et contient le pointeur.
  • Une saisie passive sur la même combinaison de touches n'existe sur aucun ancêtre de la fenêtre de saisie.

L'interprétation des arguments restants est la même que pour XGrabKeyboard. La saisie active est terminée automatiquement lorsque l'état logique du clavier a la touche spécifiée relâchée (indépendamment de l'état logique des touches modificatrices), moment auquel un événement KeyRelease est rapporté à la fenêtre de saisie.

Notez que l'état logique d'un périphérique (tel qu'il est vu par les applications clientes) peut être en retard par rapport à l'état physique si le traitement des événements du périphérique est gelé.

Un argument de modificateurs de AnyModifier est équivalent à lancer la requête pour toutes les combinaisons de modificateurs possibles (y compris la combinaison d'aucun modificateur). Il n'est pas nécessaire que tous les modificateurs spécifiés aient des KeyCodes actuellement assignés. Un argument keycode de AnyKey est équivalent à lancer la requête pour tous les KeyCodes possibles. Sinon, le keycode spécifié doit être dans la plage spécifiée par min_keycode et max_keycode dans la configuration de la connexion, ou une erreur BadValue en résulte.

Si un autre client a effectué un XGrabKey avec la même combinaison de touches sur la même fenêtre, une erreur BadAccess en résulte. Lors de l'utilisation de AnyModifier ou AnyKey, la requête échoue complètement, et une erreur BadAccess en résulte (aucune saisie n'est établie) s'il existe une saisie conflictuelle pour une combinaison quelconque.

XGrabKey peut générer des erreurs BadAccess, BadValue et BadWindow.

La fonction XUngrabKey libère la combinaison de touches sur la fenêtre spécifiée si elle a été saisie par ce client. Elle n'a aucun effet sur une saisie active. Un modificateur de AnyModifier est équivalent à lancer la requête pour toutes les combinaisons de modificateurs possibles (y compris la combinaison d'aucun modificateur). Un argument keycode de AnyKey est équivalent à lancer la requête pour tous les codes de touches possibles.

XUngrabKey peut générer des erreurs BadValue et BadWindow.

DIAGNOSTICS

BadAccess
Un client a tenté de saisir une combinaison de touches/boutons déjà saisie par un autre client.
BadValue
Une valeur numérique se situe en dehors de la plage des valeurs acceptées par la requête. Sauf si une plage spécifique est spécifiée pour un argument, la plage complète définie par le type de l'argument est acceptée. Tout argument défini comme un ensemble d'alternatives peut générer cette erreur.
BadWindow
Une valeur pour un argument Window ne nomme pas une Window définie.
