XSetTextProperty(3) FONCTIONS XLIB XSetTextProperty(3)

NOM

XSetTextProperty, XGetTextProperty - définir et lire les propriétés de texte

SYNTAXE

void XSetTextProperty(Display *display, Window w, XTextProperty *text_prop, Atom property);

Status XGetTextProperty(Display *display, Window w, XTextProperty *text_prop_return, Atom property);

ARGUMENTS

display
Spécifie la connexion au serveur X.
property
Spécifie le nom de la propriété.
text_prop
Spécifie la structure XTextProperty à utiliser.
text_prop_return
Retourne la structure XTextProperty.

DESCRIPTION

La fonction XSetTextProperty remplace la propriété spécifiée existante pour la fenêtre nommée par les données, le type, le format et le nombre d'éléments déterminés respectivement par le champ value, le champ encoding, le champ format et le champ nitems de la structure XTextProperty spécifiée. Si la propriété n'existe pas encore, XSetTextProperty la définit pour la fenêtre spécifiée.

XSetTextProperty peut générer des erreurs BadAlloc, BadAtom, BadValue et BadWindow.

La fonction XGetTextProperty lit la propriété spécifiée de la fenêtre et stocke les données dans la structure XTextProperty retournée. Elle stocke les données dans le champ value, le type des données dans le champ encoding, le format des données dans le champ format et le nombre d'éléments de données dans le champ nitems. Un octet supplémentaire contenant un caractère nul (qui n'est pas inclus dans le membre nitems) est stocké à la fin du champ value de text_prop_return. L'interprétation particulière de l'encodage et des données de la propriété en tant que texte est laissée à l'application appelante. Si la propriété spécifiée n'existe pas sur la fenêtre, XGetTextProperty définit le champ value à NULL, le champ encoding à None, le champ format à zéro et le champ nitems à zéro.

Si elle a pu lire et stocker les données dans la structure XTextProperty, XGetTextProperty retourne un statut non nul ; sinon, elle retourne un statut zéro.

XGetTextProperty peut générer des erreurs BadAtom et BadWindow.

PROPRIÉTÉS

WM_CLIENT_MACHINE
Le nom de chaîne de la machine sur laquelle l'application cliente est en cours d'exécution.
WM_COMMAND
La commande et ses arguments, séparés par des null, utilisés pour invoquer l'application.
WM_ICON_NAME
Le nom à utiliser dans une icône.
WM_NAME
Le nom de l'application.

DIAGNOSTICS

BadAlloc
Le serveur n'a pas pu allouer la ressource demandée ou la mémoire du serveur.
BadAtom
Une valeur pour un argument Atom ne nomme pas un Atom défini.
BadValue
Une valeur numérique tombe en dehors de la plage des valeurs acceptées par la requête. Sauf si une plage spécifique est spécifiée pour un argument, la plage complète définie par le type de l'argument est acceptée. Tout argument défini comme un ensemble d'alternatives peut générer cette erreur.
BadWindow
Une valeur pour un argument Window ne nomme pas une Window définie.
