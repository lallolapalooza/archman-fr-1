XGRABDEVICEKEY(3)   XGRABDEVICEKEY(3)

NOM

XGrabDeviceKey, XUngrabDeviceKey - saisir/libérer les touches du périphérique d'extension

SYNOPIS

#include <X11/extensions/XInput.h>
int XGrabDeviceKey( Display *display,
                    XDevice *device,
                    unsigned int key,
                    unsigned int modifiers,
                    XDevice *modifier_device,
                    Window grab_window,
                    Bool owner_events,
                    unsigned int event_count,
                    XEventClass *event_list,
                    int this_device_mode,
                    int other_devices_mode);
int XUngrabDeviceKey( Display *display,
                      XDevice *device,
                      unsigned int key,
                      unsigned int modifiers,
                      XDevice *modifier_device,
                      Window grab_window);
display
       Spécifie la connexion au serveur X.
device
       Spécifie le périphérique qui doit être saisi ou libéré.
Key
       Spécifie la touche du périphérique qui doit être saisie ou libérée, ou AnyKey.
modifiers
       Spécifie l'ensemble des masques de touches ou AnyModifier. Le masque est le OU
       inclusif bit à bit des bits de masques de touches valides. Les bits valides sont :
       ShiftMask, LockMask, ControlMask, Mod1Mask, Mod2Mask, Mod3Mask, Mod4Mask,
       Mod5Mask.
modifier_device
       Spécifie le périphérique dont les modificateurs doivent être utilisés. Si un
       modifier_device de NULL est spécifié, le clavier X sera utilisé comme
       modifier_device.
grab_window
       Spécifie la fenêtre de saisie.
owner_events
       Spécifie une valeur booléenne indiquant si les événements du périphérique doivent
       être rapportés comme d'habitude ou rapportés par rapport à la fenêtre de saisie s'ils
       sont sélectionnés par la liste d'événements.
event_count
       Spécifie le nombre de classes d'événements dans la liste d'événements.
event_list
       Spécifie quels événements du périphérique sont rapportés au client.
this_device_mode
       Spécifie le traitement ultérieur des événements de ce périphérique. Vous pouvez
       utiliser GrabModeSync ou GrabModeAsync.
other_devices_mode
       Spécifie le traitement ultérieur des événements des autres périphériques. Vous pouvez
       utiliser GrabModeSync ou GrabModeAsync.

DESCRIPTION

La requête XGrabDeviceKey établit une saisie passive. À l'avenir, le périphérique est saisi
activement (comme pour XGrabDevice, l'heure de la dernière saisie de périphérique est définie
à l'heure à laquelle la touche a été pressée (telle que transmise dans l'événement
DeviceKeyPress), et l'événement DeviceKeyPress est rapporté si toutes les conditions suivantes
sont vraies :
  * Le périphérique n'est pas saisi, et la touche spécifiée est logiquement enfoncée lorsque les
    touches modificatrices spécifiées sont logiquement enfoncées, et aucune autre touche ou touche
    modificatrice n'est logiquement enfoncée.
  * La fenêtre grab_window est un ancêtre (ou est) la fenêtre de focus OU la fenêtre grab_window
    est un descendant de la fenêtre de focus et contient le périphérique.
  * La fenêtre de confinement (s'il y en a une) est visible.
  * Une saisie passive sur la même combinaison de touche/modificateur n'existe sur aucun ancêtre
    de grab_window.
L'interprétation des arguments restants est la même que pour XGrabDevice. La saisie active
est terminée automatiquement lorsque l'état logique du périphérique a la touche spécifiée relâchée.
Notez que l'état logique d'un périphérique (tel que vu par le biais du protocole X) peut
être en retard sur l'état physique si le traitement des événements du périphérique est gelé.
Si la touche n'est pas AnyKey, elle doit être dans la plage spécifiée par min_keycode et
max_keycode telles que retournées par la requête XListInputDevices. Sinon, une erreur BadValue
résulte.
Cette requête remplace toutes les saisies précédentes par le même client sur les mêmes combinaisons
de touches/modificateurs sur la même fenêtre. Un modificateur de AnyModifier est équivalent à
l'émission de la requête de saisie pour toutes les combinaisons de modificateurs possibles (y compris
la combinaison sans aucun modificateur). Il n'est pas nécessaire que tous les modificateurs spécifiés
aient actuellement des KeyCodes attribués. Une touche AnyKey est équivalente à l'émission de la requête
pour toutes les touches possibles. Sinon, il n'est pas nécessaire que la touche spécifiée soit
actuellement assignée à une touche physique.
Si un modifier_device de NULL est spécifié, le clavier X sera utilisé comme modifier_device.
Si un autre client a déjà émis un XGrabDeviceKey avec la même combinaison de touches/modificateurs sur
la même fenêtre, une erreur BadAccess résulte. Lors de l'utilisation de AnyModifier ou AnyKey, la requête
échoue complètement, et une erreur BadAccess résulte (aucune saisie n'est établie) s'il y a une saisie
conflictuelle pour une combinaison quelconque. XGrabDeviceKey n'a aucun effet sur une saisie active.
XGrabDeviceKey peut générer les erreurs BadAccess, BadClass, BadDevice, BadMatch, BadValue et
BadWindow. Il retourne Success en cas de succès de la requête.
La requête XUngrabDeviceKey libère la saisie passive pour une combinaison de touche/modificateur sur la
fenêtre spécifiée si elle a été saisie par ce client. Un modificateur de AnyModifier est équivalent à
l'émission de la requête de libération pour toutes les combinaisons de modificateurs possibles, y compris
la combinaison sans aucun modificateur. Une touche AnyKey est équivalente à l'émission de la requête pour
toutes les touches possibles. XUngrabDeviceKey n'a aucun effet sur une saisie active.
Si un modifier_device de NULL est spécifié, le clavier X sera utilisé comme modifier_device.
XUngrabDeviceKey peut générer les erreurs BadDevice, BadMatch, BadValue et BadWindow.

DIAGNOSTICS

BadDevice
       Un périphérique invalide a été spécifié. Le périphérique spécifié n'existe pas ou n'a pas
       été ouvert par ce client via XOpenInputDevice. Cette erreur peut également survenir si le
       périphérique spécifié est le clavier X ou le pointeur X.
BadMatch
       Cette erreur peut survenir si une requête XGrabDeviceKey a été faite en spécifiant un
       périphérique qui n'a pas de touches, ou un périphérique modificateur qui n'a pas de touches.
BadValue
       Une valeur numérique se situe en dehors de la plage de valeurs acceptées par la requête.
       À moins qu'une plage spécifique ne soit définie pour un argument, la plage complète définie par
       le type de l'argument est acceptée. Tout argument défini comme un ensemble d'alternatives peut
       générer cette erreur.
BadWindow
       Une valeur pour un argument Window ne nomme pas une Window définie.

Installer un paquet Arch Linux

Installer un paquet Arch Linux

Ce guide vous montrera comment installer un paquet sur votre système Arch Linux. Arch Linux utilise le gestionnaire de paquets pacman.

Étape 1 : Mettre à jour votre système

Avant d'installer de nouveaux paquets, il est toujours recommandé de mettre à jour votre système pour vous assurer d'avoir les dernières versions des paquets installés et pour éviter les problèmes de dépendances.

sudo pacman -Syu

Entrez votre mot de passe lorsque vous y êtes invité. La commande -Syu fait ce qui suit :

  • -S : Synchronise les paquets.
  • y : Met à jour la liste des paquets à partir des dépôts.
  • u : Met à jour les paquets installés.

Étape 2 : Rechercher un paquet (Optionnel)

Si vous ne connaissez pas le nom exact du paquet que vous souhaitez installer, vous pouvez le rechercher. Par exemple, pour rechercher des paquets liés à firefox :

sudo pacman -Ss firefox

Cette commande recherchera dans les dépôts le mot-clé spécifié.

Étape 3 : Installer un paquet

Pour installer un paquet, utilisez la commande -S suivie du nom du paquet. Par exemple, pour installer firefox :

sudo pacman -S firefox

pacman vous demandera de confirmer l'installation et vous montrera les dépendances qui seront également installées. Appuyez sur Y puis Entrée pour continuer.

Étape 4 : Vérifier l'installation

Une fois l'installation terminée, vous pouvez vérifier que le paquet est installé. La méthode pour vérifier dépend du type de paquet. Pour un programme exécutable, vous pouvez généralement simplement taper son nom dans le terminal :

firefox --version

Ou, vous pouvez lister tous les paquets installés et filtrer par nom :

pacman -Q | grep firefox

Désinstaller un paquet

Si vous souhaitez désinstaller un paquet, utilisez la commande -R. Par exemple, pour désinstaller firefox :

sudo pacman -R firefox

Pour désinstaller un paquet et ses dépendances qui ne sont plus nécessaires par d'autres paquets :

sudo pacman -Rs firefox

Fait avec ♥ en utilisant Arch Linux.
