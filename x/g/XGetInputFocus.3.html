XSetInputFocus(3) FONCTIONS XLIB XSetInputFocus(3)

NOM

XSetInputFocus, XGetInputFocus - contrôler le focus d'entrée

SYNTAXE

int XSetInputFocus(Display *display, Window focus, int revert_to, Time time);

int XGetInputFocus(Display *display, Window *focus_return, int *revert_to_return);

ARGUMENTS

display
Spécifie la connexion au serveur X.
focus
Spécifie la fenêtre, PointerRoot, ou None.
focus_return
Retourne la fenêtre de focus, PointerRoot, ou None.
revert_to
Spécifie vers où le focus d'entrée est rétabli si la fenêtre devient non visible. Vous pouvez passer RevertToParent, RevertToPointerRoot, ou RevertToNone.
revert_to_return
Retourne l'état actuel du focus (RevertToParent, RevertToPointerRoot, ou RevertToNone).
time
Spécifie le temps. Vous pouvez passer un horodatage ou CurrentTime.

DESCRIPTION

La fonction XSetInputFocus change le focus d'entrée et l'heure du dernier changement de focus. Elle n'a aucun effet si l'heure spécifiée est antérieure à l'heure actuelle du dernier changement de focus ou est postérieure à l'heure actuelle du serveur X. Sinon, l'heure du dernier changement de focus est définie à l'heure spécifiée (CurrentTime est remplacé par l'heure actuelle du serveur X). XSetInputFocus provoque la génération d'événements FocusIn et FocusOut par le serveur X.

Selon l'argument focus, le comportement suivant se produit :

  • Si focus est None, tous les événements du clavier sont rejetés jusqu'à ce qu'une nouvelle fenêtre de focus soit définie, et l'argument revert_to est ignoré.
  • Si focus est une fenêtre, elle devient la fenêtre de focus du clavier. Si un événement clavier généré devait normalement être rapporté à cette fenêtre ou à l'un de ses inférieurs, l'événement est rapporté comme d'habitude. Sinon, l'événement est rapporté par rapport à la fenêtre de focus.
  • Si focus est PointerRoot, la fenêtre de focus est dynamiquement considérée comme étant la fenêtre racine de l'écran sur lequel se trouve le pointeur à chaque événement clavier. Dans ce cas, l'argument revert_to est ignoré.

La fenêtre de focus spécifiée doit être visible au moment où XSetInputFocus est appelée, sinon une erreur BadMatch se produit. Si la fenêtre de focus devient plus tard non visible, le serveur X évalue l'argument revert_to pour déterminer la nouvelle fenêtre de focus comme suit :

  • Si revert_to est RevertToParent, le focus est rétabli sur le parent (ou l'ancêtre visible le plus proche), et la nouvelle valeur de revert_to est considérée comme RevertToNone.
  • Si revert_to est RevertToPointerRoot ou RevertToNone, le focus est rétabli sur PointerRoot ou None, respectivement. Lorsque le focus est rétabli, le serveur X génère des événements FocusIn et FocusOut, mais l'heure du dernier changement de focus n'est pas affectée.

XSetInputFocus peut générer les erreurs BadMatch, BadValue, et BadWindow.

La fonction XGetInputFocus retourne la fenêtre de focus et l'état actuel du focus.

DIAGNOSTICS

BadValue
Une valeur numérique se situe en dehors de la plage de valeurs acceptées par la requête. Sauf si une plage spécifique est spécifiée pour un argument, la plage complète définie par le type de l'argument est acceptée. Tout argument défini comme un ensemble d'alternatives peut générer cette erreur.
BadWindow
Une valeur pour un argument Window ne désigne pas une Window définie.
