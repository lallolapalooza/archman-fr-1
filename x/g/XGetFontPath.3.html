XSetFontPath(3) FONCTIONS XLIB XSetFontPath(3)

NOM

XSetFontPath, XGetFontPath, XFreeFontPath - définir, obtenir ou libérer le chemin de recherche des polices

SYNTAX

int XSetFontPath(Display *display, char **directories, int ndirs);

char **XGetFontPath(Display *display, int *npaths_return);

int XFreeFontPath(char **list);

ARGUMENTS

directories
Spécifie le chemin du répertoire utilisé pour rechercher une police. Définir le chemin à une liste vide restaure le chemin par défaut défini pour le serveur X.
display
Spécifie la connexion au serveur X.
list
Spécifie le tableau de chaînes que vous souhaitez libérer.
ndirs
Spécifie le nombre de répertoires dans le chemin.
npaths_return
Retourne le nombre de chaînes dans le tableau du chemin des polices.

DESCRIPTION

La fonction XSetFontPath définit le chemin de recherche des répertoires pour la recherche de polices. Il n'y a qu'un seul chemin de recherche par serveur X, pas un par client. L'encodage et l'interprétation des chaînes dépendent de l'implémentation, mais généralement elles spécifient des répertoires ou des serveurs de polices à rechercher dans l'ordre listé. Un serveur X est autorisé à mettre en cache les informations de police en interne ; par exemple, il peut mettre en cache une police entière à partir d'un fichier et ne pas vérifier lors des ouvertures ultérieures de cette police pour voir si le fichier de police sous-jacent a changé. Cependant, lorsque le chemin des polices est modifié, le serveur X est garanti de vider toutes les informations mises en cache concernant les polices pour lesquelles aucun identifiant de ressource explicite n'est actuellement alloué. La signification d'une erreur provenant de cette requête dépend de l'implémentation.

XSetFontPath peut générer une erreur BadValue.

La fonction XGetFontPath alloue et retourne un tableau de chaînes contenant le chemin de recherche. Le contenu de ces chaînes dépend de l'implémentation et n'est pas destiné à être interprété par les applications client. Lorsqu'il n'est plus nécessaire, les données du chemin des polices doivent être libérées en utilisant XFreeFontPath.

La fonction XFreeFontPath libère les données allouées par XGetFontPath.

DIAGNOSTICS

BadValue
Une valeur numérique tombe en dehors de la plage de valeurs acceptées par la requête. Sauf si une plage spécifique est spécifiée pour un argument, la plage complète définie par le type de l'argument est acceptée. Tout argument défini comme un ensemble d'alternatives peut générer cette erreur.
