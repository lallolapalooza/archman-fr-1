Paquet: libx11

XSetWMProtocols(3) FONCTIONS XLIB XSetWMProtocols(3)

NOM

XSetWMProtocols, XGetWMProtocols - définir ou lire la propriété WM_PROTOCOLS d'une fenêtre

SYNTAXE

Status XSetWMProtocols(Display *display, Window w, Atom *protocols, int count);

Status XGetWMProtocols(Display *display, Window w, Atom **protocols_return, int *count_return);

ARGUMENTS

display
Spécifie la connexion au serveur X.
count
Spécifie le nombre de protocoles dans la liste.
count_return
Retourne le nombre de protocoles dans la liste.
protocols
Spécifie la liste des protocoles.
protocols_return
Retourne la liste des protocoles.

DESCRIPTION

La fonction XSetWMProtocols remplace la propriété WM_PROTOCOLS sur la fenêtre spécifiée par la liste d'atomes spécifiée par l'argument protocols. Si la propriété n'existe pas déjà, XSetWMProtocols définit la propriété WM_PROTOCOLS sur la fenêtre spécifiée à la liste d'atomes spécifiée par l'argument protocols. La propriété est stockée avec un type ATOM et un format 32. Si elle ne peut pas intern l'atome WM_PROTOCOLS, XSetWMProtocols retourne un statut zéro. Sinon, elle retourne un statut non nul.

XSetWMProtocols peut générer des erreurs BadAlloc et BadWindow.

La fonction XGetWMProtocols retourne la liste d'atomes stockée dans la propriété WM_PROTOCOLS sur la fenêtre spécifiée. Ces atomes décrivent les protocoles du gestionnaire de fenêtres auxquels le propriétaire de cette fenêtre est disposé à participer. Si la propriété existe, est de type ATOM, est de format 32, et si l'atome WM_PROTOCOLS peut être interné, XGetWMProtocols définit l'argument protocols_return à une liste d'atomes, définit l'argument count_return au nombre d'éléments dans la liste, et retourne un statut non nul. Sinon, elle ne définit aucun des arguments de retour et retourne un statut zéro. Pour libérer la liste d'atomes, utilisez XFree.

XGetWMProtocols peut générer une erreur BadWindow.

PROPRIÉTÉS

WM_PROTOCOLS
Liste d'atomes identifiant les protocoles de communication entre le client et le gestionnaire de fenêtres auxquels le client est disposé à participer.

DIAGNOSTICS

BadAlloc
Le serveur n'a pas pu allouer la ressource demandée ou la mémoire du serveur.
BadWindow
Une valeur pour un argument Window ne nomme pas une Window définie.
