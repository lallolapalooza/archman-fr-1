XGETFEEDBACKCONTROL(3)   XGETFEEDBACKCONTROL(3)

NOM

XGetFeedbackControl, XChangeFeedbackControl - interroger et modifier les rétroactions des périphériques d'entrée

SYNTAXE

#include <X11/extensions/XInput.h>
XFeedbackState *XGetFeedbackControl( Display *display,
                                     XDevice *device,
                                     int *num_feedbacks);
int XChangeFeedbackControl( Display *display,
                            XDevice *device,
                            Mask mask,
                            XFeedbackControl *control);
display
       Spécifie la connexion au serveur X.
device
       Spécifie le périphérique dont les rétroactions doivent être interrogées
       ou modifiées.
num_feedbacks
       Spécifie une adresse où le nombre de rétroactions prises en charge par le
       périphérique doit être retourné.
mask
       Spécifie un masque spécifique à chaque type de rétroaction qui décrit
       comment la rétroaction doit être modifiée.
control
       Spécifie l'adresse d'une structure XFeedbackControl qui contient les nouvelles
       valeurs pour la rétroaction.

DESCRIPTION

Ces requêtes sont fournies pour manipuler les périphériques d'entrée qui
prennent en charge les rétroactions. Une erreur BadMatch sera générée si
le périphérique demandé ne prend pas en charge les rétroactions. Le fait qu'un
périphérique donné prenne en charge ou non les rétroactions peut être déterminé
en examinant les informations renvoyées par la requête XOpenDevice.
Pour les périphériques qui prennent en charge les rétroactions, XOpenDevice
renverra une structure XInputClassInfo avec le champ input_class égal à la
constante FeedbackClass (définie dans le fichier XI.h).
La requête XGetFeedbackControl renvoie un pointeur vers une liste de
structures XFeedbackState. Chaque élément de cette liste décrit une des
rétroactions prises en charge par le périphérique. Les éléments sont de longueur
variable, donc chacun contient sa longueur pour permettre de passer à l'élément
suivant de la liste.
Les classes de rétroactions actuellement définies sont :
KbdFeedbackClass, PtrFeedbackClass, StringFeedbackClass,
IntegerFeedbackClass, LedFeedbackClass et BellFeedbackClass.
Ces constantes sont définies dans le fichier XI.h. Un périphérique d'entrée peut
prendre en charge zéro ou plusieurs classes de rétroactions, et peut prendre en
charge plusieurs rétroactions de la même classe. Chaque rétroaction contient un
identifiant de classe et un id qui est unique au sein de cette classe pour ce
périphérique d'entrée. L'id est utilisé pour identifier la rétroaction lors d'une
requête XChangeFeedbackControl.
XGetFeedbackControl peut générer une erreur BadDevice ou BadMatch.
La requête XChangeFeedbackControl modifie les valeurs d'une rétroaction sur
le périphérique spécifié. La rétroaction est identifiée par le champ id de la
structure XFeedbackControl qui est passée avec la requête. Les champs de la
rétroaction qui doivent être modifiés sont identifiés par les bits du masque qui
est passé avec la requête.
XChangeFeedbackControl peut générer une erreur BadDevice, BadMatch ou
BadValue.

Structures

Chaque classe de rétroaction est décrite par une structure spécifique à cette
classe. Ces structures sont définies dans le fichier XInput.h.
XFeedbackState et XFeedbackControl sont des structures génériques qui contiennent
trois champs qui se trouvent au début de chaque classe de rétroaction :
typedef struct {
    XID class;
    int length;
    XID id;
} XFeedbackState, XFeedbackControl;
La structure XKbdFeedbackState définit les attributs qui sont renvoyés pour les
rétroactions équivalentes à celles du clavier X.
typedef struct {
    XID class;
    int length;
    XID id;
    int click;
    int percent;
    int pitch;
    int duration;
    int led_mask;
    int global_auto_repeat;
    char auto_repeats[32];
} XKbdFeedbackState;
La structure XPtrFeedbackState définit les attributs qui sont renvoyés pour les
rétroactions équivalentes à celles du pointeur X.
typedef struct {
    XID class;
    int length;
    XID id;
    int accelNum;
    int accelDenom;
    int threshold;
} XPtrFeedbackState;
La structure XIntegerFeedbackState définit les attributs qui sont renvoyés pour
les rétroactions entières.
typedef struct {
    XID class;
    int length;
    XID id;
    int resolution;
    int minVal;
    int maxVal;
} XIntegerFeedbackState;
La structure XStringFeedbackState définit les attributs qui sont renvoyés pour
les rétroactions de chaîne.
typedef struct {
    XID class;
    int length;
    XID id;
    int max_symbols;
    int num_syms_supported;
    KeySym *syms_supported;
} XStringFeedbackState;
La structure XBellFeedbackState définit les attributs qui sont renvoyés pour les
rétroactions de sonnerie.
typedef struct {
    XID class;
    int length;
    XID id;
    int percent;
    int pitch;
    int duration;
} XBellFeedbackState;
La structure XLedFeedbackState définit les attributs qui sont renvoyés pour les
rétroactions de LED.
typedef struct {
    XID class;
    int length;
    XID id;
    int led_values;
} XLedFeedbackState;
La structure XPrtFeedbackControl définit les attributs qui peuvent être contrôlés
pour les rétroactions de pointeur.
typedef struct {
    XID class;
    int length;
    XID id;
    int accelNum;
    int accelDenom;
    int threshold;
} XPtrFeedbackControl;
La structure XKbdFeedbackControl définit les attributs qui peuvent être contrôlés
pour les rétroactions de clavier.
typedef struct {
    XID class;
    int length;
    XID id;
    int click;
    int percent;
    int pitch;
    int duration;
    int led_mask;
    int led_value;
    int key;
    int auto_repeat_mode;
} XKbdFeedbackControl;
La structure XStringFeedbackControl définit les attributs qui peuvent être
contrôlés pour les rétroactions de chaîne.
typedef struct {
    XID class;
    int length;
    XID id;
    int num_keysyms;
    KeySym  *syms_to_display;
} XStringFeedbackControl;
La structure XIntegerFeedbackControl définit les attributs qui peuvent être
contrôlés pour les rétroactions entières.
typedef struct {
    XID class;
    int length;
    XID id;
    int int_to_display;
} XIntegerFeedbackControl;
La structure XBellFeedbackControl définit les attributs qui peuvent être
contrôlés pour les rétroactions de sonnerie.
typedef struct {
    XID     class;
    int     length;
    XID     id;
    int     percent;
    int     pitch;
    int     duration;
} XBellFeedbackControl;
La structure XLedFeedbackControl définit les attributs qui peuvent être
contrôlés pour les rétroactions de LED.
typedef struct {
    XID     class;
    int     length;
    XID     id;
    int     led_mask;
    int     led_values;
} XLedFeedbackControl;

DIAGNOSTIQUES

BadDevice
       Un périphérique invalide a été spécifié. Le périphérique spécifié
       n'existe pas ou n'a pas été ouvert par ce client via
       XOpenInputDevice. Cette erreur peut également se produire si un autre
       client a fait du périphérique spécifié le clavier X ou le pointeur X via
       les requêtes XChangeKeyboardDevice ou XChangePointerDevice.
BadMatch
       Cette erreur peut se produire si une requête XGetFeedbackControl a été
       faite en spécifiant un périphérique qui n'a pas de rétroactions, ou si une
       requête XChangeFeedbackControl a été faite avec une structure
       XFeedbackControl contenant un type de rétroaction invalide. Elle peut
       également se produire si une combinaison invalide de bits de masque est
       spécifiée (DvKey mais pas DvAutoRepeatMode pour les rétroactions de clavier),
       ou si un KeySym invalide est spécifié pour une rétroaction de chaîne.
BadValue
       Une valeur numérique tombe en dehors de la plage des valeurs
       acceptées par la requête XChangeFeedbackControl. Sauf si une
       plage spécifique est spécifiée pour un argument, toute la
       plage définie par le type de l'argument est acceptée. Tout
       argument défini comme un ensemble d'alternatives peut générer
       cette erreur.
