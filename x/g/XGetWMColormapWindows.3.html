XSetWMColormapWindows(3) FONCTIONS XLIB XSetWMColormapWindows(3)

NOM

XSetWMColormapWindows, XGetWMColormapWindows - définir ou lire la propriété WM_COLORMAP_WINDOWS d'une fenêtre

SYNTAXE

Status XSetWMColormapWindows(Display *display, Window w, Window *colormap_windows, int count);

Status XGetWMColormapWindows(Display *display, Window w, Window **colormap_windows_return, int *count_return);

ARGUMENTS

display
Spécifie la connexion au serveur X.
colormap_windows
Spécifie la liste des fenêtres.
colormap_windows_return
Retourne la liste des fenêtres.
count
Spécifie le nombre de fenêtres dans la liste.
count_return
Retourne le nombre de fenêtres dans la liste.
w
Spécifie la fenêtre.

DESCRIPTION

La fonction XSetWMColormapWindows remplace la propriété WM_COLORMAP_WINDOWS sur la fenêtre spécifiée par la liste de fenêtres spécifiée par l'argument colormap_windows. Si la propriété n'existe pas déjà, XSetWMColormapWindows définit la propriété WM_COLORMAP_WINDOWS sur la fenêtre spécifiée avec la liste de fenêtres spécifiée par l'argument colormap_windows. La propriété est stockée avec le type WINDOW et le format 32. Si elle ne peut pas interpréter l'atome WM_COLORMAP_WINDOWS, XSetWMColormapWindows retourne un statut zéro. Sinon, elle retourne un statut non nul.

XSetWMColormapWindows peut générer des erreurs BadAlloc et BadWindow.

La fonction XGetWMColormapWindows retourne la liste des identifiants de fenêtre stockés dans la propriété WM_COLORMAP_WINDOWS sur la fenêtre spécifiée. Ces identifiants indiquent les tables de couleurs que le gestionnaire de fenêtres pourrait avoir besoin d'installer pour cette fenêtre. Si la propriété existe, est de type WINDOW, est de format 32, et que l'atome WM_COLORMAP_WINDOWS peut être interprété, XGetWMColormapWindows définit l'argument windows_return à une liste d'identifiants de fenêtre, définit l'argument count_return au nombre d'éléments dans la liste, et retourne un statut non nul. Sinon, elle ne définit aucun des arguments de retour et retourne un statut zéro. Pour libérer la liste des identifiants de fenêtre, utilisez XFree.

XGetWMColormapWindows peut générer une erreur BadWindow.

PROPRIÉTÉS

WM_COLORMAP_WINDOWS
La liste des ID de fenêtres qui pourraient nécessiter une table de couleurs différente de celle de leur fenêtre de niveau supérieur.

DIAGNOSTICS

BadAlloc
Le serveur n'a pas réussi à allouer la ressource demandée ou la mémoire du serveur.
BadWindow
Une valeur pour un argument Window ne nomme pas une fenêtre définie.
