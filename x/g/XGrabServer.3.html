NOM

XGrabServer, XUngrabServer - saisir le serveur

SYNTAXE

int XGrabServer(Display *display);

int XUngrabServer(Display *display);

ARGUMENTS

display
Spécifie la connexion au serveur X.

DESCRIPTION

La fonction XGrabServer désactive le traitement des requêtes et des fermetures sur toutes les autres connexions que celle sur laquelle cette requête est arrivée. Vous ne devriez pas saisir le serveur X plus que nécessaire.

La fonction XUngrabServer redémarre le traitement des requêtes et des fermetures sur les autres connexions. Vous devriez éviter de saisir le serveur X autant que possible.
