XAllocStandardColormap(3) FONCTIONS XLIB XAllocStandardColormap(3)

NOM

XAllocStandardColormap, XSetRGBColormaps, XGetRGBColormaps, XStandardColormap - allouer, définir ou lire une structure de table de couleurs standard

SYNTAXE

XStandardColormap *XAllocStandardColormap(void);

void XSetRGBColormaps(Display *display, Window w, XStandardColormap *std_colormap, int count, Atom property);

Status XGetRGBColormaps(Display *display, Window w, XStandardColormap **std_colormap_return, int *count_return, Atom property);

ARGUMENTS

display
Spécifie la connexion au serveur X.
count
Spécifie le nombre de tables de couleurs.
count_return
Retourne le nombre de tables de couleurs.
property
Spécifie le nom de la propriété.
std_colormap
Spécifie la structure XStandardColormap à utiliser.
std_colormap_return
Retourne la structure XStandardColormap.

DESCRIPTION

La fonction XAllocStandardColormap alloue et retourne un pointeur vers une structure XStandardColormap. Notez que tous les champs de la structure XStandardColormap sont initialement mis à zéro. Si une mémoire insuffisante est disponible, XAllocStandardColormap retourne NULL. Pour libérer la mémoire allouée à cette structure, utilisez XFree.

La fonction XSetRGBColormaps remplace la définition de la table de couleurs RVB dans la propriété spécifiée sur la fenêtre nommée. Si la propriété n'existe pas déjà, XSetRGBColormaps définit la définition de la table de couleurs RVB dans la propriété spécifiée sur la fenêtre nommée. La propriété est stockée avec le type RGB_COLOR_MAP et un format de 32. Notez qu'il est de la responsabilité de l'appelant de respecter la restriction ICCCM selon laquelle seul RGB_DEFAULT_MAP peut contenir plus d'une définition.

La fonction XSetRGBColormaps est généralement utilisée uniquement par les gestionnaires de fenêtres ou de sessions. Pour créer une table de couleurs standard, suivez cette procédure :

1.
Ouvrez une nouvelle connexion au même serveur.
2.
Accaparez le serveur.
3.
Vérifiez si la propriété figure dans la liste des propriétés de la fenêtre racine pour l'écran.
4.
Si la propriété souhaitée n'est pas présente :
  • Créez une table de couleurs (sauf si vous utilisez la table de couleurs par défaut de l'écran).
  • Déterminez les caractéristiques de couleur de la visualisation.
  • Allouez des cellules dans la table de couleurs (ou créez-la avec AllocAll).
  • Appelez XStoreColors pour stocker des valeurs de couleur appropriées dans la table de couleurs.
  • Remplissez les membres descriptifs de la structure XStandardColormap.
  • Attachez la propriété à la fenêtre racine.
  • Utilisez XSetCloseDownMode pour rendre la ressource permanente.
5.
Libérez l'accaparement du serveur.

XSetRGBColormaps peut générer des erreurs BadAlloc, BadAtom et BadWindow.

La fonction XGetRGBColormaps retourne les définitions de table de couleurs RVB stockées dans la propriété spécifiée sur la fenêtre nommée. Si la propriété existe, est de type RGB_COLOR_MAP, est de format 32 et est assez longue pour contenir une définition de table de couleurs, XGetRGBColormaps alloue et remplit un espace pour les tables de couleurs retournées et renvoie un statut non nul. Si visualid n'est pas présent, XGetRGBColormaps suppose la visualisation par défaut pour l'écran sur lequel la fenêtre est située ; si killid n'est pas présent, None est supposé, ce qui indique que les ressources ne peuvent pas être libérées. Sinon, aucun des champs n'est défini, et XGetRGBColormaps renvoie un statut nul. Notez qu'il est de la responsabilité de l'appelant de respecter la restriction ICCCM selon laquelle seul RGB_DEFAULT_MAP peut contenir plus d'une définition.

XGetRGBColormaps peut générer des erreurs BadAtom et BadWindow.

STRUCTURES

La structure XStandardColormap contient :

/* Indices */

#define ReleaseByFreeingColormap ( (XID) 1L)
/* Valeurs */ 
typedef struct {
        Colormap colormap;
        unsigned long red_max;
        unsigned long red_mult;
        unsigned long green_max;
        unsigned long green_mult;
        unsigned long blue_max;
        unsigned long blue_mult;
        unsigned long base_pixel;
        VisualID visualid;
        XID killid;
} XStandardColormap;

Le membre colormap est la table de couleurs créée par la fonction XCreateColormap. Les membres red_max, green_max et blue_max donnent les valeurs maximales du rouge, du vert et du bleu, respectivement. Chaque coefficient de couleur varie de zéro à son maximum, inclus. Par exemple, une allocation de table de couleurs courante est 3/3/2 (3 plans pour le rouge, 3 plans pour le vert et 2 plans pour le bleu). Cette table de couleurs aurait red_max = 7, green_max = 7 et blue_max = 3. Une allocation alternative qui n'utilise que 216 couleurs est red_max = 5, green_max = 5 et blue_max = 5.

Les membres red_mult, green_mult et blue_mult donnent les facteurs d'échelle utilisés pour composer une valeur de pixel complète. (Voir la discussion des membres base_pixel pour plus d'informations.) Pour une allocation 3/3/2, red_mult pourrait être 32, green_mult pourrait être 4 et blue_mult pourrait être 1. Pour une allocation de 6 couleurs chacune, red_mult pourrait être 36, green_mult pourrait être 6 et blue_mult pourrait être 1.

Le membre base_pixel donne la valeur de pixel de base utilisée pour composer une valeur de pixel complète. Habituellement, base_pixel est obtenu par un appel à la fonction XAllocColorPlanes. Étant donné des coefficients rouge, vert et bleu entiers dans leurs plages appropriées, on peut alors calculer une valeur de pixel correspondante en utilisant l'expression suivante :

(r * red_mult + g * green_mult + b * blue_mult + base_pixel) & 0xFFFFFFFF

Pour les tables de couleurs GrayScale, seuls les membres colormap, red_max, red_mult et base_pixel sont définis. Les autres membres sont ignorés. Pour calculer une valeur de pixel GrayScale, utilisez l'expression suivante :

(gray * red_mult + base_pixel) & 0xFFFFFFFF

Les multiplicateurs négatifs peuvent être représentés en convertissant la représentation complément à deux du multiplicateur en un unsigned long et en stockant le résultat dans le champ approprié _mult. L'étape de masquage par 0xFFFFFFFF convertit effectivement le multiplicateur positif résultant en un multiplicateur négatif. L'étape de masquage s'effectuera automatiquement sur de nombreuses architectures de machines, en fonction de la taille du type entier utilisé pour effectuer le calcul,

Le membre visualid donne le numéro d'identification de la visualisation à partir de laquelle la table de couleurs a été créée. Le membre killid donne un identifiant de ressource qui indique si les cellules détenues par cette table de couleurs standard doivent être libérées en libérant l'ID de la table de couleurs ou en appelant la fonction XKillClient sur la ressource indiquée. (Notez que cette méthode est nécessaire pour allouer à partir d'une table de couleurs existante.)

Les propriétés contenant les informations XStandardColormap ont le type RGB_COLOR_MAP.

BadAlloc

BadAtom

BadWindow
Une valeur pour un argument Window ne nomme pas une Window définie.

XGetRGBColormaps

NOM

XGetRGBColormaps - obtenir les mappages de couleurs RGB du serveur X

SYNTAXE

#include <Xlib.h>

XStandardColormap *XGetRGBColormaps(Display *display, Drawable d, XStandardColormap *std_colormap, unsigned int count, int desired_visual_class);

ARGUMENTS

display
Spécifie la connexion au serveur X.
d
Spécifie la drawable (fenêtre ou pixmap) pour laquelle les informations de mappage de couleurs sont demandées.
std_colormap
Pointeur vers un tableau de structures XStandardColormap à remplir. Vous devez allouer suffisamment d'espace pour count entrées.
count
Le nombre maximal d'entrées XStandardColormap à récupérer.
desired_visual_class
La classe de visualisation souhaitée pour laquelle les mappages de couleurs sont demandés. Les valeurs possibles sont StaticGray, GrayScale, StaticColor, PseudoColor, TrueColor et DirectColor.

DESCRIPTION

La fonction XGetRGBColormaps récupère les informations sur les mappages de couleurs RGB standard disponibles auprès du serveur X pour une drawable donnée et une classe de visualisation spécifiée. Ces informations sont renvoyées dans le tableau std_colormap fourni par l'appelant.

Le serveur X maintient une liste de mappages de couleurs RGB standard prédéfinis qui peuvent être utilisés par les applications. Ces mappages sont souvent utilisés pour fournir des couleurs cohérentes sur différents systèmes d'affichage.

La fonction renvoie le nombre réel d'entrées XStandardColormap qui ont été récupérées. Si aucune entrée de mappage de couleurs standard ne correspond à la classe de visualisation souhaitée, la fonction renvoie zéro.

STRUCTURES

La structure XStandardColormap est définie comme suit :

typedef struct {
    int     red_mult, green_mult, blue_mult;
    unsigned long   red_max, green_max, blue_max;
    unsigned long   red_shift, green_shift, blue_shift;
    unsigned long   visualid;
    Colormap        colormap;
    unsigned long   bits_per_rgb;
    unsigned short  scanline_bias;
    unsigned short  de লাল_bias, de_green_bias, de_blue_bias;
    unsigned int    count;
} XStandardColormap;

DIAGNOSTICS

En cas d'échec de la communication avec le serveur X, XGetRGBColormaps renvoie zéro.
