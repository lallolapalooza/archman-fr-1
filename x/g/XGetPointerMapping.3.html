XGetPointerMapping(3)

Paquet: libx11

Licences: MIT AND X11

XSetPointerMapping(3) FONCTIONS XLIB XSetPointerMapping(3)

NOM

XSetPointerMapping, XGetPointerMapping - manipuler les paramètres du pointeur

SYNTAXE

int XSetPointerMapping(Display *display, _Xconst unsigned char map[], int nmap);

int XGetPointerMapping(Display *display, unsigned char map_return[], int nmap);

ARGUMENTS

display
Spécifie la connexion au serveur X.
map
Spécifie la liste de mappage.
map_return
Retourne la liste de mappage.
nmap
Spécifie le nombre d'éléments dans la liste de mappage.

DESCRIPTION

La fonction XSetPointerMapping définit le mappage du pointeur. Si elle réussit, le serveur X génère un événement MappingNotify, et XSetPointerMapping retourne MappingSuccess. L'élément map[i] définit le numéro logique du bouton pour le bouton physique i+1. La longueur de la liste doit être la même que ce que XGetPointerMapping retournerait, sinon une erreur BadValue en résulte. Un élément zéro désactive un bouton, et les éléments ne sont pas restreints en valeur par le nombre de boutons physiques. Cependant, aucun deux éléments ne peuvent avoir la même valeur non nulle, ou une erreur BadValue en résulte. Si l'un des boutons à modifier est logiquement à l'état enfoncé, XSetPointerMapping retourne MappingBusy, et le mappage n'est pas modifié.

XSetPointerMapping peut générer une erreur BadValue.

La fonction XGetPointerMapping retourne le mappage actuel du pointeur. Les boutons du pointeur sont numérotés à partir de un. XGetPointerMapping retourne le nombre de boutons physiques réellement sur le pointeur. Le mappage nominal pour un pointeur est map[i]=i+1. L'argument nmap spécifie la longueur du tableau où le mappage du pointeur est retourné, et seuls les nmap premiers éléments sont retournés dans map_return.

DIAGNOSTICS

BadValue
Une valeur numérique tombe en dehors de la plage des valeurs acceptées par la requête. Sauf si une plage spécifique est spécifiée pour un argument, la plage complète définie par le type de l'argument est acceptée. Tout argument défini comme un ensemble d'alternatives peut générer cette erreur.
