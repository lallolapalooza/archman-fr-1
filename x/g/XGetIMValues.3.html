XGetIMValues(3)

Paquet: libx11

Licences: MIT AND X11

XOpenIM(3) FONCTIONS XLIB XOpenIM(3)

NOM

XOpenIM, XCloseIM, XSetIMValues, XGetIMValues, XDisplayOfIM, XLocaleOfIM, XRegisterIMInstantiateCallback, XUnregisterIMInstantiateCallback - ouvrir, fermer et obtenir des informations sur la méthode d'entrée

SYNTAXE

XIM XOpenIM(Display *display, XrmDatabase db, char *res_name, char *res_class);

Status XCloseIM(XIM im);

char *XSetIMValues(XIM im, ...);

char *XGetIMValues(XIM im, ...);

Display *XDisplayOfIM(XIM im);

char *XLocaleOfIM(XIM im);

Bool XRegisterIMInstantiateCallback(Display *display, XrmDatabase db, char *res_name, char *res_class, XIDProc callback, XPointer client_data);

Bool XUnregisterIMInstantiateCallback(Display *display, XrmDatabase db, char *res_name, char *res_class, XIDProc callback, XPointer client_data);

ARGUMENTS

callback
Spécifie un pointeur vers la fonction de rappel d'instanciation de la méthode d'entrée.
client_data
Spécifie les données client supplémentaires.
db
Spécifie un pointeur vers la base de données des ressources.
display
Spécifie la connexion au serveur X.
im
Spécifie la méthode d'entrée.
res_class
Spécifie le nom de classe complet de l'application.
res_name
Spécifie le nom de ressource complet de l'application.
...
Spécifie la liste d'arguments variables pour définir ou obtenir les valeurs XIM.

DESCRIPTION

La fonction XOpenIM ouvre une méthode d'entrée, en faisant correspondance avec les spécifications de locale et de modificateurs actuelles. La locale et les modificateurs actuels sont liés à la méthode d'entrée au moment de l'ouverture. La locale associée à une méthode d'entrée ne peut pas être modifiée dynamiquement. Cela implique que les chaînes renvoyées par XmbLookupString ou XwcLookupString, pour tout contexte d'entrée affilié à une méthode d'entrée donnée, seront encodées dans la locale actuelle au moment où la méthode d'entrée est ouverte.

La méthode d'entrée spécifique à laquelle cet appel sera routé est identifiée sur la base de la locale actuelle. XOpenIM identifiera une méthode d'entrée par défaut correspondant à la locale actuelle. Ce défaut peut être modifié en utilisant XSetLocaleModifiers pour le modificateur de méthode d'entrée.

L'argument db est la base de données des ressources à utiliser par la méthode d'entrée pour rechercher les ressources qui sont privées à la méthode d'entrée. Il n'est pas prévu que cette base de données soit utilisée pour rechercher des valeurs qui peuvent être définies comme valeurs IC dans un contexte d'entrée. Si db est NULL, aucune base de données n'est transmise à la méthode d'entrée.

Les arguments res_name et res_class spécifient le nom de ressource et la classe de l'application. Ils sont destinés à être utilisés comme préfixes par la méthode d'entrée lors de la recherche de ressources communes à tous les contextes d'entrée qui peuvent être créés pour cette méthode d'entrée. Les caractères utilisés pour les noms et classes de ressources doivent être dans le jeu de caractères portables X. Les ressources recherchées ne sont pas entièrement spécifiées si res_name ou res_class est NULL.

Les arguments res_name et res_class ne sont pas supposés exister au-delà de l'appel à XOpenIM. La base de données de ressources spécifiée est supposée exister pendant toute la durée de vie de la méthode d'entrée.

XOpenIM renvoie NULL si aucune méthode d'entrée n'a pu être ouverte.

La fonction XCloseIM ferme la méthode d'entrée spécifiée et libère la mémoire pointée par l'argument im.

La fonction XSetIMValues présente une interface de programmation à liste d'arguments variables pour définir les attributs de la méthode d'entrée spécifiée. Elle renvoie NULL si elle réussit ; sinon, elle renvoie le nom du premier argument qui n'a pas pu être défini. Xlib ne tente pas de définir les arguments de la liste fournie qui suivent l'argument en échec ; tous les arguments de la liste précédant l'argument en échec ont été définis correctement.

La fonction XGetIMValues présente une interface de programmation à liste d'arguments variables pour interroger les propriétés ou les fonctionnalités de la méthode d'entrée spécifiée. Cette fonction renvoie NULL si elle réussit ; sinon, elle renvoie le nom du premier argument qui n'a pas pu être obtenu.

Chaque argument de valeur XIM (après un nom) doit pointer vers un emplacement où la valeur XIM doit être stockée. C'est-à-dire, si la valeur XIM est de type T, l'argument doit être de type T*. Si T est lui-même un type de pointeur, alors XGetIMValues alloue de la mémoire pour stocker les données réelles, et le client est responsable de libérer ces données en appelant XFree avec le pointeur renvoyé.

La fonction XDisplayOfIM renvoie l'affichage associé à la méthode d'entrée spécifiée.

La fonction XLocaleOfIM renvoie la locale associée à la méthode d'entrée spécifiée.

La fonction XRegisterIMInstantiateCallback enregistre une fonction de rappel qui sera appelée chaque fois qu'une nouvelle méthode d'entrée deviendra disponible pour l'affichage spécifié, correspondant à la locale et aux modificateurs actuels.

La fonction renvoie True si elle réussit ; sinon, elle renvoie False.

La fonction XUnregisterIMInstantiateCallback supprime une fonction de rappel d'instanciation de méthode d'entrée précédemment enregistrée. La fonction renvoie True si elle réussit ; sinon, elle renvoie False.
