XGetWindowAttributes(3) FONCTIONS XLIB XGetWindowAttributes(3)

NOM

XGetWindowAttributes, XGetGeometry, XWindowAttributes - obtenir les attributs actuels de la fenêtre ou la géométrie et la structure des attributs de la fenêtre actuelle.

SYNTAXE

Status XGetWindowAttributes(Display *display, Window w, XWindowAttributes *window_attributes_return);

Status XGetGeometry(Display *display, Drawable d, Window *root_return, int *x_return, int *y_return, unsigned int *width_return, unsigned int *height_return, unsigned int *border_width_return, unsigned int *depth_return);

ARGUMENTS

border_width_return
Retourne la largeur de la bordure en pixels.
d
Spécifie le dessinable, qui peut être une fenêtre ou une image pixmap.
depth_return
Retourne la profondeur du dessinable (bits par pixel pour l'objet).
display
Spécifie la connexion au serveur X.
root_return
Retourne la fenêtre racine.
w
Spécifie la fenêtre dont vous souhaitez obtenir les attributs actuels.
width_return

height_return
Retourne les dimensions du dessinable (largeur et hauteur).
window_attributes_return
Retourne les attributs de la fenêtre spécifiée dans la structure XWindowAttributes.
x_return

y_return
Retourne les coordonnées x et y qui définissent l'emplacement du dessinable. Pour une fenêtre, ces coordonnées spécifient le coin extérieur supérieur gauche par rapport à l'origine de son parent. Pour les images pixmap, ces coordonnées sont toujours zéro.

DESCRIPTION

La fonction XGetWindowAttributes renvoie les attributs actuels de la fenêtre spécifiée dans une structure XWindowAttributes. Elle renvoie un statut non nul en cas de succès ; sinon, elle renvoie un statut nul.

XGetWindowAttributes peut générer des erreurs BadDrawable et BadWindow.

La fonction XGetGeometry renvoie la fenêtre racine et la géométrie actuelle du dessinable. La géométrie du dessinable comprend les coordonnées x et y, la largeur et la hauteur, la largeur de la bordure et la profondeur. Celles-ci sont décrites dans la liste des arguments. Il est légal de passer à cette fonction une fenêtre dont la classe est InputOnly. Elle renvoie un statut non nul en cas de succès ; sinon, elle renvoie un statut nul.

STRUCTURES

La structure XWindowAttributes contient :

typedef struct {
        int x, y;       /* emplacement de la fenêtre */
        int width, height;      /* largeur et hauteur de la fenêtre */
        int border_width;       /* largeur de la bordure de la fenêtre */
        int depth;      /* profondeur de la fenêtre */
        Visual *visual; /* structure visuelle associée */
        Window root;    /* racine de l'écran contenant la fenêtre */
        int class;      /* InputOutput, InputOnly*/
        int bit_gravity;        /* une des valeurs de gravité de bits */
        int win_gravity;        /* une des valeurs de gravité de fenêtre */
        int backing_store;      /* NotUseful, WhenMapped, Always */
        unsigned long backing_planes;   /* plans à préserver si possible */
        unsigned long backing_pixel;    /* valeur à utiliser lors de la restauration des plans */
        Bool save_under;        /* booléen, les bits sous doivent-ils être sauvegardés ? */
        Colormap colormap;      /* carte de couleurs à associer à la fenêtre */
        Bool map_installed;     /* booléen, la carte de couleurs est-elle actuellement installée*/
        int map_state;  /* IsUnmapped, IsUnviewable, IsViewable */
        long all_event_masks;   /* ensemble d'événements qui intéressent tout le monde */
        long your_event_mask;   /* mon masque d'événements */
        long do_not_propagate_mask;     /* ensemble d'événements qui ne doivent pas se propager */
        Bool override_redirect; /* valeur booléenne pour override-redirect */
        Screen *screen; /* pointeur de retour vers l'écran correct */
} XWindowAttributes;

Les membres x et y sont définis sur le coin extérieur supérieur gauche par rapport à l'origine de la fenêtre parente. Les membres width et height sont définis sur la taille intérieure de la fenêtre, sans inclure la bordure. Le membre border_width est défini sur la largeur de la bordure de la fenêtre en pixels. Le membre depth est défini sur la profondeur de la fenêtre (c'est-à-dire les bits par pixel de l'objet). Le membre visual est un pointeur vers la structure Visual associée à l'écran. Le membre root est défini sur la fenêtre racine de l'écran contenant la fenêtre. Le membre class est défini sur la classe de la fenêtre et peut être soit InputOutput, soit InputOnly.

Le membre bit_gravity est défini sur la gravité des bits de la fenêtre et peut être l'une des valeurs suivantes :

ForgetGravity EastGravity
NorthWestGravity SouthWestGravity
NorthGravity SouthGravity
NorthEastGravity SouthEastGravity
WestGravity StaticGravity
CenterGravity

Le membre win_gravity est défini sur la gravité de la fenêtre et peut être l'une des valeurs suivantes :

UnmapGravity EastGravity
NorthWestGravity SouthWestGravity
NorthGravity SouthGravity
NorthEastGravity SouthEastGravity
WestGravity StaticGravity
CenterGravity

Pour plus d'informations sur la gravité, voir la section 3.3.

Le membre backing_store est défini pour indiquer comment le serveur X doit maintenir le contenu d'une fenêtre et peut être WhenMapped, Always, ou NotUseful. Le membre backing_planes est défini pour indiquer (avec des bits à 1) quels plans de bits de la fenêtre contiennent des données dynamiques qui doivent être préservées dans les backing_stores et lors des save_unders. Le membre backing_pixel est défini pour indiquer quelles valeurs utiliser pour les plans non définis dans backing_planes.

Le membre save_under est défini sur True ou False. Le membre colormap est défini sur la carte de couleurs de la fenêtre spécifiée et peut être un ID de carte de couleurs ou None. Le membre map_installed est défini pour indiquer si la carte de couleurs est actuellement installée et peut être True ou False. Le membre map_state est défini pour indiquer l'état de la fenêtre et peut être IsUnmapped, IsUnviewable, ou IsViewable. IsUnviewable est utilisé si la fenêtre est mappée mais qu'un ancêtre est non mappé.

Le membre all_event_masks est défini sur le OU inclusif binaire de tous les masques d'événements sélectionnés sur la fenêtre par tous les clients. Le membre your_event_mask est défini sur le OU inclusif binaire de tous les masques d'événements sélectionnés par le client interrogeant. Le membre do_not_propagate_mask est défini sur le OU inclusif binaire de l'ensemble des événements qui ne doivent pas se propager.

Le membre override_redirect est défini pour indiquer si cette fenêtre outrepasse les installations de contrôle de structure et peut être True ou False. Les clients du gestionnaire de fenêtres doivent ignorer la fenêtre si ce membre est True.

Le membre screen est défini sur un pointeur d'écran qui vous donne un pointeur de retour vers l'écran correct. Cela facilite l'obtention des informations de l'écran sans avoir à parcourir les champs de la fenêtre racine pour voir quel champ correspond.

DIAGNOSTICS

BadDrawable
Une valeur pour un argument Drawable ne nomme pas une fenêtre ou une image pixmap définie.
BadWindow
Une valeur pour un argument Window ne nomme pas une fenêtre définie.

X | Manuel

XGetGeometry est une fonction de la bibliothèque Xlib qui permet de récupérer les informations de géométrie d'une fenêtre ou d'un pixmap. Ces informations comprennent la position de la fenêtre (x, y), ses dimensions (largeur, hauteur), sa profondeur et le masque d'écrêtage.

La fonction prend en argument un identifiant de fenêtre ou de pixmap, ainsi qu'un pointeur vers une structure `XGeometry` qui sera remplie avec les informations récupérées.

La structure `XGeometry` contient les champs suivants :

  • x : La coordonnée x du coin supérieur gauche de la fenêtre ou du pixmap par rapport à son parent.
  • y : La coordonnée y du coin supérieur gauche de la fenêtre ou du pixmap par rapport à son parent.
  • width : La largeur de la fenêtre ou du pixmap en pixels.
  • height : La hauteur de la fenêtre ou du pixmap en pixels.
  • border_width : La largeur de la bordure de la fenêtre en pixels.
  • depth : La profondeur de la fenêtre ou du pixmap (nombre de bits par pixel).
  • root : L'identifiant de la fenêtre racine de la fenêtre ou du pixmap.
  • class : La classe de la fenêtre (InputOutput, InputOnly, etc.).
  • visual : Un pointeur vers la structure `XVisualInfo` décrivant les caractéristiques visuelles.

La fonction renvoie True en cas de succès et False en cas d'erreur.

Exemple d'utilisation


#include <X11/Xlib.h>
#include <stdio.h>

int main() {
    Display *display;
    Window window;
    XGeometry geometry;
    Bool status;

    // Connexion au serveur X
    display = XOpenDisplay(NULL);
    if (display == NULL) {
        fprintf(stderr, "Impossible d'ouvrir le serveur X\n");
        return 1;
    }

    // Création d'une fenêtre simple (pour l'exemple)
    window = XCreateSimpleWindow(display, DefaultRootWindow(display),
                                 10, 10, 200, 100, 1,
                                 BlackPixel(display, DefaultScreen(display)),
                                 WhitePixel(display, DefaultScreen(display)));
    XMapWindow(display, window);
    XFlush(display);

    // Obtention des informations de géométrie
    status = XGetGeometry(display, window, &geometry.root,
                          &geometry.x, &geometry.y, &geometry.width, &geometry.height,
                          &geometry.border_width, &geometry.depth);

    if (status) {
        printf("Géométrie de la fenêtre :\n");
        printf("  x: %d\n", geometry.x);
        printf("  y: %d\n", geometry.y);
        printf("  largeur: %d\n", geometry.width);
        printf("  hauteur: %d\n", geometry.height);
        printf("  largeur de bordure: %d\n", geometry.border_width);
        printf("  profondeur: %d\n", geometry.depth);
    } else {
        fprintf(stderr, "Erreur lors de l'obtention de la géométrie\n");
    }

    // Fermeture de la connexion
    XCloseDisplay(display);
    return 0;
}

Ce programme se connecte au serveur X, crée une fenêtre simple, puis utilise `XGetGeometry` pour récupérer et afficher ses informations de géométrie.

La fonction `XGetGeometry` est un outil essentiel pour interagir avec les éléments graphiques dans un environnement X Window System, permettant aux applications de comprendre et de manipuler la taille, la position et d'autres attributs des fenêtres et des pixmaps.

Interface du langage X

La fonction `XGetGeometry` fait partie de l'API Xlib, qui est l'interface de programmation principale pour le système X Window. Elle fournit un ensemble de fonctions pour manipuler les fenêtres, les graphiques, les événements, etc. L'utilisation de `XGetGeometry` nécessite une bonne compréhension de ces concepts.
