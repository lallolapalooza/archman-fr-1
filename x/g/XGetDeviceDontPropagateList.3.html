NOM

XChangeDeviceDontPropagateList, XGetDeviceDontPropagateList - interroger ou modifier la liste de non-propagation pour les périphériques d'extension

SYNTAXE

#include <X11/extensions/XInput.h>
int XChangeDeviceDontPropagateList( Display *display,
                                    Window window,
                                    int count,
                                    XEventClass *event_list,
                                    int mode);
XEventClass* XGetDeviceDontPropagateList( Display *display,
                                          Window window,
                                          int *count);
display
       Spécifie la connexion au serveur X.
window
       Spécifie la fenêtre dont la liste de non-propagation doit être
       interrogée ou modifiée.
event_list
       Spécifie un pointeur vers une liste de classes d'événements.
mode
       Spécifie le mode. Vous pouvez passer AddToList, ou
       DeleteFromList.
count
       Spécifie le nombre de classes d'événements dans la liste.

DESCRIPTION

La requête XChangeDeviceDontPropagateList modifie la liste des
événements qui ne doivent pas être propagés aux ancêtres de la fenêtre
d'événement. Cette requête permet d'ajouter ou de supprimer des événements
d'extension de cette liste. Par défaut, tous les événements sont propagés
aux fenêtres ancêtres. Une fois modifiée, la liste reste modifiée
pendant toute la durée de vie de la fenêtre. Les événements ne sont pas
retirés de la liste parce que le client qui les a ajoutés s'est terminé.
La suppression de la propagation d'événements n'est pas autorisée pour tous les
événements d'extension d'entrée. Si une classe d'événement spécifiée est
l'une de celles qui ne peuvent pas être supprimées, une erreur BadClass en
résultera. Les événements qui peuvent être supprimés incluent DeviceKeyPress,
DeviceKeyRelease, DeviceButtonPress, DeviceButtonRelease, DeviceMotionNotify,
ProximityIn et ProximityOut.
XChangeDeviceDontPropagateList peut générer une erreur BadDevice,
BadClass ou BadValue.
La requête XGetDeviceDontPropagateList interroge la liste des
événements qui ne doivent pas être propagés aux ancêtres de la fenêtre
d'événement.
XGetDeviceDontPropagateList peut générer une erreur BadClass ou
BadWindow.

DIAGNOSTICS

BadDevice
       Un périphérique invalide a été spécifié. Le périphérique
       spécifié n'existe pas ou n'a pas été ouvert par ce client via
       XOpenInputDevice. Cette erreur peut également survenir si un autre
       client a fait en sorte que le périphérique spécifié devienne
       le périphérique clavier X ou pointeur X via les requêtes
       XChangeKeyboardDevice ou XChangePointerDevice.
BadValue
       Une valeur numérique est en dehors de la plage de valeurs
       acceptées par la requête. Sauf si une plage spécifique est
       spécifiée pour un argument, toute la plage définie par le
       type de l'argument est acceptée. Tout argument défini comme un
       ensemble d'alternatives peut générer cette erreur.
BadWindow
       Un identifiant de fenêtre invalide a été spécifié.
BadClass
       Une classe d'événement invalide a été spécifiée.
