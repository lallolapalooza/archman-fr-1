XGetVisualInfo(3)

Paquet: libx11

Licences: MIT AND X11

XGetVisualInfo(3) FONCTIONS XLIB XGetVisualInfo(3)

NOM

XGetVisualInfo, XMatchVisualInfo, XVisualIDFromVisual, XVisualInfo - obtenir des informations visuelles et des structures visuelles

SYNTAXE

XVisualInfo *XGetVisualInfo(Display *display, long vinfo_mask, XVisualInfo *vinfo_template, int *nitems_return);

Status XMatchVisualInfo(Display *display, int screen, int depth, int class, XVisualInfo *vinfo_return);

VisualID XVisualIDFromVisual(Visual *visual);

ARGUMENTS

class
Spécifie la classe de l'écran.
depth
Spécifie la profondeur de l'écran.
display
Spécifie la connexion au serveur X.
nitems_return
Retourne le nombre de structures visuelles correspondantes.
screen
Spécifie l'écran.
visual
Spécifie le type visuel.
vinfo_mask
Spécifie la valeur du masque visuel.
vinfo_return
Retourne les informations visuelles correspondantes.
vinfo_template
Spécifie les attributs visuels à utiliser pour faire correspondre les structures visuelles.

DESCRIPTION

La fonction XGetVisualInfo retourne une liste de structures visuelles dont les attributs sont égaux aux attributs spécifiés par vinfo_template. Si aucune structure visuelle ne correspond au modèle en utilisant le vinfo_mask spécifié, XGetVisualInfo retourne NULL. Pour libérer les données retournées par cette fonction, utilisez XFree.

La fonction XMatchVisualInfo retourne les informations visuelles pour un visuel qui correspond à la profondeur et à la classe spécifiées pour un écran. Comme plusieurs visuels correspondant à la profondeur et à la classe spécifiées peuvent exister, le visuel exact choisi est indéfini. Si un visuel est trouvé, XMatchVisualInfo retourne une valeur non nulle et les informations sur le visuel à vinfo_return. Sinon, lorsqu'un visuel n'est pas trouvé, XMatchVisualInfo retourne zéro.

La fonction XVisualIDFromVisual retourne l'ID visuel pour le type visuel spécifié.

STRUCTURES

La structure XVisualInfo contient :

/* Masque d'informations visuelles bits */

#define VisualNoMask 0x0
#define VisualIDMask 0x1
#define VisualScreenMask 0x2
#define VisualDepthMask 0x4
#define VisualClassMask 0x8
#define VisualRedMaskMask 0x10
#define VisualGreenMaskMask 0x20
#define VisualBlueMaskMask 0x40
#define VisualColormapSizeMask 0x80
#define VisualBitsPerRGBMask 0x100
#define VisualAllMask 0x1FF 
/* Valeurs */
typedef struct {
        Visual *visual;
        VisualID visualid;
        int screen;
        int depth;
        int class;
        unsigned long red_mask;
        unsigned long green_mask;
        unsigned long blue_mask;
        int colormap_size;
        int bits_per_rgb;
} XVisualInfo;
