XGETDEVICECONTROL(3)   XGETDEVICECONTROL(3)

NOM

XGetDeviceControl, XChangeDeviceControl - interroger et modifier les contrôles d'appareils d'entrée

SYNTAXE

#include <X11/extensions/XInput.h>
XDeviceControl *XGetDeviceControl( Display *display,
                                   XDevice *device,
                                   int *controlType);
int XChangeDeviceControl( Display *display,
                          XDevice *device,
                          int controlType,
                          XDeviceControl *control);
display
       Spécifie la connexion au serveur X.
device
       Spécifie l'appareil dont le contrôle doit être interrogé
       ou modifié.
controlType
       Spécifie le type de contrôle à interroger ou à modifier.
control
       Spécifie l'adresse d'une structure XDeviceControl
       contenant les nouvelles valeurs pour l'appareil.

DESCRIPTION

Ces requêtes sont fournies pour manipuler les appareils d'entrée
qui supportent les contrôles d'appareils. Une erreur BadMatch sera générée
si l'appareil demandé ne supporte aucun contrôle d'appareil.
Les types de contrôle d'appareil valides qui peuvent être utilisés avec ces requêtes
incluent les suivants :
DEVICE_RESOLUTION : Interroge ou modifie la résolution des
valuators sur les appareils d'entrée.
La requête XGetDeviceControl renvoie un pointeur vers une structure
XDeviceControl.
XGetDeviceControl peut générer une erreur BadDevice ou BadMatch.
La requête XChangeDeviceControl modifie les valeurs d'un
contrôle sur l'appareil spécifié. Le contrôle est identifié par
le champ id de la structure XDeviceControl qui est passée avec la requête.
XChangeDeviceControl peut générer une erreur BadDevice, BadMatch, ou
BadValue.

STRUCTURES

Chaque contrôle est décrit par une structure spécifique à ce contrôle.
Ces structures sont définies dans le fichier XInput.h.
XDeviceControl est une structure générique qui contient deux champs
qui sont au début de chaque classe de contrôle :
typedef struct {
    XID class;
    int length;
} XDeviceControl;
La structure XDeviceResolutionState définit les informations
renvoyées pour la résolution d'appareil pour les appareils avec
des valuators.
typedef struct {
    XID control;
    int length;
    int num_valuators;
    int* resolutions;
    int* min_resolutions;
    int* max_resolutions;
} XDeviceResolutionState;
La structure XDeviceResolutionControl définit les attributs
qui peuvent être contrôlés pour les appareils clavier.
typedef struct {
    XID control;
    int length;
    int first_valuator;
    int num_valuators;
    int* resolutions;
} XDeviceResolutionControl;

DIAGNOSTICS

BadDevice
       Un appareil invalide a été spécifié. L'appareil spécifié
       n'existe pas ou n'a pas été ouvert par ce client via
       XOpenInputDevice. Cette erreur peut également survenir si un autre
       client a fait de l'appareil spécifié le périphérique clavier X ou pointeur X
       via les requêtes XChangeKeyboardDevice ou XChangePointerDevice.
BadMatch
       Cette erreur peut survenir si une requête XGetDeviceControl a été faite
       spécifiant un appareil qui n'a pas de contrôles ou si une
       requête XChangeDeviceControl a été faite avec une
       structure XDeviceControl contenant un type d'appareil invalide. Elle peut
       également survenir si une combinaison invalide de bits de masque est spécifiée
       (DvKey mais pas DvAutoRepeatMode pour les appareils clavier), ou si un KeySym invalide est
       spécifié pour un appareil de type chaîne.
BadValue
       Une valeur numérique tombe en dehors de la plage des valeurs
       acceptées par la requête XChangeDeviceControl. Sauf si une
       plage spécifique est spécifiée pour un argument, toute la
       plage définie par le type de l'argument est acceptée. Tout
       argument défini comme un ensemble d'alternatives peut générer
       cette erreur.
