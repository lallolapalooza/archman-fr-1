XGETDEVICEKEYMAPPING(3)   XGETDEVICEKEYMAPPING(3)

NOM

XGetDeviceKeyMapping, XChangeDeviceKeyMapping - interroger ou modifier les mappages de touches d'un périphérique

SYNTAXE

#include <X11/extensions/XInput.h>
KeySym *XGetDeviceKeyMapping( Display *display,
                              XDevice *device,
                              KeyCode first_keycode,
                              int keycode_count,
                              int *keysyms_per_keycode_return);
display
       Spécifie la connexion au serveur X.
device
       Spécifie le périphérique dont le mappage de touches doit être interrogé
       ou modifié.
first_keycode
       Spécifie le premier KeyCode à retourner.
keycode_count
       Spécifie le nombre de KeyCodes à retourner ou
       modifier.
keysyms_per_keycode
       Spécifie le nombre de KeySyms par KeyCode.
keysyms_per_keycode_return
       Spécifie l'adresse d'une variable dans laquelle le
       nombre de KeySyms par KeyCode sera retourné.
keysyms
       Spécifie l'adresse d'un tableau de KeySyms.

DESCRIPTION

Pour le périphérique spécifié, la requête XGetDeviceKeyMapping retourne les symboles pour le nombre spécifié de KeyCodes
en commençant par first_keycode. La valeur spécifiée dans
first_keycode doit être supérieure ou égale à min_keycode telle que retournée par XListInputDevices, sinon une erreur BadValue survient. De plus, l'expression suivante doit être inférieure ou égale à max_keycode telle que retournée par XListInputDevices :
first_keycode + keycode_count - 1
Sinon, une erreur BadValue survient. Le nombre d'éléments dans la liste KeySyms est :
keycode_count * keysyms_per_keycode_return
Le numéro de KeySym N, en comptant à partir de zéro, pour le KeyCode K a l'index suivant dans la liste, en comptant à partir de zéro : (K -
first_code) * keysyms_per_code_return + N
Le serveur X choisit arbitrairement la valeur keysyms_per_keycode_return
pour qu'elle soit suffisamment grande pour rapporter tous les symboles demandés. Une valeur KeySym spéciale, NoSymbol, est utilisée pour remplir les éléments non utilisés pour les KeyCodes individuels. Pour libérer le stockage retourné par XGetDeviceKeyMapping, utilisez XFree.
Si le périphérique spécifié ne prend pas en charge les touches de classe d'entrée, une erreur BadMatch surviendra.
XGetDeviceKeyMapping peut générer une erreur BadDevice, BadMatch, ou BadValue.
Pour le périphérique spécifié, la requête XChangeDeviceKeyMapping définit les symboles pour le nombre spécifié de KeyCodes
en commençant par first_keycode. Les symboles pour les KeyCodes hors de cette plage restent inchangés. Le nombre d'éléments dans keysyms doit être :
num_codes * keysyms_per_keycode
Le first_keycode spécifié doit être supérieur ou égal à
min_keycode retourné par XListInputDevices, sinon une erreur BadValue survient. De plus, l'expression suivante doit être inférieure ou égale à max_keycode telle que retournée par XListInputDevices, sinon une erreur BadValue survient :
first_keycode + num_codes - 1
Le numéro de KeySym N, en comptant à partir de zéro, pour le KeyCode K a l'index suivant dans keysyms, en comptant à partir de zéro :
(K - first_keycode) * keysyms_per_keycode + N
Le keysyms_per_keycode spécifié peut être choisi arbitrairement par le client pour être suffisamment grand pour contenir tous les symboles souhaités. Une valeur KeySym spéciale, NoSymbol, doit être utilisée pour remplir les éléments non utilisés pour les KeyCodes individuels. Il est légal que NoSymbol apparaisse dans des positions non finales de la liste effective pour un KeyCode. XChangeDeviceKeyMapping génère un événement DeviceMappingNotify qui est envoyé à tous les clients qui ont sélectionné ce type d'événement.
Il n'est pas requis que le serveur X interprète ce
mappage. Il est simplement stocké pour être lu et écrit par les
clients.
Si le périphérique spécifié ne prend pas en charge les touches de classe d'entrée, une erreur BadMatch survient.
XChangeDeviceKeyMapping peut générer une erreur BadDevice, BadMatch,
BadAlloc, ou BadValue.

DIAGNOSTICS

BadDevice
       Un périphérique invalide a été spécifié. Le périphérique
       spécifié n'existe pas ou n'a pas été ouvert par ce client via
       XOpenInputDevice. Cette erreur peut également survenir si le
       périphérique spécifié est le clavier X ou le pointeur X.
BadMatch
       Cette erreur peut survenir si une requête XGetDeviceKeyMapping ou
       XChangeDeviceKeyMapping a été effectuée en spécifiant un
       périphérique qui n'a pas de touches.
BadValue
       Une valeur numérique se trouve en dehors de la plage de valeurs
       acceptées par la requête. Sauf si une plage spécifique est
       spécifiée pour un argument, la plage complète définie par le
       type de l'argument est acceptée. Tout argument défini comme un
       ensemble d'alternatives peut générer cette erreur.
BadAlloc
       Le serveur n'a pas réussi à allouer la ressource ou la mémoire
       serveur demandée.
