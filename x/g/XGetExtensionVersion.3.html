XGETEXTENSIONVERSION(3)   XGETEXTENSIONVERSION(3)

NOM

XGetExtensionVersion - interroger la version de l'extension d'entrée.

SYNOPSIS

#include <X11/extensions/XInput.h>
XExtensionVersion *XGetExtensionVersion( Display *display,
                                         char *name);
display
       Spécifie la connexion au serveur X.
name
       Spécifie l'extension à interroger. Le nom de l'extension d'entrée
       est défini dans le fichier d'en-tête XI.h.

DESCRIPTION

La requête XGetExtensionVersion est dépréciée et ne doit pas
être utilisée dans les applications XI2. Les clients émettant une
requête XGetExtensionVersion ne pourront pas utiliser les fonctionnalités XI2.
La requête XGetExtensionVersion interroge la version de l'extension d'entrée
et retourne une structure XExtensionVersion. Cette structure
contient un numéro major_version et minor_version qui peuvent être comparés
avec les constantes définies dans XI.h. Le support des requêtes de protocole
supplémentaires ajoutées à l'extension d'entrée après sa sortie initiale
est indiqué par un numéro de version correspondant aux requêtes ajoutées.
Chaque version contient toutes les requêtes de protocole
contenues par les versions précédentes.
Vous devriez utiliser XFree pour libérer la structure XExtensionVersion.

STRUCTURES

Cette requête retourne une structure XExtensionVersion.
typedef struct {
    int present;
    short major_version;
    short minor_version;
} XExtensionVersion;
