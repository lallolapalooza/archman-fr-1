XChangeKeyboardControl(3) FONCTIONS XLIB XChangeKeyboardControl(3)

NOM

XChangeKeyboardControl, XGetKeyboardControl, XAutoRepeatOn, XAutoRepeatOff, XBell, XQueryKeymap, XKeyboardControl - manipuler les paramètres du clavier et la structure de contrôle du clavier

SYNTAXE

int XChangeKeyboardControl(Display *display, unsigned long value_mask, XKeyboardControl *values);

int XGetKeyboardControl(Display *display, XKeyboardState *values_return);

int XAutoRepeatOn(Display *display);

int XAutoRepeatOff(Display *display);

int XBell(Display *display, int percent);

int XQueryKeymap(Display *display, char keys_return[32]);

ARGUMENTS

display
Spécifie la connexion au serveur X.
keys_return
Retourne un tableau d'octets qui identifie quelles touches sont enfoncées. Chaque bit représente une touche du clavier.
percent
Spécifie le volume de la sonnerie, qui peut varier de -100 à 100 inclus.
value_mask
Spécifie quels contrôles modifier. Ce masque est le OU logique binaire des bits de masque de contrôle valides.
values
Spécifie une valeur pour chaque bit défini à 1 dans le masque.
values_return
Retourne les contrôles actuels du clavier dans la structure XKeyboardState spécifiée.

DESCRIPTION

La fonction XChangeKeyboardControl contrôle les caractéristiques du clavier définies par la structure XKeyboardControl. L'argument value_mask spécifie les valeurs à modifier.

XChangeKeyboardControl peut générer des erreurs BadMatch et BadValue.

La fonction XGetKeyboardControl retourne les valeurs de contrôle actuelles du clavier dans la structure XKeyboardState.

La fonction XAutoRepeatOn active la répétition automatique pour le clavier sur l'affichage spécifié.

La fonction XAutoRepeatOff désactive la répétition automatique pour le clavier sur l'affichage spécifié.

La fonction XBell déclenche la sonnerie du clavier sur l'affichage spécifié, si possible. Le volume spécifié est relatif au volume de base du clavier. Si la valeur de l'argument percent n'est pas dans la plage de -100 à 100 inclus, une erreur BadValue en résulte. Le volume auquel la sonnerie retentit lorsque l'argument percent est non négatif est :

base - [(base * percent) / 100] + percent

Le volume auquel la sonnerie retentit lorsque l'argument percent est négatif est :

base + [(base * percent) / 100]

Pour modifier le volume de base de la sonnerie, utilisez XChangeKeyboardControl.

XBell peut générer une erreur BadValue.

La fonction XQueryKeymap retourne un vecteur de bits pour l'état logique du clavier, où chaque bit défini à 1 indique que la touche correspondante est actuellement enfoncée. Le vecteur est représenté par 32 octets. L'octet N (à partir de 0) contient les bits pour les touches 8N à 8N + 7, le bit de poids faible dans l'octet représentant la touche 8N.

Notez que l'état logique d'un périphérique (tel que vu par les applications clientes) peut être en retard par rapport à l'état physique si le traitement des événements du périphérique est gelé.

STRUCTURES

La structure XKeyboardControl contient :

/* Bits de masque pour ChangeKeyboardControl */

#define KBKeyClickPercent (1L<<0)
#define KBBellPercent (1L<<1)
#define KBBellPitch (1L<<2)
#define KBBellDuration (1L<<3)
#define KBLed (1L<<4)
#define KBLedMode (1L<<5)
#define KBKey (1L<<6)
#define KBAutoRepeatMode (1L<<7) 
/* Valeurs */
typedef struct {
        int key_click_percent;
        int bell_percent;
        int bell_pitch;
        int bell_duration;
        int led;
        int led_mode;   /* LedModeOn, LedModeOff */
        int key;
        int auto_repeat_mode;   /* AutoRepeatModeOff, AutoRepeatModeOn,
                                AutoRepeatModeDefault */
} XKeyboardControl;

Le membre key_click_percent définit le volume des clics de touche entre 0 (éteint) et 100 (fort) inclus, si possible. Un réglage de -1 restaure la valeur par défaut. Les autres valeurs négatives génèrent une erreur BadValue.

Le membre bell_percent définit le volume de base de la sonnerie entre 0 (éteint) et 100 (fort) inclus, si possible. Un réglage de -1 restaure la valeur par défaut. Les autres valeurs négatives génèrent une erreur BadValue. Le membre bell_pitch définit la hauteur (spécifiée en Hz) de la sonnerie, si possible. Un réglage de -1 restaure la valeur par défaut. Les autres valeurs négatives génèrent une erreur BadValue. Le membre bell_duration définit la durée de la sonnerie spécifiée en millisecondes, si possible. Un réglage de -1 restaure la valeur par défaut. Les autres valeurs négatives génèrent une erreur BadValue.

Si les membres led_mode et led sont spécifiés, l'état de cette LED est modifié, si possible. Le membre led_mode peut être défini sur LedModeOn ou LedModeOff. Si seul led_mode est spécifié, l'état de toutes les LED est modifié, si possible. Au plus 32 LED numérotées à partir de un sont supportées. Aucune interprétation standard des LED n'est définie. Si led est spécifié sans led_mode, une erreur BadMatch en résulte.

Si les membres auto_repeat_mode et key sont spécifiés, le auto_repeat_mode de cette touche est modifié (selon AutoRepeatModeOn, AutoRepeatModeOff, ou AutoRepeatModeDefault), si possible. Si seul auto_repeat_mode est spécifié, le auto_repeat_mode global pour l'ensemble du clavier est modifié, si possible, et n'affecte pas les paramètres par touche. Si une touche est spécifiée sans auto_repeat_mode, une erreur BadMatch en résulte. Chaque touche a un mode individuel pour savoir si elle doit se répéter ou non et un paramètre par défaut pour ce mode. De plus, il existe un mode global indiquant si la répétition automatique doit être activée ou non et un paramètre par défaut pour ce mode. Lorsque le mode global est AutoRepeatModeOn, les touches doivent respecter leurs modes de répétition automatique individuels. Lorsque le mode global est AutoRepeatModeOff, aucune touche ne doit se répéter. Une touche en répétition automatique génère des événements alternés KeyPress et KeyRelease. Lorsqu'une touche est utilisée comme modificateur, il est souhaitable qu'elle ne se répète pas, quelle que soit sa configuration de répétition automatique.

La structure XKeyboardState contient :

typedef struct {
        int key_click_percent;
        int bell_percent;
        unsigned int bell_pitch, bell_duration;
        unsigned long led_mask;
        int global_auto_repeat;
        char auto_repeats[32];
} XKeyboardState;

Pour les LED, le bit de poids faible de led_mask correspond à la LED un, et chaque bit défini à 1 dans led_mask indique une LED allumée. Le membre global_auto_repeat peut être défini sur AutoRepeatModeOn ou AutoRepeatModeOff. Le membre auto_repeats est un vecteur de bits. Chaque bit défini à 1 indique que la répétition automatique est activée pour la touche correspondante. Le vecteur est représenté par 32 octets. L'octet N (à partir de 0) contient les bits pour les touches 8N à 8N + 7, le bit de poids faible dans l'octet représentant la touche 8N.

DIAGNOSTICS

BadMatch
Certains arguments ou paires d'arguments ont le type et la plage corrects mais ne correspondent pas d'une autre manière requise par la requête.
BadValue
Certaine valeur numérique tombe en dehors de la plage de valeurs acceptées par la requête. Sauf si une plage spécifique est spécifiée pour un argument, la plage complète définie par le type de l'argument est acceptée. Tout argument défini comme un ensemble de valeurs alternatives
