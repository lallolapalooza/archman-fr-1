XDrawImageString16(3)

Paquet: libx11

Licences: MIT AND X11

XDrawImageString(3) FONCTIONS XLIB XDrawImageString(3)

NOM

XDrawImageString, XDrawImageString16 - dessiner du texte en image

SYNTAXE

int XDrawImageString(Display *display, Drawable d, GC gc, int x, int y, const char *string, int length);

int XDrawImageString16(Display *display, Drawable d, GC gc, int x, int y, const XChar2b *string, int length);

ARGUMENTS

d
Spécifie le drawable.
display
Spécifie la connexion au serveur X.
gc
Spécifie le GC.
length
Spécifie le nombre de caractères dans l'argument string.
string
Spécifie la chaîne de caractères.
x

y
Spécifient les coordonnées x et y, relatives à l'origine du drawable spécifié, et définissent l'origine du premier caractère.

DESCRIPTION

La fonction XDrawImageString16 est similaire à XDrawImageString, sauf qu'elle utilise des caractères à 2 octets ou 16 bits. Les deux fonctions utilisent les pixels de premier plan et d'arrière-plan du GC dans la destination.

L'effet est d'abord de remplir un rectangle de destination avec le pixel d'arrière-plan défini dans le GC, puis de peindre le texte avec le pixel de premier plan. Le coin supérieur gauche du rectangle rempli est à :

[x, y - font-ascent]

La largeur est :

overall-width

La hauteur est :

font-ascent + font-descent

Le overall-width, le font-ascent et le font-descent sont tels qu'ils seraient retournés par XQueryTextExtents en utilisant gc et string. La fonction et le fill-style définis dans le GC sont ignorés pour ces fonctions. La fonction effective est GXcopy, et le fill-style effectif est FillSolid.

Pour les polices définies avec un index matriciel à 2 octets et utilisées avec XDrawImageString, chaque octet est utilisé comme byte2 avec un byte1 de zéro.

Les deux fonctions utilisent ces composants GC : plane-mask, foreground, background, font, subwindow-mode, clip-x-origin, clip-y-origin, et clip-mask.

XDrawImageString et XDrawImageString16 peuvent générer les erreurs BadDrawable, BadGC et BadMatch.

DIAGNOSTICS

BadDrawable
Une valeur pour un argument Drawable ne nomme pas une Fenêtre ou un Pixmap défini.
BadGC
Une valeur pour un argument GContext ne nomme pas un GContext défini.
BadMatch
Une fenêtre InputOnly est utilisée comme Drawable.
BadMatch
Un argument ou une paire d'arguments a le bon type et la bonne plage, mais ne correspond pas d'une autre manière requise par la requête.

NOTES

Contrairement à XDrawString et XDrawString16, ces fonctions n'envoient pas plus de 255 caractères à la fois au serveur. Lorsque le nombre total de caractères à envoyer est supérieur à 255, ces fonctions divisent la chaîne en morceaux allant jusqu'à 255 caractères. Après l'envoi de chaque morceau, ces fonctions interrogent le serveur pour déterminer l'étendue réelle du texte.
