XDrawRectangle(3)

Paquet: libx11

Licences: MIT AND X11

XDrawRectangle(3) FONCTIONS XLIB XDrawRectangle(3)

NOM

XDrawRectangle, XDrawRectangles, XRectangle - dessiner des rectangles et structure de rectangle

SYNTAXE

int XDrawRectangle(Display *display, Drawable d, GC gc, int x, int y, unsigned int width, unsigned int height);

int XDrawRectangles(Display *display, Drawable d, GC gc, XRectangle rectangles[], int nrectangles);

ARGUMENTS

d
Spécifie le drawable.
display
Spécifie la connexion au serveur X.
gc
Spécifie le GC.
nrectangles
Spécifie le nombre de rectangles dans le tableau.
rectangles
Spécifie un tableau de rectangles.
width

height
Spécifient la largeur et la hauteur, qui définissent les dimensions du rectangle.
x

y
Spécifient les coordonnées x et y, qui définissent le coin supérieur gauche du rectangle.

DESCRIPTION

Les fonctions XDrawRectangle et XDrawRectangles dessinent les contours des rectangles spécifiés comme si une requête de protocole PolyLine à cinq points était spécifiée pour chaque rectangle :

[x,y] [x+width,y] [x+width,y+height] [x,y+height] [x,y]

Pour le rectangle ou les rectangles spécifiés, ces fonctions ne dessinent pas un pixel plus d'une fois. XDrawRectangles dessine les rectangles dans l'ordre indiqué dans le tableau. Si des rectangles s'intersectent, les pixels qui s'intersectent sont dessinés plusieurs fois.

Les deux fonctions utilisent les composants GC suivants : function, plane-mask, line-width, line-style, cap-style, join-style, fill-style, subwindow-mode, clip-x-origin, clip-y-origin, et clip-mask. Elles utilisent également ces composants GC dépendants du mode : foreground, background, tile, stipple, tile-stipple-x-origin, tile-stipple-y-origin, dash-offset, et dash-list.

XDrawRectangle et XDrawRectangles peuvent générer des erreurs BadDrawable, BadGC, et BadMatch.

STRUCTURES

La structure XRectangle contient :

typedef struct {
        short x, y;
        unsigned short width, height;
} XRectangle;

Tous les membres x et y sont des entiers signés. Les membres width et height sont des entiers non signés de 16 bits. Vous devez faire attention à ne pas générer de coordonnées et de tailles en dehors des plages de 16 bits, car le protocole n'a que des champs de 16 bits pour ces valeurs.

DIAGNOSTICS

BadDrawable
Une valeur pour un argument Drawable ne désigne pas une Fenêtre ou un Pixmap défini.
BadGC
Une valeur pour un argument GContext ne désigne pas un GContext défini.
BadMatch
Une fenêtre InputOnly est utilisée comme Drawable.
BadMatch
Un argument ou une paire d'arguments a le bon type et la bonne plage mais ne correspond pas d'une autre manière requise par la requête.
