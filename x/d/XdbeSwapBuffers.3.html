NOM

XdbeSwapBuffers - échange les tampons avant et arrière DBE.

SYNTAXE

#include <X11/extensions/Xdbe.h>

Status XdbeSwapBuffers(
Display *dpy,
XdbeSwapInfo *swap_info,
int num_windows)

DESCRIPTION

Cette fonction échange les tampons avant et arrière pour une liste de fenêtres. L'argument num_windows spécifie le nombre de fenêtres dont les tampons doivent être échangés ; il correspond au nombre d'éléments dans le tableau swap_info. L'argument swap_info spécifie les informations nécessaires par fenêtre pour effectuer l'échange.

La structure XdbeSwapInfo possède les champs suivants :


Window swap_window
XdbeSwapAction swap_action

swap_window spécifie la fenêtre pour laquelle échanger les tampons. swap_action spécifie l'action d'échange à utiliser pour cette swap_window.

swap_action détermine ce qui arrivera au nouveau tampon arrière de la swap_window associée dans la liste, en plus de rendre visible l'ancien tampon arrière. Les actions définies sont les suivantes :

XdbeUndefined
Le contenu du nouveau tampon arrière devient indéfini. Cela peut être l'action la plus efficace car elle permet à l'implémentation de rejeter le contenu du tampon si nécessaire.
XdbeBackground
La région non obstruée du nouveau tampon arrière sera remplie avec l'arrière-plan de la fenêtre. L'action d'arrière-plan permet aux périphériques d'utiliser une capacité d'effacement rapide lors d'un échange.
XdbeUntouched
La région non obstruée du nouveau tampon arrière ne sera pas modifiée par l'échange.
XdbeCopied
La région non obstruée du nouveau tampon arrière contiendra le contenu de l'ancien tampon arrière.

ERREURS

BadMatch
Une fenêtre non doublement tamponnée a été spécifiée ou une fenêtre a été spécifiée deux fois.
BadWindow
Une fenêtre invalide a été spécifiée.
BadValue
Une action d'échange invalide a été spécifiée.
