XdbeGetVisualInfo(3) FONCTIONS X XdbeGetVisualInfo(3)

NOM

XdbeGetVisualInfo - Obtenir des informations visuelles dbe

SYNTAXE

#include <X11/extensions/Xdbe.h>

XdbeScreenVisualInfo *XdbeGetVisualInfo(
Display *dpy,
Drawable *screen_specifiers,
int *num_screens)

DESCRIPTION

Cette fonction renvoie des informations sur les visuels qui prennent en charge le double buffering. L'argument num_screens spécifie le nombre d'éléments dans la liste screen_specifiers. Chaque drawable dans screen_specifiers désigne un écran pour lequel les visuels pris en charge sont demandés. Si num_screens est zéro, des informations pour tous les écrans sont demandées. Dans ce cas, au retour de cette fonction, num_screens sera défini au nombre d'écrans trouvés. Si une erreur se produit, cette fonction renvoie NULL, sinon elle renvoie un pointeur vers une liste de structures XdbeScreenVisualInfo de longueur num_screens. Le nième élément de la liste retournée correspond au nième drawable de la liste screen_specifiers, sauf si num_screens a été passé avec la valeur zéro, auquel cas le nième élément de la liste retournée correspond au nième écran du serveur, en commençant par l'écran zéro. La structure XdbeScreenVisualInfo a les champs suivants :


int count
XdbeVisualInfo *visinfo

count spécifie le nombre d'éléments dans visinfo. visinfo spécifie une liste de visuels, de profondeurs et d'indices de performance pour cet écran.

La structure XdbeVisualInfo a les champs suivants :


VisualID visual
int depth
int perflevel

visual spécifie un ID visuel prenant en charge le double-buffering. depth spécifie la profondeur du visuel. perflevel est un indice de performance.

La seule opération définie sur un perflevel est la comparaison avec un perflevel d'un autre visuel sur le même écran. Le visuel ayant le perflevel le plus élevé est susceptible d'avoir de meilleures performances graphiques en double buffering que le visuel ayant le perflevel le plus bas. Rien ne peut être déduit de ce qui suit : l'amplitude de la différence entre deux perflevels, une valeur de perflevel isolée, ou la comparaison de perflevels provenant de serveurs différents.

ERREURS

BadDrawable
Une ou plusieurs valeurs passées dans screen_specifiers ne sont pas des drawables valides.

VOIR AUSSI
