Paquet: libx11

Licences: MIT AND X11

XDrawArc(3) FONCTIONS XLIB XDrawArc(3)

NOM

XDrawArc, XDrawArcs, XArc - dessiner des arcs et structure d'arc

SYNTAXE

int XDrawArc(Display *display, Drawable d, GC gc, int x, int y, unsigned int width, unsigned int height, int angle1, int angle2);

int XDrawArcs(Display *display, Drawable d, GC gc, XArc *arcs, int narcs);

ARGUMENTS

angle1
Spécifie le début de l'arc par rapport à la position de trois heures du centre, en unités de degrés * 64.
angle2
Spécifie le chemin et l'étendue de l'arc par rapport au début de l'arc, en unités de degrés * 64.
arcs
Spécifie un tableau d'arcs.
d
Spécifie l'objet dessinable.
display
Spécifie la connexion au serveur X.
gc
Spécifie le GC.
narcs
Spécifie le nombre d'arcs dans le tableau.
width

height
Spécifient la largeur et la hauteur, qui sont les axes majeurs et mineurs de l'arc.
x

y
Spécifient les coordonnées x et y, qui sont relatives à l'origine de l'objet dessinable et spécifient le coin supérieur gauche du rectangle englobant.

DESCRIPTION

XDrawArc dessine un arc circulaire ou elliptique unique, et XDrawArcs dessine plusieurs arcs circulaires ou elliptiques. Chaque arc est spécifié par un rectangle et deux angles. Le centre du cercle ou de l'ellipse est le centre du rectangle, et les axes majeurs et mineurs sont spécifiés par la largeur et la hauteur. Les angles positifs indiquent un mouvement anti-horaire, et les angles négatifs indiquent un mouvement horaire. Si la magnitude de angle2 est supérieure à 360 degrés, XDrawArc ou XDrawArcs la tronque à 360 degrés.

Pour un arc spécifié comme [x,y,width,height,angle1,angle2] , l'origine des axes majeurs et mineurs se situe à [x+width2,y+height2] , et le chemin d'épaisseur infinie décrivant le cercle ou l'ellipse entière intersecte l'axe horizontal à [x,y+height2] et [x+width,y+height2] et intersecte l'axe vertical à [x+width2,y] et [x+width2,y+height] . Ces coordonnées peuvent être fractionnaires et ne sont donc pas tronquées en coordonnées discrètes. Le chemin doit être défini par le chemin mathématique idéal. Pour une ligne large avec une largeur de ligne lw, les contours englobants pour le remplissage sont donnés par les deux chemins d'épaisseur infinie constitués de tous les points dont la distance perpendiculaire au chemin du cercle/ellipse est égale à lw/2 (qui peut être une valeur fractionnaire). Le style de bout et le style de jointure sont appliqués comme pour une ligne correspondant à la tangente du cercle/ellipse à l'extrémité.

Pour un arc spécifié comme [x,y,width,height,angle1,angle2] , les angles doivent être spécifiés dans le système de coordonnées effectivement biaisé de l'ellipse (pour un cercle, les angles et les systèmes de coordonnées sont identiques). La relation entre ces angles et les angles exprimés dans le système de coordonnées normal de l'écran (mesurés avec un rapporteur) est la suivante :


angle-biaisé=atantan(angle-normal)*widthheight+ajustement

L'angle-biaisé et l'angle-normal sont exprimés en radians (plutôt qu'en degrés multipliés par 64) dans l'intervalle [0,2π] et où atan renvoie une valeur dans l'intervalle [−π2,π2] et ajustement est :

%0% pour angle-normal dans l'intervalle % [ 0 , ~pi sur 2 ]%
%pi% pour angle-normal dans l'intervalle % [ pi sur 2 , ~{3 pi} sur 2 ]%
%2 pi% pour angle-normal dans l'intervalle % [ {3 pi} sur 2 , ~2 pi ]%

Pour tout arc donné, XDrawArc et XDrawArcs ne dessinent pas un pixel plus d'une fois. Si deux arcs se joignent correctement et si la largeur de ligne est supérieure à zéro et que les arcs s'intersectent, XDrawArc et XDrawArcs ne dessinent pas un pixel plus d'une fois. Sinon, les pixels d'intersection des arcs qui s'intersectent sont dessinés plusieurs fois. Spécifier un arc avec un point final et une étendue horaire dessine les mêmes pixels que spécifier l'autre point final et une étendue anti-horaire équivalente, sauf en ce qui concerne les jointures.

Si le dernier point d'un arc coïncide avec le premier point de l'arc suivant, les deux arcs se joindront correctement. Si le premier point du premier arc coïncide avec le dernier point du dernier arc, les deux arcs se joindront correctement. En spécifiant qu'un axe est nul, une ligne horizontale ou verticale peut être dessinée. Les angles sont calculés uniquement sur la base du système de coordonnées et ignorent le rapport d'aspect.

Les deux fonctions utilisent ces composants GC : function, plane-mask, line-width, line-style, cap-style, join-style, fill-style, subwindow-mode, clip-x-origin, clip-y-origin, et clip-mask. Elles utilisent également ces composants dépendants du mode GC : foreground, background, tile, stipple, tile-stipple-x-origin, tile-stipple-y-origin, dash-offset, et dash-list.

XDrawArc et XDrawArcs peuvent générer des erreurs BadDrawable, BadGC, et BadMatch.

STRUCTURES

La structure XArc contient :

typedef struct {
	short x, y;
	unsigned short width, height;
	short angle1, angle2;             /* Degrés * 64 */
} XArc;

Tous les membres x et y sont des entiers signés. Les membres width et height sont des entiers non signés de 16 bits. Vous devez faire attention à ne pas générer de coordonnées et de tailles en dehors des plages de 16 bits, car le protocole n'a que des champs de 16 bits pour ces valeurs.

Une fenêtre InputOnly est utilisée comme Drawable.

XDrawArcs(3)

NOM

XDrawArcs - dessiner des arcs de cercle et des secteurs

SYNTAXE

Bool XDrawArcs(Display *display, Drawable d, GC gc,
        int x, int y, unsigned int width, unsigned int height,
        int angle1, int angle2, ...);
Bool XFillArcs(Display *display, Drawable d, GC gc,
        int x, int y, unsigned int width, unsigned int height,
        int angle1, int angle2, ...);

ARGUMENTS

display
Spécifie la connexion au serveur X.
d
Spécifie leDrawable (une fenêtre ou une pixmap) sur lequel l'arc est dessiné.
gc
Spécifie le contexte graphique.
x, y
Spécifient les coordonnées du coin supérieur gauche du rectangle englobant.
width, height
Spécifient la largeur et la hauteur du rectangle englobant.
angle1
Spécifie l'angle de départ de l'arc en unités de 1/64ème de degré. L'angle 0 est à la position 3 heures (droite).
angle2
Spécifie la longueur de l'arc en unités de 1/64ème de degré.
...
Une liste d'arcs supplémentaires sous forme de structures XArcStruct.

DESCRIPTION

La fonction XDrawArcs dessine une séquence d'arcs de cercle et de secteurs. Les arcs sont décrits par les arguments x, y, width, height, angle1, et angle2. Les coordonnées sont relatives au coin supérieur gauche du Drawable. La largeur et la hauteur spécifient la taille du rectangle englobant de l'ellipse dont l'arc fait partie. Les angles sont mesurés en unités de 1/64ème de degré, où 0 degré est à la position 3 heures. angle1 spécifie l'angle de départ, et angle2 spécifie la longueur de l'arc. Un angle2 positif dessine dans le sens antihoraire, et un angle2 négatif dessine dans le sens horaire.

Si angle2 est négatif, il est traité comme positif, et l'arc est dessiné dans le sens antihoraire. Si l'arc est complètement fermé (c'est-à-dire que la différence entre angle1 et angle2 est égale à 360 degrés), un arc complet est dessiné.

Les arcs peuvent être remplis en utilisant la fonction XFillArcs. Les arcs remplis sont dessinés comme des secteurs, où chaque arc est connecté au centre de l'ellipse.

La fonction peut prendre des arguments supplémentaires représentant des structures XArcStruct pour dessiner plusieurs arcs en un seul appel.

La fonction retourne True si le dessin a été effectué avec succès, et False en cas d'erreur.

STRUCTURES

La structure XArcStruct est définie comme suit :

typedef struct {
    int x, y;
    unsigned int width, height;
    int angle1, angle2;
} XArcStruct;

DIAGNOSTICS

BadGC
Un identifiant de contexte graphique invalide est fourni.
BadDrawable
Un identifiant de Drawable invalide est fourni.
BadValue
Un argument ou une paire d'arguments a le bon type et la bonne plage, mais ne correspond pas d'une autre manière requise par la requête.
