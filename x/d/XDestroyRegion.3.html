XCreateRegion(3) FONCTIONS XLIB XCreateRegion(3)

NOM

XCreateRegion, XSetRegion, XDestroyRegion - créer ou détruire des régions

SYNTAXE

Region XCreateRegion(void);

int XSetRegion(Display *display, GC gc, Region r);

int XDestroyRegion(Region r);

ARGUMENTS

display
Spécifie la connexion au serveur X.
gc
Spécifie le GC.
r
Spécifie la région.

DESCRIPTION

La fonction XCreateRegion crée une nouvelle région vide.

La fonction XSetRegion définit le masque de découpage (clip-mask) dans le GC à la région spécifiée. La région est spécifiée relativement à l'origine de la cible graphique (drawable). L'origine de découpage du GC résultant est dépendante de l'implémentation. Une fois qu'elle est définie dans le GC, la région peut être détruite.

La fonction XDestroyRegion désalloue le stockage associé à une région spécifiée.

VOIR AUSSI

XEmptyRegion(3), XIntersectRegion(3)
