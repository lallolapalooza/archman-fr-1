XDrawText16(3)

Paquet: libx11

Licences: MIT ET X11

XDrawText(3) FONCTIONS XLIB XDrawText(3)

NOM

XDrawText, XDrawText16, XTextItem, XTextItem16 - dessiner du texte polytextuel et structures de dessin de texte

SYNTAXE

int XDrawText(Display *display, Drawable d, GC gc, int x, int y, XTextItem *items, int nitems);

int XDrawText16(Display *display, Drawable d, GC gc, int x, int y, XTextItem16 *items, int nitems);

ARGUMENTS

d
Spécifie le drawable.
display
Spécifie la connexion au serveur X.
gc
Spécifie le GC.
items
Spécifie un tableau d'items de texte.
nitems
Spécifie le nombre d'items de texte dans le tableau.
x

y
Spécifient les coordonnées x et y, qui sont relatives à l'origine du drawable spécifié et définissent l'origine du premier caractère.

DESCRIPTION

La fonction XDrawText16 est similaire à XDrawText sauf qu'elle utilise des caractères à 2 octets ou 16 bits. Les deux fonctions permettent un espacement complexe et des décalages de police entre les chaînes comptées.

Chaque item de texte est traité successivement. Un membre font autre que None dans un item provoque le stockage de la police dans le GC et son utilisation pour le texte ultérieur. Un delta d'élément de texte spécifie un changement supplémentaire dans la position le long de l'axe x avant que la chaîne ne soit dessinée. Le delta est toujours ajouté à l'origine du caractère et ne dépend d'aucune caractéristique de la police. Chaque image de caractère, telle que définie par la police dans le GC, est traitée comme un masque supplémentaire pour une opération de remplissage sur le drawable. Le drawable est modifié uniquement là où le caractère de la police a un bit défini à 1. Si un item de texte génère une erreur BadFont, les items de texte précédents peuvent avoir été dessinés.

Pour les polices définies avec un index linéaire plutôt qu'un index matriciel à 2 octets, chaque structure XChar2b est interprétée comme un nombre de 16 bits dont byte1 est l'octet de poids fort.

Les deux fonctions utilisent ces composants GC : fonction, masque de plan, style de remplissage, police, mode sous-fenêtre, origine-x-clip, origine-y-clip et masque de clip. Elles utilisent également ces composants dépendant du mode GC : premier plan, arrière-plan, mosaïque, gabarit, origine-x-mosaïque-gabarit et origine-y-mosaïque-gabarit.

XDrawText et XDrawText16 peuvent générer des erreurs BadDrawable, BadFont, BadGC et BadMatch.

STRUCTURES

Les structures XTextItem et XTextItem16 contiennent :

typedef struct {
        char *chars;    /* pointeur vers la chaîne */
        int nchars;     /* nombre de caractères */
        int delta;      /* delta entre les chaînes */
        Font font;      /* Police pour l'impression, None pour ne pas changer */
} XTextItem;
typedef struct {
        XChar2b *chars; /* pointeur vers les caractères à deux octets */
        int nchars;     /* nombre de caractères */
        int delta;      /* delta entre les chaînes */
        Font font;      /* police pour l'impression, None pour ne pas changer */
} XTextItem16;

Si le membre font n'est pas None, la police est modifiée avant l'impression et est également stockée dans le GC. Si une erreur a été générée pendant le dessin du texte, les items précédents peuvent avoir été dessinés. La ligne de base des caractères est dessinée en commençant aux coordonnées x et y que vous passez dans les fonctions de dessin de texte.

Par exemple, considérez le rectangle d'arrière-plan dessiné par XDrawImageString. Si vous voulez que le coin supérieur gauche du rectangle d'arrière-plan soit aux coordonnées de pixel (x,y), passez (x,y + ascent) comme coordonnées d'origine de la ligne de base aux fonctions de texte. L'ascendante est l'ascendante de la police, telle que donnée dans la structure XFontStruct. Si vous voulez que le coin inférieur gauche du rectangle d'arrière-plan soit aux coordonnées de pixel (x,y), passez (x,y - descent + 1) comme coordonnées d'origine de la ligne de base aux fonctions de texte. La descendante est la descendante de la police, telle que donnée dans la structure XFontStruct.

DIAGNOSTICS

BadDrawable
Une valeur pour un argument Drawable ne nomme pas une Fenêtre ou un Pixmap défini.
BadFont
Une valeur pour un argument Font ou GContext ne nomme pas une Police définie.
BadGC
Une valeur pour un argument GContext ne nomme pas un GContext défini.
BadMatch
Une fenêtre InputOnly est utilisée comme Drawable.
