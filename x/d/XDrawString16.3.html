XDrawString16(3)

Paquet: libx11

Licences: MIT AND X11

XDrawString(3) FONCTIONS XLIB XDrawString(3)

NOM

XDrawString, XDrawString16 - dessiner des caractères de texte

SYNTAXE

int XDrawString(Display *display, Drawable d, GC gc, int x, int y, _Xconst char *string, int length);

int XDrawString16(Display *display, Drawable d, GC gc, int x, int y, _Xconst XChar2b *string, int length);

ARGUMENTS

d
Spécifie le drawable.
display
Spécifie la connexion au serveur X.
gc
Spécifie le GC.
length
Spécifie le nombre de caractères dans l'argument chaîne.
string
Spécifie la chaîne de caractères.
x

y
Spécifient les coordonnées x et y, relatives à l'origine du drawable spécifié et définissent l'origine du premier caractère.

DESCRIPTION

Chaque image de caractère, telle que définie par la police dans le GC, est traitée comme un masque supplémentaire pour une opération de remplissage sur le drawable. Le drawable est modifié uniquement là où le caractère de la police a un bit défini à 1. Pour les polices définies avec un index matriciel de 2 octets et utilisées avec XDrawString16, chaque octet est utilisé comme un byte2 avec un byte1 de zéro.

Les deux fonctions utilisent ces composants de GC : fonction, masque de plan, style de remplissage, police, mode sous-fenêtre, origine x du clip, origine y du clip et masque du clip. Elles utilisent également ces composants dépendant du mode GC : premier plan, arrière-plan, tuile, pochoir, origine x de la tuile-pochoir et origine y de la tuile-pochoir.

XDrawString et XDrawString16 peuvent générer des erreurs BadDrawable, BadGC et BadMatch.

DIAGNOSTICS

BadDrawable
Une valeur pour un argument Drawable ne nomme pas une Fenêtre ou un Pixmap défini.
BadGC
Une valeur pour un argument GContext ne nomme pas un GContext défini.
BadMatch
Une fenêtre InputOnly est utilisée comme Drawable.
BadMatch
Un argument ou une paire d'arguments a le type et la plage corrects mais ne correspond pas d'une autre manière requise par la demande.
