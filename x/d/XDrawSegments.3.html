XDrawSegments(3)

Paquet: libx11

Licences: MIT AND X11

XDrawLine(3) FONCTIONS XLIB XDrawLine(3)

NOM

XDrawLine, XDrawLines, XDrawSegments, XSegment - dessiner des lignes, des polygones et des structures de lignes

SYNTAXE

int XDrawLine(Display *display, Drawable d, GC gc, int x1, int y1, int x2, int y2);

int XDrawLines(Display *display, Drawable d, GC gc, XPoint *points, int npoints, int mode);

int XDrawSegments(Display *display, Drawable d, GC gc, XSegment *segments, int nsegments);

ARGUMENTS

d
Spécifie le dessinable.
display
Spécifie la connexion au serveur X.
gc
Spécifie le GC.
mode
Spécifie le mode de coordonnées. Vous pouvez passer CoordModeOrigin ou CoordModePrevious.
npoints
Spécifie le nombre de points dans le tableau.
nsegments
Spécifie le nombre de segments dans le tableau.
points
Spécifie un tableau de points.
segments
Spécifie un tableau de segments.
x1

y1

x2

y2
Spécifient les points (x1, y1) et (x2, y2) à connecter.

DESCRIPTION

La fonction XDrawLine utilise les composants du GC spécifié pour dessiner une ligne entre l'ensemble spécifié de points (x1, y1) et (x2, y2). Elle n'effectue pas de jonction aux extrémités coïncidentes. Pour toute ligne donnée, XDrawLine ne dessine pas un pixel plus d'une fois. Si les lignes s'intersectent, les pixels d'intersection sont dessinés plusieurs fois.

La fonction XDrawLines utilise les composants du GC spécifié pour dessiner npoints-1 lignes entre chaque paire de points (point[i], point[i+1]) dans le tableau de structures XPoint. Elle dessine les lignes dans l'ordre spécifié dans le tableau. Les lignes se joignent correctement à tous les points intermédiaires, et si le premier et le dernier points coïncident, les première et dernière lignes se joignent également correctement. Pour toute ligne donnée, XDrawLines ne dessine pas un pixel plus d'une fois. Si des lignes fines (largeur de ligne nulle) s'intersectent, les pixels d'intersection sont dessinés plusieurs fois. Si des lignes larges s'intersectent, les pixels d'intersection ne sont dessinés qu'une seule fois, comme si toute la requête de protocole PolyLine était une forme unique et remplie. CoordModeOrigin traite toutes les coordonnées comme relatives à l'origine, et CoordModePrevious traite toutes les coordonnées après la première comme relatives au point précédent.

La fonction XDrawSegments dessine plusieurs lignes non connectées. Pour chaque segment, XDrawSegments dessine une ligne entre (x1, y1) et (x2, y2). Elle dessine les lignes dans l'ordre spécifié dans le tableau de structures XSegment et n'effectue pas de jonction aux extrémités coïncidentes. Pour toute ligne donnée, XDrawSegments ne dessine pas un pixel plus d'une fois. Si les lignes s'intersectent, les pixels d'intersection sont dessinés plusieurs fois.

Les trois fonctions utilisent ces composants du GC : fonction, masque de plan, largeur de ligne, style de ligne, style de bout, style de remplissage, mode de sous-fenêtre, origine-x-clipping, origine-y-clipping et masque de clipping. La fonction XDrawLines utilise également le composant style de jonction du GC. Les trois fonctions utilisent également ces composants dépendants du mode du GC : premier plan, arrière-plan, motif, hachures, origine-x-motif-hachures, origine-y-motif-hachures, décalage de tirets et liste de tirets.

XDrawLine, XDrawLines et XDrawSegments peuvent générer les erreurs BadDrawable, BadGC et BadMatch. XDrawLines peut également générer une erreur BadValue.

STRUCTURES

La structure XSegment contient :

typedef struct {
        short x1, y1, x2, y2;
} XSegment;

Tous les membres x et y sont des entiers signés. Les membres de largeur et de hauteur sont des entiers non signés de 16 bits. Vous devez faire attention à ne pas générer de coordonnées et de tailles en dehors des plages de 16 bits, car le protocole n'a que des champs de 16 bits pour ces valeurs.

DIAGNOSTICS

BadDrawable
Une valeur pour un argument Drawable ne nomme pas une fenêtre ou un Pixmap défini.
BadGC
Une valeur pour un argument GContext ne nomme pas un GContext défini.
BadMatch
Une fenêtre InputOnly est utilisée comme Drawable.
BadMatch
Un argument ou une paire d'arguments a le type et la plage corrects mais ne correspond pas d'une autre manière requise par la requête.
BadValue
Une valeur numérique se situe en dehors de la plage des valeurs acceptées par la requête. À moins qu'une plage spécifique ne soit spécifiée pour un argument, la plage complète définie par le type de l'argument est acceptée. Tout argument défini comme un ensemble d'alternatives peut générer cette erreur.
