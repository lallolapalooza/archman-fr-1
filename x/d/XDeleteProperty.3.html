XGetWindowProperty(3) FONCTIONS XLIB XGetWindowProperty(3)

NOM

XGetWindowProperty, XListProperties, XChangeProperty, XRotateWindowProperties, XDeleteProperty - obtenir et modifier les propriétés de fenêtre

SYNTAXE

int XGetWindowProperty(Display *display, Window w, Atom property, long long_offset, long long_length, Bool delete, Atom req_type, Atom *actual_type_return, int *actual_format_return, unsigned long *nitems_return, unsigned long *bytes_after_return, unsigned char **prop_return);

Atom *XListProperties(Display *display, Window w, int *num_prop_return);

int XChangeProperty(Display *display, Window w, Atom property, Atom type, int format, int mode, _Xconst unsigned char *data, int nelements);

int XRotateWindowProperties(Display *display, Window w, Atom properties[], int num_prop, int npositions);

int XDeleteProperty(Display *display, Window w, Atom property);

ARGUMENTS

actual_format_return
Retourne le format réel de la propriété.
actual_type_return
Retourne l'identifiant de l'atome qui définit le type réel de la propriété.
bytes_after_return
Retourne le nombre d'octets restants à lire dans la propriété si une lecture partielle a été effectuée.
data
Spécifie les données de la propriété.
delete
Spécifie une valeur booléenne qui détermine si la propriété doit être supprimée.
display
Spécifie la connexion au serveur X.
format
Spécifie si les données doivent être considérées comme une liste de quantités de 8, 16 ou 32 bits. Les valeurs possibles sont 8, 16 et 32. Ces informations permettent au serveur X d'effectuer correctement les opérations d'échange d'octets si nécessaire. Si le format est de 16 ou 32 bits, vous devez explicitement transtyper votre pointeur de données en (unsigned char *) lors de l'appel à XChangeProperty.
long_length
Spécifie la longueur en multiples de 32 bits des données à récupérer.
long_offset
Spécifie le décalage dans la propriété spécifiée (en quantités de 32 bits) où les données doivent être récupérées.
mode
Spécifie le mode de l'opération. Vous pouvez passer PropModeReplace, PropModePrepend, ou PropModeAppend.
nelements
Spécifie le nombre d'éléments du format de données spécifié.
nitems_return
Retourne le nombre réel d'éléments de 8, 16 ou 32 bits stockés dans les données retournées par prop_return.
num_prop
Spécifie la longueur du tableau de propriétés.
num_prop_return
Retourne la longueur du tableau de propriétés.
npositions
Spécifie le montant de rotation.
prop_return
Retourne les données dans le format spécifié. Si le format retourné est 8, les données retournées sont représentées sous forme de tableau de char. Si le format retourné est 16, les données retournées sont représentées sous forme de tableau de type short int et doivent être transtypées vers ce type pour obtenir les éléments. Si le format retourné est 32, les données de propriété seront stockées sous forme de tableau de longs (qui dans une application 64 bits seront des valeurs de 64 bits qui sont complétées dans les 4 octets supérieurs).
property
Spécifie le nom de la propriété.
properties
Spécifie le tableau de propriétés qui doivent être pivotées.
req_type
Spécifie l'identifiant de l'atome associé au type de propriété ou AnyPropertyType.
type
Spécifie le type de la propriété. Le serveur X n'interprète pas le type mais le renvoie à une application qui appelle plus tard XGetWindowProperty.
w
Spécifie la fenêtre dont vous souhaitez obtenir, modifier, faire pivoter ou supprimer une propriété.

DESCRIPTION

La fonction XGetWindowProperty retourne le type réel de la propriété ; le format réel de la propriété ; le nombre d'éléments de 8, 16 ou 32 bits transférés ; le nombre d'octets restants à lire dans la propriété ; et un pointeur vers les données effectivement retournées. XGetWindowProperty définit les arguments de retour comme suit :

  • Si la propriété spécifiée n'existe pas pour la fenêtre spécifiée, XGetWindowProperty retourne None à actual_type_return et la valeur zéro à actual_format_return et bytes_after_return. L'argument nitems_return est vide. Dans ce cas, l'argument delete est ignoré.
  • Si la propriété spécifiée existe mais que son type ne correspond pas au type spécifié, XGetWindowProperty retourne le type de propriété réel à actual_type_return, le format de propriété réel (jamais zéro) à actual_format_return, et la longueur de la propriété en octets (même si actual_format_return est 16 ou 32) à bytes_after_return. Il ignore également l'argument delete. L'argument nitems_return est vide.
  • Si la propriété spécifiée existe et que vous assignez AnyPropertyType à l'argument req_type ou que le type spécifié correspond au type de propriété réel, XGetWindowProperty retourne le type de propriété réel à actual_type_return et le format de propriété réel (jamais zéro) à actual_format_return. Il retourne également une valeur à bytes_after_return et nitems_return, en définissant les valeurs suivantes :
N = longueur réelle de la propriété stockée en octets
     (même si le format est 16 ou 32)
I = 4 * long_offset
T = N - I
L = MINIMUM(T, 4 * long_length)
A = N - (I + L)
La valeur retournée commence à l'indice d'octet I dans la propriété (indexation à partir de zéro), et sa longueur en octets est L. Si la valeur pour long_offset fait que L est négatif, une erreur BadValue résulte. La valeur de bytes_after_return est A, donnant le nombre d'octets non lus restants dans la propriété stockée.

Si le format retourné est 8, les données retournées sont représentées comme un tableau char. Si le format retourné est 16, les données retournées sont représentées comme un tableau short et doivent être transtypées dans ce type pour obtenir les éléments. Si le format retourné est 32, les données retournées sont représentées comme un tableau long et doivent être transtypées dans ce type pour obtenir les éléments.

XGetWindowProperty alloue toujours un octet supplémentaire dans prop_return (même si la propriété est de longueur zéro) et le met à zéro afin que les propriétés simples composées de caractères n'aient pas besoin d'être copiées dans une autre chaîne avant utilisation.

Si delete est True et bytes_after_return est zéro, XGetWindowProperty supprime la propriété de la fenêtre et génère un événement PropertyNotify sur la fenêtre.

La fonction retourne Success si elle s'exécute correctement. Pour libérer les données résultantes, utilisez XFree.

XGetWindowProperty peut générer les erreurs BadAtom, BadValue et BadWindow.

La fonction XListProperties retourne un pointeur vers un tableau de propriétés d'atomes définies pour la fenêtre spécifiée ou retourne NULL si aucune propriété n'a été trouvée. Pour libérer la mémoire allouée par cette fonction, utilisez XFree.

XListProperties peut générer une erreur BadWindow.

La fonction XChangeProperty modifie la propriété pour la fenêtre spécifiée et provoque la génération d'un événement PropertyNotify par le serveur X.

XChangeProperty peut générer les erreurs BadAtom, BadMatch, BadValue et BadWindow.

La fonction XRotateWindowProperties fait pivoter les propriétés spécifiées pour la fenêtre spécifiée. Elle génère un événement PropertyNotify pour chaque propriété pivotée.

XRotateWindowProperties peut générer les erreurs BadAtom, BadValue et BadWindow.

La fonction XDeleteProperty supprime la propriété spécifiée de la fenêtre spécifiée et génère un événement PropertyNotify sur la fenêtre.

XDeleteProperty peut générer les erreurs BadAtom, BadValue et BadWindow.

VOIR AUSSI

XFree(3), XInternAtom(3)

XChangeProperty(3)

NAME

XChangeProperty, XDeleteProperty, XGetCommand, XGetWindowProperty, XListProperties, XRotateWindowProperties - modifier, lire et énumérer les propriétés d'une fenêtre

SYNTAX

#include <X11/Xlib.h>

int XChangeProperty(Display *display, Window w, Atom property, Atom type,
    int format, int mode, const unsigned char *data, int nelements);

unsigned long XGetWindowProperty(Display *display, Window w, Atom property,
    long long_offset, long long_count, Bool delete, Atom req_type,
    Atom *actual_type_return, int *actual_format_return,
    unsigned long *nitems_return, unsigned long *bytes_after_return,
    unsigned char **prop_return);

Atom *XListProperties(Display *display, Window w, int *num_properties);

int XRotateWindowProperties(Display *display, Window w,
    Atom *properties, int num_prop, int npositions);

int XDeleteProperty(Display *display, Window w, Atom property);

ARGUMENTS

Fournit une description détaillée des arguments de chaque fonction.

DESCRIPTION

La fonction XChangeProperty associe une valeur de propriété à une fenêtre. Si la propriété est déjà définie sur la fenêtre, le comportement de XChangeProperty dépend du mode spécifié.

  • Si mode est PropModeReplace, XChangeProperty supprime la valeur précédente de la propriété et stocke les nouvelles données.
  • Si mode est PropModePrepend ou PropModeAppend, XChangeProperty insère les données spécifiées avant le début des données existantes ou à la fin des données existantes, respectivement. Le type et le format doivent correspondre à la valeur existante de la propriété, sinon une erreur BadMatch sera générée. Si la propriété n'est pas définie, elle est traitée comme définie avec le bon type et format, avec des données de longueur zéro.

Si le format spécifié est 8, les données de la propriété doivent être un tableau de char. Si le format spécifié est 16, les données de la propriété doivent être un tableau de short. Si le format spécifié est 32, les données de la propriété doivent être un tableau de long.

La durée de vie d'une propriété n'est pas liée au client qui la stocke. Les propriétés restent jusqu'à ce qu'elles soient explicitement supprimées, jusqu'à ce que la fenêtre soit détruite, ou jusqu'à ce que le serveur soit réinitialisé. Pour une discussion sur ce qui se passe lorsque la connexion au serveur X est fermée, voir la section 2.6. La taille maximale d'une propriété dépend du serveur et peut varier dynamiquement en fonction de la quantité de mémoire disponible pour le serveur. (S'il n'y a pas assez d'espace, une erreur BadAlloc sera générée.)

XChangeProperty peut générer des erreurs BadAlloc, BadAtom, BadMatch, BadValue et BadWindow.

La fonction XRotateWindowProperties vous permet de faire pivoter les propriétés d'une fenêtre et provoque la génération d'événements PropertyNotify par le serveur X. Si les noms de propriétés dans le tableau properties sont considérés comme numérotés à partir de zéro et s'il y a num_prop noms de propriétés dans la liste, alors la valeur associée au nom de propriété I devient la valeur associée au nom de propriété (I + npositions) mod N pour tous les I de zéro à N - 1. L'effet est de faire pivoter les états de npositions endroits autour de l'anneau virtuel des noms de propriétés (vers la droite pour npositions positif, vers la gauche pour npositions négatif). Si npositions mod N est non nul, le serveur X génère un événement PropertyNotify pour chaque propriété dans l'ordre où elles sont listées dans le tableau. Si un atome apparaît plus d'une fois dans la liste ou si aucune propriété portant ce nom n'est définie pour la fenêtre, une erreur BadMatch sera générée. Si une erreur BadAtom ou BadMatch se produit, aucune propriété n'est modifiée.

XRotateWindowProperties peut générer des erreurs BadAtom, BadMatch et BadWindow.

La fonction XDeleteProperty supprime la propriété spécifiée uniquement si la propriété était définie sur la fenêtre spécifiée et provoque la génération d'un événement PropertyNotify sur la fenêtre par le serveur X, sauf si la propriété n'existe pas.

XDeleteProperty peut générer des erreurs BadAtom et BadWindow.

DIAGNOSTICS

BadAlloc
Le serveur n'a pas pu allouer la ressource ou la mémoire serveur demandée.
BadAtom
Une valeur pour un argument Atom ne nomme pas un Atome défini.
BadValue
Une valeur numérique est en dehors de la plage de valeurs acceptées par la requête. Sauf si une plage spécifique est spécifiée pour un argument, la plage complète définie par le type de l'argument est acceptée. Tout argument défini comme un ensemble d'alternatives peut générer cette erreur.
BadWindow
Une valeur pour un argument Window ne nomme pas une Window définie.
