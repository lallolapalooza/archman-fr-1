XDrawPoints(3)

Paquet: libx11

Licences: MIT AND X11

XDrawPoint(3) FONCTIONS XLIB XDrawPoint(3)

NOM

XDrawPoint, XDrawPoints, XPoint - dessiner des points et une structure de points

SYNTAXE

int XDrawPoint(Display *display, Drawable d, GC gc, int x, int y);

int XDrawPoints(Display *display, Drawable d, GC gc, XPoint *points, int npoints, int mode);

ARGUMENTS

d
Spécifie le drawable.
display
Spécifie la connexion au serveur X.
gc
Spécifie le GC.
mode
Spécifie le mode de coordonnées. Vous pouvez passer CoordModeOrigin ou CoordModePrevious.
npoints
Spécifie le nombre de points dans le tableau.
points
Spécifie un tableau de points.
x

y
Spécifiez les coordonnées x et y où vous souhaitez que le point soit dessiné.

DESCRIPTION

La fonction XDrawPoint utilise le pixel de premier plan et les composants de fonction du GC pour dessiner un seul point dans le drawable spécifié ; XDrawPoints dessine plusieurs points de cette manière. CoordModeOrigin traite toutes les coordonnées comme relatives à l'origine, et CoordModePrevious traite toutes les coordonnées après la première comme relatives au point précédent. XDrawPoints dessine les points dans l'ordre indiqué dans le tableau.

Les deux fonctions utilisent ces composants GC : fonction, masque de plan, premier plan, mode sous-fenêtre, origine x du clip, origine y du clip et masque du clip.

XDrawPoint peut générer des erreurs BadDrawable, BadGC et BadMatch. XDrawPoints peut générer des erreurs BadDrawable, BadGC, BadMatch et BadValue.

STRUCTURES

La structure XPoint contient :

typedef struct {
        short x, y;
} XPoint;

Tous les membres x et y sont des entiers signés. Les membres de largeur et de hauteur sont des entiers non signés de 16 bits. Vous devez faire attention à ne pas générer des coordonnées et des tailles en dehors des plages de 16 bits, car le protocole n'a que des champs de 16 bits pour ces valeurs.

DIAGNOSTICS

BadDrawable
Une valeur pour un argument Drawable ne nomme pas une fenêtre ou unPixmap défini.
BadGC
Une valeur pour un argument GContext ne nomme pas un GContext défini.
BadMatch
Une fenêtre InputOnly est utilisée comme Drawable.
BadMatch
Un argument ou une paire d'arguments a le bon type et la bonne plage mais ne correspond pas d'une autre manière requise par la requête.
BadValue
Une valeur numérique se situe en dehors de la plage de valeurs acceptées par la requête. Sauf si une plage spécifique est spécifiée pour un argument, la plage complète définie par le type de l'argument est acceptée. Tout argument défini comme un ensemble d'alternatives peut générer cette erreur.
