Paquet: libxi

XGETDEVICEPROPERTY(3)   XGETDEVICEPROPERTY(3)

NOM

XGetDeviceProperty, XChangeDeviceProperty, XDeleteDeviceProperty - Obtenir, modifier ou supprimer une propriété d'un périphérique.

SYNTAXE

#include <X11/extensions/XInput.h>
int XGetDeviceProperty( Display *display,
                        XDevice *device,
                        Atom property,
                        long offset,
                        long length,
                        Bool delete,
                        Atom req_type,
                        Atom *actual_type_return,
                        int *actual_format_return,
                        unsigned long *nitems_return,
                        unsigned long *bytes_after_return,
                        unsigned char **prop_return)
void XChangeDeviceProperty( Display *display,
                            XDevice *device,
                            Atom property,
                            Atom type,
                            int format,
                            int mode,
                            const unsigned char *data,
                            int nelements)
void XDeleteDeviceProperty( Display *display,
                            XDevice *device,
                            Atom property)
actual_type_return
       Retourne un identifiant d'atome qui définit le type réel de la
       propriété.
actual_format_return
       Retourne le format réel de la propriété.
bytes_after_return
       Retourne le nombre d'octets restants à lire dans la propriété si une
       lecture partielle a été effectuée.
data
       Spécifie les données de la propriété.
delete
       Spécifie une valeur booléenne qui détermine si la propriété est
       supprimée.
display
       Spécifie la connexion au serveur X.
device
       Le périphérique à saisir.
format
       Spécifie si les données doivent être vues comme une liste de quantités
       de 8, 16 ou 32 bits. Les valeurs possibles sont 8, 16 et 32. Ces
       informations permettent au serveur X d'effectuer correctement les
       opérations de permutation d'octets si nécessaire. Si le format est de
       16 ou 32 bits, vous devez explicitement caster le pointeur de données en
       (unsigned char*) dans l'appel à XChangeDeviceProperty.
length
       Spécifie la longueur en multiples de 32 bits des données à récupérer.
mode
       Spécifie le mode de fonctionnement. Vous pouvez passer
       PropModeReplace, PropModePrepend ou PropModeAppend.
nelements
       Spécifie le nombre d'éléments dans data.
nitems_return
       Retourne le nombre réel d'éléments de 8, 16 ou 32 bits stockés dans le
       tableau prop_return.
num_values
       Spécifie le nombre d'éléments dans la liste values.
offset
       Spécifie le décalage dans la propriété spécifiée (en quantités de 32
       bits) où les données doivent être récupérées.
property
       Spécifie la propriété à modifier ou à interroger.
prop_return
       Retourne les données dans le format spécifié. Si le format retourné est
       8, les données retournées sont représentées sous forme de tableau de
       caractères. Si le format retourné est 16, les données retournées sont
       représentées sous forme de tableau de type short int et doivent être
       castées vers ce type pour obtenir les éléments. Si le format retourné
       est 32, les données de la propriété seront stockées sous forme de
       tableau de longs (qui dans une application 64 bits seront des valeurs
       64 bits qui sont complétées dans les 4 octets supérieurs).
req_type
       Spécifie l'identifiant d'atome associé au type de propriété ou
       AnyPropertyType.

DESCRIPTION

La fonction XGetDeviceProperty retourne le type réel de la propriété ; le format réel de la propriété ; le nombre d'éléments de 8, 16 ou 32 bits transférés ; le nombre d'octets restants à lire dans la propriété ; et un pointeur vers les données réellement retournées. Pour une description détaillée de cette fonction, voir la page de manuel de XGetWindowProperty.

La fonction XChangeDeviceProperty modifie la propriété pour le périphérique spécifié et provoque la génération d'un événement XPropertyNotifyEvent sur ce périphérique par le serveur. Pour une description détaillée de cette fonction, voir la page de manuel de XChangeProperty.

La fonction XDeleteDeviceProperty supprime la propriété du périphérique spécifiée. Notez qu'un client ne peut pas supprimer une propriété créée par un pilote ou le serveur. Tenter de le faire entraînera une erreur BadAtom.

XGetDeviceProperty peut générer une erreur BadAtom, BadDevice.

XChangeDeviceProperty peut générer une erreur BadDevice, BadMatch, BadAtom et BadValue.

XDeleteDeviceProperty peut générer une erreur BadDevice et BadAtom.

DIAGNOSTIC

BadAtom
       Une valeur ne décrit pas un identifiant nommé valide ou le client a
       tenté de supprimer une propriété allouée par le pilote.
BadDevice
       Un périphérique invalide a été spécifié. Le périphérique n'existe pas.
