XDefineCursor(3)

Paquet: libx11

Licences: MIT AND X11

XDefineCursor(3) FONCTIONS XLIB XDefineCursor(3)

NOM

XDefineCursor, XUndefineCursor - définir les curseurs

SYNTAXE

int XDefineCursor(Display *display, Window w, Cursor cursor);

int XUndefineCursor(Display *display, Window w);

ARGUMENTS

cursor
Spécifie le curseur à afficher ou None.
display
Spécifie la connexion au serveur X.
w
Spécifie la fenêtre.

DESCRIPTION

Si un curseur est défini, il sera utilisé lorsque le pointeur se trouve dans la fenêtre. Si le curseur est None, cela équivaut à XUndefineCursor.

XDefineCursor peut générer des erreurs BadCursor et BadWindow.

La fonction XUndefineCursor annule l'effet d'un appel précédent à XDefineCursor pour cette fenêtre. Lorsque le pointeur se trouve dans la fenêtre, le curseur du parent sera désormais utilisé. Sur la fenêtre racine, le curseur par défaut est restauré.

XUndefineCursor peut générer une erreur BadWindow.

DIAGNOSTICS

BadAlloc
Le serveur n'a pas pu allouer la ressource ou la mémoire serveur demandée.
BadCursor
Une valeur pour un argument Cursor ne nomme pas un Cursor défini.
BadWindow
Une valeur pour un argument Window ne nomme pas une Window définie.
