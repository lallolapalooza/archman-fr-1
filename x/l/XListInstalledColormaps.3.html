XInstallColormap(3) FONCTIONS XLIB XInstallColormap(3)

NOM

XInstallColormap, XUninstallColormap, XListInstalledColormaps - contrôler les palettes de couleurs

SYNTAXE

int XInstallColormap(Display *display, Colormap colormap);

int XUninstallColormap(Display *display, Colormap colormap);

Colormap *XListInstalledColormaps(Display *display, Window w, int *num_return);

ARGUMENTS

colormap
Spécifie la palette de couleurs.
display
Spécifie la connexion au serveur X.
num_return
Retourne le nombre de palettes de couleurs actuellement installées.
w
Spécifie la fenêtre qui détermine l'écran.

DESCRIPTION

La fonction XInstallColormap installe la palette de couleurs spécifiée pour son écran associé. Toutes les fenêtres associées à cette palette de couleurs s'affichent immédiatement avec leurs vraies couleurs. Vous avez associé les fenêtres à cette palette de couleurs lors de leur création en appelant XCreateWindow, XCreateSimpleWindow, XChangeWindowAttributes ou XSetWindowColormap.

Si la palette de couleurs spécifiée n'est pas déjà une palette de couleurs installée, le serveur X génère un événement ColormapNotify sur chaque fenêtre qui possède cette palette de couleurs. De plus, pour chaque autre palette de couleurs qui est installée suite à un appel à XInstallColormap, le serveur X génère un événement ColormapNotify sur chaque fenêtre qui possède cette palette de couleurs.

XInstallColormap peut générer une erreur BadColor.

La fonction XUninstallColormap retire la palette de couleurs spécifiée de la liste requise pour son écran. En conséquence, la palette de couleurs spécifiée peut être désinstallée, et le serveur X peut implicitement installer ou désinstaller des palettes de couleurs supplémentaires. Les palettes qui sont installées ou désinstallées dépendent du serveur, à l'exception de la liste requise qui doit rester installée.

Si la palette de couleurs spécifiée devient désinstallée, le serveur X génère un événement ColormapNotify sur chaque fenêtre qui possède cette palette de couleurs. De plus, pour chaque autre palette de couleurs qui est installée ou désinstallée suite à un appel à XUninstallColormap, le serveur X génère un événement ColormapNotify sur chaque fenêtre qui possède cette palette de couleurs.

XUninstallColormap peut générer une erreur BadColor.

La fonction XListInstalledColormaps retourne une liste des palettes de couleurs actuellement installées pour l'écran de la fenêtre spécifiée. L'ordre des palettes de couleurs dans la liste n'est pas significatif et n'indique pas explicitement la liste requise. Lorsque la liste allouée n'est plus nécessaire, libérez-la en utilisant XFree.

XListInstalledColormaps peut générer une erreur BadWindow.

DIAGNOSTICS

BadColor
Une valeur pour un argument Colormap ne nomme pas une palette de couleurs définie.
BadWindow
Une valeur pour un argument Window ne nomme pas une fenêtre définie.
