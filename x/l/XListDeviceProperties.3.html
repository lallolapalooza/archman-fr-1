XLISTDEVICEPROPERTIE(3)   XLISTDEVICEPROPERTIE(3)

NOM

XListDeviceProperties - Liste les propriétés d'un périphérique.

SYNTAXE

#include <X11/extensions/XInput.h>
Atom* XListDeviceProperties( Display *display,
                             XDevice *device,
                             int *nprops_return);
display
       Spécifie la connexion au serveur X.
device
       Le périphérique dont les propriétés doivent être listées.
nprops_return
       Spécifie le nombre d'Atoms retournés.

DESCRIPTION

La fonction XListDeviceProperties retourne une liste des
propriétés associées au périphérique d'entrée spécifié dans
device. Chaque périphérique peut avoir un nombre arbitraire de
propriétés attachées, certaines ayant été créées par le pilote
et/ou le serveur, d'autres créées par les clients au moment de
l'exécution.
Le client est censé libérer la liste des propriétés en utilisant
XFree.
XListDeviceProperties peut générer une erreur BadDevice.

DIAGNOSTICS

BadDevice
       Un périphérique invalide a été spécifié. Le périphérique
       n'existe pas.

VOIR AUSSI

XChangeDeviceProperty(3),
XGetDeviceProperty(3),
XDeleteDeviceProperty(3)
