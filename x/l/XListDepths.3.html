DESCRIPTION

La macro AllPlanes retourne une valeur avec tous les bits mis à 1, adaptée pour être utilisée dans un argument de plan pour une procédure.

La macro BlackPixel retourne la valeur de pixel noir pour l'écran spécifié.

La macro WhitePixel retourne la valeur de pixel blanc pour l'écran spécifié.

La macro ConnectionNumber retourne un numéro de connexion pour l'affichage spécifié.

La macro DefaultColormap retourne l'identifiant de la carte de couleurs par défaut pour l'allocation sur l'écran spécifié.

La macro DefaultDepth retourne la profondeur (nombre de plans) de la fenêtre racine par défaut pour l'écran spécifié.

La fonction XListDepths retourne le tableau des profondeurs disponibles sur l'écran spécifié. Si screen_number est valide et qu'une mémoire suffisante pour le tableau peut être allouée, XListDepths définit count_return au nombre de profondeurs disponibles. Sinon, elle ne définit pas count_return et retourne NULL. Pour libérer la mémoire allouée pour le tableau des profondeurs, utilisez XFree.

La macro DefaultGC retourne le GC par défaut pour la fenêtre racine de l'écran spécifié.

La macro DefaultRootWindow retourne la fenêtre racine pour l'écran par défaut.

La macro DefaultScreenOfDisplay retourne l'écran par défaut de l'affichage spécifié.

La macro DefaultScreen retourne le numéro d'écran par défaut référencé dans la routine XOpenDisplay.

La macro DefaultVisual retourne le type de visualisation par défaut pour l'écran spécifié.

La macro DisplayCells retourne le nombre d'entrées dans la carte de couleurs par défaut.

La macro DisplayPlanes retourne la profondeur de la fenêtre racine de l'écran spécifié.

La macro DisplayString retourne la chaîne qui a été passée à XOpenDisplay lors de l'ouverture de l'affichage actuel.

La fonction XMaxRequestSize retourne la taille maximale de requête (en unités de 4 octets) prise en charge par le serveur sans utiliser un encodage de protocole de longueur étendue. Les requêtes de protocole uniques au serveur ne peuvent pas être plus grandes que cette taille, sauf si un encodage de protocole de longueur étendue est pris en charge par le serveur. Le protocole garantit que la taille n'est pas inférieure à 4096 unités (16384 octets). Xlib divise automatiquement les données en plusieurs requêtes de protocole au besoin pour les fonctions suivantes : XDrawPoints, XDrawRectangles, XDrawSegments, XFillArcs, XFillRectangles et XPutImage.

La fonction XExtendedMaxRequestSize retourne zéro si l'affichage spécifié ne prend pas en charge un encodage de protocole de longueur étendue ; sinon, elle retourne la taille maximale de requête (en unités de 4 octets) prise en charge par le serveur en utilisant l'encodage de longueur étendue. Les fonctions Xlib XDrawLines, XDrawArcs, XFillPolygon, XChangeProperty, XSetClipRectangles et XSetRegion utiliseront l'encodage de longueur étendue si nécessaire, s'il est pris en charge par le serveur. L'utilisation de l'encodage de longueur étendue dans d'autres fonctions Xlib (par exemple, XDrawPoints, XDrawRectangles, XDrawSegments, XFillArcs, XFillRectangles, XPutImage) est autorisée mais pas obligatoire ; une implémentation Xlib peut choisir de diviser les données en plusieurs requêtes plus petites à la place.

La macro LastKnownRequestProcessed extrait le numéro de série complet de la dernière requête dont Xlib sait qu'elle a été traitée par le serveur X.

La macro NextRequest extrait le numéro de série complet qui sera utilisé pour la prochaine requête.

La macro ProtocolVersion retourne le numéro de version majeur (11) du protocole X associé à l'affichage connecté.

La macro ProtocolRevision retourne le numéro de révision mineur du protocole du serveur X.

La macro QLength retourne la longueur de la file d'attente des événements pour l'affichage connecté.

La macro RootWindow retourne la fenêtre racine.

La macro ScreenCount retourne le nombre d'écrans disponibles.

La macro ScreenOfDisplay retourne un pointeur vers l'écran de l'affichage spécifié.

La macro ServerVendor retourne un pointeur vers une chaîne terminée par un zéro qui fournit une identification du propriétaire de l'implémentation du serveur X.

La macro VendorRelease retourne un nombre lié à une version du vendeur du serveur X.

XListDepths - liste les profondeurs de couleur disponibles pour un écran.

NAME

XListDepths - liste les profondeurs de couleur disponibles pour un écran.

SYNTAX

XListDepths [ -display display ] [ -screen screen ]

ARGUMENTS

-display display
Spécifie le serveur d'affichage à interroger. Le format de display est hostname:number.
-screen screen
Spécifie l'écran à interroger. Le format de screen est number.

DESCRIPTION

XListDepths liste toutes les profondeurs de couleur disponibles pour un écran donné d'un serveur d'affichage X. Pour chaque profondeur, il affiche également les types de visuels disponibles et leur nombre maximum.

Par défaut, XListDepths interroge l'écran par défaut du serveur d'affichage spécifié par la variable d'environnement DISPLAY.
