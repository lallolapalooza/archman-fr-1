XListFonts(3) FONCTIONS XLIB XListFonts(3)

NOM

XListFonts, XFreeFontNames, XListFontsWithInfo, XFreeFontInfo - obtenir ou libérer des noms et informations de polices

SYNTAXE

char **XListFonts(Display *display, _Xconst char *pattern, int maxnames, int *actual_count_return);

int XFreeFontNames(char *list[]);

char **XListFontsWithInfo(Display *display, _Xconst char *pattern, int maxnames, int *count_return, XFontStruct **info_return);

int XFreeFontInfo(char **names, XFontStruct *free_info, int actual_count);

ARGUMENTS

actual_count
Spécifie le nombre réel de noms de polices.
actual_count_return
Retourne le nombre réel de noms de polices.
count_return
Retourne le nombre réel de noms de polices correspondants.
display
Spécifie la connexion au serveur X.
info_return
Retourne les informations de la police.
free_info
Spécifie les informations de la police.
list
Spécifie le tableau de chaînes que vous souhaitez libérer.
maxnames
Spécifie le nombre maximum de noms à retourner.
names
Spécifie la liste des noms de polices.
pattern
Spécifie la chaîne de motif terminée par null qui peut contenir des caractères génériques.

DESCRIPTION

La fonction XListFonts retourne un tableau de noms de polices disponibles (tel que contrôlé par le chemin de recherche des polices ; voir XSetFontPath) qui correspondent à la chaîne que vous avez passée à l'argument pattern. La chaîne de motif peut contenir n'importe quels caractères, mais chaque astérisque (*) est un caractère générique pour n'importe quel nombre de caractères, et chaque point d'interrogation (?) est un caractère générique pour un seul caractère. Si la chaîne de motif n'est pas dans l'encodage de caractères portable de l'hôte (Host Portable Character Encoding), le résultat dépend de l'implémentation. L'utilisation de majuscules ou de minuscules n'a pas d'importance. Chaque chaîne retournée est terminée par null. Si les données retournées par le serveur sont dans l'encodage de caractères portable Latin (Latin Portable Character Encoding), alors les chaînes retournées sont dans l'encodage de caractères portable de l'hôte. Sinon, le résultat dépend de l'implémentation. S'il n'y a pas de noms de polices correspondants, XListFonts retourne NULL. Le client doit appeler XFreeFontNames lorsqu'il a fini avec le résultat pour libérer la mémoire.

La fonction XFreeFontNames libère le tableau et les chaînes retournés par XListFonts ou XListFontsWithInfo.

La fonction XListFontsWithInfo retourne une liste de noms de polices qui correspondent au motif spécifié et leurs informations de police associées. La liste des noms est limitée à la taille spécifiée par maxnames. Les informations retournées pour chaque police sont identiques à ce que XLoadQueryFont retournerait, sauf que les métriques par caractère ne sont pas retournées. La chaîne de motif peut contenir n'importe quels caractères, mais chaque astérisque (*) est un caractère générique pour n'importe quel nombre de caractères, et chaque point d'interrogation (?) est un caractère générique pour un seul caractère. Si la chaîne de motif n'est pas dans l'encodage de caractères portable de l'hôte (Host Portable Character Encoding), le résultat dépend de l'implémentation. L'utilisation de majuscules ou de minuscules n'a pas d'importance. Chaque chaîne retournée est terminée par null. Si les données retournées par le serveur sont dans l'encodage de caractères portable Latin (Latin Portable Character Encoding), alors les chaînes retournées sont dans l'encodage de caractères portable de l'hôte. Sinon, le résultat dépend de l'implémentation. S'il n'y a pas de noms de polices correspondants, XListFontsWithInfo retourne NULL.

Pour libérer uniquement le tableau de noms alloué, le client doit appeler XFreeFontNames. Pour libérer à la fois le tableau de noms et le tableau d'informations de polices, ou pour libérer uniquement le tableau d'informations de polices, le client doit appeler XFreeFontInfo.

La fonction XFreeFontInfo libère une structure de police ou un tableau de structures de polices et éventuellement un tableau de noms de polices. Si NULL est passé pour names, aucun nom de police n'est libéré. Si une structure de police pour une police ouverte (retournée par XLoadQueryFont) est passée, la structure est libérée, mais la police n'est pas fermée ; utilisez XUnloadFont pour fermer la police.

Notez que XListFontsWithInfo n'est pas thread-safe. Si d'autres threads effectuent des requêtes X sur le même Display, le comportement de cette fonction est indéfini.
