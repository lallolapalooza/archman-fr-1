DESCRIPTION

La macro AllPlanes renvoie une valeur avec tous les bits mis à 1, adaptée à une utilisation dans un argument de plan pour une procédure.

La macro BlackPixel renvoie la valeur du pixel noir pour l'écran spécifié.

La macro WhitePixel renvoie la valeur du pixel blanc pour l'écran spécifié.

La macro ConnectionNumber renvoie un numéro de connexion pour l'affichage spécifié.

La macro DefaultColormap renvoie l'ID de la carte des couleurs par défaut pour l'allocation sur l'écran spécifié.

La macro DefaultDepth renvoie la profondeur (nombre de plans) de la fenêtre racine par défaut pour l'écran spécifié.

La fonction XListDepths renvoie le tableau des profondeurs disponibles sur l'écran spécifié. Si le numéro d'écran spécifié est valide et que suffisamment de mémoire peut être allouée pour le tableau, XListDepths définit count_return au nombre de profondeurs disponibles. Sinon, il ne définit pas count_return et renvoie NULL. Pour libérer la mémoire allouée pour le tableau des profondeurs, utilisez XFree.

La macro DefaultGC renvoie le GC par défaut pour la fenêtre racine de l'écran spécifié.

La macro DefaultRootWindow renvoie la fenêtre racine pour l'écran par défaut.

La macro DefaultScreenOfDisplay renvoie l'écran par défaut de l'affichage spécifié.

La macro DefaultScreen renvoie le numéro d'écran par défaut référencé dans la routine XOpenDisplay.

La macro DefaultVisual renvoie le type visuel par défaut pour l'écran spécifié.

La macro DisplayCells renvoie le nombre d'entrées dans la carte des couleurs par défaut.

La macro DisplayPlanes renvoie la profondeur de la fenêtre racine de l'écran spécifié.

La macro DisplayString renvoie la chaîne qui a été passée à XOpenDisplay lors de l'ouverture de l'affichage actuel.

La fonction XMaxRequestSize renvoie la taille maximale de la requête (en unités de 4 octets) prise en charge par le serveur sans utiliser un encodage de protocole de longueur étendue. Les requêtes de protocole uniques vers le serveur ne peuvent pas dépasser cette taille, sauf si un encodage de protocole de longueur étendue est pris en charge par le serveur. Le protocole garantit que la taille n'est pas inférieure à 4096 unités (16384 octets). Xlib divise automatiquement les données en plusieurs requêtes de protocole si nécessaire pour les fonctions suivantes : XDrawPoints, XDrawRectangles, XDrawSegments, XFillArcs, XFillRectangles et XPutImage.

La fonction XExtendedMaxRequestSize renvoie zéro si l'affichage spécifié ne prend pas en charge un encodage de protocole de longueur étendue ; sinon, elle renvoie la taille maximale de la requête (en unités de 4 octets) prise en charge par le serveur en utilisant l'encodage de longueur étendue. Les fonctions Xlib XDrawLines, XDrawArcs, XFillPolygon, XChangeProperty, XSetClipRectangles et XSetRegion utiliseront l'encodage de longueur étendue si nécessaire, s'il est pris en charge par le serveur. L'utilisation de l'encodage de longueur étendue dans d'autres fonctions Xlib (par exemple, XDrawPoints, XDrawRectangles, XDrawSegments, XFillArcs, XFillRectangles, XPutImage) est autorisée mais pas obligatoire ; une implémentation Xlib peut choisir de diviser les données en plusieurs requêtes plus petites à la place.

La macro LastKnownRequestProcessed extrait le numéro de série complet de la dernière requête dont Xlib sait qu'elle a été traitée par le serveur X.

La macro NextRequest extrait le numéro de série complet qui sera utilisé pour la prochaine requête.

La macro ProtocolVersion renvoie le numéro de version majeur (11) du protocole X associé à l'affichage connecté.

La macro ProtocolRevision renvoie le numéro de révision mineur du protocole du serveur X.

La macro QLength renvoie la longueur de la file d'attente des événements pour l'affichage connecté.

La macro RootWindow renvoie la fenêtre racine.

La macro ScreenCount renvoie le nombre d'écrans disponibles.

La macro ScreenOfDisplay renvoie un pointeur vers l'écran de l'affichage spécifié.

La macro ServerVendor renvoie un pointeur vers une chaîne terminée par un octet nul qui fournit une identification du propriétaire de l'implémentation du serveur X.

La macro VendorRelease renvoie un numéro lié à une version du fournisseur du serveur X.

NOM

XExtendedMaxRequestSize - Obtenir la taille maximale des requêtes étendues.

SYNTAXE

int XExtendedMaxRequestSize(Display *display, int *major_opcode_return, int *minor_opcode_return, unsigned int *max_request_size_return);

ARGUMENTS

  • display : Spécifie la connexion au serveur X.
  • major_opcode_return : Retourne le code d'opération majeur pour les requêtes étendues.
  • minor_opcode_return : Retourne le code d'opération mineur pour les requêtes étendues.
  • max_request_size_return : Retourne la taille maximale des requêtes étendues, en octets.

DESCRIPTION

La fonction XExtendedMaxRequestSize récupère les informations relatives aux requêtes étendues du serveur X. Elle renvoie le code d'opération majeur et mineur, ainsi que la taille maximale en octets qu'une requête étendue peut avoir.

La taille maximale de la requête est importante pour savoir si une application peut envoyer des données volumineuses au serveur via des requêtes étendues. Si la taille des données à envoyer dépasse la taille maximale autorisée, l'application devra diviser les données en plusieurs requêtes plus petites.

Cette fonction est particulièrement utile pour les extensions du protocole X qui nécessitent le transfert de quantités importantes de données.
