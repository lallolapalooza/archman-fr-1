NOM

XErrorEvent - structure d'événement d'erreur X

STRUCTURES

La structure XErrorEvent contient :

typedef struct {
        int type;
        Display *display;       /* Display à partir duquel l'événement a été lu */
        XID resourceid;         /* ID de ressource */
        unsigned long serial;           /* numéro de série de la requête échouée */
        unsigned char error_code;       /* code d'erreur de la requête échouée */
        unsigned char request_code;     /* Op-code majeur de la requête échouée */
        unsigned char minor_code;       /* Op-code mineur de la requête échouée */
} XErrorEvent;

Lorsque vous recevez cet événement, les membres de la structure sont définis comme suit.

Le membre serial est le numéro des requêtes, commençant à un, envoyées sur la connexion réseau depuis son ouverture. C'est le numéro qui était la valeur de NextRequest immédiatement avant que l'appel échoué ne soit fait. Le membre request_code est une requête de protocole de la procédure qui a échoué, telle que définie dans X11/Xproto.h.
