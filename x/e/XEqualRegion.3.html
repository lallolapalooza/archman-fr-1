XEmptyRegion(3) FONCTIONS XLIB XEmptyRegion(3)

NOM

XEmptyRegion, XEqualRegion, XPointInRegion, XRectInRegion - déterminer si des régions sont vides ou égales

SYNTAXE

Bool XEmptyRegion(Region r);

Bool XEqualRegion(Region r1, Region r2);

Bool XPointInRegion(Region r, int x, int y);

int XRectInRegion(Region r, int x, int y, unsigned int width, unsigned int height);

ARGUMENTS

r
Spécifie la région.
r1

r2
Spécifient les deux régions.
width

height
Spécifient la largeur et la hauteur, qui définissent le rectangle.
x

y
Spécifient les coordonnées x et y, qui définissent le point ou les coordonnées du coin supérieur gauche du rectangle.

DESCRIPTION

La fonction XEmptyRegion retourne True si la région est vide.

La fonction XEqualRegion retourne True si les deux régions ont le même décalage, la même taille et la même forme.

La fonction XPointInRegion retourne True si le point (x, y) est contenu dans la région r.

La fonction XRectInRegion retourne RectangleIn si le rectangle est entièrement dans la région spécifiée, RectangleOut si le rectangle est entièrement hors de la région spécifiée, et RectanglePart si le rectangle est partiellement dans la région spécifiée.
