NOM

XExposeEvent - structure d'événement Expose

STRUCTURES

La structure pour les événements Expose contient :

typedef struct {
        int type;       /* Expose */
        unsigned long serial;   /* # de la dernière requête traitée par le serveur */
        Bool send_event;        /* vrai si ceci provient d'une requête SendEvent */
        Display *display;       /* Display à partir duquel l'événement a été lu */
        Window window;
        int x, y;
        int width, height;
        int count;      /* si non nul, au moins autant d'autres suivront */
} XExposeEvent;

Lorsque vous recevez cet événement, les membres de la structure sont définis comme suit.

Le membre type est défini sur le nom de la constante d'événement qui l'identifie de manière unique. Par exemple, lorsque le serveur X signale un événement GraphicsExpose à une application cliente, il envoie une structure XGraphicsExposeEvent avec le membre type défini sur GraphicsExpose. Le membre display est défini sur un pointeur vers le display sur lequel l'événement a été lu. Le membre send_event est défini sur True si l'événement provient d'une requête de protocole SendEvent. Le membre serial est défini à partir du numéro de série rapporté dans le protocole, mais étendu des 16 bits les moins significatifs à une valeur complète de 32 bits. Le membre window est défini sur la fenêtre qui est la plus utile pour les répartiteurs de toolkit.

Le membre window est défini sur la fenêtre exposée (endommagée). Les membres x et y sont définis sur les coordonnées relatives à l'origine de la fenêtre et indiquent le coin supérieur gauche du rectangle. Les membres width et height sont définis sur la taille (étendue) du rectangle. Le membre count est défini sur le nombre d'événements Expose qui suivront. Si count est nul, aucun autre événement Expose ne suit pour cette fenêtre. Cependant, si count est non nul, au moins ce nombre d'événements Expose (et potentiellement plus) suit pour cette fenêtre. Les applications simples qui ne veulent pas optimiser le redessin en distinguant les sous-zones de leur fenêtre peuvent simplement ignorer tous les événements Expose avec des décomptes non nuls et effectuer des redessins complets sur les événements avec des décomptes nuls.
