ARGUMENTS

display
Spécifie la connexion au serveur X.
screen
Spécifie quel numéro d'écran est concerné par le réglage.
event_base_return
Retourne le numéro de base de l'événement pour l'extension.
error_base_return
Retourne le numéro de base de l'erreur pour l'extension.
major_version_return
Retourne le numéro de version majeure de l'extension.
minor_version_return
Retourne le numéro de version mineure de l'extension.
dotclock_return
Retourne l'horloge pour la ligne de mode.
modecount_return
Retourne le nombre de modes vidéo disponibles dans le serveur.
zoom
Si supérieur à zéro, indique que le serveur doit passer au mode suivant, sinon il doit passer au mode précédent.
lock
Indique que le changement de mode doit être verrouillé, si non nul.
modeline
Spécifie ou retourne les valeurs de synchronisation pour un mode vidéo.
aftermode
Spécifie les valeurs de synchronisation du mode vidéo après lequel le nouveau mode sera ajouté.
modesinfo
Retourne les valeurs de synchronisation et les fréquences d'horloge pour tous les modes vidéo disponibles.
monitor
Retourne des informations sur le moniteur.
x
Spécifie la position X désirée pour la fenêtre d'affichage.
x_return
Retourne la position X actuelle de la fenêtre d'affichage.
y
Spécifie la position Y désirée pour la fenêtre d'affichage.
y_return
Retourne la position Y actuelle de la fenêtre d'affichage.

DESCRIPTION

The VidMode extension provides a mechanism for applications to query and control the video modes of a monitor. This library provides functions to interact with the extension.

Note: The VidMode extension is deprecated. Use the RandR extension instead.

The functions are:

XF86VidModeQueryExtension
XF86VidModeQueryVersion
Queries the version of the VidMode extension available on the server.
XF86VidModeSetClientVersion
Sets the client's version of the VidMode extension. This should be called after querying the version.
XF86VidModeGetModeLine
Retrieves the current mode line for the specified screen.
XF86VidModeGetAllModeLines
Retrieves all available mode lines for the specified screen.
XF86VidModeAddModeLine
Adds a new mode line to the server's list of available modes.
XF86VidModeDeleteModeLine
Deletes a mode line from the server's list of available modes.
XF86VidModeModModeLine
Modifies an existing mode line.
XF86VidModeValidateModeLine
Validates a mode line to see if it is supported by the server.
XF86VidModeSwitchMode
Switches to the next or previous video mode.
XF86VidModeSwitchToMode
Switches to the specified video mode.
XF86VidModeLockModeSwitch
Locks or unlocks mode switching.
XF86VidModeGetMonitor
Retrieves information about the connected monitor.
XF86VidModeGetViewPort
Retrieves the current viewport location.
XF86VidModeSetViewPort
Sets the viewport location.
XF86VidModeGetDotClocks
Retrieves information about the available dot clocks for the screen.
XF86VidModeGetGamma
Retrieves the current gamma settings.
XF86VidModeSetGamma
Sets the gamma settings.
XF86VidModeGetGammaRamp
Retrieves the current gamma ramp.
XF86VidModeSetGammaRamp
Sets the gamma ramp.
XF86VidModeGetGammaRampSize
Retrieves the size of the gamma ramp.
XF86VidModeGetPermissions
Checks if the client has permission to modify video modes.

DESCRIPTION

Ces fonctions fournissent une interface à l'extension serveur XFree86-VidModeExtension qui permet de consulter et d'ajuster dynamiquement les modes vidéo et de contrôler la commutation de modes. Les applications qui utilisent ces fonctions doivent être liées avec -lXxf86vm

FONCTIONS MODELINE

La fonction XF86VidModeGetModeLine est utilisée pour interroger les paramètres du mode vidéo actuellement sélectionné. Le programme appelant doit passer un pointeur vers une structure XF86VidModeModeLine qu'il a déjà allouée. La fonction remplit les champs de la structure.

S'il existe des valeurs privées du serveur (actuellement uniquement applicables au serveur S3), la fonction allouera du stockage pour celles-ci. Par conséquent, si le champ privsize n'est pas zéro, le programme appelant doit appeler Xfree(private) pour libérer le stockage.

XF86VidModeGetAllModeLines renvoie les paramètres de tous les modes vidéo. Le programme appelant fournit l'adresse d'un pointeur qui sera défini par la fonction pour pointer vers un tableau de structures XF86VidModeModeInfo. La mémoire occupée par le tableau est allouée dynamiquement par la fonction XF86VidModeGetAllModeLines et doit être libérée par l'appelant. Le premier élément du tableau correspond au mode vidéo actuel.

La fonction XF86VidModeModModeLine peut être utilisée pour modifier les paramètres du mode vidéo actuel, à condition que les paramètres demandés soient valides (par exemple, qu'ils ne dépassent pas les capacités du moniteur).

Pour ajouter un mode à la liste des modes disponibles, la fonction XF86VidModeAddModeLine peut être utilisée. En supposant que les paramètres sont valides, le mode vidéo sera ajouté après le mode existant qui correspond aux cadences spécifiées par le paramètre aftermode. Pour être considéré comme une correspondance, tous les champs de la structure XF86VidModeModeInfo donnée doivent correspondre, à l'exception des champs privsize et private. Si le paramètre aftermode est zéro, le mode sera ajouté après le mode actuel.

Les modes peuvent être supprimés avec la fonction XF86VidModeDeleteModeLine. Le mode spécifié doit correspondre à un mode existant. Pour être considéré comme une correspondance, tous les champs de la structure XF86VidModeModeInfo donnée doivent correspondre, à l'exception des champs privsize et private. Si le mode à supprimer est le mode actuel, une commutation de mode vers le mode suivant se produira d'abord. Le dernier mode restant ne peut pas être supprimé.

La validité d'un mode peut être vérifiée avec la fonction XF86VidModeValidateModeLine. Si le mode spécifié peut être utilisé par le serveur (c'est-à-dire qu'il respecte toutes les contraintes imposées à un mode par la combinaison du serveur, de la carte et du moniteur), la fonction renvoie MODE_OK, sinon elle renvoie une valeur indiquant la raison pour laquelle le mode est invalide (telle que définie dans xf86.h)

FONCTIONS DE COMMUTATION DE MODE

Lorsque la fonction XF86VidModeSwitchMode est appelée, le serveur change le mode vidéo vers le mode vidéo suivant (ou précédent). La fonction XF86VidModeSwitchToMode peut être utilisée pour passer directement au mode spécifié. La correspondance est telle que spécifiée dans la description de la fonction XF86VidModeAddModeLine ci-dessus. La fonction XF86VidModeLockModeSwitch peut être utilisée pour autoriser ou refuser la commutation de mode, que la demande de commutation de mode provienne d'un appel aux fonctions XF86VidModeSwitchMode ou XF86VidModeSwitchToMode, ou de l'une des séquences de touches de commutation de mode.

Note : En raison de la nature asynchrone du protocole X, un appel à XFlush est nécessaire si l'application souhaite voir le changement de mode immédiatement. Pour être informé de l'état d'exécution de la demande, un gestionnaire d'erreurs personnalisé doit être installé en utilisant XSetErrorHandler avant d'appeler la fonction de commutation de mode.

FONCTIONS MONITEUR

Les informations connues du serveur sur le moniteur sont renvoyées par la fonction XF86VidModeGetMonitor. Les champs hsync et vsync pointent chacun vers un tableau de structures XF86VidModeSyncRange. Les tableaux contiennent respectivement nhsync et nvsync éléments. Les valeurs hi et low seront égales si une valeur discrète a été donnée dans le fichier XF86Config.

Les champs vendor, model, hsync et vsync pointent vers un stockage alloué dynamiquement qui doit être libéré par l'appelant.

FONCTIONS DE VUE

Les fonctions XF86VidModeGetViewPort et XF86VidModeSetViewPort peuvent être utilisées pour interroger et modifier, respectivement, la position du coin supérieur gauche de la vue dans l'écran virtuel.

AUTRES FONCTIONS

La fonction XF86VidModeQueryVersion peut être utilisée pour déterminer la version de l'extension intégrée au serveur.

La fonction XF86VidModeQueryExtension renvoie les valeurs d'erreur et d'événement les plus basses attribuées à l'extension.

BOGUES

Les fonctions XF86VidModeSetClientVersion, XF86VidModeGetDotClocks, XF86VidModeGetGamma, XF86VidModeSetGamma, XF86VidModeSetGammaRamp, XF86VidModeGetGammaRamp, XF86VidModeGetGammaRampSize et XF86VidModeGetPermissions doivent être documentées. En attendant, consultez le code source pour savoir comment les utiliser.
