XCreateFontSet(3) FONCTIONS XLIB XCreateFontSet(3)

NOM

XCreateFontSet, XFreeFontSet - créer et libérer un ensemble de polices pour le dessin de texte international

SYNTAXE

XFontSet XCreateFontSet(Display *display, _Xconst char *base_font_name_list, char ***missing_charset_list_return, int *missing_charset_count_return, char **def_string_return);

void XFreeFontSet(Display *display, XFontSet font_set);

ARGUMENTS

display
Spécifie la connexion au serveur X.
base_font_name_list
Spécifie la liste des noms de polices de base.
def_string_return
Retourne la chaîne de caractères dessinée pour les jeux de caractères manquants.
font_set
Spécifie l'ensemble de polices.
missing_charset_count_return
Retourne le nombre de jeux de caractères manquants.
missing_charset_list_return
Retourne les jeux de caractères manquants.

DESCRIPTION

La fonction XCreateFontSet crée un ensemble de polices pour l'affichage spécifié. L'ensemble de polices est lié à la locale courante lors de l'appel à XCreateFontSet. L'ensemble de polices peut être utilisé dans des appels ultérieurs pour obtenir des informations sur les polices et les caractères, et pour afficher du texte dans la locale de l'ensemble de polices.

L'argument base_font_name_list est une liste de noms de polices de base que Xlib utilise pour charger les polices nécessaires à la locale. Les noms de polices de base sont une liste séparée par des virgules. La chaîne est terminée par un caractère nul et est supposée être dans le jeu de caractères portables de l'hôte ; sinon, le résultat dépend de l'implémentation. Les espaces immédiatement de chaque côté d'une virgule séparatrice sont ignorés.

L'utilisation des noms de polices XLFD permet à Xlib d'obtenir les polices nécessaires à une variété de locales à partir d'un seul nom de police de base indépendant de la locale. Le nom de police de base unique doit nommer une famille de polices dont les membres sont codés dans les divers jeux de caractères requis par les locales d'intérêt.

Un nom de police de base XLFD peut nommer explicitement un jeu de caractères requis pour la locale. Cela permet à l'utilisateur de spécifier une police exacte à utiliser avec un jeu de caractères requis par une locale, contrôlant ainsi entièrement la sélection de la police.

Si un nom de police de base n'est pas un nom XLFD, Xlib tentera d'obtenir un nom XLFD à partir des propriétés de la police. Si cette action réussit à obtenir un nom XLFD, la fonction XBaseFontNameListOfFontSet retournera ce nom XLFD au lieu du nom fourni par le client.

Xlib utilise l'algorithme suivant pour sélectionner les polices qui seront utilisées pour afficher du texte avec le XFontSet.

Pour chaque jeu de caractères requis par la locale, la liste des noms de polices de base est recherchée pour la première apparition de l'un des cas suivants qui nomme un ensemble de polices existant sur le serveur :

  • Le premier nom de police de base conforme à XLFD qui spécifie le jeu de caractères requis ou un sur-ensemble du jeu de caractères requis dans ses champs CharSetRegistry et CharSetEncoding. L'implémentation peut utiliser un nom de police de base dont le jeu de caractères spécifié est un sur-ensemble du jeu de caractères requis, par exemple, une police ISO8859-1 pour un jeu de caractères ASCII.
  • Le premier ensemble d'un ou plusieurs noms de polices de base conformes à XLFD qui spécifient un ou plusieurs jeux de caractères pouvant être remappés pour prendre en charge le jeu de caractères requis. L'implémentation Xlib peut reconnaître divers mappages d'un jeu de caractères requis vers un ou plusieurs autres jeux de caractères et utiliser les polices de ces jeux de caractères. Par exemple, JIS Roman est ASCII avec tilde et antislash remplacés par yen et barre supérieure ; Xlib peut charger une police ISO8859-1 pour prendre en charge ce jeu de caractères si une police JIS Roman n'est pas disponible.
  • Le premier nom de police XLFD ou le premier nom de police non-XLFD pour lequel un nom de police XLFD peut être obtenu, combiné avec le jeu de caractères requis (remplaçant les champs CharSetRegistry et CharSetEncoding dans le nom de police XLFD). Comme au cas 1, l'implémentation peut utiliser un jeu de caractères qui est un sur-ensemble du jeu de caractères requis.
  • Le premier nom de police qui peut être mappé d'une manière dépendant de l'implémentation vers une ou plusieurs polices prenant en charge le dessin de texte dans le jeu de caractères.

Par exemple, supposons qu'une locale ait requis les jeux de caractères :

ISO8859-1
JISX0208.1983
JISX0201.1976
GB2312-1980.0

L'utilisateur pourrait fournir une base_font_name_list qui spécifie explicitement les jeux de caractères, garantissant que des polices spécifiques sont utilisées si elles existent. Par exemple :

"-JIS-Fixed-Medium-R-Normal--26-180-100-100-C-240-JISX0208.1983-0,\
-JIS-Fixed-Medium-R-Normal--26-180-100-100-C-120-JISX0201.1976-0,\
-GB-Fixed-Medium-R-Normal--26-180-100-100-C-240-GB2312-1980.0,\
-Adobe-Courier-Bold-R-Normal--25-180-150-75-M-150-ISO8859-1"

Alternativement, l'utilisateur pourrait fournir une base_font_name_list qui omet les jeux de caractères, laissant Xlib sélectionner les jeux de caractères requis pour la locale. Par exemple :

"-JIS-Fixed-Medium-R-Normal--26-180-100-100-C-240,\
-JIS-Fixed-Medium-R-Normal--26-180-100-100-C-120,\
-GB-Fixed-Medium-R-Normal--26-180-100-100-C-240,\
-Adobe-Courier-Bold-R-Normal--25-180-100-100-M-150"

Alternativement, l'utilisateur pourrait simplement fournir un nom de police de base unique qui permet à Xlib de sélectionner parmi toutes les polices disponibles répondant à certaines exigences minimales de propriétés XLFD. Par exemple :

"-*-*-*-R-Normal--*-180-100-100-*-*"

Si XCreateFontSet ne parvient pas à créer l'ensemble de polices, soit parce qu'il n'y a pas assez de mémoire, soit parce que la locale courante n'est pas prise en charge, XCreateFontSet retourne NULL, missing_charset_list_return est mis à NULL, et missing_charset_count_return est mis à zéro. Si des polices existent pour tous les jeux de caractères requis par la locale courante, XCreateFontSet retourne un XFontSet valide, missing_charset_list_return est mis à NULL, et missing_charset_count_return est mis à zéro.

Si aucune police n'existe pour un ou plusieurs des jeux de caractères requis, XCreateFontSet met missing_charset_list_return à une liste d'un ou plusieurs noms de jeux de caractères terminés par un caractère nul pour lesquels aucune police n'existe, et met missing_charset_count_return au nombre de polices manquantes. Les jeux de caractères proviennent de la liste des jeux de caractères requis pour le codage de la locale et n'incluent aucun jeu de caractères auquel Xlib pourrait remapper un jeu de caractères requis.

Si aucune police n'existe pour l'un des jeux de caractères requis ou si la définition de locale dans Xlib exige qu'une police existe pour un jeu de caractères particulier et qu'aucune police n'est trouvée pour ce jeu de caractères, XCreateFontSet retourne NULL. Sinon, XCreateFontSet retourne un XFontSet valide à font_set.

Lorsqu'une fonction de dessin ou de mesure Xmb/wc est appelée avec un XFontSet qui a des jeux de caractères manquants, certains caractères dans la locale ne seront pas dessinables. Si def_string_return n'est pas NULL, XCreateFontSet retourne un pointeur vers une chaîne qui représente les glyphes qui sont dessinés avec cet XFontSet lorsque les jeux de caractères des polices disponibles n'incluent pas tous les glyphes de police requis pour dessiner un point de code. La chaîne ne consiste pas nécessairement en caractères valides dans la locale courante et n'est pas nécessairement dessinée avec les polices chargées pour l'ensemble de polices, mais le client peut dessiner et mesurer les glyphes par défaut en incluant cette chaîne dans une chaîne en cours de dessin ou de mesure avec le XFontSet.

Si la chaîne retournée à def_string_return est la chaîne vide (""), aucun glyphe n'est dessiné, et l'échappement est zéro. La chaîne retournée est terminée par un caractère nul. Elle appartient à Xlib et ne doit pas être modifiée ou libérée par le client. Elle sera libérée par un appel à XFreeFontSet avec le XFontSet associé. Tant qu'elle n'est pas libérée, son contenu ne sera pas modifié par Xlib.

Le client est responsable de la construction d'un message d'erreur à partir des informations sur les jeux de caractères manquants et la chaîne par défaut, et peut choisir de continuer l'opération dans le cas où certaines polices n'existaient pas.

L' XFontSet retourné et la liste des jeux de caractères manquants doivent être libérés avec XFreeFontSet et XFreeStringList, respectivement. La base_font_name_list fournie par le client peut être libérée par le client après l'appel à XCreateFontSet.

La fonction XFreeFontSet libère l'ensemble de polices spécifié. La liste des noms de polices de base associés, la liste des noms de polices, la liste XFontStruct et XFontSetExtents, le cas échéant, sont libérés.
