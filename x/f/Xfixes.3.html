NOM

XFixes - Versions augmentées des requêtes du protocole de base

SYNTAXE

#include <X11/extensions/Xfixes.h>

Bool XFixesQueryExtension (Display *dpy,
	int *event_base_return, int *error_base_return);

Status XFixesQueryVersion (Display *dpy,
	int *major_version_return,
	int *minor_version_return);

void XFixesChangeSaveSet (Display *dpy,
	Window window,
	int mode,
	int target,
	int map);

ARGUMENTS

display
Spécifie la connexion au serveur X.
window
Spécifie quelle fenêtre.
mode
Spécifie l'opération sur le jeu de sauvegarde (SetModeInsert/SetModeDelete).
target
Spécifie la cible lors de l'exécution du jeu de sauvegarde (SaveSetNearest/SaveSetRoot). En mode SaveSetNearest, la fenêtre membre du jeu de sauvegarde sera reparentée à la fenêtre la plus proche non possédée par le client du jeu de sauvegarde. En mode SaveSetRoot, la fenêtre membre du jeu de sauvegarde sera reparentée à la fenêtre racine.
map
Spécifie le mode de mappage (SaveSetMap/SaveSetUnmap) qui sélecte si la fenêtre membre du jeu de sauvegarde sera mappée ou démappée pendant le traitement du jeu de sauvegarde.

DESCRIPTION

Xfixes est une bibliothèque simple conçue pour interagir avec l'extension X Fixes. Cette extension fournit aux applications des solutions de contournement pour diverses limitations du protocole de base.

RESTRICTIONS

Xfixes restera compatible avec les versions antérieures après la publication de la version 1.0.
