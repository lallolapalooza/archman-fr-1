XFreeCursor(3)

Paquet: libx11

Licences: MIT AND X11

XRecolorCursor(3) FONCTIONS XLIB XRecolorCursor(3)

NOM

XRecolorCursor, XFreeCursor, XQueryBestCursor - manipuler les curseurs

SYNTAXE

int XRecolorCursor(Display *display, Cursor cursor, XColor *foreground_color, XColor *background_color);

int XFreeCursor(Display *display, Cursor cursor);

Status XQueryBestCursor(Display *display, Drawable d, unsigned int width, unsigned int height, unsigned int *width_return, unsigned int *height_return);

ARGUMENTS

background_color
Spécifie les valeurs RVB pour l'arrière-plan de la source.
cursor
Spécifie le curseur.
d
Spécifie l'élément dessinable, qui indique l'écran.
display
Spécifie la connexion au serveur X.
foreground_color
Spécifie les valeurs RVB pour l'avant-plan de la source.
width

height
Spécifie la largeur et la hauteur du curseur pour lesquelles vous souhaitez des informations de taille.
width_return

height_return
Retourne la meilleure largeur et hauteur qui se rapproche le plus de la largeur et de la hauteur spécifiées.

DESCRIPTION

La fonction XRecolorCursor modifie la couleur du curseur spécifié, et si le curseur est affiché sur un écran, le changement est immédiatement visible. Les membres pixel des structures XColor sont ignorés ; seules les valeurs RVB sont utilisées.

XRecolorCursor peut générer une erreur BadCursor.

La fonction XFreeCursor supprime l'association entre l'identifiant de ressource du curseur et le curseur spécifié. Le stockage du curseur est libéré lorsqu'aucune autre ressource ne le référence. L'identifiant de curseur spécifié ne doit plus être référencé.

XFreeCursor peut générer une erreur BadCursor.

Certains affichages autorisent des curseurs plus grands que d'autres. La fonction XQueryBestCursor permet de savoir quelles tailles de curseurs sont réellement possibles sur l'affichage. Elle retourne la plus grande taille qui peut être affichée. Les applications doivent être préparées à utiliser des curseurs plus petits sur les affichages qui ne peuvent pas supporter de grands curseurs.

XQueryBestCursor peut générer une erreur BadDrawable.

DIAGNOSTICS

BadCursor
Une valeur pour un argument Cursor ne nomme pas un curseur défini.
BadDrawable
Une valeur pour un argument Drawable ne nomme pas une Fenêtre ou une Pixmap définie.
