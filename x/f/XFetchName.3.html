Paquet: libx11

Licences: MIT AND X11

XSetWMName(3) FONCTIONS XLIB XSetWMName(3)

NOM

XSetWMName, XGetWMName, XStoreName, XFetchName - définir ou lire la propriété WM_NAME d'une fenêtre

SYNTAXE

void XSetWMName(Display *display, Window w, XTextProperty *text_prop);

Status XGetWMName(Display *display, Window w, XTextProperty *text_prop_return);

int XStoreName(Display *display, Window w, _Xconst char *window_name);

Status XFetchName(Display *display, Window w, char **window_name_return);

ARGUMENTS

display
Spécifie la connexion au serveur X.
text_prop
Spécifie la structure XTextProperty à utiliser.
text_prop_return
Retourne la structure XTextProperty.
w
Spécifie la fenêtre.
window_name
Spécifie le nom de la fenêtre, qui doit être une chaîne terminée par un caractère nul.
window_name_return
Retourne le nom de la fenêtre, qui est une chaîne terminée par un caractère nul.

DESCRIPTION

La fonction utilitaire XSetWMName appelle XSetTextProperty pour définir la propriété WM_NAME.

La fonction utilitaire XGetWMName appelle XGetTextProperty pour obtenir la propriété WM_NAME. Elle retourne un statut non nul en cas de succès ; sinon, elle retourne un statut nul.

La fonction XStoreName assigne le nom passé à window_name à la fenêtre spécifiée. Un gestionnaire de fenêtres peut afficher le nom de la fenêtre dans un endroit visible, comme la barre de titre, pour permettre aux utilisateurs d'identifier facilement les fenêtres. Certains gestionnaires de fenêtres peuvent afficher le nom d'une fenêtre dans son icône, bien qu'ils soient encouragés à utiliser le nom d'icône de la fenêtre s'il est fourni par l'application. Si la chaîne n'est pas dans le jeu de caractères portable hôte (Host Portable Character Encoding), le résultat est dépendant de l'implémentation.

XStoreName peut générer des erreurs BadAlloc et BadWindow.

La fonction XFetchName retourne le nom de la fenêtre spécifiée. Si elle réussit, elle retourne un statut non nul ; sinon, aucun nom n'a été défini pour la fenêtre, et elle retourne zéro. Si la propriété WM_NAME n'a pas été définie pour cette fenêtre, XFetchName définit window_name_return à NULL. Si les données retournées par le serveur sont dans le jeu de caractères portable Latin (Latin Portable Character Encoding), alors la chaîne retournée est dans le jeu de caractères portable hôte. Sinon, le résultat est dépendant de l'implémentation. Une fois terminé avec, un client doit libérer la chaîne du nom de la fenêtre en utilisant XFree.

XFetchName peut générer une erreur BadWindow.

PROPRIÉTÉS

WM_NAME
Le nom de l'application.

DIAGNOSTICS

BadAlloc
Le serveur n'a pas pu allouer la ressource demandée ou la mémoire du serveur.
BadWindow
Une valeur pour un argument de fenêtre ne nomme pas une fenêtre définie.
