XStoreBytes(3) FONCTIONS XLIB XStoreBytes(3)

NOM

XStoreBytes, XStoreBuffer, XFetchBytes, XFetchBuffer, XRotateBuffers - manipuler les tampons de copie et de collage

SYNTAXE

int XStoreBytes(Display *display, _Xconst char *bytes, int nbytes);

int XStoreBuffer(Display *display, _Xconst char *bytes, int nbytes, int buffer);

char *XFetchBytes(Display *display, int *nbytes_return);

char *XFetchBuffer(Display *display, int *nbytes_return, int buffer);

int XRotateBuffers(Display *display, int rotate);

ARGUMENTS

buffer
Spécifie le tampon dans lequel vous souhaitez stocker les octets ou à partir duquel vous souhaitez récupérer les données stockées.
bytes
Spécifie les octets, qui ne sont pas nécessairement ASCII ou terminés par null.
display
Spécifie la connexion au serveur X.
nbytes
Spécifie le nombre d'octets à stocker.
nbytes_return
Retourne le nombre d'octets dans le tampon.
rotate
Spécifie de combien faire pivoter les tampons de copie.

DESCRIPTION

Les données peuvent contenir des caractères nuls intégrés et ne nécessitent pas d'être terminées par null. Le contenu du tampon de copie peut être récupéré ultérieurement par n'importe quel client appelant XFetchBytes.

XStoreBytes peut générer une erreur BadAlloc.

Si un tampon invalide est spécifié, l'appel n'a aucun effet. Les données peuvent contenir des caractères nuls intégrés et ne nécessitent pas d'être terminées par null.

XStoreBuffer peut générer une erreur BadAlloc.

La fonction XFetchBytes retourne le nombre d'octets dans l'argument nbytes_return, si le tampon contient des données. Sinon, la fonction retourne NULL et définit nbytes à 0. La quantité appropriée de stockage est allouée et le pointeur est retourné. Le client doit libérer ce stockage une fois qu'il a terminé en appelant XFree.

La fonction XFetchBuffer retourne zéro à l'argument nbytes_return s'il n'y a pas de données dans le tampon ou si un tampon invalide est spécifié.

XFetchBuffer peut générer une erreur BadValue.

La fonction XRotateBuffers fait pivoter les tampons de copie, de sorte que le tampon 0 devienne le tampon n, le tampon 1 devienne n + 1 mod 8, et ainsi de suite. Cette numérotation des tampons de copie est globale pour l'affichage. Notez que XRotateBuffers génère des erreurs BadMatch si l'un des huit tampons n'a pas été créé.

XRotateBuffers peut générer une erreur BadMatch.

DIAGNOSTICS

BadAlloc
Le serveur n'a pas pu allouer la ressource demandée ou la mémoire du serveur.
BadAtom
Une valeur pour un argument Atom ne nomme pas un Atom défini.
BadMatch
Certains arguments ou paires d'arguments ont le type et la plage corrects mais ne correspondent pas d'une autre manière requise par la requête.
BadValue
Une valeur numérique tombe en dehors de la plage de valeurs acceptées par la requête. Sauf si une plage spécifique est spécifiée pour un argument, toute la plage définie par le type de l'argument est acceptée. Tout argument défini comme un ensemble d'alternatives peut générer cette erreur.
