Paquet: libx11

Licences: MIT AND X11

XQueryExtension(3) FONCTIONS X XQueryExtension(3)

NOM

XQueryExtension, XListExtensions, XFreeExtensionList - lister les extensions disponibles

SYNTAXE

Bool XQueryExtension(display, name, major_opcode_return, first_event_return, first_error_return)

char **XListExtensions(display, nextensions_return)

XFreeExtensionList(list)

ARGUMENTS

display
Spécifie la connexion au serveur X.
name
Spécifie le nom de l'extension.
major_opcode_return
Retourne l'opcode majeur.
first_event_return
Retourne le premier code d'événement, le cas échéant.
first_error_return
Retourne le premier code d'erreur, le cas échéant.
nextensions_return
Retourne le nombre d'extensions listées.
list
Spécifie la liste des noms d'extensions.

DESCRIPTION

La fonction XQueryExtension détermine si l'extension nommée est présente. Si l'extension n'est pas présente, XQueryExtension retourne False ; sinon, elle retourne True. Si l'extension est présente, XQueryExtension retourne l'opcode majeur de l'extension à major_opcode_return ; sinon, elle retourne zéro. Tout opcode mineur et les formats de requêtes sont spécifiques à l'extension. Si l'extension implique des types d'événements supplémentaires, XQueryExtension retourne le code de type d'événement de base à first_event_return ; sinon, elle retourne zéro. Le format des événements est spécifique à l'extension. Si l'extension implique des codes d'erreur supplémentaires, XQueryExtension retourne le code d'erreur de base à first_error_return ; sinon, elle retourne zéro. Le format des données supplémentaires dans les erreurs est spécifique à l'extension. Si le nom de l'extension n'est pas dans le jeu de caractères portables hôtes (Host Portable Character Encoding), le résultat est dépendant de l'implémentation. La casse est importante ; les chaînes « thing », « Thing », et « thinG » sont toutes considérées comme des noms différents.

La fonction XListExtensions retourne une liste de toutes les extensions supportées par le serveur. Si les données retournées par le serveur sont dans le jeu de caractères portables Latin (Latin Portable Character Encoding), alors les chaînes retournées sont dans le jeu de caractères portables hôtes. Autrement, le résultat est dépendant de l'implémentation.

La fonction XFreeExtensionList libère la mémoire allouée par XListExtensions.
