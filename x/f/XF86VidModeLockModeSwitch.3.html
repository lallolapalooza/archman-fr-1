display
Spécifie la connexion au serveur X.
screen
Spécifie le numéro de l'écran auquel s'appliquent les réglages.
event_base_return
Retourne le numéro de base de l'événement pour l'extension.
error_base_return
Retourne le numéro de base de l'erreur pour l'extension.
major_version_return
Retourne le numéro de version majeure de l'extension.
minor_version_return
Retourne le numéro de version mineure de l'extension.
dotclock_return
Retourne l'horloge pour la ligne de mode.
modecount_return
Retourne le nombre de modes vidéo disponibles sur le serveur.
zoom
Si supérieur à zéro, indique que le serveur doit passer au mode suivant, sinon passer au mode précédent.
lock
Indique que le changement de mode doit être verrouillé, si non nul.
modeline
Spécifie ou retourne les valeurs de synchronisation pour un mode vidéo.
aftermode
Spécifie les valeurs de synchronisation pour le mode vidéo après lequel le nouveau mode sera ajouté.
modesinfo
Retourne les valeurs de synchronisation et les fréquences d'horloge pour tous les modes vidéo disponibles.
monitor
Retourne des informations sur le moniteur.
x
Spécifie la position X souhaitée pour la zone d'affichage.
x_return
Retourne la position X actuelle de la zone d'affichage.
y
Spécifie la position Y souhaitée pour la zone d'affichage.
y_return
Retourne la position Y actuelle de la zone d'affichage.

ARGUMENTS

Determines if mode switching is allowed or disallowed for the specified screen. If lock is True, mode switching is disallowed. If lock is False, mode switching is allowed. Note that XF86VidModeUnlockModeSwitch is equivalent to calling XF86VidModeLockModeSwitch with False.

Queries the current video mode parameters for the specified screen. The modeline argument is filled with the current video mode parameters. The infop argument is filled with information about the current mode, such as its width and height. If the server uses private data for mode switching (e.g. for S3 cards), memory will be allocated for the infop->private field. This memory must be freed by the caller using Xfree() if infop->privsize is non-zero.

Sets the current video mode parameters for the specified screen. The modeline argument specifies the desired video mode parameters. This function may fail if the specified parameters are not valid for the current hardware.

Adds a new video mode to the list of available modes for the specified screen. The modeline argument specifies the parameters of the new mode. The after argument specifies an existing mode after which the new mode should be inserted. If after is NULL, the new mode is inserted after the current mode.

Deletes a video mode from the list of available modes for the specified screen. The mode argument specifies the mode to be deleted. If the current mode is deleted, a switch to the next mode will occur. The last remaining mode cannot be deleted.

Retrieves information about the monitor attached to the specified screen. The hsync and vsync arguments are pointers to integers which will be filled with the number of horizontal and vertical sync ranges, respectively. The red, green, and blue arguments are pointers to integers which will be filled with the red, green, and blue gamma values, respectively. The actual sync range and gamma information is stored in dynamically allocated arrays pointed to by the members of the XF86VidModeSyncRange structures which are returned by XF86VidModeGetMonitor. The caller is responsible for freeing these arrays using Xfree().

Sets the client's version for the VidMode extension. This should be called before any other VidMode functions. The major and minor version numbers are provided.

Retrieves the current viewport coordinates for the specified screen. The x and y arguments are pointers to integers which will be filled with the current x and y coordinates of the upper-left corner of the viewport.

Sets the viewport coordinates for the specified screen. The x and y arguments specify the desired coordinates of the upper-left corner of the viewport.

Switches the video mode on the specified screen to the mode indicated by modeNumber. Mode numbers are assigned sequentially starting from 0.

Switches the video mode on the specified screen to the mode specified by mode. The mode argument should point to a valid XF86VidModeModeInfo structure.

Retrieves the current gamma values for the specified screen. The red, green, and blue arguments are pointers to doubles which will be filled with the current gamma values.

Sets the gamma values for the specified screen. The red, green, and blue arguments specify the desired gamma values.

Retrieves the current gamma ramp for the specified screen. The size argument specifies the size of the gamma ramp. The red, green, and blue arguments are pointers to arrays of unsigned shorts which will be filled with the gamma ramp values.

Sets the gamma ramp for the specified screen. The size argument specifies the size of the gamma ramp. The red, green, and blue arguments are pointers to arrays of unsigned shorts which specify the desired gamma ramp values.

Retrieves the size of the gamma ramp for the specified screen.

Retrieves the permissions for the specified screen. The permissions argument is a pointer to an integer which will be filled with the current permissions.

Retrieves information about the available dot clocks for the specified screen. The flags, num, and max arguments are pointers to integers which will be filled with information about the dot clocks.

Validates a video mode line for the specified screen. The modeline argument specifies the video mode to be validated. Returns MODE_OK if the mode is valid, or an error code otherwise.

Queries the version of the XFree86-VidMode extension. The major_return and minor_return arguments are pointers to integers which will be filled with the major and minor version numbers, respectively.

Queries the XFree86-VidMode extension. The event_base_return and error_base_return arguments are pointers to integers which will be filled with the base event and error numbers for the extension.

DESCRIPTION

Ces fonctions fournissent une interface vers l'extension du serveur XFree86-VidModeExtension qui permet de consulter et d'ajuster dynamiquement les modes vidéo et de contrôler la commutation de modes. Les applications qui utilisent ces fonctions doivent être liées avec -lXxf86vm

FONCTIONS MODELINE

La fonction XF86VidModeGetModeLine est utilisée pour interroger les paramètres du mode vidéo actuellement sélectionné. Le programme appelant doit passer un pointeur vers une structure XF86VidModeModeLine qu'il a déjà allouée. La fonction remplit les champs de la structure.

S'il y a des valeurs privées du serveur (actuellement applicables uniquement au serveur S3), la fonction allouera du stockage pour elles. Par conséquent, si le champ privsize n'est pas nul, le programme appelant devrait appeler Xfree(private) pour libérer le stockage.

XF86VidModeGetAllModeLines renvoie les paramètres de tous les modes vidéo. Le programme appelant fournit l'adresse d'un pointeur qui sera défini par la fonction pour pointer vers un tableau de structures XF86VidModeModeInfo. La mémoire occupée par le tableau est allouée dynamiquement par la fonction XF86VidModeGetAllModeLines et doit être libérée par l'appelant. Le premier élément du tableau correspond au mode vidéo actuel.

La fonction XF86VidModeModModeLine peut être utilisée pour modifier les paramètres du mode vidéo actuel, à condition que les paramètres demandés soient valides (par exemple, qu'ils ne dépassent pas les capacités du moniteur).

Pour ajouter un mode à la liste des modes disponibles, la fonction XF86VidModeAddModeLine peut être utilisée. En supposant que les paramètres sont valides, le mode vidéo sera ajouté après le mode existant qui correspond aux timings spécifiés par le paramètre aftermode. Pour être considéré comme une correspondance, tous les champs de la structure XF86VidModeModeInfo donnée doivent correspondre, à l'exception des champs privsize et private. Si le paramètre aftermode est nul, le mode sera ajouté après le mode actuel.

Les modes peuvent être supprimés avec la fonction XF86VidModeDeleteModeLine. Le mode spécifié doit correspondre à un mode existant. Pour être considéré comme une correspondance, tous les champs de la structure XF86VidModeModeInfo donnée doivent correspondre, à l'exception des champs privsize et private. Si le mode à supprimer est le mode actuel, une commutation de mode vers le mode suivant se produira d'abord. Le dernier mode restant ne peut pas être supprimé.

La validité d'un mode peut être vérifiée avec la fonction XF86VidModeValidateModeLine. Si le mode spécifié peut être utilisé par le serveur (c'est-à-dire qu'il répond à toutes les contraintes imposées à un mode par la combinaison du serveur, de la carte et du moniteur), la fonction renvoie MODE_OK, sinon elle renvoie une valeur indiquant la raison pour laquelle le mode est invalide (telle que définie dans xf86.h)

FONCTIONS DE COMMUTATION DE MODE

Lorsque la fonction XF86VidModeSwitchMode est appelée, le serveur change le mode vidéo vers le mode vidéo suivant (ou précédent). La fonction XF86VidModeSwitchToMode peut être utilisée pour basculer directement vers le mode spécifié. La correspondance est spécifiée dans la description de la fonction XF86VidModeAddModeLine ci-dessus. La fonction XF86VidModeLockModeSwitch peut être utilisée pour autoriser ou interdire la commutation de mode, que la demande de commutation de mode provienne d'un appel aux fonctions XF86VidModeSwitchMode ou XF86VidModeSwitchToMode ou de l'une des séquences de touches de commutation de mode.

Note : En raison de la nature asynchrone du protocole X, un appel à XFlush est nécessaire si l'application souhaite voir le changement de mode immédiatement. Pour être informé de l'état d'exécution de la requête, un gestionnaire d'erreurs personnalisé doit être installé en utilisant XSetErrorHandler avant d'appeler la fonction de commutation de mode.

FONCTIONS MONITEUR

Les informations connues du serveur concernant le moniteur sont renvoyées par la fonction XF86VidModeGetMonitor. Les champs hsync et vsync pointent chacun vers un tableau de structures XF86VidModeSyncRange. Les tableaux contiennent respectivement nhsync et nvsync éléments. Les valeurs hi et low seront égales si une valeur discrète a été donnée dans le fichier XF86Config.

Les champs vendor, model, hsync, et vsync pointent vers du stockage alloué dynamiquement qui doit être libéré par l'appelant.

FONCTIONS VUE

Les fonctions XF86VidModeGetViewPort et XF86VidModeSetViewPort peuvent être utilisées pour, respectivement, interroger et modifier l'emplacement du coin supérieur gauche de la vue dans l'écran virtuel.

AUTRES FONCTIONS

La fonction XF86VidModeQueryVersion peut être utilisée pour déterminer la version de l'extension intégrée au serveur.

La fonction XF86VidModeQueryExtension renvoie les valeurs d'erreur et d'événement les plus basses attribuées à l'extension.

BOGUES

Les fonctions XF86VidModeSetClientVersion, XF86VidModeGetDotClocks, XF86VidModeGetGamma, XF86VidModeSetGamma, XF86VidModeSetGammaRamp, XF86VidModeGetGammaRamp, XF86VidModeGetGammaRampSize, et XF86VidModeGetPermissions doivent être documentées. En attendant, consultez le code source pour obtenir des informations sur leur utilisation.
