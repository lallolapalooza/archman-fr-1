DESCRIPTION

The XFree86-VidMode extension is a set of extensions to the Core X Window System protocol which allows clients to change the video mode (i.e. resolution and refresh rate) of the server. It also provides features for querying and setting the monitor and gamma characteristics.

The functions provided by this library are:

XF86VidModeQueryExtension()
Checks if the VidMode extension is available on the specified display. If it is, it returns the major and minor versions of the extension, and the base numbers for events and errors. Returns `False` if the extension is not available.
XF86VidModeQueryVersion()
Queries the version of the VidMode extension. Returns `False` on error.
XF86VidModeSetClientVersion()
Sets the client version, which may be necessary for compatibility with older servers.
XF86VidModeGetModeLine()
Retrieves the current video mode line for the specified screen.
XF86VidModeGetAllModeLines()
Retrieves all the video mode lines supported by the server for the specified screen. The caller is responsible for freeing the returned array of modes (using Xfree).
XF86VidModeAddModeLine()
Adds a new mode line to the list of supported modes for the specified screen. The new mode will be inserted after the specified aftermode. If aftermode is NULL, the new mode is added to the beginning of the list.
XF86VidModeDeleteModeLine()
Deletes a mode line from the list of supported modes for the specified screen.
XF86VidModeModModeLine()
Modifies an existing mode line. This function is used to change the parameters of a mode line that is already in the list of supported modes.
XF86VidModeValidateModeLine()
Validates a mode line to see if it is supported by the server. It returns `True` if the mode line is valid, `False` otherwise.
XF86VidModeSwitchMode()
Switches to the next or previous video mode. If zoom is positive, the next mode is selected, otherwise the previous mode is selected.
XF86VidModeSwitchToMode()
Switches to the specified video mode.
XF86VidModeLockModeSwitch()
Locks or unlocks mode switching. If lock is non-zero, mode switching is locked.
XF86VidModeGetMonitor()
Retrieves information about the monitor connected to the specified screen.
XF86VidModeGetViewPort()
Retrieves the current viewport location for the specified screen.
XF86VidModeSetViewPort()
Sets the viewport location for the specified screen.
XF86VidModeGetDotClocks()
Retrieves information about the dot clocks supported by the server for the specified screen.
XF86VidModeGetGamma()
Retrieves the current gamma correction for the specified screen.
XF86VidModeSetGamma()
Sets the gamma correction for the specified screen.
XF86VidModeGetGammaRamp()
Retrieves the current gamma ramp for the specified screen. The size parameter specifies the number of elements in the arrays.
XF86VidModeSetGammaRamp()
Sets the gamma ramp for the specified screen. The size parameter specifies the number of elements in the arrays.
XF86VidModeGetGammaRampSize()
Retrieves the size of the gamma ramp supported by the server for the specified screen.

DESCRIPTION


Ces fonctions fournissent une interface à l'extension serveur
    XFree86-VidModeExtension qui permet de rechercher et d'ajuster
    dynamiquement les modes vidéo, ainsi que de contrôler le changement de mode.
    Les applications qui utilisent ces fonctions doivent être liées avec
    -lXxf86vm




FONCTIONS DE MODELINE


La fonction XF86VidModeGetModeLine est utilisée pour
    interroger les paramètres du mode vidéo actuellement sélectionné. Le programme
    appelant doit passer un pointeur vers une structure
    XF86VidModeModeLine qu'il a déjà allouée. La fonction remplit les
    champs de la structure.


S'il existe des valeurs privées du serveur (actuellement applicables
    uniquement au serveur S3), la fonction allouera du stockage pour elles. Par
    conséquent, si le champ privsize n'est pas nul, le programme appelant
    devrait appeler Xfree(private) pour libérer le stockage.


XF86VidModeGetAllModeLines renvoie les paramètres de tous
    les modes vidéo. Le programme appelant fournit l'adresse d'un pointeur qui
    sera défini par la fonction pour pointer vers un tableau de structures
    XF86VidModeModeInfo. La mémoire occupée par le tableau est allouée
    dynamiquement par la fonction XF86VidModeGetAllModeLines et doit
    être libérée par l'appelant. Le premier élément du tableau correspond au mode
    vidéo actuel.


La fonction XF86VidModeModModeLine peut être utilisée pour
    modifier les paramètres du mode vidéo actuel, à condition que les paramètres
    demandés soient valides (par exemple, qu'ils ne dépassent pas les
    capacités du moniteur).


Pour ajouter un mode à la liste des modes disponibles, la fonction
    XF86VidModeAddModeLine peut être utilisée. En supposant que les
    paramètres sont valides, le mode vidéo sera ajouté après le mode existant
    qui correspond aux temporisations spécifiées par le paramètre
    aftermode. Pour être considéré comme une correspondance, tous les
    champs de la structure XF86VidModeModeInfo donnée doivent correspondre,
    à l'exception des champs privsize et private. Si le paramètre
    aftermode est zéro, le mode sera ajouté après le mode actuel.


Les modes peuvent être supprimés avec la fonction
    XF86VidModeDeleteModeLine. Le mode spécifié doit correspondre à un mode
    existant. Pour être considéré comme une correspondance, tous les champs de la
    structure XF86VidModeModeInfo donnée doivent correspondre, à l'exception
    des champs privsize et private. Si le mode à supprimer est le mode
    actuel, un changement de mode vers le mode suivant se produira d'abord. Le
    dernier mode restant ne peut pas être supprimé.


La validité d'un mode peut être vérifiée avec la fonction
    XF86VidModeValidateModeLine. Si le mode spécifié peut être utilisé par
    le serveur (c'est-à-dire qu'il respecte toutes les contraintes imposées à un
    mode par la combinaison du serveur, de la carte et du moniteur), la fonction
    renvoie MODE_OK, sinon elle renvoie une valeur indiquant la raison pour
    laquelle le mode est invalide (tel que défini dans
    xf86.h)






FONCTIONS DE CHANGEMENT DE MODE


Lorsque la fonction XF86VidModeSwitchMode est appelée, le
    serveur change le mode vidéo au mode vidéo suivant (ou précédent). La fonction
    XF86VidModeSwitchToMode peut être utilisée pour passer directement au
    mode spécifié. La correspondance est telle que spécifiée dans la description
    de la fonction XF86VidModeAddModeLine ci-dessus. La fonction
    XF86VidModeLockModeSwitch peut être utilisée pour autoriser ou
    refuser le changement de mode, que la demande de changement de mode provienne
    d'un appel aux fonctions XF86VidModeSwitchMode ou
    XF86VidModeSwitchToMode ou de l'une des séquences de touches de changement
    de mode.


Note : En raison de la nature asynchrone du protocole X, un appel
    à XFlush est nécessaire si l'application souhaite voir le changement
    de mode immédiatement. Pour être informé de l'état d'exécution de la
    demande, un gestionnaire d'erreurs personnalisé doit être installé à l'aide
    de XSetErrorHandler avant d'appeler la fonction de changement de
    mode.






FONCTIONS MONITEUR


Les informations connues du serveur concernant le moniteur sont
    renvoyées par la fonction XF86VidModeGetMonitor. Les champs
    hsync et vsync pointent chacun vers un tableau de structures
    XF86VidModeSyncRange. Les tableaux contiennent respectivement
    nhsync et nvsync éléments. Les valeurs hi et low
    seront égales si une valeur discrète a été donnée dans le fichier
    XF86Config.


Les champs vendor, model, hsync, et
    vsync pointent vers du stockage alloué dynamiquement qui devrait être
    libéré par l'appelant.






FONCTIONS VIEWPORT


Les fonctions XF86VidModeGetViewPort et
    XF86VidModeSetViewPort peuvent être utilisées pour, respectivement,
    interroger et modifier l'emplacement du coin supérieur gauche du viewport dans
    l'écran virtuel.






AUTRES FONCTIONS


La fonction XF86VidModeQueryVersion peut être utilisée pour
    déterminer la version de l'extension intégrée au serveur.


La fonction XF86VidModeQueryExtension renvoie les valeurs
    d'erreur et d'événement les plus basses attribuées à l'extension.
