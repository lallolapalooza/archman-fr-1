XGetEventData(3) FONCTIONS XLIB XGetEventData(3)

NOM

XGetEventData, XFreeEventData, XGenericEventCookie - récupérer et libérer des données d'événement supplémentaires via des cookies.

SYNTAXE

Bool XGetEventData(Display *display, XGenericEventCookie *cookie);

void XFreeEventData(Display *display, XGenericEventCookie *cookie);

ARGUMENTS

display
Spécifie la connexion au serveur X.
cookie
Spécifie le cookie à libérer ou dont récupérer les données.

STRUCTURES

typedef struct {
        int type;
        unsigned long serial;
        Bool send_event;
        Display *display;
        int extension;
        int evtype;
        unsigned int cookie;
        void *data;
} XGenericEventCookie;

DESCRIPTION

Certains XGenericEvents d'extension nécessitent une mémoire supplémentaire pour stocker des informations. Pour ces événements, la bibliothèque retourne un XGenericEventCookie avec un jeton ('cookie') unique à cet événement. Le pointeur de données du XGenericEventCookie est indéfini jusqu'à ce que XGetEventData soit appelé.

La fonction XGetEventData récupère ces données supplémentaires pour le cookie donné. Aucun aller-retour vers le serveur n'est requis. Si le cookie est invalide ou si l'événement n'est pas géré par des gestionnaires de cookies, False est retourné. Si XGetEventData retourne True, le pointeur de données du cookie pointe vers la mémoire contenant les informations de l'événement. Un client doit appeler XFreeEventData pour libérer cette mémoire. XGetEventData retourne False pour les appels multiples pour le même cookie d'événement.

La fonction XFreeEventData libère les données associées à un cookie. Un client doit appeler XFreeEventData pour chaque cookie réclamé avec XGetEventData.

EXEMPLE DE CODE

XEvent event;
XGenericEventCookie *cookie = &ev;
XNextEvent(display, &event);
if (XGetEventData(display, cookie)) {
    handle_cookie_event(cookie->data);
} else
    handle_event(&event);
}
XFreeEventData(display, cookie);

NOTES

Un cookie est défini comme non réclamé s'il a été retourné au client via XNextEvent mais que ses données n'ont pas été récupérées via XGetEventData. Les appels ultérieurs à XNextEvent peuvent libérer la mémoire associée aux cookies non réclamés. Les clients X multithreadés doivent s'assurer que XGetEventData est appelé avant le prochain appel à XNextEvent.
