XLISTINPUTDEVICES(3)   XLISTINPUTDEVICES(3)

NOM

XListInputDevices, XFreeDeviceList - lister les périphériques d'entrée disponibles

SYNTAXE

#include <X11/extensions/XInput.h>
XDeviceInfo *XListInputDevices( Display *display,
                                int *ndevices_return);
int XFreeDeviceList( XDeviceInfo *list);
display
       Spécifie la connexion au serveur X.
ndevices_return
       Spécifie un pointeur vers une variable où le nombre de
       périphériques disponibles peut être retourné.
list
       Spécifie la liste des périphériques à libérer. La
       fonction XFreeDeviceList libère la liste des périphériques d'entrée
       d'extension disponibles.

DESCRIPTION

La requête XListInputDevices liste les périphériques d'entrée
disponibles. Cette liste comprend le clavier principal (core keyboard) et tout
périphérique d'entrée physique actuellement accessible via le serveur X, ainsi que tout
périphérique d'entrée qui n'est pas actuellement accessible via le serveur X mais qui
pourrait l'être sur demande.
Un pointeur maître est un périphérique pointeur virtuel qui ne
représente pas un périphérique physique. Il est représenté visuellement par un
curseur. Un clavier maître est un périphérique clavier virtuel qui ne représente pas
un périphérique physique. Il est représenté virtuellement par un focus clavier. Un
pointeur maître et un clavier maître sont toujours appairés (c'est-à-dire que si
la touche majuscule est enfoncée sur le clavier maître, un clic de souris serait un
clic avec la touche majuscule enfoncée). Plusieurs paires pointeur/clavier maître peuvent exister.
Les serveurs X supportant la version 2 de l'extension X Input,
XListInputDevices ne retourne que le premier pointeur maître, le premier
clavier maître et tous les périphériques esclaves. Les périphériques maîtres
supplémentaires ne sont pas listés.
Les périphériques physiques (dits périphériques esclaves) sont
attachés soit à un pointeur maître, soit à un clavier maître, en fonction de leurs
capacités. Si un périphérique esclave génère un événement, cet événement est également
généré par le périphérique maître respectif. Plusieurs périphériques esclaves peuvent être
attachés à un seul périphérique maître.
Certaines implémentations de serveur peuvent rendre tous les
périphériques d'entrée physiques disponibles au moment de l'initialisation du
serveur. D'autres peuvent attendre qu'un client demande l'accès à un périphérique
d'entrée. Dans ce dernier cas, il est possible qu'un périphérique d'entrée soit
listé comme disponible à un moment donné mais pas à un autre.
Pour chaque périphérique d'entrée disponible pour le serveur,
la requête XListInputDevices retourne une structure XDeviceInfo.
Cette structure contient un pointeur vers une liste de structures, chacune
contenant des informations sur une classe d'entrée supportée par le
périphérique. La structure XDeviceInfo est définie comme suit :
             typedef struct _XDeviceInfo {
             XID     id;
             Atom    type;
             char    *name;
             int         num_classes;
             int         use;
             XAnyClassPtr inputclassinfo;
             } XDeviceInfo;
L'id est un nombre dans la plage 0-128 qui identifie de manière
unique le périphérique. Il est attribué au périphérique lors de son
initialisation par le serveur.
Le champ type est de type Atom et indique la nature du
périphérique. Le type correspondra à l'une des chaînes suivantes
(définies dans le fichier d'en-tête XI.h) :
XI_MOUSE XI_TABLET XI_KEYBOARD XI_TOUCHSCREEN XI_TOUCHPAD
XI_BUTTONBOX XI_BARCODE XI_TRACKBALL XI_QUADRATURE XI_ID_MODULE
XI_ONE_KNOB XI_NINE_KNOB XI_KNOB_BOX XI_SPACEBALL XI_DATAGLOVE
XI_EYETRACKER XI_CURSORKEYS XI_FOOTMOUSE XI_JOYSTICK
Ces chaînes peuvent être utilisées dans une requête XInternAtom
pour retourner un atome qui peut être comparé au champ type de la
structure XDeviceInfo.
Le champ name contient un pointeur vers une chaîne terminée par
un caractère nul qui sert d'identifiant au périphérique. Cet identifiant peut être
configuré par l'utilisateur ou attribué automatiquement par le serveur.
Le champ num_classes est un nombre dans la plage 0-255 qui
spécifie le nombre de classes d'entrée supportées par le périphérique pour
lesquelles des informations sont retournées par ListInputDevices. Certaines
classes d'entrée, telles que la classe Focus et la classe Proximity, n'ont pas
d'informations à retourner par ListInputDevices.
Tous les périphériques fournissent une classe AttachClass. Cette
classe spécifie le périphérique maître auquel un périphérique esclave donné est
attaché. Pour les périphériques maîtres, la classe spécifie le périphérique maître
appairé respectif.
Le champ use spécifie comment le périphérique est actuellement
utilisé. Si la valeur est IsXKeyboard, le périphérique est un clavier
maître. Si la valeur est IsXPointer, le périphérique est un pointeur
maître. Si la valeur est IsXExtensionPointer, le périphérique est un pointeur
esclave. Si la valeur est IsXExtensionKeyboard, le périphérique est un clavier
esclave. Si la valeur est IsXExtensionDevice, le périphérique est disponible
pour être utilisé comme périphérique d'extension.
Le champ inputclassinfo contient un pointeur vers la première
donnée spécifique à une classe d'entrée. Les deux premiers champs sont communs à
toutes les classes.
Le champ class est un nombre dans la plage 0-255. Il identifie
de manière unique la classe d'entrée pour laquelle des informations sont
retournées. Les classes actuellement définies sont KeyClass, ButtonClass et
ValuatorClass.
Le champ length est un nombre dans la plage 0-255. Il spécifie
le nombre d'octets de données contenus dans cette classe d'entrée. La longueur
inclut les champs class et length.
La structure XKeyInfo décrit les caractéristiques des touches sur
le périphérique. Elle est définie comme suit :
typedef struct _XKeyInfo {
XID class;
int length;
unsigned short min_keycode;
unsigned short max_keycode;
unsigned short num_keys;
} XKeyInfo;
min_keycode est de type KEYCODE. Il spécifie le keycode minimum
que le périphérique rapportera. Le keycode minimum ne sera pas inférieur à 8.
max_keycode est de type KEYCODE. Il spécifie le keycode maximum
que le périphérique rapportera. Le keycode maximum ne sera pas supérieur à 255.
num_keys spécifie le nombre de touches que possède le périphérique.
La structure XButtonInfo définit les caractéristiques des boutons
sur le périphérique. Elle est définie comme suit :
typedef struct _XButtonInfo {
XID class;
int length;
short num_buttons;
} XButtonInfo;
num_buttons spécifie le nombre de boutons que possède le
périphérique.
La structure XValuatorInfo définit les caractéristiques des
valuateurs sur le périphérique. Elle est définie comme suit :
typedef struct  _XValuatorInfo {
XID class;
int length;
unsigned char num_axes;
unsigned char mode;
unsigned long motion_buffer;
XAxisInfoPtr axes;
} XValuatorInfo;
num_axes contient le nombre d'axes que le périphérique supporte.
mode est une constante qui a l'une des valeurs suivantes :
Absolute ou Relative. Certains périphériques permettent de changer le mode
dynamiquement via la requête SetDeviceMode.
motion_buffer_size est un nombre cardinal qui spécifie le
nombre d'éléments que peut contenir le tampon d'historique des mouvements
pour le périphérique.
Le champ axes contient un pointeur vers une structure XAxisInfo.
La structure XAxisInfo est définie comme suit :
typedef struct _XAxisInfo {
int resolution;
int min_value;
int max_value;
} XAxisInfo;
La résolution contient un nombre en comptes/mètre.
Le champ min_val contient un nombre qui spécifie la valeur minimum
que le périphérique rapporte pour cet axe. Pour les périphériques dont le mode
est Relative, le champ min_val contiendra 0.
Le champ max_val contient un nombre qui spécifie la valeur maximum
que le périphérique rapporte pour cet axe. Pour les périphériques dont le mode
est Relative, le champ max_val contiendra 0.
La structure XAttachInfo est définie comme suit :
             typedef struct _XAttachInfo {
             int     attached;
             } XAttachInfo;
Si le périphérique est un périphérique esclave, attached spécifie
l'ID du périphérique maître auquel ce périphérique est attaché. Si le
périphérique n'est pas attaché à un périphérique maître, attached est
Floating. Si le périphérique est un périphérique maître, attached spécifie
l'ID du périphérique maître avec lequel ce périphérique est appairé.

VALEUR DE RETOUR

XListInputDevices retourne un pointeur vers un tableau de structures XDeviceInfo et
définit ndevices_

XFreeDeviceList - libXi manual page

NAME

XFreeDeviceList - free information about input devices

SYNOPSIS

#include <X11/extensions/XInput2.h>
void XFreeDeviceList(XDeviceInfoPtr devices);

DESCRIPTION

The XFreeDeviceList function frees the memory allocated by XListInputDevices for the specified XDeviceInfo array.

The devices argument is a pointer to an XDeviceInfo array previously returned by XListInputDevices.

To free the XDeviceInfo array created by XListInputDevices, use XFreeDeviceList.

RETURN VALUE

On error, XListInputDevices returns NULL and ndevices_return is
left unmodified.
