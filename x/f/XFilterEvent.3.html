NOM

XFilterEvent - filtre les événements X pour une méthode d'entrée

SYNTAXE

Bool XFilterEvent(XEvent *event, Window w);

ARGUMENTS

event
Spécifie l'événement à filtrer.
w
Spécifie la fenêtre pour laquelle le filtre doit être appliqué.

DESCRIPTION

Si l'argument fenêtre est None, XFilterEvent applique le filtre à la fenêtre spécifiée dans la structure XEvent. L'argument fenêtre est fourni afin que les couches supérieures à Xlib qui effectuent une redirection d'événements puissent indiquer à quelle fenêtre un événement a été redirigé.

Si XFilterEvent retourne True, alors une méthode d'entrée a filtré l'événement, et le client doit ignorer l'événement. Si XFilterEvent retourne False, alors le client doit continuer le traitement de l'événement.

Si une saisie (grab) a eu lieu dans le client et que XFilterEvent retourne True, le client doit annuler la saisie du clavier.
