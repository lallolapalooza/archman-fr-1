NOM

XFocusChangeEvent - Structure d'événements FocusIn et FocusOut

STRUCTURES

La structure pour les événements FocusIn et FocusOut contient :

typedef struct {
        int type;       /* FocusIn ou FocusOut */
        unsigned long serial;   /* # de la dernière requête traitée par le serveur */
        Bool send_event;        /* vrai si ceci provient d'une requête SendEvent */
        Display *display;       /* Affichage à partir duquel l'événement a été lu */
        Window window;  /* fenêtre de l'événement */
        int mode;       /* NotifyNormal, NotifyGrab, NotifyUngrab */
        int detail;
                /*
                * NotifyAncestor, NotifyVirtual, NotifyInferior,
                * NotifyNonlinear,NotifyNonlinearVirtual, NotifyPointer,
                * NotifyPointerRoot, NotifyDetailNone
                */
} XFocusChangeEvent;
typedef XFocusChangeEvent XFocusInEvent;
typedef XFocusChangeEvent XFocusOutEvent;

Lorsque vous recevez ces événements, les membres de la structure sont définis comme suit.

Le membre type est défini à la constante nom de type d'événement qui l'identifie de manière unique. Par exemple, lorsque le serveur X signale un événement GraphicsExpose à une application cliente, il envoie une structure XGraphicsExposeEvent avec le membre type défini sur GraphicsExpose. Le membre display est défini sur un pointeur vers l'affichage sur lequel l'événement a été lu. Le membre send_event est défini sur True si l'événement provient d'une requête de protocole SendEvent. Le membre serial est défini à partir du numéro de série rapporté dans le protocole mais étendu des 16 bits les moins significatifs à une valeur complète de 32 bits. Le membre window est défini à la fenêtre la plus utile pour les répartiteurs de boîtes à outils.

Le membre window est défini sur la fenêtre sur laquelle l'événement FocusIn ou FocusOut a été généré. C'est la fenêtre utilisée par le serveur X pour rapporter l'événement. Le membre mode est défini pour indiquer si les événements de focus sont des événements de focus normaux, des événements de focus lors d'une saisie (grab), des événements de focus lorsqu'une saisie s'active, ou des événements de focus lorsqu'une saisie se désactive. Le serveur X peut définir le membre mode sur NotifyNormal, NotifyWhileGrabbed, NotifyGrab, ou NotifyUngrab.

Tous les événements FocusOut causés par une désassociation de fenêtre (unmap) sont générés après tout événement UnmapNotify ; cependant, le protocole X ne contraint pas l'ordre des événements FocusOut par rapport aux événements générés EnterNotify, LeaveNotify, VisibilityNotify, et Expose.

En fonction du mode de l'événement, le membre detail est défini pour indiquer le détail de notification et peut être NotifyAncestor, NotifyVirtual, NotifyInferior, NotifyNonlinear, NotifyNonlinearVirtual, NotifyPointer, NotifyPointerRoot, ou NotifyDetailNone.
