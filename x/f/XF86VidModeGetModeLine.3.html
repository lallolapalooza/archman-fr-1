DESCRIPTION

L'extension XF86VidMode fournit un moyen de contrôler les modes vidéo de bas niveau des pilotes graphiques XFree86. Il permet de manipuler les caractéristiques d'un moniteur, telles que la résolution, la fréquence de rafraîchissement, etc. La plupart des fonctions nécessitent des privilèges spéciaux.

Les fonctions suivantes sont disponibles :

XF86VidModeQueryExtension
Interroge le serveur pour connaître la disponibilité de l'extension XF86VidMode et récupère ses numéros de base d'événement et d'erreur.
XF86VidModeQueryVersion
Interroge le serveur pour connaître la version de l'extension XF86VidMode implémentée.
XF86VidModeSetClientVersion
Indique au serveur la version de l'extension que le client est capable d'utiliser.
XF86VidModeGetModeLine
Récupère la ligne de mode actuelle pour l'écran spécifié.
XF86VidModeGetAllModeLines
Récupère toutes les lignes de mode disponibles pour l'écran spécifié.
XF86VidModeAddModeLine
Ajoute une nouvelle ligne de mode à la liste des modes disponibles. Elle est insérée après la ligne de mode spécifiée par aftermode. Si aftermode est NULL, elle est ajoutée à la fin.
XF86VidModeDeleteModeLine
Supprime une ligne de mode spécifiée de la liste des modes disponibles.
XF86VidModeModModeLine
Modifie la ligne de mode actuelle pour l'écran spécifié.
XF86VidModeValidateModeLine
Valide une ligne de mode donnée, vérifiant si elle est acceptable par le serveur sans la modifier.
XF86VidModeSwitchMode
Demande au serveur de passer au mode vidéo suivant ou précédent. Si zoom est différent de zéro, le mode suivant est sélectionné.
XF86VidModeSwitchToMode
Demande au serveur de passer au mode vidéo spécifié par modeline.
XF86VidModeLockModeSwitch
Verrouille ou déverrouille la possibilité de changer de mode vidéo. Si lock est différent de zéro, le changement de mode est verrouillé.
XF86VidModeGetMonitor
Récupère les informations sur le moniteur connecté à l'écran spécifié.
XF86VidModeGetViewPort
Récupère la position actuelle de la fenêtre d'affichage pour l'écran spécifié.
XF86VidModeSetViewPort
Définit la position de la fenêtre d'affichage pour l'écran spécifié.
XF86VidModeGetDotClocks
Récupère la liste des fréquences d'horloge de pixels disponibles pour l'écran spécifié, ainsi que la fréquence maximale.
XF86VidModeGetGamma
Récupère les valeurs gamma actuelles pour l'écran spécifié.
XF86VidModeSetGamma
Définit les valeurs gamma pour l'écran spécifié.
XF86VidModeGetGammaRamp
Récupère les tables gamma (ramps) pour les couleurs rouge, verte et bleue pour l'écran spécifié. La taille de ces tables est spécifiée par size.
XF86VidModeSetGammaRamp
Définit les tables gamma pour les couleurs rouge, verte et bleue pour l'écran spécifié. La taille de ces tables est spécifiée par size.
XF86VidModeGetGammaRampSize
Récupère la taille des tables gamma disponibles pour l'écran spécifié.

THé EXTENSION XF86VIDMODE

L'extension XFree86-VidMode a été conçue pour permettre aux applications de contrôler les paramètres vidéo de bas niveau, tels que les modes d'affichage, les fréquences de rafraîchissement et les paramètres du moniteur. Elle est particulièrement utile pour les applications qui nécessitent un contrôle précis de l'affichage, comme les jeux ou les applications multimédias.

Les fonctions fournies par cette extension permettent de :

  • Interroger et interagir avec l'extension VidMode.
  • Obtenir et définir les lignes de mode vidéo (modèleines) qui décrivent les paramètres tels que la résolution, le synchronisme horizontal et vertical, et la fréquence d'horloge de pixels.
  • Gérer une liste de lignes de mode, y compris l'ajout, la suppression et la modification.
  • Valider la conformité d'une ligne de mode avec les capacités du matériel.
  • Changer le mode vidéo actuel, soit en passant au mode suivant/précédent, soit en sélectionnant un mode spécifique.
  • Verrouiller ou déverrouiller les changements de mode pour éviter les modifications non désirées.
  • Obtenir des informations sur le moniteur connecté, y compris ses caractéristiques de synchronisation.
  • Contrôler la position de la fenêtre d'affichage (viewport) sur l'écran.
  • Obtenir la liste des fréquences d'horloge de pixels supportées par le matériel.
  • Ajuster les paramètres gamma pour corriger la réponse tonale de l'écran, y compris la lecture et l'écriture de tables gamma complètes.

Il est important de noter que la plupart de ces opérations peuvent requérir des privilèges d'administration (root) pour être effectuées en toute sécurité. Une utilisation incorrecte de ces fonctions peut entraîner des problèmes d'affichage, voire rendre le système instable.

HISTORIQUE

L'extension XFree86-VidMode a été introduite avec XFree86 3.3.

DESCRIPTION

Ces fonctions fournissent une interface à l'extension serveur XFree86-VidModeExtension qui permet de consulter et d'ajuster dynamiquement les modes vidéo et de contrôler la commutation de modes. Les applications qui utilisent ces fonctions doivent être liées avec -lXxf86vm.

FONCTIONS MODELINE

La fonction XF86VidModeGetModeLine est utilisée pour interroger les paramètres du mode vidéo actuellement sélectionné. Le programme appelant doit passer un pointeur vers une structure XF86VidModeModeLine qu'il a déjà allouée. La fonction remplit les champs de la structure.

S'il existe des valeurs privées du serveur (actuellement uniquement applicables au serveur S3), la fonction allouera du stockage pour elles. Par conséquent, si le champ privsize n'est pas nul, le programme appelant doit appeler Xfree(private) pour libérer le stockage.

XF86VidModeGetAllModeLines renvoie les paramètres de tous les modes vidéo. Le programme appelant fournit l'adresse d'un pointeur qui sera définie par la fonction pour pointer vers un tableau de structures XF86VidModeModeInfo. La mémoire occupée par le tableau est allouée dynamiquement par la fonction XF86VidModeGetAllModeLines et doit être libérée par l'appelant. Le premier élément du tableau correspond au mode vidéo actuel.

La fonction XF86VidModeModModeLine peut être utilisée pour modifier les paramètres du mode vidéo actuel, à condition que les paramètres demandés soient valides (par exemple, qu'ils ne dépassent pas les capacités du moniteur).

Pour ajouter un mode à la liste des modes disponibles, la fonction XF86VidModeAddModeLine peut être utilisée. En supposant que les paramètres sont valides, le mode vidéo sera ajouté après le mode existant qui correspond aux timings spécifiés par le paramètre aftermode. Pour être considéré comme une correspondance, tous les champs de la structure XF86VidModeModeInfo donnée doivent correspondre, à l'exception des champs privsize et private. Si le paramètre aftermode est nul, le mode sera ajouté après le mode actuel.

Les modes peuvent être supprimés avec la fonction XF86VidModeDeleteModeLine. Le mode spécifié doit correspondre à un mode existant. Pour être considéré comme une correspondance, tous les champs de la structure XF86VidModeModeInfo donnée doivent correspondre, à l'exception des champs privsize et private. Si le mode à supprimer est le mode actuel, un changement de mode vers le mode suivant se produira d'abord. Le dernier mode restant ne peut pas être supprimé.

La validité d'un mode peut être vérifiée avec la fonction XF86VidModeValidateModeLine. Si le mode spécifié peut être utilisé par le serveur (c'est-à-dire qu'il répond à toutes les contraintes imposées à un mode par la combinaison du serveur, de la carte et du moniteur), la fonction renvoie MODE_OK, sinon elle renvoie une valeur indiquant la raison pour laquelle le mode est invalide (telle que définie dans xf86.h).

FONCTIONS DE COMMUTATION DE MODE

Lorsque la fonction XF86VidModeSwitchMode est appelée, le serveur change le mode vidéo pour le mode vidéo suivant (ou précédent). La fonction XF86VidModeSwitchToMode peut être utilisée pour passer directement au mode spécifié. La correspondance est comme spécifié dans la description de la fonction XF86VidModeAddModeLine ci-dessus. La fonction XF86VidModeLockModeSwitch peut être utilisée pour autoriser ou interdire la commutation de modes, que la demande de commutation de modes provienne d'un appel aux fonctions XF86VidModeSwitchMode ou XF86VidModeSwitchToMode ou de l'une des séquences de touches de commutation de modes.

Note : En raison de la nature asynchrone du protocole X, un appel à XFlush est nécessaire si l'application souhaite voir le changement de mode immédiatement. Pour être informé de l'état d'exécution de la requête, un gestionnaire d'erreurs personnalisé doit être installé en utilisant XSetErrorHandler avant d'appeler la fonction de commutation de mode.

FONCTIONS MONITEUR

Les informations connues du serveur concernant le moniteur sont renvoyées par la fonction XF86VidModeGetMonitor. Les champs hsync et vsync pointent chacun vers un tableau de structures XF86VidModeSyncRange. Les tableaux contiennent respectivement nhsync et nvsync éléments. Les valeurs hi et low seront égales si une valeur discrète a été donnée dans le fichier XF86Config.

Les champs vendor, model, hsync, et vsync pointent vers un stockage alloué dynamiquement qui doit être libéré par l'appelant.

FONCTIONS VIEWPORT

Les fonctions XF86VidModeGetViewPort et XF86VidModeSetViewPort peuvent être utilisées pour, respectivement, interroger et modifier l'emplacement du coin supérieur gauche du viewport dans l'écran virtuel.

AUTRES FONCTIONS

La fonction XF86VidModeQueryVersion peut être utilisée pour déterminer la version de l'extension intégrée au serveur.

La fonction XF86VidModeQueryExtension renvoie les valeurs d'erreur et d'événement les plus basses attribuées à l'extension.

BOGUES

Les fonctions XF86VidModeSetClientVersion, XF86VidModeGetDotClocks, XF86VidModeGetGamma, XF86VidModeSetGamma, XF86VidModeSetGammaRamp, XF86VidModeGetGammaRamp, XF86VidModeGetGammaRampSize, et XF86VidModeGetPermissions doivent être documentées. En attendant, consultez le code source pour obtenir des informations sur leur utilisation.
