Paquet: libx11

XFontSetExtents(3) FONCTIONS XLIB XFontSetExtents(3)

NOM

XFontSetExtents - structure XFontSetExtents

STRUCTURES

La structure XFontSetExtents contient :

typedef struct {
        XRectangle max_ink_extent;      /* sur tous les caractères dessinables */
        XRectangle max_logical_extent;  /* sur tous les caractères dessinables */
} XFontSetExtents;

Les structures XRectangle utilisées pour retourner les métriques de jeu de polices sont les rectangles habituels de Xlib orientés écran avec x, y donnant le coin supérieur gauche, et width et height toujours positifs.

Le membre max_ink_extent donne l'étendue maximale, sur tous les caractères dessinables, des rectangles qui délimitent l'image du glyphe de caractère dessinée dans la couleur de premier plan, par rapport à une origine constante. Voir XmbTextExtents et XwcTextExtents pour les sémantiques détaillées.

Le membre max_logical_extent donne l'étendue maximale, sur tous les caractères dessinables, des rectangles qui spécifient un espacement minimum avec d'autres caractéristiques graphiques, par rapport à une origine constante. D'autres caractéristiques graphiques dessinées par le client, par exemple, une bordure entourant le texte, ne doivent pas intercepter ce rectangle. Le membre max_logical_extent doit être utilisé pour calculer l'espacement inter-lignes minimum et la zone minimum qui doit être allouée dans un champ de texte pour dessiner un nombre donné de caractères arbitraires.

En raison du rendu dépendant du contexte, l'ajout d'un caractère donné à une chaîne peut modifier l'étendue de la chaîne d'un montant autre que l'étendue individuelle de ce caractère.
