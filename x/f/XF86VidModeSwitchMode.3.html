DESCRIPTION

The XFree86-VidMode extension is a server extension that allows X clients to query and manipulate video modes, monitor settings, and viewport settings. The functions described in this page are the C library interface to this extension.

SUPPORTED PROTOCOLS

This library provides access to XFree86-VidMode protocol version 3.0, 3.1, 3.2, 3.3, 3.4, 3.5, 3.6, 3.7, 3.8, 3.9, 4.0, 4.1.

RETURN VALUES

Most functions return True on success and False on failure. XF86VidModeValidateModeLine returns True if the modeline is valid, and False otherwise. XF86VidModeGetAllModeLines returns True on success, and the array pointed to by modesinfo is allocated, and must be freed by the caller using XFree.

ERRORS

The extension defines its own error codes. Clients can get the base error number by calling XF86VidModeQueryExtension.

DESCRIPTION

Ces fonctions fournissent une interface à l'extension du serveur XFree86-VidModeExtension qui permet de consulter et d'ajuster les modes vidéo dynamiquement, ainsi que de contrôler les changements de mode. Les applications qui utilisent ces fonctions doivent être liées avec -lXxf86vm

FONCTIONS DE MODELINE

La fonction XF86VidModeGetModeLine est utilisée pour interroger les paramètres du mode vidéo actuellement sélectionné. Le programme appelant devrait passer un pointeur vers une structure XF86VidModeModeLine qu'il a déjà allouée. La fonction remplit les champs de la structure.

S'il y a des valeurs privées au serveur (actuellement applicables uniquement au serveur S3), la fonction allouera du stockage pour elles. Par conséquent, si le champ privsize est non nul, le programme appelant devrait appeler Xfree(private) pour libérer le stockage.

XF86VidModeGetAllModeLines renvoie les paramètres de tous les modes vidéo. Le programme appelant fournit l'adresse d'un pointeur qui sera défini par la fonction pour pointer vers un tableau de structures XF86VidModeModeInfo. La mémoire occupée par le tableau est allouée dynamiquement par la fonction XF86VidModeGetAllModeLines et devrait être libérée par l'appelant. Le premier élément du tableau correspond au mode vidéo actuel.

La fonction XF86VidModeModModeLine peut être utilisée pour modifier les paramètres du mode vidéo actuel, à condition que les paramètres demandés soient valides (par exemple, qu'ils ne dépassent pas les capacités du moniteur).

Pour ajouter un mode à la liste des modes disponibles, la fonction XF86VidModeAddModeLine peut être utilisée. En supposant que les paramètres sont valides, le mode vidéo sera ajouté après le mode existant qui correspond aux timings spécifiés par le paramètre aftermode. Pour être considéré comme une correspondance, tous les champs de la structure XF86VidModeModeInfo fournie doivent correspondre, à l'exception des champs privsize et private. Si le paramètre aftermode est zéro, le mode sera ajouté après le mode actuel.

Les modes peuvent être supprimés avec la fonction XF86VidModeDeleteModeLine. Le mode spécifié doit correspondre à un mode existant. Pour être considéré comme une correspondance, tous les champs de la structure XF86VidModeModeInfo fournie doivent correspondre, à l'exception des champs privsize et private. Si le mode à supprimer est le mode actuel, un changement de mode vers le mode suivant se produira d'abord. Le dernier mode restant ne peut pas être supprimé.

La validité d'un mode peut être vérifiée avec la fonction XF86VidModeValidateModeLine. Si le mode spécifié peut être utilisé par le serveur (c'est-à-dire qu'il répond à toutes les contraintes imposées à un mode par la combinaison du serveur, de la carte et du moniteur), la fonction renvoie MODE_OK, sinon elle renvoie une valeur indiquant la raison pour laquelle le mode est invalide (telle que définie dans xf86.h)

FONCTIONS DE CHANGEMENT DE MODE

Lorsque la fonction XF86VidModeSwitchMode est appelée, le serveur change le mode vidéo au mode vidéo suivant (ou précédent). La fonction XF86VidModeSwitchToMode peut être utilisée pour basculer directement vers le mode spécifié. La correspondance est comme spécifié dans la description de la fonction XF86VidModeAddModeLine ci-dessus. La fonction XF86VidModeLockModeSwitch peut être utilisée pour autoriser ou interdire les changements de mode, que la demande de changement de mode provienne d'un appel aux fonctions XF86VidModeSwitchMode ou XF86VidModeSwitchToMode, ou de l'une des séquences de touches de changement de mode.

Note : En raison de la nature asynchrone du protocole X, un appel à XFlush est nécessaire si l'application souhaite voir le changement de mode immédiatement. Pour être informé de l'état d'exécution de la requête, un gestionnaire d'erreurs personnalisé doit être installé en utilisant XSetErrorHandler avant d'appeler la fonction de changement de mode.

FONCTIONS MONITEUR

Les informations connues du serveur concernant le moniteur sont renvoyées par la fonction XF86VidModeGetMonitor. Les champs hsync et vsync pointent chacun vers un tableau de structures XF86VidModeSyncRange. Les tableaux contiennent nhsync et nvsync éléments, respectivement. Les valeurs hi et low seront égales si une valeur discrète a été donnée dans le fichier XF86Config.

Les champs vendor, model, hsync et vsync pointent vers un stockage alloué dynamiquement qui doit être libéré par l'appelant.

FONCTIONS DE PORT DE VISUALISATION

Les fonctions XF86VidModeGetViewPort et XF86VidModeSetViewPort peuvent être utilisées pour, respectivement, interroger et modifier l'emplacement du coin supérieur gauche du viewport dans l'écran virtuel.

AUTRES FONCTIONS

La fonction XF86VidModeQueryVersion peut être utilisée pour déterminer la version de l'extension intégrée au serveur.

La fonction XF86VidModeQueryExtension renvoie les valeurs d'erreur et d'événement les plus basses attribuées à l'extension.

BOGUES

Les fonctions XF86VidModeSetClientVersion, XF86VidModeGetDotClocks, XF86VidModeGetGamma, XF86VidModeSetGamma, XF86VidModeSetGammaRamp, XF86VidModeGetGammaRamp, XF86VidModeGetGammaRampSize, et XF86VidModeGetPermissions nécessitent une documentation. En attendant, consultez le code source pour obtenir des informations sur leur utilisation.
