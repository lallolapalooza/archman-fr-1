DESCRIPTION

The XFree86-VidMode extension allows clients to query and control various aspects of the X server's video modes. The functions provided by this extension library are: XF86VidModeQueryExtension(), XF86VidModeQueryVersion(), XF86VidModeSetClientVersion(), XF86VidModeGetModeLine(), XF86VidModeGetAllModeLines(), XF86VidModeAddModeLine(), XF86VidModeDeleteModeLine(), XF86VidModeModModeLine(), XF86VidModeValidateModeLine(), XF86VidModeSwitchMode(), XF86VidModeSwitchToMode(), XF86VidModeLockModeSwitch(), XF86VidModeGetMonitor(), XF86VidModeGetViewPort(), XF86VidModeSetViewPort(), XF86VidModeGetDotClocks(), XF86VidModeGetGamma(), XF86VidModeSetGamma(), XF86VidModeGetGammaRamp(), XF86VidModeSetGammaRamp(), XF86VidModeGetGammaRampSize().

The extension provides a mechanism for clients to control the video hardware, including changing screen resolution, refresh rate, and gamma correction. It is intended to provide a more robust and flexible way to manage video modes than the older XFree86-DPMS extension.

The X server communicates with the video hardware through a variety of drivers. The XFree86-VidMode extension abstracts away the differences between these drivers, providing a consistent interface for clients.

The extension also defines a set of events that are generated by the server when certain video-related events occur, such as a change in video mode or gamma ramp. Clients can listen for these events to stay informed about the state of the video hardware.

RETURN VALUES

All functions return a boolean value indicating success or failure, except for XF86VidModeValidateModeLine(), which returns a status code, and XF86VidModeGetGammaRampSize(), XF86VidModeGetDotClocks(), XF86VidModeGetAllModeLines(), which return additional information through pointer arguments.

ERRORS

The XFree86-VidMode extension defines its own error codes, which are returned by the functions when an error occurs. These error codes are defined in the <X11/extensions/xf86vmode.h> header file.

DESCRIPTION

Ces fonctions fournissent une interface à l'extension XFree86-VidModeExtension du serveur, qui permet de consulter et d'ajuster dynamiquement les modes vidéo et de contrôler la commutation des modes. Les applications qui utilisent ces fonctions doivent être liées avec -lXxf86vm

FONCTIONS DE MODELINE

La fonction XF86VidModeGetModeLine est utilisée pour interroger les paramètres du mode vidéo actuellement sélectionné. Le programme appelant doit passer un pointeur vers une structure XF86VidModeModeLine qu'il a déjà allouée. La fonction remplit les champs de la structure.

S'il existe des valeurs privées du serveur (actuellement applicables uniquement au serveur S3), la fonction allouera de l'espace pour elles. Par conséquent, si le champ privsize est différent de zéro, le programme appelant doit appeler Xfree(private) pour libérer l'espace.

XF86VidModeGetAllModeLines renvoie les paramètres de tous les modes vidéo. Le programme appelant fournit l'adresse d'un pointeur qui sera défini par la fonction pour pointer vers un tableau de structures XF86VidModeModeInfo. La mémoire occupée par le tableau est allouée dynamiquement par la fonction XF86VidModeGetAllModeLines et doit être libérée par l'appelant. Le premier élément du tableau correspond au mode vidéo actuel.

La fonction XF86VidModeModModeLine peut être utilisée pour modifier les paramètres du mode vidéo actuel, à condition que les paramètres demandés soient valides (par exemple, qu'ils ne dépassent pas les capacités du moniteur).

Pour ajouter un mode à la liste des modes disponibles, la fonction XF86VidModeAddModeLine peut être utilisée. En supposant que les paramètres sont valides, le mode vidéo sera ajouté après le mode existant qui correspond aux temporisations spécifiées par le paramètre aftermode. Pour être considéré comme une correspondance, tous les champs de la structure XF86VidModeModeInfo fournie doivent correspondre, à l'exception des champs privsize et private. Si le paramètre aftermode est zéro, le mode sera ajouté après le mode actuel.

Les modes peuvent être supprimés avec la fonction XF86VidModeDeleteModeLine. Le mode spécifié doit correspondre à un mode existant. Pour être considéré comme une correspondance, tous les champs de la structure XF86VidModeModeInfo fournie doivent correspondre, à l'exception des champs privsize et private. Si le mode à supprimer est le mode actuel, une commutation de mode vers le mode suivant se produira d'abord. Le dernier mode restant ne peut pas être supprimé.

La validité d'un mode peut être vérifiée avec la fonction XF86VidModeValidateModeLine. Si le mode spécifié peut être utilisé par le serveur (c'est-à-dire qu'il répond à toutes les contraintes imposées à un mode par la combinaison du serveur, de la carte et du moniteur), la fonction renvoie MODE_OK, sinon elle renvoie une valeur indiquant la raison pour laquelle le mode est invalide (telle que définie dans xf86.h)

FONCTIONS DE COMMUTATION DE MODE

Lorsque la fonction XF86VidModeSwitchMode est appelée, le serveur change le mode vidéo pour le mode vidéo suivant (ou précédent). La fonction XF86VidModeSwitchToMode peut être utilisée pour basculer directement vers le mode spécifié. La correspondance est telle que spécifié dans la description de la fonction XF86VidModeAddModeLine ci-dessus. La fonction XF86VidModeLockModeSwitch peut être utilisée pour autoriser ou interdire la commutation de mode, que la demande de commutation de mode provienne d'un appel aux fonctions XF86VidModeSwitchMode ou XF86VidModeSwitchToMode ou de l'une des séquences de touches de commutation de mode.

Remarque : En raison de la nature asynchrone du protocole X, un appel à XFlush est nécessaire si l'application souhaite voir le changement de mode immédiatement. Pour être informé de l'état d'exécution de la requête, un gestionnaire d'erreurs personnalisé doit être installé en utilisant XSetErrorHandler avant d'appeler la fonction de commutation de mode.

FONCTIONS DE MONITEUR

Les informations connues du serveur concernant le moniteur sont renvoyées par la fonction XF86VidModeGetMonitor. Les champs hsync et vsync pointent chacun vers un tableau de structures XF86VidModeSyncRange. Les tableaux contiennent respectivement nhsync et nvsync éléments. Les valeurs hi et lo seront égales si une valeur discrète a été donnée dans le fichier XF86Config.

Les champs vendor, model, hsync et vsync pointent vers un espace de stockage alloué dynamiquement qui devrait être libéré par l'appelant.

FONCTIONS DE VUE

Les fonctions XF86VidModeGetViewPort et XF86VidModeSetViewPort peuvent être utilisées pour, respectivement, interroger et modifier l'emplacement du coin supérieur gauche de la vue dans l'écran virtuel.

AUTRES FONCTIONS

La fonction XF86VidModeQueryVersion peut être utilisée pour déterminer la version de l'extension intégrée au serveur.

La fonction XF86VidModeQueryExtension renvoie les numéros d'erreur et d'événement les plus bas assignés à l'extension.

En attendant, consultez le code source pour obtenir des informations sur la façon de les utiliser.
