XWarpPointer(3) FONCTIONS XLIB XWarpPointer(3)

NOM

XWarpPointer - déplacer le pointeur

SYNTAXE

int XWarpPointer(Display *display, Window src_w, Window dest_w, int src_x, int src_y, unsigned int src_width, unsigned int src_height, int dest_x, int dest_y);

ARGUMENTS

dest_w
Spécifie la fenêtre de destination ou None.
dest_x

dest_y
Spécifie les coordonnées x et y dans la fenêtre de destination.
display
Spécifie la connexion au serveur X.
src_x

src_y

src_width

src_height
Spécifie un rectangle dans la fenêtre source.
src_w
Spécifie la fenêtre source ou None.

DESCRIPTION

Si dest_w est None, XWarpPointer déplace le pointeur des décalages (dest_x, dest_y) par rapport à la position actuelle du pointeur. Si dest_w est une fenêtre, XWarpPointer déplace le pointeur vers les décalages (dest_x, dest_y) par rapport à l'origine de dest_w. Cependant, si src_w est une fenêtre, le déplacement n'a lieu que si la fenêtre src_w contient le pointeur et si le rectangle spécifié de src_w contient le pointeur.

Les coordonnées src_x et src_y sont relatives à l'origine de src_w. Si src_height est zéro, il est remplacé par la hauteur actuelle de src_w moins src_y. Si src_width est zéro, il est remplacé par la largeur actuelle de src_w moins src_x.

Il y a rarement une raison d'appeler cette fonction. Le pointeur doit normalement être laissé à l'utilisateur. Si vous utilisez cette fonction, cependant, elle génère des événements comme si l'utilisateur avait instantanément déplacé le pointeur d'une position à une autre. Notez que vous ne pouvez pas utiliser XWarpPointer pour déplacer le pointeur à l'extérieur de la fenêtre de confinement d'une saisie de pointeur active. Une tentative de le faire ne déplacera le pointeur qu'aussi loin que le bord le plus proche de la fenêtre de confinement.

XWarpPointer peut générer une erreur BadWindow.

DIAGNOSTICS

BadWindow
Une valeur pour un argument Window ne nomme pas une Window définie.
