NOM

Xorg.wrap - wrapper binaire du serveur X Xorg

DESCRIPTION

Le serveur X Xorg peut nécessiter des droits root pour fonctionner correctement. Pour démarrer le serveur X Xorg avec ces droits, votre système utilise un wrapper suid root installé sous le nom /usr/libexec/Xorg.wrap qui exécutera le vrai serveur X installé sous le nom /usr/libexec/Xorg.

Par défaut, Xorg.wrap détectera automatiquement si des droits root sont nécessaires, et si ce n'est pas le cas, il abandonnera ses droits élevés avant de démarrer le vrai serveur X. Par défaut, Xorg.wrap n'autorisera que l'exécution du vrai serveur X à partir de sessions de connexion sur une console physique.

FICHIER DE CONFIGURATION

Le comportement par défaut de Xorg.wrap peut être remplacé par le fichier de configuration /etc/X11/Xwrapper.config. Les lignes commençant par un # dans Xwrapper.config sont considérées comme des commentaires et seront ignorées. Toute autre ligne non vide doit prendre la forme clé = valeur.

allowed_users = rootonly|console|anybody
Spécifiez quels utilisateurs peuvent démarrer le serveur X via le wrapper. Utilisez rootonly pour n'autoriser que root, console pour n'autoriser que les utilisateurs connectés sur une console physique, et anybody pour autoriser tout le monde. La valeur par défaut est console.
needs_root_rights = yes|no|auto
Configurez si le wrapper doit abandonner ses droits élevés (root) avant de démarrer le serveur X. Utilisez yes pour forcer l'exécution en tant que root, no pour forcer l'exécution avec tous les droits suid abandonnés, et auto pour laisser le wrapper détecter automatiquement. La valeur par défaut est auto.

Lors de la détection automatique, le wrapper abandonnera les droits si le graphique KMS (Kernel Mode Setting) est disponible et ne les abandonnera pas si aucun graphique KMS n'est détecté. Si un système possède plusieurs cartes graphiques et que certaines ne sont pas compatibles KMS, la détection automatique peut échouer. Dans ce cas, une configuration manuelle devrait être utilisée.
