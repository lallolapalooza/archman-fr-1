XIconifyWindow(3) FONCTIONS XLIB XIconifyWindow(3)

NOM

XIconifyWindow, XWithdrawWindow, XReconfigureWMWindow - manipuler les fenêtres de niveau supérieur

SYNTAXE

Status XIconifyWindow(Display *display, Window w, int screen_number);

Status XWithdrawWindow(Display *display, Window w, int screen_number);

Status XReconfigureWMWindow(Display *display, Window w, int screen_number, unsigned int value_mask, XWindowChanges *values);

ARGUMENTS

display
Spécifie la connexion au serveur X.
screen_number
Spécifie le numéro d'écran approprié sur le serveur hôte.
value_mask
Spécifie quelles valeurs doivent être définies en utilisant les informations de la structure values. Ce masque est le OU exclusif bit à bit des bits valides de valeurs de configuration de fenêtre.
values
Spécifie la structure XWindowChanges.
w
Spécifie la fenêtre.

DESCRIPTION

La fonction XIconifyWindow envoie un événement ClientMessage WM_CHANGE_STATE avec un format de 32 et un premier élément de données de IconicState (tel que décrit dans la section 4.1.4 du Inter-Client Communication Conventions Manual) et une fenêtre w à la fenêtre racine de l'écran spécifié avec un masque d'événements défini à SubstructureNotifyMask| SubstructureRedirectMask. Les gestionnaires de fenêtres peuvent choisir de recevoir ce message et, si la fenêtre est dans son état normal, peuvent le traiter comme une requête pour changer l'état de la fenêtre de normal à iconique. Si la propriété WM_CHANGE_STATE ne peut être internée, XIconifyWindow n'envoie pas de message et retourne un statut nul. Elle retourne un statut non nul si le message client est envoyé avec succès ; sinon, elle retourne un statut nul.

La fonction XWithdrawWindow dés-annexe la fenêtre spécifiée et envoie un événement synthétique UnmapNotify à la fenêtre racine de l'écran spécifié. Les gestionnaires de fenêtres peuvent choisir de recevoir ce message et peuvent le traiter comme une requête pour changer l'état de la fenêtre à retiré. Lorsqu'une fenêtre est dans l'état retiré, ni sa représentation normale ni sa représentation iconique n'est visible. Elle retourne un statut non nul si l'événement UnmapNotify est envoyé avec succès ; sinon, elle retourne un statut nul.

XWithdrawWindow peut générer une erreur BadWindow.

La fonction XReconfigureWMWindow émet une requête ConfigureWindow sur la fenêtre de niveau supérieur spécifiée. Si le mode d'empilement est modifié et que la requête échoue avec une erreur BadMatch, l'erreur est interceptée par Xlib et un événement synthétique ConfigureRequestEvent contenant les mêmes paramètres de configuration est envoyé à la racine de la fenêtre spécifiée. Les gestionnaires de fenêtres peuvent choisir de recevoir cet événement et de le traiter comme une requête pour reconfigurer la fenêtre indiquée. Elle retourne un statut non nul si la requête ou l'événement est envoyé avec succès ; sinon, elle retourne un statut nul.

XReconfigureWMWindow peut générer des erreurs BadValue et BadWindow.

DIAGNOSTICS

BadValue
Une valeur numérique est en dehors de la plage de valeurs acceptées par la requête. Sauf si une plage spécifique est définie pour un argument, la plage complète définie par le type de l'argument est acceptée. Tout argument défini comme un ensemble d'alternatives peut générer cette erreur.
BadWindow
Une valeur pour un argument Window ne nomme pas une Window définie.
