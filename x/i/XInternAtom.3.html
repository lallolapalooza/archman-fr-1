XInternAtom(3) FONCTIONS XLIB XInternAtom(3)

NOM

XInternAtom, XInternAtoms, XGetAtomName, XGetAtomNames - créer ou retourner des noms d'atomes

SYNTAXE

Atom XInternAtom(Display *display, _Xconst char *atom_name, Bool only_if_exists);

Status XInternAtoms(Display *display, char **names, int count, Bool only_if_exists, Atom *atoms_return);

char *XGetAtomName(Display *display, Atom atom);

Status XGetAtomNames(Display *display, Atom *atoms, int count, char **names_return);

ARGUMENTS

atome
Spécifie l'atome dont vous voulez retourner le nom de propriété.
atomes
Spécifie le tableau d'atomes.
nom_atome
Spécifie le nom associé à l'atome dont vous voulez retourner le nom.
retour_atomes
Retourne les atomes.
compte
Spécifie le nombre de noms d'atomes dans le tableau.
affichage
Spécifie la connexion au serveur X.
noms
Spécifie le tableau de noms d'atomes.
retour_noms
Retourne les noms d'atomes.
seulement_si_existant
Spécifie une valeur booléenne indiquant si l'atome doit être créé.

DESCRIPTION

La fonction XInternAtom retourne l'identifiant d'atome associé à la chaîne de nom d'atome spécifiée. Si only_if_exists est False, l'atome est créé s'il n'existe pas. Par conséquent, XInternAtom peut retourner None. Si le nom de l'atome n'est pas dans le jeu de caractères portable de l'hôte (Host Portable Character Encoding), le résultat dépend de l'implémentation. La casse est importante ; les chaînes « thing », « Thing » et « thinG » désignent toutes des atomes différents. L'atome restera défini même après la fermeture de la connexion du client. Il ne sera désigné que lorsque la dernière connexion au serveur X sera fermée.

XInternAtom peut générer des erreurs BadAlloc et BadValue.

La fonction XInternAtoms retourne les identifiants d'atomes associés aux noms spécifiés. Les atomes sont stockés dans le tableau atoms_return fourni par l'appelant. L'appel de cette fonction équivaut à appeler XInternAtom pour chacun des noms tour à tour avec la valeur spécifiée de only_if_exists, mais cette fonction minimise le nombre d'échanges de protocoles aller-retour entre le client et le serveur X.

Cette fonction retourne une valeur différente de zéro si des atomes sont retournés pour tous les noms ; sinon, elle retourne zéro.

XInternAtoms peut générer des erreurs BadAlloc et BadValue.

La fonction XGetAtomName retourne le nom associé à l'atome spécifié. Si les données retournées par le serveur sont dans le jeu de caractères portable Latin (Latin Portable Character Encoding), alors la chaîne retournée est dans le jeu de caractères portable de l'hôte (Host Portable Character Encoding). Sinon, le résultat dépend de l'implémentation. Pour libérer la chaîne résultante, appelez XFree.

XGetAtomName peut générer une erreur BadAtom.

La fonction XGetAtomNames retourne les noms associés aux atomes spécifiés. Les noms sont stockés dans le tableau names_return fourni par l'appelant. L'appel de cette fonction équivaut à appeler XGetAtomName pour chacun des atomes tour à tour, mais cette fonction minimise le nombre d'échanges de protocoles aller-retour entre le client et le serveur X.

Cette fonction retourne une valeur différente de zéro si des noms sont retournés pour tous les atomes ; sinon, elle retourne zéro.

XGetAtomNames peut générer une erreur BadAtom.

DIAGNOSTICS

BadAlloc
Le serveur n'a pas pu allouer la ressource demandée ou la mémoire du serveur.
BadAtom
Une valeur pour un argument Atom ne nomme pas un Atome défini.
BadValue
Une valeur numérique tombe en dehors de la plage acceptée par la requête. Sauf si une plage spécifique est spécifiée pour un argument, la plage complète définie par le type de l'argument est acceptée. Tout argument défini comme un ensemble d'alternatives peut générer cette erreur.
