NOM

XIChangeHierarchy - modifier la hiérarchie des périphériques.

SYNTAXE

#include <X11/extensions/XInput2.h>
Status XIChangeHierarchy( Display *display,
                          XIAnyHierarchyChangeInfo *changes,
                          int num_changes);
display
       Spécifie la connexion au serveur X.
num_changes
       Spécifie le nombre d'éléments dans changes.
changes
       Spécifie les modifications à apporter.

DESCRIPTION

XIChangeHierarchy modifie la hiérarchie des périphériques en créant ou
en supprimant des périphériques maîtres ou en changeant l'attachement des
périphériques esclaves. Si num_changes est différent de zéro, changes est un
tableau de structures XIAnyHierarchyChangeInfo. Si num_changes est égal ou
inférieur à zéro, XIChangeHierarchy ne fait rien.
XIChangeHierarchy traite les modifications dans l'ordre, avec prise d'effet
immédiate. Si une erreur se produit, le traitement est interrompu et l'erreur
est signalée au client. Les modifications déjà effectuées restent effectives.
La liste des modifications est toute combinaison de
XIAnyHierarchyChangeInfo. Le type d'une modification de hiérarchie peut être
XIAddMaster, XIRemoveMaster, XIAttachSlave ou XIDetachSlave.
typedef union {
    int type;
    XIAddMasterInfo add;
    XIRemoveMasterInfo remove;
    XIAttachSlave attach;
    XIDetachSlave detach;
} XIAnyHierarchyChangeInfo;
typedef struct {
    int type; /* XIAddMaster */
    char* name;
    Bool send_core;
    Bool enable;
} XIAddMasterInfo;
typedef struct {
    int type; /* XIRemoveMaster */
    int deviceid;
    int return_mode;
    int return_pointer;
    int return_keyboard;
} XIRemoveMasterInfo;
typedef struct {
    int type; /* XIAttachSlave */
    int deviceid;
    int new_master;
} XIAttachSlaveInfo;
typedef struct {
    int type; /* XIDetachSlave */
    int deviceid;
} XIDetachSlaveInfo;
XIAddMasterInfo crée un nouveau pointeur maître et un nouveau clavier maître
appelés respectivement "name pointer" et "name keyboard".
Si sendCore est True, les périphériques enverront des événements core. Si
enable est True, le périphérique est activé immédiatement.
XIAddMasterInfo peut générer une erreur BadValue.
XIRemoveMasterInfo supprime le périphérique et son périphérique maître associé.
Si returnMode est XIAttachToMaster, tous les pointeurs attachés au
périphérique ou à son périphérique maître associé sont attachés à
returnPointer. De même, tous les claviers sont attachés à
returnKeyboard. Si returnMode est XIFloating, tous les périphériques attachés
sont mis en mode flottant.
XIRemoveMasterInfo peut générer une erreur BadValue et BadDevice.
XIAttachSlaveInfo attache le périphérique à new_master. Si le périphérique est
actuellement attaché à un périphérique maître, il est détaché du
périphérique maître et attaché au nouveau périphérique maître.
XIAttachSlaveInfo peut générer une erreur BadDevice.
XIDetachSlaveInfo détache le périphérique de son périphérique maître actuel
et le met en mode flottant. Si le périphérique est déjà en mode flottant,
aucun changement n'est apporté.
XIDetachSlaveInfo peut générer une erreur BadDevice.
XIChangeHierarchy génère un XIHierarchyEvent si des modifications ont été
réalisées avec succès.

DIAGNOSTICS

BadDevice
       Un périphérique invalide a été spécifié. Le périphérique
       n'existe pas ou n'est pas approprié pour le type de modification.
BadValue
       Une valeur numérique est en dehors de la plage autorisée.
