NOM

XIWarpPointer - déplace le pointeur d'un périphérique.

SYNTAXE

#include <X11/extensions/XInput2.h>
Bool XIWarpPointer( Display *display,
                    int deviceid,
                    Window src_w,
                    Window dest_w,
                    double src_x,
                    double src_y,
                    int src_width,
                    int src_height,
                    double dest_x,
                    double dest_y);
dest_w
       Spécifie la fenêtre de destination ou None.
dest_x, dest_y
       Spécifient les coordonnées x et y dans la fenêtre de destination.
deviceid
       Spécifie le périphérique pointeur maître ou l'esclave flottant
       à déplacer.
display
       Spécifie la connexion au serveur X.
src_x, src_y, src_width, src_height
       Spécifient un rectangle dans la fenêtre source.
src_w
       Spécifie la fenêtre source ou None.

DESCRIPTION

Si dest_w est None, XIWarpPointer déplace le pointeur des
décalages (dest_x, dest_y) par rapport à la position actuelle du
pointeur. Si dest_w est une fenêtre, XIWarpPointer déplace le
pointeur aux décalages (dest_x, dest_y) par rapport à l'origine
de dest_w. Cependant, si src_w est une fenêtre, le déplacement n'a
lieu que si la fenêtre src_w contient le pointeur et si le
rectangle spécifié de src_w contient le pointeur.
Les coordonnées src_x et src_y sont relatives à l'origine de
src_w. Si src_height est zéro, il est remplacé par la hauteur
actuelle de src_w moins src_y. Si src_width est zéro, il est
remplacé par la largeur actuelle de src_w moins src_x.
Il y a rarement une raison d'appeler cette fonction. Le
pointeur doit normalement être laissé à l'utilisateur. Si vous
utilisez cette fonction, cependant, elle génère des événements
comme si l'utilisateur avait instantanément déplacé le pointeur
d'une position à une autre. Notez que vous ne pouvez pas utiliser
XIWarpPointer pour déplacer le pointeur en dehors de la fenêtre
confine_to d'un pointeur actif capturé. Une tentative de le faire
ne déplacera le pointeur qu'aussi loin que le bord le plus
proche de la fenêtre confine_to.
XIWarpPointer est identique à XWarpPointer mais spécifie le
périphérique explicitement.
XIWarpPointer peut générer une erreur BadDevice et une erreur
BadWindow.

DIAGNOSTICS

BadDevice
       Un périphérique invalide a été spécifié. Le périphérique n'existe
       pas ou n'est pas un périphérique pointeur.
BadWindow
       Une valeur pour un argument Window ne nomme pas une fenêtre
       définie.
