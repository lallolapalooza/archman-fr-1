XIDEFINECURSOR(3)   XIDEFINECURSOR(3)

NOM

XIDefineCursor, XIUndefineCursor - définir les curseurs de périphérique.

SYNTAXE

#include <X11/extensions/XInput2.h>
int XIDefineCursor( Display *display,
                    int deviceid,
                    Window win,
                    Cursor cursor);
int XIUndefineCursor( Display *display,
                      int deviceid,
                      Window win);
cursor
       Spécifie le curseur qui doit être affiché ou None.
deviceid
       Spécifie le périphérique dont le curseur doit changer.
display
       Spécifie la connexion au serveur X.
win
       Spécifie la fenêtre.

DESCRIPTION

Si un curseur est défini, il sera utilisé lorsque le pointeur du périphérique
se trouve dans la fenêtre. Si le curseur est None, cela est équivalent à
XIUndefineCursor.
Le deviceid doit être un périphérique pointeur maître ou une erreur BadDevice
est retournée.
XIDefineCursor peut générer BadDevice, BadCursor et BadWindow.
La fonction XIUndefineCursor annule l'effet d'un précédent
XIDefineCursor pour cette fenêtre. Lorsque le pointeur se trouve dans la
fenêtre, le curseur par défaut de la fenêtre sera maintenant utilisé. Si aucun
curseur par défaut n'est défini, le curseur du parent pour ce périphérique
sera utilisé (s'il est défini) ou le curseur par défaut du parent sera
utilisé.
XIDefineCursor et XIUndefineCursor sont identiques à
XDefineCursor et XUndefineCursor mais spécifient le périphérique
explicitement.
XIUndefineCursor peut générer une erreur BadDevice et BadWindow.

DIAGNOSTICS

BadCursor
       Une valeur pour un argument de curseur ne nomme pas un curseur
       défini.
BadDevice
       Un périphérique invalide a été spécifié. Le périphérique
       n'existe pas ou n'est pas un périphérique pointeur.
BadWindow
       Une valeur pour un argument Window ne nomme pas une fenêtre
       définie.
