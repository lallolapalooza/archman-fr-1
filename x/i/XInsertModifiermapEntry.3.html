XChangeKeyboardMapping(3) FONCTIONS XLIB XChangeKeyboardMapping(3)

NOM

XChangeKeyboardMapping, XGetKeyboardMapping, XDisplayKeycodes, XSetModifierMapping, XGetModifierMapping, XNewModifiermap, XInsertModifiermapEntry, XDeleteModifiermapEntry, XFreeModifiermap, XModifierKeymap - manipuler l'encodage du clavier et la structure d'encodage du clavier

SYNTAXE

int XChangeKeyboardMapping(Display *display, int first_keycode, int keysyms_per_keycode, KeySym *keysyms, int num_codes);

KeySym *XGetKeyboardMapping(Display *display, KeyCode first_keycode, int keycode_count, int *keysyms_per_keycode_return);

int XDisplayKeycodes(Display *display, int *min_keycodes_return, int *max_keycodes_return);

int XSetModifierMapping(Display *display, XModifierKeymap *modmap);

XModifierKeymap *XGetModifierMapping(Display *display);

XModifierKeymap *XNewModifiermap(int max_keys_per_mod);

XModifierKeymap *XInsertModifiermapEntry(XModifierKeymap *modmap, KeyCode keycode_entry, int modifier);

XModifierKeymap *XDeleteModifiermapEntry(XModifierKeymap *modmap, KeyCode keycode_entry, int modifier);

int XFreeModifiermap(XModifierKeymap *modmap);

ARGUMENTS

display
Spécifie la connexion au serveur X.
first_keycode
Spécifie le premier KeyCode à modifier ou à retourner.
keycode_count
Spécifie le nombre de KeyCodes à retourner.
keycode_entry
Spécifie le KeyCode.
keysyms
Spécifie un tableau de KeySyms.
keysyms_per_keycode
Spécifie le nombre de KeySyms par KeyCode.
keysyms_per_keycode_return
Retourne le nombre de KeySyms par KeyCode.
max_keys_per_mod
Spécifie le nombre d'entrées KeyCode pré-allouées aux modificateurs dans la carte.
max_keycodes_return
Retourne le nombre maximum de KeyCodes.
min_keycodes_return
Retourne le nombre minimum de KeyCodes.
modifier
Spécifie le modificateur.
modmap
Spécifie la structure XModifierKeymap.
num_codes
Spécifie le nombre de KeyCodes à modifier.

DESCRIPTION

La fonction XChangeKeyboardMapping définit les symboles pour le nombre spécifié de KeyCodes à partir de first_keycode. Les symboles pour les KeyCodes en dehors de cette plage restent inchangés. Le nombre d'éléments dans keysyms doit être :

num_codes * keysyms_per_keycode

Le first_keycode spécifié doit être supérieur ou égal à min_keycode retourné par XDisplayKeycodes, sinon une erreur BadValue se produit. De plus, l'expression suivante doit être inférieure ou égale à max_keycode tel que retourné par XDisplayKeycodes, sinon une erreur BadValue se produit :

first_keycode + num_codes - 1

Le symbole N, en comptant à partir de zéro, pour le KeyCode K a l'index suivant dans keysyms, en comptant à partir de zéro :

(K - first_keycode) * keysyms_per_keycode + N

La valeur keysyms_per_keycode spécifiée peut être choisie arbitrairement par le client pour être suffisamment grande pour contenir tous les symboles désirés. Une valeur KeySym spéciale de NoSymbol doit être utilisée pour remplir les éléments inutilisés pour les KeyCodes individuels. Il est légal que NoSymbol apparaisse dans les positions non finales de la liste effective pour un KeyCode. XChangeKeyboardMapping génère un événement MappingNotify.

Il n'y a aucune obligation que le serveur X interprète ce mappage. Il est simplement stocké pour être lu et écrit par les clients.

XChangeKeyboardMapping peut générer des erreurs BadAlloc et BadValue.

La fonction XGetKeyboardMapping retourne les symboles pour le nombre spécifié de KeyCodes à partir de first_keycode. La valeur spécifiée dans first_keycode doit être supérieure ou égale à min_keycode tel que retourné par XDisplayKeycodes, sinon une erreur BadValue se produit. De plus, l'expression suivante doit être inférieure ou égale à max_keycode tel que retourné par XDisplayKeycodes :

first_keycode + keycode_count - 1

Si ce n'est pas le cas, une erreur BadValue se produit. Le nombre d'éléments dans la liste KeySyms est :

keycode_count * keysyms_per_keycode_return

Le symbole N, en comptant à partir de zéro, pour le KeyCode K a l'index suivant dans la liste, en comptant à partir de zéro :

(K - first_code) * keysyms_per_code_return + N

Le serveur X choisit arbitrairement la valeur keysyms_per_keycode_return pour qu'elle soit suffisamment grande pour rapporter tous les symboles demandés. Une valeur KeySym spéciale de NoSymbol est utilisée pour remplir les éléments inutilisés pour les KeyCodes individuels. Pour libérer l'espace alloué retourné par XGetKeyboardMapping, utilisez XFree.

XGetKeyboardMapping peut générer une erreur BadValue.

La fonction XDisplayKeycodes retourne les min-keycodes et max-keycodes supportés par le display spécifié. Le nombre minimum de KeyCodes retournés n'est jamais inférieur à 8, et le nombre maximum de KeyCodes retournés n'est jamais supérieur à 255. Tous les KeyCodes de cette plage n'ont pas forcément de touches correspondantes.

La fonction XSetModifierMapping spécifie les KeyCodes des touches (le cas échéant) qui doivent être utilisées comme modificateurs. Si elle réussit, le serveur X génère un événement MappingNotify, et XSetModifierMapping retourne MappingSuccess. X autorise au plus 8 touches modificatrices. Si plus de 8 sont spécifiées dans la structure XModifierKeymap, une erreur BadLength se produit.

Le membre modifiermap de la structure XModifierKeymap contient 8 ensembles de KeyCodes max_keypermod, un pour chaque modificateur dans l'ordre Shift, Lock, Control, Mod1, Mod2, Mod3, Mod4 et Mod5. Seuls les KeyCodes non nuls ont un sens dans chaque ensemble, et les KeyCodes nuls sont ignorés. De plus, tous les KeyCodes non nuls doivent être dans la plage spécifiée par min_keycode et max_keycode dans la structure Display, sinon une erreur BadValue se produit.

Un serveur X peut imposer des restrictions sur la manière dont les modificateurs peuvent être modifiés, par exemple, si certaines touches ne génèrent pas de transitions "up" au niveau matériel, si l'auto-répétition ne peut pas être désactivée sur certaines touches, ou si plusieurs touches modificatrices ne sont pas supportées. Si une telle restriction est violée, la réponse de statut est MappingFailed, et aucun des modificateurs n'est modifié. Si les nouveaux KeyCodes spécifiés pour un modificateur diffèrent de ceux actuellement définis et que des touches (actuelles ou nouvelles) pour ce modificateur sont dans l'état logiquement enfoncé, XSetModifierMapping retourne MappingBusy, et aucun des modificateurs n'est modifié.

XSetModifierMapping peut générer des erreurs BadAlloc et BadValue.

La fonction XGetModifierMapping retourne un pointeur vers une structure XModifierKeymap nouvellement créée qui contient les touches utilisées comme modificateurs. La structure doit être libérée après utilisation en appelant XFreeModifiermap. Si seules des valeurs nulles apparaissent dans l'ensemble pour un modificateur, ce modificateur est désactivé.

La fonction XNewModifiermap retourne un pointeur vers la structure XModifierKeymap pour une utilisation ultérieure.

La fonction XInsertModifiermapEntry ajoute le KeyCode spécifié à l'ensemble qui contrôle le modificateur spécifié et retourne la structure résultante XModifierKeymap (agrandie si nécessaire).

La fonction XDeleteModifiermapEntry supprime le KeyCode spécifié de l'ensemble qui contrôle le modificateur spécifié et retourne un pointeur vers la structure XModifierKeymap résultante.

XInsertModifiermapEntry(3) - Arch Linux

NAME

XInsertModifiermapEntry, XRemoveModifiermapEntry, XDeleteModifiermapEntry - modifier map manipulation routines

SYNTAX

#include <X11/Xlib.h>
#include <X11/Xutil.h>

int XInsertModifiermapEntry(
    XModifierKeymap *modmap,
    KeyCode key_code,
    int modifier);

int XRemoveModifiermapEntry(
    XModifierKeymap *modmap,
    KeyCode key_code,
    int modifier);

int XDeleteModifiermapEntry(
    XModifierKeymap *modmap,
    KeyCode key_code,
    int modifier);

ARGUMENTS

modmap
Specifies the modifier map to be modified.
key_code
Specifies the keycode to be added or removed.
modifier
Specifies the modifier modifier keycode represents. This must be one of MODIFIERS.

DESCRIPTION

The function XInsertModifiermapEntry inserts the specified key_code into the modmap for the specified modifier. If the specified modifier already has the maximum number of keys associated with it, the function returns 0, otherwise it returns 1.

The function XRemoveModifiermapEntry removes the specified key_code from the modmap for the specified modifier. If the keycode is not found, it returns 0, otherwise it returns 1.

The function XDeleteModifiermapEntry removes the specified key_code from the modmap for the specified modifier. This function is identical to XRemoveModifiermapEntry.

The function XFreeModifiermap frees the specified XModifierKeymap structure.

STRUCTURES

The XModifierKeymap structure contains:

typedef struct {
        int max_keypermod;      /* This server's max number of keys per modifier */
        KeyCode *modifiermap;   /* An 8 by max_keypermod array of the modifiers */
} XModifierKeymap;

DIAGNOSTICS

BadAlloc
The server failed to allocate the requested resource or server memory.
BadValue
Some numeric value falls outside the range of values accepted by the request. Unless a specific range is specified for an argument, the full range defined by the argument's type is accepted. Any argument defined as a set of alternatives can generate this error.

typedef struct {
