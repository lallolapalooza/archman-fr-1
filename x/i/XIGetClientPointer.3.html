XISETCLIENTPOINTER(3)   XISETCLIENTPOINTER(3)

NOM

XISetClientPointer, XIGetClientPointer - définir ou obtenir le périphérique ClientPointer.

SYNTAXE

#include <X11/extensions/XInput2.h>
XISetClientPointer( Display *display,
                    Window win,
                    int deviceid);
Bool XIGetClientPointer( Display *display,
                         Window win,
                         int *device);
display
       Spécifie la connexion au serveur X.
win
       Spécifie une fenêtre appartenant au client. Peut être None.
deviceid
       Spécifie le périphérique ClientPointer.

DESCRIPTION

Le ClientPointer est le périphérique perçu comme étant le pointeur principal
pour les requêtes et réponses non-XI du protocole. Chaque fois qu'un message
de protocole a besoin de données dépendantes du périphérique et que le
périphérique n'est pas explicitement donné, le périphérique ClientPointer est
utilisé pour obtenir les données. Par exemple, une requête XQueryPointer
renverra les coordonnées du ClientPointer.
XISetClientPointer demande la définition du périphérique ClientPointer pour
le client propriétaire de la fenêtre donnée. Si win est None, le ClientPointer
du client demandeur est défini sur le périphérique spécifié par deviceid. Seuls
les périphériques pointeurs maîtres peuvent être définis comme ClientPointer.
XISetClientPointer peut générer des erreurs BadDevice et BadWindow.
La requête XIGetClientPointer renvoie l'ID du périphérique ClientPointer
pour le client propriétaire de la fenêtre donnée. Si win est None, le
ClientPointer du client demandeur est renvoyé.
win peut être un ID de client au lieu d'une fenêtre.
XIGetClientPointer peut générer une erreur BadWindow.

DIAGNOSTICS

BadDevice
       Un périphérique invalide a été spécifié. Le périphérique n'existe pas
       ou n'est pas un périphérique pointeur maître.
BadWindow
       Une valeur pour un argument Window ne nomme pas une fenêtre définie.
