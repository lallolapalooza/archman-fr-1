XIfEvent(3) FONCTIONS XLIB XIfEvent(3)

NOM

XIfEvent, XCheckIfEvent, XPeekIfEvent - vérifient la file d'attente d'événements avec une procédure prédicat

SYNTAXE

int XIfEvent(Display *display, XEvent *event_return, Bool (*predicate)(), XPointer arg);

Bool XCheckIfEvent(Display *display, XEvent *event_return, Bool (*predicate)(), XPointer arg);

int XPeekIfEvent(Display *display, XEvent *event_return, Bool (*predicate)(), XPointer arg);

ARGUMENTS

arg
Spécifie l'argument fourni par l'utilisateur qui sera passé à la procédure prédicat.
display
Spécifie la connexion au serveur X.
event_return
Retourne soit une copie, soit la structure associée à l'événement correspondant.
predicate
Spécifie la procédure à appeler pour déterminer si le prochain événement dans la file d'attente correspond à ce que vous recherchez.

DESCRIPTION

La fonction XIfEvent ne se termine que lorsque la procédure prédicat spécifiée renvoie True pour un événement, ce qui indique qu'un événement dans la file d'attente correspond. XIfEvent vide le tampon de sortie si elle se bloque en attendant d'autres événements. XIfEvent retire l'événement correspondant de la file d'attente et copie la structure dans la structure XEvent fournie par le client.

Lorsque la procédure prédicat trouve une correspondance, XCheckIfEvent copie l'événement correspondant dans la structure XEvent fournie par le client et renvoie True. (Cet événement est retiré de la file d'attente.) Si la procédure prédicat ne trouve aucune correspondance, XCheckIfEvent renvoie False et le tampon de sortie aura été vidé. Tous les événements précédents stockés dans la file d'attente ne sont pas supprimés.

La fonction XPeekIfEvent ne renvoie que lorsque la procédure prédicat spécifiée renvoie True pour un événement. Après que la procédure prédicat a trouvé une correspondance, XPeekIfEvent copie l'événement correspondant dans la structure XEvent fournie par le client sans retirer l'événement de la file d'attente. XPeekIfEvent vide le tampon de sortie si elle se bloque en attendant d'autres événements.

Chacune de ces fonctions exige que vous fournissiez une procédure prédicat qui détermine si un événement correspond à ce que vous recherchez. Votre procédure prédicat doit décider si l'événement est utile sans appeler de fonctions Xlib. Si le prédicat modifie directement ou indirectement l'état de la file d'attente d'événements, le résultat n'est pas défini. Si Xlib a été initialisé pour les threads, le prédicat est appelé avec l'affichage verrouillé et le résultat d'un appel par le prédicat à toute fonction Xlib qui verrouille l'affichage n'est pas défini, à moins que l'appelant n'ait d'abord appelé XLockDisplay.

La procédure prédicat et ses arguments associés sont :

Bool (*predicate)(Display *display, XEvent *event, XPointer arg)

display
Spécifie la connexion au serveur X.
event
Spécifie la structure XEvent.
arg
Spécifie l'argument passé depuis la fonction XIfEvent, XCheckIfEvent ou XPeekIfEvent.

La procédure prédicat est appelée une fois pour chaque événement dans la file d'attente jusqu'à ce qu'elle trouve une correspondance. Après avoir trouvé une correspondance, la procédure prédicat doit renvoyer True. Si elle n'a pas trouvé de correspondance, elle doit renvoyer False.

Notez que la procédure prédicat est appelée avec l'affichage verrouillé et ne peut donc pas appeler une fonction qui prendrait à nouveau le verrou de l'affichage.
