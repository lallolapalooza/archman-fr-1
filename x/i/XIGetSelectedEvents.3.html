XISELECTEVENTS(3)   XISELECTEVENTS(3)

NOM

XISelectEvents, XIGetSelectedEvents - sélectionner ou obtenir les événements XI2 sélectionnés sur la fenêtre.

SYNTAXE

#include <X11/extensions/XInput2.h>
Status XISelectEvents( Display *display,
                       Window win,
                       XIEventMask *masks,
                       int num_masks);
display
       Spécifie la connexion au serveur X.
masks
       Masque d'événements du périphérique.
num_masks
       Nombre de masques dans masks.
win
       Spécifie la fenêtre.
XIEventMask *XIGetSelectedEvents( Display *display,
                                  Window win,
                                  int *num_masks_return);
display
       Spécifie la connexion au serveur X.
num_masks_return
       Nombre de masques dans la valeur de retour.
win
       Spécifie la fenêtre.

DESCRIPTION

Les événements XI2 doivent être sélectionnés en utilisant XISelectEvents.
XISelectEvents définit le masque d'événements pour ce client sur win.
Les événements ultérieurs ne sont signalés à ce client que si le type
d'événement correspond au masque d'événements sélectionné. Les masques
remplacent le masque d'événements précédemment sélectionné pour le
périphérique donné.
Si deviceid est un périphérique valide, le masque d'événements est
sélectionné uniquement pour ce périphérique. Si deviceid est XIAllDevices
ou XIAllMasterDevices, le masque d'événements est sélectionné pour tous
les périphériques ou tous les périphériques maîtres, respectivement. Le
masque d'événements effectif est le OU binaire de XIAllDevices,
XIAllMasterDevices et du masque d'événements du périphérique
respectif.
typedef struct {
    int deviceid;
    int mask_len;
    unsigned char* mask;
} XIEventMask;
mask_len spécifie la longueur de mask en octets. mask est un masque binaire
sous la forme (1 << type d'événement). deviceid doit être soit un
périphérique, soit XIAllDevices, soit XIAllMasterDevices. Un client peut
soumettre plusieurs masques avec le même deviceid dans une seule
requête, mais seul le dernier masque sera effectif.
XISelectEvents peut générer une erreur BadValue, BadDevice et BadWindow.
XIGetSelectedEvents retourne les événements sélectionnés par ce client sur la
fenêtre donnée. Si aucun événement n'a été sélectionné sur cette fenêtre,
XIGetSelectedEvents retourne NULL et num_masks_return est mis à 0. Si une
erreur interne se produit, XIGetSelectedEvents retourne NULL et
num_masks_return est mis à -1. Sinon, XIGetSelectedEvent retourne les
masques d'événements sélectionnés pour tous les périphériques, y compris
les masques pour XIAllDevices et XIAllMasterDevices.
L'appelant doit libérer les données retournées en utilisant XFree().

DIAGNOSTICS

BadValue
       Une valeur est en dehors de la plage autorisée.
BadWindow
       Une valeur pour un argument Window ne nomme pas une fenêtre définie.
BadDevice
       Un périphérique invalide a été spécifié. Le périphérique n'existe
       pas.
