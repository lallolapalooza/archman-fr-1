XINERAMA(3) Manuel des fonctions de bibliothèque XINERAMA(3)

NOM

Xinerama - API pour l'extension Xinerama du protocole X11

SYNTAXE

#include <X11/extensions/Xinerama.h>

Bool XineramaQueryExtension (Display *dpy,
	int *event_base_return, int *error_base_return);

Status XineramaQueryVersion (Display *dpy,
	int *major_version_return,
	int *minor_version_return);

Bool XineramaIsActive (Display *dpy);

XineramaScreenInfo * XineramaQueryScreens (Display *dpy,
	int *number);

ARGUMENTS

display
Spécifie la connexion au serveur X.
event_base_return
Spécifie l'emplacement de retour pour le code d'événement de base assigné.
error_base_return
Spécifie l'emplacement de retour pour le code d'erreur de base assigné.
major_version_return
Retourne la version majeure prise en charge par le serveur.
minor_version_return
Retourne la version mineure prise en charge par le serveur.
number
Retourne le nombre d'entrées dans le tableau XineramaScreenInfo retourné.

DESCRIPTION

Xinerama est une bibliothèque simple conçue pour interagir avec l'extension Xinerama afin de récupérer des informations sur les périphériques de sortie physiques qui peuvent être combinés en un seul écran X logique.

FONCTIONS

XineramaQueryExtension()

La fonction XineramaQueryExtension interroge le Xserver pour déterminer la disponibilité de l'extension Xinerama. Si l'extension est disponible, la valeur de retour est True, et event_base_return et error_base_return sont définis respectivement sur le numéro d'événement de base et le numéro d'erreur de base pour l'extension. Sinon, la valeur de retour est False, et les valeurs de event_base_return et error_base_return ne sont pas définies.

XineramaQueryVersion()

La fonction XineramaQueryVersion retourne la version de l'extension Xinerama implémentée par le Xserver. La version est retournée dans major_version_return et minor_version_return. La version majeure sera incrémentée pour les changements incompatibles du protocole, et la version mineure sera incrémentée pour les changements mineurs et compatibles ascendante.

Si la bibliothèque Xinerama est compatible avec la version retournée par le serveur, elle retourne une valeur non nulle. Si le serveur ne prend pas en charge l'extension XINERAMA, ou s'il y a eu une erreur de communication avec le serveur, ou si les versions du protocole du serveur et de la bibliothèque sont incompatibles, elle retourne zéro.

XineramaIsActive()

La fonction XineramaIsActive retourne un opérateur booléen utilisé pour déterminer si Xinerama est activé sur l'écran. Retourne True pour activé et False pour non activé.

XineramaQueryScreens()

La fonction XineramaQueryScreens() retourne des informations sur chaque périphérique de sortie individuel au sein de l'écran Xinerama. L'entier pointé par l'argument number est mis à jour avec le nombre de périphériques de sortie listés dans le tableau retourné de structures XineramaScreenInfo. XineramaQueryScreens() retourne NULL et met number à 0 si Xinerama n'est pas actif.

Le pointeur retourné doit être libéré avec XFree(3) lorsqu'il n'est plus nécessaire.

NOTE

L'API originale fournie pour interagir avec l'extension XINERAMA utilisait des noms de fonctions commençant par XPanoramiX. Cette API est maintenant obsolète et doit être utilisée à la place dans les nouveaux logiciels.
