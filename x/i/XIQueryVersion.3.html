XIQUERYVERSION(3)   XIQUERYVERSION(3)

NOM

XIQueryVersion - annonce et interroge la version XI2 supportée.

SYNTAXE

#include <X11/extensions/XInput2.h>
Status XIQueryVersion( Display *display,
                       int *major_version_inout,
                       int *minor_version_inout);
display
       Spécifie la connexion au serveur X.
major_version_inout
       Spécifie la version XI2 supportée par le client, et
       renvoie la version supportée par le serveur.
minor_version_inout
       Spécifie la version XI2 supportée par le client, et
       renvoie la version supportée par le serveur.

DESCRIPTION

XIQueryVersion annonce la version XI2 supportée par le client au
serveur et renvoie la version X Input supportée par le serveur. Les clients
sont tenus d'utiliser XIQueryVersion au lieu de XGetExtensionVersion
s'ils utilisent des appels XI2. Le serveur peut traiter un client différemment
en fonction de la version supportée annoncée par le client.
La version major_version_inout doit être de 2 ou plus, sinon une erreur BadValue
se produit.
Si le serveur ne supporte pas XI2, XIQueryVersion renvoie BadRequest
au client. Sinon, XIQueryVersion renvoie Success. Dans les deux
cas, major_version_inout et minor_version_inout sont définis à la
version supportée par le serveur.
Si le client a déjà appelé XIQueryVersion, le résultat dépend
de la version précédemment demandée et de la version actuellement
demandée.
Si l'une des versions demandées ou les deux sont inférieures à 2.2,
ou si les numéros de version majeure demandés ne correspondent pas, alors
les appels consécutifs à XIQueryVersion par le même client renvoient
toujours la première version majeure.mineure renvoyée. Si le client
demande une version inférieure à la première version majeure.mineure
renvoyée lors d'un appel ultérieur, une erreur BadValue se produit.
Si toutes les versions demandées sont de 2.2 ou plus, alors
les appels consécutifs à XIQueryVersion par le même client avec la
même version majeure renverront la version demandée, mais le serveur
fonctionnera selon le numéro de version le plus élevé demandé ou
la version supportée la plus élevée, selon ce qui est le plus bas.
XIQueryVersion peut générer une erreur BadValue.

EXEMPLES

int rc;
int major = 2;
int minor = 0;
rc = XIQueryVersion(dpy, &major, &minor);
if (rc == Success)
    printf("XI2 supporté. (%d.%d)\n", major, minor);
else if (rc == BadRequest)
    printf("Pas de support XI2. (%d.%d seulement)\n", major, minor);
else
    printf("Erreur interne\n");

DIAGNOSTICS

BadValue
       Une valeur est en dehors de la plage autorisée.
