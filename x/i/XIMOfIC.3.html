XCreateIC(3) FONCTIONS XLIB XCreateIC(3)

NOM

XCreateIC, XDestroyIC, XIMOfIC - créer, détruire et obtenir la méthode d'entrée d'un contexte d'entrée

SYNTAXE

XIC XCreateIC(XIM im, ...);

void XDestroyIC(XIC ic);

XIM XIMOfIC(XIC ic);

ARGUMENTS

ic
Spécifie le contexte d'entrée.
im
Spécifie la méthode d'entrée.
...
Spécifie la liste d'arguments de longueur variable pour définir les valeurs XIC.

DESCRIPTION

La fonction XCreateIC crée un contexte au sein de la méthode d'entrée spécifiée.

Certains arguments sont obligatoires au moment de la création, et le contexte d'entrée ne sera pas créé si ces arguments ne sont pas fournis. Les arguments obligatoires sont le style d'entrée et l'ensemble des rappels de texte (si le style d'entrée sélectionné nécessite des rappels). Toutes les autres valeurs du contexte d'entrée peuvent être définies ultérieurement.

XCreateIC retourne une valeur NULL si aucun contexte d'entrée n'a pu être créé. Une valeur NULL peut être retournée pour l'une des raisons suivantes :

  • Un argument requis n'a pas été défini.
  • Un argument en lecture seule a été défini (par exemple, XNFilterEvents).
  • Le nom de l'argument n'est pas reconnu.
  • La méthode d'entrée a rencontré une erreur dépendante de l'implémentation de la méthode d'entrée.

XCreateIC peut générer les erreurs BadAtom, BadColor, BadPixmap et BadWindow.

XDestroyIC détruit le contexte d'entrée spécifié.

La fonction XIMOfIC retourne la méthode d'entrée associée au contexte d'entrée spécifié.

DIAGNOSTICS

BadAtom
Une valeur pour un argument Atom ne nomme pas un Atom défini.
BadColor
Une valeur pour un argument Colormap ne nomme pas une Colormap définie.
BadPixmap
Une valeur pour un argument Pixmap ne nomme pas un Pixmap défini.
BadWindow
Une valeur pour un argument Window ne nomme pas une Window définie.
