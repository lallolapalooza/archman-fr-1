NOM

XpmCreateXpmImage - créer une image Xpm

SYNTAXE

int XpmCreateXpmImageFromData(char **data, XpmImage *image,
XpmInfo *info);
int XpmCreateXpmImageFromBuffer(char *buffer, XpmImage *image,
XpmInfo *info);
int XpmCreateXpmImageFromImage(Display *display,
XImage *image, XImage *shapeimage,
XpmImage *xpmimage, XpmAttributes *attributes);
int XpmCreateXpmImageFromPixmap(Display *display,
Pixmap *pixmap, Pixmap *shapemask,
XpmImage *xpmimage, XpmAttributes *attributes);

ARGUMENTS

data
Spécifie l'emplacement des données.
image
Spécifie l'emplacement de la structure image.
info
Spécifie l'emplacement d'une structure XpmInfo pour obtenir et stocker des informations (ou NULL).
display
Spécifie la connexion au serveur X.
image
Spécifie l'image X utilisée comme source.
shapeimage
Spécifie l'image de masque de forme, le cas échéant.
xpmimage
Spécifie l'image XPM qui est créée.
attributes
Spécifie l'emplacement d'une structure contenant des informations (ou NULL).

DESCRIPTION

XpmCreateXpmImageFromBuffer

Pour créer une image Xpm à partir d'un tampon XPM, utilisez XpmCreateXpmImageFromBuffer(). La fonction XpmCreateXpmImageFromBuffer() lit le tampon donné pour remplir la structure XpmImage donnée. Si le tampon ne contient pas de données XPM valides, elle renvoie XpmFileInvalid. Si un espace de travail insuffisant est alloué, elle renvoie XpmNoMemory. En cas de succès, elle renvoie XpmSuccess. Si le pointeur de la structure XpmInfo passé n'est pas NULL, XpmCreateXpmImageFromBuffer() recherche les attributs suivants : XpmReturnComments et XpmReturnExtensions, et définit éventuellement l'attribut XpmHotspot lors du retour. Comme spécifié dans le tableau (page 28), si les données relatives aux attributs XpmReturnComments et XpmReturnExtensions ne peuvent pas être retournées comme demandé en raison d'un manque de mémoire, XpmCreateXpmImageFromBuffer() modifiera le mask de valeurs pour en tenir compte et essaiera de continuer. L'appelant devrait donc vérifier cela avant d'accéder aux données demandées.

Remarque : Le mask de valeurs de la structure XpmInfo passée doit être défini à une valeur valide, au minimum zéro, sinon des erreurs imprévisibles peuvent survenir.

XpmCreateXpmImageFromData

Pour créer une image Xpm à partir de données XPM, utilisez XpmCreateXpmImageFromData(). XpmCreateXpmImageFromData() remplit la structure XpmImage donnée à partir des données fournies. Si les données ne contiennent pas de données XPM valides, elle renvoie XpmFileInvalid. Si un espace de travail insuffisant est alloué, elle renvoie XpmNoMemory. En cas de succès, elle renvoie XpmSuccess. Si le pointeur de la structure XpmInfo passé n'est pas NULL, XpmCreateXpmImageFromData() recherche les attributs suivants : XpmReturnExtensions, et définit éventuellement l'attribut XpmHotspot lors du retour. Comme spécifié dans le tableau (page 28), si les données relatives à l'attribut XpmReturnExtensions ne peuvent pas être retournées comme demandé en raison d'un manque de mémoire, XpmCreateXpmImageFromData() modifiera le mask de valeurs pour en tenir compte et essaiera de continuer. L'appelant devrait donc vérifier cela avant d'accéder aux données demandées.

Remarque : Le mask de valeurs de la structure XpmInfo passée doit être défini à une valeur valide, au minimum zéro, sinon des erreurs imprévisibles peuvent survenir.

XpmCreateXpmImageFromImage

Pour créer une image Xpm à partir d'une image X, utilisez XpmCreateXpmImageFromImage(). À partir des images X et des XpmAttributes données (si non NULL), XpmCreateXpmImageFromImage() crée une image Xpm en suivant le même mécanisme que XpmWriteFileFromImage(3).

XpmCreateXpmImageFromPixmap

Pour créer une image Xpm à partir d'un Pixmap, utilisez XpmCreateXpmImageFromPixmap(). À partir des pixmaps et des XpmAttributes données (si non NULL), XpmCreateXpmImageFromPixmap() obtient les XImages associées en appelant XGetImage, puis les donne à XpmCreateXpmImageFromImage() pour créer une image Xpm qui est renvoyée à xpmimage. Enfin, elle détruit les images X créées en utilisant XDestroyImage(3).
