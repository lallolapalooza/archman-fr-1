XpSetImageResolution(3Xp) FONCTIONS XPRINT XpSetImageResolution(3Xp)

NOM

XpSetImageResolution - Définit la résolution pour les futures requêtes PutImage

SYNTAXE


cc [ indicateur... ] fichier... -lXp [ bibliothèque... ]
#include <X11/extensions/Print.h>

Bool XpSetImageResolution ( display, print_context, image_res, prev_res_return )
Display * display ;
XPContext print_context ;
int image_res ;
int * prev_res_return ;

ARGUMENTS

- display
Spécifie un pointeur vers la structure Display.
- print_context
Spécifie le contexte d'impression sur lequel définir la résolution.
- image_res
Spécifie la résolution de l'image en pixels par pouce.
- prev_res_return
Retourne la résolution d'image précédente en pixels par pouce.

DESCRIPTION

XpSetImageResolution retourne True si le serveur d'impression a autorisé la définition de la résolution, sinon False est retourné.

XpSetImageResolution définit la résolution pour les requêtes PutImage ultérieures vers l'écran du contexte d'impression spécifié. Si la valeur de retour est False, le serveur d'impression ne prend pas en charge la mise à l'échelle d'images pour la résolution donnée compte tenu de la configuration actuelle de l'imprimante, et l'application est responsable de toute mise à l'échelle souhaitée. Si la valeur de retour est True, le contenu de toute requête PutImage ultérieure vers un Pixmap ou une Window sur l'écran du contexte d'impression spécifié sera automatiquement mis à l'échelle dans le cadre de la requête PutImage. Le facteur d'échelle est :

    résolution_imprimante_par_défaut / image_res

Où résolution_imprimante_par_défaut est la valeur actuelle de cet attribut de page. Seule l'image elle-même est mise à l'échelle (signifiant que la largeur et la hauteur effectives de l'image changent), les paramètres dst-x et dst-y de PutImage ne sont pas modifiés.

Comme cas spécial, une valeur de zéro pour image_res réinitialise la résolution pour suivre automatiquement la résolution de l'imprimante ; dans ce cas (qui est aussi le réglage par défaut pour un contexte d'impression nouvellement créé), les images ultérieures ne seront pas mises à l'échelle.

Si la valeur de retour est True et prev_res_return est un pointeur non NULL, alors la résolution d'image précédente qui était définie pour le contexte d'impression est stockée dans prev_res_return.

XpSetImageResolution retourne False immédiatement si image_res est négatif ou supérieur à 65535.

DIAGNOSTICS

XpBadContext
Un identifiant de contexte d'impression valide n'a pas été défini avant de faire cet appel.
