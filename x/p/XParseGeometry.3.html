NOM

XParseGeometry, XWMGeometry - analyser la géométrie d'une fenêtre

SYNTAXE

int XParseGeometry(_Xconst char *parsestring, int *x_return, int *y_return, unsigned int *width_return, unsigned int *height_return);

int XWMGeometry(Display *display, int screen, _Xconst char *user_geom, _Xconst char *def_geom, unsigned int bwidth, XSizeHints *hints, int *x_return, int *y_return, int *width_return, int *height_return, int *gravity_return);

ARGUMENTS

position

DESCRIPTION

Par convention, les applications X utilisent une chaîne standard pour indiquer la taille et le placement de la fenêtre. XParseGeometry facilite la conformité à cette norme car elle vous permet d'analyser la géométrie standard de la fenêtre. Plus précisément, cette fonction vous permet d'analyser des chaînes de la forme :

[=][<largeur>{xX}<hauteur>][{+-}<xoffset>{+-}<yoffset>]

Les champs correspondent aux arguments associés à cette fonction. (Les éléments entre <> sont des entiers, les éléments entre [] sont optionnels, et les éléments entre {} indiquent « choisir l'un ». Notez que les crochets ne doivent pas apparaître dans la chaîne réelle.) Si la chaîne n'est pas dans l'encodage de caractères portable hôte, le résultat est dépendant de l'implémentation.

La fonction XParseGeometry retourne un masque binaire qui indique lesquelles des quatre valeurs (largeur, hauteur, xoffset et yoffset) ont été effectivement trouvées dans la chaîne et si les valeurs x et y sont négatives. Par convention, -0 n'est pas égal à +0, car l'utilisateur doit pouvoir dire « positionner la fenêtre par rapport au bord droit ou inférieur ». Pour chaque valeur trouvée, l'argument correspondant est mis à jour. Pour chaque valeur non trouvée, l'argument reste inchangé. Les bits sont représentés par XValue, YValue, WidthValue, HeightValue, XNegative ou YNegative et sont définis dans X11/Xutil.h. Ils seront définis chaque fois qu'une des valeurs est définie ou qu'un des signes est défini.

Si la fonction retourne soit le drapeau XValue, soit le drapeau YValue, vous devriez placer la fenêtre à la position demandée.

La fonction XWMGeometry combine toute information de géométrie (donnée dans le format utilisé par XParseGeometry) spécifiée par l'utilisateur et par le programme appelant avec des indications de taille (généralement celles à stocker dans WM_NORMAL_HINTS) et retourne la position, la taille et la gravité (NorthWestGravity, NorthEastGravity, SouthEastGravity ou SouthWestGravity) qui décrivent la fenêtre. Si la taille de base n'est pas définie dans la structure XSizeHints, la taille minimale est utilisée si elle est définie. Sinon, une taille de base de zéro est supposée. Si aucune taille minimale n'est définie dans la structure d'indications, la taille de base est utilisée. Un masque (sous la forme retournée par XParseGeometry) décrivant quelles valeurs proviennent de la spécification de l'utilisateur et si les coordonnées de position sont relatives aux bords droit et inférieur est retourné. Notez que ces coordonnées auront déjà été prises en compte dans les valeurs x_return et y_return.

Notez que des spécifications de géométrie invalides peuvent entraîner le retour d'une largeur ou hauteur de zéro. L'appelant peut passer l'adresse du champ win_gravity des indications comme gravity_return pour mettre à jour directement les indications.
