XpGetPdmStartParams(3Xp) FONCTIONS XPRINT XpGetPdmStartParams(3Xp)

NOM

XpGetPdmStartParams - Construit les paramètres conformément au protocole de sélection PDM en tant que fonction utilitaire standard.

SYNTAXE


cc [ indicateur... ] fichier... -lXp [ bibliothèque... ]
#include <X11/extensions/Print.h>

Status XpGetPdmStartParams ( print_display print_window print_context video_display video_window selection_display_return selection_return type_return format_return data_return nelements_return )
Display *print_display;
Window print_window;
XPContext print_context;
Display *video_display;
Window video_window;
Display **selection_display_return;
Atom *selection_return;
Atom *type_return;
int *format_return;
unsigned char **data_return;
int *nelements_return;

ARGUMENTS

print_display
Spécifie un pointeur vers la structure d'affichage d'impression ; retourné par XOpenDisplay sur le serveur d'impression X.
print_window
Spécifie une fenêtre client sur n'importe quel écran de print_display, suffisamment longtemps pour les communications ICCCM du statut final PDM (« OK » ou « ANNULER » ClientMessage) envoyées à print_window.
print_context
Un contexte d'impression existant auquel le PDM doit faire référence.
video_display
Spécifie un pointeur vers la structure d'affichage vidéo ; retourné par XOpenDisplay sur le serveur X vidéo.
video_window
Spécifie la fenêtre sur video_display près de laquelle les boîtes de dialogue transitoires du PDM doivent être affichées.
selection_display_return
Retourne la connexion d'affichage sur laquelle la sélection PDM doit être effectuée. Peut être égal à print_display ou video_display, ou peut être une nouvelle connexion d'affichage que l'appelant doit fermer une fois terminé.
selection_return
Retourne l'atome de sélection sur lequel une sélection PDM doit être effectuée.
type_return
Retourne le type pour la propriété du protocole de sélection PDM que l'appelant est censé créer.
format_return
Retourne le format pour la propriété du protocole de sélection PDM que l'appelant est censé créer.
data_return
Retourne les données définies pour la propriété du protocole de sélection PDM que l'appelant est censé créer. L'appelant est censé libérer les données avec XFree une fois terminé.
nelements_return
Retourne le nombre d'éléments pour la propriété du protocole de sélection PDM que l'appelant est censé créer.

DESCRIPTION

Cette requête retourne un statut zéro si une erreur s'est produite, non nul sinon.

XpGetPdmStartParams est une routine utilitaire utilisée pour construire les informations de propriété nécessaires et les informations de connexion d'affichage de sélection requises pour initier une sélection PDM conformément au « Protocole de Sélection PDM ». Une fois les informations construites, l'appelant est responsable de la création d'une propriété, de la génération d'une SelectionRequest, de la réception d'un événement SelectionNotify et de la réception d'un événement ClientMessage, comme décrit dans le Protocole de Sélection PDM.

Une fois terminé, l'appelant est censé libérer les données à l'aide de XFree. XpGetPdmStartParams retourne zéro si une erreur s'est produite, sinon non nul. Si une erreur se produit, toutes les autres valeurs _return sont indéfinies.

La définition de la variable d'environnement XPDMSELECTION fait que XpGetPdmStartParams utilise un nom de sélection alternatif. Si elle n'est pas définie, le nom de sélection PDM_MANAGER est utilisé.

La définition de la variable d'environnement XPDMDISPLAY fait que XpGetPdmStartParams localise la sélection sur un serveur X alternatif. Si elle n'est pas définie, selection_display_return
est défini égal à print_display. Si XPDMDISPLAY est défini sur l'un des mots-clés « print » ou « video », selection_display_return est défini respectivement sur print_display ou video_display. Si XPDMDISPLAY est défini sur une chaîne de style DISPLAY valide, selection_display_return peut être défini, comme il convient, sur l'un des print_display, video_display, ou sur une nouvelle connexion d'affichage ouverte à l'intérieur de XpGetPdmStartParams. Ce n'est que dans le seul cas où une nouvelle connexion d'affichage est établie que l'appelant doit fermer selection_display_return à l'aide de XCloseDisplay.

Lorsque XpGetPdmStartParams est appelé, la locale de l'appelant (voir XpSetLocaleHinter) est incluse dans les informations en tant qu'« indice » pour le gestionnaire de dialogue d'impression (PDM). Si elle est prise en charge par l'implémentation, le PDM utilisera l'indice pour afficher les boîtes de dialogue de manière plus appropriée pour la locale du client. Si le gestionnaire de dialogue d'impression ne peut pas comprendre l'indice, le PDM choisira un défaut. Notez que la locale des attributs d'impression auxquels le PDM accédera par la suite a déjà été déterminée lorsque le client a appelé XpCreateContext.

Les variables d'environnement XPDMDISPLAY et XPDMSELECTION sont re-lues à chaque appel de XpGetPdmStartParams.
