XpStartPage(3Xp) FONCTIONS XPRINT XpStartPage(3Xp)

NOM

XpStartPage - Indique le début d'une page d'impression.

SYNTAXE


cc [ indicateur... ] fichier... -lXp [ bibliothèque... ]
#include <X11/extensions/Print.h>

void XpStartPage ( display, window )
Display *display;
Window window;

ARGUMENTS

display
Spécifie un pointeur vers la structure Display ; renvoyé par XOpenDisplay.
window
Spécifie l'ID de la fenêtre.

DESCRIPTION

XpStartPage signale le début d'une nouvelle page d'impression, la fenêtre servant de drawable représentant la page. window doit être un descendant de la fenêtre racine de la fenêtre de contexte d'impression actuelle, sinon une erreur BadWindow sera générée. Aucune génération de données documentaires ne se produira pour les opérations de rendu sur la fenêtre ou ses inférieurs avant XpStartPage.

XpStartPage provoque le mappage de la fenêtre. Voir XpGetPageDimensions et XResizeWindow pour plus de détails sur le redimensionnement de la fenêtre à la taille du support sélectionné avant d'appeler XpStartPage. Dans la séquence XpStartPage et XpEndPage, les tentatives de redimensionnement, de déplacement ou de démappage de la fenêtre auront des résultats indéfinis. Pour redimensionner ou déplacer les inférieurs de la fenêtre, les sémantiques standard de ConfigureWindow s'appliquent, sauf que le contenu de toute fenêtre configurée peut être supprimé. Un événement Expose sera généré si le contenu d'une fenêtre est supprimé.

Toutes les modifications apportées au pool d'attributs XPPageAttr (voir XpSetAttributes) doivent être effectuées avant d'appeler XpStartPage, après quoi une erreur XPBadSequence sera générée si des modifications sont tentées, jusqu'à ce que XpEndPage soit appelée.

Pour les clients sélectionnant XPPrintMask (voir XpSelectInput), l'événement XPPrintNotify sera généré avec son champ detail défini sur XPStartPageNotify lorsque le serveur d'impression X aura terminé XpStartPage. Si l'événement Expose est également sélectionné (voir XSelectInput), les événements d'exposition seront générés avant XPPrintNotify.

Le client n'a pas besoin d'attendre XPStartPageNotify avant d'appeler d'autres routines de rendu X.

DIAGNOSTICS

BadWindow
La valeur spécifiée pour window n'est pas valide.
XPBadContext
Un ID de contexte d'impression valide n'a pas été défini avant cet appel.
XPBadSequence
La fonction n'a pas été appelée dans le bon ordre par rapport aux autres appels de l'extension X Print Service ; par exemple, XpStartPage a été appelée avant XpStartJob ou a été appelée pour un document de type XPDocRaw.
