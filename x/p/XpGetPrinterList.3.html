XpGetPrinterList(3Xp) FONCTIONS XPRINT XpGetPrinterList(3Xp)

NOM

XpGetPrinterList - Récupère une liste de toutes les imprimantes prises en charge par un serveur d'impression X.

SYNOPIS


cc [ flag... ] file... -lXp [ library... ]
#include <X11/extensions/Print.h>

XPPrinterList XpGetPrinterList ( display, printer_name, list_count_return )
Display *display;
char *printer_name;
int *list_count_return;

ARGUMENTS

display
Spécifie un pointeur vers la structure Display ; retourné par XOpenDisplay.
printer_name
Spécifie le nom de l'imprimante pour laquelle des informations sont désirées. Si NULL, alors des informations sont retournées pour toutes les imprimantes associées au serveur.
list_count_return
Retourne le nombre d'imprimantes dans la liste.

DESCRIPTION

XpGetPrinterList retourne une liste d'enregistrements d'imprimantes où chaque enregistrement décrit une imprimante prise en charge par le serveur d'impression X, ou NULL si des erreurs surviennent.

Si printer_name est NULL, alors une liste de toutes les imprimantes prises en charge est retournée. Si printer_name n'est pas NULL, seuls les enregistrements d'impression correspondant à printer_name sont retournés, et si aucun enregistrement ne correspond à printer_name, alors NULL est retourné.

printer_name est une chaîne COMPOUND_TEXT, et les champs name et desc dans la liste retournée seront en COMPOUND_TEXT (notez que l'ISO 8859-1 (Latin-1) est un sous-ensemble propre de COMPOUND_TEXT, donc peut être utilisé directement). Si printer_name est dans un jeu de codes que le serveur d'impression X ne peut pas convertir (dans son jeu de codes opérationnel), alors le serveur d'impression X peut échouer à localiser l'imprimante demandée. Si printer_name est NULL, alors tous les noms d'imprimantes, quel que soit leur jeu de codes, peuvent être retournés, laissant la tâche de reconnaissance spécifique de l'imprimante à l'appelant.

Lorsque XpGetPrinterList est appelé, la locale de l'appelant (voir XpSetLocaleHinter) est incluse dans la requête comme un "indice" pour le serveur d'impression X. Si elle est prise en charge par l'implémentation, le serveur d'impression X utilisera l'indice pour localiser une description localisée pour chaque imprimante de la liste. Si le serveur d'impression X ne peut pas comprendre l'indice, le serveur d'impression X choisira une valeur par défaut. La liste d'imprimantes retournée peut être libérée en appelant XpFreePrinterList.

La structure XPPrinterList définie dans <X11/extensions/Print.h> contient :

typedef struct {
    char *name;	/∗ nom */
    char *desc;	/∗ description localisée */
} XPPrinterRec, *XPPrinterList;

DIAGNOSTICS

BadAlloc
Mémoire insuffisante.
