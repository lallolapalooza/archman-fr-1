XpmWriteFileFromPixmap(3)

Paquet: libxpm

Licences: MIT, X11-distribute-modifications-variant

XpmWrite(3) Fonctions libXpm XpmWrite(3)

NOM

XpmWrite - écrire un fichier XPM

SYNTAXE

int XpmWriteFileFromPixmap(Display *display, char *filename,
Pixmap pixmap, Pixmap shapemask, XpmAttributes *attributes);
int XpmWriteFileFromImage(Display *display , char *filename,
XImage *image, XImage *shapeimage, XpmAttributes *attributes);
int XpmWriteFileFromData(char *filename, char **data);
int XpmWriteFileFromXpmImage(char *filename, XpmImage *image,
XImage *shapeimage, XpmInfo *info);
int XpmWriteFileFromBuffer(char *filename, char *buffer);

ARGUMENTS

display
Spécifie la connexion au serveur X.
filename
Spécifie le nom du fichier à utiliser.
pixmap
Spécifie le pixmap.
shapemask
Spécifie le pixmap du masque de forme.
attributes
Spécifie l'emplacement d'une structure contenant des informations (ou NULL).
data
Spécifie le tableau de données à lire.
image
Spécifie l'image.
info
Spécifie l'emplacement d'une structure pour obtenir des informations (ou NULL).
buffer
Spécifie le tampon à lire.

DESCRIPTION

XpmWriteFileFromImage

La fonction XpmWriteFileFromImage() écrit une image et son éventuel shapeimage dans un fichier au format XPM. Si le fichier ne peut pas être ouvert, elle renvoie XpmOpenFailed. Si un espace de stockage de travail insuffisant est alloué, elle renvoie XpmNoMemory. Si aucune erreur ne se produit, elle renvoie XpmSuccess. Si le pointeur de structure XpmAttributes passé n'est pas NULL, XpmWriteFileFromImage() recherche les attributs suivants : XpmColormap, XpmHotspot, XpmCharsPerPixel, XpmRgbFilename, et XpmExtensions. Par souci de compatibilité descendante, XpmWriteFileFromImage() recherche également les attributs XpmInfos. Si le nom du fichier contient une extension telle que “.xpm”, afin d'obtenir un nom de variable C valide, le point est remplacé par un souligné ’_’ lors de l'écriture. Par souci de compatibilité descendante, si les attributs XpmInfos sont définis, elle écrit les informations éventuellement stockées telles que les commentaires, les défauts de couleur et le symbole. Enfin, si l'attribut XpmRgbFilename est défini, XpmWriteFileFromImage() recherche les noms de couleur dans ce fichier et, s'ils sont trouvés, les écrit à la place des valeurs rgb.

De plus, sur les systèmes qui supportent de telles fonctionnalités, si le nom de fichier donné se termine par ’.Z’ ou ’.gz’, il est supposé être un fichier compressé. Alors, XpmWriteFileFromImage() écrit dans un processus compress ou gzip. Et si NULL est passé à XpmWriteFileFromImage() au lieu d'un nom de fichier, elle écrit sur la sortie standard.

XpmWriteFileFromPixmap

Pour écrire un Pixmap dans un fichier XPM, utilisez XpmWriteFileFromPixmap().

Si le pointeur de structure XpmAttributes passé n'est pas NULL, XpmWriteFileFromPixmap() recherche les attributs suivants : XpmSize. S'ils ne sont pas définis, elle effectue une opération XGetGeometry. Ensuite, elle utilise XGetImage pour obtenir à partir des pixmaps donnés les images X associées qui sont passées à XpmWriteFileFromImage(). Enfin, XpmWriteFileFromPixmap() détruit les images créées en utilisant XDestroyImage. La fonction XpmWriteFileFromPixmap() renvoie les mêmes erreurs que XpmWriteFileFromImage().

XpmWriteFileFromData

XpmWriteFileFromData() écrit un tableau de données XPM dans un fichier XPM.

XpmWriteFileToData() renvoie XpmOpenFailed s'il ne peut pas ouvrir le fichier, XpmFileInvalid si ce ne sont pas des données XPM valides, et XpmSuccess sinon.

XpmWriteFileFromXpmImage

Pour écrire une XpmImage dans un fichier XPM, utilisez XpmWriteFileFromXpmImage(). La fonction XpmWriteFileFromXpmImage() écrit une image dans un fichier au format XPM. Si le fichier ne peut pas être ouvert, elle renvoie XpmOpenFailed. Si un espace de stockage de travail insuffisant est alloué, elle renvoie XpmNoMemory. Si aucune erreur ne se produit, elle renvoie XpmSuccess. Si le pointeur de structure XpmInfo passé n'est pas NULL, XpmWriteFileFromXpmImage() recherche les attributs suivants : XpmComments, XpmExtensions, et XpmHotspot, et écrit également les informations associées. De plus, sur les systèmes qui supportent de telles fonctionnalités, si le nom de fichier donné se termine par ’.Z’ ou ’.gz’, il est supposé être un fichier compressé. Alors, XpmWriteFileFromXpmImage() écrit dans un processus compress ou gzip. Et si NULL est passé à XpmWriteFileFromXpmImage() au lieu d'un nom de fichier, elle écrit sur la sortie standard.

XpmWriteFileFromBuffer

XpmWriteFileFromBuffer() écrit un tampon XPM dans un fichier. XpmWriteFileFromBuffer() renvoie XpmOpenFailed s'il ne peut pas ouvrir le fichier, et XpmSuccess sinon.

Par commodité, les fonctions XpmReadFileToBuffer() et XpmWriteFileFromBuffer() sont fournies pour copier un fichier dans un tampon et écrire un fichier à partir d'un tampon. Ainsi, par exemple, on peut décider d'utiliser XpmCreateBufferFromPixmap(), XpmWriteFileFromBuffer(), et XpmFree() au lieu de XpmWriteFileFromPixmap(). Sur certains systèmes, cela peut améliorer les performances, car l'analyse sera effectuée en mémoire, mais cela utilise plus de mémoire.
