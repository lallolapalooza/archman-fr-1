XpCancelDoc(3Xp) FONCTIONS XPRINT XpCancelDoc(3Xp)

NOM

XpCancelDoc - Annule un document d'impression.

SYNTAXE

void XpCancelDoc ( display, discard )
Display *display;
Bool discard;

ARGUMENTS

display
Spécifie un pointeur vers la structure Display ; retourné par XOpenDisplay.
discard
Lorsque TRUE, spécifie que tous les événements XPPrintNotify avec un détail de XPEndPageNotify ou XPEndDocNotify doivent être ignorés.

DESCRIPTION

XpCancelDoc annule un document en cours. Si le travail a été démarré avec un mode de sortie XPGetData, le flux de données vers XpGetDocumentData est interrompu ; aucune donnée supplémentaire pour le document actuel ne sera générée, mais des données pour les documents suivants pourront l'être. Pour de nombreux langages de description de page, une telle terminaison arbitraire peut invalider la sortie.

Si le travail a été démarré avec le mode de sortie XPSpool, en fonction du pilote et de l'implémentation du spooler, le document entier peut être annulé ou un document partiel peut être généré.

Si discard est True, tous les événements XPPrintNotify avec un champ de détail XPEndPageNotify ou XPEndDocNotify sont ignorés avant que XpCancelDoc ne retourne.

Pour les clients sélectionnant XPPrintMask (voir XpSelectInput), l'événement XPPrintNotify sera généré avec son champ de détail défini sur XPEndDocNotify.

DIAGNOSTICS

XPBadContext
Un ID de contexte d'impression valide n'a pas été défini avant de faire cet appel.
XPBadSequence
La fonction n'a pas été appelée dans le bon ordre par rapport aux autres appels de l'extension d'impression X (par exemple, XpEndDoc avant XpStartDoc).

VOIR AUSSI
