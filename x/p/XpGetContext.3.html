XpGetContext(3Xp) FONCTIONS XPRINT XpGetContext(3Xp)

NOM

XpGetContext - Obtient l'identifiant du contexte d'impression actuel pour une connexion d'affichage.

SYNTAXE


cc [ drapeau... ] fichier... -lXp [ bibliothèque... ]
#include <X11/extensions/Print.h>

XPContext XpGetContext ( display )
Display *display;

ARGUMENTS

display
Spécifie un pointeur vers la structure Display ; retourné par XOpenDisplay.

DESCRIPTION

XpGetContext retourne l'identifiant du contexte d'impression actuel associé à display. Si aucun contexte d'impression n'a été défini, une valeur de None est retournée.
