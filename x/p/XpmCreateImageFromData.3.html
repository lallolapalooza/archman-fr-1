NOM

XpmCreateImage - créer une XImage à partir d'une XPM

SYNTAXE

int XpmCreateImageFromData(Display *display, char **data,
XImage **image_return, XImage **shapeimage_return,
XpmAttributes *attributes);
int XpmCreateImageFromBuffer(Display *display, char *buffer,
XImage **image_return, XImage **shapeimage_return,
XpmAttributes *attributes);
int XpmCreateImageFromXpmImage(Display *display,  XpmImage *image,
XImage *image_return, XImage *shapeimage_return,
XpmAttributes *attributes);

ARGUMENTS

display
Spécifie la connexion au serveur X.
data
Spécifie l'emplacement des données.
image_return
Retourne l'image créée.
shapeimage_return
Retourne l'image masque de forme qui est créée si la couleur None est utilisée.
attributes
Spécifie l'emplacement d'une structure pour obtenir et stocker des informations (ou NULL).
shapeimage
Spécifie l'image masque de forme qui est créée, le cas échéant.

DESCRIPTION

XpmCreateImageFromData

Pour créer une XImage à partir de données XPM, utilisez XpmCreateImageFromData().

La fonction XpmCreateImageFromData() vous permet d'inclure dans votre programme C un fichier XPM qui a été écrit par des fonctions telles que XpmWriteFileFromImage(3) ou XpmWriteFileFromPixmap(3) sans avoir à lire le fichier. XpmCreateImageFromData() fonctionne exactement comme XpmReadFileToImage(3) et retourne de la même manière. Elle lit simplement des données au lieu d'un fichier. Ici encore, il incombe à l'appelant de libérer les images retournées, les couleurs et éventuellement les données retournées dans la structure XpmAttributes.

XpmCreateImageFromBuffer

Pour créer une XImage à partir d'un buffer XPM, utilisez XpmCreateImageFromBuffer(). La fonction XpmCreateImageFromBuffer() fonctionne de la même manière que XpmReadFileToImage(3), elle analyse simplement le buffer au lieu du fichier. Soyez conscient que la fonctionnalité fournie sur certains systèmes par XpmReadFileToImage(3) pour traiter les fichiers compressés n'est pas disponible ici.

XpmCreateImageFromXpmImage

Pour créer une XImage à partir d'une XpmImage, utilisez XpmCreateImageFromXpmImage(). À partir de la XpmImage et des XpmAttributes données, si elles ne sont pas NULL, XpmCreateImageFromXpmImage() alloue des couleurs et crée des images X en suivant le même mécanisme que XpmReadFileToImage(3). Une fois terminé, l'appelant doit libérer les images en utilisant XDestroyImage(3), les couleurs en utilisant XFreeColors(3), et éventuellement les données retournées dans les XpmAttributes en utilisant XpmFreeAttributes(3).

VOIR AUSSI

XpmFreeAttributes(3), XpmReadFileToImage(3)
