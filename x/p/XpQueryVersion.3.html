XpQueryVersion(3Xp) FONCTIONS XPRINT XpQueryVersion(3Xp)

NOM

XpQueryVersion - Interroge un serveur X pour déterminer s'il prend en charge l'extension X Print Service, et si c'est le cas, quelle version de l'extension X Print Service.

SYNOPSIS


cc [ indicateur... ] fichier... -lXp [ bibliothèque... ]
#include <X11/extensions/Print.h>

Status XpQueryVersion ( display, major_version_return, minor_version_return )
Display *display;
short *major_version_return;
short *minor_version_return;

ARGUMENTS

display
Spécifie un pointeur vers la structure Display ; retourné par XOpenDisplay.
major_version_return
Retourne la version majeure si l'extension X Print Service existe, sinon zéro.
minor_version_return
Retourne la version mineure si l'extension X Print Service existe, sinon zéro.

DESCRIPTION

XpQueryVersion détermine si l'extension X Print Service est présente. Un statut non nul est retourné si l'extension est prise en charge, sinon un statut nul est retourné. Si l'extension est prise en charge, les numéros de version majeure et mineure sont retournés pour indiquer le niveau de prise en charge de l'extension X Print Service.

L'extension X Print Service est initialisée lors du premier appel à toute fonction X Print Service ; il n'est pas nécessaire d'initialiser explicitement l'extension X Print Service.
