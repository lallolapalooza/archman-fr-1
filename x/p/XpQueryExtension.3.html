XpQueryExtension(3Xp) FONCTIONS XPRINT XpQueryExtension(3Xp)

NOM

XpQueryExtension - Interroge un serveur X pour déterminer s'il prend en charge l'extension X Print Service, et si c'est le cas, quelles sont les valeurs de décalage pour les événements et erreurs associés.

SYNTAXE


cc [ flag... ] fichier... -lXp [ bibliothèque... ]
#include <X11/extensions/Print.h>

Bool XpQueryExtension ( display, event_base_return error_base_return )
Display *display;
int *event_base_return;
int *error_base_return;

ARGUMENTS

display
Spécifie un pointeur vers la structure Display ; retourné par XOpenDisplay.
event_base_return
La valeur de base pour les événements de l'extension X Print Service
error_base_return
La valeur de base pour les erreurs de l'extension X Print Service.

DESCRIPTION

XpQueryExtension détermine si l'extension X Print Service est présente. Elle retourne True si l'extension est prise en charge, sinon False. Si l'extension est présente, les valeurs de base pour les événements et les erreurs sont retournées et peuvent être utilisées pour décoder les valeurs d'événements et d'erreurs entrantes.

L'extension X Print Service est initialisée lors du premier appel à toute fonction X Print Service ; il n'est pas nécessaire d'initialiser explicitement l'extension X Print Service.
