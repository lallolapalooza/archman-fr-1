XpQueryScreens(3Xp) FONCTIONS XPRINT XpQueryScreens(3Xp)

NOM

XpQueryScreens - Interroge un serveur X pour déterminer quels écrans, parmi tous les écrans du serveur, prennent en charge l'extension X Print Service

SYNTAXE


cc [ flag... ] file... -lXp [ library... ]
#include <X11/extensions/Print.h>

Screen **XpQueryScreens ( display, list_count_return )
Display *display;
int *list_count_return;

ARGUMENTS

display
Spécifie un pointeur vers la structure Display ; renvoyé par XOpenDisplay.
list_count_return
Renvoie le nombre d'écrans dans la liste.

DESCRIPTION

Cette requête renvoie un pointeur non NULL vers une liste de pointeurs d'écrans si un ou plusieurs écrans prennent en charge l'extension X Print Service ; sinon, elle renvoie NULL.

XpQueryScreens détermine si l'extension X Print Service est présente, et si c'est le cas, laquelle de tous les écrans du serveur X prend en charge l'extension X Print Service. Contrairement à de nombreuses autres extensions, l'extension X Print Service peut être limitée à un sous-ensemble de tous les écrans disponibles - par exemple, un seul serveur X peut prendre en charge les affichages vidéo sur certains écrans et les imprimantes sur d'autres.

La liste des pointeurs d'écrans peut être libérée en appelant XFree.
