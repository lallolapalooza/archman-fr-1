XpCancelPage(3Xp) FONCTIONS XPRINT XpCancelPage(3Xp)

NOM

XpCancelPage - Annule une page d'impression.

SYNTAXE


cc [ indicateur... ] fichier... -lXp [ bibliothèque... ]
#include <X11/extensions/Print.h>

void XpCancelPage ( display, discard )
Display *display;
Bool discard;

ARGUMENTS

display
Spécifie un pointeur vers la structure Display ; retourné par XOpenDisplay.
discard
Lorsque TRUE, spécifie que les événements XPPrintNotify avec un détail de XPEndPageNotify doivent être ignorés.

DESCRIPTION

XpCancelPage annule une page d'impression en cours. Si le travail a été démarré avec le mode de sortie XPGetData, alors le flux de données vers XpGetDocumentData est interrompu ; aucune donnée supplémentaire pour la page actuelle n'est générée, mais des données pour les pages suivantes peuvent l'être. Pour de nombreux langages de description de page, de telles interruptions arbitraires peuvent invalider la sortie.

Si le travail a été démarré avec le mode de sortie XPSpool, alors, selon l'implémentation du pilote et du spooler, la page entière peut être annulée ou une page partielle peut être générée.

Si discard est True, tous les événements XPPrintNotify avec un champ détail de XPEndPageNotify sont ignorés avant que XpCancelPage ne retourne.

Pour les clients qui sélectionnent XPPrintMask (voir XpSelectInput), l'événement XPPrintNotify est généré avec son champ détail défini sur XPEndPageNotify lorsque le serveur d'impression X a terminé XpCancelPage.

DIAGNOSTICS

XPBadSequence
La fonction n'a pas été appelée dans l'ordre approprié par rapport aux autres appels du service d'impression X ; par exemple, XpStartPage a été appelé avant XpStartJob ou a été appelé pour un document de type XPDocRaw.
