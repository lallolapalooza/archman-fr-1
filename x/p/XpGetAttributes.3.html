Paquet: libxp

XpGetAttributes(3Xp) FONCTIONS XPRINT XpGetAttributes(3Xp)

NOM

XpGetAttributes - Obtient un pool d'attributs du contexte d'impression spécifié.

SYNTAXE


cc [ indicateur... ] fichier... -lXp [ bibliothèque... ]
#include <X11/extensions/Print.h>

char *XpGetAttributes ( display, context, type )
Display *display;
XPContext context;
XPAttributes type;

ARGUMENTS

display
Spécifie un pointeur vers la structure Display ; retourné par XOpenDisplay.
context
Le contexte d'impression à partir duquel le pool d'attributs doit être récupéré.
type
Spécifie le pool d'attributs.

DESCRIPTION

XpGetAttributes retourne un pool, une chaîne de caractères ressource COMPOUND_TEXT représentant le pool d'attributs spécifié par type. L'appelant est censé libérer le pool lorsqu'il n'est plus nécessaire en utilisant XFree.

Le pool d'attributs (et donc la chaîne de caractères ressource) se compose de nombreuses paires nom-valeur (par exemple, "copy-count: 3"). La syntaxe d'un pool d'attributs est la même que celle d'un fichier de ressources X (voir "Syntaxe des fichiers de ressources" dans la spécification Xlib).

Les caractères valides pour chaque nom (côté gauche) sont dérivés de Posix et sont "a"-"z", "A"-"Z", "0"-"9", "_" et "-". Les caractères valides pour chaque valeur (côté droit) sont tous les caractères sauf NULL et NEWLINE non échappé, bien que toutes les valeurs prédéfinies dans le service d'impression X soient limitées aux caractères de l'ensemble de caractères portables X (XPCS). Les valeurs non XPCS sont généralement limitées aux chaînes de "description" localisées. Voir XpCreateContext concernant l'indice de locale pour plus d'informations sur les valeurs localisées.

Si des erreurs surviennent, XpGetAttributes retourne NULL.

STRUCTURES

Les valeurs pour le typedef XPAttributes dans <X11/extensions/Print.h> sont :

 #define  XPJobAttr		1 /∗ obtenir/définir */
 #define  XPDocAttr		2 /∗ obtenir/définir */
 #define  XPPageAttr	3 /∗ obtenir/définir-sous-ensemble de XPDocAttr */
 #define  XPPrinterAttr	4 /∗ obtenir seulement (bibliothèque) */
 #define  XPServerAttr	5 /∗ obtenir seulement (bibliothèque), aucun contexte requis */

DIAGNOSTICS

BadAlloc
Mémoire insuffisante.
BadValue
La valeur spécifiée pour type n'est pas valide.
XPBadContext
L'identifiant du contexte d'impression spécifié n'est pas valide.
