XpSetAttributes(3)

Paquet: libxp

Licences: X11, X11-distribute-modifications-variant

XpSetAttributes(3Xp) FONCTIONS XPRINT XpSetAttributes(3Xp)

NOM

XpSetAttributes - Définit ou met à jour un pool d'attributs dans le contexte d'impression spécifié.

SYNTAXE


cc [ indicateur... ] fichier... -lXp [ bibliothèque... ]
#include <X11/extensions/Print.h>

void XpSetAttributes ( display, context, type, pool, replacement_rule )
Display *display;
XPContext context;
XPAttributes type;
char *pool;
XPAttrReplacement replacement_rule;

ARGUMENTS

display
Spécifie un pointeur vers la structure Display ; retourné par XOpenDisplay.
context
Le contexte d'impression dont le pool d'attributs doit être modifié.
type
Spécifie le pool d'attributs.
pool
Un pool d'attributs représenté sous forme de chaîne de ressources. Codé en COMPOUND_TEXT.
replacement_rule
Soit XPAttrReplace, soit XPAttrMerge.

DESCRIPTION

XpSetAttributes accepte pool, une chaîne de ressources COMPOUND_TEXT représentant de nouvelles paires nom-valeur pour le pool d'attributs spécifié par type. Le pool d'attributs est modifié par les nouvelles paires nom-valeur conformément à replacement_rule. Pour XPAttrReplace, le pool d'attributs existant est rejeté et remplacé par pool. Pour XPAttrMerge, pool est fusionné dans le pool d'attributs existant ; les paires nom-valeur préexistantes sont remplacées, et les paires nom-valeur inexistantes sont ajoutées. Le contenu de pool n'est pas affecté par cet appel, et peut être libéré par l'appelant par la suite.

Lors de la définition des noms d'attributs pris en charge, le serveur d'impression X et le pilote associé valideront les nouvelles valeurs et ignoreront celles qui sont invalides ; les valeurs précédentes restent inchangées. Lors de la définition de noms d'attributs non pris en charge (c'est-à-dire inconnus), aucune validation n'est effectuée, et les paires nom-valeur seront définies, même si elles ne seront pas utilisées. Lors de la suppression (c'est-à-dire, ne pas réinitialiser avec XPAttrReplace) d'un nom d'attribut pris en charge, le serveur d'impression X réinitialise explicitement ou implicitement l'attribut à une valeur par défaut.

Lors de la définition de certains attributs pris en charge, le serveur d'impression X peut modifier d'autres attributs associés. Par exemple, en considérant l'attribut XPPrinterAttr document-formats-supported, la définition de l'attribut XPDocAttr document-format peut entraîner la modification d'un certain nombre d'autres attributs.

Pour les pools d'attributs qui sont en lecture seule (voir « get only » dans la définition de XPAttributes), tenter d'utiliser XpSetAttributes génère un BadMatch. Pour les pools d'attributs inscriptibles, des listes des attributs pris en charge se trouvent dans le pool XPPrinterAttr.

La durée de vie de tous les pools d'attributs est limitée par la durée de vie du contexte d'impression qu'ils contiennent. Une fois définies, toutes les valeurs d'attributs seront conservées pour toutes les opérations Xp, jusqu'à ce qu'elles soient modifiées directement par l'utilisateur, par le serveur d'impression X directement, ou modifiées en raison d'un effet secondaire lorsque l'utilisateur ou le serveur d'impression X a modifié une autre valeur d'attribut.

Se référer à une description complète de tous les attributs d'impression, la précédence entre les attributs d'impression, et les effets secondaires de la définition de certains attributs d'impression sur d'autres attributs d'impression, etc.

Pour surveiller les changements apportés aux pools d'attributs, voir XpSelectInput et l'événement XPAttributeNotify. Étant donné qu'un contexte d'impression peut être partagé entre plusieurs clients, les changements apportés par un client seront visibles par tous les autres, et si la sélection est faite, l'événement XPAttributeNotify sera envoyé à tous les clients référençant le contexte d'impression lorsque des changements surviennent. Il incombe aux clients partageant un contexte d'impression de coordonner leurs opérations.

STRUCTURES

Les valeurs pour le typedef XPAttributes dans <X11/extensions/Print.h> sont :

    #define XPJobAttr		1	/∗ get/set */
    #define XPDocAttr		2	/∗ get/set */
    #define XPPageAttr		3	/∗ get/set - subset of XPDocAttr */
    #define XPPrinterAttr	4	/∗ get only (library) */
    #define XPServerAttr		5	/∗ get only (library), no context needed */

Les valeurs pour le typedef XPAttrReplacement dans <X11/extensions/Print.h> sont :

    #define XPAttrReplace	1
    #define XPAttrMerge		2

DIAGNOSTICS

BadAlloc
Mémoire insuffisante.
BadMatch
Le pool d'attributs spécifié par pool ne peut pas être défini.
BadValue
La valeur spécifiée pour type n'est pas valide.
XPBadContext
L'identifiant de contexte d'impression spécifié n'est pas valide.
XPBadSequence
Une requête pour définir un pool d'attributs a eu lieu à un moment où le pool d'attributs ne pouvait pas être modifié (par exemple, modification de XPJobAttr immédiatement après l'appel de XpStartJob).
