XpGetScreenOfContext(3Xp) FONCTIONS XPRINT XpGetScreenOfContext(3Xp)

NOM

XpGetScreenOfContext - Obtient un pointeur vers l'écran associé au contexte d'impression spécifié.

SYNTAXE


cc [ flag... ] file... -lXp [ library... ]
#include <X11/extensions/Print.h>

Screen *XpGetScreenOfContext ( display, print_context )
Display *display;
XPContext print_context;

ARGUMENTS

display
Spécifie un pointeur vers la structure Display ; retournée par XOpenDisplay.
print_context
Un contexte d'impression préexistant. Cet argument est actuellement ignoré, mais doit être spécifié.

DESCRIPTION

XpGetScreenOfContext retourne l'écran qui est associé au contexte d'impression actuel de l'affichage. Cet appel doit être effectué après XpSetContext pour déterminer sur quel écran spécifique les autres ressources X doivent être créées.

Chaque imprimante supportée par un serveur d'impression est associée à exactement un des écrans retournés dans la réponse de configuration de connexion.

Cette fonction retourne NULL si l'écran n'a pas pu être obtenu.

DIAGNOSTICS

XPBadContext
Un identifiant de contexte d'impression valide n'a pas été défini avant de passer cet appel.

VOIR AUSSI

XpSetContext(3Xp)
