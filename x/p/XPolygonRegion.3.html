XPolygonRegion(3) FONCTIONS XLIB XPolygonRegion(3)

NOM

XPolygonRegion, XClipBox - générer des régions

SYNTAXE

Region XPolygonRegion(XPoint points[], int n, int fill_rule);

int XClipBox(Region r, XRectangle *rect_return);

ARGUMENTS

fill_rule
Spécifie la règle de remplissage que vous souhaitez définir pour le GC spécifié. Vous pouvez passer EvenOddRule ou WindingRule.
n
Spécifie le nombre de points dans le polygone.
points
Spécifie un tableau de points.
r
Spécifie la région.
rect_return
Retourne le rectangle englobant le plus petit.

DESCRIPTION

La fonction XPolygonRegion renvoie une région pour le polygone défini par le tableau de points. Pour une explication de fill_rule, voir XCreateGC.

La fonction XClipBox renvoie le plus petit rectangle englobant la région spécifiée.
