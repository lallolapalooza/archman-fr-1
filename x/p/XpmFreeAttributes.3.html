XpmMisc(3) Fonctions libXpm XpmMisc(3)

NOM

XpmMisc - fonctions diverses Xpm pour libérer la mémoire utilisée et gérer les erreurs

SYNTAXE

int XpmFreeXpmImage(XpmImage *image);
int XpmFreeXpmInfo(XpmInfo *info);
int XpmFreeAttributes(XpmAttributes *attributes);
int XpmAttributesSize(void);
int XpmFreeExtensions(XpmExtension *extensions,  int nextensions);
int XpmFree(char *ptr);
char *XpmGetErrorString(int errorcode);
int XpmLibraryVersion(void);

ARGUMENTS

image
Spécifie la structure à libérer
info
Spécifie la structure à libérer
ptr
Spécifie les données à libérer
errorcode
Spécifie l'erreur XPM
extensions
Spécifie le tableau à libérer
nextensions
Spécifie le nombre d'extensions
attributes
Spécifie la structure à libérer

DESCRIPTION

Pour libérer d'éventuelles données stockées dans une structure XpmImage, utilisez XpmFreeXpmImage(). La fonction XpmFreeXpmImage() libère les membres de la structure qui ne sont pas NULL, mais pas la structure elle-même.

Pour libérer d'éventuelles données stockées dans une structure XpmInfo, utilisez XpmFreeXpmInfo().

Pour libérer d'éventuelles données stockées dans un tableau d'extensions Xpm, utilisez XpmFreeExtensions().

Pour libérer toutes données allouées par une fonction XPM, utilisez la fonction XpmFree(). La distribution actuelle de la librairie XPM utilise les fonctions d'allocation mémoire standards et donc XpmFree() n'est rien d'autre qu'un define de la fonction standard free(3). Cependant, ces fonctions pouvant être redéfinies dans des environnements spécifiques, il est sage d'utiliser XpmFree()

Pour libérer d'éventuelles données stockées dans une structure XpmAttributes, utilisez XpmFreeAttributes(). La fonction XpmFreeAttributes() libère les membres de la structure qui ont été alloués par malloc, tels que la liste des pixels.

Pour allouer dynamiquement une structure XpmAttributes, utilisez la fonction XpmAttributesSize(). La fonction XpmAttributesSize() fournit aux applications utilisant des bibliothèques dynamiques un moyen sûr d'allouer et ensuite de référencer une structure XpmAttributes, sans tenir compte du fait que la taille de la structure XpmAttributes a pu changer depuis la compilation.

Pour obtenir des données lors de la construction d'un message d'erreur, on peut utiliser XpmGetErrorString(). XpmGetErrorString() renvoie une chaîne de caractères relative au code d'erreur XPM donné.

La fonction XpmLibraryVersion() peut être utilisée lorsqu'on a besoin de déterminer quelle version de la bibliothèque est en cours d'utilisation. La valeur renvoyée par XpmLibraryVersion() peut être comparée à la valeur de XpmIncludeVersion, qui est définie dans le fichier d'en-tête "xpm.h". Ces nombres sont calculés avec la formule suivante :

 (XpmFormat * 100 + XpmVersion) * 100 + XpmRevision

où XpmFormat est le numéro de version du format, XpmVersion est le numéro de version de la bibliothèque (qui ne change que si l'API change), et XpmRevision est le numéro de version mineure de la bibliothèque.

La fonction XpmFreeExtensions() libère toutes les données stockées dans chaque extension ainsi que le tableau lui-même. Notez que XpmFreeAttributes() appelle cette fonction et donc, la plupart du temps, elle ne devrait pas avoir besoin d'être appelée explicitement.
