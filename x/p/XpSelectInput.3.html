XpSelectInput(3Xp) FONCTIONS XPRINT XpSelectInput(3Xp)

NOM

XpSelectInput - Spécifie les événements X Print auxquels le client s'intéresse, à partir du contexte d'impression spécifié.

SYNTAXE

void XpSelectInput ( display, context, event_mask )
Display *display;
XPContext context;
unsigned long event_mask;

ARGUMENTS

display
Spécifie un pointeur vers la structure Display ; renvoyé par XOpenDisplay.
context
Spécifie le contexte d'impression à partir duquel sélectionner les événements.
event_mask
Spécifie le masque d'événements event_mask. Ce masque est l'OR bit à bit d'un ou plusieurs des bits valides du masque d'événements (voir ci-dessous).

DESCRIPTION

XpSelectInput sélectionne les événements X Print du contexte d'impression spécifié auxquels le client s'intéresse. Les événements X Print sont générés à partir d'un contexte d'impression courant, et non d'une fenêtre comme c'est le cas avec XSelectInput.

STRUCTURES

Les bits pour event_mask sont définis dans <X11/extensions/Print.h> :

    #define XPNoEventMask		0
    #define XPPrintMask			(1L<<0)
    #define XPAttributeMask		(1L<<1)
Les événements résultants sont définis dans <X11/extensions/Print.h> : 
    #define XPPrintNotify		0
    #define XPAttributeNotify		1

DIAGNOSTICS

BadValue
La valeur spécifiée pour event_mask n'est pas valide.
XPBadContext
Le contexte d'impression spécifié n'est pas valide.

FICHIERS

libXp 1.0.4 X Version 11
