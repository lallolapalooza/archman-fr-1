XPresentSelectInput(3) Version X11 XPresentSelectInput(3)

NOM

XPresentSelectInput - sélectionner les événements de l'extension X Present à recevoir

SYNTAXE

#include <X11/extensions/Xpresent.h>

XID XPresentSelectInput (Display *display,
	Window window,
	unsigned int event_mask);

void XPresentFreeInput (Display *display,
        Window window,
        XID event_id);

DESCRIPTION

XPresentSelectInput sélectionne un ensemble d'événements Present à livrer pour la fenêtre spécifiée sur le serveur X spécifié par display.

XPresentSelectInput renvoie un XID qui peut être passé à XPresentFreeInput pour arrêter de recevoir les événements demandés.

VOIR AUSSI

Xpresent(3), XPresentNotifyMSC(3), XPresentPixmap(3), XPresentQueryCapabilities(3)
