XpSetContext(3Xp) FONCTIONS IMPRESSION X XpSetContext(3Xp)

NOM

XpSetContext - Définit ou annule un contexte d'impression avec la connexion d'affichage spécifiée au serveur d'impression X.

SYNOPSIS


cc [ flag... ] file... -lXp [ library... ]
#include <X11/extensions/Print.h>

void XpSetContext ( display, print_context )
Display *display;
XPContext print_context;

ARGUMENTS

display
Spécifie un pointeur vers la structure Display ; retournée par XOpenDisplay.
print_context
Un contexte d'impression préexistant sur le même serveur X.

DESCRIPTION

XpSetContext définit le contexte d'impression pour une connexion d'affichage. Toutes les opérations d'impression ultérieures qui ne prennent pas explicitement un identifiant de contexte d'impression (par exemple, XpStartJob) sur l'affichage utiliseront et agiront sur le contexte d'impression défini par cet appel, jusqu'à ce que le contexte d'impression soit annulé ou que XpDestroyContext soit appelé. Le contexte d'impression peut être défini et utilisé pour plusieurs travaux, s'il n'est pas détruit.

Si print_context est None, XpSetContext annulera (dissociera) le contexte d'impression précédemment associé à l'affichage. S'il n'y avait pas de contexte d'impression précédemment associé, aucune action n'est effectuée. Le contenu du contexte d'impression anciennement associé n'est pas affecté par cet appel, et d'autres connexions d'affichage peuvent continuer à utiliser le contexte d'impression.

Étant donné que les capacités de polices peuvent varier d'une imprimante à l'autre, XpSetContext peut modifier la liste des polices disponibles (voir XListFonts) sur l'affichage, et l'ensemble réel des polices utilisables (voir XLoadFont). Une combinaison unique de polices peut être disponible au sein d'un contexte d'impression donné ; un client ne doit pas supposer que toutes les polices disponibles lorsqu'aucun contexte d'impression n'est défini seront disponibles lorsqu'un contexte d'impression est défini.

Lorsqu'un contexte d'impression est défini sur une connexion d'affichage, le comportement par défaut de ListFonts et ListFontsWithInfo est de lister toutes les polices normalement associées au serveur d'impression X (c'est-à-dire les polices contenant des glyphes) ainsi que toutes les polices d'imprimante internes définies pour l'imprimante. L'attribut xp-listfonts-modes est fourni afin que les applications puissent contrôler le comportement de ListFonts et ListFontsWithInfo et est généralement utilisé pour afficher uniquement les polices d'imprimante internes. L'utilisation exclusive des polices d'imprimante internes est utile pour des raisons de performance ; les glyphes associés à la police sont contenus dans l'imprimante et n'ont pas besoin d'être téléchargés.

Si la valeur de xp-listfonts-modes inclut xp-list-glyph-fonts, ListFonts et ListFontsWithInfo incluront toutes les polices disponibles pour le serveur qui ont des glyphes associés. Si la valeur de xp-listfonts-modes inclut xp-list-internal-printer-fonts, alors ListFonts et ListFontsWithInfo incluront toutes les polices définies comme polices d'imprimante internes.

Lorsque le contexte d'impression est annulé ou que XpDestroyContext est appelé, les polices disponibles sur l'affichage reviennent à leur état précédent.

DIAGNOSTICS

XPBadContext
Un identifiant de contexte d'impression valide n'a pas été défini avant de faire cet appel.

VOIR AUSSI
