NOM

XpFreePrinterList - Libère une liste d'enregistrements d'imprimante.

SYNTAXE


cc [ indicateur... ] fichier... -lXp [ bibliothèque... ]

void XpFreePrinterList ( liste_imprimantes )
XPPrinterList liste_imprimantes;

ARGUMENTS

liste_imprimantes

DESCRIPTION

XpFreePrinterList libère la liste d'enregistrements d'imprimante retournée par XpGetPrinterList.
