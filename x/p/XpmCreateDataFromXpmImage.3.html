NOM

XpmCreateData - créer une structure Data

SYNTAXE

int XpmCreateDataFromImage(Display *display, char ***data_return,
XImage *image, XImage *shapeimage, XpmAttributes *attributes);
int XpmCreateDataFromPixmap(Display *display, char ***data_return,
Pixmap pixmap, Pixmap shapemask, XpmAttributes *attributes);

XpmInfo *info);

ARGUMENTS

display
Spécifie la connexion au serveur X.
data_return
Retourne les données qui sont créées.
pixmap
Spécifie le pixmap.
shapemask
Spécifie le pixmap du masque de forme.
attributes
Spécifie l'emplacement d'une structure contenant des informations (ou NULL).
info
Spécifie l'emplacement d'une structure pour obtenir des informations.
image
Spécifie l'image

DESCRIPTION

XpmCreateDataFromImage

Dans certains cas, on peut vouloir créer des données XPM à partir d'un XImage, pour ce faire, utilisez XpmCreateDataFromImage(). La fonction XpmCreateDataFromImage() fonctionne exactement comme XpmWriteFileFromImage(3) et retourne de la même manière. Elle écrit simplement dans un seul bloc de données alloué par malloc au lieu d'un fichier. Il est de la responsabilité de l'appelant de libérer les données en utilisant XpmFree(3) une fois terminé.

XpmCreateDataFromPixmap

XpmCreateDataFromPixmap() crée des données XPM à partir d'un Pixmap. La fonction XpmCreateDataFromPixmap() utilise XGetImage(3) pour obtenir à partir des pixmaps donnés les images X associées qui sont passées à XpmCreateDataFromImage(). Ensuite, elle détruit les images créées en utilisant XDestroyImage(3). XpmCreateDataFromPixmap() retourne les mêmes erreurs que XpmCreateDataFromImage().

XpmCreateDataFromXpmImage

XpmCreateDataFromXpmImage() crée des données XPM à partir d'un XpmImage. La fonction XpmCreateDataFromXpmImage() écrit l'image donnée dans un seul bloc de données alloué par malloc au format XPM. Si suffisamment de mémoire de travail n'est pas allouée, elle retourne XpmNoMemory, et retourne XpmSuccess en cas de succès. Si le pointeur de structure XpmInfo passé n'est pas NULL, XpmCreateDataFromXpmImage() recherche les attributs suivants : XpmExtensions et XpmHotspot, et écrit les informations associées également. Il est de la responsabilité de l'appelant de libérer les données en utilisant XpmFree(3) une fois terminé.

VOIR AUSSI

XpmFree(3), XpmWriteFileFromImage(3)
