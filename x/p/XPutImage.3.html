XPutImage(3) FONCTIONS XLIB XPutImage(3)

NOM

XPutImage, XGetImage, XGetSubImage - transférer des images

SYNTAXE

int XPutImage(Display *display, Drawable d, GC gc, XImage *image, int src_x, int src_y, int dest_x, int dest_y, unsigned int width, unsigned int height);

XImage *XGetImage(Display *display, Drawable d, int x, int y, unsigned int width, unsigned int height, unsigned long plane_mask, int format);

XImage *XGetSubImage(Display *display, Drawable d, int x, int y, unsigned int width, unsigned int height, unsigned long plane_mask, int format, XImage *dest_image, int dest_x, dest_y);

ARGUMENTS

d
Spécifie le drawable.
dest_image
Spécifie l'image de destination.
dest_x

dest_y
Spécifient les coordonnées x et y, qui sont relatives à l'origine du drawable et sont les coordonnées de la sous-image ou qui sont relatives à l'origine du rectangle de destination, spécifient son coin supérieur gauche et déterminent où la sous-image est placée dans l'image de destination.
display
Spécifie la connexion au serveur X.
format
Spécifie le format de l'image. Vous pouvez passer XYPixmap ou ZPixmap.
gc
Spécifie le GC.
image
Spécifie l'image que vous souhaitez combiner avec le rectangle.
plane_mask
Spécifie le masque de plan.
src_x
Spécifie le décalage en X depuis le bord gauche de l'image définie par la structure XImage.
src_y
Spécifie le décalage en Y depuis le bord supérieur de l'image définie par la structure XImage.
width

height
Spécifient la largeur et la hauteur de la sous-image, qui définissent les dimensions du rectangle.
x

y
Spécifient les coordonnées x et y, qui sont relatives à l'origine du drawable et définissent le coin supérieur gauche du rectangle.

DESCRIPTION

La fonction XPutImage combine une image avec un rectangle du drawable spécifié. La section de l'image définie par les arguments src_x, src_y, width et height est dessinée sur la partie spécifiée du drawable. Si le format XYBitmap est utilisé, la profondeur de l'image doit être de un, sinon une erreur BadMatch résulte. Le pixel de premier plan dans le GC définit la source pour les bits de valeur un dans l'image, et le pixel d'arrière-plan définit la source pour les bits de valeur zéro. Pour XYPixmap et ZPixmap, la profondeur de l'image doit correspondre à la profondeur du drawable, sinon une erreur BadMatch résulte.

Si les caractéristiques de l'image (par exemple, byte_order et bitmap_unit) diffèrent de ce que le serveur requiert, XPutImage effectue automatiquement les conversions appropriées.

Cette fonction utilise ces composants du GC : function, plane-mask, subwindow-mode, clip-x-origin, clip-y-origin et clip-mask. Elle utilise également ces composants dépendant du mode du GC : foreground et background.

XPutImage peut générer les erreurs BadDrawable, BadGC, BadMatch et BadValue.

La fonction XGetImage retourne un pointeur vers une structure XImage. Cette structure vous fournit le contenu du rectangle spécifié du drawable dans le format que vous spécifiez. Si l'argument format est XYPixmap, l'image ne contient que les plans de bits que vous avez passés à l'argument plane_mask. Si l'argument plane_mask ne demande qu'un sous-ensemble des plans de l'écran, la profondeur de l'image retournée sera le nombre de plans demandés. Si l'argument format est ZPixmap, XGetImage retourne à zéro les bits dans tous les plans non spécifiés dans l'argument plane_mask. La fonction n'effectue aucune vérification de plage sur les valeurs de plane_mask et ignore les bits supplémentaires.

XGetImage retourne la profondeur de l'image au membre depth de la structure XImage. La profondeur de l'image est celle spécifiée lors de la création du drawable, sauf lors de la récupération d'un sous-ensemble des plans en format XYPixmap, où la profondeur est donnée par le nombre de bits mis à 1 dans plane_mask.

Si le drawable est un pixmap, le rectangle donné doit être entièrement contenu dans le pixmap, sinon une erreur BadMatch résulte. Si le drawable est une fenêtre, la fenêtre doit être visible, et il doit être vrai que s'il n'y avait pas d'inférieurs ou de fenêtres superposées, le rectangle spécifié de la fenêtre serait entièrement visible à l'écran et entièrement contenu dans les bords extérieurs de la fenêtre, sinon une erreur BadMatch résulte. Notez que les bordures de la fenêtre peuvent être incluses et lues avec cette requête. Si la fenêtre a un backing-store, le contenu du backing-store est retourné pour les régions de la fenêtre qui sont obscurcies par des fenêtres non-inférieures. Si la fenêtre n'a pas de backing-store, le contenu retourné de ces régions obscurcies est indéfini. Le contenu retourné des régions visibles d'inférieurs ayant une profondeur différente de la profondeur de la fenêtre spécifiée est également indéfini. L'image du curseur pointeur n'est pas incluse dans le contenu retourné. Si un problème survient, XGetImage retourne NULL.

XGetImage peut générer les erreurs BadDrawable, BadMatch et BadValue.

La fonction XGetSubImage met à jour dest_image avec la sous-image spécifiée de la même manière que XGetImage. Si l'argument format est XYPixmap, l'image ne contient que les plans de bits que vous avez passés à l'argument plane_mask. Si l'argument format est ZPixmap, XGetSubImage retourne à zéro les bits dans tous les plans non spécifiés dans l'argument plane_mask. La fonction n'effectue aucune vérification de plage sur les valeurs de plane_mask et ignore les bits supplémentaires. Par commodité, XGetSubImage retourne un pointeur vers la même structure XImage spécifiée par dest_image.

La profondeur de la structure XImage de destination doit être la même que celle du drawable. Si la sous-image spécifiée ne rentre pas à l'emplacement spécifié dans l'image de destination, les bords droit et inférieur sont coupés. Si le drawable est un pixmap, le rectangle donné doit être entièrement contenu dans le pixmap, sinon une erreur BadMatch résulte. Si le drawable est une fenêtre, la fenêtre doit être visible, et il doit être vrai que s'il n'y avait pas d'inférieurs ou de fenêtres superposées, le rectangle spécifié de la fenêtre serait entièrement visible à l'écran et entièrement contenu dans les bords extérieurs de la fenêtre, sinon une erreur BadMatch résulte. Si la fenêtre a un backing-store, alors le contenu du backing-store est retourné pour les régions de la fenêtre qui sont obscurcies par des fenêtres non-inférieures. Si la fenêtre n'a pas de backing-store, le contenu retourné de ces régions obscurcies est indéfini. Le contenu retourné des régions visibles d'inférieurs ayant une profondeur différente de la profondeur de la fenêtre spécifiée est également indéfini. Si un problème survient, XGetSubImage retourne NULL.

XGetSubImage peut générer les erreurs BadDrawable, BadGC, BadMatch et BadValue.

DIAGNOSTICS

BadDrawable
Une valeur pour un argument Drawable ne nomme pas une Fenêtre ou un Pixmap défini.
BadGC
Une valeur pour un argument GContext ne nomme pas un GContext défini.
BadMatch
Une fenêtre InputOnly est utilisée comme Drawable.
BadMatch
Un argument ou une paire d'arg

XPutImage(3) - X Version 11

NAME

XPutImage - mettre une image sur un écran

SYNTAX

int XPutImage(Display *display, Drawable d, GC gc, XImage *image, int x, int y, int src_x, int src_y, unsigned int width, unsigned int height);

ARGUMENTS

display
Spécifie la connexion au serveur X.
d
Spécifie la fenêtre ou le pixmap sur lequel l'image sera dessinée.
gc
Spécifie le contexte graphique à utiliser.
image
Spécifie l'image à placer.
x
Spécifie la coordonnée x du coin supérieur gauche de la zone de destination sur l'écran.
y
Spécifie la coordonnée y du coin supérieur gauche de la zone de destination sur l'écran.
src_x
Spécifie la coordonnée x de l'origine de la région de l'image à transférer.
src_y
Spécifie la coordonnée y de l'origine de la région de l'image à transférer.
width
Spécifie la largeur de la région de l'image à transférer.
height
Spécifie la hauteur de la région de l'image à transférer.

DESCRIPTION

La fonction XPutImage copie une image depuis la mémoire locale vers la zone de destination spécifiée sur l'écran. La région de l'image à copier est définie par src_x, src_y, width et height. La zone de destination sur l'écran est définie par x et y, qui spécifient les coordonnées du coin supérieur gauche de la région de destination. Les dimensions de la région de destination sont identiques à celles de la région source (width et height).

Le contexte graphique gc est utilisé pour définir les attributs de dessin, tels que la couleur d'avant-plan et d'arrière-plan, le masque, etc. L'image doit être au format spécifié par la structure XImage.

Si la largeur ou la hauteur spécifiées sont supérieures aux dimensions de l'image, ou si elles sont négatives, le comportement est indéfini.

Si le type de données de l'image ne correspond pas au type de données attendu par le serveur X, ou si la taille de l'image est trop grande, une erreur peut se produire.

DIAGNOSTICS

En cas d'erreur, XPutImage renvoie BadDrawable, BadGC, ou BadValue.

BadDrawable
La valeur du drawable spécifié n'est pas valide.
BadGC
La valeur du contexte graphique spécifié n'est pas valide.
BadValue
Une valeur numérique est en dehors de la plage acceptée par la requête. Sauf si une plage spécifique est définie pour un argument, la plage complète définie par le type de l'argument est acceptée. Tout argument défini comme un ensemble d'alternatives peut générer cette erreur.
