XpEndJob(3Xp) FONCTIONS XPRINT XpEndJob(3Xp)

NOM

XpEndJob - Indique la fin d'une tâche d'impression unique.

SYNTAXE


cc [ option... ] fichier... -lXp [ librairie... ]
#include <X11/extensions/Print.h>

void XpEndJob ( display )
Display *display;

ARGUMENTS

display
Spécifie un pointeur vers la structure Display ; retourné par XOpenDisplay.

DESCRIPTION

XpEndJob signale la fin d'une tâche d'impression. Toute donnée d'impression accumulée restante est soit envoyée à l'imprimante, soit rendue disponible à XpGetDocumentData.

Pour les clients sélectionnant XPPrintMask (voir XpSelectInput), l'événement XPPrintNotify sera généré avec son champ detail défini à XPEndJobNotify lorsque le Serveur d'impression X aura terminé la requête.

DIAGNOSTICS

XPBadContext
Un identifiant de contexte d'impression valide n'a pas été défini avant cet appel.
XPBadSequence
La fonction n'a pas été appelée dans le bon ordre par rapport aux autres appels d'extension d'impression X. (Exemple, XpEndDoc avant XpStartDoc).

VOIR AUSSI

XpGetDocumentData(3Xp), XpSelectInput(3Xp), XpStartJob(3Xp)
