XpDestroyContext(3Xp) FONCTIONS XPRINT XpDestroyContext(3Xp)

NOM

XpDestroyContext - Obtient l'identifiant du contexte d'impression actuel pour une connexion d'affichage.

SYNTAXE


cc [ indicateur... ] fichier... -lXp [ bibliothèque... ]
#include <X11/extensions/Print.h>

void XpDestroyContext ( display, print_context )
Display *display;
XPContext print_context;

ARGUMENTS

display
Spécifie un pointeur vers la structure Display ; retourné par XOpenDisplay.
print_context
Spécifie le contexte d'impression à détruire.

DESCRIPTION

XpDestroyContext ferme toutes les associations en cours entre le contexte d'impression et les connexions d'affichage, puis détruit le contexte d'impression. Toutes les connexions d'affichage utilisant le contexte d'impression ne pourront plus y accéder.

La destruction d'un contexte d'impression entraînera l'annulation de toutes les pages, documents et travaux en cours dans le Serveur d'impression X.

DIAGNOSTICS

XPBadContext
Un identifiant de contexte d'impression valide n'a pas été défini avant d'effectuer cet appel.
