XpInputSelected(3Xp) FONCTIONS XPRINT XpInputSelected(3Xp)

NOM

XpInputSelected - Interroge les événements X Print que le client a sélectionné de recevoir du contexte d'impression spécifique.

SYNTAXE


cc [ indicateur... ] fichier... -lXp [ bibliothèque... ]
#include <X11/extensions/Print.h>

unsigned long XpInputSelected ( display, context, event_mask )
Display *display;
XPContext context;
unsigned long *all_event_mask_return;

ARGUMENTS

display
Spécifie un pointeur vers la structure Display ; renvoyé par XOpenDisplay.
context
Spécifie le contexte d'impression auquel l'interrogation est faite.
all_event_mask_return
Renvoie l'ensemble des événements que tout client a sélectionné.

DESCRIPTION

XpInputSelected renvoie un masque de bits décrivant quelles classes d'événements le client a sélectionné de recevoir. La valeur renvoyée à all_event_mask_return est l'union de tous les masques d'événements des clients. XpInputSelected interroge les événements X Print du contexte d'impression spécifié que le client a sélectionné de recevoir. Les événements X Print sont générés à partir d'un contexte d'impression, et non d'une fenêtre comme c'est le cas avec XSelectInput. Lorsque les événements arrivent, le champ contexte dans l'événement est utilisé pour déterminer quel contexte d'impression a généré l'événement. Voir XpSelectInput pour les valeurs event_mask et all_event_mask (??renvoie??).

DIAGNOSTICS

XPBadContext
Le contexte d'impression spécifié n'est pas valide.
