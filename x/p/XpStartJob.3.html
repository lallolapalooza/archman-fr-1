XpStartJob(3Xp) FONCTIONS XPRINT XpStartJob(3Xp)

NOM

XpStartJob - Indique le début d'un travail d'impression unique.

SYNTAXE


cc [ flag... ] fichier... -lXp [ librairie... ]
#include <X11/extensions/Print.h>

void XpStartJob ( display, output_mode )
Display *display;
XPSaveData output_mode;

ARGUMENTS

display
Spécifie un pointeur vers la structure Display ; retourné par XOpenDisplay.
output_mode
Spécifie comment les données de sortie de l'imprimante doivent être gérées.

DESCRIPTION

XpStartJob signale le début d'un nouveau travail d'impression.

Si output_mode est XPSpool, le serveur d'impression X mettra automatiquement en file d'attente la sortie de l'imprimante. Si output_mode est XPGetData, alors le serveur d'impression X met en tampon la sortie du document pour récupération par XpGetDocumentData. Dans ce cas, le serveur d'impression suspend le traitement des requêtes suivantes sur ce contexte d'impression jusqu'à ce qu'un autre client envoie XpGetDocumentData. Les opérations ultérieures utilisant le contexte d'impression peuvent être suspendues à tout moment en attendant le traitement des réponses de XpGetDocumentData pour lire toute sortie mise en tampon.

XpStartJob définit l'attribut de travail job-owner (inclus dans le pool XPJobAttr) juste avant d'émettre la requête PrintStartJob. Sur les systèmes POSIX, l'attribut job-owner est défini en utilisant getpwuid_r sur le résultat de getuid. Cet attribut peut être utilisé par le serveur d'impression X pour identifier l'utilisateur auprès du gestionnaire de files d'attente.

Toutes les modifications apportées au pool d'attributs XPJobAttr (voir XpSetAttributes) doivent être effectuées avant d'appeler XpStartJob, après quoi un XPBadSequence sera généré si des modifications sont tentées, jusqu'à ce que XpEndJob soit appelé.

Pour les clients sélectionnant XPPrintMask (voir XpSelectInput), l'événement XPPrintNotify sera généré avec son champ detail défini à XPStartJobNotify lorsque le serveur d'impression X aura terminé la requête PrintStartJob.

Conceptuellement, un "Job" est une collection de "Documents", où chaque Document est à son tour une collection de "Pages". Selon les installations d'impression sous-jacentes au serveur d'impression X, ces délimitations peuvent être mappées par un pilote DDX dans une fonctionnalité réelle (par exemple, voir l'attribut du serveur multiple-documents-supported).

STRUCTURES

Les valeurs XPSaveData pour output_mode sont définies dans <X11/extensions/Print.h>. :

    #define XPSpool               1   /∗ Données de job envoyées au spooler */
    #define XPGetData             2   /∗ Données de job via XpGetDocumentData */

DIAGNOSTICS

BadValue
La valeur spécifiée pour output_mode n'est pas valide.
XPBadContext
Un identifiant de contexte d'impression valide n'a pas été défini avant de faire cet appel.
XPBadSequence
La fonction n'a pas été appelée dans le bon ordre par rapport aux autres appels du service d'extension d'impression X (exemple, XpEndDoc avant XpStartDoc).
