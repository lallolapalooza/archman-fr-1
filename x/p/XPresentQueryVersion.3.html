XPresentQueryVersion(3)

Paquet: libxpresent

Licences: MIT

XPRESENT(3) Version X11 XPRESENT(3)

NOM

Xpresent - Extension X Present

SYNTAXE

#include <X11/extensions/Xpresent.h>

Bool XPresentQueryExtension (Display *dpy, int *major_opcode_return,
	int *event_base_return, int *error_base_return);

Status XPresentQueryVersion (Display *dpy,
	int *major_version_return,
	int *minor_version_return);

int XPresentVersion (void);

ARGUMENTS

dpy
Spécifie la connexion au serveur X.

DESCRIPTION

Xpresent est une bibliothèque conçue pour interagir avec l'extension X Present. L'extension Present fournit aux applications un moyen de mettre à jour le contenu de leurs fenêtres à partir d'un pixmap de manière bien définie, en synchronisant avec l'actualisation de l'affichage et en utilisant potentiellement un mécanisme plus efficace que la copie du contenu du pixmap source.

La fonction XPresentQueryExtension vérifie si le serveur X spécifié par dpy prend en charge l'extension X Present. Si le serveur ne prend pas en charge l'extension, elle retourne False. Si le serveur prend en charge l'extension, elle retourne True et définit les valeurs de major_opcode_return, event_base_return et error_base_return si les pointeurs ne sont pas NULL.

Les clients doivent appeler la fonction XPresentQueryExtension pour vérifier que le serveur prend en charge l'extension avant d'appeler toute autre fonction de cette extension.

La fonction XPresentQueryVersion définit les valeurs pointées par major_version_return et minor_version_return à la version de l'extension prise en charge par le serveur X spécifié par dpy. La fonction XPresentQueryVersion retourne la version de la bibliothèque libXpresent utilisée, telle que définie par la macro PRESENT_VERSION dans <X11/extensions/Xpresent.h>.

VOIR AUSSI

XPresentNotifyMSC(3), XPresentPixmap(3), XPresentQueryCapabilities(3), XPresentSelectInput(3)

RESTRICTIONS

Xpresent restera rétrocompatible après la sortie 1.0.
