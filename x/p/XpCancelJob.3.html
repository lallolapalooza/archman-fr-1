XpCancelJob(3Xp) FONCTIONS XPRINT XpCancelJob(3Xp)

NOM

XpCancelJob - Annule un travail d'impression unique.

SYNTAXE


cc [ flag... ] file... -lXp [ library... ]
#include <X11/extensions/Print.h>

void XpCancelJob ( display, discard )
Display *display;
Bool discard;

ARGUMENTS

display
Spécifie un pointeur vers la structure Display ; retourné par XOpenDisplay.
discard
Lorsque TRUE, spécifie que tous les événements XPPrintNotify doivent être ignorés.

DESCRIPTION

XpCancelJob annule un travail en cours. Si le travail a été démarré avec output_mode XPGetData, le flux de données vers XpGetDocumentData est terminé. Pour de nombreux langages de description de page, une telle terminaison arbitraire peut invalider la sortie.

Si le travail a été démarré avec output_mode XPSpool, en fonction du pilote et de la configuration du spooler, l'intégralité du travail peut être annulée ou un travail partiel peut être généré.

Si discard est TRUE, tous les événements XPPrintNotify avec un champ detail de XPEndPageNotify, XPEndDocNotify ou XPEndJobNotify sont ignorés avant que XpCancelJob ne retourne.

Pour les clients qui sélectionnent XPPrintMask (voir XpSelectInput), l'événement XPPrintNotify sera généré avec son champ detail défini à XPEndJobNotify.

DIAGNOSTICS

XPBadContext
Un identifiant de contexte d'impression valide n'a pas été défini avant d'effectuer cet appel.
XPBadSequence
La fonction n'a pas été appelée dans le bon ordre par rapport aux autres appels du service d'impression X (par exemple, XpEndJob avant XpStartJob).
