XpSetLocaleHinter(3)

Paquet: libxp

Licences: X11, X11-distribute-modifications-variant

XpSetLocaleHinter(3Xp) FONCTIONS XPRINT XpSetLocaleHinter(3Xp)

NOM

XpSetLocaleHinter - Définit une fonction "locale hinter" et sa description.

SYNTAXE


cc [ indic... ] fichier... -lXp [ librairie... ]
#include <X11/extensions/Print.h>

void XpSetLocaleHinter ( proc_hinter desc_hinter )
XPHinterProc proc_hinter;
char *desc_hinter;

ARGUMENTS

proc_hinter
Un pointeur vers une "procédure hinter".
desc_hinter
Un pointeur vers des informations contextuelles sur la procédure hinter de locale.

DESCRIPTION

Comme il n'existe (à ce jour) aucune norme industrielle unique pour les valeurs de locale, les informations de locale sur le client actuel requises par XpCreateContext, XpGetPrinterList et XpGetPdmStartParams sont au mieux considérées comme une "indication" lorsqu'elles sont transmises au serveur d'impression X et au PDM. Dans les environnements à fournisseur unique, l'indication de locale doit être cohérente et comprise. Cependant, dans les environnements multi-fournisseurs, l'indication de locale peut être comprise ou non. La locale de l'appelant sera utilisée comme valeur de repli par défaut.

XpSetLocaleHinter et XpGetLocaleHinter accèdent à des points d'entrée utilisés pour enregistrer des générateurs d'indications plus avancés. Par défaut, Xp utilise une procédure hinter qui appelle setlocale sur la catégorie CTYPE sur les systèmes POSIX, et desc_hinter est NULL.

XpSetLocaleHinter définit la proc_hinter et desc_hinter qui seront ultérieurement utilisées par les appels Xp nécessitant une indication de locale (voir ci-dessus). proc_hinter est la fonction qui générera l'indication de locale (par exemple, "C"), et desc_hinter est une chaîne de caractères, avec ou sans le mot-clé incorporable %locale%, qui fournit un contexte de niveau supérieur pour les résultats de proc_hinter.

Si proc_hinter est défini sur NULL, alors la procédure hinter Xp par défaut est installée. XpSetLocaleHinter fait sa propre copie privée de desc_hinter avant de retourner.

Un exemple d'appel pourrait ressembler à ceci :

    XpSetLocaleHinter( ma_hinter, "%locale%;CDElocale" );

Où ma_hinter pourrait ressembler à ceci :

   char *ma_hinter()
   {
       /∗
        * Utiliser setlocale() pour récupérer la locale actuelle.
        */
       return( my_x_strdup( setlocale(LC_CTYPE, (char *) NULL) ) );
   }

Lorsque la locale du client est nécessaire, si desc_hinter et les résultats de proc_hinter sont tous deux non-NULL, et que le mot-clé %locale% est trouvé dans desc_hinter, alors le mot-clé sera remplacé par le résultat de proc_hinter. La chaîne résultante sera utilisée comme indication de locale par les appels Xp.

Si desc_hinter et les résultats de proc_hinter sont tous deux non-NULL, mais que le mot-clé %locale% n'est pas trouvé dans desc_hinter, alors desc_hinter, tel quel, devient la chaîne utilisée comme indication de locale par les appels Xp.

Si l'un des éléments desc_hinter ou les résultats de proc_hinter est NULL, alors l'autre valeur non-NULL devient la chaîne utilisée comme indication de locale par les appels Xp.

Si desc_hinter et les résultats de proc_hinter sont NULL, alors une indication de locale NULL (c'est-à-dire (char *) NULL) est envoyée par les appels Xp.

La syntaxe pour desc_hinter est une variation de la norme X/Open non adoptée pour une "Syntaxe de Spécification de Locale Réseau de Chaînes" (X/Open, Distributed Internationalization Services, Version 2, 1994 Snapshot). La syntaxe desc_hinter de Xp est :

    spec_nom[;spec_registre[;spec_ver[;spec_encodage]]]

Dans Xp, le premier élément est le nom de la locale, suivi d'informations de plus en plus détaillées sur le nom de la locale, chaque élément étant séparé par un `;'.

STRUCTURES

La signature de proc_hinter est définie dans <X11/extensions/Print.h> comme suit :

    typedef char * (*XPHinterProc)();
proc_hinter est censé retourner une chaîne qui peut être libérée en utilisant XFree par les appels Xp eux-mêmes.

Quelques exemples incluent ( desc_hinter à gauche, résultats développés à droite) :

    CFRENCH                                CFRENCH
    %locale%                               C
    %locale%;CDElocale                     C;CDElocale
    %locale%;HP                            C;HP
    %locale%;IBM                           C;IBM
    %locale%;XOPEN;01_11;XFN-001001        de_DE;XOPEN;01_11;XFN-001001

FICHIERS
