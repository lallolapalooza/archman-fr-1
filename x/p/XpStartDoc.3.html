XpStartDoc(3Xp) FONCTIONS XPRINT XpStartDoc(3Xp)

NOM

XpStartDoc - Indique le début d'un document d'impression.

SYNTAXE


cc [ drapeau... ] fichier... -lXp [ bibliothèque... ]
#include <X11/extensions/Print.h>

void XpStartDoc ( display, type )
Display *display;
XPDocumentType type;

ARGUMENTS

display
Spécifie un pointeur vers la structure Display ; retournée par XOpenDisplay.
type
Spécifie le type de document. Il peut être soit XPDocRaw soit XPDocNormal.

DESCRIPTION

XpStartDoc signale le début d'un nouveau document d'impression.

Si type est XPDocRaw, alors le client fournira toutes les données pour le document résultant en utilisant XpPutDocumentData ; le serveur d'impression X n'écrira aucune donnée dans le document résultant. Appeler XpStartPage dans un document XPDocRaw générera une erreur XPBadSequence. Pour plus d'informations, voir XpPutDocumentData.

Si type est XPDocNormal, alors le serveur d'impression X générera les données du document, et selon le pilote DDX, peut incorporer des données supplémentaires de XpPutDocumentData dans la sortie. Pour plus d'informations, voir XpPutDocumentData.

Toutes les modifications apportées au pool d'attributs XPDocAttr (voir XpSetAttributes) doivent être effectuées avant d'appeler XpStartDoc, après quoi un XPBadSequence sera généré si des modifications sont tentées, jusqu'à ce que XpEndDoc soit appelé.

L'application n'est pas obligée d'appeler XpStartDoc et XpEndDoc lors de l'impression. La délimitation « document » peut ne pas être utile du point de vue de l'application ou du spooler, elle est donc facultative. Si XpStartPage est appelée immédiatement après XpStartJob, alors un XpStartDoc synthétique avec XPDocNormal sera supposé par le serveur d'impression X avant XpStartPage (c'est-à-dire que les événements XPStartDocNotify et XPStartPageNotify auront le même numéro de séquence). De même, si XpEndJob est appelée immédiatement après XpEndPage, alors un XpEndDoc synthétique sera supposé par le serveur d'impression X avant XpEndJob (c'est-à-dire que les événements XPEndDocNotify et XPEndJobNotify auront le même numéro de séquence).

Pour les clients sélectionnant XPPrintMask (voir XpSelectInput), l'événement XPPrintNotify sera généré avec son champ détail défini sur XPStartDocNotify.

STRUCTURES

Les valeurs de XPDocumentType sont définies dans <X11/extensions/Print.h> :

    #define   XPDocNormal     1     /∗ Données doc gérées par Xserver*/
    #define   XPDocRaw        2     /∗ Données doc passées via Xserver*/

DIAGNOSTICS

XPBadContext
Un identifiant de contexte d'impression valide n'a pas été défini avant de faire cet appel.
XPBadSequence
La fonction n'a pas été appelée dans le bon ordre par rapport aux autres appels de l'extension d'impression X (par exemple, XpEndDoc avant XpStartDoc).
BadValue
La valeur spécifiée pour type n'est pas valide.
