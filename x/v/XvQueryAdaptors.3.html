XvQueryAdaptors(3) Fonctions libXv XvQueryAdaptors(3)

NOM

XvQueryAdaptors - retourne les informations de l'adaptateur pour un écran

SYNTAXE

#include <X11/extensions/Xvlib.h>

int XvQueryAdaptors(Display *dpy, Window window,
                    unsigned int *p_num_adaptors,
                    XvAdaptorInfo **pp_adaptor_info);

ARGUMENTS

dpy
Spécifie la connexion au serveur X.
window
Spécifie une fenêtre de l'écran pour laquelle les informations de l'adaptateur sont désirées.
p_num_adaptors
Un pointeur vers l'emplacement où le nombre d'adaptateurs pour l'écran spécifié est retourné.
pp_adaptor_info
Un pointeur vers l'emplacement où la liste des informations d'adaptateur renvoyées est retournée.

DESCRIPTION

XvQueryAdaptors(3)
retourne les informations d'un adaptateur vidéo pour l'écran du dessin spécifié. La structure XvAdaptorInfo a l'organisation suivante :

     typedef struct {
       XvPortID base_id;
       unsigned long num_ports;
       char type;
       char *name;
       unsigned long num_formats;
       XvFormat *formats;
       unsigned long num_adaptors;
     } XvAdaptorInfo;
base_id
L'ID de ressource du premier port de l'adaptateur.
num_ports
Le nombre de ports supportés par l'adaptateur.
type
Un masque de bits avec la valeur XvInputMask affirmée si l'adaptateur supporte l'entrée vidéo, et la valeur XvOutputMask affirmée si l'adaptateur supporte la sortie vidéo. Dans le protocole Xv 2.2 et versions ultérieures, 3 nouveaux bits sont définis - XvVideoMask, XvStillMask et XvImageMask indiquant que l'adaptateur est capable de primitives vidéo, d'images fixes ou d'images respectivement.
name
Un nom spécifique au vendeur qui identifie l'adaptateur.
num_formats
Le nombre de formats de profondeur/ID visuel supportés par l'adaptateur.
formats
Un pointeur vers un tableau de structures XvFormat.

La structure XvFormat a l'organisation suivante :

     typedef struct {
       char depth;
       unsigned long visual_id;
     } XvFormat;
depth
Une profondeur de dessin supportée par l'adaptateur.
visual_id
Un ID visuel supporté pour la profondeur donnée par l'adaptateur.

VALEURS DE RETOUR

[Succès]
Retourné si XvQueryAdaptors(3) s'est terminé avec succès.
[XvBadExtension]
Retourné si l'extension Xv n'est pas disponible.
[XvBadAlloc]
Retourné si XvQueryAdaptors(3) n'a pas pu allouer de mémoire pour traiter la requête.

DIAGNOSTICS

[Drawable]
Retourné si le dessin demandé n'existe pas.
