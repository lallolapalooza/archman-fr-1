NOM

Xvfb - serveur X de tampon d'images virtuel pour X Version 11

SYNTAXE

Xvfb [ option ] ...

DESCRIPTION

Xvfb est un serveur X qui peut s'exécuter sur des machines sans matériel d'affichage et sans périphériques d'entrée physiques. Il émule un tampon d'images basique en utilisant la mémoire virtuelle.

L'utilisation principale de ce serveur était initialement prévue pour les tests de serveurs. Le code de tampon d'images de n'importe quelle profondeur peut être exercé avec ce serveur sans avoir besoin de matériel réel qui prend en charge les profondeurs souhaitées. La communauté X a trouvé de nombreuses autres utilisations nouvelles pour Xvfb, y compris le test de clients avec des profondeurs et des configurations d'écran inhabituelles, le traitement par lots avec Xvfb comme moteur de rendu en arrière-plan, les tests de charge, comme aide au portage du serveur X vers une nouvelle plateforme, et en fournissant un moyen discret d'exécuter des applications qui n'ont pas vraiment besoin d'un serveur X mais insistent pour en avoir un quand même.

OPTIONS

En plus des options normales du serveur décrites dans la page de manuel Xserver(1), Xvfb accepte les commutateurs de ligne de commande suivants :

-screen numéro-écran LxHxP
Cette option crée l'écran numéro-écran et définit sa largeur, sa hauteur et sa profondeur à L, H et P respectivement. Par défaut, seul l'écran 0 existe et a les dimensions 1280x1024x24.
-pixdepths liste-de-profondeurs
Cette option spécifie une liste de profondeurs de pixmaps que le serveur devrait prendre en charge en plus des profondeurs implicites par les écrans pris en charge. liste-de-profondeurs est une liste séparée par des espaces d'entiers qui peuvent avoir des valeurs de 1 à 32.
-fbdir répertoire-tampon-image
Cette option spécifie le répertoire dans lequel les fichiers mappés en mémoire contenant la mémoire du tampon d'images doivent être créés. Voir FICHIERS. Cette option n'existe que sur les machines qui ont les appels système mmap et msync.
-shmem
Cette option spécifie que le tampon d'images doit être placé en mémoire partagée. L'identifiant de mémoire partagée pour chaque écran sera imprimé par le serveur. La mémoire partagée est au format xwd. Cette option n'existe que sur les machines qui prennent en charge l'interface de mémoire partagée System V.

Si ni -shmem ni -fbdir n'est spécifié, la mémoire du tampon d'images sera allouée avec malloc().

-linebias n
Cette option spécifie comment ajuster la pixellisation des lignes fines. La valeur n est un masque de bits d'octants dans lesquels préférer une étape axiale lorsque le terme d'erreur de Bresenham est exactement nul. Voir le fichier Xserver/mi/miline.h pour plus d'informations. Cette option est probablement utile uniquement aux développeurs de serveurs pour expérimenter la gamme de pixellisation de lignes possible avec le code fb.
-blackpixel valeur-pixel, -whitepixel valeur-pixel
Ces options spécifient les valeurs de pixels noir et blanc que le serveur doit utiliser.

FICHIERS

Les fichiers suivants sont créés si l'option -fbdir est donnée.

répertoire-tampon-image/Xvfb_screen<n>
Fichier mappé en mémoire contenant la mémoire du tampon d'images de l'écran n, un fichier par écran. Le fichier est au format xwd. Ainsi, prendre une capture d'écran complète peut être fait avec une commande de copie de fichier, et la capture résultante contiendra même l'image du curseur.

EXEMPLES

Xvfb :1 -screen 0 1600x1200x24
Le serveur écoutera les connexions en tant que serveur numéro 1, et l'écran 0 aura une profondeur de 24 avec une résolution de 1600x1200.
Xvfb :1 -screen 1 1600x1200x16
Le serveur écoutera les connexions en tant que serveur numéro 1, l'écran 0 aura la configuration d'écran par défaut (1280x1024x24), et l'écran 1 aura une profondeur de 16 avec une résolution de 1600x1200.
Xvfb -pixdepths 3 27 -fbdir /var/tmp
Le serveur écoutera les connexions en tant que serveur numéro 0, aura la configuration d'écran par défaut (un écran, 1280x1024x24), prendra également en charge les profondeurs de pixmaps de 3 et 27, et utilisera des fichiers mappés en mémoire dans /var/tmp pour le tampon d'images.
xwud -in /var/tmp/Xvfb_screen0
Affiche l'écran 0 du serveur démarré par l'exemple précédent.
