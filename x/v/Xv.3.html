NOM

Xv - extension vidéo du système X Window

DESCRIPTION

L'extension X Video (Xv) fournit un support pour les adaptateurs vidéo connectés à un écran X. Elle adopte l'approche qu'un écran peut avoir un ou plusieurs adaptateurs vidéo, chacun ayant un ou plusieurs ports par lesquels transitent les flux vidéo indépendants.

Un adaptateur peut être capable d'afficher la vidéo dans un objet dessinable, de capturer la vidéo à partir d'un objet dessinable, ou les deux. Il traduit entre le codage vidéo (NTSC, PAL, SECAM, etc...) et le format de l'objet dessinable (paire profondeur et id visuel). Un adaptateur peut supporter plusieurs codages vidéo et/ou plusieurs formats d'objets dessinables.

Les clients utilisent Xv(3) pour accéder et gérer le partage des ressources vidéo d'un écran. Typiquement, un client utilisera XvQueryExtension(3) pour déterminer l'état de l'extension, XvQueryAdaptors(3) pour obtenir une description des adaptateurs vidéo existants, et XvQueryEncodings(3) pour obtenir une description des codages vidéo supportés par un adaptateur.

Une fois qu'un client a déterminé quelles ressources vidéo sont disponibles, il est libre de placer la vidéo dans un objet dessinable ou d'en extraire, conformément aux capacités supportées. Les clients peuvent choisir de recevoir des événements lorsque l'activité vidéo change dans un objet dessinable et lorsque les attributs des ports ont changé.

Le protocole Xv version 2.2 et ultérieures est étendu pour supporter les images client dans des espaces colorimétriques alternatifs (XvImages). Les adaptateurs Xv capables d'afficher des XvImages auront le champ XvImageMask défini dans le type du champ XvAdaptorInfo. Les formats XvImage supportés par le port peuvent être interrogés avec XvListImageFormats(3). Les XvImages peuvent être créés à l'aide de XvCreateImage(3) ou XvShmCreateImage(3) ; les XvImages peuvent être affichés avec XvPutImage(3) ou XvShmPutImage(3). Les attributs du port spécifié dans la commande Xv(Shm)PutImage seront valides pour l'opération d'image le cas échéant. Il y aura un codage de port nommé "XV_IMAGE". La largeur et la hauteur de ce codage indiqueront la taille maximale de l'image source.

RÉSUMÉ DES FONCTIONS DE BIBLIOTHÈQUE

Voici un résumé des fonctions et événements de la bibliothèque Xv :

XvCreateImage(3) - créer une XvImage

XvGetPortAttribute(3) - renvoyer la valeur actuelle d'un attribut de port

XvGetStill(3) - capturer une seule image vidéo à partir d'un objet dessinable

XvGetVideo(3) - capturer la vidéo à partir d'un objet dessinable

XvGrabPort(3) - verrouiller un port pour une utilisation exclusive par le client

XvListImageFormats(3) - renvoyer la liste des formats d'image pour un port

XvPortNotify(3) - événement généré lorsque les attributs du port changent

XvPutImage(3) - écrire une XvImage dans un objet dessinable

XvPutStill(3) - écrire une seule image vidéo dans un objet dessinable

XvPutVideo(3) - écrire la vidéo dans un objet dessinable

XvQueryAdaptors(3) - renvoyer des informations sur les adaptateurs pour un écran

XvQueryBestSize(3) - déterminer la taille optimale de la région dessinable

XvQueryEncodings(3) - renvoyer la liste des codages pour un adaptateur

XvQueryExtension(3) - renvoyer la version et la révision de l'extension

XvQueryPortAttributes(3) - renvoyer la liste des attributs d'un port

XvSelectPortNotify(3) - activer ou désactiver les événements XvPortNotify

XvSelectVideoNotify(3) - activer ou désactiver les événements XvVideoNotify

XvSetPortAttribute(3) - définir un attribut pour un port

XvShmCreateImage(3) - créer une XvImage en mémoire partagée

XvShmPutImage(3) - écrire une XvImage en mémoire partagée dans un objet dessinable

XvStopVideo(3) - arrêter la vidéo active

XvUngrabPort(3) - libérer un port saisi

XvVideoNotify(3) - événement généré pour le traitement vidéo

Chacune de ces fonctions et événements est décrite dans sa propre page man Xv.
