XvGrabPort(3) Fonctions libXv XvGrabPort(3)

NOM

XvGrabPort - Verrouiller un port pour une utilisation exclusive par un client

SYNTAXE

#include <X11/extensions/Xvlib.h>

int XvGrabPort(Display *dpy, XvPortID port, Time time);

ARGUMENTS

dpy
Spécifie la connexion au serveur X.
port
Définit le port à saisir.
time
Spécifie l'horodatage de la requête.

DESCRIPTION

XvGrabPort(3) saisit un port. Une fois qu'un client a saisi un port, seul ce client peut effectuer des requêtes vidéo sur ce port.

Si l'heure est antérieure à l'heure actuelle du port, la requête XvGrabPort est ignorée et XvInvalidTime est retourné. Si le port est déjà saisi par un autre client, XvAlreadyGrabbed est retourné. Sinon, le statut Success est retourné. L'heure du port est mise à jour lorsque les requêtes suivantes sont traitées : XvGrabPort(3), XvUngrabPort(3), XvPutVideo(3), XvPutStill(3), XvGetVideo(3), XvGetStill(3).

Si le port traite activement de la vidéo pour un autre client, la vidéo est interrompue et un événement XvVideoNotify avec le détail XvPreempted est généré pour sa fenêtre graphique.

VALEURS DE RETOUR

[Success]
Retourné si XvGrabPort(3) s'est terminé avec succès.
[XvInvalidTime]
Retourné si l'heure demandée est antérieure à l'heure actuelle du port.
[XvAlreadyGrabbed]
Retourné si le port est déjà saisi par un autre client.
[XvBadExtension]
Retourné si l'extension Xv n'est pas disponible.
[XvBadAlloc]
Retourné si XvGrabPort(3) n'a pas réussi à allouer de la mémoire pour traiter la requête.

DIAGNOSTICS

[XvBadPort]
Généré si le port demandé n'existe pas.

VOIR AUSSI

XvUngrabPort(3), XvVideoNotify(3)
