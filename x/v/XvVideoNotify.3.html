XvVideoNotify(3) Fonctions libXv XvVideoNotify(3)

NOM

XvVideoNotify - événement généré pour le traitement vidéo

SYNTAXE

#include <X11/extensions/Xvlib.h>

     typedef union {
       int type;
       XvVideoNotifyEvent xvvideo;
       XvPortNotifyEvent xvport;
       long pad[24];
     } XvEvent;
     typedef struct {
       int type;
       unsigned long serial;
       Bool send_event;
       Display *display;
       Drawable drawable;
       unsigned long reason;
       XvPortID port_id;
       Time time;
     } XvVideoNotifyEvent;
type
Spécifie le type d'événement : XvVideoNotify.
serial
Numéro de la dernière requête traitée par le serveur.
send_event
Vrai si l'événement a été généré par une requête SendEvent.
display
Un pointeur vers l'affichage à partir duquel l'événement a été lu.
drawable
Le drawable pour lequel l'événement a été généré.
reason
La raison pour laquelle l'événement a été généré : XvStarted, XvStopped, XvPreempted, XvBusy, XvHardError.
port_id
Le port traitant la vidéo pour laquelle l'événement a été généré.

DESCRIPTION

Les événements XvVideoNotify sont générés lorsque la vidéo est démarrée, arrêtée, supplantée par une autre requête vidéo, ignorée car le port est capturé par un autre client, ou interrompue en raison d'une erreur de transmission ou de réception matérielle.

VOIR AUSSI

XvPutVideo(3), XvPutStill(3), XvGetVideo(3), XvGetStill(3), XvStopVideo(3), XvSelectVideoNotify(3)
