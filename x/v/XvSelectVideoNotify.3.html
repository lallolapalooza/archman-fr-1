NOM

XvSelectVideoNotify - activer ou désactiver les événements VideoNotify

SYNTAXE

#include <X11/extensions/Xvlib.h>

int XvSelectVideoNotify(Display *dpy, Drawable drawable, Bool onoff);

ARGUMENTS

dpy
Spécifie la connexion au serveur X.
drawable
Définit le drawable pour lequel l'activité vidéo doit être signalée.
onoff
Sélectionne si la notification vidéo est activée ou désactivée.

DESCRIPTION

XvSelectVideoNotify(3) active ou désactive les événements XvVideoNotify(3) à signaler pour l'activité vidéo dans un drawable.

VALEURS DE RETOUR

[Succès]
Retourné si XvSelectVideoNotify(3) s'est terminé avec succès.
[XvBadExtension]
Retourné si l'extension Xv n'est pas disponible.
[XvBadAlloc]
Retourné si XvSelectVideoNotify(3) n'a pas pu allouer de mémoire pour traiter la requête.

DIAGNOSTICS

[BadDrawable]
Généré si le drawable demandé n'existe pas.
