XvCreateImage(3) Fonctions libXv XvCreateImage(3)

NOM

XvCreateImage, XvShmCreateImage - créer une XvImage

SYNTAXE

#include <X11/extensions/Xvlib.h>

XvImage * XvCreateImage (Display *dpy, XvPortID port,
                         int id, char *data,
                         int width, int height);

XvImage * XvShmCreateImage (Display *dpy, XvPortID port,
                            int id, char *data,
                            int width, int height,
                            XShmSegmentInfo *shminfo);

ARGUMENTS

dpy
Spécifie la connexion au serveur X.
port
Spécifie le port avec lequel la XvImage sera utilisée.
id
Spécifie le format de l'image à créer par l'identifiant XvImageFormatValues.
data
Spécifie les données de l'image.
width, height
Spécifie la largeur et la hauteur désirées de l'image.

DESCRIPTION

XvCreateImage(3) est similaire à XCreateImage(3). XvShmCreateImage(3) est similaire à XShmCreateImage(3). La bibliothèque allouera la structure XvImage et remplira tous les champs sauf pour data. Width et height peuvent être agrandis dans certains formats YUV. La taille du tampon de données qui doit être alloué sera indiquée dans le champ data_size de la XvImage. Les données de l'image ne sont pas allouées par cette fonction. Le client peut passer un pointeur vers la mémoire pré-allouée comme data ou peut allouer la mémoire et remplir le champ data de la structure XvImage après que le champ data_size ait été rempli par le serveur. La structure XvImage peut être libérée par XFree(3). Les segments de mémoire partagée sont attachés/détachés avec XShmAttach(3)/XShmDetach(3).

VALEURS DE RETOUR

XvImage a la structure suivante :

typedef struct {
   int id;
   int width, height;
   int data_size;
   int num_planes;
   int *pitches;
   int *offsets;
   char *data;
   XPointer obdata;
} XvImage;
id
Un descripteur pour le format de la structure XvImageFormatValues renvoyée par XvListImageFormats(3).
width, height
La largeur et la hauteur de l'image en pixels.
data_size
La taille du tampon de données en octets.
num_planes
Le nombre de plans d'image.
pitches
Un tableau de taille num_planes indiquant le pas de balayage en octets. Chaque plan peut avoir un pas différent.
offsets
Un tableau de taille num_planes indiquant le décalage en octets depuis data jusqu'au début de chaque plan.
data
Un pointeur vers le début du tampon de données.
obdata
Un champ privé pour contenir les informations SHM. Ce champ sera configuré par les bibliothèques clientes, de sorte que le programmeur n'aura généralement pas à s'en préoccuper.

DIAGNOSTICS

[XvBadPort]
Généré si le port demandé n'existe pas.
[XvBadAlloc]
Généré si le serveur X n'a pas pu allouer les ressources nécessaires pour compléter l'opération.
[BadMatch]
Généré si des arguments incompatibles ont été fournis, comme un port qui n'est pas capable d'afficher des XvImages.
