XVisibilityEvent(3) FONCTIONS XLIB XVisibilityEvent(3)

NOM

XVisibilityEvent - structure d'événement VisibilityNotify

STRUCTURES

La structure pour les événements VisibilityNotify contient :

typedef struct {
        int type;       /* VisibilityNotify */
        unsigned long serial;   /* # de la dernière requête traitée par le serveur */
        Bool send_event;        /* vrai si ceci provient d'une requête SendEvent */
        Display *display;       /* Display à partir duquel l'événement a été lu */
        Window window;
        int state;
} XVisibilityEvent;

Lorsque vous recevez cet événement, les membres de la structure sont définis comme suit.

Le membre type est défini à la constante de type d'événement qui l'identifie de manière unique. Par exemple, lorsque le serveur X signale un événement GraphicsExpose à une application cliente, il envoie une structure XGraphicsExposeEvent avec le membre type défini à GraphicsExpose. Le membre display est défini à un pointeur vers le display sur lequel l'événement a été lu. Le membre send_event est défini à True si l'événement provient d'une requête de protocole SendEvent. Le membre serial est défini à partir du numéro de série rapporté dans le protocole mais développé à partir des 16 bits les moins significatifs vers une valeur complète de 32 bits. Le membre window est défini à la fenêtre qui est la plus utile pour les répartiteurs de toolkit.

Le membre window est défini à la fenêtre dont l'état de visibilité change. Le membre state est défini à l'état de visibilité de la fenêtre et peut être VisibilityUnobscured, VisibilityPartiallyObscured, ou VisibilityFullyObscured. Le serveur X ignore toutes les sous-fenêtres d'une fenêtre lors de la détermination de l'état de visibilité de la fenêtre et traite les événements VisibilityNotify selon les règles suivantes :

  • Lorsque la fenêtre passe d'un état partiellement obscurci, entièrement obscurci, ou non visible à visible et complètement non obscurci, le serveur X génère l'événement avec le membre state de la structure XVisibilityEvent défini à VisibilityUnobscured.
  • Lorsque la fenêtre passe d'un état visible et complètement non obscurci, ou non visible, à visible et partiellement obscurci, le serveur X génère l'événement avec le membre state de la structure XVisibilityEvent défini à VisibilityPartiallyObscured.
  • Lorsque la fenêtre passe d'un état visible et complètement non obscurci, visible et partiellement obscurci, ou non visible, à visible et entièrement obscurci, le serveur X génère l'événement avec le membre state de la structure XVisibilityEvent défini à VisibilityFullyObscured.
