NOM

XvPortNotify - événement généré lorsque les attributs d'un port changent

SYNTAXE

#include <X11/extensions/Xvlib.h>

     typedef union {
       int type;
       XvVideoNotifyEvent xvvideo;
       XvPortNotifyEvent xvport;
       long pad[24];
     } XvEvent;
     typedef struct {
       int type;
       unsigned long serial;
       Bool send_event;
       Display *display;
       XvPortID port_id;
       Time time;
       Atom attribute;
       long value;
     } XvPortNotifyEvent;
type
Spécifie le type d'événement : XvPortNotify.
serial
Numéro de la dernière requête traitée par le serveur.
send_event
Vrai si l'événement a été généré par une requête SendEvent.
display
Un pointeur vers l'affichage à partir duquel l'événement a été lu.
port_id
Le port dont l'attribut a changé.
attribute
Un atome spécifiant l'attribut qui a changé.
value
La nouvelle valeur de l'attribut.

DESCRIPTION

Les événements XvPortNotify sont générés lorsqu'un attribut de port est défini à l'aide de la fonction XvSetPortAttribute(3).

VOIR AUSSI

XvSetPortAttribute(3), XvGetPortAttribute(3), XvSelectPortNotify(3).
