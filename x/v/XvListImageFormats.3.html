XvListImageFormats(3) Fonctions libXv XvListImageFormats(3)

NOM

XvListImageFormats - renvoie la liste des formats d'image pris en charge par un port vidéo

SYNTAXE

#include <X11/extensions/Xvlib.h>

XvImageFormatValues * XvListImageFormats (Display *dpy,
                 XvPortID port,  int *p_num_formats);

ARGUMENTS

dpy
Spécifie la connexion au serveur X.
port
Spécifie le port dont l'adaptateur doit être interrogé pour sa liste d'attributs.
p_num_formats
Un pointeur vers l'endroit où le nombre de formats renvoyés dans le tableau est écrit.

DESCRIPTION

XvListImageFormats(3) renvoie les XvImageFormatValues pris en charge par le port spécifié. Cette liste doit être libérée avec XFree(3).

VALEURS DE RETOUR

XvImageFormatValues a la structure suivante :

    typedef struct {
      int id;                      /* Descripteur unique pour le format */
      int type;                    /* XvRGB, XvYUV */
      int byte_order;              /* LSBFirst, MSBFirst */
      char guid[16];               /* Identifiant Unique Global */
      int bits_per_pixel;
      int format;                  /* XvPacked, XvPlanar */
      int num_planes;
      /* pour les formats RGB */
      int depth;
      unsigned int red_mask;
      unsigned int green_mask;
      unsigned int blue_mask;
      /* pour les formats YUV */
      unsigned int y_sample_bits;
      unsigned int u_sample_bits;
      unsigned int v_sample_bits;
      unsigned int horz_y_period;
      unsigned int horz_u_period;
      unsigned int horz_v_period;
      unsigned int vert_y_period;
      unsigned int vert_u_period;
      unsigned int vert_v_period;
      char component_order[32];    /* ex. UYVY */
      int scanline_order;          /* XvTopToBottom, XvBottomToTop */
    } XvImageFormatValues;
id
Un descripteur unique pour le format. Il s'agit souvent du FOURCC pour le format, le cas échéant. Cet identifiant est utilisé pour décrire le format lors de la création d'images XvImage.
type
XvRGB ou XvYUV.
byte_order
L'ordre des octets de l'image. Il est soit LSBFirst, soit MSBFirst.
guid
L'Identifiant Unique Global (également connu sous le nom d'Identifiant Unique Universel). Lorsqu'il n'est pas applicable, tous les caractères sont NULL.
bits_per_pixel
Le nombre d'octets occupés (mais pas nécessairement utilisés) par chaque pixel. Notez que pour certains formats planaires qui ont un nombre fractionnaire de bits par pixel (comme IF09), ce nombre peut être arrondi _vers le bas_.
format
XvPacked ou XvPlanar.
num_planes
Le nombre de plans dans les formats planaires.
depth
Nombre de bits significatifs par pixel.
red_mask, green_mask, blue_mask
Les masques de bits rouge, vert et bleu (formats RGB uniquement).
?_sample_bits
La taille de chaque échantillon en bits (formats YUV uniquement).
horz_?_period, vert_?_period
La période (en pixels) à laquelle les échantillons se produisent dans les directions horizontale et verticale (formats YUV uniquement).
component_order
Caractères ASCII majuscules représentant l'ordre dans lequel les échantillons sont stockés dans les formats packed. Pour les formats planaires, cela représente l'ordre des plans.
scanline_order
XvTopToBottom ou XvBottomToTop.

NOTES

Étant donné que certains formats (en particulier certains formats YUV planaires) peuvent ne pas être entièrement définis par les paramètres ci-dessus, le guid, lorsqu'il est disponible, devrait fournir la description la plus précise du format.

DIAGNOSTICS

[XvBadPort]
Généré si le port demandé n'existe pas.
