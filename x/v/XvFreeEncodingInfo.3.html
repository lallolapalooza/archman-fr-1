NOM

XvFreeEncodingInfo - libérer les informations d'encodage

SYNTAXE

void XvFreeEncodingInfo(XvEncodingInfo *p_encoding_info);

ARGUMENTS

p_encoding_info
Pointeur vers l'emplacement des informations d'encodage.

DESCRIPTION

XvFreeEncodingInfo(3) libère les informations d'encodage qui ont été renvoyées par XvQueryEncodings(3). La structure de données utilisée pour les informations d'encodage est définie dans la page de référence de XvQueryEncodings(3).
