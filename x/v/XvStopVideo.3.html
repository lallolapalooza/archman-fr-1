XvStopVideo(3) Fonctions libXv XvStopVideo(3)

NOM

XvStopVideo - arrêter la vidéo active

SYNTAXE

#include <X11/extensions/Xvlib.h>

int XvStopVideo(Display *dpy, XvPortID port, Drawable draw);

ARGUMENTS

dpy
Spécifie la connexion au serveur X.
port
Spécifie le port pour lequel la vidéo doit être arrêtée.
draw
Spécifie le dessin associé au port nommé.

DESCRIPTION

XvStopVideo(3) arrête la vidéo active pour le port et le dessin spécifiés. Si le port ne traite pas de vidéo, ou s'il traite de la vidéo sur un autre dessin, la requête est ignorée. Lorsque la vidéo est arrêtée, un événement XvVideoNotify(3) avec le détail XvStopped est généré pour le dessin associé.

VALEURS DE RETOUR

[Succès]
Retourné si XvStopVideo(3) s'est terminée avec succès.
[XvBadExtension]
Retourné si l'extension Xv n'est pas disponible.
[XvBadAlloc]
Retourné si XvStopVideo(3) n'a pas pu allouer de mémoire pour traiter la requête.

DIAGNOSTICS

[XvBadPort]
Généré si le port demandé n'existe pas.
[BadDrawable]
Généré si le dessin demandé n'existe pas.

VOIR AUSSI

XvGetVideo(3), XvPutVideo(3), XvVideoNotify(3)
