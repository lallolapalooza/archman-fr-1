NOM

XvQueryExtension - retourne la version et la révision de l'extension

SYNTAXE

#include <X11/extensions/Xvlib.h>

int XvQueryExtension(Display *dpy, unsigned int *p_version,
                    unsigned int *p_revision,
                    unsigned int *p_request_base,
                    unsigned int *p_event_base,
                    unsigned int *p_error_base);

ARGUMENTS

dpy
Spécifie la connexion au serveur X.
p_version
Pointeur vers l'emplacement où le numéro de version actuel de l'extension vidéo Xv est écrit.
p_revision
Pointeur vers l'emplacement où le numéro de révision de l'extension vidéo Xv est écrit.
p_request_base
Pointeur vers l'emplacement où le numéro de requête majeur de l'extension est retourné
p_event_base
Pointeur vers l'emplacement où la base des événements de l'extension est retournée
p_error_base
Pointeur vers l'emplacement où la base des erreurs de l'extension est retournée

DESCRIPTION

XvQueryExtension(3) retourne les numéros de version et de révision de l'extension vidéo Xv actuellement chargée sur le système. Le numéro de requête majeur de l'extension, sa base d'événements et sa base d'erreurs sont également retournés.

VALEURS DE RETOUR

[Succès]
Retourné si XvQueryExtension(3) s'est terminée avec succès.
[XvBadExtension]
Retourné si l'extension vidéo Xv n'est pas disponible pour l'affichage spécifié.
