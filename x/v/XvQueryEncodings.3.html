XvQueryEncodings(3) Fonctions libXv XvQueryEncodings(3)

NOM

XvQueryEncodings - renvoie la liste des codages pour un adaptateur

SYNTAXE

#include <X11/extensions/Xvlib.h>

int XvQueryEncodings(Display *dpy, XvPortID port,
                     unsigned int *p_num_encodings,
                     XvEncodingInfo **pp_encoding_info);

ARGUMENTS

dpy
Spécifie la connexion au serveur X.
port
Spécifie le port dont l'adaptateur doit être interrogé pour sa liste de codages.
p_num_encodings
Un pointeur où le nombre de codages supportés par l'adaptateur est écrit.
pp_encoding_info
Un pointeur où la liste des informations de codage renvoyées est retournée. XvEncodingInfo a la structure suivante : 
    typedef struct {
      XvEncodingID encoding_id;
      char *name;
      unsigned long width;
      unsigned long height;
      XvRational rate;
      unsigned long num_encodings;
    } XvEncodingInfo;
encoding_id
Spécifie l'identifiant d'encodage de l'encodage. L'identifiant d'encodage est utilisé pour identifier un encodage lorsque l'attribut d'encodage d'un port est modifié.
name
Un pointeur vers une chaîne de caractères formatée qui identifie l'encodage. La chaîne a le format "timing-signaltype". Par exemple "ntsc-composite".
width,height
La largeur et la hauteur, en pixels, de l'image vidéo décodée.
rate
Le taux de trame de la vidéo décodée.

La structure XvRational est utilisée pour spécifier un nombre fractionnaire. Elle a la structure suivante :

    typedef struct {
      int numerator;
      int denominator;
    } XvRational;

Les champs numerator et denominator spécifient les parties appropriées d'un nombre fractionnaire.

DESCRIPTION

XvQueryEncodings(3) renvoie des informations d'encodage sur un adaptateur. Chaque encodage est décrit par la structure XvEncodingInfo décrite ci-dessus. Les encodages sont identifiés par un identifiant d'encodage, qui peut être utilisé pour définir ou obtenir l'attribut d'encodage d'un port.

VALEUR DE RETOUR

[Succès]
Renvoyé si XvQueryEncodings(3) s'est terminée avec succès.
[XvBadExtension]
Renvoyé si l'extension Xv n'est pas disponible.
[XvBadAlloc]
Renvoyé si XvQueryEncodings(3) n'a pas pu allouer de mémoire pour traiter la requête.

DIAGNOSTICS

[XvBadPort]
Généré si le port demandé n'existe pas.
