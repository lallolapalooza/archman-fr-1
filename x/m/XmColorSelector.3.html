NOM

Le widget Sélecteur de couleur

SYNOPSIS

#include <Xm/ColorS.h>

DESCRIPTION

Le widget Sélecteur de couleur permet aux utilisateurs de choisir une couleur en utilisant soit un ensemble de curseurs RVB, soit en choisissant parmi une liste de toutes les couleurs disponibles dans la base de données rgb. Le nom ou la valeur rvb, ainsi que la couleur sélectionnée, sont affichés dynamiquement à l'utilisateur au fur et à mesure qu'il choisit différentes couleurs.

Tous les noms de ressources commencent par XmN et tous les noms de classes de ressources commencent par XmC.

blueSliderLabel

La chaîne apparaissant pour l'étiquette du curseur bleu

colorListTogLabel

La chaîne apparaissant pour l'étiquette du bouton de bascule de la liste de couleurs

colorMode

La liste de couleurs peut être utilisée en mode curseur ou en mode liste. Les valeurs acceptables sont XmListMode et XmScaleMode. Cette ressource permet à l'application de déterminer le mode que le sélecteur de couleurs doit utiliser lors de sa création. Après ce point, l'utilisateur peut changer librement de mode en utilisant une paire de boutons radio dans le sélecteur de couleurs. Un convertisseur de type est enregistré pour convertir les chaînes « ScaleMode » et « ListMode » en modes couleur pour une utilisation avec la base de données des ressources.

colorName

Cette ressource contrôle le nom de la couleur actuellement affiché à l'utilisateur. Cette valeur peut être modifiée pour changer la couleur affichée dans le sélecteur de couleurs ou interrogée pour connaître la couleur sélectionnée par l'utilisateur. La chaîne retournée est soit un nom de couleur, soit un signe dièse (#) suivi d'un ensemble de valeurs rvb, comme spécifié dans la spécification Xlib.

fileReadError

Le message qui s'affiche lorsque le Sélecteur de couleurs ne peut pas lire le fichier rgb.txt. Le message est affiché en haut de la fenêtre où la liste de couleurs apparaîtrait normalement.

greenSliderLabel

La chaîne apparaissant pour l'étiquette du curseur vert

marginHeight

marginWidth

C'est la quantité d'espace laissée entre chacun des enfants dans le sélecteur de couleurs et entre les enfants extérieurs et le bord du widget sélecteur de couleurs.

noCellError

Cette ressource contrôle le message affiché dans le champ de couleur d'échantillon lorsque le Sélecteur de couleurs ne peut pas allouer une cellule de couleur en lecture/écriture.

redSliderLabel

La chaîne apparaissant pour l'étiquette du curseur rouge

rgbFile

C'est le nom du fichier à charger, qui contient les noms de couleurs valides. Chacun de ces noms est trié et les doublons sont supprimés avant d'être présentés à l'utilisateur.

sliderTogLabel

La chaîne apparaissant pour l'étiquette du bouton de bascule des curseurs de couleur

Enfants

Le sélecteur de couleurs est composé de nombreux sous-widgets. Comme pour tous les widgets, la plupart des valeurs sont passées à ce widget via la liste d'arguments au moment de la création ou via des appels `set values` et sont passées à chacun des enfants de ce widget, bien que les requêtes `get values` doivent être effectuées enfant par enfant. Les enfants du sélecteur de couleurs sont listés ci-dessous. La documentation de chacun des enfants doit être consultée pour une liste des ressources de chaque enfant.

NAME

XmColorSelector - A widget that allows the user to select a color

SYNOPSIS

#include <Xm/Color.h>

WidgetClass, widget;

widget = XmCreateColorSelector(parent, name, arglist, argCount);

DESCRIPTION

The XmColorSelector widget provides a simple, modeless dialog box that allows the user to select a color. The color can be specified as an RGB value or by selecting a color from a predefined palette. The widget consists of several components: an RGB slider, a color palette, and a color name field.

RESOURCES

The XmColorSelector widget has the following resources:

Normal Resources

blueSliderLabel: (string)
Label for the blue slider. Default is "Blue".
colorListTogLabel: (string)
Label for the color list toggle button. Default is "Color List".
colorMode: (integer)
Specifies the color selection mode. Can be XmCOLOR_RGB or XmCOLOR_GRAYSCALE. Default is XmCOLOR_RGB.
colorName: (string)
Name of the currently selected color.
fileReadError: (string)
Error message for file read errors. Default is "Cannot read file".
greenSliderLabel: (string)
Label for the green slider. Default is "Green".
marginHeight: (dimension)
Vertical margin between components. Default is 5.
marginWidth: (dimension)
Horizontal margin between components. Default is 5.
noCellError: (string)
Error message for no cell errors. Default is "No cell selected".
redSliderLabel: (string)
Label for the red slider. Default is "Red".
rgbFile: (string)
Path to the RGB color definition file. Default is "/usr/share/X11/rgb.txt".
sliderTogLabel: (string)
Label for the slider toggle button. Default is "Sliders".

Convenience Routine

XmCreateColorSelector - Widget creation convenience routine

The XmCreateColorSelector function creates an XmColorSelector widget.

Parameters:

  • parent: The parent widget.
  • name: The name of the widget.
  • arglist: A list of argument-value pairs.
  • argCount: The number of argument-value pairs.

Returns: The created XmColorSelector widget.

Children

The XmColorSelector widget has the following children:

  • XmScale (for Red, Green, Blue sliders)
  • XmDrawnButton (for color palette cells)
  • XmToggleButton (for toggling between color list and sliders)
  • XmLabel (for labels)
