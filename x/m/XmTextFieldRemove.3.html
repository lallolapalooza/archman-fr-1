NOM

XmTextFieldRemove — Fonction TextField pour supprimer la sélection primaire

SYNTAXE

#include <Xm/TextF.h>
Boolean XmTextFieldRemove(
Widget widget);

DESCRIPTION

XmTextFieldRemove supprime le texte sélectionné en mode primaire. S'il y a une sélection, cette routine appelle également les callbacks du widget XmNvalueChangedCallback et les callbacks de vérification, soit XmNmodifyVerifyCallback, soit XmNmodifyVerifyCallbackWcs, ou les deux. Si les deux listes de callbacks de vérification sont enregistrées, les procédures de la liste XmNmodifyVerifyCallback sont exécutées en premier et les données résultantes sont transmises aux callbacks XmNmodifyVerifyCallbackWcs. Cette fonction peut également appeler le callback XmNmotionVerifyCallback.

widget
Spécifie l'identifiant du widget TextField.

Pour une définition complète de TextField et de ses ressources associées, voir XmTextField(3).

VALEUR DE RETOUR

Cette fonction retourne False si la sélection primaire est NULL ou si le widget ne possède pas la sélection primaire. Sinon, elle retourne True.
