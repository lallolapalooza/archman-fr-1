NOM

XmStringPeekNextComponent — Une fonction de chaîne composite qui renvoie le type du composant suivant à extraire

SYNTAXE

#include <Xm/Xm.h>
XmStringComponentType XmStringPeekNextComponent(
XmStringContext context);

DESCRIPTION

Cette fonction est obsolète et existe pour des raisons de compatibilité avec les versions précédentes. Elle est remplacée par XmStringPeekNextTriple. XmStringPeekNextComponent examine le composant suivant qui serait extrait par XmStringGetNextComponent et renvoie le type de composant.

contexte
Spécifie la structure de contexte de chaîne qui a été allouée par la fonction XmStringInitContext.

VALEUR DE RETOUR

Renvoie le type de composant trouvé. Reportez-vous à la page de référence XmStringComponentType(3) pour une liste des types de composants.

LIEN CONNEXES

XmStringComponentType(3), XmStringCreate(3), XmStringGetNextComponent(3), et XmStringInitContext(3).
