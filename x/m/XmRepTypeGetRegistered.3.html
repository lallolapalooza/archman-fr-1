NOM

XmRepTypeGetRegistered — Fonction de gestion des types de représentation qui retourne une copie de la liste d'enregistrement

SYNTAXE

#include <Xm/RepType.h>
XmRepTypeList XmRepTypeGetRegistered(void)

DESCRIPTION

XmRepTypeGetRegistered récupère des informations sur tous les types de représentation qui sont enregistrés auprès du gestionnaire de types de représentation. La liste d'enregistrement est un tableau de structures, chacune contenant des informations pour une entrée de type de représentation. La fin de la liste d'enregistrement est marquée par une entrée de type de représentation dont le champ rep_type_name a un pointeur NULL. Cette routine alloue de la mémoire pour les données retournées. L'application doit libérer cette mémoire en utilisant XtFree.

La structure d'entrée de type de représentation contient les informations suivantes :

typedef struct
{
        String  rep_type_name;
        String  *value_names;
        unsigned char   *values;
        unsigned char   num_values;
        Boolean reverse_installed;
        XmRepTypeId     rep_type_id;
} XmRepTypeEntryRec, *XmRepTypeList;
(void)
rep_type_name
Le nom du type de représentation
value_names
Un tableau de noms de valeurs de type de représentation
values
Un tableau de valeurs numériques de type de représentation
num_values
Le nombre de valeurs associées au type de représentation
reverse_installed
Un indicateur qui indique si le convertisseur inverse est installé ou non
rep_type_id
Le numéro d'identification du type de représentation

VALEUR DE RETOUR

Retourne un pointeur vers la liste d'enregistrement des types de représentation.

VOIR AUSSI

XmRepTypeRegister(3) et XmRepTypeGetRecord(3).
