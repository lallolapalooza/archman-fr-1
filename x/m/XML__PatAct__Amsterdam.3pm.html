NOM

XML::PatAct::Amsterdam - Un module d'action pour des feuilles de style simplistes

SYNOPSIS

use XML::PatAct::Amsterdam;
my $patterns = [ PATTERN => { Before => 'avant',
                              After => 'apres' },
                 ... ];
my $matcher = XML::PatAct::Amsterdam->new( OPTIONS => );

DESCRIPTION

XML::PatAct::Amsterdam est un gestionnaire PerlSAX pour appliquer des listes de motifs-actions à des analyseurs ou des arbres XML. XML::PatAct::Amsterdam applique une feuille de style très simple à une instance et génère le résultat. Amsterdam tire son nom de l'analyseur SGML d'Amsterdam (ASP) qui a inspiré ce module.

ATTENTION : Amsterdam est un module de style très simple, vous rencontrerez rapidement ses limites même avec des instances XML modérément complexes, soyez conscients et préparés à passer à des modules de style plus complets.

De nouvelles instances de XML::PatAct::Amsterdam sont créées en appelant `new()'. Les paramètres peuvent être passés sous forme d'une liste de paires clé, valeur ou d'une table de hachage. Les options Patterns et Matcher sont requises. Les OPTIONS suivantes sont prises en charge :

Patterns
La liste de motifs-actions à appliquer. La liste est un tableau anonyme de paires motif, action. Chaque action dans la liste contient soit l'un, soit les deux, une chaîne Before et une chaîne After à copier dans la sortie avant et après le traitement d'un élément XML. Les chaînes Before et After peuvent contenir des noms d'attributs entre crochets (`"["' NOM `"]"'), ceux-ci sont remplacés par la valeur de l'attribut portant ce nom. Le NOM spécial `"_element"' sera remplacé par le nom de l'élément.
Matcher
Une instance du module de correspondance de motifs ou de requêtes.
Output
Un IO::Handle ou l'une de ses sous-classes (comme IO::File), si ce paramètre n'est pas présent et que l'option AsString n'est pas utilisée, le module écrira sur la sortie standard.
AsString
Retourne la sortie générée sous forme de chaîne à partir de la méthode `parse()' du générateur d'événements PerlSAX.
