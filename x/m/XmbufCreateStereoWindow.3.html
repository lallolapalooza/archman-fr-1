DESCRIPTION

La bibliothèque d'interface de programmation pour l'*Extension X11 de Double-Buffering, Multi-Buffering et Stéréo* contient les interfaces décrites ci-dessous. À l'exception de XmbufQueryExtension, si une quelconque de ces routines est appelée avec un affichage qui ne supporte pas l'extension, l'ExtensionErrorHandler (qui peut être défini avec XSetExtensionErrorHandler et fonctionne de la même manière que XSetErrorHandler) sera appelée et la fonction retournera ensuite.

XmbufQueryExtension retourne True si l'extension multibuffering/stéréo est disponible sur l'affichage donné. Si l'extension existe, la valeur du premier code d'événement (qui doit être ajoutée aux constantes de type d'événement MultibufferClobberNotify et MultibufferUpdateNotify pour obtenir les valeurs réelles) est stockée dans event_base_return et la valeur du premier code d'erreur (qui doit être ajoutée à la constante de type d'erreur MultibufferBadBuffer pour obtenir la valeur réelle) est stockée dans error_base_return.

XmbufGetVersion obtient les numéros de version majeure et mineure de l'extension. La valeur de retour est zéro si une erreur se produit ou non-zéro si aucune erreur ne se produit.

XmbufCreateBuffers demande que "count" tampons soient créés avec l'update_action et l'update_hint donnés et soient associés à la fenêtre indiquée. Le nombre de tampons créés est retourné (zéro si une erreur s'est produite) et buffers_update est rempli avec ce nombre d'identificateurs Multibuffer.

XmbufDestroyBuffers détruit les tampons associés à la fenêtre donnée.

XmbufDisplayBuffers affiche les tampons indiqués dans leurs fenêtres appropriées dans un délai maximal de max_delay millisecondes après que min_delay millisecondes se soient écoulées. Aucun deux tampons ne peut être associé à la même fenêtre, sinon une erreur Match est générée.

XmbufGetWindowAttributes obtient les attributs de multibuffering qui s'appliquent à tous les tampons associés à la fenêtre donnée. La liste des tampons retournée peut être libérée avec XFree. Retourne non-zéro en cas de succès et zéro en cas d'erreur.

XmbufChangeWindowAttributes définit les attributs de multibuffering qui s'appliquent à tous les tampons associés à la fenêtre donnée. Ceci est actuellement limité à l'update_hint.

XmbufGetBufferAttributes obtient les attributs du tampon indiqué. Retourne non-zéro en cas de succès et zéro en cas d'erreur.

XmbufChangeBufferAttributes définit les attributs du tampon indiqué. Ceci est actuellement limité à l'event_mask.

XmbufGetScreenInfo obtient les paramètres contrôlant la façon dont les fenêtres mono et stéréo peuvent être créées sur l'écran du dessinable donné. Les nombres d'ensembles de visuels et de profondeurs sont retournés dans nmono_return et nstereo_return. Si nmono_return est supérieur à zéro, alors mono_info_return est défini à l'adresse d'un tableau de structures XmbufBufferInfo décrivant les différents visuels et profondeurs qui peuvent être utilisés. Sinon, mono_info_return est défini à NULL. De même, stereo_info_return est défini en fonction de nstereo_return. Le stockage retourné dans mono_info_return et stereo_info_return peut être libéré par XFree. Si aucune erreur n'est rencontrée, non-zéro sera retourné.

XmbufCreateStereoWindow crée une fenêtre stéréo de la même manière que XCreateWindow crée une fenêtre mono. Les identifiants de tampons pour les tampons gauche et droit sont retournés dans left_return et right_return, respectivement. Si un gestionnaire d'erreurs d'extension qui retourne est installé, None sera retourné si l'extension n'est pas disponible sur cet affichage.

NAME

XmbufCreateStereoWindow - create a stereo window.

SYNTAX

    Status XmbufCreateStereoWindow(
        Display *dpy,
        Window parent,
        int x, int y,
        unsigned int width, unsigned int height,
        int border_width,
        int depth,
        unsigned int class,
        Visual *visual,
        unsigned long valuemask,
        XSetWindowAttributes *attributes,
        unsigned int stereo_type
    );

STRUCTURES

The XmbufCreateStereoWindow function takes a stereo_type argument which specifies the stereo viewing method. The available stereo types are defined in <X11/extensions/mbuf.h>.

DESCRIPTION

The XmbufCreateStereoWindow function creates a stereo window with the specified parameters. The stereo_type parameter specifies the stereo viewing method to be used. The available stereo types are:

XmStereoTypeNone
No stereo is enabled.
XmStereoTypeSequential
Sequential stereo is enabled. This method alternates between the left and right eye views.
XmStereoTypeInterlaced
Interlaced stereo is enabled. This method interleaves the left and right eye views.
XmStereoTypeAnaglyph
Anaglyph stereo is enabled. This method uses color filtering to produce a stereo effect.

The other parameters are the same as for the standard Xlib function XCreateWindow.

PREDEFINED VALUES

The following values are defined in <X11/extensions/mbuf.h>:

    ibufferUpdateNotifyMask
    MultibufferClobberNotify
    MultibufferUpdateNotify
    MultibufferNumberEvents
    MultibufferBadBuffer
    MultibufferNumberErrors

La fonction XmbufCreateStereoWindow prend un argument stereo_type qui spécifie la méthode de visualisation stéréo. Les types de stéréo disponibles sont définis dans <X11/extensions/mbuf.h>.

DESCRIPTION

La fonction XmbufCreateStereoWindow crée une fenêtre stéréo avec les paramètres spécifiés. Le paramètre stereo_type spécifie la méthode de visualisation stéréo à utiliser. Les types de stéréo disponibles sont :

XmStereoTypeInterlaced
La stéréo entrelacée est activée. Cette méthode entrelace les vues de l'œil gauche et de l'œil droit.
XmStereoTypeAnaglyph
La stéréo anaglyphe est activée. Cette méthode utilise un filtrage des couleurs pour produire un effet stéréo.
