NOM

XmTextFieldPosToXY — Fonction TextField qui accède à la position x et y d'une position de caractère

SYNTAXE

#include <Xm/TextF.h>
Boolean XmTextFieldPosToXY(
Widget widget,
XmTextPosition position,
Position *x,
Position *y);

DESCRIPTION

XmTextFieldPosToXY accède à la position x et y, par rapport au coin supérieur gauche du widget TextField, d'une position de caractère donnée dans le tampon de texte.

widget
Spécifie l'identifiant du widget TextField.
position
Spécifie la position du caractère dans le texte pour laquelle la position x et y est accédée. Il s'agit d'un nombre entier de caractères à partir du début du tampon. La première position de caractère est 0.
x
Spécifie le pointeur dans lequel la position x est retournée. La position retournée est la distance entre le bord gauche du widget et la bordure gauche du caractère. Cette valeur n'est significative que si la fonction retourne True.
y
Spécifie le pointeur dans lequel la position y est retournée. La position retournée est la distance entre le haut du widget et la ligne de base du caractère. Cette valeur n'est significative que si la fonction retourne True.

Pour une définition complète de TextField et de ses ressources associées, voir XmTextField(3).

RETOUR

Cette fonction retourne True si la position du caractère est affichée dans le widget TextField ; sinon, elle retourne False, et aucune valeur x ou y n'est retournée.

VOIR AUSSI

XmTextField(3).
