NOM

XmGadget — La classe de widget Gadget

SYNTAXE

#include <Xm/Xm.h>

DESCRIPTION

Gadget est une classe de widget utilisée comme superclasse de support pour d'autres classes de gadgets. Elle gère le dessin et la mise en évidence des bordures d'ombre, l'activation et la désactivation du parcours, ainsi que diverses listes de rappels nécessaires aux gadgets.

Les ressources de couleur et de pixmap définies par XmManager sont directement utilisées par les gadgets. Si XtSetValues est utilisé pour modifier l'une des ressources d'un widget gestionnaire, tous les gadgets enfants du gestionnaire sont également modifiés.

Classes

Gadget hérite des comportements et des ressources de Object et RectObj.

Le pointeur de classe est xmGadgetClass.

Le nom de la classe est XmGadget.

Nouvelles Ressources

Le tableau suivant définit un ensemble de ressources de widget utilisées par le programmeur pour spécifier des données. Le programmeur peut également définir les valeurs des ressources pour les classes héritées afin de définir les attributs de ce widget. Pour faire référence à une ressource par son nom ou par sa classe dans un fichier .Xdefaults, supprimez le préfixe XmN ou XmC et utilisez les lettres restantes. Pour spécifier l'une des valeurs définies pour une ressource dans un fichier .Xdefaults, supprimez le préfixe Xm et utilisez les lettres restantes (en minuscules ou en majuscules, mais incluez les éventuels underscores entre les mots). Les codes dans la colonne d'accès indiquent si la ressource donnée peut être définie au moment de la création (C), définie en utilisant XtSetValues (S), récupérée en utilisant XtGetValues (G), ou n'est pas applicable (N/A).

Contient la couleur du rectangle de surbrillance.
XmNhighlightOnEnter
Spécifie si le rectangle de surbrillance est dessiné lorsque le curseur entre dans le widget. Si la politique de focus du shell est XmEXPLICIT, cette ressource est ignorée et le widget est mis en surbrillance lorsqu'il a le focus. Si la politique de focus du shell est XmPOINTER et si cette ressource est True, le rectangle de surbrillance est dessiné lorsque le curseur entre dans le widget. Si la politique de focus du shell est XmPOINTER et si cette ressource est False, le rectangle de surbrillance n'est pas dessiné lorsque le curseur entre dans le widget. XmNnavigationType
Détermine si le widget est un groupe d'onglets.
XmNONE
Indique que le widget n'est pas un groupe d'onglets.
XmTAB_GROUP
Indique que le widget est un groupe d'onglets, sauf si la XmNnavigationType d'un autre widget dans la hiérarchie est XmEXCLUSIVE_TAB_GROUP.
XmSTICKY_TAB_GROUP
Indique que le widget est un groupe d'onglets, même si la XmNnavigationType d'un autre widget dans la hiérarchie est XmEXCLUSIVE_TAB_GROUP.
XmEXCLUSIVE_TAB_GROUP
Indique que le widget est un groupe d'onglets et que les widgets de la hiérarchie dont la XmNnavigationType est XmTAB_GROUP ne sont pas des groupes d'onglets.
Lorsqu'un widget parent a un XmNnavigationType de XmEXCLUSIVE_TAB_GROUP, la navigation entre les widgets qui ne sont pas des groupes d'onglets au sein du groupe est basée sur l'ordre de ces widgets dans la liste XmNchildren de leur parent.
Lorsque la XmNnavigationType de n'importe quel widget dans une hiérarchie est XmEXCLUSIVE_TAB_GROUP, la navigation entre les groupes d'onglets dans la hiérarchie procède vers les widgets dans l'ordre dans lequel leurs ressources XmNnavigationType ont été spécifiées comme XmEXCLUSIVE_TAB_GROUP ou XmSTICKY_TAB_GROUP, que ce soit en créant les widgets avec cette valeur, en appelant XtSetValues, ou en appelant XmAddTabGroup.

Spécifie la taille de l'ombre de bordure dessinée.
XmNtopShadowColor
Contient la couleur à utiliser pour dessiner les côtés supérieur et gauche de l'ombre de la bordure.
XmNtopShadowPixmap
Spécifie la pixmap à utiliser pour dessiner les côtés supérieur et gauche de l'ombre de la bordure.
XmNtraversalOn
Spécifie l'activation de la navigation pour ce gadget.
XmNunitType
Fournit le support de base pour l'indépendance de résolution. Il définit le type d'unités qu'un widget utilise avec les ressources de dimensionnement et de positionnement. Si le parent du widget est une sous-classe de XmManager et si la ressource XmNunitType n'est pas explicitement définie, elle prend par défaut le type d'unité du widget parent. Si le widget parent n'est pas une sous-classe de XmManager, la ressource a un type d'unité par défaut de XmPIXELS.

NAME

XmGadget — a specialized gadget that manages the geometry of other gadgets within a parent widget

SYNOPSIS

#include <Xm/Xm.h>

The XmGadget widget is derived from XmManager, which is derived from Core, which is derived from Object.

A specification of the XmGadget widget follows:

widgetClass = xmGadgetClass

DESCRIPTION

The XmGadget widget is a specialized gadget that manages the geometry of other gadgets within a parent widget. It is not a visible widget, and it does not have its own window. It is used to group other gadgets and to provide a common interface for managing them.

Gadgets are non-widget objects that exist solely to facilitate the management of other widgets. Because they do not have their own windows, they have significantly less overhead than widgets. This makes them useful for implementing things like text fields and buttons, where an application may need to manage many similar objects.

The XmGadget widget provides the base class for all Xm gadgets. It defines the common resources and behavior for all gadgets.

Resource Set

The XmGadget widget has the following resources:

XmNclipWindow
This resource is used internally by the XmGadget widget to manage its children. It should not be set by the application.
XmNunitType
This resource specifies the unit type to be used for the widget's geometry. The default value is Xm1000TH_INCHES.

The following unit types are available:

XmPIXELS
All values provided to the widget are treated as normal pixel values.
Xm100TH_MILLIMETERS
All values provided to the widget are treated as 1/100 of a millimeter.
Xm100TH_CENTIMETERS
All values provided to the widget are treated as 1/100 of a centimeter.
XmMILLIMETERS
All values provided to the widget are treated as normal millimeter values.
XmCENTIMETERS
All values provided to the widget are treated as normal centimeter values.
XmINCHES
All values provided to the widget are treated as normal inch values.
Xm1000TH_INCHES
All values provided to the widget are treated as 1/1000 of an inch.
XmPOINTS
All values provided to the widget are treated as normal point values. A point is a unit used in text processing applications and is defined as 1/72 of an inch.
Xm100TH_POINTS
All values provided to the widget are treated as 1/100 of a point. A point is a unit used in text processing applications and is defined as 1/72 inch.
XmFONT_UNITS
All values provided to the widget are treated as normal font units. A font unit has horizontal and vertical components. These are the values of the XmScreen resources XmNhorizontalFontUnit and XmNverticalFontUnit.
Xm100TH_FONT_UNITS
All values provided to the widget are treated as 1/100 of a font unit. A font unit has horizontal and vertical components. These are the values of the XmScreen resources XmNhorizontalFontUnit and XmNverticalFontUnit.
XmNuserData
Allows the application to attach any necessary specific data to the gadget. This is an internally unused resource.
XmNtoolTipString
The XmString to display as the toolTip. If this resource is NULL, no tip will be displayed. ToolTips are described in VendorShell(3)

Callback Information

A pointer to the following structure is passed to each callback:

typedef struct
{
        int reason;
        XEvent * event;
} XmAnyCallbackStruct;
reason
Indicates why the callback was invoked. For this callback, reason is set to XmCR_HELP.
event
Points to the XEvent that triggered the callback.

Behavior

Gadgets cannot have translations associated with them. Because of this, a Gadget's behavior is determined by the Manager widget into which the Gadget is placed. If focus is on a Gadget, events are passed to the Gadget by its Manager.
