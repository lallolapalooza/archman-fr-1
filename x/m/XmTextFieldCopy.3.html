NOM

XmTextFieldCopy — Fonction TextField qui copie la sélection primaire dans le presse-papiers

SYNTAXE

#include <Xm/TextF.h>
Boolean XmTextFieldCopy(
Widget widget,
Time time);

DESCRIPTION

XmTextFieldCopy copie le texte sélectionné par la primaire dans le presse-papiers.

Cette routine appelle les procédures XmNconvertCallback, potentiellement plusieurs fois, avec le membre selection de XmConvertCallbackStruct défini sur CLIPBOARD et avec le membre parm défini sur XmCOPY.

widget
Spécifie l'identifiant du widget TextField.
time
Spécifie le moment où la valeur de la sélection doit être modifiée. Il devrait s'agir du moment de l'événement qui a déclenché cette requête.

Pour une définition complète de TextField et de ses ressources associées, consultez XmTextField(3).

RETOUR

Cette fonction renvoie False si la sélection primaire est NULL, si le widget ne possède pas la sélection primaire, si la fonction ne parvient pas à acquérir la propriété de la sélection du presse-papiers, ou si aucune donnée n'est placée dans le presse-papiers. Sinon, elle renvoie True.
