XmCreatePromptDialog(appel de bibliothèque) XmCreatePromptDialog(appel de bibliothèque)

NOM

XmCreatePromptDialog — Fonction de création pratique pour le DialogShell de type SelectionBox

SYNTAXE

#include <Xm/SelectioB.h>
Widget XmCreatePromptDialog(
Widget parent,
String name,
ArgList arglist,
Cardinal argcount);

DESCRIPTION

XmCreatePromptDialog est une fonction de création pratique qui crée un DialogShell et un enfant SelectionBox non géré de ce DialogShell. Un DialogShell de type PromptDialog invite l'utilisateur à saisir du texte. Il comprend un message, une zone de saisie de texte et trois boutons gérés. Les étiquettes par défaut des boutons sont OK, Cancel et Help. Un bouton supplémentaire, avec Apply comme étiquette par défaut, est créé non géré ; il peut être géré explicitement si nécessaire. Un enfant WorkArea supplémentaire peut être ajouté au SelectionBox après sa création.

XmCreatePromptDialog force la valeur de la ressource SelectionBox XmNdialogType à XmDIALOG_PROMPT.

Utilisez XtManageChild pour afficher le DialogShell de type PromptDialog (en passant le SelectionBox comme paramètre du widget) ; utilisez XtUnmanageChild pour le masquer.

XmCreatePromptDialog force la valeur de la ressource Shell XmNallowShellResize à True.

parent
Spécifie l'identifiant du widget parent.
name
Spécifie le nom du widget créé.
arglist
Spécifie la liste d'arguments.
argcount
Spécifie le nombre de paires attribut/valeur dans la liste d'arguments (arglist).

Pour une définition complète de SelectionBox et de ses ressources associées, voir XmSelectionBox(3).

RETOUR

Retourne l'identifiant du widget SelectionBox.

VOIR AUSSI

XmSelectionBox(3).
