NOM

XML::Parser::Lite - Analyseur XML léger entièrement en Perl (basé sur des expressions régulières)

SYNOPSIS

use XML::Parser::Lite;
$p1 = new XML::Parser::Lite;
$p1->setHandlers(
  Start => sub { shift; print "début : @_\n" },
  Char => sub { shift; print "car : @_\n" },
  End => sub { shift; print "fin : @_\n" },
);
$p1->parse('<foo id="moi">Bonjour le monde !</foo>');
$p2 = new XML::Parser::Lite
  Handlers => {
    Start => sub { shift; print "début : @_\n" },
    Char => sub { shift; print "car : @_\n" },
    End => sub { shift; print "fin : @_\n" },
  }
;
$p2->parse('<foo id="moi">Bonjour <bar>cruel</bar> le monde !</foo>');

DESCRIPTION

Ce module implémente un analyseur XML avec une interface similaire à XML::Parser. Bien que toutes les fonctions de rappel ne soient pas prises en charge, vous devriez pouvoir l'utiliser de la même manière que XML::Parser. En raison de l'utilisation de fonctionnalités d'expressions régulières expérimentales, il ne fonctionnera qu'avec Perl 5.6 et supérieur et peut se comporter différemment selon les plateformes.

Notez que vous ne pouvez pas utiliser d'expressions régulières ou de `split` dans les fonctions de rappel. Ceci est dû à une limitation de l'implémentation des expressions régulières de Perl (qui n'est pas réentrante).

SOUS-ROUTINES/MÉTHODES

new

Constructeur.

La méthode new() renvoie l'objet sur lequel elle a été appelée lorsqu'elle est appelée comme méthode d'objet. Ce comportement a été hérité de SOAP::Lite, dont XML::Parser::Lite a été extrait. Cela signifie que ce qui suit est effectivement une opération nulle si $obj est un objet :

$obj = $obj->new();

New accepte un seul paramètre nommé, "Handlers" avec une référence de hachage comme valeur :

my $parser = XML::Parser::Lite->new(
   Handlers => {
       Start => sub { shift; print "début : @_\n" },
       Char => sub { shift; print "car : @_\n" },
       End => sub { shift; print "fin : @_\n" },
   }
);

Les gestionnaires fournis seront passés à setHandlers.

setHandlers

Définit (ou réinitialise) les gestionnaires d'analyse. Accepte une hachure avec les noms des gestionnaires et les références de code des gestionnaires en paramètres. Passer "undef" au lieu d'une référence de code remplace le gestionnaire par une opération nulle.

Les gestionnaires suivants peuvent être définis :

Init
Start
Char
End
Final

Tous les autres gestionnaires sont ignorés.

Appeler setHandlers sans paramètres réinitialise tous les gestionnaires à des opérations nulles.

parse

Analyse le XML donné. Contrairement à la méthode parse de XML::Parser, parse() n'analyse que des chaînes de caractères.

Méthodes de gestionnaires

Init

Appelé avant le début de l'analyse. Vous devriez effectuer toutes les initialisations nécessaires dans Init.

Start

Appelé au début de chaque nœud XML. Voir XML::Parser pour les détails.

Char

Appelé pour chaque séquence de caractères. Peut être appelé plusieurs fois pour les caractères contenus dans un nœud XML (même pour chaque caractère individuel). Votre implémentation doit s'assurer qu'elle capture tous les caractères.

End

Appelé à la fin de chaque nœud XML. Voir XML::Parser pour les détails.

Comment

Voir XML::Parser pour les détails.

XMLDecl

Voir XML::Parser pour les détails.

Doctype

Voir XML::Parser pour les détails.

Final

Appelé à la fin du processus d'analyse. Vous devriez effectuer tout nettoyage nécessaire ici.

VOIR AUSSI

XML::Parser - un analyseur XML complet, sur lequel XML::Parser::Lite est basé. Nécessite un compilateur C et l'analyseur XML expat.

XML::Parser::LiteCopy - un fork dans XML::Parser::Lite::Tree.

YAX - un autre module entièrement en Perl pour l'analyse XML.

XML::Parser::REX - un autre module qui analyse XML avec des expressions régulières.
