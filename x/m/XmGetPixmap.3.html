NOM

XmGetPixmap — Fonction de mise en cache de pixmap qui génère un pixmap, le stocke dans un cache de pixmaps et renvoie le pixmap

SYNTAXE

#include <Xm/Xm.h>
Pixmap XmGetPixmap(
Screen *screen,
char *image_name,
Pixel foreground,
Pixel background);

DESCRIPTION

XmGetPixmap utilise les données des paramètres pour effectuer une recherche dans le cache de pixmaps afin de déterminer si un pixmap a déjà été généré et qui correspond aux données. S'il en trouve un, un compteur de références est incrémenté et le pixmap est renvoyé. Les applications devraient utiliser XmDestroyPixmap lorsque le pixmap n'est plus nécessaire.

screen
Spécifie l'écran de l'affichage sur lequel le pixmap doit être dessiné. La profondeur du pixmap est la profondeur par défaut pour cet écran.
image_name
Spécifie le nom de l'image à utiliser pour générer le pixmap.
foreground
Combine l'image avec la couleur de premier plan (foreground) pour créer le pixmap si l'image référencée est une image à un bit par pixel.
background
Combine l'image avec la couleur d'arrière-plan (background) pour créer le pixmap si l'image référencée est une image à un bit par pixel.

Si aucun pixmap n'est trouvé, image_name est utilisé pour effectuer une recherche dans le cache d'images. Si une image est trouvée, elle est utilisée pour générer le pixmap, qui est ensuite mis en cache et renvoyé.

Si aucune image n'est trouvée, image_name est utilisé comme nom de fichier et une recherche est effectuée pour un fichier bitmap X10 ou X11. S'il est trouvé, le fichier est lu, converti en une image, et mis en cache dans le cache d'images. L'image est ensuite utilisée pour générer un pixmap, qui est mis en cache et renvoyé.

Si image_name commence par une barre oblique (/), il spécifie un chemin absolu, et XmGetPixmap ouvre le fichier comme spécifié. Sinon, image_name spécifie un nom de fichier. Dans ce cas, XmGetPixmap recherche le fichier le long d'un chemin de recherche spécifié par la variable d'environnement XBMLANGPATH ou par un chemin de recherche par défaut, qui varie selon que la variable d'environnement XAPPLRESDIR est définie ou non. Le chemin de recherche par défaut contient de nombreux répertoires. Par conséquent, XmGetPixmap mettra un temps relativement long à parcourir tous ces répertoires pour les pixmaps et les bitmaps. Les applications qui utilisent beaucoup de pixmaps et de bitmaps s'exécuteront probablement plus rapidement si XBMLANGPATH est défini sur une courte liste de répertoires. En plus des fichiers bitmap X (XBM), Motif prend également en charge les formats de fichiers XPM (X Pixmap) et, depuis la version 2.3, les formats d'image JPEG et PNG. (Notez que la prise en charge des formats d'image JPEG et PNG est une fonctionnalité optionnelle de Motif, afin de vérifier si la version actuelle prend en charge les formats d'image PNG et JPEG, les macros PNG_SUPPORT et JPEG_SUPPORT doivent être vérifiées en conséquence.) Le XBMLANGPATH spécifie le chemin pour les fichiers XBM, XPM, PNG et JPEG. Reportez-vous à la page de référence XmGetPixmapByDepth pour plus de détails.

La variable d'environnement XBMLANGPATH spécifie un chemin de recherche pour les fichiers bitmap X. Elle peut contenir le champ de substitution %B, où l'argument image_name de XmGetPixmap est substitué à %B. Elle peut également contenir les champs de substitution acceptés par XtResolvePathname. Le champ de substitution %T est toujours mappé à bitmaps, et %S est toujours mappé à NULL.

Ces chemins sont des valeurs par défaut que les fournisseurs peuvent modifier. Par exemple, un fournisseur peut utiliser des répertoires différents pour /usr/lib/X11 et /usr/include/X11.

Les substitutions suivantes sont utilisées dans ces chemins :

%B
Le nom de l'image, de l'argument image_name
%N
Le nom de classe de l'application
%L
La chaîne de langue de l'affichage. Cette chaîne est influencée par XtSetLanguageProc. La chaîne par défaut est déterminée en appelant setlocale(LC_ALL, NULL).
%l_%t
La composante langue et territoire de la chaîne de langue de l'affichage
%l
La composante langue de la chaîne de langue de l'affichage

Le contenu du fichier doit être conforme aux règles des fichiers bitmap X11. En d'autres termes, Motif peut lire n'importe quel fichier bitmap conforme à X11.

RETOUR

Renvoie un pixmap en cas de succès ; renvoie XmUNSPECIFIED_PIXMAP si l'image correspondant à image_name ne peut pas être trouvée.

VOIR AUSSI

    NOM

    XmGetPixmap - Crée ou récupère un pixmap.

    SYNTAXE

    #include <Xm/Xm.h>

Pixmap XmGetPixmap (
    Widget widget,
    char *image_name,
    char *pixmap_name
);

    DESCRIPTION

    La fonction XmGetPixmap crée ou récupère un pixmap. Elle recherche d'abord le pixmap dans le cache de pixmaps. Si le pixmap n'est pas trouvé dans le cache, elle crée un nouveau pixmap en utilisant les informations fournies par image_name et pixmap_name. Le nouveau pixmap est ensuite ajouté au cache avant d'être retourné.

    • widget : Le widget associé à cette opération. Peut être NULL.
    • image_name : Le nom de l'image à utiliser pour créer le pixmap. Si NULL, le pixmap sera créé à partir des données de pixmap brutes spécifiées par pixmap_name.
    • pixmap_name : Le nom du pixmap à créer ou à récupérer. Si image_name est NULL, ce nom sera utilisé comme nom de pixmap dans le cache.

    RETOUR

    La fonction retourne le Pixmap créé ou récupéré. En cas d'échec, elle retourne XmINVALID_PIXMAP.
