NOM

XmImFreeXIC — Une fonction de gestionnaire d'entrée qui désenregistre les widgets pour un XIC

SYNTAXE

#include <Xm/XmIm.h>
void XmImFreeXIC(
Widget widget,
XIC xic);

DESCRIPTION

XmImFreeXIC désenregistre tous les widgets associés au Contexte d'Entrée X (XIC) spécifié. Le widget spécifié doit être associé au xic spécifié.

Après avoir désenregistré les widgets associés, cet appel libère le xic.

widget
Spécifie l'ID d'un widget utilisé pour identifier le VendorShell et le XmDisplay qui maintiennent le registre widget-XIC.
xic
Spécifie le Contexte d'Entrée associé au widget.

CONNEXES

XmImGetXIC(3) et XmImSetXIC(3).
