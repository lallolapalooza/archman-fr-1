NOM

XmVaCreateContainer, XmVaCreateManagedContainer — Fonctions pratiques de création de widget Conteneur.

SYNTAXE

#include <Xm/Container.h>
Widget XmVaCreateContainer(
Widget parent,
String name,
...);
Widget XmVaCreateManagedContainer(
Widget parent,
String name,
...);

DESCRIPTION

Ces fonctions créent une instance d'un widget Conteneur et retournent l'ID du widget associé. Ces routines utilisent la convention d'appel de liste d'arguments de longueur variable (varargs) de la norme ANSI C.

La fonction XmVaCreateContainer est une routine pratique qui appelle XtCreateWidget.

La fonction XmVaCreatemanagedContainer est une routine pratique qui appelle XtCreateManagedWidget.

parent
Spécifie l'ID du widget parent.
name
Spécifie le nom du widget créé.
...
Spécifie la liste d'arguments variables pour outrepasser les valeurs par défaut des ressources.

Pour une définition complète du Conteneur et de ses ressources associées, voir XmContainer(3).

RETOUR

Retourne l'ID du widget Conteneur.

VOIR AUSSI

XmContainer(3), XmCreateContainer(3), XtCreateWidget(3), et XtCreateManagedWidget(3).
