NOM

XML::LibXML::Dtd - Gestion des DTD dans XML::LibXML

SYNOPSIS

use XML::LibXML;
$dtd = XML::LibXML::Dtd->new($public_id, $system_id);
$dtd = XML::LibXML::Dtd->parse_string($dtd_str);
$publicId = $dtd->getName();
$publicId = $dtd->publicId();
$systemId = $dtd->systemId();

DESCRIPTION

Cette classe contient une DTD. Vous pouvez analyser une DTD à partir d'une chaîne de caractères, ou à partir d'un identifiant SYSTEM externe.

Aucun support n'est encore disponible pour l'analyse à partir d'un flux (filehandle).

XML::LibXML::Dtd est une sous-classe de XML::LibXML::Node, donc toutes les méthodes disponibles pour les nœuds (en particulier toString()) sont disponibles pour les objets Dtd.

MÉTHODES

new
$dtd = XML::LibXML::Dtd->new($public_id, $system_id);

Analyse une DTD à partir de l'identifiant système et renvoie un objet DTD que vous pouvez passer à $doc->is_valid() ou $doc->validate().

my $dtd = XML::LibXML::Dtd->new(
                      "SOME // Public / ID / 1.0",
                      "test.dtd"
                                );
 my $doc = XML::LibXML->new->parse_file("test.xml");
 $doc->validate($dtd);
parse_string
$dtd = XML::LibXML::Dtd->parse_string($dtd_str);

Identique à new() ci-dessus, sauf que vous pouvez analyser une DTD à partir d'une chaîne. Notez que l'analyse à partir d'une chaîne peut échouer si la DTD contient des références d'entités paramétriques externes avec des URL relatives.

getName
$publicId = $dtd->getName();

Renvoie le nom de la DTD ; c'est-à-dire le nom qui suit immédiatement le mot-clé DOCTYPE.

publicId
$publicId = $dtd->publicId();

Renvoie l'identifiant public du sous-ensemble externe.

systemId
$systemId = $dtd->systemId();

Renvoie l'identifiant système du sous-ensemble externe.
