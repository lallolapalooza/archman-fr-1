NOM

XmRemoveWMProtocolCallback — Une interface pratique de VendorShell qui retire un rappel de la liste interne

SYNTAXE

#include <Xm/Xm.h>
#include <Xm/Protocols.h>
void XmRemoveWMProtocolCallback(
Widget shell,
Atom protocol,
XtCallbackProc callback,
XtPointer closure);

DESCRIPTION

XmRemoveWMProtocolCallback est une interface pratique. Elle appelle XmRemoveProtocolCallback avec la valeur de propriété définie à l'atome retourné par l'internement de WM_PROTOCOLS.

shell
Spécifie le widget auquel la propriété de protocole est associée.
protocol
Spécifie l'atome de protocole.
callback
Spécifie la procédure à appeler lorsqu'un message de protocole est reçu.
closure
Spécifie les données client à passer au rappel lorsqu'il est invoqué.

Pour une définition complète de VendorShell et de ses ressources associées, voir VendorShell(3).

VOIR AUSSI

VendorShell(3), XmAddWMProtocolCallback(3), XmInternAtom(3), et XmRemoveProtocolCallback(3).
