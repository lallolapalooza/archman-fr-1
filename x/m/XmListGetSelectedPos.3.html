NOM

XmListGetSelectedPos — Fonction de liste qui renvoie la position de chaque élément sélectionné dans la liste

SYNTAXE

#include <Xm/List.h>
Boolean XmListGetSelectedPos(
Widget widget,
int **position_list,
int *position_count);

DESCRIPTION

Cette routine est obsolète. Elle est remplacée par l'appel à XtGetValues pour les ressources de liste XmNselectedPositions et XmNselectedPositionCount. XmListGetSelectedPos est une fonction booléenne qui renvoie un tableau des positions des éléments sélectionnés dans une liste.

widget
Spécifie l'identifiant du widget de liste.
position_list
Renvoie un tableau des positions des éléments sélectionnés dans la liste. La position du premier élément de la liste est 1 ; la position du second élément est 2 ; et ainsi de suite. Lorsque la valeur de retour est True, XmListGetSelectedPos alloue de la mémoire pour ce tableau. L'appelant est responsable de la libération de cette mémoire. L'appelant peut récupérer la mémoire allouée en appelant XtFree.
position_count
Renvoie le nombre d'éléments dans position_list.

Pour une définition complète de la liste et de ses ressources associées, voir XmList(3).

RETOUR

Renvoie True si la liste a des éléments sélectionnés, et False si ce n'est pas le cas.

RELATIF

XmList(3).
