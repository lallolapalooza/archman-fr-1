NOM

XmMainWindowSep1 — Fonction MainWindow retournant l'ID du widget du premier séparateur

SYNTAXE

#include <Xm/MainW.h>
Widget XmMainWindowSep1(
Widget widget);

DESCRIPTION

XmMainWindowSep1 retourne l'ID du widget du premier séparateur dans la MainWindow. Le premier séparateur est situé entre la MenuBar et le widget Command. Ce séparateur n'est visible que lorsque XmNshowSeparator est défini sur True.

NOTE : XmMainWindowSep1 est obsolète et existe pour assurer la compatibilité avec les versions précédentes. Utilisez plutôt XtNameToWidget. Passez une variable MainWindow comme premier argument à XtNameToWidget et Separator1 comme second argument.

widget
Spécifie l'ID du widget MainWindow

Pour une définition complète de MainWindow et de ses ressources associées, consultez XmMainWindow(3).

RETOUR

Retourne l'ID du widget du premier séparateur.
