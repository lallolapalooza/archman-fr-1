NOM

XmRepTypeGetId — une fonction du gestionnaire de types de représentation qui récupère le numéro d'identification d'un type de représentation

SYNOPSIS

#include <Xm/RepType.h>
XmRepTypeId XmRepTypeGetId(
String rep_type);

DESCRIPTION

XmRepTypeGetId recherche dans la liste d'enregistrement le type de représentation spécifié et renvoie le numéro d'identification associé.

rep_type
Spécifie le type de représentation pour lequel un numéro d'identification est demandé

RETOUR

Renvoie le numéro d'identification du type de représentation spécifié. Si le type de représentation n'est pas enregistré, la fonction renvoie XmREP_TYPE_INVALID.

VOIR AUSSI

XmRepTypeGetRegistered(3) et XmRepTypeRegister(3).
