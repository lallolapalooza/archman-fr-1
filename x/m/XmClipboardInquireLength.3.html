NOM

XmClipboardInquireLength — Une fonction de presse-papiers qui retourne la longueur des données stockées

SYNTAXE

#include <Xm/CutPaste.h>
int XmClipboardInquireLength (display, window, format_name, length)
        Display * display;
        Window  window;
        char    * format_name;
        unsigned long   * length;
(void)

DESCRIPTION

XmClipboardInquireLength retourne la longueur des données stockées sous un nom de format spécifié pour l'élément de données du presse-papiers. Si aucune donnée n'est trouvée pour le format spécifié, ou s'il n'y a pas d'élément dans le presse-papiers, cette fonction retourne une valeur de 0 (zéro) dans l'argument length.

Tout format passé par nom est supposé avoir une length passée dans un appel à XmClipboardCopy, même si les données n'ont pas encore été transférées au presse-papiers dans ce format.

display
Spécifie un pointeur vers la structure Display qui a été retournée lors d'un appel précédent à XOpenDisplay ou XtDisplay.
window
Spécifie l'identifiant de fenêtre d'un widget qui relie la fenêtre de l'application au presse-papiers. L'identifiant de fenêtre du widget peut être obtenu via XtWindow. La même instance d'application doit passer le même identifiant de fenêtre à chacune des fonctions de presse-papiers qu'elle appelle.
format_name
Spécifie le nom du format pour l'élément de données.
length
Spécifie la longueur du prochain élément de données dans le format spécifié. Cet argument est égal à 0 (zéro) si aucune donnée n'est trouvée pour le format spécifié, ou si le presse-papiers est vide.

VALEUR DE RETOUR

XmClipboardSuccess
La fonction a réussi.
XmClipboardLocked
La fonction a échoué car le presse-papiers était verrouillé par une autre application. L'application peut continuer à appeler la fonction à nouveau avec les mêmes paramètres jusqu'à ce que le verrou disparaisse. Cela donne à l'application l'opportunité de demander si l'utilisateur souhaite continuer à essayer ou abandonner l'opération.
XmClipboardNoData
La fonction n'a pas pu trouver de données dans le presse-papiers correspondant au format demandé. Cela peut se produire car le presse-papiers est vide ; il y a des données dans le presse-papiers, mais pas dans le format demandé ; ou les données dans le format demandé ont été passées par nom et ne sont plus disponibles.

VOIR AUSSI

XmClipboardCopy(3) et XmClipboardStartCopy(3).
