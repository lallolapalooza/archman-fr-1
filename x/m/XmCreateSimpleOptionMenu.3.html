NOM

XmCreateSimpleOptionMenu — Fonction de création simplifiée de widget RowColumn

SYNTAXE

#include <Xm/RowColumn.h>
Widget XmCreateSimpleOptionMenu(
Widget parent,
String name,
ArgList arglist,
Cardinal argcount);

DESCRIPTION

XmCreateSimpleOptionMenu crée une instance d'un widget RowColumn de type XmMENU_OPTION et retourne l'identifiant du widget associé.

Cette routine crée un OptionMenu et son sous-menu contenant des enfants PushButtonGadget ou CascadeButtonGadget. Le nom de chaque bouton est button_n, où n est un entier allant de 0 (zéro) au nombre de boutons du menu moins 1. Le nom de chaque séparateur est separator_n, où n est un entier allant de 0 (zéro) au nombre de séparateurs du menu moins 1. Les boutons et les séparateurs sont nommés et créés dans l'ordre où ils sont spécifiés dans les ressources de création de menu simple RowColumn fournies dans la liste d'arguments.

parent
Spécifie l'identifiant du widget parent
name
Spécifie le nom du widget créé
arglist
Spécifie la liste d'arguments
argcount
Spécifie le nombre de paires attribut/valeur dans la liste d'arguments (arglist)

L'utilisateur peut spécifier des ressources dans un fichier de ressources pour les widgets et gadgets créés automatiquement d'un OptionMenu. Ces widgets (ou gadgets) et les zones associées de l'OptionMenu sont

Gadget de label de l'Option Menu
OptionLabel
Bouton cascade de l'Option Menu
OptionButton

Un certain nombre de ressources existent spécifiquement pour être utilisées avec cette routine et d'autres routines de création de menu simple. Les seuls types de boutons autorisés dans la ressource XmNbuttonType sont XmPUSHBUTTON, XmCASCADEBUTTON, XmSEPARATOR et XmDOUBLE_SEPARATOR. Pour une définition complète de RowColumn et de ses ressources associées, voir XmRowColumn(3).

RETOUR

Retourne l'identifiant du widget RowColumn.

VOIR AUSSI

XmCreateOptionMenu(3), XmCreateRowColumn(3), XmRowColumn(3), et XmVaCreateSimpleOptionMenu(3).
