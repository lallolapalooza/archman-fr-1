NOM

XmRepTypeValidValue — Fonction de gestion de type de représentation qui teste la validité d'une valeur numérique d'une ressource de type de représentation

SYNTAXE

#include <Xm/RepType.h>
Boolean XmRepTypeValidValue(
XmRepTypeId rep_type_id,
unsigned char test_value,
Widget enable_default_warning);

DESCRIPTION

XmRepTypeValidValue teste la validité d'une valeur numérique pour un type de représentation donné. La fonction génère un message d'avertissement par défaut si la valeur est invalide et si l'argument enable_default_warning n'est pas NULL.

rep_type_id
Spécifie l'identifiant du type de représentation.
test_value
Spécifie la valeur numérique à tester.
enable_default_warning
Spécifie l'identifiant du widget qui contient un message d'avertissement par défaut. Si ce paramètre est NULL, aucun message d'avertissement par défaut n'est généré et l'application doit fournir sa propre gestion des erreurs.

VALEUR DE RETOUR

Retourne True si la valeur spécifiée est valide ; sinon, retourne False.

VOIR AUSSI

XmRepTypeGetId(3) et XmRepTypeRegister(3).
