NOM

XmCreateRadioBox — Une fonction de création de commodité pour le widget RowColumn

SYNTAXE

#include <Xm/RowColumn.h>
Widget XmCreateRadioBox(
Widget parent,
String name,
ArgList arglist,
Cardinal argcount);

DESCRIPTION

XmCreateRadioBox crée une instance d'un widget RowColumn de type XmWORK_AREA et renvoie l'identifiant du widget associé. Typiquement, il s'agit d'un widget composite qui contient plusieurs ToggleButtonGadgets. Le RadioBox arbitre et garantit qu'au plus un ToggleButtonGadget est activé à tout moment.

À moins que l'application ne fournisse d'autres valeurs dans arglist, cette fonction fournit des valeurs initiales pour plusieurs ressources de RowColumn. Elle initialise XmNpacking à XmPACK_COLUMN, XmNradioBehavior à True, XmNisHomogeneous à True, et XmNentryClass à XmToggleButtonGadgetClass.

Dans un RadioBox, la ressource ToggleButton ou ToggleButtonGadget XmNindicatorType est par défaut XmONE_OF_MANY, et la ressource ToggleButton ou ToggleButtonGadget XmNvisibleWhenOff est par défaut True.

Cette routine est fournie comme une fonction de commodité pour la création de widgets RowColumn.

parent
Spécifie l'identifiant du widget parent.
name
Spécifie le nom du widget créé.
arglist
Spécifie la liste des arguments.
argcount
Spécifie le nombre de paires attribut/valeur dans la liste des arguments (arglist).

Pour une définition complète de RowColumn et de ses ressources associées, voir XmRowColumn(3).

VALEUR_RETOURNEE

Renvoie l'identifiant du widget RowColumn.
