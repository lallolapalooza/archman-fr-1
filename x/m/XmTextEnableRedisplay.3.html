NOM

XmTextEnableRedisplay — Fonction Text qui force la mise à jour visuelle d'un widget Text

SYNOPSIS

#include <Xm/Text.h>
void XmTextEnableRedisplay(
Widget widget);

DESCRIPTION

XmTextEnableRedisplay est utilisé conjointement avec XmTextDisableRedisplay, qui supprime la mise à jour visuelle du widget Text. Lorsque XmTextEnableRedisplay est appelé, il détermine si des attributs visuels ont été définis ou modifiés pour le widget spécifié depuis que XmTextDisableRedisplay a été appelé. Si c'est le cas, il force le widget à mettre à jour son affichage visuel pour tous les changements intermédiaires. Tous les changements ultérieurs affectant l'apparence visuelle provoquent la mise à jour de l'affichage visuel par le widget. Cette fonction provoque également la restauration du curseur d'insertion, qui n'est pas affiché pendant la désactivation du réaffichage.

widget
Spécifie l'ID du widget Text
