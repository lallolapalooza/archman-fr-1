NOM

XmSimpleSpinBox — classe de widget SpinBox simple

SYNTAXE

#include <Xm/SSpinB.h>

DESCRIPTION

Le widget XmSimpleSpinBox est un contrôle d'interface utilisateur pour incrémenter et décrémenter un TextField arbitraire. Par exemple, il peut être utilisé pour parcourir les mois de l'année ou les jours du mois.

La sous-classification de widget n'est pas prise en charge pour la classe de widget XmSimpleSpinBox.

Classes

Le widget XmSimpleSpinBox hérite des comportements et des ressources des classes Core, Composite et XmManager.

Le pointeur de classe est XmSimpleSpinBoxWidgetClass.

Le nom de la classe est XmSimpleSpinBoxWidget.

Nouvelles Ressources

Le tableau suivant définit un ensemble de ressources de widget utilisées par l'application pour spécifier des données. L'application peut également définir les valeurs des ressources pour les classes héritées afin de définir les attributs de ce widget. Pour référencer une ressource par son nom ou par sa classe dans un fichier .Xdefaults, l'application doit supprimer le préfixe XmN ou XmC et utiliser les lettres restantes. Pour spécifier l'une des valeurs définies pour une ressource dans un fichier .Xdefaults, l'application doit supprimer le préfixe Xm et utiliser les lettres restantes (en minuscules ou en majuscules, mais en incluant les underscores entre les mots). Les codes dans la colonne d'accès indiquent si la ressource donnée peut être définie au moment de la création (C), définie en utilisant XtSetValues (S), récupérée en utilisant XtGetValues (G), ou n'est pas applicable (N/A).

XmNarrowLayout
Spécifie le style et la position des flèches du SpinBox. Les valeurs suivantes sont prises en charge :
XmARROWS_FLAT_BEGINNING
Les flèches sont placées côte à côte à droite du TextField.
XmARROWS_FLAT_END
Les flèches sont placées côte à côte à gauche du TextField.
XmARROWS_SPLIT
La flèche vers le bas est à gauche et la flèche vers le haut est à droite du TextField.
XmARROWS_BEGINNING
Les flèches sont empilées et placées à gauche du TextField.
XmARROWS_END
Les flèches sont empilées et placées à droite du TextField.
XmNarrowSensitivity
Spécifie la sensibilité des flèches dans le XmSimpleSpinBox. Les valeurs suivantes sont prises en charge :
XmARROWS_SENSITIVE

XmARROWS_DECREMENT_SENSITIVE

XmARROWS_INCREMENT_SENSITIVE
La flèche vers le haut est active et la flèche vers le bas est inactive pour la sélection utilisateur.
XmARROWS_INSENSITIVE

XmNcolumns
Spécifie le nombre de colonnes du champ de texte.
XmNdecimalPoints
Spécifie la position du caractère radix dans la valeur numérique lorsque XmNspinBoxChildType est XmNUMERIC. Cette ressource est utilisée pour permettre des valeurs flottantes dans le widget XmSimpleSpinBox.
XmNeditable
Spécifie si le champ de texte peut accepter des saisies.
Lorsque XmNeditable est utilisé sur un widget, il définit le site de dépôt sur XmDROP_SITE_ACTIVE.
XmNincrementValue
Spécifie le montant à ajouter ou soustraire de la XmNposition lorsque le XmNspinBoxChildType est XmNUMERIC. Lorsque l'action Up est activée, la XmNincrementValue est ajoutée à la valeur XmNposition ; lorsque l'action Down est activée, la XmNincrementValue est soustraite de la valeur XmNposition. Lorsque XmNspinBoxChildType est XmSTRING, cette ressource est ignorée.
XmNinitialDelay
Spécifie le temps en millisecondes avant que les boutons fléchés ne commencent à tourner en continu.
XmNnumValues
Spécifie le nombre d'éléments dans la liste XmNvalues lorsque la ressource XmNspinBoxChildType est XmSTRING. La valeur de cette ressource doit être un entier positif. Le XmNnumValues est maintenu par le widget XmSimpleSpinBox lorsque des éléments sont ajoutés ou supprimés de la liste XmNvalues. Lorsque XmNspinBoxChildType n'est pas XmSTRING, cette ressource est ignorée.
XmNvalues
Fournit la liste des chaînes de caractères à parcourir lorsque la ressource XmNspinButtonChildType est XmSTRING. Lorsque XmNspinBoxChildType n'est pas XmSTRING, cette ressource est ignorée.
XmNmaximumValue
Spécifie la valeur maximale autorisée pour le widget XmSimpleSpinBox.
XmNminimumValue
Spécifie la valeur minimale autorisée pour le widget XmSimpleSpinBox.
XmNposition
Spécifie la valeur actuelle du widget XmSimpleSpinBox.
XmNrepeatDelay
Spécifie le temps en millisecondes entre chaque répétition lorsque les boutons fléchés sont maintenus enfoncés.
XmNspinBoxChildType
Spécifie le type de données que le widget XmSimpleSpinBox gérera. Les valeurs suivantes sont prises en charge :
XmSTRING
Le widget gère une liste de chaînes de caractères. Il est utilisé avec les ressources XmNvalues et XmNnumValues.
XmNUMERIC
Le widget gère des valeurs numériques entières. Il est utilisé avec les ressources XmNminimumValue, XmNmaximumValue, XmNincrementValue et XmNdecimalPoints.
XmNtextField
Définit le widget TextField associé au XmSimpleSpinBox. S'il n'est pas spécifié, le widget XmSimpleSpinBox en créera un par défaut.

Listes de rappels

Le widget XmSimpleSpinBox prend en charge les listes de rappels suivantes :

XmNmodifyVerifyCallback
Ce rappel est appelé lorsqu'une modification est apportée au champ texte avant que la modification ne soit effectivement appliquée. Il permet de valider ou de rejeter la modification. L'appelant peut intercepter la modification en modifiant le `reason` dans la structure XmSpinBoxVerifyCallbackStruct.
XmNvalueChangedCallback
Ce rappel est appelé après qu'une nouvelle valeur a été définie dans le widget, soit par l'utilisateur, soit programmatiquement.

La structure de rappel XmSpinBoxCallbackStruct contient les champs suivants :

reason
Indique la raison du rappel. Peut être XmCR_VALUE_CHANGED ou XmCR_MODIFY_VERIFY.
event
Un pointeur vers l'événement XEvent qui a déclenché le rappel.
current_value
La valeur actuelle du spinbox (pour XmNUMERIC).
new_value
La nouvelle valeur proposée pour le spinbox (pour XmNUMERIC).
current_string
La chaîne actuelle du spinbox (pour XmSTRING).
new_string
La nouvelle chaîne proposée pour le spinbox (pour XmSTRING).
do_it
(Uniquement pour XmCR_MODIFY_VERIFY) Indique si la modification doit être effectuée. Définir à False rejette la modification.
ptrue
(Uniquement pour XmCR_MODIFY_VERIFY) Un pointeur booléen qui, s'il est défini sur False, empêche la modification.
widget
Le widget SpinBox.

EXEMPLE

Pour créer un widget XmSimpleSpinBox simple :

    Widget spinbox;
    spinbox = XmCreateSimpleSpinBox(parent, "spinbox", args, num_args);
    XtManageChild(spinbox);

Pour créer un XmSimpleSpinBox qui gère des chaînes de caractères :

    XmString months[] = {
        XmStringCreateLtoR("January", XmSTRING_DEFAULT_CHARSET),
        XmStringCreateLtoR("February", XmSTRING_DEFAULT_CHARSET),
        // ... autres mois
        XmStringCreateLtoR("December", XmSTRING_DEFAULT_CHARSET)
    };
    int num_months = XtNumber(months);
    Widget spinbox;
    Arg args[5];
    int n = 0;

    XtSetArg(args[n], XmNspinBoxChildType, XmSTRING); n++;
    XtSetArg(args[n], XmNvalues, months); n++;
    XtSetArg(args[n], XmNnumValues, num_months); n++;
    XtSetArg(args[n], XmNposition, 0); n++; // Commence par Janvier

    spinbox = XmCreateSimpleSpinBox(parent, "month_spinbox", args, n);
    XtManageChild(spinbox);

Pour créer un XmSimpleSpinBox qui gère des valeurs numériques :

    Widget spinbox;
    Arg args[5];
    int n = 0;

    XtSetArg(args[n], XmNspinBoxChildType, XmNUMERIC); n++;
    XtSetArg(args[n], XmNminimumValue, 1); n++;
    XtSetArg(args[n], XmNmaximumValue, 31); n++;
    XtSetArg(args[n], XmNincrementValue, 1); n++;
    XtSetArg(args[n], XmNposition, 1); n++; // Commence par le 1er jour

    spinbox = XmCreateSimpleSpinBox(parent, "day_spinbox", args, n);
    XtManageChild(spinbox);

WIDGETS

Le widget XmSimpleSpinBox est un composite qui contient généralement un widget XmTextField et deux widgets XmArrowButton (ou XmDrawnButton).

XmManager(3), XmTextField(3), XmArrowButton(3), XmCreateSimpleSpinBox(3), Motif Reference Manual.

>XmNmaximumValue
Spécifie la limite supérieure de la plage du XmSimpleSpinBox lorsque XmNspinBoxChildType est XmNUMERIC.
XmNminimumValue
Spécifie la limite inférieure de la plage du XmSimpleSpinBox lorsque XmNspinBoxChildType est XmNUMERIC.
XmNmodifyVerifyCallback
Spécifie la fonction de rappel à appeler juste avant que la position du XmSimpleSpinBox ne change. L'application peut utiliser cette fonction de rappel pour implémenter une nouvelle logique liée à l'application (y compris la définition d'une nouvelle position de rotation ou l'annulation de l'action imminente). Par exemple, cette fonction de rappel peut être utilisée pour arrêter la rotation juste avant de passer les limites de position supérieure et inférieure. Si l'application définit le membre doit de la structure XmSimpleSpinBoxCallbackStruct à False, rien ne se passe. Sinon, la position change. Les raisons envoyées par la fonction de rappel sont XmCR_SPIN_NEXT ou XmCR_SPIN_PRIOR.
XmNposition
La ressource XmNposition a une valeur différente en fonction de la ressource XmNspinBoxChildType. Lorsque XmNspinBoxChildType est XmSTRING, XmNposition est l'index dans la liste XmNvalues pour l'élément actuel. Lorsque la ressource XmNspinBoxChildType est XmNUMERIC, XmNposition est la valeur entière du XmSimpleSpinBox qui se situe dans la plage de XmNmaximumValue et XmNminimumValue.
XmNrepeatDelay
Spécifie le nombre de millisecondes entre les appels répétés à la fonction XmNvalueChangedCallback pendant que l'utilisateur fait tourner le XmSimpleSpinBox.
XmNspinBoxChildType
Spécifie le style du XmSimpleSpinBox. Les valeurs suivantes sont prises en charge :
XmSTRING
L'élément enfant est une valeur de chaîne spécifiée par la ressource XmNvalues et incrémentée et décrémentée en modifiant la ressource XmNposition.
XmNUMERIC
L'élément enfant est une valeur numérique spécifiée par la ressource XmNposition et incrémentée conformément à la ressource XmNincrementValue.
XmtextField
Spécifie le widget de champ de texte.
XmNvalueChangedCallback
Spécifie la fonction de rappel à appeler chaque fois que la valeur de la ressource XmNposition est modifiée à l'aide des flèches de rotation. La fonction XmNvalueChangedCallback transmet la structure XmSimpleSpinBoxCallbackStruct call_data.

Informations sur les Rappels

Un pointeur vers la structure suivante est passé à chaque fonction de rappel XmSimpleSpinBox :

typedef struct {
        int             reason;
        XEvent          *event;
        Widget          widget;
        Boolean doit;
        int             position;
        XmString        value;
        Boolean crossed_boundary;
} XmSimpleSpinBoxCallbackStruct;

L'argument reason indique la raison pour laquelle la fonction de rappel a été invoquée. Il existe trois raisons possibles pour que cette fonction de rappel soit émise. La raison est XmCR_OK lorsqu'il s'agit du premier appel à la fonction de rappel au début d'une rotation ou s'il s'agit d'une activation unique des flèches de rotation. Si le XmSimpleSpinBox est en cours de rotation continue, la raison sera XmCR_SPIN_NEXT ou XmCR_SPIN_PRIOR, en fonction de la flèche qui tourne.

L'argument event pointe vers le XEvent qui a déclenché la fonction de rappel. Il peut être NULL lorsque le XmSimpleSpinBox tourne continuellement.

L'argument widget

> l'identifiant du widget pour le widget boîte déroulante simple qui a été affecté par ce rappel.

L'argument doit est défini uniquement lorsque call_data provient de XmNmodifyVerifyCallback. Il indique que l'action qui a provoqué l'appel du rappel doit être effectuée. L'action n'est pas effectuée si doit est défini sur False.

L'argument position est la nouvelle valeur de la ressource XmNposition résultant du défilement.

L'argument value est la nouvelle valeur XmString affichée dans le widget Text résultant du défilement. L'application doit copier cette chaîne si elle est utilisée au-delà de la portée de la structure call_data.

L'argument crossed_boundary est True lorsque la boîte déroulante effectue un cycle. C'est le cas lorsque le type d'enfant XmNspinBoxChildType de XmSTRING passe du premier élément au dernier ou du dernier élément au premier. Dans le cas du type d'enfant XmNspinBoxChildType de XmNUMERIC, la limite est franchie lorsque le XmSimpleSpinBox passe de la valeur maximale à la valeur minimale ou vice versa.

ERREURS/AVERTISSEMENTS

Le toolkit affichera un avertissement si l'application tente de définir la valeur de la ressource XmNtextField, qui est en lecture seule (marquée G dans la table des ressources).
