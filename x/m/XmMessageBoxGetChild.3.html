NOM

XmMessageBoxGetChild — Fonction MessageBox utilisée pour accéder à un composant

SYNTAXE

#include <Xm/MessageB.h>
Widget XmMessageBoxGetChild(
Widget widget,
unsigned char child);

DESCRIPTION

XmMessageBoxGetChild est utilisée pour accéder à un composant dans une MessageBox. Les paramètres fournis à la fonction sont le widget MessageBox et une valeur indiquant quel composant accéder.

NOTE : Cette routine est obsolète et existe pour assurer la compatibilité avec les versions précédentes. Au lieu d'appeler XmMessageBoxGetChild, vous devriez appeler XtNameToWidget comme décrit dans la page de référence XmMessageBox(3).

widget
Spécifie l'identifiant du widget MessageBox.
child
Spécifie un composant dans la MessageBox. Les valeurs suivantes sont légales pour ce paramètre :
•
XmDIALOG_CANCEL_BUTTON
•
XmDIALOG_DEFAULT_BUTTON
•
XmDIALOG_HELP_BUTTON
•
XmDIALOG_MESSAGE_LABEL
•
XmDIALOG_OK_BUTTON
•
XmDIALOG_SEPARATOR
•
XmDIALOG_SYMBOL_LABEL

Pour une définition complète de MessageBox et de ses ressources associées, voir XmMessageBox(3).

VALEUR DE RETOUR

Retourne l'identifiant du widget du composant MessageBox spécifié. Une application ne doit pas supposer que le widget retourné sera d'une classe particulière.

VOIR AUSSI
