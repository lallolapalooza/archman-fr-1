NOM

XmCreateDropDown — Fonction de création du widget DropDown par défaut

SYNTAXE

#include <Xm/DropDown.h>
Widget XmCreateDropDown(
Widget parent,
String name,
ArgList arglist,
Cardinal arg_count);

DESCRIPTION

XmCreateDropDown crée une instance d'un widget DropDown et retourne l'identifiant du widget associé.

parent
Spécifie l'identifiant du widget parent.
name
Spécifie le nom du widget créé.
arglist
Spécifie la liste des arguments.
arg_count
Spécifie le nombre de paires attribut/valeur dans la liste des arguments (arglist).

Pour une définition complète de DropDown et de ses ressources associées, voir XmDropDown(3).

RETOUR

Retourne l'identifiant du widget DropDown.

VOIR AUSSI

XmDropDown(3).
