NOM

XmStringDirection — Type de données pour la direction d'affichage dans une chaîne

SYNTAXE

#include <Xm/Xm.h>

DESCRIPTION

XmStringDirection est le type de données pour spécifier la direction dans laquelle le système affiche les caractères d'une chaîne, ou les caractères d'un segment d'une chaîne composée. Il s'agit d'une énumération avec trois valeurs possibles :

XmSTRING_DIRECTION_L_TO_R
Spécifie l'affichage de gauche à droite
XmSTRING_DIRECTION_R_TO_L
Spécifie l'affichage de droite à gauche
XmSTRING_DIRECTION_DEFAULT
Spécifie que la direction d'affichage sera définie par le widget dans lequel la chaîne composée doit être affichée.
