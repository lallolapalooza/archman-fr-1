NOM

XmRowColumn — Classe de widget RowColumn

SYNTAXE

#include <Xm/RowColumn.h>

DESCRIPTION

Le widget RowColumn est un gestionnaire RowColumn à usage général capable de contenir tout type de widget comme enfant. En général, il ne nécessite aucune connaissance particulière sur le fonctionnement de ses enfants et ne fournit rien au-delà de la prise en charge de plusieurs styles de mise en page différents. Cependant, il peut être configuré comme un menu, auquel cas il attend uniquement certains enfants, et se configure selon une mise en page particulière. Les menus pris en charge sont la barre de menu (MenuBar), les sous-menus (Pulldown) ou les menus contextuels (Popup), et les menus optionnels (OptionMenu). RowColumn utilise le trait XmQTmenuSavvy et détient le trait XmQTmenuSystem.

Le type de mise en page effectuée est contrôlé par la manière dont l'application a défini les différentes ressources de mise en page. Il peut être configuré pour organiser ses enfants soit en lignes, soit en colonnes. De plus, l'application peut spécifier comment les enfants sont organisés, comme suit :

•
Les enfants sont regroupés de manière serrée en lignes ou en colonnes
•
Chaque enfant est placé dans une boîte de taille identique (produisant un aspect symétrique)
•
Une mise en page spécifique (les positions x et y actuelles des enfants contrôlent leur emplacement)

De plus, l'application contrôle l'espacement entre chaque ligne et chaque colonne, ainsi que l'espacement des marges entre les bords du widget RowColumn et les enfants qui y sont placés.

La procédure par défaut XmNinsertPosition pour RowColumn renvoie la valeur de XmNpositionIndex si elle a été spécifiée pour l'enfant. Sinon, cette procédure renvoie le nombre d'enfants dans la liste XmNnumChildren de RowColumn. Dans une barre de menu, un sous-menu ou un menu contextuel, la valeur par défaut de la ressource XmNshadowThickness est 2. Dans un menu optionnel ou une zone de travail (telle qu'une boîte radio ou une case à cocher), cette ressource n'est pas applicable et son utilisation n'est pas définie. Si une application souhaite placer une ombre 3D autour d'un menu optionnel ou d'une zone de travail, elle peut créer le RowColumn comme enfant d'un widget Frame.

Dans une barre de menu, un sous-menu ou un menu contextuel, la ressource XmNnavigationType n'est pas applicable et son utilisation est indéfinie. Dans une zone de travail, la valeur par défaut de XmNnavigationType est XmTAB_GROUP. Dans un menu optionnel, la valeur par défaut de XmNnavigationType est XmNONE.

Dans une barre de menu, un sous-menu ou un menu contextuel, la ressource XmNtraversalOn n'est pas applicable et son utilisation est indéfinie. Dans un menu optionnel ou une zone de travail, la valeur par défaut de XmNtraversalOn est True.

Si le parent du RowColumn est un MenuShell, la ressource XmNmappedWhenManaged est forcée à False lorsque le widget est réalisé.

L'utilisateur peut spécifier des ressources dans un fichier de ressources pour les widgets et gadgets créés automatiquement d'un menu optionnel. La liste suivante identifie les noms de ces widgets (ou gadgets) et les zones associées du menu optionnel.

Gadget d'étiquette de menu optionnel
OptionLabel
Bouton de cascade de menu optionnel
OptionButton

Pour les sous-menus et les menus contextuels, les menus contextuels et les sous-menus ont des comportements particuliers lorsque le bouton <Btn1> est pressé en dehors des menus. Ces comportements sont résumés ici.

Lorsqu'un menu est déjà affiché, un utilisateur peut soit presser <Btn1> dans la même zone que le menu affiché, soit presser <Btn1> dans une autre zone qui devrait avoir un menu affiché. Lorsque <Btn1> est pressé dans la même zone que le menu déjà affiché, ce menu est retiré. Si <Btn1> est pressé dans une zone différente, le menu contextuel associé est affiché pour la nouvelle zone. Notez, cependant, que si le XmNpopupHandlerCallback de XmManager ou XmPrimitive est disponible, le rappel peut remplacer ces comportements par défaut.

Pour les sous-menus, un utilisateur peut presser <Btn1> sur le bouton de cascade pour afficher le sous-menu, puis cliquer à nouveau dessus. Lors du second clic, le sous-menu est retiré.

Les menus contextuels ne sont pas autorisés à avoir des parents NULL.

Menus détachables

Les sous-menus et les menus contextuels prennent en charge les menus détachables, qui permettent à l'utilisateur de conserver un panneau de menu à l'écran pour faciliter les sélections de menu ultérieures. Un panneau de menu qui peut être détaché est identifié par un bouton détachable qui s'étend sur la largeur du panneau de menu et affiche une ligne pointillée. Un panneau de menu détaché contient une icône de menu système du gestionnaire de fenêtres et une barre de titre. La fenêtre de titre affiche l'étiquette du bouton de cascade qui a initié l'action lorsque le type d'étiquette est XmSTRING. Si l'étiquette contient un pixmap, la fenêtre de titre est vide. Un menu détachable d'un panneau de menu contextuel affiche également un titre vide. Les menus détachables ne doivent pas être partagés.

L'utilisateur peut détacher un panneau de menu à l'aide de la souris ou du clavier. Cliquer sur <Btn1> ou presser <osfActivate> (ou <osfSelect>) sur le bouton détachable détache le panneau de menu à la position actuelle. Presser <Btn2> sur le bouton détachable détache le panneau de menu et permet à l'utilisateur de faire glisser le panneau détaché vers une nouvelle position désignée en relâchant le bouton de la souris. Détacher un panneau de menu retire le menu actif actuel. Une seule copie détachable par panneau de menu est autorisée. Les actions de détachement ultérieures d'un menu détaché retirent d'abord la copie existante.

Le nom du bouton détachable d'un panneau de menu détaché est TearOffControl. Le nom peut être utilisé pour définir des ressources dans un fichier de ressources. Une application peut également obtenir le bouton détachable lui-même en utilisant XmGetTearOffControl puis définir des valeurs de ressources en appelant XtSetValues.

Le bouton détachable a un comportement similaire à un séparateur. Son apparence peut être spécifiée avec les ressources suivantes du bouton détachable : XmNbackground, XmNbackgroundPixmap, XmNbottomShadowColor, XmNforeground, XmNheight, XmNmargin, XmNseparatorType, XmNshadowThickness, et XmNtopShadowColor. Reportez-vous à la page de référence XmSeparator pour une description complète de chacune de ces ressources.

Les ressources XmNtearOffModel, XmNtearOffMenuActivateCallback et XmNtearOffMenuDeactivateCallback sont des ressources RowColumn qui affectent le comportement des menus détachables. La ressource XmNtearOffTitle permet à l'application de spécifier le titre du menu détachable si celui-ci est détaché.

Par défaut, les menus ne se détachent pas. Définir la ressource XmNtearOffModel sur XmTEAR_OFF_ENABLED active la fonctionnalité de détachement. Il n'y a pas de convertisseur de ressources préenregistré pour XmNtearOffModel. Pour permettre l'activation de la fonctionnalité de détachement via la base de données de ressources, appelez la fonction XmRepTypeInstallTearOffModelConverter.

La politique de focus des menus détachables suit la politique standard du gestionnaire de fenêtres. Il est recommandé de définir les ressources startupKeyFocus et autoKeyFocus de mwm sur True.

Classes

RowColumn hérite des comportements, ressources et traits des classes Core, Composite, Constraint et XmManager.

Le pointeur de classe est xmRowColumnWidgetClass.

XmNadjustLast
Étend la dernière ligne d'enfants jusqu'au bord inférieur de RowColumn (lorsque XmNorientation est XmHORIZONTAL) ou étend la dernière colonne jusqu'au bord droit de RowColumn (lorsque XmNorientation est XmVERTICAL). La définition de XmNadjustLast à Faux désactive cette fonctionnalité.
XmNadjustMargin
Spécifie si les marges mineures internes de tous les éléments contenus dans le widget RowColumn sont forcées à la même valeur. La marge mineure interne correspond aux ressources XmNmarginLeft, XmNmarginRight, XmNmarginTop et XmNmarginBottom prises en charge par XmLabel et XmLabelGadget.
Une orientation horizontale fait en sorte que XmNmarginTop et XmNmarginBottom de tous les éléments d'une ligne particulière soient forcés à la même valeur ; la valeur est la plus grande marge spécifiée pour l'un des éléments Label.
Une orientation verticale fait en sorte que XmNmarginLeft et XmNmarginRight de tous les éléments d'une colonne particulière soient forcés à la même valeur ; la valeur est la plus grande marge spécifiée pour l'un des éléments Label.
Ceci permet de garder tout le texte de chaque ligne ou colonne aligné avec tout autre texte de sa ligne ou colonne. Si XmNrowColumnType est soit XmMENU_POPUP soit XmMENU_PULLDOWN et que cette ressource est Vrai, seuls les enfants de type bouton auront leurs marges ajustées.
XmNentryAlignment
Spécifie le type d'alignement pour les enfants qui sont des sous-classes de XmLabel ou XmLabelGadget lorsque XmNisAligned est activé. Les types d'alignement textuels suivants sont disponibles :
•
XmALIGNMENT_BEGINNING (par défaut)
•
XmALIGNMENT_CENTER
•
XmALIGNMENT_END
Voir la description de XmNalignment dans la page de référence XmLabel(3) pour une explication de ces actions.
XmNentryBorder
Impose une largeur de bordure uniforme à tous les enfants de RowColumn. La valeur par défaut est
e est 0 (zéro), ce qui désactive la fonctionnalité.
XmNentryCallback
Désactive les callbacks XmNactivateCallback et XmNvalueChangedCallback pour tous les widgets et gadgets CascadeButton, DrawnButton, PushButton et ToggleButton contenus dans le widget RowColumn. Si l'application fournit cette ressource, les callbacks XmNactivateCallback et XmNvalueChangedCallback sont alors réacheminés vers les callbacks XmNentryCallback. Cela permet à une application de fournir une routine de callback unique pour gérer tous les éléments contenus dans un widget RowColumn. La raison du callback est XmCR_ACTIVATE. Si l'application ne fournit pas cette ressource, les callbacks XmNactivateCallback et XmNvalueChangedCallback pour chaque élément du widget RowColumn fonctionnent normalement.
L'application doit fournir cette ressource lors de la création de ce widget. La modification de cette ressource à l'aide de XtSetValues n'est pas prise en charge.
XmNentryClass
Spécifie la seule classe de widget qui peut être ajoutée au widget RowColumn ; cette ressource n'est significative que lorsque la ressource XmNisHomogeneous est définie sur True. Les variantes de widget et de gadget de la classe spécifiée peuvent être ajoutées au widget.
Lorsque XmCreateRadioBox est appelé ou lorsque XmNrowColumnType est défini sur XmWORK_AREA et que XmNradioBehavior est True, la valeur par défaut de XmNentryClass est xmToggleButtonGadgetClass. Lorsque XmNrowColumnType est défini sur XmMENU_BAR, la valeur de XmNentryClass est forcée à xmCascadeButtonWidgetClass.
XmNentryVerticalAlignment
Spécifie le type d'alignement vertical pour les enfants qui sont des sous-classes de XmLabel, XmLabelGadget et XmText. Cette ressource n'est pas valide si XmNorientation est XmVERTICAL et XmNpacking est XmPACK_TIGHT, car cette disposition préserve des hauteurs variables parmi les enfants. Les types d'alignement vertical incluent :
XmALIGNMENT_BASELINE_BOTTOM
Aligne la ligne de base inférieure de tous les enfants d'une ligne. Cette ressource est applicable uniquement lorsque tous les enfants d'une ligne contiennent des données textuelles.
XmALIGNMENT_BASELINE_TOP
Aligne la ligne de base supérieure de tous les enfants d'une ligne. Cette ressource est applicable uniquement lorsque tous les enfants d'une ligne contiennent des données textuelles.
XmALIGNMENT_CONTENTS_BOTTOM
Aligne le bas du contenu (texte ou pixmap) de tous les enfants d'une ligne.
XmALIGNMENT_CENTER
Aligne le centre de tous les enfants d'une ligne.
XmALIGNMENT_CONTENTS_TOP
Aligne le haut du contenu (texte ou pixmap) de tous les enfants d'une ligne.
XmNisAligned
Spécifie l'alignement du texte pour chaque élément du widget RowColumn ; cela s'applique uniquement aux éléments qui sont des sous-classes de XmLabel ou XmLabelGadget. Cependant, si l'élément est un widget ou un gadget Label et que son parent est un panneau de menu Popup ou un panneau de menu Pulldown, l'alignement n'est pas effectué ; le Label est traité comme le titre du panneau de menu, et l'alignement défini par l'application n'est pas remplacé. XmNentryAlignment contrôle le type d'alignement textuel.
XmNisHomogeneous
Indique si le widget RowColumn doit appliquer une homogénéité exacte parmi les éléments qu'il contient ; si cette ressource est définie sur True, seuls les widgets appartenant à la classe indiquée par XmNentryClass sont autorisés comme enfants du widget RowColumn. Ceci est le plus souvent utilisé lors de la création d'une MenuBar. Tenter d'insérer un enfant qui n'est pas membre de la classe spécifiée génère un message d'avertissement.
Dans une MenuBar, la valeur de XmNisHomogeneous est forcée à True. Dans une OptionMenu, la valeur est forcée à False. Lorsque XmCreateRadioBox est appelé, la valeur par défaut est True. Sinon, la valeur par défaut est False.
XmNlabelString
Lorsque XmNrowColumnType est défini sur XmMENU_OPTION, cette ressource pointe vers une chaîne de texte qui affiche le libellé par rapport à la zone de sélection. Le positionnement du libellé par rapport à la zone de sélection dépend de la direction de mise en page dans l'orientation horizontale. Cette ressource n'est pas significative pour tous les autres types de RowColumn. Si l'application souhaite modifier le libellé après la création, elle doit obtenir l'ID du LabelGadget (XmOptionLabelGadget) et appeler XtSetValues directement sur le LabelGadget. La valeur par défaut est aucun libellé.
XmNmapCallback
Spécifie une fonction de rappel spécifique au widget qui est appelée lorsque la fenêtre associée au widget RowColumn est sur le point d'être mappée. La raison du rappel est XmCR_MAP.
XmNmarginHeight
Spécifie la quantité d'espace vide entre le bord supérieur du widget RowColumn et le premier élément de chaque colonne, et entre le bord inférieur du widget RowColumn et le dernier élément de chaque colonne. La valeur par défaut est 0 (zéro) pour les panneaux de menu Pulldown et Popup, et 3 pixels pour les autres types de RowColumn.
XmNmarginWidth
Spécifie la quantité d'espace vide entre le bord gauche du widget RowColumn et le premier élément de chaque ligne, et entre le bord droit du widget RowColumn et le dernier élément de chaque ligne. La valeur par défaut est 0 (zéro) pour les panneaux de menu Pulldown et Popup, et 3 pixels pour les autres types de RowColumn.
XmNmenuAccelerator
Cette ressource est utile uniquement lorsque le widget RowColumn a été configuré pour fonctionner comme un panneau de menu Popup ou une MenuBar. Le format de cette ressource est similaire à la spécification de la partie gauche d'une chaîne de traduction, avec la limitation qu'elle doit spécifier un événement clavier. Pour un panneau de menu Popup, lorsque l'accélérateur est tapé par l'utilisateur, le panneau de menu Popup est affiché. Pour une MenuBar, lorsque l'accélérateur est tapé par l'utilisateur, le premier élément de la MenuBar est mis en surbrillance, et le parcours est activé dans la MenuBar. La valeur par défaut pour un panneau de menu Popup est <osfMenu>. La valeur par défaut pour une MenuBar est <osfMenuBar>. La définition de la ressource XmNpopupEnabled sur False désactive l'accélérateur.
XmNmenuHelpWidget
Spécifie l'ID du widget pour le CascadeButton, qui est traité comme le widget d'aide si XmNrowColumnType est défini sur XmMENU_BAR. Le coin de la MenuBar où le widget d'aide est placé dépend de la ressource XmNlayoutDirection du widget. Si le widget RowColumn est d'un type autre que XmMENU_BAR, cette ressource n'est pas significative.
XmNmenuHistory
Spécifie l'ID du widget du dernier élément de menu activé. Il est également utile pour spécifier la sélection actuelle pour une OptionMenu. Si XmNrowColumnType est défini sur XmMENU_OPTION, l'élément de menu spécifié est positionné sous le curseur lorsque le menu est affiché.
Si le widget RowColumn a la ressource XmNradioBehavior définie sur True, le champ widget associé à cette ressource contient l'ID du widget du dernier ToggleButton ou ToggleButtonGadget qui est passé de non sélectionné à sélectionné. La valeur par défaut est l'ID du widget du premier enfant du widget.
XmNmenuPost
Spécifie une description d'événement X indiquant un événement de bouton qui affiche un système de menu. La valeur par défaut pour XmMENU_POPUP est BMenu Press. La valeur par défaut pour XmMENU_OPTION, XmMENU_BAR et XmWORK_AREA est <Btn1> Press. La ressource XmNmenuPost pour les menus déroulants doit être cohérente avec celle du parent de menu de niveau supérieur (bien que le type d'événement soit ignoré). La définition de cette ressource sur BTransfer Press entrera en conflit avec les opérations de glisser-déposer, qui utilisent BTransfer Press comme liaison de bouton par défaut. Par conséquent, cette ressource ne peut pas être BTransfer Press.
XmNmnemonic
Cette ressource est utile uniquement lorsque XmNrowColumnType est défini sur XmMENU_OPTION. Elle spécifie un keysym pour une touche qui, lorsqu'elle est enfoncée par l'utilisateur avec le modificateur MAlt, affiche le panneau de menu déroulant associé. Le premier caractère de la chaîne de libellé de l'OptionMenu qui correspond exactement au mnemonic dans l'ensemble de caractères spécifié dans XmNmnemonicCharSet est souligné. L'utilisateur peut afficher le menu en appuyant sur la touche mnemonic, qu'elle soit majuscule ou non. La valeur par défaut est aucun mnemonic.
XmNmnemonicCharSet
Spécifie l'ensemble de caractères du mnemonic pour une OptionMenu. La valeur par défaut est XmFONTLIST_DEFAULT_TAG. Si le widget RowColumn est d'un type autre que XmMENU_OPTION, cette ressource n'est pas significative.
XmNnumColumns
Spécifie le nombre d'extensions de dimension mineure qui sont effectuées pour accueillir les entrées ; cet attribut n'est significatif que lorsque XmNpacking est défini sur XmPACK_COLUMN.
Pour les widgets RowColumn orientés verticalement, cet attribut indique le nombre de colonnes construites ; le nombre d'éléments par colonne est ajusté pour maintenir ce nombre de colonnes, si possible.
Pour les widgets RowColumn orientés horizontalement, cet attribut indique le nombre de lignes construites.
La valeur par défaut est 1. Dans une OptionMenu, la valeur est forcée à 1. La valeur doit être supérieure à 0 (zéro).
XmNorientation
Détermine si les dispositions de RowColumn sont en ordre de lignes ou en ordre de colonnes. Dans une disposition en ordre de colonnes, les enfants du RowColumn sont disposés en columns dans le widget. Dans une disposition par ordre de lignes (row-major), les enfants de RowColumn sont disposés en lignes. La direction de la disposition horizontale dans la disposition par ordre de lignes (de gauche à droite) et le retour à la ligne dans la disposition par ordre de colonnes (vertical) dépendent de la ressource XmNlayoutDirection du widget. La valeur de ressource XmVERTICAL sélectionne une disposition par ordre de colonnes. XmHORIZONTAL sélectionne une disposition par ordre de lignes.
Lors de la création d'un MenuBar ou d'un OptionMenu, la valeur par défaut est XmHORIZONTAL. Sinon, la valeur par défaut est XmVERTICAL. Les résultats de la spécification de la valeur XmVERTICAL pour un MenuBar sont indéfinis.
XmNpacking
Spécifie comment empaqueter les éléments contenus dans un widget RowColumn. Cela peut être défini sur XmPACK_TIGHT, XmPACK_COLUMN ou XmPACK_NONE. Lorsqu'un widget RowColumn empaquette les éléments qu'il contient, il détermine sa dimension principale en utilisant la valeur de la ressource XmNorientation.
XmPACK_TIGHT indique que, compte tenu de la dimension principale actuelle (par exemple, verticale si XmNorientation est XmVERTICAL), les entrées sont placées les unes après les autres jusqu'à ce que le widget RowColumn doive passer à la ligne. RowColumn passe à la ligne lorsqu'il n'y a plus de place pour un enfant complet dans cette dimension. Le passage à la ligne se fait en commençant une nouvelle ligne ou une nouvelle colonne dans le prochain espace disponible. Le passage à la ligne se poursuit, aussi souvent que nécessaire, jusqu'à ce que tous les enfants soient disposés. Dans la dimension verticale (colonnes), les boîtes sont définies avec la même largeur ; dans la dimension horizontale (lignes), les boîtes sont définies avec la même hauteur. La position de chaque entrée dans la dimension principale est laissée inchangée (par exemple, XmNy reste inchangé lorsque XmNorientation est XmVERTICAL) ; sa position dans la dimension secondaire est définie avec la même valeur que l'élément le plus grand dans cette ligne ou colonne particulière. La position dans la dimension secondaire de toute ligne ou colonne particulière est indépendante de toutes les autres lignes ou colonnes.
XmPACK_COLUMN indique que toutes les entrées sont placées dans des boîtes de taille identique. Les boîtes sont basées sur les valeurs de hauteur et de largeur les plus grandes de tous les widgets enfants. La valeur de la ressource XmNnumColumns détermine le nombre de boîtes placées dans la dimension principale, avant de s'étendre dans la dimension secondaire.
XmPACK_NONE indique qu'aucun empaquetage n'est effectué. Les attributs x et y de chaque entrée sont laissés tels quels, et le widget RowColumn tente de devenir suffisamment grand pour englober toutes les entrées.
Lorsque XmCreateRadioBox est appelé ou lorsque XmNrowColumnType est défini sur XmWORK_AREA et XmNradioBehavior est True, la valeur par défaut de XmNpacking est XmPACK_COLUMN. Dans un OptionMenu, la valeur est initialisée à XmPACK_TIGHT. Sinon, la valeur par défaut est XmPACK_TIGHT.
XmNpopupEnabled
Permet au système de menu d'activer l'entrée clavier (accélérateurs et mnémoniques) définie pour le panneau de menu Popup et tous ses sous-menus. Le panneau de menu Popup doit être informé à chaque fois que son accessibilité pour l'utilisateur change, car le post du panneau de menu Popup est contrôlé par l'application. Cette ressource peut prendre quatre valeurs, dont :
XmPOPUP_KEYBOARD
Spécifie que l'entrée clavier — accélérateurs et mnémoniques — définie pour le panneau de menu Popup et tous ses sous-menus est activée. C'est la valeur par défaut.
XmPOPUP_DISABLED
Spécifie que l'entrée clavier est désactivée.
XmPOPUP_AUTOMATIC
Spécifie que le clavier est activé pour les menus popup automatiques.
XmPOPUP_AUTOMATIC_RECURSIVE
Spécifie que le clavier est activé pour les menus popup automatiques récursifs.
XmNradioAlwaysOne
Si True, force le ToggleButton ou ToggleButtonGadget actif à être automatiquement sélectionné après avoir été désélectionné (si aucun autre bouton n'a été activé). Si False, le bouton actif peut être désélectionné. La valeur par défaut est True. Cette ressource n'est importante que lorsque XmNradioBehavior est True.
L'application peut toujours ajouter et supprimer des boutons bascule de RowColumn indépendamment de l'état sélectionné/désélectionné du bouton bascule. L'application peut également gérer et désinstaller des enfants bascules de RowColumn à tout moment, quel que soit leur état. Par conséquent, l'application peut parfois créer un RowColumn dont la valeur de XmNradioAlwaysOne est True et aucun des enfants bascules n'est sélectionné. Le résultat est indéfini si la valeur de cette ressource est True et que l'application définit plus d'un ToggleButton à la fois.
XmNradioBehavior
Spécifie une valeur booléenne qui, lorsqu'elle est True, indique que le widget RowColumn doit appliquer un comportement de type RadioBox à tous ses enfants qui sont des ToggleButtons ou des ToggleButtonGadgets.
Lorsque la valeur de cette ressource est True, XmNindicatorType prend par défaut la valeur XmONE_OF_MANY pour les enfants ToggleButton et ToggleButtonGadget.
Le comportement RadioBox dicte que lorsqu'un bouton est sélectionné et que l'utilisateur sélectionne un autre bouton, le premier bouton est automatiquement désélectionné. Le RowColumn n'applique généralement pas ce comportement si l'application, plutôt que l'utilisateur, modifie l'état d'un bouton. Le RowColumn applique ce comportement si un enfant bascule est sélectionné avec XmToggleButtonSetState ou XmToggleButtonGadgetSetState avec un argument notify de True.
Lorsque XmCreateRadioBox est appelé, la valeur par défaut de XmNradioBehavior est True. Sinon, la valeur par défaut est False.
XmNresizeHeight
Demande une nouvelle hauteur si nécessaire, lorsqu'elle est définie sur True. Lorsque cette ressource est définie sur False, le widget ne demande pas de nouvelle hauteur, quelles que soient les modifications apportées au widget ou à ses enfants.
XmNresizeWidth
Demande une nouvelle largeur si nécessaire, lorsqu'elle est définie sur True. Lorsqu'elle est définie sur False, le widget ne demande pas de nouvelle largeur, quelles que soient les modifications apportées au widget ou à ses enfants.

Informations sur les rappels

Un pointeur vers la structure suivante est passé à chaque rappel :

typedef struct
{
        int reason;
        XEvent * event;
        Widget widget;
        char * data;
        char * callbackstruct;
} XmRowColumnCallbackStruct;
reason
Indique pourquoi le rappel a été invoqué.
event
Pointe vers le XEvent qui a déclenché le rappel.

Les champs suivants s'appliquent uniquement lorsque la raison du rappel est XmCR_ACTIVATE ; pour toutes les autres raisons de rappel, ces champs sont définis sur NULL. La raison de rappel XmCR_ACTIVATE n'est générée que lorsque l'application a fourni un rappel d'entrée, qui remplace tous les rappels d'activation enregistrés auprès des éléments individuels RowColumn.

widget
Est défini sur l'ID du widget de l'élément RowColumn qui a été activé.
data
Contient la valeur de données client fournie par l'application lors de l'enregistrement du rappel d'activation de l'élément RowColumn.
callbackstruct
Pointe vers la structure de rappel générée par le rappel d'activation de l'élément RowColumn.

MenuBtnDown():
Lorsqu'un gadget enfant du menu a le focus, invoque le comportement du gadget enfant associé à <Btn1Down>. Cela a généralement pour effet de retirer de la pile tout menu affiché par le menu parent, d'activer le parcours de la souris dans le menu et d'armer le gadget. Pour un CascadeButtonGadget avec un sous-menu, il affiche également le sous-menu associé.
MenuBtnUp():
Lorsqu'un gadget enfant du menu a le focus, invoque le comportement du gadget enfant associé à <Btn1Up>. Cela a généralement pour effet de retirer de la pile le menu hiérarchique et d'activer le gadget, sauf que pour un CascadeButtonGadget avec un sous-menu, il affiche le sous-menu et active le parcours au clavier dans le menu.
MenuGadgetEscape():
Dans un MenuPane Pulldown de niveau supérieur d'une MenuBar, retire le menu de la pile, désarme le CascadeButton de la MenuBar et la MenuBar, et, lorsque la politique de focus clavier du shell est XmEXPLICIT, restaure le focus clavier sur le widget qui avait le focus avant l'entrée dans la MenuBar. Dans d'autres MenuPanes Pulldown, retire le menu de la pile.
Dans un MenuPane Popup, retire le menu de la pile et, lorsque la politique de focus clavier du shell est XmEXPLICIT, restaure le focus clavier sur le widget à partir duquel le menu a été affiché. Dans un MenuPane TearOff qui n'a pas de sous-menus affichés, ferme le menu ; sinon, si un ou plusieurs sous-menus sont affichés, retire le dernier panneau de menu de la pile.
MenuGadgetTraverseDown():
Si l'élément de menu actuel a un sous-menu et se trouve dans une MenuBar, cette action affiche le sous-menu, désarme l'élément de menu actuel et arme le premier élément de menu accessible du sous-menu.
Si l'élément de menu actuel se trouve dans un MenuPane, cette action désarme l'élément de menu actuel et arme l'élément situé en dessous. Cette action boucle dans le MenuPane. La direction de la boucle dépend de la ressource XmNlayoutDirection.

Comportement apparenté

Les fonctions de menu suivantes sont disponibles :

<osfMenuBar>:
Dans tout descendant non contextuel du parent d'une barre de menu (MenuBar), à l'exception de la barre de menu elle-même, cette action active la traversée au clavier et déplace le focus clavier vers le premier élément de la barre de menu. Dans la barre de menu ou tout menu qui en est issu en cascade, cette action dépublie la hiérarchie des menus et, lorsque la politique de focus clavier de la fenêtre (shell) est XmEXPLICIT, restaure le focus vers le widget qui avait le focus lorsque le système de menu a été entré.
<osfMenu>:
Affiche le menu associé au contrôle qui a le focus clavier. Active la traversée au clavier dans le menu. Dans le système de menu contextuel (Popup) ou tout menu qui en est issu en cascade, cette action dépublie la hiérarchie des menus et, lorsque la politique de focus clavier de la fenêtre (shell) est XmEXPLICIT, restaure le focus vers le widget qui avait le focus lorsque le système de menu a été entré.
