NOM

XmTextGetSource — Appel de fonction Text accédant à la source du widget

SYNTAXE

#include <Xm/Text.h>
XmTextSource XmTextGetSource(
Widget widget);

DESCRIPTION

XmTextGetSource accède à la source du widget Text. Les widgets Text peuvent partager des sources de texte, de sorte que les modifications apportées dans un widget se reflètent dans un autre. Cette fonction accède à la source d'un widget afin qu'elle puisse être définie comme source d'un autre widget, en utilisant la fonction XmTextSetSource(3).

La définition d'une nouvelle source de texte détruit l'ancienne source de texte si aucun autre widget Text n'utilise cette source. Pour remplacer une source de texte tout en la conservant pour une utilisation ultérieure, créez un widget Text non géré et définissez sa source sur la source de texte que vous souhaitez conserver.

widget
Spécifie l'ID du widget Text

Pour une définition complète de Text et de ses ressources associées, voir XmText(3).

VALEUR DE RETOUR

Retourne une valeur de type XmTextSource qui représente la source du widget Text.
