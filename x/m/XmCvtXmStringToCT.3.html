NOM

XmCvtXmStringToCT — Une fonction de chaîne composite qui convertit une chaîne composite en texte composite

SYNOPSIS

#include <Xm/Xm.h>
char * XmCvtXmStringToCT(
XmString string);

DESCRIPTION

XmCvtXmStringToCT convertit une chaîne composite en une chaîne (char *) au format texte composite. L'application doit appeler XtAppInitialize avant d'appeler cette fonction. Le convertisseur utilise la balise de liste de polices associée à un segment de chaîne composite donné pour sélectionner un format de texte composite pour ce segment. Un registre définit un mappage entre les balises de liste de polices et les formats d'encodage de texte composite. Le convertisseur utilise l'algorithme suivant pour chaque segment de chaîne composite :

1.
Si la balise du segment de chaîne composite est mappée à XmFONTLIST_DEFAULT_TAG dans le registre, le convertisseur passe le texte du segment de chaîne composite à XmbTextListToTextProperty avec un style d'encodage de XCompoundTextStyle et utilise le texte composite résultant pour ce segment.
2.
Si la balise du segment de chaîne composite est mappée à un jeu de caractères MIT enregistré dans le registre, le convertisseur crée le texte composite pour ce segment en utilisant le jeu de caractères (du registre) et le texte du segment de chaîne composite tel que défini dans la norme X Consortium Compound Text Encoding.
3.
Si la balise du segment de chaîne composite est mappée à un jeu de caractères dans le registre qui n'est ni XmFONTLIST_DEFAULT_TAG ni un jeu de caractères MIT enregistré, le convertisseur crée le texte composite pour ce segment en utilisant le jeu de caractères (du registre) et le texte du segment de chaîne composite comme un segment "étendu" avec un nombre variable d'octets par caractère.
4.
Si la balise du segment de chaîne composite n'est pas mappée dans le registre, le résultat dépend de l'implémentation.
string
Spécifie une chaîne composite à convertir en texte composite.

RETOUR

Renvoie une chaîne (char *) au format texte composite. Ce format est décrit dans la norme X Consortium Compound Text Encoding. La fonction alloue de l'espace pour contenir la chaîne renvoyée. L'application est responsable de la gestion de l'espace alloué. L'application peut récupérer l'espace alloué en appelant XtFree.

VOIR AUSSI

XmCvtCTToXmString(3), XmFontList(3), XmMapSegmentEncoding(3), XmRegisterSegmentEncoding(3), et XmString.
