NOM

XmRedisplayWidget — Active de manière synchrone la méthode expose d'un widget pour dessiner son contenu

SYNTAXE

#include <Xm/Xm.h>
voidXmRedisplayWidget(
Widgetwidget);

DESCRIPTION

Cette fonction est une routine pratique qui cache les détails internes de Xt au programmeur d'application en appelant la méthode expose du widget donné avec un événement Expose bien formé et une Region correspondant à la zone totale du widget. Si le widget n'a pas de méthode Expose, la fonction ne fait rien.

Ceci est principalement utilisé dans le contexte de l'impression X si le modèle de programmation choisi par l'application est *synchrone* ; c'est-à-dire qu'il ne repose pas sur les événements X Print pour la mise en page, mais souhaite contrôler entièrement la séquence des requêtes de rendu.

XmRedisplayWidget ne nettoie pas la fenêtre du widget avant d'appeler la méthode expose, car cela est géré par les appels à XpStartPage.

widget
Le widget à réafficher.

VALEUR DE RETOUR

Aucune.

ERREURS/AVERTISSEMENTS

Non applicable

EXEMPLES

Dans ce qui suit, une application simple veut imprimer le contenu d'un widget texte multipage (similaire à dtpad).

PrintOKCallback(print_dialog...)
/*-------------*/
{
    pshell = XmPrintSetup (print_dialog, pbs->print_screen,
                                   "Print", NULL, 0);
    XpStartJob(XtDisplay(pshell), XPSpool);
    /**** ici je réalise le shell, j'obtiens sa taille, je crée mon widget
     hiérarchie: un bulletin board, puis un widget texte,
     que je remplis avec le buffer du widget texte vidéo */
    /* obtenir le nombre total de pages à imprimer */
    XtVaGetValues(ptext, XmNrows, &prows,
                         XmNtotalLines, n_lines, NULL);
    n_pages = n_lines / prows;
    /***** maintenant imprimer les pages dans une boucle */
    for (cur_page=0; cur_page != n_pages; cur_page++) {
               XpStartPage(XtDisplay(pshell), XtWindow(pshell), False);
               XmRedisplayWidget(ptext);  /* faire le dessin */
               XpEndPage(XtDisplay(pshell));
        XmTextScroll(ptext, prows);  /* se préparer pour la page suivante */
    }
    /***** j'ai terminé */
    XpEndJob(XtDisplay(pshell));
}

Bien sûr, on pourrait modifier le code ci-dessus pour l'inclure dans une branche fork() afin que le programme principal ne soit pas bloqué pendant l'impression. Une autre façon d'obtenir un effet d'impression en arrière-plan est d'utiliser un proc de travail Xt. En utilisant la même application exemple, cela nous donne :

Boolean
PrintOnePageWP(XtPointer npages) /* proc de travail */
/*-------------*/
{
    static int cur_page = 0;
    cur_page++;
    XpStartPage(XtDisplay(pshell), XtWindow(pshell), False);
    XmRedisplayWidget(ptext);  /* faire le dessin */
    XpEndPage(XtDisplay(pshell));
    XmTextScroll(ptext, prows);  /* se préparer pour la page suivante */
    if (cur_page == n_pages) { /***** j'ai terminé */
        XpEndJob(XtDisplay(pshell));
        XtDestroyWidget(pshell);
        XtCloseDisplay(XtDisplay(pshell));
    }
    return (cur_page == n_pages);
}
PrintOKCallback(...)
/*-------------*/
{
    pshell = XmPrintSetup (widget, pbs->print_screen,
                                   "Print", NULL, 0);
    XpStartJob(XtDisplay(pshell), XPSpool);
    /**** ici j'obtiens la taille du shell, je crée mon widget
          hiérarchie: un bulletin board, puis un widget texte,
                  que je remplis avec le buffer du widget texte vidéo */
    /* obtenir le nombre total de pages à imprimer */
    /* ... même code que l'exemple ci-dessus */
    /***** imprimer les pages en arrière-plan */
    XtAppAddWorkProc(app_context, PrintOnePageWP, n_pages);
}
