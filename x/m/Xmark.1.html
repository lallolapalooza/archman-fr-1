NOM

Xmark - résumer les résultats de x11perf

SYNTAXE

Xmark fichierdata

DESCRIPTION

Xmark est un script shell qui lit le fichierdata indiqué et compile un benchmark qu'il écrit sur la sortie standard. Il écrit trois chiffres :

Un chiffre de performance pondéré pour les résultats x11perf.

Un chiffre de performance pondéré pour une SparcStation 1 standard, avec SunOS 4.1.2, X11R5 Xsun, et une carte graphique couleur CG3 basique.

Le Xmark, qui est le rapport des deux chiffres ci-dessus.

Le fichierdata doit être un fichier ordinaire, produit par x11perf de la manière suivante :

x11perf -display affichage -v1.3 -rop GXcopy GXxor -all > fichierdata

Il est possible d'exécuter les tests GXcopy et GXxor séparément, tant qu'ils sont concaténés dans le même fichier de sortie :

x11perf -display affichage -v1.3 -rop GXcopy -all > fichierdata
x11perf -display affichage -v1.3 -rop GXxor -all >> fichierdata
ou 
x11perf -display affichage -v1.3 -rop GXxor -all > fichierdata
x11perf -display affichage -v1.3 -rop GXcopy -all >> fichierdata

FICHIERS

temp.$$
Fichier temporaire créé dans le répertoire courant, supprimé après utilisation.

DIAGNOSTICS

Usage : Xmark fichierdata
Xmark a été invoqué sans arguments ou avec plus d'un argument, ou avec des options. Xmark n'accepte aucune option.
Erreur : le fichier data n'existe pas ou n'est pas un fichier ordinaire.
Xmark ne trouve pas le fichierdata nommé dans sa ligne de commande, ou le fichierdata est un fichier spécial tel qu'un répertoire.
AVERTISSEMENT : le fichierdata contient nnn, pas 441 ou 447 résultats 'trep' ;
Le fichier nommé dans la ligne de commande ne semble pas être un fichier généré par x11perf de la manière attendue.
Diagnostic : ERREUR : somme des poids =nnn, pas égale à 4566,0 ;
Il y a une erreur interne dans Xmark.

VOIR AUSSI
