XmbSetWMProperties(3)

Paquet: libx11

Licences: MIT AND X11

XSetWMProperties(3) FONCTIONS XLIB XSetWMProperties(3)

NOM

XSetWMProperties, XmbSetWMProperties, Xutf8SetWMProperties - définir les propriétés standard de la fenêtre

SYNTAXE

void XSetWMProperties(Display *display, Window w, XTextProperty *window_name, XTextProperty *icon_name, char **argv, int argc, XSizeHints *normal_hints, XWMHints *wm_hints, XClassHint *class_hints);

void XmbSetWMProperties(Display *display, Window w, _Xconst char *window_name, _Xconst char *icon_name, char *argv[], int argc, XSizeHints *normal_hints, XWMHints *wm_hints, XClassHint *class_hints);

void Xutf8SetWMProperties(Display *display, Window w, _Xconst char *window_name, _Xconst char *icon_name, char *argv[], int argc, XSizeHints *normal_hints, XWMHints *wm_hints, XClassHint *class_hints);

ARGUMENTS

argc
Spécifie le nombre d'arguments.
argv
Spécifie la liste d'arguments de l'application.
class_hints
Spécifie la structure XClassHint à utiliser.
display
Spécifie la connexion au serveur X.
icon_name
Spécifie le nom de l'icône, qui doit être une chaîne terminée par un nul.
normal_hints
Spécifie les indications de taille pour la fenêtre dans son état normal.
w
Spécifie la fenêtre.
window_name
Spécifie le nom de la fenêtre, qui doit être une chaîne terminée par un nul.
wm_hints
Spécifie la structure XWMHints à utiliser.

DESCRIPTION

La fonction utilitaire XSetWMProperties fournit une interface de programmation unique pour définir ces propriétés essentielles de la fenêtre qui sont utilisées pour communiquer avec d'autres clients (en particulier les gestionnaires de fenêtres et de sessions).

Si l'argument window_name n'est pas NULL, XSetWMProperties appelle XSetWMName, qui à son tour définit la propriété WM_NAME (voir la section 14.1.4). Si l'argument icon_name n'est pas NULL, XSetWMProperties appelle XSetWMIconName, qui définit la propriété WM_ICON_NAME (voir la section 14.1.5). Si l'argument argv n'est pas NULL, XSetWMProperties appelle XSetCommand, qui définit la propriété WM_COMMAND (voir la section 14.2.1). Notez qu'un argc de zéro est autorisé pour indiquer une commande de longueur nulle. Notez également que le nom d'hôte de cette machine est stocké en utilisant XSetWMClientMachine (voir la section 14.2.2).

Si l'argument normal_hints n'est pas NULL, XSetWMProperties appelle XSetWMNormalHints, qui définit la propriété WM_NORMAL_HINTS (voir la section 14.1.7). Si l'argument wm_hints n'est pas NULL, XSetWMProperties appelle XSetWMHints, qui définit la propriété WM_HINTS (voir la section 14.1.6).

Si l'argument class_hints n'est pas NULL, XSetWMProperties appelle XSetClassHint, qui définit la propriété WM_CLASS (voir la section 14.1.8). Si le membre res_name dans la structure XClassHint est défini sur le pointeur NULL et que la variable d'environnement RESOURCE_NAME est définie, alors la valeur de la variable d'environnement est substituée à res_name. Si le membre res_name est NULL, la variable d'environnement n'est pas définie, et argv et argv[0] sont définis, alors la valeur de argv[0], débarrassée de tout préfixe de répertoire, est substituée à res_name.

Les fonctions utilitaires XmbSetWMProperties et Xutf8SetWMProperties fournissent une interface de programmation simple pour définir ces propriétés essentielles de la fenêtre qui sont utilisées pour communiquer avec d'autres clients (en particulier les gestionnaires de fenêtres et de sessions).

Si l'argument window_name n'est pas NULL, elles définissent la propriété WM_NAME. Si l'argument icon_name n'est pas NULL, elles définissent la propriété WM_ICON_NAME. Les arguments window_name et icon_name sont des chaînes terminées par un nul, pour XmbSetWMProperties dans le codage de la locale actuelle, pour Xutf8SetWMProperties en codage UTF-8. Si les arguments peuvent être entièrement convertis en codage STRING, les propriétés sont créées avec le type “STRING”; sinon, les arguments sont convertis en texte composite (Compound Text), et les propriétés sont créées avec le type “COMPOUND_TEXT”.

Si l'argument normal_hints n'est pas NULL, XmbSetWMProperties et Xutf8SetWMProperties appellent XSetWMNormalHints, qui définit la propriété WM_NORMAL_HINTS (voir la section 14.1.7). Si l'argument wm_hints n'est pas NULL, XmbSetWMProperties et Xutf8SetWMProperties appellent XSetWMHints, qui définit la propriété WM_HINTS (voir la section 14.1.6).

Si l'argument argv n'est pas NULL, XmbSetWMProperties et Xutf8SetWMProperties définissent la propriété WM_COMMAND à partir de argv et argc. Un argc de zéro indique une commande de longueur nulle.

Le nom d'hôte de la machine est stocké en utilisant XSetWMClientMachine (voir la section 14.2.2).

Si l'argument class_hints n'est pas NULL, XmbSetWMProperties et Xutf8SetWMProperties définissent la propriété WM_CLASS. Si le membre res_name dans la structure XClassHint est défini sur le pointeur NULL et que la variable d'environnement RESOURCE_NAME est définie, la valeur de la variable d'environnement est substituée à res_name. Si le membre res_name est NULL, la variable d'environnement n'est pas définie, et argv et argv[0] sont définis, alors la valeur de argv[0], débarrassée de tout préfixe de répertoire, est substituée à res_name.

Il est supposé que class_hints.res_name et argv, la variable d'environnement RESOURCE_NAME, et le nom d'hôte de la machine sont dans le codage de la locale actuelle. Les propriétés WM_CLASS, WM_COMMAND et WM_CLIENT_MACHINE correspondantes sont typées selon l'annonceur de locale de l'hôte local. Aucune conversion de codage n'est effectuée pour ces chaînes avant leur stockage dans les propriétés.

Pour les clients qui ont besoin de traiter le texte de la propriété dans une locale, XmbSetWMProperties et Xutf8SetWMProperties définissent la propriété WM_LOCALE_NAME pour qu'elle soit le nom de la locale actuelle. Le nom est supposé être dans le codage de caractères portable de l'hôte (Host Portable Character Encoding) et est converti en STRING pour être stocké dans la propriété.

XSetWMProperties, XmbSetWMProperties et Xutf8SetWMProperties peuvent générer des erreurs BadAlloc et BadWindow.

La fonction Xutf8SetWMProperties est une extension introduite par The XFree86 Project, Inc., dans sa version 4.0.2. Sa présence est indiquée par le macro X_HAVE_UTF8_STRING.

PROPRIÉTÉS

WM_CLASS
Définit par les programmes d'application pour permettre aux gestionnaires de fenêtres et de sessions d'obtenir les ressources de l'application à partir de la base de données des ressources.
WM_CLIENT_MACHINE
Le nom de chaîne de la machine sur laquelle l'application cliente s'exécute.
WM_COMMAND
La commande et les arguments, séparés par des nuls, utilisés pour invoquer l'application.
WM_HINTS
Indications supplémentaires définies par le client pour l'utilisation par le gestionnaire de fenêtres. Le type C de cette propriété est XWMHints.
WM_ICON_NAME
Le nom à utiliser dans une icône.
WM_NAME
Le nom de l'application.
WM_NORMAL_HINTS
Indications de taille pour une fenêtre dans son état normal. Le type C de cette propriété est XSizeHints.

DIAGNOSTICS

BadAlloc
Le serveur n'a pas réussi à allouer la ressource demandée ou la mémoire du serveur.
BadWindow
Une valeur pour un argument de type Window ne nomme pas une fenêtre définie.
