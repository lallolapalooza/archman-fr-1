NOM

XML::XPath::PerlSAX - Un générateur d'événements PerlSAX pour ma structure de nœuds étrange

SYNTAXE

use XML::XPath;
use XML::XPath::PerlSAX;
use XML::DOM::PerlSAX;
my $xp = XML::XPath->new(filename => 'test.xhtml');
my $paras = $xp->find('/html/body/p');
my $handler = XML::DOM::PerlSAX->new();
my $generator = XML::XPath::PerlSAX->new( Handler => $handler );
foreach my $node ($paras->get_nodelist) {
        my $domtree = $generator->parse($node);
        # faire quelque chose avec $domtree
}

DESCRIPTION

Ce module génère des événements PerlSAX à passer à un gestionnaire PerlSAX tel que XML::DOM::PerlSAX. Il fonctionne spécifiquement sur mon format d'arbre étrange.

Malheureusement, SAX ne semble pas gérer les espaces de noms, donc ceux-ci sont complètement perdus. Je crois que SAX2 gère les espaces de noms.

AUTRE

Le gestionnaire XML::DOM::PerlSAX que j'ai essayé était complètement défectueux (il ne compilait même pas avant que je le corrige un peu), donc je ne sais pas à quel point ceci est correct ni jusqu'où cela fonctionnera.
