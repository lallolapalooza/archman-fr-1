NOM

XML::PatAct::ACTION - Un module d'action pour

SYNTAXE

use XML::PatAct::ACTION;
my $patterns = [ PATTERN => ACTION,
                 ... ];
my $matcher = XML::PatAct::ACTION->new(Patterns => $patterns,
                                       Matcher => $matcher );

DESCRIPTION

XML::PatAct::ACTION est un gestionnaire PerlSAX pour appliquer des listes de modèles-actions à des analyseurs ou des arbres XML. XML::PatAct::ACTION ...

De nouvelles instances de XML::PatAct::ACTION sont créées en appelant `new()'. Les paramètres peuvent être passés sous forme de liste de paires clé, valeur ou d'une table de hachage. Les options Patterns et Matcher sont requises. Patterns est la liste de modèles-actions à appliquer. Matcher est une instance du module de correspondance de modèles ou de requête.
