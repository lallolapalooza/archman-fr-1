NOM

XmListSetAddMode — Appel de fonction de liste qui définit le mode d'ajout dans la liste

SYNTAXE

#include <Xm/List.h>
void XmListSetAddMode(
Widget widget,
Boolean state);

DESCRIPTION

XmListSetAddMode permet aux applications de contrôler le mode d'ajout dans le modèle de sélection étendue. Cette fonction garantit que le mode qu'elle définit est compatible avec la politique de sélection (XmNselectionPolicy) du widget. Par exemple, elle ne peut pas mettre le widget en mode d'ajout lorsque la valeur de XmNselectionPolicy est XmBROWSE_SELECT.

widget
Spécifie l'ID du widget List
state
Spécifie si le mode d'ajout doit être activé ou désactivé. Si state est True, le mode d'ajout est activé. Si state est False, le mode d'ajout est désactivé.

Pour une définition complète de la liste et de ses ressources associées, voir XmList(3).
