NOM

XmParseMapping — Type de données pour un mappage d'analyse de chaîne composite

SYNTAXE

#include <Xm/Xm.h>

DESCRIPTION

XmParseMapping est un type de données opaque pour un mappage d'analyse utilisé par XmStringParseText pour créer une chaîne composite. Un mappage d'analyse contient un motif à rechercher dans le texte en cours d'analyse pour créer une chaîne composite. Il contient également une chaîne composite, ou une fonction à appeler pour fournir une chaîne composite, à inclure dans la chaîne composite en cours de création chaque fois que le motif est trouvé.

Une application utilise une interface de type ressource pour spécifier les composants d'un XmParseMapping. XmParseMappingCreate crée un mappage d'analyse, en utilisant une liste d'arguments de style ressource. XmParseMappingGetValues et XmParseMappingSetValues récupèrent et définissent les composants d'un mappage d'analyse. XmParseMappingFree récupère la mémoire utilisée par un mappage d'analyse. XmParseTable est un tableau d'objets XmParseMapping.

La ressource XmNinvokeParseProc est une fonction de type XmParseProc, qui est définie comme suit :

XmIncludeStatus (*XmParseProc) (text_in_out, text_end, type, tag, entry, pattern_length,
str_include, call_data)
        XtPointer *text_in_out;
        XtPointer text_end;
        XmTextType type;
        XmStringTag tag;
        XmParseMapping entry;
        int pattern_length;
        XmString *str_include;
        XtPointer call_data;

Une procédure d'analyse fournit un mécanisme d'échappement pour des analyses arbitrairement complexes. Cette procédure est appelée lorsqu'un motif dans le texte d'entrée correspond à un motif dans un mappage d'analyse dont XmNincludeStatus est XmINVOKE.

Le texte d'entrée est un pointeur vers le premier octet du motif qui a déclenché l'appel à la procédure d'analyse. La procédure d'analyse consomme autant d'octets de la chaîne d'entrée qu'elle en a besoin et définit le pointeur de texte d'entrée sur l'octet suivant. Elle retourne une chaîne composite à inclure dans la chaîne composite en cours de création, et elle retourne également un XmIncludeStatus indiquant comment la chaîne composite retournée doit être traitée. Si la procédure d'analyse ne fait pas avancer le pointeur de texte d'entrée d'au moins un octet, la routine d'analyse continue d'essayer de faire correspondre le texte d'entrée avec les motifs des mappages d'analyse restants dans la table d'analyse. Sinon, la routine d'analyse recommence avec le nouveau pointeur de texte d'entrée et essaie de faire correspondre le texte d'entrée avec les motifs des mappages d'analyse à partir du début de la table d'analyse.

text_in_out
Spécifie le texte en cours d'analyse. La valeur est un pointeur vers le premier octet de texte correspondant au motif qui a déclenché l'appel à la procédure d'analyse. Lorsque la procédure d'analyse retourne, cet argument est défini sur la position dans le texte où l'analyse doit reprendre, c'est-à-dire l'octet suivant le dernier caractère analysé par la procédure d'analyse.
text_end
Spécifie un pointeur vers la fin de la chaîne text_in_out. Si text_end est NULL, la chaîne est parcourue jusqu'à ce qu'un caractère NULL soit trouvé. Sinon, la chaîne est parcourue jusqu'au caractère dont l'adresse est text_end, mais sans l'inclure.
type
Spécifie le type de texte et le type de balise. Si une balise de locale doit être créée, type a une valeur de XmMULTIBYTE_TEXT ou XmWIDECHAR_TEXT. Si un jeu de caractères doit être créé, type a la valeur XmCHARSET_TEXT.
tag
Spécifie la balise à utiliser lors de la création du résultat. Le type de balise de chaîne créé (jeu de caractères ou locale) dépend du type de texte et de la valeur de tag transmise. Si la valeur de tag est NULL et si type indique qu'une balise de chaîne de jeu de caractères doit être créée, la balise de chaîne a la valeur qui est le résultat du mappage de XmSTRING_DEFAULT_CHARSET. Si type indique une balise de chaîne de locale, la balise de chaîne a la valeur _MOTIF_DEFAULT_LOCALE.
entry
Spécifie le mappage d'analyse qui a déclenché l'appel à la procédure d'analyse.
pattern_length
Spécifie le nombre d'octets dans le texte d'entrée, après text_in_out, qui constituent le motif trouvé.
str_include
Spécifie un pointeur vers une chaîne composite. La procédure d'analyse crée une chaîne composite à inclure dans la chaîne composite en cours de création. La procédure d'analyse retourne ensuite la chaîne composite dans cet argument.
call_data
Spécifie les données transmises par l'application à la routine d'analyse.

La procédure d'analyse retourne un XmIncludeStatus indiquant comment str_include doit être inclus dans la chaîne composite en cours de construction. Les valeurs possibles sont les suivantes :

XmINSERT
Concaténer le résultat à la chaîne composite en cours de construction et continuer l'analyse.
XmTERMINATE
Concaténer le résultat à la chaîne composite en cours de construction et terminer l'analyse.

DESCRIPTION

A parse mapping is a collection of rules that define how to interpret and transform a string. The XmParseTable structure specifies the mapping rules. Each rule consists of a pattern, an action, and associated data.

The XmParseMappingCreate function creates a new parse mapping and initializes it with the rules from the specified XmParseTable. The parse_table argument is a pointer to an XmParseTable structure that contains the mapping rules. The pattern argument is an XmString that specifies the pattern to be matched in the text being parsed. The mapping_ptr argument is a pointer to a variable that will receive the newly created parse mapping.

The XmParseMappingFree function frees a parse mapping and all associated resources.

The XmParseMappingGetValues function retrieves the XmParseTable associated with a parse mapping.

The XmParseMappingSetValues function updates the XmParseTable associated with a parse mapping.

The XmParseMappingOptions function returns the options associated with a parse mapping.

The following functions add or remove specific rules from a parse mapping:

XmNfilter
Specifies a filter procedure to be called before parsing. The filter procedure can modify the text being parsed or perform other actions.
XmNactions
Specifies an action procedure to be called when a pattern is matched. The action procedure can perform custom actions based on the matched pattern.
XmNcharset
Specifies a character set procedure to be called when a character set is encountered in the text being parsed. The character set procedure can be used to map characters to different character sets.
XmNsubstitute
Specifies a substitute string to be used when a pattern is matched. The substitute string replaces the matched pattern in the resulting compound string.
XmNincludeStatus
Specifies how the result of a mapping is to be included in the compound string being constructed. Possible values include:
XmINSERT
Concatenate the result to the compound string being constructed and continue parsing.
XmINVOKE
Invoke the XmNinvokeParseProc on the text being parsed and use the returned compound string instead of XmNsubstitute as the result to be inserted into the compound string being constructed. The include status returned by the parse procedure (XmINSERT or XmTERMINATE) determines how the returned compound string is included.
XmTERMINATE
Concatenate the result to the compound string being constructed and terminate parsing.
XmNpattern
Specifies a pattern to be matched in the text being parsed. This is a maximum of one character.
XmNpatternType
Specifies the type of the pattern that is the value of XmNpattern. Following are the possible values:
•
XmCHARSET_TEXT
•
XmMULTIBYTE_TEXT
•
XmWIDECHAR_TEXT
XmNclientData
Specifies data to be used by the parse procedure.

XmINSERT
