NOM

XmCreateTemplateDialog — Fonction de création pratique pour une boîte de dialogue modèle MessageBox

SYNTAXE

#include <Xm/MessageB.h>
Widget XmCreateTemplateDialog(
Widget parent,
String name,
ArgList arglist,
Cardinal argcount);

DESCRIPTION

XmCreateTemplateDialog est une fonction de création pratique qui crée un DialogShell et un enfant MessageBox non géré du DialogShell. La ressource XmNdialogType du widget MessageBox est définie sur XmDIALOG_TEMPLATE. Par défaut, le widget TemplateDialog ne contient que l'enfant séparateur. Vous pouvez construire une boîte de dialogue personnalisée en ajoutant des enfants au TemplateDialog.

Vous pouvez créer les boutons poussoirs standard de MessageBox, Cancel, Help et OK, en spécifiant les callbacks associés et les ressources de chaîne d'étiquette. La définition de XmNsymbolPixmap ou XmNmessageString crée une étiquette de symbole ou de message.

Utilisez XtManageChild pour faire apparaître le TemplateDialog (en passant le MessageBox comme paramètre widget) ; utilisez XtUnmanageChild pour le faire disparaître.

XmCreateTemplateDialog force la valeur de la ressource Shell XmNallowShellResize à True.

parent
Spécifie l'ID du widget parent.
name
Spécifie le nom du widget créé.
arglist
Spécifie la liste d'arguments.
argcount
Spécifie le nombre de paires attribut/valeur dans la liste d'arguments (arglist).

Pour une définition complète de MessageBox et de ses ressources associées, voir XmMessageBox(3).

RETOUR

Retourne l'ID du widget MessageBox.
