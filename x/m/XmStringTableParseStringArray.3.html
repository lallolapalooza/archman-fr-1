Licences: LGPL-2.1-or-later

XmStringTableParseStringArray(appel de bibliothèque) XmStringTableParseStringArray(appel de bibliothèque)

NOM

XmStringTableParseStringArray — Une fonction pratique qui convertit un tableau de chaînes en une table de chaînes composites

SYNOPSIS

#include <Xm/Xm.h>
XmStringTable XmStringTableParseStringArray(
XtPointer *strings,
Cardinal count,
XmStringTag tag,
XmTextType type,
XmParseTable parse,
Cardinal parse_count,
XtPointer call_data);

DESCRIPTION

XmStringTableParseStringArray prend un tableau de chaînes, alloue une XmStringTable avec un nombre égal d'emplacements, appelle XmStringParseText sur chaque chaîne de strings, et insère la XmString résultante dans l'emplacement correspondant de la XmStringTable.

strings
Spécifie un tableau de chaînes de caractères tel que déterminé par type.
count
Spécifie le nombre de chaînes dans strings.
tag
Spécifie le tag à utiliser lors de la création du résultat. Le type de tag créé (charset ou locale) dépend du type du texte et de la valeur donnée. Si la valeur spécifiée est NULL, et que type indique qu'un tag de charset doit être créé, alors le tag aura la valeur de XmFONTLIST_DEFAULT_TAG. Si type indique un tag de locale, alors le tag aura la valeur de XmFONTLIST_DEFAULT_TAG.
type
Spécifie le type de texte à passer et le type de tag. Si le type est soit XmMULTIBYTE_TEXT soit XmWIDECHAR_TEXT, un tag de locale doit être créé. Si le type est XmCHARSET_TEXT, un tag de charset sera créé.
parse
Spécifie la table d'analyse à utiliser.
parse_count
Spécifie le nombre d'entrées dans la table d'analyse.
call_data
Spécifie les données à passer aux procédures d'analyse.

RETOUR

Retourne une nouvelle XmStringTable. La fonction alloue de l'espace pour contenir la XmStringTable. Lorsque l'application n'a plus besoin de la XmStringTable retournée, l'application doit appeler XmStringFree count fois (c'est-à-dire une fois pour chaque chaîne composite retournée) et ensuite appeler XtFree pour désallouer la XmStringTable elle-même.

CONNEXES

XmStringFree(3) et XmTabList(3).
