NOM

XmVaCreateScrolledWindow, XmVaCreateManagedScrolledWindow — Fonctions de création pratique pour le widget ScrolledWindow.

SYNTAXE

#include <Xm/ScrolledW.h>
Widget XmVaCreateScrolledWindow(
Widget parent,
String name,
...);
Widget XmVaCreateManagedScrolledWindow(
Widget parent,
String name,
...);

DESCRIPTION

Ces fonctions créent une instance d'un widget ToggleButtonGadget et renvoient l'identifiant du widget associé. Ces routines utilisent la convention d'appel de liste d'arguments de longueur variable (varargs) d'ANSI C.

La fonction XmVaCreateScrolledWindow est une routine pratique qui appelle XtCreateWidget.

La fonction XmVaCreateScrolledWindow est une routine pratique qui appelle XtCreateManagedWidget.

parent
Spécifie l'identifiant du widget parent.
name
Spécifie le nom du widget créé.
...
Spécifie la liste d'arguments variables pour remplacer les valeurs par défaut des ressources.

Pour une définition complète de ScrolledWindow et de ses ressources associées, voir XmScrolledWindow(3).

RETOUR

Renvoie l'identifiant du widget ScrolledWindow.

VOIR AUSSI

XmScrolledWindow(3), XmCreateScrolledWindow(3), XtCreateWidget(3), et XtCreateManagedWidget(3).
