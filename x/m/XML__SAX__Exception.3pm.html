NOM

XML::SAX::Exception - Classes d'exception pour XML::SAX

SYNTAXE

throw XML::SAX::Exception::NotSupported(
        Message => "La fonctionnalité foo n'est pas supportée",
        );

DESCRIPTION

Ce module est la classe de base pour toutes les exceptions SAX, celles définies dans la spécification ainsi que celles que l'on peut créer pour ses propres erreurs SAX.

Trois sous-classes sont incluses, correspondant à celles de la spécification SAX :

XML::SAX::Exception::NotSupported
XML::SAX::Exception::NotRecognized
XML::SAX::Exception::Parse

Utilisez-les où vous voulez, et autant que possible lorsque vous rencontrez de telles erreurs. SAX est censé utiliser des exceptions autant que possible pour signaler les problèmes.

CRÉATION DE NOUVELLES CLASSES D'EXCEPTION

Tout ce que vous avez à faire pour créer une nouvelle classe d'exception est :

@XML::SAX::Exception::MyException::ISA = ('XML::SAX::Exception')

Le package donné n'a pas besoin d'exister, il se comportera correctement ainsi. Si votre exception affine une classe d'exception existante, vous pouvez alors hériter de celle-ci au lieu de la classe de base.

LANCER DES EXCEPTIONS

C'est aussi simple que ce qui est montré dans la SYNTAXE. En fait, il n'y a rien d'autre à savoir. Tout ce que vous avez à faire est :

throw XML::SAX::Exception::MyException( Message => 'Quelque chose s'est mal passé' );

Et voilà, vous avez lancé une exception qui peut être capturée dans un bloc eval.
