XmNotebookGetPageInfo(3)

XmNotebookGetPageInfo(appel de bibliothèque) XmNotebookGetPageInfo(appel de bibliothèque)

NOM

XmNotebookGetPageInfo — Une fonction de Notebook qui renvoie des informations sur les pages

SYNOPSIS

#include <Xm/Notebook.h>
XmNotebookPageStatus XmNotebookGetPageInfo(
Widget notebook,
int page_number,
XmNotebookPageInfo *page_info);

DESCRIPTION

XmNotebookGetPageInfo renvoie des informations d'état pour la page Notebook spécifiée.

notebook
Spécifie le widget Notebook.
page_number
Spécifie le numéro de page à interroger.
page_info
Pointe vers la structure contenant les informations de page. La structure a la forme suivante :
typedef struct
{
        int     page_number;
        Widget  page_widget;
        Widget  status_area_widget;
        Widget  major_tab_widget;
        Widget  minor_tab_widget;
} XmNotebookPageInfo;
(void)
page_number
Spécifie le page_number passé à la fonction.
page_widget
Spécifie un widget enfant du Notebook avec un XmNchildType de XmPAGE et un XmNpageNumber égal à page_number s'il existe ; sinon NULL.
status_area_widget
Spécifie un widget enfant du Notebook avec un XmNchildType de XmSTATUS_AREA et un XmNpageNumber égal à page_number s'il existe ; sinon NULL.
major_tab_widget
Spécifie un widget enfant du Notebook avec un XmNchildType de XmMAJOR_TAB et le XmNpageNumber le plus proche égal ou inférieur à page_number s'il existe ; sinon NULL.
minor_tab_widget
Spécifie un widget enfant du Notebook avec un XmNchildType de XmMINOR_TAB et le XmNpageNumber le plus proche égal ou inférieur à page_number s'il existe ; sinon NULL.

Pour une définition complète de Notebook et de ses ressources associées, voir XmNotebook(3).

RETOUR

Renvoie l'une des valeurs d'état de page suivantes :

XmPAGE_FOUND
La page spécifiée a été trouvée.
XmPAGE_INVALID
Le numéro de page spécifié est en dehors de la plage des numéros de page.
XmPAGE_EMPTY
La page spécifiée n'a pas de widget de page.
XmPAGE_DUPLICATED
Il existe plus d'un widget de page avec le numéro de page spécifié. Le widget de page géré le plus récemment est utilisé pour la structure d'informations de page.

VOIR AUSSI

XmNotebook(3).
