NOM

XmCreateSimpleCheckBox — Fonction de création pratique pour le widget RowColumn

SYNTAXE

#include <Xm/RowColumn.h>
Widget XmCreateSimpleCheckBox(
Widget parent,
String name,
ArgList arglist,
Cardinal argcount);

DESCRIPTION

XmCreateSimpleCheckBox crée une instance d'un widget RowColumn de type XmWORK_AREA et retourne l'identifiant du widget associé.

Cette routine crée une Case à cocher et ses enfants ToggleButtonGadget. Une Case à cocher est similaire à une Boîte de radio, sauf que plusieurs boutons peuvent être sélectionnés en même temps. Le nom de chaque bouton est button_n, où n est un entier allant de 0 (zéro) au nombre de boutons du menu moins 1. Les boutons sont nommés et créés dans l'ordre où ils sont spécifiés dans les ressources de création de menu simple de RowColumn fournies dans la liste d'arguments.

parent
Spécifie l'identifiant du widget parent
name
Spécifie le nom du widget créé
arglist
Spécifie la liste d'arguments
argcount
Spécifie le nombre de paires attribut/valeur dans la liste d'arguments (arglist)

Un certain nombre de ressources existent spécifiquement pour être utilisées avec cette fonction et d'autres routines de création de menu simple. Le seul type de bouton autorisé pour la ressource XmNbuttonType est XmCHECKBUTTON. Pour une définition complète de RowColumn et de ses ressources associées, voir XmRowColumn(3).

RETOUR

Retourne l'identifiant du widget RowColumn.

LIENS CORRESPONDANTS

XmCreateRadioBox(3), XmCreateRowColumn(3), XmCreateSimpleRadioBox(3), XmRowColumn(3), XmVaCreateSimpleCheckBox(3), et XmVaCreateSimpleRadioBox(3).
