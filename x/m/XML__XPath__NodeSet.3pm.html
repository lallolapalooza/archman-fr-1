XML::XPath::NodeSet(3) Documentation Perl fournie par l'utilisateur XML::XPath::NodeSet(3)

NOM

XML::XPath::NodeSet - un ensemble de nœuds de document XML

DESCRIPTION

Un objet XML::XPath::NodeSet contient une liste ordonnée de nœuds. Chaque nœud est au même format que celui décrit dans XML::XPath::XMLParser.

SYNTAXE

my $results = $xp->find('//someelement');
if (!$results->isa('XML::XPath::NodeSet')) {
        print "Found $results\n";
        exit;
}
foreach my $context ($results->get_nodelist) {
        my $newresults = $xp->find('./other/element', $context);
        ...
}

API

new()

Vous n'aurez presque jamais besoin de créer un nouvel objet NodeSet, car tout est fait pour vous par XPath.

get_nodelist()

Retourne une liste de nœuds. Voir XML::XPath::XMLParser pour le format des nœuds.

string_value()

Retourne la valeur chaîne du premier nœud de la liste. Voir la spécification XPath pour ce que signifie "valeur chaîne".

to_literal()

Retourne la concaténation de toutes les valeurs chaînes de tous les nœuds de la liste.

get_node($pos)

Retourne le nœud à la position $pos. La position des nœuds dans XPath est basée sur 1, pas sur 0.

size()

Retourne le nombre de nœuds dans le NodeSet.

pop()

Équivalent de la fonction pop de Perl.

push(@nodes)

Équivalent de la fonction push de Perl.

append($nodeset)

Étant donné un ensemble de nœuds, ajoute la liste des nœuds de $nodeset à la fin de la liste actuelle.

shift()

Équivalent de la fonction shift de Perl.

unshift(@nodes)

Équivalent de la fonction unshift de Perl.

prepend($nodeset)

Étant donné un ensemble de nœuds, ajoute la liste des nœuds de $nodeset au début de la liste actuelle.
