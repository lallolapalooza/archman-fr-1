NOM

XmVaCreateTabStack, XmVaCreateManagedTabStack — Fonctions de création pratiques pour le widget TabStack.

SYNTAXE

#include <Xm/TabStack.h>
Widget XmVaCreateTabStack(
Widget parent,
String name,
...);
Widget XmVaCreateManagedTabStack(
Widget parent,
String name,
...);

DESCRIPTION

Ces fonctions créent une instance d'un widget ToggleButtonGadget et retournent l'identifiant du widget associé. Ces routines utilisent la convention d'appel de liste d'arguments de longueur variable (varargs) ANSI C.

La fonction XmVaCreateTabStack est une routine pratique qui appelle XtCreateWidget.

La fonction XmVaCreateTabStack est une routine pratique qui appelle XtCreateManagedWidget.

parent
Spécifie l'identifiant du widget parent.
name
Spécifie le nom du widget créé.
...
Spécifie la liste d'arguments variables pour remplacer les valeurs par défaut des ressources.

Pour une définition complète de TabStack et de ses ressources associées, voir XmTabStack(3).

RETOUR

Retourne l'identifiant du widget TabStack.

VOIR AUSSI

XmTabStack(3), XmCreateTabStack(3), XtCreateWidget(3), et XtCreateManagedWidget(3).
