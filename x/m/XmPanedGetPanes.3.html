NOM

XmPanedGetPanes — Appel de fonction Paned qui renvoie le nombre de panneaux dans le widget paned

SYNTAXE

#include <Xm/Paned.h>
int         XmPanedGetPanes(
Widget      widget,
WidgetList *panes,
int        *num);

DESCRIPTION

XmPanedGetPanes renvoie le nombre de panneaux dans le widget paned.

widget
Spécifie l'ID du widget Paned

RETOUR

panes
Spécifie la liste de tous les panneaux contenus dans ce widget
num
Spécifie le nombre de panneaux dans le widget paned

Renvoie le nombre de panneaux dans le widget paned.

CONNEXE

XmPaned(3).
