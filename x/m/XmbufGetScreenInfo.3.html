DESCRIPTION

La bibliothèque d'interface de programmation pour l'Extension X11 de Double Buffering, Multi-Buffering et Stéréo contient les interfaces décrites ci-dessous. À l'exception de XmbufQueryExtension, si l'une de ces routines est appelée avec un affichage qui ne prend pas en charge l'extension, l'ExtensionErrorHandler (qui peut être défini avec XSetExtensionErrorHandler et fonctionne de la même manière que XSetErrorHandler) sera appelé et la fonction retournera ensuite.

XmbufQueryExtension renvoie True si l'extension de multibuffering/stéréo est disponible sur l'affichage donné. Si l'extension existe, la valeur du premier code d'événement (qui doit être ajoutée aux constantes de type d'événement MultibufferClobberNotify et MultibufferUpdateNotify pour obtenir les valeurs réelles) est stockée dans event_base_return et la valeur du premier code d'erreur (qui doit être ajoutée à la constante de type d'erreur MultibufferBadBuffer pour obtenir la valeur réelle) est stockée dans error_base_return.

XmbufGetVersion obtient les numéros de version majeure et mineure de l'extension. La valeur de retour est zéro si une erreur se produit ou non zéro si aucune erreur ne se produit.

XmbufCreateBuffers demande que "count" buffers soient créés avec l'action de mise à jour et l'indice de mise à jour donnés et soient associés à la fenêtre indiquée. Le nombre de buffers créés est renvoyé (zéro si une erreur s'est produite) et buffers_update est rempli avec ce nombre d'identifiants Multibuffer.

XmbufDestroyBuffers détruit les buffers associés à la fenêtre donnée.

XmbufDisplayBuffers affiche les buffers indiqués dans leurs fenêtres appropriées dans un délai maximal de max_delay millisecondes après que min_delay millisecondes se sont écoulées. Deux buffers ne peuvent pas être associés à la même fenêtre, sinon une erreur Match est générée.

XmbufGetWindowAttributes obtient les attributs de multibuffering qui s'appliquent à tous les buffers associés à la fenêtre donnée. La liste des buffers retournés peut être libérée avec XFree. Renvoie non-zéro en cas de succès et zéro si une erreur se produit.

XmbufChangeWindowAttributes définit les attributs de multibuffering qui s'appliquent à tous les buffers associés à la fenêtre donnée. Ceci est actuellement limité à l'indice de mise à jour.

XmbufGetBufferAttributes obtient les attributs du buffer indiqué. Renvoie non-zéro en cas de succès et zéro si une erreur se produit.

XmbufChangeBufferAttributes définit les attributs du buffer indiqué. Ceci est actuellement limité au masque d'événement.

XmbufGetScreenInfo obtient les paramètres contrôlant la façon dont les fenêtres mono et stéréo peuvent être créées sur l'écran du drawable donné. Les nombres d'ensembles de visuals et de profondeurs sont retournés dans nmono_return et nstereo_return. Si nmono_return est supérieur à zéro, alors mono_info_return est défini à l'adresse d'un tableau de structures XmbufBufferInfo décrivant les différents visuals et profondeurs qui peuvent être utilisés. Sinon, mono_info_return est défini à NULL. De même, stereo_info_return est défini en fonction de nstereo_return. Le stockage retourné dans mono_info_return et stereo_info_return peut être libéré par XFree. Si aucune erreur n'est rencontrée, une valeur non nulle sera renvoyée.

XmbufCreateStereoWindow crée une fenêtre stéréo de la même manière que XCreateWindow crée une fenêtre mono. Les identifiants de buffer pour les buffers gauche et droit sont retournés dans left_return et right_return, respectivement. Si un gestionnaire d'erreurs d'extension qui retourne est installé, None sera retourné si l'extension n'est pas disponible sur cet affichage.

NAME

XmbufGetScreenInfo, XmbufQueryScreens, XmbufQueryExtension - getting multi-buffering information

SYNTAX

    int XmbufGetScreenInfo(Display *dpy, XScreenNumber **screens);
    int XmbufQueryScreens(Display *dpy, XScreenNumber **screens);
    int XmbufQueryExtension(Display *dpy, int *event_basep, int *error_basep);

STRUCTURES

    typedef struct {
        int screen;
        int max_buffers;
        int current_buffers;
    } XScreenNumber;

DESCRIPTION

The multi-buffering extension for X allows applications to use multiple buffers on a single screen. This is useful for implementing double-buffering, triple-buffering, stereo rendering, or general purpose multi-buffering for animations or fast drawing.

The XmbufQueryExtension function probes for the multi-buffering extension and returns the event and error base numbers if found. The extension must be queried before any other multi-buffering functions can be used.

The XmbufQueryScreens and XmbufGetScreenInfo functions return a list of screens that support multi-buffering. The list is returned as an array of XScreenNumber structures. The screen member identifies the screen number. The max_buffers member indicates the maximum number of buffers that can be allocated on that screen. The current_buffers member indicates the number of buffers currently allocated on that screen.

If the extension is not found, or if there is an error, XmbufQueryExtension, XmbufQueryScreens, and XmbufGetScreenInfo return 0. Otherwise, they return a non-zero value.

The memory for the returned screen list must be freed by the application using XFree.

PREDEFINED VALUES

Error codes:

    MultibufferBadBuffer      0
    MultibufferNumberErrors   1

Event codes:

    MultibufferUpdateNotify   0
    MultibufferClobberNotify  1
    MultibufferNumberEvents   2

Update mask:

NOM

XmbufGetScreenInfo, XmbufQueryScreens, XmbufQueryExtension - obtenir des informations sur le multi-buffering

SYNTAXE

    int XmbufGetScreenInfo(Display *dpy, XScreenNumber **screens);
    int XmbufQueryScreens(Display *dpy, XScreenNumber **screens);
    int XmbufQueryExtension(Display *dpy, int *event_basep, int *error_basep);

STRUCTURES

    typedef struct {

        int max_buffers;

DESCRIPTION

L'extension de multi-buffering pour X permet aux applications d'utiliser plusieurs tampons sur un seul écran. Ceci est utile pour implémenter le double buffering, le triple buffering, le rendu stéréo, ou le multi-buffering à usage général pour les animations ou le dessin rapide.

La fonction XmbufQueryExtension recherche l'extension de multi-buffering et retourne les numéros de base d'événement et d'erreur si elle est trouvée. L'extension doit être interrogée avant que toute autre fonction de multi-buffering puisse être utilisée.

Les fonctions XmbufQueryScreens et XmbufGetScreenInfo retournent une liste d'écrans qui prennent en charge le multi-buffering. La liste est retournée sous forme d'un tableau de structures XScreenNumber. Le membre screen identifie le numéro de l'écran. Le membre max_buffers indique le nombre maximum de tampons pouvant être alloués sur cet écran. Le membre current_buffers indique le nombre de tampons actuellement alloués sur cet écran.

Si l'extension n'est pas trouvée, ou s'il y a une erreur, XmbufQueryExtension, XmbufQueryScreens, et XmbufGetScreenInfo retournent 0. Sinon, elles retournent une valeur non nulle.

La mémoire pour la liste d'écrans retournée doit être libérée par l'application en utilisant XFree.
