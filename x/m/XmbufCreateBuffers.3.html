DESCRIPTION

La bibliothèque d'interface de programmation pour le X11 Double-Buffering, Multi-Buffering, et Extension Stéréo contient les interfaces décrites ci-dessous. À l'exception de XmbufQueryExtension, si l'une de ces routines est appelée avec un affichage qui ne prend pas en charge l'extension, l'ExtensionErrorHandler (qui peut être défini avec XSetExtensionErrorHandler et fonctionne de la même manière que XSetErrorHandler) sera appelée et la fonction retournera ensuite.

XmbufQueryExtension retourne True si l'extension multibuffering/stéréo est disponible sur l'affichage donné. Si l'extension existe, la valeur du premier code d'événement (qui doit être ajouté aux constantes de type d'événement MultibufferClobberNotify et MultibufferUpdateNotify pour obtenir les valeurs réelles) est stockée dans event_base_return et la valeur du premier code d'erreur (qui doit être ajouté à la constante de type d'erreur MultibufferBadBuffer pour obtenir la valeur réelle) est stockée dans error_base_return.

XmbufGetVersion récupère les numéros de version majeure et mineure de l'extension. La valeur de retour est zéro si une erreur se produit ou non nulle si aucune erreur ne se produit.

XmbufCreateBuffers demande que "count" buffers soient créés avec l'action de mise à jour et l'indice de mise à jour donnés et soient associés à la fenêtre indiquée. Le nombre de buffers créés est retourné (zéro si une erreur s'est produite) et buffers_update est rempli avec ce nombre d'identifiants Multibuffer.

XmbufDestroyBuffers détruit les buffers associés à la fenêtre donnée.

XmbufDisplayBuffers affiche les buffers indiqués dans leurs fenêtres appropriées dans un délai maximum de max_delay millisecondes après que min_delay millisecondes se soient écoulées. Deux buffers ne peuvent pas être associés à la même fenêtre, sinon une erreur Match est générée.

XmbufGetWindowAttributes récupère les attributs de multibuffering qui s'appliquent à tous les buffers associés à la fenêtre donnée. La liste des buffers retournée peut être libérée avec XFree. Retourne non nul en cas de succès et zéro en cas d'erreur.

XmbufChangeWindowAttributes définit les attributs de multibuffering qui s'appliquent à tous les buffers associés à la fenêtre donnée. Ceci est actuellement limité à l'indice de mise à jour.

XmbufGetBufferAttributes récupère les attributs du buffer indiqué. Retourne non nul en cas de succès et zéro en cas d'erreur.

XmbufChangeBufferAttributes définit les attributs du buffer indiqué. Ceci est actuellement limité au event_mask.

XmbufGetScreenInfo récupère les paramètres contrôlant comment les fenêtres mono et stéréo peuvent être créées sur l'écran du dessinable donné. Les nombres d'ensembles de visuels et de profondeurs sont retournés dans nmono_return et nstereo_return. Si nmono_return est supérieur à zéro, alors mono_info_return est défini à l'adresse d'un tableau de structures XmbufBufferInfo décrivant les différents visuels et profondeurs qui peuvent être utilisés. Sinon, mono_info_return est défini à NULL. De même, stereo_info_return est défini en fonction de nstereo_return. Le stockage retourné dans mono_info_return et stereo_info_return peut être libéré par XFree. Si aucune erreur n'est rencontrée, non nul sera retourné.

XmbufCreateStereoWindow crée une fenêtre stéréo de la même manière que XCreateWindow crée une fenêtre mono. Les identifiants de buffer pour les buffers gauche et droit sont retournés respectivement dans left_return et right_return. Si un gestionnaire d'erreurs d'extension qui retourne est installé, None sera retourné si l'extension n'est pas disponible sur cet affichage.

DESCRIPTION

Ces fonctions font partie de l'extension Multi-Buffering du protocole X11. Elles permettent aux applications de gérer plusieurs tampons graphiques pour un écran ou une fenêtre spécifique, facilitant ainsi les effets d'animation et de double mise en mémoire tampon.

XmbufCreateBuffers
Crée un nombre spécifié de tampons pour un écran donné. Le paramètre event_mask spécifie les événements de mise à jour des tampons que l'application souhaite recevoir.
XmbufDestroyBuffers
Détruit tous les tampons créés pour un écran donné.
XmbufGetBufferInfo
Retourne un pointeur vers un tableau de structures XmbufBufferInfo contenant des informations sur chaque tampon d'un écran donné.
XmbufGetScreenInfo
Retourne un pointeur vers une structure XmbufScreenInfo contenant des informations générales sur la configuration des tampons multiples pour un écran donné.
XmbufGetWindowInfo
Retourne un pointeur vers une structure XmbufWindowInfo contenant des informations sur la configuration des tampons multiples pour une fenêtre donnée.
XmbufSelectEvent
Modifie le masque d'événements pour les mises à jour de tampons pour un écran donné.
XmbufSetContext
Associe un pointeur de contexte personnalisé à la configuration des tampons multiples d'un écran donné. Ce pointeur peut être utilisé par les gestionnaires d'événements.
XmbufGetContext
Retourne le pointeur de contexte précédemment associé à la configuration des tampons multiples d'un écran donné.
