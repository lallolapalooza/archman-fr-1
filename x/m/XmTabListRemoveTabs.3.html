NOM

XmTabListRemoveTabs — Une fonction de commodité qui supprime des onglets non contigus

SYNOPSIS

#include <Xm/Xm.h>
XmTabList XmTabListRemoveTabs(
XmTabList oldlist,
Cardinal *position_list,
Cardinal position_count);

DESCRIPTION

XmTabListRemoveTabs supprime les onglets non contigus d'une liste d'onglets. La fonction crée une nouvelle liste d'onglets en copiant le contenu de oldlist et en supprimant tous les onglets dont les positions correspondantes apparaissent dans le tableau position_list. Un message d'avertissement est affiché si une position spécifiée est invalide ; par exemple, si la valeur est un nombre supérieur au nombre d'onglets dans la liste d'onglets.

oldlist
Spécifie la liste d'onglets. La fonction désalloue oldlist et les onglets qu'elle contient après avoir extrait les informations requises.
position_list
Spécifie un tableau des positions d'onglets à supprimer. La position du premier onglet dans la liste est 0 (zéro), la position du deuxième onglet est 1, et ainsi de suite.
position_count
Spécifie le nombre d'éléments dans position_list.

RETOUR

Si oldlist ou position_list est NULL, ou si position_count est 0 (zéro), retourne oldlist. Sinon, cette fonction retourne la nouvelle liste d'onglets. La fonction alloue de l'espace pour contenir la liste d'onglets retournée. L'application est responsable de la gestion de l'espace alloué. L'application peut récupérer l'espace alloué en appelant XmTabListFree.

VOIR AUSSI

XmTabList(3) et XmTabListFree(3).
