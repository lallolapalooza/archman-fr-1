NOM

XmFileSelectionDoSearch — Fonction de FileSelectionBox qui initie une recherche de répertoire

SYNTAXE

#include <Xm/FileSB.h>
void XmFileSelectionDoSearch(
Widget widget,
XmString dirmask);

DESCRIPTION

XmFileSelectionDoSearch initie une recherche de répertoire et de fichiers dans un widget FileSelectionBox. Pour une description des actions que le FileSelectionBox entreprend lors d'une recherche, voir XmFileSelectionBox(3).

widget
Spécifie l'identifiant du widget FileSelectionBox.
dirmask
Spécifie le masque de répertoire utilisé pour déterminer les répertoires et les fichiers affichés dans les listes du FileSelectionBox. Cette valeur est utilisée comme membre mask de la structure de données d'entrée XmFileSelectionBoxCallbackStruct passée au XmNqualifySearchDataProc du FileSelectionBox. Les membres dir et pattern de cette structure sont NULL.

Pour une définition complète de FileSelectionBox et de ses ressources associées, voir XmFileSelectionBox(3).

VOIR AUSSI

XmFileSelectionBox(3).
