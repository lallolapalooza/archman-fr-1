XmPrintToFile(3)

Paquet: openmotif

XmPrintToFile(appel de bibliothèque) XmPrintToFile(appel de bibliothèque)

NOM

XmPrintToFile — Récupère et enregistre les données qui seraient normalement imprimées par le serveur d'impression X.

SYNTAXE

#include <Xm/Print.h>
XtEnumXmPrintToFile(
Display*dpy,
Stringfilename,
XPFinishProcfinish_proc,
XtPointerclient_data);

DESCRIPTION

XmPrintToFile masque les détails de la connexion d'affichage X et de XpGetDocumentData pour le programmeur d'applications Motif.

Cette fonction est une routine pratique qui masque les détails des internes X et Xp pour le programmeur d'applications en appelant la fonction XpGetDocumentData avec des rappels de sauvegarde et de fin appropriés.

Ceci est utilisé dans le contexte de l'impression X lorsque l'utilisateur a spécifié l'option « imprimer vers un fichier » à partir d'une boîte de dialogue normale de configuration d'impression.

XmPrintToFile essaie d'abord d'ouvrir le nom de fichier donné en écriture et retourne False s'il n'y parvient pas. Sinon, il utilise XpGetDocumentData, lui donnant un procédure de sauvegarde qui écrit les données reçues dans le fichier et une procédure de fin qui ferme le fichier ou le supprime en cas d'échec de terminaison. Il appelle finish_proc à ce moment-là, en lui passant l'argument reçu de la couche Xp (status == XPGetDocFinished signifie que le fichier est valide et a été fermé, sinon le fichier a été supprimé).

XmPrintToFile n'est pas bloquant ; s'il retourne avec succès, cela signifie simplement que le fichier a été ouvert avec succès, et non que toutes les données ont été reçues.

dpy
Connexion d'affichage d'impression.
filename
Nom du fichier dans lequel placer les données d'impression.
finish_proc
Appelé lorsque toutes les données ont été reçues.
client_data
Passé avec le finish_proc.

VALEUR DE RETOUR

Retourne False si le nom de fichier n'a pas pu être créé ou ouvert en écriture, True sinon.

ERREURS/AVERTISSEMENTS

Non applicable

EXEMPLES

Un rappel OK typique d'une DtPrintSetupBox :

PrintOKCallback(widget...)
/*-------------*/
{   int save_data = XPSpool;
    pshell = XmPrintSetup (widget, pbs->print_screen,
                                   "Print", NULL, 0);
    XtAddCallback(pshell, XmNstartJobCallback, startJobCB, data);
    if (pbs->destination == DtPRINT_TO_FILE)
                 save_data = XPGetData;
    /* start job doit précéder XpGetDocumentData dans XmPrintToFile */
    XpStartJob(XtDisplay(pshell), save_data);
    XFlush(XtDisplay(pshell));  /* maintenir la séquence
                                 entre startjob et getdocument */
    /* configurer l'impression vers un fichier */
    if (pbs->destination == DtPRINT_TO_FILE)
        XmPrintToFile(XtDisplay(pshell),
                                 pbs->dest_info, FinishPrintToFile, NULL);
    }
}
static void
startJobCB(Widget, XtPointer call_data, XtPointer client_data)
{
  print(p);   /* le rendu se passe ici */
  XpEndJob(XtDisplay(p->print_shell));
  /* nettoyage */
  XtDestroyWidget(p->print_shell);
          XtCloseDisplay(XtDisplay(p->print_shell));
}
