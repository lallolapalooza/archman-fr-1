NOM

XML::SAX2Perl -- Traduire les méthodes SAX Perl en méthodes de style Java/CORBA

SYNTAXE

use XML::Perl2SAX;
$perl2sax = XML::Perl2SAX(handler => $gestionnaire_style_java);

DESCRIPTION

"XML::Perl2SAX" est un filtre SAX qui traduit les méthodes SAX de style Perl en appels de méthodes de style Java/CORBA. Ce module effectue l'opération inverse de "XML::SAX2Perl".

"Perl2SAX" est un gestionnaire de documents SAX Perl. La méthode `"new"' prend un argument `"handler"' qui est un gestionnaire de style Java/CORBA que la nouvelle instance de Perl2SAX appellera. Les interfaces SAX sont définies sur http://www.megginson.com/SAX/.
