XML::Atom::Person - Objet auteur ou contributeur

SYNTAXE

my $person = XML::Atom::Person->new;

$person->name('Foo Bar');

DESCRIPTION

XML::Atom::Person représente un élément auteur ou contributeur dans un flux ou une entrée Atom.
