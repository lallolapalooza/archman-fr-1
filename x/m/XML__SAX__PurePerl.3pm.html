XML::SAX::PurePerl(3) Documentation Perl Contribuée par l'Utilisateur XML::SAX::PurePerl(3)

NOM

XML::SAX::PurePerl - Analyseur XML Pure Perl avec interface SAX2

SYNTHÈSE

use XML::Handler::Foo;
use XML::SAX::PurePerl;
my $handler = XML::Handler::Foo->new();
my $parser = XML::SAX::PurePerl->new(Handler => $handler);
$parser->parse_uri("myfile.xml");

DESCRIPTION

Ce module implémente un analyseur XML en pure perl. Il est écrit autour du support Unicode de perl 5.8 à venir et du support de multiples encodages de documents (en utilisant la couche PerlIO), cependant il a été porté pour fonctionner avec des documents ASCII/UTF8 sous des versions de perl inférieures.

L'API SAX2 est décrite en détail sur http://sourceforge.net/projects/perl-xml/, dans l'archive CVS, sous libxml-perl/docs. Espérons que ces documents seront bientôt disponibles à un meilleur emplacement.

Veuillez vous référer à la documentation SAX2 pour savoir comment utiliser ce module - c'est simplement une interface vers SAX2, et n'implémente rien qui ne soit pas dans cette spécification (ou du moins, essaie de ne pas le faire - veuillez m'envoyer un email si vous trouvez des erreurs dans cette implémentation).

BOGUES

XML::SAX::PurePerl est lent. Très lent. Je suggère en fait d'utiliser autre chose. Cependant, il est excellent comme analyseur de secours pour XML::SAX, où l'utilisateur pourrait ne pas être en mesure d'installer un analyseur basé sur XS ou une bibliothèque C.

Actuellement, il y en a probablement beaucoup. Pour le moment, le domaine le plus faible est l'analyse des déclarations DOCTYPE, bien que le code soit en place pour commencer à le faire. L'analyse des références d'entités de paramètres me cause également beaucoup de confusion, car ce n'est pas exactement ce que j'appellerais trivial, ni bien documenté dans la grammaire XML. Les documents XML avec des sous-ensembles internes risquent d'échouer.

Cependant, j'essaie de travailler vers une conformité totale en utilisant la suite de tests Oasis.
