NOM

XML::LibXML::PI - Instructions de traitement XML::LibXML

SYNOPIS

use XML::LibXML;
# Seules les méthodes spécifiques aux nœuds d'instructions de traitement sont listées ici,
# voir la page de manuel XML::LibXML::Node pour les autres méthodes
$pinode->setData( $data_string );
$pinode->setData( name=>string_value [...] );

DESCRIPTION

Les instructions de traitement sont implémentées avec XML::LibXML avec un accès en lecture et écriture. Les données de l'instruction de traitement sont l'instruction sans la cible de l'instruction (comme spécifié dans XML 1.0 [17]) sous forme de chaîne de caractères. Cette chaîne peut être accédée avec getData comme implémenté dans XML::LibXML::Node.

L'accès en écriture est conscient du fait que de nombreuses instructions de traitement ont des données de type attribut. Par conséquent, setData() fournit en plus de l'interface conforme à la spécification DOM, une interface pour passer un ensemble de paramètres nommés. Ainsi, le segment de code

my $pi = $dom->createProcessingInstruction("abc");
$pi->setData(foo=>'bar', foobar=>'foobar');
$dom->appendChild( $pi );

résultera dans l'instruction de traitement suivante dans le DOM :

<?abc foo="bar" foobar="foobar"?>

Ce qui correspond à la spécification du DOM. Cette interface en trois étapes crée temporairement un nœud dans l'espace Perl. Cela peut être évité en utilisant la méthode insertProcessingInstruction(). Au lieu des trois appels décrits ci-dessus, l'appel

$dom->insertProcessingInstruction("abc",'foo="bar" foobar="foobar"');

aura le même résultat que ci-dessus.

L'implémentation de setData() de XML::LibXML::PI, documentée ci-dessous, diffère légèrement de la version standard disponible dans XML::LibXML::Node :

setData
$pinode->setData( $data_string );
$pinode->setData( name=>string_value [...] );

Cette méthode permet de modifier les données de contenu d'une instruction de traitement. En plus de l'interface spécifiée pour DOM Level2, la méthode fournit une interface de paramètres nommés pour définir les données. Cette liste de paramètres est convertie en une chaîne de caractères avant d'être ajoutée à l'instruction de traitement.
