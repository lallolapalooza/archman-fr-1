NOM

XML::RSSLite - analyseur RSS (et similaire à XML) léger et "relaxé"

SYNTAXE

use XML::RSSLite;
parseRSS(\%result, \$content);
print "=== Chaîne ===\n",
      "Titre: $result{'title'}\n",
      "Desc:  $result{'description'}\n",
      "Lien:  $result{'link'}\n\n";
foreach $item (@{$result{'items'}}) {
print "  --- Élément ---\n",
      "  Titre: $item->{'title'}\n",
      "  Desc:  $item->{'description'}\n",
      "  Lien:  $item->{'link'}\n\n";
}

DESCRIPTION

Ce module tente d'extraire le maximum de contenu des documents disponibles, et est moins soucieux de la conformité XML que les alternatives. Plutôt que de s'appuyer sur XML::Parser, il utilise des heuristiques et de bonnes vieilles expressions régulières Perl. Il stocke les données dans une structure de hachage simple, et "alias" certains balises afin qu'une fois terminé, vous puissiez compter sur la disponibilité des données minimales nécessaires pour reconstruire un fichier RSS valide. Cela signifie que vous obtenez le titre, la description et le lien de base pour une chaîne et ses éléments.

Ce module extrait plus de liens utilisables en analysant les formats "scriptingNews" et "weblog" en plus de RDF et RSS. Il "assainit" également la sortie pour de meilleurs résultats. Ces modifications comprennent :

Supprimer les balises HTML pour laisser du texte brut
Supprimer les espaces blancs en début d'URI
Par défaut, supprime les caractères sauf 0-9~!@#$%^&*()-+=a-zA-Z[];',.:"<>?\s
Utiliser les balises <url> lorsque <link> est vide
Utiliser les URL mal placées dans <title> lorsque <link> est vide
Extraire les liens des balises <a href=...> si nécessaire
Limiter les liens aux protocoles ftp et http(s)
Joindre les URL d'éléments relatifs (commençant par / ou #) à la base du site

EXPORT

parseRSS($outHashRef, $inScalarRef, [$strip])
inScalarRef - requis
Référence vers un scalaire contenant le document à analyser. NOTE : Le contenu sera effectivement détruit. Faites une copie profonde au préalable si vous y tenez.
outHashRef - requis
Référence vers le hachage dans lequel stocker le contenu analysé.
strip - facultatif
Une expression indiquant le niveau de filtrage à effectuer sur les caractères autorisés dans les résultats.
1 supprime les caractères non imprimables
0 aucun caractère n'est supprimé
indéfini (Par défaut) supprime tout sauf :
0-9~!@#$%^&*()-+= a-zA-Z[];',.:"<>?\t\n

EXPORTABLE

parseXML(\%parsedTree, \$parseThis, 'topTag', $comments);
parsedTree - requis
Référence vers un hachage pour stocker le document analysé.
parseThis - requis
Référence vers un scalaire contenant le document à analyser.
topTag - facultatif
Balise à considérer comme le nœud racine. Laisser cette valeur indéfinie n'est pas recommandé.
comments - facultatif
faux supprimera le contenu de parseThis
vrai ne supprimera pas les commentaires de parseThis
référence de tableau est vrai, les commentaires y seront stockés

AVERTISSEMENTS

Ce n'est pas un analyseur conforme. Il ne gère pas les éléments suivants :

  • <foo bar=">">

  • <foo><bar> <bar></bar> <bar></bar> </bar></foo>

  • <![CDATA[ ]]>

  • PI (instructions de traitement)

Il n'est pas valide, et sans DTD, les éléments suivants ne peuvent pas être correctement gérés :

entités
espaces de noms
Ceci arrivera peut-être ou peut-être pas dans une future version.
