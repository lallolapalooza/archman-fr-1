NOM

XmContainerGetItemChildren — Fonction du widget Container pour trouver tous les enfants d'un élément

SYNTAXE

#include <Xm/Container.h>
int XmContainerGetItemChildren(
Widget container,
Widget item,
WidgetList * item_children);

DESCRIPTION

XmContainerGetItemChildren alloue une WidgetList et y stocke les identificateurs de widget de tous les widgets qui ont item spécifié comme valeur de leur ressource XmNentryParent. Le programmeur de l'application est responsable de libérer la WidgetList allouée en utilisant XtFree. Le nombre d'identificateurs de widget renvoyés dans item_children est renvoyé par la fonction. Si aucun widget ne spécifie item comme valeur de sa ressource XmNentryParent, la fonction renvoie zéro et item_children n'est pas modifié.

container
Spécifie l'identificateur du widget Container.
item
Spécifie un identificateur de widget dans container.
item_children
Tableau de widgets renvoyé.

Pour une définition complète de Container et de ses ressources associées, voir XmContainer(3).

RETOUR

Cette fonction renvoie un décompte de tous les widgets qui ont item spécifié comme valeur de leur ressource XmNentryParent.

VOIR AUSSI

XmContainer(3).
