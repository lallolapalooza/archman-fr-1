NOM

XML::SAX2Perl -- traduire les méthodes SAX de style Java/CORBA en méthodes Perl

SYNOPSIS

use XML::SAX2Perl;
$sax2perl = XML::SAX2Perl(Handler => $my_handler);
$sax->setDocumentHandler($sax2perl);

DESCRIPTION

"XML::SAX2Perl" est un filtre SAX qui traduit les méthodes SAX de style Java/CORBA en appels de méthodes Perl. Cette page de manuel résume les options, les gestionnaires et les propriétés spécifiques pris en charge par "XML::SAX2Perl" ; veuillez vous référer à la norme Perl SAX "XML::SAX" pour les informations générales d'utilisation.

MÉTHODES

new
Crée un nouvel objet analyseur. Les options par défaut pour l'analyse, décrites ci-dessous, sont passées sous forme de paires clé-valeur ou d'une seule hash. Les options peuvent être modifiées directement dans l'objet analyseur, sauf indication contraire. Les options passées à `parse()' remplacent les options par défaut de l'objet analyseur pendant la durée de l'analyse.
parse
Analyse un document. Les options, décrites ci-dessous, sont passées sous forme de paires clé-valeur ou d'une seule hash. Les options passées à `parse()' remplacent les options par défaut de l'objet analyseur.
location
Retourne la localisation sous forme de hash : 
ColumnNumber    Le numéro de colonne de l'analyse.
LineNumber      Le numéro de ligne de l'analyse.
PublicId        Une chaîne contenant l'identifiant public, ou undef
                s'il n'est pas disponible.
SystemId        Une chaîne contenant l'identifiant système, ou undef
                s'il n'est pas disponible.
Méthodes du DocumentHandler SAX
Les méthodes suivantes sont des méthodes DocumentHandler que l'analyseur SAX 1.0 appellera et que "XML::SAX2Perl" traduira en appels de méthodes Perl SAX. Voir SAX 1.0 pour plus de détails. 
setDocumentLocator(locator)
startDocument()
endDocument()
startElement(name, atts)
endElement(name)
characters(ch, start, length)
ignorableWhitespace(ch, start, length)
processingInstruction(target, data)

OPTIONS

Les options suivantes sont prises en charge par "XML::SAX2Perl" :

Handler          gestionnaire par défaut pour recevoir les événements
DocumentHandler  gestionnaire pour recevoir les événements de document
DTDHandler       gestionnaire pour recevoir les événements DTD
ErrorHandler     gestionnaire pour recevoir les événements d'erreur
EntityResolver   gestionnaire pour résoudre les entités
Locale           locale pour fournir la localisation des erreurs
Source           hash contenant la source d'entrée pour l'analyse

Si aucun gestionnaire n'est fourni, tous les événements seront ignorés silencieusement, à l'exception de `fatal_error()' qui provoquera un appel à `die()' après avoir appelé `end_document()'.

Si un argument de chaîne unique est passé à la méthode `parse()', il est traité comme si une option `"Source"' avait été donnée avec un paramètre `"String"'.

Le hash `"Source"' peut contenir les paramètres suivants :

ByteStream       Le flux d'octets brut (descripteur de fichier) contenant le
                 document.
String           Une chaîne contenant le document.
SystemId         L'identifiant système (URI) du document.
PublicId         L'identifiant public.
Encoding         Une chaîne décrivant l'encodage des caractères.

Si plus d'une des options `"ByteStream"', `"String"', ou `"SystemId"' sont présentes, la préférence est donnée d'abord à `"ByteStream"', puis à `"String"', puis à `"SystemId"'.

GESTIONNAIRES

Les gestionnaires et propriétés suivants sont pris en charge par "XML::SAX2Perl" :

DocumentHandler méthodes

start_document
Recevoir la notification du début d'un document. 
Locator          Un objet qui peut retourner la localisation de tout événement
                 SAX dans le document.
end_document
Recevoir la notification de la fin d'un document.

Aucune propriété définie.

start_element
Recevoir la notification du début d'un élément. 
Name             Le nom du type d'élément.
Attributes       Les attributs attachés à l'élément, le cas échéant.

AVERTISSEMENT ALPHA : La valeur `"Attributes"' n'est pas traduite depuis la valeur SAX 1.0, elle contiendra donc un objet AttributeList.

end_element
Recevoir la notification de la fin d'un élément. 
Name             Le nom du type d'élément.
characters
Recevoir la notification des données de caractères. 
Data             Les caractères du document XML.
ignorable_whitespace
Recevoir la notification des espaces blancs ignorables dans le contenu d'un élément. 
Data             Les caractères du document XML.
processing_instruction
Recevoir la notification d'une instruction de traitement. 
Target           La cible de l'instruction de traitement.
Data             Les données de l'instruction de traitement, le cas échéant.
