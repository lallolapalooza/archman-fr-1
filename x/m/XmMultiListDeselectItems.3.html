NOM

XmMultiListDeselectItems — Une fonction MultiList qui désélectionne des éléments dans la liste en faisant correspondre les entrées de colonne

SYNTAXE

#include <Xm/MultiList.h>
void XmMultiListDeselectItems(
Widget widget,
XmString item,
int column);

DESCRIPTION

XmMultiListDeselectItems désélectionne les lignes dans la liste où le numéro de colonne column correspond à item.

widget
Spécifie l'ID du widget MultiList dont l'élément est désélectionné.
item
Spécifie la chaîne XmString à utiliser comme clé de sélection.
column
Spécifie un numéro de colonne (à partir de 0) à faire correspondre, ou XmANY_COLUMN pour rechercher dans n'importe quelle colonne.

Pour une définition complète de MultiList et de ses ressources associées, voir XmMultiList(3).

LIRE AUSSI

XmMultiList(3).
