XmImSetFocusValues(appel de bibliothèque) XmImSetFocusValues(appel de bibliothèque)

NOM

XmImSetFocusValues — Une fonction du gestionnaire d'entrée qui notifie un gestionnaire d'entrée qu'un widget a reçu le focus d'entrée et met à jour les attributs du contexte d'entrée

SYNTAXE

#include <Xm/XmIm.h>
void XmImSetFocusValues(
Widget widget,
ArgList arglist,
Cardinal argcount,
);

DESCRIPTION

XmImSetFocusValues notifie le gestionnaire d'entrée que le widget spécifié a reçu le focus d'entrée. Cette fonction met également à jour les attributs du contexte d'entrée associé au widget. La fenêtre de focus pour le XIC est définie à la fenêtre du widget. L'argument arglist est une liste de paires attribut/valeur pour le contexte d'entrée. Cette fonction transmet les attributs et les valeurs à XICSetValues. L'appelant de cette routine doit passer uniquement les valeurs qui ont changé depuis le dernier appel à l'une de ces fonctions ; XmImSetValues, XmImSetFocusValues, XmImVaSetValues ou XmImVaSetFocusValues. Voir la description dans la page de référence XmImSetValues(3) pour une liste des ressources associées.

Si les paramètres précédents pour le XIC du widget ne permettent pas la réutilisation du XIC précédemment enregistré, ce XIC sera désenregistré, et un nouveau sera créé et enregistré avec le widget. Notez que le partage des données est préservé.

widget
Spécifie l'identifiant du widget enregistré auprès du gestionnaire d'entrée.
arglist
Spécifie la liste des paires attribut/valeur à passer à XICSetValues. Voir la description dans la page de manuel XmImSetValues(3) pour une description des ressources.
argcount
Spécifie le nombre de paires attribut/valeur dans la liste d'arguments (arglist)

Notez que les widgets Text et TextField appellent la fonction XmImSetFocusValues lorsqu'ils reçoivent le focus. Par conséquent, des appels supplémentaires à la fonction XmImSetFocusValues pour ces widgets sont inutiles.

CONNEXES

XmImSetValues(3), XmImVaSetFocusValues(3), et XmImVaSetValues(3).
