NOM

XmStringComponentCreate — Fonction de chaîne composite qui crée des composants arbitraires

SYNTAXE

#include <Xm/Xm.h>
XmString XmStringComponentCreate(
XmStringComponentType c_type,
unsigned int length,
XtPointer value);

DESCRIPTION

XmStringComponentCreate crée un nouveau composant XmString de type c_type, contenant value. Si value est invalide pour le type de composant particulier, cette fonction échoue et retourne NULL.

c_type
Spécifie le type de composant à créer.
length
Spécifie la longueur en octets de value. Notez qu'il doit s'agir précisément de la longueur de la chaîne value, sans inclure les éventuels caractères nuls de fin.
value
Spécifie la valeur à utiliser lors de la création du composant.

Consultez la page de référence de XmStringComponentType(3) pour une liste des types de composants XmString possibles.

VALEUR

Si value est invalide pour c_type, échoue et retourne NULL. Sinon, cette fonction retourne une nouvelle chaîne composite. Lorsque l'application n'a plus besoin de la chaîne composite retournée, l'application doit appeler XmStringFree.

VOIR AUSSI

XmString(3), XmStringGetNextTriple, XmStringComponentType, et XmStringFree(3).
