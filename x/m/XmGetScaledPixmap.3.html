XmGetScaledPixmap(appel de bibliothèque) XmGetScaledPixmap(appel de bibliothèque)

NOM

XmGetScaledPixmap — lire un fichier pixmap et le mettre à l'échelle selon la résolution du pixmap et de l'imprimante

SYNTAXE

#include <Xm/Xm.h>
XtEnum XmGetScaledPixmap(
Widget widget,
String image_name,
Pixel foreground,
Pixel background,
int depth,
Double scaling_ratio);

DESCRIPTION

XmGetScaledPixmap utilise son argument Widget pour rechercher un ancêtre Print Shell afin d'obtenir les informations sur la résolution du pixmap et la résolution par défaut de l'imprimante à utiliser si scaling_ratio ==0.

Si la mise à l'échelle est à 0, et qu'un PrintShell valide est présent, XmGetScaledPixmap applique un ratio égal à (résolution de l'imprimante / résolution par défaut du pixmap) avant de créer le Pixmap sur l'écran du widget. Sinon, le scaling_ratio est utilisé pour mettre à l'échelle les deux dimensions de l'image convertie en Pixmap.

XmGetScaledPixmap complète l'API existante XmGetPixmapByDepth en utilisant le XmNdefaultPixmapResolution du XmPrintShell racine. Se référer à la documentation de XmGetPixmapByDepth pour les détails.

widget
Widget utilisé pour déterminer la résolution par défaut du pixmap (de l'ancêtre du shell d'impression).
image_name
Voir XmGetPixmapByDepth pour la description.
foreground
Voir XmGetPixmapByDepth pour la description.
background
Voir XmGetPixmapByDepth pour la description.
depth
Voir XmGetPixmapByDepth pour la description.
scaling_ratio
Indique le ratio de mise à l'échelle à appliquer, ou 0.

VALEUR DE RETOUR

Retourne Pixmap ou NULL en cas d'échec.

ERREURS/AVERTISSEMENTS

Identiques à ceux de XmGetPixmapByDepth.

VOIR AUSSI

XmPrintSetup(3), XmPrintShell(3), XmRedisplayWidget(3)
