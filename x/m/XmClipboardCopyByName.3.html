NOM

XmClipboardCopyByName — Fonction de presse-papiers qui copie un élément de données passé par nom

SYNOPSIS

#include <Xm/CutPaste.h>
int XmClipboardCopyByName (display, window, data_id,
        buffer, length, private_id)
        Display * display;
        Window  window;
        long    data_id;
        XtPointer       buffer;
        unsigned long   length;
        long    private_id;
(void)

DESCRIPTION

XmClipboardCopyByName copie les données réelles d'un élément de données qui a été précédemment passé par nom au presse-papiers. Les données sont considérées comme passées par nom lorsqu'un appel à XmClipboardCopy est effectué avec un paramètre buffer NULL. Des appels supplémentaires à cette fonction ajoutent de nouvelles données aux données existantes.

display
Spécifie un pointeur vers la structure Display qui a été retournée lors d'un appel précédent à XOpenDisplay ou XtDisplay.
window
Spécifie l'identifiant de fenêtre d'un widget qui relie la fenêtre de l'application au presse-papiers. L'identifiant de fenêtre du widget peut être obtenu via XtWindow. La même instance d'application doit passer le même identifiant de fenêtre à chaque fonction de presse-papiers qu'elle appelle.
data_id
Spécifie un numéro d'identification attribué à l'élément de données qui identifie de manière unique l'élément de données et le format. Ce numéro a été attribué par XmClipboardCopy à l'élément de données.
buffer
Spécifie le tampon à partir duquel le presse-papiers copie les données.
length
Spécifie le nombre d'octets dans l'élément de données.
private_id
Spécifie les données privées que l'application souhaite stocker avec l'élément de données.

RETOUR

XmClipboardSuccess
La fonction a réussi.
XmClipboardLocked
La fonction a échoué car le presse-papiers était verrouillé par une autre application. L'application peut continuer à appeler la fonction à nouveau avec les mêmes paramètres jusqu'à ce que le verrouillage disparaisse. Cela donne à l'application la possibilité de demander si l'utilisateur souhaite continuer à essayer ou abandonner l'opération.

VOIR AUSSI

XmClipboardCopy(3), XmClipboardLock(3), XmClipboardStartCopy(3), et XmClipboardUnlock(3).
