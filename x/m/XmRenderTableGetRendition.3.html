NOM

XmRenderTableGetRendition — Fonction de commodité pour faire correspondre une rendition

SYNTAXE

#include <Xm/Xm.h>
XmRendition XmRenderTableGetRendition(
XmRenderTable table,
XmStringTag tag);

DESCRIPTION

XmRenderTableGetRendition recherche dans table et renvoie une copie de la rendition dont la ressource XmNtag correspond à tag. Si aucune rendition ne correspond, NULL est renvoyé. Cette fonction doit être utilisée pour une seule correspondance de rendition.

Il incombe à l'appelant de libérer la rendition renvoyée avec la fonction XmRenditionFree.

table
Spécifie la table contenant les rendus à rechercher.
tag
Spécifie le tag à rechercher.

VALEUR

Renvoie NULL s'il n'y a pas de correspondance ; sinon, cette fonction renvoie une nouvelle XmRendition.

VOIR AUSSI

XmRenderTableGetRenditions(3), XmRenderTableGetTags(3), et XmRendition(3).
