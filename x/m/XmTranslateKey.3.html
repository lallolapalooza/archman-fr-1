NOM

XmTranslateKey — Le traducteur par défaut de code clavier vers keysym

SYNTAXE

#include <Xm/Xm.h>
void XmTranslateKey(
Display *display,
KeyCode keycode,
Modifiers modifiers,
Modifiers *modifiers_return,
KeySym *keysym_return);

DESCRIPTION

XmTranslateKey est la procédure de traduction XtKeyProc par défaut pour les applications Motif. La fonction prend un code clavier et des modificateurs et renvoie le keysym correspondant.

XmTranslateKey sert deux objectifs principaux : permettre aux nouveaux traducteurs avec des fonctionnalités étendues d'obtenir la traduction par défaut de Motif code clavier-vers-keysym en plus de ce qu'ils ajoutent, et réinstaller le traducteur par défaut. Cette fonction permet d'utiliser les keysyms définis par les liaisons virtuelles Motif lorsqu'une application exige que son propre XtKeyProc soit installé.

display
Spécifie l'affichage dont provient le code clavier
keycode
Spécifie le code clavier à traduire
modifiers
Spécifie les touches modificatrices à appliquer au code clavier
modifiers_return
Spécifie un masque des touches modificatrices réellement utilisées pour générer le keysym (un ET logique de modifiers et de tout modificateur par défaut appliqué par le traducteur actuellement enregistré)
keysym_return
Spécifie un pointeur vers le keysym résultant
