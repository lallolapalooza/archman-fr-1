NOM

XmDrawnButton — Classe du widget DrawnButton

SYNOPSIS

#include <Xm/DrawnB.h>

DESCRIPTION

Le widget DrawnButton est constitué d'une fenêtre de widget vide entourée d'une bordure d'ombre. Il fournit au développeur d'applications une zone graphique qui peut avoir la sémantique d'entrée d'un PushButton.

Les types de rappels sont définis pour l'exposition du widget et le redimensionnement du widget afin de permettre à l'application de redessiner ou de repositionner ses graphiques. Si le widget DrawnButton a une épaisseur de mise en évidence et d'ombre, l'application ne doit pas dessiner dans cette zone. Pour éviter de dessiner dans la zone de mise en évidence et d'ombre, créez le contexte graphique avec un rectangle de découpage pour dessiner dans le widget. Le rectangle de découpage doit tenir compte de la taille de l'épaisseur de mise en évidence et de l'ombre du widget. DrawnButton utilise les traits XmQTmenuSystem et XmQTspecifyRenderTable, et détient le trait XmQTactivatable.

Classes

DrawnButton hérite du comportement, des ressources et des traits des classes Core, Primitive et XmLabel.

Le pointeur de classe est xmDrawnButtonWidgetClass.

Le nom de la classe est XmDrawnButton.

XmNshadowType
Décrit le style de dessin pour le DrawnButton. Cette ressource peut avoir les valeurs suivantes :
XmSHADOW_IN
Dessine le DrawnButton de sorte que l'ombre apparaisse en creux. Cela signifie que les visuels d'ombre inférieure et supérieure sont inversés.
XmSHADOW_OUT
Dessine le DrawnButton de sorte que l'ombre apparaisse en relief.
XmSHADOW_ETCHED_IN
Dessine le DrawnButton à l'aide d'une double ligne. Cela donne l'effet d'une ligne gravée dans la fenêtre. L'épaisseur de la double ligne est égale à la valeur de XmNshadowThickness.
XmSHADOW_ETCHED_OUT
Dessine le DrawnButton à l'aide d'une double ligne. Cela donne l'effet d'une ligne sortant de la fenêtre. L'épaisseur de la double ligne est égale à la valeur de XmNshadowThickness.

Description

The XmDrawnButton widget is a general-purpose button that allows the application to draw arbitrary content within its boundaries. It is derived from the XmBulletinBoard widget. This widget is useful for creating custom buttons, such as those with images or complex graphical elements. The widget handles basic button functionality, including traversal and activation. The application can then use callbacks to draw custom content within the widget's window.

Callback Information

A pointer to the following structure is passed to each callback:

typedef struct
{
        int reason;
        XEvent * event;
        Window window;
        int click_count;
} XmDrawnButtonCallbackStruct;
reason
Indicates why the callback was invoked.
event
Points to the XEvent that triggered the callback. This is NULL for XmNresizeCallback.
window
Is set to the window ID in which the event occurred.
click_count
Contains the number of clicks in the last multiclick sequence if the XmNmultiClick resource is set to XmMULTICLICK_KEEP, otherwise it contains 1. The activate callback is invoked for each click if XmNmultiClick is set to XmMULTICLICK_KEEP.

NOM

XmDrawnButton - Un bouton dessinable pour X.

SYNTAXE

#include <Xm/DrawnB.h>

DESCRIPTION

Le widget XmDrawnButton est une extension du widget XmPrimitive. Il permet de créer un bouton qui peut être utilisé pour dessiner des graphiques et des textes à l'intérieur. Il fournit des fonctionnalités similaires à celles d'un bouton poussoir mais avec la possibilité de personnaliser entièrement l'apparence du bouton grâce aux fonctions de dessin.

Ce widget prend en charge les options suivantes :

XmNactivateCallback:
Un pointeur vers une liste de callbacks à appeler lorsque le bouton est activé (par exemple, lorsque l'utilisateur clique dessus).
XmNarmCallback:
Un pointeur vers une liste de callbacks à appeler lorsque le bouton est armé (par exemple, lorsque le curseur entre dans la zone du bouton pendant une pression de bouton).
XmNdisarmCallback:
Un pointeur vers une liste de callbacks à appeler lorsque le bouton est désarmé (par exemple, lorsque l'utilisateur relâche le bouton de la souris après l'avoir pressé sur le bouton).
XmNhelpCallback:
Un pointeur vers une liste de callbacks à appeler lorsque l'aide est demandée pour ce widget.
XmNpushButtonEnabled:
Un booléen indiquant si le widget doit se comporter comme un bouton poussoir standard (avec une mise à jour de l'ombre en fonction de l'état sélectionné/non sélectionné). Si False, l'ombre est gérée par XmNshadowType.
XmNshadowType:
Le type d'ombre à afficher pour le widget. Les valeurs possibles sont XmSHADOW_IN, XmSHADOW_OUT, XmSHADOW_ETCHED_IN, XmSHADOW_ETCHED_OUT.
XmNmultiClick:
Spécifie le comportement du widget lors de clics multiples. Les valeurs possibles sont XmMULTICLICK_DISCARD (ignore les clics multiples) et XmMULTICLICK_KEEP (traite les clics multiples).

Actions par défaut

Les actions suivantes sont associées au widget XmDrawnButton par défaut :

<Btn1Up>:

<Btn1Down><Btn1Up> (double click):

Routines d'action

Les routines d'action de XmDrawnButton sont :

Activate():
Si XmNpushButtonEnabled est True, redessine l'ombre dans l'état non sélectionné ; sinon, redessine l'ombre selon XmNshadowType. Si le pointeur est à l'intérieur du DrawnButton, appelle les callbacks XmNactivateCallback.
Arm():
Si XmNpushButtonEnabled est True, redessine l'ombre dans l'état sélectionné ; sinon, redessine l'ombre selon XmNshadowType. Appelle les callbacks XmNarmCallback.
ArmAndActivate():
Si XmNpushButtonEnabled est True, redessine l'ombre dans l'état sélectionné ; sinon, redessine l'ombre selon XmNshadowType. Appelle les callbacks XmNarmCallback.
Si XmNpushButtonEnabled est True, l'ombre est redessinée dans l'état non sélectionné ; sinon, l'ombre est redessinée selon XmNshadowType. Les callbacks XmNactivateCallback et XmNdisarmCallback sont appelés. Ces actions se produisent immédiatement ou plus tard.
ButtonTakeFocus():
Permet au PushButton de prendre le focus clavier lorsque Ctrl<Btn1Down> est pressé, sans activer le widget.
Disarm():
Marque le DrawnButton comme non sélectionné et appelle les callbacks XmNdisarmCallback.
Help():
Appelle les callbacks XmNhelpCallback s'il y en a. S'il n'y a pas de callbacks d'aide pour ce widget, cette action appelle les callbacks d'aide de l'ancêtre le plus proche qui en possède.
MultiActivate():
Si XmNmultiClick est XmMULTICLICK_DISCARD, cette action ne fait rien.
Si XmNmultiClick est XmMULTICLICK_KEEP, cette action incrémente click_count dans la structure de callback. Si XmNpushButtonEnabled est True, cette action redessine l'ombre dans l'état non sélectionné ; sinon, elle redessine l'ombre selon XmNshadowType. Si le pointeur est à l'intérieur du DrawnButton, cette action appelle les callbacks XmNactivateCallback et les callbacks XmNdisarmCallback.
MultiArm():
Si XmNmultiClick est XmMULTICLICK_DISCARD, cette action ne fait rien.
Si XmNmultiClick est XmMULTICLICK_KEEP et si XmNpushButtonEnabled est True, cette action redessine l'ombre dans l'état sélectionné ; sinon, elle redessine l'ombre selon XmNshadowType et appelle les callbacks XmNarmCallback.

Comportement supplémentaire

Ce widget a le comportement supplémentaire suivant :

<EnterWindow>:
Dessine l'ombre dans son état sélectionné si XmNpushButtonEnabled est True et si le curseur quitte et rentre dans la fenêtre pendant que BSelect est pressé.
<LeaveWindow>:
Dessine l'ombre dans son état non sélectionné si XmNpushButtonEnabled est True et si le curseur quitte la fenêtre pendant que BSelect est pressé.
