NOM

XmCascadeButton — La classe de widget CascadeButton

SYNTAXE

#include <Xm/CascadeB.h>

DESCRIPTION

CascadeButton relie deux panneaux de menu ou une barre de menu à un panneau de menu.

Il est utilisé dans les systèmes de menus et doit avoir un parent RowColumn dont la ressource XmNrowColumnType est définie sur XmMENU_BAR, XmMENU_POPUP ou XmMENU_PULLDOWN.

C'est le seul widget qui peut avoir un panneau de menu déroulant attaché comme sous-menu. Le sous-menu est affiché lorsque ce widget est activé dans une barre de menu, un menu contextuel ou un menu déroulant. Ses visuels peuvent inclure une étiquette ou une pixmap et un indicateur de cascade lorsqu'il se trouve dans un panneau de menu contextuel ou déroulant ; ou il peut inclure uniquement une étiquette ou une pixmap lorsqu'il se trouve dans une barre de menu. Le positionnement du menu déroulant par rapport au CascadeButton dépend de la ressource XmNlayoutDirection du MenuShell.

Le comportement par défaut associé à un CascadeButton dépend du type de système de menu dans lequel il réside. Par défaut, BSelect contrôle le comportement du CascadeButton. De plus, BMenu contrôle le comportement du CascadeButton s'il réside dans un système de menu contextuel. Le bouton de souris réel utilisé est déterminé par son parent RowColumn. BMenu effectue également les actions BSelect dans tous les types de systèmes de menu.

Les visuels d'un CascadeButton diffèrent de la plupart des autres gadgets de bouton. Lorsque le bouton est armé, ses visuels passent d'une apparence 2D à une apparence 3D, et il affiche le sous-menu qui lui a été attaché. Si aucun sous-menu n'est attaché, il change simplement ses visuels.

Lorsqu'un CascadeButton dans un panneau de menu déroulant ou contextuel est armé à la suite du passage du pointeur de la souris sur le widget, il n'affiche pas immédiatement son sous-menu. Au lieu de cela, il attend un court laps de temps pour voir si l'armement était temporaire (c'est-à-dire que l'utilisateur passait simplement sur le widget) ou si l'utilisateur souhaitait réellement afficher le sous-menu. Ce délai est configurable à l'aide de XmNmappingDelay.

CascadeButton fournit un mécanisme unique pour activer le widget depuis le clavier. Ce mécanisme est appelé un mnémonique clavier. Si un mnémonique a été spécifié pour le widget, l'utilisateur peut activer le CascadeButton en tapant simplement le mnémonique pendant que le CascadeButton est visible. Si le CascadeButton se trouve dans une barre de menu et que la barre de menu n'a pas le focus, le modificateur MAlt doit être pressé avec le mnémonique. Les mnémoniques sont généralement utilisés pour interagir avec un menu à l'aide de l'interface clavier.

Si le CascadeButton se trouve dans un panneau de menu déroulant ou contextuel et qu'un sous-menu est attaché, les ressources XmNmarginBottom, XmNmarginLeft, XmNmarginRight et XmNmarginTop peuvent être agrandies pour accueillir XmNcascadePixmap. XmNmarginWidth est par défaut à 6 si cette ressource se trouve dans une barre de menu ; sinon, elle prend la valeur par défaut de Label, qui est 2.

CascadeButton utilise les traits XmQTmenuSystem et XmQTspecifyRenderTable.

Classes

CascadeButton hérite du comportement, des ressources et des traits des classes Core, XmPrimitive et XmLabel.

Le pointeur de classe est xmCascadeButtonWidgetClass.

Le nom de la classe est XmCascadeButton.

XmNactivateCallback
Spécifie la liste des callbacks appelés lorsque l'utilisateur active le widget CascadeButton et qu'aucun sous-menu n'est attaché pour être affiché. L'activation se produit lorsqu'un bouton de souris est relâché ou lorsque le mnémonique associé au widget est tapé. Le bouton de souris spécifique dépend des informations du parent RowColumn. La raison envoyée par le callback est XmCR_ACTIVATE.
XmNcascadePixmap
Spécifie la pixmap de cascade affichée à une extrémité du widget lorsqu'un CascadeButton est utilisé dans un panneau de menu contextuel ou déroulant et qu'un sous-menu est attaché. Les ressources de classe Label XmNmarginBottom, XmNmarginLeft, XmNmarginRight et XmNmarginTop peuvent être modifiées pour garantir qu'il y a de la place pour la pixmap de cascade. La pixmap de cascade par défaut est une flèche pointant vers le côté du menu où le sous-menu apparaîtra. Le positionnement de la pixmap de cascade à gauche ou à droite du widget, et la direction de la flèche, dépendent de la ressource XmNlayoutDirection du MenuShell.
XmNcascadingCallback
Spécifie la liste des callbacks appelés juste avant le mappage du sous-menu associé au CascadeButton.
La raison envoyée par le rappel est XmCR_CASCADING.
XmNmappingDelay
Spécifie le temps, en millisecondes, entre le moment où un CascadeButton devient armé et le moment où il affiche son sous-menu. Ce délai est utilisé uniquement lorsque le widget se trouve dans un menu contextuel ou déroulant. La valeur ne doit pas être négative.
XmNsubMenuId
Spécifie l'identifiant du widget pour le menu déroulant à associer à ce CascadeButton. Le menu spécifié est affiché lorsque le CascadeButton devient armé. Le menu doit avoir été créé avec la hiérarchie appropriée en fonction du type de menu utilisé. Voir XmCreateMenuBar(3), XmCreatePulldownMenu(3), et XmCreatePopupMenu(3) pour plus d'informations sur les systèmes de menus.

NAME

XmCascadeButton - A cascade button widget that installs a Tear Off Menu Pane or Popup Menu Pane.

SYNTAX

WidgetClass
xmCascadeButtonWidgetClass
Include file
/usr/include/Xm/CascadeB.h

DESCRIPTION

The XmCascadeButton widget is a button that installs a Tear Off Menu Pane or a Popup Menu Pane. It is used to create a menu bar and cascade menus. The cascade button is part of the menu bar and is typically placed in a row of other cascade buttons. When the cascade button is activated, it pops up a menu pane. This menu pane can be a tear-off menu pane, which can be moved to a different location on the screen, or a standard popup menu pane.

The cascade button must be a child of a XmRowColumn widget that is in the XmMENU_BAR, XmMENU_POPUP, or XmMENU_PULLDOWN widget.

NOM

XmCascadeButton — Le widget XmCascadeButton

SYNTAXIS

#include <Xm/CascadeB.h>

DESCRIPTION

Le widget XmCascadeButton est un bouton qui, lorsqu'il est activé, affiche un sous-menu associé. Le widget XmCascadeButton est un widget de conteneur qui a une seule partie enfant. L'enfant est généralement un widget XmRowColumn configuré pour agir comme un menu.

CALLBACKS

Le widget XmCascadeButton appelle les routines de rappel suivantes et leur fournit les arguments suivants :

XmNactivateCallback:
Appelé lorsque le bouton est activé par un clic de souris ou en appuyant sur la touche Espace ou Retour. Les données de rappel sont un XmActivationCallbackStruct.
XmNcascadingCallback:
Appelé lorsque le sous-menu associé au bouton est sur le point d'être affiché. Les données de rappel sont un XmCascadingCallbackStruct.
XmNhelpCallback:
Appelé lorsque le widget doit fournir une aide. Les données de rappel sont un XmHelpCallbackStruct.

Pour plus d'informations sur chaque rappel, voir XmCascadeButton(3).

REPRESENTATION TYPES

Le widget XmCascadeButton a les types de représentation suivants :

XmNlabelString:
Le texte ou le motif affiché sur le bouton.
XmNmnemonic:
Une touche de raccourci pour activer le bouton.
XmNsubLabelString:
Le texte ou le motif affiché sur le bouton.
XmNuserData:
Données utilisateur associées au widget.

ACTION ROUTINES

Le widget XmCascadeButton a les routines d'action suivantes :

Arm():
Affiche le sous-menu associé au bouton.
Disarm():
Masque le sous-menu associé au bouton.
Activate():
Appelle les rappels XmNactivateCallback et affiche le sous-menu associé.
MenuBarActivate():
Appelle les rappels XmNactivateCallback et affiche le sous-menu associé.
CheckDisarm():
Vérifie si le sous-menu doit être masqué.
MenuButtonTakeFocus():
Donne le focus au bouton.
MenuButtonTakeFocusUp():
Donne le focus au bouton lorsque le bouton de la souris est relâché.
ProcessDrag():
Traite l'événement de glissement.
StartDrag():
Commence un événement de glissement.
DoSelect():
Sélectionne le bouton.
KeySelect():
Sélectionne le bouton en utilisant le clavier.
Help():
Appelle la routine d'aide.
CleanupMenuBar():
Nettoie la barre de menu.

ROUTINES D'ACTION

Les routines d'action de XmCascadeButton sont

CleanupMenuBar():
Dans une barre de menu, désarme le CascadeButton et le menu et, lorsque la politique de focus clavier du shell est XmEXPLICIT, restaure le focus clavier sur le widget qui avait le focus avant l'entrée dans le menu.
Dans un menu déroulant de premier niveau à partir d'une barre de menu, dépublie le menu, désarme le CascadeButton de la barre de menu et la barre de menu, et, lorsque la politique de focus clavier du shell est XmEXPLICIT, restaure le focus clavier sur le widget qui avait le focus avant l'entrée dans la barre de menu. Dans les autres menus déroulants, dépublie le menu.
Dans un menu contextuel, dépublie le menu et, lorsque la politique de focus clavier du shell est XmEXPLICIT, restaure le focus clavier sur le widget à partir duquel le menu a été affiché.
DoSelect():
Appelle les rappels dans XmNcascadingCallback, affiche le sous-menu attaché au CascadeButton et active la navigation au clavier dans le menu. Si le CascadeButton n'a pas de sous-menu attaché, cette action appelle les rappels dans XmNactivateCallback, active le CascadeButton et dépublie tous les menus affichés dans la cascade.
Help():
Dépublie tous les menus de la hiérarchie de menus et, lorsque la politique de focus clavier du shell est XmEXPLICIT, restaure le focus clavier sur le widget qui avait le focus avant l'entrée dans le système de menus. Appelle les rappels pour XmNhelpCallback s'il en existe. S'il n'y a pas de rappels d'aide pour ce widget, cette action appelle les rappels d'aide de l'ancêtre le plus proche qui en a.
KeySelect():
Appelle les rappels dans XmNcascadingCallback, et affiche le sous-menu attaché au CascadeButton si la navigation au clavier est activée dans le menu. Si le CascadeButton n'a pas de sous-menu attaché, cette action appelle les rappels dans XmNactivateCallback, active le CascadeButton et dépublie tous les menus affichés dans la cascade.
MenuBarSelect():
Dépublie tous les menus affichés par le menu parent. Arme à la fois le CascadeButton et la barre de menu, affiche le sous-menu associé et active la navigation à la souris. Si le menu est déjà actif, cet événement désactive la navigation au clavier pour le menu et renvoie le menu en mode de navigation à la souris.
StartDrag():
Arme le CascadeButton, affiche le sous-menu associé et active la navigation à la souris. Si le menu est déjà actif, cet événement désactive la navigation au clavier pour le menu et renvoie le menu en mode de navigation à la souris.

COMPORTEMENT ADDITIONNEL

L'affichage d'un sous-menu appelle les rappels XmNcascadingCallback. Ce widget a le comportement supplémentaire suivant :

<EnterWindow>:
Si la navigation au clavier est activée, ne fait rien. Sinon, dans une barre de menu armée, dépublie les MenuPanes associés à une autre entrée de barre de menu, arme le CascadeButton et affiche le sous-menu associé. Dans les autres menus, arme le CascadeButton et affiche le sous-menu associé après le délai spécifié par XmNmappingDelay.
<LeaveWindow>:
Si la navigation au clavier est activée, ne fait rien. Sinon, dans une barre de menu armée, désarme le CascadeButton si le sous-menu associé au CascadeButton n'est pas actuellement affiché ou s'il n'y a pas de sous-menu associé au CascadeButton.
Dans les autres menus, si le pointeur se déplace n'importe où sauf dans un sous-menu associé au CascadeButton, le CascadeButton est désarmé et son sous-menu est dépublié.
