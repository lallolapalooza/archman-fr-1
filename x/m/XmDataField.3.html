NOM

XmDataField — La classe de widget DataField

SYNTAXE

#include <Xm/DataF.h>

DESCRIPTION

Le widget DataField est un widget de présentation de données qui gère l'affichage et la saisie de données sous forme de texte. Le widget DataField est une sous-classe du widget XmTextField destiné aux applications de saisie de données. En plus de toutes les fonctionnalités normales de XmTextField, il prend en charge l'analyse basée sur des expressions régulières et l'acceptation/le rejet de ses entrées via la ressource XmNpicture, et le positionnement à droite via la ressource XmNalignment.

Le widget DataField offre des capacités supplémentaires en prenant en charge plusieurs types de validation : un widget DataField contenant une valeur invalide ne cédera pas le focus ; l'utilisateur doit entrer une valeur correcte avant de passer à un autre champ.

Classes

DataField hérite du comportement, des ressources et des traits de Core, XmPrimitive et XmTextField.

Le pointeur de classe est xmDataFieldWidgetClass.

Le nom de la classe est XmDataField.

Nouvelles ressources

Le tableau suivant définit un ensemble de ressources de widget utilisées par le programmeur pour spécifier les données. Le programmeur peut également définir les valeurs des ressources pour les classes héritées afin de définir les attributs de ce widget. Pour référencer une ressource par nom ou par classe dans un fichier .Xdefaults, supprimez le préfixe XmN ou XmC et utilisez les lettres restantes. Pour spécifier l'une des valeurs définies pour une ressource dans un fichier .Xdefaults, supprimez le préfixe Xm et utilisez les lettres restantes (en minuscules ou en majuscules, mais incluez les éventuels tirets bas entre les mots). Les codes dans la colonne d'accès indiquent si la ressource donnée peut être définie au moment de la création (C), définie en utilisant XtSetValues (S), récupérée en utilisant XtGetValues (G), ou si elle n'est pas applicable (N/A).

XmNalignment
Lorsqu'il est défini sur XmALIGNMENT_END, le widget aligne tout son texte sur le côté droit de la zone de saisie.
XmNautoFill
Lorsqu'il est défini sur True, le widget "remplit automatiquement" son contenu lorsqu'il peut déterminer que le caractère suivant de la chaîne doit être un littéral particulier. Par exemple, l'image "###-####" insère automatiquement un caractère '-' après avoir reçu trois chiffres numériques en entrée.
XmNpicture
Spécifie une image pour la saisie de données dans le widget. Une image sert de modèle qui formate la valeur que vous entrez dans un champ. Un exemple serait l'image du numéro de téléphone américain : (###)###-####. L'image est utilisée pour convertir les caractères saisis dans le champ en une valeur formatée.
Interprétations des caractères

La liste suivante définit les caractères que vous pouvez utiliser dans une image et comment le widget DataField les interprète.

#
N'importe quel chiffre numérique
?
Lettre insensible à la casse
&
Lettre majuscule (force les minuscules en majuscules)
@
Caractère insensible à la casse
!
Caractère majuscule
;
Interpréter le caractère suivant littéralement
*
Répéter le caractère suivant un certain nombre de fois
[]
Les caractères entre crochets sont facultatifs
{}
Les caractères entre accolades sont regroupés
,
Valeurs alternatives
Les autres caractères sont interprétés littéralement.
Définissez XmNpicture sur NULL pour désactiver le traitement par expressions régulières. Le widget DataField est effacé chaque fois que la ressource XmNpicture est modifiée.
XmNpictureErrorCallback
Spécifie une liste de rappels à appeler lorsque le widget XmDataField détermine que des données sont saisies qui ne correspondent pas au format spécifié par la ressource XmNpicture.
XmNvalidateCallback
Spécifie une liste de rappels à appeler lorsque des données ont été saisies dans le widget XmDataField et que l'utilisateur a quitté le widget XmDataField (généralement en appuyant sur la touche Tab). Les rappels peuvent rejeter le déplacement du focus.

FONCTIONS SÉPARÉES

Le widget DataField n'exporte aucune fonction séparée.

CRÉATION DE WIDGET

La création d'une instance de ce widget nécessite l'appel à la fonction XtCreateWidget, en utilisant le nom de la classe XmDataField et la classe de widget xmDataFieldWidgetClass.

Widget xmDataField;
    xmDataField = XtCreateWidget(
        "dataFieldWidgetName",
        xmDataFieldWidgetClass,
        parentWidget,
        args,
        num_args);

Routines de rappel

Un pointeur vers la structure suivante est passé à la liste des routines pour XmNvalidateCallback :

XmDataFieldCallbackStruct(3)

NAME

XmDataFieldCallbackStruct — Callback structure for the XmDataField widget

SYNOPSIS

typedef struct _XmDataFieldCallbackStruct {
	Widget   w;       /* The XmDataField */   
	String   text;    /* Proposed string */   
	Boolean  accept;  /* Accept return value, for validation */
} XmDataFieldCallbackStruct;

DESCRIPTION

The XmDataFieldCallbackStruct is used by callbacks associated with the XmDataField widget.

  • w : Specifies the XmDataField widget that triggered the callback.

  • text : Contains the proposed string for the XmDataField. Callbacks can modify this string to suggest an alternative value.

  • accept : A Boolean value that the callback can set to indicate whether the proposed string should be accepted. Setting it to False rejects the string.

Callback Routines

The following callback resources use this structure:

XmNmodifyTextCallback
This callback is invoked when the text in the XmDataField widget is modified but before the modification is applied. It allows for real-time validation and modification of the input text.
XmNvalidateTextCallback
This callback is invoked when the XmDataField widget loses focus or when the user attempts to commit the text change. It provides a final opportunity to validate the input text.
