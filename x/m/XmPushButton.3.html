NOM

XmPushButton — Classe du widget PushButton

SYNTAXE

#include <Xm/PushB.h>

DESCRIPTION

PushButton émet des commandes dans une application. Il se compose d'une étiquette texte ou d'une pixmap entourée d'une ombre de bordure. Lorsqu'un PushButton est sélectionné, l'ombre change pour donner l'apparence qu'il a été enfoncé. Lorsqu'un PushButton est désélectionné, l'ombre change pour donner l'apparence qu'il est sorti.

Le comportement par défaut associé à un PushButton dans un menu dépend du type de système de menu dans lequel il réside. Par défaut, <Btn1> contrôle le comportement du PushButton. De plus, <Btn3> contrôle le comportement du PushButton s'il réside dans un système PopupMenu. Le bouton de souris réellement utilisé est déterminé par son parent RowColumn.

L'épaisseur d'une seconde ombre, utilisée lorsque le PushButton est le bouton par défaut, peut être spécifiée avec la ressource XmNshowAsDefault. Si elle a une valeur non nulle, les ressources XmNmarginLeft, XmNmarginRight, XmNmarginTop et XmNmarginBottom du Label peuvent être modifiées pour accueillir la seconde ombre.

Si une valeur initiale est spécifiée pour XmNarmPixmap mais pas pour XmNlabelPixmap, la valeur de XmNarmPixmap est utilisée pour XmNlabelPixmap.

PushButton utilise les traits XmQTmenuSystem et XmQTspecifyRenderTable, et détient les traits XmQactivatable, XmQTmenuSavvy et XmQTtakesDefault.

Classes

PushButton hérite du comportement, des ressources et des traits de Core, XmPrimitive et XmLabel.

Le pointeur de classe est xmPushButtonWidgetClass.

Le nom de la classe est XmPushButton.

RESOURCES

The following resources are specific to the PushButton widget. Refer to the XmLabel(3) and Core(3) reference pages for a description of the resources inherited by PushButton.

XmNarmColor
Specifies the background color of the PushButton when it is armed. For a color display, the color is between the background and the bottom shadow color. For a monochrome display, the default is set to the foreground color, and any text in the label appears in the background color when the button is armed.
This resource is also used when the button is armed in a menu and the XmNenableEtchedInMenu resource is True.
XmNarmPixmap
Specifies the pixmap to be used as the button face if XmNlabelType is XmPIXMAP or XmPIXMAP_AND_STRING and PushButton is armed. This resource is disabled when the PushButton is in a menu.
XmNdefaultButtonShadowThickness
This resource specifies the width of the default button indicator shadow. If this resource is 0 (zero), the width of the shadow comes from the value of the XmNshowAsDefault resource. If this resource is greater than 0, the XmNshowAsDefault resource is only used to specify whether this button is the default. The default value is the initial value of XmNshowAsDefault.
XmNdisarmCallback
Specifies the list of callbacks that is called when PushButton is disarmed. PushButton is disarmed when the user presses and releases the active mouse button while the pointer is inside that widget. For this callback, the reason is XmCR_DISARM.
XmNfillOnArm
Forces the PushButton to fill the background of the button with the color specified by XmNarmColor when the button is armed and when this resource is set to True. If False, only the top and bottom shadow colors are switched. When the PushButton is in a menu, this resource is ignored and assumed to be False.
XmNmultiClick
If a button click is followed by another button click within the time span specified by the display's multiclick time, and this resource is set to XmMULTICLICK_DISCARD, do not process the second click. If this resource is set to XmMULTICLICK_KEEP, process the event and increment click_count in the callback structure. When the button is in a menu, the default is XmMULTICLICK_DISCARD; otherwise, for a button not in a menu, XmMULTICLICK_KEEP is the default value.
XmNshowAsDefault
If XmNdefaultButtonShadowThickness is greater than 0 (zero), a value greater than 0 in this resource specifies to mark this button as the default button. If XmNdefaultButtonShadowThickness is 0, a value greater than 0 in this resource specifies to mark this button as the default button with the shadow thickness specified by this resource. When the Display resource XmNdefaultButtonEmphasis has a value of XmEXTERNAL_HIGHLIGHT (the default), PushButton draws the location cursor outside of the outer shadow. When this resource has a value of XmINTERNAL_HIGHLIGHT, the highlight is drawn between the inner and outer shadows. The space between the shadow and the default shadow is equal to the sum of both shadows. The default value is 0. When this value is not 0, the Label resources XmNmarginLeft, XmNmarginRight, XmNmarginTop, and XmNmarginBottom may be modified to accommodate the second shadow. This resource is disabled when the PushButton is in a menu.

XmPushButton - PushButton widget

The XmPushButton widget provides a simple pushbutton that invokes a specified application callback when activated.

SYNTAX

   typedef struct _XmPushButtonCallbackStruct {
            int reason;
            XEvent *event;
            int click_count;
   } XmPushButtonCallbackStruct;

DESCRIPTION

The XmPushButton widget is a control that allows the user to directly manipulate it to produce a specified response. Activating the XmPushButton invokes a callback routine that was registered by the application. The widget is typically used to trigger discrete actions, such as updating a dialog, applying changes, or canceling an operation.

The XmPushButton widget supports the XmNlabelString resource, which allows for the display of text or pixmaps. It also supports resources for controlling its appearance, such as XmNshadowThickness and XmNarmColor.

The widget's behavior can be customized through various callbacks, including XmNactivateCallback, XmNarmCallback, and XmNdisarmCallback.

The XmPushButton widget inherits from the XmLabel widget and the XmPrimitive widget class.

This widget can also be used in a menu system. In this context, it functions as a cascade button or a simple menu item. When used in a menu, its appearance and behavior might differ slightly to conform to menu conventions.

WIDGET RELATIONSHIP

XmPushButton
   |
   +-- XmDrawnButton

The XmPushButton widget is a subclass of XmLabel.

The XmPushButton widget is a subclass of XmPrimitive.

CALLBACKS INFORMATION

A pointer to the following structure is passed to each callback:

typedef struct
{
        int reason;
        XEvent * event;
        int click_count;
} XmPushButtonCallbackStruct;
reason
Indicates why the callback was invoked. For XmPushButton, the following reasons are defined:
XmCR_ACTIVATE: The button was activated.
XmCR_ARM: The button was armed.
XmCR_DISARM: The button was disarmed.
XmCR_HELP: The Help key was invoked for the button.
event
Points to the XEvent that triggered the callback. This may be NULL if the event is not relevant.
click_count
This value is valid only when the reason is XmCR_ACTIVATE. It contains the number of clicks in the last multiclick sequence if the XmNmultiClick resource is set to XmMULTICLICK_KEEP, otherwise it contains 1. The activate callback is invoked for each click if XmNmultiClick is set to XmMULTICLICK_KEEP.

ACTION ROUTINES

The XmPushButton action routines are

Activate():
This action draws the shadow in the unarmed state. If the button is not in a menu and if XmNfillOnArm is set to True, the background color reverts to the unarmed color. If XmNlabelType is XmPIXMAP or XmPIXMAP_AND_STRING, XmNlabelPixmap is used for the button face. If the pointer is still within the button, this action calls the callbacks for XmNactivateCallback.
Arm():
This action arms the PushButton. It draws the shadow in the armed state. If the button is not in a menu and if XmNfillOnArm is set to True, it fills the button with the color specified by XmNarmColor. If XmNlabelType is XmPIXMAP or XmPIXMAP_AND_STRING, the XmNarmPixmap is used for the button face. It calls the XmNarmCallback callbacks.
ArmAndActivate():
In a menu, unposts all menus in the menu hierarchy and, unless the button is already armed, calls the XmNarmCallback callbacks. This action calls the XmNactivateCallback and XmNdisarmCallback callbacks.
Outside a menu, draws the shadow in the armed state and, if XmNfillOnArm is set to True, fills the button with the color specified by XmNarmColor. If XmNlabelType is XmPIXMAP or XmPIXMAP_AND_STRING, XmNarmPixmap is used for the button face. This action calls the XmNarmCallback callbacks.
Outside a menu, this action also arranges for the following to happen, either immediately or at a later time: the shadow is drawn in the unarmed state and, if XmNfillOnArm is set to True, the background color reverts to the unarmed color. If XmNlabelType is XmPIXMAP or XmPIXMAP_AND_STRING, XmNlabelPixmap is used for the button face. The XmNactivateCallback and XmNdisarmCallback callbacks are called.
BtnDown():
This action unposts any menus posted by the PushButton's parent menu, disables keyboard traversal for the menu, and enables mouse traversal for the menu. It draws the shadow in the armed state and, unless the button is already armed, calls the XmNarmCallback callbacks.
BtnUp():
This action unposts all menus in the menu hierarchy and activates the PushButton. It calls the XmNactivateCallback callbacks and then the XmNdisarmCallback callbacks.
ButtonTakeFocus():
Causes the PushButton to take keyboard focus when Ctrl<Btn1Down> is pressed, without activating the widget.
Disarm():
Calls the callbacks for XmNdisarmCallback.
Help():
In a Pulldown or Popup MenuPane, unposts all menus in the menu hierarchy and, when the shell's keyboard focus policy is XmEXPLICIT, restores keyboard focus to the widget that had the focus before the menu system was entered. This action calls the callbacks for XmNhelpCallback if any exist. If there are no help callbacks for this widget, this action calls the help callbacks for the nearest ancestor that has them.
MenuShellPopdownOne():
In a top-level Pulldown MenuPane from a MenuBar, unposts the menu, disarms the MenuBar CascadeButton and the MenuBar; and, when the shell's keyboard focus policy is XmEXPLICIT, restores keyboard focus to the widget that had the focus before the MenuBar was entered. In other Pulldown MenuPanes, it unposts the menu.
In a Popup MenuPane, this action unposts the menu and restores keyboard focus to the widget from which the menu was posted.
MultiActivate():
If XmNmultiClick is XmMULTICLICK_DISCARD, this action does nothing.
If XmNmultiClick is XmMULTICLICK_KEEP, this action increments click_count in the callback structure and draws the shadow in the unarmed state. If the button is not in a menu and if XmNfillOnArm is set to True, the background color reverts to the unarmed color. If XmNlabelType is XmPIXMAP, the XmNlabelPixmap is used for the button face. If the pointer is within the PushButton, calls the callbacks for XmNactivateCallback and XmNdisarmCallback.
MultiArm():
If XmNmultiClick is XmMULTICLICK_DISCARD, this action does nothing.
If XmNmultiClick is XmMULTICLICK_KEEP, this action draws the shadow in the armed state. If the button is not in a menu and if XmNfillOnArm is set to True, this action fills the button with the color specified by XmNarmColor. If XmNlabelType is XmPIXMAP, the XmNarmPixmap is used for the button face.

NAME

XmPushButton - une spécification du widget PushButton

SYNOPSIS

#include <Xm/PushB.h>

Le widget PushButton crée un bouton. Lorsqu'il est activé, il exécute une fonction de rappel définie par le développeur. Le widget PushButton est un sous-module du widget Primitive.

Ce widget prend en charge les options suivantes :

XmNactivateCallback
Une liste de rappels à exécuter lorsqu'une activation se produit. Une activation se produit lorsque le bouton est relâché alors que le curseur est au-dessus du bouton.
XmNarmCallback
Une liste de rappels à exécuter lorsqu'un événement arm prend place. Un événement arm se produit lorsque le curseur entre dans la fenêtre du bouton et que le bouton est déjà enfoncé.
XmNdisarmCallback
Une liste de rappels à exécuter lorsqu'un événement disarm prend place. Un événement disarm se produit lorsque le curseur quitte la fenêtre du bouton alors que le bouton est enfoncé.
XmNlabelInsensitivePixmap
Une pixmap à utiliser lorsque le bouton est désactivé.
XmNlabelPixmap
Une pixmap à utiliser comme image du bouton.
XmNlabelString
Une chaîne de caractères à utiliser comme image du bouton.
XmNlabelType
Indique si le label est une chaîne de caractères ou une pixmap. Les valeurs possibles sont XmSTRING ou XmPIXMAP.
XmNpushButtonChildType
Indique le type d'enfant. La seule valeur valide est XmLABEL.
XmNshadowThickness
L'épaisseur de l'ombre du bouton.
XmNtopShadowPixmap
Une pixmap pour l'ombre supérieure.
XmNbottomShadowPixmap
Une pixmap pour l'ombre inférieure.
XmNtopShadowStip
Un motif pour l'ombre supérieure.
XmNbottomShadowStip
Un motif pour l'ombre inférieure.
XmNfillOnArm
Un indicateur booléen qui, s'il est vrai, remplit le bouton avec XmNarmColor lorsqu'il est armé.
XmNarmColor
La couleur utilisée pour remplir le bouton lorsqu'il est armé.

Les callbacks pour l'activation, l'armement et le désarmement reçoivent un pointeur vers une structure XmPushButtonCallbackStruct.

reason
Indique la raison de l'appel de rappel. Les valeurs possibles sont XmCR_ACTIVATE, XmCR_ARM ou XmCR_DISARM.
event
Un pointeur vers l'événement X qui a déclenché le rappel.

DESCRIPTION

Le widget XmPushButton crée un bouton qui peut être utilisé dans une application Motif. Le bouton peut contenir une chaîne de caractères ou une pixmap. Lorsqu'il est activé, le bouton exécute une ou plusieurs fonctions de rappel définies par le développeur.

Les actions suivantes sont associées au widget PushButton :

Arm
Si le curseur entre dans la fenêtre du bouton alors que le bouton est déjà enfoncé, l'ombre est dessinée dans l'état armé. Si XmNfillOnArm est défini sur True, le bouton est rempli avec la couleur spécifiée par XmNarmColor. Si XmNlabelType est XmPIXMAP ou XmPIXMAP_AND_STRING, le XmNarmPixmap est utilisé pour la face du bouton. Cette action appelle les rappels XmNarmCallback.
Disarm
Si le curseur quitte la fenêtre du bouton alors que le bouton est enfoncé, l'ombre est dessinée dans l'état désarmé. Si XmNfillOnArm est défini sur True, la couleur de fond revient à la couleur de l'état non armé. Si XmNlabelType est XmPIXMAP ou XmPIXMAP_AND_STRING, le XmNlabelPixmap est utilisé pour la face du bouton. Cette action appelle les rappels XmNdisarmCallback.
Activate
Si le bouton de la souris est relâché alors que le curseur est sur le bouton, le bouton est activé. Cette action appelle les rappels XmNactivateCallback.
ProcessDrag():
Fait glisser le contenu d'une étiquette de bouton PushButton, identifié lorsque BTransfer est pressé. Cette action définit le XmNconvertProc du DragContext sur une fonction qui appelle les procédures XmNconvertCallback, potentiellement plusieurs fois, pour la sélection _MOTIF_DROP. Cette action est indéfinie pour les boutons PushButtons utilisés dans un système de menu.

Comportement supplémentaire

Ce widget a le comportement supplémentaire suivant :

<EnterWindow>:
Dans un menu, si la traversée au clavier est activée, cette action ne fait rien. Sinon, elle dessine l'ombre dans l'état armé et appelle les rappels XmNarmCallback.
Si le PushButton n'est pas dans un menu et que le curseur quitte puis rentre dans la fenêtre du PushButton alors que le bouton est pressé, cette action dessine l'ombre dans l'état armé. Si XmNfillOnArm est défini sur True, elle remplit également le bouton avec la couleur spécifiée par XmNarmColor. Si XmNlabelType est XmPIXMAP ou XmPIXMAP_AND_STRING, XmNarmPixmap est utilisé pour la face du bouton.
<LeaveWindow>:
Dans un menu, si la traversée au clavier est activée, cette action ne fait rien. Sinon, elle dessine l'ombre dans l'état non armé et appelle les rappels XmNdisarmCallback.
Si le PushButton n'est pas dans un menu et que le curseur quitte la fenêtre du PushButton alors que le bouton est pressé, cette action dessine l'ombre dans l'état non armé. Si XmNfillOnArm est défini sur True, la couleur de fond revient à la couleur de l'état non armé. Si XmNlabelType est XmPIXMAP ou XmPIXMAP_AND_STRING, le XmNlabelPixmap est utilisé pour la face du bouton.

Bindings virtuels

Les liaisons pour les touches virtuelles sont spécifiques au vendeur. Pour plus d'informations sur les liaisons pour les boutons et touches virtuels, voir VirtualBindings(3).
