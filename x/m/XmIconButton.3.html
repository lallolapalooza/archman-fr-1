XmIconButton(3X) XmIconButton(3X)

NOM

Le widget Bouton Icône

SYNOPIS

Décrit le widget XmIconButton

DESCRIPTION

Le widget Bouton Icône est une zone sélectionnable de l'écran qui contient à la fois une étiquette et une chaîne de caractères. Lorsque l'utilisateur sélectionne ce bouton avec le bouton de sélection OSF/Motif, son activateCallback est appelé. Ce widget peut également être utilisé comme un bouton bascule, bien qu'il n'aura pas d'indicateur. La position de l'icône par rapport au texte peut être modifiée en utilisant la ressource iconPlacement.

Remarque : Ce widget accepte une chaîne de caractères comme étiquette, pas une XmString, il n'est donc pas nécessaire d'utiliser XmStringCreate pour obtenir une chaîne correctement formatée. Le texte internationalisé n'est pas actuellement pris en charge.

Tous les noms de ressources commencent par XmN et tous les noms de classes de ressources commencent par XmC.

activateCallback

Cette liste de routines de rappel est appelée chaque fois que le bouton icône est cliqué par l'utilisateur. Le format des routines de rappel est spécifié ci-dessous.

armColor

Ceci est l'indice de pixel qui décrit la couleur à utiliser pour remplir le widget lorsqu'il est activé.

doubleClickCallback

Cette liste de routines de rappel est appelée chaque fois que l'utilisateur double-clique sur ce widget. Le format des routines de rappel est spécifié ci-dessous.

fontList

La police par défaut dans cette liste est utilisée pour rendre la chaîne d'étiquette du bouton icône.

horizontalMargin

verticalMargin

La quantité d'espace laissée entre le bord de l'ombre et le texte ou le pixmap affiché. L'espacement vertical et horizontal peut être contrôlé indépendamment.

iconTextPadding

La quantité d'espace laissée entre le pixmap et la chaîne d'étiquette.

iconPlacement

L'emplacement du pixmap (icône) par rapport au texte affiché. Cette ressource peut prendre l'une des valeurs suivantes : XmIconTop, XmIconBottom, XmIconLeft, XmIconRight, XmIconNone, et XmIconOnly. Un convertisseur de type a été enregistré qui convertit les chaînes suivantes : "top", "bottom", "left", "right", "none", et "iconOnly".

Si seule une chaîne est affichée dans le Bouton Icône, cette ressource peut être utilisée pour modifier la justification de l'étiquette. XmIconTop=bottom, XmIconBottom=top, XmIconRight=Left, XmIconLeft=Right, XmIconNone=Center. Pour utiliser ces options, pixmap doit être défini sur None.

label

La chaîne à afficher dans ce bouton. Cette chaîne ne peut avoir qu'une seule police, mais peut être longue de plusieurs lignes. Utilisez le caractère NOUVELLE_LIGNE ( '0 ) pour séparer les lignes. Cette ressource a été remplacée par labelString, mais est incluse pour des raisons de compatibilité ascendante. Si XmNlabelString est défini, XmNlabel est ignoré

labelString

Spécifie la chaîne composée à afficher dans le bouton. Si cette valeur est NULL, la valeur de XmNlabel est utilisée. Si les deux sont NULL, labelString est initialisée en convertissant le nom du widget en une chaîne composée. Reportez-vous à XmString(3X) dans le Manuel du Programmeur OSD/Motif pour plus d'informations sur la création et la structure des chaînes composées.

pixmap

Le pixmap à afficher. Ce pixmap peut être de profondeur un (1), ou de la même profondeur que l'écran sur lequel ce widget est affiché. Si le pixmap est de profondeur un, alors XCopyPlane est utilisé pour rendre le pixmap avec les couleurs de premier plan et d'arrière-plan. Si le pixmap n'est pas de profondeur un, alors XCopyArea est utilisé et toutes les couleurs d'origine du pixmap sont préservées. Contrairement au widget PushButton de Motif, le pixmap est automatiquement tramé lorsque le Bouton Icône devient insensible.

recomputeSize

Si cette valeur booléenne est True, le bouton icône demandera à son parent de le redimensionner pour qu'il soit juste assez grand pour contenir le pixmap, l'étiquette et les ombres. S'il est False, le bouton icône ne tentera pas de redimensionnement.

set

Cette valeur booléenne représente l'état actuel du bouton icône. Si cette valeur est True, le bouton icône est activé et rendu comme enfoncé. Sinon, il est désactivé et rendu normalement.

stringDirection

Spécifie la direction dans laquelle la chaîne doit être dessinée. XmNSTRING_DIRECTION_L_TO_R est dessinée de gauche à droite, tandis que XmNSTRING_DIRECTION_R_TO_L est dessinée de droite à gauche. La valeur par défaut pour cette ressource est déterminée au moment de la création. Si aucune valeur n'est spécifiée pour cette ressource et que le parent du widget est un gestionnaire, la valeur est héritée du parent ; sinon, elle prend par défaut XmNSTRING_DIRECTION_L_TO_R.

Routines de Rappel

Chaque fois que l'utilisateur sélectionne le bouton icône, les rappels d'activation seront appelés. Chaque fois que l'utilisateur double-clique sur ce widget, le premier clic appellera l'activateCallback, et si le second se produit dans le délai MultiClickTime, il appellera le doubleClickCallback. Ces rappels ont les paramètres suivants :

void (activate_callback)(Widget w, XtPointer client_data, XtPointer call_data)

w le widget Bouton Icône

client_data les données client spécifiées par l'application

call_data un pointeur vers une structure XmIconButtonCallbackInfo

void (double_click_callback)(Widget w, XtPointer client_data, XtPointer call_data)

w le widget Bouton Icône

client_data les données client spécifiées par l'application

call_data un pointeur vers une structure XmIconButtonCal

XmIconButton(3) — Documentation Arch Linux

Nom

XmIconButton — un widget de bouton icône

Syntaxe

#include <Xm/Xm.h>
#include <Xm/Xm.h>

Description

Le widget XmIconButton est un bouton qui peut avoir une icône ou une chaîne de caractères à côté de l'icône. Ce widget est un widget générique qui peut être utilisé comme un bouton poussoir ou comme un bouton à bascule. L'apparence du widget est définie par les ressources de ce widget, ainsi que par les ressources héritées du widget parent.

Structure

Toutes les procédures sur les listes activateCallback et doubleClickCallback du widget IconButton auront un pointeur vers une structure IconButtonCallbackInfo passé dans le champ call_data. Cette structure est définie dans le fichier d'en-tête public du widget IconButton comme suit :

typedef struct _XmIconButtonCallbackInfo {

Boolean state; /* L'état actuel du bouton icône.*/

XEvent * event; /* L'événement qui a causé cette action.*/

} XmIconButtonCallbackInfo;

state L'état actuel du bouton icône. Lorsqu'il est utilisé comme bouton poussoir (par défaut), la variable state sera toujours True.

event L'événement X qui a causé cette action. Voir Traductions et Actions ci-dessous pour plus de détails sur les événements qui peuvent déclencher ces callbacks.

Ressources normales

activateCallback

Spécifie une liste de callbacks à appeler lorsque le bouton est activé. Le widget XmIconButton appelle les routines de cette liste chaque fois que le bouton est activé. L'identifiant du widget est passé comme premier argument à chaque callback. La structure XmIconButtonCallbackInfo est passée comme deuxième argument.

armColor

Spécifie la couleur du bouton lorsque celui-ci est armé. La couleur par défaut est la couleur par défaut du système.

doubleClickCallback

Spécifie une liste de callbacks à appeler lorsque le bouton est double-cliqué. L'identifiant du widget est passé comme premier argument à chaque callback. La structure XmIconButtonCallbackInfo est passée comme deuxième argument.

fontList

Spécifie la police de caractères à utiliser pour le texte du bouton.

horizontalMargin

Spécifie la marge horizontale entre l'icône et le texte du bouton.

verticalMargin

Spécifie la marge verticale entre l'icône et le texte du bouton.

iconTextPadding

Spécifie le remplissage entre l'icône et le texte.

iconPlacement

Spécifie l'emplacement de l'icône par rapport au texte. Les valeurs possibles sont XmICON_ABOVE_TEXT, XmICON_BELOW_TEXT, XmICON_LEFT_OF_TEXT, XmICON_RIGHT_OF_TEXT.

label

Spécifie le texte du bouton.

labelString

Spécifie le texte du bouton sous forme de chaîne de caractères de type XmString.

pixmap

Spécifie le pixmap à utiliser comme icône du bouton.

recomputeSize

Indique si la taille du widget doit être recalculée lorsque ses ressources changent. La valeur par défaut est True.

set

Indique si le bouton est sélectionné. Utilisé pour les boutons à bascule.

stringDirection

Spécifie la direction de la chaîne de caractères du bouton. Les valeurs possibles sont XmSTRING_DIRECTION_L_TO_R et XmSTRING_DIRECTION_R_TO_L.

Procédures de Callback

Toutes les procédures sur les listes activateCallback et doubleClickCallback du widget IconButton auront un pointeur vers une structure IconButtonCallbackInfo passé dans le champ call_data. Cette structure est définie dans le fichier d'en-tête public du widget IconButton comme suit :

typedef struct _XmIconButtonCallbackInfo {

Boolean state; /* L'état actuel du bouton icône.*/

XEvent * event; /* L'événement qui a causé cette action.*/

} XmIconButtonCallbackInfo;

state L'état actuel du bouton icône. Lorsqu'il est utilisé comme bouton poussoir (par défaut), la variable state sera toujours True.

event L'événement X qui a causé cette action. Voir Traductions et Actions ci-dessous pour plus de détails sur les événements qui peuvent déclencher ces callbacks.

Traductions et Actions :
Les liaisons de traduction par défaut utilisées par le bouton icône sont les suivantes :
<Btn1Down>,<Btn1Up>: XmToggle() XmNotify()
<Btn1Down>(2): XmDoubleNotify()
<Btn1Down>: XmGetFocus() XmToggle()
<Key>osfSelect: XmArmAndActivate()
<Key>osfActivate: XmArmAndActivate()
None<Key>space: XmArmAndActivate()
None<Key>Return: XmArmAndActivate()
<Btn1Down>,<Leave> XmToggle() 
Les actions suivantes sont prises en charge par le bouton icône :
XmToggle() Bascule l'état du bouton icône.
XmNotify() Appelle toutes les routines de la liste activateCallback.
XmDoubleNotify() Appelle toutes les routines de la liste doubleClickCallback. 
XmArmAndActivated() Cette action arme le bouton, appelle les actions de la liste activateCallback, 
attend une fraction de seconde puis désarme le bouton.
Pour utiliser ce bouton comme un bouton à bascule plutôt qu'un bouton poussoir, remplacez la table de traduction par défaut par la table suivante.
<Btn1Down>: XmToggle() XmNotify()
<Btn1Up>(2): XmDoubleNotify()
<Key>osfSelect: XmToggle() XmNotify()
<Key>osfActivate: XmToggle() XmNotify()
None<Key>space: XmToggle() XmNotify()
None<Key>Return: XmToggle() XmNotify()
