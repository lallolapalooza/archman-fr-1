XML::XPath::Node::Namespace(3) Documentation Perl Contribuée par l'Utilisateur XML::XPath::Node::Namespace(3)

NOM

Namespace - un nœud d'espace de noms XML

API

new ( préfixe, élargi )

Crée un nouveau nœud d'espace de noms, où élargi est l'URI d'espace de noms élargi.

getPrefix

Retourne le préfixe.

getExpanded

Retourne l'URI élargi.

toString

Retourne une chaîne que vous pouvez ajouter à la liste des attributs d'un élément : xmlns:préfixe="élargi".
