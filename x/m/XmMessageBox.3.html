NOM

XmMessageBox — La classe de widget MessageBox

SYNTAXE

#include <Xm/MessageB.h>

DESCRIPTION

MessageBox est une classe de boîte de dialogue utilisée pour créer des boîtes de dialogue de message simples. Des boîtes de dialogue pratiques basées sur MessageBox sont fournies pour plusieurs tâches d'interaction courantes, notamment pour donner des informations, poser des questions et signaler des erreurs.

Une boîte de dialogue MessageBox est généralement transitoire, affichée pendant la durée d'une seule interaction. MessageBox est une sous-classe de BulletinBoard et s'appuie sur celle-ci pour une grande partie de son comportement général de boîte de dialogue.

La valeur par défaut pour XmNinitialFocus est la valeur de XmNdefaultButton.

Une MessageBox typique contient un symbole de message, un message et jusqu'à trois boutons poussoirs par défaut : OK, Annuler et Aide. Elle est disposée avec le symbole et le message en haut et les boutons poussoirs en bas. Le bouton Aide est positionné à côté des autres boutons poussoirs. Vous pouvez localiser les symboles et les étiquettes de boutons par défaut pour les boîtes de dialogue pratiques MessageBox.

L'utilisateur peut spécifier des ressources dans un fichier de ressources pour les gadgets créés automatiquement qui contiennent lePixmap du symbole MessageBox et le séparateur. Les noms des gadgets sont Symbol et Separator.

Une MessageBox peut également être personnalisée en créant et en gérant de nouveaux enfants qui sont ajoutés aux enfants MessageBox créés automatiquement par les boîtes de dialogue pratiques. Dans le cas de TemplateDialog, seul l'enfant séparateur est créé par défaut. Si les ressources de rappel, de chaîne ou de symbole pixmap sont spécifiées, l'enfant approprié sera créé.

Les enfants supplémentaires sont disposés de la manière suivante :

•
Le premier enfant MenuBar est placé en haut de la fenêtre. Le trait XmQTmenuSystem est utilisé pour vérifier qu'il s'agit du premier enfant MenuBar.
•
Tous les widgets ou gadgets sont placés après le bouton OK dans l'ordre de leur création (cet ordre est vérifié à l'aide du trait XmQTactivatable).
•
Un enfant qui n'appartient pas aux catégories ci-dessus est placé au-dessus de la rangée de boutons. Si une étiquette de message existe, l'enfant est placé sous l'étiquette. Si un pixmap de message existe, mais qu'une étiquette de message est absente, l'enfant est placé sur la même rangée que le pixmap. L'enfant se comporte comme une zone de travail et grandit ou rétrécit pour remplir l'espace au-dessus de la rangée de boutons. La disposition de plusieurs enfants de zone de travail est indéfinie.

Lors de l'initialisation, MessageBox recherche les fichiers bitmap suivants :

•
xm_error
•
xm_information
•
xm_question
•
xm_working
•
xm_warning

Voir XmGetPixmap(3) pour une liste des chemins recherchés pour ces fichiers.

MessageBox utilise les traits XmQTactivatable et XmQTmenuSystem.

Classes

MessageBox hérite du comportement, des ressources et des traits de Core, Composite, Constraint, XmManager et XmBulletinBoard.

Le pointeur de classe est xmMessageBoxWidgetClass.

Le nom de la classe est XmMessageBox.

XmNcancelCallback
Spécifie la liste des fonctions de rappel qui est appelée lorsque l'utilisateur clique sur le bouton annuler. La raison envoyée par la fonction de rappel est XmCR_CANCEL.
XmNcancelLabelString
Spécifie le libellé de la chaîne pour le bouton annuler. La valeur par défaut pour cette ressource dépend de la locale. Dans la locale C, la valeur par défaut est Cancel.
Maintenant que certaines chaînes de libellé localisées par défaut sont fournies par des catalogues de messages pour les enfants des widgets composites, les ressources labelString ne peuvent pas être définies sur l'enfant via des fichiers de ressources par défaut. Spécifie le bouton PushButton par défaut. Une valeur de XmDIALOG_NONE signifie qu'il ne doit y avoir aucun bouton PushButton par défaut. Les types suivants sont valides :
•
XmDIALOG_CANCEL_BUTTON
•
XmDIALOG_OK_BUTTON
•
XmDIALOG_HELP_BUTTON
•
XmDIALOG_NONE
XmNdialogType
Spécifie le type de boîte de dialogue MessageBox, qui détermine le symbole de message par défaut. Les valeurs possibles pour cette ressource sont les suivantes :
XmDIALOG_ERROR
Indique une boîte de dialogue d'erreur.
XmDIALOG_INFORMATION
Indique une boîte de dialogue d'information.
XmDIALOG_MESSAGE
Indique une boîte de dialogue de message. C'est le type de boîte de dialogue MessageBox par défaut. Elle n'a pas de symbole de message associé.
XmDIALOG_QUESTION
Indique une boîte de dialogue de question.
XmDIALOG_TEMPLATE
Indique une boîte de dialogue modèle. La boîte de dialogue modèle ne contient qu'un enfant séparateur. Elle n'a pas de symbole de message associé.
XmDIALOG_WARNING
Indique une boîte de dialogue d'avertissement.
XmDIALOG_WORKING
Indique une boîte de dialogue de travail.
Si cette ressource est modifiée avec XtSetValues, la pixmap symbole est modifiée au nouveau bitmap XmNdialogType à moins que XmNsymbolPixmap ne soit également défini dans l'appel à XtSetValues. Si le type de boîte de dialogue n'a pas de symbole de message associé, alors aucune pixmap ne sera affichée.
XmNhelpLabelString
Spécifie le libellé de la chaîne pour le bouton aide. La valeur par défaut pour cette ressource dépend de la locale. Dans la locale C, la valeur par défaut est Help.

Au lieu de cela, la ressource fournie au niveau parent doit être utilisée.

Contrôle l'alignement du libellé du message. Les valeurs possibles incluent les suivantes :
•
XmALIGNMENT_BEGINNING (par défaut)
•
XmALIGNMENT_CENTER
•
XmALIGNMENT_END
Voir la description de XmNalignment sur la page de référence de XmLabel pour une explication de ces valeurs.
XmNmessageString
Spécifie la chaîne à utiliser comme message.
XmNminimizeButtons
Définit les boutons à la largeur du bouton le plus large et à la hauteur du bouton le plus haut si False. Si cette ressource est True, la largeur et la hauteur des boutons sont définies à la taille préférée de chaque bouton.
XmNokCallback
Spécifie la liste des fonctions de rappel qui est appelée lorsque l'utilisateur clique sur le bouton OK. La raison envoyée par la fonction de rappel est XmCR_OK.
XmNokLabelString
Spécifie le libellé de la chaîne pour le bouton OK. La valeur par défaut pour cette ressource dépend de la locale. Dans la locale C, la valeur par défaut est OK.

Au lieu de cela, la ressource fournie au niveau parent doit être utilisée.
XmNsymbolPixmap
Spécifie la pixmap de libellé à utiliser comme symbole de message.

NAME

XmMessageBox — A dialog box component that displays a message and a symbol.

INSTRUCTIONAL SYNTAX

XmMessageBox

DESCRIPTION

The XmMessageBox widget is a primitive dialog box that displays a message, an optional symbol, and zero or more callback buttons. It is derived from the XmBulletinBoard widget.

XmMessageBox provides a standard way to display different types of messages to the user. The widget displays a message string, a symbol (such as an error icon, a warning icon, or an information icon), and a set of callback buttons. The appearance and behavior of the XmMessageBox widget can be customized by creating instances of the widget with specific resource values.

The XmMessageBox widget supports the following resources. For a complete specification of the resources, see the man pages for XmMessageBox.

TRANSLATIONS

XmMessageBox includes the translations from XmManager.

ADDITIONAL BEHAVIOR

The XmMessageBox widget has the following additional behavior:

<Key><osfCancel>:
Calls the activate callbacks for the cancel button if it is sensitive.
<Key><osfActivate>:
Calls the activate callbacks for the button with the keyboard focus. If no button has the keyboard focus, calls the activate callbacks for the default button if it is sensitive.
<Ok Button Activated>:
Calls the callbacks for XmNokCallback.
<Cancel Button Activated>:
Calls the callbacks for XmNcancelCallback.
<Help Button Activated>:
Calls the callbacks for XmNhelpCallback.
<FocusIn>:
Calls the callbacks for XmNfocusCallback.
<Map>:

The XmMessageBox widget also supports the following resources:

XmNcancelCallback
Specifies the list of callbacks to be called when the Cancel button is activated.
XmNdefaultButton
Specifies the default button for the message box. This button is activated when the user presses the Enter key.
XmNhelpCallback
Specifies the list of callbacks to be called when the Help button is activated.
XmNmessageString
Specifies the message string to be displayed in the message box.
XmNokCallback
Specifies the list of callbacks to be called when the OK button is activated.
XmNsymbolPixmap
Specifies the pixmap to be displayed as the symbol in the message box.
Appelle les callbacks pour XmNmapCallback si le parent est une DialogShell.
<Unmap>:
Appelle les callbacks pour XmNunmapCallback si le parent est une DialogShell.
