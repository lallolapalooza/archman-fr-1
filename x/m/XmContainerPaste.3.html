NOM

XmContainerPaste — Fonction du widget Container pour insérer des éléments du presse-papiers

SYNOPSIS

#include <Xm/Container.h>
Boolean XmContainerPaste(
Widget container);

DESCRIPTION

XmContainerPaste demande le transfert de données depuis la sélection du presse-papiers vers le Container. Cette routine appelle les procédures XmNdestinationCallback du widget avec le membre selection de la structure XmDestinationCallbackStruct défini sur CLIPBOARD et avec le membre operation défini sur XmCOPY. Le widget Container lui-même n'effectue aucun transfert ; les procédures XmNdestinationCallback sont responsables de l'insertion de la sélection du presse-papiers et de la prise de toute action connexe.

container
Spécifie l'ID du widget Container.

Pour une définition complète du Container et de ses ressources associées, voir XmContainer(3).

RETOUR

La fonction retourne False si aucun transfert de données n'a lieu. Sinon, elle retourne True.

VOIR AUSSI

XmContainer(3).
