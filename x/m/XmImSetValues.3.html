XmImSetValues(appel de bibliothèque) XmImSetValues(appel de bibliothèque)

NOM

XmImSetValues — Une fonction de gestion des entrées qui met à jour les attributs d'un contexte d'entrée

SYNTAXE

#include <Xm/XmIm.h>
void XmImSetValues(
Widget widget,
ArgList arglist,
Cardinal argcount,
);

DESCRIPTION

XmImSetValues met à jour les attributs du contexte d'entrée associé au widget spécifié. L'argument arglist est une liste de paires attribut/valeur pour le contexte d'entrée. Cette fonction transmet les attributs et les valeurs à XICSetValues. Le premier appel à cette routine doit passer tous les attributs du contexte d'entrée. Par la suite, le programmeur de l'application appelle XmImSetValues, pour un XIC, uniquement si une valeur a changé.

Si les paramètres précédents pour le XIC du widget ne permettent pas la réutilisation du XIC enregistré précédemment, ce XIC sera désenregistré, et un nouveau sera créé et enregistré avec le widget. Notez que le partage des données est préservé.

Notez que les widgets Text et TextField appellent la fonction XmImSetValues lorsqu'ils reçoivent le focus. Par conséquent, d'autres appels à la fonction XmImSetValues pour ces widgets sont inutiles.

widget
Spécifie l'identifiant du widget enregistré auprès du gestionnaire d'entrée.
arglist
Spécifie la liste des paires attribut/valeur à passer à XICSetValues ; les attributs suivants sont acceptés : XmNpreeditStartCallback XmNpreeditDoneCallback XmNpreeditDrawCallback et XmNpreeditCaretCallback. Ces attributs acceptent une valeur associée de type pointeur vers une structure de type XIMCallback.
Ces rappels sont utilisés uniquement lorsque la ressource XmNpreeditType du VendorShell pertinent a la valeur « onthespot », et que le XIM prend en charge le style d'entrée XIMPreeditCallbacks. Ces valeurs sont ignorées si la condition n'est pas remplie.
Pour chacun de ces rappels, si la valeur du rappel n'est pas définie par cette fonction, aucune action ne sera entreprise lorsque la Méthode d'Entrée tentera d'appeler ce rappel. Référez-vous au « Xlib - C Language X Interface, X Version 11, Release 6 », Chapitre 13 pour les détails de ces rappels.
argcount
Spécifie le nombre de paires attribut/valeur dans la liste d'arguments (arglist)

Les ressources qui peuvent être définies pour le contexte d'entrée incluent :

XmNbackground
Spécifie la valeur en pixels de la couleur de fond.
XmNbackgroundPixmap
Spécifie un pixmap pour le remplissage du fond.
XmNfontList
Spécifie la liste de polices utilisée par le widget. La méthode d'entrée utilise la première occurrence d'un jeu de polices étiqueté avec XmFONTLIST_DEFAULT_TAG. Si aucune telle instance n'est trouvée, le premier jeu de polices de la liste de polices est utilisé. Si la liste de polices ne contient pas de jeu de polices, une valeur n'est pas passée à XICSetValues.
XmNforeground
Spécifie la valeur en pixels de la couleur de premier plan.
XmNlineSpace
Spécifie l'espacement des lignes utilisé dans la fenêtre de pré-édition.
XmNrenderTable
Spécifie la table de rendu utilisée par le widget.
XmNspotLocation
Spécifie les coordonnées x et y de la position où le texte sera inséré dans le widget gérant l'entrée, dont le style de méthode d'entrée est « OverTheSpot ». La coordonnée y est la position de la ligne de base utilisée par la ligne de texte actuelle.

L'appelant peut également passer toute autre ressource définie par le fournisseur à cette fonction. Pour des informations supplémentaires sur l'interface d'internationalisation, voir la documentation Xlib.
