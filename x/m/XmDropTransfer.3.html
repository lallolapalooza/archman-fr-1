NOM

XmDropTransfer — Classe du widget DropTransfer

SYNTAXE

#include <Xm/DragDrop.h>

DESCRIPTION

DropTransfer fournit un ensemble de ressources qui identifient les procédures et les informations associées requises par la toolkit pour traiter et compléter une transaction de dépôt. Les clients ne doivent pas créer explicitement un widget DropTransfer. Au lieu de cela, un client initie un transfert en appelant XmDropTransferStart, qui initialise et retourne un widget DropTransfer. Si cette fonction est appelée dans un rappel XmNdropProc, les transferts réels sont initiés après le retour du rappel. Même si aucune donnée ne doit être transférée, XmDropTransferStart doit être appelée (typiquement sans arguments, ou en définissant simplement XmNtransferStatus) pour terminer la transaction de glisser-déposer.

La ressource XmNdropTransfers spécifie une liste de transfert qui décrit les types cibles demandés pour les données source. Une liste de transfert est un tableau de structures XmDropTransferEntryRec, chacune identifiant un type cible. La liste de transfert est analogue à la capacité de sélection MULTIPLE définie dans le Inter-Client Communication Conventions Manual (ICCCM).

La ressource DropTransfer, XmNtransferProc, spécifie une procédure de transfert de type XtSelectionCallbackProc qui délivre les données de sélection demandées. Cette procédure fonctionne en conjonction avec les capacités de sélection Xt sous-jacentes et est appelée pour chaque cible dans la liste de transfert. Des types cibles supplémentaires peuvent être demandés après l'initiation d'un transfert en appelant la fonction XmDropTransferAdd.

STRUCTURES

Un XmDropTransferEntry est un pointeur vers la structure suivante de type XmDropTransferEntryRec, qui identifie une cible de sélection associée à une transaction de dépôt donnée :

typedef struct
{
        XtPointer       client_data;
        Atom target;
} XmDropTransferEntryRec, *XmDropTransferEntry;
client_data
Spécifie toute information supplémentaire requise par cette cible de sélection.
target
Spécifie une cible de sélection associée à l'opération de dépôt.

CLASSES

DropTransfer hérite du comportement et d'une ressource de Object.

Le pointeur de classe est xmDropTransferObjectClass.

Le nom de la classe est XmDropTransfer.

NOUVELLES RESSOURCES

Le tableau suivant définit un ensemble de ressources de widget utilisées par le programmeur pour spécifier les données. Le programmeur peut également définir les valeurs des ressources pour les classes héritées afin de définir les attributs de ce widget. Pour référencer une ressource par nom ou par classe dans un fichier .Xdefaults, supprimez le préfixe XmN ou XmC et utilisez les lettres restantes. Pour spécifier l'une des valeurs définies pour une ressource dans un fichier .Xdefaults, supprimez le préfixe Xm et utilisez les lettres restantes (en minuscules ou majuscules, mais incluez les traits de soulignement entre les mots). Les codes dans la colonne d'accès indiquent si la ressource donnée peut être définie au moment de la création (C), définie à l'aide de XtSetValues (S), récupérée à l'aide de XtGetValues (G), ou si elle n'est pas applicable (N/A).

XmNdropTransfers
Spécifie l'adresse d'un tableau d'enregistrements d'entrée de transfert de dépôt. Le transfert de dépôt est terminé lorsque toutes les entrées de la liste ont été traitées.
XmNincremental
Spécifie une valeur booléenne qui indique si le transfert côté récepteur utilise le mécanisme de transfert de sélection incrémentiel Xt décrit dans X Toolkit Intrinsics—C Language Interface. Si la valeur est True, le récepteur utilise le transfert incrémentiel ; si la valeur est False, le récepteur utilise le transfert atomique.
XmNnumDropTransfers
Spécifie le nombre d'entrées dans XmNdropTransfers. Si cette ressource est définie à 0 à tout moment, le transfert est considéré comme terminé. La valeur de XmNtransferStatus détermine le processus de validation de fin.
XmNtransferProc
Spécifie une procédure de type XtSelectionCallbackProc qui délivre les valeurs de sélection demandées. L'argument widget passé à cette procédure est le widget DropTransfer. L'atome de sélection passé est _MOTIF_DROP. Pour plus d'informations sur les procédures de rappel de sélection, voir X Toolkit Intrinsics—C Language Interface.
XmNtransferStatus
Spécifie l'état actuel du transfert de dépôt. Le client met à jour cette valeur lorsque le transfert se termine et communique la valeur à l'initiateur. Les valeurs possibles sont
XmTRANSFER_SUCCESS
Le transfert a réussi.
XmTRANSFER_FAILURE
Le transf er a échoué.
