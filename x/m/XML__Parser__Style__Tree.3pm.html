XML__Parser__Style__Tree(3pm)

Paquet: perl-xml-parser

Licences: GPL, PerlArtistic

Parser::Style::Tree(3) Documentation Perl fournie par l'utilisateur Parser::Style::Tree(3)

NOM

XML::Parser::Style::Tree - Analyseur de style arborescent

SYNTAXE

use XML::Parser;
my $p = XML::Parser->new(Style => 'Tree');
my $tree = $p->parsefile('foo.xml');

DESCRIPTION

Ce module implémente l'analyseur de style Arborescent de XML::Parser.

Lors de l'analyse d'un document, parse() renverra un arbre d'analyse pour le document. Chaque nœud de l'arbre prend la forme d'une paire balise, contenu. Les nœuds texte sont représentés par une pseudo-balise "0" et la chaîne qui est leur contenu. Pour les éléments, le contenu est une référence tableau. Le premier élément du tableau est une référence de hachage (potentiellement vide) contenant les attributs. Le reste du tableau est une séquence de paires balise-contenu représentant le contenu de l'élément.

Ainsi, par exemple, le résultat de l'analyse de :

<foo><head id="a">Bonjour <em>là</em></head><bar>Salut</bar>voici</foo>

serait :

           Balise   Contenu
==================================================================
[foo, [{}, head, [{id => "a"}, 0, "Bonjour ",  em, [{}, 0, "là"]],
            bar, [         {}, 0, "Salut",  ref, [{}]],
              0, "voici"
      ]
]

La racine du document "foo", a 3 enfants : un élément "head", un élément "bar" et le texte "voici". Après la référence de hachage vide, ceux-ci sont représentés dans son contenu par 3 paires balise-contenu.
