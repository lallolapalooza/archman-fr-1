XML::SAX(3) Documentation Perl fournie par l'utilisateur XML::SAX(3)

NOM

XML::SAX - API Simple pour XML

SYNOPIS

use XML::SAX;

# obtenir une liste des analyseurs connus
my $parsers = XML::SAX->parsers();

# ajouter/mettre à jour un analyseur
XML::SAX->add_parser(q(XML::SAX::PurePerl));
# supprimer un analyseur
XML::SAX->remove_parser(q(XML::SAX::Foodelberry));
# sauvegarder les analyseurs
XML::SAX->save_parsers();

DESCRIPTION

XML::SAX est une API d'accès à l'analyseur SAX pour Perl. Il inclut les classes et les API nécessaires à l'implémentation des pilotes SAX, ainsi qu'une classe usine pour retourner n'importe quel analyseur SAX installé sur le système de l'utilisateur.

UTILISATION D'UN ANALYSEUR SAX2

La classe usine est XML::SAX::ParserFactory. Veuillez consulter la documentation de ce module pour savoir comment instancier un analyseur SAX : XML::SAX::ParserFactory. Cependant, si vous ne souhaitez pas charger une autre page de manuel, voici un bref synopsis :

use XML::SAX::ParserFactory;
use XML::SAX::XYZHandler;
my $handler = XML::SAX::XYZHandler->new();
my $p = XML::SAX::ParserFactory->parser(Handler => $handler);
$p->parse_uri("foo.xml");
# ou $p->parse_string("<foo/>") ou $p->parse_file($fh);

Ceci chargera automatiquement un analyseur SAX2 (par défaut XML::SAX::PurePerl si aucun autre n'est trouvé) et vous le retournera.

Pour apprendre à utiliser SAX pour analyser du XML, vous devrez lire XML::SAX::Intro et pour référence, XML::SAX::Specification.

ECRITURE D'UN ANALYSEUR SAX2

La première chose à retenir lors de l'écriture d'un analyseur SAX2 est de sous-classer XML::SAX::Base. Cela vous facilitera grandement la vie en vous fournissant un certain nombre de méthodes automatiquement. Voir XML::SAX::Base pour plus de détails.

Lorsque vous écrivez un analyseur SAX2 compatible avec XML::SAX, vous devez informer XML::SAX de la présence de ce pilote lors de son installation. Pour ce faire, XML::SAX contient des méthodes pour sauvegarder le fait que l'analyseur existe sur votre système dans un fichier "INI", qui est ensuite chargé pour déterminer quels analyseurs sont installés.

La meilleure façon de le faire est de suivre ces règles :

  • Ajoutez XML::SAX comme prérequis dans Makefile.PL : 
    WriteMakefile(
    ...
    PREREQ_PM => { 'XML::SAX' => 0 },
    ...
);

    Alternativement, vous pourriez vouloir vérifier cela d'autres manières qui ne causeront pas seulement un avertissement.

  • Ajoutez le fragment de code suivant à votre Makefile.PL : 
    sub MY::install {
  package MY;
  my $script = shift->SUPER::install(@_);
  if (ExtUtils::MakeMaker::prompt(
    "Do you want to modify ParserDetails.ini?", 'Y')
    =~ /^y/i) {
    $script =~ s/install :: (.*)$/install :: $1 install_sax_driver/m;
    $script .= <<"INSTALL";

install_sax_driver :
\t\@\$(PERL) -MXML::SAX -e "XML::SAX->add_parser(q(\$(NAME)))->save_parsers()"

INSTALL
  }
  return $script;
}

    Notez que vous devriez vérifier la sortie de cela - \$(NAME) utilisera le nom de votre distribution, ce qui n'est peut-être pas exactement ce que vous voulez. Par exemple, XML::LibXML a un pilote appelé XML::LibXML::SAX::Generator, qui est utilisé à la place de \$(NAME) ci-dessus.

  • Ajoutez un test XML::SAX :

    Un fichier de test devrait être ajouté à votre répertoire t/ contenant quelque chose comme ce qui suit :

    use Test;
BEGIN { plan tests => 3 }
use XML::SAX;
use XML::SAX::PurePerl::DebugHandler;
XML::SAX->add_parser(q(XML::SAX::MyDriver));
local $XML::SAX::ParserPackage = 'XML::SAX::MyDriver';
eval {
  my $handler = XML::SAX::PurePerl::DebugHandler->new();
  ok($handler);
  my $parser = XML::SAX::ParserFactory->parser(Handler => $handler);
  ok($parser);
  ok($parser->isa('XML::SAX::MyDriver');
  $parser->parse_string("<tag/>");
  ok($handler->{seen}{start_element});
};

EXPORTATION

Par défaut, XML::SAX n'exporte rien dans l'espace de noms de l'appelant. Cependant, vous pouvez demander les symboles "Namespaces" et "Validation" qui sont les URI pour ces fonctionnalités, permettant un moyen plus facile de demander ces fonctionnalités via ParserFactory :

use XML::SAX qw(Namespaces Validation);
my $factory = XML::SAX::ParserFactory->new();
$factory->require_feature(Namespaces);
$factory->require_feature(Validation);
my $parser = $factory->parser();
