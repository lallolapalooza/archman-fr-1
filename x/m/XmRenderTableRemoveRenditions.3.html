NOM

XmRenderTableRemoveRenditions — Une fonction de commodité qui supprime des rendus

SYNTAXE

#include <Xm/Xm.h>
XmRenderTable XmRenderTableRemoveRenditions(
XmRenderTable oldtable,
XmStringTag *tags,
int tag_count);

DESCRIPTION

XmRenderTableRemoveRenditions supprime de oldtable les rendus dont les étiquettes correspondent aux étiquettes spécifiées dans tags, puis place les rendus restants dans une nouvelle table de rendus.

oldtable
Spécifie la table de rendus à partir de laquelle les rendus doivent être supprimés. Cette fonction désalloue la table de rendus originale et les rendus correspondants après extraction des informations requises.
tags
Spécifie un tableau d'étiquettes, dont les rendus correspondants doivent être supprimés de oldtable.
tag_count
Spécifie le nombre d'étiquettes dans tags.

VALEUR DE RETOUR

Si oldtable ou tags est NULL, ou si tag_count est 0 (zéro), ou si aucun rendu n'est supprimé de oldtable, cette fonction renvoie oldtable. Sinon, elle renvoie une XmRenderTable nouvellement allouée. L'application est responsable de la gestion de cette table de rendus allouée. L'application peut récupérer cet espace alloué en appelant XmRenderTableFree.

VOIR AUSSI

XmRendition(3) et XmRenderTableFree(3).
