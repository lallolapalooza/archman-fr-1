NOM

XmCvtXmStringToByteStream — Une fonction de chaîne composée qui convertit une chaîne composée en format de flux d'octets (Byte Stream)

SYNTAXE

#include <Xm/Xm.h>
unsigned int XmCvtXmStringToByteStream(
XmString string,
unsigned char **prop_return);

DESCRIPTION

XmCvtXmStringToByteStream convertit une chaîne composée en une chaîne d'octets représentant la chaîne composée au format Byte Stream. Cette routine est généralement utilisée par la source d'une opération de transfert de données pour produire une représentation Byte Stream afin de transférer une chaîne composée vers une destination.

Si prop_return n'est pas NULL, cette fonction crée une chaîne de caractères au format Byte Stream et la retourne dans prop_return. La fonction retourne également le nombre d'octets dans prop_return. Si prop_return est NULL, la fonction ne retourne pas la chaîne au format Byte Stream, mais elle calcule et retourne le nombre d'octets qui apparaîtraient dans la chaîne au format Byte Stream.

string
Spécifie une chaîne composée à convertir au format Byte Stream.
prop_return
Spécifie un pointeur vers une chaîne au format Byte Stream qui est créée et retournée par cette fonction. Si prop_return est NULL, aucune chaîne au format Byte Stream n'est retournée. Lorsqu'une chaîne au format Byte Stream est retournée, la fonction alloue de l'espace pour la contenir. L'application est responsable de la gestion de cet espace alloué. L'application peut récupérer l'espace alloué en appelant XtFree.

RETOUR

Retourne le nombre d'octets dans la représentation Byte Stream (que la représentation Byte Stream soit retournée ou non).

VOIR AUSSI

XmString(3) et XmCvtByteStreamToXmString(3).
