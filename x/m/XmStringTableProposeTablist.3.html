NOM

XmStringTableProposeTablist — Une fonction pratique qui renvoie une liste d'onglets

SYNTAXE

#include <Xm/Xm.h>
XmTabList XmStringTableProposeTablist(
XmStringTable strings,
Cardinal num_strings,
Widget widget,
float pad_value,
XmOffsetModel offset_model);

DESCRIPTION

XmStringTableProposeTablist prend une structure XmStringTable contenant des chaînes composées avec des tabulations, des informations sur le remplissage entre les colonnes, et des informations de rendu, et renvoie une liste d'onglets qui, si elle est utilisée pour rendre les chaînes de la table, ferait que les chaînes s'alignent en colonnes sans chevauchement et avec le montant spécifié de remplissage entre l'élément le plus large de chaque colonne et le début de la colonne suivante. Chaque tabulation de la liste d'onglets aurait le même type d'unité que units, un modèle de décalage de offset_model, et un type d'alignement de XmALIGNMENT_BEGINNING.

strings
Spécifie un tableau de chaînes composées.
num_strings
Spécifie le nombre de chaînes composées dans strings.
widget
Spécifie le widget utilisé pour dériver toute information nécessaire à la création du rendu. En particulier, le XmNunitType du widget sera utilisé pour spécifier le type d'unité à utiliser pour déterminer le montant du remplissage séparant les colonnes et pour les onglets de la liste d'onglets proposée. De plus, la table de rendu du widget sera utilisée pour interpréter les balises de rendu dans les chaînes.
pad_value
Spécifie la valeur du montant de remplissage à utiliser pour séparer les colonnes. Les unités de ce paramètre sont spécifiées comme le XmNunitType défini pour le paramètre widget. Référez-vous à la ressource XmNunitType de la page de référence XmGadget, XmManager, ou XmPrimitive.
offset_model
Spécifie le modèle de décalage à utiliser pour créer les onglets. Peut être XmABSOLUTE ou XmRELATIVE.

RETOUR

Renvoie une nouvelle XmTabList. La fonction alloue de l'espace pour contenir la liste d'onglets renvoyée. L'application est responsable de la gestion de l'espace alloué. L'application peut récupérer l'espace alloué en appelant XmTabListFree.

VOIR AUSSI

XmTabList(3) et XmTabListFree(3).
