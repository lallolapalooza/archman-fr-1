DESCRIPTION

La bibliothèque de programmation de l'application pour l'Extension X11 de Double-Buffering, Multi-Buffering et Stéréo contient les interfaces décrites ci-dessous. À l'exception de XmbufQueryExtension, si l'une de ces routines est appelée avec un display qui ne prend pas en charge l'extension, l'ExtensionErrorHandler (qui peut être défini avec XSetExtensionErrorHandler et fonctionne de la même manière que XSetErrorHandler) sera appelée et la fonction retournera alors.

XmbufQueryExtension retourne True si l'extension de multi-buffering/stéréo est disponible sur le display donné. Si l'extension existe, la valeur du premier code d'événement (qui doit être ajoutée aux constantes de type d'événement MultibufferClobberNotify et MultibufferUpdateNotify pour obtenir les valeurs réelles) est stockée dans event_base_return et la valeur du premier code d'erreur (qui doit être ajoutée à la constante de type d'erreur MultibufferBadBuffer pour obtenir la valeur réelle) est stockée dans error_base_return.

XmbufGetVersion obtient les numéros de version majeure et mineure de l'extension. La valeur de retour est zéro en cas d'erreur ou non nulle si aucune erreur ne se produit.

XmbufCreateBuffers demande la création de « count » buffers avec l'action de mise à jour et l'indice de mise à jour donnés et leur association à la fenêtre indiquée. Le nombre de buffers créés est retourné (zéro en cas d'erreur) et buffers_update est rempli avec ce nombre d'identifiants Multibuffer.

XmbufDestroyBuffers détruit les buffers associés à la fenêtre donnée.

XmbufDisplayBuffers affiche les buffers indiqués dans leurs fenêtres appropriées dans un délai maximum de max_delay millisecondes après que min_delay millisecondes se soient écoulées. Deux buffers ne peuvent pas être associés à la même fenêtre, sinon une erreur de correspondance est générée.

XmbufGetWindowAttributes obtient les attributs de multi-buffering qui s'appliquent à tous les buffers associés à la fenêtre donnée. La liste des buffers retournée peut être libérée avec XFree. Retourne non nulle en cas de succès et zéro en cas d'erreur.

XmbufChangeWindowAttributes définit les attributs de multi-buffering qui s'appliquent à tous les buffers associés à la fenêtre donnée. Ceci est actuellement limité à l'indice de mise à jour.

XmbufGetBufferAttributes obtient les attributs du buffer indiqué. Retourne non nulle en cas de succès et zéro en cas d'erreur.

XmbufChangeBufferAttributes définit les attributs du buffer indiqué. Ceci est actuellement limité au masque d'événements.

XmbufGetScreenInfo obtient les paramètres contrôlant comment les fenêtres mono et stéréo peuvent être créées sur l'écran du dessinable donné. Le nombre d'ensembles de visuels et de profondeurs est retourné dans nmono_return et nstereo_return. Si nmono_return est supérieur à zéro, alors mono_info_return est défini à l'adresse d'un tableau de structures XmbufBufferInfo décrivant les divers visuels et profondeurs pouvant être utilisés. Sinon, mono_info_return est défini à NULL. De même, stereo_info_return est défini en fonction de nstereo_return. Le stockage retourné dans mono_info_return et stereo_info_return peut être libéré par XFree. Si aucune erreur n'est rencontrée, une valeur non nulle sera retournée.

XmbufCreateStereoWindow crée une fenêtre stéréo de la même manière que XCreateWindow crée une fenêtre mono. Les identifiants de buffer pour les buffers gauche et droit sont retournés respectivement dans left_return et right_return. Si un gestionnaire d'erreurs d'extension qui retourne est installé, None sera retourné si l'extension n'est pas disponible sur ce display.

DESCRIPTION

The multi-buffering extension provides support for double-buffering, multi-buffering, and stereo in X. The extension defines a set of functions to manage buffers and sub-buffers associated with windows.

The XmbufChangeBufferAttributes function allows modification of attributes for a given buffer.

The XmbufGetBufferAttributes function retrieves the attributes of a specified buffer.

The XmbufCreateSubBuffer function creates a new sub-buffer associated with an existing buffer.

The XmbufDestroySubBuffer function destroys a specified sub-buffer.

The XmbufChangeSubBufferAttributes function modifies the attributes of a sub-buffer.

The XmbufGetSubBufferAttributes function retrieves the attributes of a sub-buffer.

The XmbufGetWindowBufferAttributes function retrieves the buffer and sub-buffer IDs associated with a given window.

The XmbufSelectSubBufferEvents function allows clients to select which events they want to receive for a specific sub-buffer.

The XmbufGetSelectedSubBufferEvents function retrieves the event mask for a sub-buffer.

The XmbufNotifyBufferUpdate and XmbufNotifyBufferUpdateToClient functions are used to notify about buffer updates.

The XmbufQueryExtension function queries the multi-buffering extension, returning the event and error base numbers.

DESCRIPTION

L'extension de multi-buffering fournit la prise en charge du double buffering, du multi-buffering et de la stéréo sous X. L'extension définit un ensemble de fonctions pour gérer les buffers et les sous-buffers associés aux fenêtres.

La fonction XmbufChangeBufferAttributes permet la modification des attributs d'un buffer donné.

La fonction XmbufGetBufferAttributes récupère les attributs d'un buffer spécifié.

La fonction XmbufCreateSubBuffer crée un nouveau sous-buffer associé à un buffer existant.

La fonction XmbufDestroySubBuffer détruit un sous-buffer spécifié.

La fonction XmbufChangeSubBufferAttributes modifie les attributs d'un sous-buffer.

La fonction XmbufGetSubBufferAttributes récupère les attributs d'un sous-buffer.

La fonction XmbufGetWindowBufferAttributes récupère les identifiants de buffer et de sous-buffer associés à une fenêtre donnée.

La fonction XmbufSelectSubBufferEvents permet aux clients de sélectionner les événements qu'ils souhaitent recevoir pour un sous-buffer spécifique.

La fonction XmbufGetSelectedSubBufferEvents récupère le masque d'événements pour un sous-buffer.

Les fonctions XmbufNotifyBufferUpdate et XmbufNotifyBufferUpdateToClient sont utilisées pour notifier les mises à jour de buffer.

La fonction XmbufQueryExtension interroge l'extension de multi-buffering, retournant les numéros de base des événements et des erreurs.
