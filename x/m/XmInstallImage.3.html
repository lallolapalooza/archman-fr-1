Paquet: openmotif

XmInstallImage(appel de bibliothèque) XmInstallImage(appel de bibliothèque)

NOM

XmInstallImage — Fonction de mise en cache de pixmap qui ajoute une image au cache d'images

SYNTAXE

#include <Xm/Xm.h>
Boolean XmInstallImage(
XImage * image,
char * image_name);

DESCRIPTION

XmInstallImage stocke une image dans un cache d'images qui peut être utilisé plus tard pour générer une pixmap. Une partie du processus d'installation consiste à étendre le convertisseur de ressources utilisé pour référencer ces images. Le convertisseur de ressources reçoit le nom de l'image afin que celle-ci puisse être référencée dans un fichier .Xdefaults. Comme une image peut être référencée par un widget via ses ressources pixmap, il appartient à l'application de s'assurer que l'image est installée avant la création du widget.

image
Pointe vers la structure d'image à installer. Le processus d'installation ne fait pas de copie locale de l'image. Par conséquent, l'application ne doit pas détruire l'image tant qu'elle n'a pas été désinstallée des fonctions de mise en cache.
image_name
Spécifie une chaîne de caractères que l'application utilise pour nommer l'image. Après l'installation, ce nom peut être utilisé dans .Xdefaults pour référencer l'image. Une copie locale du nom est créée par les fonctions de mise en cache d'images.

Les fonctions de mise en cache d'images fournissent un ensemble de huit images préinstallées. Ces noms peuvent être utilisés dans un fichier .Xdefaults pour générer des pixmaps pour la ressource pour laquelle ils sont fournis.

Nom de l'image Description
background Une mosaïque de fond uni
25_foreground Une mosaïque de 25% de premier plan, 75% d'arrière-plan
50_foreground Une mosaïque de 50% de premier plan, 50% d'arrière-plan
75_foreground Une mosaïque de 75% de premier plan, 25% d'arrière-plan
horizontal Une mosaïque de lignes horizontales des deux couleurs
vertical Une mosaïque de lignes verticales des deux couleurs
slant_right Une mosaïque de lignes en biais vers la droite des deux couleurs
slant_left Une mosaïque de lignes en biais vers la gauche des deux couleurs
menu_cascade Une mosaïque de flèche de la couleur du premier plan
menu_checkmark Une mosaïque de coche de la couleur du premier plan
menu_dash Une mosaïque d'une ligne horizontale de la couleur du premier plan

RETOUR

Retourne True en cas de succès ; retourne False si NULL image, NULL image_name, ou un image_name en double est utilisé comme valeur de paramètre.

VOIR AUSSI

XmUninstallImage(3), XmGetPixmap(3), et XmDestroyPixmap(3).
