XML::PatAct::ToObjects(3) Documentation Perl fournie par l'utilisateur XML::PatAct::ToObjects(3)

NOM

XML::PatAct::ToObjects - un module d'action pour créer des objets Perl

SYNOPIS

use XML::PatAct::ToObjects;
my $patterns = [ MODÈLE => [ OPTIONS ],
                 MODÈLE => "CODE-PERL",
                 ... ];
my $matcher = XML::PatAct::ToObjects->new( Patterns => $patterns,
                                           Matcher => $matcher,
                                           CopyId => 1,
                                           CopyAttributes => 1 );

DESCRIPTION

XML::PatAct::ToObjects est un gestionnaire PerlSAX pour appliquer des listes de motifs-actions à des analyseurs ou des arbres XML. XML::PatAct::ToObjects crée des objets Perl des types et contenus des éléments d'action que vous définissez.

Les nouvelles instances de XML::PatAct::ToObject sont créées en appelant `new()'. Les paramètres peuvent être passés sous forme de liste de paires clé, valeur ou sous forme de hash. `new()' requiert les paramètres Patterns et Matcher, les autres sont optionnels :

Patterns
La liste de motifs-actions à appliquer.
Matcher
Une instance du module de correspondance de motifs ou de requête.
CopyId
Copie l'attribut `ID', s'il existe, dans un élément XML source vers un attribut `ID' dans les objets nouvellement créés. Notez que les IDs peuvent être perdus si aucun motif ne correspond à cet élément ou si aucun objet n'est créé ("-make") pour cet élément.
CopyAttributes
Copie tous les attributs de l'élément vers les objets nouvellement créés.

Chaque action peut être soit une liste d'options définies ci-dessous, soit une chaîne contenant un fragment de code Perl. Si l'action est une chaîne de code Perl, alors de simples substitutions sont effectuées comme décrit plus loin.

Options utilisables dans un élément d'action contenant une liste d'options :

-holder
Ignore cet élément, mais continue de traiter ses enfants (à comparer avec -ignore). "-pcdata" peut être utilisé avec cette option.
-ignore
Ignore (supprime) cet élément et ses enfants (à comparer avec -holder).
-pcdata
Les données de caractères de cet élément doivent être copiées dans le champ "Contents".
-make PACKAGE
Crée un objet béni dans PACKAGE, et continue de traiter cet élément et ses enfants. PACKAGE peut être le type `"HASH"' pour simplement créer un hash anonyme.
-args ARGUMENTS
Utilise ARGUMENTS pour créer l'objet spécifié par -make. Ceci est couramment utilisé pour copier les attributs d'élément dans des champs du nouvel objet créé. Par exemple : 
-make => 'HASH', -args => 'URL => %{href}'

copierait l'attribut `"href"' d'un élément dans le champ `"URL"' du hash nouvellement créé.

-field FIELD
Stocke cet élément, objet, ou les enfants de cet élément dans le champ de l'objet parent nommé par FIELD.
-push-field FIELD
Similaire à -field, sauf que FIELD est un tableau et que les contenus sont ajoutés à ce tableau.
-value VALUE
Utilise VALUE comme une valeur littérale à stocker dans FIELD, ignorant sinon cet élément et ses enfants. Valide uniquement avec -field ou -push-field. La notation `"%{ATTRIBUTE}"' peut être utilisée pour substituer la valeur d'un attribut dans la valeur littérale.
-as-string
Convertit le contenu de cet élément en chaîne de caractères (comme dans "XML::Grove::AsString") et le stocke dans FIELD. Valide uniquement avec -field ou -push-field.
-grove
Copie cet élément dans FIELD sans traitement supplémentaire. L'élément peut ensuite être traité ultérieurement lorsque les objets Perl sont manipulés. Valide uniquement avec -field ou -push-field. Si ToObjects est utilisé avec PerlSAX, cela utilisera XML::Grove::Builder pour construire l'élément grove.
-grove-contents
Utilisé avec -make, -grove-contents crée un objet mais prend ensuite tout le contenu de cet élément et le stocke dans Contents.

Si un élément d'action est une chaîne, cette chaîne est traitée comme un fragment de code Perl. Les substitutions simples suivantes sont effectuées sur le fragment pour fournir un accès facile aux informations en cours de conversion :

@ELEM@
L'objet qui a déclenché l'appel de cette action. Si ToObjects est utilisé avec PerlSAX, ce sera un hash avec le nom de l'élément et les attributs. Avec XML::Grove, ce sera l'objet élément. Avec Data::Grove, ce sera l'objet correspondant. Et avec XML::DOM, ce sera un XML::DOM::Element.

EXEMPLE

La liste de motifs-actions ci-dessous convertira le XML suivant représentant un schéma de base de données :

<schema>
  <table>
    <name>MyTable</name>
    <summary>A short summary</summary>
    <description>A long description that may
      contain a subset of HTML</description>
    <column>
      <name>MyColumn1</name>
      <summary>A short summary</summary>
      <description>A long description</description>
      <unique/>
      <non-null/>
      <default>42</default>
    </column>
  </table>
</schema>

en objets Perl ressemblant à :

[
  { Name => "MyTable",
    Summary => "A short summary",
    Description => $grove_object,
    Columns => [
      { Name => "MyColumn1",
        Summary => "A short summary",
        Description => $grove_object,
        Unique => 1,
        NonNull => 1,
        Default => 42
      }
    ]
  }
]

Voici un script Perl et une liste de motifs qui effectuent la conversion en utilisant le module de correspondance de nom simple XML::PatAct::MatchName. Le script accepte un fichier XML de schéma comme argument ($ARGV[0]) pour le script. Ce script crée un grove comme l'un de ses objets, il nécessite donc le module XML::Grove.

use XML::Parser::PerlSAX;
use XML::PatAct::MatchName;
use XML::PatAct::ToObjects;
my $patterns = [
  'schema'      => [ qw{ -holder                                  } ],
  'table'       => [ qw{ -make Schema::Table                      } ],
  'name'        => [ qw{ -field Name -as-string                   } ],
  'summary'     => [ qw{ -field Summary -as-string                } ],
  'description' => [ qw{ -field Description -grove                } ],
  'column'      => [ qw{ -make Schema::Column -push-field Columns } ],
  'unique'      => [ qw{ -field Unique -value 1                   } ],
  'non-null'    => [ qw{ -field NonNull -value 1                  } ],
  'default'     => [ qw{ -field Default -as-string                } ],
];
my $matcher = XML::PatAct::MatchName->new( Patterns => $patterns );
my $handler = XML::PatAct::ToObjects->new( Patterns => $patterns,
                                           Matcher => $matcher);
my $parser = XML::Parser::PerlSAX->new( Handler => $handler );
my $schema = $parser->parse(Source => { SystemId => $ARGV[0] } );

À FAIRE

  • Implémenter les actions de code Perl.
  • -as-xml pour écrire du XML dans le champ.
