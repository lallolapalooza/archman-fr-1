NOM

XmStringLength — Une fonction de chaîne composite qui obtient la longueur d'une chaîne composite

SYNTAXE

#include <Xm/Xm.h>
int XmStringLength(
XmString s1);

DESCRIPTION

Cette fonction est obsolète et existe pour des raisons de compatibilité avec les versions précédentes. Elle est remplacée par XmStringByteStreamLength. XmStringLength obtient la longueur d'une chaîne composite. Elle retourne le nombre d'octets dans s1, y compris toutes les balises, les indicateurs de direction et les séparateurs. Si la structure de la chaîne composite n'est pas valide, 0 (zéro) est retourné.

s1
Spécifie la chaîne composite

RETOUR

Retourne la longueur de la chaîne composite.

LIENS CORROBORANTS

XmStringByteStreamLength(3) et XmStringCreate(3).
