NOM

XmWidgetGetBaselines — Récupère les informations de ligne de base pour un widget

SYNTAXE

#include <Xm/Xm.h>
Boolean XmWidgetGetBaselines(
Widget widget,
Dimension **baselines,
int *line_count);

DESCRIPTION

XmWidgetGetBaselines retourne un tableau qui contient une ou plusieurs valeurs de ligne de base associées au widget spécifié. La ligne de base de toute ligne de texte donnée est un décalage vertical en pixels depuis l'origine de la boîte englobante du widget jusqu'à la ligne de base donnée.

widget
Spécifie l'ID du widget pour lequel les valeurs de ligne de base sont demandées
baselines
Retourne un tableau qui contient la valeur de chaque ligne de base de texte dans le widget. La fonction alloue de l'espace pour contenir le tableau retourné. L'application est responsable de la gestion de l'espace alloué. L'application peut récupérer cet espace alloué en appelant XtFree.
line_count
Retourne le nombre de lignes dans le widget

VALEUR DE RETOUR

Retourne une valeur booléenne qui indique si le widget contient une ligne de base. Si la valeur est True, la fonction retourne une valeur pour chaque ligne de base de texte. Si elle est False, la fonction n'a pas pu retourner de valeur de ligne de base.
