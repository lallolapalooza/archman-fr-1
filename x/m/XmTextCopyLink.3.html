NOM

XmTextCopyLink — Fonction Text qui copie un lien de la sélection primaire vers le presse-papiers

SYNTAXE

#include <Xm/Text.h>
Boolean XmTextCopyLink(
Widget widget,
Time time);

DESCRIPTION

XmTextCopyLink copie un lien du texte sélectionné de manière primaire vers le presse-papiers. Cette routine appelle les procédures XmNconvertCallback, potentiellement plusieurs fois, avec le membre selection de la XmConvertCallbackStruct défini sur CLIPBOARD et avec le membre parm défini sur XmLINK. Le widget Text lui-même ne copie aucun lien ; les procédures XmNconvertCallback sont responsables de copier le lien vers le presse-papiers et de prendre toutes les actions associées.

widget
Spécifie l'identifiant du widget Text.
time
Spécifie l'heure du transfert. Il doit s'agir de l'heure de l'événement qui a déclenché cette requête. Une source d'horodatage valide est la fonction XtLastTimestampProcessed.

Pour une définition complète de Text et de ses ressources associées, voir XmText(3).

RETOUR

Cette fonction retourne False si la sélection primaire est NULL, si le widget ne possède pas la sélection primaire, si la fonction est incapable d'acquérir la propriété de la sélection du presse-papiers, ou si aucune donnée n'est placée sur le presse-papiers. Sinon, elle retourne True.

CONNEXES
