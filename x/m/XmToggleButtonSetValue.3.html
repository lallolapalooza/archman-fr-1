NOM

XmToggleButtonSetValue — Fonction ToggleButton qui définit ou modifie l'état actuel

SYNTAXE

#include <Xm/ToggleB.h>
void XmToggleButtonSetValue(
Widget widget,
XmToggleButtonState state,
Boolean notify);

DESCRIPTION

XmToggleButtonSetValue définit ou modifie l'état actuel du ToggleButton.

widget
Spécifie l'ID du widget ToggleButton.
state
Spécifie si l'état du ToggleButton est sélectionné ou non sélectionné. Si la valeur est True, l'état du bouton est sélectionné ; si elle est False, l'état du bouton n'est pas sélectionné ; si elle est XmINDETERMINATE, l'état du bouton n'est ni l'un ni l'autre.
notify
Indique si XmNvalueChangedCallback est appelé ; il peut être True ou False. Le XmNvalueChangedCallback n'est appelé que lorsque cette fonction modifie l'état du ToggleButton. Lorsque cet argument est True et que le ToggleButton est un enfant d'un widget RowColumn dont le XmNradioBehavior est True, la définition du ToggleButton entraîne la désélection des autres enfants ToggleButton et ToggleButtonGadget du RowColumn.

Pour une définition complète de ToggleButton et de ses ressources associées, voir XmToggleButton(3).
