NOM

XmListSelectItem — Fonction de liste qui sélectionne un élément dans la liste

SYNOPSIS

#include <Xm/List.h>
void XmListSelectItem(
Widget widget,
XmString item,
Boolean notify);

DESCRIPTION

XmListSelectItem met en surbrillance et ajoute à la liste des éléments sélectionnés le premier élément de la liste qui correspond à item.

widget
Spécifie l'ID du widget List à partir de la liste duquel un élément est sélectionné.
item
Spécifie l'élément à sélectionner dans le widget List. Si item apparaît plus d'une fois dans la Liste, seule la première occurrence est correspondante.
notify
Spécifie une valeur booléenne qui, lorsqu'elle est TRUE, appelle le rappel de sélection pour le mode actuel. Du point de vue de l'interface applicative, appeler cette fonction avec notify à TRUE est indiscernable d'une action de sélection initiée par l'utilisateur. Lorsque notify est FALSE, aucun rappel n'est appelé.

Pour une définition complète de List et de ses ressources associées, voir XmList(3).

VOIR AUSSI

XmList(3) et XmListSelectPos(3).
