XmVaCreateSimpleOptionMenu(appel de bibliothèque) XmVaCreateSimpleOptionMenu(appel de bibliothèque)

NOM

XmVaCreateSimpleOptionMenu — Fonction de création pratique pour le widget RowColumn

SYNTAXE

#include <Xm/RowColumn.h>
Widget XmVaCreateSimpleOptionMenu(
Widget parent,
String name,
XmString option_label,
KeySym option_mnemonic,
int button_set,
XtCallbackProc callback);

DESCRIPTION

XmVaCreateSimpleOptionMenu crée une instance d'un widget RowColumn de type XmMENU_OPTION et retourne l'identifiant du widget associé. Cette routine utilise la convention d'appel de liste d'arguments de longueur variable (varargs) ANSI C.

Cette routine crée un OptionMenu et son sous-menu déroulant contenant des enfants de type PushButtonGadget ou CascadeButtonGadget. Le nom de chaque bouton est button_n, où n est un entier allant de 0 (zéro) au nombre de boutons du menu moins 1. Le nom de chaque séparateur est separator_n, où n est un entier allant de 0 (zéro) au nombre de séparateurs dans le menu moins 1. Les boutons et les séparateurs sont nommés et créés dans l'ordre où ils sont spécifiés dans la partie variable de la liste d'arguments.

parent
Spécifie l'identifiant du widget parent
name
Spécifie le nom du widget créé
option_label
Spécifie la chaîne de label à utiliser sur le côté gauche de l'OptionMenu.
option_mnemonic
Spécifie un keysym pour une touche qui, lorsqu'elle est pressée par l'utilisateur, affiche le panneau de menu déroulant associé.
button_set
Spécifie quel PushButtonGadget est initialement sélectionné. La valeur est l'entier n qui correspond au n-ième PushButtonGadget spécifié dans la partie variable de la liste d'arguments. Seul un PushButtonGadget peut être sélectionné, et seuls les PushButtonGadgets sont comptés pour déterminer l'entier n. Le premier PushButtonGadget est le numéro 0 (zéro).
callback
Spécifie une procédure de rappel à appeler lorsqu'un bouton est activé. Cette fonction de rappel est ajoutée à chaque bouton après sa création en tant que XmNactivateCallback du bouton. La fonction de rappel est appelée lorsqu'un bouton est activé, et le numéro du bouton est retourné dans le champ client_data.

La partie variable de la liste d'arguments est composée de groupes d'arguments. Le premier argument de chaque groupe est une constante ou une chaîne et détermine quels arguments suivent dans ce groupe. Le dernier argument de la liste doit être NULL. Voici les premiers arguments possibles dans chaque groupe de varargs :

XmVaPUSHBUTTON
Ceci est suivi de quatre arguments supplémentaires. L'ensemble spécifie un bouton dans le sous-menu déroulant de l'OptionMenu et certaines de ses valeurs de ressources. Le bouton créé est un PushButtonGadget. Voici les quatre arguments supplémentaires, dans l'ordre :
label
La chaîne de label, de type XmString
mnemonic
Le mnémonique, de type KeySym
accelerator
L'accélérateur, de type String
accelerator_text
Le texte de l'accélérateur, de type XmString
XmVaSEPARATOR
Ceci est suivi d'aucun argument supplémentaire. Il spécifie un séparateur dans le sous-menu déroulant de l'OptionMenu.
XmVaDOUBLE_SEPARATOR
Ceci est suivi d'aucun argument supplémentaire. Il spécifie un séparateur dans le sous-menu déroulant de l'OptionMenu. Le type de séparateur est XmDOUBLE_LINE.
resource_name
Ceci est suivi d'un argument supplémentaire, la valeur de la ressource, de type XtArgVal. La paire spécifie une ressource et sa valeur pour le sous-menu déroulant.
XtVaTypedArg
Ceci est suivi de quatre arguments supplémentaires. L'ensemble spécifie une ressource et sa valeur pour le sous-menu déroulant. Une conversion de type de ressource est effectuée si nécessaire. Voici les quatre arguments supplémentaires, dans l'ordre :
name
Le nom de la ressource, de type String
type
Le type de la valeur de ressource fournie, de type String
value
La valeur de la ressource (ou un pointeur vers la valeur de la ressource, selon le type et la taille de la valeur), de type XtArgVal
size
La taille de la valeur de ressource en octets, de type int
XtVaNestedList
Ceci est suivi d'un argument supplémentaire de type XtVarArgsList. Cet argument est une liste imbriquée de varargs retournée par XtVaCreateArgsList.

L'utilisateur peut spécifier des ressources dans un fichier de ressources pour les widgets et gadgets créés automatiquement d'un OptionMenu. La liste suivante identifie les noms de ces widgets (ou gadgets) et les zones associées de l'OptionMenu :

Gadget de label de l'Option Menu
OptionLabel
Bouton Cascade de l'Option Menu
OptionButton

Pour plus d'informations sur les listes d'arguments de longueur variable, consultez la documentation X Toolkit Intrinsics.

Un certain nombre de ressources existent spécifiquement pour être utilisées avec cette routine et d'autres routines de création de menus simples. Pour une définition complète de RowColumn et de ses ressources associées, voir XmRowColumn(3).

RETOUR

Retourne l'identifiant du widget RowColumn.

VOIR AUSSI

XmCreateOptionMenu(3), XmCreateRowColumn(3), XmCreateSimpleOptionMenu(3), et XmRowColumn(3).
