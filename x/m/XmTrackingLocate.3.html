NOM

XmTrackingLocate — Une fonction Toolkit qui fournit une interaction modale

SYNTAXE

#include <Xm/Xm.h>
Widget XmTrackingLocate(
Widget widget,
Cursor cursor,
Boolean confine_to);

DESCRIPTION

XmTrackingLocate fournit une interface modale pour la sélection d'un composant. Elle est destinée à supporter l'aide contextuelle. Cette fonction est implémentée comme XmTrackingEvent.

NOTE : Cette fonction est obsolète et existe pour la compatibilité avec les versions précédentes. Elle a été remplacée par XmTrackingEvent.

widget
Spécifie l'identifiant du widget à utiliser comme base de l'interaction modale. C'est-à-dire, le widget dans lequel l'interaction doit se produire, généralement un shell de plus haut niveau.
cursor
Spécifie le curseur à utiliser pour le pointeur pendant l'interaction. Il s'agit d'un nom de curseur X standard.
confine_to
Spécifie si le curseur doit être confiné ou non à widget

RETOUR

Retourne le widget ou le gadget qui contient le pointeur lorsque BSelect est relâché ou qu'une touche est relâchée. Si aucun widget ou gadget ne contient le pointeur, la fonction retourne NULL.

VOIR AUSSI

XmTrackingEvent(3).
