NOM

XmListSetKbdItemPos — Fonction de liste qui place le curseur de localisation à une position spécifiée

SYNTAXE

#include <Xm/List.h>
Boolean XmListSetKbdItemPos(
Widget widget,
int position);

DESCRIPTION

XmListSetKbdItemPos place le curseur de localisation sur l'élément spécifié par position. Cette fonction ne détermine pas si l'élément à la position spécifiée est sélectionné ou non.

widget
Spécifie l'identifiant du widget Liste.
position
Spécifie la position de l'élément sur lequel le curseur de localisation est placé. Une valeur de 1 indique le premier élément de la liste ; une valeur de 2 indique le deuxième élément ; et ainsi de suite. Une valeur de 0 (zéro) place le curseur de localisation sur le dernier élément de la liste.

Pour une définition complète de List et de ses ressources associées, voir XmList(3).

VALEUR

Retourne False si aucun élément n'existe à la position spécifiée ou si la liste est vide ; sinon, retourne True.
