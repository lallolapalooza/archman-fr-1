NOM

XmContainerPasteLink — Fonction du widget Container pour insérer des liens depuis le presse-papiers

SYNTAXE

#include <Xm/Container.h>
Boolean XmContainerPasteLink(
Widget container);

DESCRIPTION

XmContainerPasteLink demande le transfert de données depuis la sélection du presse-papiers vers le Container. Cette routine appelle les procédures XmNdestinationCallback du widget avec le membre selection de la XmDestinationCallbackStruct défini sur CLIPBOARD et avec le membre operation défini sur XmLINK. Le widget Container lui-même n'effectue aucun transfert ; les procédures XmNdestinationCallback sont responsables de l'insertion du lien vers la sélection du presse-papiers et de la prise de toute action connexe.

container
Spécifie l'ID du widget Container.

Pour une définition complète du Container et de ses ressources associées, voir XmContainer(3).

VALEUR DE RETOUR

La fonction renvoie False si aucun transfert de données n'a lieu. Sinon, elle renvoie True.

VOIR AUSSI

XmContainer(3).
