NOM

XmCreateFormDialog — Fonction de création pratique pour FormDialog

SYNTAXE

#include <Xm/Form.h>
Widget XmCreateFormDialog(
Widget parent,
String name,
ArgList arglist,
Cardinal argcount);

DESCRIPTION

XmCreateFormDialog est une fonction de création pratique qui crée un DialogShell et un enfant non géré Form du DialogShell. Un FormDialog est utilisé pour les interactions non prises en charge par l'ensemble de boîtes de dialogue standard. Cette fonction ne crée pas automatiquement d'étiquettes, de boutons ou d'autres composants de boîte de dialogue. Ces composants doivent être ajoutés par l'application après la création du FormDialog.

Utilisez XtManageChild pour afficher le FormDialog (en passant le Form comme paramètre widget) ; utilisez XtUnmanageChild pour le masquer.

XmCreateFormDialog force la valeur de la ressource Shell XmNallowShellResize à True.

parent
Spécifie l'identifiant du widget parent
name
Spécifie le nom du widget créé
arglist
Spécifie la liste d'arguments
argcount
Spécifie le nombre de paires attribut/valeur dans la liste d'arguments (arglist)

Pour une définition complète de Form et de ses ressources associées, consultez XmForm(3).

VALEUR DE RETOUR

Retourne l'identifiant du widget Form.

LIÉS
