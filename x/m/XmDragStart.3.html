NOM

XmDragStart — Une fonction de glisser-déposer qui initie une transaction de glisser-déposer

SYNOPSIS

#include <Xm/DragDrop.h>
Widget XmDragStart(
Widget widget,
XEvent *event,
ArgList arglist,
Cardinal argcount);

DESCRIPTION

XmDragStart initie une opération de glisser. Cette routine renvoie le widget DragContext qu'elle initialise pour la transaction de glisser-déposer associée. Le toolkit est responsable de libérer le DragContext une fois la transaction de glisser-déposer terminée.

widget
Spécifie l'identifiant du plus petit widget et/ou gadget qui englobe les éléments source sélectionnés pour une opération de glisser.
event
Spécifie l'XEvent qui a déclenché l'opération de glisser. Cet événement doit être un événement ButtonPress.
arglist
Spécifie la liste d'arguments. Toutes les ressources XmDragContext non spécifiées dans la liste d'arguments sont obtenues de la base de données des ressources ou définies à leurs valeurs par défaut.
argcount
Spécifie le nombre de paires attribut/valeur dans la liste d'arguments (arglist)

Pour une définition complète de DragContext et de ses ressources associées, voir XmDragContext(3).

RETOUR

Renvoie l'identifiant du widget DragContext qui contrôle cette transaction de glisser-déposer. Renvoie NULL si le glisser ne peut pas être initié.

VOIR AUSSI

XmDragCancel(3) et XmDragContext(3).
