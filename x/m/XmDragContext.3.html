NOM

XmDragContext — La classe de widget DragContext

SYNTAXE

#include <Xm/DragDrop.h>

DESCRIPTION

Les DragContext sont des widgets spéciaux utilisés dans les transactions de glisser-déposer. Un DragContext est implémenté comme un widget, mais un client ne crée pas explicitement de widget DragContext. Au lieu de cela, un client initie une transaction de glisser-déposer en appelant XmDragStart, et cette routine initialise et retourne un widget DragContext. Il existe un DragContext unique pour chaque opération de glisser. Le toolkit libère un DragContext une fois la transaction terminée ; par conséquent, un programmeur d'application ne doit pas détruire explicitement un DragContext.

Les clients initiateurs et récepteurs utilisent tous deux des DragContexts pour suivre l'état d'une transaction. Lorsque l'initiateur et le récepteur d'une transaction sont dans le même client, ils partagent la même instance de DragContext. S'ils sont dans des clients différents, il existe deux DragContexts distincts. Dans ce cas, l'initiateur appelle XmDragStart et le toolkit fournit un DragContext pour le client récepteur. Les seules ressources pertinentes pour le récepteur sont XmNexportTargets et XmNnumExportTargets. Ces deux éléments peuvent être passés comme arguments à la fonction XmDropSiteRetrieve pour obtenir des informations sur le site de dépôt actuel.

En général, pour recevoir des données, un site de dépôt doit partager au moins un type de cible et une opération en commun avec une source de glisser. La ressource DragContext, XmNexportTargets, identifie les cibles de sélection pour la source de glisser. Ces cibles d'exportation sont comparées à la liste de ressources XmNimportTargets spécifiée par un site de dépôt. La ressource DragContext, XmNdragOperations, identifie les opérations valides qui peuvent être appliquées aux données sources par l'initiateur. La ressource homologue du site de dépôt est XmNdropSiteOperations, qui indique les opérations prises en charge par un site de dépôt.

Un client utilise des widgets DragIcon pour définir les effets d'animation de survol associés à une transaction de glisser-déposer donnée. Un initiateur spécifie un ensemble d'icônes de glisser, sélectionne un modèle de mélange et définit les couleurs de curseur de premier plan et d'arrière-plan avec les ressources DragContext.

Le type de visuel de survol utilisé pour représenter une opération de glisser dépend du style du protocole de glisser. En mode de pré-enregistrement, le serveur est saisi, et un curseur ou une pixmap peut être utilisé comme visuel de survol. En mode dynamique, les visuels de survol doivent être implémentés avec le curseur X. Si le style du protocole de glisser résultant est Drop Only ou None et que XmNdragInitiatorProtocolStyle est XmDRAG_DYNAMIC ou XmDRAG_PREFER_DYNAMIC, alors un style de visuel dynamique (curseur) est utilisé. Sinon, un style de visuel de pré-enregistrement est utilisé.

Classes

DragContext hérite du comportement et des ressources de Core.

Le pointeur de classe est xmDragDragContextClass.

Le nom de la classe est XmDragContext.

Nouvelles ressources

Le tableau suivant définit un ensemble de ressources de widget utilisées par le programmeur pour spécifier les données. Le programmeur peut également définir les valeurs des ressources pour les classes héritées afin de définir les attributs de ce widget. Pour référencer une ressource par nom ou par classe dans un fichier .Xdefaults, supprimez le préfixe XmN ou XmC et utilisez les lettres restantes. Pour spécifier l'une des valeurs définies pour une ressource dans un fichier .Xdefaults, supprimez le préfixe Xm et utilisez les lettres restantes (en minuscules ou en majuscules, mais incluez les underscores entre les mots). Les codes dans la colonne d'accès indiquent si la ressource donnée peut être définie au moment de la création (C), définie à l'aide de XtSetValues (S), récupérée à l'aide de XtGetValues (G), ou n'est pas applicable (N/A).

XmNblendModel
Spécifie quelle combinaison d'icônes de glisser-déposer sont mélangées pour produire un visuel de survol lors du glisser-déposer.
XmBLEND_ALL
Mélange les trois icônes de glisser-déposer : l'icône source, l'icône d'état et l'icône d'opération. Les icônes sont superposées de haut en bas, l'icône d'opération étant au-dessus et l'icône source en dessous. Le point chaud est dérivé de l'icône d'état.
XmBLEND_STATE_SOURCE
Mélange uniquement les icônes d'état et source. Le point chaud est dérivé de l'icône d'état.
XmBLEND_JUST_SOURCE
Spécifie que seule l'icône source est utilisée, que l'initiateur met à jour au besoin.
XmBLEND_NONE
Spécifie qu'aucun visuel de survol lors du glisser-déposer n'est généré. Le client suit le statut du site de dépôt via les routines de rappel et met à jour les visuels de survol si nécessaire.
XmNclientData
Spécifie les données client à passer à XmNconvertProc lorsqu'elle est invoquée.
XmNconvertProc
Si XmNincremental est True, spécifie une procédure de type XtConvertSelectionIncrProc qui convertit les données source dans le(s) format(s) demandé(s) par le client récepteur. Le widget passé à cette procédure est le widget DragContext. L'atome de sélection passé est _MOTIF_DROP. Si XmNincremental est False, la procédure est une XtConvertSelectionProc et doit ignorer les arguments max_length, client_data et request_id et doit gérer la conversion de manière atomique. Les données retournées par XmNconvertProc doivent être allouées en utilisant XtMalloc et seront libérées automatiquement par la boîte à outils après le transfert. Pour plus d'informations sur les procédures de conversion de sélection, voir X Toolkit Intrinsics—C Language Interface.
XmNcursorBackground
Spécifie la valeur du pixel d'arrière-plan du curseur.
XmNcursorForeground
Spécifie la valeur du pixel d'avant-plan du curseur lorsque l'icône d'état n'est pas mélangée. Cette ressource prend par défaut la couleur d'avant-plan du widget passé à la fonction XmDragStart.
XmNdragDropFinishCallback
Spécifie la liste des rappels qui sont appelés lorsque la transaction est terminée. Le type de la structure dont l'adresse est passée à ce rappel est XmDragDropFinishCallbackStruct. La raison envoyée par le rappel
k est XmCR_DRAG_DROP_FINISH.
XmNdragMotionCallback
Spécifie la liste des callbacks qui sont appelés lorsque le pointeur bouge. Le type de structure dont l'adresse est passée à ce callback est XmDragMotionCallbackStruct. La raison envoyée par le callback est XmCR_DRAG_MOTION.
XmNdragOperations
Spécifie l'ensemble des opérations valides associées à un client initiateur pour une transaction de glisser-déposer. Cette ressource est un masque de bits formé en combinant une ou plusieurs des valeurs suivantes à l'aide d'une opération bit à bit telle que le OU inclusif (|) : XmDROP_COPY, XmDROP_LINK, XmDROP_MOVE. La valeur XmDROP_NOOP pour cette ressource indique qu'aucune opération n'est valide. Pour les widgets Text et TextField, cette ressource est définie sur XmDROP_COPY | XmDROP_MOVE ; pour les widgets List, elle est définie sur XmDROP_COPY.
XmNdropFinishCallback
Spécifie la liste des callbacks qui sont appelés lorsque le dépôt est terminé. Le type de la structure dont l'adresse est passée à ce callback est XmDropFinishCallbackStruct. La raison envoyée par le callback est XmCR_DROP_FINISH.
XmNdropSiteEnterCallback
Spécifie la liste des callbacks qui sont appelés lorsque le pointeur entre dans un site de dépôt. Le type de la structure dont l'adresse est passée à ce callback est XmDropSiteEnterCallbackStruct. La raison envoyée par le callback est XmCR_DROP_SITE_ENTER.
XmNdropSiteLeaveCallback
Spécifie la liste des callbacks qui sont appelés lorsque le pointeur quitte un site de dépôt. Le type de la structure dont l'adresse est passée à ce callback est XmDropSiteLeaveCallbackStruct. La raison envoyée par le callback est XmCR_DROP_SITE_LEAVE.
XmNdropStartCallback
Spécifie la liste des callbacks qui sont appelés lorsqu'un dépôt est initié. Le type de la structure dont l'adresse est passée à ce callback est XmDropStartCallbackStruct. La raison envoyée par le callback est XmCR_DROP_START.
XmNexportTargets
Spécifie la liste des atomes cibles associés à cette source. Cette ressource identifie les cibles de sélection vers lesquelles cette source peut être convertie.
XmNincremental
Spécifie une valeur booléenne qui indique si le transfert du côté de l'initiateur utilise le mécanisme de transfert de sélection incrémentiel de Xt décrit dans X Toolkit Intrinsics—C Language Interface. Si la valeur est Vrai, l'initiateur utilise le transfert incrémentiel ; si la valeur est Faux, l'initiateur utilise le transfert atomique.
XmNinvalidCursorForeground
Spécifie la valeur de pixel de premier plan du curseur lorsque l'état est invalide. Cette ressource est par défaut la valeur de la ressource XmNcursorForeground.
XmNnoneCursorForeground
Spécifie la valeur de pixel de premier plan du curseur lorsque l'état est aucun. Cette ressource est par défaut la valeur de la ressource XmNcursorForeground.
XmNnumExportTargets
Spécifie le nombre d'entrées dans la liste des cibles d'exportation.
XmNoperationChangedCallback
Spécifie la liste des callbacks qui sont appelés lorsque le glisser-déposer est démarré et lorsque l'utilisateur demande qu'une opération différente soit appliquée au dépôt. Le type de la structure dont l'adresse est passée à ce callback est XmOperationChangedCallbackStruct. La raison envoyée par le callback est XmCR_OPERATION_CHANGED.
XmNoperationCursorIcon
Spécifie l'icône de curseur utilisée pour désigner le type d'opération effectuée par la transaction de glisser-déposer. Si NULL, les ressources XmScreen fournissent des icônes par défaut pour les opérations de copie, de lien et de déplacement.
XmNsourceCursorIcon
Spécifie l'icône de curseur utilisée pour représenter la source lorsqu'un style visuel dynamique est utilisé. Si NULL, la ressource XmNdefaultSourceCursorIcon de XmScreen fournit une icône de curseur par défaut.
XmNsourcePixmapIcon
Spécifie l'icône pixmap utilisée pour représenter la source lorsqu'un style visuel pré-enregistré est utilisé. L'icône est utilisée conjointement avec la palette de couleurs du widget passé à XmDragStart. Si NULL, XmNsourceCursorIcon est utilisé.
XmNstateCursorIcon
Spécifie l'icône de curseur utilisée pour désigner l'état d'un site de dépôt. Si NULL, les ressources XmScreen fournissent des icônes par défaut pour une condition de site de dépôt valide, invalide et nulle.
XmNtopLevelEnterCallback
Spécifie la liste des callbacks qui sont appelés lorsque le pointeur entre dans une fenêtre de niveau supérieur ou une fenêtre racine (en raison d'un changement d'écran). Le type de la structure dont l'adresse est passée à ce callback est XmTopLevelEnterCallbackStruct. La raison envoyée par le callback est XmCR_TOP_LEVEL_ENTER.
XmNtopLevelLeaveCallback
Spécifie la liste des callbacks qui sont appelés lorsque le pointeur quitte une fenêtre de niveau supérieur ou la fenêtre racine (en raison d'un changement d'écran). Le type de la structure dont l'adresse est passée à ce callback est XmTopLevelLeaveCallbackStruct. La raison envoyée par le callback est XmCR_TOP_LEVEL_LEAVE.
XmNvalidCursorForeground
Spécifie la valeur de pixel de premier plan du curseur désigné comme icône de curseur valide.

Informations de rappel

Chacun des rappels de DragContext a une structure de rappel associée.

Un pointeur vers la structure suivante est passé au rappel XmNdragDropFinishCallback:

typedef struct
{
        int reason;
        XEvent  *event;
        Time timeStamp;
}XmDragDropFinishCallbackStruct, *XmDragDropFinishCallback;
raison
Indique la raison pour laquelle le rappel a été appelé.
événement
Pointe vers l'XEvent qui a déclenché le rappel.
horodatage
Spécifie l'heure à laquelle le glisser ou le déposer a été terminé.

Un pointeur vers la structure suivante est passé aux rappels pour XmNdragMotionCallback:

typedef struct
{
        int reason;
        XEvent *event;
        Time timeStamp;
        unsigned char operation;
        unsigned char operations;
        unsigned char dropSiteStatus;
        Position x;
        Position y;
}XmDragMotionCallbackStruct, *XmDragMotionCallback;
raison
Indique la raison pour laquelle le rappel a été appelé.
événement
Pointe vers l'XEvent qui a déclenché le rappel.
horodatage
Spécifie l'horodatage de l'événement logique.
opération
Identifie une opération.
Si le toolkit vient d'appeler le XmNdragProc d'un site de dépôt, le toolkit initialise operation à la valeur du membre operation de la XmDragProcCallbackStruct au moment où le XmNdragProc du site de dépôt renvoie.
Si le toolkit n'a pas appelé de XmNdragProc et que le pointeur se trouve dans un site de dépôt actif, le toolkit initialise operation en sélectionnant une opération à partir du ET bit à bit de la valeur initiale du membre operations et de la valeur de la ressource XmNdropSiteOperations du site de dépôt. Le toolkit recherche d'abord dans cet ensemble XmDROP_MOVE, puis XmDROP_COPY, puis XmDROP_LINK, et initialise operation à la première opération trouvée dans l'ensemble. Si le toolkit ne trouve aucune de ces opérations dans l'ensemble, il initialise operation à XmDROP_NOOP.
Si le toolkit n'a pas appelé de XmNdragProc et que le pointeur ne se trouve pas dans un site de dépôt actif, le toolkit initialise operation en sélectionnant une opération à partir de la valeur initiale du membre operations. Le toolkit recherche d'abord dans cet ensemble XmDROP_MOVE, puis XmDROP_COPY, puis XmDROP_LINK, et initialise operation à la première opération trouvée dans l'ensemble. Si le toolkit ne trouve aucune de ces opérations dans l'ensemble, il initialise operation à XmDROP_NOOP.
opérations
Indique l'ensemble des opérations prises en charge pour les données source.
Si le toolkit vient d'appeler le XmNdragProc d'un site de dépôt, le toolkit initialise operations au ET bit à bit de XmNdropSiteOperations du site de dépôt et de la valeur du membre operations de la XmDragProcCallbackStruct au moment où le XmNdragProc du site de dépôt renvoie. Si l'ensemble d'opérations résultant est vide, le toolkit initialise operations à XmDROP_NOOP.
Si le toolkit n'a pas appelé de XmNdragProc et que l'utilisateur ne sélectionne pas d'opération (en appuyant sur une touche modificatrice), le toolkit initialise operations à la valeur de la ressource XmNdragOperations du DragContext.
Si le toolkit n'a pas appelé de XmNdragProc et que l'utilisateur sélectionne une opération, le toolkit initialise operations au ET bit à bit de l'opération correspondante et de la valeur de la ressource XmNdragOperations du DragContext. Si l'ensemble d'opérations résultant est vide, le toolkit initialise operations à XmDROP_NOOP.
statutSiteDepot
Indique si un site de dépôt est valide ou non.
Si le toolkit vient d'appeler le XmNdragProc d'un site de dépôt, le toolkit initialise statutSiteDepot à la valeur du membre statutSiteDepot de la XmDragProcCallbackStruct au moment où le XmNdragProc du site de dépôt renvoie.
Si le toolkit n'a pas appelé de XmNdragProc, il initialise statutSiteDepot comme suit : le toolkit initialise statutSiteDepot à XmNO_DROP_SITE si le pointeur se trouve sur un site de dépôt inactif ou s'il ne se trouve sur aucun site de dépôt. Le toolkit initialise statutSiteDepot à XmDROP_SITE_VALID si toutes les conditions suivantes
•
Le pointeur se trouve sur un site de dépôt actif.
•
Les ressources XmNexportTargets du DragContext et XmNimportTargets du DropSite sont compatibles.
•
La valeur initiale du membre operation n'est pas XmDROP_NOOP.
•
Le pointeur se trouve sur un site de dépôt actif.
•
Les ressources XmNexportTargets du DragContext et XmNimportTargets du DropSite sont compatibles.
•
La valeur initiale du membre operation n'est pas XmDROP_NOOP.
Sinon, le toolkit initialise dropSiteStatus à XmDROP_SITE_INVALID.

Un membre d'entrée/sortie qui indique l'état de l'action de dépôt. Après le retour de la dernière procédure de rappel, la valeur finale de ce membre détermine les effets de transition visuelle qui seront appliqués. Il existe deux valeurs :
XmDROP_SUCCESS

XmDROP_FAILURE
Le dépôt a échoué.

Un pointeur vers la structure suivante est transmis aux rappels pour XmNdropProc :

typedef struct
{
        int reason;
        XEvent  *event;
        Time timeStamp;
        unsigned char operation;
        unsigned char operations;
        unsigned char dropSiteStatus;
        int dropAction;
        Position x;
        Position y;

reason
Indique la raison pour laquelle le rappel a été déclenché.
event
Pointe vers le XEvent qui a déclenché le rappel.
timeStamp
Spécifie le moment où l'événement de franchissement s'est produit.
operation
Indique l'opération de glisser-déposer sélectionnée.
Si le pointeur se trouve sur un site de dépôt actif lorsque le dépôt commence, la boîte à outils initialise operation en calculant l'intersection logique (ET bit à bit) des opérations prises en charge par le site de dépôt (déterminées par XmNdropOperations) et des opérations demandées par le contexte de glisser (déterminées par le membre operations de la structure XmDropProcCallbackStruct au moment où le XmNdropProc du site de dépôt renvoie). La boîte à outils recherche d'abord XmDROP_MOVE, puis XmDROP_COPY, puis XmDROP_LINK dans cet ensemble et initialise operation avec la première opération trouvée. Si aucune de ces opérations n'est trouvée, elle l'initialise à XmDROP_NOOP.
Si le pointeur ne se trouve pas sur un site de dépôt actif lorsque le dépôt commence, la boîte à outils initialise operation en sélectionnant une opération à partir de la valeur initiale du membre operations. La boîte à outils recherche d'abord XmDROP_MOVE, puis XmDROP_COPY, puis XmDROP_LINK dans cet ensemble et initialise operation avec la première opération trouvée. Si elle ne trouve aucune de ces opérations dans l'ensemble, elle l'initialise à XmDROP_NOOP.
operations
Indique l'ensemble des opérations prises en charge pour les données sources.
Si le pointeur se trouve sur un site de dépôt actif lorsque le dépôt commence, la boîte à outils initialise operations avec l'intersection logique (ET bit à bit) des XmNdropOperations du site de dépôt et de la valeur du membre operations de la structure XmDropProcCallbackStruct au moment où le XmNdropProc du site de dépôt renvoie. Si l'ensemble résultant d'opérations est vide, la boîte à outils initialise operations à XmDROP_NOOP.
Si le pointeur ne se trouve pas sur un site de dépôt actif lorsque le dépôt commence et si l'utilisateur ne sélectionne pas d'opération (en appuyant sur une touche modificatrice), la boîte à outils initialise operations avec la valeur de la ressource XmNdragOperations du DragContext.
Si le pointeur ne se trouve pas sur un site de dépôt actif lorsque le dépôt commence et si l'utilisateur sélectionne une opération, la boîte à outils initialise operations avec l'intersection logique (ET bit à bit) de l'opération correspondante et de la valeur de la ressource XmNdragOperations du DragContext. Si l'ensemble résultant d'opérations est vide, la boîte à outils initialise operations à XmDROP_NOOP.
dropSiteStatus
Indique si un site de dépôt est valide ou non.
Si le pointeur se trouve sur un site de dépôt actif lorsque le dépôt commence, la boîte à outils initialise dropSiteStatus avec la valeur du membre dropSiteStatus de la structure XmDropProcCallbackStruct au moment où le XmNdropProc du site de dépôt renvoie.
Si le pointeur ne se trouve pas sur un site de dépôt actif lorsque le dépôt commence, la boîte à outils initialise dropSiteStatus à XmNO_DROP_SITE.
Ce champ est invalide si le champ dropAction est défini sur XmDROP_CANCEL.
dropAction
Un membre ENTRÉE/SORTIE qui identifie l'action de dépôt. Les valeurs sont XmDROP, XmDROP_CANCEL, XmDROP_HELP et XmDROP_INTERRUPT. La valeur de dropAction peut être modifiée pour changer l'action réellement initiée. La valeur XmDROP_INTERRUPT n'est actuellement pas prise en charge ; si elle est spécifiée, elle sera interprétée comme XmDROP_CANCEL.
x
Indique la coordonnée x du pointeur dans les coordonnées de la fenêtre racine.
y
Indique la coordonnée y du pointeur dans les coordonnées de la fenêtre racine.

XmDragContext(3) — openmotif

NOM

XmDragContext — Une primitive de widget de gestion du glisser-déposer

SYNTAXIS

#include <Xm/DragDrop.h>

DESCRIPTION

La XmDragContext est une structure de données qui contient des informations relatives à une opération de glisser-déposer. Elle est renvoyée par les fonctions XmDragStart et est utilisée par diverses autres fonctions de glisser-déposer.

La table suivante répertorie les combinaisons de touches qui déclenchent les routines d'action de glisser-déposer. Les noms des touches suivantes sont répertoriés dans la syntaxe du tableau de traduction des événements de touches standard X. Ce format est celui utilisé par Motif pour spécifier les actions du widget correspondant à une touche donnée. Un bref aperçu du format est fourni sous VirtualBindings(3). Pour une description complète du format, veuillez vous référer à la Documentation des intrinsèques du kit d'outils X.

Routines d'action

Les routines d'action de XmDragContext sont :

CancelDrag():
Annule l'opération de glisser-déposer et libère le DragContext associé.
DragKey(Chaîne)
Si la valeur de Chaîne est Left, Right, Up ou Down, cette action déplace l'objet déplacé dans la position correspondante. Toute autre valeur de Chaîne est ignorée.
DragMotion():
Déplace les données sélectionnées au fur et à mesure que le pointeur se déplace.
FinishDrag():
Termine l'opération de glisser-déposer et lance l'opération de déposer.
HelpDrag():
Initie un dépôt conditionnel qui permet au destinataire de fournir des informations d'aide à l'utilisateur. L'utilisateur peut annuler ou poursuivre l'opération de dépôt en réponse à ces informations.

Liaisons virtuelles

Les liaisons pour les touches virtuelles sont spécifiques au fournisseur. Pour plus d'informations sur les liaisons pour les boutons et les touches virtuelles, voir VirtualBindings(3).
