NOM

XmMultiListSelectRow — Fonction MultiList pour sélectionner une ligne dans la liste

SYNTAXE

#include <Xm/MultiList.h>
void XmMultiListSelectRow(
Widget widget,
XmString row,
Boolean notify);

DESCRIPTION

XmMultiListSelectRow met en évidence la ligne spécifiée dans le widget MultiList.

widget
Spécifie l'identifiant du widget MultiList à partir duquel un élément est sélectionné.
row
Spécifie le numéro de ligne (commençant à 0) à sélectionner dans le widget MultiList.
notify
Spécifie une valeur booléenne qui, lorsqu'elle est VRAIE, appelle le rappel de sélection pour le mode actuel. Du point de vue de l'interface de l'application, l'appel de cette fonction avec notify VRAI est indiscernable d'une action de sélection initiée par l'utilisateur. Lorsque notify est FAUX, aucun rappel n'est appelé.

Pour une définition complète de MultiList et de ses ressources associées, voir XmMultiList(3).

VOIR AUSSI

XmMultiList(3).
