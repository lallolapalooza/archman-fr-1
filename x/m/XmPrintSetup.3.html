XmPrintSetup(3)

Paquet: openmotif

Licences: LGPL-2.1-or-later

XmPrintSetup(library call) XmPrintSetup(library call)

NOM

XmPrintSetup — configuration et création d'un widget Print Shell

SYNTAXE

#include <Xm/Print.h>
Widget XmPrintSetup(
Widget video_widget,
Screen *print_screen,
String print_shell_name,
ArgList args,
Cardinal num_args);

DESCRIPTION

Une fonction qui effectue la configuration appropriée et crée un XmPrintShell réalisé qu'elle retourne à l'appelant. Cette fonction masque les détails de Xt pour configurer une hiérarchie de shell d'impression valide pour l'application. Elle est également destinée à encourager la cohérence dans la manière dont les applications enracinent leur hiérarchie de widgets d'impression.

print_screen doit appartenir à une connexion Display qui a déjà été initialisée avec Xt.

Le video_widget est utilisé pour accéder au contexte d'application, au nom et à la classe de l'application, et à argc/argv stockés dans le applicationShell qui racine ce widget. Si aucun applicationShell n'est trouvé, NULL argv/argc sont utilisés.

XmPrintSetup crée ensuite un ApplicationShell non réalisé avec le même nom et la même classe que celui fourni par l'affichage vidéo, sur l'affichage d'impression et sur l'écran d'impression spécifié.

Un XmPrintShell est alors créé en tant qu'enfant de ce shell de niveau supérieur, en utilisant XtCreatePopupShell, avec le nom print_shell_name, et en utilisant les args fournis. Il réalise ensuite et affiche le shell d'impression, en utilisant XtPopup avec XtGrabNone.

De cette façon, les fichiers de ressources de l'application et les utilisateurs peuvent spécifier des attributs spécifiques à l'impression en utilisant la syntaxe suivante (si print_shell_name est "Print") :

Dtpad.Print*textFontList: somefont
*Print*background:white
*Print*highlightThickness:0
video_widget
Un widget vidéo pour récupérer les données vidéo de l'application.
print_screen
Un écran d'impression sur l'affichage d'impression - spécifie l'écran sur lequel le nouveau shell est créé.
print_shell_name
Spécifie le nom du XmPrintShell créé sur le serveur d'impression X.
args
Spécifie la liste d'arguments à partir de laquelle obtenir les ressources pour le XmPrintShell.
num_args
Spécifie le nombre d'arguments dans la liste d'arguments.

VALEUR DE RETOUR

L'identifiant du widget XmPrintShell créé sur la connexion du serveur d'impression X, ou NULL si une erreur s'est produite.

ERREURS/AVERTISSEMENTS

Aucun.

EXEMPLES

À partir du rappel OK et du rappel SetUp du widget de dialogue d'impression principal :

static void
printOKCB(Widget, XtPointer call_data, XtPointer client_data)
{
  AppPrint *p = (AppPrint *) client_data;
  DtPrintSetupCallbackStruct *pbs =
                         (XmPrintCallbackStruct *) call_data;
  /* connexion si ce n'est pas déjà fait.
     le rappel de dialogue d'impression fournit toujours un
             nom d'imprimante valide, un affichage d'impression et un écran
             déjà initialisés : XpInitContext appelé */
 */
  p->print_shell = XmPrintSetup (widget, pbs->print_screen,
                                              "Print", NULL, 0);
  ...
}
