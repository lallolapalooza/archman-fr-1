NOM

XmRendition — Le registre de Rendition

SYNTAXE

#include <Xm/Xm.h>
XmRendition

DESCRIPTION

XmRendition est un pseudo-widget utilisé pour le rendu des XmStrings. XmRendition a deux parties : XmStringTag et informations de rendu. La partie XmStringTag peut être mise en correspondance avec un XmStringTag associé à un composant LOCALE, CHARSET, ou RENDITION[BEGIN|END] dans XmString. Les informations de rendu contiennent des informations sur la police ou le jeu de polices, les couleurs, les tabulations et les lignes à utiliser pour le rendu d'un composant texte.

Si une ressource dans une rendition n'est pas spécifiée, généralement en la définissant à XmAS_IS ou XmUNSPECIFIED_PIXEL, alors la valeur à utiliser pour cette ressource est la valeur de la rendition immédiatement précédente dans XmString. Si cette valeur n'est pas spécifiée, alors la valeur précédente est utilisée, et ainsi de suite. Si aucune rendition ne spécifie de valeur pour une ressource, une valeur par défaut sera utilisée.

Classes

XmRendition n'hérite d'aucune classe de widget.

Nouvelles Ressources

Le tableau suivant définit un ensemble de ressources de widget utilisées par le programmeur pour spécifier des données. Pour faire référence à une ressource par son nom ou sa classe dans un fichier .Xdefaults, supprimez le préfixe XmN ou XmC et utilisez les lettres restantes. Pour spécifier l'une des valeurs définies pour une ressource dans un fichier .Xdefaults, supprimez le préfixe Xm et utilisez les lettres restantes (en minuscules ou en majuscules, mais incluez les éventuels underscores entre les mots). Les codes dans la colonne d'accès indiquent si la ressource donnée peut être définie à la création (C), définie en utilisant XmRenditionUpdate (S), récupérée en utilisant XmRenditionRetrieve (G), ou n'est pas applicable (N/A).

XmNrenditionBackground
Spécifie la couleur de dessin de l'arrière-plan. Une valeur de XmUNSPECIFIED_PIXEL indique que l'arrière-plan n'est pas spécifié pour cette rendition.
XmNfont
Spécifie la police ou le jeu de polices réel à utiliser par cette rendition. La valeur de cette ressource, si elle est définie à autre chose que XmAS_IS, sera utilisée indépendamment des paramètres des autres ressources de police. La définition de cette ressource forcera XmNloadModel à être XmLOAD_IMMEDIATE. Si cette ressource n'est pas initialement définie, elle sera définie ultérieurement par la rendition chaque fois que la police ou le jeu de polices spécifié par XmNfontName sera chargé. Si XmNfontName et XmNfont sont tous deux spécifiés dans un fichier de ressources, la spécification XmNfont aura la priorité.
XmNfontName
Spécifie une chaîne de description de police logique X (XLFD), qui est interprétée comme un nom de police ou comme une liste de noms de polices de base. XmNfontType
Spécifie si la ressource XmNfontName fait référence à un nom de police ou à une liste de noms de polices de base. Les valeurs valides sont XmFONT_IS_FONT et XmFONT_IS_FONTSET.
XmNrenditionForeground
Spécifie la couleur de dessin du premier plan. Une valeur de XmUNSPECIFIED_PIXEL indique que le premier plan n'est pas spécifié pour cette rendition.
XmNloadModel
Spécifie si la police ou le jeu de polices spécifié par XmNfontName doit être chargé lors de la création de la rendition (XmLOAD_IMMEDIATE) ou seulement lorsque la police est requise pour rendre un segment XmString (XmLOAD_DEFERRED). Notez que la spécification de XmLOAD_IMMEDIATE pour XmNloadModel n'est valide que si XmNfontName est spécifié, auquel cas la police spécifiée sera chargée à la création, ou si XmNfont est spécifié, auquel cas la police est déjà chargée. XmLOAD_DEFERRED n'est valide que lorsque XmNfontName est spécifié.
XmNstrikethruType
Spécifie le type de ligne à utiliser pour barrer un segment de texte. Les valeurs valides sont XmNO_LINE, XmSINGLE_LINE, XmDOUBLE_LINE, XmSINGLE_DASHED_LINE et XmDOUBLE_DASHED_LINE. Une valeur de XmAS_IS indique que le type de barrure n'est pas spécifié pour cette rendition.
XmNtabList
Spécifie la liste de tabulation à utiliser lors du rendu de chaînes composées contenant des composants de tabulation.
XmNtag
Spécifie la chaîne d'étiquette à utiliser pour faire correspondre les renditions avec d'autres renditions ou avec des composants XmStringTag dans les XmStrings. Cette ressource doit toujours être spécifiée. C'est-à-dire que NULL n'est pas une valeur légale, mais la chaîne vide l'est. Cette ressource est automatiquement définie à la valeur du paramètre tag dans l'appel XmRenditionCreate.
XmNunderlineType
Spécifie le type de ligne à utiliser pour souligner un segment de texte. Les valeurs valides sont XmNO_LINE, XmSINGLE_LINE, XmDOUBLE_LINE, XmSINGLE_DASHED_LINE et XmDOUBLE_DASHED_LINE. Une valeur de XmAS_IS indique que le type de soulignement n'est pas spécifié pour cette rendition.
