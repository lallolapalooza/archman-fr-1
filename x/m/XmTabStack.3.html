NOM

XmTabStack — Classe du widget TabStack

SYNOPSIS

#include <Xm/TabStack.h>

DESCRIPTION

Le widget XmTabStack gère un groupe de widgets de telle sorte qu'un seul widget du groupe soit visible à la fois. Chaque enfant est associé à un "onglet" qui affiche une étiquette texte et/ou une pixmap. En sélectionnant l'"onglet", l'utilisateur détermine interactivement quel enfant est affiché. Ce widget présente un comportement similaire au Contrôle d'onglets de Microsoft Windows(TM).

Les onglets peuvent être configurés pour apparaître au-dessus, en dessous, à droite et à gauche d'une zone de travail, avec le texte orienté dans l'une des quatre directions cardinales.

Le TabStack permet à l'utilisateur de sélectionner, soit par pointeur soit par parcours clavier, des onglets. Lorsqu'un onglet est sélectionné, il change d'apparence pour donner l'impression qu'il est surélevé par rapport aux autres onglets. Lorsqu'un onglet est sélectionné, l'enfant associé à cet onglet est rendu visible. Un onglet est sélectionné à tout moment.

Classes

TabStack hérite du comportement et des ressources de Core, Composite, Constraint, XmManager et des classes XmBulletinBoard.

Le pointeur de classe est xmTabStackWidgetClass.

Le nom de la classe est XmTabStack.

Les codes dans la colonne d'accès indiquent si la ressource donnée peut être définie au moment de la création (C), définie à l'aide de XtSetValues (S), récupérée à l'aide de XtGetValues (G), ou si elle n'est pas applicable (N/A).

Distribue les onglets dans une rangée verticale ou horizontale. S'il n'y a pas assez de place pour afficher tous les onglets, des rangées supplémentaires sont ajoutées. Lorsqu'un onglet est sélectionné, sa rangée est déplacée à côté des enfants de la pile.
XmTABS_STACKED_STATIC
Distribue les onglets dans une rangée verticale ou horizontale. S'il n'y a pas assez de place pour afficher tous les onglets, des rangées supplémentaires sont ajoutées. Les positions des rangées ne changent pas lorsque des onglets sont sélectionnés.

Informations sur les rappels

Un pointeur vers la structure suivante est passé à chaque rappel :

typedef struct _XmTabStackCallbackStruct {
	int	reason;
	XEvent	*event;
	Widget	selected_child;
} XmTabStackCallbackStruct;
reason
Indique la raison pour laquelle le rappel a été invoqué. Les raisons de rappel valides comprennent :
XmCR_TAB_SELECTED
Indique qu'un enfant a été désigné comme widget sélectionné.
event
Pointe vers le XEvent qui a déclenché le rappel.
selected_child
Contient l'identifiant du widget de l'enfant sélectionné.
