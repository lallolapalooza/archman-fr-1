NOM

XmContainerReorder — Fonction du widget Container pour réorganiser les enfants

SYNOPSIS

#include <Xm/Container.h>
void XmContainerReorder(
Widget container,
WidgetList widgets,
int num_widgets);

DESCRIPTION

XmContainerReorder récupère les ressources de contrainte XmNpositionIndex de chaque widget spécifié dans widgets, les trie dans l'ordre croissant, et insère les ressources de contrainte XmNpositionIndex dans le nouvel ordre dans chaque widget. Si la ressource XmNlayoutType de Container est XmOUTLINE ou XmDETAIL, XmContainerReorder forcera une disposition de tous les éléments.

container
Spécifie l'identifiant du widget Container.
widgets
Spécifie un tableau d'enfants de type widget de container.
num_widgets
Spécifie le nombre d'éléments dans le tableau widgets.

Pour une définition complète de Container et de ses ressources associées, voir XmContainer(3).
