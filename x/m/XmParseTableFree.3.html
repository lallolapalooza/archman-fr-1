NOM

XmParseTableFree — Une fonction de chaîne composée qui récupère de la mémoire

SYNTAXE

#include <Xm/Xm.h>
void XmParseTableFree(
XmParseTable parse_table,
Cardinal count);

DESCRIPTION

XmParseTableFree récupère la mémoire utilisée par une XmParseTable et ses XmParseMappings constituants.

parse_table
Spécifie la table d'analyse à libérer
count
Spécifie le nombre de correspondances d'analyse dans la table d'analyse

VOIR AUSSI

XmParseTable(3) et XmString(3).
