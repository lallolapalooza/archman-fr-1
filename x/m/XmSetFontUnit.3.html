NOM

XmSetFontUnit — Une fonction qui définit la valeur de l'unité de police pour un écran

SYNTAXE

#include <Xm/Xm.h>
void XmSetFontUnit(
Display * display,
int font_unit_value);

DESCRIPTION

XmSetFontUnit fournit une fonction externe pour initialiser les valeurs des unités de police. Les applications peuvent vouloir spécifier des données indépendantes de la résolution basées sur une taille de police globale. Voir la description de la ressource XmNunitType dans les pages de référence pour XmGadget, XmManager et XmPrimitive pour plus d'informations sur l'indépendance de la résolution.

Cette fonction définit les unités de police pour tous les écrans de l'affichage.

NOTE: XmSetFontUnit est obsolète et existe pour la compatibilité avec les versions précédentes. Au lieu d'utiliser cette fonction, fournissez des valeurs initiales ou appelez XtSetValues pour les ressources XmScreen XmNhorizontalFontUnit et XmNverticalFontUnit.

display
Définit l'affichage pour lequel cette valeur d'unité de police doit être appliquée.
font_unit_value
Spécifie la valeur à utiliser pour les unités de police horizontales et verticales dans les calculs de conversion.

VOIR AUSSI

XmConvertUnits(3), XmSetFontUnits(3), XmGadget(3), XmManager(3), XmPrimitive(3), et XmScreen(3).
