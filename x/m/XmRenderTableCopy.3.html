NOM

XmRenderTableCopy — Une fonction de table de rendu qui copie des rendus

SYNTAXE

#include <Xm/Xm.h>
XmRenderTable XmRenderTableCopy(
XmRenderTable table,
XmStringTag *tags,
int tag_count);

DESCRIPTION

XmRenderTableCopy crée une nouvelle table de rendu qui contiendra les rendus de la *table* dont les étiquettes correspondent à celles de *tags*.

table
Spécifie la table contenant les rendus à copier.
tags
Spécifie un tableau d'étiquettes, dont les rendus correspondants doivent être copiés. NULL indique que la table complète doit être copiée.
tag_count
Spécifie le nombre d'étiquettes dans *tags*.

VALEUR

Retourne NULL si table est NULL. Sinon, cette fonction retourne la nouvelle table de rendu. Cette fonction alloue de l'espace pour contenir la nouvelle table de rendu. L'application est responsable de la gestion de cet espace alloué. L'application peut récupérer cet espace alloué en appelant XmRenderTableFree.

VOIR AUSSI

XmRendition(3) et XmRenderTableFree(3).
