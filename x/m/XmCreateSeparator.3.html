NOM

XmCreateSeparator — Fonction de création du widget Separator

SYNOPSIS

#include <Xm/Separator.h>
Widget XmCreateSeparator(
Widget parent,
String name,
ArgList arglist,
Cardinal argcount);

DESCRIPTION

XmCreateSeparator crée une instance d'un widget Separator et retourne l'identifiant du widget associé.

parent
Spécifie l'identifiant du widget parent
name
Spécifie le nom du widget créé
arglist
Spécifie la liste d'arguments
argcount
Spécifie le nombre de paires attribut/valeur dans la liste d'arguments (arglist)

Pour une définition complète de Separator et de ses ressources associées, voir XmSeparator(3).

RETOUR

Retourne l'identifiant du widget Separator.

VOIR AUSSI

XmSeparator(3).
