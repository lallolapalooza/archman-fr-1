NOM

XML::LibXML::XPathExpression - Interface pour les expressions XPath pré-compilées de libxml2

SYNOPIS

use XML::LibXML;
my $compiled_xpath = XML::LibXML::XPathExpression->new('//foo[@bar="baz"][position()<4]');
# Interface depuis XML::LibXML::Node
my $result = $node->find($compiled_xpath);
my @nodes = $node->findnodes($compiled_xpath);
my $value = $node->findvalue($compiled_xpath);
# Interface depuis XML::LibXML::XPathContext
my $result = $xpc->find($compiled_xpath,$node);
my @nodes = $xpc->findnodes($compiled_xpath,$node);
my $value = $xpc->findvalue($compiled_xpath,$node);
$compiled = XML::LibXML::XPathExpression->new( xpath_string );

DESCRIPTION

Il s'agit d'une interface Perl pour les expressions XPath pré-compilées de libxml2. La pré-compilation d'une expression XPath peut apporter un avantage de performance si la même requête XPath est évaluée plusieurs fois. Les objets "XML::LibXML::XPathExpression" peuvent être passés à toutes les fonctions "find..." de "XML::LibXML" qui attendent une expression XPath.

new()
$compiled = XML::LibXML::XPathExpression->new( xpath_string );

Le constructeur prend une expression XPath 1.0 sous forme de chaîne et retourne un objet représentant les expressions pré-compilées (la structure de données réelle est interne à libxml2).
