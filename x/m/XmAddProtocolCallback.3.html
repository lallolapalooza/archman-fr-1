NOM

XmAddProtocolCallback — Une fonction de VendorShell qui ajoute des callbacks clients pour un protocole

SYNTAXE

#include <Xm/Protocols.h>
void XmAddProtocolCallback(
Widget shell,
Atom property,
Atom protocol,
XtCallbackProc callback,
XtPointer closure);

DESCRIPTION

XmAddProtocolCallback ajoute des callbacks clients pour un protocole. Elle vérifie si le protocole est enregistré, et s'il ne l'est pas, appelle XmAddProtocols. Elle ajoute ensuite le callback à la liste interne. Ces callbacks sont appelés lorsque le message client correspondant est reçu.

XmAddWMProtocolCallback est une interface pratique. Elle appelle XmAddProtocolCallback avec la valeur de la propriété définie à l'atome retourné par l'internement de WM_PROTOCOLS.

shell
Spécifie le widget auquel la propriété de protocole est associée
property
Spécifie la propriété du protocole
protocol
Spécifie l'Atom du protocole
callback
Spécifie la procédure à appeler lorsqu'un message de protocole est reçu
closure
Spécifie les données client à passer au callback lorsqu'il est invoqué

Pour une définition complète de VendorShell et de ses ressources associées, voir VendorShell(3).

LIÉ

VendorShell(3), XmAddWMProtocolCallback(3), XmInternAtom(3), et XmRemoveProtocolCallback(3).
