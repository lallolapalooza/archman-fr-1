NOM

XML::LibXML::RelaxNG - Validation de schéma RelaxNG

SYNTAXE

use XML::LibXML;
$doc = XML::LibXML->new->parse_file($url);
$rngschema = XML::LibXML::RelaxNG->new( location => $filename_or_url, no_network => 1 );
$rngschema = XML::LibXML::RelaxNG->new( string => $xmlschemastring, no_network => 1 );
$rngschema = XML::LibXML::RelaxNG->new( DOM => $doc, no_network => 1 );
eval { $rngschema->validate( $doc ); };

DESCRIPTION

La classe XML::LibXML::RelaxNG est une petite interface vers l'implémentation RelaxNG de libxml2. Actuellement, elle ne prend en charge que l'analyse de schéma et la validation de document.

MÉTHODES

new
$rngschema = XML::LibXML::RelaxNG->new( location => $filename_or_url, no_network => 1 );
$rngschema = XML::LibXML::RelaxNG->new( string => $xmlschemastring, no_network => 1 );
$rngschema = XML::LibXML::RelaxNG->new( DOM => $doc, no_network => 1 );

Le constructeur de XML::LibXML::RelaxNG doit être appelé avec une liste de paramètres. Au moins un paramètre location, string ou DOM est requis pour spécifier la source du schéma. Le paramètre facultatif no_network défini à 1 fait que l'analyseur n'accède pas au réseau et le paramètre facultatif recover défini à 1 fait que l'analyseur n'appelle pas die() en cas d'erreurs.

Il est important que chaque schéma n'ait qu'une seule source.

Le paramètre location permet d'analyser un schéma à partir du système de fichiers ou d'une URL (non-HTTPS).

Le paramètre string analyse le schéma à partir de la chaîne XML donnée.

Le paramètre DOM permet d'analyser le schéma à partir d'un objet XML::LibXML::Document pré-analysé.

Notez que le constructeur appellera die() si le schéma ne respecte pas les contraintes de la spécification RelaxNG.

validate
eval { $rngschema->validate( $doc ); };

Cette fonction permet de valider un document (analysé) par rapport au schéma RelaxNG donné. L'argument de cette fonction doit être un objet XML::LibXML::Document. Si cette fonction réussit, elle retournera 0, sinon elle appellera die() et signalera les erreurs trouvées. En raison de cela, validate() doit toujours être évalué.
