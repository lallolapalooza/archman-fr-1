NOM

XML::LibXML::ErrNo - Erreurs structurées

DESCRIPTION

Ce module est basé sur le fichier d'en-tête C xmlerror.h de libxml2. Il définit des constantes symboliques pour tous les codes d'erreur de libxml2. Actuellement, libxml2 utilise plus de 480 codes d'erreur différents. Voir aussi XML::LibXML::Error.
