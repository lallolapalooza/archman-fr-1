NOM

XmFontListRemoveEntry — Fonction de liste de polices qui supprime une entrée de liste de polices d'une liste de polices

SYNTAXE

#include <Xm/Xm.h>
XmFontList XmFontListRemoveEntry(
XmFontList oldlist,
XmFontListEntry entry);

DESCRIPTION

XmFontListRemoveEntry crée une nouvelle liste de polices qui contient le contenu de oldlist moins les entrées spécifiées dans entry. La routine supprime toutes les entrées de oldlist qui correspondent aux composants (tag, type de police/ensemble de polices) de l'entrée spécifiée. La fonction désalloue la liste de polices d'origine après avoir extrait les informations requises. L'appelant utilise XmFontListEntryFree pour récupérer la mémoire allouée pour l'entrée spécifiée. Cette routine ne libère pas le XFontSet ou le XFontStruct associé à l'entrée de liste de polices qui est supprimée.

oldlist
Spécifie la liste de polices
entry
Spécifie l'entrée de liste de polices à supprimer

VALEUR

Si oldlist est NULL, la fonction retourne NULL. Si entry est NULL ou si aucune entrée n'est supprimée, la fonction retourne oldlist. Sinon, elle retourne une nouvelle liste de polices. Si la fonction retourne une nouvelle liste de polices, elle alloue de l'espace pour contenir la nouvelle liste de polices. L'application est responsable de la gestion de l'espace alloué. L'application peut récupérer l'espace alloué en appelant XmFontListFree.

VOIR AUSSI

XmFontList(3), XmFontListAppendEntry(3), XmFontListEntryCreate(3), XmFontListEntryFree(3), XmFontListEntryLoad(3), et XmFontListFree(3).
