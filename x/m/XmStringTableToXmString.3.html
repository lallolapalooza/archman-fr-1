NOM

XmStringTableToXmString — Une fonction utilitaire qui convertit une table de chaînes composites en une seule chaîne composite

SYNTAXE

#include <Xm/Xm.h>
XmString XmStringTableToXmString(
XmStringTable table,
Cardinal count,
XmString break_component);

DESCRIPTION

XmStringTableToXmString prend en entrée une table de chaînes composites et un composant de chaîne spécifié (tel qu'une tabulation) et retourne une seule chaîne composite constituée de chaque élément de table concaténé avec une seule copie de break_component insérée entre chaque élément.

table
Spécifie une XmStringTable contenant les chaînes composites à convertir.
count
Spécifie le nombre de chaînes composites dans table.
break_component
Spécifie le XmStringComponent qui sera inséré dans le résultat pour séparer les éléments individuels de table. Les types les plus utiles seront XmSTRING_COMPONENT_SEPARATOR et XmSTRING_COMPONENT_TAB. Reportez-vous à la page de référence XmStringComponentType(3) pour une liste complète des types de composants possibles. Notez cependant que le composant XmSTRING_COMPONENT_UNKNOWN n'est pas un type possible.

VALEUR

Retourne une nouvelle XmString. La fonction allouera de l'espace pour contenir la chaîne composite retournée. Lorsque l'application n'aura plus besoin de la chaîne composite retournée, elle devra appeler XmStringFree.

LIRE AUSSI

XmString(3), XmStringComponentType(3), et XmStringFree(3).
