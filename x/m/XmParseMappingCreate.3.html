NOM

XmParseMappingCreate — Une fonction de chaîne composite pour créer une table de correspondance d'analyse

SYNTAXE

#include <Xm/Xm.h>
XmParseMapping XmParseMappingCreate(
ArgList arglist,
Cardinal argcount);

DESCRIPTION

XmParseMappingCreate crée une table de correspondance d'analyse à utiliser dans une table d'analyse. Cette fonction permet à l'application de spécifier des valeurs pour les composants de la table de correspondance d'analyse en utilisant une liste d'arguments de style de ressource.

arglist
Spécifie la liste d'arguments
argcount
Spécifie le nombre de paires attribut/valeur dans la liste d'arguments (arglist)

Pour une définition complète de XmParseMapping et de ses ressources associées, voir XmParseMapping(3).

VALEUR DE RETOUR

Retourne l'objet XmParseMapping. La fonction alloue de l'espace pour contenir l'objet XmParseMapping retourné. L'application est responsable de la gestion de l'espace alloué. L'application peut récupérer l'espace alloué en appelant XmParseMappingFree.

LIRE AUSSI

XmParseMapping(3), XmParseMappingFree(3), XmParseMappingGetValues(3), XmParseMappingSetValues(3), XmParseTable(3), et XmString(3).
