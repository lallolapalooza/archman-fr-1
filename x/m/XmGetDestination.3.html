NOM

XmGetDestination — Une fonction qui retourne l'identifiant du widget à utiliser comme destination actuelle pour le collage rapide et certaines opérations de presse-papiers.

SYNOPSIS

#include <Xm/Xm.h>
Widget XmGetDestination(
Display *display);

DESCRIPTION

XmGetDestination retourne le widget qui est la destination actuelle sur l'affichage spécifié. La destination est généralement le dernier widget éditable sur lequel une opération de sélection, d'édition, d'insertion ou de collage a été effectuée et est la destination pour le collage rapide et certaines fonctions de presse-papiers. La destination est NULL jusqu'à ce qu'une opération au clavier ou à la souris ait été effectuée sur un widget éditable. Référez-vous au *Guide du programmeur Motif* pour une description du focus clavier.

display
Spécifie l'affichage dont le widget de destination doit être interrogé.

RETOUR

Retourne l'identifiant du widget pour la destination actuelle ou NULL s'il n'y a pas de destination actuelle.
