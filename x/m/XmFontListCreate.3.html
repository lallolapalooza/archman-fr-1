NOM

XmFontListCreate — Fonction de liste de polices qui crée une liste de polices

SYNOPSIS

#include <Xm/Xm.h>
XmFontList XmFontListCreate(
XFontStruct * font,
XmStringCharSet charset);

DESCRIPTION

XmFontListCreate crée une nouvelle liste de polices avec un unique élément spécifié par la police et le jeu de caractères fournis. Elle alloue également l'espace pour la liste de polices.

NOTE: Cette fonction est obsolète et existe pour la compatibilité avec les versions précédentes. Elle est remplacée par XmFontListAppendEntry.

font
Spécifie un pointeur vers une structure de police pour laquelle la nouvelle liste de polices est générée. Il s'agit de la structure retournée par la fonction XLib XLoadQueryFont.
charset
Spécifie l'identifiant du jeu de caractères pour la police. Il peut s'agir de XmSTRING_DEFAULT_CHARSET, mais cette valeur n'est pas conforme aux AES et pourrait être supprimée dans de futures versions de Motif. Si la valeur est XmSTRING_DEFAULT_CHARSET, la routine dérive le jeu de caractères de l'environnement linguistique actuel.

RETOUR

Retourne NULL si font ou charset est NULL ; sinon, retourne une nouvelle liste de polices.

RELATIF

XmFontList(3) et XmFontListAppendEntry(3).
