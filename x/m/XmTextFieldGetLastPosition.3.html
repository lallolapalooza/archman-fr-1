NOM

XmTextFieldGetLastPosition — Appel de fonction du TextField qui accède à la position du dernier caractère de texte

SYNTAXE

#include <Xm/TextF.h>
XmTextPosition XmTextFieldGetLastPosition(
Widget widget);

DESCRIPTION

XmTextFieldGetLastPosition accède à la position du dernier caractère dans le tampon de texte du widget TextField.

widget
Spécifie l'ID du widget TextField

Pour une définition complète de TextField et de ses ressources associées, voir XmTextField(3).

VALEUR DE RETOUR

Retourne une valeur de type XmTextPosition qui indique la position du dernier caractère dans le tampon de texte. Il s'agit d'un nombre entier de caractères à partir du début du tampon. La position du premier caractère est 0 (zéro). La position du dernier caractère est égale au nombre de caractères dans le tampon de texte.
