NOM

XmFontListEntryLoad — Une fonction de liste de polices qui charge une police ou crée un ensemble de polices et crée une entrée de liste de polices associée

SYNTAXE

#include <Xm/Xm.h>
XmFontListEntry XmFontListEntryLoad(
Display *display,
char *font_name,
XmFontType type,
char *tag);

DESCRIPTION

XmFontListEntryLoad charge une police ou crée un ensemble de polices en fonction de la valeur de l'argument type. Elle crée et renvoie une entrée de liste de polices contenant la police ou l'ensemble de polices et le tag spécifié.

Si la valeur de type est XmFONT_IS_FONT, la fonction utilise la routine XtCvtStringToFontStruct pour convertir la valeur de font_name en une structure de police. Si la valeur de type est XmFONT_IS_FONTSET, la fonction utilise le convertisseur XtCvtStringToFontSet pour créer un ensemble de polices dans la locale actuelle. XmFontListEntryLoad crée une entrée de liste de polices contenant la police ou l'ensemble de polices dérivé du convertisseur. Pour plus d'informations sur XtCvtStringToFontStruct et XtCvtStringToFontSet, consultez X Toolkit Intrinsics—Interface en langage C.

display
Spécifie l'affichage où la liste de polices sera utilisée.
font_name
Spécifie une chaîne de description de police logique X (XLFD), interprétée soit comme un nom de police, soit comme une liste de noms de polices de base. Une liste de noms de polices de base est une chaîne séparée par des virgules et terminée par NULL.
type
Spécifie si l'argument font_name fait référence à un nom de police ou à une liste de noms de polices de base. Les valeurs valides sont XmFONT_IS_FONT et XmFONT_IS_FONTSET.
tag
Spécifie le tag de l'entrée de liste de polices à créer. Le tag peut être spécifié comme XmFONTLIST_DEFAULT_TAG, qui est utilisé pour identifier l'élément de liste de polices par défaut dans une liste de polices lorsqu'il est spécifié dans le cadre d'une ressource.

RETOUR

Si la police spécifiée n'est pas trouvée, ou si l'ensemble de polices spécifié ne peut pas être créé, alors soit une police définie par l'implémentation sera ouverte, soit un ensemble de polices sera créé, et un message d'avertissement sera généré. Si aucune police appropriée ne peut être trouvée ou si un ensemble de polices ne peut pas être créé, un autre message sera généré et la fonction retournera NULL ; sinon, la fonction renvoie une entrée de liste de polices. Si la fonction renvoie une entrée de liste de polices, elle alloue de l'espace pour contenir cette entrée. L'application est responsable de la gestion de l'espace alloué. L'application peut récupérer l'espace alloué en appelant XmFontListEntryFree.

VOIR AUSSI

XmFontList(3), XmFontListAppendEntry(3), XmFontListEntryCreate(3), XmFontListEntryFree(3), XmFontListEntryGetFont(3), XmFontListEntryGetTag(3), et XmFontListRemoveEntry(3).
