NOM

XmChangeColor — Recalcule toutes les couleurs associées d'un widget

SYNTAXE

#include <Xm/Xm.h>
void XmChangeColor(
Widget widget,
Pixel background);

DESCRIPTION

XmChangeColor gère toutes les modifications de couleur pour le widget spécifié lorsqu'une nouvelle valeur de pixel d'arrière-plan est spécifiée. Cette fonction recalcule les couleurs de premier plan, de sélection et d'ombre en fonction de la nouvelle couleur d'arrière-plan et définit les ressources correspondantes pour le widget. Si une procédure de calcul de couleur a été définie par un appel à XmSetColorCalculation, XmChangeColor utilise cette procédure pour calculer les nouvelles couleurs. Sinon, la routine utilise une procédure par défaut.

widget
Spécifie l'ID du widget dont les couleurs seront mises à jour
background
Spécifie la valeur du pixel de couleur d'arrière-plan

LIÉ

XmGetColorCalculation(3), XmGetColors(3), et XmSetColorCalculation(3).
