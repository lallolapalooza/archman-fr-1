NOM

XmLabelGadget — Classe de widget LabelGadget

SYNTAXE

#include <Xm/LabelG.h>

DESCRIPTION

LabelGadget est un widget instanciable et est également utilisé comme superclasse pour d'autres gadgets de bouton, tels que PushButtonGadget et ToggleButtonGadget.

LabelGadget peut contenir soit du texte, soit une pixmap. Le texte de LabelGadget est une chaîne composée. Référez-vous au Guide du programmeur Motif pour plus d'informations sur les chaînes composées. Le texte peut être multilingue, multiligne et/ou multifontes. Lorsqu'un LabelGadget est inactif, son texte est grisé, ou la pixmap inactive fournie par l'utilisateur est affichée.

LabelGadget prend en charge les accélérateurs et les mnémotechniques principalement pour une utilisation dans les widgets de sous-classe LabelGadget contenus dans des menus. Les mnémotechniques sont disponibles dans un système de menu lorsque le bouton est visible. Les accélérateurs dans un système de menu sont accessibles même lorsque le bouton n'est pas visible. Le LabelGadget affiche la mnémotechnique en soulignant le premier caractère correspondant dans la chaîne de texte. L'accélérateur est affiché sous forme de chaîne de texte adjacente au texte ou à la pixmap du label, en fonction de la direction de la disposition.

LabelGadget comprend de nombreux champs de marge entourant le texte ou la pixmap. Ces champs de marge sont des ressources qui peuvent être définies par l'utilisateur, mais les sous-classes de LabelGadget et les parents Manager modifient également certains de ces champs. Ils ont tendance à modifier les ressources XmNmarginLeft, XmNmarginRight, XmNmarginTop et XmNmarginBottom et laissent les ressources XmNmarginWidth et XmNmarginHeight telles que définies par l'application.

LabelGadget prend en compte XmNshadowThickness pour déterminer sa disposition mais ne dessine pas l'ombre. C'est-à-dire que si XmNshadowThickness est supérieur à 0 (zéro), LabelGadget laisse de la place pour l'ombre, mais l'ombre n'apparaît pas.

Dans un LabelGadget, XmNtraversalOn et XmNhighlightOnEnter sont forcés à False à l'intérieur des fenêtres de menu contextuelles, des fenêtres de menu déroulant et des menus d'options. Sinon, ces ressources valent par défaut False.

LabelGadget utilise les traits XmQTmenuSystem et XmQTspecifyRenderTable, et détient les traits XmQTaccessTextual, XmQTcareParentVisual, XmQTmenuSavvy et XmQTtransfer.

Comportement de transfert de données

LabelGadget et ses sous-classes, sauf lorsqu'ils sont utilisés dans un système de menu, prennent en charge le glisser-déposer du contenu du label à partir du LabelGadget. Cependant, le contenu du label n'est déplaçable que si la ressource XmNenableUnselectableDrag de XmDisplay est définie sur True.

En tant que source de données, LabelGadget et ses sous-classes prennent en charge les cibles suivantes et les conversions associées de données vers ces cibles :

locale
Si la cible locale correspond à la locale du widget, le widget transfère XmNlabelString dans le codage de la locale. Cette cible n'est prise en charge que lorsque XmNlabelType est XmSTRING ou XmPIXMAP_AND_STRING.
COMPOUND_TEXT
Le widget transfère XmNlabelString comme type COMPOUND_TEXT. Cette cible n'est prise en charge que lorsque XmNlabelType est XmSTRING ou XmPIXMAP_AND_STRING.
UTF8_STRING
Le widget transfère XmNlabelString comme type UTF8_STRING. Cette cible n'est prise en charge que lorsque XmNlabelType est XmSTRING ou XmPIXMAP_AND_STRING.
PIXMAP
Le widget transfère XmNlabelPixmap comme type DRAWABLE. Cette cible est prise en charge lorsque XmNlabelType est XmPIXMAP ou XmPIXMAP_AND_STRING.
STRING
Le widget transfère XmNlabelString comme type STRING. Cette cible est prise en charge lorsque XmNlabelType est XmSTRING ou XmPIXMAP_AND_STRING.
TEXT
Si XmNlabelString est entièrement convertible dans le codage de la locale, le widget transfère XmNlabelString dans le codage de la locale. Sinon, le widget transfère XmNlabelString comme type COMPOUND_TEXT. Cette cible est prise en charge lorsque XmNlabelType est XmSTRING ou XmPIXMAP_AND_STRING.

"droite".

L'espace à laisser entre le pixmap et la chaîne de caractères de l'étiquette.

Spécifie une valeur booléenne indiquant si le gadget se réduit ou s'agrandit pour s'adapter à son contenu (chaîne de caractères de l'étiquette ou pixmap) en conséquence d'une valeur de ressource XtSetValues qui modifierait la taille du gadget. Reportez-vous à XmRenderTable(3) pour plus d'informations sur la création et la structure d'une table de rendu.

Est une ressource synthétique pour définir XmNlayoutDirection. Les valeurs de cette ressource sont XmSTRING_DIRECTION_L_TO_R et XmSTRING_DIRECTION_R_TO_L. Reportez-vous à la description de la ressource XmNlayoutDirection. La ressource XmNstringDirection est obsolète par XmNlayoutDirection, mais est conservée ici pour la compatibilité descendante.

NAME

XmLabelGadget
A primitive gadget that displays a label that can be text or a bitmap

SYNOPSIS

#include <Xm/LabelG.h>

DESCRIPTION

The XmLabelGadget is a primitive gadget that displays a label which can be either text or a bitmap. It is used as a child of any XmManager widget.

The XmLabelGadget supports the XmNlabelInsensitivePixmap and XmNlabelPixmap resources, which allow the display of a pixmap. If XmNlabelInsensitivePixmap is specified, it is used when the gadget is insensitive. If XmNlabelInsensitivePixmap is NULL, the XmNlabelPixmap is used and modulated to simulate insensitivity.

The XmLabelGadget also supports the XmNlabelString resource for displaying text.

Behavior

XmLabelGadget includes behavior from XmGadget. Additional XmLabelGadget behavior is described in the following list:

<Btn2Down>:
Drags the contents of a LabelGadget, identified when BTransfer is pressed. This action is undefined for LabelGadgets used in a menu system.
<Key><osfHelp>:
In a Popup or Pulldown MenuPane, unposts all menus in the menu hierarchy and, when the shell's keyboard focus policy is XmEXPLICIT, restores keyboard focus to the widget that had the focus before the menu system was entered. Calls the callbacks for XmNhelpCallback if any exist. If there are no help callbacks for this widget, this action calls the help callbacks for the nearest ancestor that has them.
<key><osfCancel>:
In a MenuBar, disarms the CascadeButton and the menu and, when the shell's keyboard focus policy is XmEXPLICIT, restores keyboard focus to the widget that had the focus before the menu was entered.
In a toplevel Pulldown MenuPane from a MenuBar, unposts the menu, disarms the MenuBar CascadeButton and the MenuBar, and, when the shell's keyboard focus policy is XmEXPLICIT, restores keyboard focus to the widget that had the focus before the MenuBar was entered. In other Pulldown MenuPanes, unposts the menu.
In a Popup MenuPane, unposts the menu and, when the shell's keyboard focus policy is XmEXPLICIT, restores keyboard focus to the widget from which the menu was posted.
<Key><osfDown>:
If the current menu item has a submenu and is in a MenuBar, then this action posts the submenu, disarms the current menu item, and arms the submenu's first traversable menu item.

If the current menu item is at the left edge of a submenu not directly attached to a MenuBar item, then this action unposts the current submenu only.

XmLabelGadget(3) — Documentation

NOM

XmLabelGadget, XmCreateLabelGadget, XmVaCreateLabelGadget, XmVaCreateManagedLabelGadget — Un gadget d'étiquette pour les éléments de menu et autres

SYNTAXIS

#include <Xm/LabelG.h>
Widget XmCreateLabelGadget(Widget parent, const char *name, ArgList arglist, Cardinal argCount);
Widget XmVaCreateLabelGadget(Widget parent, const char *name, va_list var);
Widget XmVaCreateManagedLabelGadget(Widget parent, const char *name, va_list var);

DESCRIPTION

Le gadget XmLabelGadget crée un gadget d'étiquette. Les étiquettes sont des widgets qui affichent du texte ou des graphiques. Ils sont utilisés comme éléments de menu, comme indicateurs dans les boîtes de dialogue, et pour d'autres usages où une étiquette statique est nécessaire.

Les fonctions XmCreateLabelGadget, XmVaCreateLabelGadget, et XmVaCreateManagedLabelGadget créent un gadget d'étiquette. La seule différence entre les fonctions est la manière dont les arguments sont passés.

Les options suivantes sont disponibles pour les gadgets d'étiquette:

XmNaccelerator
Une chaîne de caractères spécifiant l'accélérateur pour un élément de menu.
XmNacceleratorText
Une chaîne de caractères spécifiant le texte de l'accélérateur pour un élément de menu.
XmNalignment
Définit l'alignement du contenu de l'étiquette. Les valeurs possibles sont XmALIGNMENT_BEGINNING, XmALIGNMENT_CENTER, et XmALIGNMENT_END.
XmNfontList
La liste de polices à utiliser pour afficher le texte de l'étiquette.
XmNlabelInsensitivePixmap
La pixmap à utiliser lorsque l'étiquette est désactivée.
XmNlabelPixmap
La pixmap à utiliser pour l'étiquette. Si cette option est définie, elle est prioritaire sur XmNlabelString.
XmNlabelString
La chaîne de caractères à utiliser pour l'étiquette. Si cette option est définie et que XmNlabelPixmap n'est pas défini, elle sera utilisée pour afficher l'étiquette.
XmNmarginBottom
La marge en bas de l'étiquette.
XmNmarginHeight
La marge horizontale en haut et en bas de l'étiquette.
XmNmarginLeft
La marge à gauche de l'étiquette.
XmNmarginRight
La marge à droite de l'étiquette.
XmNmarginTop
La marge en haut de l'étiquette.
XmNmarginWidth
La marge verticale à gauche et à droite de l'étiquette.
XmNmnemonic
La touche mnémonique pour l'étiquette.
XmNrecomputeSize
Un indicateur booléen qui, s'il est vrai, fait que le gadget se redimensionne automatiquement pour s'adapter à son contenu.
XmNrightBitmap
La pixmap à afficher à droite du texte de l'étiquette.
XmNshadowThickness
L'épaisseur de l'ombre autour de l'étiquette.
XmNtopShadowPixmap
La pixmap à utiliser pour l'ombre supérieure.
XmNbottomShadowPixmap
La pixmap à utiliser pour l'ombre inférieure.
XmNuserData
Un pointeur vers des données utilisateur.

Navigation dans les menus

Les actions suivantes sont associées à la navigation dans les menus:

<Key><osfDown>:
Si l'élément de menu actuel est un CascadeButton, cette action publie son sous-menu associé. Si l'élément de menu actuel n'est pas un CascadeButton et qu'il n'est pas sur le bord droit d'un MenuPane, cette action désarme l'élément actuel et arme l'élément à sa droite, en revenant à la ligne si nécessaire. Si l'élément de menu actuel n'est pas un CascadeButton et qu'il se trouve sur le bord droit d'un sous-menu qui est un descendant d'une MenuBar, cette action retire tous les sous-menus et se déplace vers l'élément MenuBar à droite. Si cet élément MenuBar a un sous-menu, il publie le sous-menu et arme le premier élément parcourable du sous-menu.
Dans les menus contextuels ou détachés, si l'élément de menu actuel n'est pas un CascadeButton et se trouve sur le bord droit d'une ligne (sauf la dernière ligne), cette action passe à l'élément de menu le plus à gauche de la ligne inférieure. Si l'élément de menu actuel n'est pas un CascadeButton et se trouve dans le coin inférieur droit d'un MenuPane contextuel ou déroulant, cette action passe au contrôle de détachement, s'il est présent, sinon elle passe à l'élément de menu le plus en haut et le plus à gauche du MenuPane. La description précédente s'applique lorsque la direction horizontale de la ressource XmNlayoutDirection est XmLEFT_TO_RIGHT. Si la direction horizontale de la ressource XmNlayoutDirection est XmRIGHT_TO_LEFT, alors ce qui suit s'applique.
Lorsque l'élément de menu actuel se trouve dans une MenuBar, cette action désarme l'élément actuel et arme l'élément MenuBar à droite. Cette action revient à la ligne dans la MenuBar.
Dans les MenuPanes, si l'élément de menu actuel ne se trouve pas sur le bord droit d'un MenuPane, cette action désarme l'élément actuel et arme l'élément à sa droite. Si l'élément de menu actuel se trouve sur le bord droit d'un sous-menu attaché à un élément MenuBar, cette action retire le sous-menu et se déplace vers l'élément MenuBar à droite, en revenant à la ligne si nécessaire. Si cet élément MenuBar a un sous-menu, il publie le sous-menu et arme le premier élément parcourable du sous-menu. Si l'élément de menu actuel se trouve sur le bord droit d'un sous-menu non directement attaché à un élément MenuBar, cette action retire uniquement le sous-menu actuel.
Dans les MenuPanes contextuels ou détachés, lorsque l'élément de menu actuel se trouve sur le bord droit, cette action revient à la ligne dans le MenuPane. Si l'élément de menu actuel se trouve sur le bord droit du MenuPane et non dans la ligne supérieure, cette action passe à l'élément de menu le plus à gauche de la ligne supérieure. Si l'élément de menu actuel se trouve dans le coin supérieur droit, cette action passe au contrôle de détachement, s'il est présent, sinon elle passe à l'élément de menu le plus en bas et le plus à gauche du MenuPane.
<Key><osfUp>:
Lorsque l'élément de menu actuel se trouve dans un MenuPane, cette action désarme l'élément de menu actuel et arme l'élément situé au-dessus. Cette action revient à la ligne dans le MenuPane. La direction du retour à la ligne dépend de la ressource XmNlayoutDirection.
