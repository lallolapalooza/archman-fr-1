XML__XPath__Node__Element(3pm)

Paquet: perl-xml-xpath

Licences: PerlArtistic, GPL

XML::XPath::Node::Element(3) Documentation Perl fournie par l'utilisateur XML::XPath::Node::Element(3)

NOM

Element - un <élément>

API

new ( nom, préfixe )

Crée un nouveau nœud Élément avec le nom "nom" et le préfixe "préfixe". Le nom sera "préfixe:local" si le préfixe est défini. Je sais que cela semble étrange, mais cela fonctionne ;-)

getNom

Retourne le nom (y compris le "préfixe:" s'il est défini) de cet élément.

getNomLocal

Retourne uniquement la partie locale du nom (la partie après le "préfixe:").

getEnfants

Retourne les enfants de cet élément. En contexte de liste retourne une liste. En contexte scalaire retourne une référence de tableau.

getEnfant ( pos )

Retourne l'enfant à la position pos.

ajouterEnfant ( nœud_enfant )

Ajoute le nœud enfant à la liste des nœuds enfants actuels.

supprimerEnfant ( nœud_enfant )

Supprime le nœud enfant fourni de la liste des nœuds enfants actuels.

getAttribut ( nom )

Retourne le nœud attribut avec la clé nom.

getAttributs / getNœudsAttributs

Retourne les nœuds attributs. En contexte de liste retourne une liste. En contexte scalaire retourne une référence de tableau.

ajouterAttribut ( nœud_attribut)

Ajoute le nœud attribut à la liste des attributs (XML::XPath stocke les attributs dans l'ordre).

getEspaceNom ( préfixe )

Retourne le nœud d'espace de noms par le préfixe donné

getEspacesNoms / getNœudsEspacesNoms

Retourne les nœuds d'espace de noms. En contexte de liste retourne une liste. En contexte scalaire retourne une référence de tableau.

ajouterEspaceNom ( nœud_ns )

Ajoute le nœud d'espace de noms à la liste des espaces de noms.

getPréfixe

Retourne le préfixe de cet élément

getNomDéveloppé

Retourne le nom développé de cet élément (pas encore correctement implémenté).

valeur_Texte

Pour les éléments, la valeur_Texte est la concaténation de toutes les valeurs_Texte de tous les descendants texte du nœud élément dans l'ordre du document.

toString ( [ norecurse ] )

Affiche (et tous les enfants) le nœud sous forme de chaîne de caractères. Ne traite pas les enfants si l'option norecurse est vraie.
