NOM

XmTextFieldSetEditable — Appel de fonction TextField qui définit la permission d'édition

SYNTAXE

#include <Xm/TextF.h>
void XmTextFieldSetEditable(
Widget widget,
Boolean editable);

DESCRIPTION

XmTextFieldSetEditable définit l'état de permission d'édition du widget TextField. Lorsqu'il est défini sur True, la chaîne de texte peut être modifiée.

widget
Spécifie l'identifiant du widget TextField.
editable
Spécifie une valeur booléenne qui, lorsqu'elle est True, autorise les modifications de la chaîne de texte.

Pour une définition complète de TextField et de ses ressources associées, voir XmTextField(3).
