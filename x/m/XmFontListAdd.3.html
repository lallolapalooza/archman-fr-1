NOM

XmFontListAdd — Une fonction de liste de polices qui crée une nouvelle liste de polices

SYNTAXE

#include <Xm/Xm.h>
XmFontList XmFontListAdd(
XmFontList oldlist,
XFontStruct *font,
XmStringCharSet charset);

DESCRIPTION

XmFontListAdd crée une nouvelle liste de polices composée du contenu de oldlist et du nouvel élément de liste de polices ajouté. Cette fonction désalloue oldlist après en avoir extrait les informations nécessaires ; par conséquent, ne référez plus oldlist par la suite.

NOTE : Cette fonction est obsolète et existe pour des raisons de compatibilité avec les versions précédentes. Elle a été remplacée par XmFontListAppendEntry.

oldlist
Spécifie un pointeur vers la liste de polices à laquelle un élément sera ajouté.
font
Spécifie un pointeur vers une structure de police pour laquelle la nouvelle liste de polices est générée. Il s'agit de la structure renvoyée par la fonction XLib XLoadQueryFont.
charset
Spécifie l'identifiant de l'ensemble de caractères pour la police. Il peut s'agir de XmSTRING_DEFAULT_CHARSET, mais cette valeur n'est pas conforme aux AES et pourrait être supprimée dans les futures versions de Motif. Si la valeur est XmSTRING_DEFAULT_CHARSET, la routine dérive l'ensemble de caractères de l'environnement linguistique actuel.

RETOUR

Renvoie NULL si oldlist est NULL ; renvoie oldlist si font ou charset est NULL ; sinon, renvoie une nouvelle liste de polices.

LIENS DELA

XmFontList(3) et XmFontListAppendEntry(3).
