XmVaCreateComboBox(library call) XmVaCreateComboBox(library call)

NOM

XmVaCreateComboBox, XmVaCreateManagedComboBox — Fonctions de création pratique pour le widget ComboBox.

SYNTAXE

#include <Xm/ComboBox.h>
Widget XmVaCreateComboBox(
Widget parent,
String name,
...);
Widget XmVaCreateManagedComboBox(
Widget parent,
String name,
...);

DESCRIPTION

Ces fonctions créent une instance du widget ComboBox et retournent l'identifiant du widget associé. Ces routines utilisent la convention d'appel de liste d'arguments de longueur variable (varargs) d'ANSI C.

La fonction XmVaCreateComboBox est une routine pratique qui appelle XtCreateWidget.

La fonction XmVaCreateManagedComboBox est une routine pratique qui appelle XtCreateManagedWidget.

parent
Spécifie l'identifiant du widget parent.
name
Spécifie le nom du widget créé.
...
Spécifie la liste d'arguments variables pour remplacer les valeurs défaut des ressources.

Pour une définition complète du ComboBox et de ses ressources associées, voir XmComboBox(3).

RETOUR

Retourne l'identifiant du widget ComboBox.

LIENS CONNEXES

XmComboBox(3), XmCreateComboBox(3), XtCreateWidget(3), et XtCreateManagedWidget(3).
