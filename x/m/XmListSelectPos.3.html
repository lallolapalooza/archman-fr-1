NOM

XmListSelectPos — Une fonction de liste qui sélectionne un élément à une position spécifiée dans la liste

SYNOPSIS

#include <Xm/List.h>
void XmListSelectPos(
Widget widget,
int position,
Boolean notify);

DESCRIPTION

XmListSelectPos met en surbrillance un élément de la liste à la position spécifiée et l'ajoute à la liste des éléments sélectionnés.

widget
Spécifie l'identifiant du widget Liste.
position
Spécifie la position de l'élément à sélectionner. Une valeur de 1 indique que le premier élément de la liste est sélectionné ; une valeur de 2 indique que le deuxième élément est sélectionné ; et ainsi de suite. Une valeur de 0 (zéro) indique que le dernier élément de la liste est sélectionné.
notify
Spécifie une valeur booléenne qui, lorsqu'elle est TRUE, appelle la fonction de rappel de sélection pour le mode actuel. Du point de vue de l'interface de l'application, l'appel de cette fonction avec notify à TRUE est indiscernable d'une action de sélection initiée par l'utilisateur. Lorsque notify est FALSE, aucune fonction de rappel n'est appelée.

Pour une définition complète de Liste et de ses ressources associées, voir XmList(3).

LIÉ À

XmList(3) et XmListSelectItem(3).
