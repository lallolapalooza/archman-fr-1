NOM

XmTextInsert — Fonction Text pour insérer une chaîne de caractères dans une chaîne de texte

SYNTAXE

#include <Xm/Text.h>
void XmTextInsert(
Widget widget,
XmTextPosition position,
char * value);

DESCRIPTION

XmTextInsert insère une chaîne de caractères dans la chaîne de texte du widget Text. Les positions de caractères commencent à 0 (zéro) et sont numérotées séquentiellement depuis le début du texte. Par exemple, pour insérer une chaîne après le quatrième caractère, le paramètre position doit être 4.

Cette routine appelle les callbacks XmNvalueChangedCallback du widget et les callbacks de vérification, soit XmNmodifyVerifyCallback, soit XmNmodifyVerifyCallbackWcs, ou les deux. Si les deux listes de callbacks de vérification sont enregistrées, les procédures de la liste XmNmodifyVerifyCallback sont exécutées en premier et les données résultantes sont passées aux callbacks XmNmodifyVerifyCallbackWcs. Si la ressource XmNcursorPosition est supérieure ou égale à position, le callback XmNmotionVerifyCallback est appelé.

Notez que si value est une chaîne nulle, aucun callback ne sera généré, car aucune modification n'aura été apportée.

widget
Spécifie l'ID du widget Text.
position
Spécifie la position dans la chaîne de texte où la chaîne de caractères doit être insérée.
value
Spécifie la chaîne de caractères à ajouter au widget texte.

Pour une définition complète de Text et de ses ressources associées, consultez XmText(3).

VOIR AUSSI

XmText(3) et XmTextInsertWcs(3).
