NOM

XmUpdateDisplay — Une fonction qui traite immédiatement tous les événements d'exposition en attente

SYNTAXE

void XmUpdateDisplay (widget)
        Widget  widget;
(void)

DESCRIPTION

XmUpdateDisplay offre à l'application un mécanisme pour forcer le retrait de tous les événements d'exposition en attente de la file d'entrée et leur traitement immédiat. Lorsqu'un utilisateur sélectionne un bouton dans un menu, les panneaux de menu sont retirés, puis les rappels d'activation enregistrés par l'application sont invoqués. Si l'un des rappels effectue une action longue, la partie de la fenêtre de l'application qui était couverte par les panneaux de menu n'aura pas été redessinée ; le traitement normal des expositions ne se produit pas tant que tous les rappels n'ont pas été invoqués. Si le développeur de l'application suspecte qu'un rappel prendra beaucoup de temps, il peut choisir d'invoquer XmUpdateDisplay avant de commencer son opération longue. Cette fonction est également utile chaque fois qu'une fenêtre transitoire, telle qu'une boîte de dialogue, est retirée ; les rappels sont invoqués avant que le traitement normal des expositions ne puisse se produire.

widget
Spécifie un widget ou un gadget.
