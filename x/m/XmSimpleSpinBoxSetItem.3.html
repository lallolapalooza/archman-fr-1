NOM

XmSimpleSpinBoxSetItem — définir un élément dans la liste XmSimpleSpinBox

SYNTAXE

#include <Xm/SpinB.h>
void XmSimpleSpinBoxSetItem(
Widget w,
XmString item);

DESCRIPTION

La fonction XmSimpleSpinBoxSetItem sélectionne un élément dans la liste du widget XmSimpleSpinBox donné et en fait la valeur actuelle.

L'argument w spécifie l'identifiant du widget.

L'argument item spécifie le XmString pour l'élément à définir dans le XmSimpleSpinBox. Si l'item n'est pas trouvé dans la liste, XmSimpleSpinBoxSetItem en informe l'utilisateur via la fonction XtWarning.

VALEUR DE RETOUR

La fonction XmSimpleSpinBoxSetItem ne retourne aucune valeur.

VOIR AUSSI
