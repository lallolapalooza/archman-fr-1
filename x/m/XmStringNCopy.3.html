NOM

XmStringNCopy — Une fonction de chaîne composite qui crée une copie d'une chaîne composite

SYNTAXE

#include <Xm/Xm.h>
XmString XmStringNCopy(
XmString s1,
int num_bytes);

DESCRIPTION

Cette fonction est obsolète et existe pour des raisons de compatibilité avec les versions précédentes. XmStringNCopy crée une copie de s1 qui contient un nombre spécifié d'octets, y compris les étiquettes, les indicateurs directionnels et les séparateurs. Elle renvoie ensuite la chaîne composite résultante. Les chaînes d'origine sont préservées. La fonction alloue de l'espace pour la chaîne composite résultante. L'application est responsable de la gestion de l'espace alloué. L'application peut récupérer l'espace alloué en appelant XmStringFree.

s1
Spécifie la chaîne composite.
num_bytes
Spécifie le nombre d'octets de s1 à copier. Si cette valeur est inférieure à la longueur de s1, autant d'octets que possible, mais potentiellement moins que cette valeur, seront ajoutés à s1 de telle sorte que la chaîne résultante reste une chaîne composite valide.

VALEUR DE RETOUR

Renvoie une nouvelle chaîne composite.

VOIR AUSSI

XmStringCreate(3) et XmStringFree(3).
