NOM

XmImSetXIC — Fonction du gestionnaire d'entrée qui enregistre un XIC existant auprès d'un widget

SYNTAXE

#include <Xm/XmIm.h>
XIC XmImSetXIC(
Widget widget,
XIC xic);

DESCRIPTION

XmImSetXIC enregistre le Contexte d'Entrée X (XIC) spécifié auprès du widget. Tout XIC existant enregistré pour le widget est désenregistré. Le nouveau XIC enregistré pour le widget est retourné.

Si xic n'a pas été créé par XmImGetXIC ou XmImRegister, il ne sera pas soumis aux activités de fermeture lorsqu'il n'aura plus de widgets enregistrés auprès de lui.

widget
Spécifie l'identifiant d'un widget pour lequel un nouveau Contexte d'Entrée doit être enregistré.
xic
Spécifie le Contexte d'Entrée à enregistrer auprès du widget. Si xic est NULL, la fonction retourne le XIC actuel utilisé par le widget.

VALEUR DE RETOUR

Retourne le nouveau XIC enregistré pour le widget. L'application est responsable de la libération du XIC retourné. Pour libérer le XIC, appelez XmImFreeXIC.

VOIR AUSSI

XmImGetXIC(3) et XmImFreeXIC(3).
