NOM

XmStringSegmentCreate — Une fonction de chaîne composite qui crée une chaîne composite

SYNTAXE

#include <Xm/Xm.h>
XmString XmStringSegmentCreate(
char * text,
XmStringTag tag,
XmStringDirection direction,
Boolean separator);

DESCRIPTION

Cette fonction est obsolète et existe pour des raisons de compatibilité avec les versions précédentes. Elle peut être remplacée en utilisant une combinaison de XmStringComponentCreate et XmStringConcat. XmStringSegmentCreate est une fonction de haut niveau qui assemble une chaîne composite composée d'une étiquette d'élément de liste de polices, d'un composant de direction, d'un composant de texte et d'un composant de séparateur facultatif.

La fonction alloue de l'espace pour la chaîne composite retournée. L'application est responsable de la gestion de l'espace alloué. L'application peut récupérer l'espace alloué en appelant XmStringFree.

text
Spécifie une chaîne terminée par NULL à utiliser comme composant texte de la chaîne composite.
tag
Spécifie le composant d'étiquette à associer au texte. La valeur XmFONTLIST_DEFAULT_TAG est pour la compatibilité avec les versions précédentes.
direction
Spécifie la direction du texte.
separator
Une valeur de False signifie que la chaîne composite n'a pas de séparateur à la fin. Une valeur de True signifie qu'un séparateur suit immédiatement le composant texte.

RETOUR

Retourne une nouvelle chaîne composite.
