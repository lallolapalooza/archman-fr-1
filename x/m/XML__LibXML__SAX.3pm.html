NOM

XML::LibXML::SAX - Analyseur SAX direct de XML::LibXML

DESCRIPTION

XML::LibXML fournit une interface à l'interface SAX directe de libxml2. Grâce à cette interface, il est possible de générer des événements SAX directement lors de l'analyse d'un document. En utilisant l'analyseur SAX, XML::LibXML ne créera pas une arborescence de document DOM.

Une telle interface est utile lorsque des documents XML très volumineux doivent être traités et qu'aucune fonction DOM n'est requise. En utilisant cette interface, il est possible de lire directement les données stockées dans un document XML dans les structures de données de l'application sans charger le document en mémoire.

L'interface SAX de XML::LibXML est basée sur la célèbre interface XML::SAX. Elle utilise l'interface générique telle que fournie par XML::SAX::Base.

En plus des fonctions génériques, qui ne peuvent traiter que des documents entiers, XML::LibXML::SAX fournit parse_chunk(). Cette méthode génère des événements SAX à partir de données bien équilibrées telles que celles souvent fournies par les bases de données.

FONCTIONNALITÉS

NOTE: Cette fonctionnalité est expérimentale.

Vous pouvez activer la jointure des données de caractères, ce qui peut entraîner une amélioration significative de la vitesse de votre traitement XML dans les situations où le ratio de balisage est faible, en activant la fonctionnalité http://xmlns.perl.org/sax/join-character-data de cet analyseur. Ceci est fait via la méthode set_feature comme suit :

$p->set_feature('http://xmlns.perl.org/sax/join-character-data', 1);

Vous pouvez également spécifier 0 pour désactiver. Par défaut, cette fonctionnalité est désactivée.
