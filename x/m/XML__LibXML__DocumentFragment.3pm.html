NOM

XML::LibXML::DocumentFragment - Implémentation du fragment de document DOM L2 par XML::LibXML

SYNTAXE

use XML::LibXML;

DESCRIPTION

Cette classe est une classe d'assistance telle que décrite dans la spécification DOM de niveau 2. Elle est implémentée comme un nœud sans nom. Toutes les fonctions d'ajout, d'insertion ou de remplacement sont désormais conscientes des fragments de document.

De plus, *tous* les nœuds non liés (tous les nœuds n'appartenant à aucun sous-arbre de document) sont des membres implicites des fragments de document.
