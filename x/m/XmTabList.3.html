NOM

XmTabList — Type de données pour une liste d'onglets

SYNTAXE

#include <Xm/Xm.h>
XmTabList

DESCRIPTION

XmTabList est le type de données pour une liste d'onglets. Une liste d'onglets est composée d'entrées de position d'onglet (XmTabs). Chaque fois qu'un composant d'onglet est rencontré pendant le rendu d'un XmString, l'origine du prochain dessin X dépend du prochain XmTab. Si une position d'onglet provoque le chevauchement du texte, la position x du segment est réinitialisée pour suivre immédiatement la fin du segment précédent.

Les listes d'onglets sont spécifiées dans les fichiers de ressources avec la syntaxe suivante :

spécification_ressource: onglet ESPACE [, ESPACE onglet ]*

La chaîne de valeur de ressource se compose d'un ou plusieurs onglets séparés par des virgules. Chaque onglet identifie la valeur de l'onglet, le type d'unité et si le décalage est relatif ou absolu. Par exemple :

onglet := nombre_décimal [ ESPACE unités ]
nombre_décimal := [ signe ] [[ CHIFFRE]*. ]CHIFFRE+
signe := +

où la présence ou l'absence de signe indique respectivement un décalage relatif ou un décalage absolu. Notez que les valeurs d'onglet négatives ne sont pas autorisées. unités indique le type d'unité à utiliser, comme décrit dans la page de référence XmConvertUnits.

Par exemple, ce qui suit spécifie une liste d'onglets composée d'un onglet absolu d'un pouce suivi d'un onglet relatif d'un pouce :

*tabList: 1in, +1in

Pour les ressources de type dimension ou position, vous pouvez spécifier des unités comme décrit dans la ressource XmNunitType des pages de référence XmGadget, XmManager ou XmPrimitive.

VOIR AUSSI

Consultez le Motif Programmer's Guide pour plus d'informations sur les onglets et les listes d'onglets. XmTabListCopy(3), XmTabListFree(3), XmTabListGetTab(3), XmTabListInsertTabs(3), XmTabListRemoveTabs(3), XmTabListReplacePositions(3), et XmTabListTabCount(3).
