XML::LibXML::Common(3) Documentation Perl fournie par l'utilisateur XML::LibXML::Common(3)

NOM

XML::LibXML::Common - Constantes et routines de codage de caractères

SYNTAXE

use XML::LibXML::Common;
$string_encodee = encodeToUTF8( $nom_encodage, $chaine_a_encoder );
$string_decodee = decodeFromUTF8($nom_encodage, $chaine_a_decoder );

DESCRIPTION

XML::LibXML::Common définit des constantes pour tous les types de nœuds et fournit une interface aux fonctions de conversion de jeux de caractères de libxml2.

Étant donné que XML::LibXML utilise ses propres définitions de types de nœuds, on pourrait vouloir utiliser XML::LibXML::Common en mode de compatibilité :

TAGS EXPORTER

use XML::LibXML::Common qw(:libxml);

Le tag ":libxml" utilisera le mode de compatibilité XML::LibXML, qui définit les anciennes définitions de type de nœud 'XML_'.

use XML::LibXML::Common qw(:gdome);

Le tag ":gdome" utilisera le mode de compatibilité XML::GDOME, qui définit les anciennes définitions de type de nœud 'GDOME_'.

use XML::LibXML::Common qw(:w3c);

Ceci utilise les noms de définition de type de nœud tels que spécifiés pour DOM.

use XML::LibXML::Common qw(:encoding);

Ce tag peut être utilisé pour exporter uniquement les fonctions de codage de jeux de caractères de XML::LibXML::Common.

Exports

Par défaut, les définitions W3 telles que définies dans les spécifications DOM et les fonctions d'encodage sont exportées par XML::LibXML::Common.

Fonctions de codage

Pour encoder ou décoder une chaîne vers ou depuis UTF-8, XML::LibXML::Common exporte deux fonctions qui fournissent une interface au support de codage dans "libxml2". Les jeux de caractères pris en charge par ces fonctions dépendent de la manière dont "libxml2" a été compilé. UTF-16 est toujours pris en charge et dans la plupart des installations, les codages ISO sont également pris en charge.

Cette interface était utile pour les versions antérieures de Perl. Depuis que Perl >= 5.8 fournit des fonctions similaires via le module "Encode", il est probablement préférable d'utiliser ces dernières.

encodeToUTF8
$string_encodee = encodeToUTF8( $nom_encodage, $chaine_a_encoder );

La fonction convertira une chaîne d'octets à partir de l'encodage spécifié vers une chaîne de caractères encodée en UTF-8.

decodeToUTF8
$string_decodee = decodeFromUTF8($nom_encodage, $chaine_a_decoder );

Cette fonction convertit une chaîne de caractères encodée en UTF-8 vers un encodage spécifié. Notez que la conversion peut déclencher une erreur si la chaîne donnée contient des caractères qui ne peuvent pas être représentés dans l'encodage cible.

Ces deux fonctions signalent leurs erreurs sur la sortie d'erreur standard. En cas d'erreur, la fonction croak()era. Pour capturer les informations d'erreur, il est nécessaire d'appeler la fonction d'encodage depuis un bloc eval afin d'éviter que l'intégralité du script ne soit interrompue en cas d'erreur d'encodage.

Une note sur l'historique

Avant XML::LibXML 1.70, cette classe était disponible en tant que distribution CPAN distincte, destinée à fournir des fonctionnalités partagées entre XML::LibXML, XML::GDOME et potentiellement d'autres modules. Comme il semble y avoir peu de progrès dans cette direction, nous avons décidé de fusionner XML::LibXML::Common 0.13 et XML::LibXML 1.70 en une seule distribution CPAN.

La fusion élimine également naturellement un problème pratique et urgent rencontré par de nombreux utilisateurs de XML::LibXML sur certaines plateformes, à savoir un comportement erratique mystérieux de XML::LibXML se produisant si la version installée (souvent pré-packagée) de XML::LibXML::Common était compilée avec une version plus ancienne de libxml2 que XML::LibXML.
