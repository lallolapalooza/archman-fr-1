NOM

XmComboBox — La classe du widget ComboBox

SYNOPSIS

#include <Xm/ComboBox.h>

DESCRIPTION

XmComboBox combine les capacités d'un widget TextField sur une seule ligne et d'un widget List. Il permet aux utilisateurs d'effectuer des opérations telles que la saisie et le collage d'informations, et il fournit également une liste de choix possibles parmi lesquels l'utilisateur peut sélectionner pour compléter le champ de saisie du TextField. La liste peut être affichée en permanence ou peut être déroulée par l'utilisateur. Lorsque la partie liste du ComboBox est masquée, les utilisateurs reçoivent un indice visuel (une flèche pointant vers le bas) à côté du champ TextField. La position de la flèche par rapport au champ TextField dépend de la ressource XmNlayoutDirection du widget. Cette version du ComboBox est appelée ComboBox « déroulant ». Les ComboBox déroulants sont utiles lorsque l'espace de l'écran est limité, ou lorsque les utilisateurs complèteront plus souvent le champ de saisie de texte en tapant du texte qu'en sélectionnant le texte du champ de saisie dans la liste. L'utilisateur peut accéder au ComboBox déroulant de l'une des deux manières suivantes :

•
En cliquant et en relâchant <Btn1> sur la flèche pointant vers le bas, ce qui fait apparaître la liste, et la liste reste affichée. Une sélection ultérieure d'un élément de la liste entraînera l'affichage de cet élément dans le champ de saisie de texte, et la liste se masquera elle-même.
•
En appuyant sur <Btn1> sur la flèche pointant vers le bas, en la faisant glisser vers un élément de la liste, puis en la relâchant là, ce qui sélectionne cet élément. La liste disparaît et l'élément sélectionné apparaît dans le champ de saisie de texte.

L'application fournit un tableau de chaînes qui remplissent la liste. Au moment de la création, des éléments de chaîne peuvent être passés au ComboBox via une arglist. Chaque chaîne devient un élément dans la liste, la première chaîne devenant l'élément en position 1, la deuxième chaîne devenant l'élément en position 2, et ainsi de suite. La taille de la liste est définie en spécifiant le nombre d'éléments visibles dans la liste (XmNvisibleItemCount). Si le nombre d'éléments dans la liste dépasse le nombre d'éléments visibles, une barre de défilement verticale apparaîtra automatiquement, permettant à l'utilisateur de faire défiler un grand nombre d'éléments.

ComboBox crée deux widgets enfants : un widget TextField pour la saisie de texte et une ScrolledWindow contenant une List pour la liste des éléments. Le nom de la liste d'éléments elle-même est List, et le nom du TextField est Text. L'application ou l'utilisateur peut spécifier des valeurs de ressources pour ces widgets dans un fichier de ressources, et l'application peut utiliser XtNameToWidget (en spécifiant "*List" pour la liste d'éléments ou "*Text" pour le widget TextField) pour obtenir les identifiants de widgets des widgets descendants. Au moment de la création, ComboBox transmet des valeurs de ressources appropriées dans l'arglist de création, y compris XmNitems, à la liste d'éléments. Notez que le résultat de la fourniture de la ressource XmNdestroyCallback dans l'arglist de création n'est pas spécifié. L'application doit utiliser la fonction XtAddCallback pour ajouter des callbacks au widget approprié (TextField ou List) après sa création.

ComboBox force les valeurs de ressources suivantes sur son enfant List :

•
Si XmNcomboBoxType est XmCOMBO_BOX, XmNtraversalOn est forcé à False.
•
XmNhighlightThickness est forcé à 2 dans un ComboBox déroulant et à 0 dans d'autres types de ComboBoxes.
•
XmNborderWidth est forcé à 0.
•
XmNnavigationType est forcé à XmNONE.
•
XmNselectionPolicy est forcé à XmBROWSE_SELECT.
•
XmNlistSizePolicy est forcé à XmVARIABLE.
•
XmNspacing est forcé à 0.
•
XmNvisualPolicy est forcé à XmVARIABLE.
•
XmNselectedPositions est forcé à NULL.
•
XmNselectedPositionsCount est forcé à 0.

Lorsque XmNcomboBoxType est XmDROP_DOWN_LIST, ComboBox force les valeurs de ressources suivantes sur son enfant TextField :

•
XmNeditable est forcé à False.
•
XmNcursorPositionVisible est forcé à False.
•
XmNshadowThickness est forcé à 0.

En revanche, lorsque XmNcomboBoxType est XmCOMBO_BOX ou XmDROP_DOWN_COMBO_BOX, ComboBox force les valeurs de ressources suivantes sur son enfant TextField :

•
XmNeditable est forcé à True.
•
XmNcursorPositionVisible est forcé à True.
•
XmNeditMode est forcé à XmSINGLE_LINE_EDIT.

ComboBox force toujours les valeurs des ressources suivantes sur le TextField :

•
XmNnavigationType est forcé à XmNONE.
•
XmNhighlightThickness est forcé à 0.
•
XmNborderWidth est forcé à 0.

ComboBox permet la sélection d'un seul élément de deux manières : en sélectionnant l'élément souhaité dans la List ou en saisissant du texte dans le TextField. ComboBox ne sélectionne pas automatiquement un élément de liste si l'utilisateur tape cette chaîne dans le TextField. Il sélectionne l'élément lorsque l'utilisateur appuie sur KActivate ou déplace le focus. ComboBox prend en charge le modèle de sélection Browse Select de List (voir la page de référence XmList pour une description de ce modèle), donc les sélections sont mutuellement exclusives. La sélection d'un élément dans la liste fait que cet élément est affiché dans le TextField du ComboBox. Si une application définit la ressource XmNvalue de TextField, cette chaîne est affichée dans le TextField. Si l'application n'a fourni aucun élément de liste, ou s'il n'y a pas de sélection actuelle, le TextField est vide.

Le TextField dans le widget ComboBox peut être éditable ou non éditable, en fonction de la valeur de la ressource XmNcomboBoxType.

Si le TextField est éditable, l'utilisateur peut y taper. Lorsque l'utilisateur appuie sur la touche Entrée, le ComboBox compare l'entrée tapée aux éléments de la List. S'il y a une correspondance exacte, l'élément de List correspondant est sélectionné. Si l'application souhaite valider le texte saisi (par exemple, pour s'assurer que la sélection tapée est valide), elle peut le faire en définissant XmNmodifyVerifyCallback sur le widget TextField.

Si le TextField n'est pas éditable, la saisie de texte peut déclencher un algorithme de correspondance qui tentera de faire correspondre le texte saisi avec les éléments de la liste. L'algorithme de correspondance spécifique appliqué, qui peut être nul, est déterminé par la valeur de la ressource XmNmatchBehavior dans ComboBox, qui peut être soit XmNONE, soit XmQUICK_NAVIGATE. Une valeur de XmNONE indique qu'aucun algorithme de correspondance ne se produira. Une valeur de XmQUICK_NAVIGATE indique que lorsque le widget List a le focus, la navigation d'un caractère est prise en charge. Dans cet algorithme, si le caractère tapé est le caractère initial de certains éléments de la List, cet algorithme provoque la navigation et la sélection de cet élément, et l'élément est affiché dans le TextField. La saisie ultérieure du même caractère fera cycler parmi les éléments ayant le même premier caractère.

Indépendamment du mécanisme de sélection utilisé (soit sélectionné directement dans la List, soit tapé dans le TextField), lorsqu'un élément de la List est sélectionné, cet élément est mis en surbrillance dans la List. De plus, l'élément sélectionné est affiché dans le TextField du ComboBox. Si l'utilisateur effectue une action qui déplacerait le focus hors du ComboBox, ou sélectionne un élément de la List, les callbacks XmNselectionCallback sont appelés pour notifier l'application du contenu actuel du TextField (ou du choix). L'application prend alors les mesures nécessaires en fonction de ce contenu (ou de ce choix).

ComboBox utilise le trait XmQTspecifyRenderTable et détient le trait XmQTaccessTextual.

Classes

XmComboBox hérite du comportement, des ressources et des traits des classes Core, Composite et XmManager.

Le pointeur de classe est xmComboBoxWidgetClass.

Le nom de la classe est XmComboBox.

ComboBox Resources

The following table lists the resources defined by the widget, along with other information associated with each resource. ComboBox resources are described in the following sections.

XmNallowOverlap
A Boolean value that determines whether the ComboBox list can overlay the parent's window. The default is False.
XmNcomboBoxType
Specifies the type of ComboBox to be created. This can be one of the following:
XmCOMBO_BOX
Generates a ComboBox where the list is always displayed, and the text entry field is editable.
XmDROP_DOWN_COMBO_BOX
Generates a ComboBox where the list is hidden unless specifically requested, and the text entry field is editable.
XmDROP_DOWN_LIST
Generates a ComboBox where the list is hidden unless specifically requested, and the text entry field is noneditable.
XmNfontList
Specifies the fontlist associated with XmComboBox. The fontlist is an obsolete construct, and has been superseded by the render table. It is included for compatibility with earlier versions of Motif, and for applications that do not easily support render tables. The default fontlist is derived from the default render table, and if both a fontlist and a render table are specified, the render table takes precedence.
XmNhighlightThickness
Specifies the thickness of the highlighting rectangle.
XmNitemCount
Specifies the number of items in the list. If unset, the lists's value is used. Refer to the XmList man page for more detailed information.
XmNitems
Specifies the items in the list. If unset, the lists's value is used. Refer to the XmList man page for more detailed information.
XmNlist
The list widget.
XmNmarginWidth
Specifies the horizontal spacing between the child widgets and the boundary of the ComboBox.
XmNmarginHeight
Specifies the vertical spacing between the child widgets and the boundary of the ComboBox.
XmNmatchBehavior
Defines the matching algorithm applied to match the text typed by the user in the TextField field with items in the list. The current values are XmNONE and XmQUICK_NAVIGATE, as follows:
XmNONE
Indicates that there is no assigned matching algorithm.
XmQUICK_NAVIGATE
Is only valid for noneditable ComboBoxes (XmNcomboBoxType resource value XmDROP_DOWN_LIST). This algorithm supports 1-character navigation when the List widget has focus. If the typed character is the initial character of some item in the List, this algorithm causes that item to be navigated to and selected. Subsequently typing the same character will cycle among the items with the same first character.
XmNpositionMode
Specifies how the value of the XmNselectedPosition resource and the item_position field of the callback structure are to be interpreted. Note that the convenience functions XmComboBoxDeletePos and XmComboBoxAddItem are not affected by this resource, and (like XmList) always use 1-based positions. Valid values for this resource are:
XmZERO_BASED
(DtComboBox compatibility mode: default) XmNselectedPosition is in [0,itemcount-1]. The item_position in the XmComboBoxCallbackStruct is 0 if the first element in the list was selected. Note that 0 is also returned if no element in the list was selected (that is, a new item was entered in the text field).
XmONE_BASED
(Motif mode) Both the resource value and the callback fields are 1-based. This is consistent with other Motif widgets.
XmNrenderTable
Specifies the render table associated with ComboBox. This render table is used in both the TextField field and the List in the ComboBox. This is used in conjunction with the XmNvisibleItemCount resource of the List to determine the height of the ComboBox widget.
If this value is NULL at initialization, and if the widget parent is XmBulletinBoard or its subclasses, VendorShell or its subclasses, or XmMenuShell, then the widget parent provides the default render table associated with the widget. If both a render table and a fontlist are specified, the render table will take precedence.
XmNselectedItem
Specifies a compound string that represents the current selection of the ComboBox. The selected item is the content of the ComboBox text entry field.
XmNselectedPosition
If the selection in the ComboBox is an item in the list, this is the index of the selected item in the list. If no item in the list is selected, this is 0.
XmNselectionCallback
Specifies the list of callbacks called when an item is selected. The reason field in the XmComboBoxCallbackStruct is XmCR_SELECT.
XmNtextField
The text field widget.
XmNvisibleItemCount
Specifies the number of visible items in the list. This will override any value specified for the list. Refer to the XmList man page for more detailed information.

Informations de rappel

Un pointeur vers la structure suivante est passé à chaque rappel. La structure de rappel est définie comme suit :

typedef struct
{
        int reason;
        XEvent *event;
        XmString item_or_text;
        int item_position;
} XmComboBoxCallbackStruct;
reason
Indique la raison pour laquelle le rappel a été invoqué.
event
Pointe vers le XEvent qui a déclenché le rappel. Il peut être NULL.
item_or_text
Le contenu du champ texte au moment où l'événement a provoqué le rappel. Le paramètre item_or_text pointe vers un espace de stockage temporaire qui est réutilisé une fois le rappel terminé. Si une application a besoin de sauvegarder l'élément, elle doit copier item_or_text dans son propre espace de données.
item_position
La position de l'élément dans le tableau XmNitems de la liste, basé sur 1. Si c'est 0, cela signifie que l'élément item_or_text n'a pas été sélectionné dans la liste.

NAME

XmComboBox — A ComboBox widget combines a Text widget and a List widget. A ComboBox widget is a combination of a Text widget and a List widget that allows the user to type a value directly into the Text widget or select a value from the List widget.

SYNOPSIS

#include <Xm/ComboBox.h>

DESCRIPTION

The XmComboBox widget combines a Text widget and a List widget. The ComboBox widget allows the user to type a value directly into the Text widget or select a value from the List widget. The ComboBox widget is a primitive widget.

The ComboBox widget is created by the XmCreateComboBox function. The ComboBox widget uses the XmInherit resources for the XmTextField widget and the XmList widget.

The ComboBox widget supports the following actions:

CBListAction(XmNcomboBoxType):
If the ComboBox is a drop-down type, this action posts the list. If the list is displayed, it unposts the list. If the ComboBox is not a drop-down type, this action does nothing.
CBListAction(ListNextPage):
Scrolls the list to the next page, moving the location cursor to a new item. This action also selects the new item, deselects any current selection, and calls the XmNbrowseSelectionCallback callbacks. If the ComboBox is not a drop-down type, then this action does nothing.
CBListAction(ListPrevPage):
Scrolls the list to the previous page, moving the location cursor to a new item. This action also selects the new item, deselects any current selection, and calls the XmNbrowseSelectionCallback callbacks. If the ComboBox is not a drop-down type, then this action does nothing.
CBListAction(ListBeginData):
Moves the location cursor to the first item in the list. In Normal Mode, this also deselects any current selection, selects the first item in the list, and calls the XmNbrowseSelectionCallback selection callback.
CBListAction(ListEndData):
Moves the location cursor to the last item in the list. In Normal Mode, this also deselects any current selection, selects the last item in the list, and calls the XmNbrowseSelectionCallback selection callback.
CBListAction(Up):
Moves the location cursor to the previous item in the list. This action also selects the previous item, deselects any current selection, and calls the XmNbrowseSelectionCallback callbacks. Note that, unlike the List ListPrevItem action, this action wraps around.
CBListAction(Down):
Moves the location cursor to the next item in the list. This action also selects the next item, deselects any current selection, and calls the XmNbrowseSelectionCallback callbacks. Note that, unlike the List ListNextItem action, this action wraps around.
CBListAction(XmDROP_DOWN_LIST):
If the ComboBox is not a drop-down type, this action does nothing. If the ComboBox is a drop-down type, this action posts the list. If the ComboBox is a drop-down type, and list is not displayed, posts the list. If list is displayed, it unposts the list.

ERRORS/WARNINGS

The toolkit will display a warning if the application tries to set the value of XmNlist or the XmNtextField resource, which are read-only (marked G in the resource table).
