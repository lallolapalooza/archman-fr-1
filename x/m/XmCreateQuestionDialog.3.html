NOM

XmCreateQuestionDialog — Fonction de création pratique pour les boîtes de dialogue MessageBox de type Question

SYNTAXE

#include <Xm/MessageB.h>
Widget XmCreateQuestionDialog(
Widget parent,
String name,
ArgList arglist,
Cardinal argcount);

DESCRIPTION

XmCreateQuestionDialog est une fonction de création pratique qui crée une DialogShell et une MessageBox enfant non gérée de la DialogShell. Une boîte de dialogue Question est utilisée pour obtenir la réponse à une question de l'utilisateur. Elle inclut un symbole, un message et trois boutons. Le symbole par défaut est un point d'interrogation. Les étiquettes par défaut des boutons sont OK, Cancel et Help.

Utilisez XtManageChild pour afficher la boîte de dialogue Question (en passant la MessageBox comme paramètre de widget) ; utilisez XtUnmanageChild pour la masquer.

XmCreateQuestionDialog force la valeur de la ressource Shell XmNallowShellResize à True.

parent
Spécifie l'ID du widget parent.
name
Spécifie le nom du widget créé.
arglist
Spécifie la liste d'arguments.
argcount
Spécifie le nombre de paires attribut/valeur dans la liste d'arguments (arglist).

Pour une définition complète de MessageBox et de ses ressources associées, voir XmMessageBox(3).

RETOUR

Retourne l'ID du widget MessageBox.

VOIR AUSSI

XmMessageBox(3).
