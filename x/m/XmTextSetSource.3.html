NOM

XmTextSetSource — Fonction Text définissant la source du widget

SYNTAXE

#include <Xm/Text.h>
void XmTextSetSource(
Widget widget,
XmTextSource source,
XmTextPosition top_character,
XmTextPosition cursor_position);

DESCRIPTION

XmTextSetSource définit la source du widget Text. Les widgets Text peuvent partager des sources de texte de sorte que les modifications dans un widget soient reflétées dans un autre. Cette fonction configure la source d'un widget afin qu'il puisse partager la source d'un autre widget.

La définition d'une nouvelle source de texte détruit l'ancienne source de texte si aucun autre widget Text n'utilise cette source. Pour remplacer une source de texte tout en la conservant pour une utilisation ultérieure, créez un widget Text non géré et définissez sa source sur la source de texte que vous souhaitez conserver.

widget
Spécifie l'identifiant du widget Text.
source
Spécifie la source avec laquelle le widget affiche le texte. Il peut s'agir d'une valeur retournée par la fonction XmTextGetSource(3). Si aucune source n'est spécifiée, le widget crée une source de chaîne par défaut.
top_character
Spécifie la position dans le texte à afficher en haut du widget. Il s'agit d'un nombre entier de caractères à partir du début du tampon de texte. La première position de caractère est 0 (zéro).
cursor_position
Spécifie la position dans le texte où se trouve le curseur d'insertion. Il s'agit d'un nombre entier de caractères à partir du début du tampon de texte. La première position de caractère est 0 (zéro).

Pour une définition complète de Text et de ses ressources associées, voir XmText(3).

VOIR AUSSI
