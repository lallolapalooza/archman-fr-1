NOM

XML::LibXML::Error - Erreurs structurées

SYNTAXE

eval { ... };
        if (ref($@)) {
          # gérer une erreur structurée (objet XML::LibXML::Error)
        } elsif ($@) {
          # erreur, mais pas un objet XML::LibXML::Error
        } else {
          # pas d'erreur
        }
$XML::LibXML::Error::WARNINGS=1;
$message = $@->as_string();
print $@->dump();
$error_domain = $@->domain();
$error_code = $@->code();
$error_message = $@->message();
$error_level = $@->level();
$filename = $@->file();
$line = $@->line();
$nodename = $@->nodename();
$error_str1 = $@->str1();
$error_str2 = $@->str2();
$error_str3 = $@->str3();
$error_num1 = $@->num1();
$error_num2 = $@->num2();
$string = $@->context();
$offset = $@->column();
$previous_error = $@->_prev();

DESCRIPTION

La classe XML::LibXML::Error est une petite interface pour la prise en charge des erreurs structurées de libxml2. Si XML::LibXML est compilé avec la prise en charge des erreurs structurées, toutes les erreurs rapportées par libxml2 sont transformées en objets XML::LibXML::Error. Ces objets sont automatiquement sérialisés en messages d'erreur correspondants lorsqu'ils sont imprimés ou utilisés dans une opération de chaîne de caractères, mais en tant qu'objets, ils peuvent également être utilisés pour obtenir des informations détaillées et structurées sur l'erreur qui s'est produite.

Contrairement à la plupart des autres objets XML::LibXML, XML::LibXML::Error ne wrappe pas directement une structure sous-jacente de libxml2, mais la transforme plutôt en une référence de hachage Perl "blessed" contenant les champs individuels des informations d'erreur structurées sous forme de paires clé-valeur de hachage. Les éléments individuels (champs) d'une erreur structurée peuvent soit être obtenus directement via $@->{field}, soit en utilisant des méthodes autoloaded telles que $@->field() (où field est le nom du champ). Les objets XML::LibXML::Error ont les champs suivants : domain, code, level, file, line, nodename, message, str1, str2, str3, num1, num2, et _prev (certains d'entre eux peuvent être indéfinis).

$XML::LibXML::Error::WARNINGS
$XML::LibXML::Error::WARNINGS=1;

Traditionnellement, XML::LibXML supprimait les avertissements du parseur en réglant la variable globale de libxml2 xmlGetWarningsDefaultValue à 0. Depuis la version 1.70, nous ne modifions plus les variables globales de libxml2 ; pour des raisons de compatibilité descendante, XML::LibXML supprime les avertissements. Cette variable peut être définie à 1 pour activer le rapport de ces avertissements via "warn" de Perl, et à 2 pour les rapporter via "die".

as_string
$message = $@->as_string();

Cette fonction sérialise un objet XML::LibXML::Error en une chaîne contenant le message d'erreur complet, proche du message produit par les gestionnaires d'erreur par défaut de libxml2 et les outils comme xmllint. Cette méthode est également utilisée pour surcharger l'opérateur « "" » sur XML::LibXML::Error, elle est donc appelée automatiquement chaque fois qu'un objet XML::LibXML::Error est traité comme une chaîne de caractères (par exemple, dans print $@).

dump
print $@->dump();

Cette fonction sérialise un XML::LibXML::Error en une chaîne affichant tous les champs de la structure d'erreur individuellement sur des lignes séparées de la forme 'nom' => 'valeur'.

domain
$error_domain = $@->domain();

Retourne une chaîne contenant des informations sur la partie de la bibliothèque qui a généré l'erreur. Peut être l'une des valeurs suivantes : "parser", "tree", "namespace", "validity", "HTML parser", "memory", "output", "I/O", "ftp", "http", "XInclude", "XPath", "xpointer", "regexp", "Schemas datatype", "Schemas parser", "Schemas validity", "Relax-NG parser", "Relax-NG validity", "Catalog", "C14N", "XSLT", "validity".

code
$error_code = $@->code();

Retourne le code d'erreur réel de libxml2. Le module XML::LibXML::ErrNo définit des constantes pour les codes d'erreur individuels. Actuellement, libxml2 utilise plus de 480 codes d'erreur différents.

message
$error_message = $@->message();

Retourne un message d'erreur informatif et lisible par l'homme.

level
$error_level = $@->level();

Retourne une valeur entière décrivant la gravité de l'erreur. XML::LibXML::Error définit les constantes suivantes :

  • XML_ERR_NONE = 0
  • XML_ERR_WARNING = 1 : Un simple avertissement.
  • XML_ERR_ERROR = 2 : Une erreur récupérable.
  • XML_ERR_FATAL = 3 : Une erreur fatale.
file
$filename = $@->file();

Retourne le nom du fichier en cours de traitement lorsque l'erreur s'est produite.

line
$line = $@->line();

Le numéro de ligne, si disponible.

nodename
$nodename = $@->nodename();

Nom du nœud où l'erreur s'est produite, si disponible. Lorsque ce champ n'est pas vide, libxml2 a effectivement retourné un pointeur physique vers le nœud spécifié. En raison de problèmes de gestion de la mémoire, il est très difficile d'implémenter un moyen d'exposer le pointeur au niveau Perl sous forme de XML::LibXML::Node. Pour cette raison, XML::LibXML::Error expose actuellement uniquement le nom du nœud.

str1
$error_str1 = $@->str1();

Spécifique à l'erreur. Informations textuelles supplémentaires.

str2
$error_str2 = $@->str2();

Spécifique à l'erreur. Informations textuelles supplémentaires.

str3
$error_str3 = $@->str3();

Spécifique à l'erreur. Informations textuelles supplémentaires.

num1
$error_num1 = $@->num1();

Spécifique à l'erreur. Informations numériques supplémentaires.

num2
$error_num2 = $@->num2();

Dans les versions récentes de libxml2, cette valeur contient un numéro de colonne de l'erreur ou 0 si non applicable.

context
$string = $@->context();

Pour les erreurs d'analyse, ce champ contient environ 80 caractères du XML près de l'endroit où l'erreur s'est produite. Le champ "$@->column()" contient le décalage correspondant. Si non applicable, le champ est indéfini.

column
$offset = $@->column();

Voir "$@->column()" ci-dessus.

_prev
$previous_error = $@->_prev();

Ce champ peut éventuellement contenir une référence à un autre objet XML::LibXML::Error représentant une erreur qui s'est produite juste avant cette erreur.
