NOM

XmMainWindowSetAreas — Une fonction de MainWindow qui identifie les enfants gérables pour chaque zone

SYNTAXE

#include <Xm/MainW.h>
void XmMainWindowSetAreas(
Widget widget,
Widget menu_bar,
Widget command_window,
Widget horizontal_scrollbar,
Widget vertical_scrollbar,
Widget work_region);

DESCRIPTION

XmMainWindowSetAreas identifie quels enfants valides pour chaque zone (comme la barre de menu et la zone de travail) doivent être activement gérés par MainWindow. Cette fonction configure également ou ajoute les widgets MenuBar, fenêtre de travail, fenêtre de commande et barres de défilement au widget de la fenêtre principale de l'application.

Chaque zone est facultative ; par conséquent, l'utilisateur peut passer NULL à un ou plusieurs des arguments suivants. Le gestionnaire de fenêtres fournit la barre de titre.

NOTE : XmMainWindowSetAreas est obsolète et existe pour des raisons de compatibilité avec les versions précédentes. Les informations précédemment renvoyées par cette fonction peuvent maintenant être obtenues via un appel à XtGetValues sur la ressource XmNscrolledWindowChildType.

widget
Spécifie l'identifiant du widget MainWindow.
menu_bar
Spécifie l'identifiant du widget pour la MenuBar à associer au widget MainWindow. Définissez cet identifiant uniquement après avoir créé une instance du widget MainWindow. Le nom de l'attribut associé à cet argument est XmNmenuBar.
command_window
Spécifie l'identifiant du widget pour la fenêtre de commande à associer au widget MainWindow. Définissez cet identifiant uniquement après avoir créé une instance du widget MainWindow. Le nom de l'attribut associé à cet argument est XmNcommandWindow.
horizontal_scrollbar
Spécifie l'identifiant du widget ScrollBar pour la barre de défilement horizontale à associer au widget MainWindow. Définissez cet identifiant uniquement après avoir créé une instance du widget MainWindow. Le nom de l'attribut associé à cet argument est XmNhorizontalScrollBar.
vertical_scrollbar
Spécifie l'identifiant du widget ScrollBar pour la barre de défilement verticale à associer au widget MainWindow. Définissez cet identifiant uniquement après avoir créé une instance du widget MainWindow. Le nom de l'attribut associé à cet argument est XmNverticalScrollBar.
work_region
Spécifie l'identifiant du widget pour la fenêtre de travail à associer au widget MainWindow. Définissez cet identifiant uniquement après avoir créé une instance du widget MainWindow. Le nom de l'attribut associé à cet argument est XmNworkWindow.

Pour une définition complète de MainWindow et de ses ressources associées, voir XmMainWindow(3).
