NOM

XmClipboardInquirePendingItems — Une fonction du presse-papiers qui renvoie une liste de paires identifiant de données/identifiant privé

SYNOPSIS

#include <Xm/CutPaste.h>
int XmClipboardInquirePendingItems (display, window, format_name, item_list, count)
        Display * display;
        Window  window;
        char    * format_name;
        XmClipboardPendingList  * item_list;
        unsigned long   * count;
(void)

DESCRIPTION

XmClipboardInquirePendingItems renvoie une liste de paires identifiant de données/identifiant privé pour le nom de format spécifié. Un élément de données est considéré comme en attente si l'application l'a initialement passé par nom, si l'application n'a pas encore copié les données et si l'élément n'a pas été supprimé du presse-papiers. L'application est responsable de libérer la mémoire fournie par cette fonction pour stocker la liste. Pour libérer la mémoire, appelez XtFree.

Cette fonction est utilisée par une application lors de sa sortie, pour déterminer si les données passées par nom doivent être envoyées au presse-papiers.

display
Spécifie un pointeur vers la structure Display qui a été retournée lors d'un appel précédent à XOpenDisplay ou XtDisplay.
window
Spécifie l'identifiant de fenêtre d'un widget qui relie la fenêtre de l'application au presse-papiers. L'identifiant de fenêtre du widget peut être obtenu via XtWindow. La même instance d'application doit passer le même identifiant de fenêtre à chacune des fonctions du presse-papiers qu'elle appelle.
format_name
Spécifie une chaîne de caractères contenant le nom du format pour lequel la liste des paires identifiant de données/identifiant privé doit être obtenue.
item_list
Spécifie l'adresse du tableau de paires identifiant de données/identifiant privé pour le nom de format spécifié. Cet argument est de type XmClipboardPendingList. L'application est responsable de libérer la mémoire fournie par cette fonction pour stocker la liste.
count
Spécifie le nombre d'éléments renvoyés dans la liste. S'il n'y a pas de données pour le nom de format spécifié, ou s'il n'y a pas d'élément dans le presse-papiers, cet argument est égal à 0 (zéro).

RETOUR

XmClipboardSuccess
La fonction a réussi.
XmClipboardLocked
La fonction a échoué car le presse-papiers était verrouillé par une autre application. L'application peut continuer à appeler la fonction à plusieurs reprises avec les mêmes paramètres jusqu'à ce que le verrou disparaisse. Cela donne à l'application la possibilité de demander si l'utilisateur souhaite continuer à essayer ou abandonner l'opération.
