NOM

XmPrintPopupPDM — Envoyer une notification pour que le PDM soit affiché

SYNTAXE

#include <Xm/Print.h>
XtEnum XmPrintPopupPDM(
Widgetprint_shell,
Widgetvideo_transient_for);

DESCRIPTION

Une fonction pratique qui envoie une notification pour démarrer un gestionnaire de dialogue d'impression au nom de l'application. XmPrintPopupPDM masque les détails du mécanisme de sélection X utilisé pour notifier le PDM qu'un nouveau dialogue doit être affiché pour cette application.

XmPrintPopupPDM envoie une requête de sélection soit à l'affichage d'impression du shell d'impression, soit à l'affichage vidéo du widget vidéo transitoire (en fonction de la variable d'environnement XPDMDISPLAY, qui ne peut prendre que les valeurs "print" ou "video"), demandant que les fenêtres PDM soient affichées au nom de l'application.

Retourne immédiatement avec le statut XmPDM_NOTIFY_FAIL (par exemple, si la fonction n'a pas pu allouer de mémoire pour la valeur de sélection, ou si XPDMDISPLAY n'est ni "print" ni "video") ou avec XmPDM_NOTIFY_SUCCESS, ce qui signifie simplement qu'un "message" a été envoyé au PDM spécifié par XPDMSELECTION, et non qu'il est déjà affiché à l'écran.

Pour savoir si le PDM est affiché ou s'il n'est pas en cours d'exécution, l'application doit enregistrer un rappel XmNpdmNotificationCallback avec le shell d'impression.

XmPrintPopupPDM affiche une fenêtre InputOnly au-dessus du dialogue, afin que l'utilisateur final n'utilise pas le dialogue de configuration d'impression pendant que le PDM essaie de s'afficher. Cette fenêtre est automatiquement supprimée lorsque le shell est sur le point d'appeler le rappel pour la première fois.

print_shell
Le shell d'impression utilisé pour ce travail et ce contexte d'impression.
video_transient_for
Le widget vidéo gérant la configuration d'impression de l'application.

VALEUR DE RETOUR

Retourne XmPDM_NOTIFY_SUCCESS si la fonction a pu envoyer la notification au processus PDM, XmPDM_NOTIFY_FAIL sinon.

ERREURS/AVERTISSEMENTS

Non applicable.

EXEMPLES

Exemple de rappel à partir du bouton "Setup..." d'une boîte de dialogue de configuration d'impression :

PrintSetupCallback(print_dialog...)
/*-------------*/
{
    if (XmPrintPopupPDM (pshell, XtParent(print_dialog)) !=
                                    XmPDM_NOTIFY_SUCCESS) {
        /* une boîte de dialogue d'erreur */
    }
}

Exemple de XmNpdmNotificationCallback à partir d'un shell d'impression :

pdmNotifyCB(print_shell...)
{
    XmPrintShellCallBackStruct * pr_cb = ...
    switch (pr_cb->reason) {
       case XmCR_PDM_NONE:
           /* aucun PDM disponible */
           PostErrorDialog(...);
           break;
       case XmCR_PDM_VXAUTH:
           /* le PDM n'est pas autorisé... */
           PostErrorDialog(...);
           break;
       case XmCR_PDM_UP: le PDM est en cours d'exécution
           /* tout va bien */
           break;
               default: /* autres cas */
   }
}
