NOM

XmCvtCTToXmString — Une fonction de chaîne composée qui convertit du texte composé en une chaîne composée

SYNTAXE

#include <Xm/Xm.h>
XmString XmCvtCTToXmString(
char * text);

DESCRIPTION

XmCvtCTToXmString convertit une chaîne (char *) au format de texte composé en une chaîne composée. L'application doit appeler XtAppInitialize avant d'appeler cette fonction. La conversion du texte composé en chaînes composées dépend de l'implémentation.

text
Spécifie une chaîne au format de texte composé à convertir en une chaîne composée.

RETOUR

Retourne une chaîne composée dérivée du texte composé. La fonction alloue de l'espace pour contenir la chaîne composée renvoyée. L'application est responsable de la gestion de l'espace alloué. L'application peut récupérer l'espace alloué en appelant XmStringFree. Le texte composé est supposé se terminer par NULL ; les caractères NULL dans le texte composé sont gérés correctement. La gestion des caractères de contrôle de TABULATION HORIZONTALE (HT) dans le texte composé est indéfinie. Le format de texte composé est décrit dans la norme du X Consortium Compound Text Encoding.
