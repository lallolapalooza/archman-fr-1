NOM

XmFileSelectionBoxGetChild — Fonction FileSelectionBox utilisée pour accéder à un composant

SYNTAXE

#include <Xm/FileSB.h>
Widget XmFileSelectionBoxGetChild(
Widget widget,
unsigned char child);

DESCRIPTION

XmFileSelectionBoxGetChild est utilisée pour accéder à un composant au sein d'un FileSelectionBox. Les paramètres donnés à la fonction sont le widget FileSelectionBox et une valeur indiquant quel composant doit être accédé.

NOTE : Cette routine est obsolète et existe pour la compatibilité avec les versions précédentes. Au lieu d'appeler XmFileSelectionBoxGetChild, vous devriez appeler XtNameToWidget tel que décrit dans la page de référence XmFileSelectionBox(3).

widget
Spécifie l'ID du widget FileSelectionBox.
child
Spécifie un composant au sein du FileSelectionBox. Les valeurs suivantes sont légales pour ce paramètre :
•
XmDIALOG_APPLY_BUTTON
•
XmDIALOG_CANCEL_BUTTON
•
XmDIALOG_DEFAULT_BUTTON
•
XmDIALOG_DIR_LIST
•
XmDIALOG_DIR_LIST_LABEL
•
XmDIALOG_FILTER_LABEL
•
XmDIALOG_FILTER_TEXT
•
XmDIALOG_HELP_BUTTON
•
XmDIALOG_LIST
•
XmDIALOG_LIST_LABEL
•
XmDIALOG_OK_BUTTON
•
XmDIALOG_SELECTION_LABEL
•
XmDIALOG_SEPARATOR
•
XmDIALOG_TEXT
•
XmDIALOG_WORK_AREA

Pour une définition complète de FileSelectionBox et de ses ressources associées, voir XmFileSelectionBox(3).

RETOUR

Retourne l'ID du widget du composant FileSelectionBox spécifié. Une application ne doit pas supposer que le widget retourné sera d'une classe particulière.

VOIR AUSSI

XmFileSelectionBox(3).
