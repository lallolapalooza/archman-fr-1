NOM

XML::Smart::DTD - Analyseur DTD pour XML::Smart.

DESCRIPTION

Ceci analysera une DTD et fournira des méthodes pour accéder aux informations stockées dans la DTD.

UTILISATION

use XML::Smart::DTD ;
my $dtd = XML::Smart::DTD->new('some.dtd') ;

if ( $dtd->child_exists('tag1','subtag1') ) {
...
}
use Data::Dumper ;
print Dumper( $dtd->tree ) ;

new

MÉTHODES

attr_exists ( TAG , ATTR )

Retourne TRUE si l'attribut existe dans l'élément TAG.

child_exists ( TAG , CHILD )

Retourne TRUE si l'enfant existe dans l'élément TAG.

elem_exists ( TAG )

Retourne TRUE si l'élément TAG existe.

error

Retourne la liste des erreurs.

get_attr_def ( TAG , ATTR )

Retourne la valeur par défaut d'un attribut.

get_attr_type ( TAG , ATTR )

Retourne le type de l'attribut.

get_attr_values ( TAG , ATTR )

Retourne les valeurs définies d'un attribut.

get_attrs ( TAG )

Retourne la liste des attributs d'un élément.

get_attrs_req ( TAG )

Retourne la liste des attributs requis d'un élément.

get_childs ( TAG )

Retourne la liste des enfants d'un élément.

get_childs_req ( TAG )

Retourne la liste des enfants requis d'un élément.

get_elem_opt ( TAG )

Retourne l'option d'occurrence d'un élément :

!  REQUIS ET UNIQUE OCCURRENCE
+  1 ou plus
*  0 ou plus
?  0 ou 1

get_elem_child_opt ( TAG , CHILD )

Identique à get_elem_opt() mais pour un élément en tant qu'enfant d'un élément.

is_attr_fix ( TAG , ATTR )

Retourne TRUE si un attribut est FIXED.

is_attr_req ( TAG , ATTR )

Retourne TRUE si un attribut est REQUIRED.

is_elem_any ( TAG )

Retourne TRUE si un élément est ANY.

is_elem_child_multi ( TAG , CHILD )

Retourne TRUE si un élément peut avoir plusieurs occurrences en tant qu'enfant de TAG.

is_elem_child_opt ( TAG , CHILD )

Retourne TRUE si un élément est optionnel en tant qu'enfant de TAG.

is_elem_child_req ( TAG , CHILD )

Retourne TRUE si un élément est requis en tant qu'enfant de TAG.

is_elem_child_uniq ( TAG , CHILD )

Retourne TRUE si un élément est requis et unique en tant qu'enfant de TAG.

is_elem_pcdata ( TAG )

Retourne TRUE si un élément est PCDATA (a du contenu).

is_elem_empty ( TAG )

Retourne TRUE si un élément est EMPTY (n'a pas d'attributs, de contenu ou d'enfants).

is_elem_multi ( TAG )

Retourne TRUE si un élément peut avoir plusieurs occurrences globalement.

is_elem_opt ( TAG )

Retourne TRUE si un élément est optionnel globalement.

is_elem_parent ( TAG , @PARENTS )

Retourne TRUE si la liste de @PARENTS peut être le parent de l'élément TAG.

is_elem_req

Retourne TRUE si un élément est requis globalement.

is_elem_uniq

Retourne TRUE si un élément est unique et requis globalement.

root

Retourne le nom de la racine de la DTD.

tree

Retourne l'arbre HASH de la DTD.
