NOM

XmStringCompare — Fonction de chaîne de caractères composée pour comparer deux chaînes

SYNTAXE

#include <Xm/Xm.h>
Boolean XmStringCompare(
XmString s1,
XmString s2);

DESCRIPTION

XmStringCompare renvoie une valeur booléenne indiquant les résultats d'une comparaison sémantiquement équivalente de deux chaînes de caractères composées.

Sémantiquement équivalent signifie que les chaînes ont les mêmes composantes textuelles, les mêmes étiquettes d'éléments de liste de polices, les mêmes directions et les mêmes séparateurs. En général, si deux chaînes composées sont créées avec la même chaîne (char *) en utilisant XmStringCreateLocalized dans le même environnement linguistique, les chaînes composées sont comparées comme étant égales. Si deux chaînes composées sont créées avec le même texte et le même argument d'étiquette en utilisant XmStringCreate, les chaînes sont comparées comme étant égales.

s1
Spécifie une chaîne composée à comparer avec s2
s2
Spécifie une chaîne composée à comparer avec s1

VALEUR DE RETOUR

Renvoie True si les deux chaînes composées sont équivalentes.

VOIR AUSSI

XmStringCreate(3) et XmStringCreateLocalized(3).
