NOM

XmCreateSpinBox — La fonction de création de SpinBox

SYNTAXE

#include <Xm/SpinB.h>
(void)

DESCRIPTION

XmCreateSpinBox crée un widget SpinBox.

Cette fonction crée un SpinBox avec deux flèches, mais sans aucun enfant traversable (choix à faire tourner). L'application peut créer des enfants de type texte pour accompagner ce SpinBox parent en utilisant XmCreateTextField ou XmCreateText.

parent
Spécifie l'ID du widget parent
nom
Spécifie le nom du widget créé
arglist
Spécifie la liste d'arguments
argcount
Spécifie le nombre de paires attribut/valeur dans la liste d'arguments (arglist)

Pour une définition complète de SpinBox et de ses ressources associées, voir XmSpinBox(3).

RETOUR

Retourne l'ID du widget SpinBox.
