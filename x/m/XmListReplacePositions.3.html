NOM

XmListReplacePositions — Fonction de liste qui remplace des éléments dans une liste en fonction de leur position

SYNOPIS

#include <Xm/List.h>
void XmListReplacePositions(
Widget widget,
int *position_list,
XmString *item_list,
int item_count;);

DESCRIPTION

XmListReplacePositions remplace des éléments non contigus dans une liste. L'élément à chaque position spécifiée dans position_list est remplacé par l'entrée correspondante dans item_list. Lorsque les éléments sont insérés dans la liste, ils sont comparés à la liste XmNselectedItems actuelle. Tous les nouveaux éléments qui correspondent à des éléments de la liste sélectionnée apparaissent comme sélectionnés. Un message d'avertissement est affiché si une position spécifiée est invalide ; c'est-à-dire si la valeur est 0 (zéro), un entier négatif, ou un nombre supérieur au nombre d'éléments dans la liste.

widget
Spécifie l'identifiant du widget Liste.
position_list
Spécifie un tableau des positions des éléments à remplacer. La position du premier élément de la liste est 1 ; la position du deuxième élément est 2 ; et ainsi de suite.
item_list
Spécifie un tableau des éléments de remplacement.
item_count
Spécifie le nombre d'éléments dans position_list et item_list. Ce nombre doit être non négatif.

Pour une définition complète de la liste et de ses ressources associées, voir XmList(3).
