NOM

XmMainWindowSep3 — Fonction MainWindow renvoyant l'ID du troisième widget Separator

SYNTAXE

#include <Xm/MainW.h>
Widget XmMainWindowSep3(
Widget widget);

DESCRIPTION

XmMainWindowSep3 renvoie l'ID du troisième Separator dans le MainWindow. Le troisième Separator est situé entre la fenêtre de message et le widget situé au-dessus. Ce Separator n'est visible que lorsque XmNshowSeparator est défini sur True.

NOTE : XmMainWindowSep3 est obsolète et existe pour des raisons de compatibilité avec les versions précédentes. Utilisez plutôt XtNameToWidget. Passez une variable MainWindow comme premier argument à XtNameToWidget et Separator3 comme second argument.

widget
Spécifie l'ID du widget MainWindow.

Pour une définition complète de MainWindow et de ses ressources associées, consultez XmMainWindow(3).

RETOUR

Renvoie l'ID du troisième Separator.

CONNEXES

XmMainWindow(3).
