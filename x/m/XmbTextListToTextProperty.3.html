XmbTextListToTextProperty(3) FONCTIONS XLIB XmbTextListToTextProperty(3)

NOM

XmbTextListToTextProperty, XwcTextListToTextProperty, Xutf8TextListToTextProperty, XmbTextPropertyToTextList, XwcTextPropertyToTextList, Xutf8TextPropertyToTextList, XwcFreeStringList, XDefaultString - convertir des listes de texte et des structures de propriétés de texte

SYNTAXE

int XmbTextListToTextProperty(Display *display, char **list, int count, XICCEncodingStyle style, XTextProperty *text_prop_return);

int XwcTextListToTextProperty(Display *display, wchar_t **list, int count, XICCEncodingStyle style, XTextProperty *text_prop_return);

int Xutf8TextListToTextProperty(Display *display, char **list, int count, XICCEncodingStyle style, XTextProperty *text_prop_return);

int XmbTextPropertyToTextList(Display *display, _Xconst XTextProperty *text_prop, char ***list_return, int *count_return);

int XwcTextPropertyToTextList(Display *display, _Xconst XTextProperty *text_prop, wchar_t ***list_return, int *count_return);

int Xutf8TextPropertyToTextList(Display *display, _Xconst XTextProperty *text_prop, char ***list_return, int *count_return);

void XwcFreeStringList(wchar_t **list);

char *XDefaultString(void)

ARGUMENTS

display
Spécifie la connexion au serveur X.
list
Spécifie une liste de chaînes de caractères terminées par un caractère nul.
count
Spécifie le nombre de chaînes fournies.
style
Spécifie la manière dont la propriété est encodée.
text_prop_return
Retourne la structure XTextProperty.
text_prop
Spécifie la structure XTextProperty à utiliser.
list_return
Retourne une liste de chaînes de caractères terminées par un caractère nul.
count_return
Retourne le nombre de chaînes.
list
Spécifie la liste de chaînes à libérer.

DESCRIPTION

Les fonctions XmbTextListToTextProperty, XwcTextListToTextProperty et Xutf8TextListToTextProperty définissent la valeur XTextProperty spécifiée à un ensemble d'éléments séparés par des nuls, représentant la concaténation de la liste spécifiée de chaînes de texte terminées par un caractère nul. Les chaînes de texte en entrée doivent être fournies dans l'encodage de la locale courante (pour XmbTextListToTextProperty et XwcTextListToTextProperty), ou dans l'encodage UTF-8 (pour Xutf8TextListToTextProperty).

Les fonctions définissent le champ d'encodage de text_prop_return à un Atom pour le display spécifié, nommant l'encodage déterminé par le style spécifié, et convertissent la liste de texte spécifiée dans cet encodage pour le stockage dans le champ de valeur text_prop_return. Si le style XStringStyle ou XCompoundTextStyle est spécifié, cet encodage est respectivement “STRING” ou “COMPOUND_TEXT”. Si le style XUTF8StringStyle est spécifié, cet encodage est “UTF8_STRING”. (Ceci est une extension introduite par The XFree86 Project, Inc., dans sa version 4.0.2. Sa présence est indiquée par le macro X_HAVE_UTF8_STRING.) Si le style XTextStyle est spécifié, cet encodage est celui de la locale courante. Si le style XStdICCTextStyle est spécifié, cet encodage est “STRING” si le texte est entièrement convertible en STRING, sinon “COMPOUND_TEXT”. Un octet nul final terminant est stocké à la fin du champ de valeur de text_prop_return mais n'est pas inclus dans le membre nitems.

Si la mémoire disponible est insuffisante pour la nouvelle chaîne de valeur, les fonctions retournent XNoMemory. Si la locale courante n'est pas supportée, les fonctions retournent XLocaleNotSupported. Dans chacun de ces cas d'erreur, les fonctions ne définissent pas text_prop_return.

Pour déterminer si les fonctions sont garanties de ne pas retourner XLocaleNotSupported, utilisez XSupportsLocale.

Si le texte fourni n'est pas entièrement convertible à l'encodage spécifié, les fonctions retournent le nombre de caractères non convertibles. Chaque caractère non convertible est converti en une chaîne par défaut, définie par l'implémentation et spécifique à l'encodage. Sinon, les fonctions retournent Success. Notez que la convertibilité complète à tous les styles sauf XStringStyle est garantie.

Pour libérer la mémoire allouée pour le champ de valeur, utilisez XFree.

Les fonctions XmbTextPropertyToTextList, XwcTextPropertyToTextList et Xutf8TextPropertyToTextList retournent une liste de chaînes de texte représentant les éléments séparés par des nuls de la structure XTextProperty spécifiée. Les chaînes retournées sont encodées en utilisant l'encodage de la locale courante (pour XmbTextPropertyToTextList et XwcTextPropertyToTextList) ou en UTF-8 (pour Xutf8TextPropertyToTextList). Les données dans text_prop doivent être de format 8.

Plusieurs éléments de la propriété (par exemple, les chaînes dans une sélection de texte disjointes) sont séparés par un octet nul. Le contenu de la propriété n'est pas nécessairement terminé par un nul ; tout nul terminant ne doit pas être inclus dans text_prop.nitems.

Si la mémoire disponible est insuffisante pour la liste et ses éléments, XmbTextPropertyToTextList, XwcTextPropertyToTextList et Xutf8TextPropertyToTextList retournent XNoMemory. Si la locale courante n'est pas supportée, les fonctions retournent XLocaleNotSupported. Sinon, si le champ d'encodage de text_prop n'est pas convertible à l'encodage de la locale courante, les fonctions retournent XConverterNotFound. Pour les locales supportées, l'existence d'un convertisseur depuis COMPOUND_TEXT, STRING, UTF8_STRING ou l'encodage de la locale courante est garantie si XSupportsLocale retourne True pour la locale courante (mais le texte réel peut contenir des caractères non convertibles). La conversion d'autres encodages dépend de l'implémentation. Dans tous ces cas d'erreur, les fonctions ne définissent aucune valeur de retour.

Sinon, XmbTextPropertyToTextList, XwcTextPropertyToTextList et Xutf8TextPropertyToTextList retournent la liste de chaînes de texte terminées par un caractère nul dans list_return et le nombre de chaînes de texte dans count_return.

Si le champ de valeur de text_prop n'est pas entièrement convertible à l'encodage de la locale courante, les fonctions retournent le nombre de caractères non convertibles. Chaque caractère non convertible est converti en une chaîne dans la locale courante, spécifique à cette locale. Pour obtenir la valeur de cette chaîne, utilisez XDefaultString. Sinon, XmbTextPropertyToTextList, XwcTextPropertyToTextList et Xutf8TextPropertyToTextList retournent Success.

Pour libérer la mémoire allouée pour la liste et son contenu retourné par XmbTextPropertyToTextList ou Xutf8TextPropertyToTextList, utilisez XFreeStringList. Pour libérer la mémoire allouée pour la liste et son contenu retourné par XwcTextPropertyToTextList, utilisez XwcFreeStringList.

La fonction XwcFreeStringList libère la mémoire allouée par XwcTextPropertyToTextList.

La fonction XDefaultString retourne la chaîne par défaut utilisée par Xlib pour la conversion de texte (par exemple, dans XmbTextPropertyToTextList). La chaîne par défaut est la chaîne dans la locale courante qui est produite lorsqu'un caractère non convertible est trouvé pendant la conversion de texte. Si la chaîne retournée par XDefaultString est la chaîne vide (""), aucun caractère n'est produit dans le texte converti. XDefaultString ne retourne pas NULL.

La chaîne retournée par XDefaultString est indépendante de la chaîne par défaut pour le dessin de texte ; consultez XCreateFontSet pour obtenir la chaîne par défaut d'un XFontSet.

Le comportement lorsqu'un point de code invalide est fourni à toute fonction Xlib est indéfini.

La chaîne retournée est terminée par un caractère nul. Elle est la propriété de Xlib et ne doit pas être modifiée ni libérée par le client. Elle peut être libérée après que la locale courante a été changée. Jusqu'à ce qu'elle soit libérée, elle ne sera pas modifiée par Xlib.

XmbTextListToTextProperty(3)

NAME

XmbTextListToTextProperty, XwcTextListToTextProperty, Xutf8TextListToTextProperty - convert a list of strings to a text property

SYNOPSIS

    #include <X11/Xlib.h>

    Status XmbTextListToTextProperty(
        Display *display,
        char **list,
        int count,
        XICCEncodingStyle style,
        XTextProperty *text_prop_return
    );
    Status XwcTextListToTextProperty(
        Display *display,
        wchar_t **list,
        int count,
        XICCEncodingStyle style,
        XTextProperty *text_prop_return
    );
    Status Xutf8TextListToTextProperty(
        Display *display,
        char **list,
        int count,
        XICCEncodingStyle style,
        XTextProperty *text_prop_return
    );

ARGUMENTS

display
Specifies the connection to the X server.
list
Specifies a list of text strings.
count
Specifies the number of strings in the list.
style
Specifies the desired encoding style for the text property. This can be XStringStyle, XCompoundTextStyle, XTextStyle, XStdICCTextStyle, or XUTF8StringStyle.
text_prop_return
Returns the resulting text property.

DESCRIPTION

These functions convert a list of text strings into a single XTextProperty structure. The conversion process depends on the specified XICCEncodingStyle.

XmbTextListToTextProperty converts a list of strings that are encoded according to the current locale.

XwcTextListToTextProperty converts a list of wide character strings.

Xutf8TextListToTextProperty converts a list of strings that are encoded in UTF-8.

The functions return Success if the conversion is successful, or a non-zero error code if an error occurs. If the conversion requires memory allocation and fails, XNoMemory is returned.

The functions XmbTextListToTextProperty and XwcTextListToTextProperty are part of the Xlib library. The function Xutf8TextListToTextProperty is an extension introduced by The XFree86 Project, Inc., in their 4.0.2 release. Its presence is indicated by the macro X_HAVE_UTF8_STRING.

STRUCTURES

The XTextProperty structure contains:

typedef struct {
        unsigned char *value;   /* property data */
        Atom encoding;  /* type of property */
        int format;     /* 8, 16, or 32 */
        unsigned long nitems;   /* number of items in value */
} XTextProperty;

The XICCEncodingStyle structure contains:

#define XNoMemory -1
#define XLocaleNotSupported -2
#define XConverterNotFound -3 
typedef enum {
        XStringStyle,           /* STRING */
        XCompoundTextStyle,     /* COMPOUND_TEXT */
        XTextStyle,             /* text in owner's encoding (current locale) */
        XStdICCTextStyle,       /* STRING, else COMPOUND_TEXT */
        XUTF8StringStyle        /* UTF8_STRING */
} XICCEncodingStyle;

DESCRIPTION

Ces fonctions convertissent une liste de chaînes de caractères en une unique structure XTextProperty. Le processus de conversion dépend du style de codage XICCEncodingStyle spécifié.

XmbTextListToTextProperty convertit une liste de chaînes qui sont codées selon l'environnement local actuel.

XwcTextListToTextProperty convertit une liste de chaînes de caractères larges.

Xutf8TextListToTextProperty convertit une liste de chaînes qui sont codées en UTF-8.

Les fonctions retournent Success si la conversion réussit, ou un code d'erreur non nul si une erreur se produit. Si la conversion nécessite une allocation de mémoire et échoue, XNoMemory est retourné.

Les fonctions XmbTextListToTextProperty et XwcTextListToTextProperty font partie de la bibliothèque Xlib. La fonction Xutf8TextListToTextProperty est une extension introduite par The XFree86 Project, Inc., dans sa version 4.0.2. Sa présence est indiquée par la macro X_HAVE_UTF8_STRING.

STRUCTURES

La structure XTextProperty contient :

typedef struct {
        unsigned char *value;   /* données de la propriété */
        Atom encoding;  /* type de la propriété */
        int format;     /* 8, 16 ou 32 */
        unsigned long nitems;   /* nombre d'éléments dans value */
} XTextProperty;

La structure XICCEncodingStyle contient :

#define XNoMemory -1
#define XLocaleNotSupported -2
#define XConverterNotFound -3 
typedef enum {
        XStringStyle,           /* STRING */
        XCompoundTextStyle,     /* COMPOUND_TEXT */
        XTextStyle,             /* texte dans le codage du propriétaire (locale actuelle) */
        XStdICCTextStyle,       /* STRING, sinon COMPOUND_TEXT */
        XUTF8StringStyle        /* UTF8_STRING */
} XICCEncodingStyle;
