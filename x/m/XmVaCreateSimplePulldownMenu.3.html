XmVaCreateSimplePulldownMenu(appel de bibliothèque) XmVaCreateSimplePulldownMenu(appel de bibliothèque)

NOM

XmVaCreateSimplePulldownMenu — Fonction de création pratique pour le widget RowColumn

SYNTAXE

#include <Xm/RowColumn.h>
Widget XmVaCreateSimplePulldownMenu(
Widget parent,
String name,
int post_from_button,
XtCallbackProc callback);

DESCRIPTION

XmVaCreateSimplePulldownMenu crée une instance d'un widget RowColumn de type XmMENU_PULLDOWN et retourne l'identifiant du widget associé. Cette routine utilise la convention d'appel de liste d'arguments de taille variable (varargs) ANSI C.

Cette routine crée un panneau de menu déroulant et ses boutons enfants. Le nom de chaque bouton est button_n, où n est un entier allant de 0 au nombre de boutons du menu moins 1. Le nom de chaque séparateur est separator_n, où n est un entier allant de 0 au nombre de séparateurs du menu moins 1. Le nom de chaque titre est label_n, où n est un entier allant de 0 (zéro) au nombre de titres du menu moins 1. Les boutons, séparateurs et titres sont nommés et créés dans l'ordre où ils sont spécifiés dans la partie variable de la liste d'arguments.

Cette routine attache également le menu déroulant à un CascadeButton ou CascadeButtonGadget dans le parent. Le menu déroulant est alors affiché à partir de ce bouton.

parent
Spécifie l'identifiant du widget parent du MenuShell.
name
Spécifie le nom du widget créé.
post_from_button
Spécifie le CascadeButton ou CascadeButtonGadget dans le parent auquel le panneau de menu déroulant est attaché. La valeur est l'entier n qui correspond au nème CascadeButton ou CascadeButtonGadget spécifié pour le parent du panneau de menu déroulant. Un panneau de menu déroulant ne peut être attaché qu'à un CascadeButton ou CascadeButtonGadget, et seuls les CascadeButtons et CascadeButtonGadgets sont comptés pour déterminer l'entier n. Le premier CascadeButton ou CascadeButtonGadget est le numéro 0 (zéro).
callback
Spécifie une procédure de rappel à appeler lorsqu'un bouton est activé ou lorsque sa valeur change. Cette fonction de rappel est ajoutée à chaque bouton après sa création. Pour un CascadeButtonGadget ou un PushButtonGadget, le rappel est ajouté en tant que XmNactivateCallback du bouton, et il est appelé lorsque le bouton est activé. Pour un ToggleButtonGadget, le rappel est ajouté en tant que XmNvalueChangedCallback du bouton, et il est appelé lorsque la valeur du bouton change. Le numéro du bouton est retourné dans le champ client_data.

La partie variable de la liste d'arguments se compose de groupes d'arguments. Le premier argument de chaque groupe est une constante ou une chaîne de caractères et détermine quels arguments suivent dans ce groupe. Le dernier argument de la liste doit être NULL. Voici les premiers arguments possibles dans chaque groupe de varargs:

XmVaCASCADEBUTTON
Ceci est suivi de deux arguments supplémentaires. L'ensemble spécifie un bouton dans le PulldownMenu et certaines de ses valeurs de ressources. Le bouton créé est un CascadeButtonGadget. Voici les deux arguments supplémentaires, dans l'ordre :
label
La chaîne d'étiquette, de type XmString
mnemonic
La touche mnémonique, de type KeySym
XmVaPUSHBUTTON
Ceci est suivi de quatre arguments supplémentaires. L'ensemble spécifie un bouton dans le PulldownMenu et certaines de ses valeurs de ressources. Le bouton créé est un PushButtonGadget. Voici les quatre arguments supplémentaires, dans l'ordre :
label
La chaîne d'étiquette, de type XmString
mnemonic
La touche mnémonique, de type KeySym
accelerator
L'accélérateur, de type String
accelerator_text
Le texte de l'accélérateur, de type XmString
XmVaRADIOBUTTON
Ceci est suivi de quatre arguments supplémentaires. L'ensemble spécifie un bouton dans le PulldownMenu et certaines de ses valeurs de ressources. Le bouton créé est un ToggleButtonGadget. Voici les quatre arguments supplémentaires, dans l'ordre :
label
La chaîne d'étiquette, de type XmString
mnemonic
La touche mnémonique, de type KeySym
accelerator
L'accélérateur, de type String
accelerator_text
Le texte de l'accélérateur, de type XmString
XmVaCHECKBUTTON
Ceci est suivi de quatre arguments supplémentaires. L'ensemble spécifie un bouton dans le PulldownMenu et certaines de ses valeurs de ressources. Le bouton créé est un ToggleButtonGadget. Voici les quatre arguments supplémentaires, dans l'ordre :
label
La chaîne d'étiquette, de type XmString.
mnemonic
La touche mnémonique, de type KeySym
accelerator
L'accélérateur, de type String
accelerator_text
Le texte de l'accélérateur, de type XmString
XmVaTITLE
Ceci est suivi d'un argument supplémentaire. La paire spécifie un LabelGadget de titre dans le PulldownMenu. Voici l'argument supplémentaire :
title
La chaîne de titre, de type XmString
XmVaSEPARATOR
Ceci est suivi d'aucun argument supplémentaire. Il spécifie un séparateur dans le PulldownMenu.
XmVaDOUBLE_SEPARATOR
Ceci est suivi d'aucun argument supplémentaire. Il spécifie un séparateur dans le PulldownMenu. Le type de séparateur est XmDOUBLE_LINE.
resource_name
Ceci est suivi d'un argument supplémentaire, la valeur de la ressource, de type XtArgVal. La paire spécifie une ressource et sa valeur pour le widget RowColumn.
XtVaTypedArg
Ceci est suivi de quatre arguments supplémentaires. L'ensemble spécifie une ressource et sa valeur pour le widget RowColumn. Une conversion de type de ressource est effectuée si nécessaire. Voici les quatre arguments supplémentaires, dans l'ordre :
name
Le nom de la ressource, de type String.
type
Le type de la valeur de ressource fournie, de type String.
value
La valeur de la ressource (ou un pointeur vers la valeur de la ressource, selon le type et la taille de la valeur), de type XtArgVal.
size
La taille de la valeur de ressource en octets, de type int.

XmVaCreateSimplePulldownMenu(3) — OpenMotif 2.3.8-4

NAME

XmVaCreateSimplePulldownMenu, XmVaCreateSimpleMenuBar, XmVaCreateSimplePopupMenu, XmVaCreateSimpleOptionMenu — create simple menus using variable argument lists

SYNOPSIS

#include <Xm/RowColumn.h>
Widget XmVaCreateSimplePulldownMenu(
        Widget parent,
        char *name,
        ArgList args,
        Cardinal num_args,
        ... );
Widget XmVaCreateSimpleMenuBar(
        Widget parent,
        char *name,
        ArgList args,
        Cardinal num_args,
        ... );
Widget XmVaCreateSimplePopupMenu(
        Widget parent,
        char *name,
        ArgList args,
        Cardinal num_args,
        ... );
Widget XmVaCreateSimpleOptionMenu(
        Widget parent,
        char *name,
        ArgList args,
        Cardinal num_args,
        ... );

DESCRIPTION

The XmVaCreateSimplePulldownMenu function creates a simple pulldown menu widget. The XmVaCreateSimpleMenuBar function creates a simple menubar widget. The XmVaCreateSimplePopupMenu function creates a simple popup menu widget. The XmVaCreateSimpleOptionMenu function creates a simple option menu widget.

These functions differ from the XmCreateSimple* functions in that they accept variable argument lists rather than argument lists created by XtVaCreateArgsList.

The simple menu functions create a menu pane and its children. The menu pane is a widget of type RowColumn with its XmNrowColumnType resource set to the appropriate value for the specific menu type:

XmVAPulldownMenu
Creates a pulldown menu pane. This is the default type for XmVaCreateSimplePulldownMenu.
XmVAMenuBar
Creates a menubar. This is the default type for XmVaCreateSimpleMenuBar.
XmVAPopupMenu
Creates a popup menu.
XmVAOptionMenu
Creates an option menu.

The simple menu functions also create a cascade button or a tear-off pane if appropriate. The function automatically sets the XmNmenuHelpWidget resource if the help button is created.

The variable argument list is a list of items to be created in the menu. Each item is specified by an XtVaNestedList structure. The list must be terminated by a NULL pointer.

XtVaNestedList
This is followed by one additional argument of type XtVarArgsList. This argument is a nested list of varargs returned by XtVaCreateArgsList.

For more information on variable-length argument lists, see the X Toolkit Intrinsics documentation.

A number of resources exist specifically for use with this and other simple menu creation routines. For a complete definition of RowColumn and its associated resources, see XmRowColumn(3).

RETURN

Returns the RowColumn widget ID.

RELATED

XmCreatePulldownMenu(3), XmCreateRowColumn(3), XmCreateSimplePulldownMenu, and XmRowColumn(3).
