NOM

XmImVaSetFocusValues — Une fonction de gestionnaire d'entrée qui notifie un gestionnaire d'entrée qu'un widget a reçu le focus d'entrée et met à jour les attributs du contexte d'entrée

SYNTAXE

#include <Xm/XmIm.h>
void XmImVaSetFocusValues(
Widget widget);

DESCRIPTION

XmImVaSetFocusValues notifie le gestionnaire d'entrée que le widget spécifié a reçu le focus d'entrée. Cette fonction met également à jour les attributs du contexte d'entrée associé au widget. Cette fonction transmet les attributs et les valeurs à XICSetValues. L'appelant de cette routine doit ne passer que les valeurs qui ont changé depuis le dernier appel à l'une de ces fonctions ; XmImVaSetValues, XmImVaSetFocusValues, XmImSetValues, ou XmImSetFocusValues. Voir la description dans la page de référence de XmImSetValues(3) pour une liste des ressources associées.

Cette routine utilise les conventions d'appel de liste d'arguments de longueur variable (varargs) d'ANSI C. La liste d'arguments de longueur variable se compose de groupes d'arguments, chacun contenant un attribut suivi de la valeur de l'attribut. Le dernier argument de la liste doit être NULL.

Notez que les widgets List et TextField appellent la fonction XmImVaSetFocusValues lorsqu'ils reçoivent le focus. Par conséquent, des appels supplémentaires à la fonction XmImVaSetFocusValues pour ces widgets sont inutiles.

widget
Spécifie l'ID du widget enregistré auprès du gestionnaire d'entrée

Pour plus d'informations sur les listes d'arguments de longueur variable, consultez la documentation de X Toolkit Intrinsics.

LIENS CONCERNÉS

XmImSetFocusValues(3), XmImSetValues(3), et XmImVaSetValues(3).
