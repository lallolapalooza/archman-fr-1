NOM

XmStringGetLtoR — Une fonction de chaîne composite qui recherche un segment de texte dans la chaîne composite d'entrée

SYNTAXE

#include <Xm/Xm.h>
Boolean XmStringGetLtoR(
XmString string,
XmStringCharSet tag,
char **text);

DESCRIPTION

Cette fonction est obsolète et existe pour des raisons de compatibilité avec les versions précédentes. Elle est remplacée par XmStringUnparse. XmStringGetLtoR renvoie le premier composant textuel de la chaîne composite d'entrée qui est étiqueté avec le tag spécifié. Le texte renvoyé doit être une séquence d'octets uniques, terminée par NULL. Si la fonction renvoie True, elle allouera de l'espace pour contenir le text renvoyé. L'application est responsable de la gestion de l'espace alloué. L'application peut libérer l'espace alloué en appelant XtFree.

string
Spécifie la chaîne composite.
tag
Spécifie le tag de l'élément de la liste de polices associé au texte. Une valeur de XmFONTLIST_DEFAULT_TAG identifie un segment de texte localisé.
text
Spécifie un pointeur vers une chaîne terminée par NULL.

VALEUR

Renvoie True si le segment de texte correspondant peut être trouvé. Au retour, text contiendra une séquence d'octets terminée par NULL contenant le segment correspondant.

VOIR AUSSI

XmStringCreate(3).
