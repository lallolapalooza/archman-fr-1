NOM

XmTextGetLastPosition — Fonction Text accédant à la dernière position dans le texte

SYNTAXE

#include <Xm/Text.h>
XmTextPosition XmTextGetLastPosition(
Widget widget);

DESCRIPTION

XmTextGetLastPosition accède à la dernière position dans le tampon de texte du widget Text. Il s'agit d'un nombre entier de caractères depuis le début du tampon, et représente la position à laquelle le texte ajouté à la fin du tampon est placé. La première position de caractère est 0 (zéro). La dernière position de caractère est égale au nombre de caractères dans le tampon de texte.

widget
Spécifie l'ID du widget Text.

Pour une définition complète de Text et de ses ressources associées, voir XmText(3).

RETOUR

Retourne une valeur de type XmTextPosition qui indique la dernière position dans le tampon de texte.

VOIR AUSSI

XmText(3).
