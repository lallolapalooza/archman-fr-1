NOM

XMapRequestEvent - Structure de l'événement MapRequest

STRUCTURES

La structure des événements MapRequest contient :

typedef struct {
        int type;       /* MapRequest */
        unsigned long serial;   /* # de la dernière requête traitée par le serveur */
        Bool send_event;        /* vrai si cela provient d'une requête SendEvent */
        Display *display;       /* Display à partir duquel l'événement a été lu */
        Window parent;
        Window window;
} XMapRequestEvent;

Lorsque vous recevez cet événement, les membres de la structure sont configurés comme suit.

Le membre type est défini sur le nom de constante du type d'événement qui l'identifie de manière unique. Par exemple, lorsque le serveur X signale un événement GraphicsExpose à une application cliente, il envoie une structure XGraphicsExposeEvent avec le membre type défini sur GraphicsExpose. Le membre display est défini sur un pointeur vers le Display sur lequel l'événement a été lu. Le membre send_event est défini sur True si l'événement provient d'une requête de protocole SendEvent. Le membre serial est défini à partir du numéro de série rapporté dans le protocole mais étendu à partir des 16 bits les moins significatifs à une valeur complète de 32 bits. Le membre window est défini sur la fenêtre la plus utile pour les gestionnaires de fenêtres graphiques.

Le membre parent est défini sur la fenêtre parente. Le membre window est défini sur la fenêtre à afficher.
