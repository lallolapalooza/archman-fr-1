DESCRIPTION

La classe Document est dans la plupart des cas le résultat d'un processus d'analyse. Mais il est parfois nécessaire de créer un Document à partir de zéro. La classe DOM Document fournit des fonctions qui sont conformes au style de nommage DOM Core.

Elle hérite de toutes les fonctions de XML::LibXML::Node, comme spécifié dans la spécification DOM. Cela permet l'accès aux nœuds en plus de l'élément racine au niveau du document - un "DTD" par exemple. Le support de ces nœuds est limité pour le moment.

Bien que généralement les nœuds soient liés à un document dans le concept DOM, il est suggéré que l'on devrait toujours créer un nœud non lié à aucun document. Il n'est pas nécessaire d'inclure réellement le nœud au document, mais une fois que le nœud est lié à un document, il est tout à fait sûr que toutes les chaînes de caractères ont le bon encodage. Si un nœud texte non lié avec une chaîne encodée en ISO est créé (par exemple avec $CLASS->new()), la fonction "toString" pourrait ne pas retourner le résultat attendu.

Pour éviter de tels problèmes, il est recommandé de passer toutes les données aux méthodes XML::LibXML sous forme de chaînes de caractères (c'est-à-dire encodées en UTF-8, avec le drapeau UTF8 activé).

MÉTHODES

De nombreuses fonctions listées ici sont exhaustivement documentées dans la spécification DOM Level 3 (http://www.w3.org/TR/DOM-Level-3-Core/). Veuillez vous référer à la spécification pour une documentation exhaustive.

new
$dom = XML::LibXML::Document->new( $version, $encoding );

alias pour createDocument()

createDocument
$dom = XML::LibXML::Document->createDocument( $version, $encoding );

Le constructeur pour la classe document. En tant que paramètre, il prend la chaîne de version et (optionnellement) la chaîne d'encodage. Appeler simplement createDocument() créera le document :

<?xml version="votre version" encoding="votre encodage"?>

Les deux paramètres sont optionnels. La valeur par défaut pour $version est 1.0, bien sûr. Si le paramètre $encoding n'est pas défini, l'encodage sera laissé non défini, ce qui signifie que UTF-8 est implicite.

L'appel de createDocument() sans aucun paramètre résultera en le code suivant :

<?xml version="1.0"?>

Alternativement, on peut appeler ce constructeur directement depuis le niveau de classe de XML::LibXML, pour éviter quelques frappes. Cela n'aura aucun effet sur l'instance de classe, qui est toujours XML::LibXML::Document.

my $document = XML::LibXML->createDocument( "1.0", "UTF-8" );

est donc un raccourci pour

my $document = XML::LibXML::Document->createDocument( "1.0", "UTF-8" );
URI
$strURI = $doc->URI();

Retourne l'URI (ou le nom de fichier) du document original. Pour les documents obtenus en analysant une chaîne de caractères ou un FH sans utiliser l'argument d'analyse d'URI de la fonction correspondante "parse_*", le résultat est une chaîne générée unknown-XYZ où XYZ est un nombre ; pour les documents créés avec le constructeur "new", l'URI est indéfinie.

La valeur peut être modifiée en appelant la méthode "setURI" sur le nœud du document.

setURI
$doc->setURI($strURI);

Définit l'URI du document rapporté par la méthode URI (voir aussi l'argument URI des diverses fonctions "parse_*").

encoding
$strEncoding = $doc->encoding();

retourne la chaîne d'encodage du document.

my $doc = XML::LibXML->createDocument( "1.0", "ISO-8859-15" );
print $doc->encoding; # affiche ISO-8859-15
actualEncoding
$strEncoding = $doc->actualEncoding();

retourne l'encodage dans lequel le XML sera retourné par $doc->toString(). Il s'agit généralement de l'encodage original du document tel que déclaré dans la déclaration XML et renvoyé par $doc->encoding. Si l'encodage original n'est pas connu (par exemple, s'il a été créé en mémoire ou analysé à partir d'un XML sans encodage déclaré), 'UTF-8' est retourné.

my $doc = XML::LibXML->createDocument( "1.0", "ISO-8859-15" );
print $doc->encoding; # affiche ISO-8859-15
setEncoding
$doc->setEncoding($new_encoding);

Cette méthode permet de changer la déclaration d'encodage dans la déclaration XML du document. La valeur affecte également l'encodage dans lequel le document est sérialisé en XML par $doc->toString(). Utilisez setEncoding() pour supprimer la déclaration d'encodage.

version
$strVersion = $doc->version();

retourne la chaîne de version du document

getVersion() est une forme alternative de cette fonction.

standalone
$doc->standalone

Cette fonction retourne la valeur numérique de l'attribut standalone des déclarations XML d'un document. Elle retourne 1 si standalone="yes" a été trouvé, 0 si standalone="no" a été trouvé et -1 si standalone n'a pas été spécifié (par défaut lors de la création).

setStandalone
$doc->setStandalone($numvalue);

Cette fonction définit l'attribut standalone de la déclaration XML du document. La valeur doit être un entier : 1 pour "yes", 0 pour "no". Si la valeur est indéfinie ou négative, la déclaration standalone sera supprimée.

compression
my $compression = $doc->compression;

retourne le niveau de compression zlib utilisé pour les flux de sortie. Par défaut, il est à 0, ce qui signifie aucune compression. Si zlib n'est pas disponible, cette méthode lèvera une exception.

setCompression
$doc->setCompression($ziplevel);

définit le niveau de compression zlib utilisé pour les flux de sortie. Les valeurs valides sont comprises entre 0 et 9. La valeur 0 désactive la compression. Si zlib n'est pas disponible, cette méthode lèvera une exception.

toString
$docstring = $dom->toString($format);

sérialise le document XML entier en une chaîne. Le paramètre facultatif $format (un entier) peut être utilisé pour contrôler le formatage de la sortie :

0   =>  compact output (no newlines, no indentation)
        1   =>  formatted output (newlines, indentation)
        2   =>  no declaration line
        3   =>  no declaration line, formatted output
        4   =>  no declaration line, compact output
        5   =>  no declaration line, no indentation, no newlines
        6   =>  no declaration line, no header, no declaration
        7   =>  no declaration line, no header, no declaration, formatted
        The default value is 1 (formatted output).
toStringC14N
$c14nstr = $doc->toStringC14N($comment_flag, $xpath [, $xpath_context ]);

produit une représentation Canoncial XML (C14N) du document. Si $comment_flag est vrai, les commentaires sont inclus dans la sortie. Sinon, ils sont omis. Si $xpath est fourni, seule la partie du document sélectionnée par l'expression XPath sera canonisée. $xpath_context peut être utilisé pour définir le contexte de l'expression XPath.

toStringEC14N
$ec14nstr = $doc->toStringEC14N($comment_flag, $xpath [, $xpath_context ], $inclusive_prefix_list);

produit une représentation Exclusive Canonical XML (EC14N) du document. Si $comment_flag est vrai, les commentaires sont inclus dans la sortie. Sinon, ils sont omis. Si $xpath est fourni, seule la partie du document sélectionnée par l'expression XPath sera canonisée. $xpath_context peut être utilisé pour définir le contexte de l'expression XPath. $inclusive_prefix_list est une liste des préfixes d'espace de noms à inclure dans la sortie.

serialize
$str = $doc->serialize($format);

Cette méthode est un alias pour toString().

toFile
$state = $doc->toFile($filename, $format);

s'assure que le document entier est écrit dans le fichier spécifié par $filename. Le paramètre facultatif $format contrôle le formatage de la sortie (voir toString()). La méthode retourne un booléen indiquant le succès.

toFH
$state = $doc->toFH($fh, $format);

s'assure que le document entier est écrit dans le Handle de Fichier spécifié par $fh. Le paramètre facultatif $format contrôle le formatage de la sortie (voir toString()). La méthode retourne un booléen indiquant le succès.

toStringHTML
$str = $document->toStringHTML();

produit une chaîne HTML du document. C'est utile pour les documents HTML car cela évite l'ajout de la déclaration XML.

serialize_html
$str = $document->serialize_html();

Ceci est un alias pour toStringHTML().

is_valid
$bool = $dom->is_valid();

vérifie si le document est valide par rapport à son DTD.

validate
$dom->validate();

valide le document par rapport à son DTD. Si le document n'est pas valide, une exception sera levée.

retourne le nœud de l'élément racine du document.

setDocumentElement
$dom->setDocumentElement( $root );

définit le nœud de l'élément racine du document.

createElement
$element = $dom->createElement( $nodename );

crée un élément avec le nom de nœud donné.

createElementNS
$element = $dom->createElementNS( $namespaceURI, $nodename );

crée un élément avec le nom d'espace donné et le nom de nœud.

createTextNode
$text = $dom->createTextNode( $content_text );

crée un nœud texte avec le contenu donné.

createComment
$comment = $dom->createComment( $comment_text );

crée un nœud commentaire avec le texte donné.

createAttribute
$attrnode = $doc->createAttribute($name [,$value]);

crée un nœud attribut avec le nom donné et (optionnellement) la valeur.

createAttributeNS
$attrnode = $doc->createAttributeNS( namespaceURI, $name [,$value] );

crée un nœud attribut avec le nom d'espace donné et (optionnellement) la valeur.

createDocumentFragment
$fragment = $doc->createDocumentFragment();

crée un fragment de document vide.

createCDATASection

crée une section CDATA avec le contenu donné.

createProcessingInstruction

crée une instruction de traitement avec la cible et les données données.

createEntityReference

createInternalSubset

crée une déclaration DTD interne. $rootnode est le nom de l'élément racine, $public est l'identifiant public (peut être undef) et $system est l'identifiant système (peut être undef).

createExternalSubset
$dtd = $document->createExternalSubset( $rootnode_name, $publicId, $systemId);

crée une déclaration DTD externe. $rootnode_name est le nom de l'élément racine, $publicId est l'identifiant public (peut être undef) et $systemId est l'identifiant système.

importNode

importe un nœud d'un autre document dans le document courant. Les nœuds importés ne sont pas encore liés au nouveau document.

adoptNode
$document->adoptNode( $node );

adopte un nœud d'un autre document. Le nœud est détaché de son ancien document et est maintenant lié au document courant.

externalSubset
my $dtd = $doc->externalSubset;

retourne le nœud DTD externe du document, s'il existe.

internalSubset
my $dtd = $doc->internalSubset;

retourne le nœud DTD interne du document, s'il existe.

définit le nœud DTD externe du document.

setInternalSubset
$doc->setInternalSubset($dtd);

définit le nœud DTD interne du document.

supprime et retourne le nœud DTD externe du document.

removeInternalSubset
my $dtd = $doc->removeInternalSubset();

supprime et retourne le nœud DTD interne du document.

getElementsByTagName
my @nodelist = $doc->getElementsByTagName($tagname);

retourne une liste de tous les nœuds d'éléments dont le nom de balise correspond au paramètre $tagname.

getElementsByTagNameNS

retourne une liste de tous les nœuds d'éléments dont l'espace de noms et le nom de balise correspondent aux paramètres fournis.

getElementsByLocalName
my @nodelist = $doc->getElementsByLocalName($localname);

retourne une liste de tous les nœuds d'éléments dont le nom local correspond au paramètre $localname.

getElementById

retourne le nœud d'élément avec l'ID spécifié. Si aucun nœud avec cet ID n'est trouvé, undef est retourné.

indexElements
$dom->indexElements();

Construit une table de hachage interne des éléments par leur ID. Cela rendra les appels ultérieurs à getElementById() beaucoup plus rapides.

compression
my $compression = $doc->compression;

libxml2 permet de lire des documents directement à partir de fichiers gzippés. Dans ce cas, la variable de compression est définie sur le niveau de compression de ce fichier (0-8). Si XML::LibXML a analysé une autre source ou si le fichier n'était pas compressé, la valeur retournée sera -1.

setCompression
$doc->setCompression($ziplevel);

Si l'on a l'intention d'écrire le document directement dans un fichier, il est possible de définir le niveau de compression pour un document donné. Ce niveau peut être compris entre 0 et 8. Si XML::LibXML ne doit pas essayer de compresser, utilisez -1 (par défaut).

Notez que cette fonctionnalité ne fonctionnera que si libxml2 est compilé avec le support zlib et si toFile() est utilisé pour la sortie.

toString
$docstring = $dom->toString($format);

toString est une fonction de sérialisation DOM, donc l'arbre DOM est sérialisé en une chaîne XML, prête pour la sortie.

IMPORTANT : contrairement à toString pour d'autres nœuds, sur les nœuds de document, cette fonction renvoie le XML sous forme de chaîne d'octets dans l'encodage d'origine du document (voir la méthode actualEncoding()) ! Cela signifie que vous pouvez simplement faire :

open my $out_fh, '>', $file;
print {$out_fh} $doc->toString;

quel que soit l'encodage réel du document. Voir la section sur les encodages dans XML::LibXML pour plus de détails.

Le paramètre facultatif $format définit l'indentation de la sortie. Ce paramètre est attendu comme une valeur "integer", qui spécifie que l'indentation doit être utilisée. Le paramètre de format peut avoir trois valeurs différentes s'il est utilisé :

Si $format est 0, le document est déchargé tel qu'il a été analysé à l'origine.

Si $format est 1, libxml2 ajoutera des espaces blancs ignorables, de sorte que le contenu des nœuds soit plus facile à lire. Les nœuds de texte existants ne seront pas modifiés.

Si $format est 2 (ou plus), libxml2 agira comme $format == 1 mais ajoutera un saut de ligne avant et après chaque nœud de texte.

libxml2 utilise une indentation codée en dur de 2 espaces par niveau d'indentation. Cette valeur ne peut pas être modifiée à l'exécution.

NOM

XML::LibXML::Document - Représente le document DOM XML

SYNOPIS

    use XML::LibXML;

    my $dom = XML::LibXML::Document->new( 'version' => '1.0', 'encoding' => 'UTF-8' );

    # Ajouter un noeud racine
    my $root = $dom->createElement('root');
    $dom->setDocumentElement($root);

    # Ajouter un element enfant
    my $child = $dom->createElement('child');
    $root->addChild($child);

    # Afficher le document
    print $dom->toString;

    # Parser un document
    my $dom = XML::LibXML::Parser->parse_file('monfichier.xml');

DESCRIPTION

La classe XML::LibXML::Document représente un document DOM XML. Elle hérite de XML::LibXML::Node.

Toutes les méthodes disponibles pour les nœuds XML::LibXML::Node sont disponibles pour les documents, à l'exception de celles qui ne sont pas pertinentes.

MÉTHODES

new
my $document = XML::LibXML::Document->new(
    version    => '1.0',
    encoding   => 'UTF-8',
    standalone => 1,
);

Crée un nouveau document DOM vide. Les arguments sont optionnels et définissent les attributs de la déclaration XML.

my $document = XML::LibXML::Document->new('foo.dtd');

Dans ce cas, un DTD interne est créé avec le nom de racine 'foo' et la déclaration du DTD est 'foo.dtd'. Pour plus de détails, voir createInternalSubset.

set_options
$document->set_options($option_flag);

Définit diverses options pour ce document. Les options sont une combinaison des drapeaux de libxml2.

setDocumentElement
$document->setDocumentElement($element);

Définit le nœud racine du document. L'élément donné devient le nœud enfant du document.

createInternalSubset
$dtd = $document->createInternalSubset( $rootnode, $public, $system);

Cette fonction crée et ajoute un sous-ensemble interne au document donné. Comme la fonction ajoute automatiquement le DTD au document, il n'est pas nécessaire d'ajouter explicitement le nœud créé au document.

my $document = XML::LibXML::Document->new();
my $dtd      = $document->createInternalSubset( "foo", undef, "foo.dtd" );

résultera dans le document XML suivant :

<?xml version="1.0"?>
 <!DOCTYPE foo SYSTEM "foo.dtd">

En définissant le paramètre public, il est possible de définir des DTD PUBLICS pour un document donné. Ainsi,

my $document = XML::LibXML::Document->new();
my $dtd      = $document->createInternalSubset( "foo", "-//FOO//DTD FOO 0.1//EN", undef );

provoquera la création de la déclaration suivante dans le document :

<?xml version="1.0"?>
<!DOCTYPE foo PUBLIC "-//FOO//DTD FOO 0.1//EN">
createExternalSubset
$dtd = $document->createExternalSubset( $rootnode_name, $publicId, $systemId);

Cette fonction est similaire à createInternalSubset(), mais ce DTD est considéré comme externe et n'est donc pas ajouté au document lui-même. Néanmoins, il peut être utilisé à des fins de validation.

importNode
$document->importNode( $node );

Si un nœud ne fait pas partie d'un document, il peut être importé dans un autre document. Comme spécifié dans la spécification DOM Level 2, le nœud ne sera pas modifié ni supprimé de son document d'origine ("$node->cloneNode(1)" sera appelé implicitement).

NOTE : N'essayez pas d'utiliser importNode() pour importer des sous-arbres contenant des références d'entités, même si la référence d'entité est le nœud racine du sous-arbre. Cela causera de graves problèmes à votre programme. Il s'agit d'une limitation de libxml2 et non de XML::LibXML lui-même.

adoptNode
$document->adoptNode( $node );

Si un nœud ne fait pas partie d'un document, il peut être importé dans un autre document. Comme spécifié dans la spécification DOM Level 3, le nœud ne sera pas modifié mais il sera supprimé de son document d'origine.

Après qu'un document a adopté un nœud, le nœud, ses attributs et tous ses descendants appartiennent au nouveau document. Comme le nœud n'appartient pas à l'ancien document, il sera d'abord détaché de son ancien emplacement.

NOTE : N'essayez pas d'utiliser adoptNode() pour importer des sous-arbres contenant des références d'entités, même si la référence d'entité est le nœud racine du sous-arbre. Cela causera de graves problèmes à votre programme. Il s'agit d'une limitation de libxml2 et non de XML::LibXML lui-même.

externalSubset
my $dtd = $doc->externalSubset;

Si un document a un sous-ensemble externe défini, il sera retourné par cette fonction.

NOTE Les nœuds Dtd ne sont pas des nœuds ordinaires dans libxml2. Le support de ces nœuds dans XML::LibXML est encore limité. En particulier, il peut être préférable de ne pas utiliser les fonctions de nœuds courantes sur les nœuds de déclaration doctype !

internalSubset
my $dtd = $doc->internalSubset;

Si un document a un sous-ensemble interne défini, il sera retourné par cette fonction.

NOTE Les nœuds Dtd ne sont pas des nœuds ordinaires dans libxml2. Le support de ces nœuds dans XML::LibXML est encore limité. En particulier, il peut être préférable de ne pas utiliser les fonctions de nœuds courantes sur les nœuds de déclaration doctype !

setExternalSubset
$doc->setExternalSubset($dtd);

EXPÉRIMENTAL !

Cette méthode définit un nœud DTD comme sous-ensemble externe du document donné.

setInternalSubset
$doc->setInternalSubset($dtd);

EXPÉRIMENTAL !

Cette méthode définit un nœud DTD comme sous-ensemble interne du document donné.

removeExternalSubset
my $dtd = $doc->removeExternalSubset();

EXPÉRIMENTAL !

Si un document a un sous-ensemble externe défini, il peut être retiré du document en utilisant cette fonction. Le nœud dtd retiré sera retourné.

removeInternalSubset
my $dtd = $doc->removeInternalSubset();

EXPÉRIMENTAL !

Si un document a un sous-ensemble interne défini, il peut être retiré du document en utilisant cette fonction. Le nœud dtd retiré sera retourné.

getElementsByTagName
my @nodelist = $doc->getElementsByTagName($tagname);

Implémente la fonction DOM Level 2.

Dans le contexte SCALAR, cette fonction retourne un objet XML::LibXML::NodeList.

getElementsByTagNameNS
my @nodelist = $doc->getElementsByTagNameNS($nsURI,$tagname);

Implémente la fonction DOM Level 2.

Dans le contexte SCALAR, cette fonction retourne un objet XML::LibXML::NodeList.

getElementsByLocalName
my @nodelist = $doc->getElementsByLocalName($localname);

Ceci permet de récupérer tous les nœuds d'un document donné avec le nom local spécifié.

Dans le contexte SCALAR, cette fonction retourne un objet XML::LibXML::NodeList.

getElementById
my $node = $doc->getElementById($id);

Retourne l'élément qui a un attribut ID avec la valeur donnée. Si aucun élément de ce type n'existe, retourne undef.

Note : l'ID d'un élément peut changer lors de la manipulation du document. Pour les documents avec un DTD, les informations sur les attributs ID ne sont disponibles que si le chargement/la validation du DTD a été demandé. Pour les documents HTML analysés avec l'analyseur HTML, la détection des ID est effectuée automatiquement. Dans les documents XML, tous les attributs "xml:id" sont considérés comme de type ID. Vous pouvez tester si un attribut est un ID avec $attr->isId().

Dans les versions 1.59 et antérieures, cette méthode s'appelait getElementsById() (au pluriel) par erreur. À partir de la version 1.60, ce nom est conservé comme alias uniquement pour des raisons de compatibilité ascendante.

indexElements
$dom->indexElements();

Cette fonction demande à libxml2 d'étiqueter tous les éléments d'un document avec leur index de position dans le document, ce qui accélère considérablement les requêtes XPath pour les grands documents. Elle ne doit être utilisée qu'avec des documents statiques qui ne seront pas modifiés par d'autres méthodes DOM, car une fois qu'un document est indexé, XPath préférera toujours l'index aux autres méthodes de détermination de l'ordre des nœuds dans le document. XPath pourrait donc retourner des listes de nœuds mal ordonnées lorsqu'elles sont appliquées à un document qui a été modifié après avoir été indexé. Il est bien sûr possible d'utiliser cette méthode pour réindexer un document modifié avant de l'utiliser à nouveau avec XPath. Cette fonction ne fait pas partie de la spécification DOM.

Cette fonction retourne le nombre d'éléments indexés, -1 si une erreur s'est produite, ou -2 si cette fonctionnalité n'est pas disponible dans la version de libxml2 en cours d'exécution.

Autres formats : txt, 3pm - Archivage de paquets

Description

3pm est un outil simple et léger pour archiver et restaurer des paquets à partir d'un dépôt Pacman. Il permet de créer des archives de paquets spécifiques ou de l'ensemble du dépôt, et de les restaurer plus tard si nécessaire. C'est particulièrement utile pour sauvegarder des versions spécifiques de paquets ou pour effectuer des restaurations rapides en cas de problème.

Utilisation

Voici quelques exemples d'utilisation de 3pm :

  • Archiver un paquet spécifique : 3pm -a mon_paquet
  • Archiver tous les paquets installés : 3pm -a
  • Restaurer un paquet à partir d'une archive : 3pm -r mon_paquet
  • Lister les archives disponibles : 3pm -l
  • Supprimer une archive : 3pm -d mon_paquet

Options

Les options courantes de 3pm incluent :

  • -a, --archive : Archiver le ou les paquets spécifiés. Si aucun paquet n'est spécifié, archive tous les paquets installés.
  • -r, --restore : Restaurer le ou les paquets spécifiés à partir de leur archive.
  • -l, --list : Lister toutes les archives de paquets disponibles.
  • -d, --delete : Supprimer l'archive du ou des paquets spécifiés.
  • -h, --help : Afficher ce message d'aide.

Fichiers

Les archives sont stockées par défaut dans le répertoire ~/.config/3pm/archives/.
