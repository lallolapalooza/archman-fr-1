NOM

XmClipboardUnlock — Une fonction de presse-papiers qui déverrouille le presse-papiers

SYNTAXE

#include <Xm/CutPaste.h>
int XmClipboardUnlock (display, window, remove_all_locks)
        Display * display;
        Window  window;
        Boolean remove_all_locks;
(void)

DESCRIPTION

XmClipboardUnlock déverrouille le presse-papiers, permettant à d'autres applications d'y accéder.

Si plusieurs appels à XmClipboardLock ont été effectués, le même nombre d'appels à XmClipboardUnlock est nécessaire pour déverrouiller le presse-papiers, sauf si remove_all_locks est défini sur True.

display
Spécifie un pointeur vers la structure Display qui a été retournée dans un appel précédent à XOpenDisplay ou XtDisplay.
window
Spécifie l'ID de fenêtre d'un widget qui relie la fenêtre de l'application au presse-papiers. L'ID de fenêtre du widget peut être obtenu via XtWindow. La même instance d'application doit passer le même ID de fenêtre à chacune des fonctions de presse-papiers qu'elle appelle.
remove_all_locks
Lorsque True, indique que tous les verrous imbriqués doivent être supprimés. Lorsque False, indique qu'un seul niveau de verrou doit être supprimé.

VALEUR

XmClipboardSuccess
La fonction a réussi.
XmClipboardFail
La fonction a échoué car le presse-papiers n'était pas verrouillé ou était verrouillé par une autre application.
