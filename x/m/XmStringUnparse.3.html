NOM

XmStringUnparse — Fonction de chaîne composite qui analyse le texte

SYNTAXE

#include <Xm/Xm.h>
XtPointer XmStringUnparse(
XmString string,
XmStringTag tag,
XmTextType tag_type,
XmTextType output_type,
XmParseTable parse_table,
Cardinal parse_count,
XmParseModel parse_model);

DESCRIPTION

XmStringUnparse recherche dans la chaîne d'entrée string des segments de texte marqués avec des balises de locale ou de jeu de caractères qui correspondent à tag. Le paramètre tag_type spécifie si la balise est de type locale ou de jeu de caractères. Si tag a la valeur NULL, tous les segments sont mis en correspondance. Lorsqu'un segment de texte est trouvé avec une balise correspondante, il est ajouté à la fin d'une chaîne résultante. Les caractères de la chaîne résultante sont de type output_type.

XmStringUnparse vérifie également string pour les composants qui correspondent aux composants de parse_table, et aussi pour voir si le composant correspond à la condition spécifiée par parse_model. Si le composant de chaîne correspond dans les deux vérifications, le caractère associé est ajouté à la fin de la chaîne résultante.

string
Spécifie le XmString à convertir.
tag
Spécifie la balise à utiliser pour la mise en correspondance avec les segments de texte. Seuls les segments de texte qui correspondent à tag seront inclus dans la chaîne résultante. Si tag a la valeur NULL, tous les segments sont considérés comme des correspondances, et tag_type est ignoré.
tag_type
Spécifie le type de balise à rechercher, y compris XmMULTIBYTE_TEXT, XmWIDECHAR_TEXT, et XmCHARSET_TEXT.
output_type
Spécifie le type de texte à retourner dans la chaîne, y compris XmMULTIBYTE_TEXT, XmWIDECHAR_TEXT, et XmCHARSET_TEXT.
parse_table
Spécifie la table d'analyse à utiliser pour scanner les composants de chaîne composite à convertir en d'autres caractères.
parse_count
Spécifie le nombre d'entrées dans parse_table.
parse_model
Spécifie quels composants non textuels doivent être considérés dans la mise en correspondance dans parse_table. Ceux-ci incluent :
XmOUTPUT_ALL
Sort toutes les correspondances de composants.
XmOUTPUT_BETWEEN
Ne sort que les correspondances de composants qui se trouvent entre deux composants textuels correspondants.
XmOUTPUT_BEGINNING
Ne sort que les correspondances de composants qui se trouvent au début d'un composant textuel correspondant.
XmOUTPUT_END
Ne sort que les correspondances de composants qui se trouvent à la fin d'un composant textuel correspondant.
XmOUTPUT_BOTH
Ne sort que les correspondances de composants qui se trouvent au début ou à la fin d'un composant textuel correspondant.

RETOUR

Retourne une chaîne nouvellement allouée contenant des caractères d'un type déterminé par output_type. L'application est responsable de la gestion de cet espace alloué. L'application peut récupérer cet espace alloué en appelant XtFree.

VOIR AUSSI

XmString(3), XmParseTable(3), XmParseMapping(3).
