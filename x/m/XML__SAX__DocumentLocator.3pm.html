XML::SAX::DocumentLocator(3) Documentation Perl fournie par l'utilisateur XML::SAX::DocumentLocator(3)

NOM

XML::SAX::DocumentLocator - Classe d'aide pour les localisateurs de documents

SYNOPSIS

my $locator = XML::SAX::DocumentLocator->new(
    sub { $object->get_public_id },
    sub { $object->get_system_id },
    sub { $reader->current_line },
    sub { $reader->current_column },
    sub { $reader->get_encoding },
    sub { $reader->get_xml_version },
);

DESCRIPTION

Ce module vous donne une référence de hachage liée qui appelle les fermetures spécifiées lorsqu'on lui demande PublicId, SystemId, LineNumber et ColumnNumber.

Il est utile pour écrire des analyseurs SAX afin de ne pas avoir à mettre à jour constamment les numéros de ligne dans une référence de hachage sur l'objet que vous passez à set_document_locator(). Voir le code source de XML::SAX::PurePerl pour un exemple d'utilisation.

API

Il n'y a qu'une seule méthode : "new". Passez-lui simplement une liste de fermetures qui, lorsqu'elles sont appelées, renverront respectivement le PublicId, le SystemId, le LineNumber, le ColumnNumber, l'Encoding et la XMLVersion.

Les fermetures reçoivent un seul paramètre, la clé demandée. Mais vous êtes libre de l'ignorer.
