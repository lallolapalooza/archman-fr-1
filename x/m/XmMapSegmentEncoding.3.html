NOM

XmMapSegmentEncoding — Fonction de chaîne composite qui renvoie le format d'encodage de texte composite associé à l'étiquette de liste de polices spécifiée

SYNTAXE

#include <Xm/Xm.h>
char * XmMapSegmentEncoding(
char *fontlist_tag);

DESCRIPTION

XmMapSegmentEncoding recherche dans le registre d'encodage de segments une entrée qui correspond à l'étiquette de liste de polices spécifiée et renvoie une copie du format d'encodage de texte composite associé. L'application est responsable de libérer la mémoire associée aux données renvoyées en appelant XtFree.

fontlist_tag
Spécifie l'étiquette de liste de polices de chaîne composite

VALEUR

Renvoie une copie du format d'encodage de texte composite associé si l'étiquette de liste de polices est trouvée dans le registre ; sinon, renvoie NULL.

VOIR AUSSI

XmCvtXmStringToCT(3), XmFontList(3), XmRegisterSegmentEncoding(3), et XmString(3).
