NOM

XmTextSetInsertionPosition — Fonction Text qui définit la position du curseur d'insertion

SYNTAXE

#include <Xm/Text.h>
void XmTextSetInsertionPosition(
Widget widget,
XmTextPosition position);

DESCRIPTION

XmTextSetInsertionPosition définit la position du curseur d'insertion du widget Text. Cette routine appelle également les rappels XmNmotionVerifyCallback du widget si la position du curseur d'insertion change.

widget
Spécifie l'identifiant du widget Text
position
Spécifie la position du curseur d'insertion. Il s'agit d'un nombre entier de caractères à partir du début du tampon de texte. La première position de caractère est 0 (zéro).

Pour une définition complète de Text et de ses ressources associées, voir XmText(3).
