NOM

XML::Atom - Implémentation des flux et API Atom

SYNOPSIS

use XML::Atom;

DESCRIPTION

Atom est un format de syndication, d'API et d'archivage pour les weblogs et autres données. XML::Atom implémente le format de flux ainsi qu'un client pour l'API.

LICENCE

XML::Atom est un logiciel libre ; vous pouvez le redistribuer et/ou le modifier selon les mêmes termes que Perl lui-même.
