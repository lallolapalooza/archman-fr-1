NOM

XmDirectionMatch — Une fonction qui vérifie un composant de direction spécifié

SYNTAXE

#include <Xm/Xm.h>
Boolean XmDirectionMatch (d1, d2)
        XmDirection     d1;
        XmDirection     d2;
(void)

DESCRIPTION

XmDirectionMatch compare deux valeurs XmDirection. La fonction renvoie une valeur booléenne en fonction de si les deux valeurs d'entrée "correspondent" ou non. La correspondance la plus simple est lorsque d1 et d2 sont identiques. Cependant, d'autres correspondances sont possibles. XmDirectionMatch tente de comparer uniquement les bits spécifiés ; les bits non spécifiés correspondent automatiquement.

Par exemple, supposons que d1 soit égal à XmTOP_TO_BOTTOM_RIGHT_TO_LEFT. Dans ce cas, la fonction renverra True si d2 est égal soit à XmRIGHT_TO_LEFT, soit à XmTOP_TO_BOTTOM. Cependant, la fonction renverra False si d2 est égal à XmTOP_TO_BOTTOM_LEFT_TO_RIGHT, XmBOTTOM_TO_TOP_RIGHT_TO_LEFT, ou XmBOTTOM_TO_TOP_LEFT_TO_RIGHT.

Notez que la direction peut être considérée comme ayant trois composantes : une composante horizontale, une composante verticale et la priorité entre elles. Cela signifie qu'en plus des directions mentionnées précédemment, la fonction renverra toujours False si d1 est égal à XmTOP_TO_BOTTOM_RIGHT_TO_LEFT et d2 est égal à XmRIGHT_TO_LEFT_TOP_TO_BOTTOM.

d1
Spécifie une valeur XmDirection.
d2
Spécifie une valeur XmDirection.

VALEURS DE RETOUR

Renvoie True si d1 "correspond" à d2 ; sinon, renvoie False.
