XmClipboardRegisterFormat(3)

NOM

XmClipboardRegisterFormat — Une fonction de presse-papiers qui enregistre un nouveau format

SYNTAXE

#include <Xm/CutPaste.h>
int XmClipboardRegisterFormat (display, format_name, format_length)
        Display * display;
        char    * format_name;
        int     format_length;
(void)

DESCRIPTION

XmClipboardRegisterFormat enregistre un nouveau format. Chaque format stocké dans le presse-papiers doit avoir une longueur associée ; cette longueur doit être connue des routines du presse-papiers. Les formats sont connus sous le nom de cibles dans le Inter-Client Communication Conventions Manual (ICCCM). Tous les formats spécifiés par la version 1.1 des conventions ICCCM sont pré-enregistrés. Tout autre format que l'application souhaite utiliser doit soit être des données 8 bits, soit être enregistré via cette routine. L'échec de l'enregistrement de la longueur des données entraîne des incompatibilités entre les applications sur différentes plateformes ayant des ordres d'inversion d'octets différents.

display
Spécifie un pointeur vers la structure Display qui a été retournée lors d'un appel précédent à XOpenDisplay ou XtDisplay.
format_name
Spécifie le nom de la chaîne pour le nouveau format (cible).
format_length
Spécifie la longueur du format en bits (8, 16 ou 32).

VALEUR

XmClipboardBadFormat
Le format_name ne doit pas être NULL, et le format_length doit être 8, 16 ou 32.
XmClipboardSuccess
La fonction a réussi.
XmClipboardLocked
La fonction a échoué car le presse-papiers était verrouillé par une autre application. L'application peut continuer à appeler la fonction à nouveau avec les mêmes paramètres jusqu'à ce que le verrou disparaisse. Cela donne à l'application la possibilité de demander si l'utilisateur souhaite continuer d'essayer ou abandonner l'opération.
XmClipboardFail
La fonction a échoué car le format spécifié était déjà enregistré avec une longueur différente de celle spécifiée maintenant. Si un format spécifié était déjà enregistré avec la même longueur que celle spécifiée maintenant, XmClipboardSuccess est retourné.
