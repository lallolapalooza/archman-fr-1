NOM

XmStringComponentType — Type de données pour les composants de chaînes composites

SYNTAXE

#include <Xm/Xm.h>

DESCRIPTION

XmStringComponentType est le type de données spécifiant les types de composants de chaînes composites. Un composant de chaîne composite identifie une partie d'une chaîne composite et peut avoir une valeur et une longueur. Un composant de chaîne composite peut être de l'un des types suivants. Ces types de composants sont regroupés selon leur longueur et leur type de valeur.

Les composants suivants ont des valeurs NULL et des longueurs de 0 (zéro).

XmSTRING_COMPONENT_SEPARATOR
Ce composant correspond généralement à un saut de ligne ou à un retour chariot dans le texte affiché.
XmSTRING_COMPONENT_TAB
Ce composant peut être considéré comme un composant texte ne contenant qu'une seule tabulation.
XmSTRING_COMPONENT_LAYOUT_POP
La direction de mise en page est conservée dans une pile, la direction actuelle se trouvant au sommet de la pile. Lorsque ce composant est lu, la direction de mise en page la plus récemment lue est retirée de la pile et remplacée par la direction qui la précédait immédiatement.
XmSTRING_COMPONENT_END
Ce composant marque la fin d'une chaîne composite. Aucun autre composant ne devrait suivre. Si une application ne place pas de composant XmSTRING_COMPONENT_END à la fin d'une XmString, Motif le fait automatiquement pour l'application.

Le composant suivant a une valeur de type XmDirection et la longueur de cette direction.

XmSTRING_COMPONENT_LAYOUT_PUSH
La direction de mise en page est conservée dans une pile, la direction actuelle se trouvant au sommet de la pile. Ce composant remplace la direction de mise en page actuelle et en fait pousser une autre au sommet de cette pile.

Le composant suivant a une valeur de type XmStringDirection et la longueur de cette direction.

XmSTRING_COMPONENT_DIRECTION
Ce composant définit la direction de la chaîne en remplaçant la direction précédente de la chaîne.

Les composants suivants ont des valeurs de type char * ou un type équivalent, et les longueurs de ces types.

XmSTRING_COMPONENT_LOCALE_TEXT
Ce composant contient le texte multibyte d'une chaîne composite.
XmSTRING_COMPONENT_WIDECHAR_TEXT
Ce composant contient le texte widechar d'une chaîne composite.
XmSTRING_COMPONENT_TEXT
Ce composant contient le texte charset d'une chaîne composite. Notez qu'une chaîne composite ne peut pas contenir à la fois du texte charset et du texte local (multibyte ou widechar).
XmSTRING_COMPONENT_RENDITION_BEGIN
Ce composant marque le début d'une nouvelle rendition. Tout le texte suivant ce composant sera rendu en utilisant cette rendition comme primaire. S'il existe déjà une rendition en cours, elle est conservée en mémoire et utilisée pour remplir toutes les valeurs non spécifiées dans la rendition primaire. Les renditions sont conservées jusqu'à ce qu'un composant correspondant XmSTRING_COMPONENT_RENDITION_END soit rencontré.
XmSTRING_COMPONENT_RENDITION_END
Ce composant signifie que la rendition spécifiée ne sera plus utilisée pour rendre le texte, et ne sera pas disponible pour remplir les valeurs non spécifiées des renditions plus récentes.
XmSTRING_COMPONENT_UNKNOWN
Ce type de composant signifie que le contenu du composant appartient à un type de composant inconnu.
XmSTRING_COMPONENT_LOCALE
Utilisez ce composant pour spécifier la locale dans laquelle une application internationalisée doit s'exécuter. La seule chaîne de caractères valide pour ce composant est _MOTIF_DEFAULT_LOCALE.
XmSTRING_COMPONENT_TAG
Pour le texte charset, il s'agit de la balise de la police à utiliser pour afficher le texte. Cette balise est parfois appelée balise charset ou balise fontlist.
XmSTRING_COMPONENT_CHARSET
Ce composant est obsolète et est conservé pour des raisons de compatibilité avec les versions précédentes. Il a été remplacé par XmSTRING_COMPONENT_TAG.
XmSTRING_COMPONENT_FONTLIST_ELEMENT_TAG
Ce composant est obsolète et est conservé pour des raisons de compatibilité avec les versions précédentes. Il a été remplacé par XmSTRING_COMPONENT_TAG.

Certains composants de chaînes composites dépendent de valeurs définies dans d'autres composants. La définition du composant XmSTRING_COMPONENT_TAB, par exemple, dépend des informations du composant XmSTRING_COMPONENT_RENDITION_BEGIN. Pour tenir compte de ces dépendances, une chaîne composite typique aura ses composants membres dans l'ordre suivant :

[
  [ XmSTRING_COMPONENT_LAYOUT_PUSH ]
  [ XmSTRING_COMPONENT_RENDITION_BEGIN ]*
  [ XmSTRING_COMPONENT_TAG | XmSTRING_COMPONENT_LOCALE ]
  [ XmSTRING_COMPONENT_TAB ]*
  [ XmSTRING_COMPONENT_DIRECTION ]
  [ XmSTRING_COMPONENT_TEXT |
    XmSTRING_COMPONENT_LOCALE_TEXT |
    XmSTRING_COMPONENT_WIDECHAR_TEXT ]
  [ XmSTRING_COMPONENT_RENDITION_END ]*
  [ XmSTRING_COMPONENT_LAYOUT_POP ]
  [ XmSTRING_COMPONENT_SEPARATOR ]
]*
XmSTRING_COMPONENT_END
