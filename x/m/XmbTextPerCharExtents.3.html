Paquet: libx11

XmbTextPerCharExtents(3) FONCTIONS XLIB XmbTextPerCharExtents(3)

NOM

XmbTextPerCharExtents, XwcTextPerCharExtents, Xutf8TextPerCharExtents - obtenir des informations par caractère pour une chaîne de texte

SYNTAXE

Status XmbTextPerCharExtents(XFontSet font_set, _Xconst char *string, int num_bytes, XRectangle *ink_array_return, XRectangle *logical_array_return, int array_size, int *num_chars_return, XRectangle *overall_ink_return, XRectangle *overall_logical_return);

Status XwcTextPerCharExtents(XFontSet font_set, _Xconst wchar_t *string, int num_wchars, XRectangle *ink_array_return, XRectangle *logical_array_return, int array_size, int *num_chars_return, XRectangle *overall_ink_return, XRectangle *overall_logical_return);

Status Xutf8TextPerCharExtents(XFontSet font_set, _Xconst char *string, int num_bytes, XRectangle *ink_array_return, XRectangle *logical_array_return, int array_size, int *num_chars_return, XRectangle *overall_ink_return, XRectangle *overall_logical_return);

ARGUMENTS

array_size
Spécifie la taille de ink_array_return et logical_array_return. L'appelant doit fournir des tableaux de cette taille.
font_set
Spécifie l'ensemble de polices.
ink_array_return
Retourne les dimensions d'encre pour chaque caractère.
logical_array_return
Retourne les dimensions logiques pour chaque caractère.
num_bytes
Spécifie le nombre d'octets dans l'argument string.
num_chars_return
Retourne le nombre de caractères dans l'argument string.
num_wchars
Spécifie le nombre de caractères dans l'argument string.
overall_ink_return
Retourne les dimensions d'encre globales de toute la chaîne.
overall_logical_return
Retourne les dimensions logiques globales de toute la chaîne.
string
Spécifie la chaîne de caractères.

DESCRIPTION

Les fonctions XmbTextPerCharExtents, XwcTextPerCharExtents et Xutf8TextPerCharExtents retournent les dimensions de texte de chaque caractère du texte spécifié, en utilisant les polices chargées pour l'ensemble de polices spécifié. Chaque élément successif de ink_array_return et logical_array_return est défini avec les métriques dessinées du caractère successif, par rapport à l'origine du dessin de la chaîne et un rectangle pour chaque caractère dans la chaîne de texte fournie. Le nombre d'éléments de ink_array_return et logical_array_return qui ont été définis est retourné à num_chars_return.

Chaque élément de ink_array_return est défini avec la boîte englobante de la couleur de premier plan dessinée du caractère correspondant. Chaque élément de logical_array_return est défini avec la boîte englobante qui fournit un espacement minimum avec d'autres caractéristiques graphiques pour le caractère correspondant. D'autres caractéristiques graphiques ne doivent pas intersecter les rectangles de logical_array_return.

Notez qu'un XRectangle représente les dimensions de dessin effectives du caractère, quel que soit le nombre de glyphes de police utilisés pour dessiner le caractère ou la direction dans laquelle le caractère est dessiné. Si plusieurs caractères correspondent à un seul glyphe de caractère, les dimensions de tous les XRectangles de ces caractères sont les mêmes.

Lorsque le XFontSet a des jeux de caractères manquants, les métriques de chaque caractère indisponible sont prises de la chaîne par défaut retournée par XCreateFontSet afin que les métriques représentent le texte tel qu'il sera réellement dessiné. Le comportement pour un point de code invalide n'est pas défini.

Si array_size est trop petit pour le nombre de caractères dans le texte fourni, les fonctions retournent zéro et num_chars_return est défini avec le nombre de rectangles requis. Sinon, les fonctions retournent une valeur non nulle.

Si l'argument overall_ink_return ou overall_logical_return est non NULL, XmbTextPerCharExtents, XwcTextPerCharExtents et Xutf8TextPerCharExtents retournent l'étendue maximale des métriques de la chaîne à overall_ink_return ou overall_logical_return, tels que retournés par XmbTextExtents, XwcTextExtents ou Xutf8TextExtents.

La fonction Xutf8TextPerCharExtents est une extension introduite par The XFree86 Project, Inc., dans sa version 4.0.2. Sa présence est indiquée par le macro X_HAVE_UTF8_STRING.
