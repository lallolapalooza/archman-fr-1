NOM

XmObjectAtPoint — Fonction de toolkit qui détermine quel enfant intersecte ou est le plus proche d'un point spécifié

SYNTAXE

#include <Xm/Xm.h>
Widget XmObjectAtPoint(
Widget widget,
Position x,
Position y);

DESCRIPTION

XmObjectAtPoint parcourt la liste des enfants du widget gestionnaire spécifié et retourne l'enfant le plus étroitement associé à la paire de coordonnées x,y spécifiée.

Pour le widget gestionnaire Motif typique, XmObjectAtPoint utilise les règles suivantes pour déterminer l'objet retourné :

•
Si un enfant intersecte x,y, XmObjectAtPoint retourne l'identifiant du widget de cet enfant.
•
Si plusieurs enfants intersectent x,y, XmObjectAtPoint retourne l'identifiant du widget de l'enfant visible.
•
Si aucun enfant n'intersecte x,y, XmObjectAtPoint retourne NULL.

Les règles précédentes sont générales. En fait, chaque widget gestionnaire est libre de définir « le plus étroitement associé » comme il le souhaite. Par exemple, si aucun enfant n'intersecte x,y, un gestionnaire pourrait retourner l'enfant le plus proche de x,y.

widget
Spécifie un widget gestionnaire.
x
Spécifie la coordonnée x pour laquelle vous recherchez des informations sur les enfants. La coordonnée x doit être spécifiée en pixels, par rapport au côté gauche du gestionnaire.
y
Spécifie la coordonnée y pour laquelle vous recherchez des informations sur les enfants. La coordonnée y doit être spécifiée en pixels, par rapport au haut du gestionnaire.

RETOUR

Retourne l'enfant du gestionnaire le plus étroitement associé à x,y. Si aucun de ses enfants n'est suffisamment associé à x,y, retourne NULL.
