DESCRIPTION

La bibliothèque d'interface de programmation pour l'extension X11 Double-Buffering, Multi-Buffering, and Stereo Extension contient les interfaces décrites ci-dessous. À l'exception de XmbufQueryExtension, si l'une de ces routines est appelée avec un affichage qui ne prend pas en charge l'extension, le gestionnaire d'erreurs d'extension (qui peut être défini avec XSetExtensionErrorHandler et fonctionne de la même manière que XSetErrorHandler) sera appelé et la fonction retournera alors.

XmbufQueryExtension renvoie True si l'extension multibuffering/stéréo est disponible sur l'affichage donné. Si l'extension existe, la valeur du premier code d'événement (qui doit être ajoutée aux constantes de type d'événement MultibufferClobberNotify et MultibufferUpdateNotify pour obtenir les valeurs réelles) est stockée dans event_base_return et la valeur du premier code d'erreur (qui doit être ajoutée à la constante de type d'erreur MultibufferBadBuffer pour obtenir la valeur réelle) est stockée dans error_base_return.

XmbufGetVersion obtient les numéros de version majeure et mineure de l'extension. La valeur de retour est zéro en cas d'erreur ou non zéro s'il n'y a pas d'erreur.

XmbufCreateBuffers demande la création de "count" tampons avec l'action de mise à jour et l'indicateur de mise à jour donnés et leur association à la fenêtre indiquée. Le nombre de tampons créés est renvoyé (zéro en cas d'erreur) et buffers_update est rempli avec ce nombre d'identifiants Multibuffer.

XmbufDestroyBuffers détruit les tampons associés à la fenêtre donnée.

XmbufDisplayBuffers affiche les tampons indiqués dans leurs fenêtres appropriées dans un délai maximum de max_delay millisecondes après que min_delay millisecondes se soient écoulées. Deux tampons ne peuvent pas être associés à la même fenêtre, sinon une erreur Match est générée.

XmbufGetWindowAttributes obtient les attributs de multibuffering qui s'appliquent à tous les tampons associés à la fenêtre donnée. La liste des tampons renvoyée peut être libérée avec XFree. Renvoie une valeur non nulle en cas de succès et zéro en cas d'erreur.

XmbufChangeWindowAttributes définit les attributs de multibuffering qui s'appliquent à tous les tampons associés à la fenêtre donnée. Ceci est actuellement limité à l'indicateur de mise à jour.

XmbufGetBufferAttributes obtient les attributs du tampon indiqué. Renvoie une valeur non nulle en cas de succès et zéro en cas d'erreur.

XmbufChangeBufferAttributes définit les attributs du tampon indiqué. Ceci est actuellement limité au masque d'événements.

XmbufGetScreenInfo obtient les paramètres contrôlant la manière dont les fenêtres mono et stéréo peuvent être créées sur l'écran du dessinable donné. Le nombre d'ensembles de visuels et de profondeurs est renvoyé dans nmono_return et nstereo_return. Si nmono_return est supérieur à zéro, alors mono_info_return est défini à l'adresse d'un tableau de structures XmbufBufferInfo décrivant les différents visuels et profondeurs qui peuvent être utilisés. Sinon, mono_info_return est défini à NULL. De même, stereo_info_return est défini en fonction de nstereo_return. Le stockage renvoyé dans mono_info_return et stereo_info_return peut être libéré par XFree. Si aucune erreur n'est rencontrée, une valeur non nulle sera renvoyée.

XmbufCreateStereoWindow crée une fenêtre stéréo de la même manière que XCreateWindow crée une fenêtre mono. Les identifiants de tampon pour les tampons gauche et droit sont renvoyés respectivement dans left_return et right_return. Si un gestionnaire d'erreurs d'extension qui retourne est installé, None sera renvoyé si l'extension n'est pas disponible sur cet affichage.

NAME

XmbufGetVersion - get version of the multi-buffering extension

SYNTAX

#include <X11/extensions/xf86vmode.h>
#include <X11/extensions/XInput.h>
#include <X11/extensions/XInput2.h>
#include <X11/extensions/Xge.h>
#include <X11/extensions/Xmu.h>
#include <X11/extensions/Xrender.h>
#include <X11/extensions/XShm.h>
#include <X11/extensions/Xv.h>
#include <X11/extensions/Xvlib.h>

Bool XmbufGetVersion(Display *display, int *major_version_return,
                      int *minor_version_return);

STRUCTURES

The multi-buffering extension does not define any structures.

DESCRIPTION

The XmbufGetVersion function retrieves the version of the multi-buffering extension. This function should be called after the extension has been initialized.

The major_version_return and minor_version_return parameters are pointers to integers where the major and minor version numbers will be stored, respectively.

If the multi-buffering extension is not available on the server, the function returns False. Otherwise, it returns True.

PREDEFINED VALUES

None.

MultibufferUpdateNotify
MultibufferNumberEvents
MultibufferBadBuffer
