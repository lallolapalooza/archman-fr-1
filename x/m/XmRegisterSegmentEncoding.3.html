NOM

XmRegisterSegmentEncoding — Une fonction de chaîne composée qui enregistre un format d'encodage de texte composé pour une balise d'élément de liste de polices spécifiée

SYNTAXE

#include <Xm/Xm.h>
char * XmRegisterSegmentEncoding(
char *fontlist_tag,
char *ct_encoding);

DESCRIPTION

XmRegisterSegmentEncoding enregistre un format d'encodage de texte composé avec la balise d'élément de liste de polices spécifiée. La fonction XmCvtXmStringToCT utilise ce registre pour mapper les balises de liste de polices des segments de chaînes composées aux formats d'encodage de texte composé. L'enregistrement d'une balise de liste de polices qui existe déjà dans le registre écrase l'entrée d'origine. Vous pouvez désenregistrer une balise de liste de polices en passant une valeur NULL pour le paramètre ct_encoding.

fontlist_tag
Spécifie la balise d'élément de liste de polices à enregistrer. La balise doit être une chaîne ISO8859-1 terminée par NULL.
ct_encoding
Spécifie l'ensemble de caractères de texte composé à utiliser pour les segments avec la balise de liste de polices. La valeur doit être une chaîne ISO8859-1 terminée par NULL. Une valeur de XmFONTLIST_DEFAULT_TAG mappe la balise de liste de polices spécifiée au jeu de codes de la locale.

RETOUR

Retourne NULL pour une nouvelle balise de liste de polices ou l'ancienne valeur de ct_encoding pour une balise de liste de polices déjà enregistrée. L'application est responsable de libérer la mémoire associée aux données retournées (le cas échéant) en appelant XtFree.

LIRE AUSSI

XmCvtXmStringToCT(3), XmFontList(3), XmMapSegmentEncoding(3), et XmString(3).
