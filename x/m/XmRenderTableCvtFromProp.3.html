NOM

XmRenderTableCvtFromProp — Une fonction de table de rendu qui convertit une représentation sous forme de chaîne en table de rendu

SYNTAXE

#include <Xm/Xm.h>
XmRenderTable XmRenderTableCvtFromProp(
Widget widget,
char *property,
unsigned int length);

DESCRIPTION

XmRenderTableCvtFromProp convertit une chaîne de caractères représentant une table de rendu en une table de rendu. Cette routine est généralement utilisée par la destination d'une opération de transfert de données pour produire une table de rendu à partir d'une représentation transférée.

widget
Spécifie le widget qui est la destination de la table de rendu
property
Spécifie une chaîne de caractères représentant une table de rendu
length
Spécifie le nombre d'octets dans property

RETOUR

Renvoie une table de rendu. La fonction alloue de l'espace pour contenir la table de rendu renvoyée. L'application est responsable de la gestion de cet espace alloué. L'application peut récupérer cet espace alloué en appelant XmRenderTableFree.

VOIR AUSSI

XmRenderTable(3), XmRenderTableCvtToProp(3), et XmRenderTableFree(3).
