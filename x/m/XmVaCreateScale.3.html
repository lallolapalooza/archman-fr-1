NOM

XmVaCreateScale, XmVaCreateManagedScale — Fonctions de création pratiques pour un widget Scale.

SYNTAXE

#include <Xm/Scale.h>
Widget XmVaCreateScale(
Widget parent,
String name,
...);
Widget XmVaCreateManagedScale(
Widget parent,
String name,
...);

DESCRIPTION

Ces fonctions créent une instance d'un widget ToggleButtonGadget et retournent l'identifiant du widget associé. Ces routines utilisent la convention d'appel de liste d'arguments de longueur variable (varargs) ANSI C.

La fonction XmVaCreateScale est une routine pratique qui appelle XtCreateWidget.

La fonction XmVaCreateScale est une routine pratique qui appelle XtCreateManagedWidget.

parent
Spécifie l'identifiant du widget parent.
name
Spécifie le nom du widget créé.
...
Spécifie la liste d'arguments variables pour remplacer les valeurs par défaut des ressources.

Pour une définition complète de Scale et de ses ressources associées, voir XmScale(3).

VALEUR

Retourne l'identifiant du widget Scale.

LIENS UTRALS

XmScale(3), XmCreateScale(3), XtCreateWidget(3), et XtCreateManagedWidget(3).
