NOM

XmCommandSetValue — Une fonction de Commande qui remplace une chaîne affichée

SYNTAXE

#include <Xm/Command.h>
void XmCommandSetValue(
Widget widget,
XmString command);

DESCRIPTION

XmCommandSetValue remplace la chaîne affichée dans la zone de commande du widget Commande par le XmString passé.

widget
Spécifie l'ID du widget Commande.
command
Spécifie le XmString passé.

Pour une définition complète de Commande et de ses ressources associées, voir XmCommand(3).

LIÉ

XmCommand(3).
