NOM

XML::Parser::PerlSAX - Analyseur SAX Perl utilisant XML::Parser

SYNOPSIS

use XML::Parser::PerlSAX;
$parser = XML::Parser::PerlSAX->new( [OPTIONS] );
$result = $parser->parse( [OPTIONS] );
$result = $parser->parse($string);

DESCRIPTION

"XML::Parser::PerlSAX" est un analyseur PerlSAX utilisant le module XML::Parser. Cette page man décrit les options, gestionnaires et propriétés spécifiques pris en charge par "XML::Parser::PerlSAX" ; veuillez vous référer à la norme PerlSAX dans `"PerlSAX.pod"' pour des informations générales d'utilisation.

MÉTHODES

new
Crée un nouvel objet analyseur. Les options par défaut pour l'analyse, décrites ci-dessous, sont passées sous forme de paires clé-valeur ou d'une seule table de hachage. Les options peuvent être modifiées directement dans l'objet analyseur sauf indication contraire. Les options passées à `parse()' remplacent les options par défaut de l'objet analyseur pour la durée de l'analyse.
parse
Analyse un document. Les options, décrites ci-dessous, sont passées sous forme de paires clé-valeur ou d'une seule table de hachage. Les options passées à `parse()' remplacent les options par défaut de l'objet analyseur.
location
Retourne l'emplacement sous forme de table de hachage : 
ColumnNumber    Le numéro de colonne de l'analyse.
LineNumber      Le numéro de ligne de l'analyse.
BytePosition    La position actuelle en octets de l'analyse.
PublicId        Une chaîne contenant l'identifiant public, ou undef
                si aucun n'est disponible.
SystemId        Une chaîne contenant l'identifiant système, ou undef
                si aucun n'est disponible.
Base            La valeur actuelle de la base pour la résolution des URI
                relatifs.

AVERTISSEMENT ALPHA : Les propriétés `"SystemId"' et `"PublicId"' retournées sont les identifiants système et publics du document passé à `parse()', et non les identifiants de l'entité externe actuellement analysée. Les positions en colonne, ligne et octet correspondent bien à l'entité actuellement analysée.

OPTIONS

Les options suivantes sont prises en charge par "XML::Parser::PerlSAX" :

Handler          Gestionnaire par défaut pour recevoir les événements
DocumentHandler  Gestionnaire pour recevoir les événements de document
DTDHandler       Gestionnaire pour recevoir les événements DTD
ErrorHandler     Gestionnaire pour recevoir les événements d'erreur
EntityResolver   Gestionnaire pour résoudre les entités
Locale           Locale pour fournir une localisation pour les erreurs
Source           Table de hachage contenant la source d'entrée pour l'analyse
UseAttributeOrder défini à true pour fournir les propriétés AttributeOrder et Defaulted
                  dans `start_element()'

Si aucun gestionnaire n'est fourni, tous les événements seront silencieusement ignorés, sauf pour `fatal_error()' qui provoquera un `die()' après avoir appelé `end_document()'.

Si un seul argument de type chaîne est passé à la méthode `parse()', il est traité comme si une option `"Source"' avait été donnée avec un paramètre `"String"'.

La table de hachage `"Source"' peut contenir les paramètres suivants :

ByteStream       Le flux brut d'octets (descripteur de fichier) contenant le
                 document.
String           Une chaîne contenant le document.
SystemId         L'identifiant système (URI) du document.
PublicId         L'identifiant public.
Encoding         Une chaîne décrivant l'encodage des caractères.

Si plusieurs parmi `"ByteStream"', `"String"', ou `"SystemId"' sont présents, la préférence est donnée d'abord à `"ByteStream"', puis à `"String"', puis à `"SystemId"'.

GESTIONNAIRES

Les gestionnaires et propriétés suivants sont pris en charge par "XML::Parser::PerlSAX" :

DocumentHandler méthodes

start_document
Reçoit une notification du début d'un document.

Aucune propriété définie.

end_document
Reçoit une notification de la fin d'un document.

Aucune propriété définie.

start_element
Reçoit une notification du début d'un élément. 
Name             Le nom du type d'élément.
Attributes       Une table de hachage contenant les attributs attachés à
                 l'élément, le cas échéant.

La table de hachage `"Attributes"' ne contient que des valeurs de chaînes.

Si l'option de l'analyseur `"UseAttributeOrder"' est vraie, les propriétés suivantes sont également passées à `"start_element"' :

AttributeOrder   Un tableau des noms d'attributs dans l'ordre où ils ont été
                 spécifiés, suivi des noms d'attributs par défaut.
Defaulted        L'indice du premier attribut par défaut dans
                 `AttributeOrder'. Si cet indice est égal à la longueur
                 de `AttributeOrder', il n'y avait pas de valeurs par
                 défaut.

Note aux utilisateurs de "XML::Parser" : `"Defaulted"' sera la moitié de la valeur de la fonction `specified_attr()' de "XML::Parser::Expat" car seuls les noms d'attributs sont fournis, pas leurs valeurs.

end_element
Reçoit une notification de la fin d'un élément. 
Name             Le nom du type d'élément.
characters
Reçoit une notification de données de caractères. 
Data             Les caractères du document XML.
processing_instruction
Reçoit une notification d'une instruction de traitement. 
Target           La cible de l'instruction de traitement.
Data             Les données de l'instruction de traitement, le cas échéant.
comment
Reçoit une notification d'un commentaire. 
Data             Les données du commentaire, le cas échéant.
start_cdata
Reçoit une notification du début d'une section CDATA.

Aucune propriété définie.

end_cdata
Reçoit une notification de la fin d'une section CDATA.

Aucune propriété définie.

entity_reference
Reçoit une notification d'une référence d'entité interne. Si ce gestionnaire est défini, les entités internes ne seront pas développées et ne seront pas passées au gestionnaire `characters()'. Si ce gestionnaire n'est pas défini, les entités internes seront développées si possible et passées au gestionnaire `characters()'. 
Name             Le nom de la référence d'entité
Value            La valeur de la référence d'entité

DTDHandler méthodes

notation_decl
Reçoit une notification d'un événement de déclaration de notation. 
Name             Le nom de la notation.
PublicId         L'identifiant public de la notation, le cas échéant.
SystemId         L'identifiant système de la notation, le cas échéant.
Base             La base pour résoudre un URI relatif, le cas échéant.
unparsed_entity_decl
Reçoit une notification d'une déclaration d'entité non analysée. 
Name             Le nom de l'entité.
PublicId         L'identifiant public de l'entité, le cas échéant.
SystemId         L'identifiant système de l'entité, le cas échéant.
NDData           Le nom de la notation pour l'entité non analysée.
Base             La base pour résoudre un URI relatif, le cas échéant.

ErrorHandler méthodes

warning
Reçoit une notification d'un avertissement. 
Message          Le message d'avertissement.
error
Reçoit une notification d'une erreur. 
Message          Le message d'erreur.
fatal_error
Reçoit une notification d'une erreur fatale. 
Message          Le message d'erreur fatale.

EntityResolver méthodes

resolve_entity
Permet à l'utilisateur de résoudre les entités externes. 
PublicId         L'identifiant public de l'entité.
SystemId         L'identifiant système de l'entité.

Doit retourner une table de hachage contenant les paramètres de la source d'entrée ("String", "ByteStream", "SystemId", "PublicId", "Encoding"), ou `undef' si l'entité ne peut pas être résolue.

Nom             Le nom de l'entité non analysée.

entity_decl
Recevoir une notification d'un événement de déclaration d'entité. 
Nom             Le nom de l'entité.
Valeur           La valeur de l'entité, le cas échéant.
PublicId         L'identifiant public de la notation, le cas échéant.
SystemId         L'identifiant système de la notation, le cas échéant.
Notation         La notation déclarée pour cette entité, le cas échéant.

Pour les entités internes, le paramètre `"Valeur"' contiendra la valeur et les paramètres `"PublicId"', `"SystemId"' et `"Notation"' seront indéfinis. Pour les entités externes, le paramètre `"Valeur"' sera indéfini, le paramètre `"SystemId"' contera l'identifiant système, le paramètre `"PublicId"' contera l'identifiant public s'il a été fourni (il sera indéfini sinon), le paramètre `"Notation"' contiendra le nom de la notation pour les entités non analysées. S'il s'agit d'une déclaration d'entité paramétrique, alors un '%' sera préfixé au nom de l'entité.

Notez que `entity_decl()' et `unparsed_entity_decl()' se chevauchent. Si les deux méthodes sont implémentées par un gestionnaire, alors ce gestionnaire ne sera pas appelé pour les entités non analysées.

element_decl
Recevoir une notification d'un événement de déclaration d'élément. 
Nom             Le nom du type d'élément.
Modèle           Le modèle de contenu sous forme de chaîne.
attlist_decl
Recevoir une notification d'un événement de déclaration de liste d'attributs.

Ce gestionnaire est appelé pour chaque attribut dans une déclaration ATTLIST trouvée dans le sous-ensemble interne. Ainsi, une déclaration ATTLIST ayant plusieurs attributs générera plusieurs appels à ce gestionnaire.

NomElement      Le nom du type d'élément.
NomAttribut     Le nom de l'attribut.
Type             Le type de l'attribut.
Fixe             Vrai si c'est un attribut fixe.

La valeur par défaut pour `"Type"' est la valeur par défaut, qui sera soit "#REQUIRED", "#IMPLIED", soit une chaîne entre guillemets (c'est-à-dire que la chaîne renvoyée commencera et se terminera par un caractère guillemet).

doctype_decl
Recevoir une notification d'un événement de déclaration DOCTYPE. 
Nom             Le nom du type de document.
SystemId         L'identifiant système du document.
PublicId         L'identifiant public du document, le cas échéant.
Interne          Le sous-ensemble interne sous forme de chaîne, le cas échéant.

`Interne` contiendra tous les espaces blancs, commentaires, instructions de traitement et déclarations vus dans le sous-ensemble interne. Les déclarations seront présentes, qu'elles aient été traitées ou non par un autre gestionnaire (sauf les entités non analysées traitées par le gestionnaire `Unparsed`). Cependant, les commentaires et instructions de traitement n'apparaîtront pas s'ils ont été traités par leurs gestionnaires respectifs.

xml_decl
Recevoir une notification d'un événement de déclaration XML. 
Version          La version.
Encodage         La chaîne d'encodage, le cas échéant.
Indépendant      Vrai, faux, ou indéfini si non déclaré.

EntityResolver

resolve_entity
Permettre au gestionnaire de résoudre les entités externes. 
Nom             Le nom de la notation.
SystemId         L'identifiant système de la notation.
PublicId         L'identifiant public de la notation, le cas échéant.
Base             La base pour résoudre une URI relative, le cas échéant.

`resolve_entity()' doit renvoyer `undef` pour demander à l'analyseur d'ouvrir une connexion URI normale à l'identifiant système ou un hachage décrivant la nouvelle source d'entrée. Ce hachage a les mêmes propriétés que le paramètre `"Source"' de `parse()':

PublicId    L'identifiant public de l'entité externe référencée,
            ou undef si aucun n'a été fourni. 
SystemId    L'identifiant système de l'entité externe référencée.
Chaîne      Chaîne contenant du texte XML
FluxOctets  Un descripteur de fichier ouvert.
FluxCaract  Un descripteur de fichier ouvert.
Encodage    L'encodage des caractères, si connu.
