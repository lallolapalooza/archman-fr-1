NOM

XML::LibXML::Comment - Classe Commentaire XML::LibXML

SYNOPSIS

use XML::LibXML;
# Seules les méthodes spécifiques aux nœuds Comment sont listées ici,
# voir la page man XML::LibXML::Node pour les autres méthodes
$noeud = XML::LibXML::Comment->new( $contenu );

DESCRIPTION

Cette classe fournit toutes les fonctions de XML::LibXML::Text, mais pour les nœuds de commentaire. Cela est possible car seule la sortie des types de nœuds diffère, mais pas la structure des données. :-)

MÉTHODES

La classe hérite de XML::LibXML::Node. La documentation des méthodes héritées n'est pas répertoriée ici.

De nombreuses fonctions listées ici sont largement documentées dans la spécification DOM Level 3 (http://www.w3.org/TR/DOM-Level-3-Core/). Veuillez vous référer à la spécification pour une documentation détaillée.

new
$noeud = XML::LibXML::Comment->new( $contenu );

Le constructeur est la seule fonction fournie pour ce paquet. Il est requis car libxml2 traite les nœuds texte et les nœuds commentaire de manière légèrement différente.
