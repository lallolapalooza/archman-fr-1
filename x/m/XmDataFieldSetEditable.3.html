NOM

XmDataFieldSetEditable — Fonction DataField qui définit la permission d'édition

SYNTAXE

#include <Xm/DataF.h>
void XmDataFieldSetEditable(
Widget widget,
Boolean editable);

DESCRIPTION

XmDataFieldSetEditable définit l'état de permission d'édition du widget DataField. Lorsqu'il est défini sur True, la chaîne de caractères textuels peut être éditée.

widget
Spécifie l'identifiant du widget DataField.
editable
Spécifie une valeur booléenne qui, lorsqu'elle est True, autorise les modifications de la chaîne de caractères textuels.

Pour une définition complète de DataField et de ses ressources associées, voir XmDataField(3).
