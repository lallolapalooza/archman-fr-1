NOM

XmDataFieldSetAddMode — Une fonction DataField qui définit l'état du mode d'ajout

SYNTAXE

#include <Xm/DataF.h>
void XmDataFieldSetAddMode(
Widget widget,
Boolean state);

DESCRIPTION

XmDataFieldSetAddMode contrôle si le widget DataField est en mode d'ajout ou non. Lorsque le widget est en mode d'ajout, le curseur d'insertion peut être déplacé sans perturber la sélection primaire.

widget
Spécifie l'identifiant du widget DataField.
state
Spécifie si le widget est en mode d'ajout ou non. Une valeur True active le mode d'ajout ; une valeur False désactive le mode d'ajout.

Pour une définition complète de DataField et de ses ressources associées, voir XmDataField(3).

VOIR AUSSI

XmDataField(3).
