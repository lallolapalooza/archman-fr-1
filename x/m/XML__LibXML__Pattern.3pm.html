NOM

XML::LibXML::Pattern - Interface pour les motifs XPath de XML::LibXML

SYNTAXE

use XML::LibXML;
my $pattern = XML::LibXML::Pattern->new('/x:html/x:body//x:div', { 'x' => 'http://www.w3.org/1999/xhtml' });
# tester une correspondance sur un nœud XML::LibXML::Node $node
if ($pattern->matchesNode($node)) { ... }
# ou sur un XML::LibXML::Reader
if ($reader->matchesPattern($pattern)) { ... }
# ou ignorer la lecture de tous les nœuds ne correspondant pas
print $reader->nodePath while $reader->nextPatternMatch($pattern);
$pattern = XML::LibXML::Pattern->new( motif, { préfixe => uri_espace_nom, ... } );
$bool = $pattern->matchesNode($node);

DESCRIPTION

Ceci est une interface Perl pour le support de correspondance de motifs de libxml2 http://xmlsoft.org/html/libxml-pattern.html. Cette fonctionnalité nécessite des versions récentes de libxml2.

Les motifs sont un petit sous-ensemble du langage XPath, limité à (disjonctions de) chemins de localisation impliquant les axes enfant et descendant sous forme abrégée, comme décrit par la BNF étendue ci-dessous :

Selector ::=     Path ( '|' Path )*
Path     ::=     ('.//' | '//' | '/' )? Step ( '/' Step )*
Step     ::=     '.' | NameTest
NameTest ::=     QName | '*' | NCName ':' '*'

Pour la lisibilité, les espaces blancs peuvent être utilisés dans les expressions XPath de motif, même s'ils ne sont pas explicitement autorisés par la grammaire : les espaces blancs peuvent être ajoutés librement dans les motifs avant ou après n'importe quel jeton, où

token     ::=     '.' | '/' | '//' | '|' | NameTest

Notez qu'aucun prédicat ni test d'attribut n'est autorisé.

Les motifs sont particulièrement utiles pour l'analyse en flux fournie par l'interface "XML::LibXML::Reader".

new()
$pattern = XML::LibXML::Pattern->new( motif, { préfixe => uri_espace_nom, ... } );

Le constructeur d'un motif prend une expression de motif (telle que décrite par la grammaire BNF ci-dessus) et une référence HASH optionnelle mappant des préfixes à des URI d'espaces de noms. La méthode renvoie un objet motif compilé.

Notez que si le document a un espace de noms par défaut, il doit toujours se voir attribuer un préfixe pour être reconnu (conformément à la spécification XPath 1.0). Par exemple, pour reconnaître un élément "<a xmlns="http://foo.bar"</a>", il faut utiliser un motif comme celui-ci :

$pattern = XML::LibXML::Pattern->new( 'foo:a', { foo => 'http://foo.bar' });
matchesNode($node)
$bool = $pattern->matchesNode($node);

Étant donné un objet XML::LibXML::Node, renvoie une valeur vraie si le nœud correspond à l'expression de motif compilée.

VOIR AUSSI

XML::LibXML::Reader pour d'autres méthodes impliquant des motifs compilés.
