NOM

XmToggleButtonSetState — Une fonction ToggleButton qui définit ou modifie l'état actuel.

SYNTAXE

#include <Xm/ToggleB.h>
void XmToggleButtonSetState(
Widget widget,
Boolean state,
Boolean notify);

DESCRIPTION

XmToggleButtonSetState définit ou modifie l'état actuel du ToggleButton.

widget
Spécifie l'identifiant du widget ToggleButton.
state
Spécifie une valeur booléenne indiquant si l'état du ToggleButton est sélectionné ou non sélectionné. Si la valeur est Vrai, l'état du bouton est sélectionné ; si elle est Faux, l'état du bouton n'est pas sélectionné.
notify
Indique si XmNvalueChangedCallback est appelé ; il peut être Vrai ou Faux. Le XmNvalueChangedCallback n'est appelé que lorsque cette fonction modifie l'état du ToggleButton. Lorsque cet argument est Vrai et que le ToggleButton est un enfant d'un widget RowColumn dont XmNradioBehavior est Vrai, la définition du ToggleButton entraîne la désélection des autres enfants ToggleButton et ToggleButtonGadget du RowColumn.

Pour une définition complète de ToggleButton et de ses ressources associées, voir XmToggleButton(3).
