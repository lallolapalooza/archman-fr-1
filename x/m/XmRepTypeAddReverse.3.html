NOM

XmRepTypeAddReverse — Fonction de gestion de type de représentation qui installe le convertisseur inverse pour un type de représentation précédemment enregistré

SYNOPSIS

#include <Xm/RepType.h>
void XmRepTypeAddReverse(
XmRepTypeId rep_type_id);

DESCRIPTION

XmRepTypeAddReverse installe le convertisseur inverse pour un type de représentation précédemment enregistré. Le convertisseur inverse prend une valeur numérique de type de représentation et renvoie sa valeur textuelle correspondante. Certaines applications peuvent nécessiter cette capacité pour obtenir une valeur textuelle à afficher à l'écran ou pour construire un fichier de ressources.

L'argument values de la fonction XmRepTypeRegister peut être utilisé pour enregistrer des types de représentation avec des valeurs non consécutives ou avec des noms dupliqués pour la même valeur. Si la liste des valeurs numériques pour un type de représentation contient des valeurs dupliquées, le convertisseur inverse utilise le premier nom dans la liste value_names qui correspond à la valeur numérique spécifiée. Par exemple, si un tableau value_names contient cancel, proceed, et abort, et que le tableau values correspondant contient 0, 1, et 0, le convertisseur inverse renverra cancel au lieu de abort pour une valeur d'entrée de 0.

rep_type_id
Spécifie le numéro d'identification du type de représentation

VOIR AUSSI

XmRepTypeGetId(3) et XmRepTypeRegister(3).
