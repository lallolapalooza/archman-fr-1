NOM

XmCreateOptionMenu — Fonction utilitaire de création de widget RowColumn

SYNTAXE

#include <Xm/RowColumn.h>
Widget XmCreateOptionMenu(
Widget parent,
String name,
ArgList arglist,
Cardinal argcount);

DESCRIPTION

XmCreateOptionMenu crée une instance d'un widget RowColumn de type XmMENU_OPTION et retourne l'identifiant de widget associé.

Elle est fournie comme fonction utilitaire pour la création d'un widget RowColumn configuré pour fonctionner comme un OptionMenu et n'est pas implémentée comme une classe de widget distincte.

Le widget OptionMenu est un RowColumn spécialisé composé d'une étiquette, d'une zone de sélection et d'un seul panneau de menu déroulant. Lorsqu'une application crée un widget OptionMenu, elle fournit la chaîne de l'étiquette et le panneau de menu déroulant. Pour que l'opération réussisse, une ressource XmNsubMenuId valide doit être définie lorsque cette fonction est appelée. Le LabelGadget et la zone de sélection (un CascadeButtonGadget) sont créés par l'OptionMenu.

Le panneau de menu déroulant de l'OptionMenu ne doit pas contenir de ToggleButtons ou de ToggleButtonGadgets. Les résultats de l'inclusion de CascadeButtons ou de CascadeButtonGadgets dans le panneau de menu déroulant de l'OptionMenu sont indéfinis.

Un OptionMenu est disposé avec l'étiquette affichée d'un côté du widget et la zone de sélection de l'autre côté lorsque XmNorientation est XmHORIZONTAL. La disposition de l'étiquette par rapport à la zone de sélection dépend de la ressource XmNlayoutDirection dans l'orientation horizontale. Si la valeur est XmVERTICAL, l'étiquette est au-dessus de la zone de sélection. La zone de sélection a un double objectif ; elle affiche l'étiquette du dernier élément sélectionné dans le panneau de menu déroulant associé, et elle fournit le moyen de déclencher le panneau de menu déroulant.

L'OptionMenu n'affiche généralement pas de visuels 3D autour de lui-même ou du LabelGadget interne. Par défaut, le CascadeButtonGadget interne a une ombre 3D visible. L'application peut modifier cela en obtenant l'identifiant du CascadeButtonGadget à l'aide de XmOptionButtonGadget, puis en appelant XtSetValues à l'aide des ressources standard liées à la visualisation.

Le panneau de menu déroulant est déclenché lorsque le pointeur de la souris est déplacé sur la zone de sélection et qu'un bouton de la souris défini par le parent RowColumn de l'OptionMenu est enfoncé. Le panneau de menu déroulant est déclenché et positionné de sorte que le dernier élément sélectionné soit directement au-dessus de la zone de sélection. La souris est ensuite utilisée pour armer l'élément de menu souhaité. Lorsque le bouton de la souris est relâché, l'élément de menu armé est sélectionné et l'étiquette dans la zone de sélection est modifiée pour correspondre à celle de l'élément sélectionné. Par défaut, BSelect est utilisé pour interagir avec un OptionMenu. La valeur par défaut peut être modifiée avec la ressource RowColumn XmNmenuPost.

L'OptionMenu fonctionne également avec le mécanisme de l'interface clavier. Si l'application a établi un raccourci mnémonique avec l'OptionMenu, l'appui sur <Alt> avec le mnémonique déclenche le panneau de menu déroulant avec le parcours activé. Les touches de parcours standard peuvent alors être utilisées pour se déplacer dans le panneau de menu. L'appui sur <Return> ou la saisie d'un mnémonique ou d'un accélérateur pour l'un des éléments de menu sélectionne cet élément.

Une application peut utiliser la ressource XmNmenuHistory pour indiquer quel élément du panneau de menu déroulant doit être traité comme le choix actuel et dont l'étiquette doit être affichée dans la zone de sélection. Par défaut, le premier élément sélectionnable du panneau de menu déroulant est utilisé.

parent
Spécifie l'identifiant du widget parent.
name
Spécifie le nom du widget créé.
arglist
Spécifie la liste des arguments.
argcount
Spécifie le nombre de paires attribut/valeur dans la liste des arguments (arglist).

L'utilisateur peut spécifier des ressources dans un fichier de ressources pour les widgets et gadgets automatiquement créés d'un OptionMenu. Ces widgets (ou gadgets) et les zones associées de l'OptionMenu sont :

Étiquette du menu optionnel Gadget
OptionLabel
Bouton cascade du menu optionnel
OptionButton

Pour une définition complète de RowColumn et de ses ressources associées, voir XmRowColumn(3).

RETOUR

Retourne l'identifiant du widget RowColumn.
