XML::Atom::Feed(3pm) Documentation Perl fournie par l'utilisateur XML::Atom::Feed(3pm)

NOM

XML::Atom::Feed - flux Atom

SYNOPSIS

use XML::Atom::Feed;
use XML::Atom::Entry;
my $feed = XML::Atom::Feed->new;
$feed->title('Mon blog');
$feed->id('tag:example.com,2006:feed-id');
my $entry = XML::Atom::Entry->new;
$entry->title('Premier article');
$entry->id('tag:example.com,2006:entry-id');
$entry->content('Corps de l\'article');
$feed->add_entry($entry);
$feed->add_entry($entry, { mode => 'insert' });
my @entries = $feed->entries;
my $xml = $feed->as_xml;
## Obtenir une liste des balises <link rel="..." /> dans le flux.
my $links = $feed->link;
## Trouver tous les flux Atom sur une page donnée, en utilisant l'auto-découverte.
my @uris = XML::Atom::Feed->find_feeds('http://www.example.com/');
## Utiliser l'auto-découverte pour charger le premier flux Atom sur une page donnée.
my $feed = XML::Atom::Feed->new(URI->new('http://www.example.com/'));

UTILISATION

XML::Atom::Feed->new([ $stream ])

Crée un nouvel objet flux et, si $stream est fourni, le remplit avec les données spécifiées par $stream.

Gère automatiquement l'auto-découverte si $stream est une URI (voir ci-dessous).

Retourne le nouvel objet XML::Atom::Feed. En cas d'échec, retourne "undef".

$stream peut être l'un des éléments suivants :

  • Référence à un scalaire

    Ceci est traité comme le corps XML du flux.

  • Scalaire

    Ceci est traité comme le nom d'un fichier contenant le XML du flux.

  • Descripteur de fichier

    Ceci est traité comme un descripteur de fichier ouvert à partir duquel le XML du flux peut être lu.

  • Objet URI

    Ceci est traité comme une URI, et le XML du flux sera récupéré depuis l'URI.

    Si le type de contenu renvoyé lors de la récupération du contenu à l'URI est text/html, cette méthode tentera automatiquement d'effectuer une auto-découverte en recherchant une balise <link> décrivant l'URL du flux. Si une telle URL est trouvée, le XML du flux sera automatiquement récupéré.

    Si l'URI est déjà un flux, aucune auto-découverte n'est nécessaire, et le XML du flux sera récupéré et analysé normalement.

XML::Atom::Feed->find_feeds($uri)

Étant donné une URI $uri, utilise l'auto-découverte pour trouver tous les flux Atom liés à partir de cette page (en utilisant les balises <link>).

Retourne une liste d'URIs de flux.

$feed->link

Si appelée dans un contexte scalaire, retourne un objet XML::Atom::Link correspondant à la première balise <link> trouvée dans le flux.

Si appelée dans un contexte de liste, retourne une liste d'objets XML::Atom::Link correspondant à toutes les balises <link> trouvées dans le flux.

$feed->add_link($link)

Ajoute le lien $link, qui doit être un objet XML::Atom::Link, au flux en tant que nouvelle balise <link>. Par exemple :

my $link = XML::Atom::Link->new;
$link->type('text/html');
$link->rel('alternate');
$link->href('http://www.example.com/');
$feed->add_link($link);

$feed->add_entry($entry)

Ajoute l'entrée $entry, qui doit être un objet XML::Atom::Entry, au flux. Si vous souhaitez ajouter une entrée avant les entrées existantes, vous pouvez passer une référence de hachage optionnelle contenant la clé "mode" avec la valeur "insert".

$feed->add_entry($entry, { mode => 'insert' });

$feed->entries

Retourne la liste des objets XML::Atom::Entry contenus dans le flux.

$feed->language

Retourne la langue du flux, à partir de xml:lang.

$feed->author([ $author ])

Retourne un objet XML::Atom::Person représentant l'auteur de l'entrée, ou "undef" s'il n'y a pas d'informations d'auteur présentes.

Si $author est fourni, il doit s'agir d'un objet XML::Atom::Person représentant l'auteur. Par exemple :

my $author = XML::Atom::Person->new;
$author->name('Foo Bar');
$author->email('foo@bar.com');
$feed->author($author);

$feed->id([ $id ])

Retourne un identifiant pour le flux. Si $id est fourni, il définit l'identifiant. Lors de la génération du nouveau flux, il est de votre responsabilité de générer un identifiant unique pour le flux et de le définir dans l'objet XML::Atom::Feed. Vous pouvez utiliser un permalien http, le schéma d'URI tag ou urn:uuid.

FLAGS UNICODE

Par défaut, XML::Atom retire tous les drapeaux Unicode du contenu du flux. Par exemple,

my $title = $feed->title;

la variable $title contient des octets UTF-8 sans le drapeau Unicode défini, même si le titre du flux contient des caractères multibytes.

Si ce comportement ne vous plaît pas et que vous souhaitez traiter tout comme des caractères Unicode (plutôt que des octets UTF-8), définissez le drapeau $XML::Atom::ForceUnicode à 1.

$XML::Atom::ForceUnicode = 1;

alors toutes les données retournées par l'objet XML::Atom::Feed et l'objet XML::Atom::Entry etc., auront le drapeau Unicode défini.

La seule exception sera "$entry->content->body", si le type de contenu n'est pas text/* (par exemple, image/gif). Dans ce cas, le corps du contenu reste des données binaires, sans drapeau Unicode défini.

CRÉATION FLUX ATOM 1.0

Par défaut, XML::Atom::Feed et d'autres classes (Entry, Link et Content) créeront des entités en utilisant les espaces de noms Atom 0.3. Afin de créer des éléments de flux et d'entrée 1.0, vous pouvez définir Version comme paramètre, comme ceci :

$feed = XML::Atom::Feed->new(Version => 1.0);
$entry = XML::Atom::Entry->new(Version => 1.0);

Définir ces versions pour chaque élément peut parfois être fastidieux. Dans ce cas, vous pouvez remplacer le numéro de version par défaut en définissant la variable globale $XML::Atom::DefaultVersion à "1.0".

use XML::Atom;
$XML::Atom::DefaultVersion = "1.0";
my $feed = XML::Atom::Feed->new;
$feed->title("blah");
my $entry = XML::Atom::Entry->new;
$feed->add_entry($entry);
$feed->version; # 1.0

NAME

XML::Atom::Feed - une classe pour manipuler des flux Atom

SYNOPSIS

use XML::Atom::Feed;

my $feed = XML::Atom::Feed->new(
    title    => "Mon Flux Atom",
    id       => "tag:example.com,2006:myfeed",
    updated  => "2006-03-10T12:00:00Z",
    author   => XML::Atom::Person->new( name => "John Doe" ),
    entries  => [
        XML::Atom::Entry->new(
            title   => "Premier Article",
            id      => "tag:example.com,2006:myfeed:1",
            updated => "2006-03-10T12:00:00Z",
            content => "Ceci est le contenu du premier article."
        ),
        XML::Atom::Entry->new(
            title   => "Deuxième Article",
            id      => "tag:example.com,2006:myfeed:2",
            updated => "2006-03-10T12:05:00Z",
            content => "Contenu du deuxième article."
        ),
    ],
);

print $feed->as_xml;

UTILISATION

La classe XML::Atom::Feed est une classe pour manipuler des flux Atom tels que définis par la spécification RFC 4287.

Elle peut être utilisée pour créer de nouveaux flux Atom à partir de données Perl, ou pour analyser des flux Atom existants à partir de chaînes XML ou de fichiers.

Voici les principaux éléments d'un flux Atom :

  • title : Le titre du flux.
  • id : Un identifiant unique pour le flux.
  • updated : La date et l'heure de la dernière modification du flux.
  • author : L'auteur du flux (un objet XML::Atom::Person).
  • entries : Une liste d'articles (objets XML::Atom::Entry).

Vous pouvez également accéder à d'autres éléments facultatifs tels que link, category, contributor, generator, icon, logo, rights et subtitle.

FLAGS UNICODE

Par défaut, XML::Atom::Feed utilise l'encodage UTF-8 pour les données. Si vous travaillez avec des données qui ne sont pas en UTF-8, vous pouvez utiliser les flags Unicode lors de la création ou de l'analyse du flux.

Par exemple, pour analyser un flux encodé en Latin-1 :

use XML::Atom::Feed;
use Encode;

my $xml_data = decode( 'iso-8859-1', $raw_xml_string );
my $feed = XML::Atom::Feed->parse($xml_data);

Pour générer un flux avec un encodage spécifique :

use XML::Atom::Feed;
use Encode;

my $feed = XML::Atom::Feed->new(...);
my $xml_string = $feed->as_xml( encoding => 'iso-8859-1' );

CRÉATION DE FLUX ATOM 1.0

L'utilisation la plus courante de XML::Atom::Feed est la création de flux Atom à partir de données Perl. L'exemple dans la section SYNOPSIS montre comment créer un objet XML::Atom::Feed et le convertir en XML.

Vous pouvez construire votre flux étape par étape :

use XML::Atom::Feed;
use XML::Atom::Entry;
use XML::Atom::Person;

my $feed = XML::Atom::Feed->new;
$feed->title("Mon Super Flux");
$feed->id("tag:monblog.com,2023:flux");
$feed->updated(DateTime->now); # Nécessite le module DateTime

my $author = XML::Atom::Person->new(name => "Moi-même");
$feed->author($author);

my $entry = XML::Atom::Entry->new;
$entry->title("Mon Premier Article");
$entry->id("tag:monblog.com,2023:flux:1");
$entry->updated(DateTime->now);
$entry->content("Contenu de mon article.");
$feed->add_entry($entry);

print $feed->as_xml;
