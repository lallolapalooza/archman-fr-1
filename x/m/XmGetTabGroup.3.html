NOM

XmGetTabGroup — Retourne l'ID du widget d'un groupe d'onglets

SYNTAXE

#include <Xm/Xm.h>
Widget XmGetTabGroup(
Widget widget);

DESCRIPTION

XmGetTabGroup retourne l'ID du widget du groupe d'onglets qui contient le widget spécifié.

widget
Spécifie un ID de widget dans un groupe d'onglets

VALEUR

Retourne l'ID du widget d'un groupe d'onglets ou d'une fenêtre, déterminé comme suit :

•
Si widget est un groupe d'onglets ou une fenêtre, retourne widget
•
Si ni widget ni aucun ancêtre jusqu'à la fenêtre la plus proche n'est un groupe d'onglets, retourne l'ancêtre le plus proche de widget qui est une fenêtre
•
Sinon, retourne l'ancêtre le plus proche de widget qui est un groupe d'onglets

VOIR AUSSI

XmAddTabGroup(3), XmManager(3), et XmPrimitive(3).
