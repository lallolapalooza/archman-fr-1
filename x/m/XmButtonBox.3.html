NOM

XmButtonBox — La classe Button Box

SYNTAXE

#include <Xm/ButtonBox.h>

DESCRIPTION

Le widget Button Box gère les enfants (généralement des boutons) dans une disposition en une seule ligne ou une seule colonne.

Le Button Box maintient un espacement égal entre ses enfants à tout moment et tente d'ajuster sa hauteur et sa largeur si nécessaire afin que tous les enfants rentrent. Si cela n'est pas possible, en raison de contraintes parentales ou du programmeur, le Button Box redimensionnera ses enfants si nécessaire pour qu'ils s'insèrent dans l'espace disponible.

Note : dans ce qui suit, la direction principale fait référence à la direction de l'orientation, et la direction secondaire fait référence à la direction perpendiculaire.

CLASSES

Button Box hérite du comportement, des ressources et des traits de Core, Composite, Constraint et XmManager.

Le pointeur de classe est xmButtonBoxWidgetClass.

Le nom de la classe est XmButtonBox.

XmNequalSize
Spécifie si les enfants doivent être maintenus avec des hauteurs et des largeurs de taille égale. La hauteur et la largeur choisies pour les enfants sont obtenues en demandant à chaque enfant sa taille préférée et en prenant la plus grande valeur dans chaque direction.
XmNfillOption
Spécifie comment utiliser l'espace supplémentaire restant une fois que tous les enfants ont été dimensionnés selon leur préférence ou leur taille égale. Il existe quatre options :
XmFillNone
Aucun remplissage automatique n'est effectué. Centre les enfants dans la direction secondaire et place les enfants avec un espacement égal entre eux dans la direction principale.
XmFillMinor
Place les enfants avec un espacement égal entre eux dans la direction principale, mais force tous les enfants à prendre la dimension secondaire du Button Box comme leur dimension secondaire.
XmFillMajor
Centre les enfants dans la direction secondaire, mais étend tous les enfants dans leur direction principale de sorte qu'il n'y ait pas d'espacement entre eux. Étendez les enfants de manière à ce que leurs tailles relatives restent constantes.
XmFillAll
Cette option combine les actions de placement et de dimensionnement de XmFillMinor et XmFillMajor.
Indépendamment du mode de remplissage, le widget ButtonBox laissera toujours la marge spécifiée entre son bord et l'enfant le plus proche. Un nouveau convertisseur de ressource String vers fillOption a été enregistré pour convertir les chaînes suivantes en options de remplissage : « none », « major », « minor », « all. » Cette ressource peut donc être définie dans un fichier de paramètres d'application.
XmNmarginHeight
XmNmarginWidth
Spécifie le nombre de pixels à utiliser comme marge autour de l'ensemble des enfants. La valeur marginHeight s'applique aux marges supérieure et inférieure, tandis que marginWidth s'applique aux marges gauche et droite.
XmNorientation
Spécifie si les enfants doivent être placés en ligne ou en colonne. L'orientation peut être XmHORIZONTAL ou XmVERTICAL. Si l'orientation est XmHORIZONTAL, les enfants sont placés en ligne avec la dimension principale étant la largeur et la dimension secondaire étant la hauteur. Si la valeur est XmVERTICAL, les enfants sont placés en colonne avec la dimension principale étant la hauteur et la dimension secondaire étant la largeur. La valeur par défaut est XmHORIZONTAL.

NAME

XmButtonBox

container widget that arranges its children in a row or column

SYNOPSIS

#include <Xm/Xm.h>

Widget XmCreateButtonBox(Widget parent, char *name,
ArgList args, Cardinal num_args
);

Widget XmVaCreateButtonBox(Widget parent, char *name,
va_list var
);

Widget XmCreateManagedButtonBox(Widget parent, char *name,
ArgList args, Cardinal num_args
);

Widget XmVaCreateManagedButtonBox(Widget parent, char *name,
va_list var
);

DESCRIPTION

The XmButtonBox widget is a container widget that arranges its children in a row or column. The children can be managed or unmanaged. The widget is derived from the XmManager widget class.

The XmButtonBox widget is useful for creating dialogs and forms that contain groups of buttons or other widgets. It simplifies the layout of these groups by automatically arranging them in a specified orientation (horizontal or vertical).

The widget supports the following resources:

XmNalignment

Specifies the alignment of the children within the widget. The possible values are XmALIGNMENT_BEGINNING, XmALIGNMENT_CENTER, and XmALIGNMENT_END.

XmNbuttonBoxChildType

Specifies the type of the child widget. The possible values are XmCHILD_BUTTON and XmCHILD_WIDGET.

XmNbuttonBoxRowColumnType

Specifies the layout orientation of the children. The possible values are XmHORIZONTAL and XmVERTICAL.

XmNchildHorizontalSpacing

Specifies the horizontal spacing between child widgets.

XmNchildVerticalSpacing

Specifies the vertical spacing between child widgets.

XmNlabelString

Specifies the label string for the button box.
