NOM

XmToggleButtonGetState — Une fonction de ToggleButton qui obtient l'état d'un ToggleButton

SYNTAXE

#include <Xm/ToggleB.h>
Boolean XmToggleButtonGetState(
Widget widget);

DESCRIPTION

XmToggleButtonGetState obtient l'état d'un ToggleButton.

widget
Spécifie l'ID du widget ToggleButton

Pour une définition complète de ToggleButton et de ses ressources associées, voir XmToggleButton(3).

VALEUR DE RETOUR

Retourne True si le bouton est sélectionné et False s'il est désélectionné.

LIRE AUSSI
