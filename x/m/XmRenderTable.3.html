NOM

XmRenderTable — Type de données pour une table de rendu

SYNTAXE

#include <Xm/Xm.h>
XmRenderTable

DESCRIPTION

XmRenderTable est le type de données pour une table de rendu, qui contient une table de rendus (XmRenditions). Chaque rendu se compose d'un ensemble d'attributs pour le rendu de texte, y compris une police ou un ensemble de polices, des couleurs, des tabulations et des lignes. Chaque rendu est identifié par une étiquette (tag).

Lorsqu'une chaîne composée est affichée, pour chaque segment de la chaîne, le rendu utilisé pour rendre cette chaîne est formé comme suit. Si le segment a au moins une étiquette de début de rendu ou si la liste des étiquettes formée en accumulant à partir des segments précédents les étiquettes de début de rendu et en supprimant les étiquettes de fin de rendu n'est pas vide, ces étiquettes sont mises en correspondance avec des rendus dans la table de rendu. Le rendu effectif utilisé pour rendre le segment est formé en fusionnant successivement chaque rendu trouvé dans le rendu actuel avec des valeurs non-XmAS_IS (XmUNSPECIFIED_PIXEL pour les ressources de couleur) pour les ressources dans le rendu à fusionner, remplaçant ainsi les valeurs correspondantes des ressources dans le rendu actuel. Enfin, si le rendu résultant a encore des ressources avec des valeurs non spécifiées et que le segment a une étiquette de locale ou de jeu de caractères (celles-ci sont optionnelles et mutuellement exclusives), cette étiquette est mise en correspondance avec un rendu dans la table de rendu, et les valeurs de rendu manquantes sont remplies à partir de cette entrée.

Si aucun rendu correspondant n'est trouvé pour une étiquette donnée, alors le callback XmNnoRenditionCallback de l'objet XmDisplay est appelé et la table de rendu est recherchée à nouveau pour cette étiquette.

Si le rendu résultant ne spécifie pas de police ou d'ensemble de polices, alors pour les segments dont le type de texte est XmCHARSET_TEXT, la table de rendu sera recherchée pour un rendu étiqueté avec XmFONTLIST_DEFAULT_TAG, et si un rendu correspondant est trouvé, il sera fusionné dans le rendu actuel. Si le rendu résultant ne contient pas de police ou d'ensemble de polices, le callback XmNnoFontCallback sera appelé avec le rendu par défaut et "" comme nom de police. Si aucun rendu ne correspond ou si aucune police n'a été trouvée après le callback, alors le premier rendu de la table de rendu sera fusionné dans le rendu actuel. Si ce rendu n'a toujours pas de police, alors le segment ne sera pas rendu et un avertissement sera émis.

Pour les segments dont le type de texte est XmMULTIBYTE_TEXT ou XmWIDECHAR_TEXT, la table de rendu sera recherchée pour un rendu étiqueté avec _MOTIF_DEFAULT_LOCALE, et, si un rendu correspondant est trouvé, il sera fusionné dans le rendu actuel. Si le rendu résultant ne contient pas de police, le callback XmNnoFontCallback sera appelé avec le rendu par défaut et "" comme nom de police. Une application peut faire en sorte que ce callback tente de remédier à ce problème en appelant XmRenditionUpdate sur le rendu d'entrée pour fournir une police à utiliser par le widget. Cela peut être fait soit en fournissant un nom de police alternatif à charger en utilisant les ressources XmNfontName et XmNfontType, soit avec une police déjà chargée en utilisant la ressource XmNfont. Si aucun rendu ne correspond ou si aucune police n'a été trouvée après le callback, alors le segment ne sera pas rendu et un avertissement sera émis.

Les tables de rendu sont spécifiées dans les fichiers de ressources avec la syntaxe suivante :

spécification_ressource: [ étiquette [, étiquette ]* ]

où étiquette est une chaîne appropriée pour la ressource XmNtag d'un rendu.

Si aucune étiquette n'est spécifiée, alors une table de rendu sera créée, soit vide, soit contenant uniquement un rendu avec une étiquette de _MOTIF_DEFAULT_LOCALE.

Les valeurs spécifiques pour des ressources de rendu spécifiques sont spécifiées en utilisant la syntaxe suivante :

spécification_ressource [*|.] rendu[*|.] nom_ressource: valeur

où :

spécification_ressource
Spécifie la table de rendu.
rendu
Est soit la classe Rendition, soit une étiquette.
nom_ressource
Est soit la classe, soit le nom d'une ressource particulière.
valeur
Est la spécification de la valeur à définir.

Toute ligne de ressource qui consiste uniquement en un composant de nom ou de classe de ressource sans composant de rendu ou liaison lâche sera supposée spécifier des valeurs de ressource pour un rendu avec une étiquette de _MOTIF_DEFAULT_LOCALE. En effet, cela crée un rendu par défaut de la même manière que la spécification d'aucune étiquette de liste de polices pour une ressource de liste de polices entraîne la création d'une liste de polices contenant une entrée étiquetée avec XmFONTLIST_DEFAULT_TAG :

spécification_ressource.nom_ressource: valeur

Par exemple, ce qui suit définirait la ressource XmNrenderTable de label1 à une table de rendu composée de trois rendus étiquetés _MOTIF_DEFAULT_LOCALE, bold et oblique, avec des valeurs pour les ressources définies comme décrit dans les spécifications de ressources.

*label1.renderTable: bold, oblique
*label1.renderTable.bold.renditionForeground: Green
*label1.renderTable.bold.fontName: *-*-*-bold-*-iso8859-1
*label1.renderTable.bold.fontType: FONT_IS_FONT
*label1.renderTable.oblique.renditionBackground: Red
*label1.renderTable.oblique.fontName: *-*-*-italic-*-iso8859-1
*label1.renderTable.oblique.fontType: FONT_IS_FONT
*label1.renderTable.oblique.underlineType: AS_IS
*label1.renderTable.fontName: fixed
*label1.renderTable.fontType: FONT_IS_FONT
*label1.renderTable.renditionForegound: black
*label1.renderTable*tabList: 1in, +1.5in, +3in
