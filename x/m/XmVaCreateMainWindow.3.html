NOM

XmVaCreateMainWindow, XmVaCreateManagedMainWindow — Fonctions pratiques de création de widget MainWindow.

SYNTAXE

#include <Xm/MainW.h>
Widget XmVaCreateMainWindow(
Widget parent,
String name,
...);
Widget XmVaCreateManagedMainWindow(
Widget parent,
String name,
...);

DESCRIPTION

Ces fonctions créent une instance d'un widget MainWindow et renvoient l'identifiant du widget associé. Ces routines utilisent la convention d'appel de liste d'arguments de longueur variable (varargs) ANSI C.

La fonction XmVaCreateMainWindow est une routine pratique qui appelle XtCreateWidget.

La fonction XmVaCreateManagedMainWindow est une routine pratique qui appelle XtCreateManagedWidget.

parent
Spécifie l'identifiant du widget parent.
name
Spécifie le nom du widget créé.
...
Spécifie la liste d'arguments variables pour remplacer les valeurs par défaut des ressources.

Pour une définition complète de MainWindow et de ses ressources associées, voir XmMainWindow(3).

RETOUR

Renvoie l'identifiant du widget MainWindow.

VOIR AUSSI

XmMainWindow(3), XmCreateMainWindow(3), XtCreateWidget(3), et XtCreateManagedWidget(3).
