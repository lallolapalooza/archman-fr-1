XmVaCreateSimplePopupMenu(library call) XmVaCreateSimplePopupMenu(library call)

NOM

XmVaCreateSimplePopupMenu — Fonction de création simplifiée de widget RowColumn

SYNTAXE

#include <Xm/RowColumn.h>
Widget XmVaCreateSimplePopupMenu(
Widget parent,
String name,
XtCallbackProc callback);

DESCRIPTION

XmVaCreateSimplePopupMenu crée une instance d'un widget RowColumn de type XmMENU_POPUP et retourne l'identifiant du widget associé. Cette routine utilise la convention d'appel de liste d'arguments de taille variable ANSI C (varargs).

Cette routine crée un panneau de menu Popup et ses widgets boutons enfants. Le nom de chaque bouton est button_n, où n est un entier allant de 0 (zéro) au nombre de boutons dans le menu moins 1. Le nom de chaque séparateur est separator_n, où n est un entier allant de 0 (zéro) au nombre de séparateurs dans le menu moins 1. Le nom de chaque titre est label_n, où n est un entier allant de 0 (zéro) au nombre de titres dans le menu moins 1. Les boutons, les séparateurs et les titres sont nommés et créés dans l'ordre dans lequel ils sont spécifiés dans la partie variable de la liste d'arguments.

parent
Spécifie l'identifiant du widget parent du MenuShell.
name
Spécifie le nom du widget créé.
callback
Spécifie une procédure de rappel à appeler lorsqu'un bouton est activé ou lorsque sa valeur change. Cette fonction de rappel est ajoutée à chaque bouton après sa création. Pour un CascadeButtonGadget ou un PushButtonGadget, le rappel est ajouté en tant que XmNactivateCallback du bouton et est appelé lorsque le bouton est activé. Pour un ToggleButtonGadget, le rappel est ajouté en tant que XmNvalueChangedCallback du bouton et est appelé lorsque la valeur du bouton change. Le numéro du bouton est retourné dans le champ client_data.

La partie variable de la liste d'arguments se compose de groupes d'arguments. Le premier argument de chaque groupe est une constante ou une chaîne de caractères et détermine quels arguments suivent dans ce groupe. Le dernier argument de la liste doit être NULL. La liste suivante décrit les premiers arguments possibles dans chaque groupe de varargs.

XmVaCASCADEBUTTON
Suivi de deux arguments supplémentaires. L'ensemble spécifie un bouton dans le PopupMenu et certaines de ses valeurs de ressource. Le bouton créé est un CascadeButtonGadget. Les deux arguments supplémentaires suivent, dans l'ordre :
label
La chaîne de libellé, de type XmString.
mnemonic
Le mnémonique, de type KeySym.
XmVaPUSHBUTTON
Suivi de quatre arguments supplémentaires. L'ensemble spécifie un bouton dans le PopupMenu et certaines de ses valeurs de ressource. Le bouton créé est un PushButtonGadget. Les quatre arguments supplémentaires suivent, dans l'ordre :
label
La chaîne de libellé, de type XmString.
mnemonic
Le mnémonique, de type KeySym.
accelerator
L'accélérateur, de type String.
accelerator_text
Le texte de l'accélérateur, de type XmString.
XmVaRADIOBUTTON
Suivi de quatre arguments supplémentaires. L'ensemble spécifie un bouton dans le PopupMenu et certaines de ses valeurs de ressource. Le bouton créé est un ToggleButtonGadget. Les quatre arguments supplémentaires suivent, dans l'ordre :
label
La chaîne de libellé, de type XmString.
mnemonic
Le mnémonique, de type KeySym.
accelerator
L'accélérateur, de type String.
accelerator_text
Le texte de l'accélérateur, de type XmString.
XmVaCHECKBUTTON
Suivi de quatre arguments supplémentaires. L'ensemble spécifie un bouton dans le PopupMenu et certaines de ses valeurs de ressource. Le bouton créé est un ToggleButtonGadget. Les quatre arguments supplémentaires suivent, dans l'ordre :
label
La chaîne de libellé, de type XmString.
mnemonic
Le mnémonique, de type KeySym.
accelerator
L'accélérateur, de type String.
accelerator_text
Le texte de l'accélérateur, de type XmString.
XmVaTITLE
Suivi d'un argument supplémentaire. La paire spécifie un LabelGadget de titre dans le PopupMenu. L'argument supplémentaire est le suivant :
title
La chaîne de titre, de type XmString.
XmVaSEPARATOR
Suivi d'aucun argument supplémentaire. Il spécifie un séparateur dans le PopupMenu.
XmVaDOUBLE_SEPARATOR
Suivi d'aucun argument supplémentaire. Il spécifie un séparateur dans le PopupMenu. Le type de séparateur est XmDOUBLE_LINE.
resource_name
Suivi d'un argument supplémentaire, la valeur de la ressource, de type XtArgVal. La paire spécifie une ressource et sa valeur pour le widget RowColumn.
XtVaTypedArg
Suivi de quatre arguments supplémentaires. L'ensemble spécifie une ressource et sa valeur pour le widget RowColumn. Une conversion de type de ressource est effectuée si nécessaire. Les quatre arguments supplémentaires suivent, dans l'ordre :
name
Le nom de la ressource, de type String.
type
Le type de la valeur de ressource fournie, de type String.
value
La valeur de la ressource (ou un pointeur vers la valeur de la ressource, selon le type et la taille de la valeur), de type XtArgVal.
size
La taille de la valeur de ressource en octets, de type int.
XtVaNestedList
Suivi d'un argument supplémentaire de type XtVarArgsList. Cet argument est une liste imbriquée de varargs retournée par XtVaCreateArgsList.

Pour plus d'informations sur les listes d'arguments de taille variable, voir la documentation des X Toolkit Intrinsics.

Un certain nombre de ressources existent spécifiquement pour une utilisation avec cette fonction et d'autres routines de création de menus simples. Pour une définition complète de RowColumn et de ses ressources associées, voir XmRowColumn(3).

RETOUR

Retourne l'identifiant du widget RowColumn.
