XmListPosToBounds(3)

Paquet: openmotif

Licences: LGPL-2.1-or-later

XmListPosToBounds(library call) XmListPosToBounds(library call)

NOM

XmListPosToBounds — Fonction de liste qui renvoie la boîte englobante d'un élément à une position spécifiée dans une liste

SYNTAXE

#include <Xm/List.h>
Boolean XmListPosToBounds(
Widget widget,
int position,
Position *x,
Position *y,
Dimension *width,
Dimension *height);

DESCRIPTION

XmListPosToBounds renvoie les coordonnées d'un élément dans une liste et les dimensions de sa boîte englobante. La fonction renvoie les coordonnées x et y associées du coin supérieur gauche de la boîte englobante par rapport au coin supérieur gauche du widget List, ainsi que la largeur et la hauteur de la boîte. L'appelant peut passer une valeur NULL pour les paramètres x, y, width ou height pour indiquer que la valeur de retour pour ce paramètre n'est pas demandée.

widget
Spécifie l'ID du widget List.
position
Spécifie la position de l'élément spécifié. Une valeur de 1 indique le premier élément de la liste ; une valeur de 2 indique le deuxième élément ; et ainsi de suite. Une valeur de 0 (zéro) spécifie le dernier élément de la liste.
x
Spécifie un pointeur vers la coordonnée x renvoyée de l'élément.
y
Spécifie le pointeur vers la coordonnée y renvoyée de l'élément.
width
Spécifie le pointeur vers la largeur renvoyée de l'élément.
height
Spécifie le pointeur vers la hauteur renvoyée de l'élément.

Pour une définition complète de List et de ses ressources associées, voir XmList(3).

RETOUR

Si l'élément à la position spécifiée n'est pas visible, renvoie False, et les valeurs renvoyées (le cas échéant) sont indéfinies. Sinon, cette fonction renvoie True.

CONNEXES

XmList(3) et XmListYToPos(3).
