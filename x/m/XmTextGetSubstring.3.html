Paquet: openmotif

XmTextGetSubstring(library call) XmTextGetSubstring(library call)

NOM

XmTextGetSubstring — Appel de fonction Texte qui récupère une copie d'une partie du tampon de texte interne

SYNTAXE

#include <Xm/Text.h>
int XmTextGetSubstring(
Widget widget,
XmTextPosition start,
int num_chars,
int buffer_size,
char *buffer);

DESCRIPTION

XmTextGetSubstring récupère une copie d'une partie du tampon de texte interne d'un widget Texte. La fonction copie un nombre spécifié de caractères à partir d'une position de départ donnée dans le tampon de texte interne vers un tampon fourni par l'application. Un terminateur NULL est placé à la fin des données copiées.

La taille du tampon requis dépend du nombre maximum d'octets par caractère (MB_CUR_MAX) pour la locale actuelle. MB_CUR_MAX est une macro définie dans stdlib.h. Le tampon doit être suffisamment grand pour contenir la sous-chaîne à copier et un terminateur NULL. Utilisez l'équation suivante pour calculer la taille du tampon que l'application doit fournir :

buffer_size = (num_chars* MB_CUR_MAX) + 1
(void)
widget
Spécifie l'identifiant du widget Texte.
start
Spécifie la position du caractère de début à partir de laquelle les données seront récupérées. Il s'agit d'un nombre entier de caractères à partir du début du tampon de texte. La première position de caractère est 0 (zéro).
num_chars
Spécifie le nombre de caractères à copier dans le tampon fourni.
buffer_size
Spécifie la taille du tampon fourni en octets. Cette taille doit tenir compte d'un terminateur NULL.
buffer
Spécifie le tampon de caractères dans lequel le tampon de texte interne sera copié.

Pour une définition complète de Texte et de ses ressources associées, voir XmText(3).

RETOUR

XmCOPY_SUCCEEDED
La fonction a réussi.
XmCOPY_FAILED
La fonction a échoué car elle n'a pas pu copier le nombre spécifié de caractères dans le tampon fourni. La taille du tampon peut être insuffisante. Le contenu de buffer est indéfini.
XmCOPY_TRUNCATED
Le nombre de caractères demandé dépassait le tampon interne. La fonction a copié les caractères entre start et la fin du tampon du widget et a terminé la chaîne avec un terminateur NULL ; moins de num_chars caractères ont été copiés.

VOIR AUSSI

XmText(3) et XmTextGetSubstringWcs(3).
