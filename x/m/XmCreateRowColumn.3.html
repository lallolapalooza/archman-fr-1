NOM

XmCreateRowColumn — Fonction de création de widget RowColumn

SYNOPSIS

#include <Xm/RowColumn.h>
Widget XmCreateRowColumn(
Widget parent,
String name,
ArgList arglist,
Cardinal argcount);

DESCRIPTION

XmCreateRowColumn crée une instance d'un widget RowColumn et retourne son identifiant de widget. Si XmNrowColumnType n'est pas spécifié, il est créé avec XmWORK_AREA, qui est la valeur par défaut.

Si cette fonction est utilisée pour créer un menu Popup de type XmMENU_POPUP ou un menu Pulldown de type XmMENU_PULLDOWN, un widget MenuShell n'est pas automatiquement créé en tant que parent de la fenêtre du menu. L'application doit d'abord créer le MenuShell en utilisant soit XmCreateMenuShell, soit la fonction de création standard du toolkit.

parent
Spécifie l'identifiant du widget parent
name
Spécifie le nom du widget créé
arglist
Spécifie la liste d'arguments
argcount
Spécifie le nombre de paires attribut/valeur dans la liste d'arguments (arglist)

Pour une définition complète de RowColumn et de ses ressources associées, voir XmRowColumn(3).

RETOUR

Retourne l'identifiant du widget RowColumn.
