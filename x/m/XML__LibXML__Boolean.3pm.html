XML::LibXML::Boolean(3) Documentation Perl Contribuée par l'Utilisateur XML::LibXML::Boolean(3)

NOM

XML::LibXML::Boolean - Valeurs booléennes vrai/faux

DESCRIPTION

Les objets XML::LibXML::Boolean implémentent des objets simples de valeurs booléennes vrai/faux.

API

XML::LibXML::Boolean->True

Crée un nouvel objet Booléen avec une valeur vraie.

XML::LibXML::Boolean->False

Crée un nouvel objet Booléen avec une valeur fausse.

value()

Retourne vrai ou faux.

to_literal()

Retourne la chaîne de caractères "true" ou "false".
