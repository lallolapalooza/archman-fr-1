DESCRIPTION

La classe XML::LibXML::XPathContext fournit une interface presque complète à l'implémentation XPath de libxml2. Avec XML::LibXML::XPathContext, il est possible d'évaluer des expressions XPath dans le contexte d'un nœud arbitraire, d'une taille de contexte et d'une position de contexte, avec un mappage préfixe-espace de noms défini par l'utilisateur, des fonctions XPath personnalisées écrites en Perl, et même un résolveur de variables XPath personnalisé.

EXEMPLES

Espaces de noms

Cet exemple démontre la méthode registerNs(). Il trouve tous les nœuds de paragraphe dans un document XHTML.

my $xc = XML::LibXML::XPathContext->new($xhtml_doc);
$xc->registerNs('xhtml', 'http://www.w3.org/1999/xhtml');
my @nodes = $xc->findnodes('//xhtml:p');

Fonctions XPath personnalisées

Cet exemple démontre la méthode registerFunction() en définissant une fonction qui filtre les nœuds en fonction d'une expression régulière Perl :

sub grep_nodes {
  my ($nodelist,$regexp) =  @_;
  my $result = XML::LibXML::NodeList->new;
  for my $node ($nodelist->get_nodelist()) {
    $result->push($node) if $node->textContent =~ $regexp;
  }
  return $result;
};
my $xc = XML::LibXML::XPathContext->new($node);
$xc->registerFunction('grep_nodes', \&grep_nodes);
my @nodes = $xc->findnodes('//section[grep_nodes(para,"\bsearch(ing|es)?\b")]');

Variables

Cet exemple démontre la méthode registerVarLookup(). Nous utilisons des variables XPath pour recycler les résultats des évaluations précédentes :

sub var_lookup {
  my ($varname,$ns,$data)=@_;
  return $data->{$varname};
}
my $areas = XML::LibXML->new->parse_file('areas.xml');
my $empl = XML::LibXML->new->parse_file('employees.xml');
my $xc = XML::LibXML::XPathContext->new($empl);
my %variables = (
  A => $xc->find('/employees/employee[@salary>10000]'),
  B => $areas->find('/areas/area[district='Brooklyn']/street'),
);
# obtenir les noms des employés de $A travaillant dans une zone listée dans $B
$xc->registerVarLookupFunc(\&var_lookup, \%variables);
my @nodes = $xc->findnodes('$A[work_area/street = $B]/name');

MÉTHODES

new
my $xpc = XML::LibXML::XPathContext->new();

Crée un nouvel objet XML::LibXML::XPathContext sans nœud de contexte.

my $xpc = XML::LibXML::XPathContext->new($node);

Crée un nouvel objet XML::LibXML::XPathContext avec le nœud de contexte défini sur $node.

registerNs
$xpc->registerNs($prefix, $namespace_uri)

Enregistre l'espace de noms $prefix vers $namespace_uri.

unregisterNs
$xpc->unregisterNs($prefix)

Désenregistre l'espace de noms $prefix.

lookupNs
$uri = $xpc->lookupNs($prefix)

Retourne l'URI de l'espace de noms enregistrée avec $prefix. Si $prefix n'est enregistré à aucune URI d'espace de noms, retourne "undef".

registerVarLookupFunc
$xpc->registerVarLookupFunc($callback, $data)

Enregistre la fonction de recherche de variables $callback. La fonction enregistrée est exécutée par le moteur XPath chaque fois qu'une variable XPath est évaluée. Elle prend trois arguments : $data, le nom de la variable et l'URI de l'espace de noms de la variable, et doit retourner une valeur : un nombre, une chaîne de caractères ou tout objet "XML::LibXML::" qui peut être le résultat de findnodes : Booléen, Littéral, Nombre, Nœud (par exemple, Document, Élément, etc.), ou NodeList. Pour plus de commodité, des références de tableaux simples (non-blessed) contenant uniquement des objets XML::LibXML::Node peuvent être utilisées à la place d'une XML::LibXML::NodeList.

getVarLookupData
$data = $xpc->getVarLookupData();

Retourne les données qui ont été associées à une fonction de recherche de variables lors d'un appel précédent à "registerVarLookupFunc".

getVarLookupFunc
$callback = $xpc->getVarLookupFunc();

Retourne la fonction de recherche de variables précédemment enregistrée avec "registerVarLookupFunc".

unregisterVarLookupFunc
$xpc->unregisterVarLookupFunc($name);

Désenregistre la fonction de recherche de variables et les données de recherche associées.

registerFunctionNS
$xpc->registerFunctionNS($name, $uri, $callback)

Enregistre une fonction d'extension $name dans l'espace de noms $uri. $callback doit être une référence CODE. Les arguments de la fonction de rappel sont soit des scalaires simples, soit des objets "XML::LibXML::*" en fonction des types d'arguments XPath. La fonction est responsable de la vérification du nombre et des types d'arguments. Le résultat du code de rappel doit être une valeur unique des types suivants : un scalaire simple (nombre, chaîne) ou un objet "XML::LibXML::*" arbitraire qui peut être le résultat de findnodes : Booléen, Littéral, Nombre, Nœud (par exemple, Document, Élément, etc.), ou NodeList. Pour plus de commodité, des références de tableaux simples (non-blessed) contenant uniquement des objets XML::LibXML::Node peuvent être utilisées à la place d'une XML::LibXML::NodeList.

unregisterFunctionNS
$xpc->unregisterFunctionNS($name, $uri)

Désenregistre la fonction d'extension $name dans l'espace de noms $uri. A le même effet que de passer "undef" comme $callback à registerFunctionNS.

registerFunction
$xpc->registerFunction($name, $callback)

Identique à "registerFunctionNS" mais sans espace de noms.

unregisterFunction
$xpc->unregisterFunction($name)

Identique à "unregisterFunctionNS"

XML::LibXML::XPathContext(3pm) - Perl documentation

NAME

XML::LibXML::XPathContext - A convenient interface for XPath queries

SYNOPSIS

    use XML::LibXML;
    my $parser = XML::LibXML->new();
    my $doc = $parser->parse_string("<root><node name='foo'>bar</node></root>");
    my $xpc = XML::LibXML::XPathContext->new($doc);
    my @nodes = $xpc->findnodes('//node');
    my $val = $xpc->findvalue('//node');
    my $bool = $xpc->exists('//node');

DESCRIPTION

This module provides a convenient interface to perform XPath queries on an XML::LibXML::Document or an XML::LibXML::Node. It manages namespaces and context information for you.

EXAMPLES

    use XML::LibXML;
    use XML::LibXML::XPathContext;

    my $xml_string = <<EOS;
    <?xml version="1.0" encoding="UTF-8"?>
    <root xmlns:html="http://www.w3.org/1999/xhtml">
        <node name="foo">bar</node>
        <node name="baz">qux</node>
        <html:a href="http://example.com">Link</html:a>
    </root>
    EOS

    my $parser = XML::LibXML->new();
    my $doc = $parser->parse_string($xml_string);

    # Create XPath context for the document
    my $xpc = XML::LibXML::XPathContext->new($doc);

    # Register namespaces (needed for qualified names in XPath)
    $xpc->registerNs('h', 'http://www.w3.org/1999/xhtml');

    # Find all 'node' elements
    my @nodes = $xpc->findnodes('//node');
    print "Found ", scalar(@nodes), " nodes:\n";
    foreach my $node (@nodes) {
        print "- ", $node->textContent, "\n";
    }

    # Find the value of the first 'node' element
    my $value = $xpc->findvalue('//node');
    print "Value of first node: ", $value, "\n";

    # Check if an element exists
    my $exists = $xpc->exists('//html:a');
    print "HTML link exists: ", $exists ? 'Yes' : 'No', "\n";

    # Find a specific node by attribute
    my $specific_node = $xpc->find('//node[@name="baz"]');
    if ($specific_node) {
        print "Found node with name='baz': ", $specific_node->textContent, "\n";
    }

    # Use a specific node as context
    my $first_node = $xpc->findnodes('//node')->[0];
    my @sub_nodes = $xpc->findnodes('./@name', $first_node);
    print "Attribute of the first node: ", $sub_nodes[0]->value, "\n";

    # Using XPathExpression object
    my $xpath_expr = $xpc->compile('//node');
    my @compiled_nodes = $xpc->findnodes($xpath_expr);

METHODS

new
    $xpc = XML::LibXML::XPathContext->new($root)

Creates a new XPath context. The first argument, $root, must be either an XML::LibXML::Document or an XML::LibXML::Node object. This object will serve as the context node for queries unless overridden.

registerNs
    $xpc->registerNs($prefix, $uri)

Registers a namespace with the context. This is necessary for using prefixed names in XPath expressions. For example, to use the html namespace, you would call $xpc->registerNs('html', 'http://www.w3.org/1999/xhtml').

registerNsList
    $xpc->registerNsList($ns_hashref)

Registers multiple namespaces from a hash reference. Keys are prefixes, values are URIs.

getNsList
    my $ns_hashref = $xpc->getNsList()

Returns a hash reference of all registered namespaces.

registerFunc
    $xpc->registerFunc($name, $coderef)
    $xpc->registerFunc($name, $coderef, $ret_type)

Registers an XPath extension function. $name is the name of the function (without prefix), $coderef is a Perl subroutine reference that will be called when the function is invoked. $ret_type specifies the return type of the function (e.g., 'number', 'string', 'boolean', 'node-set'). If $ret_type is omitted, it is assumed to be 'node-set'.

registerFuncNS
    $xpc->registerFuncNS($name, $uri, $coderef)
    $xpc->registerFuncNS($name, $uri, $coderef, $ret_type)

Registers an XPath extension function with a namespace URI. $name is the local name of the function, $uri is the namespace URI. The rest is the same as registerFunc.

registerVariable
    $xpc->registerVariable($name, $value)

Registers an XPath variable. $name is the name of the variable (without prefix), $value is the Perl value to be associated with the variable. The value will be converted to an appropriate XPath type.

registerVariableNS
    $xpc->registerVariableNS($name, $uri, $value)

Registers an XPath variable with a namespace URI. $name is the local name of the variable, $uri is the namespace URI. The rest is the same as registerVariable.

findnodes
@nodes = $xpc->findnodes($xpath)
@nodes = $xpc->findnodes($xpath, $context_node )
$nodelist = $xpc->findnodes($xpath, $context_node )

Performs the xpath statement on the current node and returns the result as an array. In scalar context, returns an XML::LibXML::NodeList object. Optionally, a node may be passed as a second argument to set the context node for the query.

The xpath expression can be passed either as a string, or as a XML::LibXML::XPathExpression object.

find
$object = $xpc->find($xpath )
$object = $xpc->find($xpath, $context_node )

Performs the xpath expression using the current node as the context of the expression, and returns the result depending on what type of result the XPath expression had. For example, the XPath "1 * 3 + 52" results in an XML::LibXML::Number object being returned. Other expressions might return a XML::LibXML::Boolean object, or a XML::LibXML::Literal object (a string). Each of those objects uses Perl's overload feature to ``do the right thing'' in different contexts. Optionally, a node may be passed as a second argument to set the context node for the query.

The xpath expression can be passed either as a string, or as a XML::LibXML::XPathExpression object.

findvalue
$value = $xpc->findvalue($xpath )
$value = $xpc->findvalue($xpath, $context_node )

Is exactly equivalent to:

$xpc->find( $xpath, $context_node )->to_literal;

That is, it returns the literal value of the results. This enables you to ensure that you get a string back from your search, allowing certain shortcuts. This could be used as the equivalent of <xsl:value-of select=``some_xpath''/>. Optionally, a node may be passed in the second argument to set the context node for the query.

The xpath expression can be passed either as a string, or as a XML::LibXML::XPathExpression object.

exists
$bool = $xpc->exists( $xpath_expression, $context_node );

This method behaves like findnodes, except that it only returns a boolean value (1 if the expression matches a node, 0 otherwise) and may be faster than findnodes, because the XPath evaluation may stop early on the first match (this is true for libxml2 >= 2.6.27).

For XPath expressions that do not return node-set, the method returns true if the returned value is a non-zero number or a non-empty string.

setContextNode
$xpc->setContextNode($node)

Set the current context node.

getContextNode
my $node = $xpc->getContextNode;

Get the current context node.

setContextPosition
$xpc->setContextPosition($position)

Set the current context position. By default, this value is -1 (and evaluating XPath function position() in the initial context raises an XPath error), but can be set to any value up to context size. This usually only serves to cheat the XPath engine to return given position when position() XPath function is called. Setting this value to -1 restores the default behavior.

getContextPosition
my $position = $xpc->getContextPosition;

Get the current context position.

setContextSize
$xpc->setContextSize($size)

Set the current context size. By default, this value is -1 (and evaluating XPath function last() in the initial context raises an XPath error), but can be set to any non-negative value. This usually only serves to cheat the XPath engine to return the given value when last() XPath function is called. If context size is set to 0, position is automatically also set to 0. If context size is positive, position is automatically set to 1. Setting context size to -1 restores the default behavior.

getContextSize
my $size = $xpc->getContextSize;

Get the current context size.

compile
$expr = $xpc->compile($xpath_string);

Compiles an XPath expression string into an XML::LibXML::XPathExpression object. This can be useful if you plan to reuse the same XPath expression multiple times, as compilation is done only once.

findnodes
@nodes = $xpc->findnodes($xpath_expression, $context_node )

Finds nodes using a pre-compiled XML::LibXML::XPathExpression object.

find
$object = $xpc->find($xpath_expression, $context_node )

Finds values using a pre-compiled XML::LibXML::XPathExpression object.

findvalue
$value = $xpc->findvalue($xpath_expression, $context_node )

Finds literal values using a pre-compiled XML::LibXML::XPathExpression object.

exists
$bool = $xpc->exists($xpath_expression, $context_node )

Checks for existence using a pre-compiled XML::LibXML::XPathExpression object.

setContextNode
$xpc->setContextNode($node)

Set the current context node.

BUGS AND CAVEATS

XML::LibXML::XPathContext objects are reentrant, meaning that you can call methods of an XML::LibXML::XPathContext even from XPath extension functions registered with the same object or from a variable lookup function. On the other hand, you should rather avoid registering new extension functions, namespaces and a variable lookup function from within extension functions and a variable lookup function, unless you want to experience untested behavior.
