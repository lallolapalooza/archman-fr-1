NOM

XmClipboardInquireCount — Une fonction de presse-papiers qui renvoie le nombre de formats d'éléments de données

SYNTAXE

#include <Xm/CutPaste.h>
int XmClipboardInquireCount (display, window, count,
        max_format_name_length)
        Display * display;
        Window  window;
        int     * count;
        unsigned long   * max_format_name_length;
(void)

DESCRIPTION

XmClipboardInquireCount renvoie le nombre de formats d'éléments de données disponibles pour l'élément de données dans le presse-papiers. Cette fonction renvoie également la longueur maximale du nom pour tous les formats dans lesquels l'élément de données est stocké.

display
Spécifie un pointeur vers la structure Display qui a été retournée lors d'un appel précédent à XOpenDisplay ou XtDisplay.
window
Spécifie l'ID de fenêtre d'un widget qui relie la fenêtre de l'application au presse-papiers. L'ID de fenêtre du widget peut être obtenu via XtWindow. La même instance d'application doit passer le même ID de fenêtre à chacune des fonctions de presse-papiers qu'elle appelle.
count
Renvoie le nombre de formats d'éléments de données disponibles pour l'élément de données dans le presse-papiers. S'il n'y a pas de formats disponibles, cet argument est égal à 0 (zéro). Le compte inclut les formats qui ont été passés par nom.
max_format_name_length
Spécifie la longueur maximale de tous les noms de format pour l'élément de données dans le presse-papiers.

RETOUR

XmClipboardSuccess
La fonction a réussi.
XmClipboardLocked
La fonction a échoué car le presse-papiers était verrouillé par une autre application. L'application peut continuer à appeler la fonction à plusieurs reprises avec les mêmes paramètres jusqu'à ce que le verrou disparaisse. Cela donne à l'application la possibilité de demander si l'utilisateur souhaite continuer d'essayer ou abandonner l'opération.
XmClipboardNoData
La fonction n'a pas pu trouver de données dans le presse-papiers correspondant au format demandé. Cela peut se produire car le presse-papiers est vide ; il y a des données dans le presse-papiers, mais pas dans le format demandé ; ou les données dans le format demandé ont été passées par nom et ne sont plus disponibles.
