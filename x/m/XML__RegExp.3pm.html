NOM

XML::RegExp - Expressions régulières pour les jetons XML

SYNOPSIS

use XML::RegExp;
if ($my_name =~ /^$XML::RegExp::Name$/)
{
  # $my_name est un 'Name' XML valide
}

DESCRIPTION

Ce paquet contient les expressions régulières pour les jetons XML suivants : BaseChar, Ideographic, Letter, Digit, Extender, CombiningChar, NameChar, EntityRef, CharRef, Reference, Name, NmToken, et AttValue.

Les définitions de ces jetons proviennent de la spécification XML (Extensible Markup Language 1.0) à l'adresse http://www.w3.org/TR/REC-xml.

Contient également les expressions régulières pour les jetons suivants de la spécification XML Namespaces à l'adresse http://www.w3.org/TR/REC-xml-names : NCNameChar, NCName, QName, Prefix et LocalPart.
