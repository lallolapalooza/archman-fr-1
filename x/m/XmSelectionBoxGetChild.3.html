NOM

XmSelectionBoxGetChild — Une fonction de SelectionBox utilisée pour accéder à un composant

SYNTAXE

#include <Xm/SelectioB.h>
Widget XmSelectionBoxGetChild(
Widget widget,
unsigned char child);

DESCRIPTION

XmSelectionBoxGetChild est utilisé pour accéder à un composant au sein d'une SelectionBox. Les paramètres transmis à la fonction sont le widget SelectionBox et une valeur indiquant quel composant accéder.

NOTE : Cette routine est obsolète et existe pour la compatibilité avec les versions précédentes. Au lieu d'appeler XmSelectionBoxGetChild, vous devriez appeler XtNameToWidget comme décrit sur la page de référence de XmSelectionBox(3).

widget
Spécifie l'ID du widget SelectionBox.
child
Spécifie un composant au sein de la SelectionBox. Les valeurs suivantes sont légales pour ce paramètre :
•
XmDIALOG_APPLY_BUTTON
•
XmDIALOG_CANCEL_BUTTON
•
XmDIALOG_DEFAULT_BUTTON
•
XmDIALOG_HELP_BUTTON
•
XmDIALOG_LIST
•
XmDIALOG_LIST_LABEL
•
XmDIALOG_OK_BUTTON
•
XmDIALOG_SELECTION_LABEL
•
XmDIALOG_SEPARATOR
•
XmDIALOG_TEXT
•
XmDIALOG_WORK_AREA

Pour une définition complète de SelectionBox et de ses ressources associées, voir XmSelectionBox(3).

VALEUR DE RETOUR

Retourne l'ID du widget du composant SelectionBox spécifié. Une application ne doit pas supposer que le widget retourné sera d'une classe particulière.
