NOM

XML::LibXML::Text - Classe XML::LibXML pour les nœuds de texte

SYNOPSIS

use XML::LibXML;
# Seules les méthodes spécifiques aux nœuds de texte sont listées ici,
# voir la page de manuel XML::LibXML::Node pour les autres méthodes
$text = XML::LibXML::Text->new( $content );
$nodedata = $text->data;
$text->setData( $text_content );
$text->substringData($offset, $length);
$text->appendData( $somedata );
$text->insertData($offset, $string);
$text->deleteData($offset, $length);
$text->deleteDataString($remstring, $all);
$text->replaceData($offset, $length, $string);
$text->replaceDataString($old, $new, $flag);
$text->replaceDataRegEx( $search_cond, $replace_cond, $reflags );

DESCRIPTION

Contrairement à la spécification DOM, XML::LibXML implémente le nœud de texte comme classe de base de tous les nœuds de données caractères. Par conséquent, il n'existe pas de classe CharacterData. Cela permet d'appliquer les méthodes des nœuds de texte également aux commentaires et aux sections CDATA.

MÉTHODES

La classe hérite de XML::LibXML::Node. La documentation des méthodes héritées n'est pas listée ici.

De nombreuses fonctions listées ici sont documentées de manière exhaustive dans la spécification DOM Level 3 (http://www.w3.org/TR/DOM-Level-3-Core/). Veuillez vous référer à la spécification pour une documentation complète.

new
$text = XML::LibXML::Text->new( $content );

Le constructeur de la classe. Il crée un nœud de texte non lié.

data
$nodedata = $text->data;

Bien qu'il existe l'attribut "nodeValue" dans la classe Node, la spécification DOM définit les données comme un attribut séparé. "XML::LibXML" implémente ces deux attributs non pas comme des attributs différents, mais comme des alias, tout comme "libxml2". Par conséquent,

$text->data;

et

$text->nodeValue;

auront le même résultat et ne sont pas des entités différentes.

setData($string)
$text->setData( $text_content );

Cette fonction définit ou remplace le contenu texte d'un nœud. Le nœud doit être de type "text", "cdata" ou "comment".

substringData($offset,$length)
$text->substringData($offset, $length);

Extrait une plage de données du nœud. (Spécification DOM) Cette fonction prend les deux paramètres $offset et $length et renvoie la sous-chaîne, si elle est disponible.

Si le nœud ne contient aucune donnée ou si $offset fait référence à un index de chaîne inexistant, cette fonction renverra undef. Si $length est hors limites, "substringData" renverra les données commençant à $offset au lieu de provoquer une erreur.

appendData($string)
$text->appendData( $somedata );

Ajoute une chaîne à la fin des données existantes. Si le nœud de texte actuel ne contient aucune donnée, cette fonction a le même effet que "setData".

insertData($offset,$string)
$text->insertData($offset, $string);

Insère le paramètre $string à l'$offset donné des données existantes du nœud. Cette opération ne supprime pas les données existantes, mais modifie l'ordre des données existantes.

L'$offset doit être une valeur positive. Si $offset est hors limites, "insertData" aura le même comportement que "appendData".

deleteData($offset, $length)
$text->deleteData($offset, $length);

Cette méthode supprime un fragment des données du nœud existantes à l'offset donné. Le paramètre $length indique combien de caractères doivent être supprimés de la chaîne.

deleteDataString($string, [$all])
$text->deleteDataString($remstring, $all);

Cette méthode supprime un fragment des données existantes du nœud. Comme la spécification DOM est assez peu pratique si vous connaissez déjà "quelle" chaîne supprimer d'un nœud de texte, cette méthode permet un code plus perlesque :)

La fonction prend deux paramètres : $string et optionnellement le flag $all. Si $all n'est pas défini, undef ou 0, "deleteDataString" supprimera uniquement la première occurrence de $string. Si $all est TRUE"deleteDataString" supprimera toutes les occurrences de $string des données du nœud.

replaceData($offset, $length, $string)
$text->replaceData($offset, $length, $string);

La version style DOM pour remplacer les données du nœud.

replaceDataString($oldstring, $newstring, [$all])
$text->replaceDataString($old, $new, $flag);

La version plus conviviale pour le programmeur de replaceData() :)

Au lieu de fournir des offsets et des longueurs, on peut spécifier la chaîne exacte ($oldstring) à remplacer. De plus, le flag $all permet de remplacer toutes les occurrences de $oldstring.

replaceDataRegEx( $search_cond, $replace_cond, $reflags )
$text->replaceDataRegEx( $search_cond, $replace_cond, $reflags );

Cette méthode remplace les données du nœud par une expression régulière "simple". Optionnellement, cette fonction permet de passer des drapeaux qui seront ajoutés comme drapeaux à l'instruction de remplacement.

NOTE : C'est un raccourci pour

my $datastr = $node->getData();
 $datastr =~ s/somecond/replacement/g; # 'g' n'est qu'un exemple de drapeau
 $node->setData( $datastr );

Cette fonction peut rendre les choses plus faciles à lire pour des remplacements simples. Pour des variantes plus complexes, il est recommandé d'utiliser l'extrait de code ci-dessus.
