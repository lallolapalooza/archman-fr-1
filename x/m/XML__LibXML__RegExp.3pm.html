XML::LibXML::RegExp(3) Documentation Perl fournie par l'utilisateur XML::LibXML::RegExp(3)

NOM

XML::LibXML::RegExp - interface vers les expressions régulières de libxml2

SYNTAXE

use XML::LibXML;
my $re_compile = XML::LibXML::RegExp->new('[0-9]{5}(-[0-9]{4})?');
if ($re_compile->isDeterministic()) { ... }
if ($re_compile->matches($chaine)) { ... }
$re_compile = XML::LibXML::RegExp->new( $chaine_re );
$bool = $re_compile->matches($chaine);
$bool = $re_compile->isDeterministic();

DESCRIPTION

Il s'agit d'une interface Perl pour l'implémentation des expressions régulières de libxml2, qui sont utilisées par exemple pour la validation des types simples de schémas XML (facette de motif).

new()
$re_compile = XML::LibXML::RegExp->new( $chaine_re );

Le constructeur prend une chaîne contenant une expression régulière et retourne un objet d'expression régulière compilée.

matches($chaine)
$bool = $re_compile->matches($chaine);

Étant donné une valeur de chaîne, retourne une valeur vraie si la valeur correspond à l'expression régulière compilée.

isDeterministic()
$bool = $re_compile->isDeterministic();

Retourne une valeur vraie si l'expression régulière est déterministe ; retourne faux sinon. (Voir la définition du déterminisme dans la spécification XML (http://www.w3.org/TR/REC-xml/#determinism))
