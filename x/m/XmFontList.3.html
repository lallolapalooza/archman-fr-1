NOM

XmFontList — Type de données pour une liste de polices

SYNTAXE

#include <Xm/Xm.h>

DESCRIPTION

XmFontList est le type de données pour une liste de polices. Une liste de polices est composée d'entrées de liste de polices. Chaque entrée contient une police ou un ensemble de polices (un groupe de polices) et est identifiée par une étiquette (tag), qui est facultative. Si cette étiquette est NULL, l'étiquette est définie sur XmFONTLIST_DEFAULT_TAG.

La valeur de XmFONTLIST_DEFAULT_TAG est XmFONTLIST_DEFAULT_TAG_STRING.

Lorsqu'une chaîne composite est affichée, l'étiquette de l'élément de liste de polices du segment de chaîne composite est mise en correspondance avec une étiquette d'entrée de liste de polices dans la liste de polices et l'entrée de liste de polices correspondante est utilisée pour afficher la chaîne composite. Une entrée de liste de polices est choisie comme suit :

•
La première entrée de liste de polices dont l'étiquette correspond à l'étiquette du segment de chaîne composite est utilisée.
•
Si aucune correspondance n'a été trouvée et si l'étiquette du segment de chaîne composite est XmFONTLIST_DEFAULT_TAG, la première entrée de liste de polices dont l'étiquette correspond à l'étiquette qui résulterait de la création d'une entrée avec XmSTRING_DEFAULT_CHARSET est utilisée. Par exemple, si la création d'une entrée avec XmSTRING_DEFAULT_CHARSET aboutirait à l'étiquette ISO8859-1, l'étiquette du segment de chaîne composite XmFONTLIST_DEFAULT_TAG correspondra à l'étiquette d'entrée de liste de polices ISO8859-1.
•
Si aucune correspondance n'a été trouvée et si l'étiquette du segment de chaîne composite correspond à l'étiquette qui résulterait de la création d'un segment avec XmSTRING_DEFAULT_CHARSET, la première entrée de liste de polices dont l'étiquette est XmFONTLIST_DEFAULT_TAG est utilisée.
•
Si aucune correspondance n'a été trouvée, la première entrée de la liste de polices est utilisée.

L'interface de liste de polices comprend les routines listées dans Informations associées.

Les listes de polices sont spécifiées dans les fichiers de ressources avec la syntaxe suivante :

spécification_ressource:  entrée_police [, entrée_police ]+

La chaîne de valeur de ressource se compose d'une ou plusieurs entrées de liste de polices séparées par des virgules. Chaque entrée_police identifie une police ou un ensemble de polices et une étiquette d'entrée de liste de polices facultative. Une étiquette spécifiée pour une seule police suit le nom de la police et est séparée par = (signe égal) ; sinon, dans un ensemble de polices, l'étiquette est séparée par un deux-points. Le deux-points est requis, qu'une étiquette soit spécifiée ou non. Une entrée de police utilise la syntaxe suivante pour spécifier une seule police :

nom_police [ '=' étiquette ]

Par exemple, l'entrée suivante spécifie une police Times Italic de 10 points sans étiquette d'entrée de liste de polices ;

*fontList:  -Adobe-Times-Medium-I-Normal--10*

Une entrée de police contenant un ensemble de polices est similaire, sauf qu'un point-virgule sépare plusieurs noms de police et que la spécification se termine par un deux-points suivi d'une étiquette facultative :

nom_police [ ';' nom_police ]+ ':' [ étiquette ]

Un nom_police est une chaîne de description de police logique X (XLFD) et étiquette est tout ensemble de caractères d'ISO646IRV sauf l'espace, la virgule, le deux-points, le signe égal et le point-virgule. Voici un exemple d'entrée d'ensemble de polices. Il se compose de trois polices (sauf pour les jeux de caractères) et d'une étiquette d'entrée de liste de polices explicite.

*fontList: -Adobe-Courier-Bold-R-Normal--25-180-100-100-M-150;-JIS-Fixed-Medium-R-Normal--26-180-100-100-C-240;-JIS-Fixed-Medium-R-Normal--26-180-100-100-C-120:MON_TAG

Notez que la XmRenderTable est un autre type de données qui peut être utilisé pour les listes de polices. Reportez-vous à la page XmRenderTable(3) pour plus de détails.
