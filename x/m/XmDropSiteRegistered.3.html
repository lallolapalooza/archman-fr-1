NOM

XmDropSiteRegistered — Fonction de Glisser-Déposer qui détermine si un site de dépôt a été enregistré

SYNTAXE

#include <Xm/DragDrop.h>
Boolean XmDropSiteRegistered(
Widget widget);

DESCRIPTION

XmDropSiteRegistered détermine si le widget spécifié possède un site de dépôt enregistré. Si un site de dépôt est enregistré, cette fonction renvoie Vrai.

widget
Spécifie l'ID du widget interrogé.

Pour une définition complète de DropSite et de ses ressources associées, consultez XmDropSite(3).

RETOUR

Si le widget n'est pas un site de dépôt enregistré, cette fonction renvoie Faux. Sinon, elle renvoie Vrai.

LIENS CONNEXES

XmDisplay(3), XmDropSite(3), XmDropSiteEndUpdate(3), XmDropSiteStartUpdate(3), XmDropSiteUpdate(3), XmDropSiteUnregister(3), et XmScreen(3).
