NOM

XmStringToXmStringTable — Une fonction pratique qui convertit une seule chaîne composite en une table de chaînes composites

SYNTAXE

#include <Xm/Xm.h>
Cardinal XmStringToXmStringTable(
XmString string,
XmString break_component,
XmStringTable *table);

DESCRIPTION

XmStringToXmStringTable prend en entrée une seule chaîne composite et un composant de chaîne spécifié (tel qu'une tabulation) et renvoie une table de chaînes composites constituée des parties de string délimitées par des composants correspondant à break_component. Les composants marquant les séparations n'apparaîtront pas dans la table résultante.

string
Spécifie la XmString à convertir.
break_component
Spécifie le XmStringComponent qui sera utilisé pour indiquer où diviser string afin de former les éléments individuels de table. Les types les plus utiles seront XmSTRING_COMPONENT_SEPARATOR et XmSTRING_COMPONENT_TAB. Référez-vous à la page de référence XmStringComponentType(3) pour une liste complète des types de composants possibles. Notez cependant que le composant XmSTRING_COMPONENT_UNKNOWN n'est pas un type possible.
table
Renvoie la XmStringTable équivalente. La fonction allouera de l'espace pour contenir la XmStringTable renvoyée. Lorsque l'application n'aura plus besoin de la XmStringTable renvoyée, l'application devra appeler XmStringFree une fois pour chaque chaîne composite dans la table, puis appeler XtFree pour libérer la XmStringTable elle-même.

RETOUR

Renvoie le nombre de chaînes composites dans table.

VOIR AUSSI

XmStringTable(3).
