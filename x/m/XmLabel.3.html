NOM

XmLabel — La classe de widget Label

SYNOPSIS

#include <Xm/Label.h>

DESCRIPTION

Label est un widget instanciable et est également utilisé comme superclasse pour d'autres widgets de bouton, tels que PushButton et ToggleButton. Le widget Label n'accepte aucune entrée de bouton ou de touche, et le rappel d'aide est le seul rappel défini. Label reçoit également des événements d'entrée et de sortie.

Label peut contenir du texte ou une pixmap. Le texte de Label est une chaîne composite. Référez-vous au Motif Programmer's Guide pour plus d'informations sur les chaînes composites. Le texte peut être multilingue, multiligne et/ou multi-polices. Lorsqu'un Label est inactif, son texte est pointillé, ou la pixmap inactive fournie par l'utilisateur est affichée.

Label prend en charge les accélérateurs et les mnémoniques principalement pour être utilisés dans les widgets sous-classes de Label contenus dans des menus. Les mnémoniques sont disponibles dans un système de menu lorsque le bouton est visible. Les accélérateurs dans un système de menu sont accessibles même lorsque le bouton n'est pas visible. Le widget Label affiche le mnémonique en soulignant le premier caractère correspondant dans la chaîne de texte. L'accélérateur est affiché comme une chaîne de texte adjacente au texte ou à la pixmap du label, en fonction de la direction de la mise en page.

Label se compose de nombreux champs de marge entourant le texte ou la pixmap. Ces champs de marge sont des ressources qui peuvent être définies par l'utilisateur, mais les sous-classes de Label et les parents Manager modifient également certains de ces champs. Ils ont tendance à modifier les ressources XmNmarginLeft, XmNmarginRight, XmNmarginTop et XmNmarginBottom et laissent les ressources XmNmarginWidth et XmNmarginHeight telles que définies par l'application.

Label prend en compte XmNshadowThickness pour déterminer sa mise en page mais ne dessine pas l'ombre. C'est-à-dire que si XmNshadowThickness est supérieur à 0 (zéro), Label laisse de l'espace pour l'ombre, mais l'ombre n'apparaît pas.

Dans un Label, XmNtraversalOn et XmNhighlightOnEnter sont forcés à False à l'intérieur des panneaux de menu Popup, des panneaux de menu Pulldown et des OptionMenus. Sinon, ces ressources sont fausses par défaut.

Label utilise les traits XmQTmenuSystem et XmQTspecifyRenderTable, et détient les traits XmQTaccessTextual, XmQTmenuSavvy et XmQTtransfer.

Comportement de transfert de données

Label et ses sous-classes, sauf lorsqu'ils sont utilisés dans un système de menu, prennent en charge le glisser-déposer du contenu du label à partir du Label. Cependant, le contenu du label n'est glissable que si la ressource XmNenableUnselectableDrag de XmDisplay est définie sur True.

En tant que source de données, Label et ses sous-classes prennent en charge les cibles suivantes et les conversions associées de données vers ces cibles :

locale
Si la cible locale correspond à la locale du widget, le widget transfère XmNlabelString dans l'encodage de la locale. Cette cible est prise en charge lorsque XmNlabelType est XmSTRING ou XmPIXMAP_AND_STRING.
COMPOUND_TEXT
Le widget transfère XmNlabelString sous le type COMPOUND_TEXT. Cette cible est prise en charge lorsque XmNlabelType est XmSTRING ou XmPIXMAP_AND_STRING.
UTF8_STRING
Le widget transfère XmNlabelString sous le type UTF8_STRING. Cette cible est prise en charge lorsque XmNlabelType est XmSTRING ou XmPIXMAP_AND_STRING.
PIXMAP
Le widget transfère XmNlabelPixmap sous le type DRAWABLE. Cette cible est prise en charge lorsque XmNlabelType est XmPIXMAP ou XmPIXMAP_AND_STRING.
STRING
Le widget transfère XmNlabelString sous le type STRING. Cette cible est prise en charge lorsque XmNlabelType est XmSTRING ou XmPIXMAP_AND_STRING.
TEXT
Si XmNlabelString est entièrement convertible dans l'encodage de la locale, le widget transfère XmNlabelString dans l'encodage de la locale. Sinon, le widget transfère XmNlabelString sous le type COMPOUND_TEXT. Cette cible n'est prise en charge que lorsque XmNlabelType est XmSTRING ou XmPIXMAP_AND_STRING.
_MOTIF_CLIPBOARD_TARGETS
Le widget transfère, sous le type ATOM, une liste des cibles qu'il prend en charge pour la sélection CLIPBOARD. Lorsque XmNlabelType est XmSTRING ou XmPIXMAP_AND_STRING, celles-ci incluent les cibles suivantes :

STRING, si XmNlabelString est entièrement convertible en STRING
Lorsque XmNlabelType est XmPIXMAP ou XmPIXMAP_AND_STRING, les cibles incluent PIXMAP.
_MOTIF_COMPOUND_STRING
Le widget transfère XmNlabelString sous forme de chaîne composite en format Byte Stream. Cette cible est prise en charge lorsque XmNlabelType est XmSTRING ou XmPIXMAP_AND_STRING.
_MOTIF_EXPORT_TARGETS
Le widget transfère, sous le type ATOM, une liste des cibles à utiliser comme valeur de XmNexportTargets du DragContext lors d'un transfert par glisser-déposer. Lorsque XmNlabelType est XmSTRING ou XmPIXMAP_AND_STRING, cela inclut _MOTIF_COMPOUND_STRING, COMPOUND_TEXT, UTF8_STRING, l'encodage de la locale, STRING, TEXT, BACKGROUND et FOREGROUND. Lorsque XmNlabelType est XmPIXMAP ou XmPIXMAP_AND_STRING, cela inclut PIXMAP, BACKGROUND et FOREGROUND.

XmNaccelerator
Définit l'accélérateur sur un widget bouton dans un menu, qui active un bouton visible ou invisible, mais géré, à partir du clavier. Cette ressource est une chaîne qui décrit un ensemble de modificateurs et la touche qui peut être utilisée pour sélectionner le bouton. Le format de cette chaîne est identique à celui utilisé par le gestionnaire de traductions, à l'exception qu'un seul événement peut être spécifié et seuls les événements KeyPress sont autorisés.
Les accélérateurs pour les boutons ne sont pris en charge que pour les PushButtons et les ToggleButtons dans les panneaux de menu déroulants et contextuels.
XmNacceleratorText
Spécifie le texte affiché pour l'accélérateur. Le texte est affiché à côté de la chaîne de caractères ou du pixmap du libellé. La direction de sa disposition dépend de la ressource XmNlayoutDirection du widget. Le texte de l'accélérateur pour les boutons n'est affiché que pour les PushButtons et les ToggleButtons dans les menus déroulants et contextuels.
XmNalignment
Spécifie l'alignement du libellé pour le texte ou le pixmap.
XmALIGNMENT_BEGINNING (alignement à gauche)
Entraîne l'alignement vertical des côtés gauches des lignes de texte sur le bord gauche de la fenêtre du widget. Pour un pixmap, son côté gauche est aligné verticalement sur le bord gauche de la fenêtre du widget.
XmALIGNMENT_CENTER (alignement au centre)
Entraîne l'alignement vertical des centres des lignes de texte au centre de la fenêtre du widget. Pour un pixmap, son centre est aligné verticalement sur le centre de la fenêtre du widget.
XmALIGNMENT_END (alignement à droite)
Entraîne l'alignement vertical des côtés droits des lignes de texte sur le bord droit de la fenêtre du widget. Pour un pixmap, son côté droit est aligné verticalement sur le bord droit de la fenêtre du widget.
Les descriptions précédentes pour le texte sont correctes lorsque XmNlayoutDirection est XmLEFT_TO_RIGHT. Lorsque cette ressource est XmRIGHT_TO_LEFT, les descriptions pour XmALIGNMENT_BEGINNING et XmALIGNMENT_END sont inversées.
Si le parent est un RowColumn dont la ressource XmNisAligned est True, XmNalignment est forcé à la même valeur que XmNentryAlignment du RowColumn si le XmNrowColumnType du RowColumn est XmWORK_AREA ou si le widget est une sous-classe de XmLabel. Sinon, la valeur par défaut est XmALIGNMENT_CENTER.
XmNfontList
Spécifie la police du texte utilisé dans le widget. XmNfontList est obsolète et existe pour la compatibilité avec les versions précédentes. Vous devriez maintenant utiliser XmNrenderTable au lieu de XmNfontList. Si les deux sont spécifiés, la table de rendu aura la priorité. Si XmNfontList est NULL lors de l'initialisation, Label recherche dans sa hiérarchie parente un ancêtre qui est une sous-classe de la classe de widget XmBulletinBoard, VendorShell, ou XmMenuShell. Si un tel ancêtre est trouvé, Label initialise XmNfontList avec le XmNlabelFontList du widget ancêtre. De même, les sous-classes de boutons de Label initialisent XmNfontList avec le XmNbuttonFontList du widget ancêtre. (Actuellement, toutes les sous-classes de Label sont des sous-classes de boutons.) Si aucun ancêtre de ce type n'est trouvé, la valeur par défaut dépend de l'implémentation. Référez-vous à XmFontList(3) pour plus d'informations sur la création et la structure d'une liste de polices.
XmNlabelInsensitivePixmap
Spécifie un pixmap utilisé comme face de bouton si XmNlabelType est XmPIXMAP et que le bouton est insensible. La valeur par défaut, XmUNSPECIFIED_PIXMAP, affiche un libellé vide.
XmNlabelPixmap
Spécifie le pixmap lorsque XmNlabelType est XmPIXMAP ou XmPIXMAP_AND_STRING. La valeur par défaut, XmUNSPECIFIED_PIXMAP, affiche un libellé vide.
XmNlabelString
Spécifie la chaîne de caractères composée lorsque XmNlabelType est XmSTRING ou XmPIXMAP_AND_STRING. Si cette valeur est NULL, elle est initialisée par la conversion du nom du widget en une chaîne de caractères composée. Référez-vous à XmString(3) pour plus d'informations sur la création et la structure des chaînes de caractères composées.
XmNlabelType
Spécifie le type de libellé.
XmSTRING
Affiche du texte à l'aide de XmNlabelString.
XmPIXMAP
Affiche un pixmap à l'aide de XmNlabelPixmap ou
XmPIXMAP_AND_STRING
Affiche du texte et un pixmap à l'aide de XmNlabelPixmap ou XmNlabelInsensitivePixmap et XmNlabelString.
XmNmarginBottom
Spécifie la quantité d'espace entre le bas du texte du libellé et le haut de la marge inférieure définie par XmNmarginHeight. Ceci peut être modifié par les sous-classes de Label. Par exemple, CascadeButton peut augmenter ce champ pour faire de la place pour le pixmap en cascade.
XmNmarginHeight
Spécifie une quantité égale d'espace au-dessus de la marge définie par XmNmarginTop et en dessous de la marge définie par XmNmarginBottom. XmNmarginHeight spécifie la quantité d'espace entre le bord supérieur de la marge définie par XmNmarginTop et le bord inférieur de l'ombre supérieure, et la quantité d'espace entre le bord inférieur de la marge spécifiée par XmNmarginBottom et le bord supérieur de l'ombre inférieure.
XmNmarginLeft
Spécifie la quantité d'espace entre le bord gauche du texte du libellé et le côté droit de la marge gauche (spécifiée par XmNmarginWidth). Ceci peut être modifié par les sous-classes de Label. Par exemple, ToggleButton peut augmenter ce champ pour faire de la place pour l'indicateur de bascule et pour l'espace entre l'indicateur et le libellé. Que cela s'applique effectivement au côté gauche ou droit du libellé dépend de la valeur de la ressource XmNlayoutDirection.
XmNmarginRight
Spécifie la quantité d'espace entre le bord droit du texte du libellé et le côté gauche de la marge droite (spécifiée par XmNmarginWidth). Ceci peut être modifié par les sous-classes de Label. Par exemple, CascadeButton peut augmenter ce champ pour faire de la place pour le pixmap en cascade. Que cela s'applique effectivement au côté gauche ou droit du libellé dépend de la valeur de la ressource XmNlayoutDirection.
XmNmarginTop
Spécifie la quantité d'espace entre le haut du texte du libellé et le bas de la marge supérieure spécifiée par XmNmarginHeight. Ceci peut être modifié par les sous-classes de Label. Par exemple, CascadeButton peut augmenter ce champ pour faire de la place pour le pixmap en cascade.
XmNmarginWidth
Spécifie une quantité égale d'espace à gauche de la marge définie par XmNmarginLeft et à droite de la marge définie par XmNmarginRight. XmNmarginWidth spécifie la quantité d'espace entre le bord gauche de la marge définie par XmNmarginLeft et le bord droit de l'ombre gauche, et la quantité d'espace entre le bord droit de la marge spécifiée par XmNmarginRight et le bord gauche de l'ombre droite.
XmNmnemonic
Offre à l'utilisateur un moyen alternatif d'activer un bouton. Un bouton dans une MenuBar, un panneau de menu contextuel ou un panneau de menu déroulant peut avoir un mnémonique.
Cette ressource contient un keysym tel qu'il est listé dans la table des keysyms X11. Le premier caractère de la chaîne de libellé qui correspond exactement au mnémonique dans le jeu de caractères spécifié dans XmNmnemonicCharSet est souligné lorsque le bouton est affiché.
Lorsqu'un mnémonique a été spécifié, l'utilisateur active le bouton en appuyant sur la touche mnémonique pendant que le bouton est visible. Si le bouton est un CascadeButton dans une MenuBar et que la MenuBar n'a pas le focus, l'utilisateur doit utiliser le modificateur MAlt tout en appuyant sur le mnémonique. L'utilisateur peut activer le bouton en appuyant soit sur la touche mnémonique décalée, soit sur la touche non décalée.
XmNmnemonicCharSet
Spécifie le jeu de caractères du mnémonique pour le libellé. La valeur par défaut est XmFONTLIST_DEFAULT_TAG.
XmNpixmapPlacement
L'emplacement du pixmap par rapport au libellé textuel. Cette ressource peut prendre l'une des valeurs suivantes : XmPIXMAP_TOP, XmPIXMAP_BOTTOM, XmPIXMAP_LEFT, et XmPIXMAP_RIGHT. Un convertisseur de type a été enregistré qui convertit les chaînes suivantes : "top", "bottom", "left", et "right".
XmNpixmapTextPadding
La quantité d'espace à laisser entre le pixmap et la chaîne de libellé.
XmNrecomputeSize
Spécifie une valeur booléenne qui indique si le widget se rétrécit ou s'agrandit pour accommoder son contenu (chaîne de libellé ou pixmap) à la suite d'une ressource XtSetValues dont la valeur changerait la taille du widget. Si True, le widget se rétrécit ou s'agrandit pour s'adapter exactement à la chaîne de libellé ou au pixmap. Si False, le widget n'essaie jamais de changer de taille par lui-même.
XmNrenderTable
Spécifie la table de rendu associée à XmNlabelString. Si cette valeur est NULL lors de l'initialisation, Label recherche dans sa hiérarchie parente un ancêtre qui détient le trait XmQTspecifyRenderTable. Si un tel ancêtre est trouvé, Label initialise XmNrenderTable à la valeur XmLABEL_RENDER_TABLE du widget ancêtre. De même, les sous-classes de boutons de Label initialisent XmNrenderTable à la valeur XmBUTTON_RENDER_TABLE du widget ancêtre. (Notez que toutes les sous-classes actuelles de Label sont des sous-classes de boutons.) Si aucun ancêtre de ce type n'est trouvé, la valeur par défaut dépend de l'implémentation. Si une liste de polices et une table de rendu sont toutes deux spécifiées, la table de rendu aura la priorité. Voir XmRenderTable(3) pour plus d'informations sur la création et la structure d'une table de rendu.
XmNstringDirection
Est une ressource synthétique pour définir XmNlayoutDirection. Les valeurs pour cette ressource sont XmSTRING_DIRECTION_L_TO_R et XmSTRING_DIRECTION_R_TO_L. Voir la description de la ressource XmNlayoutDirection. La ressource XmNstringDirection est obsolète au profit de XmNlayoutDirection, mais est conservée ici pour la compatibilité descendante.

Routines d'action

Les routines d'action XmLabel sont :

Help():
Dans un MenuPane Popup ou Pulldown, annule le post de tous les menus de la hiérarchie des menus et, lorsque la politique de focalisation du clavier du shell est XmEXPLICIT, restaure la focalisation du clavier sur le widget qui avait la focalisation avant l'entrée dans le système de menu. Appelle les callbacks pour XmNhelpCallback s'il y en a. S'il n'y a pas de callbacks d'aide pour ce widget, cette action appelle les callbacks d'aide de l'ancêtre le plus proche qui en a.
MenuEscape():
Dans une MenuBar, désarme le CascadeButton et le menu et, lorsque la politique de focalisation du clavier du shell est XmEXPLICIT, restaure la focalisation du clavier sur le widget qui avait la focalisation avant l'entrée dans le menu.
Dans un MenuPane Pulldown de niveau supérieur provenant d'une MenuBar, annule le post du menu, désarme le CascadeButton de la MenuBar et la MenuBar, et, lorsque la politique de focalisation du clavier du shell est XmEXPLICIT, restaure la focalisation du clavier sur le widget qui avait la focalisation avant l'entrée dans la MenuBar. Dans d'autres MenuPanes Pulldown, annule le post du menu et déplace la focalisation vers son CascadeButton.
Dans un MenuPane Popup, annule le post du menu et, lorsque la politique de focalisation du clavier du shell est XmEXPLICIT, restaure la focalisation du clavier sur le widget à partir duquel le menu a été posté.
MenuTraverseDown():
Si l'élément de menu actuel a un sous-menu et se trouve dans une MenuBar, cette action poste le sous-menu, désarme l'élément de menu actuel et arme le premier élément de menu traversable du sous-menu.
Si l'élément de menu actuel se trouve dans un MenuPane, cette action désarme l'élément de menu actuel et arme l'élément situé en dessous. Cette action effectue un wraparound dans le MenuPane. La direction du wraparound dépend de la ressource XmNlayoutDirection.
MenuTraverseLeft():
Lorsque l'élément de menu actuel se trouve dans une MenuBar, cette action désarme l'élément actuel et arme l'élément de la MenuBar situé à gauche. Cette action effectue un wraparound dans la MenuBar.
Dans les MenuPanes, si l'élément de menu actuel ne se trouve pas sur le bord gauche d'un MenuPane, cette action désarme l'élément actuel et arme l'élément situé à sa gauche. Si l'élément de menu actuel se trouve sur le bord gauche d'un sous-menu attaché à un élément de MenuBar, cette action annule le post du sous-menu et traverse vers l'élément de MenuBar à gauche, en effectuant un wraparound si nécessaire. Si cet élément de MenuBar a un sous-menu, il poste le sous-menu et arme le premier élément traversable du sous-menu. Si l'élément de menu actuel se trouve sur le bord gauche d'un sous-menu non directement attaché à un élément de MenuBar, cette action annule uniquement le post du sous-menu actuel.
Dans les MenuPanes Popup ou déclipsables, lorsque l'élément de menu actuel se trouve sur le bord gauche, cette action effectue un wraparound dans le MenuPane. Si l'élément de menu actuel se trouve sur le bord gauche du MenuPane et pas dans la rangée supérieure, cette action effectue un wraparound vers l'élément de menu le plus à droite de la rangée supérieure. Si l'élément de menu actuel se trouve dans le coin supérieur gauche, cette action effectue un wraparound vers le contrôle de déclipsage, s'il est présent, sinon elle effectue un wraparound vers l'élément de menu le plus à droite en bas du MenuPane. La description précédente s'applique lorsque la direction horizontale de XmNlayoutDirection est XmLEFT_TO_RIGHT. Si la direction horizontale de XmNlayoutDirection est XmRIGHT_TO_LEFT, alors ce qui suit s'applique.
Si l'élément de menu actuel se trouve dans une MenuBar, cette action désarme l'élément actuel et arme l'élément de la MenuBar situé à gauche. Cette action effectue un wraparound dans la MenuBar.
Dans les MenuPanes, si l'élément de menu actuel est un CascadeButton, alors cette action poste son sous-menu associé. Si l'élément de menu actuel n'est pas un CascadeButton et ne se trouve pas sur le bord gauche d'un MenuPane, cette action désarme l'élément actuel et arme l'élément à sa gauche, en effectuant un wraparound si nécessaire. Si l'élément de menu actuel n'est pas un CascadeButton et se trouve sur le bord gauche d'un sous-menu qui est un descendant d'une MenuBar, alors cette action annule le post de tous les sous-menus et traverse vers l'élément de MenuBar à gauche. Si cet élément de MenuBar a un sous-menu, il poste le sous-menu et arme le premier élément traversable du sous-menu.
Dans les menus Popup ou déclipsables, si l'élément de menu actuel n'est pas un CascadeButton et se trouve sur le bord gauche d'une rangée (sauf la rangée inférieure), cette action effectue un wraparound vers l'élément de menu le plus à droite de la rangée inférieure. Si l'élément de menu actuel n'est pas un CascadeButton et se trouve dans le coin inférieur gauche d'un MenuPane Popup ou Pulldown, cette action effectue un wraparound vers le contrôle de déclipsage, s'il est présent, sinon elle effectue un wraparound vers l'élément de menu le plus à droite en haut du MenuPane.
MenuTraverseRight():

MenuTraverseUp():
Lorsque l'élément de menu actuel se trouve dans un MenuPane, cette action désarme l'élément de menu actuel et arme l'élément situé au-dessus. Cette action effectue un wraparound dans le MenuPane. La direction du wraparound dépend de la ressource XmNlayoutDirection.
ProcessDrag():
Déplace le contenu d'un Label, identifié lorsque BTransfer est pressé. Cette action définit le XmNconvertProc du DragContext sur une fonction qui appelle les procédures XmNconvertCallback, éventuellement plusieurs fois, pour la sélection _MOTIF_DROP. Cette action est indéfinie pour les Labels utilisés dans un système de menu.
