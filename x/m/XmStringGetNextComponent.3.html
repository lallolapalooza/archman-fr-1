NOM

XmStringGetNextComponent — Une fonction de chaîne composée qui retourne le type et la valeur du prochain composant d'une chaîne composée

SYNTAXE

#include <Xm/Xm.h>
XmStringComponentType XmStringGetNextComponent(
XmStringContext context,
char **text,
XmStringTag *tag,
XmStringDirection *direction,
XmStringComponentType *unknown_tag,
unsigned short *unknown_length,
unsigned char **unknown_value);

DESCRIPTION

Cette fonction est obsolète et existe pour assurer la compatibilité avec les versions antérieures. Elle est remplacée par XmStringGetNextTriple. XmStringGetNextComponent retourne le type et la valeur du prochain composant de la chaîne composée identifiée par context. Les composants sont retournés un par un. Au retour, seuls certains paramètres de sortie seront valides ; ceux-ci peuvent être déterminés en examinant le type de composant retourné. Le tableau suivant décrit les retours valides pour chaque type de composant.

Champs valides Type de composant
tag XmSTRING_COMPONENT_LOCALE, XmSTRING_COMPONENT_TAG
text XmSTRING_COMPONENT_LOCALE_TEXT, XmSTRING_COMPONENT_TEXT, XmSTRING_COMPONENT_WIDECHAR_TEXT
direction XmSTRING_COMPONENT_DIRECTION
unknown_tag, unknown_length, unknown_value XmSTRING_COMPONENT_LAYOUT_POP, XmSTRING_COMPONENT_LAYOUT_PUSH, XmSTRING_COMPONENT_TAB, XmSTRING_COMPONENT_RENDITION_BEGIN, XmSTRING_COMPONENT_RENDITION_END
aucun champ valide XmSTRING_COMPONENT_SEPARATOR, XmSTRING_COMPONENT_END, XmSTRING_COMPONENT_UNKNOWN

Notez que plusieurs composants produisent une valeur de retour de XmSTRING_COMPONENT_UNKNOWN. Les données retournées par ces composants sont retournées dans les champs unknown_tag, unknown_length et unknown_value. Cette incohérence apparente est conçue pour accueillir les anciennes applications qui peuvent ne pas être équipées pour gérer les types de composants plus récents de Motif version 2.0 et ultérieures. Par conséquent, l'utilisation de cette procédure n'est pas recommandée. Utilisez plutôt la procédure XmStringGetNextTriple, qui fournit toutes les fonctionnalités de XmStringGetNextComponent et est entièrement compatible avec les types de composants plus récents.

Si la valeur de retour de la fonction est XmSTRING_COMPONENT_LOCALE_TEXT ou XmSTRING_COMPONENT_TEXT, la fonction alloue de l'espace pour contenir le text retourné. Si la fonction retourne XmSTRING_COMPONENT_FONTLIST_ELEMENT_TAG ou XmSTRING_COMPONENT_TAG, alors la fonction alloue de l'espace pour contenir le tag retourné. L'application est responsable de la gestion de l'espace alloué. L'application peut récupérer l'espace alloué en appelant XtFree.

context
Spécifie la structure de contexte de chaîne qui a été allouée par la fonction XmStringInitContext.
text
Spécifie un pointeur vers une chaîne terminée par NULL.
tag
Spécifie un pointeur vers le composant de tag associé au texte. La valeur XmFONTLIST_DEFAULT_TAG identifie un segment de texte local.
direction
Spécifie un pointeur vers la direction du texte.
unknown_tag
Spécifie un pointeur vers le tag d'un composant inconnu.
unknown_length
Spécifie un pointeur vers la longueur d'un composant inconnu.
unknown_value
Spécifie un pointeur vers la valeur d'un composant inconnu.

RETOUR

Retourne le type de composant trouvé. Consulter la page de référence XmStringComponentType(3) pour une liste des types de composants.

LIENS CONNEXES

XmStringComponentType(3), XmStringCreate(3), et XmStringInitContext(3).
