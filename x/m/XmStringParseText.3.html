NOM

XmStringParseText — Fonction qui convertit une chaîne de caractères en une chaîne composée

SYNTAXE

#include <Xm/Xm.h>
XmString XmStringParseText(
XtPointer text,
XtPointer *text_end,
XmStringTag tag,
XmTextType type,
XmParseTable parse_table,
Cardinal parse_count,
XtPointer call_data);

DESCRIPTION

XmStringParseText convertit les caractères spécifiés dans text en composants correspondants dans la chaîne composée retournée. La chaîne composée résultante se compose d'au moins un composant d'étiquette de locale ou de jeu de caractères et d'une série de composants texte XmString et d'autres composants. La conversion s'effectue selon les informations d'analyse contenues dans parse_table. Voir le Motif Programmer's Guide pour plus d'informations sur l'analyse et les tables d'analyse.

•
Si type est XmCHARSET_TEXT, l'étiquette associée tag est interprétée comme un nom de jeu de caractères. Si tag a une valeur NULL, un composant de jeu de caractères dont la valeur est le résultat du mappage de XmFONTLIST_DEFAULT_TAG est créé.
•
Si type est XmMULTIBYTE_TEXT ou XmWIDECHAR_TEXT, l'étiquette associée tag est interprétée comme un nom d'environnement linguistique. Si tag a une valeur NULL, un composant de locale dont la valeur est _MOTIF_DEFAULT_LOCALE est créé. Si type est XmMULTIBYTE_TEXT ou XmWIDECHAR_TEXT, tag doit être NULL ou _MOTIF_DEFAULT_LOCALE.

XmStringParseText analyse également la chaîne à la recherche de caractères qui correspondent à des entrées dans parse_table. Chaque fois qu'une correspondance est trouvée, le texte jusqu'à ce point est concaténé avec le composant mappé.

text
Spécifie la chaîne terminée par NULL contenant des caractères d'un type déterminé par type. Elle est mise à jour pour pointer après le dernier caractère analysé.
text_end
Spécifie un pointeur dans text. Si NULL est fourni au paramètre text_end, alors XmStringParseText analyse text jusqu'à ce qu'un caractère NULL soit rencontré, ou jusqu'à ce qu'elle atteigne un point dans text où elle est dirigée pour s'arrêter (par exemple, par une parse_proc). Sinon, la valeur fournie au paramètre text_end est le pointeur dans text où l'analyse doit s'arrêter, et le caractère retourné est celui où l'analyse s'est arrêtée.
tag
Spécifie l'étiquette à utiliser pour créer le résultat. Le type d'étiquette de chaîne créée (jeu de caractères ou locale) dépend du type de texte et de la valeur tag fournie. Si la valeur tag est NULL et si type indique qu'une étiquette de chaîne de jeu de caractères doit être créée, l'étiquette de chaîne a la valeur qui est le résultat du mappage de XmFONTLIST_DEFAULT_TAG. Si type indique une étiquette de chaîne de locale, l'étiquette de chaîne a la valeur _MOTIF_DEFAULT_LOCALE.
type
Spécifie le type de texte et le type d'étiquette. Si une étiquette de locale doit être créée, type a une valeur de soit XmMULTIBYTE_TEXT, soit XmWIDECHAR_TEXT. Si type a la valeur XmCHARSET_TEXT, une étiquette de jeu de caractères sera créée.
parse_table
Spécifie la table d'analyse à utiliser pour rechercher les caractères à convertir en d'autres composants de chaîne composée.
parse_count
Spécifie le nombre d'entrées dans parse_table.
call_data
Spécifie les données à passer aux procédures d'analyse.

RETOUR

Retourne une nouvelle chaîne composée. La fonction alloue de l'espace pour contenir la chaîne composée retournée. Lorsque l'application n'a plus besoin de la chaîne composée retournée, l'application doit appeler XmStringFree.

VOIR AUSSI

XmString(3), XmStringFree(3), XmParseTable(3), XmParseMapping(3).
