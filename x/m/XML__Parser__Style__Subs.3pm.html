Paquet: perl-xml-parser

Licences: GPL, PerlArtistic

Parser::Style::Subs(3) Documentation Perl fournie par l'utilisateur Parser::Style::Subs(3)

NOM

XML::Parser::Style::Subs - pont pour gérer les rappels d'éléments

SYNOPIS

use XML::Parser;
my $p = XML::Parser->new(Style => 'Subs', Pkg => 'MySubs');
$p->parsefile('foo.xml');

{
  package MySubs;

  sub foo {
    # début de la balise foo
  }

  sub foo_ {
    # fin de la balise foo
  }
}

DESCRIPTION

Chaque fois qu'un élément commence, une sous-routine portant ce nom dans le paquet spécifié par l'option Pkg est appelée avec les mêmes paramètres que ceux reçus par le gestionnaire Start.

Chaque fois qu'un élément se termine, une sous-routine dont le nom est complété par un trait de soulignement ("_") est appelée avec les mêmes paramètres que ceux reçus par le gestionnaire End.

Rien de spécial n'est retourné par parse.
