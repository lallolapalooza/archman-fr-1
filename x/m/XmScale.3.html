NOM

XmScale — La classe du widget Scale

SYNTAXE

#include <Xm/Scale.h>

DESCRIPTION

Scale est utilisé par une application pour indiquer une valeur dans une plage de valeurs, et il permet à l'utilisateur d'entrer ou de modifier une valeur dans la même plage.

Un Scale a une région rectangulaire allongée similaire à un ScrollBar. Un curseur à l'intérieur de cette région indique la valeur actuelle le long du Scale. L'utilisateur peut également modifier la valeur du Scale en déplaçant le curseur à l'intérieur de la région rectangulaire du Scale. Un Scale peut également inclure un ensemble d'étiquettes situé à l'extérieur de la région du Scale. Celles-ci peuvent indiquer la valeur relative à diverses positions le long du scale. L'emplacement de cette étiquette dépend de la ressource XmNlayoutDirection du widget.

Un Scale peut être en mode entrée/sortie ou en mode sortie uniquement. Un Scale entrée/sortie peut avoir sa valeur définie par l'application et aussi être modifié par l'utilisateur avec le curseur. Un Scale en sortie uniquement est utilisé strictement comme indicateur de la valeur actuelle de quelque chose et ne peut pas être modifié interactivement par l'utilisateur. La ressource XmNeditable de XmScale spécifie si l'utilisateur peut modifier interactivement la valeur du Scale.

L'utilisateur peut spécifier des ressources dans un fichier de ressources pour le gadget créé automatiquement qui contient le titre du widget Scale. Le nom du gadget est Title. L'emplacement du titre dépend de la ressource XmNlayoutDirection du widget. La direction du titre est basée sur la direction de mise en page du widget.

Scale utilise le trait XmQTspecifyRenderTable et détient le trait XmQTtransfer.

Comportement de transfert de données

Scale prend en charge le glisser-déposer de la représentation de la valeur du Scale à partir du Scale lorsque la valeur est affichée et lorsque la valeur de la ressource XmNenableUnselectableDrag de XmDisplay est définie à True.

En tant que source de données, Scale prend en charge les cibles suivantes et les conversions associées de données vers ces cibles :

COMPOUND_TEXT
Le widget transfère une représentation textuelle de XmNvalue en tant que type COMPOUND_TEXT.
UTF8_STRING
Le widget transfère une représentation textuelle de XmNvalue en tant que type UTF8_STRING.
STRING
Le widget transfère une représentation textuelle de XmNvalue en tant que type STRING.
_MOTIF_CLIPBOARD_TARGETS
Le widget transfère, en tant que type ATOM, une liste des cibles qu'il prend en charge pour la sélection CLIPBOARD. Celles-ci incluent STRING, COMPOUND_TEXT et UTF8_STRING.
_MOTIF_EXPORT_TARGETS
Le widget transfère, en tant que type ATOM, une liste des cibles à utiliser comme valeur de XmNexportTargets du DragContext dans un transfert glisser-déposer. Celles-ci incluent STRING, COMPOUND_TEXT et UTF8_STRING.

En tant que source de données, Scale prend également en charge les cibles Motif standard suivantes :

BACKGROUND
Le widget transfère XmNbackground en tant que type PIXEL.
CLASS
Le widget trouve le premier shell dans la hiérarchie des widgets qui a une propriété WM_CLASS et transfère le contenu sous forme de texte dans la locale actuelle.
CLIENT_WINDOW
Le widget trouve le premier shell dans la hiérarchie des widgets et transfère sa fenêtre en tant que type WINDOW.
COLORMAP
Le widget transfère XmNcolormap en tant que type COLORMAP.
FOREGROUND
Le widget transfère XmNforeground en tant que type PIXEL.
NAME
Le widget trouve le premier shell dans la hiérarchie des widgets qui a une propriété WM_NAME et transfère le contenu sous forme de texte dans la locale actuelle.
TARGETS
Le widget transfère, en tant que type ATOM, une liste des cibles qu'il prend en charge. Celles-ci incluent les cibles standard de cette liste. Celles-ci incluent également STRING, COMPOUND_TEXT et UTF8_STRING.
TIMESTAMP
Le widget transfère l'horodatage utilisé pour acquérir la sélection en tant que type INTEGER.
_MOTIF_RENDER_TABLE
Le widget transfère XmNrenderTable s'il existe, sinon la table de rendu de texte par défaut, en tant que type STRING.
_MOTIF_ENCODING_REGISTRY
Le widget transfère son registre d'encodage en tant que type STRING. La valeur est une liste d'éléments séparés par NULL sous forme de paires tag-encodage. Cette cible symbolise la cible de transfert pour le registre d'encodage de segment Motif. Les applications et les widgets peuvent utiliser ce registre pour enregistrer les formats d'encodage de texte pour les tags de table de rendu spécifiés. Les applications accèdent à ce registre en appelant XmRegisterSegmentEncoding et XmMapSegmentEncoding.

CALLBACKS

Le widget Scale a un rappel spécial appelé XmNdragCallback. Ce rappel est appelé lorsque l'utilisateur déplace le curseur du Scale. Les applications peuvent utiliser ce rappel pour effectuer des actions pendant que le curseur est en mouvement.

Le rappel XmNvalueChangedCallback est appelé lorsque la valeur du Scale change. Ce rappel est appelé à la fin du déplacement du curseur, et non pendant le déplacement.

Les applications peuvent utiliser le rappel XmNworkValueCallback, qui est appelé lorsque le curseur est déplacé. Les applications peuvent utiliser ce rappel pour valider la nouvelle valeur avant qu'elle ne soit appliquée.

Notez que les rappels XmNdragCallback et XmNvalueChangedCallback sont mutuellement exclusifs. Si le rappel XmNdragCallback est défini, le rappel XmNvalueChangedCallback ne sera pas appelé.

XmNdragCallback

Ce rappel est appelé lorsque l'utilisateur déplace le curseur du Scale. Les données du rappel incluent :

reason
XmCR_DRAG
event
Le pointeur de l'événement X sous-jacent.
value
La valeur actuelle du Scale.

XmNvalue_Changed_Callback

Ce rappel est appelé lorsque la valeur du Scale change.

reason
XmCR_VALUE_CHANGED
event
Le pointeur de l'événement X sous-jacent.
value
La nouvelle valeur du Scale.

XmNwork_Value_Callback

Ce rappel est appelé lorsque le curseur est déplacé et que la valeur peut être validée.

reason
XmCR_WORK_VALUE
event
Le pointeur de l'événement X sous-jacent.
value
La valeur proposée du Scale.

RELATIONS ENTRE WIDGETS

Le widget Scale est un gestionnaire de contraintes. Les widgets enfants d'un Scale sont les widgets de la barre de défilement et de l'étiquette du titre. Le comportement de mise en page de ces widgets est déterminé par les ressources XmNlayoutDirection et XmNclipWindow.

XmNconvertCallback
Spécifie une liste de rappels appelés lorsque le curseur est invité à convertir une sélection. Le type de la structure dont l'adresse est passée à ces rappels est XmConvertCallbackStruct. La raison est XmCR_OK.
XmNdecimalPoints
Spécifie le nombre de décimales à décaler lors de l'affichage de la valeur du curseur. Par exemple, une valeur de curseur de 2 350 et une valeur XmNdecimalPoints de 2 entraînent une valeur affichée de 23,50. La valeur ne doit pas être négative.
XmNdragCallback
Spécifie la liste des rappels qui sont appelés lorsque la position du curseur change pendant son déplacement. La raison envoyée par le rappel est XmCR_DRAG.
XmNeditable
Spécifie comment la barre de défilement du curseur réagit aux entrées utilisateur. Cette ressource peut avoir les valeurs True ou False, comme suit :
True
Permet à la barre de défilement d'être sensible aux entrées utilisateur. C'est la valeur par défaut.
False
Rend la barre de défilement du curseur insensible aux entrées utilisateur. Le visuel n'est pas grisé. Cette valeur serait principalement utilisée en mode XmTHERMOMETER.
Lorsque XmNeditable est utilisé sur un widget, il définit le site de dépôt à XmDROP_SITE_ACTIVE.
XmNfontList
Spécifie la liste de polices à utiliser pour la chaîne de texte de titre spécifiée par XmNtitleString, et pour l'étiquette affichée lorsque XmNshowValue est True. La liste de polices est une structure obsolète, conservée uniquement pour la compatibilité avec les versions antérieures de Motif. Voir la ressource XmNrenderTable.
XmNhighlightOnEnter
Spécifie si le rectangle de mise en surbrillance est dessiné lorsque le curseur entre dans le widget. Si la politique de focalisation du shell est XmEXPLICIT, cette ressource est ignorée et le widget est mis en surbrillance lorsqu'il a le focus. Si la politique de focalisation du shell est XmPOINTER et si cette ressource est True, le rectangle de mise en surbrillance est dessiné lorsque le curseur entre dans le widget. Si la politique de focalisation du shell est XmPOINTER et si cette ressource est False, le rectangle de mise en surbrillance n'est pas dessiné lorsque le curseur entre dans le widget. La valeur par défaut est False.
XmNhighlightThickness
Spécifie la taille du rectangle de dessin de bordure du curseur utilisé pour le dessin de la mise en surbrillance à l'entrée de la fenêtre et du parcours.
XmNmaximum
Spécifie la valeur maximale du curseur. XmNmaximum doit être supérieur à XmNminimum.
XmNminimum
Spécifie la valeur minimale du curseur. XmNmaximum doit être supérieur à XmNminimum.
XmNorientation
Affiche le curseur verticalement ou horizontalement. Cette ressource peut avoir les valeurs XmVERTICAL et XmHORIZONTAL.
XmNprocessingDirection
Spécifie si la valeur de XmNmaximum se trouve sur le côté droit ou gauche de XmNminimum pour les curseurs horizontaux, ou au-dessus ou en dessous de XmNminimum pour les curseurs verticaux. Cette ressource peut avoir les valeurs XmMAX_ON_TOP, XmMAX_ON_BOTTOM, XmMAX_ON_LEFT et XmMAX_ON_RIGHT. Si le curseur est orienté verticalement, la valeur par défaut est XmMAX_ON_TOP. Si le XmScale est orienté horizontalement, la valeur par défaut dépend de la ressource XmNlayoutDirection du widget.
XmNrenderTable
Spécifie la table de rendu à utiliser pour la chaîne de texte de titre spécifiée par XmNtitleString, et pour l'étiquette affichée lorsque XmNshowValue est True. Si cette valeur est NULL lors de l'initialisation, la hiérarchie parente est recherchée pour un ancêtre qui détient le trait XmQTspecifyRenderTable. Si un tel ancêtre est trouvé, la table de rendu est initialisée à la valeur XmLABEL_RENDER_TABLE du widget ancêtre. Si aucun ancêtre de ce type n'est trouvé, la valeur par défaut dépend de l'implémentation. Si une liste de polices (XmNfontList) et une table de rendu sont toutes deux spécifiées, la table de rendu aura la priorité. Référez-vous à XmRenderTable(3) pour plus d'informations sur la création et la structure d'une table de rendu.
XmNscaleHeight
Spécifie la hauteur de la zone du curseur. La valeur doit être dans le type d'unité spécifié (la valeur par défaut est les pixels). Si aucune valeur n'est spécifiée, une hauteur par défaut est calculée.
XmNscaleMultiple
Spécifie le montant à déplacer le curseur lorsque l'utilisateur effectue une action qui déplace le curseur par un incrément multiple. La valeur par défaut est (XmNmaximum - XmNminimum) divisé par 10, avec un minimum de 1.
XmNscaleWidth
Spécifie la largeur de la zone du curseur. La valeur doit être dans le type d'unité spécifié (la valeur par défaut est les pixels). Si aucune valeur n'est spécifiée, une largeur par défaut est calculée.
XmNshowArrows
Spécifie si les flèches sont affichées et comment elles doivent être affichées. Cette ressource peut prendre les valeurs suivantes :
XmEACH_SIDE
Indique qu'une flèche est affichée à chaque extrémité du curseur de la barre de défilement.
XmMAX_SIDE
Indique qu'une flèche est affichée du côté XmNmaximum du curseur de la barre de défilement.
XmMIN_SIDE
Indique qu'une flèche est affichée du côté XmNminimum du curseur de la barre de défilement.
XmNONE
Indique qu'aucune flèche n'est affichée.
XmNONE est la valeur par défaut.
XmNshowValue
Spécifie si une étiquette pour la valeur actuelle du curseur doit être affichée à côté du curseur. Si la valeur est XmNEAR_SLIDER, la valeur actuelle du curseur est affichée. Si la valeur est XmNONE, aucune valeur de curseur n'est affichée. Si la valeur est XmNEAR_BORDER, la valeur actuelle du curseur est affichée près de la bordure.
XmNsliderMark
Spécifie la forme dans laquelle le curseur doit être affiché. Cette ressource peut prendre les valeurs suivantes :
XmETCHED_LINE
Spécifie le curseur comme une ligne gravée. C'est la valeur par défaut lorsque XmNslidingMode est XmSLIDER.
XmNONE
Spécifie le curseur comme un rectangle mis en avant-plan. C'est la valeur par défaut lorsque XmNslidingMode est XmTHERMOMETER et que la barre de défilement du curseur est insensible aux entrées utilisateur (XmNeditable est False.
XmROUND_MARK
Spécifie le curseur comme un cercle ombré. C'est la valeur par défaut lorsque XmNslidingMode est XmTHERMOMETER et que la barre de défilement du curseur est sensible aux entrées utilisateur (XmNeditable est True.
XmTHUMB_MARK
Spécifie le curseur comme une série de trois lignes gravées centrées au milieu du curseur.
XmNslidingMode
Spécifie le mode dans lequel le curseur fonctionne. Il existe deux modes possibles :
XmSLIDER
Permet au curseur de se déplacer librement entre les extrémités minimale et maximale de l'échelle. C'est la valeur par défaut.
XmTHERMOMETER
Force le curseur à être ancré à un côté de la zone de la gouttière.
XmNsliderVisual
Spécifie la couleur du visuel du curseur. Cette ressource peut prendre les valeurs suivantes :
XmBACKGROUND_COLOR
Spécifie que le visuel du curseur est dans la couleur d'arrière-plan.
XmFOREGROUND_COLOR
Spécifie que le visuel du curseur est dans la couleur de premier plan.
XmSHADOWED_BACKGROUND
Spécifie que le visuel du curseur est dans la couleur d'arrière-plan, avec une ombre. C'est la valeur par défaut lorsque la ressource XmNslidingModel est XmSLIDER.
XmTROUGH_COLOR
Spécifie que le visuel du curseur est dans la couleur de la gouttière. C'est la valeur par défaut lorsque la ressource XmNslidingModel est XmTHERMOMETER.
XmNtitleString
Spécifie la chaîne de texte de titre qui doit apparaître dans la fenêtre du widget curseur.
XmNvalue
Spécifie la position actuelle du curseur le long de l'échelle, entre XmNminimum et XmNmaximum. La valeur est contrainte d'être comprise dans ces limites inclusives. La valeur initiale de cette ressource est la plus grande des deux valeurs : 0 (zéro) et XmNminimum.
XmNvalueChangedCallback
Spécifie la liste des rappels qui est appelée lorsque la valeur du curseur a changé. La raison envoyée par le rappel est XmCR_VALUE_CHANGED.

XmScale - Provides a vertical or horizontal slider widget that allows a user to select a value within a range

#include <Xm/Scale.h>

The XmScale widget is a slider that allows the user to select a value from a range. The scale widget displays a slider in a trough. A scale can be oriented vertically or horizontally. The scale widget can display a label and a numeric value associated with the slider's current position. If the scale widget displays a numeric value, it can be edited.

The scale widget provides a convenient way to input numeric values. It is useful for applications that require the user to select values from a range, such as setting volume levels, adjusting colors, or choosing a font size.

The XmScale widget is a subclass of the XmManager widget.

The XmScale widget is a subclass of XmManager.

A scale widget is created by calling:

widget = XmCreateScale(parent, name, arglist);

where:

parent
Specifies the parent widget.
name
Specifies the name of the new scale widget.
arglist
Specifies the resource list, which is a pointer to an argument list that determines the resources for the widget.
