NOM

XmPushButtonGadget — Classe du widget PushButtonGadget

SYNTAXE

#include <Xm/PushBG.h>

DESCRIPTION

PushButtonGadget émet des commandes au sein d'une application. Il est constitué d'une étiquette textuelle ou d'une pixmap entourée d'une ombre de bordure. Lorsque PushButtonGadget est sélectionné, l'ombre change pour donner l'apparence que le PushButtonGadget a été enfoncé. Lorsque PushButtonGadget est désélectionné, l'ombre change pour donner l'apparence que le PushButtonGadget est sorti.

Le comportement par défaut associé à un PushButtonGadget dans un menu dépend du type de système de menu dans lequel il réside. Par défaut, <Btn1> contrôle le comportement du PushButtonGadget. De plus, <Btn3> contrôle le comportement du PushButtonGadget s'il réside dans un système de PopupMenu. Le bouton de souris réel utilisé est déterminé par son parent RowColumn.

L'épaisseur d'une deuxième ombre peut être spécifiée avec la ressource XmNshowAsDefault. Si elle a une valeur non nulle, les ressources XmNmarginLeft, XmNmarginRight, XmNmarginTop et XmNmarginBottom de Label peuvent être modifiées pour accommoder la deuxième ombre.

Si une valeur initiale est spécifiée pour XmNarmPixmap mais pas pour XmNlabelPixmap, la valeur de XmNarmPixmap est utilisée pour XmNlabelPixmap.

PushButtonGadget utilise les traits XmQTmenuSystem et XmQTspecifyRenderTable, et détient les traits XmQactivatable, XmQTmenuSavvy et XmQTtakesDefault.

Classes

PushButtonGadget hérite du comportement, des ressources et des traits de Object, RectObj, XmGadget et XmLabelGadget.

Le pointeur de classe est xmPushButtonGadgetClass.

Le nom de classe est XmPushButtonGadget.

RESOURCES

XmNarmColor
Specifies the color to be used to fill the armed button. XmNfillOnArm must be set to True for this resource to have an effect. The default for a color display is a color between the background and the bottom shadow color. For a monochrome display, the default is set to the foreground color, and any text in the label appears in the background color when the button is armed.
XmNarmPixmap
Specifies the pixmap to be used as the button face if XmNlabeltype is XmPIXMAP or XmPIXMAP_AND_STRING and PushButtonGadget is armed. This resource is disabled when the PushButtonGadget is in a menu.
XmNdefaultButtonShadowThickness
This resource specifies the width of the default button indicator shadow. If this resource is 0 (zero), the width of the shadow comes from the value of the XmNshowAsDefault resource. If this resource is greater than zero, the XmNshowAsDefault resource is only used to specify whether this button is the default. The default value is the initial value of XmNshowAsDefault.
XmNdisarmCallback
Specifies the list of callbacks that is called when the PushButtonGadget is disarmed. PushButtonGadget is disarmed when the user presses and releases the active mouse button while the pointer is inside that gadget. For this callback, the reason is XmCR_DISARM.
XmNfillOnArm
Forces the PushButtonGadget to fill the background of the button with the color specified by XmNarmColor when the button is armed and when this resource is set to True. If it is False, only the top and bottom shadow colors are switched. When the PushButtonGadget is in a menu, this resource is ignored and assumed to be False.
XmNmultiClick
If a button click is followed by another button click within the time span specified by the display's multiclick time, and this resource is set to XmMULTICLICK_DISCARD, the second click is not processed. If this resource is set to XmMULTICLICK_KEEP, the event is processed and click_count is incremented in the callback structure. When the button is in a menu, the default is XmMULTICLICK_DISCARD; otherwise, for a button not in a menu, the default value is XmMULTICLICK_KEEP.
XmNshowAsDefault
If XmNdefaultButtonShadowThickness is greater than 0 (zero), a value greater than zero in this resource specifies to mark this button as the default button. If XmNdefaultButtonShadowThickness is 0, a value greater than 0 in this resource specifies to mark this button as the default button with the shadow thickness specified by this resource. The space between the shadow and the default shadow is equal to the sum of both shadows. The default value is 0. When the Display resource XmNdefaultButtonEmphasis has a value of XmEXTERNAL_HIGHLIGHT (the default), PushButton draws the location cursor outside of the outer shadow. When this resource has a value of XmINTERNAL_HIGHLIGHT, the highlight is drawn between the inner and outer shadows. When this value is not 0, the Label XmNmarginLeft, XmNmarginRight, XmNmarginTop, and XmNmarginBottom resources may be modified to accommodate the second shadow. This resource is disabled when the PushButton is in a menu.

Informations sur le rappel

Un pointeur vers la structure suivante est passé à chaque rappel :

typedef struct
{
        int reason;
        XEvent * event;
        int click_count;
} XmPushButtonCallbackStruct;
reason
Indique la raison pour laquelle le rappel a été invoqué.
event
Pointe vers l' XEvent qui a déclenché le rappel.
click_count
Valide uniquement lorsque la raison est XmCR_ACTIVATE. Elle contient le nombre de clics dans la dernière séquence de clics multiples si la ressource XmNmultiClick est définie sur XmMULTICLICK_KEEP ; sinon, elle contient 1. Le rappel d'activation est invoqué pour chaque clic si XmNmultiClick est défini sur XmMULTICLICK_KEEP.

Comportement

XmPushButtonGadget inclut le comportement de XmGadget. XmPushButtonGadget inclut le comportement de traversée de menu de XmLabelGadget. Le comportement supplémentaire pour XmPushButtonGadget est décrit dans la liste suivante.

<Btn2Down>:
Fait glisser le contenu de l'étiquette d'un PushButtonGadget, identifié lorsque <Btn2> est enfoncé. Cette action est indéfinie pour les PushButtonGadgets utilisés dans un système de menu.
<Btn1Down>:
Cette action arme le PushButtonGadget.
Dans un menu, cette action annule tous les menus affichés par le menu parent du PushButtonGadget, désactive la traversée au clavier pour le menu et active la traversée à la souris pour le menu. Elle dessine l'ombre dans l'état armé. Sauf si le bouton est déjà armé, elle appelle les rappels XmNarmCallback.
Si le bouton n'est pas dans un menu, cette action dessine l'ombre dans l'état armé. Si XmNfillOnArm est défini sur True, il remplit le bouton avec la couleur spécifiée par XmNarmColor. Si XmNlabelType est XmPIXMAP ou XmPIXMAP_AND_STRING, le XmNarmPixmap est utilisé pour la face du bouton. Elle appelle les rappels XmNarmCallback.
<Btn1>(2+):
Si XmNmultiClick est XmMULTICLICK_DISCARD, cette action ne fait rien.
Si XmNmultiClick est XmMULTICLICK_KEEP, cette action dessine l'ombre dans l'état armé. Si le bouton n'est pas dans un menu et si XmNfillOnArm est défini sur True, il remplit le bouton avec la couleur spécifiée par XmNarmColor. Si XmNlabelType est XmPIXMAP ou XmPIXMAP_AND_STRING, le XmNarmPixmap est utilisé pour la face du bouton. Cette action appelle les rappels XmNarmCallback.
<Btn1Up>:
Dans un menu, cette action annule tous les menus de la hiérarchie du menu et active le PushButtonGadget. Elle appelle les rappels XmNactivateCallback, puis les rappels XmNdisarmCallback.
Si le PushButtonGadget n'est pas dans un menu, cette action dessine l'ombre dans l'état non armé. Si XmNfillOnArm est défini sur True, la couleur de fond revient à la couleur non armée. Si XmNlabelType est XmPIXMAP ou XmPIXMAP_AND_STRING, le XmNlabelPixmap est utilisé pour la face du bouton. Si le pointeur est toujours à l'intérieur du bouton, cette action appelle les rappels pour XmNactivateCallback et XmNdisarmCallback.
<Btn1Up>(2+):
Si XmNmultiClick est XmMULTICLICK_DISCARD, cette action ne fait rien.
Si XmNmultiClick est XmMULTICLICK_KEEP, cette acti
on incrémente click_count dans la structure de rappel et dessine l'ombre dans l'état non armé. Si le bouton ne se trouve pas dans un menu et si XmNfillOnArm est défini sur True, la couleur d'arrière-plan revient à la couleur non armée. Si XmNlabelType est XmPIXMAP ou XmPIXMAP_AND_STRING, XmNlabelPixmap est utilisé pour la face du bouton. Si le pointeur se trouve dans le PushButtonGadget, cette action appelle les rappels pour XmNactivateCallback et XmNdisarmCallback.
<Touche><osfActivate>:
Dans un menu, cette action dépublie tous les menus de la hiérarchie des menus, à moins que le bouton ne soit déjà armé, et appelle les rappels XmNarmCallback, XmNactivateCallback et XmNdisarmCallback. En dehors d'un menu, KActivate n'a aucun effet. Pour les PushButtonGadgets en dehors d'un menu, si le parent est un gestionnaire, cette action transmet l'événement au parent.
<Touche><osfSelect>:
Dans un menu, cette action dépublie tous les menus de la hiérarchie des menus, à moins que le bouton ne soit déjà armé, et appelle les rappels XmNarmCallback. Cette action appelle les rappels XmNactivateCallback et XmNdisarmCallback.
En dehors d'un menu, cette action dessine l'ombre dans l'état armé et, si XmNfillOnArm est défini sur True, remplit le bouton avec la couleur spécifiée par XmNarmColor. Si XmNlabelType est XmPIXMAP ou XmPIXMAP_AND_STRING, XmNarmPixmap est utilisé pour la face du bouton. Cette action appelle les rappels XmNarmCallback.
En dehors d'un menu, cette action organise également les éléments suivants, immédiatement ou plus tard : l'ombre est dessinée dans l'état non armé et, si XmNfillOnArm est défini sur True, la couleur d'arrière-plan revient à la couleur non armée. Si XmNlabelType est XmPIXMAP ou XmPIXMAP_AND_STRING, XmNlabelPixmap est utilisé pour la face du bouton. Les rappels XmNactivateCallback et XmNdisarmCallback sont appelés.
<Touche><osfHelp>:
Dans un Pulldown ou Popup MenuPane, dépublie tous les menus de la hiérarchie des menus et restaure le focus clavier vers le widget qui avait le focus avant l'entrée dans le système de menus. Cette action appelle les rappels pour XmNhelpCallback s'ils existent. S'il n'y a pas de rappels d'aide pour ce widget, cette action appelle les rappels d'aide de l'ancêtre le plus proche qui en possède.
<Touche><osfCancel>:
Dans un Pulldown MenuPane de niveau supérieur provenant d'une MenuBar, dépublie le menu, désarme le MenuBar CascadeButton et la MenuBar, et restaure le focus clavier vers le widget qui avait le focus avant l'entrée dans la MenuBar. Dans d'autres Pulldown MenuPanes, dépublie le menu.
Dans un Popup MenuPane, dépublie le menu et restaure le focus clavier vers le widget à partir duquel le menu a été publié. Pour un PushButtonGadget en dehors d'un menu, si le parent est un gestionnaire, cette action transmet l'événement au parent.
<Entrée>:
Dans un menu, si la navigation au clavier est activée, cette action ne fait rien. Sinon, elle dessine l'ombre dans l'état armé et appelle les rappels XmNarmCallback.
Si le PushButtonGadget n'est pas dans un menu et que le curseur quitte puis rentre dans le PushButtonGadget pendant que le bouton est pressé, cette action dessine l'ombre dans l'état armé. Si XmNfillOnArm est défini sur True, elle remplit également le bouton avec la couleur spécifiée par XmNarmColor. Si XmNlabelType est XmPIXMAP ou XmPIXMAP_AND_STRING, XmNarmPixmap est utilisé pour la face du bouton.
<Sortie>:
Dans un menu, si la navigation au clavier est activée, cette action ne fait rien. Sinon, elle dessine l'ombre dans l'état non armé et appelle les rappels XmNdisarmCallback.
Si le PushButtonGadget n'est pas dans un menu et que le curseur quitte le PushButtonGadget pendant que le bouton est pressé, cette action dessine l'ombre dans l'état non armé. Si XmNfillOnArm est défini sur True, la couleur d'arrière-plan revient à la couleur non armée. Si XmNlabelType est XmPIXMAP ou XmPIXMAP_AND_STRING, XmNlabelPixmap est utilisé pour la face du bouton.

Liaisons virtuelles

Les liaisons pour les touches virtuelles sont spécifiques au vendeur. Pour plus d'informations sur les liaisons pour les boutons et les touches virtuelles, voir VirtualBindings(3).
