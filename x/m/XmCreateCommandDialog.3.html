NOM

XmCreateCommandDialog — Fonction de création pratique pour la boîte de dialogue Command

SYNTAXE

#include <Xm/Command.h>
Widget XmCreateCommandDialog(
Widget parent,
String name,
ArgList arglist,
Cardinal argcount);

DESCRIPTION

XmCreateCommandDialog est une fonction pratique qui crée une boîte de dialogue (DialogShell) et un enfant non géré de type Command pour cette boîte de dialogue. Une boîte de dialogue Command est utilisée pour saisir des commandes à traiter.

Utilisez XtManageChild pour faire apparaître la boîte de dialogue Command (en passant le widget Command comme paramètre) ; utilisez XtUnmanageChild pour la faire disparaître.

XmCreateCommandDialog force la valeur de la ressource Shell XmNallowShellResize à True.

parent
Spécifie l'identifiant du widget parent
name
Spécifie le nom du widget créé
arglist
Spécifie la liste d'arguments
argcount
Spécifie le nombre de paires attribut/valeur dans la liste d'arguments (arglist)

Pour une définition complète de Command et de ses ressources associées, consultez XmCommand(3).

VALEUR DE RETOUR

Retourne l'identifiant du widget Command.

VOIR AUSSI

XmCommand(3).
