NOM

XmTextCut — Fonction de texte qui copie la sélection primaire dans le presse-papiers et supprime le texte sélectionné

SYNOPSIS

#include <Xm/Text.h>
Boolean XmTextCut(
Widget widget,
Time time);

DESCRIPTION

XmTextCut copie le texte sélectionné dans la sélection primaire dans le presse-papiers, puis supprime le texte sélectionné dans la sélection primaire. Cette routine appelle le XmNvalueChangedCallback du widget et les callbacks de vérification, soit XmNmodifyVerifyCallback, soit XmNmodifyVerifyCallbackWcs, ou les deux. Si les deux listes de callbacks de vérification sont enregistrées, les procédures de la liste XmNmodifyVerifyCallback sont exécutées en premier et les données résultantes sont transmises aux callbacks XmNmodifyVerifyCallbackWcs.

Cette routine appelle les procédures XmNconvertCallback, potentiellement plusieurs fois, avec le membre selection de la XmConvertCallbackStruct défini sur CLIPBOARD et avec le membre parm défini sur XmMOVE. Si le transfert réussit, cette routine appelle ensuite les procédures XmNconvertCallback pour la sélection CLIPBOARD et la cible DELETE.

widget
Spécifie l'ID du widget Text.
time
Spécifie l'heure du serveur à laquelle la valeur de sélection doit être modifiée. Ce devrait être l'heure de l'événement qui a déclenché cette demande. Une source d'horodatage valide est la fonction XtLastTimestampProcessed().

Pour une définition complète de Text et de ses ressources associées, voir XmText(3).

RETOUR

Cette fonction renvoie False si la sélection primaire est NULL, si le widget ne possède pas la sélection primaire, si la fonction ne parvient pas à acquérir la propriété de la sélection du presse-papiers, ou si aucune donnée n'est placée dans le presse-papiers. Sinon, elle renvoie True.

VOIR AUSSI
