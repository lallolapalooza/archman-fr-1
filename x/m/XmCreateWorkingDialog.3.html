NOM

XmCreateWorkingDialog — Fonction de création pratique pour le WorkingDialog de MessageBox

SYNOPSIS

#include <Xm/MessageB.h>
Widget XmCreateWorkingDialog(
Widget parent,
String name,
ArgList arglist,
Cardinal argcount);

DESCRIPTION

XmCreateWorkingDialog est une fonction de création pratique qui crée une DialogShell et un enfant MessageBox non géré de la DialogShell. Un WorkingDialog informe les utilisateurs qu'une opération longue est en cours et leur permet d'annuler l'opération. Il comprend un symbole, un message et trois boutons. Le symbole par défaut est un sablier. Les libellés des boutons par défaut sont OK, Annuler et Aide.

Utilisez XtManageChild pour afficher le WorkingDialog (en passant le MessageBox comme paramètre de widget) ; utilisez XtUnmanageChild pour le masquer.

XmCreateWorkingDialog force la valeur de la ressource Shell XmNallowShellResize à True.

parent
Spécifie l'identifiant du widget parent.
name
Spécifie le nom du widget créé.
arglist
Spécifie la liste des arguments.
argcount
Spécifie le nombre de paires attribut/valeur dans la liste des arguments (arglist).

Pour une définition complète de MessageBox et de ses ressources associées, voir XmMessageBox(3).

VALEUR DE RETOUR

Retourne l'identifiant du widget MessageBox.

VOIR AUSSI

XmMessageBox(3).
