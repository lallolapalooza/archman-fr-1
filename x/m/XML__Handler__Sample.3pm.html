XML::Handler::Sample(3) Documentation Perl Contribuée par l'Utilisateur XML::Handler::Sample(3)

NOM

XML::Handler::Sample - un gestionnaire PerlSAX trivial

SYNTAXE

use XML::Parser::PerlSAX;
use XML::Handler::Sample;
$my_handler = XML::Handler::Sample->new;
XML::Parser::PerlSAX->new->parse(Source => { SystemId => 'REC-xml-19980210.xml' },
                                 Handler => $my_handler);

DESCRIPTION

"XML::Handler::Sample" est un gestionnaire PerlSAX trivial qui affiche le nom de chaque événement qu'il reçoit. La source de "XML::Handler::Sample" liste toutes les méthodes de gestionnaire PerlSAX actuellement connues.

"XML::Handler::Sample" est destiné aux auteurs de modules Perl qui souhaitent examiner des modules de gestionnaire PerlSAX d'exemple. "XML::Handler::Sample" peut servir de modèle pour écrire vos propres modules de gestionnaire PerlSAX. "XML::Handler::Sample" est dans le domaine public et peut être utilisé à toute fin sans restriction.
