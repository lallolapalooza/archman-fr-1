NOM

XmGetTearOffControl — Appel de bibliothèque RowColumn qui obtient l'ID du widget pour le contrôle de détachement dans un menu

SYNTAXE

#include <Xm/RowColumn.h>
Widget XmGetTearOffControl(
Widget menu);

DESCRIPTION

XmGetTearOffControl fournit à l'application les moyens d'obtenir l'ID du widget du contrôle de détachement créé en interne dans un menu détachable.

RowColumn crée un contrôle de détachement pour un PulldownMenu ou un PopupMenu lorsque la ressource XmNtearOffModel est initialisée ou définie sur XmTEAR_OFF_ENABLED. Le contrôle de détachement est un widget qui apparaît comme le premier élément du menu. L'utilisateur détache le menu à l'aide d'événements de souris ou de clavier dans le contrôle de détachement.

Le contrôle de détachement a un comportement similaire à celui d'un séparateur. Une fois que l'application a obtenu l'ID du widget du contrôle de détachement, elle peut définir des ressources pour spécifier l'apparence du contrôle. L'application ou l'utilisateur peut également définir ces ressources dans un fichier de ressources en utilisant le nom du contrôle, qui est TearOffControl. Pour une liste des ressources que l'application ou l'utilisateur peut définir, voir XmRowColumn(3).

menu
Spécifie l'ID du widget du menu déroulant ou popup RowColumn

Pour plus d'informations sur les menus détachables et une définition complète de RowColumn et de ses ressources associées, voir XmRowColumn(3).

RETOUR

Retourne l'ID du widget pour le contrôle de détachement, ou NULL s'il n'existe aucun contrôle de détachement. Une application ne doit pas supposer que le widget retourné sera d'une classe particulière.
