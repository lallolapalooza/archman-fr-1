NOM

XmClipboardEndCopy — Une fonction de presse-papiers qui achève la copie de données dans le presse-papiers

SYNTAXE

#include <Xm/CutPaste.h>
int XmClipboardEndCopy (display, window, item_id)
        Display * display;
        Window  window;
        long    item_id;
(void)

DESCRIPTION

XmClipboardEndCopy verrouille le presse-papiers pour empêcher l'accès par d'autres applications, place les données dans la structure de données du presse-papiers et déverrouille le presse-papiers. Les éléments de données copiés dans le presse-papiers par XmClipboardCopy ne sont pas réellement entrés dans la structure de données du presse-papiers jusqu'à l'appel à XmClipboardEndCopy.

Cette fonction libère également le stockage temporaire qui a été alloué par XmClipboardStartCopy, qui doit être appelé avant XmClipboardEndCopy. Cette dernière fonction ne doit pas être appelée si XmClipboardCancelCopy a été appelée.

display
Spécifie un pointeur vers la structure Display qui a été retournée lors d'un appel précédent à XOpenDisplay ou XtDisplay.
window
Spécifie l'identifiant de fenêtre d'un widget qui relie la fenêtre de l'application au presse-papiers. L'identifiant de fenêtre du widget peut être obtenu via XtWindow. La même instance d'application doit passer le même identifiant de fenêtre à chaque fonction de presse-papiers qu'elle appelle.
item_id
Spécifie le numéro attribué à cet élément de données, qui a été retourné par un appel précédent à XmClipboardStartCopy.

RETOUR

XmClipboardSuccess
La fonction a réussi.
XmClipboardLocked
La fonction a échoué car le presse-papiers était verrouillé par une autre application. L'application peut continuer à appeler la fonction à nouveau avec les mêmes paramètres jusqu'à ce que le verrou disparaisse. Cela donne à l'application l'opportunité de demander si l'utilisateur souhaite continuer d'essayer ou abandonner l'opération.
XmClipboardFail
La fonction a échoué car XmClipboardStartCopy n'a pas été appelée.

LIEN CONNEXE

XmClipboardCancelCopy(3), XmClipboardCopy(3) et XmClipboardStartCopy(3).
