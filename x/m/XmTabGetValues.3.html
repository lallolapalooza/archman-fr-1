NOM

XmTabGetValues — Une fonction de commodité qui renvoie les valeurs des tabulations

SYNOPSIS

#include <Xm/Xm.h>
float XmTabGetValues(
XmTab tab,
unsigned char *units,
XmOffsetModel *offset,
unsigned char *alignment,
char **decimal);

DESCRIPTION

XmTabGetValues prend une structure XmTab, renvoie le nombre à virgule flottante défini comme valeur de la tabulation, puis définit les valeurs pour les arguments units, offset, alignment et decimal lorsqu'ils ne sont pas NULL. Le nombre à virgule flottante renvoyé représente la distance de décalage du rendu du segment XmString associé à tab. Le décalage est par rapport au début du rendu ou à la tabulation précédente, selon le réglage du modèle de décalage offset. La distance utilisera le type d'unité pointé par unit.

tab
Spécifie la tabulation dont on veut obtenir la valeur.
units
Spécifie un pointeur vers le type d'unité.
offset
Spécifie un pointeur vers le modèle de décalage.
alignment
Spécifie un pointeur vers le type d'alignement.
decimal
Spécifie un pointeur vers le caractère multibyte utilisé comme point décimal.

RETOUR

Renvoie un nombre à virgule flottante qui est défini comme valeur de la tabulation.

VOIR AUSSI

XmTab(3).
