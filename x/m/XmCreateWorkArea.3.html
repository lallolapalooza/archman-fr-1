NOM

XmCreateWorkArea — Une fonction qui crée une zone de travail RowColumn

SYNTAXE

#include <Xm/RowColumn.h>
Widget XmCreateWorkArea(
Widget parent,
String name,
ArgList arglist,
Cardinal argcount);

DESCRIPTION

XmCreateWorkArea crée une instance d'un widget RowColumn et retourne l'identifiant de widget associé. Le widget est créé avec XmNrowColumnType défini sur XmWORK_AREA.

parent
Spécifie l'identifiant du widget parent
name
Spécifie le nom du widget créé
arglist
Spécifie la liste d'arguments
argcount
Spécifie le nombre de paires attribut/valeur dans la liste d'arguments (arglist)

Pour une définition complète de RowColumn et de ses ressources associées, consultez XmRowColumn(3).

RETOUR

Retourne l'identifiant du widget RowColumn.

VOIR AUSSI

XmCreateRadioBox(3), XmCreateSimpleCheckBox(3), XmCreateSimpleRadioBox(3), XmRowColumn(3), XmVaCreateSimpleCheckBox(3), et XmVaCreateSimpleRadioBox(3).
