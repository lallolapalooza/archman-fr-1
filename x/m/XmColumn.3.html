NOM

XmColumn — La classe du widget XmColumn

SYNTAXE

#include <Xm/Column.h>

DESCRIPTION

XmColumn affiche ses enfants empilés dans une colonne, chacun avec une étiquette facultative associée : les étiquettes apparaissent dans une colonne et les enfants dans une autre. Ceci est utile pour afficher, par exemple, des champs de saisie de données étiquetés. Il peut également afficher toutes les paires étiquette-enfant dans une orientation horizontale. Ce widget offre plusieurs ressources de contrainte qui permettent de spécifier les caractéristiques de l'étiquette, telles que l'affichage de texte ou de pixmap, l'alignement du texte, la police à utiliser, etc. Il offre également plusieurs ressources pour définir les valeurs par défaut des enfants qui ne spécifient pas de valeurs spécifiques.

CLASSES

XmColumn hérite des comportements et ressources de Core, Composite, Constraint, XmManager, et XmBulletinBoard.

Le pointeur de classe est xmColumnWidgetClass.

Le nom de la classe est XmColumn.

Le programmeur peut également définir les valeurs des ressources pour les classes héritées afin de définir les attributs de ce widget. XmColumn(3)

NAME

XmColumn — A RowColumn widget that arranges its children in a single column.

SYNOPSIS

                    Widget child;
                    Widget parent;
                    
                    child = XmCreateColumn(parent, name, arglist, argCount);
                    child = XmVaCreateColumn(parent, name, varArgs);
                    child = XmVaCreateManagedColumn(parent, name, varArgs);

DESCRIPTION

The XmColumn widget is a specialized XmRowColumn widget. It arranges its children in a single column. The children are laid out vertically, one after the other. The XmColumn widget uses the default behavior of the XmRowColumn widget, with the exception of the XmNorientation resource, which is set to XmVERTICAL and cannot be changed.

The XmColumn widget supports all of the resources of XmRowColumn, in addition to the resources listed below.

Widget Resources

The XmColumn widget inherits the resources of XmRowColumn. The following resources are specific to XmColumn:

XmNdefaultAlignment
Specifies the default alignment for labels within the column. Valid values are the same as those for XmNalignment in XmLabel.
XmNdefaultFontList
Specifies the default font list to be used for labels within the column. If this resource is not set, the column inherits the font list from its parent.
XmNdefaultRenderTable
Specifies the default render table to be used for labels within the column. If this resource is not set, the column inherits the render table from its parent.
XmNdefaultPixmap
Specifies the default pixmap to be used for labels within the column. This pixmap is used if the child widget does not have its own XmNlabelPixmap resource set.
XmNdefaultString
Specifies the default string to be used for labels within the column. This string is used if the child widget does not have its own XmNlabelString resource set.
XmNdefaultType
Specifies the default type of the label within the column. Valid values are XmSTRING and XmPIXMAP.
XmNfillStyle
Specifies how children should be displayed within the column.
XmFILL_RAGGED
Children are displayed at their natural size.
XmFILL_FLUSH
Children are stretched to fill the entire width of the column.
If set to XmFILL_UNSPECIFIED, the value of the XmNdefaultFillStyle resource is used.
XmNshowDefaultLabels
Specifies whether or not the default labels for the children should be displayed.
XmNstretchable
Specifies whether the children should expand to fill the available space when the XmColumn widget is resized vertically. If this resource is True, the children will resize proportionately. If it is False, only the last child will resize to fill the extra space.
