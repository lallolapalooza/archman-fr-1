XML::LibXML::Attr(3) Documentation Perl contribuée par l'utilisateur XML::LibXML::Attr(3)

NOM

XML::LibXML::Attr - Classe d'attribut XML::LibXML

SYNTAXE

use XML::LibXML;
# Seules les méthodes spécifiques aux nœuds d'attribut sont listées ici,
# voir la page de manuel XML::LibXML::Node pour les autres méthodes
$attr = XML::LibXML::Attr->new($nom [,$valeur]);
$chaine = $attr->getValue();
$chaine = $attr->value;
$attr->setValue( $chaine );
$noeud = $attr->getOwnerElement();
$attr->setNamespace($nsURI, $prefix);
$booleen = $attr->isId;
$chaine = $attr->serializeContent;

DESCRIPTION

Ceci est l'interface pour manipuler les attributs comme des nœuds ordinaires. Le nommage de la classe s'inspire de la documentation W3C DOM.

MÉTHODES

La classe hérite de XML::LibXML::Node. La documentation des méthodes héritées n'est pas listée ici.

De nombreuses fonctions listées ici sont exhaustivement documentées dans la spécification DOM Level 3 (http://www.w3.org/TR/DOM-Level-3-Core/). Veuillez vous référer à la spécification pour une documentation détaillée.

new
$attr = XML::LibXML::Attr->new($nom [,$valeur]);

Constructeur de classe. Si vous avez besoin de travailler avec des chaînes encodées ISO, vous devriez *toujours* utiliser la méthode "createAttribute" de XML::LibXML::Document.

getValue
$chaine = $attr->getValue();

Retourne la valeur stockée pour l'attribut. Si `undef` est retourné, l'attribut n'a pas de valeur, ce qui est différent de "non spécifié".

value
$chaine = $attr->value;

Alias pour getValue()

setValue
$attr->setValue( $chaine );

Ceci est nécessaire pour définir une nouvelle valeur d'attribut. Si des chaînes encodées ISO sont passées en paramètre, le nœud doit être lié à un document, sinon l'encodage pourrait être effectué incorrectement.

getOwnerElement
$noeud = $attr->getOwnerElement();

retourne le nœud auquel l'attribut appartient. Si l'attribut n'est pas lié à un nœud, `undef` sera retourné. En surchargeant l'implémentation sous-jacente, la fonction *parentNode* retournera `undef`, au lieu de l'élément propriétaire.

setNamespace
$attr->setNamespace($nsURI, $prefix);

Cette fonction essaie de lier l'attribut à un espace de noms donné. Si $nsURI est indéfini ou vide, la fonction supprime toute association précédente de l'attribut avec un espace de noms. Si l'espace de noms n'était pas précédemment déclaré dans le contexte de l'attribut, cette fonction échouera. Dans ce cas, vous pourriez vouloir appeler setNamespace() sur l'élément propriétaire. Si l'URI de l'espace de noms n'est pas vide et déclaré dans le contexte de l'attribut, mais seulement avec un préfixe différent (non vide), alors l'attribut reste lié à l'espace de noms mais reçoit un préfixe différent de $prefix. La fonction échoue également si le préfixe est vide mais l'URI de l'espace de noms ne l'est pas (car les attributs sans préfixe ne devraient par définition appartenir à aucun espace de noms). Cette fonction retourne 1 en cas de succès, 0 sinon.

isId
$booleen = $attr->isId;

Détermine si un attribut est de type ID. Pour les documents avec une DTD, cette information n'est disponible que si le chargement/la validation DTD a été demandé. Pour les documents HTML analysés avec l'analyseur HTML, la détection d'ID est effectuée automatiquement. Dans les documents XML, tous les attributs "xml:id" sont considérés comme étant de type ID.

serializeContent($docencoding)
$chaine = $attr->serializeContent;

Cette fonction ne fait pas partie de l'API DOM. Elle retourne le contenu de l'attribut sous la forme dans laquelle il est sérialisé en XML, c'est-à-dire avec tous les méta-caractères correctement échappés et avec des références d'entités brutes (à l'exception des entités développées lors de l'analyse). La définition de l'option facultative $docencoding à 1 force l'encodage du document pour la chaîne de sortie (qui est ensuite passée à Perl sous forme de chaîne d'octets). Sinon, la chaîne est passée à Perl sous forme de caractères (encodés en UTF-8).
