NOM

XmMenuShell — La classe de widget MenuShell

SYNTAXE

#include <Xm/MenuShell.h>

DESCRIPTION

Le widget MenuShell est un widget OverrideShell personnalisé. Un widget OverrideShell contourne mwm lors de son affichage. Il est conçu spécifiquement pour contenir des panneaux de menu contextuels (Popup) ou déroulants (Pulldown).

La plupart des développeurs d'applications ne rencontrent jamais ce widget s'ils utilisent les fonctions de commodité du système de menu, XmCreatePopupMenu ou XmCreatePulldown Menu, pour créer un panneau de menu contextuel ou déroulant. Les fonctions de commodité créent automatiquement un widget MenuShell comme parent du panneau de menu. Cependant, si les fonctions de commodité ne sont pas utilisées, le programmeur de l'application doit créer le MenuShell requis. Dans ce cas, il est important de noter que le parent du MenuShell dépend du type de système de menu en cours de construction.

•
Si le MenuShell est destiné au panneau de menu contextuel de niveau supérieur, le parent du MenuShell doit être le widget à partir duquel le panneau de menu contextuel est affiché.
•
Si le MenuShell est destiné à un panneau de menu qui est déroulé à partir d'un menu contextuel ou d'un autre panneau de menu déroulant, le parent du MenuShell doit être le menu contextuel ou le panneau de menu déroulant.
•
Si le MenuShell est destiné à un panneau de menu déroulant à partir d'une barre de menu (MenuBar), le parent du MenuShell doit être la barre de menu.
•
Si le MenuShell est destiné à un panneau de menu déroulant dans un OptionMenu, le parent du MenuShell doit être le parent de l'OptionMenu.

La définition des ressources XmNheight, XmNwidth, ou XmNborderWidth pour un MenuShell ou son enfant applique cette ressource de la même manière au parent et à l'enfant. Une application doit toujours spécifier ces ressources pour l'enfant, pas pour le parent.

Pour l'enfant géré d'un MenuShell, quelle que soit la valeur de XmNallowShellResize du shell, la définition de XmNx ou XmNy applique la ressource correspondante du parent mais ne modifie pas la position de l'enfant par rapport au parent. XtGetValues pour XmNx ou XmNy de l'enfant renvoie la valeur de la ressource correspondante du parent. Les coordonnées x et y du coin extérieur supérieur gauche de l'enfant par rapport au coin intérieur supérieur gauche du parent sont toutes deux de 0 (zéro) moins la valeur de XmNborderWidth.

MenuShell utilise le trait XmQTmenuSystem et détient le trait XmQTspecifyRenderTable.

CLASSES

MenuShell hérite du comportement, des ressources et des traits de Core, Composite, Shell et OverrideShell.

Le pointeur de classe est xmMenuShellWidgetClass.

Le nom de la classe est XmMenuShell.

NOUVELLES RESSOURCES

MenuShell surcharge la ressource XmNallowShellResize dans Shell. Le tableau suivant définit un ensemble de ressources de widget utilisées par le programmeur pour spécifier des données. Le programmeur peut également définir les valeurs des ressources pour les classes héritées afin de définir les attributs de ce widget. Pour référencer une ressource par son nom ou sa classe dans un fichier .Xdefaults, supprimez le préfixe XmN ou XmC et utilisez les lettres restantes. Pour spécifier une des valeurs définies pour une ressource dans un fichier .Xdefaults, supprimez le préfixe Xm et utilisez les lettres restantes (en minuscules ou en majuscules, mais incluez les traits de soulignement entre les mots). Les codes dans la colonne d'accès indiquent si la ressource donnée peut être définie au moment de la création (C), définie à l'aide de XtSetValues (S), récupérée à l'aide de XtGetValues (G), ou n'est pas applicable (N/A).

XmNbuttonFontList
Spécifie la liste de polices utilisée pour les descendants des boutons. Voir la ressource XmNbuttonRenderTable.
XmNbuttonRenderTable
Spécifie la table de rendu utilisée pour les descendants des boutons de MenuShell. Si cette valeur est NULL à l'initialisation et si la valeur de XmNdefaultFontList n'est pas NULL, XmNbuttonRenderTable est initialisée à la valeur de XmNdefaultFontList. Si la valeur de XmNdefaultFontList est NULL, XmNbuttonRenderTable est initialisée en recherchant dans la hiérarchie des parents du widget un ancêtre qui détient le trait XmQTspecifyRenderTable. Si un tel ancêtre est trouvé, XmNbuttonRenderTable est initialisée à la valeur XmBUTTON_RENDER_TABLE du widget ancêtre. Si aucun ancêtre de ce type n'est trouvé.

RESOURCES

MenuShell defines the following resources:

XmNdefaultFont
Specifies a default font for MenuShell's descendants. This resource is obsolete and exists for compatibility with earlier releases. It has been replaced by XmNbuttonFont and XmNlabelFont.
XmNdefaultFontSet
Specifies a default font set for MenuShell's descendants. This resource is obsolete and exists for compatibility with earlier releases. It has been replaced by XmNbuttonFontSet and XmNlabelFontSet.
XmNdefaultRenderTable
Specifies the default render table for MenuShell's descendants. If this value is NULL at initialization, the parent hierarchy of the widget is searched for an ancestor that holds the XmQTspecifyRenderTable trait. If such an ancestor is found, XmNdefaultRenderTable is initialized to the XmDEFAULT_RENDER_TABLE value of the ancestor widget. If no such ancestor is found, the default is implementation dependent. Refer to XmRenderTable(3) for more information on the creation and structure of a render table.
XmNdefaultFontList
Specifies a default font list for MenuShell's descendants. This resource is obsolete and exists for compatibility with earlier releases. It has been replaced by XmNbuttonFontList and XmNlabelFontList.
XmNlabelFontList
Specifies the font list used for label descendants. See the XmNlabelRenderTable resource.
XmNlabelRenderTable
Specifies the render table used for MenuShell's label descendants (Labels and LabelGadgets). If this value is NULL at initialization and if the value of XmNdefaultFontList is not NULL, XmNlabelRenderTable is initialized to the value of XmNdefaultFontList. If the value of XmNdefaultFontList is NULL, the parent hierarchy of the widget is searched for an ancestor that holds the XmQTspecifyRenderTable trait. If such an ancestor is found, XmNlabelRenderTable is initialized to the XmLABEL_RENDER_TABLE value of the ancestor widget. If no such ancestor is found, the default is implementation dependent. Refer to XmRenderTable(3) for more information on the creation and structure of a render table.
XmNlayoutDirection
Specifies the direction in which the subwidgets, children of a widget, or other visual components are to be laid out. This policy will apply as the default layout policy for all descendants of this MenuShell.
XmNanimate
Controls whether menus will post in an animated fashion.

<BtnUp>:

Procédures d'action

Les procédures d'action XmMenuShell sont

ClearTraversal():
Désactive le parcours au clavier pour le menu, active le parcours à la souris et retire tous les menus affichés par ce menu.
MenuShellPopdownDone():
Retire la hiérarchie des menus et, lorsque la politique de focus clavier du shell est XmEXPLICIT, restaure le focus au widget qui avait le focus avant que le système de menu ne soit entré.
MenuShellPopdownOne():
Dans un MenuPane déroulant de premier niveau à partir d'une barre de menu, cette action retire le menu, désactive le bouton de cascade de la barre de menu et la barre de menu elle-même, et, lorsque la politique de focus clavier du shell est XmEXPLICIT, restaure le focus clavier au widget qui avait le focus avant que la barre de menu ne soit entrée. Dans d'autres MenuPanes déroulants, cette action retire le menu.
Dans un MenuPane contextuel, cette action retire le menu et, lorsque la politique de focus clavier du shell est XmEXPLICIT, restaure le focus clavier au widget à partir duquel le menu a été affiché.

Liaisons virtuelles

Les liaisons pour les touches virtuelles sont spécifiques au vendeur. Pour des informations sur les liaisons pour les boutons et touches virtuels, voir VirtualBindings(3).
