NOM

XmIconGadget — La classe IconGadget

SYNTAXE

#include <Xm/IconG.h>

DESCRIPTION

IconGadget est un gadget instanciable utilisé pour afficher à la fois du texte et une pixmap dans diverses combinaisons. D'autres gadgets qui possèdent le trait XmQTcontainer, tels que Container, peuvent utiliser IconGadget pour représenter des objets.

Le texte de IconGadget est une chaîne composite. Si aucun texte n'est fourni, la chaîne composite est générée à partir du nom du gadget. Le texte de IconGadget est placé par rapport au type de pixmap associée.

Selon la ressource XmNviewType, IconGadget peut afficher deux vues :

XmLARGE_ICON
La chaîne de texte IconGadget est affichée sous la pixmap, et centrée.
XmSMALL_ICON
La chaîne de texte IconGadget est placée sur le côté de la petite icône, dans la direction XmNlayoutDirection du gadget.

Un masque bitmap peut être fourni pour chaque pixmap afin de détourer la pixmap dans une forme autre qu'un rectangle. Les ressources XmNlargeIconMask et XmNsmallIconMask spécifient respectivement les masques de grande et petite icône. L'emphase visuelle pour IconGadget est fournie par la ressource XmNvisualEmphasis. Les ressources XmNdetail et XmNdetailCount d'IconGadget fournissent une vue détaillée pour les IconGadgets, permettant l'affichage de chaînes de caractères à côté de l'IconGadget. L'ordre exact de disposition des chaînes dépend du gadget conteneur associé.

IconGadget utilise les traits XmQTcontainer et XmQTspecifyRenderTable, et détient les traits XmQTcareParentVisual et XmQTcontainerItem.

Classes

IconGadget hérite du comportement, des ressources et des traits des classes Object, RectObject, et XmGadget.

Le pointeur de classe est xmIconGadgetClass.

Le nom de la classe est XmIconGadget.

Nouvelles Ressources

Le tableau suivant définit un ensemble de ressources de gadget utilisées par le programmeur pour spécifier des données. Le programmeur peut également définir les valeurs des ressources pour les classes héritées afin de définir les attributs de ce gadget. Pour référencer une ressource par son nom ou par sa classe dans un fichier .Xdefaults, supprimez le préfixe XmN ou XmC et utilisez les lettres restantes. Pour spécifier l'une des valeurs définies pour une ressource dans un fichier .Xdefaults, supprimez le préfixe Xm et utilisez les lettres restantes (en minuscules ou en majuscules, mais incluez les éventuels underscores entre les mots). Les codes dans la colonne d'accès indiquent si la ressource donnée peut être définie au moment de la création (C), définie en utilisant XtSetValues (S), récupérée en utilisant XtGetValues (G), ou si elle n'est pas applicable (N/A).

XmNalignment
Spécifie l'alignement horizontal du pixmap par rapport à l'étiquette lorsque l'icône est en vue LARGE_ICON. Les valeurs valides sont XmALIGNMENT_BEGINNING, XmALIGNMENT_CENTER et XmALIGNMENT_END.
XmNdetail
Spécifie un tableau de XmString qui constituent les informations de détail associées au gadget.
XmNdetailCount
Spécifie la taille du tableau XmNdetail.
XmNfontList
Spécifie la liste de polices associée à XmIconGadget. La liste de polices est une construction obsolète, remplacée par la table de rendu. Elle est incluse pour la compatibilité avec les versions antérieures de Motif, et pour les applications qui ne prennent pas facilement en charge les tables de rendu. La liste de polices par défaut est dérivée de la table de rendu par défaut, et si une liste de polices et une table de rendu sont spécifiées, la table de rendu a la priorité.
XmNlabelString
Spécifie la chaîne composite. Si cette valeur est NULL, elle est initialisée en convertissant le nom du gadget en une chaîne composite. Voir XmString(3) pour plus d'informations sur la création et la structure des chaînes composites.
XmNlargeIconMask
Spécifie le masque d'icône utilisé lorsque XmNviewType est XmLARGE_ICON.
XmNlargeIconPixmap
Spécifie le pixmap lorsque XmNviewType est XmLARGE_ICON. Si la valeur de cette ressource est XmUNSPECIFIED_PIXMAP, il n'y a pas de pixmap. Si un pixmap d'icône large est spécifié, et si lors de la conversion un masque associé peut être récupéré, alors la ressource XmNlargeIconMask est définie sur ce masque.
XmNmarginHeight
Spécifie la quantité d'espace vertical entre le surlignage et l'intérieur (pixmap et étiquette).
XmNmarginWidth
Spécifie la quantité d'espace horizontal entre le surlignage et l'intérieur (pixmap et étiquette).
XmNrenderTable
Spécifie la XmRenderTable du texte utilisé dans le gadget. Si XmNrenderTable est NULL lors de la création de l'IconGadget, la valeur de la ressource de la table de rendu du parent est utilisée s'il y en a une. Si le parent n'a pas de table de rendu, la hiérarchie parente du widget est parcourue pour trouver un widget qui détient le trait XmQTspecifyRenderTable. Si un tel ancêtre est trouvé, la table de rendu est initialisée à la valeur XmLABEL_RENDER_TABLE du widget ancêtre. Si aucun tel widget n'est trouvé, la valeur par défaut dépend de l'implémentation. Voir XmRenderTable(3) pour plus d'informations sur la création et la structure d'une XmRenderTable. Si une table de rendu et une liste de polices sont spécifiées, la table de rendu aura la priorité.
XmNsmallIconMask
Spécifie le masque d'icône utilisé lorsque XmNviewType est XmSMALL_ICON.
XmNsmallIconPixmap
Spécifie le pixmap lorsque XmNviewType est XmSMALL_ICON. Si la valeur de cette ressource est XmUNSPECIFIED_PIXMAP, il n'y a pas de pixmap. Si un pixmap d'icône petite est spécifié, et si lors de la conversion un masque associé peut être récupéré, alors la ressource XmNsmallIconMask est définie sur ce masque.
XmNspacing
Spécifie la quantité d'espace entre le pixmap et les parties étiquette de l'icône.
XmNviewType
Spécifie la vue (combinaison de pixmaps/texte) qui sera affichée. Si l'IconGadget est enfant d'un widget Container, alors la spécification de cette ressource sera prise à partir du Container — si XmNentryViewType du Container est soit XmLARGE_ICON soit XmSMALL_ICON, alors XmNviewType de l'IconGadget prend cette valeur ; sinon, la valeur par défaut est XmLARGE_ICON. Cette ressource est définie sur l'une des valeurs suivantes :
XmLARGE_ICON
Le pixmap spécifié par XmNlargeIconPixmap est affiché avec le XmNlabelString en dessous.
XmSMALL_ICON
Le pixmap spécifié par XmNsmallIconPixmap est affiché avec le XmNlabelString affiché dans la direction de la ressource XmNlayoutDirection.
XmNvisualEmphasis
Spécifie l'état visuel de l'IconGadget. Si l'IconGadget est dans un état sélectionné, tous les visuels sont affichés en utilisant la ressource XmNselectColor du Container. Il est défini sur l'une des valeurs suivantes :
XmSELECTED
L'IconGadget est dans l'état sélectionné et affiche les visuels appropriés.
XmNOT_SELECTED
L'IconGadget n'est pas dans l'état sélectionné.
