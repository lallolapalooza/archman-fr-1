NOM

XmFontListEntryCreate — Une fonction de liste de polices qui crée une entrée de liste de polices

SYNTAXE

#include <Xm/Xm.h>
XmFontListEntry XmFontListEntryCreate(
char *tag,
XmFontType type,
XtPointer font);

DESCRIPTION

XmFontListEntryCreate crée une entrée de liste de polices qui contient une police ou un ensemble de polices et est identifiée par une balise.

tag
Spécifie une chaîne terminée par NULL pour la balise de l'entrée de la liste de polices. La balise peut être spécifiée comme XmFONTLIST_DEFAULT_TAG, qui est utilisée pour identifier l'élément de liste de polices par défaut dans une liste de polices.
type
Spécifie si l'argument font est une structure de police ou un ensemble de polices. Les valeurs valides sont XmFONT_IS_FONT et XmFONT_IS_FONTSET.
font
Spécifie soit un XFontSet retourné par XCreateFontSet, soit un pointeur vers une XFontStruct retournée par XLoadQueryFont.

Le toolkit ne copie pas la structure de police X spécifiée par l'argument font. Par conséquent, le programmeur de l'application ne doit pas libérer XFontStruct ou XFontSet tant que toutes les listes de polices et/ou les entrées de polices qui y font référence n'ont pas été libérées.

RETOUR

Retourne une entrée de liste de polices. La fonction alloue de l'espace pour contenir l'entrée de liste de polices retournée. L'application est responsable de la gestion de l'espace alloué. L'application peut récupérer l'espace alloué en appelant XmFontListEntryFree.

CONNEXE

XmFontList(3), XmFontListAppendEntry(3), XmFontListEntryFree(3), XmFontListEntryGetFont(3), XmFontListEntryGetTag(3), XmFontListEntryLoad(3), et XmFontListRemoveEntry(3).
