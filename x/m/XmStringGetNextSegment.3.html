XmStringGetNextSegment(3)

XmStringGetNextSegment(appel de bibliothèque) XmStringGetNextSegment(appel de bibliothèque)

NOM

XmStringGetNextSegment — Une fonction de chaîne composée qui récupère les octets du segment suivant d'une chaîne composée

SYNTAXE

#include <Xm/Xm.h>
Boolean XmStringGetNextSegment(
XmStringContext context,
char **text,
XmStringTag *tag,
XmStringDirection *direction,
Boolean *separator);

DESCRIPTION

Cette routine est obsolète et existe pour des raisons de compatibilité avec les versions précédentes. Pour lire le contenu d'une chaîne composée, lisez chaque composant de la chaîne avec XmStringGetNextTriple. Cette fonction XmString renvoie le type, la longueur et la valeur du composant suivant dans la chaîne composée. XmStringGetNextSegment récupère les octets du segment suivant ; des appels répétés récupèrent les segments séquentiels. Le text, le tag et la direction du segment récupéré sont renvoyés à chaque fois. Un statut booléen est renvoyé pour indiquer si un segment valide a été analysé avec succès.

Si la fonction renvoie True, elle alloue de l'espace pour contenir le text et le tag renvoyés. L'application est responsable de la gestion de l'espace alloué. L'application peut récupérer l'espace alloué en appelant XtFree.

context
Spécifie la structure de contexte de chaîne qui a été allouée par la fonction XmStringInitContext
text
Spécifie un pointeur vers une chaîne terminée par NULL
tag
Spécifie un pointeur vers la balise de l'élément de la liste de polices associée au texte
direction
Spécifie un pointeur vers la direction du texte
separator
Spécifie si le composant suivant de la chaîne composée est un séparateur

VALEUR

Renvoie True si un segment valide est trouvé.

VOIR AUSSI

XmStringCreate(3) et XmStringInitContext(3).
