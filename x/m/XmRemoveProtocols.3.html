NOM

XmRemoveProtocols — Appel de fonction VendorShell qui supprime les protocoles du gestionnaire de protocoles et désalloue les tables internes

SYNTAXE

#include <Xm/Xm.h>
#include <Xm/Protocols.h>
void XmRemoveProtocols(
Widget shell,
Atom property,
Atom * protocols,
Cardinal num_protocols);

DESCRIPTION

XmRemoveProtocols supprime les protocoles du gestionnaire de protocoles et désalloue les tables internes. Si l'un des protocoles est actif, il mettra à jour les gestionnaires et mettra à jour la propriété si shell est réalisé.

XmRemoveWMProtocols est une interface de commodité. Elle appelle XmRemoveProtocols avec la valeur de la propriété définie sur l'atome retourné par l'interrogation de WM_PROTOCOLS.

shell
Spécifie le widget auquel la propriété de protocole est associée.
property
Spécifie la propriété de protocole.
protocols
Spécifie les atomes de protocole.
num_protocols
Spécifie le nombre d'éléments dans protocols.

Pour une définition complète de VendorShell et de ses ressources associées, voir VendorShell(3).

VOIR AUSSI

VendorShell(3), XmAddProtocols(3), XmInternAtom(3), et XmRemoveWMProtocols(3).
