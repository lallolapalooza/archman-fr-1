Sites Web

Les sites Web suivants contiennent plus d'informations sur ce module et pourraient vous être utiles. Comme toujours, en plus de ces sites Web, utilisez votre moteur de recherche préféré pour découvrir plus de ressources.

    Un moteur de recherche CPAN moderne et open-source, utile pour visualiser la POD en format HTML.

  • RT : Suivi des bogues de CPAN

    Le site RT (Request Tracker) est le système par défaut de suivi des bogues/incidents pour CPAN.

    https://rt.cpan.org/Public/Dist/Display.html?Name=XML-RSS

  • CPANTS

    CPANTS est un site qui analyse la Kwalitee (métriques de code) d'une distribution.

    http://cpants.cpanauthors.org/dist/XML-RSS

  • CPAN Testers

    CPAN Testers est un réseau de testeurs qui exécutent des tests automatisés sur les distributions CPAN téléchargées.

    http://www.cpantesters.org/distro/X/XML-RSS

  • Matrice CPAN Testers

    La Matrice CPAN Testers est un site qui fournit un aperçu visuel des résultats des tests pour une distribution sur divers Perl/plateformes.

    http://matrix.cpantesters.org/?dist=XML-RSS

  • Dépendances CPAN Testers

    Les Dépendances CPAN Testers est un site qui montre un graphique des résultats des tests de toutes les dépendances d'une distribution.
