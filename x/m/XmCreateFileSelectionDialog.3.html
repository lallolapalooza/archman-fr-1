NOM

XmCreateFileSelectionDialog — Fonction de création pratique de la boîte de dialogue FileSelectionDialog

SYNTAXE

#include <Xm/FileSB.h>
Widget XmCreateFileSelectionDialog(
Widget parent,
String name,
ArgList arglist,
Cardinal argcount);

DESCRIPTION

XmCreateFileSelectionDialog est une fonction de création pratique qui crée une DialogShell et un enfant FileSelectionBox non géré de la DialogShell. Une FileSelectionDialog sélectionne un fichier. Elle comprend les éléments suivants :

•
Un champ de texte modifiable pour le masque de répertoire
•
Une liste déroulante de noms de fichiers
•
Un champ de texte modifiable pour le fichier sélectionné
•
Des étiquettes pour la liste et les champs de texte
•
Quatre boutons

Les étiquettes de boutons par défaut sont OK, Filter, Cancel et Help. Un enfant WorkArea supplémentaire peut être ajouté à la FileSelectionBox après la création.

Utilisez XtManageChild pour afficher la FileSelectionDialog (en passant la FileSelectionBox comme paramètre widget) ; utilisez XtUnmanageChild pour la masquer.

XmCreateFileSelectionDialog force la valeur de la ressource Shell XmNallowShellResize à True.

parent
Spécifie l'ID du widget parent
name
Spécifie le nom du widget créé
arglist
Spécifie la liste des arguments
argcount
Spécifie le nombre de paires attribut/valeur dans la liste des arguments (arglist)

Pour une définition complète de FileSelectionBox et de ses ressources associées, consultez XmFileSelectionBox(3).

RETOUR

Retourne l'ID du widget FileSelectionBox.

CONNEXES

XmFileSelectionBox(3).
