NOM

XmImGetXIC — Une fonction de gestionnaire d'entrée qui obtient un XIC pour un widget

SYNTAXE

#include <Xm/XmIm.h>
XIC XmImGetXIC(
Widget widget,
XmInputPolicy input_policy,
ArgList args,
Cardinal num_args);

DESCRIPTION

XmImGetXIC crée et enregistre un contexte d'entrée X (XIC) avec les arguments spécifiés pour widget. Si XmINHERIT_POLICY est spécifié pour input_policy, un nouveau XIC ne sera créé que si requis par les arguments ou par la politique d'entrée de VendorShell. Tout XIC existant enregistré avec widget est désenregistré.

Consultez la page de référence de VendorShell pour plus de détails.

widget
Spécifie l'identifiant d'un widget pour lequel un contexte d'entrée doit être créé.
input_policy
Spécifie le type de politique d'entrée. Il accepte les valeurs suivantes :
XmINHERIT_POLICY
Hérite de la politique de VendorShell.
XmPER_WIDGET
Crée un nouveau XIC pour ce widget.
XmPER_SHELL
Crée un nouveau XIC pour le shell, si nécessaire.
args
Spécifie un paramètre XtArgList à utiliser pour la création du XIC.
num_args
Spécifie le nombre d'arguments dans le paramètre args.

RETOUR

Retourne le XIC créé. L'application est responsable de libérer le XIC retourné en appelant XmImFreeXIC.

LIENS CONNEXES

XmImSetXIC(3) et XmImFreeXIC(3).
