NOM

XML::LibXML::Reader - interface vers l'analyseur par tirage (pull parser) de libxml2

SYNOPSIS

use XML::LibXML::Reader;
my $reader = XML::LibXML::Reader->new(location => "fichier.xml")
       or die "impossible de lire le fichier.xml\n";
while ($reader->read) {
  processNode($reader);
}
sub processNode {
    my $reader = shift;
    printf "%d %d %s %d\n", ($reader->depth,
                             $reader->nodeType,
                             $reader->name,
                             $reader->isEmptyElement);
}

ou

my $reader = XML::LibXML::Reader->new(location => "fichier.xml")
       or die "impossible de lire le fichier.xml\n";
  $reader->preservePattern('//table/tr');
  $reader->finish;
  print $reader->document->toString(1);

DESCRIPTION

Ceci est une interface perl pour l'implémentation de l'analyseur par tirage (pull parser) de libxml2, xmlTextReader, disponible à l'adresse http://xmlsoft.org/html/libxml-xmlreader.html. Cette fonctionnalité nécessite au minimum libxml2-2.6.21. Les analyseurs par tirage (comme StAX en Java, ou XmlReader en C#) utilisent une approche itérative pour analyser les documents XML. Ils sont plus faciles à programmer que les analyseurs basés sur les événements (SAX) et beaucoup plus légers que les analyseurs basés sur les arbres (DOM), qui chargent l'arbre complet en mémoire.

Le Reader agit comme un curseur se déplaçant dans le flux du document et s'arrêtant à chaque nœud rencontré. À chaque étape, les méthodes de type DOM de l'objet Reader permettent d'examiner le nœud courant (nom, espace de noms, attributs, etc.)

Le code de l'utilisateur contrôle la progression et appelle simplement la fonction read() de manière répétée pour passer au nœud suivant dans le document. D'autres fonctions permettent de sauter des sous-arbres complets, ou des nœuds jusqu'à un élément spécifique, etc.

À chaque instant, seule une portion très limitée du document est conservée en mémoire, ce qui rend l'API plus efficace en mémoire que l'utilisation de DOM. Cependant, il est également possible de mélanger Reader et DOM. L'utilisateur peut à tout moment copier le nœud courant (éventuellement développé en un sous-arbre complet) du document traité vers un autre arbre DOM, ou demander au Reader de collecter des sous-documents sous la forme d'un arbre DOM composé de nœuds sélectionnés.

L'API Reader prend également en charge les espaces de noms, xml:base, la gestion des entités et la validation DTD. Le support de la validation par schéma et RelaxNG sera probablement ajouté dans une future révision de l'interface Perl.

La nomenclature des méthodes par rapport à libxml2 et XmlTextReader de C# a été légèrement modifiée pour correspondre aux conventions de XML::LibXML. Certaines fonctions ont été modifiées ou ajoutées par rapport à l'interface C.

CONSTRUCTEUR

Selon la source XML, l'objet Reader peut être créé avec l'une des méthodes suivantes :

my $reader = XML::LibXML::Reader->new( location => "fichier.xml", ... );
  my $reader = XML::LibXML::Reader->new( string => $chaine_xml, ... );
  my $reader = XML::LibXML::Reader->new( IO => $descripteur_fichier, ... );
  my $reader = XML::LibXML::Reader->new( FD => fileno(STDIN), ... );
  my $reader = XML::LibXML::Reader->new( DOM => $dom, ... );

où ... sont des options du lecteur (facultatives) décrites ci-dessous dans "Options du lecteur" ou diverses options de l'analyseur décrites dans XML::LibXML::Parser. Le constructeur reconnaît les sources XML suivantes :

Spécification de la source

location
Lit le XML à partir d'un fichier local ou d'une URL (non-HTTPS).
string
Lit le XML à partir d'une chaîne de caractères.
IO
Lit le XML à partir d'un descripteur de fichier IO Perl.
FD
Lit le XML à partir d'un descripteur de fichier (contourne la couche I/O de Perl, applicable uniquement aux descripteurs de fichiers pour les fichiers réguliers ou les tuyaux). Potentiellement plus rapide que IO.
DOM
Utilise l'API du lecteur pour parcourir un document XML::LibXML::Document pré-analysé.

Options du lecteur

encoding => $encodage
remplace l'encodage du document.
RelaxNG => $schéma_rng
peut être utilisé pour passer soit un objet XML::LibXML::RelaxNG, soit un nom de fichier, soit une URL (non-HTTPS) d'un schéma RelaxNG au constructeur. Le schéma est ensuite utilisé pour valider le document au fur et à mesure de son traitement.
Schema => $schéma_xsd
peut être utilisé pour passer soit un objet XML::LibXML::Schema, soit un nom de fichier, soit une URL (non-HTTPS) d'un schéma W3C XSD au constructeur. Le schéma est ensuite utilisé pour valider le document au fur et à mesure de son traitement.
...
le lecteur prend en charge diverses options de l'analyseur décrites dans XML::LibXML::Parser (spécifiquement celles marquées par /reader/).

MÉTHODES CONTRÔLANT LA PROGRESSION DE L'ANALYSE

read ()
Déplace la position vers le nœud suivant dans le flux, exposant ses propriétés.

Retourne 1 si le nœud a été lu avec succès, 0 s'il n'y a plus de nœuds à lire, ou -1 en cas d'erreur.

readAttributeValue ()
Analyse la valeur d'un attribut en un ou plusieurs nœuds Texte et Entité de référence.

Retourne 1 en cas de succès, 0 si le lecteur n'était pas positionné sur un nœud d'attribut ou si toutes les valeurs d'attributs ont été lues, ou -1 en cas d'erreur.

readState ()
Obtient l'état de lecture du lecteur. Retourne la valeur de l'état, ou -1 en cas d'erreur. Le module exporte des constantes pour les états du lecteur, voir STATES ci-dessous.
depth ()
La profondeur du nœud dans l'arbre, commence à 0 pour le nœud racine.
next ()
Saute vers le nœud suivant dans l'ordre du document tout en évitant le sous-arbre s'il y en a un. Retourne 1 si le nœud a été lu avec succès, 0 s'il n'y a plus de nœuds à lire, ou -1 en cas d'erreur.
nextElement (localname?,nsURI?)
Saute les nœuds suivants dans l'ordre du document jusqu'à ce qu'un élément spécifique soit atteint. Le nom de l'élément doit être égal à un localname donné s'il est défini, et son espace de noms doit être égal à un nsURI donné s'il est défini. L'un ou l'autre des arguments peut être indéfini (ou omis, dans le cas des derniers ou des deux).

Retourne 1 si l'élément a été trouvé, 0 s'il n'y a plus de nœuds à lire, ou -1 en cas d'erreur.

nextPatternMatch (motif_compilé)
Saute les nœuds suivants dans l'ordre du document jusqu'à ce qu'un élément correspondant à un motif compilé donné soit atteint. Voir XML::LibXML::Pattern pour des informations sur les motifs compilés. Voir également la méthode "matchesPattern".

Retourne 1 si l'élément a été trouvé, 0 s'il n'y a plus de nœuds à lire, ou -1 en cas d'erreur.

skipSiblings ()
Saute tous les nœuds du même niveau ou de niveau inférieur jusqu'à ce que le premier nœud d'un niveau supérieur soit atteint. En particulier, si le nœud courant se trouve dans un élément, le lecteur s'arrête à la balise de fermeture de l'élément parent, sinon il s'arrête à un nœud immédiatement après le nœud parent.

Retourne 1 en cas de succès, 0 si la fin du document est atteinte, ou -1 en cas d'erreur.

nextSibling ()
Il saute vers le nœud suivant dans l'ordre du document tout en évitant le sous-arbre s'il y en a un.

Retourne 1 si le nœud a été lu avec succès, 0 s'il n'y a plus de nœuds à lire, ou -1 en cas d'erreur.

nextSiblingElement (nom?,uri_ns?)
Comme nextElement mais ne traite que les éléments frères du nœud courant.
(se déplaçant en utilisant "nextSibling ()" plutôt que "read ()", en interne).

Retourne 1 si l'élément a été trouvé, 0 s'il n'y a plus de nœuds frères, ou -1 en cas d'erreur.

finish ()
Ignore tous les nœuds restants dans le document, atteignant la fin du document.

Retourne 1 en cas de succès, 0 en cas d'erreur.

close ()
Cette méthode libère toutes les ressources allouées par l'instance actuelle et ferme toute entrée sous-jacente. Elle retourne 0 en cas d'échec et 1 en cas de succès. Cette méthode est appelée automatiquement par le destructeur lorsque le lecteur est oublié, vous n'avez donc pas à l'appeler directement.

MÉTHODES EXTRACTION INFORMATIONS

name ()
Retourne le nom qualifié du nœud courant, égal à (Préfixe:)NomLocal.
nodeType ()
Retourne le type du nœud courant. Voir TYPES DE NŒUDS ci-dessous.
localName ()
Retourne le nom local du nœud.
prefix ()
Retourne le préfixe de l'espace de noms associé au nœud.
namespaceURI ()
Retourne l'URI définissant l'espace de noms associé au nœud.
isEmptyElement ()
Vérifie si le nœud courant est vide. C'est un peu bizarre dans le sens où <a/> sera considéré comme vide tandis que <a></a> ne le sera pas.
hasValue ()
Retourne vrai si le nœud peut avoir une valeur textuelle.
value ()
Fournit la valeur textuelle du nœud si elle est présente ou undef si elle n'est pas disponible.
readInnerXml ()
Lit le contenu du nœud courant, y compris les nœuds enfants et le balisage. Retourne une chaîne contenant le XML du contenu du nœud, ou undef si le nœud courant n'est ni un élément ni un attribut, ou n'a pas de nœuds enfants.
readOuterXml ()
Lit le contenu du nœud courant, y compris les nœuds enfants et le balisage.

Retourne une chaîne contenant le XML du nœud y compris son contenu, ou undef si le nœud courant n'est ni un élément ni un attribut.

nodePath()
Retourne un chemin canonique vers l'élément courant, de la racine au nœud courant. Les éléments avec espaces de noms sont mis en correspondance par '*', car il n'y a aucun moyen de déclarer des préfixes dans les motifs XPath. Contrairement à XML::LibXML::Node::nodePath(), cette fonction ne fournit pas de comptes de frères (c'est-à-dire qu'au lieu de par exemple '/a/b[1]' et '/a/b[2]', elle renvoie '/a/b' pour les deux correspondances).
matchesPattern(compiled_pattern)
Retourne une valeur vraie si le nœud courant correspond à un motif compilé. Voir XML::LibXML::Pattern pour des informations sur les motifs compilés. Voir également la méthode "nextPatternMatch".

MÉTHODES EXTRACTION NOEUDS DOM

document ()
Fournit l'accès à l'arbre de document construit par le lecteur. Cette fonction peut être utilisée pour collecter les nœuds préservés (voir preserveNode() et preservePattern).

ATTENTION : N'utilisez jamais cette fonction pour modifier l'arbre, sauf si la lecture de l'intégralité du document est terminée !

copyCurrentNode (deep)
Cette fonction est similaire à la fonction DOM copyNode(). Elle retourne une copie du nœud actuellement traité sous forme d'objet DOM correspondant. Utilisez deep = 1 pour obtenir le sous-arbre complet.
preserveNode ()
Cela indique au lecteur XML de préserver le nœud courant dans l'arbre de document. Un arbre de document composé des nœuds préservés et de leur contenu peut être obtenu en utilisant la méthode document() une fois l'analyse terminée.

Retourne le nœud ou NULL en cas d'erreur.

preservePattern (pattern,\%ns_map)
Cela indique au lecteur XML de préserver tous les nœuds correspondant au motif (qui est un sous-ensemble XPath en streaming). Un arbre de document composé des nœuds préservés et de leur contenu peut être obtenu en utilisant la méthode document() une fois l'analyse terminée.

Un deuxième argument optionnel peut être utilisé pour fournir une référence HASH mappant les préfixes utilisés par le XPath aux URIs d'espace de noms.

Le sous-ensemble XPath disponible avec cette fonction est décrit sur

http://www.w3.org/TR/xmlschema-1/#Selector

et correspond à la production

Path ::= ('.//')? ( Step '/' )* ( Step | '@' NameTest )

Retourne un nombre positif en cas de succès et -1 en cas d'erreur.

MÉTHODES TRAITEMENT ATTRIBUTS

attributeCount ()
Fournit le nombre d'attributs du nœud courant.
hasAttributes ()
Si le nœud possède des attributs.
getAttribute (name)
Fournit la valeur de l'attribut avec le nom qualifié spécifié.

Retourne une chaîne contenant la valeur de l'attribut spécifié, ou undef en cas d'erreur.

getAttributeNs (localName, namespaceURI)
Fournit la valeur de l'attribut spécifié.

Retourne une chaîne contenant la valeur de l'attribut spécifié, ou undef en cas d'erreur.

getAttributeNo (no)
Fournit la valeur de l'attribut avec l'index spécifié par rapport à l'élément parent.

Retourne une chaîne contenant la valeur de l'attribut spécifié, ou undef en cas d'erreur.

isDefault ()
Retourne vrai si le nœud d'attribut courant a été généré à partir de la valeur par défaut définie dans la DTD.
moveToAttribute (name)
Déplace la position vers l'attribut avec le nom local et l'espace de noms spécifiés.

Retourne 1 en cas de succès, -1 en cas d'erreur, 0 si non trouvé.

moveToAttributeNo (no)
Déplace la position vers l'attribut avec l'index spécifié par rapport à l'élément parent.

Retourne 1 en cas de succès, -1 en cas d'erreur, 0 si non trouvé.

moveToAttributeNs (localName,namespaceURI)
Déplace la position vers l'attribut avec le nom local et l'espace de noms spécifiés.

Retourne 1 en cas de succès, -1 en cas d'erreur, 0 si non trouvé.

moveToFirstAttribute ()
Déplace la position vers le premier attribut associé au nœud courant.

Retourne 1 en cas de succès, -1 en cas d'erreur, 0 si non trouvé.

moveToNextAttribute ()
Déplace la position vers l'attribut suivant associé au nœud courant.

Retourne 1 en cas de succès, -1 en cas d'erreur, 0 si non trouvé.

moveToElement ()
Déplace la position vers le nœud qui contient le nœud d'attribut courant.

Retourne 1 en cas de succès, -1 en cas d'erreur, 0 si non déplacé.

isNamespaceDecl ()
Détermine si le nœud courant est une déclaration d'espace de noms plutôt qu'un attribut ordinaire.

Retourne 1 si le nœud courant est une déclaration d'espace de noms, 0 s'il s'agit d'un attribut ordinaire ou d'un autre type de nœud, ou -1 en cas d'erreur.

AUTRES MÉTHODES

lookupNamespace (prefix)
Résout un préfixe d'espace de noms dans la portée de l'élément courant.

Retourne une chaîne contenant l'URI de l'espace de noms auquel le préfixe est mappé, ou undef en cas d'erreur.

encoding ()
Retourne une chaîne contenant l'encodage du document ou undef en cas d'erreur.
standalone ()
Détermine le statut autonome du document en cours de lecture. Retourne 1 si le document a été déclaré comme autonome, 0 s'il a été déclaré comme non autonome, ou -1 si le document n'a pas spécifié son statut autonome ou en cas d'erreur.
xmlVersion ()
Détermine la version XML du document en cours de lecture. Retourne une chaîne contenant la version XML du document ou undef en cas d'erreur.
baseURI ()
Retourne l'URI de base d'un nœud donné.
isValid ()
Récupère le statut de validité de l'analyseur.

Retourne 1 si valide, 0 si non, et -1 en cas d'erreur.

xmlLang ()
Le scope xml:lang dans leq

DESTRUCTION

XML::LibXML prend en charge la destruction de l'objet lecteur lorsque la dernière référence à l'objet lecteur sort de portée. L'arbre du document est préservé, cependant, si l'une des méthodes $reader->document ou $reader->preserveNode a été utilisée et que des références à l'arbre du document existent.
