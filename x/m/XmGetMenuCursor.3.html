NOM

XmGetMenuCursor — Une fonction qui retourne l'ID du curseur du menu courant

SYNTAXE

#include <Xm/Xm.h>
Cursor XmGetMenuCursor(
Display * display);

DESCRIPTION

XmGetMenuCursor interroge le curseur de menu actuellement utilisé par ce client sur l'affichage spécifié et retourne l'ID du curseur. Cette fonction retourne le curseur de menu pour l'écran par défaut de l'affichage.

NOTE : XmGetMenuCursor est obsolète et existe pour des raisons de compatibilité avec les versions précédentes. Au lieu d'utiliser cette fonction, appelez XtGetValues pour la ressource XmScreen XmNmenuCursor.

display
Spécifie l'affichage dont le curseur de menu doit être interrogé.

RETOUR

Retourne l'ID du curseur pour le curseur de menu actuel ou la valeur None si un curseur n'est pas encore défini. Un curseur ne sera pas défini si l'application appelle cette fonction avant que le client n'ait créé de menus sur l'affichage spécifié.

VOIR AUSSI

XmScreen(3).
