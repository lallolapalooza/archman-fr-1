XmStringDrawImage(3)

Paquet: openmotif

Licences: LGPL-2.1-or-later

XmStringDrawImage(appel de bibliothèque) XmStringDrawImage(appel de bibliothèque)

NOM

XmStringDrawImage — Fonction de chaîne composée qui dessine une chaîne composée dans une fenêtre X et crée une image

SYNTAXE

#include <Xm/Xm.h>
void XmStringDrawImage(
Display * d,
Window w,
XmRenderTable rendertable,
XmString string,
GC gc,
Position x,
Position y,
Dimension width,
unsigned char alignment,
unsigned char layout_direction,
XRectangle * clip);

DESCRIPTION

XmStringDrawImage dessine une chaîne composée dans une fenêtre X et peint les bits de premier plan et d'arrière-plan de chaque caractère. Si un segment de chaîne composée utilise une rendition contenant un ensemble de polices, le contexte graphique passé à cette routine laissera le membre de police du GC dans un état indéfini. La fonction sous-jacente XmbStringDraw appelée par cette routine modifie le champ d'identifiant de police du GC qui lui est passé et ne tente pas de restaurer l'identifiant de police à la valeur entrante. Si le segment de chaîne composée n'est pas dessiné à l'aide d'un ensemble de polices, le contexte graphique doit contenir un membre de police valide. Les contextes graphiques créés par XtGetGC ne sont pas acceptés par cette routine ; utilisez plutôt XtAllocateGC pour créer un contexte graphique.

d
Spécifie l'affichage.
w
Spécifie la fenêtre.
rendertable
Spécifie la table de rendu.
string
Spécifie la chaîne.
gc
Spécifie le contexte graphique à utiliser.
x
Spécifie une coordonnée du rectangle qui contiendra la chaîne composée affichée.
y
Spécifie une coordonnée du rectangle qui contiendra la chaîne composée affichée.
width
Spécifie la largeur du rectangle qui contiendra la chaîne composée affichée.
alignment
Spécifie comment la chaîne sera alignée dans le rectangle spécifié. Elle est soit XmALIGNMENT_BEGINNING, XmALIGNMENT_CENTER, ou XmALIGNMENT_END.
layout_direction
Contrôle la direction dans laquelle les segments de la chaîne composée seront disposés. Elle détermine également la signification du paramètre alignment.
clip
Permet à l'application de restreindre la zone dans laquelle la chaîne composée sera dessinée. Si NULL, le découpage sera déterminé par le GC.
