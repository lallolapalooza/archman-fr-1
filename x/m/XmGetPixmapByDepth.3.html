NOM

XmGetPixmapByDepth — Une fonction de mise en cache de pixmap qui génère une pixmap, la stocke dans un cache de pixmaps et retourne la pixmap

SYNOPSIS

#include <Xm/Xm.h>
Pixmap XmGetPixmapByDepth(
Screen *screen,
char *image_name,
Pixel foreground,
Pixel background,
int depth);

DESCRIPTION

XmGetPixmapByDepth utilise les données des paramètres pour effectuer une recherche dans le cache de pixmaps afin de déterminer si une pixmap a déjà été générée qui correspond aux données. Si une pixmap est trouvée, un compteur de références est incrémenté et la pixmap est retournée. Les applications doivent utiliser XmDestroyPixmap lorsque la pixmap n'est plus nécessaire.

screen
Spécifie l'écran d'affichage sur lequel la pixmap doit être dessinée.
image_name
Spécifie le nom de l'image à utiliser pour générer la pixmap.
foreground
Combine l'image avec la couleur de premier plan pour créer la pixmap si l'image référencée est une image de 1 bit par pixel.
background
Combine l'image avec la couleur d'arrière-plan pour créer la pixmap si l'image référencée est une image de 1 bit par pixel.
depth
Spécifie la profondeur de la pixmap.

Si une pixmap correspondante n'est pas trouvée, image_name est utilisé pour effectuer une recherche dans le cache d'images. Si une image est trouvée, elle est utilisée pour générer la pixmap, qui est ensuite mise en cache et retournée.

Si une image n'est pas trouvée, image_name est utilisé comme nom de fichier, et une recherche est effectuée pour un fichier bitmap X10 ou X11. S'il est trouvé, le fichier est lu, converti en image, et mis en cache dans le cache d'images. L'image est ensuite utilisée pour générer une pixmap, qui est mise en cache et retournée.

Si image_name commence par / (barre oblique), il spécifie un chemin d'accès complet, et XmGetPixmapByDepth ouvre le fichier tel que spécifié. Sinon, image_name spécifie un nom de fichier. Dans ce cas, XmGetPixmapByDepth recherche le fichier le long d'un chemin de recherche spécifié par la variable d'environnement XBMLANGPATH ou par un chemin de recherche par défaut, qui varie selon que la variable d'environnement XAPPLRESDIR est définie ou non. Le chemin de recherche par défaut contient de nombreux répertoires. Par conséquent, XmGetPixmapByDepth aura besoin d'un temps relativement long pour parcourir tous ces répertoires pour les pixmaps et les bitmaps. Les applications qui utilisent beaucoup de pixmaps et de bitmaps s'exécuteront probablement plus rapidement si XBMLANGPATH est défini sur une liste courte de répertoires. En plus des fichiers bitmap X (XBM), Motif prend également en charge les formats de fichiers XPM (X Pixmap) et, à partir de la version 2.3, les formats d'image JPEG et PNG. (Notez que la prise en charge des formats d'image JPEG et PNG est une fonctionnalité facultative de Motif, afin de vérifier si la version actuelle prend en charge les formats d'image PNG et JPEG, les macros PNG_SUPPORT et JPEG_SUPPORT doivent être vérifiées respectivement.) Le XBMLANGPATH spécifie le chemin pour les fichiers XBM, XPM, PNG et JPEG. Les fichiers XPM sont décrits plus en détail plus loin dans cette page de référence.

La variable d'environnement XBMLANGPATH spécifie un chemin de recherche pour les fichiers bitmap X. Elle peut contenir le champ de substitution %B, où l'argument image_name de XmGetPixmapByDepth est substitué à %B. Elle peut également contenir les champs de substitution acceptés par XtResolvePathname. Le champ de substitution %T est toujours mappé à bitmaps, et %S est toujours mappé à NULL.

Ce sont les chemins par défaut que les fournisseurs peuvent modifier. Par exemple, un fournisseur peut utiliser des répertoires différents pour /usr/lib/X11 et /usr/include/X11.

Les substitutions suivantes sont utilisées dans ces chemins :

%B
Le nom de l'image, de l'argument image_name.
%N
Le nom de classe de l'application.
%L
La chaîne de langue de l'affichage. Cette chaîne est influencée par XtSetLanguageProc. La chaîne par défaut est déterminée en appelant setlocale(LC_ALL, NULL).
%l_%t
Le composant langue et territoire de la chaîne de langue de l'affichage.
%l
Le composant langue de la chaîne de langue de l'affichage.

Le contenu du fichier doit être conforme aux règles des fichiers bitmap X11. Autrement dit, Motif peut lire tout fichier bitmap conforme à X11.

NOM

XmGetPixmapByDepth, XmGetPixmap - créer ou récupérer une pixmap

SYNTAXIS

#include <Xm/Xm.h>

Pixmap XmGetPixmapByDepth(
    Widget widget,
    XImage *image,
    unsigned int width,
    unsigned int height,
    int depth );

Pixmap XmGetPixmap(
    Widget widget,
    char *image_name,
    Pixel foreground,
    Pixel background );

DESCRIPTION

XmGetPixmapByDepth crée une pixmap pour l'application. La pixmap est stockée dans le cache des pixmaps pour une réutilisation future. Si la pixmap existe déjà dans le cache, elle est renvoyée sans être recréée. La fonction prend comme arguments le widget, l'image (qui contient les données de la pixmap), la largeur et la hauteur de la pixmap, ainsi que la profondeur des couleurs.

XmGetPixmap est une version simplifiée qui utilise un nom d'image (stocké dans la table des images de l'application) et les couleurs de premier plan et d'arrière-plan pour créer la pixmap. Si l'image correspondante ne peut être trouvée, cette fonction appelle XmGetPixmapByDepth avec les paramètres appropriés.

RETOUR

Renvoie une pixmap en cas de succès ; renvoie XmUNSPECIFIED_PIXMAP si l'image correspondant à image_name ne peut pas être trouvée.
