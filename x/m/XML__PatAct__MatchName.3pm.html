NOM

XML::PatAct::MatchName - Un module de motif pour la correspondance des noms d'éléments

SYNOPIS

use XML::PatAct::MatchName;
my $matcher = XML::PatAct::MatchName->new();
my $patterns = [ 'foo' => ACTION,
                 'bar/foo' => ACTION,
                 ... ];

DESCRIPTION

XML::PatAct::MatchName est un module de motif destiné à être utilisé avec les pilotes PatAct pour appliquer des listes de motifs-actions à des analyseurs ou des arbres XML. XML::PatAct::MatchName est un module de motif simple qui utilise uniquement les noms d'éléments pour effectuer la correspondance. Si plusieurs noms sont fournis séparés par des caractères de type `"/"', alors tous les noms des éléments parents doivent également correspondre.

L'ordre des motifs dans la liste n'est pas significatif. XML::PatAct::MatchName utilisera la correspondance la plus spécifique. En utilisant la synopsis ci-dessus comme exemple, si vous avez un élément `"foo"', `"bar/foo"' correspondra si `"foo"' se trouve dans un élément `"bar"', sinon seul le motif avec `"foo"' correspondra.
