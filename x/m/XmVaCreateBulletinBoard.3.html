NOM

XmVaCreateBulletinBoard, XmVaCreateManagedBulletinBoard — Fonctions de création de commodité pour un widget BulletinBoard.

SYNTAXE

#include <Xm/BulletinB.h>
Widget XmVaCreateBulletinBoard(
Widget parent,
String name,
...);
Widget XmVaCreateManagedBulletinBoard(
Widget parent,
String name,
...);

DESCRIPTION

Ces fonctions créent une instance d'un widget BulletinBoard et renvoient l'ID du widget associé. Ces routines utilisent la convention d'appel de liste d'arguments de longueur variable (varargs) ANSI C.

La fonction XmVaCreateBulletinBoard est une routine de commodité qui appelle XtCreateWidget.

La fonction XmVaCreateManagedBulletinBoard est une routine de commodité qui appelle XtCreateManagedWidget.

parent
Spécifie l'ID du widget parent.
name
Spécifie le nom du widget créé.
...
Spécifie la liste d'arguments variables pour remplacer les valeurs par défaut des ressources.

Pour une définition complète de BulletinBoard et de ses ressources associées, voir XmBulletinBoard(3).

VALEUR DE RETOUR

Renvoie l'ID du widget BulletinBoard.

VOIR AUSSI

XmBulletinBoard(3), XmCreateBulletinBoard(3), XtCreateWidget(3), et XtCreateManagedWidget(3).
