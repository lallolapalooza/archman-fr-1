XML::Stream::Tree(3) Documentation Perl fournie par l'utilisateur XML::Stream::Tree(3)

NOM

XML::Stream::Tree - Fonctions pour faciliter la construction et l'analyse de l'arbre.

SYNOPIS

  Juste une collection de fonctions qui ne nécessitent pas d'être en mémoire si vous
choisissez l'une des autres méthodes de stockage de données.

FORMAT

Le résultat de l'analyse :

<foo><head id="a">Hello <em>there</em></head><bar>Howdy<ref/></bar>do</foo>

serait :
Contenu de la balise
==================================================================
[foo, [{},
head, [{id => "a"},
0, "Hello ",
em, [{},
0, "there"
]
],
bar, [{},
0, "Howdy",
ref, [{}]
],
0, "do"
]
]
