DESCRIPTION

La bibliothèque d'interface de programmation pour l'extension X11 Double-Buffering, Multi-Buffering, et Stereo Extension contient les interfaces décrites ci-dessous. À l'exception de XmbufQueryExtension, si l'une de ces routines est appelée avec un affichage qui ne prend pas en charge l'extension, le ExtensionErrorHandler (qui peut être défini avec XSetExtensionErrorHandler et fonctionne de la même manière que XSetErrorHandler) sera appelé et la fonction retournera ensuite.

XmbufQueryExtension retourne True si l'extension de multibuffering/stéréo est disponible sur l'affichage donné. Si l'extension existe, la valeur du premier code d'événement (qui doit être ajoutée aux constantes de type d'événement MultibufferClobberNotify et MultibufferUpdateNotify pour obtenir les valeurs réelles) est stockée dans event_base_return et la valeur du premier code d'erreur (qui doit être ajoutée à la constante de type d'erreur MultibufferBadBuffer pour obtenir la valeur réelle) est stockée dans error_base_return.

XmbufGetVersion obtient les numéros de version majeure et mineure de l'extension. La valeur de retour est zéro si une erreur se produit ou non zéro si aucune erreur ne se produit.

XmbufCreateBuffers demande la création de "count" buffers avec l'action de mise à jour et l'indice de mise à jour donnés et leur association à la fenêtre indiquée. Le nombre de buffers créés est retourné (zéro si une erreur s'est produite) et buffers_update est rempli avec ce nombre d'identifiants Multibuffer.

XmbufDestroyBuffers détruit les buffers associés à la fenêtre donnée.

XmbufDisplayBuffers affiche les buffers indiqués dans leurs fenêtres appropriées dans un délai maximum de max_delay millisecondes après que min_delay millisecondes se soient écoulées. Aucun deux buffers ne peut être associé à la même fenêtre, sinon une erreur Match est générée.

XmbufGetWindowAttributes obtient les attributs de multibuffering qui s'appliquent à tous les buffers associés à la fenêtre donnée. La liste des buffers retournée peut être libérée avec XFree. Retourne une valeur non nulle en cas de succès et zéro en cas d'erreur.

XmbufChangeWindowAttributes définit les attributs de multibuffering qui s'appliquent à tous les buffers associés à la fenêtre donnée. Ceci est actuellement limité à l'indice de mise à jour.

XmbufGetBufferAttributes obtient les attributs du buffer indiqué. Retourne une valeur non nulle en cas de succès et zéro en cas d'erreur.

XmbufChangeBufferAttributes définit les attributs du buffer indiqué. Ceci est actuellement limité au masque d'événements.

XmbufGetScreenInfo obtient les paramètres contrôlant comment les fenêtres mono et stéréo peuvent être créées sur l'écran du drawable donné. Les nombres d'ensembles de visuels et de profondeurs sont retournés dans nmono_return et nstereo_return. Si nmono_return est supérieur à zéro, mono_info_return est défini à l'adresse d'un tableau de structures XmbufBufferInfo décrivant les différents visuels et profondeurs qui peuvent être utilisés. Sinon, mono_info_return est défini à NULL. De même, stereo_info_return est défini en fonction de nstereo_return. L'espace alloué retourné dans mono_info_return et stereo_info_return peut être libéré par XFree. Si aucune erreur n'est rencontrée, une valeur non nulle sera retournée.

XmbufCreateStereoWindow crée une fenêtre stéréo de la même manière que XCreateWindow crée une fenêtre mono. Les identifiants des buffers gauche et droit sont retournés dans left_return et right_return, respectivement. Si un gestionnaire d'erreurs d'extension qui retourne est installé, None sera retourné si l'extension n'est pas disponible sur cet affichage.

STRUCTURES

None.

DESCRIPTION

The Xmbuf library provides functions for interacting with the multi-buffering extension of the X Window System. This extension allows for more efficient rendering by enabling applications to draw to off-screen buffers and then swap them to make the changes visible.

The functions provided by Xmbuf allow clients to control various aspects of multi-buffering, including locking, event handling, and buffer management.

DESCRIPTION

La bibliothèque Xmbuf fournit des fonctions pour interagir avec l'extension de multi-mise en mémoire tampon du système X Window. Cette extension permet un rendu plus efficace en permettant aux applications de dessiner dans des tampons hors écran, puis de les échanger pour rendre les modifications visibles.

Les fonctions fournies par Xmbuf permettent aux clients de contrôler divers aspects de la multi-mise en mémoire tampon, y compris le verrouillage, la gestion des événements et la gestion des tampons.
