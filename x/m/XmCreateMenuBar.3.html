NOM

XmCreateMenuBar — Fonction de création de commodité pour le widget RowColumn

SYNOPSIS

#include <Xm/RowColumn.h>
Widget XmCreateMenuBar(
Widget parent,
String name,
ArgList arglist,
Cardinal argcount);

DESCRIPTION

XmCreateMenuBar crée une instance d'un widget RowColumn de type XmMENU_BAR et retourne l'ID du widget associé. Il est fourni comme fonction de commodité pour créer des widgets RowColumn configurés pour fonctionner comme une barre de menu et n'est pas implémenté comme une classe de widget distincte.

Le widget MenuBar est généralement utilisé pour construire un système de menus déroulants. Typiquement, une barre de menu est créée et placée en haut de la fenêtre de l'application, et plusieurs boutons de cascade (CascadeButtons) y sont insérés comme enfants. Chacun de ces boutons de cascade a une fenêtre de menu déroulante associée. Ces fenêtres de menu déroulantes doivent avoir été créées comme enfants de la barre de menu. L'utilisateur interagit avec la barre de menu en utilisant soit la souris, soit le clavier.

Le widget MenuBar affiche une ombre 3D le long de sa bordure. L'application contrôle les attributs de l'ombre en utilisant les ressources liées à la visualisation supportées par XmManager.

Le widget MenuBar est homogène en ce sens qu'il n'accepte que des enfants qui sont une sous-classe de XmCascadeButton ou XmCascadeButtonGadget. Tenter d'insérer un enfant d'une classe différente génère un message d'avertissement.

Si la barre de menu n'a pas assez d'espace pour contenir tous ses sous-widgets sur une seule ligne, la barre de menu tente de faire passer les entrées restantes sur des lignes supplémentaires si cela est autorisé par le gestionnaire de géométrie du widget parent.

parent
Spécifie l'ID du widget parent
name
Spécifie le nom du widget créé
arglist
Spécifie la liste d'arguments
argcount
Spécifie le nombre de paires attribut/valeur dans la liste d'arguments (arglist)

Pour une définition complète de RowColumn et de ses ressources associées, voir XmRowColumn(3).

RETOUR

Retourne l'ID du widget RowColumn.
