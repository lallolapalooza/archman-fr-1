NOM

XmStringExtent — Fonction de chaîne composite qui détermine la taille du plus petit rectangle qui englobera la chaîne composite

SYNTAXE

#include <Xm/Xm.h>
void XmStringExtent(
XmRenderTable rendertable,
XmString string,
Dimension *width,
Dimension *height);

DESCRIPTION

XmStringExtent détermine la largeur et la hauteur, en pixels, du plus petit rectangle qui englobera la chaîne composite fournie.

rendertable
Spécifie la table de rendu
string
Spécifie la chaîne
width
Spécifie un pointeur vers la largeur du rectangle
height
Spécifie un pointeur vers la hauteur du rectangle

VOIR AUSSI

XmStringCreate(3).
