NOM

XmSetMenuCursor — Une fonction qui modifie le curseur de menu pour un client

SYNTAXE

#include <Xm/Xm.h>
void XmSetMenuCursor(
Display * display,
Cursor cursorId);

DESCRIPTION

XmSetMenuCursor modifie par programmation le curseur de menu pour un client ; une fois le curseur créé par le client, cette fonction enregistre le curseur auprès du système de menus. Après avoir appelé cette fonction, le curseur spécifié est affiché chaque fois que ce client affiche un menu Motif sur l'affichage indiqué. Le client peut ensuite spécifier différents curseurs sur différents affichages.

Cette fonction définit le curseur de menu pour tous les écrans de l'affichage. XmSetMenuCursor est obsolète et existe pour la compatibilité avec les versions précédentes. Au lieu d'utiliser cette fonction, fournissez des valeurs initiales ou appelez XtSetValues pour la ressource XmScreen XmNmenuCursor.

display
Spécifie l'affichage auquel le curseur doit être associé
cursorId
Spécifie l'ID du curseur X

VOIR AUSSI

XmScreen(3).
