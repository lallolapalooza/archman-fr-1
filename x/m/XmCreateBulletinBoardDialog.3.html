NOM

XmCreateBulletinBoardDialog — Fonction de création pratique pour BulletinBoard BulletinBoardDialog

SYNTAXE

#include <Xm/BulletinB.h>
Widget XmCreateBulletinBoardDialog(
Widget parent,
String name,
ArgList arglist,
Cardinal argcount);

DESCRIPTION

XmCreateBulletinBoardDialog est une fonction de création pratique qui crée un DialogShell et un enfant BulletinBoard non géré du DialogShell. Un BulletinBoardDialog est utilisé pour les interactions non prises en charge par l'ensemble de boîtes de dialogue standard. Cette fonction ne crée pas automatiquement d'étiquettes, de boutons ou d'autres composants de boîte de dialogue. Ces composants doivent être ajoutés par l'application après la création du BulletinBoardDialog.

Utilisez XtManageChild pour faire apparaître le BulletinBoardDialog (en passant le BulletinBoard comme paramètre widget) ; utilisez XtUnmanageChild pour le faire disparaître.

XmCreateBulletinBoardDialog force la valeur de la ressource Shell XmNallowShellResize à True.

parent
Spécifie l'identifiant du widget parent
name
Spécifie le nom du widget créé
arglist
Spécifie la liste d'arguments
argcount
Spécifie le nombre de paires attribut/valeur dans la liste d'arguments (arglist)

Pour une définition complète de BulletinBoard et de ses ressources associées, voir XmBulletinBoard(3).

RETOUR

Retourne l'identifiant du widget BulletinBoard.

VOIR AUSSI

XmBulletinBoard(3).
