NOM

XmTabCreate — Une fonction de commodité qui crée une tabulation

SYNTAXE

#include <Xm/Xm.h>
XmTab XmTabCreate(
float value,
unsigned char units,
XmOffsetModel offset_model,
unsigned char alignment,
char *decimal);

DESCRIPTION

XmTabCreate crée une tabulation à une position définie par les arguments value et units.

value
Spécifie la valeur flottante à utiliser conjointement avec units pour calculer la position de la tabulation. Notez que les valeurs négatives ne sont pas permises.
units
Spécifie le type d'unité (par exemple, XmMILLIMETERS) à utiliser conjointement avec value pour calculer la position de la tabulation. Vous pouvez spécifier n'importe quelle unité décrite sur la page de référence de XmConvertUnits. Pour les ressources de type dimension ou position, vous pouvez spécifier des unités comme décrit dans la ressource XmNunitType de la page de référence de XmGadget, XmManager ou XmPrimitive.
offset_model
Spécifie si la valeur de tabulation représente une position absolue ou un décalage relatif par rapport à la tabulation précédente. Les valeurs valides sont XmABSOLUTE et XmRELATIVE.
alignment
Spécifie comment le texte doit être aligné par rapport à cette tabulation. Les valeurs valides sont XmALIGNMENT_BEGINNING.
decimal
Spécifie le caractère multibyte dans l'environnement linguistique actuel à utiliser comme point décimal pour une tabulation alignée sur le décimal. Ceci est actuellement inutilisé.

RETOUR

Retourne une structure XmTab nouvellement allouée. L'application est responsable de la gestion de cet espace alloué. L'application peut récupérer cet espace alloué en appelant XmTabFree.

VOIR AUSSI

XmTab(3) et XmTabFree(3).
