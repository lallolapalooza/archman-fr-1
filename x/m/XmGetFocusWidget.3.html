NOM

XmGetFocusWidget — Retourne l'ID du widget qui a le focus clavier

SYNTAXE

#include <Xm/Xm.h>
Widget XmGetFocusWidget(
Widget widget);

DESCRIPTION

XmGetFocusWidget examine la hiérarchie qui contient le widget spécifié et retourne l'ID du widget qui a le focus clavier. La fonction extrait l'ID du widget du widget Shell associé ; par conséquent, le widget spécifié peut être situé n'importe où dans la hiérarchie.

widget
Spécifie un ID de widget au sein d'une hiérarchie donnée

RETOUR

Retourne l'ID du widget ayant le focus clavier. Si aucun enfant du Shell n'a le focus, la fonction retourne NULL.
