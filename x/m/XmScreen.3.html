NOM

XmScreen — La classe de widget Screen

SYNTAXE

#include <Xm/Screen.h>

DESCRIPTION

L'objet XmScreen est utilisé par les widgets Motif pour stocker des informations spécifiques à un écran. Il permet également à la boîte à outils de stocker certaines informations sur les hiérarchies de widgets qui seraient autrement indisponibles. Chaque client possède un objet XmScreen pour chaque écran auquel il accède.

Un objet XmScreen est créé automatiquement lorsque l'application crée le premier shell sur un écran (généralement accompli par un appel à XtAppInitialize ou XtAppCreateShell). Il n'est pas nécessaire de créer un objet XmScreen par tout autre moyen. Une application peut utiliser la fonction XmGetXmScreen pour obtenir l'identifiant du widget de l'objet XmScreen pour un écran donné.

Une application ne peut pas fournir de valeurs initiales pour les ressources XmScreen en tant qu'arguments à un appel de fonction créant des widgets. L'application ou l'utilisateur peut fournir des valeurs initiales dans un fichier de ressources. Après avoir créé le premier shell sur l'écran, l'application peut utiliser XmGetXmScreen pour obtenir l'identifiant du widget de l'objet XmScreen, puis appeler XtSetValues pour définir les ressources XmScreen.

Classes

Screen hérite du comportement et des ressources de Core.

Le pointeur de classe est xmScreenClass.

Le nom de la classe est XmScreen.

Nouvelles ressources

Le tableau suivant définit un ensemble de ressources de widget utilisées par le programmeur pour spécifier des données. Le programmeur peut également définir les valeurs des ressources pour les classes héritées afin de définir les attributs de ce widget. Pour référencer une ressource par son nom ou par sa classe dans un fichier .Xdefaults, supprimez le préfixe XmN ou XmC et utilisez les lettres restantes. Pour spécifier l'une des valeurs définies pour une ressource dans un fichier .Xdefaults, supprimez le préfixe Xm et utilisez les lettres restantes (en minuscules ou en majuscules, mais incluez les underscores entre les mots). Les codes dans la colonne d'accès indiquent si la ressource donnée peut être définie au moment de la création (C), définie à l'aide de XtSetValues (S), récupérée à l'aide de XtGetValues (G), ou n'est pas applicable (N/A).

XmNbitmapConversionModel
Fournit une politique pour la conversion des fichiers xbm et xpm en type Pixmap. Cette ressource prend les valeurs suivantes :
XmMATCH_DEPTH
À partir d'un fichier xbm ou xpm fourni, génère un fichier pixmap converti ayant la même profondeur que le widget.
XmDYNAMIC_DEPTH
Convertit un fichier xbm d'entrée en un Pixmap de profondeur 1, ou convertit un fichier xpm d'entrée en un Pixmap ayant la même profondeur que le widget.
XmNcolorAllocationProc
Identifie la procédure à utiliser pour l'allocation des couleurs. Normalement, cette procédure est une procédure d'allocation des couleurs définie par l'application. Cependant, si aucune procédure d'allocation des couleurs définie par l'application n'est définie, le système utilise la procédure d'allocation des couleurs prédéfinie de Motif.
XmNcolorCalculationProc
Identifie la procédure à utiliser pour le calcul des couleurs par widget. Normalement, cette procédure est une procédure de calcul des couleurs définie par l'application. Cependant, si aucune procédure de calcul des couleurs définie par l'application n'est définie, le système utilise la procédure de calcul des couleurs prédéfinie de Motif.
XmNdarkThreshold
Un entier compris entre 0 (zéro) et 100, inclus, qui spécifie un niveau de luminosité perçue pour une couleur. Si la luminosité perçue de la couleur de fond est inférieure à ce niveau, Motif traite le fond comme "sombre" lors du calcul des couleurs d'ombre et de sélection par défaut. Si cette ressource est spécifiée pour un écran particulier, elle s'applique aux widgets créés sur cet écran ; sinon, elle s'applique aux widgets créés sur tous les écrans. La valeur par défaut est spécifique à l'implémentation.
XmNdefaultCopyCursorIcon
Spécifie l'icône de glissement (DragIcon) utilisée lors d'une opération de glissement de copie, lorsqu'aucune autre pixmap n'est spécifiée par l'application. Si cette ressource est NULL, une icône système par défaut est utilisée. L'icône système par défaut est déterminée par la ressource d'affichage XmNenableDragIcon.
XmNdefaultInvalidCursorIcon
Spécifie l'icône de glissement (DragIcon) utilisée pour indiquer que le curseur se trouve sur un site de dépôt invalide lors d'une opération de glissement, lorsqu'aucun autre symbole pixmap n'est spécifié par l'application. Si cette ressource est NULL, une icône système par défaut est utilisée. L'icône système par défaut est déterminée par la ressource d'affichage XmNenableDragIcon.
XmNdefaultLinkCursorIcon
Spécifie l'icône de glissement (DragIcon) utilisée lors d'une opération de glissement de lien, lorsqu'aucune autre pixmap n'est spécifiée par l'application. Si cette ressource est NULL, une icône système par défaut est utilisée. L'icône système par défaut est déterminée par la ressource d'affichage XmNenableDragIcon.
XmNdefaultMoveCursorIcon
Spécifie l'icône de glissement (DragIcon) utilisée lors d'une opération de glissement de déplacement, lorsqu'aucune autre pixmap n'est spécifiée par l'application. Si cette ressource est NULL, une icône système par défaut est utilisée. L'icône système par défaut est déterminée par la ressource d'affichage XmNenableDragIcon.
XmNdefaultNoneCursorIcon
Spécifie l'icône de glissement (DragIcon) utilisée pour indiquer que le curseur ne se trouve pas sur un site de dépôt lors d'une opération de glissement, lorsqu'aucune autre pixmap n'est spécifiée par l'application. Si cette ressource est NULL, une icône système par défaut est utilisée. L'icône système par défaut est déterminée par la ressource d'affichage XmNenableDragIcon.
XmNdefaultSourceCursorIcon
Spécifie la pixmap de profondeur 1 utilisée comme curseur lorsqu'une XmNsourceCursorIcon n'est pas fournie par le DragContext, ou qu'elle n'est pas utilisable. Si cette ressource est NULL, une icône système par défaut est utilisée. L'icône système par défaut est déterminée par la ressource d'affichage XmNenableDragIcon.
XmNdefaultValidCursorIcon
Spécifie l'icône de glissement (DragIcon) utilisée pour indiquer que le curseur se trouve sur un site de dépôt valide lors d'une opération de glissement, lorsqu'aucun autre symbole pixmap n'est spécifié par l'application. Si cette ressource est NULL, une icône système par défaut est utilisée. L'icône système par défaut est déterminée par la ressource d'affichage XmNenableDragIcon.
XmNfont
Spécifie une police à utiliser pour le calcul des valeurs de XmNhorizontalFontUnit et XmNverticalFontUnit. Lorsque l'application est initialisée, cette ressource peut être fournie dans un fichier de ressources ou via les options de ligne de commande standard -fn, -font, et -xrm. Notez que cette ressource est uniquement utilisée pour le calcul des valeurs d'unité de police. Pour spécifier une police à utiliser pour afficher du texte, utilisez la ressource de table de rendu d'un widget (XmNrenderTable).
XmNforegroundThreshold
Un entier compris entre 0 (zéro) et 100, inclus, qui spécifie un niveau de luminosité perçue pour une couleur. Si la luminosité perçue de la couleur de fond est égale ou inférieure à ce niveau, Motif traite le fond comme "sombre" lors du calcul des couleurs par défaut pour le premier plan et la mise en évidence. Si la luminosité perçue
la luminosité de la couleur d'arrière-plan est supérieure à ce niveau, Motif traite l'arrière-plan comme "clair" lors du calcul des couleurs de premier plan et de surbrillance par défaut. Lorsque l'arrière-plan est "foncé", le premier plan et la surbrillance par défaut sont blancs ; lorsque l'arrière-plan est "clair", le premier plan et la surbrillance par défaut sont noirs. Si cette ressource est spécifiée pour un écran particulier, elle s'applique aux widgets créés sur cet écran ; sinon, elle s'applique aux widgets créés sur tous les écrans. La valeur par défaut est spécifique à l'implémentation.
XmNhorizontalFontUnit
Spécifie la composante horizontale des unités de police utilisées par XmConvertUnits, et est utilisée pour interpréter les valeurs des ressources de géométrie lorsque la ressource XmNshellUnitType de VendorShell ou la ressource XmNunitType de Gadget, Manager, ou Primitive a la valeur Xm100TH_FONT_UNITS. Si aucune valeur initiale n'est fournie pour cette ressource, la valeur par défaut est calculée à partir de la police spécifiée dans XmNfont. Si aucune valeur initiale n'est fournie pour cette ressource ou pour XmNfont, la valeur par défaut est 10.
Si un appel à XtSetValues spécifie une valeur pour XmNhorizontalFontUnit, cette ressource est définie à cette valeur. Si un appel à XtSetValues spécifie une valeur pour XmNfont mais pas pour XmNhorizontalFontUnit, cette ressource est définie à une valeur calculée à partir de la nouvelle XmNfont.
Une unité de police horizontale est dérivée d'une police comme suit :
•
Si la police a une propriété AVERAGE_WIDTH, l'unité de police horizontale est la propriété AVERAGE_WIDTH divisée par 10.
•
Si la police n'a pas de propriété AVERAGE_WIDTH mais a une propriété QUAD_WIDTH, l'unité de police horizontale est la propriété QUAD_WIDTH.
•
Si la police n'a ni propriété AVERAGE_WIDTH ni QUAD_WIDTH, l'unité de police horizontale est la somme de min_bounds.width et max_bounds.width de la structure de police divisée par 2.3.

Fournit aux widgets le bitmap à utiliser lors de la génération de la représentation visuelle inactive. Ce bitmap doit être utilisé comme tampon pour le rendu des représentations visuelles inactives.
XmNlightThreshold

Si la luminosité perçue de la couleur d'arrière-plan est supérieure à ce niveau, Motif traite l'arrière-plan comme "clair" lors du calcul des couleurs d'ombre et de sélection par défaut. Si cette ressource est spécifiée pour un écran particulier, elle s'applique aux widgets créés sur cet écran ; sinon, elle s'applique aux widgets créés sur tous les écrans. La valeur par défaut est spécifique à l'implémentation.

Spécifie si une opération interactive qui déplace une fenêtre, comme détacher et faire glisser un menu détachable ou déplacer une fenêtre dans MWM, affiche le contour de la fenêtre ou une représentation de la fenêtre elle-même pendant le déplacement. NAME

XmScreen — A widget class that manages screen-specific resources.

SYNOPSIS

#include <Xm/Screen.h>

DESCRIPTION

The XmScreen widget class manages resources that are specific to a particular screen in a display. A widget of this class is created automatically by the XmDisplay widget. An application can access the XmScreen widget for a particular screen using XmGetXmScreen.

The XmScreen widget supports the following resource characteristics:

max_bounds.descent
This resource specifies the maximum descent for fonts. The default value is calculated as min_bounds.descent plus max_bounds.descent divided by 2.2.

Inherited Resources

All of the superclass resources inherited by XmScreen are designated N/A (not applicable).

RELATED

NOM

XmScreen — Une classe de widget qui gère les ressources spécifiques à l'écran.

SYNTAXE

#include <Xm/Screen.h>

DESCRIPTION

La classe de widget XmScreen gère les ressources qui sont spécifiques à un écran particulier d'un afficheur. Un widget de cette classe est créé automatiquement par le widget XmDisplay. Une application peut accéder au widget XmScreen pour un écran particulier en utilisant XmGetXmScreen.

Le widget XmScreen supporte les caractéristiques de ressources suivantes :

max_bounds.descent
Cette ressource spécifie la descente maximale pour les polices. La valeur par défaut est calculée comme min_bounds.descent plus max_bounds.descent divisé par 2.2.

Ressources héritées

Toutes les ressources de la superclasse héritées par XmScreen sont désignées par N/A (non applicable).
