NOM

XmVaCreateHierarchy, XmVaCreateManagedHierarchy — Fonctions utilitaires de création d'un widget Hiérarchie.

SYNTAXE

#include <Xm/Hierarchy.h>
Widget XmVaCreateHierarchy(
Widget parent,
String name,
...);
Widget XmVaCreateManagedHierarchy(
Widget parent,
String name,
...);

DESCRIPTION

Ces fonctions créent une instance d'un widget Hiérarchie et renvoient l'identifiant du widget associé. Ces routines utilisent la convention d'appel de liste d'arguments de longueur variable (varargs) d'ANSI C.

La fonction XmVaCreateHierarchy est une routine utilitaire qui appelle XtCreateWidget.

La fonction XmVaCreateManagedHierarchy est une routine utilitaire qui appelle XtCreateManagedWidget.

parent
Spécifie l'identifiant du widget parent.
name
Spécifie le nom du widget créé.
...
Spécifie la liste d'arguments variables pour outrepasser les valeurs défaut des ressources.

Pour une définition complète de Hiérarchie et de ses ressources associées, voir XmHierarchy(3).

RETOUR

Renvoie l'identifiant du widget Hiérarchie.

LIRE AUSSI

XmCreateHierarchy(3), XtCreateWidget(3), XtCreateManagedWidget(3), et XmHierarchy(3).
