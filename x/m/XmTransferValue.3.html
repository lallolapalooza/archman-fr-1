NOM

XmTransferValue — Une fonction de boîte à outils qui transfère des données vers une destination

SYNOPSIS

#include <Xm/Xm.h>

void XmTransferValue(
XtPointer transfer_id,
Atom target,
XtCallbackProc proc,
XtPointer client_data,
Time time);

DESCRIPTION

XmTransferValue convertit une sélection, transférant toute donnée du propriétaire de la sélection, dans le contexte d'une opération de transfert de données déjà initiée. Une application peut appeler cette routine à partir d'une procédure XmNdestinationCallback ou de toute fonction appelée en conséquence.

L'appelant de XmTransferValue fournit la cible vers laquelle la sélection est convertie. L'appelant fournit également une procédure de rappel pour gérer les données résultant de la conversion.

transfer_id
Spécifie un identifiant unique pour l'opération de transfert de données. La valeur doit être identique à la valeur du membre transfer_id du XmDestinationCallbackStruct passé à la procédure XmNdestinationCallback.
target
Spécifie la cible vers laquelle la sélection doit être convertie.
proc
Spécifie une procédure de rappel à invoquer lorsque la sélection a été convertie et que les données, le cas échéant, sont disponibles. Cette procédure est responsable de l'insertion ou du traitement des données transférées. La procédure peut également terminer le transfert de données en appelant XmTransferDone. Le proc reçoit trois arguments :
•
Le widget qui a demandé la conversion
•
La valeur de l'argument client_data
•
Un pointeur vers un XmSelectionCallbackStruct
Cette procédure peut être appelée avant ou après le retour de XmTransferValue.
client_data
Spécifie les données à passer à la procédure de rappel (la valeur de l'argument proc) lorsque la sélection a été convertie.
time
Spécifie le moment de l'XEvent qui a déclenché le transfert de données. Vous devriez généralement définir ce champ sur XtLastTimestampProcessed.

La procédure de rappel (la valeur de l'argument proc) reçoit un pointeur vers un XmSelectionCallbackStruct, qui a la définition suivante :

typedef struct
{
        int reason;
        XEvent *event;
        Atom selection;
        Atom target;
        Atom type;
        XtPointer transfer_id;
        int flags;
        int remaining;
        XtPointer value;
        unsigned long length;
        int format;
} XmSelectionCallbackStruct;
reason
Indique pourquoi le rappel a été invoqué.
event
Pointe vers l'XEvent qui a déclenché le rappel. Il peut être NULL.
selection
Spécifie la sélection qui a été convertie.
target
Spécifie la cible vers laquelle XmTransferValue a demandé la conversion. La valeur est identique à la valeur de l'argument target de XmTransferValue.
type
Spécifie le type de la valeur de sélection. Ce n'est pas la cible, mais le type utilisé pour représenter la cible. La valeur XT_CONVERT_FAIL signifie que le propriétaire de la sélection n'a pas répondu à la demande de conversion dans le délai d'attente de sélection des Intrinsics.
transfer_id
Spécifie un identifiant unique pour l'opération de transfert de données. La valeur est identique à la valeur de l'argument transfer_id de XmTransferValue.
flags
Ce membre n'est actuellement pas utilisé. La valeur est toujours XmSELECTION_DEFAULT.
remaining
Indique le nombre de transferts restants pour l'opération spécifiée par transfer_id.
value
Représente les données transférées par cette requête. L'application est responsable de libérer la valeur en appelant XtFree.
length
Indique le nombre d'éléments de données dans value, où chaque élément a la taille symbolisée par format. Si value est NULL, length est 0.
format
Indique si les données dans value doivent être considérées comme une liste de quantités de type char, short ou long. Les valeurs possibles sont 8 (pour une liste de char), 16 (pour une liste de short) ou 32 (pour une liste de long).
