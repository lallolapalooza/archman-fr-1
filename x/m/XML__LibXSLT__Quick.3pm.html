NOM

XML::LibXSLT::Quick - une interface plus facile à utiliser (= "plus rapide") à XML::LibXSLT

SYNOPSIS

use XML::LibXSLT::Quick ();
my $stylesheet =
    XML::LibXSLT::Quick->new( { location => 'example/1.xsl', } );
my $xml1_text = _utf8_slurp('example/1.xml');
my $out_fn = 'foo.xml';
$stylesheet->generic_transform(
    +{
        type => 'file',
        path => $out_fn,
    },
    $xml1_text,
);

DESCRIPTION

C'est un module qui encapsule XML::LibXSLT avec une interface plus facile à utiliser.

Il peut être utilisé pour traiter des documents XML en utilisant des feuilles de style XSLT (Extensible Stylesheet Language Transformations) https://en.wikipedia.org/wiki/XSLT.

MÉTHODES

XML::LibXSLT::Quick->new({ location=>"./xslt/my.xslt", });

À définir.

$obj->stylesheet()

Le résultat de parse_stylesheet().

$obj->xml_parser()

L'instance XML::LibXML.

$obj->generic_transform($dest, $source)

À discuter.

Voir "t/using-quick-wrapper.t" .

$dest peut être :

"\$my_string_var"

"{type => 'dom', }" - le DOM sera retourné.

"{type => 'file', path => $filepath, }" - la chaîne de sortie sera écrite dans $filepath .

"{type => 'implicit', }" - la chaîne de sortie sera calculée mais implicitement ignorée et undef() sera retourné. (Ajouté dans la version 2.00300 .)

"{type => 'return', }" - la chaîne de sortie sera retournée.

$source peut être :

Une chaîne de caractères.

"{type => 'file', path => $filepath, params => +{}, }" - le fichier sera analysé.

"{type => 'string', string => $my_xml_string, params => +{}, }" - la chaîne sera analysée.

$obj->output_as_chars($dom)

$obj->transform(...)

$obj->transform_into_chars(...)

Délégation de $obj->stylesheet(). Voir XML::LibXSLT .
