NOM

XmGetColors — Une fonction qui génère des couleurs de premier plan, de sélection et d'ombre

SYNTAXE

#include <Xm/Xm.h>
void XmGetColors(
Screen * screen,
Colormap colormap,
Pixel background,
Pixel * foreground,
Pixel * top_shadow,
Pixel * bottom_shadow,
Pixel * select);

DESCRIPTION

XmGetColors prend un écran, une table des couleurs et un pixel de fond, et renvoie des valeurs de pixel pour les couleurs de premier plan, de sélection et d'ombre.

screen
Spécifie l'écran pour lequel ces couleurs doivent être allouées.
colormap
Spécifie la table des couleurs à partir de laquelle ces couleurs doivent être allouées.
background
Spécifie l'arrière-plan sur lequel les couleurs doivent être basées.
foreground
Spécifie un pointeur vers la valeur de pixel de premier plan renvoyée. Si cet argument est NULL, aucune valeur n'est allouée ou renvoyée pour cette couleur.
top_shadow
Spécifie un pointeur vers la valeur de pixel d'ombre supérieure renvoyée. Si cet argument est NULL, aucune valeur n'est allouée ou renvoyée pour cette couleur.
bottom_shadow
Spécifie un pointeur vers la valeur de pixel d'ombre inférieure renvoyée. Si cet argument est NULL, aucune valeur n'est allouée ou renvoyée pour cette couleur.
select
Spécifie un pointeur vers la valeur de pixel de sélection renvoyée. Si cet argument est NULL, aucune valeur n'est allouée ou renvoyée pour cette couleur.

LIENS CONNEXES

XmChangeColor(3), XmGetColorCalculation(3), et XmSetColorCalculation(3).
