NOM

XML::ESISParser - Analyseur SAX Perl utilisant nsgmls

SYNOPIS

use XML::ESISParser;
$parser = XML::ESISParser->new( [OPTIONS] );
$result = $parser->parse( [OPTIONS] );
$result = $parser->parse($string);

DESCRIPTION

"XML::ESISParser" est un analyseur SAX Perl utilisant la commande `nsgmls' de James Clark's SGML Parser (SP), un analyseur XML et SGML validant. Cette page de manuel résume les options, gestionnaires et propriétés spécifiques pris en charge par "XML::ESISParser" ; veuillez vous référer à la norme SAX Perl dans `"SAX.pod"' pour des informations d'utilisation générales.

"XML::ESISParser" analyse par défaut le XML et dispose d'une option pour analyser le SGML.

La source de `"nsgmls"', ainsi que des binaires pour certaines plateformes, est disponible sur http://www.jclark.com/. `"nsgmls"' est inclus dans les deux paquets SP et Jade.

MÉTHODES

new
Crée un nouvel objet analyseur. Les options par défaut pour l'analyse, décrites ci-dessous, sont passées sous forme de paires clé-valeur ou d'une seule hash. Les options peuvent être modifiées directement dans l'objet analyseur, sauf indication contraire. Les options passées à `parse()' remplacent les options par défaut dans l'objet analyseur pour la durée de l'analyse.

OPTIONS

Les options suivantes sont prises en charge par "XML::ESISParser" :

Handler          Gestionnaire par défaut pour recevoir les événements
DocumentHandler  Gestionnaire pour recevoir les événements de document
DTDHandler       Gestionnaire pour recevoir les événements de DTD
ErrorHandler     Gestionnaire pour recevoir les événements d'erreur
Source           Hash contenant la source d'entrée pour l'analyse
IsSGML           Le document à analyser est en SGML

Si aucun gestionnaire n'est fourni, tous les événements seront ignorés silencieusement.

Si un seul argument de type chaîne de caractères est passé à la méthode `parse()', il est traité comme si une option `"Source"' avait été donnée avec un paramètre `"String"'.

Le hash `"Source"' peut contenir les paramètres suivants :

ByteStream       Le flux d'octets brut (descripteur de fichier) contenant le
                 document.
String           Une chaîne de caractères contenant le document.
SystemId         L'identifiant système (URI) du document.

Si plus d'un des paramètres `"ByteStream"', `"String"', ou `"SystemId"' est spécifié, la préférence est donnée d'abord à `"ByteStream"', puis à `"String"', puis à `"SystemId"'.

GESTIONNAIRES

Les gestionnaires et propriétés suivants sont pris en charge par "XML::ESISParser" :

Méthodes DocumentHandler

start_document
Reçoit la notification du début d'un document.

Aucune propriété définie.

end_document
Reçoit la notification de la fin d'un document.

Aucune propriété définie.

start_element
Reçoit la notification du début d'un élément. 
Name             Le nom du type d'élément.
Attributes       Un hash contenant les attributs attachés à l'élément,
                 le cas échéant.
IncludedSubelement Cet élément est un sous-élément inclus.
Empty            Cet élément est déclaré vide.

Le hash `"Attributes"' ne contient que des valeurs de type chaîne de caractères. Le drapeau `"Empty"' n'est pas défini pour un élément qui n'a simplement pas de contenu, il n'est défini que si la DTD le déclare vide.

BETA : Les valeurs des attributs n'étendent pas actuellement les entités SData en objets d'entité, elles sont toujours dans la notation des données système utilisée par nsgmls (entre `|'). Une future version de XML::ESISParser convertira également d'autres types d'attributs en leurs objets respectifs, actuellement seuls leurs noms de notation ou d'entité sont donnés.

end_element
Reçoit la notification de la fin d'un élément. 
Name             Le nom du type d'élément.
characters
Reçoit la notification de données de caractères. 
Data             Les caractères du document.
record_end
Reçoit la notification d'une séquence de fin d'enregistrement. Les applications XML doivent convertir cela en un saut de ligne.
processing_instruction
Reçoit la notification d'une instruction de traitement. 
Target           La cible de l'instruction de traitement en XML.
Data             Les données de l'instruction de traitement, le cas échéant.
internal_entity_ref
Reçoit la notification d'une référence d'entité interne de données système (SData). 
Name             Le nom de la référence d'entité interne.
external_entity_ref
Reçoit la notification d'une référence d'entité externe. 
Name             Le nom de la référence d'entité externe.
start_subdoc
Reçoit la notification du début d'un sous-document. 
Name             Le nom de la référence d'entité externe.
end_subdoc
Reçoit la notification de la fin d'un sous-document. 
Name             Le nom de la référence d'entité externe.
conforming
Reçoit la notification que le document vient d'être analysé conformément à sa déclaration de type de document (DTD).

Aucune propriété définie.

Méthodes DTDHandler

external_entity_decl
Reçoit la notification d'une déclaration d'entité externe. 
Name             Le nom de l'entité.
Type             Le type de l'entité (CDATA, NDATA, etc.)
SystemId         L'identifiant système de l'entité.
PublicId         L'identifiant public de l'entité, le cas échéant.
GeneratedId      Les identifiants système générés, le cas échéant.
internal_entity_decl
Reçoit la notification d'une déclaration d'entité interne. 
Name             Le nom de l'entité.
Type             Le type de l'entité (CDATA, NDATA, etc.)
Value            La valeur de caractères de l'entité.
notation_decl
Reçoit la notification d'une déclaration de notation. 
Name             Le nom de la notation.
SystemId         L'identifiant système de la notation.
PublicId         L'identifiant public de la notation, le cas échéant.
GeneratedId      Les identifiants système générés, le cas échéant.
subdoc_entity_decl
Reçoit la notification d'une déclaration d'entité sous-document. 
Name             Le nom de l'entité.
SystemId         L'identifiant système de l'entité.
PublicId         L'identifiant public de l'entité, le cas échéant.
GeneratedId      Les identifiants système générés, le cas échéant.
