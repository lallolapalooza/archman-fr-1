NOM

XmTextFindString — Appel de fonction Text pour trouver la position de début d'une chaîne de caractères

SYNTAXE

#include <Xm/Xm.h>
Boolean XmTextFindString(
Widget widget,
XmTextPosition start,
char *string,
XmTextDirection direction,
XmTextPosition *position);

DESCRIPTION

XmTextFindString localise la position de début d'une chaîne de caractères spécifiée. Cette routine recherche vers l'avant ou vers l'arrière la première occurrence de la chaîne à partir de la position de départ donnée. Si elle trouve une correspondance, la fonction retourne la position du premier caractère de la chaîne dans position. Si la chaîne correspondante commence à la position actuelle, cette routine retourne la position actuelle.

widget
Spécifie l'ID du widget Text.
start
Spécifie la position du caractère à partir de laquelle la recherche se déroule. Il s'agit d'un nombre entier de caractères à partir du début du tampon de texte. La première position de caractère est 0 (zéro).
string
Spécifie la chaîne de recherche.
direction
Indique la direction de la recherche. Elle est relative à la direction principale du texte. Les valeurs possibles sont
XmTEXT_FORWARD
La recherche se déroule vers la fin du tampon de texte.
XmTEXT_BACKWARD
La recherche se déroule vers le début du tampon de texte.
position
Spécifie le pointeur dans lequel est retournée la position du premier caractère de la correspondance de chaîne. Il s'agit d'un nombre entier de caractères à partir du début du tampon. La première position de caractère est 0 (zéro). Si la fonction retourne False, cette valeur est indéfinie.

Pour une définition complète de Text et de ses ressources associées, voir XmText(3).

RETOUR

Retourne True si une correspondance de chaîne est trouvée ; sinon, retourne False.

CONNEXES

XmText(3) et XmTextFindStringWcs(3).
