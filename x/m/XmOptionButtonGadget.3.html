NOM

XmOptionButtonGadget — Appel de bibliothèque RowColumn qui obtient l'ID du widget pour le CascadeButtonGadget dans un OptionMenu

SYNTAXE

#include <Xm/RowColumn.h>
Widget XmOptionButtonGadget(
Widget option_menu);

DESCRIPTION

XmOptionButtonGadget fournit à l'application les moyens d'obtenir l'ID du widget pour le CascadeButtonGadget créé en interne. Une fois que l'application a obtenu l'ID du widget, elle peut ajuster les visuels du CascadeButtonGadget, si désiré.

Lorsqu'une application crée une instance du widget OptionMenu, le widget crée deux gadgets internes. L'un est un LabelGadget utilisé pour afficher la ressource XmNlabelString de RowColumn. L'autre est un CascadeButtonGadget qui affiche la sélection actuelle et fournit le moyen d'afficher le sous-menu de l'OptionMenu.

L'utilisateur peut spécifier des ressources dans un fichier de ressources pour les widgets et gadgets automatiquement créés d'un OptionMenu. La liste suivante identifie les noms de ces widgets (ou gadgets) et les zones associées de l'OptionMenu.

Label Gadget de l'Option Menu
OptionLabel
Bouton Cascade de l'Option Menu
OptionButton
option_menu
Spécifie l'ID du widget OptionMenu

Pour une définition complète de RowColumn et de ses ressources associées, voir XmRowColumn(3).

VALEUR

Retourne l'ID du widget pour le bouton interne.

VOIR AUSSI

XmCreateOptionMenu(3), XmCascadeButtonGadget(3), XmOptionLabelGadget(3), et XmRowColumn(3).
