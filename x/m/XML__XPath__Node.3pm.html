XML::XPath::Node(3) Documentation Perl fournie par l'utilisateur XML::XPath::Node(3)

NOM

XML::XPath::Node - représentation interne d'un nœud

API

L'API Node vise à émuler le DOM dans une certaine mesure, cependant l'API n'est pas tout à fait compatible avec le DOM. Ceci est destiné à faciliter la transition de la programmation XML::DOM à XML::XPath. La compatibilité avec le DOM pourrait survenir une fois que XML::DOM gérera les espaces de noms.

new

Crée un nouveau nœud. Voir les sous-classes pour les paramètres à passer à new().

getNodeType

Retourne l'un des ELEMENT_NODE, TEXT_NODE, COMMENT_NODE, ATTRIBUTE_NODE, PROCESSING_INSTRUCTION_NODE ou NAMESPACE_NODE. UNKNOWN_NODE est retourné si la sous-classe n'implémente pas getNodeType - mais cela signifie que quelque chose ne va pas ! Les constantes sont exportées par défaut par XML::XPath::Node. Les constantes ont la même valeur numérique que les versions XML::DOM.

getParentNode

Retourne le parent de ce nœud, ou undef si c'est le nœud racine. Notez que le nœud racine est la racine en termes d'XPath - pas l'élément racine.

to_sax ( $handler | %handlers )

Génère des appels sax vers le gestionnaire ou les gestionnaires. Voir la documentation PerlSAX pour les détails (pas encore implémenté correctement).
