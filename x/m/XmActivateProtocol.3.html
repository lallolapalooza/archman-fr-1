NOM

XmActivateProtocol — Appel de fonction VendorShell qui active un protocole

SYNTAXE

#include <Xm/Protocols.h>
void XmActivateProtocol(
Widget shell,
Atom property,
Atom protocol);

DESCRIPTION

XmActivateProtocol active un protocole. Elle met à jour les gestionnaires et la property si le shell est réalisé. Il est parfois utile de permettre aux informations d'état d'un protocole (listes de callbacks, etc.) de persister, même si le client choisit de se retirer temporairement de l'interaction. Ceci est pris en charge en permettant à un protocol d'être dans l'un des deux états : actif ou inactif. Si le protocol est actif et que le shell est réalisé, la property contient l'Atom du protocol. Si le protocol est inactif, l'Atom n'est pas présent dans la property.

XmActivateWMProtocol est une interface de commodité. Elle appelle XmActivateProtocol avec la valeur de la propriété définie sur l'atome retourné par l'internement de WM_PROTOCOLS.

shell
Spécifie le widget auquel la propriété du protocole est associée
property
Spécifie la propriété du protocole
protocol
Spécifie l'Atom du protocole

Pour une définition complète de VendorShell et de ses ressources associées, voir VendorShell(3).

VOIR AUSSI

VendorShell(3), XmActivateWMProtocol(3), XmRemoveProtocols(3) et XmInternAtom(3).
