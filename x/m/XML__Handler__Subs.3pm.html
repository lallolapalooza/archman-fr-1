NOM

XML::Handler::Subs - une classe de base de gestionnaire PerlSAX pour appeler des sous-programmes définis par l'utilisateur

SYNTAXE

use XML::Handler::Subs;
package MyHandlers;
use vars qw{ @ISA };
sub s_NOM { my ($self, $element) = @_ };
sub e_NOM { my ($self, $element) = @_ };
$self->{Noms};    # un tableau de noms
$self->{Noeuds};    # un tableau de nœuds $element
$handler = MyHandlers->new();
$self->in_element($name);
$self->within_element($name);

DESCRIPTION

"XML::Handler::Subs" est une classe de base pour les gestionnaires PerlSAX. "XML::Handler::Subs" est héritée pour implémenter un comportement complet et ajouter une gestion spécifique aux éléments.

Chaque fois qu'un élément commence, une méthode portant ce nom, précédée de `s_', est appelée avec l'élément à traiter. Chaque fois qu'un élément se termine, une méthode portant ce nom, précédée de `e_', est appelée. Tous les caractères spéciaux dans le nom de l'élément sont remplacés par des underscores.

L'héritage de XML::Handler::Subs de cette manière est similaire au style Subs de XML::Parser.

XML::Handler::Subs maintient une pile de noms d'éléments, `"$self-"{Noms}', et une pile de nœuds d'éléments, `"$self-"{Noeuds}>' qui peut être utilisée par les classes dérivées. L'élément courant est empilé sur les piles avant d'appeler une méthode de nom d'élément de démarrage et dépilé des piles après avoir appelé la méthode de nom d'élément de fin. Les appels à `in_element()' et `within_element()' utilisent ces piles.

Si la classe dérivée implémente `start_document()', `end_document()', `start_element()', et `end_element()', assurez-vous d'utiliser `"SUPER::"' pour appeler également les méthodes de la classe parente. Voir perlobj(1) pour les détails sur SUPER::. `SUPER::start_element()' et `SUPER::end_element()' retournent 1 si une méthode de nom d'élément est appelée, ils retournent 0 si aucune méthode n'a été appelée.

XML::Handler::Subs n'implémente aucun autre gestionnaire PerlSAX.

XML::Handler::Subs prend en charge les méthodes suivantes :

new( OPTIONS )
Une méthode `new()' basique. `new()' prend une liste de paires clé, valeur ou une table de hachage et crée et retourne une table de hachage avec ces options ; la table de hachage est bénie dans la classe dérivée.
in_element($name)
Retourne vrai si `$name' est égal au nom de l'élément le plus interne actuellement ouvert.
within_element($name)
Retourne le nombre de fois où `$name' apparaît dans Noms.
