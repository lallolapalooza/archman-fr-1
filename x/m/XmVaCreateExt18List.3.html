NOM

XmVaCreateExt18List, XmVaCreateManagedExt18List — Fonctions de création pratiques pour le widget Ext18List.

SYNOPSIS

#include <Xm/Ext18List.h>
Widget XmVaCreateExt18List(
Widget parent,
String name,
...);
Widget XmVaCreateManagedExt18List(
Widget parent,
String name,
...);

DESCRIPTION

Ces fonctions créent une instance d'un widget Ext18List et retournent l'identifiant du widget associé. Ces routines utilisent la convention d'appel de liste d'arguments de longueur variable (varargs) de ANSI C.

La fonction XmVaCreateExt18List est une routine pratique qui appelle XtCreateWidget.

La fonction XmVaCreateManagedExt18List est une routine pratique qui appelle XtCreateManagedWidget.

parent
Spécifie l'identifiant du widget parent.
name
Spécifie le nom du widget créé.
...
Spécifie la liste d'arguments variables pour remplacer les valeurs par défaut des ressources.

Pour une définition complète de Form et de ses ressources associées, voir XmExt18List(3).

RETOUR

Retourne l'identifiant du widget Ext18List.

CONNEXES

XmCreateExt18List(3), XtCreateManagedWidget(3), XtCreateWidget(3), et XmExt18List(3).
