NOM

XML::Handler::XMLWriter - un gestionnaire PerlSAX pour écrire du XML lisible

SYNOPIS

use XML::Parser::PerlSAX;
use XML::Handler::XMLWriter;
$mon_gestionnaire = XML::Handler::XMLWriter->new( OPTIONS );
XML::Parser::PerlSAX->new->parse(Source => { SystemId => 'REC-xml-19980210.xml' },
                                 Handler => $mon_gestionnaire);

DESCRIPTION

"XML::Handler::XMLWriter" est un gestionnaire PerlSAX pour écrire du XML lisible (par opposition au XML canonique, par exemple). XML::Handler::XMLWriter peut être utilisé avec un parseur pour reformater du XML, avec XML::DOM ou XML::Grove pour écrire du XML, ou avec d'autres modules PerlSAX qui génèrent des événements.

"XML::Handler::XMLWriter" est destiné à être utilisé avec des générateurs d'événements PerlSAX et n'effectue aucune vérification lui-même (par exemple, la correspondance des événements d'éléments de début et de fin). Si vous souhaitez générer du XML directement à partir de votre code Perl, utilisez le module XML::Writer. XML::Writer dispose d'une interface facile à utiliser et effectue de nombreuses vérifications pour s'assurer que le XML que vous générez est bien formé.

"XML::Handler::XMLWriter" est une sous-classe de "XML::Handler::Subs". "XML::Handler::XMLWriter" peut être davantage sous-classé pour modifier son comportement ou ajouter une gestion spécifique aux éléments. Dans la sous-classe, chaque fois qu'un élément commence, une méthode portant ce nom préfixée par `s_' est appelée avec l'élément à traiter. Chaque fois qu'un élément se termine, une méthode portant ce nom préfixée par `e_' est appelée. Tous les caractères spéciaux dans le nom de l'élément sont remplacés par des underscores. S'il n'y a pas de méthode de début ou de fin pour un élément, l'action par défaut consiste à écrire la balise de début ou de fin. Les méthodes de début et de fin peuvent utiliser les méthodes `print_start_element()' et `print_end_element()' pour imprimer les balises de début ou de fin. Les sous-classes peuvent appeler la méthode `print()' pour écrire une sortie supplémentaire.

La sous-classification de XML::Handler::XMLWriter de cette manière est similaire au style Stream de XML::Parser.

XML::Handler::Subs maintient une pile de noms d'éléments, `"$self-"{Names}', et une pile de nœuds d'éléments, `"$self-"{Nodes}>', qui peuvent être utilisés par les sous-classes. L'élément courant est poussé sur les piles avant d'appeler une méthode de début de nom d'élément et retiré des piles après avoir appelé la méthode de fin de nom d'élément.

Voir XML::Handler::Subs pour des méthodes supplémentaires.

En plus des méthodes standard du gestionnaire PerlSAX (voir PerlSAX pour les descriptions), XML::Handler::XMLWriter prend en charge les méthodes suivantes :

new( OPTIONS )
Crée et renvoie une nouvelle instance de XML::Handler::XMLWriter avec les OPTIONS données. Les options peuvent être modifiées à tout moment en les modifiant directement dans le hash renvoyé. OPTIONS peut être une liste de paires clé, valeur ou un hash. Les OPTIONS suivantes sont prises en charge :
Output
Un IO::Handle ou l'une de ses sous-classes (comme IO::File). Si ce paramètre n'est pas présent et que l'option AsString n'est pas utilisée, le module écrira sur la sortie standard.
AsString
Renvoie le XML généré sous forme de chaîne à partir de la méthode `parse()' du générateur d'événements PerlSAX.
Newlines
Une valeur vraie ou fausse. Si ce paramètre est présent et que sa valeur est vraie, le module insérera un saut de ligne supplémentaire avant le délimiteur de fermeture des balises de début, de fin et vides pour garantir que le document ne se retrouve pas sur une seule longue ligne. Si le paramètre n'est pas présent, le module n'insérera pas de sauts de ligne.
IsSGML
Une valeur vraie ou fausse. Si ce paramètre est présent et que sa valeur est vraie, le module générera du SGML plutôt que du XML.
print_start_element($element)
Imprime une balise de début pour `$element'. C'est l'action par défaut pour le gestionnaire PerlSAX `start_element()', mais les sous-classes peuvent l'utiliser si elles définissent une méthode de début pour un élément.
print_end_element($element)
Imprime une balise de fin pour `$element'. C'est l'action par défaut pour le gestionnaire PerlSAX `end_element()', mais les sous-classes peuvent l'utiliser si elles définissent une méthode de début pour un élément.
print($output)
Écrit `$output' sur Output et/ou l'ajoute à la chaîne à renvoyer. Les sous-classes peuvent l'utiliser pour écrire une sortie supplémentaire.
