NOM

XML::Parser::Style::Stream - Style de flux pour XML::Parser

SYNOPIS

use XML::Parser;
my $p = XML::Parser->new(Style => 'Stream', Pkg => 'MySubs');
$p->parsefile('foo.xml');

{
  package MySubs;

  sub StartTag {
    my ($e, $name) = @_;
    # faire quelque chose avec les balises de début
  }

  sub EndTag {
    my ($e, $name) = @_;
    # faire quelque chose avec les balises de fin
  }

  sub Characters {
    my ($e, $data) = @_;
    # faire quelque chose avec les nœuds de texte
  }
}

DESCRIPTION

Ce style utilise l'option Pkg pour trouver les sous-programmes dans un paquet donné à appeler pour chaque événement. Si aucun des sous-programmes que ce style recherche n'est présent, l'effet de l'analyse avec ce style est d'imprimer une copie canonique du document sans commentaires ni déclarations. Tous les sous-programmes reçoivent comme premier paramètre l'instance Expat du document qu'ils analysent.

Il recherche les routines suivantes :

  • StartDocument

    Appelé au début de l'analyse.

  • StartTag

    Appelé pour chaque balise de début avec le type d'élément comme deuxième paramètre. La variable $_ contiendra une copie de la balise et la variable %_ contiendra les valeurs des attributs fournies pour cet élément.

  • EndTag

    Appelé pour chaque balise de fin avec le type d'élément comme deuxième paramètre. La variable $_ contiendra une copie de la balise de fin.

  • Text

    Appelé juste avant les balises de début ou de fin avec le texte accumulé sans balisage dans la variable $_.

  • PI

    Appelé pour les instructions de traitement. La variable $_ contiendra une copie de l'instruction de traitement, et la cible et les données sont envoyées comme deuxième et troisième paramètres respectivement.

  • EndDocument

    Appelé à la conclusion de l'analyse.
