NOM

XmVaCreateSimpleMenuBar — Une fonction de création pratique pour le widget RowColumn

SYNTAXE

#include <Xm/RowColumn.h>
Widget XmVaCreateSimpleMenuBar(
Widget parent,
String name);

DESCRIPTION

XmVaCreateSimpleMenuBar crée une instance d'un widget RowColumn de type XmMENU_BAR et retourne l'identifiant du widget associé. Cette routine utilise la convention d'appel de liste d'arguments de longueur variable ANSI C (varargs).

Cette routine crée une barre de menu et ses enfants CascadeButtonGadget. Le nom de chaque bouton est button_n, où n est un entier allant de 0 (zéro) au nombre de boutons du menu moins 1. Les boutons sont nommés et créés dans l'ordre où ils sont spécifiés dans la partie variable de la liste d'arguments.

parent
Spécifie l'identifiant du widget parent
name
Spécifie le nom du widget créé

La partie variable de la liste d'arguments se compose de groupes d'arguments. Le premier argument de chaque groupe est une constante ou une chaîne de caractères et détermine quels arguments suivent dans ce groupe. Le dernier argument de la liste doit être NULL. Voici les premiers arguments possibles dans chaque groupe de varargs :

XmVaCASCADEBUTTON
Ceci est suivi de deux arguments supplémentaires. L'ensemble spécifie un bouton dans la barre de menu et certaines de ses valeurs de ressources. Voici les deux arguments supplémentaires, dans l'ordre :
label
La chaîne d'étiquette, de type XmString
mnemonic
La touche mnémonique, de type KeySym
resource_name
Ceci est suivi d'un argument supplémentaire, la valeur de la ressource, de type XtArgVal. La paire spécifie une ressource et sa valeur pour le widget RowColumn.
XtVaTypedArg
Ceci est suivi de quatre arguments supplémentaires. L'ensemble spécifie une ressource et sa valeur pour le widget RowColumn. Une conversion de type de ressource est effectuée si nécessaire. Voici les quatre arguments supplémentaires, dans l'ordre :
name
Le nom de la ressource, de type String
type
Le type de la valeur de la ressource fournie, de type String
value
La valeur de la ressource (ou un pointeur vers la valeur de la ressource, selon le type et la taille de la valeur), de type XtArgVal
size
La taille de la valeur de la ressource en octets, de type int
XtVaNestedList
Ceci est suivi d'un argument supplémentaire de type XtVarArgsList. Cet argument est une liste imbriquée de varargs retournée par XtVaCreateArgsList.

Pour plus d'informations sur les listes d'arguments de longueur variable, consultez la documentation de X Toolkit Intrinsics.

Un certain nombre de ressources existent spécifiquement pour être utilisées avec cette routine et d'autres routines de création de menus simples. Pour une définition complète de RowColumn et de ses ressources associées, voir XmRowColumn(3).

RETOUR

Retourne l'identifiant du widget RowColumn.

VOIR AUSSI

XmCreateMenuBar(3), XmCreateRowColumn(3), XmCreateSimpleMenuBar(3), et XmRowColumn(3).
