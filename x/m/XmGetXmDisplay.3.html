NOM

XmGetXmDisplay — Une fonction d'affichage qui renvoie l'ID de l'objet XmDisplay pour un affichage spécifié

SYNOPSIS

#include <Xm/Display.h>
Widget XmGetXmDisplay(
Display *display);

DESCRIPTION

XmGetXmDisplay renvoie l'ID de l'objet XmDisplay associé à un affichage. L'application peut accéder aux ressources d'affichage avec XtGetValues.

display
Spécifie l'affichage pour lequel l'ID de l'objet XmDisplay doit être renvoyé

Pour une définition complète de Display et de ses ressources associées, voir XmDisplay(3).

RETOUR

Renvoie l'ID de l'objet XmDisplay pour l'affichage spécifié.
