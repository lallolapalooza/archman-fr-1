SYNTAXE

Ceci est la liste des questions fréquemment posées sur XML::Smart.

QUESTIONS

Pour toute nouvelle question, envoyez un e-mail à l'auteur, mais lisez d'abord toute la FAQ.

Dois-je installer XML::Parser pour pouvoir utiliser XML::Smart ?

Non ! XML::Smart est livré avec 2 analyseurs indépendants, XML::Smart::Parser et XML::Smart::HTMLParser.

Si XML::Parser est trouvé, XML::Smart l'utilisera par défaut, et la 2ème option sera XML::Smart::Parser.

Notez que pour une analyse complexe, XML::Parser est recommandé, mais XML::Smart::Parser fonctionnera aussi bien.

Quelle est la meilleure version de XML::Smart à installer ?

C'est toujours la dernière ! Gardez un œil sur les nouvelles versions avant de demander de l'aide sur XML::Smart.

Notez qu'en interne, XML::Smart est complexe, l'idée principale étant de supprimer la complexité pour le programmeur. L'idée est de permettre au programmeur Perl d'utiliser et de créer des données XML sans vraiment connaître le format XML.

Où puis-je en apprendre davantage sur XML ?

http://www.xml.com

Comment appliquer une DTD à un arbre d'objets XML::Smart ?

Regardez la méthode apply_dtd(). Exemple d'utilisation :

$xml->apply_dtd(q`
<!DOCTYPE cds [
<!ELEMENT cds (album+)>
<!ATTLIST cds
          creator  CDATA
          date     CDATA #REQUIRED
>
<!ELEMENT album (artist , tracks+)>
<!ELEMENT artist (#PCDATA)>
<!ELEMENT tracks (#PCDATA)>
]>
`);

Ceci formatera automatiquement les éléments, attributs, etc...

Comment fonctionne XML::Smart ?

Pour créer XML::Smart, j'ai d'abord créé le module Object::MultiType. Avec lui, vous pouvez avoir un objet qui fonctionne à la fois comme une HASH, un ARRAY, un SCALAR, un CODE et un GLOB. Vous pouvez donc faire des choses comme ceci avec le même objet :

$obj = Object::MultiType->new() ;

$obj->{key} ;
$obj->[0] ;
$obj->method ;

@l = @{$obj} ;
%h = %{$obj} ;

&$obj(args) ;

print $obj "envoyer des données\n" ;

Cela peut sembler fou, et peut devenir encore plus si vous utilisez tie() à l'intérieur, ce que fait XML::Smart.

Pour XML::Smart, l'accès en mode Hash et Array passe par tie(). Autrement dit, vous avez une HASH liée et un ARRAY lié à l'intérieur. Cette Hash et cet Array liés fonctionnent ensemble, de sorte que vous pouvez accéder à une clé de Hash comme à l'index 0 d'un Array, ou accéder à un index 0 comme à une clé de Hash :

%hash = (
key => ['a','b','c']
) ;

$hash->{key}    ## renvoie $hash{key}[0]
$hash->{key}[0] ## renvoie $hash{key}[0]
$hash->{key}[1] ## renvoie $hash{key}[1]

## Inverse :

%hash = ( key => 'a' ) ;

$hash->{key}    ## renvoie $hash{key}
$hash->{key}[0] ## renvoie $hash{key}
$hash->{key}[1] ## renvoie undef

Le meilleur de cette nouvelle ressource est d'éviter les accès erronés aux données et les avertissements lorsque vous essayez d'accéder à une Hash ayant un Array (et vice-versa). Chose qui fait généralement mourir () le script.

Une fois que vous avez un accès facile aux données, vous pouvez utiliser la même ressource pour créer des données ! Par exemple :

## Données précédentes :
<hosts>
  <server address="192.168.2.100" os="linux" type="conectiva" version="9.0"/>
</hosts>

## Maintenant, vous avez {address} comme une clé normale avec une chaîne à l'intérieur :
$XML->{hosts}{server}{address}

## Et pour ajouter une nouvelle adresse, la clé {address} doit être une référence ARRAY !
## Donc, XML::Smart effectue la conversion : ;-P
$XML->{hosts}{server}{address}[1] = '192.168.2.101' ;

## Ajout à une liste dont vous ne connaissez pas la taille :
push(@{$XML->{hosts}{server}{address}} , '192.168.2.102') ;

## Les données maintenant :
<hosts>
  <server os="linux" type="conectiva" version="9.0"/>
    <address>192.168.2.100</address>
    <address>192.168.2.101</address>
    <address>192.168.2.102</address>
  </server>
</hosts>

Après avoir modifié votre arbre XML en utilisant les ressources Hash et Array, vous récupérez simplement les données refaites (via l'arbre Hash à l'intérieur de l'objet) :

my $xmldata = $XML->data ;

Mais notez que XML::Smart renvoie toujours un objet ! Même lorsque vous accédez à une clé finale. Ceci renvoie donc un autre objet, pointant (à l'intérieur) vers la clé :

$addr = $XML->{hosts}{server}{address}[0] ;

## Comme $addr est un objet, vous pouvez ESSAYER d'accéder à plus de données :
$addr->{foo}{bar} ; ## Cela ne génère pas d'avertissements ! renvoie juste UNDEF.
## Mais vous pouvez aussi l'utiliser comme un SCALAR normal :
print "$addr\n" ;
$addr .= ':80' ; ## Après cela, $addr n'est plus un objet, juste un SCALAR !

Lorsque je génère les données XML, de nouvelles lignes (\n) sont ajoutées au contenu !

Vous devriez utiliser les options pour les méthodes data() et save() pour ne pas ajouter d'indentation aux données générées :

$XML->data( noident => 1 ) ;
## ou mieux :
$XML->data( nospace => 1 ) ;
