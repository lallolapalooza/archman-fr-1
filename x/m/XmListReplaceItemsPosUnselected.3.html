NOM

XmListReplaceItemsPosUnselected — Fonction de liste qui remplace des éléments dans une liste sans sélectionner les éléments de remplacement

SYNTAXE

#include <Xm/List.h>
void XmListReplaceItemsPosUnselected(
Widget widget,
XmString *new_items,
int item_count,
int position);

DESCRIPTION

XmListReplaceItemsPosUnselected remplace le nombre spécifié d'éléments dans la liste par de nouveaux éléments, en commençant à la position donnée. Les éléments de remplacement restent non sélectionnés, même s'ils apparaissent actuellement dans la liste XmNselectedItems.

widget
Spécifie l'identifiant du widget Liste dans lequel remplacer les éléments.
new_items
Spécifie un pointeur vers les éléments de remplacement.
item_count
Spécifie le nombre d'éléments dans new_items et le nombre d'éléments dans la liste à remplacer. Ce nombre doit être non négatif.
position
Spécifie la position du premier élément de la liste à remplacer. Une valeur de 1 indique que le premier élément remplacé est le premier élément de la liste ; une valeur de 2 indique qu'il s'agit du deuxième élément ; et ainsi de suite.
À partir de l'élément spécifié dans position, item_count éléments de la liste sont remplacés par les éléments correspondants de new_items. C'est-à-dire que l'élément à la position position est remplacé par le premier élément de new_items ; l'élément après position est remplacé par le deuxième élément de new_items ; et ainsi de suite, jusqu'à ce que item_count soit atteint.

Pour une définition complète de Liste et de ses ressources associées, voir XmList(3).

VOIR AUSSI

XmList(3).
