NOM

XmTabListInsertTabs — Une fonction de commodité qui insère des onglets dans une liste d'onglets

SYNTAXE

#include <Xm/Xm.h>
XmTabList XmTabListInsertTabs(
XmTabList oldlist,
XmTab *tabs,
Cardinal tab_count,
int position);

DESCRIPTION

XmTabListInsertTabs crée une nouvelle liste d'onglets qui inclut les onglets de oldlist. Cette fonction copie les onglets spécifiés dans la liste d'onglets à la position donnée. Les tab_count premiers onglets du tableau tabs sont ajoutés à la liste d'onglets. Si oldlist est NULL, XmTabListInsertTabs crée une nouvelle liste d'onglets ne contenant que les onglets spécifiés.

oldlist
Spécifie la liste d'onglets à laquelle ajouter les onglets. La fonction désalloue oldlist après en avoir extrait les informations requises.
tabs
Spécifie un pointeur vers les onglets à ajouter à la liste d'onglets. Il incombe à l'appelant de libérer les onglets de tabs en utilisant XmTabFree.
tab_count
Spécifie le nombre d'onglets dans tabs.
position
Spécifie la position du premier nouvel onglet dans la liste d'onglets. Une valeur de 0 (zéro) fait du premier nouvel onglet le premier onglet de la liste d'onglets, une valeur de 1 en fait le deuxième onglet, et ainsi de suite. Si position est supérieure au nombre d'onglets dans oldlist, alors les onglets seront insérés à la fin. Si position est négatif, le comptage se fera à rebours à partir de la fin. Une valeur de -1 fait du premier nouvel onglet le dernier onglet, et ainsi de suite.

RETOUR

Si tabs est NULL ou tab_count est 0 (zéro), cette fonction retourne oldlist. Sinon, elle retourne une nouvelle liste d'onglets. La fonction alloue de l'espace pour contenir la liste d'onglets retournée. L'application est responsable de la gestion de l'espace alloué. L'application peut récupérer l'espace alloué en appelant XmTabListFree.

VOIR AUSSI

XmTabList(3) et XmTabListFree(3).
