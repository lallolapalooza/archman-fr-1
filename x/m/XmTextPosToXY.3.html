NOM

XmTextPosToXY — Fonction de texte qui accède à la position x et y d'une position de caractère

SYNTAXE

#include <Xm/Text.h>
Boolean XmTextPosToXY(
Widget widget,
XmTextPosition position,
Position *x,
Position *y);

DESCRIPTION

XmTextPosToXY accède à la position x et y, relativement au coin supérieur gauche du widget Text, d'une position de caractère donnée dans le tampon de texte.

Dans le cas d'une écriture horizontale, la position est l'origine du caractère. Dans le cas d'une écriture verticale, la position est l'origine verticale du caractère.

widget
Spécifie l'identifiant du widget Text
position
Spécifie la position du caractère dans le texte pour laquelle la position x et y est accédée. Il s'agit d'un nombre entier de caractères à partir du début du tampon. La première position de caractère est 0 (zéro).
x
Spécifie le pointeur dans lequel la position x est retournée. La position retournée est la distance entre le côté gauche du widget et la bordure gauche du caractère. Cette valeur n'est significative que si la fonction retourne True.
y
Spécifie le pointeur dans lequel la position y est retournée. La position retournée est la distance entre le haut du widget et la ligne de base du caractère. Cette valeur n'est significative que si la fonction retourne True.

Pour une définition complète de Text et de ses ressources associées, voir XmText(3).

RETOUR

Cette fonction retourne True si la position du caractère est affichée dans le widget Text ; sinon, elle retourne False, et aucune valeur x ou y n'est retournée.

VOIR AUSSI

XmText(3).
