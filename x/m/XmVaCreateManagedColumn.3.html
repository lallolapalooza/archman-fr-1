XmVaCreateColumn(appel de bibliothèque) XmVaCreateColumn(appel de bibliothèque)

NOM

XmVaCreateColumn, XmVaCreateManagedColumn — Fonctions de création pratiques pour un widget Colonne.

SYNTAXE

#include <Xm/Column.h>
Widget XmVaCreateColumn(
Widget parent,
String name,
...);
Widget XmVaCreateManagedColumn(
Widget parent,
String name,
...);

DESCRIPTION

Ces fonctions créent une instance d'un widget Colonne et renvoient l'ID de widget associé. Ces routines utilisent la convention d'appel de liste d'arguments de longueur variable ANSI C (varargs).

La fonction XmVaCreateColumn est une routine pratique qui appelle XtCreateWidget.

La fonction XmVaCreateManagedColumn est une routine pratique qui appelle XtCreateManagedWidget.

parent
Spécifie l'ID du widget parent.
name
Spécifie le nom du widget créé.
...
Spécifie la liste d'arguments variables pour remplacer les valeurs par défaut des ressources.

Pour une définition complète de Colonne et de ses ressources associées, voir XmColumn(3).

RETOUR

Renvoie l'ID du widget Colonne.

LIENS

XmColumn(3), XmCreateColumn(3), XtCreateWidget(3), et XtCreateManagedWidget(3).
