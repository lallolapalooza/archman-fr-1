DESCRIPTION

La bibliothèque d'application de programmation pour l'extension *X11 de Double Buffering, Multi-Buffering et Stéréo* contient les interfaces décrites ci-dessous. À l'exception de *XmbufQueryExtension*, si l'une de ces routines est appelée avec un affichage qui ne prend pas en charge l'extension, l'ExtensionErrorHandler (qui peut être défini avec *XSetExtensionErrorHandler* et fonctionne de la même manière que *XSetErrorHandler*) sera appelée et la fonction retournera.

XmbufQueryExtension renvoie *True* si l'extension de multibuffering/stéréo est disponible sur l'affichage donné. Si l'extension existe, la valeur du premier code d'événement (qui doit être ajoutée aux constantes de type d'événement *MultibufferClobberNotify* et *MultibufferUpdateNotify* pour obtenir les valeurs réelles) est stockée dans event_base_return et la valeur du premier code d'erreur (qui doit être ajoutée à la constante de type d'erreur *MultibufferBadBuffer* pour obtenir la valeur réelle) est stockée dans error_base_return.

XmbufGetVersion récupère les numéros de version majeure et mineure de l'extension. La valeur de retour est zéro si une erreur se produit ou non nulle si aucune erreur ne se produit.

XmbufCreateBuffers demande que "count" tampons soient créés avec l'action de mise à jour et l'indice de mise à jour donnés et qu'ils soient associés à la fenêtre indiquée. Le nombre de tampons créés est renvoyé (zéro si une erreur s'est produite) et buffers_update est rempli avec ce nombre d'identifiants Multibuffer.

XmbufDestroyBuffers détruit les tampons associés à la fenêtre donnée.

XmbufDisplayBuffers affiche les tampons indiqués sur leurs fenêtres appropriées dans un délai maximal de max_delay millisecondes après l'expiration de min_delay millisecondes. Deux tampons ne peuvent pas être associés à la même fenêtre, sinon une erreur Match est générée.

XmbufGetWindowAttributes obtient les attributs de multibuffering qui s'appliquent à tous les tampons associés à la fenêtre donnée. La liste des tampons renvoyée peut être libérée avec *XFree*. Renvoie une valeur non nulle en cas de succès et zéro en cas d'erreur.

XmbufChangeWindowAttributes définit les attributs de multibuffering qui s'appliquent à tous les tampons associés à la fenêtre donnée. Ceci est actuellement limité à l'indice de mise à jour.

XmbufGetBufferAttributes obtient les attributs du tampon indiqué. Renvoie une valeur non nulle en cas de succès et zéro en cas d'erreur.

XmbufChangeBufferAttributes définit les attributs du tampon indiqué. Ceci est actuellement limité au masque d'événements.

XmbufGetScreenInfo obtient les paramètres contrôlant la façon dont les fenêtres mono et stéréo peuvent être créées sur l'écran du dessin donné. Le nombre d'ensembles de visuels et de profondeurs est renvoyé dans nmono_return et nstereo_return. Si nmono_return est supérieur à zéro, alors mono_info_return est défini sur l'adresse d'un tableau de structures *XmbufBufferInfo* décrivant les différents visuels et profondeurs qui peuvent être utilisés. Sinon, mono_info_return est défini sur NULL. De même, stereo_info_return est défini en fonction de nstereo_return. Le stockage renvoyé dans mono_info_return et stereo_info_return peut être libéré par *XFree*. Si aucune erreur n'est rencontrée, une valeur non nulle sera renvoyée.

XmbufCreateStereoWindow crée une fenêtre stéréo de la même manière que *XCreateWindow* crée une fenêtre mono. Les identifiants de tampon pour les tampons gauche et droit sont renvoyés respectivement dans left_return et right_return. Si un gestionnaire d'erreurs d'extension qui retourne est installé, *None* sera renvoyé si l'extension n'est pas disponible sur cet affichage.

SYNTAX

#include <X11/extensions/mbuf.h>

STRUCTURES

The following structures are used by the multi-buffering extension:

XmbufWindowAttributes
This structure contains information about the multi-buffering attributes of a window.
XmbufMultibufferStack
This structure contains information about the multi-buffering stack of a window.
XmbufWindowPixmap
This structure contains information about the pixmaps associated with a window.
XmbufMultibufferNotifyMask
This structure contains information about the notification mask for multi-buffering events.
XmbufMultibufferClipMask
This structure contains information about the clipping mask for multi-buffering operations.
XmbufMultibufferBufferMask
This structure contains information about the buffer mask for multi-buffering operations.
XmbufMultibufferUpdateNotifyMask
This structure contains information about the update notification mask for multi-buffering events.

DESCRIPTION

The multi-buffering extension provides a mechanism for applications to use multiple buffers for rendering, allowing for smoother animations and reduced flickering. The functions described in this manual page allow applications to query and modify the multi-buffering attributes of windows, manage multi-buffering stacks, and handle multi-buffering events.

PREDEFINED VALUES

The following constants are defined for use with the multi-buffering extension:

MultibufferClobberNotify
MultibufferUpdateNotify
MultibufferNumberEvents
MultibufferBadBuffer
MultibufferNumberErrors
