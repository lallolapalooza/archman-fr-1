NOM

XmTextScroll — Appel de fonction Text faisant défiler du texte

SYNTAXE

#include <Xm/Text.h>
void XmTextScroll(
Widget widget,
int lines);

DESCRIPTION

XmTextScroll fait défiler le texte d'un nombre donné de lignes dans un widget Text. Le signe du nombre est interprété en fonction de la valeur de la ressource XmNlayoutDirection.

widget
Spécifie l'identifiant du widget Text.
lines
Spécifie le nombre de lignes de texte à faire défiler. Une valeur positive fait défiler le texte vers le haut ; une valeur négative fait défiler le texte vers le bas. Notez que le texte ne fera défiler que tant qu'une ligne de texte restera visible dans la fenêtre.
Si un navigateur existe, cette fonction utilise le trait XmQTnavigator pour mettre à jour la valeur du navigateur vertical.
Dans le cas de l'écriture verticale, une valeur positive fait défiler le texte vers l'avant ; une valeur négative fait défiler les lignes vers l'arrière.

Pour une définition complète de Text et de ses ressources associées, voir XmText(3).

VOIR AUSSI
