NOM

XmDropSiteRegister — Une fonction de glisser-déposer qui identifie un site de dépôt et lui attribue des ressources spécifiant son comportement

SYNTAXE

#include <Xm/DragDrop.h>
void XmDropSiteRegister(
Widget widget,
ArgList arglist,
Cardinal argcount);

DESCRIPTION

XmDropSiteRegister identifie le widget ou le gadget spécifié comme site de dépôt et définit les valeurs des ressources qui déterminent le comportement du site de dépôt. La routine attribue des valeurs par défaut à toute ressource non spécifiée dans la liste d'arguments. Le toolkit génère un message d'avertissement si un site de dépôt est enregistré avec XmNdropSiteActivity défini sur XmDROP_SITE_ACTIVE et que la ressource XmNdropProc est NULL.

Si le site de dépôt est un descendant d'un widget enregistré comme site de dépôt, la ressource XmNdropSiteType du site de dépôt ancêtre doit être spécifiée comme XmDROP_SITE_COMPOSITE. L'ancêtre doit être enregistré avant le descendant. Le site de dépôt est empilé au-dessus de tous les autres sites de dépôt frères déjà enregistrés.

widget
Spécifie l'ID du widget à enregistrer.
arglist
Spécifie la liste d'arguments.
argcount
Spécifie le nombre de paires attribut/valeur dans la liste d'arguments (arglist).

Pour une définition complète de DropSite et de ses ressources associées, voir XmDropSite(3).
