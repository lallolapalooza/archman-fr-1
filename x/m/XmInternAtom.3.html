NOM

XmInternAtom — Une macro qui retourne un atome pour un nom donné

SYNTAXE

#include <Xm/AtomMgr.h>
Atom XmInternAtom(
Display * display,
String name,
Boolean only_if_exists);

DESCRIPTION

XmInternAtom retourne un atome pour un nom donné. L'atome retourné reste défini même après la fermeture de la connexion du client. L'atome retourné devient indéfini lorsque la dernière connexion au serveur X se ferme.

display
Spécifie la connexion au serveur X.
name
Spécifie le nom associé à l'atome que vous souhaitez obtenir. La valeur de name est sensible à la casse.
only_if_exists
Spécifie une valeur booléenne. Si Faux, l'atome est créé même s'il n'existe pas. (S'il n'existe pas, l'atome retourné sera None.) Si Vrai, l'atome est créé uniquement s'il existe.

RETOUR

Retourne un atome.
