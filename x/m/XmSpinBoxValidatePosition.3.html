XmSpinBoxValidatePosition(3) — appel de bibliothèque XmSpinBoxValidatePosition(3) — appel de bibliothèque

NOM

XmSpinBoxValidatePosition — traduit la valeur actuelle de l'enfant XmSpinBox spécifié en une position valide

SYNOPSIS

#include <Xm/SpinBox.h>
int XmSpinBoxValidatePosition(
Widget textfield,
int *position);

DESCRIPTION

La fonction XmSpinBoxValidatePosition est un utilitaire qui peut être utilisé par les applications souhaitant implémenter une politique pour suivre les modifications de l'utilisateur sur les enfants XmSpinBox modifiables de type XmNUMERIC. Les détails sur quand et comment les modifications de l'utilisateur prennent effet sont laissés à l'application.

text_field
L'argument text_field spécifie l'ID du widget enfant de XmSpinBox qui est en cours de modification. L'exigence sur text_field est qu'il détienne le trait accessTextual (déjà une exigence pour les enfants de XmSpinBox). De cette façon, XmSpinBox peut extraire la chaîne du widget text_field (même si ce n'est pas un XmTextField).
position
L'emplacement pointé par l'argument position se voit attribuer le résultat de la traduction effectuée par XmSpinBoxValidatePosition. XmSpinBoxValidatePosition vérifie d'abord pour s'assurer qu'il s'agit d'un enfant XmNUMERIC de XmSpinBox. Si ce n'est pas le cas, XmSpinBoxValidatePosition définit position à la position actuelle et renvoie XmCURRENT_VALUE.

XmSpinBoxValidatePosition tente de traduire la chaîne d'entrée en un nombre à virgule flottante. Si cette traduction échoue, XmSpinBoxValidatePosition définit position à la position actuelle et renvoie XmCURRENT_VALUE.

XmSpinBoxValidatePosition convertit le nombre à virgule flottante en un entier en utilisant la ressource XmNdecimalPoints. Les décimales supplémentaires sont tronquées. L'entier résultant est vérifié dans ses limites pour s'assurer qu'il se situe dans la plage valide définie par XmNminimumValue et XmNmaximumValue inclus. Si l'entrée se situe en dehors de cette plage, XmSpinBoxValidatePosition définit position à la limite la plus proche et renvoie XmMINIMUM_VALUE ou XmMAXIMUM_VALUE.

Enfin, XmSpinBoxValidatePosition vérifie l'entier pour s'assurer qu'il appartient à la série définie par XmNminimumValue ... XmNminimumValue + ((n - 1) * XmNincrementValue). Si l'entier n'appartient pas à cette série, XmSpinBoxValidatePosition définit position à l'élément le plus proche qui est inférieur ou égal à l'entier et renvoie XmINCREMENT_VALUE.

Sinon, XmSpinBoxValidatePosition attribue l'entier à position et renvoie XmVALID_VALUE.

VALEUR DE RETOUR

La fonction XmSpinBoxValidatePosition renvoie le statut de la validation. L'ensemble des valeurs possibles renvoyées est le suivant :

XmCURRENT_VALUE
Impossible de convertir, renvoie la valeur de position actuelle.
XmMINIMUM_VALUE
Inférieur au minimum.
XmMAXIMUM_VALUE
Supérieur au maximum.
XmINCREMENT_VALUE
Pas sur l'incrément.
XmVALID_VALUE
OK.

EXEMPLES

Le premier exemple montre comment la fonction XmSpinBoxValidatePosition pourrait être utilisée depuis une fonction de rappel XmNmodifyVerifyCallback installée sur le XmSpinBox ou le XmSimpleSpinBox :

/*
 * Installer une fonction de rappel sur une pression de flèche de spin box.
 */
  XtAddCallback(sb, XmNmodifyVerifyCallback, ModifyVerifyCB, NULL);
  XtAddCallback(simple_sb, XmNmodifyVerifyCallback, ModifyVerifyCB, NULL);

avec la fonction de rappel faisant :

void ModifyVerifyCB(widget, call_data, client_data) {
    XmSpinBoxCallbackStruct *cbs = (XmSpinBoxCallbackStruct*) call_data;
    int position;
    Widget textual = NULL;
    if (XtIsSubclass(w, xmSimpleSpinBoxWidgetClass))
    {
        Arg args[1];
        XtSetArg(args[0], XmNtextField, &textual);
        XtGetValues(w, args, 1);
    }
    else if (XtIsSubclass(w, xmSpinBoxWidgetClass))
      textual = cbs->widget;
    else
      textual = (Widget) NULL;
    ...
    if (XmSpinBoxValidatePosition(textual, &position) == XmCURRENT_VALUE)
      XBell(XtDisplay(w), 0);
    else
      cbs->position = position;
}

Ce deuxième exemple montre comment la fonction XmSpinBoxValidatePosition pourrait être utilisée depuis une fonction de rappel XmNactivateCallback installée sur l'enfant TextField du XmSpinBox :

/*
 * Installer une fonction de rappel sur une pression de flèche de spin box.
 */
XtAddCallback(tf, XmNactivateCallback, ModifyVerifyChildCB, NULL);

avec la fonction de rappel faisant :

void ModifyVerifyChildCB(widget, call_data, client_data) {
    int     position;
    Widget  textual = widget;
    Arg     args[1];
    if (XmSpinBoxValidatePosition (textual, &position) == XmCURRENT_VALUE)
      XBell(XtDisplay(widget), 0);
    /* Définir la ressource de contrainte de position du textfield */
    XtSetArg(args[0], XmNposition, position);
    XtSetValues(textual, args, 1);
}
