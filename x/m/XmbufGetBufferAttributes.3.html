DESCRIPTION

La bibliothèque d'interface de programmation pour l'extension de Double-Buffering, Multi-Buffering et Stéréo X11 contient les interfaces décrites ci-dessous. À l'exception de XmbufQueryExtension, si l'une de ces routines est appelée avec un display qui ne prend pas en charge l'extension, l'ExtensionErrorHandler (qui peut être défini avec XSetExtensionErrorHandler et fonctionne de la même manière que XSetErrorHandler) sera appelée et la fonction renverra alors.

XmbufQueryExtension renvoie True si l'extension de mise en mémoire tampon multiple/stéréo est disponible sur le display donné. Si l'extension existe, la valeur du premier code d'événement (qui doit être ajouté aux constantes de type d'événement MultibufferClobberNotify et MultibufferUpdateNotify pour obtenir les valeurs réelles) est stockée dans event_base_return et la valeur du premier code d'erreur (qui doit être ajouté à la constante de type d'erreur MultibufferBadBuffer pour obtenir la valeur réelle) est stockée dans error_base_return.

XmbufGetVersion obtient les numéros de version majeure et mineure de l'extension. La valeur de retour est zéro si une erreur se produit ou non nulle si aucune erreur ne se produit.

XmbufCreateBuffers demande la création de "count" tampons avec l'action de mise à jour et l'indice de mise à jour donnés et leur association avec la fenêtre indiquée. Le nombre de tampons créés est renvoyé (zéro si une erreur s'est produite) et buffers_update est rempli avec ce nombre d'identifiants Multibuffer.

XmbufDestroyBuffers détruit les tampons associés à la fenêtre donnée.

XmbufDisplayBuffers affiche les tampons indiqués dans leurs fenêtres appropriées dans un délai maximum de max_delay millisecondes après que min_delay millisecondes se soient écoulées. Deux tampons ne peuvent pas être associés à la même fenêtre, sinon une erreur Match est générée.

XmbufGetWindowAttributes obtient les attributs de mise en mémoire tampon multiple qui s'appliquent à tous les tampons associés à la fenêtre donnée. La liste des tampons renvoyée peut être libérée avec XFree. Renvoie une valeur non nulle en cas de succès et zéro en cas d'erreur.

XmbufChangeWindowAttributes définit les attributs de mise en mémoire tampon multiple qui s'appliquent à tous les tampons associés à la fenêtre donnée. Ceci est actuellement limité à l'indice de mise à jour.

XmbufGetBufferAttributes obtient les attributs pour le tampon indiqué. Renvoie une valeur non nulle en cas de succès et zéro en cas d'erreur.

XmbufChangeBufferAttributes définit les attributs pour le tampon indiqué. Ceci est actuellement limité au masque d'événements.

XmbufGetScreenInfo obtient les paramètres contrôlant la façon dont les fenêtres mono et stéréo peuvent être créées sur l'écran du dessinable donné. Les nombres d'ensembles de visuels et de profondeurs sont renvoyés dans nmono_return et nstereo_return. Si nmono_return est supérieur à zéro, alors mono_info_return est défini à l'adresse d'un tableau de structures XmbufBufferInfo décrivant les différents visuels et profondeurs qui peuvent être utilisés. Sinon, mono_info_return est défini à NULL. De même, stereo_info_return est défini en fonction de nstereo_return. Le stockage renvoyé dans mono_info_return et stereo_info_return peut être libéré par XFree. Si aucune erreur n'est rencontrée, une valeur non nulle sera renvoyée.

XmbufCreateStereoWindow crée une fenêtre stéréo de la même manière que XCreateWindow crée une fenêtre mono. Les identifiants de tampon pour les tampons gauche et droit sont renvoyés dans left_return et right_return, respectivement. Si un gestionnaire d'erreurs d'extension qui renvoie est installé, None sera renvoyé si l'extension n'est pas disponible sur ce display.

    Display *dpy,
    XID buffer,
    unsigned long *n_attributes,
    XBufferAttribute **attributes
);

STRUCTURES

typedef struct {
    unsigned int type;
    unsigned int size;
    void *data;
} XBufferAttribute;

DESCRIPTION

This function returns the attributes associated with the specified buffer.

The attributes argument is a pointer to an array of XBufferAttribute structures. The n_attributes argument is a pointer to a value that will be updated with the number of attributes returned.

The XBufferAttribute structure contains the following fields:

  • type: The type of the attribute.
  • size: The size of the attribute data in bytes.
  • data: A pointer to the attribute data. The format of the data depends on the attribute type.

The function returns 0 on success, and a negative value on error.

NOM

XmbufGetBufferAttributes - obtenir les attributs du tampon

SYNTAXE

int XmbufGetBufferAttributes(
    Display *dpy,
    XID buffer,
    unsigned long *n_attributes,
    XBufferAttribute **attributes
);

STRUCTURES

typedef struct {
    unsigned int type;
    unsigned int size;
    void *data;
} XBufferAttribute;

DESCRIPTION

Cette fonction retourne les attributs associés au tampon spécifié.

L'argument attributes est un pointeur vers un tableau de structures XBufferAttribute. L'argument n_attributes est un pointeur vers une valeur qui sera mise à jour avec le nombre d'attributs retournés.

La structure XBufferAttribute contient les champs suivants :

  • type : Le type de l'attribut.
  • size : La taille des données de l'attribut en octets.
  • data : Un pointeur vers les données de l'attribut. Le format des données dépend du type d'attribut.

La fonction retourne 0 en cas de succès et une valeur négative en cas d'erreur.
