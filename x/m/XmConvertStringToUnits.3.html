NOM

XmConvertStringToUnits — Une fonction qui convertit une spécification de chaîne en une valeur d'unité

SYNTAXE

#include <Xm/Xm.h>
int XmConvertStringToUnits(
Screen *screen,
String spec,
int orientation,
int to_type,
XtEnum *parse_error);

DESCRIPTION

XmConvertStringToUnits convertit une valeur spécifiée par une chaîne et retourne la valeur convertie comme valeur de retour de la fonction. Cette fonction utilise la résolution de l'écran spécifié pour calculer le nombre d'unités pour la spécification de chaîne.

screen
Spécifie l'écran dont la résolution doit être utilisée pour le calcul.
spec
Spécifie la chaîne, au format <valeur flottante><unité>, à convertir.
orientation
Spécifie si le convertisseur utilise la résolution d'écran horizontale ou verticale lors de la conversion. Le paramètre orientation peut avoir les valeurs XmHORIZONTAL ou XmVERTICAL.
to_type
Convertit la valeur dans le type d'unité spécifié. Se référer à la ressource XmNunitType de la page de référence XmGadget, XmManager ou XmPrimitive. Ce paramètre peut avoir l'une des valeurs suivantes :
XmPIXELS
La valeur retournée sera le nombre de pixels.
XmMILLIMETERS
La valeur retournée sera le nombre de millimètres.
Xm100TH_MILLIMETERS
Les valeurs retournées seront le nombre de 1/100 de millimètre.
XmCENTIMETERS
Les valeurs retournées seront le nombre de centimètres.
XmINCHES
Les valeurs retournées seront le nombre de pouces.
Xm1000TH_INCHES
Les valeurs retournées seront le nombre de 1/1000 de pouce.
XmPOINTS
Les valeurs retournées seront le nombre de points. Un point est une unité de traitement de texte définie comme 1/72 de pouce.
Xm100TH_POINTS
Les valeurs retournées seront le nombre de 1/100 de point.
XmFONT_UNITS
Toutes les valeurs fournies au widget sont traitées comme des unités de police. Une unité de police a des composantes horizontale et verticale. Ce sont les valeurs des ressources XmScreen XmNhorizontalFontUnit et XmNverticalFontUnit.
Xm100TH_FONT_UNITS
Toutes les valeurs fournies au widget sont traitées comme 1/100 d'unité de police. Une unité de police a des composantes horizontale et verticale. Ce sont les valeurs des ressources XmScreen XmNhorizontalFontUnit et XmNverticalFontUnit.
parse_error
Spécifie si une erreur d'analyse s'est produite. Une valeur de True indique qu'une erreur s'est produite, une valeur de False indique qu'aucune erreur.

VALEUR DE RETOUR

Retourne la valeur convertie. Si un écran NULL, une orientation incorrecte, ou un unit_type incorrect sont fournis comme données de paramètre, ou si une erreur d'analyse s'est produite, 0 (zéro) est retourné.

LIENS CONNEXES

XmConvertUnits(3), XmSetFontUnits(3), et XmScreen(3).
