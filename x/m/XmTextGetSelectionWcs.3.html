NOM

XmTextGetSelectionWcs — Appel de bibliothèque Texte qui récupère la valeur d'une sélection primaire codée en caractères larges

SYNTAXE

#include <Xm/Text.h>
wchar_t * XmTextGetSelectionWcs(
Widget widget);

DESCRIPTION

XmTextGetSelectionWcs récupère la valeur de la sélection primaire qui est codée dans un format de caractères larges. Elle renvoie un pointeur NULL si aucun texte n'est sélectionné dans le widget. L'application est responsable de libérer le stockage associé au tampon de caractères larges en appelant XtFree.

widget
Spécifie l'identifiant du widget Texte

Pour une définition complète de Texte et de ses ressources associées, voir XmText(3).

VALEUR RETOURNÉE

Renvoie la chaîne de caractères larges associée à la sélection primaire dans le widget Texte.

VOIR AUSSI

XmText(3) et XmTextGetSelection(3).
