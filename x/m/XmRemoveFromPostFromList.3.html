NOM

XmRemoveFromPostFromList — fonction de RowColumn qui désactive un menu pour un widget particulier

SYNTAXE

#include <Xm/RowColumn.h>

void XmRemoveFromPostFromList(
Widget menu,
Widget post_from_widget);

DESCRIPTION

XmRemoveFromPostFromList rend un menu Popup ou Pulldown inaccessible à partir d'un widget. Cette fonction ne détruit pas un menu, ni ne désalloue la mémoire qui lui est associée. Elle retire simplement le widget de la liste des widgets autorisés à activer ce menu.

Si l'argument menu fait référence à un menu Popup, les gestionnaires d'événements sont retirés du widget post_from_widget. Si l'argument fait référence à un menu Pulldown, son ID est retiré du XmNsubMenuId du post_from_widget spécifié. De plus, si le menu est un menu Pulldown, le widget post_from_widget doit être soit un CascadeButton, soit un CascadeButtonGadget.

menu
Spécifie l'ID du widget du menu Popup ou Pulldown qui doit être rendu inaccessible à partir du widget post_from_widget.
post_from_widget
Spécifie l'ID du widget qui ne peut plus activer le menu référencé par l'argument menu.

Pour une définition complète de RowColumn et de ses ressources associées, voir XmRowColumn(3).

VOIR AUSSI

XmAddToPostFromList(3), XmGetPostedFromWidget(3), et XmRowColumn(3).
