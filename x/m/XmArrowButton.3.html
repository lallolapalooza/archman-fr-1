NOM

XmArrowButton — La classe de widget ArrowButton

SYNTAXE

#include <Xm/ArrowB.h>

DESCRIPTION

ArrowButton est constitué d'une flèche directionnelle entourée d'une ombre de bordure. Lorsqu'il est sélectionné, l'ombre change pour donner l'apparence que le ArrowButton a été enfoncé. Lorsque le ArrowButton n'est pas sélectionné, l'ombre revient à son état initial pour donner l'apparence que le ArrowButton est relâché, ou sorti.

ArrowButton détient le trait XmQTactivatable.

Classes

ArrowButton hérite du comportement, des ressources et des traits des classes Core et XmPrimitive.

Le pointeur de classe est xmArrowButtonWidgetClass.

Le nom de la classe est XmArrowButton.

NAME

XmArrowButton — A button that displays an arrow and invokes a callback routine when activated

SYNOPSIS

#include <Xm/ArrowB.h>

This section describes the XmArrowButton widget.

DESCRIPTION

The XmArrowButton widget displays an arrow and invokes a callback routine when activated. It provides a simple button mechanism for invoking functions. The widget's appearance is defined by the arrow's direction, foreground and background colors, and shadow characteristics.

The widget inherits its behavior from the XmPrimitive class. XmArrowButton adds arrow-specific behavior and resources to XmPrimitive.

XmArrowButton is a subclass of XmManager. It has no children.

The XmNfillOnArm resource is used to determine whether the arrow is filled when the button is armed.

Callback Information

A pointer to the following structure is passed to each callback:

typedef struct
{
        int reason;
        XEvent * event;
        int click_count;
} XmArrowButtonCallbackStruct;
reason
Indicates why the callback was invoked.
event
Points to the XEvent that triggered the callback.
click_count
This value is valid only when the reason is XmCR_ACTIVATE. It contains the number of clicks in the last multiclick sequence if the XmNmultiClick resource is set to XmMULTICLICK_KEEP; otherwise it contains 1. The activate callback is invoked for each click if XmNmultiClick is set to XmMULTICLICK_KEEP.

Action Routines

The XmArrowButton action routines are

Activate():
Draws the shadow in the unselected state. If the pointer is within the ArrowButton, calls the callbacks for XmNactivateCallback.
Arm():
Draws the shadow in the selected state and calls the callbacks for XmNarmCallback.
ArmAndActivate():
Draws the shadow in the selected state and calls the callbacks for XmNarmCallback. Arranges for the shadow to be drawn in the unselected state and the callbacks for XmNactivateCallback and XmNdisarmCallback to be called, either immediately or at a later time.
ButtonTakeFocus():
Takes focus if the widget is not already focused.
Disarm():
Draws the shadow in the unselected state and calls the callbacks for XmNdisarmCallback.
Enter():
Called when the pointer enters the widget. If the widget has armed itself, it redraws the shadow in the armed state.
Leave():
Called when the pointer leaves the widget. If the widget has armed itself, it redraws the shadow in the disarmed state.
MultiActivate():
Called for subsequent clicks in a multi-click sequence. Calls the callbacks for XmNactivateCallback.
MultiArm():
Called for subsequent clicks in a multi-click sequence. Calls the callbacks for XmNarmCallback.
PrimitiveParentActivate():
Calls the callbacks for XmNactivateCallback.
PrimitiveParentCancel():
Calls the callbacks for XmNcancelCallback.

NAME

XmArrowButton

a widget that displays an arrow and generates arrow button events

SYNOPSIS

#include <Xm/ArrowB.h>

A managed child of a XmManager widget.

WidgetClass: xmArrowButtonWidgetClass

Creation:

XtCreateManagedWidget("arrowButton", xmArrowButtonWidgetClass, parent, arg, argCount);
XmCreateArrowButton(parent, name, arg, argCount);
XmCreateArrowButtonGadget(parent, name, arg, argCount);

DESCRIPTION

The XmArrowButton widget is a rectangular widget that displays an arrow. The arrow can point up, down, left, or right. An arrow button can generate events when the pointer passes over it, when it is clicked, or when it is activated by the keyboard. The arrow button can also be used as a trigger for other actions.

CALLBACKS

The following callbacks are defined for the XmArrowButton widget:

XmNactivateCallback:
Called when the widget is activated. Activation occurs when the user presses and releases a mouse button while the pointer is within the widget boundaries, or when the user presses the Enter or Spacebar key while the widget has focus.
XmNarmCallback:
Called when the widget is armed. Arming occurs when the user presses a mouse button while the pointer is within the widget boundaries, or when the user presses the Enter or Spacebar key while the widget has focus.
XmNdisarmCallback:
Called when the widget is disarmed. Disarming occurs when the user releases a mouse button while the pointer is within the widget boundaries, or when the user releases the Enter or Spacebar key while the widget has focus.
XmNhelpCallback:
Called when the widget isHelp.

ACTIONS

The XmArrowButton widget has the following actions:

ButtonTakeFocus():
Causes the ArrowButton to take keyboard focus when Ctrl<Btn1Down> is pressed, without activating the widget.
Disarm():
Draws the shadow in the unselected state and calls the callbacks for XmNdisarmCallback.
Help():
Calls the callbacks for XmNhelpCallback if any exist. If there are no help callbacks for this widget, this action calls the help callbacks for the nearest ancestor that has them.
MultiActivate():
If XmNmultiClick is XmMULTICLICK_DISCARD, this action does nothing.
If XmNmultiClick is XmMULTICLICK_KEEP, this action increments click_count in the callback structure and draws the shadow in the unselected state. If the pointer is within the ArrowButton, this action calls the callbacks for XmNactivateCallback and XmNdisarmCallback.
MultiArm():
If XmNmultiClick is XmMULTICLICK_DISCARD, this action does nothing. If XmNmultiClick is XmMULTICLICK_KEEP, this action draws the shadow in the selected state and calls the callbacks for XmNarmCallback.

Additional Behavior

This widget has the following additional behavior:

<EnterWindow>:
Draws the ArrowButton shadow in its selected state if the pointer leaves and re-enters the window while <Btn1> is pressed.
<LeaveWindow>:
Draws the ArrowButton shadow in its unselected state if the pointer leaves the window while <Btn1> is pressed.

Virtual Bindings

The bindings for virtual keys are vendor specific. For information about bindings for virtual buttons and keys, see VirtualBindings(3).

RELATED

Core(3), XmCreateArrowButton(3), XmPrimitive(3), XmVaCreateArrowButton(3), and XmVaCreateManagedArrowButton(3).

NOM

XmArrowButton

un widget qui affiche une flèche et génère des événements de bouton flèche

SYNTAXE

#include <Xm/ArrowB.h>

Un enfant géré d'un widget XmManager.

WidgetClass: xmArrowButtonWidgetClass

Création:

XtCreateManagedWidget("arrowButton", xmArrowButtonWidgetClass, parent, arg, argCount);
XmCreateArrowButton(parent, name, arg, argCount);
XmCreateArrowButtonGadget(parent, name, arg, argCount);

DESCRIPTION

Le widget XmArrowButton est un widget rectangulaire qui affiche une flèche. La flèche peut pointer vers le haut, le bas, la gauche ou la droite. Un bouton flèche peut générer des événements lorsque le pointeur passe dessus, lorsqu'il est cliqué, ou lorsqu'il est activé par le clavier. Le bouton flèche peut également être utilisé comme déclencheur pour d'autres actions.

CALLBACKS

Les callbacks suivants sont définis pour le widget XmArrowButton:

XmNactivateCallback:
Appelé lorsque le widget est activé. L'activation se produit lorsque l'utilisateur appuie et relâche un bouton de souris tandis que le pointeur est dans les limites du widget, ou lorsque l'utilisateur appuie sur la touche Entrée ou Espace tandis que le widget a le focus.
XmNarmCallback:
Appelé lorsque le widget est armé. L'armement se produit lorsque l'utilisateur appuie sur un bouton de souris tandis que le pointeur est dans les limites du widget, ou lorsque l'utilisateur appuie sur la touche Entrée ou Espace tandis que le widget a le focus.
XmNdisarmCallback:
Appelé lorsque le widget est désarmé. Le désarmement se produit lorsque l'utilisateur relâche un bouton de souris tandis que le pointeur est dans les limites du widget, ou lorsque l'utilisateur relâche la touche Entrée ou Espace tandis que le widget a le focus.
XmNhelpCallback:
Appelé lorsque le widget est Help.

ACTIONS

Le widget XmArrowButton a les actions suivantes :

ButtonTakeFocus():
Demande au bouton flèche de prendre le focus du clavier lorsque Ctrl<Btn1Down> est pressé, sans activer le widget.
Disarm():
Dessine l'ombre dans l'état non sélectionné et appelle les callbacks pour XmNdisarmCallback.
Help():
Appelle les callbacks pour XmNhelpCallback s'il en existe. S'il n'y a pas de callbacks d'aide pour ce widget, cette action appelle les callbacks d'aide de l'ancêtre le plus proche qui en possède.
MultiActivate():
Si XmNmultiClick est XmMULTICLICK_DISCARD, cette action ne fait rien.
Si XmNmultiClick est XmMULTICLICK_KEEP, cette action incrémente click_count dans la structure de callback et dessine l'ombre dans l'état non sélectionné. Si le pointeur est à l'intérieur du bouton flèche, cette action appelle les callbacks pour XmNactivateCallback et XmNdisarmCallback.
MultiArm():
Si XmNmultiClick est XmMULTICLICK_DISCARD, cette action ne fait rien. Si XmNmultiClick est XmMULTICLICK_KEEP, cette action dessine l'ombre dans l'état sélectionné et appelle les callbacks pour XmNarmCallback.

Comportement supplémentaire

Ce widget a le comportement supplémentaire suivant :

<EnterWindow>:
Dessine l'ombre du bouton flèche dans son état sélectionné si le pointeur quitte et rentre dans la fenêtre pendant que <Btn1> est enfoncé.
<LeaveWindow>:
Dessine l'ombre du bouton flèche dans son état non sélectionné si le pointeur quitte la fenêtre pendant que <Btn1> est enfoncé.

Liaisons virtuelles

Les liaisons pour les touches virtuelles sont spécifiques au vendeur. Pour plus d'informations sur les liaisons pour les boutons et touches virtuels, voir VirtualBindings(3).
