NOM

XmSlideContext - Classe du widget SlideContext

SYNTAXE

#include <Xm/SlideC.h>

DESCRIPTION


SlideContext peut être utilisé pour modifier la géométrie d'un widget sur une période de temps.

Paragraphe suivant

Paragraphe suivant

Classes

SlideContext hérite du comportement et des ressources de la classe Object.

Le pointeur de classe est XmSlideContextWidgetClass.

Le nom de la classe est XmSlideContext.

Nouvelles Ressources

Le tableau suivant définit un ensemble de ressources de widget utilisées par le programmeur pour spécifier des données. Le programmeur peut également définir les valeurs des ressources pour les classes héritées afin de définir les attributs de ce widget. Pour référencer une ressource par son nom ou par sa classe dans un fichier .Xdefaults, supprimez le préfixe XmN ou XmC et utilisez les lettres restantes. Pour spécifier l'une des valeurs définies pour une ressource dans un fichier .Xdefaults, supprimez le préfixe Xm et utilisez les lettres restantes (en minuscules ou majuscules, mais incluez les tirets bas entre les mots). Les codes dans la colonne d'accès indiquent si la ressource donnée peut être définie au moment de la création (C), définie à l'aide de XtSetValues (S), récupérée à l'aide de XtGetValues (G), ou n'est pas applicable (N/A).

Comportement

Le comportement de XmSlideContext est décrit ci-dessous : XmSlideContext installe un timer Xt qui est appelé toutes les XmNslideInterval millisecondes. À chaque appel de la procédure de timer, la géométrie de XmNslideWidget est ajustée de telle sorte que les valeurs X/Y/Largeur/Hauteur soient 10 % plus proches des valeurs finales. Le XmSlideContext est automatiquement détruit lorsque XmNslideWidget atteint sa destination. Si XmNslideWidget est détruit avant que le glissement ne soit terminé, le XmSlideContext est détruit.

Liaisons Virtuelles

Les liaisons pour les touches virtuelles sont spécifiques au vendeur. Pour plus d'informations sur les liaisons pour les boutons et les touches virtuels, voir VirtualBindings(3X).
