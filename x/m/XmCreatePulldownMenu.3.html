NOM

XmCreatePulldownMenu — Fonction utilitaire de création de widget RowColumn

SYNTAXE

#include <Xm/RowColumn.h>
Widget XmCreatePulldownMenu(
Widget parent,
String name,
ArgList arglist,
Cardinal argcount);

DESCRIPTION

XmCreatePulldownMenu crée une instance d'un widget RowColumn de type XmMENU_PULLDOWN et retourne l'identifiant du widget associé.

parent
Spécifie l'identifiant du widget parent
name
Spécifie le nom du widget créé
arglist
Spécifie la liste d'arguments
argcount
Spécifie le nombre de paires attribut/valeur dans la liste d'arguments (arglist)

Spécifie le nombre de paires attribut/valeur dans la liste d'arguments (arglist). Lorsque cette fonction est utilisée pour créer le panneau de menu déroulant, un widget MenuShell est automatiquement créé comme parent du panneau de menu. Si le widget spécifié par le paramètre parent est un panneau de menu contextuel ou déroulant, le widget MenuShell est créé comme enfant du MenuShell parent ; sinon, il est créé comme enfant du widget parent spécifié.

XmCreatePulldownMenu est fournie comme fonction utilitaire pour créer des widgets RowColumn configurés pour fonctionner comme des panneaux de menu déroulant et n'est pas implémentée comme une classe de widget distincte.

Un panneau de menu déroulant affiche une ombre 3D, sauf si la fonctionnalité est désactivée par l'application. L'ombre apparaît autour du bord du panneau de menu.

Un panneau de menu déroulant est utilisé avec des sous-menus qui doivent être attachés à un CascadeButton ou à un CascadeButtonGadget. C'est le cas pour tous les panneaux de menu qui font partie d'un système de menu déroulant (une barre de menu), le panneau de menu associé à un OptionMenu, et tous les panneaux de menu qui s'enchaînent à partir d'un panneau de menu contextuel. Les panneaux de menu déroulant qui doivent être associés à un OptionMenu doivent être créés avant la création de l'OptionMenu.

Le panneau de menu déroulant doit être attaché à un CascadeButton ou à un CascadeButtonGadget qui réside dans une barre de menu, un panneau de menu contextuel, un panneau de menu déroulant, ou un OptionMenu. Il est attaché avec la ressource de bouton XmNsubMenuId.

Un widget MenuShell est requis entre le panneau de menu déroulant et son parent. Si l'application utilise cette fonction utilitaire pour créer un panneau de menu déroulant, le MenuShell est automatiquement créé comme parent réel du panneau de menu ; sinon, il incombe à l'application de créer le widget MenuShell.

Pour fonctionner correctement lorsqu'il est incorporé dans un menu, la hiérarchie du panneau de menu déroulant doit être prise en compte. Cette hiérarchie dépend du type de système de menu en cours de construction, comme suit :

•
Si le panneau de menu déroulant doit être déclenché à partir d'une barre de menu, son parent doit être la barre de menu.
•
Si le panneau de menu déroulant doit être déclenché à partir d'un menu contextuel ou d'un autre panneau de menu déroulant, son parent doit être ce menu contextuel ou ce panneau de menu déroulant.
•
Si le panneau de menu déroulant doit être déclenché à partir d'un OptionMenu, son parent doit être le même que le parent de l'OptionMenu.

Les panneaux de menu déroulant prennent en charge les fonctionnalités de "tear-off" (menu détachable) pour les menus détachables via les ressources XmRowColumn. Pour une définition complète de RowColumn et de ses ressources associées, voir XmRowColumn(3).

RETOUR

Retourne l'identifiant du widget RowColumn.
