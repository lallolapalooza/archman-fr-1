XML::LibXML::Namespace(3) Documentation Perl Contribuée par l'Utilisateur XML::LibXML::Namespace(3)

NOM

XML::LibXML::Namespace - Implémentation des Espaces de Noms XML::LibXML

SYNOPIS

use XML::LibXML;
# Seules les méthodes spécifiques aux nœuds Namespace sont listées ici,
# voir la page de manuel XML::LibXML::Node pour les autres méthodes
my $ns = XML::LibXML::Namespace->new($nsURI);
print $ns->nodeName();
print $ns->name();
$localname = $ns->getLocalName();
print $ns->getData();
print $ns->getValue();
print $ns->value();
$known_uri = $ns->getNamespaceURI();
$known_prefix = $ns->getPrefix();
$key = $ns->unique_key();

DESCRIPTION

Les nœuds d'espace de noms sont retournés par $element->findnodes('namespace::foo') ou par $node->getNamespaces().

L'API des nœuds d'espace de noms ne fait pas partie d'une API DOM actuelle, et elle est donc assez minimale. Il convient de noter que les nœuds d'espace de noms ne sont *pas* une sous-classe de XML::LibXML::Node, cependant les nœuds d'espace de noms se comportent beaucoup comme les nœuds d'attribut, et des méthodes portant le même nom retourneront ce à quoi vous vous attendriez si vous traitiez le nœud d'espace de noms comme un attribut. Notez que pour corriger plusieurs incohérences entre l'API et la documentation, le comportement de certaines fonctions a été modifié dans la version 1.64.

MÉTHODES

new
my $ns = XML::LibXML::Namespace->new($nsURI);

Crée un nouveau nœud d'espace de noms. Notez qu'il ne s'agit pas d'un 'nœud' comme un nœud d'attribut ou d'élément. Par conséquent, vous ne pouvez pas appeler toutes les fonctions XML::LibXML::Node. Toutes les fonctions disponibles pour ce nœud sont listées ci-dessous.

Optionnellement, vous pouvez passer le préfixe au constructeur de l'espace de noms. Si ce second paramètre est omis, vous créerez un espace de noms dit par défaut. Notez que le nouvel espace de noms créé n'est lié à aucun document ni nœud, par conséquent vous ne devriez pas vous attendre à ce qu'il soit disponible dans un document existant.

declaredURI
Retourne l'URI pour cet espace de noms.
declaredPrefix
Retourne le préfixe de cet espace de noms.
nodeName
print $ns->nodeName();

Retourne « xmlns:prefix », où prefix est le préfixe de cet espace de noms.

name
print $ns->name();

Alias pour nodeName()

getLocalName
$localname = $ns->getLocalName();

Retourne le nom local de ce nœud comme s'il s'agissait d'un attribut, c'est-à-dire le préfixe associé à l'espace de noms.

getData
print $ns->getData();

Retourne l'URI de l'espace de noms, c'est-à-dire la valeur de ce nœud comme s'il s'agissait d'un attribut.

getValue
print $ns->getValue();

Alias pour getData()

value
print $ns->value();

Alias pour getData()

getNamespaceURI
$known_uri = $ns->getNamespaceURI();

Retourne la chaîne « http://www.w3.org/2000/xmlns/ »

getPrefix
$known_prefix = $ns->getPrefix();

Retourne la chaîne « xmlns »

unique_key
$key = $ns->unique_key();

Cette méthode retourne une clé garantie d'être unique pour cet espace de noms, et d'être toujours la même valeur pour cet espace de noms. Deux objets d'espace de noms retournent la même clé si et seulement s'ils ont le même préfixe et le même URI. La valeur de clé retournée est utile comme clé dans les hachages.
