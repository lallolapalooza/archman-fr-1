NOM

XmIconBoxIsCellEmpty — Une fonction qui détermine si une cellule dans le IconBox est vide

SYNTAXE

#include <Xm/IconBox.h>
Boolean   XmIconBoxIsCellEmpty(
Position  cell_x,
Position  cell_y,
Widget    ignore);

DESCRIPTION

XmIconBoxIsCellEmpty retourne True si la cellule spécifiée ne contient aucun enfant et False sinon.

widget
Spécifie l'identifiant du widget IconBox
cell_x
Spécifie la position X de la cellule à vérifier
cell_y
Spécifie la position Y de la cellule à vérifier
ignore
Si l'identifiant du widget spécifié par ignore est présent dans la cellule spécifiée, il sera ignoré et la fonction retournera True

RETOUR

Retourne True si la cellule spécifiée ne contient aucun enfant, et False sinon.
