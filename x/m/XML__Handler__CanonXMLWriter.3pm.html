NOM

XML::Handler::CanonXMLWriter - sortie XML au format XML canonique

SYNTAXE

use XML::Handler::CanonXMLWriter;
$writer = XML::Handler::CanonXMLWriter OPTIONS;
$parser->parse(Handler => $writer);

DESCRIPTION

"XML::Handler::CanonXMLWriter" est un gestionnaire PerlSAX qui renverra une chaîne ou écrira un flux de XML canonique pour une instance XML et son contenu.

"XML::Handler::CanonXMLWriter" les objets détiennent les options utilisées pour écrire les objets XML. Les options peuvent être fournies lors de la création de l'objet,

$writer = new XML::Handler::CanonXMLWriter PrintComments => 1;

ou modifiées à tout moment avant d'appeler la méthode `parse()' de l'analyseur :

$writer->{PrintComments} = 0;

OPTIONS

IOHandle
IOHandle contient une poignée pour écrire le XML canonique. Si aucun IOHandle n'est fourni, la chaîne XML canonique sera retournée par `parse()'.
PrintComments
Par défaut, les commentaires ne sont pas écrits dans la sortie. Définir commenter sur une valeur vraie inclura les commentaires dans la sortie.
