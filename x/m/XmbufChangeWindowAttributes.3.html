DESCRIPTION

La bibliothèque d'interface de programmation pour le X11 Double-Buffering, Multi-Buffering, et Stereo Extension contient les interfaces décrites ci-dessous. À l'exception de XmbufQueryExtension, si l'une de ces routines est appelée avec un affichage qui ne prend pas en charge l'extension, l'ExtensionErrorHandler (qui peut être défini avec XSetExtensionErrorHandler et fonctionne de la même manière que XSetErrorHandler) sera appelé et la fonction retournera alors.

XmbufQueryExtension retourne True si l'extension de multi-buffering/stéréo est disponible sur l'affichage donné. Si l'extension existe, la valeur du premier code d'événement (qui doit être ajouté aux constantes de type d'événement MultibufferClobberNotify et MultibufferUpdateNotify pour obtenir les valeurs réelles) est stockée dans event_base_return et la valeur du premier code d'erreur (qui doit être ajouté à la constante de type d'erreur MultibufferBadBuffer pour obtenir la valeur réelle) est stockée dans error_base_return.

XmbufGetVersion obtient les numéros de version majeure et mineure de l'extension. La valeur de retour est zéro si une erreur se produit ou non-zéro si aucune erreur ne se produit.

XmbufCreateBuffers demande que "count" tampons soient créés avec l'action de mise à jour et l'indice de mise à jour donnés et soient associés à la fenêtre indiquée. Le nombre de tampons créés est retourné (zéro si une erreur s'est produite) et buffers_update est rempli avec ce nombre d'identifiants Multibuffer.

XmbufDestroyBuffers détruit les tampons associés à la fenêtre donnée.

XmbufDisplayBuffers affiche les tampons indiqués dans leurs fenêtres appropriées dans un délai maximum de max_delay millisecondes après que min_delay millisecondes se soient écoulées. Deux tampons ne peuvent pas être associés à la même fenêtre, sinon une erreur Match est générée.

XmbufGetWindowAttributes obtient les attributs de multi-buffering qui s'appliquent à tous les tampons associés à la fenêtre donnée. La liste des tampons retournée peut être libérée avec XFree. Retourne une valeur non nulle en cas de succès et zéro en cas d'erreur.

XmbufChangeWindowAttributes définit les attributs de multi-buffering qui s'appliquent à tous les tampons associés à la fenêtre donnée. Ceci est actuellement limité à l'indice de mise à jour.

XmbufGetBufferAttributes obtient les attributs pour le tampon indiqué. Retourne une valeur non nulle en cas de succès et zéro en cas d'erreur.

XmbufChangeBufferAttributes définit les attributs pour le tampon indiqué. Ceci est actuellement limité au masque d'événements.

XmbufGetScreenInfo obtient les paramètres contrôlant comment les fenêtres mono et stéréo peuvent être créées sur l'écran du dessin donné. Le nombre d'ensembles de visuels et de profondeurs est retourné dans nmono_return et nstereo_return. Si nmono_return est supérieur à zéro, alors mono_info_return est défini à l'adresse d'un tableau de structures XmbufBufferInfo décrivant les divers visuels et profondeurs qui peuvent être utilisés. Sinon, mono_info_return est défini à NULL. De même, stereo_info_return est défini en fonction de nstereo_return. Le stockage retourné dans mono_info_return et stereo_info_return peut être libéré par XFree. Si aucune erreur n'est rencontrée, une valeur non nulle sera retournée.

XmbufCreateStereoWindow crée une fenêtre stéréo de la même manière que XCreateWindow crée une fenêtre mono. Les identifiants de tampon pour les tampons gauche et droit sont retournés dans left_return et right_return, respectivement. Si un gestionnaire d'erreurs d'extension qui retourne est installé, None sera retourné si l'extension n'est pas disponible sur cet affichage.

NAME

XmbufChangeWindowAttributes, XmbufGetWindowAttributes - changer et obtenir les attributs de fenêtre multibuffering

SYNTAX

    Bool XmbufChangeWindowAttributes (Display *dpy, Window w,
                                     unsigned long valuemask,
                                     const XmbufSetWindowAttributes *values);
    Bool XmbufGetWindowAttributes (Display *dpy, Window w,
                                  XmbufWindowAttributes *attribs_return);

STRUCTURES

La structure XmbufSetWindowAttributes est définie comme suit :

    typedef struct {
        int         event_mask;
        int         dont_propagate;
        Bool        override_redirect;
        Colormap    colormap;
        int         cursor;
        XGCValues   background_gc;
        XGCValues   border_gc;
        int         backing_store;
        unsigned long backing_planes;
        XID         backing_pixel;
        Bool        save_under;
        Colormap    visual_colormap;
        Bool        peer_pixmap;
    } XmbufSetWindowAttributes;

La structure XmbufWindowAttributes est définie comme suit :

    typedef struct {
        int         event_mask;
        int         dont_propagate;
        Bool        override_redirect;
        Colormap    colormap;
        int         cursor;
        int         backing_store;
        unsigned long backing_planes;
        XID         backing_pixel;
        Bool        save_under;
        Colormap    visual_colormap;
        Bool        peer_pixmap;
        int         width;
        int         height;
        int         depth;
        int         map_state;
        Bool        override_redirect;
    } XmbufWindowAttributes;

DESCRIPTION

La fonction XmbufChangeWindowAttributes modifie les attributs de la fenêtre spécifiée w sur le display dpy. Le masque valuemask indique quels attributs doivent être modifiés. Les valeurs des attributs sont fournies dans la structure XmbufSetWindowAttributes pointed to par values.

La fonction XmbufGetWindowAttributes récupère les attributs de la fenêtre spécifiée w sur le display dpy et les stocke dans la structure pointed to par attribs_return.

PREDEFINED VALUES

Les valeurs prédéfinies sont les suivantes :

    MultibufferUpdateNotifyMask
    MultibufferClobberNotify
    MultibufferUpdateNotify
    MultibufferNumberEvents
    MultibufferBadBuffer
    MultibufferNumberErrors
