NOM

XmIsMotifWMRunning — Une fonction qui détermine si le gestionnaire de fenêtres est en cours d'exécution

SYNTAXE

#include <Xm/Xm.h>
Boolean XmIsMotifWMRunning(
Widget shell);

DESCRIPTION

XmIsMotifWMRunning permet à un utilisateur de savoir si le Motif Window Manager est en cours d'exécution sur un écran contenant une hiérarchie de widgets spécifique. Cette fonction vérifie d'abord si la propriété _MOTIF_WM_INFO est présente sur la fenêtre racine de l'écran du shell. Si c'est le cas, son champ fenêtre est utilisé pour interroger la présence de la fenêtre spécifiée en tant qu'enfant de la racine.

shell
Spécifie le shell dont l'écran sera testé pour la présence de mwm.

RETOUR

Retourne True si MWM est en cours d'exécution.
