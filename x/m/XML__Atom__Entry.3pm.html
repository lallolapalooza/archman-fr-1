XML::Atom::Entry(3pm) Documentation Perl fournie par l'utilisateur XML::Atom::Entry(3pm)

NOM

XML::Atom::Entry - Entrée Atom

SYNOPSIS

use XML::Atom::Entry;
my $entry = XML::Atom::Entry->new;
$entry->title('Mon article');
$entry->content('Le contenu de mon article.');
my $xml = $entry->as_xml;
my $dc = XML::Atom::Namespace->new(dc => 'http://purl.org/dc/elements/1.1/');
$entry->set($dc, 'subject', 'Nourriture & Boissons');

UTILISATION

XML::Atom::Entry->new([ $flux ])

Crée un nouvel objet d'entrée, et si $flux est fourni, le remplit avec les données spécifiées par $flux.

Gère automatiquement la découverte automatique si $flux est une URI (voir ci-dessous).

Retourne le nouvel objet XML::Atom::Entry. En cas d'échec, retourne "undef".

$flux peut être l'un des éléments suivants :

  • Référence à un scalaire

    Ceci est traité comme le corps XML de l'entrée.

  • Scalaire

    Ceci est traité comme le nom d'un fichier contenant le XML de l'entrée.

  • Descripteur de fichier

    Ceci est traité comme un descripteur de fichier ouvert à partir duquel le XML de l'entrée peut être lu.

$entry->content([ $contenu ])

Retourne le contenu de l'entrée. Si $contenu est donné, définit le contenu de l'entrée. Gère automatiquement toutes les échappements nécessaires.

$entry->author([ $auteur ])

Retourne un objet XML::Atom::Person représentant l'auteur de l'entrée, ou "undef" s'il n'y a pas d'informations d'auteur.

Si $auteur est fourni, il doit s'agir d'un objet XML::Atom::Person représentant l'auteur. Par exemple :

my $auteur = XML::Atom::Person->new;
$auteur->name('Foo Bar');
$auteur->email('foo@bar.com');
$entry->author($auteur);

$entry->link

Si appelé dans un contexte scalaire, retourne un objet XML::Atom::Link correspondant à la première balise <link> trouvée dans l'entrée.

Si appelé dans un contexte de liste, retourne une liste d'objets XML::Atom::Link correspondant à toutes les balises <link> trouvées dans l'entrée.

$entry->add_link($lien)

Ajoute le lien $lien, qui doit être un objet XML::Atom::Link, à l'entrée en tant que nouvelle balise <link>. Par exemple :

my $lien = XML::Atom::Link->new;
$lien->type('text/html');
$lien->rel('alternate');
$lien->href('http://www.example.com/2003/12/post.html');
$entry->add_link($lien);

$entry->get($ns, $element)

Étant donné un élément XML::Atom::Namespace $ns et un nom d'élément $element, récupère la valeur de l'élément dans ce namespace.

Ceci est utile pour récupérer la valeur des éléments qui ne sont pas dans le namespace Atom principal, comme les catégories. Par exemple :

my $dc = XML::Atom::Namespace->new(dc => 'http://purl.org/dc/elements/1.1/');
my $subj = $entry->get($dc, 'subject');

$entry->getlist($ns, $element)

Identique à $entry->get, mais s'il existe plusieurs instances de l'élément $element dans le namespace $ns, retourne toutes ces instances. get ne retournera que la première.
