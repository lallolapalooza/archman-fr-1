XmGetAtomName(appel de bibliothèque) XmGetAtomName(appel de bibliothèque)

NOM

XmGetAtomName — Une fonction qui renvoie la représentation sous forme de chaîne pour un atome

SYNTAXE

#include <Xm/Xm.h>
#include <Xm/AtomMgr.h>
String XmGetAtomName(
Display * display,
Atom atom);

DESCRIPTION

XmGetAtomName renvoie la représentation sous forme de chaîne pour un atome. Elle reflète les interfaces Xlib pour la gestion des atomes mais fournit une mise en cache côté client. Lorsque et où la mise en cache est fournie dans Xlib, les routines deviendront des pseudonymes pour les routines Xlib.

display
Spécifie la connexion au serveur X
atom
Spécifie l'atome pour le nom de propriété que vous souhaitez obtenir

RETOUR

Renvoie une chaîne. La fonction alloue de l'espace pour contenir la chaîne renvoyée. L'application est responsable de la gestion de l'espace alloué. L'application peut récupérer l'espace alloué en appelant XFree.
