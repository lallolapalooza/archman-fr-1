Paquet: perl-xml-stream

XML::Stream::Node(3) Documentation Perl fournie par l'utilisateur XML::Stream::Node(3)

NOM

XML::Stream::Node - Fonctions pour faciliter la manipulation de la construction et de l'analyse de l'arbre.

SYNOPIS

  Juste une collection de fonctions qui n'ont pas besoin d'être en mémoire si vous
choisissez l'une des autres méthodes de stockage de données.
  Cela crée une hiérarchie d'objets Perl et fournit diverses méthodes
pour manipuler la structure de l'arbre. C'est très similaire à la librairie C
libxml.

FORMAT

Le résultat de l'analyse :

<foo><head id="a">Bonjour <em>là</em></head><bar>Salut</bar>do</foo>

serait :

[ tag:       foo
  att:       {}
  children:  [ tag:      head
               att:      {id=>"a"}
               children: [ tag:      "__xmlstream__:node:cdata"
                           children: "Bonjour "
                         ]
                         [ tag:      em
                           children: [ tag:      "__xmlstream__:node:cdata"
                                       children: "là"
                                     ]
                         ]
             ]
             [ tag:      bar
               children: [ tag:      "__xmlstream__:node:cdata"
                           children: "Salut "
                         ]
                         [ tag:      ref
                         ]
             ]
             [ tag:      "__xmlstream__:node:cdata"
               children: "do"
             ]
]

MÉTHODES

new()          - crée un nouveau nœud. Si vous spécifiez un tag, alors le tag
new(tag)         racine est défini. Si vous spécifiez des données, alors du cdata
new(tag,cdata)   est également ajouté au nœud. Retourne le nœud créé.
get_tag() - retourne le tag racine du nœud.
set_tag(tag) - définit le tag racine du nœud sur tag.
add_child(node)      - ajoute le nœud spécifié comme enfant au nœud courant
add_child(tag)         ou crée un nouveau nœud avec le tag spécifié
add_child(tag,cdata)   comme nœud racine. Retourne le nœud ajouté.
remove_child(node) - retire le nœud enfant du nœud courant.

remove_cdata() - retire tous les enfants cdata du nœud courant.
add_cdata(string) - ajoute la chaîne sous forme de cdata à la liste des enfants
                    du nœud courant.
get_cdata() - retourne tous les enfants cdata concaténés ensemble
              en une seule chaîne.
get_attrib(attrib) - retourne la valeur de l'attribut s'il est valide,
                     ou retourne undef si l'attribut n'est pas un vrai
                     attribut.
put_attrib(hash) - pour chaque paire clé/valeur spécifiée, crée un
                   attribut dans le nœud.
remove_attrib(attrib) - retire l'attribut spécifié du nœud.
add_raw_xml(string,[string,...]) - ajoute directement une chaîne dans le paquet XML
                                   comme dernier enfant, sans aucune
                                   traduction.
get_raw_xml() - retourne tout le XML en une seule chaîne, undef s'il
                n'y a pas de XML brut à inclure.
remove_raw_xml() - retire toutes les chaînes XML brutes.
children() - retourne tous les enfants du nœud dans une liste.
attrib() - retourne une hash contenant tous les attributs de ce
           nœud.
copy() - retourne une copie récursive du nœud.
XPath(path) - exécute XML::Stream::XPath sur ce nœud.

XPathCheck(path) - exécute XML::Stream::XPath sur ce nœud et retourne 1 ou 0
                   pour voir s'il correspond ou non.
GetXML() - retourne le nœud sous forme de chaîne XML.
