NOM

XML::LibXML::Schema - Validation de schémas XML

SYNOPSIS

use XML::LibXML;
$doc = XML::LibXML->new->parse_file($url);
$xmlschema = XML::LibXML::Schema->new( location => $filename_or_url, no_network => 1 );
$xmlschema = XML::LibXML::Schema->new( string => $xmlschemastring, no_network => 1 );
eval { $xmlschema->validate( $doc ); };

DESCRIPTION

La classe XML::LibXML::Schema est une petite interface pour l'implémentation de schémas XML de libxml2. Actuellement, elle ne prend en charge que l'analyse de schémas et la validation de documents. Depuis la version 2.6.32, libxml2 ne prend en charge que les types décimaux jusqu'à 24 chiffres (la norme exige au moins 18).

MÉTHODES

new
$xmlschema = XML::LibXML::Schema->new( location => $filename_or_url, no_network => 1 );
$xmlschema = XML::LibXML::Schema->new( string => $xmlschemastring, no_network => 1 );

Le constructeur de XML::LibXML::Schema doit être appelé avec une liste de paramètres. Au moins le paramètre location ou string est requis pour spécifier la source du schéma. Le paramètre optionnel no_network défini à 1 indique que l'analyseur n'accédera pas au réseau, et le paramètre optionnel recover défini à 1 indique que l'analyseur n'appellera pas die() en cas d'erreur.

Il est important que chaque schéma n'ait qu'une seule source.

Le paramètre location permet d'analyser un schéma à partir du système de fichiers ou d'une URL (non-HTTPS).

Le paramètre string analysera le schéma à partir de la chaîne XML donnée.

Notez que le constructeur appellera die() si le schéma ne respecte pas les contraintes de la spécification XML Schema.

validate
eval { $xmlschema->validate( $doc ); };

Cette fonction permet de valider un document (analysé) par rapport au schéma XML donné. L'argument de cette fonction doit être un objet XML::LibXML::Document. Si cette fonction réussit, elle retournera 0, sinon elle appellera die() et rapportera les erreurs trouvées. Pour cette raison, validate() doit toujours être évalué.
