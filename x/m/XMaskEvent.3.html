XMaskEvent(3)

Paquet: libx11

Licences: MIT AND X11

XNextEvent(3) FONCTIONS XLIB XNextEvent(3)

NOM

XNextEvent, XPeekEvent, XWindowEvent, XCheckWindowEvent, XMaskEvent, XCheckMaskEvent, XCheckTypedEvent, XCheckTypedWindowEvent - sélectionner des événements par type

SYNTAXE

int XNextEvent(Display *display, XEvent *event_return);

int XPeekEvent(Display *display, XEvent *event_return);

int XWindowEvent(Display *display, Window w, long event_mask, XEvent *event_return);

Bool XCheckWindowEvent(Display *display, Window w, long event_mask, XEvent *event_return);

int XMaskEvent(Display *display, long event_mask, XEvent *event_return);

Bool XCheckMaskEvent(Display *display, long event_mask, XEvent *event_return);

Bool XCheckTypedEvent(Display *display, int event_type, XEvent *event_return);

Bool XCheckTypedWindowEvent(Display *display, Window w, int event_type, XEvent *event_return);

ARGUMENTS

display
Spécifie la connexion au serveur X.
event_mask
Spécifie le masque d'événements.
event_return
Retourne la structure associée à l'événement correspondant.
event_return
Retourne le prochain événement dans la file d'attente.
event_return
Retourne une copie de la structure associée à l'événement correspondant.
event_type
Spécifie le type d'événement à comparer.
w
Spécifie la fenêtre pour laquelle vous recherchez un événement.

DESCRIPTION

La fonction XNextEvent copie le premier événement de la file d'attente des événements dans la structure XEvent spécifiée, puis le retire de la file. Si la file d'attente des événements est vide, XNextEvent vide le tampon de sortie et se bloque jusqu'à ce qu'un événement soit reçu.

La fonction XPeekEvent retourne le premier événement de la file d'attente des événements, mais ne le retire pas de la file. Si la file est vide, XPeekEvent vide le tampon de sortie et se bloque jusqu'à ce qu'un événement soit reçu. Elle copie ensuite l'événement dans la structure XEvent fournie par le client sans le retirer de la file d'attente des événements.

La fonction XWindowEvent recherche dans la file d'attente des événements un événement qui correspond à la fois à la fenêtre et au masque d'événements spécifiés. Lorsqu'elle trouve une correspondance, XWindowEvent retire cet événement de la file et le copie dans la structure XEvent spécifiée. Les autres événements stockés dans la file ne sont pas écartés. Si un événement correspondant n'est pas dans la file, XWindowEvent vide le tampon de sortie et se bloque jusqu'à ce qu'il en soit reçu un.

La fonction XCheckWindowEvent recherche dans la file d'attente des événements, puis dans les événements disponibles sur la connexion du serveur, le premier événement qui correspond à la fenêtre et au masque d'événements spécifiés. Si elle trouve une correspondance, XCheckWindowEvent retire cet événement, le copie dans la structure XEvent spécifiée, et retourne True. Les autres événements stockés dans la file ne sont pas écartés. Si l'événement demandé n'est pas disponible, XCheckWindowEvent retourne False, et le tampon de sortie aura été vidé.

La fonction XMaskEvent recherche dans la file d'attente des événements ceux associés au masque spécifié. Lorsqu'elle trouve une correspondance, XMaskEvent retire cet événement et le copie dans la structure XEvent spécifiée. Les autres événements stockés dans la file ne sont pas écartés. Si l'événement demandé n'est pas dans la file, XMaskEvent vide le tampon de sortie et se bloque jusqu'à ce qu'il en soit reçu un.

La fonction XCheckMaskEvent recherche dans la file d'attente des événements, puis dans tous les événements disponibles sur la connexion du serveur, le premier événement qui correspond au masque spécifié. Si elle trouve une correspondance, XCheckMaskEvent retire cet événement, le copie dans la structure XEvent spécifiée, et retourne True. Les autres événements stockés dans la file ne sont pas écartés. Si l'événement demandé n'est pas disponible, XCheckMaskEvent retourne False, et le tampon de sortie aura été vidé.

La fonction XCheckTypedEvent recherche dans la file d'attente des événements, puis dans tous les événements disponibles sur la connexion du serveur, le premier événement qui correspond au type spécifié. Si elle trouve une correspondance, XCheckTypedEvent retire cet événement, le copie dans la structure XEvent spécifiée, et retourne True. Les autres événements dans la file ne sont pas écartés. Si l'événement n'est pas disponible, XCheckTypedEvent retourne False, et le tampon de sortie aura été vidé.

La fonction XCheckTypedWindowEvent recherche dans la file d'attente des événements, puis dans tous les événements disponibles sur la connexion du serveur, le premier événement qui correspond au type et à la fenêtre spécifiés. Si elle trouve une correspondance, XCheckTypedWindowEvent retire l'événement de la file, le copie dans la structure XEvent spécifiée, et retourne True. Les autres événements dans la file ne sont pas écartés. Si l'événement n'est pas disponible, XCheckTypedWindowEvent retourne False, et le tampon de sortie aura été vidé.
