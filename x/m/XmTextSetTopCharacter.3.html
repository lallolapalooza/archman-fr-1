NOM

XmTextSetTopCharacter — Appel de fonction Text qui définit la position du premier caractère affiché

SYNTAXE

#include <Xm/Text.h>
void XmTextSetTopCharacter(
Widget widget,
XmTextPosition top_character);

DESCRIPTION

XmTextSetTopCharacter définit la position du texte en haut du widget Text. Si le mode d'édition XmNeditMode est XmMULTI_LINE_EDIT, la ligne de texte contenant top_character est affichée en haut du widget sans que le texte ne décale vers la gauche ou la droite. Si le mode d'édition est XmSINGLE_LINE_EDIT, le texte se déplace horizontalement de sorte que top_character soit le premier caractère affiché.

widget
Spécifie l'ID du widget Text
top_character
Spécifie la position dans le texte à afficher en haut du widget. Il s'agit d'un nombre entier de caractères à partir du début du tampon de texte. La première position de caractère est 0 (zéro).

Pour une définition complète de Text et de ses ressources associées, voir XmText(3).

LIÉ
