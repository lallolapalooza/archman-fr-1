NOM

XML::Smart::Tutorial - Tutoriel et exemples pour XML::Smart.

SYNOPSIS

Ce document est un tutoriel pour XML::Smart et présente quelques exemples d'opérations courantes.

Travailler avec les contenus :

Dans XML::Smart, la clé CONTENT est réservée et ne doit pas être utilisée directement, car XML::Smart gérera automatiquement la conversion des arguments en contenus de nœuds, y compris les contenus de nœuds multiples.

Que se passe-t-il lorsque vous définissez une valeur :

$xml->{root}{foo} = 'valeur simple' ;

Ici, foo sera une valeur d'argument/attribut normale et générera les données XML suivantes :

<root foo="valeur simple"/>

Mais si vous insérez une balise ou des lignes dans les valeurs, par défaut XML::Smart les convertira en contenu de nœud :

$xml->{root}{foo} = "ligne0\nlien1\nligne2\n" ;

Et générera ces données XML :

<root>
<foo>ligne0
lien1
ligne2
</foo>
</root>

Mais que faire si vous voulez forcer un type, par exemple, avoir un contenu de nœud avec une valeur simple :

$xml->{root}{foo} = 'valeur simple' ;
$xml->{root}{foo}->set_node(1) ;

Et générera ces données XML :

<root>
  <foo>valeur simple</foo>
</root>

Contenus multiples :

Lorsque vous avez un contenu/des données interpolés, vous devez travailler différemment. Supposons que vous chargez ces données XML :

<root>
contenu0
<tag1 arg="1"/>
contenu1
</root>

Si vous accédez directement à la clé root en tant que chaîne, vous obtiendrez toutes les parties du contenu groupées. Donc, ce code :

my $xml = new XML::Smart(q`
<root>
contenu0
<tag1 arg="1"/>
contenu1
</root>
`,'smart') ;

print "#$xml->{root}#" ;

Imprimera ceci :

#
contenu0

contenu1
#

Pour accéder à chaque partie du contenu indépendamment, vous devez utiliser un tableau qui reçoit la méthode content() :

my @content = $xml->{root}->content ;

print "#$content[0]#\n" ;

Et cela imprimera ceci :

#
contenu0
#

Maintenant, pour définir les valeurs de contenu multiple, vous devez utiliser la méthode content() avec 2 arguments :

$xml->{root}->content(0,'nouveau contenu') ;

Et maintenant, les données XML produites seront :

<root>nouveau contenu<tag1 arg="1"/>
contenu1
</root>

Si vous utilisez la méthode content() avec un seul argument, elle supprimera tous les contenus multiples et définira la nouvelle valeur à la place du premier contenu.

Définir le parseur XML.

Par défaut, XML::Smart utilisera XML::Parser ou XML::Smart::Parser (dans cet ordre de préférence) pour charger des données XML.

Pour forcer ou définir vous-même le parseur, vous pouvez utiliser l'option du 2ème argument lors de la création d'un objet XML::Smart :

my $xml = new XML::Smart( 'some.xml' , 'XML::Parser' ) ;

## et

my $xml = new XML::Smart( 'some.xml' , 'XML::Smart::Parser' ) ;

XML::Smart possède également un parseur supplémentaire, XML::Smart::HTMLParser, qui peut être utilisé pour charger du HTML en tant que XML, ou pour charger des données XML non structurées :

my $xml = new XML::Smart( 'some.xml' , 'XML::Smart::HTMLParser' ) ;

Alias pour les options du parseur :

SMART|REGEXP   => XML::Smart::Parser
HTML           => XML::Smart::HTMLParser

Ainsi, vous pouvez utiliser comme ceci :

my $xml = new XML::Smart( 'some.xml' , 'smart' ) ;
my $xml = new XML::Smart( 'some.xml' , 'html' ) ;

Personnaliser le parseur.

Vous pouvez personnaliser la façon dont le parseur traitera les données XML :

Forcer les nœuds/balises et arguments/attributs en minuscules ou majuscules :

## Pour les minuscules :
my $xml = new XML::Smart( 'some.xml' ,
lowtag => 1 ,
lowarg => 1 ,
) ;

## Pour les majuscules :

my $xml = new XML::Smart( 'some.xml' ,
upertag => 1 ,
uperarg => 1 ,
) ;

Charger les arguments sans valeurs (flags) comme un booléen VRAI :

** Note, cette option ne fonctionnera que lorsque le XML sera analysé par XML::Smart::HTMLParser, car seul celui-ci accepte les arguments sans valeurs !

my $xml = new XML::Smart(
'<root><foo arg1="" flag></root>' ,
'XML::Smart::HTMLParser' ,
arg_single => 1 ,
) ;

Voici l'arbre de l'exemple ci-dessus :

'root' => {
            'foo' => {
                       'flag' => 1,
                       'arg1' => ''
                     },
          },

Personnaliser les événements d'analyse :

XML::Smart peut rediriger le processus d'analyse vers des fonctions personnalisées :

my $xml = XML::Smart->new( 'some.xml' ,
on_start => \&on_start ,
on_char  => \&on_char ,
on_end   => \&on_end ,
) ;

sub on_start {
  my ( $tag , $pointer , $pointer_back ) = @_ ;
  $pointer->{$tag}{type_user} = 1 if $tag =~ /(?:name|age)/ ;
}
sub on_char {
  my ( $tag , $pointer , $pointer_back , $content) = @_ ;
  $$content =~ s/\s+/ /gs ;
}

sub on_end {
  my ( $tag , $pointer , $pointer_back ) = @_ ;
  $pointer->{$tag}{type_extra} = 1 if $tag =~ /(?:more|tel|address)/ ;
}
