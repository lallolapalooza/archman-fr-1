XmCreateScrolledText(appel de fonction) XmCreateScrolledText(appel de fonction)

NOM

XmCreateScrolledText — Fonction de création pratique pour Text ScrolledText

SYNTAXE

#include <Xm/Text.h>
Widget XmCreateScrolledText(
Widget parent,
String name,
ArgList arglist,
Cardinal argcount);

DESCRIPTION

XmCreateScrolledText crée une instance d'un widget Text contenu dans une ScrolledWindow. Le parent ScrolledWindow est créé et géré. Tous les widgets de sous-zone de la ScrolledWindow sont automatiquement créés par cette fonction. L'ID retourné par cette fonction est celui du widget Text (pas celui du widget ScrolledWindow). Utilisez cet ID de widget pour toutes les opérations sur le widget Text. Utilisez l'ID de widget du parent du widget Text pour toutes les opérations sur la ScrolledWindow. Pour obtenir l'ID du widget ScrolledWindow associé au widget Text, utilisez la fonction intrinsèque Xt XtParent. Le nom de la ScrolledWindow créée par cette fonction est formé en concaténant les lettres SW à la fin du nom spécifié dans la liste de paramètres.

Le widget Text est par défaut en mode édition sur une seule ligne ; par conséquent, aucune barre de défilement n'est affichée. La ressource Text XmNeditMode doit être définie sur XmMULTI_LINE_EDIT pour afficher les barres de défilement. Les résultats du placement d'un widget Text dans une ScrolledWindow lorsque le XmNeditMode de Text est XmSINGLE_LINE_EDIT sont indéfinis.

Tous les arguments du widget Text ou du widget ScrolledWindow peuvent être spécifiés lors de la création avec cette fonction. Les modifications de la position et de la taille initiales sont envoyées uniquement au widget ScrolledWindow. Les autres ressources sont envoyées au widget Text ou ScrolledWindow selon ce qui est approprié. Notez que le résultat de la fourniture de la ressource XmNdestroyCallback dans la arglist de création est indéterminé. L'application doit utiliser la fonction XtAddCallback pour ajouter des callbacks au widget approprié (Text ou ScrolledWindow) après sa création.

Cette fonction force les valeurs initiales suivantes pour les ressources ScrolledWindow :

•
XmNscrollingPolicy est défini sur XmAPPLICATION_DEFINED.
•
XmNvisualPolicy est défini sur XmVARIABLE.
•
XmNscrollBarDisplayPolicy est défini sur XmSTATIC.
•
XmNshadowThickness est défini sur 0 (zéro).
parent
Spécifie l'ID du widget parent.
name
Spécifie le nom du widget créé.
arglist
Spécifie la liste des arguments.
argcount
Spécifie le nombre de paires attribut/valeur dans la liste des arguments (arglist).

Pour une définition complète de Text et de ses ressources associées, voir XmText(3).

RETOUR

Retourne l'ID du widget Text.

VOIR AUSSI

XmScrolledWindow(3) et XmText(3).
