NOM

XmCreateSimpleSpinBox — fonction de création du widget SimpleSpinBox

SYNOPSIS

#include <Xm/SSpinB.h>
Widget XmCreateSimpleSpinBox(
Widget parent,
String name,
ArgList arglist,
Cardinal argcount);

DESCRIPTION

La fonction XmCreateSimpleSpinBox crée une instance d'un widget SpinBox et renvoie l'identifiant du widget associé.

L'argument parent spécifie l'identifiant du widget parent.

L'argument name spécifie le nom du widget créé.

L'argument arglist spécifie la liste des arguments.

L'argument argcount spécifie le nombre de paires attribut/valeur dans la liste des arguments.

VALEUR DE RETOUR

En cas de succès, la fonction XmCreateSimpleSpinBox renvoie l'identifiant du widget SimpleSpinBox.
