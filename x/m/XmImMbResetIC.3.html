NOM

XmImMbResetIC — Une fonction de gestionnaire d'entrée qui réinitialise le contexte d'entrée pour un widget

SYNOPSIS

#include <Xm/XmIm.h>
void XmImMbResetIC(
Widget widget,
char **mb);

DESCRIPTION

XmImMbResetIC récupère le XIC du widget et le réinitialise. Il place un pointeur vers une chaîne contenant la chaîne de pré-édition actuelle dans mb. L'appelant doit libérer la chaîne retournée après utilisation en appelant Xfree.

widget
Spécifie l'ID du widget.
mb
Contient un pointeur vers la chaîne de pré-édition au retour.

VALEUR DE RETOUR

Aucune
