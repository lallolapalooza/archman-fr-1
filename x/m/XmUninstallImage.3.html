NOM

XmUninstallImage — Une fonction de mise en cache de pixmap qui supprime une image du cache d'images

SYNTAXE

#include <Xm/Xm.h>
Boolean XmUninstallImage(
XImage * image);

DESCRIPTION

XmUninstallImage supprime une image du cache d'images.

image
Pointe vers la structure d'image transmise à la routine XmInstallImage()

VALEUR DE RETOUR

Retourne True en cas de succès ; retourne False si image est NULL, ou s'il ne peut pas être trouvé pour être désinstallé.

VOIR AUSSI

XmInstallImage(3), XmGetPixmap(3), et XmDestroyPixmap(3).
