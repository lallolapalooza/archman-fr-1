NOM

XmTextShowPosition — Une fonction Text qui force l'affichage du texte à une position donnée

SYNOPSIS

#include <Xm/Text.h>
void XmTextShowPosition(
Widget widget,
XmTextPosition position);

DESCRIPTION

XmTextShowPosition force l'affichage du texte à la position spécifiée. Si la ressource XmNautoShowCursorPosition est True, l'application devrait également définir le curseur d'insertion à cette position.

widget
Spécifie l'identifiant du widget Text
position
Spécifie la position du caractère à afficher. Il s'agit d'un nombre entier de caractères à partir du début du tampon de texte. La première position de caractère est 0 (zéro).

Si un navigateur existe, cette fonction utilise le trait XmQTnavigator pour mettre à jour la valeur du navigateur horizontal.

Pour une définition complète de Text et de ses ressources associées, voir XmText(3).
