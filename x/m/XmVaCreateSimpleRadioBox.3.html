NOM

XmVaCreateSimpleRadioBox — Fonction de création pratique de widget RowColumn

SYNTAXE

#include <Xm/RowColumn.h>
Widget XmVaCreateSimpleRadioBox(
Widget parent,
String name,
int button_set,
XtCallbackProc callback);

DESCRIPTION

XmVaCreateSimpleRadioBox crée une instance d'un widget RowColumn de type XmWORK_AREA et renvoie l'identifiant du widget associé. Cette routine utilise la convention d'appel de liste d'arguments de longueur variable ANSI C (varargs).

Cette routine crée une RadioBox et ses enfants ToggleButtonGadget. Le nom de chaque bouton est button_n, où n est un entier de 0 (zéro) au nombre de boutons dans le menu moins 1.

parent
Spécifie l'identifiant du widget parent.
name
Spécifie le nom du widget créé.
button_set
Spécifie quel bouton est initialement sélectionné. La valeur est l'entier n dans le nom du bouton button_n.
callback
Spécifie une procédure de rappel à appeler lorsque la valeur d'un bouton change. Cette fonction de rappel est ajoutée à chaque bouton après sa création en tant que XmNvalueChangedCallback du bouton. La fonction de rappel est appelée lorsqu'une valeur de bouton change, et le numéro du bouton est renvoyé dans le champ client_data.

La partie variable de la liste d'arguments se compose de groupes d'arguments. Le premier argument de chaque groupe est une constante ou une chaîne et détermine les arguments qui suivent dans ce groupe. Le dernier argument de la liste doit être NULL. Les premiers arguments possibles dans chaque groupe de varargs sont les suivants :

XmVaRADIOBUTTON
Ceci est suivi de quatre arguments supplémentaires. L'ensemble spécifie un bouton dans la RadioBox et certaines de ses valeurs de ressource. Les quatre arguments supplémentaires, dans l'ordre, sont les suivants :
label
La chaîne d'étiquette, de type XmString.
mnemonic
La touche mnémonique, de type KeySym. Ceci est ignoré dans cette version.
accelerator
L'accélérateur, de type String. Ceci est ignoré dans cette version.
accelerator_text
Le texte de l'accélérateur, de type XmString. Ceci est ignoré dans cette version.
resource_name
Ceci est suivi d'un argument supplémentaire, la valeur de la ressource, de type XtArgVal. La paire spécifie une ressource et sa valeur pour le widget RowColumn.
XtVaTypedArg
Ceci est suivi de quatre arguments supplémentaires. L'ensemble spécifie une ressource et sa valeur pour le widget RowColumn. Une conversion de type de ressource est effectuée si nécessaire. Les quatre arguments supplémentaires, dans cet ordre, sont les suivants :
name
Le nom de la ressource, de type String
type
Le type de la valeur de ressource fournie, de type String
value
La valeur de la ressource (ou un pointeur vers la valeur de la ressource, selon le type et la taille de la valeur), de type XtArgVal
size
La taille de la valeur de ressource en octets, de type int
XtVaNestedList
Ceci est suivi d'un argument supplémentaire de type XtVarArgsList. Cet argument est une liste imbriquée de varargs renvoyée par XtVaCreateArgsList.

Pour plus d'informations sur les listes d'arguments de longueur variable, consultez la documentation X Toolkit Intrinsics.

Un certain nombre de ressources existent spécifiquement pour être utilisées avec cette fonction et d'autres routines de création de menus simples. Pour une définition complète de RowColumn et de ses ressources associées, voir XmRowColumn(3).

RETOURNER

Renvoie l'identifiant du widget RowColumn.
