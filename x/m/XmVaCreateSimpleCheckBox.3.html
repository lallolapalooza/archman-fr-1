NOM

XmVaCreateSimpleCheckBox — Fonction utilitaire de création du widget RowColumn

SYNTAXE

#include <Xm/RowColumn.h>
Widget XmVaCreateSimpleCheckBox(
Widget parent,
String name,
XtCallbackProc callback);

DESCRIPTION

XmVaCreateSimpleCheckBox crée une instance d'un widget RowColumn de type XmWORK_AREA et retourne l'ID du widget associé. Cette routine utilise la convention d'appel de liste d'arguments de longueur variable ANSI C (varargs).

Cette routine crée une CheckBox et ses enfants ToggleButtonGadget. Une CheckBox est similaire à une RadioBox, sauf que plusieurs boutons peuvent être sélectionnés simultanément. Le nom de chaque bouton est button_n, où n est un entier allant de 0 (zéro) au nombre de boutons du menu moins 1. Les boutons sont nommés et créés dans l'ordre où ils sont spécifiés dans la partie variable de la liste d'arguments.

parent
Spécifie l'ID du widget parent.
name
Spécifie le nom du widget créé.
callback
Spécifie une procédure de rappel à appeler lorsque la valeur d'un bouton change. Cette fonction de rappel est ajoutée à chaque bouton après sa création en tant que XmNvalueChangedCallback du bouton. La fonction de rappel est appelée lorsque la valeur d'un bouton change, et le numéro du bouton est retourné dans le champ client_data.

La partie variable de la liste d'arguments est constituée de groupes d'arguments. Le premier argument de chaque groupe est une constante ou une chaîne et détermine les arguments qui suivent dans ce groupe. Le dernier argument de la liste doit être NULL. La liste suivante décrit les premiers arguments possibles dans chaque groupe de varargs :

XmVaCHECKBUTTON
Ceci est suivi de quatre arguments supplémentaires. L'ensemble spécifie un bouton dans la CheckBox et certaines de ses valeurs de ressource. La liste suivante décrit les quatre arguments supplémentaires, dans l'ordre.
label
La chaîne d'étiquette, de type XmString
mnemonic
Le moyen mnémotechnique, de type KeySym. Ceci est ignoré dans cette version.
accelerator
L'accélérateur, de type String. Ceci est ignoré dans cette version.
accelerator_text
Le texte de l'accélérateur, de type XmString. Ceci est ignoré dans cette version.
resource_name
Ceci est suivi d'un argument supplémentaire, la valeur de la ressource, de type XtArgVal. La paire spécifie une ressource et sa valeur pour le widget RowColumn.
XtVaTypedArg
Ceci est suivi de quatre arguments supplémentaires. L'ensemble spécifie une ressource et sa valeur pour le widget RowColumn. Une conversion de type de ressource est effectuée si nécessaire. Voici les quatre arguments supplémentaires, dans l'ordre :
name
Le nom de la ressource, de type String
type
Le type de la valeur de ressource fournie, de type String
value
La valeur de la ressource (ou un pointeur vers la valeur de la ressource, en fonction du type et de la taille de la valeur), de type XtArgVal
size
La taille de la valeur de ressource en octets, de type int
XtVaNestedList
Ceci est suivi d'un argument supplémentaire de type XtVarArgsList. Cet argument est une liste imbriquée de varargs retournée par XtVaCreateArgsList.

Pour plus d'informations sur les listes d'arguments de longueur variable, consultez la documentation des X Toolkit Intrinsics.

Un certain nombre de ressources existent spécifiquement pour être utilisées avec cette fonction et d'autres routines de création de menus simples. Pour une définition complète de RowColumn et de ses ressources associées, voir XmRowColumn(3).

RETOUR

Retourne l'ID du widget RowColumn.

VOIR AUSSI

XmCreateRadioBox(3), XmCreateRowColumn(3), XmCreateSimpleCheckBox(3), XmCreateSimpleRadioBox(3), XmRowColumn(3), et XmVaCreateSimpleRadioBox(3).
