NOM

XmTextFieldInsertWcs — Une fonction TextField qui insère une chaîne de caractères larges dans un widget TextField

SYNTAXE

#include <Xm/TextF.h>
void XmTextFieldInsertWcs(
Widget widget,
XmTextPosition position,
wchar_t *wcstring);

DESCRIPTION

XmTextFieldInsertWcs insère une chaîne de caractères larges dans le widget TextField à un emplacement spécifié. Les positions de caractères commencent à 0 (zéro) et sont numérotées séquentiellement à partir du début du texte. Par exemple, pour insérer une chaîne après le quatrième caractère, le paramètre position doit être 4.

Cette routine appelle les callbacks XmNvalueChangedCallback du widget et les callbacks de vérification, soit XmNmodifyVerifyCallback soit XmNmodifyVerifyCallbackWcs, ou les deux. Si les deux listes de callbacks de vérification sont enregistrées, les procédures de la liste XmNmodifyVerifyCallback sont exécutées en premier et les données résultantes sont transmises aux callbacks XmNmodifyVerifyCallbackWcs. Si la ressource XmNcursorPosition est supérieure ou égale à la valeur de position, le callback XmNmotionVerifyCallback est appelé.

widget
Spécifie l'ID du widget TextField
position
Spécifie la position dans la chaîne de texte où la nouvelle chaîne de caractères doit être insérée
wcstring
Spécifie la chaîne de caractères larges à ajouter au widget TextField

Pour une définition complète de TextField et de ses ressources associées, voir XmTextField(3).

VOIR AUSSI

XmTextField(3) et XmTextFieldInsert(3).
