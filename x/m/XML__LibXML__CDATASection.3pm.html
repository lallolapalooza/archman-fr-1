NOM

XML::LibXML::CDATASection - Classe XML::LibXML pour les sections CDATA

SYNTAXE

use XML::LibXML;
# Seules les méthodes spécifiques aux nœuds CDATA sont listées ici,
# voir la page de manuel XML::LibXML::Node pour les autres méthodes
$node = XML::LibXML::CDATASection->new( $content );

DESCRIPTION

Cette classe fournit toutes les fonctions de XML::LibXML::Text, mais pour les nœuds CDATA.

MÉTHODES

La classe hérite de XML::LibXML::Node. La documentation des méthodes héritées n'est pas listée ici.

De nombreuses fonctions listées ici sont abondamment documentées dans la spécification DOM Level 3 (http://www.w3.org/TR/DOM-Level-3-Core/). Veuillez vous référer à la spécification pour une documentation exhaustive.

new
$node = XML::LibXML::CDATASection->new( $content );

Le constructeur est la seule fonction fournie pour ce package. Il est requis car libxml2 traite différemment les différents types de nœuds texte.
