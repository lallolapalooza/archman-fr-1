Retourne le nombre de profondeurs.

DESCRIPTION

Le macro AllPlanes renvoie une valeur avec tous les bits mis à 1 appropriée pour une utilisation dans un argument de plan pour une procédure.

Le macro BlackPixel renvoie la valeur du pixel noir pour l'écran spécifié.

Le macro WhitePixel renvoie la valeur du pixel blanc pour l'écran spécifié.

Le macro ConnectionNumber renvoie un numéro de connexion pour l'affichage spécifié.

Le macro DefaultColormap renvoie l'ID de la carte des couleurs par défaut pour l'allocation sur l'écran spécifié.

Le macro DefaultDepth renvoie la profondeur (nombre de plans) de la fenêtre racine par défaut pour l'écran spécifié.

La fonction XListDepths renvoie le tableau des profondeurs disponibles sur l'écran spécifié. Si le screen_number spécifié est valide et que suffisamment de mémoire pour le tableau peut être allouée, XListDepths définit count_return sur le nombre de profondeurs disponibles. Sinon, elle ne définit pas count_return et renvoie NULL. Pour libérer la mémoire allouée pour le tableau des profondeurs, utilisez XFree.

Le macro DefaultGC renvoie le GC par défaut pour la fenêtre racine de l'écran spécifié.

Le macro DefaultRootWindow renvoie la fenêtre racine pour l'écran par défaut.

Le macro DefaultScreenOfDisplay renvoie l'écran par défaut de l'affichage spécifié.

Le macro DefaultScreen renvoie le numéro d'écran par défaut référencé dans la routine XOpenDisplay.

Le macro DefaultVisual renvoie le type visuel par défaut pour l'écran spécifié.

Le macro DisplayCells renvoie le nombre d'entrées dans la carte des couleurs par défaut.

Le macro DisplayPlanes renvoie la profondeur de la fenêtre racine de l'écran spécifié.

Le macro DisplayString renvoie la chaîne qui a été passée à XOpenDisplay lors de l'ouverture de l'affichage actuel.

La fonction XMaxRequestSize renvoie la taille de requête maximale (en unités de 4 octets) prise en charge par le serveur sans utiliser un encodage de protocole de longueur étendue. Les requêtes de protocole individuelles au serveur ne peuvent pas être plus grandes que cette taille, sauf si un encodage de protocole de longueur étendue est pris en charge par le serveur. Le protocole garantit que la taille n'est pas inférieure à 4096 unités (16384 octets). Xlib divise automatiquement les données en plusieurs requêtes de protocole au besoin pour les fonctions suivantes : XDrawPoints, XDrawRectangles, XDrawSegments, XFillArcs, XFillRectangles et XPutImage.

La fonction XExtendedMaxRequestSize renvoie zéro si l'affichage spécifié ne prend pas en charge un encodage de protocole de longueur étendue ; sinon, elle renvoie la taille de requête maximale (en unités de 4 octets) prise en charge par le serveur utilisant l'encodage de longueur étendue. Les fonctions Xlib XDrawLines, XDrawArcs, XFillPolygon, XChangeProperty, XSetClipRectangles et XSetRegion utiliseront l'encodage de longueur étendue au besoin, s'il est pris en charge par le serveur. L'utilisation de l'encodage de longueur étendue dans d'autres fonctions Xlib (par exemple, XDrawPoints, XDrawRectangles, XDrawSegments, XFillArcs, XFillRectangles, XPutImage) est autorisée mais pas obligatoire ; une implémentation Xlib peut choisir de diviser les données sur plusieurs requêtes plus petites à la place.

Le macro LastKnownRequestProcessed extrait le numéro de série complet de la dernière requête dont Xlib sait qu'elle a été traitée par le serveur X.

Le macro NextRequest extrait le numéro de série complet qui doit être utilisé pour la prochaine requête.

Le macro ProtocolVersion renvoie le numéro de version majeure (11) du protocole X associé à l'affichage connecté.

Le macro ProtocolRevision renvoie le numéro de révision mineure du protocole du serveur X.

Le macro QLength renvoie la longueur de la file d'attente d'événements pour l'affichage connecté.

Le macro RootWindow renvoie la fenêtre racine.

Le macro ScreenCount renvoie le nombre d'écrans disponibles.

Le macro ScreenOfDisplay renvoie un pointeur vers l'écran de l'affichage spécifié.

Le macro ServerVendor renvoie un pointeur vers une chaîne se terminant par un nul qui fournit une identification du propriétaire de l'implémentation du serveur X.

Le macro VendorRelease renvoie un nombre lié à une version du serveur X par un fournisseur.

NOM

XMaxRequestSize - Définit la taille maximale des requêtes de mise en ligne.

SYNTAXE

XMaxRequestSize T | Off

ARGUMENTS

  • T: un nombre entier positif (par défaut : 1073741824, soit 1 Go).
  • Off: désactive la limite.

DESCRIPTION

La directive XMaxRequestSize permet de spécifier la taille maximale en octets des requêtes HTTP qui seront acceptées par le serveur. Cela est particulièrement utile pour limiter la taille des fichiers mis en ligne afin d'éviter de saturer le serveur.

Si la taille de la requête dépasse la limite définie, le serveur renverra une erreur 413 Request Entity Too Large.

La valeur par défaut est de 1 Go (1073741824 octets). Définir cette directive à Off désactive complètement la limitation de taille.
