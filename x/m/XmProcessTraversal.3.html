NOM

XmProcessTraversal — Une fonction qui détermine quel composant reçoit les événements clavier lorsque qu'un widget a le focus

SYNTAXE

#include <Xm/Xm.h>
Boolean XmProcessTraversal(
Widget widget,
XmTraversalDirection direction);

DESCRIPTION

XmProcessTraversal détermine quel composant d'une hiérarchie reçoit les événements clavier lorsque la hiérarchie qui contient le widget spécifié a le focus clavier.

XmProcessTraversal ne change le focus que lorsque la politique de focus clavier de la hiérarchie de widgets est explicite. Si la ressource XmNkeyboardFocusPolicy de l'ancêtre shell le plus proche du widget spécifié n'est pas XmEXPLICIT, XmProcessTraversal retourne False sans apporter de changements de focus.

widget
Spécifie l'ID du widget dont la hiérarchie doit être parcourue.
direction
Spécifie la direction du parcours.

DÉFINITIONS

Pour être éligible à recevoir le focus clavier lorsque la politique de focus clavier du shell est XmEXPLICIT, un widget ou un gadget doit remplir les conditions suivantes :

•
Le widget et ses ancêtres ne sont pas en cours de destruction.
•
Le widget et ses ancêtres sont sensibles. Un widget est sensible lorsque ses ressources XmNsensitive et XmNancestorSensitive sont toutes deux True.
•
La ressource XmNtraversalOn pour le widget et ses ancêtres est True.
•
Le widget est visible. Cela signifie que le widget et ses ancêtres sont gérés, réalisés et (sauf pour les gadgets) mappés. De plus, en général, une partie de la zone rectangulaire du widget ne doit pas être obstruée par les ancêtres du widget. Si une application démappe un widget dont la ressource XmNmappedWhenManaged est définie sur True, le résultat est indéfini.
Dans une fenêtre défilante avec une politique de défilement XmAUTOMATIC, un widget qui est obstrué parce qu'il n'est pas dans la fenêtre de découpe peut être en mesure de recevoir le focus si une partie du widget se trouve dans la zone de travail et si une routine XmNtraverseObscuredCallback peut rendre le widget au moins partiellement visible en faisant défiler la fenêtre.

En général, seuls les primitives, les gadgets et la zone de dessin sont éligibles pour recevoir le focus. La plupart des gestionnaires ne peuvent pas recevoir le focus, même s'ils remplissent toutes ces conditions.

La valeur de l'argument direction identifie le type d'action de parcours à effectuer. Les descriptions de ces actions ci-dessous font référence aux widgets non-groupes de tabulation parcourables et aux groupes de tabulation parcourables.

•
Un widget non-groupe de tabulation parcourable est un widget qui n'est pas un groupe de tabulation et qui remplit toutes les conditions pour recevoir le focus décrites ci-dessus.
•
Un widget groupe de tabulation parcourable est un widget groupe de tabulation qui remplit les mêmes conditions, à l'exception qu'un gestionnaire qui est un groupe de tabulation et qui remplit les autres conditions est également éligible au parcours tant qu'il contient un descendant capable de recevoir le focus.

Un groupe de tabulation est un widget dont la ressource XmNnavigationType est :

•
XmTAB_GROUP ou XmSTICKY_TAB_GROUP, si la hiérarchie (jusqu'à l'ancêtre shell le plus proche) qui contient le widget n'a aucun widget dont la ressource XmNnavigationType est XmEXCLUSIVE_TAB_GROUP.
•
XmEXCLUSIVE_TAB_GROUP ou XmSTICKY_TAB_GROUP, si la hiérarchie (jusqu'à l'ancêtre shell le plus proche) qui contient le widget a n'importe quel widget dont la ressource XmNnavigationType est XmEXCLUSIVE_TAB_GROUP.

ACTIONS DE PARCOURS

La hiérarchie à parcourir est celle qui contient l'argument widget. Cette hiérarchie n'est parcourue que jusqu'au shell le plus proche ; XmProcessTraversal ne déplace pas le focus d'un shell à un autre. Si le shell contenant widget n'a pas actuellement le focus, tout changement que XmProcessTraversal apporte à l'élément ayant le focus dans ce shell ne prendra effet qu'au moment où le shell recevra le focus ultérieurement.

XmProcessTraversal commence l'action de parcours à partir du widget de la hiérarchie qui a actuellement le focus clavier ou qui a eu le focus en dernier lorsque l'utilisateur s'est déplacé hors de la hiérarchie du shell.

La valeur de l'argument direction détermine lequel des trois types d'actions de parcours doit être effectué :

•
Parcours vers un widget non-groupe de tabulation. Ce type de parcours n'est possible que lorsque le widget ayant actuellement le focus n'est pas un groupe de tabulation ; sinon, XmProcessTraversal retourne False pour ces actions.
Ces actions ne déplacent pas le focus d'un groupe de tabulation à un autre. Les actions déterminent d'abord le groupe de tabulation contenant. C'est le groupe de tabulation contenant le widget qui a actuellement le focus. Les actions ne parcourent que les widgets non-groupes de tabulation à l'intérieur du groupe de tabulation contenant.
Un widget non-groupe de tabulation est éligible pour ce type de parcours si le widget est parcourable et n'a pas d'ancêtres groupe de tabulation jusqu'au groupe de tabulation contenant. Si le groupe de tabulation ne contient aucun widget non-groupe de tabulation parcourable, XmProcessTraversal retourne False.
Voici les valeurs possibles de l'argument direction. Notez que lorsque les actions bouclent, la boucle se fait dans la direction du parcours. Ce qui suit décrit ce qui se passe dans un environnement de gauche à droite :
•
XmTRAVERSE_RIGHT—Si la ressource XmNnavigationType du groupe de tabulation contenant n'est pas XmEXCLUSIVE_TAB_GROUP, le focus se déplace vers le prochain widget non-groupe de tabulation parcourable situé à droite du widget ayant actuellement le focus. Dans un environnement de gauche à droite, sur le côté droit du groupe de tabulation, cette action boucle vers le widget non-groupe de tabulation du côté gauche et suivant vers le bas. Au widget le plus à droite de la rangée inférieure du groupe de tabulation, cette action boucle vers le widget non-groupe de tabulation du widget le plus à gauche de la rangée supérieure.
Dans un environnement de droite à gauche, sur le côté droit du groupe de tabulation, cette action boucle vers le widget non-groupe de tabulation du côté gauche et suivant vers le haut. Au widget le plus à droite de la rangée supérieure du groupe de tabulation, cette action boucle vers le widget non-groupe de tabulation du widget le plus à gauche de la rangée inférieure.
Si la ressource XmNnavigationType du groupe de tabulation contenant est XmEXCLUSIVE_TAB_GROUP, le focus se déplace vers le prochain widget non-groupe de tabulation parcourable dans le groupe de tabulation, en procédant dans l'ordre dans lequel les widgets apparaissent dans les listes XmNchildren de leurs parents. Après le dernier widget du groupe de tabulation, cette action boucle vers le premier widget non-groupe de tabulation.
•
XmTRAVERSE_LEFT—Si la ressource XmNnavigationType du groupe de tabulation contenant n'est pas XmEXCLUSIVE_TAB_GROUP, le focus se déplace vers le prochain widget non-groupe de tabulation parcourable situé à gauche du widget ayant actuellement le focus. Dans un environnement de gauche à droite, sur le côté gauche du groupe de tabulation, cette action boucle vers le widget non-groupe de tabulation du côté droit et suivant vers le haut. Au widget le plus à gauche de la rangée supérieure du groupe de tabulation, cette action boucle vers le widget non-groupe de tabulation du widget le plus à droite de la rangée inférieure.
Dans un environnement de droite à gauche, sur le côté gauche du groupe de tabulation, cette action boucle vers le widget non-groupe de tabulation du côté droit et suivant vers le bas. Au widget le plus à gauche de la rangée inférieure du groupe de tabulation, cette action boucle vers le widget non-groupe de tabulation du widget le plus à droite de la rangée supérieure.
Si la ressource XmNnavigationType du groupe de tabulation contenant est XmEXCLUSIVE_TAB_GROUP, le focus se déplace vers le widget non-groupe de tabulation parcourable précédent dans le groupe de tabulation, en procédant dans l'ordre inverse dans lequel les widgets apparaissent dans les listes XmNchildren de leurs parents. Après le premier widget du groupe de tabulation, cette action boucle vers le dernier widget non-groupe de tabulation.

XmProcessTraversal(3) — Page de manuel

NOM

XmProcessTraversal — Traite les actions de navigation pour les widgets.

SYNOPSIS

#include <Xm/Traversal.h>

Boolean XmProcessTraversal (
        Widget widget,
        XtEnum direction
);

DESCRIPTION

La fonction XmProcessTraversal traite les actions de navigation demandées pour un widget donné. Elle peut être utilisée pour la navigation dans les groupes d'onglets, la navigation entre les groupes d'onglets ou la navigation vers n'importe quel widget. L'argument widget est le widget qui initie l'action de traversal. L'argument direction spécifie l'action de traversal à effectuer.

•
XmTRAVERSE_DOWN—Si le XmNnavigationType du groupe d'onglets contenant le widget n'est pas XmEXCLUSIVE_TAB_GROUP, le focus se déplace vers le widget non-groupe d'onglets navigable suivant dans le groupe d'onglets, en procédant dans l'ordre dans lequel les widgets apparaissent dans les listes XmNchildren de leurs parents. Au bas du widget dans la colonne la plus à droite du groupe d'onglets, cette action revient au widget non-groupe d'onglets en haut de la colonne la plus à gauche.
Dans un environnement de droite à gauche, en bas du groupe d'onglets, cette action revient au widget non-groupe d'onglets en haut et ensuite vers la gauche. Au widget du bas de la colonne la plus à gauche du groupe d'onglets, cette action revient au widget non-groupe d'onglets en haut de la colonne la plus à droite.
Si le XmNnavigationType du groupe d'onglets contenant est XmEXCLUSIVE_TAB_GROUP, le focus se déplace vers le widget non-groupe d'onglets navigable suivant dans le groupe d'onglets, en procédant dans l'ordre dans lequel les widgets apparaissent dans les listes XmNchildren de leurs parents. Après le dernier widget du groupe d'onglets, cette action revient au premier widget non-groupe d'onglets.
•
XmTRAVERSE_UP—Si le XmNnavigationType du groupe d'onglets contenant n'est pas XmEXCLUSIVE_TAB_GROUP, le focus se déplace vers le widget non-groupe d'onglets navigable suivant au-dessus du widget qui a actuellement le focus. Dans un environnement de gauche à droite, en haut du groupe d'onglets, cette action revient au widget non-groupe d'onglets en bas et ensuite vers la gauche. Au widget du haut de la colonne la plus à gauche du groupe d'onglets, cette action revient au widget du bas de la colonne la plus à droite.
Dans un environnement de droite à gauche, en haut du groupe d'onglets, cette action revient au widget non-groupe d'onglets en bas et ensuite vers la droite. Au widget du haut de la colonne la plus à droite du groupe d'onglets, cette action revient au widget du bas de la colonne la plus à gauche.
Si le XmNnavigationType du groupe d'onglets contenant est XmEXCLUSIVE_TAB_GROUP, le focus se déplace vers le widget non-groupe d'onglets navigable précédent dans le groupe d'onglets, en procédant dans l'ordre inverse dans lequel les widgets apparaissent dans les listes XmNchildren de leurs parents. Après le premier widget du groupe d'onglets, cette action revient au dernier widget non-groupe d'onglets.
•
XmTRAVERSE_NEXT—Le focus se déplace vers le widget non-groupe d'onglets navigable suivant dans le groupe d'onglets, en procédant dans l'ordre dans lequel les widgets apparaissent dans les listes XmNchildren de leurs parents. Après le dernier widget du groupe d'onglets, cette action revient au premier widget non-groupe d'onglets.
•
XmTRAVERSE_PREV—Le focus se déplace vers le widget non-groupe d'onglets navigable précédent dans le groupe d'onglets, en procédant dans l'ordre inverse dans lequel les widgets apparaissent dans les listes XmNchildren de leurs parents. Après le premier widget du groupe d'onglets, cette action revient au dernier widget non-groupe d'onglets.
•
XmTRAVERSE_HOME—Si le XmNnavigationType du groupe d'onglets contenant n'est pas XmEXCLUSIVE_TAB_GROUP, le focus se déplace vers le premier widget non-groupe d'onglets navigable au focus initial du groupe d'onglets.
Si le XmNnavigationType du groupe d'onglets contenant est XmEXCLUSIVE_TAB_GROUP, le focus se déplace vers le premier widget non-groupe d'onglets navigable dans le groupe d'onglets, selon l'ordre dans lequel les widgets apparaissent dans les listes XmNchildren de leurs parents.
•
Traversal vers un groupe d'onglets. Ces actions déterminent d'abord la hiérarchie des widgets actuelle et le groupe d'onglets contenant. La hiérarchie des widgets actuelle est la hiérarchie des widgets dont la racine est l'ancêtre de shell le plus proche du widget qui a actuellement le focus. Le groupe d'onglets contenant est le groupe d'onglets contenant le widget qui a actuellement le focus. Si la hiérarchie des widgets actuelle ne contient aucun groupe d'onglets navigable, XmProcessTraversal renvoie False.
Voici les valeurs possibles de l'argument direction. Si un groupe d'onglets dans la hiérarchie des widgets actuelle a un XmNnavigationType de XmEXCLUSIVE_TAB_GROUP, le parcours des groupes d'onglets dans la hiérarchie procède vers les widgets dans l'ordre dans lequel leurs ressources XmNnavigationType ont été spécifiées comme XmEXCLUSIVE_TAB_GROUP ou XmSTICKY_TAB_GROUP :
•
XmTRAVERSE_NEXT_TAB_GROUP—Trouve la hiérarchie qui contient widget, trouve le groupe d'onglets actif (le cas échéant), et fait du groupe d'onglets suivant le groupe d'onglets actif dans la hiérarchie.
•
XmTRAVERSE_PREV_TAB_GROUP—Trouve la hiérarchie qui contient widget, trouve le groupe d'onglets actif (le cas échéant), et fait du groupe d'onglets précédent le groupe d'onglets actif dans la hiérarchie.
•
Traversal vers n'importe quel widget. Dans ce cas, l'argument widget est le widget auquel XmProcessTraversal tente de donner le focus. Si le widget n'est pas navigable, XmProcessTraversal renvoie False.
Voici les valeurs possibles de l'argument direction :
•
XmTRAVERSE_CURRENT—Trouve la hiérarchie et le groupe d'onglets qui contiennent widget. Si ce groupe d'onglets n'est pas le groupe d'onglets actif, cette action en fait le groupe d'onglets actif. Si widget est un élément du groupe d'onglets actif, cette action en fait l'élément actif. Si widget est le groupe d'onglets actif, cette action fait du premier élément navigable du groupe d'onglets l'élément actif.

MISES EN GARDE

L'utilisation de XmProcessTraversal pour parcourir les MenuBars, les fenêtres de menu déroulantes ou les fenêtres de menu contextuels n'est pas prise en charge.

XmProcessTraversal ne peut pas être appelé de manière récursive. En particulier, une application ne peut pas appeler cette routine à partir d'une procédure XmNfocusCallback ou XmNlosingFocusCallback.

RETOUR

Renvoie True si l'action de traversal a réussi. Renvoie False si le XmNkeyboardFocusPolicy de l'ancêtre shell le plus proche de widget n'est pas XmEXPLICIT, si l'action de traversal ne trouve aucun widget navigable pour recevoir le focus, ou si l'appel à la routine contient des arguments invalides.

CONNEXES
