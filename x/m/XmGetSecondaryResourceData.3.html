NOM

XmGetSecondaryResourceData — Une fonction qui fournit l'accès aux données de ressources secondaires des widgets

SYNTAXE

#include <Xm/Xm.h>
Cardinal XmGetSecondaryResourceData(
WidgetClass widget_class,
XmSecondaryResourceData **secondary_data_return);

DESCRIPTION

Certaines classes de widgets Motif (comme Gadget, Text et VendorShell) ont des ressources qui ne sont pas accessibles via les fonctions XtGetResourceList et XtGetConstraintResourceList. Afin de récupérer les descriptions de ces ressources, une application doit utiliser XmGetSecondaryResourceData.

Lorsqu'une classe de widget possède de telles ressources, cette fonction fournit les descriptions des ressources dans une ou plusieurs structures de données. XmGetSecondaryResourceData prend un argument de classe de widget et renvoie le nombre de ces structures de données associées à la classe de widget. Si la valeur de retour est supérieure à 0 (zéro), la fonction alloue et remplit un tableau de pointeurs vers les structures de données correspondantes. Elle renvoie ce tableau à l'adresse qui est la valeur de l'argument secondary_data_return.

Le type XmSecondaryResourceData est un pointeur vers une structure avec deux membres utiles à une application : resources, de type XtResourceList, et num_resources, de type Cardinal. Le membre resources est une liste des ressources du widget qui ne sont pas accessibles à l'aide des fonctions Xt. Le membre num_resources est la longueur de la liste resources.

Si la valeur de retour est supérieure à 0 (zéro), XmGetSecondaryResourceData alloue de la mémoire que l'application doit libérer. Utilisez XtFree pour libérer la liste des ressources dans chaque structure (la valeur du membre resources), les structures elles-mêmes, et le tableau de pointeurs vers les structures (le tableau dont l'adresse est secondary_data_return).

widget_class
Spécifie la classe de widget pour laquelle les données de ressources secondaires doivent être récupérées.
secondary_data_return
Spécifie un pointeur vers un tableau de pointeurs XmSecondaryResourceData à renvoyer par cette fonction. Si la classe de widget n'a pas de données de ressources secondaires, par exemple, si la valeur renvoyée par la fonction est 0 (zéro), la fonction ne renvoie aucune valeur significative pour cet argument.

VALEUR

Renvoie le nombre de structures de données de ressources secondaires associées à cette classe de widget.

EXEMPLE

L'exemple suivant utilise XmGetSecondaryResourceData pour afficher les noms des ressources secondaires du widget Motif Text, puis libère les données allouées par la fonction :

XmSecondaryResourceData * block_array;
Cardinal num_blocks, i, j;
if (num_blocks = XmGetSecondaryResourceData (xmTextWidgetClass,
                                             &block_array)) {
  for (i = 0; i < num_blocks; i++) {
    for (j = 0; j < block_array[i]->num_resources; j++) {
      printf("%s\n", block_array[i]->resources[j].resource_name);
    }
    XtFree((char*)block_array[i]->resources);
    XtFree((char*)block_array[i]);
  }
  XtFree((char*)block_array);
}
