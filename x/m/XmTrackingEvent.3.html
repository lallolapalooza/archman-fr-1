NOM

XmTrackingEvent — Fonction du Toolkit fournissant une interaction modale

SYNOPSIS

#include <Xm/Xm.h>
Widget XmTrackingEvent(
Widget widget,
Cursor cursor,
Boolean confine_to,
XEvent *event_return);

DESCRIPTION

XmTrackingEvent fournit une interface modale pour la sélection d'un composant. Elle est conçue pour supporter l'aide contextuelle. La fonction appelle XmUpdateDisplay. XmTrackingEvent capture ensuite le pointeur et ignore les événements suivants jusqu'à ce que BSelect soit relâché ou qu'une touche soit pressée puis relâchée. La fonction retourne ensuite le widget ou le gadget qui contient le pointeur lorsque BSelect est relâché ou qu'une touche est relâchée, et libère le pointeur.

widget
Spécifie l'identifiant du widget à utiliser comme base de l'interaction modale. C'est-à-dire, le widget dans lequel l'interaction doit avoir lieu, généralement un shell de plus haut niveau.
cursor
Spécifie le curseur à utiliser pour le pointeur pendant l'interaction. Ceci est un nom de curseur X standard.
confine_to
Spécifie si le curseur doit être confiné à widget ou non.
event_return
Retourne l'événement ButtonRelease ou KeyRelease qui provoque le retour de la fonction.

RETOUR

Retourne le widget ou le gadget qui contient le pointeur lorsque BSelect est relâché ou qu'une touche est relâchée. Si aucun widget ou gadget ne contient le pointeur, la fonction retourne NULL.
