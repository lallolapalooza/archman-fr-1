NOM

XmClipboardInquireFormat — Une fonction de presse-papiers qui renvoie le nom d'un format spécifié

SYNTAXE

#include <Xm/CutPaste.h>
int XmClipboardInquireFormat (display, window, index, format_name_buf,
        buffer_len, copied_len)
        Display * display;
        Window  window;
        int     index;
        XtPointer       format_name_buf;
        unsigned long   buffer_len;
        unsigned long   * copied_len;
(void)

DESCRIPTION

XmClipboardInquireFormat renvoie le nom d'un format spécifié pour l'élément de données dans le presse-papiers. Si le nom doit être tronqué, la fonction renvoie un statut d'avertissement.

display
Spécifie un pointeur vers la structure Display qui a été retournée lors d'un appel précédent à XOpenDisplay ou XtDisplay.
window
Spécifie l'identifiant de fenêtre d'un widget qui relie la fenêtre de l'application au presse-papiers. L'identifiant de fenêtre du widget peut être obtenu via XtWindow. La même instance d'application doit passer le même identifiant de fenêtre à chacune des fonctions de presse-papiers qu'elle appelle.
index
Spécifie lequel des noms de formats ordonnés doit être obtenu. Si cet index est supérieur au nombre de formats pour l'élément de données, cette fonction renvoie 0 (zéro) dans l'argument copied_len.
format_name_buf
Spécifie le tampon qui reçoit le nom du format.
buffer_len
Spécifie le nombre d'octets dans le tampon du nom du format.
copied_len
Spécifie le nombre d'octets de l'élément de données copiés dans le tampon. Si cet argument est égal à 0 (zéro), il n'y a pas de n-ième format pour l'élément de données.

RETOUR

XmClipboardSuccess
La fonction a réussi.
XmClipboardLocked
La fonction a échoué car le presse-papiers était verrouillé par une autre application. L'application peut continuer à appeler la fonction à nouveau avec les mêmes paramètres jusqu'à ce que le verrouillage disparaisse. Cela donne à l'application la possibilité de demander si l'utilisateur souhaite continuer à essayer ou abandonner l'opération.
XmClipboardTruncate
Les données renvoyées sont tronquées car l'utilisateur n'a pas fourni de tampon suffisamment grand pour contenir les données.
XmClipboardNoData
La fonction n'a pas pu trouver de données sur le presse-papiers correspondant au format demandé. Cela peut se produire parce que le presse-papiers est vide ; il y a des données sur le presse-papiers, mais pas dans le format demandé ; ou les données dans le format demandé ont été passées par nom et ne sont plus disponibles.
