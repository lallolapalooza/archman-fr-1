NOM

XmAddToPostFromList — un appel de RowColumn qui rend un menu accessible depuis plus d'un widget

SYNTAXE

#include <Xm/RowColumn.h>

void XmAddToPostFromList(
Widget menu,
Widget post_from_widget);

DESCRIPTION

XmAddToPostFromList rend un menu accessible depuis plus d'un widget. Une fois qu'un menu est créé, cette fonction peut être utilisée pour le rendre accessible depuis un second widget. Le processus peut être répété indéfiniment. En d'autres termes, là où une application utiliserait XmCreatePopupMenu ou XmCreatePulldownMenu ou leurs équivalents pour créer un nouveau menu identique à un qui existe déjà, elle peut utiliser cette fonction pour réutiliser ce menu précédent.

Si menu fait référence à un menu Popup, alors le widget post_from_widget peut maintenant faire apparaître le menu spécifié. L'apparition effective du menu se produit comme d'habitude, soit via un gestionnaire d'événements, soit via la prise en charge automatique des menus contextuels (voir la page de référence de XmRowColumn(3)).

Si menu fait référence à un menu Pulldown, son ID est placé dans la ressource XmNsubMenuId du widget post_from_widget spécifié. Dans ce cas, le widget post_from_widget doit être soit un CascadeButton, soit un CascadeButtonGadget.

Notez que cette fonction manipule les structures internes elles-mêmes, pas une copie de celles-ci.

menu
Spécifie l'ID du widget RowColumn contenant le menu (Popup ou Pulldown) à rendre accessible depuis le widget.
post_from_widget
Spécifie l'ID du widget qui sera maintenant capable de faire apparaître le menu spécifié par menu.

Pour une définition complète de RowColumn et de ses ressources associées, voir XmRowColumn(3).

LIÉS

XmGetPostedFromWidget(3), XmRemoveFromPostFromList(3), et XmRowColumn(3).
