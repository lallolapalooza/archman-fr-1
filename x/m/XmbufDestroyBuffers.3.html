DESCRIPTION

La bibliothèque d'interface de programmation pour l'extension X11 de Double-Buffering, Multi-Buffering et Stéréo contient les interfaces décrites ci-dessous. À l'exception de XmbufQueryExtension, si l'une de ces routines est appelée avec un affichage qui ne prend pas en charge l'extension, le gestionnaire d'erreurs d'extension (qui peut être défini avec XSetExtensionErrorHandler et fonctionne de la même manière que XSetErrorHandler) sera appelé et la fonction retournera ensuite.

XmbufQueryExtension retourne True si l'extension de multi-buffering/stéréo est disponible sur l'affichage donné. Si l'extension existe, la valeur du premier code d'événement (qui doit être ajoutée aux constantes de type d'événement MultibufferClobberNotify et MultibufferUpdateNotify pour obtenir les valeurs réelles) est stockée dans event_base_return et la valeur du premier code d'erreur (qui doit être ajoutée à la constante de type d'erreur MultibufferBadBuffer pour obtenir la valeur réelle) est stockée dans error_base_return.

XmbufGetVersion récupère les numéros de version majeure et mineure de l'extension. La valeur de retour est zéro si une erreur se produit ou est non nulle si aucune erreur ne se produit.

XmbufCreateBuffers demande la création de "count" buffers avec l'action de mise à jour et l'indice de mise à jour donnés et leur association avec la fenêtre indiquée. Le nombre de buffers créés est renvoyé (zéro si une erreur s'est produite) et buffers_update est rempli avec ce nombre d'identifiants Multibuffer.

XmbufDestroyBuffers détruit les buffers associés à la fenêtre donnée.

XmbufDisplayBuffers affiche les buffers indiqués dans leurs fenêtres appropriées dans un délai maximum de max_delay millisecondes après que min_delay millisecondes se soient écoulées. Deux buffers ne peuvent pas être associés à la même fenêtre, sinon une erreur Match est générée.

XmbufGetWindowAttributes récupère les attributs de multi-buffering qui s'appliquent à tous les buffers associés à la fenêtre donnée. La liste des buffers renvoyée peut être libérée avec XFree. Retourne une valeur non nulle en cas de succès et zéro en cas d'erreur.

XmbufChangeWindowAttributes définit les attributs de multi-buffering qui s'appliquent à tous les buffers associés à la fenêtre donnée. Ceci est actuellement limité à l'indice de mise à jour.

XmbufGetBufferAttributes récupère les attributs du buffer indiqué. Retourne une valeur non nulle en cas de succès et zéro en cas d'erreur.

XmbufChangeBufferAttributes définit les attributs du buffer indiqué. Ceci est actuellement limité au masque d'événements.

XmbufGetScreenInfo récupère les paramètres contrôlant la manière dont les fenêtres mono et stéréo peuvent être créées sur l'écran du dessinable donné. Le nombre d'ensembles de visuals et de profondeurs est renvoyé dans nmono_return et nstereo_return. Si nmono_return est supérieur à zéro, alors mono_info_return est défini à l'adresse d'un tableau de structures XmbufBufferInfo décrivant les différents visuals et profondeurs qui peuvent être utilisés. Sinon, mono_info_return est défini à NULL. De même, stereo_info_return est défini en fonction de nstereo_return. Le stockage renvoyé dans mono_info_return et stereo_info_return peut être libéré par XFree. Si aucune erreur n'est rencontrée, une valeur non nulle sera renvoyée.

XmbufCreateStereoWindow crée une fenêtre stéréo de la même manière que XCreateWindow crée une fenêtre mono. Les identifiants de buffer pour les buffers gauche et droit sont renvoyés respectivement dans left_return et right_return. Si un gestionnaire d'erreurs d'extension qui retourne est installé, None sera renvoyé si l'extension n'est pas disponible sur cet affichage.

XmbufDestroyBuffers(3)

NAME

XmbufDestroyBuffers – detruit les tampons

SYNTAX

void XmbufDestroyBuffers(Display *dpy, XICImageBuffer *buffer_list);

STRUCTURES

typedef struct {
    XICImageBuffer *next;
    int buffer_id;
    unsigned int update_mask;
} XICImageBuffer;

DESCRIPTION

La fonction XmbufDestroyBuffers detruit une liste de tampons qui ont eté alloués par les fonctions d'extension multi-buffers de libXext.

Elle itere sur la liste des tampons, libere la memoire de chaque tampon et ensuite la memoire de la liste elle-meme.

PREDEFINED VALUES

Les valeurs suivantes peuvent apparaitre dans le champ update_mask.

    ferUpdateNotifyMask
    MultibufferClobberNotify
    MultibufferUpdateNotify
    MultibufferNumberEvents
    MultibufferBadBuffer
    MultibufferNumberErrors
