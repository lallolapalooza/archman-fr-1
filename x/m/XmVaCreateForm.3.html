NOM

XmVaCreateForm, XmVaCreateManagedForm — Fonctions de création pratique pour les widgets Form.

SYNOPSIS

#include <Xm/Form.h>
Widget XmVaCreateForm(
Widget parent,
String name,
...);
Widget XmVaCreateManagedForm(
Widget parent,
String name,
...);

DESCRIPTION

Ces fonctions créent une instance d'un widget Form et retournent l'identifiant du widget associé. Ces routines utilisent la convention d'appel de liste d'arguments de longueur variable (varargs) d'ANSI C.

La fonction XmVaCreateForm est une routine pratique qui appelle XtCreateWidget.

La fonction XmVaCreateManagedForm est une routine pratique qui appelle XtCreateManagedWidget.

parent
Spécifie l'identifiant du widget parent.
name
Spécifie le nom du widget créé.
...
Spécifie la liste d'arguments variables pour remplacer les valeurs par défaut des ressources.

Pour une définition complète de Form et de ses ressources associées, voir XmForm(3).

RETOUR

Retourne l'identifiant du widget Form.

LIRE AUSSI

XmForm(3), XmCreateForm(3), XtCreateWidget(3), et XtCreateManagedWidget(3).
