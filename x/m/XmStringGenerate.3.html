NOM

XmStringGenerate — Une fonction de commodité qui génère une chaîne composée

SYNOPSIS

#include <Xm/Xm.h>
XmString XmStringGenerate(
XtPointer text,
XmStringTag tag,
XmTextType type,
XmStringTag rendition);

DESCRIPTION

XmStringGenerate appelle la fonction XmStringParseText avec une table d'analyse par défaut composée des entrées '0&', qui est mappée à Separator, et '', qui est mappée à Tab. Les composants RENDITION_BEGIN et RENDITION_END correspondants contenant rendition sont placés autour du XmString résultant.

text
Spécifie une chaîne terminée par NULL contenant des caractères d'un type déterminé par type.
tag
Spécifie l'étiquette à utiliser pour créer le résultat. Le type d'étiquette créée (charset ou locale) dépend du type de texte et de la valeur donnée. Si la valeur spécifiée est NULL, et type indique qu'une étiquette de jeu de caractères doit être créée, alors l'étiquette aura la valeur de XmFONTLIST_DEFAULT_TAG. Si tag est NULL, et type indique une étiquette de locale, alors l'étiquette aura la valeur de _MOTIF_DEFAULT_LOCALE.
type
Spécifie le type de texte à passer, et le type d'étiquette. Si une étiquette de locale doit être créée, alors type a une valeur de XmMULTIBYTE_TEXT ou XmWIDECHAR_TEXT. Si un jeu de caractères doit être créé, type a une valeur de XmCHARSET_TEXT.
rendition
Spécifie l'étiquette de rendition à utiliser dans un composant XmSTRING_COMPONENT_RENDITION_BEGIN qui commencera la chaîne retournée et dans un composant XmSTRING_COMPONENT_RENDITION_END qui la terminera. Si rendition est NULL, aucune étiquette de rendition n'est placée.

RETOUR

Retourne une nouvelle chaîne composée. La fonction allouera de l'espace pour contenir la chaîne composée retournée. Lorsque l'application n'aura plus besoin de la chaîne composée retournée, elle devra appeler XmStringFree.

VOIR AUSSI

XmString(3) et XmStringFree(3).
