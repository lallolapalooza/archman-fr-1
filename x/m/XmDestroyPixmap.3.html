NOM

XmDestroyPixmap — Une fonction de mise en cache de pixmap qui supprime une pixmap du cache de pixmaps

SYNTAXE

#include <Xm/Xm.h>
Boolean XmDestroyPixmap(
Screen * screen,
Pixmap pixmap);

DESCRIPTION

XmDestroyPixmap supprime les pixmaps qui ne sont plus utilisées. Les pixmaps ne sont complètement libérées que lorsqu'il n'y a plus aucune référence à celles-ci.

screen
Spécifie l'écran d'affichage pour lequel la pixmap a été demandée
pixmap
Spécifie la pixmap à détruire

VALEUR DE RETOUR

Retourne True en cas de succès ; retourne False s'il n'y a pas d'écran et de pixmap correspondants dans le cache de pixmaps.

VOIR AUSSI

XmInstallImage(3), XmUninstallImage(3), et XmGetPixmap(3).
