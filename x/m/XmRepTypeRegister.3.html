NOM

XmRepTypeRegister — Une fonction du gestionnaire de types de représentation qui enregistre une ressource de type de représentation

SYNOPSIS

#include <Xm/RepType.h>
XmRepTypeId XmRepTypeRegister(
String rep_type,
String *value_names,
unsigned char *values,
unsigned char num_values);

DESCRIPTION

XmRepTypeRegister enregistre une ressource de type de représentation auprès du gestionnaire de types de représentation. Toutes les fonctionnalités de l'installation de gestion des types de représentation deviennent disponibles pour le type de représentation spécifié. La fonction installe un convertisseur de type direct pour convertir les valeurs chaîne en valeurs numériques de type de représentation.

Lorsque l'argument values est NULL, des valeurs numériques consécutives sont supposées. L'ordre des chaînes dans le tableau value_names détermine les valeurs numériques pour la ressource. Par exemple, le premier nom de valeur est 0 (zéro) ; le deuxième nom de valeur est 1 ; et ainsi de suite.

S'il n'est pas NULL, l'argument values peut être utilisé pour attribuer des valeurs aux types de représentation qui ont des valeurs non consécutives ou des noms dupliqués pour la même valeur. Les types de représentation enregistrés de cette manière consommeront du stockage supplémentaire et seront légèrement plus lents que les types de représentation avec des valeurs consécutives.

Un type de représentation ne peut être enregistré qu'une seule fois ; si le même nom de type de représentation est enregistré plus d'une fois, le comportement n'est pas défini.

La fonction XmRepTypeAddReverse installe un convertisseur inverse pour un type de représentation enregistré. Le convertisseur inverse prend une valeur numérique de type de représentation et renvoie la valeur chaîne correspondante. Si la liste des valeurs numériques pour un type de représentation contient des valeurs dupliquées, le convertisseur inverse utilise le premier nom de la liste value_names qui correspond à la valeur numérique spécifiée. Par exemple, si un tableau value_names contient cancel, proceed et abort, et que le tableau values correspondant contient 0, 1 et 0, le convertisseur inverse renverra cancel au lieu de abort pour une valeur d'entrée de 0.

rep_type
Spécifie le nom du type de représentation.
value_names
Spécifie un pointeur vers un tableau de noms de valeurs associés au type de représentation. Un nom de valeur est spécifié en minuscules sans préfixe Xm. Les mots dans un nom sont séparés par des underscores.
values
Spécifie un pointeur vers un tableau de valeurs associées au type de représentation. Une valeur dans ce tableau est associée au nom de valeur dans la position correspondante du tableau value_names.
num_values
Spécifie le nombre d'entrées dans les tableaux value_names et values.

RETOUR

Renvoie l'identifiant du type de représentation spécifié.

VOIR AUSSI

XmRepTypeAddReverse(3), XmRepTypeGetId(3), XmRepTypeGetNameList(3), XmRepTypeGetRecord(3), XmRepTypeGetRegistered(3), et XmRepTypeValidValue(3).
