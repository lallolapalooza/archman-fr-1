NOM

XmString — Type de données pour une chaîne composite

SYNTAXE

#include <Xm/Xm.h>

DESCRIPTION

XmString est le type de données pour une chaîne composite. Les chaînes composites consistent en une séquence de composantes, incluant, mais sans s'y limiter, les suivantes :

•
XmSTRING_COMPONENT_SEPARATOR
•
XmSTRING_COMPONENT_TAB
•
XmSTRING_COMPONENT_LAYOUT_POP
•
XmSTRING_COMPONENT_DIRECTION
•
XmSTRING_COMPONENT_LAYOUT_PUSH
•
XmSTRING_COMPONENT_CHARSET
•
XmSTRING_COMPONENT_FONTLIST_ELEMENT_TAG
•
XmSTRING_COMPONENT_LOCALE
•
XmSTRING_COMPONENT_LOCALE_TEXT
•
XmSTRING_COMPONENT_TAG
•
XmSTRING_COMPONENT_TEXT
•
XmSTRING_COMPONENT_END
•
XmSTRING_COMPONENT_RENDITION_BEGIN
•
XmSTRING_COMPONENT_RENDITION_END
•
XmSTRING_COMPONENT_UNKNOWN
•
XmSTRING_COMPONENT_WIDECHAR_TEXT

et également une table de balises de rendition, un texte et un composant de texte. Lorsqu'une chaîne composite est affichée, les balises de rendition et la direction sont utilisées pour déterminer comment afficher le texte.

Appeler XtGetValues pour une ressource dont le type est XmString renvoie une copie de la valeur de la ressource de chaîne composite. L'application est responsable de l'utilisation de XmStringFree pour libérer la mémoire allouée pour la copie.

Veuillez consulter la page de référence XmStringComponentType pour plus de détails sur les composantes de chaînes composites, et pour une description de l'ordre dans lequel les composantes doivent apparaître dans une chaîne composite. Référez-vous à la page de référence XmRenderTable pour une description de l'algorithme qui associe les balises de rendition utilisées pour afficher une composante de texte de chaîne composite à une rendition dans une table de rendu.
