NOM

XmTextFieldCopyLink — Fonction TextField qui copie un lien de la sélection principale dans le presse-papiers

SYNTAXE

#include <Xm/TextF.h>
Boolean XmTextFieldCopyLink(
Widget widget,
Time time);

DESCRIPTION

XmTextFieldCopyLink copie un lien vers le texte sélectionné principalement dans le presse-papiers. Cette routine appelle les procédures XmNconvertCallback, éventuellement plusieurs fois, avec le membre selection de XmConvertCallbackStruct défini sur CLIPBOARD et avec le membre parm défini sur XmLINK. Le widget TextField lui-même ne copie aucun lien ; les procédures XmNconvertCallback sont responsables de la copie du lien dans le presse-papiers et de la prise de toute action connexe.

widget
Spécifie l'ID du widget TextField.
time
Spécifie l'heure du transfert. Il doit s'agir de l'heure de l'événement qui a déclenché cette requête. Une source d'horodatage valide est la fonction XtLastTimestampProcessed.

Pour une définition complète de TextField et de ses ressources associées, voir XmTextField(3).

VALEUR

Cette fonction renvoie False si la sélection principale est NULL, si le widget ne possède pas la sélection principale, si la fonction ne peut pas obtenir la propriété de la sélection du presse-papiers, ou si aucune donnée n'est placée dans le presse-papiers. Sinon, elle renvoie True.
