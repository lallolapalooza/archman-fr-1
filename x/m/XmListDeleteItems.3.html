NOM

XmListDeleteItems — Fonction de liste pour supprimer des éléments de la liste

SYNOPSIS

#include <Xm/List.h>
void XmListDeleteItems(
Widget widget,
XmString *items,
int item_count);

DESCRIPTION

XmListDeleteItems supprime les éléments spécifiés de la liste. Pour chaque élément de items, le premier élément de la liste qui correspond à cet élément est supprimé. Un message d'avertissement apparaît si l'un des éléments n'existe pas.

widget
Spécifie l'ID de la liste dont un élément est supprimé
items
Spécifie un pointeur vers les éléments à supprimer de la liste
item_count
Spécifie le nombre d'éléments dans items Ce nombre doit être non négatif.

Pour une définition complète de List et de ses ressources associées, voir XmList(3).
