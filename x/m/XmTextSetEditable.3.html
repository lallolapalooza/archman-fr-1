NOM

XmTextSetEditable — Une fonction Text qui définit la permission d'édition

SYNOPSIS

#include <Xm/Text.h>
void XmTextSetEditable(
Widget widget,
Boolean editable);

DESCRIPTION

XmTextSetEditable définit l'état de la permission d'édition du widget Text. Lorsqu'il est défini sur True, la chaîne de caractères peut être modifiée.

widget
Spécifie l'identifiant du widget Text
editable
Spécifie une valeur booléenne qui, lorsqu'elle est à True, autorise les modifications de la chaîne de caractères

Pour une définition complète de Text et de ses ressources associées, voir XmText(3).
