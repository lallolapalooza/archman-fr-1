XmRenderTableAddRenditions(appel de bibliothèque) XmRenderTableAddRenditions(appel de bibliothèque)

NOM

XmRenderTableAddRenditions — Crée une nouvelle table de rendu

SYNTAXE

#include <Xm/Xm.h>
XmRenderTable XmRenderTableAddRenditions(
XmRenderTable oldtable,
XmRendition *renditions,
Cardinal rendition_count,
XmMergeMode merge_mode);

DESCRIPTION

XmRenderTableAddRenditions est une fonction pour créer une nouvelle table de rendu qui inclut les rendus listés dans oldtable, s'il y en a une. Cette fonction copie également les rendus spécifiés (renditions) dans la nouvelle table de rendu. Les rendition_count premiers rendus du tableau renditions sont ajoutés à la nouvelle table. Si un rendu est marqué avec une étiquette qui correspond à une étiquette déjà présente dans oldtable, le rendu existant utilisant cette étiquette est soit modifié, soit libéré et remplacé par le nouveau rendu, en fonction de la valeur de merge_mode. Si oldtable est NULL, XmRenderTableAddRenditions crée une nouvelle table de rendu contenant uniquement les rendus spécifiés.

Cette fonction désalloue la table de rendu d'origine après avoir extrait les informations requises. Il incombe à l'appelant de libérer les rendus du tableau renditions en appelant la fonction XmRenditionFree.

oldtable
Spécifie la table de rendu à laquelle ajouter.
renditions
Spécifie un tableau de rendus à ajouter.
rendition_count
Spécifie le nombre de rendus de renditions à ajouter.
merge_mode
Spécifie quoi faire si le XmNtag d'un rendu correspond à celui d'un rendu déjà existant dans oldtable. Les valeurs possibles sont les suivantes :
XmMERGE_REPLACE
Remplace complètement l'ancien rendu par le nouveau.
XmMERGE_OLD
Remplace les valeurs non spécifiées de l'ancien rendu par les valeurs correspondantes du nouveau rendu.
XmMERGE_NEW
Remplace l'ancien rendu par le nouveau rendu, en remplaçant les valeurs non spécifiées du nouveau rendu par les valeurs correspondantes de l'ancien rendu.
XmSKIP
Ignore le nouveau rendu, laissant l'ancien rendu intact.

RETOUR

Si renditions est NULL ou rendition_count est 0 (zéro), cette fonction retourne oldtable. Sinon, la fonction retourne une nouvelle XmRenderTable. La fonction alloue de l'espace pour contenir cette nouvelle table de rendu. L'application est responsable de la gestion de cet espace alloué. L'application peut récupérer l'espace alloué en appelant XmRenderTableFree.

VOIR AUSSI

XmRendition(3) et XmRenderTableFree(3).
