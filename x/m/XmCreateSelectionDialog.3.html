NOM

XmCreateSelectionDialog — Fonction de création pratique de boîte de dialogue SelectionBox

SYNTAXE

#include <Xm/SelectioB.h>
Widget XmCreateSelectionDialog(
Widget parent,
String name,
ArgList arglist,
Cardinal argcount);

DESCRIPTION

XmCreateSelectionDialog est une fonction de création pratique qui crée une boîte de dialogue (DialogShell) et un enfant non géré de type SelectionBox pour cette boîte de dialogue. Une boîte de dialogue de sélection (SelectionDialog) propose à l'utilisateur un choix parmi une liste d'alternatives et obtient une sélection. Elle comprend les éléments suivants :

•
Une liste déroulante d'alternatives
•
Un champ de texte modifiable pour l'alternative sélectionnée
•
Des étiquettes pour le champ de texte
•
Quatre boutons

Les étiquettes par défaut des boutons sont OK, Cancel, Apply et Help. Un enfant supplémentaire de type WorkArea peut être ajouté à la SelectionBox après sa création.

XmCreateSelectionDialog force la valeur de la ressource SelectionBox XmNdialogType à XmDIALOG_SELECTION.

XmCreateSelectionDialog force la valeur de la ressource Shell XmNallowShellResize à True.

Utilisez XtManageChild pour afficher la SelectionDialog (en passant la SelectionBox comme paramètre widget) ; utilisez XtUnmanageChild pour la masquer.

parent
Spécifie l'ID du widget parent
name
Spécifie le nom du widget créé
arglist
Spécifie la liste d'arguments
argcount
Spécifie le nombre de paires attribut/valeur dans la liste d'arguments (arglist)

Pour une définition complète de SelectionBox et de ses ressources associées, consultez XmSelectionBox(3).

RETOUR

Retourne l'ID du widget SelectionBox.

VOIR AUSSI

XmSelectionBox(3).
