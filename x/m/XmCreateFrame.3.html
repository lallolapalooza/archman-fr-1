NOM

XmCreateFrame — Fonction de création du widget Frame

SYNTAXE

#include <Xm/Frame.h>
Widget XmCreateFrame(
Widget parent,
String name,
ArgList arglist,
Cardinal argcount);

DESCRIPTION

XmCreateFrame crée une instance d'un widget Frame et renvoie l'identifiant du widget associé.

parent
Spécifie l'identifiant du widget parent
name
Spécifie le nom du widget créé
arglist
Spécifie la liste d'arguments
argcount
Spécifie le nombre de paires attribut/valeur dans la liste d'arguments (arglist)

Pour une définition complète de Frame et de ses ressources associées, voir XmFrame(3).

VALEUR DE RETOUR

Renvoie l'identifiant du widget Frame.

VOIR AUSSI

XmFrame(3).
