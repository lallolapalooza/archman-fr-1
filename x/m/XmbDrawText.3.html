XmbDrawText(3)

Paquet: libx11

Licences: MIT AND X11

XmbDrawText(3) FONCTIONS XLIB XmbDrawText(3)

NOM

XmbDrawText, XwcDrawText, Xutf8DrawText - dessiner du texte en utilisant plusieurs ensembles de polices

SYNTAXE

void XmbDrawText(Display *display, Drawable d, GC gc, int x, int y, XmbTextItem *items, int nitems);

void XwcDrawText(Display *display, Drawable d, GC gc, int x, int y, XwcTextItem *items, int nitems);

void Xutf8DrawText(Display *display, Drawable d, GC gc, int x, int y, XmbTextItem *items, int nitems);

ARGUMENTS

d
Spécifie le dessinable.
display
Spécifie la connexion au serveur X.
gc
Spécifie le GC.
items
Spécifie un tableau d'éléments textuels.
nitems
Spécifie le nombre d'éléments textuels dans le tableau.
x

y
Spécifient les coordonnées x et y.

DESCRIPTION

Les fonctions XmbDrawText, XwcDrawText et Xutf8DrawText permettent des décalages complexes et des changements d'ensembles de polices entre les chaînes de texte. Chaque élément textuel est traité tour à tour, l'origine d'un élément de texte étant avancée dans la direction de dessin principale par l'échappement de l'élément textuel précédent. Un delta d'élément textuel spécifie un échappement supplémentaire de l'origine du dessin de l'élément textuel dans la direction de dessin principale. Un membre font_set autre que None dans un élément provoque l'utilisation de l'ensemble de polices pour cet élément et les éléments textuels suivants dans la liste text_items. Les éléments textuels de tête dont le membre font_set est réglé sur None ne seront pas dessinés.

XmbDrawText, XwcDrawText et Xutf8DrawText n'effectuent aucun rendu dépendant du contexte entre les segments de texte. Les clients peuvent calculer les métriques de dessin en passant chaque segment de texte à XmbTextExtents, XwcTextExtents, Xutf8TextExtents ou XmbTextPerCharExtents, XwcTextPerCharExtents. Xutf8TextPerCharExtents. Lorsque le XFontSet a des jeux de caractères manquants, chaque caractère indisponible est dessiné avec la chaîne par défaut retournée par XCreateFontSet. Le comportement pour un point de code invalide est indéfini.

La fonction Xutf8DrawText est une extension introduite par The XFree86 Project, Inc., dans sa version 4.0.2. Sa présence est indiquée par le macro X_HAVE_UTF8_STRING.

STRUCTURES

La structure XmbTextItem contient :

typedef struct {
        char *chars;    /* pointeur vers la chaîne */
        int nchars;     /* nombre d'octets */
        int delta;      /* delta de pixels entre les chaînes */
        XFontSet font_set;      /* polices, None signifie ne pas changer */
} XmbTextItem;

La structure XwcTextItem contient :

typedef struct {
        wchar_t *chars; /* pointeur vers la chaîne de caractères larges */
        int nchars;     /* nombre de caractères larges */
        int delta;      /* delta de pixels entre les chaînes */
        XFontSet font_set;      /* polices, None signifie ne pas changer */
} XwcTextItem;
