NOM

XmListItemPos — Fonction de liste renvoyant la position d'un élément dans la liste

SYNTAXE

#include <Xm/List.h>
int XmListItemPos(
Widget widget,
XmString item);

DESCRIPTION

XmListItemPos renvoie la position de la première instance de l'élément spécifié dans une liste.

widget
Spécifie l'identifiant du widget List
item
Spécifie l'élément dont la position est renvoyée

Pour une définition complète de List et de ses ressources associées, voir XmList(3).

VALEUR

Renvoie la position dans la liste de la première instance de l'élément spécifié. La position du premier élément de la liste est 1 ; la position du deuxième élément est 2 ; et ainsi de suite. Cette fonction renvoie 0 (zéro) si l'élément n'est pas trouvé.

VOIR AUSSI

XmList(3).
