NOM

XmStringTableUnparse — Une fonction utilitaire qui convertit une table de chaînes composées en un tableau de texte

SYNTAXE

#include <Xm/Xm.h>
XtPointer * XmStringTableUnparse(
XmStringTable table,
Cardinal count,
XmStringTag tag,
XmTextType tag_type,
XmTextType output_type,
XmParseTable parse,
Cardinal parse_count,
XmParseModel parse_model);

DESCRIPTION

XmStringTableUnparse prend un tableau de chaînes composées, alloue un tableau de chaînes pour le type de caractères déterminé par type avec un nombre égal d'emplacements, appelle XmStringUnparse sur chaque chaîne composée dans table, et insère la chaîne résultante dans l'emplacement correspondant du tableau.

table
Spécifie une XmStringTable contenant la chaîne composée à convertir.
count
Spécifie le nombre de chaînes composées dans table.
tag
Spécifie la balise à utiliser pour la correspondance avec les segments de texte. Les deux types de balises sont XmFONTLIST_DEFAULT_TAG et _MOTIF_DEFAULT_LOCALE. Seuls les segments balisés avec tag seront retournés. Si tag est NULL, tous les segments seront mis en correspondance.
tag_type
Spécifie le type de balise à rechercher. Ces types incluent XmMULTIBYTE_TEXT, XmWIDECHAR_TEXT, et XmCHARSET_TEXT.
output_type
Spécifie le type de texte à générer. Ces types incluent XmMULTIBYTE_TEXT, XmWIDECHAR_TEXT, et XmCHARSET_TEXT.
parse
Spécifie la table d'analyse à utiliser.
parse_count
Spécifie le nombre d'éléments dans parse.
parse_model
Spécifie quels composants non textuels doivent être pris en compte lors de la mise en correspondance dans parse_table. Les valeurs possibles sont :
XmOUTPUT_ALL
Sortie de tous les composants correspondants.
XmOUTPUT_BETWEEN
Sortie uniquement des composants correspondants qui se trouvent entre deux composants textuels correspondants.
XmOUTPUT_BEGINNING
Sortie uniquement des composants correspondants qui se trouvent au début d'un composant textuel correspondant.
XmOUTPUT_END
Sortie uniquement des composants correspondants qui se trouvent à la fin d'un composant textuel correspondant.
XmOUTPUT_BOTH
Sortie uniquement des composants correspondants qui se trouvent au début ou à la fin d'un composant textuel correspondant.

RETOUR

Retourne un tableau alloué de chaînes allouées. L'application est responsable de la gestion de l'espace alloué. L'application peut récupérer l'espace des chaînes allouées en appelant XtFree count fois (c'est-à-dire une fois pour chaque chaîne allouée). L'application peut ensuite récupérer le tableau alloué en appelant XtFree sur le tableau alloué lui-même.
