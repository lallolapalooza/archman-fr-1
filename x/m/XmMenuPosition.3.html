NOM

XmMenuPosition — Fonction RowColumn qui positionne un panneau de menu contextuel

SYNTAXE

#include <Xm/RowColumn.h>
void XmMenuPosition(
Widget menu,
XButtonPressedEvent * event);

DESCRIPTION

XmMenuPosition positionne un panneau de menu contextuel en utilisant les informations de l'événement spécifié. Sauf si une application positionne elle-même le panneau de menu, elle doit d'abord appeler cette fonction avant de gérer le menu contextuel. Les champs x_root et y_root de l'événement X spécifié sont utilisés pour déterminer la position du menu.

menu
Spécifie le menu contextuel à positionner
event
Spécifie l'événement passé à la procédure d'action qui gère le menu contextuel

Le coin du menu contextuel qui est positionné à x_root et y_root dépend de la ressource XmNlayoutDirection du widget à partir duquel le menu contextuel est affiché.

Pour une définition complète de RowColumn et de ses ressources associées, voir XmRowColumn(3).
