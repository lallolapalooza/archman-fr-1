NOM

XmMultiListDeselectRow — Fonction MultiList pour désélectionner une ligne dans la liste

SYNTAXE

#include <Xm/MultiList.h>
void XmMultiListDeselectRow(
Widget widget,
XmString row);

DESCRIPTION

XmMultiListDeselectRow désélectionne (enlève la mise en surbrillance) la ligne spécifiée dans le widget MultiList.

widget
Spécifie l'identifiant du widget MultiList à partir duquel un élément est désélectionné.
row
Spécifie le numéro de ligne (commençant à 0) à désélectionner dans le widget MultiList.

Pour une définition complète de MultiList et de ses ressources associées, voir XmMultiList(3).
