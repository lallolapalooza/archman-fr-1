NOM

XmCommandError — Une fonction de Commande qui affiche un message d'erreur

SYNTAXE

#include <Xm/Command.h>
void XmCommandError(
Widget widget,
XmString error);

DESCRIPTION

XmCommandError affiche un message d'erreur dans la zone d'historique du widget Commande. Le XmString d'erreur est affiché jusqu'à ce que la prochaine commande saisie se produise.

widget
Spécifie l'ID du widget Commande
error
Spécifie le XmString passé

Pour une définition complète de Commande et de ses ressources associées, voir XmCommand(3).

LIÉ

XmCommand(3).
