XChangeKeyboardMapping(3) FONCTIONS XLIB XChangeKeyboardMapping(3)

NOM

XChangeKeyboardMapping, XGetKeyboardMapping, XDisplayKeycodes, XSetModifierMapping, XGetModifierMapping, XNewModifiermap, XInsertModifiermapEntry, XDeleteModifiermapEntry, XFreeModifiermap, XModifierKeymap - manipuler le codage du clavier et la structure du codage du clavier

SYNTAXE

int XChangeKeyboardMapping(Display *display, KeyCode first_keycode, int keysyms_per_keycode, KeySym *keysyms, int num_codes);

KeySym *XGetKeyboardMapping(Display *display, KeyCode first_keycode, int keycode_count, int *keysyms_per_keycode_return);

int XDisplayKeycodes(Display *display, int *min_keycodes_return, int *max_keycodes_return);

int XSetModifierMapping(Display *display, XModifierKeymap *modmap);

XModifierKeymap *XGetModifierMapping(Display *display);

XModifierKeymap *XNewModifiermap(int max_keys_per_mod);

XModifierKeymap *XInsertModifiermapEntry(XModifierKeymap *modmap, KeyCode keycode_entry, int modifier);

XModifierKeymap *XDeleteModifiermapEntry(XModifierKeymap *modmap, KeyCode keycode_entry, int modifier);

int XFreeModifiermap(XModifierKeymap *modmap);

ARGUMENTS

display
Spécifie la connexion au serveur X.
first_keycode
Spécifie le premier KeyCode à modifier ou à retourner.
keycode_count
Spécifie le nombre de KeyCodes à retourner.
keycode_entry
Spécifie le KeyCode.
keysyms
Spécifie un tableau de KeySyms.
keysyms_per_keycode
Spécifie le nombre de KeySyms par KeyCode.
keysyms_per_keycode_return
Retourne le nombre de KeySyms par KeyCode.
max_keys_per_mod
Spécifie le nombre d'entrées KeyCode pré-allouées pour les modificateurs dans la carte.
max_keycodes_return
Retourne le nombre maximum de KeyCodes.
min_keycodes_return
Retourne le nombre minimum de KeyCodes.
modifier
Spécifie le modificateur.
modmap
Spécifie la structure XModifierKeymap.
num_codes
Spécifie le nombre de KeyCodes à modifier.

DESCRIPTION

La fonction XChangeKeyboardMapping définit les symboles pour le nombre spécifié de KeyCodes à partir de first_keycode. Les symboles pour les KeyCodes en dehors de cette plage restent inchangés. Le nombre d'éléments dans keysyms doit être :

num_codes * keysyms_per_keycode

Le first_keycode spécifié doit être supérieur ou égal au min_keycode retourné par XDisplayKeycodes, sinon une erreur BadValue se produit. De plus, l'expression suivante doit être inférieure ou égale au max_keycode retourné par XDisplayKeycodes, sinon une erreur BadValue se produit :

first_keycode + num_codes - 1

Le symbole KeySym numéro N, en comptant à partir de zéro, pour le KeyCode K a l'index suivant dans keysyms, en comptant à partir de zéro :

(K - first_keycode) * keysyms_per_keycode + N

Le keysyms_per_keycode spécifié peut être choisi arbitrairement par le client pour être suffisamment grand pour contenir tous les symboles désirés. Une valeur spéciale de KeySym, NoSymbol, doit être utilisée pour remplir les éléments inutilisés pour des KeyCodes individuels. Il est légal que NoSymbol apparaisse dans des positions non finales de la liste effective pour un KeyCode. XChangeKeyboardMapping génère un événement MappingNotify.

Il n'y a aucune obligation que le serveur X interprète ce mappage. Il est simplement stocké pour être lu et écrit par les clients.

XChangeKeyboardMapping peut générer des erreurs BadAlloc et BadValue.

La fonction XGetKeyboardMapping retourne les symboles pour le nombre spécifié de KeyCodes à partir de first_keycode. La valeur spécifiée dans first_keycode doit être supérieure ou égale au min_keycode retourné par XDisplayKeycodes, sinon une erreur BadValue se produit. De plus, l'expression suivante doit être inférieure ou égale au max_keycode retourné par XDisplayKeycodes :

first_keycode + keycode_count - 1

Si ce n'est pas le cas, une erreur BadValue se produit. Le nombre d'éléments dans la liste KeySyms est :

keycode_count * keysyms_per_keycode_return

Le symbole KeySym numéro N, en comptant à partir de zéro, pour le KeyCode K a l'index suivant dans la liste, en comptant à partir de zéro :

(K - first_code) * keysyms_per_code_return + N

Le serveur X choisit arbitrairement la valeur de keysyms_per_keycode_return pour qu'elle soit suffisamment grande pour rapporter tous les symboles demandés. Une valeur spéciale de KeySym, NoSymbol, est utilisée pour remplir les éléments inutilisés pour des KeyCodes individuels. Pour libérer le stockage retourné par XGetKeyboardMapping, utilisez XFree.

XGetKeyboardMapping peut générer une erreur BadValue.

La fonction XDisplayKeycodes retourne le min-keycodes et le max-keycodes supportés par l'affichage spécifié. Le nombre minimum de KeyCodes retournés n'est jamais inférieur à 8, et le nombre maximum de KeyCodes retournés n'est jamais supérieur à 255. Tous les KeyCodes dans cette plage ne sont pas obligatoirement associés à des touches.

La fonction XSetModifierMapping spécifie les KeyCodes des touches (le cas échéant) qui doivent être utilisées comme modificateurs. En cas de succès, le serveur X génère un événement MappingNotify, et XSetModifierMapping retourne MappingSuccess. X autorise au plus 8 touches modificatrices. Si plus de 8 sont spécifiées dans la structure XModifierKeymap, une erreur BadLength se produit.

Le membre modifiermap de la structure XModifierKeymap contient 8 ensembles de max_keypermod KeyCodes, un pour chaque modificateur dans l'ordre Shift, Lock, Control, Mod1, Mod2, Mod3, Mod4 et Mod5. Seuls les KeyCodes non nuls ont une signification dans chaque ensemble, et les KeyCodes nuls sont ignorés. De plus, tous les KeyCodes non nuls doivent se trouver dans la plage spécifiée par min_keycode et max_keycode dans la structure Display, sinon une erreur BadValue se produit.

Un serveur X peut imposer des restrictions sur la manière dont les modificateurs peuvent être modifiés, par exemple, si certaines touches ne génèrent pas de transitions "release" en matériel, si l'auto-répétition ne peut pas être désactivée sur certaines touches, ou si plusieurs touches modificatrices ne sont pas supportées. Si une telle restriction est violée, la réponse de statut est MappingFailed, et aucun des modificateurs n'est modifié. Si les nouveaux KeyCodes spécifiés pour un modificateur diffèrent de ceux actuellement définis et que des touches (actuelles ou nouvelles) pour ce modificateur sont dans l'état logiquement "enfoncé", XSetModifierMapping retourne MappingBusy, et aucun des modificateurs n'est modifié.

XSetModifierMapping peut générer des erreurs BadAlloc et BadValue.

La fonction XGetModifierMapping retourne un pointeur vers une structure XModifierKeymap nouvellement créée qui contient les touches utilisées comme modificateurs. La structure doit être libérée après utilisation en appelant XFreeModifiermap. Si seules des valeurs nulles apparaissent dans l'ensemble pour un quelconque modificateur, ce modificateur est désactivé.

La fonction XNewModifiermap retourne un pointeur vers une structure XModifierKeymap pour une utilisation ultérieure.

La fonction XInsertModifiermapEntry ajoute le KeyCode spécifié à l'ensemble qui contrôle le modificateur spécifié et retourne la structure XModifierKeymap résultante (agrandie si nécessaire).

La fonction XDeleteModifiermapEntry supprime le KeyCode spécifié de l'ensemble qui contrôle le modificateur spécifié et retourne un pointeur vers la structure XModifierKeymap résultante.

XModifierKeymap(3) - X Version 11

NOM

XModifierKeymap - structure de mappage des touches modificatrices X

SYNTAXE

#include <X11/Xutil.h>

ARGUMENTS

display
Spécifie le Display auquel se connecter.
modifier
Spécifie le modificateur à examiner.

DESCRIPTION

La fonction XInsertModifiermapEntry insère une entrée dans la structure XModifierKeymap.

La fonction XDeleteModifiermapEntry supprime une entrée de la structure XModifierKeymap.

La fonction XFreeModifiermap libère la structure XModifierKeymap spécifiée.

STRUCTURES

La structure XModifierKeymap contient :

typedef struct {
        int max_keypermod;      /* Nombre maximum de touches par modificateur sur ce serveur */
        KeyCode *modifiermap;   /* Tableau de 8 par max_keypermod des modificateurs */
} XModifierKeymap;

DIAGNOSTICS

BadAlloc
Le serveur n'a pas pu allouer la ressource ou la mémoire serveur demandée.
BadValue
Une valeur numérique tombe en dehors de la plage acceptée par la requête. Sauf si une plage spécifique est indiquée pour un argument, la plage complète définie par le type de l'argument est acceptée. Tout argument défini comme un ensemble d'alternatives peut générer cette erreur.
