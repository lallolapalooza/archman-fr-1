NOM

XML::Filter::BufferText - Filtre pour mettre tous les caractères() en un seul événement

SYNOPSIS

my $h = SomeHandler->new;
my $f = XML::Filter::BufferText->new( Handler => $h );
my $p = SomeParser->new( Handler => $f );
$p->parse;

DESCRIPTION

Ceci est un filtre très simple. Une cause fréquente de problèmes (et d'erreurs de programmation) est que les analyseurs XML ne sont pas obligés de fournir des événements de caractères en un seul bloc. Ils peuvent le faire, mais n'y sont pas contraints, et la plupart ne le font pas. Ce filtre accomplit la tâche triviale mais souvent répétée de mettre tous les caractères dans un seul événement.

Notez que cela ne vous aidera pas dans les cas comme :

<foo> blah <!-- commentaire --> phubar </foo>

Dans le cas ci-dessus, étant donné le commentaire entrelacé, il y aura deux événements caractère(). Cela pourrait être résolu à l'avenir s'il y a une demande pour cela.

Une façon intéressante d'utiliser ce filtre, au lieu de demander aux utilisateurs de l'utiliser, est de le retourner du constructeur de votre gestionnaire, déjà configuré et tout. Cela rendra la mise en mémoire tampon totalement transparente pour eux ("XML::SAX::Writer" fait cela).
