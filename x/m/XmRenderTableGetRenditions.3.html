NOM

XmRenderTableGetRenditions — Fonction utilitaire qui fait correspondre des balises de rendu

SYNTAXE

#include <Xm/Xm.h>
XmRendition *XmRenderTableGetRenditions(
XmRenderTable table,
XmStringTag *tags,
Cardinal tag_count);

DESCRIPTION

XmRenderTableGetRenditions recherche dans table et renvoie un tableau de copies des rendus dont les ressources XmNtag correspondent à une balise dans tags. Si aucun rendu ne correspond, alors NULL est renvoyé. La taille du tableau renvoyé est tag_count. La ressource XmNtag de chaque rendu correspondra à la balise correspondante dans tags. Si aucune correspondance n'est trouvée pour une balise particulière, l'emplacement correspondant dans la valeur de retour sera NULL.

Il incombe à l'appelant d'appeler la fonction XmRenditionFree pour libérer les nouveaux rendus, et la fonction XtFree pour libérer le tableau.

table
Spécifie la table contenant les rendus à rechercher.
tags
Spécifie les balises à rechercher.
tag_count
Spécifie le nombre de balises dans tags.

VALEUR DE RETOUR

Renvoie NULL s'il n'y a pas de correspondance ; sinon, cette fonction renvoie un tableau de nouveaux XmRenditions.

LIEN CONNEXES

XmRenderTableGetRendition(3), XmRenderTableGetTags(3), et XmRendition(3).
