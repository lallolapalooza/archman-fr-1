NOM

XmDataFieldCopy — Une fonction DataField qui copie la sélection primaire dans le presse-papiers

SYNTAXE

#include <Xm/DataF.h>
Boolean XmDataFieldCopy(
Widget widget,
Time time);

DESCRIPTION

XmDataFieldCopy copie le texte sélectionné en primaire dans le presse-papiers.

Cette routine appelle les procédures XmNconvertCallback, éventuellement plusieurs fois, avec le membre selection de la structure XmConvertCallbackStruct défini sur CLIPBOARD et avec le membre parm défini sur XmCOPY.

widget
Spécifie l'identifiant du widget DataField.
time
Spécifie le moment où la valeur de la sélection doit être modifiée. Ce doit être l'heure de l'événement qui a déclenché cette requête.

Pour une définition complète de DataField et de ses ressources associées, voir XmDataField(3).

VALEUR DE RETOUR

Cette fonction renvoie False si la sélection primaire est NULL, si le widget ne possède pas la sélection primaire, si la fonction ne parvient pas à obtenir la propriété de la sélection du presse-papiers, ou si aucune donnée n'est placée dans le presse-papiers. Sinon, elle renvoie True.
