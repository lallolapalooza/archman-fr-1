NAME

XOpenDevice, XCloseDevice - ouvrir ou fermer un périphérique d'entrée d'extension

SYNOPSIS

#include <X11/extensions/XInput.h>
XDevice *XOpenDevice( Display *display,
                      XID device_id);
XCloseDevice( Display *display,
              XDevice *device);
display
       Spécifie la connexion au serveur X.
device_id
       Spécifie l'identifiant du périphérique à ouvrir
device
       Spécifie le périphérique à fermer

DESCRIPTION

La requête XOpenDevice rend un périphérique d'entrée accessible à
un client via des requêtes de protocole d'extension d'entrée. En cas de
succès, elle retourne un pointeur vers une structure XDevice.
La requête XCloseDevice rend un périphérique d'entrée inaccessible à
un client via des requêtes de protocole d'extension d'entrée. Avant de
se terminer, tout client qui a ouvert des périphériques d'entrée via
l'extension d'entrée devrait les fermer en utilisant CloseDevice.
Lorsqu'un client effectue une requête XCloseDevice, toutes les suspensions actives
que le client a sur le périphérique sont libérées. Toutes les sélections d'événements
que le client a sont supprimées, ainsi que toutes les suspensions passives. Si le client
demandeur est le dernier client à accéder au périphérique, le serveur peut désactiver
tout accès par X au périphérique.
XOpenDevice et XCloseDevice peuvent générer une erreur BadDevice.

Structures

La structure XDevice retournée par XOpenDevice contient :
             typedef struct {
             XID device_id;
             int num_classes;
             XInputClassInfo *classes;
             } XDevice;
Le champ classes est un pointeur vers un tableau de structures XInputClassInfo.
Chaque élément de ce tableau contient une base de type d'événement pour une classe
d'entrée supportée par le périphérique spécifié. Le champ num_classes indique le
nombre d'éléments dans le tableau classes.
La structure XInputClassInfo contient :
typedef struct {
    unsigned char input_class;
    unsigned char event_type_base;
} XInputClassInfo;
Le champ input_class identifie une classe d'entrée supportée par le périphérique.
Les types définis incluent KeyClass, ButtonClass, ValuatorClass, ProximityClass,
FeedbackClass, FocusClass et OtherClass. Le champ event_type_base identifie le
type d'événement du premier événement de cette classe.
Les informations contenues dans la structure XInputClassInfo sont utilisées par des
macros pour obtenir les classes d'événements que les clients utilisent dans les
requêtes XSelectExtensionEvent. Les macros actuellement définies incluent
DeviceKeyPress, DeviceKeyRelease, DeviceButtonPress, DeviceButtonRelease,
DeviceMotionNotify, DeviceFocusIn, DeviceFocusOut, ProximityIn, ProximityOut,
DeviceStateNotify, DeviceMappingNotify, ChangeDeviceNotify,
DevicePointerMotionHint, DeviceButton1Motion, DeviceButton2Motion,
DeviceButton3Motion, DeviceButton4Motion, DeviceButton5Motion, DeviceButtonMotion,
DeviceOwnerGrabButton, DeviceButtonPressGrab et NoExtensionEvent.
Pour obtenir la classe d'événement appropriée pour un périphérique particulier,
l'une des macros ci-dessus est appelée en utilisant la structure XDevice pour ce
périphérique. Par exemple,
             DeviceKeyPress (*device, type, eventclass);
retourne le type d'événement DeviceKeyPress et eventclass pour les événements
DeviceKeyPress de ce périphérique.
Cet eventclass peut ensuite être utilisé dans une requête XSelectExtensionEvent
pour demander au serveur d'envoyer des événements DeviceKeyPress de ce périphérique.
Lorsqu'un événement sélectionné est reçu via XNextEvent, le type peut être utilisé
pour comparaison avec le type de l'événement.

DIAGNOSTICS

BadDevice
       Un périphérique invalide a été spécifié. Le périphérique spécifié
       n'existe pas, ou est le clavier X ou le pointeur X. Cette
       erreur peut également survenir si un autre client a fait en sorte que le
       périphérique spécifié devienne le clavier X ou le pointeur X via
       les requêtes XChangeKeyboardDevice ou XChangePointerDevice.
