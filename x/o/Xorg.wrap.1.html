NOM

Xorg.wrap - Wrapper binaire pour le serveur X Xorg

DESCRIPTION

Le serveur X Xorg peut nécessiter des droits root pour fonctionner correctement. Pour démarrer le serveur X Xorg avec ces droits, votre système utilise un wrapper suid root installé sous le nom de /usr/libexec/Xorg.wrap qui exécutera le véritable serveur X installé sous le nom de /usr/libexec/Xorg.

Par défaut, Xorg.wrap détectera automatiquement si les droits root sont nécessaires, et si ce n'est pas le cas, il abandonnera ses droits élevés avant de démarrer le véritable serveur X. Par défaut, Xorg.wrap autorisera uniquement l'exécution du véritable serveur X à partir de sessions de connexion sur une console physique.

FICHIER DE CONFIGURATION

Le comportement par défaut de Xorg.wrap peut être remplacé depuis le fichier de configuration /etc/X11/Xwrapper.config. Les lignes commençant par un # dans Xwrapper.config sont considérées comme des commentaires et seront ignorées. Toute autre ligne non vide doit prendre la forme clé = valeur.

utilisateurs_autorises = rootonly|console|anybody
Spécifie quels utilisateurs peuvent démarrer le serveur X via le wrapper. Utilisez rootonly pour autoriser uniquement root, console pour autoriser uniquement les utilisateurs connectés sur une console physique, et anybody pour autoriser n'importe qui. La valeur par défaut est console.
a_besoin_de_droits_root = oui|non|auto
Configure si le wrapper doit abandonner ses droits élevés (root) avant de démarrer le serveur X. Utilisez oui pour forcer l'exécution en tant que root, non pour forcer l'exécution avec tous les droits suid abandonnés, et auto pour laisser le wrapper détecter automatiquement. La valeur par défaut est auto.

Lors de la détection automatique, le wrapper abandonnera les droits si le graphisme KMS est disponible et ne les abandonnera pas si aucun graphisme KMS n'est détecté. Si un système possède plusieurs cartes graphiques et que certaines ne sont pas compatibles KMS, la détection automatique peut échouer, dans ce cas, une configuration manuelle devrait être utilisée.
