XIntersectRegion(3) FONCTIONS XLIB XIntersectRegion(3)

NOM

XIntersectRegion, XUnionRegion, XUnionRectWithRegion, XSubtractRegion, XXorRegion, XOffsetRegion, XShrinkRegion - arithmétique de régions

SYNTAXE

int XIntersectRegion(Region sra, Region srb, Region dr_return);

int XUnionRegion(Region sra, Region srb, Region dr_return);

int XUnionRectWithRegion(XRectangle *rectangle, Region src_region, Region dest_region_return);

int XSubtractRegion(Region sra, Region srb, Region dr_return);

int XXorRegion(Region sra, Region srb, Region dr_return);

int XOffsetRegion(Region r, int dx, int dy);

int XShrinkRegion(Region r, int dx, int dy);

ARGUMENTS

dest_region_return
Retourne la région de destination.
dr_return
Retourne le résultat du calcul.
dx

dy
Spécifie les coordonnées x et y, qui définissent la quantité de déplacement ou de réduction de la région spécifiée.
r
Spécifie la région.
rectangle
Spécifie le rectangle.
sra

srb
Spécifie les deux régions avec lesquelles vous souhaitez effectuer le calcul.
src_region
Spécifie la région source à utiliser.

DESCRIPTION

La fonction XIntersectRegion calcule l'intersection de deux régions.

La fonction XUnionRegion calcule l'union de deux régions.

La fonction XUnionRectWithRegion met à jour la région de destination à partir de l'union du rectangle spécifié et de la région source spécifiée.

La fonction XSubtractRegion soustrait srb de sra et stocke les résultats dans dr_return.

La fonction XXorRegion calcule la différence entre l'union et l'intersection de deux régions.

La fonction XOffsetRegion déplace la région spécifiée d'une quantité spécifiée.

La fonction XShrinkRegion réduit la région spécifiée d'une quantité spécifiée. Les valeurs positives réduisent la taille de la région, et les valeurs négatives l'agrandissent.
