XkbNoteDeviceChanges(3) FONCTIONS XKB XkbNoteDeviceChanges(3)

NOM

XkbNoteDeviceChanges - Enregistre les changements de périphérique signalés dans un événement XkbExtensionDeviceNotify

SYNTAXE

void XkbNoteDeviceChanges (XkbDeviceChangesPtr ancien, XkbExtensionDeviceNotifyEvent *nouveau, unsigned int voulu);

ARGUMENTS

ancien
structure qui suit les changements d'état
nouveau
événement indiquant les changements d'état
voulu
masque indiquant les changements à enregistrer

DESCRIPTION

Le champ voulu spécifie les changements qui doivent être enregistrés dans ancien, et est composé de l'OU inclusif binaire de un ou plusieurs des masques du Tableau 1. Le champ reason de l'événement dans nouveau indique les types de changements rapportés par l'événement. XkbNoteDeviceChanges met à jour le XkbDeviceChangesRec spécifié par ancien avec les changements qui sont à la fois spécifiés dans voulu et contenus dans nouveau->reason.

Pour mettre à jour une copie locale de l'état et de la configuration d'un périphérique d'extension d'entrée X avec les changements précédemment enregistrés dans une structure XkbDeviceChangesRec, utilisez XkbGetDeviceInfoChanges.

STRUCTURES

Les changements apportés à un périphérique d'extension Xkb peuvent être suivis en écoutant les événements XkbDeviceExtensionNotify et en accumulant les changements dans une structure XkbDeviceChangesRec. Les changements enregistrés dans la structure peuvent ensuite être utilisés dans des opérations ultérieures pour mettre à jour soit une configuration serveur, soit une copie locale d'une configuration de périphérique d'extension Xkb. La structure des changements est définie comme suit :

typedef struct _XkbDeviceChanges {
    unsigned int         changed;       /* bits indiquant ce qui a changé */
    unsigned short       first_btn;     /* numéro du premier bouton qui a changé, le cas échéant */
    unsigned short       num_btns;      /* nombre de boutons qui ont changé */
    XkbDeviceLedChangesRec leds;
} XkbDeviceChangesRec,*XkbDeviceChangesPtr;
