XkbGetKeyTypes(3) FONCTIONS XKB XkbGetKeyTypes(3)

NOM

XkbGetKeyTypes - Obtient la liste des types de touches disponibles dans la configuration du clavier du serveur

SYNTAXE

Status XkbGetKeyTypes (Display *dpy, unsigned int first, unsigned int num, XkbDescPtr xkb);

ARGUMENTS

dpy
connexion au serveur X
first
indice du premier type à obtenir, 0 => 1er type
num
nombre de types de touches à retourner
xkb
description du clavier contenant la carte client à mettre à jour

DESCRIPTION

XkbGetKeyTypes interroge le serveur pour les types souhaités, attend une réponse et retourne les types souhaités dans xkb->map->types. En cas de succès, elle retourne Success.

XkbGetKeyTypes retourne BadAccess si l'extension Xkb n'a pas été correctement initialisée et BadValue si la combinaison de first et num aboutit à des nombres hors de la plage valide.

NOTE: XkbGetKeyTypes est utilisée pour obtenir des descriptions des types de touches eux-mêmes, pas des types de touches associés à des touches individuelles. Pour obtenir les types de touches associés à une touche individuelle, référez-vous au champ key_sym_map de la carte client.

DIAGNOSTICS

BadAccess
L'extension Xkb n'a pas été correctement initialisée
BadValue
Un argument est hors de portée

VOIR AUSSI

XkbKeyKeyType(3), XkbKeyKeyTypeIndex(3)
