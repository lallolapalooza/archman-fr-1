XkbAllocGeometry(3) FONCTIONS XKB XkbAllocGeometry(3)

NOM

XkbAllocGeometry - Alloue une géométrie entière

SYNTAXE

Status XkbAllocGeometry (XkbDescPtr xkb, XkbGeometrySizesPtr sizes);

ARGUMENTS

xkb
description du clavier pour laquelle la géométrie doit être allouée
sizes
tailles initiales pour tous les composants de la géométrie

DESCRIPTION

Xkb fournit un certain nombre de fonctions pour allouer et libérer des sous-composants d'une géométrie de clavier. Utilisez ces fonctions pour créer ou modifier des géométries de clavier. Notez que ces fonctions allouent simplement de l'espace pour le(s) nouvel(aux) élément(s), et il vous appartient de remplir explicitement les valeurs dans votre code. Ces fonctions d'allocation augmentent sz_* mais ne touchent jamais num_* (sauf en cas d'échec d'allocation, auquel cas elles réinitialisent sz_* et num_* à zéro). Ces fonctions retournent Success si elles réussissent, BadAlloc si elles ne parviennent pas à allouer d'espace, ou BadValue si un paramètre n'est pas conforme aux attentes.

XkbAllocGeometry alloue une géométrie de clavier et l'ajoute à la description du clavier spécifiée par xkb. La description du clavier doit être obtenue via les fonctions XkbGetKeyboard ou XkbAllocKeyboard. Le paramètre sizes spécifie le nombre d'éléments à réserver pour les sous-composants de la géométrie du clavier et peut être nul ou plus. Ces sous-composants incluent les properties, colors, shapes, sections, and doodads.

Pour libérer une géométrie entière, utilisez XkbFreeGeometry.

DIAGNOSTICS

BadAlloc
Impossible d'allouer de l'espace
BadValue
Un argument est hors de portée

VOIR AUSSI

XkbAllocKeyboard(3), XkbFreeGeometry(3), XkbGetKeyboard(3)
