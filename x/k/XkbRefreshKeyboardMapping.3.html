NOM

XkbRefreshKeyboardMapping - Met à jour la description du clavier qui est interne à la bibliothèque X

SYNTAXE

Status XkbRefreshKeyboardMapping (XkbMapNotifyEvent *event);

ARGUMENTS

event
événement initiant le remappage

DESCRIPTION

XkbRefreshKeyboardMapping est l'équivalent Xkb de la fonction XRefreshKeyboardMapping du noyau. Elle demande au serveur X d'envoyer les informations de mappage de clavier actuelles à ce client. Un client invoque généralement XkbRefreshKeyboardMapping après avoir reçu un événement XkbMapNotify. XkbRefreshKeyboardMapping retourne Success si elle réussit et BadMatch si l'événement n'est pas un événement Xkb.

L'événement XkbMapNotify peut être généré lorsqu'un client appelle XkbSetMap, XkbChangeMap, XkbGetKeyboardByName, ou l'une des fonctions standard de la bibliothèque X qui modifient le mappage du clavier ou le mappage des modificateurs.

VALEURS DE RETOUR

Success
La fonction XkbRefreshKeyboardMapping retourne Success lorsque la demande que le serveur X envoie les informations de mappage de clavier actuelles à ce client réussit.

DIAGNOSTICS

BadMatch
Une version compatible de Xkb n'était pas disponible dans le serveur ou un argument a le bon type et la bonne plage, mais est par ailleurs invalide.

VOIR AUSSI

XkbChangeMap(3), XkbGetKeyboardByName(3), XkbSetMap(3), XRefreshKeyboardMapping(3)
