NOM

XkbKeyNumGroups - Renvoie le nombre de groupes de symboles liés à la touche correspondant au keycode

SYNTAXE

int XkbKeyNumGroups (XkbDescPtr xkb, KeyCode keycode);

ARGUMENTS

xkb
Description Xkb d'intérêt
keycode
Keycode d'intérêt

DESCRIPTION

Le champ group_info d'un XkbSymMapRec est une valeur codée contenant le nombre de groupes de symboles liés à la touche ainsi que la spécification du traitement des groupes hors limites. Il est légal pour une touche d'avoir zéro groupe, auquel cas elle n'a pas non plus de symboles et tous les événements de cette touche retournent NoSymbol. Pour obtenir le nombre de groupes de symboles liés à la touche, utilisez XkbKeyNumGroups. Pour modifier le nombre de groupes liés à une touche, utilisez XkbChangeTypesOfKey. Pour obtenir un masque qui détermine le traitement des groupes hors limites, utilisez XkbKeyGroupInfo et XkbOutOfRangeGroupInfo.

Les contrôles du clavier contiennent un champ groups_wrap spécifiant la gestion des groupes illégaux sur une base globale. C'est-à-dire que lorsque l'utilisateur effectue une action qui fait que le groupe effectif sort de la plage légale, le champ groups_wrap spécifie comment normaliser le groupe de clavier effectif vers un groupe qui est légal pour le clavier dans son ensemble, mais il n'y a aucune garantie que le groupe normalisé sera dans la plage des groupes légaux pour une touche individuelle. Le champ group_info par touche spécifie comment une touche traite un groupe effectif légal si la touche n'a pas de type spécifié pour le groupe concerné. Par exemple, la touche Entrée a généralement un seul groupe défini. Si l'utilisateur effectue une action entraînant le changement du groupe de clavier global vers Groupe2, le champ group_info pour la touche Entrée décrit comment gérer cette situation.

Les groupes hors limites pour les touches individuelles sont mappés vers un groupe légal en utilisant les mêmes options que celles utilisées pour le groupe de clavier global. Le type particulier de mappage utilisé est contrôlé par les bits définis dans le drapeau group_info, comme indiqué dans le Tableau 1.

L'extension Xkb est composée de deux parties : une extension serveur, et une extension de bibliothèque X côté client. Ce chapitre discute des fonctions utilisées pour modifier les contrôles affectant le comportement de la partie serveur de l'extension Xkb. Contrôles de bibliothèque X discute des fonctions utilisées pour modifier les contrôles qui affectent uniquement le comportement de la partie client de l'extension ; ces contrôles sont connus sous le nom de Contrôles de bibliothèque.

Xkb contient des fonctionnalités de contrôle qui affectent l'ensemble du clavier, appelées contrôles de clavier globaux. Certains des contrôles peuvent être activés et désactivés sélectivement ; ces contrôles sont appelés les Contrôles Booléens. Les Contrôles Booléens peuvent être activés ou désactivés sous le contrôle du programme et peuvent également être réglés automatiquement sur un état activé ou désactivé lorsqu'un programme client se termine. Les contrôles restants, appelés les Contrôles Non Booléens, sont toujours actifs. La structure XkbControlsRec décrit l'état actuel de la plupart des contrôles globaux et les attributs affectant le comportement de chacune de ces fonctionnalités Xkb. Ce chapitre décrit les contrôles Xkb et comment les manipuler.

Il existe deux composantes possibles pour chacun des Contrôles Booléens : des attributs décrivant comment le contrôle doit fonctionner, et un état décrivant si le comportement dans son ensemble est activé ou désactivé. Les attributs et l'état de la plupart de ces contrôles sont conservés dans la structure XkbControlsRec.

Vous pouvez manipuler les contrôles Xkb individuellement, via des fonctions utilitaires, ou dans leur ensemble. Pour les traiter comme un groupe, modifiez une structure XkbControlsRec pour décrire toutes les modifications à apporter, puis passez cette structure et les indicateurs appropriés à une fonction de bibliothèque Xkb, ou utilisez un XkbControlsChangesRec pour réduire le trafic réseau. Lors de l'utilisation d'une fonction utilitaire pour manipuler un contrôle individuellement, vous n'utilisez pas directement une structure XkbControlsRec.

XkbKeyNumGroups(3)

Nom

XkbKeyNumGroups - utilities XKB pour les groupes de clavier

Synopsis

#include <X11/Xlib.h>
#include <X11/extensions/Xkb.h>

unsigned int XkbKeyNumGroups(XkbDescPtr xkb);
Bool XkbKeyGroupInfo(XkbDescPtr xkb, KeyCode key, unsigned int *num_groups_ret);
Bool XkbOutOfRangeGroupInfo(XkbDescPtr xkb, KeyCode key, unsigned int *num_groups_ret);
Bool XkbControlsControls(XkbDescPtr xkb, unsigned int enable_mask);
XkbControlsPtr XkbGetControls(Display *dpy, XkbDescPtr xkb);
Bool XkbSetControls(Display *dpy, XkbDescPtr xkb, XkbControlsPtr controls);

Arguments

dpy

Une connexion au serveur X.

xkb

Un descripteur de disposition de clavier XKB, souvent obtenu via XkbGetMap(3).

Description

La fonction XkbKeyNumGroups renvoie le nombre de groupes actuellement associés à la touche spécifiée par key dans la disposition de clavier XKB actuelle (xkb).

XkbKeyGroupInfo renvoie le nombre de groupes associés à la touche spécifiée par key, en plaçant la valeur dans num_groups_ret.

XkbOutOfRangeGroupInfo est similaire à XkbKeyGroupInfo, mais il renvoie le nombre de groupes utilisables même si la touche n'en a aucun défini.

XkbControlsControls active ou désactive les contrôles spécifiés par enable_mask.

XkbGetControls renvoie un pointeur vers la structure XkbControlsRec qui contient les paramètres de contrôle de la disposition XKB.

XkbSetControls définit les paramètres de contrôle de la disposition XKB en utilisant les valeurs fournies dans controls.
