XkbLatchModifiers(3) FONCTIONS XKB XkbLatchModifiers(3)

NOM

XkbLatchModifiers - Verrouille et déverrouille n'importe lequel des huit modificateurs réels du clavier

SYNTAXE

Bool XkbLatchModifiers (Display *display, unsigned int device_spec, unsigned int affect, unsigned int values);

ARGUMENTS

display
connexion au serveur X
device_spec
identifiant de périphérique, ou XkbUseCoreKbd
affect
masque des modificateurs réels dont l'état de verrouillage doit changer
values
1 => verrouiller, 0 => déverrouiller ; uniquement pour les modificateurs sélectionnés par affect

DESCRIPTION

XkbLatchModifiers envoie une requête au serveur pour verrouiller les modificateurs réels sélectionnés par affect et values, et pour déverrouiller les modificateurs réels sélectionnés par affect, mais non sélectionnés par values.

XkbLatchModifiers n'attend pas de réponse du serveur. Elle renvoie True si la requête a été envoyée, et False sinon.

Les fonctions de cette section qui modifient l'utilisation des modificateurs utilisent un masque dans le paramètre affect. C'est un OU inclusif au niveau du bit des masques de modificateurs légaux :

Tableau 1 Masques de Modificateurs Réels
Masque
ShiftMask
LockMask
ControlMask
Mod1Mask
Mod2Mask
Mod3Mask
Mod4Mask
Mod5Mask

VALEURS DE RETOUR

True
La fonction XkbLatchModifiers renvoie True si une requête a été envoyée au serveur pour verrouiller les modificateurs réels sélectionnés par affect et values, et pour déverrouiller les modificateurs réels sélectionnés par affect, mais non sélectionnés par values.
False
La fonction XkbLatchModifiers renvoie False si la requête n'a pas été envoyée.
