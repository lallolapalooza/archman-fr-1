XkbOutOfRangeGroupInfo(3) FONCTIONS XKB XkbOutOfRangeGroupInfo(3)

NOM

XkbOutOfRangeGroupInfo - Retourne uniquement les informations de traitement hors limites du champ group_info d'une structure XkbSymMapRec

SYNTAXE

unsigned char XkbOutOfRangeGroupInfo (unsigned char grp_inf);

ARGUMENTS

grp_inf
Description Xkb d'intérêt

DESCRIPTION

XkbOutOfRangeGroupInfo retourne uniquement les informations de traitement hors limites du champ group_info d'une structure XkbSymMapRec.

Le champ group_info d'une XkbSymMapRec est une valeur codée contenant le nombre de groupes de symboles associés à la touche ainsi que la spécification du traitement des groupes hors limites. Il est légal qu'une touche ait zéro groupe, auquel cas elle a également zéro symbole et tous les événements provenant de cette touche produisent NoSymbol. Pour obtenir le nombre de groupes de symboles associés à la touche, utilisez XkbKeyNumGroups. Pour modifier le nombre de groupes associés à une touche, utilisez XkbChangeTypesOfKey. Pour obtenir un masque qui détermine le traitement des groupes hors limites, utilisez XkbKeyGroupInfo et XkbOutOfRangeGroupInfo.

Les contrôles du clavier contiennent un champ groups_wrap spécifiant la gestion des groupes illégaux sur une base globale. C'est-à-dire que lorsque l'utilisateur effectue une action entraînant la sortie du groupe de clavier effectif de la plage légale, le champ groups_wrap spécifie comment normaliser le groupe de clavier effectif vers un groupe légal pour l'ensemble du clavier, mais il n'y a aucune garantie que le groupe normalisé sera dans la plage des groupes légaux pour une touche individuelle. Le champ group_info par touche spécifie comment une touche traite un groupe effectif légal si la touche n'a pas de type spécifié pour le groupe concerné. Par exemple, la touche Entrée n'a généralement qu'un seul groupe défini. Si l'utilisateur effectue une action entraînant le passage du groupe global du clavier au Groupe 2, le champ group_info pour la touche Entrée décrit comment gérer cette situation.

Les groupes hors limites pour les touches individuelles sont mappés vers un groupe légal en utilisant les mêmes options que celles utilisées pour le groupe global du clavier. Le type particulier de mappage utilisé est contrôlé par les bits définis dans le drapeau group_info, comme montré dans le Tableau 1.

Tableau 1 Normalisation des plages group_info
Bits définis dans group_info Méthode de normalisation
XkbRedirectIntoRange XkbRedirectIntoRange
XkbClampIntoRange XkbClampIntoRange
aucun des précédents XkbWrapIntoRange

STRUCTURES

La structure KeySymMapRec est définie comme suit :

    #define XkbNumKbdGroups             4
    #define XkbMaxKbdGroup              (XkbNumKbdGroups-1)
    typedef struct {                    /* map to keysyms for a single keycode */
        unsigned char       kt_index[XkbNumKbdGroups];  /* index du type de touche pour chaque groupe */
        unsigned char       group_info; /* # de groupes et gestion des groupes hors limites */
        unsigned char       width;      /* # max de niveaux de décalage pour la touche */
        unsigned short      offset;     /* index dans la table des touches dans le tableau syms */
} XkbSymMapRec, *XkbSymMapPtr;

XkbOutOfRangeGroupInfo(3)

NOM

XkbOutOfRangeGroupInfo - Obtient des informations sur un groupe de clavier hors limites.

SYNOPIS

#include <X11/Xlib.h>
#include <X11/extensions/XKBrules.h>

unsigned int XkbOutOfRangeGroupInfo (Display *dpy,
                                   int *error_code_return);

ARGUMENTS

dpy :
Connect to the X server.
error_code_return :
Pointes vers un entier pour stocker le code d'erreur.

DESCRIPTION

La fonction XkbOutOfRangeGroupInfo renvoie le numéro du groupe de clavier actuel s'il est hors limites. Si le groupe de clavier actuel est valide, la fonction renvoie 0. Dans tous les cas, si une erreur se produit, le code d'erreur est stocké dans error_code_return.

STRUCTURES

Aucune.

VOIR AUSSI

XkbGetGroupInfo
