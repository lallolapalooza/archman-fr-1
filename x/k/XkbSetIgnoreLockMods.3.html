XkbSetIgnoreLockMods(3) FONCTIONS XKB XkbSetIgnoreLockMods(3)

NOM

XkbSetIgnoreLockMods - Définit les modificateurs qui, s'ils sont verrouillés, ne doivent pas être signalés dans les événements correspondants aux saisies passives

SYNTAXE

Bool XkbSetIgnoreLockMods (Display *display, unsigned int device_spec, unsigned int affect_real, unsigned int real_values, unsigned int affect_virtual, unsigned int virtual_values);

ARGUMENTS

display
connexion au serveur X
device_spec
ID du périphérique, ou XkbUseCoreKbd
affect_real
masque des modificateurs réels affectés par cet appel
real_values
valeurs pour les modificateurs réels affectés (1=>défini, 0=>non défini)
affect_virtual
masque des modificateurs virtuels affectés par cet appel
virtual_values
valeurs pour les modificateurs virtuels affectés (1=>défini, 0=>non défini)

DESCRIPTION

Le protocole de base ne fournit pas de moyen d'exclure des modificateurs spécifiques des calculs de saisie, ce qui entraîne des effets secondaires imprévus des modificateurs de verrouillage.

Le contrôle IgnoreLockMods spécifie les modificateurs qui doivent être exclus des calculs de saisie. Ces modificateurs ne sont pas non plus signalés dans les événements de base, sauf les événements KeyPress et KeyRelease qui n'activent pas une saisie passive et qui ne se produisent pas pendant qu'une saisie est active.

Manipulez le contrôle IgnoreLockMods via le champ ignore_lock dans la structure XkbControlsRec, puis utilisez XkbSetControls et XkbGetControls pour interroger et modifier ce contrôle. Alternativement, utilisez XkbSetIgnoreLockMods.

XkbSetIgnoreLockMods envoie une requête au serveur pour modifier le contrôle IgnoreLockMods du serveur. affect_real et real_values sont des masques de bits de modificateurs réels indiquant quels modificateurs réels doivent être ajoutés et supprimés du contrôle IgnoreLockMods du serveur. Les modificateurs sélectionnés par affect_real et real_values sont ajoutés au contrôle IgnoreLockMods du serveur ; ceux sélectionnés par affect_real mais pas par real_values sont supprimés du contrôle IgnoreLockMods du serveur. Les valeurs valides pour affect_real et real_values consistent en toute combinaison des huit bits de modificateurs de base : ShiftMask, LockMask, ControlMask, Mod1Mask - Mod5Mask. affect_virtual et virtual_values sont des masques de bits de modificateurs virtuels indiquant quels modificateurs virtuels doivent être ajoutés et supprimés du contrôle IgnoreLockMods du serveur. Les modificateurs sélectionnés par affect_virtual et virtual_values sont ajoutés au contrôle IgnoreLockMods du serveur ; ceux sélectionnés par affect_virtual mais pas par virtual_values sont supprimés du contrôle IgnoreLockMods du serveur. Voir ci-dessous pour une discussion sur les masques de modificateurs virtuels à utiliser dans affect_virtual et virtual_values. XkbSetIgnoreLockMods n'attend pas de réponse du serveur. Il renvoie True si la requête a été envoyée, et False sinon.

Les modificateurs virtuels sont nommés en convertissant leur nom de chaîne en un atome X et en stockant l'atome dans le tableau names.vmods dans une structure XkbDescRec. La position d'un nom d'atome dans le tableau names.vmods définit la position du bit utilisée pour représenter le modificateur virtuel et également l'index utilisé lors de l'accès aux informations des modificateurs virtuels dans les tableaux : le nom dans l'entrée i-ième (relativement 0) de names.vmods est le i-ème modificateur virtuel, représenté par le masque (1<<i). Partout dans Xkb, diverses fonctions ont un paramètre qui est un masque représentant les choix de modificateurs virtuels. Dans chaque cas, le i-ème bit (relativement 0) du masque représente le i-ème modificateur virtuel.

Pour définir le nom d'un modificateur virtuel, utilisez XkbSetNames, en utilisant XkbVirtualModNamesMask dans which et le nom dans l'argument xkb ; pour récupérer les noms des indicateurs, utilisez XkbGetNames.

STRUCTURES

La description complète d'un clavier Xkb est donnée par une XkbDescRec. Les structures de composants dans la XkbDescRec représentent les principaux composants Xkb.

typedef struct {
    struct _XDisplay * display;      /* connexion au serveur X */
    unsigned short     flags;        /* privé à Xkb, ne pas modifier */
    unsigned short     device_spec;  /* périphérique d'intérêt */
    KeyCode            min_key_code; /* keycode minimum pour le périphérique */
    KeyCode            max_key_code; /* keycode maximum pour le périphérique */
    XkbControlsPtr     ctrls;        /* contrôles */
    XkbServerMapPtr    server;       /* table des correspondances du serveur */
    XkbClientMapPtr    map;          /* table des correspondances du client */
    XkbIndicatorPtr    indicators;   /* table des correspondances des indicateurs */
    XkbNamesPtr        names;        /* noms pour tous les composants */
    XkbCompatMapPtr    compat;       /* table des correspondances de compatibilité */
    XkbGeometryPtr     geom;         /* géométrie physique du clavier */
} XkbDescRec, *XkbDescPtr;

Le champ display pointe vers une structure d'affichage X. Le champ flags est privé à la bibliothèque : modifier flags peut donner des résultats imprévisibles. Le champ device_spec spécifie l'identifiant du périphérique d'entrée du clavier, ou XkbUseCoreKeyboard, qui spécifie le périphérique clavier principal. Les champs min_key_code et max_key_code spécifient le keycode le plus petit et le plus grand qui peuvent être retournés par le clavier.

Chaque composant structure a un bit de masque correspondant qui est utilisé dans les appels de fonction pour indiquer que la structure doit être manipulée d'une manière ou d'une autre, telle que son allocation ou sa libération. Ces masques et leurs relations avec les champs de la XkbDescRec sont montrés dans le Tableau 1.

Tableau 1 Bits de Masque pour XkbDescRec
Bit de Masque Champ XkbDescRec Valeur

XkbServerMapMask server (1L<<1)
