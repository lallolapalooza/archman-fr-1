XkbSetServerInternalMods(3) FONCTIONS XKB XkbSetServerInternalMods(3)

NOM

XkbSetServerInternalMods - Définit les modificateurs qui sont consommés par le serveur avant que les événements ne soient livrés au client

SYNTAXE

Bool XkbSetServerInternalMods (Display *display, unsigned int device_spec, unsigned int affect_real, unsigned int real_values, unsigned int affect_virtual, unsigned int virtual_values);

ARGUMENTS

display
connexion au serveur X
device_spec
spécification de périphérique, ou XkbUseCoreKbd
affect_real
masque des modificateurs réels affectés par cet appel
real_values
valeurs pour les modificateurs réels affectés (1=>défini, 0=>non défini)
affect_virtual
masque des modificateurs virtuels affectés par cet appel
virtual_values
valeurs pour les modificateurs virtuels affectés (1=>défini, 0=>non défini)

DESCRIPTION

Le protocole principal ne fournit aucun moyen d'empêcher qu'un modificateur ne soit signalé dans les événements envoyés aux clients ; Xkb, cependant, rend cela possible via le contrôle InternalMods. Il spécifie les modificateurs qui doivent être consommés par le serveur et non signalés aux clients. Lorsqu'une touche est enfoncée et qu'un modificateur dont le bit est activé dans InternalMods est signalé au serveur, le serveur utilise ce modificateur pour déterminer les actions à appliquer à la touche. Le serveur efface alors le bit, de sorte qu'il ne soit pas réellement signalé au client. De plus, les modificateurs spécifiés dans le contrôle InternalMods ne sont pas utilisés pour déterminer les "grabs" et ne sont pas utilisés pour calculer l'état de compatibilité du protocole principal.

Manipulez le contrôle InternalMods via le champ internal dans la structure XkbControlsRec, en utilisant XkbSetControls et XkbGetControls. Alternativement, utilisez XkbSetServerInternalMods.

XkbSetServerInternalMods envoie une requête au serveur pour modifier les modificateurs internes consommés par le serveur. affect_real et real_values sont des masques de bits de modificateurs réels indiquant quels modificateurs réels doivent être ajoutés et retirés du contrôle des modificateurs internes du serveur. Les modificateurs sélectionnés par affect_real et real_values sont ajoutés au contrôle des modificateurs internes du serveur ; ceux sélectionnés par affect_real mais pas par real_values sont retirés du masque des modificateurs internes du serveur. Les valeurs valides pour affect_real et real_values consistent en toute combinaison des huit bits de modificateurs principaux : ShiftMask, LockMask, ControlMask, Mod1Mask - Mod5Mask. affect_virtual et virtual_values sont des masques de bits de modificateurs virtuels indiquant quels modificateurs virtuels doivent être ajoutés et retirés du contrôle des modificateurs internes du serveur. Les modificateurs sélectionnés par affect_virtual et virtual_values sont ajoutés au contrôle des modificateurs internes du serveur ; ceux sélectionnés par affect_virtual mais pas par virtual_values sont retirés du contrôle des modificateurs internes du serveur. Voir ci-dessous pour une discussion sur les masques de modificateurs virtuels à utiliser dans affect_virtual et virtual_values. XkbSetServerInternalMods n'attend pas de réponse du serveur. Il renvoie True si la requête a été envoyée et False sinon.

Les modificateurs virtuels sont nommés en convertissant leur nom chaîne en un atome X et en stockant l'atome dans le tableau names.vmods d'une structure XkbDescRec. La position d'un nom d'atome dans le tableau names.vmods définit la position du bit utilisée pour représenter le modificateur virtuel et aussi l'index utilisé lors de l'accès aux informations de modificateurs virtuels dans les tableaux : le nom dans la i-ème entrée (relative à 0) de names.vmods est le i-ème modificateur virtuel, représenté par le masque (1<<i). Partout dans Xkb, diverses fonctions ont un paramètre qui est un masque représentant les choix de modificateurs virtuels. Dans chaque cas, le i-ème bit (relatif à 0) du masque représente le i-ème modificateur virtuel.

Pour définir le nom d'un modificateur virtuel, utilisez XkbSetNames, en utilisant XkbVirtualModNamesMask dans which et le nom dans l'argument xkb ; pour récupérer les noms des indicateurs, utilisez XkbGetNames.

STRUCTURES

La description complète d'un clavier Xkb est donnée par une XkbDescRec. Les structures composantes dans XkbDescRec représentent les composants majeurs de Xkb décrits dans la Figure 1.1.

typedef struct {
    struct _XDisplay * display;      /* connexion au serveur X */
    unsigned short     flags;        /* privé à Xkb, ne pas modifier */
    unsigned short     device_spec;  /* périphérique concerné */
    KeyCode            min_key_code; /* code de touche minimum pour le périphérique */
    KeyCode            max_key_code; /* code de touche maximum pour le périphérique */
    XkbControlsPtr     ctrls;        /* contrôles */
    XkbServerMapPtr    server;       /* table de correspondance serveur */
    XkbClientMapPtr    map;          /* table de correspondance client */
    XkbIndicatorPtr    indicators;   /* table de correspondance indicateurs */
    XkbNamesPtr        names;        /* noms pour tous les composants */
    XkbCompatMapPtr    compat;       /* table de correspondance compatibilité */
    XkbGeometryPtr     geom;         /* géométrie physique du clavier */
} XkbDescRec, *XkbDescPtr;

Le champ display pointe vers une structure d'affichage X. Le champ flags est privé à la bibliothèque : modifier les flags peut entraîner des résultats imprévisibles. Le champ device_spec spécifie l'identifiant du périphérique d'entrée du clavier, ou XkbUseCoreKeyboard, qui spécifie le périphérique de clavier principal. Les champs min_key_code et max_key_code spécifient le code de touche le plus bas et le plus élevé qui peut être retourné par le clavier.

Chaque composant structure a un bit de masque correspondant qui est utilisé dans les appels de fonction pour indiquer que la structure doit être manipulée d'une manière ou d'une autre, comme l'allocation ou la libération. Ces masques et leurs relations avec les champs de XkbDescRec sont montrés dans le Tableau 1.

Tableau 1 Bits de masque pour XkbDescRec
Bit de masque Champ XkbDescRec Valeur
XkbControlsMask ctrls (1L<<0)
XkbServerMapMask server (1L<<1)
XkbIClientMapMask map (1L<<2)
XkbIndicatorMapMask indicators (1L<<3)
XkbNamesMask names (1L<<4)
XkbCompatMapMask compat (1L<<5)
XkbGeometryMask geom (1L<<6)
XkbAllComponentsMask Tous les champs (0x7f)
