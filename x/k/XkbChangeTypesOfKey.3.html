XkbChangeTypesOfKey(3) FONCTIONS XKB XkbChangeTypesOfKey(3)

NOM

XkbChangeTypesOfKey - Changer le nombre de groupes et les types associés à une touche

SYNTAXE

Status XkbChangeTypesOfKey (XkbDescPtr xkb, int key, int n_groups, unsigned int groups, int *new_types_in, XkbMapChangesPtr p_changes);

ARGUMENTS

xkb
description du clavier à modifier
key
code de touche pour la touche concernée
n_groups
nouveau nombre de groupes pour la touche
groups
masque indiquant les groupes à modifier
new_types_in
indices pour les nouveaux types spécifiés dans groups
p_changes
note les changements apportés à xkb

DESCRIPTION

XkbChangeTypesOfKey réalloue les symboles et les actions associés à la touche, si nécessaire, et initialise tout nouveau symbole ou action à NoSymbol ou NoAction, selon le cas. Si le paramètre p_changes n'est pas NULL, XkbChangeTypesOfKey ajoute le XkbKeySymsMask au champ changes de p_changes et modifie les champs first_key_sym et num_key_syms de p_changes pour inclure la key qui a été modifiée. Voir STRUCTURE pour plus d'informations sur la structure XkbMapChangesPtr. En cas de succès, XkbChangeTypesOfKey renvoie Success.

Le paramètre n_groups spécifie le nouveau nombre de groupes pour la touche. Le paramètre groups est un masque spécifiant les groupes pour lesquels de nouveaux types sont fournis et est une opération OU exclusive bit à bit des masques suivants : XkbGroup1Mask, XkbGroup2Mask, XkbGroup3Mask, et XkbGroup4Mask.

Le paramètre new_types_in est un tableau d'entiers de longueur n_groups. Chaque entrée représente le type à utiliser pour le groupe associé et est un indice dans xkb->map->types. Le tableau new_types_in est indexé par l'indice du groupe ; si n_groups est quatre et que groups n'a que Group1Mask et Group3Mask définis, new_types_in ressemble à ceci :

    new_types_in[0] = type pour Group1
    new_types_in[1] = ignoré
    new_types_in[2] = type pour Group3
    new_types_in[3] = ignoré
Pour plus de commodité, Xkb fournit les constantes suivantes à utiliser comme indices pour les groupes :
Tableau 1 Constantes d'indice de groupe
Nom de la constante Valeur
XkbGroup1Index 0
XkbGroup2Index 1
XkbGroup3Index 2
XkbGroup4Index 3

Si l'extension Xkb n'a pas été correctement initialisée, XkbChangeTypesOfKey renvoie BadAccess. Si le paramètre xkb n'est pas valide (c'est-à-dire, s'il est NULL ou s'il ne contient pas de carte client valide), XkbChangeTypesOfKey renvoie BadMatch. Si la key n'est pas un code de touche valide, n_groups est supérieur à XkbNumKbdGroups, ou si le masque groups ne contient aucun des bits de masque de groupe valides, XkbChangeTypesOfKey renvoie BadValue. S'il est nécessaire de redimensionner les tableaux de symboles de touches ou d'actions de touches et que des erreurs d'allocation se produisent, XkbChangeTypesOfKey renvoie BadAlloc.

STRUCTURES

Utilisez la structure XkbMapChangesRec pour identifier et suivre les modifications partielles des composants de la carte et pour réduire la quantité de trafic entre le serveur et les clients.

typedef struct _XkbMapChanges {
    unsigned short   changed;            /* identifie les composants valides dans la structure */
    KeyCode          min_key_code;       /* code de touche le plus bas pour le périphérique */
    KeyCode          max_key_code;       /* code de touche le plus haut pour le périphérique */
    unsigned char    first_type;         /* indice du premier type de touche modifié */
    unsigned char    num_types;          /* # de types modifiés */
    KeyCode          first_key_sym;      /* première touche dont le key_sym_map a changé */
    unsigned char    num_key_syms;       /* # d'entrées key_sym_map modifiées */
    KeyCode          first_key_act;      /* première touche dont l'entrée key_acts a changé */
    unsigned char    num_key_acts;       /* # d'entrées key_acts modifiées */
    KeyCode          first_key_behavior; /* première touche dont les comportements ont changé */
    unsigned char    num_key_behaviors;  /* # d'entrées de comportements modifiées */
    KeyCode          first_key_explicit; /* première touche dont l'entrée explicite a changé */
    unsigned char    num_key_explicit;   /* # d'entrées explicites modifiées */
    KeyCode          first_modmap_key;   /* première touche dont l'entrée modmap a changé */
    unsigned char    num_modmap_keys;    /* # d'entrées modmap modifiées */
    KeyCode          first_vmodmap_key;  /* première touche dont le vmodmap a changé */
    unsigned char    num_vmodmap_keys;   /* # d'entrées vmodmap modifiées */
    unsigned char    pad1;               /* réservé */
    unsigned short   vmods;              /* masque indiquant quels vmods ont changé */
} XkbMapChangesRec,*XkbMapChangesPtr;

DIAGNOSTICS

BadAccess
L'extension Xkb n'a pas été correctement initialisée
BadAlloc
Impossible d'allouer du stockage
BadMatch
Une version compatible de Xkb n'était pas disponible dans le serveur ou un argument a le bon type et la bonne plage, mais est invalide par ailleurs
BadValue
Un argument est hors plage
