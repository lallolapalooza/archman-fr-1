XkbSetNamedDeviceIndicator(3)

Paquet: libx11

Licences: MIT AND X11

XkbSetNamedIndicator(3) FONCTIONS XKB XkbSetNamedIndicator(3)

NOM

XkbSetNamedIndicator - Nomme un indicateur s'il n'est pas déjà nommé ; bascule l'état de l'indicateur ; définit l'indicateur à un état spécifié et définit la carte de l'indicateur pour cet indicateur.

SYNTAXE

Bool XkbSetNamedDeviceIndicator (Display *dpy, unsigned int device_spec, unsigned int led_class, unsigned int led_id, Atom name, Bool change_state, Bool state, Bool create_new, XkbIndicatorMapPtr map); Bool XkbSetNamedIndicator (Display *dpy, Atom name, Bool change_state, Bool state, Bool create_new, XkbIndicatorMapPtr map);

ARGUMENTS

dpy
connexion au serveur X
device_spec
identifiant du périphérique, ou XkbUseCoreKbd
led_class
classe de retour, ou XkbDfltXIClass
led_id
identifiant de retour, ou XkbDfltXIId
name
nom de l'indicateur à modifier
change_state
indique s'il faut changer l'état de l'indicateur ou non
state
nouvel état souhaité pour l'indicateur
create_new
indique si un nouvel indicateur avec le nom spécifié doit être créé si nécessaire
map
nouvelle carte pour l'indicateur

DESCRIPTION

Si une version compatible de l'extension Xkb n'est pas disponible sur le serveur, XkbSetNamedDeviceIndicator retourne False. Sinon, il envoie une requête au serveur X pour modifier l'indicateur spécifié par name et retourne True.

Si change_state est True, XkbSetNamedDeviceIndicator demande au serveur de changer l'état de l'indicateur nommé à la valeur spécifiée par state. Si change_state est False, alors state n'est pas utilisé.

Si un indicateur portant le nom spécifié par name n'existe pas déjà, le paramètre create_new indique au serveur s'il doit créer un nouvel indicateur nommé. Si create_new est True, le serveur recherche le premier indicateur qui n'a pas de nom et lui attribue le nom spécifié par name. Si le paramètre optionnel, map, n'est pas NULL, XkbSetNamedDeviceIndicator demande au serveur de changer la carte de l'indicateur pour les valeurs spécifiées dans map.

De plus, il peut également générer des événements XkbIndicatorStateNotify, XkbIndicatorMapNotify et XkbNamesNotify.

XkbSetNamedIndicator est une fonction utilitaire qui appelle XkbSetNamedDeviceIndicator avec un device_spec de XkbUseCoreKbd, une led_class de XkbDfltXIClass et un led_id de XkbDfltXIId. Elle retourne la valeur de retour de XkbSetNamedDeviceIndicator.

VALEURS DE RETOUR

True
Les fonctions XkbSetNamedIndicator et XkbSetNamedDeviceIndicator retournent True si une version compatible de l'extension Xkb est disponible sur le serveur.
False
Les fonctions XkbSetNamedIndicator et XkbSetNamedDeviceIndicator retournent False si une version compatible de l'extension Xkb n'est pas disponible sur le serveur.

DIAGNOSTICS

BadAtom
Un nom n'est ni un Atom valide ni None.
BadImplementation
Réponse invalide du serveur.
BadKeyboard
device_spec ne spécifie pas un périphérique avec des indicateurs.
BadMatch
led_id n'est pas DfltXIId et ne spécifie pas un retour de la classe spécifiée par led_class sur le périphérique spécifié par device_spec.
BadValue
led_class ne spécifie pas DfltXIClass, LedFeedbackClass, ou KbdFeedbackClass.

VOIR AUSSI

XkbIndicatorMapNotify(3), XkbIndicatorStateNotify(3), XkbNamesNotify(3)
