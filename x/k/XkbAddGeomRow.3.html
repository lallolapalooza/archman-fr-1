XkbAddGeomRow(3) FONCTIONS XKB XkbAddGeomRow(3)

NOM

XkbAddGeomRow - Ajouter une ligne à une section

SYNTAXE

XkbRowPtr XkbAddGeomRow (XkbSectionPtr section, int sz_keys);

ARGUMENTS

section
section à mettre à jour
sz_keys
nombre de clés à réserver

DESCRIPTION

Xkb fournit des fonctions pour ajouter un seul nouvel élément à la géométrie de clavier de haut niveau. Dans chaque cas, les champs num_* de la structure correspondante sont incrémentés de 1. Ces fonctions ne changent pas sz_* à moins qu'il n'y ait plus de place dans le tableau. Certaines de ces fonctions remplissent les valeurs de la structure de l'élément à partir des arguments. Pour d'autres fonctions, vous devez explicitement écrire du code pour remplir les éléments de la structure.

La description géométrique de haut niveau inclut une liste de propriétés géométriques. Une propriété géométrique associe une chaîne arbitraire à un nom tout aussi arbitraire. Les programmes qui affichent des images de claviers peuvent utiliser les propriétés géométriques comme indices, mais elles ne sont pas interprétées par Xkb. Aucune autre structure géométrique ne fait référence aux propriétés géométriques.

L'un des composants d'une section géométrique de clavier est une ou plusieurs lignes de touches. XkbAddGeomRow ajoute une ligne à la section spécifiée. La nouvelle ligne créée contient de l'espace pour le nombre de touches spécifié dans sz_keys. Elles sont allouées et mises à zéro, mais sinon non initialisées. XkbAddGeomRow retourne NULL si l'un des paramètres est vide ou s'il n'a pas pu allouer d'espace pour la ligne. Pour allouer de l'espace pour un nombre arbitraire de lignes à une section, utilisez la fonction XkbAllocGeomRows.

STRUCTURES

typedef struct _XkbRow {
        short           top;
        short           left;
        unsigned short  num_keys;
        unsigned short  sz_keys;
        int             vertical;
        XkbKeyPtr       keys;
        XkbBoundsRec    bounds;
} XkbRowRec, *XkbRowPtr;
