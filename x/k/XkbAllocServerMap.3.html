XkbAllocServerMap(3) FONCTIONS XKB XkbAllocServerMap(3)

NOM

XkbAllocServerMap - Alloue et initialise un enregistrement de description de carte serveur vide

SYNTAXE

Status XkbAllocServerMap (XkbDescPtr xkb, unsigned int which, unsigned int count_acts);

ARGUMENTS

xkb
description du clavier dans laquelle allouer la carte serveur
which
masque sélectionnant les composants de la carte à allouer
count_acts
valeur du champ num_acts dans la carte à allouer

DESCRIPTION

XkbAllocServerMap alloue et initialise une carte serveur vide dans le champ server de la description du clavier spécifiée par xkb. Le paramètre which spécifie les composants particuliers de la structure de la carte serveur à allouer, comme spécifié dans le Tableau 1.

Tableau 1 Masques XkbAllocServerMap
Masque Effet
XkbExplicitComponentsMask Les champs min_key_code et max_key_code du paramètre xkb sont utilisés pour allouer le champ explicit de la carte serveur.
XkbKeyActionsMask Les champs min_key_code et max_key_code du paramètre xkb sont utilisés pour allouer le champ key_acts de la carte serveur. Le paramètre count_acts est utilisé pour allouer le champ acts de la carte serveur.
XkbKeyBehaviorsMask Les champs min_key_code et max_key_code du paramètre xkb sont utilisés pour allouer le champ behaviors de la carte serveur.
XkbVirtualModMapMask Les champs min_key_code et max_key_code du paramètre xkb sont utilisés pour allouer le champ vmodmap de la carte serveur.

Si la carte serveur de la description du clavier n'est pas NULL et que des champs sont déjà alloués dans la carte serveur, XkbAllocServerMap ne remplace pas les valeurs existantes. La seule exception concerne le tableau acts. Si le paramètre count_acts est supérieur au champ num_acts actuel de la carte serveur, XkbAllocServerMap redimensionne le tableau acts et réinitialise le champ num_acts en conséquence.

Si XkbAllocServerMap réussit, il retourne Success. Sinon, il peut retourner soit une erreur BadMatch, soit BadAlloc.

DIAGNOSTICS

BadAlloc
Impossible d'allouer de l'espace
BadMatch
Une version compatible de Xkb n'était pas disponible sur le serveur ou un argument a un type et une plage corrects, mais est par ailleurs invalide
BadValue
Un argument est hors plage

NOTES

Les champs min_key_code et max_key_code du paramètre xkb doivent être des valeurs légales. S'ils ne sont pas valides, XkbAllocServerMap retourne BadValue.
