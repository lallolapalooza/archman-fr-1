XkbAllocIndicatorMaps(3) FONCTIONS XKB XkbAllocIndicatorMaps(3)

NOM

XkbAllocIndicatorMaps - Alloue, directement, le membre indicators de l'enregistrement de description du clavier

SYNTAXE

Status XkbAllocIndicatorMaps (variable_type *xkb);

ARGUMENTS

xkb
structure de description du clavier

DESCRIPTION

Le paramètre xkb doit pointer vers une description de clavier valide. Si ce n'est pas le cas, XkbAllocIndicatorMaps renvoie une erreur BadMatch. Sinon, XkbAllocIndicatorMaps alloue et initialise le membre indicators de l'enregistrement de description du clavier et renvoie Success. Si XkbAllocIndicatorMaps n'a pas pu allouer l'enregistrement des indicateurs, il signale une erreur BadAlloc.

VALEURS DE RETOUR

Success
La fonction XkbAllocIndicatorMaps renvoie Success si elle réussit à allouer et initialiser le membre indicators de l'enregistrement de description du clavier.

DIAGNOSTICS

BadMatch
Une version compatible de Xkb n'était pas disponible sur le serveur ou un argument a le type et la plage corrects, mais est par ailleurs invalide.
BadAlloc
Impossible d'allouer de la mémoire.
