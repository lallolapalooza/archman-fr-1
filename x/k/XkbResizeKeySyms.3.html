XkbResizeKeySyms(3) FONCTIONS XKB XkbResizeKeySyms(3)

NOM

XkbResizeKeySyms - Modifie le nombre de symboles associés à une touche

SYNTAXE

KeySym * XkbResizeKeySyms (XkbDescRec *xkb, int key, int needed);

ARGUMENTS

xkb
description du clavier à modifier
key
code de touche pour la touche à modifier
needed
nouveau nombre de symboles requis pour la touche

DESCRIPTION

XkbResizeKeySyms réserve l'espace nécessaire pour needed symboles et renvoie un pointeur vers le début du nouveau tableau qui contient les symboles. Il ajuste le champ offset de l'entrée key_sym_map pour la touche si nécessaire et peut également modifier les champs syms, num_syms, et size_syms de xkb->map s'il est nécessaire de réallouer le tableau syms. XkbResizeKeySyms ne modifie ni la largeur ni le nombre de groupes associés à la touche.

Si needed est supérieur au nombre actuel de symboles pour la touche, XkbResizeKeySyms initialise tous les nouveaux symboles dans le tableau à NoSymbol.

Étant donné que le nombre de symboles nécessaires par une touche est normalement calculé comme largeur * nombre de groupes, et que XkbResizeKeySyms ne modifie ni la largeur ni le nombre de groupes pour la touche, une discrépance existe au retour de XkbResizeKeySyms entre l'espace alloué pour les symboles et le nombre requis. Les entrées inutilisées dans la liste des symboles renvoyée par XkbResizeKeySyms ne sont pas préservées lors des appels ultérieurs à l'une des fonctions d'édition de carte, vous devez donc mettre à jour le mappage des symboles de touche (qui met à jour la largeur et le nombre de groupes pour la touche) avant d'appeler une autre fonction d'allocation. Un appel à XkbChangeTypesOfKey mettra à jour le mappage.

Si des erreurs d'allocation se produisent lors du redimensionnement du nombre de symboles associés à la touche, XkbResizeKeySyms renvoie NULL.

VOIR AUSSI

XkbChangeTypesOfKey(3), XkbResizeKeyActions(3)

NOTES

Une modification du nombre de symboles associés à une touche doit être accompagnée d'une modification du nombre d'actions associées à une touche. Reportez-vous à XkbResizeKeyActions pour plus d'informations sur la modification du nombre d'actions associées à une touche.
