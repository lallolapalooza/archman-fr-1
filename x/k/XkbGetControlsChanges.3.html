XkbGetControlsChanges(3)

Paquet: libx11

Licences: MIT AND X11

XkbGetControlsChanges(3) FONCTIONS XKB XkbGetControlsChanges(3)

NOM

XkbGetControlsChanges - Met à jour une copie locale d'une description de clavier avec les changements précédemment notés par un ou plusieurs appels à XkbNoteControlsChanges

SYNTAXE

XkbGetControlsChanges (Display *dpy, XkbDescPtr xkb, XkbNameChangesPtr changes);

ARGUMENTS

dpy
connexion au serveur X
xkb
xkb->ctrls sera mis à jour
changes
indique quelles parties de xkb->ctrls doivent être mises à jour

DESCRIPTION

Chaque fois qu'un champ dans la structure des contrôles change dans la description du clavier du serveur, le serveur envoie un événement XkbControlsNotify à tous les clients intéressés. Pour recevoir des événements XkbControlsNotify dans toutes les conditions possibles, utilisez XkbSelectEvents et passez XkbControlsNotifyMask dans bits_to_change et values_for_bits.

Pour recevoir des événements XkbControlsNotify uniquement dans certaines conditions, utilisez XkbSelectEventDetails en utilisant XkbControlsNotify comme event_type et en spécifiant les changements d'état souhaités dans bits_to_change et values_for_bits en utilisant les bits de masque du Tableau 1.

Le Tableau 1 montre les valeurs réelles pour les bits de masque individuels utilisés pour sélectionner les contrôles à modifier et pour activer et désactiver le contrôle. Notez que le même bit de masque est utilisé pour spécifier les modifications générales apportées aux paramètres utilisés pour configurer le contrôle (which), et pour activer et désactiver le contrôle (enabled_ctrls). Les anomalies dans le tableau (pas de "ok" dans la colonne) concernent les contrôles qui n'ont pas d'attributs configurables ; et pour les contrôles qui ne sont pas des contrôles booléens et ne peuvent donc pas être activés ou désactivés.

Le champ changed_ctrls spécifie les composants des contrôles qui ont changé et se compose de bits tirés des masques définis dans le Tableau 10.7 avec "ok" dans la colonne changed_ctrls.

Les contrôles actuellement activés dans le serveur sont rapportés dans le champ enabled_ctrls. Si des contrôles viennent d'être activés ou désactivés (c'est-à-dire que le contenu du champ enabled_ctrls a changé), ils sont marqués dans le champ enabled_ctrl_changes. Les bits valides pour ces champs sont les masques listés dans le Tableau 10.7 avec "ok" dans la colonne enabled_ctrls. Le champ num_groups rapporte le nombre de groupes liés à la touche appartenant au plus grand nombre de groupes et est automatiquement mis à jour lorsque le mappage du clavier change.

Si le changement a été causé par une requête d'un client, les champs keycode et event_type sont mis à zéro et les champs req_major et req_minor identifient la requête. La valeur req_major est la même que l'opcode d'extension principal. Sinon, event_type est réglé sur le type d'événement qui a causé le changement (l'un de KeyPress, KeyRelease, DeviceKeyPress, DeviceKeyRelease, ButtonPress ou ButtonRelease), et req_major et req_minor sont indéfinis. Si event_type est KeyPress, KeyRelease, DeviceKeyPress, ou DeviceKeyRelease, le champ keycode est réglé sur la touche qui a causé le changement. Si event_type est ButtonPress ou ButtonRelease, keycode contient le numéro du bouton.

Lorsqu'un client reçoit un événement XkbControlsNotify, il peut noter les changements dans une structure de changements à l'aide de XkbNoteControlsChanges.

XkbGetControlsChanges examine le paramètre changes, interroge le serveur pour les informations nécessaires et copie les résultats dans la description du clavier xkb->ctrls. Si le champ ctrls de xkb est NULL, XkbGetControlsChanges l'alloue et l'initialise. Pour libérer le champ ctrls, utilisez XkbFreeControls.

XkbGetControlsChanges retourne Success en cas de succès et peut générer des erreurs BadAlloc, BadImplementation et BadMatch.

VALEUR DE RETOUR

Success
La fonction XkbGetControlsChanges retourne Success si la requête au serveur a réussi.

STRUCTURES

La structure pour l'événement XkbControlsNotify est définie comme suit :
typedef struct {
    int           type;          /* code d'événement de base de l'extension Xkb */
    unsigned long serial;        /* numéro de série du serveur X pour l'événement */
    Bool          send_event;    /* True => généré synthétiquement */
    Display *     display;       /* connexion au serveur où l'événement a été généré */
    Time          time;          /* heure du serveur à laquelle l'événement a été généré */
    int           xkb_type;      /* XkbCompatMapNotify */
    int           device;        /* ID de périphérique Xkb, ne sera pas XkbUseCoreKbd */
    unsigned int  changed_ctrls; /* bits indiquant quelles données de contrôles ont changé */
    unsigned int  enabled_ctrls; /* contrôles actuellement activés sur le serveur */
    unsigned int  enabled_ctrl_changes; /* bits indiquant les contrôles activés/désactivés */
    int           num_groups;    /* nombre actuel de groupes de clavier */
    KeyCode       keycode;       /* != 0 => code de la touche à l'origine du changement */
    char          event_type;    /* Type d'événement à l'origine du changement */
    char          req_major;     /* code d'événement principal à l'origine du changement */
    char          req_minor;     /* code d'événement secondaire à l'origine du changement */
} XkbControlsNotifyEvent;
