XkbResizeKeyType(3)

Paquet: libx11

Licences: MIT AND X11

XkbResizeKeyType(3) FONCTIONS XKB XkbResizeKeyType(3)

NOM

XkbResizeKeyType - Changer le nombre de niveaux dans un type de touche

SYNTAXE

Status XkbResizeKeyType (XkbDescPtr xkb, int type_ndx, int map_count, Bool want_preserve, int new_num_lvls);

ARGUMENTS

xkb
description du clavier contenant la carte client à mettre à jour
type_ndx
index dans xkb->map->types du type à modifier
map_count
nombre total d'entrées de carte nécessaires pour le type
want_preserve
Vrai => la liste des modificateurs préservés est nécessaire
new_num_lvls
nouveau nombre max de niveaux pour le type

DESCRIPTION

XkbResizeKeyType modifie le type spécifié par xkb->map->types[type_ndx], et réalloue les symboles et les actions associés à toutes les touches qui utilisent ce type, si nécessaire. XkbResizeKeyType ne met à jour que la copie locale des types dans xkb ; pour mettre à jour la copie du serveur pour le périphérique physique, utilisez XkbSetMap ou XkbChangeMap après avoir appelé XkbResizeKeyType.

Le paramètre map_count spécifie le nombre total d'entrées de carte nécessaires pour le type, et peut être zéro ou plus. Si map_count est zéro, XkbResizeKeyType libère les entrées map et preserve existantes pour le type si elles existent et les met à NULL.

Le paramètre want_preserve spécifie si une liste preserve pour la touche doit être créée. Si want_preserve est Vrai, la liste preserve avec map_count entrées est allouée ou réallouée si elle existe déjà. Sinon, si want_preserve est Faux, le champ preserve est libéré si nécessaire et mis à NULL.

Le paramètre new_num_lvls spécifie le nouveau nombre maximum de niveaux de décalage pour le type et est utilisé pour calculer et redimensionner les symboles et les actions associés à toutes les touches qui utilisent ce type.

Si type_ndx ne spécifie pas un type valide, new_num_lvls est inférieur à 1, ou map_count est inférieur à zéro, XkbResizeKeyType renvoie BadValue. Si XkbResizeKeyType rencontre des problèmes d'allocation, il renvoie BadAlloc. Sinon, il renvoie Success.

VALEURS DE RETOUR

Success
La fonction XkbResizeKeyType renvoie Success si type_ndx spécifie un type valide, new_num_lvls est supérieur à zéro et map_count est positif.

DIAGNOSTICS

BadAlloc
Impossible d'allouer de l'espace
BadValue
Un argument est hors limites

VOIR AUSSI

XkbChangeMap(3), XkbSetMap(3)
