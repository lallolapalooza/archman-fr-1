XkbAllocGeomOutlines(3) FONCTIONS XKB XkbAllocGeomOutlines(3)

NOM

XkbAllocGeomOutlines - Alloue de l'espace pour un nombre arbitraire de contours d'une forme

SYNTAXE

Status XkbAllocGeomOutlines (XkbShapePtr shape, int num_needed);

ARGUMENTS

shape
forme pour laquelle les contours doivent être alloués
num_needed
nombre de nouveaux contours requis

DESCRIPTION

Xkb fournit un certain nombre de fonctions pour allouer et libérer des sous-composants d'une géométrie de clavier. Utilisez ces fonctions pour créer ou modifier des géométries de clavier. Notez que ces fonctions allouent simplement de l'espace pour le(s) nouvel(aux) élément(s), et il vous appartient de remplir les valeurs explicitement dans votre code. Ces fonctions d'allocation augmentent sz_* mais ne touchent jamais num_* (sauf en cas d'échec d'allocation, auquel cas elles réinitialisent sz_* et num_* à zéro). Ces fonctions renvoient Success si elles réussissent, BadAlloc si elles ne parviennent pas à allouer d'espace, ou BadValue si un paramètre n'est pas conforme aux attentes.

XkbAllocGeomOutlines alloue de l'espace pour num_needed contours dans la shape spécifiée. Les contours ne sont pas initialisés.

Pour libérer les contours de géométrie, utilisez XkbFreeGeomOutlines.

DIAGNOSTICS

BadAlloc
Impossible d'allouer du stockage
BadValue
Un argument est hors limites

VOIR AUSSI

XkbFreeGeomOutlines(3)
