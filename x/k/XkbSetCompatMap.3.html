XkbSetCompatMap(3)

Paquet: libx11

Licences: MIT AND X11

XkbSetCompatMap(3) FONCTIONS XKB XkbSetCompatMap(3)

NOM

XkbSetCompatMap - Modifier la carte de compatibilité du serveur

SYNTAXE

Bool XkbSetCompatMap (Display *display, unsigned int which, XkbDescPtr xkb, Bool update_actions);

ARGUMENTS

display
connexion au serveur
which
masque des composants de la carte de compatibilité à définir
xkb
source pour les composants de la carte de compatibilité
update_actions
True => appliquer à la carte du clavier du serveur

DESCRIPTION

Pour modifier la carte de compatibilité du serveur, modifiez d'abord une copie locale de la carte de compatibilité Xkb, puis appelez XkbSetCompatMap. Vous pouvez allouer une nouvelle carte de compatibilité à cette fin en utilisant XkbAllocCompatMap. Vous pouvez également utiliser une carte de compatibilité d'un autre serveur, bien que vous deviez ajuster le champ device_spec dans la structure XkbDescRec en conséquence. Notez que les interprétations de symboles dans une carte de compatibilité ( sym_interpret, le vecteur de structures XkbSymInterpretRec) sont également allouées en utilisant cette même fonction. XkbSetCompatMap copie les informations de la carte de compatibilité depuis la description du clavier dans xkb vers le serveur spécifié dans la carte de compatibilité de display pour le périphérique spécifié par le champ device_spec de xkb. Sauf si vous avez spécifiquement modifié ce champ, il s'agit du périphérique de clavier par défaut. which spécifie les composants de la carte de compatibilité à définir, et est une combinaison OR inclusive des bits indiqués dans le Tableau 1.

Tableau 1 Masques de composants de la carte de compatibilité
Masque Valeur Affectation
XkbSymInterpMask (1<<0) Interprétations de symboles
XkbGroupCompatMask (1<<1) Cartes de groupes
XkbAllCompatMask (0x3) Tous les composants de la carte de compatibilité

Après avoir mis à jour sa carte de compatibilité pour le périphérique spécifié, si update_actions est True, le serveur applique la nouvelle carte de compatibilité à l'ensemble de son clavier pour le périphérique afin de générer un nouvel ensemble de sémantiques de touches, d'état de compatibilité et une nouvelle carte de clavier principale. Si update_actions est False, la nouvelle carte de compatibilité n'est pas utilisée pour générer des modifications aux sémantiques, à l'état ou à la carte de clavier principale actuels. Une raison de ne pas appliquer la carte de compatibilité immédiatement pourrait être si un serveur était configuré pour correspondre à un autre de manière fragmentaire ; la carte ne devrait pas être appliquée tant que tout n'est pas mis à jour. Pour forcer une mise à jour ultérieure, utilisez XkbSetCompatMap en spécifiant which comme zéro et update_actions comme True. XkbSetCompatMap renvoie True en cas de succès et False en cas d'échec. Le serveur peut signaler ultérieurement les problèmes rencontrés lors du traitement de la requête via des erreurs de protocole.

VALEURS DE RETOUR

True
La fonction XkbSetCompatMap renvoie True en cas de succès.
False
La fonction XkbSetCompatMap renvoie False en cas d'échec.

STRUCTURES

La description complète d'un clavier Xkb est donnée par une XkbDescRec. Les structures de composants dans la XkbDescRec représentent les composants majeurs de Xkb.

typedef struct {
   struct _XDisplay  *display;      /* connexion au serveur X */
   unsigned short     flags;        /* privé à Xkb, ne pas modifier */
   unsigned short     device_spec;  /* périphérique d'intérêt */
   KeyCode            min_key_code; /* keycode minimum pour le périphérique */
   KeyCode            max_key_code; /* keycode maximum pour le périphérique */
   XkbControlsPtr     ctrls;        /* contrôles */
   XkbServerMapPtr    server;       /* carte du clavier du serveur */
   XkbClientMapPtr    map;          /* carte du clavier du client */
   XkbIndicatorPtr    indicators;   /* carte des indicateurs */
   XkbNamesPtr        names;        /* noms pour tous les composants */
   XkbCompatMapPtr    compat;       /* carte de compatibilité */
   XkbGeometryPtr     geom;         /* géométrie physique du clavier */
} XkbDescRec, *XkbDescPtr;

Le champ display pointe vers une structure d'affichage X. Le champ flags est privé à la bibliothèque : modifier flags peut conduire à des résultats imprévisibles. Le champ device_spec spécifie l'identificateur de périphérique du périphérique d'entrée clavier, ou XkbUseCoreKeyboard, qui spécifie le périphérique clavier principal. Les champs min_key_code et max_key_code spécifient le keycode le plus bas et le plus élevé pouvant être retournés par le clavier.

Chaque composant de structure a un bit de masque correspondant qui est utilisé dans les appels de fonction pour indiquer que la structure doit être manipulée d'une manière ou d'une autre, comme l'allouer ou la libérer. Ces masques et leurs relations avec les champs de la XkbDescRec sont montrés dans le Tableau 2.

Tableau 2 Bits de masque pour XkbDescRec
Bit de masque Champ XkbDescRec Valeur
XkbControlsMask ctrls (1L<<0)
XkbServerMapMask server (1L<<1)
XkbIClientMapMask map (1L<<2)
XkbIndicatorMapMask indicators (1L<<3)
XkbNamesMask names (1L<<4)
XkbCompatMapMask compat (1L<<5)
XkbGeometryMask geom (1L<<6)
XkbAllComponentsMask Tous les champs (0x7f)

La structure XkbSymInterpretRec spécifie une interprétation de symbole :

    typedef struct {
        KeySym        sym;         /* keysym d'intérêt ou NULL */
        unsigned char flags;       /* XkbSI_AutoRepeat, XkbSI_LockingKey */
        unsigned char match;       /* spécifie comment mods est interprété */
        unsigned char mods;        /* bits de modificateur, correspondent à huit vrais modificateurs */
        unsigned char virtual_mod; /* 1 modificateur à ajouter à la carte des modificateurs virtuels de la touche */
        XkbAnyAction  act;         /* action à lier à la position du symbole sur la touche */
    } XkbSymInterpretRec,*XkbSymInterpretPtr;
