XkbSetDebuggingFlags(3) FONCTIONS XKB XkbSetDebuggingFlags(3)

NOM

XkbSetDebuggingFlags - Modifier les valeurs des contrôles de débogage

SYNTAXE

Bool XkbSetDebuggingFlags (Display *display, unsigned int mask, unsigned int flags, char *msg, unsigned int ctrls_mask, unsigned int ctrls, unsigned int *ret_flags, unsigned int *ret_ctrls);

ARGUMENTS

display
connexion au serveur X
mask
masque sélectionnant les indicateurs de sortie de débogage à modifier
flags
valeurs pour les indicateurs de sortie de débogage sélectionnés par le masque
msg
message à afficher immédiatement
ctrls_mask
masque sélectionnant les contrôles de débogage à modifier
ctrls
valeurs pour les contrôles de débogage sélectionnés par ctrls_mask
ret_flags
état résultant de tous les indicateurs de sortie de débogage
ret_ctrls
état résultant de tous les contrôles de débogage

DESCRIPTION

Les outils de débogage sont destinés principalement aux implémenteurs de Xkb et sont optionnels dans toute implémentation.

Il existe deux masques de bits qui peuvent être utilisés pour contrôler le débogage. Un masque de bits contrôle la sortie des informations de débogage, et l'autre contrôle le comportement. Ces deux masques de bits sont initialement tous à zéro.

Pour modifier les valeurs de l'un des contrôles de débogage, utilisez XkbSetDebuggingFlags.

XkbSetDebuggingFlags modifie les indicateurs de sortie de débogage tels que spécifiés par mask et flags, modifie les indicateurs de contrôle de débogage tels que spécifiés par ctrls_mask et ctrls, affiche le message msg, et remplit ret_flags et ret_ctrls avec les indicateurs de sortie de débogage et les indicateurs de contrôle de débogage résultants.

Lorsque des bits sont définis dans les masques de sortie de débogage, mask et flags, Xkb affiche des informations de débogage correspondant à chaque bit aux points appropriés de son traitement. Le périphérique auquel la sortie est écrite dépend de l'implémentation, mais est normalement le même périphérique auquel les messages d'erreur du serveur X sont dirigés ; par conséquent, les bits qui peuvent être définis dans mask et flags sont spécifiques à l'implémentation. Pour activer une sélection de sortie de débogage, définissez le bit pour la sortie dans le paramètre mask et définissez le bit correspondant dans le paramètre flags. Pour désactiver la sélection d'événements pour un événement, définissez le bit pour la sortie dans le paramètre mask et ne définissez pas le bit correspondant dans le paramètre flags.

Lorsque des bits sont définis dans les masques de contrôle de débogage, ctrls_mask et ctrls, Xkb modifie son comportement en fonction de chaque bit de contrôle. ctrls_mask et ctrls sont liés de la même manière que mask et flags. Les bits de contrôle valides sont définis dans le Tableau 1.

Tableau 1 Masques de contrôle de débogage
Masque de contrôle de débogage Valeur Signification
XkbDF_DisableLocks (1 << 0) Désactiver les actions qui verrouillent les modificateurs

XkbSetDebuggingFlags renvoie True en cas de succès et False sinon. La seule erreur de protocole qu'elle peut générer est BadAlloc, si pour une raison quelconque elle ne parvient pas à allouer de stockage.

XkbSetDebuggingFlags est destiné à l'utilisation par les développeurs et peut être désactivé dans les serveurs X de production. S'il est désactivé, XkbSetDebuggingFlags n'a aucun effet et ne génère aucune erreur de protocole.

Le message dans msg est écrit immédiatement. Le périphérique auquel il est écrit dépend de l'implémentation, mais est normalement le même périphérique où les messages d'erreur du serveur X sont dirigés.

VALEURS DE RETOUR

True
La fonction XkbSetDebuggingFlags renvoie True en cas de succès.
False
La fonction XkbSetDebuggingFlags renvoie False en cas d'échec.

DIAGNOSTICS

BadAlloc
Impossible d'allouer du stockage
