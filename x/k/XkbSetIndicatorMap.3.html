Paquet: libx11

XkbSetIndicatorMap(3) FONCTIONS XKB XkbSetIndicatorMap(3)

NOM

XkbSetIndicatorMap - Télécharge les modifications sur le serveur basées sur les modifications d'une copie locale de la description du clavier qui mettra à jour les mappings d'un ou plusieurs indicateurs.

SYNTAXE

Bool XkbSetIndicatorMap (Display *dpy, unsigned int which, XkbDescPtr desc);

ARGUMENTS

dpy
connexion au serveur X
which
masque des indicateurs à modifier
desc
description du clavier à partir de laquelle les mappings sont pris

DESCRIPTION

Cette section discute des effets de la modification explicite des indicateurs en fonction des différents réglages de la carte d'indicateur. Voir Tableau 1 et Tableau 2 pour des informations sur les effets des champs de la carte d'indicateur lors de modifications explicites.

Tableau 1 XkbIndicatorMapRec which_groups et groups,
Indicateur pilote le clavier

XkbIM_UseNone Activé ou Désactivé Aucun effet
XkbIM_UseBase Activé ou Désactivé Aucun effet
XkbIM_UseLatched Activé Le champ groups est traité comme un masque de groupe. Le verrouillage du groupe du clavier est modifié pour le groupe le plus bas numéroté spécifié dans groups ; si groups est vide, le verrouillage du groupe du clavier est modifié à zéro.
XkbIM_UseLatched Désactivé Le champ groups est traité comme un masque de groupe. Si l'indicateur est explicitement éteint, le verrouillage du groupe du clavier est modifié au groupe le plus bas numéroté non spécifié dans groups ; si groups est zéro, le verrouillage du groupe du clavier est défini sur l'index du groupe de clavier légal le plus élevé.
XkbIM_UseLocked ou
XkbIM_UseEffective Activé Si le masque de groupes est vide, le groupe n'est pas modifié ; sinon, le groupe de clavier verrouillé est modifié au groupe le plus bas numéroté spécifié dans groups.
XkbIM_UseLocked ou
XkbIM_UseEffective Désactivé Le groupe de clavier verrouillé est modifié au groupe le plus bas numéroté non spécifié dans le masque de groupes, ou à Group1 si le masque de groupes contient tous les groupes du clavier.

Si XkbIM_LEDDrivesKB est défini et XkbIM_NoExplicit ne l'est pas, et si vous appelez une fonction qui met à jour l'image du serveur de la carte d'indicateur (telle que XkbSetIndicatorMap ou XkbSetNamedIndicator), Xkb modifie l'état et les contrôles du clavier pour refléter les autres champs de la carte d'indicateur. Si vous tentez de modifier explicitement la valeur d'un indicateur pour lequel XkbIM_LEDDrivesKB est absent ou pour lequel XkbIM_NoExplicit est présent, l'état ou les contrôles du clavier ne sont pas affectés.

Si ni XkbIM_NoAutomatic ni XkbIM_NoExplicit n'est défini dans une carte d'indicateur, Xkb honore toute demande de modification de l'état de l'indicateur, mais le nouvel état peut être immédiatement remplacé par des changements automatiques de l'état de l'indicateur si l'état ou les contrôles du clavier changent.

Les effets de la modification d'un indicateur qui pilote le clavier sont cumulatifs ; il est possible qu'une seule modification affecte le groupe du clavier, les modificateurs et les contrôles simultanément.

Si vous modifiez un indicateur pour lequel les drapeaux XkbIM_LEDDrivesKB et XkbIM_NoAutomatic sont tous deux spécifiés, Xkb applique les modifications du clavier spécifiées dans les autres champs de la carte d'indicateur et modifie l'indicateur pour refléter l'état qui a été explicitement demandé. L'indicateur reste dans le nouvel état jusqu'à ce qu'il soit à nouveau modifié explicitement.

Si le drapeau XkbIM_NoAutomatic n'est pas défini et XkbIM_LEDDrivesKB est défini, Xkb applique les modifications spécifiées dans les autres champs de la carte d'indicateur et définit l'état de l'indicateur aux valeurs spécifiées par la carte d'indicateur. Notez qu'il est possible dans ce cas que l'indicateur finisse dans un état différent de celui qui a été explicitement demandé. Par exemple, Xkb n'éteint pas un indicateur avec which_mods de XkbIM_UseBase et mods de Shift si, au moment où Xkb traite la demande d'extinction de l'indicateur, l'une des touches Shift est physiquement enfoncée.

Si vous allumez explicitement un indicateur pour lequel XkbIM_LEDDrivesKB est défini, Xkb active tous les contrôles booléens spécifiés dans le champ ctrls de sa carte d'indicateur. Éteindre explicitement un tel indicateur amène Xkb à désactiver tous les contrôles booléens spécifiés dans ctrls.

Pour chaque bit défini dans le paramètre which, XkbSetIndicatorMap envoie la carte d'indicateur correspondante du paramètre desc au serveur.
