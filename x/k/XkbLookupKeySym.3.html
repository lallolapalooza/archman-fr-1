NOM

XkbLookupKeySym - Trouver le symbole associé à une touche pour un état particulier

SYNTAXE

Bool XkbLookupKeySym (Display *dpy, KeyCode key, unsigned int state, unsigned int *mods_rtrn, KeySym *sym_rtrn);

ARGUMENTS

dpy
connexion au serveur X
key
touche dont les symboles doivent être trouvés
state
état pour lequel le symbole doit être trouvé
mods_rtrn
rempli avec les modificateurs consommés
sym_rtrn
rempli avec le symbole associé à la touche + état

DESCRIPTION

XkbLookupKeySym est l'équivalent de la fonction principale XLookupKeySym. Pour le clavier principal, étant donné un code de touche key et un état Xkb state, XkbLookupKeySym renvoie le symbole associé à la touche dans sym_rtrn et la liste des modificateurs qui devraient toujours être appliqués dans mods_rtrn. Le paramètre state est l'état d'un événement KeyPress ou KeyRelease. XkbLookupKeySym renvoie True si elle réussit.
