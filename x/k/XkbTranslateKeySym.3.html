XkbTranslateKeySym(3) FONCTIONS XKB XkbTranslateKeySym(3)

NOM

XkbTranslateKeySym - Trouver la chaîne et le symbole associés à un keysym pour un état de clavier donné

SYNTAXE

int XkbTranslateKeySym (Display *dpy, KeySym *sym_inout, unsigned int mods, char *buf, int nbytes, int *extra_rtrn);

ARGUMENTS

dpy
connexion au serveur X
sym_inout
symbole à traduire ; résultat de la traduction
mods
modificateurs à appliquer à sym_inout
buf
tampon dans lequel la chaîne retournée est écrite
nbytes
taille du tampon en octets
extra_rtrn
nombre d'octets en débordement

DESCRIPTION

XkbTranslateKeySym applique les transformations spécifiées dans mods au symbole spécifié par sym_inout. Il retourne dans buf la chaîne, le cas échéant, associée au keysym pour la locale courante. Si les transformations dans mods changent le keysym, sym_inout est mis à jour en conséquence. Si la chaîne retournée est plus grande que nbytes, un nombre d'octets qui ne rentre pas dans le tampon est retourné dans extra_rtrn. XkbTranslateKeySym retourne le nombre d'octets qu'il a placés dans buf.

VALEUR DE RETOUR

buf
Retourne la chaîne, le cas échéant, associée au keysym pour la locale courante.
