XkbSetDeviceInfo(3) FONCTIONS XKB XkbSetDeviceInfo(3)

NOM

XkbSetDeviceInfo - Modifier certaines ou toutes les caractéristiques d'un périphérique d'extension d'entrée X

SYNTAXE

Bool XkbSetDeviceInfo (Display *dpy, unsigned int which, XkbDeviceInfoPtr device_info);

ARGUMENTS

dpy
connexion au serveur X
which
masque indiquant les caractéristiques à modifier
device_info
structure définissant le périphérique et les modifications

DESCRIPTION

Pour modifier les caractéristiques d'un périphérique d'extension d'entrée X dans le serveur, modifiez d'abord une copie locale de la structure du périphérique, puis utilisez soit XkbSetDeviceInfo, soit, pour économiser le trafic réseau, utilisez une structure XkbDeviceChangesRec et appelez XkbChangeDeviceInfo pour télécharger les modifications vers le serveur.

XkbSetDeviceInfo envoie une requête au serveur pour modifier les caractéristiques du périphérique spécifié dans la structure device_info. Les caractéristiques particulières modifiées sont identifiées par les bits définis dans which et prennent leurs valeurs à partir des champs pertinents dans device_info (voir Tableau 1). XkbSetDeviceInfo retourne True si la requête a été envoyée avec succès au serveur. Si l'implémentation du serveur X ne permet pas l'interaction entre l'extension d'entrée X et l'extension Xkb, la fonction ne fait rien et retourne False.

Le paramètre which spécifie quels aspects du périphérique doivent être modifiés et est un masque de bits composé d'une OU inclusive d'un ou plusieurs des bits suivants : XkbXI_ButtonActionsMask, XkbXI_IndicatorNamesMask, XkbXI_IndicatorMapsMask. Si les fonctionnalités demandées pour être manipulées dans which sont valides pour le périphérique, mais que le serveur ne permet pas l'assignation d'une ou plusieurs d'entre elles, cette partie particulière de la requête est ignorée.

Si le périphérique spécifié dans device_info->device_spec ne contient pas de boutons et qu'une requête affectant les boutons est faite, ou si le périphérique ne contient pas d'indicateurs et qu'une requête affectant les indicateurs est faite, une erreur de protocole BadMatch en résulte.

Si le bit XkbXI_ButtonActionsMask est défini dans le masque supported renvoyé par XkbGetDeviceInfo, l'extension Xkb permet aux applications d'assigner des actions de touche aux boutons des périphériques d'entrée autres que le périphérique clavier principal. Si XkbXI_ButtonActionsMask est défini dans which, les actions pour tous les boutons spécifiés dans device_info sont définies sur les XkbActions spécifiées dans device_info->btn_acts. Si le nombre de boutons dont la mise à jour est demandée n'est pas valide pour le périphérique, XkbSetDeviceInfo retourne False et une erreur de protocole BadValue en résulte.

Si le bit XkbXI_IndicatorMaps et/ou XkbXI_IndicatorNamesMask est défini dans le masque supported renvoyé par XkbGetDeviceInfo, l'extension Xkb permet aux applications d'assigner des cartes et/ou des noms aux indicateurs des périphériques d'extension autres que clavier. Si supporté, des cartes et/ou des noms peuvent être assignés à tous les indicateurs des périphériques d'extension, qu'ils fassent partie d'un retour de clavier ou d'un retour d'indicateur.

Si le drapeau XkbXI_IndicatorMapsMask et/ou XkbXI_IndicatorNamesMask est défini dans which, les cartes et/ou noms d'indicateurs pour tous les device_info->num_leds périphériques indicateurs spécifiés dans device_info->leds sont définis sur les cartes et/ou noms spécifiés dans device_info->leds. device_info->leds->led_class et led_id spécifient la classe d'extension d'entrée et l'ID du périphérique pour chaque périphérique indicateur à modifier ; s'ils ont des valeurs invalides, une erreur de protocole BadValue en résulte et XkbSetDeviceInfo retourne False. S'ils ont des valeurs légales mais ne spécifient pas un retour clavier ou indicateur pour le périphérique concerné, une erreur BadMatch en résulte. Si l'une des valeurs dans device_info->leds->names n'est pas un Atom valide ou None, une erreur de protocole BadAtom en résulte.

VALEURS DE RETOUR

True
La fonction XkbSetDeviceInfo retourne True si la requête a été envoyée avec succès au serveur.
False
La fonction XkbSetDeviceInfo retourne False si l'implémentation du serveur X ne permet pas l'interaction entre l'extension d'entrée X et l'extension Xkb.

STRUCTURES

Les modifications d'un périphérique d'extension Xkb peuvent être suivies en écoutant les événements XkbDeviceExtensionNotify et en accumulant les modifications dans une structure XkbDeviceChangesRec. Les modifications notées dans la structure peuvent ensuite être utilisées dans des opérations ultérieures pour mettre à jour soit une configuration serveur, soit une copie locale d'une configuration de périphérique d'extension Xkb. La structure des modifications est définie comme suit :

typedef struct _XkbDeviceChanges {
    unsigned int    changed;    /* bits indiquant ce qui a changé */
    unsigned short  first_btn;  /* numéro du premier bouton qui a changé, le cas échéant */
    unsigned short  num_btns;   /* nombre de boutons qui ont changé */
    XkbDeviceLedChangesRec leds;
} XkbDeviceChangesRec,*XkbDeviceChangesPtr;
