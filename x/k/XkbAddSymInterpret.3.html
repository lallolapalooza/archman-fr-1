XkbAddSymInterpret(3) FONCTIONS XKB XkbAddSymInterpret(3)

NOM

XkbAddSymInterpret - Ajoute une interprétation de symbole à la liste des interprétations de symboles dans un XkbCompatRec

SYNTAXE

XkbSymInterpretPtr XkbAddSymInterpret (XkbDescPtr xkb, XkbSymInterpretPtr si, Bool updateMap, XkbChangesPtr changes);

ARGUMENTS

xkb
description du clavier à mettre à jour
si
interprétation de symbole à ajouter
updateMap
Vrai => appliquer la carte de compatibilité aux touches
changes
les modifications sont placées ici

DESCRIPTION

XkbAddSymInterpret ajoute si à la liste des interprétations de symboles dans xkb. Si updateMap est Vrai, elle (ré)applique la carte de compatibilité à toutes les touches du clavier. Si changes n'est pas NULL, elle rapporte les parties du clavier qui ont été affectées (sauf si updateMap est Vrai, peu de choses changent). XkbAddSymInterpret retourne un pointeur vers la nouvelle interprétation de symbole réelle dans la liste ou NULL si elle a échoué.
