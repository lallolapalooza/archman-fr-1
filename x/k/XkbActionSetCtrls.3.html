XkbActionSetCtrls(3) FONCTIONS XKB XkbActionSetCtrls(3)

NOM

XkbActionSetCtrls - Définit les champs ctrls0 à ctrls3 de act à partir de ctrls

SYNTAXE

void XkbActionSetCtrls (XkbCtrlsAction act, unsigned int ctrls);

ARGUMENTS

act
action dans laquelle définir ctrls0-ctrls3
ctrls
valeur à définir dans ctrls0-ctrls3

DESCRIPTION

Les actions associées à la structure XkbCtrlsAction modifient l'état des contrôles booléens.

Le champ type peut prendre l'une des valeurs indiquées dans le Tableau 1.

Tableau 1 Types d'action de contrôle
Type Effet
XkbSA_SetControls Une pression sur une touche active tous les contrôles booléens spécifiés dans les champs ctrls qui n'étaient pas déjà activés au moment de la pression de la touche. Un relâchement de touche désactive tous les contrôles activés par la pression de la touche. Cette action peut provoquer des événements XkbControlsNotify.
XkbSA_LockControls Si le bit XkbSA_LockNoLock n'est pas défini dans le champ flags, une pression sur une touche active tous les contrôles spécifiés dans les champs ctrls qui n'étaient pas déjà désactivés au moment de la pression de la touche. Si le bit XkbSA_LockNoUnlock n'est pas défini dans le champ flags, un relâchement de touche désactive tous les contrôles spécifiés dans les champs ctrls qui n'étaient pas déjà désactivés au moment du relâchement de la touche. Cette action peut provoquer des événements XkbControlsNotify.

Le champ flags est composé de l'OU (OR) bit à bit inclusif des masques indiqués dans le Tableau 2.

Tableau 2 Indicateurs d'action de contrôle
Indicateur Signification
XkbSA_LockNoLock S'il est défini, et que le type d'action est XkbSA_LockControls, le serveur ne désactive que les contrôles.
XkbSA_LockNoUnlock S'il est défini, et que le type d'action est XkbSA_LockControls, le serveur n'active que les contrôles.

L'action XkbSA_SetControls implémente une touche qui active un contrôle booléen lorsqu'elle est pressée et le désactive lorsqu'elle est relâchée. L'action XkbSA_LockControls est utilisée pour implémenter une touche qui bascule l'état d'un contrôle booléen à chaque pression et relâchement. Les indicateurs XkbSA_LockNoLock et XkbSA_LockNoUnlock permettent de modifier le comportement de basculement pour uniquement déverrouiller ou uniquement verrouiller le contrôle booléen.

Les champs ctrls0, ctrls1, ctrls2 et ctrls3 représentent les contrôles booléens dans le champ enabled_ctrls de la structure des contrôles. Macros Xkb, pour convertir entre les deux formats.

XkbActionSetCtrls définit les champs ctrls0 à ctrls3 de act à partir de ctrls.

STRUCTURES

    typedef struct _XkbCtrlsAction {
        unsigned char    type;    /* XkbSA_SetControls, XkbSA_LockControls */
        unsigned char    flags;   /* avec type, contrôle l'activation et la désactivation des contrôles */
        unsigned char    ctrls3;  /* ctrls0 à ctrls3 représentent les contrôles booléens */
        unsigned char    ctrls2;  /* ctrls0 à ctrls3 représentent les contrôles booléens */
        unsigned char    ctrls1;  /* ctrls0 à ctrls3 représentent les contrôles booléens */
        unsigned char    ctrls0;  /* ctrls0 à ctrls3 représentent les contrôles booléens */
    } XkbCtrlsAction;
