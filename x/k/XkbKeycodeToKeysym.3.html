XkbKeycodeToKeysym(3) FONCTIONS XKB XkbKeycodeToKeysym(3)

NOM

XkbKeycodeToKeysym - Trouve le keysym associé à une touche particulière pour un groupe et un niveau de décalage spécifiés

SYNTAXE

KeySym XkbKeycodeToKeysym (Display *dpy, KeyCode kc, unsigned int group, unsigned int level);

ARGUMENTS

dpy
connexion au serveur X
kc
touche concernée
group
groupe concerné
level
niveau de décalage concerné

DESCRIPTION

XkbKeycodeToKeysym renvoie le keysym associé à un groupe et un niveau de décalage spécifiés pour une touche donnée du clavier principal. Si kc n'est pas un keycode valide pour le clavier principal, ou si group ou level sont hors limites pour la touche spécifiée, XkbKeycodeToKeysym renvoie NoSymbol.
