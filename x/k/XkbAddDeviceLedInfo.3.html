XkbAddDeviceLedInfo(3)

Paquet: libx11

Licences: MIT AND X11

XkbAddDeviceLedInfo(3) FONCTIONS Xkb XkbAddDeviceLedInfo(3)

NOM

XkbAddDeviceLedInfo - Initialise une structure XkbDeviceLedInfoRec

SYNTAXE

XkbDeviceLedInfoPtr XkbAddDeviceLedInfo (XkbDeviceInfoPtr device_info, unsigned int led_class, unsigned int led_id);

ARGUMENTS

device_info
structure dans laquelle ajouter les informations de LED
led_class
classe d'extension d'entrée pour le périphérique LED d'intérêt
led_id
ID d'extension d'entrée pour le périphérique LED d'intérêt

DESCRIPTION

XkbAddDeviceLedInfo vérifie d'abord si une entrée correspondant à led_class et led_id existe déjà dans le tableau device_info->leds. Si elle trouve une entrée correspondante, elle renvoie un pointeur vers cette entrée. Sinon, elle vérifie qu'il y a au moins une entrée vide dans device_info->leds et l'étend s'il n'y a pas assez de place. Elle incrémente ensuite device_info->num_leds et remplit la prochaine entrée disponible dans device_info->leds avec led_class et led_id.

En cas de succès, XkbAddDeviceLedInfo renvoie un pointeur vers la structure XkbDeviceLedInfoRec qui a été initialisée. Si elle ne parvient pas à allouer suffisamment de stockage, ou si device_info pointe vers une structure XkbDeviceInfoRec invalide, ou si led_class ou led_id sont inappropriés, XkbAddDeviceLedInfo renvoie NULL.

Pour allouer de l'espace supplémentaire pour les actions de boutons dans une structure XkbDeviceInfoRec, utilisez XkbResizeDeviceButtonActions.

STRUCTURES

Les informations sur les périphériques d'extension d'entrée X sont transférées entre un programme client et l'extension Xkb dans une structure XkbDeviceInfoRec :

    typedef struct {
        char *               name;          /* nom du périphérique */
        Atom                 type;          /* nom de la classe des périphériques */
        unsigned short       device_spec;   /* périphérique d'intérêt */
        Bool                 has_own_state; /* Vrai => ce périphérique a son propre état */
        unsigned short       supported;     /* bits indiquant les capacités prises en charge */
        unsigned short       unsupported;   /* bits indiquant les capacités non prises en charge */
        unsigned short       num_btns;      /* nombre d'entrées dans btn_acts */
        XkbAction *          btn_acts;      /* actions de boutons */
        unsigned short       sz_leds;       /* nombre total d'entrées dans le vecteur LEDs */
        unsigned short       num_leds;      /* nombre d'entrées valides dans le vecteur LEDs */
        unsigned short       dflt_kbd_fb;   /* ID d'extension d'entrée de l'indicateur par défaut (clavier principal) */
        unsigned short       dflt_led_fb;   /* ID d'extension d'entrée du retour d'information par défaut */
        XkbDeviceLedInfoPtr  leds;          /* descriptions des LEDs */
    } XkbDeviceInfoRec, *XkbDeviceInfoPtr;
    typedef struct {
        unsigned short      led_class;        /* classe pour ce périphérique LED */
        unsigned short      led_id;           /* ID pour ce périphérique LED */
        unsigned int        phys_indicators;  /* bits pour les LEDs physiquement présentes */
        unsigned int        maps_present;     /* bits pour les LEDs ayant des mappings dans maps */
        unsigned int        names_present;    /* bits pour les LEDs figurant dans names */
        unsigned int        state;            /* 1 bit => LED correspondante allumée */
        Atom                names[XkbNumIndicators];   /* noms des LEDs */
        XkbIndicatorMapRec  maps;             /* mappings d'indicateurs pour chaque LED */
    } XkbDeviceLedInfoRec, *XkbDeviceLedInfoPtr;
