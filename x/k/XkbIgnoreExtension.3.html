XkbIgnoreExtension(3) FONCTIONS XKB XkbIgnoreExtension(3)

NOM

XkbIgnoreExtension - Empêche les fonctions clavier du noyau X d'utiliser l'extension X Keyboard

SYNTAXE

Bool XkbIgnoreExtension (Bool *ignore);

ARGUMENTS

ignore
True signifie ignorer l'extension

DESCRIPTION

Si un serveur prend en charge l'extension Xkb, la bibliothèque X implémente normalement les fonctions clavier pré-Xkb en utilisant la description et l'état clavier Xkb. L'état du clavier Xkb du serveur peut différer de l'état du clavier pré-Xkb. Cette différence n'affecte pas la plupart des clients, mais il existe des exceptions. Pour permettre à ces clients de fonctionner correctement, vous pouvez demander à l'extension de ne pas utiliser les fonctionnalités Xkb.

Appelez XkbIgnoreExtension pour empêcher les fonctions clavier du noyau X d'utiliser l'extension X Keyboard. Vous devez appeler XkbIgnoreExtension avant d'ouvrir une connexion au serveur ; Xkb ne fournit aucun moyen d'activer ou de désactiver l'utilisation de l'extension une fois qu'une connexion est établie.

XkbIgnoreExtension indique à la bibliothèque X si elle doit utiliser l'extension X Keyboard pour toutes les connexions d'affichage X ultérieures. Si ignore est True, la bibliothèque n'initialise pas l'extension Xkb lors de l'ouverture d'un nouvel écran. Cela force le serveur X à utiliser le mode de compatibilité et à communiquer avec le client en utilisant uniquement les requêtes et événements du protocole de base. Si ignore est False, la bibliothèque traite les appels ultérieurs à XOpenDisplay normalement et utilise les requêtes, événements et états de l'extension Xkb. N'utilisez pas explicitement Xkb sur une connexion pour laquelle elle est désactivée. XkbIgnoreExtension renvoie False s'il n'a pas été possible d'appliquer la demande d'ignorance.

VALEURS DE RETOUR

True
XkbIgnoreExtension renvoie True si
False
La fonction XkbIgnoreExtension renvoie False s'il n'a pas été possible d'appliquer la demande d'ignorance.
