XkbGetKeyActions(3) FONCTIONS XKB XkbGetKeyActions(3)

NOM

XkbGetKeyActions - Met à jour les actions (le tableau key_acts) pour un sous-ensemble des touches d'une description de clavier

SYNTAXE

Status XkbGetKeyActions (Display *dpy, unsigned int first, unsigned int num, XkbDescPtr xkb);

ARGUMENTS

dpy
connexion au serveur X
first
code de touche de la première touche concernée
num
nombre de touches souhaitées
xkb
pointeur vers la description du clavier où le résultat est stocké

DESCRIPTION

XkbGetKeyActions envoie une requête au serveur pour obtenir les actions de num touches du clavier en commençant par la touche first. Elle attend une réponse et retourne les actions dans le champ server->key_acts de xkb. En cas de succès, XkbGetKeyActions retourne Success. Le paramètre xkb doit être un pointeur vers une description de clavier Xkb valide.

Si la carte server, dans le paramètre xkb, n'a pas été allouée, XkbGetKeyActions l'alloue et l'initialise avant d'obtenir les actions.

Si le serveur n'a pas une version compatible de Xkb, ou si l'extension Xkb n'a pas été correctement initialisée, XkbGetKeyActions retourne BadAccess. Si num est inférieur à 1 ou supérieur à XkbMaxKeyCount, XkbGetKeyActions retourne BadValue. Si des erreurs d'allocation se produisent, XkbGetKeyActions retourne BadAlloc.

DIAGNOSTICS

BadAccess
L'extension Xkb n'a pas été correctement initialisée
BadAlloc
Impossible d'allouer de l'espace
BadValue
Un argument est hors de portée
