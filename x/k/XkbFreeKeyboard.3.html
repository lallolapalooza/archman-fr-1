XkbFreeKeyboard(3)

Paquet: libx11

Licences: MIT AND X11

XkbFreeKeyboard(3) FONCTIONS XKB XkbFreeKeyboard(3)

NOM

XkbFreeKeyboard - Détruit soit un XkbDescRec entier, soit certains de ses membres.

SYNTAXE

void XkbFreeKeyboard (XkbDescPtr xkb, unsigned int which, Bool free_all);

ARGUMENTS

xkb
description du clavier avec les composants à libérer.
which
masque sélectionnant les composants à libérer.
free_all
Vrai => libérer tous les composants et xkb.

DESCRIPTION

XkbFreeKeyboard libère les composants de xkb spécifiés par which et met les valeurs correspondantes à NULL. Si free_all est Vrai, XkbFreeKeyboard libère chaque composant non-NULL de xkb, puis libère la structure xkb elle-même.

Si kbd est NULL, aucune opération n'est effectuée.
