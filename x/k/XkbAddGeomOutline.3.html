Paquet: libx11

XkbAddGeomOutline(3) FONCTIONS XKB XkbAddGeomOutline(3)

NOM

XkbAddGeomOutline - Ajoute un contour à une forme existante

SYNTAXE

XkbOutlinePtr XkbAddGeomOutline (XkbShapePtr shape, int sz_points);

ARGUMENTS

shape
forme à mettre à jour
sz_points
nombre de points à réserver

DESCRIPTION

Xkb fournit des fonctions pour ajouter un nouvel élément unique à la géométrie du clavier de haut niveau. Dans chaque cas, les champs num_ * de la structure correspondante sont incrémentés de 1. Ces fonctions ne modifient pas sz_* à moins qu'il n'y ait plus de place dans le tableau. Certaines de ces fonctions remplissent les valeurs de la structure de l'élément à partir des arguments. Pour d'autres fonctions, vous devez écrire explicitement du code pour remplir les éléments de la structure.

La description de la géométrie de haut niveau comprend une liste de propriétés de géométrie. Une propriété de géométrie associe une chaîne arbitraire à un nom tout aussi arbitraire. Les programmes qui affichent des images de claviers peuvent utiliser les propriétés de géométrie comme indices, mais elles ne sont pas interprétées par Xkb. Aucune autre structure de géométrie ne fait référence aux propriétés de géométrie.

Un contour se compose d'un nombre arbitraire de points. XkbAddGeomOutline ajoute un contour à la forme spécifiée en réservant sz_points points pour celui-ci. Le nouveau contour est alloué et mis à zéro. XkbAddGeomOutline renvoie NULL si l'un des paramètres est vide ou s'il n'a pas pu allouer d'espace. Pour allouer de l'espace pour un nombre arbitraire de contours à une forme, utilisez XkbAllocGeomOutlines.

STRUCTURES

    typedef struct _XkbOutline {
        unsigned short    num_points;      /* nombre de points dans le contour */
        unsigned short    sz_points;       /* taille du tableau de points */
        unsigned short    corner_radius;   /* dessine les coins comme des cercles de ce rayon */
        XkbPointPtr       points;          /* tableau de points définissant le contour */
    } XkbOutlineRec, *XkbOutlinePtr;
