XkbChangeControls(3) FONCTIONS XKB XkbChangeControls(3)

NOM

XkbChangeControls - Fournit une méthode flexible pour mettre à jour les contrôles d'un serveur afin qu'ils correspondent à ceux de la description du clavier modifiée

SYNTAXE

Bool XkbChangeControls (Display *dpy, XkbDescPtr xkb, XkbControlsChangesPtr changes);

ARGUMENTS

dpy
connexion au serveur X
xkb
description du clavier avec xkb->ctrls modifiés
changes
quelles parties de xkb->ctrls ont changé

DESCRIPTION

La structure XkbControlsChangesRec permet aux applications de suivre les modifications apportées à une structure XkbControlsRec et ainsi de réduire la quantité de trafic envoyée au serveur. La même structure XkbControlsChangesRec peut être utilisée pour plusieurs modifications successives de la même structure XkbControlsRec, puis utilisée par la suite pour que toutes les modifications, et uniquement les modifications, soient propagées au serveur.

Le champ changed_ctrls est un masque spécifiant quels ensembles logiques de données dans la structure de contrôles ont été modifiés. Dans ce contexte, modifié signifie défini, c'est-à-dire que si une valeur est définie à la même valeur qu'elle contenait précédemment, elle a quand même été modifiée et est notée comme changée. Les valeurs valides pour changed_ctrls sont n'importe quelle combinaison des masques listés dans le Tableau 1 qui ont "ok" dans la colonne changed_ctrls. La définition d'un bit implique que les champs de données correspondants de la colonne "Champs de données pertinents XkbControlsRec" du Tableau 1 ont été modifiés. Le champ enabled_ctrls_changes spécifie quels bits dans le champ enabled_ctrls ont changé. Si le nombre de groupes de clavier a changé, le champ num_groups_changed est défini sur Vrai.

Le Tableau 1 montre les valeurs réelles pour les bits de masque individuels utilisés pour sélectionner les contrôles à modifier et pour activer et désactiver le contrôle. Notez que le même bit de masque est utilisé pour spécifier les modifications générales apportées aux paramètres utilisés pour configurer le contrôle (lequel), et pour activer et désactiver le contrôle (enabled_ctrls).

XkbChangeControls(3)

NAME

XkbChangeControls - Modifier les contrôles du serveur Xkb

SYNOPSIS

#include <X11/Xlib.h>
#include <X11/Xutil.h>
#include <X11/keysym.h>
#include <X11/extensions/Xkb.h>

Bool XkbChangeControls(
    Display *dpy,
    XkbDescPtr xkb,
    XkbControlsChangesPtr	changes
);

ARGUMENTS

dpy
Un pointeur vers la structure Display qui spécifie la connexion au serveur X.
xkb
Un pointeur vers la structure XkbDescRec qui contient la description du clavier et les contrôles qui doivent être mis à jour.
changes
Un pointeur vers la structure XkbControlsChangesRec qui spécifie quels contrôles ont été modifiés et doivent être mis à jour sur le serveur.

DESCRIPTION

La fonction XkbChangeControls permet de modifier les contrôles du serveur X en fonction des changements spécifiés dans une description de clavier Xkb. Elle copie les champs de contrôle spécifiés par changes de la structure des contrôles de la description du clavier (xkb->ctrls) vers le serveur spécifié par dpy.

Les champs de contrôle disponibles sont les suivants :

Table 1. Masques de contrôle Xkb
Nom du masque Valeur
XkbAlwaysGroupLockMask (1L<<13)
XkbGroupsWrapMask (1L<<12)
XkbAccessXKeysMask (1L<<11)
XkbStickyKeysMask (1L<<10)
XkbAccessXFeedbackMask (1L<<9)
XkbAllBooleanCtrlsMask ok (0x00001FFF)
XkbAllControlsMask ok (0xF8001FFF)

Si vous avez une description Xkb avec des contrôles modifiés et une structure XkbControlsChangesRec qui décrit les changements apportés, la fonction XkbChangeControls offre une méthode flexible pour mettre à jour les contrôles dans un serveur afin qu'ils correspondent à ceux de la description du clavier modifiée.

XkbChangeControls copie tous les champs de contrôles spécifiés par changes de la structure des contrôles de la description du clavier, xkb->ctrls, vers le serveur spécifié par dpy.

STRUCTURES

La structure XkbControlsChangesRec est définie comme suit :

typedef struct _XkbControlsChanges {
    unsigned int  changed_ctrls;         /* bits indiquant les données de contrôle modifiées */
    unsigned int  enabled_ctrls_changes; /* bits indiquant les contrôles activés/désactivés */
    Bool          num_groups_changed;    /* True si le nombre de groupes de clavier a changé */
} XkbControlsChangesRec,*XkbControlsChangesPtr;
