NOM

XkbChangeMap - Met à jour seulement des composants partiels d'une description de clavier, modifie les champs appropriés dans les composants serveur et map d'une copie locale de la description du clavier

SYNTAXE

Bool XkbChangeMap (Display *dpy, XkbDescPtr xkb, XkbMapChangesPtr changes);

ARGUMENTS

dpy
connexion au serveur X
xkb
description à partir de laquelle les nouvelles valeurs sont prises
changes
identifie les parties composantes à mettre à jour

DESCRIPTION

Pour mettre à jour seulement des composants partiels d'une description de clavier, modifiez les champs appropriés dans les composants serveur et map d'une copie locale de la description du clavier, puis appelez XkbChangeMap avec une structure XkbMapChangesRec indiquant quels composants ont changé.

XkbChangeMap copie les composants spécifiés par la structure changes depuis la description du clavier, xkb, vers le serveur X spécifié par dpy.

Si des composants spécifiés par changes ne sont pas présents dans le paramètre xkb, XkbChangeMap retourne False. Sinon, il envoie une requête au serveur et retourne True.

XkbChangeMap peut générer des erreurs de protocole BadAlloc, BadLength et BadValue.

VALEURS DE RETOUR

True
La fonction XkbChangeMap retourne True si les composants spécifiés par changes sont présents dans le paramètre xkb.
False
La fonction XkbChangeMap retourne False si les composants spécifiés par changes ne sont pas présents dans le paramètre xkb.

STRUCTURES

Utilisez la structure XkbMapChangesRec pour identifier et suivre les modifications partielles des composants de mappage et pour réduire la quantité de trafic entre le serveur et les clients.

typedef struct _XkbMapChanges {
    unsigned short   changed;            /* identifie les composants valides dans la structure */
    KeyCode          min_key_code;       /* keycode de plus bas numéro pour le périphérique */
    KeyCode          max_key_code;       /* keycode de plus haut numéro pour le périphérique */
    unsigned char    first_type;         /* index du premier type de touche modifié */
    unsigned char    num_types;          /* nombre de types modifiés */
    KeyCode          first_key_sym;      /* première touche dont le key_sym_map a changé */
    unsigned char    num_key_syms;       /* nombre d'entrées key_sym_map modifiées */
    KeyCode          first_key_act;      /* première touche dont l'entrée key_acts a changé */
    unsigned char    num_key_acts;       /* nombre d'entrées key_acts modifiées */
    KeyCode          first_key_behavior; /* première touche dont les behaviors ont changé */
    unsigned char    num_key_behaviors;  /* nombre d'entrées behaviors modifiées */
    KeyCode          first_key_explicit; /* première touche dont l'entrée explicit a changé */
    unsigned char    num_key_explicit;   /* nombre d'entrées explicit modifiées */
    KeyCode          first_modmap_key;   /* première touche dont l'entrée modmap a changé */
    unsigned char    num_modmap_keys;    /* nombre d'entrées modmap modifiées */
    KeyCode          first_vmodmap_key;  /* première touche dont le vmodmap a changé */
    unsigned char    num_vmodmap_keys;   /* nombre d'entrées vmodmap modifiées */
    unsigned char    pad1;               /* réservé */
    unsigned short   vmods;              /* masque indiquant quels vmods ont changé */
} XkbMapChangesRec,*XkbMapChangesPtr;

DIAGNOSTICS

BadAlloc
Impossible d'allouer du stockage
BadLength
La longueur d'une requête est plus courte ou plus longue que nécessaire pour contenir minimalement les arguments
BadValue
Un argument est hors de portée
