XkbAddGeomDoodad(3) FONCTIONS XKB XkbAddGeomDoodad(3)

NOM

XkbAddGeomDoodad - Ajoute un doodad à une section d'une géométrie de clavier ou à la géométrie de niveau supérieur

SYNTAXE

XkbDoodadPtr XkbAddGeomDoodad (XkbGeometryPtr geom, XkbSectionPtr section, Atom name);

ARGUMENTS

geom
géométrie à laquelle le doodad est ajouté
section
section, le cas échéant, à laquelle le doodad est ajouté
name
nom du nouveau doodad

DESCRIPTION

Xkb fournit des fonctions pour ajouter un nouvel élément à la géométrie de clavier de niveau supérieur. Dans chaque cas, les champs num_ * de la structure correspondante sont incrémentés de 1. Ces fonctions ne modifient pas sz_* à moins qu'il n'y ait plus de place dans le tableau. Certaines de ces fonctions remplissent les valeurs de la structure de l'élément à partir des arguments. Pour d'autres fonctions, vous devez explicitement écrire du code pour remplir les éléments de la structure.

La description de la géométrie de niveau supérieur inclut une liste de propriétés de géométrie. Une propriété de géométrie associe une chaîne de caractères arbitraire à un nom tout aussi arbitraire. Les programmes qui affichent des images de claviers peuvent utiliser les propriétés de géométrie comme indices, mais elles ne sont pas interprétées par Xkb. Aucune autre structure de géométrie ne fait référence à des propriétés de géométrie.

Un doodad décrit un aspect visible du clavier qui n'est ni une touche ni une section. XkbAddGeomDoodad ajoute un doodad dont le nom est spécifié par name à la géométrie geom si section est NULL, ou à la section de la géométrie spécifiée par section si section n'est pas NULL. XkbAddGeomDoodad retourne NULL si l'un des paramètres est vide ou s'il n'a pas pu allouer d'espace pour le doodad. S'il existe déjà un doodad portant le nom name dans le tableau de doodads pour la géométrie (si section est NULL) ou la section (si section n'est pas NULL), un pointeur vers ce doodad est retourné. Pour allouer de l'espace pour un nombre arbitraire de doodads à une section, utilisez la fonction XkbAllocGeomSectionDoodads. Pour allouer de l'espace pour un nombre arbitraire de doodads à une géométrie de clavier, utilisez la fonction XkbAllocGeomDoodads.

STRUCTURES
