XkbFreeControls(3) FONCTIONS XKB XkbFreeControls(3)

NOM

XkbFreeControls - Libère la mémoire utilisée par le membre `ctrls` d'une structure XkbDescRec

SYNTAXE

void XkbFreeControls (XkbDescPtr xkb, unsigned int which, Bool free_all);

ARGUMENTS

xkb
Description Xkb dans laquelle libérer les composants de contrôle.
which
Masque des composants de `ctrls` à libérer.
free_all
Vrai => libérer tout + `ctrls` lui-même.

DESCRIPTION

XkbFreeControls libère les composants spécifiés du champ ctrls dans la description du clavier xkb et met les valeurs des composants de structure correspondants à NULL ou zéro. Le masque which spécifie les champs de ctrls à libérer et peut contenir n'importe lequel des composants de contrôle spécifiés dans le Tableau 1.

Le Tableau 1 montre les valeurs réelles des bits de masque individuels utilisés pour sélectionner les contrôles à modifier et pour activer et désactiver le contrôle. Notez que le même bit de masque est utilisé pour spécifier des modifications générales aux paramètres utilisés pour configurer le contrôle (which), et pour activer et désactiver le contrôle (enabled_ctrls). Les anomalies dans le tableau (pas de "ok" dans la colonne) concernent les contrôles qui n'ont pas d'attributs configurables ; et les contrôles qui ne sont pas des contrôles booléens et ne peuvent donc pas être activés ou désactivés.

Tableau 1 Bits de masque des contrôles
Bit de masque which ou enabled Valeur
changed_ctrls _ctrls
XkbRepeatKeysMask ok ok (1L<<0)
XkbSlowKeysMask ok ok (1L<<1)
XkbBounceKeysMask ok ok (1L<<2)
XkbStickyKeysMask ok ok (1L<<3)
XkbMouseKeysMask ok ok (1L<<4)
XkbMouseKeysAccelMask ok ok (1L<<5)
XkbAccessXKeysMask ok ok (1L<<6)
XkbAccessXTimeoutMask ok ok (1L<<7)
XkbAccessXFeedbackMask ok ok (1L<<8)
XkbAudibleBellMask ok (1L<<9)
XkbOverlay1Mask ok (1L<<10)
XkbOverlay2Mask ok (1L<<11)
XkbIgnoreGroupLockMask ok (1L<<12)
XkbGroupsWrapMask ok (1L<<27)
XkbInternalModsMask ok (1L<<28)
XkbIgnoreLockModsMask ok (1L<<29)
XkbPerKeyRepeatMask ok (1L<<30)
XkbControlsEnabledMask ok (1L<<31)
XkbAccessXOptionsMask ok ok (XkbStickyKeysMask |
XkbAccessXFeedbackMask)
XkbAllBooleanCtrlsMask ok (0x00001FFF)
XkbAllControlsMask ok (0xF8001FFF)

Si free_all est Vrai, XkbFreeControls libère chaque composant de structure non-NULL dans les contrôles, libère la structure XkbControlsRec référencée par le membre ctrls de xkb, et met ctrls à NULL.
