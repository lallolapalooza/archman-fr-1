XkbSASetPtrDfltValue(3) FONCTIONS XKB XkbSASetPtrDfltValue(3)

NOM

XkbSASetPtrDfltValue - Définit le champ valueXXX de act à partir de val

SYNTAXE

void XkbSASetPtrDfltValue (XkbAction act, int val);

ARGUMENTS

act
action dans laquelle définir valueXXX
val
valeur à définir dans valueXXX

DESCRIPTION

Les actions associées à la structure XkbPtrDfltAction modifient l'attribut mk_dflt_btn du contrôle MouseKeys.

Si le contrôle MouseKeys n'est pas activé, les événements KeyPress et KeyRelease sont traités comme si l'action était XkbSA_NoAction. Sinon, cette action modifie l'attribut mk_dflt_btn du contrôle MouseKeys.

Le champ type de la structure XkbPtrDfltAction doit toujours être XkbSA_SetPtrDflt.

Le champ flags est composé de l'OR inclusif bit à bit des valeurs montrées dans le Tableau 1 (actuellement, une seule valeur est définie).

Tableau 1 Indicateurs Pointer Default
Indicateur Signification
XkbSA_DfltBtnAbsolute Si défini, le champ value représente un bouton de pointeur absolu. Sinon, le champ value représente le montant à ajouter au bouton par défaut actuel.

Le champ affect spécifie ce qui change à la suite de cette action. La seule valeur valide pour le champ affect est XkbSA_AffectDfltBtn.

Le champ valueXXX est un caractère signé qui représente la nouvelle valeur du bouton pour l'attribut mk_dflt_btn du contrôle MouseKeys. Si XkbSA_DfltBtnAbsolute est défini dans flags, valueXXX spécifie le bouton à utiliser ; sinon, valueXXX spécifie le montant à ajouter au bouton par défaut actuel. Dans les deux cas, les choix de boutons illégaux sont renvoyés dans la plage. Xkb fournit des macros pour convertir entre les valeurs entières et signées en caractères dans les structures XkbPtrDfltAction.

STRUCTURES

    typedef struct _XkbPtrDfltAction {
        unsigned char    type;      /* XkbSA_SetPtrDflt */
        unsigned char    flags;     /* contrôle le numéro du bouton du pointeur */
        unsigned char    affect;    /* XkbSA_AffectDfltBtn */
        char             valueXXX;  /* nouveau membre du bouton par défaut */
    } XkbPtrDfltAction;
