XkbGetControls(3) FONCTIONS XKB XkbGetControls(3)

NOM

XkbGetControls - Trouve l'état actuel des contrôles du serveur Xkb

SYNTAXE

Status XkbGetControls (Display *display, unsigned long which, XkbDescPtr xkb);

ARGUMENTS

display
connexion au serveur X
which
masque des contrôles demandés
xkb
description du clavier pour les informations de contrôle

DESCRIPTION

XkbGetControls interroge le serveur pour les informations de contrôle demandées, attend une réponse, puis copie les valeurs du serveur pour les informations demandées dans la structure ctrls de l'argument xkb. Seuls les composants spécifiés par le paramètre which sont copiés. Les valeurs valides pour which sont toute combinaison des masques listés dans le Tableau 1 qui ont "ok" dans la colonne which.

Le Tableau 1 montre les valeurs réelles pour les bits de masque individuels utilisés pour sélectionner les contrôles à modifier et pour activer et désactiver le contrôle. Notez que le même bit de masque est utilisé pour spécifier les modifications générales des paramètres utilisés pour configurer le contrôle (which), et pour activer et désactiver le contrôle (enabled_ctrls). Les anomalies dans le Tableau 1 (pas de "ok" dans la colonne) concernent les contrôles qui n'ont pas d'attributs configurables ; et les contrôles qui ne sont pas des contrôles booléens et ne peuvent donc pas être activés ou désactivés.

Tableau 1 Bits de masque des contrôles
Bit de masque which ou activé Valeur
changed_ctrls _ctrls
XkbRepeatKeysMask ok ok (1L<<0)
XkbSlowKeysMask ok ok (1L<<1)
XkbBounceKeysMask ok ok (1L<<2)
XkbStickyKeysMask ok ok (1L<<3)
XkbMouseKeysMask ok ok (1L<<4)
XkbMouseKeysAccelMask ok ok (1L<<5)
XkbAccessXKeysMask ok ok (1L<<6)
XkbAccessXTimeoutMask ok ok (1L<<7)
XkbAccessXFeedbackMask ok ok (1L<<8)
XkbAudibleBellMask ok (1L<<9)
XkbOverlay1Mask ok (1L<<10)
XkbOverlay2Mask ok (1L<<11)
XkbIgnoreGroupLockMask ok (1L<<12)
XkbGroupsWrapMask ok (1L<<27)
XkbInternalModsMask ok (1L<<28)
XkbIgnoreLockModsMask ok (1L<<29)
XkbPerKeyRepeatMask ok (1L<<30)
XkbControlsEnabledMask ok (1L<<31)
XkbAccessXOptionsMask ok ok (XkbStickyKeysMask |
XkbAccessXFeedbackMask)
XkbAllBooleanCtrlsMask ok (0x00001FFF)
XkbAllControlsMask ok (0xF8001FFF)

Si xkb->ctrls est NULL, XkbGetControls l'alloue et l'initialise avant d'obtenir les valeurs spécifiées par which. Si xkb->ctrls n'est pas NULL, XkbGetControls modifie uniquement les portions de xkb->ctrls correspondant aux valeurs spécifiées par which.

XkbGetControls retourne Success en cas de succès ; sinon, il retourne BadAlloc s'il ne peut obtenir suffisamment de stockage, BadMatch si xkb est NULL ou which est vide, ou BadImplementation.

Pour libérer le membre ctrls d'une description de clavier, utilisez XkbFreeControls.

Le champ num_groups de la structure ctrls est toujours rempli par XkbGetControls, indépendamment des bits sélectionnés par which.

VALEURS DE RETOUR

Success
La fonction XkbGetControls retourne Success en cas de succès.

DIAGNOSTICS

BadAlloc
Impossible d'allouer du stockage
BadImplementation
Réponse invalide du serveur
BadMatch
Une version compatible de Xkb n'était pas disponible dans le serveur ou un argument a un type et une plage corrects, mais est par ailleurs invalide
