NOM

XkbFreeGeomColors - Libérer les couleurs de géométrie

SYNTAXE

void XkbFreeGeomColors (XkbGeometryPtr geom, int first, int count, Bool free_all);

ARGUMENTS

geom
géométrie dans laquelle les couleurs doivent être libérées
first
première couleur à libérer
count
nombre de couleurs à libérer
free_all
True => toutes les couleurs sont libérées

DESCRIPTION

Xkb fournit un certain nombre de fonctions pour allouer et libérer des sous-composants d'une géométrie de clavier. Utilisez ces fonctions pour créer ou modifier des géométries de clavier. Notez que ces fonctions allouent simplement de l'espace pour le(s) nouvel(aux) élément(s), et il vous appartient de remplir explicitement les valeurs dans votre code. Ces fonctions d'allocation augmentent sz_* mais ne touchent jamais num_* (sauf en cas d'échec d'allocation, auquel cas elles remettent à zéro sz_* et num_*). Ces fonctions retournent Success si elles réussissent, BadAlloc si elles ne parviennent pas à allouer d'espace, ou BadValue si un paramètre n'est pas conforme aux attentes.

Si free_all est True, toutes les couleurs sont libérées quelle que soit la valeur de first ou count. Sinon, count couleurs sont libérées en commençant par celle spécifiée par first.

DIAGNOSTICS

BadAlloc
Impossible d'allouer du stockage
BadValue
Un argument est hors de portée
