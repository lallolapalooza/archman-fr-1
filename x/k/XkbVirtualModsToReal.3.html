Paquet: libx11

Licences: MIT AND X11

XkbVirtualModsToReal(3) FONCTIONS XKB XkbVirtualModsToReal(3)

NOM

XkbVirtualModsToReal - Détermine le mappage des modificateurs virtuels aux modificateurs X du protocole principal

SYNTAXE

Bool XkbVirtualModsToReal (XkbDescPtr xkb, unsigned int virtual_mask, unsigned int *mask_rtrn);

ARGUMENTS

xkb
description du clavier pour l'appareil d'entrée
virtual_mask
masque de modificateurs virtuels à traduire
mask_rtrn
rempli avec les modificateurs réels

DESCRIPTION

Xkb maintient un mappage de modificateurs virtuels, qui liste les modificateurs virtuels associés à, ou liés à, chaque touche. Les modificateurs réels liés à un modificateur virtuel incluent toujours tous les modificateurs liés à l'une des touches qui spécifient ce modificateur virtuel dans leur mappage de modificateurs virtuels. Le tableau server.vmodmap indique quels modificateurs virtuels sont liés à chaque touche ; chaque entrée est un masque de bits pour les bits de modificateurs virtuels. Le tableau server.vmodmap est indexé par code de touche.

Les membres vmodmap et vmods de la carte serveur sont les définitions de modificateurs virtuels "maîtres". Xkb propage automatiquement toute modification de ces champs à tous les autres champs qui utilisent des mappages de modificateurs virtuels.

Par exemple, si Mod3 est lié à la touche Num_Lock par le mappage de modificateurs du protocole principal, et que le modificateur virtuel NumLock est lié à la touche Num_Lock par le mappage de modificateurs virtuels, Mod3 est ajouté à l'ensemble des modificateurs associés à NumLock.

Le mappage des modificateurs virtuels est normalement mis à jour chaque fois que des actions sont automatiquement appliquées aux symboles et peu d'applications devraient avoir besoin de changer explicitement le mappage des modificateurs virtuels.

Utilisez XkbGetMap pour obtenir les modificateurs virtuels du serveur ou utilisez XkbGetVirtualMods pour mettre à jour une copie locale des liaisons de modificateurs virtuels depuis le serveur. Pour définir la liaison d'un modificateur virtuel à un modificateur réel, utilisez XkbGetVirtualMods

Si la description du clavier définie par xkb inclut des liaisons pour les modificateurs virtuels, XkbVirtualModsToReal utilise ces liaisons pour déterminer l'ensemble des modificateurs réels qui correspondent à l'ensemble des modificateurs virtuels spécifiés dans virtual_mask. Le paramètre virtual_mask est un masque spécifiant les modificateurs virtuels à traduire ; le i-ème bit (0 relatif) du masque représente le i-ème modificateur virtuel. Si mask_rtrn n'est pas NULL, XkbVirtualModsToReal le remplit avec le masque de modificateurs réels résultant. Si la description du clavier dans xkb n'inclut pas de liaisons de modificateurs virtuels, XkbVirtualModsToReal retourne False ; sinon, il retourne True.

VALEURS DE RETOUR

Vrai
La fonction XkbVirtualModsToReal retourne Vrai si la description du clavier dans xkb inclut des liaisons de modificateurs virtuels.
Faux
La fonction XkbVirtualModsToReal retourne Faux si la description du clavier dans xkb n'inclut pas de liaisons de modificateurs virtuels.

VOIR AUSSI

XkbGetMap(3), XkbGetVirtualMods(3)

NOTES

Il est possible qu'une description de clavier locale (côté client) (le paramètre xkb) ne contienne aucune information de modificateur virtuel (simplement parce que le client ne l'a pas demandée) alors que la définition correspondante du serveur peut contenir des informations de modificateur virtuel.
