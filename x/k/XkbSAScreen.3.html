XkbSAScreen(3) FONCTIONS XKB XkbSAScreen(3)

NOM

XkbSAScreen - Retourne le champ screenXXX de act converti en entier signé

SYNTAXE

int XkbSAScreen (XkbSwitchScreenAction act);

ARGUMENTS

act
action dont extraire l'écran

DESCRIPTION

Les actions associées à la structure d'action XkbSwitchScreen modifient l'écran actif sur un affichage multiscreen.

Le champ type de la structure XkbSwitchScreenAction doit toujours être XkbSA_SwitchScreen.

Le champ flags est composé du OU inclusif bit à bit des masques présentés dans le Tableau 1.

Tableau 1 Indicateurs d'action de changement d'écran
Indicateur Signification
XkbSA_SwitchAbsolute Si défini, le champ screenXXX représente l'index du nouvel écran. Sinon, il représente un décalage par rapport à l'écran actuel vers le nouvel écran.
XkbSA_SwitchApplication Si non défini, l'action doit passer à un autre écran sur le même serveur. Sinon, elle doit passer à un autre serveur X ou une autre application qui partage le même affichage physique.

Le champ screenXXX est une valeur de caractère signé qui représente soit l'index relatif, soit l'index absolu de l'écran, en fonction de l'état du bit XkbSA_SwitchAbsolute dans le champ flags. Xkb fournit les macros suivantes pour convertir entre la valeur entière et le caractère signé pour les numéros d'écran dans les structures XkbSwitchScreenAction.

La macro XkbSAScreen renvoie le champ screenXXX de act converti en entier signé.

STRUCTURES

    typedef struct _XkbSwitchScreenAction {
        unsigned char    type;        /* XkbSA_SwitchScreen */
        unsigned char    flags;       /* contrôle le changement d'écran */
        char             screenXXX;   /* numéro d'écran ou delta */
    } XkbSwitchScreenAction;

NOTES

L'action XkbSwitchScreen est facultative. Les serveurs sont libres d'ignorer l'action ou l'un de ses indicateurs s'ils ne prennent pas en charge le comportement demandé. Si l'action est ignorée, elle se comporte comme XkbSA_NoAction. Sinon, les événements de pression et de relâchement de touche ne génèrent pas d'événement.
