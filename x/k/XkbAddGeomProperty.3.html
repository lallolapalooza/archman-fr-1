XkbAddGeomProperty(3) FONCTIONS XKB XkbAddGeomProperty(3)

NOM

XkbAddGeomProperty - Ajoute une propriété à une description de géométrie de clavier existante

SYNTAXE

XkbPropertyPtr XkbAddGeomProperty (XkbGeometryPtr geom, _Xconst char *name, _Xconst char *value);

ARGUMENTS

geom
géométrie à mettre à jour
name
nom de la nouvelle propriété
value
valeur de la nouvelle propriété

DESCRIPTION

Xkb fournit des fonctions pour ajouter un nouvel élément unique à la géométrie de clavier de haut niveau. Dans chaque cas, les champs num_ * de la structure correspondante sont incrémentés de 1. Ces fonctions ne modifient pas sz_* sauf s'il n'y a plus de place dans le tableau. Certaines de ces fonctions remplissent les valeurs de la structure de l'élément à partir des arguments. Pour d'autres fonctions, vous devez explicitement écrire du code pour remplir les éléments de la structure.

La description de la géométrie de haut niveau inclut une liste de propriétés géométriques. Une propriété géométrique associe une chaîne de caractères arbitraire à un nom tout aussi arbitraire. Les programmes qui affichent des images de claviers peuvent utiliser les propriétés géométriques comme indices, mais elles ne sont pas interprétées par Xkb. Aucune autre structure de géométrie ne fait référence à des propriétés géométriques.

XkbAddGeomProperty ajoute une propriété avec le nom et la valeur spécifiés à la géométrie du clavier spécifiée par geom. XkbAddGeomProperty renvoie NULL si l'un des paramètres est vide ou s'il n'a pas pu allouer d'espace pour la propriété. Pour allouer de l'espace pour un nombre arbitraire de propriétés, utilisez la fonction XkbAllocGeomProps.

STRUCTURES

    typedef struct _XkbProperty {
        char *         name;       /* nom de la propriété */
        char *         value;      /* valeur de la propriété */
    } XkbPropertyRec,*XkbPropertyPtr;
