XkbQueryExtension(3) FONCTIONS XKB XkbQueryExtension(3)

NOM

XkbQueryExtension - Détermine la compatibilité d'une bibliothèque au moment de l'exécution.

SYNTAXE

Bool XkbQueryExtension (Display *dpy, int *opcode_rtrn, int *event_rtrn, int *error_rtrn, int *major_in_out, int *minor_in_out);

ARGUMENTS

dpy
connexion au serveur X
opcode_rtrn
rempli avec l'opcode majeur de l'extension
event_rtrn
rempli avec le code événement de base de l'extension
error_rtrn
rempli avec le code d'erreur de base de l'extension
major_in_out
version majeure de la lib compilée en entrée, version majeure du serveur en sortie
minor_in_out
version mineure de la lib compilée en entrée, version mineure du serveur en sortie

DESCRIPTION

Appelez XkbQueryExtension pour vérifier la présence et la compatibilité de l'extension dans le serveur et pour initialiser l'extension. En raison de potentielles incompatibilités de version, vous ne pouvez pas utiliser les fonctions génériques de mécanisme d'extension ( XQueryExtension et XInitExtension ) pour vérifier la présence et initialiser l'extension Xkb.

Vous devez appeler XkbQueryExtension ou XkbOpenDisplay avant d'utiliser toute autre interface de la bibliothèque Xkb, sauf si cette utilisation est explicitement autorisée dans la description de l'interface de ce document. Les exceptions sont : XkbIgnoreExtension, XkbLibraryVersion, et une poignée de fonctions de sonnerie audible. Vous ne devriez pas utiliser d'autres fonctions Xkb si l'extension n'est pas présente ou n'est pas initialisée. En général, les appels aux fonctions de la bibliothèque Xkb effectués avant l'initialisation de l'extension Xkb provoquent des erreurs de protocole BadAccess.

XkbQueryExtension détermine à la fois si une extension Xkb compatible est présente dans le serveur X et initialise l'extension lorsqu'elle est présente.

La fonction XkbQueryExtension détermine si une version compatible de l'extension X Keyboard est présente dans le serveur. Si une extension compatible est présente, XkbQueryExtension retourne True ; sinon, elle retourne False.

Si une version compatible de Xkb est présente, XkbQueryExtension initialise l'extension. Elle remplit l'opcode majeur de l'extension clavier dans opcode_rtrn, le code événement de base dans event_rtrn, le code d'erreur de base dans error_rtrn, et les numéros de version majeure et mineure de l'extension dans major_in_out et minor_in_out. L'opcode majeur est rapporté dans les champs req_major de certains événements Xkb. Pour une discussion sur le code événement de base.

VALEUR DE RETOUR

True
La fonction XkbQueryExtension retourne True si elle détermine qu'une version compatible de l'extension X Keyboard est présente dans le serveur.
False
La fonction XkbQueryExtension retourne False si elle détermine qu'une version compatible de l'extension X Keyboard n'est pas présente dans le serveur.

VOIR AUSSI

XkbIgnoreExtension(3), XkbLibraryVersion(3), XkbOpenDisplay(3)
