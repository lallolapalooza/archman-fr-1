XkbInitCanonicalKeyTypes(3) FONCTIONS XKB XkbInitCanonicalKeyTypes(3)

NOM

XkbInitCanonicalKeyTypes - Définit les définitions des types de touches canoniques dans une carte client à leurs valeurs par défaut

SYNOPSIS

Status XkbInitCanonicalKeyTypes (XkbDescPtr xkb, unsigned int which, int keypadVMod);

ARGUMENTS

xkb
description du clavier contenant la carte client à initialiser
which
masque des types à initialiser
keypadVMod
index du modificateur virtuel NumLock

DESCRIPTION

XkbInitCanonicalKeyTypes initialise les XkbNumRequiredTypes premiers types de touches canoniques du clavier spécifié par le paramètre xkb à leurs valeurs par défaut. Le paramètre which spécifie quels types de touches canoniques initialiser et est une combinaison OU inclusive au niveau du bit des masques suivants : XkbOneLevelMask, XkbTwoLevelMask, XkbAlphabeticMask, et XkbKeypadMask. Seuls les types canoniques spécifiés par le masque which sont initialisés.

Si XkbKeypadMask est défini dans le paramètre which, XkbInitCanonicalKeyTypes recherche le modificateur virtuel nommé NumLock pour déterminer quel modificateur virtuel utiliser lors de l'initialisation du type de touche KEYPAD. Si le modificateur virtuel NumLock n'existe pas, XkbInitCanonicalKeyTypes le crée.

XkbInitCanonicalKeyTypes retourne normalement Success. Il retourne BadAccess si l'extension Xkb n'a pas été correctement initialisée, et BadAccess si le paramètre xkb n'est pas valide.

VALEURS DE RETOUR

Success
La fonction XkbInitCanonicalKeyTypes retourne Success si l'extension Xkb a été correctement initialisée et que le paramètre xkb est valide.

DIAGNOSTICS

BadAccess
L'extension Xkb n'a pas été correctement initialisée
