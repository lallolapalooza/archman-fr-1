XkbGetVirtualMods(3) FONCTIONS XKB XkbGetVirtualMods(3)

NOM

XkbGetVirtualMods - Obtient un sous-ensemble des liaisons de modificateurs virtuels (le tableau vmods) dans une description de clavier

SYNTAXE

Status XkbGetVirtualMods (Display *dpy, unsigned int which, XkbDescPtr xkb);

ARGUMENTS

dpy
connexion au serveur
which
masque indiquant les liaisons de modificateurs virtuels à obtenir
xkb
description Xkb où les résultats seront placés

DESCRIPTION

XkbGetVirtualMods envoie une requête au serveur pour obtenir les entrées vmods pour les modificateurs virtuels spécifiés dans le masque, which, et attend une réponse.

Les modificateurs virtuels sont nommés en convertissant leur nom de chaîne en un Atom X et en stockant l'Atom dans le tableau names.vmods d'une structure XkbDescRec. La position d'un nom Atom dans le tableau names.vmods définit la position du bit utilisée pour représenter le modificateur virtuel et aussi l'index utilisé lors de l'accès aux informations de modificateur virtuel dans les tableaux : le nom dans la i-ème entrée (index 0) de names.vmods est le i-ème modificateur virtuel, représenté par le masque (1<<i). Partout dans Xkb, diverses fonctions ont un paramètre qui est un masque représentant les choix de modificateurs virtuels. Dans chaque cas, le i-ème bit (index 0) du masque représente le i-ème modificateur virtuel.

Pour définir le nom d'un modificateur virtuel, utilisez XkbSetNames, en utilisant XkbVirtualModNamesMask dans which et le nom dans l'argument xkb ; pour récupérer les noms d'indicateurs, utilisez XkbGetNames.

Pour chaque bit défini dans which, XkbGetVirtualMods met à jour la définition correspondante du modificateur virtuel dans le tableau server->vmods de xkb. Le paramètre xkb doit être un pointeur vers une description de clavier Xkb valide. En cas de succès, XkbGetVirtualMods retourne Success.

Noms et Masques de Modificateurs Virtuels

Les modificateurs virtuels sont nommés en convertissant leur nom de chaîne en un Atom X et en stockant l'Atom dans le tableau names.vmods d'une structure XkbDescRec. La position d'un nom Atom dans le tableau names.vmods définit la position du bit utilisée pour représenter le modificateur virtuel et aussi l'index utilisé lors de l'accès aux informations de modificateur virtuel dans les tableaux : le nom dans la i-ème entrée (index 0) de names.vmods est le i-ème modificateur virtuel, représenté par le masque (1<<i). Partout dans Xkb, diverses fonctions ont un paramètre qui est un masque représentant les choix de modificateurs virtuels. Dans chaque cas, le i-ème bit (index 0) du masque représente le i-ème modificateur virtuel.

Pour définir le nom d'un modificateur virtuel, utilisez XkbSetNames, en utilisant XkbVirtualModNamesMask dans which et le nom dans l'argument xkb ; pour récupérer les noms d'indicateurs, utilisez XkbGetNames.

Si la carte server n'a pas été allouée dans le paramètre xkb, XkbGetVirtualMods l'alloue et l'initialise avant d'obtenir les liaisons de modificateurs virtuels.

Si le serveur ne dispose pas d'une version compatible de Xkb, ou si l'extension Xkb n'a pas été initialisée correctement, XkbGetVirtualMods retourne BadMatch. Toute erreur d'allocation entraîne le retour de XkbGetVirtualMods avec BadAlloc.

VALEUR DE RETOUR

Success
La fonction XkbGetVirtualMods retourne Success lorsqu'elle met à jour avec succès la définition correspondante du modificateur virtuel dans le tableau server->vmods de xkb.

STRUCTURES

La description complète d'un clavier Xkb est donnée par une XkbDescRec. Les structures de composants dans la XkbDescRec représentent les composants majeurs de Xkb.

typedef struct {
   struct _XDisplay * display;      /* connexion au serveur X */
   unsigned short     flags;        /* privé à Xkb, ne pas modifier */
   unsigned short     device_spec;  /* périphérique d'intérêt */
   KeyCode            min_key_code; /* keycode minimum pour le périphérique */
   KeyCode            max_key_code; /* keycode maximum pour le périphérique */
   XkbControlsPtr     ctrls;        /* contrôles */
   XkbServerMapPtr    server;       /* carte clavier serveur */
   XkbClientMapPtr    map;          /* carte clavier client */
   XkbIndicatorPtr    indicators;   /* carte d'indicateurs */
   XkbNamesPtr        names;        /* noms pour tous les composants */
   XkbCompatMapPtr    compat;       /* carte de compatibilité */
   XkbGeometryPtr     geom;         /* géométrie physique du clavier */
} XkbDescRec, *XkbDescPtr;
Le champ display pointe vers une structure d'affichage X. Le champ flags est privé à la bibliothèque : modifier flags peut produire des résultats imprévisibles. Le champ device_spec spécifie l'identifiant du périphérique d'entrée du clavier, ou XkbUseCoreKeyboard, qui spécifie le périphérique clavier principal. Les champs min_key_code et max_key_code spécifient le keycode le plus bas et le plus haut pouvant être retourné par le clavier.

Chaque composant de structure a un bit de masque correspondant qui est utilisé dans les appels de fonction pour indiquer que la structure doit être manipulée d'une manière ou d'une autre, comme l'allouer ou la libérer. Ces masques et leurs relations avec les champs dans la XkbDescRec sont montrés dans le Tableau 1.

Tableau 1 Bits de Masque pour XkbDescRec

Impossible d'allouer de l'espace
BadMatch
Une version compatible de Xkb n'était pas disponible sur le serveur ou un argument a un type et une plage corrects, mais est par ailleurs invalide

XkbGetVirtualMods - Récupère les modifications virtuelles.

NOM

XkbGetVirtualMods - Récupère les modifications virtuelles.

SYNOPIS

#include <X11/extensions/XKBcomp.h>

XkbModsCtrlDescPtr XkbGetVirtualMods(Display *display, KeySym keysym, XkbInfoPtr info);

DESCRIPTION

XkbGetVirtualMods récupère les modifications virtuelles associées à la touche spécifiée keysym dans le contexte de la configuration XKB décrite par info. L'argument display est un pointeur vers la structure Display de la connexion X.

Les modifications virtuelles sont un moyen de regrouper des modifications de touches physiques en des groupes logiques, permettant par exemple de contrôler les comportements des touches mortes ou des modificateurs complexes.

VALEUR DE RETOUR

La fonction retourne un pointeur vers une structure XkbModsCtrlDescRec décrivant les modifications virtuelles pour la touche donnée. Si aucune modification virtuelle n'est trouvée ou en cas d'erreur, elle peut retourner NULL ou un pointeur vers une structure vide.

DIAGNOSTICS

Des erreurs peuvent survenir si la connexion au serveur X est interrompue ou si les structures de données XKB sont invalides.

VOIR AUSSI

XkbGetSymsForKeyRec(3), XkbHandleActions(3).
