XkbGetKeyboard(3) FONCTIONS XKB XkbGetKeyboard(3)

NOM

XkbGetKeyboard - Récupère un ou plusieurs composants d'une description de périphérique clavier

SYNOPSIS

XkbDescPtr XkbGetKeyboard (Display *display, unsigned int which, unsigned int device_spec);

ARGUMENTS

display
connexion au serveur X
device_spec
ID du périphérique, ou XkbUseCoreKbd
bits_to_change
détermine les événements à sélectionner / désélectionner
values_for_bits
1=>sélectionner, 0->désélectionner ; pour les événements dans bits_to_change

DESCRIPTION

XkbGetKeyboard alloue et renvoie un pointeur vers une description de clavier. Elle interroge le serveur pour les composants spécifiés dans le paramètre which pour le périphérique device_spec et copie les résultats dans la structure XkbDescRec qu'elle a allouée. Les autres champs de la description du clavier sont mis à NULL. Les masques valides pour which sont ceux listés dans le Tableau 1.

Tableau 1 Masques pour XkbDescRec
Bit de masque Champ XkbDescRec Valeur
XkbControlsMask ctrls (1L<<0)
XkbServerMapMask server (1L<<1)
XkbIClientMapMask map (1L<<2)
XkbIndicatorMapMask indicators (1L<<3)
XkbNamesMask names (1L<<4)
XkbCompatMapMask compat (1L<<5)
XkbGeometryMask geom (1L<<6)
XkbAllComponentsMask Tous les champs (1L<<7)

XkbGetKeyboard est utilisée pour lire la description actuelle d'un ou plusieurs composants d'un périphérique clavier. Elle appelle XkbGetKeyboardByName(3) comme suit :

XkbGetKeyboardByName(dpy, device_spec, NULL, which, which, False).

En cas de succès, XkbGetKeyboard renvoie un pointeur vers une structure XkbDescRec nouvellement allouée, décrite dans XkbGetKeyboardByName(3), et qui doit être libérée avec XkbFreeKeyboard(3). Si XkbGetKeyboard ne réussit pas, elle renvoie NULL.

DIAGNOSTICS

BadAlloc
Impossible d'allouer le stockage

VOIR AUSSI
