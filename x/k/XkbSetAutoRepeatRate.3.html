XkbSetAutoRepeatRate(3)

Paquet: libx11

Licences: MIT AND X11

XkbSetAutoRepeatRate(3) FONCTIONS XKB XkbSetAutoRepeatRate(3)

NOM

XkbSetAutoRepeatRate - Définit les attributs du contrôle RepeatKeys pour un périphérique clavier

SYNTAXE

Bool XkbSetAutoRepeatRate (Display *display, unsigned int device_spec, unsigned int timeout, unsigned int interval);

ARGUMENTS

display
connexion au serveur X
device_spec
périphérique à configurer, ou XkbUseCoreKbd
timeout
délai initial, ms
interval
délai entre les répétitions, ms

DESCRIPTION

Le protocole de base ne permet que le contrôle de l'auto-répétition globale du clavier ou de touches individuelles lorsqu'elles sont maintenues enfoncées. RepeatKeys est un contrôle booléen qui étend cette capacité en ajoutant un contrôle sur le délai avant qu'une touche ne commence à se répéter et sur la vitesse à laquelle elle se répète. RepeatKeys est couplé au contrôle d'auto-répétition de base : lorsque RepeatKeys est activé ou désactivé, l'auto-répétition de base est activée ou désactivée et vice versa.

Les touches en auto-répétition sont contrôlées par deux attributs. Le premier, timeout, est le délai entre la pression initiale d'une touche en auto-répétition et le premier événement de répétition généré. Le second, interval, est le délai entre tous les événements de répétition subséquents générés. Comme pour tous les contrôles booléens, la configuration des attributs qui déterminent le fonctionnement du contrôle n'active pas automatiquement le contrôle dans son ensemble.

XkbSetAutoRepeatRate envoie une requête au serveur X pour configurer les attributs du contrôle AutoRepeat aux valeurs spécifiées dans timeout et interval.

XkbSetAutoRepeatRate n'attend pas de réponse ; il renvoie normalement True. La spécification d'une valeur nulle pour timeout ou interval provoque la génération d'une erreur de protocole BadValue par le serveur. Si une version compatible de l'extension Xkb n'est pas disponible sur le serveur, XkbSetAutoRepeatRate renvoie False.

VALEURS DE RETOUR

Vrai
La fonction XkbSetAutoRepeatRate renvoie normalement Vrai.
Faux
La fonction XkbSetAutoRepeatRate renvoie Faux si une version compatible de l'extension Xkb n'est pas disponible sur le serveur.

DIAGNOSTICS

BadValue
Un argument est hors de portée
