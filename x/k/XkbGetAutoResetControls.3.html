XkbGetAutoResetControls(3) FONCTIONS XKB XkbGetAutoResetControls(3)

NOM

XkbGetAutoResetControls - Obtient les valeurs actuelles des contrôles de réinitialisation automatique

SYNTAXE

Bool XkbGetAutoResetControls (Display *dpy, unsigned int *auto_ctrls, unsigned int *auto_values);

ARGUMENTS

dpy
connexion au serveur X
auto_ctrls
spécifie quels bits dans auto_values sont pertinents
auto_values
1 bit => le contrôle correspondant a la réinitialisation automatique activée

DESCRIPTION

Vous pouvez configurer les contrôles booléens pour qu'ils soient automatiquement activés ou désactivés lorsqu'un programme se termine. Cette capacité est contrôlée par deux masques maintenus dans le serveur X sur une base par client. Il n'y a pas de structure de données Xkb côté client correspondant à ces masques. Chaque fois que le client se termine pour quelque raison que ce soit, tous les contrôles booléens spécifiés dans le masque de réinitialisation automatique sont définis sur la valeur correspondante du masque de valeurs de réinitialisation automatique. Cela permet aux clients de se "nettoyer après eux-mêmes" automatiquement, même en cas de terminaison anormale. Les bits utilisés dans les masques correspondent aux bits de contrôle EnabledControls.

Par exemple, un client qui remplace la sonnerie du clavier par un autre signal sonore pourrait vouloir désactiver le contrôle AudibleBell pour empêcher le serveur de générer également un son et éviter la cacophonie. Si le client se terminait sans réinitialiser le contrôle AudibleBell, l'utilisateur se retrouverait sans aucun retour d'information. La définition d'AudibleBell dans le masque de réinitialisation automatique et les valeurs de réinitialisation automatique garantit que la sonnerie audible sera réactivée à la sortie du client.

XkbGetAutoResetControls remplit auto_ctrls et auto_values avec les attributs de contrôle AutoReset pour ce client particulier. Il renvoie True en cas de succès, et False sinon.

VALEURS DE RETOUR

Vrai
La fonction XkbGetAutoResetControls renvoie Vrai lorsqu'elle remplit avec succès auto_ctrls et auto_values avec les attributs de contrôle AutoReset pour ce client particulier.
Faux
La fonction XkbGetAutoResetControls renvoie Faux lorsqu'elle ne remplit pas avec succès auto_ctrls et auto_values avec les attributs de contrôle AutoReset pour ce client particulier.
