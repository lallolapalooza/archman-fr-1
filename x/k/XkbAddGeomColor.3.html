NOM

XkbAddGeomColor - Ajoute un nom de couleur à une description de géométrie de clavier existante

SYNTAXE

XkbColorPtr XkbAddGeomColor (XkbGeometryPtr geom, _Xconst char *spec, unsigned int pixel);

ARGUMENTS

geom
géométrie à mettre à jour
spec
couleur à ajouter
pixel
couleur à ajouter

DESCRIPTION

Xkb fournit des fonctions pour ajouter un nouvel élément unique à la géométrie de clavier de haut niveau. Dans chaque cas, les champs num_* de la structure correspondante sont incrémentés de 1. Ces fonctions ne modifient pas sz_* à moins qu'il n'y ait plus de place dans le tableau. Certaines de ces fonctions remplissent les valeurs de la structure de l'élément à partir des arguments. Pour les autres fonctions, vous devez explicitement écrire du code pour remplir les éléments de la structure.

La description de géométrie de haut niveau comprend une liste de propriétés de géométrie. Une propriété de géométrie associe une chaîne arbitraire à un nom tout aussi arbitraire. Les programmes qui affichent des images de claviers peuvent utiliser les propriétés de géométrie comme indices, mais elles ne sont pas interprétées par Xkb. Aucune autre structure de géométrie ne fait référence aux propriétés de géométrie.

XkbAddGeomColor ajoute le nom et le pixel de couleur spécifiés à la géométrie geom spécifiée. La description de géométrie de haut niveau comprend une liste de jusqu'à MaxColors (32) noms de couleur. Un nom de couleur est une chaîne dont l'interprétation n'est pas spécifiée par Xkb, pas plus que l'interprétation de la valeur pixel. Toutes les autres structures de données de géométrie font référence aux couleurs en utilisant leurs indices dans cette liste globale ou des pointeurs vers des couleurs dans cette liste. XkbAddGeomColor renvoie NULL si l'un des paramètres est vide ou s'il n'a pas pu allouer d'espace pour la couleur. Pour allouer de l'espace pour un nombre arbitraire de couleurs à une géométrie, utilisez la fonction XkbAllocGeomColors.

STRUCTURES

    typedef struct _XkbColor {
        unsigned int    pixel;      /* couleur */
        char *          spec;       /* nom de la couleur */
    } XkbColorRec,*XkbColorPtr;
