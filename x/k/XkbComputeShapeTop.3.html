XkbComputeShapeTop(3) FONCTIONS XKB XkbComputeShapeTop(3)

NOM

XkbComputeShapeTop - Détermine la boîte englobante de la surface supérieure d'une forme

SYNTAXE

Bool XkbComputeShapeTop (XkbShapePtr shape, XkbBoundsPtr bounds_rtrn);

ARGUMENTS

shape
forme à examiner
bounds_rtrn
rempli avec la boîte englobante pour la forme

DESCRIPTION

Xkb fournit un certain nombre de fonctions utilitaires pour aider à utiliser une géométrie de clavier. Celles-ci incluent des fonctions pour retourner la boîte englobante de la surface supérieure d'une forme et pour mettre à jour la boîte englobante d'une ligne ou d'une section de forme.

Une forme est composée d'un certain nombre de contours. Chaque contour est un polygone composé d'un certain nombre de points. La boîte englobante d'une forme est un rectangle qui contient tous les contours de cette forme.

XkbComputeShapeTop retourne un BoundsRec qui contient deux coordonnées x et y. Ces coordonnées décrivent les coins d'un rectangle qui contient le contour décrivant la surface supérieure de la forme. La surface supérieure est définie comme le contour approximatif si le champ approx de shape n'est pas NULL. Si approx est NULL, la surface supérieure est définie comme le dernier contour dans le tableau de contours de shape. XkbComputeShapeTop retourne False si shape est NULL ou s'il n'y a pas de contours pour la forme ; sinon, il retourne True.

STRUCTURES

typedef struct _XkbBounds {
	short	x1,y1;	/* coin supérieur gauche de la boîte, en mm/10 */
	short	x2,y2;	/* coin inférieur droit de la boîte, en mm/10 */
} XkbBoundsRec, *XkbBoundsPtr;
