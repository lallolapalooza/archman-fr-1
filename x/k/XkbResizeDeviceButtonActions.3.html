XkbResizeDeviceButtonActions(3) FONCTIONS XKB XkbResizeDeviceButtonActions(3)

NOM

XkbResizeDeviceButtonActions - Allouer de l'espace supplémentaire pour les actions de boutons dans une structure XkbDeviceInfoRec

SYNTAXE

Status XkbResizeDeviceButtonActions (XkbDeviceInfoPtr device_info, unsigned int new_total);

ARGUMENTS

device_info
structure dans laquelle allouer les actions de boutons
new_total
nombre total d'actions de boutons requis

DESCRIPTION

XkbResizeDeviceButtonActions réalloue de l'espace, si nécessaire, pour s'assurer qu'il y a de la place pour un total de new_total actions de boutons dans la structure device_info. Les nouvelles entrées allocées sont mises à zéro. En cas de succès, XkbResizeDeviceButtonActions renvoie Success. Si new_total est zéro, toutes les actions de boutons sont supprimées, device_info->num_btns est mis à zéro et device_info->btn_acts est mis à NULL. Si device_info est invalide ou si new_total est supérieur à 255, BadValue est renvoyé. En cas d'échec d'allocation de mémoire, BadAlloc est renvoyé.

Pour libérer une structure XkbDeviceInfoRec, utilisez XkbFreeDeviceInfo.

STRUCTURES

Les informations sur les périphériques d'extension d'entrée X sont transférées entre un programme client et l'extension Xkb dans une structure XkbDeviceInfoRec :

    typedef struct {
        char *               name;          /* nom du périphérique */
        Atom                 type;          /* nom de la classe de périphériques */
        unsigned short       device_spec;   /* périphérique concerné */
        Bool                 has_own_state; /* True=>ce périphérique a son propre état */
        unsigned short       supported;     /* bits indiquant les capacités supportées */
        unsigned short       unsupported;   /* bits indiquant les capacités non supportées */
        unsigned short       num_btns;      /* nombre d'entrées dans btn_acts */
        XkbAction *          btn_acts;      /* actions de boutons */
        unsigned short       sz_leds;       /* nombre total d'entrées dans le vecteur LEDs */
        unsigned short       num_leds;      /* nombre d'entrées valides dans le vecteur LEDs */
        unsigned short       dflt_kbd_fb;   /* ID d'extension d'entrée de l'indicateur par défaut (clavier core) */
        unsigned short       dflt_led_fb;   /* ID d'extension d'entrée du retour d'information par défaut */
        XkbDeviceLedInfoPtr  leds;          /* descriptions des LEDs */
    } XkbDeviceInfoRec, *XkbDeviceInfoPtr;

DIAGNOSTICS

BadAlloc
Impossible d'allouer du stockage
BadValue
Un argument est hors limites
