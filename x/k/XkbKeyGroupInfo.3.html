XkbKeyGroupInfo(3) FONCTIONS XKB XkbKeyGroupInfo(3)

NOM

XkbKeyGroupInfo - Retourne le nombre de groupes de symboles liés à la touche correspondant à la touche code

SYNTAXE

unsigned char XkbKeyGroupInfo (XkbDescPtr xkb, KeyCode keycode);

ARGUMENTS

xkb
Description Xkb d'intérêt
keycode
Code de touche d'intérêt

DESCRIPTION

Le champ group_info d'une XkbSymMapRec est une valeur codée contenant le nombre de groupes de symboles liés à la touche ainsi que la spécification du traitement des groupes hors limites. Il est légal pour une touche d'avoir zéro groupe, auquel cas elle a également zéro symbole et tous les événements de cette touche retournent NoSymbol. Pour obtenir le nombre de groupes de symboles liés à la touche, utilisez XkbKeyNumGroups. Pour modifier le nombre de groupes liés à une touche, utilisez XkbChangeTypesOfKey. Pour obtenir un masque qui détermine le traitement des groupes hors limites, utilisez XkbKeyGroupInfo et XkbOutOfRangeGroupInfo.

Les contrôles du clavier contiennent un champ groups_wrap spécifiant la gestion des groupes illégaux sur une base globale. C'est-à-dire, lorsque l'utilisateur effectue une action entraînant le dépassement du groupe effectif de clavier hors des limites légales, le champ groups_wrap spécifie comment normaliser le groupe effectif du clavier vers un groupe légal pour le clavier dans son ensemble, mais il n'y a aucune garantie que le groupe normalisé sera dans la plage des groupes légaux pour une touche individuelle. Le champ group_info par touche spécifie comment une touche traite un groupe effectif légal si la touche n'a pas de type spécifié pour le groupe concerné. Par exemple, la touche Entrée a généralement un seul groupe défini. Si l'utilisateur effectue une action entraînant le changement du groupe global du clavier vers le Groupe 2, le champ group_info pour la touche Entrée décrit comment gérer cette situation.

Les groupes hors limites pour les touches individuelles sont mappés vers un groupe légal en utilisant les mêmes options que celles utilisées pour le groupe global du clavier. Le type particulier de mappage utilisé est contrôlé par les bits définis dans le drapeau group_info, comme indiqué dans le Tableau 1.

Tableau 1 Normalisation des plages de group_info
Bits définis dans group_info Méthode de normalisation
XkbRedirectIntoRange XkbRedirectIntoRange
XkbClampIntoRange XkbClampIntoRange
aucun des ci-dessus XkbWrapIntoRange

XkbKeyGroupInfo retourne le champ group_info de la structure XkbSymMapRec associée à la touche correspondant à keycode.

STRUCTURES

La structure KeySymMapRec est définie comme suit :

#define XkbNumKbdGroups             4
#define XkbMaxKbdGroup              (XkbNumKbdGroups-1)
typedef struct {                    /* map to keysyms for a single keycode */
    unsigned char       kt_index[XkbNumKbdGroups];  /* index du type de touche pour chaque groupe */
    unsigned char       group_info; /* # de groupes et gestion des groupes hors limites */
    unsigned char       width;      /* # max de niveaux de décalage pour la touche */
    unsigned short      offset;     /* index de la table des keysyms dans le tableau syms */
} XkbSymMapRec, *XkbSymMapPtr;

XkbKeyGroupInfo(3)

NAME

XkbKeyGroupInfo, XkbKeyGroupByGroup, XkbKeyGroupNames, XkbKeyGroupNumber - obtenir des informations sur les groupes de touches du clavier Xkb

SYNOPSIS

int XkbKeyGroupInfo (Display *dpy, unsigned int *key_group_info ); int XkbKeyGroupByGroup (Display *dpy, unsigned int *key_group ); int XkbKeyGroupNames (Display *dpy, unsigned int *key_group_names ); int XkbKeyGroupNumber (Display *dpy, unsigned int *key_group_number );

ARGUMENTS

dpy
Connexion au serveur X.
key_group_info
Pointeur vers une variable entière qui recevra les informations sur le groupe de touches.
key_group
Pointeur vers une variable entière qui recevra le groupe de touches actuel.
key_group_names
Pointeur vers une variable entière qui recevra les noms des groupes de touches.
key_group_number
Pointeur vers une variable entière qui recevra le numéro du groupe de touches.

DESCRIPTION

Les fonctions XkbKeyGroupInfo, XkbKeyGroupByGroup, XkbKeyGroupNames et XkbKeyGroupNumber permettent d'obtenir des informations sur les groupes de touches du clavier Xkb.

XkbKeyGroupInfo renvoie un masque de bits contenant des informations sur le groupe de touches actuel. Les bits significatifs sont les suivants :

  • XkbKeyGroupInfoShiftMask : Le groupe de touches actuel est décalé.
  • XkbKeyGroupInfoLatchMask : Le groupe de touches actuel est verrouillé.

XkbKeyGroupByGroup renvoie le groupe de touches actuel sous forme d'entier.

XkbKeyGroupNames renvoie les noms des groupes de touches sous forme d'une chaîne de caractères.

XkbKeyGroupNumber renvoie le numéro du groupe de touches actuel sous forme d'entier.

STRUCTURES

Aucune structure spécifique n'est utilisée par ces fonctions.
