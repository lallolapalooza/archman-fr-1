Paquet: libx11

Licences: MIT AND X11

XkbCopyKeyTypes(3) FONCTIONS XKB XkbCopyKeyTypes(3)

NOM

XkbCopyKeyTypes - Copie plusieurs structures XkbKeyTypeRec

SYNOPSIS

Status XkbCopyKeyTypes (XkbKeyTypePtr from, XkbKeyTypePtr into, int num_types);

ARGUMENTS

from
pointeur vers le tableau de XkbKeyTypeRec à copier
into
pointeur vers le tableau de XkbKeyTypeRec à modifier
num_types
nombre de types à copier

DESCRIPTION

XkbCopyKeyTypes copie num_types structures XkbKeyTypeRec depuis le tableau spécifié par from vers le tableau spécifié par into. Elle est destinée à copier entre, plutôt qu'à l'intérieur, des descriptions de clavier, elle ne vérifie donc pas les chevauchements. Les mêmes règles qui s'appliquent aux paramètres from et into de XkbCopyKeyType s'appliquent à chaque entrée des tableaux from et into de XkbCopyKeyTypes. Si des erreurs d'allocation surviennent lors de la copie de from vers into, XkbCopyKeyTypes renvoie BadAlloc. Sinon, XkbCopyKeyTypes copie from vers into et renvoie Success.

VALEURS DE RETOUR

Success
La fonction XkbCopyKeyTypes renvoie Success lorsqu'il n'y a pas d'erreurs d'allocation.

STRUCTURES

Les types de touches sont utilisés pour déterminer le niveau de décalage d'une touche étant donné l'état actuel du clavier. L'ensemble de tous les types de touches possibles pour la description du clavier Xkb est contenu dans le champ types de la carte client, dont la taille totale est stockée dans size_types, et dont le nombre total d'entrées valides est stocké dans num_types. Les types de touches sont définis à l'aide de la structure suivante :

typedef struct {                   /* Type de touche */
    XkbModsRec        mods;        /* modificateurs utilisés pour calculer le niveau de décalage */
    unsigned char     num_levels;  /* nombre total de niveaux de décalage, ne pas modifier directement */
    unsigned char     map_count;   /* nombre d'entrées dans la carte, préserver (si non NULL) */
    XkbKTMapEntryPtr  map;         /* vecteur de modificateurs pour chaque niveau de décalage */
    XkbModsPtr        preserve;    /* mods à préserver pour l'entrée de carte correspondante */
    Atom              name;        /* nom du type de touche */
    Atom *            level_names; /* tableau des noms de chaque niveau de décalage */
} XkbKeyTypeRec, *XkbKeyTypePtr;

DIAGNOSTICS

BadAlloc
Impossible d'allouer du stockage
