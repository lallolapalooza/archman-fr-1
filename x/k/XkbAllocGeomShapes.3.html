NOM

XkbAllocGeomShapes - Alloue de l'espace pour un nombre arbitraire de formes géométriques

SYNOPSIS

Status XkbAllocGeomShapes (XkbGeometryPtr geom, int num_needed);

ARGUMENTS

geom
géométrie pour laquelle les formes doivent être allouées
num_needed
nombre de nouvelles formes requises

DESCRIPTION

Xkb fournit un certain nombre de fonctions pour allouer et libérer des sous-composants d'une géométrie de clavier. Utilisez ces fonctions pour créer ou modifier des géométries de clavier. Notez que ces fonctions allouent simplement de l'espace pour le(s) nouvel(aux) élément(s), et il vous appartient de remplir les valeurs explicitement dans votre code. Ces fonctions d'allocation augmentent sz_* mais ne touchent jamais num_* (sauf en cas d'échec d'allocation, auquel cas elles réinitialisent à la fois sz_* et num_* à zéro). Ces fonctions retournent Success si elles réussissent, BadAlloc si elles ne parviennent pas à allouer d'espace, ou BadValue si un paramètre n'est pas celui attendu.

XkbAllocGeomShapes alloue de l'espace pour num_needed formes dans la géométrie spécifiée geom. Les formes ne sont pas initialisées.

Pour libérer les formes géométriques, utilisez XkbFreeGeomShapes.

DIAGNOSTICS

BadAlloc
Impossible d'allouer du stockage
BadValue
Un argument est hors limites

VOIR AUSSI

XkbFreeGeomShapes(3)
