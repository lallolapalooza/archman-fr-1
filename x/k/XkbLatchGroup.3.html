NOM

XkbLatchGroup - Verrouille le groupe de keysyms

SYNTAXE

Bool XkbLatchGroup (Display *display, unsigned int device_spec, unsigned int group);

ARGUMENTS

display
connexion au serveur X
device_spec
ID de périphérique, ou XkbUseCoreKbd
group
index du groupe de keysyms à verrouiller

DESCRIPTION

XkbLatchGroup envoie une requête au serveur pour verrouiller le group spécifié et n'attend pas de réponse. Elle renvoie True si la requête a été envoyée et False sinon.

Référez-vous aux indices de groupe de keysyms avec ces constantes symboliques :

Tableau 1 Noms de groupe symboliques
Nom Symbolique Valeur
XkbGroup1Index 0
XkbGroup2Index 1
XkbGroup3Index 2
XkbGroup4Index 3

VALEURS DE RETOUR

True
La fonction XkbLatchGroup renvoie True si une requête a été envoyée au serveur pour verrouiller le group spécifié.
False
La fonction XkbLatchGroup renvoie False si la requête n'a pas été envoyée.
