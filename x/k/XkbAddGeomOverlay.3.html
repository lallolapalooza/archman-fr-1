XkbAddGeomOverlay(3) FONCTIONS XKB XkbAddGeomOverlay(3)

NOM

XkbAddGeomOverlay - Ajouter une superposition à une section

SYNTAXE

XkbOverlayPtr XkbAddGeomOverlay (XkbSectionPtr section, Atom name, int sz_rows);

ARGUMENTS

section
section à laquelle une superposition sera ajoutée
name
nom de la superposition
sz_rows
nombre de lignes à réserver dans la superposition

DESCRIPTION

Xkb fournit des fonctions pour ajouter un seul nouvel élément à la géométrie de clavier de haut niveau. Dans chaque cas, les champs num_ * de la structure correspondante sont incrémentés de 1. Ces fonctions ne modifient pas sz_* à moins qu'il n'y ait plus de place dans le tableau. Certaines de ces fonctions remplissent les valeurs de la structure de l'élément à partir des arguments. Pour d'autres fonctions, vous devez explicitement écrire du code pour remplir les éléments de la structure.

La description de la géométrie de haut niveau inclut une liste de propriétés géométriques. Une propriété géométrique associe une chaîne de caractères arbitraire à un nom tout aussi arbitraire. Les programmes qui affichent des images de claviers peuvent utiliser les propriétés géométriques comme indices, mais elles ne sont pas interprétées par Xkb. Aucune autre structure géométrique ne fait référence aux propriétés géométriques.

XkbAddGeomOverlay ajoute une superposition avec le nom spécifié à la section spécifiée. La nouvelle superposition est créée avec de l'espace alloué pour sz_rows lignes. Si une superposition portant le nom name existe déjà dans la section, un pointeur vers la superposition existante est renvoyé. XkbAddGeomOverlay renvoie NULL si l'un des paramètres est vide ou s'il n'a pas pu allouer d'espace pour la superposition. Pour allouer de l'espace pour un nombre arbitraire de superpositions à une section, utilisez la fonction XkbAllocGeomOverlay.

STRUCTURES

    typedef struct _XkbOverlayRec {
        Atom                  name;            /* nom de la superposition */
        XkbSectionPtr         section_under;   /* la section sous cette superposition */
        unsigned short        num_rows;        /* nombre de lignes dans le tableau des lignes */
        unsigned short        sz_rows;         /* taille du tableau des lignes */
        XkbOverlayRowPtr      rows;            /* tableau des lignes dans la superposition */
        XkbBoundsPtr          bounds;          /* boîte englobante pour la superposition */
    } XkbOverlayRec,*XkbOverlayPtr;
