XkbFreeComponentList(3) FONCTIONS XKB XkbFreeComponentList(3)

NOM

XkbFreeComponentList - Libérer la structure retournée par XkbListComponents

SYNTAXE

void XkbFreeComponentList (XkbComponentListPtr list);

ARGUMENTS

list
pointeur vers XkbComponentListRec à libérer

DESCRIPTION

Lorsque vous avez fini d'utiliser la structure retournée par XkbListComponents, libérez-la en utilisant XkbFreeComponentList.
