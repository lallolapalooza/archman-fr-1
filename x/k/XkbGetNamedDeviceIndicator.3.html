XkbGetNamedIndicator(3) FONCTIONS XKB XkbGetNamedDeviceIndicator(3)

NOM

XkbGetNamedIndicator - Recherche la carte d'indicateur et d'autres informations pour un indicateur par son nom

SYNTAXE

Bool XkbGetNamedDeviceIndicator (Display *dpy, unsigned int dev_spec, unsigned int led_class, unsigned int led_id, Atom name, int *ndx_rtrn, Bool *state_rtrn, XkbIndicatorMapPtr map_rtrn, Bool *real_rtrn);

Bool XkbGetNamedIndicator (Display *dpy, Atom name, int *ndx_rtrn, Bool *state_rtrn, XkbIndicatorMapPtr map_rtrn, Bool *real_rtrn);

ARGUMENTS

dpy
connexion au serveur X
dev_spec
ID du périphérique clavier, ou XkbUseCoreKbd
led_class
classe de retour, ou XkbDfltXIClass
led_id
ID de retour, ou XkbDfltXIId
name
nom de l'indicateur à récupérer
ndx_rtrn
rempli avec l'indice de l'indicateur récupéré
state_rtrn
rempli avec l'état actuel de l'indicateur récupéré
map_rtrn
rempli avec la carte de l'indicateur récupéré
real_rtrn
rempli avec True si l'indicateur nommé est réel (physique)

DESCRIPTION

Xkb permet également aux applications de faire référence aux indicateurs par leur nom. Utilisez XkbGetNames pour obtenir les noms des indicateurs. L'utilisation de noms élimine le besoin de coder en dur des valeurs de masque pour des claviers spécifiques. Par exemple, au lieu d'utiliser des constantes spécifiques au fournisseur telles que le masque WSKBLed_ScrollLock sur les stations de travail Digital ou XLED_SCROLL_LOCK sur les stations de travail Sun, vous pouvez plutôt utiliser XkbGetNamedDeviceIndicator pour récupérer des informations sur l'indicateur nommé "Scroll Lock".

Si le périphérique spécifié par device_spec a un indicateur nommé name, XkbGetNamedDeviceIndicator renvoie True et remplit le reste des paramètres avec des informations sur l'indicateur. Sinon, XkbGetNamedDeviceIndicator renvoie False.

Le champ ndx_rtrn renvoie l'indice basé sur zéro de l'indicateur nommé. Cet indice est la position du bit à utiliser dans tout appel de fonction qui nécessite un masque de bits d'indicateur, ainsi que l'indice de l'indicateur dans le tableau XkbIndicatorRec des cartes d'indicateurs. state_rtrn renvoie l'état actuel de l'indicateur nommé (True = allumé, False = éteint). map_rtrn renvoie la carte de l'indicateur pour l'indicateur nommé. De plus, si l'indicateur est mappé à une LED physique, le paramètre real_rtrn est défini sur True.

Chacun des arguments " _rtrn " est facultatif ; vous pouvez passer NULL pour tous les arguments " _rtrn " inutiles.

XkbGetNamedIndicator est une fonction de commodité qui appelle XkbGetNamedDeviceIndicator avec un device_spec de XkbUseCoreKbd, une led_class de XkbDfltXIClass et un led_id de XkbDfltXIId. Elle renvoie la valeur de retour de XkbGetNamedDeviceIndicator.

VALEURS DE RETOUR

True
Les fonctions XkbGetNamedIndicator et XkbGetNamedDeviceIndicator renvoient True si le périphérique spécifié par device_spec possède un indicateur nommé name.
False
Les fonctions XkbGetNamedIndicator et XkbGetNamedDeviceIndicator renvoient False si le périphérique spécifié par device_spec ne possède pas d'indicateur nommé name.
