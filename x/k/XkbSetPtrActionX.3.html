XkbSetPtrActionX(3) FONCTIONS XKB XkbSetPtrActionX(3)

NOM

XkbSetPtrActionX - Définit les champs high_XXX et low_XXX de act à partir de la valeur entière signée x

SYNTAXE

void XkbSetPtrActionX (XkbPtrAction act, int x);

ARGUMENTS

act
action dans laquelle définir X
x
nouvelle valeur à définir

DESCRIPTION

Les actions associées à la structure XkbPtrAction déplacent le pointeur lors de l'appui et du relâchement des touches.

Si le contrôle MouseKeys n'est pas activé, les événements KeyPress et KeyRelease sont traités comme si l'action était XkbSA_NoAction.

Si le contrôle MouseKeys est activé, une action serveur de type XkbSA_MovePtr demande au serveur de générer des événements de mouvement pointer MotionNotify plutôt que l'événement KeyPress habituel, et l'événement KeyRelease correspondant désactive tous les temporisateurs de souris activés suite à la gestion de l'action XkbSA_MovePtr.

Le champ type de la structure XkbPtrAction est toujours XkbSA_MovePtr.

Le champ flags est un OU inclusif binaire des masques indiqués dans le Tableau 1.

Tableau 1 Types d'actions de pointeur
Type d'action Signification
XkbSA_NoAcceleration Si non défini, et que le contrôle MouseKeysAccel est activé, le KeyPress déclenche un temporisateur de souris pour cette touche ; chaque fois que le temporisateur expire, le curseur se déplace.
XkbSA_MoveAbsoluteX Si défini, la partie X de la structure spécifie la nouvelle coordonnée X du pointeur. Sinon, la partie X est ajoutée à la coordonnée X actuelle du pointeur pour déterminer la nouvelle coordonnée X du pointeur.
XkbSA_MoveAbsoluteY Si défini, la partie Y de la structure spécifie la nouvelle coordonnée Y du pointeur. Sinon, la partie Y est ajoutée à la coordonnée Y actuelle du pointeur pour déterminer la nouvelle coordonnée Y du pointeur.

Chacune des coordonnées X et Y de la structure XkbPtrAction est composée de deux valeurs signées de 16 bits, c'est-à-dire que la coordonnée X est composée de high_XXX et low_XXX, et de même pour la coordonnée Y. Xkb fournit les macros suivantes pour convertir entre un entier signé et deux valeurs signées de 16 bits dans les structures XkbPtrAction.

STRUCTURES

    typedef struct _XkbPtrAction {
        unsigned char    type;         /* XkbSA_MovePtr */
        unsigned char    flags;        /* détermine le type de mouvement du pointeur */
        unsigned char    high_XXX;     /* coordonnée x, bits hauts*/
        unsigned char    low_XXX;      /* coordonnée x, bits bas */
        unsigned char    high_YYY;     /* coordonnée y, bits hauts */
        unsigned char    low_YYY;      /* coordonnée y, bits bas */
    } XkbPtrAction;
