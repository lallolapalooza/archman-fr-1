XkbChangeNames(3) FONCTIONS XKB XkbChangeNames(3)

NOM

XkbChangeNames - Modifier les noms symboliques dans le serveur

SYNTAXE

Bool XkbChangeNames (Display *dpy, unsigned int which, XkbDescPtr xkb);

ARGUMENTS

dpy
connexion au serveur X
which
masque des noms ou des composants de la carte à mettre à jour
xkb
description du clavier à mettre à jour

DESCRIPTION

XkbChangeNames fournit une méthode plus flexible pour modifier les noms symboliques que XkbSetNames et nécessite l'utilisation d'une structure XkbNameChangesRec.

XkbChangeNames copie tous les noms spécifiés par changes depuis la description du clavier, xkb, vers le serveur X spécifié par dpy. XkbChangeNames s'arrête et retourne False si des noms de type illégaux ou des noms de niveaux de décalage de type sont spécifiés par changes.

Pour modifier les noms symboliques dans le serveur, modifiez d'abord une copie locale de la description du clavier, puis utilisez soit XkbSetNames, soit, pour économiser du trafic réseau, utilisez une structure XkbNameChangesRec et appelez XkbChangeNames pour télécharger les modifications vers le serveur. XkbSetNames et XkbChangeNames peuvent générer des erreurs BadAlloc, BadAtom, BadLength, BadMatch et BadImplementation.

STRUCTURES

Le XkbNameChangesRec permet aux applications d'identifier de petites modifications des noms symboliques et réduit efficacement la quantité de trafic envoyée au serveur :

    typedef struct _XkbNameChanges {
        unsigned int   changed;            /* nom des composants qui ont changé */
        unsigned char  first_type;         /* premier type de clé avec un nouveau nom */
        unsigned char  num_types;          /* nombre de types avec de nouveaux noms */
        unsigned char  first_lvl;          /* premier type de clé avec de nouveaux noms de niveau */
        unsigned char  num_lvls;           /* nombre de types de clés avec de nouveaux noms de niveau */
        unsigned char  num_aliases;        /* si les alias de clé ont changé, nombre total d'alias de clé */
        unsigned char  num_rg;             /* si les groupes radio ont changé, nombre total de groupes radio */
        unsigned char  first_key;          /* première clé avec un nouveau nom */
        unsigned char  num_keys;           /* nombre de clés avec de nouveaux noms */
        unsigned short changed_vmods;      /* masque des modificateurs virtuels dont les noms ont changé */
        unsigned long  changed_indicators; /* masque des indicateurs dont les noms ont été changés */
        unsigned char  changed_groups;     /* masque des groupes dont les noms ont été changés */
    } XkbNameChangesRec, *XkbNameChangesPtr

Le champ changed spécifie les composants du nom qui ont changé et est le OU inclusif binaire des bits du masque des noms valides définis dans le Tableau 1. Le reste des champs de la structure spécifie les plages qui ont changé pour les différents types de noms symboliques, comme montré dans le Tableau 2.

Xkb fournit plusieurs fonctions qui fonctionnent avec des noms symboliques. Chacune de ces fonctions utilise un masque pour spécifier les champs individuels des structures décrites ci-dessus. Ces masques et leurs relations avec les champs d'une description de clavier sont montrés dans le Tableau 1.

DIAGNOSTICS

BadAlloc
Impossible d'allouer de l'espace
BadAtom
Un nom n'est ni un Atom valide ni None
BadImplementation
Réponse invalide du serveur
BadLength
La longueur d'une requête est plus courte ou plus longue que celle requise pour contenir minimalement les arguments
BadMatch
Une version compatible de Xkb n'était pas disponible dans le serveur ou un argument a le type et la plage corrects, mais est autrement invalide
