NOM

XkbOpenDisplay - Vérifie la compatibilité des versions de l'extension Xkb dans la bibliothèque et le serveur, et initialise l'extension pour utilisation.

SYNOPSIS

Display *XkbOpenDisplay (_Xconst char *display_name, int *event_rtrn, int *error_rtrn, int *major_in_out, int *minor_in_out, int *reason_rtrn);

ARGUMENTS

display_name
nom de l'affichage matériel, qui détermine l'affichage et le domaine de communication à utiliser
event_rtrn
rempli avec le code d'événement de base de l'extension
error_rtrn
rempli avec le code d'erreur de base de l'extension
major_in_out
version majeure de la bibliothèque au moment de la compilation en entrée, version majeure du serveur en sortie
minor_in_out
version mineure de la bibliothèque au moment de la compilation en entrée, version mineure du serveur en sortie
reason_rtrn
rempli avec un code de statut

DESCRIPTION

Par commodité, vous pouvez utiliser la fonction XkbOpenDisplay pour effectuer ces trois tâches en même temps : ouvrir une connexion à un serveur X, vérifier la compatibilité des versions de l'extension Xkb dans la bibliothèque et le serveur, et initialiser l'extension pour utilisation.

XkbOpenDisplay est une fonction utilitaire qui ouvre une connexion d'affichage X et initialise l'extension du clavier X. Dans tous les cas, au retour, reason_rtrn contient une valeur de statut indiquant le succès ou le type d'échec. Si major_in_out et minor_in_out ne sont pas NULL, XkbOpenDisplay appelle d'abord XkbLibraryVersion pour déterminer si la bibliothèque cliente est compatible, en lui passant les valeurs pointées par major_in_out et minor_in_out. Si la bibliothèque est incompatible, XkbOpenDisplay remplit major_in_out et minor_in_out avec les versions majeure et mineure de l'extension de la bibliothèque utilisée et retourne NULL. Si la bibliothèque est compatible, XkbOpenDisplay appelle ensuite XOpenDisplay avec le display_name. Si cela échoue, la fonction retourne NULL. En cas de succès, XkbOpenDisplay appelle XkbQueryExtension et remplit les numéros de version majeure et mineure du serveur Xkb dans major_in_out et minor_in_out. Si la version du serveur n'est pas compatible avec la version de l'extension de la bibliothèque ou si l'extension du serveur n'est pas présente, XkbOpenDisplay ferme l'affichage et retourne NULL. En cas de succès, la fonction retourne la connexion d'affichage.

Les valeurs possibles pour reason_rtrn sont :

  • XkbOD_BadLibraryVersion indique que XkbLibraryVersion a retourné False.
  • XkbOD_ConnectionRefused indique que l'affichage n'a pas pu être ouvert.
  • XkbOD_BadServerVersion indique que la bibliothèque et le serveur ont des versions d'extension incompatibles.
  • XkbOD_NonXkbServer indique que l'extension n'est pas présente dans le serveur X.
  • XkbOD_Success indique que la fonction a réussi.

VALEUR DE RETOUR

NULL
La fonction XkbOpenDisplay retourne NULL si la bibliothèque est incompatible.


La fonction XkbOpenDisplay retourne NULL si l'appel à XOpenDisplay avec le display_name échoue.


La fonction XkbOpenDisplay retourne NULL et ferme l'affichage si la version de l'extension du serveur n'est pas compatible avec la version de l'extension de la bibliothèque ou si l'extension du serveur n'est pas présente.

DIAGNOSTICS

BadAccess
L'extension Xkb n'a pas été correctement initialisée

VOIR AUSSI

XkbLibraryVersion(3), XkbQueryExtension(3), XOpenDisplay(3)
