XkbChangeEnabledControls(3) FONCTIONS XKB XkbChangeEnabledControls(3)

NOM

XkbChangeEnabledControls - Manipule le contrôle EnabledControls

SYNTAXE

Bool XkbChangeEnabledControls (Display *dpy, unsigned int device_spec, unsigned int mask, unsigned int values);

ARGUMENTS

dpy
connexion au serveur X
device_spec
périphérique clavier à modifier
mask
1 bit -> contrôles à activer / désactiver
values
1 bit => activer, 0 bit => désactiver

DESCRIPTION

Le contrôle EnabledControls est un masque de bits où chaque bit activé signifie que le contrôle correspondant est activé, et désactivé lorsqu'il est éteint. Il correspond au champ enabled_ctrls d'une structure XkbControlsRec (voir STRUCTURES). Les bits décrivant quels contrôles sont activés ou désactivés sont définis dans le Tableau 1.

Le Tableau 1 montre les valeurs réelles des bits de masque individuels utilisés pour sélectionner les contrôles à modifier et pour activer et désactiver le contrôle. Notez que le même bit de masque est utilisé pour spécifier des modifications générales aux paramètres utilisés pour configurer le contrôle (quel), et pour activer et désactiver le contrôle (enabled_ctrls). Les anomalies dans le tableau (pas de "ok" dans la colonne) concernent les contrôles qui n'ont pas d'attributs configurables ; et pour les contrôles qui ne sont pas des contrôles booléens et ne peuvent donc pas être activés ou désactivés.

Tableau 1 Bits de masque des contrôles
Bit de masque quel ou activé Valeur
changed_ctrls _ctrls
XkbRepeatKeysMask ok ok (1L<<0)
XkbSlowKeysMask ok ok (1L<<1)
XkbBounceKeysMask ok ok (1L<<2)
XkbStickyKeysMask ok ok (1L<<3)
XkbMouseKeysMask ok ok (1L<<4)
XkbMouseKeysAccelMask ok ok (1L<<5)
XkbAccessXKeysMask ok ok (1L<<6)
XkbAccessXTimeoutMask ok ok (1L<<7)
XkbAccessXFeedbackMask ok ok (1L<<8)
XkbAudibleBellMask ok (1L<<9)
XkbOverlay1Mask ok (1L<<10)
XkbOverlay2Mask ok (1L<<11)
XkbIgnoreGroupLockMask ok (1L<<12)
XkbGroupsWrapMask ok (1L<<27)
XkbInternalModsMask ok (1L<<28)
XkbIgnoreLockModsMask ok (1L<<29)
XkbPerKeyRepeatMask ok (1L<<30)
XkbControlsEnabledMask ok (1L<<31)
XkbAccessXOptionsMask ok ok (XkbStickyKeysMask |
XkbAccessXFeedbackMask)
XkbAllBooleanCtrlsMask ok (0x00001FFF)
XkbAllControlsMask ok (0xF8001FFF)

Le paramètre mask spécifie les contrôles booléens à activer ou désactiver, et le masque values spécifie le nouvel état de ces contrôles. Les valeurs valides pour ces deux masques sont composées d'une combinaison OU inclusive au niveau du bit des bits pris dans l'ensemble des bits de masque du Tableau 1, en utilisant uniquement les masques avec "ok" dans la colonne enabled_ctrls.

Si le serveur X ne prend pas en charge une version compatible de Xkb ou si l'extension Xkb n'a pas été correctement initialisée, XkbChangeEnabledControls renvoie False ; sinon, il envoie la requête au serveur X et renvoie True.

Notez que le contrôle EnabledControls active et désactive uniquement les contrôles ; il ne les configure pas. Certains contrôles, tels que le contrôle AudibleBell, n'ont pas d'attributs de configuration et sont donc manipulés uniquement en les activant et désactivant. D'autres, cependant, ont des attributs supplémentaires pour configurer leur comportement. Par exemple, le contrôle RepeatControl utilise les champs repeat_delay et repeat_interval pour décrire le comportement temporel des touches qui se répètent. Le comportement de RepeatControl est activé ou désactivé en fonction de la valeur du bit XkbRepeatKeysMask, mais vous devez utiliser d'autres moyens, comme décrit dans ce chapitre, pour configurer son comportement en détail.

VALEURS DE RETOUR

True
Le serveur X prend en charge une version compatible de Xkb.
False
Le serveur X ne prend pas en charge une version compatible de Xkb ou l'extension Xkb n'a pas été correctement initialisée.

STRUCTURES

La structure XkbControlsRec est définie comme suit :
    #define XkbMaxLegalKeyCode     255
    #define XkbPerKeyBitArraySize  ((XkbMaxLegalKeyCode+1)/8)
    typedef struct {
        unsigned char   mk_dflt_btn;      /* bouton par défaut pour la souris pilotée par clavier */
        unsigned char   num_groups;       /* nombre de groupes de clavier */
        unsigned char   groups_wrap;      /* comment faire pivoter les groupes hors limites */
        XkbModsRec      internal;         /* définit les modificateurs internes du serveur */
        XkbModsRec      ignore_lock;      /* modificateurs à ignorer lors de la vérification des saisies */
        unsigned int    enabled_ctrls;    /* 1 bit => contrôle booléen correspondant activé */
        unsigned short  repeat_delay;     /* délai en ms avant la première répétition */
        unsigned short  repeat_interval;  /* délai en ms entre les répétitions */
        unsigned short  slow_keys_delay;  /* délai minimum en ms pendant lequel la touche doit être enfoncée pour être valide */
        unsigned short  debounce_delay;   /* délai en ms avant la réactivation de la touche */
        unsigned short  mk_delay;         /* délai en ms pour le deuxième événement de mouvement de souris */
        unsigned short  mk_interval;      /* délai en ms entre les événements de répétition de la souris */
        unsigned short  mk_time_to_max;   /* nombre d'intervalles avant le mouvement constant de la souris */
        unsigned short  mk_max_speed;     /* multiplicateur pour la vitesse maximale de la souris */
        short           mk_curve;         /* détermine le type de courbe de mouvement de la souris */
        unsigned short  ax_options;       /* 1 bit => option Access X activée */
        unsigned short  ax_timeout;       /* secondes jusqu'à ce que Access X soit désactivé */
        unsigned short  axt_opts_mask;    /* 1 bit => options à réinitialiser lors du délai d'expiration Access X */
        unsigned short  axt_opts_values;  /* 1 bit => activer l'option, 0=> désactiver */
        unsigned int    axt_ctrls_mask;   /* quels bits dans enabled_ctrls modifier */
        unsigned int    axt_ctrls_values; /* valeurs pour les nouveaux bits dans enabled_ctrls */
        unsigned char   per_key_repeat[XkbPerKeyBitArraySize];  /* répétition automatique par touche */
     } XkbControlsRec, *XkbControlsPtr;
