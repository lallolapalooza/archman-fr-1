XkbGetMap(3) FONCTIONS XKB XkbGetMap(3)

NOM

XkbGetMap - Alloue une structure XkbDescRec et la remplit avec la carte client et la carte serveur du clavier du serveur

SYNTAXE

XkbDescPtr XkbGetMap (Display *display, unsigned int which, unsigned int device_spec);

ARGUMENTS

display
connexion au serveur X
which
masque sélectionnant les sous-composants à remplir
device_spec
spécificateur de périphérique, ou XkbUseCoreKbd

DESCRIPTION

Xkb fournit deux fonctions pour obtenir les composants de la carte du clavier depuis le serveur. La première fonction, XkbGetMap, alloue une structure XkbDescRec, récupère les composants de la carte depuis le serveur, et les stocke dans la structure XkbDescRec qu'elle vient d'allouer. La seconde fonction, XkbGetUpdatedMap, récupère les composants de la carte depuis le serveur et les stocke dans une structure XkbDescRec qui a été préalablement allouée.

Pour allouer une structure XkbDescRec et la remplir avec la carte client et la carte serveur du clavier du serveur, utilisez XkbGetMap. XkbGetMap est similaire à XkbGetKeyboard, mais est utilisée uniquement pour obtenir l'adresse d'une structure XkbDescRec qui est remplie avec les composants de la carte du clavier. Elle permet un contrôle plus fin sur quelles sous-structures des composants de la carte du clavier doivent être remplies. XkbGetKeyboard retourne toujours des composants entièrement remplis, tandis que XkbGetMap peut être instruite pour retourner un composant partiellement rempli.

Le masque which est un OU exclusif (bitwise) des masques définis dans le Tableau 14.1. Seules les portions de la carte serveur du clavier et des cartes client du clavier qui sont spécifiées dans which sont allouées et remplies.

En plus d'allouer et d'obtenir la carte serveur et la carte client, XkbGetMap définit également les champs device_spec, min_key_code, et max_key_code de la description du clavier.

XkbGetMap est synchrone ; elle interroge le serveur pour les informations souhaitées, attend une réponse, puis retourne. En cas de succès, XkbGetMap retourne un pointeur vers la structure XkbDescRec qu'elle a allouée. En cas d'échec, XkbGetMap retourne NULL. En cas d'échec, l'une des erreurs de protocole suivantes est également générée : BadAlloc (incapacité d'allouer la structure XkbDescRec), BadValue (certains bits du masque dans which sont indéfinis), ou BadImplementation (une version compatible de l'extension Xkb n'est pas disponible sur le serveur). Pour libérer les données retournées, utilisez XkbFreeKeyboard.

Xkb fournit également des fonctions pratiques pour obtenir des définitions de composants partielles depuis le serveur. Ces fonctions sont spécifiées dans la colonne "fonctions pratiques" du Tableau 1. Reportez-vous aux sections listées dans le tableau pour plus d'informations sur ces fonctions.

Les types de touches, les cartes de symboles et les actions sont tous interdépendants : les changements dans l'un nécessitent des changements dans les autres. Les fonctions pratiques facilitent la modification de ces composants et la gestion des interdépendances.

STRUCTURES

La description complète d'un clavier Xkb est donnée par une XkbDescRec. Les structures de composants dans la XkbDescRec représentent les principaux composants Xkb.

typedef struct {
   struct _XDisplay * display;      /* connexion au serveur X */
   unsigned short     flags;        /* privé à Xkb, ne pas modifier */
   unsigned short     device_spec;  /* périphérique concerné */
   KeyCode            min_key_code; /* code de touche minimum pour le périphérique */
   KeyCode            max_key_code; /* code de touche maximum pour le périphérique */
   XkbControlsPtr     ctrls;        /* contrôles */
   XkbServerMapPtr    server;       /* carte de touches serveur */
   XkbClientMapPtr    map;          /* carte de touches client */
   XkbIndicatorPtr    indicators;   /* carte d'indicateurs */
   XkbNamesPtr        names;        /* noms de tous les composants */
   XkbCompatMapPtr    compat;       /* carte de compatibilité */
   XkbGeometryPtr     geom;         /* géométrie physique du clavier */
} XkbDescRec, *XkbDescPtr;
Le champ display pointe vers une structure d'affichage X. Le champ flags est privé à la bibliothèque : modifier flags peut produire des résultats imprévisibles. Le champ device_spec spécifie l'identifiant du périphérique d'entrée du clavier, ou XkbUseCoreKeyboard, qui spécifie le périphérique clavier principal. Les champs min_key_code et max_key_code spécifient le code de touche le plus bas et le plus élevé qui peut être retourné par le clavier.

Chaque composant structurel a un bit de masque correspondant qui est utilisé dans les appels de fonction pour indiquer que la structure doit être manipulée d'une certaine manière, comme l'allouer ou la libérer. Ces masques et leurs relations avec les champs de la XkbDescRec sont présentés dans le Tableau 2.
