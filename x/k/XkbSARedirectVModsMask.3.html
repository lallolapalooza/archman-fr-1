NOM

XkbSARedirectVModsMask - Retourne les champs vmods_mask0 et vmods_mask1 de act convertis en entier non signé

SYNTAXE

unsigned int XkbSARedirectVModsMask (XkbRedirectKeyAction act);

ARGUMENTS

act
action à partir de laquelle extraire vmods

DESCRIPTION

Les actions associées à la structure XkbRedirectKeyAction génèrent des événements KeyPress et KeyRelease contenant un code de touche différent de celui qui a été pressé ou relâché.

Le champ type de la structure XkbRedirectKeyAction doit toujours être XkbSA_RedirectKey. Les pressions de touches provoquent un événement KeyPress pour la touche spécifiée par le champ new_key au lieu de la touche réelle. L'état rapporté dans cet événement indique les modificateurs effectifs actuels modifiés comme suit : tous les modificateurs réels sélectionnés par le champ mods_mask sont définis aux valeurs correspondantes du champ mods. Tous les modificateurs réels liés aux modificateurs virtuels spécifiés par les champs vmods_mask0 et vmods_mask1 sont soit définis, soit effacés, en fonction des valeurs correspondantes dans les champs vmods0 et vmods1. Si les définitions de modificateurs réels et virtuels spécifient des valeurs conflictuelles pour un seul modificateur, la définition du modificateur réel a la priorité.

Les relâchements de touches provoquent un événement KeyRelease pour la touche spécifiée par le champ new_key au lieu de la touche réelle. L'état de cet événement consiste en les modificateurs de clavier effectifs au moment du relâchement, modifiés comme décrit précédemment.

L'action XkbSA_RedirectKey redirige normalement vers une autre touche du même périphérique que la touche qui a provoqué l'événement, sauf si ce périphérique n'appartient pas à la classe de touches KeyClass de l'extension d'entrée, auquel cas cette action provoque un événement sur le périphérique clavier principal. (L'extension d'entrée catégorise les périphériques en les brisant en classes. Les claviers, et autres périphériques d'entrée avec des touches, sont classés comme périphériques KeyClass par l'extension d'entrée.)

Les champs vmods_mask0 et vmods_mask1 représentent en fait une seule valeur vmods_mask. Xkb fournit des macros pour convertir entre les deux formats.

XkbSARedirectVModsMask retourne les champs vmods_mask0 et vmods_mask1 de act convertis en un entier non signé.

STRUCTURES

    typedef struct_XkbRedirectKeyAction {
        unsigned char   type;        /* XkbSA_RedirectKey */
        unsigned char   new_key;     /* code de touche à insérer dans l'événement */
        unsigned char   mods_mask;   /* masque des modificateurs réels à réinitialiser */
        unsigned char   mods;        /* masque des modificateurs réels à partir desquels prendre les valeurs */
        unsigned char   vmods_mask0; /* première moitié du masque des modificateurs virtuels à réinitialiser */
        unsigned char   vmods_mask1; /* autre moitié du masque des modificateurs virtuels à réinitialiser */
        unsigned char   vmods0;      /* première moitié du masque des modificateurs virtuels à partir desquels prendre les valeurs */
        unsigned char   vmods1;      /* autre moitié du masque des modificateurs virtuels à partir desquels prendre les valeurs */
    } XkbRedirectKeyAction;
