XkbChangeDeviceInfo(3) FONCTIONS XKB XkbChangeDeviceInfo(3)

NOM

XkbChangeDeviceInfo - Mettre à jour la description par le serveur d'un périphérique avec les changements notés dans un XkbDeviceChangesRec

SYNTAXE

Bool XkbChangeDeviceInfo (Display *dpy, XkbDeviceInfoPtr device_info, XkbDeviceChangesPtr changes);

ARGUMENTS

dpy
connexion au serveur X
device_info
copie locale de l'état et de la configuration du périphérique
changes
note spécifiant les changements dans device_info

DESCRIPTION

XkbChangeDeviceInfo met à jour la description par le serveur du périphérique spécifié dans device_info->device_spec avec les changements spécifiés dans changes et contenus dans device_info. La mise à jour est effectuée par une requête XkbSetDeviceInfo.

STRUCTURES

Les changements apportés à un périphérique d'extension Xkb peuvent être suivis en écoutant les événements XkbDeviceExtensionNotify et en accumulant les changements dans une structure XkbDeviceChangesRec. Les changements notés dans la structure peuvent ensuite être utilisés dans des opérations ultérieures pour mettre à jour soit une configuration du serveur, soit une copie locale d'une configuration de périphérique d'extension Xkb. La structure des changements est définie comme suit :

typedef struct _XkbDeviceChanges {
    unsigned int         changed;        /* bits indiquant ce qui a changé */
    unsigned short       first_btn;      /* numéro du premier bouton qui a changé, le cas échéant */
    unsigned short       num_btns;       /* nombre de boutons qui ont changé */
    XkbDeviceLedChangesRec leds;
} XkbDeviceChangesRec,*XkbDeviceChangesPtr;
