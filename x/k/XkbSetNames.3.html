XkbSetNames(3) FONCTIONS XKB XkbSetNames(3)

NOM

XkbSetNames - Changer les noms symboliques dans le serveur

SYNOPSIS

Bool XkbSetNames (Display *dpy, unsigned int which, unsigned int first_type, unsigned int num_types, XkbDescPtr xkb);

ARGUMENTS

dpy
connexion au serveur X
which
masque des noms ou des composants de la carte à modifier
first_type
premier type dont le nom doit être modifié
num_types
nombre de types dont les noms doivent être modifiés
xkb
description du clavier à partir de laquelle les noms doivent être pris

DESCRIPTION

Pour changer les noms symboliques dans le serveur, modifiez d'abord une copie locale de la description du clavier, puis utilisez soit XkbSetNames, soit, pour économiser le trafic réseau, utilisez une structure XkbNameChangesRec et appelez XkbChangeNames pour télécharger les modifications vers le serveur. XkbSetNames et XkbChangeNames peuvent générer des erreurs BadAlloc, BadAtom, BadLength, BadMatch et BadImplementation.

Utilisez XkbSetNames pour changer plusieurs noms en même temps. Pour chaque bit défini dans which, XkbSetNames prend la valeur correspondante (ou les valeurs dans le cas des tableaux) de la description du clavier xkb et l'envoie au serveur.

Les arguments first_type et num_types sont utilisés uniquement si XkbKeyTypeNamesMask ou XkbKTLevelNamesMask est défini dans which et spécifient un sous-ensemble des types pour lesquels les noms correspondants doivent être modifiés. Si l'un ou les deux de ces bits de masque sont définis mais que les types spécifiés sont illégaux, XkbSetNames retourne False et ne met à jour aucun des noms spécifiés dans which. Les types spécifiés sont illégaux si xkb n'inclut pas de composant de carte ou si first_type et num_types spécifient des types qui ne sont pas définis dans la description du clavier.

STRUCTURES

Le XkbNameChangesRec permet aux applications d'identifier de petites modifications des noms symboliques et réduit efficacement la quantité de trafic envoyée au serveur :

    typedef struct _XkbNameChanges {
        unsigned int   changed;          /* composants de nom qui ont changé */
        unsigned char  first_type;       /* premier type avec un nouveau nom */
        unsigned char  num_types;        /* nombre de types avec de nouveaux noms */
        unsigned char  first_lvl;        /* premier type de niveau avec de nouveaux noms */
        unsigned char  num_lvls;         /* nombre de types de niveau avec de nouveaux noms */
        unsigned char  num_aliases;      /* si les alias de touches ont changé, nombre total d'alias de touches */
        unsigned char  num_rg;           /* si les groupes radio ont changé, nombre total de groupes radio */
        unsigned char  first_key;        /* première touche avec un nouveau nom */
        unsigned char  num_keys;         /* nombre de touches avec de nouveaux noms */
        unsigned short changed_vmods;    /* masque des modificateurs virtuels pour lesquels les noms ont changé */
        unsigned long  changed_indicators; /* masque des indicateurs pour lesquels les noms ont été modifiés */
        unsigned char  changed_groups;     /* masque des groupes pour lesquels les noms ont été modifiés */
    } XkbNameChangesRec, *XkbNameChangesPtr

Le champ changed spécifie les composants de nom qui ont changé et est l'OU inclusif au niveau du bit des bits de masque valides pour les noms définis dans le Tableau 1. Le reste des champs de la structure spécifie les plages qui ont changé pour les différents types de noms symboliques, comme indiqué dans le Tableau 2.

Xkb fournit plusieurs fonctions qui fonctionnent avec des noms symboliques. Chacune de ces fonctions utilise un masque pour spécifier des champs individuels des structures décrites ci-dessus. Ces masques et leurs relations avec les champs d'une description de clavier sont indiqués dans le Tableau 1.

XkbSetNames(3)

NOM

XkbSetNames — configurer les noms pour les touches et les modificateurs Xkb.

SYNTAXE

void XkbSetNames(Display *display, unsigned int affect,
                 XkbNameTypePtr names);

ARGUMENTS

display
Un pointeur vers la structure Display.
affect
Une liste de drapeaux spécifiant les types de noms à modifier. XkbKeyNames, XkbKeyAliases, XkbModifierNames.
names
Un pointeur vers la structure XkbNameTypePtr contenant les noms.

DESCRIPTION

XkbSetNames configure les noms pour les touches et les modificateurs pour le clavier Xkb.

Les arguments affect spécifient quels noms doivent être modifiés. Les drapeaux possibles sont :

XkbKeyNames
Les noms des touches.
XkbKeyAliases
Les alias des touches.
XkbModifierNames
Les noms des modificateurs.

La structure XkbNameTypePtr est définie dans XkbLib.h comme suit :

STRUCTURES

XkbNameTypePtr est un pointeur vers une structure qui contient une liste de chaînes de caractères.

typedef struct {
    unsigned int    n_names;
    char            **names;
} XkbNameType;
typedef XkbNameType *XkbNameTypePtr;

typedef struct {
    XkbNameTypePtr  key_names;
    XkbNameTypePtr  key_aliases;
    XkbNameTypePtr  modifier_names;
} XkbNamedArray;
typedef XkbNamedArray *XkbNamedArrayPtr;

DIAGNOSTICS

BadLength
La longueur d'une requête est plus courte ou plus longue que ce qui est requis pour contenir minimalement les arguments.
BadMatch
Une version compatible de Xkb n'était pas disponible sur le serveur ou un argument a un type et une plage corrects, mais est par ailleurs invalide.
