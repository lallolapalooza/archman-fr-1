XkbGetKeyVirtualModMap(3) FONCTIONS XKB XkbGetKeyVirtualModMap(3)

NOM

XkbGetKeyVirtualModMap - Obtenir la carte des modificateurs virtuels (le tableau vmodmap) pour un sous-ensemble des touches d'une description de clavier

SYNTAXE

Status XkbGetKeyVirtualModMap (Display *dpy, unsigned int first, unsigned int num, XkbDescPtr xkb);

ARGUMENTS

dpy
connexion au serveur
first
code de touche de la première touche à récupérer
num
nombre de touches pour lesquelles les cartes de modificateurs virtuels sont désirées
xkb
description Xkb où les résultats seront placés

DESCRIPTION

XkbGetKeyVirutalModmap envoie une requête au serveur pour obtenir les mappages des modificateurs virtuels pour num touches du clavier à partir de la touche first. Elle attend une réponse et retourne les mappages des modificateurs virtuels dans le tableau server->vmodmap de xkb. En cas de succès, XkbGetKeyVirtualModMap retourne Success. Le paramètre xkb doit être un pointeur vers une description de clavier Xkb valide.

Si la carte server dans le paramètre xkb n'a pas été allouée, XkbGetKeyVirtualModMap l'alloue et l'initialise avant d'obtenir les mappages des modificateurs virtuels.

Si le serveur n'a pas une version compatible de Xkb, ou si l'extension Xkb n'a pas été correctement initialisée, XkbGetKeyVirtualModMap retourne BadMatch. Si num est inférieur à 1 ou supérieur à XkbMaxKeyCount, XkbGetKeyVirtualModMap retourne BadValue. Si des erreurs d'allocation se produisent, XkbGetKeyVirtualModMap retourne BadAlloc.

VALEURS DE RETOUR

Success
La fonction XkbGetKeyVirutalModmap retourne Success suite à une réponse réussie du serveur pour obtenir les mappages des modificateurs virtuels pour num touches du clavier à partir de la touche first.

DIAGNOSTICS

BadAlloc
Impossible d'allouer de l'espace
BadMatch
Une version compatible de Xkb n'était pas disponible sur le serveur ou un argument a un type et une plage corrects, mais est invalide par ailleurs
BadValue
Un argument est hors plage
