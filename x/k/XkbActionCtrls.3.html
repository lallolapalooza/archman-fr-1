XkbActionCtrls(3) FONCTIONS Xkb XkbActionCtrls(3)

NOM

XkbActionCtrls - Retourne les champs ctrls de act convertis en un entier non signé

SYNTAXE

unsigned int XkbActionCtrls (XkbCtrlsAction act);

ARGUMENTS

act
action dont il faut extraire les contrôles

DESCRIPTION

Les actions associées à la structure XkbCtrlsAction modifient l'état des contrôles booléens.

Le champ type peut prendre l'une des valeurs indiquées dans le Tableau 1.

Tableau 1 Types d'actions de contrôle
Type Effet
XkbSA_SetControls Une pression de touche active tous les contrôles booléens spécifiés dans les champs ctrls qui n'étaient pas déjà actifs au moment de la pression de touche. Un relâchement de touche désactive tous les contrôles activés par la pression de touche. Cette action peut générer des événements XkbControlsNotify.
XkbSA_LockControls Si le bit XkbSA_LockNoLock n'est pas défini dans le champ flags, une pression de touche active tous les contrôles spécifiés dans les champs ctrls qui n'étaient pas déjà actifs au moment de la pression de touche. Si le bit XkbSA_LockNoUnlock n'est pas défini dans le champ flags, un relâchement de touche désactive tous les contrôles spécifiés dans les champs ctrls qui n'étaient pas déjà désactivés au moment du relâchement de touche. Cette action peut générer des événements XkbControlsNotify.

Le champ flags est composé de l'OU inclusif par bit des masques indiqués dans le Tableau 2.

Tableau 2 Indicateurs d'actions de contrôle
Indicateur Signification
XkbSA_LockNoLock S'il est défini, et que le type d'action est XkbSA_LockControls, le serveur ne désactive que les contrôles.
XkbSA_LockNoUnlock S'il est défini, et que le type d'action est XkbSA_LockControls, le serveur n'active que les contrôles.

L'action XkbSA_SetControls implémente une touche qui active un contrôle booléen lorsqu'elle est pressée et le désactive lorsqu'elle est relâchée. L'action XkbSA_LockControls est utilisée pour implémenter une touche qui inverse l'état d'un contrôle booléen à chaque pression et relâchement. Les indicateurs XkbSA_LockNoLock et XkbSA_LockNoUnlock permettent de modifier le comportement d'inversion pour ne déverrouiller ou ne verrouiller que le contrôle booléen.

Les champs ctrls0, ctrls1, ctrls2, et ctrls3 représentent les contrôles booléens dans le champ enabled_ctrls de la structure controls. Macros Xkb, pour convertir entre les deux formats.

XkbActionCtrls retourne les champs ctrls de act convertis en un entier non signé.

STRUCTURES

    typedef struct _XkbCtrlsAction {
        unsigned char    type;    /* XkbSA_SetControls, XkbSA_LockControls */
        unsigned char    flags;   /* avec le type, active et désactive les contrôles */
        unsigned char    ctrls3;  /* ctrls0 à ctrls3 représentent les contrôles booléens */
        unsigned char    ctrls2;  /* ctrls0 à ctrls3 représentent les contrôles booléens */
        unsigned char    ctrls1;  /* ctrls0 à ctrls3 représentent les contrôles booléens */
        unsigned char    ctrls0;  /* ctrls0 à ctrls3 représentent les contrôles booléens */
    } XkbCtrlsAction;
