XkbSetAutoResetControls(3) FONCTIONS XKB XkbSetAutoResetControls(3)

NOM

XkbSetAutoResetControls - Modifie les valeurs actuelles des attributs de réinitialisation automatique

SYNOPSIS

Bool XkbSetAutoResetControls (Display *dpy, unsigned int changes, unsigned int *auto_ctrls, unsigned int *auto_values);

ARGUMENTS

dpy
connexion au serveur X
changes
contrôles dont les valeurs de réinitialisation automatique doivent être modifiées
auto_ctrls
contrôles issus des changements qui doivent être réinitialisés automatiquement
auto_values
1 bit => réinitialisation automatique activée

DESCRIPTION

XkbSetAutoResetControls modifie le statut de réinitialisation automatique et les valeurs associées pour les contrôles sélectionnés par changes. Pour tout contrôle sélectionné par changes, si le bit correspondant est activé dans auto_ctrls, le contrôle est configuré pour se réinitialiser automatiquement à la sortie du client. Si le bit correspondant dans auto_values est activé, le contrôle est activé à la sortie du client ; s'il est à zéro, le contrôle est désactivé à la sortie du client. Pour tout contrôle sélectionné par changes, si le bit correspondant n'est pas activé dans auto_ctrls, le contrôle est configuré pour ne pas se réinitialiser à la sortie du client.

Par exemple :

Pour laisser les contrôles de réinitialisation automatique de StickyKeys tels quels :
	ok = XkbSetAutoResetControls(dpy, 0, 0, 0);

Pour modifier les contrôles de réinitialisation automatique afin que StickyKeys ne soit pas affecté à la sortie du client :
	ok = XkbSetAutoResetControls(dpy, XkbStickyKeysMask, 0, 0);

Pour modifier les contrôles de réinitialisation automatique afin que StickyKeys soit désactivé à la sortie du client :
	ok = XkbSetAutoResetControls(dpy, XkbStickyKeysMask, XkbStickyKeysMask, 0);

Pour modifier les contrôles de réinitialisation automatique afin que StickyKeys soit activé à la sortie du client :
	ok = XkbSetAutoResetControls(dpy, XkbStickyKeysMask, XkbStickyKeysMask, 
XkbStickyKeysMask);
XkbSetAutoResetControls remplit également auto_ctrls et auto_values avec les contrôles de réinitialisation automatique pour ce client particulier. Notez que tous les bits sont valides dans les valeurs retournées, pas seulement ceux sélectionnés dans le masque changes.
