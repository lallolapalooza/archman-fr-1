XkbAddGeomKeyAlias(3) FONCTIONS XKB XkbAddGeomKeyAlias(3)

NOM

XkbAddGeomKeyAlias - Ajoute un alias de touche à une description de géométrie de clavier existante

SYNTAXE

XkbKeyAliasPtr XkbAddGeomKeyAlias (XkbGeometryPtr geom, _Xconst char *alias, _Xconst char *real);

ARGUMENTS

geom
géométrie à mettre à jour
alias
alias à ajouter
real
nom réel à associer au nouvel alias

DESCRIPTION

Xkb fournit des fonctions pour ajouter un nouvel élément unique à la géométrie de clavier de haut niveau. Dans chaque cas, les champs num_* de la structure correspondante sont incrémentés de 1. Ces fonctions ne modifient pas sz_* à moins qu'il n'y ait plus de place dans le tableau. Certaines de ces fonctions remplissent les valeurs de la structure de l'élément à partir des arguments. Pour d'autres fonctions, vous devez écrire explicitement du code pour remplir les éléments de la structure.

La description de la géométrie de haut niveau inclut une liste de propriétés de géométrie. Une propriété de géométrie associe une chaîne de caractères arbitraire à un nom arbitraire. Les programmes qui affichent des images de claviers peuvent utiliser les propriétés de géométrie comme indices, mais elles ne sont pas interprétées par Xkb. Aucune autre structure de géométrie ne fait référence aux propriétés de géométrie.

XkbAddGeomKeyAlias ajoute un alias de touche avec la valeur alias à la géométrie geom, et l'associe à la touche dont le nom réel est real. XkbAddGeomKeyAlias retourne NULL si l'un des paramètres est vide ou s'il n'a pas pu allouer d'espace pour l'alias. Pour allouer de l'espace pour un nombre arbitraire d'alias, utilisez la fonction XkbAllocGeomKeyAliases.

STRUCTURES

    typedef struct {
        char            real[XkbKeyNameLength];   /* ce nom de touche doit être dans le tableau keys */
        char            alias[XkbKeyNameLength];  /* nom de touche symbolique comme alias pour la touche */
    } XkbKeyAliasRec,*XkbKeyAliasPtr;
