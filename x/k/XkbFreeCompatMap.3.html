XkbFreeCompatMap(3) FONCTIONS XKB XkbFreeCompatMap(3)

NOM

XkbFreeCompatMap - Libérer une carte de compatibilité entière ou des parties sélectionnées d'une carte.

SYNTAXE

void XkbFreeCompatMap (XkbDescPtr xkb, unsigned int which, Bool free_map);

ARGUMENTS

xkb
Description Xkb dans laquelle libérer la carte de compatibilité.
which
Masque des composants de la carte de compatibilité à libérer.
free_map
True => libérer la structure XkbCompatMap elle-même.

DESCRIPTION

which spécifie les composants de la carte de compatibilité à libérer (voir XkbGetCompatMap). which est un OU inclusif des bits montrés dans le Tableau 1.

Tableau 1 Masques de composants de la carte de compatibilité
Masque Valeur Affectation
XkbSymInterpMask (1<<0) Interprétations de symboles
XkbGroupCompatMask (1<<1) Cartes de groupes
XkbAllCompatMask (0x3) Tous les composants de la carte de compatibilité

free_map indique si la structure XkbCompatMap elle-même doit être libérée. Si free_map est True, which est ignoré, tous les composants de la carte de compatibilité non NULL sont libérés, et le champ compat dans le XkbDescRec référencé par xkb est mis à NULL.

STRUCTURES

    typedef struct _XkbCompatMapRec {
        XkbSymInterpretPtr    sym_interpret;            /* sémantique des touches basée sur les symboles */
        XkbModsRec            groups[XkbNumKbdGroups];  /* groupe => carte des modificateurs */
        unsigned short        num_si;                   /* # structures utilisées dans sym_interpret */
        unsigned short        size_si;                  /* # structures allouées dans sym_interpret */
    } XkbCompatMapRec, *XkbCompatMapPtr;

La description complète d'un clavier Xkb est donnée par un XkbDescRec. Les structures de composants dans le XkbDescRec représentent les principaux composants Xkb décrits dans la Figure 1.1.

typedef struct {
   struct _XDisplay * display;      /* connexion au serveur X */
   unsigned short     flags;        /* privé à Xkb, ne pas modifier */
   unsigned short     device_spec;  /* appareil concerné */
   KeyCode            min_key_code; /* code de touche minimum pour l'appareil */
   KeyCode            max_key_code; /* code de touche maximum pour l'appareil */
   XkbControlsPtr     ctrls;        /* contrôles */
   XkbServerMapPtr    server;       /* carte de touches du serveur */
   XkbClientMapPtr    map;          /* carte de touches du client */
   XkbIndicatorPtr    indicators;   /* carte des indicateurs */
   XkbNamesPtr        names;        /* noms pour tous les composants */
   XkbCompatMapPtr    compat;       /* carte de compatibilité */
   XkbGeometryPtr     geom;         /* géométrie physique du clavier */
} XkbDescRec, *XkbDescPtr;
Le champ display pointe vers une structure d'affichage X. Le champ flags est privé à la bibliothèque : modifier flags peut produire des résultats imprévisibles. Le champ device_spec spécifie l'identifiant de l'appareil d'entrée du clavier, ou XkbUseCoreKeyboard, qui spécifie l'appareil clavier principal. Les champs min_key_code et max_key_code spécifient le code de touche le plus bas et le plus élevé pouvant être retourné par le clavier. Les autres champs spécifient des structures composantes de la description du clavier et sont décrits en détail dans d'autres sections de ce document. Le Tableau 2 identifie les sections suivantes de ce document qui traitent des composants individuels du XkbDescRec.
Tableau 2 Références aux composants de XkbDescRec
Champ XkbDescRec Pour plus d'informations
ctrls Chapitre 10
server Chapitre 16
map Chapitre 15
indicators Chapitre 8
names Chapitre 18
compat Chapitre 17
geom Chapitre 13

Chaque composant de structure a un bit de masque correspondant qui est utilisé dans les appels de fonction pour indiquer que la structure doit être manipulée d'une manière ou d'une autre, telle que son allocation ou sa libération. Ces masques et leurs relations avec les champs du XkbDescRec sont montrés dans le Tableau 3.

Tableau 3 Bits de masque pour XkbDescRec
Bit de masque Champ XkbDescRec Valeur
XkbControlsMask ctrls (1L<<0)
XkbServerMapMask server (1L<<1)
XkbIClientMapMask map (1L<<2)
XkbIndicatorMapMask indicators (1L<<3)
XkbNamesMask names (1L<<4)
XkbCompatMapMask compat (1L<<5)
XkbGeometryMask geom (1L<<6)
XkbAllComponentsMask Tous les champs (0x7f)
