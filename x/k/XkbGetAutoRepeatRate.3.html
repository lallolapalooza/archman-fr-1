XkbGetAutoRepeatRate(3) FONCTIONS XKB XkbGetAutoRepeatRate(3)

NOM

XkbGetAutoRepeatRate - Obtient les attributs actuels du contrôle RepeatKeys pour un périphérique clavier

SYNTAXE

Bool XkbGetAutoRepeatRate (Display *display, unsigned int device_spec, unsigned int *timeout_rtrn, unsigned int *interval_rtrn);

ARGUMENTS

display
connexion au serveur X
device_spec
identifiant du périphérique souhaité, ou XkbUseCoreKbd
timeout_rtrn
rempli avec le délai initial de répétition, ms
interval_rtrn
rempli avec le délai de répétition subséquent, ms

DESCRIPTION

Le protocole de base ne permet de contrôler que si le clavier entier ou des touches individuelles doivent se répéter automatiquement lorsqu'elles sont maintenues enfoncées. RepeatKeys est un contrôle booléen qui étend cette capacité en ajoutant le contrôle du délai avant qu'une touche ne commence à se répéter et de la fréquence à laquelle elle se répète. RepeatKeys est couplé au contrôle d'auto-répétition de base : lorsque RepeatKeys est activé ou désactivé, l'auto-répétition de base est activée ou désactivée et vice versa.

Les touches en auto-répétition sont contrôlées par deux attributs. Le premier, timeout, est le délai entre la pression initiale d'une touche en auto-répétition et le premier événement de répétition généré. Le second, interval, est le délai entre tous les événements de répétition subséquents générés. Comme pour tous les contrôles booléens, la configuration des attributs qui déterminent le fonctionnement du contrôle n'active pas automatiquement le contrôle dans son ensemble.

XkbGetAutoRepeatRate interroge le serveur pour obtenir les valeurs actuelles des attributs du contrôle RepeatControls, remplit timeout_rtrn et interval_rtrn avec ces valeurs, et retourne True. Si une version compatible de l'extension Xkb n'est pas disponible sur le serveur, XkbGetAutoRepeatRate retourne False.

VALEURS DE RETOUR

True
La fonction XkbGetAutoRepeatRate retourne True si une version compatible de l'extension Xkb est disponible sur le serveur.
False
La fonction XkbGetAutoRepeatRate retourne False si une version compatible de l'extension Xkb n'est pas disponible sur le serveur.
