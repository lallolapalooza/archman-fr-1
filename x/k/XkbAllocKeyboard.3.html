XkbAllocKeyboard(3) FONCTIONS XKB XkbAllocKeyboard(3)

NOM

XkbAllocKeyboard - Crée une description de clavier à partir de zéro

SYNTAXE

XkbDescRec XkbAllocKeyboard (void);

DESCRIPTION

Les applications ont rarement besoin d'allouer directement une description de clavier ; appeler XkbGetKeyboard suffit généralement. Cependant, si vous avez besoin de créer une description de clavier à partir de zéro, utilisez XkbAllocKeyboard plutôt que d'appeler directement malloc.

Si XkbAllocKeyboard ne parvient pas à allouer la description du clavier, il renvoie NULL. Sinon, il renvoie un pointeur vers une structure de description de clavier vide. Le champ device_spec aura été initialisé à XkbUseCoreKbd. Vous pouvez alors soit remplir les composants de la structure, soit utiliser les fonctions Xkb pour obtenir les valeurs des composants de la structure à partir d'un périphérique clavier.

VOIR AUSSI

malloc(3F), XkbUseCoreKbd(3), XkbGetKeyboard(3)
