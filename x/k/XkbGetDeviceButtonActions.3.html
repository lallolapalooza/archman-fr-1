XkbGetDeviceButtonActions(3) FONCTIONS XKB XkbGetDeviceButtonActions(3)

NOM

XkbGetDeviceButtonActions - Interroger les actions de boutons associées à un périphérique d'extension d'entrée X

SYNTAXE

Status XkbGetDeviceButtonActions (Display *dpy, XkbDeviceInfoPtr device_info, Bool all_buttons, unsigned int first_button, unsigned int num_buttons);

ARGUMENTS

dpy
connexion au serveur X
device_info
structure à mettre à jour avec les résultats
all_buttons
Vrai => obtenir des informations pour tous les boutons
first_button
numéro du premier bouton pour lequel des informations sont désirées
num_buttons
nombre de boutons pour lesquels des informations sont désirées

DESCRIPTION

XkbGetDeviceButtonActions interroge le serveur pour les informations de bouton désirées pour le périphérique indiqué par le champ device_spec de device_info et attend une réponse. En cas de succès, XkbGetDeviceButtonActions remplit les actions de bouton (champ btn_acts de device_info) uniquement pour les boutons demandés, met à jour les champs name, type, supported, et unsupported, et renvoie Success.

all_buttons, first_button et num_buttons spécifient les boutons du périphérique pour lesquels les actions doivent être renvoyées. Définir all_buttons à Vrai demande les actions pour tous les boutons du périphérique ; si all_buttons est Faux, first_button et num_buttons spécifient une plage de boutons pour lesquels les actions sont demandées.

Si une version compatible de Xkb n'est pas disponible sur le serveur ou si l'extension Xkb n'a pas été correctement initialisée, XkbGetDeviceButtonActions renvoie BadAccess. Si des erreurs d'allocation se produisent, un statut BadAlloc est renvoyé. Si le périphérique spécifié (device_info->device_spec) est invalide, un statut BadKeyboard est renvoyé. Si le périphérique n'a pas de boutons, un statut BadMatch est renvoyé. Si first_button et num_buttons spécifient des boutons illégaux, un statut BadValue est renvoyé.

DIAGNOSTICS

BadAccess
L'extension Xkb n'a pas été correctement initialisée
BadAlloc
Impossible d'allouer du stockage
BadKeyboard
Le périphérique spécifié n'était pas un périphérique de base ou d'extension d'entrée valide
BadMatch
Une version compatible de Xkb n'était pas disponible sur le serveur ou un argument a un type et une plage corrects, mais est autrement invalide
BadValue
Un argument est hors de portée
