XkbSASetGroup(3) FONCTIONS XKB XkbSASetGroup(3)

NOM

XkbSASetGroup - Définit le champ group_XXX de act à partir de l'indice de groupe grp

SYNTAXE

void XkbSASetGroup (XkbAction act, int grp);

ARGUMENTS

act
action à partir de laquelle définir le groupe
grp
indice du groupe à définir dans group_XXX

DESCRIPTION

XkbSASetGroup définit le champ group_XXX de act à partir de l'indice de groupe grp.

STRUCTURE

Les actions associées à la structure XkbGroupAction modifient l'état du groupe actuel lorsque les touches sont pressées et relâchées :

    typedef struct _XkbGroupAction {
        unsigned char    type;       /* XkbSA_{Set|Latch|Lock}Group */
        unsigned char    flags;      /* avec type, contrôle l'effet sur les groupes */
        char             group_XXX;  /* représente un indice de groupe ou un delta */
    } XkbGroupAction;
