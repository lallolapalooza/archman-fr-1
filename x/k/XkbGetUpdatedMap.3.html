XkbGetUpdatedMap(3) FONCTIONS XKB XkbGetUpdatedMap(3)

NOM

XkbGetUpdatedMap - Met à jour les informations de la carte client ou serveur dans une description de clavier existante

SYNTAXE

Status XkbGetUpdatedMap (Display *display, unsigned int which, XkbDescPtr xkb);

ARGUMENTS

display
connexion au serveur X
which
masque sélectionnant les sous-composants à peupler
xkb
description du clavier à mettre à jour

DESCRIPTION

Le paramètre which est un OU exclusif bit à bit des masques du Tableau 1. Si les composants nécessaires de la structure xkb ne sont pas déjà alloués, XkbGetUpdatedMap les alloue. XkbGetUpdatedMap récupère les informations demandées pour le périphérique spécifié dans le XkbDescRec passé dans le paramètre xkb.

XkbGetUpdatedMap est synchrone ; il interroge le serveur pour les informations désirées, attend une réponse, puis retourne. En cas de succès, XkbGetUpdatedMap retourne Success. En cas d'échec, XkbGetUpdatedMap retourne l'un des éléments suivants : BadAlloc (incapacité d'allouer un composant dans la structure XkbDescRec), BadValue (certains bits du masque dans which sont indéfinis), BadImplementation (une version compatible de l'extension Xkb n'est pas disponible sur le serveur ou la réponse du serveur est invalide).

VALEUR DE RETOUR

Success
La fonction XkbGetUpdatedMap retourne Success si une réponse est reçue à la requête du serveur pour les informations désirées.

STRUCTURES

La description complète d'un clavier Xkb est donnée par un XkbDescRec. Les structures de composants dans le XkbDescRec représentent les principaux composants Xkb.

typedef struct {
   struct _XDisplay * display;      /* connexion au serveur X */
   unsigned short     flags;        /* privé à Xkb, ne pas modifier */
   unsigned short     device_spec;  /* périphérique d'intérêt */
   KeyCode            min_key_code; /* keycode minimum pour le périphérique */
   KeyCode            max_key_code; /* keycode maximum pour le périphérique */
   XkbControlsPtr     ctrls;        /* contrôles */
   XkbServerMapPtr    server;       /* carte de clavier serveur */
   XkbClientMapPtr    map;          /* carte de clavier client */
   XkbIndicatorPtr    indicators;   /* carte d'indicateurs */
   XkbNamesPtr        names;        /* noms pour tous les composants */
   XkbCompatMapPtr    compat;       /* carte de compatibilité */
   XkbGeometryPtr     geom;         /* géométrie physique du clavier */
} XkbDescRec, *XkbDescPtr;
Le champ display pointe vers une structure d'affichage X. Le champ flags est privé à la bibliothèque : modifier flags peut produire des résultats imprévisibles. Le champ device_spec spécifie l'identifiant du périphérique d'entrée du clavier, ou XkbUseCoreKeyboard, qui spécifie le périphérique clavier principal. Les champs min_key_code et max_key_code spécifient le keycode le plus bas et le plus haut pouvant être retourné par le clavier.

Chaque composant structurel a un bit de masque correspondant qui est utilisé dans les appels de fonction pour indiquer que la structure doit être manipulée d'une manière ou d'une autre, comme son allocation ou sa libération. Ces masques et leurs relations avec les champs du XkbDescRec sont montrés dans le Tableau 2.

Tableau 2 Bits de masque pour XkbDescRec
Bit de masque Champ XkbDescRec Valeur
