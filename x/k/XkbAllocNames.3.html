NOM

XkbAllocNames - Allouer des structures de noms symboliques

SYNTAXE

Status XkbAllocNames (XkbDescPtr xkb, unsigned int which, int num_rg, int num_key_aliases);

ARGUMENTS

xkb
description du clavier pour lequel les noms doivent être alloués
which
masque des noms à allouer
num_rg
nombre total de noms de groupes radio nécessaires
num_key_aliases
nombre total d'alias de clés nécessaires

DESCRIPTION

La plupart des applications n'ont pas besoin d'allouer directement des structures de noms symboliques. N'allouez pas une structure de noms directement en utilisant malloc ou Xmalloc si votre application modifie le nombre d'alias de clés ou de groupes radio, ou construit une structure de noms symboliques sans charger les composants nécessaires du serveur X. Utilisez plutôt XkbAllocNames.

XkbAllocNames peut renvoyer des erreurs BadAlloc, BadMatch et BadValue. Le paramètre which est le OU inclusif bit à bit des bits de masque de noms valides définis dans le Tableau 1.

Tableau 1 Masques de noms symboliques
Bit de masque Valeur Clavier Champ
Composant
XkbKeycodesNameMask (1<<0) Xkb->names keycodes
XkbGeometryNameMask (1<<1) Xkb->names geometry
XkbSymbolsNameMask (1<<2) Xkb->names symbols
XkbPhysSymbolsNameMask (1<<3) Xkb->names phys_symbols
XkbTypesNameMask (1<<4) Xkb->names type
XkbCompatNameMask (1<<5) Xkb->names compat
XkbKeyTypeNamesMask (1<<6) Xkb->map type[*].name
XkbKTLevelNamesMask (1<<7) Xkb->map type[*].lvl_names[*]
XkbIndicatorNamesMask (1<<8) Xkb->names indicators[*]
XkbKeyNamesMask (1<<9) Xkb->names keys[*], num_keys
XkbKeyAliasesMask (1<<10) Xkb->names key_aliases[*], num_key_aliases
XkbVirtualModNamesMask (1<<11) Xkb->names vmods[*]
XkbGroupNamesMask (1<<12) Xkb->names groups[*]
XkbRGNamesMask (1<<13) Xkb->names radio_groups[*], num_rg
XkbComponentNamesMask (0x3f) Xkb->names keycodes,
geometry,
symbols,
physical symbols,
types, et
map de compatibilité
XkbAllNamesMask (0x3fff) Xkb->names tous les composants de nom

Ne libérez pas les structures de noms symboliques directement en utilisant free ou XFree. Utilisez XkbFreeNames à la place.

DIAGNOSTICS

BadAlloc
Impossible d'allouer de l'espace
BadMatch
Une version compatible de Xkb n'était pas disponible sur le serveur ou un argument a un type et une plage corrects, mais est par ailleurs invalide
BadValue
Un argument est hors de portée
