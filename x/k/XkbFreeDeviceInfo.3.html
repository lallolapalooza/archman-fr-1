XkbFreeDeviceInfo(3) FONCTIONS XKB XkbFreeDeviceInfo(3)

NOM

XkbFreeDeviceInfo - Libérer une structure XkbDeviceInfoRec

SYNTAXE

void XkbFreeDeviceInfo (XkbDeviceInfoPtr device_info, unsigned int which, Bool free_all);

ARGUMENTS

device_info
pointeur vers XkbDeviceInfoRec dans lequel libérer les éléments
which
masque des composants de device_info à libérer
free_all
True => tout libérer, y compris device_info

DESCRIPTION

Si free_all est True, XkbFreeDeviceInfo libère tous les composants de device_info et la structure XkbDeviceInfoRec pointée par device_info elle-même. Si free_all est False, la valeur de which détermine quels sous-composants sont libérés. which est un OU inclusif d'une ou plusieurs des valeurs du Tableau 1. Si which contient XkbXI_ButtonActionsMask, toutes les actions de bouton associées à device_info sont libérées, device_info->btn_acts est mis à NULL, et device_info->num_btns est mis à zéro. Si which contient tous les bits de XkbXI_IndicatorsMask, toutes les structures XkbDeviceLedInfoRec associées à device_info sont libérées, device_info->leds est mis à NULL, et device_info->sz_leds et device_info->num_leds sont mis à zéro. Si which contient XkbXI_IndicatorMapsMask, toutes les cartes d'indicateurs associées à device_info sont effacées, mais le nombre de LEDs et les structures de LEDs elles-mêmes sont préservées. Si which contient XkbXI_IndicatorNamesMask, tous les noms d'indicateurs associés à device_info sont effacés, mais le nombre de LEDs et les structures de LEDs elles-mêmes sont préservées. Si which contient XkbXI_IndicatorStateMask, l'état de l'indicateur associé aux LEDs de device_info est mis à zéro, mais le nombre de LEDs et les structures de LEDs elles-mêmes sont préservées.
