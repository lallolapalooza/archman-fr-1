NOM

XkbFreeNames - Libérer les structures de noms symboliques

SYNTAXE

void XkbFreeNames (XkbDescPtr xkb, unsigned int which, Bool free_map);

ARGUMENTS

xkb
description du clavier pour laquelle les noms doivent être libérés
which
masque des composants de noms à libérer
free_map
Vrai => la structure XkbNamesRec elle-même doit être libérée

DESCRIPTION

Ne libérez pas les structures de noms symboliques directement en utilisant free ou XFree. Utilisez XkbFreeNames à la place.

Le paramètre which est le OU binaire inclusif des bits de masque de noms valides définis dans le Tableau 1.

Xkb fournit plusieurs fonctions qui travaillent avec des noms symboliques. Chacune de ces fonctions utilise un masque pour spécifier les champs individuels des structures décrites ci-dessus. Ces masques et leurs relations avec les champs d'une description de clavier sont montrés dans le Tableau 1.
