NOM

XkbGetGeometry - Charge la géométrie d'un clavier si vous possédez déjà la description du clavier

SYNTAXE

Status XkbGetGeometry (Display *dpy, XkbDescPtr xkb);

ARGUMENTS

dpy
connexion au serveur X
xkb
description du clavier contenant l'ID du clavier et dans laquelle la géométrie doit être chargée

DESCRIPTION

Vous pouvez charger une géométrie de clavier dans le cadre de la description du clavier retournée par XkbGetKeyboard. Cependant, si une description de clavier a été précédemment chargée, vous pouvez obtenir la géométrie en appelant XkbGetGeometry. Dans ce cas, la géométrie retournée est celle associée au clavier dont l'ID de périphérique est contenu dans la description du clavier.

XkbGetGeometry peut retourner des erreurs BadValue, BadImplementation, BadName, BadAlloc, ou Success s'il réussit.

DIAGNOSTICS

BadAlloc
Impossible d'allouer de l'espace
BadImplementation
Réponse invalide du serveur
BadLength
La longueur d'une requête est plus courte ou plus longue que celle requise pour contenir minimalement les arguments
BadName
Une police ou une couleur du nom spécifié n'existe pas
BadValue
Un argument est hors limites
