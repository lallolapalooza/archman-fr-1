XkbUpdateMapFromCore(3) FONCTIONS XKB XkbUpdateMapFromCore(3)

NOM

XkbUpdateMapFromCore - Mettre à jour une carte de clavier Xkb locale pour refléter le mappage exprimé par un mappage de format principal

SYNOPSIS

Bool XkbUpdateMapFromCore (XkbDescPtr xkb, KeyCode first_key, int num_keys, int map_width, KeySym *core_keysyms, XkbChangesPtr changes);

ARGUMENTS

xkb
description du clavier à mettre à jour
first_key
code de touche de la première description de touche à mettre à jour
num_keys
nombre de descriptions de touches à mettre à jour
map_width
largeur de la carte de touches du protocole principal
core_keysyms
symboles dans la carte de touches du protocole principal
changes
rempli avec les modifications apportées à Xkb

DESCRIPTION

Xkb fournit plusieurs fonctions qui facilitent l'application de la carte de compatibilité pour configurer une carte de clavier Xkb côté client, étant donné une représentation du protocole principal d'une partie ou de la totalité d'une carte de clavier. Obtenez une représentation du protocole principal d'une carte de clavier à partir d'un serveur réel (en utilisant par exemple XGetKeyboardMapping,), d'un fichier de données ou d'une autre source.

XkbUpdateMapFromCore interprète les informations des arguments d'entrée représentant une carte de clavier au format principal pour mettre à jour la description du clavier Xkb passée dans xkb. Seule une partie de la carte Xkb est mise à jour - la partie correspondant aux touches avec des codes de touche dans la plage first_key à first_key + num_keys - 1. Si XkbUpdateMapFromCore est appelé en réponse à un événement MappingNotify, first_key et num_keys sont rapportés dans l'événement MappingNotify. core_keysyms contient les keysyms correspondant à la plage de codes de touche mise à jour, dans l'ordre de description du clavier principal. map_width est le nombre de keysyms par touche dans core_keysyms. Ainsi, les map_width premières entrées dans core_keysyms sont pour la touche avec le code de touche first_key, les map_width entrées suivantes sont pour la touche first_key + 1, et ainsi de suite.

En plus de modifier la carte de clavier Xkb dans xkb, XkbUpdateMapFromCore remplit la structure de changements dont l'adresse est passée dans changes pour indiquer les modifications qui ont été apportées. Vous pouvez ensuite utiliser changes dans des appels ultérieurs tels que XkbSetMap, pour propager les modifications locales à un serveur.
