NOM

XkbSetXlibControls - Modifie l'état des Contrôles de Bibliothèque

SYNOPSIS

unsigned int XkbSetXlibControls (Display *display, unsigned long bits_to_change, unsigned long values_for_bits);

ARGUMENTS

display
connexion au serveur X
bits_to_change
sélectionne les contrôles à modifier
values_for_bits
active (1) ou désactive (0) les contrôles sélectionnés

DESCRIPTION

XkbSetXlibControls modifie l'état des contrôles sélectionnés par bits_to_change ; seuls les contrôles sélectionnés par bits_to_change sont modifiés. Si le bit correspondant à un contrôle est activé dans bits_to_change et également activé dans values_for_bits, le contrôle est activé. Si le bit correspondant à un contrôle est activé dans bits_to_change mais désactivé dans values_for_bits, le contrôle est désactivé. bits_to_change doit être un OU inclusif des bits du Tableau 1.

Tableau 1 Masques de Contrôle de Bibliothèque
Masque de Contrôle de Bibliothèque Valeur
XkbLC_ForceLatin1Lookup (1 << 0)
XkbLC_ConsumeLookupMods (1 << 1)
XkbLC_AlwaysConsumeShiftAndLock (1 << 2)
XkbLC_IgnoreNewKeyboards (1 << 3)
XkbLC_ConsumeKeysOnComposeFail (1 << 29)
XkbLC_ComposeLED (1 << 30)
XkbLC_BeepOnComposeFail (1 << 31)
XkbLC_AllControls (0xc0000007)
