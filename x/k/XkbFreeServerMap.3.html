XkbFreeServerMap(3) FONCTIONS XKB XkbFreeServerMap(3)

NOM

XkbFreeServerMap - Libère la mémoire utilisée par le membre serveur d'une structure XkbDescRec

SYNOPSIS

void XkbFreeServerMap (XkbDescPtr xkb, unsigned int which, Bool free_all);

ARGUMENTS

xkb
description du clavier contenant la carte serveur à libérer
which
masque identifiant les composants de la carte à libérer
free_all
True => libère tous les composants de la carte serveur et le serveur lui-même

DESCRIPTION

La fonction XkbFreeServerMap libère les composants spécifiés de la carte serveur dans la structure XkbDescRec spécifiée par le paramètre xkb et met les valeurs des composants de structure correspondants à NULL. Le paramètre which spécifie une combinaison des masques de la carte serveur et est un OU inclusif au niveau du bit des masques listés dans le Tableau 1. Si free_all est True, which est ignoré et XkbFreeServerMap libère chaque composant de structure non-NULL dans la carte serveur, libère la structure XkbServerMapRec référencée par le membre server du paramètre xkb, et met le membre server à NULL.

Tableau 1 Masques XkbAllocServerMap
Masque Effet
XkbExplicitComponentsMask Les champs min_key_code et max_key_code du paramètre xkb sont utilisés pour allouer le champ explicit de la carte serveur.
XkbKeyActionsMask Les champs min_key_code et max_key_code du paramètre xkb sont utilisés pour allouer le champ key_acts de la carte serveur. Le paramètre count_acts est utilisé pour allouer le champ acts de la carte serveur.
XkbKeyBehaviorsMask Les champs min_key_code et max_key_code du paramètre xkb sont utilisés pour allouer le champ behaviors de la carte serveur.
XkbVirtualModMapMask Les champs min_key_code et max_key_code du paramètre xkb sont utilisés pour allouer le champ vmodmap de la carte serveur.

STRUCTURES

La description complète d'un clavier Xkb est donnée par une XkbDescRec. Les structures de composants dans la XkbDescRec représentent les composants majeurs de Xkb.

typedef struct {
   struct _XDisplay * display;      /* connexion au serveur X */
   unsigned short     flags;        /* privé à Xkb, ne pas modifier */
   unsigned short     device_spec;  /* périphérique d'intérêt */
   KeyCode            min_key_code; /* keycode minimum pour le périphérique */
   KeyCode            max_key_code; /* keycode maximum pour le périphérique */
   XkbControlsPtr     ctrls;        /* contrôles */
   XkbServerMapPtr    server;       /* carte serveur */
   XkbClientMapPtr    map;          /* carte client */
   XkbIndicatorPtr    indicators;   /* carte d'indicateurs */
   XkbNamesPtr        names;        /* noms pour tous les composants */
   XkbCompatMapPtr    compat;       /* carte de compatibilité */
   XkbGeometryPtr     geom;         /* géométrie physique du clavier */
} XkbDescRec, *XkbDescPtr;
Le champ display pointe vers une structure d'affichage X. Le champ flags est privé à la bibliothèque : la modification de flags peut entraîner des résultats imprévisibles. Le champ device_spec spécifie l'identifiant du périphérique d'entrée du clavier, ou XkbUseCoreKeyboard, qui spécifie le périphérique clavier principal. Les champs min_key_code et max_key_code spécifient le keycode le plus bas et le plus haut qui peut être retourné par le clavier.

Chaque composant de structure a un bit de masque correspondant qui est utilisé dans les appels de fonction pour indiquer que la structure doit être manipulée d'une manière ou d'une autre, comme son allocation ou sa libération. Ces masques et leurs relations avec les champs de la XkbDescRec sont indiqués dans le Tableau 2.

Tableau 2 Bits de masque pour XkbDescRec
Bit de masque Champ XkbDescRec Valeur
XkbControlsMask ctrls (1L<<0)
XkbServerMapMask server (1L<<1)
XkbIClientMapMask map (1L<<2)
XkbIndicatorMapMask indicators (1L<<3)
XkbNamesMask names (1L<<4)
XkbCompatMapMask compat (1L<<5)
XkbGeometryMask geom (1L<<6)
XkbAllComponentsMask Tous les champs (0x7f)

La carte serveur Xkb contient les informations dont le serveur a besoin pour interpréter les événements clavier et est de type XkbServerMapRec :

#define XkbNumVirtualMods          16
typedef struct {                    /* Carte Serveur */
    unsigned short    num_acts;     /* # d'entrées occupées dans acts */
    unsigned short    size_acts;    /* # d'entrées dans acts */
    XkbAction *       acts;         /* tables 2D linéaires d'actions de touches, 1 par keycode */
    XkbBehavior *     behaviors;    /* comportements de touches, 1 par keycode */
    unsigned short *  key_acts;     /* index dans acts, 1 par keycode */
    unsigned char *   explicit;     /* substitutions explicites du remappage core, 1 par touche */
    unsigned char     vmods[XkbNumVirtualMods]; /* mods réels liés aux mods virtuels */
    unsigned short *  vmodmap;      /* mods virtuels liés à la touche, 1 par keycode*/
} XkbServerMapRec, *XkbServerMapPtr;
