XkbGetKeyBehaviors(3) FONCTIONS XKB XkbGetKeyBehaviors(3)

NOM

XkbGetKeyBehaviors - Obtenir les comportements (tableau des comportements) pour un sous-ensemble de touches d'une description de clavier depuis le serveur

SYNOPSIS

Status XkbGetKeyBehaviors (Display *dpy, unsigned int first, unsigned int num, XkbDescPtr xkb);

ARGUMENTS

dpy
connexion au serveur
first
code de touche de la première touche à obtenir
num
nombre de touches pour lesquelles les comportements sont souhaités
xkb
description Xkb pour contenir le résultat

DESCRIPTION

XkbGetKeyBehaviors envoie une requête au serveur pour obtenir les comportements de num touches du clavier en commençant par la touche dont le code est first. Il attend une réponse et retourne les comportements dans le champ server->behaviors de xkb. En cas de succès, XkbGetKeyBehaviors retourne Success.

Si la carte server dans le paramètre xkb n'a pas été allouée, XkbGetKeyBehaviors l'alloue et l'initialise avant d'obtenir les actions.

Si le serveur n'a pas une version compatible de Xkb, ou si l'extension Xkb n'a pas été correctement initialisée, XkbGetKeyBehaviors retourne BadAccess. Si num est inférieur à 1 ou supérieur à XkbMaxKeyCount, XkbGetKeyBehaviors retourne BadValue. Si des erreurs d'allocation se produisent, XkbGetKeyBehaviors retourne BadAlloc.

DIAGNOSTICS

BadAccess
L'extension Xkb n'a pas été correctement initialisée
BadAlloc
Impossible d'allouer de l'espace
BadValue
Un argument est hors limites
