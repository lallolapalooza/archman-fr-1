NOM

XkbGetNames - Obtenir les noms symboliques du serveur

SYNTAXE

Status XkbGetNames (Display *dpy, unsigned int which, XkbDescPtr xkb);

ARGUMENTS

dpy
connexion au serveur X
which
masque des noms ou des composants de carte à mettre à jour
xkb
description du clavier à mettre à jour

DESCRIPTION

XkbGetNames récupère les noms symboliques des composants de l'extension du clavier depuis le serveur X. Le paramètre which spécifie les composants de nom à mettre à jour dans le paramètre xkb, et est le OU booléen des bits de masque de noms valides définis dans le Tableau 1.

Tableau 1 Masques de noms symboliques
Bit de masque Valeur Clavier Champ
Composant
XkbKeycodesNameMask (1<<0) Xkb->names keycodes
XkbGeometryNameMask (1<<1) Xkb->names geometry
XkbSymbolsNameMask (1<<2) Xkb->names symbols
XkbPhysSymbolsNameMask (1<<3) Xkb->names phys_symbols
XkbTypesNameMask (1<<4) Xkb->names type
XkbCompatNameMask (1<<5) Xkb->names compat
XkbKeyTypeNamesMask (1<<6) Xkb->map type[*].name
XkbKTLevelNamesMask (1<<7) Xkb->map type[*].lvl_names[*]
XkbIndicatorNamesMask (1<<8) Xkb->names indicators[*]
XkbKeyNamesMask (1<<9) Xkb->names keys[*], num_keys
XkbKeyAliasesMask (1<<10) Xkb->names key_aliases[*], num_key_aliases
XkbVirtualModNamesMask (1<<11) Xkb->names vmods[*]
XkbGroupNamesMask (1<<12) Xkb->names groups[*]
XkbRGNamesMask (1<<13) Xkb->names radio_groups[*], num_rg
XkbComponentNamesMask (0x3f) Xkb->names keycodes,
geometry,
symbols,
physical symbols,
types, et
carte de compatibilité
XkbAllNamesMask (0x3fff) Xkb->names tous les composants de noms

Si le champ names de la description du clavier xkb est NULL, XkbGetNames alloue et initialise le composant names de la description du clavier avant d'obtenir les valeurs spécifiées par which. Si le champ names de xkb n'est pas NULL, XkbGetNames obtient les valeurs spécifiées par which et les copie dans la description du clavier Xkb.

Si le composant map du paramètre xkb est NULL, XkbGetNames ne récupère pas les noms de type ou de niveau de décalage, même si XkbKeyTypeNamesMask ou XkbKTLevelNamesMask sont définis dans which.

XkbGetNames peut retourner Success, ou des erreurs BadAlloc, BadLength, BadMatch, et BadImplementation.

Pour libérer les noms symboliques, utilisez XkbFreeNames.

DIAGNOSTICS

BadAlloc
Impossible d'allouer du stockage
BadImplementation
Réponse invalide du serveur
BadLength
La longueur d'une requête est plus courte ou plus longue que nécessaire pour contenir minimalement les arguments
BadMatch
Une version compatible de Xkb n'était pas disponible sur le serveur ou un argument a le type et la plage corrects, mais est autrement invalide
