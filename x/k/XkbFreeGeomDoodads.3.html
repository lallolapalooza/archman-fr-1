NOM

XkbFreeGeomDoodads - Libérer les "doodads" de géométrie

SYNTAXE

void XkbFreeGeomDoodads (XkbDoodadPtr doodads, int count, Bool free_all);

ARGUMENTS

doodads
les doodads à libérer
count
nombre de doodads à libérer
free_all
Vrai => tous les doodads sont libérés

DESCRIPTION

Xkb fournit un certain nombre de fonctions pour allouer et libérer des sous-composants d'une géométrie de clavier. Utilisez ces fonctions pour créer ou modifier les géométries de clavier. Notez que ces fonctions allouent simplement de l'espace pour le(s) nouvel(s) élément(s), et il vous appartient de remplir les valeurs explicitement dans votre code. Ces fonctions d'allocation augmentent sz_* mais ne touchent jamais num_* (sauf en cas d'échec d'allocation, auquel cas elles réinitialisent sz_* et num_* à zéro). Ces fonctions retournent Success si elles réussissent, BadAlloc si elles ne parviennent pas à allouer d'espace, ou BadValue si un paramètre n'est pas conforme aux attentes.

Si free_all est Vrai, tous les doodads du tableau sont libérés, quelle que soit la valeur de count. Sinon, count doodads sont libérés.

VALEUR DE RETOUR

Success
La fonction XkbFreeGeomDoodads retourne Success s'il n'y a pas d'erreurs d'allocation.

DIAGNOSTICS

BadAlloc
Impossible d'allouer du stockage
BadValue
Un argument est hors limites
