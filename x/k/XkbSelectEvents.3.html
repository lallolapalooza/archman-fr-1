XkbSelectEvents(3) FONCTIONS XKB XkbSelectEvents(3)

NOM

XkbSelectEvents - Sélectionne et/ou désélectionne la livraison d'un ou plusieurs événements Xkb et les fait livrer dans toutes les conditions

SYNTAXE

Bool XkbSelectEvents (Display *display, unsigned int device_spec, unsigned long int bits_to_change, unsigned long int values_for_bits);

ARGUMENTS

display
connexion au serveur X
device_spec
ID du périphérique, ou XkbUseCoreKbd
bits_to_change
détermine les événements à sélectionner / désélectionner
values_for_bits
1=>sélectionner, 0=>désélectionner ; pour les événements dans bits_to_change

DESCRIPTION

Les événements Xkb sont sélectionnés à l'aide d'un masque d'événements, de manière très similaire aux événements X de base normaux. Cependant, contrairement à la sélection des événements X de base, où vous devez spécifier l'état de sélection (activé ou désactivé) pour tous les types d'événements possibles chaque fois que vous souhaitez modifier les critères de sélection pour un seul événement, Xkb vous permet de limiter la spécification aux seuls types d'événements que vous souhaitez modifier. Cela signifie que vous n'avez pas besoin de vous souvenir des valeurs de sélection d'événements pour tous les types possibles chaque fois que vous souhaitez en modifier un.

De nombreux types d'événements Xkb sont générés dans plusieurs circonstances différentes. Lors de la sélection pour recevoir un événement Xkb, vous pouvez spécifier soit que vous souhaitez qu'il soit livré dans toutes les circonstances, soit que vous souhaitez qu'il soit livré uniquement pour un sous-ensemble des circonstances possibles.

Vous pouvez également désélectionner un type d'événement qui a été précédemment sélectionné, en utilisant la même granularité.

Xkb fournit deux fonctions pour sélectionner et désélectionner la livraison des événements Xkb. XkbSelectEvents vous permet de sélectionner ou de désélectionner la livraison de plusieurs types d'événements Xkb à la fois. Les événements sélectionnés à l'aide de XkbSelectEvents sont livrés à votre programme dans toutes les circonstances qui génèrent les événements. Pour restreindre la livraison d'un événement à un sous-ensemble des conditions dans lesquelles il se produit, utilisez XkbSelectEventDetails. XkbSelectEventDetails vous permet uniquement de modifier les conditions de sélection pour un seul événement à la fois, mais il fournit un moyen d'affiner les conditions dans lesquelles l'événement est livré.

Cette requête modifie le masque de sélection d'événements Xkb pour le clavier spécifié par device_spec.

Chaque événement Xkb pouvant être sélectionné est représenté par un bit dans les masques bits_to_change et values_for_bits. Seuls les bits de sélection d'événements spécifiés par le paramètre bits_to_change sont affectés ; tous les bits non spécifiés restent inchangés. Pour activer la sélection d'événements pour un événement, définissez le bit correspondant à l'événement dans le paramètre bits_to_change et définissez le bit correspondant dans le paramètre values_for_bits. Pour désactiver la sélection d'événements pour un événement, définissez le bit correspondant à l'événement dans le paramètre bits_to_change et ne définissez pas le bit correspondant dans le paramètre values_for_bits. Les valeurs valides pour ces deux paramètres sont un OU binaire inclusif des masques indiqués dans le Tableau 1. Il n'existe pas d'interface pour renvoyer le masque de sélection d'événements actuel de votre client. Les clients ne peuvent pas définir les masques de sélection d'événements des autres clients.

Le serveur X rapporte les événements définis par Xkb à votre application cliente uniquement si vous les avez demandés via un appel à XkbSelectEvents ou XkbSelectEventDetails. Spécifiez les types d'événements qui vous intéressent dans un masque.

Le Tableau 1 liste les constantes de masque d'événements qui peuvent être spécifiées avec la requête XkbSelectEvents et les circonstances dans lesquelles le masque doit être spécifié.

Tableau 1 Constantes de masque XkbSelectEvents
Masque d'événement Valeur Notification souhaitée
XkbNewKeyboardNotifyMask (1L<<0) Changement de géométrie du clavier
XkbMapNotifyMask (1L<<1) Changement de mappage du clavier
XkbStateNotifyMask (1L<<2) Changement d'état du clavier
XkbControlsNotifyMask (1L<<3) Changement de contrôle du clavier
XkbIndicatorStateNotifyMask (1L<<4) Changement d'état de l'indicateur du clavier
XkbIndicatorMapNotifyMask (1L<<5) Changement de mappage de l'indicateur du clavier
XkbNamesNotifyMask (1L<<6) Changement de nom du clavier
XkbCompatMapNotifyMask (1L<<7) Changement de carte de compatibilité du clavier
XkbBellNotifyMask (1L<<8) Sonnerie
XkbActionMessageMask (1L<<9) Message d'action
XkbAccessXNotifyMask (1L<<10) Fonctionnalités AccessX
XkbExtensionDeviceNotifyMask (1L<<11) Périphérique d'extension
XkbAllEventsMask (0xFFF) Tous les événements Xkb

Si un bit n'est pas défini dans le paramètre bits_to_change, mais que le bit correspondant est défini dans le paramètre values_for_bits, une erreur de protocole BadMatch se produit. Si un bit indéfini est défini dans l'un ou l'autre des paramètres bits_to_change ou values_for_bits, une erreur de protocole BadValue se produit.

Tous les bits de sélection d'événements sont initialement à zéro pour les clients utilisant l'extension Xkb. Une fois que vous avez défini certains bits, ils restent définis pour votre client jusqu'à ce que vous les effaciez via un autre appel à XkbSelectEvents.

XkbSelectEvents renvoie False si l'extension Xkb n'a pas été initialisée et True dans le cas contraire.

VALEURS DE RETOUR

True
La fonction XkbSelectEvents renvoie True si l'extension Xkb a été initialisée.
False
La fonction XkbSelectEvents renvoie False si l'extension Xkb n'a pas été initialisée.

VOIR AUSSI

XkbSelectEventDetails(3), XkbUseCoreKbd(3)
