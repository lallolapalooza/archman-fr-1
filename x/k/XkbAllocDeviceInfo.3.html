XkbAllocDeviceInfo(3) FONCTIONS XKB XkbAllocDeviceInfo(3)

NOM

XkbAllocDeviceInfo - Obtenir une structure XkbDeviceInfoRec

SYNTAXE

XkbDeviceInfoPtr XkbAllocDeviceInfo (unsigned int device_spec, unsigned int n_buttons, unsigned int sz_leds);

ARGUMENTS

device_spec
ID du périphérique avec lequel la structure sera utilisée
n_buttons
nombre d'actions de boutons pour lesquelles allouer de l'espace
sz_leds
nombre de retours d'information LED pour lesquels allouer de l'espace

DESCRIPTION

XkbAllocDeviceInfo alloue de l'espace pour une structure XkbDeviceInfoRec et initialise le champ device_spec de cette structure avec l'ID du périphérique spécifié par device_spec. Si n_buttons est non nul, n_buttons XkbActions sont liés à la structure XkbDeviceInfoRec et initialisés à zéro. Si sz_leds est non nul, sz_leds structures XkbDeviceLedInfoRec sont également allouées et liées à la structure XkbDeviceInfoRec. Si vous demandez l'allocation de structures XkbDeviceLedInfoRec via cette requête, vous devez les initialiser explicitement, en utilisant XkbAddDeviceLedInfo(3).

STRUCTURES

Les informations sur les périphériques de l'Extension d'Entrée X sont transférées entre un programme client et l'extension Xkb dans une structure XkbDeviceInfoRec :

    typedef struct {
        char *               name;          /* nom du périphérique */
        Atom                 type;          /* nom de la classe des périphériques */
        unsigned short       device_spec;   /* périphérique concerné */
        Bool                 has_own_state; /* True=>ce périphérique a son propre état */
        unsigned short       supported;     /* bits indiquant les capacités supportées */
        unsigned short       unsupported;   /* bits indiquant les capacités non supportées */
        unsigned short       num_btns;      /* nombre d'entrées dans btn_acts */
        XkbAction *          btn_acts;      /* actions des boutons */
        unsigned short       sz_leds;       /* nombre total d'entrées dans le vecteur LEDs */
        unsigned short       num_leds;      /* nombre d'entrées valides dans le vecteur LEDs */
        unsigned short       dflt_kbd_fb;   /* ID d'extension d'entrée de l'indicateur par défaut (clavier principal) */
        unsigned short       dflt_led_fb;   /* ID d'extension d'entrée du retour d'information par défaut */
        XkbDeviceLedInfoPtr  leds;          /* descriptions des LEDs */
    } XkbDeviceInfoRec, *XkbDeviceInfoPtr;
    typedef struct {
        unsigned short      led_class;        /* classe pour ce périphérique LED */
        unsigned short      led_id;           /* ID pour ce périphérique LED */
        unsigned int        phys_indicators;  /* bits indiquant quelles LEDs sont physiquement présentes */
        unsigned int        maps_present;     /* bits indiquant quelles LEDs sont présentes dans les maps */
        unsigned int        names_present;    /* bits indiquant quelles LEDs sont présentes dans les noms */
        unsigned int        state;            /* 1 bit => la LED correspondante est allumée */
        Atom                names[XkbNumIndicators];   /* noms des LEDs */
        XkbIndicatorMapRec  maps;             /* maps d'indicateurs pour chaque LED */
    } XkbDeviceLedInfoRec, *XkbDeviceLedInfoPtr;
