XkbCopyKeyType(3)

Paquet: libx11

Licences: MIT AND X11

XkbCopyKeyType(3) FONCTIONS XKB XkbCopyKeyType(3)

NOM

XkbCopyKeyType - Copier une structure XkbKeyTypeRec

SYNTAXE

Status XkbCopyKeyType (XkbKeyTypePtr from, XkbKeyTypePtr into);

ARGUMENTS

from
pointeur vers la XkbKeyTypeRec à copier
into
pointeur vers la XkbKeyTypeRec à modifier

DESCRIPTION

XkbCopyKeyType copie le type de touche spécifié par from vers le type de touche spécifié par into. Les deux doivent pointer vers des structures XkbKeyTypeRec valides. Xkb suppose que from et into pointent vers des emplacements différents. Par conséquent, les chevauchements peuvent être fatals. XkbCopyKeyType libère tout map, preserve, et level_names existant dans into avant la copie. Si des erreurs d'allocation surviennent lors de la copie de from vers into, XkbCopyKeyType retourne BadAlloc. Sinon, XkbCopyKeyType copie from vers into et retourne Success.

STRUCTURES

Les types de touches sont utilisés pour déterminer le niveau de décalage d'une touche étant donné l'état actuel du clavier. L'ensemble de tous les types de touches possibles pour la description du clavier Xkb est contenu dans le champ types de la carte client, dont la taille totale est stockée dans size_types, et dont le nombre total d'entrées valides est stocké dans num_types. Les types de touches sont définis à l'aide de la structure suivante :

typedef struct {                   /* Type de touche */
    XkbModsRec        mods;        /* modificateurs utilisés pour calculer le niveau de décalage */
    unsigned char     num_levels;  /* # total de niveaux de décalage, ne pas modifier directement */
    unsigned char     map_count;   /* # d'entrées dans map, preserve (si non NULL) */
    XkbKTMapEntryPtr  map;         /* vecteur de modificateurs pour chaque niveau de décalage */
    XkbModsPtr        preserve;    /* mods à préserver pour l'entrée map correspondante */
    Atom              name;        /* nom du type de touche */
    Atom *            level_names; /* tableau des noms de chaque niveau de décalage */
} XkbKeyTypeRec, *XkbKeyTypePtr;
