XkbResizeKeyActions(3) FONCTIONS XKB XkbResizeKeyActions(3)

NOM

XkbResizeKeyActions - Changer le nombre d'actions liées à une touche

SYNTAXE

XkbAction * XkbResizeKeyActions (XkbDescRec *xkb, int key, int needed);

ARGUMENTS

xkb
description du clavier à modifier
key
code de touche à modifier
needed
nouveau nombre d'actions requis

DESCRIPTION

Le paramètre xkb pointe vers la description du clavier contenant la key dont le nombre d'actions doit être modifié. Le paramètre key est le code de la touche à modifier, et needed spécifie le nouveau nombre d'actions requis pour la touche.

XkbResizeKeyActions réserve l'espace nécessaire pour les actions et renvoie un pointeur vers le début du nouveau tableau qui contient les actions. Il peut modifier les champs acts, num_acts, et size_acts de xkb->server s'il est nécessaire de réallouer le tableau acts.

Si needed est supérieur au nombre actuel de symboles pour la touche, XkbResizeKeyActions initialise toutes les nouvelles actions du tableau à NoAction.

Étant donné que le nombre d'actions nécessaires par une touche est normalement calculé comme largeur * nombre de groupes, et que XkbResizeKeyActions ne modifie ni la largeur ni le nombre de groupes pour la touche, il existe une divergence au retour de XkbResizeKeyActions entre l'espace alloué pour les actions et le nombre requis. Les entrées inutilisées dans la liste des actions renvoyées par XkbResizeKeyActions ne sont pas conservées lors d'appels futurs aux fonctions de modification de carte, vous devez donc mettre à jour les actions de la touche (ce qui met à jour la largeur et le nombre de groupes pour la touche) avant d'appeler une autre fonction d'allocation. Un appel à XkbChangeTypesOfKey met à jour ces éléments.

Si des erreurs d'allocation surviennent lors du redimensionnement du nombre d'actions liées à la touche, XkbResizeKeyActions renvoie NULL.

VOIR AUSSI

XkbChangeTypesOfKey(3), XkbResizeKeySyms(3)

NOTES

Une modification du nombre d'actions liées à une touche doit être accompagnée d'une modification du nombre de symboles liés à une touche. Reportez-vous à XkbResizeKeySyms pour plus d'informations sur la modification du nombre de symboles liés à une touche.
