Paquet: libx11

XkbNoteControlsChanges(3) FONCTIONS XKB XkbNoteControlsChanges(3)

NOM

XkbNoteControlsChanges - Note les changements dans une structure de changements lorsqu'un client reçoit un événement XkbControlsNotify

SYNOPSIS

void XkbNoteControlsChanges (XkbControlsChangesPtr changes, XkbControlsNotifyEvent *new, unsigned int wanted);

ARGUMENTS

changes
enregistre les changements indiqués par new
new
indique quelles choses ont changé
wanted
indique quelles parties de new enregistrer dans changes

DESCRIPTION

Chaque fois qu'un champ de la structure de contrôles change dans la description du clavier du serveur, le serveur envoie un événement XkbControlsNotify à tous les clients intéressés. Pour recevoir les événements XkbControlsNotify dans toutes les conditions possibles, utilisez XkbSelectEvents et passez XkbControlsNotifyMask dans bits_to_change et values_for_bits.

Pour recevoir les événements XkbControlsNotify uniquement sous certaines conditions, utilisez XkbSelectEventDetails en utilisant XkbControlsNotify comme event_type et en spécifiant les changements d'état désirés dans bits_to_change et values_for_bits en utilisant les bits de masque du Tableau 1.

Le Tableau 1 montre les valeurs réelles pour les bits de masque individuels utilisés pour sélectionner les contrôles à modifier et pour activer et désactiver le contrôle. Notez que le même bit de masque est utilisé pour spécifier les modifications générales des paramètres utilisés pour configurer le contrôle (which), et pour activer et désactiver le contrôle (enabled_ctrls). Les anomalies dans le tableau (pas de "ok" dans la colonne) concernent les contrôles qui n'ont pas d'attributs configurables ; et pour les contrôles qui ne sont pas des contrôles booléens et qui ne peuvent donc pas être activés ou désactivés.

Tableau 1 Bits de masque des contrôles

XkbSlowKeysMask ok ok (1L<<1)
XkbBounceKeysMask ok ok (1L<<2)
XkbStickyKeysMask ok ok (1L<<3)
XkbMouseKeysMask ok ok (1L<<4)
XkbMouseKeysAccelMask ok ok (1L<<5)
XkbAccessXKeysMask ok ok (1L<<6)
XkbAccessXTimeoutMask ok ok (1L<<7)
XkbAccessXFeedbackMask ok ok (1L<<8)
XkbAudibleBellMask ok (1L<<9)
XkbOverlay1Mask ok (1L<<10)
XkbOverlay2Mask ok (1L<<11)
XkbIgnoreGroupLockMask ok (1L<<12)
XkbGroupsWrapMask ok (1L<<27)
XkbInternalModsMask ok (1L<<28)

XkbAllControlsMask ok (0xF8001FFF)

Le champ changed_ctrls spécifie les composants de contrôles qui ont changé et se compose de bits tirés des masques définis dans le Tableau 1 avec "ok" dans la colonne changed_ctrls.

Les contrôles actuellement activés sur le serveur sont rapportés dans le champ enabled_ctrls. Si des contrôles viennent d'être activés ou désactivés (c'est-à-dire si le contenu du champ enabled_ctrls a changé), ils sont signalés dans le champ enabled_ctrl_changes. Les bits valides pour ces champs sont les masques listés dans le Tableau 1 avec "ok" dans la colonne enabled_ctrls. Le champ num_groups rapporte le nombre de groupes associés à la touche appartenant au plus grand nombre de groupes et est automatiquement mis à jour lorsque la configuration du clavier change.

Si le changement a été causé par une requête d'un client, les champs keycode et event_type sont mis à zéro et les champs req_major et req_minor identifient la requête. La valeur req_major est la même que l'opcode d'extension principal. Sinon, event_type est défini sur le type d'événement qui a causé le changement (une des KeyPress, KeyRelease, DeviceKeyPress, DeviceKeyRelease, ButtonPress ou ButtonRelease), et req_major et req_minor sont indéfinis. Si event_type est KeyPress, KeyRelease, DeviceKeyPress ou DeviceKeyRelease, le champ keycode est défini sur la touche qui a causé le changement. Si event_type est ButtonPress ou ButtonRelease, keycode contient le numéro du bouton.

Lorsqu'un client reçoit un événement XkbControlsNotify, il peut noter les changements dans une structure de changements à l'aide de XkbNoteControlsChanges.

Le paramètre wanted est un OR inclusif bit à bit des bits tirés de l'ensemble des masques spécifiés dans le Tableau 1 avec "ok" dans la colonne changed_ctrls. XkbNoteControlsChanges copie tous les changements rapportés dans new et spécifiés dans wanted dans l'enregistrement de changements spécifié par old.

STRUCTURES

La structure pour l'événement XkbControlsNotify est définie comme suit :
typedef struct {
    int           type;          /* Code de base de l'événement d'extension Xkb */
    unsigned long serial;        /* Numéro de série du serveur X pour l'événement */
    Bool          send_event;    /* True => généré synthétiquement */
    Display *     display;       /* Connexion serveur où l'événement a été généré */
    Time          time;          /* Heure du serveur à laquelle l'événement a été généré */
    int           xkb_type;      /* XkbCompatMapNotify */
    int           device;        /* ID du périphérique Xkb, ne sera pas XkbUseCoreKbd */
    unsigned int  changed_ctrls; /* bits indiquant quelles données de contrôles ont changé*/
    unsigned int  enabled_ctrls; /* contrôles actuellement activés sur le serveur */
    unsigned int  enabled_ctrl_changes; /* bits indiquant les contrôles activés/désactivés */
    int           num_groups;    /* nombre actuel de groupes de clavier */
    KeyCode       keycode;       /* != 0 => keycode de la touche provoquant le changement */
    char          event_type;    /* Type d'événement provoquant le changement */
    char          req_major;     /* code majeur de l'événement provoquant le changement */
    char          req_minor;     /* code mineur de l'événement provoquant le changement */
} XkbControlsNotifyEvent;

NOM

XkbNoteControlsChanges - Notifie les modifications des contrôles Xkb.

SYNTAXE

                    #include <X11/extensions/Xkb.h>

                    Bool XkbNoteControlsChanges(
                        Display *dpy,
                        XkbModsRec *mods_rtrn,
                        XkbControlsPtr controls_rtrn
                    );

ARGUMENTS

dpy
Connecte au serveur X.
mods_rtrn
Pointeur vers une structure XkbModsRec dans laquelle les modifications des contrôles Xkb seront retournées.
controls_rtrn
Pointeur vers une structure XkbControlsPtr dans laquelle les contrôles Xkb seront retournés.

DESCRIPTION

XkbNoteControlsChanges enregistre les changements apportés aux contrôles Xkb. Lorsqu'elle est appelée, elle met à jour les champs mods_rtrn et controls_rtrn avec les modifications actuelles. Cela est utile pour le suivi des modifications apportées aux paramètres du clavier, tels que la disposition du clavier, la vitesse de répétition des touches, le délai d'appui, etc.

STRUCTURES

XkbModsRec
Représente les modifications Xkb. Elle contient des informations sur les modificateurs actifs, leurs états, etc.
XkbControlsPtr
Pointeur vers une structure qui contient divers paramètres de contrôle Xkb.

VOIR AUSSI

XkbChangeControls(3), XkbGetControls(3)
