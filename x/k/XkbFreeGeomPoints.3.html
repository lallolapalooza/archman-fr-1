XkbFreeGeomPoints(3) FONCTIONS XKB XkbFreeGeomPoints(3)

NOM

XkbFreeGeomPoints - Libérer les points d'un contour

SYNTAXE

void XkbFreeGeomPoints (XkbOutlinePtr outline, int first, int count, Bool free_all);

ARGUMENTS

outline
le contour dont les points doivent être libérés
first
le premier point à libérer
count
le nombre de points à libérer
free_all
True => tous les points sont libérés

DESCRIPTION

Xkb fournit un certain nombre de fonctions pour allouer et libérer des sous-composants d'une géométrie de clavier. Utilisez ces fonctions pour créer ou modifier des géométries de clavier. Notez que ces fonctions allouent simplement de l'espace pour le(s) nouvel(aux) élément(s), et il vous incombe de remplir les valeurs explicitement dans votre code. Ces fonctions d'allocation augmentent sz_* mais ne touchent jamais num_* (sauf en cas d'échec d'allocation, auquel cas elles réinitialisent sz_* et num_* à zéro). Ces fonctions retournent Success si elles réussissent, BadAlloc si elles ne parviennent pas à allouer d'espace, ou BadValue si un paramètre n'est pas conforme aux attentes.

Si free_all est True, tous les points sont libérés indépendamment de la valeur de first et count. Sinon, le nombre de points spécifié par count est libéré, en commençant par le point spécifié par first dans le contour donné.

VALEURS DE RETOUR

Success
La fonction XkbFreeGeomPoints retourne Success lorsqu'il n'y a pas d'erreurs d'allocation ou d'arguments.

DIAGNOSTICS

BadAlloc
Impossible d'allouer de l'espace
BadValue
Un argument est hors limites
