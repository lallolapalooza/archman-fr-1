XkbNoteNameChanges(3) FONCTIONS XKB XkbNoteNameChanges(3)

NOM

XkbNoteNameChanges - Noter les noms modifiés dans une structure de changements

SYNTAXE

void XkbNoteNameChanges (XkbNameChangesPtr ancien, XkbNamesNotifyEvent *nouveau, unsigned int voulu);

ARGUMENTS

ancien
Structure XkbNameChanges à mettre à jour
nouveau
Événement à partir duquel les changements doivent être copiés
voulu
Types de noms pour lesquels les changements doivent être notés

DESCRIPTION

Lorsque votre application reçoit un événement XkbNamesNotify, vous pouvez noter les noms modifiés dans une structure de changements en utilisant XkbNoteNameChanges.

Le paramètre voulu est l'OR logique bit à bit des bits de masque de noms valides indiqués dans le Tableau 1. XkbNoteNameChanges copie tous les changements rapportés dans nouveau et spécifiés dans voulu dans l'enregistrement des changements spécifié par ancien.
