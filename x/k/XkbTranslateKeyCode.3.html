XkbTranslateKeyCode(3) FONCTIONS XKB XkbTranslateKeyCode(3)

NOM

XkbTranslateKeyCode - Traduit un code de touche en symbole de touche et modificateurs

SYNTAXE

Bool XkbTranslateKeyCode (XkbDescPtr xkb, KeyCode key, unsigned int mods, unsigned int *mods_rtrn, KeySym *keysym_rtrn);

ARGUMENTS

xkb
description du clavier à utiliser pour la traduction
key
code de touche à traduire
mods
modificateurs à appliquer lors de la traduction de la touche
mods_rtrn
rempli avec les modificateurs consommés
keysym_rtrn
symbole de touche résultant de la traduction

DESCRIPTION

mods_rtrn est rempli avec les modificateurs consommés par le processus de traduction. mods est un OR logique bit à bit des masques de modificateurs valides : ShiftMask, LockMask, ControlMask, Mod1Mask, Mod2Mask, Mod3Mask, Mod4Mask, Mod5Mask. Le contrôle de la bibliothèque AlwaysConsumeShiftAndLock (voir ci-dessous), s'il est activé, fait que XkbTranslateKeyCode consomme les modificateurs Shift et Lock. XkbTranslateKeyCode renvoie True si la traduction a résulté en un symbole de touche, et False si elle a résulté en NoSymbol.

Le contrôle AlwaysConsumeShiftAndLock, s'il est activé, force XLookupString à consommer les modificateurs Shift et Lock lors du traitement de toutes les touches, même si la définition du type de touche ne spécifie pas ces modificateurs. Le contrôle AlwaysConsumeShiftAndLock est désactivé par défaut.
