XkbFreeClientMap(3) FONCTIONS XKB XkbFreeClientMap(3)

NOM

XkbFreeClientMap - Libérer la mémoire utilisée par le membre client map de la structure XkbDescRec

SYNOPSIS

void XkbFreeClientMap (XkbDescPtr xkb, unsigned int which, Bool free_all);

ARGUMENTS

xkb
description du clavier contenant la map client à libérer
which
masque identifiant les composants de la map à libérer
free_all
True => libérer tous les composants client et la map elle-même

DESCRIPTION

XkbFreeClientMap libère les composants de la map client spécifiés par which dans la structure XkbDescRec spécifiée par le paramètre xkb et met les valeurs des composants de structure correspondants à NULL. Le paramètre which spécifie une combinaison des masques de map client présentés dans le Tableau 1.

Si free_all est True, which est ignoré ; XkbFreeClientMap libère chaque composant de structure non-NULL dans la map client, libère la structure XkbClientMapRec référencée par le membre map du paramètre xkb, et met le membre map à NULL.

Tableau 1 Masques XkbAllocClientMap
Masque Effet
XkbKeyTypesMask Le champ type_count spécifie le nombre d'entrées à préallouer pour le champ types de la map client. Si le champ type_count est inférieur à XkbNumRequiredTypes, renvoie BadValue.
XkbKeySymsMask Les champs min_key_code et max_key_code du paramètre xkb sont utilisés pour allouer les champs syms et key_sym_map de la map client. Les champs sont alloués pour contenir le nombre maximal d'entrées nécessaires pour max_key_code - min_key_code + 1 touches.
XkbModifierMapMask Les champs min_key_code et max_key_code du paramètre xkb sont utilisés pour allouer le champ modmap de la map client. Le champ est alloué pour contenir le nombre maximal d'entrées nécessaires pour max_key_code - min_key_code + 1 touches.

NOTE : Les champs min_key_code et max_key_code du paramètre xkb doivent être des valeurs légales si les masques XkbKeySymsMask ou XkbModifierMapMask sont définis dans le paramètre which. S'ils ne sont pas valides, XkbAllocClientMap renvoie BadValue.

STRUCTURES

La description complète d'un clavier Xkb est donnée par une XkbDescRec. Les structures composantes de la XkbDescRec représentent les composants majeurs de Xkb.

typedef struct {
   struct _XDisplay * display;      /* connexion au serveur X */
   unsigned short     flags;        /* privé à Xkb, ne pas modifier */
   unsigned short     device_spec;  /* périphérique d'intérêt */
   KeyCode            min_key_code; /* keycode minimum pour le périphérique */
   KeyCode            max_key_code; /* keycode maximum pour le périphérique */
   XkbControlsPtr     ctrls;        /* contrôles */
   XkbServerMapPtr    server;       /* map de clavier serveur */
   XkbClientMapPtr    map;          /* map de clavier client */
   XkbIndicatorPtr    indicators;   /* map d'indicateurs */
   XkbNamesPtr        names;        /* noms pour tous les composants */
   XkbCompatMapPtr    compat;       /* map de compatibilité */
   XkbGeometryPtr     geom;         /* géométrie physique du clavier */
} XkbDescRec, *XkbDescPtr;
Le champ display pointe vers une structure d'affichage X. Le champ flags est privé à la librairie : modifier flags peut donner des résultats imprévisibles. Le champ device_spec spécifie l'identifiant du périphérique d'entrée clavier, ou XkbUseCoreKeyboard, qui spécifie le périphérique clavier principal. Les champs min_key_code et max_key_code spécifient le keycode le plus bas et le plus haut qui peut être retourné par le clavier.

Chaque composant structure a un bit de masque correspondant qui est utilisé dans les appels de fonction pour indiquer que la structure doit être manipulée d'une manière ou d'une autre, comme l'allocation ou la libération. Ces masques et leurs relations avec les champs de la XkbDescRec sont montrés dans le Tableau 2.

Tableau 2 Bits de masque pour XkbDescRec
Bit de masque Champ XkbDescRec Valeur
XkbControlsMask ctrls (1L<<0)
XkbServerMapMask server (1L<<1)
XkbIClientMapMask map (1L<<2)
XkbIndicatorMapMask indicators (1L<<3)
XkbNamesMask names (1L<<4)
XkbCompatMapMask compat (1L<<5)
XkbGeometryMask geom (1L<<6)
XkbAllComponentsMask Tous les champs (0x7f)

Le champ map de la description complète du clavier Xkb est un pointeur vers la map client Xkb, qui est de type XkbClientMapRec :

   typedef struct {                   /* Client Map */
      unsigned char     size_types;   /* # entrées occupées dans types */
      unsigned char     num_types;    /* # entrées dans types */
      XkbKeyTypePtr     types;        /* vecteur des types de touches utilisés par cette map de clavier */
      unsigned short    size_syms;    /* longueur du tableau syms */
      unsigned short    num_syms;     /* # entrées dans syms */
      KeySym *          syms;         /* tables linéaires 2D de keysyms, 1 par touche */
      XkbSymMapPtr      key_sym_map;  /* 1 par keycode, mappe keycode à syms */
      unsigned char *   modmap;       /* 1 par keycode, mods réels liés à la touche */
} XkbClientMapRec, *XkbClientMapPtr;
