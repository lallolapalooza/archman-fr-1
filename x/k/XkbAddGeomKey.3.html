XkbAddGeomKey(3) FONCTIONS XKB XkbAddGeomKey(3)

NOM

XkbAddGeomKey - Ajoute une clé à la fin d'une ligne de clés existante

SYNTAXE

XkbKeyPtr XkbAddGeomKey (XkbRowPtr ligne);

ARGUMENTS

ligne
ligne à mettre à jour

DESCRIPTION

Xkb fournit des fonctions pour ajouter un seul nouvel élément à la géométrie du clavier de haut niveau. Dans chaque cas, les champs num_ * de la structure correspondante sont incrémentés de 1. Ces fonctions ne modifient pas sz_* à moins qu'il n'y ait plus de place dans le tableau. Certaines de ces fonctions remplissent les valeurs de la structure de l'élément à partir des arguments. Pour d'autres fonctions, vous devez explicitement écrire du code pour remplir les éléments de la structure.

La description de la géométrie de haut niveau comprend une liste de propriétés de géométrie. Une propriété de géométrie associe une chaîne arbitraire à un nom tout aussi arbitraire. Les programmes qui affichent des images de claviers peuvent utiliser les propriétés de géométrie comme indices, mais elles ne sont pas interprétées par Xkb. Aucune autre structure de géométrie ne fait référence aux propriétés de géométrie.

Les clés sont regroupées en lignes. XkbAddGeomKey ajoute une clé à la fin de la ligne spécifiée. La clé est allouée et initialisée à zéro. XkbAddGeomKey renvoie NULL si ligne est vide ou s'il n'a pas pu allouer d'espace pour la clé. Pour allouer de l'espace pour un nombre arbitraire de clés à une ligne, utilisez XkbAllocGeomKeys.

STRUCTURES

    typedef struct _XkbKey {              /* clé dans une ligne */
        XkbKeyNameRec   name;             /* nom de la clé */
        short           gap;              /* espacement en mm/10 par rapport à la clé précédente de la ligne */
        unsigned char   shape_ndx;        /* index de la forme pour la clé */
        unsigned char   color_ndx;        /* index de la couleur pour le corps de la clé */
    } XkbKeyRec, *XkbKeyPtr;
