XkbGetIndicatorState(3) FONCTIONS XKB XkbGetIndicatorState(3)

NOM

XkbGetIndicatorState - Obtient l'état actuel des indicateurs du clavier

SYNOPSIS

Status XkbGetIndicatorState (Display *display, unsigned int device_spec, unsigned int state_return);

ARGUMENTS

display
connexion au serveur X
device_spec
ID de l'appareil, ou XkbUseCoreKbd
state_return
rempli avec un masque de l'état de l'indicateur

DESCRIPTION

Xkb permet aux applications d'obtenir des informations sur les indicateurs de deux manières différentes. La première méthode, similaire à l'implémentation du noyau X, utilise un masque pour spécifier les indicateurs. La seconde méthode, plus adaptée aux applications soucieuses de l'interopérabilité, utilise des noms d'indicateurs. La correspondance entre le nom de l'indicateur et la position du bit dans les masques est la suivante : l'un des paramètres renvoyés par XkbGetNamedIndicators est un index qui correspond à la position du bit à utiliser dans tout appel de fonction nécessitant un masque de bits d'indicateurs, ainsi qu'à l'index de l'indicateur dans le tableau XkbIndicatorRec des cartes d'indicateurs.

XkbGetIndicatorState interroge le display pour connaître l'état des indicateurs sur le périphérique spécifié par device_spec. Pour chaque indicateur qui est "allumé" sur le périphérique, le bit associé est positionné dans state_return. Si une version compatible de l'extension Xkb n'est pas disponible dans le serveur, XkbGetIndicatorState renvoie une erreur BadMatch. Sinon, il envoie la requête au serveur X, place l'état des indicateurs dans state_return et renvoie Success. Ainsi, la valeur signalée par XkbGetIndicatorState est identique à la valeur signalée par le protocole de base.

DIAGNOSTICS

BadMatch
Une version compatible de Xkb n'était pas disponible dans le serveur ou un argument a un type et une plage corrects, mais est par ailleurs invalide
