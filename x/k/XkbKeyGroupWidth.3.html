NOM

XkbKeyGroupWidth - Calcule la largeur du type associé au groupe grp pour la touche correspondant à keycode

SYNTAXE

int XkbKeyGroupWidth (XkbDescPtr xkb, KeyCode keycode, int grp);

ARGUMENTS

xkb
Description Xkb d'intérêt
keycode
Code de touche d'intérêt
grp
Groupe d'intérêt

DESCRIPTION

La largeur de la touche et le nombre de groupes associés à une touche sont utilisés pour former un petit tableau bidimensionnel de KeySyms pour une touche. Ce tableau peut avoir des tailles différentes pour des touches différentes. Le tableau pour une seule touche est stocké sous forme de liste linéaire, en ordre par ligne. Les tableaux pour toutes les touches sont stockés dans le champ syms de la carte client. Il y a une ligne pour chaque groupe associé à une touche et une colonne pour chaque niveau. L'index correspondant à un groupe et un niveau de décalage donnés est calculé comme suit :

     idx = group_index * key_width + shift_level

Le champ offset de l'entrée key_sym_map pour une touche est utilisé pour accéder au début du tableau.

XkbKeyGroupWidth calcule la largeur du type associé au groupe grp pour la touche correspondant à keycode.
