NOM

XkbSetModActionVMods - Définit les champs vmods1 et vmods2 de l'action en utilisant le format vmods d'une description de modificateur Xkb

SYNOPSIS

void XkbSetModActionVMods (XkbAction act, unsigned short vmods);

ARGUMENTS

act
action dans laquelle définir les vmods
vmods
mods virtuels à définir

DESCRIPTION

XkbSetModActionVMods définit les champs vmods1 et vmods2 de act en utilisant le format vmods d'une description de modificateur Xkb.

NOTES

Malgré le fait que le premier paramètre de ces deux macros soit de type XkbAction, ces macros ne peuvent être utilisées qu'avec des actions de type XkbModAction et XkbISOAction.
