Paquet: libx11

Licences: MIT AND X11

XkbSetPtrActionY(3) FONCTIONS XKB XkbSetPtrActionY(3)

NOM

XkbSetPtrActionY - Définit les champs high_YYY et low_YYY de act à partir de la valeur entière signée y

SYNTAXE

void XkbSetPtrActionY (XkbPtrAction act, int y);

ARGUMENTS

act
action dans laquelle définir Y
y
nouvelle valeur à définir

DESCRIPTION

Les actions associées à la structure XkbPtrAction déplacent le pointeur lorsque les touches sont pressées et relâchées.

Si le contrôle MouseKeys n'est pas activé, les événements KeyPress et KeyRelease sont traités comme si l'action était XkbSA_NoAction.

Si le contrôle MouseKeys est activé, une action serveur de type XkbSA_MovePtr demande au serveur de générer des événements core pointer MotionNotify plutôt que l'événement KeyPress habituel, et l'événement KeyRelease correspondant désactive tous les timers de souris qui ont été créés suite au traitement de l'action XkbSA_MovePtr.

Le champ type de la structure XkbPtrAction est toujours XkbSA_MovePtr.

Le champ flags est un OU inclusif au niveau du bit des masques montrés dans le Tableau 1.

Tableau 1 Types d'actions du pointeur
Type d'action Signification
XkbSA_NoAcceleration Si non défini, et si le contrôle MouseKeysAccel est activé, le KeyPress initie un timer de souris pour cette touche ; à chaque expiration du timer, le curseur se déplace.
XkbSA_MoveAbsoluteX Si défini, la partie X de la structure spécifie la nouvelle coordonnée X du pointeur. Sinon, la partie X est ajoutée à la coordonnée X actuelle du pointeur pour déterminer la nouvelle coordonnée X du pointeur.
XkbSA_MoveAbsoluteY Si défini, la partie Y de la structure spécifie la nouvelle coordonnée Y du pointeur. Sinon, la partie Y est ajoutée à la coordonnée Y actuelle du pointeur pour déterminer la nouvelle coordonnée Y du pointeur.

Chacune des coordonnées X et Y de la structure XkbPtrAction est composée de deux valeurs signées de 16 bits, c'est-à-dire que la coordonnée X est composée de high_XXX et low_XXX, et de même pour la coordonnée Y. Xkb fournit les macros suivantes pour convertir entre un entier signé et deux valeurs signées de 16 bits dans les structures XkbPtrAction.

STRUCTURES

    typedef struct _XkbPtrAction {
        unsigned char    type;         /* XkbSA_MovePtr */
        unsigned char    flags;        /* détermine le type de mouvement du pointeur */
        unsigned char    high_XXX;     /* coordonnée X, bits de poids fort*/
        unsigned char    low_XXX;      /* coordonnée Y, bits de poids faible */
        unsigned char    high_YYY;     /* coordonnée X, bits de poids fort */
        unsigned char    low_YYY;      /* coordonnée Y, bits de poids faible */
    } XkbPtrAction;
