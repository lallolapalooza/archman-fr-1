XkbGetKeyModifierMap(3) FONCTIONS XKB XkbGetKeyModifierMap(3)

NOM

XkbGetKeyModifierMap - Met à jour la table des modificateurs pour une ou plusieurs des touches dans une description de clavier

SYNOPSIS

Status XkbGetKeyModifierMap (Display *dpy, unsigned int first, unsigned int num, XkbDescPtr xkb);

ARGUMENTS

dpy
connexion au serveur X
first
code de touche de la première touche à obtenir
num
nombre de touches pour lesquelles des informations sont désirées
xkb
description du clavier à mettre à jour

DESCRIPTION

L'entrée modmap de la carte client est un tableau, indexé par le code de touche, spécifiant les modificateurs réels liés à une touche. Chaque entrée est un masque composé d'une OR inclusive bit à bit des modificateurs réels légaux : ShiftMask, LockMask, ControlMask, Mod1Mask, Mod2Mask, Mod3Mask, Mod4Mask et Mod5Mask. Si un bit est défini dans une entrée modmap, la touche correspondante est liée à ce modificateur.

Appuyer ou relâcher la touche liée à un modificateur change l'état d'ensemble et de désactivation du modificateur. La manière particulière dont l'état d'ensemble et de désactivation du modificateur change est déterminée par le comportement et les actions assignés à la touche.

XkbGetKeyModifierMap envoie une requête au serveur pour les mappings de modificateurs pour num touches à partir de la touche dont le code est first. Il attend une réponse et place les résultats dans le tableau xkb->map->modmap. En cas de succès, XkbGetKeyModifier renvoie Success.

Si le composant map de paramètre xkb n'a pas été alloué, XkbGetKeyModifierMap l'alloue et l'initialise.

Si une version compatible de Xkb n'est pas disponible dans le serveur ou si l'extension Xkb n'a pas été correctement initialisée, XkbGetKeySyms renvoie BadAccess. Si des erreurs d'allocation se produisent lors de l'obtention de la table des modificateurs, XkbGetKeyModifierMap renvoie BadAlloc.

DIAGNOSTICS

BadAccess
L'extension Xkb n'a pas été correctement initialisée
BadAlloc
Impossible d'allouer de l'espace
