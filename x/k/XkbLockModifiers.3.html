XkbLockModifiers(3) FONCTIONS XKB XkbLockModifiers(3)

NOM

XkbLockModifiers - Verrouille et déverrouille n'importe lequel des huit modificateurs réels du clavier

SYNTAXE

Bool XkbLockModifiers (Display *display, unsigned int device_spec, unsigned int affect, unsigned int values);

ARGUMENTS

display
connexion au serveur X
device_spec
identifiant du périphérique, ou XkbUseCoreKbd
affect
masque des modificateurs réels dont l'état de verrouillage doit changer
values
1 => verrouiller, 0 => déverrouiller ; uniquement pour les modificateurs sélectionnés par affect

DESCRIPTION

XkbLockModifiers envoie une requête au serveur pour verrouiller les modificateurs réels sélectionnés par affect et values et pour déverrouiller les modificateurs réels sélectionnés par affect, mais pas par values. XkbLockModifiers n'attend pas de réponse du serveur. Elle renvoie True si la requête a été envoyée, et False sinon.

Les fonctions de cette section qui modifient l'utilisation des modificateurs utilisent un masque dans le paramètre affect. Il s'agit d'un OU binaire inclusif des masques de modificateurs légaux :

Table 1 Masques de modificateurs réels
Masque
ShiftMask
LockMask
ControlMask
Mod1Mask
Mod2Mask
Mod3Mask
Mod4Mask
Mod5Mask

VALEURS DE RETOUR

True
La fonction XkbLockModifiers renvoie True si une requête est envoyée au serveur pour verrouiller les modificateurs réels sélectionnés par affect et values et pour déverrouiller les modificateurs réels sélectionnés par affect, mais pas par values.
False
La fonction XkbLockModifiers renvoie False si la requête n'a pas été envoyée.
