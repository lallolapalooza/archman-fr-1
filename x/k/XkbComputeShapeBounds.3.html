XkbComputeShapeBounds(3) FONCTIONS XKB XkbComputeShapeBounds(3)

NOM

XkbComputeShapeBounds - Met à jour la boîte englobante d'une forme

SYNTAXE

Bool XkbComputeShapeBounds (XkbShapePtr shape);

ARGUMENTS

shape
forme à examiner

DESCRIPTION

Xkb fournit un certain nombre de fonctions utilitaires pour aider à utiliser une géométrie de clavier. Celles-ci incluent des fonctions pour retourner la boîte englobante de la surface supérieure d'une forme et pour mettre à jour la boîte englobante d'une ligne ou d'une section de forme.

Une forme est composée d'un certain nombre de contours. Chaque contour est un polygone composé d'un certain nombre de points. La boîte englobante d'une forme est un rectangle qui contient tous les contours de cette forme.

Une ShapeRec contient une BoundsRec qui décrit les limites de la forme. Si vous ajoutez ou supprimez un contour d'une forme, la boîte englobante doit être mise à jour.

XkbComputeShapeBounds met à jour la BoundsRec contenue dans la forme en examinant tous les contours de la forme et en définissant la BoundsRec avec les valeurs x minimum et y minimum, et x maximum et y maximum trouvées dans ces contours. XkbComputeShapeBounds retourne False si shape est NULL ou s'il n'y a pas de contours pour la forme ; sinon, elle retourne True.

Si vous ajoutez ou supprimez une touche d'une ligne, ou si vous mettez à jour la forme de l'une des touches de cette ligne, vous devrez peut-être mettre à jour la boîte englobante de cette ligne. Pour mettre à jour la boîte englobante d'une ligne, utilisez XkbComputeRowBounds.

STRUCTURES

typedef struct _XkbShape {
    Atom           name;         /* nom de la forme */
    unsigned short num_outlines; /* nombre de contours pour la forme */
    unsigned short sz_outlines;  /* taille du tableau de contours */
    XkbOutlinePtr  outlines;     /* tableau de contours pour la forme */
    XkbOutlinePtr  approx;       /* pointeur vers le contour approximatif dans le tableau */
    XkbOutlinePtr  primary;      /* pointeur vers le contour principal dans le tableau */
    XkbBoundsRec   bounds;       /* boîte englobante pour la forme ; englobe tous les contours */
} XkbShapeRec, *XkbShapePtr;
typedef struct _XkbBounds {
    short	x1,y1;	/* coin supérieur gauche des limites, en mm/10 */
    short	x2,y2;	/* coin inférieur droit des limites, en mm/10 */
} XkbBoundsRec, *XkbBoundsPtr;
