XkbKeyKeyType(3) FONCTIONS XKB XkbKeyKeyType(3)

NOM

XkbKeyKeyType - Obtenir l'index d'un type de touche ou le pointeur vers un type de touche

SYNTAXE

XkbKeyTypePtr XkbKeyKeyType (XkbDescPtr xkb, KeyCode keycode, int group);

ARGUMENTS

xkb
Description Xkb d'intérêt
keycode
Code de touche d'intérêt
group
Index de groupe

DESCRIPTION

XkbKeyKeyType renvoie un pointeur vers le type de touche dans le vecteur types de la carte client dans xkb correspondant au keycode et à l'index de group fournis.

STRUCTURES

typedef struct {                             /* Type de touche */
	XkbModsRec              mods;           /* Modificateurs utilisés pour calculer le niveau de décalage */
	unsigned char           num_levels;     /* Nombre total de niveaux de décalage, ne pas modifier directement */
	unsigned char           map_count;      /* Nombre d'entrées dans la carte, préserver (si non NULL) */
	XkbKTMapEntryPtr        map;            /* Vecteur de modificateurs pour chaque niveau de décalage */
	XkbModsPtr              preserve;       /* Modificateurs à préserver pour l'entrée de carte correspondante */
	Atom                    name;           /* Nom du type de touche */
	Atom *                  level_names;    /* Tableau de noms de chaque niveau de décalage */
} XkbKeyTypeRec, *XkbKeyTypePtr;
