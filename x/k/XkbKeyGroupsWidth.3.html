XkbKeyGroupsWidth(3) FONCTIONS XKB XkbKeyGroupsWidth(3)

NOM

XkbKeyGroupsWidth - Calcule la largeur maximale associée à la touche correspondant à keycode

SYNTAXE

int XkbKeyGroupsWidth (XkbDescPtr xkb, KeyCode keycode);

ARGUMENTS

xkb
Description Xkb d'intérêt
keycode
Code de touche d'intérêt

DESCRIPTION

La largeur de la touche et le nombre de groupes associés à une touche sont utilisés pour former un petit tableau bidimensionnel de KeySyms pour une touche. Ce tableau peut avoir des tailles différentes pour différentes touches. Le tableau pour une seule touche est stocké sous forme de liste linéaire, en ordre ligne par ligne (row-major). Les tableaux pour toutes les touches sont stockés dans le champ syms de la carte client. Il y a une ligne pour chaque groupe associé à une touche et une colonne pour chaque niveau. L'indice correspondant à un groupe et un niveau de décalage donnés est calculé comme suit :

     idx = group_index * key_width + shift_level

Le champ offset de l'entrée key_sym_map pour une touche est utilisé pour accéder au début du tableau.

XkbKeyGroupsWidth calcule la largeur maximale associée à la touche correspondant à keycode.
