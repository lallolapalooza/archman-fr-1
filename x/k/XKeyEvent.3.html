XButtonEvent(3) FONCTIONS XLIB XButtonEvent(3)

NOM

XButtonEvent, XKeyEvent, XMotionEvent - Structures d'événements KeyPress, KeyRelease, ButtonPress, ButtonRelease et MotionNotify

STRUCTURES

Les structures pour les événements KeyPress, KeyRelease, ButtonPress, ButtonRelease et MotionNotify contiennent :

typedef struct {
        int type;       /* ButtonPress ou ButtonRelease */
        unsigned long serial;   /* # de la dernière requête traitée par le serveur */
        Bool send_event;        /* vrai si cela provient d'une requête SendEvent */
        Display *display;       /* Affichage à partir duquel l'événement a été lu */
        Window window;  /* fenêtre « d'événement » par rapport à laquelle il est rapporté */
        Window root;    /* fenêtre racine sur laquelle l'événement s'est produit */
        Window subwindow;       /* fenêtre enfant */
        Time time;      /* millisecondes */
        int x, y;       /* coordonnées du pointeur x, y dans la fenêtre d'événement */
        int x_root, y_root;     /* coordonnées relatives à la fenêtre racine */
        unsigned int state;     /* masque de touche ou de bouton */
        unsigned int button;    /* détail */
        Bool same_screen;       /* indicateur même écran */
} XButtonEvent;
typedef XButtonEvent XButtonPressedEvent;
typedef XButtonEvent XButtonReleasedEvent;
typedef struct {
        int type;       /* KeyPress ou KeyRelease */
        unsigned long serial;   /* # de la dernière requête traitée par le serveur */
        Bool send_event;        /* vrai si cela provient d'une requête SendEvent */
        Display *display;       /* Affichage à partir duquel l'événement a été lu */
        Window window;  /* fenêtre « d'événement » par rapport à laquelle il est rapporté */
        Window root;    /* fenêtre racine sur laquelle l'événement s'est produit */
        Window subwindow;       /* fenêtre enfant */
        Time time;      /* millisecondes */
        int x, y;       /* coordonnées du pointeur x, y dans la fenêtre d'événement */
        int x_root, y_root;     /* coordonnées relatives à la fenêtre racine */
        unsigned int state;     /* masque de touche ou de bouton */
        unsigned int keycode;   /* détail */
        Bool same_screen;       /* indicateur même écran */
} XKeyEvent;
typedef XKeyEvent XKeyPressedEvent;
typedef XKeyEvent XKeyReleasedEvent;
typedef struct {
        int type;       /* MotionNotify */
        unsigned long serial;   /* # de la dernière requête traitée par le serveur */
        Bool send_event;        /* vrai si cela provient d'une requête SendEvent */
        Display *display;       /* Affichage à partir duquel l'événement a été lu */
        Window window;  /* fenêtre « d'événement » par rapport à laquelle il est rapporté */
        Window root;    /* fenêtre racine sur laquelle l'événement s'est produit */
        Window subwindow;       /* fenêtre enfant */
        Time time;      /* millisecondes */
        int x, y;       /* coordonnées du pointeur x, y dans la fenêtre d'événement */
        int x_root, y_root;     /* coordonnées relatives à la fenêtre racine */
        unsigned int state;     /* masque de touche ou de bouton */
        char is_hint;   /* détail */
        Bool same_screen;       /* indicateur même écran */
} XMotionEvent;
typedef XMotionEvent XPointerMovedEvent;

Lorsque vous recevez ces événements, les membres de leur structure sont définis comme suit.

Le membre type est défini sur le nom de la constante du type d'événement qui l'identifie de manière unique. Par exemple, lorsque le serveur X rapporte un événement GraphicsExpose à une application cliente, il envoie une structure XGraphicsExposeEvent avec le membre type défini sur GraphicsExpose. Le membre display est défini sur un pointeur vers l'affichage sur lequel l'événement a été lu. Le membre send_event est défini sur True si l'événement provient d'une requête de protocole SendEvent. Le membre serial est défini à partir du numéro de série rapporté dans le protocole mais développé à partir des 16 bits de poids faible en une valeur complète de 32 bits. Le membre window est défini sur la fenêtre la plus utile aux répartiteurs de trousseaux.

Ces structures ont les membres communs suivants : window, root, subwindow, time, x, y, x_root, y_root, state et same_screen. Le membre window est défini sur la fenêtre sur laquelle l'événement a été généré et est désigné comme la fenêtre d'événement. Tant que les conditions mentionnées précédemment sont remplies, c'est la fenêtre utilisée par le serveur X pour rapporter l'événement. Le membre root est défini sur la fenêtre racine de la fenêtre source. Les membres x_root et y_root sont définis sur les coordonnées du pointeur par rapport à l'origine de la fenêtre racine au moment de l'événement.

Le membre same_screen est défini pour indiquer si la fenêtre d'événement est sur le même écran que la fenêtre racine et peut être soit True, soit False. Si True, les fenêtres d'événement et racine sont sur le même écran. Si False, les fenêtres d'événement et racine ne sont pas sur le même écran.

Si la fenêtre source est un inférieur de la fenêtre d'événement, le membre subwindow de la structure est défini sur la fenêtre enfant de la fenêtre d'événement qui est la fenêtre source ou la fenêtre enfant de la fenêtre d'événement qui est un ancêtre de la fenêtre source. Sinon, le serveur X définit le membre subwindow sur None. Le membre time est défini sur l'heure à laquelle l'événement a été généré et est exprimé en millisecondes.

Si la fenêtre d'événement est sur le même écran que la fenêtre racine, les membres x et y sont définis sur les coordonnées relatives à l'origine de la fenêtre d'événement. Sinon, ces membres sont définis sur zéro.

Le membre state est défini pour indiquer l'état logique des boutons du pointeur et des touches modificateurs juste avant l'événement, qui est l'OU bit à bit inclusif d'un ou plusieurs des masques de bouton ou de touche modificateur : Button1Mask, Button2Mask, Button3Mask, Button4Mask, Button5Mask, ShiftMask, LockMask, ControlMask, Mod1Mask, Mod2Mask, Mod3Mask, Mod4Mask et Mod5Mask.

Chacune de ces structures possède également un membre qui indique le détail. Pour les structures XKeyPressedEvent et XKeyReleasedEvent, ce membre est appelé keycode. Il est défini sur un nombre qui représente une touche physique du clavier. Le keycode est une représentation arbitraire pour toute touche du clavier (voir les sections 12.7 et 16.1).

Pour les structures XButtonPressedEvent et XButtonReleasedEvent, ce membre est appelé button. Il représente le bouton du pointeur qui a changé d'état et peut être la valeur Button1, Button2, Button3, Button4 ou Button5. Pour la structure XPointerMovedEvent, ce membre est appelé is_hint. Il peut être défini sur NotifyNormal ou NotifyHint.
