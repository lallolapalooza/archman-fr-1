XkbAllocCompatMap(3)

Paquet: libx11

Licences: MIT AND X11

XkbAllocCompatMap(3) FONCTIONS XKB XkbAllocCompatMap(3)

NOM

XkbAllocCompatMap - Alloue une nouvelle carte de compatibilité si vous n'en avez pas déjà une disponible

SYNTAXE

Status XkbAllocCompatMap (XkbDescPtr xkb, unsigned int which, unsigned int num_si);

ARGUMENTS

xkb
description du clavier dans laquelle allouer la carte de compatibilité
which
masque des composants de la carte de compatibilité à allouer
num_si
nombre d'interprétations de symboles à allouer

DESCRIPTION

xkb spécifie la description du clavier pour laquelle les cartes de compatibilité doivent être allouées. La carte de compatibilité est le champ compat de cette structure.

which spécifie les composants de la carte de compatibilité à allouer (voir XkbGetCompatMap). which est un OU inclusif des bits indiqués dans le Tableau 1.

Tableau 1 Masques des composants de la carte de compatibilité
Masque Valeur Affectant
XkbSymInterpMask (1<<0) Interprétations de symboles
XkbGroupCompatMask (1<<1) Cartes de groupes
XkbAllCompatMask (0x3) Tous les composants de la carte de compatibilité

num_si spécifie le nombre total d'entrées à allouer dans le vecteur d'interprétation de symboles (xkb.compat.sym_interpret).

XkbAllocCompatMap renvoie Success en cas de succès, BadMatch si xkb est NULL, ou BadAlloc si des erreurs sont rencontrées lors de la tentative d'allocation de stockage.

STRUCTURES

    typedef struct {
        KeySym            sym;          /* touche de symbole intéressante ou NULL */
        unsigned char     flags;        /* XkbSI_AutoRepeat, XkbSI_LockingKey */
        unsigned char     match;        /* spécifie comment les modificateurs sont interprétés */
        unsigned char     mods;         /* bits de modificateurs, correspondent à huit modificateurs réels */
        unsigned char     virtual_mod;  /* 1 modificateur à ajouter à la carte des modificateurs virtuels de la touche */
        XkbAnyAction      act;          /* action à lier à la position du symbole sur la touche */
    } XkbSymInterpretRec,*XkbSymInterpretPtr;

DIAGNOSTICS

BadAlloc
Impossible d'allouer du stockage
BadMatch
Une version compatible de Xkb n'était pas disponible sur le serveur ou un argument a le bon type et la bonne plage, mais est par ailleurs invalide

VOIR AUSSI

XkbGetCompatMap(3)

NOTES

Notez que les interprétations de symboles dans une carte de compatibilité (le vecteur sym_interpret des structures XkbSymInterpretRec) sont également allouées en utilisant cette même fonction. Pour s'assurer qu'il y a suffisamment d'espace dans le vecteur d'interprétation de symboles pour y ajouter des entrées, utilisez XkbAllocCompatMap en spécifiant which comme XkbSymInterpretMask et le nombre d'interprétations de symboles libres nécessaires dans num_si.
