NOM

XkbAddGeomSection - Ajouter une section à une géométrie de clavier existante

SYNTAXE

XkbSectionPtr XkbAddGeomSection (XkbGeometryPtr geom, Atom name, int sz_rows, int sz_doodads, int sz_overlays);

ARGUMENTS

geom
géométrie à mettre à jour
name
nom de la nouvelle section
sz_rows
nombre de lignes à réserver dans la section
sz_doodads
nombre de "doodads" à réserver dans la section
sz_overlays
nombre de superpositions à réserver dans la section

DESCRIPTION

Xkb fournit des fonctions pour ajouter un nouvel élément à la géométrie de haut niveau du clavier. Dans chaque cas, les champs num_ * de la structure correspondante sont incrémentés de 1. Ces fonctions ne modifient pas sz_* sauf s'il n'y a plus de place dans le tableau. Certaines de ces fonctions remplissent les valeurs de la structure de l'élément à partir des arguments. Pour d'autres fonctions, vous devez explicitement écrire du code pour remplir les éléments de la structure.

La description de géométrie de haut niveau inclut une liste de propriétés de géométrie. Une propriété de géométrie associe une chaîne arbitraire à un nom tout aussi arbitraire. Les programmes qui affichent des images de claviers peuvent utiliser les propriétés de géométrie comme indices, mais elles ne sont pas interprétées par Xkb. Aucune autre structure de géométrie ne fait référence aux propriétés de géométrie.

Une géométrie de clavier contient un nombre arbitraire de sections. XkbAddGeomSection ajoute une section à une géométrie de clavier existante geom. La nouvelle section contient de l'espace pour le nombre de lignes, de "doodads" et de superpositions spécifiés par sz_rows, sz_doodads et sz_overlays. La nouvelle section est allouée, initialisée à zéro et reçoit le nom spécifié par name. Si une section portant le nom name existe déjà dans la géométrie, un pointeur vers la section existante est retourné. XkbAddGeomSection retourne NULL si l'un des paramètres est vide ou s'il n'a pas pu allouer d'espace pour la section. Pour allouer de l'espace pour un nombre arbitraire de sections à une géométrie, utilisez XkbAllocGeomSections.

STRUCTURES

typedef struct _XkbSection {
    Atom                    name;        /* nom de la section */
    unsigned char           priority;    /* priorité de dessin, 0=>la plus haute, 255=>la plus basse */
    short                   top;         /* coordonnée supérieure de l'origine de la section */
    short                   left;        /* coordonnée gauche de l'origine de la ligne */
    unsigned short          width;       /* largeur de la section, en mm/10 */
    unsigned short          height;      /* hauteur de la section, en mm/10 */
    short                   angle;       /* angle de rotation de la section, dans le sens antihoraire */
    unsigned short          num_rows;    /* nombre de lignes dans le tableau des lignes */
    unsigned short          num_doodads; /* nombre de "doodads" dans le tableau des "doodads" */
    unsigned short          num_overlays; /* nombre de superpositions dans le tableau des superpositions */
    unsigned short          sz_rows;      /* taille du tableau des lignes */
    unsigned short          sz_doodads;   /* taille du tableau des "doodads" */
    unsigned short          sz_overlays;  /* taille du tableau des superpositions */
    XkbRowPtr               rows;         /* tableau des lignes de la section */
    XkbDoodadPtr            doodads;      /* tableau des "doodads" de la section */
    XkbBoundsRec            bounds;       /* boîte englobante pour la section, avant rotation */
    XkbOverlayPtr           overlays;     /* tableau des superpositions de la section */
} XkbSectionRec, *XkbSectionPtr;

top et left sont l'origine de la section, par rapport à l'origine du clavier, en mm/10. angle est en 1/10 de degré.
