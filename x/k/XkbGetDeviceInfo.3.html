XkbGetDeviceInfo(3) FONCTIONS XKB XkbGetDeviceInfo(3)

NOM

XkbGetDeviceInfo - Détermine si le serveur X autorise l'accès Xkb à des capacités particulières des périphériques d'entrée autres que le clavier X principal, ou détermine l'état des cartes d'indicateurs, des noms d'indicateurs ou des actions de boutons sur un périphérique d'extension ne faisant pas partie de la classe Clavier.

SYNTAXE

XkbDeviceInfoPtr XkbGetDeviceInfo (Display *dpy, unsigned int which, unsigned int device_spec, unsigned int ind_class, unsigned int ind_id);

ARGUMENTS

dpy
connexion au serveur X
which
masque indiquant les informations à retourner
device_spec
ID du périphérique, ou XkbUseCoreKbd
ind_class
classe de rétroaction pour les requêtes d'indicateur
ind_id
ID de rétroaction pour les requêtes d'indicateur

DESCRIPTION

Pour déterminer si le serveur X autorise l'accès Xkb à des capacités particulières des périphériques d'entrée autres que le clavier X principal, ou pour déterminer l'état des cartes d'indicateurs, des noms d'indicateurs ou des actions de boutons sur un périphérique d'extension ne faisant pas partie de la classe Clavier, utilisez XkbGetDeviceInfo.

XkbGetDeviceInfo retourne des informations sur le périphérique d'entrée spécifié par device_spec. Contrairement au paramètre device_spec de la plupart des fonctions Xkb, device_spec n'a pas besoin d'être un périphérique clavier. Il doit cependant indiquer soit le clavier principal, soit un périphérique valide de l'extension d'entrée X.

Le paramètre which est un masque spécifiant les informations optionnelles à retourner. C'est une combinaison OR inclusive d'une ou plusieurs des valeurs du Tableau 1 et provoque le remplissage de la structure XkbDeviceInfoRec retournée avec les valeurs des champs correspondants spécifiés dans le tableau.

La structure XkbDeviceInfoRec retournée par XkbGetDeviceInfo contient toujours des valeurs pour les champs name (peut être une chaîne nulle, ""), type, supported, unsupported, has_own_state, dflt_kbd_fd, et dflt_kbd_fb. Les autres champs sont remplis comme spécifié par which.

Au retour, le champ supported sera défini à la combinaison OR inclusive de zéro ou plusieurs bits du Tableau 1 ; chaque bit défini indique une fonctionnalité optionnelle du périphérique d'extension Xkb prise en charge par l'implémentation du serveur, et un client peut modifier le comportement associé.

Si le bit XkbButtonActionsMask est défini dans which, la structure XkbDeviceInfoRec retournée aura les actions de boutons (champ btn_acts) remplies pour tous les boutons.

Si which inclut l'un des bits de XkbXI_IndicatorsMask, la classe de rétroaction des indicateurs doit être spécifiée dans ind_class, et l'ID de rétroaction des indicateurs doit être spécifié dans ind_id. Si la requête n'inclut aucun des bits de XkbXI_IndicatorsMask, les paramètres ind_class et ind_id sont ignorés. La classe et l'ID peuvent être obtenus via la requête XListInputDevices de l'extension d'entrée.

Si l'un des bits de XkbXI_IndicatorsMask est défini dans which, la structure XkbDeviceInfoRec retournée aura les portions de la structure leds remplies correspondant à la rétroaction de l'indicateur identifiée par ind_class et ind_id. Le vecteur leds de la structure XkbDeviceInfoRec est alloué si nécessaire et sz_leds et num_leds sont remplis. Les champs led_class, led_id et phys_indicators de l'entrée leds correspondant à ind_class et ind_id sont toujours remplis. Si which contient XkbXI_IndicatorNamesMask, les champs names_present et names de la structure leds correspondant à ind_class et ind_id sont retournés. Si which contient XkbXI_IndicatorStateMask, le champ state correspondant est mis à jour. Si which contient XkbXI_IndicatorMapsMask, les champs maps_present et maps sont mis à jour.

Xkb fournit des fonctions pratiques pour demander des sous-ensembles des informations disponibles via XkbGetDeviceInfo. Ces fonctions pratiques reflètent certains des bits de masque. Toutes les fonctions prennent une structure XkbDeviceInfoPtr comme argument d'entrée et opèrent sur le périphérique d'extension d'entrée X spécifié par le champ device_spec de la structure. Seules les parties de la structure indiquées dans la description de la fonction sont mises à jour. La structure XkbDeviceInfoRec utilisée dans l'appel de fonction peut être obtenue en appelant XkbGetDeviceInfo ou peut être allouée en appelant XkbAllocDeviceInfo.

STRUCTURES

Les informations sur les périphériques d'extension d'entrée X sont transférées entre un programme client et l'extension Xkb dans une structure XkbDeviceInfoRec :

typedef struct {
    char *               name;          /* nom du périphérique */
    Atom                 type;          /* nom de la classe des périphériques */
    unsigned short       device_spec;   /* périphérique d'intérêt */
    Bool                 has_own_state; /* Vrai => ce périphérique a son propre état */
    unsigned short       supported;     /* bits indiquant les capacités prises en charge */
    unsigned short       unsupported;   /* bits indiquant les capacités non prises en charge */
    unsigned short       num_btns;      /* nombre d'entrées dans btn_acts */
    XkbAction *          btn_acts;      /* actions de boutons */
    unsigned short       sz_leds;       /* nombre total d'entrées dans le vecteur LEDs */
    unsigned short       num_leds;      /* nombre d'entrées valides dans le vecteur LEDs */
    unsigned short       dflt_kbd_fb;   /* ID de l'extension d'entrée pour l'indicateur par défaut (clavier principal) */
    unsigned short       dflt_led_fb;   /* ID de l'extension d'entrée pour l'indicateur par défaut */
    XkbDeviceLedInfoPtr  leds;          /* descriptions des LEDs */
} XkbDeviceInfoRec, *XkbDeviceInfoPtr;
