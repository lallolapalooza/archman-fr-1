XkbSelectEventDetails(3) FONCTIONS XKB XkbSelectEventDetails(3)

NOM

XkbSelectEventDetails - Sélectionne ou désélectionne un événement Xkb spécifique et place éventuellement des conditions sur le moment où les événements de ce type sont rapportés à votre client.

SYNTAXE

Bool XkbSelectEventDetails (Display *display, unsigned int device_spec, unsigned int event_type, unsigned long int bits_to_change, unsigned long int values_for_bits);

ARGUMENTS

display
connexion au serveur X
device_spec
identifiant du périphérique, ou XkbUseCoreKbd
event_type
type d'événement Xkb d'intérêt
bits_to_change
détermine les événements à sélectionner / désélectionner
values_for_bits
1=>sélectionner, 0=>désélectionner ; pour les événements dans bits_to_change

DESCRIPTION

Les événements Xkb sont sélectionnés à l'aide d'un masque d'événements, tout comme les événements X de base sont sélectionnés. Cependant, contrairement à la sélection des événements X de base, où vous devez spécifier le statut de sélection (activé ou désactivé) pour tous les types d'événements possibles chaque fois que vous souhaitez modifier les critères de sélection pour un événement donné, Xkb vous permet de restreindre la spécification aux seuls types d'événements que vous souhaitez modifier. Cela signifie que vous n'avez pas besoin de mémoriser les valeurs de sélection d'événements pour tous les types possibles à chaque fois que vous souhaitez en modifier un.

De nombreux types d'événements Xkb sont générés dans plusieurs circonstances différentes. Lors de la sélection pour recevoir un événement Xkb, vous pouvez spécifier soit que vous souhaitez qu'il soit livré dans toutes les circonstances, soit que vous souhaitez qu'il soit livré uniquement pour un sous-ensemble des circonstances possibles.

Vous pouvez également désélectionner un type d'événement pour lequel vous aviez précédemment sélectionné, en utilisant la même granularité.

Xkb fournit deux fonctions pour sélectionner et désélectionner la livraison des événements Xkb. XkbSelectEvents vous permet de sélectionner ou désélectionner la livraison de plusieurs types d'événements Xkb à la fois. Les événements sélectionnés à l'aide de XkbSelectEvents sont livrés à votre programme dans toutes les circonstances qui génèrent les événements. Pour restreindre la livraison d'un événement à un sous-ensemble des conditions dans lesquelles il se produit, utilisez XkbSelectEventDetails. XkbSelectEventDetails vous permet uniquement de modifier les conditions de sélection d'un seul événement à la fois, mais il offre un moyen d'affiner les conditions dans lesquelles l'événement est livré.

Pour sélectionner ou désélectionner un événement Xkb spécifique et placer éventuellement des conditions sur le moment où les événements de ce type sont signalés à votre client, utilisez XkbSelectEventDetails. Cela vous permet d'exercer une granularité de contrôle plus fine sur la livraison des événements Xkb avec XkbSelectEvents.

Alors que XkbSelectEvents permet de sélectionner plusieurs événements, XkbSelectEventDetails modifie les critères de sélection pour un seul type d'événement Xkb. L'interprétation des masques bits_to_change et values_for_bits dépend du type d'événement en question.

XkbSelectEventDetails modifie le masque de sélection d'événements Xkb pour le clavier spécifié par device_spec et l'événement Xkb spécifié par event_type. Pour activer la sélection d'événements pour un détail d'événement, définissez le bit correspondant au détail dans le paramètre bits_to_change et définissez le bit correspondant dans le paramètre values_for_bits. Pour désactiver la sélection de détails d'événement pour un détail, définissez le bit correspondant au détail dans le paramètre bits_to_change et ne définissez pas le bit correspondant dans le paramètre values_for_bits.

Si un type d'événement invalide est spécifié, une erreur de protocole BadValue en résulte. Si un bit n'est pas défini dans le paramètre bits_to_change, mais que le bit correspondant est défini dans le paramètre values_for_bits, une erreur de protocole BadMatch en résulte. Si un bit indéfini est défini dans l'un des paramètres bits_to_change ou values_for_bits, une erreur de protocole BadValue en résulte.

Pour chaque type d'événement Xkb, les détails d'événements légaux que vous pouvez spécifier dans la requête XkbSelectEventDetails sont listés dans les chapitres qui décrivent chaque événement en détail.

DIAGNOSTICS

BadMatch
Une version compatible de Xkb n'était pas disponible sur le serveur ou un argument a un type et une plage corrects, mais est autrement invalide.
BadValue
Un argument est hors de portée.
