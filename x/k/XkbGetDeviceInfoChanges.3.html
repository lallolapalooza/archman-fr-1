XkbGetDeviceInfoChanges(3) FONCTIONS XKB XkbGetDeviceInfoChanges(3)

NOM

XkbGetDeviceInfoChanges - interroger les modifications survenues dans les actions des boutons ou les noms d'indicateurs et les mappages d'indicateurs associés à un périphérique d'extension d'entrée

SYNTAXE

Status XkbGetDeviceInfoChanges (Display *dpy, XkbDeviceInfoPtr device_info, XkbDeviceChangesPtr changes);

ARGUMENTS

dpy
connexion au serveur X
device_info
structure à mettre à jour avec les résultats
changes
contient des notes sur les modifications survenues

DESCRIPTION

Le champ changes->changed indique quels attributs du périphérique spécifié dans changes->device ont changé. Les paramètres décrivant les modifications sont contenus dans les autres champs de changes. XkbGetDeviceInfoChanges utilise ces informations pour appeler XkbGetDeviceInfo afin d'obtenir le statut actuel des attributs qui ont changé. Il met ensuite à jour la description locale du périphérique dans device_info avec les nouvelles informations.
