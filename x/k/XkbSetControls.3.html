XkbSetControls(3)

Paquet: libx11

Licences: MIT AND X11

XkbSetControls(3) FONCTIONS XKB XkbSetControls(3)

NOM

XkbSetControls - Copie les modifications dans le serveur X en se basant sur une structure ctrls modifiée dans une copie locale de la description du clavier

SYNTAXE

Bool XkbSetControls (Display *display, unsigned long which, XkbDescPtr xkb);

ARGUMENTS

display
connexion au serveur X
which
masque des contrôles demandés
xkb
description du clavier pour les informations de contrôle

DESCRIPTION

Pour chaque bit défini dans le paramètre which, XkbSetControls envoie les valeurs correspondantes du champ xkb->ctrls au serveur. Les valeurs valides pour which sont toutes les combinaisons des masques listés dans le Tableau 1 qui ont "ok" dans la colonne which.

Le Tableau 1 montre les valeurs réelles pour les bits de masques individuels utilisés pour sélectionner les contrôles à modifier et pour activer et désactiver le contrôle. Notez que le même bit de masque est utilisé pour spécifier les modifications générales des paramètres utilisés pour configurer le contrôle (which), et pour activer et désactiver le contrôle (enabled_ctrls). Les anomalies dans le tableau (pas de "ok" dans la colonne) concernent les contrôles qui n'ont pas d'attributs configurables ; et les contrôles qui ne sont pas des contrôles booléens et ne peuvent donc pas être activés ou désactivés.

Tableau 1 Bits de masque des contrôles

changed_ctrls _ctrls
XkbRepeatKeysMask ok ok (1L<<0)
XkbSlowKeysMask ok ok (1L<<1)
XkbBounceKeysMask ok ok (1L<<2)
XkbStickyKeysMask ok ok (1L<<3)
XkbMouseKeysMask ok ok (1L<<4)
XkbMouseKeysAccelMask ok ok (1L<<5)
XkbAccessXKeysMask ok ok (1L<<6)
XkbAccessXTimeoutMask ok ok (1L<<7)
XkbAccessXFeedbackMask ok ok (1L<<8)
XkbAudibleBellMask ok (1L<<9)
XkbOverlay1Mask ok (1L<<10)
XkbOverlay2Mask ok (1L<<11)
XkbIgnoreGroupLockMask ok (1L<<12)
XkbGroupsWrapMask ok (1L<<27)
XkbInternalModsMask ok (1L<<28)
XkbIgnoreLockModsMask ok (1L<<29)
XkbPerKeyRepeatMask ok (1L<<30)
XkbControlsEnabledMask ok (1L<<31)

XkbAccessXFeedbackMask)
XkbAllBooleanCtrlsMask ok (0x00001FFF)
XkbAllControlsMask ok (0xF8001FFF)

Si xkb->ctrls est NULL, que le serveur ne supporte pas une version compatible de Xkb, ou que l'extension Xkb n'a pas été correctement initialisée, XkbSetControls renvoie False. Sinon, il envoie la requête au serveur X et renvoie True.

Notez que les modifications apportées aux attributs des contrôles dans la structure XkbControlsRec ne sont apparentes que lorsque le contrôle associé est activé, bien que les valeurs correspondantes soient toujours mises à jour dans le serveur X. Par exemple, les champs repeat_delay et repeat_interval sont ignorés à moins que le contrôle RepeatKeys ne soit activé (c'est-à-dire que l'équivalent dans le serveur X de xkb->ctrls ait XkbRepeatKeyMask défini dans enabled_ctrls). Il est permis de modifier les attributs d'un contrôle dans un appel à XkbSetControls et d'activer le contrôle dans un appel ultérieur. Voir XkbChangeEnabledControls pour plus d'informations sur l'activation et la désactivation des contrôles.

Notez que le champ enabled_ctrls est lui-même un contrôle - le contrôle EnabledControls. À ce titre, pour définir une configuration spécifique de contrôles activés et désactivés, vous devez définir enabled_ctrls aux bits appropriés pour activer uniquement les contrôles que vous souhaitez et désactiver tous les autres, puis spécifier le XkbControlsEnabledMask dans un appel à XkbSetControls.

Comme cela est quelque peu maladroit si tout ce que vous voulez faire est d'activer et de désactiver des contrôles, et de ne modifier aucun de leurs attributs, une fonction pratique est également fournie à cet effet, XkbChangeEnabledControls.

VALEURS DE RETOUR

True
La fonction XkbSetControls renvoie True lorsqu'elle envoie la requête au serveur X.
False
La fonction XkbSetControls renvoie False lorsque xkb->ctrls est NULL, que le serveur ne supporte pas une version compatible de Xkb, ou que l'extension Xkb n'a pas été correctement initialisée.

DIAGNOSTICS

BadAlloc
Impossible d'allouer du stockage
BadMatch
Une version compatible de Xkb n'était pas disponible dans le serveur ou un argument a un type et une plage corrects, mais est par ailleurs invalide

VOIR AUSSI

XkbChangeEnabledControls(3), XkbFreeControls(3)
