XkbGetIndicatorMap(3)

Paquet: libx11

XkbGetIndicatorMap(3) FONCTIONS XKB XkbGetIndicatorMap(3)

NOM

XkbGetIndicatorMap - Obtient la carte d'un ou plusieurs indicateurs, en utilisant un masque pour spécifier les indicateurs

SYNTAXE

Status XkbGetIndicatorMap (Display *dpy, unsigned int which, XkbDescPtr desc);

ARGUMENTS

dpy
connexion au serveur X
which
masque des indicateurs pour lesquels des cartes doivent être retournées
desc
description du clavier à mettre à jour

DESCRIPTION

Xkb permet aux applications d'obtenir des informations sur les indicateurs en utilisant deux méthodes différentes. La première méthode, qui est similaire à l'implémentation X de base, utilise un masque pour spécifier les indicateurs. La seconde méthode, plus adaptée aux applications soucieuses de l'interopérabilité, utilise des noms d'indicateurs. La correspondance entre le nom de l'indicateur et la position du bit dans les masques est la suivante : l'un des paramètres renvoyés par XkbGetNamedIndicators est un index qui est la position du bit à utiliser dans tout appel de fonction nécessitant un masque de bits d'indicateurs, ainsi que l'index de l'indicateur dans le tableau XkbIndicatorRec des cartes d'indicateurs.

XkbGetIndicatorMap obtient les cartes du serveur pour uniquement les indicateurs spécifiés par le masque which et copie les valeurs dans la description du clavier spécifiée par desc. Si le champ indicators du paramètre desc est NULL, XkbGetIndicatorMap l'alloue et l'initialise.

Pour libérer les cartes d'indicateurs, utilisez XkbFreeIndicatorMaps.

DIAGNOSTICS

BadAlloc
Impossible d'allouer du stockage
BadMatch
Une version compatible de Xkb n'était pas disponible sur le serveur ou un argument a un type et une plage corrects, mais est autrement invalide
BadImplementation
Réponse invalide du serveur

VOIR AUSSI

XkbFreeIndicatorMaps(3), XkbGetNamedIndicators(3)
