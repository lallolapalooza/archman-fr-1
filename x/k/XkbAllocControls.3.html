XkbAllocControls(3)

Paquet: libx11

Licences: MIT AND X11

XkbAllocControls(3) FONCTIONS XKB XkbAllocControls(3)

NOM

XkbAllocControls - Alloue une structure XkbControlsRec dans la XkbDescRec

SYNTAXE

Status XkbAllocControls (XkbDescPtr xkb, unsigned int which);

ARGUMENTS

xkb
Description Xkb dans laquelle allouer la rec de ctrls
which
masque des composants de ctrls à allouer

DESCRIPTION

Le besoin d'allouer une structure XkbControlsRec se présente rarement ; Xkb en crée une lorsqu'une application appelle XkbGetControls ou une fonction apparentée. Pour les situations où il n'y a pas de structure XkbControlsRec allouée dans la XkbDescRec, allouez-en une en appelant XkbAllocControls.

XkbAllocControls alloue le champ ctrls du paramètre xkb, initialise tous les champs à zéro, et retourne Success. Si le champ ctrls n'est pas NULL, XkbAllocControls retourne simplement Success. Si xkb est NULL, XkbAllocControls signale une erreur BadMatch. Si le champ ctrls n'a pas pu être alloué, il signale une erreur BadAlloc.

Le masque which spécifie les champs individuels de la structure ctrls à allouer et peut contenir n'importe lequel des masques valides définis dans le Tableau 1. (CE COMMENTAIRE DOIT-IL ÊTRE LAISSÉ????) Comme aucun des contrôles existants n'a de structures qui leur sont associées, which n'a actuellement que peu de valeur pratique dans cet appel.

Le Tableau 1 montre les valeurs réelles des bits de masque individuels utilisés pour sélectionner les contrôles à modifier et pour activer et désactiver le contrôle. Notez que le même bit de masque est utilisé pour spécifier les modifications générales apportées aux paramètres utilisés pour configurer le contrôle (which), et pour activer et désactiver le contrôle (enabled_ctrls). Les anomalies dans le tableau (pas de "ok" dans la colonne) concernent les contrôles qui n'ont pas d'attributs configurables ; et pour les contrôles qui ne sont pas des contrôles booléens et qui ne peuvent donc pas être activés ou désactivés.
