XkbSetDetectableAutoRepeat(3)

Paquet: libx11

Licences: MIT AND X11

XkbSetDetectableAutoRepeat(3) FONCTIONS XKB XkbSetDetectableAutoRepeat(3)

NOM

XkbSetDetectableAutoRepeat - Définit DetectableAutoRepeat

SYNTAXE

Bool XkbSetDetectableAutoRepeat (Display *display, Bool detectable, Bool *supported_rtrn);

ARGUMENTS

display
connexion au serveur X
detectable
True => définit DetectableAutoRepeat
supported_rtrn
rempli avec True si DetectableAutoRepeat est supporté

DESCRIPTION

La répétition automatique est la génération d'événements de touche multiples par un clavier lorsque l'utilisateur appuie sur une touche et la maintient enfoncée. Le matériel du clavier et le logiciel du serveur X dépendant du périphérique implémentent souvent la répétition automatique en générant plusieurs événements KeyPress sans événement KeyRelease intermédiaire. Le comportement standard du serveur X est de générer un événement KeyRelease pour chaque événement KeyPress. Si le matériel du clavier et le logiciel du serveur X dépendant du périphérique implémentent la répétition automatique en générant plusieurs événements KeyPress, la partie indépendante du serveur X génère par défaut synthétiquement un événement KeyRelease après chaque événement KeyPress. Cela offre un comportement prévisible pour les clients X, mais ne permet pas à ces clients de détecter le fait qu'une touche se répète.

Xkb permet aux clients de demander la répétition automatique détectable. Si un client la demande et que le serveur la prend en charge, Xkb génère des événements KeyRelease uniquement lorsque la touche est physiquement relâchée. Si la répétition automatique détectable n'est pas prise en charge ou n'a pas été demandée, le serveur synthétise un événement KeyRelease pour chaque événement KeyPress répété qu'il génère.

DétectableAutoRepeat, contrairement à d'autres contrôles, n'est pas contenu dans la structure XkbControlsRec, ni ne peut être activé ou désactivé via le contrôle EnabledControls. Au lieu de cela, interrogez et définissez DetectableAutoRepeat en utilisant XkbGetDetectableAutoRepeat et XkbSetDetectableAutoRepeat.

DetectableAutoRepeat est une condition qui s'applique à tous les périphériques clavier pour la connexion d'un client à un serveur X donné ; elle ne peut pas être définie sélectivement pour certains périphériques et pas pour d'autres. Pour cette raison, aucune des fonctions de la bibliothèque Xkb impliquant DetectableAutoRepeat n'implique un spécificateur de périphérique.

Cette requête affecte uniquement l'activité du clavier pour le client demandeur ; les autres clients voient toujours le comportement attendu de répétition automatique non détectable, sauf s'ils ont demandé autre chose.

XkbSetDetectableAutoRepeat envoie une requête au serveur pour définir DetectableAutoRepeat sur vrai pour le client actuel si detectable est True, et sur faux s'il est False ; il attend ensuite une réponse. Si supported_rtrn n'est pas NULL, XkbSetDetectableAutoRepeat remplit supported_rtrn avec True si le serveur prend en charge DetectableAutoRepeat, et False s'il ne le fait pas. XkbSetDetectableAutoRepeat renvoie l'état actuel de DetectableAutoRepeat pour le client demandeur : True si DetectableAutoRepeat est défini, et False sinon.

VALEURS DE RETOUR

True
La fonction XkbSetDetectableAutoRepeat renvoie True si DetectableAutoRepeat est défini.
False
La fonction XkbSetDetectableAutoRepeat renvoie False si DetectableAutoRepeat n'est pas défini.
