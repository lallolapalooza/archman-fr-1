NOM

XkbFreeGeomRows - Libérer les lignes d'une section

SYNOPSIS

void XkbFreeGeomRows (XkbSectionPtr section, int first, int count, Bool free_all);

ARGUMENTS

section
section dans laquelle les lignes doivent être libérées
first
première ligne à libérer
count
nombre de lignes à libérer
free_all
Vrai => toutes les lignes sont libérées

DESCRIPTION

Xkb fournit un certain nombre de fonctions pour allouer et libérer des sous-composants d'une géométrie de clavier. Utilisez ces fonctions pour créer ou modifier des géométries de clavier. Notez que ces fonctions allouent simplement de l'espace pour le(s) nouvel(nouveau) élément(s), et il vous appartient de remplir explicitement les valeurs dans votre code. Ces fonctions d'allocation augmentent sz_* mais ne touchent jamais num_* (sauf en cas d'échec d'allocation, auquel cas elles remettent à la fois sz_* et num_* à zéro). Ces fonctions renvoient Success si elles réussissent, BadAlloc si elles ne parviennent pas à allouer l'espace, ou BadValue si un paramètre n'est pas conforme aux attentes.

Si free_all est Vrai, toutes les lignes sont libérées indépendamment de la valeur de first et count. Sinon, le nombre de lignes spécifié par count est libéré, en commençant par la ligne spécifiée par first dans la section spécifiée.

VALEURS DE RETOUR

Success
La fonction XkbFreeGeomRows retourne Success lorsqu'il n'y a pas d'erreurs d'allocation ou d'arguments.

DIAGNOSTICS

BadAlloc
Impossible d'allouer de l'espace
BadValue
Un argument est hors de portée
