XQUERYDEVICESTATE(3)   XQUERYDEVICESTATE(3)

NOM

XQueryDeviceState - interroger l'état d'un périphérique d'entrée d'extension.

SYNOPIS

#include <X11/extensions/XInput.h>
XDeviceState* XQueryDeviceState( Display *display,
                                 XDevice *device);
display
       Spécifie la connexion au serveur X.
device
       Spécifie le périphérique dont l'état doit être interrogé.

DESCRIPTION

La requête XQueryDeviceState interroge l'état d'un périphérique d'entrée.
L'état actuel des touches et des boutons (enfoncés ou relâchés), et des
valuateurs (valeur actuelle) du périphérique est rapporté par cette
requête. Chaque touche ou bouton est représenté par un bit dans la
structure XDeviceState qui est retournée. Lesvaluateurs du
périphérique rapportent 0 s'ils rapportent des informations relatives, et
la valeur actuelle s'ils rapportent des informations absolues.
XQueryDeviceState peut générer une erreur BadDevice.
Structures :
La structure XDeviceState contient :
typedef struct {
    XID device_id;
    int num_classes;
    XInputClass *data;
} XDeviceState;
La structure XValuatorState contient :
typedef struct {
    unsigned char class;
    unsigned char length;
    unsigned char num_valuators;
    unsigned char mode;
    int *valuators;
} XValuatorState;
La structure XKeyState contient :
typedef struct {
    unsigned char class;
    unsigned char length;
    short     num_keys;
    char keys[32];
} XKeyState;
La structure XButtonState contient :
typedef struct {
    unsigned char class;
    unsigned char length;
    short     num_buttons;
    char buttons[32];
} XButtonState;

DIAGNOSTICS

BadDevice
       Un périphérique invalide a été spécifié. Le périphérique spécifié
       n'existe pas ou n'a pas été ouvert par ce client via
       XOpenInputDevice. Cette erreur peut également survenir si un autre
       client a fait du périphérique spécifié le périphérique clavier X ou
       le périphérique pointeur X via les requêtes
       XChangeKeyboardDevice ou XChangePointerDevice.
