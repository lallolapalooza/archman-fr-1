XQueryBestSize(3) FONCTIONS XLIB XQueryBestSize(3)

NOM

XQueryBestSize, XQueryBestTile, XQueryBestStipple - déterminer des tailles efficaces

SYNTAXE

Status XQueryBestSize(Display *display, int class, Drawable which_screen, unsigned int width, unsigned int height, unsigned int *width_return, unsigned int *height_return);

Status XQueryBestTile(Display *display, Drawable which_screen, unsigned int width, unsigned int height, unsigned int *width_return, unsigned int *height_return);

Status XQueryBestStipple(Display *display, Drawable which_screen, unsigned int width, unsigned int height, unsigned int *width_return, unsigned int *height_return);

ARGUMENTS

class
Spécifie la classe qui vous intéresse. Vous pouvez passer TileShape, CursorShape, ou StippleShape.
display
Spécifie la connexion au serveur X.
width

height
Spécifiez la largeur et la hauteur.
which_screen
Spécifie un objet dessinable sur l'écran.
width_return

height_return
Retourne la largeur et la hauteur de l'objet le mieux supporté par le matériel d'affichage.

DESCRIPTION

La fonction XQueryBestSize renvoie la taille la meilleure ou la plus proche de la taille spécifiée. Pour CursorShape, c'est la plus grande taille qui peut être entièrement affichée sur l'écran spécifié par which_screen. Pour TileShape, c'est la taille qui peut être carrelée le plus rapidement. Pour StippleShape, c'est la taille qui peut être hachurée le plus rapidement. Pour CursorShape, l'objet dessinable indique l'écran désiré. Pour TileShape et StippleShape, l'objet dessinable indique l'écran et éventuellement la classe et la profondeur de la fenêtre. Une fenêtre InputOnly ne peut pas être utilisée comme objet dessinable pour TileShape ou StippleShape, sinon une erreur BadMatch est générée.

XQueryBestSize peut générer des erreurs BadDrawable, BadMatch et BadValue.

La fonction XQueryBestTile renvoie la taille la meilleure ou la plus proche, c'est-à-dire la taille qui peut être carrelée le plus rapidement sur l'écran spécifié par which_screen. L'objet dessinable indique l'écran et éventuellement la classe et la profondeur de la fenêtre. Si une fenêtre InputOnly est utilisée comme objet dessinable, une erreur BadMatch est générée.

XQueryBestTile peut générer des erreurs BadDrawable et BadMatch.

La fonction XQueryBestStipple renvoie la taille la meilleure ou la plus proche, c'est-à-dire la taille qui peut être hachurée le plus rapidement sur l'écran spécifié par which_screen. L'objet dessinable indique l'écran et éventuellement la classe et la profondeur de la fenêtre. Si une fenêtre InputOnly est utilisée comme objet dessinable, une erreur BadMatch est générée.

XQueryBestStipple peut générer des erreurs BadDrawable et BadMatch.

DIAGNOSTICS

BadMatch
Une fenêtre InputOnly est utilisée comme objet dessinable.
BadDrawable
Une valeur pour un argument Drawable ne nomme pas une Fenêtre ou un Pixmap défini.
BadMatch
Les valeurs n'existent pas pour une fenêtre InputOnly.
BadValue
Une valeur numérique sort de la plage acceptée par la requête. Sauf si une plage spécifique est spécifiée pour un argument, la plage complète définie par le type de l'argument est acceptée. Tout argument défini comme un ensemble d'alternatives peut générer cette erreur.
