XQueryTree(3)

Paquet: libx11

Licences: MIT AND X11

XQueryTree(3) FONCTIONS XLIB XQueryTree(3)

NOM

XQueryTree - interroger les informations de l'arbre des fenêtres

SYNTAXE

Status XQueryTree(Display *display, Window w, Window *root_return, Window *parent_return, Window **children_return, unsigned int *nchildren_return);

ARGUMENTS

children_return
Retourne la liste des enfants.
display
Spécifie la connexion au serveur X.
nchildren_return
Retourne le nombre d'enfants.
parent_return
Retourne la fenêtre parente.
root_return
Retourne la fenêtre racine.
w
Spécifie la fenêtre dont vous souhaitez obtenir la liste des enfants, la racine, le parent et le nombre d'enfants.

DESCRIPTION

La fonction XQueryTree renvoie l'ID racine, l'ID de la fenêtre parente, un pointeur vers la liste des fenêtres enfants (NULL s'il n'y a pas d'enfants), et le nombre d'enfants dans la liste pour la fenêtre spécifiée. Les enfants sont listés dans l'ordre d'empilement actuel, du plus bas (premier) au plus haut (dernier). XQueryTree renvoie zéro en cas d'échec et une valeur non nulle en cas de succès. Pour libérer une liste d'enfants non nulle lorsqu'elle n'est plus nécessaire, utilisez XFree.

XQueryTree peut générer une erreur BadWindow.

BOGUES

Cela devrait réellement retourner un écran *, pas un ID de fenêtre racine.

DIAGNOSTICS

BadWindow
Une valeur pour un argument Window ne nomme pas une Window définie.

VOIR AUSSI

XFree(3), XGetWindowAttributes(3), XQueryPointer(3)
