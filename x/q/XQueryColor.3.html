NOM

XQueryColor, XQueryColors, XLookupColor, XParseColor - obtenir des valeurs de couleur

SYNTAXE

int XQueryColor(Display *display, Colormap colormap, XColor *def_in_out);

int XQueryColors(Display *display, Colormap colormap, XColor defs_in_out[], int ncolors);

Status XLookupColor(Display *display, Colormap colormap, _Xconst char *color_name, XColor *exact_def_return, XColor *screen_def_return);

Status XParseColor(Display *display, Colormap colormap, _Xconst char *spec, XColor *exact_def_return);

ARGUMENTS

colormap
Spécifie la table de couleurs.
color_name
Spécifie la chaîne de nom de couleur (par exemple, red) dont vous souhaitez obtenir la structure de définition de couleur.
def_in_out
Spécifie et retourne les valeurs RVB pour le pixel spécifié dans la structure.
defs_in_out
Spécifie et retourne un tableau de structures de définition de couleur pour le pixel spécifié dans la structure.
display
Spécifie la connexion au serveur X.
exact_def_return
Retourne les valeurs RVB exactes.
ncolors
Spécifie le nombre de structures XColor dans le tableau de définition de couleur.
screen_def_return
Retourne les valeurs RVB les plus proches fournies par le matériel.
spec
Spécifie la chaîne de nom de couleur ; la casse est ignorée.
exact_def_return
Retourne la valeur de couleur exacte pour une utilisation ultérieure et définit les indicateurs DoRed, DoGreen et DoBlue.

DESCRIPTION

La fonction XQueryColor retourne la valeur RVB actuelle pour le pixel dans la structure XColor et définit les indicateurs DoRed, DoGreen et DoBlue. La fonction XQueryColors retourne la valeur RVB pour chaque pixel dans chaque structure XColor et définit les indicateurs DoRed, DoGreen et DoBlue dans chaque structure.

XQueryColor et XQueryColors peuvent générer des erreurs BadColor et BadValue.

La fonction XLookupColor recherche le nom chaîne d'une couleur par rapport à l'écran associé à la table de couleurs spécifiée. Elle retourne à la fois les valeurs de couleur exactes et les valeurs les plus proches fournies par l'écran par rapport au type visuel de la table de couleurs spécifiée. Si le nom de couleur n'est pas dans le jeu de caractères portable de l'hôte, le résultat est dépendant de l'implémentation. L'utilisation de majuscules ou de minuscules n'a pas d'importance. XLookupColor retourne une valeur non nulle si le nom est résolu ; sinon, elle retourne zéro.

La fonction XParseColor recherche le nom chaîne d'une couleur par rapport à l'écran associé à la table de couleurs spécifiée. Elle retourne la valeur de couleur exacte. Si le nom de couleur n'est pas dans le jeu de caractères portable de l'hôte, le résultat est dépendant de l'implémentation. L'utilisation de majuscules ou de minuscules n'a pas d'importance. XParseColor retourne une valeur non nulle si le nom est résolu ; sinon, elle retourne zéro.

XLookupColor et XParseColor peuvent générer une erreur BadColor.

NOMS DE COULEUR

Une spécification de périphérique RVB est identifiée par le préfixe “rgb:” et est conforme à la syntaxe suivante :

rgb:<rouge>/<vert>/<bleu>
    <rouge>, <vert>, <bleu> := h | hh | hhh | hhhh
    h := chiffre hexadécimal unique (insensible à la casse)

Notez que h indique la valeur mise à l'échelle sur 4 bits, hh la valeur mise à l'échelle sur 8 bits, hhh la valeur mise à l'échelle sur 12 bits et hhhh la valeur mise à l'échelle sur 16 bits, respectivement.

Pour des raisons de compatibilité ascendante, une ancienne syntaxe pour les périphériques RVB est prise en charge, mais son utilisation continue n'est pas encouragée. La syntaxe est un caractère dièse (#) suivi d'une spécification numérique, dans l'un des formats suivants :

#RVB (4 bits chacun)
#RRGGBB (8 bits chacun)
#RRRGGGBBB (12 bits chacun)
#RRRRGGGGBBBB (16 bits chacun)

Les R, G et B représentent des chiffres hexadécimaux uniques. Lorsqu'ils sont spécifiés sur moins de 16 bits chacun, ils représentent les bits de poids fort de la valeur (contrairement à la syntaxe “rgb:”, dans laquelle les valeurs sont mises à l'échelle). Par exemple, la chaîne “#3a7” est équivalente à “#3000a0007000”.

Une spécification d'intensité RVB est identifiée par le préfixe “rgbi:” et est conforme à la syntaxe suivante :

rgbi:<rouge>/<vert>/<bleu>

Notez que rouge, vert et bleu sont des valeurs flottantes comprises entre 0.0 et 1.0, inclus. Le format d'entrée pour ces valeurs est un signe optionnel, une chaîne de chiffres pouvant contenir un point décimal et un champ exponentiel optionnel contenant un E ou un e suivi d'une chaîne entière éventuellement signée.

Les spécifications de chaîne standard indépendantes du périphérique ont la syntaxe suivante :

CIEXYZ:<X>/<Y>/<Z>
CIEuvY:<u>/<v>/<Y>
CIExyY:<x>/<y>/<Y>
CIELab:<L>/<a>/<b>
CIELuv:<L>/<u>/<v>
TekHVC:<H>/<V>/<C>

Toutes les valeurs (C, H, V, X, Y, Z, a, b, u, v, y, x) sont des valeurs flottantes. La syntaxe de ces valeurs est un signe plus ou moins optionnel, une chaîne de chiffres pouvant contenir un point décimal, et un champ exponentiel optionnel composé d'un “E” ou “e” suivi d'un signe optionnel plus ou moins suivi d'une chaîne de chiffres.

DIAGNOSTICS

BadColor
Une valeur pour un argument Colormap ne nomme pas une table de couleurs définie.
BadValue
Une valeur numérique tombe en dehors de la plage de valeurs acceptées par la requête. Sauf si une plage spécifique est spécifiée pour un argument, toute la plage définie par le type de l'argument est acceptée. Tout argument défini comme un ensemble d'alternatives peut générer cette erreur.

NAME

XQueryColor - query color information

SYNOPSIS

XQueryColor [-display display] [-window window] [colorname ...]

DESCRIPTION

XQueryColor queries the X server for the RGB value of a specified color name. If no color names are specified on the command line, XQueryColor reads them from standard input.

The output consists of the color name and its corresponding RGB value, in the format:

colorname red: rrrr green: gggg blue: bbbb

where rrrr, gggg, and bbbb are hexadecimal values representing the red, green, and blue components of the color, respectively. These values range from 0 to 65535.

If a -window option is specified, the color information is queried for the specified window. Otherwise, the root window of the specified display is used.

OPTIONS

-display display
Specifies the X server to connect to. The default is the value of the DISPLAY environment variable.
-window window
Specifies the window for which to query color information. window can be a window ID or a name that can be resolved to a window ID.

COLOR NAMES

Color names are typically defined in the rgb.txt file, which is usually located in /usr/share/X11/rgb.txt. The format of this file is:

rrr ggg bbb colorname

where rrr, ggg, and bbb are decimal values ranging from 0 to 255. Color names can contain spaces and other special characters.

Examples of color names include:

  • red
  • blue
  • DarkGreen
  • LightSkyBlue

You can also specify colors using the rgb: syntax, e.g., rgb:ff/00/00 for red.

DIAGNOSTICS

If XQueryColor cannot connect to the X server or cannot resolve a color name, it will print an error message to standard error.

SEE ALSO

xcolors(1), xrdb(1)

NOM

XQueryColor - interroger les informations de couleur

SYNTAXE

XQueryColor [-display affichage] [-window fenêtre] [nomcouleur ...]

DESCRIPTION

XQueryColor interroge le serveur X pour obtenir la valeur RVB d'un nom de couleur spécifié. Si aucun nom de couleur n'est spécifié sur la ligne de commande, XQueryColor les lit depuis l'entrée standard.

La sortie se compose du nom de la couleur et de sa valeur RVB correspondante, au format :

nomcouleur rouge : rrrr vert : gggg bleu : bbbb

où rrrr, gggg et bbbb sont des valeurs hexadécimales représentant respectivement les composantes rouge, verte et bleue de la couleur. Ces valeurs vont de 0 à 65535.

Si une option -window est spécifiée, les informations de couleur sont interrogées pour la fenêtre spécifiée. Sinon, la fenêtre racine de l'affichage spécifié est utilisée.

OPTIONS

-display affichage
Spécifie le serveur X auquel se connecter. La valeur par défaut est celle de la variable d'environnement DISPLAY.
-window fenêtre
Spécifie la fenêtre pour laquelle interroger les informations de couleur. fenêtre peut être un identifiant de fenêtre ou un nom qui peut être résolu en identifiant de fenêtre.

NOMS DE COULEURS

Les noms de couleurs sont généralement définis dans le fichier rgb.txt, qui se trouve habituellement dans /usr/share/X11/rgb.txt. Le format de ce fichier est :

rrr ggg bbb nomcouleur

où rrr, ggg et bbb sont des valeurs décimales allant de 0 à 255. Les noms de couleurs peuvent contenir des espaces et d'autres caractères spéciaux.

Exemples de noms de couleurs :

  • red
  • blue
  • DarkGreen
  • LightSkyBlue

Vous pouvez également spécifier des couleurs en utilisant la syntaxe rgb:, par exemple, rgb:ff/00/00 pour le rouge.

DIAGNOSTICS

Si XQueryColor ne parvient pas à se connecter au serveur X ou à résoudre un nom de couleur, il affichera un message d'erreur sur la sortie d'erreur standard.
