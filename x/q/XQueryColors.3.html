XQueryColors(3)

Paquet: libx11

Licences: MIT AND X11

XQueryColor(3) FONCTIONS XLIB XQueryColor(3)

NOM

XQueryColor, XQueryColors, XLookupColor, XParseColor - obtenir les valeurs de couleur

SYNTAXE

int XQueryColor(Display *display, Colormap colormap, XColor *def_in_out);

int XQueryColors(Display *display, Colormap colormap, XColor defs_in_out[], int ncolors);

Status XLookupColor(Display *display, Colormap colormap, _Xconst char *color_name, XColor *exact_def_return, XColor *screen_def_return);

Status XParseColor(Display *display, Colormap colormap, _Xconst char *spec, XColor *exact_def_return);

ARGUMENTS

colormap
Spécifie la table de correspondance des couleurs.
color_name
Spécifie la chaîne de nom de couleur (par exemple, red) dont vous voulez obtenir la structure de définition de couleur.
def_in_out
Spécifie et renvoie les valeurs RVB pour le pixel spécifié dans la structure.
defs_in_out
Spécifie et renvoie un tableau de structures de définition de couleur pour le pixel spécifié dans la structure.
display
Spécifie la connexion au serveur X.
exact_def_return
Renvoie les valeurs RVB exactes.
ncolors
Spécifie le nombre de structures XColor dans le tableau de définition de couleurs.
screen_def_return
Renvoie les valeurs RVB les plus proches fournies par le matériel.
spec
Spécifie la chaîne de nom de couleur ; la casse est ignorée.
exact_def_return
Renvoie la valeur de couleur exacte pour une utilisation ultérieure et définit les indicateurs DoRed, DoGreen et DoBlue.

DESCRIPTION

La fonction XQueryColor renvoie la valeur RVB actuelle pour le pixel dans la structure XColor et définit les indicateurs DoRed, DoGreen et DoBlue. La fonction XQueryColors renvoie la valeur RVB pour chaque pixel dans chaque structure XColor et définit les indicateurs DoRed, DoGreen et DoBlue dans chaque structure.

XQueryColor et XQueryColors peuvent générer des erreurs BadColor et BadValue.

La fonction XLookupColor recherche le nom de chaîne d'une couleur par rapport à l'écran associé à la table de correspondance des couleurs spécifiée. Elle renvoie à la fois les valeurs de couleur exactes et les valeurs les plus proches fournies par l'écran par rapport au type visuel de la table de correspondance des couleurs spécifiée. Si le nom de couleur n'est pas dans l'encodage de caractères portable hôte, le résultat est dépendant de l'implémentation. L'utilisation des majuscules ou des minuscules n'a pas d'importance. XLookupColor renvoie une valeur non nulle si le nom est résolu ; sinon, elle renvoie zéro.

La fonction XParseColor recherche le nom de chaîne d'une couleur par rapport à l'écran associé à la table de correspondance des couleurs spécifiée. Elle renvoie la valeur de couleur exacte. Si le nom de couleur n'est pas dans l'encodage de caractères portable hôte, le résultat est dépendant de l'implémentation. L'utilisation des majuscules ou des minuscules n'a pas d'importance. XParseColor renvoie une valeur non nulle si le nom est résolu ; sinon, elle renvoie zéro.

XLookupColor et XParseColor peuvent générer une erreur BadColor.

NOMS DE COULEUR

Une spécification de périphérique RVB est identifiée par le préfixe “rgb:” et est conforme à la syntaxe suivante :

rgb:<rouge>/<vert>/<bleu>
    <rouge>, <vert>, <bleu> := h | hh | hhh | hhhh
    h := chiffres hexadécimaux uniques (insensible à la casse)

Notez que h indique la valeur mise à l'échelle en 4 bits, hh la valeur mise à l'échelle en 8 bits, hhh la valeur mise à l'échelle en 12 bits et hhhh la valeur mise à l'échelle en 16 bits, respectivement.

Pour des raisons de compatibilité ascendante, une ancienne syntaxe pour RVB Appareil est prise en charge, mais son utilisation continue n'est pas recommandée. La syntaxe est un caractère dièse initial suivi d'une spécification numérique, dans l'un des formats suivants :

#RGB (4 bits chacun)
#RRGGBB (8 bits chacun)
#RRRGGGBBB (12 bits chacun)
#RRRRGGGGBBBB (16 bits chacun)

Les R, G et B représentent des chiffres hexadécimaux uniques. Lorsque moins de 16 bits chacun sont spécifiés, ils représentent les bits les plus significatifs de la valeur (contrairement à la syntaxe “rgb:”, dans laquelle les valeurs sont mises à l'échelle). Par exemple, la chaîne “#3a7” est identique à “#3000a0007000”.

Une spécification d'intensité RVB est identifiée par le préfixe “rgbi:” et est conforme à la syntaxe suivante :

rgbi:<rouge>/<vert>/<bleu>

Notez que rouge, vert et bleu sont des valeurs flottantes comprises entre 0.0 et 1.0, inclus. Le format d'entrée pour ces valeurs est un signe optionnel, une chaîne de nombres contenant éventuellement un point décimal et un champ d'exposant optionnel contenant un E ou un e suivi d'une chaîne entière éventuellement signée.

Les spécifications de chaîne standard indépendantes de l'appareil ont la syntaxe suivante :

CIEXYZ:<X>/<Y>/<Z>
CIEuvY:<u>/<v>/<Y>
CIExyY:<x>/<y>/<Y>
CIELab:<L>/<a>/<b>
CIELuv:<L>/<u>/<v>
TekHVC:<H>/<V>/<C>

Toutes les valeurs (C, H, V, X, Y, Z, a, b, u, v, y, x) sont des valeurs flottantes. La syntaxe de ces valeurs est un signe plus ou moins optionnel, une chaîne de chiffres contenant éventuellement un point décimal et un champ d'exposant facultatif composé d'un “E” ou d'un “e” suivi d'un plus ou moins optionnel suivi d'une chaîne de chiffres.

DIAGNOSTICS

BadColor
Une valeur pour un argument Colormap ne nomme pas une Colormap définie.
BadValue
Une valeur numérique tombe en dehors de la plage des valeurs acceptées par la requête. Sauf si une plage spécifique est spécifiée pour un argument, la plage complète définie par le type de l'argument est acceptée. Tout argument défini comme un ensemble d'alternatives peut générer cette erreur.

NOM

XQueryColors — Couleurs pour le langage XQuery.

DESCRIPTION

Ce document décrit les couleurs utilisées pour la coloration syntaxique du langage XQuery dans divers outils et éditeurs. Il sert de référence pour assurer la cohérence de la présentation du code XQuery.

LISTE DES COULEURS

Les couleurs suivantes sont utilisées pour mettre en évidence les différents éléments du langage XQuery :

Mot-clé
Met en évidence les mots-clés réservés du langage XQuery (par exemple, for, let, where, return).
Chaîne de caractères
Met en évidence les chaînes de caractères littérales (par exemple, "hello", 'world').
Commentaire
Met en évidence les commentaires (par exemple, (: ceci est un commentaire :)).
Fonction
Met en évidence les noms des fonctions prédéfinies et définies par l'utilisateur.
Variable
Met en évidence les variables (par exemple, $variable).
Type
Met en évidence les types de données prédéfinis (par exemple, xs:string, xs:integer).
Opérateur
Met en évidence les opérateurs (par exemple, +, -, =, <).
Numérique
Met en évidence les nombres littéraux.
Booléen
Met en évidence les valeurs booléennes littérales (true(), false()).
Expression
Met en évidence les expressions générales ou les fragments de code non spécifiés autrement.
