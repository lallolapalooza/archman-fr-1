XtAppAddBlockHook(3) FONCTIONS XT XtAppAddBlockHook(3)

NOM

XtAppAddBlockHook, XtRemoveBlockHook - enregistrer une procédure de point d'interruption (block hook)

SYNTAXE

#include <X11/Intrinsic.h>

XtBlockHookId XtAppAddBlockHook(XtAppContext app_context, XtBlockHookProc proc, XtPointer client_data);

void XtRemoveBlockHook(XtBlockHookId id);

ARGUMENTS

app_context
Spécifie le contexte de l'application.
proc
Spécifie la procédure de point d'interruption.
num_args
Spécifie les données spécifiques à l'application à passer à la procédure de point d'interruption.

DESCRIPTION

XtAppAddBlockHook enregistre la procédure spécifiée et renvoie un identifiant pour celle-ci. Le point d'interruption est appelé à tout moment dans le futur lorsque les Intrinsèques sont sur le point de bloquer en attendant une entrée.

Les procédures de point d'interruption sont supprimées automatiquement et l'XtBlockHookId est détruit lorsque le contexte de l'application dans lequel elles ont été ajoutées est détruit.

XtRemoveBlockHook supprime la procédure de point d'interruption spécifiée de la liste dans laquelle elle a été enregistrée.
