XtSetKeyboardFocus(3) FONCTIONS XT XtSetKeyboardFocus(3)

NOM

XtSetKeyboardFocus - focalise les événements sur un widget enfant

SYNTAXE

#include <X11/Intrinsic.h>

void XtSetKeyboardFocus(Widget subtree, Widget descendant);

ARGUMENTS

subtree
Spécifie soit le widget de la structure de sous-arbre qui doit recevoir l'événement clavier, soit None. Notez qu'il n'est pas une erreur de spécifier None lorsqu'aucun focus d'entrée n'a été précédemment défini.
descendant
Spécifie le widget pour lequel le focus clavier doit être défini.

DESCRIPTION

Si un événement KeyPress ou KeyRelease futur se produit dans le sous-arbre spécifié, XtSetKeyboardFocus fait en sorte que XtDispatchEvent remappe et envoie l'événement au widget descendant spécifié.

Lorsqu'il n'y a pas de cascade modale, les événements clavier peuvent se produire dans un widget W de trois manières :

  • W a le focus d'entrée X.
  • W a le focus clavier de l'un de ses ancêtres, et l'événement se produit dans l'ancêtre ou dans l'un de ses descendants.
  • Aucun ancêtre de W n'a de descendant dans le focus clavier, et le pointeur se trouve dans W.

Lorsqu'il y a une cascade modale, un widget W reçoit des événements clavier si un ancêtre de W se trouve dans le sous-ensemble actif de la cascade modale et que l'une ou plusieurs des conditions précédentes sont Vraies.

Lorsque le sous-arbre ou l'un de ses descendants acquiert le focus d'entrée X ou que le pointeur entre dans le sous-arbre de telle sorte que les événements clavier soient désormais livrés au sous-arbre, un événement FocusIn est généré pour le descendant si des événements FocusNotify ont été sélectionnés par le descendant. De même, lorsque W perd le focus d'entrée X ou le focus clavier pour l'un de ses ancêtres, un événement FocusOut est généré pour le descendant si des événements FocusNotify ont été sélectionnés par le descendant.
