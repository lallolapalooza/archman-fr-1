XTranslateCoordinates(3) FONCTIONS XLIB XTranslateCoordinates(3)

NOM

XTranslateCoordinates - traduire les coordonnées de fenêtre

SYNTAXE

Bool XTranslateCoordinates(Display *display, Window src_w, dest_w, int src_x, int src_y, int *dest_x_return, int *dest_y_return, Window *child_return);

ARGUMENTS

child_return
Retourne l'enfant si les coordonnées sont contenues dans un enfant mappé de la fenêtre de destination.
dest_w
Spécifie la fenêtre de destination.
dest_x_return

dest_y_return
Retourne les coordonnées x et y dans la fenêtre de destination.
display
Spécifie la connexion au serveur X.
src_w
Spécifie la fenêtre source.
src_x

src_y
Spécifient les coordonnées x et y dans la fenêtre source.

DESCRIPTION

Si XTranslateCoordinates retourne True, elle prend les coordonnées src_x et src_y relatives à l'origine de la fenêtre source et retourne ces coordonnées à dest_x_return et dest_y_return relatives à l'origine de la fenêtre de destination. Si XTranslateCoordinates retourne False, src_w et dest_w sont sur des écrans différents, et dest_x_return et dest_y_return sont zéro. Si les coordonnées sont contenues dans un enfant mappé de dest_w, cet enfant est retourné à child_return. Sinon, child_return est mis à None.

XTranslateCoordinates peut générer une erreur BadWindow.

DIAGNOSTICS

BadWindow
Une valeur pour un argument Window ne nomme pas une Window définie.
