XtGetSelectionParameters(3)

XtGetSelectionParameters(3) FONCTIONS XT XtGetSelectionParameters(3)

NOM

XtGetSelectionParameters - récupère les paramètres de sélection pour une requête de sélection avec une cible unique

SYNTAXE

#include <X11/Intrinsic.h>

void XtGetSelectionParameters(Widget owner, Atom selection, XtRequestId request_id, Atom *type_return, XtPointer *value_return, unsigned long *length_return, int *format_return);

ARGUMENTS

owner
Spécifie le widget qui possède la sélection spécifiée.
selection
Spécifie la sélection en cours de traitement.
request_id
Spécifie l'identifiant du demandeur en cas de sélections incrémentales, ou NULL en cas de transferts atomiques.
type_return
Spécifie un pointeur vers un atome dans lequel le type de propriété des paramètres sera stocké.
value_return
Spécifie un pointeur dans lequel un pointeur vers les paramètres doit être stocké. NULL sera stocké si aucun paramètre n'accompagne la requête.
length_return
Spécifie un pointeur dans lequel le nombre d'éléments de données dans value_return de la taille indiquée par format_return sera stocké.
format_return
Spécifie un pointeur dans lequel la taille en bits des données de paramètre dans les éléments de value_return sera stockée.

DESCRIPTION

XtGetSelectionParameters ne peut être appelée que depuis un XtConvertSelectionProc ou depuis le dernier appel à un XtConvertSelectionIncrProc avec un nouvel request_id.

VOIR AUSSI
