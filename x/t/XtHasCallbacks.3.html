XtCallCallbacks(3) FONCTIONS XT XtCallCallbacks(3)

NOM

XtCallCallbacks, XtCallCallbackList, XtHasCallbacks - traiter les rappels

SYNTAXE

#include <X11/Intrinsic.h>

void XtCallCallbacks(Widget w, const char *callback_name, XtPointer call_data);

void XtCallCallbackList(Widget w, XtCallbackList callbacks, XtPointer call_data);

typedef enum {XtCallbackNoList, XtCallbackHasNone, XtCallbackHasSome} XtCallbackStatus;

XtCallbackStatus XtHasCallbacks(Widget w, const char *callback_name);

ARGUMENTS

callback_name
Spécifie la liste de rappels à exécuter ou à vérifier.
call_data
Spécifie une valeur de données spécifique à la liste de rappels à passer à chaque procédure de rappel de la liste.
callbacks
Spécifie la liste de rappels à exécuter.
w
Spécifie le widget.

DESCRIPTION

La fonction XtCallCallbacks appelle chaque procédure qui est enregistrée dans la liste de rappels du widget spécifié.

Si callbacks n'est pas NULL, XtCallCallbackList appelle chaque procédure de rappel de la liste, en passant les données client et call_data. Le paramètre callbacks doit spécifier le contenu d'une ressource de widget ou d'objet déclarée avec le type de représentation XtRCallback.

La fonction XtHasCallbacks vérifie d'abord si le widget a une liste de rappels identifiée par callback_name. Si la liste de rappels n'existe pas, XtHasCallbacks retourne XtCallbackNoList. Si la liste de rappels existe mais est vide, elle retourne XtCallbackHasNone. Si la liste de rappels existe et a au moins un rappel enregistré, elle retourne XtCallbackHasSome.
