XtMalloc(3) FONCTIONS XT XtMalloc(3)

NOM

XtMalloc, XtCalloc, XtRealloc, XtReallocArray, XtFree, XtNew, XtNewString - fonctions de gestion de la mémoire

SYNTAXE

#include <X11/Intrinsic.h>

char *XtMalloc(Cardinal size);

char *XtCalloc(Cardinal num, Cardinal size);

char *XtRealloc(char *ptr, Cardinal size);

void *XtReallocArray(void *ptr, Cardinal num, Cardinal size);

void XtFree(char *ptr);

type *XtNew(type);

String XtNewString(String string);

Cardinal XtAsprintf(char **new_string, const char *format, ...);

ARGUMENTS

num
Spécifie le nombre d'éléments du tableau.
ptr
Spécifie un pointeur vers l'ancien stockage ou vers le bloc de stockage à libérer.
size
Spécifie la taille d'un élément de tableau (en octets) ou le nombre d'octets désiré.
string
Spécifie une chaîne de caractères précédemment déclarée.
type
Spécifie un type de données précédemment déclaré.
new_string
Spécifie un pointeur vers lequel écrire une nouvelle chaîne allouée.
format
Spécifie une chaîne de formatage telle que définie par sprintf(3c)

DESCRIPTION

XtMalloc renvoie un pointeur vers un bloc de stockage d'au moins la taille spécifiée en octets. S'il n'y a pas suffisamment de mémoire pour allouer le nouveau bloc, XtMalloc appelle XtErrorMsg.

La fonction XtCalloc alloue de l'espace pour le nombre spécifié d'éléments de tableau de la taille spécifiée et initialise l'espace à zéro. S'il n'y a pas suffisamment de mémoire pour allouer le nouveau bloc, XtCalloc appelle XtErrorMsg.

Les fonctions XtRealloc et XtReallocArray modifient la taille d'un bloc de stockage (le déplaçant éventuellement). Ensuite, elles copient le contenu ancien (ou autant qu'il rentre) dans le nouveau bloc et libèrent l'ancien bloc. S'il n'y a pas suffisamment de mémoire pour allouer le nouveau bloc, ou si les calculs pour la taille du nouveau bloc provoquent un débordement d'entier, ces fonctions appellent XtErrorMsg. Si ptr est NULL, ces fonctions allouent le nouveau stockage sans copier le contenu ancien ; elles appellent simplement XtMalloc.

La fonction XtFree rend un stockage disponible pour être réutilisé. Si ptr est NULL, XtFree retourne immédiatement.

XtNew renvoie un pointeur vers le stockage alloué. S'il n'y a pas suffisamment de mémoire pour allouer le nouveau bloc, XtNew appelle XtErrorMsg. XtNew est une macro pratique qui appelle XtMalloc avec les arguments suivants spécifiés :

((type *) XtMalloc((unsigned) sizeof(type))

XtNewString renvoie un pointeur vers une nouvelle chaîne qui est une duplication de string. S'il n'y a pas suffisamment de mémoire pour allouer le nouveau bloc, ou si l'argument est NULL, XtNewString renvoie NULL. La mémoire peut être libérée avec XtFree.

La fonction XtAsprintf alloue de l'espace pour une chaîne suffisamment grande pour contenir la chaîne spécifiée par le modèle de format sprintf(3c) lorsqu'elle est utilisée avec les arguments restants, et la remplit avec les résultats formatés. L'adresse de la chaîne allouée est placée dans le pointeur passé comme ret. La longueur de la chaîne (sans inclure l'octet nul terminant) est renvoyée. S'il n'y a pas suffisamment de mémoire pour allouer le nouveau bloc, XtAsprintf appelle XtErrorMsg.
