XtSetSensitive(3) FONCTIONS XT XtSetSensitive(3)

NOM

XtSetSensitive, XtIsSensitive - définir et vérifier l'état de sensibilité d'un widget

SYNTAXE

#include <X11/Intrinsic.h>

void XtSetSensitive(Widget w, Boolean sensitive);

Boolean XtIsSensitive(Widget w);

ARGUMENTS

sensitive
Spécifie une valeur booléenne indiquant si le widget doit recevoir des événements clavier et pointeur.
w
Spécifie le widget.

DESCRIPTION

La fonction XtSetSensitive appelle d'abord XtSetValues sur le widget courant avec une liste d'arguments spécifiant que le champ sensitive doit changer pour la nouvelle valeur. Elle propage ensuite récursivement la nouvelle valeur vers les enfants gérés en appelant XtSetValues sur chaque enfant pour définir ancestor_sensitive à la nouvelle valeur si les nouvelles valeurs pour sensitive et l'ancestor_sensitive de l'enfant ne sont pas les mêmes.

XtSetSensitive appelle XtSetValues pour modifier sensitive et ancestor_sensitive. Par conséquent, lorsqu'un de ceux-ci change, la procédure set_values du widget doit effectuer les actions d'affichage nécessaires (par exemple, griser ou pocher le widget).

XtSetSensitive maintient l'invariant selon lequel si parent a soit sensitive soit ancestor_sensitive à False, alors tous les enfants ont ancestor_sensitive à False.

La fonction XtIsSensitive renvoie True ou False pour indiquer si les événements d'entrée utilisateur sont distribués ou non. Si core.sensitive et core.ancestor_sensitive sont tous deux à True, XtIsSensitive renvoie True; sinon, elle renvoie False.
