XtAddCallback(3)

XtAddCallback(3) FONCTIONS XT XtAddCallback(3)

NOM

XtAddCallback, XtAddCallbacks, XtRemoveCallback, XtRemoveCallbacks, XtRemoveAllCallbacks - ajouter et supprimer des procédures de rappel

SYNTAXE

#include <X11/Intrinsic.h>

void XtAddCallback(Widget w, const char *callback_name, XtCallbackProc callback, XtPointer client_data);

void XtAddCallbacks(Widget w, const char *callback_name, XtCallbackList callbacks);

void XtRemoveCallback(Widget w, const char *callback_name, XtCallbackProc callback, XtPointer client_data);

void XtRemoveCallbacks(Widget w, const char *callback_name, XtCallbackList callbacks);

void XtRemoveAllCallbacks(Widget w, const char *callback_name);

ARGUMENTS

callback
Spécifie la procédure de rappel.
callbacks
Spécifie la liste terminée par NULL des procédures de rappel et des données client correspondantes.
callback_name
Spécifie la liste de rappel à laquelle la procédure doit être ajoutée ou de laquelle elle doit être supprimée.
client_data
Spécifie l'argument qui doit être passé à la procédure spécifiée lorsqu'elle est invoquée par XtCallbacks ou NULL, ou les données client à faire correspondre sur les procédures de rappel enregistrées.
w
Spécifie le widget.

DESCRIPTION

La fonction XtAddCallback ajoute la procédure de rappel spécifiée à la liste de rappel du widget spécifié.

La fonction XtAddCallbacks ajoute la liste spécifiée de rappels à la liste de rappel du widget spécifié.

La fonction XtRemoveCallback supprime un rappel uniquement si la procédure et les données client correspondent.

La fonction XtRemoveCallbacks supprime les procédures de rappel spécifiées de la liste de rappel du widget spécifié.

La fonction XtRemoveAllCallbacks supprime toutes les procédures de rappel de la liste de rappel du widget spécifié.
