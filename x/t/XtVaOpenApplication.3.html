XtOpenApplication(3) FONCTIONS XT XtOpenApplication(3)

NOM

XtOpenApplication, XtVaOpenApplication - initialiser, ouvrir ou fermer un affichage

SYNTAXE

#include <X11/Intrinsic.h>

Widget XtOpenApplication(XtAppContext *app_context_return, const char *application_class, XrmOptionDescRec *options, Cardinal num_options, int *argc_in_out, char **argv_in_out, String *fallback_resources, WidgetClass widget_class, ArgList args, Cardinal num_args);

Widget XtVaOpenApplication(XtAppContext *app_context_return, const char *application_class, XrmOptionDescRec *options, Cardinal num_options, int *argc_in_out, char **argv_in_out, String *fallback_resources, WidgetClass widget_class, ...);

ARGUMENTS

app_context_return
Spécifie le contexte de l'application.
application_class
Spécifie le nom de classe de cette application, qui est généralement le nom générique pour toutes les instances de cette application.
options
Spécifie comment analyser la ligne de commande pour les ressources spécifiques à l'application. L'argument options est passé en paramètre à XrmParseCommand. Pour plus d'informations, voir Xlib - Interface X en langage C.
num_options
Spécifie le nombre d'entrées dans la liste des options.
argc_in_out
Spécifie un pointeur vers le nombre de paramètres de la ligne de commande.
argv_in_out
Spécifie les paramètres de la ligne de commande.
fallback_resources
Spécifie les valeurs des ressources à utiliser si le fichier de ressources de la classe de l'application ne peut être ouvert ou lu, ou NULL.
widget_class
Spécifie la classe du widget de la fenêtre principale à créer.
args
Spécifie la liste des arguments pour remplacer toute autre spécification de ressource pour le widget de fenêtre créé.
num_args
Spécifie le nombre d'entrées dans la liste des arguments.
...
Spécifie la liste d'arguments variable pour remplacer toute autre spécification de ressource pour le widget de fenêtre créé.

DESCRIPTION

La fonction XtOpenApplication appelle XtToolkitInitialize suivi de XtCreateApplicationContext, puis appelle XtOpenDisplay avec display_string NULL et application_name NULL, et enfin appelle XtAppCreateShell avec application_name NULL, le widget_class spécifié, et les args et num_args spécifiés, puis retourne le widget de fenêtre créé. Le argc et argv modifiés retournés par XtDisplayInitialize sont retournés dans argc_in_out et argv_in_out. Si app_context_return n'est pas NULL, le contexte de l'application créé est également retourné. Si l'affichage spécifié par la ligne de commande ne peut pas être ouvert, un message d'erreur est émis et XtOpenApplication termine l'application. Si fallback_resources n'est pas NULL, XtAppSetFallbackResources est appelé avec la valeur avant d'appeler XtOpenDisplay.

XtAppInitialize et XtVaAppInitialize ont été remplacés par XtOpenApplication et XtVaOpenApplication respectivement.
