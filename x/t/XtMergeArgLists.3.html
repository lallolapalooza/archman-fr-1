XtMergeArgLists(3)

Paquet: libxt

Licences: MIT, HPND-sell-variant, SMLNJ, MIT-open-group, X11

XtSetArg(3) FONCTIONS XT XtSetArg(3)

NOM

XtSetArg, XtMergeArgLists - définir et fusionner des ArgLists

SYNTAXE

#include <X11/Intrinsic.h>

int XtSetArg(Arg arg, String name, XtArgVal value);

ArgList XtMergeArgLists(ArgList args1, Cardinal num_args1, ArgList args2, Cardinal num_args2);

ARGUMENTS

arg
Spécifie la paire nom-valeur à définir.
args1
Spécifie la première ArgList.
args2
Spécifie la deuxième ArgList.
num_args1
Spécifie le nombre d'arguments dans la première liste d'arguments.
num_args2
Spécifie le nombre d'arguments dans la deuxième liste d'arguments.
name
Spécifie le nom de la ressource.
value
Spécifie la valeur de la ressource si elle tient dans un XtArgVal ou l'adresse.

DESCRIPTION

La fonction XtSetArg est généralement utilisée d'une manière très stylisée pour minimiser la probabilité d'erreur ; par exemple :

Arg args[20];
int n;
n = 0;
XtSetArg(args[n], XtNheight, 100);      n++;
XtSetArg(args[n], XtNwidth, 200);       n++;
XtSetValues(widget, args, n);

Alternativement, une application peut déclarer statiquement la liste d'arguments et utiliser XtNumber :

static Args args[] = {
        {XtNheight, (XtArgVal) 100},
        {XtNwidth, (XtArgVal) 200},
};
XtSetValues(Widget, args, XtNumber(args));

Notez que vous ne devez pas utiliser l'incrémentation ou la décrémentation automatique dans le premier argument de XtSetArg. XtSetArg peut être implémentée comme une macro qui déréférence l'argument une deuxième fois.

La fonction XtMergeArgLists alloue suffisamment d'espace pour contenir les structures ArgList combinées et les copie dedans. Notez qu'elle ne vérifie pas les doublons. Lorsqu'il n'est plus nécessaire, libérez l'espace retourné en utilisant XtFree.
