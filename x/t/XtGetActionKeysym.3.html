XtGetActionKeysym(3) FONCTIONS XT XtGetActionKeysym(3)

NOM

XtGetActionKeysym - obtenir le keysym correspondant

SYNTAXE

#include <X11/Intrinsic.h>

KeySym XtGetActionKeysym(XEvent* event, Modifiers* modifiers_return);

ARGUMENTS

event
Spécifie le pointeur d'événement passé à la procédure d'action par les Intrinsics.
modifiers_return
Retourne les modificateurs qui ont provoqué la correspondance, si non-NULL.

DESCRIPTION

Si XtGetActionKeysym est appelé après qu'une procédure d'action a été invoquée par les Intrinsics et avant que cette procédure d'action ne retourne, et si le pointeur d'événement a la même valeur que le pointeur d'événement passé à cette routine d'action, et si l'événement est un événement KeyPress ou KeyRelease, alors XtGetActionKeysym retourne le KeySym qui correspond à la spécification d'événement finale dans la table de traduction et, si modifiers_return n'est pas NULL, l'état du modificateur réellement utilisé pour générer ce KeySym ; sinon, si l'événement est un événement KeyPress ou KeyRelease, alors XtGetActionKeysym appelle XtTranslateKeycode et retourne les résultats ; sinon, il retourne NoSymbol et n'examine pas modifiers_return.
