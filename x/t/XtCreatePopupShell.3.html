XtCreatePopupShell(3) FONCTIONS XT XtCreatePopupShell(3)

NOM

XtCreatePopupShell, XtVaCreatePopupShell - créer une fenêtre contextuelle

SYNTAXE

#include <X11/Intrinsic.h>

Widget XtCreatePopupShell(const char *name, WidgetClass widget_class, Widget parent, ArgList args, Cardinal num_args);

Widget XtVaCreatePopupShell(const char *name, WidgetClass widget_class, Widget parent, ...);

ARGUMENTS

args
Spécifie la liste d'arguments pour remplacer les valeurs par défaut des ressources.
name
Spécifie le nom textuel du widget fenêtre créé.
num_args
Spécifie le nombre d'arguments dans la liste d'arguments.
parent
Spécifie le widget parent.
widget_class
Spécifie le pointeur de classe de widget pour le widget fenêtre créé.
...
Spécifie la liste d'arguments variables pour remplacer les valeurs par défaut des ressources.

DESCRIPTION

La fonction XtCreatePopupShell garantit que la classe spécifiée est une sous-classe de Shell et, plutôt que d'utiliser insert_child pour attacher le widget à la liste des enfants du parent, attache directement la fenêtre à la liste des pop-ups du parent.

Une fenêtre contextuelle déclenchée à partir d'une table de traduction doit déjà exister au moment où la traduction est invoquée, afin que le gestionnaire de traduction puisse trouver la fenêtre par son nom. Les fenêtres contextuelles invoquées par d'autres moyens peuvent être créées «à la volée» lorsque la fenêtre contextuelle est réellement nécessaire. Cette création différée de la fenêtre est particulièrement utile lorsque vous ouvrez un nombre indéterminé de fenêtres contextuelles. Vous pouvez vérifier s'il existe une fenêtre contextuelle inutilisée appropriée (c'est-à-dire non actuellement ouverte) et en créer une nouvelle si nécessaire.
