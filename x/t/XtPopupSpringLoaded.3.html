XtPopupSpringLoaded(3)

Paquet: libxt

Licences: MIT, HPND-sell-variant, SMLNJ, MIT-open-group, X11

XtPopup(3) FONCTIONS XT XtPopup(3)

NOM

XtPopup, XtPopupSpringLoaded, XtCallbackNone, XtCallbackNonexclusive, XtCallbackExclusive - afficher une fenêtre contextuelle

SYNTAXE

#include <X11/Intrinsic.h>

void XtPopup(Widget popup_shell, XtGrabKind grab_kind);

void XtPopupSpringLoaded(Widget popup_shell);

void XtCallbackNone(Widget w, XtPointer client_data, XtPointer call_data);

void XtCallbackNonexclusive(Widget w, XtPointer client_data, XtPointer call_data);

void XtCallbackExclusive(Widget w, XtPointer client_data, XtPointer call_data);

ACTIONS

void XtMenuPopup(String shell_name);

ARGUMENTS

call_data
Spécifie les données de rappel, qui ne sont pas utilisées par cette procédure.
client_data
Spécifie le shell de la fenêtre contextuelle.
grab_kind
Spécifie la manière dont les événements utilisateur doivent être contraints.
popup_shell
Spécifie le shell du widget.
w
Spécifie le widget.

DESCRIPTION

La fonction XtPopup effectue les opérations suivantes :

  • Appelle XtCheckSubclass pour s'assurer que popup_shell est une sous-classe de Shell.
  • Génère une erreur si le champ popped_up du shell est déjà True.
  • Appelle les procédures de rappel de la liste popup_callback du shell.
  • Définit le champ popped_up du shell sur True, le champ spring_loaded sur False, et le champ grab_kind du shell à partir de grab_kind.
  • Si le champ create_popup_child du shell n'est pas NULL, XtPopup l'appelle avec popup_shell comme paramètre.
  • Si grab_kind est XtGrabNonexclusive ou XtGrabExclusive, elle appelle :
XtAddGrab(popup_shell, (grab_kind == XtGrabExclusive), False)
  • Appelle XtRealizeWidget avec popup_shell spécifié.
  • Appelle XMapWindow avec popup_shell spécifié.

La fonction XtPopupSpringLoaded fonctionne exactement comme XtPopup, sauf qu'elle définit le champ spring_loaded du shell sur True et appelle toujours XtAddGrab avec exclusive True et spring_loaded True.

Les fonctions XtCallbackNone, XtCallbackNonexclusive et XtCallbackExclusive appellent XtPopup avec le shell spécifié par l'argument client_data et grab_kind défini comme l'indique le nom. XtCallbackNone, XtCallbackNonexclusive et XtCallbackExclusive spécifient respectivement XtGrabNone, XtGrabNonexclusive et XtGrabExclusive. Chaque fonction désactive ensuite le widget qui a exécuté la liste de rappel en utilisant XtSetSensitive. L'utilisation de ces fonctions dans les rappels n'est pas obligatoire. En particulier, une application doit fournir du code personnalisé pour les rappels qui créent des shells de fenêtres contextuelles dynamiquement ou qui doivent faire plus que désactiver le bouton.

XtMenuPopup est connu du gestionnaire de traduction, qui doit effectuer des actions spéciales pour les fenêtres contextuelles à ressort. Les appels à XtMenuPopup dans une spécification de traduction sont mappés à des appels à une procédure d'action non exportée, et le gestionnaire de traduction remplit les paramètres en fonction de l'événement spécifié à gauche d'une traduction.

Si XtMenuPopup est invoqué sur ButtonPress (avec ou sans modificateurs), le gestionnaire de traduction fait apparaître le shell avec grab_kind défini sur XtGrabExclusive et spring_loaded défini sur True. Si XtMenuPopup est invoqué sur EnterWindow (avec ou sans modificateurs), le gestionnaire de traduction fait apparaître le shell avec grab_kind défini sur XtGrabNonexclusive et spring_loaded défini sur False. Sinon, le gestionnaire de traduction génère une erreur. Lorsque le widget apparaît, les actions suivantes se produisent :

  • Appelle XtCheckSubclass pour s'assurer que popup_shell est une sous-classe de Shell.
  • Génère une erreur si le champ popped_up du shell est déjà True.
  • Appelle les procédures de rappel de la liste popup_callback du shell.
  • Définit le champ popped_up du shell sur True et les champs grab_kind et spring_loaded du shell de manière appropriée.
  • Si le champ create_popup_child du shell n'est pas NULL, il est appelé avec popup_shell comme paramètre.
  • Appelle :
XtAddGrab(popup_shell, (grab_kind == XtGrabExclusive), spring_loaded)
  • Appelle XtRealizeWidget avec popup_shell spécifié.
  • Appelle XMapWindow avec popup_shell spécifié.

(Notez que ces actions sont identiques à celles de XtPopup.) XtMenuPopup essaie de trouver le shell en parcourant l'arbre des widgets à partir du parent du widget dans lequel il est invoqué. S'il trouve un shell avec le nom spécifié dans les enfants contextuels de ce parent, il fait apparaître le shell avec les paramètres appropriés. Sinon, il remonte la chaîne des parents si nécessaire. Si XtMenuPopup atteint le widget de l'application et ne trouve pas de shell correspondant, il génère une erreur.
