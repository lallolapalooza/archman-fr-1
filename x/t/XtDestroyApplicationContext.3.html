XtCreateApplicationContext(3) FONCTIONS XT XtCreateApplicationContext(3)

NOM

XtCreateApplicationContext, XtDestroyApplicationContext, XtWidgetToApplicationContext, XtToolkitInitialize - créer, détruire et obtenir un contexte d'application

SYNTAXE

#include <X11/Intrinsic.h>

XtAppContext XtCreateApplicationContext(void);

void XtDestroyApplicationContext(XtAppContext app_context);

XtAppContext XtWidgetToApplicationContext(Widget w);

void XtToolkitInitialize(void);

ARGUMENTS

app_context
Spécifie le contexte de l'application.
w
Spécifie le widget pour lequel vous souhaitez obtenir le contexte de l'application.

DESCRIPTION

La fonction XtCreateApplicationContext renvoie un contexte d'application, qui est un type opaque. Chaque application doit avoir au moins un contexte d'application.

La fonction XtDestroyApplicationContext détruit le contexte d'application spécifié dès que cela est possible sans risque. Si elle est appelée depuis une procédure de dispatch d'événements (par exemple, une procédure de rappel), XtDestroyApplicationContext ne détruit le contexte d'application qu'une fois le dispatch terminé.

La fonction XtWidgetToApplicationContext renvoie le contexte d'application pour le widget spécifié.

La fonction XtToolkitInitialize initialise les internes des Intrinsics. Si XtToolkitInitialize a été appelée précédemment, elle revient immédiatement.
