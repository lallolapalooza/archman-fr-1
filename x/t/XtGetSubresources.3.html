XtGetSubresources(3)

Paquet: libxt

Licences: MIT, HPND-sell-variant, SMLNJ, MIT-open-group, X11

XtGetSubresources(3) FONCTIONS XT XtGetSubresources(3)

NOM

XtGetSubresources, XtVaGetSubresources - obtenir des sous-ressources

SYNTAXE

#include <X11/Intrinsic.h>

void XtGetSubresources(Widget w, XtPointer base, const char *name, const char * class, XtResourceList resources, Cardinal num_resources, ArgList args, Cardinal num_args);

void XtVaGetSubresources(Widget w, XtPointer base, const char *name, const char *class, XtResourceList resources, Cardinal num_resources, ...);

ARGUMENTS

args
Spécifie la liste d'arguments pour substituer les ressources obtenues de la base de données de ressources.
base
Spécifie l'adresse de base de la structure de données de la sous-partie où les ressources doivent être écrites.
class
Spécifie la classe de la sous-partie.
name
Spécifie le nom de la sous-partie.
num_args
Spécifie le nombre d'arguments dans la liste d'arguments.
num_resources
Spécifie le nombre de ressources dans la liste de ressources.
resources
Spécifie la liste de ressources pour la sous-partie.
w
Spécifie le widget qui désire des ressources pour une sous-partie ou qui identifie la base de données de ressources à rechercher.
...
Spécifie les arguments variables pour substituer les ressources obtenues de la base de données de ressources.

DESCRIPTION

La fonction XtGetSubresources construit une liste nom/classe à partir du nom/classe de l'application, des noms/classes de tous ses ancêtres et du widget lui-même. Ensuite, elle ajoute à cette liste la paire nom/classe fournie. Les ressources sont récupérées de la liste d'arguments, de la base de données de ressources, ou des valeurs par défaut dans la liste de ressources. Elles sont ensuite copiées dans l'enregistrement de la sous-partie. Si args est NULL, num_args doit être zéro. Cependant, si num_args est zéro, la liste d'arguments n'est pas référencée.
