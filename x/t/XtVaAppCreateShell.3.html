XtAppCreateShell(3) FONCTIONS XT XtVaAppCreateShell(3)

NOM

XtAppCreateShell, XtVaAppCreateShell - créer une instance de widget de haut niveau

SYNTAXE

#include <X11/Intrinsic.h>

Widget XtAppCreateShell(const char *application_name, const char *application_class, WidgetClass widget_class, Display *display, ArgList args, Cardinal num_args);

Widget XtVaAppCreateShell(const char * application_name, const char * application_class, WidgetClass widget_class, Display *display, ...);

ARGUMENTS

application_name
Spécifie le nom de l'instance de l'application.
application_class
Spécifie le nom de la classe de cette application, qui est généralement le nom générique de toutes les instances de cette application.
widget_class
Spécifie la classe du widget qui doit être le widget de haut niveau de l'application.
display
Spécifie l'écran à partir duquel obtenir les ressources.
args
Spécifie la liste d'arguments à partir de laquelle obtenir les ressources.
num_args
Spécifie le nombre d'arguments dans la liste d'arguments.
...
Spécifie la liste d'arguments variables à partir de laquelle obtenir les ressources.

DESCRIPTION

La fonction XtAppCreateShell enregistre le nom d'application et la classe d'application spécifiés pour qualifier tous les spécificateurs de ressources de widget. Le nom d'application et la classe d'application sont utilisés comme les composants les plus à gauche dans tous les noms de ressources de widget pour cette application. XtAppCreateShell doit être utilisée pour créer une nouvelle application logique au sein d'un programme ou pour créer un shell sur un autre écran. Dans le premier cas, elle permet la spécification d'une nouvelle racine dans la hiérarchie des ressources. Dans le second cas, elle utilise la base de données de ressources associée à l'autre écran.

Notez que le widget retourné par XtAppCreateShell a la propriété WM_COMMAND définie pour les gestionnaires de session (voir Chapitre 4).
