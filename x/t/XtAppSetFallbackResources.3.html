XtAppSetFallbackResources(3) FONCTIONS XT XtAppSetFallbackResources(3)

NOM

XtAppSetFallbackResources - définir des ressources de secours

SYNTAXE

#include <X11/Intrinsic.h>

void XtAppSetFallbackResources(XtAppContext app_context, String* specification_list);

ARGUMENTS

app_context
Spécifie le contexte de l'application.
specification_list
Spécifie une liste terminée par NULL de spécifications de ressources à précharger dans la base de données, ou NULL.

DESCRIPTION

Chaque entrée de specification_list pointe vers une chaîne de caractères au format défini par XrmPutLineResource. Après un appel à XtAppSetFallbackResources, lorsqu'une base de données de ressources est créée pour un écran particulier et que les Intrinsèques ne parviennent pas à trouver ou lire un fichier de ressources de classe spécifique à l'application, et si specification_list n'est pas NULL, la spécification de ressources dans specification_list sera fusionnée dans la base de données des ressources de l'écran à la place du fichier de ressources de classe spécifique à l'application. XtAppSetFallbackResources n'est pas tenu de copier specification_list ; l'appelant doit s'assurer que le contenu de la liste et les chaînes adressées par la liste restent valides jusqu'à ce que tous les affichages soient initialisés ou jusqu'à ce que XtAppSetFallbackResources soit appelée à nouveau. La valeur NULL pour specification_list supprime toute spécification de ressource de secours précédente pour le contexte de l'application. L'utilisation prévue des ressources de secours est de fournir un nombre minimal de ressources qui rendront l'application utilisable (ou du moins se terminera avec des messages de diagnostic utiles) lorsqu'un problème existe dans la recherche et le chargement du fichier de défauts de l'application.
