XTextExtents(3) FONCTIONS XLIB XTextExtents(3)

NOM

XTextExtents, XTextExtents16, XQueryTextExtents, XQueryTextExtents16 - calculer ou interroger les extensions de texte

SYNTAXE

int XTextExtents(XFontStruct *font_struct, _Xconst char *string, int nchars, int *direction_return, int *font_ascent_return, int *font_descent_return, XCharStruct *overall_return);

int XTextExtents16(XFontStruct *font_struct, _Xconst XChar2b *string, int nchars, int *direction_return, int *font_ascent_return, int *font_descent_return, XCharStruct *overall_return);

int XQueryTextExtents(Display *display, XID font_ID, _Xconst char *string, int nchars, int *direction_return, int *font_ascent_return, int *font_descent_return, XCharStruct *overall_return);

int XQueryTextExtents16(Display *display, XID font_ID, _Xconst XChar2b *string, int nchars, int *direction_return, int *font_ascent_return, int *font_descent_return, XCharStruct *overall_return);

ARGUMENTS

direction_return
Retourne la valeur de l'indice de direction (FontLeftToRight ou FontRightToLeft).
display
Spécifie la connexion au serveur X.
font_ID
Spécifie soit l'ID de la police, soit l'ID du GContext qui contient la police.
font_ascent_return
Retourne l'ascendante de la police.
font_descent_return
Retourne la descendante de la police.
font_struct
Spécifie la structure XFontStruct.
nchars
Spécifie le nombre de caractères dans la chaîne de caractères.
string
Spécifie la chaîne de caractères.
overall_return
Retourne la taille globale dans la structure XCharStruct spécifiée.

DESCRIPTION

Les fonctions XTextExtents et XTextExtents16 effectuent le calcul de taille localement et évitent ainsi le surcoût d'aller-retour de XQueryTextExtents et XQueryTextExtents16. Ces deux fonctions retournent une structure XCharStruct, dont les membres sont définis comme suit.

Le membre ascent est défini comme le maximum des métriques d'ascendante de tous les caractères de la chaîne. Le membre descent est défini comme le maximum des métriques de descendante. Le membre width est défini comme la somme des métriques de largeur de caractère de tous les caractères de la chaîne. Pour chaque caractère de la chaîne, soit W la somme des métriques de largeur de caractère de tous les caractères qui le précèdent dans la chaîne. Soit L le métrique de port de gauche du caractère plus W. Soit R le métrique de port de droite du caractère plus W. Le membre lbearing est défini comme le minimum de L pour tous les caractères de la chaîne. Le membre rbearing est défini comme le maximum de R.

Pour les polices définies avec un indexage linéaire plutôt qu'un indexage matriciel à 2 octets, chaque structure XChar2b est interprétée comme un nombre de 16 bits avec byte1 comme octet de poids fort. Si la police n'a pas de caractère par défaut défini, les caractères indéfinis de la chaîne auront des métriques toutes à zéro.

Les fonctions XQueryTextExtents et XQueryTextExtents16 retournent la boîte englobante de la chaîne de caractères 8 bits et 16 bits spécifiée dans la police spécifiée ou dans la police contenue dans le GC spécifié. Ces fonctions interrogent le serveur X et subissent donc le surcoût d'aller-retour évité par XTextExtents et XTextExtents16. Ces deux fonctions retournent une structure XCharStruct, dont les membres sont définis comme suit.

Le membre ascent est défini comme le maximum des métriques d'ascendante de tous les caractères de la chaîne. Le membre descent est défini comme le maximum des métriques de descendante. Le membre width est défini comme la somme des métriques de largeur de caractère de tous les caractères de la chaîne. Pour chaque caractère de la chaîne, soit W la somme des métriques de largeur de caractère de tous les caractères qui le précèdent dans la chaîne. Soit L le métrique de port de gauche du caractère plus W. Soit R le métrique de port de droite du caractère plus W. Le membre lbearing est défini comme le minimum de L pour tous les caractères de la chaîne. Le membre rbearing est défini comme le maximum de R.

Pour les polices définies avec un indexage linéaire plutôt qu'un indexage matriciel à 2 octets, chaque structure XChar2b est interprétée comme un nombre de 16 bits avec byte1 comme octet de poids fort. Si la police n'a pas de caractère par défaut défini, les caractères indéfinis de la chaîne auront des métriques toutes à zéro.

Les caractères avec des métriques toutes à zéro sont ignorés. Si la police n'a pas de caractère par défaut défini, les caractères indéfinis dans la chaîne sont également ignorés.

XQueryTextExtents et XQueryTextExtents16 peuvent générer des erreurs BadFont et BadGC.

DIAGNOSTICS

BadFont
Une valeur pour un argument Font ou GContext ne nomme pas une police définie.
BadGC
Une valeur pour un argument GContext ne nomme pas un GContext défini.
