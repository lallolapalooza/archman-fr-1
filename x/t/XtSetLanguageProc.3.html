XtSetLanguageProc(3) FONCTIONS XT XtSetLanguageProc(3)

NOM

XtSetLanguageProc - définir la procédure de langue

SYNTAXE

#include <X11/Intrinsic.h>

XtLanguageProc XtSetLanguageProc(XtAppContext app_context, XtLanguageProc proc, XtPointer client_data);

ARGUMENTS

app_context
Spécifie le contexte d'application dans lequel la procédure de langue doit être utilisée, ou NULL.
proc
Spécifie la procédure de langue, ou NULL.
client_data
Spécifie des données client supplémentaires à passer à la procédure de langue lorsqu'elle est appelée.

DESCRIPTION

XtSetLanguageProc définit la procédure de langue qui sera appelée depuis XtDisplayInitialize pour tous les Displays initialisés ultérieurement dans le contexte d'application spécifié. Si app_context est NULL, la procédure de langue spécifiée est enregistrée dans tous les contextes d'application créés par le processus appelant, y compris tous les futurs contextes d'application qui pourraient être créés. Si proc est NULL, une procédure de langue par défaut est enregistrée. XtSetLanguageProc retourne la procédure de langue précédemment enregistrée. Si une procédure de langue n'a pas encore été enregistrée, la valeur de retour n'est pas spécifiée, mais si cette valeur de retour est utilisée dans un appel ultérieur à XtSetLanguageProc, cela entraînera l'enregistrement de la procédure de langue par défaut.

La procédure de langue par défaut fait ce qui suit :

  • Définit la locale selon l'environnement. Sur les systèmes basés sur ANSI C, cela est fait en appelant setlocale( LC_ALL, language ). En cas d'erreur, un message d'avertissement est émis avec XtWarning.
  • Appelle XSupportsLocale pour vérifier que la locale actuelle est prise en charge. Si la locale n'est pas prise en charge, un message d'avertissement est émis avec XtWarning et la locale est définie sur “C”.
  • Appelle XSetLocaleModifiers en spécifiant la chaîne vide.
  • Retourne la valeur de la locale actuelle. Sur les systèmes basés sur ANSI C, c'est la valeur de retour d'un appel final à setlocale( LC_ALL, NULL ).

Un client souhaitant utiliser ce mécanisme pour établir la locale peut le faire en appelant XtSetLanguageProc avant XtDisplayInitialize.
