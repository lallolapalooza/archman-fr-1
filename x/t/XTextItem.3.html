XTextItem(3)

Paquet: libx11

Licences: MIT AND X11

XDrawText(3) FONCTIONS XLIB XDrawText(3)

NOM

XDrawText, XDrawText16, XTextItem, XTextItem16 - dessiner du texte polytexte et des structures de dessin de texte

SYNTAXE

int XDrawText(Display *display, Drawable d, GC gc, int x, int y, XTextItem *items, int nitems);

int XDrawText16(Display *display, Drawable d, GC gc, int x, int y, XTextItem16 *items, int nitems);

ARGUMENTS

d
Spécifie le dessinable.
display
Spécifie la connexion au serveur X.
gc
Spécifie le GC.
items
Spécifie un tableau d'éléments de texte.
nitems
Spécifie le nombre d'éléments de texte dans le tableau.
x

y
Spécifient les coordonnées x et y, qui sont relatives à l'origine du dessinable spécifié et définissent l'origine du premier caractère.

DESCRIPTION

La fonction XDrawText16 est similaire à XDrawText sauf qu'elle utilise des caractères à 2 octets ou 16 bits. Les deux fonctions permettent un espacement complexe et des changements de police entre les chaînes comptées.

Chaque élément de texte est traité tour à tour. Un membre font autre que None dans un élément provoque le stockage de la police dans le GC et son utilisation pour le texte ultérieur. Un décalage delta de l'élément de texte spécifie une modification supplémentaire de la position le long de l'axe x avant que la chaîne ne soit dessinée. Le décalage est toujours ajouté à l'origine du caractère et ne dépend d'aucune caractéristique de la police. Chaque image de caractère, telle que définie par la police dans le GC, est traitée comme un masque supplémentaire pour une opération de remplissage sur le dessinable. Le dessinable n'est modifié que là où le caractère de la police a un bit défini à 1. Si un élément de texte génère une erreur BadFont, les éléments de texte précédents peuvent avoir été dessinés.

Pour les polices définies avec un indexation linéaire plutôt qu'une indexation matricielle à 2 octets, chaque structure XChar2b est interprétée comme un nombre de 16 bits avec byte1 comme octet le plus significatif.

Les deux fonctions utilisent ces composants GC : function, plane-mask, fill-style, font, subwindow-mode, clip-x-origin, clip-y-origin et clip-mask. Elles utilisent également ces composants dépendants du mode GC : foreground, background, tile, stipple, tile-stipple-x-origin et tile-stipple-y-origin.

XDrawText et XDrawText16 peuvent générer les erreurs BadDrawable, BadFont, BadGC et BadMatch.

STRUCTURES

Les structures XTextItem et XTextItem16 contiennent :

typedef struct {
        char *chars;    /* pointeur vers la chaîne */
        int nchars;     /* nombre de caractères */
        int delta;      /* décalage entre les chaînes */
        Font font;      /* Police pour l'impression, None ne change pas */
} XTextItem;
typedef struct {
        XChar2b *chars; /* pointeur vers des caractères à deux octets */
        int nchars;     /* nombre de caractères */
        int delta;      /* décalage entre les chaînes */
        Font font;      /* police pour l'impression, None ne change pas */
} XTextItem16;

Si le membre font n'est pas None, la police est modifiée avant l'impression et est également stockée dans le GC. Si une erreur a été générée pendant le dessin du texte, les éléments précédents peuvent avoir été dessinés. La ligne de base des caractères est dessinée à partir des coordonnées x et y que vous passez dans les fonctions de dessin de texte.

Par exemple, considérez le rectangle d'arrière-plan dessiné par XDrawImageString. Si vous voulez que le coin supérieur gauche du rectangle d'arrière-plan soit aux coordonnées de pixel (x,y), passez (x,y + ascent) comme coordonnées d'origine de la ligne de base aux fonctions de texte. L'ascent est l'ascent de la police, tel que donné dans la structure XFontStruct. Si vous voulez que le coin inférieur gauche du rectangle d'arrière-plan soit aux coordonnées de pixel (x,y), passez (x,y - descent + 1) comme coordonnées d'origine de la ligne de base aux fonctions de texte. Le descent est le descent de la police, tel que donné dans la structure XFontStruct.

DIAGNOSTICS

BadDrawable
Une valeur pour un argument Drawable ne nomme pas une fenêtre ou un Pixmap défini.
BadFont
Une valeur pour un argument Font ou GContext ne nomme pas une police ou un GContext défini.
BadGC
Une valeur pour un argument GContext ne nomme pas un GContext défini.
BadMatch
Une fenêtre InputOnly est utilisée comme Drawable.
