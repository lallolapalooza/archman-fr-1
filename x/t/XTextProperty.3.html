Paquet: libx11

Licences: MIT AND X11

XStringListToTextProperty(3) FONCTIONS XLIB XStringListToTextProperty(3)

NOM

XStringListToTextProperty, XTextPropertyToStringList, XFreeStringList, XTextProperty - convertir des listes de chaînes et une structure de propriété de texte

SYNTAXE

Status XStringListToTextProperty(char **list, int count, XTextProperty *text_prop_return);

Status XTextPropertyToStringList(XTextProperty *text_prop, char ***list_return, int *count_return);

void XFreeStringList(char **list);

ARGUMENTS

count
Spécifie le nombre de chaînes.
count_return
Retourne le nombre de chaînes.
list
Spécifie la liste de chaînes à libérer.
list
Spécifie une liste de chaînes de caractères terminées par un caractère nul.
list_return
Retourne une liste de chaînes de caractères terminées par un caractère nul.
text_prop
Spécifie la structure XTextProperty à utiliser.
text_prop_return
Retourne la structure XTextProperty.

DESCRIPTION

La fonction XStringListToTextProperty initialise la structure XTextProperty spécifiée pour être de type STRING (format 8) avec une valeur représentant la concaténation de la liste spécifiée de chaînes de caractères séparées par des caractères nuls. Un octet nul supplémentaire (qui n'est pas inclus dans le membre nitems) est stocké à la fin du champ de valeur de text_prop_return. Les chaînes sont supposées (sans vérification) être dans le codage STRING. Si une mémoire insuffisante est disponible pour la nouvelle chaîne de valeur, XStringListToTextProperty ne définit aucun champ dans la structure XTextProperty et retourne un statut nul. Sinon, elle retourne un statut non nul. Pour libérer la mémoire du champ de valeur, utilisez XFree.

La fonction XTextPropertyToStringList retourne une liste de chaînes représentant les éléments séparés par des caractères nuls de la structure XTextProperty spécifiée. Les données dans text_prop doivent être de type STRING et de format 8. Plusieurs éléments de la propriété (par exemple, les chaînes d'une sélection de texte disjointes) sont séparés par un caractère NULL (codage 0). Le contenu de la propriété n'est pas terminé par un caractère nul. Si une mémoire insuffisante est disponible pour la liste et ses éléments, XTextPropertyToStringList ne définit aucune valeur de retour et retourne un statut nul. Sinon, elle retourne un statut non nul. Pour libérer la mémoire de la liste et de son contenu, utilisez XFreeStringList.

La fonction XFreeStringList libère la mémoire allouée par XmbTextPropertyToTextList, Xutf8TextPropertyToTextList et XTextPropertyToStringList ainsi que la liste de jeux de caractères manquants allouée par XCreateFontSet.

STRUCTURES

La structure XTextProperty contient :

typedef struct {
        unsigned char *value;   /* données de la propriété */
        Atom encoding;  /* type de la propriété */
        int format;     /* 8, 16, ou 32 */
        unsigned long nitems;   /* nombre d'éléments dans value */
} XTextProperty;
