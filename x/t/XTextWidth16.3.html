XTextWidth16(3)

Paquet: libx11

Licences: MIT AND X11

XTextWidth(3) FONCTIONS XLIB XTextWidth(3)

NOM

XTextWidth, XTextWidth16 - calculer la largeur du texte

SYNTAXE

int XTextWidth(XFontStruct *font_struct, _Xconst char *string, int count);

int XTextWidth16(XFontStruct *font_struct, _Xconst XChar2b *string, int count);

ARGUMENTS

count
Spécifie le nombre de caractères dans la chaîne indiquée.
font_struct
Spécifie la police utilisée pour le calcul de la largeur.
string
Spécifie la chaîne de caractères.

DESCRIPTION

Les fonctions XTextWidth et XTextWidth16 retournent la largeur des chaînes de caractères de 8 bits ou de 2 octets spécifiées.
