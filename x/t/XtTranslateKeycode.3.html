XtSetKeyTranslator(3) FONCTIONS XT XtSetKeyTranslator(3)

NOM

XtSetKeyTranslator, XtTranslateKeycode, XtRegisterCaseConverter, XtConvertCase - convertir les KeySym en KeyCodes

SYNTAXE

#include <X11/Intrinsic.h>

void XtSetKeyTranslator(Display *display, XtKeyProc proc);

void XtTranslateKeycode(Display *display, KeyCode keycode, Modifiers modifiers, Modifiers *modifiers_return, KeySym *keysym_return);

void XtRegisterCaseConverter(Display *display, XtCaseProc proc, KeySym start, KeySym stop);

void XtConvertCase(Display *display, KeySym keysym, KeySym *lower_return, KeySym *upper_return);

ARGUMENTS

display
Spécifie l'affichage.
keycode
Spécifie le KeyCode à traduire.
keysym
Spécifie le KeySym à convertir.
keysym_return
Retourne le KeySym résultant.
lower_return
Retourne l'équivalent en minuscule du KeySym.
upper_return
Retourne l'équivalent en majuscule du KeySym.
modifiers
Spécifie les modificateurs du KeyCode.
modifiers_return
Retourne un masque indiquant les modificateurs effectivement utilisés pour générer le KeySym.
proc
Spécifie la procédure qui doit effectuer les translations ou conversions de touches.
start
Spécifie le premier KeySym pour lequel ce convertisseur est valide.
stop
Spécifie le dernier KeySym pour lequel ce convertisseur est valide.

DESCRIPTION

La fonction XtSetKeyTranslator définit la procédure spécifiée comme traducteur de touches courant. Le traducteur par défaut est XtTranslateKey, un XtKeyProc qui utilise les modificateurs Shift et Lock avec les interprétations définies par le protocole de base. Il est fourni afin que les nouveaux traducteurs puissent l'appeler pour obtenir les traductions par défaut KeyCode-vers-KeySym et afin que le traducteur par défaut puisse être réinstallé.

La fonction XtTranslateKeycode transmet les arguments spécifiés directement au traducteur KeyCode vers KeySym actuellement enregistré.

La fonction XtRegisterCaseConverter enregistre le convertisseur de casse spécifié. Les arguments start et stop fournissent la plage inclusive des KeySyms pour lesquels ce convertisseur doit être appelé. Le nouveau convertisseur remplace tous les convertisseurs précédents pour les KeySyms de cette plage. Aucune interface n'existe pour supprimer les convertisseurs ; vous devez enregistrer un convertisseur d'identité. Lorsque un nouveau convertisseur est enregistré, les Intrinsics rafraîchissent l'état du clavier si nécessaire. Le convertisseur par défaut comprend la conversion de casse pour tous les KeySyms définis dans le protocole de base.

La fonction XtConvertCase appelle le convertisseur approprié et retourne les résultats. Un XtKeyProc fourni par l'utilisateur peut avoir besoin d'utiliser cette fonction.
