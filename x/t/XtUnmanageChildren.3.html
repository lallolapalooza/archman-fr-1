XtManageChildren(3) FONCTIONS XT XtManageChildren(3)

NOM

XtManageChildren, XtManageChild, XtUnmanageChildren, XtUnmanageChild, XtChangeManagedSet, XtIsManaged - gérer et dégerer les enfants

SYNTAXE

#include <X11/Intrinsic.h>

typedef Widget *WidgetList;

void XtManageChildren(WidgetList children, Cardinal num_children);

void XtManageChild(Widget child);

void XtUnmanageChildren(WidgetList children, Cardinal num_children);

void XtUnmanageChild(Widget child);

void XtChangeManagedSet(WidgetList unmanage_children, Cardinal num_unmanage_children, XtDoChangeProc do_change_proc, XtPointer client_data, WidgetList manage_children, Cardinal num_manage_children);

Boolean XtIsManaged(Widget widget);

ARGUMENTS

enfant
Spécifie l'enfant.
enfants
Spécifie une liste de widgets enfants.
nb_enfants
Spécifie le nombre d'enfants.
widget
Spécifie le widget.
gerer_enfants
Spécifie la liste des widgets enfants à ajouter à l'ensemble géré.
nb_gerer_enfants
Spécifie le nombre d'entrées dans la liste gerer_enfants.
degere_enfants
Spécifie la liste des widgets enfants à retirer de l'ensemble géré.
nb_degere_enfants
Spécifie le nombre d'entrées dans la liste degere_enfants.
proc_changement
Spécifie la procédure de hook post-dégérence, pré-gérence à appeler.
donnees_client
Spécifie les données client à passer à la procédure de hook.

DESCRIPTION

La fonction XtManageChildren effectue les opérations suivantes :

  • Émet une erreur si les enfants n'ont pas tous le même parent ou si le parent n'est pas une sous-classe de compositeWidgetClass.
  • Retourne immédiatement si le parent commun est en cours de destruction ; sinon, pour chaque enfant unique de la liste, XtManageChildren ignore l'enfant s'il est déjà géré ou en cours de destruction et le marque sinon.
  • Si le parent est réalisé et après que tous les enfants aient été marqués, il rend certains des enfants nouvellement gérés visibles :
  • Appelle la routine de changement_géré des widgets parents.
  • Appelle XtRealizeWidget sur chaque enfant précédemment non géré qui est non réalisé.
  • Mappe chaque enfant précédemment non géré dont map_when_managed est True.

La gestion des enfants est indépendante de l'ordre des enfants et indépendante de la création et de la suppression des enfants. La routine de disposition du parent doit prendre en compte les enfants dont le champ « managed » est True et ignorer tous les autres enfants. Notez que certains widgets composites, notamment les boîtes fixes, appellent XtManageChild depuis leur procédure insert_child.

Si le widget parent est réalisé, sa procédure change_managed est appelée pour l'informer que son ensemble d'enfants gérés a changé. Le parent peut repositionner et redimensionner n'importe lequel de ses enfants. Il déplace chaque enfant si nécessaire en appelant XtMoveWidget, qui met d'abord à jour les champs x et y, puis appelle XMoveWindow si le widget est réalisé.

La fonction XtManageChild construit une WidgetList de longueur un et appelle XtManageChildren.

La fonction XtUnmanageChildren effectue les opérations suivantes :

  • Émet une erreur si les enfants n'ont pas tous le même parent ou si le parent n'est pas une sous-classe de compositeWidgetClass.
  • Retourne immédiatement si le parent commun est en cours de destruction ; sinon, pour chaque enfant unique de la liste, XtUnmanageChildren effectue les opérations suivantes :
  • Ignore l'enfant s'il est déjà non géré ou en cours de destruction et le marque sinon.
  • Si l'enfant est réalisé, il est rendu non visible en étant démappé.
•
Appelle la routine change_managed du parent des widgets après que tous les enfants aient été marqués si le parent est réalisé.

XtUnmanageChildren ne détruit pas les widgets enfants. Retirer des widgets de l'ensemble géré d'un parent est souvent une exclusion temporaire, et, plus tard, vous pourrez gérer à nouveau les enfants.

La fonction XtUnmanageChild construit une liste de widgets de longueur un et appelle XtUnmanageChildren.

La fonction XtChangeManagedSet effectue les opérations suivantes :

  • Émet une erreur si les widgets spécifiés dans les listes manage_children et unmanage_children n'ont pas tous le même parent, ou si ce parent n'est pas une sous-classe de compositeWidgetClass.
  • Retourne immédiatement si le parent commun est en cours de destruction.
  • Si aucune CompositeClassExtension n'est définie, ou si une CompositeClassExtension est définie mais avec un champ allows_change_managed_set ayant la valeur False, et que XtChangeManagedSet a été appelée avec une procédure do_change_proc non nulle, alors XtChangeManagedSet effectue les opérations suivantes :
  • Appelle XtUnmanageChildren (unmanage_children, num_unmanage_children).
  • Appelle la procédure do_change_proc spécifiée.
  • Appelle XtManageChildren (manage_children, num_manage_children) puis retourne immédiatement.
•
Sinon, si une CompositeClassExtension est définie avec un champ allows_change_managed_set ayant la valeur True, ou si aucune CompositeClassExtension n'est définie, et que XtChangeManagedSet a été appelée avec une procédure do_change_proc nulle, alors les opérations suivantes sont effectuées :
  • Pour chaque enfant de la liste unmanage_children ; si l'enfant est déjà non géré ou en cours de destruction, il est ignoré, sinon il est marqué comme non géré et s'il est réalisé, il est rendu non visible en étant démappé.
  • Si la procédure do_change_proc est non nulle, elle est appelée comme spécifié.
  • Pour chaque enfant de la liste manage_children ; si l'enfant est déjà géré ou en cours de destruction, il est ignoré, sinon il est marqué comme géré.
•
Si le parent est réalisé et après que tous les enfants aient été marqués, la méthode change_managed du parent est appelée et par la suite certains des enfants nouvellement gérés sont rendus visibles en :
  • Appelant XtRealizeWidget sur chaque enfant précédemment non géré qui est non réalisé.
  • Mappant chaque enfant précédemment non géré dont map_when_managed est True.

La fonction XtIsManaged retourne True si le widget spécifié est de classe RectObj ou d'une sous-classe de celle-ci et est géré, sinon False.

XtUnmanageChildren(3)

NOM

XtUnmanageChildren - Désactive la gestion des enfants d'un widget.

SYNTAXE

void XtUnmanageChildren(WidgetList children, Cardinal num_children);

ARGUMENTS

children
Spécifie une liste de widgets enfants à désactiver.
num_children
Spécifie le nombre de widgets dans la liste children.

DESCRIPTION

La fonction XtUnmanageChildren désactive la gestion des widgets spécifiés dans la liste children. Lorsqu'un widget est désactivé, son gestionnaire de géométrie n'est plus appelé, et le widget n'est plus affiché ou géré par son widget parent.

Pour réactiver la gestion d'un widget, utilisez la fonction XtManageChildren.

VOIR AUSSI

XtManageChildren(3), XtIsManaged(3)
