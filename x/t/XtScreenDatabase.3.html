XtDisplayInitialize(3) FONCTIONS XT XtDisplayInitialize(3)

NOM

XtDisplayInitialize, XtOpenDisplay, XtDatabase, XtScreenDatabase, XtCloseDisplay - initialiser, ouvrir ou fermer un affichage

SYNTAXE

#include <X11/Intrinsic.h>

void XtDisplayInitialize(XtAppContext app_context, Display *display, const char *application_name, const char *application_class, XrmOptionDescRec *options, Cardinal num_options, int *argc, char **argv);

Display *XtOpenDisplay(XtAppContext app_context, const char *display_string, const char *application_name, const char *application_class, XrmOptionDescRec *options, Cardinal num_options, int *argc, char **argv);

void XtCloseDisplay(Display *display);

XrmDatabase XtDatabase(Display *display);

XrmDatabase XtScreenDatabase(Screen* screen);

ARGUMENTS

argc
Spécifie un pointeur vers le nombre de paramètres de la ligne de commande.
argv
Spécifie les paramètres de la ligne de commande.
app_context
Spécifie le contexte de l'application.
application_class
Spécifie le nom de classe de cette application, qui est généralement le nom générique pour toutes les instances de cette application.
application_name
Spécifie le nom de l'instance de l'application.
display
Spécifie l'affichage. Notez qu'un affichage ne peut être que dans un seul contexte d'application.
num_options
Spécifie le nombre d'entrées dans la liste des options.
options
Spécifie comment analyser la ligne de commande pour toute ressource spécifique à l'application. L'argument options est passé en paramètre à XrmParseCommand. Pour plus d'informations, voir Xlib - C Language X Interface.
screen
Spécifie l'écran dont la base de données de ressources doit être retournée.

DESCRIPTION

La fonction XtDisplayInitialize construit la base de données des ressources, appelle la fonction XrmParseCommand de Xlib pour analyser la ligne de commande et effectue d'autres initialisations par affichage. Après l'appel à XrmParseCommand, argc et argv ne contiennent que les paramètres qui n'étaient ni dans la table d'options standard, ni dans la table spécifiée par l'argument options. Si argc modifié n'est pas zéro, la plupart des applications impriment simplement argv modifié avec un message listant les options autorisées. Sur les systèmes de type UNIX, le nom de l'application est généralement le dernier composant de argv[0]. Si la ressource synchronize est True pour l'application spécifiée, XtDisplayInitialize appelle la fonction XSynchronize de Xlib pour mettre Xlib en mode synchrone pour cette connexion d'affichage. Si la ressource reverseVideo est True, les Intrinsèques échangent XtDefaultForeground et XtDefaultBackground pour les widgets créés sur cet affichage. (Voir Section 9.6.1).

La fonction XtOpenDisplay appelle XOpenDisplay avec le nom d'affichage spécifié. Si display_string est NULL, XtOpenDisplay utilise la valeur actuelle de l'option -display spécifiée dans argv et, si aucun affichage n'est spécifié dans argv, utilise l'affichage par défaut de l'utilisateur (sur les systèmes de type UNIX, c'est la valeur de la variable d'environnement DISPLAY).

Si cela réussit, elle appelle ensuite XtDisplayInitialize et lui transmet l'affichage ouvert et la valeur de l'option -name spécifiée dans argv comme nom d'application. Si aucune option de nom n'est spécifiée, elle utilise le nom d'application passé à XtOpenDisplay. Si le nom d'application est NULL, elle utilise le dernier composant de argv[0]. XtOpenDisplay retourne le nouvel affichage ouvert ou NULL s'il a échoué.

XtOpenDisplay est fournie comme une commodité pour le programmeur d'application.

La fonction XtCloseDisplay ferme l'affichage spécifié dès qu'il est sûr de le faire. Si elle est appelée depuis une procédure de traitement d'événements (par exemple, une procédure de rappel), XtCloseDisplay ne ferme pas l'affichage tant que le traitement n'est pas terminé. Notez que les applications n'ont besoin d'appeler XtCloseDisplay que si elles doivent continuer à s'exécuter après la fermeture de l'affichage ; sinon, elles devraient appeler XtDestroyApplicationContext ou simplement quitter.

La fonction XtDatabase retourne la base de données de ressources complètement fusionnée qui a été construite par XtDisplayInitialize et associée à l'affichage passé en argument. Si cet affichage n'a pas été initialisé par XtDisplayInitialize, les résultats ne sont pas définis.

La fonction XtScreenDatabase retourne la base de données de ressources complètement fusionnée associée à l'écran spécifié. Si l'argument screen n'appartient pas à un Display initialisé par XtDisplayInitialize, les résultats sont indéfinis.
