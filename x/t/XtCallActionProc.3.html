XtCallActionProc(3) FONCTIONS XT XtCallActionProc(3)

NOM

XtCallActionProc - invoquer une procédure d'action directement

SYNTAXE

#include <X11/Intrinsic.h>

void XtCallActionProc(Widget widget, const char *action, XEvent *event, String *params, Cardinal num_params);

ARGUMENTS

widget
Spécifie le widget dans lequel l'action doit être invoquée. Doit être de classe core ou l'une de ses sous-classes.
action
Spécifie le nom de la routine d'action.
event
Spécifie le contenu de l'event passé à la routine d'action.
params
Spécifie le contenu des params passés à la routine d'action.
num_params
Spécifie le nombre d'entrées dans params.

DESCRIPTION

XtCallActionProc recherche la routine d'action nommée de la même manière et dans le même ordre que les tables de traduction sont liées. Si elle est trouvée, la routine d'action est invoquée avec le widget spécifié, le pointeur d'événement et les paramètres. Il incombe à l'appelant de s'assurer que le contenu des arguments event, params et num_params est approprié pour la routine spécifiée, et si nécessaire, que le widget spécifié est réalisé ou sensible. Si la routine d'action nommée ne peut pas être trouvée, XtCallActionProc génère un message d'avertissement et retourne.
