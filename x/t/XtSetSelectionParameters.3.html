XtSetSelectionParameters(3)

Paquet: libxt

XtSetSelectionParameters(3) FONCTIONS XT XtSetSelectionParameters(3)

NOM

XtSetSelectionParameters - spécifier les paramètres de cible pour une demande de sélection avec une cible unique

SYNTAXE

#include <X11/Intrinsic.h>

void XtSetSelectionParameters(Widget requestor, Atom selection, Atom type, XtPointer value, unsigned long length, int format);

ARGUMENTS

requestor
Spécifie le widget effectuant la requête. Doit être de classe Core ou de toute sous-classe de celle-ci.
selection
Spécifie l'atome qui nomme la sélection.
type
Spécifie le type de la propriété dans laquelle les paramètres seront transmis.
value
Spécifie un pointeur vers les paramètres.
length
Spécifie le nombre d'éléments contenant des données dans value, chaque élément d'une taille indiquée par format.
format
Spécifie la taille en bits des données dans les éléments de value.

DESCRIPTION

Les paramètres spécifiés seront copiés et stockés dans une nouvelle propriété du type et du format spécifiés sur la fenêtre du demandeur. Pour initier une requête de sélection avec une cible et ces paramètres, un appel ultérieur à XtGetSelectionValue ou à XtGetSelectionValueIncremental spécifiant le même widget demandeur et l'atome de sélection générera une requête ConvertSelection faisant référence à la propriété contenant les paramètres. Si XtSetSelectionParameters est appelé plus d'une fois avec le même widget et la même sélection sans appel pour spécifier une requête, les paramètres spécifiés le plus récemment sont utilisés dans la requête ultérieure.

Les valeurs possibles de format peuvent être 8, 16 ou 32. Si le format est 8, les éléments de value sont supposés être sizeof(char) ; si 16, sizeof(short) ; si 32, sizeof(long).

Pour générer une requête cible MULTIPLE avec des paramètres pour n'importe laquelle des cibles multiples de la requête de sélection, précéder les appels individuels à XtGetSelectionValue et XtGetSelectionValueIncremental avec des appels individuels correspondants à XtSetSelectionParameters, et englober le tout dans XtCreateSelectionRequest et XtSendSelectionRequest. XtGetSelectionValues et XtGetSelectionValuesIncremental ne peuvent pas être utilisés pour effectuer des requêtes de sélection avec des cibles paramétrées.
