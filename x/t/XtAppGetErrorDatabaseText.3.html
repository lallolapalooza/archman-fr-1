XtAppGetErrorDatabase(3) FONCTIONS XT XtAppGetErrorDatabase(3)

NOM

XtAppGetErrorDatabase, XtAppGetErrorDatabaseText - obtenir la base de données d'erreurs

SYNTAXE

#include <X11/Intrinsic.h>

XrmDatabase *XtAppGetErrorDatabase(XtAppContext app_context);

void XtAppGetErrorDatabaseText(XtAppContext app_context, const char *name, const char *type, const char *class, const char *defaultMsg, char *buffer_return, int nbytes, XrmDatabase database);

ARGUMENTS

app_context
Spécifie le contexte de l'application.
buffer_return
Spécifie le tampon dans lequel le message d'erreur doit être renvoyé.
class
Spécifie la classe de ressource du message d'erreur.
database
Spécifie le nom de la base de données alternative à utiliser ou NULL si la base de données de l'application doit être utilisée.
defaultMsg
Spécifie le message par défaut à utiliser.
name

type
Spécifie le nom et le type qui sont concaténés pour former le nom de ressource du message d'erreur.
nbytes
Spécifie la taille du tampon en octets.

DESCRIPTION

La fonction XtAppGetErrorDatabase renvoie l'adresse de la base de données d'erreurs. Les Intrinsics effectuent une liaison paresseuse de la base de données d'erreurs et ne fusionnent le fichier de base de données que lors du premier appel à XtAppGetDatbaseText.

La fonction XtAppGetErrorDatabaseText renvoie le message approprié de la base de données d'erreurs ou renvoie le message par défaut spécifié si aucun n'est trouvé dans la base de données d'erreurs.
