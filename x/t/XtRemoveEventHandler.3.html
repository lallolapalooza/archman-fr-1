XtAddEventHandler(3) FONCTIONS XT XtAddEventHandler(3)

NOM

XtAddEventHandler, XtAddRawEventHandler, XtRemoveEventHandler, XtRemoveRawEventHandler, XtInsertEventHandler, XtInsertRawEventHandler - ajouter et supprimer des gestionnaires d'événements

SYNTAXE

#include <X11/Intrinsic.h>

void XtAddEventHandler(Widget w, EventMask event_mask, Boolean nonmaskable, XtEventHandler proc, XtPointer client_data);

void XtAddRawEventHandler(Widget w, EventMask event_mask, Boolean nonmaskable, XtEventHandler proc, XtPointer client_data);

void XtRemoveEventHandler(Widget w, EventMask event_mask, Boolean nonmaskable, XtEventHandler proc, XtPointer client_data);

void XtRemoveRawEventHandler(Widget w, EventMask event_mask, Boolean nonmaskable, XtEventHandler proc, XtPointer client_data);

void XtInsertEventHandler(Widget w, EventMask event_mask, Boolean nonmaskable, XtEventHandler proc, XtPointer client_data, XtListPosition position);

void XtInsertRawEventHandler(Widget w, EventMask event_mask, Boolean nonmaskable, XtEventHandler proc, XtPointer client_data, XtListPosition position);

typedef enum { XtListHead, XtListTail } XtListPosition;

ARGUMENTS

client_data
Spécifie des données supplémentaires à passer au gestionnaire d'événements du client.
event_mask
Spécifie le masque d'événements pour lequel appeler ou désenregistrer cette procédure.
nonmaskable
Spécifie une valeur booléenne indiquant si cette procédure doit être appelée ou supprimée pour les événements non masquables ( GraphicsExpose, NoExpose, SelectionClear, SelectionRequest, SelectionNotify, ClientMessage, et MappingNotify).
proc
Spécifie la procédure à ajouter ou à supprimer.
w
Spécifie le widget pour lequel ce gestionnaire d'événements est enregistré.
position
Spécifie quand le gestionnaire d'événements doit être appelé par rapport aux autres gestionnaires précédemment enregistrés.

DESCRIPTION

La fonction XtAddEventHandler enregistre une procédure auprès du mécanisme de dispatch qui doit être appelée lorsqu'un événement correspondant au masque se produit sur le widget spécifié. Si la procédure est déjà enregistrée avec le même client_data, le masque spécifié est combiné (OR) avec le masque existant. Si le widget est réalisé, XtAddEventHandler appelle XSelectInput, si nécessaire.

La fonction XtAddRawEventHandler est similaire à XtAddEventHandler, à la différence qu'elle n'affecte pas le masque du widget et ne provoque jamais un appel à XSelectInput pour ses événements. Notez que le widget peut déjà avoir ces bits de masque définis en raison d'autres gestionnaires d'événements non bruts qui y sont enregistrés.

La fonction XtRemoveRawEventHandler arrête la réception des événements spécifiés par la procédure donnée. Étant donné que la procédure est un gestionnaire d'événements brut, cela n'affecte pas le masque du widget et ne provoque jamais un appel à XSelectInput.

XtInsertEventHandler est identique à XtAddEventHandler avec l'argument supplémentaire position. Si position est XtListHead, le gestionnaire d'événements est enregistré de manière à être appelé avant tous les gestionnaires d'événements qui étaient précédemment enregistrés pour le même widget. Si position est XtListTail, le gestionnaire d'événements est enregistré pour être appelé après tous les gestionnaires d'événements précédemment enregistrés. Si la procédure est déjà enregistrée avec la même valeur client_data, le masque spécifié augmente le masque existant et la procédure est repositionnée dans la liste.

XtInsertRawEventHandler est similaire à XtInsertEventHandler à la différence qu'elle ne modifie pas le masque d'événements du widget et ne provoque jamais un appel à XSelectInput pour les événements spécifiés. Si la procédure est déjà enregistrée avec la même valeur client_data, le masque spécifié augmente le masque existant et la procédure est repositionnée dans la liste.
