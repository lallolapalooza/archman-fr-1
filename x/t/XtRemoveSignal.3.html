XtRemoveSignal(3)

Paquet: libxt

Licences: MIT, HPND-sell-variant, SMLNJ, MIT-open-group, X11

XtAppAddSignal(3) FONCTIONS XT XtRemoveSignal(3)

NOM

XtAppAddSignal, XtRemoveSignal, XtNoticeSignal - enregistrer et supprimer une source de signal

SYNTAXE

#include <X11/Intrinsic.h>

XtSignalId XtAppAddSignal(XtAppContext app_context, XtSignalCallbackProc proc, XtPointer client_data);

void XtRemoveSignal(XtSignalId id);

void XtNoticeSignal(XtSignalId id);

ARGUMENTS

app_context
Spécifie le contexte d'application.
client_data
Spécifie l'argument qui doit être passé à la procédure spécifiée lorsqu'un signal a été déclenché.
id
Spécifie l'ID renvoyé par l'appel correspondant à XtAppAddSignal.
proc
Spécifie la procédure qui doit être appelée lorsque le signal a été déclenché.

DESCRIPTION

La fonction XtAppAddSignal initie un mécanisme pour gérer les signaux dans le contexte des Intrinsics. Avant d'établir un gestionnaire de signaux dépendant du système d'exploitation, l'application peut appeler XtAppAddSignal et stocker l'id renvoyé dans un endroit accessible au gestionnaire de signaux.

Lors de la réception d'un signal du système d'exploitation, l'application peut appeler XtNoticeSignal en passant l'id renvoyé par l'appel à XtAppAddSignal.

XtNoticeSignal est la seule fonction des Intrinsics qui peut être appelée en toute sécurité depuis un gestionnaire de signaux. Si XtNoticeSignal est appelée plusieurs fois avant que les Intrinsics ne puissent invoquer le callback enregistré, le callback n'est appelé qu'une seule fois. Logiquement, les Intrinsics maintiennent un indicateur "en attente" pour chaque callback enregistré. Cet indicateur est initialement à False et est mis à True par XtNoticeSignal ; les Intrinsics invoquent le callback chaque fois que l'indicateur est à True, et l'indicateur est mis à False juste avant que le callback ne soit invoqué.

La fonction XtRemoveSignal est appelée pour supprimer le gestionnaire de signaux des Intrinsics spécifié. Le client doit désactiver la source du signal avant d'appeler XtRemoveSignal.
