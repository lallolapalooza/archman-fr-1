XtUnrealizeWidget(3) FONCTIONS XT XtUnrealizeWidget(3)

NOM

XtRealizeWidget, XtIsRealized, XtUnrealizeWidget - réaliser et dé-réaliser des widgets

SYNTAXE

#include <X11/Intrinsic.h>

void XtRealizeWidget(Widget w);

Boolean XtIsRealized(Widget w);

void XtUnrealizeWidget(Widget w);

ARGUMENTS

w
Spécifie le widget.

DESCRIPTION

Si le widget est déjà réalisé, XtRealizeWidget retourne simplement. Sinon, il effectue les opérations suivantes :

  • Lie tous les noms d'actions dans la table de traduction du widget aux procédures (voir Section 10.1.2).
  • Effectue un parcours post-ordre de l'arbre de widgets dont la racine est le widget spécifié et appelle la procédure change_managed de chaque widget composite qui a un ou plusieurs enfants gérés.
  • Construit une structure XSetWindowAttributes remplie avec des informations dérivées des champs de widget Core et appelle la procédure de réalisation du widget, qui ajoute tous les attributs spécifiques au widget et crée la fenêtre X.
  • Si le widget n'est pas une sous-classe de compositeWidgetClass, XtRealizeWidget retourne ; sinon, il continue et effectue les opérations suivantes :
  • Descend récursivement vers chacun des enfants gérés du widget et appelle les procédures de réalisation. Les widgets primitifs qui instancient des enfants sont responsables de la réalisation de ces enfants eux-mêmes.
  • Mappe toutes les fenêtres des enfants gérés dont mapped_when_managed est True. (Si un widget est géré mais mapped_when_managed est False, le widget se voit allouer un espace visuel mais n'est pas affiché. Certains semblent aimer cela pour indiquer certains états.)

Si le widget est un widget shell de premier niveau (c'est-à-dire qu'il n'a pas de parent), et mapped_when_managed est True, XtRealizeWidget mappe la fenêtre du widget.

La fonction XtIsRealized retourne True si le widget a été réalisé, c'est-à-dire si le widget a un ID de fenêtre X non nul.

Certaines procédures de widget (par exemple, set_values) peuvent souhaiter fonctionner différemment après que le widget a été réalisé.

La fonction XtUnrealizeWidget détruit les fenêtres d'un widget existant et de tous ses enfants (récursivement dans l'arbre des widgets). Pour recréer les fenêtres ultérieurement, appelez à nouveau XtRealizeWidget. Si le widget était géré, il sera automatiquement dé-géré avant que sa fenêtre ne soit libérée.
