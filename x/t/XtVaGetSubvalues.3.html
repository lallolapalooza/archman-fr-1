XtSetValues(3) FONCTIONS XT XtSetValues(3)

NOM

XtSetValues, XtVaSetValues, XtSetSubvalues, XtVaSetSubvalues, XtGetValues, XtVaGetValues, XtGetSubvalues, XtVaGetSubvalues - obtenir et définir les ressources des widgets

SYNTAXE

#include <X11/Intrinsic.h>

void XtSetValues(Widget w, ArgList args, Cardinal num_args);

void XtVaSetValues(Widget w, ...);

void XtSetSubvalues(XtPointer base, XtResourceList resources, Cardinal num_resources, ArgList args, Cardinal num_args);

void XtVaSetSubvalues(XtPointer base, XtResourceList resources, Cardinal num_resources, ...);

void XtGetValues(Widget w, ArgList args, Cardinal num_args);

void XtVaGetValues(Widget w, ...);

void XtGetSubvalues(XtPointer base, XtResourceList resources, Cardinal num_resources, ArgList args, Cardinal num_args);

void XtVaGetSubvalues(XtPointer base, XtResourceList resources, Cardinal num_resources, ...);

ARGUMENTS

args
Spécifie la liste d'arguments de paires nom/adresse qui contiennent le nom de la ressource et soit l'adresse dans laquelle la valeur de la ressource doit être stockée, soit leurs nouvelles valeurs.
base
Spécifie l'adresse de base de la structure de données de sous-partie où les ressources doivent être récupérées ou écrites.
num_args
Spécifie le nombre d'arguments dans la liste d'arguments.
resources
Spécifie la liste de ressources ou les valeurs non-widget.
num_resources
Spécifie le nombre de ressources dans la liste de ressources.
w
Spécifie le widget.
...
Spécifie la liste variable d'arguments de paires nom/adresse qui contiennent le nom de la ressource et soit l'adresse dans laquelle la valeur de la ressource doit être stockée, soit leurs nouvelles valeurs.

DESCRIPTION

La fonction XtSetValues commence par les ressources spécifiées pour les champs du widget Core et progresse dans la chaîne des sous-classes jusqu'au widget. À chaque étape, elle écrit la nouvelle valeur (si spécifiée par l'un des arguments) ou la valeur existante (si aucune nouvelle valeur n'est spécifiée) dans un nouvel enregistrement de données de widget. XtSetValues appelle ensuite les procédures set_values pour le widget dans l'ordre superclasse-à-sous-classe. Si le widget a des champs set_values_hook non-NULL, ceux-ci sont appelés immédiatement après la procédure set_values correspondante. Cette procédure permet aux sous-classes de définir des données non-widget pour XtSetValues.

Si le parent du widget est une sous-classe de constraintWidgetClass, XtSetValues met également à jour les contraintes du widget. Elle commence par les ressources de contrainte spécifiées pour constraintWidgetClass et progresse dans la chaîne des sous-classes jusqu'à la classe parente. À chaque étape, elle écrit la nouvelle valeur ou la valeur existante dans un nouvel enregistrement de contrainte. Elle appelle ensuite les procédures set_values de contrainte de constraintWidgetClass vers la classe parente. Les procédures set_values de contrainte sont appelées avec des arguments de widget, comme pour toutes les procédures set_values, et pas seulement les arguments de l'enregistrement de contrainte, de sorte qu'elles puissent apporter des ajustements aux valeurs souhaitées en se basant sur des informations complètes sur le widget.

XtSetValues détermine si une requête de géométrie est nécessaire en comparant le widget actuel au nouveau widget. Si des changements de géométrie sont requis, elle effectue la requête, et le gestionnaire de géométrie renvoie XtGeometryYes, XtGeometryAlmost, ou XtGeometryNo. Si XtGeometryYes, XtSetValues appelle la procédure de redimensionnement du widget. Si XtGeometryNo, XtSetValues réinitialise les champs de géométrie à leurs valeurs initiales. Si XtGeometryAlmost, XtSetValues appelle la procédure set_values_almost, qui détermine ce qui doit être fait et écrit de nouvelles valeurs pour les champs de géométrie dans le nouveau widget. XtSetValues répète ensuite ce processus, décidant une fois de plus si le gestionnaire de géométrie doit être appelé.

Enfin, si l'une des procédures set_values a renvoyé True, XtSetValues fait invoquer la procédure expose du widget en appelant la fonction Xlib XClearArea sur la fenêtre du widget.

La fonction XtSetSubvalues stocke les ressources dans la structure identifiée par base.

La fonction XtGetValues commence par les ressources spécifiées pour les champs du widget core et progresse dans la chaîne des sous-classes jusqu'au widget. Le champ valeur d'une liste d'arguments passée doit contenir l'adresse dans laquelle stocker la valeur de la ressource correspondante. Il est de la responsabilité de l'appelant d'allouer et de désallouer ce stockage en fonction de la taille du type de représentation de ressource utilisé dans le widget.

Si le parent du widget est une sous-classe de constraintWidgetClass, XtGetValues récupère ensuite les valeurs pour toutes les ressources de contrainte demandées. Elle commence par les ressources de contrainte spécifiées pour constraintWidgetClass et progresse vers la chaîne des sous-classes jusqu'aux ressources de contrainte du parent. Si la liste d'arguments contient un nom de ressource qui n'est pas trouvé dans l'une des listes de ressources recherchées, la valeur à l'adresse correspondante n'est pas modifiée. Enfin, si les procédures get_values_hook ne sont pas NULL, elles sont appelées dans l'ordre superclasse-à-sous-classe après que toutes les valeurs de ressources aient été récupérées par XtGetValues. Cela permet à une sous-classe de fournir des données de ressources non-widget à XtGetValues.

La fonction XtGetSubvalues obtient les valeurs de ressources de la structure identifiée par base.
