XtConvertAndStore(3) FONCTIONS XT XtConvertAndStore(3)

NOM

XtConvertAndStore, XtCallConverter - invoquer les convertisseurs de ressources

SYNTAXE

#include <X11/Intrinsic.h>

Boolean XtConvertAndStore(Widget widget, const char *from_type, XrmValuePtr from, const char *to_type, XrmValuePtr to_in_out);

Boolean XtCallConverter(Display* dpy, XtTypeConverter converter, XrmValuePtr args, Cardinal num_args, XrmValuePtr from, XrmValuePtr to_in_out, XtCacheRef* cache_ref_return);

ARGUMENTS

args
Spécifie la liste d'arguments contenant les arguments supplémentaires nécessaires pour effectuer la conversion, ou NULL.
converter
Spécifie la procédure de conversion à appeler.
from
Spécifie la valeur à convertir.
from_type
Spécifie le type source.
num_args
Spécifie le nombre d'arguments supplémentaires (souvent zéro).
to_type
Spécifie le type de destination.
to_in_out
Retourne la valeur convertie.
widget
Spécifie le widget à utiliser pour les arguments supplémentaires, s'il y en a, et la liste des callbacks de destruction.
dpy
Spécifie l'affichage auquel la conversion doit être associée.

DESCRIPTION

La fonction XtConvertAndStore recherche le convertisseur de type enregistré pour convertir from_type en to_type, calcule les arguments supplémentaires nécessaires, puis appelle XtCallConverter. (ou XtDirectConvert si un convertisseur de style ancien a été enregistré avec XtAddConverter ou XtAppAddConverter. ) avec les arguments from et to_in_out.

La fonction XtCallConverter recherche le convertisseur de type spécifié dans le contexte d'application associé à l'affichage et, si le convertisseur n'a pas été enregistré ou a été enregistré avec le type de cache XtCacheAll ou XtCacheByDisplay, recherche dans le cache de conversion pour voir si cette procédure de conversion a déjà été appelée avec les arguments de conversion spécifiés. Si c'est le cas, elle vérifie le statut de succès de l'appel précédent, et si la conversion a échoué, XtCallConverter retourne immédiatement False ; sinon, elle vérifie la taille spécifiée dans l'argument to et, si elle est supérieure ou égale à la taille stockée dans le cache, copie les informations stockées dans le cache dans l'emplacement spécifié par to->addr, stocke la taille du cache dans to->size, et retourne True. Si la taille spécifiée dans l'argument to est plus petite que la taille stockée dans le cache, XtCallConverter copie la taille du cache dans to->size et retourne False. Si le convertisseur a été enregistré avec le type de cache XtCacheNone ou si aucune valeur n'a été trouvée dans le cache de conversion, XtCallConverter appelle le convertisseur et, s'il n'a pas été enregistré avec le type de cache XtCacheNone, enregistre le résultat dans le cache. XtCallConverter retourne ensuite ce que le convertisseur a retourné.

Le champ cache_ref_return spécifie un espace alloué par l'appelant dans lequel une valeur opaque sera stockée. Si le convertisseur de type a été enregistré avec le modificateur XtCacheRefCount et si la valeur retournée dans cache_ref_return n'est pas NULL, alors l'appel doit stocker la valeur cache_ref_return afin de décrémenter le compteur de références lorsque la valeur convertie n'est plus nécessaire. L'argument cache_ref_return doit être NULL si l'appelant ne souhaite pas ou ne peut pas stocker la valeur.
