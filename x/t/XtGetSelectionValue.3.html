XtGetSelectionValue(3)

Paquet: libxt

Licences: MIT, HPND-sell-variant, SMLNJ, MIT-open-group, X11

XtGetSelectionValue(3) FONCTIONS XT XtGetSelectionValue(3)

NOM

XtGetSelectionValue, XtGetSelectionValues - obtenir les valeurs de sélection

SYNTAXE

#include <X11/Intrinsic.h>

void XtGetSelectionValue(Widget w, Atom selection, Atom target, XtSelectionCallbackProc callback, XtPointer client_data, Time time);

void XtGetSelectionValues(Widget w, Atom selection, Atom *targets, int count, XtSelectionCallbackProc callback, XtPointer *client_data, Time time);

ARGUMENTS

callback
Spécifie la procédure de rappel qui doit être appelée lorsque la valeur de sélection a été obtenue.
client_data
Spécifie l'argument qui doit être passé à la procédure spécifiée lorsqu'elle est appelée.
client_data
Spécifie les données client (une pour chaque type de cible) qui sont passées à la procédure de rappel lorsqu'elle est appelée pour cette cible.
count
Spécifie la longueur des listes de cibles et de données client.
selection
Spécifie la sélection particulière désirée (c'est-à-dire primaire ou secondaire).
target
Spécifie le type des informations nécessaires sur la sélection.
targets
Spécifie les types d'informations nécessaires sur la sélection.
time
Spécifie l'horodatage qui indique quand la valeur de sélection est désirée.
w
Spécifie le widget qui fait la requête.

DESCRIPTION

La fonction XtGetSelectionValue demande la valeur de la sélection qui a été convertie au type de cible. Le rappel spécifié sera appelé un certain temps après l'appel à XtGetSelectionValue ; en fait, il peut être appelé avant ou après le retour de XtGetSelectionValue.

La fonction XtGetSelectionValues est similaire à XtGetSelectionValue sauf qu'elle prend une liste de types de cibles et une liste de données client et obtient la valeur actuelle de la sélection convertie à chacun des cibles. L'effet est comme si chaque cible était spécifiée dans un appel séparé à XtGetSelectionValue. Le rappel est appelé une fois avec les données client correspondantes pour chaque cible. XtGetSelectionValues garantit que toutes les conversions utiliseront la même valeur de sélection car la propriété de la sélection ne peut pas changer au milieu de la liste, comme ce serait le cas en appelant XtGetSelectionValue de manière répétée.
