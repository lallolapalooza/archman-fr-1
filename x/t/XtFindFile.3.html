NOM

XtFindFile - recherche un fichier en utilisant des substitutions dans la liste des chemins

SYNTAXE

#include <X11/Intrinsic.h>

char * XtFindFile(const char *chemin, Substitution substitutions, Cardinal nb_substitutions, XtFilePredicate predicat);

ARGUMENTS

chemin
Spécifie un chemin de noms de fichiers, incluant des caractères de substitution.
substitutions
Spécifie une liste de substitutions à effectuer dans un chemin.
nb_substitutions
Spécifie le nombre de substitutions passées.
predicat
Spécifie une procédure à appeler pour juger un nom de fichier potentiel, ou NULL.

DESCRIPTION

Le paramètre chemin spécifie une chaîne de caractères qui consiste en une série de noms de fichiers potentiels délimités par des deux-points. Dans chaque nom, le caractère pourcentage spécifie une substitution de chaîne sélectionnée par le caractère suivant. La séquence de caractères “%:” spécifie un deux-points intégré qui n'est pas un délimiteur ; la séquence est remplacée par un seul deux-points. La séquence de caractères “%%” spécifie un caractère pourcentage qui n'introduit pas de substitution ; la séquence est remplacée par un seul caractère pourcentage. Si un caractère pourcentage est suivi par un autre caractère, XtFindFile recherche dans les substitutions spécifiées ce caractère dans le champ correspondance et si trouvé, remplace le pourcentage et les caractères de correspondance par la chaîne dans le champ de substitution correspondant. Une entrée de champ substitution de NULL est équivalente à un pointeur vers une chaîne vide. Si le système d'exploitation n'interprète pas plusieurs séparateurs de noms intégrés dans le chemin (c'est-à-dire “/” en POSIX) de la même manière qu'un seul séparateur, XtFindFile réduira les séparateurs multiples en un seul après avoir effectué toutes les substitutions de chaînes. Sauf pour la réduction des séparateurs intégrés, le contenu des substitutions de chaînes n'est pas interprété par XtFindFile et peut donc contenir des caractères dépendants du système d'exploitation, y compris des séparateurs de noms supplémentaires. Chaque chaîne résultante est passée à la procédure prédicat jusqu'à ce qu'une chaîne soit trouvée pour laquelle la procédure renvoie True ; cette chaîne est la valeur de retour pour XtFindFile. Si aucune chaîne ne produit un retour True du prédicat, XtFindFile renvoie NULL.

Si le paramètre predicat est NULL, une procédure interne qui vérifie si le fichier existe, est lisible et n'est pas un répertoire sera utilisée.

Il incombe à l'appelant de libérer la chaîne renvoyée en utilisant XtFree lorsqu'elle n'est plus nécessaire.
