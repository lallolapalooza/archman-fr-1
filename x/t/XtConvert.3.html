XtConvert(3) FONCTIONS DE COMPATIBILITÉ XT XtConvert(3)

NOM

XtConvert, XtDirectConvert - invoquer les convertisseurs de ressources

SYNTAXE

#include <X11/Intrinsic.h>

void XtConvert(Widget w, const char *from_type, XrmValuePtr from, const char *to_type, XrmValuePtr to_return);

void XtDirectConvert(XtConverter converter, XrmValuePtr args, Cardinal num_args, XrmValuePtr from, XrmValuePtr to_return);

ARGUMENTS

args
Spécifie la liste d'arguments qui contient les arguments supplémentaires nécessaires pour effectuer la conversion (souvent NULL).
converter
Spécifie la procédure de conversion à appeler.
from
Spécifie la valeur à convertir.
from_type
Spécifie le type source.
num_args
Spécifie le nombre d'arguments supplémentaires (souvent zéro).
to_type
Spécifie le type destination.
to_return
Retourne la valeur convertie.
w
Spécifie le widget à utiliser pour les arguments supplémentaires (si nécessaire).

DESCRIPTION

La fonction XtConvert recherche le convertisseur de type enregistré pour convertir from_type en to_type, calcule les arguments supplémentaires nécessaires, puis appelle XtDirectConvert. XtConvert a été remplacé par XtConvertAndStore.

La fonction XtDirectConvert recherche dans le cache du convertisseur si cette procédure de conversion a déjà été appelée avec les arguments spécifiés. Si c'est le cas, elle renvoie un descripteur pour les informations stockées dans le cache ; sinon, elle appelle le convertisseur et enregistre le résultat dans le cache.

Avant d'appeler le convertisseur spécifié, XtDirectConvert initialise la taille de la valeur de retour à zéro et l'adresse de la valeur de retour à NULL. Pour déterminer si la conversion a réussi, le client doit vérifier si to_return.address n'est pas NULL. XtDirectConvert a été remplacé par XtCallConverter.
