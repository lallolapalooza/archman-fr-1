XtResolvePathname(3) FONCTIONS XT XtResolvePathname(3)

NOM

XtResolvePathname - rechercher un fichier en utilisant la substitution standard

SYNTAXE

#include <X11/Intrinsic.h>

char * XtResolvePathname(Display *display, const char *type, const char *filename, const char *suffix, const char *path, Substitution substitutions, Cardinal num_substitutions, XtFilePredicate predicate);

ARGUMENTS

display
Spécifie l'affichage à utiliser pour trouver la langue des substitutions linguistiques.
type

filename

suffix
Spécifient les valeurs à substituer dans le chemin.
path
Spécifie la liste des spécifications de fichiers, ou NULL.
substitutions
Spécifie une liste de substitutions supplémentaires à faire dans le chemin, ou NULL.
num_substitutions
Spécifie le nombre d'entrées dans substitutions.
predicate
Spécifie une procédure appelée pour juger chaque nom de fichier potentiel, ou NULL.

DESCRIPTION

Les substitutions spécifiées par XtResolvePathname sont déterminées à partir de la valeur de la chaîne de langue récupérée par XtDisplayInitialize pour l'affichage spécifié. Pour définir la langue pour toutes les applications, spécifiez “*xnlLanguage: lang” dans la base de données des ressources. Le format et le contenu de la chaîne de langue sont définis par l'implémentation. Une syntaxe suggérée est de composer la chaîne de langue de trois parties : une partie 'langue', une partie 'territoire' et une partie 'codeset'. La manière dont cette composition est réalisée est définie par l'implémentation et les Intrinsics n'interprètent pas les parties autrement que pour les utiliser dans les substitutions, comme décrit ci-dessous.

XtResolvePathname appelle XtFindFile avec les substitutions suivantes en plus de celles passées par l'appelant et renvoie la valeur renvoyée par XtFindFile:

%N
La valeur du paramètre filename, ou le nom de classe de l'application si filename est NULL.
%T
La valeur du paramètre type.
%S
La valeur du paramètre suffix.
%L
La chaîne de langue associée à l'affichage spécifié.
%l
La partie langue de la chaîne de langue de l'affichage.
%t
La partie territoire de la chaîne de langue de l'affichage.
%c
La partie codeset de la chaîne de langue de l'affichage.
%C
La chaîne de personnalisation récupérée de la base de données des ressources associée à display.
%D
La valeur du chemin par défaut spécifique à l'implémentation.

Si un chemin est passé à XtResolvePathname, il sera passé à XtFindFile. Si l'argument path est NULL, la valeur de la variable d'environnement XFILESEARCHPATH sera passée à XtFindFile. Si XFILESEARCHPATH n'est pas définie, un chemin par défaut spécifique à l'implémentation sera utilisé, contenant au moins 6 entrées. Ces entrées doivent contenir les substitutions suivantes :

1.	%C, %N, %S, %T, %L	ou	%C, %N, %S, %T, %l, %t, %c
2.	%C, %N, %S, %T, %l
3.	%C, %N, %S, %T
4.	%N, %S, %T, %L	ou	%N, %S, %T, %l, %t, %c
5.	%N, %S, %T, %l
6.	%N, %S, %T

L'ordre de ces six entrées dans le chemin doit être celui donné ci-dessus. L'ordre et l'utilisation des substitutions dans une entrée donnée dépendent de l'implémentation. Si le chemin commence par deux-points, il sera précédé par %N%S. Si le chemin inclut deux deux-points adjacents, %N%S sera inséré entre eux.

Le paramètre type est destiné à être une catégorie de fichiers, généralement traduite en un répertoire dans le chemin du fichier. Des valeurs possibles pourraient inclure 'app-defaults', 'help', et 'bitmap'.

Le paramètre suffix est destiné à être ajouté au nom de fichier. Des valeurs possibles pourraient inclure '.txt', '.dat', et '.bm'.

Une valeur suggérée pour le chemin par défaut sur les systèmes basés sur POSIX est

/usr/lib/X11/%L/%T/%N%C%S:/usr/lib/X11/%l/%T/%N%C%S:\
/usr/lib/X11/%T/%N%C%S:/usr/lib/X11/%L/%T/%N%S:\
/usr/lib/X11/%l/%T/%N%S:/usr/lib/X11/%T/%N%S

En utilisant cet exemple, si l'utilisateur a spécifié une langue, elle sera utilisée comme sous-répertoire de /usr/lib/X11 qui sera recherché pour d'autres fichiers. Si le fichier souhaité n'y est pas trouvé, la recherche sera tentée à nouveau en utilisant uniquement la partie langue de la spécification. Si le fichier n'y est pas, il sera recherché dans /usr/lib/X11. Le paramètre type est utilisé comme sous-répertoire du répertoire de langue ou de /usr/lib/X11, et suffix est ajouté au nom de fichier.

La substitution %D permet l'ajout d'éléments de chemin au chemin par défaut spécifique à l'implémentation, généralement pour permettre la recherche de répertoires supplémentaires sans empêcher la découverte des ressources dans les répertoires système. Par exemple, un utilisateur installant des fichiers de ressources sous un répertoire appelé 'ourdir' pourrait définir XFILESEARCHPATH à

%D:ourdir/%T/%N%C:ourdir/%T/%N

La chaîne de personnalisation est obtenue en interrogeant la base de données des ressources actuellement associée à l'affichage (la base de données renvoyée par XrmGetDatabase) pour la ressource nom_application.customization, classe classe_application.Customization où nom_application et classe_application sont les valeurs renvoyées par XtGetApplicationNameAndClass. Si aucune valeur n'est spécifiée dans la base de données, la chaîne vide est utilisée.

Il incombe à l'appelant de libérer la chaîne retournée en utilisant XtFree lorsqu'elle n'est plus nécessaire.
