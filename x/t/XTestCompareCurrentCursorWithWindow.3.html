DESCRIPTION

Cette extension est un ensemble minimal de fonctions client et serveur nécessaires pour tester complètement le serveur X11 sans aucune intervention de l'utilisateur. Cette extension n'est pas destinée à supporter la journalisation et la relecture générales des actions de l'utilisateur.

Les fonctions fournies par cette extension se divisent en deux groupes :

Opérations Client

Ces routines manipulent le comportement caché du client. L'implémentation réelle dépendra des détails de la liaison linguistique et du degré de mise en mémoire tampon des requêtes, de la mise en cache des GContext, etc., fournis. Dans la liaison C, des routines sont fournies pour accéder aux internes de deux structures de données opaques — les GC et les Visuals — et pour rejeter toutes les requêtes en attente dans le tampon de sortie d'une connexion. Les détails exacts peuvent différer pour d'autres liaisons linguistiques.

Requêtes Serveur

La première de ces requêtes est similaire à celle fournie dans la plupart des extensions : elle permet à un client de spécifier un numéro de version majeure et mineure au serveur, et au serveur de répondre avec ses propres numéros de version majeure et mineure. Les deux requêtes restantes permettent ce qui suit :
•Accès à une ressource serveur par ailleurs en écriture seule : le curseur associé à une fenêtre donnée
•Peut-être le plus important, synthèse limitée des événements des périphériques d'entrée, presque comme si un utilisateur coopératif avait déplacé le dispositif de pointage ou appuyé sur une touche ou un bouton.

Toutes les fonctions et procédures d'extension XTEST, ainsi que tous les constantes manifestes et macros, commenceront par la chaîne XTest. Toutes les opérations sont classées comme serveur/client (Serveur) ou client uniquement (Client).

XTestQueryExtension renvoie True si l'affichage spécifié prend en charge l'extension XTEST, sinon False. Comme aucune erreur ou événement n'est défini pour cette version de l'extension, les valeurs renvoyées ici ne sont pas définies (ni utiles). Si l'extension est prise en charge, *major_version et *minor_version sont définis sur les numéros de version majeure et mineure de l'extension pris en charge par l'affichage. Si l'extension n'est pas prise en charge, la requête est ignorée et zéro est renvoyé.

XTestCompareCurrentCursorWithWindow(3)

NAME

XTestCompareCurrentCursorWithWindow, XTestDiscard - compare cursor position with window.

SYNOPSIS

#include <X11/extensions/XTest.h>

Bool
XTestCompareCurrentCursorWithWindow(Display *dpy, Window w, int x, int y, int prio);

void
XTestDiscard(Display *dpy);

DESCRIPTION

The XTest extension provides routines to simulate keyboard and pointer input.

XTestCompareCurrentCursorWithWindow compares the current cursor position with the specified window coordinates.

XTestDiscard discards all buffered events.

Note that the XTEST extension is not a general purpose testing tool. It is intended for use by window managers to correctly handle input when switching focus or on other occasions when the input state is uncertain. Misuse of this extension may lead to an unstable X server or client.

The priority argument is currently unused and should be set to 0. If the cursor is not within the specified window, then XTestCompareCurrentCursorWithWindow returns False.

RETURN VALUES

All routines that have return type Status will return nonzero for success and zero for failure. Even if the XTEST extension is supported, the server may withdraw such facilities arbitrarily; in which case they will subsequently return zero.

L'extension XTest fournit des routines pour simuler des entrées au clavier et à la souris.

XTestCompareCurrentCursorWithWindow compare la position actuelle du curseur avec les coordonnées spécifiées de la fenêtre.

XTestDiscard rejette tous les événements mis en mémoire tampon.

Notez que l'extension XTEST n'est pas un outil de test à usage général. Elle est destinée à être utilisée par les gestionnaires de fenêtres pour gérer correctement les entrées lors du changement de focus ou lors d'autres occasions où l'état des entrées est incertain. Une mauvaise utilisation de cette extension peut entraîner une instabilité du serveur ou du client X.

L'argument de priorité n'est actuellement pas utilisé et doit être défini sur 0. Si le curseur n'est pas dans la fenêtre spécifiée, alors XTestCompareCurrentCursorWithWindow renvoie False.

VALEURS DE RETOUR

Toutes les routines dont le type de retour est Status renverront une valeur non nulle en cas de succès et zéro en cas d'échec. Même si l'extension XTEST est prise en charge, le serveur peut retirer arbitrairement ces facilités ; dans ce cas, elles renverront ensuite zéro.
