XtError(3) FONCTIONS DE COMPATIBILITÉ XT XtError(3)

NOM

XtError, XtSetErrorHandler, XtSetWarningHandler, XtWarning - gestionnaires d'erreurs de bas niveau

SYNTAXE

#include <X11/Intrinsic.h>

_X_NORETURN void XtError(const char *message);

void XtSetErrorHandler(_X_NORETURN XtErrorHandler handler);

void XtSetWarningHandler(XtErrorHandler handler);

void XtWarning(const char *message);

ARGUMENTS

message
Spécifie le message d'erreur non fatal à signaler.
handler
Spécifie la nouvelle procédure de gestion des erreurs fatales, qui ne doit pas retourner, ou la procédure de gestion des erreurs non fatales, qui retourne généralement.
message
Spécifie le message à signaler.

DESCRIPTION

La fonction XtError a été remplacée par XtAppError.

La fonction XtSetErrorHandler a été remplacée par XtAppSetErrorHandler.

La fonction XtSetWarningHandler a été remplacée par XtAppSetWarningHandler.

La fonction XtWarning a été remplacée par XtAppWarning.
