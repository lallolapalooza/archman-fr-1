XtVaGetApplicationResources(3)

Paquet: libxt

XtGetApplicationResources(3) FONCTIONS XT XtGetApplicationResources(3)

NOM

XtGetApplicationResources, XtVaGetApplicationResources - obtenir les ressources de l'application

SYNTAXE

#include <X11/Intrinsic.h>

void XtGetApplicationResources(Widget w, XtPointer base, XtResourceList resources, Cardinal num_resources, ArgList args, Cardinal num_args);

void XtVaGetApplicationResources(Widget w, XtPointer base, XtResourceList resources, Cardinal num_resources, ...);

ARGUMENTS

args
Spécifie la liste d'arguments pour remplacer les ressources obtenues de la base de données des ressources.
base
Spécifie l'adresse de base de la structure de données de sous-partie où les ressources doivent être écrites.
num_args
Spécifie le nombre d'arguments dans la liste d'arguments.
num_resources
Spécifie le nombre de ressources dans la liste de ressources.
resources
Spécifie la liste de ressources pour la sous-partie.
w
Spécifie le widget qui demande des ressources pour une sous-partie ou qui identifie la base de données des ressources à rechercher.
...
Spécifie les arguments variables pour remplacer les ressources obtenues de la base de données des ressources.

DESCRIPTION

La fonction XtGetApplicationResources utilise d'abord le widget passé, qui est généralement un shell d'application, pour construire une liste de noms et de classes de ressources. Ensuite, elle récupère les ressources de la liste d'arguments, de la base de données des ressources ou des valeurs par défaut de la liste de ressources. Après avoir ajouté la base à chaque adresse, XtGetApplicationResources copie les ressources dans l'adresse donnée dans la liste de ressources. Si args est NULL, num_args doit être zéro. Cependant, si num_args est zéro, la liste d'arguments n'est pas référencée. La manière portable de spécifier les ressources de l'application est de les déclarer comme membres d'une structure et de passer l'adresse de la structure comme argument de base.
