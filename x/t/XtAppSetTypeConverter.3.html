XtAppSetTypeConverter(3)

Paquet: libxt

Licences: MIT, HPND-sell-variant, SMLNJ, MIT-open-group, X11

XtAppSetTypeConverter(3) FONCTIONS XT XtAppSetTypeConverter(3)

NOM

XtAppSetTypeConverter, XtSetTypeConverter - enregistrer un convertisseur de ressources

SYNTAXE

#include <X11/Intrinsic.h>

void XtAppSetTypeConverter(XtAppContext app_context, const char *from_type, const char * to_type, XtTypeConverter converter, XtConvertArgList convert_args, Cardinal num_args, XtCacheType cache_type, XtDestructor destructor);

void XtSetTypeConverter(const char *from_type, const char *to_type, XtTypeConverter converter, XtConvertArgList convert_args, Cardinal num_args, XtCacheType cache_type, XtDestructor destructor);

ARGUMENTS

app_context
Spécifie le contexte d'application.
converter
Spécifie la procédure de conversion de type.
convert_args
Spécifie comment calculer les arguments supplémentaires du convertisseur ou NULL.
from_type
Spécifie le type source.
num_args
Spécifie le nombre d'arguments supplémentaires pour le convertisseur ou zéro.
to_type
Spécifie le type de destination.
cache_type
Spécifie si les ressources produites par ce convertisseur sont partageables ou spécifiques à l'affichage et quand elles doivent être libérées.
destructor
Spécifie une procédure de destruction pour les ressources produites par cette conversion, ou NULL si aucune action supplémentaire n'est requise pour désallouer les ressources produites par le convertisseur.

DESCRIPTION

XtSetTypeConverter enregistre le convertisseur de type et le destructeur spécifiés dans tous les contextes d'application créés par le processus appelant, y compris tout contexte d'application futur qui pourrait être créé. XtAppSetTypeConverter enregistre le convertisseur de type spécifié dans le seul contexte d'application spécifié. Si les mêmes from_type et to_type sont spécifiés dans plusieurs appels à l'une ou l'autre fonction, le dernier appel remplace les précédents.
