XtHooksOfDisplay(3) FONCTIONS XT XtHooksOfDisplay(3)

NOM

XtHooksOfDisplay - points d'accès aux agents externes

SYNTAXE

#include <X11/Intrinsic.h>

Widget XtHooksOfDisplay(Display* display);

ARGUMENTS

display
Spécifie l'affichage désiré.

DESCRIPTION

La classe de cet objet est une sous-classe privée, dépendante de l'implémentation, de Object. L'objet hook n'a pas de parent. Les ressources de cet objet sont les listes de callbacks pour les hooks et les ressources en lecture seule pour obtenir une liste de fenêtres sans parent.
