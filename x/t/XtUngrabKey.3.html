XtUngrabKey(3)

Paquet: libxt

Licences: MIT, HPND-sell-variant, SMLNJ, MIT-open-group, X11

XtGrabKey(3) FONCTIONS XT XtGrabKey(3)

NOM

XtGrabKey, XtUngrabKey, XtGrabKeyboard, XtUngrabKeyboard, XtGrabButton, XtUngrabButton, XtGrabPointer, XtUngrabPointer - gérer les saisies (grabs)

SYNTAXE

#include <X11/Intrinsic.h>

void XtGrabKey(Widget widget, KeyCode keycode, Modifiers modifiers, Boolean owner_events, int pointer_mode, int keyboard_mode);

void XtUngrabKey(Widget widget, KeyCode keycode, Modifiers modifiers);

int XtGrabKeyboard(Widget widget, Boolean owner_events, int pointer_mode, int keyboard_mode, Time time);

void XtUngrabKeyboard(Widget widget, Time time);

void XtGrabButton(Widget widget, int button, Modifiers modifiers, Boolean owner_events, unsigned int event_mask, int pointer_mode, int keyboard_mode, Window confine_to, Cursor cursor);

void XtUngrabButton(Widget widget, unsigned button, Modifiers modifiers);

int XtGrabPointer(Widget widget, Boolean owner_events, unsigned int event_mask, int pointer_mode, int keyboard_mode, Window confine_to, Cursor cursor, Time time);

void XtUngrabPointer(Widget widget, Time time);

ARGUMENTS

widget
Spécifie le widget dans la fenêtre duquel la saisie aura lieu. Doit être de la classe Core ou d'une sous-classe de celle-ci.
keycode

modifiers

owner_events

pointer_mode

keyboard_mode

time

button

confine_to

cursor
Spécifie les arguments pour l'appel de fonction Xlib associé.

DESCRIPTION

XtGrabKey appelle XGrabKey en spécifiant la fenêtre du widget comme fenêtre de saisie si le widget est réalisé. Les autres arguments sont identiques à ceux de XGrabKey. Si le widget n'est pas réalisé, ou s'il est désintégré ultérieurement, l'appel à XGrabKey sera effectué (à nouveau) lorsque le widget sera réalisé et sa fenêtre mappée. À l'avenir, si XtDispatchEvent est appelé avec un événement KeyPress correspondant au keycode et aux modificateurs spécifiés (qui peuvent être AnyKey ou AnyModifier, respectivement) pour la fenêtre du widget, les Intrinsics appelleront XtUngrabKeyboard avec le timestamp de l'événement KeyPress si l'une des conditions suivantes est vraie :

  • Il y a une cascade modale et le widget ne fait pas partie du sous-ensemble actif de la cascade et le clavier n'a pas été précédemment saisi, ou
  • XFilterEvent retourne True.

XtUngrabKey appelle XUngrabKey en spécifiant la fenêtre du widget comme fenêtre de libération de saisie si le widget est réalisé. Les arguments restants sont identiques à ceux de XUngrabKey. Si le widget n'est pas réalisé, XtUngrabKey supprime une requête XtGrabKey différée, le cas échéant, pour le widget, le keycode et les modificateurs spécifiés.

Si le widget spécifié est réalisé, XtGrabKeyboard appelle XGrabKeyboard en spécifiant la fenêtre du widget comme fenêtre de saisie. Les arguments restants et la valeur de retour sont identiques à ceux de XGrabKeyboard. Si le widget n'est pas réalisé, XtGrabKeyboard retourne immédiatement GrabNotViewable. Aucune libération future n'est impliquée par XtGrabKeyboard.

XtUngrabKeyboard appelle XUngrabKeyboard avec le temps spécifié.

XtGrabButton appelle XGrabButton en spécifiant la fenêtre du widget comme fenêtre de saisie si le widget est réalisé. Les arguments restants sont identiques à ceux de XGrabButton. Si le widget n'est pas réalisé, ou s'il est désintégré ultérieurement, l'appel à XGrabButton sera effectué (à nouveau) lorsque le widget sera réalisé et sa fenêtre mappée. À l'avenir, si XtDispatchEvent est appelé avec un événement ButtonPress correspondant au bouton et aux modificateurs spécifiés (qui peuvent être AnyButton ou AnyModifier, respectivement) pour la fenêtre du widget, les Intrinsics appelleront XtUngrabPointer avec le timestamp de l'événement ButtonPress si l'une des conditions suivantes est vraie :

  • Il y a une cascade modale et le widget ne fait pas partie du sous-ensemble actif de la cascade et le pointeur n'a pas été précédemment saisi, ou
  • XFilterEvent retourne True.

XtUngrabButton appelle XUngrabButton en spécifiant la fenêtre du widget comme fenêtre de libération de saisie si le widget est réalisé. Les arguments restants sont identiques à ceux de XUngrabButton. Si le widget n'est pas réalisé, XtUngrabButton supprime une requête XtGrabButton différée, le cas échéant, pour le widget, le bouton et les modificateurs spécifiés.

XtGrabPointer appelle XGrabPointer en spécifiant la fenêtre du widget comme fenêtre de saisie. Les arguments restants et la valeur de retour sont identiques à ceux de XGrabPointer. Si le widget n'est pas réalisé, XtGrabPointer retourne immédiatement GrabNotViewable. Aucune libération future n'est impliquée par XtGrabPointer.

XtUngrabPointer appelle XUngrabPointer avec le temps spécifié.
