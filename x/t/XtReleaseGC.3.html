XtGetGC(3) FONCTIONS XT XtGetGC(3)

NOM

XtGetGC, XtReleaseGC - obtenir et détruire un GC partageable

SYNTAXE

#include <X11/Intrinsic.h>

GC XtGetGC(Widget w, XtGCMask value_mask, XGCValues *values);

void XtReleaseGC(Widget w, GC gc);

ARGUMENTS

gc
Spécifie le GC à désallouer.
values
Spécifie les valeurs réelles pour ce GC.
value_mask
Spécifie quels champs des valeurs sont indiqués.
w
Spécifie le widget.

DESCRIPTION

La fonction XtGetGC renvoie un GC partageable et en lecture seule. Les paramètres de cette fonction sont les mêmes que ceux de XCreateGC sauf qu'un widget est passé à la place d'un affichage. XtGetGC ne partage que les GCs dans lesquels toutes les valeurs du GC retourné par XCreateGC sont identiques. En particulier, il n'utilise pas le value_mask fourni pour déterminer quels champs du GC un widget considère comme pertinents. Le value_mask est utilisé uniquement pour indiquer au serveur quels champs doivent être remplis avec les données du widget et lesquels il doit remplir avec des valeurs par défaut. Pour plus d'informations sur value_mask et values, voir XCreateGC dans le Xlib - Interface du langage C X.

La fonction XtReleaseGC désalloue le GC partagé spécifié.
