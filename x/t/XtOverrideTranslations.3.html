XtOverrideTranslations(3)

Paquet: libxt

Licences: MIT, HPND-sell-variant, SMLNJ, MIT-open-group, X11

XtParseTranslationTable(3) FONCTIONS XT XtParseTranslationTable(3)

NOM

XtParseTranslationTable, XtAugmentTranslations, XtOverrideTranslations, XtUninstallTranslations - gérer les tables de traduction

SYNTAXE

#include <X11/Intrinsic.h>

XtTranslations XtParseTranslationTable(const char *table);

void XtAugmentTranslations(Widget w, XtTranslations translations);

void XtOverrideTranslations(Widget w, XtTranslations translations);

void XtUninstallTranslations(Widget w);

ARGUMENTS

table
Spécifie la table de traduction à compiler.
translations
Spécifie la table de traduction compilée à fusionner (ne doit pas être NULL).
w
Spécifie le widget dans lequel les nouvelles traductions doivent être fusionnées ou supprimées.

DESCRIPTION

La fonction XtParseTranslationTable compile la table de traduction dans la représentation interne opaque de type XtTranslations. Notez que si une table de traduction vide est nécessaire à quelque fin que ce soit, on peut l'obtenir en appelant XtParseTranslationTable et en lui passant une chaîne vide.

La fonction XtAugmentTranslations fusionne de manière non destructive les nouvelles traductions dans les traductions existantes du widget. Si les nouvelles traductions contiennent un événement ou une séquence d'événements qui existe déjà dans les traductions du widget, la nouvelle traduction est ignorée.

La fonction XtOverrideTranslations fusionne de manière destructive les nouvelles traductions dans les traductions existantes du widget. Si les nouvelles traductions contiennent un événement ou une séquence d'événements qui existe déjà dans les traductions du widget, la nouvelle traduction est fusionnée et remplace la traduction du widget.

Pour remplacer complètement les traductions d'un widget, utilisez XtSetValues sur la ressource XtNtranslations et spécifiez une table de traduction compilée comme valeur.

La fonction XtUninstallTranslations supprime toute la table de traduction du widget.
