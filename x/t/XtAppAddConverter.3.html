XtAppAddConverter(3) FONCTIONS DE COMPATIBILITÉ XT XtAppAddConverter(3)

NOM

XtAppAddConverter, XtAddConverter - enregistrer un convertisseur de ressources

SYNTAXE

#include <X11/Intrinsic.h>

void XtAppAddConverter(XtAppContext app_context, const char *from_type, const char *to_type, XtConverter converter, XtConvertArgList convert_args, Cardinal num_args);

void XtAddConverter(const char *from_type, const char *to_type, XtConverter converter, XtConvertArgList convert_args, Cardinal num_args);

ARGUMENTS

app_context
Spécifie le contexte de l'application.
converter
Spécifie la procédure de conversion de type.
convert_args
Spécifie comment calculer les arguments supplémentaires du convertisseur ou NULL.
from_type
Spécifie le type source.
num_args
Spécifie le nombre d'arguments supplémentaires pour le convertisseur ou zéro.
to_type
Spécifie le type de destination.

DESCRIPTION

XtAppAddConverter est équivalent en fonction à XtAppSetTypeConverter avec cache_type égal à XtCacheAll pour les convertisseurs de type anciens formats. Il a été remplacé par XtAppSetTypeConverter.

XtAddConverter est équivalent en fonction à XtSetTypeConverter avec cache_type égal à XtCacheAll pour les convertisseurs de type anciens formats. Il a été remplacé par XtSetTypeConverter.
