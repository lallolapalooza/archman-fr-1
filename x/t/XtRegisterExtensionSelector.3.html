XtInsertEventTypeHandler(3) FONCTIONS XT XtInsertEventTypeHandler(3)

NOM

XtInsertEventTypeHandler, XtRemoveEventTypeHandler, XtRegisterExtensionSelector, XtSetEventDispatcher, XtDispatchEventToWidget - gestion des événements d'extension

SYNTAXE

#include <X11/Intrinsic.h>

void XtInsertEventTypeHandler(Widget widget, int event_type, XtPointer select_data, XtEventHandler proc, XtPointer client_data, XtListPosition position);

void XtRemoveEventTypeHandler(Widget widget, int event_type, XtPointer select_data, XtEventHandler proc, XtPointer client_data);

void XtRegisterExtensionSelector(Display* display, int min_event_type, int max_event_type, XtExtensionSelectProc proc, XtPointer client_data);

XtEventDispatchProc XtSetEventDispatcher(Display* display, int event_type, XtEventDispatchProc proc);

Boolean XtDispatchEventToWidget(Widget widget, XEvent* event);

ARGUMENTS

widget
Spécifie le widget pour ce gestionnaire d'événements. Doit être de classe Core ou de l'une de ses sous-classes.
event_type
Spécifie le type d'événement.
select_data
Spécifie les données utilisées pour sélectionner ou désélectionner les événements du serveur.
proc
Spécifie la procédure.
client_data
Spécifie des données supplémentaires à passer au gestionnaire d'événements.
position
Spécifie quand le gestionnaire d'événements doit être appelé par rapport à d'autres gestionnaires précédemment enregistrés.
display
Spécifie l'affichage.
min_event_type, max_event_type
Spécifie la plage des types d'événements pour cette extension.
event
Spécifie un pointeur vers l'événement à distribuer.

DESCRIPTION

La fonction XtInsertEventTypeHandler enregistre une procédure auprès du mécanisme de distribution qui doit être appelée lorsqu'un événement correspondant à event_type spécifié est distribué au widget spécifié.

Si event_type est l'un des événements du protocole X de base, select_data doit être un pointeur vers une valeur de type EventMask, indiquant le masque d'événements à utiliser pour sélectionner l'événement souhaité. Ce masque d'événements sera inclus dans la valeur renvoyée par XtBuildEventMask. Si le widget est réalisé, XtInsertEventTypeHandler appelle XSelectInput si nécessaire. Spécifier NULL pour select_data est équivalent à spécifier un pointeur vers un masque d'événements contenant 0. Ceci est similaire à la fonction XtInsertRawEventHandler.

Si event_type spécifie un type d'événement d'extension, les sémantiques des données pointées par select_data sont définies par le sélecteur d'extension enregistré pour le type d'événement spécifié.

Dans les deux cas, les Intrinsics ne sont pas obligés de copier les données pointées par select_data, le déclarant doit donc s'assurer qu'elles restent valides tant que le gestionnaire d'événements reste enregistré avec cette valeur de select_data.

L'argument position permet au client de contrôler l'ordre d'invocation des gestionnaires d'événements enregistrés pour le même type d'événement. Si le client ne se soucie pas de l'ordre, il doit normalement spécifier XtListTail, qui enregistre ce gestionnaire d'événements après tous les gestionnaires précédemment enregistrés pour ce type d'événement.

La fonction XtRemoveEventTypeHandler désenregistre un gestionnaire d'événements enregistré avec XtInsertEventTypeHandler pour le type d'événement spécifié. La requête est ignorée si client_data ne correspond pas à la valeur donnée lors de l'enregistrement du gestionnaire.

Si event_type spécifie l'un des événements du protocole X de base, select_data doit être un pointeur vers une valeur de type EventMask, indiquant le masque à utiliser pour désélectionner l'événement approprié. Si le widget est réalisé, XtRemoveEventTypeHandler appelle XSelectInput si nécessaire. Spécifier NULL pour select_data est équivalent à spécifier un pointeur vers un masque d'événements contenant 0. Ceci est similaire à la fonction XtRemoveRawEventHandler.

Si event_type spécifie un type d'événement d'extension, les sémantiques des données pointées par select_data sont définies par le sélecteur d'extension enregistré pour le type d'événement spécifié.

La fonction XtRegisterExtensionSelector enregistre une procédure pour organiser la livraison des événements d'extension aux widgets.

Si min_event_type et max_event_type correspondent aux paramètres d'un appel précédent à XtRegisterExtensionSelector pour le même affichage, proc et client_data remplacent les valeurs précédemment enregistrées. Si la plage spécifiée par min_event_type et max_event_type chevauche la plage des paramètres d'un appel précédent pour le même affichage de toute autre manière, une erreur se produit.

La fonction XtSetEventDispatcher enregistre la procédure de distribution d'événements spécifiée par proc pour les événements de type event_type. Le distributeur précédemment enregistré (ou le distributeur par défaut s'il n'y avait pas de distributeur précédemment enregistré) est renvoyé. Si proc est NULL, la procédure par défaut est restaurée pour le type spécifié.

À l'avenir, lorsque XtDispatchEvent sera appelé avec un événement de event_type, la procédure proc spécifiée (ou le distributeur par défaut) sera invoquée pour déterminer un widget auquel distribuer l'événement.

La fonction XtDispatchEventToWidget parcourt la liste des gestionnaires d'événements enregistrés pour le widget spécifié et appelle chaque gestionnaire qui a été enregistré pour le type d'événement spécifié, sous réserve de la valeur continue_to_dispatch renvoyée par chaque gestionnaire. Les Intrinsics se comportent comme si des gestionnaires d'événements étaient enregistrés en tête de liste pour les événements Expose, NoExpose, GraphicsExpose et VisibilityNotify pour appeler la procédure d'exposition du widget selon les règles de compression d'exposition et pour mettre à jour le champ visible du widget si visible_interest est True. Ces gestionnaires d'événements internes ne définissent jamais continue_to_dispatch sur False.

XtDispatchEventToWidget renvoie True si un gestionnaire d'événements a été appelé et False sinon.

terExtensionSelector(3) — Arch Linux

NOM

terExtensionSelector — Sélectionne une extension de terminal.

SYNTAXE

terExtensionSelector [OPTIONS]

DESCRIPTION

terExtensionSelector est un programme utilitaire conçu pour aider l'utilisateur à sélectionner une extension de terminal parmi celles disponibles. Il présente une interface interactive qui permet de parcourir, filtrer et choisir l'extension souhaitée.

OPTIONS

Cette commande n'a pas d'options spécifiques documentées dans cette page de manuel. Les options de configuration peuvent être gérées via des fichiers de configuration séparés ou des variables d'environnement.

EXEMPLES

terExtensionSelector

Lance l'interface interactive de sélection d'extension de terminal.

FICHIERS

Les extensions disponibles sont généralement recherchées dans les répertoires standard où les extensions de terminal sont installées. Les chemins exacts peuvent varier en fonction de la distribution et de la configuration du système.
