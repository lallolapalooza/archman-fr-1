XtRegisterDrawable(3) FONCTIONS XT XtRegisterDrawable(3)

NOM

XtRegisterDrawable - enregistre un objet dessinable auprès du distributeur d'événements des Intrinsics

SYNTAXE

#include <X11/Intrinsic.h>

void XtRegisterDrawable(Display* display, Drawable drawable, Widget widget);

void XtUnregisterDrawable(Display* display, Drawable drawable);

ARGUMENTS

display
Spécifie l'affichage de l'objet dessinable.
drawable
Spécifie l'objet dessinable à enregistrer.
widget
Spécifie le widget pour lequel l'objet dessinable est enregistré.

DESCRIPTION

XtRegisterDrawable associe l'objet dessinable spécifié au widget spécifié, de sorte que les appels futurs à XtWindowToWidget avec cet objet dessinable renvoient le widget. Le distributeur d'événements par défaut distribuera les futurs événements de base arrivant avec l'objet dessinable au widget, comme si l'événement contenait la fenêtre du widget, mais l'événement lui-même ne sera modifié d'aucune manière lorsqu'il sera transmis aux procédures de gestion d'événements ou d'actions.

Si l'objet dessinable est déjà enregistré auprès d'un autre widget, ou si l'objet dessinable est la fenêtre d'un widget dans l'arbre des widgets du client, les résultats de l'appel à XtRegisterDrawable sont indéfinis.

XtUnregisterDrawable supprime une association créée avec XtRegisterDrawable. Si l'objet dessinable est la fenêtre d'un widget dans l'arbre des widgets du client, les résultats de l'appel à XtUnregisterDrawable sont indéfinis.
