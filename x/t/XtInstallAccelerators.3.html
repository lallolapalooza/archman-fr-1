XtParseAcceleratorTable(3) FONCTIONS XT XtParseAcceleratorTable(3)

NOM

XtParseAcceleratorTable, XtInstallAccelerators, XtInstallAllAccelerators - gestion des tables d'accélérateurs

SYNTAXE

#include <X11/Intrinsic.h>

XtAccelerators XtParseAcceleratorTable(const char * source);

void XtInstallAccelerators(Widget destination, Widget source);

void XtInstallAllAccelerators(Widget destination, Widget source);

ARGUMENTS

source
Spécifie la table d'accélérateurs à compiler.
destination
Spécifie le widget sur lequel les accélérateurs doivent être installés.
source
Spécifie le widget ou le widget racine de l'arbre de widgets d'où proviennent les accélérateurs.

DESCRIPTION

La fonction XtParseAcceleratorTable compile la table d'accélérateurs dans la représentation interne opaque.

La fonction XtInstallAccelerators installe les accélérateurs de la source sur la destination en augmentant les traductions de la destination avec les accélérateurs de la source. Si la méthode display_accelerator de la source n'est pas NULL, XtInstallAccelerators l'appelle avec le widget source et une représentation textuelle de la table d'accélérateurs, qui indique que ses accélérateurs ont été installés et qu'elle doit les afficher de manière appropriée. La représentation textuelle de la table d'accélérateurs est sa représentation canonique de table de traduction.

La fonction XtInstallAllAccelerators descend récursivement l'arbre de widgets dont la racine est source et installe les accélérateurs de chaque widget rencontré sur destination. Une utilisation courante consiste à appeler XtInstallAllAccelerators et à passer la fenêtre principale de l'application comme source.
