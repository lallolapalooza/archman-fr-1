XtGetActionList(3) FONCTIONS XT XtGetActionList(3)

NOM

XtGetActionList - obtenir la liste d'actions de classe

SYNTAXE

#include <X11/Intrinsic.h>

void XtGetActionList(WidgetClass widget_class, XtActionList* actions_return, Cardinal* num_actions_return);

ARGUMENTS

widget_class
Spécifie la classe de widget dont les actions doivent être retournées.
actions_return
Retourne la liste d'actions.
num_actions_return
Retourne le nombre de procédures d'action déclarées par la classe.

DESCRIPTION

XtGetActionList retourne la table d'actions définie par la classe de widget spécifiée. Cette table n'inclut pas les actions définies par les superclasses. Si widget_class n'est pas initialisé, ou n'est pas coreWidgetClass ou une sous-classe de celle-ci, ou si la classe ne définit aucune action, *actions_return sera NULL et *num_actions_return sera zéro. Si *actions_return n'est pas NULL, le client est responsable de libérer la table en utilisant XtFree lorsqu'elle n'est plus nécessaire.
