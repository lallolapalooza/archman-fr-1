XtGetSelectionTimeout(3) FONCTIONS DE COMPATIBILITÉ XT XtGetSelectionTimeout(3)

NOM

XtGetSelectionTimeout, XtSetSelectionTimeout - définir et obtenir les valeurs de délai de sélection

SYNTAXE

#include <X11/Intrinsic.h>

unsigned long XtGetSelectionTimeout(void);

void XtSetSelectionTimeout(unsigned long timeout);

ARGUMENTS

timeout
Spécifie le délai de sélection en millisecondes.

DESCRIPTION

La fonction XtGetSelectionTimeout a été remplacée par XtAppGetSelectionTimeout.

La fonction XtSetSelectionTimeout a été remplacée par XtAppSetSelectionTimeout.

VOIR AUSSI
