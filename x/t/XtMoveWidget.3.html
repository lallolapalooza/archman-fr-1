XtConfigureWidget(3) FONCTIONS XT XtConfigureWidget(3)

NOM

XtConfigureWidget, XtMoveWidget, XtResizeWidget - déplacer et redimensionner des widgets

SYNTAXE

#include <X11/Intrinsic.h>

void XtConfigureWidget(Widget w, Position x, Position y, Dimension width, Dimension height, Dimension border_width);

void XtMoveWidget(Widget w, Position x, Position y);

void XtResizeWidget(Widget w, Dimension width, Dimension height, Dimension border_width);

void XtResizeWindow(Widget w);

ARGUMENTS

width

height

border_width
Spécifiez la nouvelle taille du widget.
w
Spécifie le widget.
x

y
Spécifiez les nouvelles coordonnées x et y du widget.

DESCRIPTION

La fonction XtConfigureWidget retourne immédiatement si les champs de géométrie spécifiés sont identiques aux anciennes valeurs. Sinon, XtConfigureWidget écrit les nouvelles valeurs x, y, width, height et border_width dans le widget et, si le widget est réalisé, effectue un appel XConfigureWindow de Xlib sur la fenêtre du widget.

Si la nouvelle largeur ou hauteur est différente de l'ancienne valeur, XtConfigureWidget appelle la procédure de redimensionnement du widget pour le notifier du changement de taille ; sinon, elle retourne simplement.

La fonction XtMoveWidget retourne immédiatement si les champs de géométrie spécifiés sont identiques aux anciennes valeurs. Sinon, XtMoveWidget écrit les nouvelles valeurs x et y dans le widget et, si le widget est réalisé, émet un appel XMoveWindow de Xlib sur la fenêtre du widget.

La fonction XtResizeWidget retourne immédiatement si les champs de géométrie spécifiés sont identiques aux anciennes valeurs. Sinon, XtResizeWidget écrit les nouvelles valeurs width, height et border_width dans le widget et, si le widget est réalisé, émet un appel XConfigureWindow sur la fenêtre du widget.

Si la nouvelle largeur ou hauteur est différente des anciennes valeurs, XtResizeWidget appelle la procédure de redimensionnement du widget pour le notifier du changement de taille.

La fonction XtResizeWindow appelle la fonction Xlib XConfigureWindow pour faire correspondre la fenêtre du widget spécifié à sa largeur, sa hauteur et la largeur de sa bordure. Cette requête est effectuée inconditionnellement car il n'y a aucun moyen de savoir si ces valeurs correspondent aux valeurs actuelles. Notez que la procédure de redimensionnement du widget n'est pas appelée.

Il y a très peu de cas où utiliser XtResizeWindow est approprié ; utilisez plutôt XtResizeWidget.
