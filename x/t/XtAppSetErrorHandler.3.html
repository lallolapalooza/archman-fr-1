XtAppSetErrorHandler(3)

Paquet: libxt

XtAppError(3) FONCTIONS XT XtAppError(3)

NOM

XtAppError, XtAppSetErrorHandler, XtAppSetWarningHandler, XtAppWarning - gestionnaires d'erreurs de bas niveau

SYNTAXE

#include <X11/Intrinsic.h>

_X_NORETURN void XtAppError(XtAppContext app_context, const char *message);

XtErrorHandler XtAppSetErrorHandler(XtAppContext app_context, _X_NORETURN XtErrorHandler handler);

XtErrorHandler XtAppSetWarningHandler(XtAppContext app_context, XtErrorHandler handler);

void XtAppWarning(XtAppContext app_context, const char *message);

ARGUMENTS

app_context
Spécifie le contexte de l'application.
message
Spécifie le message d'erreur non fatal qui doit être signalé.
handler
Spécifie la nouvelle procédure d'erreur fatale, qui ne doit pas retourner, ou la procédure d'erreur non fatale, qui retourne généralement.
message
Spécifie le message qui doit être signalé.

DESCRIPTION

La fonction XtAppError appelle la procédure d'erreur installée et lui transmet le message spécifié.

La fonction XtAppSetErrorHandler enregistre la procédure spécifiée, qui est appelée lorsqu'une condition d'erreur fatale se produit.

La fonction XtAppSetWarningHandler enregistre la procédure spécifiée, qui est appelée lorsqu'une condition d'erreur non fatale se produit.

La fonction XtAppWarning appelle la procédure d'erreur non fatale installée et lui transmet le message spécifié.
