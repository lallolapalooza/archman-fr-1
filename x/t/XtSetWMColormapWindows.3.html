XtSetWMColormapWindows(3) FONCTIONS XT XtSetWMColormapWindows(3)

NOM

XtSetWMColormapWindows - Définir la valeur de la propriété WM_COLORMAP_WINDOWS

SYNTAXE

#include <X11/Intrinsic.h>

void XtSetWMColormapWindows(Widget widget, Widget* list, Cardinal count);

ARGUMENTS

widget
Spécifie le widget sur la fenêtre duquel la propriété WM_COLORMAP_WINDOWS sera stockée. Doit être de classe Core ou de l'un de ses sous-classes.
list
Spécifie une liste de widgets dont les fenêtres sont potentiellement à lister dans la propriété WM_COLORMAP_WINDOWS.
count
Spécifie le nombre de widgets dans list.

DESCRIPTION

XtSetWMColormapWindows retourne immédiatement si widget n'est pas réalisé ou si count est zéro. Sinon, XtSetWMColormapWindows construit une liste ordonnée de fenêtres en examinant chaque widget dans list tour à tour et en ignorant le widget s'il n'est pas réalisé, ou en ajoutant la fenêtre du widget à la liste des fenêtres si le widget est réalisé et si sa ressource de palette de couleurs est différente des ressources de palettes de couleurs de tous les widgets dont les fenêtres sont déjà sur la liste des fenêtres.

Finalement, XtSetWMColormapWindows stocke la liste de fenêtres résultante dans la propriété WM_COLORMAP_WINDOWS sur la fenêtre du widget spécifié.
