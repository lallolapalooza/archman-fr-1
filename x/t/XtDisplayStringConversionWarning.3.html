XtDisplayStringConversionWarning(3) FONCTIONS XT XtDisplayStringConversionWarning(3)

NOM

XtDisplayStringConversionWarning - émettre un message d'avertissement de conversion

SYNTAXE

#include <X11/Intrinsic.h>

void XtDisplayStringConversionWarning(Display* display, const char *from_value, const char *to_type);

ARGUMENTS

display
Spécifie la connexion d'affichage à laquelle la conversion est associée.
from_value
Spécifie la chaîne qui n'a pas pu être convertie.
to_type
Spécifie le type de représentation cible demandé.

DESCRIPTION

La fonction XtDisplayStringConversionWarning émet un message d'avertissement en utilisant XtAppWarningMsg avec le nom “conversionError”, le type “string”, la classe “XtToolkitError”, et le message par défaut “Impossible de convertir “from_value” en type to_type”.

Pour émettre d'autres types de messages d'avertissement ou d'erreur, le convertisseur de type doit utiliser XtAppWarningMsg ou XtAppErrorMsg.
