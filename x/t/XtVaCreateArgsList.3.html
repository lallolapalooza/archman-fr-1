XtVaCreateArgsList(3) FONCTIONS XT XtVaCreateArgsList(3)

NOM

XtVaCreateArgsList - alloue dynamiquement une liste d'arguments variables

SYNTAXE

#include <X11/Intrinsic.h>

XtVarArgsList XtVaCreateArgsList(XtPointer unused, ...);

ARGUMENTS

unused
Doit être spécifié comme NULL.
...
Spécifie une liste de paramètres variables de paires nom-valeur de ressources.

DESCRIPTION

La fonction XtVaCreateArgsList alloue de la mémoire et copie ses arguments dans un pointeur de liste unique, qui peut être utilisé avec XtVaNestedList. La fin des deux listes est identifiée par une entrée name contenant NULL. Toutes les entrées de type XtVaTypedArg sont copiées comme spécifié sans appliquer de conversions. Les données passées par référence (y compris les chaînes) ne sont pas copiées, seuls les pointeurs eux-mêmes ; l'appelant doit s'assurer que les données restent valides pendant la durée de vie de la liste d'arguments variables créée. La liste doit être libérée en utilisant XtFree lorsqu'elle n'est plus nécessaire.
