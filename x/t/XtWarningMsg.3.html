XtErrorMsg(3) FONCTIONS DE COMPATIBILITÉ XT XtErrorMsg(3)

NOM

XtErrorMsg, XtSetErrorMsgHandler, XtWarningMsg, XtSetWarningMsgHandler - gestionnaires d'erreurs de haut niveau

SYNTAXE

#include <X11/Intrinsic.h>

_X_NORETURN void XtErrorMsg(const char *name, const char *type, const char *class, const char *defaultMsg, String *params, Cardinal *num_params);

void XtSetErrorMsgHandler(_X_NORETURN XtErrorMsgHandler msg_handler);

void XtSetWarningMsgHandler(XtErrorMsgHandler msg_handler);

void XtWarningMsg(const char *name, const char *type, const char *class, const char *defaultMsg, String *params, Cardinal *num_params);

ARGUMENTS

class
Spécifie la classe de ressource du message d'erreur.
default
Spécifie le message par défaut à utiliser.
name
Spécifie la nature générale de l'erreur.
type
Spécifie le nom détaillé de l'erreur.
msg_handler
Spécifie la nouvelle procédure d'erreur fatale, qui ne doit pas retourner, ou la procédure d'erreur non fatale, qui retourne généralement.
num_params
Spécifie le nombre de valeurs dans la liste de paramètres.
params
Spécifie un pointeur vers une liste de valeurs à stocker dans le message.

DESCRIPTION

La fonction XtErrorMsg a été remplacée par XtAppErrorMsg.

La fonction XtSetErrorMsgHandler a été remplacée par XtAppSetErrorMsgHandler.

La fonction XtSetWarningMsgHandler a été remplacée par XtAppSetWarningMsgHandler.

La fonction XtWarningMsg a été remplacée par XtAppWarningMsg
