XtRegisterDrawable(3) FONCTIONS XT XtRegisterDrawable(3)

NOM

XtRegisterDrawable - enregistrer un dessin dans le gestionnaire d'événements des Intrinsics

SYNTAXE

#include <X11/Intrinsic.h>

void XtRegisterDrawable(Display* display, Drawable drawable, Widget widget);

void XtUnregisterDrawable(Display* display, Drawable drawable);

ARGUMENTS

display
Spécifie l'affichage du dessin.
drawable
Spécifie le dessin à enregistrer.
widget
Spécifie le widget pour lequel le dessin est enregistré.

DESCRIPTION

XtRegisterDrawable associe le dessin spécifié au widget spécifié de sorte que les appels futurs à XtWindowToWidget avec ce dessin renvoient le widget. Le gestionnaire d'événements par défaut distribuera les événements de base futurs arrivant avec le dessin au widget, comme si l'événement contenait la fenêtre du widget, mais l'événement lui-même ne sera pas modifié de quelque manière que ce soit lors de son passage aux procédures de gestion des événements ou d'action.

Si le dessin est déjà enregistré avec un autre widget, ou si le dessin est la fenêtre d'un widget dans l'arbre des widgets du client, les résultats de l'appel à XtRegisterDrawable sont indéfinis.

XtUnregisterDrawable supprime une association créée avec XtRegisterDrawable. Si le dessin est la fenêtre d'un widget dans l'arbre des widgets du client, les résultats de l'appel à XtUnregisterDrawable sont indéfinis.
