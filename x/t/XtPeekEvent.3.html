XtNextEvent(3) FONCTIONS DE COMPATIBILITÉ XT XtNextEvent(3)

NOM

XtNextEvent, XtPending, XtPeekEvent, XtProcessEvent, XtMainLoop - interroger et traiter les événements et les entrées

SYNTAXE

#include <X11/Intrinsic.h>

void XtNextEvent(XEvent *event_return);

Boolean XtPeekEvent(XEvent *event_return);

Boolean XtPending(void);

void XtProcessEvent(XtInputMask mask);

void XtMainLoop(void);

ARGUMENTS

event
Spécifie un pointeur vers la structure d'événement qui doit être transmise au gestionnaire d'événements approprié.
event_return
Retourne les informations d'événement dans la structure d'événement spécifiée.
mask
Spécifie quels types d'événements traiter. Le masque est l'OU logique bit à bit de n'importe quelle combinaison de XtIMXEvent, XtIMTimer, XtIMAlternateInput et XtIMSignal. Par souci de commodité, la boîte à outils X définit le nom symbolique XtIMAll pour être l'OU logique bit à bit de tous les types d'événements.

DESCRIPTION

XtNextEvent a été remplacé par XtAppNextEvent.

XtPeekEvent a été remplacé par XtAppPeekEvent.

XtPending a été remplacé par XtAppPending.

XtProcessEvent a été remplacé par XtAppProcessEvent.

XtMainLoop a été remplacé par XtAppMainLoop.
