XtGetConstraintResourceList(3)

Paquet: libxt

XtGetResourceList(3) FONCTIONS XT XtGetResourceList(3)

NOM

XtGetResourceList, XtGetConstraintResourceList - obtenir la liste des ressources

SYNTAXE

#include <X11/Intrinsic.h>

void XtGetResourceList(WidgetClass class, XtResourceList *resources_return, Cardinal *num_resources_return);

void XtGetConstraintResourceList(WidgetClass class, XtResourceList *resources_return, Cardinal *num_resources_return);

ARGUMENTS

num_resources_return
Spécifie un pointeur vers l'endroit où stocker le nombre d'entrées dans la liste de ressources.
resources_return
Spécifie un pointeur vers l'endroit où stocker la liste de ressources retournée. L'appelant doit libérer cette mémoire en utilisant XtFree lorsqu'il a terminé.
widget_class
Spécifie la classe de widget pour laquelle vous souhaitez obtenir la liste.

DESCRIPTION

Si XtGetResourceList est appelée avant que la classe de widget ne soit initialisée (c'est-à-dire avant que le premier widget de cette classe n'ait été créé), XtGetResourceList retourne la liste des ressources telle que spécifiée dans l'enregistrement de la classe de widget. Si elle est appelée après l'initialisation de la classe de widget, XtGetResourceList retourne une liste de ressources fusionnée qui contient les ressources de toutes les superclasses. La liste retournée par XtGetResourceList doit être libérée à l'aide de XtFree lorsqu'elle n'est plus nécessaire.

Si XtGetConstraintResourceList est appelée avant que la classe de widget ne soit initialisée (c'est-à-dire avant que le premier widget de cette classe n'ait été créé), XtGetConstraintResourceList retourne la liste des ressources telle que spécifiée dans l'enregistrement de la partie Constraint de la classe de widget. Si elle est appelée après l'initialisation de la classe de widget, XtGetConstraintResourceList retourne une liste de ressources fusionnée qui contient les ressources Constraint de toutes les superclasses. Si la classe spécifiée n'est pas une sous-classe de constraintWidgetClass, *resources_return est défini sur NULL et *num_resources_return est défini sur zéro. La liste retournée par XtGetConstraintResourceList doit être libérée à l'aide de XtFree lorsqu'elle n'est plus nécessaire.
