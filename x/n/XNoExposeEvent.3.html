XNoExposeEvent(3)

Paquet: libx11

Licences: MIT AND X11

XGraphicsExposeEvent(3) FONCTIONS XLIB XGraphicsExposeEvent(3)

NOM

XGraphicsExposeEvent, XNoExposeEvent - structures d'événements GraphicsExpose et NoExpose

STRUCTURES

Les structures pour les événements GraphicsExpose et NoExpose contiennent :

typedef struct {
        int type;       /* GraphicsExpose */
        unsigned long serial;   /* # de la dernière requête traitée par le serveur */
        Bool send_event;        /* vrai si ceci provient d'une requête SendEvent */
        Display *display;       /* Display à partir duquel l'événement a été lu */
        Drawable drawable;
        int x, y;
        int width, height;
        int count;      /* si non nul, au moins autant d'autres */
        int major_code; /* core est CopyArea ou CopyPlane */
        int minor_code; /* non défini dans le core */
} XGraphicsExposeEvent;
typedef struct {
        int type;       /* NoExpose */
        unsigned long serial;   /* # de la dernière requête traitée par le serveur */
        Bool send_event;        /* vrai si ceci provient d'une requête SendEvent */
        Display *display;       /* Display à partir duquel l'événement a été lu */
        Drawable drawable;
        int major_code; /* core est CopyArea ou CopyPlane */
        int minor_code; /* non défini dans le core */
} XNoExposeEvent;

Lorsque vous recevez ces événements, les membres de leur structure sont définis comme suit.

Le membre type est défini sur le nom de constante du type d'événement qui l'identifie de manière unique. Par exemple, lorsque le serveur X signale un événement GraphicsExpose à une application cliente, il envoie une structure XGraphicsExposeEvent avec le membre type défini sur GraphicsExpose. Le membre display est défini sur un pointeur vers le display sur lequel l'événement a été lu. Le membre send_event est défini sur True si l'événement provient d'une requête de protocole SendEvent. Le membre serial est défini à partir du numéro de série rapporté dans le protocole, mais développé à partir des 16 bits de poids faible à une valeur complète de 32 bits. Le membre window est défini sur la fenêtre qui est la plus utile pour les dispatchers de toolkit.

Les deux structures ont ces membres communs : drawable, major_code, et minor_code. Le membre drawable est défini sur le drawable de la région de destination sur laquelle la requête graphique devait être effectuée. Le membre major_code est défini sur la requête graphique initiée par le client et peut être soit X_CopyArea soit X_CopyPlane. S'il s'agit de X_CopyArea, un appel à XCopyArea a initié la requête. S'il s'agit de X_CopyPlane, un appel à XCopyPlane a initié la requête. Ces constantes sont définies dans X11/Xproto.h. Le membre minor_code, comme le membre major_code, indique quelle requête graphique a été initiée par le client. Cependant, le membre minor_code n'est pas défini par le protocole X core et sera nul dans ces cas, bien qu'il puisse être utilisé par une extension.

La structure XGraphicsExposeEvent a ces membres supplémentaires : x, y, width, height et count. Les membres x et y sont définis sur les coordonnées relatives à l'origine du drawable et indiquent le coin supérieur gauche du rectangle. Les membres width et height sont définis sur la taille (étendue) du rectangle. Le membre count est défini sur le nombre d'événements GraphicsExpose à suivre. Si count est nul, aucun autre événement GraphicsExpose ne suit pour cette fenêtre. Cependant, si count est non nul, au moins ce nombre d'événements GraphicsExpose (et potentiellement plus) doit suivre pour cette fenêtre.
