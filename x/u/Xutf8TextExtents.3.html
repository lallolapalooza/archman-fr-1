Paquet: libx11

XmbTextExtents(3) FONCTIONS XLIB XmbTextExtents(3)

NOM

XmbTextExtents, XwcTextExtents, Xutf8TextExtents - calculer les extensions de texte

SYNTAXE

int XmbTextExtents(XFontSet font_set, _Xconst char *string, int num_bytes, XRectangle *overall_ink_return, XRectangle *overall_logical_return);

int XwcTextExtents(XFontSet font_set, _Xconst wchar_t *string, int num_wchars, XRectangle *overall_ink_return, XRectangle *overall_logical_return);

int Xutf8TextExtents(XFontSet font_set, _Xconst char *string, int num_bytes, XRectangle *overall_ink_return, XRectangle *overall_logical_return);

ARGUMENTS

font_set
Spécifie le jeu de polices.
num_bytes
Spécifie le nombre d'octets dans l'argument chaîne.
num_wchars
Spécifie le nombre de caractères dans l'argument chaîne.
overall_ink_return
Retourne les dimensions de l'encre globale.
overall_logical_return
Retourne les dimensions logiques globales.
string
Spécifie la chaîne de caractères.

DESCRIPTION

Les fonctions XmbTextExtents, XwcTextExtents et Xutf8TextExtents définissent les composantes des arguments spécifiés overall_ink_return et overall_logical_return au cadre englobant global de l'image de la chaîne et à un cadre englobant logique à des fins d'espacement, respectivement. Elles retournent la valeur retournée par XmbTextEscapement, XwcTextEscapement ou Xutf8TextEscapement. Ces métriques sont relatives à l'origine du dessin de la chaîne, en utilisant les polices chargées pour le jeu de polices spécifié.

Si l'argument overall_ink_return n'est pas NULL, il est défini au cadre englobant de l'encre des caractères de la chaîne. L'overall_ink_return pour un caractère latin non descendant, dessiné horizontalement, est conventionnellement entièrement au-dessus de la ligne de base ; c'est-à-dire, overall_ink_return.height <= -overall_ink_return.y. L'overall_ink_return pour un caractère non espacé est entièrement à l'origine et à sa droite ; c'est-à-dire, overall_ink_return.x >= 0. Un caractère composé d'un seul pixel à l'origine définirait les champs overall_ink_return y = 0, x = 0, width = 1, et height = 1.

Si l'argument overall_logical_return n'est pas NULL, il est défini au cadre englobant qui fournit un espacement minimum aux autres éléments graphiques pour la chaîne. D'autres éléments graphiques, par exemple, une bordure entourant le texte, ne devraient pas intercepter ce rectangle.

Lorsque le XFontSet a des jeux de caractères manquants, les métriques pour chaque caractère indisponible sont prises de la chaîne par défaut retournée par XCreateFontSet afin que les métriques représentent le texte tel qu'il sera réellement dessiné. Le comportement pour un point de code invalide n'est pas défini.

La fonction Xutf8TextExtents est une extension introduite par The XFree86 Project, Inc., dans sa version 4.0.2. Sa présence est indiquée par la macro X_HAVE_UTF8_STRING.
