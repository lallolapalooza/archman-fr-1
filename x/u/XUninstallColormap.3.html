Paquet: libx11

XInstallColormap(3) FONCTIONS XLIB XInstallColormap(3)

NOM

XInstallColormap, XUninstallColormap, XListInstalledColormaps - contrôler les tables de couleurs

SYNTAXE

int XInstallColormap(Display *display, Colormap colormap);

int XUninstallColormap(Display *display, Colormap colormap);

Colormap *XListInstalledColormaps(Display *display, Window w, int *num_return);

ARGUMENTS

colormap
Spécifie la table de couleurs.
display
Spécifie la connexion au serveur X.
num_return
Retourne le nombre de tables de couleurs actuellement installées.
w
Spécifie la fenêtre qui détermine l'écran.

DESCRIPTION

La fonction XInstallColormap installe la table de couleurs spécifiée pour son écran associé. Toutes les fenêtres associées à cette table de couleurs s'affichent immédiatement avec des couleurs vraies. Vous avez associé les fenêtres à cette table de couleurs lors de leur création en appelant XCreateWindow, XCreateSimpleWindow, XChangeWindowAttributes, ou XSetWindowColormap.

Si la table de couleurs spécifiée n'est pas déjà une table de couleurs installée, le serveur X génère un événement ColormapNotify sur chaque fenêtre qui possède cette table de couleurs. De plus, pour chaque autre table de couleurs qui est installée suite à un appel à XInstallColormap, le serveur X génère un événement ColormapNotify sur chaque fenêtre qui possède cette table de couleurs.

XInstallColormap peut générer une erreur BadColor.

La fonction XUninstallColormap retire la table de couleurs spécifiée de la liste requise pour son écran. Par conséquent, la table de couleurs spécifiée peut être désinstallée, et le serveur X peut implicitement installer ou désinstaller des tables de couleurs supplémentaires. Les tables de couleurs qui sont installées ou désinstallées dépendent du serveur, sauf que la liste requise doit rester installée.

Si la table de couleurs spécifiée devient désinstallée, le serveur X génère un événement ColormapNotify sur chaque fenêtre qui possède cette table de couleurs. De plus, pour chaque autre table de couleurs qui est installée ou désinstallée suite à un appel à XUninstallColormap, le serveur X génère un événement ColormapNotify sur chaque fenêtre qui possède cette table de couleurs.

XUninstallColormap peut générer une erreur BadColor.

La fonction XListInstalledColormaps retourne une liste des tables de couleurs actuellement installées pour l'écran de la fenêtre spécifiée. L'ordre des tables de couleurs dans la liste n'est pas significatif et n'est aucune indication explicite de la liste requise. Lorsque la liste allouée n'est plus nécessaire, libérez-la en utilisant XFree.

XListInstalledColormaps peut générer une erreur BadWindow.

DIAGNOSTICS

BadColor
Une valeur pour un argument Colormap ne nomme pas une table de couleurs définie.
BadWindow
Une valeur pour un argument Window ne nomme pas une fenêtre définie.

VOIR AUSSI

XChangeWindowAttributes(3), XCreateColormap(3), XCreateWindow(3), XFree(3)
