Paquet: libx11

XmbTextEscapement(3) FONCTIONS XLIB XmbTextEscapement(3)

NOM

XmbTextEscapement, XwcTextEscapement, Xutf8TextEscapement - obtenir l'échappement de texte

SYNTAXE

int XmbTextEscapement(XFontSet font_set, _Xconst char *string, int num_bytes);

int XwcTextEscapement(XFontSet font_set, _Xconst wchar_t *string, int num_wchars);

int Xutf8TextEscapement(XFontSet font_set, _Xconst char *string, int num_bytes);

ARGUMENTS

font_set
Spécifie le jeu de polices.
num_bytes
Spécifie le nombre d'octets dans l'argument chaîne.
num_wchars
Spécifie le nombre de caractères dans l'argument chaîne.
string
Spécifie la chaîne de caractères.

DESCRIPTION

Les fonctions XmbTextEscapement, XwcTextEscapement et Xutf8TextEscapement retournent l'échappement en pixels de la chaîne spécifiée en tant que valeur, en utilisant les polices chargées pour le jeu de polices spécifié. L'échappement est la distance en pixels dans la direction de dessin principale, depuis l'origine du dessin jusqu'à l'origine du caractère suivant à dessiner, en supposant que le rendu du caractère suivant ne dépend pas de la chaîne fournie.

Indépendamment de l'ordre de rendu des caractères, l'échappement est toujours positif.

La fonction Xutf8TextEscapement est une extension introduite par The XFree86 Project, Inc., dans sa version 4.0.2. Sa présence est indiquée par la macro X_HAVE_UTF8_STRING.
