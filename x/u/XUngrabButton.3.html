XUngrabButton(3)

Paquet: libx11

Licences: MIT AND X11

XGrabButton(3) FONCTIONS XLIB XGrabButton(3)

NOM

XGrabButton, XUngrabButton - saisir les boutons du pointeur

SYNTAXE

int XGrabButton(Display *display, unsigned int button, unsigned int modifiers, Window grab_window, Bool owner_events, unsigned int event_mask, int pointer_mode, keyboard_mode, Window confine_to, Cursor cursor);

int XUngrabButton(Display *display, unsigned int button, unsigned int modifiers, Window grab_window);

ARGUMENTS

button
Spécifie le bouton du pointeur à saisir ou à relâcher ou AnyButton.
confine_to
Spécifie la fenêtre dans laquelle le pointeur doit être confiné ou None.
cursor
Spécifie le curseur à afficher ou None.
display
Spécifie la connexion au serveur X.
event_mask
Spécifie quels événements du pointeur sont rapportés au client. Le masque est l'OU logique (OU bit à bit) des bits de masque d'événements de pointeur valides.
grab_window
Spécifie la fenêtre de saisie.
keyboard_mode
Spécifie le traitement ultérieur des événements du clavier. Vous pouvez passer GrabModeSync ou GrabModeAsync.
modifiers
Spécifie l'ensemble des masques de touches ou AnyModifier. Le masque est l'OU logique (OU bit à bit) des bits de masque de touches valides.
owner_events
Spécifie une valeur booléenne indiquant si les événements du pointeur doivent être rapportés comme d'habitude ou rapportés par rapport à la fenêtre de saisie s'ils sont sélectionnés par le masque d'événements.
pointer_mode
Spécifie le traitement ultérieur des événements du pointeur. Vous pouvez passer GrabModeSync ou GrabModeAsync.

DESCRIPTION

La fonction XGrabButton établit une saisie passive. À l'avenir, le pointeur est saisi activement (comme pour XGrabPointer), l'heure de la dernière saisie du pointeur est définie à l'heure à laquelle le bouton a été pressé (tel que transmis dans l'événement ButtonPress), et l'événement ButtonPress est rapporté si toutes les conditions suivantes sont remplies :

  • Le pointeur n'est pas saisi, et le bouton spécifié est logiquement pressé lorsque les touches modificateurs spécifiées sont logiquement enfoncées, et aucun autre bouton ou touche modificateur n'est logiquement enfoncé.
  • La fenêtre de saisie (grab_window) contient le pointeur.
  • La fenêtre de confinement (confine_to) (le cas échéant) est visible.
  • Aucune saisie passive sur la même combinaison bouton/touche n'existe sur un ancêtre de la fenêtre de saisie.

L'interprétation des arguments restants est la même que pour XGrabPointer. La saisie active est terminée automatiquement lorsque l'état logique du pointeur a tous les boutons relâchés (indépendamment de l'état des touches modificateurs logiques), auquel moment un événement ButtonRelease est rapporté à la fenêtre de saisie.

Notez que l'état logique d'un périphérique (tel que vu par les applications clientes) peut être en retard par rapport à l'état physique si le traitement des événements du périphérique est gelé.

Cette requête remplace toutes les saisies précédentes par le même client sur les mêmes combinaisons bouton/touche sur la même fenêtre. Un modificateur de AnyModifier est équivalent à l'émission de la requête de saisie pour toutes les combinaisons de modificateurs possibles (y compris la combinaison sans aucun modificateur). Il n'est pas requis que tous les modificateurs spécifiés aient des KeyCodes actuellement assignés. Un bouton de AnyButton est équivalent à l'émission de la requête pour tous les boutons possibles. Sinon, il n'est pas requis que le bouton spécifié soit actuellement assigné à un bouton physique.

Si un autre client a déjà émis une XGrabButton avec la même combinaison bouton/touche sur la même fenêtre, une erreur BadAccess en résulte. Lors de l'utilisation de AnyModifier ou AnyButton, la requête échoue complètement, et une erreur BadAccess en résulte (aucune saisie n'est établie) s'il existe une saisie conflictuelle pour une combinaison quelconque. XGrabButton n'a aucun effet sur une saisie active.

XGrabButton peut générer des erreurs BadCursor, BadValue et BadWindow.

La fonction XUngrabButton relâche la combinaison bouton/touche passive sur la fenêtre spécifiée si elle a été saisie par ce client. Un modificateur de AnyModifier est équivalent à l'émission de la requête de relâchement pour toutes les combinaisons de modificateurs possibles, y compris la combinaison sans aucun modificateur. Un bouton de AnyButton est équivalent à l'émission de la requête pour tous les boutons possibles. XUngrabButton n'a aucun effet sur une saisie active.

XUngrabButton peut générer des erreurs BadValue et BadWindow.

DIAGNOSTICS

BadCursor
Une valeur pour un argument Cursor ne nomme pas un Cursor défini.
BadValue
Une valeur numérique tombe en dehors de la plage de valeurs acceptées par la requête. Sauf si une plage spécifique est spécifiée pour un argument, la plage complète définie par le type de l'argument est acceptée. Tout argument défini comme un ensemble d'alternatives peut générer cette erreur.
BadWindow
Une valeur pour un argument Window ne nomme pas une Window définie.
