XUngrabDeviceButton(3)

Paquet: libxi

XGRABDEVICEBUTTON(3)   XGRABDEVICEBUTTON(3)

NOM

XGrabDeviceButton, XUngrabDeviceButton - saisir/libérer les boutons d'un périphérique d'extension

SYNTAXE

#include <X11/extensions/XInput.h>
int XGrabDeviceButton( Display *display,
                       XDevice *device,
                       unsigned int button,
                       unsigned int modifiers,
                       XDevice* modifier_device,
                       Window grab_window,
                       Bool owner_events,
                       unsigned int event_count,
                       XEventClass *event_list,
                       int this_device_mode,
                       int other_devices_mode);
int XUngrabDeviceButton( Display *display,
                         XDevice *device,
                         unsigned int button,
                         unsigned int modifiers,
                         XDevice* modifier_device,
                         Window grab_window);
display
       Spécifie la connexion au serveur X.
device
       Spécifie le périphérique qui doit être saisi ou libéré.
button
       Spécifie le bouton du périphérique qui doit être saisi ou
       libéré, ou AnyButton.
modifiers
       Spécifie l'ensemble des masques de touches ou AnyModifier. Le masque
       est le OU logique des bits des masques de touches valides.
       Les bits valides sont : ShiftMask, LockMask, ControlMask,
       Mod1Mask, Mod2Mask, Mod3Mask, Mod4Mask, Mod5Mask.
modifier_device
       spécifie le périphérique dont les modificateurs doivent être utilisés. Si
       le modifier_device spécifié est NULL, le clavier X sera utilisé comme
       modifier_device.
grab_window
       Spécifie la fenêtre de saisie.
owner_events
       Spécifie une valeur booléenne indiquant si les événements du périphérique
       doivent être rapportés comme d'habitude ou rapportés par rapport à la
       fenêtre de saisie s'ils sont sélectionnés par la liste d'événements.
event_count
       Spécifie le nombre de classes d'événements dans la liste d'événements.
event_list
       Spécifie quels événements sont rapportés au client.
this_device_mode
       Spécifie le traitement supplémentaire des événements de ce
       périphérique. Vous pouvez passer GrabModeSync ou GrabModeAsync.
other_devices_mode
       Spécifie le traitement supplémentaire des événements de tous les autres
       périphériques. Vous pouvez passer GrabModeSync ou GrabModeAsync.

DESCRIPTION

La requête XGrabDeviceButton établit une saisie passive. À l'avenir, le
périphérique est saisi activement (comme pour XGrabDevice, l'heure de la dernière
saisie est définie à l'heure à laquelle le bouton a été pressé (tel que transmis
dans l'événement DeviceButtonPress), et l'événement DeviceButtonPress est rapporté
si toutes les conditions suivantes sont remplies :
  * Le périphérique n'est pas saisi, et le bouton spécifié est
    logiquement pressé lorsque les touches modifiantes spécifiées sont
    logiquement enfoncées sur le périphérique modifiant spécifié et qu'aucun
    autre bouton ou touche modifiante n'est logiquement enfoncé.
  * Soit la fenêtre de saisie est un ancêtre de (ou est) la fenêtre de focus,
    SOIT la fenêtre de saisie est un descendant de la fenêtre de focus et
    contient le périphérique.
  * Aucune saisie passive sur la même combinaison de bouton/modificateur n'existe
    sur un ancêtre de la fenêtre de saisie.
L'interprétation des arguments restants est la même que pour XGrabDevice. La
saisie active est automatiquement terminée lorsque l'état logique du périphérique
a tous ses boutons relâchés (indépendamment de l'état logique des touches
modifiantes).
Notez que l'état logique d'un périphérique (tel que vu par les applications
client) peut être en retard sur l'état physique si le traitement des événements
du périphérique est gelé.
Cette requête remplace toutes les saisies précédentes par le même client sur
les mêmes combinaisons de boutons/modificateurs sur la même fenêtre. Un modificateur
AnyModifier équivaut à émettre la requête de saisie pour toutes les combinaisons
de modificateurs possibles (y compris la combinaison d'aucun modificateur). Il n'est
pas requis que tous les modificateurs spécifiés aient actuellement des KeyCodes
assignés. Un bouton AnyButton équivaut à émettre la requête pour tous les boutons
possibles. Sinon, il n'est pas requis que le bouton spécifié soit actuellement
assigné à un bouton physique.
Un modifier_device de NULL indique que le clavier X doit être utilisé comme
modifier_device.
Si un autre client a déjà effectué une requête XGrabDeviceButton avec la même
combinaison de bouton/modificateur sur la même fenêtre, une erreur BadAccess
en résulte. Lors de l'utilisation de AnyModifier ou AnyButton, la requête échoue
complètement, et une erreur BadAccess en résulte (aucune saisie n'est établie)
s'il existe une saisie conflictuelle pour une combinaison quelconque. XGrabDeviceButton
n'a aucun effet sur une saisie active.
XGrabDeviceButton peut générer les erreurs BadClass, BadDevice, BadMatch,
BadValue et BadWindow.
La requête XUngrabDeviceButton libère la saisie passive pour une combinaison
de bouton/modificateur sur la fenêtre spécifiée si elle a été saisie par ce
client. Un modificateur AnyModifier équivaut à émettre la requête de libération
pour toutes les combinaisons de modificateurs possibles, y compris la combinaison
d'aucun modificateur. Un bouton AnyButton équivaut à émettre la requête pour tous
les boutons possibles. XUngrabDeviceButton n'a aucun effet sur une saisie active.
Un modifier_device de NULL indique que le clavier X doit être utilisé comme
modifier_device.
XUngrabDeviceButton peut générer les erreurs BadDevice, BadMatch, BadValue et
BadWindow.

DIAGNOSTICS

BadDevice
       Un périphérique invalide a été spécifié. Le périphérique spécifié
       n'existe pas ou n'a pas été ouvert par ce client via XOpenInputDevice.
       Cette erreur peut également survenir si le périphérique spécifié est le
       clavier X ou le pointeur X.
BadMatch
       Cette erreur peut survenir si une requête XGrabDeviceButton a été effectuée
       en spécifiant un périphérique qui n'a pas de boutons, ou en
       spécifiant un périphérique modificateur qui n'a pas de touches.
BadValue
       Une valeur numérique tombe en dehors de la plage des valeurs
       acceptées par la requête. Sauf si une plage spécifique est
       spécifiée pour un argument, la plage complète définie par le
       type de l'argument est acceptée. Tout argument défini comme un
       ensemble d'alternatives peut générer cette erreur.
BadWindow
       Une valeur pour un argument Window ne nomme pas une Window
       définie.
