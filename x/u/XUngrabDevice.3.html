XGRABDEVICE(3)   XGRABDEVICE(3)

NOM

XGrabDevice, XUngrabDevice - saisir/libérer le périphérique d'extension spécifié

SYNTAXE

#include <X11/extensions/XInput.h>
int XGrabDevice( Display *display,
                 XDevice* device,
                 Window grab_window,
                 Bool owner_events,
                 int event_count,
                 XEventClass *event_list,
                 int this_device_mode,
                 int other_devices_mode,
                 Time time);
int XUngrabDevice( Display *display,
                   XDevice *device,
                   Time time);
display
       Spécifie la connexion au serveur X.
device
       Spécifie le périphérique à saisir ou à libérer.
grab_window
       Spécifie l'identifiant d'une fenêtre à associer au
       périphérique.
owner_events
       Spécifie une valeur booléenne qui indique si
       les événements du périphérique doivent être rapportés comme d'habitude ou
       rapportés par rapport à la fenêtre de saisie s'ils sont sélectionnés par
       la liste d'événements.
event_count
       Spécifie le nombre d'éléments dans le tableau event_list.
event_list
       Spécifie un pointeur vers une liste de classes d'événements qui indique quels événements le client souhaite recevoir.
       Ces classes d'événements doivent avoir été obtenues en spécifiant
       le périphérique saisi.
this_device_mode
       Spécifie le traitement ultérieur des événements de ce
       périphérique. Vous pouvez utiliser GrabModeSync ou GrabModeAsync.
other_devices_mode
       Spécifie le traitement ultérieur des événements des autres
       périphériques. Vous pouvez utiliser GrabModeSync ou GrabModeAsync.
time
       Spécifie le temps. Vous pouvez utiliser soit un horodatage, soit CurrentTime.

DESCRIPTION

La requête XGrabDevice saisit activement le contrôle du périphérique
et génère des événements DeviceFocusIn et DeviceFocusOut. Les événements de périphérique ultérieurs sont signalés uniquement au
client qui saisit. XGrabDevice remplace toute saisie de périphérique active par ce
client. event_list est un pointeur vers une liste de classes d'événements.
Cette liste indique quels événements le client souhaite recevoir
pendant que la saisie est active. Si owner_events est False, tous
les événements de périphérique générés sont signalés par rapport à
la fenêtre de saisie s'ils sont sélectionnés. Si owner_events est True et si un
événement de périphérique généré doit normalement être signalé à ce
client, il est signalé normalement ; sinon, l'événement est signalé
par rapport à la fenêtre de saisie et n'est signalé que s'il est spécifié dans la liste d'événements.
Si l'argument this_device_mode est GrabModeAsync, le traitement des événements du périphérique
se poursuit comme d'habitude. Si le périphérique est actuellement gelé par ce
client, le traitement des événements du périphérique est repris. Si
l'argument this_device_mode est GrabModeSync, l'état du périphérique (tel qu'il est vu par les applications clientes) semble se
figer, et le serveur X ne génère plus d'événements de périphérique jusqu'à ce que le client qui saisit émette un appel XAllowDeviceEvents libérateur
ou jusqu'à ce que la saisie du périphérique soit libérée. Les modifications réelles du périphérique ne sont pas perdues pendant que le périphérique est gelé ; elles sont simplement mises en file d'attente dans le serveur pour un traitement ultérieur.
Si other_devices_mode est GrabModeAsync, le traitement des événements des autres
périphériques n'est pas affecté par l'activation de la saisie. Si
other_devices_mode est GrabModeSync, l'état de tous les périphériques sauf le périphérique saisi (tel qu'il est vu par les applications clientes) semble se
figer, et le serveur X ne génère plus d'événements de ces
périphériques jusqu'à ce que le client qui saisit émette un appel XAllowDeviceEvents libérateur
ou jusqu'à ce que la saisie du périphérique soit libérée. Les événements réels ne sont pas perdus pendant que les périphériques sont gelés ; ils sont simplement mis en file d'attente dans le serveur pour un traitement ultérieur.
Si le périphérique est activement saisi par un autre client,
XGrabDevice échoue et renvoie AlreadyGrabbed. Si grab_window n'est pas visible, il échoue et renvoie GrabNotViewable. Si le
périphérique est gelé par une saisie active d'un autre client, il échoue et renvoie GrabFrozen. Si l'heure spécifiée est antérieure à
l'heure de la dernière saisie de périphérique ou ultérieure à l'heure actuelle du serveur X, il échoue et renvoie GrabInvalidTime. Sinon, l'heure de la dernière saisie de périphérique est définie à l'heure spécifiée
(CurrentTime est remplacé par l'heure actuelle du serveur X).
Si un périphérique saisi est fermé par un client alors qu'une saisie active par ce client est en vigueur, la saisie active est libérée. Si
le périphérique n'est gelé que par une saisie active du client demandeur, il est dégelé.
XGrabDevice peut générer des erreurs BadClass, BadDevice, BadValue et
BadWindow.
La requête XUngrabDevice libère le périphérique et tous les événements mis en file d'attente si ce client l'a saisi activement via
XGrabDevice ou XGrabDeviceKey. Si d'autres périphériques sont gelés par la saisie, XUngrabDevice les dégèle. XUngrabDevice ne libère pas le périphérique et les événements mis en file d'attente si l'heure spécifiée est antérieure à
l'heure de la dernière saisie de périphérique ou est postérieure à l'heure actuelle du serveur X. Il génère également des événements DeviceFocusIn et DeviceFocusOut. Le serveur X effectue automatiquement une requête UngrabDevice si la fenêtre d'événement d'une saisie de périphérique active devient non visible.
XUngrabDevice peut générer une erreur BadDevice.

DIAGNOSTICS

BadDevice
       Un périphérique invalide a été spécifié. Le périphérique
       spécifié n'existe pas ou n'a pas été ouvert par ce client via
       XOpenInputDevice. Cette erreur peut également survenir si le
       périphérique spécifié est le périphérique clavier X ou pointeur X.
BadValue
       Une valeur numérique se situe en dehors de la plage de valeurs
       acceptées par la requête. Sauf si une plage spécifique est
       spécifiée pour un argument, la plage complète définie par le
       type de l'argument est acceptée. Tout argument défini comme un
       ensemble d'alternatives peut générer cette erreur.
BadWindow
       Une valeur pour un argument Window ne nomme pas une fenêtre définie.
