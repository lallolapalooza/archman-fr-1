Paquet: libx11

XStoreBytes(3) FONCTIONS XLIB XStoreBytes(3)

NOM

XStoreBytes, XStoreBuffer, XFetchBytes, XFetchBuffer, XRotateBuffers - manipuler les tampons de copie et collage

SYNTAXE

int XStoreBytes(Display *display, _Xconst char *bytes, int nbytes);

int XStoreBuffer(Display *display, _Xconst char *bytes, int nbytes, int buffer);

char *XFetchBytes(Display *display, int *nbytes_return);

char *XFetchBuffer(Display *display, int *nbytes_return, int buffer);

int XRotateBuffers(Display *display, int rotate);

ARGUMENTS

buffer
Spécifie le tampon dans lequel vous souhaitez stocker les octets ou à partir duquel vous souhaitez obtenir les données stockées.
bytes
Spécifie les octets, qui ne sont pas nécessairement ASCII ou terminés par un caractère nul.
display
Spécifie la connexion au serveur X.
nbytes
Spécifie le nombre d'octets à stocker.
nbytes_return
Retourne le nombre d'octets dans le tampon.
rotate
Spécifie de combien faire pivoter les tampons de copie.

DESCRIPTION

Les données peuvent contenir des caractères nuls intégrés et n'ont pas besoin d'être terminées par un caractère nul. Le contenu du tampon de copie peut être récupéré ultérieurement par tout client appelant XFetchBytes.

XStoreBytes peut générer une erreur BadAlloc.

Si un tampon invalide est spécifié, l'appel n'a aucun effet. Les données peuvent contenir des caractères nuls intégrés et n'ont pas besoin d'être terminées par un caractère nul.

XStoreBuffer peut générer une erreur BadAlloc.

La fonction XFetchBytes renvoie le nombre d'octets dans l'argument nbytes_return, si le tampon contient des données. Sinon, la fonction renvoie NULL et met nbytes à 0. La quantité appropriée de stockage est allouée et le pointeur est renvoyé. Le client doit libérer ce stockage lorsqu'il a terminé de l'utiliser en appelant XFree.

La fonction XFetchBuffer renvoie zéro à l'argument nbytes_return s'il n'y a pas de données dans le tampon ou si un tampon invalide est spécifié.

XFetchBuffer peut générer une erreur BadValue.

La fonction XRotateBuffers fait pivoter les tampons de copie, de sorte que le tampon 0 devienne le tampon n, le tampon 1 devienne n + 1 mod 8, et ainsi de suite. Cette numérotation des tampons de copie est globale à l'affichage. Notez que XRotateBuffers génère des erreurs BadMatch si l'un des huit tampons n'a pas été créé.

XRotateBuffers peut générer une erreur BadMatch.

DIAGNOSTICS

BadAlloc
Le serveur n'a pas pu allouer la ressource ou la mémoire serveur demandée.
BadAtom
Une valeur pour un argument Atom ne nomme pas un Atom défini.
BadMatch
Un argument ou une paire d'arguments a le bon type et la bonne plage, mais ne correspond pas d'une autre manière requise par la demande.
BadValue
Une valeur numérique sort de la plage de valeurs acceptées par la demande. À moins qu'une plage spécifique ne soit spécifiée pour un argument, la plage complète définie par le type de l'argument est acceptée. Tout argument défini comme un ensemble d'alternatives peut générer cette erreur.
