XSELECTEXTENSIONEVEN(3)   XSELECTEXTENSIONEVEN(3)

NOM

XSelectExtensionEvent, XGetSelectedExtensionEvents - sélectionner les événements d'extension, obtenir la liste des événements d'extension actuellement sélectionnés

SYNOPSIS

#include <X11/extensions/XInput.h>
XSelectExtensionEvent( Display *display,
                       Window w,
                       XEventClass *event_list,
                       int event_count);
XGetSelectedExtensionEvents( Display *display,
                             Window w,
                             int *this_client_event_count_return,
                             XEventClass **this_client_event_list_return,
                             int *all_clients_event_count_return,
                             XEventClass **all_clients_event_list_return);
display
       Spécifie la connexion au serveur X.
w
       Spécifie la fenêtre dont les événements vous intéressent.
event_list
       Spécifie la liste des classes d'événements qui décrivent les
       événements qui vous intéressent.
event_count
       Spécifie le nombre de classes d'événements dans la liste d'événements.
this_client_event_count_return
       Retourne le nombre de classes d'événements sélectionnées par ce
       client.
this_client_event_list_return
       Retourne un pointeur vers la liste des classes d'événements sélectionnées
       par ce client.
all_clients_event_count_return
       Retourne le nombre de classes d'événements sélectionnées par tous les
       clients.
all_clients_event_list_return
       Retourne un pointeur vers la liste des classes d'événements sélectionnées
       par tous les clients.

DESCRIPTION

La requête XSelectExtensionEvent demande au serveur X de signaler les
événements associés à la liste spécifiée de classes d'événements.
Initialement, X ne signalera aucun de ces événements. Les événements sont
signalés par rapport à une fenêtre. Si une fenêtre n'est pas intéressée par
un événement de périphérique, il se propage généralement à l'ancêtre le plus
proche qui est intéressé, à moins que le masque do_not_propagate ne l'interdise.
Plusieurs clients peuvent sélectionner les mêmes événements sur la même
fenêtre avec les restrictions suivantes :
  * Plusieurs clients peuvent sélectionner des événements sur la même fenêtre
    car leurs masques d'événements sont disjoints. Lorsque le serveur X
    génère un événement, il le signale à tous les clients intéressés.
  * Un seul client à la fois peut sélectionner un événement DeviceButtonPress
    avec la saisie passive automatique activée, ce qui est associé à la
    classe d'événement DeviceButtonPressGrab. Pour recevoir des événements
    DeviceButtonPress sans saisie passive automatique, utilisez la classe
    d'événement DeviceButtonPress mais ne spécifiez pas la classe d'événement
    DeviceButtonPressGrab.
Le serveur signale l'événement à tous les clients intéressés.
Les informations contenues dans la structure XDevice renvoyée par
XOpenDevice sont utilisées par des macros pour obtenir les classes d'événements
que les clients utilisent dans les requêtes XSelectExtensionEvent. Les macros
actuellement définies incluent DeviceKeyPress, DeviceKeyRelease,
DeviceButtonPress, DeviceButtonRelease, DeviceMotionNotify,
DeviceFocusIn, DeviceFocusOut, ProximityIn, ProximityOut,
DeviceStateNotify, DeviceMappingNotify, ChangeDeviceNotify,
DevicePointerMotionHint, DeviceButton1Motion,
DeviceButton2Motion, DeviceButton3Motion, DeviceButton4Motion,
DeviceButton5Motion, DeviceButtonMotion, DeviceOwnerGrabButton,
DeviceButtonPressGrab, et NoExtensionEvent.
Pour obtenir la classe d'événement appropriée pour un périphérique particulier,
l'une des macros ci-dessus est appelée en utilisant la structure XDevice pour
ce périphérique. Par exemple,
             DeviceKeyPress (*device, type, eventclass);
renvoie le type d'événement DeviceKeyPress et la classe d'événement pour
sélectionner les événements DeviceKeyPress de ce périphérique.
XSelectExtensionEvent peut générer une erreur BadWindow ou BadClass. La
requête XGetSelectedExtensionEvents signale les événements d'extension
sélectionnés par ce client et tous les clients pour la fenêtre spécifiée.
Cette requête renvoie des pointeurs vers deux tableaux XEventClass. L'un
liste les événements d'extension d'entrée sélectionnés par ce client à partir
de la fenêtre spécifiée. L'autre liste les classes d'événements sélectionnées
par tous les clients à partir de la fenêtre spécifiée. Vous devriez utiliser
XFree pour libérer ces deux tableaux.
XGetSelectedExtensionEvents peut générer une erreur BadWindow.

DIAGNOSTICS

BadWindow
       Une valeur pour un argument Window ne nomme pas une fenêtre valide.
BadClass
       Une valeur pour un XEventClass est invalide.
