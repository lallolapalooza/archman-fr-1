NOM

XSendExtensionEvent - envoyer des événements d'extension d'entrée à un client

SYNTAXE

#include <X11/extensions/XInput.h>
Status XSendExtensionEvent( Display *display,
                            XDevice *device,
                            Window destination,
                            Bool propagate,
                            int event_count,
                            XEventClass *event_list,
                            XEvent *event_send);
display
       Spécifie la connexion au serveur X.
device
       Spécifie le périphérique à partir duquel les événements doivent
       être envoyés.
destination
       Spécifie la fenêtre à laquelle l'événement doit être envoyé. Vous pouvez
       passer l'identifiant de la fenêtre, PointerWindow, ou InputFocus.
propagate
       Spécifie une valeur booléenne, soit True soit False.
event_count
       Spécifie le nombre de XEventClasses dans event_list.
event_list
       Spécifie la liste des sélections d'événements à utiliser.
event_send
       Spécifie un pointeur vers l'événement qui doit être envoyé.

DESCRIPTION

La requête XSendExtensionEvent identifie la fenêtre de destination,
détermine quels clients doivent recevoir les événements spécifiés et ignore
toutes les saisies actives. Cette requête nécessite de passer une liste de
classes d'événements. Pour une discussion sur les noms de classes
d'événements valides, voir XOpenDevice(3). Cette
requête utilise l'argument w pour identifier la fenêtre de destination comme suit :
  * Si w est PointerWindow, la fenêtre de destination est la fenêtre
    qui contient le pointeur.
  * Si w est InputFocus et si la fenêtre de focus contient
    le pointeur, la fenêtre de destination est la fenêtre qui contient
    le pointeur ; sinon, la fenêtre de destination est la fenêtre de focus.
Pour déterminer quels clients doivent recevoir les événements spécifiés,
XSendExtensionEvent utilise l'argument propagate comme suit :
  * Si event_list est un ensemble vide, l'événement est envoyé au
    client qui a créé la fenêtre de destination. Si ce client
    n'existe plus, aucun événement n'est envoyé.
  * Si propagate est False, l'événement est envoyé à chaque client
    sélectionnant sur destination l'un des types d'événements spécifiés par
    le tableau event_list.
  * Si propagate est True et aucun client n'a sélectionné sur
    destination l'un des événements spécifiés par le tableau
    event_list, la destination est remplacée par l'ancêtre le plus proche
    de destination pour lequel un client a sélectionné un type
    spécifié par le tableau event-list et pour lequel aucune fenêtre
    intermédiaire n'a ce type dans
    son masque do-not-propagate-mask. Si aucune telle fenêtre n'existe ou
    si la fenêtre est un ancêtre de la fenêtre de focus et
    InputFocus a été spécifié à l'origine comme destination, l'événement
    n'est envoyé à aucun client. Sinon, l'événement est signalé à chaque
    client sélectionnant sur la destination finale l'un des événements
    spécifiés dans le tableau event_list.
L'événement dans la structure XEvent doit être l'un des événements
définis par l'extension d'entrée (ou une erreur BadValue en résultera) de sorte
que le serveur X puisse correctement permuter les octets du contenu si
nécessaire. Le contenu de l'événement est par ailleurs inchangé et non vérifié
par le serveur X, à l'exception de la force de send_event à True dans l'événement
transmis et de la définition correcte du numéro de série dans l'événement.
XSendExtensionEvent retourne zéro si la conversion au format du protocole
filaire a échoué et retourne une valeur non nulle
sinon. XSendExtensionEvent peut générer des erreurs BadClass, BadDevice,
BadValue et BadWindow.

DIAGNOSTICS

BadDevice
       Un périphérique invalide a été spécifié. Le périphérique spécifié
       n'existe pas ou n'a pas été ouvert par ce client via
       XOpenInputDevice. Cette erreur peut également survenir si
       le périphérique spécifié est le périphérique clavier X ou pointeur X.
BadValue
       Une valeur numérique tombe en dehors de la plage de valeurs
       acceptées par la requête. Sauf si une plage spécifique est
       spécifiée pour un argument, la plage complète définie par le
       type de l'argument est acceptée. Tout argument défini comme un
       ensemble d'alternatives peut générer cette erreur.
BadWindow
       Une valeur pour un argument Window ne nomme pas une fenêtre
       définie.
