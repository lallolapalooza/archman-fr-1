NOM

XScreenSaver - Bibliothèque cliente de l'extension économiseur d'écran X11

SYNTAXE

#include <X11/extensions/scrnsaver.h>

typedef struct {
    Window window;                /* fenêtre de l'économiseur d'écran */
    int state;                    /* ScreenSaver{Off,On,Disabled} */
    int kind;                     /* ScreenSaver{Blanked,Internal,External} */
    unsigned long til_or_since;   /* millisecondes */
    unsigned long idle;           /* millisecondes */
    unsigned long eventMask;      /* événements */
} XScreenSaverInfo;

typedef struct {
    int type;               /* type d'événement */
    unsigned long serial;   /* # de la dernière requête traitée par le serveur */
    Bool send_event;        /* vrai si ceci provient d'une requête SendEvent */
    Display *display;       /* Display à partir duquel l'événement a été lu */
    Window window;          /* fenêtre de l'économiseur d'écran */
    Window root;            /* fenêtre racine de l'écran de l'événement */
    int state;              /* ScreenSaver{Off,On,Cycle} */
    int kind;               /* ScreenSaver{Blanked,Internal,External} */
    Bool forced;            /* étendues de la nouvelle région */
    Time time;              /* horodatage de l'événement */
} XScreenSaverNotifyEvent;
Bool XScreenSaverQueryExtension(Display *dpy,
    int *event_base_return, int *error_base_return);
Status XScreenSaverQueryVersion(Display *dpy,
    int *major_version_return, int *minor_version_return);
XScreenSaverInfo *XScreenSaverAllocInfo(void);
Status XScreenSaverQueryInfo(Display *dpy, Drawable drawable,
    XScreenSaverInfo *saver_info);
void XScreenSaverSelectInput(Display *dpy, Drawable drawable,
    unsigned long mask);
void XScreenSaverSetAttributes(Display *dpy, Drawable drawable,
    int x, int y, unsigned int width, unsigned int height,
    unsigned int border_width, int depth, unsigned int class,
    Visual *visual, unsigned long valuemask,
    XSetWindowAttributes *attributes);
void XScreenSaverUnsetAttributes(Display *dpy, Drawable drawable);
void XScreenSaverRegister(Display *dpy, int screen, XID xid, Atom type);
Status XScreenSaverUnregister(Display *dpy, int screen);
Status XScreenSaverGetRegistered(Display *dpy, int screen,
    XID *xid, Atom *type);
void XScreenSaverSuspend(Display *dpy, Bool suspend);

DESCRIPTION

Le système de fenêtrage X fournit une prise en charge pour changer l'image sur un écran d'affichage après une période d'inactivité configurable par l'utilisateur afin d'éviter de brûler les phosphores du tube cathodique. Cependant, aucune interface n'est fournie pour que l'utilisateur contrôle l'image affichée. Cette extension permet à un client externe « d'économiseur d'écran » de détecter quand l'image alternative doit être affichée et de fournir les graphismes.

Les implémentations actuelles de serveurs X fournissent généralement au moins une forme d'image « d'économiseur d'écran ». Historiquement, il s'agissait d'une copie du logo X dessinée sur le motif de fond de la racine. Cependant, de nombreux utilisateurs ont demandé un mécanisme leur permettant d'écrire des programmes d'économiseur d'écran offrant des capacités similaires à celles fournies par d'autres systèmes de fenêtrage. En particulier, ces utilisateurs souhaitent souvent pouvoir afficher des logos d'entreprise, des instructions sur la manière de réactiver l'écran et des utilitaires de verrouillage d'écran automatique. Cette extension fournit un moyen d'écrire de tels clients.

Hypothèses

Cette extension exporte la notion d'une fenêtre spéciale d'économiseur d'écran qui est mappée au-dessus de toutes les autres fenêtres sur un écran. Cette fenêtre a l'attribut override-redirect défini de manière à ne pas être soumise à la manipulation par le gestionnaire de fenêtres. De plus, l'identifiant X de la fenêtre n'est jamais retourné par les requêtes QueryTree sur la fenêtre racine, de sorte qu'elle n'est généralement pas visible par les autres clients.

XScreenSaverQueryExtension retourne True si l'extension XScreenSaver est disponible sur l'écran donné. Un client doit appeler XScreenSaverQueryExtension avant d'appeler toute autre fonction XScreenSaver afin de négocier une version de protocole compatible ; sinon, le client obtiendra un comportement indéfini (XScreenSaver peut fonctionner ou non).

Si l'extension est prise en charge, le numéro d'événement pour les événements ScreenSaverNotify est retourné dans la valeur pointée par event_base. Étant donné qu'aucun erreur supplémentaire n'est défini par cette extension, les résultats de error_base ne sont pas définis.

XScreenSaverQueryVersion retourne True si la requête a réussi ; les valeurs des versions de protocole majeure et mineure prises en charge par le serveur sont retournées dans major_version_return et minor_version_return.

XScreenSaverAllocInfo alloue et retourne une structure XScreenSaverInfo pour utilisation dans les appels à XScreenSaverQueryInfo. Tous les champs de la structure sont initialisés à zéro. Si une mémoire insuffisante est disponible, NULL est retourné. Les résultats de cette routine peuvent être libérés avec XFree.

XScreenSaverQueryInfo retourne des informations sur l'état actuel du serveur d'écran dans saver_info et une valeur non nulle est retournée. Si l'extension n'est pas prise en charge, saver_info n'est pas modifié et 0 est retourné.

Le champ state spécifie si l'économiseur d'écran est actuellement actif et comment la valeur til-or-since doit être interprétée :

Off
L'écran n'est actuellement pas sauvegardé ; til-or-since spécifie le nombre de millisecondes avant que l'économiseur d'écran ne s'active.
On
L'écran est actuellement sauvegardé ; til-or-since spécifie le nombre de millisecondes depuis que l'économiseur d'écran s'est activé.
Disabled
L'économiseur d'écran est actuellement désactivé ; til-or-since est zéro.

Le champ kind spécifie le mécanisme qui est actuellement utilisé ou qui aurait été utilisé si l'écran avait été sauvegardé :

Blanked
Le signal vidéo vers le moniteur d'affichage a été désactivé.
Internal
Une image d'économiseur d'écran intégrée, dépendante du serveur, a été affichée ; soit aucun client n'avait défini les attributs de la fenêtre d'économiseur d'écran, soit un autre client avait saisi le serveur lorsque l'économiseur d'écran s'est activé.
External
La fenêtre de l'économiseur d'écran a été mappée avec des attributs définis par un client utilisant la requête ScreenSaverSetAttributes.

Le champ idle spécifie le nombre de millisecondes depuis la dernière entrée reçue de l'utilisateur sur l'un des périphériques d'entrée.
Le champ event-mask spécifie quels événements d'économiseur d'écran, le cas échéant, ce client a demandés en utilisant ScreenSaverSelectInput.

XScreenSaverSelectInput demande que les événements liés à l'économiseur d'écran soient générés pour ce client. Si aucun bit n'est défini dans event-mask, aucun événement ne sera généré. Sinon, toute combinaison des bits suivants peut être définie :

ScreenSaverNotify
Si ce bit est défini, des événements ScreenSaverNotify sont générés chaque fois que l'économiseur d'écran est activé ou désactivé.
ScreenSaverCycle
Si ce bit est défini, des événements ScreenSaverNotify sont générés chaque fois que l'intervalle de cycle de l'économiseur d'écran est passé.

XScreenSaverSetAttributes définit les attributs à utiliser la prochaine fois que l'économiseur d'écran externe sera activé. Si un autre client a actuellement les attributs définis, une erreur BadAccess est générée et la requête est ignorée.
Sinon, les attributs de fenêtre spécifiés sont vérifiés comme s'ils étaient utilisés dans une requête CreateWindow de base dont le parent est la racine. Le champ override-redirect est ignoré car il est implicitement défini à True. Si les attributs de fenêtre entraînent une erreur selon les règles de CreateWindow, la requête est ignorée.
Sinon, les attributs sont stockés et prendront effet lors de la prochaine activation qui se produit lorsque le serveur n'est pas saisi par un autre client. Toutes les ressources spécifiées pour les attributs background-pixmap ou cursor peuvent être libérées immédiatement.

. Le serveur est libre de copier les ressources background-pixmap ou cursor ou de les utiliser en place ; par conséquent, l'effet de la modification du contenu de ces ressources est indéfini. Si la colormap spécifiée n'existe plus lorsque l'économiseur d'écran s'active, la colormap du parent est utilisée à la place. Si aucune erreur n'est générée par cette requête, tous les attributs de fenêtre d'économiseur d'écran précédemment définis par ce client sont libérés.
Lorsque l'économiseur d'écran s'activera la prochaine fois et que le serveur ne sera pas saisi par un autre client, la fenêtre de l'économiseur d'écran sera créée, si nécessaire, et configurée avec les attributs spécifiés, et les événements seront générés comme d'habitude. La colormap associée à la fenêtre de l'économiseur d'écran sera installée. Enfin, la fenêtre de l'économiseur d'écran sera mappée.
La fenêtre reste mappée et au sommet de l'ordre de superposition jusqu'à ce que l'économiseur d'écran soit désactivé en réponse à une activité sur l'un des périphériques d'entrée utilisateur, une requête ForceScreenSaver avec la valeur Reset, ou toute requête qui provoquerait le démappage de la fenêtre.
Si l'économiseur d'écran s'active alors que le serveur est saisi par un autre client, le mécanisme de sauvegarde interne est utilisé. La requête ForceScreenSaver peut être utilisée avec la valeur Active pour désactiver le sauvegarde interne et activer la sauvegarde externe.
Si la connexion du client économiseur d'écran au serveur est rompue pendant que l'économiseur d'écran est activé et que le mode de fermeture du client n'est pas RetainPermanent ou RetainTemporary, l'économiseur d'écran actuel est désactivé et l'économiseur d'écran interne est immédiatement activé.
Lorsque l'économiseur d'écran est désactivé, la colormap de la fenêtre de l'économiseur d'écran est désinstallée et la fenêtre est démappée (sauf indication contraire ci-dessous). Le XID de l'économiseur d'écran est dissocié de la fenêtre, et le serveur peut, mais n'est pas obligé, détruire la fenêtre ainsi que ses enfants.
Lorsque l'économiseur d'écran est en cours de désactivation puis de réactivation immédiate (par exemple, lors du changement d'économiseur d'écran), le serveur peut laisser la fenêtre de l'économiseur d'écran mappée (généralement pour éviter de générer des expositions).

XScreenSaverUnsetAttributes demande au serveur de rejeter tous les attributs de fenêtre d'économiseur d'écran précédemment définis par ce client.

XScreenSaverRegister stocke le XID donné dans la propriété _SCREEN_SAVER_ID (du type donné) sur la fenêtre racine de l'écran spécifié. Il renvoie zéro si une erreur est rencontrée et que la propriété n'est pas modifiée, sinon il renvoie une valeur non nulle.

XScreenSaverUnregister supprime tout _SCREEN_SAVER_ID de la fenêtre racine de l'écran spécifié. Il renvoie zéro si une erreur est rencontrée et que la propriété est modifiée, sinon il renvoie une valeur non nulle.

XScreenSaverGetRegistered renvoie le XID et le type stockés dans la propriété _SCREEN_SAVER_ID sur la fenêtre racine de l'écran spécifié. Il renvoie zéro si une erreur est rencontrée ou si la propriété n'existe pas ou n'est pas du format correct ; sinon, il renvoie une valeur non nulle.

XScreenSaverSuspend suspend temporairement l'économiseur d'écran et le minuteur DPMS si suspend est 'True', et redémarre le minuteur si suspend est 'False'.
Cette fonction doit être utilisée par les applications qui ne veulent pas que l'économiseur d'écran ou DPMS s'activent pendant qu'elles sont, par exemple, en train de lire une séquence multimédia, ou qui présentent continuellement des informations visuelles à l'utilisateur dans un état non interactif. Cette fonction n'est pas destinée à être appelée par une application d'économiseur d'écran externe.
Si XScreenSaverSuspend est appelé plusieurs fois avec suspend défini sur 'True', il doit être appelé un nombre égal de fois avec suspend défini sur 'False' afin que le minuteur de l'économiseur d'écran soit redémarré. Cette requête n'a aucun effet si un client tente de reprendre l'économiseur d'écran sans l'avoir d'abord suspendu. XScreenSaverSuspend ne peut donc pas être utilisé par un client pour reprendre l'économiseur d'écran s'il a été suspendu par un autre client.
Si un client qui a suspendu l'économiseur d'écran devient déconnecté du serveur X, le minuteur de l'économiseur d'écran sera automatiquement redémarré, à moins qu'il ne soit toujours suspendu par un autre client. La suspension du minuteur de l'économiseur d'écran n'empêche pas l'activation forcée de l'économiseur d'écran avec la requête ForceScreenSaver, ni la définition d'un mode DPMS avec la requête DPMSForceLevel.
XScreenSaverSuspend ne désactive pas non plus l'économiseur d'écran ou DPMS s'ils sont actifs au moment où la requête pour les suspendre est reçue par le serveur X. Mais une fois désactivés, ils ne seront pas automatiquement réactivés avant que le client n'ait annulé la suspension.

ERREURS

XScreenSaverSelectInput, XScreenSaverQueryInfo, XScreenSaverSetAttributes et XScreenSaverUnsetAttributes généreront une erreur BadDrawable si drawable n'est pas un identifiant de drawable valide. Si des bits indéfinis sont définis dans event-mask, une erreur BadValue est générée par XScreenSaverSelectInput.

DISPONIBILITÉ

XScreenSaverSuspend est disponible dans la version 1.1 et les versions ultérieures de l'extension X Screen Saver. La version 1.1 est sortie pour la première fois avec X11R7.1.
