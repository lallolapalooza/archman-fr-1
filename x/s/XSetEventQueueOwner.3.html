XSetEventQueueOwner(3)

Paquet: libx11

Licences: MIT AND X11

XSetEventQueueOwner(3) FONCTIONS XLIB XSetEventQueueOwner(3)

NOM

XSetEventQueueOwner - définir le propriétaire de la file d'attente d'événements sur une connexion Xlib/XCB partagée

SYNTAXE


#include <X11/Xlib-xcb.h>

void XSetEventQueueOwner(Display *dpy, enum XEventQueueOwner owner);

ARGUMENTS

dpy
Spécifie la connexion au serveur X.
owner
Spécifie la propriété de la file d'attente d'événements :
XlibOwnsEventQueue (par défaut)
Xlib possède la file d'attente d'événements. Utilisez les fonctions de gestion d'événements Xlib. N'appelez pas les fonctions de gestion d'événements XCB.
XCBOwnsEventQueue
XCB possède la file d'attente d'événements. Utilisez les fonctions de gestion d'événements XCB. N'appelez pas les fonctions de gestion d'événements Xlib.

DESCRIPTION

Bien qu'un client utilisant Xlib/XCB puisse émettre des requêtes et gérer leurs réponses ou erreurs avec Xlib ou XCB, un seul peut posséder et gérer la file d'attente d'événements. Par défaut, Xlib doit posséder la file d'attente d'événements, pour la compatibilité avec les clients Xlib hérités. Les clients peuvent appeler XSetEventQueueOwner immédiatement après XOpenDisplay pour laisser XCB posséder la file d'attente d'événements à la place. Les clients ne peuvent pas appeler XSetEventQueueOwner à tout autre moment, car cela pourrait entraîner la perte de réponses.
