NOM

XScreenSaver - Bibliothèque cliente de l'extension économiseur d'écran X11

SYNTAXE

#include <X11/extensions/scrnsaver.h>

typedef struct {
    Window window;                /* fenêtre de l'économiseur d'écran */
    int state;                    /* ScreenSaver{Off,On,Disabled} */
    int kind;                     /* ScreenSaver{Blanked,Internal,External} */
    unsigned long til_or_since;   /* millisecondes */
    unsigned long idle;           /* millisecondes */
    unsigned long eventMask;      /* événements */
} XScreenSaverInfo;

typedef struct {
    int type;               /* type d'événement */
    unsigned long serial;   /* # de la dernière requête traitée par le serveur */
    Bool send_event;        /* vrai si cela provient d'une requête SendEvent */
    Display *display;       /* Display à partir duquel l'événement a été lu */
    Window window;          /* fenêtre de l'économiseur d'écran */
    Window root;            /* fenêtre racine de l'écran d'événement */
    int state;              /* ScreenSaver{Off,On,Cycle} */
    int kind;               /* ScreenSaver{Blanked,Internal,External} */
    Bool forced;            /* étendues de la nouvelle région */
    Time time;              /* horodatage de l'événement */
} XScreenSaverNotifyEvent;

DESCRIPTION

Le système X Window fournit un support pour changer l'image sur un écran après une période d'inactivité définie par l'utilisateur afin d'éviter la brûlure des phosphores du tube cathodique. Cependant, aucune interface n'est fournie à l'utilisateur pour contrôler l'image qui est dessinée. Cette extension permet à un client « économiseur d'écran » externe de détecter quand l'image alternative doit être affichée et de fournir les graphiques.

Les implémentations actuelles de serveurs X fournissent généralement au moins une forme d'image « économiseur d'écran ». Historiquement, il s'agissait d'une copie du logo X dessinée sur le motif de fond racine. Cependant, de nombreux utilisateurs ont demandé un mécanisme leur permettant d'écrire des programmes d'économiseur d'écran offrant des capacités similaires à celles fournies par d'autres systèmes de fenêtrage. En particulier, ces utilisateurs souhaitent souvent pouvoir afficher des logos d'entreprise, des instructions sur la façon de réactiver l'écran, et des utilitaires de verrouillage automatique de l'écran. Cette extension fournit un moyen d'écrire de tels clients.

Hypothèses

Cette extension exporte la notion d'une fenêtre d'économiseur d'écran spéciale qui est mappée au-dessus de toutes les autres fenêtres sur un écran. Cette fenêtre a l'attribut override-redirect défini de sorte qu'elle ne soit pas soumise à la manipulation par le gestionnaire de fenêtres. De plus, l'identifiant X de la fenêtre n'est jamais retourné par les requêtes QueryTree sur la fenêtre racine, il n'est donc généralement pas visible par d'autres clients.

XScreenSaverQueryExtension retourne True si l'extension XScreenSaver est disponible sur l'affichage donné. Un client doit appeler XScreenSaverQueryExtension avant d'appeler toute autre fonction XScreenSaver afin de négocier une version de protocole compatible ; sinon, le client obtiendra un comportement indéfini (XScreenSaver peut fonctionner ou non).

Si l'extension est prise en charge, le numéro d'événement pour les événements ScreenSaverNotify est retourné dans la valeur pointée par event_base. Aucun autre erreur n'étant défini par cette extension, les résultats de error_base ne sont pas définis.

XScreenSaverQueryVersion retourne True si la requête a réussi ; les valeurs des versions de protocole majeure et mineure prises en charge par le serveur sont retournées dans major_version_return et minor_version_return.

XScreenSaverAllocInfo alloue et retourne une structure XScreenSaverInfo à utiliser dans les appels à XScreenSaverQueryInfo. Tous les champs de la structure sont initialisés à zéro. Si une mémoire insuffisante est disponible, NULL est retourné. Les résultats de cette routine peuvent être libérés en utilisant XFree.

XScreenSaverQueryInfo retourne des informations sur l'état actuel du serveur d'affichage dans saver_info et une valeur non nulle est retournée. Si l'extension n'est pas prise en charge, saver_info n'est pas modifié et 0 est retourné.

Le champ state spécifie si l'économiseur d'écran est actuellement actif ou non et comment la valeur til-or-since doit être interprétée :

Off
L'écran n'est pas actuellement sauvegardé ; til-or-since spécifie le nombre de millisecondes avant que l'économiseur d'écran ne s'active.
On
L'écran est actuellement sauvegardé ; til-or-since spécifie le nombre de millisecondes depuis l'activation de l'économiseur d'écran.
Disabled
L'économiseur d'écran est actuellement désactivé ; til-or-since est zéro.

Le champ kind spécifie le mécanisme qui est actuellement utilisé ou qui l'aurait été si l'écran était sauvegardé :

Blanked
Le signal vidéo vers le moniteur d'affichage a été désactivé.
Internal
Une image d'économiseur d'écran intégrée et dépendante du serveur a été affichée ; soit aucun client n'avait défini les attributs de la fenêtre d'économiseur d'écran, soit un autre client avait le serveur saisi lorsque l'économiseur d'écran s'est activé.
External
La fenêtre de l'économiseur d'écran a été mappée avec les attributs définis par un client utilisant la requête ScreenSaverSetAttributes.

Le champ idle spécifie le nombre de millisecondes depuis la dernière entrée reçue de l'utilisateur sur l'un des périphériques d'entrée.
Le champ event-mask spécifie quels événements d'économiseur d'écran, le cas échéant, ce client a demandés en utilisant ScreenSaverSelectInput.

XScreenSaverSelectInput demande que les événements liés à l'économiseur d'écran soient générés pour ce client. Si aucun bit n'est défini dans event-mask, aucun événement ne sera généré. Sinon, toute combinaison des bits suivants peut être définie :

ScreenSaverNotify
Si ce bit est défini, des événements ScreenSaverNotify sont générés chaque fois que l'économiseur d'écran est activé ou désactivé.
ScreenSaverCycle
Si ce bit est défini, des événements ScreenSaverNotify sont générés chaque fois que l'intervalle de cycle de l'économiseur d'écran est atteint.

XScreenSaverSetAttributes définit les attributs à utiliser la prochaine fois que l'économiseur d'écran externe sera activé. Si un autre client a actuellement les attributs définis, une erreur BadAccess est générée et la requête est ignorée.
Sinon, les attributs spécifiés sont vérifiés comme s'ils étaient utilisés dans une requête CreateWindow du cœur dont le parent est la racine. Le champ override-redirect est ignoré car il est implicitement défini à True. Si les attributs de fenêtre entraînent une erreur conformément aux règles de CreateWindow, la requête est ignorée.

NAME

XScreenSaverUnregister, XScreenSaverRegister, XScreenSaverGetRegistered, XScreenSaverSetAttributes, XScreenSaverUnsetAttributes, XScreenSaverQueryInfo, XScreenSaverSelectInput, XScreenSaverForce, XScreenSaverPause, XScreenSaverSuspend — interface to the X Screen Saver extension

SYNOPSIS

#include <X11/extensions/scrnsaver.h>
bool XScreenSaverQueryExtension(Display *dpy, int *event_base_return, int *error_base_return);
bool XScreenSaverQueryVersion(Display *dpy, int *major_version_return, int *minor_version_return);
XScreenSaverInfo *XScreenSaverAllocInfo(void);
bool XScreenSaverQueryInfo(Display *dpy, Drawable d, XScreenSaverInfo *info_return);
void XScreenSaverFreeInfo(XScreenSaverInfo *info);
void XScreenSaverSelectInput(Display *dpy, Drawable d, unsigned long mask);
void XScreenSaverSetAttributes(Display *dpy, Window w, XScreenSaverAttribute *attributes, int count);
void XScreenSaverUnsetAttributes(Display *dpy, Window w);
XScreenSaverAttribute *XScreenSaverGetAttributes(Display *dpy, Window w);
void XScreenSaverForce(Display *dpy, int preference);
void XScreenSaverPause(Display *dpy);
int XScreenSaverSuspend(Display *dpy, Bool suspend);
int XScreenSaverRegister(Display *dpy, Screen *screen, XID xid, const char *type);
int XScreenSaverUnregister(Display *dpy, Screen *screen);
int XScreenSaverGetRegistered(Display *dpy, Screen *screen, XID *xid_return, const char **type_return);

DESCRIPTION

The X Screen Saver extension allows clients to control the X screen saver and DPMS features. The extension defines several functions, structures, and event types.

XScreenSaverAllocInfo allocates and returns a pointer to an XScreenSaverInfo structure. This structure is used to hold information about the screen saver.

XScreenSaverQueryExtension checks if the screen saver extension is available on the specified display. If it is available, event_base_return and error_base_return are set to the appropriate base numbers for screen saver events and errors, and the function returns true. Otherwise, it returns false.

XScreenSaverQueryVersion queries the version of the screen saver extension supported by the server. If the server supports the requested version (or a compatible one), major_version_return and minor_version_return are set to the server's major and minor version numbers, and the function returns true. Otherwise, it returns false.

XScreenSaverQueryInfo retrieves information about the screen saver for the specified drawable's screen. The information is returned in the info_return structure. This structure contains the following members:

event-mask
Specifies which screen saver events the client wants to receive.
prefer-blanking
Indicates whether the client prefers the screen to be blanked when the screen saver is active. Values are True, False, or DontPrefer.
DontPrefer is a special value that means the client doesn't care whether the screen is blanked or not.
allow-exposures
Indicates whether the client allows exposures on the screen saver window. Values are True, False, or NotUseful.
NotUseful means that exposures are not useful to the client.
min-delay
Specifies the minimum delay in seconds between screen saver deactivations.
max-delay
Specifies the maximum delay in seconds between screen saver deactivations.
வுகள்-delay
Specifies the delay in seconds before the screen saver blanks the screen.
current-state
Indicates the current state of the screen saver: ScreenSaverActive, ScreenSaverDisabled, or ScreenSaverReset.
kind-of-screen-saver
Indicates the type of screen saver: ScreenSaverBlankWindow, ScreenSaverWindow, or ScreenSaverEmbedWindow.
pixmap-of-screen-saver
Specifies the pixmap to be used as the background for the screen saver window. If kind-of-screen-saver is ScreenSaverBlankWindow, this member is unused.

XScreenSaverFreeInfo frees the memory allocated for an XScreenSaverInfo structure.

XScreenSaverSelectInput registers the specified event mask for the screen saver extension. The client will receive events specified by the mask.

XScreenSaverSetAttributes sets the attributes for the screen saver window. The attributes argument is an array of XScreenSaverAttribute structures, and count is the number of attributes in the array. The XScreenSaverAttribute structure contains the following members:

valuator
The name of the attribute (e.g., "background-pixmap").
value
The value of the attribute.

XScreenSaverUnsetAttributes instructs the server to discard any previously set screen saver window attributes by this client.

XScreenSaverGetAttributes retrieves the attributes of the screen saver window. It returns an array of XScreenSaverAttribute structures representing the current attributes. The returned array must be freed using XFree.

XScreenSaverForce attempts to activate or deactivate the screen saver. If preference is ScreenSaverActive, the screen saver is activated. If preference is ScreenSaverReset, the screen saver is deactivated and its internal state is reset.

XScreenSaverPause pauses the screen saver. This function is equivalent to calling XScreenSaverForce with a value of ScreenSaverReset.

The server is free to copy the background-pixmap or cursor resources or to use them in place; therefore, the effect of changing the contents of those resources is undefined. If the specified colormap no longer exists when the screen saver activates, the parent's colormap is used instead. If no errors are generated by this request, any previous screen saver window attributes set by this client are released.
When the screen saver next activates and the server is not grabbed by another client, the screen saver window is created, if necessary, and set to the specified attributes and events are generated as usual. The colormap associated with the screen saver window is installed. Finally, the screen saver window is mapped.
The window remains mapped and at the top of the stacking order until the screen saver is deactivated in response to activity on any of the user input devices, a ForceScreenSaver request with a value of Reset, or any request that would cause the window to be unmapped.
If the screen saver activates while the server is grabbed by another client, the internal saver mechanism is used. The ForceScreenSaver request may be used with a value of Active to deactivate the internal saver and activate the external saver.
If the screen saver client's connection to the server is broken while the screen saver is activated and the client's close down mode has not been RetainPermanent or RetainTemporary, the current screen saver is deactivated and the internal screen saver is immediately activated.
When the screen saver deactivates, the screen saver window's colormap is uninstalled and the window is unmapped (except as described below). The screen saver XID is disassociated with the window and the server may, but is not required to, destroy the window along with any children.
When the screen saver is being deactivated and then immediately reactivated (such as when switching screen savers), the server may leave the screen saver window mapped (typically to avoid generating exposures).

XScreenSaverUnsetAttributes instructs the server to discard any previous screen saver window attributes set by this client.

XScreenSaverRegister stores the given XID in the _SCREEN_SAVER_ID property (of the given type) on the root window of the specified screen. It returns zero if an error is encountered and the property is not changed, otherwise it returns non-zero.

XScreenSaverUnregister removes any _SCREEN_SAVER_ID from the root window of the specified screen. It returns zero if an error is encountered and the property is changed, otherwise it returns non-zero.

XScreenSaverGetRegistered returns the XID and type stored in the _SCREEN_SAVER_ID property on the root window of the specified screen. It returns zero if an error is encountered or if the property does not exist or is not of the correct format; otherwise it returns non-zero.

XScreenSaverSuspend temporarily suspends the screensaver and DPMS timer if suspend is 'True', and restarts the timer if suspend is 'False'.
This function should be used by applications that don't want the screensaver or DPMS to become activated while they're for example in the process of playing a media sequence, or are otherwise continuously presenting visual information to the user while in a non-interactive state. This function is not intended to be called by an external screensaver application.
If XScreenSaverSuspend is called multiple times with suspend set to 'True', it must be called an equal number of times with suspend set to 'False' in order for the screensaver timer to be restarted. This request has no affect if a client tries to resume the screensaver without first having suspended it. XScreenSaverSuspend can thus not be used by one client to resume the screensaver if it's been suspended by another client.
If a client that has suspended the screensaver becomes disconnected from the X server, the screensaver timer will automatically be restarted, unless it's still suspended by another client. Suspending the screensaver timer doesn't prevent the screensaver from being forcibly activated with the ForceScreenSaver request, or a DPMS mode from being set with the DPMSForceLevel request.
XScreenSaverSuspend also doesn't deactivate the screensaver or DPMS if either is active at the time the request to suspend them is received by the X server. But once they've been deactivated, they won't automatically be activated again, until the client has canceled the suspension.

ERRORS

XScreenSaverSelectInput, XScreenSaverQueryInfo, XScreenSaverSetAttributes, and XScreenSaverUnsetAttributes will generate a BadDrawable error if drawable is not a valid drawable identifier. If any undefined bits are set in event-mask, a BadValue error is generated by XScreenSaverSelectInput.

AVAILABILITY

XScreenSaverSuspend is available in version 1.1 and later versions of the X Screen Saver Extension. Version 1.1 was first released with X11R7.1.
