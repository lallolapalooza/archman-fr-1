Paquet: libx11

Licences: MIT AND X11

XChangeWindowAttributes(3) FONCTIONS XLIB XChangeWindowAttributes(3)

NOM

XChangeWindowAttributes, XSetWindowBackground, XSetWindowBackgroundPixmap, XSetWindowBorder, XSetWindowBorderPixmap, XSetWindowColormap - changer les attributs d'une fenêtre

SYNTAXE

int XChangeWindowAttributes(Display *display, Window w, unsigned long valuemask, XSetWindowAttributes *attributes);

int XSetWindowBackground(Display *display, Window w, unsigned long background_pixel);

int XSetWindowBackgroundPixmap(Display *display, Window w, Pixmap background_pixmap);

int XSetWindowBorder(Display *display, Window w, unsigned long border_pixel);

int XSetWindowBorderPixmap(Display *display, Window w, Pixmap border_pixmap);

int XSetWindowColormap(Display *display, Window w, Colormap colormap);

ARGUMENTS

attributes
Spécifie la structure à partir de laquelle les valeurs (comme spécifié par le masque de valeur) doivent être prises. Le masque de valeur doit avoir les bits appropriés définis pour indiquer quels attributs ont été définis dans la structure.
background_pixel
Spécifie le pixel à utiliser pour l'arrière-plan.
background_pixmap
Spécifie la pixmap d'arrière-plan, ParentRelative, ou None.
border_pixel
Spécifie l'entrée dans la table de couleurs.
border_pixmap
Spécifie la pixmap de bordure ou CopyFromParent.
display
Spécifie la connexion au serveur X.
valuemask
Spécifie quels attributs de fenêtre sont définis dans l'argument attributes. Ce masque est le OU inclusif bit à bit des bits valides du masque d'attribut. Si valuemask est zéro, les attributs sont ignorés et ne sont pas référencés.
w
Spécifie la fenêtre.
colormap
Spécifie la table de couleurs.

DESCRIPTION

Selon le valuemask, la fonction XChangeWindowAttributes utilise les attributs de fenêtre dans la structure XSetWindowAttributes pour changer les attributs de fenêtre spécifiés. Changer l'arrière-plan ne provoque pas le changement du contenu de la fenêtre. Pour repeindre la fenêtre et son arrière-plan, utilisez XClearWindow. Définir la bordure ou changer l'arrière-plan de manière à ce que l'origine de la tuile de bordure change provoque la repeinture de la bordure. Changer l'arrière-plan d'une fenêtre racine à None ou ParentRelative restaure la pixmap d'arrière-plan par défaut. Changer la bordure d'une fenêtre racine à CopyFromParent restaure la pixmap de bordure par défaut. Changer la gravité de la fenêtre n'affecte pas la position actuelle de la fenêtre. Changer le backing-store d'une fenêtre obstruée à WhenMapped ou Always, ou changer les backing-planes, backing-pixel, ou save-under d'une fenêtre mappée peut n'avoir aucun effet immédiat. Changer la table de couleurs d'une fenêtre (c'est-à-dire, définir une nouvelle table, pas changer le contenu de la table existante) génère un événement ColormapNotify. Changer la table de couleurs d'une fenêtre visible peut n'avoir aucun effet immédiat sur l'écran car la table peut ne pas être installée (voir XInstallColormap). Changer le curseur d'une fenêtre racine à None restaure le curseur par défaut. Dans la mesure du possible, il est encouragé de partager les tables de couleurs.

Plusieurs clients peuvent sélectionner des entrées sur la même fenêtre. Leurs masques d'événements sont gérés séparément. Lorsqu'un événement est généré, il est rapporté à tous les clients intéressés. Cependant, un seul client à la fois peut sélectionner SubstructureRedirectMask, ResizeRedirectMask, et ButtonPressMask. Si un client tente de sélectionner l'un de ces masques d'événements et qu'un autre client en a déjà sélectionné un, une erreur BadAccess en résulte. Il n'y a qu'un seul masque do-not-propagate-mask pour une fenêtre, pas un par client.

XChangeWindowAttributes peut générer les erreurs BadAccess, BadColor, BadCursor, BadMatch, BadPixmap, BadValue, et BadWindow.

La fonction XSetWindowBackground définit l'arrière-plan de la fenêtre à la valeur de pixel spécifiée. Changer l'arrière-plan ne provoque pas le changement du contenu de la fenêtre. XSetWindowBackground utilise une pixmap de taille indéfinie remplie de la valeur de pixel que vous avez passée. Si vous essayez de changer l'arrière-plan d'une fenêtre InputOnly, une erreur BadMatch en résulte.

XSetWindowBackground peut générer les erreurs BadMatch et BadWindow.

La fonction XSetWindowBackgroundPixmap définit la pixmap d'arrière-plan de la fenêtre à la pixmap spécifiée. La pixmap d'arrière-plan peut être libérée immédiatement si aucune référence explicite supplémentaire à celle-ci ne doit être faite. Si ParentRelative est spécifié, la pixmap d'arrière-plan du parent de la fenêtre est utilisée, ou sur la fenêtre racine, l'arrière-plan par défaut est restauré. Si vous essayez de changer l'arrière-plan d'une fenêtre InputOnly, une erreur BadMatch en résulte. Si l'arrière-plan est défini à None, la fenêtre n'a pas d'arrière-plan défini.

XSetWindowBackgroundPixmap peut générer les erreurs BadMatch, BadPixmap, et BadWindow.

La fonction XSetWindowBorder définit la bordure de la fenêtre à la valeur de pixel que vous spécifiez. Si vous tentez d'effectuer cela sur une fenêtre InputOnly, une erreur BadMatch en résulte.

XSetWindowBorder peut générer les erreurs BadMatch et BadWindow.

La fonction XSetWindowBorderPixmap définit la pixmap de bordure de la fenêtre à la pixmap que vous spécifiez. La pixmap de bordure peut être libérée immédiatement si aucune référence explicite supplémentaire à celle-ci ne doit être faite. Si vous spécifiez CopyFromParent, une copie de la pixmap de bordure de la fenêtre parente est utilisée. Si vous tentez d'effectuer cela sur une fenêtre InputOnly, une erreur BadMatch en résulte.

XSetWindowBorderPixmap peut générer les erreurs BadMatch, BadPixmap, et BadWindow.

La fonction XSetWindowColormap définit la table de couleurs spécifiée de la fenêtre spécifiée. La table de couleurs doit avoir le même type visuel que la fenêtre, sinon une erreur BadMatch en résulte.

XSetWindowColormap peut générer les erreurs BadColor, BadMatch, et BadWindow.

DIAGNOSTICS

BadAccess
Un client a tenté de libérer une entrée de table de couleurs qu'il n'avait pas déjà allouée.
BadAccess
Un client a tenté d'écrire dans une entrée de table de couleurs en lecture seule.
BadColor
Une valeur pour un argument Colormap ne nomme pas une Colormap définie.
BadCursor
Une valeur pour un argument Cursor ne nomme pas un Cursor défini.
BadMatch
Un argument ou une paire d'arguments a le type et la plage corrects mais ne correspond pas d'une autre manière requise par la requête.
BadMatch
Une fenêtre InputOnly verrouille cet attribut.
BadPixmap
Une valeur pour un argument Pixmap ne nomme pas une Pixmap définie.
BadValue
Une valeur numérique se situe en dehors de la plage de valeurs acceptées par la requête. Sauf si une plage spécifique est spécifiée pour un argument, la plage complète définie par le type de l'argument est acceptée. Tout argument défini comme un ensemble d'alternatives peut générer cette erreur.
BadWindow
Une valeur pour un argument Window ne nomme pas une Window définie.

XSetWindowBackgroundPixmap(3) X Functions XSetWindowBackgroundPixmap(3)

NAME

XSetWindowBackgroundPixmap, XSetWindowBorderPixmap — set window background and border

SYNTAX

#include <X11/Xlib.h>

int XSetWindowBackgroundPixmap (Display *display, Window w, Pixmap pixmap);
int XSetWindowBorderPixmap (Display *display, Window w, Pixmap pixmap);

ARGUMENTS

display
Specifies the connection to the X server.
w
Specifies the window.
pixmap
Specifies the pixmap to be used for the background or border. If None, the background is cleared and the default background is used. If ParentRelative, the pixmap is the same as the parent window's background pixmap. If the pixmap is a valid pixmap, it is used.

DESCRIPTION

XSetWindowBackgroundPixmap sets the background of the specified window to the specified pixmap. The pixmap must be a valid pixmap, or None, or ParentRelative. If the pixmap is None, the background is cleared and the default background is used. If the pixmap is ParentRelative, the pixmap is the same as the parent window's background pixmap. If the pixmap is a valid pixmap, it is used.

XSetWindowBorderPixmap sets the border of the specified window to the specified pixmap. The pixmap must be a valid pixmap, or None, or ParentRelative. If the pixmap is None, the border is reset to the default border. If the pixmap is ParentRelative, the pixmap is the same as the parent window's background pixmap.

Both functions return a non-zero status if they succeed, and 0 if they fail. On failure, the X server does not send an error event.

DIAGNOSTICS

BadPixmap, BadWindow, BadMatch. These errors are generated if a value for a required argument is invalid.
