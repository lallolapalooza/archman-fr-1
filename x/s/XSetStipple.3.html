NOM

XSetTile, XSetStipple, XSetTSOrigin - Routines utilitaires GC

SYNTAXE

int XSetTile(Display *display, GC gc, Pixmap tile);

int XSetStipple(Display *display, GC gc, Pixmap stipple);

int XSetTSOrigin(Display *display, GC gc, int ts_x_origin, int ts_y_origin);

ARGUMENTS

display
Spécifie la connexion au serveur X.
gc
Spécifie le GC.
stipple
Spécifie le pochoir que vous souhaitez définir pour le GC spécifié.
tile
Spécifie le motif de remplissage que vous souhaitez définir pour le GC spécifié.
ts_x_origin

ts_y_origin
Spécifient les coordonnées x et y de l'origine du motif et du pochoir.

DESCRIPTION

La fonction XSetTile définit le motif de remplissage dans le GC spécifié. Le motif et le GC doivent avoir la même profondeur, sinon une erreur BadMatch se produit.

XSetTile peut générer les erreurs BadAlloc, BadGC, BadMatch et BadPixmap.

La fonction XSetStipple définit le pochoir dans le GC spécifié. Le pochoir doit avoir une profondeur de un, sinon une erreur BadMatch se produit.

XSetStipple peut générer les erreurs BadAlloc, BadGC, BadMatch et BadPixmap.

La fonction XSetTSOrigin définit l'origine du motif/pochoir dans le GC spécifié. Lorsque les requêtes graphiques demandent un motif ou un pochoir, l'origine du parent sera interprétée par rapport à la fenêtre de destination spécifiée dans la requête graphique.

XSetTSOrigin peut générer les erreurs BadAlloc et BadGC.

DIAGNOSTICS

BadAlloc
Le serveur n'a pas réussi à allouer la ressource ou la mémoire serveur demandée.
BadGC
Une valeur d'argument GContext ne nomme pas un GContext défini.
BadMatch
Un argument ou une paire d'arguments a le type et la plage corrects mais ne correspond pas d'une autre manière requise par la demande.
BadPixmap
Une valeur d'argument Pixmap ne nomme pas un Pixmap défini.
