NOM

XScreenSaver - Bibliothèque client d'extension X11 pour l'économiseur d'écran

SYNTAXE

#include <X11/extensions/scrnsaver.h>

typedef struct {
    Window window;                /* fenêtre de l'économiseur d'écran */
    int state;                    /* ScreenSaver{Off,On,Disabled} */
    int kind;                     /* ScreenSaver{Blanked,Internal,External} */
    unsigned long til_or_since;   /* millisecondes */
    unsigned long idle;           /* millisecondes */
    unsigned long eventMask;      /* événements */
} XScreenSaverInfo;

typedef struct {
    int type;               /* de l'événement */
    unsigned long serial;   /* # de la dernière requête traitée par le serveur */
    Bool send_event;        /* vrai si ceci vient d'une requête SendEvent */
    Display *display;       /* Display depuis lequel l'événement a été lu */
    Window window;          /* fenêtre de l'économiseur d'écran */
    Window root;            /* fenêtre racine de l'écran de l'événement */
    int state;              /* ScreenSaver{Off,On,Cycle} */
    int kind;               /* ScreenSaver{Blanked,Internal,External} */
    Bool forced;            /* étendue de la nouvelle région */
    Time time;              /* horodatage de l'événement */
} XScreenSaverNotifyEvent;

DESCRIPTION

Le système de fenêtrage X fournit un support pour changer l'image sur l'écran après une période d'inactivité définie par l'utilisateur afin d'éviter de brûler les phosphores du tube cathodique. Cependant, aucune interface n'est fournie pour que l'utilisateur contrôle l'image affichée. Cette extension permet à un client externe de type « économiseur d'écran » de détecter quand l'image alternative doit être affichée et de fournir les graphiques.

Les implémentations actuelles de serveurs X fournissent généralement au moins une forme d'image « économiseur d'écran ». Historiquement, il s'agissait d'une copie du logo X dessinée sur le fond de la fenêtre racine. Cependant, de nombreux utilisateurs ont demandé un mécanisme leur permettant d'écrire des programmes d'économiseur d'écran offrant des fonctionnalités similaires à celles fournies par d'autres systèmes de fenêtrage. En particulier, ces utilisateurs souhaitent souvent pouvoir afficher des logos d'entreprise, des instructions sur la façon de réactiver l'écran et des utilitaires de verrouillage d'écran automatique. Cette extension fournit un moyen d'écrire de tels clients.

Hypothèses

Cette extension exporte la notion d'une fenêtre d'économiseur d'écran spéciale qui est mappée au-dessus de toutes les autres fenêtres sur un écran. Cette fenêtre a l'attribut override-redirect défini de sorte qu'elle ne soit pas soumise à la manipulation par le gestionnaire de fenêtres. De plus, l'identifiant X de la fenêtre n'est jamais retourné par les requêtes QueryTree sur la fenêtre racine, elle n'est donc généralement pas visible par les autres clients.

XScreenSaverQueryExtension renvoie True si l'extension XScreenSaver est disponible sur l'écran donné. Un client doit appeler XScreenSaverQueryExtension avant d'appeler toute autre fonction XScreenSaver afin de négocier une version de protocole compatible ; sinon, le client obtiendra un comportement indéfini (XScreenSaver peut fonctionner ou non).

Si l'extension est prise en charge, le numéro d'événement pour les événements ScreenSaverNotify est retourné dans la valeur pointée par event_base. Aucun erreur supplémentaire n'étant défini par cette extension, les résultats de error_base ne sont pas définis.

XScreenSaverQueryVersion renvoie True si la requête a réussi ; les valeurs des versions majeures et mineures du protocole prises en charge par le serveur sont retournées dans major_version_return et minor_version_return.

XScreenSaverAllocInfo alloue et retourne une structure XScreenSaverInfo à utiliser dans les appels à XScreenSaverQueryInfo. Tous les champs de la structure sont initialisés à zéro. Si une mémoire insuffisante est disponible, NULL est retourné. Les résultats de cette routine peuvent être libérés à l'aide de XFree.

XScreenSaverQueryInfo retourne des informations sur l'état actuel du serveur d'écran dans saver_info et une valeur non nulle est retournée. Si l'extension n'est pas prise en charge, saver_info n'est pas modifié et 0 est retourné.

Le champ state spécifie si l'économiseur d'écran est actuellement actif ou non et comment la valeur til-or-since doit être interprétée :

Off
L'écran n'est pas actuellement protégé ; til-or-since spécifie le nombre de millisecondes avant que l'économiseur d'écran ne s'active.
On
L'écran est actuellement protégé ; til-or-since spécifie le nombre de millisecondes depuis l'activation de l'économiseur d'écran.
Disabled
L'économiseur d'écran est actuellement désactivé ; til-or-since est zéro.

Le champ kind spécifie le mécanisme qui est actuellement utilisé ou qui aurait été utilisé si l'écran avait été protégé :

Blanked
Le signal vidéo vers le moniteur d'affichage a été désactivé.
Internal
Une image d'économiseur d'écran intégrée et dépendante du serveur a été affichée ; soit aucun client n'avait défini les attributs de la fenêtre d'économiseur d'écran, soit un autre client avait saisi le serveur lorsque l'économiseur d'écran s'est activé.
External
La fenêtre de l'économiseur d'écran a été mappée avec les attributs définis par un client à l'aide de la requête ScreenSaverSetAttributes.

Le champ idle spécifie le nombre de millisecondes depuis la dernière entrée reçue de l'utilisateur sur l'un des périphériques d'entrée.
Le champ event-mask spécifie quels événements liés à l'économiseur d'écran, le cas échéant, ce client a demandés en utilisant ScreenSaverSelectInput.

XScreenSaverSelectInput demande que des événements liés à l'économiseur d'écran soient générés pour ce client. Si aucun bit n'est défini dans event-mask, alors aucun événement ne sera généré. Sinon, toute combinaison des bits suivants peut être définie :

ScreenSaverNotify
Si ce bit est défini, des événements ScreenSaverNotify sont générés chaque fois que l'économiseur d'écran est activé ou désactivé.
ScreenSaverCycle
Si ce bit est défini, des événements ScreenSaverNotify sont générés chaque fois que l'intervalle de cycle de l'économiseur d'écran est atteint.

XScreenSaverSetAttributes définit les attributs à utiliser la prochaine fois que l'économiseur d'écran externe sera activé. Si un autre client a actuellement les attributs définis, une erreur BadAccess est générée et la requête est ignorée.
Sinon, les attributs spécifiés sont vérifiés comme s'ils étaient utilisés dans une requête core CreateWindow dont le parent est la racine.       NAME

      XScreenSaverSuspend, XScreenSaverUnsetAttributes, XScreenSaverRegister, XScreenSaverUnregister, XScreenSaverGetRegistered, XScreenSaverSuspend - control the screensaver

      LIBRARY

      XScreenSaver (libXScrnSaver)

      SYNOPSIS

      #include <X11/extensions/scrnsaver.h>

      Bool XScreenSaverQueryExtension(Display *dpy, int *event_base, int *error_base);

      XScreenSaverInfo *XScreenSaverQueryInfo(Display *dpy, Window d, XScreenSaverInfo **ret_info);

      Status XScreenSaverSelectInput(Display *dpy, Window d, unsigned long mask);

      Status XScreenSaverSetAttributes(Display *dpy, Window d, int x, int y, unsigned int width, unsigned int height, int border, int depth, int scrn, Colormap cmap, Pixmap back_pixmap, Cursor cursor);

      Status XScreenSaverUnsetAttributes(Display *dpy, Window d);

      Status XScreenSaverRegister(Display *dpy, Screen *screen, Window xid, XID type);

      Status XScreenSaverUnregister(Display *dpy, Screen *screen);

      Bool XScreenSaverGetRegistered(Display *dpy, Screen *screen, Window *xid_ret, XID *type_ret);

      Bool XScreenSaverSuspend(Display *dpy, Bool suspend);

      DESCRIPTION

      The X Screen Saver Extension provides a mechanism for applications to interact with the X server's screen saver and screen locker. These functions allow clients to query the state of the screen saver, set attributes for the screen saver window, and suspend or resume the screen saver and DPMS timers.

      XScreenSaverQueryExtension checks if the screen saver extension is present on the server. If it is, it returns the base event code and error code for the extension. It returns False if the extension is not present.

      XScreenSaverQueryInfo returns information about the current state of the screen saver for the specified screen. It returns a pointer to a static XScreenSaverInfo structure, which is also copied into the structure pointed to by ret_info. The XScreenSaverInfo structure contains the following fields:

      • int event_state: The current state of the screen saver. This can be ScreenSaverOn, ScreenSaverDisabled, or ScreenSaverOff.
      • int kind: The type of screen saver. This can be ScreenSaverBlanked (screen is blanked), ScreenSaverInternal (internal saver is running), or ScreenSaverExternal (external saver is running).
      • Bool til_since_user_input: True if there has been user input since the screen saver was activated.
      • int idle: The number of seconds the server has been idle.
      • int event_delay: The number of seconds until the screen saver activates.

      XScreenSaverSelectInput tells the server which screen saver events the client wishes to receive. The mask is a bitmask composed of ScreenSaverNotifyMask. Currently, only ScreenSaverNotifyMask is defined, and it selects events that occur when the screen saver state changes.

      XScreenSaverSetAttributes sets the attributes for the screen saver window. The server is free to copy the background-pixmap or cursor resources or to use them in place; therefore, the effect of changing the contents of those resources is undefined. If the specified colormap no longer exists when the screen saver activates, the parent's colormap is used instead. If no errors are generated by this request, any previous screen saver window attributes set by this client are released.

      When the screen saver next activates and the server is not grabbed by another client, the screen saver window is created, if necessary, and set to the specified attributes and events are generated as usual. The colormap associated with the screen saver window is installed. Finally, the screen saver window is mapped.

      The window remains mapped and at the top of the stacking order until the screen saver is deactivated in response to activity on any of the user input devices, a ForceScreenSaver request with a value of Reset, or any request that would cause the window to be unmapped.

      If the screen saver activates while the server is grabbed by another client, the internal saver mechanism is used. The ForceScreenSaver request may be used with a value of Active to deactivate the internal saver and activate the external saver.

      If the screen saver client's connection to the server is broken while the screen saver is activated and the client's close down mode has not been RetainPermanent or RetainTemporary, the current screen saver is deactivated and the internal screen saver is immediately activated.

      When the screen saver deactivates, the screen saver window's colormap is uninstalled and the window is unmapped (except as described below). The screen saver XID is disassociated with the window and the server may, but is not required to, destroy the window along with any children.

      When the screen saver is being deactivated and then immediately reactivated (such as when switching screen savers), the server may leave the screen saver window mapped (typically to avoid generating exposures).

      XScreenSaverUnsetAttributes instructs the server to discard any previous screen saver window attributes set by this client.

      XScreenSaverRegister stores the given XID in the _SCREEN_SAVER_ID property (of the given type) on the root window of the specified screen. It returns zero if an error is encountered and the property is not changed, otherwise it returns non-zero.

      XScreenSaverUnregister removes any _SCREEN_SAVER_ID from the root window of the specified screen. It returns zero if an error is encountered and the property is changed, otherwise it returns non-zero.

      XScreenSaverGetRegistered returns the XID and type stored in the _SCREEN_SAVER_ID property on the root window of the specified screen. It returns zero if an error is encountered or if the property does not exist or is not of the correct format; otherwise it returns non-zero.

      XScreenSaverSuspend temporarily suspends the screensaver and DPMS timer if suspend is 'True', and restarts the timer if suspend is 'False'.

      This function should be used by applications that don't want the screensaver or DPMS to become activated while they're for example in the process of playing a media sequence, or are otherwise continuously presenting visual information to the user while in a non-interactive state. This function is not intended to be called by an external screensaver application.

      If XScreenSaverSuspend is called multiple times with suspend set to 'True', it must be called an equal number of times with suspend set to 'False' in order for the screensaver timer to be restarted. This request has no affect if a client tries to resume the screensaver without first having suspended it. XScreenSaverSuspend can thus not be used by one client to resume the screensaver if it's been suspended by another client.

      If a client that has suspended the screensaver becomes disconnected from the X server, the screensaver timer will automatically be restarted, unless it's still suspended by another client. Suspending the screensaver timer doesn't prevent the screensaver from being forcibly activated with the ForceScreenSaver request, or a DPMS mode from being set with the DPMSForceLevel request.

      XScreenSaverSuspend also doesn't deactivate the screensaver or DPMS if either is active at the time the request to suspend them is received by the X server. But once they've been deactivated, they won't automatically be activated again, until the client has canceled the suspension.

      ERRORS

      XScreenSaverSelectInput, XScreenSaverQueryInfo, XScreenSaverSetAttributes, and XScreenSaverUnsetAttributes will generate a BadDrawable error if drawable is not a valid drawable identifier. If any undefined bits are set in event-mask, a BadValue error is generated by XScreenSaverSelectInput.

      AVAILABILITY

      XScreenSaverSuspend is available in version 1.1 and later versions of the X Screen Saver Extension. Version 1.1 was first released with X11R7.1.
