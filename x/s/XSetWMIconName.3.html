XSetWMIconName(3)

Paquet: libx11

Licences: MIT AND X11

XSetWMIconName(3) FONCTIONS XLIB XSetWMIconName(3)

NOM

XSetWMIconName, XGetWMIconName, XSetIconName, XGetIconName - définir ou lire la propriété WM_ICON_NAME d'une fenêtre

SYNTAXE

void XSetWMIconName(Display *display, Window w, XTextProperty *text_prop);

Status XGetWMIconName(Display *display, Window w, XTextProperty *text_prop_return);

int XSetIconName(Display *display, Window w, _Xconst char *icon_name);

Status XGetIconName(Display *display, Window w, char **icon_name_return);

ARGUMENTS

display
Spécifie la connexion au serveur X.
icon_name
Spécifie le nom de l'icône, qui doit être une chaîne terminée par un nul.
icon_name_return
Retourne le nom de l'icône de la fenêtre, qui est une chaîne terminée par un nul.
text_prop
Spécifie la structure XTextProperty à utiliser.
text_prop_return
Retourne la structure XTextProperty.
w
Spécifie la fenêtre.

DESCRIPTION

La fonction utilitaire XSetWMIconName appelle XSetTextProperty pour définir la propriété WM_ICON_NAME.

La fonction utilitaire XGetWMIconName appelle XGetTextProperty pour obtenir la propriété WM_ICON_NAME. Elle retourne un statut non nul en cas de succès ; sinon, elle retourne un statut nul.

La fonction XSetIconName définit le nom à afficher dans l'icône d'une fenêtre.

XSetIconName peut générer les erreurs BadAlloc et BadWindow.

La fonction XGetIconName retourne le nom à afficher dans l'icône de la fenêtre spécifiée. Si elle réussit, elle retourne un statut non nul ; sinon, si aucun nom d'icône n'a été défini pour la fenêtre, elle retourne zéro. Si vous n'avez jamais attribué de nom à la fenêtre, XGetIconName définit icon_name_return à NULL. Si les données retournées par le serveur sont encodées en Latin Portable Character Encoding, alors la chaîne retournée est en Host Portable Character Encoding. Sinon, le résultat est dépendant de l'implémentation. Une fois terminé, un client doit libérer la chaîne du nom d'icône en utilisant XFree.

XGetIconName peut générer une erreur BadWindow.

PROPRIÉTÉS

WM_ICON_NAME
Le nom à utiliser dans une icône.

DIAGNOSTICS

BadAlloc
Le serveur n'a pas pu allouer la ressource demandée ou la mémoire du serveur.
BadWindow
Une valeur pour un argument de type Window ne nomme pas une fenêtre définie.
