XSetWMHints(3)

Paquet: libx11

Licences: MIT AND X11

XAllocWMHints(3) FONCTIONS XLIB XAllocWMHints(3)

NOM

XAllocWMHints, XSetWMHints, XGetWMHints, XWMHints - alloue une structure d'indices de gestionnaire de fenêtres et définit ou lit la propriété WM_HINTS d'une fenêtre.

SYNTAXE

XWMHints *XAllocWMHints(void);

int XSetWMHints(Display *display, Window w, XWMHints *wmhints);

XWMHints *XGetWMHints(Display *display, Window w);

ARGUMENTS

display
Spécifie la connexion au serveur X.
w
Spécifie la fenêtre.
wmhints
Spécifie la structure XWMHints à utiliser.

DESCRIPTION

La fonction XAllocWMHints alloue et retourne un pointeur vers une structure XWMHints. Notez que tous les champs de la structure XWMHints sont initialisés à zéro. Si la mémoire disponible est insuffisante, XAllocWMHints retourne NULL. Pour libérer la mémoire allouée à cette structure, utilisez XFree.

La fonction XSetWMHints définit les indices du gestionnaire de fenêtres qui incluent des informations et une position sur l'icône, l'état initial de la fenêtre, et si l'application dépend du gestionnaire de fenêtres pour recevoir l'entrée clavier.

XSetWMHints peut générer des erreurs BadAlloc et BadWindow.

La fonction XGetWMHints lit les indices du gestionnaire de fenêtres et retourne NULL si aucune propriété WM_HINTS n'a été définie sur la fenêtre, ou retourne un pointeur vers une structure XWMHints en cas de succès. Une fois que vous n'avez plus besoin des données, libérez l'espace utilisé en appelant XFree.

XGetWMHints peut générer une erreur BadWindow.

PROPRIÉTÉS

WM_HINTS
Indices supplémentaires définis par le client pour être utilisés par le gestionnaire de fenêtres. Le type C de cette propriété est XWMHints.

STRUCTURES

La structure XWMHints contient :

/* bits du masque des indices de gestionnaire de fenêtres */

#define InputHint (1L << 0)
#define StateHint (1L << 1)
#define IconPixmapHint (1L << 2)
#define IconWindowHint (1L << 3)
#define IconPositionHint (1L << 4)
#define IconMaskHint (1L << 5)
#define WindowGroupHint (1L << 6)
#define XUrgencyHint (1L << 8)
#define AllHints (InputHint| StateHint| IconPixmapHint| IconWindowHint| IconPositionHint| IconMaskHint| WindowGroupHint) 
/* Valeurs */
typedef struct {
        long flags;     /* indique quels champs dans cette structure sont définis */
        Bool input;     /* cette application dépend-elle du gestionnaire de fenêtres pour
                        recevoir l'entrée clavier ? */
        int initial_state;      /* voir ci-dessous */
        Pixmap icon_pixmap;     /* pixmap à utiliser comme icône */
        Window icon_window;     /* fenêtre à utiliser comme icône */
        int icon_x, icon_y;     /* position initiale de l'icône */
        Pixmap icon_mask;       /* pixmap à utiliser comme masque pour icon_pixmap */
        XID window_group;       /* id du groupe de fenêtres liées */
        /* cette structure peut être étendue à l'avenir */
} XWMHints;

Le membre input est utilisé pour communiquer au gestionnaire de fenêtres le modèle d'entrée utilisé par l'application. Les applications qui attendent une entrée mais ne définissent jamais explicitement le focus sur aucune de leurs sous-fenêtres (c'est-à-dire utilisent le modèle "push" de gestion du focus), comme les applications de style X Version 10 qui utilisent le focus piloté par l'espace de travail, devraient définir ce membre à True. De même, les applications qui définissent le focus d'entrée sur leurs sous-fenêtres uniquement lorsqu'il est donné à leur fenêtre de niveau supérieur par un gestionnaire de fenêtres devraient également définir ce membre à True. Les applications qui ne s'attendent jamais à recevoir d'entrée clavier devraient également définir ce membre à False. Les applications qui gèrent elles-mêmes leur focus d'entrée en définissant explicitement le focus sur l'une de leurs sous-fenêtres chaque fois qu'elles veulent une entrée clavier (c'est-à-dire utilisent le modèle "pull" de gestion du focus) devraient définir ce membre à False.

Les gestionnaires de fenêtres en mode "pull" devraient permettre aux applications en mode "push" de recevoir l'entrée en définissant le focus d'entrée sur les fenêtres de niveau supérieur des applications dont le membre input est True. Les gestionnaires de fenêtres en mode "push" devraient s'assurer que les applications en mode "pull" ne les perturbent pas en réinitialisant le focus d'entrée à PointerRoot lorsque c'est approprié (par exemple, chaque fois qu'une application dont le membre input est False définit le focus d'entrée sur l'une de ses sous-fenêtres).

Les définitions pour le drapeau initial_state sont :

#define WithdrawnState 0
#define NormalState 1 /* la plupart des applications démarrent dans cet état */
#define IconicState 3 /* l'application veut démarrer sous forme d'icône */
Le masque icon_mask spécifie quels pixels de l'icon_pixmap doivent être utilisés comme icône. Ceci permet des icônes non rectangulaires. L'icon_pixmap et l'icon_mask doivent tous deux être des bitmaps. L'icon_window permet à une application de fournir une fenêtre à utiliser comme icône pour les gestionnaires de fenêtres qui supportent une telle utilisation. Le window_group vous permet de spécifier que cette fenêtre appartient à un groupe d'autres fenêtres. Par exemple, si une seule application manipule plusieurs fenêtres de niveau supérieur, cela vous permet de fournir suffisamment d'informations pour qu'un gestionnaire de fenêtres puisse iconifier toutes les fenêtres plutôt qu'une seule.

Le drapeau UrgencyHint, s'il est défini dans le champ flags, indique que le client juge le contenu de la fenêtre urgent, nécessitant une réponse rapide de l'utilisateur. Le gestionnaire de fenêtres fera des efforts pour attirer l'attention de l'utilisateur sur cette fenêtre tant que ce drapeau est défini. Le client doit fournir un moyen par lequel l'utilisateur peut faire effacer le drapeau d'urgence (en atténuant la condition qui a rendu la fenêtre urgente ou en éteignant simplement l'alarme) ou la fenêtre doit être retirée.

DIAGNOSTICS

BadAlloc
Le serveur n'a pas pu allouer la ressource ou la mémoire serveur demandée.
BadWindow
Une valeur pour un argument Window ne nomme pas une Fenêtre définie.
