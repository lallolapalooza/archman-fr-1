XSynchronize(3) FONCTIONS XLIB XSynchronize(3)

NOM

XSynchronize, XSetAfterFunction - activer ou désactiver la synchronisation

SYNTAXE

int (*XSynchronize(Display *display, Bool onoff))();

int (*XSetAfterFunction(Display *display, int (*procedure)()))();

ARGUMENTS

display
Spécifie la connexion au serveur X.
procedure
Spécifie la procédure à appeler.
onoff
Spécifie une valeur booléenne indiquant si la synchronisation doit être activée ou désactivée.

DESCRIPTION

La fonction XSynchronize retourne la fonction précédente "after". Si onoff est True, XSynchronize active le comportement synchrone. Si onoff est False, XSynchronize désactive le comportement synchrone.

La procédure spécifiée est appelée avec uniquement un pointeur d'affichage. XSetAfterFunction retourne la procédure "after" précédente.
