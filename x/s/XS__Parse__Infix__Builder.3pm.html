XS::Parse::Infix::Builder(3pm) Documentation Perl fournie par l'utilisateur XS::Parse::Infix::Builder(3pm)

NOM

"XS::Parse::Infix::Builder" - support au moment de la compilation pour "XS::Parse::Infix"

SYNOPSIS

Dans Build.PL:

use XS::Parse::Infix::Builder;
my $build = Module::Build->new(
   ...,
   configure_requires => {
      ...
      'XS::Parse::Infix::Builder' => 0,
   }
);
XS::Parse::Infix::Builder->extend_module_build( $build );
...

DESCRIPTION

Ce module fournit une aide au moment de la compilation pour aider les auteurs de modules XS qui utilisent XS::Parse::Infix. Il prépare une distribution utilisant Module::Build à pouvoir utiliser "XS::Parse::Infix".

FONCTIONS

write_XSParseInfix_h

XS::Parse::Infix::Builder->write_XSParseInfix_h;

Cette méthode ne fait plus rien depuis la version 0.43.

extra_compiler_flags

@flags = XS::Parse::Infix::Builder->extra_compiler_flags;

Retourne une liste de drapeaux supplémentaires que les scripts de construction devraient ajouter à l'invocation du compilateur. Cela permet au compilateur C de trouver le fichier XSParseInfix.h.

extend_module_build

XS::Parse::Infix::Builder->extend_module_build( $build );

Un raccourci pratique pour effectuer toutes les tâches nécessaires pour qu'une distribution basée sur Module::Build utilise l'aide.
