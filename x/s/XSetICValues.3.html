XSetICValues(3)

Paquet: libx11

Licences: MIT AND X11

XSetICValues(3) FONCTIONS XLIB XSetICValues(3)

NOM

XSetICValues, XGetICValues - définir et obtenir les valeurs XIC

SYNTAXE

char * XSetICValues(XIC ic, ...);

char * XGetICValues(XIC ic, ...);

ARGUMENTS

ic
Spécifie le contexte d'entrée.
...
Spécifie la liste d'arguments de longueur variable pour définir ou obtenir les valeurs XIC.

DESCRIPTION

La fonction XSetICValues retourne NULL si aucune erreur ne s'est produite ; sinon, elle retourne le nom du premier argument qui n'a pas pu être défini. Un argument pourrait ne pas être défini pour l'une des raisons suivantes :

  • L'argument est en lecture seule (par exemple, XNFilterEvents).
  • Le nom de l'argument n'est pas reconnu.
  • Une erreur dépendant de l'implémentation se produit.

Chaque valeur à définir doit être une donnée appropriée, correspondant au type de données imposé par la sémantique de l'argument.

XSetICValues peut générer des erreurs BadAtom, BadColor, BadCursor, BadPixmap et BadWindow.

La fonction XGetICValues retourne NULL si aucune erreur ne s'est produite ; sinon, elle retourne le nom du premier argument qui n'a pas pu être obtenu. Un argument n'a pas pu être obtenu pour l'une des raisons suivantes :

  • Le nom de l'argument n'est pas reconnu.
  • La méthode d'entrée a rencontré une erreur dépendant de l'implémentation.

Chaque argument de valeur d'attribut IC (après un nom) doit pointer vers un emplacement où la valeur IC doit être stockée. C'est-à-dire, si la valeur IC est de type T, l'argument doit être de type T*. Si T est lui-même un type pointeur, alors XGetICValues alloue de la mémoire pour stocker les données réelles, et le client est responsable de libérer ces données en appelant XFree avec le pointeur retourné. L'exception à cette règle concerne une valeur IC de type XNVaNestedList (pour les attributs preedit et status). Dans ce cas, l'argument doit également être de type XVaNestedList. Ensuite, la règle de transformation du type T en T* et de libération des données allouées s'applique à chaque élément de la liste imbriquée.

DIAGNOSTICS

BadAtom
Une valeur pour un argument Atom ne nomme pas un Atom défini.
BadColor
Une valeur pour un argument Colormap ne nomme pas une Colormap définie.
BadCursor
Une valeur pour un argument Cursor ne nomme pas un Cursor défini.
BadPixmap
Une valeur pour un argument Pixmap ne nomme pas un Pixmap défini.
BadWindow
Une valeur pour un argument Window ne nomme pas une Window définie.
