XSetIconSizes(3)

Paquet: libx11

Licences: MIT AND X11

XAllocIconSize(3) FONCTIONS XLIB XAllocIconSize(3)

NOM

XAllocIconSize, XSetIconSizes, XGetIconSizes, XIconSize - allouer une structure de taille d'icône et définir ou lire la propriété WM_ICON_SIZES d'une fenêtre

SYNTAXE

XIconSize *XAllocIconSize(void);

int XSetIconSizes(Display *display, Window w, XIconSize *size_list, int count);

Status XGetIconSizes(Display *display, Window w, XIconSize **size_list_return, int *count_return);

ARGUMENTS

display
Spécifie la connexion au serveur X.
count
Spécifie le nombre d'éléments dans la liste de tailles.
count_return
Retourne le nombre d'éléments dans la liste de tailles.
size_list
Spécifie la liste de tailles.
size_list_return
Retourne la liste de tailles.
w
Spécifie la fenêtre.

DESCRIPTION

La fonction XAllocIconSize alloue et retourne un pointeur vers une structure XIconSize. Notez que tous les champs de la structure XIconSize sont initialisés à zéro. Si une mémoire insuffisante est disponible, XAllocIconSize retourne NULL. Pour libérer la mémoire allouée à cette structure, utilisez XFree.

La fonction XSetIconSizes est utilisée uniquement par les gestionnaires de fenêtres pour définir les tailles d'icônes prises en charge.

XSetIconSizes peut générer des erreurs BadAlloc et BadWindow.

La fonction XGetIconSizes retourne zéro si un gestionnaire de fenêtres n'a pas défini de tailles d'icônes ; sinon, elle retourne une valeur non nulle. XGetIconSizes doit être appelée par une application qui souhaite savoir quelles tailles d'icônes seraient les plus appréciées par le gestionnaire de fenêtres sous lequel l'application s'exécute. L'application devrait ensuite utiliser XSetWMHints pour fournir au gestionnaire de fenêtres un pixmap d'icône ou une fenêtre dans l'une des tailles prises en charge. Pour libérer les données allouées dans size_list_return, utilisez XFree.

XGetIconSizes peut générer une erreur BadWindow.

PROPRIÉTÉS

WM_ICON_SIZES
Le gestionnaire de fenêtres peut définir cette propriété sur la fenêtre racine pour spécifier les tailles d'icônes qu'il prend en charge. Le type C de cette propriété est XIconSize.

STRUCTURES

La structure XIconSize contient :

typedef struct {
        int min_width, min_height;
        int max_width, max_height;
        int width_inc, height_inc;
} XIconSize;

Les membres width_inc et height_inc définissent une progression arithmétique des tailles (minimum à maximum) qui représentent les tailles d'icônes prises en charge.

DIAGNOSTICS

BadAlloc
Le serveur n'a pas pu allouer la ressource ou la mémoire serveur demandée.
BadWindow
Une valeur pour un argument Window ne nomme pas une fenêtre définie.
