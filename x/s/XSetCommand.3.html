XSetCommand(3)

Paquet: libx11

Licences: MIT AND X11

XSetCommand(3) FONCTIONS XLIB XSetCommand(3)

NOM

XSetCommand, XGetCommand - définir ou lire la propriété WM_COMMAND d'une fenêtre

SYNTAXE

int XSetCommand(Display *display, Window w, char **argv, int argc);

Status XGetCommand(Display *display, Window w, char ***argv_return, int *argc_return);

ARGUMENTS

argc
Spécifie le nombre d'arguments.
argc_return
Retourne le nombre d'arguments retournés.
argv
Spécifie la liste des arguments de l'application.
argv_return
Retourne la liste des arguments de l'application.
display
Spécifie la connexion au serveur X.
w
Spécifie la fenêtre.

DESCRIPTION

La fonction XSetCommand définit la commande et les arguments utilisés pour invoquer l'application. (Généralement, argv est le tableau argv de votre programme principal.) Si les chaînes ne sont pas dans l'encodage de caractères portable hôte, le résultat dépend de l'implémentation.

XSetCommand peut générer des erreurs BadAlloc et BadWindow.

La fonction XGetCommand lit la propriété WM_COMMAND de la fenêtre spécifiée et retourne une liste de chaînes. Si la propriété WM_COMMAND existe, elle est de type STRING et de format 8. Si suffisamment de mémoire peut être allouée pour contenir la liste de chaînes, XGetCommand remplit les arguments argv_return et argc_return et retourne un statut non nul. Sinon, ou si une autre erreur est rencontrée, elle retourne un statut nul. Si les données retournées par le serveur sont dans l'encodage de caractères portable Latin, alors les chaînes retournées sont dans l'encodage de caractères portable hôte. Sinon, le résultat dépend de l'implémentation. Pour libérer la mémoire allouée à la liste de chaînes, utilisez XFreeStringList.

PROPRIÉTÉS

WM_COMMAND
La commande et les arguments, séparés par des nuls, utilisés pour invoquer l'application.

DIAGNOSTICS

BadAlloc
Le serveur n'a pas pu allouer la ressource demandée ou la mémoire du serveur.
BadWindow
Une valeur pour un argument Window ne nomme pas une fenêtre définie.
