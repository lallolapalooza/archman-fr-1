XSelectionClearEvent(3)

Paquet: libx11

XSelectionClearEvent(3) FONCTIONS XLIB XSelectionClearEvent(3)

NOM

XSelectionClearEvent - Structure d'événement SelectionClear

STRUCTURES

La structure pour les événements SelectionClear contient :

typedef struct {
        int type;       /* SelectionClear */
        unsigned long serial;   /* # de la dernière requête traitée par le serveur */
        Bool send_event;        /* vrai si ceci provient d'une requête SendEvent */
        Display *display;       /* Display à partir duquel l'événement a été lu */
        Window window;
        Atom selection;
        Time time;
} XSelectionClearEvent;

Lorsque vous recevez cet événement, les membres de la structure sont configurés comme suit.

Le membre type est défini sur le nom de la constante du type d'événement qui l'identifie de manière unique. Par exemple, lorsque le serveur X rapporte un événement GraphicsExpose à une application cliente, il envoie une structure XGraphicsExposeEvent avec le membre type défini sur GraphicsExpose. Le membre display est défini sur un pointeur vers le display sur lequel l'événement a été lu. Le membre send_event est défini sur True si l'événement provient d'une requête de protocole SendEvent. Le membre serial est défini à partir du numéro de série rapporté dans le protocole mais développé à partir des 16 bits les moins significatifs pour une valeur complète de 32 bits. Le membre window est défini sur la fenêtre qui est la plus utile pour les gestionnaires de dispersion de boîtes à outils.

Le membre selection est défini sur l'atome de sélection. Le membre time est défini sur la dernière heure de changement enregistrée pour la sélection. Le membre window est la fenêtre qui a été spécifiée par le propriétaire actuel (le propriétaire perdant la sélection) dans son appel XSetSelectionOwner.
