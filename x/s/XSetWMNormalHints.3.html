Paquet: libx11

XAllocSizeHints(3) FONCTIONS XLIB XAllocSizeHints(3)

NOM

XAllocSizeHints, XSetWMNormalHints, XGetWMNormalHints, XSetWMSizeHints, XGetWMSizeHints, XSizeHints - allouer une structure d'indices de taille et définir ou lire la propriété WM_NORMAL_HINTS d'une fenêtre

SYNTAXE

XSizeHints *XAllocSizeHints(void);

void XSetWMNormalHints(Display *display, Window w, XSizeHints *hints);

Status XGetWMNormalHints(Display *display, Window w, XSizeHints *hints_return, long *supplied_return);

void XSetWMSizeHints(Display *display, Window w, XSizeHints *hints, Atom property);

Status XGetWMSizeHints(Display *display, Window w, XSizeHints *hints_return, long *supplied_return, Atom property);

ARGUMENTS

display
Spécifie la connexion au serveur X.
hints
Spécifie les indices de taille pour la fenêtre dans son état normal.
hints
Spécifie la structure XSizeHints à utiliser.
hints_return
Retourne les indices de taille pour la fenêtre dans son état normal.
property
Spécifie le nom de la propriété.
supplied_return
Retourne les indices qui ont été fournis par l'utilisateur.
w
Spécifie la fenêtre.

DESCRIPTION

La fonction XAllocSizeHints alloue et retourne un pointeur vers une structure XSizeHints. Notez que tous les champs de la structure XSizeHints sont initialisés à zéro. Si la mémoire est insuffisante, XAllocSizeHints retourne NULL. Pour libérer la mémoire allouée à cette structure, utilisez XFree.

La fonction XSetWMNormalHints remplace les indices de taille de la propriété WM_NORMAL_HINTS sur la fenêtre spécifiée. Si la propriété n'existe pas déjà, XSetWMNormalHints définit les indices de taille de la propriété WM_NORMAL_HINTS sur la fenêtre spécifiée. La propriété est stockée avec un type WM_SIZE_HINTS et un format de 32.

XSetWMNormalHints peut générer des erreurs BadAlloc et BadWindow.

La fonction XGetWMNormalHints retourne les indices de taille stockés dans la propriété WM_NORMAL_HINTS sur la fenêtre spécifiée. Si la propriété est de type WM_SIZE_HINTS, de format 32 et suffisamment longue pour contenir une structure d'indices de taille ancienne (pré-ICCCM) ou nouvelle, XGetWMNormalHints définit les différents champs de la structure XSizeHints, définit l'argument supplied_return à la liste des champs qui ont été fournis par l'utilisateur (qu'ils contiennent ou non des valeurs définies), et retourne un statut non nul. Sinon, elle retourne un statut nul.

Si XGetWMNormalHints retourne avec succès et qu'une propriété d'indices de taille pré-ICCCM est lue, l'argument supplied_return contiendra les bits suivants :

(USPosition|USSize|PPosition|PSize|PMinSize|
 PMaxSize|PResizeInc|PAspect)

Si la propriété est suffisamment longue pour contenir également les champs de taille de base et de gravité de fenêtre, l'argument supplied_return contiendra également les bits suivants :

PBaseSize|PWinGravity

XGetWMNormalHints peut générer une erreur PN BadWindow.

La fonction XSetWMSizeHints remplace les indices de taille de la propriété spécifiée sur la fenêtre nommée. Si la propriété spécifiée n'existe pas déjà, XSetWMSizeHints définit les indices de taille de la propriété spécifiée sur la fenêtre nommée. La propriété est stockée avec un type WM_SIZE_HINTS et un format de 32. Pour définir les indices de taille normaux d'une fenêtre, vous pouvez utiliser la fonction XSetWMNormalHints.

XSetWMSizeHints peut générer des erreurs BadAlloc, BadAtom et BadWindow.

La fonction XGetWMSizeHints retourne les indices de taille stockés dans la propriété spécifiée sur la fenêtre nommée. Si la propriété est de type WM_SIZE_HINTS, de format 32 et suffisamment longue pour contenir une structure d'indices de taille ancienne (pré-ICCCM) ou nouvelle, XGetWMSizeHints définit les différents champs de la structure XSizeHints, définit l'argument supplied_return à la liste des champs qui ont été fournis par l'utilisateur (qu'ils contiennent ou non des valeurs définies), et retourne un statut non nul. Sinon, elle retourne un statut nul. Pour obtenir les indices de taille normaux d'une fenêtre, vous pouvez utiliser la fonction XGetWMNormalHints.

Si XGetWMSizeHints retourne avec succès et qu'une propriété d'indices de taille pré-ICCCM est lue, l'argument supplied_return contiendra les bits suivants :

(USPosition|USSize|PPosition|PSize|PMinSize|
 PMaxSize|PResizeInc|PAspect)

Si la propriété est suffisamment longue pour contenir également les champs de taille de base et de gravité de fenêtre, l'argument supplied_return contiendra également les bits suivants :

PBaseSize|PWinGravity

XGetWMSizeHints peut générer des erreurs BadAtom et BadWindow.

PROPRIÉTÉS

WM_NORMAL_HINTS
Indices de taille pour une fenêtre dans son état normal. Le type C de cette propriété est XSizeHints.

STRUCTURES

La structure XSizeHints contient :

/* Bits du masque des indices de taille */

#define USPosition (1L << 0) /* x, y spécifiés par l'utilisateur */
#define USSize (1L << 1) /* largeur, hauteur spécifiés par l'utilisateur */
#define PPosition (1L << 2) /* position spécifiée par le programme */
#define PSize (1L << 3) /* taille spécifiée par le programme */
#define PMinSize (1L << 4) /* taille minimale spécifiée par le programme */
#define PMaxSize (1L << 5) /* taille maximale spécifiée par le programme */
#define PResizeInc (1L << 6) /* incréments de redimensionnement spécifiés par le programme */
#define PAspect (1L << 7) /* rapports d'aspect min et max spécifiés par le programme */
#define PBaseSize (1L << 8)
#define PWinGravity (1L << 9)
#define PAllHints (PPosition| PSize| PMinSize| PMaxSize| PResizeInc| PAspect) 
/* Valeurs */
typedef struct {
        long flags;     /* marque quels champs de cette structure sont définis */
        int x, y;       /* Obsolète */
        int width, height;      /* Obsolète */
        int min_width, min_height;
        int max_width, max_height;
        int width_inc, height_inc;
        struct {
               int x;   /* numérateur */
               int y;   /* dénominateur */
        } min_aspect, max_aspect;
        int base_width, base_height;
        int win_gravity;
        /* cette structure pourra être étendue à l'avenir */
} XSizeHints;

Les membres x, y, width et height sont maintenant obsolètes et sont laissés uniquement pour des raisons de compatibilité. Les membres min_width et min_height spécifient la taille minimale de la fenêtre qui permet encore à l'application d'être utile. Les membres max_width et max_height spécifient la taille maximale de la fenêtre. Les membres width_inc et height_inc définissent une progression arithmétique des tailles (de la minimale à la maximale) dans lesquelles la fenêtre préfère être redimensionnée. Les membres min_aspect et max_aspect sont exprimés en ratios x et y, et ils permettent à une application de spécifier la plage de rapports d'aspect qu'elle préfère. Les membres base_width et base_height définissent la taille souhaitée de la fenêtre. Le gestionnaire de fenêtres interprétera la position de la fenêtre et la largeur de ses bordures pour positionner le point du rectangle extérieur de la fenêtre globale spécifiée par le membre win_gravity. Le rectangle extérieur de la fenêtre comprend toutes les bordures ou décorations fournies par le gestionnaire de fenêtres. En d'autres termes, si le gestionnaire de fenêtres décide de placer la fenêtre là où le cli

ent demandé, la position sur la bordure de la fenêtre parente nommée par le win_gravity sera placée là où la fenêtre cliente aurait été placée en l'absence d'un gestionnaire de fenêtres.

Notez que l'utilisation de la macro PAllHints est fortement déconseillée.

DIAGNOSTICS

BadAlloc
Le serveur n'a pas pu allouer la ressource ou la mémoire serveur demandée.
BadAtom
Une valeur pour un argument Atom ne nomme pas un Atom défini.
BadWindow
Une valeur pour un argument Window ne nomme pas une Window définie.
