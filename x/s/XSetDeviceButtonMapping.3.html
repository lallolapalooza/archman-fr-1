XSETDEVICEBUTTONMAPP(3)   XSETDEVICEBUTTONMAPP(3)

NOM

XSetDeviceButtonMapping, XGetDeviceButtonMapping - interroger ou modifier les mappages de boutons des périphériques

SYNOPIS

#include <X11/extensions/XInput.h>
int XSetDeviceButtonMapping( Display *display,
                             XDevice *device,
                             unsigned char map[],
                             int nmap);
int XGetDeviceButtonMapping( Display *display,
                             XDevice *device,
                             unsigned char map_return[],
                             int nmap);
display
       Spécifie la connexion au serveur X.
device
       Spécifie le périphérique dont le mappage de boutons doit être
       interrogé ou modifié.
map
       Spécifie la liste de mappage.
map_return
       Retourne la liste de mappage.
nmap
       Spécifie le nombre d'éléments dans la liste de mappage.

DESCRIPTION

La requête XSetDeviceButtonMapping définit le mappage du
périphérique spécifié. Si elle réussit, le serveur X génère un
événement DeviceMappingNotify, et XSetDeviceButtonMapping renvoie
MappingSuccess. L'élément map[i] définit le numéro logique du
bouton pour le bouton physique i+1. La longueur de la liste doit
être la même que celle que XGetDeviceButtonMapping retournerait,
ou une erreur BadValue en résulte. Un élément zéro désactive un
bouton, et les éléments ne sont pas limités en valeur par le
nombre de boutons physiques. Cependant, deux éléments ne peuvent
pas avoir la même valeur non nulle, ou une erreur BadValue en
résulte. Si certains des boutons à modifier sont logiquement
dans l'état enfoncé,
XSetDeviceButtonMapping renvoie MappingBusy, et le mappage n'est
pas modifié.
XSetDeviceButtonMapping peut générer des erreurs BadDevice,
BadMatch et BadValue.
La requête XGetDeviceButtonMapping renvoie le mappage actuel du
périphérique spécifié. Les boutons sont numérotés à partir de un.
XGetDeviceButtonMapping renvoie le nombre de boutons physiques
réellement présents sur le périphérique. Le mappage nominal d'un
périphérique est map[i]=i+1. L'argument nmap spécifie la longueur
du tableau où le mappage du périphérique est renvoyé, et seuls
les nmap premiers éléments sont renvoyés dans map_return.
XGetDeviceButtonMapping peut générer des erreurs BadDevice ou
BadMatch.

DIAGNOSTICS

BadDevice
       Un périphérique invalide a été spécifié. Le périphérique
       spécifié n'existe pas ou n'a pas été ouvert par ce client
       via XOpenInputDevice. Cette erreur peut également se
       produire si le périphérique spécifié est le clavier X ou
       le pointeur X.
BadMatch
       Cette erreur peut se produire si une requête
       XGetDeviceButtonMapping ou XSetDeviceButtonMapping a été
       faite en spécifiant un périphérique qui n'a pas de
       boutons.
BadValue
       Une valeur numérique tombe en dehors de la plage de valeurs
       acceptées par la requête. Sauf si une plage spécifique est
       indiquée pour un argument, la plage complète définie par le
       type de l'argument est acceptée. Tout argument défini comme un
       ensemble d'alternatives peut générer cette erreur.
