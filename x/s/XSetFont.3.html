XSetFont(3)

Paquet: libx11

Licences: MIT AND X11

XSetFont(3) FONCTIONS XLIB XSetFont(3)

NOM

XSetFont - routines utilitaires pour GC

SYNTAXE

int XSetFont(Display *display, GC gc, Font font);

ARGUMENTS

display
Spécifie la connexion au serveur X.
font
Spécifie la police.
gc
Spécifie le GC.

DESCRIPTION

La fonction XSetFont définit la police actuelle dans le GC spécifié.

XSetFont peut générer les erreurs BadAlloc, BadFont et BadGC.

DIAGNOSTICS

BadAlloc
Le serveur n'a pas pu allouer la ressource demandée ou la mémoire serveur.
BadFont
Une valeur pour un argument Font ou GContext ne nomme pas une Font définie.
BadGC
Une valeur pour un argument GContext ne nomme pas un GContext défini.
