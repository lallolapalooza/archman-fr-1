XSetFillStyle(3)

XSetFillStyle(3) FONCTIONS XLIB XSetFillStyle(3)

NOM

XSetFillStyle, XSetFillRule - Routines de commodité pour GC

SYNTAXE

int XSetFillStyle(Display *display, GC gc, int fill_style);

int XSetFillRule(Display *display, GC gc, int fill_rule);

ARGUMENTS

display
Spécifie la connexion au serveur X.
fill_rule
Spécifie la règle de remplissage que vous souhaitez définir pour le GC spécifié. Vous pouvez passer EvenOddRule ou WindingRule.
fill_style
Spécifie le style de remplissage que vous souhaitez définir pour le GC spécifié. Vous pouvez passer FillSolid, FillTiled, FillStippled ou FillOpaqueStippled.
gc
Spécifie le GC.

DESCRIPTION

La fonction XSetFillStyle définit le style de remplissage dans le GC spécifié.

XSetFillStyle peut générer les erreurs BadAlloc, BadGC et BadValue.

La fonction XSetFillRule définit la règle de remplissage dans le GC spécifié.

XSetFillRule peut générer les erreurs BadAlloc, BadGC et BadValue.

DIAGNOSTICS

BadAlloc
Le serveur n'a pas réussi à allouer la ressource ou la mémoire serveur demandée.
BadGC
Une valeur pour un argument GContext ne nomme pas un GContext défini.
BadValue
Une valeur numérique se situe en dehors de la plage de valeurs acceptées par la demande. Sauf si une plage spécifique est spécifiée pour un argument, la plage complète définie par le type de l'argument est acceptée. Tout argument défini comme un ensemble d'alternatives peut générer cette erreur.
