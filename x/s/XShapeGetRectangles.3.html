STRUCTURES

typedef struct {
    int type;	/* du type d'événement */
    unsigned long serial;	/* # de la dernière requête traitée par le serveur */
    Bool send_event;	/* vrai si cet événement provient d'une requête SendEvent */
    Display *display;	/* Display à partir duquel l'événement a été lu */
    Window window;	/* fenêtre de l'événement */
    int kind;	/* ShapeBounding ou ShapeClip */
    int x, y;	/* extents de la nouvelle région */
    unsigned width, height;
    Time time;	/* timestamp du serveur lorsque la région a changé */
    Bool shaped;	/* vrai si la région existe */
} XShapeEvent;

DESCRIPTION

L'extension X11 Nonrectangular Window Shape ajoute des fenêtres non rectangulaires au système X Window.

VALEURS PRÉDÉFINIES

Opérations :

ShapeSet
ShapeUnion
ShapeIntersect
ShapeSubtract
ShapeInvert

Types de formes :

ShapeClip

Définitions d'événements :

ShapeNotifyMask
ShapeNotify
