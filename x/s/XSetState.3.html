XSetState(3)

Paquet: libx11

Licences: MIT AND X11

XSetState(3) FONCTIONS XLIB XSetState(3)

NOM

XSetState, XSetFunction, XSetPlaneMask, XSetForeground, XSetBackground - Routines utilitaires pour les GC

SYNTAXE

int XSetState(Display *display, GC gc, unsigned long foreground, unsigned long background, int function, unsigned long plane_mask);

int XSetFunction(Display *display, GC gc, int function);

int XSetPlaneMask(Display *display, GC gc, unsigned long plane_mask);

int XSetForeground(Display *display, GC gc, unsigned long foreground);

int XSetBackground(Display *display, GC gc, unsigned long background);

ARGUMENTS

background
Spécifie l'arrière-plan que vous souhaitez définir pour le GC spécifié.
display
Spécifie la connexion au serveur X.
foreground
Spécifie le premier plan que vous souhaitez définir pour le GC spécifié.
function
Spécifie la fonction que vous souhaitez définir pour le GC spécifié.
gc
Spécifie le GC.
plane_mask
Spécifie le masque de plan.

DESCRIPTION

La fonction XSetState définit les composants de premier plan, d'arrière-plan, de masque de plan et de fonction pour le GC spécifié.

XSetState peut générer des erreurs BadAlloc, BadGC et BadValue.

XSetFunction définit une valeur spécifiée dans le GC spécifié.

XSetFunction peut générer des erreurs BadAlloc, BadGC et BadValue.

La fonction XSetPlaneMask définit le masque de plan dans le GC spécifié.

XSetPlaneMask peut générer des erreurs BadAlloc et BadGC.

La fonction XSetForeground définit le premier plan dans le GC spécifié.

XSetForeground peut générer des erreurs BadAlloc et BadGC.

La fonction XSetBackground définit l'arrière-plan dans le GC spécifié.

XSetBackground peut générer des erreurs BadAlloc et BadGC.

DIAGNOSTICS

BadAlloc
Le serveur n'a pas pu allouer la ressource demandée ou la mémoire du serveur.
BadGC
Une valeur pour un argument GContext ne nomme pas un GContext défini.
BadValue
Une valeur numérique est hors de la plage de valeurs acceptées par la requête. Sauf si une plage spécifique est spécifiée pour un argument, la plage complète définie par le type de l'argument est acceptée. Tout argument défini comme un ensemble d'alternatives peut générer cette erreur.
