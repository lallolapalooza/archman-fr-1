XSetLineAttributes(3)

Paquet: libx11

Licences: MIT AND X11

XSetLineAttributes(3) FONCTIONS XLIB XSetLineAttributes(3)

NOM

XSetLineAttributes, XSetDashes - routines utilitaires GC

SYNTAXE

int XSetLineAttributes(Display *display, GC gc, unsigned int line_width, int line_style, int cap_style, int join_style);

int XSetDashes(Display *display, GC gc, int dash_offset, _Xconst char dash_list[], int n);

ARGUMENTS

cap_style
Spécifie le style de ligne et le style de bout de ligne que vous souhaitez définir pour le GC spécifié. Vous pouvez passer CapNotLast, CapButt, CapRound ou CapProjecting.
dash_list
Spécifie la liste de tirets pour le style de ligne en pointillés que vous souhaitez définir pour le GC spécifié.
dash_offset
Spécifie la phase du motif pour le style de ligne en pointillés que vous souhaitez définir pour le GC spécifié.
display
Spécifie la connexion au serveur X.
gc
Spécifie le GC.
join_style
Spécifie le style de jointure de ligne que vous souhaitez définir pour le GC spécifié. Vous pouvez passer JoinMiter, JoinRound ou JoinBevel.
line_style
Spécifie le style de ligne que vous souhaitez définir pour le GC spécifié. Vous pouvez passer LineSolid, LineOnOffDash ou LineDoubleDash.
line_width
Spécifie la largeur de ligne que vous souhaitez définir pour le GC spécifié.
n
Spécifie le nombre d'éléments dans dash_list.

DESCRIPTION

La fonction XSetLineAttributes définit les composants de dessin de ligne dans le GC spécifié.

XSetLineAttributes peut générer les erreurs BadAlloc, BadGC et BadValue.

La fonction XSetDashes définit les attributs de décalage de tiret et de liste de tirets pour les styles de ligne en pointillés dans le GC spécifié. Il doit y avoir au moins un élément dans la liste de tirets spécifiée, sinon une erreur BadValue se produit. Les éléments initiaux et alternés (deuxième, quatrième, etc.) de la liste de tirets sont les tirets pairs, et les autres sont les tirets impairs. Chaque élément spécifie une longueur de tiret en pixels. Tous les éléments doivent être non nuls, sinon une erreur BadValue se produit. Spécifier une liste de longueur impaire équivaut à spécifier la même liste concaténée avec elle-même pour produire une liste de longueur paire.

Le décalage de tiret définit la phase du motif, spécifiant à quel pixel de la liste de tirets le motif doit réellement commencer dans chaque requête graphique individuelle. Les pointillés sont continus à travers les éléments de chemin combinés avec un style de jointure, mais sont réinitialisés au décalage de tiret entre chaque séquence de lignes jointes.

L'unité de mesure pour les tirets est la même que pour le système de coordonnées ordinaire. Idéalement, une longueur de tiret est mesurée le long de la pente de la ligne, mais les implémentations ne sont tenues de faire correspondre cet idéal que pour les lignes horizontales et verticales. À défaut des sémantiques idéales, il est suggéré que la longueur soit mesurée le long de l'axe principal de la ligne. L'axe principal est défini comme l'axe x pour les lignes tracées à un angle compris entre -45 et +45 degrés ou entre 135 et 225 degrés par rapport à l'axe x. Pour toutes les autres lignes, l'axe principal est l'axe y.

XSetDashes peut générer les erreurs BadAlloc, BadGC et BadValue.

DIAGNOSTICS

BadAlloc
Le serveur n'a pas réussi à allouer la ressource ou la mémoire serveur demandée.
BadGC
Une valeur pour un argument GContext ne nomme pas un GContext défini.
BadValue
Certains valeurs numériques tombent en dehors de la plage de valeurs acceptées par la requête. Sauf si une plage spécifique est définie pour un argument, la plage complète définie par le type de l'argument est acceptée. Tout argument défini comme un ensemble d'alternatives peut générer cette erreur.
