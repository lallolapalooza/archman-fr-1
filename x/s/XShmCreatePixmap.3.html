DESCRIPTION

XShmQueryExtension vérifie si les extensions de mémoire partagée sont disponibles pour le display spécifié.

XShmQueryVersion retourne les numéros de version de l'implémentation de l'extension. Les pixmaps en mémoire partagée sont supportées si l'argument pixmaps retourne true.

XShmAttach demande au serveur de s'attacher à votre segment de mémoire partagée. Si tout se passe bien, vous obtiendrez un statut non nul et votre XImage sera prêt à être utilisé.

XShmDetach demande au serveur de se détacher de votre segment de mémoire partagée.

XShmPutImage combine une image en mémoire avec une forme du drawable spécifié. Si le format XYBitmap est utilisé, la profondeur doit être un, sinon une erreur ``BadMatch'' est générée. Le pixel de premier plan dans le GC définit la source pour les bits un de l'image, et le pixel d'arrière-plan définit la source pour les bits zéro. Pour XYPixmap et ZPixmap, la profondeur doit correspondre à la profondeur du drawable, sinon une erreur ``BadMatch'' est générée.

XShmGetImage lit les données de l'image dans un XImage en mémoire partagée où display est le display concerné, drawable est le drawable source, image est le XImage de destination, x et y sont les offsets dans le drawable, et plane_mask définit les plans à lire.

XShmCreateImage alloue la mémoire nécessaire pour une structure XImage pour le display spécifié, mais n'alloue pas d'espace pour l'image elle-même.

XShmPixmapFormat obtient le format pour le serveur. Si votre application peut gérer le format des données de pixmap du serveur, un segment de mémoire partagée et une structure shminfo sont créés.

XShmCreatePixmap pointe vers une pixmap que vous pouvez manipuler de toutes les manières habituelles, avec l'avantage supplémentaire de pouvoir modifier son contenu directement via le segment de mémoire partagée.

XShmGetEventBase obtient la valeur de l'événement de complétion.
