XSetCloseDownMode(3)

Paquet: libx11

Licences: MIT AND X11

XSetCloseDownMode(3) FONCTIONS XLIB XSetCloseDownMode(3)

NOM

XSetCloseDownMode, XKillClient - contrôler les clients

SYNTAXE

int XSetCloseDownMode(Display *display, int close_mode);

int XKillClient(Display *display, XID resource);

ARGUMENTS

close_mode
Spécifie le mode de fermeture du client. Vous pouvez passer DestroyAll, RetainPermanent ou RetainTemporary.
display
Spécifie la connexion au serveur X.
resource
Spécifie n'importe quelle ressource associée au client que vous souhaitez détruire ou AllTemporary.

DESCRIPTION

La fonction XSetCloseDownMode définit ce qui arrivera aux ressources du client à la fermeture de la connexion. Une connexion commence en mode DestroyAll. Pour des informations sur ce qui arrive aux ressources du client lorsque l'argument close_mode est RetainPermanent ou RetainTemporary, voir la section 2.6.

XSetCloseDownMode peut générer une erreur BadValue.

La fonction XKillClient force la fermeture du client qui a créé la ressource si une ressource valide est spécifiée. Si le client s'est déjà terminé en mode RetainPermanent ou RetainTemporary, toutes les ressources du client sont détruites. Si AllTemporary est spécifié, les ressources de tous les clients qui se sont terminés en mode RetainTemporary sont détruites (voir la section 2.5). Cela permet la mise en œuvre de facilités de gestionnaire de fenêtres qui aident au débogage. Un client peut définir son mode de fermeture à RetainTemporary. Si le client plante ensuite, ses fenêtres ne seraient pas détruites. Le programmeur peut alors inspecter l'arbre de fenêtres de l'application et utiliser le gestionnaire de fenêtres pour détruire les fenêtres zombies.

XKillClient peut générer une erreur BadValue.

DIAGNOSTICS

BadValue
Une valeur numérique est en dehors de la plage de valeurs acceptées par la requête. Sauf si une plage spécifique est spécifiée pour un argument, toute la plage définie par le type de l'argument est acceptée. Tout argument défini comme un ensemble d'alternatives peut générer cette erreur.
