XSetWindowAttributes(3)

Paquet: libx11

Licences: MIT AND X11

XCreateWindow(3) FONCTIONS XLIB XCreateWindow(3)

NOM

XCreateWindow, XCreateSimpleWindow, XSetWindowAttributes - créer des fenêtres et une structure d'attributs de fenêtre

SYNTAXE

Window XCreateWindow(Display *display, Window parent, int x, int y, unsigned int width, unsigned int height, unsigned int border_width, int depth, unsigned int class, Visual *visual, unsigned long valuemask, XSetWindowAttributes *attributes);

Window XCreateSimpleWindow(Display *display, Window parent, int x, int y, unsigned int width, unsigned int height, unsigned int border_width, unsigned long border, unsigned long background);

ARGUMENTS

attributes
Spécifie la structure à partir de laquelle les valeurs (telles que spécifiées par le masque de valeur) doivent être prises. Le masque de valeur doit avoir les bits appropriés définis pour indiquer quelles attributs ont été définis dans la structure.
background
Spécifie la valeur du pixel de fond de la fenêtre.
border
Spécifie la valeur du pixel de bordure de la fenêtre.
border_width
Spécifie la largeur de la bordure de la fenêtre créée en pixels.
class
Spécifie la classe de la fenêtre créée. Vous pouvez passer InputOutput, InputOnly, ou CopyFromParent. Une classe de CopyFromParent signifie que la classe est héritée du parent.
depth
Spécifie la profondeur de la fenêtre. Une profondeur de CopyFromParent signifie que la profondeur est héritée du parent.
display
Spécifie la connexion au serveur X.
parent
Spécifie la fenêtre parente.
valuemask
Spécifie quels attributs de fenêtre sont définis dans l'argument attributes. Ce masque est le OU logique (OU inclusif) des bits valides du masque d'attribut. Si valuemask est zéro, les attributs sont ignorés et ne sont pas référencés.
visual
Spécifie le type de visualisation. Un type de visualisation de CopyFromParent signifie que le type de visualisation est hérité du parent.
width

height
Spécifient la largeur et la hauteur, qui sont les dimensions intérieures de la fenêtre créée et n'incluent pas les bordures de la fenêtre créée.
x

y
Spécifient les coordonnées x et y, qui sont le coin supérieur gauche extérieur des bordures de la fenêtre et sont relatives à l'intérieur des bordures de la fenêtre parente.

DESCRIPTION

La fonction XCreateWindow crée une sous-fenêtre non mappée pour une fenêtre parente spécifiée, retourne l'identifiant de la fenêtre créée, et provoque la génération d'un événement CreateNotify par le serveur X. La fenêtre créée est placée au-dessus dans l'ordre d'empilement par rapport à ses frères et sœurs.

Le système de coordonnées a l'axe X horizontal et l'axe Y vertical, avec l'origine [0, 0] dans le coin supérieur gauche. Les coordonnées sont entières, en pixels, et coïncident avec les centres des pixels. Chaque fenêtre et chaque pixmap a son propre système de coordonnées. Pour une fenêtre, l'origine est à l'intérieur de la bordure, au coin supérieur gauche intérieur.

La largeur de bordure (border_width) pour une fenêtre de classe InputOnly doit être zéro, sinon une erreur BadMatch est générée. Pour la classe InputOutput, le type de visualisation et la profondeur doivent être une combinaison supportée pour l'écran, sinon une erreur BadMatch est générée. La profondeur n'a pas besoin d'être la même que celle du parent, mais le parent ne doit pas être une fenêtre de classe InputOnly, sinon une erreur BadMatch est générée. Pour une fenêtre InputOnly, la profondeur doit être zéro, et la visualisation doit être l'une de celles supportées par l'écran. Si l'une de ces conditions n'est pas remplie, une erreur BadMatch est générée. La fenêtre parente, cependant, peut avoir n'importe quelle profondeur et classe. Si vous spécifiez un attribut de fenêtre invalide pour une fenêtre, une erreur BadMatch est générée.

La fenêtre créée n'est pas encore affichée (mappée) sur l'écran de l'utilisateur. Pour afficher la fenêtre, appelez XMapWindow. La nouvelle fenêtre utilise initialement le même curseur que son parent. Un nouveau curseur peut être défini pour la nouvelle fenêtre en appelant XDefineCursor. La fenêtre ne sera pas visible à l'écran à moins qu'elle et tous ses ancêtres ne soient mappés et qu'elle ne soit pas obstruée par l'un de ses ancêtres.

XCreateWindow peut générer les erreurs BadAlloc, BadColor, BadCursor, BadMatch, BadPixmap, BadValue, et BadWindow.

La fonction XCreateSimpleWindow crée une sous-fenêtre InputOutput non mappée pour une fenêtre parente spécifiée, retourne l'identifiant de la fenêtre créée, et provoque la génération d'un événement CreateNotify par le serveur X. La fenêtre créée est placée au-dessus dans l'ordre d'empilement par rapport à ses frères et sœurs. Toute partie de la fenêtre qui s'étend au-delà de sa fenêtre parente est coupée. La largeur de bordure (border_width) pour une fenêtre InputOnly doit être zéro, sinon une erreur BadMatch est générée. XCreateSimpleWindow hérite de sa profondeur, classe et visualisation de son parent. Tous les autres attributs de fenêtre, à l'exception du fond et de la bordure, prennent leurs valeurs par défaut.

XCreateSimpleWindow peut générer les erreurs BadAlloc, BadMatch, BadValue, et BadWindow.

STRUCTURES

La structure XSetWindowAttributes contient :

/* Masque des bits de valeur d'attribut de fenêtre */

#define CWBackPixmap (1L<<0)
#define CWBackPixel (1L<<1)
#define CWBorderPixmap (1L<<2)
#define CWBorderPixel (1L<<3)
#define CWBitGravity (1L<<4)
#define CWWinGravity (1L<<5)
#define CWBackingStore (1L<<6)
#define CWBackingPlanes (1L<<7)
#define CWBackingPixel (1L<<8)
#define CWOverrideRedirect (1L<<9)
#define CWSaveUnder (1L<<10)
#define CWEventMask (1L<<11)
#define CWDontPropagate (1L<<12)
#define CWColormap (1L<<13)
#define CWCursor (1L<<14) 
/* Valeurs */
typedef struct {
        Pixmap background_pixmap;       /* fond, None, ou ParentRelative */
        unsigned long background_pixel; /* pixel de fond */
        Pixmap border_pixmap;           /* bordure de la fenêtre ou CopyFromParent */
        unsigned long border_pixel;     /* valeur du pixel de bordure */
        int bit_gravity;        /* une des valeurs de gravité de bits */
        int win_gravity;        /* une des valeurs de gravité de fenêtre */
        int backing_store;      /* NotUseful, WhenMapped, Always */
        unsigned long backing_planes;   /* plans à préserver si possible */
        unsigned long backing_pixel;    /* valeur à utiliser pour restaurer les plans */
        Bool save_under;        /* faut-il sauvegarder les bits en dessous ? (popups) */
        long event_mask;        /* ensemble des événements à sauvegarder */
        long do_not_propagate_mask;     /* ensemble des événements qui ne doivent pas se propager */
        Bool override_redirect; /* valeur booléenne pour override_redirect */
        Colormap colormap;      /* carte de couleurs à associer à la fenêtre */
        Cursor cursor;          /* curseur à afficher (ou None) */
} XSetWindowAttributes;

Pour une explication détaillée des membres de cette structure, voir Xlib - C Language X Interface.

DIAGNOSTICS

BadAlloc
Le serveur n'a pas pu allouer la ressource demandée ou la mémoire du serveur.
BadColor
Une valeur pour un argument Colormap ne nomme pas une Colormap définie.
BadCursor
Une valeur pour un argument Cursor ne nomme pas un Cursor défini.
BadMatch
Les valeurs n'existent pas pour une fenêtre InputOnly.
BadMatch
Certains arguments ou paires d'arguments ont le type et la plage corrects mais ne correspondent pas d'une autre manière requise par la requête.
BadPixmap
Une valeur pour un argument Pixmap ne nomme pas un Pixmap défini.
BadValue
Une valeur numérique se situe en dehors de la plage des valeurs acceptées par la requête. Sauf si une plage spécifique est spécifiée pour un argument, la plage complète définie par le type de l'argument est acceptée. Tout argument défini comme un ensemble d'alternatives peut générer cette erreur.
BadWindow
Une valeur pour un argument Window ne nomme pas une Window définie.
