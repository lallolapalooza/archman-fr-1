NOM

XSelectInput - sélectionner les événements d'entrée

SYNTAXE

int XSelectInput(Display *display, Window w, long event_mask);

ARGUMENTS

display
Spécifie la connexion au serveur X.
event_mask
Spécifie le masque d'événements.
w
Spécifie la fenêtre pour laquelle vous souhaitez recevoir des événements.

DESCRIPTION

La fonction XSelectInput demande au serveur X de signaler les événements associés au masque d'événements spécifié. Initialement, X ne signale aucun de ces événements. Les événements sont signalés par rapport à une fenêtre. Si une fenêtre n'est pas intéressée par un événement de périphérique, il est généralement propagé à l'ancêtre le plus proche qui l'est, à moins que le masque do_not_propagate ne l'interdise.

La définition de l'attribut event-mask d'une fenêtre remplace tout appel précédent pour la même fenêtre mais pas pour d'autres clients. Plusieurs clients peuvent sélectionner les mêmes événements sur la même fenêtre avec les restrictions suivantes :

  • Plusieurs clients peuvent sélectionner des événements sur la même fenêtre car leurs masques d'événements sont disjoints. Lorsque le serveur X génère un événement, il le signale à tous les clients intéressés.
  • Un seul client à la fois peut sélectionner les événements CirculateRequest, ConfigureRequest, ou MapRequest, qui sont associés au masque d'événements SubstructureRedirectMask.
  • Un seul client à la fois peut sélectionner un événement ResizeRequest, qui est associé au masque d'événements ResizeRedirectMask.
  • Un seul client à la fois peut sélectionner un événement ButtonPress, qui est associé au masque d'événements ButtonPressMask.

Le serveur signale l'événement à tous les clients intéressés.

XSelectInput peut générer une erreur BadWindow.

DIAGNOSTICS

BadWindow
Une valeur pour un argument Window ne nomme pas une fenêtre définie.
