NOM

XScreenSaver - Bibliothèque client d'extension de l'économiseur d'écran X11

SYNOPIS

#include <X11/extensions/scrnsaver.h>

typedef struct {
    Window window;                /* fenêtre de l'économiseur d'écran */
    int state;                    /* ScreenSaver{Off,On,Disabled} */
    int kind;                     /* ScreenSaver{Blanked,Internal,External} */
    unsigned long til_or_since;   /* millisecondes */
    unsigned long idle;           /* millisecondes */
    unsigned long eventMask;      /* événements */
} XScreenSaverInfo;

typedef struct {
    int type;               /* type d'événement */
    unsigned long serial;   /* # de la dernière requête traitée par le serveur */
    Bool send_event;        /* vrai si ceci provient d'une requête SendEvent */
    Display *display;       /* Display à partir duquel l'événement a été lu */
    Window window;          /* fenêtre de l'économiseur d'écran */
    Window root;            /* fenêtre racine de l'écran d'événement */
    int state;              /* ScreenSaver{Off,On,Cycle} */
    int kind;               /* ScreenSaver{Blanked,Internal,External} */
    Bool forced;            /* étendue de la nouvelle région */
    Time time;              /* horodatage de l'événement */
} XScreenSaverNotifyEvent;
Bool XScreenSaverQueryExtension(Display *dpy,
    int *event_base_return, int *error_base_return);
Status XScreenSaverQueryVersion(Display *dpy,
    int *major_version_return, int *minor_version_return);
XScreenSaverInfo *XScreenSaverAllocInfo(void);
Status XScreenSaverQueryInfo(Display *dpy, Drawable drawable,
    XScreenSaverInfo *saver_info);
void XScreenSaverSelectInput(Display *dpy, Drawable drawable,
    unsigned long mask);
void XScreenSaverSetAttributes(Display *dpy, Drawable drawable,
    int x, int y, unsigned int width, unsigned int height,
    unsigned int border_width, int depth, unsigned int class,
    Visual *visual, unsigned long valuemask,
    XSetWindowAttributes *attributes);
void XScreenSaverUnsetAttributes(Display *dpy, Drawable drawable);
void XScreenSaverRegister(Display *dpy, int screen, XID xid, Atom type);
Status XScreenSaverUnregister(Display *dpy, int screen);
Status XScreenSaverGetRegistered(Display *dpy, int screen,
    XID *xid, Atom *type);
void XScreenSaverSuspend(Display *dpy, Bool suspend);

DESCRIPTION

Le système X Window fournit un support pour changer l'image d'un écran après une période d'inactivité définie par l'utilisateur afin d'éviter de brûler les phosphores des tubes cathodiques. Cependant, aucune interface n'est fournie pour que l'utilisateur contrôle l'image dessinée. Cette extension permet à un client externe de ``l'économiseur d'écran'' de détecter quand l'image alternative doit être affichée et de fournir les graphiques.

Les implémentations actuelles de serveurs X fournissent généralement au moins une forme d'image d'"économiseur d'écran". Historiquement, il s'agissait d'une copie du logo X dessinée sur le motif de fond racine. Cependant, de nombreux utilisateurs ont demandé un mécanisme leur permettant d'écrire des programmes d'économiseur d'écran offrant des capacités similaires à celles fournies par d'autres systèmes de fenêtrage. En particulier, ces utilisateurs souhaitent souvent pouvoir afficher des logos d'entreprise, des instructions sur la manière de réactiver l'écran et des utilitaires de verrouillage d'écran automatiques. Cette extension fournit un moyen d'écrire de tels clients.

Hypothèses

Cette extension exporte la notion d'une fenêtre spéciale d'économiseur d'écran qui est mappée au-dessus de toutes les autres fenêtres d'un affichage. Cette fenêtre a l'attribut override-redirect défini de sorte qu'elle ne soit pas soumise à la manipulation par le gestionnaire de fenêtres. De plus, l'identifiant X de la fenêtre n'est jamais renvoyé par les requêtes QueryTree sur la fenêtre racine, il n'est donc généralement pas visible par les autres clients.

XScreenSaverQueryExtension renvoie True si l'extension XScreenSaver est disponible sur l'affichage donné. Un client doit appeler XScreenSaverQueryExtension avant d'appeler toute autre fonction XScreenSaver afin de négocier une version de protocole compatible; sinon, le client obtiendra un comportement indéfini (XScreenSaver peut fonctionner ou non).

Si l'extension est prise en charge, le numéro d'événement pour les événements ScreenSaverNotify est renvoyé dans la valeur pointée par event_base. Étant donné qu'aucun erreur supplémentaire n'est défini par cette extension, les résultats de error_base ne sont pas définis.

XScreenSaverQueryVersion renvoie True si la requête a réussi ; les valeurs des versions de protocole majeure et mineure prises en charge par le serveur sont renvoyées dans major_version_return et minor_version_return.

XScreenSaverAllocInfo alloue et renvoie une structure XScreenSaverInfo à utiliser dans les appels à XScreenSaverQueryInfo. Tous les champs de la structure sont initialisés à zéro. Si une mémoire insuffisante est disponible, NULL est renvoyé. Les résultats de cette routine peuvent être libérés avec XFree.

XScreenSaverQueryInfo renvoie des informations sur l'état actuel du serveur d'écran dans saver_info et une valeur non nulle est renvoyée. Si l'extension n'est pas prise en charge, saver_info n'est pas modifié et 0 est renvoyé.

Le champ state spécifie si l'économiseur d'écran est actuellement actif ou non et comment la valeur til-or-since doit être interprétée :

Off
L'écran n'est pas actuellement sauvegardé ; til-or-since spécifie le nombre de millisecondes avant que l'économiseur d'écran ne soit censé s'activer.
On
L'écran est actuellement sauvegardé ; til-or-since spécifie le nombre de millisecondes depuis l'activation de l'économiseur d'écran.
Disabled
L'économiseur d'écran est actuellement désactivé ; til-or-since est zéro.

Le champ kind spécifie le mécanisme qui est actuellement utilisé ou qui aurait été utilisé si l'écran était sauvegardé :

Blanked
Le signal vidéo du moniteur d'affichage a été désactivé.
Internal
Une image d'économiseur d'écran intégrée, dépendante du serveur, a été affichée ; soit aucun client n'avait défini les attributs de la fenêtre d'économiseur d'écran, soit un autre client avait le serveur saisi lorsque l'économiseur d'écran s'est activé.
External
La fenêtre de l'économiseur d'écran a été mappée avec des attributs définis par un client utilisant la requête ScreenSaverSetAttributes.

Le champ idle spécifie le nombre de millisecondes depuis la dernière entrée utilisateur reçue sur l'un des périphériques d'entrée.
Le champ event-mask spécifie quels événements d'économiseur d'écran, le cas échéant, ce client a demandés en utilisant ScreenSaverSelectInput.

XScreenSaverSelectInput demande que les événements liés à l'économiseur d'écran soient générés pour ce client. Si aucun bit n'est défini dans event-mask, aucun événement ne sera généré. Sinon, toute combinaison des bits suivants peut être définie :

ScreenSaverNotify
Si ce bit est défini, des événements ScreenSaverNotify sont générés chaque fois que l'économiseur d'écran est activé ou désactivé.
ScreenSaverCycle
Si ce bit est défini, des événements ScreenSaverNotify sont générés chaque fois que l'intervalle de cycle de l'économiseur d'écran est atteint.

XScreenSaverSetAttributes définit les attributs à utiliser la prochaine fois que l'économiseur d'écran externe sera activé. Si un autre client a actuellement les attributs définis, une erreur BadAccess est générée et la requête est ignorée.
Sinon, les attributs de fenêtre spécifiés sont vérifiés comme s'ils étaient utilisés dans une requête core CreateWindow dont le parent est la racine. Le champ override-redirect est ignoré car il est implicitement défini à True. Si les attributs de fenêtre entraînent une erreur conformément aux règles de CreateWindow, la requête est ignorée.

XScreenSaverAllocInfo(3)

NAME

XScreenSaverAllocInfo, XScreenSaverQueryInfo, XScreenSaverSetAttributes, XScreenSaverUnsetAttributes, XScreenSaverRegister, XScreenSaverUnregister, XScreenSaverGetRegistered, XScreenSaverSuspend – screen saver control functions

SYNOPSIS

#include <X11/extensions/scrnsaver.h>

Bool XScreenSaverAllocInfo(
    XScreenSaverInfo *info
);

Bool XScreenSaverQueryInfo(
    Display *dpy,
    Window window,
    XScreenSaverInfo *info
);

Bool XScreenSaverSetAttributes(
    Display *dpy,
    Window window,
    unsigned int event_mask,
    unsigned int period
);

Bool XScreenSaverUnsetAttributes(
    Display *dpy,
    Window window
);

Bool XScreenSaverRegister(
    Display *dpy,
    Screen *screen,
    Window xid,
    int type
);

Bool XScreenSaverUnregister(
    Display *dpy,
    Screen *screen
);

Bool XScreenSaverGetRegistered(
    Display *dpy,
    Screen *screen,
    Window *xid,
    int *type
);

Bool XScreenSaverSuspend(
    Display *dpy,
    Bool suspend
);

DESCRIPTION

The X Screen Saver Extension provides a mechanism for applications to participate in the screen saving process. Clients can activate or deactivate the screen saver, query its status, and set attributes for the screen saver window.

XScreenSaverAllocInfo allocates memory for an XScreenSaverInfo structure.

XScreenSaverQueryInfo retrieves information about the current screen saver settings for the specified window and stores it in the XScreenSaverInfo structure pointed to by info. If the information cannot be retrieved, XScreenSaverQueryInfo returns False, otherwise it returns True.

The XScreenSaverInfo structure contains the following fields:

defer
The number of seconds the screen saver waits after the last user activity before activating.
timeout
The number of seconds the screen saver stays active before blanking the screen.
event_mask
A bitmask of events that the screen saver is interested in.
closet
The number of seconds the screen saver waits after the screen has been blanked before activating the screen saver window.
window_saved
A boolean indicating whether the screen saver window is currently mapped.
root_saved
A boolean indicating whether the root window has been saved.
pixmap
A pixmap containing the saved contents of the root window, if root_saved is True.
cmap
The colormap associated with the screen saver window.
Px
The x-coordinate of the screen saver window.
Py
The y-coordinate of the screen saver window.
Pwidth
The width of the screen saver window.
Pheight
The height of the screen saver window.
Pborder_width
The border width of the screen saver window.
Pdepth
The depth of the screen saver window.
Pvisual
The visual of the screen saver window.

XScreenSaverSetAttributes sets the attributes for the screen saver window. The window argument is the window that will be used as the screen saver window. The event_mask argument specifies the events that the screen saver should listen for to deactivate itself. The period argument is ignored.

The server is free to copy the background-pixmap or cursor resources or to use them in place; therefore, the effect of changing the contents of those resources is undefined. If the specified colormap no longer exists when the screen saver activates, the parent's colormap is used instead. If no errors are generated by this request, any previous screen saver window attributes set by this client are released.

When the screen saver next activates and the server is not grabbed by another client, the screen saver window is created, if necessary, and set to the specified attributes and events are generated as usual. The colormap associated with the screen saver window is installed. Finally, the screen saver window is mapped.

The window remains mapped and at the top of the stacking order until the screen saver is deactivated in response to activity on any of the user input devices, a ForceScreenSaver request with a value of Reset, or any request that would cause the window to be unmapped.

If the screen saver activates while the server is grabbed by another client, the internal saver mechanism is used. The ForceScreenSaver request may be used with a value of Active to deactivate the internal saver and activate the external saver.

If the screen saver client's connection to the server is broken while the screen saver is activated and the client's close down mode has not been RetainPermanent or RetainTemporary, the current screen saver is deactivated and the internal screen saver is immediately activated.

When the screen saver deactivates, the screen saver window's colormap is uninstalled and the window is unmapped (except as described below). The screen saver XID is disassociated with the window and the server may, but is not required to, destroy the window along with any children.

When the screen saver is being deactivated and then immediately reactivated (such as when switching screen savers), the server may leave the screen saver window mapped (typically to avoid generating exposures).

XScreenSaverUnsetAttributes instructs the server to discard any previous screen saver window attributes set by this client.

XScreenSaverRegister stores the given XID in the _SCREEN_SAVER_ID property (of the given type) on the root window of the specified screen. It returns zero if an error is encountered and the property is not changed, otherwise it returns non-zero.

XScreenSaverUnregister removes any _SCREEN_SAVER_ID from the root window of the specified screen. It returns zero if an error is encountered and the property is changed, otherwise it returns non-zero.

XScreenSaverGetRegistered returns the XID and type stored in the _SCREEN_SAVER_ID property on the root window of the specified screen. It returns zero if an error is encountered or if the property does not exist or is not of the correct format; otherwise it returns non-zero.

XScreenSaverSuspend temporarily suspends the screensaver and DPMS timer if suspend is 'True', and restarts the timer if suspend is 'False'.

This function should be used by applications that don't want the screensaver or DPMS to become activated while they're for example in the process of playing a media sequence, or are otherwise continuously presenting visual information to the user while in a non-interactive state. This function is not intended to be called by an external screensaver application.

If XScreenSaverSuspend is called multiple times with suspend set to 'True', it must be called an equal number of times with suspend set to 'False' in order for the screensaver timer to be restarted. This request has no affect if a client tries to resume the screensaver without first having suspended it. XScreenSaverSuspend can thus not be used by one client to resume the screensaver if it's been suspended by another client.

If a client that has suspended the screensaver becomes disconnected from the X server, the screensaver timer will automatically be restarted, unless it's still suspended by another client. Suspending the screensaver timer doesn't prevent the screensaver from being forcibly activated with the ForceScreenSaver request, or a DPMS mode from being set with the DPMSForceLevel request.

XScreenSaverSuspend also doesn't deactivate the screensaver or DPMS if either is active at the time the request to suspend them is received by the X server. But once they've been deactivated, they won't automatically be activated again, until the client has canceled the suspension.

ERRORS

XScreenSaverSelectInput, XScreenSaverQueryInfo, XScreenSaverSetAttributes, and XScreenSaverUnsetAttributes will generate a BadDrawable error if drawable is not a valid drawable identifier. If any undefined bits are set in event-mask, a BadValue error is generated by XScreenSaverSelectInput.

AVAILABILITY

XScreenSaverSuspend is available in version 1.1 and later versions of the X Screen Saver Extension. Version 1.1 was first released with X11R7.1.
