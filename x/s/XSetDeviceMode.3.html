XSETDEVICEMODE(3)   XSETDEVICEMODE(3)

NOM

XSetDeviceMode - changer le mode d'un périphérique

SYNTAXE

#include <X11/extensions/XInput.h>
XSetDeviceMode( Display *display,
                XDevice *device,
                int mode);
display
       Spécifie la connexion au serveur X.
device
       Spécifie le périphérique dont le mode doit être changé.
mode
       Spécifie le mode. Vous pouvez passer Absolute, ou Relative.

DESCRIPTION

La requête XSetDeviceMode change le mode d'un périphérique d'entrée
capable de rapporter des informations de position absolue ou des
informations de mouvement relatives. Tous les périphériques d'entrée
ne sont pas capables de rapporter des données de mouvement, et tous ne
sont pas capables de changer de mode de Absolute à Relative.
XSetDeviceMode peut générer une erreur BadDevice ou BadMode.

DIAGNOSTICS

BadDevice
       Un périphérique invalide a été spécifié. Le périphérique
       spécifié n'existe pas ou n'a pas été ouvert par ce client via
       XOpenInputDevice. Cette erreur peut également se produire si un
       autre client a fait du périphérique spécifié le clavier X ou le
       pointeur X via les requêtes XChangeKeyboardDevice ou
       XChangePointerDevice.
BadMatch
       Cette erreur peut survenir si une requête XSetDeviceMode est
       faite en spécifiant un périphérique qui n'a pas de valuators et
       ne rapporte aucun axe de mouvement.
BadMode
       Un mode invalide a été spécifié. Cette erreur sera également
       retournée si le périphérique spécifié n'est pas capable de
       supporter la requête XSetDeviceMode.
