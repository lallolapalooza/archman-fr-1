XSetPlaneMask(3)

Paquet: libx11

Licences: MIT AND X11

XSetPlaneMask(3) FONCTIONS XLIB XSetPlaneMask(3)

NOM

XSetState, XSetFunction, XSetPlaneMask, XSetForeground, XSetBackground - routines utilitaires de GC

SYNTAXE

int XSetState(Display *display, GC gc, unsigned long foreground, unsigned long background, int function, unsigned long plane_mask);

int XSetFunction(Display *display, GC gc, int function);

int XSetPlaneMask(Display *display, GC gc, unsigned long plane_mask);

int XSetForeground(Display *display, GC gc, unsigned long foreground);

int XSetBackground(Display *display, GC gc, unsigned long background);

ARGUMENTS

background
Spécifie l'arrière-plan que vous souhaitez définir pour la GC spécifiée.
display
Spécifie la connexion au serveur X.
foreground
Spécifie le premier plan que vous souhaitez définir pour la GC spécifiée.
function
Spécifie la fonction que vous souhaitez définir pour la GC spécifiée.
gc
Spécifie la GC.
plane_mask
Spécifie le masque de plan.

DESCRIPTION

La fonction XSetState définit les composants premier plan, arrière-plan, masque de plan et fonction pour la GC spécifiée.

XSetState peut générer des erreurs BadAlloc, BadGC et BadValue.

XSetFunction définit une valeur spécifiée dans la GC spécifiée.

XSetFunction peut générer des erreurs BadAlloc, BadGC et BadValue.

La fonction XSetPlaneMask définit le masque de plan dans la GC spécifiée.

XSetPlaneMask peut générer des erreurs BadAlloc et BadGC.

La fonction XSetForeground définit le premier plan dans la GC spécifiée.

XSetForeground peut générer des erreurs BadAlloc et BadGC.

La fonction XSetBackground définit l'arrière-plan dans la GC spécifiée.

XSetBackground peut générer des erreurs BadAlloc et BadGC.

DIAGNOSTICS

BadAlloc
Le serveur n'a pas réussi à allouer la ressource ou la mémoire serveur demandée.
BadGC
Une valeur pour un argument GContext ne nomme pas un GContext défini.
BadValue
Une valeur numérique est hors de la plage acceptée par la requête. Sauf si une plage spécifique est précisée pour un argument, toute la plage définie par le type de l'argument est acceptée. Tout argument défini comme un ensemble d'alternatives peut générer cette erreur.
