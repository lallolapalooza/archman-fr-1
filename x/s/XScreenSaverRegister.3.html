NOM

XScreenSaver - Bibliothèque client de l'extension de l'économiseur d'écran X11

SYNOPHIS

#include <X11/extensions/scrnsaver.h>

typedef struct {
    Window window;                /* fenêtre de l'économiseur d'écran */
    int state;                    /* ScreenSaver{Off,On,Disabled} */
    int kind;                     /* ScreenSaver{Blanked,Internal,External} */
    unsigned long til_or_since;   /* millisecondes */
    unsigned long idle;           /* millisecondes */
    unsigned long eventMask;      /* événements */
} XScreenSaverInfo;

typedef struct {
    int type;               /* type d'événement */
    unsigned long serial;   /* # de la dernière requête traitée par le serveur */
    Bool send_event;        /* vrai si cela provient d'une requête SendEvent */
    Display *display;       /* Display à partir duquel l'événement a été lu */
    Window window;          /* fenêtre de l'économiseur d'écran */
    Window root;            /* fenêtre racine de l'écran d'événement */
    int state;              /* ScreenSaver{Off,On,Cycle} */
    int kind;               /* ScreenSaver{Blanked,Internal,External} */
    Bool forced;            /* étendue de la nouvelle région */
    Time time;              /* horodatage de l'événement */
} XScreenSaverNotifyEvent;
Bool XScreenSaverQueryExtension(Display *dpy,
    int *event_base_return, int *error_base_return);
Status XScreenSaverQueryVersion(Display *dpy,
    int *major_version_return, int *minor_version_return);
XScreenSaverInfo *XScreenSaverAllocInfo(void);
Status XScreenSaverQueryInfo(Display *dpy, Drawable drawable,
    XScreenSaverInfo *saver_info);
void XScreenSaverSelectInput(Display *dpy, Drawable drawable,
    unsigned long mask);
void XScreenSaverSetAttributes(Display *dpy, Drawable drawable,
    int x, int y, unsigned int width, unsigned int height,
    unsigned int border_width, int depth, unsigned int class,
    Visual *visual, unsigned long valuemask,
    XSetWindowAttributes *attributes);
void XScreenSaverUnsetAttributes(Display *dpy, Drawable drawable);
void XScreenSaverRegister(Display *dpy, int screen, XID xid, Atom type);
Status XScreenSaverUnregister(Display *dpy, int screen);
Status XScreenSaverGetRegistered(Display *dpy, int screen,
    XID *xid, Atom *type);
void XScreenSaverSuspend(Display *dpy, Bool suspend);

DESCRIPTION

Le système X Window fournit une prise en charge pour changer l'image d'un écran après une période d'inactivité définie par l'utilisateur, afin d'éviter de brûler les phosphores du tube cathodique. Cependant, aucune interface n'est fournie à l'utilisateur pour contrôler l'image dessinée. Cette extension permet à un client externe « d'économiseur d'écran » de détecter quand l'image alternative doit être affichée et de fournir les graphiques.

Les implémentations actuelles de serveurs X fournissent généralement au moins une forme d'image « d'économiseur d'écran ». Historiquement, il s'agissait d'une copie du logo X dessinée sur le motif de fond de la racine. Cependant, de nombreux utilisateurs ont demandé un mécanisme leur permettant d'écrire des programmes d'économiseur d'écran qui fournissent des fonctionnalités similaires à celles offertes par d'autres systèmes de fenêtrage. En particulier, ces utilisateurs souhaitent souvent pouvoir afficher des logos d'entreprise, des instructions sur la manière de réactiver l'écran, et des utilitaires de verrouillage d'écran automatique. Cette extension fournit un moyen d'écrire de tels clients.

Hypothèses

Cette extension exporte la notion d'une fenêtre d'économiseur d'écran spéciale qui est mappée au-dessus de toutes les autres fenêtres d'un écran. Cette fenêtre a l'attribut override-redirect défini de sorte qu'elle ne soit pas soumise à la manipulation par le gestionnaire de fenêtres. De plus, l'identifiant X de la fenêtre n'est jamais retourné par les requêtes QueryTree sur la fenêtre racine, de sorte qu'elle n'est généralement pas visible par les autres clients.

XScreenSaverQueryExtension retourne True si l'extension XScreenSaver est disponible sur l'écran donné. Un client doit appeler XScreenSaverQueryExtension avant d'appeler toute autre fonction XScreenSaver afin de négocier une version de protocole compatible ; sinon, le comportement du client sera indéfini (XScreenSaver peut fonctionner ou non).

Si l'extension est prise en charge, le numéro d'événement pour les événements ScreenSaverNotify est retourné dans la valeur pointée par event_base. Comme aucun erreur supplémentaire n'est défini par cette extension, les résultats de error_base ne sont pas définis.

XScreenSaverQueryVersion retourne True si la requête a réussi ; les valeurs des versions majeures et mineures du protocole prises en charge par le serveur sont retournées dans major_version_return et minor_version_return.

XScreenSaverAllocInfo alloue et retourne une structure XScreenSaverInfo à utiliser dans les appels à XScreenSaverQueryInfo. Tous les champs de la structure sont initialisés à zéro. Si une mémoire insuffisante est disponible, NULL est retourné. Les résultats de cette routine peuvent être libérés en utilisant XFree.

XScreenSaverQueryInfo retourne des informations sur l'état actuel du serveur d'écran dans saver_info et une valeur non nulle est retournée. Si l'extension n'est pas prise en charge, saver_info n'est pas modifié et 0 est retourné.

Le champ state spécifie si l'économiseur d'écran est actuellement actif et comment la valeur til-or-since doit être interprétée :

Off
L'écran n'est actuellement pas protégé ; til-or-since spécifie le nombre de millisecondes avant que l'économiseur d'écran ne s'active.
On
L'écran est actuellement protégé ; til-or-since spécifie le nombre de millisecondes depuis l'activation de l'économiseur d'écran.
Disabled
L'économiseur d'écran est actuellement désactivé ; til-or-since vaut zéro.

Le champ kind spécifie le mécanisme qui est actuellement utilisé ou qui aurait été utilisé si l'écran avait été protégé :

Blanked
Le signal vidéo vers le moniteur d'affichage a été désactivé.
Internal
Une image d'économiseur d'écran intégrée, dépendant du serveur, a été affichée ; soit aucun client n'avait défini les attributs de la fenêtre de l'économiseur d'écran, soit un autre client avait capturé le serveur lorsque l'économiseur d'écran s'est activé.
External
La fenêtre de l'économiseur d'écran a été mappée avec les attributs définis par un client utilisant la requête ScreenSaverSetAttributes.

Le champ idle spécifie le nombre de millisecondes depuis la dernière entrée reçue de l'utilisateur sur l'un des périphériques d'entrée.
Le champ event-mask spécifie quels événements liés à l'économiseur d'écran, le cas échéant, ce client a demandés en utilisant ScreenSaverSelectInput.

XScreenSaverSelectInput demande que les événements liés à l'économiseur d'écran soient générés pour ce client. Si aucun bit n'est défini dans event-mask, aucun événement ne sera généré. Sinon, toute combinaison des bits suivants peut être définie :

ScreenSaverNotify
Si ce bit est défini, les événements ScreenSaverNotify sont générés chaque fois que l'économiseur d'écran est activé ou désactivé.
ScreenSaverCycle
Si ce bit est défini, les événements ScreenSaverNotify sont générés chaque fois que l'intervalle de cycle de l'économiseur d'écran est dépassé.

XScreenSaverSetAttributes définit les attributs à utiliser lors de la prochaine activation de l'économiseur d'écran externe. Si un autre client a actuellement les attributs définis, une erreur BadAccess est générée et la requête est ignorée.
Sinon, les attributs spécifiés sont vérifiés comme s'ils étaient utilisés dans une requête CreateWindow de base dont le parent est la racine. Le champ override-redirect est ignoré car il est implicitement défini à True. Si les attributs de la fenêtre entraînent une erreur conformément aux règles de CreateWindow, la requête est ignorée.
Sinon, les attributs sont stockés et prendront effet lors de la prochaine activation qui se produit lorsque le serveur n'est pas capturé par un autre client. Toutes les ressources spécifiées pour les attributs background-pixmap ou cursor peuvent être libérées immédiatement. Le

NOM

XScreenSaverRegister, XScreenSaverUnregister, XScreenSaverGetRegistered, XScreenSaverSuspend — fonctions du protocole X Screen Saver

SYNTAXIS

int XScreenSaverRegister(Display *display, Window root, XID xid, const char *type);

int XScreenSaverUnregister(Display *display, Window root);

int XScreenSaverGetRegistered(Display *display, Window root, XID *xid_return, const char **type_return);

int XScreenSaverSuspend(Display *display, Bool suspend);

DESCRIPTION

Ces fonctions implémentent le protocole X Screen Saver et sont destinées à être utilisées par des applications qui souhaitent contrôler le comportement de l'économiseur d'écran. Le protocole X Screen Saver est une extension du protocole X Window System qui fournit un moyen standardisé pour les applications d'interagir avec la fonctionnalité de l'économiseur d'écran.

La fonction XScreenSaverSetAttributes configure les attributs de la fenêtre de l'économiseur d'écran. Elle prend un identifiant de fenêtre drawable, un masque d'événements event-mask, un pixel foreground, un pixel background, une largeur width, une hauteur height, un décalage de bordure border, une largeur de bordure border-width, une profondeur depth, une carte de couleurs colormap, un pixmap de fond background-pixmap, un curseur cursor, et une mise en page layout.

Le serveur est libre de copier les ressources background-pixmap ou cursor ou de les utiliser telles quelles ; par conséquent, l'effet de la modification du contenu de ces ressources est indéfini. Si la colormap spécifiée n'existe plus lorsque l'économiseur d'écran s'active, la colormap du parent est utilisée à la place. Si aucune erreur n'est générée par cette requête, tous les attributs précédents de la fenêtre de l'économiseur d'écran définis par ce client sont libérés.

Lorsque l'économiseur d'écran s'active la prochaine fois et que le serveur n'est pas saisi par un autre client, la fenêtre de l'économiseur d'écran est créée, si nécessaire, et définie avec les attributs spécifiés, et les événements sont générés comme d'habitude. La carte de couleurs associée à la fenêtre de l'économiseur d'écran est installée. Enfin, la fenêtre de l'économiseur d'écran est mappée.

La fenêtre reste mappée et au sommet de l'ordre d'empilement jusqu'à ce que l'économiseur d'écran soit désactivé en réponse à une activité sur l'un des périphériques d'entrée utilisateur, une requête ForceScreenSaver avec une valeur de Reset, ou toute requête qui provoquerait le démappage de la fenêtre.

Si l'économiseur d'écran s'active alors que le serveur est saisi par un autre client, le mécanisme de sauvegarde interne est utilisé. La requête ForceScreenSaver peut être utilisée avec une valeur de Active pour désactiver le sauvegarde interne et activer la sauvegarde externe.

Si la connexion du client de l'économiseur d'écran au serveur est rompue pendant que l'économiseur d'écran est activé et que le mode de fermeture du client n'a pas été RetainPermanent ou RetainTemporary, l'économiseur d'écran actuel est désactivé et l'économiseur d'écran interne est immédiatement activé.

Lorsque l'économiseur d'écran est désactivé, la carte de couleurs de la fenêtre de l'économiseur d'écran est désinstallée et la fenêtre est démappée (sauf comme décrit ci-dessous). Le XID de l'économiseur d'écran est dissocié de la fenêtre et le serveur peut, mais n'est pas obligé de, détruire la fenêtre ainsi que tous ses enfants.

Lorsque l'économiseur d'écran est désactivé puis immédiatement réactivé (par exemple lors du changement d'économiseur d'écran), le serveur peut laisser la fenêtre de l'économiseur d'écran mappée (typiquement pour éviter de générer des expositions).

XScreenSaverUnsetAttributes demande au serveur de rejeter tous les attributs précédents de la fenêtre de l'économiseur d'écran définis par ce client.

XScreenSaverRegister stocke le XID donné dans la propriété _SCREEN_SAVER_ID (du type donné) sur la fenêtre racine de l'écran spécifié screen. Elle renvoie zéro si une erreur est rencontrée et que la propriété n'est pas modifiée, sinon elle renvoie une valeur non nulle.

XScreenSaverUnregister supprime toute propriété _SCREEN_SAVER_ID de la fenêtre racine de l'écran spécifié screen. Elle renvoie zéro si une erreur est rencontrée et que la propriété est modifiée, sinon elle renvoie une valeur non nulle.

XScreenSaverGetRegistered renvoie le XID et le type stockés dans la propriété _SCREEN_SAVER_ID sur la fenêtre racine de l'écran spécifié screen. Elle renvoie zéro si une erreur est rencontrée ou si la propriété n'existe pas ou n'est pas du bon format ; sinon elle renvoie une valeur non nulle.

XScreenSaverSuspend suspend temporairement l'économiseur d'écran et le minuteur DPMS si suspend est 'True', et redémarre le minuteur si suspend est 'False'.
Cette fonction doit être utilisée par des applications qui ne veulent pas que l'économiseur d'écran ou le DPMS soient activés pendant qu'elles, par exemple, sont en train de lire une séquence média, ou présentent continuellement des informations visuelles à l'utilisateur tout en étant dans un état non interactif. Cette fonction n'est pas destinée à être appelée par une application d'économiseur d'écran externe.
Si XScreenSaverSuspend est appelée plusieurs fois avec suspend défini sur 'True', elle doit être appelée un nombre égal de fois avec suspend défini sur 'False' afin que le minuteur de l'économiseur d'écran soit redémarré. Cette requête n'a aucun effet si un client tente de reprendre l'économiseur d'écran sans l'avoir d'abord suspendu. XScreenSaverSuspend ne peut donc pas être utilisée par un client pour reprendre l'économiseur d'écran s'il a été suspendu par un autre client.
Si un client qui a suspendu l'économiseur d'écran perd sa connexion au serveur X, le minuteur de l'économiseur d'écran sera automatiquement redémarré, sauf s'il est toujours suspendu par un autre client. La suspension du minuteur de l'économiseur d'écran n'empêche pas l'activation forcée de l'économiseur d'écran avec la requête ForceScreenSaver, ou la définition d'un mode DPMS avec la requête DPMSForceLevel.
XScreenSaverSuspend ne désactive pas non plus l'économiseur d'écran ou le DPMS s'ils sont actifs au moment où la requête pour les suspendre est reçue par le serveur X. Mais une fois qu'ils ont été désactivés, ils ne seront pas automatiquement réactivés, jusqu'à ce que le client ait annulé la suspension.

ERREURS

XScreenSaverSelectInput, XScreenSaverQueryInfo, XScreenSaverSetAttributes, et XScreenSaverUnsetAttributes généreront une erreur BadDrawable si drawable n'est pas un identifiant de dessin valide. Si des bits indéfinis sont définis dans event-mask, une erreur BadValue est générée par XScreenSaverSelectInput.

DISPONIBILITE

XScreenSaverSuspend est disponible dans la version 1.1 et les versions ultérieures de l'extension X Screen Saver. La version 1.1 est sortie pour la première fois avec X11R7.1.
