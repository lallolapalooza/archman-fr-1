XrmOptionDescRec(3)

Paquet: libx11

Licences: MIT AND X11

XrmInitialize(3) FONCTIONS XLIB XrmInitialize(3)

NOM

XrmInitialize, XrmParseCommand, XrmValue, XrmOptionKind, XrmOptionDescRec - initialiser le gestionnaire de ressources, les structures du gestionnaire de ressources et analyser la ligne de commande

SYNTAXE

#include <X11/Xresource.h>

void XrmInitialize(void);

void XrmParseCommand(XrmDatabase *database, XrmOptionDescList table, int table_count, _Xconst char *name, int *argc_in_out, char **argv_in_out);

ARGUMENTS

argc_in_out
Spécifie le nombre d'arguments et retourne le nombre d'arguments restants.
argv_in_out
Spécifie les arguments de la ligne de commande et retourne les arguments restants.
database
Spécifie la base de données des ressources.
name
Spécifie le nom de l'application.
table
Spécifie la table des arguments de la ligne de commande à analyser.
table_count
Spécifie le nombre d'entrées dans la table.

DESCRIPTION

La fonction XrmInitialize initialise le gestionnaire de ressources. Elle doit être appelée avant d'utiliser toute autre fonction Xrm.

La fonction XrmParseCommand analyse une paire (argc, argv) conformément à la table d'options spécifiée, charge les options reconnues dans la base de données spécifiée avec le type « String », et modifie la paire (argc, argv) pour supprimer toutes les options reconnues. Si la base de données contient NULL, XrmParseCommand crée une nouvelle base de données et retourne un pointeur vers celle-ci. Sinon, les entrées sont ajoutées à la base de données spécifiée. Si une base de données est créée, elle est créée dans la locale actuelle.

La table spécifiée est utilisée pour analyser la ligne de commande. Les options reconnues dans la table sont supprimées de argv, et les entrées sont ajoutées à la base de données de ressources spécifiée dans l'ordre où elles apparaissent dans argv. Les entrées de la table contiennent des informations sur la chaîne d'option, le nom de l'option, le style de l'option et une valeur à fournir si le type d'option est XrmoptionNoArg. Les noms d'options sont comparés octet par octet aux arguments de argv, indépendamment de toute locale. Les valeurs de ressources données dans la table sont stockées dans la base de données de ressources sans modification. Toutes les entrées de la base de données de ressources sont créées en utilisant une représentation de type « String ». L'argument argc spécifie le nombre d'arguments dans argv et est modifié à son retour pour indiquer le nombre d'arguments restants qui n'ont pas été analysés. L'argument name doit être le nom de votre application pour être utilisé dans la construction de l'entrée de la base de données. L'argument name est préfixé au resourceName dans la table d'options avant de stocker une entrée de base de données. L'argument name est traité comme un composant unique, même s'il contient des points. Aucun caractère de séparation (liaison) n'est inséré, donc la table doit contenir soit un point (.) soit un astérisque (*) comme premier caractère dans chaque entrée resourceName. Pour spécifier un nom de ressource plus complètement qualifié, l'entrée resourceName peut contenir plusieurs composants. Si l'argument name et les resourceNames ne sont pas dans l'encodage de caractères portable hôte, le résultat est dépendant de l'implémentation.

STRUCTURES

Les structures XrmValue, XrmOptionKind et XrmOptionDescRec contiennent :

typedef struct {
        unsigned int size;
        XPointer addr;
} XrmValue, *XrmValuePtr;
typedef enum {
        XrmoptionNoArg, /* La valeur est spécifiée dans XrmOptionDescRec.value */
        XrmoptionIsArg, /* La valeur est la chaîne d'option elle-même */
        XrmoptionStickyArg,     /* La valeur est les caractères suivant immédiatement l'option */
        XrmoptionSepArg,        /* La valeur est l'argument argv suivant */
        XrmoptionResArg,        /* Ressource et valeur dans l'argument argv suivant */
        XrmoptionSkipArg,       /* Ignorer cette option et l'argument argv suivant */
        XrmoptionSkipLine,      /* Ignorer cette option et le reste de argv */
        XrmoptionSkipNArgs      /* Ignorer cette option et les
                   arguments XrmOptionDescRec.value dans argv suivants */
} XrmOptionKind;
typedef struct {
        char *option;   /* Chaîne de spécification d'option dans argv                    */
        char *specifier;        /* Liaison et nom de ressource (sans nom d'application)    */
        XrmOptionKind argKind;  /* Quel style d'option c'est            */
        XPointer value; /* Valeur à fournir si XrmoptionNoArg ou
                   XrmoptionSkipNArgs   */
} XrmOptionDescRec, *XrmOptionDescList;
