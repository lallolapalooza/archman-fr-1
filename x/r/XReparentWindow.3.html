NOM

XReparentWindow - Reparenter des fenêtres

SYNTAXE

int XReparentWindow(Display *display, Window w, Window parent, int x, int y);

ARGUMENTS

display
Spécifie la connexion au serveur X.
parent
Spécifie la fenêtre parente.
w
Spécifie la fenêtre.
x

y
Spécifie les coordonnées x et y de la position dans la nouvelle fenêtre parente.

DESCRIPTION

Si la fenêtre spécifiée est mappée, XReparentWindow effectue automatiquement une requête UnmapWindow dessus, la retire de sa position actuelle dans la hiérarchie, et l'insère comme enfant de la fenêtre parente spécifiée. La fenêtre est placée au sommet de l'ordre de superposition par rapport aux fenêtres frères.

Après avoir reparenté la fenêtre spécifiée, XReparentWindow provoque la génération d'un événement ReparentNotify par le serveur X. Le membre override_redirect retourné dans cet événement est défini sur l'attribut correspondant de la fenêtre. Les clients gestionnaires de fenêtres doivent généralement ignorer cette fenêtre si ce membre est défini sur True. Finalement, si la fenêtre spécifiée était initialement mappée, le serveur X effectue automatiquement une requête MapWindow dessus.

Le serveur X effectue le traitement normal des expositions sur les fenêtres précédemment obscures. Le serveur X peut ne pas générer d'événements Expose pour les régions de la requête initiale UnmapWindow qui sont immédiatement obscurcies par la requête finale MapWindow. Une erreur BadMatch survient si :

  • La nouvelle fenêtre parente n'est pas sur le même écran que l'ancienne fenêtre parente.
  • La nouvelle fenêtre parente est la fenêtre spécifiée ou un inférieur de la fenêtre spécifiée.
  • Le nouveau parent est InputOnly, et la fenêtre ne l'est pas.
  • La fenêtre spécifiée a un fond ParentRelative, et la nouvelle fenêtre parente n'a pas la même profondeur que la fenêtre spécifiée.

XReparentWindow peut générer les erreurs BadMatch et BadWindow.

DIAGNOSTICS

BadWindow
Une valeur pour un argument Window ne nomme pas une fenêtre définie.
