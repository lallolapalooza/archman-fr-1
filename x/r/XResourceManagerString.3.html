XResourceManagerString(3) FONCTIONS XLIB XResourceManagerString(3)

NOM

XResourceManagerString, XScreenResourceString - obtenir les propriétés de ressources du serveur

SYNTAXE

char *XResourceManagerString(Display *display);

char *XScreenResourceString(Screen *screen);

ARGUMENTS

display
Spécifie la connexion au serveur X.
screen
Spécifie l'écran.

DESCRIPTION

La fonction XResourceManagerString retourne la propriété RESOURCE_MANAGER de la fenêtre racine du serveur de l'écran zéro, qui a été renvoyée lors de l'ouverture de la connexion à l'aide de XOpenDisplay. La propriété est convertie du type STRING vers la locale actuelle. La conversion est identique à celle produite par XmbTextPropertyToTextList pour une propriété STRING à élément unique. La chaîne renvoyée appartient à Xlib et ne doit pas être libérée par le client. La valeur de la propriété doit être dans un format acceptable par XrmGetStringDatabase. Si aucune propriété n'existe, NULL est renvoyé.

La fonction XScreenResourceString retourne la propriété SCREEN_RESOURCES de la fenêtre racine de l'écran spécifié. La propriété est convertie du type STRING vers la locale actuelle. La conversion est identique à celle produite par XmbTextPropertyToTextList pour une propriété STRING à élément unique. La valeur de la propriété doit être dans un format acceptable par XrmGetStringDatabase. Si aucune propriété n'existe, NULL est renvoyé. L'appelant est responsable de libérer la chaîne renvoyée en utilisant XFree.
