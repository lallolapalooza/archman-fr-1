XrmQPutResource(3)

Paquet: libx11

Licences: MIT AND X11

XrmPutResource(3) FONCTIONS XLIB XrmPutResource(3)

NOM

XrmPutResource, XrmQPutResource, XrmPutStringResource, XrmQPutStringResource, XrmPutLineResource - stocker des ressources de base de données

SYNTAXE

#include <X11/Xresource.h>

void XrmPutResource(XrmDatabase *database, char *specifier, char *type, XrmValue *value);

void XrmQPutResource(XrmDatabase *database, XrmBindingList bindings, XrmQuarkList quarks, XrmRepresentation type, XrmValue *value);

void XrmPutStringResource(XrmDatabase *database, _Xconst char *specifier, _Xconst char *value);

void XrmQPutStringResource(XrmDatabase *database, XrmBindingList bindings, XrmQuarkList quarks, _Xconst char *value);

void XrmPutLineResource(XrmDatabase *database, _Xconst char *line);

ARGUMENTS

bindings
Spécifie une liste de liaisons.
database
Spécifie la base de données des ressources.
line
Spécifie le nom de la ressource et la paire de valeurs sous forme d'une chaîne unique.
quarks
Spécifie le nom complet ou partiel ou la liste de classes de la ressource.
specifier
Spécifie une spécification complète ou partielle de la ressource.
type
Spécifie le type de la ressource.
value
Spécifie la valeur de la ressource, qui est fournie sous forme de chaîne.

DESCRIPTION

Si database contient NULL, XrmPutResource crée une nouvelle base de données et retourne un pointeur vers celle-ci. XrmPutResource est une fonction pratique qui appelle XrmStringToBindingQuarkList suivi de :

XrmQPutResource(database, bindings, quarks, XrmStringToQuark(type), value)

Si le spécificateur et le type ne sont pas dans l'encodage de caractères portable hôte, le résultat dépend de l'implémentation. La valeur est stockée dans la base de données sans modification.

Si database contient NULL, XrmQPutResource crée une nouvelle base de données et retourne un pointeur vers celle-ci. Si une entrée de ressource avec les mêmes liaisons et quarks existe déjà dans la base de données, le type et la valeur précédents sont remplacés par le nouveau type et la nouvelle valeur spécifiés. La valeur est stockée dans la base de données sans modification.

Si database contient NULL, XrmPutStringResource crée une nouvelle base de données et retourne un pointeur vers celle-ci. XrmPutStringResource ajoute une ressource avec la valeur spécifiée à la base de données spécifiée. XrmPutStringResource est une fonction pratique qui appelle d'abord XrmStringToBindingQuarkList sur le spécificateur, puis appelle XrmQPutResource, en utilisant un type de représentation "String". Si le spécificateur n'est pas dans l'encodage de caractères portable hôte, le résultat dépend de l'implémentation. La valeur est stockée dans la base de données sans modification.

Si database contient NULL, XrmQPutStringResource crée une nouvelle base de données et retourne un pointeur vers celle-ci. XrmQPutStringResource est une routine pratique qui construit une XrmValue pour la chaîne de valeur (en appelant strlen pour calculer la taille), puis appelle XrmQPutResource, en utilisant un type de représentation "String". La valeur est stockée dans la base de données sans modification.

Si database contient NULL, XrmPutLineResource crée une nouvelle base de données et retourne un pointeur vers celle-ci. XrmPutLineResource ajoute une seule entrée de ressource à la base de données spécifiée. La ligne doit être au format valide ResourceLine (voir section 15.1) terminée par un caractère de nouvelle ligne ou nul ; la base de données résultant de l'utilisation d'une chaîne avec une syntaxe incorrecte dépend de l'implémentation. La chaîne est analysée dans la locale de la base de données. Si le ResourceName n'est pas dans l'encodage de caractères portable hôte, le résultat dépend de l'implémentation. Notez que les lignes de commentaire ne sont pas stockées.
