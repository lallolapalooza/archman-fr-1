NOM

XrmMergeDatabases, XrmCombineDatabase, XrmCombineFileDatabase - fusionner des bases de données de ressources

SYNTAXE

#include <X11/Xresource.h>

void XrmMergeDatabases(XrmDatabase source_db, XrmDatabase *target_db);

void XrmCombineDatabase(XrmDatabase source_db, XrmDatabase *target_db, Bool override);

Status XrmCombineFileDatabase(_Xconst char *filename, XrmDatabase *target_db, Bool override);

ARGUMENTS

source_db
Spécifie la base de données de ressources à fusionner dans la base de données cible.
target_db
Spécifie la base de données de ressources dans laquelle la base de données source doit être fusionnée.
filename
Spécifie le nom du fichier de la base de données de ressources.
override
Spécifie si les entrées source remplacent celles de la cible.

DESCRIPTION

Appeler la fonction XrmMergeDatabases équivaut à appeler la fonction XrmCombineDatabase avec un argument d'écrasement de True.

La fonction XrmCombineDatabase fusionne le contenu d'une base de données dans une autre. Si le même spécificateur est utilisé pour une entrée dans les deux bases de données, l'entrée de source_db remplacera l'entrée dans target_db si override est True ; sinon, l'entrée dans source_db est rejetée. Si target_db contient NULL, XrmCombineDatabase y stocke simplement source_db. Sinon, source_db est détruite par la fusion, mais la base de données pointée par target_db n'est pas détruite. Les entrées de la base de données sont fusionnées sans modification des valeurs ou des types, quelle que soit la locale des bases de données. La locale de la base de données cible n'est pas modifiée.

La fonction XrmCombineFileDatabase fusionne le contenu d'un fichier de ressources dans une base de données. Si le même spécificateur est utilisé pour une entrée dans le fichier et la base de données, l'entrée du fichier remplacera l'entrée de la base de données si override est True ; sinon, l'entrée du fichier est rejetée. Le fichier est analysé dans la locale actuelle. Si le fichier ne peut pas être lu, un statut zéro est renvoyé ; sinon, un statut non nul est renvoyé. Si target_db contient NULL, XrmCombineFileDatabase crée et renvoie une nouvelle base de données vers celui-ci. Sinon, la base de données pointée par target_db n'est pas détruite par la fusion. Les entrées de la base de données sont fusionnées sans modification des valeurs ou des types, quelle que soit la locale de la base de données. La locale de la base de données cible n'est pas modifiée.
