XResQueryClientResources(3)

Paquet: libxres

Licences: X11

XRes(3) X Version 11 XRes(3)

NOM

XRes - bibliothèque cliente d'extension X-Resource

SYNTAXE

#include <X11/extensions/XRes.h>

typedef struct {
	XID	resource_base;
	XID	resource_mask;
} XResClient;

typedef struct {
	Atom	resource_type;
	unsigned int	count;
} XResType;
Bool XResQueryExtension(Display *dpy,
    int *event_base_return, int *error_base_return);
Status XResQueryVersion(Display *dpy,
    int *major_version_return, int *minor_version_return);
Status XResQueryClients(Display *dpy,
    int *num_clients, XResClient **clients);
Status XResQueryClientResources(Display *dpy, XID xid,
    int *num_types, XResType **types);
Status XResQueryClientPixmapBytes(Display *dpy, XID xid,
    unsigned long *bytes);

DESCRIPTION

L'extension X-Resource permet à un client d'interroger le serveur X sur son utilisation des différentes ressources. Elle ne doit pas être confondue avec les fonctions d'accès à la base de données des ressources X.

XResQueryExtension renvoie True si l'extension XRes est disponible sur l'affichage donné. Un client doit appeler XResQueryExtension avant d'appeler toute autre fonction XRes afin de négocier une version de protocole compatible ; sinon, le client obtiendra un comportement indéfini (XRes peut fonctionner ou non).

XResQueryVersion renvoie True si la requête a réussi ; les valeurs des versions majeures et mineures du protocole prises en charge par le serveur sont retournées dans major_version_return et minor_version_return.

XResQueryClients remplit une liste des clients de l'affichage donné. Pour chaque client, il retourne dans la structure XResClient un masque et une valeur de base des ressources utilisées par ces clients. Renvoie True en cas de succès ou False en cas d'échec.

XResQueryClientResources remplit une liste de structures XResType, indiquant pour chaque type de ressource alloué par le client son nom (en tant qu'Atom) et le nombre de ressources de ce type allouées. Renvoie True en cas de succès ou False en cas d'échec.

XResQueryClientPixmapBytes donne, pour les ressources de type PIXMAP, le nombre total d'octets alloués dans le serveur X par le client donné. Renvoie True en cas de succès ou False en cas d'échec.

ERREURS

XResQueryClientResources et XResQueryClientPixmapBytes renverront BadValue si un identifiant de client illégal est passé.
