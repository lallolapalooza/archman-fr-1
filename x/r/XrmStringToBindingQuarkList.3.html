XrmUniqueQuark, XrmStringToQuark, XrmPermStringToQuark, XrmQuarkToString, XrmStringToQuarkList, XrmStringToBindingQuarkList - manipuler les quarks de ressources

ARGUMENTS

bindings_return
Retourne la liste des liaisons.
quark
Spécifie le quark dont la chaîne de caractères équivalente est désirée.
quarks_return
Retourne la liste des quarks.
string
Spécifie la chaîne de caractères pour laquelle un quark ou une liste de quarks doit être alloué.

DESCRIPTION

La fonction XrmUniqueQuark alloue un quark qui est garanti de ne pas représenter une chaîne de caractères connue du gestionnaire de ressources.

Ces fonctions peuvent être utilisées pour convertir une chaîne de caractères en une représentation quark. Si la chaîne n'est pas dans l'encodage de caractères portable hôte, la conversion dépend de l'implémentation. L'argument string de XrmStringToQuark n'a pas besoin d'être stocké dans un espace alloué de manière permanente. XrmPermStringToQuark est identique à XrmStringToQuark, sauf que Xlib est autorisé à supposer que l'argument string est alloué de manière permanente, et, par conséquent, qu'il peut être utilisé comme valeur retournée par XrmQuarkToString.

Pour un quark donné, si XrmStringToQuark retourne une valeur non NULL, tous les appels futurs retourneront la même valeur (adresse identique).

Ces fonctions peuvent être utilisées pour convertir une représentation quark en une chaîne de caractères. La chaîne pointée par la valeur de retour ne doit pas être modifiée ou libérée. La chaîne retournée est identique, caractère par caractère, à la chaîne originale passée à l'une des routines de conversion chaîne-vers-quark. Si aucune chaîne n'existe pour ce quark, XrmQuarkToString retourne NULL. Pour un quark donné, si XrmQuarkToString retourne une valeur non NULL, tous les appels futurs retourneront la même valeur (adresse identique).

Ces fonctions peuvent être utilisées pour convertir une chaîne de caractères en une représentation quark. Si la chaîne n'est pas dans l'encodage de caractères portable hôte, la conversion dépend de l'implémentation. L'argument string de XrmStringToQuark n'a pas besoin d'être stocké dans un espace alloué de manière permanente. XrmPermStringToQuark est identique à XrmStringToQuark, sauf que Xlib est autorisé à supposer que l'argument string est alloué de manière permanente, et, par conséquent, qu'il peut être utilisé comme valeur retournée par XrmQuarkToString.

Pour un quark donné, si XrmStringToQuark retourne une valeur non NULL, tous les appels futurs retourneront la même valeur (adresse identique).

La fonction XrmStringToQuarkList convertit la chaîne de caractères terminée par un caractère nul (généralement un nom complètement qualifié) en une liste de quarks. L'appelant doit allouer suffisamment d'espace pour la liste des quarks avant d'appeler XrmStringToQuarkList. Notez que la chaîne doit être dans le format valide de nom de ressource (voir section 15.1). Si la chaîne n'est pas dans l'encodage de caractères portable hôte, la conversion dépend de l'implémentation.

Une liste de liaisons est une liste de type XrmBindingList et indique si les composants des listes de noms ou de classes sont liés étroitement ou lâchement (c'est-à-dire, si l'utilisation de caractères joker pour les composants intermédiaires est spécifiée).

typedef enum {XrmBindTightly, XrmBindLoosely} XrmBinding, *XrmBindingList;

XrmBindTightly indique qu'un point sépare les composants, et XrmBindLoosely indique qu'un astérisque sépare les composants.

La fonction XrmStringToBindingQuarkList convertit la chaîne spécifiée en une liste de liaisons et une liste de quarks. L'appelant doit allouer suffisamment d'espace pour la liste des quarks et la liste des liaisons avant d'appeler XrmStringToBindingQuarkList. Si la chaîne n'est pas dans l'encodage de caractères portable hôte, la conversion dépend de l'implémentation. Les noms des composants de la liste sont séparés par un point ou un astérisque. Si la chaîne ne commence pas par un point ou un astérisque, un point est supposé. Par exemple, “*a.b*c” devient :

quarks a b c
liaisons lâche serrée lâche
