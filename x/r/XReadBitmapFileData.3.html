XReadBitmapFile(3) FONCTIONS XLIB XReadBitmapFile(3)

NOM

XReadBitmapFile, XReadBitmapFileData, XWriteBitmapFile, XCreatePixmapFromBitmapData, XCreateBitmapFromData - manipuler les bitmaps

SYNTAXE

int XReadBitmapFile(Display *display, Drawable d, _Xconst char *filename, unsigned int *width_return, unsigned int *height_return, Pixmap *bitmap_return, int *x_hot_return, int *y_hot_return);

int XReadBitmapFileData(_Xconst char *filename, unsigned int *width_return, unsigned int *height_return, unsigned char **data_return, int *x_hot_return, int *y_hot_return);

int XWriteBitmapFile(Display *display, _Xconst char *filename, Pixmap bitmap, unsigned int width, unsigned int height, int x_hot, int y_hot);

Pixmap XCreatePixmapFromBitmapData(Display *display, Drawable d, char *data, unsigned int width, unsigned int height, unsigned long fg, unsigned long bg, unsigned int depth);

Pixmap XCreateBitmapFromData(Display *display, Drawable d, _Xconst char *data, unsigned int width, unsigned int height);

ARGUMENTS

bitmap
Spécifie la bitmap.
bitmap_return
Retourne la bitmap qui est créée.
d
Spécifie le dessinable qui indique l'écran.
data
Spécifie les données au format bitmap.
data
Spécifie l'emplacement des données de la bitmap.
data_return
Retourne les données de la bitmap.
depth
Spécifie la profondeur de la pixmap.
display
Spécifie la connexion au serveur X.
fg

bg
Spécifie les valeurs de pixel de premier plan et d'arrière-plan à utiliser.
filename
Spécifie le nom du fichier à utiliser. Le format du nom de fichier dépend du système d'exploitation.
width

height
Spécifie la largeur et la hauteur.
width_return

height_return
Retourne les valeurs de largeur et de hauteur du fichier bitmap lu.
x_hot

y_hot
Spécifie où placer les coordonnées du point chaud (ou -1,-1 s'il n'y en a pas) dans le fichier.
x_hot_return

y_hot_return
Retourne les coordonnées du point chaud.

DESCRIPTION

La fonction XReadBitmapFile lit un fichier contenant une bitmap. Le fichier est analysé dans le codage de la locale actuelle. La capacité de lire autre chose que le format standard dépend de l'implémentation. Si le fichier ne peut pas être ouvert, XReadBitmapFile retourne BitmapOpenFailed. Si le fichier peut être ouvert mais ne contient pas de données bitmap valides, il retourne BitmapFileInvalid. Si un espace de travail insuffisant est alloué, il retourne BitmapNoMemory. Si le fichier est lisible et valide, il retourne BitmapSuccess.

XReadBitmapFile retourne la hauteur et la largeur de la bitmap, telles que lues depuis le fichier, à width_return et height_return. Elle crée ensuite une pixmap de la taille appropriée, lit les données de la bitmap depuis le fichier dans la pixmap et assigne la pixmap à la variable bitmap de l'appelant. L'appelant doit libérer la pixmap en utilisant XFreePixmap une fois terminé. Si nom_x_hot et nom_y_hot existent, XReadBitmapFile les retourne à x_hot_return et y_hot_return ; sinon, elle retourne -1,-1.

XReadBitmapFile peut générer des erreurs BadAlloc et BadDrawable.

La fonction XReadBitmapFileData lit un fichier contenant une bitmap, de la même manière que XReadBitmapFile, mais retourne les données directement plutôt que de créer une pixmap dans le serveur. Les données de la bitmap sont retournées dans data_return ; le client doit libérer cet espace une fois qu'il a terminé en appelant XFree. Le statut et les autres valeurs de retour sont les mêmes que pour XReadBitmapFile.

La fonction XWriteBitmapFile écrit une bitmap dans un fichier au format X Version 11. Le nom utilisé dans le fichier de sortie est dérivé du nom de fichier en supprimant le préfixe du répertoire. Le fichier est écrit dans le codage de la locale actuelle. Si le fichier ne peut pas être ouvert en écriture, elle retourne BitmapOpenFailed. Si une mémoire insuffisante est allouée, XWriteBitmapFile retourne BitmapNoMemory ; sinon, en l'absence d'erreur, elle retourne BitmapSuccess. Si x_hot et y_hot ne sont pas -1, -1, XWriteBitmapFile les écrit comme coordonnées du point chaud pour la bitmap.

XWriteBitmapFile peut générer des erreurs BadDrawable et BadMatch.

La fonction XCreatePixmapFromBitmapData crée une pixmap de la profondeur donnée, puis effectue un XPutImage au format bitmap des données dans celle-ci. La profondeur doit être supportée par l'écran du dessinable spécifié, sinon une erreur BadMatch est générée.

XCreatePixmapFromBitmapData peut générer des erreurs BadAlloc et BadMatch.

La fonction XCreateBitmapFromData vous permet d'inclure dans votre programme C (en utilisant #include) un fichier bitmap qui a été écrit par XWriteBitmapFile (format X version 11 uniquement) sans avoir à lire le fichier bitmap. L'exemple suivant crée une bitmap grise :

#include "gray.bitmap"

Pixmap bitmap;
bitmap = XCreateBitmapFromData(display, window, gray_bits, gray_width, gray_height);

Si un espace de travail insuffisant a été alloué, XCreateBitmapFromData retourne None. Il est de votre responsabilité de libérer la pixmap en utilisant XFreePixmap une fois terminé.

XCreateBitmapFromData peut générer une erreur BadAlloc.

DIAGNOSTICS

BadAlloc
Le serveur n'a pas pu allouer la ressource ou la mémoire serveur demandée.
BadDrawable
Une valeur pour un argument Drawable ne nomme pas une fenêtre ou une pixmap définie.
BadMatch
Une fenêtre InputOnly est utilisée comme un Drawable.

VOIR AUSSI

XCreatePixmap(3), XPutImage(3)

NOM

XReadBitmapFileData — lit un fichier bitmap X et renvoie une structure Pixmap.

SYNTAXE

Pixmap XReadBitmapFileData(Display *display, Drawable d, char *filename, unsigned int *width_return, unsigned int *height_return, int *x_hot_return, int *y_hot_return);

ARGUMENTS

  • display : Spécifie la connexion au serveur X.
  • d : Spécifie le Drawable pour lequel la Pixmap est créée.
  • filename : Spécifie le nom du fichier bitmap à lire.
  • width_return : Renvoie la largeur de la bitmap lue.
  • height_return : Renvoie la hauteur de la bitmap lue.
  • x_hot_return : Renvoie la coordonnée x du point chaud (hot spot).
  • y_hot_return : Renvoie la coordonnée y du point chaud (hot spot).

DESCRIPTION

XReadBitmapFileData lit le fichier spécifié par filename, crée une Pixmap dans le display spécifié et renvoie la Pixmap. Les dimensions de la bitmap et les coordonnées du point chaud sont renvoyées via les arguments width_return, height_return, x_hot_return et y_hot_return.

Le fichier doit être au format bitmap X, qui est un format texte décrivant une bitmap 1 bit par pixel. Le fichier peut contenir des définitions pour la largeur, la hauteur, le point chaud et les données de la bitmap. Si le fichier ne spécifie pas toutes ces informations, des valeurs par défaut seront utilisées.

La Pixmap créée est associée au Drawable spécifié par d. Cela signifie que la Pixmap aura les mêmes attributs que le Drawable, tels que le profondeur et le jeu de couleurs.

DIAGNOSTICS

XReadBitmapFileData renvoie None en cas d'erreur, par exemple si le fichier ne peut pas être ouvert ou lu, ou si le format du fichier est incorrect.

VOIR AUSSI

XCreatePixmap(3), XReadBitmapFile(3)
