XLookupKeysym(3) FONCTIONS XLIB XLookupKeysym(3)

NOM

XLookupKeysym, XRefreshKeyboardMapping, XLookupString, XRebindKeysym - gérer les événements d'entrée clavier en Latin-1

SYNTAXE

KeySym XLookupKeysym(XKeyEvent *key_event, int index);

int XRefreshKeyboardMapping(XMappingEvent *event_map);

int XLookupString(XKeyEvent *event_struct, char *buffer_return, int bytes_buffer, KeySym *keysym_return, XComposeStatus *status_in_out);

int XRebindKeysym(Display *display, KeySym keysym, KeySym list[], int mod_count, _Xconst unsigned char *string, int num_bytes);

ARGUMENTS

buffer_return
Retourne les caractères traduits.
bytes_buffer
Spécifie la longueur du tampon. Pas plus de bytes_buffer de traduction sont retournés.
num_bytes
Spécifie le nombre d'octets dans l'argument string.
display
Spécifie la connexion au serveur X.
event_map
Spécifie l'événement de mapping à utiliser.
event_struct
Spécifie la structure d'événement clavier à utiliser. Vous pouvez passer XKeyPressedEvent ou XKeyReleasedEvent.
index
Spécifie l'index dans la liste KeySyms pour le KeyCode de l'événement.
key_event
Spécifie l'événement KeyPress ou KeyRelease.
keysym
Spécifie le KeySym qui doit être retourné.
keysym_return
Retourne le KeySym calculé à partir de l'événement si cet argument n'est pas NULL.
list
Spécifie les KeySyms à utiliser comme modificateurs.
mod_count
Spécifie le nombre de modificateurs dans la liste des modificateurs.
status_in_out
Spécifie ou retourne la structure XComposeStatus ou NULL.
string
Spécifie la chaîne de caractères qui est copiée et sera retournée par XLookupString.

DESCRIPTION

La fonction XLookupKeysym utilise un événement clavier donné et l'index que vous avez spécifié pour retourner le KeySym de la liste qui correspond au membre KeyCode dans la structure XKeyPressedEvent ou XKeyReleasedEvent. Si aucun KeySym n'est défini pour le KeyCode de l'événement, XLookupKeysym retourne NoSymbol.

La fonction XRefreshKeyboardMapping rafraîchit les informations stockées sur les modificateurs et la table de correspondance clavier. Vous appelez généralement cette fonction lorsqu'un événement MappingNotify avec un membre request de MappingKeyboard ou MappingModifier se produit. Le résultat est de mettre à jour la connaissance du clavier par Xlib.

La fonction XLookupString traduit un événement clavier en un KeySym et une chaîne de caractères. Le KeySym est obtenu en utilisant l'interprétation standard des modificateurs Shift, Lock, groupe et numlock tels que définis dans la spécification X Protocol. Si le KeySym a été réaffecté (voir XRebindKeysym), la chaîne réaffectée sera stockée dans le tampon. Sinon, le KeySym est mappé, si possible, à un caractère ISO Latin-1 ou (si le modificateur Control est activé) à un caractère de contrôle ASCII, et ce caractère est stocké dans le tampon. XLookupString retourne le nombre de caractères stockés dans le tampon.

Si elle est présente (non-NULL), la structure XComposeStatus enregistre l'état, qui est privé à Xlib, et qui doit être préservé entre les appels à XLookupString pour implémenter le traitement de composition. La création de structures XComposeStatus dépend de l'implémentation ; un programme portable doit passer NULL pour cet argument.

La fonction XRebindKeysym peut être utilisée pour réaffecter la signification d'un KeySym pour le client. Elle ne redéfinit pas de touche dans le serveur X mais fournit simplement un moyen simple d'attacher de longues chaînes à des touches. XLookupString retourne cette chaîne lorsque l'ensemble approprié de touches modificatrices est pressé et lorsque le KeySym aurait été utilisé pour la traduction. Aucune conversion de texte n'est effectuée ; le client est responsable de fournir des chaînes encodées de manière appropriée. Notez que vous pouvez réaffecter un KeySym qui pourrait ne pas exister.
