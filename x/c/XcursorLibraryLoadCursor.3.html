NOM

Xcursor - Bibliothèque de gestion des curseurs

SYNTAXE

#include <X11/Xcursor/Xcursor.h>

DESCRIPTION

Xcursor est une bibliothèque simple conçue pour aider à localiser et charger des curseurs. Les curseurs peuvent être chargés depuis des fichiers ou la mémoire. Une bibliothèque de curseurs courants existe, qui mappe aux noms de curseurs X standard. Les curseurs peuvent exister en plusieurs tailles et la bibliothèque en choisit automatiquement la meilleure taille.

APERÇU FONCTIONNEL

Xcursor est construit en plusieurs couches ; la couche inférieure contient le code capable de charger des images de curseur à partir de fichiers. Au-dessus se trouve une couche qui localise les fichiers de curseurs en fonction du chemin de la bibliothèque et du thème. Au sommet se trouve une couche qui construit des curseurs soit à partir d'une image chargée depuis un fichier, soit à partir de l'un des curseurs X standard. Lors de l'utilisation d'images chargées à partir de fichiers, Xcursor préfère utiliser la requête CreateCursor de l'extension Render si elle est prise en charge par le serveur X. Lorsque ce n'est pas pris en charge, Xcursor mappe l'image du curseur à un curseur X standard et utilise la requête CreateCursor principale.

FICHIERS DE CURSEUR

Xcursor définit un nouveau format pour les curseurs sur disque. Chaque fichier contient une ou plusieurs images de curseur. Chaque image de curseur est étiquetée avec une taille nominale afin que la meilleure taille puisse être sélectionnée automatiquement. Plusieurs curseurs de la même taille nominale peuvent être chargés ensemble ; les applications sont censées les utiliser comme une séquence animée.

Les fichiers de curseur sont stockés sous forme d'un en-tête contenant une table des matières suivie d'une séquence de blocs. La table des matières indique le type, le sous-type et la position dans le fichier de chaque bloc. L'en-tête du fichier ressemble à ceci :


magic:	CARD32 « Xcur » (0x58, 0x63, 0x75, 0x72)
header:	CARD32 octets dans cet en-tête
version:	CARD32 numéro de version du fichier
ntoc:	CARD32 nombre d'entrées de la table des matières
toc:	LISTofTOC table des matières

Chaque entrée de la table des matières ressemble à ceci :


type:	CARD32 type d'entrée
subtype:	CARD32 étiquette spécifique au type - taille pour les images
position:	CARD32 position absolue en octets de la table dans le fichier

Chaque bloc dans le fichier a un ensemble d'en-têtes communs suivis de champs supplémentaires spécifiques au type :


header:	CARD32 octets dans l'en-tête du bloc (y compris les champs spécifiques au type)
type:	CARD32 doit correspondre au type dans la TOC pour ce bloc
subtype:	CARD32 doit correspondre au sous-type dans la TOC pour ce bloc
version:	CARD32 numéro de version pour ce type de bloc

Il existe actuellement deux types de blocs définis pour les fichiers de curseurs ; les commentaires et les images. Les commentaires ressemblent à ceci :


header:	20 Les en-têtes de commentaires font 20 octets
type:	0xfffe0001 Le type de commentaire est 0xfffe0001
subtype:	{ 1 (COPYRIGHT), 2 (LICENSE), 3 (OTHER) }
version:	1
length:	CARD32 longueur en octets de la chaîne UTF-8
string:	LISTofCARD8 chaîne UTF-8

Les images ressemblent à ceci :


header:	36 Les en-têtes d'image font 36 octets
type:	0xfffd0002 Le type d'image est 0xfffd0002
subtype:	CARD32 Le sous-type d'image est la taille nominale
version:	1
width:	CARD32 Doit être inférieur ou égal à 0x7fff
height:	CARD32 Doit être inférieur ou égal à 0x7fff
xhot:	CARD32 Doit être inférieur ou égal à la largeur
yhot:	CARD32 Doit être inférieur ou égal à la hauteur
delay:	CARD32 Délai entre les images d'animation en millisecondes
pixels:	LISTofCARD32 Pixels au format ARGB compressé

THÈMES

Xcursor suit (en grande partie) la spécification freedesktop.org pour la thémisation des icônes. Le chemin de recherche par défaut qu'il utilise est

~/.local/share/icons, ~/.icons, /usr/share/icons, /usr/share/pixmaps

Dans chacun de ces répertoires, il recherche un répertoire utilisant le nom du thème :

•
Dans le répertoire du thème, il recherche les fichiers de curseur dans le sous-répertoire « cursors ».
Xcursor recherche un fichier spécifique, qui doit être l'un des noms de forme de curseur, comme ceux utilisés dans XcursorLibraryLoadImage ou XcursorLibraryShape.
•
S'il ne trouve aucun fichier de curseur correspondant dans le sous-répertoire « cursors », Xcursor recherche ensuite un fichier « index.theme » dans chaque répertoire de thème pour rechercher les thèmes hérités. Ce sont des lignes de ce format :
Inherits = nom-du-thème

Xcursor utilise le premier nom-du-thème hérité, en ignorant les autres qui pourraient exister dans un fichier « index.theme » donné. S'il trouve un thème hérité, Xcursor recherche également le chemin pour l'utiliser. Xcursor ignore les autres clés dans le fichier « index.theme », y compris « Name » (c'est-à-dire le nom qu'une application graphique peut utiliser comme nom de présentation).

Plusieurs nom-du-thème peuvent être listés sur la ligne Inherits=. La spécification freedesktop.org indique que les éléments de la liste sont séparés par des virgules. Xcursor accepte également le point-virgule, mais traduit les deux en deux-points lors de la recherche dans le chemin. Xcursor attend une seule ligne Inherits= ; la spécification freedesktop.org n'est pas claire quant à savoir si plusieurs clés sont autorisées.

Si aucun thème n'est défini, ou si aucun curseur n'est trouvé pour le thème spécifié n'importe où sur le chemin, Xcursor vérifie le thème « default ».

Lorsque Xcursor trouve un fichier de curseur, il arrête la recherche. Il utilise toujours le premier fichier de curseur trouvé lors de la recherche le long du chemin.

TYPES DE DONNÉES

XcursorImage
contient une seule image de curseur en mémoire. Chaque pixel du curseur est une valeur de 32 bits contenant ARGB avec A dans l'octet de poids fort. 


typedef struct _XcursorImage {
    XcursorDim 	 size; 	/* taille nominale pour la correspondance */
    XcursorDim 	 width; 	/* largeur réelle */
    XcursorDim 	 height; 	/* hauteur réelle */
    XcursorDim 	 xhot; 	/* point chaud x (doit être à l'intérieur de l'image) */
    XcursorDim 	 yhot; 	/* point chaud y (doit être à l'intérieur de l'image) */
    XcursorPixel 	*pixels; 	/* pointeur vers les pixels */
} XcursorImage;
XcursorImages
contient plusieurs structures XcursorImage. Elles sont toutes libérées lorsque XcursorImages est libéré dans XcursorImagesDestroy. 


typedef struct _XcursorImages {
    int 	 nimage; 	/* nombre d'images */
    XcursorImage 	**images; 	/* tableau de pointeurs XcursorImage */
} XcursorImages;
XcursorCursors
Contient plusieurs objets Cursor. Ils sont tous libérés lorsque XcursorCursors est libéré. Ils sont référencés par compteurs de références afin que plusieurs structures XcursorAnimate puissent utiliser le même XcursorCursors. 


typedef struct _XcursorCursors {
    Display 	*dpy; 	/* Affichage contenant les curseurs */
    int 	 ref; 	/* compteur de références */
    int 	 ncursor; 	/* nombre de curseurs */
    Cursor 	*cursors; 	/* tableau de curseurs */
} XcursorCursors;
XcursorAnimate
Référence un ensemble de curseurs et une séquence dans cet ensemble. Plusieurs structures XcursorAnimate peuvent référencer le même XcursorCursors ; chacune détient une référence qui est supprimée lorsque XcursorAnimate est libéré. 


typedef struct _XcursorAnimate {
    XcursorCursors 	*cursors; 	/* liste des curseurs à utiliser */
    int 	 sequence; 	/* quel est le prochain curseur */
} XcursorAnimate;

Lecture d'images de bibliothèque

XcursorImage *XcursorLibraryLoadImage (
const char 	*name,
const char 	*theme,
int 	 size)
XcursorImages *XcursorLibraryLoadImages (
	const char 	*name,
	const char 	*theme,
	int 	 size)

Ces fonctions recherchent dans le chemin de la bibliothèque, chargeant le premier fichier trouvé de la taille souhaitée, en utilisant une fonction privée (XcursorScanTheme) pour trouver le thème approprié :

  • Si theme n'est pas NULL, utilisez-le.
  • Si theme est NULL, ou s'il n'y a pas eu de correspondance pour le thème souhaité, utilisez "default" comme nom de thème.
  • Si aucune recherche ne réussit, ces fonctions retournent NULL.
Les deux fonctions diffèrent par plus que le nombre d'images chargées :
  • XcursorLibraryLoadImage appelle XcursorFileLoadImage mais
  • XcursorLibraryLoadImages appelle XcursorFileLoadImages, et (en cas de succès) elle appelle XcursorImagesSetName pour associer name au résultat.

ENVIRONNEMENT
\n
Les variables d'environnement peuvent être utilisées pour remplacer les paramètres de ressources, qui à leur tour remplacent les valeurs par défaut compilées.
\n
Certaines des variables d'environnement reconnues par Xcursor sont booléennes, spécifiées comme suit :
\n
\n
\n  
vrai pour “t”, “1”, “y” ou “on”
\n  
\n  
faux pour “f”, “0”, “n” ou “off”
\n  
\n
\n
\n
Xcursor ignore les autres valeurs pour ces booléens.
\n
\n  
HOME
\n  
Xcursor interprète “~” dans la liste de recherche comme le répertoire personnel, en utilisant cette variable plutôt que la base de données des mots de passe.
\n

NAME


XcursorLibraryLoadCursor, XcursorLibraryLoadIconCursor, XcursorLibraryLoadHotspot, XcursorLibraryLoadCursorFromFile, XcursorLibraryLoadCursorFromPixels - load cursors






SYNOPSIS


#include <Xcursor/Xcursor.h>

XcursorBool
XcursorLibraryLoadCursor(
    Display *dpy,
    const char *name,
    XcursorCursor **outcursor
);

XcursorBool
XcursorLibraryLoadIconCursor(
    Display *dpy,
    const char *name,
    XcursorCursor **outcursor
);

XcursorBool
XcursorLibraryLoadHotspot(
    Display *dpy,
    const char *name,
    int *x,
    int *y
);

XcursorBool
XcursorLibraryLoadCursorFromFile(
    Display *dpy,
    const char *file,
    XcursorCursor **outcursor
);

XcursorBool
XcursorLibraryLoadCursorFromPixels(
    Display *dpy,
    const unsigned char *pixels,
    const unsigned char *mask,
    int width,
    int height,
    int hotx,
    int hoty,
    XcursorCursor **outcursor
);







DESCRIPTION


These functions provide a higher-level interface to the Xcursor
    library. They are designed to load cursors from the Xcursor theme directories,
    from a file, or directly from pixel data.


XcursorLibraryLoadCursor attempts to load a cursor named
    name from the Xcursor theme directories. If found, it is returned in
    outcursor. The cursor name is typically a string like "left_ptr",
    "hand2", etc.


XcursorLibraryLoadIconCursor is similar to
    XcursorLibraryLoadCursor, but it attempts to load the cursor from the
    icon theme directories instead of the cursor theme directories. This is
    useful for cursors that are also used as icons.


XcursorLibraryLoadHotspot attempts to load the hotspot for a
    cursor named name from the Xcursor theme directories. The hotspot
    coordinates are returned in x and y.


XcursorLibraryLoadCursorFromFile loads a cursor directly
    from the specified file. The file is expected to be in Xcursor file
    format (.xcursor).


XcursorLibraryLoadCursorFromPixels loads a cursor from raw
    pixel data. pixels is a pointer to the cursor image data, and
    mask is a pointer to the mask data (for transparency). The width and
    height of the cursor are given by width and height. The hotspot
    is specified by hotx and hoty.


All these functions return XcursorTrue on success and
    XcursorFalse on failure. If a cursor is successfully loaded, it should
    be freed later using XcursorDestroyCursor.






FUNCTIONAL OVERVIEW


These functions abstract the process of finding and loading cursor
    data. They handle searching through standard theme directories and parsing
    cursor files.






DATATYPES



  
XcursorCursor

  
Structure representing a cursor, containing image data and hotspot
      information.

  
XcursorBool

  
Boolean type, typically defined as int, with
      values XcursorTrue and XcursorFalse.








FUNCTIONS



  
XcursorLibraryLoadCursor

  
Loads a cursor by name from the Xcursor theme.
    

    Returns XcursorTrue on success, XcursorFalse otherwise.

  
XcursorLibraryLoadIconCursor

  
Loads an icon cursor by name from the icon theme.
    

    Returns XcursorTrue on success, XcursorFalse otherwise.

  
XcursorLibraryLoadHotspot

  
Loads the hotspot coordinates for a cursor by name.
    

    Returns XcursorTrue on success, XcursorFalse otherwise.

  
XcursorLibraryLoadCursorFromFile

  
Loads a cursor from a specified file.
    

    Returns XcursorTrue on success, XcursorFalse otherwise.

  
XcursorLibraryLoadCursorFromPixels

  
Loads a cursor from raw pixel and mask data.
    

    Returns XcursorTrue on success, XcursorFalse otherwise.








ENVIRONMENT



  
R_THEME_CORE

  
Enables themes for core cursors if the environment variable is
      true.





  

  
If the environment variable is not given, Xcursor tries the
      Xcursor.theme_core resource.

  

  
An application can enable or disable themes using
    XcursorSetThemeCore.








CAVEATS


Xcursor will probably change radically in the future; weak
    attempts will be made to retain some level of source-file compatibility.
