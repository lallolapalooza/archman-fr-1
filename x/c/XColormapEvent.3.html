NOM

XColormapEvent - structure d'événement ColormapNotify

STRUCTURES

La structure pour les événements ColormapNotify contient :

typedef struct {
        int type;       /* ColormapNotify */
        unsigned long serial;   /* # de la dernière requête traitée par le serveur */
        Bool send_event;        /* vrai si ceci provient d'une requête SendEvent */
        Display *display;       /* Display à partir duquel l'événement a été lu */
        Window window;
        Colormap colormap;      /* colormap ou None */
        Bool new;
        int state;      /* ColormapInstalled, ColormapUninstalled */
} XColormapEvent;

Lorsque vous recevez cet événement, les membres de la structure sont définis comme suit.

Le membre type est défini sur le nom de la constante du type d'événement qui l'identifie de manière unique. Par exemple, lorsque le serveur X signale un événement GraphicsExpose à une application client, il envoie une structure XGraphicsExposeEvent avec le membre type défini sur GraphicsExpose. Le membre display est défini sur un pointeur vers le display sur lequel l'événement a été lu. Le membre send_event est défini sur True si l'événement provient d'une requête de protocole SendEvent. Le membre serial est défini à partir du numéro de série rapporté dans le protocole mais étendu des 16 bits les moins significatifs à une valeur complète de 32 bits. Le membre window est défini sur la fenêtre la plus utile aux répartiteurs de boîtes à outils.

Le membre window est défini sur la fenêtre dont la colormap associée est modifiée, installée ou désinstallée. Pour une colormap qui est modifiée, installée ou désinstallée, le membre colormap est défini sur la colormap associée à la fenêtre. Pour une colormap qui est modifiée par un appel à XFreeColormap, le membre colormap est défini sur None. Le membre new est défini pour indiquer si la colormap pour la fenêtre spécifiée a été modifiée, installée ou désinstallée et peut être True ou False. Si c'est True, la colormap a été modifiée. Si c'est False, la colormap a été installée ou désinstallée. Le membre state est toujours défini pour indiquer si la colormap est installée ou désinstallée et peut être ColormapInstalled ou ColormapUninstalled.
