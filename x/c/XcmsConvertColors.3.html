NOM

XcmsConvertColors - convertir les spécifications de couleur CCC

SYNTAXE

Status XcmsConvertColors(XcmsCCC ccc, XcmsColor colors_in_out[], unsigned int ncolors, XcmsColorFormat target_format, Bool compression_flags_return[]);

ARGUMENTS

ccc
Spécifie le CCC. Si la conversion s'effectue uniquement entre des espaces de couleurs indépendants du périphérique (par exemple, TekHVC vers CIELuv), le CCC est nécessaire uniquement pour spécifier le Point Blanc du Client.
colors_in_out
Spécifie un tableau de spécifications de couleur. Les membres Pixel sont ignorés et restent inchangés au retour.
compression_flags_return
Retourne un tableau de valeurs booléennes indiquant l'état de compression. Si un pointeur non NULL est fourni, chaque élément du tableau est défini sur True si la couleur correspondante a été compressée et False sinon. Passez NULL si l'état de compression n'est pas utile.
ncolors
Spécifie le nombre de structures XcmsColor dans le tableau de spécifications de couleur.
target_format
Spécifie le format de spécification de couleur cible.

DESCRIPTION

La fonction XcmsConvertColors convertit les spécifications de couleur dans le tableau spécifié de structures XcmsColor de leur format actuel vers un format cible unique, en utilisant le CCC spécifié. Lorsque la valeur de retour est XcmsFailure, le contenu du tableau de spécifications de couleur reste inchangé.

Le tableau peut contenir un mélange de formats de spécification de couleur (par exemple, 3 XYZ CIE, 2 Luv CIE, etc.). Lorsque le tableau contient des spécifications de couleur dépendantes et indépendantes du périphérique, et que l'argument target_format spécifie un format dépendant du périphérique (par exemple, XcmsRGBiFormat, XcmsRGBFormat), toutes les spécifications sont converties au format XYZ CIE, puis au format dépendant du périphérique cible.
