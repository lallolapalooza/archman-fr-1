XCOMPOSITE(3) libXcomposite XCOMPOSITE(3)

NOM

Xcomposite - Bibliothèque d'extension X Composite

SYNTAXE

#include <X11/extensions/Xcomposite.h>

Bool XCompositeQueryExtension(Display *dpy, int *event_base_return, int *error_base_return);

Status XCompositeQueryVersion(Display *dpy, int *major_version_return, int *minor_version_return);

int XCompositeVersion(void);

void XCompositeRedirectWindow(Display *dpy, Window window, int update);

void XCompositeRedirectSubwindows(Display *dpy, Window window, int update);

void XCompositeUnredirectWindow(Display *dpy, Window window, int update);

void XCompositeUnredirectSubwindows(Display *dpy, Window window, int update);

XserverRegion XCompositeCreateRegionFromBorderClip(Display *dpy, Window window);

Pixmap XCompositeNameWindowPixmap(Display *dpy, Window window);

Window XCompositeGetOverlayWindow(Display *dpy, Window window);

void XCompositeReleaseOverlayWindow(Display *dpy, Window window);

DESCRIPTION

L'extension composite fournit plusieurs mécanismes apparentés :

Stockage par hiérarchie

Le rendu d'une hiérarchie entière de fenêtres est redirigé vers un stockage hors écran. Les pixels de cette hiérarchie sont disponibles tant qu'elle est visible. Le stockage est automatiquement réalloué lorsque la fenêtre de plus haut niveau change de taille. Le contenu au-delà de la géométrie de la fenêtre supérieure n'est pas préservé.

Mise à jour automatique de l'ombre

Lorsqu'une hiérarchie est rendue hors écran, le serveur X fournit un mécanisme automatique pour présenter ce contenu dans la fenêtre parente. L'implémentation est libre de faire en sorte que cette mise à jour soit légèrement retardée par rapport aux opérations de rendu réelles d'une durée non spécifiée. Ce mécanisme de mise à jour automatique peut être désactivé afin que le contenu de la fenêtre parente puisse être entièrement déterminé par une application externe.

Fenêtre de superposition composite (Composite Overlay Window)

La version 0.3 du protocole ajoute la Fenêtre de superposition composite, qui fournit aux gestionnaires de composition une surface sur laquelle dessiner sans interférence. Cette fenêtre est toujours au-dessus des fenêtres normales et toujours en dessous de la fenêtre de protection d'écran. C'est une fenêtre InputOutput dont la largeur et la hauteur correspondent aux dimensions de l'écran. Sa visualisation est la visualisation racine et sa bordure est de largeur zéro. Les tentatives de la rediriger à l'aide de l'extension composite sont ignorées. Cette fenêtre n'apparaît pas dans la réponse de la requête QueryTree. C'est aussi une fenêtre avec redirection forcée (override redirect). Ces deux dernières caractéristiques la rendent invisible aux gestionnaires de fenêtres et aux autres clients X11. La seule façon d'accéder au XID de cette fenêtre est via la requête CompositeGetOverlayWindow. Initialement, la Fenêtre de superposition composite est désaffichée.

Coupure de la fenêtre parente

La version 0.4 du protocole modifie la sémantique de la coupure de la fenêtre parente en présence d'enfants redirigés manuellement. Avec cette version, la zone du parent couverte par les enfants redirigés manuellement est laissée dans la liste de coupure du parent au lieu d'être supprimée comme dans les anciennes versions.

Le stockage par hiérarchie peut être créé pour des fenêtres individuelles ou pour tous les enfants d'une fenêtre. La mise à jour manuelle de l'ombre peut être sélectionnée par une seule application pour chaque fenêtre ; la mise à jour manuelle peut également être sélectionnée au niveau de chaque fenêtre ou pour chaque enfant d'une fenêtre. La détection du moment de la mise à jour peut être effectuée avec l'extension Damage.

Le stockage hors écran comprend le contenu de la fenêtre, ses bordures et le contenu de tous ses descendants.

ARGUMENTS

display

Pointeur vers la structure Display renvoyée par XOpenDisplay pour la connexion au serveur X.

event_base_return

Pointeur vers un entier où la valeur de base pour les événements de l'extension Composite sera stockée.

error_base_return

Pointeur vers un entier où la valeur de base pour les erreurs de l'extension Composite sera stockée.

major_version_return

Pointeur vers un entier où la version majeure de l'extension Composite prise en charge par le serveur X sera stockée.

minor_version_return

Pointeur vers un entier où la version mineure de l'extension Composite prise en charge par le serveur X sera stockée.

window

Spécifie l'ID de la fenêtre sur laquelle opérer.

update

Spécifie le mode de mise à jour du contenu de la fenêtre. Doit être soit CompositeRedirectAutomatic, soit CompositeRedirectManual.

FONCTIONS

XCompositeQueryExtension

XCompositeQueryExtension détermine si l'extension Composite est disponible sur l'affichage donné. Elle renvoie True si l'extension est prise en charge, sinon False. Si l'extension est présente, les valeurs de base pour les événements et les erreurs sont renvoyées et peuvent être utilisées pour décoder les valeurs d'événements et d'erreurs entrantes.

XCompositeQueryVersion

XCompositeQueryVersion détermine si le serveur X prend en charge une version de l'extension X Composite compatible avec la bibliothèque client. Un statut non nul est renvoyé si une version compatible de l'extension est prise en charge, sinon un statut nul est renvoyé. Si l'extension est prise en charge, les numéros de version majeure et mineure sont renvoyés pour indiquer le niveau de prise en charge de l'extension Composite. Aucune autre fonction XComposite (sauf XCompositeQueryExtension) ne peut être appelée avant cette fonction. Si un client viole cette règle, les effets de tous les appels XComposite ultérieurs qu'il effectue sont indéfinis.

XCompositeVersion

XCompositeVersion renvoie la version de la bibliothèque X Composite. Le numéro de version est encodé comme : (majeur * 10000) + (mineur * 100) + révision

Par exemple, la version 1.4.6 serait encodée comme l'entier 10406.

XCompositeRedirectWindow

XCompositeRedirectWindow demande au serveur X de diriger la hiérarchie commençant à window vers un stockage hors écran. L'argument update spécifie si le contenu est automatiquement mis en miroir dans la fenêtre parente ou non. Un seul client à la fois peut spécifier un type de mise à jour de CompositeRedirectManual, une autre tentative résultera en une erreur BadAccess. Lorsque tous les clients activant la redirection se terminent, la redirection sera automatiquement désactivée.

La fenêtre racine ne peut pas être redirigée. Cela entraîne une erreur BadMatch. La spécification d'un ID de fenêtre invalide entraînera une erreur BadWindow.

XCompositeRedirectSubwindows

XCompositeRedirectSubwindows demande au serveur X de rediriger les hiérarchies commençant à tous les enfants actuels et futurs de window comme dans XCompositeRedirectWindow. Si update est CompositeRedirectManual, alors la peinture de l'arrière-plan de la fenêtre pendant la manipulation de la fenêtre et les requêtes ClearArea sont inhibées.

XCompositeUnredirectWindow

XCompositeUnredirectWindow demande au serveur X de terminer la redirection de window. Si la fenêtre spécifiée n'a pas été sélectionnée pour la redirection par le client actuel, une erreur BadValue en résulte.

XCompositeUnredirectSubwindows

XCompositeUnredirectSubwindows demande au serveur X de terminer la redirection de tous les enfants de window. Si la fenêtre spécifiée n'a pas été sélectionnée pour la sous-redirection par le client actuel, une erreur BadValue en résulte.

XCompositeCreateRegionFromBorderClip

XCompositeCreateRegionFromBorderClip crée une région contenant la bordure "habituelle"

NAME

XCompositeNameWindowPixmap, XCompositeGetOverlayWindow, XCompositeReleaseOverlayWindow - composite window operations

SYNOPSIS

#include <X11/extensions/Xcomposite.h>

unsigned long
XCompositeNameWindowPixmap(Display *dpy, Window window);

Window
XCompositeGetOverlayWindow(Display *dpy, Window window);

void
XCompositeReleaseOverlayWindow(Display *dpy, Window window);

DESCRIPTION

The Composite Extension provides a mechanism for redirecting windows to off-screen pixmaps, allowing applications to implement custom window management, compositing, or manipulation of window contents.

The redirection is controlled on a per-window basis. When a window is redirected, its normal drawing operations are instead directed to a pixmap. This pixmap can then be accessed and manipulated by another application, such as a window manager or compositor.

Redirection can be enabled or disabled on a window-by-window basis. When a window is first redirected, the X server allocates a pixmap to hold its contents. This pixmap is associated with the window and persists even if the window is unmapped or destroyed.

The Composite Extension also provides overlay windows, which are special windows managed by the X server that can be used to draw effects or decorations above or below redirected windows. These overlay windows are managed by the X server and can be accessed and manipulated through specific functions.

ARGUMENTS

dpy

Specifies the connection to the X server.

window

Specifies the window for which the operation is to be performed.

FUNCTIONS

XCompositeRedirectWindow

XCompositeRedirectWindow redirects the contents of window to a pixmap. If update is CompositeRedirectManual, the client is responsible for updating the window contents by rendering to the pixmap returned by XCompositeNameWindowPixmap. If update is CompositeRedirectAutomatic, the X server automatically handles updating the pixmap as the window contents change. A BadMatch error is generated if the window is not eligible for redirection (e.g., it is already redirected, or it is a subwindow of a redirected window).

XCompositeRedirectSubwindow

XCompositeRedirectSubwindow redirects the contents of all subwindows of window to pixmaps. The update argument is the same as for XCompositeRedirectWindow. A BadMatch error is generated if the window is not eligible for redirection.

XCompositeUnredirectWindow

XCompositeUnredirectWindow stops redirecting the contents of window. The update argument must be CompositeRedirectAutomatic. A BadMatch error is generated if the window is not currently redirected.

XCompositeUnredirectSubwindow

XCompositeUnredirectSubwindow stops redirecting the contents of all subwindows of window. The update argument must be CompositeRedirectAutomatic. A BadMatch error is generated if the window's subwindows are not currently redirected.

XCompositeGetWindowAttributes

XCompositeGetWindowAttributes retrieves the attributes of the specified window. The attributes structure includes information about whether the window is redirected, the update mode, and the clip value. The clip value represents the area of the window clipped against siblings and the parent. This region can be used to restrict rendering to suitable areas while updating only a single window. The region is copied at the moment the request is executed; future changes to the window hierarchy will not be reflected in this region.

XCompositeNameWindowPixmap

XCompositeNameWindowPixmap creates and returns a pixmap id that serves as a reference to the off-screen storage for window. This pixmap will remain allocated until freed, even if the window is unmapped, reconfigured or destroyed. However, the window will get a new pixmap allocated each time it is mapped or resized, so this function will need to be reinvoked for the client to continue to refer to the storage holding the current window contents. Generates a BadMatch error if window is not redirected or is not visible.

The X server must support at least version 0.2 of the Composite Extension for XCompositeNameWindowPixmap.

XCompositeGetOverlayWindow

XCompositeGetOverlayWindow returns the window ID of the Composite Overlay Window for the screen specified by the argument window. This function notifies the X server that the client wishes to use the Composite Overlay Window of this screen. If this Composite Overlay Window has not yet been mapped, it is mapped by this request.

The Composite Overlay Window for a particular screen will be unmapped when all clients who have called this function have either called XCompositeReleaseOverlayWindow for that screen, or terminated their connection to the X server.

The X server must support at least version 0.3 of the Composite Extension for XCompositeGetOverlayWindow.

XCompositeReleaseOverlayWindow

This request specifies that the client is no longer using the Composite Overlay Window on the screen specified by the argument window. A screen's Composite Overlay Window is unmapped when there are no longer any clients using it.

The X server must support at least version 0.3 of the Composite Extension for XCompositeReleaseOverlayWindow.

NOM

XCompositeNameWindowPixmap, XCompositeGetOverlayWindow, XCompositeReleaseOverlayWindow - opérations de fenêtrage composite

SYNOPSIS

#include <X11/extensions/Xcomposite.h>

unsigned long
XCompositeNameWindowPixmap(Display *dpy, Window window);

Window
XCompositeGetOverlayWindow(Display *dpy, Window window);

void
XCompositeReleaseOverlayWindow(Display *dpy, Window window);

DESCRIPTION

L'extension Composite fournit un mécanisme pour rediriger les fenêtres vers des pixmaps hors écran, permettant aux applications d'implémenter une gestion de fenêtres personnalisée, un compositing ou une manipulation du contenu des fenêtres.

La redirection est contrôlée sur une base par fenêtre. Quand une fenêtre est redirigée, ses opérations de dessin normales sont plutôt dirigées vers une pixmap. Cette pixmap peut alors être accédée et manipulée par une autre application, telle qu'un gestionnaire de fenêtres ou un compositeur.

La redirection peut être activée ou désactivée sur une base par fenêtre. Quand une fenêtre est redirigée pour la première fois, le serveur X alloue une pixmap pour contenir son contenu. Cette pixmap est associée à la fenêtre et persiste même si la fenêtre est désinstallée ou détruite.

L'extension Composite fournit également des fenêtres de superposition, qui sont des fenêtres spéciales gérées par le serveur X qui peuvent être utilisées pour dessiner des effets ou des décorations au-dessus ou en dessous des fenêtres redirigées. Ces fenêtres de superposition sont gérées par le serveur X et peuvent être accédées et manipulées via des fonctions spécifiques.

ARGUMENTS

dpy

Spécifie la connexion au serveur X.

window

Spécifie la fenêtre pour laquelle l'opération doit être effectuée.

FONCTIONS

XCompositeRedirectWindow

XCompositeRedirectWindow redirige le contenu de window vers une pixmap. Si update est CompositeRedirectManual, le client est responsable de la mise à jour du contenu de la fenêtre en rendant dans la pixmap renvoyée par XCompositeNameWindowPixmap. Si update est CompositeRedirectAutomatic, le serveur X gère automatiquement la mise à jour de la pixmap au fur et à mesure que le contenu de la fenêtre change. Une erreur BadMatch est générée si la fenêtre n'est pas éligible à la redirection (par exemple, elle est déjà redirigée, ou c'est une sous-fenêtre d'une fenêtre redirigée).

XCompositeRedirectSubwindow

XCompositeRedirectSubwindow redirige le contenu de toutes les sous-fenêtres de window vers des pixmaps. L'argument update est le même que pour XCompositeRedirectWindow. Une erreur BadMatch est générée si la fenêtre n'est pas éligible à la redirection.

XCompositeUnredirectWindow

XCompositeUnredirectWindow arrête la redirection du contenu de window. L'argument update doit être CompositeRedirectAutomatic. Une erreur BadMatch est générée si la fenêtre n'est pas actuellement redirigée.

XCompositeUnredirectSubwindow

XCompositeUnredirectSubwindow arrête la redirection du contenu de toutes les sous-fenêtres de window. L'argument update doit être CompositeRedirectAutomatic. Une erreur BadMatch est générée si les sous-fenêtres de la fenêtre ne sont pas actuellement redirigées.

XCompositeGetWindowAttributes

XCompositeGetWindowAttributes récupère les attributs de la fenêtre spécifiée window. La structure des attributs inclut des informations sur la redirection de la fenêtre, le mode de mise à jour et la valeur du clip. La valeur du clip représente la zone de la fenêtre coupée par rapport aux frères et au parent. Cette région peut être utilisée pour restreindre le rendu à des zones appropriées tout en mettant à jour une seule fenêtre. La région est copiée au moment où la requête est exécutée; les futures modifications de la hiérarchie des fenêtres ne seront pas reflétées dans cette région.

XCompositeNameWindowPixmap

XCompositeNameWindowPixmap crée et renvoie un identifiant de pixmap qui sert de référence au stockage hors écran pour window. Cette pixmap restera allouée jusqu'à ce qu'elle soit libérée, même si la fenêtre est désinstallée, reconfigurée ou détruite. Cependant, la fenêtre obtiendra une nouvelle pixmap allouée à chaque fois qu'elle sera installée ou redimensionnée, donc cette fonction devra être réinvoquée pour que le client continue à faire référence au stockage contenant le contenu actuel de la fenêtre. Génère une erreur BadMatch si window n'est pas redirigée ou n'est pas visible.

Le serveur X doit supporter au moins la version 0.2 de l'extension Composite pour XCompositeNameWindowPixmap.

XCompositeGetOverlayWindow

XCompositeGetOverlayWindow renvoie l'identifiant de la fenêtre de superposition composite (Composite Overlay Window) pour l'écran spécifié par l'argument window. Cette fonction notifie le serveur X que le client souhaite utiliser la fenêtre de superposition composite de cet écran. Si cette fenêtre de superposition composite n'a pas encore été installée, elle est installée par cette requête.

La fenêtre de superposition composite pour un écran particulier sera désinstallée lorsque tous les clients ayant appelé cette fonction auront soit appelé XCompositeReleaseOverlayWindow pour cet écran, soit terminé leur connexion au serveur X.

Le serveur X doit supporter au moins la version 0.3 de l'extension Composite pour XCompositeGetOverlayWindow.

XCompositeReleaseOverlayWindow

Cette requête spécifie que le client n'utilise plus la fenêtre de superposition composite sur l'écran spécifié par l'argument window. La fenêtre de superposition composite d'un écran est désinstallée lorsqu'il n'y a plus aucun client qui l'utilise.

Le serveur X doit supporter au moins la version 0.3 de l'extension Composite pour XCompositeReleaseOverlayWindow.
