NOM

XcupQueryVersion - Retourne la version du protocole TOG-CUP prise en charge par le serveur X

SYNTAXE

cc [ flag ... ] file ... -lXext [ library ... ]
#include <X11/extensions/Xcup.h>
Status XcupQueryVersion(Display *display,
int *major_version_return, int *minor_version_return);

ARGUMENTS

display
Spécifie la connexion au serveur X
major_version_return
Retourne la version majeure prise en charge par le serveur
minor_version_return
Retourne la version mineure prise en charge par le serveur

DESCRIPTION

XcupQueryVersion définit major_version_return et minor_version_return à la version majeure et mineure du protocole TOG-CUP prise en charge par le serveur. Si la bibliothèque TOG-CUP est compatible avec la version retournée par le serveur, elle retourne une valeur non nulle. Si le serveur ne prend pas en charge l'extension TOG-CUP, ou s'il y a eu une erreur de communication avec le serveur, ou si les versions de protocole du serveur et de la bibliothèque sont incompatibles, elle retourne zéro. Aucune autre fonction Xcup ne peut être appelée avant cette fonction. Si un client enfreint cette règle, les effets de tous les appels Xcup ultérieurs qu'il effectue sont indéfinis.

Pour obtenir la liste des entrées de table de correspondance réservées, utilisez XcupGetReservedColormapEntries.

Pour allouer une ou plusieurs cellules de couleur en lecture seule avec des valeurs RVB, utilisez XcupStoreColors.
