NOM

XClientMessageEvent - Structure d'événement ClientMessage

STRUCTURES

La structure pour les événements ClientMessage contient :

typedef struct {
        int type;       /* ClientMessage */
        unsigned long serial;           /* # du dernier requête traitée par le serveur */
        Bool send_event;                /* vrai si ceci vient d'une requête SendEvent */
        Display *display;               /* Display sur lequel l'événement a été lu */
        Window window;
        Atom message_type;
        int format;
        union {
                char b[20];
                short s[10];
                long l[5];
                } data;
} XClientMessageEvent;

Lorsque vous recevez cet événement, les membres de la structure sont définis comme suit.

Le membre type est défini à la constante de type d'événement qui l'identifie de manière unique. Par exemple, lorsque le serveur X rapporte un événement GraphicsExpose à une application cliente, il envoie une structure XGraphicsExposeEvent avec le membre type défini à GraphicsExpose. Le membre display est défini à un pointeur vers le display sur lequel l'événement a été lu. Le membre send_event est défini à True si l'événement provient d'une requête de protocole SendEvent. Le membre serial est défini à partir du numéro de série rapporté dans le protocole mais étendu des 16 bits les moins significatifs à une valeur complète de 32 bits. Le membre window est défini à la fenêtre qui est la plus utile aux répartiteurs de boîte à outils.

Le membre message_type est défini à un atome qui indique comment les données doivent être interprétées par le client récepteur. Le membre format est défini à 8, 16 ou 32 et spécifie si les données doivent être considérées comme une liste d'octets, de mots courts ou de mots longs. Le membre data est une union qui contient les membres b, s et l;. Les membres b, s et l; représentent des données de vingt valeurs de 8 bits, dix valeurs de 16 bits et cinq valeurs de 32 bits. Certains types de messages peuvent ne pas utiliser toutes ces valeurs. Le serveur X n'interprète pas les valeurs des membres window, message_type ou data.
