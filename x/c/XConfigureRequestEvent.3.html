XConfigureRequestEvent(3) FONCTIONS XLIB XConfigureRequestEvent(3)

NOM

XConfigureRequestEvent - structure de l'événement ConfigureRequest

STRUCTURES

La structure pour les événements ConfigureRequest contient :

typedef struct {
        int type;       /* ConfigureRequest */
        unsigned long serial;   /* # de la dernière requête traitée par le serveur */
        Bool send_event;        /* vrai si ceci provient d'une requête SendEvent */
        Display *display;       /* Display à partir duquel l'événement a été lu */
        Window parent;
        Window window;
        int x, y;
        int width, height;
        int border_width;
        Window above;
        int detail;     /* Above, Below, TopIf, BottomIf, Opposite */
        unsigned long value_mask;
} XConfigureRequestEvent;

Lorsque vous recevez cet événement, les membres de la structure sont définis comme suit.

Le membre type est défini à la constante nommée du type d'événement qui l'identifie de manière unique. Par exemple, lorsque le serveur X signale un événement GraphicsExpose à une application cliente, il envoie une structure XGraphicsExposeEvent avec le membre type défini à GraphicsExpose. Le membre display est défini à un pointeur vers le display sur lequel l'événement a été lu. Le membre send_event est défini à True si l'événement provient d'une requête de protocole SendEvent. Le membre serial est défini à partir du numéro de série rapporté dans le protocole mais développé à partir des 16 bits de poids faible vers une valeur complète de 32 bits. Le membre window est défini à la fenêtre qui est la plus utile aux dispatchers de boîtes à outils.

Le membre parent est défini à la fenêtre parente. Le membre window est défini à la fenêtre dont la taille, la position, la largeur de bordure et/ou l'ordre d'empilement doivent être reconfigurés. Le membre value_mask indique quels composants ont été spécifiés dans la requête de protocole ConfigureWindow. Les valeurs correspondantes sont rapportées telles que données dans la requête. Les valeurs restantes sont remplies à partir de la géométrie actuelle de la fenêtre, sauf dans le cas de above (frère) et detail (mode d'empilement), qui sont rapportés comme None et Above, respectivement, s'ils ne sont pas donnés dans la requête.
