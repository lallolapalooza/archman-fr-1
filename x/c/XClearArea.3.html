XClearArea(3)

Paquet: libx11

Licences: MIT AND X11

XClearArea(3) FONCTIONS XLIB XClearArea(3)

NOM

XClearArea, XClearWindow - effacer une zone ou une fenêtre

SYNTAXE

int XClearArea(Display *display, Window w, int x, int y, unsigned width, unsigned height, Bool exposures);

int XClearWindow(Display *display, Window w);

ARGUMENTS

display
Spécifie la connexion au serveur X.
exposures
Spécifie une valeur booléenne qui indique si des événements Expose doivent être générés.
w
Spécifie la fenêtre.
width

height
Spécifient la largeur et la hauteur, qui sont les dimensions du rectangle.
x

y
Spécifient les coordonnées x et y, qui sont relatives à l'origine de la fenêtre et spécifient le coin supérieur gauche du rectangle.

DESCRIPTION

La fonction XClearArea peint une zone rectangulaire dans la fenêtre spécifiée selon les dimensions spécifiées avec le pixel ou le pixmap de fond de la fenêtre. Le mode sous-fenêtre est effectivement ClipByChildren. Si la largeur est zéro, elle est remplacée par la largeur actuelle de la fenêtre moins x. Si la hauteur est zéro, elle est remplacée par la hauteur actuelle de la fenêtre moins y. Si la fenêtre a une tuile de fond définie, le rectangle découpé par les enfants est rempli avec cette tuile. Si la fenêtre a un fond None, le contenu de la fenêtre n'est pas modifié. Dans les deux cas, si exposures est True, un ou plusieurs événements Expose sont générés pour les régions du rectangle qui sont soit visibles, soit conservées dans un backing store. Si vous spécifiez une fenêtre dont la classe est InputOnly, une erreur BadMatch en résulte.

XClearArea peut générer des erreurs BadMatch, BadValue et BadWindow.

La fonction XClearWindow efface toute la zone de la fenêtre spécifiée et est équivalente à XClearArea (display, w, 0, 0, 0, 0, False). Si la fenêtre a une tuile de fond définie, le rectangle est tuilé avec un masque de plan de tous les uns et la fonction GXcopy. Si la fenêtre a un fond None, le contenu de la fenêtre n'est pas modifié. Si vous spécifiez une fenêtre dont la classe est InputOnly, une erreur BadMatch en résulte.

XClearWindow peut générer des erreurs BadMatch et BadWindow.

DIAGNOSTICS

BadMatch
Une fenêtre InputOnly est utilisée comme Drawable.
BadValue
Une valeur numérique tombe en dehors de la plage de valeurs acceptées par la requête. Sauf si une plage spécifique est spécifiée pour un argument, la plage complète définie par le type de l'argument est acceptée. Tout argument défini comme un ensemble d'alternatives peut générer cette erreur.
BadWindow
Une valeur pour un argument Window ne nomme pas une fenêtre définie.
