XCHANGEPOINTERDEVICE(3)   XCHANGEPOINTERDEVICE(3)

NOM

XChangePointerDevice - changer le périphérique qui sert de pointeur X

SYNTAXE

#include <X11/extensions/XInput.h>
Status XChangePointerDevice( Display *display,
                             XDevice *device,
                             int xaxis,
                             int yaxis);
display
       Spécifie la connexion au serveur X.
device
       Spécifie le périphérique à utiliser comme pointeur X.
xaxis
       Spécifie l'axe du périphérique à utiliser comme axe X
       du pointeur X.
yaxis
       Spécifie l'axe du périphérique à utiliser comme axe Y
       du pointeur X.

DESCRIPTION

La requête XChangePointerDevice demande au serveur d'utiliser le
périphérique spécifié comme pointeur X. Le périphérique doit avoir été
ouvert par le client via XOpenDevice, sinon une erreur BadDevice résultera.
Le périphérique doit supporter la classe d'entrée Valuators, sinon une
erreur BadMatch résultera. Si l'implémentation ne supporte pas l'utilisation
du périphérique spécifié comme pointeur X, une erreur BadDevice résultera.
Si le périphérique spécifié est capturé par un autre client,
AlreadyGrabbed est retourné. Si le périphérique spécifié est gelé
par une capture sur un autre périphérique, GrabFrozen est retourné. Si la
requête réussit, Success est retourné.
Si la requête réussit, un événement ChangeDeviceNotify est envoyé à tous les
clients qui ont sélectionné cet événement. Un événement MappingNotify
avec request = MappingPointer est envoyé à tous les clients. Le
périphérique spécifié devient le pointeur X, et l'ancien pointeur X devient
accessible via les requêtes du protocole d'extension d'entrée.
XChangePointerDevice peut générer une erreur BadDevice ou BadMatch.

DIAGNOSTICS

BadDevice
       Un périphérique invalide a été spécifié. Le périphérique spécifié
       n'existe pas, n'a pas été ouvert par ce client via
       XOpenInputDevice, ou est déjà l'un des périphériques d'entrée
       principaux X (pointeur ou clavier). Cette erreur peut également survenir
       si l'implémentation du serveur ne supporte pas l'utilisation du
       périphérique spécifié comme pointeur X.
BadMatch
       Cette erreur peut survenir si une requête XChangePointerDevice a été
       effectuée en spécifiant un périphérique qui a moins de deux
       valueurs, ou en spécifiant un index de valueur en dehors de la plage
       supportée par le périphérique.
