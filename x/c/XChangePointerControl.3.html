XChangePointerControl(3) FONCTIONS XLIB XChangePointerControl(3)

NOM

XChangePointerControl, XGetPointerControl - contrôler le pointeur

SYNTAXE

int XChangePointerControl(Display *display, Bool do_accel, Bool do_threshold, int accel_numerator, int accel_denominator, int threshold);

int XGetPointerControl(Display *display, int *accel_numerator_return, int *accel_denominator_return, int *threshold_return);

ARGUMENTS

accel_denominator
Spécifie le dénominateur du multiplicateur d'accélération.
accel_denominator_return
Retourne le dénominateur du multiplicateur d'accélération.
accel_numerator
Spécifie le numérateur du multiplicateur d'accélération.
accel_numerator_return
Retourne le numérateur du multiplicateur d'accélération.
display
Spécifie la connexion au serveur X.
do_accel
Spécifie une valeur booléenne qui contrôle si les valeurs pour accel_numerator ou accel_denominator sont utilisées.
do_threshold
Spécifie une valeur booléenne qui contrôle si la valeur pour le seuil est utilisée.
threshold
Spécifie le seuil d'accélération.
threshold_return
Retourne le seuil d'accélération.

DESCRIPTION

La fonction XChangePointerControl définit comment le dispositif de pointage se déplace. L'accélération, exprimée en fraction, est un multiplicateur de mouvement. Par exemple, spécifier 3/1 signifie que le pointeur se déplace trois fois plus vite que la normale. La fraction peut être arrondie arbitrairement par le serveur X. L'accélération ne prend effet que si le pointeur se déplace de plus de threshold pixels à la fois et ne s'applique qu'à la partie du mouvement dépassant la valeur de l'argument threshold. Définir une valeur à -1 restaure la valeur par défaut. Les valeurs des arguments do_accel et do_threshold doivent être True pour que les valeurs du pointeur soient définies, sinon les paramètres restent inchangés. Les valeurs négatives (autres que -1) génèrent une erreur BadValue, tout comme une valeur nulle pour l'argument accel_denominator.

XChangePointerControl peut générer une erreur BadValue.

La fonction XGetPointerControl renvoie le multiplicateur d'accélération et le seuil d'accélération actuels du pointeur.

DIAGNOSTICS

BadValue
Une valeur numérique se situe en dehors de la plage des valeurs acceptées par la requête. Sauf si une plage spécifique est spécifiée pour un argument, toute la plage définie par le type de l'argument est acceptée. Tout argument défini comme un ensemble d'alternatives peut générer cette erreur.
