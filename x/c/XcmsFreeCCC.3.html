XcmsCreateCCC(3) FONCTIONS XLIB XcmsCreateCCC(3)

NOM

XcmsCreateCCC, XcmsFreeCCC - création et destruction de CCC

SYNTAXE

XcmsCCC XcmsCreateCCC(Display *display, int screen_number, Visual *visual, XcmsColor *client_white_point, XcmsCompressionProc compression_proc, XPointer compression_client_data, XcmsWhiteAdjustProc white_adjust_proc, XPointer white_adjust_client_data);

void XcmsFreeCCC(XcmsCCC ccc);

ARGUMENTS

display
Spécifie la connexion au serveur X.
ccc
Spécifie le CCC.
client_white_point
Spécifie le Point Blanc Client. Si NULL est spécifié, le Point Blanc Client est supposé être le même que le Point Blanc de l'Écran. Notez que le membre pixel est ignoré.
compression_client_data
Spécifie les données client à utiliser par la procédure de compression de gamme ou NULL.
compression_proc
Spécifie la procédure de compression de gamme qui doit être appliquée lorsqu'une couleur se situe en dehors de la gamme de couleurs de l'écran. Si NULL est spécifié et qu'une fonction utilisant ce CCC doit convertir une spécification de couleur en un format dépendant de l'appareil et rencontre une couleur qui se situe en dehors de la gamme de couleurs de l'écran, cette fonction retournera XcmsFailure.
screen_number
Spécifie le numéro d'écran approprié sur le serveur hôte.
visual
Spécifie le type de visualisation.
white_adjust_client_data
Spécifie les données client à utiliser avec la procédure d'ajustement du point blanc ou NULL.
white_adjust_proc
Spécifie la procédure d'ajustement du point blanc qui doit être appliquée lorsque le Point Blanc Client diffère du Point Blanc de l'Écran. NULL indique qu'aucun ajustement du point blanc n'est souhaité.

DESCRIPTION

La fonction XcmsCreateCCC crée un CCC pour l'affichage, l'écran et la visualisation spécifiés.

La fonction XcmsFreeCCC libère la mémoire utilisée pour le CCC spécifié. Notez que les CCC par défaut et ceux actuellement associés aux colormaps sont ignorés.
