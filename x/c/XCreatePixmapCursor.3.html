Paquet: libx11

XCreateFontCursor(3) FONCTIONS XLIB XCreateFontCursor(3)

NOM

XCreateFontCursor, XCreatePixmapCursor, XCreateGlyphCursor - créer des curseurs

SYNTAXE

#include <X11/cursorfont.h>

Cursor XCreateFontCursor(Display *display, unsigned int shape);

Cursor XCreatePixmapCursor(Display *display, Pixmap source, Pixmap mask, XColor *foreground_color, XColor *background_color, unsigned int x, unsigned int y);

Cursor XCreateGlyphCursor(Display *display, Font source_font, Font mask_font, unsigned int source_char, unsigned int mask_char, XColor _Xconst *foreground_color, XColor _Xconst *background_color);

ARGUMENTS

background_color
Spécifie les valeurs RVB pour l'arrière-plan de la source.
display
Spécifie la connexion au serveur X.
foreground_color
Spécifie les valeurs RVB pour le premier plan de la source.
mask
Spécifie les bits sources du curseur à afficher ou None.
mask_char
Spécifie le caractère glyphe pour le masque.
mask_font
Spécifie la police pour le glyphe de masque ou None.
shape
Spécifie la forme du curseur.
source
Spécifie la forme du curseur source.
source_char
Spécifie le caractère glyphe pour la source.
source_font
Spécifie la police pour le glyphe source.
x

y
Spécifiez les coordonnées x et y, qui indiquent le point d'ancrage par rapport à l'origine de la source.

DESCRIPTION

X fournit un ensemble de formes de curseurs standard dans une police spéciale nommée cursor. Les applications sont encouragées à utiliser cette interface pour leurs curseurs car la police peut être personnalisée pour le type d'affichage individuel. L'argument shape spécifie quel glyphe des polices standard utiliser.

Le point d'ancrage provient des informations stockées dans la police de curseurs. Les couleurs initiales d'un curseur sont un premier plan noir et un arrière-plan blanc (voir XRecolorCursor).

XCreateFontCursor peut générer des erreurs BadAlloc et BadValue.

La fonction XCreatePixmapCursor crée un curseur et renvoie l'identifiant du curseur qui lui est associé. Les valeurs RVB du premier plan et de l'arrière-plan doivent être spécifiées à l'aide de foreground_color et background_color, même si le serveur X ne possède qu'un écran StaticGray ou GrayScale. La couleur du premier plan est utilisée pour les pixels mis à 1 dans la source, et la couleur de l'arrière-plan est utilisée pour les pixels mis à 0. La source et le masque, s'ils sont spécifiés, doivent avoir une profondeur de 1 (ou une erreur BadMatch en résulte) mais peuvent avoir n'importe quelle racine. L'argument mask définit la forme du curseur. Les pixels mis à 1 dans le masque définissent quels pixels sources sont affichés, et les pixels mis à 0 définissent quels pixels sont ignorés. Si aucun masque n'est fourni, tous les pixels de la source sont affichés. Le masque, s'il est présent, doit avoir la même taille que le pixmap défini par l'argument source, sinon une erreur BadMatch en résulte. Le point d'ancrage doit être un point à l'intérieur de la source, sinon une erreur BadMatch en résulte.

Les composants du curseur peuvent être transformés arbitrairement pour s'adapter aux limitations de l'affichage. Les pixmaps peuvent être libérés immédiatement si aucune référence explicite supplémentaire ne doit y être faite. Les dessins ultérieurs dans le pixmap source ou masque ont un effet indéfini sur le curseur. Le serveur X peut ou peut ne pas copier le pixmap.

XCreatePixmapCursor peut générer des erreurs BadAlloc et BadPixmap.

La fonction XCreateGlyphCursor est similaire à XCreatePixmapCursor sauf que les bitmaps sources et masques sont obtenus à partir des glyphes de police spécifiés. Le source_char doit être un glyphe défini dans source_font, sinon une erreur BadValue en résulte. Si mask_font est fourni, mask_char doit être un glyphe défini dans mask_font, sinon une erreur BadValue en résulte. mask_font et le caractère sont optionnels. Les origines des glyphes source_char et mask_char (s'ils sont définis) sont positionnées de manière coïncidente et définissent le point d'ancrage. Les source_char et mask_char n'ont pas besoin d'avoir les mêmes métriques de boîte englobante, et il n'y a aucune restriction sur le placement du point d'ancrage par rapport aux boîtes englobantes. Si aucun mask_char n'est fourni, tous les pixels de la source sont affichés. Vous pouvez libérer les polices immédiatement en appelant XFreeFont si aucune référence explicite supplémentaire ne doit y être faite.

Pour les polices matricielles à 2 octets, la valeur de 16 bits doit être formée avec le membre byte1 dans l'octet le plus significatif et le membre byte2 dans l'octet le moins significatif.

XCreateGlyphCursor peut générer des erreurs BadAlloc, BadFont et BadValue.

DIAGNOSTICS

BadAlloc
Le serveur n'a pas pu allouer la ressource demandée ou la mémoire du serveur.
BadFont
Une valeur pour un argument Font ou GContext ne nomme pas une Police définie.
BadMatch
Un argument ou une paire d'arguments a le bon type et la bonne plage mais ne correspond pas d'une autre manière requise par la requête.
BadPixmap
Une valeur pour un argument Pixmap ne nomme pas un Pixmap défini.
BadValue
Une valeur numérique tombe en dehors de la plage des valeurs acceptées par la requête. Sauf si une plage spécifique est spécifiée pour un argument, la plage complète définie par le type de l'argument est acceptée. Tout argument défini comme un ensemble d'alternatives peut générer cette erreur.
