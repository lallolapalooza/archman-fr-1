Paquet: libx11

XLoadFont(3) FONCTIONS XLIB XLoadFont(3)

NOM

XLoadFont, XQueryFont, XLoadQueryFont, XFreeFont, XGetFontProperty, XUnloadFont, XCharStruct, XFontProp, XChar2b, XFontStruct - charger ou décharger des polices et des structures de métriques de polices

SYNTAXE

Font XLoadFont(Display *display, _Xconst char *name);

XFontStruct *XQueryFont(Display *display, XID font_ID);

XFontStruct *XLoadQueryFont(Display *display, _Xconst char *name);

int XFreeFont(Display *display, XFontStruct *font_struct);

Bool XGetFontProperty(XFontStruct *font_struct, Atom atom, unsigned long *value_return);

int XUnloadFont(Display *display, Font font);

ARGUMENTS

atom
Spécifie l'atome pour le nom de la propriété que vous souhaitez obtenir.
display
Spécifie la connexion au serveur X.
font
Spécifie la police.
font_ID
Spécifie l'ID de la police ou l'ID GContext.
font_struct
Spécifie le stockage associé à la police.
gc
Spécifie le GC.
name
Spécifie le nom de la police, qui est une chaîne terminée par un zéro.
value_return
Retourne la valeur de la propriété de la police.

DESCRIPTION

La fonction XLoadFont charge la police spécifiée et retourne son ID de police associé. Si le nom de la police n'est pas dans le codage de caractères portable de l'hôte, le résultat dépend de l'implémentation. L'usage des majuscules ou des minuscules n'a pas d'importance. Lorsque les caractères “?” et “*” sont utilisés dans un nom de police, une correspondance de motif est effectuée et toute police correspondante est utilisée. Dans le motif, le caractère “?” correspondra à n'importe quel caractère unique, et le caractère “*” correspondra à n'importe quel nombre de caractères. Un format structuré pour les noms de polices est spécifié dans les conventions de description des polices logiques X du standard X Consortium. Si XLoadFont n'a pas réussi à charger la police spécifiée, une erreur BadName se produit. Les polices ne sont pas associées à un écran particulier et peuvent être stockées comme un composant de n'importe quel GC. Lorsque la police n'est plus nécessaire, appelez XUnloadFont.

XLoadFont peut générer des erreurs BadAlloc et BadName.

La fonction XQueryFont retourne un pointeur vers la structure XFontStruct, qui contient des informations associées à la police. Vous pouvez interroger une police ou la police stockée dans un GC. L'ID de police stocké dans la structure XFontStruct sera l'ID GContext, et vous devrez faire attention lors de l'utilisation de cet ID dans d'autres fonctions (voir XGContextFromGC). Si la police n'existe pas, XQueryFont retourne NULL. Pour libérer ces données, utilisez XFreeFontInfo.

XLoadQueryFont peut générer une erreur BadAlloc.

La fonction XLoadQueryFont fournit la manière la plus courante d'accéder à une police. XLoadQueryFont ouvre (charge) la police spécifiée et retourne un pointeur vers la structure XFontStruct appropriée. Si le nom de la police n'est pas dans le codage de caractères portable de l'hôte, le résultat dépend de l'implémentation. Si la police n'existe pas, XLoadQueryFont retourne NULL.

La fonction XFreeFont supprime l'association entre l'ID de ressource de la police et la police spécifiée et libère la structure XFontStruct. La police elle-même sera libérée lorsqu'aucune autre ressource ne la référencera. Les données et la police ne doivent plus être référencées.

XFreeFont peut générer une erreur BadFont.

Étant donné l'atome pour cette propriété, la fonction XGetFontProperty retourne la valeur de la propriété de police spécifiée. XGetFontProperty retourne également False si la propriété n'était pas définie ou True si elle était définie. Un ensemble d'atomes prédéfinis existe pour les propriétés de polices, qui se trouvent dans X11/Xatom.h. Cet ensemble contient les propriétés standard associées à une police. Bien que ce ne soit pas garanti, il est probable que les propriétés de polices prédéfinies seront présentes.

La fonction XUnloadFont supprime l'association entre l'ID de ressource de la police et la police spécifiée. La police elle-même sera libérée lorsqu'aucune autre ressource ne la référencera. La police ne doit plus être référencée.

XUnloadFont peut générer une erreur BadFont.

STRUCTURES

La structure XFontStruct contient toutes les informations de la police et comprend les informations spécifiques à la police ainsi qu'un pointeur vers un tableau de structures XCharStruct pour les caractères contenus dans la police. Les structures XFontStruct, XFontProp, et XCharStruct contiennent :

typedef struct {
	short lbearing;	/* origine au bord gauche du raster */
	short rbearing;	/* origine au bord droit du raster */
	short width;	/* avancement vers l'origine du caractère suivant */
	short ascent;	/* ligne de base vers le bord supérieur du raster */
	short descent;	/* ligne de base vers le bord inférieur du raster */
	unsigned short attributes;	/* indicateurs par caractère (non prédéfinis) */
} XCharStruct;
typedef struct {
	Atom	name;
	unsigned long card32;
} XFontProp;
typedef struct {	/* les caractères normaux de 16 bits sont composés de deux octets */
    unsigned char byte1;
    unsigned char byte2;
} XChar2b;
typedef struct {
	XExtData *ext_data;	/* crochet pour que l'extension accroche des données */
	Font fid;	/* ID de police pour cette police */
	unsigned direction;	/* indice quant à la direction dans laquelle la police est peinte */
	unsigned min_char_or_byte2;	/* premier caractère */
	unsigned max_char_or_byte2;	/* dernier caractère */
	unsigned min_byte1;	/* première ligne existante */
	unsigned max_byte1;	/* dernière ligne existante */
	Bool all_chars_exist;	/* indicateur si tous les caractères ont une taille non nulle */
	unsigned default_char;	/* caractère à imprimer pour un caractère indéfini */
	int n_properties;	/* nombre de propriétés */
	XFontProp *properties;	/* pointeur vers le tableau de propriétés supplémentaires */
	XCharStruct min_bounds;	/* bornes minimales de tous les caractères existants */
	XCharStruct max_bounds;	/* bornes maximales de tous les caractères existants */
	XCharStruct *per_char;	/* informations du premier caractère au dernier */
	int ascent;	/* étendue logique au-dessus de la ligne de base pour l'espacement */
	int descent;	/* descente logique sous la ligne de base pour l'espacement */
} XFontStruct;

X prend en charge les opérations sur texte à un octet/caractère, à deux octets/caractères en matrice, et à 16 bits. Notez que l'une quelconque de ces formes peut être utilisée avec une police, mais une requête de texte à un octet/caractère ne peut spécifier qu'un seul octet (c'est-à-dire la première ligne d'une police à 2 octets). Vous devriez considérer les polices à 2 octets comme une matrice bidimensionnelle de caractères définis : byte1 spécifie la plage des lignes définies et byte2 définit la plage des colonnes définies de la police. Les polices à un octet/caractère ont une ligne définie, et la plage d'octets spécifiée dans la structure définit une plage de caractères.

La boîte englobante d'un caractère est définie par le XCharStruct de ce caractère. Lorsque des caractères sont absents d'une police, le caractère par défaut (default_char) est utilisé. Lorsque les polices ont tous les caractères de la même taille, seules les informations dans les bornes min et max de XFontStruct sont utilisées.

Les membres de XFontStruct ont les sémantiques suivantes :

  • Le membre direction peut être soit FontLeftToRight, soit FontRightToLeft. C'est juste un indice quant à savoir si la plupart des éléments XCharStruct ont une métrique de largeur de caractère positive (FontLeftToRight) ou négative (FontRightToLeft). Le protocole de base ne définit aucun support pour le texte vertical.
  • Si les membres min_byte1 et max_byte1 sont tous deux à zéro, min_char_or_byte2 spécifie l'index de caractère linéaire correspondant au premier élément du tableau per_char, et max_char_or_byte2 spécifie l'index de caractère linéaire du dernier élément.
Si min_byte1 ou max_byte1 est non nul, alors min_char_or_byte2 et max_char_or_byte2 sont tous deux inférieurs à 256, et les valeurs d'index de caractères à 2 octets correspondant à l'élément N du tableau per_char (en comptant à partir de 0) sont :
byte1 = N/D + min_byte1
byte2 = N\D + min_char_or_byte2
où : 
        D = max_char_or_byte2 - min_char_or_byte2 + 1
        / = division entière
        \ = reste

NOM

XCharStruct - structure d'information de caractère X

SYNTAXIS

typedef struct {
    int lbearing;
    int rbearing;
    int width;
    int ascent;
    int descent;
    unsigned int fallback;
} XCharStruct;

ARGUMENTS

Aucun

DESCRIPTION

La structure XCharStruct fournit des informations sur la taille et le positionnement des glyphes dans une police.

per_char
Un pointeur vers un tableau de structures XCharStruct. Ce tableau contient des informations sur chaque caractère de la police. Si ce pointeur est NULL, il est supposé que tous les caractères ont les mêmes limites, définies par min_bounds et max_bounds.
min_bounds
Les limites minimales pour tous les caractères de la police. Ces valeurs représentent les valeurs les plus extrêmes (plus petites) pour lbearing, rbearing, width, ascent et descent sur tous les caractères existants.
max_bounds
Les limites maximales pour tous les caractères de la police. Ces valeurs représentent les valeurs les plus extrêmes (plus grandes) pour lbearing, rbearing, width, ascent et descent sur tous les caractères existants.
all_chars_exist
Un drapeau booléen qui indique si tous les caractères prévus dans la plage spécifiée existent réellement dans la police. Si True, cela signifie que tous les caractères dans le tableau per_char ont des boîtes englobantes non nulles.
default_char
Le caractère utilisé lorsqu'un caractère non défini ou inexistant est imprimé. Ce caractère est un entier de 16 bits. Pour les polices utilisant un format matriciel de 2 octets, le default_char a le premier octet dans l'octet de poids fort et le second octet dans l'octet de poids faible. Si le default_char lui-même spécifie un caractère non défini ou inexistant, aucune impression n'est effectuée pour un tel caractère.
font_ascent
L'étendue logique de la police au-dessus de la ligne de base, utilisée pour déterminer l'espacement des lignes. Des caractères spécifiques peuvent dépasser cette limite.
font_descent
L'étendue logique de la police à la ligne de base ou en dessous, utilisée pour déterminer l'espacement des lignes. Des caractères spécifiques peuvent dépasser cette limite.
left_side_bearing
Définit l'étendue du bord gauche de l'encre du caractère par rapport à l'origine.
right_side_bearing
Définit l'étendue du bord droit de l'encre du caractère par rapport à l'origine.
character_width
Définit la largeur logique du caractère.
ascent
L'étendue du bord supérieur de l'encre du caractère par rapport à l'origine.
descent
L'étendue du bord inférieur de l'encre du caractère par rapport à l'origine.
fallback
Un drapeau indiquant si ce caractère est un caractère de secours.
  • Si le pointeur per_char est NULL, tous les glyphes entre les index du premier et du dernier caractère inclus ont les mêmes informations, comme donné par min_bounds et max_bounds.
  • Si all_chars_exist est True, tous les caractères dans le tableau per_char ont des boîtes englobantes non nulles.
  • Le membre default_char spécifie le caractère qui sera utilisé lors de l'impression d'un caractère indéfini ou inexistant. Le default_char est un caractère de 16 bits (pas un caractère de 2 octets). Pour une police utilisant le format matriciel de 2 octets, le default_char a byte1 dans l'octet le plus significatif et byte2 dans l'octet le moins significatif. Si le default_char spécifie lui-même un caractère indéfini ou inexistant, aucune impression n'est effectuée pour un caractère indéfini ou inexistant.
  • Les membres min_bounds et max_bounds contiennent les valeurs les plus extrêmes de chaque composant individuel de XCharStruct sur tous les éléments de ce tableau (et ignorent les caractères inexistants). La boîte englobante de la police (le plus petit rectangle englobant la forme obtenue en superposant tous les caractères à la même origine [x,y]) a sa coordonnée supérieure gauche à : 
    [x + min_bounds.lbearing, y - max_bounds.ascent]
Sa largeur est : 
max_bounds.rbearing - min_bounds.lbearing
Sa hauteur est : 
max_bounds.ascent + max_bounds.descent
  • Le membre ascent est l'étendue logique de la police au-dessus de la ligne de base qui est utilisée pour déterminer l'espacement des lignes. Des caractères spécifiques peuvent dépasser cette limite.
  • Le membre descent est l'étendue logique de la police au niveau ou en dessous de la ligne de base qui est utilisée pour déterminer l'espacement des lignes. Des caractères spécifiques peuvent dépasser cette limite.
  • Si la ligne de base est à la coordonnée Y y, l'étendue logique de la police est comprise entre les coordonnées Y (y - font.ascent) et (y + font.descent - 1). Typiquement, l'espacement minimum entre les lignes de texte est donné par ascent + descent.

Pour une origine de caractère à [x,y], la boîte englobante d'un caractère (c'est-à-dire le plus petit rectangle qui englobe la forme du caractère) décrite en termes de composants XCharStruct est un rectangle dont le coin supérieur gauche est à :

[x + lbearing, y - ascent]

Sa largeur est :

rbearing - lbearing

Sa hauteur est :

ascent + descent

L'origine du caractère suivant est définie comme étant :

[x + width, y]

Le membre lbearing définit l'étendue du bord gauche de l'encre du caractère par rapport à l'origine. Le membre rbearing définit l'étendue du bord droit de l'encre du caractère par rapport à l'origine. Le membre ascent définit l'étendue du bord supérieur de l'encre du caractère par rapport à l'origine. Le membre descent définit l'étendue du bord inférieur de l'encre du caractère par rapport à l'origine. Le membre width définit la largeur logique du caractère.

DIAGNOSTICS

BadAlloc
Le serveur n'a pas pu allouer la ressource ou la mémoire serveur demandée.
BadFont
Une valeur pour un argument Font ou GContext ne nomme pas une police définie.
BadName
Une police ou une couleur du nom spécifié n'existe pas.
