XOpenDisplay(3) FONCTIONS XLIB XOpenDisplay(3)

NOM

XOpenDisplay, XCloseDisplay - se connecter ou se déconnecter du serveur X

SYNTAXE

Display *XOpenDisplay(_Xconst char *display_name);

int XCloseDisplay(Display *display);

ARGUMENTS

display
Spécifie la connexion au serveur X.
display_name
Spécifie le nom d'affichage matériel, qui détermine le périphérique d'affichage et le domaine de communication à utiliser. Sur un système conforme POSIX, si display_name est NULL, il prend par défaut la valeur de la variable d'environnement DISPLAY.

DESCRIPTION

La fonction XOpenDisplay retourne une structure Display qui sert de connexion au serveur X et qui contient toutes les informations sur ce serveur X. XOpenDisplay connecte votre application au serveur X via les protocoles de communication TCP ou DECnet, ou via un protocole de communication inter-processus local. Si le nom d'hôte est le nom d'une machine hôte et qu'un simple deux-points (:) sépare le nom d'hôte et le numéro d'affichage, XOpenDisplay se connecte en utilisant des flux TCP. Si le nom d'hôte n'est pas spécifié, Xlib utilise le transport qu'elle juge le plus rapide. Si le nom d'hôte est le nom d'une machine hôte et que deux deux-points (::) séparent le nom d'hôte et le numéro d'affichage, XOpenDisplay se connecte en utilisant DECnet. Un seul serveur X peut prendre en charge l'un quelconque ou la totalité de ces mécanismes de transport simultanément. Une implémentation Xlib particulière peut prendre en charge de nombreux autres mécanismes de transport.

En cas de succès, XOpenDisplay retourne un pointeur vers une structure Display, qui est définie dans X11/Xlib.h. Si XOpenDisplay ne réussit pas, elle retourne NULL. Après un appel réussi à XOpenDisplay, tous les écrans du périphérique d'affichage peuvent être utilisés par le client. Le numéro d'écran spécifié dans l'argument display_name est retourné par la macro DefaultScreen (ou la fonction XDefaultScreen). Vous ne pouvez accéder aux éléments des structures Display et Screen qu'en utilisant les macros ou fonctions d'information. Pour plus d'informations sur l'utilisation des macros et fonctions pour obtenir des informations à partir de la structure Display, consultez la section 2.2.1.

La fonction XCloseDisplay ferme la connexion au serveur X pour le périphérique d'affichage spécifié dans la structure Display et détruit toutes les fenêtres, identifiants de ressources (Window, Font, Pixmap, Colormap, Cursor et GContext), ou autres ressources que le client a créées sur ce périphérique d'affichage, à moins que le mode de fermeture de la ressource n'ait été modifié (voir XSetCloseDownMode). Par conséquent, ces fenêtres, identifiants de ressources et autres ressources ne doivent plus jamais être référencés, sous peine d'erreur. Avant de quitter, vous devez appeler explicitement XCloseDisplay afin que toute erreur en attente soit signalée, car XCloseDisplay effectue une opération XSync finale.

XCloseDisplay peut générer une erreur BadGC.
