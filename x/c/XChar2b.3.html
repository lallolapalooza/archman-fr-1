XLoadFont(3) FONCTIONS XLIB XLoadFont(3)

NOM

XLoadFont, XQueryFont, XLoadQueryFont, XFreeFont, XGetFontProperty, XUnloadFont, XCharStruct, XFontProp, XChar2b, XFontStruct - charger ou décharger des polices et des structures de métriques de polices

SYNTAXE

Font XLoadFont(Display *display, _Xconst char *name);

XFontStruct *XQueryFont(Display *display, XID font_ID);

XFontStruct *XLoadQueryFont(Display *display, _Xconst char *name);

int XFreeFont(Display *display, XFontStruct *font_struct);

Bool XGetFontProperty(XFontStruct *font_struct, Atom atom, unsigned long *value_return);

int XUnloadFont(Display *display, Font font);

ARGUMENTS

atom
Spécifie l'atome pour le nom de la propriété que vous souhaitez retourner.
display
Spécifie la connexion au serveur X.
font
Spécifie la police.
font_ID
Spécifie l'ID de la police ou l'ID du GContext.
font_struct
Spécifie le stockage associé à la police.
gc
Spécifie le GC.
name
Spécifie le nom de la police, qui est une chaîne terminée par un zéro.
value_return
Retourne la valeur de la propriété de la police.

DESCRIPTION

La fonction XLoadFont charge la police spécifiée et retourne son ID de police associé. Si le nom de la police n'est pas dans le jeu de caractères portable de l'hôte (Host Portable Character Encoding), le résultat est dépendant de l'implémentation. L'utilisation de majuscules ou de minuscules n'a pas d'importance. Lorsque les caractères « ? » et « * » sont utilisés dans un nom de police, une correspondance de modèle est effectuée et toute police correspondante est utilisée. Dans le modèle, le caractère « ? » correspond à n'importe quel caractère unique, et le caractère « * » correspond à n'importe quel nombre de caractères. Un format structuré pour les noms de police est spécifié dans les conventions de description des polices logiques X (X Logical Font Description Conventions) de la norme du Consortium X. Si XLoadFont n'a pas réussi à charger la police spécifiée, une erreur BadName en résulte. Les polices ne sont pas associées à un écran particulier et peuvent être stockées comme composant de n'importe quel GC. Lorsque la police n'est plus nécessaire, appelez XUnloadFont.

XLoadFont peut générer des erreurs BadAlloc et BadName.

La fonction XQueryFont retourne un pointeur vers la structure XFontStruct, qui contient des informations associées à la police. Vous pouvez interroger une police ou la police stockée dans un GC. L'ID de police stocké dans la structure XFontStruct sera l'ID du GContext, et vous devez être prudent lors de l'utilisation de cet ID dans d'autres fonctions (voir XGContextFromGC). Si la police n'existe pas, XQueryFont retourne NULL. Pour libérer ces données, utilisez XFreeFontInfo.

XLoadQueryFont peut générer une erreur BadAlloc.

La fonction XLoadQueryFont fournit le moyen le plus courant d'accéder à une police. XLoadQueryFont ouvre (charge) la police spécifiée et retourne un pointeur vers la structure XFontStruct appropriée. Si le nom de la police n'est pas dans le jeu de caractères portable de l'hôte (Host Portable Character Encoding), le résultat est dépendant de l'implémentation. Si la police n'existe pas, XLoadQueryFont retourne NULL.

La fonction XFreeFont supprime l'association entre l'ID de ressource de police et la police spécifiée et libère la structure XFontStruct. La police elle-même sera libérée lorsqu'aucune autre ressource ne la référencera. Les données et la police ne doivent plus être référencées.

XFreeFont peut générer une erreur BadFont.

Étant donné l'atome pour cette propriété, la fonction XGetFontProperty retourne la valeur de la propriété de police spécifiée. XGetFontProperty retourne également False si la propriété n'a pas été définie ou True si elle l'a été. Un ensemble d'atomes prédéfinis existe pour les propriétés de police, qui peuvent être trouvés dans X11/Xatom.h. Cet ensemble contient les propriétés standard associées à une police. Bien que ce ne soit pas garanti, il est probable que les propriétés de police prédéfinies soient présentes.

La fonction XUnloadFont supprime l'association entre l'ID de ressource de police et la police spécifiée. La police elle-même sera libérée lorsqu'aucune autre ressource ne la référencera. La police ne doit plus être référencée.

XUnloadFont peut générer une erreur BadFont.

STRUCTURES

La structure XFontStruct contient toutes les informations de la police et se compose des informations spécifiques à la police ainsi que d'un pointeur vers un tableau de structures XCharStruct pour les caractères contenus dans la police. Les structures XFontStruct, XFontProp et XCharStruct contiennent :

typedef struct {
	short lbearing;	/* origine vers le bord gauche du raster */
	short rbearing;	/* origine vers le bord droit du raster */
	short width;	/* avancée vers l'origine du caractère suivant */
	short ascent;	/* ligne de base vers le bord supérieur du raster */
	short descent;	/* ligne de base vers le bord inférieur du raster */
	unsigned short attributes;	/* indicateurs par caractère (non prédéfinis) */
} XCharStruct;
typedef struct {
	Atom	name;
	unsigned long card32;
} XFontProp;
typedef struct {	/* les caractères normaux de 16 bits sont deux octets */
    unsigned char byte1;
    unsigned char byte2;
} XChar2b;
typedef struct {
	XExtData *ext_data;	/* crochet pour que l'extension accroche des données */
	Font fid;	/* Id de police pour cette police */
	unsigned direction;	/* indice sur la direction dans laquelle la police est dessinée */
	unsigned min_char_or_byte2;	/* premier caractère */
	unsigned max_char_or_byte2;	/* dernier caractère */
	unsigned min_byte1;	/* première ligne qui existe */
	unsigned max_byte1;	/* dernière ligne qui existe */
	Bool all_chars_exist;	/* indicateur si tous les caractères ont une taille non nulle */
	unsigned default_char;	/* caractère à imprimer pour un caractère indéfini */
	int n_properties;	/* nombre de propriétés */
	XFontProp *properties;	/* pointeur vers le tableau de propriétés supplémentaires */
	XCharStruct min_bounds;	/* limites minimales sur tous les caractères existants */
	XCharStruct max_bounds;	/* limites maximales sur tous les caractères existants */
	XCharStruct *per_char;	/* informations du premier caractère à dernier caractère */
	int ascent;	/* étendue logique au-dessus de la ligne de base pour l'espacement */
	int descent;	/* étendue logique en dessous de la ligne de base pour l'espacement */
} XFontStruct;

X prend en charge les opérations de texte sur un seul octet/caractère, deux octets/caractère en matrice, et des caractères de 16 bits. Notez que n'importe laquelle de ces formes peut être utilisée avec une police, mais une requête de texte sur un seul octet/caractère ne peut spécifier qu'un seul octet (c'est-à-dire la première ligne d'une police à 2 octets). Vous devriez considérer les polices à 2 octets comme une matrice bidimensionnelle de caractères définis : byte1 spécifie la plage de lignes définies et byte2 définit la plage de colonnes définies de la police. Les polices à un seul octet/caractère ont une ligne définie, et la plage byte2 spécifiée dans la structure définit une plage de caractères.

La boîte englobante d'un caractère est définie par le XCharStruct de ce caractère. Lorsque des caractères sont absents d'une police, le caractère par défaut (default_char) est utilisé. Lorsque les polices ont tous les caractères de la même taille, seules les informations dans les limites min et max du XFontStruct sont utilisées.

Les membres du XFontStruct ont les sémantiques suivantes :

  • Le membre direction peut être soit FontLeftToRight, soit FontRightToLeft. C'est juste un indice indiquant si la plupart des éléments XCharStruct ont une largeur de caractère métrique positive (FontLeftToRight) ou négative (FontRightToLeft). Le protocole de base ne définit aucun support pour le texte vertical.
  • Si les membres min_byte1 et max_byte1 sont tous deux zéro, min_char_or_byte2 spécifie l'indice de caractère linéaire correspondant au premier élément du tableau per_char, et max_char_or_byte2 spécifie l'indice de caractère linéaire du dernier élément.
Si min_byte1 ou max_byte1 sont non nuls, alors min_char_or_byte2 et max_char_or_byte2 sont tous deux inférieurs à 256, et les valeurs d'indice de caractère à 2 octets correspondant à l'élément N du tableau per_char (en comptant à partir de 0) sont :
byte1 = N/D + min_byte1
byte2 = N%D + min_char_or_byte2
où : 
        D = max_char_or_byte2 - min_char_or_byte2 + 1
        / = division entière
        % = reste de la division
