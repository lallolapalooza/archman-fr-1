XCHANGEKEYBOARDDEVIC(3)   XCHANGEKEYBOARDDEVIC(3)

NOM

XChangeKeyboardDevice - changer le périphérique utilisé comme clavier X

SYNTAXE

#include <X11/extensions/XInput.h>
Status XChangeKeyboardDevice( Display *display,
                              XDevice *device);
display
       Spécifie la connexion au serveur X.
device
       Spécifie le périphérique à utiliser comme clavier X.

DESCRIPTION

La requête XChangeKeyboardDevice demande au serveur d'utiliser le
périphérique spécifié comme clavier X. Le périphérique doit avoir été
précédemment ouvert par le client demandeur via XOpenDevice, sinon une
erreur BadDevice surviendra. Le périphérique doit supporter la classe
d'entrée Keys, sinon une erreur BadMatch surviendra. Si l'implémentation du
serveur ne supporte pas l'utilisation du périphérique demandé comme clavier
X, une erreur BadDevice surviendra.
Si le périphérique spécifié est déjà saisi (grabbed) par un autre client,
AlreadyGrabbed sera retourné. Si le périphérique spécifié est gelé par une
saisie sur un autre périphérique, GrabFrozen sera retourné. Si la requête
réussit, Success sera retourné.
Si la requête réussit, un événement ChangeDeviceNotify est envoyé à tous les
clients ayant sélectionné cet événement. Un événement MappingNotify avec
request = MappingKeyboard est envoyé à tous les clients. Le périphérique
spécifié devient le clavier X et l'ancien clavier X devient accessible via
les requêtes du protocole d'extension d'entrée.
XChangeKeyboardDevice peut générer une erreur BadDevice ou BadMatch.

DIAGNOSTICS

BadDevice
       Un périphérique invalide a été spécifié. Le périphérique spécifié
       n'existe pas, n'a pas été ouvert par ce client via XOpenInputDevice,
       ou est déjà l'un des périphériques principaux X (pointeur ou clavier).
       Cette erreur peut également survenir si l'implémentation du serveur
       ne supporte pas l'utilisation du périphérique spécifié comme clavier
       X.
BadMatch
       Cette erreur peut survenir si une requête XChangeKeyboardDevice a été
       faite en spécifiant un périphérique qui n'a pas de touches.
