XSetSelectionOwner(3) FONCTIONS XLIB XSetSelectionOwner(3)

NOM

XSetSelectionOwner, XGetSelectionOwner, XConvertSelection - manipuler la sélection de fenêtre

SYNTAXE

int XSetSelectionOwner(Display *display, Atom selection, Window owner, Time time);

Window XGetSelectionOwner(Display *display, Atom selection);

int XConvertSelection(Display *display, Atom selection, Atom target, Atom property, Window requestor, Time time);

ARGUMENTS

display
Spécifie la connexion au serveur X.
owner
Spécifie le propriétaire de l'atome de sélection donné. Vous pouvez passer une fenêtre ou None.
property
Spécifie le nom de la propriété. Vous pouvez également passer None.
requestor
Spécifie le demandeur.
selection
Spécifie l'atome de sélection.
target
Spécifie l'atome cible.
time
Spécifie le temps. Vous pouvez passer soit un horodatage, soit CurrentTime.

DESCRIPTION

La fonction XSetSelectionOwner modifie le propriétaire et l'heure du dernier changement pour la sélection spécifiée et n'a aucun effet si l'heure spécifiée est antérieure à l'heure du dernier changement de la sélection spécifiée ou est postérieure à l'heure actuelle du serveur X. Sinon, l'heure du dernier changement est définie à l'heure spécifiée, avec CurrentTime remplacé par l'heure actuelle du serveur. Si la fenêtre propriétaire est spécifiée comme None, alors le propriétaire de la sélection devient None (c'est-à-dire aucun propriétaire). Sinon, le propriétaire de la sélection devient le client exécutant la requête.

Si le nouveau propriétaire (qu'il s'agisse d'un client ou de None) n'est pas le même que le propriétaire actuel de la sélection et que le propriétaire actuel n'est pas None, le propriétaire actuel reçoit un événement SelectionClear. Si le client qui est propriétaire d'une sélection est ultérieurement terminé (c'est-à-dire que sa connexion est fermée) ou si la fenêtre propriétaire qu'il a spécifiée dans la requête est ultérieurement détruite, le propriétaire de la sélection revient automatiquement à None, mais l'heure du dernier changement n'est pas affectée. L'atome de sélection n'est pas interprété par le serveur X. XGetSelectionOwner renvoie l'ID de la fenêtre, qui est rapporté dans les événements SelectionRequest et SelectionClear. Les sélections sont globales au serveur X.

XSetSelectionOwner peut générer des erreurs BadAtom et BadWindow.

La fonction XGetSelectionOwner renvoie l'ID de la fenêtre associé à la fenêtre qui possède actuellement la sélection spécifiée. Si aucune sélection n'a été spécifiée, la fonction renvoie la constante None. Si None est renvoyé, il n'y a pas de propriétaire pour la sélection.

XGetSelectionOwner peut générer une erreur BadAtom.

XConvertSelection demande que la sélection spécifiée soit convertie vers le type cible spécifié :

  • Si la sélection spécifiée a un propriétaire, le serveur X envoie un événement SelectionRequest à ce propriétaire.
  • Si aucun propriétaire n'existe pour la sélection spécifiée, le serveur X génère un événement SelectionNotify au demandeur avec la propriété None.

Les arguments sont transmis tels quels dans l'un ou l'autre des événements. Il existe deux atomes de sélection prédéfinis : PRIMARY et SECONDARY.

XConvertSelection peut générer des erreurs BadAtom et BadWindow.

DIAGNOSTICS

BadAtom
Une valeur pour un argument d'Atome ne nomme pas un Atome défini.
BadWindow
Une valeur pour un argument de Fenêtre ne nomme pas une Fenêtre définie.
