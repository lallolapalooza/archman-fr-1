XcmsQueryColor(3) FONCTIONS XLIB XcmsQueryColor(3)

NOM

XcmsQueryColor, XcmsQueryColors, XcmsLookupColor - obtenir les valeurs de couleur

SYNTAXE

Status XcmsQueryColor(Display *display, Colormap colormap, XcmsColor *color_in_out, XcmsColorFormat result_format);

Status XcmsQueryColors(Display *display, Colormap colormap, XcmsColor colors_in_out[], unsigned int ncolors, XcmsColorFormat result_format);

Status XcmsLookupColor(Display *display, Colormap colormap, _Xconst char *color_string, XcmsColor *color_exact_return, XcmsColor *color_screen_return, XcmsColorFormat result_format);

ARGUMENTS

display
Spécifie la connexion au serveur X.
colormap
Spécifie la table des couleurs.
color_exact_return
Retourne la spécification de couleur analysée à partir de la chaîne de couleur ou analysée à partir de la chaîne correspondante trouvée dans une base de données de noms de couleur.
color_in_out
Spécifie le membre pixel qui indique la cellule de couleur à interroger. La spécification de couleur stockée pour la cellule de couleur est retournée dans cette structure XcmsColor.
color_screen_return
Retourne la couleur qui peut être reproduite à l'écran.
color_string
Spécifie la chaîne de couleur.
result_format
Spécifie le format de couleur pour les spécifications de couleur retournées (arguments color_screen_return et color_exact_return). Si le format est XcmsUndefinedFormat et que la chaîne de couleur contient une spécification de couleur numérique, la spécification est retournée dans le format utilisé dans cette spécification de couleur numérique. Si le format est XcmsUndefinedFormat et que la chaîne de couleur contient un nom de couleur, la spécification est retournée dans le format utilisé pour stocker la couleur dans la base de données.
ncolors
Spécifie le nombre de structures XcmsColor dans le tableau de spécifications de couleur.

DESCRIPTION

La fonction XcmsQueryColor obtient la valeur RVB de la valeur de pixel dans le membre pixel de la structure XcmsColor spécifiée, puis convertit la valeur au format cible comme spécifié par l'argument result_format. Si le pixel n'est pas un index valide dans la table des couleurs spécifiée, une erreur BadValue se produit. La fonction XcmsQueryColors obtient les valeurs RVB pour les valeurs de pixel dans les membres pixel des structures XcmsColor, puis convertit les valeurs au format cible comme spécifié par l'argument result_format. Si un pixel n'est pas un index valide dans la table des couleurs spécifiée, une erreur BadValue se produit. Si plusieurs pixels sont en erreur, celui qui est signalé est arbitraire.

XcmsQueryColor et XcmsQueryColors peuvent générer des erreurs BadColor et BadValue.

La fonction XcmsLookupColor recherche le nom de chaîne d'une couleur par rapport à l'écran associé à la table des couleurs spécifiée. Elle retourne à la fois les valeurs exactes de la couleur et les valeurs les plus proches fournies par l'écran par rapport au type visuel de la table des couleurs spécifiée. Les valeurs sont retournées dans le format spécifié par result_format. Si le nom de la couleur n'est pas dans le codage de caractères portable de l'hôte, le résultat dépend de l'implémentation. L'utilisation de majuscules ou de minuscules n'a pas d'importance. XcmsLookupColor retourne XcmsSuccess ou XcmsSuccessWithCompression si le nom est résolu ; sinon, elle retourne XcmsFailure. Si XcmsSuccessWithCompression est retourné, la spécification de couleur retournée dans color_screen_return est le résultat de la compression de la gamme.

DIAGNOSTICS

BadColor
Une valeur pour un argument Colormap ne nomme pas une Colormap définie.
BadValue
Une valeur numérique tombe en dehors de la plage de valeurs acceptées par la requête. Sauf si une plage spécifique est spécifiée pour un argument, la plage complète définie par le type de l'argument est acceptée. Tout argument défini comme un ensemble d'alternatives peut générer cette erreur.
