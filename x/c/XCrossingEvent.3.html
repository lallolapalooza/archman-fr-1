NOM

XCrossingEvent - Structure d'événement EnterNotify et LeaveNotify

STRUCTURES

La structure pour les événements EnterNotify et LeaveNotify contient :

typedef struct {
        int type;       /* EnterNotify or LeaveNotify */
        unsigned long serial;   /* # of last request processed by server */
        Bool send_event;        /* true if this came from a SendEvent request */
        Display *display;       /* Display the event was read from */
        Window window;  /* “event” window reported relative to */
        Window root;    /* root window that the event occurred on */
        Window subwindow;       /* child window */
        Time time;      /* milliseconds */
        int x, y;       /* pointer x, y coordinates in event window */
        int x_root, y_root;     /* coordinates relative to root */
        int mode;       /* NotifyNormal, NotifyGrab, NotifyUngrab */
        int detail;
                /*
                * NotifyAncestor, NotifyVirtual, NotifyInferior,
                * NotifyNonlinear,NotifyNonlinearVirtual
                */
        Bool same_screen;       /* same screen flag */
        Bool focus;     /* boolean focus */
        unsigned int state;     /* key or button mask */
} XCrossingEvent;
typedef XCrossingEvent XEnterWindowEvent;
typedef XCrossingEvent XLeaveWindowEvent;

Lorsque vous recevez ces événements, les membres de la structure sont définis comme suit.

Le membre type est défini sur la constante symbolique identifiant de manière unique l'événement. Par exemple, lorsque le serveur X rapporte un événement GraphicsExpose à une application cliente, il envoie une structure XGraphicsExposeEvent avec le membre type défini sur GraphicsExpose. Le membre display est défini sur un pointeur vers l'affichage à partir duquel l'événement a été lu. Le membre send_event est défini sur True si l'événement provient d'une requête de protocole SendEvent. Le membre serial est défini à partir du numéro de série rapporté dans le protocole mais développé à partir des 16 bits les moins significatifs vers une valeur complète de 32 bits. Le membre window est défini sur la fenêtre la plus utile pour les répartiteurs de boîtes à outils.

Le membre window est défini sur la fenêtre sur laquelle l'événement EnterNotify ou LeaveNotify a été généré et est désigné comme la fenêtre d'événement. C'est la fenêtre utilisée par le serveur X pour signaler l'événement, et elle est relative à la fenêtre racine sur laquelle l'événement s'est produit. Le membre root est défini sur la fenêtre racine de l'écran sur lequel l'événement s'est produit.

Pour un événement LeaveNotify, si un enfant de la fenêtre d'événement contient la position initiale du pointeur, le composant subwindow est défini sur cet enfant. Sinon, le serveur X définit le membre subwindow sur None. Pour un événement EnterNotify, si un enfant de la fenêtre d'événement contient la position finale du pointeur, le composant subwindow est défini sur cet enfant ou sur None.

Le membre time est défini sur le moment où l'événement a été généré et est exprimé en millisecondes. Les membres x et y sont définis sur les coordonnées de la position du pointeur dans la fenêtre d'événement. Cette position est toujours la position finale du pointeur, pas sa position initiale. Si la fenêtre d'événement se trouve sur le même écran que la fenêtre racine, x et y sont les coordonnées du pointeur relatives à l'origine de la fenêtre d'événement. Sinon, x et y sont définis sur zéro. Les membres x_root et y_root sont définis sur les coordonnées du pointeur relatives à l'origine de la fenêtre racine au moment de l'événement.

Le membre same_screen est défini pour indiquer si la fenêtre d'événement se trouve sur le même écran que la fenêtre racine et peut être soit True, soit False. Si True, les fenêtres d'événement et racine sont sur le même écran. Si False, les fenêtres d'événement et racine ne sont pas sur le même écran.

Le membre focus est défini pour indiquer si la fenêtre d'événement est la fenêtre de focalisation ou un inférieur de la fenêtre de focalisation. Le serveur X peut définir ce membre sur True ou False. Si True, la fenêtre d'événement est la fenêtre de focalisation ou un inférieur de la fenêtre de focalisation. Si False, la fenêtre d'événement n'est pas la fenêtre de focalisation ou un inférieur de la fenêtre de focalisation.

Le membre state est défini pour indiquer l'état des boutons du pointeur et des touches modificatrices juste avant l'événement. Le serveur X peut définir ce membre sur l'opération OU bit à bit inclusive d'un ou plusieurs des masques de boutons ou de touches modificatrices : Button1Mask, Button2Mask, Button3Mask, Button4Mask, Button5Mask, ShiftMask, LockMask, ControlMask, Mod1Mask, Mod2Mask, Mod3Mask, Mod4Mask, Mod5Mask.

Le membre mode est défini pour indiquer si les événements sont des événements normaux, des événements de pseudo-mouvement lorsqu'une prise s'active, ou des événements de pseudo-mouvement lorsqu'une prise se désactive. Le serveur X peut définir ce membre sur NotifyNormal, NotifyGrab, ou NotifyUngrab.

Le membre detail est défini pour indiquer le détail de notification et peut être NotifyAncestor, NotifyVirtual, NotifyInferior, NotifyNonlinear, ou NotifyNonlinearVirtual.
