NOM

Xcursor — Bibliothèque de gestion des curseurs

SYNTAXE

#include <X11/Xcursor/Xcursor.h>

DESCRIPTION

Xcursor est une bibliothèque simple conçue pour aider à localiser et charger des curseurs. Les curseurs peuvent être chargés à partir de fichiers ou de la mémoire. Une bibliothèque de curseurs courants existe, qui correspond aux noms de curseurs X standard. Les curseurs peuvent exister en plusieurs tailles et la bibliothèque choisit automatiquement la meilleure taille.

APERÇU FONCTIONNEL

Xcursor est construit en plusieurs couches ; la couche inférieure contient le code qui peut charger des images de curseurs à partir de fichiers. Au-dessus se trouve une couche qui localise les fichiers de curseurs en fonction du chemin de la bibliothèque et du thème. Au sommet se trouve une couche qui construit des curseurs soit à partir d'une image chargée à partir d'un fichier, soit à partir de l'un des curseurs X standard. Lors de l'utilisation d'images chargées à partir de fichiers, Xcursor préfère utiliser la requête `CreateCursor` de l'extension Render si elle est prise en charge par le serveur X. Là où elle n'est pas prise en charge, Xcursor mappe l'image du curseur à un curseur X standard et utilise la requête `CreateCursor` du noyau.

FICHIERS DE CURSEURS

Xcursor définit un nouveau format pour les curseurs sur disque. Chaque fichier contient une ou plusieurs images de curseurs. Chaque image de curseur est étiquetée avec une taille nominale afin que la meilleure taille puisse être sélectionnée automatiquement. Plusieurs curseurs de la même taille nominale peuvent être chargés ensemble ; les applications sont censées les utiliser comme une séquence animée.

Les fichiers de curseurs sont stockés sous la forme d'un en-tête contenant une table des matières suivie d'une séquence de blocs. La table des matières indique le type, le sous-type et la position dans le fichier de chaque bloc. L'en-tête du fichier ressemble à ceci :


magie:	CARD32 "Xcur" (0x58, 0x63, 0x75, 0x72)
en-tête:	CARD32 octets dans cet en-tête
version:	CARD32 numéro de version du fichier
ntoc:	CARD32 nombre d'entrées de la table des matières
toc:	LISTofTOC table des matières

Chaque entrée de la table des matières ressemble à ceci :


type:	CARD32 type d'entrée
sous-type:	CARD32 étiquette spécifique au type - taille pour les images
position:	CARD32 position absolue en octets de la table dans le fichier

Chaque bloc dans le fichier possède un ensemble de champs d'en-tête communs suivis de champs supplémentaires spécifiques au type :


en-tête:	CARD32 octets dans l'en-tête du bloc (y compris les champs spécifiques au type)
type:	CARD32 doit correspondre au type dans la table des matières pour ce bloc
sous-type:	CARD32 doit correspondre au sous-type dans la table des matières pour ce bloc
version:	CARD32 numéro de version pour ce type de bloc

Il existe actuellement deux types de blocs définis pour les fichiers de curseurs ; commentaires et images. Les commentaires ressemblent à ceci :


en-tête:	20 Les en-têtes de commentaire font 20 octets
type:	0xfffe0001 Le type de commentaire est 0xfffe0001
sous-type:	{ 1 (COPYRIGHT), 2 (LICENSE), 3 (AUTRE) }
version:	1
longueur:	CARD32 longueur en octets de la chaîne UTF-8
chaîne:	LISTofCARD8 chaîne UTF-8

Les images ressemblent à ceci :


en-tête:	36 Les en-têtes d'image font 36 octets
type:	0xfffd0002 Le type d'image est 0xfffd0002
sous-type:	CARD32 Le sous-type d'image est la taille nominale
version:	1
largeur:	CARD32 Doit être inférieure ou égale à 0x7fff
hauteur:	CARD32 Doit être inférieure ou égale à 0x7fff
xhot:	CARD32 Doit être inférieur ou égal à la largeur
yhot:	CARD32 Doit être inférieur ou égal à la hauteur
délai:	CARD32 Délai entre les images d'animation en millisecondes
pixels:	LISTofCARD32 Pixels au format ARGB compressé

THÈMES

Xcursor suit (en grande partie) les spécifications freedesktop.org pour le thématisation des icônes. Le chemin de recherche par défaut qu'il utilise est

~/.local/share/icons, ~/.icons, /usr/share/icons, /usr/share/pixmaps

Dans chacun de ces répertoires, il recherche un répertoire en utilisant le nom du thème :

•
Dans le répertoire du thème, il recherche des fichiers de curseurs dans le sous-répertoire "cursors".
Xcursor recherche un fichier spécifique, qui doit être l'un des noms de forme de curseur, par exemple, tel qu'utilisé dans XcursorLibraryLoadImage ou XcursorLibraryShape.
•
S'il ne trouve aucun fichier de curseur correspondant dans le sous-répertoire "cursors", Xcursor recherche ensuite un fichier "index.theme" dans chaque répertoire de thème pour rechercher les thèmes hérités. Il s'agit de lignes de ce format :
Hérite = nom-du-thème

Xcursor utilise le premier nom-du-thème hérité, ignorant les autres qui peuvent exister dans un fichier "index.theme" donné. S'il trouve un thème hérité, Xcursor recherche également le long du chemin pour l'utiliser. Xcursor ignore les autres clés dans le fichier "index.theme", y compris "Nom" (c'est-à-dire le nom qu'une application graphique peut utiliser comme nom de présentation).

Plus d'un nom-du-thème peut être listé sur la ligne Hérite=. La spécification freedesktop.org indique que les éléments de la liste sont séparés par des virgules. Xcursor accepte également le point-virgule, mais traduit les deux en deux-points lors de la recherche dans le chemin. Xcursor attend une seule ligne Hérite= ; la spécification freedesktop.org n'est pas claire quant à savoir si plusieurs clés sont autorisées.

Si aucun thème n'est défini, ou si aucun curseur n'est trouvé pour le thème spécifié nulle part le long du chemin, Xcursor vérifie le thème "par défaut".

Lorsque Xcursor trouve un fichier de curseur, il arrête de chercher. Il utilise toujours le premier fichier de curseur trouvé lors de la recherche le long du chemin.

TYPES DE DONNÉES

XcursorImage
contient une seule image de curseur en mémoire. Chaque pixel du curseur est une valeur de 32 bits contenant ARGB avec A dans l'octet de poids fort. 


typedef struct _XcursorImage {
    XcursorDim 	 size; 	/* taille nominale pour la correspondance */
    XcursorDim 	 width; 	/* largeur réelle */
    XcursorDim 	 height; 	/* hauteur réelle */
    XcursorDim 	 xhot; 	/* point chaud x (doit être à l'intérieur de l'image) */
    XcursorDim 	 yhot; 	/* point chaud y (doit être à l'intérieur de l'image) */
    XcursorPixel 	*pixels; 	/* pointeur vers les pixels */
} XcursorImage;
XcursorImages
contient plusieurs structures XcursorImage. Elles sont toutes libérées lorsque les XcursorImages sont libérées dans XcursorImagesDestroy. 


typedef struct _XcursorImages {
    int 	 nimage; 	/* nombre d'images */
    XcursorImage 	**images; 	/* tableau de pointeurs XcursorImage */
} XcursorImages;
XcursorCursors
Contient plusieurs objets Cursor. Ils sont tous libérés lorsque XcursorCursors est libéré. Ils sont comptés par référence afin que plusieurs structures XcursorAnimate puissent utiliser les mêmes XcursorCursors. 


typedef struct _XcursorCursors {
    Display 	*dpy; 	/* Affichage contenant les curseurs */
    int 	 ref; 	/* compteur de références */
    int 	 ncursor; 	/* nombre de curseurs */
    Cursor 	*cursors; 	/* tableau de curseurs */
} XcursorCursors;
XcursorAnimate
Fait référence à un ensemble de curseurs et à une séquence dans cet ensemble. Plusieurs structures XcursorAnimate peuvent faire référence au même XcursorCursors ; chacune détient une référence qui est supprimée lorsque XcursorAnimate est libéré. 


typedef struct _XcursorAnimate {
    XcursorCursors 	*cursors; 	/* liste des curseurs à utiliser */
    int 	 sequence; 	/* quel curseur est le suivant */
} XcursorAnimate;
XcursorFile
Xcursor fournit une API abstraite pour accéder aux données des fichiers. Xcursor fournit une implémentation stdio de cette API abstraite ; les applications sont libres de créer des implémentations supplémentaires. Ces fonctions sont parallèles aux fonctions stdio.
o fonctions dans la valeur de retour et les valeurs d'arguments attendues ; les fonctions read et write inversent les arguments pour correspondre aux versions POSIX. 


typedef struct _XcursorFile {
    void *closure;
    int (*read)  (XcursorFile *file, unsigned char *buf, int len);
    int (*write) (XcursorFile *file, unsigned char *buf, int len);
    int (*seek)  (XcursorFile *file, long offset, int whence);
};

Lecture des images de bibliothèque

XcursorImage *XcursorLibraryLoadImage (
const char 	*name,
const char 	*theme,
int 	 size)
XcursorImages *XcursorLibraryLoadImages (
	const char 	*name,
	const char 	*theme,
	int 	 size)

Ces fonctions recherchent dans le chemin de la bibliothèque, chargeant le premier fichier trouvé de la taille désirée, en utilisant une fonction privée (XcursorScanTheme) pour trouver le thème approprié :

  • Si theme n'est pas NULL, utilisez-le.
  • Si theme est NULL, ou s'il n'y a pas eu de correspondance pour le thème désiré, utilisez “default” pour le nom du thème.
  • Si aucune des recherches ne réussit, ces fonctions retournent NULL.
Les deux fonctions diffèrent par plus que le nombre d'images chargées :
  • XcursorLibraryLoadImage appelle XcursorFileLoadImage mais
  • XcursorLibraryLoadImages appelle XcursorFileLoadImages, et (en cas de succès) appelle XcursorImagesSetName pour associer name au résultat.

DESCRIPTION


The Xcursor library provides an interface to load and manage Xcursor
    images and cursors. It allows applications to load cursors from files or
    from the Xcursor library, and to set and get various properties such as
    theme, size, and color.






FUNCTIONAL OVERVIEW


The library provides functions for loading cursor images from
    different sources:



  

  
XcursorFilenameLoadImage and XcursorFilenameLoadCursor load
      a single image or cursor from a specified filename.

  

  
XcursorLoadImages and XcursorLoadCursors load all images
      or cursors from a specified theme directory.

  

  
XcursorLibraryLoadImage and XcursorLibraryLoadCursor load
      a single image or cursor from the Xcursor library.

  

  
XcursorLibraryLoadImages and XcursorLibraryLoadCursors load
      all images or cursors from the Xcursor library.




The library also allows managing cursor themes, sizes, and
    colors:



  

  
XcursorGetDefaultTheme and XcursorGetTheme retrieve the
      current or default cursor theme name.

  

  
XcursorSetTheme sets the cursor theme for the display.

  

  
XcursorGetDefaultSize and XcursorGetSize retrieve the
      current or default cursor size.

  

  
XcursorSetSize sets the cursor size for the display.

  

  
XcursorGetColor and XcursorSetColor get and set the cursor
      color.

  

  
XcursorGetDefaultColor retrieves the default cursor color.

  

  
XcursorGetThemeCore and XcursorSetThemeCore get and set
      whether themes are enabled for core cursors.








DATATYPES



  
XcursorImagesPtr

  
A pointer to a structure containing a list of cursor images.

  
XcursorCursorPtr

  
A pointer to a structure representing a cursor.

  
XcursorError

  
An enumeration type for error codes.

  
XcursorScheme

  
An enumeration type for cursor schemes (e.g., left_ptr, right_ptr).

  
XcursorColor

  
A structure representing a color, with fields for red, green, blue, and
      pixel value.








FUNCTIONS


The functions listed in the SYNOPSIS section are described in
    detail in their respective manual pages.






ENVIRONMENT



  
XCURSOR_THEME

  
Specifies the default cursor theme to use.

  
XCURSOR_SIZE

  
Specifies the default cursor size to use.

  
XCURSOR_DIR

  
Specifies the directory to search for cursor themes.

  
R_THEME_CORE

  
Enables themes for core cursors if the environment variable is
      true.





  

  
If the environment variable is not given, Xcursor tries the
      Xcursor.theme_core resource.

  

  
An application can enable or disable themes using
    XcursorSetThemeCore.

    attempts will be made to retain some level of source-file compatibility.
