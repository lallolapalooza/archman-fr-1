NOM

XcmsQueryBlack, XcmsQueryBlue, XcmsQueryGreen, XcmsQueryRed, XcmsQueryWhite - obtenir les spécifications de couleur CCC noir, bleu, vert, rouge et blanc

SYNTAXE

Status XcmsQueryBlack(XcmsCCC ccc, XcmsColorFormat target_format, XcmsColor *color_return);

Status XcmsQueryBlue(XcmsCCC ccc, XcmsColorFormat target_format, XcmsColor *color_return);

Status XcmsQueryGreen(XcmsCCC ccc, XcmsColorFormat target_format, XcmsColor *color_return);

Status XcmsQueryRed(XcmsCCC ccc, XcmsColorFormat target_format, XcmsColor *color_return);

Status XcmsQueryWhite(XcmsCCC ccc, XcmsColorFormat target_format, XcmsColor *color_return);

ARGUMENTS

ccc
Spécifie le CCC. Notez que les procédures de point blanc et d'ajustement du point blanc du CCC sont ignorées.
color_return
Retourne la spécification de couleur dans le format cible spécifié. Le point blanc associé à la spécification de couleur retournée est le Point Blanc de l'Écran. La valeur retournée dans le membre pixel est indéfinie.
target_format
Spécifie le format de la spécification de couleur cible.

DESCRIPTION

La fonction XcmsQueryBlack retourne la spécification de couleur dans le format cible spécifié pour une intensité nulle des composantes rouge, verte et bleue.

La fonction XcmsQueryBlue retourne la spécification de couleur dans le format cible spécifié pour une intensité maximale de la composante bleue, tandis que les composantes rouge et verte sont nulles.

La fonction XcmsQueryGreen retourne la spécification de couleur dans le format cible spécifié pour une intensité maximale de la composante verte, tandis que les composantes rouge et bleue sont nulles.

La fonction XcmsQueryRed retourne la spécification de couleur dans le format cible spécifié pour une intensité maximale de la composante rouge, tandis que les composantes verte et bleue sont nulles.

La fonction XcmsQueryWhite retourne la spécification de couleur dans le format cible spécifié pour une intensité maximale des composantes rouge, verte et bleue.
