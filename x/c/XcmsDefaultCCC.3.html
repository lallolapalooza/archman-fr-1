NOM

XcmsDefaultCCC - obtenir le CCC par défaut pour un écran

SYNTAXE

XcmsCCC XcmsDefaultCCC(Display *display, int screen_number);

ARGUMENTS

display
Spécifie la connexion au serveur X.
screen_number
Spécifie le numéro d'écran approprié sur le serveur hôte.

DESCRIPTION

La fonction XcmsDefaultCCC renvoie le CCC par défaut pour l'écran spécifié. Sa visualisation est la visualisation par défaut de l'écran. Ses procédures initiales de compression de gamme et d'ajustement du point blanc ainsi que les données client associées sont spécifiques à l'implémentation.
