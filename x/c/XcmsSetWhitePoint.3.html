XcmsSetWhitePoint(3) FONCTIONS XLIB XcmsSetWhitePoint(3)

NOM

XcmsSetWhitePoint, XcmsSetWhiteAdjustProc - modification des attributs CCC

SYNTAXE

Status XcmsSetWhitePoint(XcmsCCC ccc, XcmsColor *color);

XcmsWhiteAdjustProc XcmsSetWhiteAdjustProc(XcmsCCC ccc, XcmsWhiteAdjustProc white_adjust_proc, XPointer client_data);

ARGUMENTS

ccc
Spécifie le CCC.
client_data
Spécifie les données client pour la procédure d'ajustement du point blanc ou NULL.
color
Spécifie le nouveau Point Blanc Client.
white_adjust_proc
Spécifie la procédure d'ajustement du point blanc.

DESCRIPTION

La fonction XcmsSetWhitePoint modifie le Point Blanc Client dans le CCC spécifié. Notez que le membre pixel est ignoré et que la spécification de couleur reste inchangée au retour. Le format pour le nouveau point blanc doit être XcmsCIEXYZFormat, XcmsCIEuvYFormat, XcmsCIExyYFormat ou XcmsUndefinedFormat. Si l'argument color est NULL, cette fonction définit le composant format de la spécification du Point Blanc Client à XcmsUndefinedFormat, indiquant que le Point Blanc Client est supposé être identique au Point Blanc de l'Écran.

Cette fonction retourne un statut non nul si le format du nouveau point blanc est valide ; sinon, elle retourne zéro.

La fonction XcmsSetWhiteAdjustProc définit d'abord la procédure d'ajustement du point blanc et les données client dans le CCC spécifié avec la nouvelle procédure et les nouvelles données client, puis retourne l'ancienne procédure.
