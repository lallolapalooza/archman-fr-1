XcupStoreColors(3) FONCTIONS X XcupStoreColors(3)

NOM

XcupStoreColors - initialise les entrées de table de couleurs partageables à des emplacements spécifiques

SYNTAXE

cc [ flag ... ] fichier ... -lXext [ bibliothèque ... ]
#include <X11/extensions/Xcup.h>
Status XcupStoreColors(Display *display, Colormap colormap,
XColor *colors_in_out, int ncolors);

ARGUMENTS

display
Spécifie la connexion au serveur X
colormap
Spécifie la table de couleurs
colors_in_out
Spécifie et retourne les valeurs effectivement utilisées dans la table de couleurs
ncolors
Spécifie le nombre d'éléments dans colors_in_out

DESCRIPTION

La fonction XcupStoreColors modifie les entrées de la table de couleurs des valeurs de pixels dans les membres `pixel` des structures XColor. Les entrées de la table de couleurs sont allouées comme si une fonction AllocColor avait été utilisée, c'est-à-dire que les couleurs sont en lecture seule (partageables). XcupStoreColors retourne le nombre de couleurs qui ont été allouées avec succès dans la table de couleurs.

Une erreur Value est générée si un pixel n'est pas un index valide dans la table de couleurs. Une erreur BadMatch est générée si la table de couleurs n'appartient pas à un visuel GrayScale, PseudoColor ou DirectColor.

Les applications qui allouent de nombreuses couleurs dans la table de couleurs par défaut d'un écran, par exemple un cube de couleurs ou une rampe de gris, devraient les allouer avec XCupStoreColors. En utilisant XCupStoreColors, les couleurs seront allouées de manière partageable (lecture seule) et toute autre application qui alloue la même couleur partagera cette cellule de couleur.
