XCopyArea(3)

Paquet: libx11

Licences: MIT AND X11

XCopyArea(3) FONCTIONS XLIB XCopyArea(3)

NOM

XCopyArea, XCopyPlane - copier des zones

SYNTAXE

int XCopyArea(Display *display, Drawable src, Drawable dest, GC gc, int src_x, int src_y, unsigned int width, unsigned int height, int dest_x, int dest_y);

int XCopyPlane(Display *display, Drawable src, Drawable dest, GC gc, int src_x, int src_y, unsigned int width, unsigned int height, int dest_x, int dest_y, unsigned long plane);

ARGUMENTS

dest_x

dest_y
Spécifiez les coordonnées x et y, relatives à l'origine du rectangle de destination et définissant son coin supérieur gauche.
display
Spécifie la connexion au serveur X.
gc
Spécifie le GC.
plane
Spécifie le plan de bits. Vous devez définir exactement un bit à 1.
src

dest
Spécifiez les rectangles source et destination à combiner.
src_x

src_y
Spécifiez les coordonnées x et y, relatives à l'origine du rectangle source et définissant son coin supérieur gauche.
width

height
Spécifiez la largeur et la hauteur, qui sont les dimensions des rectangles source et destination.

DESCRIPTION

La fonction XCopyArea combine le rectangle spécifié de la source avec le rectangle spécifié de la destination. Les objets dessinables doivent avoir la même racine et la même profondeur, sinon une erreur BadMatch se produit.

Si des régions du rectangle source sont obscurcies et n'ont pas été conservées dans le stockage de sauvegarde (backing store) ou si des régions extérieures aux limites de l'objet dessinable source sont spécifiées, ces régions ne sont pas copiées. Au lieu de cela, les actions suivantes se produisent sur toutes les régions de destination correspondantes qui sont soit visibles, soit conservées dans le stockage de sauvegarde. Si la destination est une fenêtre avec un arrière-plan différent de None, les régions correspondantes de la destination sont pavées avec cet arrière-plan (avec un masque de plan de tous les uns et la fonction GXcopy). Indépendamment du pavage ou que la destination soit une fenêtre ou une pixmap, si graphics-exposures est à True, alors des événements GraphicsExpose pour toutes les régions de destination correspondantes sont générés. Si graphics-exposures est à True mais qu'aucun événement GraphicsExpose n'est généré, un événement NoExpose est généré. Notez que par défaut, graphics-exposures est à True dans les nouveaux GC.

Cette fonction utilise les composants GC suivants : fonction, masque de plan, mode sous-fenêtre, graphics-exposures, clip-x-origin, clip-y-origin et masque de clip.

XCopyArea peut générer des erreurs BadDrawable, BadGC et BadMatch.

La fonction XCopyPlane utilise un seul plan de bits du rectangle source spécifié combiné avec le GC spécifié pour modifier le rectangle de destination spécifié. Les objets dessinables doivent avoir la même racine mais pas nécessairement la même profondeur. Si les objets dessinables n'ont pas la même racine, une erreur BadMatch se produit. Si le plan n'a pas exactement un bit défini à 1 et que la valeur du plan est inférieure à 2 n, où n est la profondeur de src, une erreur BadValue se produit.

Efficacement, XCopyPlane forme une pixmap de la même profondeur que le rectangle de destination et avec une taille spécifiée par la région source. Elle utilise les pixels de premier plan/arrière-plan dans le GC (premier plan partout où le plan de bits dans src contient un bit à 1, arrière-plan partout où le plan de bits dans src contient un bit à 0) et l'équivalent d'une requête de protocole CopyArea est effectuée avec toutes les mêmes sémantiques d'exposition. Cela peut également être considéré comme l'utilisation de la région spécifiée du plan de bits source comme un pochoir avec un style de remplissage de FillOpaqueStippled pour remplir une zone rectangulaire de la destination.

Cette fonction utilise les composants GC suivants : fonction, masque de plan, premier plan, arrière-plan, mode sous-fenêtre, graphics-exposures, clip-x-origin, clip-y-origin et masque de clip.

XCopyPlane peut générer des erreurs BadDrawable, BadGC, BadMatch et BadValue.

DIAGNOSTICS

BadDrawable
Une valeur pour un argument Drawable ne nomme pas une Fenêtre ou Pixmap définie.
BadGC
Une valeur pour un argument GContext ne nomme pas un GContext défini.
BadMatch
Une fenêtre InputOnly est utilisée comme Drawable.
BadMatch
Un argument ou une paire d'arguments a le bon type et la bonne plage, mais ne correspond pas d'une autre manière requise par la requête.
BadValue
Une valeur numérique est en dehors de la plage acceptée par la requête. Sauf si une plage spécifique est indiquée pour un argument, la plage complète définie par le type de l'argument est acceptée. Tout argument défini comme un ensemble d'alternatives peut générer cette erreur.
