XCreateGlyphCursor(3)

Paquet: libx11

Licences: MIT AND X11

XCreateFontCursor(3) FONCTIONS XLIB XCreateFontCursor(3)

NOM

XCreateFontCursor, XCreatePixmapCursor, XCreateGlyphCursor - créer des curseurs

SYNTAXE

#include <X11/cursorfont.h>

Cursor XCreateFontCursor(Display *display, unsigned int shape);

Cursor XCreatePixmapCursor(Display *display, Pixmap source, Pixmap mask, XColor *foreground_color, XColor *background_color, unsigned int x, unsigned int y);

Cursor XCreateGlyphCursor(Display *display, Font source_font, Font mask_font, unsigned int source_char, unsigned int mask_char, XColor _Xconst *foreground_color, XColor _Xconst *background_color);

ARGUMENTS

background_color
Spécifie les valeurs RVB pour l'arrière-plan de la source.
display
Spécifie la connexion au serveur X.
foreground_color
Spécifie les valeurs RVB pour l'avant-plan de la source.
mask
Spécifie les bits sources du curseur à afficher ou None.
mask_char
Spécifie le caractère de glyphe pour le masque.
mask_font
Spécifie la police pour le glyphe du masque ou None.
shape
Spécifie la forme du curseur.
source
Spécifie la forme du curseur source.
source_char
Spécifie le caractère glyphe pour la source.
source_font
Spécifie la police pour le glyphe source.
x

y
Spécifient les coordonnées x et y, qui indiquent le point sensible (hotspot) par rapport à l'origine de la source.

DESCRIPTION

X fournit un ensemble de formes de curseurs standard dans une police spéciale nommée cursor. Les applications sont encouragées à utiliser cette interface pour leurs curseurs car la police peut être personnalisée pour le type d'affichage individuel. La forme spécifiée indique quel glyphe des polices standard utiliser.

Le point sensible provient des informations stockées dans la police de curseurs. Les couleurs initiales d'un curseur sont un avant-plan noir et un arrière-plan blanc (voir XRecolorCursor).

XCreateFontCursor peut générer des erreurs BadAlloc et BadValue.

La fonction XCreatePixmapCursor crée un curseur et retourne l'identifiant du curseur qui lui est associé. Les valeurs RVB de l'avant-plan et de l'arrière-plan doivent être spécifiées en utilisant foreground_color et background_color, même si le serveur X n'a qu'un écran StaticGray ou GrayScale. La couleur de premier plan est utilisée pour les pixels définis à 1 dans la source, et la couleur d'arrière-plan est utilisée pour les pixels définis à 0. La source et le masque, s'ils sont spécifiés, doivent avoir une profondeur de un (sinon une erreur BadMatch survient) mais peuvent avoir n'importe quelle racine. L'argument mask définit la forme du curseur. Les pixels définis à 1 dans le masque déterminent quels pixels de la source sont affichés, et les pixels définis à 0 déterminent quels pixels sont ignorés. Si aucun masque n'est donné, tous les pixels de la source sont affichés. Le masque, s'il est présent, doit avoir la même taille que le pixmap défini par l'argument source, sinon une erreur BadMatch survient. Le point sensible doit être un point à l'intérieur de la source, sinon une erreur BadMatch survient.

Les composants du curseur peuvent être transformés arbitrairement pour répondre aux limitations d'affichage. Les pixmaps peuvent être libérées immédiatement s'il n'y a plus de références explicites à elles. Dessiner ultérieurement dans le pixmap source ou masque a un effet indéfini sur le curseur. Le serveur X peut ou non faire une copie du pixmap.

XCreatePixmapCursor peut générer des erreurs BadAlloc et BadPixmap.

La fonction XCreateGlyphCursor est similaire à XCreatePixmapCursor sauf que les bitmaps source et masque sont obtenus à partir des glyphes de police spécifiés. Le source_char doit être un glyphe défini dans source_font, sinon une erreur BadValue survient. Si mask_font est fourni, mask_char doit être un glyphe défini dans mask_font, sinon une erreur BadValue survient. mask_font et mask_char sont facultatifs. Les origines des glyphes source_char et mask_char (s'ils sont définis) sont positionnées de manière coïncidente et définissent le point sensible. Les source_char et mask_char n'ont pas besoin d'avoir les mêmes métriques de boîte englobante, et il n'y a aucune restriction sur le positionnement du point sensible par rapport aux boîtes englobantes. Si aucun mask_char n'est donné, tous les pixels de la source sont affichés. Vous pouvez libérer les polices immédiatement en appelant XFreeFont si aucune référence explicite supplémentaire ne doit y être faite.

Pour les polices matricielles à 2 octets, la valeur de 16 bits doit être formée avec le membre byte1 dans l'octet le plus significatif et le membre byte2 dans l'octet le moins significatif.

XCreateGlyphCursor peut générer des erreurs BadAlloc, BadFont, et BadValue.

DIAGNOSTICS

BadAlloc
Le serveur n'a pas réussi à allouer la ressource demandée ou la mémoire du serveur.
BadFont
Une valeur pour un argument de police ou GContext ne nomme pas une police définie.
BadMatch
Un argument ou une paire d'arguments a le type et la plage corrects mais ne correspond pas d'une autre manière requise par la requête.
BadPixmap
Une valeur pour un argument Pixmap ne nomme pas un Pixmap défini.
BadValue
Une valeur numérique sort de la plage de valeurs acceptées par la requête. Sauf si une plage spécifique est spécifiée pour un argument, la plage complète définie par le type de l'argument est acceptée. Tout argument défini comme un ensemble d'alternatives peut générer cette erreur.
