Paquet: libx11

Licences: MIT AND X11

XIfEvent(3) FONCTIONS XLIB XIfEvent(3)

NOM

XIfEvent, XCheckIfEvent, XPeekIfEvent - vérifier la file d'attente des événements avec une procédure de prédicat

SYNTAXE

int XIfEvent(Display *display, XEvent *event_return, Bool (*predicate)(), XPointer arg);

Bool XCheckIfEvent(Display *display, XEvent *event_return, Bool (*predicate)(), XPointer arg);

int XPeekIfEvent(Display *display, XEvent *event_return, Bool (*predicate)(), XPointer arg);

ARGUMENTS

arg
Spécifie l'argument fourni par l'utilisateur qui sera passé à la procédure de prédicat.
display
Spécifie la connexion au serveur X.
event_return
Retourne soit une copie de l'événement correspondant, soit sa structure associée.
predicate
Spécifie la procédure qui doit être appelée pour déterminer si l'événement suivant dans la file correspond à ce que vous recherchez.

DESCRIPTION

La fonction XIfEvent ne se termine que lorsque la procédure de prédicat spécifiée retourne True pour un événement, ce qui indique qu'un événement dans la file correspond. XIfEvent vide le tampon de sortie si elle bloque en attendant d'autres événements. XIfEvent supprime l'événement correspondant de la file et copie la structure dans la structure XEvent fournie par le client.

Lorsque la procédure de prédicat trouve une correspondance, XCheckIfEvent copie l'événement correspondant dans la structure XEvent fournie par le client et retourne True. (Cet événement est retiré de la file.) Si la procédure de prédicat ne trouve aucune correspondance, XCheckIfEvent retourne False, et le tampon de sortie aura été vidé. Tous les événements précédents stockés dans la file ne sont pas supprimés.

La fonction XPeekIfEvent ne retourne que lorsque la procédure de prédicat spécifiée retourne True pour un événement. Après que la procédure de prédicat ait trouvé une correspondance, XPeekIfEvent copie l'événement correspondant dans la structure XEvent fournie par le client sans retirer l'événement de la file. XPeekIfEvent vide le tampon de sortie si elle bloque en attendant d'autres événements.

Chacune de ces fonctions exige que vous fournissiez une procédure de prédicat qui détermine si un événement correspond à ce que vous recherchez. Votre procédure de prédicat doit décider si l'événement est utile sans appeler aucune fonction Xlib. Si le prédicat modifie directement ou indirectement l'état de la file d'attente des événements, le résultat n'est pas défini. Si Xlib a été initialisé pour les threads, le prédicat est appelé avec l'affichage verrouillé et le résultat d'un appel par le prédicat à toute fonction Xlib qui verrouille l'affichage n'est pas défini à moins que l'appelant n'ait d'abord appelé XLockDisplay.

La procédure de prédicat et ses arguments associés sont :

Bool (*predicate)(Display *display, XEvent *event, XPointer arg)

display
Spécifie la connexion au serveur X.
event
Spécifie la structure XEvent.
arg
Spécifie l'argument passé depuis la fonction XIfEvent, XCheckIfEvent ou XPeekIfEvent.

La procédure de prédicat est appelée une fois pour chaque événement dans la file jusqu'à ce qu'elle trouve une correspondance. Après avoir trouvé une correspondance, la procédure de prédicat doit retourner True. Si elle n'a pas trouvé de correspondance, elle doit retourner False.

Notez que la procédure de prédicat est appelée avec l'affichage verrouillé, et ne peut donc pas appeler de fonction qui prendrait à nouveau le verrou de l'affichage.
