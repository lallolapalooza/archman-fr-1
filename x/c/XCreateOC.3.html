XCreateOC(3)

Paquet: libx11

Licences: MIT AND X11

XCreateOC(3) FONCTIONS XLIB XCreateOC(3)

NOM

XCreateOC, XDestroyOC, XSetOCValues, XGetOCValues, XOMOfOC - créer des contextes de sortie

SYNTAXE

XOC XCreateOC(XOM om, ...);

void XDestroyOC(XOC oc);

char * XSetOCValues(XOC oc, ...);

char * XGetOCValues(XOC oc, ...);

XOM XOMOfOC(XOC oc);

ARGUMENTS

oc
Spécifie le contexte de sortie.
om
Spécifie la méthode de sortie.
...
Spécifie la liste d'arguments de longueur variable pour définir ou obtenir les valeurs XOC.

DESCRIPTION

La fonction XCreateOC crée un contexte de sortie au sein de la méthode de sortie spécifiée.

Le nom de la police de base est obligatoire au moment de la création, et le contexte de sortie ne sera pas créé s'il n'est pas fourni. Toutes les autres valeurs du contexte de sortie peuvent être définies ultérieurement.

XCreateOC renvoie NULL si aucun contexte de sortie n'a pu être créé. NULL peut être renvoyé pour l'une des raisons suivantes :

  • Un argument requis n'a pas été défini.
  • Un argument en lecture seule a été défini.
  • Un nom d'argument n'est pas reconnu.
  • La méthode de sortie a rencontré une erreur dépendante de l'implémentation de la méthode de sortie.

La fonction XDestroyOC détruit le contexte de sortie spécifié.

La fonction XSetOCValues renvoie NULL si aucune erreur ne s'est produite ; sinon, elle renvoie le nom du premier argument qui n'a pas pu être défini. Un argument pourrait ne pas être défini pour l'une des raisons suivantes :

  • L'argument est en lecture seule.
  • Le nom de l'argument n'est pas reconnu.
  • Une erreur dépendante de l'implémentation se produit.

Chaque valeur à définir doit être une donnée appropriée, correspondant au type de données imposé par la sémantique de l'argument.

La fonction XGetOCValues renvoie NULL si aucune erreur ne s'est produite ; sinon, elle renvoie le nom du premier argument qui n'a pas pu être obtenu. Un argument pourrait ne pas être obtenu pour l'une des raisons suivantes :

  • Le nom de l'argument n'est pas reconnu.
  • Une erreur dépendante de l'implémentation se produit.

Chaque valeur d'argument suivant un nom doit pointer vers un emplacement où la valeur doit être stockée.

La fonction XOMOfOC renvoie la méthode de sortie associée au contexte de sortie spécifié.
