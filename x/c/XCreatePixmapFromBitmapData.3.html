XReadBitmapFile(3) FONCTIONS XLIB XReadBitmapFile(3)

NOM

XReadBitmapFile, XReadBitmapFileData, XWriteBitmapFile, XCreatePixmapFromBitmapData, XCreateBitmapFromData - manipuler des bitmaps

SYNTAXE

int XReadBitmapFile(Display *display, Drawable d, _Xconst char *filename, unsigned int *width_return, unsigned int *height_return, Pixmap *bitmap_return, int *x_hot_return, int *y_hot_return);

int XReadBitmapFileData(_Xconst char *filename, unsigned int *width_return, unsigned int *height_return, unsigned char **data_return, int *x_hot_return, int *y_hot_return);

int XWriteBitmapFile(Display *display, _Xconst char *filename, Pixmap bitmap, unsigned int width, unsigned int height, int x_hot, int y_hot);

Pixmap XCreatePixmapFromBitmapData(Display *display, Drawable d, char *data, unsigned int width, unsigned int height, unsigned long fg, unsigned long bg, unsigned int depth);

Pixmap XCreateBitmapFromData(Display *display, Drawable d, _Xconst char *data, unsigned int width, unsigned int height);

ARGUMENTS

bitmap
Spécifie la bitmap.
bitmap_return
Retourne la bitmap qui est créée.
d
Spécifie le drawable qui indique l'écran.
data
Spécifie les données au format bitmap.
data
Spécifie l'emplacement des données de la bitmap.
data_return
Retourne les données de la bitmap.
depth
Spécifie la profondeur de la pixmap.
display
Spécifie la connexion au serveur X.
fg

bg
Spécifie les valeurs de pixel de premier plan et d'arrière-plan à utiliser.
filename
Spécifie le nom du fichier à utiliser. Le format du nom de fichier dépend du système d'exploitation.
width

height
Spécifie la largeur et la hauteur.
width_return

height_return
Retourne les valeurs de largeur et de hauteur du fichier bitmap lu.
x_hot

y_hot
Spécifie où placer les coordonnées du point chaud (ou -1,-1 s'il n'y en a pas) dans le fichier.
x_hot_return

y_hot_return
Retourne les coordonnées du point chaud.

DESCRIPTION

La fonction XReadBitmapFile lit un fichier contenant une bitmap. Le fichier est analysé dans le codage de la locale actuelle. La capacité de lire autre chose que le format standard dépend de l'implémentation. Si le fichier ne peut pas être ouvert, XReadBitmapFile retourne BitmapOpenFailed. Si le fichier peut être ouvert mais ne contient pas de données bitmap valides, il retourne BitmapFileInvalid. Si un espace de travail insuffisant est alloué, il retourne BitmapNoMemory. Si le fichier est lisible et valide, il retourne BitmapSuccess.

XReadBitmapFile retourne la hauteur et la largeur de la bitmap, telles que lues dans le fichier, à width_return et height_return. Il crée ensuite une pixmap de la taille appropriée, lit les données bitmap du fichier dans la pixmap, et assigne la pixmap à la variable bitmap de l'appelant. L'appelant doit libérer la pixmap à l'aide de XFreePixmap une fois terminé. Si nom_x_hot et nom_y_hot existent, XReadBitmapFile les retourne à x_hot_return et y_hot_return ; sinon, il retourne -1,-1.

XReadBitmapFile peut générer des erreurs BadAlloc et BadDrawable.

La fonction XReadBitmapFileData lit un fichier contenant une bitmap, de la même manière que XReadBitmapFile, mais retourne les données directement plutôt que de créer une pixmap dans le serveur. Les données de la bitmap sont retournées dans data_return ; le client doit libérer cet espace lorsqu'il a terminé en appelant XFree. Le statut et les autres valeurs de retour sont les mêmes que pour XReadBitmapFile.

La fonction XWriteBitmapFile écrit une bitmap dans un fichier au format X version 11. Le nom utilisé dans le fichier de sortie est dérivé du nom de fichier en supprimant le préfixe du répertoire. Le fichier est écrit dans le codage de la locale actuelle. Si le fichier ne peut pas être ouvert en écriture, elle retourne BitmapOpenFailed. Si une mémoire insuffisante est allouée, XWriteBitmapFile retourne BitmapNoMemory ; sinon, en l'absence d'erreur, elle retourne BitmapSuccess. Si x_hot et y_hot ne sont pas -1, -1, XWriteBitmapFile les écrit comme coordonnées du point chaud pour la bitmap.

XWriteBitmapFile peut générer des erreurs BadDrawable et BadMatch.

La fonction XCreatePixmapFromBitmapData crée une pixmap de la profondeur donnée, puis effectue un XPutImage au format bitmap des données dans celle-ci. La profondeur doit être supportée par l'écran du drawable spécifié, sinon une erreur BadMatch résulte.

XCreatePixmapFromBitmapData peut générer des erreurs BadAlloc et BadMatch.

La fonction XCreateBitmapFromData vous permet d'inclure dans votre programme C (en utilisant #include) un fichier bitmap qui a été écrit par XWriteBitmapFile (format X version 11 uniquement) sans lire le fichier bitmap. L'exemple suivant crée une bitmap grise :

#include "gray.bitmap"

Pixmap bitmap;
bitmap = XCreateBitmapFromData(display, window, gray_bits, gray_width, gray_height);

Si un espace de travail insuffisant a été alloué, XCreateBitmapFromData retourne None. Il est de votre responsabilité de libérer la pixmap en utilisant XFreePixmap une fois terminé.

XCreateBitmapFromData peut générer une erreur BadAlloc.

DIAGNOSTICS

BadAlloc
Le serveur n'a pas réussi à allouer la ressource demandée ou la mémoire du serveur.
BadDrawable
Une valeur pour un argument Drawable ne nomme pas une Fenêtre ou une Pixmap définie.
BadMatch
Une fenêtre InputOnly est utilisée comme Drawable.

VOIR AUSSI

XCreatePixmap(3), XPutImage(3)

NOM

XCreatePixmapFromBitmapData - crée une pixmap à partir de données de bitmap

SYNTAXE

Pixmap XCreatePixmapFromBitmapData(
    Display *display,
    Drawable drawable,
    _Xconst unsigned char *data,
    unsigned int width,
    unsigned int height,
    unsigned int depth,
    Pixel foreground,
    Pixel background
);

ARGUMENTS

  • display : Spécifie la connexion au serveur X.
  • drawable : Spécifie le drawable (fenêtre ou pixmap) utilisé pour déterminer la profondeur et le contexte du serveur.
  • data : Spécifie les données du bitmap. Les données sont interprétées comme une série d'octets représentant les bits du bitmap, ligne par ligne.
  • width : Spécifie la largeur du bitmap en pixels.
  • height : Spécifie la hauteur du bitmap en pixels.
  • depth : Spécifie la profondeur de la pixmap créée. Elle doit être égale à la profondeur du drawable.
  • foreground : Spécifie la couleur du premier plan (les bits à 1) en pixels.
  • background : Spécifie la couleur de l'arrière-plan (les bits à 0) en pixels.

DESCRIPTION

La fonction XCreatePixmapFromBitmapData crée une nouvelle pixmap sur le serveur X à partir des données de bitmap fournies. La pixmap créée aura la largeur, la hauteur et la profondeur spécifiées.

Les données du bitmap sont fournies sous forme d'un tableau d'octets. Chaque octet représente 8 pixels dans le sens horizontal. Les bits à 1 dans les données seront dessinés avec la couleur foreground et les bits à 0 avec la couleur background.

La depth de la pixmap créée doit correspondre à la profondeur du drawable spécifié. Le drawable est utilisé pour déterminer le contexte du serveur X et la profondeur appropriée pour la nouvelle pixmap.

Si la création de la pixmap réussit, un identifiant de pixmap est retourné. Sinon, None est retourné.

DIAGNOSTICS

En cas d'échec de la création de la pixmap (par exemple, si les dimensions sont invalides ou si la mémoire du serveur est insuffisante), XCreatePixmapFromBitmapData retourne None.

VOIR AUSSI

XCreatePixmap(3), XCreateBitmapFromData(3)
