NOM

Xcursor - Bibliothèque de gestion des curseurs

SYNTAXE

#include <X11/Xcursor/Xcursor.h>

DESCRIPTION

Xcursor est une bibliothèque simple conçue pour aider à localiser et charger les curseurs. Les curseurs peuvent être chargés à partir de fichiers ou de la mémoire. Une bibliothèque de curseurs courants existe, qui correspond aux noms de curseurs X standards. Les curseurs peuvent exister en plusieurs tailles et la bibliothèque choisit automatiquement la meilleure taille.

APERÇU FONCTIONNEL

Xcursor est construit en plusieurs couches ; à la couche inférieure se trouve le code qui peut charger les images de curseur à partir de fichiers. Au-dessus se trouve une couche qui localise les fichiers de curseur en fonction du chemin de la bibliothèque et du thème. Au sommet se trouve une couche qui construit les curseurs à partir d'une image chargée depuis un fichier ou d'un des curseurs X standards. Lors de l'utilisation d'images chargées à partir de fichiers, Xcursor préfère utiliser la requête de création de curseur de l'extension Render si elle est prise en charge par le serveur X. Là où elle n'est pas prise en charge, Xcursor mappe l'image du curseur à un curseur X standard et utilise la requête de création de curseur principale.

FICHIERS DE CURSEUR

Xcursor définit un nouveau format pour les curseurs sur disque. Chaque fichier contient une ou plusieurs images de curseur. Chaque image de curseur est étiquetée avec une taille nominale afin que la meilleure taille puisse être sélectionnée automatiquement. Plusieurs curseurs de la même taille nominale peuvent être chargés ensemble ; les applications sont censées les utiliser comme une séquence animée.

Les fichiers de curseur sont stockés sous forme d'en-tête contenant une table des matières suivie d'une séquence de blocs. La table des matières indique le type, le sous-type et la position dans le fichier de chaque bloc. L'en-tête du fichier ressemble à ceci :


magie:	CARD32 "Xcur" (0x58, 0x63, 0x75, 0x72)
en-tête:	CARD32 octets dans cet en-tête
version:	CARD32 numéro de version du fichier
ntoc:	CARD32 nombre d'entrées de la table des matières
toc:	LISTofTOC table des matières

Chaque entrée de la table des matières ressemble à ceci :


type:	CARD32 type d'entrée
sous-type:	CARD32 étiquette spécifique au type - taille pour les images
position:	CARD32 position absolue en octets de la table dans le fichier

Chaque bloc dans le fichier a un ensemble de champs d'en-tête communs suivis de champs supplémentaires spécifiques au type :


en-tête:	CARD32 octets dans l'en-tête du bloc (y compris les champs spécifiques au type)
type:	CARD32 doit correspondre au type dans la table des matières pour ce bloc
sous-type:	CARD32 doit correspondre au sous-type dans la table des matières pour ce bloc
version:	CARD32 numéro de version pour ce type de bloc

Il existe actuellement deux types de blocs définis pour les fichiers de curseurs ; commentaires et images. Les commentaires ressemblent à ceci :


en-tête:	20 Les en-têtes de commentaires font 20 octets
type:	0xfffe0001 Le type de commentaire est 0xfffe0001
sous-type:	{ 1 (COPYRIGHT), 2 (LICENSE), 3 (OTHER) }
version:	1
longueur:	CARD32 longueur en octets de la chaîne UTF-8
chaîne:	LISTofCARD8 chaîne UTF-8

Les images ressemblent à ceci :


en-tête:	36 Les en-têtes d'image font 36 octets
type:	0xfffd0002 Le type d'image est 0xfffd0002
sous-type:	CARD32 Le sous-type d'image est la taille nominale
version:	1
largeur:	CARD32 Doit être inférieur ou égal à 0x7fff
hauteur:	CARD32 Doit être inférieur ou égal à 0x7fff
xhot:	CARD32 Doit être inférieur ou égal à la largeur
yhot:	CARD32 Doit être inférieur ou égal à la hauteur
délai:	CARD32 Délai entre les images d'animation en millisecondes
pixels:	LISTofCARD32 Pixels au format ARGB compacté

THÈMES

Xcursor suit (en grande partie) la spécification freedesktop.org pour les thèmes d'icônes. Le chemin de recherche par défaut qu'il utilise est

~/.local/share/icons, ~/.icons, /usr/share/icons, /usr/share/pixmaps

Dans chacun de ces répertoires, il recherche un répertoire utilisant le nom du thème :

•
Dans le répertoire du thème, il recherche des fichiers de curseur dans le sous-répertoire “cursors”.
Xcursor recherche un fichier spécifique, qui doit être l'un des noms de forme du curseur, tel qu'utilisé dans XcursorLibraryLoadImage ou XcursorLibraryShape.
•
S'il ne trouve aucun fichier de curseur correspondant dans le sous-répertoire “cursors”, Xcursor recherche ensuite un fichier “index.theme” dans chaque répertoire de thème pour rechercher les thèmes hérités. Ce sont des lignes dans ce format :
Hérite = nom-du-thème

Xcursor utilise le premier nom-du-thème hérité, en ignorant les autres qui peuvent exister dans un fichier “index.theme” donné. S'il trouve un thème hérité, Xcursor recherche également le long du chemin pour l'utiliser. Xcursor ignore les autres clés dans le fichier “index.theme”, y compris “Name” (c'est-à-dire le nom qu'une application graphique peut utiliser comme nom de présentation).

Plusieurs nom-du-thème peuvent être listés sur la ligne Hérite=. La spécification freedesktop.org stipule que les éléments de liste sont séparés par des virgules. Xcursor accepte également le point-virgule, mais traduit les deux en deux-points lors de la recherche dans le chemin. Xcursor attend une seule ligne Hérite= ; la spécification freedesktop.org ne précise pas si plusieurs clés sont autorisées.

Si aucun thème n'est défini, ou si aucun curseur n'est trouvé pour le thème spécifié quelque part dans le chemin, Xcursor vérifie le thème “par défaut”.

Lorsque Xcursor trouve un fichier de curseur, il arrête de chercher. Il utilise toujours le premier fichier de curseur trouvé lors de la recherche le long du chemin.

TYPES DE DONNÉES

XcursorImage
contient une seule image de curseur en mémoire. Chaque pixel du curseur est une valeur de 32 bits contenant ARGB avec A dans l'octet de poids fort. 


typedef struct _XcursorImage {
    XcursorDim 	 taille; 	/* taille nominale pour la correspondance */
    XcursorDim 	 largeur; 	/* largeur réelle */
    XcursorDim 	 hauteur; 	/* hauteur réelle */
    XcursorDim 	 xhot; 	/* point chaud x (doit être à l'intérieur de l'image) */
    XcursorDim 	 yhot; 	/* point chaud y (doit être à l'intérieur de l'image) */
    XcursorPixel 	*pixels; 	/* pointeur vers les pixels */
} XcursorImage;
XcursorImages
contient plusieurs structures XcursorImage. Elles sont toutes libérées lorsque XcursorImages est libéré dans XcursorImagesDestroy. 


typedef struct _XcursorImages {
    int 	 nimage; 	/* nombre d'images */
    XcursorImage 	**images; 	/* tableau de pointeurs XcursorImage */
} XcursorImages;
XcursorCursors
Contient plusieurs objets Cursor. Ils sont tous libérés lorsque XcursorCursors est libéré. Ils sont comptés par référence de sorte que plusieurs structures XcursorAnimate puissent utiliser le même XcursorCursors. 


typedef struct _XcursorCursors {
    Display 	*dpy; 	/* Affichage contenant les curseurs */
    int 	 ref; 	/* compteur de références */
    int 	 ncursor; 	/* nombre de curseurs */
    Cursor 	*cursors; 	/* tableau de curseurs */
} XcursorCursors;
XcursorAnimate
Référence un ensemble de curseurs et une séquence dans cet ensemble. Plusieurs structures XcursorAnimate peuvent référencer le même XcursorCursors ; chacune détient une référence qui est supprimée lorsque XcursorAnimate est libéré. 


typedef struct _XcursorAnimate {
    XcursorCursors 	*cursors; 	/* liste des curseurs à utiliser */
    int 	 sequence; 	/* quel curseur est le suivant */
} XcursorAnimate;

Ces fonctions recherchent dans le chemin de la bibliothèque, en chargeant le premier fichier trouvé de la taille souhaitée, en utilisant une fonction privée (XcursorScanTheme) pour trouver le thème approprié :

  • Si theme n'est pas NULL, utilisez-le.
  • Si theme est NULL, ou s'il n'y a pas eu de correspondance pour le thème souhaité, utilisez "default" comme nom de thème.
  • Si aucune des recherches ne réussit, ces fonctions renvoient NULL.
Les deux fonctions diffèrent par plus que le nombre d'images chargées :
  • XcursorLibraryLoadImage appelle XcursorFileLoadImage mais
  • XcursorLibraryLoadImages appelle XcursorFileLoadImages, et (en cas de succès) appelle XcursorImagesSetName pour associer name au résultat.

NAME


Xcursor — cursor loading library






SYNOPSIS


#include <X11/Xcursor.h>







DESCRIPTION


The Xcursor library provides APIs to load cursors for X11 applications.
    It abstracts the details of cursor theming, animated cursors, and automatic
    resizing. It is intended to be used by applications that want to support
    customizable cursors beyond the basic X core cursors.

ENVIRONMENT


Environment variables can be used to override resource settings,
    which in turn override compiled-in default values.


Some of the environment variables recognized by Xcursor are
    booleans, specified as follows:





  
true for
    “t”, “1”, “y” or
    “on”

  

  
false for
    “f”, “0”, “n” or
    “off”

  






Xcursor ignores other values for these booleans.



  
HOME

  
Xcursor interprets “~” in the search list as the home
      directory, using this variable rather than the password database.

  
XCURSOR_ANIM

  
If the display supports the Render CreateCursor request, and the Render
      feature is enabled, disable animated cursors if the environment
      variable is false.





  

  
If the environment variable is not given, Xcursor uses the resource
      Xcursor.anim.





  
XCURSOR_CORE

  
If the display supports the Render CreateCursor request disable the Render
      feature if the environment variable is false.





  

  
If the environment variable is not given, Xcursor uses the resource
      Xcursor.core.





  
XCURSOR_DISCOVER

  
If the variable is set, Xcursor turns on a logging feature. It displays
      the hash value and the image so that users can see which cursor name is
      associated with each image.





  

  
There is no corresponding resource setting.





  
XCURSOR_DITHER

  
This variable sets the desired dither.





  

  
If the environment variable is not given, Xcursor uses the resource
      Xcursor.dither.

  

  
If neither environment variable or resource is found, Xcursor uses
      “threshold”

  

  
These are the recognized values:







  
diffuse

  

  
median

  

  
ordered

  

  
threshold

  







  
XCURSOR_PATH

  
This variable sets the list of paths in which to search for cursors,
      rather than the compiled-in default list.





  

  
Directories in this path are separated by colons (:).





  
XCURSOR_RESIZED

  
Enables automatic resizing of cursors to improve their displayed size if
      the environment variable is true.





  

  
If the environment variable is not given, Xcursor tries the
      Xcursor.resized resource.





  
XCURSOR_SIZE

  
This variable sets the desired cursor size, in pixels.





  

  
If the environment variable is not given, Xcursor tries the
      Xcursor.size resource.

  

  
If no size is given, whether by environment variable or resource setting,
      Xcursor next tries the Xft.dpi resource setting to guess the size
      of a 16-point cursor.

  

  
Finally, if Xft.dpi is not set, Xcursor uses the display height,
      dividing by 48 (assuming that the height is 768).





  
XCURSOR_THEME

  
This variable selects the desired theme.





  

  
If the environment variable is not given, Xcursor tries the
      Xcursor.theme resource.

  

  
If neither environment variable or resource is found, Xcursor uses the
      default theme.

NAME

    
XcursorGetTheme, XcursorGetThemeName, XcursorGetThemeCore - obtenir le nom du curseur de thème





    
SYNOPSIS

    
#include <Xcursor/Xcursor.h>

const XcursorTheme *
XcursorGetTheme (Display *display);

const char *
XcursorGetThemeName (Display *display);

int
XcursorGetThemeCore (Display *display);
    





    
DESCRIPTION

    
Ces fonctions obtiennent des informations sur le thème du curseur actuellement actif.

    
XcursorGetTheme renvoie une structure XcursorTheme qui décrit le thème du curseur, y compris son nom, son répertoire et sa taille. Si aucun thème n'est actif, elle renvoie NULL.

    
XcursorGetThemeName renvoie le nom du thème du curseur actif sous forme de chaîne de caractères. Si aucun thème n'est actif, elle renvoie NULL.

    
XcursorGetThemeCore renvoie un entier qui indique si les curseurs de base du système sont activés ou désactivés. La valeur 1 indique qu'ils sont activés, 0 indique qu'ils sont désactivés.





    
FUNCTIONAL OVERVIEW

    

        

        
L'ordre de recherche des thèmes de curseurs est le suivant :

        

        
1. La variable d'environnement XCURSOR_THEME.

        

        
2. La ressource X Xcursor.theme.

        

        
3. Le thème par défaut du système (généralement fourni par le gestionnaire de fenêtres).

    

    

        

        
Si XCURSOR_THEME est défini, il est utilisé comme nom de thème.

        

        
Sinon, si Xcursor.theme est défini, il est utilisé comme nom de thème.

        

        
Sinon, le thème par défaut du système est utilisé.

    

    

        

        
L'ordre de recherche des tailles de curseurs est le suivant :

        

        
1. La variable d'environnement XCURSOR_SIZE.

        

        
2. La ressource X Xcursor.size.

        

        
3. La taille par défaut du système (généralement 24).

    

    

        

        
Si XCURSOR_SIZE est défini, il est utilisé comme taille du thème.

        

        
Sinon, si Xcursor.size est défini, il est utilisé comme taille du thème.

        

        
Sinon, la taille par défaut du système est utilisée.

    





    
DATATYPES

    

        

        
XcursorTheme structure :

    

    
typedef struct {
    char *name;
    char *directories;
    int size;
    int scaled;
} XcursorTheme;
    

    

        
name

        
Le nom du thème.

        
directories

        
Une liste des répertoires où chercher les curseurs.

        
size

        
La taille des curseurs dans ce thème.

        
scaled

        
Indique si les curseurs sont mis à l'échelle.

ENVIRONMENT

    

        

        
XCURSOR_THEME : Définit le nom du thème du curseur actif.

        

        
XCURSOR_SIZE : Définit la taille des curseurs du thème actif.

    

    

        

        
Si la variable d'environnement XCURSOR_THEME_CORE est définie sur true, les thèmes pour les curseurs de base sont activés.
