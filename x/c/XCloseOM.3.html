XOpenOM(3) FONCTIONS XLIB XOpenOM(3)

NOM

XOpenOM, XCloseOM, XSetOMValues, XGetOMValues, XDisplayOfOM, XLocaleOfOM - ouvrir des méthodes de sortie

SYNTAXE

XOM XOpenOM(Display *display, XrmDatabase db, char *res_name, char *res_class);

Status XCloseOM(XOM om);

char *XSetOMValues(XOM om, ...);

char *XGetOMValues(XOM om, ...);

Display *XDisplayOfOM(XOM om);

char *XLocaleOfOM(XOM om);

ARGUMENTS

display
Spécifie la connexion au serveur X.
db
Spécifie un pointeur vers la base de données des ressources.
res_name
Spécifie le nom complet de la ressource de l'application.
res_class
Spécifie le nom complet de la classe de l'application.
om
Spécifie la méthode de sortie.
...
Spécifie la liste d'arguments de longueur variable pour définir ou obtenir les valeurs XOM.

DESCRIPTION

La fonction XOpenOM ouvre une méthode de sortie correspondant à la locale et aux spécifications des modificateurs actuels. La locale et les modificateurs actuels sont liés à la méthode de sortie lorsque XOpenOM est appelée. La locale associée à une méthode de sortie ne peut pas être modifiée.

La méthode de sortie spécifique à laquelle cet appel sera routé est identifiée sur la base de la locale et des modificateurs actuels. XOpenOM identifiera une méthode de sortie par défaut correspondant à la locale actuelle. Ce défaut peut être modifié en utilisant XSetLocaleModifiers pour définir le modificateur de méthode de sortie.

L'argument db est la base de données des ressources à utiliser par la méthode de sortie pour rechercher les ressources privées à la méthode de sortie. Il n'est pas prévu que cette base de données soit utilisée pour rechercher des valeurs qui peuvent être définies comme valeurs OC dans un contexte de sortie. Si db est NULL, aucune base de données n'est transmise à la méthode de sortie.

Les arguments res_name et res_class spécifient le nom et la classe de la ressource de l'application. Ils sont destinés à être utilisés comme préfixes par la méthode de sortie lors de la recherche de ressources communes à tous les contextes de sortie qui peuvent être créés pour cette méthode de sortie. Les caractères utilisés pour les noms et classes de ressources doivent être dans le jeu de caractères portable X. Les ressources recherchées ne sont pas entièrement spécifiées si res_name ou res_class est NULL.

Les arguments res_name et res_class ne sont pas supposés exister au-delà de l'appel à XOpenOM. La base de données des ressources spécifiée est supposée exister pendant toute la durée de vie de la méthode de sortie.

XOpenOM retourne NULL si aucune méthode de sortie n'a pu être ouverte.

La fonction XCloseOM ferme la méthode de sortie spécifiée.

La fonction XSetOMValues présente une interface de programmation à liste d'arguments variable pour définir les propriétés ou les fonctionnalités de la méthode de sortie spécifiée. Cette fonction retourne NULL si elle réussit ; sinon, elle retourne le nom du premier argument qui n'a pas pu être défini. Xlib ne tente pas de définir les arguments de la liste fournie qui suivent l'argument échoué ; tous les arguments de la liste précédant l'argument échoué ont été définis correctement.

Aucun argument standard n'est actuellement défini par Xlib.

La fonction XGetOMValues présente une interface de programmation à liste d'arguments variable pour interroger les propriétés ou les fonctionnalités de la méthode de sortie spécifiée. Cette fonction retourne NULL si elle réussit ; sinon, elle retourne le nom du premier argument qui n'a pas pu être obtenu.

La fonction XDisplayOfOM retourne l'affichage associé à la méthode de sortie spécifiée.

La fonction XLocaleOfOM retourne la locale associée à la méthode de sortie spécifiée.
