XCreateWindowEvent(3) FONCTIONS XLIB XCreateWindowEvent(3)

NOM

XCreateWindowEvent - structure d'événement CreateNotify

STRUCTURES

La structure pour les événements CreateNotify contient :

typedef struct {
        int type;       /* CreateNotify */
        unsigned long serial;   /* # de la dernière requête traitée par le serveur */
        Bool send_event;        /* true si cela provient d'une requête SendEvent */
        Display *display;       /* Affichage à partir duquel l'événement a été lu */
        Window parent;  /* parent de la fenêtre */
        Window window;  /* id de la fenêtre créée */
        int x, y;       /* position de la fenêtre */
        int width, height;      /* taille de la fenêtre */
        int border_width;       /* largeur de la bordure */
        Bool override_redirect; /* la création doit être ignorée */
} XCreateWindowEvent;

Lorsque vous recevez cet événement, les membres de la structure sont définis comme suit.

Le membre type est défini sur le nom de la constante du type d'événement qui l'identifie de manière unique. Par exemple, lorsque le serveur X signale un événement GraphicsExpose à une application cliente, il envoie une structure XGraphicsExposeEvent avec le membre type défini sur GraphicsExpose. Le membre display est défini sur un pointeur vers l'affichage sur lequel l'événement a été lu. Le membre send_event est défini sur True si l'événement provient d'une requête de protocole SendEvent. Le membre serial est défini à partir du numéro de série rapporté dans le protocole, mais développé à partir des 16 bits les moins significatifs en une valeur complète de 32 bits. Le membre window est défini sur la fenêtre qui est la plus utile aux répartiteurs d'outils.

Le membre parent est défini sur le parent de la fenêtre créée. Le membre window spécifie la fenêtre créée. Les membres x et y sont définis sur les coordonnées de la fenêtre créée par rapport à l'origine de la fenêtre parente et indiquent la position du coin extérieur supérieur gauche de la fenêtre créée. Les membres width et height sont définis sur la taille interne de la fenêtre créée (sans inclure la bordure) et sont toujours différents de zéro. Le membre border_width est défini sur la largeur de la bordure de la fenêtre créée, en pixels. Le membre override_redirect est défini sur l'attribut override-redirect de la fenêtre. Les clients de gestionnaire de fenêtres devraient normalement ignorer cette fenêtre si le membre override_redirect est True.
