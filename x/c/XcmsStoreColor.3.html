Paquet: libx11

XcmsStoreColor(3) FONCTIONS XLIB XcmsStoreColor(3)

NOM

XcmsStoreColor, XcmsStoreColors - définir les couleurs

SYNTAXE

Status XcmsStoreColor(Display *display, Colormap colormap, XcmsColor *color);

Status XcmsStoreColors(Display *display, Colormap colormap, XcmsColor *colors, unsigned ncolors, Bool *compression_flags_return);

ARGUMENTS

display
Spécifie la connexion au serveur X.
color
Spécifie la cellule de couleur et la couleur à enregistrer. Les valeurs spécifiées dans cette structure XcmsColor restent inchangées au retour.
colors
Spécifie le tableau de structures XcmsColor de spécification de couleur, chacune spécifiant une cellule de couleur et la couleur à enregistrer dans cette cellule. Les valeurs spécifiées dans le tableau restent inchangées au retour.
colormap
Spécifie la palette de couleurs.
compression_flags_return
Retourne un tableau de valeurs booléennes indiquant l'état de la compression. Si un pointeur non NULL est fourni, chaque élément du tableau est défini sur True si la couleur correspondante a été compressée et False sinon. Passez NULL si l'état de la compression n'est pas utile.
ncolors
Spécifie le nombre de structures XcmsColor dans le tableau de spécification de couleurs.

DESCRIPTION

La fonction XcmsStoreColor convertit la couleur spécifiée dans la structure XcmsColor en valeurs RVB. Elle utilise ensuite cette spécification RVB dans une structure XColor, dont les trois indicateurs (DoRed, DoGreen et DoBlue) sont définis, dans un appel à XStoreColor pour modifier la cellule de couleur spécifiée par le membre pixel de la structure XcmsColor. La valeur de ce pixel doit être un index valide pour la palette de couleurs spécifiée, et la cellule de couleur spécifiée par la valeur du pixel doit être une cellule en lecture/écriture. Si la valeur du pixel n'est pas un index valide, une erreur BadValue se produit. Si la cellule de couleur est non allouée ou est allouée en lecture seule, une erreur BadAccess se produit. Si la palette de couleurs est une carte installée pour son écran, les modifications sont immédiatement visibles.

Notez que XStoreColor n'a pas de valeur de retour ; par conséquent, une valeur de retour XcmsSuccess pour cette fonction indique que la conversion en RVB a réussi et que l'appel à XStoreColor a été effectué. Pour obtenir la couleur réellement enregistrée, utilisez XcmsQueryColor. En raison des limitations matérielles de l'écran ou de la compression de la gamme, la couleur enregistrée dans la palette de couleurs peut ne pas être identique à la couleur spécifiée.

XcmsStoreColor peut générer des erreurs BadAccess, BadColor et BadValue.

La fonction XcmsStoreColors convertit les couleurs spécifiées dans le tableau de structures XcmsColor en valeurs RVB, puis utilise ces spécifications RVB dans des structures XColor, dont les trois indicateurs (DoRed, DoGreen et DoBlue) sont définis, dans un appel à XStoreColors pour modifier les cellules de couleur spécifiées par le membre pixel de la structure XcmsColor correspondante. Chaque valeur de pixel doit être un index valide pour la palette de couleurs spécifiée, et la cellule de couleur spécifiée par chaque valeur de pixel doit être une cellule en lecture/écriture. Si une valeur de pixel n'est pas un index valide, une erreur BadValue se produit. Si une cellule de couleur est non allouée ou est allouée en lecture seule, une erreur BadAccess se produit. S'il y a plusieurs pixels en erreur, celui qui est signalé est arbitraire. Si la palette de couleurs est une carte installée pour son écran, les modifications sont immédiatement visibles.

Notez que XStoreColors n'a pas de valeur de retour ; par conséquent, une valeur de retour XcmsSuccess pour cette fonction indique que les conversions en RVB ont réussi et que l'appel à XStoreColors a été effectué. Pour obtenir les couleurs réellement enregistrées, utilisez XcmsQueryColors. En raison des limitations matérielles de l'écran ou de la compression de la gamme, les couleurs enregistrées dans la palette de couleurs peuvent ne pas être identiques aux couleurs spécifiées.

XcmsStoreColors peut générer des erreurs BadAccess, BadColor et BadValue.

DIAGNOSTICS

BadAccess
Un client a tenté de libérer une entrée de palette de couleurs qu'il n'avait pas précédemment allouée.
BadAccess
Un client a tenté d'écrire dans une entrée de palette de couleurs en lecture seule.
BadColor
Une valeur pour un argument Colormap ne nomme pas une Colormap définie.
BadValue
Une valeur numérique se situe en dehors de la plage de valeurs acceptées par la requête. Sauf si une plage spécifique est spécifiée pour un argument, la plage complète définie par le type de l'argument est acceptée. Tout argument défini comme un ensemble d'alternatives peut générer cette erreur.
