NOM

Compose - Mappages client X pour les séquences d'entrée multi-clés

DESCRIPTION

La bibliothèque X, libX11, fournit une méthode d'entrée simple pour les caractères au-delà de ceux représentés sur les claviers typiques, en utilisant des séquences de frappes qui sont combinées pour entrer un seul caractère.

Le fichier compose est recherché dans l'ordre suivant :

-
Si la variable d'environnement $XCOMPOSEFILE est définie, sa valeur est utilisée comme nom du fichier Compose.
-
Si le répertoire personnel de l'utilisateur contient un fichier nommé .XCompose, celui-ci est utilisé comme fichier Compose.
-
Le fichier compose fourni par le système est utilisé en mappant la locale à un fichier compose à partir de la liste dans /usr/share/X11/locale/compose.dir.

Les fichiers Compose peuvent utiliser une instruction "include". Cela permet de faire des modifications locales aux fichiers compose existants sans inclure tout le contenu directement. Par exemple, le fichier compose iso8859-1 du système peut être inclus avec une ligne comme celle-ci :

include "%S/iso8859-1/Compose"

Plusieurs substitutions peuvent être effectuées dans le nom de fichier de l'instruction include :

%H
se développe en répertoire personnel de l'utilisateur (la variable d'environnement $HOME)
%L
se développe en nom du fichier Compose spécifique à la locale (c'est-à-dire "/usr/share/X11/locale/<nomdelalocale>/Compose")
%S
se développe en nom du répertoire système pour les fichiers Compose (c'est-à-dire "/usr/share/X11/locale")

Par exemple, vous pouvez inclure dans votre fichier compose le fichier Compose par défaut en utilisant :

include "%L"
et ensuite réécrire uniquement les quelques règles que vous devez modifier. De nouvelles règles de composition peuvent être ajoutées et les précédentes remplacées.

FORMAT DES FICHIERS

Les fichiers Compose sont des fichiers texte brut, avec une ligne séparée pour chaque séquence de composition. Les commentaires commencent par un caractère #. Chaque séquence de composition spécifie un ou plusieurs événements et une séquence de sortie résultante, avec un commentaire facultatif à la fin de la ligne :

ÉVÉNEMENT [ÉVÉNEMENT...] : RÉSULTAT [# COMMENTAIRE]

Chaque événement se compose d'un keysym d'entrée spécifié, et d'états de modificateurs optionnels :

[([!] ([~] MODIFICATEUR)...) | None] <keysym>

Si la liste des modificateurs est précédée de "!", elle doit correspondre exactement. MODIFICATEUR peut être l'un des suivants : Ctrl, Lock, Caps, Shift, Alt ou Meta. Chaque modificateur peut être précédé d'un caractère "~" pour indiquer que le modificateur ne doit pas être présent. Si "None" est spécifié, aucun modificateur ne peut être présent.

Le résultat spécifie une chaîne, un keysym, ou les deux, que le client X reçoit en entrée lorsque la séquence d'événements est entrée :

"CHAÎNE" | keysym | "CHAÎNE" keysym

Les keysyms sont spécifiés sans le préfixe XK_.

Les chaînes peuvent être du texte direct encodé dans la locale pour laquelle le fichier compose est destiné, ou un code de caractère octal ou hexadécimal échappé. Les codes octaux sont spécifiés comme "\123" et les codes hexadécimaux comme "\x3a". Il n'est pas nécessaire de spécifier dans la partie droite d'une règle une chaîne encodée locale en plus du nom du keysym. Si la chaîne est omise, Xlib la déduit du keysym selon la locale actuelle. Par exemple, si une règle ressemble à ceci :

<dead_grave> <A> : "\300" Agrave
le résultat de la composition est toujours la lettre avec le code "\300". Mais si la règle est :
<dead_grave> <A> : Agrave
le résultat dépend de la manière dont Agrave est mappé dans la locale actuelle.

ENVIRONNEMENT

XCOMPOSEFILE
Fichier à utiliser pour les séquences de composition.
XCOMPOSECACHE
Répertoire à utiliser pour la mise en cache des fichiers compose compilés.

FICHIERS

$HOME/.XCompose
Fichier compose par défaut de l'utilisateur si XCOMPOSEFILE n'est pas défini.
/usr/share/X11/locale/compose.dir
Fichier listant le chemin du fichier compose à utiliser pour chaque locale.
/usr/share/X11/locale/<mappage locale>/Compose
Fichier compose par défaut du système pour la locale, mappé via compose.dir.
/var/cache/libx11/compose/
Répertoire de cache système pour les fichiers compose compilés.
$HOME/.compose-cache/
Répertoire de cache par utilisateur pour les fichiers compose compilés.
