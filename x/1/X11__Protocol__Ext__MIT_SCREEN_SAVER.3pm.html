NOM

X11::Protocol::Ext::MIT_SCREEN_SAVER - support externe de l'économiseur d'écran

SYNOPSIS

use X11::Protocol;
my $X = X11::Protocol->new;
$X->init_extension('MIT-SCREEN-SAVER')
  or print "L'extension MIT-SCREEN-SAVER n'est pas disponible";

DESCRIPTION

L'extension MIT-SCREEN-SAVER permet à un programme d'économiseur d'écran client de dessiner un économiseur d'écran. N'importe quel client peut également écouter l'activation de l'économiseur d'écran.

Un programme d'économiseur d'écran s'enregistre ainsi que les attributs de fenêtre souhaités avec MitScreenSaverSetAttributes() et sélectionne les événements de notification de l'économiseur avec MitScreenSaverSelectInput(). Il ne peut y avoir qu'un seul programme d'économiseur externe à la fois.

Voir examples/mit-screen-saver-external.pl pour un programme d'économiseur d'écran complet.

Voir la requête principale SetScreenSaver() pour le délai d'inactivité habituel de l'écran, la période de cycle de l'économiseur et les styles intégrés de l'économiseur "Blank" ou "Internal". Voir la requête principale ForceScreenSaver() pour activer de force l'économiseur d'écran.

REQUÊTES

Les requêtes suivantes sont mises à disposition avec un init_extension() par "EXTENSIONS" dans X11::Protocol.

my $bool = $X->init_extension('MIT-SCREEN-SAVER');
"($serveur_major, $serveur_minor) = $X->MitScreenSaverQueryVersion ($client_major, $client_minor)"
Négocie une version de protocole avec le serveur. $client_major et $client_minor est ce que le client souhaiterait, les valeurs retournées $serveur_major et $serveur_minor sont ce que le serveur fera, ce qui sera le plus proche de la version demandée par le client que le serveur prend en charge.

Le code de ce module supporte la version 1.0. L'intention serait de négocier automatiquement dans init_extension() si/quand nécessaire.

"($etat, $fenetre, $jusqua_ou_depuis, $inactif, $masque_evenement, $type) = $X->MitScreenSaverQueryInfo ($dessinable)"
Retourne des informations sur l'économiseur d'écran de l'écran de $dessinable (un XID entier).

$etat est une chaîne d'énumération "Off", "On", ou "Disabled", selon "MitScreenSaverState" ci-dessous.

$fenetre est la fenêtre de l'économiseur d'écran, ou "None". Quand cette fenêtre existe, c'est un enfant override-redirect de la fenêtre racine mais elle n'apparaît pas dans les enfants de la racine de QueryTree(). Cette fenêtre existe lorsqu'un économiseur externe est activé mais peut ne pas exister à d'autres moments (auquel cas $fenetre est "None").

$jusqua_ou_depuis est une période en millisecondes. Si $etat est "Off", c'est le temps jusqu'à ce que l'économiseur soit activé en raison de l'inactivité. Si $etat est "On", c'est le temps en millisecondes depuis que l'économiseur a été activé. Mais voir " BUGS" ci-dessous.

$inactif est le temps en millisecondes depuis que l'écran est inactif. Dans les serveurs X.org, c'est aussi disponible comme un compteur "IDLETIME" dans l'extension SYNC (voir X11::Protocol::Ext::SYNC).

$masque_evenement est le masque du client actuel tel que défini par MitScreenSaverSelectInput() ci-dessous.

$type est une chaîne d'énumération "Blanked", "Internal" ou "External" pour la manière dont l'économiseur est réalisé maintenant ou le sera lors de la prochaine activation, selon "MitScreenSaverKind" ci-dessous.

"$X->MitScreenSaverSelectInput ($dessinable, $masque_evenement)"
Sélectionne les événements "MitScreenSaverNotify" de l'écran de $dessinable (un XID). $masque_evenement a deux bits, 
              position du bit  valeur du bit
NotifyMask      0      0x01
CycleMask       1      0x02

Il n'y a pas encore de fonction de regroupement pour ceux-ci, alors donnez simplement les valeurs entières des bits, par exemple 0x03 pour les deux.

"$X->MitScreenSaverSetAttributes ($dessinable, $classe, $profondeur, $visuel, $x, $y, $largeur, $hauteur, $largeur_bordure, clé => valeur, ...)"
Configure la fenêtre de l'économiseur d'écran sur l'écran de $dessinable (un XID).

Les arguments sont les mêmes que ceux de la requête principale CreateWindow(), sauf qu'il n'y a pas de nouvel XID à créer et que la fenêtre parente est toujours la fenêtre racine de l'écran de $dessinable ($dessinable pourrait déjà être la fenêtre racine).

Cette configuration rend l'économiseur de type "External" lors de sa prochaine activation. Si l'économiseur est actuellement actif, il n'est pas modifié. Le client peut écouter "MitScreenSaverNotify" (voir "ÉVÉNEMENTS" ci-dessous) pour savoir quand l'économiseur est activé. Le XID de la fenêtre de l'économiseur est rapporté dans cette notification, et des expositions etc peuvent y être sélectionnées à ce moment-là pour savoir quand dessiner, sauf peut-être si un pixel de fond ou un pixmap dans ce MitScreenSaverSetAttributes() est suffisant.

Un seul client à la fois peut configurer une fenêtre d'économiseur de cette manière. Si un autre l'a fait, une erreur "Access" en résulte.

"$X->MitScreenSaverUnsetAttributes ($dessinable)"
Supprime la configuration de la fenêtre de l'économiseur d'écran. Si le client n'a pas défini la fenêtre, ne fait rien.

Cela change le type de l'économiseur de "External" vers les types intégrés du serveur. Si l'économiseur d'écran est actuellement actif, cela se produit immédiatement.

À l'arrêt du client, un Unset est effectué automatiquement, sauf en mode de fermeture "RetainPermanent".

ÉVÉNEMENTS

Les événements "MitScreenSaverNotify" sont envoyés au client lorsqu'ils sont sélectionnés par MitScreenSaverSelectInput() ci-dessus. Ces événements rapportent quand l'état de l'économiseur d'écran change. L'événement a les champs habituels

nom             "MitScreenSaverNotify"
synthétique     true si issu d'un SendEvent
code            opcode entier
numero_sequence entier

et les champs spécifiques à l'événement

etat         "Off", "On", "Cycle"
temps          horodatage du serveur (entier)
racine         fenêtre racine de l'écran affecté (XID)
fenetre        la fenêtre de l'économiseur d'écran (XID)
type          "Blanked", "Internal", "External"
force          entier 0 ou 1

$etat est "Off" si l'économiseur s'est éteint ou "On" s'il s'est allumé. $force est 1 si le changement était dû à une requête ForceScreenSaver() plutôt qu'à une activité/inactivité de l'utilisateur. Les événements On/Off sont sélectionnés par NotifyMask dans MitScreenSaverSelectInput() ci-dessus.

$etat est "Cycle" si la période de cycle de l'économiseur a expiré, ce qui signifie qu'il est temps d'afficher quelque chose de différent. Ceci est sélectionné par CycleMask dans MitScreenSaverSelectInput() ci-dessus.

$type est le type d'économiseur actuel selon "MitScreenSaverKind" ci-dessous.

TYPES ÉNUMÉRÉS

Les types suivants sont disponibles pour "$X->interp()" et "$X->num()" après init_extension().

MitScreenSaverKind
"Blanked"    0     sortie vidéo désactivée
"Internal"   1     économiseur intégré au serveur
"External"   2     client d'économiseur externe
MitScreenSaverState
L'état de l'économiseur d'écran, tel que retourné par MitScreenSaverQueryInfo() et dans "MitScreenSaverNotif
y" événements. 
"Off"         0
"On"          1
"Cycle"       2
"Disabled"    3

Par exemple,

my $num = $X->num("MitScreenSaverKind", "External");
# définit $num à 2

BOGUES

Dans XFree86 et les serveurs X.org jusqu'à environ X.org 1.10, si l'économiseur d'écran est activé avec une requête ForceScreenSaver(), alors le $til_or_since de MitScreenSaverQueryInfo() est un grand nombre, semblant être une valeur négative pour le temps futur où il se serait activé en raison de l'inactivité. Aucune tentative n'est faite pour résoudre ce problème ici.

Également dans ces serveurs, lorsque le mode saver est "On", le délai d'inactivité semble continuer à se déclencher aussi, de sorte que le "depuis" de $til_or_since n'est que depuis le dernier déclenchement, comme si l'économiseur d'écran avait été réactivé, et non le temps depuis la première activation, ou quelque chose de similaire.
