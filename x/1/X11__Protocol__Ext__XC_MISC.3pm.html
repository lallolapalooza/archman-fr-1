NOM

X11::Protocol::Ext::XC_MISC - Module Perl pour l'extension XC-MISC du protocole X11

SYNOPIS

use X11::Protocol;
$x = X11::Protocol->new();
$x->init_extension('XC-MISC');

DESCRIPTION

Ce module est utilisé par le programmeur pour acquérir à l'avance un grand nombre d'identifiants de ressources X à utiliser avec le module X11::Protocol.

Si le serveur le supporte, X11::Protocol chargera ce module automatiquement lorsque des identifiants de ressources supplémentaires seront nécessaires via l'interface standard new_rsrc(). Cependant, si vous prévoyez qu'un programme s'exécute longtemps et alloue de nombreuses ressources, il serait judicieux d'initialiser l'extension au démarrage pour vérifier son existence.

REQUETES

Cette extension ajoute trois requêtes, appelées comme indiqué ci-dessous :

$x->XCMiscGetVersion => ($major, $minor)
$x->XCMiscGetXIDRange => ($start_id, $count)
$x->XCMiscGetXIDList($count) => ($count, @ids)
