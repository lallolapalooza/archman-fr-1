NOM

X11::Protocol::Ext::DPMS - Module Perl pour l'extension de protocole X11 DPMS

SYNOPIS

use X11::Protocol;
$x = X11::Protocol->new();
$x->init_extension('DPMS');

DESCRIPTION

Ce module est utilisé pour contrôler les fonctionnalités DPMS des moniteurs compatibles.

CONSTANTES SYMBOLiques

Cette extension ajoute le type de constante DPMSPowerLevels, avec les valeurs telles que définies dans la norme.

REQUETES

Cette extension ajoute plusieurs requêtes, appelées comme indiqué ci-dessous :

$x->DPMSGetVersion => ($major, $minor)
$x->DPMSCapable => ($capable)
$x->DPMSGetTimeouts => ($standby_timeout, $suspend_timeout, $off_timeout)
$x->DPMSSetTimeouts($standby_timeout, $suspend_timeout, $off_timeout) => ()
$x->DPMSEnable => ()
$x->DPMSDisable => ()
$x->DPMSForceLevel($power_level) => ()
$x->DPMSInfo => ($power_level,$state)
