X11::Protocol::Other(3) Documentation Perl fournie par l'utilisateur X11::Protocol::Other(3)

NOM

X11::Protocol::Other -- fonctions utilitaires diverses pour X11::Protocol

SYNOPIS

use X11::Protocol::Other;

DESCRIPTION

Ceci contient des fonctions utilitaires pour "X11::Protocol".

EXPORT

Rien n'est exporté par défaut, mais les fonctions peuvent être demandées dans le style habituel d'"Exporter",

use X11::Protocol::Other 'visual_is_dynamic';
if (visual_is_dynamic ($X, $visual_id)) {
  ...
}

Ou simplement appelées avec le nom de paquet complet

use X11::Protocol::Other;
if (X11::Protocol::Other::visual_is_dynamic ($X, $visual_id)) {
  ...
}

Il n'y a pas de tag ":all" car ce module est conçu comme un fourre-tout de fonctions et importer des éléments inconnus à l'avance demanderait des conflits de noms.

FONCTIONS

Recherche de l'écran

"$nombre = root_to_screen ($X, $root)"
"$hashref = root_to_screen_info ($X, $root)"
Retourne le numéro d'écran ou le hash d'informations d'écran pour une fenêtre racine donnée. $root peut être n'importe quel entier XID sur $X. Si ce n'est pas l'une des fenêtres racines, le retour est "undef".
"$nombre = default_colormap_to_screen ($X, $colormap)"
"$hashref = default_colormap_to_screen_info ($X, $colormap)"
Retourne le numéro d'écran ou le hash d'informations d'écran pour une palette de couleurs par défaut donnée. $colormap peut être n'importe quel entier XID sur $X. Si ce n'est pas l'une des palettes de couleurs par défaut de l'écran, le retour est "undef".

Visuels

"$bool = visual_is_dynamic ($X, $visual_id)"
"$bool = visual_class_is_dynamic ($X, $visual_class)"
Retourne vrai si le visuel donné est dynamique, ce qui signifie que les entrées de la palette de couleurs peuvent être modifiées pour changer la couleur d'une valeur de pixel donnée.

$visual_id est l'un des numéros d'ID visuels, c'est-à-dire l'une des clés dans "$X->{'visuals'}". Ou $visual_class est une chaîne VisualClass comme "PseudoColor" ou un entier correspondant comme 3.

Informations sur la fenêtre

"($width, $height) = window_size ($X, $window)"
"$visual_id = window_visual ($X, $window)"
Retourne la taille ou l'ID visuel d'une fenêtre donnée.

$window est un entier XID sur $X. S'il s'agit de l'une des fenêtres racines, les valeurs de retour proviennent du hash d'informations d'écran dans $X, sinon le serveur est interrogé avec GetGeometry() (pour la taille) ou GetWindowAttributes() (pour le visuel).

Ces fonctions sont utiles lorsqu'il y a une forte probabilité que $window soit une fenêtre racine et donc qu'un aller-retour au serveur ne soit pas nécessaire.

"@atoms = get_property_atoms($X, $window, $property)"
Obtient de $window (entier XID) une propriété de liste d'atomes $property (entier d'atome). Le retour est une liste d'entiers d'atomes, éventuellement une liste vide. Si $property n'existe pas ou n'est pas une liste d'atomes, retourne une liste vide.
"set_property_atoms($X, $window, $property, @atoms)"
Définit sur $window (entier XID) une propriété de liste d'atomes $property (entier d'atome) comme la liste donnée de @atoms (éventuellement vide).

Analyse des couleurs

"($red16, $green16, $blue16) = hexstr_to_rgb($str)"
Analyse une chaîne de couleur RVB donnée comme "#FF00FF" en composantes rouge, verte et bleue sur 16 bits. Les valeurs de retour sont toujours comprises dans la plage de 0 à 65535. Les chaînes reconnues sont des hexadécimaux à 1, 2, 3 ou 4 chiffres. 
#RGB
#RRGGBB
#RRRGGGBBB
#RRRRGGGGBBBB

Si $str n'est pas reconnu, le retour est une liste vide, donc par exemple

my @rgb = hexstr_to_rgb($str)
  or die "Couleur non reconnue : $str";

Les chiffres des formes à 1, 2 et 3 chiffres sont répétés si nécessaire pour donner une plage de 16 bits. Par exemple, le style à 3 chiffres "#321FFF000" donne les valeurs de retour 0x3213, 0xFFFF, 0. Ou à 1 chiffre "#F0F" est 0xFFFF, 0, 0xFFFF. Notez que "F" s'étend à 0xFFFF, donc "F", "FF" ou "FFF" signifient tous une saturation complète, tout comme un "FFFF" à 4 chiffres.

Serait-il utile de reconnaître le style Xcms "rgb:RR/GG/BB" ? C'est peut-être mieux laissé à Xcms complet, ou aux modules de conversion de couleur généraux. La page de manuel X(7) de X11R6 décrit la forme "rgb:", mais juste "#" est beaucoup plus courant.
