NOM

X11::Protocol::Connection - Classe de base abstraite pour les modules Perl représentant les connexions client-serveur X11

SYNTAXE

# Dans le module de l'objet de connexion
package X11::Protocol::Connection::CarrierPigeon;
use X11::Protocol::Connection;
@ISA = ('X11::Protocol::Connection');
sub open { ... }
sub give { ... }
sub get { ... }
sub fh { ... }
...
# Dans le programme
$connection = X11::Protocol::Connection::CarrierPigeon
  ->open($host, $display_number);
$x = X11::Protocol->new($connection);
$connection->give($data);
$reply = unpack("I", $connection->get(4));
use IO::Select;
$sel = IO::select->new($connection->fh);
if ($sel->can_read == $connection->fh) ...

DESCRIPTION

Ce module est une classe de base abstraite pour les divers modules X11::Protocol::Connection::* qui fournissent des connexions aux serveurs X pour le module X11::Protocol. Il fournit des squelettes pour les méthodes suivantes :

open

$conn = X11::Protocol::Connection::Foo->open($host, $display_num)

Ouvre une connexion au serveur d'affichage spécifié (numéroté à partir de 0) sur la machine $host spécifiée.

give

$conn->give($data)

Envoie les données fournies au serveur. Normalement, cette méthode est utilisée uniquement par le module de protocole lui-même.

get

$data = $conn->get($n)

Lit $n octets de données depuis le serveur. Normalement, cette méthode est utilisée uniquement par le module de protocole lui-même.

fh

$filehandle = $conn->fh

Retourne un objet approprié pour être utilisé comme handle de fichier. Ceci est principalement utile pour les appels système comme select() et autres similaires.
