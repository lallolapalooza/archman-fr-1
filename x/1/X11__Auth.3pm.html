NOM

X11::Auth - Module Perl pour lire les fichiers d'autorité X11

SYNTAXE

require X11::Auth;
$a = new X11::Auth;
($type_auth, $donnees_auth) = $a->get_by_host($hote, $num_disp);

DESCRIPTION

Ce module est un remplacement approximatif en Perl de la bibliothèque C libXau et du programme xauth(1). Il lit et interprète les fichiers (généralement '~/.Xauthority') qui contiennent les données d'autorisation utilisées pour se connecter aux serveurs X. Comme il a été principalement écrit pour l'utilisation de X11::Protocol, ses fonctionnalités sont actuellement limitées à la lecture, et non à l'écriture, de ces fichiers.

MÉTHODES

new

$auth = X11::Auth->new;
$auth = X11::Auth->open($nom_fichier);

Ouvre un fichier d'autorité et crée un objet pour le gérer. Le nom du fichier sera pris de la variable d'environnement XAUTHORITY, si elle est présente, ou de '.Xauthority' dans le répertoire personnel de l'utilisateur, ou il peut être remplacé par un argument. 'open' peut être utilisé comme synonyme.

get_one

($famille, $addr_hote, $num_affichage, $nom_auth, $donnees_auth)
   = $auth->get_one;

Lit une entrée du fichier. Renvoie une liste nulle en fin de fichier. $famille est généralement 'Internet' ou 'Local', et $num_affichage peut être n'importe quelle chaîne.

get_all

@donnees_auth = $auth->get_all;

Lit toutes les entrées du fichier. Chaque membre du tableau renvoyé est une référence de tableau similaire à la liste renvoyée par get_one().

get_by_host

($nom_auth, $donnees_auth)
   = $auth->get_by_host($hote, $famille, $num_affichage);

Obtient les données d'authentification pour une connexion de type $famille à l'affichage $num_affichage sur $hote. Si $famille est 'Internet', l'hôte sera traduit en une adresse appropriée par gethostbyname(). Si aucune donnée n'est trouvée, renvoie une liste vide.

COMPATIBILITÉ

Le tableau suivant montre la correspondance (approximative) entre les appels libXau et les méthodes X11::Auth :

libXau                     X11::Auth
------                     ---------
XauFileName                $ENV{XAUTHORITY}
                           || "$ENV{HOME}/.Xauthority"
fopen(XauFileName(), "rb") $auth = new X11::Auth
XauReadAuth                $auth->get_one
XauWriteAuth
XauGetAuthByAddr           $auth->get_by_host
XauGetBestAuthByAddr 
XauLockAuth
XauUnlockAuth
XauDisposeAuth
