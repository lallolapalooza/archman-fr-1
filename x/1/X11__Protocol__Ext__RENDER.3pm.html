Protocol::Ext::RENDER(3) Documentation Perl fournie par la communauté Protocol::Ext::RENDER(3)

NOM

X11::Protocol::Ext::RENDER - Module Perl pour l'extension X Rendering

SYNOPIS

use X11::Protocol;
$x = X11::Protocol->new($ENV{'DISPLAY'});
$x->init_extension('RENDER') or die;

DESCRIPTION

L'extension RENDER ajoute un nouvel ensemble de primitives de dessin qui représentent effectivement un remplacement des routines de dessin du protocole principal, repensées en fonction des besoins des clients plus modernes. Elle ajoute des fonctionnalités longtemps désirées telles que le positionnement de sous-pixels, la composition alpha, la spécification directe des couleurs et les curseurs multicolores ou animés. D'autre part, elle omet des fonctionnalités qui ne sont plus couramment utilisées : les lignes larges, les polygones arbitraires (seuls les triangles et les trapèzes alignés horizontalement sont pris en charge), les ellipses, les opérations de dessin au niveau du bit et les polices côté serveur (au profit des « glyphes » qui sont rendus côté client et transmis une seule fois).

À l'heure actuelle (début 2004), la spécification et l'implémentation ont des aspérités, mais il existe relativement peu d'alternatives pour décharger le traitement graphique avancé vers le serveur, ce qui est nécessaire sur des liaisons lentes ou si le client est écrit dans un langage lent. Une autre possibilité que vous pourriez envisager est le sous-ensemble 2D d'OpenGL, bien qu'il ne dispose pas encore d'une interface compatible avec X11::Protocol.

CONSTANTES SYMBOLIQES

Cette extension ajoute les types de constantes 'PictType', 'PictOp', 'SubPixel', 'PolyEdge' et 'PolyMode', avec des valeurs telles que définies dans la norme.

REQUETES

Cette extension ajoute plusieurs requêtes, appelées comme indiqué ci-dessous :

$x->RenderQueryVersion($major, $minor)
=>
($major, $minor)
$x->RenderQueryPictFormats()
=>
([[$id, $type, $depth,
   $red, $red_m, $green, $green_m, $blue, $blue_m,
   $alpha, $alpha_m, $cmap], ...],
 [[$fallback, [$depth, [$visual, $format], ...], ...], ...],
 [$subpixel, ...])
$x->RenderQueryPictIndexValues($pict_format)
=>
([$index, $red, $green, $blue, $alpha], ...)
$x->RenderQueryFilters($drawable)
=>
([@filters], [@aliases])
$x->RenderCreatePicture($picture, $drawable, $format,
                        'attribute' => $value, ...)
$x->RenderChangePicture($picture, 'attribute' => $value, ...)
$x->RenderSetPictureClipRectangles($pic, $x_origin, $y_origin,
                                   [$x, $y, $width, $height], ...)
$x->RenderSetPictureTransform($pict, $m11, $m12, $m13,
                                     $m21, $m22, $m23,
                                     $m31, $m32, $m33);
$x->RenderSetPictureFilter($pict, $filter, @args)
$x->RenderComposite($op, $src, $mask, $dst, $src_x, $src_y,
                    $mask_x, $mask_y, $dst_x, $dst_y,
                    $width, $height)
$x->RenderFillRectangles($op, $dst, [$red, $green, $blue, $alpha],
                         [$x, $y, $width, $height], ...)
$x->RenderTrapezoids($op, $src, $src_x, $src_y, $dst, $mask_format,
                     [$top, $bottom, $lx1, $ly1, $lx2, $ly2,
                                     $rx1, $ry1, $rx2, $ry2] ,...)
$x->RenderTriangles($op, $src, $src_x, $src_y, $dst, $mask_format,
                    [$x1, $y1, $x2, $y2, $x3, $y3])
$x->RenderTriStrip($op, $src, $src_x, $src_y, $dst, $mask_format,
                    [$x, $y], [$x, $y], [$x, $y], [$x, $y], ...)
$x->RenderTriFan($op, $src, $src_x, $src_y, $dst, $mask_format,
                 [$x, $y], [$x, $y], [$x, $y], [$x, $y], ...)
$x->RenderCreateGlyphSet($gsid, $format)
$x->RenderReferenceGlyphSet($gsid, $existing)
$x->RenderFreeGlyphSet($gsid)
$x->RenderAddGlyphs($gsid, [$glyph, $width, $height,
                            $x, $y, $x_off, $y_off, $data], ...)

Attention : avec certaines implémentations de serveur (y compris XFree86 jusqu'à la version 4.4), le passage de plus d'un glyphe à AddGlyphs peut bloquer ou faire planter le serveur. Ne le faites donc pas.

$x->RenderFreeGylphs($gsid, @glyphs)
$x->RenderCompositeGlyphs8($op, $src, $dst, $mask_format, $gsid,
                           $src_x, $src_y,
                           [$delta_x, $delta_y, $str], ...)
$x->RenderCompositeGlyphs16($op, $src, $dst, $mask_format, $gsid,
                            $src_x, $src_y,
                            [$delta_x, $delta_y, $str], ...)
$x->RenderCompositeGlyphs32($op, $src, $dst, $mask_format, $gsid,
                            $src_x, $src_y,
                            [$delta_x, $delta_y, $str], ...)

Dans ces trois requêtes, de nouveaux GlyphSetIDs peuvent également être intercalés avec les références de tableau.

$x->RenderCreateCursor($cid, $source, $hot_x, $hot_y)
$x->RenderCreateAnimCursor($cid, [$cursor, $delay], ...)
