X11::Protocol::Ext::TOG_CUP(3) Documentation Perl contribuée par l'utilisateur X11::Protocol::Ext::TOG_CUP(3)

NOM

X11::Protocol::Ext::TOG_CUP - extension de politique d'utilisation de la palette de couleurs

SYNTAXE

use X11::Protocol;
my $X = X11::Protocol->new;
$X->init_extension('TOG-CUP')
  or print "L'extension TOG-CUP n'est pas disponible";

DESCRIPTION

L'extension TOG-CUP aide les applications utilisant des palettes de couleurs privées à utiliser le même pixel pour la même couleur dans différentes palettes de couleurs.

L'utilisation de valeurs de pixels communes, lorsque cela est possible, signifie que lorsqu'une palette de couleurs privée est utilisée ("$x->InstallColormap()", généralement fait par le gestionnaire de fenêtres), certaines des couleurs des autres fenêtres apparaîtront toujours correctement.

Notez que cette extension apporte une subtile modification aux requêtes de base "$X->AllocColor()" et "$X->AllocNamedColor()". Normalement, elles allouent le premier pixel disponible, mais avec TOG-CUP, s'il existe une couleur correspondante dans la palette par défaut et que ce même pixel dans la palette cible est libre, alors ce pixel est alloué, rendant ainsi cette couleur identique dans les deux palettes.

REQUETES

Les éléments suivants sont mis à disposition avec un init_extension() par "EXTENSIONS" dans X11::Protocol.

my $bool = $X->init_extension('TOG-CUP');
"($server_major, $server_minor) = $X->CupQueryVersion ($client_major, $client_minor)"
Négocie une version de protocole avec le serveur. $client_major et $client_minor représentent ce que le client souhaite, les valeurs retournées $server_major et $server_minor représentent ce que le serveur fera, ce qui peut être différent.

Le code actuel prend en charge jusqu'à la version 1.0. L'intention serait de négocier automatiquement dans init_extension() si nécessaire, ce qui n'est pas le cas actuellement.

"@couleurs = $X->CupGetReservedColormapEntries ($ecran)"
Retourne une liste d'entrées de palette réservées dans la palette par défaut de l'écran numéro $ecran (un entier à partir de 0). Chaque élément retourné est un tableau référencé 
[ $pixel, $rouge16, $bleu16, $vert16, $alloc_flags ]

$rouge16, $bleu16 et $vert16 sont des composantes de couleur RVB dans la plage de 0 à 65535. $alloc_flags n'est actuellement pas utilisé.

Les couleurs réservées sont pré-allouées et immuables. Le protocole de base spécifie "$X->{'black_pixel'}" et "$X->{'white_pixel'}" et ils sont inclus dans le résultat, ainsi que toute autre couleur qui pourrait être réservée.

Par exemple, sous le gestionnaire d'interface graphique MS-DOS, il existe un certain ensemble de couleurs "desktop" qu'un serveur sur ce système pourrait traiter comme réservées.

"@couleurs = $X->CupStoreColors ($colormap, [$pixel,$rouge16,$vert16,$bleu16],...)"
Alloue des couleurs en lecture seule dans $colormap à des pixels spécifiques.

Chaque argument est une référence de tableau contenant le pixel désiré et la couleur RVB. (Un paramètre $do_mask peut également être présent à la fin, mais il n'est pas utilisé et peut être omis.)

[ $pixel, $rouge16, $bleu16, $vert16 ]

La couleur désirée est allouée en partageable lecture seule (comme "$X->AllocColor()") au $pixel donné si possible, ou à un autre si nécessaire. Le retour est une liste similaire d'éléments de référence de tableau, un pour chaque argument

[ $pixel, $rouge16, $bleu16, $vert16, $alloc_flags ]

Le $pixel retourné peut différer de celui qui a été demandé. Si le $pixel demandé est déjà alloué et qu'il a une couleur différente, alors une autre valeur de pixel est choisie.

Les composantes RVB retournées représentent la nuance de couleur réelle allouée. Cela peut différer si la visualisation a une résolution de couleur limitée (ce qui est probable).

Le $alloc_flags retourné a le bit 0x08 défini si le pixel a été alloué avec succès, ou effacé sinon. D'autres bits dans $alloc_flags ne sont actuellement pas utilisés.

Par exemple

my @ret = $X->CupStoreColors
            ($colormap,
             [ 2,  65535,0,0],           # rouge   
             [ 3,  0,65535,0],           # vert
             [ 4,  16383,16383,16383]);  # gris
foreach my $elem (@ret) {
  my ($pixel, $red,$green,$blue, $alloc_ok) = @$elem;
  my $ok = ($alloc_ok & 8 ? "alloué" : "oops, non alloué");
  print "au pixel $pixel couleur réelle $red,$green,$blue  $ok\n";
}
