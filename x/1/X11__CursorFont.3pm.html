NOM

X11::CursorFont - noms et numéros des glyphes de polices de curseurs

SYNOPIS

use X11::CursorFont '%CURSOR_GLYPH';
my $num = $CURSOR_GLYPH{'fleur'};               # vaut 52
my $name = $X11::CursorFont::CURSOR_NAME[52];   # vaut "fleur"

DESCRIPTION

Ce module contient les noms et les numéros des glyphes de la police de curseurs X11 qui comprend divers pointeurs de souris standards.

%CURSOR_GLYPH mappe un nom de glyphe à son numéro de caractère dans la police,

$CURSOR_GLYPH{'fleur'}     # vaut 52

@CURSOR_NAME fait l'inverse, étant indexée par le numéro de caractère et renvoyant le nom du glyphe,

$CURSOR_NAME[52]           # vaut "fleur"

Chaque glyphe a un masque associé au numéro de caractère glyph+1, qui représente la forme du curseur (les pixels affichés par rapport aux pixels transparents). Par conséquent, les numéros de caractères sont toujours pairs et, dans @CURSOR_NAME, seules les positions de caractères paires ont des noms.

Les images des curseurs peuvent être visualisées avec le programme d'affichage de polices habituel "xfd",

xfd -fn cursor

VARIABLES

%X11::CursorFont::CURSOR_GLYPH
Une table de correspondance entre le nom du glyphe et le numéro de caractère de la police de curseurs.
@X11::CursorFont::CURSOR_NAME
Une table de correspondance entre le numéro de caractère de la police de curseurs et le nom du glyphe.

EXPORTATIONS

Rien n'est exporté par défaut, mais %CURSOR_GLYPH et @CURSOR_NAME peuvent être sélectionnés dans le style habituel d'"Exporter" (voir Exporter),

use X11::CursorFont '%CURSOR_GLYPH', '@CURSOR_NAME';

EXEMPLE

Pour créer un curseur à partir d'un glyphe désiré,

my $cursor_name = 'spraycan';
my $cursor_glyph = $CURSOR_GLYPH{$cursor_name}; # numéro
my $cursor_font = $X->new_rsrc;
$X->OpenFont ($cursor_font, "cursor"); # police de curseurs
my $cursor = $X->new_rsrc;
$X->CreateGlyphCursor
       ($cursor,
        $cursor_font,  # police
        $cursor_font,  # police de masque
        $cursor_glyph,      # glyphe
        $cursor_glyph + 1,  # et son masque
        0,0,0,                  # premier plan, noir
        0xFFFF,0xFFFF,0xFFFF);  # arrière-plan, blanc
$X->CloseFont ($cursor_font);
# puis utiliser $cursor avec CreateWindow ou ChangeWindowAttributes
#       cursor => $cursor

La variable $cursor_font pourrait être laissée ouverte si elle est utilisée de manière répétée. L'ouverture et la fermeture ne sont pas des allers-retours, donc une ouverture au besoin peut suffire.

Toutes les couleurs RGB peuvent être données dans CreateGlyphCursor(), mais l'apparence réelle à l'écran sera limitée par le matériel.

Tous les curseurs du protocole de base sont bicolores, avec des pixels entièrement opaques ou entièrement transparents selon cette création. L'extension RENDER, lorsqu'elle est disponible, peut créer des couleurs multiples et une transparence partielle si désiré (voir X11::Protocol::Ext::RENDER).
