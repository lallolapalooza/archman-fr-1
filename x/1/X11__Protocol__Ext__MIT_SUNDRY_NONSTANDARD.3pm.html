NOM

X11::Protocol::Ext::MIT_SUNDRY_NONSTANDARD - Mode de compatibilité X11R2/R3

SYNTAXE

use X11::Protocol;
my $X = X11::Protocol->new;
$X->init_extension('MIT-SUNDRY-NONSTANDARD')
  or print "L'extension MIT-SUNDRY-NONSTANDARD n'est pas disponible";

DESCRIPTION

L'extension MIT-SUNDRY-NONSTANDARD contrôle un paramètre de « mode bug » dans le serveur qui aide certains programmes clients X11R2 et X11R3, y compris "xterm" de ces versions.

Le mode bug signifie : assouplir la vérification des masques d'événements dans les requêtes de pointeur de capture et de bouton, ainsi que les attributs de non-propagation de fenêtre (pour ignorer les bits de masque qui ne sont pas applicables) ; quelque chose pour l'ordre d'empilement des fenêtres sœurs qui ne se chevauchent pas ; et maintenir la clé maximale en dessous de 255 pour éviter un segment de faute du kit d'outils Xt. Sauf si vous travaillez avec de vieux programmes clients, ces choses ne présentent probablement pas d'intérêt.

REQUETES

Les éléments suivants sont mis à disposition avec une init_extension() par « EXTENSIONS » dans X11::Protocol.

my $bool = $X->init_extension('MIT-SUNDRY-NONSTANDARD');
"$X->MitSundryNonstandardSetBugMode ($flag)"
"$flag = $X->MitSundryNonstandardGetBugMode ()"
Obtenir ou définir le drapeau du mode bug. 1 signifie que le mode de compatibilité est activé, 0 signifie qu'il est désactivé.

VOIR AUSSI

X11::Protocol

xset(1) option « bc » pour contrôler le drapeau bug depuis la ligne de commande.

Xserver(1) option en ligne de commande « bc » pour définir le drapeau au démarrage du serveur.
