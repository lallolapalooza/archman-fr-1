NOM

X11::Keysyms - Module Perl pour les noms de keysyms X11

SYNTAXE

use X11::Keysyms '%Keysyms', qw(MISCELLANY XKB_KEYS LATIN1);
%Keysyms_name = reverse %Keysyms;
$ks = $Keysyms{'BackSpace'};
$name = $Keysysms_name{$ks};

DESCRIPTION

Ce module exporte une table de hachage associant les noms des keysyms X11, tels que 'A' ou 'Linefeed' ou 'Hangul_J_YeorinHieuh', aux nombres qui les représentent. Le premier argument de 'use' est le nom de la variable dans laquelle la table de hachage doit être exportée, et les suivants sont les noms des sous-ensembles de keysyms à exporter : un ou plusieurs parmi

'MISCELLANY', 'XKB_KEYS', '3270', 'LATIN1', 'LATIN2',
'LATIN3', 'LATIN4', 'KATAKANA', 'ARABIC', 'CYRILLIC',
'GREEK', 'TECHNICAL', 'SPECIAL', 'PUBLISHING', 'APL',
'HEBREW', 'THAI', 'KOREAN'.

Si cette liste est omise, la liste

'MISCELLANY', 'XKB_KEYS', 'LATIN1', 'LATIN2', 'LATIN3',
'LATIN4', 'GREEK'

est utilisée.

AUTEUR

Ce module a été généré semi-automatiquement par Stephen McCamant (<SMCCAM@cpan.org>) à partir du fichier d'en-tête 'X11/keysymdef.h', distribué par le X Consortium.
