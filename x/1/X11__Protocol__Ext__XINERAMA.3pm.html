NOM

X11::Protocol::Ext::XINERAMA - informations sur les affichages multi-moniteurs

SYNOPHIS

use X11::Protocol;
my $X = X11::Protocol->new;
$X->init_extension('XINERAMA')
  or print "L'extension XINERAMA n'est pas disponible";

DESCRIPTION

Xinerama combine deux moniteurs physiques ou plus pour créer un grand écran unique. L'extension XINERAMA permet aux clients de s'enquérir de la configuration.

Les requêtes "PanoramiX" 1.0 prennent un paramètre $window apparemment pour permettre plus d'un écran X composé de plusieurs moniteurs physiques, mais en pratique, les serveurs n'ont créé qu'un seul écran de cette manière et les requêtes "Xinerama" 1.1 n'ont pas cela.

Voir examples/xinerama-info.pl pour un exemple de programme qui décharge les informations d'état Xinerama.

REQUETES

Les requêtes suivantes sont mises à disposition avec un init_extension() par "EXTENSIONS" dans X11::Protocol.

my $bool = $X->init_extension('XINERAMA');

Xinerama 1.0

"($server_major, $server_minor) = $X->PanoramiXQueryVersion ($client_major, $client_minor)"
Négocie une version de protocole avec le serveur. $client_major et $client_minor sont ce que le client souhaite, $server_major et $server_minor retournés sont ce que le serveur fera, ce qui peut être inférieur à la demande (mais pas plus).

Le code actuel de ce module supporte jusqu'à 1.1. L'intention serait de négocier automatiquement au sein de init_extension() si/quand nécessaire.

"$flag = $X->PanoramiXGetState ($window)"
Retourne une valeur non nulle si Xinerama est actif sur l'écran de $window (un XID).
"$count = $X->PanoramiXGetScreenCount ($window)"
Retourne le nombre de moniteurs physiques sur l'écran de $window (un XID).
"($width, $height) = $X->PanoramiXGetScreenSize ($window, $monitor)"
Retourne la taille en pixels du moniteur physique numéro $monitor (entier, 0 pour le premier moniteur) sur l'écran de $window (un XID).

Xinerama 1.1

"$bool = $X->XineramaIsActive ()"
Retourne une valeur non nulle si Xinerama est actif sur le serveur $X.
"@rectangles = $X->XineramaQueryScreens ()"
Retourne les zones rectangulaires composées par les moniteurs physiques. Le retour est une liste d'arrayrefs, 
[ $x,$y, $width,$height ]

$x,$y est le coin supérieur gauche du moniteur dans l'écran combiné.

BOGUES

"Xsun"

La rumeur dit que le serveur "Xsun" avec Xinerama 1.0 avait un numéro de requête différent, le 4, par rapport à "XineramaIsActive" de Xinerama 1.1 ci-dessus.

http://blogs.sun.com/alanc/entry/xinerama_protocol_clashes_on_solaris

Aucune tentative n'est faite ici pour y remédier, pour l'instant. Si PanoramiXQueryVersion() retourne 1.0, alors vous ne devriez pas utiliser XineramaIsActive() de toute façon, donc pas de conflit. Si vous le faites et qu'il s'agit du serveur "Xsun", attendez-vous soit à une réponse d'erreur de longueur, soit à ce que le serveur s'adapte à la longueur de la requête et se comporte comme "XineramaIsActive".

PanoramiXGetScreenSize() Dépassement de tampon

Les premiers codes de serveur tels que X11R6.4 peuvent ne pas vérifier la plage du numéro de moniteur dans PanoramiXGetScreenSize(). Les grandes valeurs ont-elles lu des fragments de mémoire arbitraire ou provoqué un segfault ? Ne le faites pas.

X.org un certain temps après 1.5.x, "Empêcher le dépassement de tampon dans ProcPanoramiXGetScreenSize", http://cgit.freedesktop.org/xorg/xserver/commit/?id=2b266eda6e23d16116f8a8e258192df353970279

AUTRES NOTES

Pour simuler un Xinerama afin de tester le serveur "Xdmx" peut multiplexer deux autres serveurs ou plus pour présenter un grand écran unique. Ces sous-serveurs peuvent même être des fenêtres "Xnest" ou "Xephyr" sur un affichage X existant. Par exemple, lancer "Xdmx" comme affichage ":102",

Xephyr :5 -screen 200x100 &
Xephyr :6 -screen 190x110 &
sleep 1
Xdmx -display :5 -display :6 +xinerama -input :5 -input :6 :102

"Xephyr" implémente certaines extensions nativement, tandis que "Xnest" repose sur les capacités du serveur cible. Ou pour lancer sans se soucier de regarder quoi que ce soit, "Xvfb" en mémoire ou un fichier sur disque.

    NAME

    X11::Protocol::Ext::XINERAMA - Perl interface to the X-Window system XINERAMA extension protocol

    SYNOPSIS

    use X11::Protocol::Ext::XINERAMA;

my $xinerama = X11::Protocol::Ext::XINERAMA->new($x_connection);

my $supported = $xinerama->QueryVersion();
if ($supported) {
    my $screen_count = $xinerama->GetScreenCount();
    my $screens = $xinerama->GetScreenSize($screen_count);
}

    DESCRIPTION

    This module provides a Perl interface to the XINERAMA extension protocol for the X Window System.

    The XINERAMA extension allows applications to query information about the physical arrangement of screens managed by an X server. This is particularly useful for multi-monitor setups.

    The module offers methods corresponding to the XINERAMA protocol requests.

    METHODS

    new($x_connection)

    Constructor. Creates a new X11::Protocol::Ext::XINERAMA object associated with the given X connection object.

    Arguments:

    $x_connection
    An object representing the X connection (e.g., from X11::Protocol).

    Returns: A new X11::Protocol::Ext::XINERAMA object.

    QueryVersion()

    Sends a QueryVersion request to the X server to determine if the XINERAMA extension is supported and to get its version.

    Returns: A boolean indicating whether the extension is supported, or an error string if not.

    GetScreenCount()

    Sends a GetScreenCount request to the X server to retrieve the number of physical screens configured.

    Returns: The number of screens, or undef on error.

    GetScreenSize($screen_number)

    Sends a GetScreenSize request to the X server to get the geometry (width and height) of a specific physical screen.

    Arguments:

    $screen_number
    The index of the screen (0-based).

    Returns: A hash reference containing the screen's geometry (e.g., {width => 1920, height => 1080}), or undef on error.

    BUGS

    None reported currently.

    OTHER NOTES

    This module assumes you have a working X connection object from a module like X11::Protocol.

    XINERAMA protocol specification, X11::Protocol.
