NOM

X11::Protocol::Connection::UNIXSocket - Module Perl pour les connexions X11 basées sur IO::Socket::UNIX

SYNTAXE

use X11::Protocol;
use X11::Protocol::Connection::UNIXSocket;
$conn = X11::Protocol::Connection::UNIXSocket
  ->open($hôte, $numéro_de_display);
$x = X11::Protocol->new($conn);

DESCRIPTION

Ce module est utilisé par X11::Protocol pour établir une connexion et communiquer avec un serveur via une connexion de socket de domaine Unix locale, en utilisant le module IO::Socket::UNIX. L'argument hôte est ignoré.
