NOM

X11::AtomConstants -- atomes X11 prédéfinis

SYNOPSIS

use X11::AtomConstants;
$X->ChangeProperty($window,
                   X11::AtomConstants::WM_NAME,  # propriété
                   X11::AtomConstants::PIXMAP,   # type
                   8,                            # format
                   'Replace',
                   'Titre de ma fenêtre');

DESCRIPTION

Ce sont les atomes X11 prédéfinis sous forme de constantes Perl. Par exemple, "PIXMAP" vaut 20, l'atome PIXMAP.

my $atom_id = X11::AtomConstants::PIXMAP;  # $atom_id vaut 20
my $name = $X->GetAtomName($atom_id);      # $name vaut "PIXMAP"

La constante "LAST_PREDEFINED" n'est pas un atome en soi, mais la dernière des valeurs prédéfinies, qui se trouve être "WM_TRANSIENT_FOR".

EXPORTS

Rien n'est exporté par défaut, mais les constantes peuvent être demandées dans le style habituel de "Exporter",

use X11::AtomConstants 'PIXMAP';
blah (atom => PIXMAP);

Le tag ":all" importe tout,

use X11::AtomConstants ':all';
blah (atom1 => POINT,
      atom2 => RECTANGLE);

Beaucoup d'atomes comme "STRING" ou "WEIGHT" ont des noms assez génériques et leur importation peut être indésirable. Ils peuvent toujours être utilisés avec le nom complet du paquet,

use X11::AtomConstants;
blah (atom => X11::AtomConstants::PIXMAP);
