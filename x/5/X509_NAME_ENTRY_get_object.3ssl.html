X509_NAME_ENTRY_get_object(3ssl)

Paquet: openssl

Licences: Apache-2.0

X509_NAME_ENTRY_GET_OBJECT(3ssl) OpenSSL X509_NAME_ENTRY_GET_OBJECT(3ssl)

NOM

X509_NAME_ENTRY_get_object, X509_NAME_ENTRY_get_data, X509_NAME_ENTRY_set_object, X509_NAME_ENTRY_set_data, X509_NAME_ENTRY_create_by_txt, X509_NAME_ENTRY_create_by_NID, X509_NAME_ENTRY_create_by_OBJ - Fonctions utilitaires X509_NAME_ENTRY

SYNTAXE

#include <openssl/x509.h>
ASN1_OBJECT *X509_NAME_ENTRY_get_object(const X509_NAME_ENTRY *ne);
ASN1_STRING *X509_NAME_ENTRY_get_data(const X509_NAME_ENTRY *ne);
int X509_NAME_ENTRY_set_object(X509_NAME_ENTRY *ne, const ASN1_OBJECT *obj);
int X509_NAME_ENTRY_set_data(X509_NAME_ENTRY *ne, int type,
                             const unsigned char *bytes, int len);
X509_NAME_ENTRY *X509_NAME_ENTRY_create_by_txt(X509_NAME_ENTRY **ne, const char *field,
                                               int type, const unsigned char *bytes,
                                               int len);
X509_NAME_ENTRY *X509_NAME_ENTRY_create_by_NID(X509_NAME_ENTRY **ne, int nid,
                                               int type, const unsigned char *bytes,
                                               int len);
X509_NAME_ENTRY *X509_NAME_ENTRY_create_by_OBJ(X509_NAME_ENTRY **ne,
                                               const ASN1_OBJECT *obj, int type,
                                               const unsigned char *bytes, int len);

DESCRIPTION

X509_NAME_ENTRY_get_object() récupère le nom du champ de ne sous forme de structure ASN1_OBJECT.

X509_NAME_ENTRY_get_data() récupère la valeur du champ de ne sous forme de structure ASN1_STRING.

X509_NAME_ENTRY_set_object() définit le nom du champ de ne à obj.

X509_NAME_ENTRY_set_data() définit la valeur du champ de ne au type de chaîne type et à la valeur déterminée par bytes et len.

X509_NAME_ENTRY_create_by_txt(), X509_NAME_ENTRY_create_by_NID() et X509_NAME_ENTRY_create_by_OBJ() créent et retournent une structure X509_NAME_ENTRY.

NOTES

X509_NAME_ENTRY_get_object() et X509_NAME_ENTRY_get_data() peuvent être utilisés pour examiner une fonction X509_NAME_ENTRY telle que retournée par X509_NAME_get_entry(), par exemple.

X509_NAME_ENTRY_create_by_txt(), X509_NAME_ENTRY_create_by_OBJ(), X509_NAME_ENTRY_create_by_NID() et X509_NAME_ENTRY_set_data() sont rarement utilisés en pratique car les structures X509_NAME_ENTRY font presque toujours partie de structures X509_NAME et les fonctions X509_NAME correspondantes sont typiquement utilisées pour créer et ajouter de nouvelles entrées en une seule opération.

Les arguments de ces fonctions prennent en charge des options similaires à celles des fonctions X509_NAME de nom similaire, telles que X509_NAME_add_entry_by_txt(). Ainsi, par exemple, type peut être défini sur MBSTRING_ASC, mais dans le cas de X509_set_data(), le nom du champ doit être défini au préalable afin que les informations du champ pertinent puissent être recherchées en interne.

VALEURS DE RETOUR

X509_NAME_ENTRY_get_object() retourne une structure ASN1_OBJECT valide si elle est définie ou NULL en cas d'erreur.

X509_NAME_ENTRY_get_data() retourne une structure ASN1_STRING valide si elle est définie ou NULL en cas d'erreur.

X509_NAME_ENTRY_set_object() et X509_NAME_ENTRY_set_data() retournent 1 en cas de succès ou 0 en cas d'erreur.

X509_NAME_ENTRY_create_by_txt(), X509_NAME_ENTRY_create_by_NID() et X509_NAME_ENTRY_create_by_OBJ() retournent une structure X509_NAME_ENTRY valide en cas de succès ou NULL en cas d'erreur.
