X509_REQ_get_extensions(3ssl)

Paquet: openssl

Licences: Apache-2.0

X509_REQ_GET_EXTENSIONS(3ssl) OpenSSL X509_REQ_GET_EXTENSIONS(3ssl)

NOM

X509_REQ_get_extensions, X509_REQ_add_extensions, X509_REQ_add_extensions_nid - gérer les attributs d'extension X.509 d'une CSR

SYNTAXE

#include <openssl/x509.h>
STACK_OF(X509_EXTENSION) *X509_REQ_get_extensions(const X509_REQ *req);
int X509_REQ_add_extensions(X509_REQ *req, const STACK_OF(X509_EXTENSION) *exts);
int X509_REQ_add_extensions_nid(X509_REQ *req,
                                const STACK_OF(X509_EXTENSION) *exts, int nid);

DESCRIPTION

X509_REQ_get_extensions() renvoie la première liste d'extensions X.509 trouvées dans les attributs de req. La liste renvoyée est vide s'il n'y a pas de telles extensions dans req. L'appelant est responsable de la libération de la liste obtenue.

X509_REQ_add_extensions_nid() ajoute à req une liste d'extensions X.509 exts, en utilisant nid pour identifier l'attribut d'extensions. req n'est pas modifié si exts est NULL ou une liste vide. Cette fonction peut être appelée plusieurs fois sur le même req et nid. Dans ce cas, les extensions précédentes sont augmentées, où une extension à ajouter qui a le même OID qu'une extension préexistante remplace cette dernière.

X509_REQ_add_extensions() est similaire à X509_REQ_add_extensions_nid(), sauf que le NID_ext_req par défaut est utilisé.

VALEURS DE RETOUR

X509_REQ_get_extensions() renvoie un pointeur vers STACK_OF(X509_EXTENSION) ou NULL en cas d'erreur.

X509_REQ_add_extensions() et X509_REQ_add_extensions_nid() renvoient 1 en cas de succès, 0 en cas d'erreur.
