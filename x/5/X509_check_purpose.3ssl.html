X509_check_purpose(3ssl)

NOM

X509_check_purpose, X509_PURPOSE_get_count, X509_PURPOSE_get_unused_id, X509_PURPOSE_get_by_sname, X509_PURPOSE_get_by_id, X509_PURPOSE_add, X509_PURPOSE_cleanup, X509_PURPOSE_get0, X509_PURPOSE_get_id, X509_PURPOSE_get0_name, X509_PURPOSE_get0_sname, X509_PURPOSE_get_trust, X509_PURPOSE_set - fonctions liées à la vérification de l'objectif d'un certificat

SYNTAXE

#include <openssl/x509v3.h>
int X509_check_purpose(X509 *x, int id, int ca);
int X509_PURPOSE_get_count(void);
int X509_PURPOSE_get_unused_id(OSSL_LIB_CTX *libctx);
int X509_PURPOSE_get_by_sname(const char *sname);
int X509_PURPOSE_get_by_id(int id);
int X509_PURPOSE_add(int id, int trust, int flags,
                     int (*ck) (const X509_PURPOSE *, const X509 *, int),
                     const char *name, const char *sname, void *arg);
void X509_PURPOSE_cleanup(void);
X509_PURPOSE *X509_PURPOSE_get0(int idx);
int X509_PURPOSE_get_id(const X509_PURPOSE *);
char *X509_PURPOSE_get0_name(const X509_PURPOSE *xp);
char *X509_PURPOSE_get0_sname(const X509_PURPOSE *xp);
int X509_PURPOSE_get_trust(const X509_PURPOSE *xp);
int X509_PURPOSE_set(int *p, int purpose);

DESCRIPTION

X509_check_purpose() vérifie si le certificat x a été créé dans le but représenté par id. Si ca est non nul, alors le certificat x est vérifié pour déterminer s'il s'agit d'une CA possible avec divers niveaux de certitude potentiellement retournés. Le certificat x doit être un certificat complet, sinon la fonction retourne une erreur.

Voici les ID potentiels qui peuvent être vérifiés :

# define X509_PURPOSE_SSL_CLIENT        1
# define X509_PURPOSE_SSL_SERVER        2
# define X509_PURPOSE_NS_SSL_SERVER     3
# define X509_PURPOSE_SMIME_SIGN        4
# define X509_PURPOSE_SMIME_ENCRYPT     5
# define X509_PURPOSE_CRL_SIGN          6
# define X509_PURPOSE_ANY               7
# define X509_PURPOSE_OCSP_HELPER       8
# define X509_PURPOSE_TIMESTAMP_SIGN    9
# define X509_PURPOSE_CODE_SIGN        10

Les vérifications effectuées tiennent compte des extensions X.509 keyUsage, extendedKeyUsage et basicConstraints.

X509_PURPOSE_get_count() retourne le nombre d'objectifs actuellement définis.

X509_PURPOSE_get_unused_id() retourne le plus petit ID d'objectif non encore utilisé, qui est garanti unique et supérieur à X509_PURPOSE_MAX. Le paramètre libctx doit être utilisé pour fournir le contexte de la bibliothèque. Il est actuellement ignoré car la table de mappage des objectifs est globale.

X509_PURPOSE_get_by_sname() retourne l'indice de l'objectif avec le nom court donné ou -1 s'il n'est pas trouvé.

X509_PURPOSE_get_by_id() retourne l'indice de l'objectif avec l'ID donné ou -1 s'il n'est pas trouvé.

X509_PURPOSE_add() ajoute ou modifie une entrée d'objectif identifiée par sname. Sauf si l'ID reste le même pour une entrée existante, id doit être nouveau, ce qui peut être obtenu en utilisant le résultat de X509_PURPOSE_get_unused_id(). La fonction définit également dans l'entrée l'ID de confiance trust, les flags donnés, le nom (long) de l'objectif name, le nom court sname, la fonction de vérification d'objectif ck de type int (*) (const X509_PURPOSE *, const X509 *, int), et ses données utilisateur arg qui peuvent être récupérées via le pointeur X509_PURPOSE.

X509_PURPOSE_cleanup() supprime tous les objectifs qui ne sont pas prédéfinis.

X509_PURPOSE_get0() retourne un pointeur X509_PURPOSE ou NULL en cas d'erreur.

X509_PURPOSE_get_id() retourne l'ID de la structure X509_PURPOSE donnée.

X509_PURPOSE_get0_name() retourne le nom (long) de X509_PURPOSE donné.

X509_PURPOSE_get0_sname() retourne le nom court de X509_PURPOSE donné.

X509_PURPOSE_get_trust() retourne l'ID de confiance de X509_PURPOSE donné.

X509_PURPOSE_set() assigne l'ID d'objectif purpose donné à l'emplacement pointé par p. Ceci réinitialise à l'objectif 'any' si purpose est X509_PURPOSE_DEFAULT_ANY.

VALEURS DE RETOUR

X509_check_purpose() retourne les valeurs suivantes. Pour les vérifications non-CA

-1 une condition d'erreur s'est produite
1 si le certificat a été créé pour accomplir l'objectif représenté par id
0 si le certificat n'a pas été créé pour accomplir l'objectif représenté par id

Pour les vérifications de CA, les entiers ci-dessous pourraient être retournés avec les significations suivantes :

-1 une condition d'erreur s'est produite
0 pas une CA ou n'a pas l'objectif représenté par id
1 est une CA.
2 Seulement possible dans les anciennes versions d'openSSL lorsque basicConstraints est absent. Les nouvelles versions ne retourneront pas cette valeur. Peut être une CA
3 basicConstraints absent mais V1 auto-signé.
4 basicConstraints absent mais keyUsage présent et keyCertSign affirmé.
5 Anciens flags de CA spécifiques à Netscape présents

X509_PURPOSE_get_count() retourne le nombre d'objectifs actuellement définis.

X509_PURPOSE_get_unused_id() retourne le plus petit ID d'objectif non encore utilisé.

X509_PURPOSE_get_by_sname() retourne l'indice de l'objectif avec le nom court donné ou -1 s'il n'est pas trouvé.

X509_PURPOSE_get_by_id() retourne l'indice de l'objectif avec l'ID donné ou -1 s'il n'est pas trouvé.

int X509_PURPOSE_add() retourne 1 en cas de succès, 0 en cas d'erreur.

X509_PURPOSE_cleanup() ne retourne rien.

X509_PURPOSE_get0() retourne un pointeur X509_PURPOSE ou NULL en cas d'erreur.

X509_PURPOSE_get_id() retourne l'ID de la structure X509_PURPOSE donnée.

X509_PURPOSE_get0_name() retourne le nom (long) de X509_PURPOSE donné.

X509_PURPOSE_get0_sname() retourne le nom court de X509_PURPOSE donné.

X509_PURPOSE_get_trust() retourne l'ID de confiance de X509_PURPOSE donné.

X509_PURPOSE_set() retourne 1 en cas de succès, 0 en cas d'erreur.

BOGUES

L'implémentation de X509_PURPOSE n'est pas encore thread-safe. Il peut y avoir des conditions de concurrence lors de la récupération des informations sur les objectifs pendant que X509_PURPOSE_add() ou X509_PURPOSE_cleanup(void) est appelée.

HISTORIQUE

X509_PURPOSE_get_unused_id() a été ajouté dans OpensSL 3.5.
