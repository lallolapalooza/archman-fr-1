X509_sign(3ssl)

Paquet: openssl

Licences: Apache-2.0

X509_SIGN(3ssl) OpenSSL X509_SIGN(3ssl)

NOM

X509_sign, X509_sign_ctx, X509_REQ_sign, X509_REQ_sign_ctx, X509_ACERT_sign, X509_ACERT_sign_ctx, X509_CRL_sign, X509_CRL_sign_ctx - signer un certificat, une demande de certificat ou une signature de CRL

SYNTAXE

#include <openssl/x509.h>
int X509_sign(X509 *x, EVP_PKEY *pkey, const EVP_MD *md);
int X509_sign_ctx(X509 *x, EVP_MD_CTX *ctx);
int X509_REQ_sign(X509_REQ *x, EVP_PKEY *pkey, const EVP_MD *md);
int X509_REQ_sign_ctx(X509_REQ *x, EVP_MD_CTX *ctx);
int X509_CRL_sign(X509_CRL *x, EVP_PKEY *pkey, const EVP_MD *md);
int X509_CRL_sign_ctx(X509_CRL *x, EVP_MD_CTX *ctx);
#include <openssl/x509_acert.h>
int X509_ACERT_sign(X509_ACERT *x, EVP_PKEY *pkey, const EVP_MD *md);
int X509_ACERT_sign_ctx(X509_ACERT *x, EVP_MD_CTX *ctx);

DESCRIPTION

X509_sign() signe le certificat x en utilisant la clé privée pkey et le résumé de message md, et définit la signature dans x. X509_sign_ctx() signe également le certificat x mais utilise les paramètres contenus dans le contexte de résumé ctx. Si les informations du certificat incluent des extensions X.509, ces deux fonctions assurent que le certificat porte la version 3 de X.509.

X509_REQ_sign(), X509_REQ_sign_ctx(), X509_ACERT_sign(), X509_ACERT_sign_ctx(), X509_CRL_sign() et X509_CRL_sign_ctx() signent respectivement les demandes de certificat et les CRL.

NOTES

X509_sign_ctx() est utilisé lorsque les paramètres par défaut pour la clé publique et le résumé correspondants ne conviennent pas. Il peut être utilisé pour signer des clés en utilisant RSA-PSS, par exemple.

Pour des raisons d'efficacité et pour contourner les problèmes d'encodage ASN.1, l'encodage de la partie signée d'un certificat, d'une demande de certificat et d'une CRL est mis en cache en interne. Si la partie signée de la structure est modifiée, l'encodage n'est pas toujours mis à jour, ce qui signifie qu'une version obsolète est parfois utilisée. Ce n'est normalement pas un problème, car la modification de la partie signée invaliderait la signature et la signature mettrait toujours à jour l'encodage.

VALEUR DE RETOUR

Toutes les fonctions retournent la taille de la signature en octets en cas de succès et zéro en cas d'échec.

VOIR AUSSI

ERR_get_error(3), X509_NAME_add_entry_by_txt(3), X509_new(3), X509_verify_cert(3), X509_verify(3), X509_REQ_verify_ex(3), X509_REQ_verify(3), X509_CRL_verify(3)

HISTORIQUE

Les fonctions X509_sign(), X509_REQ_sign() et X509_CRL_sign() sont disponibles dans toutes les versions d'OpenSSL.

Les fonctions X509_sign_ctx(), X509_REQ_sign_ctx() et X509_CRL_sign_ctx() ont été ajoutées dans OpenSSL 1.0.1.

Les fonctions X509_ACERT_sign() et X509_ACERT_sign_ctx() ont été ajoutées dans OpenSSL 3.4.
