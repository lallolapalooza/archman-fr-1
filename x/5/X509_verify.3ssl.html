X509_verify(3ssl)

Paquet: openssl

Licences: Apache-2.0

X509_VERIFY(3ssl) OpenSSL X509_VERIFY(3ssl)

NOM

X509_verify, X509_self_signed, X509_REQ_verify_ex, X509_REQ_verify, X509_CRL_verify, X509_ACERT_verify - vérifier la signature d'un certificat, d'une requête de certificat ou d'une CRL

SYNTAXE

#include <openssl/x509.h>
int X509_verify(X509 *x, EVP_PKEY *pkey);
int X509_self_signed(X509 *cert, int verify_signature);
int X509_REQ_verify_ex(X509_REQ *a, EVP_PKEY *pkey, OSSL_LIB_CTX *libctx,
                       const char *propq);
int X509_REQ_verify(X509_REQ *a, EVP_PKEY *r);
int X509_CRL_verify(X509_CRL *a, EVP_PKEY *r);
#include <openssl/x509_acert.h>
int X509_ACERT_verify(X509_CRL *a, EVP_PKEY *r);

DESCRIPTION

X509_verify() vérifie la signature du certificat x en utilisant la clé publique pkey. Seule la signature est vérifiée : aucune autre vérification (telle que la validité de la chaîne de certificats) n'est effectuée.

X509_self_signed() vérifie si le certificat cert est auto-signé. Pour que cela réussisse, les noms de l'émetteur et du sujet doivent correspondre, les composants de l'identifiant de clé d'autorité (s'il est présent) doivent correspondre à l'identifiant de clé du sujet, etc. La signature elle-même n'est réellement vérifiée que si verify_signature est à 1, car pour les certificats explicitement approuvés, cette vérification ne vaut pas l'effort.

X509_REQ_verify_ex(), X509_REQ_verify(), X509_CRL_verify() et X509_ACERT_verify() vérifient les signatures des requêtes de certificat, des CRL et des certificats d'attribut respectivement.

VALEURS DE RETOUR

X509_verify(), X509_REQ_verify_ex(), X509_REQ_verify() et X509_CRL_verify() retournent 1 si la signature est valide et 0 si la vérification de la signature échoue. Si la signature n'a pas pu être vérifiée du tout parce qu'elle était mal formée, que le certificat ou la requête était incomplet(e) ou qu'une autre erreur s'est produite, alors -1 est retourné.

X509_self_signed() retourne les mêmes valeurs, mais retourne également 1 si tous les champs respectifs correspondent et que verify_signature est à 0.

HISTORIQUE

Les fonctions X509_verify(), X509_REQ_verify(), et X509_CRL_verify() sont disponibles dans toutes les versions d'OpenSSL.

X509_REQ_verify_ex() et X509_self_signed() ont été ajoutées dans OpenSSL 3.0.

X509_ACERT_verify() a été ajoutée dans OpenSSL 3.4.
