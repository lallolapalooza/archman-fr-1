X509_get0_notBefore(3ssl)

Paquet: openssl

Licences: Apache-2.0

X509_GET0_NOTBEFORE(3ssl) OpenSSL X509_GET0_NOTBEFORE(3ssl)

NOM

X509_get0_notBefore, X509_getm_notBefore, X509_get0_notAfter, X509_getm_notAfter, X509_set1_notBefore, X509_set1_notAfter, X509_ACERT_get0_notBefore, X509_ACERT_get0_notAfter, X509_ACERT_set1_notBefore, X509_ACERT_set1_notAfter, X509_CRL_get0_lastUpdate, X509_CRL_get0_nextUpdate, X509_CRL_set1_lastUpdate, X509_CRL_set1_nextUpdate - obtenir ou définir les dates de certificat ou CRL

SYNOPSIS

#include <openssl/x509.h>
const ASN1_TIME *X509_get0_notBefore(const X509 *x);
const ASN1_TIME *X509_get0_notAfter(const X509 *x);
ASN1_TIME *X509_getm_notBefore(const X509 *x);
ASN1_TIME *X509_getm_notAfter(const X509 *x);
int X509_set1_notBefore(X509 *x, const ASN1_TIME *tm);
int X509_set1_notAfter(X509 *x, const ASN1_TIME *tm);
const ASN1_GENERALIZEDTIME *X509_ACERT_get0_notBefore(const X509 *x);
const ASN1_GENERALIZEDTIME *X509_ACERT_get0_notAfter(const X509 *x);
int X509_ACERT_set1_notBefore(X509_ACERT *x, const ASN1_GENERALIZEDTIME *tm);
int X509_ACERT_set1_notAfter(X509_ACERT *x, const ASN1_GENERALIZEDTIME *tm);
const ASN1_TIME *X509_CRL_get0_lastUpdate(const X509_CRL *crl);
const ASN1_TIME *X509_CRL_get0_nextUpdate(const X509_CRL *crl);
int X509_CRL_set1_lastUpdate(X509_CRL *x, const ASN1_TIME *tm);
int X509_CRL_set1_nextUpdate(X509_CRL *x, const ASN1_TIME *tm);

DESCRIPTION

X509_get0_notBefore() et X509_get0_notAfter() retournent respectivement les champs notBefore et notAfter du certificat x. La valeur retournée est un pointeur interne qui ne doit pas être libéré après l'appel. x NE DOIT PAS être NULL.

X509_getm_notBefore() et X509_getm_notAfter() sont similaires à X509_get0_notBefore() et X509_get0_notAfter() sauf qu'elles retournent des références mutables non constantes aux champs de date associés du certificat.

X509_set1_notBefore() et X509_set1_notAfter() définissent les champs notBefore et notAfter de x à tm. La propriété du paramètre passé tm n'est pas transférée par ces fonctions, il doit donc être libéré après l'appel.

X509_ACERT_get0_notBefore() et X509_ACERT_get0_notAfter() retournent respectivement les champs notBefore et notAfter du certificat x. La valeur retournée est un pointeur interne qui ne doit pas être libéré après l'appel.

X509_ACERT_set1_notBefore() et X509_ACERT_set1_notAfter() définissent les champs notBefore et notAfter de x à tm. La propriété du paramètre passé tm n'est pas transférée par ces fonctions, il doit donc être libéré après l'appel.

X509_CRL_get0_lastUpdate() et X509_CRL_get0_nextUpdate() retournent les champs lastUpdate et nextUpdate de crl. La valeur retournée est un pointeur interne qui ne doit pas être libéré après l'appel. Si le champ nextUpdate est absent de crl, NULL est retourné.

X509_CRL_set1_lastUpdate() et X509_CRL_set1_nextUpdate() définissent les champs lastUpdate et nextUpdate de crl à tm. La propriété du paramètre passé tm n'est pas transférée par ces fonctions, il doit donc être libéré après l'appel. Pour X509_CRL_set1_nextUpdate(), l'argument tm peut être NULL, ce qui implique la suppression du champ optionnel nextUpdate.

VALEURS DE RETOUR

X509_get0_notBefore(), X509_get0_notAfter() et X509_CRL_get0_lastUpdate() retournent un pointeur vers une structure ASN1_TIME.

X509_CRL_get0_lastUpdate() retourne un pointeur vers une structure ASN1_TIME ou NULL si le champ lastUpdate est absent.

X509_set1_notBefore(), X509_set1_notAfter(), X509_CRL_set1_lastUpdate() et X509_CRL_set1_nextUpdate() retournent 1 en cas de succès ou 0 en cas d'échec.

NOTES

Contrairement aux routines X509 et X509_CRL, les routines X509_ACERT utilisent le format ASN1_GENERALIZEDTIME au lieu de ASN1_TIME pour stocker les données temporelles.

HISTORIQUE

X509_get_notBefore() et X509_get_notAfter() ont été dépréciés dans OpenSSL 1.1.0.

X509_ACERT_get0_notBefore(), X509_ACERT_get0_notAfter(), X509_ACERT_set1_notBefore(), X509_ACERT_set1_notAfter() ont été ajoutés dans OpenSSL 3.4.
