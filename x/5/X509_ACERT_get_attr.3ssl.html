X509_ACERT_get_attr(3ssl)

Paquet: openssl

Licences: Apache-2.0

X509_ACERT_GET_ATTR(3ssl) OpenSSL X509_ACERT_GET_ATTR(3ssl)

NOM

X509_ACERT_get_attr, X509_ACERT_get_attr_by_NID, X509_ACERT_get_attr_by_OBJ, X509_ACERT_get_attr_count - Récupérer les attributs d'une structure X509_ACERT

SYNTAXE

#include <openssl/x509_acert.h>
X509_ATTRIBUTE *X509_ACERT_get_attr(const X509_ACERT *x, int loc);
int X509_ACERT_get_attr_by_NID(const X509_ACERT *x, int nid, int lastpos);
int X509_ACERT_get_attr_by_OBJ(const X509_ACERT *x, const ASN1_OBJECT *obj,
                               int lastpos);
int X509_ACERT_get_attr_count(const X509_ACERT *x);

DESCRIPTION

X509_ACERT_get0_attr() récupère le loc-ième X509_ATTRIBUTE d'une structure X509_ACERT x. X509_ACERT_get_attr_count() renvoie le nombre total d'attributs dans la structure X509_ACERT.

X509_ACERT_get_attr_by_NID() et X509_ACERT_get_attr_by_OBJ() récupèrent l'emplacement de l'attribut suivant correspondant à nid ou obj après lastpos. lastpos doit initialement être défini à -1. Si aucune autre entrée n'est trouvée, -1 est renvoyé. Si nid est invalide (ne correspond pas à un OID valide), -2 est renvoyé.

VALEUR DE RETOUR

X509_ACERT_get0_attr() renvoie un X509_ATTRIBUTE à partir d'un certificat d'attribut, ou NULL si l'attribut spécifié n'est pas trouvé.

X509_ACERT_get_attr_by_NID() et X509_ACERT_get_attr_by_OBJ() renvoient l'emplacement de l'attribut suivant demandé ou -1 s'il n'est pas trouvé. X509_ACERT_get_attr_by_NID() peut également renvoyer -2 si le NID fourni est invalide.

X509_ACERT_get_attr_count() renvoie le nombre d'attributs dans le certificat d'attribut donné.

HISTORIQUE

X509_ACERT_get0_attr(), X509_ACERT_get_attr_by_NID(), X509_ACERT_get_attr_by_OBJ() et X509_ACERT_get_attr_count() ont été ajoutés dans OpenSSL 3.4.
