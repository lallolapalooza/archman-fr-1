X509_EXTENSION_set_object(3ssl)

Paquet: openssl

Licences: Apache-2.0

X509_EXTENSION_SET_OBJECT(3ssl) OpenSSL X509_EXTENSION_SET_OBJECT(3ssl)

NOM

X509_EXTENSION_set_object, X509_EXTENSION_set_critical, X509_EXTENSION_set_data, X509_EXTENSION_create_by_NID, X509_EXTENSION_create_by_OBJ, X509_EXTENSION_get_object, X509_EXTENSION_get_critical, X509_EXTENSION_get_data - fonctions utilitaires d'extension

SYNOPIS

int X509_EXTENSION_set_object(X509_EXTENSION *ex, const ASN1_OBJECT *obj);
int X509_EXTENSION_set_critical(X509_EXTENSION *ex, int crit);
int X509_EXTENSION_set_data(X509_EXTENSION *ex, ASN1_OCTET_STRING *data);
X509_EXTENSION *X509_EXTENSION_create_by_NID(X509_EXTENSION **ex,
                                             int nid, int crit,
                                             ASN1_OCTET_STRING *data);
X509_EXTENSION *X509_EXTENSION_create_by_OBJ(X509_EXTENSION **ex,
                                             const ASN1_OBJECT *obj, int crit,
                                             ASN1_OCTET_STRING *data);
ASN1_OBJECT *X509_EXTENSION_get_object(X509_EXTENSION *ex);
int X509_EXTENSION_get_critical(const X509_EXTENSION *ex);
ASN1_OCTET_STRING *X509_EXTENSION_get_data(X509_EXTENSION *ne);

DESCRIPTION

X509_EXTENSION_set_object() définit le type d'extension de ex à obj. Le pointeur obj est dupliqué en interne, donc obj doit être libéré après utilisation.

X509_EXTENSION_set_critical() définit la criticité de ex à crit. Si crit est zéro, l'extension est non critique, sinon elle est critique.

X509_EXTENSION_set_data() définit les données de l'extension ex à data. Le pointeur data est dupliqué en interne.

X509_EXTENSION_create_by_NID() crée une extension de type nid, de criticité crit, en utilisant les données data. L'extension créée est retournée et écrite dans *ex, en réutilisant ou en allouant une nouvelle extension si nécessaire. Ainsi, *ex doit être soit NULL, soit une structure X509_EXTENSION valide ; ce ne doit pas être un pointeur non initialisé.

X509_EXTENSION_create_by_OBJ() est identique à X509_EXTENSION_create_by_NID(), sauf qu'elle crée une extension en utilisant obj au lieu d'un NID.

X509_EXTENSION_get_object() retourne le type d'extension de ex sous forme de pointeur ASN1_OBJECT. Le pointeur retourné est une valeur interne qui ne doit pas être libérée.

X509_EXTENSION_get_critical() retourne la criticité de l'extension ex. Elle retourne 1 pour critique et 0 pour non critique.

X509_EXTENSION_get_data() retourne les données de l'extension ex. Le pointeur retourné est une valeur interne qui ne doit pas être libérée.

NOTES

Ces fonctions manipulent directement le contenu d'une extension. La plupart des applications souhaiteront analyser ou encoder et ajouter une extension : elles devraient plutôt utiliser les fonctions d'encodage et de décodage d'extension, telles que X509_add1_ext_i2d() et X509_get_ext_d2i().

Les données associées à une extension sont l'encodage de l'extension dans une structure ASN1_OCTET_STRING.

VALEUR DE RETOUR

X509_EXTENSION_set_object(), X509_EXTENSION_set_critical() et X509_EXTENSION_set_data() retournent 1 en cas de succès et 0 en cas d'échec.

X509_EXTENSION_create_by_NID() et X509_EXTENSION_create_by_OBJ() retournent un pointeur X509_EXTENSION ou NULL en cas d'erreur.

X509_EXTENSION_get_object() retourne un pointeur ASN1_OBJECT.

X509_EXTENSION_get_critical() retourne 0 pour non critique et 1 pour critique.

X509_EXTENSION_get_data() retourne un pointeur ASN1_OCTET_STRING.
