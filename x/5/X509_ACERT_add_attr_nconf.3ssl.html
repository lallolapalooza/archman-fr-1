X509_ACERT_add_attr_nconf(3ssl)

NOM

X509_ACERT_add_attr_nconf - Ajoute des attributs à X509_ACERT à partir d'une section de configuration

SYNTAXE

#include <openssl/x509_acert.h>
int X509_ACERT_add_attr_nconf(CONF *conf, const char *section,
                              X509_ACERT *acert);

DESCRIPTION

X509_ACERT_add_attr_nconf() ajoute un ou plusieurs X509_ATTRIBUTEs à la structure X509_ACERT existante acert. Les attributs sont lus à partir d'une section de l'objet conf.

La section de configuration donnée doit contenir des descriptions d'attributs de la forme :

nom_attribut = valeur

Le format de la valeur variera en fonction du nom_attribut. La valeur peut être une chaîne de caractères ou un objet ASN1_TYPE.

Pour encoder un objet ASN1_TYPE, utilisez le préfixe "ASN1:" suivi de la description de l'objet qui utilise la même syntaxe que ASN1_generate_nconf(3). Par exemple :

id-aca-group = ASN1:SEQUENCE:ietfattr
[ietfattr]
values = SEQUENCE:groups
[groups]
1.string = UTF8:mygroup1

VALEURS DE RETOUR

X509_ACERT_add_attr_nconf() retourne 1 en cas de succès et 0 en cas d'échec.

VOIR AUSSI

ASN1_generate_nconf(3).

HISTORIQUE

La fonction X509_ACERT_add_attr_nconf() a été ajoutée dans OpenSSL 3.4.
