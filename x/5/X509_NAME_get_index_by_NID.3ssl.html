X509_NAME_get_index_by_NID(3ssl)

Paquet: openssl

Licences: Apache-2.0

X509_NAME_GET_INDEX_BY_NID(3ssl) OpenSSL X509_NAME_GET_INDEX_BY_NID(3ssl)

NOM

X509_NAME_get_index_by_NID, X509_NAME_get_index_by_OBJ, X509_NAME_get_entry, X509_NAME_entry_count, X509_NAME_get_text_by_NID, X509_NAME_get_text_by_OBJ - Fonctions de recherche et d'énumération X509_NAME

SYNTAXE

#include <openssl/x509.h>
int X509_NAME_get_index_by_NID(const X509_NAME *name, int nid, int lastpos);
int X509_NAME_get_index_by_OBJ(const X509_NAME *name,
                               const ASN1_OBJECT *obj, int lastpos);
int X509_NAME_entry_count(const X509_NAME *name);
X509_NAME_ENTRY *X509_NAME_get_entry(const X509_NAME *name, int loc);
int X509_NAME_get_text_by_NID(const X509_NAME *name, int nid,
                              char *buf, int len);
int X509_NAME_get_text_by_OBJ(const X509_NAME *name, const ASN1_OBJECT *obj,
                              char *buf, int len);

DESCRIPTION

Ces fonctions permettent d'examiner une structure X509_NAME. La structure X509_NAME est identique au type Name défini dans la RFC 5280 (et ailleurs) et utilisé par exemple pour les noms de sujet et d'émetteur de certificat.

X509_NAME_get_index_by_NID() et X509_NAME_get_index_by_OBJ() récupèrent l'indice suivant correspondant à nid ou obj après lastpos. lastpos doit être initialisé à -1. S'il n'y a plus d'entrées, -1 est retourné. Si nid est invalide (ne correspond pas à un OID valide), alors -2 est retourné.

X509_NAME_entry_count() retourne le nombre total d'entrées dans name.

X509_NAME_get_entry() récupère l'X509_NAME_ENTRY depuis name correspondant à l'indice loc. Les valeurs acceptables pour loc vont de 0 à (X509_NAME_entry_count(name) - 1). La valeur retournée est un pointeur interne qui ne doit pas être libéré.

X509_NAME_get_text_by_NID() et X509_NAME_get_text_by_OBJ() récupèrent le « texte » de la première entrée dans name qui correspond à nid ou obj. Si aucune entrée correspondante n'existe, -1 est retourné. Au plus len octets seront écrits et le texte écrit dans buf sera terminé par un null. La longueur de la chaîne de sortie écrite est retournée, excluant le null de terminaison. Si buf est <NULL>, alors la quantité d'espace nécessaire dans buf (excluant le null final) est retournée.

NOTES

X509_NAME_get_text_by_NID() et X509_NAME_get_text_by_OBJ() devraient être considérées comme obsolètes car elles présentent diverses limitations qui les rendent d'une utilité minimale en pratique. Elles ne peuvent trouver que la première entrée correspondante et copient le contenu du champ verbatim : cela peut être très déroutant si la cible est un type de chaîne à plusieurs caractères comme un BMPString ou un UTF8String.

Pour une solution plus générale, il convient d'utiliser X509_NAME_get_index_by_NID() ou X509_NAME_get_index_by_OBJ() suivi de X509_NAME_get_entry() sur tous les indices correspondants, puis d'utiliser les différentes fonctions utilitaires X509_NAME_ENTRY sur le résultat.

La liste de tous les codes NID_* et OBJ_* pertinents peut être trouvée dans les fichiers d'en-tête du code source <openssl/obj_mac.h> et/ou <openssl/objects.h>.

Les applications qui pourraient passer des NIDs invalides à X509_NAME_get_index_by_NID() devraient vérifier la valeur de retour de -2. Alternativement, la validité du NID peut être déterminée en vérifiant au préalable si OBJ_nid2obj(nid) n'est pas NULL.

VALEURS DE RETOUR

X509_NAME_get_index_by_NID() et X509_NAME_get_index_by_OBJ() retournent l'indice de la prochaine entrée correspondante ou -1 si elle n'est pas trouvée. X509_NAME_get_index_by_NID() peut également retourner -2 si le NID fourni est invalide.

X509_NAME_entry_count() retourne le nombre total d'entrées, et 0 en cas d'échec.

X509_NAME_get_entry() retourne un pointeur X509_NAME vers l'entrée demandée ou NULL si l'indice est invalide.

EXEMPLES

Traiter toutes les entrées :

int i;
X509_NAME_ENTRY *e;
for (i = 0; i < X509_NAME_entry_count(nm); i++) {
    e = X509_NAME_get_entry(nm, i);
    /* Faire quelque chose avec e */
}

Traiter toutes les entrées commonName :

int lastpos = -1;
X509_NAME_ENTRY *e;
for (;;) {
    lastpos = X509_NAME_get_index_by_NID(nm, NID_commonName, lastpos);
    if (lastpos == -1)
        break;
    e = X509_NAME_get_entry(nm, lastpos);
    /* Faire quelque chose avec e */
}
