Paquet: openssl

Licences: Apache-2.0

X509_NEW(3ssl) OpenSSL X509_NEW(3ssl)

NOM

X509_new, X509_new_ex, X509_free, X509_up_ref, X509_chain_up_ref, OSSL_STACK_OF_X509_free - Fonctions d'allocation et de désallocation ASN1 pour les certificats X509

SYNOPSIS

#include <openssl/x509.h>
X509 *X509_new(void);
X509 *X509_new_ex(OSSL_LIB_CTX *libctx, const char *propq);
void X509_free(X509 *a);
int X509_up_ref(X509 *a);
STACK_OF(X509) *X509_chain_up_ref(STACK_OF(X509) *x);
void OSSL_STACK_OF_X509_free(STACK_OF(X509) *certs);

DESCRIPTION

Les routines d'allocation ASN1 pour X509 allouent et libèrent une structure X509, qui représente un certificat X509.

X509_new_ex() alloue et initialise une structure X509 avec un contexte de bibliothèque libctx, une requête de propriété propq et un compteur de références de 1. De nombreuses fonctions X509 telles que X509_check_purpose() et X509_verify() utilisent ce contexte de bibliothèque pour sélectionner les fournisseurs qui fournissent les algorithmes récupérés (SHA1 est utilisé en interne). Cet objet X509 créé peut ensuite être utilisé lors du chargement de données binaires à l'aide de d2i_X509().

X509_new() est similaire à X509_new_ex() mais définit le contexte de bibliothèque et la requête de propriété à NULL. Cela entraîne l'utilisation du contexte de bibliothèque par défaut (NULL) pour toutes les opérations X509 nécessitant la récupération d'algorithmes.

X509_free() décrémente le compteur de références de la structure X509 a et la libère si le compteur de références est zéro. Si l'argument est NULL, rien n'est fait.

X509_up_ref() incrémente le compteur de références de a.

X509_chain_up_ref() augmente le compteur de références de tous les certificats de la chaîne x et renvoie une copie de la pile, ou une pile vide si a est NULL.

OSSL_STACK_OF_X509_free() désalloue la liste donnée de pointeurs vers les certificats après avoir appelé X509_free() sur tous ses éléments. Si l'argument est NULL, rien n'est fait.

NOTES

La fonction X509_up_ref() est utile si une structure de certificat est utilisée par plusieurs opérations différentes, chacune la libérant après utilisation : cela évite d'avoir à dupliquer toute la structure du certificat.

La fonction X509_chain_up_ref() ne fait pas que mettre à jour le compteur de références de chaque certificat. Elle renvoie également une copie de la pile, en utilisant sk_X509_dup(), mais elle sert un but similaire : la chaîne renvoyée persiste après la libération de l'originale.

VALEURS DE RETOUR

Si l'allocation échoue, X509_new() renvoie NULL et définit un code d'erreur qui peut être obtenu par ERR_get_error(3). Sinon, il renvoie un pointeur vers la structure nouvellement allouée.

X509_up_ref() renvoie 1 en cas de succès et 0 en cas d'échec.

X509_chain_up_ref() renvoie une copie de la pile ou NULL si une erreur s'est produite.

OSSL_STACK_OF_X509_free() n'a pas de valeur de retour.
