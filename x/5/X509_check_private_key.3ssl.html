X509_check_private_key(3ssl)

Paquet: openssl

Licences: Apache-2.0

X509_CHECK_PRIVATE_KEY(3ssl) OpenSSL X509_CHECK_PRIVATE_KEY(3ssl)

NOM

X509_check_private_key, X509_REQ_check_private_key - vérifier la cohérence d'une clé privée avec la clé publique dans un certificat X509 ou une demande de certificat

SYNTAXE

#include <openssl/x509.h>
int X509_check_private_key(const X509 *cert, EVP_PKEY *pkey);
int X509_REQ_check_private_key(X509_REQ *req, EVP_PKEY *pkey);

DESCRIPTION

La fonction X509_check_private_key() vérifie la cohérence de la clé privée pkey avec la clé publique dans cert.

X509_REQ_check_private_key() est équivalent à X509_check_private_key() à ceci près que req représente une demande de certificat de structure X509_REQ.

VALEURS DE RETOUR

X509_check_private_key() et X509_REQ_check_private_key() retournent 1 si les clés correspondent, et 0 sinon.

Si la clé est invalide ou si une erreur s'est produite, le code d'erreur peut être obtenu en utilisant ERR_get_error(3).

BOGUES

Les fonctions X509_check_private_key() et X509_REQ_check_private_key() ne vérifient pas si pkey est effectivement une clé privée. Elles comparent simplement les éléments publics (par exemple, l'exposant et le module d'une clé RSA) et/ou les paramètres de clé (par exemple, les paramètres EC d'une clé EC) d'une paire de clés. Elles retournent donc également succès si pkey est une clé publique correspondante.

VOIR AUSSI

ERR_get_error(3)
