X509_ALGOR_dup(3ssl)

Paquet: openssl

Licences: Apache-2.0

X509_ALGOR_DUP(3ssl) OpenSSL X509_ALGOR_DUP(3ssl)

NOM

X509_ALGOR_dup, X509_ALGOR_set0, X509_ALGOR_get0, X509_ALGOR_set_md, X509_ALGOR_cmp, X509_ALGOR_copy - Fonctions AlgorithmIdentifier

SYNTAXE

#include <openssl/x509.h>
X509_ALGOR *X509_ALGOR_dup(X509_ALGOR *alg);
int X509_ALGOR_set0(X509_ALGOR *alg, ASN1_OBJECT *aobj, int ptype, void *pval);
void X509_ALGOR_get0(const ASN1_OBJECT **paobj, int *pptype,
                     const void **ppval, const X509_ALGOR *alg);
void X509_ALGOR_set_md(X509_ALGOR *alg, const EVP_MD *md);
int X509_ALGOR_cmp(const X509_ALGOR *a, const X509_ALGOR *b);
int X509_ALGOR_copy(X509_ALGOR *dest, const X509_ALGOR *src);

DESCRIPTION

X509_ALGOR_dup() retourne une copie de alg.

X509_ALGOR_set0() définit l'OID de l'algorithme de alg à aobj et le type de paramètre associé à ptype avec la valeur pval. Si ptype est V_ASN1_UNDEF le paramètre est omis, sinon ptype et pval ont la même signification que les paramètres type et value de ASN1_TYPE_set(). Tous les paramètres fournis sont utilisés en interne et ne doivent donc PAS être libérés après la réussite de cet appel ; sinon, la propriété reste au demandeur et alg reste inchangé.

X509_ALGOR_get0() est l'inverse de X509_ALGOR_set0() : il retourne l'OID de l'algorithme dans *paobj et le paramètre associé dans *pptype et *ppval depuis l'AlgorithmIdentifier alg.

X509_ALGOR_set_md() définit l'AlgorithmIdentifier alg aux valeurs appropriées pour le digest de message md.

X509_ALGOR_cmp() compare a et b et retourne 0 s'ils ont des codages identiques et non nul sinon.

X509_ALGOR_copy() copie les valeurs source dans les structures dest ; créant un duplicata de chacune (et libérant tout ce qui est pointé par *dest).

VALEURS DE RETOUR

X509_ALGOR_dup() retourne une structure valide X509_ALGOR ou NULL en cas d'erreur.

X509_ALGOR_set0() et X509_ALGOR_copy() retournent 1 en cas de succès ou 0 en cas d'erreur.

X509_ALGOR_get0() et X509_ALGOR_set_md() ne retournent aucune valeur.

X509_ALGOR_cmp() retourne 0 si les deux paramètres ont des codages identiques et non nul sinon.

HISTORIQUE

X509_ALGOR_copy() a été ajouté dans la version 1.1.1e.
