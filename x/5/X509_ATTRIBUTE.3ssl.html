DESCRIPTION

Les objets X509_ATTRIBUTE sont utilisés par de nombreuses normes, y compris X509, X509_REQ, PKCS12, PKCS8, PKCS7 et CMS.

L'objet X509_ATTRIBUTE est utilisé pour représenter l'attribut ASN.1 tel que défini dans la RFC 5280, c'est-à-dire :

Attribute ::= SEQUENCE {
  type             AttributeType,
  values    SET OF AttributeValue }
AttributeType ::= OBJECT IDENTIFIER
AttributeValue ::= ANY -- DEFINED BY AttributeType

Par exemple, CMS définit l'attribut signing-time comme :

id-signingTime OBJECT IDENTIFIER ::= { iso(1) member-body(2)
    us(840) rsadsi(113549) pkcs(1) pkcs9(9) 5 }
SigningTime ::= Time
Time ::= CHOICE {
  utcTime UTCTime,
  generalizedTime GeneralizedTime }

Dans OpenSSL, AttributeType est mappé sur un objet ASN1_OBJECT et AttributeValue sur une liste d'objets ASN1_TYPE.

Les fonctions suivantes sont utilisées pour les objets X509_ATTRIBUTE.

X509at_get_attr_by_OBJ() trouve l'emplacement du premier objet correspondant obj dans une liste d'attributs sk. La recherche commence à la position après lastpos. Si la valeur retournée est positive, elle peut être utilisée lors de l'appel suivant à X509at_get_attr_by_OBJ() comme valeur de lastpos afin d'itérer à travers les attributs restants. lastpos peut être défini sur n'importe quelle valeur négative lors du premier appel, afin de commencer la recherche depuis le début de la liste.

X509at_get_attr_by_NID() est similaire à X509at_get_attr_by_OBJ(), sauf qu'elle passe l'identifiant numérique (NID) nid associé à l'objet. Voir <openssl/obj_mac.h> pour une liste de NID_*.

X509at_get_attr() renvoie l'objet X509_ATTRIBUTE à l'indice loc dans la liste d'attributs x. loc doit être compris entre 0 et X509at_get_attr_count() - 1.

X509at_delete_attr() supprime l'objet X509_ATTRIBUTE à l'indice loc dans la liste d'attributs x.

X509at_add1_attr() ajoute une copie de l'objet X509_ATTRIBUTE passé à la liste x. x et attr doivent être non NULL, sinon une erreur se produira. Si *x est NULL, une nouvelle liste est créée, sinon la liste passée est utilisée. Une erreur se produira si un attribut existant (avec le même type d'attribut) existe déjà dans la liste d'attributs.

X509at_add1_attr_by_OBJ() crée un nouvel X509_ATTRIBUTE en utilisant X509_ATTRIBUTE_set1_object() et X509_ATTRIBUTE_set1_data() pour assigner un nouveau obj de type type et de données bytes de longueur len, puis l'ajoute à la liste d'attributs x. x et attr doivent être non NULL, sinon une erreur se produira. Si *x est NULL, une nouvelle liste d'attributs est créée. Si obj existe déjà dans la liste d'attributs, une erreur se produit.

X509at_add1_attr_by_NID() est similaire à X509at_add1_attr_by_OBJ(), sauf qu'elle passe l'identifiant numérique (NID) nid associé à l'objet. Voir <openssl/obj_mac.h> pour une liste de NID_*.

X509at_add1_attr_by_txt() est similaire à X509at_add1_attr_by_OBJ(), sauf qu'elle passe un nom attrname associé à l'objet. Voir <openssl/obj_mac.h> pour une liste de noms SN_*.

X509_ATTRIBUTE_set1_object() assigne un objet ASN1_OBJECT obj à l'attribut attr. Si attr contenait un ASN1_OBJECT existant, il est libéré. Une erreur se produit si attr ou obj sont NULL, ou si l'objet obj passé ne peut pas être dupliqué.

X509_ATTRIBUTE_set1_data() ajoute un nouvel objet ASN1_TYPE à la liste d'attributs attr. Le nouvel objet se voit assigner une copie des données dans data de taille len. Si attrtype a le drapeau MBSTRING_FLAG défini, une recherche dans la table utilisant le NID de l'attribut attr est utilisée pour définir une ASN1_STRING en utilisant ASN1_STRING_set_by_NID(), et les données data passées doivent être dans le format requis pour ce type d'objet, sinon une erreur se produira. Si len n'est pas -1, ASN1_STRING_type_new() est utilisé en interne avec attrtype passé. Si attrtype est 0, l'appel ne fait rien sauf renvoyer 1.

X509_ATTRIBUTE_create() crée un nouvel X509_ATTRIBUTE en utilisant le nid pour définir l'OID de ASN1_OBJECT et le atrtype et la value pour définir l'ASN1_TYPE.

X509_ATTRIBUTE_create_by_OBJ() utilise X509_ATTRIBUTE_set1_object() et X509_ATTRIBUTE_set1_data() pour assigner un nouvel obj de type atrtype et de données data de longueur len. Si l'attribut passé attr OU *attr est NULL, un nouvel X509_ATTRIBUTE sera renvoyé, sinon l'X509_ATTRIBUTE passé est utilisé. Notez que l'objet ASN1 obj est ajouté à la liste existante d'objets des attributs, ce qui pourrait poser problème si l'objet ASN1 de l'attribut était différent.

X509_ATTRIBUTE_create_by_NID() est similaire à X509_ATTRIBUTE_create_by_OBJ(), sauf qu'elle passe l'identifiant numérique (NID) nid associé à l'objet. Voir <openssl/obj_mac.h> pour une liste de NID_*.

X509_ATTRIBUTE_create_by_txt() est similaire à X509_ATTRIBUTE_create_par by_OBJ(), sauf qu'elle passe un nom atrname associé à l'objet. Voir <openssl/obj_mac.h> pour une liste de noms SN_*.

X509_ATTRIBUTE_count() renvoie le nombre d'objets ASN1_TYPE dans un attribut attr.

X509_ATTRIBUTE_get0_type() renvoie l'objet ASN1_TYPE à l'index idx dans la liste d'attributs attr. idx doit être compris entre 0 et X509_ATTRIBUTE_count() - 1, sinon une erreur se produira.

X509_ATTRIBUTE_get0_data() renvoie les données d'un objet ASN1_TYPE à l'index idx dans l'attribut attr. data est inutilisé et peut être défini à NULL. Une erreur se produira si le type d'attribut atrtype ne correspond pas au type de l'objet ASN1_TYPE à l'index idx OU si atrtype est V_ASN1_BOOLEAN ou V_ASN1_NULL OU si l'index idx n'est pas compris entre 0 et X509_ATTRIBUTE_count() - 1.

X509at_get0_data_by_OBJ() trouve le premier attribut dans une liste d'attributs x qui correspond à obj en commençant à l'index lastpos et renvoie les données récupérées du premier objet ASN1_TYPE des attributs trouvés. Une erreur se produira si le type d'attribut type ne correspond pas au type de l'objet ASN1_TYPE OU si type est soit V_ASN1_BOOLEAN soit V_ASN1_NULL OU si l'attribut n'est pas trouvé. Si lastpos est inférieur à -1, une erreur se produira s'il existe plusieurs objets dans la liste x qui correspondent à obj. Si lastpos est inférieur à -2, une erreur se produira s'il y a plus d'un objet ASN1_TYPE dans l'attribut trouvé.

VALEURS DE RETOUR

X509at_get_attr_count() renvoie le nombre d'attributs dans la liste x ou -1 si x est NULL.

X509at_get_attr_by_OBJ() renvoie -1 si la liste est vide OU si l'objet n'est pas trouvé, sinon elle renvoie la position de l'objet dans la liste.

X509at_get_attr_by_NID() est similaire à X509at_get_attr_by_OBJ(), sauf qu'elle renvoie -2 si le nid n'est pas connu par OpenSSL.

X509at_get_attr() renvoie soit un X509_ATTRIBUTE soit NULL en cas d'erreur.

X509at_delete_attr() renvoie soit l' X509_ATTRIBUTE supprimé soit NULL en cas d'erreur.

X509_ATTRIBUTE_count() renvoie -1 en cas d'erreur, sinon elle renvoie le nombre d'éléments ASN1_TYPE.

X509_ATTRIBUTE_get0_type() renvoie NULL en cas d'erreur, sinon elle renvoie un objet ASN1_TYPE.

X509_ATTRIBUTE_get0_data() renvoie NULL en cas d'erreur, sinon elle renvoie les données associées à un objet ASN1_TYPE.

X509_ATTRIBUTE_set1_object() et X509_ATTRIBUTE_set1_data() renvoient 1 en cas de succès, ou 0 sinon.

X509_ATTRIBUTE_create(), X509_ATTRIBUTE_create_by_OBJ(), X509_ATTRIBUTE_create_by_NID() et X509_ATTRIBUTE_create_by_txt() renvoient soit un X509_ATTRIBUTE en cas de succès, soit NULL en cas d'erreur.

X509at_add1_attr(), X509at_add1_attr_by_OBJ(), X509at_add1_attr_by_NID() et X509at_add1_attr_by_txt() renvoient NULL en cas d'erreur, sinon elles renvoient une liste d' X509_ATTRIBUTE.

X509at_get0_data_by_OBJ() renvoie les données récupérées du premier objet ASN1_TYPE des attributs trouvés, ou NULL en cas d'erreur.
