X509_STORE_new(3ssl)

Paquet: openssl

Licences: Apache-2.0

X509_STORE_NEW(3ssl) OpenSSL X509_STORE_NEW(3ssl)

NOM

X509_STORE_new, X509_STORE_up_ref, X509_STORE_free, X509_STORE_lock,X509_STORE_unlock - Fonctions d'allocation, de libération et de verrouillage de X509_STORE

SYNOPIS

#include <openssl/x509_vfy.h>
X509_STORE *X509_STORE_new(void);
void X509_STORE_free(X509_STORE *xs);
int X509_STORE_lock(X509_STORE *xs);
int X509_STORE_unlock(X509_STORE *xs);
int X509_STORE_up_ref(X509_STORE *xs);

DESCRIPTION

La fonction X509_STORE_new() retourne un nouveau X509_STORE.

X509_STORE_up_ref() incrémente le compteur de références associé à l'objet X509_STORE.

X509_STORE_lock() verrouille le magasin pour empêcher toute modification par d'autres fils d'exécution, X509_STORE_unlock() le déverrouille.

X509_STORE_free() libère un unique objet X509_STORE. Si l'argument est NULL, rien n'est fait.

VALEURS DE RETOUR

X509_STORE_new() retourne un X509_STORE nouvellement créé ou NULL si l'appel échoue.

X509_STORE_up_ref(), X509_STORE_lock() et X509_STORE_unlock() retournent 1 en cas de succès et 0 en cas d'échec.

X509_STORE_free() ne retourne pas de valeur.

VOIR AUSSI

X509_STORE_set_verify_cb_func(3) X509_STORE_get0_param(3)

HISTORIQUE

Les fonctions X509_STORE_up_ref(), X509_STORE_lock() et X509_STORE_unlock() ont été ajoutées dans OpenSSL 1.1.0.
