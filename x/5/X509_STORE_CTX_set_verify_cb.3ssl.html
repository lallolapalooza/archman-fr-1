DESCRIPTION

X509_STORE_CTX_set_verify_cb() définit le rappel de vérification de ctx à verify_cb, écrasant tout rappel existant.

Le rappel de vérification peut être utilisé pour personnaliser le fonctionnement de la vérification de certificat, par exemple en remplaçant les conditions d'erreur ou en journalisant les erreurs à des fins de débogage.

Cependant, un rappel de vérification n'est pas essentiel et le fonctionnement par défaut est souvent suffisant.

Le paramètre ok du rappel indique la valeur que le rappel doit renvoyer pour conserver le comportement par défaut. S'il est zéro, une condition d'erreur est indiquée. S'il est 1, aucune erreur ne s'est produite. Si le drapeau X509_V_FLAG_NOTIFY_POLICY est défini, ok est défini à 2 pour indiquer que la vérification de politique est terminée.

Le paramètre ctx du rappel est la structure X509_STORE_CTX qui effectue l'opération de vérification. Un rappel peut examiner cette structure et recevoir des informations supplémentaires sur l'erreur, par exemple en appelant X509_STORE_CTX_get_current_cert(). Des données supplémentaires de l'application peuvent être transmises au rappel via le mécanisme ex_data.

X509_STORE_CTX_print_verify_cb() est une fonction de rappel de vérification qui, lorsqu'une vérification de certificat a échoué, ajoute une entrée à la file d'attente d'erreurs avec le code X509_R_CERTIFICATE_VERIFICATION_FAILED et avec des détails de diagnostic, y compris les champs les plus pertinents du certificat cible qui n'a pas pu être vérifié et, le cas échéant, des certificats non approuvés et approuvés disponibles.

X509_STORE_CTX_get_verify_cb() renvoie la valeur du rappel actuel pour le ctx spécifique.

X509_STORE_CTX_get_get_issuer(), X509_STORE_CTX_get_check_issued(), X509_STORE_CTX_get_check_revocation(), X509_STORE_CTX_get_get_crl(), X509_STORE_CTX_get_check_crl(), X509_STORE_CTX_get_cert_crl(), X509_STORE_CTX_get_check_policy(), X509_STORE_CTX_get_lookup_certs(), X509_STORE_CTX_get_lookup_crls() et X509_STORE_CTX_get_cleanup() renvoient les pointeurs de fonction mis en cache à partir du X509_STORE correspondant, veuillez consulter X509_STORE_set_verify(3) pour plus d'informations.

X509_STORE_CTX_set_get_crl() définit la fonction pour obtenir le crl pour un certificat donné x. Lorsqu'il est trouvé, le crl doit être assigné à *crl. Cette fonction doit renvoyer 0 en cas d'échec et 1 en cas de succès. Si aucune fonction pour obtenir l'émetteur n'est fournie, la fonction interne par défaut sera utilisée à la place.

X509_STORE_CTX_set_current_reasons() est utilisée conjointement avec X509_STORE_CTX_get_crl_fn. Le rappel X509_STORE_CTX_get_crl_fn doit utiliser cette méthode pour définir la raison pour laquelle le certificat est invalide.

ATTENTION

En général, un rappel de vérification ne doit PAS renvoyer inconditionnellement 1 dans toutes les circonstances, car cela permettra à la vérification de réussir quelle que soit l'erreur. Cela supprime effectivement toute sécurité de l'application, car n'importe quel certificat (y compris ceux générés et non approuvés) sera accepté.

NOTES

Le rappel de vérification peut être défini et hérité de la structure parente effectuant l'opération. Dans certains cas (comme la vérification S/MIME), la structure X509_STORE_CTX est créée et détruite en interne et la seule façon de définir un rappel de vérification personnalisé est de l'hériter du X509_STORE associé.

VALEURS DE RETOUR

X509_STORE_CTX_set_verify_cb() ne renvoie pas de valeur.

EXEMPLES

Fonctionnement du rappel par défaut :

int verify_callback(int ok, X509_STORE_CTX *ctx) {
    return ok;
}

Exemple simple, supposons qu'un certificat dans la chaîne soit expiré et que nous souhaitions continuer après cette erreur :

int verify_callback(int ok, X509_STORE_CTX *ctx) {
    /* Tolérer l'expiration du certificat */
    if (X509_STORE_CTX_get_error(ctx) == X509_V_ERR_CERT_HAS_EXPIRED)
        return 1;
    /* Sinon, ne pas outrepasser */
    return ok;
}

Exemple plus complexe, nous ne souhaitons pas continuer après l'expiration d'un certificat, mais seulement dans un cas spécifique :

int verify_callback(int ok, X509_STORE_CTX *ctx)
{
    int err = X509_STORE_CTX_get_error(ctx);
    X509 *err_cert = X509_STORE_CTX_get_current_cert(ctx);
    if (err == X509_V_ERR_CERT_HAS_EXPIRED) {
        if (check_is_acceptable_expired_cert(err_cert)
            return 1;
    }
    return ok;
}

Rappel de journalisation complet. Dans ce cas, bio_err est supposé être un BIO de journalisation global, une alternative serait de stocker un BIO dans ctx en utilisant ex_data.

int verify_callback(int ok, X509_STORE_CTX *ctx)
{
    X509 *err_cert;
    int err, depth;
    err_cert = X509_STORE_CTX_get_current_cert(ctx);
    err = X509_STORE_CTX_get_error(ctx);
    depth = X509_STORE_CTX_get_error_depth(ctx);
    BIO_printf(bio_err, "depth=%d ", depth);
    if (err_cert) {
        X509_NAME_print_ex(bio_err, X509_get_subject_name(err_cert),
                           0, XN_FLAG_ONELINE);
        BIO_puts(bio_err, "\n");
    }
    else
        BIO_puts(bio_err, "<no cert>\n");
    if (!ok)
        BIO_printf(bio_err, "verify error:num=%d:%s\n", err,
                   X509_verify_cert_error_string(err));
    switch (err) {
    case X509_V_ERR_UNABLE_TO_GET_ISSUER_CERT:
        BIO_puts(bio_err, "issuer= ");
        X509_NAME_print_ex(bio_err, X509_get_issuer_name(err_cert),
                           0, XN_FLAG_ONELINE);
        BIO_puts(bio_err, "\n");
        break;
    case X509_V_ERR_CERT_NOT_YET_VALID:
    case X509_V_ERR_ERROR_IN_CERT_NOT_BEFORE_FIELD:
        BIO_printf(bio_err, "notBefore=");
        ASN1_TIME_print(bio_err, X509_get_notBefore(err_cert));
        BIO_printf(bio_err, "\n");
        break;
    case X509_V_ERR_CERT_HAS_EXPIRED:
    case X509_V_ERR_ERROR_IN_CERT_NOT_AFTER_FIELD:
        BIO_printf(bio_err, "notAfter=");
        ASN1_TIME_print(bio_err, X509_get_notAfter(err_cert));
        BIO_printf(bio_err, "\n");
        break;
    case X509_V_ERR_NO_EXPLICIT_POLICY:
        policies_print(bio_err, ctx);
        break;
    }
    if (err == X509_V_OK && ok == 2)
        /* print out policies */
    BIO_printf(bio_err, "verify return:%d\n", ok);
    return(ok);
}
