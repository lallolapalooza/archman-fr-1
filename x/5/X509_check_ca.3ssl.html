NOM

X509_check_ca - vérifier si un certificat donné est un certificat d'autorité (CA)

SYNTAXE

#include <openssl/x509v3.h>
int X509_check_ca(X509 *cert);

DESCRIPTION

Cette fonction vérifie si le certificat donné est un certificat d'autorité (CA) (peut être utilisé pour signer d'autres certificats). Le certificat doit être un certificat complet, sinon une erreur est retournée.

VALEURS DE RETOUR

La fonction retourne 0 s'il ne s'agit pas d'un certificat de CA, 1 s'il s'agit d'un certificat X509v3 de CA approprié avec l'extension basicConstraints CA:TRUE, 3 s'il s'agit d'un certificat auto-signé X509 v1, 4 s'il s'agit d'un certificat avec l'extension keyUsage et le bit keyCertSign défini, mais sans basicConstraints, et 5 s'il possède une extension obsolète Netscape Certificate Type indiquant qu'il s'agit d'un certificat de CA.

Cette fonction retournera également 0 en cas d'erreur.

En fait, toute valeur non nulle signifie que ce certificat aurait pu être utilisé pour signer d'autres certificats.

VOIR AUSSI

X509_verify_cert(3), X509_check_issued(3), X509_check_purpose(3)
