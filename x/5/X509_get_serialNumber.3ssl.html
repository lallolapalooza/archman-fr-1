X509_get_serialNumber(3ssl)

Paquet: openssl

Licences: Apache-2.0

X509_GET_SERIALNUMBER(3ssl) OpenSSL X509_GET_SERIALNUMBER(3ssl)

NOM

X509_get_serialNumber, X509_get0_serialNumber, X509_set_serialNumber, X509_ACERT_get0_serialNumber, X509_ACERT_set1_serialNumber - obtenir ou définir le numéro de série d'un certificat

SYNTAXE

#include <openssl/x509.h>
ASN1_INTEGER *X509_get_serialNumber(X509 *x);
const ASN1_INTEGER *X509_get0_serialNumber(const X509 *x);
int X509_set_serialNumber(X509 *x, ASN1_INTEGER *serial);
#include <openssl/x509_acert.h>
ASN1_INTEGER *X509_ACERT_get0_serialNumber(X509_ACERT *x);
int X509_ACERT_set1_serialNumber(X509_ACERT *x, ASN1_INTEGER *serial);

DESCRIPTION

X509_get_serialNumber() renvoie le numéro de série du certificat x sous forme de structure ASN1_INTEGER qui peut être examinée ou initialisée. La valeur renvoyée est un pointeur interne qui NE DOIT PAS être libérée après l'appel.

X509_get0_serialNumber() est identique à X509_get_serialNumber() à l'exception près qu'elle accepte un paramètre constant et renvoie un résultat constant.

X509_set_serialNumber() définit le numéro de série du certificat x à serial. Une copie du numéro de série est utilisée en interne, donc serial doit être libérée après utilisation.

X509_ACERT_get0_serialNumber() effectue la même opération que X509_get_serialNumber() pour les certificats d'attribut.

X509_ACERT_set1_serialNumber() effectue la même opération que X509_set_serialNumber() pour les certificats d'attribut.

VALEUR DE RETOUR

X509_get_serialNumber(), X509_get0_serialNumber() et X509_ACERT_get0_serialNumber() renvoient un pointeur vers une structure ASN1_INTEGER.

X509_set_serialNumber() et X509_ACERT_set1_serialNumber() renvoient 1 en cas de succès et 0 en cas d'échec.

HISTORIQUE

Les fonctions X509_get_serialNumber() et X509_set_serialNumber() sont disponibles dans toutes les versions d'OpenSSL. La fonction X509_get0_serialNumber() a été ajoutée dans OpenSSL 1.1.0. Les fonctions X509_ACERT_get0_serialNumber() et X509_ACERT_set1_serialNumber() ont été ajoutées dans OpenSSL 3.4.
