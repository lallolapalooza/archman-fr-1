NOM

X509_add_cert, X509_add_certs - Fonctions d'ajout de liste de certificats X509

SYNTAXE

#include <openssl/x509.h>
int X509_add_cert(STACK_OF(X509) *sk, X509 *cert, int flags);
int X509_add_certs(STACK_OF(X509) *sk, STACK_OF(X509) *certs, int flags);

DESCRIPTION

X509_add_cert() ajoute un certificat cert à la liste donnée sk. Il est erroné que l'argument cert soit NULL.

X509_add_certs() ajoute une liste de certificats certs à la liste donnée sk. L'argument certs peut être NULL, ce qui implique aucun effet. Il ne modifie pas la liste certs, mais dans le cas où le drapeau X509_ADD_FLAG_UP_REF (décrit ci-dessous) est défini, les compteurs de références de ses membres ajoutés à sk sont augmentés.

Ces deux fonctions ont un paramètre flags, qui est utilisé pour contrôler les détails de l'opération.

La valeur X509_ADD_FLAG_DEFAULT, qui est égale à 0, signifie aucune sémantique spéciale.

Si X509_ADD_FLAG_UP_REF est défini, alors les compteurs de références des certificats ajoutés avec succès sont augmentés.

Si X509_ADD_FLAG_PREPEND est défini, alors les certificats sont ajoutés en tête de sk. Par défaut, ils sont ajoutés à la fin de sk. Dans les deux cas, l'ordre d'origine des certificats ajoutés est préservé.

Si X509_ADD_FLAG_NO_DUP est défini, alors les certificats déjà contenus dans sk, ce qui est déterminé en utilisant X509_cmp(3), sont ignorés.

Si X509_ADD_FLAG_NO_SS est défini, alors les certificats qui sont marqués comme auto-signés, ce qui est déterminé en utilisant X509_self_signed(3), sont ignorés.

VALEURS DE RETOUR

Les deux fonctions retournent 1 en cas de succès et 0 en cas d'échec.

NOTES

Si X509_add_certs() est utilisée avec les drapeaux X509_ADD_FLAG_NO_DUP ou X509_ADD_FLAG_NO_SS, il est conseillé d'utiliser également X509_ADD_FLAG_UP_REF car sinon il est probable que l'appartenance de tous les membres de la liste certs ne soit pas transférée à la liste de certificats sk.

Il faut également faire attention dans le cas où l'argument certs est égal à sk.

VOIR AUSSI

X509_cmp(3) X509_self_signed(3)

HISTORIQUE

Les fonctions X509_add_cert() et X509_add_certs() ont été ajoutées dans OpenSSL 3.0.
