DESCRIPTION

X509_STORE_set_verify_cb() définit la fonction de rappel de vérification de xs à verify_cb, en écrasant la fonction précédente. La fonction de rappel attribuée avec cette fonction devient une valeur par défaut pour celle qui peut être attribuée directement à la X509_STORE_CTX correspondante, voir X509_STORE_CTX_set_verify_cb(3) pour plus d'informations.

X509_STORE_set_verify() définit la fonction de vérification finale de la chaîne pour xs à verify. Son objectif est de parcourir la chaîne de certificats et de vérifier que toutes les signatures sont valides et que l'heure actuelle se situe dans les limites de la première et de la dernière période de validité de chaque certificat. Les fonctions de vérification finale de la chaîne doivent retourner 0 en cas d'échec et 1 en cas de succès. Si aucune fonction de vérification de chaîne n'est fournie, la fonction interne par défaut sera utilisée à la place.

X509_STORE_CTX_get1_issuer() essaie de trouver dans le composant store de ctx un certificat dont le nom du sujet correspond au nom de l'émetteur de x et qui est accepté par la fonction check_issued de ctx. En cas de succès, elle attribue à *issuer la première correspondance ayant une période de validité appropriée ou, sinon, la date d'expiration la plus récente parmi tous les certificats correspondants. Si la fonction retourne 1, l'appelant est responsable de libérer *issuer. Notez que cette recherche ne prend pas en charge le retour arrière.

X509_STORE_set_get_issuer() définit la fonction get_issuer utilisée pour obtenir le certificat d'émetteur "meilleur" candidat pour le certificat donné x. Lorsqu'un tel certificat est trouvé, get_issuer doit incrémenter sa référence et l'attribuer à *issuer, puis retourner 1. Sinon, get_issuer doit retourner 0 si non trouvé et -1 (ou 0) en cas d'échec. Si X509_STORE_set_get_issuer() n'est pas utilisé ou si get_issuer est NULL, alors X509_STORE_CTX_get1_issuer() est utilisé comme implémentation par défaut.

X509_STORE_set_check_issued() définit la fonction pour vérifier qu'un certificat donné x est émis par le certificat d'émetteur issuer. Cette fonction doit retourner 0 en cas d'échec (entre autres si x n'a pas été émis par issuer) et 1 en cas de succès. Si aucune fonction pour obtenir l'émetteur n'est fournie, la fonction interne par défaut sera utilisée à la place.

X509_STORE_set_check_revocation() définit la fonction de vérification de révocation. Son objectif est de parcourir la chaîne finale et de vérifier le statut de révocation de chaque certificat. Elle doit retourner 0 en cas d'échec et 1 en cas de succès. Si aucune fonction pour obtenir l'émetteur n'est fournie, la fonction interne par défaut sera utilisée à la place.

X509_STORE_set_get_crl() définit la fonction pour obtenir la CRL pour un certificat donné x. Lorsqu'elle est trouvée, la CRL doit être attribuée à *crl. Cette fonction doit retourner 0 en cas d'échec et 1 en cas de succès. Si aucune fonction pour obtenir l'émetteur n'est fournie, la fonction interne par défaut sera utilisée à la place.

X509_STORE_set_check_crl() définit la fonction pour vérifier la validité de la crl donnée. Cette fonction doit retourner 0 en cas d'échec et 1 en cas de succès. Si aucune fonction pour obtenir l'émetteur n'est fournie, la fonction interne par défaut sera utilisée à la place.

X509_STORE_set_cert_crl() définit la fonction pour vérifier le statut de révocation du certificat donné x par rapport à la crl donnée. Cette fonction doit retourner 0 en cas d'échec et 1 en cas de succès. Si aucune fonction pour obtenir l'émetteur n'est fournie, la fonction interne par défaut sera utilisée à la place.

DESCRIPTION

The verification process for certificates involves several steps. Some of these steps may be customized by providing callback functions. The callback functions are associated with an X509_STORE object. When an X509_STORE_CTX is created from an X509_STORE, these callbacks are inherited by the context.

The functions starting with X509_STORE_set_*() are used to set the various callback functions. The functions starting with X509_STORE_get_*() are used to retrieve the currently set callback functions.

X509_STORE_set_verify_cb() sets the primary verification callback function. This is the function that is ultimately called to perform the verification. It is called with the X509_STORE_CTX as an argument. It should return 1 on success and 0 on failure.

X509_STORE_set_verify() is an alias for X509_STORE_set_verify_cb().

X509_STORE_set_get_issuer() sets the function used to retrieve the issuer certificate for a given certificate. The default implementation searches the trusted certificate store. The function is passed a pointer to the certificate for which the issuer is to be found, and it should return a pointer to the issuer certificate. It returns NULL on failure.

X509_STORE_set_check_issued() sets the function used to check if a certificate was indeed issued by its claimed issuer. The default implementation performs the necessary signature checks.

X509_STORE_set_check_revocation() sets the function used to check if a certificate has been revoked. The default implementation checks the certificate revocation list (CRL) for the issuer of the certificate.

X509_STORE_set_get_crl() sets the function used to retrieve the CRLs for a given issuer name. The function is passed the issuer name and should return a stack of CRLs (X509_CRL). It returns NULL on failure.

X509_STORE_set_check_crl() sets the function used to check if a certificate has been revoked using a specific CRL. The function is passed the certificate and the CRL to check. It should return 1 if the certificate is not revoked in the CRL, and 0 if it is revoked or if the CRL is invalid.

X509_STORE_set_cert_crl() sets the function used to get the relevant CRLs for a given certificate. The function is passed the certificate and should return a stack of CRLs (X509_CRL). It returns NULL on failure.

X509_STORE_set_check_policy() sets the function used to check the certificate policies. The default implementation checks for policy constraints and mappings.

X509_STORE_set_lookup_certs() and X509_STORE_set_lookup_crls() set the functions to look up all the certs or all the CRLs that match the given name nm. These functions return NULL on failure and a pointer to a stack of certificates (X509) or to a stack of CRLs (X509_CRL) on success. If no function to get the issuer is provided, the internal default function will be used instead.

X509_STORE_set_cleanup() sets the final cleanup function, which is called when the context (X509_STORE_CTX) is being torn down. This function doesn't return any value. If no function to get the issuer is provided, the internal default function will be used instead.

X509_STORE_get_verify_cb(), X509_STORE_CTX_get_verify(), X509_STORE_get_get_issuer(), X509_STORE_get_check_issued(), X509_STORE_get_check_revocation(), X509_STORE_get_get_crl(), X509_STORE_get_check_crl(), X509_STORE_set_verify(), X509_STORE_set_get_issuer(), X509_STORE_get_cert_crl(), X509_STORE_get_check_policy(), X509_STORE_get_lookup_certs(), X509_STORE_get_lookup_crls() and X509_STORE_get_cleanup() all return the function pointer assigned with X509_STORE_set_check_issued(), X509_STORE_set_check_revocation(), X509_STORE_set_get_crl(), X509_STORE_set_check_crl(), X509_STORE_set_cert_crl(), X509_STORE_set_check_policy(), X509_STORE_set_lookup_certs(), X509_STORE_set_lookup_crls() and X509_STORE_set_cleanup(), or NULL if no assignment has been made.

X509_STORE_set_verify_cb_func(), X509_STORE_set_verify_func() and X509_STORE_set_lookup_crls_cb() are aliases for X509_STORE_set_verify_cb(), X509_STORE_set_verify() and X509_STORE_set_lookup_crls, available as macros for backward compatibility.

X509_STORE_CTX_get1_issuer() searches for the issuer of certificate x within the context ctx. If found, the issuer certificate is copied into *ret and 1 is returned. If no issuer is found, 0 is returned. If an error occurs, -1 is returned.

NOTES

All the callbacks from a X509_STORE are inherited by the corresponding X509_STORE_CTX structure when it is initialized. See X509_STORE_CTX_set_verify_cb(3) for further details.

BUGS

The macro version of this function was the only one available before OpenSSL 1.0.0.

RETURN VALUES

The X509_STORE_set_*() functions do not return a value.

The X509_STORE_get_*() functions return a pointer of the appropriate function type.

X509_STORE_CTX_get1_issuer() returns 1 if a suitable certificate is found, 0 if not found, -1 on other error.
