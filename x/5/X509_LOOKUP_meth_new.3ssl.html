DESCRIPTION

Le type X509_LOOKUP_METHOD est une structure utilisée pour l'implémentation de nouveaux types X509_LOOKUP. Il fournit un ensemble de fonctions utilisées par OpenSSL pour l'implémentation de diverses capacités de recherche X509 et X509_CRL. Une instance d'un X509_LOOKUP_METHOD peut être associée à de nombreuses instanciations d'une structure X509_LOOKUP.

X509_LOOKUP_meth_new() crée une nouvelle structure X509_LOOKUP_METHOD. Elle doit recevoir une chaîne de caractères lisible par l'homme contenant une brève description de la méthode de recherche.

X509_LOOKUP_meth_free() détruit une structure X509_LOOKUP_METHOD. Si l'argument est NULL, rien n'est fait.

X509_LOOKUP_get_new_item() et X509_LOOKUP_set_new_item() obtiennent et définissent la fonction qui est appelée lorsqu'un objet X509_LOOKUP est créé avec X509_LOOKUP_new(). Si un X509_LOOKUP_METHOD requiert des données spécifiques par X509_LOOKUP, la fonction new_item fournie doit allouer ces données et invoquer X509_LOOKUP_set_method_data(3).

X509_LOOKUP_get_free() et X509_LOOKUP_set_free() obtiennent et définissent la fonction utilisée pour libérer toute donnée de méthode qui a été allouée et définie dans la fonction new_item.

X509_LOOKUP_meth_get_init() et X509_LOOKUP_meth_set_init() obtiennent et définissent la fonction utilisée pour initialiser les données de méthode qui ont été définies avec X509_LOOKUP_set_method_data(3) dans le cadre de la routine new_item.

X509_LOOKUP_meth_get_shutdown() et X509_LOOKUP_meth_set_shutdown() obtiennent et définissent la fonction utilisée pour terminer les données de méthode dont l'état a été précédemment initialisé dans la fonction init.

X509_LOOKUP_meth_get_ctrl() et X509_LOOKUP_meth_set_ctrl() obtiennent et définissent une fonction pour gérer les commandes de contrôle arbitraires émises par X509_LOOKUP_ctrl(). La fonction de contrôle reçoit le contexte X509_LOOKUP ctx, ainsi que les arguments passés par X509_LOOKUP_ctrl. cmd est un entier arbitraire qui définit une opération. argc est un pointeur vers un tableau de caractères. argl est un entier. ret, s'il est défini, pointe vers un emplacement où les données de retour doivent être écrites. L'utilisation de argc et argl dépend entièrement de la fonction de contrôle.

X509_LOOKUP_set_get_by_subject(), X509_LOOKUP_set_get_by_issuer_serial(), X509_LOOKUP_set_get_by_fingerprint(), X509_LOOKUP_set_get_by_alias() définissent les fonctions utilisées pour récupérer un objet X509 ou X509_CRL par le sujet, l'émetteur, l'empreinte digitale et l'alias de l'objet respectivement. Ces fonctions reçoivent le contexte X509_LOOKUP, le type de l'X509_OBJECT demandé, les paramètres liés à la recherche, et un X509_OBJECT qui recevra l'objet demandé.

Les implémentations doivent ajouter les objets trouvés à l'objet X509_STORE en utilisant X509_STORE_add_cert() ou X509_STORE_add_crl(). Cela incrémente son compteur de références. Cependant, la fonction X509_STORE_CTX_get_by_subject(3) augmente également le compteur de références, ce qui conduit à une référence supplémentaire. Par conséquent, les applications doivent également appeler X509_free() ou X509_CRL_free() pour décrémenter à nouveau le compteur de références.

Les implémentations doivent également utiliser soit X509_OBJECT_set1_X509(), soit X509_OBJECT_set1_X509_CRL() pour définir le résultat. Notez que cela incrémente également le compteur de références du résultat.

Toute donnée de méthode créée à la suite de la fonction new_item définie par X509_LOOKUP_meth_set_new_item() peut être accédée avec X509_LOOKUP_get_method_data(3). L'objet X509_STORE qui possède le X509_LOOKUP peut être accédé avec X509_LOOKUP_get_store(3). Les recherches réussies doivent retourner 1, et les recherches infructueuses doivent retourner 0.

X509_LOOKUP_get_get_by_subject(), X509_LOOKUP_get_get_by_issuer_serial(), X509_LOOKUP_get_get_by_fingerprint(), X509_LOOKUP_get_get_by_alias() récupèrent la fonction définie par le régleur correspondant.

VALEUR DE RETOUR

Les fonctions X509_LOOKUP_meth_set retournent 1 en cas de succès ou 0 en cas d'erreur.

T

he X509_LOOKUP_meth_get fonctions renvoient les pointeurs de fonction correspondants.
