X509_ACERT_add1_attr(3ssl)

Paquet: openssl

Licences: Apache-2.0

X509_ACERT_ADD1_ATTR(3ssl) OpenSSL X509_ACERT_ADD1_ATTR(3ssl)

NOM

X509_ACERT_add1_attr, X509_ACERT_add1_attr_by_NID, X509_ACERT_add1_attr_by_OBJ, X509_ACERT_add1_attr_by_txt, X509_ACERT_delete_attr - Fonctions d'attributs X509_ACERT

SYNOPSIS

#include <openssl/x509_acert.h>
int X509_ACERT_add1_attr(X509_ACERT *x, X509_ATTRIBUTE *attr);
int X509_ACERT_add1_attr_by_NID(X509_ACERT *x, int nid, int type,
                                const void *bytes, int len);
int X509_ACERT_add1_attr_by_OBJ(X509_ACERT *x, const ASN1_OBJECT *obj,
                                int type, const void *bytes, int len);
int X509_ACERT_add1_attr_by_txt(X509_ACERT *x, const char *attrname, int type,
                                const unsigned char *bytes, int len);
X509_ATTRIBUTE *X509_ACERT_delete_attr(X509_ACERT *x, int loc);

DESCRIPTION

X509_ACERT_add1_attr() ajoute un X509_ATTRIBUTE construit attr à la structure X509_ACERT existante x.

X509_ACERT_add1_attr_by_NID() et X509_ACERT_add1_attr_by_OBJ() ajoutent un attribut de type nid ou obj avec une valeur de type ASN1 type construite en utilisant len octets à partir de bytes.

X509_ACERT_add1_attr_by_txt() ajoute un attribut de type attrname avec une valeur de type ASN1 type construite en utilisant len octets à partir de bytes.

X509_ACERT_delete_attr() supprimera le loc-ième attribut de x et retournera un pointeur vers celui-ci ou NULL s'il y a moins de loc attributs contenus dans x.

VALEURS DE RETOUR

X509_ACERT_add1_attr(), X509_ACERT_add1_attr_by_NID(), et X509_ACERT_add1_attr_by_OBJ() retournent 1 en cas de succès et 0 en cas d'échec.

X509_ACERT_delete_attr() retourne un pointeur X509_ATTRIBUTE en cas de succès ou NULL en cas d'échec.

VOIR AUSSI

X509_ACERT_get_attr_count(3)

HISTORIQUE

X509_ACERT_add1_attr(), X509_ACERT_add1_attr_by_NID(), X509_ACERT_add1_attr_by_OBJ(), X509_ACERT_add1_attr_by_txt() et X509_ACERT_delete_attr() ont été ajoutés dans OpenSSL 3.4.
