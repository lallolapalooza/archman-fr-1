NOM

X509_NAME_get0_der - obtenir le codage DER de X509_NAME

SYNTAXE

#include <openssl/x509.h>
int X509_NAME_get0_der(const X509_NAME *nm, const unsigned char **pder,
                       size_t *pderlen);

DESCRIPTION

La fonction X509_NAME_get0_der() renvoie un pointeur interne vers le codage d'une structure X509_NAME dans *pder et composé de *pderlen octets. Elle est utile pour les applications qui souhaitent examiner le codage d'une structure X509_NAME sans la copier.

VALEURS DE RETOUR

La fonction X509_NAME_get0_der() renvoie 1 en cas de succès et 0 si une erreur s'est produite.
