X509_REQ_get_attr(3ssl)

Paquet: openssl

Licences: Apache-2.0

X509_REQ_GET_ATTR(3ssl) OpenSSL X509_REQ_GET_ATTR(3ssl)

NOM

X509_REQ_get_attr_count, X509_REQ_get_attr_by_NID, X509_REQ_get_attr_by_OBJ, X509_REQ_get_attr, X509_REQ_delete_attr, X509_REQ_add1_attr, X509_REQ_add1_attr_by_OBJ, X509_REQ_add1_attr_by_NID, X509_REQ_add1_attr_by_txt - Support X509_ATTRIBUTE pour les demandes de certificats signés

SYNOPIS

#include <openssl/x509.h>
int X509_REQ_get_attr_count(const X509_REQ *req);
int X509_REQ_get_attr_by_NID(const X509_REQ *req, int nid, int lastpos);
int X509_REQ_get_attr_by_OBJ(const X509_REQ *req, const ASN1_OBJECT *obj,
                             int lastpos);
X509_ATTRIBUTE *X509_REQ_get_attr(const X509_REQ *req, int loc);
X509_ATTRIBUTE *X509_REQ_delete_attr(X509_REQ *req, int loc);
int X509_REQ_add1_attr(X509_REQ *req, X509_ATTRIBUTE *attr);
int X509_REQ_add1_attr_by_OBJ(X509_REQ *req,
                              const ASN1_OBJECT *obj, int type,
                              const unsigned char *bytes, int len);
int X509_REQ_add1_attr_by_NID(X509_REQ *req,
                              int nid, int type,
                              const unsigned char *bytes, int len);
int X509_REQ_add1_attr_by_txt(X509_REQ *req,
                              const char *attrname, int type,
                              const unsigned char *bytes, int len);

DESCRIPTION

X509_REQ_get_attr_by_OBJ() trouve la position du premier objet correspondant obj dans la liste d'attributs de req. La recherche commence à la position après lastpos. Si la valeur retournée est positive, elle peut être utilisée lors de l'appel suivant à X509_REQ_get_attr_by_OBJ() comme valeur de lastpos afin d'itérer sur les attributs restants. lastpos peut être défini à toute valeur négative lors du premier appel, afin de commencer la recherche depuis le début de la liste d'attributs.

X509_REQ_get_attr_by_NID() est similaire à X509_REQ_get_attr_by_OBJ() sauf qu'elle passe l'identifiant numérique (NID) nid associé à l'objet. Voir <openssl/obj_mac.h> pour une liste de NID_*.

X509_REQ_get_attr() retourne l'objet X509_ATTRIBUTE à l'indice loc dans la liste d'attributs de req. loc doit être dans la plage de 0 à X509_REQ_get_attr_count() - 1.

X509_REQ_delete_attr() supprime l'objet X509_ATTRIBUTE à l'indice loc dans la liste des attributs de req. Une erreur se produit si req est NULL.

X509_REQ_add1_attr() ajoute une copie de l'attribut X509_ATTRIBUTE attr passé en paramètre à la liste d'attributs de l'objet req. Une erreur se produira si la liste d'attributs est NULL ou si l'attribut existe déjà.

X509_REQ_add1_attr_by_OBJ() crée un nouvel X509_ATTRIBUTE en utilisant X509_ATTRIBUTE_set1_object() et X509_ATTRIBUTE_set1_data() pour assigner un nouveau obj avec le type type et les données bytes de longueur len, puis l'ajoute à la liste d'attributs de l'objet req. req doit être non NULL ou une erreur se produira. Si obj existe déjà dans la liste d'attributs, une erreur se produit.

X509_REQ_add1_attr_by_NID() est similaire à X509_REQ_add1_attr_by_OBJ() sauf qu'elle passe l'identifiant numérique (NID) nid associé à l'objet. Voir <openssl/obj_mac.h> pour une liste de NID_*.

X509_REQ_add1_attr_by_txt() est similaire à X509_REQ_add1_attr_by_OBJ() sauf qu'elle passe un nom attrname associé à l'objet. Voir <openssl/obj_mac.h> pour une liste de noms SN_*.

Référez-vous à X509_ATTRIBUTE(3) pour des informations relatives aux attributs.

VALEURS DE RETOUR

X509_REQ_get_attr_count() retourne le nombre d'attributs dans la liste d'attributs de l'objet req ou -1 si la liste d'attributs est NULL.

X509_REQ_get_attr_by_OBJ() retourne -1 si la liste d'attributs de l'objet req est vide OU si obj n'est pas trouvé, sinon elle retourne la position de obj dans la liste d'attributs.

X509_REQ_get_attr_by_NID() est similaire à X509_REQ_get_attr_by_OBJ(), sauf qu'elle retourne -2 si le nid n'est pas connu par OpenSSL.

X509_REQ_get_attr() retourne soit un X509_ATTRIBUTE, soit NULL en cas d'erreur.

X509_REQ_delete_attr() retourne soit le X509_ATTRIBUTE supprimé, soit NULL en cas d'erreur.

X509_REQ_add1_attr(), X509_REQ_add1_attr_by_OBJ(), X509_REQ_add1_attr_by_NID() et X509_REQ_add1_attr_by_txt() retournent 1 en cas de succès ou 0 en cas d'erreur.

NOTES

Toutes les fonctions qui modifient les attributs (ajout ou suppression) définissent en interne un indicateur pour signaler que l'encodage ASN.1 a été modifié.
