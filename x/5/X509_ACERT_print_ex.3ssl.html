X509_ACERT_print_ex(3ssl)

Paquet: openssl

Licences: Apache-2.0

X509_ACERT_PRINT_EX(3ssl) OpenSSL X509_ACERT_PRINT_EX(3ssl)

NOM

X509_ACERT_print_ex, X509_ACERT_print - Routines d'impression X509_ACERT

SYNOPSIS

#include <openssl/x509_acert.h>
int X509_ACERT_print(BIO *bp, X509_ACERT *acert);
int X509_ACERT_print_ex(BIO *bp, X509_ACERT *acert, unsigned long nmflags,
                        unsigned long cflag);

DESCRIPTION

X509_ACERT_print_ex() imprime une version lisible par l'homme du certificat d'attribut acert dans le BIO bp.

Les données suivantes contenues dans le certificat d'attribut sont imprimées dans l'ordre :

•
Les textes d'en-tête "Attribute certificate:" et "Data:" (X509_FLAG_NO_HEADER)

= élément *

Le numéro de version du certificat d'attribut tel que défini par la norme, suivi entre parenthèses de la valeur contenue dans le champ version en notation hexadécimale. Si le numéro de version n'est pas une valeur valide selon la spécification, seule la valeur brute est imprimée. Voir X509_ACERT_get_version(3) pour les détails. (X509_FLAG_NO_VERSION)

= élément *

Le numéro de série du certificat d'attribut (X509_FLAG_NO_SERIAL)

= élément *

L'identité du détenteur du certificat d'attribut. Si le nom de l'émetteur du détenteur est présent, le premier GENERAL_NAME retourné par X509_ACERT_get0_holder_entityName() est imprimé. Si le baseCertificateId du détenteur est présent, le nom de l'émetteur (imprimé avec X509_NAME_print_ex) et le numéro de série du certificat du détenteur sont affichés. (X509_FLAG_NO_SUBJECT)

= élément *

Le nom de l'émetteur du certificat d'attribut tel que retourné par X509_ACERT_get0_issuerName() et imprimé en utilisant X509_NAME_print_ex(). (X509_FLAG_NO_ISSUER)

= élément *

La période de validité entre les moments retournés par X509_ACERT_get0_notBefore() et X509_ACERT_get0_notAfter(). Les valeurs sont imprimées comme des heures généralisées en utilisant ASN1_GENERALIZEDTIME_print(). (X509_FLAG_NO_VALIDITY)

= élément *

La liste des attributs contenus dans le certificat d'attribut. Le type d'attribut est imprimé avec i2a_ASN1_OBJECT(). Les attributs de type chaîne sont imprimés comme des données de chaîne brutes. Les valeurs encodées ASN1 sont imprimées avec ASN1_parse_dump(). (X509_FLAG_NO_ATTRIBUTES)

= élément *

Toutes les extensions X.509 contenues dans le certificat d'attribut. (X509_FLAG_NO_EXTENSIONS)

= élément *

La signature est imprimée avec X509_signature_print(). (X509_FLAG_NO_SIGDUMP)

Si cflag est spécifié comme X509_FLAG_COMPAT, toutes les données ci-dessus du certificat d'attribut seront imprimées.

Le drapeau nmflags détermine le format utilisé pour afficher tous les champs imprimés en utilisant X509_NAME_print_ex(). Voir X509_NAME_print_ex(3) pour les détails.

X509_ACERT_print() est équivalent à appeler X509_ACERT_print_ex() avec les nmflags et cflags définis respectivement à XN_FLAG_COMPAT et X509_FLAG_COMPAT.

VALEURS DE RETOUR

X509_ACERT_print_ex() X509_ACERT_print() renvoient 1 en cas de succès et 0 en cas d'échec.

VOIR AUSSI

X509_NAME_print_ex(3)

HISTORIQUE

X509_ACERT_print() et X509_ACERT_print_ex() ont été ajoutés dans OpenSSL 3.4.
