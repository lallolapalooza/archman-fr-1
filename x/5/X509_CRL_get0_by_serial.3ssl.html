X509_CRL_GET0_BY_SERIAL(3ssl) OpenSSL X509_CRL_GET0_BY_SERIAL(3ssl)

NOM

X509_CRL_get0_by_serial, X509_CRL_get0_by_cert, X509_CRL_get_REVOKED, X509_REVOKED_get0_serialNumber, X509_REVOKED_get0_revocationDate, X509_REVOKED_set_serialNumber, X509_REVOKED_set_revocationDate, X509_CRL_add0_revoked, X509_CRL_sort - Fonctions utilitaires d'entrée révoquée de CRL

SYNTAXE

#include <openssl/x509.h>
int X509_CRL_get0_by_serial(X509_CRL *crl,
                            X509_REVOKED **ret, const ASN1_INTEGER *serial);
int X509_CRL_get0_by_cert(X509_CRL *crl, X509_REVOKED **ret, X509 *x);
STACK_OF(X509_REVOKED) *X509_CRL_get_REVOKED(X509_CRL *crl);
const ASN1_INTEGER *X509_REVOKED_get0_serialNumber(const X509_REVOKED *r);
const ASN1_TIME *X509_REVOKED_get0_revocationDate(const X509_REVOKED *r);
int X509_REVOKED_set_serialNumber(X509_REVOKED *r, ASN1_INTEGER *serial);
int X509_REVOKED_set_revocationDate(X509_REVOKED *r, ASN1_TIME *tm);
int X509_CRL_add0_revoked(X509_CRL *crl, X509_REVOKED *rev);
int X509_CRL_sort(X509_CRL *crl);

DESCRIPTION

X509_CRL_get0_by_serial() tente de trouver une entrée révoquée dans crl pour le numéro de série serial. Si elle réussit, elle définit *ret sur le pointeur interne de l'entrée correspondante. En conséquence, *ret **NE DOIT PAS** être libéré après l'appel.

X509_CRL_get0_by_cert() est similaire à X509_get0_by_serial(), sauf qu'elle recherche une entrée révoquée en utilisant le numéro de série du certificat x.

X509_CRL_get_REVOKED() renvoie un pointeur interne vers une PILE de toutes les entrées révoquées pour crl.

X509_REVOKED_get0_serialNumber() renvoie un pointeur interne vers le numéro de série de r.

X509_REVOKED_get0_revocationDate() renvoie un pointeur interne vers la date de révocation de r.

X509_REVOKED_set_serialNumber() définit le numéro de série de r à serial. Le pointeur serial fourni n'est pas utilisé en interne, il doit donc être libéré après utilisation.

X509_REVOKED_set_revocationDate() définit la date de révocation de r à tm. Le pointeur tm fourni n'est pas utilisé en interne, il doit donc être libéré après utilisation.

X509_CRL_add0_revoked() ajoute l'entrée révoquée rev à la CRL crl. Le pointeur rev est utilisé en interne et **NE DOIT PAS** être libéré après l'appel : il est libéré lorsque la CRL parente est libérée.

X509_CRL_sort() trie les entrées révoquées de crl par ordre croissant de numéro de série.

NOTES

Les applications peuvent déterminer le nombre d'entrées révoquées renvoyées par X509_CRL_get_REVOKED() en utilisant sk_X509_REVOKED_num() et les examiner une par une en utilisant sk_X509_REVOKED_value().

VALEURS DE RETOUR

X509_CRL_get0_by_serial() et X509_CRL_get0_by_cert() renvoient 0 en cas d'échec, 1 en cas de succès, sauf si l'entrée révoquée a la raison "removeFromCRL" (8), auquel cas 2 est renvoyé.

X509_CRL_get_REVOKED() renvoie une PILE d'entrées révoquées.

X509_REVOKED_get0_serialNumber() renvoie une structure ASN1_INTEGER.

X509_REVOKED_get0_revocationDate() renvoie une structure ASN1_TIME.

X509_REVOKED_set_serialNumber(), X509_REVOKED_set_revocationDate(), X509_CRL_add0_revoked() et X509_CRL_sort() renvoient 1 en cas de succès et 0 en cas d'échec.
