X509_cmp_time(3ssl)

Paquet: openssl

Licences: Apache-2.0

X509_CMP_TIME(3ssl) OpenSSL X509_CMP_TIME(3ssl)

NOM

X509_cmp_time, X509_cmp_current_time, X509_cmp_timeframe, X509_time_adj, X509_time_adj_ex, X509_gmtime_adj - Fonctions temporelles X509

SYNTAXE

int X509_cmp_time(const ASN1_TIME *asn1_time, time_t *in_tm);
int X509_cmp_current_time(const ASN1_TIME *asn1_time);
int X509_cmp_timeframe(const X509_VERIFY_PARAM *vpm,
                       const ASN1_TIME *start, const ASN1_TIME *end);
ASN1_TIME *X509_time_adj(ASN1_TIME *asn1_time, long offset_sec, time_t *in_tm);
ASN1_TIME *X509_time_adj_ex(ASN1_TIME *asn1_time, int offset_day, long
                            offset_sec, time_t *in_tm);
ASN1_TIME *X509_gmtime_adj(ASN1_TIME *asn1_time, long offset_sec);

DESCRIPTION

X509_cmp_time() compare l'ASN1_TIME dans asn1_time avec le temps dans <in_tm>.

X509_cmp_current_time() compare l'ASN1_TIME dans asn1_time avec le temps actuel, exprimé en time_t.

X509_cmp_timeframe() compare la période de temps donnée avec le temps de référence inclus dans les paramètres de vérification vpm s'ils ne sont pas NULL et contiennent X509_V_FLAG_USE_CHECK_TIME; sinon le temps actuel est utilisé comme temps de référence.

X509_time_adj_ex() définit la structure ASN1_TIME asn1_time au temps offset_day et offset_sec après in_tm.

X509_time_adj() définit la structure ASN1_TIME asn1_time au temps offset_sec après in_tm. Cette méthode ne peut gérer que des décalages de secondes jusqu'à la capacité de long, donc l'API plus récente X509_time_adj_ex() devrait être préférée.

Dans les deux méthodes, si asn1_time est NULL, une nouvelle structure ASN1_TIME est allouée et retournée.

Dans toutes les méthodes, si in_tm est NULL, le temps actuel, exprimé en time_t, est utilisé.

asn1_time doit satisfaire le format ASN1_TIME imposé par la RFC 5280, c'est-à-dire que son format doit être soit YYMMDDHHMMSSZ soit YYYYMMDDHHMMSSZ.

X509_gmtime_adj() définit la structure ASN1_TIME asn1_time au temps offset_sec après le temps actuel. C'est équivalent à appeler X509_time_adj() avec le dernier paramètre comme NULL.

BOGUES

Contrairement à de nombreuses fonctions de comparaison standard, X509_cmp_time() et X509_cmp_current_time() retournent 0 en cas d'erreur.

VALEURS DE RETOUR

X509_cmp_time() et X509_cmp_current_time() retournent -1 si asn1_time est antérieur ou égal à in_tm (resp. temps actuel), et 1 sinon. Ces méthodes retournent 0 en cas d'erreur.

X509_cmp_timeframe() retourne 0 si vpm n'est pas NULL et que les paramètres de vérification ne contiennent pas X509_V_FLAG_USE_CHECK_TIME mais contiennent X509_V_FLAG_NO_CHECK_TIME. Sinon, elle retourne 1 si l'heure de fin n'est pas NULL et que l'heure de référence (qui a été déterminée comme indiqué ci-dessus) est après l'heure de fin, -1 si l'heure de début n'est pas NULL et que l'heure de référence est avant, sinon 0 pour indiquer que l'heure de référence est dans la plage (impliquant que l'heure de fin n'est pas avant l'heure de début si les deux sont présents).

X509_time_adj(), X509_time_adj_ex() et X509_gmtime_adj() retournent un pointeur vers la structure ASN1_TIME mise à jour, et NULL en cas d'erreur.

HISTORIQUE

X509_cmp_timeframe() a été ajoutée dans OpenSSL 3.0.
