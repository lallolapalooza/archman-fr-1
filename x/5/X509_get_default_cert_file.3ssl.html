X509_get_default_cert_file(3ssl)

Paquet: openssl

Licences: Apache-2.0

X509_GET_DEFAULT_CERT_FILE(3ssl) OpenSSL X509_GET_DEFAULT_CERT_FILE(3ssl)

NOM

X509_get_default_cert_file, X509_get_default_cert_file_env, X509_get_default_cert_dir, X509_get_default_cert_dir_env - récupérer les emplacements par défaut pour les certificats CA de confiance

SYNTAXE

#include <openssl/x509.h>
const char *X509_get_default_cert_file(void);
const char *X509_get_default_cert_dir(void);
const char *X509_get_default_cert_file_env(void);
const char *X509_get_default_cert_dir_env(void);

DESCRIPTION

La fonction X509_get_default_cert_file() renvoie le chemin par défaut vers un fichier contenant les certificats CA de confiance. OpenSSL utilisera ce chemin par défaut lorsqu'il sera invité à charger des certificats CA de confiance à partir d'un fichier et qu'aucun autre chemin ne sera spécifié. Si le fichier existe, les certificats CA sont chargés à partir du fichier.

La fonction X509_get_default_cert_dir() renvoie une liste par défaut de chemins séparés par des délimiteurs vers des répertoires contenant les certificats CA de confiance nommés au format haché. OpenSSL utilisera cette liste par défaut de chemins lorsqu'il sera invité à charger des certificats CA de confiance à partir d'un répertoire et qu'aucun autre chemin ne sera spécifié. Si un répertoire donné dans la liste existe, OpenSSL tente de rechercher les certificats CA dans ce répertoire en calculant un nom de fichier basé sur un hachage du nom du sujet du certificat.

X509_get_default_cert_file_env() renvoie le nom d'une variable d'environnement qui est recommandée pour spécifier une valeur non par défaut à utiliser à la place de la valeur renvoyée par X509_get_default_cert_file(). La valeur renvoyée par cette dernière fonction n'est pas affectée par ces variables d'environnement ; vous devez vérifier cette variable d'environnement vous-même, en utilisant cette fonction pour récupérer le nom correct de la variable d'environnement. Si une variable d'environnement n'est pas définie, la valeur renvoyée par X509_get_default_cert_file() doit être utilisée.

X509_get_default_cert_dir_env() renvoie le nom de la variable d'environnement qui est recommandée pour spécifier une valeur non par défaut à utiliser à la place de la valeur renvoyée par X509_get_default_cert_dir(). La valeur spécifiée par cette variable d'environnement peut également être une URI de magasin (mais voir BUGS ci-dessous).

BUGS

Par défaut (par exemple, lorsque X509_STORE_set_default_paths(3) est utilisé), le nom de la variable d'environnement renvoyé par X509_get_default_cert_dir_env() est interprété à la fois comme une liste de chemins séparés par des délimiteurs et comme une URI de magasin. Ceci est ambigu. Par exemple, spécifier une valeur de "file:///etc/certs" entraînerait l'instanciation du magasin "file" fourni dans le cadre du fournisseur par défaut, mais provoquerait également l'instanciation d'un X509_LOOKUP_hash_dir(3) pour rechercher des certificats dans le répertoire "file" (par rapport au répertoire de travail courant) et le répertoire "///etc/certs". Cela peut être évité en évitant l'utilisation du mécanisme des variables d'environnement et en utilisant d'autres méthodes pour construire des instances X509_LOOKUP.

VALEUR DE RETOUR

Ces fonctions renvoient des pointeurs vers des chaînes constantes ayant une durée de vie de stockage statique.
