RSA_set_method(3ssl)

RSA_SET_METHOD(3ssl) OpenSSL RSA_SET_METHOD(3ssl)

NOM

RSA_set_default_method, RSA_get_default_method, RSA_set_method, RSA_get_method, RSA_PKCS1_OpenSSL, RSA_flags, RSA_new_method - sélectionner une méthode RSA

SYNTAXE

#include <openssl/rsa.h>

Les fonctions suivantes sont dépréciées depuis OpenSSL 3.0, et peuvent être entièrement masquées en définissant OPENSSL_API_COMPAT avec une valeur de version appropriée, voir openssl_user_macros(7):

void RSA_set_default_method(const RSA_METHOD *meth);
const RSA_METHOD *RSA_get_default_method(void);
int RSA_set_method(RSA *rsa, const RSA_METHOD *meth);
const RSA_METHOD *RSA_get_method(const RSA *rsa);
const RSA_METHOD *RSA_PKCS1_OpenSSL(void);
int RSA_flags(const RSA *rsa);
RSA *RSA_new_method(ENGINE *engine);

DESCRIPTION

Toutes les fonctions décrites sur cette page sont dépréciées. Les applications devraient plutôt utiliser les API OSSL_PROVIDER.

Une RSA_METHOD spécifie les fonctions qu'OpenSSL utilise pour les opérations RSA. En modifiant la méthode, des implémentations alternatives telles que des accélérateurs matériels peuvent être utilisées. IMPORTANT : Voir la section NOTES pour des informations importantes sur la manière dont ces fonctions API RSA sont affectées par l'utilisation des appels API ENGINE.

Initialement, la RSA_METHOD par défaut est l'implémentation interne d'OpenSSL, telle que retournée par RSA_PKCS1_OpenSSL().

RSA_set_default_method() fait de meth la méthode par défaut pour toutes les structures RSA créées ultérieurement. NB : Ceci n'est vrai que tant qu'aucun ENGINE n'a été défini par défaut pour RSA, cette fonction n'est donc plus recommandée. Cette fonction n'est pas thread-safe et ne doit pas être appelée en même temps que d'autres fonctions OpenSSL.

RSA_get_default_method() retourne un pointeur vers la RSA_METHOD par défaut actuelle. Cependant, la pertinence de ce résultat dépend de l'utilisation ou non de l'API ENGINE, cette fonction n'est donc plus recommandée.

RSA_set_method() sélectionne meth pour effectuer toutes les opérations utilisant la clé rsa. Cela remplacera la RSA_METHOD utilisée par la clé RSA et si la méthode précédente était fournie par un ENGINE, le descripteur de cet ENGINE sera libéré lors du changement. Il est possible d'avoir des clés RSA qui ne fonctionnent qu'avec certaines implémentations RSA_METHOD (par exemple, provenant d'un module ENGINE qui prend en charge les clés protégées par matériel embarqué), et dans de tels cas, tenter de changer la RSA_METHOD pour la clé peut avoir des résultats inattendus.

RSA_get_method() retourne un pointeur vers la RSA_METHOD utilisée par rsa. Cette méthode peut ou peut ne pas être fournie par une implémentation ENGINE, mais si c'est le cas, la valeur de retour ne peut être garantie que valide tant que la clé RSA elle-même est valide et que son implémentation n'est pas modifiée par RSA_set_method().

RSA_flags() retourne les flags qui sont définis pour la RSA_METHOD actuelle de rsa. Voir la section BUGS.

RSA_new_method() alloue et initialise une structure RSA afin que engine soit utilisé pour les opérations RSA. Si engine est NULL, l'ENGINE par défaut pour les opérations RSA est utilisé, et si aucun ENGINE par défaut n'est défini, la RSA_METHOD contrôlée par RSA_set_default_method() est utilisée.

RSA_flags() retourne les flags qui sont définis pour la méthode actuelle de rsa.

RSA_new_method() alloue et initialise une structure RSA afin que method soit utilisé pour les opérations RSA. Si method est NULL, la méthode par défaut est utilisée.

LA STRUCTURE RSA_METHOD

typedef struct rsa_meth_st
{
    /* nom de l'implémentation */
    const char *name;
    /* chiffrement */
    int (*rsa_pub_enc)(int flen, unsigned char *from,
                       unsigned char *to, RSA *rsa, int padding);
    /* vérification de données arbitraires */
    int (*rsa_pub_dec)(int flen, unsigned char *from,
                       unsigned char *to, RSA *rsa, int padding);
    /* signature de données arbitraires */
    int (*rsa_priv_enc)(int flen, unsigned char *from,
                        unsigned char *to, RSA *rsa, int padding);
    /* déchiffrement */
    int (*rsa_priv_dec)(int flen, unsigned char *from,
                        unsigned char *to, RSA *rsa, int padding);
    /* calcul r0 = r0 ^ I mod rsa->n (Peut être NULL pour certaines implémentations) */
    int (*rsa_mod_exp)(BIGNUM *r0, BIGNUM *I, RSA *rsa);
    /* calcul r = a ^ p mod m (Peut être NULL pour certaines implémentations) */
    int (*bn_mod_exp)(BIGNUM *r, BIGNUM *a, const BIGNUM *p,
                      const BIGNUM *m, BN_CTX *ctx, BN_MONT_CTX *m_ctx);
    /* appelé lors de RSA_new */
    int (*init)(RSA *rsa);
    /* appelé lors de RSA_free */
    int (*finish)(RSA *rsa);
    /*
     * RSA_FLAG_EXT_PKEY        - rsa_mod_exp est appelé pour les opérations
     *                            de clé privée, même si p,q,dmp1,dmq1,iqmp
     *                            sont NULL
     * RSA_METHOD_FLAG_NO_CHECK - ne pas vérifier la correspondance pub/privé
     */
    int flags;
    char *app_data; /* ?? */
    int (*rsa_sign)(int type,
                    const unsigned char *m, unsigned int m_length,
                    unsigned char *sigret, unsigned int *siglen, const RSA *rsa);
    int (*rsa_verify)(int dtype,
                      const unsigned char *m, unsigned int m_length,
                      const unsigned char *sigbuf, unsigned int siglen,
                      const RSA *rsa);
    /* génération de clé. Si NULL, la génération de clé RSA intégrée sera utilisée */
    int (*rsa_keygen)(RSA *rsa, int bits, BIGNUM *e, BN_GENCB *cb);
} RSA_METHOD;

VALEURS DE RETOUR

RSA_PKCS1_OpenSSL(), RSA_PKCS1_null_method(), RSA_get_default_method() et RSA_get_method() retournent des pointeurs vers les RSA_METHOD respectives.

RSA_set_default_method() ne retourne aucune valeur.

RSA_set_method() retourne un pointeur vers l'ancienne implémentation RSA_METHOD qui a été remplacée. Cependant, cette valeur de retour devrait probablement être ignorée car si elle était fournie par un ENGINE, le pointeur pourrait être invalidé à tout moment si l'ENGINE est déchargé (en fait, il pourrait être déchargé à la suite de la fonction RSA_set_method() libérant son descripteur vers l'ENGINE). Pour cette raison, le type de retour peut être remplacé par une déclaration void dans une future version.

RSA_new_method() retourne NULL et définit un code d'erreur qui peut être obtenu par ERR_get_error(3) si l'allocation échoue. Sinon, il retourne un pointeur vers la structure nouvellement allouée.

BUGS

Le comportement de RSA_flags() est une mauvaise fonctionnalité qui est laissée telle quelle pour l'instant afin d'éviter de créer des problèmes de compatibilité. Les fonctionnalités RSA, telles que les fonctions de chiffrement, sont contrôlées par la valeur flags dans la clé RSA elle-même, et non par la valeur flags dans la RSA_METHOD attachée à la clé RSA (ce que cette fonction retourne). Si l'élément flags d'une clé RSA est modifié, les modifications seront prises en compte par les fonctionnalités RSA mais ne seront pas reflétées dans la valeur de retour de la fonction RSA_flags() - en effet RSA_flags() se comporte plus comme une fonction RSA_default_flags() (qui n'existe pas actuellement).

HISTORIQUE

Toutes ces fonctions ont été dépréciées dans OpenSSL 3.0.

RSA_null_method(), qui était une tentative partielle d'éviter les problèmes de brevets, a été remplacé pour retourner toujours NULL dans OpenSSL 1.1.1.
