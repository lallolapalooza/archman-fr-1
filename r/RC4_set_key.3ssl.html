RC4_set_key(3ssl)

Paquet: openssl

Licences: Apache-2.0

RC4_SET_KEY(3ssl) OpenSSL RC4_SET_KEY(3ssl)

NOM

RC4_set_key, RC4 - chiffrement RC4

SYNTAXIS

#include <openssl/rc4.h>

Les fonctions suivantes sont dépréciées depuis OpenSSL 3.0, et peuvent être entièrement masquées en définissant OPENSSL_API_COMPAT avec une valeur de version appropriée, voir openssl_user_macros(7) :

void RC4_set_key(RC4_KEY *key, int len, const unsigned char *data);
void RC4(RC4_KEY *key, unsigned long len, const unsigned char *indata,
         unsigned char *outdata);

DESCRIPTION

Toutes les fonctions décrites sur cette page sont dépréciées. Les applications devraient plutôt utiliser EVP_EncryptInit_ex(3), EVP_EncryptUpdate(3) et EVP_EncryptFinal_ex(3) ou les fonctions de déchiffrement portant des noms équivalents.

Cette bibliothèque implémente le chiffrement Alleged RC4, qui est décrit par exemple dans Applied Cryptography. Il est considéré comme compatible avec RC4[TM], un chiffrement propriétaire de RSA Security Inc.

RC4 est un chiffrement de flux avec une longueur de clé variable. Typiquement, des clés de 128 bits (16 octets) sont utilisées pour un chiffrement fort, mais des tailles de clé plus courtes et non sécurisées ont été largement utilisées en raison des restrictions d'exportation.

RC4 comprend une phase de configuration de la clé et la phase de chiffrement ou déchiffrement réelle.

RC4_set_key() configure la RC4_KEY key en utilisant les len octets de la clé à l'emplacement data.

RC4() chiffre ou déchiffre les len octets de données à l'emplacement indata en utilisant la clé key et place le résultat à l'emplacement outdata. Des appels répétés à RC4() avec la même clé key génèrent un flux de clé continu.

Comme RC4 est un chiffrement de flux (l'entrée est XORée avec un flux de clé pseudo-aléatoire pour produire la sortie), le déchiffrement utilise les mêmes appels de fonction que le chiffrement.

VALEURS DE RETOUR

RC4_set_key() et RC4() ne retournent pas de valeurs.

NOTE

Les applications devraient utiliser les fonctions de niveau supérieur EVP_EncryptInit(3), etc., au lieu d'appeler directement ces fonctions.

Il est difficile d'utiliser les chiffrements de flux de manière sécurisée. Par exemple, n'effectuez pas plusieurs chiffrements en utilisant le même flux de clé.
