NOM

Role::Tiny::With - Interface soignée pour les consommateurs de rôles Role::Tiny

SYNOPSIS

package Some::Class;
use Role::Tiny::With;
with 'Some::Role';
# Le rôle est maintenant mélangé

DESCRIPTION

"Role::Tiny" est un outil minimaliste de composition de rôles. "Role::Tiny::With" fournit une fonction "with" pour composer de tels rôles.
