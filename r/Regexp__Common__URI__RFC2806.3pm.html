NOM

Regexp::Common::URI::RFC2806 -- Définitions de la RFC2806 ;

SYNOPIS

use Regexp::Common::URI::RFC2806 qw /:ALL/;

DESCRIPTION

Ce paquet exporte des définitions de la RFC2806. Son usage prévu est uniquement pour les sous-modules de Regexp::Common::URI. Son interface peut changer sans préavis.
