NOM

Regexp::Common::SEN -- fournir des expressions régulières pour les numéros socio-économiques.

SYNOPSIS

use Regexp::Common qw /SEN/;
while (<>) {
    /^$RE{SEN}{USA}{SSN}$/    and  print "Numéro de sécurité sociale\n";
}

DESCRIPTION

Veuillez consulter le manuel de Regexp::Common pour une description générale du fonctionnement de cette interface.

N'utilisez pas ce module directement, mais chargez-le via Regexp::Common.

"$RE{SEN}{USA}{SSN}{-sep}"

Retourne un motif qui correspond à un numéro de sécurité sociale (SSN) américain. Les SSN sont constitués de trois groupes de chiffres, séparés par un tiret ("-"). Ce motif ne vérifie que la structure valide, c'est-à-dire qu'il valide si un numéro est un SSN valide, était un SSN valide, ou pourrait être un SSN valide à l'avenir. Il y a près d'un milliard de SSN possibles, et environ 400 millions sont utilisés ou l'ont été.

Si "-sep=P" est spécifié, le motif P est utilisé comme séparateur entre les groupes de chiffres.

Sous "-keep" (voir Regexp::Common) :

S1
capture l'intégralité du SSN.
S2
capture le premier groupe de chiffres (le numéro de zone).
S3
capture le deuxième groupe de chiffres (le numéro de groupe).
S4
capture le troisième groupe de chiffres (le numéro de série).
