NOM

Regexp::Common::CC -- fournit des motifs pour les numéros de carte de crédit.

SYNTAXE

use Regexp::Common qw /CC/;
while (<>) {
    /^$RE{CC}{Mastercard}$/   and  print "Numéro de carte Mastercard\n";
}

DESCRIPTION

Veuillez consulter le manuel de Regexp::Common pour une description générale du fonctionnement de cette interface.

N'utilisez pas ce module directement, mais chargez-le via Regexp::Common.

Ce module offre des motifs pour les numéros de carte de crédit de plusieurs types de cartes majeurs. Actuellement, les cartes prises en charge sont : Mastercard, Amex, Diners Club et Discover.
