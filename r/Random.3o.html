Module Random
: sig end

Générateurs de nombres pseudo-aléatoires (PRNG).

Avec plusieurs domaines, chaque domaine possède son propre générateur qui évolue indépendamment des générateurs des autres domaines. Lorsqu'un domaine est créé, son générateur est initialisé en divisant l'état du générateur associé au domaine parent.

En revanche, tous les fils d'exécution (threads) au sein d'un domaine partagent le même générateur local au domaine. Des générateurs indépendants peuvent être créés avec la fonction Random.split et utilisés avec les fonctions du module Random.State.

Avant5.0 La génération de valeurs aléatoires utilisait un algorithme différent. Cela affecte toutes les fonctions de ce module qui renvoient des valeurs aléatoires.

Fonctions de base

val init : int -> unit

Initialise le générateur local au domaine, en utilisant l'argument comme germe (seed). Le même germe produira toujours la même séquence de nombres.

val full_init : int array -> unit

Identique à Random.init mais prend plus de données comme germe.

val self_init : unit -> unit

Initialise le générateur local au domaine avec un germe aléatoire choisi de manière dépendante du système. Si un générateur de nombres pseudo-aléatoires cryptographiquement sécurisé est disponible sur la machine hôte, il est utilisé pour fournir un germe très aléatoire. Sinon, un germe moins aléatoire est calculé à partir de paramètres système (heure actuelle, identifiants de processus, état local au domaine).

val bits : unit -> int

Retourne 30 bits aléatoires sous forme d'entier non négatif.

val int : int -> int

Random.int bound renvoie un entier aléatoire compris entre 0 (inclus) et bound (exclu). bound doit être supérieur à 0 et inférieur à 2^30.

Lève Invalid_argument si bound <= 0 ou bound >= 2^30.

val full_int : int -> int

Random.full_int bound renvoie un entier aléatoire compris entre 0 (inclus) et bound (exclu). bound peut être n'importe quel entier positif.

Si bound est inférieur à 2^31, alors Random.full_int bound produit une sortie identique sur les systèmes avec des tailles d'int variables.

Si bound est inférieur à 2^30, alors Random.full_int bound est égal à Random.int bound.

Si bound est supérieur ou égal à 2^30 (sur les systèmes 64 bits, ou dans des environnements non standard comme JavaScript), alors Random.full_int renvoie une valeur tandis que Random.int lève Invalid_argument.

Depuis 4.13

Lève Invalid_argument si bound <= 0.

val int_in_range : min:int -> max:int -> int

Random.int_in_range ~min ~max renvoie un entier aléatoire compris entre min (inclus) et max (inclus). min et max peuvent être négatifs ; min doit être inférieur ou égal à max.

Si les deux bornes tiennent dans des entiers signés 32 bits (c'est-à-dire si -2^31 <= min et max < 2^31), alors int_in_range produit une sortie identique sur les systèmes avec des tailles d'int variables.

Depuis 5.2

Lève Invalid_argument si min > max.

val int32 : Int32.t -> Int32.t

Random.int32 bound renvoie un entier aléatoire compris entre 0 (inclus) et bound (exclu). bound doit être supérieur à 0.

Lève Invalid_argument si bound <= 0.

val int32_in_range : min:int32 -> max:int32 -> int32

Random.int32_in_range ~min ~max renvoie un entier aléatoire compris entre min (inclus) et max (inclus). min et max peuvent être négatifs ; min doit être inférieur ou égal à max.

Depuis 5.2

Lève Invalid_argument si min > max.

val nativeint : Nativeint.t -> Nativeint.t

Random.nativeint bound renvoie un entier aléatoire compris entre 0 (inclus) et bound (exclu). bound doit être supérieur à 0.

Lève Invalid_argument si bound <= 0.

val nativeint_in_range : min:nativeint -> max:nativeint -> nativeint

Random.nativeint_in_range ~min ~max renvoie un entier aléatoire compris entre min (inclus) et max (inclus). min et max peuvent être négatifs ; min doit être inférieur ou égal à max.

Depuis 5.2

Lève Invalid_argument si min > max.

val int64 : Int64.t -> Int64.t

Random.int64 bound renvoie un entier aléatoire compris entre 0 (inclus) et bound (exclu). bound doit être supérieur à 0.

Lève Invalid_argument si bound <= 0.

val int64_in_range : min:int64 -> max:int64 -> int64

Random.int64_in_range ~min ~max renvoie un entier aléatoire compris entre min (inclus) et max (inclus). min et max peuvent être négatifs ; min doit être inférieur ou égal à max.

Depuis 5.2

Lève Invalid_argument si min > max.

val float : float -> float

Random.float bound renvoie un nombre à virgule flottante aléatoire compris entre 0 et bound (inclus). Si bound est négatif, le résultat est négatif ou zéro. Si bound est 0, le résultat est 0.

val bool : unit -> bool

Random.bool () renvoie true ou false avec une probabilité de 0.5 chacun.

val bits32 : unit -> Int32.t

Random.bits32 () renvoie 32 bits aléatoires sous forme d'entier compris entre Int32.min_int et Int32.max_int.

Depuis 4.14

val bits64 : unit -> Int64.t

Random.bits64 () renvoie 64 bits aléatoires sous forme d'entier compris entre Int64.min_int et Int64.max_int.

Depuis 4.14

val nativebits : unit -> Nativeint.t

Random.nativebits () renvoie 32 ou 64 bits aléatoires (selon la largeur de bits de la plateforme) sous forme d'entier compris entre Nativeint.min_int et Nativeint.max_int.

Depuis 4.14

Fonctions avancées

Les fonctions du module Random.State manipulent explicitement l'état actuel du générateur aléatoire. Cela permet d'utiliser un ou plusieurs PRNG déterministes, même dans un programme multi-threadé, sans interférence avec d'autres parties du programme.

module State : sig end

val get_state : unit -> State.t

get_state() renvoie une copie fraîche de l'état actuel du générateur local au domaine (utilisé par les fonctions de base).

val set_state : State.t -> unit

set_state s met à jour l'état actuel du générateur local au domaine (utilisé par les fonctions de base) en copiant l'état s dedans.

val split : unit -> State.t

Tire un nouvel état PRNG de l'état actuel du générateur local au domaine utilisé par les fonctions par défaut. (L'état du générateur local au domaine est modifié.) Voir Random.State.split.

Depuis 5.0
