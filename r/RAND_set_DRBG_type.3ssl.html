RAND_set_DRBG_type(3ssl)

Paquet: openssl

Licences: Apache-2.0

RAND_SET_DRBG_TYPE(3ssl) OpenSSL RAND_SET_DRBG_TYPE(3ssl)

NOM

RAND_set_DRBG_type, RAND_set_seed_source_type - spécifier les types du générateur de nombres aléatoires global

SYNTAXE

#include <openssl/rand.h>
int RAND_set_DRBG_type(OSSL_LIB_CTX *ctx, const char *drbg, const char *propq,
                       const char *cipher, const char *digest);
int RAND_set_seed_source_type(OSSL_LIB_CTX *ctx, const char *seed,
                              const char *propq);

DESCRIPTION

RAND_set_DRBG_type() spécifie le générateur de bits aléatoires qui sera utilisé dans le contexte de bibliothèque ctx. Un générateur de nom drbg avec les propriétés propq sera récupéré. Il sera instancié avec soit cipher soit digest comme algorithme cryptographique sous-jacent. Ceci spécifie le type qui sera utilisé pour les instances aléatoires publiques, primaires et privées.

RAND_set_seed_source_type() spécifie la source de graine qui sera utilisée dans le contexte de bibliothèque ctx. La source de graine de nom seed avec les propriétés propq sera récupérée et utilisée pour semer le générateur de bits aléatoires primaire.

VALEURS DE RETOUR

Ces fonctions retournent 1 en cas de succès et 0 en cas d'échec.

NOTES

Ces fonctions doivent être appelées avant que les générateurs de bits aléatoires ne soient créés pour la première fois dans le contexte de bibliothèque. Elles retourneront une erreur si l'appel est fait trop tard.

Le DRBG par défaut est "CTR-DRBG" utilisant le chiffrement "AES-256-CTR".

La source de graine par défaut peut être configurée lors de la compilation d'OpenSSL en définissant -DOPENSSL_DEFAULT_SEED_SRC=SEED-SRC. Si ce n'est pas défini, "SEED-SRC" est utilisé.

EXEMPLES

unsigned char bytes[100];
RAND_set_seed_source_type(NULL, "JITTER", NULL);
RAND_bytes(bytes, 100);

VOIR AUSSI

EVP_RAND(3), RAND_get0_primary(3)

HISTORIQUE

Ces fonctions ont été ajoutées dans OpenSSL 3.0.
