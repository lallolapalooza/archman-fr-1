Return::MultiLevel(3) Documentation Perl fournie par l'utilisateur Return::MultiLevel(3)

NOM

Return::MultiLevel - Retourner à travers plusieurs niveaux d'appel

VERSION

version 0.08

SYNOPSIS

use Return::MultiLevel qw(with_return);
sub inner {
  my ($f) = @_;
  $f->(42);  # retour implicite depuis 'with_return' ci-dessous
  print "Vous ne voyez pas ça\n";
}
sub outer {
  my ($f) = @_;
  inner($f);
  print "Vous ne voyez pas ça non plus\n";
}
my $result = with_return {
  my ($return) = @_;
  outer($return);
  die "Pas atteint";
};
print $result, "\n";  # 42

DESCRIPTION

Ce module fournit un moyen de retourner immédiatement d'une pile d'appels profondément imbriquée. C'est similaire aux exceptions, mais les exceptions ne s'arrêtent pas automatiquement à une trame cible (et elles peuvent être interceptées par des trames intermédiaires en utilisant "eval"). En d'autres termes, c'est plus proche de setjmp(3)/longjmp(3) que de "die".

Une autre façon de voir les choses est que le coderef de "retour multi-niveaux" représente une continuation à usage unique/vers le haut uniquement.

Fonctions

Les fonctions suivantes sont disponibles (et peuvent être importées à la demande).

with_return BLOC
Exécute BLOC, lui passant une référence de code (appelée $return dans cette description) comme seul argument. Retourne ce que BLOC retourne.

Si $return est appelé, cela provoque un retour immédiat de "with_return". Tous les arguments passés à $return deviennent la valeur de retour de "with_return" (si "with_return" est dans un contexte scalaire, il retournera le dernier argument passé à $return).

Il est interdit d'invoquer $return après la fin de son bloc BLOC englobant. En particulier, il est interdit d'appeler $return deux fois.

DEBUGAGE

Ce module utilise "unwind" de "Scope::Upper" pour fonctionner. Si "Scope::Upper" n'est pas disponible, il substitue sa propre implémentation Perl pure. Vous pouvez forcer l'utilisation de la version Perl pure, quelle que soit la situation, en définissant la variable d'environnement "RETURN_MULTILEVEL_PP" à 1.

Si vous obtenez le message d'erreur "Attempt to re-enter dead call frame", cela signifie que quelque chose a appelé un $return depuis l'extérieur de son bloc "with_return { ... }". Vous pouvez obtenir une trace de la pile de l'emplacement de ce "with_return" en définissant la variable d'environnement "RETURN_MULTILEVEL_DEBUG" à 1.

ATTENTION

Vous ne pouvez pas utiliser ce module pour retourner à travers des appels de fonction implicites, tels que les gestionnaires de signaux (comme $SIG{ALRM}) ou les destructeurs ("sub DESTROY { ... }"). Ceux-ci sont invoqués automatiquement par perl et ne font pas partie de la chaîne d'appels normale.
