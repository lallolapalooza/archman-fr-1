NOM

Regexp::Common::lingua -- fournit des expressions régulières pour les éléments liés à la langue.

SYNOPSIS

use Regexp::Common qw /lingua/;
while (<>) {
    /^$RE{lingua}{palindrome}$/    and  print "est un palindrome\n";
}

DESCRIPTION

Veuillez consulter le manuel de Regexp::Common pour une description générale du fonctionnement de cette interface.

N'utilisez pas ce module directement, mais chargez-le via Regexp::Common.

"$RE{lingua}{palindrome}"

Retourne un motif qui reconnaît un palindrome, une chaîne qui est la même si on la renverse. Par défaut, il ne correspond qu'aux chaînes composées de lettres, mais cela peut être modifié en utilisant l'option "{-chars}". Cette option prend une classe de caractères (par défaut "[A-Za-z]") comme argument.

Si "{-keep}" est utilisé, seul $1 sera défini, et sera défini sur la correspondance entière.

Ce motif nécessite au moins perl 5.6.0.
