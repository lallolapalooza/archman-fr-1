RSA_size(3ssl)

Paquet: openssl

Licences: Apache-2.0

RSA_SIZE(3ssl) OpenSSL RSA_SIZE(3ssl)

NOM

RSA_size, RSA_bits, RSA_security_bits - obtenir la taille ou les bits de sécurité RSA

SYNTAXE

#include <openssl/rsa.h>
int RSA_bits(const RSA *rsa);

Les fonctions suivantes ont été dépréciées depuis OpenSSL 3.0, et peuvent être entièrement masquées en définissant OPENSSL_API_COMPAT avec une valeur de version appropriée, voir openssl_user_macros(7):

int RSA_size(const RSA *rsa);
int RSA_security_bits(const RSA *rsa);

DESCRIPTION

RSA_bits() retourne le nombre de bits significatifs.

rsa et rsa->n ne doivent pas être NULL.

Les autres fonctions décrites sur cette page sont dépréciées. Les applications devraient plutôt utiliser EVP_PKEY_get_size(3), EVP_PKEY_get_bits(3) et EVP_PKEY_get_security_bits(3).

RSA_size() retourne la taille du module RSA en octets. Elle peut être utilisée pour déterminer la quantité de mémoire à allouer pour une valeur RSA chiffrée.

RSA_security_bits() retourne le nombre de bits de sécurité de la clé rsa donnée. Voir BN_security_bits(3).

VALEURS DE RETOUR

RSA_bits() retourne le nombre de bits dans la clé.

RSA_size() retourne la taille du module en octets.

RSA_security_bits() retourne le nombre de bits de sécurité.

VOIR AUSSI

BN_num_bits(3)

HISTORIQUE

Les fonctions RSA_size() et RSA_security_bits() ont été dépréciées dans OpenSSL 3.0.

La fonction RSA_bits() a été ajoutée dans OpenSSL 1.1.0.
