NOM

Regexp::Common::URI::RFC1035 -- Définitions de la RFC1035 ;

SYNTAXE

use Regexp::Common::URI::RFC1035 qw /:ALL/;

DESCRIPTION

Ce paquet exporte des définitions de la RFC1035. Son usage prévu est uniquement pour les sous-modules de Regexp::Common::URI. Son interface peut changer sans préavis.

RÉFÉRENCES

Mockapetris, P.: DOMAIN NAMES - IMPLEMENTATION AND SPECIFICATION. Novembre 1987.
