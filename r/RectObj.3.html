NOM

RectObj — La classe de widget RectObj

SYNOPSIS

#include <Xm/Xm.h>

DESCRIPTION

RectObj n'est jamais instancié. Son seul but est de servir de classe parente à d'autres classes de widgets.

Classes

RectObj hérite le comportement et une ressource de Object.

Le pointeur de classe est rectObjClass.

Le nom de la classe est RectObj.

Nouvelles Ressources

Le tableau suivant définit un ensemble de ressources de widget utilisées par le programmeur pour spécifier des données. Le programmeur peut également définir les valeurs des ressources pour les classes filles afin d'établir des attributs pour ce widget. Pour faire référence à une ressource par son nom ou sa classe dans un fichier .Xdefaults, supprimez le préfixe XmN ou XmC et utilisez les lettres restantes. Pour spécifier l'une des valeurs définies pour une ressource dans un fichier .Xdefaults, supprimez le préfixe Xm et utilisez les lettres restantes (en majuscules ou en minuscules, mais incluez les traits d'union entre les mots). Les codes dans la colonne d'accès indiquent si la ressource donnée peut être définie lors de la création (C), via XtSetValues (S), récupérée via XtGetValues (G), ou non applicable (N/A).

XmNancestorSensitive
Indique si le descendant d'un gadget reçoit des événements d'entrée. Si vous changez l'argument en utilisant XtSetSensitive pour maintenir l'intégrité des données (voir XmNsensitive), la valeur par défaut est le ET bit à bit de la ressource XmNsensitive du parent et de XmNancestorSensitive.
XmNborderWidth
Indique la largeur de la ligne de bordure de la zone d'affichage rectangulaire de RectObj.
XmNheight
Indique la hauteur intérieure (sans la bordure) de la zone d'affichage rectangulaire de RectObj.
XmNsensitive
Définit si un RectObj reçoit des événements d'entrée. Si un RectObj est sensible, le parent envoie tous les événements clavier, bouton, mouvement, entrée/sortie de fenêtre et focus à ce gadget. Les gadgets insensibles ne reçoivent pas ces événements. Utilisez XtSetSensitive pour modifier l'argument de sensibilité. L'utilisation de XtSetSensitive garantit que si un widget parent a XmNsensitive réglé sur False, le bit de sensibilité du descendant de ce widget est correctement réglé.
XmNwidth
Indique la largeur intérieure (sans la bordure) de la zone d'affichage rectangulaire de RectObj.
XmNx
Indique la coordonnée x du coin supérieur gauche de la zone d'affichage rectangulaire de RectObj. La valeur est relative au coin supérieur gauche de l'intérieur de la fenêtre parente.
XmNy
Indique la coordonnée y du coin supérieur gauche de la zone d'affichage rectangulaire de RectObj. La valeur est relative au coin supérieur gauche de l'intérieur de la fenêtre parente.

RectObj(3) — Manpages Arch Linux

NOM

RectObj - Objet rectangle.

SYNTAXE

#include <RectObj.h>

DESCRIPTION

La classe RectObj est une classe de base qui définit le comportement général des objets rectangles.

FONCTIONS PUBLIQUES

Fonction Description
RectObj() Constructeur par défaut.
~RectObj() Destructeur.
SetRect(int x, int y, int w, int h) Définit la position et les dimensions du rectangle.
GetX() Retourne la coordonnée x du rectangle.
GetY() Retourne la coordonnée y du rectangle.
GetWidth() Retourne la largeur du rectangle.
GetHeight() Retourne la hauteur du rectangle.

MEMBRES PROTÉGÉS

Membre Description
x Coordonnée x du coin supérieur gauche.
y Coordonnée y du coin supérieur gauche.
width Largeur du rectangle.
height Hauteur du rectangle.
