Valeurs de résultat.

Les valeurs de résultat gèrent les résultats de calcul et les erreurs de manière explicite et déclarative sans recourir aux exceptions.

Depuis 4.08

Résultats

type ('a, 'e) t = ('a, 'e) result =
| Ok of 'a
| Error of 'e

Le type pour les valeurs de résultat. Soit une valeur Ok v soit une erreur Error e.

val ok : 'a -> ('a, 'e) result

ok v est Ok v.

val error : 'e -> ('a, 'e) result

error e est Error e.

val value : ('a, 'e) result -> default:'a -> 'a

value r ~default est v si r est Ok v et default sinon.

val get_ok : ('a, 'e) result -> 'a

get_ok r est v si r est Ok v et lève une exception sinon.

Lève Invalid_argument si r est Error _.

val get_ok' : ('a, string) result -> 'a

get_ok' est similaire à Result.get_ok mais en cas d'erreur, utilise le message d'erreur pour lever Invalid_argument.

Depuis 5.4

val get_error : ('a, 'e) result -> 'e

get_error r est e si r est Error e et lève une exception sinon.

Lève Invalid_argument si r est Ok _.

val error_to_failure : ('a, string) result -> 'a

error_to_failure r est v si r est Ok v et lève Failure e si r est Error e.

Depuis 5.4

val bind : ('a, 'e) result -> ('a -> ('b, 'e) result) -> ('b, 'e) result

bind r f est f v si r est Ok v et r si r est Error _.

val join : (('a, 'e) result, 'e) result -> ('a, 'e) result

join rr est r si rr est Ok r et rr si rr est Error _.

val map : ('a -> 'b) -> ('a, 'e) result -> ('b, 'e) result

map f r est Ok (f v) si r est Ok v et r si r est Error _.

val product : ('a, 'e) result -> ('b, 'e) result -> ('a * 'b, 'e) result

product r0 r1 est Ok (v0, v1) si r0 est Ok v0 et r1 est Ok v2 et sinon retourne l'erreur de r0, le cas échéant, ou l'erreur de r1.

Depuis 5.4

val map_error : ('e -> 'f) -> ('a, 'e) result -> ('a, 'f) result

map_error f r est Error (f e) si r est Error e et r si r est Ok _.

val fold : ok:('a -> 'c) -> error:('e -> 'c) -> ('a, 'e) result -> 'c

fold ~ok ~error r est ok v si r est Ok v et error e si r est Error e.

val retract : ('a, 'a) result -> 'a

retract r est v si r est Ok v ou Error v.

Depuis 5.4

val iter : ('a -> unit) -> ('a, 'e) result -> unit

iter f r est f v si r est Ok v et () sinon.

val iter_error : ('e -> unit) -> ('a, 'e) result -> unit

iter_error f r est f e si r est Error e et () sinon.

Prédicats et comparaisons

val is_ok : ('a, 'e) result -> bool

is_ok r est true si et seulement si r est Ok _.

val is_error : ('a, 'e) result -> bool

is_error r est true si et seulement si r est Error _.

val equal : ok:('a -> 'a -> bool) -> error:('e -> 'e -> bool) -> ('a, 'e) result -> ('a, 'e) result -> bool

equal ~ok ~error r0 r1 teste l'égalité de r0 et r1 en utilisant ok et error pour comparer respectivement les valeurs encapsulées par Ok _ et Error _.

val compare : ok:('a -> 'a -> int) -> error:('e -> 'e -> int) -> ('a, 'e) result -> ('a, 'e) result -> int

compare ~ok ~error r0 r1 ordonne totalement r0 et r1 en utilisant ok et error pour comparer respectivement les valeurs encapsulées par Ok _ et Error _. Les valeurs Ok _ sont plus petites que les valeurs Error _.

Conversion

val to_option : ('a, 'e) result -> 'a option

to_option r est r sous forme d'option, mappant Ok v à Some v et Error _ à None.

val to_list : ('a, 'e) result -> 'a list

to_list r est [v] si r est Ok v et [] sinon.

val to_seq : ('a, 'e) result -> 'a Seq.t

to_seq r est r sous forme de séquence. Ok v est la séquence singleton contenant v et Error _ est la séquence vide.
