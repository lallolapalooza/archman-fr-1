NOM

Regexp::Common::list -- fournir des expressions régulières pour les listes

SYNTAXE

use Regexp::Common qw /list/;
while (<>) {
    /$RE{list}{-pat => '\w+'}/          and print "Liste de mots";
    /$RE{list}{-pat =>$RE{num}{real}}/ and print "Liste de nombres";
}

DESCRIPTION

Veuillez consulter le manuel de Regexp::Common pour une description générale du fonctionnement de cette interface.

N'utilisez pas ce module directement, mais chargez-le via Regexp::Common.

"$RE{list}{-pat}{-sep}{-lastsep}"

Renvoie un motif correspondant à une liste d'au moins deux sous-chaînes.

Si "-pat=P" est spécifié, il définit le motif de chaque sous-chaîne de la liste. Par défaut, P est "qr/.*?\S/". Dans Regexp::Common 0.02 ou antérieur, le motif par défaut était "qr/.*?/". Mais cela correspondait à un unique espace, entraînant une analyse non intentionnelle de "a, b, and c" comme une liste de quatre éléments au lieu de 3 (avec "-word" étant "(?:and)"). Une conséquence est qu'une liste de la forme "a,,b" ne sera plus analysée. Utilisez le motif "qr /.*?/" pour pouvoir analyser cela, mais voir la remarque précédente.

Si "-sep=P" est spécifié, il définit le motif P utilisé comme séparateur entre chaque paire de sous-chaînes de la liste, sauf les deux dernières. Par défaut P est "qr/\s*,\s*/".

Si "-lastsep=P" est spécifié, il définit le motif P utilisé comme séparateur entre les deux dernières sous-chaînes de la liste. Par défaut P est le même que le motif spécifié par le drapeau "-sep".

Par exemple :

$RE{list}{-pat=>'\w+'}                # correspond à une liste de caractères de mots
$RE{list}{-pat=>$RE{num}{real}}       # correspond à une liste de nombres
$RE{list}{-sep=>"\t"}                 # correspond à une liste séparée par des tabulations
$RE{list}{-lastsep=>',\s+and\s+'}     # correspond à une liste en anglais correct

Sous "-keep" :

$1
capture toute la liste
$2
capture le dernier séparateur

"$RE{list}{conj}{-word=PATTERN}"

Un alias pour "$RE{list}{-lastsep=>'\s*,?\s*PATTERN\s*'}"

Si "-word" n'est pas spécifié, le motif par défaut est "qr/and|or/".

Par exemple :

$RE{list}{conj}{-word=>'et'}        # correspond à Jean, Paul, et Satre
$RE{list}{conj}{-word=>'oder'}      # correspond à Bonn, Koln oder Hamburg

"$RE{list}{and}"

Un alias pour "$RE{list}{conj}{-word=>'and'}"

"$RE{list}{or}"

Un alias pour "$RE{list}{conj}{-word=>'or'}"
