NOM

Regexp::Common::URI::telnet -- Retourne un modèle pour les URI telnet.

SYNTAXE

use Regexp::Common qw /URI/;
while (<>) {
    /$RE{URI}{telnet}/       and  print "Contient un URI telnet.\n";
}

DESCRIPTION

$RE{URI}{telnet}

Retourne un modèle qui correspond aux URI telnet, tels que définis par la RFC 1738. Les URI Telnet ont le format :

"telnet:" "//" [ utilisateur [ ":" mot de passe ] "@" ] hôte [ ":" port ] [ "/" ]

Sous "{-keep}", les éléments suivants sont retournés :

$1
L'URI complet.
$2
Le schéma.
$3
La combinaison nom d'utilisateur:mot de passe, ou juste le nom d'utilisateur s'il n'y a pas de mot de passe.
$4
Le nom d'utilisateur, s'il est fourni.
$5
Le mot de passe, s'il est fourni.
$6
La combinaison hôte:port, ou juste l'hôte s'il n'y a pas de port.
$7
L'hôte.
$8
Le port, s'il est fourni.
$9
La barre oblique finale, le cas échéant.

RÉFÉRENCES

[RFC 1738]
Berners-Lee, Tim, Masinter, L., McCahill, M.: Uniform Resource Locators (URL). December 1994.

VOIR AUSSI

Regexp::Common::URI pour les autres URI supportés.
