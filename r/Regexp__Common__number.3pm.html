NOM

Regexp::Common::number -- fournit des expressions régulières pour les nombres

SYNOPSIS

use Regexp::Common qw /number/;
while (<>) {
    /^$RE{num}{int}$/                and  print "Entier\n";
    /^$RE{num}{real}$/               and  print "Réel\n";
    /^$RE{num}{real}{-base => 16}$/  and  print "Réel hexadécimal\n";
}

DESCRIPTION

Veuillez consulter le manuel de Regexp::Common pour une description générale du fonctionnement de cette interface.

N'utilisez pas ce module directement, mais chargez-le via Regexp::Common.

"$RE{num}{int}{-base}{-sep}{-group}{-places}{-sign}"

Retourne un modèle qui correspond à un entier.

Si "-base => B" est spécifié, l'entier est en base B, avec "2 <= B <= 36". Pour les bases supérieures à 10, les lettres majuscules sont utilisées. La base par défaut est 10.

Si "-sep => P" est spécifié, le modèle P est requis comme marqueur de groupement dans le nombre. Si cette option n'est pas donnée, aucun marqueur de groupement n'est utilisé.

Si "-group => N" est spécifié, les chiffres entre les marqueurs de groupement doivent être groupés par séquences de exactement N chiffres. La valeur par défaut de N est 3. Si "-group => N,M" est spécifié, les chiffres entre les marqueurs de groupement doivent être groupés par séquences d'au moins N chiffres, et au plus M chiffres. Cette option est ignorée sauf si l'option "-sep" est utilisée.

Si "-places => N" est spécifié, l'entier reconnu doit avoir exactement N chiffres de longueur. Si "-places => N,M" est spécifié, l'entier doit avoir au moins N caractères de long, et au plus M. Il n'y a pas de valeur par défaut, ce qui signifie que les entiers sont illimités en taille. Cette option est ignorée si l'option "-sep" est utilisée.

Si "-sign => P" est utilisé, il s'agit d'un modèle que le signe de début doit correspondre. Ceci vaut par défaut "[-+]?", ce qui signifie que le nombre est facultativement précédé d'un moins ou d'un plus. Si vous souhaitez faire correspondre des entiers non signés, utilisez "$RE{num}{int}{-sign => ''}".

Par exemple :

$RE{num}{int}                          # correspond à 1234567
$RE{num}{int}{-sep=>','}               # correspond à 1,234,567
$RE{num}{int}{-sep=>',?'}              # correspond à 1234567 ou 1,234,567
$RE{num}{int}{-sep=>'.'}{-group=>4}    # correspond à 1.2345.6789

Sous "-keep" (voir Regexp::Common) :

$1
capture le nombre entier
$2
capture le signe optionnel du nombre
$3
capture l'ensemble complet des chiffres

"$RE{num}{real}{-base}{-radix}{-places}{-sep}{-group}{-expon}"

Retourne un modèle qui correspond à un nombre à virgule flottante.

Si "-base=N" est spécifié, le nombre est supposé être dans cette base (avec A..Z représentant les chiffres pour 11..36). Par défaut, la base est 10.

Si "-radix=P" est spécifié, le modèle P est utilisé comme point de radix pour le nombre (c'est-à-dire le "point décimal" en base 10). La valeur par défaut est "qr/[.]/".

Si "-places=N" est spécifié, le nombre est supposé avoir exactement N places après le point de radix. Si "-places=M,N" est spécifié, le nombre est supposé avoir entre M et N places après le point de radix. Par défaut, le nombre de places n'est pas restreint.

Si "-sep=P" est spécifié, le modèle P est requis comme marqueur de groupement dans la section pré-radix du nombre. Par défaut, aucun séparateur n'est autorisé.

Si "-group=N" est spécifié, les chiffres entre les séparateurs de groupement doivent être groupés en séquences de exactement N caractères. La valeur par défaut de N est 3.

Si "-expon=P" est spécifié, le modèle P est utilisé comme marqueur d'exposant. La valeur par défaut de P est "qr/[Ee]/".

Si "-sign=P" est spécifié, le modèle P est utilisé pour correspondre au signe de début (et au signe de l'exposant). Par défaut, il vaut "[-+]?", ce qui signifie qu'un signe plus ou moins optionnel peut être utilisé.

Par exemple :

$RE{num}{real}                  # correspond à 123.456 ou -0.1234567
$RE{num}{real}{-places=>2}      # correspond à 123.45 ou -0.12
$RE{num}{real}{-places=>'0,3'}  # correspond à 123.456 ou 0 ou 9.8
$RE{num}{real}{-sep=>'[,.]?'}   # correspond à 123,456 ou 123.456
$RE{num}{real}{-base=>3'}       # correspond à 121.102

Sous "-keep" :

$1
capture la correspondance entière
$2
capture le signe optionnel du nombre
$3
capture la mantisse complète
$4
capture la partie entière de la mantisse
$5
capture le point de radix
$6
capture la partie fractionnaire de la mantisse
$7
capture le marqueur d'exposant optionnel
$8
capture la valeur entière de l'exposant
$9
capture le signe optionnel de l'exposant
$10
capture les chiffres de l'exposant

NOM

Regexp::Common::number - Expressions rationnelles pour les nombres.

SYNTAXE

  use Regexp::Common;

  # Correspond à un nombre décimal
  $RE{num}{decimal}

  # Correspond à un nombre entier
  $RE{num}{integer}

  # Correspond à un carré (avec des restrictions)
  $RE{num}{square}

  # Correspond à un nombre romain
  $RE{num}{roman}

DESCRIPTION

Cette collection d'expressions rationnelles de Regexp::Common fournit des motifs pour la correspondance des nombres sous diverses formes.

"$RE{num}{integer}"

Correspond à un entier (signé ou non). Les options suivantes sont disponibles :

-base=<N>
Suppose que le nombre est dans la base N. Les lettres majuscules A à Z représentent les chiffres pour 11 à 36. Par défaut, la base est 10.
-sign=[+-]?
Spécifie quel signe est autorisé. Par défaut, [+-]? (un signe plus ou moins facultatif).
-min=<N>
Le nombre doit être au moins N.
-max=<N>
Le nombre doit être au plus N.
-between=<M,N>
Le nombre doit être compris entre M et N, compris.

Exemples :

$RE{num}{integer}                  # correspond à 123, -45, +6789
$RE{num}{integer}{-sign=>'+'}        # correspond à +123, +45
$RE{num}{integer}{-sign=>'-'}        # correspond à -123, -45
$RE{num}{integer}{-min=>100}         # correspond à 100, 101, ...
$RE{num}{integer}{-max=>-10}        # correspond à -10, -11, ...
$RE{num}{integer}{-between=>'10,20'} # correspond à 10, 11, ..., 20
$RE{num}{integer}{-base=>16}       # correspond à 123 ou ABC (en hexadécimal)

Sous -keep :

$1
capture l'intégralité de la correspondance.
$2
capture le signe facultatif du nombre.
$3
capture la partie numérique du nombre.

"$RE{num}{real}"

Correspond à un nombre décimal à virgule flottante. Les options suivantes sont disponibles :

-base=<N>
Suppose que le nombre est dans la base N. Les lettres majuscules A à Z représentent les chiffres pour 11 à 36. Par défaut, la base est 10.
-radix=<P>
Le motif P est utilisé comme point décimal du nombre. Par défaut, "qr/[.]/".
-places=<N>
Le nombre doit avoir exactement N chiffres après le point décimal. Si -places=<M,N> est spécifié, le nombre doit avoir entre M et N chiffres après le point décimal. Par défaut, le nombre de chiffres est illimité.
-sep=<P>
Le motif P est requis comme séparateur de regroupement dans la partie entière du nombre. Par défaut, aucun séparateur n'est autorisé.
-group=<N>
Les chiffres entre les séparateurs de regroupement doivent être groupés en séquences de exactement N chiffres. La valeur par défaut de N est 3.
-exponent
Autorise un exposant facultatif (par exemple, 1.23e4).

Exemples :

$RE{num}{real}                  # correspond à 123.456 ou -0.1234567 ou 1e10
$RE{num}{real}{-places=>2}      # correspond à 123.45 ou -0.12
$RE{num}{real}{-places=>'0,3'}  # correspond à 123.456 ou 0 ou 9.8
$RE{num}{real}{-sep=>'[,.]?'}   # correspond à 123,456 ou 123.456
$RE{num}{real}{-group=>4}       # correspond à 12,3456.789 ou 123456789
$RE{num}{real}{-base=>3}       # correspond à 121.102
$RE{num}{real}{-exponent}       # correspond à 1.23e45

Sous -keep :

$1
capture l'intégralité de la correspondance.
$2
capture le signe facultatif du nombre.
$3
capture la partie entière de la mantisse.
$4
capture le point décimal.
$5
capture la partie fractionnaire de la mantisse.
$6
capture l'exposant (si -exponent est utilisé).

"$RE{num}{decimal}"

Identique à $RE{num}{real}, sauf qu'un exposant n'est pas autorisé. Par conséquent, ceci renvoie un motif correspondant aux nombres *décimaux*.

Si -base=<N> est spécifié, le nombre est supposé être dans cette base (avec A..Z représentant les chiffres pour 11..36). Par défaut, la base est 10.

Si -radix=<P> est spécifié, le motif P est utilisé comme point décimal du nombre (c'est-à-dire le "point décimal" en base 10). La valeur par défaut est "qr/[.]/".

Si -places=<N> est spécifié, le nombre est supposé avoir exactement N chiffres après le point décimal. Si -places=<M,N> est spécifié, le nombre est supposé avoir entre M et N chiffres après le point décimal. Par défaut, le nombre de chiffres est illimité.

Si -sep=<P> est spécifié, le motif P est requis comme séparateur de regroupement dans la partie non décimale du nombre. Par défaut, aucun séparateur n'est autorisé.

Si -group=<N> est spécifié, les chiffres entre les séparateurs de regroupement doivent être groupés en séquences de exactement N caractères. La valeur par défaut de N est 3.

Exemple :

$RE{num}{decimal}                  # correspond à 123.456 ou -0.1234567
$RE{num}{decimal}{-places=>2}      # correspond à 123.45 ou -0.12
$RE{num}{decimal}{-places=>'0,3'}  # correspond à 123.456 ou 0 ou 9.8
$RE{num}{decimal}{-sep=>'[,.]?'}   # correspond à 123,456 ou 123.456
$RE{num}{decimal}{-base=>3}       # correspond à 121.102

Sous -keep :

$1
capture l'intégralité de la correspondance.
$2
capture le signe facultatif du nombre.
$3
capture la mantisse complète.
$4
capture la partie entière de la mantisse.
$5
capture le point décimal.
$6
capture la partie fractionnaire de la mantisse.

"$RE{num}{square}"

Renvoie un motif qui correspond à un carré (décimal). Parce que l'arithmétique de Perl est perdue lors de l'utilisation de nombres entiers de plus de 53 bits, ce motif ne reconnaît que les nombres inférieurs à 9000000000000000, si vous utilisez un Perl configuré pour utiliser des entiers de 64 bits. Sinon, la limite est 2147483647. Ces restrictions ont été introduites dans les versions 2.116 et 2.117 de Regexp::Common. Indépendamment du fait que -keep soit spécifié, le nombre correspondant sera renvoyé dans $1.

"$RE{num}{roman}"

Renvoie un motif qui correspond à un nombre écrit en chiffres romains. La casse n'a pas d'importance. Il n'y a pas une seule façon d'écrire les nombres romains, mais nous ne correspondrons à rien. Nous exigeons que les nombres romains listent les symboles dans l'ordre (le plus grand d'abord). Les symboles pour mille ("M"), cent ("C"), dix ("X"), et un ("I") ne peuvent pas être répétés plus de quatre fois. Les symboles pour cinq cents ("D"), cinquante ("L"), et cinq ("V") ne peuvent apparaître qu'une fois. Une séquence de quatre caractères répétés peut également être écrite comme une soustraction : en utilisant le caractère répété une seule fois et en le faisant suivre du symbole qui est 5 ou 10 plus grand. Ainsi, quatre peut s'écrire "IIII", ou "IV", et neuf peut s'écrire "VIIII" ou "IX". Cela correspond à la plupart des utilisations modernes des nombres romains.

Le plus grand nombre qui sera reconnu est 4999, soit "MMMMDCCCCLXXXXVIIII", soit "MMMMCMXCIX".

Sous -keep, le nombre sera capturé dans $1.
