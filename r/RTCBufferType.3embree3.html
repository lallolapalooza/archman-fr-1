RTCBufferType(3) Embree Ray Tracing Kernels 3 RTCBufferType(3)

NOM

RTCBufferType - spécifie le format des données dans les tampons

SYNTAXE

#include <embree3/rtcore_ray.h>
enum RTCBufferType
{
  RTC_BUFFER_TYPE_INDEX            = 0,
  RTC_BUFFER_TYPE_VERTEX           = 1,
  RTC_BUFFER_TYPE_VERTEX_ATTRIBUTE = 2,
  RTC_BUFFER_TYPE_NORMAL           = 3,
  RTC_BUFFER_TYPE_TANGENT          = 4,
  RTC_BUFFER_TYPE_NORMAL_DERIVATIVE = 5,
  RTC_BUFFER_TYPE_GRID                 = 8,
  RTC_BUFFER_TYPE_FACE                 = 16,
  RTC_BUFFER_TYPE_LEVEL                = 17,
  RTC_BUFFER_TYPE_EDGE_CREASE_INDEX    = 18,
  RTC_BUFFER_TYPE_EDGE_CREASE_WEIGHT   = 19,
  RTC_BUFFER_TYPE_VERTEX_CREASE_INDEX  = 20,
  RTC_BUFFER_TYPE_VERTEX_CREASE_WEIGHT = 21,
  RTC_BUFFER_TYPE_HOLE                 = 22,
  RTC_BUFFER_TYPE_FLAGS = 32
};

DESCRIPTION

La structure RTBufferType définit des emplacements pour assigner des tampons de données en utilisant les appels d'API [rtcSetGeometryBuffer], [rtcSetSharedGeometryBuffer] et [rtcSetNewGeometryBuffer].

Pour la plupart des types de géométrie, l'emplacement RTC_BUFFER_TYPE_INDEX est utilisé pour assigner un tampon d'indices, tandis que RTC_BUFFER_TYPE_VERTEX est utilisé pour assigner le tampon de sommets correspondant.

L'emplacement RTC_BUFFER_TYPE_VERTEX_ATTRIBUTE peut être utilisé pour assigner des données de sommets supplémentaires arbitraires qui peuvent être interpolées à l'aide de l'appel d'API [rtcInterpolate].

Les RTC_BUFFER_TYPE_NORMAL, RTC_BUFFER_TYPE_TANGENT et RTC_BUFFER_TYPE_NORMAL_DERIVATIVE sont des tampons spéciaux requis pour assigner des normales, des tangentes et des dérivées de normales par sommet pour certains types de courbes.

Le tampon RTC_BUFFER_TYPE_GRID est utilisé pour assigner le tampon de primitives de grille pour les géométries de grille (voir [RTC_GEOMETRY_TYPE_GRID]).

Les RTC_BUFFER_TYPE_FACE, RTC_BUFFER_TYPE_LEVEL, RTC_BUFFER_TYPE_EDGE_CREASE_INDEX, RTC_BUFFER_TYPE_EDGE_CREASE_WEIGHT, RTC_BUFFER_TYPE_VERTEX_CREASE_INDEX, RTC_BUFFER_TYPE_VERTEX_CREASE_WEIGHT et RTC_BUFFER_TYPE_HOLE sont des tampons spéciaux requis pour créer des maillages de subdivision (voir [RTC_GEOMETRY_TYPE_SUBDIVISION]).

L'emplacement RTC_BUFFER_TYPE_FLAGS peut être utilisé pour ajouter des drapeaux supplémentaires par primitive d'une géométrie, et est actuellement utilisé uniquement pour les courbes linéaires.
