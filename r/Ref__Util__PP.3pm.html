NOM

Ref::Util::PP - version pure-Perl de Ref::Util

VERSION

version 0.204

SYNOPIS

use Ref::Util;

DESCRIPTION

Ce module fournit une implémentation pure-Perl des fonctions de Ref::Util.

Ref::Util::PP sera utilisé automatiquement si Ref::Util est installé sur un système sans compilateur C, mais vous pouvez forcer son utilisation en définissant soit $Ref::Util::IMPLEMENTATION soit la variable d'environnement "PERL_REF_UTIL_IMPLEMENTATION" à "PP".
