RTCRayN(3) Embree Ray Tracing Kernels 4 RTCRayN(3)

NOM

RTCRayN - paquet de rayons de taille dynamique

SYNTAXE

#include <embree4/rtcore_ray.h>
struct RTCRayN;
float& RTCRayN_org_x(RTCRayN* ray, unsigned int N, unsigned int i);
float& RTCRayN_org_y(RTCRayN* ray, unsigned int N, unsigned int i);
float& RTCRayN_org_z(RTCRayN* ray, unsigned int N, unsigned int i);
float& RTCRayN_tnear(RTCRayN* ray, unsigned int N, unsigned int i);
float& RTCRayN_dir_x(RTCRayN* ray, unsigned int N, unsigned int i);
float& RTCRayN_dir_y(RTCRayN* ray, unsigned int N, unsigned int i);
float& RTCRayN_dir_z(RTCRayN* ray, unsigned int N, unsigned int i);
float& RTCRayN_time (RTCRayN* ray, unsigned int N, unsigned int i);
float&        RTCRayN_tfar (RTCRayN* ray, unsigned int N, unsigned int i);
unsigned int& RTCRayN_mask (RTCRayN* ray, unsigned int N, unsigned int i);
unsigned int& RTCRayN_id   (RTCRayN* ray, unsigned int N, unsigned int i);
unsigned int& RTCRayN_flags(RTCRayN* ray, unsigned int N, unsigned int i);

DESCRIPTION

Lorsque la taille du paquet de rayons n'est pas connue à la compilation (par exemple, lorsque Embree retourne un paquet de rayons dans la fonction de rappel RTCFilterFuncN), Embree utilise le type RTCRayN pour les paquets de rayons. Ces paquets de rayons ne peuvent avoir que les tailles 1, 4, 8 ou 16. Aucune autre taille de paquet ne sera utilisée.

Vous pouvez soit implémenter des chemins de code différents pour chacune de ces tailles de paquet possibles et caster le rayon vers le type de paquet de rayon approprié, soit implémenter un chemin de code général qui utilise les fonctions d'aide RTCRayN_XXX pour accéder aux composants du paquet de rayons.

Ces fonctions d'aide reçoivent un pointeur vers le paquet de rayons (argument ray), la taille du paquet (argument N) et retournent une référence à un composant (par exemple, composant x de l'origine) du i-ème rayon du paquet (argument i).
