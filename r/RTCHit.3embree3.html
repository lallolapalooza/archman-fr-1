RTCHit(3) Embree Ray Tracing Kernels 3 RTCHit(3)

NOM

RTCHit - structure de succès unique

SYNTAXE

#include <embree3/rtcore.h>
struct RTCHit
{
  float Ng_x;                                        // coordonnée x de la normale géométrique
  float Ng_y;                                        // coordonnée y de la normale géométrique
  float Ng_z;                                        // coordonnée z de la normale géométrique
  float u;                                           // coordonnée barycentrique u du succès
  float v;                                           // coordonnée barycentrique v du succès
  unsigned int primID;                               // ID de géométrie
  unsigned int geomID;                               // ID de primitive
  unsigned int instID[RTC_MAX_INSTANCE_LEVEL_COUNT]; // ID d'instance
};

DESCRIPTION

Le type RTCHit définit le type de résultat d'intersection rayon/primitive. Le succès contient la normale géométrique non normalisée dans l'espace objet au point d'impact (membres Ng_x, Ng_y, Ng_z), les coordonnées barycentriques u/v du succès (membres u et v), ainsi que l'ID de primitive (membre primID), l'ID de géométrie (membre geomID) et la pile d'ID d'instance (membre instID) du succès. La distance d'intersection paramétrique n'est pas stockée dans le succès, mais est stockée dans le membre tfar du rayon.

L'en-tête embree3/rtcore_ray.h définit en outre la même structure de succès dans une disposition de structure de tableaux (SOA) pour les paquets de succès de taille 4 (type RTCHit4), de taille 8 (type RTCHit8) et de taille 16 (type RTCHit16). L'en-tête définit également un modèle RTCHitNt pour les paquets de succès d'une taille arbitraire compilée.
