NOM

Regexp::Common::profanity -- fournit des expressions régulières pour la grossièreté

SYNTAXE

use Regexp::Common qw /profanity/;
while (<>) {
    /$RE{profanity}/               and  print "Contient des grossièretés\n";
}

DESCRIPTION

Veuillez consulter le manuel de Regexp::Common pour une description générale du fonctionnement de cette interface.

N'utilisez pas ce module directement, mais chargez-le via Regexp::Common.

$RE{profanity}

Renvoie un modèle correspondant aux mots - tels que les « sept grands mots » de Carlin - qui sont les plus susceptibles de choquer. Notez que les termes anatomiques corrects ne sont délibérément pas inclus dans la liste.

Sous "-keep" (voir Regexp::Common) :

$1
capture le mot entier

"$RE{profanity}{contextual}"

Renvoie un modèle correspondant aux mots susceptibles de choquer lorsqu'ils sont utilisés dans des contextes spécifiques, mais qui ont également des significations non offensantes.

Sous "-keep" (voir Regexp::Common) :

$1
capture le mot entier
