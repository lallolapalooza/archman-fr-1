DESCRIPTION

L'énumération RTCFeatureFlags spécifie un masque de bits pour activer des fonctionnalités spécifiques de lancer de rayons pour les opérations de requêtes de rayons. Les indicateurs de fonctionnalités sont passés aux fonctions rtcIntersect1/4/8/16 et rtcOccluded1/4/8/16 via les structures RTCIntersectArguments et RTCOccludedArguments. Seule une fonctionnalité de lancer de rayons dont le bit est activé dans le masque de fonctionnalités peut être utilisée. Si un bit de fonctionnalité n'est pas défini, le comportement est indéfini, donc la fonctionnalité peut fonctionner ou non. Pour activer plusieurs fonctionnalités, les fonctionnalités respectives doivent être combinées à l'aide d'une opération OU bit à bit.

Le but des indicateurs de fonctionnalités est de réduire la taille du code sur le GPU en activant uniquement les fonctionnalités requises pour rendre la scène. Sur le CPU, il n'est pas nécessaire d'utiliser des indicateurs de fonctionnalités, et la valeur par défaut de toutes les fonctionnalités activées (RTC_FEATURE_FLAG_ALL) peut simplement être conservée.

Les fonctionnalités suivantes peuvent être activées à l'aide des indicateurs de fonctionnalités :

•
RTC_FEATURE_FLAG_MOTION_BLUR : Active le flou de mouvement pour tous les types de géométrie.
•
RTC_FEATURE_FLAG_TRIANGLE : Active les géométries de triangle (RTC_GEOMETRY_TYPE_TRIANGLE).
•
RTC_FEATURE_FLAG_QUAD : Active les géométries de quad (RTC_GEOMETRY_TYPE_QUAD).
•
RTC_FEATURE_FLAG_GRID : Active les géométries de grille (RTC_GEOMETRY_TYPE_GRID).
•
RTC_FEATURE_FLAG_SUBDIVISION : Active les géométries de subdivision (RTC_GEOMETRY_TYPE_SUBDIVISION).
•
RTC_FEATURE_FLAG_POINT : Active tous les types de géométrie de point (RTC_GEOMETRY_TYPE_XXX_POINT)
•
RTC_FEATURE_FLAG_CURVES : Active tous les types de géométrie de courbe (RTC_GEOMETRY_TYPE_XXX_YYY_CURVE)
•
RTC_FEATURE_FLAG_ROUND_CURVES : Active toutes les courbes rondes (RTC_GEOMETRY_TYPE_ROUND_XXX_CURVE).
•
RTC_FEATURE_FLAG_FLAT_CURVES : Active toutes les courbes plates (RTC_GEOMETRY_TYPE_FLAT_XXX_CURVE).
•
RTC_FEATURE_FLAG_NORMAL_ORIENTED_CURVES : Active toutes les courbes orientées normalement (RTC_GEOMETRY_TYPE_NORMAL_ORIENTED_XXX_CURVE).
•
RTC_FEATURE_FLAG_LINEAR_CURVES : Active toutes les courbes linéaires (RTC_GEOMETRY_TYPE_XXX_LINEAR_CURVE).
•
RTC_FEATURE_FLAG_BEZIER_CURVES : Active toutes les courbes de Bézier (RTC_GEOMETRY_TYPE_XXX_BEZIER_CURVE).
•
RTC_FEATURE_FLAG_BSPLINE_CURVES : Active toutes les courbes B-spline (RTC_GEOMETRY_TYPE_XXX_BSPLINE_CURVE).
•
RTC_FEATURE_FLAG_HERMITE_CURVES : Active toutes les courbes d'Hermite (RTC_GEOMETRY_TYPE_XXX_HERMITE_CURVE).
•
RTC_FEATURE_FLAG_CONE_LINEAR_CURVE : Active le type de géométrie de cône (RTC_GEOMETRY_TYPE_CONE_LINEAR_CURVE).
•
RTC_FEATURE_FLAG_ROUND_LINEAR_CURVE : Active les courbes linéaires rondes (RTC_GEOMETRY_TYPE_ROUND_LINEAR_CURVE).
•
RTC_FEATURE_FLAG_FLAT_LINEAR_CURVE : Active les courbes linéaires plates (RTC_GEOMETRY_TYPE_FLAT_LINEAR_CURVE).
•
RTC_FEATURE_FLAG_ROUND_BEZIER_CURVE : Active les courbes de Bézier rondes (RTC_GEOMETRY_TYPE_ROUND_BEZIER_CURVE).
•
RTC_FEATURE_FLAG_FLAT_BEZIER_CURVE : Active les courbes de Bézier plates (RTC_GEOMETRY_TYPE_FLAT_BEZIER_CURVE).
•
RTC_FEATURE_FLAG_NORMAL_ORIENTED_BEZIER_CURVE : Active les courbes de Bézier orientées normalement (RTC_GEOMETRY_TYPE_NORMAL_ORIENTED_BEZIER_CURVE).
•
RTC_FEATURE_FLAG_ROUND_BSPLINE_CURVE : Active les courbes B-spline rondes (RTC_GEOMETRY_TYPE_ROUND_BSPLINE_CURVE).
•
RTC_FEATURE_FLAG_FLAT_BSPLINE_CURVE : Active les courbes B-spline plates (RTC_GEOMETRY_TYPE_FLAT_BSPLINE_CURVE).
•
RTC_FEATURE_FLAG_NORMAL_ORIENTED_BSPLINE_CURVE : Active les courbes B-spline orientées normalement (RTC_GEOMETRY_TYPE_NORMAL_ORIENTED_BSPLINE_CURVE).
•
RTC_FEATURE_FLAG_ROUND_HERMITE_CURVE : Active les courbes d'Hermite rondes (RTC_GEOMETRY_TYPE_ROUND_HERMITE_CURVE).
•
RTC_FEATURE_FLAG_FLAT_HERMITE_CURVE : Active les courbes d'Hermite plates (RTC_GEOMETRY_TYPE_FLAT_HERMITE_CURVE).
•
RTC_FEATURE_FLAG_NORMAL_ORIENTED_HERMITE_CURVE : Active les courbes d'Hermite orientées normalement (RTC_GEOMETRY_TYPE_NORMAL_ORIENTED_HERMITE_CURVE).
•
RTC_FEATURE_FLAG_ROUND_CATMULL_ROM_CURVE : Active les courbes Catmull Rom rondes (RTC_GEOMETRY_TYPE_ROUND_CATMULL_ROM_CURVE).
•
RTC_FEATURE_FLAG_FLAT_CATMULL_ROM_CURVE : Active les courbes Catmull Rom plates (RTC_GEOMETRY_TYPE_FLAT_CATMULL_ROM_CURVE).
•
RTC_FEATURE_FLAG_NORMAL_ORIENTED_CATMULL_ROM_CURVE : Active les courbes Catmull Rom orientées normalement (RTC_GEOMETRY_TYPE_NORMAL_ORIENTED_CATMULL_ROM_CURVE).
•
RTC_FEATURE_FLAG_SPHERE_POINT : Active le type de géométrie de sphère (RTC_GEOMETRY_TYPE_SPHERE_POINT).
•
RTC_FEATURE_FLAG_DISC_POINT : Active le type de géométrie de disque (RTC_GEOMETRY_TYPE_DISC_POINT).
•
RTC_FEATURE_FLAG_ORIENTED_DISC_POINT : Active les types de géométrie de disque orienté (RTC_GEOMETRY_TYPE_ORIENTED_DISC_POINT).
•
RTC_FEATURE_FLAG_INSTANCE : Active les géométries d'instance (RTC_GEOMETRY_TYPE_INSTANCE).
•
RTC_FEATURE_FLAG_FILTER_FUNCTION_IN_ARGUMENTS : Active les fonctions de filtrage passées via les arguments d'intersection.
•
RTC_FEATURE_FLAG_FILTER_FUNCTION_IN_GEOMETRY : Active les fonctions de filtrage passées via la géométrie.
•
RTC_FEATURE_FLAG_FILTER_FUNCTION : Active les fonctions de filtrage (version par arguments et par géométrie).
•
RTC_FEATURE_FLAG_USER_GEOMETRY_CALLBACK_IN_ARGUMENTS : Active RTC_GEOMETRY_TYPE_USER avec un pointeur de fonction passé via les arguments d'intersection.
•
RTC_FEATURE_FLAG_USER_GEOMETRY_CALLBACK_IN_GEOMETRY : Active RTC_GEOMETRY_TYPE_USER avec un pointeur de fonction passé via l'objet géométrie.
•
RTC_FEATURE_FLAG_USER_GEOMETRY : Active les géométries RTC_GEOMETRY_TYPE_USER (versions par arguments et par rappel de géométrie).
•
RTC_FEATURE_FLAG_32_BIT_RAY_MASK : Active les masques de rayons complets de 32 bits. S'il n'est pas utilisé, seuls les 7 bits inférieurs du masque de rayon sont gérés correctement.
•
RTC_FEATURE_FLAG_ALL : Active toutes les fonctionnalités (par défaut).
