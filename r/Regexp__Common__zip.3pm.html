Regexp::Common::zip(3) Documentation Perl fournie par l'utilisateur Regexp::Common::zip(3)

NOM

Regexp::Common::zip -- fournit des expressions régulières pour les codes postaux.

SYNOPIS

use Regexp::Common qw /zip/;
while (<>) {
    /^$RE{zip}{Netherlands}$/   and  print "Code postal néerlandais\n";
}

DESCRIPTION

Veuillez consulter le manuel de Regexp::Common pour une description générale du fonctionnement de cette interface.

N'utilisez pas ce module directement, mais chargez-le via Regexp::Common.

Ce module propose des motifs pour les codes postaux de nombreux pays différents. Ils ont tous la forme "$RE{zip}{Pays}[{options}]".

Les options courantes suivantes sont utilisées :

"{-prefix=[oui|non|autorisé]}" et "{-country=PAT}".

Les codes postaux peuvent être précédés d'une abréviation de pays. C'est-à-dire qu'un code postal néerlandais de 1234 AB peut aussi s'écrire NL-1234 AB. Par défaut, tous les motifs autorisent les préfixes. Mais cela peut être modifié avec l'option "-prefix". Avec "-prefix=oui", l'expression régulière retournée exige un préfixe de pays, tandis que "-prefix=non" interdit un préfixe. Tout argument qui ne commence pas par un "o" ou un "n" autorise un préfixe de pays, mais ne l'exige pas.

Les préfixes utilisés ne sont malheureusement pas toujours les mêmes. Officiellement, les codes de pays ISO doivent être utilisés, mais l'usage des codes CEPT (les mêmes que ceux utilisés sur les voitures) est aussi courant. Par défaut, chaque code postal reconnaîtra un préfixe de pays qui est soit la norme ISO, soit le code CEPT. C'est-à-dire que les codes postaux allemands peuvent être précédés de "DE" ou de "D". Le préfixe reconnu peut être modifié avec l'option "-country", qui prend un (sous-)motif comme argument. Les arguments "iso" et "cept" sont spéciaux et indiquent que le préfixe de langue doit être le code pays ISO, ou le code CEPT.

Exemples :
/$RE{zip}{Netherlands}/;
# Correspond à '1234 AB' et 'NL-1234 AB'.
/$RE{zip}{Netherlands}{-prefix => 'non'}/;
# Correspond à '1234 AB' mais pas à 'NL-1234 AB'.
/$RE{zip}{Netherlands}{-prefix => 'oui'}/;
# Correspond à 'NL-1234 AB' mais pas à '1234 AB'.

/$RE{zip}{Germany}/;
          # Correspond à 'DE-12345' et 'D-12345'.
/$RE{zip}{Germany}{-country => 'iso'}/; 
          # Correspond à 'DE-12345' mais pas à 'D-12345'.
/$RE{zip}{Germany}{-country => 'cept'}/;
          # Correspond à 'D-12345' mais pas à 'DE-12345'.
/$RE{zip}{Germany}{-country => 'GER'}/;
          # Correspond à 'GER-12345'.

"{-sep=PAT}"

Certains pays ont des codes postaux composés de deux parties. Typiquement, il y a une manière officielle de séparer ces parties ; mais en pratique, les gens ont tendance à utiliser des séparateurs différents. Par exemple, si la manière officielle de séparer les parties est d'utiliser un espace, il arrive que l'espace soit omis. L'option "-sep" peut recevoir un motif comme argument qui indique ce qu'il faut utiliser comme séparateur entre les parties.

Exemples :
/$RE{zip}{Netherlands}/;
# Correspond à '1234 AB' mais pas à '1234AB'.
/$RE{zip}{Netherlands}{-sep => '\s*'}/;
# Correspond à '1234 AB' et '1234AB'.

"$RE{zip}{Australia}{-lax}"

Renvoie un motif qui reconnaît les codes postaux australiens. Les codes postaux australiens se composent de quatre chiffres ; les deux premiers chiffres, allant de '10' à '97', indiquent l'état, bien qu'il y ait des exceptions. Les territoires utilisent '02' ou '08' comme chiffres de départ. '0909' est le seul code postal commençant par '09' - c'est le code postal de la Northern Territory University). Les préfixes de pays (optionnels) sont AU (code pays ISO) et AUS (code CEPT).

Dans le passé, il a été affirmé que pour les codes postaux commençant par un 0, le 0 initial pouvait être omis, et jusqu'à la version 2016060201 (incluse), le 0 initial était optionnel. Mais il ne semble pas y avoir de preuve solide que le 0 initial soit optionnel. Nous exigeons donc maintenant qu'il y ait toujours quatre chiffres -- sauf si l'option "{-lax}" est donnée, auquel cas un 0 initial éventuel est optionnel.

Regexp::Common 2.107 et avant utilisaient "$RE{zip}{Australian}". Ceci est toujours supporté.

Si "{-keep}" est utilisé, les variables suivantes seront définies :

$1
Le code postal entier.
$2
Le préfixe du code pays.
$3
Le code postal sans le préfixe du code pays.

À partir de la version 2016060201, aucun $4 ou $5 ne sera défini.

"$RE {zip} {Austria}"

Renvoie un motif qui reconnaît les codes postaux autrichiens. Les codes postaux autrichiens comportent 4 chiffres, mais toutes les possibilités ne sont pas utilisées. Ce motif correspond aux codes postaux en usage. Les préfixes de pays (optionnels) sont AT (code pays ISO) et AUT (code CEPT).

Si "{-keep}" est utilisé, les variables suivantes seront définies :

$1
Le code postal entier.
$2
Le préfixe du code pays.
$3
Le code postal sans le préfixe du code pays.

"$RE{zip}{Belgium}"

Renvoie un motif qui reconnaît les codes postaux belges. Les codes postaux belges comportent 4 chiffres, dont le premier indique la province. Les préfixes de pays (optionnels) sont BE (code pays ISO) et B (code CEPT).

Si "{-keep}" est utilisé, les variables suivantes seront définies :

$1
Le code postal entier.
$2
Le préfixe du code pays.
$3
Le code postal sans le préfixe du code pays.

"$RE{zip}{Denmark}"

Renvoie un motif qui reconnaît les codes postaux danois. Les codes postaux danois se composent de quatre chiffres ; le premier chiffre indique la région de distribution, le second le district de distribution. Le préfixe de pays (optionnel) est DK, qui est à la fois le code pays ISO et le code CEPT.

Si "{-keep}" est utilisé, les variables suivantes seront définies :

$1
Le code postal entier.
$2
Le préfixe du code pays.
$3
Le code postal sans le préfixe du code pays.

Les codes postaux danois ne commenceront pas par 39. Les codes postaux de la forme 39XX sont réservés au Groenland ; le motif des codes postaux danois ne les reconnaîtra pas.

"$RE{zip}{France}"

Renvoie un motif qui reconnaît les codes postaux français. Les codes postaux français se composent de cinq chiffres ; les deux premiers chiffres, allant de '01' à '98', indiquent le département. Les préfixes de pays (optionnels) sont FR (code pays ISO) et F (code CEPT). Regexp::Common 2.107 et avant utilisaient "$RE{zip}{French}". Ceci est toujours supporté.

Monaco utilise des codes postaux qui font partie du système de numérotation utilisé par le système de codes postaux français ; leurs numéros commencent par 980. Ces numéros ne sont "pas" reconnus par ce motif.

Si "{-keep}" est utilisé, les variables suivantes seront définies :

$1
Le code postal entier.
$2
Le préfixe du code pays.
$3
Le code postal sans le préfixe du code pays.

"$RE{zip}{Allemagne}"

Retourne un modèle qui reconnaît les codes postaux allemands. Les codes postaux allemands consistent en cinq chiffres ; les deux premiers chiffres indiquant une zone postale plus large, les trois derniers chiffres un district postal. Les préfixes de pays (optionnels) sont DE (code pays ISO) et D (code CEPT). Regexp::Common 2.107 et les versions antérieures utilisaient "$RE{zip}{Allemand}". Ceci est toujours pris en charge.

Si "{-keep}" est utilisé, les variables suivantes seront définies :

$1
Le code postal complet.
$2
Le préfixe du code pays.
$3
Le code postal sans le préfixe du pays.

"$RE{zip}{Groenland}"

Retourne un modèle qui reconnaît les codes postaux du Groenland. Le Groenland utilise le système de codes postaux danois. Les codes postaux commençant par 39 sont réservés au Groenland, et tous les codes postaux groenlandais commencent par 39. À l'exception du code postal pour le Père Noël. Il utilise 2412.

Le préfixe de pays (optionnel) est GL, qui est utilisé à la fois comme code pays ISO et comme code CEPT. Les versions antérieures utilisaient DK comme préfixe.

Si "{-keep}" est utilisé, les variables suivantes seront définies :

$1
Le code postal complet.
$2
Le préfixe du code pays.
$3
Le code postal sans le préfixe du pays.

"$RE{zip}{Italie}"

Retourne un modèle reconnaissant les codes postaux italiens. Les codes postaux italiens sont composés de 5 chiffres. Le premier chiffre indique la région, le second la province. Le troisième chiffre est impair pour les capitales de province, et pair pour la province elle-même. Le quatrième chiffre indique la route, et le cinquième un lieu sur la route (0 pour les petits lieux, alphabétiquement pour le reste).

Les codes commençant par 4789 sont des codes postaux pour Saint-Marin ; ils ne sont pas reconnus par le modèle. Utilisez "$RE {zip} {'Saint-Marin'}" à la place.

Le préfixe de pays est soit IT (le code pays ISO), soit I (le code CEPT).

Si "{-keep}" est utilisé, les variables suivantes seront définies :

$1
Le code postal complet.
$2
Le préfixe du code pays.
$3
Le code postal sans le préfixe du pays.

"$RE {zip} {Liechtenstein}"

Retourne un modèle qui reconnaît les codes postaux utilisés au Liechtenstein. Le Liechtenstein utilise les codes postaux du système postal suisse. Ce système utilise quatre chiffres. Les codes postaux commençant par 94, et utilisant 8 ou 9 comme troisième chiffre sont des codes postaux pour le Liechtenstein.

Si "{-keep}" est utilisé, les variables suivantes seront définies :

$1
Le code postal complet.
$2
Le préfixe du code pays.
$3
Le code postal sans le préfixe du pays.

Le préfixe de pays ISO est LI, le préfixe de pays CEPT est LIE.

"$RE {zip {Monaco}"

Retourne un modèle pour les codes postaux utilisés à Monaco. Monaco utilise une plage du système utilisé en France. Ils comportent 5 chiffres, commençant par 980. Le numéro 98000 est utilisé pour les adresses physiques. Les numéros se terminant par 01 à 99 sont utilisés pour les livraisons spéciales.

Le code pays ISO est MC.

Si "{-keep}" est utilisé, les variables suivantes seront définies :

$1
Le code postal complet.
$2
Le préfixe du code pays.
$3
Le code postal sans le préfixe du pays.

"$RE{zip}{Pays-Bas}"

Retourne un modèle qui reconnaît les codes postaux néerlandais. Les codes postaux néerlandais consistent en 4 chiffres et 2 lettres, séparés par un espace. Le séparateur peut être modifié en utilisant l'option "{-sep}", comme discuté ci-dessus. Le préfixe de pays (optionnel) est NL, qui est à la fois le code pays ISO et le code CEPT. Regexp::Common 2.107 et les versions antérieures utilisaient "$RE{zip}{Néerlandais}". Ceci est toujours pris en charge.

Si "{-keep}" est utilisé, les variables suivantes seront définies :

$5

La partie lettres du code postal.

"$RE{zip}{Norvège}"

Le préfixe de pays est soit NO (le code pays ISO), soit N (le code CEPT).

"$RE{zip}{Espagne}"

Retourne un modèle qui reconnaît les codes postaux espagnols. Les codes postaux espagnols consistent en 5 chiffres. Les 2 premiers indiquent l'une des cinquante provinces d'Espagne (par ordre alphabétique), commençant par 00. Le troisième chiffre indique une ville principale ou les principales tournées de distribution. Les deux derniers chiffres sont la zone de distribution, la route de distribution secondaire ou un lien vers les zones rurales.

Le préfixe de pays est soit ES (le code pays ISO), soit E (le code CEPT).

$6

"$RE {zip} {Suisse}"

Retourne un modèle qui reconnaît les codes postaux suisses. Les codes postaux suisses consistent en 4 chiffres, mais toutes les combinaisons ne sont pas utilisées. Les codes postaux commençant par 948 et 949 sont pour des lieux au Liechtenstein, et ne seront pas reconnus par le modèle pour les codes postaux suisses. Utilisez "$RE {zip} {Liechtenstein}" pour ceux-là.

Si "{-keep}" est utilisé, les variables suivantes seront définies :

Le code postal complet.
$2
Le préfixe du code pays.
$3
Le code postal sans le préfixe du pays.

Le préfixe de pays est CH, pour les préfixes ISO et CEPT.

"$RE{zip}{US}{-extended => [oui|non|autoriser]}"

Retourne un modèle qui reconnaît les codes postaux américains (zip codes). Les codes postaux américains consistent en 5 chiffres, avec une extension optionnelle de 4 chiffres. Par défaut, les extensions sont autorisées, mais pas requises. Ceci peut être influencé par l'option "-extended". Si son argument commence par un "o" (pour "oui"), les extensions sont requises ; si l'argument commence par un "n" (pour "non"), les extensions ne seront pas reconnues. Si une extension est utilisée, un tiret est utilisé pour séparer la partie principale de l'extension, mais ceci peut être modifié avec l'option "-sep".

Le préfixe de pays est soit US (le code pays ISO), soit USA (le code CEPT).

NOM

Regexp::Common::zip

SYNTAXE

use Regexp::Common::zip;

DESCRIPTION

Regexp::Common::zip est un module Perl qui fournit des modèles d'expressions régulières pour l'analyse des codes postaux. Il est conçu pour gérer différents formats de codes postaux utilisés dans divers pays.

L'exemple suivant montre comment utiliser le module :


use Regexp::Common::zip;

my $pattern = Regexp::Common::zip->zip;

my $match = $pattern->match("12345");
if ($match) {
    print "Correspondance : $match\n";
}
