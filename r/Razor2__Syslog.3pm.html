NOM

Razor2::Syslog -- Support Syslog pour Razor2

SYNOPSIS

use Razor2::Syslog;
my $s=new Razor2::Syslog(Facility=>'local4',Priority=>'debug');
$s->send('voir ceci dans syslog',Priority=>'info');

DESCRIPTION

Ce module a été dérivé de Net::Syslog. Des optimisations ont été apportées à Net::Syslog, en particulier le support pour garder un socket ouvert. Ce qui suit est la documentation pour Net::Syslog, qui s'applique entièrement à ce module.

Net::Syslog implémente le protocole de transfert syslog intra-hôte. Il n'est pas destiné à remplacer les modules Sys::Syslog ou Unix::Syslog, mais plutôt à fournir une méthode d'utilisation de syslog lorsqu'un syslogd local n'est pas disponible ou lorsque vous ne souhaitez pas écrire de messages syslog dans le syslog local.

L'appel new configure des valeurs par défaut, dont chacune peut être remplacée dans l'appel send. Les clés (listées avec leurs valeurs par défaut) sont :

Name            <nom du script appelant>
Facility        local5
Priority        err
SyslogPort      514
SyslogHost      127.0.0.1

Les Facilities valides sont : kern, user, mail, daemon, auth, syslog, lpr, news, uucp, cron, authpriv, ftp, local0, local1, local2, local3, local4, local5, local6

Les Priorités valides sont : emerg, alert, crit, err, warning, notice, info, debug
