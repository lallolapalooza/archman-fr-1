Paquet: postgresql

ROLLBACK(7) Documentation PostgreSQL 18.1 ROLLBACK(7)

NOM

ROLLBACK - abandonner la transaction courante

SYNTAXE

ROLLBACK [ WORK | TRANSACTION ] [ AND [ NO ] CHAIN ]

DESCRIPTION

ROLLBACK annule la transaction courante et provoque l'annulation de toutes les modifications effectuées par cette transaction.

PARAMÈTRES

WORK
TRANSACTION

Mots-clés optionnels. Ils n'ont aucun effet.

AND CHAIN

Si AND CHAIN est spécifié, une nouvelle transaction (non annulée) est immédiatement démarrée avec les mêmes caractéristiques de transaction (voir SET TRANSACTION (SET_TRANSACTION(7))) que celle qui vient de se terminer. Sinon, aucune nouvelle transaction n'est démarrée.

NOTES

Utilisez COMMIT pour terminer une transaction avec succès.

L'émission de ROLLBACK en dehors d'un bloc de transaction émet un avertissement et n'a par ailleurs aucun effet. ROLLBACK AND CHAIN en dehors d'un bloc de transaction est une erreur.

EXEMPLES

Pour annuler toutes les modifications :

ROLLBACK;

COMPATIBILITÉ

La commande ROLLBACK est conforme à la norme SQL. La forme ROLLBACK TRANSACTION est une extension PostgreSQL.

VOIR AUSSI

BEGIN(7), COMMIT(7), ROLLBACK TO SAVEPOINT (ROLLBACK_TO_SAVEPOINT(7))
