NOM

RESET - restaurer la valeur d'un paramètre d'exécution à sa valeur par défaut

SYNTAXE

RESET paramètre_de_configuration
RESET ALL

DESCRIPTION

RESET restaure les paramètres d'exécution à leurs valeurs par défaut. RESET est une orthographe alternative pour

SET paramètre_de_configuration TO DEFAULT

Consultez SET(7) pour plus de détails.

La valeur par défaut est définie comme la valeur que le paramètre aurait eue, si aucun SET n'avait jamais été émis pour lui dans la session actuelle. La source réelle de cette valeur peut être une valeur par défaut compilée, le fichier de configuration, les options de la ligne de commande ou des paramètres par défaut par base de données ou par utilisateur. C'est subtilement différent de la définir comme « la valeur que le paramètre avait au début de la session », car si la valeur provenait du fichier de configuration, elle sera réinitialisée à ce qui est spécifié par le fichier de configuration maintenant. Voir le chapitre 19 pour les détails.

Le comportement transactionnel de RESET est le même que celui de SET : ses effets seront annulés par un rollback de transaction.

PARAMETRES

paramètre_de_configuration

Nom d'un paramètre d'exécution configurable. Les paramètres disponibles sont documentés au chapitre 19 et sur la page de référence de SET(7).

ALL

Réinitialise tous les paramètres d'exécution configurables à leurs valeurs par défaut.

EXEMPLES

Définir la variable de configuration timezone à sa valeur par défaut :

RESET timezone;

COMPATIBILITE

RESET est une extension PostgreSQL.

VOIR AUSSI

SET(7), SHOW(7)
