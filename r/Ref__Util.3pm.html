NOM

Ref::Util - Fonctions utilitaires pour vérifier les références

VERSION

version 0.204

SYNOPSIS

use Ref::Util qw( is_plain_arrayref is_plain_hashref );
if ( is_plain_arrayref( $something ) ) {
    print for @{ $something };
} elsif ( is_plain_hashref( $something ) ) {
    print for sort values %{ $something };
}

DESCRIPTION

Ref::Util introduit plusieurs fonctions pour aider à identifier les références de manière plus intelligente (et généralement plus rapide). En résumé :

# approche traditionnelle             # avec Ref::Util
ref( $foo ) eq 'ARRAY'              is_plain_arrayref( $foo )
use Scalar::Util qw( reftype );
reftype( $foo ) eq 'ARRAY'          is_arrayref( $foo )

La différence :

  • Évite la comparaison avec une constante chaîne

    • Lorsque "ref" est appelé, la référence est standardisée puis comparée à une constante chaîne (telle que "ARRAY" ou "HASH"). Non seulement cela est inadéquat, mais c'est aussi fragile car il peut y avoir des fautes de frappe dans la constante.

    Si "reftype" de Scalar::Util est utilisé, il est toujours comparé comme une chaîne :

    if ( reftype($foo) eq 'ARRAY' ) { ... }
  • Prend en charge les variables bénies

    • Note : Dans les futures versions, il est prévu que les fonctions par défaut utilisent la variation plain, ce qui signifie des références explicitement non bénies.

    Si vous voulez savoir explicitement si c'est une variable bénie, vous devriez utiliser des fonctions comme "is_blessed_*". Il y aura une variation "is_any_*" qui agira comme les fonctions principales - peu importe si elle est bénie ou non.

    Lorsque "ref" est appelé, vous obtenez le type de référence (SCALAR, ARRAY, HASH, etc.) ou le paquet auquel elle est bénie.

    Lorsque "is_arrayref" (et al.) est appelé, il vérifie les indicateurs de la variable, donc même si elle est bénie, vous savez à quel type de variable elle est bénie.

    my $foo = bless {}, 'PKG';
ref($foo) eq 'HASH'; # échoue
use Ref::Util 'is_hashref';
my $foo = bless {}, 'PKG';
is_hashref($foo); # fonctionne

    Dans d'autres cas, il peut être préférable d'exclure les références bénies. Le raisonnement derrière cela pourrait être que même si un objet est implémenté avec un hash, il n'est pas nécessairement correct de le traiter comme un hash. Pour ces cas, vous pouvez utiliser "is_plain_hashref" et ses semblables, qui ont les mêmes avantages de performance que "is_hashref".

    Il existe également un ensemble de fonctions nommées comme "is_blessed_hashref" ; celles-ci renvoient vrai pour les objets bénis qui sont implémentés avec le type pertinent.

  • Prend en charge les variables liées et la magie

    • Les variables liées (utilisées dans Readonly, par exemple) sont prises en charge.

    use Ref::Util qw<is_plain_hashref>;
use Readonly;
Readonly::Scalar my $rh2 => { a => { b => 2 } };
is_plain_hashref($rh2); # succès

    Ref::Util a ajouté la prise en charge de cela en 0.100. Avant cette version, le test échouait.

  • Ignore les surcharges

    • Ces fonctions ignorent les opérateurs surchargés et vérifient simplement le type de variable. La surcharge ne sera probablement jamais prise en charge, car je la considère problématique et confuse.

    La surcharge fait de vos variables des conteneurs opaques et cache quoi elles sont au lieu de vous faire comprendre comment les utiliser. Cela conduit à un code qui doit tester différentes capacités (dans "eval", donc il ne plante pas) et à des interfaces qui évitent ce qu'une personne pensait que vous feriez avec une variable. Ce serait correct, mais il n'y a pas de moyen clair d'introspection.

  • Ignore les types subtils :

    • Les types suivants, fournis par "reftype" de Scalar::Util, ne sont pas pris en charge :

  • "VSTRING"

    • Il s'agit d'un "PVMG" avec un indicateur pour les VSTRINGs. Comme ce n'est pas une référence, ce n'est pas pris en charge.

  • "LVALUE"

    • Une variable qui est déléguée à un autre scalaire. Comme ce n'est pas une référence, ce n'est pas pris en charge.

  • "INVLIST"

    • Je ne parviens pas à trouver de documentation pour ce type.

La prise en charge pourrait être ajoutée s'il y a une bonne raison.

•
Généralement rapide

Dans la mesure du possible, Ref::Util utilise Ref::Util::XS comme implémentation. (Si vous n'avez pas de compilateur C disponible, utilisez une alternative Perl pure qui a tous les avantages de Ref::Util, mais qui n'est pas aussi rapide.)

En fait, Ref::Util::XS possède deux implémentations alternatives en interne, en fonction des fonctionnalités prises en charge par la version de Perl que vous utilisez. Pour les Perl qui prennent en charge les OP personnalisés, nous ajoutons en fait un OP (plus rapide) ; pour les autres Perl, l'implémentation consiste simplement à appeler une fonction XS (plus rapide que l'équivalent Perl pur).

Voir les résultats de benchmark ci-dessous.

EXPORT

Aucune sous-routine n'est exportée par défaut. Vous pouvez demander des sous-routines spécifiques (description ci-dessous) ou demander toutes à la fois :

use Ref::Util qw<is_scalarref is_arrayref is_hashref ...>;
# ou
use Ref::Util ':all';

SOUTINES

is_ref($ref)

Vérifie s'il s'agit d'une référence à n'importe quel type de valeur.

is_ref([]);

is_scalarref($ref)

Vérifie s'il s'agit d'une référence à une valeur scalaire.

is_scalarref(\"hello");
is_scalarref(\30);
is_scalarref(\$value);

Note : Bien qu'une référence soit elle-même un type de valeur scalaire, une référence à une autre référence n'est pas traitée comme une référence à une valeur scalaire :

!is_scalarref(\\1);

La raison en est double. Premièrement, les appelants qui veulent décider comment gérer les entrées en fonction du type de référence le feront en différenciant une référence à une référence et une référence à une valeur scalaire. Deuxièmement, cela correspond mieux au comportement de la fonction "ref" et de "reftype" dans Scalar::Util, qui rapportent une référence à une référence comme "REF" au lieu de "SCALAR".

is_arrayref($ref)

Vérifie s'il s'agit d'une référence à un tableau.

is_arrayref([]);

is_hashref($ref)

Vérifie s'il s'agit d'une référence à un hash.

is_hashref({});

is_coderef($ref)

Vérifie s'il s'agit d'une référence à une fonction.

is_coderef( sub {} );

is_regexpref($ref)

Vérifie s'il s'agit d'une référence à une expression régulière (regex, regexp).

is_regexpref( qr// );

is_globref($ref)

Vérifie s'il s'agit d'une référence à un glob.

is_globref( \*STDIN );

is_formatref($ref)

Vérifie s'il s'agit d'une référence à un format.

# configurer un format sur STDOUT
format STDOUT =
.
# maintenant nous pouvons tester cela
is_formatref( *main::STDOUT{'FORMAT'} );

NAME

Ref::Util - Various subroutines for checking references.

VERSION

0.204

SYNOPSIS

    use Ref::Util qw(
        is_plain_arrayref
        is_plain_hashref
        is_plain_coderef
        is_plain_scalarref
        is_plain_globref
        is_plain_formatref
        is_plain_refref
        is_blessed_arrayref
        is_blessed_hashref
        is_blessed_coderef
        is_blessed_scalarref
        is_blessed_globref
        is_blessed_formatref
        is_blessed_refref
        is_ioref
        is_refref
    );

    # is_plain_arrayref
    is_plain_arrayref([]); # True
    is_plain_arrayref({}); # False
    is_plain_arrayref(\[]); # True
    is_plain_arrayref(\{}); # False
    is_plain_arrayref(bless []); # False

    # is_blessed_arrayref
    is_blessed_arrayref([]); # False
    is_blessed_arrayref(\[]); # False
    is_blessed_arrayref(bless []); # True
    is_blessed_arrayref(bless {}, 'MyClass'); # False

DESCRIPTION

This module provides a suite of subroutines for checking the type of a Perl reference.

The subroutines fall into two categories:

  • Those checking for "plain" references (unblessed).
  • Those checking for blessed references.

Additionally, there are a couple of general reference checking subroutines.

EXPORT

All subroutines are exported by default.

is_croak($ref)

Check for an IO reference.

is_ioref( *STDOUT{IO} );

is_ioref($ref)

Check for an IO reference.

is_ioref( *STDOUT{IO} );

is_refref($ref)

Check for a reference to a reference.

is_refref( \[] ); # reference to array reference

is_plain_scalarref($ref)

Check for an unblessed scalar reference.

is_plain_scalarref(\"hello\");
is_plain_scalarref(\30);
is_plain_scalarref(\$value);

is_plain_ref($ref)

Check for an unblessed reference to anything.

is_plain_ref([]);

is_plain_arrayref($ref)

Check for an unblessed array reference.

is_plain_arrayref([]);

is_plain_hashref($ref)

Check for an unblessed hash reference.

is_plain_hashref({});

is_plain_coderef($ref)

Check for an unblessed code reference.

is_plain_coderef( sub {} );

is_plain_globref($ref)

Check for an unblessed glob reference.

is_plain_globref( \*STDIN );

is_plain_formatref($ref)

Check for an unblessed format reference.

# set up format in STDOUT
format STDOUT =
.
# now we can test it
is_plain_formatref(bless *main::STDOUT{'FORMAT'} );

is_plain_refref($ref)

Check for an unblessed reference to a reference.

is_plain_refref( \[] ); # reference to array reference

is_blessed_scalarref($ref)

Check for a blessed scalar reference.

is_blessed_scalarref(bless \$value);

is_blessed_ref($ref)

Check for a blessed reference to anything.

is_blessed_ref(bless [], $class);

is_blessed_arrayref($ref)

Check for a blessed array reference.

is_blessed_arrayref(bless [], $class);

is_blessed_hashref($ref)

Check for a blessed hash reference.

is_blessed_hashref(bless {}, $class);

is_blessed_coderef($ref)

Check for a blessed code reference.

is_blessed_coderef( bless sub {}, $class );

is_blessed_globref($ref)

Check for a blessed glob reference.

is_blessed_globref( bless \*STDIN, $class );

is_blessed_formatref($ref)

Check for a blessed format reference.

# set up format for FH
format FH =
.
# now we can test it
is_blessed_formatref(bless *FH{'FORMAT'}, $class );

is_blessed_refref($ref)

Check for a blessed reference to a reference.

is_blessed_refref( bless \[], $class ); # reference to array reference

BENCHMARKS

Here is a benchmark comparing similar checks.

my $bench = Dumbbench->new(
    target_rel_precision => 0.005,
    initial_runs         => 20,
);
my $amount = 1e7;
my $ref    = [];
$bench->add_instances(
    Dumbbench::Instance::PerlSub->new(
        name => 'Ref::Util::is_plain_arrayref (CustomOP)',
        code => sub {
            Ref::Util::is_plain_arrayref($ref) for ( 1 .. $amount )
        },
    ),
    Dumbbench::Instance::PerlSub->new(
        name => 'ref(), reftype(), !blessed()',
        code => sub {
            ref $ref
                && Scalar::Util::reftype($ref) eq 'ARRAY'
                && !Scalar::Util::blessed($ref)
                for ( 1 .. $amount );
        },
    ),
    Dumbbench::Instance::PerlSub->new(
        name => 'ref()',
        code => sub { ref($ref) eq 'ARRAY' for ( 1 .. $amount ) },
    ),
    Dumbbench::Instance::PerlSub->new(
        name => 'Data::Util::is_array_ref',
        code => sub { is_array_ref($ref) for ( 1 .. $amount ) },
    ),
);

The results:

ref():                                   5.335e+00 +/- 1.8e-02 (0.3%)
ref(), reftype(), !blessed():            1.5545e+01 +/- 3.1e-02 (0.2%)
Ref::Util::is_plain_arrayref (CustomOP): 2.7951e+00 +/- 6.2e-03 (0.2%)
Data::Util::is_array_ref:                5.9074e+00 +/- 7.5e-03 (0.1%)

(Rounded run time per iteration)

A benchmark against Data::Util:

Ref::Util::is_plain_arrayref: 3.47157e-01 +/- 6.8e-05 (0.0%)
Data::Util::is_array_ref:     6.7562e-01 +/- 7.5e-04 (0.1%)
