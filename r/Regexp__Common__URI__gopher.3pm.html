NOM

Regexp::Common::URI::gopher -- Retourne un motif pour les URI gopher.

SYNTAXE

use Regexp::Common qw /URI/;
while (<>) {
    /$RE{URI}{gopher}/       and  print "Contient un URI gopher.\n";
}

DESCRIPTION

$RE{URI}{gopher}{-notab}

Les URI Gopher sont mal définis. Initialement, la RFC 1738 définissait les URI gopher, mais ils ont été redéfinis ultérieurement dans une ébauche Internet. L'une d'elles a expiré en juin 1997.

L'ébauche Internet pour les URI gopher les définit comme suit :

"gopher:" "//" host [ ":" port ] "/" gopher-type selector
                    [ "%09" search [ "%09" gopherplus_string ]]

Malheureusement, un selector est défini de telle manière que les caractères peuvent être échappés en utilisant le mécanisme d'échappement d'URI. Cela inclut les tabulations, qui échappées sont %09. Par conséquent, la syntaxe ne peut pas distinguer entre un URI qui a à la fois une partie selector et une partie search, et un URI où le selector inclut une tabulation échappée. (Le texte de l'ébauche interdit cependant les tabulations dans le selector).

"$RE{URI}{gopher}" suit la syntaxe définie. Pour interdire les tabulations échappées dans les parties selector et search, utilisez "$RE{URI}{gopher}{-notab}".

Il y a d'autres différences entre le texte et la syntaxe donnée. Selon le texte, les chaînes de sélecteurs ne peuvent pas contenir de tabulations, de sauts de ligne ou de retours chariot. Le texte permet également que le gopher-path entier, (la partie après le slash suivant l'hôte et le port) soit vide ; si celui-ci est vide, le slash peut également être omis. Cependant, cela n'est pas reflété dans la syntaxe.

Sous "{-keep}", les éléments suivants sont retournés :

$1
L'URI entier.
$2
Le schéma.
$3
L'hôte (nom ou adresse).
$4
Le port (s'il y en a un).
$5
Le "gopher-path", la partie après le / suivant l'hôte et le port.
$6
Le type gopher.
$7
Le sélecteur. (Lorsque aucun "{-notab}" n'est utilisé, cela inclut la recherche et la chaîne gopherplus, y compris les tabulations échappées séparatrices).
$8
La recherche, si fournie. (Uniquement lorsque "{-notab}" est fourni).
$9
La chaîne gopherplus, si fournie. (Uniquement lorsque "{-notab}" est fourni).
