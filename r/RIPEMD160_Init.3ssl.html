RIPEMD160_INIT(3ssl) OpenSSL RIPEMD160_INIT(3ssl)

NOM

RIPEMD160, RIPEMD160_Init, RIPEMD160_Update, RIPEMD160_Final - fonction de hachage RIPEMD-160

SYNOPIS

#include <openssl/ripemd.h>

Les fonctions suivantes sont obsolètes depuis OpenSSL 3.0 et peuvent être entièrement masquées en définissant OPENSSL_API_COMPAT avec une valeur de version appropriée, voir openssl_user_macros(7) :

unsigned char *RIPEMD160(const unsigned char *d, unsigned long n,
                         unsigned char *md);
int RIPEMD160_Init(RIPEMD160_CTX *c);
int RIPEMD160_Update(RIPEMD160_CTX *c, const void *data, unsigned long len);
int RIPEMD160_Final(unsigned char *md, RIPEMD160_CTX *c);

DESCRIPTION

Toutes les fonctions décrites dans cette page sont obsolètes. Les applications devraient plutôt utiliser EVP_DigestInit_ex(3), EVP_DigestUpdate(3) et EVP_DigestFinal_ex(3).

RIPEMD-160 est une fonction de hachage cryptographique avec une sortie de 160 bits.

RIPEMD160() calcule le résumé de message RIPEMD-160 des n octets à d et le place dans md (qui doit avoir de la place pour RIPEMD160_DIGEST_LENGTH == 20 octets de sortie). Si md est NULL, le résumé est placé dans un tableau statique.

Les fonctions suivantes peuvent être utilisées si le message n'est pas entièrement stocké en mémoire :

RIPEMD160_Init() initialise une structure RIPEMD160_CTX.

RIPEMD160_Update() peut être appelée de manière répétée avec des fragments du message à hacher (len octets à data).

RIPEMD160_Final() place le résumé du message dans md, qui doit avoir de la place pour RIPEMD160_DIGEST_LENGTH == 20 octets de sortie, et efface le RIPEMD160_CTX.

VALEURS DE RETOUR

RIPEMD160() renvoie un pointeur vers la valeur de hachage.

RIPEMD160_Init(), RIPEMD160_Update() et RIPEMD160_Final() renvoient 1 en cas de succès, 0 sinon.

NOTE

Les applications devraient utiliser les fonctions de plus haut niveau EVP_DigestInit(3) etc. au lieu d'appeler ces fonctions directement.

CONFORME À

ISO/IEC 10118-3:2016 Dedicated Hash-Function 1 (RIPEMD-160).

VOIR AUSSI

EVP_DigestInit(3)

HISTORIQUE

Toutes ces fonctions ont été rendues obsolètes dans OpenSSL 3.0.
