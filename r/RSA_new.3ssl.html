RSA_new(3ssl)

Paquet: openssl

Licences: Apache-2.0

RSA_NEW(3ssl) OpenSSL RSA_NEW(3ssl)

NOM

RSA_new, RSA_free - allouer et libérer des objets RSA

SYNTAXE

#include <openssl/rsa.h>

Les fonctions suivantes ont été dépréciées depuis OpenSSL 3.0 et peuvent être entièrement masquées en définissant OPENSSL_API_COMPAT avec une valeur de version appropriée, voir openssl_user_macros(7).

RSA *RSA_new(void);
void RSA_free(RSA *rsa);

DESCRIPTION

RSA_new() alloue et initialise une structure RSA. Elle est équivalente à l'appel de RSA_new_method(NULL).

RSA_free() libère la structure RSA et ses composants. La clé est effacée avant que la mémoire ne soit retournée au système. Si rsa est NULL, rien n'est fait.

VALEURS DE RETOUR

Si l'allocation échoue, RSA_new() retourne NULL et définit un code d'erreur qui peut être obtenu par ERR_get_error(3). Sinon, elle retourne un pointeur vers la structure nouvellement allouée.

RSA_free() ne retourne aucune valeur.

VOIR AUSSI

ERR_get_error(3), RSA_generate_key(3), RSA_new_method(3)

HISTORIQUE

Toutes les fonctions décrites ici ont été dépréciées dans OpenSSL 3.0. Pour un remplacement, voir EVP_PKEY-RSA(7).
