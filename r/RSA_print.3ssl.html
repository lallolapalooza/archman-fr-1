RSA_print(3ssl)

Paquet: openssl

Licences: Apache-2.0

RSA_PRINT(3ssl) OpenSSL RSA_PRINT(3ssl)

NOM

RSA_print, RSA_print_fp, DSAparams_print, DSAparams_print_fp, DSA_print, DSA_print_fp, DHparams_print, DHparams_print_fp - imprimer les paramètres cryptographiques

SYNOPSIS

#include <openssl/rsa.h>

Les fonctions suivantes ont été dépréciées depuis OpenSSL 3.0 et peuvent être entièrement masquées en définissant OPENSSL_API_COMPAT avec une valeur de version appropriée, voir openssl_user_macros(7) :

int RSA_print(BIO *bp, const RSA *x, int offset);
int RSA_print_fp(FILE *fp, const RSA *x, int offset);
#include <openssl/dsa.h>

Les fonctions suivantes ont été dépréciées depuis OpenSSL 3.0 et peuvent être entièrement masquées en définissant OPENSSL_API_COMPAT avec une valeur de version appropriée, voir openssl_user_macros(7) :

int DSAparams_print(BIO *bp, const DSA *x);
int DSAparams_print_fp(FILE *fp, const DSA *x);
int DSA_print(BIO *bp, const DSA *x, int offset);
int DSA_print_fp(FILE *fp, const DSA *x, int offset);
#include <openssl/dh.h>

Les fonctions suivantes ont été dépréciées depuis OpenSSL 3.0 et peuvent être entièrement masquées en définissant OPENSSL_API_COMPAT avec une valeur de version appropriée, voir openssl_user_macros(7) :

int DHparams_print(BIO *bp, DH *x);
int DHparams_print_fp(FILE *fp, const DH *x);

DESCRIPTION

Toutes les fonctions décrites sur cette page sont dépréciées. Les applications devraient plutôt utiliser EVP_PKEY_print_params(3) et EVP_PKEY_print_private(3).

Une sortie hexadécimale lisible par l'homme des composants de la clé RSA, des paramètres ou de la clé DSA ou des paramètres DH est imprimée sur bp ou fp.

Les lignes de sortie sont indentées par offset espaces.

VALEURS DE RETOUR

DSAparams_print(), DSAparams_print_fp(), DSA_print() et DSA_print_fp() retournent 1 en cas de succès et 0 ou une valeur négative en cas d'échec.

DHparams_print() et DHparams_print_fp() retournent 1 en cas de succès, 0 en cas d'erreur.
