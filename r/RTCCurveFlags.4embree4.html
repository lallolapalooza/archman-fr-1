RTCCurveFlags(3) Embree Ray Tracing Kernels 4 RTCCurveFlags(3)

NOM

RTCCurveFlags - indicateurs par segment pour la géométrie des courbes

SYNOPIS

#include <embree4/rtcore.h>
enum RTCCurveFlags
{
  RTC_CURVE_FLAG_NEIGHBOR_LEFT  = (1 << 0), 
  RTC_CURVE_FLAG_NEIGHBOR_RIGHT = (1 << 1) 
};

DESCRIPTION

Le type RTCCurveFlags est utilisé pour les courbes linéaires afin de déterminer si le segment voisin gauche et/ou droit existe. Par conséquent, on attache un tampon de type RTC_BUFFER_TYPE_FLAGS à la géométrie de la courbe, qui stocke un octet individuel par segment de courbe.

Si l'indicateur RTC_CURVE_FLAG_NEIGHBOR_LEFT dans cet octet est activé pour un segment de courbe, alors le segment de gauche existe (qui commence un sommet avant le sommet de départ de la courbe actuelle) et le segment actuel est rendu pour s'attacher correctement à ce segment.

Si l'indicateur RTC_CURVE_FLAG_NEIGHBOR_RIGHT dans cet octet est activé pour un segment de courbe, alors le segment de droite existe (qui se termine un sommet après le sommet de fin de la courbe actuelle) et le segment actuel est rendu pour s'attacher correctement à ce segment.

Lorsqu'on ne spécifie pas correctement les indicateurs gauche et droit pour les courbes linéaires, le rendu aux extrémités de ces courbes peut ne pas paraître correct, en particulier lorsque des courbes linéaires arrondies sont vues de l'intérieur.
