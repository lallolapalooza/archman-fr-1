ROLLBACK PREPARED(7) Documentation PostgreSQL 18.1 ROLLBACK PREPARED(7)

NOM

ROLLBACK PREPARED - annuler une transaction précédemment préparée pour un commit en deux phases

SYNTAXE

ROLLBACK PREPARED identifiant_transaction

DESCRIPTION

ROLLBACK PREPARED annule une transaction qui est dans l'état préparé.

PARAMÈTRES

identifiant_transaction

L'identifiant de la transaction à annuler.

NOTES

Pour annuler une transaction préparée, vous devez être soit le même utilisateur qui a exécuté la transaction à l'origine, soit un superutilisateur. Mais vous n'avez pas besoin d'être dans la même session qui a exécuté la transaction.

Cette commande ne peut pas être exécutée à l'intérieur d'un bloc de transaction. La transaction préparée est annulée immédiatement.

Toutes les transactions préparées actuellement disponibles sont listées dans la vue système pg_prepared_xacts.

EXEMPLES

Annuler la transaction identifiée par l'identifiant de transaction foobar :

ROLLBACK PREPARED 'foobar';

COMPATIBILITÉ

ROLLBACK PREPARED est une extension PostgreSQL. Elle est destinée à être utilisée par des systèmes externes de gestion de transactions, dont certains sont couverts par des normes (telles que X/Open XA), mais le côté SQL de ces systèmes n'est pas standardisé.

VOIR AUSSI

PREPARE TRANSACTION (PREPARE_TRANSACTION(7)), COMMIT PREPARED (COMMIT_PREPARED(7))
