RSA_generate_key(3ssl)

Paquet: openssl

Licences: Apache-2.0

RSA_GENERATE_KEY(3ssl) OpenSSL RSA_GENERATE_KEY(3ssl)

NOM

EVP_RSA_gen, RSA_generate_key_ex, RSA_generate_key, RSA_generate_multi_prime_key - générer une paire de clés RSA

SYNTAXE

#include <openssl/rsa.h>
EVP_PKEY *EVP_RSA_gen(unsigned int bits);

Les fonctions suivantes ont été dépréciées à partir d'OpenSSL 3.0 et peuvent être complètement masquées en définissant OPENSSL_API_COMPAT avec une valeur de version appropriée, voir openssl_user_macros(7):

int RSA_generate_key_ex(RSA *rsa, int bits, BIGNUM *e, BN_GENCB *cb);
int RSA_generate_multi_prime_key(RSA *rsa, int bits, int primes, BIGNUM *e, BN_GENCB *cb);

La fonction suivante a été dépréciée à partir d'OpenSSL 0.9.8 et peut être complètement masquée en définissant OPENSSL_API_COMPAT avec une valeur de version appropriée, voir openssl_user_macros(7):

RSA *RSA_generate_key(int bits, unsigned long e,
                      void (*callback)(int, int, void *), void *cb_arg);

DESCRIPTION

EVP_RSA_gen() génère une nouvelle paire de clés RSA avec une taille de module de bits.

Toutes les fonctions décrites ci-dessous sont dépréciées. Les applications devraient plutôt utiliser EVP_RSA_gen(), EVP_PKEY_Q_keygen(3), ou EVP_PKEY_keygen_init(3) et EVP_PKEY_keygen(3).

RSA_generate_key_ex() génère une paire de clés RSA à 2 premiers et la stocke dans la structure RSA fournie dans rsa.

RSA_generate_multi_prime_key() génère une paire de clés RSA multi-premiers et la stocke dans la structure RSA fournie dans rsa. Le nombre de premiers est donné par le paramètre primes. Si l'amorçage ou le réamorçage automatique du générateur de nombres pseudo-aléatoires cryptographiques (CSPRNG) d'OpenSSL échoue en raison de circonstances externes (voir RAND(7)), l'opération échouera.

La taille du module sera de longueur bits, le nombre de premiers formant le module sera primes, et l'exposant public sera e. Les tailles de clé avec num < 1024 devraient être considérées comme non sécurisées. L'exposant est un nombre impair, typiquement 3, 17 ou 65537.

Afin de maintenir un niveau de sécurité adéquat, le nombre maximum de primes autorisés dépend de la longueur du module en bits:

<1024 | >=1024 | >=4096 | >=8192
------+--------+--------+-------
  2   |   3    |   4    |   5

Une fonction de rappel peut être utilisée pour fournir des informations sur la progression de la génération de la clé. Si cb n'est pas NULL, elle sera appelée en utilisant la fonction BN_GENCB_call() décrite dans la page BN_generate_prime(3).

RSA_generate_key() est similaire à RSA_generate_key_ex() mais attend une fonction de rappel de l'ancien style ; voir BN_generate_prime(3) pour des informations sur la fonction de rappel de l'ancien style.

  • Lorsqu'un nombre premier aléatoire est généré, il est appelé comme décrit dans BN_generate_prime(3).
  • Lorsque le n-ième nombre premier généré aléatoirement est rejeté comme inapproprié pour la clé, BN_GENCB_call(cb, 2, n) est appelé.
  • Lorsqu'un premier aléatoire p est trouvé tel que p-1 est relativement premier à e, il est appelé comme BN_GENCB_call(cb, 3, 0).

Le processus est ensuite répété pour le premier q et les autres premiers (le cas échéant) avec BN_GENCB_call(cb, 3, i) où i indique le i-ème premier.

VALEURS DE RETOUR

EVP_RSA_gen() renvoie un EVP_PKEY ou NULL en cas d'échec.

RSA_generate_multi_prime_key() renvoie 1 en cas de succès ou 0 en cas d'erreur. RSA_generate_key_ex() renvoie 1 en cas de succès ou 0 en cas d'erreur. Les codes d'erreur peuvent être obtenus par ERR_get_error(3).

RSA_generate_key() renvoie un pointeur vers la structure RSA ou NULL si la génération de la clé échoue.

BOGUES

BN_GENCB_call(cb, 2, x) est utilisé avec deux significations différentes.

VOIR AUSSI

EVP_PKEY_Q_keygen(3) BN_generate_prime(3), ERR_get_error(3), RAND_bytes(3), RAND(7)

HISTORIQUE

EVP_RSA_gen() a été ajoutée dans OpenSSL 3.0. Toutes les autres fonctions décrites ici ont été dépréciées dans OpenSSL 3.0. Pour le remplacement, voir EVP_PKEY-RSA(7).
