NOM

RTCRayHit - structure combinée rayon/impact simple

SYNTAXE

#include <embree4/rtcore_ray.h>
struct RTCORE_ALIGN(16) RTCRayHit
{
  struct RTCRay ray;
  struct RTCHit hit;
};

DESCRIPTION

La structure RTCRayHit est utilisée comme entrée pour les fonctions de type rtcIntersect et stocke le rayon à intersecter ainsi que certains champs d'impact qui contiendront ensuite le résultat de l'intersection.

L'en-tête embree4/rtcore_ray.h définit également la même structure de rayon/impact dans une disposition structure de tableaux (SOA) pour les fonctions d'API acceptant des paquets de rayons de taille 4 (type RTCRayHit4), taille 8 (type RTCRayHit8) et taille 16 (type RTCRayHit16). L'en-tête définit également un modèle RTCRayHitNt pour générer des paquets de rayons/impacts de taille arbitraire à la compilation.
