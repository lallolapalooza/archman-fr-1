NOM

RTCFormat - spécifie le format des données dans les tampons

SYNTAXE

#include <embree3/rtcore_ray.h>
enum RTCFormat
{
  RTC_FORMAT_UINT,
  RTC_FORMAT_UINT2,
  RTC_FORMAT_UINT3,
  RTC_FORMAT_UINT4,
  RTC_FORMAT_FLOAT,
  RTC_FORMAT_FLOAT2,
  RTC_FORMAT_FLOAT3,
  RTC_FORMAT_FLOAT4,
  RTC_FORMAT_FLOAT5,
  RTC_FORMAT_FLOAT6,
  RTC_FORMAT_FLOAT7,
  RTC_FORMAT_FLOAT8,
  RTC_FORMAT_FLOAT9,
  RTC_FORMAT_FLOAT10,
  RTC_FORMAT_FLOAT11,
  RTC_FORMAT_FLOAT12,
  RTC_FORMAT_FLOAT13,
  RTC_FORMAT_FLOAT14,
  RTC_FORMAT_FLOAT15,
  RTC_FORMAT_FLOAT16,
  RTC_FORMAT_FLOAT3X4_ROW_MAJOR,
  RTC_FORMAT_FLOAT4X4_ROW_MAJOR,
  RTC_FORMAT_FLOAT3X4_COLUMN_MAJOR,
  RTC_FORMAT_FLOAT4X4_COLUMN_MAJOR,
  RTC_FORMAT_GRID,

};

DESCRIPTION

La structure RTFormat définit le format des données stockées dans les tampons de données fournis à Embree via les appels API [rtcSetGeometryBuffer], [rtcSetSharedGeometryBuffer] et [rtcSetNewGeometryBuffer].

Les formats RTC_FORMAT_UINT/2/3/4 sont utilisés pour spécifier que les tampons de données stockent des entiers non signés, ou des vecteurs d'entiers non signés de taille 2, 3 ou 4. Ce format doit généralement être utilisé lors de la spécification des tampons d'index, par exemple, RTC_FORMAT_UINT3 pour les maillages triangulaires.

Les formats RTC_FORMAT_FLOAT/2/3/4... sont utilisés pour spécifier que les tampons de données stockent des valeurs à virgule flottante de précision simple, ou des vecteurs de ceux-ci (taille 2, 3, 4, etc.). Ce format est typiquement utilisé pour spécifier le format des tampons de sommets, par exemple, le type RTC_FORMAT_FLOAT3 pour les tampons de sommets de maillages triangulaires.

Les formats RTC_FORMAT_FLOAT3X4_ROW_MAJOR et RTC_FORMAT_FLOAT3X4_COLUMN_MAJOR spécifient une matrice 3x4 en virgule flottante disposée soit en ordre ligne majeure, soit en ordre colonne majeure. Les formats RTC_FORMAT_FLOAT4X4_ROW_MAJOR et RTC_FORMAT_FLOAT4X4_COLUMN_MAJOR spécifient une matrice 4x4 en virgule flottante disposée soit en ordre ligne majeure, soit en ordre colonne majeure. Ces formats de matrice sont utilisés dans la fonction [rtcSetGeometryTransform] afin de définir une matrice de transformation pour les géométries.

RTC_FORMAT_GRID est un format de données spécial utilisé pour spécifier des primitives de grille de disposition RTCGrid lors de la création de géométries de grille (voir [RTC_GEOMETRY_TYPE_GRID]).
