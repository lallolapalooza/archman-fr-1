RSA_sign_ASN1_OCTET_STRING(3ssl)

Paquet: openssl

Licences: Apache-2.0

RSA_SIGN_ASN1_OCTET_STRING(3ssl) OpenSSL RSA_SIGN_ASN1_OCTET_STRING(3ssl)

NOM

RSA_sign_ASN1_OCTET_STRING, RSA_verify_ASN1_OCTET_STRING - Signatures RSA

SYNTAXE

#include <openssl/rsa.h>

Les fonctions suivantes sont dépréciées depuis OpenSSL 3.0 et peuvent être entièrement masquées en définissant OPENSSL_API_COMPAT avec une valeur de version appropriée, voir openssl_user_macros(7):

int RSA_sign_ASN1_OCTET_STRING(int dummy, unsigned char *m,
                               unsigned int m_len, unsigned char *sigret,
                               unsigned int *siglen, RSA *rsa);
int RSA_verify_ASN1_OCTET_STRING(int dummy, unsigned char *m,
                                 unsigned int m_len, unsigned char *sigbuf,
                                 unsigned int siglen, RSA *rsa);

DESCRIPTION

Toutes les fonctions décrites sur cette page sont dépréciées. Les applications devraient utiliser les API EVP PKEY à la place.

RSA_sign_ASN1_OCTET_STRING() signe la chaîne d'octets m de taille m_len en utilisant la clé privée rsa représentée en DER avec un remplissage PKCS #1. Elle stocke la signature dans sigret et la taille de la signature dans siglen. sigret doit pointer vers RSA_size(rsa) octets de mémoire.

dummy est ignoré.

Le générateur de nombres aléatoires doit être amorcé lors de l'appel à RSA_sign_ASN1_OCTET_STRING(). Si l'amorçage automatique ou le réamorçage du CSPRNG OpenSSL échoue en raison de circonstances externes (voir RAND(7)), l'opération échouera.

RSA_verify_ASN1_OCTET_STRING() vérifie que la signature sigbuf de taille siglen est la représentation DER d'une chaîne d'octets donnée m de taille m_len. dummy est ignoré. rsa est la clé publique du signataire.

VALEURS DE RETOUR

RSA_sign_ASN1_OCTET_STRING() retourne 1 en cas de succès, 0 sinon. RSA_verify_ASN1_OCTET_STRING() retourne 1 en cas de vérification réussie, 0 sinon.

Les codes d'erreur peuvent être obtenus par ERR_get_error(3).

BOGUES

Ces fonctions n'ont aucun but reconnaissable.

VOIR AUSSI

ERR_get_error(3), RAND_bytes(3), RSA_sign(3), RSA_verify(3), RAND(7)

HISTORIQUE

Toutes ces fonctions ont été dépréciées dans OpenSSL 3.0.
