NOM

Regexp::Common::URI::tel -- Renvoie un modèle pour les URI de téléphone.

SYNTAXE

use Regexp::Common qw /URI/;
while (<>) {
    /$RE{URI}{tel}/       and  print "Contient un URI de téléphone.\n";
}

DESCRIPTION

$RE{URI}{tel}

Renvoie un modèle qui correspond aux URI tel, tels que définis par la RFC 2806. Sous "{-keep}", les éléments suivants sont retournés :

$1
L'URI complet.
$2
Le schéma.
$3
Le numéro de téléphone, y compris tous les compléments possibles tels qu'un sous-adresse ISDN, une partie post-dial, un spécificateur de région, un fournisseur de services, etc.

"$RE{URI}{tel}{nofuture}"

Comme ci-dessus (y compris ce qui est renvoyé par "{-keep}"), à l'exception près que les extensions futures ne sont pas autorisées. Sans autoriser ces extensions futures, il devient beaucoup plus facile de vérifier un URI si la syntaxe correcte pour le post-dial, le fournisseur de services, le contexte téléphonique, etc. a été utilisée - sinon, l'expression régulière pourrait toujours les classer comme une extension future.

RÉFÉRENCES

[RFC 1035]
Mockapetris, P.: DOMAIN NAMES - IMPLEMENTATION AND SPECIFICATION. Novembre 1987.
[RFC 2396]
Berners-Lee, Tim, Fielding, R., and Masinter, L.: Uniform Resource Identifiers (URI): Generic Syntax. Août 1998.
[RFC 2806]
Vaha-Sipila, A.: URLs for Telephone Calls. Avril 2000.

Regexp::Common::URI pour les autres URI pris en charge.
