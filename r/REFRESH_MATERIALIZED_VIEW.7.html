NOM

REFRESH MATERIALIZED VIEW - remplace le contenu d'une vue matérialisée

SYNOPIS

REFRESH MATERIALIZED VIEW [ CONCURRENTLY ] nom
    [ WITH [ NO ] DATA ]

DESCRIPTION

REFRESH MATERIALIZED VIEW remplace complètement le contenu d'une vue matérialisée. Pour exécuter cette commande, vous devez avoir le privilège MAINTAIN sur la vue matérialisée. Le contenu précédent est supprimé. Si WITH DATA est spécifié (ou par défaut), la requête de base est exécutée pour fournir les nouvelles données, et la vue matérialisée est laissée dans un état scannable. Si WITH NO DATA est spécifié, aucune nouvelle donnée n'est générée et la vue matérialisée est laissée dans un état non scannable.

CONCURRENTLY et WITH NO DATA ne peuvent pas être spécifiés ensemble.

PARAMÈTRES

CONCURRENTLY

Rafraîchit la vue matérialisée sans bloquer les sélections concurrentes sur la vue matérialisée. Sans cette option, un rafraîchissement qui affecte un grand nombre de lignes tendra à utiliser moins de ressources et à se terminer plus rapidement, mais pourrait bloquer d'autres connexions qui essaient de lire depuis la vue matérialisée. Cette option peut être plus rapide dans les cas où un petit nombre de lignes est affecté.

Cette option n'est autorisée que s'il existe au moins un index UNIQUE sur la vue matérialisée qui utilise uniquement des noms de colonnes et inclut toutes les lignes ; c'est-à-dire qu'il ne doit pas s'agir d'un index d'expression ni inclure une clause WHERE.

Cette option ne peut être utilisée que lorsque la vue matérialisée est déjà remplie.

Même avec cette option, un seul REFRESH à la fois peut être exécuté sur une vue matérialisée donnée.

nom

Le nom (éventuellement qualifié par un schéma) de la vue matérialisée à rafraîchir.

NOTES

S'il y a une clause ORDER BY dans la requête définissant la vue matérialisée, le contenu original de la vue matérialisée sera ordonné ainsi ; mais REFRESH MATERIALIZED VIEW ne garantit pas de conserver cet ordre.

Pendant que REFRESH MATERIALIZED VIEW s'exécute, le search_path est temporairement modifié en pg_catalog, pg_temp.

EXEMPLES

Cette commande remplacera le contenu de la vue matérialisée nommée order_summary en utilisant la requête de la définition de la vue matérialisée, et la laissera dans un état scannable :

REFRESH MATERIALIZED VIEW order_summary;

Cette commande libérera le stockage associé à la vue matérialisée annual_statistics_basis et la laissera dans un état non scannable :

REFRESH MATERIALIZED VIEW annual_statistics_basis WITH NO DATA;

COMPATIBILITÉ

REFRESH MATERIALIZED VIEW est une extension PostgreSQL.
