RTCRay(3) Embree Ray Tracing Kernels 4 RTCRay(3)

NOM

RTCRay - structure de rayon unique

SYNTAXE

#include <embree4/rtcore_ray.h>
struct RTC_ALIGN(16) RTCRay
{
  float org_x;        // coordonnée x de l'origine du rayon
  float org_y;        // coordonnée y de l'origine du rayon
  float org_z;        // coordonnée z de l'origine du rayon
  float tnear;        // début du segment de rayon
  float dir_x;        // coordonnée x de la direction du rayon
  float dir_y;        // coordonnée y de la direction du rayon
  float dir_z;        // coordonnée z de la direction du rayon
  float time;         // temps de ce rayon pour le flou de mouvement
  float tfar;         // fin du segment de rayon (fixé à la distance de collision)
  unsigned int mask;  // masque de rayon
  unsigned int id;    // ID du rayon
  unsigned int flags; // indicateurs de rayon
};

DESCRIPTION

La structure RTCRay définit la disposition des rayons pour un rayon unique. Le rayon contient l'origine (membres org_x, org_y, org_z), le vecteur de direction (membres dir_x, dir_y, dir_z) et le segment de rayon (membres tnear et tfar). La direction du rayon n'a pas besoin d'être normalisée, et seule la plage de paramètres spécifiée par l'intervalle tnear/tfar est considérée comme valide.

Le segment de rayon doit être dans la plage [0,∞], ainsi les intervalles qui commencent derrière l'origine du rayon ne sont pas autorisés, mais les intervalles peuvent s'étendre à l'infini.

Le rayon contient en outre un temps de flou de mouvement dans la plage [0,1] (membre time), un masque de rayon (membre mask), un ID de rayon (membre id) et des indicateurs de rayon (membre flags). Le masque de rayon peut être utilisé pour masquer certaines géométries pour certains rayons (voir rtcSetGeometryMask pour plus de détails). L'ID du rayon peut être utilisé pour identifier un rayon dans une fonction de rappel, même si l'ordre des rayons à l'intérieur d'un paquet de rayons a changé.

L'en-tête embree4/rtcore_ray.h définit en outre la même structure de rayon dans une disposition de structure d'arrayOf (SOA) pour les fonctions API acceptant des paquets de rayons de taille 4 (type RTCRay4), de taille 8 (type RTCRay8) et de taille 16 (type RTCRay16). L'en-tête définit en outre un modèle RTCRayNt pour les paquets de rayons d'une taille arbitraire déterminée à la compilation.
