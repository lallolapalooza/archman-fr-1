RTCHit(3) Embree Ray Tracing Kernels 4 RTCHit(3)

NOM

RTCHit - structure de frappe unique

SYNOPIS

#include <embree4/rtcore.h>
struct RTCHit
{
  float Ng_x;                                        // coordonnée x de la normale géométrique
  float Ng_y;                                        // coordonnée y de la normale géométrique
  float Ng_z;                                        // coordonnée z de la normale géométrique
  float u;                                           // coordonnée barycentrique u de la frappe
  float v;                                           // coordonnée barycentrique v de la frappe
  unsigned int primID;                               // ID de la géométrie
  unsigned int geomID;                               // ID de la primitive
  unsigned int instID[RTC_MAX_INSTANCE_LEVEL_COUNT]; // ID de l'instance
};

DESCRIPTION

Le type RTCHit définit le type d'un résultat d'intersection rayon/primitive. La frappe contient la normale géométrique non normalisée dans l'espace objet à l'emplacement de la frappe (membres Ng_x, Ng_y, Ng_z), les coordonnées barycentriques u/v de la frappe (membres u et v), ainsi que l'ID de la primitive (membre primID), l'ID de la géométrie (membre geomID) et la pile des ID d'instance (membre instID) de la frappe. La distance d'intersection paramétrique n'est pas stockée dans la frappe, mais est stockée dans le membre tfar du rayon.

L'en-tête embree4/rtcore_ray.h définit également la même structure de frappe en disposition de structure de tableaux (SOA) pour les paquets de frappe de taille 4 (type RTCHit4), taille 8 (type RTCHit8) et taille 16 (type RTCHit16). L'en-tête définit en outre un modèle RTCHitNt pour les paquets de frappe d'une taille arbitraire déterminée à la compilation.
