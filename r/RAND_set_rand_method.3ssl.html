RAND_set_rand_method(3ssl)

Paquet: openssl

RAND_SET_RAND_METHOD(3ssl) OpenSSL RAND_SET_RAND_METHOD(3ssl)

NOM

RAND_set_rand_method, RAND_get_rand_method, RAND_OpenSSL - sélectionner une méthode RAND

SYNOPSIS

#include <openssl/rand.h>

Les fonctions suivantes ont été dépréciées depuis OpenSSL 3.0, et peuvent être entièrement masquées en définissant OPENSSL_API_COMPAT avec une valeur de version appropriée, voir openssl_user_macros(7) :

RAND_METHOD *RAND_OpenSSL(void);
int RAND_set_rand_method(const RAND_METHOD *meth);
const RAND_METHOD *RAND_get_rand_method(void);

DESCRIPTION

Toutes les fonctions décrites sur cette page sont dépréciées. Les applications devraient plutôt utiliser RAND_set_DRBG_type(3), EVP_RAND(3) et EVP_RAND(7).

Une RAND_METHOD spécifie les fonctions utilisées par OpenSSL pour la génération de nombres aléatoires.

RAND_OpenSSL() retourne l'implémentation par défaut de RAND_METHOD par OpenSSL. Cette implémentation garantit que l'état du PRNG est unique pour chaque thread.

Si un ENGINE est chargé et fournit l'API RAND, il sera utilisé à la place de la méthode retournée par RAND_OpenSSL(). Ceci est déprécié dans OpenSSL 3.0.

RAND_set_rand_method() fait de meth la méthode utilisée pour le PRNG. Si un ENGINE fournissait la méthode, il sera libéré en premier.

RAND_get_rand_method() retourne un pointeur vers la RAND_METHOD actuelle.

LA STRUCTURE RAND_METHOD

typedef struct rand_meth_st {
    int (*seed)(const void *buf, int num);
    int (*bytes)(unsigned char *buf, int num);
    void (*cleanup)(void);
    int (*add)(const void *buf, int num, double entropy);
    int (*pseudorand)(unsigned char *buf, int num);
    int (*status)(void);
} RAND_METHOD;

Les champs pointent vers les fonctions utilisées par, dans l'ordre, RAND_seed(), RAND_bytes(), le nettoyage interne de RAND, RAND_add(), RAND_pseudo_rand() et RAND_status(). Chaque pointeur peut être NULL si la fonction n'est pas implémentée.

VALEURS DE RETOUR

RAND_set_rand_method() retourne 1 en cas de succès et 0 en cas d'échec. RAND_get_rand_method() et RAND_OpenSSL() retournent des pointeurs vers les méthodes respectives.
