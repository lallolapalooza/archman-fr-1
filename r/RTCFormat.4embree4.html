NOM

RTCFormat - spécifie le format des données dans les tampons

SYNOPIS

#include <embree4/rtcore_ray.h>
enum RTCFormat
{
  RTC_FORMAT_UINT,
  RTC_FORMAT_UINT2,
  RTC_FORMAT_UINT3,
  RTC_FORMAT_UINT4,
  RTC_FORMAT_FLOAT,
  RTC_FORMAT_FLOAT2,
  RTC_FORMAT_FLOAT3,
  RTC_FORMAT_FLOAT4,
  RTC_FORMAT_FLOAT5,
  RTC_FORMAT_FLOAT6,
  RTC_FORMAT_FLOAT7,
  RTC_FORMAT_FLOAT8,
  RTC_FORMAT_FLOAT9,
  RTC_FORMAT_FLOAT10,
  RTC_FORMAT_FLOAT11,
  RTC_FORMAT_FLOAT12,
  RTC_FORMAT_FLOAT13,
  RTC_FORMAT_FLOAT14,
  RTC_FORMAT_FLOAT15,

  RTC_FORMAT_FLOAT3X4_COLUMN_MAJOR,
  RTC_FORMAT_FLOAT4X4_COLUMN_MAJOR,
  RTC_FORMAT_GRID,
  RTC_FORMAT_QUATERNION_DECOMPOSITION
};

DESCRIPTION

La structure RTFormat définit le format des données stockées dans les tampons de données fournis à Embree via les appels d'API [rtcSetGeometryBuffer], [rtcSetSharedGeometryBuffer] et [rtcSetNewGeometryBuffer].

Les formats RTC_FORMAT_UINT/2/3/4 sont utilisés pour spécifier que les tampons de données stockent des entiers non signés, ou des vecteurs d'entiers non signés de taille 2, 3 ou 4. Ce format doit généralement être utilisé lors de la spécification des tampons d'indices, par exemple RTC_FORMAT_UINT3 pour les maillages triangulaires.

Les formats RTC_FORMAT_FLOAT/2/3/4... sont utilisés pour spécifier que les tampons de données stockent des valeurs flottantes simple précision, ou des vecteurs de celles-ci (taille 2, 3, 4, etc.). Ce format est typiquement utilisé pour spécifier le format des tampons de sommets, par exemple le type RTC_FORMAT_FLOAT3 pour les tampons de sommets de maillages triangulaires.

Les formats RTC_FORMAT_FLOAT3X4_ROW_MAJOR et RTC_FORMAT_FLOAT3X4_COLUMN_MAJOR spécifient une matrice flottante 3x4 disposée en ligne majeure ou en colonne majeure. Les formats RTC_FORMAT_FLOAT4X4_ROW_MAJOR et RTC_FORMAT_FLOAT4X4_COLUMN_MAJOR spécifient une matrice flottante 4x4 disposée en ligne majeure ou en colonne majeure. Le format RTC_FORMAT_QUATERNION_DECOMPOSITION spécifie une structure qui représente une décomposition quaternionique (voir [RTCQuaternionDecomposition]) d'une transformation affine. Ces formats sont utilisés dans la fonction [rtcSetGeometryTransform] ou dans les tampons de géométrie avec le type RTC_BUFFER_TYPE_TRANSFORM afin de définir une matrice de transformation pour les géométries d'instance et de tableaux d'instances.

RTC_FORMAT_GRID est un format de données spécial utilisé pour spécifier des primitives de grille de disposition RTCGrid lors de la création de géométries de grille (voir [RTC_GEOMETRY_TYPE_GRID]).
