RTCRayHitN(3) Embree Ray Tracing Kernels 3 RTCRayHitN(3)

NOM

RTCRayHitN - paquet combiné rayon/intersection de taille dynamique

SYNTAXE

#include <embree3/rtcore_ray.h>
struct RTCRayHitN;
struct RTCRayN* RTCRayHitN_RayN(struct RTCRayHitN* rayhit, unsigned int N);
struct RTCHitN* RTCRayHitN_HitN(struct RTCRayHitN* rayhit, unsigned int N);

DESCRIPTION

Lorsque la taille du paquet d'une structure rayon/intersection n'est pas connue à la compilation (par exemple, lorsque Embree renvoie un paquet rayon/intersection dans la fonction de rappel RTCIntersectFunctionN), Embree utilise le type RTCRayHitN pour les paquets de rayons. Ces paquets rayon/intersection ne peuvent avoir que des tailles de 1, 4, 8 ou 16. Aucune autre taille de paquet ne sera utilisée.

Vous pouvez soit implémenter des chemins de code spéciaux différents pour chacune de ces tailles de paquet possibles et caster le rayon/intersection vers le type de paquet rayon/intersection approprié, soit extraire les composants RTCRayN et RTCHitN à l'aide des fonctions d'aide rtcGetRayN et rtcGetHitN et utiliser les fonctions RTCRayN_XXX et RTCHitN_XXX pour accéder aux parties rayon et intersection de la structure.
