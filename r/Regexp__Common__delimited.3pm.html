NOM

Regexp::Common::delimited -- fournit une expression régulière pour les chaînes délimitées

SYNTAXE

use Regexp::Common qw /delimited/;
while (<>) {
    /$RE{delimited}{-delim=>'"'}/  and print 'une chaîne délimitée par des guillemets';
    /$RE{delimited}{-delim=>'/'}/  and print 'une chaîne délimitée par des slashs';
}

DESCRIPTION

Veuillez consulter le manuel de Regexp::Common pour une description générale du fonctionnement de cette interface.

N'utilisez pas ce module directement, mais chargez-le via Regexp::Common.

"$RE{delimited}{-delim}{-cdelim}{-esc}"

Renvoie un modèle qui correspond à une sous-chaîne délimitée par un seul caractère, avec une échappement interne optionnel du délimiteur.

Lorsque "-delim =" S> est spécifié, chaque caractère de la séquence S est un délimiteur possible. Il n'y a pas de délimiteur par défaut, donc cet indicateur doit toujours être spécifié.

Par défaut, le délimiteur de fermeture est le même caractère que le délimiteur d'ouverture. Si ce n'est pas souhaité, par exemple, si vous voulez faire correspondre une chaîne avec des délimiteurs symétriques, vous pouvez spécifier les délimiteurs de fermeture avec "-cdelim =" S>. Chaque caractère de S correspond au caractère correspondant fourni avec l'option "-delim". Si l'option "-cdelim" a moins de caractères que l'option "-delim", le dernier caractère est répété autant de fois que nécessaire. Si l'option "-cdelim" a plus de caractères que l'option "-delim", les caractères supplémentaires sont ignorés.

Si "-esc =" S> est spécifié, chaque caractère de la séquence S est le délimiteur pour chaque caractère correspondant dans la liste "-delim=S". Le caractère d'échappement par défaut est la barre oblique inverse.

Par exemple:

$RE{delimited}{-delim=>'"'}               # correspond à "une chaîne délimitée par des guillemets\" "
$RE{delimited}{-delim=>'"'}{-esc=>'"'}    # correspond à "une chaîne délimitée par des guillemets"" "
$RE{delimited}{-delim=>'/'}               # correspond à /une chaîne délimitée par des slashs\/ /
$RE{delimited}{-delim=>q{'"}}             # correspond à "chaîne" ou 'chaîne'
$RE{delimited}{-delim=>"("}{-cdelim=>")"} # correspond à (chaîne)

Sous "-keep" (Voir Regexp::Common):

$1
capture toute la correspondance
$2
capture le délimiteur d'ouverture
$3
capture la partie délimitée de la chaîne
$4
capture le délimiteur de fermeture

$RE{quoted}{-esc}

Un synonyme de "$RE {delimited} {-delim => q {'"`}} {...}".

$RE {bquoted} {-esc}

Ceci est un modèle qui correspond aux chaînes délimitées, où les délimiteurs sont un ensemble de crochets correspondants. Actuellement, cela inclut 85 paires. Cela inclut les 60 paires de crochets bidirectionnels, telles que listées dans http://www.unicode.org/Public/UNIDATA/BidiBrackets.txt.

Les 25 autres paires sont les guillemets, les guillemets doubles, les guillemets simples et doubles pointés, les virgules lourdes simples et doubles, 4 paires de parenthèses et crochets haut-bas, 9 paires de formes de présentation pour les crochets verticaux, et les crochets de paraphrase basse, d'omission élevée, de substitution, de double substitution et de transposition.

Dans une future mise à jour, des paires pourront être ajoutées (ou supprimées).

Ce modèle nécessite perl 5.14.0 ou supérieur.

Pour une liste complète des paires de crochets, inspectez la sortie de "Regexp::Common::delimited::bracket_pair ()", qui renvoie une liste de tableaux à deux éléments, chacun contenant les noms Unicode de la paire de délimiteurs correspondants.

L'option "{-esc => S }" fonctionne comme dans le modèle "$RE {delimited}".

Si "{-keep}" est donné, les éléments suivants seront capturés :

$1
capture toute la correspondance
$2
capture le délimiteur d'ouverture
$3
capture la partie délimitée de la chaîne
$4
capture le délimiteur de fermeture
