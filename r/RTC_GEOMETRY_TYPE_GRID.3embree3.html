NOM

RTC_GEOMETRY_TYPE_GRID - type de géométrie de grille

SYNTAXE

#include <embree3/rtcore.h>
RTCGeometry geometry =
  rtcNewGeometry(device, RTC_GEOMETRY_TYPE_GRID);

DESCRIPTION

Les maillages de grille sont créés en passant RTC_GEOMETRY_TYPE_GRID à l'appel de fonction rtcNewGeometry, et contiennent un tableau de primitives de grille. Ce tableau de grilles peut être spécifié en configurant un tampon de grille (avec le type RTC_BUFFER_TYPE_GRID et le format RTC_FORMAT_GRID) et les sommets du maillage de grille en configurant un tampon de sommets (type RTC_BUFFER_TYPE_VERTEX). Voir rtcSetGeometryBuffer et rtcSetSharedGeometryBuffer pour plus de détails sur la manière de configurer les tampons. Le nombre de primitives de grille dans le maillage de grille est déduit de la taille du tampon de grille.

Le tampon de sommets contient un tableau de coordonnées flottantes x, y, z en simple précision (format RTC_FORMAT_FLOAT3), et le nombre de sommets est déduit de la taille de ce tampon.

Chaque grille dans le tampon de grille est de type RTCGrid:

struct RTCGrid
{
  unsigned int startVertexID;
  unsigned int stride;
  unsigned short width,height; 
};

La structure RTCGrid décrit une grille 2D de sommets (par rapport au tampon de sommets du maillage de grille). Les membres width et height spécifient le nombre de sommets dans la direction u et v, par exemple, régler width et height à 3 configure une grille de sommets 3x3. La largeur et la hauteur maximales autorisées sont de 32767. startVertexID spécifie l'ID du sommet en haut à gauche dans la grille de sommets, tandis que le paramètre stride spécifie un pas (en nombre de sommets) utilisé pour passer à la ligne suivante.

Une grille de sommets de dimensions width et height est traitée comme une grille de quads (paires de triangles) de (width-1) x (height-1), avec la même gestion des bords partagés que pour les maillages de quads réguliers. Cependant, les coordonnées u/v ont la plage uniforme [0..1] pour une grille de sommets entière. La direction u suit la largeur de la grille tandis que la direction v suit la hauteur.

Pour le flou de mouvement multi-segments, le nombre de pas de temps doit d'abord être spécifié à l'aide de l'appel rtcSetGeometryTimeStepCount. Ensuite, un tampon de sommets pour chaque pas de temps peut être configuré en utilisant différents emplacements de tampon, et tous ces tampons doivent avoir le même pas et la même taille.

STATUT DE RÉSULTAT

En cas d'échec, NULL est retourné et un code d'erreur est défini qui peut être interrogé à l'aide de rtcGetDeviceError.

VOIR AUSSI

[rtcNewGeometry]
