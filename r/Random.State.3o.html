type t

Le type des états de PRNG.

val make : int array -> t

Crée un nouvel état et l'initialise avec la graine donnée.

val make_self_init : unit -> t

Crée un nouvel état et l'initialise avec une graine aléatoire choisie d'une manière dépendante du système. La graine est obtenue comme décrit dans Random.self_init .

val copy : t -> t

Retourne une copie de l'état donné.

Ces fonctions sont les mêmes que les fonctions de base, sauf qu'elles utilisent (et mettent à jour) l'état PRNG donné au lieu de celui par défaut.

val split : t -> t

Tire un nouvel état PRNG à partir de l'état PRNG donné. (L'état PRNG donné est modifié.) Le nouvel état PRNG est statistiquement indépendant de l'état PRNG donné. Des données peuvent être tirées des deux PRNG, dans n'importe quel ordre, sans risque de corrélation. Les deux PRNG peuvent être divisés plus tard, arbitrairement de nombreuses fois.

Depuis 5.0

val to_binary_string : t -> string

Sérialise l'état PRNG dans une séquence de bytes immuable. Voir Random.State.of_binary_string pour la désérialisation.

Le type string est destiné ici uniquement à la sérialisation, l'encodage n'est pas lisible par l'homme et peut ne pas être imprimable.

Notez que le format de sérialisation peut différer entre les versions d'OCaml.

Depuis 5.1

val of_binary_string : string -> t

Désérialise une séquence de bytes obtenue en appelant Random.State.to_binary_string . L'état PRNG résultant produira les mêmes nombres aléatoires que l'état qui a été passé en entrée à Random.State.to_binary_string .

Depuis 5.1

Lève Failure si l'entrée n'est pas dans le format attendu.

Notez que le format de sérialisation peut différer entre les versions d'OCaml.

Contrairement aux fonctions fournies par le module Marshal, cette fonction produit soit un état valide, soit échoue proprement avec une exception Failure. Elle peut être utilisée en toute sécurité sur des entrées fournies par l'utilisateur et non fiables.
