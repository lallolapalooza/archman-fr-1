NOM

Regexp::Common::URI -- fournir des modèles pour les URI.

SYNOPSIS

use Regexp::Common qw /URI/;
while (<>) {
    /$RE{URI}{HTTP}/       and  print "Contient un URI HTTP.\n";
}

DESCRIPTION

Les modèles pour les URI suivants sont pris en charge : fax, file, FTP, gopher, HTTP, news, NTTP, pop, prospero, tel, telnet, tv et WAIS. Chacun est documenté dans la page man Regexp::Common::URI::schéma, pour le schéma approprié (en minuscules), à l'exception des URI NNTP qui se trouvent dans Regexp::Common::URI::news.

$RE{URI}

Renvoie un modèle qui reconnaît l'un des URI pris en charge. Avec "{-keep}", seul l'URI entier est renvoyé (dans $1).
