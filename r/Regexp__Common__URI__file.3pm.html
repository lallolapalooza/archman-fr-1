NOM

Regexp::Common::URI::file -- Retourne un modèle pour les URI de type file.

SYNOPIS

use Regexp::Common qw /URI/;
while (<>) {
    /$RE{URI}{file}/       and  print "Contient un URI de type file.\n";
}

DESCRIPTION

$RE{URI}{file}

Retourne un modèle qui correspond aux URI de type file, tels que définis par la RFC 1738. Les URI de type file ont la forme suivante :

"file:" "//" [ hôte | "localhost" ] "/" chemin_fichier

Sous "{-keep}", les éléments suivants sont retournés :

$1
L'URI complet.
$2
Le schéma.
$3
La partie de l'URI suivant "file://".
$4
Le nom d'hôte.
$5
Le nom du chemin, incluant la barre oblique initiale.
$6
Le nom du chemin, sans la barre oblique initiale.

RÉFÉRENCES

[RFC 1738]
Berners-Lee, Tim, Masinter, L., McCahill, M.: Uniform Resource Locators (URL). Décembre 1994.

VOIR AUSSI

Regexp::Common::URI pour les autres URI pris en charge.
