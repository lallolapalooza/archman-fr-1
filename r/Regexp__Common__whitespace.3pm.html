NOM

Regexp::Common::whitespace -- fournit une expression régulière pour les espaces blancs de début ou de fin

SYNTAXE

use Regexp::Common qw /whitespace/;
while (<>) {
    s/$RE{ws}{crop}//g;           # Supprime les espaces blancs environnants
}

DESCRIPTION

Veuillez consulter le manuel de Regexp::Common pour une description générale du fonctionnement de cette interface.

N'utilisez pas ce module directement, mais chargez-le via Regexp::Common.

"$RE{ws}{crop}"

Retourne un motif qui identifie les espaces blancs de début ou de fin.

Par exemple :

$str =~ s/$RE{ws}{crop}//g;     # Supprime les espaces blancs environnants

L'appel :

$RE{ws}{crop}->subs($str);

est optimisé (mais probablement toujours plus lent que de faire le s///g explicitement).

Ce motif ne capture pas sous l'option "-keep".
