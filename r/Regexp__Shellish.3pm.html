NOM

Regexp::Shellish - Expressions régulières similaires au shell

SYNOPSIS

use Regexp::Shellish qw( :all ) ;
$re = compile_shellish( 'a/c*d' ) ;
## Ceci est similaire à 'a*d' sauf qu'il
## correspondra à 'a/d'.
$re = compile_shellish( 'a**d' ) ;
## Et ici '**' ne correspondra pas à 'a/d', mais se comportera
## comme 'a*d', à l'exception d'une consommation potentiellement élevée de CPU.
$re = compile_shellish( 'a**d', { star_star => 0 } ) ;
## Les deux prochains génèrent des $re1 et $re2 identiques.
## Le second est une opération nulle pour que les références Regexp puissent
## être facilement prises en charge.
$re1 = compile_shellish( 'a{b,c}d' ) ;
$re2 = compile_shellish( qr/\A(?:a(?:b|c)d)\Z/ ) ;
@matches = shellish_glob( $re, @possibilities ) ;

DESCRIPTION

Fournit des expressions régulières similaires au shell. Les jokers fournis sont "?", "*" et "**", où "**" est comme "*" mais correspond au "/". Voir "compile_shellish" pour les détails.

La sensibilité à la casse et des constructions comme <**>, "(a*b)" et "{a,b,c}" peuvent être désactivées.

compile_shellish
Compile une chaîne contenant une expression régulière « shellish », renvoyant une référence Regexp. Les références Regexp passées sont renvoyées sans modification.

Voici les règles de transformation des termes d'expression shellish en termes d'expression régulière Perl :

Shellish  RE Perl
========  =======
*         [^/]*
?         .
**        .*               ## sauf si { star_star   => 0 }
...       .*               ## sauf si { dot_dot_dot => 0 }
(         (                ## sauf si { parens => 0 }
)         )                ## sauf si { parens => 0 }
{a,b,c}   (?:a|b|c)        ## sauf si { braces => 0 }
\a        a                ## Ceux-ci sont déséchappés et
\*        \*               ## passés à quotemeta()

Les jokers traitent les sauts de ligne comme des caractères normaux.

Les parenthèses regroupent en $1..$n, car elles sont transmises sans modification (sauf si l'option parens => 0 est passée). Ceci est cependant inutile lors de l'utilisation de glob_shellish().

Le dernier paramètre peut être une référence de hachage contenant des options :

compile_shellish(
   '**',
   {
      anchors        => 0,   ## N'entoure pas le
                             ## regexp résultant de ^ et $
      case_sensitive => 0,   ## Insensible à la casse
      dot_dot_dot    => 0,   ## '...' correspond maintenant à trois '.'
      star_star      => 0,   ## '**' correspond maintenant à deux jokers '*'
      parens         => 0,   ## '(', ')' sont maintenant des caractères ordinaires
      braces         => 0,   ## '{', '}' sont maintenant des caractères ordinaires
   }
) ;

Aucune option n'affecte les Regexps transmis.

shellish_glob
Passe une expression régulière et une liste de valeurs possibles, renvoie une liste de valeurs correspondantes. 
my @matches = shellish_glob( '*/*', @possibilities ) ;
my @matches = shellish_glob( '*/*', @possibilities, \%options ) ;
