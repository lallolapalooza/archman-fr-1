NOM

Ref::Util::XS - Implémentation XS pour Ref::Util

VERSION

version 0.117

SYNOPIS

use Ref::Util;
# N'utilisez pas directement Ref::Util::XS !
if (is_arrayref($something) {
    print for @$something;
}
elsif (is_hashref($something)) {
    print for sort values %$something;
}

DESCRIPTION

Ref::Util::XS est l'implémentation XS de Ref::Util, qui fournit plusieurs fonctions pour aider à identifier les références de manière plus pratique que l'approche habituelle consistant à examiner la valeur de retour de "ref".

Vous devriez utiliser Ref::Util::XS en installant Ref::Util lui-même : si le système sur lequel vous l'installez dispose d'un compilateur C, "Ref::Util::XS" sera installé et utilisé automatiquement, offrant une amélioration significative de la vitesse à tout ce qui utilise "Ref::Util".

Voir Ref::Util pour la documentation complète des fonctions disponibles.
