RAND_EGD(3ssl) OpenSSL RAND_EGD(3ssl)

NOM

RAND_egd, RAND_egd_bytes, RAND_query_egd_bytes - interroger le démon de collecte d'entropie

SYNTAXE

#include <openssl/rand.h>
int RAND_egd_bytes(const char *path, int num);
int RAND_egd(const char *path);
int RAND_query_egd_bytes(const char *path, unsigned char *buf, int num);

DESCRIPTION

Sur les plateformes plus anciennes sans source de caractère aléatoire adéquate telle que "/dev/urandom", il est possible d'interroger un démon de collecte d'entropie (EGD) via une socket locale pour obtenir de l'aléatoire et initialiser le générateur de nombres aléatoires d'OpenSSL. Le protocole utilisé est défini par les EGD disponibles sur http://egd.sourceforge.net/ ou http://prngd.sourceforge.net.

RAND_egd_bytes() demande num octets d'aléatoire à un EGD situé à la socket spécifiée par path, et passe les données qu'il reçoit à RAND_add(). RAND_egd() est équivalent à RAND_egd_bytes() avec num défini à 255.

RAND_query_egd_bytes() demande num octets d'aléatoire à un EGD situé à la socket spécifiée par path, où num doit être inférieur à 256. Si buf est NULL, cela est équivalent à RAND_egd_bytes(). Si buf n'est pas NULL, alors les données sont copiées dans le tampon et RAND_add() n'est pas appelé.

OpenSSL peut être configuré au moment de la compilation pour essayer d'utiliser l'EGD pour l'initialisation automatiquement.

VALEURS DE RETOUR

RAND_egd() et RAND_egd_bytes() retournent le nombre d'octets lus du démon en cas de succès, ou -1 si la connexion a échoué ou si le démon n'a pas renvoyé suffisamment de données pour initialiser complètement le PRNG.

RAND_query_egd_bytes() retourne le nombre d'octets lus du démon en cas de succès, ou -1 si la connexion a échoué.

VOIR AUSSI

RAND_add(3), RAND_bytes(3), RAND(7)
