RAND_load_file(3ssl)

Paquet: openssl

Licences: Apache-2.0

RAND_LOAD_FILE(3ssl) OpenSSL RAND_LOAD_FILE(3ssl)

NOM

RAND_load_file, RAND_write_file, RAND_file_name - Fichier de graine du PRNG

SYNTAXE

#include <openssl/rand.h>
int RAND_load_file(const char *filename, long max_bytes);
int RAND_write_file(const char *filename);
const char *RAND_file_name(char *buf, size_t num);

DESCRIPTION

RAND_load_file() lit un certain nombre d'octets du fichier filename et les ajoute au PRNG. Si max_bytes est non négatif, jusqu'à max_bytes sont lus ; si max_bytes est -1, le fichier complet est lu (sauf si le fichier n'est pas un fichier régulier, auquel cas un nombre fixe d'octets, 256 dans l'implémentation actuelle, est tenté d'être lu). RAND_load_file() peut lire moins que le fichier complet ou le nombre d'octets demandé s'il ne tient pas dans le type de valeur de retour. Ne chargez pas le même fichier plusieurs fois à moins que son contenu n'ait été mis à jour par RAND_write_file() entre les lectures. De plus, notez que filename doit être protégé de manière adéquate pour qu'un attaquant ne puisse pas remplacer ou examiner le contenu. Si filename n'est pas un fichier régulier, l'utilisateur est considéré comme responsable de tout effet de bord, par exemple un blocage non anticipé ou la capture du terminal de contrôle.

RAND_write_file() écrit un certain nombre d'octets aléatoires (actuellement 128) dans le fichier filename qui peut être utilisé pour initialiser le PRNG en appelant RAND_load_file() lors d'une session ultérieure.

RAND_file_name() génère un chemin par défaut pour le fichier de graine aléatoire. buf pointe vers un tampon de taille num dans lequel stocker le nom de fichier.

Sur tous les systèmes, si la variable d'environnement RANDFILE est définie, sa valeur sera utilisée comme nom de fichier de graine. Sinon, le fichier s'appelle ".rnd", et se trouve dans des emplacements spécifiques à la plateforme :

Sous Windows (par ordre de préférence)
%HOME%, %USERPROFILE%, %SYSTEMROOT%, C:\
Sous VMS
SYS$LOGIN:
Sur tous les autres systèmes
$HOME

Si $HOME (sur les systèmes non-Windows et non-VMS) n'est pas non plus défini, ou si num est trop petit pour le chemin d'accès, une erreur se produit.

VALEURS DE RETOUR

RAND_load_file() retourne le nombre d'octets lus ou -1 en cas d'erreur.

RAND_write_file() retourne le nombre d'octets écrits, ou -1 si les octets écrits ont été générés sans amorçage approprié.

RAND_file_name() retourne un pointeur vers buf en cas de succès, et NULL en cas d'erreur.
