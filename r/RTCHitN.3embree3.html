RTCHitN(3) Embree Ray Tracing Kernels 3 RTCHitN(3)

NOM

RTCHitN - paquet de succès de taille d'exécution

SYNTAXE

#include <embree3/rtcore.h>
struct HitN;
float& RTCHitN_Ng_x(RTCHitN* hit, unsigned int N, unsigned int i);
float& RTCHitN_Ng_y(RTCHitN* hit, unsigned int N, unsigned int i);
float& RTCHitN_Ng_z(RTCHitN* hit, unsigned int N, unsigned int i);
float& RTCHitN_u(RTCHitN* hit, unsigned int N, unsigned int i);
float& RTCHitN_v(RTCHitN* hit, unsigned int N, unsigned int i);
unsigned& RTCHitN_primID(RTCHitN* hit, unsigned int N, unsigned int i);
unsigned& RTCHitN_geomID(RTCHitN* hit, unsigned int N, unsigned int i);
unsigned& RTCHitN_instID(RTCHitN* hit, unsigned int N, unsigned int i, unsigned int level);

DESCRIPTION

Lorsque la taille du paquet de succès n'est pas connue au moment de la compilation (par exemple, lorsque Embree renvoie un paquet de succès dans la fonction de rappel RTCFilterFuncN), Embree utilise le type RTCHitN pour les paquets de succès. Ces paquets de succès ne peuvent avoir que des tailles de 1, 4, 8 ou 16. Aucune autre taille de paquet ne sera utilisée.

Vous pouvez soit implémenter différents chemins de code spéciaux pour chacune de ces tailles de paquet possibles et caster le succès vers le type de paquet de succès approprié, soit implémenter un chemin de code général qui utilise les fonctions d'aide RTCHitN_XXX pour accéder aux composants du paquet de succès.

Ces fonctions d'aide reçoivent un pointeur vers le paquet de succès (argument hit), la taille du paquet (argument N) et renvoient une référence vers un composant (par exemple, le composant x de Ng) du i-ème succès du paquet (argument i).
