NOM

RSA_private_encrypt, RSA_public_decrypt - opérations de signature de bas niveau

SYNTAXE

#include <openssl/rsa.h>

Les fonctions suivantes sont dépréciées depuis OpenSSL 3.0, et peuvent être entièrement masquées en définissant OPENSSL_API_COMPAT avec une valeur de version appropriée, voir openssl_user_macros(7):

int RSA_private_encrypt(int flen, unsigned char *from,
                        unsigned char *to, RSA *rsa, int padding);
int RSA_public_decrypt(int flen, unsigned char *from,
                       unsigned char *to, RSA *rsa, int padding);

DESCRIPTION

Les deux fonctions décrites dans cette page sont dépréciées. Les applications devraient plutôt utiliser EVP_PKEY_sign_init_ex(3), EVP_PKEY_sign(3), EVP_PKEY_verify_recover_init(3), et EVP_PKEY_verify_recover(3).

Ces fonctions gèrent les signatures RSA à bas niveau.

RSA_private_encrypt() signe les flen octets de from (généralement un résumé de message avec un identifiant d'algorithme) en utilisant la clé privée rsa et stocke la signature dans to. to doit pointer vers une mémoire de RSA_size(rsa) octets.

padding désigne l'un des modes suivants :

RSA_PKCS1_PADDING
Rembourrage PKCS #1 v1.5. Cette fonction ne gère pas l'algorithmIdentifier spécifié dans PKCS #1. Lors de la génération ou de la vérification des signatures PKCS #1, RSA_sign(3) et RSA_verify(3) devraient être utilisés.
RSA_NO_PADDING
Signature RSA brute. Ce mode ne devrait être utilisé *que* pour implémenter des modes de rembourrage cryptographiquement sûrs dans le code applicatif. Signer directement des données utilisateur avec RSA est non sécurisé.

RSA_public_decrypt() récupère le résumé du message des flen octets de signature dans from en utilisant la clé publique du signataire rsa. to doit pointer vers une section mémoire suffisamment grande pour contenir le résumé du message (qui est plus petit que RSA_size(rsa) - 11). padding est le mode de rembourrage utilisé pour signer les données.

VALEURS DE RETOUR

RSA_private_encrypt() retourne la taille de la signature (c'est-à-dire RSA_size(rsa)). RSA_public_decrypt() retourne la taille du résumé du message récupéré.

En cas d'erreur, -1 est retourné ; les codes d'erreur peuvent être obtenus via ERR_get_error(3).

VOIR AUSSI

ERR_get_error(3), RSA_sign(3), RSA_verify(3), EVP_PKEY_sign(3), EVP_PKEY_verify_recover(3)

HISTORIQUE

Ces deux fonctions ont été dépréciées dans OpenSSL 3.0.
