RTCRayHitN(3) Embree Ray Tracing Kernels 4 RTCRayHitN(3)

NOM

RTCRayHitN - paquet combiné rayon/impact de taille dynamique

SYNTAXE

#include <embree4/rtcore_ray.h>
struct RTCRayHitN;
struct RTCRayN* RTCRayHitN_RayN(struct RTCRayHitN* rayhit, unsigned int N);
struct RTCHitN* RTCRayHitN_HitN(struct RTCRayHitN* rayhit, unsigned int N);

DESCRIPTION

Lorsque la taille du paquet d'une structure rayon/impact n'est pas connue à la compilation (par exemple, lorsque Embree retourne un paquet rayon/impact dans la fonction de rappel RTCIntersectFunctionN), Embree utilise le type RTCRayHitN pour les paquets de rayons. Ces paquets rayon/impact ne peuvent avoir que des tailles de 1, 4, 8 ou 16. Aucune autre taille de paquet ne sera utilisée.

Vous pouvez soit implémenter différents chemins de code spéciaux pour chacune de ces tailles de paquet possibles et caster le rayon/impact vers le type de paquet rayon/impact approprié, soit extraire les composants RTCRayN et RTCHitN à l'aide des fonctions d'aide rtcGetRayN et rtcGetHitN et utiliser les fonctions RTCRayN_XXX et RTCHitN_XXX pour accéder aux parties rayon et impact de la structure.
