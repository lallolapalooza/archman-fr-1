RTCCurveFlags(3) Embree Ray Tracing Kernels 3 RTCCurveFlags(3)

NOM

RTCCurveFlags - drapeaux par segment pour la géométrie de courbe

SYNOPIS

#include <embree3/rtcore.h>

enum RTCCurveFlags { RTC_CURVE_FLAG_NEIGHBOR_LEFT = (1 << 0), RTC_CURVE_FLAG_NEIGHBOR_RIGHT = (1 << 1) };

DESCRIPTION

Le type RTCCurveFlags est utilisé pour les courbes linéaires afin de déterminer si le segment voisin gauche et/ou droit existe. Par conséquent, on attache un tampon de type RTC_BUFFER_TYPE_FLAGS à la géométrie de courbe qui stocke un octet individuel par segment de courbe.

Si le drapeau RTC_CURVE_FLAG_NEIGHBOR_LEFT dans cet octet est activé pour un segment de courbe, alors le segment gauche existe (qui commence un vértice avant le sommet de départ de la courbe actuelle) et le segment actuel est rendu pour s'attacher correctement à ce segment.

Si le drapeau RTC_CURVE_FLAG_NEIGHBOR_RIGHT dans cet octet est activé pour un segment de courbe, alors le segment droit existe (qui se termine un vértice après le sommet de fin de la courbe actuelle) et le segment actuel est rendu pour s'attacher correctement à ce segment.

Lorsque les drapeaux gauche et droit ne sont pas correctement spécifiés pour les courbes linéaires, le rendu aux extrémités de ces courbes peut ne pas sembler correct, en particulier lorsque des courbes linéaires arrondies sont vues de l'intérieur.
