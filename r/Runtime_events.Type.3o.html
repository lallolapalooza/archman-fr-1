type 'a t

Le type pour le contenu d'un événement utilisateur.

val unit : unit t

Un événement qui n'a pas de données associées.

type span =
| Begin
| End

val span : span t

Un événement qui a un début et une fin.

val int : int t

Un événement contenant une valeur entière.

val register : encode:(bytes -> 'a -> int) -> decode:(bytes -> int -> 'a) -> 'a t

Enregistre un type personnalisé en fournissant un encodeur et un décodeur. L'encodeur écrit la valeur dans le tampon fourni et renvoie le nombre d'octets écrits. Le décodeur reçoit une tranche du tampon d'une longueur spécifiée et renvoie la valeur décodée.

La longueur maximale de la valeur est de 1024 octets.
