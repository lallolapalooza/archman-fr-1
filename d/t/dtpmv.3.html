Documentation de la fonction/sous-programme

sous-programme dtpmv (caractère uplo, caractère trans, caractère diag, entier n, double précision, dimension(*) ap, double précision, dimension(*) x, entier incx)

DTPMV

Objectif :

!>
!> DTPMV  effectue l'une des opérations matrice-vecteur suivantes :
!>
!>    x := A*x,   ou   x := A**T*x,
!>
!> où x est un vecteur de n éléments et A est une matrice triangulaire
!> de dimension n par n, unitaire ou non, supérieure ou inférieure,
!> fournie sous forme compactée.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>           À l'entrée, UPLO spécifie si la matrice est supérieure ou
!>           inférieure triangulaire comme suit :
!>
!>              UPLO = 'U' ou 'u'   A est une matrice triangulaire supérieure.
!>
!>              UPLO = 'L' ou 'l'   A est une matrice triangulaire inférieure.
!>

TRANS

!>          TRANS est CHARACTER*1
!>           À l'entrée, TRANS spécifie l'opération à effectuer comme suit :
!>
!>              TRANS = 'N' ou 'n'   x := A*x.
!>
!>              TRANS = 'T' ou 't'   x := A**T*x.
!>
!>              TRANS = 'C' ou 'c'   x := A**T*x.
!>

DIAG

!>          DIAG est CHARACTER*1
!>           À l'entrée, DIAG spécifie si A est unitaire ou non
!>           triangulaire comme suit :
!>
!>              DIAG = 'U' ou 'u'   A est supposée être unitaire triangulaire.
!>
!>              DIAG = 'N' ou 'n'   A n'est pas supposée être unitaire
!>                                  triangulaire.
!>

N

!>          N est INTEGER
!>           À l'entrée, N spécifie l'ordre de la matrice A.
!>           N doit être supérieur ou égal à zéro.
!>

AP

!>          AP est un tableau de DOUBLE PRÉCISION, de dimension au moins
!>           ( ( n*( n + 1 ) )/2 ).
!>           Avant l'appel avec UPLO = 'U' ou 'u', le tableau AP doit
!>           contenir la matrice triangulaire supérieure compactée séquentiellement,
!>           colonne par colonne, de sorte que AP( 1 ) contienne a( 1, 1 ),
!>           AP( 2 ) et AP( 3 ) contiennent respectivement a( 1, 2 ) et a( 2, 2 ),
!>           et ainsi de suite.
!>           Avant l'appel avec UPLO = 'L' ou 'l', le tableau AP doit
!>           contenir la matrice triangulaire inférieure compactée séquentiellement,
!>           colonne par colonne, de sorte que AP( 1 ) contienne a( 1, 1 ),
!>           AP( 2 ) et AP( 3 ) contiennent respectivement a( 2, 1 ) et a( 3, 1 ),
!>           et ainsi de suite.
!>           Notez que lorsque DIAG = 'U' ou 'u', les éléments diagonaux de
!>           A ne sont pas référencés, mais sont supposés être égaux à un.
!>

X

!>          X est un tableau de DOUBLE PRÉCISION, de dimension au moins
!>           ( 1 + ( n - 1 )*abs( INCX ) ).
!>           Avant l'appel, le tableau incrémenté X doit contenir le vecteur
!>           x de n éléments. À la sortie, X est écrasé par le vecteur
!>           transformé x.
!>

INCX

!>          INCX est INTEGER
!>           À l'entrée, INCX spécifie l'incrément pour les éléments de
!>           X. INCX ne doit pas être nul.
!>
