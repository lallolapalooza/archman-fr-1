sous-programme dtplqt (integer m, integer n, integer l, integer mb, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( ldb, * ) b, integer ldb, double precision, dimension( ldt, * ) t, integer ldt, double precision, dimension( * ) work, integer info)

DTPLQT

But :

!>
!> DTPLQT calcule une factorisation LQ bloquée d'une matrice réelle
!> C, qui est composée d'un bloc triangulaire A et d'un bloc pentagonal B,
!> en utilisant la représentation WY compacte pour Q.
!>

Paramètres

M 
!>          M est INTEGER
!>          Le nombre de lignes de la matrice B, et l'ordre de la
!>          matrice triangulaire A.
!>          M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice B.
!>          N >= 0.
!>

L

!>          L est INTEGER
!>          Le nombre de lignes de la partie trapézoïdale inférieure de B.
!>          MIN(M,N) >= L >= 0.  Voir Détails supplémentaires.
!>

MB

!>          MB est INTEGER
!>          La taille du bloc à utiliser dans la QR bloquée.  M >= MB >= 1.
!>

A

!>          A est un tableau DOUBLE PRECISION, de dimension (LDA,N)
!>          À l'entrée, la matrice triangulaire inférieure N-par-N A.
!>          À la sortie, les éléments sur et sous la diagonale du tableau
!>          contiennent la matrice triangulaire inférieure L.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

B

!>          B est un tableau DOUBLE PRECISION, de dimension (LDB,N)
!>          À l'entrée, la matrice pentagonale M-par-N B. Les N-L colonnes
!>          de gauche sont rectangulaires, et les L colonnes de droite sont
!>          trapézoïdales inférieures.
!>          À la sortie, B contient la matrice pentagonale V.  Voir Détails supplémentaires.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,M).
!>

T

!>          T est un tableau DOUBLE PRECISION, de dimension (LDT,N)
!>          Les réflecteurs de bloc triangulaires inférieurs stockés sous forme compacte
!>          en séquence de blocs triangulaires supérieurs.  Voir Détails supplémentaires.
!>

LDT

!>          LDT est INTEGER
!>          La dimension principale du tableau T.  LDT >= MB.
!>

WORK

!>          WORK est un tableau DOUBLE PRECISION, de dimension (MB*M)
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument était invalide
!>

Détails supplémentaires :

!>
!>  La matrice d'entrée C est une matrice M-par-(M+N)
!>
!>               C = [ A ] [ B ]
!>
!>
!>  où A est une matrice N-par-N triangulaire inférieure, et B est une matrice
!>  pentagonale M-par-N composée d'une matrice rectangulaire M-par-(N-L), B1,
!>  à gauche et d'une matrice trapézoïdale supérieure M-par-L, B2, à droite :
!>          [ B ] = [ B1 ] [ B2 ]
!>                   [ B1 ]  <- rectangulaire M-par-(N-L)
!>                   [ B2 ]  <- trapézoïdale supérieure M-par-L
!>
!>  La matrice trapézoïdale inférieure B2 est composée des L premières colonnes
!>  d'une matrice triangulaire inférieure N-par-N, où 0 <= L <= MIN(M,N). Si L=0,
!>  B est rectangulaire M-par-N ; si M=L=N, B est triangulaire inférieure.
!>
!>  La matrice W stocke les réflecteurs élémentaires H(i) dans la i-ème ligne
!>  au-dessus de la diagonale (de A) dans la matrice d'entrée C M-par-(M+N)
!!>            [ C ] = [ A ] [ B ]
!>                   [ A ]  <- N-par-N triangulaire inférieure
!>                   [ B ]  <- pentagonale M-par-N
!>
!>  de sorte que W puisse être représentée comme
!>            [ W ] = [ I ] [ V ]
!>                   [ I ]  <- identité, N-par-N
!>                   [ V ]  <- M-par-N, même forme que B.
!>
!>  Ainsi, toutes les informations nécessaires pour W sont contenues à la sortie dans B,
!>  que nous appelons V ci-dessus. Notez que V a la même forme que B ; c'est-à-dire,
!!>            [ V ] = [ V1 ] [ V2 ]
!>                   [ V1 ] <- rectangulaire M-par-(N-L)
!>                   [ V2 ] <- trapézoïdale inférieure M-par-L.
!>
!>  Les lignes de V représentent les vecteurs qui définissent les H(i).
!>
!>  Le nombre de blocs est B = ceiling(M/MB), où chaque
!>  bloc est de taille MB sauf le dernier bloc, qui est de taille
!>  IB = M - (M-1)*MB. Pour chacun des B blocs, un réflecteur de bloc
!>  triangulaire supérieur est calculé : T1, T2, ..., TB. Les T de taille MB-par-MB
!>  (et IB-par-IB pour le dernier bloc) sont stockés dans la matrice T MB-par-N comme
!>
!>               T = [T1 T2 ... TB].
!>
