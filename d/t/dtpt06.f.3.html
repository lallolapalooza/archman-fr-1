sous-programme dtpt06 (double precision rcond, double precision rcondc, caractere uplo, caractere diag, entier n, double precision, dimension( * ) ap, double precision, dimension( * ) work, double precision rat)

DTPT06

But:

!>
!> DTPT06 calcule un rapport de test comparant RCOND (le nombre de condition réciproque
!> d'une matrice triangulaire A) et RCONDC, l'estimation calculée par DTPCON.
!> Les informations sur la matrice triangulaire A sont utilisées si une estimation
!> est nulle et l'autre non nulle pour décider si le sous-dépassement dans l'estimation
!> est justifié.
!>

Paramètres

RCOND 
!>          RCOND est DOUBLE PRECISION
!>          L'estimation du nombre de condition réciproque obtenue en formant
!>          l'inverse explicite de la matrice A et en calculant
!>          RCOND = 1/( norme(A) * norme(inv(A)) ).
!>

RCONDC

!>          RCONDC est DOUBLE PRECISION
!>          L'estimation du nombre de condition réciproque calculée par
!>          DTPCON.
!>

UPLO

!>          UPLO est CARACTERE
!>          Spécifie si la matrice A est triangulaire supérieure ou inférieure.
!>          = 'U':  Triangulaire supérieure
!>          = 'L':  Triangulaire inférieure
!>

DIAG

!>          DIAG est CARACTERE
!>          Spécifie si la matrice A est triangulaire unitaire ou non.
!>          = 'N':  Triangulaire non unitaire
!>          = 'U':  Triangulaire unitaire
!>

N

!>          N est ENTIER
!>          L'ordre de la matrice A.  N >= 0.
!>

AP

!>          AP est un tableau DOUBLE PRECISION, de dimension (N*(N+1)/2)
!>          La matrice triangulaire A supérieure ou inférieure, empaquetée
!>          par colonne dans un tableau linéaire. La j-ième colonne de A est
!>          stockée dans le tableau AP comme suit :
!>          si UPLO = 'U', AP((j-1)*j/2 + i) = A(i,j) pour 1<=i<=j;
!>          si UPLO = 'L',
!>             AP((j-1)*(n-j) + j*(j+1)/2 + i-j) = A(i,j) pour j<=i<=n.
!>

WORK

!>          WORK est un tableau DOUBLE PRECISION, de dimension (N)
!>

RAT

!>          RAT est DOUBLE PRECISION
!>          Le rapport de test.  Si RCOND et RCONDC sont tous deux non nuls,
!>             RAT = MAX( RCOND, RCONDC )/MIN( RCOND, RCONDC ) - 1.
!>          Si RAT = 0, les deux estimations sont exactement les mêmes.
!>
