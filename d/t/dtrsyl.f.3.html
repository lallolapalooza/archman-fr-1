Documentation de la fonction/sous-routine

sous-routine dtrsyl (caractère trana, caractère tranb, entier isgn, entier m, entier n, double précision, dimension( lda, * ) a, entier lda, double précision, dimension( ldb, * ) b, entier ldb, double précision, dimension( ldc, * ) c, entier ldc, double précision scale, entier info)

DTRSYL

But:

!>
!> DTRSYL résout l'équation matricielle de Sylvester réelle :
!>
!>    op(A)*X + X*op(B) = scale*C ou
!>    op(A)*X - X*op(B) = scale*C,
!>
!> où op(A) = A ou A**T, et A et B sont toutes deux quasi-triangulaires supérieures.
!> A est M par M et B est N par N ; le membre de droite C et la solution X sont M par N ;
!> et scale est un facteur d'échelle de sortie, défini comme <= 1 pour éviter le débordement dans X.
!>
!> A et B doivent être en forme canonique de Schur (comme retourné par DHSEQR),
!> c'est-à-dire triangulaire supérieure par blocs avec des blocs diagonaux 1x1 et 2x2 ;
!> chaque bloc diagonal 2x2 a ses éléments diagonaux égaux et ses éléments hors diagonaux de signe opposé.
!>

Paramètres

TRANA 
!>          TRANA est CHARACTER*1
!>          Spécifie l'option op(A) :
!>          = 'N' : op(A) = A    (Pas de transposée)
!>          = 'T' : op(A) = A**T (Transposée)
!>          = 'C' : op(A) = A**H (Conjuguée transposée = Transposée)
!>

TRANB

!>          TRANB est CHARACTER*1
!>          Spécifie l'option op(B) :
!>          = 'N' : op(B) = B    (Pas de transposée)
!>          = 'T' : op(B) = B**T (Transposée)
!>          = 'C' : op(B) = B**H (Conjuguée transposée = Transposée)
!>

ISGN

!>          ISGN est INTEGER
!>          Spécifie le signe dans l'équation :
!>          = +1 : résout op(A)*X + X*op(B) = scale*C
!>          = -1 : résout op(A)*X - X*op(B) = scale*C
!>

M

!>          M est INTEGER
!>          L'ordre de la matrice A, et le nombre de lignes des matrices X et C. M >= 0.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice B, et le nombre de colonnes des matrices X et C. N >= 0.
!>

A

!>          A est un tableau DOUBLE PRECISION, de dimension (LDA,M)
!>          La matrice quasi-triangulaire supérieure A, en forme canonique de Schur.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,M).
!>

B

!>          B est un tableau DOUBLE PRECISION, de dimension (LDB,N)
!>          La matrice quasi-triangulaire supérieure B, en forme canonique de Schur.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B. LDB >= max(1,N).
!>

C

!>          C est un tableau DOUBLE PRECISION, de dimension (LDC,N)
!>          En entrée, la matrice C du membre de droite M par N.
!>          En sortie, C est écrasée par la matrice solution X.
!>

LDC

!>          LDC est INTEGER
!>          La dimension principale du tableau C. LDC >= max(1,M)
!>

SCALE

!>          SCALE est DOUBLE PRECISION
!>          Le facteur d'échelle, scale, défini comme <= 1 pour éviter le débordement dans X.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          = 1 : A et B ont des valeurs propres communes ou très proches ; des valeurs perturbées ont été utilisées pour résoudre l'équation (mais les matrices A et B ne sont pas modifiées).
!>
