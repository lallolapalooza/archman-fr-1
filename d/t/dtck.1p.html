NOM

dtck - Vérifie la cohérence des fichiers de données DNSSEC-Tools.

SYNTAXE

dtck [options] [fichier_de_configuration_dtck]

DESCRIPTION

dtck vérifie les fichiers de données DNSSEC-Tools pour déterminer si les entrées sont valides. dtck vérifie la validité des fichiers de configuration DNSSEC-Tools, des fichiers rollrec et des fichiers keyrec. Il n'effectue pas la vérification des fichiers lui-même, mais exécute des programmes de vérification spécifiques à chaque type de fichier de données.

Un fichier de configuration dtck est consulté pour déterminer les fichiers à vérifier. Ce fichier liste les fichiers de données DNSSEC-Tools et leurs types. Si un fichier de configuration dtck n'est pas fourni en ligne de commande, dtck ne vérifiera que le fichier de configuration DNSSEC-Tools. Ceci est équivalent à exécuter directement dtconfchk.

FICHIER DE CONFIGURATION DTCK

Un fichier de configuration dtck contient une liste des fichiers à vérifier par dtck. À l'exception des commentaires, chaque ligne a le format suivant :

mot-clé fichier répertoire

mot-clé est l'un des termes « config », « rollrec » ou « keyrec ». fichier est le chemin du fichier à vérifier. répertoire est le nom du répertoire qui contient le fichier et est facultatif.

Le fichier de configuration dtck contient les types d'enregistrements suivants :

config
Ces lignes définissent les fichiers de configuration DNSSEC-Tools qui seront vérifiés. Le programme dtconfchk sera utilisé pour vérifier ces fichiers.
rollrec
Ces lignes définissent les fichiers rollrec qui seront vérifiés. Le programme rollchk sera utilisé pour vérifier ces fichiers.
keyrec
Ces lignes définissent les fichiers keyrec qui seront vérifiés. Le programme krfcheck sera utilisé pour vérifier ces fichiers.
commentaires
Toutes les lignes commençant par un octothorpe (#) sont des lignes de commentaire et sont ignorées.

OPTIONS

dtck accepte deux types d'options. Les options du premier type sont traitées directement par dtck, contrôlant sa sortie et son traitement. Les options du second type sont transmises aux programmes de vérification de fichiers et ne sont pas traitées davantage par dtck.

Options gérées par dtck

-defcon
Cette option demande à dtck d'ajouter le fichier de configuration DNSSEC-Tools par défaut à la liste des fichiers de configuration à vérifier.
-list
Les noms des fichiers seront listés au fur et à mesure de leur vérification.
-pretty
Une sortie explicative est ajoutée à la sortie de dtck et des programmes de vérification de fichiers.
-help
Affiche un message d'utilisation.

Options non gérées par dtck

-count
Les programmes de vérification de fichiers afficheront un décompte final d'erreurs.
-quiet
Aucune sortie ne sera produite par le programme de vérification de fichiers.
-verbose
Une sortie détaillée sera produite par le programme de vérification de fichiers.
-Version
Affiche les informations de version pour dtck et le paquet DNSSEC-Tools.
