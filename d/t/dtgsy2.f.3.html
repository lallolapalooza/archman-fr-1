sous-programme dtgsy2 (character trans, integer ijob, integer m, integer n, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( ldb, * ) b, integer ldb, double precision, dimension( ldc, * ) c, integer ldc, double precision, dimension( ldd, * ) d, integer ldd, double precision, dimension( lde, * ) e, integer lde, double precision, dimension( ldf, * ) f, integer ldf, double precision scale, double precision rdsum, double precision rdscal, integer, dimension( * ) iwork, integer pq, integer info)

DTGSY2 résout l'équation de Sylvester généralisée (algorithme non bloqué).

Objectif :

!>
!> DTGSY2 résout l'équation de Sylvester généralisée :
!>
!>             A * R - L * B = scale * C                (1)
!>             D * R - L * E = scale * F,
!>
!> en utilisant les routines BLAS de niveaux 1 et 2. Où R et L sont des matrices M-par-N inconnues,
!> (A, D), (B, E) et (C, F) sont des paires de matrices données de taille M-par-M,
!> N-par-N et M-par-N, respectivement, avec des entrées réelles. (A, D) et (B, E)
!> doivent être sous forme canonique quasi-Schur généralisée, c'est-à-dire A, B sont supérieurs
!> quasi-triangulaires et D, E sont triangulaires supérieurs. La solution (R, L)
!> écrase (C, F). 0 <= SCALE <= 1 est un facteur d'échelle de sortie
!> choisi pour éviter le dépassement de capacité.
!>
!> En notation matricielle, résoudre l'équation (1) correspond à résoudre
!> Z*x = scale*b, où Z est défini comme
!>
!>        Z = [ kron(In, A)  -kron(B**T, Im) ]             (2)
!>            [ kron(In, D)  -kron(E**T, Im) ],
!>
!> Ik est la matrice identité de taille k et X**T est la transposée de X.
!> kron(X, Y) est le produit de Kronecker entre les matrices X et Y.
!> Lors de la résolution de (1), nous résolvons un certain nombre de tels systèmes
!> où Dim(In), Dim(In) = 1 ou 2.
!>
!> Si TRANS = 'T', résout le système transposé Z**T*y = scale*b pour y,
!> ce qui équivaut à résoudre pour R et L dans
!>
!>             A**T * R  + D**T * L   = scale * C           (3)
!>             R  * B**T + L  * E**T  = scale * -F
!>
!> Ce cas est utilisé pour calculer une estimation de Dif[(A, D), (B, E)] =
!> sigma_min(Z) en utilisant la communication inverse avec DLACON.
!>
!> DTGSY2 contribue également (IJOB >= 1) au calcul dans DTGSYL
!> d'une borne supérieure de la séparation entre deux paires de matrices. Alors
!> les entrées (A, D), (B, E) sont des sous-pénons de la paire de matrices dans
!> DTGSYL. Voir DTGSYL pour plus de détails.
!>

Paramètres

TRANS 
!>          TRANS est CHARACTER*1
!>          = 'N' : résout l'équation de Sylvester généralisée (1).
!>          = 'T' : résout le système 'transposé' (3).
!>

IJOB

!>          IJOB est INTEGER
!>          Spécifie le type de fonctionnalité à exécuter.
!>          = 0 : résout (1) uniquement.
!>          = 1 : une contribution de ce sous-système à une estimation de la norme de Frobenius
!>               de la séparation entre deux paires de matrices est calculée. (stratégie de 'look ahead' utilisée).
!>          = 2 : une contribution de ce sous-système à une estimation de la norme de Frobenius
!>               de la séparation entre deux paires de matrices est calculée. (DGECON sur les sous-systèmes est utilisé.)
!>          Non référencé si TRANS = 'T'.
!>

M

!>          M est INTEGER
!>          En entrée, M spécifie l'ordre de A et D, et la dimension en ligne
!>          de C, F, R et L.
!>

N

!>          N est INTEGER
!>          En entrée, N spécifie l'ordre de B et E, et la dimension en colonne
!>          de C, F, R et L.
!>

A

!>          A est un tableau DOUBLE PRECISION, dimension (LDA, M)
!>          En entrée, A contient une matrice quasi-triangulaire supérieure.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale de la matrice A. LDA >= max(1, M).
!>

B

!>          B est un tableau DOUBLE PRECISION, dimension (LDB, N)
!>          En entrée, B contient une matrice quasi-triangulaire supérieure.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale de la matrice B. LDB >= max(1, N).
!>

C

!>          C est un tableau DOUBLE PRECISION, dimension (LDC, N)
!>          En entrée, C contient le membre de droite de la première matrice
!>          de l'équation (1).
!>          En sortie, si IJOB = 0, C a été écrasé par la solution R.
!>

LDC

!>          LDC est INTEGER
!>          La dimension principale de la matrice C. LDC >= max(1, M).
!>

D

!>          D est un tableau DOUBLE PRECISION, dimension (LDD, M)
!>          En entrée, D contient une matrice triangulaire supérieure.
!>

LDD

!>          LDD est INTEGER
!>          La dimension principale de la matrice D. LDD >= max(1, M).
!>

E

!>          E est un tableau DOUBLE PRECISION, dimension (LDE, N)
!>          En entrée, E contient une matrice triangulaire supérieure.
!>

LDE

!>          LDE est INTEGER
!>          La dimension principale de la matrice E. LDE >= max(1, N).
!>

F

!>          F est un tableau DOUBLE PRECISION, dimension (LDF, N)
!>          En entrée, F contient le membre de droite de la seconde matrice
!>          de l'équation (1).
!>          En sortie, si IJOB = 0, F a été écrasé par la solution L.
!>

LDF

!>          LDF est INTEGER
!>          La dimension principale de la matrice F. LDF >= max(1, M).
!>

SCALE

!>          SCALE est DOUBLE PRECISION
!>          En sortie, 0 <= SCALE <= 1. Si 0 < SCALE < 1, les solutions
!>          R et L (C et F en entrée) contiendront les solutions d'un
!>          système légèrement perturbé mais les matrices d'entrée A, B, D et
!>          E n'ont pas été modifiées. Si SCALE = 0, R et L contiendront
!>          les solutions du système homogène avec C = F = 0. Normalement,
!>          SCALE = 1.
!>

RDSUM

!>          RDSUM est DOUBLE PRECISION
!>          En entrée, la somme des carrés des contributions calculées à
!>          l'estimation de Dif en cours de calcul par DTGSYL, où le
!>          facteur d'échelle RDSCAL (voir ci-dessous) a été extrait.
!>          En sortie, la somme des carrés correspondante mise à jour avec les
!>          contributions du sous-système actuel.
!>          Si TRANS = 'T', RDSUM n'est pas modifié.
!>          NOTE : RDSUM n'a de sens que lorsque DTGSY2 est appelé par DTGSYL.
!>

RDSCAL

!>          RDSCAL est DOUBLE PRECISION
!>          En entrée, facteur d'échelle utilisé pour éviter le dépassement de capacité dans RDSUM.
!>          En sortie, RDSCAL est mis à jour par rapport aux contributions actuelles
!>          dans RDSUM.
!>          Si TRANS = 'T', RDSCAL n'est pas modifié.
!>          NOTE : RDSCAL n'a de sens que lorsque DTGSY2 est appelé par
!>                DTGSYL.
!>

IWORK

!>          IWORK est un tableau INTEGER, dimension (M+N+2)
!>

PQ

!>          PQ est INTEGER
!>          En sortie, le nombre de sous-systèmes (de taille 2x2, 4x4 et
!>          8x8) résolus par cette routine.

SYNOPSIS

SUBROUTINE DTGSY2( TRANS, ILASCL, ILBSCL, N, A, LDA, B, LDB, C, LDC, D, LDD, E, 
                 LDE, SCALE, SWAP, IINFO )

INTEGER N
REAL*8 A( LDA, * ), B( LDB, * ), C( LDC, * ), D( LDD, * ), E( LDE, * )
REAL*8 SCALE
INTEGER SWAP, IINFO

Function/Subroutine Documentation

Description:

DTGSY2 computes a solution to the generalized Sylvester equation

    A*Q*E - B*Q*D = C

or

    A'*Q*E - B'*Q*D = C

where A, B, C, D, E are given matrices, Q is the solution matrix to be computed, and A', B' are the transposes of A, B respectively. (A, D) and (B, E) must be in real Schur form, i.e., A, B, D, E are upper quasi-triangular matrices. D and E are also upper triangular matrices.

Arguments:

TRANS

CHARACTER*1.
           On entry, TRANS specifies the form of the Sylvester equation to
           be solved.
           = 'N': Solve A*Q*E - B*Q*D = C             (No transpose)
           = 'T': Solve A'*Q*E - B'*Q*D = C           (Transpose)

ILASCL

INTEGER.
           On entry, ILASCL specifies whether or not to apply the scaling
           of A and B based on the values in the array SCL
           = 0: Do not scale A and B.
           = 1: Scale A and B.

ILBSCL

INTEGER.
           On entry, ILBSCL specifies whether or not to apply the scaling
           of D and E based on the values in the array SCL
           = 0: Do not scale D and E.
           = 1: Scale D and E.

N

INTEGER.
           On entry, N is the order of the matrices A, B, C, D, E. N >= 0.

A

REAL*8 array, dimension ( LDA, N ).
           On entry, the upper quasi-triangular matrix A.

LDA

INTEGER.
           On entry, LDA is the leading dimension of the array A. LDA >= max(1, N).

B

REAL*8 array, dimension ( LDB, N ).
           On entry, the upper quasi-triangular matrix B.

LDB

INTEGER.
           On entry, LDB is the leading dimension of the array B. LDB >= max(1, N).

C

REAL*8 array, dimension ( LDC, N ).
           On entry, the right hand side matrix C.

LDC

INTEGER.
           On entry, LDC is the leading dimension of the array C. LDC >= max(1, N).

D

REAL*8 array, dimension ( LDD, N ).
           On entry, the upper triangular matrix D.

LDD

INTEGER.
           On entry, LDD is the leading dimension of the array D. LDD >= max(1, N).

E

REAL*8 array, dimension ( LDE, N ).
           On entry, the upper triangular matrix E.

LDE

INTEGER.
           On entry, LDE is the leading dimension of the array E. LDE >= max(1, N).

SCALE

REAL*8.
           On exit, SCALE is the scaling factor.

SWAP

INTEGER.
           On exit, SWAP is the number of row interchanges applied to A and B.

INFO

INTEGER.
           On exit, if INFO is set to
           =0: Successful exit
           <0: If INFO = -i, the i-th argument had an illegal value.
           >0: The matrix pairs (A, D) and (B, E) have common or very
               close eigenvalues.
