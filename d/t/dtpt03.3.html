DTPT03

But:

!>
!> DTPT03 calcule le résidu pour la solution d'un système triangulaire mis à
!> l'échelle A*x = s*b  ou  A'*x = s*b  lorsque la matrice triangulaire
!> A est stockée au format compacté. Ici A' est la transposée de A,
!> s est un scalaire, et x et b sont des matrices N par NRHS. Le ratio de test est
!> le maximum sur le nombre de seconds membres de
!>    norm(s*b - op(A)*x) / ( norm(op(A)) * norm(x) * EPS ),
!> où op(A) désigne A ou A' et EPS est le epsilon machine.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si la matrice A est triangulaire supérieure ou inférieure.
!>          = 'U':  Triangulaire supérieure
!>          = 'L':  Triangulaire inférieure
!>

TRANS

!>          TRANS est CHARACTER*1
!>          Spécifie l'opération appliquée à A.
!>          = 'N':  A *x = s*b  (Pas de transposée)
!>          = 'T':  A'*x = s*b  (Transposée)
!>          = 'C':  A'*x = s*b  (Conjuguée transposée = Transposée)
!>

DIAG

!>          DIAG est CHARACTER*1
!>          Spécifie si la matrice A est unitaire ou non.
!>          = 'N':  Triangulaire non unitaire
!>          = 'U':  Triangulaire unitaire
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de seconds membres, c'est-à-dire le nombre de colonnes
!>          des matrices X et B.  NRHS >= 0.
!>

AP

!>          AP est tableau DOUBLE PRÉCISION, dimension (N*(N+1)/2)
!>          La matrice triangulaire supérieure ou inférieure A, compactée par
!>          colonnes dans un tableau linéaire. La j-ième colonne de A est
!>          stockée dans le tableau AP comme suit :
!>          si UPLO = 'U', AP((j-1)*j/2 + i) = A(i,j) pour 1<=i<=j;
!>          si UPLO = 'L',
!>             AP((j-1)*(n-j) + j*(j+1)/2 + i-j) = A(i,j) pour j<=i<=n.
!>

SCALE

!>          SCALE est DOUBLE PRÉCISION
!>          Le facteur d'échelle s utilisé dans la résolution du système
!>          triangulaire.
!>

CNORM

!>          CNORM est tableau DOUBLE PRÉCISION, dimension (N)
!>          Les normes 1 des colonnes de A, sans compter la diagonale.
!>

TSCAL

!>          TSCAL est DOUBLE PRÉCISION
!>          Le facteur d'échelle utilisé dans le calcul des normes 1 dans CNORM.
!>          CNORM contient en fait les normes des colonnes de TSCAL*A.
!>

X

!>          X est tableau DOUBLE PRÉCISION, dimension (LDX,NRHS)
!>          Les vecteurs solution calculés pour le système d'équations
!>          linéaires.
!>

LDX

!>          LDX est INTEGER
!>          La dimension principale du tableau X.  LDX >= max(1,N).
!>

B

!>          B est tableau DOUBLE PRÉCISION, dimension (LDB,NRHS)
!>          Les vecteurs du second membre pour le système d'équations
!>          linéaires.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

WORK

!>          WORK est tableau DOUBLE PRÉCISION, dimension (N)
!>

RESID

!>          RESID est DOUBLE PRÉCISION
!>          Le maximum sur le nombre de seconds membres de
!>          norm(op(A)*x - s*b) / ( norm(op(A)) * norm(x) * EPS ).
!>
