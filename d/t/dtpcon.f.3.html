sous-programme dtpcon (caractère norm, caractère uplo, caractère diag, entier n, double précision, dimension( * ) ap, double précision rcond, double précision, dimension( * ) work, entier, dimension( * ) iwork, entier info)

DTPCON

Objectif :

!>
!> DTPCON estime la réciproque du nombre de condition d'une matrice triangulaire
!> A compressée, dans la norme 1 ou la norme infinie.
!>
!> La norme de A est calculée et une estimation de
!> norm(inv(A)) est obtenue, puis la réciproque du nombre de condition est
!> calculée comme suit :
!>    RCOND = 1 / ( norm(A) * norm(inv(A)) ).
!>

Paramètres

NORM 
!>          NORM est CHARACTER*1
!>          Spécifie si le nombre de condition en norme 1 ou en norme
!>          infinie est requis :
!>          = '1' ou 'O' :  Norme 1 ;
!>          = 'I'        :  Norme infinie.
!>

UPLO

!>          UPLO est CHARACTER*1
!>          = 'U' : A est triangulaire supérieure ;
!>          = 'L' : A est triangulaire inférieure.
!>

DIAG

!>          DIAG est CHARACTER*1
!>          = 'N' : A est triangulaire non unitaire ;
!>          = 'U' : A est triangulaire unitaire.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

AP

!>          AP est un tableau DOUBLE PRECISION, de dimension (N*(N+1)/2)
!>          La matrice triangulaire supérieure ou inférieure A, compressée
!>          par colonne dans un tableau linéaire. La j-ième colonne de A
!>          est stockée dans le tableau AP comme suit :
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) pour 1<=i<=j ;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) pour j<=i<=n.
!>          Si DIAG = 'U', les éléments diagonaux de A ne sont pas référencés
!>          et sont supposés être 1.
!>

RCOND

!>          RCOND est DOUBLE PRECISION
!>          La réciproque du nombre de condition de la matrice A,
!>          calculée comme RCOND = 1/(norm(A) * norm(inv(A))).
!>

WORK

!>          WORK est un tableau DOUBLE PRECISION, de dimension (3*N)
!>

IWORK

!>          IWORK est un tableau INTEGER, de dimension (N)
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>
