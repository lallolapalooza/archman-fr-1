DTGSJ

A

But

: 
!>
!> DTGSJA calcule la décomposition en valeurs singulières généralisée (GSVD)
!> de deux matrices réelles triangulaires supérieures (ou trapézoïdales) A et B.
!>
!> À l'entrée, on suppose que les matrices A et B ont les formes suivantes,
!> qui peuvent être obtenues par la sous-routine de prétraitement DGGSVP
!> à partir d'une matrice générale A de dimensions M par N et d'une matrice B de dimensions P par N :
!>
!>              N-K-L  K    L
!>    A =    K ( 0    A12  A13 ) si M-K-L >= 0 ;
!>           L ( 0     0   A23 )
!>       M-K-L ( 0     0    0  )
!>
!>            N-K-L  K    L
!>    A =  K ( 0    A12  A13 ) si M-K-L < 0 ;
!>       M-K ( 0     0   A23 )
!>
!>            N-K-L  K    L
!>    B =  L ( 0     0   B13 )
!>       P-L ( 0     0    0  )
!>
!> où la matrice A12 de dimensions K par K et la matrice B13 de dimensions L par L sont non singulières
!> et triangulaires supérieures ; A23 est triangulaire supérieure de dimensions L par L si M-K-L >= 0,
!> sinon A23 est trapézoïdale supérieure de dimensions (M-K) par L.
!>
!> À la sortie,
!>
!>        U**T *A*Q = D1*( 0 R ),    V**T *B*Q = D2*( 0 R ),
!>
!> où U, V et Q sont des matrices orthogonales.
!> R est une matrice triangulaire supérieure non singulière, et D1 et D2 sont
!> des matrices « diagonales », qui ont les structures suivantes :
!>
!> Si M-K-L >= 0,
!>
!>                     K  L
!>        D1 =     K ( I  0 )
!>                 L ( 0  C )
!>             M-K-L ( 0  0 )
!>
!>                   K  L
!>        D2 = L   ( 0  S )
!>             P-L ( 0  0 )
!>
!>                N-K-L  K    L
!>   ( 0 R ) = K (  0   R11  R12 ) K
!>             L (  0    0   R22 ) L
!>
!> où
!>
!>   C = diag( ALPHA(K+1), ... , ALPHA(K+L) ),
!>   S = diag( BETA(K+1),  ... , BETA(K+L) ),
!>   C**2 + S**2 = I.
!>
!>   R est stocké dans A(1:K+L,N-K-L+1:N) à la sortie.
!>
!> Si M-K-L < 0,
!>
!>                K M-K K+L-M
!>     D1 =   K ( I  0    0   )
!>          M-K ( 0  C    0   )
!>
!>                  K M-K K+L-M
!>     D2 =   M-K ( 0  S    0   )
!>          K+L-M ( 0  0    I   )
!>            P-L ( 0  0    0   )
!>
!>                N-K-L  K   M-K  K+L-M
!> ( 0 R ) =    K ( 0    R11  R12  R13  )
!>           M-K ( 0     0   R22  R23  )
!>         K+L-M ( 0     0    0   R33  )
!>
!> où
!> C = diag( ALPHA(K+1), ... , ALPHA(M) ),
!> S = diag( BETA(K+1),  ... , BETA(M) ),
!> C**2 + S**2 = I.
!>
!> R = ( R11 R12 R13 ) est stocké dans A(1:M, N-K-L+1:N) et R33 est stocké
!>     (  0  R22 R23 )
!> dans B(M-K+1:L,N+M-K-L+1:N) à la sortie.
!>
!> Le calcul des matrices de transformation orthogonales U, V ou Q
!> est facultatif. Ces matrices peuvent être formées explicitement, ou elles
!> peuvent être multipliées à droite par les matrices d'entrée U1, V1 ou Q1.
!
>

Paramètre

!>          = 'U' :  U doit contenir une matrice orthogonale U1 à l'entrée, et

!>          = 'I' :  U est initialisé à la matrice unité, et la

!>          = 'I' :  V est initialisé à la matrice unité, et la
!>                  matrice orthogonale V est renvoyée ;
!>          = 'N' :  V n'est pas calculé.

!>          JOBQ est CHARACTER*1
!>          = 'Q' :  Q doit contenir une matrice orthogonale Q1 à l'entrée, et

!>          = 'I' :  Q est initialisé à la matrice unité, et la
!>                  matrice orthogonale Q est renvoyée ;

!
>

M 
!>          M est INTEGER

>

!>          P est INTEGER
!>          Le nombre de lignes de la matrice B.  P >= 0.
!
>

!>          N est INTEGER

>

!>          Voir Détails supplémentaires.
!

!>          TOLA et TOLB sont les critères de convergence pour la procédure

ALPH

A

!
>

A 
!>          BETA est un tableau DOUBLE PRECISION, dimension (N)
!>
!>          À la sortie, ALPHA et BETA contiennent les paires de valeurs
!>          singulières généralisées de A et B ;
!>            ALPHA(1:K) = 1,
!>            BETA(1:K)  = 0,
!>          et si M-K-L >= 0,
!>            ALPHA(K+1:K+L) = diag(C),
!>            BETA(K+1:K+L)  = diag(S),
!>          ou si M-K-L < 0,
!>            ALPHA(K+1:M)= C, ALPHA(M+1:K+L)= 0
!>            BETA(K+1:M) = S, BETA(M+1:K+L) = 1.
!>          De plus, si K+L < N,
!>            ALPHA(K+L+1:N) = 0 et
!>            BETA(K+L+1:N)  = 0.
!
>

U 
!>          U est un tableau DOUBLE PRECISION, dimension (LDU,M)
!>          À l'entrée, si JOBU = 'U', U doitst contient une matrice U1 (généralement
!>          la matrice orthogonale retournée par DGGSVP).
!>          À la sortie,
!>          si JOBU = 'I', U contient la matrice orthogonale U ;
!>          si JOBU = 'U', U contient le produit U1*U.
!>          Si JOBU = 'N', U n'est pas référencé.
!
>

U

!>          À la sortie,
!>          si JOBV = 'I', V contient la matrice orthogonale V ;
!>          si JOBV = 'V', V contient le produit V1*V.

Détails supplémentaires

!>
!>  DTGSJA utilise essentiellement une variante de l'algorithme de Kogbetliantz pour réduire
!>  la matrice triangulaire (ou trapézoïdale) A23 de dimension min(L,M-K)-par-L et la matrice B13 de dimension L-par-L
!>  à la forme :
!>
!>           U1**T *A13*Q1 = C1*R1 ; V1**T *B13*Q1 = S1*R1,
!>
!>  où U1, V1 et Q1 sont des matrices orthogonales, et Z**T est la transposée
!>  de Z.  C1 et S1 sont des matrices diagonales satisfaisant
!>
!>                C1**2 + S1**2 = I,
!>
!>  et R1 est une matrice triangulaire supérieure non singulière de dimension L-par-L.

!
>
