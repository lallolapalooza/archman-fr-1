sous-routine dtzrqf (integer m, integer n, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( * ) tau, integer info)

DTZRQF

Objectif :

!>
!> Cette routine est obsolète et a été remplacée par la routine DTZRZF.
!>
!> DTZRQF réduit la matrice réelle supérieure trapézoïdale M par N ( M<=N ) A
!> en forme triangulaire supérieure au moyen de transformations orthogonales.
!>
!> La matrice trapézoïdale supérieure A est factorisée comme suit :
!>
!>    A = ( R  0 ) * Z,
!>
!> où Z est une matrice orthogonale N par N et R est une matrice triangulaire
!> supérieure M par M.
!>

Paramètres :

M 
!>          M est un entier (INTEGER)
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

N

!>          N est un entier (INTEGER)
!>          Le nombre de colonnes de la matrice A.  N >= M.
!>

A

!>          A est un tableau de précision double (DOUBLE PRECISION), dimension (LDA,N)
!>          À l'entrée, la partie supérieure trapézoïdale M par N de
!>          la matrice A doit contenir la matrice à factoriser.
!>          À la sortie, la partie triangulaire supérieure M par M de A
!>          contient la matrice triangulaire supérieure R, et les éléments M+1 à
!>          N des premières lignes M de A, avec le tableau TAU, représentent la
!>          matrice orthogonale Z sous forme de produit de M réflecteurs élémentaires.
!>

LDA

!>          LDA est un entier (INTEGER)
!>          La dimension principale du tableau A.  LDA >= max(1,M).
!>

TAU

!>          TAU est un tableau de précision double (DOUBLE PRECISION), dimension (M)
!>          Les facteurs scalaires des réflecteurs élémentaires.
!>

INFO

!>          INFO est un entier (INTEGER)
!>          = 0 :  sortie réussie
!>          < 0 :  si INFO = -i, le i-ème argument avait une valeur illégale
!>

Détails supplémentaires :

!>
!>  La factorisation est obtenue par la méthode de Householder. La k-ième
!>  matrice de transformation, Z( k ), qui est utilisée pour introduire des zéros dans
!>  la ( m - k + 1 )-ième ligne de A, est donnée sous la forme
!>
!>     Z( k ) = ( I     0   ),
!>              ( 0  T( k ) )
!>
!>  où
!>
!>     T( k ) = I - tau*u( k )*u( k )**T,   u( k ) = (   1    ),
!>                                                   (   0    )
!>                                                   ( z( k ) )
!>
!>  tau est un scalaire et z( k ) est un vecteur de ( n - m ) éléments.
!>  tau et z( k ) sont choisis pour annuler les éléments de la k-ième ligne
!>  de X.
!>
!>  Le scalaire tau est renvoyé dans le k-ième élément de TAU et le vecteur
!>  u( k ) dans la k-ième ligne de A, de telle sorte que les éléments de z( k )
!>  sont dans  a( k, m + 1 ), ..., a( k, n ). Les éléments de R sont renvoyés dans
!>  la partie triangulaire supérieure de A.
!>
!>  Z est donné par
!>
!>     Z =  Z( 1 ) * Z( 2 ) * ... * Z( m ).
!>
