Documentation de la fonction/sous-routine

subroutine dtgevc (character side, character howmny, logical, dimension( * ) select, integer n, double precision, dimension( lds, * ) s, integer lds, double precision, dimension( ldp, * ) p, integer ldp, double precision, dimension( ldvl, * ) vl, integer ldvl, double precision, dimension( ldvr, * ) vr, integer ldvr, integer mm, integer m, double precision, dimension( * ) work, integer info)

DTGEVC

But :

!>
!> DTGEVC calcule certaines ou toutes les vecteurs propres droits et/ou
!> gauches d'une paire de matrices réelles (S,P), où S est une matrice
!> quasi-triangulaire et P est triangulaire supérieure.  Les paires de
!> matrices de ce type sont produites par la factorisation de Schur
!> généralisée d'une paire de matrices (A,B) :
!>
!>    A = Q*S*Z**T,  B = Q*P*Z**T
!>
!> telle que calculée par DGGHRD + DHGEQZ.
!>
!> Le vecteur propre droit x et le vecteur propre gauche y de (S,P)
!> correspondant à une valeur propre w sont définis par :
!>
!>    S*x = w*P*x,  (y**H)*S = w*(y**H)*P,
!>
!> où y**H désigne la transposée conjuguée de y.
!> Les valeurs propres ne sont pas des entrées de cette routine, mais sont
!> calculées directement à partir des blocs diagonaux de S et P.
!>
!> Cette routine retourne les matrices X et/ou Y des vecteurs propres
!> droits et gauches de (S,P), ou les produits Z*X et/ou Q*Y,
!> où Z et Q sont des matrices d'entrée.
!> Si Q et Z sont les facteurs orthogonaux de la factorisation de Schur
!> généralisée d'une paire de matrices (A,B), alors Z*X et Q*Y
!> sont les matrices des vecteurs propres droits et gauches de (A,B).
!>
!>

Paramètres

SIDE 
!>          SIDE est CHARACTER*1
!>          = 'R' : calculer uniquement les vecteurs propres droits ;
!>          = 'L' : calculer uniquement les vecteurs propres gauches ;
!>          = 'B' : calculer à la fois les vecteurs propres droits et gauches.
!>

HOWMNY

!>          HOWMNY est CHARACTER*1
!>          = 'A' : calculer tous les vecteurs propres droits et/ou gauches ;
!>          = 'B' : calculer tous les vecteurs propres droits et/ou gauches,
!>                 rétrotransformés par les matrices dans VR et/ou VL ;
!>          = 'S' : calculer les vecteurs propres droits et/ou gauches
!>                 sélectionnés, spécifiés par le tableau logique SELECT.
!>

SELECT

!>          SELECT est un tableau LOGICAL, dimension (N)
!>          Si HOWMNY='S', SELECT spécifie les vecteurs propres à
!>          calculer.  Si w(j) est une valeur propre réelle, le vecteur
!>          propre réel correspondant est calculé si SELECT(j) est .TRUE..
!>          Si w(j) et w(j+1) sont les parties réelle et imaginaire d'une
!>          valeur propre complexe, le vecteur propre complexe
!>          correspondant est calculé si SELECT(j) ou SELECT(j+1) est
!>          .TRUE., et à la sortie SELECT(j) est défini à .TRUE. et
!>          SELECT(j+1) est défini à .FALSE..
!>          Non référencé si HOWMNY = 'A' ou 'B'.
!>

N

!>          N est INTEGER
!>          L'ordre des matrices S et P.  N >= 0.
!>

S

!>          S est un tableau DOUBLE PRECISION, dimension (LDS,N)
!>          La matrice quasi-triangulaire supérieure S issue d'une
!>          factorisation de Schur généralisée, telle que calculée par
!>          DHGEQZ.
!>

LDS

!>          LDS est INTEGER
!>          La dimension principale du tableau S.  LDS >= max(1,N).
!>

P

!>          P est un tableau DOUBLE PRECISION, dimension (LDP,N)
!>          La matrice triangulaire supérieure P issue d'une factorisation
!>          de Schur généralisée, telle que calculée par DHGEQZ.
!>          Les blocs diagonaux 2-par-2 de P correspondant aux blocs
!>          2-par-2 de S doivent être sous forme diagonale positive.
!>

LDP

!>          LDP est INTEGER
!>          La dimension principale du tableau P.  LDP >= max(1,N).
!>

VL

!>          VL est un tableau DOUBLE PRECISION, dimension (LDVL,MM)
!>          À l'entrée, si SIDE = 'L' ou 'B' et HOWMNY = 'B', VL doit
!>          contenir une matrice N-par-N Q (généralement la matrice
!>          orthogonale Q des vecteurs de Schur gauches retournée par
!>          DHGEQZ).
!>          À la sortie, si SIDE = 'L' ou 'B', VL contient :
!>          si HOWMNY = 'A', la matrice Y des vecteurs propres gauches de (S,P) ;
!>          si HOWMNY = 'B', la matrice Q*Y ;
!>          si HOWMNY = 'S', les vecteurs propres gauches de (S,P) spécifiés
!>                      par SELECT, stockés consécutivement dans les
!>                      colonnes de VL, dans le même ordre que leurs
!>                      valeurs propres.
!>
!>          Un vecteur propre complexe correspondant à une valeur propre
!>          complexe est stocké dans deux colonnes consécutives, la
!>          première contenant la partie réelle et la seconde la partie
!>          imaginaire.
!>
!>          Non référencé si SIDE = 'R'.
!>

LDVL

!>          LDVL est INTEGER
!>          La dimension principale du tableau VL.  LDVL >= 1, et si
!>          SIDE = 'L' ou 'B', LDVL >= N.
!>

VR

!>          VR est un tableau DOUBLE PRECISION, dimension (LDVR,MM)
!>          À l'entrée, si SIDE = 'R' ou 'B' et HOWMNY = 'B', VR doit
!>          contenir une matrice N-par-N Z (généralement la matrice
!>          orthogonale Z des vecteurs de Schur droits retournée par
!>          DHGEQZ).
!>
!>          À la sortie, si SIDE = 'R' ou 'B', VR contient :
!>          si HOWMNY = 'A', la matrice X des vecteurs propres droits de (S,P) ;
!>          si HOWMNY = 'B' ou 'b', la matrice Z*X ;
!>          si HOWMNY = 'S' ou 's', les vecteurs propres droits de (S,P)
!>                      spécifiés par SELECT, stockés consécutivement
!>                      dans les colonnes de VR, dans le même ordre que
!>                      leurs valeurs propres.
!>
!>          Un vecteur propre complexe correspondant à une valeur propre
!>          complexe est stocké dans deux colonnes consécutives, la
!>          première contenant la partie réelle et la seconde la partie
!>          imaginaire.
!>
!>          Non référencé si SIDE = 'L'.
!>

LDVR

!>          LDVR est INTEGER
!>          La dimension principale du tableau VR.  LDVR >= 1, et si
!>          SIDE = 'R' ou 'B', LDVR >= N.
!>

MM

!>          MM est INTEGER
!>          Le nombre de colonnes dans les tableaux VL et/ou VR. MM >= M.
!>

M

!>          M est INTEGER
!>          Le nombre de colonnes dans les tableaux VL et/ou VR
!>          effectivement utilisées pour stocker les vecteurs propres.
!>          Si HOWMNY = 'A' ou 'B', M est défini à N.  Chaque vecteur
!>          propre réel sélectionné occupe une colonne et chaque vecteur
!>          propre complexe sélectionné occupe deux colonnes.
!>

WORK

!>          WORK est un tableau DOUBLE PRECISION, dimension (6*N)
!>

INFO

!>          INFO est INTEGER
!>          = 0 :  sortie réussie.
!>          < 0 :  si INFO = -i, le i-ème argument avait une valeur illégale.
!>          > 0 :  le bloc 2-par-2 (INFO:INFO+1) n'a pas de valeur propre
!>                complexe.
!>
