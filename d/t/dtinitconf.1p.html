Les fichiers existants, qu'ils soient celui par défaut ou celui spécifié par l'utilisateur, ne seront pas écrasés sauf indication contraire de l'utilisateur. Chaque champ

Tout d'abord, les répertoires de la variable d'environnement path sont vérifiés ; les noms de tout répertoire contenant les programmes BIND sont enregistrés. Ensuite, plusieurs emplacements courants pour les programmes BIND sont vérifiés ; de même, les noms des répertoires contenant les programmes BIND sont enregistrés. Après avoir collecté ces répertoires, la liste est présentée à l'utilisateur, qui peut choisir d'utiliser l'ensemble désiré. Si aucun répertoire contenant les programmes BIND n'est

trouvé,

l'utilisateur est interrogé sur l'emplacement approprié. Si le répertoire parent du fichier de configuration n'existe pas, une tentative est faite pour créer le répertoire. La propriété du nouveau répertoire sera définie à root pour le propriétaire et dnssec pour le groupe, en supposant que le groupe dnssec existe. Les vérificati

La longueur longue signifie qu'une description de phase sera incluse avec certains messages de journalisation. Par exemple, la forme longue d'un message concernant la phase 3 du roulement de ZSK ressemblera à ceci : "ZSK phase 3 (Waiting for old zone data to expire from caches)
