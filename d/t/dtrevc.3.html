DTREVC

But :

!>
!> DTREVC calcule certains ou tous les vecteurs propres droits et/ou gauches
!> d'une matrice quasi-triangulaire réelle T.
!> Les matrices de ce type sont produites par la factorisation de Schur d'une
!> matrice générale réelle : A = Q*T*Q**T, comme calculé par DHSEQR.
!>
!> Les vecteurs propres droits x et gauches y de T correspondant à une valeur propre w
!> sont définis par :
!>
!>    T*x = w*x,     (y**H)*T = w*(y**H)
!>
!> où y**H dénote la transposée conjuguée de y.
!> Les valeurs propres ne sont pas entrées dans cette routine, mais sont lues directement
!> à partir des blocs diagonaux de T.
!>
!> Cette routine renvoie les matrices X et/ou Y des vecteurs propres droits et/ou gauches
!> de T, ou les produits Q*X et/ou Q*Y, où Q est une matrice d'entrée. Si Q est le
!> facteur orthogonal qui réduit une matrice A à la forme de Schur T, alors Q*X et Q*Y
!> sont les matrices des vecteurs propres droits et gauches de A.
!>

Paramètres

SIDE 
!>          SIDE est CARACTÈRE*1
!>          = 'R' : calculer uniquement les vecteurs propres droits ;
!>          = 'L' : calculer uniquement les vecteurs propres gauches ;
!>          = 'B' : calculer les deux vecteurs propres droits et gauches.
!>

HOWMNY

!>          HOWMNY est CARACTÈRE*1
!>          = 'A' : calculer tous les vecteurs propres droits et/ou gauches ;
!>          = 'B' : calculer tous les vecteurs propres droits et/ou gauches,
!>                  rétrotransformés par les matrices dans VR et/ou VL ;
!>          = 'S' : calculer des vecteurs propres droits et/ou gauches sélectionnés,
!>                  comme indiqué par le tableau logique SELECT.
!>

SELECT

!>          SELECT est un tableau LOGIQUE, de dimension (N)
!>          Si HOWMNY = 'S', SELECT spécifie les vecteurs propres à calculer.
!>          Si w(j) est une valeur propre réelle, le vecteur propre réel correspondant
!>          est calculé si SELECT(j) est .VRAI..
!>          Si w(j) et w(j+1) sont les parties réelles et imaginaires d'une
!>          valeur propre complexe, le vecteur propre complexe correspondant est
!>          calculé si SELECT(j) ou SELECT(j+1) est .VRAI., et
!>          en sortie SELECT(j) est mis à .VRAI. et SELECT(j+1) est mis à
!>          .FAUX..
!>          Non référencé si HOWMNY = 'A' ou 'B'.
!>

N

!>          N est ENTIER
!>          L'ordre de la matrice T. N >= 0.
!>

T

!>          T est un tableau DOUBLE PRÉCISION, de dimension (LDT,N)
!>          La matrice quasi-triangulaire supérieure T en forme canonique de Schur.
!>

LDT

!>          LDT est ENTIER
!>          La dimension principale du tableau T. LDT >= max(1,N).
!>

VL

!>          VL est un tableau DOUBLE PRÉCISION, de dimension (LDVL,MM)
!>          À l'entrée, si SIDE = 'L' ou 'B' et HOWMNY = 'B', VL doit
!>          contenir une matrice Q de taille N x N (généralement la matrice orthogonale Q
!>          des vecteurs de Schur retournée par DHSEQR).
!>          À la sortie, si SIDE = 'L' ou 'B', VL contient :
!>          si HOWMNY = 'A', la matrice Y des vecteurs propres gauches de T ;
!>          si HOWMNY = 'B', la matrice Q*Y ;
!>          si HOWMNY = 'S', les vecteurs propres gauches de T spécifiés par
!>                           SELECT, stockés consécutivement dans les colonnes
!>                           de VL, dans le même ordre que leurs
!>                           valeurs propres.
!>          Un vecteur propre complexe correspondant à une valeur propre complexe
!>          est stocké dans deux colonnes consécutives, la première contenant la
!>          partie réelle et la seconde la partie imaginaire.
!>          Non référencé si SIDE = 'R'.
!>

LDVL

!>          LDVL est ENTIER
!>          La dimension principale du tableau VL. LDVL >= 1, et si
!>          SIDE = 'L' ou 'B', LDVL >= N.
!>

VR

!>          VR est un tableau DOUBLE PRÉCISION, de dimension (LDVR,MM)
!>          À l'entrée, si SIDE = 'R' ou 'B' et HOWMNY = 'B', VR doit
!>          contenir une matrice Q de taille N x N (généralement la matrice orthogonale Q
!>          des vecteurs de Schur retournée par DHSEQR).
!>          À la sortie, si SIDE = 'R' ou 'B', VR contient :
!>          si HOWMNY = 'A', la matrice X des vecteurs propres droits de T ;
!>          si HOWMNY = 'B', la matrice Q*X ;
!>          si HOWMNY = 'S', les vecteurs propres droits de T spécifiés par
!>                           SELECT, stockés consécutivement dans les colonnes
!>                           de VR, dans le même ordre que leurs
!>                           valeurs propres.
!>          Un vecteur propre complexe correspondant à une valeur propre complexe
!>          est stocké dans deux colonnes consécutives, la première contenant la
!>          partie réelle et la seconde la partie imaginaire.
!>          Non référencé si SIDE = 'L'.
!>

LDVR

!>          LDVR est ENTIER
!>          La dimension principale du tableau VR. LDVR >= 1, et si
!>          SIDE = 'R' ou 'B', LDVR >= N.
!>

MM

!>          MM est ENTIER
!>          Le nombre de colonnes dans les tableaux VL et/ou VR. MM >= M.
!>

M

!>          M est ENTIER
!>          Le nombre de colonnes dans les tableaux VL et/ou VR réellement
!>          utilisées pour stocker les vecteurs propres.
!>          Si HOWMNY = 'A' ou 'B', M est mis à N.
!>          Chaque vecteur propre réel sélectionné occupe une colonne et chaque
!>          vecteur propre complexe sélectionné occupe deux colonnes.
!>

WORK

!>          WORK est un tableau DOUBLE PRÉCISION, de dimension (3*N)
!>

INFO

!>          INFO est ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>

dtrevc - Remplace les vecteurs propres gauches ou droits de la forme triangulaire supérieure d'une matrice de Hess-Wigner.

Documentation Fonction/Sous-routine

Cette sous-routine est une partie de la bibliothèque LAPACK, qui est une collection de routines Fortran pour résoudre des problèmes de calcul linéaire numérique.

Le but de dtrevc est de calculer les vecteurs propres de la forme triangulaire supérieure d'une matrice. Elle peut calculer soit les vecteurs propres gauches, soit les vecteurs propres droits, ou les deux.

Les arguments de la routine sont les suivants :

  • SIDE : Spécifie si les vecteurs propres gauches, droits, ou les deux doivent être calculés.
  • HOWMNY : Spécifie si tous les vecteurs propres doivent être calculés, ou seulement une sélection.
  • SELECT : Un tableau logique qui indique quels vecteurs propres doivent être calculés lorsque HOWMNY est 'S'.
  • N : L'ordre de la matrice triangulaire.
  • T : La matrice triangulaire supérieure dont les vecteurs propres doivent être calculés.
  • LDT : La ligne de dimension de T.
  • VL : Sur l'entrée, si SIDE est 'L' ou 'B', contient les vecteurs propres gauches à mettre à jour. Sur la sortie, contient les vecteurs propres gauches calculés.
  • LDVL : La ligne de dimension de VL.
  • VR : Sur l'entrée, si SIDE est 'R' ou 'B', contient les vecteurs propres droits à mettre à jour. Sur la sortie, contient les vecteurs propres droits calculés.
  • LDVR : La ligne de dimension de VR.
  • MM : Le nombre maximum de vecteurs propres à stocker dans VL et VR.
  • M : Sur la sortie, le nombre de vecteurs propres réellement calculés.
  • WORK : Un tableau de travail.
  • INFO : Entier. Sur la sortie, INFO est égal à 0 en cas de succès, et un entier négatif en cas d'échec.

Pour plus de détails sur l'utilisation et les algorithmes implémentés, veuillez consulter la documentation officielle de LAPACK.
