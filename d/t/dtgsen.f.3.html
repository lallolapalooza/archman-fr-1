sous-routine dtgsen (integer ijob, logical wantq, logical wantz, logical, dimension( * ) select, integer n, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( ldb, * ) b, integer ldb, double precision, dimension( * ) alphar, double precision, dimension( * ) alphai, double precision, dimension( * ) beta, double precision, dimension( ldq, * ) q, integer ldq, double precision, dimension( ldz, * ) z, integer ldz, integer m, double precision pl, double precision pr, double precision, dimension( * ) dif, double precision, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, integer liwork, integer

!>
!> DTGSEN réordonne la décomposition de Schur réelle généralisée d'une
!> paire de matrices réelles (A, B) (en termes d'une transformation
!> d'équivalence orthogonale Q**T * (A, B) * Z), de sorte qu'un
!> cluster d'eigenvalues sélectionné apparaisse dans les blocs
!> diagonaux de tête de la matrice quasi-triangulaire supérieure A et
!> de la matrice triangulaire supérieure B. Les colonnes de tête de Q
!> et Z forment des bases orthogonales des espaces propres gauche et
!> droit correspondants (sous-espaces déflationnels). (A, B) doit être
!> sous forme canonique de Schur réelle généralisée (comme retournée
!> par DGGES), c.-à-d. A est triangulaire par blocs supérieure avec des
!> blocs diagonaux 1-par-1 et 2-par-2. B est triangulaire supérieure.
!>
!> DTGSEN calcule également les eigenvalues généralisées
!>
!>             w(j) = (ALPHAR(j) + i*ALPHAI(j))/BETA(j)
!>
!> de la paire de matrices réordonnées (A, B).
!>
!> En option, DTGSEN calcule les estimations des nombres de condition
!> réciproques pour les eigenvalues et les espaces propres. Ce sont
!> Difu[(A11,B11), (A22,B22)] et Difl[(A11,B11), (A22,B22)], c.-à-d.
!> la/les séparation(s) entre les paires de matrices (A11, B11) et
!> (A22,B22) qui correspondent respectivement au cluster sélectionné et
!> aux eigenvalues hors du cluster, et les normes de  sur les espaces
!> propres gauche et droit par rapport au cluster sélectionné dans le
!> bloc (1,1).
!
>

Paramètre

s
IJOB 
!>          IJOB est INTEGER
!>          Spécifie si les nombres de condition sont requis pour le
!>          cluster d'eigenvalues (PL et PR) ou pour les sous-espaces
!>          déflationnels (Difu et Difl) :
!>           =0 : Réordonner uniquement par rapport à SELECT. Pas
!>                d'extras.
!>           =1 : Réciproque des normes de  sur les espaces propres
!>                gauche et droit par rapport au cluster sélectionné
!>                (PL et PR).
!>           =2 : Bornes supérieures sur Difu et Difl. Estimation basée
!>                sur la norme F (DIF(1:2)).
!>           =3 : Estimation de Difu et Difl. Estimation basée sur la
!>                norme 1 (DIF(1:2)).
!>                Environ 5 fois plus coûteux que IJOB = 2.
!>           =4 : Calculer PL, PR et DIF (c.-à-d. 0, 1 et 2 ci-dessus) :
!>                version économique pour tout obtenir.
!>           =5 : Calculer PL, PR et DIF (c.-à-d. 0, 1 et 3 ci-dessus)
!

Détails supplémentaires

: 
!>
!>  DTGSEN collecte d'abord les valeurs propres sélectionnées en calculant
!>  les matrices orthogonales U et W qui les déplacent dans le coin supérieur
!>  gauche de (A, B). En d'autres termes, les valeurs propres sélectionnées
!>  sont les valeurs propres de (A11, B11) dans :
!>
!>              U**T*(A, B)*W = (A11 A12) (B11 B12) n1
!>                              ( 0  A22),( 0  B22) n2
!>                                n1  n2    n1  n2
!>
!>  où N = n1+n2 et U**T désigne la transposée de U. Les premières n1 colonnes
!>  de U et W engendrent la paire spécifiée de sous-espaces propres gauche et
!>  droit (sous-espaces déflationnaires) de (A, B).
!>
!>  Si (A, B) a été obtenu à partir de la décomposition de Schur réelle
!>  généralisée d'une paire de matrices (C, D) = Q*(A, B)*Z**T, alors la
!>  forme de Schur réelle généralisée réordonnée de (C, D) est donnée par
!>
!>           (C, D) = (Q*U)*(U**T*(A, B)*W)*(Z*W)**T,
!>
!>  et les premières n1 colonnes de Q*U et Z*W engendrent les sous-espaces
!>  déflationnaires correspondants de (C, D) (Q et Z stockent Q*U et Z*W,
!>  respectivement).
!>
!>  Remarquez que si la valeur propre sélectionnée est suffisamment mal
!>  conditionnée, alors sa valeur peut différer significativement de sa
!>  valeur avant le réordonnancement.
!>
!>  Les nombres de condition réciproques des sous-espaces propres gauche et
!>  droit engendrés par les premières n1 colonnes de U et W (ou Q*U et Z*W)
!>  peuvent être renvoyés dans DIF(1:2), correspondant à Difu et Difl,
!>  respectivement.
!>
!>  Difu et Difl sont définis comme suit :
!>
!>       Difu[(A11, B11), (A22, B22)] = sigma-min(Zu)
!>  et
!>       Difl[(A11, B11), (A22, B22)] = Difu[(A22, B22), (A11, B11)],
!>
!>  où sigma-min(Zu) est la plus petite valeur singulière de la matrice
!>  (2*n1*n2)-par-(2*n1*n2)
!>
!>       Zu = [ kron(In2, A11)  -kron(A22**T, In1) ]
!>            [ kron(In2, B11)  -kron(B22**T, In1) ].
!>
!>  Ici, Inx est la matrice identité de taille nx et A22**T est la
!>  transposée de A22. kron(X, Y) est le produit de Kronecker entre
!>  les matrices X et Y.
!>
!>  Lorsque DIF(2) est petit, de petites variations dans (A, B) peuvent
!>  causer de grands changements dans le sous-espace déflationnaire. Une
!>  borne (asymptotique) approchée sur l'erreur angulaire maximale dans
!>  les sous-espaces déflationnaires calculés est
!>
!>       EPS * norme((A, B)) / DIF(2),
!>
!>  où EPS est la précision machine.
!>
!>  La norme réciproque des projecteurs sur les sous-espaces propres gauche
!>  et droit associés à (A11, B11) peut être renvoyée dans PL et PR.
!>  Elles sont calculées comme suit. D'abord, nous calculons L et R de sorte
!>  que P*(A, B)*Q soit bloc diagonal, où
!>
!>       P = ( I -L ) n1           Q = ( I R ) n1
!>           ( 0  I ) n2    et        ( 0 I ) n2
!>             n1 n2                    n1 n2
!>
!>  et (L, R) est la solution de l'équation de Sylvester généralisée
!>
!>       A11*R - L*A22 = -A12
!>       B11*R - L*B22 = -B12
!>
!>  Ensuite PL = (norme-F(L)**2+1)**(-1/2) et PR = (norme-F(R)**2+1)**(-1/2).
!>  Une borne (asymptotique) approchée sur l'erreur absolue moyenne des
!>  valeurs propres sélectionnées est
!>
!>       EPS * norme((A, B)) / PL.
!>
!>  Il existe également des bornes d'erreur globales valides pour des
!>  perturbations jusqu'à une certaine restriction : une borne inférieure (x)
!>  sur la plus petite norme-F(E,F) pour laquelle une valeur propre de
!>  (A11, B11) peut se déplacer et coalescer avec une valeur propre de
!>  (A22, B22) sous la perturbation (E,F), (c.-à-d. (A + E, B + F)), est
!>
!>   x = min(Difu,Difl)/((1/(PL*PL)+1/(PR*PR))**(1/2)+2*max(1/PL,1/PR)).
!>
!>  Une borne approchée sur x peut être calculée à partir de DIF(1:2), PL et PR.
!>
!>  Si y = (norme-F(E,F) / x) <= 1, les angles entre les sous-espaces
!>  déflationnaires gauche et droit perturbés (L', R') et non perturbés
!>  (L, R) associés au groupe sélectionné dans les blocs (1,1) peuvent
!>  être bornés par
!>
!>   max-angle(L, L') <= arctan( y * PL / (1 - y * (1 - PL * PL)**(1/2))
!>   max-angle(R, R') <= arctan( y * PR / (1 - y * (1 - PR * PR)**(1/2))
!>
!>  Voir la section 4.11 du Guide de l'utilisateur de LAPACK ou les
!>  références suivantes pour plus d'informations.
!>
!>  Remarquez que si la méthode par défaut pour calculer l'estimation DIF
!>  basée sur la norme de Frobenius n'est pas souhaitée (voir DLATDF), alors
!>  le paramètre IDIFJB (voir ci-dessous) devrait être changé de 3 à 4
!>  (la routine DLATDF (IJOB = 2 sera utilisée)). Voir DTGSYL pour plus de
!>  détails.
!
>
