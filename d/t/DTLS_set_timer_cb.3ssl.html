DTLS_set_timer_cb(3ssl)

Paquet: openssl

Licences: Apache-2.0

DTLS_SET_TIMER_CB(3ssl) OpenSSL DTLS_SET_TIMER_CB(3ssl)

NOM

DTLS_timer_cb, DTLS_set_timer_cb - Définir une fonction de rappel pour contrôler la durée du minuteur DTLS

SYNTAXE

#include <openssl/ssl.h>
typedef unsigned int (*DTLS_timer_cb)(SSL *s, unsigned int timer_us);
void DTLS_set_timer_cb(SSL *s, DTLS_timer_cb cb);

DESCRIPTION

Cette fonction définit une fonction de rappel facultative pour contrôler l'intervalle de temps d'attente du protocole DTLS. La fonction de rappel sera appelée par DTLS pour chaque nouveau paquet DTLS envoyé.

Le rappel doit retourner l'intervalle de temps d'attente en microsecondes.

Le paramètre timer_us du rappel est le dernier intervalle de temps d'attente défini et retourné. Lors de la première invocation du rappel, cette valeur sera de 0.

Au début de la connexion, si aucun rappel de temps d'attente n'a été défini via DTLS_set_timer_cb(), la valeur de temps d'attente par défaut est de 1 seconde. Pour tous les temps d'attente suivants, le comportement par défaut est de doubler la durée jusqu'à un maximum de 1 minute.

VALEURS DE RETOUR

Retourne void.

HISTORIQUE

La fonction DTLS_set_timer_cb() a été ajoutée dans OpenSSL 1.1.1.
