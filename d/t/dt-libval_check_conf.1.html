DT-LIBVAL_CHECK_CONF(1) Commandes utilisateur DT-LIBVAL_CHECK_CONF(1)

NOM

dt-libval_check_conf - programme en ligne de commande pour vérifier la validité des fichiers de configuration du validateur.

SYNTAXE

dt-libval_check_conf [options]

DESCRIPTION

Ce programme vérifie un fichier de configuration de validateur donné pour toute erreur de syntaxe. Si aucun fichier n'est spécifié en option dans la ligne de commande, le fichier dnsval.conf par défaut est vérifié.

VALEURS DE RETOUR

Le programme retourne 0 en cas de succès et -1 en cas d'échec.

OPTIONS

-d, --dnsval-conf
Spécifie l'emplacement du fichier dnsval.conf. Si cette option n'est pas spécifiée, le fichier dnsval.conf par défaut reconnu par la bibliothèque du validateur est utilisé à la place.
-r, --resolv-conf
Spécifie l'emplacement du fichier resolv.conf. Si cette option n'est pas spécifiée, le fichier resolv.conf par défaut reconnu par la bibliothèque du validateur est utilisé à la place.
-i, --root-hints
Spécifie l'emplacement du fichier root.hints. Si cette option n'est pas spécifiée, le fichier root.hints par défaut reconnu par la bibliothèque du validateur est utilisé à la place.
-v, --verbose
Affiche des messages détaillés et des avertissements associés au processus de vérification du fichier de configuration du validateur.
-h, --help
Affiche un message d'aide d'utilisation et quitte le programme.
