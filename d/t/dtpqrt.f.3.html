sous-programme dtpqrt (integer m, integer n, integer l, integer nb, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( ldb, * ) b, integer ldb, double precision, dimension( ldt, * ) t, integer ldt, double precision, dimension( * ) work, integer info)

DTPQRT

But :

!>
!> DTPQRT calcule une factorisation QR bloquée d'une matrice réelle
!>  C, qui est composée d'un bloc triangulaire A et d'un bloc pentagonal B,
!>  en utilisant la représentation WY compacte pour Q.
!>

Paramètres

M 
!>          M est un INTEGER
!>          Le nombre de lignes de la matrice B.
!>          M >= 0.
!>

N

!>          N est un INTEGER
!>          Le nombre de colonnes de la matrice B, et l'ordre de la
!>          matrice triangulaire A.
!>          N >= 0.
!>

L

!>          L est un INTEGER
!>          Le nombre de lignes de la partie trapézoïdale supérieure de B.
!>          MIN(M,N) >= L >= 0.  Voir Détails supplémentaires.
!>

NB

!>          NB est un INTEGER
!>          La taille du bloc à utiliser dans la QR bloquée.  N >= NB >= 1.
!>

A

!>          A est un tableau DOUBLE PRECISION, dimension (LDA,N)
!>          À l'entrée, la matrice triangulaire supérieure N-par-N A.
!>          À la sortie, les éléments sur et au-dessus de la diagonale du
!>          tableau contiennent la matrice triangulaire supérieure R.
!>

LDA

!>          LDA est un INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

B

!>          B est un tableau DOUBLE PRECISION, dimension (LDB,N)
!>          À l'entrée, la matrice pentagonale M-par-N B. Les M-L premières
!>          lignes sont rectangulaires, et les L dernières lignes sont
!>          trapézoïdales supérieures.
!>          À la sortie, B contient la matrice pentagonale V.  Voir Détails
!>          supplémentaires.
!>

LDB

!>          LDB est un INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,M).
!>

T

!>          T est un tableau DOUBLE PRECISION, dimension (LDT,N)
!>          Les réflecteurs de blocs triangulaires supérieurs stockés sous
!>          forme compacte comme une séquence de blocs triangulaires
!>          supérieurs.  Voir Détails supplémentaires.
!>

LDT

!>          LDT est un INTEGER
!>          La dimension principale du tableau T.  LDT >= NB.
!>

WORK

!>          WORK est un tableau DOUBLE PRECISION, dimension (NB*N)
!>

INFO

!>          INFO est un INTEGER
!>          = 0:  Succès de l'exécution
!>          < 0:  Si INFO = -i, le i-ème argument était illégal
!>

Détails supplémentaires :

!>
!>  La matrice d'entrée C est une matrice (N+M)-par-N
!>
!>               C = [ A ]
!>                   [ B ]
!>
!>  où A est une matrice triangulaire supérieure N-par-N, et B est une matrice
!>  pentagonale M-par-N composée d'une matrice rectangulaire B1 (M-L)-par-N en
!>  haut et d'une matrice trapézoïdale supérieure L-par-N B2 en bas :
!>
!>               B = [ B1 ]  <- rectangulaire (M-L)-par-N
!>                   [ B2 ]  <- trapézoïdale supérieure L-par-N.
!>
!>  La matrice trapézoïdale supérieure B2 est composée des L premières lignes
!>  d'une matrice triangulaire supérieure N-par-N, où 0 <= L <= MIN(M,N). Si L=0,
!>  B est rectangulaire M-par-N ; si M=L=N, B est triangulaire supérieure.
!>
!>  La matrice W stocke les réflecteurs élémentaires H(i) dans la i-ème colonne
!>  en dessous de la diagonale (de A) dans la matrice d'entrée C (N+M)-par-N
!>
!>               C = [ A ]  <- triangulaire supérieure N-par-N
!>                   [ B ]  <- pentagonale M-par-N
!>
!>  de sorte que W puisse être représentée comme
!>
!>               W = [ I ]  <- identité, N-par-N
!>                   [ V ]  <- M-par-N, même forme que B.
!>
!>  Ainsi, toutes les informations nécessaires pour W sont contenues à la sortie
!>  dans B, que nous appelons V ci-dessus. Notez que V a la même forme que B ;
!>  c'est-à-dire,
!>
!>               V = [ V1 ] <- rectangulaire (M-L)-par-N
!>                   [ V2 ] <- trapézoïdale supérieure L-par-N.
!>
!>  Les colonnes de V représentent les vecteurs qui définissent les H(i).
!>
!>  Le nombre de blocs est B = ceiling(N/NB), où chaque
!>  bloc est d'ordre NB sauf le dernier bloc, qui est d'ordre
!>  IB = N - (B-1)*NB. Pour chacun des B blocs, un facteur de réflecteur
!>  triangulaire supérieur est calculé : T1, T2, ..., TB. Les T de taille
!>  NB-par-NB (et IB-par-IB pour le dernier bloc) sont stockés dans la matrice
!>  T de taille NB-par-N comme suit :
!>
!>               T = [T1 T2 ... TB].
!>
