NOM

dtconf - Affiche le contenu d'un fichier de configuration DNSSEC-Tools

SYNTAXE

dtconf [options] [fichier_config]

DESCRIPTION

dtconf affiche les paires clé/valeur d'un fichier de configuration DNSSEC-Tools. Si aucun fichier de configuration n'est spécifié, le fichier de configuration système sera affiché.

Sans l'option -key, dtconf affiche toutes les paires clé/valeur du fichier de configuration. Les commentaires ne sont jamais affichés. Si l'option -key est donnée, alors seule cette paire clé/valeur est affichée. Si la clé n'est pas définie, alors la valeur sera "(undefined)".

OPTIONS

-key
La valeur de la clé spécifiée sera imprimée. Si la clé n'est pas définie, alors la valeur sera donnée comme "(undefined)".
-Version
Affiche les informations de version pour dtconf et le paquet DNSSEC-Tools.
-help
Affiche un message d'utilisation.
