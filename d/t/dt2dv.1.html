DT2DV(1) Manuel des commandes générales DT2DV(1)

NOM

dt2dv - convertir une représentation textuelle DTL d'un fichier DVI TeX en fichier DVI binaire

SYNTAXE

dt2dv [-debug] [-group] [-si] [-so] [fichier-DTL-entrée] [fichier-DVI-sortie]

En l'absence des options -si et -so, les deux arguments de fichier sont requis dans l'ordre fichier-DTL-entrée fichier-DVI-sortie. Mais consultez également la section OPTIONS ci-dessous. Aucune extension de fichier par défaut n'est fournie.

DESCRIPTION

dt2dv convertit une représentation textuelle d'un fichier DVI TeX, généralement produite par l'utilitaire compagnon dv2dt(1), pour la reconvertir en un fichier DVI binaire. Les fichiers DTL (DVI Text Language) peuvent être modifiés, avec précaution, puis restaurés sous forme DVI pour être traités par n'importe quel programme pilote DVI TeX. Dans les fichiers DTL, les noms de répertoires de polices et les noms de polices sont précédés d'un champ de longueur, qui doit être mis à jour si les noms sont modifiés.

dvitype(1) peut également afficher une représentation textuelle des fichiers DVI, mais dans certaines implémentations au moins, il ne peut pas être utilisé en mode batch, et sa sortie n'est pas bien adaptée à la conversion en fichier DVI.

Le format des fichiers DVI TeX est entièrement décrit dans Donald E. Knuth, TeX: The Program, Addison-Wesley (1986), ISBN 0-201-13437-3, ainsi que dans le code source du programme littéraire dvitype(1). Des descriptions succinctes des formats DTL et DVI sont données dans dv2dt(1).

OPTIONS

-debug
Active la sortie de débogage détaillée.
-group
Attend que chaque commande DTL soit entre parenthèses.
-si
Lit toutes les commandes DTL depuis l'entrée standard.
-so
Écrit toutes les commandes DVI sur la sortie standard.

VOIR AUSSI

dv2dt(1), dvitype(1), tex(1).

FICHIERS

*.dvi
fichier DVI TeX binaire.
*.dtl
représentation textuelle d'un fichier DVI TeX au format DVI Text Language.
