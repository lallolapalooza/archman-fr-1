Documentation de la fonction/sous-routine

sous-routine dtplqt (integer m, integer n, integer l, integer mb, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( ldb, * ) b, integer ldb, double precision, dimension( ldt, * ) t, integer ldt, double precision, dimension( * ) work, integer info)

DTPLQT

Purpose:

!>
!> DTPLQT calcule une factorisation LQ bloquée d'une matrice réelle
!>  C, composée d'un bloc triangulaire A et d'un bloc pentagonal B,
!>  en utilisant la représentation WY compacte pour Q.
!>

Paramètres

M 
!>          M est un entier
!>          Le nombre de lignes de la matrice B, et l'ordre de la
!>          matrice triangulaire A.
!>          M >= 0.
!>

N

!>          N est un entier
!>          Le nombre de colonnes de la matrice B.
!>          N >= 0.
!>

L

!>          L est un entier
!>          Le nombre de lignes de la partie trapézoïdale inférieure de B.
!>          MIN(M,N) >= L >= 0.  Voir Détails supplémentaires.
!>

MB

!>          MB est un entier
!>          La taille du bloc à utiliser dans la QR bloquée.  M >= MB >= 1.
!>

A

!>          A est un tableau de type DOUBLE PRECISION, de dimension (LDA,N)
!>          En entrée, la matrice triangulaire inférieure N-par-N A.
!>          En sortie, les éléments sur et sous la diagonale du tableau
!>          contiennent la matrice triangulaire inférieure L.
!>

LDA

!>          LDA est un entier
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

B

!>          B est un tableau de type DOUBLE PRECISION, de dimension (LDB,N)
!>          En entrée, la matrice pentagonale M-par-N B. Les N-L premières colonnes
!>          sont rectangulaires, et les L dernières colonnes sont trapézoïdales inférieures.
!>          En sortie, B contient la matrice pentagonale V.  Voir Détails supplémentaires.
!>

LDB

!>          LDB est un entier
!>          La dimension principale du tableau B.  LDB >= max(1,M).
!>

T

!>          T est un tableau de type DOUBLE PRECISION, de dimension (LDT,N)
!>          Les réflecteurs de bloc triangulaires stockés sous forme compacte
!>          sous forme d'une séquence de blocs triangulaires supérieurs. Voir Détails supplémentaires.
!>

LDT

!>          LDT est un entier
!>          La dimension principale du tableau T.  LDT >= MB.
!>

WORK

!>          WORK est un tableau de type DOUBLE PRECISION, de dimension (MB*M)
!>

INFO

!>          INFO est un entier
!>          = 0:  fin réussie
!>          < 0:  si INFO = -i, le i-ème argument était invalide
!>

Détails supplémentaires:

!>
!>  La matrice d'entrée C est une matrice M-par-(M+N)
!>
!>               C = [ A ] [ B ]
!>
!>
!>  où A est une matrice N-par-N triangulaire inférieure, et B est une matrice
!>  pentagonale M-par-N constituée d'une matrice rectangulaire M-par-(N-L) B1
!>  à gauche d'une matrice trapézoïdale supérieure M-par-L B2:
!>          [ B ] = [ B1 ] [ B2 ]
!>                   [ B1 ]  <- rectangulaire M-par-(N-L)
!>                   [ B2 ]  <-     trapézoïdale supérieure M-par-L.
!>
!>  La matrice trapézoïdale inférieure B2 est constituée des L premières colonnes
!>  d'une matrice triangulaire inférieure N-par-N, où 0 <= L <= MIN(M,N). Si L=0,
!>  B est rectangulaire M-par-N ; si M=L=N, B est triangulaire inférieure.
!>
!>  La matrice W stocke les réflecteurs élémentaires H(i) dans la i-ème ligne
!>  au-dessus de la diagonale (de A) dans la matrice C d'entrée M-par-(M+N)
!>            [ C ] = [ A ] [ B ]
!>                   [ A ]  <- triangulaire inférieure N-par-N
!>                   [ B ]  <- pentagonale M-par-N
!>
!>  de sorte que W peut être représentée comme
!>            [ W ] = [ I ] [ V ]
!>                   [ I ]  <- identité, N-par-N
!>                   [ V ]  <- M-par-N, même forme que B.
!>
!>  Ainsi, toutes les informations nécessaires pour W sont contenues en sortie
!>  dans B, que nous appelons V ci-dessus. Notons que V a la même forme que B ;
!>  c'est-à-dire,
!>            [ V ] = [ V1 ] [ V2 ]
!>                   [ V1 ] <- rectangulaire M-par-(N-L)
!>                   [ V2 ] <-     trapézoïdale inférieure M-par-L.
!>
!>  Les lignes de V représentent les vecteurs qui définissent les H(i).
!>
!>  Le nombre de blocs est B = ceiling(M/MB), où chaque
!>  bloc est d'ordre MB sauf le dernier bloc, qui est d'ordre
!>  IB = M - (M-1)*MB. Pour chacun des B blocs, un facteur de réflecteur
!>  de bloc triangulaire supérieur est calculé : T1, T2, ..., TB. Les T de taille
!>  MB-par-MB (et IB-par-IB pour le dernier bloc) sont stockés dans la matrice
!>  T de taille MB-par-N sous la forme
!>
!>               T = [T1 T2 ... TB].
!>
