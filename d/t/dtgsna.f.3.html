Documentation de la fonction/sous-routine

sous-routine dtgsna (character job, character howmny, logical, dimension( * ) select, integer n, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( ldb, * ) b, integer ldb, double precision, dimension( ldvl, * ) vl, integer ldvl, double precision, dimension( ldvr, * ) vr, integer ldvr, double precision, dimension( * ) s, double precision, dimension( * ) dif, integer mm, integer m, double precision, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, integer info)

DTGSNA

But :

!>
!> DTGSNA estime les nombres de condition réciproques pour les
!> valeurs propres et/ou vecteurs propres spécifiés d'une paire de
!> matrices (A, B) en forme canonique de Schur réelle généralisée
!> (ou de toute paire de matrices (Q*A*Z**T, Q*B*Z**T) avec des
!> matrices orthogonales Q et Z, où Z**T désigne la transposée de Z.
!>
!> (A, B) doit être en forme de Schur réelle généralisée (comme
!> renvoyée par DGGES), c'est-à-dire A est triangulaire supérieure
!> par blocs avec des blocs diagonaux de taille 1 par 1 et 2 par 2.
!> B est triangulaire supérieure.
!>
!>

Paramètres

JOB 
!>          JOB est CHARACTER*1
!>          Spécifie si les nombres de condition sont requis pour
!>          les valeurs propres (S) ou les vecteurs propres (DIF) :
!>          = 'E' : pour les valeurs propres uniquement (S) ;
!>          = 'V' : pour les vecteurs propres uniquement (DIF) ;
!>          = 'B' : pour les valeurs propres et les vecteurs propres
!>                  (S et DIF).
!>

HOWMNY

!>          HOWMNY est CHARACTER*1
!>          = 'A' : calcule les nombres de condition pour toutes les
!>                  paires propres ;
!>          = 'S' : calcule les nombres de condition pour les paires
!>                  propres sélectionnées spécifiées par le tableau
!>                  SELECT.
!>

SELECT

!>          SELECT est un tableau LOGICAL, dimension (N)
!>          Si HOWMNY = 'S', SELECT spécifie les paires propres pour
!>          lesquelles les nombres de condition sont requis. Pour
!>          sélectionner les nombres de condition pour la paire propre
!>          correspondant à une valeur propre réelle w(j), SELECT(j)
!>          doit être défini à .TRUE.. Pour sélectionner les nombres
!>          de condition correspondant à une paire conjuguée complexe
!>          de valeurs propres w(j) et w(j+1), soit SELECT(j), soit
!>          SELECT(j+1), ou les deux, doivent être définis à .TRUE..
!>          Si HOWMNY = 'A', SELECT n'est pas référencé.
!>

N

!>          N est INTEGER
!>          L'ordre de la paire de matrices carrées (A, B). N >= 0.
!>

A

!>          A est un tableau DOUBLE PRECISION, dimension (LDA,N)
!>          La matrice quasi-triangulaire supérieure A dans la paire
!>          (A,B).
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,N).
!>

B

!>          B est un tableau DOUBLE PRECISION, dimension (LDB,N)
!>          La matrice triangulaire supérieure B dans la paire (A,B).
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B. LDB >= max(1,N).
!>

VL

!>          VL est un tableau DOUBLE PRECISION, dimension (LDVL,M)
!>          Si JOB = 'E' ou 'B', VL doit contenir les vecteurs
!>          propres gauches de (A, B), correspondant aux paires
!>          propres spécifiées par HOWMNY et SELECT. Les vecteurs
!>          propres doivent être stockés dans des colonnes
!>          consécutives de VL, comme renvoyé par DTGEVC.
!>          Si JOB = 'V', VL n'est pas référencé.
!>

LDVL

!>          LDVL est INTEGER
!>          La dimension principale du tableau VL. LDVL >= 1.
!>          Si JOB = 'E' ou 'B', LDVL >= N.
!>

VR

!>          VR est un tableau DOUBLE PRECISION, dimension (LDVR,M)
!>          Si JOB = 'E' ou 'B', VR doit contenir les vecteurs
!>          propres droits de (A, B), correspondant aux paires
!>          propres spécifiées par HOWMNY et SELECT. Les vecteurs
!>          propres doivent être stockés dans des colonnes
!>          consécutives de VR, comme renvoyé par DTGEVC.
!>          Si JOB = 'V', VR n'est pas référencé.
!>

LDVR

!>          LDVR est INTEGER
!>          La dimension principale du tableau VR. LDVR >= 1.
!>          Si JOB = 'E' ou 'B', LDVR >= N.
!>

S

!>          S est un tableau DOUBLE PRECISION, dimension (MM)
!>          Si JOB = 'E' ou 'B', les nombres de condition réciproques
!>          des valeurs propres sélectionnées, stockés dans des
!>          éléments consécutifs du tableau. Pour une paire conjuguée
!>          complexe de valeurs propres, deux éléments consécutifs de
!>          S sont définis à la même valeur. Ainsi S(j), DIF(j), et
!>          les j-ièmes colonnes de VL et VR correspondent tous à la
!>          même paire propre (mais pas en général à la j-ième paire
!>          propre, sauf si toutes les paires propres sont
!>          sélectionnées).
!>          Si JOB = 'V', S n'est pas référencé.
!>

DIF

!>          DIF est un tableau DOUBLE PRECISION, dimension (MM)
!>          Si JOB = 'V' ou 'B', les nombres de condition réciproques
!>          estimés des vecteurs propres sélectionnés, stockés dans
!>          des éléments consécutifs du tableau. Pour un vecteur
!>          propre complexe, deux éléments consécutifs de DIF sont
!>          définis à la même valeur. Si les valeurs propres ne peuvent
!>          pas être réordonnées pour calculer DIF(j), DIF(j) est
!>          défini à 0 ; cela ne peut se produire que lorsque la
!>          valeur réelle serait de toute façon très petite.
!>          Si JOB = 'E', DIF n'est pas référencé.
!>

MM

!>          MM est INTEGER
!>          Le nombre d'éléments dans les tableaux S et DIF. MM >= M.
!>

M

!>          M est INTEGER
!>          Le nombre d'éléments des tableaux S et DIF utilisés pour
!>          stocker les nombres de condition spécifiés ; pour chaque
!>          valeur propre réelle sélectionnée, un élément est utilisé,
!>          et pour chaque paire conjuguée complexe de valeurs propres
!>          sélectionnée, deux éléments sont utilisés.
!>          Si HOWMNY = 'A', M est défini à N.
!>

WORK

!>          WORK est un tableau DOUBLE PRECISION, dimension
!>          (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) renvoie le LWORK optimal.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK. LWORK >= max(1,N).
!>          Si JOB = 'V' ou 'B', LWORK >= 2*N*(N+2)+16.
!>
!>          Si LWORK = -1, une interrogation d'espace de travail est
!>          supposée ; la routine calcule uniquement la taille
!>          optimale du tableau WORK, renvoie cette valeur comme
!>          première entrée du tableau WORK, et aucun message d'erreur
!>          lié à LWORK n'est émis par XERBLA.
!>

IWORK

!>          IWORK est un tableau INTEGER, dimension (N + 6)
!>          Si JOB = 'E', IWORK n'est pas référencé.
!>

INFO

!>          INFO est INTEGER
!>          =0 : sortie réussie
!>          <0 : si INFO = -i, le i-ème argument avait une valeur
!>               illégale
!>

Détails supplémentaires :

!>
!>  Le réciproque du nombre de condition d'une valeur propre
!>  généralisée w = (a, b) est défini comme
!>
!>       S(w) = (|u**TAv|**2 + |u**TBv|**2)**(1/2) / (norm(u)*norm(v))
!>
!>  où u et v sont les vecteurs propres gauche et droit de (A, B)>  correspondant à w ; |z| désigne la valeur absolue du nombre
!>  complexe, et norm(u) désigne la 2-norme du vecteur u.
!>  La paire (a, b) correspond à une valeur propre w = a/b (= u**TAv/u**TBv)
!>  de la paire de matrices (A, B). Si a et b sont tous deux égaux à zéro,
!>  alors (A B) est singulière et S(I) = -1 est retourné.
!>
!>  Une borne d'erreur approchée sur la distance en corde entre la i-ème
!>  valeur propre généralisée w calculée et la valeur propre exacte
!>  correspondante lambda est
!>
!>       chord(w, lambda) <= EPS * norm(A, B) / S(I)
!>
!>  où EPS est la précision machine.
!>
!>  L'inverse du conditionnement DIF(i) du vecteur propre droit u
!>  et du vecteur propre gauche v correspondant à la valeur propre
!>  généralisée w est défini comme suit :
!>
!>  a) Si la i-ème valeur propre w = (a,b) est réelle
!>
!>     Supposons que U et V soient des transformations orthogonales telles que
!>
!>              U**T*(A, B)*V  = (S, T) = ( a   *  ) ( b  *  )  1
!>                                        ( 0  S22 ),( 0 T22 )  n-1
!>                                          1  n-1     1 n-1
!>
!>     Alors l'inverse du conditionnement DIF(i) est
!>
!>                Difl((a, b), (S22, T22)) = sigma-min( Zl ),
!>
!>     où sigma-min(Zl) désigne la plus petite valeur singulière de la
!>     matrice 2(n-1)-par-2(n-1)
!>
!>         Zl = [ kron(a, In-1)  -kron(1, S22) ]
!>              [ kron(b, In-1)  -kron(1, T22) ] .
!>
!>     Ici In-1 est la matrice identité de taille n-1. kron(X, Y) est le
!>     produit de Kronecker entre les matrices X et Y.
!>
!>     Remarquez que si la méthode par défaut pour calculer DIF(i) est souhaitée
!>     (voir DLATDF), alors le paramètre DIFDRI (voir ci-dessous) devrait être
!>     changé de 3 à 4 (la routine DLATDF(IJOB = 2 sera utilisée)).
!>     Voir DTGSYL pour plus de détails.
!>
!>  b) Si les i-ème et (i+1)-ème valeurs propres forment une paire conjuguée complexe,
!>
!>     Supposons que U et V soient des transformations orthogonales telles que
!>
!>              U**T*(A, B)*V = (S, T) = ( S11  *   ) ( T11  *  )  2
!>                                       ( 0    S22 ),( 0    T22) n-2
!>                                         2    n-2     2    n-2
!>
!>     et (S11, T11) correspond à la paire de valeurs propres conjuguées
!>     complexes (w, conjg(w)). Il existe des matrices unitaires U1 et V1 telles
!>     que
!>
!>       U1**T*S11*V1 = ( s11 s12 ) et U1**T*T11*V1 = ( t11 t12 )
!>                      (  0  s22 )                    (  0  t22 )
!>
!>     où les valeurs propres généralisées w = s11/t11 et
!>     conjg(w) = s22/t22.
!>
!>     Alors l'inverse du conditionnement DIF(i) est borné par
!>
!>         min( d1, max( 1, |real(s11)/real(s22)| )*d2 )
!>
!>     où d1 = Difl((s11, t11), (s22, t22)) = sigma-min(Z1), où
!>     Z1 est la matrice complexe 2-par-2
!>
!>              Z1 =  [ s11  -s22 ]
!>                    [ t11  -t22 ],
!>
!>     Ceci est fait en calculant (en utilisant l'arithmétique réelle) les
!>     racines du polynôme caractéristique det(Z1**T * Z1 - lambda I),
!>     où Z1**T désigne la transposée de Z1 et det(X) désigne
!>     le déterminant de X.
!>
!>     et d2 est une borne supérieure sur Difl((S11, T11), (S22, T22)), c'est-à-dire une
!>     borne supérieure sur sigma-min(Z2), où Z2 est (2n-2)-par-(2n-2)
!>
!>              Z2 = [ kron(S11**T, In-2)  -kron(I2, S22) ]
!>                   [ kron(T11**T, In-2)  -kron(I2, T22) ]
!>
!>     Remarquez que si la méthode par défaut pour calculer DIF est souhaitée (voir
!>     DLATDF), alors le paramètre DIFDRI (voir ci-dessous) devrait être changé
!>     de 3 à 4 (la routine DLATDF(IJOB = 2 sera utilisée)). Voir DTGSYL
!>     pour plus de détails.
!>
!>  Pour chaque valeur propre/vecteur spécifié par SELECT, DIF stocke une
!>  estimation basée sur la norme de Frobenius de Difl.
!>
!>  Une borne d'erreur approchée pour le i-ème vecteur propre calculé VL(i) ou
!>  VR(i) est donnée par
!>
!>             EPS * norm(A, B) / DIF(i).
!>
!>  Voir la réf. [2-3] pour plus de détails et de références supplémentaires.
!>
