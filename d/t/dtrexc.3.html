Documentation de fonction/sous-programme

subroutine dtrexc (character compq, integer n, double precision, dimension( ldt, * ) t, integer ldt, double precision, dimension( ldq, * ) q, integer ldq, integer ifst, integer ilst, double precision, dimension( * ) work, integer info)

DTREXC

Purpose:

!>
!> DTREXC réordonne la factorisation de Schur réelle d'une matrice réelle
!> A = Q*T*Q**T, de telle sorte que le bloc diagonal de T avec l'indice de ligne IFST soit
!> déplacé à la ligne ILST.
!>
!> La forme de Schur réelle T est réordonnée par une transformation de similarité orthogonale
!> Z**T*T*Z, et éventuellement la matrice Q des vecteurs de Schur est mise à jour en
!> la multipliant par Z.
!>
!> T doit être sous forme canonique de Schur (tel que retourné par DHSEQR), c'est-à-dire
!> quasi-triangulaire par blocs avec des blocs diagonaux de 1x1 et 2x2 ; chaque
!> bloc diagonal de 2x2 a ses éléments diagonaux égaux et ses
!> éléments hors diagonaux de signe opposé.
!>

Paramètres

COMPQ 
!>          COMPQ est CHARACTER*1
!>          = 'V':  met à jour la matrice Q des vecteurs de Schur ;
!>          = 'N':  ne met pas à jour Q.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice T. N >= 0.
!>          Si N == 0, les arguments ILST et IFST peuvent avoir n'importe quelle valeur.
!>

T

!>          T est un tableau de DOUBLE PRECISION, de dimension (LDT,N)
!>          À l'entrée, la matrice quasi-triangulaire supérieure T, en forme
!>          canonique de Schur.
!>          À la sortie, la matrice quasi-triangulaire réordonnée, à nouveau
!>          en forme canonique de Schur.
!>

LDT

!>          LDT est INTEGER
!>          La dimension principale du tableau T. LDT >= max(1,N).
!>

Q

!>          Q est un tableau de DOUBLE PRECISION, de dimension (LDQ,N)
!>          À l'entrée, si COMPQ = 'V', la matrice Q des vecteurs de Schur.
!>          À la sortie, si COMPQ = 'V', Q a été post-multiplié par la
!>          matrice de transformation orthogonale Z qui réordonne T.
!>          Si COMPQ = 'N', Q n'est pas référencé.
!>

LDQ

!>          LDQ est INTEGER
!>          La dimension principale du tableau Q. LDQ >= 1, et si
!>          COMPQ = 'V', LDQ >= max(1,N).
!>

IFST

!>          IFST est INTEGER
!>

ILST

!>          ILST est INTEGER
!>
!>          Spécifient le réordonnancement des blocs diagonaux de T.
!>          Le bloc avec l'indice de ligne IFST est déplacé à la ligne ILST, par une
!>          séquence de transpositions entre blocs adjacents.
!>          À la sortie, si IFST pointait à l'entrée sur la deuxième ligne d'un
!>          bloc 2x2, il est modifié pour pointer sur la première ligne ; ILST
!>          pointe toujours sur la première ligne du bloc dans sa position finale
!>          (qui peut différer de sa valeur d'entrée de +1 ou -1).
!>          1 <= IFST <= N ; 1 <= ILST <= N.
!>

WORK

!>          WORK est un tableau de DOUBLE PRECISION, de dimension (N)
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          = 1 : deux blocs adjacents étaient trop proches pour être échangés (le problème
!>                est très mal conditionné) ; T a pu être partiellement réordonné,
!>                et ILST pointe sur la première ligne de la position actuelle du
!>                bloc en cours de déplacement.
!>
