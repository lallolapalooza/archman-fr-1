But

: 
!>
!> DTBT05 teste les bornes d'erreur issues de l'affinage itératif pour la
!> solution calculée d'un système d'équations A*X = B, où A est une
!> matrice bande triangulaire.
!>
!> RESLTS(1) = test de la borne d'erreur
!>           = norm(X - XACT) / ( norm(X) * FERR )
!>
!> Une grande valeur est retournée si ce rapport n'est pas inférieur à un.
!>
!> RESLTS(2) = résidu provenant de la routine d'affinage itératif
!>           = le maximum de BERR / ( NZ*EPS + (*) ), où
!>             (*) = NZ*UNFL / (min_i (abs(A)*abs(X) +abs(b))_i )
!>             et NZ = nombre max. de coefficients non nuls dans n'importe
!>             quelle ligne de A, plus 1
!
>

Paramètre

s
UPLO 
!>          UPLO est CHARACTER*1
!>          Indique si la matrice A est triangulaire supérieure ou inférieure.
!>          = 'U' :  Triangulaire supérieure
!>          = 'L' :  Triangulaire inférieure
!
>

TRAN

S 
!>          TRANS est CHARACTER*1
!>          Indique la forme du système d'équations.
!>          = 'N' :  A * X = B  (Pas de transposition)
!>          = 'T' :  A'* X = B  (Transposition)
!>          = 'C' :  A'* X = B  (Transposition conjuguée = Transposition)
!
>

DIA

G 
!>          DIAG est CHARACTER*1
!>          Indique si la matrice A est triangulaire unitaire ou non.
!>          = 'N' :  Triangulaire non unitaire
!>          = 'U' :  Triangulaire unitaire
!
>

N 
!>          N est INTEGER
!>          Le nombre de lignes des matrices X, B et XACT, et l'ordre
!>          de la matrice A.  N >= 0.
!
>

K

D 
!>          KD est INTEGER
!>          Le nombre de sur-diagonales de la matrice A si UPLO = 'U',
!>          ou le nombre de sous-diagonales si UPLO = 'L'.  KD >= 0.
!
>

NRH

S 
!>          NRHS est INTEGER
!>          Le nombre de colonnes des matrices X, B et XACT.
!>          NRHS >= 0.
!
>

A

B 
!>          AB est un tableau DOUBLE PRECISION, dimension (LDAB,N)
!>          La matrice bande triangulaire supérieure ou inférieure A, stockée dans
!>          les kd+1 premières lignes du tableau. La j-ième colonne de A est stockée
!>          dans la j-ième colonne du tableau AB comme suit :
!>          si UPLO = 'U', AB(kd+1+i-j,j) = A(i,j) pour max(1,j-kd)<=i<=j ;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) pour j<=i<=min(n,j+kd).
!>          Si DIAG = 'U', les éléments diagonaux de A ne sont pas référencés
!>          et sont supposés valoir 1.
!
>

LDA

B 
!>          LDAB est INTEGER
!>          La dimension principale du tableau AB.  LDAB >= KD+1.
!
>

B 
!>          B est un tableau DOUBLE PRECISION, dimension (LDB,NRHS)
!>          Les vecteurs du second membre pour le système d'équations
!>          linéaires.
!
>

LD

B 
!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!
>

X 
!>          X est un tableau DOUBLE PRECISION, dimension (LDX,NRHS)
!>          Les vecteurs solution calculés. Chaque vecteur est stocké comme une
!>          colonne de la matrice X.
!
>

LD

X 
!>          LDX est INTEGER
!>          La dimension principale du tableau X.  LDX >= max(1,N).
!
>

XAC

T 
!>          XACT est un tableau DOUBLE PRECISION, dimension (LDX,NRHS)
!>          Les vecteurs solution exacts. Chaque vecteur est stocké comme une
!>          colonne de la matrice XACT.
!
>

LDXAC

T 
!>          LDXACT est INTEGER
!>          La dimension principale du tableau XACT.  LDXACT >= max(1,N).
!
>

FER

R 
!>          FERR est un tableau DOUBLE PRECISION, dimension (NRHS)
!>          Les bornes estimées d'erreur directe pour chaque vecteur solution
!>          X. Si XTRUE est la solution exacte, FERR borne la magnitude
!>          du plus grand élément de (X - XTRUE) divisée par la magnitude
!>          du plus grand élément de X.
!
>

BER

R 
!>          BERR est un tableau DOUBLE PRECISION, dimension (NRHS)
!>          L'erreur relative arrière composante par composante de chaque
!>          vecteur solution (c'est-à-dire la plus petite variation relative
!>          de n'importe quel élément de A ou B qui rend X une solution exacte).
!
>

RESLT

S 
!>          RESLTS est un tableau DOUBLE PRECISION, dimension (2)
!>          Le maximum sur les NRHS vecteurs solution des rapports :
!>          RESLTS(1) = norm(X - XACT) / ( norm(X) * FERR )
!>          RESLTS(2) = BERR / ( NZ*EPS + (*) )
!
>
