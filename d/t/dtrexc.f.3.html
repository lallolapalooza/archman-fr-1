Documentation de la fonction/sous-routine

sous-routine dtrexc (caractere compq, entier n, double precision, dimension( ldt, * ) t, entier ldt, double precision, dimension( ldq, * ) q, entier ldq, entier ifst, entier ilst, double precision, dimension( * ) work, entier info)

DTREXC

But :

!>
!> DTREXC réordonne la factorisation de Schur réelle d'une matrice réelle
!> A = Q*T*Q**T, de sorte que le bloc diagonal de T avec l'indice de ligne IFST soit
!> déplacé à la ligne ILST.
!>
!> La forme de Schur réelle T est réordonnée par une transformation de similarité orthogonale
!> Z**T*T*Z, et éventuellement la matrice Q des vecteurs de Schur
!> est mise à jour en la post-multipliant par Z.
!>
!> T doit être en forme canonique de Schur (comme retournée par DHSEQR), c'est-à-dire,
!> triangulaire par blocs avec des blocs diagonaux de 1x1 et 2x2 ; chaque
!> bloc diagonal de 2x2 a ses éléments diagonaux égaux et ses
!> éléments hors diagonaux de signe opposé.
!>

Paramètres

COMPQ 
!>          COMPQ est CHARACTER*1
!>          = 'V':  met à jour la matrice Q des vecteurs de Schur ;
!>          = 'N':  ne met pas à jour Q.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice T. N >= 0.
!>          Si N == 0, les arguments ILST et IFST peuvent avoir n'importe quelle valeur.
!>

T

!>          T est un tableau DOUBLE PRECISION, dimension (LDT,N)
!>          En entrée, la matrice quasi-triangulaire supérieure T, en forme
!>          canonique de Schur.
!>          En sortie, la matrice quasi-triangulaire réordonnée, à nouveau
!>          en forme canonique de Schur.
!>

LDT

!>          LDT est INTEGER
!>          La dimension principale du tableau T. LDT >= max(1,N).
!>

Q

!>          Q est un tableau DOUBLE PRECISION, dimension (LDQ,N)
!>          En entrée, si COMPQ = 'V', la matrice Q des vecteurs de Schur.
!>          En sortie, si COMPQ = 'V', Q a été post-multipliée par la
!>          matrice de transformation orthogonale Z qui réordonne T.
!>          Si COMPQ = 'N', Q n'est pas référencée.
!>

LDQ

!>          LDQ est INTEGER
!>          La dimension principale du tableau Q.  LDQ >= 1, et si
!>          COMPQ = 'V', LDQ >= max(1,N).
!>

IFST

!>          IFST est INTEGER
!>

ILST

!>          ILST est INTEGER
!>
!>          Spécifie le réordonnancement des blocs diagonaux de T.
!>          Le bloc avec l'indice de ligne IFST est déplacé à la ligne ILST, par une
!>          séquence de transpositions entre blocs adjacents.
!>          En sortie, si IFST pointait à l'entrée sur la deuxième ligne d'un
!>          bloc 2x2, il est modifié pour pointer sur la première ligne ; ILST
!>          pointe toujours sur la première ligne du bloc dans sa position finale
!>          (qui peut différer de sa valeur d'entrée de +1 ou -1).
!>          1 <= IFST <= N ; 1 <= ILST <= N.
!>

WORK

!>          WORK est un tableau DOUBLE PRECISION, dimension (N)
!>

INFO

!>          INFO est INTEGER
!>          = 0:  sortie réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale
!>          = 1:  deux blocs adjacents étaient trop proches pour être échangés (le problème
!>                est très mal conditionné) ; T a peut-être été partiellement
!>                réordonné, et ILST pointe sur la première ligne de la
!>                position actuelle du bloc en cours de déplacement.
!>
