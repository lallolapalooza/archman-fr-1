A

But

: 
!>
!> DTRSNA estime les nombres de condition réciproques pour des
!> valeurs propres et/ou vecteurs propres à droite spécifiés d'une
!> matrice réelle quasi-triangulaire supérieure T (ou de toute
!> matrice Q*T*Q**T avec Q orthogonale).
!>
!> T doit être sous forme canonique de Schur (telle que renvoyée par
!> DHSEQR), c'est-à-dire triangulaire par blocs supérieure avec des
!> blocs diagonaux 1-par-1 et 2-par-2 ; chaque bloc diagonal 2-par-2
!> a ses éléments diagonaux égaux et ses éléments hors diagonaux de
!> signes opposés.
!
>

Paramètre

s
JOB 
!>          JOB est CHARACTER*1
!>          Spécifie si les nombres de condition sont requis pour
!>          les valeurs propres (S) ou les vecteurs propres (SEP) :
!>          = 'E' : pour les valeurs propres uniquement (S) ;
!>          = 'V' : pour les vecteurs propres uniquement (SEP) ;
!>          = 'B' : à la fois pour les valeurs propres et les
!>          vecteurs propres (S et SEP).
!
>

HOWMN

Y 
!>          HOWMNY est CHARACTER*1
!>          = 'A' : calculer les nombres de condition pour toutes les
!>          paires propres ;
!>          = 'S' : calculer les nombres de condition pour les paires
!>          propres sélectionnées spécifiées par le tableau SELECT.
!
>

SELEC

T 
!>          SELECT est un tableau LOGICAL, dimension (N)
!>          Si HOWMNY = 'S', SELECT spécifie les paires propres pour
!>          lesquelles les nombres de condition sont requis. Pour
!>          sélectionner les nombres de condition de la paire propre
!>          correspondant à une valeur propre réelle w(j), SELECT(j)
!>          doit être défini à .TRUE.. Pour sélectionner les nombres
!>          de condition correspondant à une paire conjuguée de
!>          valeurs propres w(j) et w(j+1), soit SELECT(j), soit
!>          SELECT(j+1), soit les deux, doivent être définis à
!>          .TRUE..
!>          Si HOWMNY = 'A', SELECT n'est pas référencé.
!
>

N 
!>          N est INTEGER
!>          L'ordre de la matrice T. N >= 0.
!
>

T 
!>          T est un tableau DOUBLE PRECISION, dimension (LDT,N)
!>          La matrice quasi-triangulaire supérieure T, sous forme
!>          canonique de Schur.
!
>

LD

T 
!>          LDT est INTEGER
!>          La dimension principale du tableau T. LDT >= max(1,N).
!
>

V

L 
!>          VL est un tableau DOUBLE PRECISION, dimension (LDVL,M)
!>          Si JOB = 'E' ou 'B', VL doit contenir les vecteurs
!>          propres à gauche de T (ou de toute Q*T*Q**T avec Q
!>          orthogonale), correspondant aux paires propres spécifiées
!>          par HOWMNY et SELECT. Les vecteurs propres doivent être
!>          stockés dans des colonnes consécutives de VL, tels que
!>          renvoyés par DHSEIN ou DTREVC.
!>          Si JOB = 'V', VL n'est pas référencé.
!
>

LDV

L 
!>          LDVL est INTEGER
!>          La dimension principale du tableau VL.
!>          LDVL >= 1 ; et si JOB = 'E' ou 'B', LDVL >= N.
!
>

V

R 
!>          VR est un tableau DOUBLE PRECISION, dimension (LDVR,M)
!>          Si JOB = 'E' ou 'B', VR doit contenir les vecteurs
!>          propres à droite de T (ou de toute Q*T*Q**T avec Q
!>          orthogonale), correspondant aux paires propres spécifiées
!>          par HOWMNY et SELECT. Les vecteurs propres doivent être
!>          stockés dans des colonnes consécutives de VR, tels que
!>          renvoyés par DHSEIN ou DTREVC.
!>          Si JOB = 'V', VR n'est pas référencé.
!
>

LDV

R 
!>          LDVR est INTEGER
!>          La dimension principale du tableau VR.
!>          LDVR >= 1 ; et si JOB = 'E' ou 'B', LDVR >= N.
!
>

S 
!>          S est un tableau DOUBLE PRECISION, dimension (MM)
!>          Si JOB = 'E' ou 'B', les nombres de condition
!>          réciproques des valeurs propres sélectionnées, stockés
!>          dans des éléments consécutifs du tableau. Pour une paire
!>          conjuguée de valeurs propres, deux éléments consécutifs
!>          de S sont définis à la même valeur. Ainsi S(j), SEP(j),
!>          et les j-ièmes colonnes de VL et VR correspondent tous à
!>          la même paire propre (mais pas en général à la j-ième
!>          paire propre, sauf si toutes les paires propres sont
!>          sélectionnées).
!>          Si JOB = 'V', S n'est pas référencé.
!
>

SE

P 
!>          SEP est un tableau DOUBLE PRECISION, dimension (MM)
!>          Si JOB = 'V' ou 'B', les nombres de condition
!>          réciproques estimés des vecteurs propres sélectionnés,
!>          stockés dans des éléments consécutifs du tableau. Pour un
!>          vecteur propre complexe, deux éléments consécutifs de SEP
!>          sont définis à la même valeur. Si les valeurs propres ne
!>          peuvent pas être réordonnées pour calculer SEP(j), SEP(j)
!>          est défini à 0 ; cela ne peut se produire que lorsque la
!>          vraie valeur serait de toute façon très petite.
!>          Si JOB = 'E', SEP n'est pas référencé.
!
>

M

M 
!>          MM est INTEGER
!>          Le nombre d'éléments dans les tableaux S (si JOB = 'E'
!>          ou 'B') et/ou SEP (si JOB = 'V' ou 'B'). MM >= M.
!
>

M 
!>          M est INTEGER
!>          Le nombre d'éléments des tableaux S et/ou SEP
!>          effectivement utilisés pour stocker les nombres de
!>          condition estimés.
!>          Si HOWMNY = 'A', M est défini à N.
!
>

WOR

K 
!>          WORK est un tableau DOUBLE PRECISION, dimension
!>          (LDWORK,N+6)
!>          Si JOB = 'E', WORK n'est pas référencé.
!
>

LDWOR

K 
!>          LDWORK est INTEGER
!>          La dimension principale du tableau WORK.
!>          LDWORK >= 1 ; et si JOB = 'V' ou 'B', LDWORK >= N.
!
>

IWOR

K 
!>          IWORK est un tableau INTEGER, dimension (2*(N-1))
!>          Si JOB = 'E', IWORK n'est pas référencé.
!
>

INF

O 
!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur
!>          illégale
!
>

Détails supplémentaires

: 
!>
!>  L'inverse du nombre de condition d'une valeur propre lambda est
!>  défini comme
!>
!>          S(lambda) = |v**T*u| / (norm(u)*norm(v))
!>
!>  où u et v sont les vecteurs propres à droite et à gauche de T
!>  correspondant à lambda ; v**T désigne la transposée de v, et
!>  norm(u) désigne la norme euclidienne. Ces nombres de condition
!>  réciproques sont toujours compris entre zéro (très mal conditionné)
!>  et un (très bien conditionné). Si n = 1, S(lambda) est défini
!>  comme étant 1.
!>
!>  Une borne d'erreur approximative pour une valeur propre calculée
!>  W(i) est donnée par
!>
!>                      EPS * norm(T) / S(i)
!>
!>  où EPS est la précision machine.
!>
!>  L'inverse du nombre de condition du vecteur propre à droite u
!>  correspondant à lambda est défini comme suit. Supposons
!>
!>              T = ( lambda  c  )
!>                  (   0    T22 )
!>
!>  Alors le nombre de condition réciproque est
!>
!>          SEP( lambda, T22 ) = sigma-min( T22 - lambda*I )
!>
!>  où sigma-min désigne la plus petite valeur singulière. Nous approchons
!>  la plus petite valeur singulière par l'inverse d'une estimation de la
!>  norme 1 de l'inverse de T22 - lambda*I. Si n = 1, SEP(1) est
!>  défini comme abs(T(1,1)).
!>
!>  Une borne d'erreur approchée pour un vecteur propre droit calculé VR(i)
!>  est donnée par
!>
!>                      EPS * norm(T) / SEP(i)
!
>
