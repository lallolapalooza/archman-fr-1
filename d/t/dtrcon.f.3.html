sous-programme dtrcon (caractère norm, caractère uplo, caractère diag, entier n, double précision, dimension( lda, * ) a, entier lda, double précision rcond, double précision, dimension( * ) work, entier, dimension( * ) iwork, entier info)

DTRCON

But:

!>
!> DTRCON estime l'inverse du nombre de condition d'une matrice
!> triangulaire A, soit dans la norme 1, soit dans la norme
!> de l'infini.
!>
!> La norme de A est calculée et une estimation de
!> norm(inv(A)) est obtenue, puis l'inverse du nombre de condition
!> est calculé comme suit :
!>    RCOND = 1 / ( norm(A) * norm(inv(A)) ).
!>

Paramètres

NORM 
!>          NORM est CHARACTER*1
!>          Spécifie si le nombre de condition en norme 1 ou en norme
!>          de l'infini est requis :
!>          = '1' ou 'O':  Norme 1 ;
!>          = 'I':         Norme de l'infini.
!>

UPLO

!>          UPLO est CHARACTER*1
!>          = 'U':  A est triangulaire supérieure ;
!>          = 'L':  A est triangulaire inférieure.
!>

DIAG

!>          DIAG est CHARACTER*1
!>          = 'N':  A est triangulaire non unitaire ;
!>          = 'U':  A est triangulaire unitaire.
!>

N

!>          N est un ENTIER
!>          L'ordre de la matrice A.  N >= 0.
!>

A

!>          A est un tableau de DOUBLE PRÉCISION, de dimension (LDA,N)
!>          La matrice triangulaire A.  Si UPLO = 'U', la partie
!>          supérieure triangulaire de taille N par N de A contient la
!>          matrice triangulaire supérieure, et la partie strictement
!>          inférieure triangulaire de A n'est pas référencée.  Si UPLO = 'L',
!>          la partie inférieure triangulaire de taille N par N de A contient
!>          la matrice triangulaire inférieure, et la partie strictement
!>          supérieure triangulaire de A n'est pas référencée.  Si DIAG = 'U',
!>          les éléments diagonaux de A ne sont pas non plus référencés et sont
!>          supposés être 1.
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

RCOND

!>          RCOND est DOUBLE PRÉCISION
!>          L'inverse du nombre de condition de la matrice A,
!>          calculé comme RCOND = 1/(norm(A) * norm(inv(A))).
!>

WORK

!>          WORK est un tableau de DOUBLE PRÉCISION, de dimension (3*N)
!>

IWORK

!>          IWORK est un tableau d'ENTIERS, de dimension (N)
!>

INFO

!>          INFO est un ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>
