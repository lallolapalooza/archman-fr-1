sous-programme dtrttp (uplo, n, a, lda, ap, info)
DTRTTP copie une matrice triangulaire du format complet standard (TR) vers le format compact standard (TP).

Documentation de la fonction/sous-programme

sous-programme dtrttp (caractère uplo, entier n, double précision, dimension( lda, * ) a, entier lda, double précision, dimension( * ) ap, entier info)

DTRTTP copie une matrice triangulaire du format complet standard (TR) vers le format compact standard (TP).

Objectif :

!>
!> DTRTTP copie une matrice triangulaire A du format complet (TR) vers le format
!> compact standard (TP).
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          = 'U' :  A est triangulaire supérieure.
!>          = 'L' :  A est triangulaire inférieure.
!>

N

!>          N est un ENTIER
!>          L'ordre des matrices AP et A.  N >= 0.
!>

A

!>          A est un tableau DOUBLE PRECISION, de dimension (LDA,N)
!>          À la sortie, la matrice triangulaire A.  Si UPLO = 'U', la partie
!>          supérieure triangulaire de N par N de A contient la partie
!>          triangulaire supérieure de la matrice A, et la partie strictement
!>          inférieure triangulaire de A n'est pas référencée. Si UPLO = 'L', la
!>          partie inférieure triangulaire de N par N de A contient la partie
!>          triangulaire inférieure de la matrice A, et la partie strictement
!>          supérieure triangulaire de A n'est pas référencée.
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

AP

!>          AP est un tableau DOUBLE PRECISION, de dimension (N*(N+1)/2)
!>          À la sortie, la matrice triangulaire supérieure ou inférieure A,
!>          compactée par colonne dans un tableau linéaire. La j-ième colonne de A est
!>          stockée dans le tableau AP comme suit :
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) pour 1<=i<=j;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) pour j<=i<=n.
!>

INFO

!>          INFO est un ENTIER
!>          = 0 :  succès de l'exécution
!>          < 0 :  si INFO = -i, le i-ième argument était invalide
!>
