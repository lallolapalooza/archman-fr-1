subroutine dtgsja (caractère jobu, caractère jobv, caractère jobq, entier m, entier p, entier n, entier k, entier l, double précision, dimension( lda, * ) a, entier lda, double précision, dimension( ldb, * ) b, entier ldb, double précision tola, double précision tolb, double précision, dimension( * ) alpha, double précision, dimension( * ) beta, double précision, dimension( ldu, * ) u, entier ldu, double précision, dimension( ldv, * ) v, entier ldv, double précision, dimension( ldq, * ) q, entier ldq, double précision, dimension( * ) work, entier ncycle, entier info)

DTGSJA

Objectif:

!>
!> DTGSJA calcule la décomposition en valeurs singulières généralisées (GSVD)
!> de deux matrices réelles triangulaires supérieures (ou trapézoïdales) A et B.
!>
!> À l'entrée, on suppose que les matrices A et B ont les formes suivantes,
!> qui peuvent être obtenues par la sous-routine de pré-traitement DGGSVP
!> à partir d'une matrice générale M-par-N A et d'une matrice P-par-N B :
!>
!>              N-K-L  K    L
!>    A =    K ( 0    A12  A13 ) si M-K-L >= 0;
!>           L ( 0     0   A23 )
!>       M-K-L ( 0     0    0  )
!>
!>            N-K-L  K    L
!>    A =  K ( 0    A12  A13 ) si M-K-L < 0;
!>       M-K ( 0     0   A23 )
!>
!>            N-K-L  K    L
!>    B =  L ( 0     0   B13 )
!>       P-L ( 0     0    0  )
!>
!> où la matrice K-par-K A12 et la matrice L-par-L B13 sont des matrices
!> triangulaires supérieures non singulières ; A23 est triangulaire supérieure
!> L-par-L si M-K-L >= 0, sinon A23 est trapézoïdale supérieure (M-K)-par-L.
!>
!> À la sortie,
!>
!>        U**T *A*Q = D1*( 0 R ),    V**T *B*Q = D2*( 0 R ),
!>
!> où U, V et Q sont des matrices orthogonales.
!> R est une matrice triangulaire supérieure non singulière, et D1 et D2 sont
!> des matrices « diagonales », qui sont des structures suivantes :
!>
!> Si M-K-L >= 0,
!>
!>                     K  L
!>        D1 =     K ( I  0 )
!>                 L ( 0  C )
!>             M-K-L ( 0  0 )
!>
!>                   K  L
!>        D2 = L   ( 0  S )
!>             P-L ( 0  0 )
!>
!>                N-K-L  K    L
!>   ( 0 R ) = K (  0   R11  R12 ) K
!>             L (  0    0   R22 ) L
!>
!> où
!>
!>   C = diag( ALPHA(K+1), ... , ALPHA(K+L) ),
!>   S = diag( BETA(K+1),  ... , BETA(K+L) ),
!>   C**2 + S**2 = I.
!>
!>   R est stocké dans A(1:K+L,N-K-L+1:N) à la sortie.
!>
!> Si M-K-L < 0,
!>
!>                K M-K K+L-M
!>     D1 =   K ( I  0    0   )
!>          M-K ( 0  C    0   )
!>
!>                  K M-K K+L-M
!>     D2 =   M-K ( 0  S    0   )
!>          K+L-M ( 0  0    I   )
!>            P-L ( 0  0    0   )
!>
!>                N-K-L  K   M-K  K+L-M
!> ( 0 R ) =    K ( 0    R11  R12  R13  )
!>           M-K ( 0     0   R22  R23  )
!>         K+L-M ( 0     0    0   R33  )
!>
!> où
!> C = diag( ALPHA(K+1), ... , ALPHA(M) ),
!> S = diag( BETA(K+1),  ... , BETA(M) ),
!> C**2 + S**2 = I.
!>
!> R = ( R11 R12 R13 ) est stocké dans A(1:M, N-K-L+1:N) et R33 est stocké
!>     (  0  R22 R23 )
!> dans B(M-K+1:L,N+M-K-L+1:N) à la sortie.
!>
!> Le calcul des matrices de transformation orthogonales U, V ou Q
!> est optionnel. Ces matrices peuvent être formées explicitement, ou elles
!> peuvent être multipliées à droite dans les matrices d'entrée U1, V1, ou Q1.
!>

Paramètres

JOBU 
!>          JOBU est CHARACTER*1
!>          = 'U':  U doit contenir une matrice orthogonale U1 à l'entrée, et
!>                  le produit U1*U est retourné ;
!>          = 'I':  U est initialisée à la matrice identité, et la
!>                  matrice orthogonale U est retournée ;
!>          = 'N':  U n'est pas calculée.
!>

JOBV

!>          JOBV est CHARACTER*1
!>          = 'V':  V doit contenir une matrice orthogonale V1 à l'entrée, et
!>                  le produit V1*V est retourné ;
!>          = 'I':  V est initialisée à la matrice identité, et la
!>                  matrice orthogonale V est retournée ;
!>          = 'N':  V n'est pas calculée.
!>

JOBQ

!>          JOBQ est CHARACTER*1
!>          = 'Q':  Q doit contenir une matrice orthogonale Q1 à l'entrée, et
!>                  le produit Q1*Q est retourné ;
!>          = 'I':  Q est initialisée à la matrice identité, et la
!>                  matrice orthogonale Q est retournée ;
!>          = 'N':  Q n'est pas calculée.
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

P

!>          P est INTEGER
!>          Le nombre de lignes de la matrice B.  P >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes des matrices A et B.  N >= 0.
!>

K

!>          K est INTEGER
!>

L

!>          L est INTEGER
!>
!>          K et L spécifient les sous-blocs dans les matrices d'entrée A et B :
!>          A23 = A(K+1:MIN(K+L,M),N-L+1:N) et B13 = B(1:L,N-L+1:N)
!>          de A et B, dont la GSVD va être calculée par DTGSJA.
!>          Voir Détails supplémentaires.
!>

A

!>          A est un tableau DOUBLE PRECISION, dimension (LDA,N)
!>          À l'entrée, la matrice M-par-N A.
!>          À la sortie, A(N-K+1:N,1:MIN(K+L,M) ) contient la matrice
!>          triangulaire R ou une partie de R. Voir Objectif pour les détails.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,M).
!>

B

!>          B est un tableau DOUBLE PRECISION, dimension (LDB,N)
!>          À l'entrée, la matrice P-par-N B.
!>          À la sortie, si nécessaire, B(M-K+1:L,N+M-K-L+1:N) contient
!>          une partie de R. Voir Objectif pour les détails.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B. LDB >= max(1,P).
!>

TOLA

!>          TOLA est DOUBLE PRECISION
!>

TOLB

!>          TOLB est DOUBLE PRECISION
!>
!>          TOLA et TOLB sont les critères de convergence pour la procédure
!>          d'itération de Jacobi-Kogbetliantz. Généralement, ils sont les
!>          mêmes que ceux utilisés dans l'étape de pré-traitement, par exemple
!>              TOLA = max(M,N)*norm(A)*MAZHEPS,
!>              TOLB = max(P,N)*norm(B)*MAZHEPS.
!>

ALPHA

!>          ALPHA est un tableau DOUBLE PRECISION, dimension (N)
!>

BETA

!>          BETA est un tableau DOUBLE PRECISION, dimension (N)
!>
!>          À la sortie, ALPHA et BETA contiennent les paires de valeurs
!>          singulières généralisées de A et B ;
!>            ALPHA(1:K) = 1,
!>            BETA(1:K)  = 0,
!>          et si M-K-L >= 0,
!>            ALPHA(K+1:K+L) = diag(C),
!>            BETA(K+1:K+L)  = diag(S),
!>          ou si M-K-L < 0,
!>            ALPHA(K+1:M)= C, ALPHA(M+1:K+L)= 0
!>            BETA(K+1:M) = S, BETA(M+1:K+L) = 1.
!>          De plus, si K+L < N,
!>            ALPHA(K+L+1:N) = 0 et
!>            BETA(K+L+1:N)  = 0.
!>

U

!>          U est un tableau DOUBLE PRECISION, dimension (LDU,M)
!>          À l'entrée, si JOBU = 'U', U

Détails supplémentaires :




!>
!>  DTGSJA utilise essentiellement une variante de l'algorithme de Kogbetliantz pour réduire
!>  la matrice triangulaire (ou trapézoïdale) A23 de dimension min(L,M-K)-par-L et la matrice B13 de dimension L-par-L
!>  à la forme :
!>
!>           U1**T *A13*Q1 = C1*R1 ; V1**T *B13*Q1 = S1*R1,
!>
!>  où U1, V1 et Q1 sont des matrices orthogonales, et Z**T est la transposée
!>  de Z. C1 et S1 sont des matrices diagonales satisfaisant
!>
!>                C1**2 + S1**2 = I,
!>
!>  et R1 est une matrice triangulaire supérieure non singulière de dimension L-par-L.
!>
