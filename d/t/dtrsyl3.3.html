DTRSYL

3

But

: 
!>
!>  DTRSYL3 résout l'équation matricielle de Sylvester réelle :
!>
!>     op(A)*X + X*op(B) = scale*C ou
!>     op(A)*X - X*op(B) = scale*C,
!>
!>  où op(A) = A ou A**T, et A et B sont tous deux quasi-triangulaires
!>  supérieurs. A est de dimension M par M et B de dimension N par N ;
!>  le membre de droite C et la solution X sont de dimension M par N ;
!>  et scale est un facteur d'échelle de sortie, défini <= 1 pour éviter
!>  le débordement dans X.
!>
!>  A et B doivent être sous forme canonique de Schur (comme renvoyé par
!>  DHSEQR), c'est-à-dire triangulaires par blocs supérieurs avec des
!>  blocs diagonaux de taille 1 par 1 et 2 par 2 ; chaque bloc diagonal
!>  de taille 2 par 2 a ses éléments diagonaux égaux et ses éléments
!>  hors diagonaux de signe opposé.
!>
!>  Il s'agit de la version par blocs de l'algorithme.
!
>

Paramètre

s
TRANA 
!>          TRANA est de type CHARACTER*1
!>          Spécifie l'option op(A) :
!>          = 'N' : op(A) = A    (pas de transposition)
!>          = 'T' : op(A) = A**T (transposition)
!>          = 'C' : op(A) = A**H (transposition conjuguée = transposition)
!
>

TRAN

B 
!>          TRANB est de type CHARACTER*1
!>          Spécifie l'option op(B) :
!>          = 'N' : op(B) = B    (pas de transposition)
!>          = 'T' : op(B) = B**T (transposition)
!>          = 'C' : op(B) = B**H (transposition conjuguée = transposition)
!
>

ISG

N 
!>          ISGN est de type INTEGER
!>          Spécifie le signe dans l'équation :
!>          = +1 : résout op(A)*X + X*op(B) = scale*C
!>          = -1 : résout op(A)*X - X*op(B) = scale*C
!
>

M 
!>          M est de type INTEGER
!>          L'ordre de la matrice A, et le nombre de lignes dans les
!>          matrices X et C. M >= 0.
!
>

N 
!>          N est de type INTEGER
!>          L'ordre de la matrice B, et le nombre de colonnes dans les
!>          matrices X et C. N >= 0.
!
>

A 
!>          A est un tableau de type DOUBLE PRECISION, dimension (LDA,M)
!>          La matrice quasi-triangulaire supérieure A, sous forme canonique de Schur.
!
>

LD

A 
!>          LDA est de type INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,M).
!
>

B 
!>          B est un tableau de type DOUBLE PRECISION, dimension (LDB,N)
!>          La matrice quasi-triangulaire supérieure B, sous forme canonique de Schur.
!
>

LD

B 
!>          LDB est de type INTEGER
!>          La dimension principale du tableau B. LDB >= max(1,N).
!
>

C 
!>          C est un tableau de type DOUBLE PRECISION, dimension (LDC,N)
!>          À l'entrée, la matrice C de dimension M par N, membre de droite.
!>          À la sortie, C est écrasée par la matrice solution X.
!
>

LD

C 
!>          LDC est de type INTEGER
!>          La dimension principale du tableau C. LDC >= max(1,M)
!
>

SCAL

E 
!>          SCALE est de type DOUBLE PRECISION
!>          Le facteur d'échelle, scale, défini <= 1 pour éviter le débordement dans X.
!
>

IWOR

K 
!>          IWORK est un tableau de type INTEGER, dimension (MAX(1,LIWORK))
!>          À la sortie, si INFO = 0, IWORK(1) renvoie la valeur optimale de LIWORK.
!
>

LIWOR

K 
!>          IWORK est de type INTEGER
!>          La dimension du tableau IWORK. LIWORK >=  ((M + NB - 1) / NB + 1)
!>          + ((N + NB - 1) / NB + 1), où NB est la taille de bloc optimale.
!>
!>          Si LIWORK = -1, une interrogation d'espace de travail est supposée ; la routine
!>          calcule uniquement la dimension optimale du tableau IWORK,
!>          renvoie cette valeur comme première entrée du tableau IWORK, et
!>          aucun message d'erreur lié à LIWORK n'est émis par XERBLA.
!
>

SWOR

K 
!>          SWORK est un tableau de type DOUBLE PRECISION, dimension (MAX(2, ROWS),
!>          MAX(1,COLS)).
!>          À la sortie, si INFO = 0, SWORK(1) renvoie la valeur optimale ROWS
!>          et SWORK(2) renvoie la valeur optimale COLS.
!
>

LDSWOR

K 
!>          LDSWORK est de type INTEGER
!>          LDSWORK >= MAX(2,ROWS), où ROWS = ((M + NB - 1) / NB + 1)
!>          et NB est la taille de bloc optimale.
!>
!>          Si LDSWORK = -1, une interrogation d'espace de travail est supposée ; la routine
!>          calcule uniquement les dimensions optimales de la matrice SWORK,
!>          renvoie ces valeurs comme première et deuxième entrée de la matrice SWORK,
!>          et aucun message d'erreur lié à LWORK n'est émis par XERBLA.
!
>

INF

O 
!>          INFO est de type INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          = 1 : A et B ont des valeurs propres communes ou très proches ; des valeurs
!>               perturbées ont été utilisées pour résoudre l'équation (mais les matrices
!>               A et B sont inchangées).
!
>
