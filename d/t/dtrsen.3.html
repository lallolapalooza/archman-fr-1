sous-routine dtrsen (character job, character compq, logical, dimension( * ) select, integer n, double precision, dimension( ldt, * ) t, integer ldt, double precision, dimension( ldq, * ) q, integer ldq, double precision, dimension( * ) wr, double precision, dimension( * ) wi, integer m, double precision s, double precision sep, double precision, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, integer liwork, integer

DTRSE

N

But

: 
!>
!> DTRSEN réordonne la factorisation de Schur réelle d'une matrice réelle
!> A = Q*T*Q**T, de sorte qu'un cluster d'eigenvalues sélectionné apparaisse dans
!> les blocs diagonaux principaux de la matrice quasi-triangulaire supérieure T,
!> et que les colonnes principales de Q forment une base orthonormale du
!> sous-espace invariant droit correspondant.
!>
!> Optionnellement, la routine calcule les nombres de condition réciproques du
!> cluster d'eigenvalues et/ou du sous-espace invariant.
!>
!> T doit être sous forme canonique de Schur (comme retourné par DHSEQR), c'est-à-dire,
!> triangulaire supérieure par blocs avec des blocs diagonaux de taille 1x1 et 2x2 ; chaque
!> bloc diagonal 2x2 a ses éléments diagonaux égaux et ses
!> éléments hors diagonaux de signes opposés.
!
>

Paramètre

s
JOB 
!>          JOB est CHARACTER*1
!>          Spécifie si les nombres de condition sont requis pour le
!>          cluster d'eigenvalues (S) ou le sous-espace invariant (SEP) :
!>          = 'N' : aucun ;
!>          = 'E' : pour les eigenvalues uniquement (S) ;
!>          = 'V' : pour le sous-espace invariant uniquement (SEP) ;
!>          = 'B' : pour les eigenvalues et le sous-espace invariant (S et
!>                 SEP).
!
>

COMP

Q 
!>          COMPQ est CHARACTER*1
!>          = 'V' : mettre à jour la matrice Q des vecteurs de Schur ;
!>          = 'N' : ne pas mettre à jour Q.
!
>

SELEC

T 
!>          SELECT est un tableau LOGICAL, dimension (N)
!>          SELECT spécifie les eigenvalues dans le cluster sélectionné. Pour
!>          sélectionner une eigenvalue réelle w(j), SELECT(j) doit être défini à
!>          .TRUE.. Pour sélectionner une paire conjuguée complexe d'eigenvalues
!>          w(j) et w(j+1), correspondant à un bloc diagonal 2x2,
!>          soit SELECT(j) ou SELECT(j+1) ou les deux doivent être définis à
!>          .TRUE. ; une paire conjuguée complexe d'eigenvalues doit être
!>          soit toutes les deux incluses dans le cluster, soit toutes les deux exclues.
!
>

N 
!>          N est INTEGER
!>          L'ordre de la matrice T. N >= 0.
!
>

T 
!>          T est un tableau DOUBLE PRECISION, dimension (LDT,N)
!>          À l'entrée, la matrice quasi-triangulaire supérieure T, sous forme
!>          canonique de Schur.
!>          À la sortie, T est écrasée par la matrice T réordonnée, à nouveau sous
!>          forme canonique de Schur, avec les eigenvalues sélectionnées dans les
!>          blocs diagonaux principaux.
!
>

LD

T 
!>          LDT est INTEGER
!>          La dimension principale du tableau T. LDT >= max(1,N).
!
>

Q 
!>          Q est un tableau DOUBLE PRECISION, dimension (LDQ,N)
!>          À l'entrée, si COMPQ = 'V', la matrice Q des vecteurs de Schur.
!>          À la sortie, si COMPQ = 'V', Q a été post-multipliée par la
!>          matrice de transformation orthogonale qui réordonne T ; les
!>          M premières colonnes de Q forment une base orthonormale pour le
!>          sous-espace invariant spécifié.
!>          Si COMPQ = 'N', Q n'est pas référencée.
!
>

LD

Q 
!>          LDQ est INTEGER
!>          La dimension principale du tableau Q.
!>          LDQ >= 1 ; et si COMPQ = 'V', LDQ >= N.
!
>

W

R 
!>          WR est un tableau DOUBLE PRECISION, dimension (N)
!
>

W

I 
!>          WI est un tableau DOUBLE PRECISION, dimension (N)
!>
!>          Les parties réelle et imaginaire, respectivement, des eigenvalues
!>          réordonnées de T. Les eigenvalues sont stockées dans le même
!>          ordre que sur la diagonale de T, avec WR(i) = T(i,i) et, si
!>          T(i:i+1,i:i+1) est un bloc diagonal 2x2, WI(i) > 0 et
!>          WI(i+1) = -WI(i). Notez que si une eigenvalue complexe est
!>          suffisamment mal conditionnée, alors sa valeur peut différer
!>          considérablement de sa valeur avant réordonnancement.
!
>

M 
!>          M est INTEGER
!>          La dimension du sous-espace invariant spécifié.
!>          0 < = M <= N.
!
>

S 
!>          S est DOUBLE PRECISION
!>          Si JOB = 'E' ou 'B', S est une borne inférieure sur le nombre
!>          de condition réciproque pour le cluster d'eigenvalues sélectionné.
!>          S ne peut pas sous-estimer le vrai nombre de condition réciproque
!>          de plus d'un facteur sqrt(N). Si M = 0 ou N, S = 1.
!>          Si JOB = 'N' ou 'V', S n'est pas référencé.
!
>

SE

P 
!>          SEP est DOUBLE PRECISION
!>          Si JOB = 'V' ou 'B', SEP est le nombre de condition réciproque
!>          estimé du sous-espace invariant spécifié. Si
!>          M = 0 ou N, SEP = norm(T).
!>          Si JOB = 'N' ou 'E', SEP n'est pas référencé.
!
>

WOR

K 
!>          WORK est un tableau DOUBLE PRECISION, dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) retourne le LWORK optimal.
!
>

LWOR

K 
!>          LWORK est INTEGER
!>          La dimension du tableau WORK.
!>          Si JOB = 'N', LWORK >= max(1,N) ;
!>          si JOB = 'E', LWORK >= max(1,M*(N-M)) ;
!>          si JOB = 'V' ou 'B', LWORK >= max(1,2*M*(N-M)).
!>
!>          Si LWORK = -1, alors une interrogation d'espace de travail est supposée ; la routine
!>          calcule uniquement la taille optimale du tableau WORK, retourne
!>          cette valeur comme la première entrée du tableau WORK, et aucun message
!>          d'erreur lié à LWORK n'est émis par XERBLA.
!
>

IWOR

K 
!>          IWORK est un tableau INTEGER, dimension (MAX(1,LIWORK))
!>          À la sortie, si INFO = 0, IWORK(1) retourne le LIWORK optimal.
!
>

LIWOR

K 
!>          LIWORK est INTEGER
!>          La dimension du tableau IWORK.
!>          Si JOB = 'N' ou 'E', LIWORK >= 1 ;
!>          si JOB = 'V' ou 'B', LIWORK >= max(1,M*(N-M)).
!>
!>          Si LIWORK = -1, alors une interrogation d'espace de travail est supposée ; la
!>          routine calcule uniquement la taille optimale du tableau IWORK,
!>          retourne cette valeur comme la première entrée du tableau IWORK, et
!>          aucun message d'erreur lié à LIWORK n'est émis par XERBLA.
!
>

INF

O 
!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          = 1 : le réordonnancement de T a échoué car certaines eigenvalues sont trop
!>               proches pour être séparées (le problème est très mal conditionné) ;
!>               T peut avoir été partiellement réordonnée, et WR et WI
!>               contiennent les eigenvalues dans le même ordre que dans T ; S et
!>               SEP (si demandés) sont mis à zéro.
!
>

Détails supplémentaires

: 
!>
!>  DTRSEN rassemble d'abord les eigenvalues sélectionnées en calculant une
!>  transformation orthogonale Z pour les déplacer dans le coin supérieur gauche de T.
!>  Danser mots, les valeurs propres sélectionnées sont les valeurs propres de T11
!>  telles que :
!>
!>          Z**T * T * Z = ( T11 T12 ) n1
!>                         (  0  T22 ) n2
!>                            n1  n2
!>
!>  où N = n1+n2 et Z**T désigne la transposée de Z. Les n1 premières
!>  colonnes de Z engendrent le sous-espace invariant spécifié de T.
!>
!>  Si T provient de la factorisation de Schur réelle de la matrice
!>  A = Q*T*Q**T, alors la factorisation de Schur réelle réordonnée de A
!>  est donnée par A = (Q*Z)*(Z**T*T*Z)*(Q*Z)**T, et les n1 premières
!>  colonnes de Q*Z engendrent le sous-espace invariant correspondant de A.
!>
!>  Le conditionnement réciproque de la moyenne des valeurs propres de
!>  T11 peut être renvoyé dans S. S est compris entre 0 (très mal
!>  conditionné) et 1 (très bien conditionné). Il est calculé comme suit.
!>  D'abord, on calcule R tel que
!>
!>                         P = ( I  R ) n1
!>                             ( 0  0 ) n2
!>                               n1 n2
!>
!>  soit le projecteur sur le sous-espace invariant associé à T11.
!>  R est la solution de l'équation de Sylvester :
!>
!>                        T11*R - R*T22 = T12.
!>
!>  Soit F-norm(M) la norme de Frobenius de M et 2-norm(M) la
!>  2-norme de M. Alors S est calculé comme la borne inférieure
!>
!>                      (1 + F-norm(R)**2)**(-1/2)
!>
!>  sur le réciproque de 2-norm(P), le vrai conditionnement réciproque.
!>  S ne peut pas sous-estimer 1 / 2-norm(P) d'un facteur supérieur à
!>  sqrt(N).
!>
!>  Une borne d'erreur approchée pour la moyenne calculée des
!>  valeurs propres de T11 est
!>
!>                         EPS * norm(T) / S
!>
!>  où EPS est la précision machine.
!>
!>  Le conditionnement réciproque du sous-espace invariant à droite
!>  engendré par les n1 premières colonnes de Z (ou de Q*Z) est renvoyé
!>  dans SEP. SEP est défini comme la séparation de T11 et T22 :
!>
!>                     sep( T11, T22 ) = sigma-min( C )
!>
!>  où sigma-min(C) est la plus petite valeur singulière de la
!>  matrice n1*n2 par n1*n2
!>
!>     C  = kprod( I(n2), T11 ) - kprod( transpose(T22), I(n1) )
!>
!>  I(m) est une matrice identité m par m, et kprod désigne le produit
!>  de Kronecker. Nous estimons sigma-min(C) par le réciproque d'une
!>  estimation de la 1-norme de inverse(C). Le vrai réciproque de la
!>  1-norme de inverse(C) ne peut pas différer de sigma-min(C) d'un
!>  facteur supérieur à sqrt(n1*n2).
!>
!>  Quand SEP est petit, de petites modifications de T peuvent causer de
!>  grands changements dans le sous-espace invariant. Une borne approchée
!>  sur l'erreur angulaire maximale dans le sous-espace invariant à
!>  droite calculé est
!>
!>                      EPS * norm(T) / SEP
!
>
