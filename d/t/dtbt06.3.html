sous-routine dtbt06 (double precision rcond, double precision rcondc, character uplo, character diag, integer n, integer kd, double precision, dimension( ldab, * ) ab, integer ldab, double precision, dimension( * ) work, double precision rat)

DTBT06

But:

!>
!> DTBT06 calcule un ratio de test comparant RCOND (le nombre de condition
!> réciproque d'une matrice triangulaire A) et RCONDC, l'estimation calculée
!> par DTBCON. L'information sur la matrice triangulaire A est utilisée si une
!> estimation est nulle et l'autre non nulle pour décider si le sous-dépassement
!> dans l'estimation est justifié.
!>

Paramètres

RCOND 
!>          RCOND est DOUBLE PRECISION
!>          L'estimation du nombre de condition réciproque obtenue en formant
!>          l'inverse explicite de la matrice A et en calculant
!>          RCOND = 1/( norm(A) * norm(inv(A)) ).
!>

RCONDC

!>          RCONDC est DOUBLE PRECISION
!>          L'estimation du nombre de condition réciproque calculée par
!>          DTBCON.
!>

UPLO

!>          UPLO est CHARACTER
!>          Spécifie si la matrice A est triangulaire supérieure ou inférieure.
!>          = 'U':  Triangulaire supérieure
!>          = 'L':  Triangulaire inférieure
!>

DIAG

!>          DIAG est CHARACTER
!>          Spécifie si la matrice A est unie triangulaire ou non.
!>          = 'N':  Non unie triangulaire
!>          = 'U':  Unie triangulaire
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

KD

!>          KD est INTEGER
!>          Le nombre de superdiagonales ou de sous-diagonales de la
!>          matrice bande triangulaire A.  KD >= 0.
!>

AB

!>          AB est un tableau DOUBLE PRECISION, dimension (LDAB,N)
!>          La matrice bande triangulaire supérieure ou inférieure A, stockée
!>          dans les kd+1 premières lignes du tableau. La j-ième colonne de A
!>          est stockée dans la j-ième colonne du tableau AB comme suit :
!>          si UPLO = 'U', AB(kd+1+i-j,j) = A(i,j) pour max(1,j-kd)<=i<=j;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) pour j<=i<=min(n,j+kd).
!>

LDAB

!>          LDAB est INTEGER
!>          La dimension principale du tableau AB.  LDAB >= KD+1.
!>

WORK

!>          WORK est un tableau DOUBLE PRECISION, dimension (N)
!>

RAT

!>          RAT est DOUBLE PRECISION
!>          Le ratio de test.  Si RCOND et RCONDC sont tous deux non nuls,
!>             RAT = MAX( RCOND, RCONDC )/MIN( RCOND, RCONDC ) - 1.
!>          Si RAT = 0, les deux estimations sont exactement les mêmes.
!>
