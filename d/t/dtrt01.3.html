Documentation de la fonction/sous-routine

subroutine dtrt01 (character uplo, character diag, integer n, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( ldainv, * ) ainv, integer ldainv, double precision rcond, double precision, dimension( * ) work, double precision resid)

DTRT01

Objectif:

!>
!> DTRT01 calcule le résidu pour une matrice triangulaire A multipliée par son
!> inverse :
!>    RESID = norm( A*AINV - I ) / ( N * norm(A) * norm(AINV) * EPS ),
!> où EPS est l'epsilon machine.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si la matrice A est triangulaire supérieure ou inférieure.
!>          = 'U':  Triangulaire supérieure
!>          = 'L':  Triangulaire inférieure
!>

DIAG

!>          DIAG est CHARACTER*1
!>          Spécifie si la matrice A est unitaire ou non.
!>          = 'N':  Non unitaire
!>          = 'U':  Unitaire
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

A

!>          A est un tableau DOUBLE PRECISION, de dimension (LDA,N)
!>          La matrice triangulaire A.  Si UPLO = 'U', la partie supérieure
!>          triangulaire n x n principale du tableau A contient la matrice
!>          triangulaire supérieure, et la partie triangulaire inférieure
!>          strictement de A n'est pas référencée.  Si UPLO = 'L', la partie
!>          inférieure triangulaire n x n principale du tableau A contient
!>          la matrice triangulaire inférieure, et la partie supérieure
!>          strictement de A n'est pas référencée.  Si DIAG = 'U', les éléments
!>          diagonaux de A ne sont pas non plus référencés et sont supposés
!>          être 1.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

AINV

!>          AINV est un tableau DOUBLE PRECISION, de dimension (LDAINV,N)
!>          En entrée, l'inverse (triangulaire) de la matrice A, dans le
!>          même format de stockage que A.
!>          En sortie, le contenu de AINV est détruit.
!>

LDAINV

!>          LDAINV est INTEGER
!>          La dimension principale du tableau AINV.  LDAINV >= max(1,N).
!>

RCOND

!>          RCOND est DOUBLE PRECISION
!>          Le nombre de condition inversé de A, calculé comme
!>          1/(norm(A) * norm(AINV)).
!>

WORK

!>          WORK est un tableau DOUBLE PRECISION, de dimension (N)
!>

RESID

!>          RESID est DOUBLE PRECISION
!>          norm(A*AINV - I) / ( N * norm(A) * norm(AINV) * EPS )
!>
