sous-routine dtrt05 (character uplo, character trans, character diag, integer n, integer nrhs, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( ldb, * ) b, integer ldb, double precision, dimension( ldx, * ) x, integer ldx, double precision, dimension( ldxact, * ) xact, integer ldxact, double precision, dimension( * ) ferr, double precision, dimension( * ) berr, double precision, dimension( * )

DTRT0

5

But

: 
!>
!> DTRT05 teste les bornes d'erreur issues de l'affinement itératif pour la
!> solution calculée d'un système d'équations A*X = B, où A est une
!> matrice triangulaire n par n.
!>
!> RESLTS(1) = test de la borne d'erreur
!>           = norm(X - XACT) / ( norm(X) * FERR )
!>
!> Une grande valeur est retournée si ce rapport n'est pas inférieur à un.
!>
!> RESLTS(2) = résidu de la routine d'affinement itératif
!>           = le maximum de BERR / ( (n+1)*EPS + (*) ), où
!>             (*) = (n+1)*UNFL / (min_i (abs(A)*abs(X) +abs(b))_i )
!
>

Paramètre

s
UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si la matrice A est triangulaire supérieure ou inférieure.
!>          = 'U':  Triangulaire supérieure
!>          = 'L':  Triangulaire inférieure
!
>

TRAN

S 
!>          TRANS est CHARACTER*1
!>          Spécifie la forme du système d'équations.
!>          = 'N':  A * X = B  (Pas de transposition)
!>          = 'T':  A'* X = B  (Transposition)
!>          = 'C':  A'* X = B  (Transposition conjuguée = Transposition)
!
>

DIA

G 
!>          DIAG est CHARACTER*1
!>          Spécifie si la matrice A est triangulaire unitaire ou non.
!>          = 'N':  Triangulaire non unitaire
!>          = 'U':  Triangulaire unitaire
!
>

N 
!>          N est INTEGER
!>          Le nombre de lignes des matrices X, B et XACT, et l'ordre
!>          de la matrice A.  N >= 0.
!
>

NRH

S 
!>          NRHS est INTEGER
!>          Le nombre de colonnes des matrices X, B et XACT.
!>          NRHS >= 0.
!
>

A 
!>          A est un tableau DOUBLE PRECISION, dimension (LDA,N)
!>          La matrice triangulaire A.  Si UPLO = 'U', la partie triangulaire
!>          supérieure n par n principale du tableau A contient la matrice
!>          triangulaire supérieure, et la partie strictement triangulaire
!>          inférieure de A n'est pas référencée.  Si UPLO = 'L', la partie
!>          triangulaire inférieure n par n principale du tableau A contient
!>          la matrice triangulaire inférieure, et la partie strictement
!>          triangulaire supérieure de A n'est pas référencée.  Si DIAG = 'U',
!>          les éléments diagonaux de A ne sont pas non plus référencés et
!>          sont supposés être égaux à 1.
!
>

LD

A 
!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!
>

B 
!>          B est un tableau DOUBLE PRECISION, dimension (LDB,NRHS)
!>          Les vecteurs du second membre pour le système d'équations
!>          linéaires.
!
>

LD

B 
!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!
>

X 
!>          X est un tableau DOUBLE PRECISION, dimension (LDX,NRHS)
!>          Les vecteurs solution calculés.  Chaque vecteur est stocké comme
!>          une colonne de la matrice X.
!
>

LD

X 
!>          LDX est INTEGER
!>          La dimension principale du tableau X.  LDX >= max(1,N).
!
>

XAC

T 
!>          XACT est un tableau DOUBLE PRECISION, dimension (LDX,NRHS)
!>          Les vecteurs solution exacts.  Chaque vecteur est stocké comme
!>          une colonne de la matrice XACT.
!
>

LDXAC

T 
!>          LDXACT est INTEGER
!>          La dimension principale du tableau XACT.  LDXACT >= max(1,N).
!
>

FER

R 
!>          FERR est un tableau DOUBLE PRECISION, dimension (NRHS)
!>          Les bornes estimées d'erreur directe pour chaque vecteur
!>          solution X.  Si XTRUE est la solution exacte, FERR borne la
!>          magnitude de la plus grande entrée de (X - XTRUE) divisée par
!>          la magnitude de la plus grande entrée de X.
!
>

BER

R 
!>          BERR est un tableau DOUBLE PRECISION, dimension (NRHS)
!>          L'erreur relative arrière composante par composante de chaque
!>          vecteur solution (c'est-à-dire la plus petite variation relative
!>          de n'importe quelle entrée de A ou B qui rend X une solution
!>          exacte).
!
>

RESLT

S 
!>          RESLTS est un tableau DOUBLE PRECISION, dimension (2)
!>          Le maximum sur les NRHS vecteurs solution des rapports :
!>          RESLTS(1) = norm(X - XACT) / ( norm(X) * FERR )
!>          RESLTS(2) = BERR / ( (n+1)*EPS + (*) )
!
>
