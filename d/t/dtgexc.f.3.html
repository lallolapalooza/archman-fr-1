Documentation de la fonction/sous-routine

subroutine dtgexc (logical wantq, logical wantz, integer n, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( ldb, * ) b, integer ldb, double precision, dimension( ldq, * ) q, integer ldq, double precision, dimension( ldz, * ) z, integer ldz, integer ifst, integer ilst, double precision, dimension( * ) work, integer lwork, integer info)

DTGEXC

But :

!>
!> DTGEXC réordonne la décomposition de Schur réelle généralisée d'une
!> paire de matrices réelles (A,B) en utilisant une transformation
!> d'équivalence orthogonale
!>
!>                (A, B) = Q * (A, B) * Z**T,
!>
!> de sorte que le bloc diagonal de (A, B) dont l'indice de ligne est
!> IFST soit déplacé à la ligne ILST.
!>
!> (A, B) doit être sous forme canonique de Schur réelle généralisée
!> (telle que renvoyée par DGGES), c'est-à-dire que A est triangulaire
!> supérieure par blocs avec des blocs diagonaux de taille 1 par 1 et
!> 2 par 2. B est triangulaire supérieure.
!>
!> En option, les matrices Q et Z des vecteurs de Schur généralisés
!> sont mises à jour.
!>
!>        Q(in) * A(in) * Z(in)**T = Q(out) * A(out) * Z(out)**T
!>        Q(in) * B(in) * Z(in)**T = Q(out) * B(out) * Z(out)**T
!>
!>

Paramètres

WANTQ 
!>          WANTQ est de type LOGICAL
!>          .TRUE. : mettre à jour la matrice de transformation gauche Q ;
!>          .FALSE. : ne pas mettre à jour Q.
!>

WANTZ

!>          WANTZ est de type LOGICAL
!>          .TRUE. : mettre à jour la matrice de transformation droite Z ;
!>          .FALSE. : ne pas mettre à jour Z.
!>

N

!>          N est de type INTEGER
!>          L'ordre des matrices A et B. N >= 0.
!>

A

!>          A est un tableau de type DOUBLE PRECISION, dimension (LDA,N)
!>          À l'entrée, la matrice A sous forme canonique de Schur réelle
!>          généralisée.
!>          À la sortie, la matrice A mise à jour, de nouveau sous forme
!>          canonique de Schur réelle généralisée.
!>

LDA

!>          LDA est de type INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,N).
!>

B

!>          B est un tableau de type DOUBLE PRECISION, dimension (LDB,N)
!>          À l'entrée, la matrice B sous forme canonique de Schur réelle
!>          généralisée (A,B).
!>          À la sortie, la matrice B mise à jour, de nouveau sous forme
!>          canonique de Schur réelle généralisée (A,B).
!>

LDB

!>          LDB est de type INTEGER
!>          La dimension principale du tableau B. LDB >= max(1,N).
!>

Q

!>          Q est un tableau de type DOUBLE PRECISION, dimension (LDQ,N)
!>          À l'entrée, si WANTQ = .TRUE., la matrice orthogonale Q.
!>          À la sortie, la matrice Q mise à jour.
!>          Si WANTQ = .FALSE., Q n'est pas référencée.
!>

LDQ

!>          LDQ est de type INTEGER
!>          La dimension principale du tableau Q. LDQ >= 1.
!>          Si WANTQ = .TRUE., LDQ >= N.
!>

Z

!>          Z est un tableau de type DOUBLE PRECISION, dimension (LDZ,N)
!>          À l'entrée, si WANTZ = .TRUE., la matrice orthogonale Z.
!>          À la sortie, la matrice Z mise à jour.
!>          Si WANTZ = .FALSE., Z n'est pas référencée.
!>

LDZ

!>          LDZ est de type INTEGER
!>          La dimension principale du tableau Z. LDZ >= 1.
!>          Si WANTZ = .TRUE., LDZ >= N.
!>

IFST

!>          IFST est de type INTEGER
!>

ILST

!>          ILST est de type INTEGER
!>          Spécifient le réordonnancement des blocs diagonaux de (A, B).
!>          Le bloc dont l'indice de ligne est IFST est déplacé à la
!>          ligne ILST, par une séquence d'échanges entre blocs adjacents.
!>          À la sortie, si IFST pointait à l'entrée vers la deuxième
!>          ligne d'un bloc 2 par 2, il est modifié pour pointer vers la
!>          première ligne ; ILST pointe toujours vers la première ligne
!>          du bloc dans sa position finale (ce qui peut différer de sa
!>          valeur d'entrée de +1 ou -1). 1 <= IFST, ILST <= N.
!>

WORK

!>          WORK est un tableau de type DOUBLE PRECISION, dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) renvoie la valeur optimale de LWORK.
!>

LWORK

!>          LWORK est de type INTEGER
!>          La dimension du tableau WORK.
!>          LWORK >= 1 lorsque N <= 1, sinon LWORK >= 4*N + 16.
!>
!>          Si LWORK = -1, une interrogation d'espace de travail est
!>          supposée ; la routine calcule uniquement la taille optimale
!>          du tableau WORK, renvoie cette valeur comme première entrée
!>          du tableau WORK, et aucun message d'erreur lié à LWORK n'est
!>          émis par XERBLA.
!>

INFO

!>          INFO est de type INTEGER
!>           =0 : sortie réussie.
!>           <0 : si INFO = -i, le i-ème argument avait une valeur illégale.
!>           =1 : La paire de matrices (A, B) transformée serait trop
!>                éloignée de la forme de Schur généralisée ; le
!>                problème est mal conditionné. (A, B) peut avoir été
!>                partiellement réordonnée, et ILST pointe vers la
!>                première ligne de la position actuelle du bloc en
!>                cours de déplacement.
!>
