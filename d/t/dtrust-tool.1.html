NOM

dtrust-tool - affiche des informations sur les cartes de signature D-Trust et supprime la protection de transport

SYNTAXE

dtrust-tool [OPTIONS]

DESCRIPTION

L'utilitaire dtrust-tool est utilisé pour afficher des informations sur les cartes de signature D-Trust et pour supprimer la protection de transport initiale.

OPTIONS

--check-transport-protection, -c

Dans l'état de livraison, la carte est verrouillée par une protection dite de transport. Cette option permet de vérifier si la protection de transport est toujours en vigueur. La PIN de signature ne peut être utilisée que si la protection de transport est supprimée.

Initialement, la protection de transport doit être intacte. Si vous recevez une nouvelle carte et que la protection de transport a déjà été brisée, n'utilisez pas cette carte et contactez le producteur pour obtenir des conseils supplémentaires.

Si vous avez supprimé la protection de transport, il est normal que dtrust-tool signale la protection de transport comme étant brisée. C'est l'état de fonctionnement normal. Cela ne signifie pas que votre carte est défectueuse.

--help, -h

Affiche le message d'aide à l'écran.

--reader arg, -r arg

Numéro du lecteur à utiliser. Par défaut, le premier lecteur avec une carte présente est utilisé. Si arg est une ATR, le lecteur avec une carte correspondante sera choisi.

--pin-status, -s

Affiche l'état des différentes PIN. La PIN du détenteur de carte est utilisée pour les signatures avancées et le déchiffrement. Elle n'est définie que pour les cartes de signature, mais pas pour les cartes de scellage. La PIN de signature est utilisée pour les signatures qualifiées. Elle ne peut être utilisée que si elle est déverrouillée en présentant la PIN de transport. Une fois la PIN de transport utilisée, elle ne peut plus l'être. La PUK est utilisée pour déverrouiller les PIN qui ont été saisies incorrectement plusieurs fois.

--unlock-transport-protection, -u

Cette commande supprime la protection de transport. Elle demande d'abord la PIN de transport, puis la nouvelle valeur de la PIN de signature deux fois.

--verbose, -v

Rend dtrust-tool plus verbeux. Spécifiez ce drapeau plusieurs fois pour activer la sortie de débogage dans la bibliothèque opensc.

--wait, -w

Indique à dtrust-tool d'attendre que le jeton soit inséré dans le lecteur.
