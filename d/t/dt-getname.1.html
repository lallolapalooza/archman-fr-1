NOM

dt-getname - programme de test en ligne de commande pour la fonction val_getnameinfo()

SYNTAXE

dt-getname [options] adresse

DESCRIPTION

Cet utilitaire est un wrapper en ligne de commande autour de la fonction val_getnameinfo(). Il appelle la fonction val_getnameinfo() avec les arguments de la ligne de commande fournis et affiche les informations d'hôte et de service renvoyées pour le nom de nœud donné, avec une valeur d'état de validation.

Le statut de sortie de ce programme est 1 si la réponse reçue est fiable, 2 si la réponse reçue est validée, et -1 en cas d'erreur. Le programme renvoie 0 si aucune validation n'a été effectuée ou si le résultat n'était ni fiable ni validé. Les valeurs d'état fiable et validé sont obtenues à l'aide des fonctions val_istrusted() et val_isvalidated() de libval(3).

OPTIONS

-p, --port
Utiliser le port fourni. Si un port est spécifié, les informations de service ne sont pas recherchées.
-F
Utiliser le drapeau NI_NOFQDN.
-H
Utiliser le drapeau NI_NUMERICHOST.
-N
Utiliser le drapeau NI_NAMEREQD.
-S
Utiliser le drapeau NI_NUMERICSERV.
-D
Utiliser le drapeau NI_DGRAM.
-o, --output=<niveau-debug>:<type-dest>[:<options-dest>]
<niveau-debug> est de 1 à 7, correspondant aux niveaux syslog ALERT-DEBUG <type-dest> est l'un des suivants : file, net, syslog, stderr, stdout <options-dest> dépend de <type-dest>
file:<nom-fichier> (ouvert en mode ajout)
net[:<nom-hôte>:<port-hôte>] (127.0.0.1:1053
syslog[:facility] (0-23 (par défaut 1 USER))
-h, --help
Afficher l'aide et quitter.
