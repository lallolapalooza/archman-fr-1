NOM

dt-danechk - valider les enregistrements TLSA par rapport aux certificats SSL.

SYNTAXE

dt-danechk [options] NOM_DOMAINE

DESCRIPTION

dt-danechk est un outil de diagnostic qui peut être utilisé pour tester la validité d'un certificat SSL/TLS par rapport à l'enregistrement TLSA publié dans le DNS. Pour plus d'informations sur TLSA et DANE, voir la RFC 6698.

OPTIONS

-h, --help
Afficher l'aide et quitter.
-l label, --label=label
Cette option peut être utilisée pour spécifier l'étiquette de politique de validation. Si cette option n'est pas fournie, la politique de validation par défaut est utilisée.
-x proto, --proto proto
Spécifie le protocole associé au certificat TLSA. Les valeurs possibles pour le champ proto sont :
  • tcp Protocole TCP
  • udp Protocole UDP
  • sc Protocole SCTP (non pris en charge)

La valeur par défaut pour proto est tcp.

-p port, --port=port
Spécifie le port associé au certificat TLSA. La valeur par défaut pour port est 443.
-o, --output=<niveau-debug>:<type-destination>[:<options-destination>]
<niveau-debug> est 1-7, correspondant aux niveaux syslog ALERTE-DEBUG <type-destination> est l'un des suivants : file, net, syslog, stderr, stdout <options-destination> dépend de <type-destination>
file:<nom-fichier> (ouvert en mode ajout)
net[:<nom-hôte>:<port-hôte>] (127.0.0.1:1053
syslog[:facility] (0-23 (par défaut 1 USER))
-s, --sync
Effectuer des recherches synchrones. La valeur par défaut est d'effectuer des recherches asynchrones.
-v FICHIER, --dnsval-conf=FICHIER
Cette option peut être utilisée pour spécifier l'emplacement du fichier de configuration dnsval.conf.
-r FICHIER, --resolv-conf=FICHIER
Cette option peut être utilisée pour spécifier l'emplacement du fichier de configuration resolv.conf contenant les serveurs de noms à utiliser pour les recherches.
-i FICHIER, --root-hints=FICHIER
Cette option peut être utilisée pour spécifier l'emplacement du fichier de configuration root.hints, contenant les serveurs de noms racine. Ceci n'est utilisé que lorsqu'aucun serveur de noms n'est trouvé et que dt-validate doit effectuer lui-même des recherches récursives.
-V, --version
Afficher la version et quitter.
