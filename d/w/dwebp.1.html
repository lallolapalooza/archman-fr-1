NOM

dwebp - décompresser un fichier WebP en un fichier image

SYNTAXE

dwebp [options] fichier_entree.webp

DESCRIPTION

Cette page de manuel documente la commande dwebp.

dwebp décompresse les fichiers WebP en images PNG, PAM, PPM ou PGM. Remarque : les fichiers WebP animés ne sont pas pris en charge.

OPTIONS

Les options de base sont :

-h
Afficher le résumé d'utilisation.
-version
Afficher le numéro de version (au format majeur.mineur.révision) et quitter.
-o chaîne
Spécifier le nom du fichier de sortie (au format PNG par défaut). L'utilisation de "-" comme nom de sortie dirigera la sortie vers 'stdout'.
-- chaîne
Spécifier explicitement le fichier d'entrée. Cette option est utile si le fichier d'entrée commence par un "-", par exemple. Cette option doit apparaître en dernier. Toute autre option après sera ignorée. Si le fichier d'entrée est "-", les données seront lues depuis stdin au lieu d'un fichier.
-bmp
Changer le format de sortie en BMP non compressé.
-tiff
Changer le format de sortie en TIFF non compressé.
-pam
Changer le format de sortie en PAM (conserve la transparence).
-ppm
Changer le format de sortie en PPM (rejette la transparence).
-pgm
Changer le format de sortie en PGM. La sortie consiste en des échantillons de luminance/chrominance au lieu de RVB, en utilisant la disposition IMC4. Cette option est principalement à des fins de vérification et de débogage.
-yuv
Changer le format de sortie en YUV brut. La sortie consiste en des échantillons de luminance/chrominance-U/chrominance-V au lieu de RVB, enregistrés séquentiellement comme des plans individuels. Cette option est principalement à des fins de vérification et de débogage.
-nofancy
Ne pas utiliser l'upscaler sophistiqué pour YUV420. Cela peut entraîner des bords dentelés (en particulier les bords rouges), mais devrait être plus rapide.
-nofilter
Ne pas utiliser le processus de filtrage en boucle même s'il est requis par le flux binaire. Cela peut produire des blocs visibles sur la sortie non conforme, mais cela accélérera le décodage.
-dither force
Spécifier une force de tramage entre 0 et 100. Le tramage est un effet de post-traitement appliqué aux composantes chromatiques dans la compression avec perte. Il aide à lisser les dégradés et à éviter les artefacts de banding.
-alpha_dither
Si le fichier compressé contient un plan de transparence qui a été quantifié pendant la compression, ce drapeau permettra de tramé le plan reconstruit afin de générer des dégradés de transparence plus lisses.
-nodither
Désactiver tout tramage (par défaut).
-mt
Utiliser le multithreading pour le décodage, si possible.
-crop position_x position_y largeur hauteur
Recadrer l'image décodée sur un rectangle dont le coin supérieur gauche est aux coordonnées (position_x, position_y) et dont la taille est largeur x hauteur. Cette zone de recadrage doit être entièrement contenue dans le rectangle source. Le coin supérieur gauche sera aligné sur des coordonnées paires si nécessaire. Cette option est destinée à réduire la mémoire nécessaire pour recadrer de grandes images. Remarque : le recadrage est appliqué avant toute mise à l'échelle.
-flip
Retourner l'image décodée verticalement (peut être utile pour les textures OpenGL par exemple).
-resize, -scale largeur hauteur
Redimensionner l'image décodée aux dimensions largeur x hauteur. Cette option est principalement destinée à réduire la mémoire nécessaire pour décoder de grandes images, lorsqu'une petite version est suffisante (miniature, aperçu, etc.). Remarque : le redimensionnement est appliqué après le recadrage. Si l'un (mais pas les deux) des paramètres largeur ou hauteur est 0, la valeur sera calculée en préservant le rapport d'aspect.
-quiet
Ne rien imprimer.
-v
Afficher des informations supplémentaires (temps de décodage en particulier).
-noasm
Désactiver toutes les optimisations d'assemblage.

STATUT DE SORTIE

En cas d'exécution sans problème, dwebp se termine avec la valeur de la constante C EXIT_SUCCESS. C'est généralement zéro.

En cas d'erreur, dwebp se termine avec la valeur de la constante C EXIT_FAILURE. C'est généralement un.

EXEMPLES

dwebp image.webp -o sortie.png
dwebp image.webp -ppm -o sortie.ppm
dwebp -o sortie.ppm -- --image.webp
cat image.webp | dwebp -o - -- - > sortie.ppm
