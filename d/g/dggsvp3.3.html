DGGSVP

3

But

: 
!>
!> DGGSVP3 calcule les matrices orthogonales U, V et Q telles que
!>
!>                    N-K-L  K    L
!>  U**T*A*Q =     K ( 0    A12  A13 )  si M-K-L >= 0;
!>                 L ( 0     0   A23 )
!>             M-K-L ( 0     0    0  )
!>
!>                  N-K-L  K    L
!>         =     K ( 0    A12  A13 )  si M-K-L < 0;
!>             M-K ( 0     0   A23 )
!>
!>                  N-K-L  K    L
!>  V**T*B*Q =   L ( 0     0   B13 )
!>             P-L ( 0     0    0  )
!>
!> où la matrice K-par-K A12 et la matrice L-par-L B13 sont triangulaires
!> supérieures non singulières ; A23 est triangulaire supérieure L-par-L si
!> M-K-L >= 0, sinon A23 est trapézoïdale supérieure (M-K)-par-L.  K+L = le
!> rang numérique effectif de la matrice (M+P)-par-N (A**T,B**T)**T.
!>
!> Cette décomposition est l'étape de prétraitement pour calculer la
!> Décomposition en Valeurs Singulières Généralisée (GSVD), voir la
!> sous-routine DGGSVD3.
!
>

>

!
>

!>          Le nombre de colonnes des matrices A et B.  N >= 0.
!
>

A 
!>          A est un tableau DOUBLE PRECISION, dimension (LDA,N)
!>          À l'entrée, la matrice A de dimension M-par-N.
!>          À la sortie, A contient la matrice triangulaire (ou trapézoïdale)
!>          décrite dans la section But.
!
>

LD

A 
!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,M).
!
>

B 
!>          B est un tableau DOUBLE PRECISION, dimension (LDB,N)
!>          À l'entrée, la matrice B de dimension P-par-N.
!>          À la sortie, B contient la matrice triangulaire décrite dans la
!>          section But.
!
>

LD

B 
!>          LDB est INTEGER
!>          La dimension principale du tableau B. LDB >= max(1,P).
!
>

TOL

A 
!>          TOLA est DOUBLE PRECISION
!
>

TOL

B 
!>          TOLB est DOUBLE PRECISION
!>
!>          TOLA et TOLB sont les seuils pour déterminer le rang numérique
!>          effectif de la matrice B et d'un sous-bloc de A. Généralement,
!>          ils sont définis à
!>             TOLA = MAX(M,N)*norm(A)*MACHEPS,
!>             TOLB = MAX(P,N)*norm(B)*MACHEPS.
!>          La taille de TOLA et TOLB peut affecter la taille des erreurs
!>          arrière de la décomposition.
!
>

K 
!>          K est INTEGER
!
>

L 
!>          L est INTEGER
!>
!>          À la sortie, K et L spécifient la dimension des sous-blocs
!>          décrits dans la section But.
!>          K + L = rang numérique effectif de (A**T,B**T)**T.
!
>

U 
!>          U est un tableau DOUBLE PRECISION, dimension (LDU,M)
!>          Si JOBU = 'U', U contient la matrice orthogonale U.
!>          Si JOBU = 'N', U n'est pas référencé.
!
>

LD

U

!>          JOBU = 'U' ; LDU >= 1 sinon.
!
>

V

!>          Si JOBV = 'N', V n'est pas référencé.
!
>

LD

V 
!>          LDV est INTEGER
!>          La dimension principale du tableau V. LDV >= max(1,P) si
!>          JOBV = 'V' ; LDV >= 1 sinon.

>

Q 
!>          Q est un tableau DOUBLE PRECISION, dimension (LDQ,N)

!
>

LD

Q

!>          JOBQ = 'Q' ; LDQ >= 1 sinon.
!
>

IWOR

K

>

U
