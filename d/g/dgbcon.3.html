sous-programme dgbcon (caractère norm, entier n, entier kl, entier ku, double précision, dimension( ldab, * ) ab, entier ldab, entier, dimension( * ) ipiv, double précision anorm, double précision rcond, double précision, dimension( * ) work, entier, dimension( * ) iwork, entier info)

DGBCON

But :

!>
!> DGBCON estime l'inverse du nombre de condition d'une matrice bande générale réelle A,
!> en norme 1 ou norme infinie, en utilisant la factorisation LU calculée par DGBTRF.
!>
!> Une estimation de norm(inv(A)) est obtenue, et l'inverse du nombre de condition est calculé comme
!>    RCOND = 1 / ( norm(A) * norm(inv(A)) ).
!>

Paramètres

NORM 
!>          NORM est CHARACTER*1
!>          Spécifie si le nombre de condition en norme 1 ou en norme
!>          infinie est requis :
!>          = '1' ou 'O':  Norme 1;
!>          = 'I':         Norme infinie.
!>

N

!>          N est INTEGER
!>          Ordre de la matrice A.  N >= 0.
!>

KL

!>          KL est INTEGER
!>          Nombre de sous-diagonales dans la bande de A.  KL >= 0.
!>

KU

!>          KU est INTEGER
!>          Nombre de super-diagonales dans la bande de A.  KU >= 0.
!>

AB

!>          AB est tableau DOUBLE PRECISION, dimension (LDAB,N)
!>          Détails de la factorisation LU de la matrice bande A, tels que
!>          calculés par DGBTRF. U est stocké comme une matrice bande triangulaire supérieure
!>          avec KL+KU super-diagonales dans les lignes 1 à KL+KU+1, et
!>          les multiplicateurs utilisés pendant la factorisation sont stockés dans
!>          les lignes KL+KU+2 à 2*KL+KU+1.
!>

LDAB

!>          LDAB est INTEGER
!>          Dimension principale du tableau AB.  LDAB >= 2*KL+KU+1.
!>

IPIV

!>          IPIV est tableau INTEGER, dimension (N)
!>          Indices de pivot ; pour 1 <= i <= N, la ligne i de la matrice a été
!>          échangée avec la ligne IPIV(i).
!>

ANORM

!>          ANORM est DOUBLE PRECISION
!>          Si NORM = '1' ou 'O', la norme 1 de la matrice originale A.
!>          Si NORM = 'I', la norme infinie de la matrice originale A.
!>

RCOND

!>          RCOND est DOUBLE PRECISION
!>          L'inverse du nombre de condition de la matrice A,
!>          calculé comme RCOND = 1/(norm(A) * norm(inv(A))).
!>

WORK

!>          WORK est tableau DOUBLE PRECISION, dimension (3*N)
!>

IWORK

!>          IWORK est tableau INTEGER, dimension (N)
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>
