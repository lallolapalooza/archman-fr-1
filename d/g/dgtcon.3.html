Documentation de la fonction/sous-routine

sous-routine dgtcon (caractère norm, entier n, double précision, dimension( * ) dl, double précision, dimension( * ) d, double précision, dimension( * ) du, double précision, dimension( * ) du2, entier, dimension( * ) ipiv, double précision anorm, double précision rcond, double précision, dimension( * ) work, entier, dimension( * ) iwork, entier info)

DGTCON

Objectif :

!>
!> DGTCON estime la réciproque du nombre de condition d'une matrice
!> tridiagonale réelle A en utilisant la factorisation LU calculée par
!> DGTTRF.
!>
!> Une estimation de norm(inv(A)) est obtenue, et la réciproque du
!> nombre de condition est calculée comme RCOND = 1 / (ANORM * norm(inv(A))).
!>

Paramètres

NORM 
!>          NORM est CHARACTER*1
!>          Spécifie si le nombre de condition en norme 1 ou en norme
!>          infini est requis :
!>          = '1' ou 'O':  Norme 1 ;
!>          = 'I':         Norme infinie.
!>

N

!>          N est ENTIER
!>          Ordre de la matrice A.  N >= 0.
!>

DL

!>          DL est un tableau de DOUBLE PRÉCISION, dimension (N-1)
!>          Les (n-1) multiplicateurs qui définissent la matrice L de la
!>          factorisation LU de A calculée par DGTTRF.
!>

D

!>          D est un tableau de DOUBLE PRÉCISION, dimension (N)
!>          Les n éléments diagonaux de la matrice triangulaire supérieure U
!>          issue de la factorisation LU de A.
!>

DU

!>          DU est un tableau de DOUBLE PRÉCISION, dimension (N-1)
!>          Les (n-1) éléments de la première superdiagonale de U.
!>

DU2

!>          DU2 est un tableau de DOUBLE PRÉCISION, dimension (N-2)
!>          Les (n-2) éléments de la deuxième superdiagonale de U.
!>

IPIV

!>          IPIV est un tableau d'ENTIERS, dimension (N)
!>          Les indices de pivot ; pour 1 <= i <= n, la ligne i de la matrice
!>          a été échangée avec la ligne IPIV(i). IPIV(i) sera toujours
!>          égal à i ou i+1 ; IPIV(i) = i indique qu'un échange de ligne
!>          n'était pas nécessaire.
!>

ANORM

!>          ANORM est DOUBLE PRÉCISION
!>          Si NORM = '1' ou 'O', la norme 1 de la matrice originale A.
!>          Si NORM = 'I', la norme infinie de la matrice originale A.
!>

RCOND

!>          RCOND est DOUBLE PRÉCISION
!>          La réciproque du nombre de condition de la matrice A,
!>          calculée comme RCOND = 1/(ANORM * AINVNM), où AINVNM est une
!>          estimation de la norme 1 de inv(A) calculée dans cette routine.
!>

WORK

!>          WORK est un tableau de DOUBLE PRÉCISION, dimension (2*N)
!>

IWORK

!>          IWORK est un tableau d'ENTIERS, dimension (N)
!>

INFO

!>          INFO est ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>
