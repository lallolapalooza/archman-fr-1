sous-routine dgsvj1 (character*1 jobv, integer m, integer n, integer n1, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( n ) d, double precision, dimension( n ) sva, integer mv, double precision, dimension( ldv, * ) v, integer ldv, double precision eps, double precision sfmin, double precision tol, integer nsweep, double precision, dimension( lwork ) work, integer lwork, integer

DGSVJ1 est un préprocesseur pour la routine dgesvj, applique des rotations Jacobi ciblant uniquement des pivots

particuliers.

Objectif

: 
!>
!> DGSVJ1 est appelé depuis DGESVJ en tant que préprocesseur et c'est son objectif
!> principal. Il applique des rotations Jacobi de la même manière que DGESVJ, mais
!> il cible uniquement des pivots particuliers et ne vérifie pas la convergence
!> (critère d'arrêt). Quelques paramètres de réglage (marqués par [TP]) sont
!> disponibles pour l'implémenteur.
!>
!> Détails supplémentaires
!> ~~~~~~~~~~~~~~~~~~~~~~~
!> DGSVJ1 applique quelques balayages de rotations Jacobi dans l'espace des colonnes
!> de la matrice d'entrée M-par-N A. Les paires de pivots sont prises dans le bloc
!> (1,2) hors-diagonal de la matrice de Gram correspondante N-par-N A^T * A. Les
!> entrées de bloc (tuiles) du bloc (1,2) hors-diagonal sont marquées par les
!> [x] dans le schéma suivant :
!>
!>    | *  *  * [x] [x] [x]|
!>    | *  *  * [x] [x] [x]|    Cycle de lignes dans les blocs [x] nblr-par-nblc.
!>    | *  *  * [x] [x] [x]|    Pivotation cyclique par ligne à l'intérieur de chaque bloc [x].
!>    |[x] [x] [x] *  *  * |
!>    |[x] [x] [x] *  *  * |
!>    |[x] [x] [x] *  *  * |
!>
!> En termes de colonnes de A, les premières N1 colonnes sont tournées « contre »
!> les N-N1 colonnes restantes, en essayant d'augmenter l'angle entre les
!> sous-espaces correspondants. Le bloc hors-diagonal est N1-par(N-N1) et il est
!> tuilé à l'aide de tuiles quadratiques de côté KBL. Ici, KBL est un paramètre de
!> réglage. Le nombre de balayages est donné dans NSWEEP et le seuil d'orthogonalité
!> est donné dans TOL.
!
>

Paramètre

s
JOBV 
!>          JOBV est CHARACTER*1
!>          Spécifie si la sortie de cette procédure est utilisée
!>          pour calculer la matrice V :
!>          = 'V' : le produit des rotations Jacobi est accumulé
!>                 en multipliant à droite le tableau V de taille N-par-N.
!>                (Voir la description de V.)
!>          = 'A' : le produit des rotations Jacobi est accumulé
!>                 en multipliant à droite le tableau V de taille MV-par-N.
!>                (Voir les descriptions de MV et V.)
!>          = 'N' : les rotations Jacobi ne sont pas accumulées.
!
>

M 
!>          M est INTEGER
!>          Le nombre de lignes de la matrice d'entrée A.  M >= 0.
!
>

N 
!>          N est INTEGER
!>          Le nombre de colonnes de la matrice d'entrée A.
!>          M >= N >= 0.
!
>

N

1 
!>          N1 est INTEGER
!>          N1 spécifie la partition en blocs 2 x 2, les premières N1 colonnes sont
!>          tournées « contre » les N-N1 colonnes restantes de A.
!
>

A 
!>          A est un tableau DOUBLE PRECISION, dimension (LDA,N)
!>          À l'entrée, matrice A de taille M-par-N, telle que A*diag(D) représente
!>          la matrice d'entrée.
!>          À la sortie,
!>          A_onexit * D_onexit représente la matrice d'entrée A*diag(D)
!>          post-multipliée par une séquence de rotations Jacobi, où le
!>          seuil de rotation et le nombre total de balayages sont donnés dans
!>          TOL et NSWEEP, respectivement.
!>          (Voir les descriptions de N1, D, TOL et NSWEEP.)
!
>

LD

A 
!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,M).
!
>

D 
!>          D est un tableau DOUBLE PRECISION, dimension (N)
!>          Le tableau D accumule les facteurs d'échelle provenant des rotations Jacobi
!>          mises à l'échelle rapides.
!>          À l'entrée, A*diag(D) représente la matrice d'entrée.
!>          À la sortie, A_onexit*diag(D_onexit) représente la matrice d'entrée
!>          post-multipliée par une séquence de rotations Jacobi, où le
!>          seuil de rotation et le nombre total de balayages sont donnés dans
!>          TOL et NSWEEP, respectivement.
!>          (Voir les descriptions de N1, A, TOL et NSWEEP.)
!
>

SV

A 
!>          SVA est un tableau DOUBLE PRECISION, dimension (N)
!>          À l'entrée, SVA contient les normes euclidiennes des colonnes de
!>          la matrice A*diag(D).
!>          À la sortie, SVA contient les normes euclidiennes des colonnes de
!>          la matrice onexit*diag(D_onexit).
!
>

M

V 
!>          MV est INTEGER
!>          Si JOBV = 'A', alors MV lignes de V sont post-multipliées par une
!>                         séquence de rotations Jacobi.
!>          Si JOBV = 'N', alors MV n'est pas référencé.
!
>

V 
!>          V est un tableau DOUBLE PRECISION, dimension (LDV,N)
!>          Si JOBV = 'V', alors N lignes de V sont post-multipliées par une
!>                         séquence de rotations Jacobi.
!>          Si JOBV = 'A', alors MV lignes de V sont post-multipliées par une
!>                         séquence de rotations Jacobi.
!>          Si JOBV = 'N', alors V n'est pas référencé.
!
>

LD

V 
!>          LDV est INTEGER
!>          La dimension principale du tableau V,  LDV >= 1.
!>          Si JOBV = 'V', LDV >= N.
!>          Si JOBV = 'A', LDV >= MV.
!
>

EP

S 
!>          EPS est DOUBLE PRECISION
!>          EPS = DLAMCH('Epsilon')
!
>

SFMI

N 
!>          SFMIN est DOUBLE PRECISION
!>          SFMIN = DLAMCH('Safe Minimum')
!
>

TO

L 
!>          TOL est DOUBLE PRECISION
!>          TOL est le seuil pour les rotations Jacobi. Pour une paire
!>          A(:,p), A(:,q) de colonnes de pivot, la rotation Jacobi est
!>          appliquée uniquement si DABS(COS(angle(A(:,p),A(:,q)))) > TOL.
!
>

NSWEE

P 
!>          NSWEEP est INTEGER
!>          NSWEEP est le nombre de balayages de rotations Jacobi à
!>          effectuer.
!
>

WOR

K 
!>          WORK est un tableau DOUBLE PRECISION, dimension (LWORK)
!
>

LWOR

K 
!>          LWORK est INTEGER
!>          LWORK est la dimension de WORK. LWORK >= M.
!
>

INF

O 
!>          INFO est INTEGER
!>          = 0 :  sortie réussie.
!>          < 0 :  si INFO = -i, alors le i-ème argument avait une valeur illégale
!
>
