Documentation de la fonction/sous-routine

sous-routine dgeesx (character jobvs, character sort, external select, character sense, integer n, double precision, dimension( lda, * ) a, integer lda, integer sdim, double precision, dimension( * ) wr, double precision, dimension( * ) wi, double precision, dimension( ldvs, * ) vs, integer ldvs, double precision rconde, double precision rcondv, double precision, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, integer liwork, logical, dimension( * ) bwork, integer info)

DGEESX calcule les valeurs propres, la forme de Schur et, éventuellement, la matrice des vecteurs de Schur pour les matrices GE

But :

!>
!> DGEESX calcule pour une matrice réelle non symétrique A de taille N par N, les
!> valeurs propres, la forme de Schur réelle T et, éventuellement, la matrice de
!> vecteurs de Schur Z. Cela donne la factorisation de Schur A = Z*T*(Z**T).
!>
!> Éventuellement, elle ordonne aussi les valeurs propres sur la diagonale de la
!> forme de Schur réelle de sorte que les valeurs propres sélectionnées soient en
!> haut à gauche ; calcule un nombre de condition réciproque pour la moyenne des
!> valeurs propres sélectionnées (RCONDE) ; et calcule un nombre de condition
!> réciproque pour le sous-espace invariant droit correspondant aux valeurs
!> propres sélectionnées (RCONDV). Les colonnes principales de Z forment une base
!> orthonormale pour ce sous-espace invariant.
!>
!> Pour une explication plus détaillée des nombres de condition réciproques RCONDE
!> et RCONDV, voir la section 4.10 du Guide de l'utilisateur LAPACK (où
!> ces quantités sont appelées s et sep respectivement).
!>
!> Une matrice réelle est en forme de Schur réelle si elle est quasi-triangulaire
!> supérieure avec des blocs de taille 1 par 1 et 2 par 2. Les blocs 2 par 2 seront standardisés sous la
!> forme
!>           [  a  b  ]
!>           [  c  a  ]
!>
!> où b*c < 0. Les valeurs propres d'un tel bloc sont a +- sqrt(bc).
!>

Paramètres

JOBVS 
!>          JOBVS est de type CHARACTER*1
!>          = 'N' : les vecteurs de Schur ne sont pas calculés ;
!>          = 'V' : les vecteurs de Schur sont calculés.
!>

SORT

!>          SORT est de type CHARACTER*1
!>          Indique s'il faut ou non ordonner les valeurs propres sur la
!>          diagonale de la forme de Schur.
!>          = 'N' : les valeurs propres ne sont pas ordonnées ;
!>          = 'S' : les valeurs propres sont ordonnées (voir SELECT).
!>

SELECT

!>          SELECT est une FONCTION LOGIQUE de deux arguments DOUBLE PRECISION
!>          SELECT doit être déclarée EXTERNAL dans la sous-routine appelante.
!>          Si SORT = 'S', SELECT est utilisée pour sélectionner les valeurs propres à trier
!>          en haut à gauche de la forme de Schur.
!>          Si SORT = 'N', SELECT n'est pas référencée.
!>          Une valeur propre WR(j)+sqrt(-1)*WI(j) est sélectionnée si
!>          SELECT(WR(j),WI(j)) est vraie ; c'est-à-dire que si l'une des deux
!>          valeurs propres d'une paire conjuguée complexe est sélectionnée, alors les deux
!>          le sont. Notez qu'une valeur propre complexe sélectionnée peut ne plus
!>          satisfaire SELECT(WR(j),WI(j)) = .TRUE. après le tri, car le
!>          tri peut changer la valeur des valeurs propres complexes
!>          (surtout si la valeur propre est mal conditionnée) ; dans ce
!>          cas, INFO peut être défini à N+3 (voir INFO ci-dessous).
!>

SENSE

!>          SENSE est de type CHARACTER*1
!>          Détermine quels nombres de condition réciproques sont calculés.
!>          = 'N' : aucun n'est calculé ;
!>          = 'E' : calculé uniquement pour la moyenne des valeurs propres sélectionnées ;
!>          = 'V' : calculé uniquement pour le sous-espace invariant droit sélectionné ;
!>          = 'B' : calculé pour les deux.
!>          Si SENSE = 'E', 'V' ou 'B', SORT doit être égal à 'S'.
!>

N

!>          N est de type INTEGER
!>          L'ordre de la matrice A. N >= 0.
!>

A

!>          A est un tableau DOUBLE PRECISION, dimension (LDA, N)
!>          À l'entrée, la matrice A de taille N par N.
!>          À la sortie, A est écrasée par sa forme de Schur réelle T.
!>

LDA

!>          LDA est de type INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,N).
!>

SDIM

!>          SDIM est de type INTEGER
!>          Si SORT = 'N', SDIM = 0.
!>          Si SORT = 'S', SDIM = le nombre de valeurs propres (après tri)
!>                         pour lesquelles SELECT est vraie. (Les paires conjuguées
!>                         complexes pour lesquelles SELECT est vraie pour l'une
!>                         des valeurs propres comptent pour 2.)
!>

WR

!>          WR est un tableau DOUBLE PRECISION, dimension (N)
!>

WI

!>          WI est un tableau DOUBLE PRECISION, dimension (N)
!>          WR et WI contiennent respectivement les parties réelle et imaginaire
!>          des valeurs propres calculées, dans le même ordre qu'elles
!>          apparaissent sur la diagonale de la forme de Schur de sortie T. Les paires conjuguées
!>          complexes de valeurs propres apparaissent consécutivement avec
!>          la valeur propre ayant la partie imaginaire positive en premier.
!>

VS

!>          VS est un tableau DOUBLE PRECISION, dimension (LDVS,N)
!>          Si JOBVS = 'V', VS contient la matrice orthogonale Z des vecteurs
!>          de Schur.
!>          Si JOBVS = 'N', VS n'est pas référencée.
!>

LDVS

!>          LDVS est de type INTEGER
!>          La dimension principale du tableau VS. LDVS >= 1, et si
!>          JOBVS = 'V', LDVS >= N.
!>

RCONDE

!>          RCONDE est de type DOUBLE PRECISION
!>          Si SENSE = 'E' ou 'B', RCONDE contient le nombre de condition
!>          réciproque pour la moyenne des valeurs propres sélectionnées.
!>          Non référencé si SENSE = 'N' ou 'V'.
!>

RCONDV

!>          RCONDV est de type DOUBLE PRECISION
!>          Si SENSE = 'V' ou 'B', RCONDV contient le nombre de condition
!>          réciproque pour le sous-espace invariant droit sélectionné.
!>          Non référencé si SENSE = 'N' ou 'E'.
!>

WORK

!>          WORK est un tableau DOUBLE PRECISION, dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) renvoie la valeur optimale de LWORK.
!>

LWORK

!>          LWORK est de type INTEGER
!>          La dimension du tableau WORK. LWORK >= max(1,3*N).
!>          De plus, si SENSE = 'E' ou 'V' ou 'B',
!>          LWORK >= N+2*SDIM*(N-SDIM), où SDIM est le nombre de
!>          valeurs propres sélectionnées calculées par cette routine. Notez que
!>          N+2*SDIM*(N-SDIM) <= N+N*N/2. Notez également qu'une erreur n'est
!>          renvoyée que si LWORK < max(1,3*N), mais si SENSE = 'E' ou 'V' ou
!>          'B', cela peut ne pas être suffisant.
!>          Pour de bonnes performances, LWORK doit généralement être plus grand.
!>
!>          Si LWORK = -1, une interrogation de l'espace de travail est supposée ; la routine
!>          ne calcule que des bornes supérieures sur les tailles optimales des
!>          tableaux WORK et IWORK, renvoie ces valeurs comme premières
!>          entrées des tableaux WORK et IWORK, et aucun message d'erreur
!>          lié à LWORK ou LIWORK n'est émis par XERBLA.
!>

IWORK

!>          IWORK est un tableau INTEGER, dimension (MAX(1,LIWORK))
!>          À la sortie, si INFO = 0, IWORK(1) renvoie la valeur optimale de LIWORK.
!>

LIWORK

!>          LIWORK est de type INTEGER
!>          La dimension du tableau IWORK.
!>          LIWORK >= 1; si SENSE = 'V' ou 'B', LIWORK >= SDIM*(N-SDIM).
!>          Notez que SDIM*(N-SDIM) <= N*N/4. Notez également qu'une erreur n'est
!>          renvoyée que si LIWORK < 1, mais si SENSE = 'V' ou 'B' cela
!>          peut ne pas être suffisant.
!>
!>          Si LIWORK = -1, une interrogation d'espace de travail est supposée ; la
!>          routine calcule uniquement des bornes supérieures sur les tailles optimales
!>          des tableaux WORK et IWORK, renvoie ces valeurs comme les premières
!>          entrées des tableaux WORK et IWORK, et aucun message d'erreur
!>          lié à LWORK ou LIWORK n'est émis par XERBLA.
!>

BWORK

!>          BWORK est un tableau LOGICAL, de dimension (N)
!>          Non référencé si SORT = 'N'.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.
!>          > 0 : si INFO = i, et i est
!>             <= N : l'algorithme QR n'a pas réussi à calculer toutes les
!>                   valeurs propres ; les éléments 1:ILO-1 et i+1:N de WR et WI
!>                   contiennent celles des valeurs propres qui ont convergé ; si
!>                   JOBVS = 'V', VS contient la transformation qui
!>                   réduit A à sa forme de Schur partiellement convergée.
!>             = N+1 : les valeurs propres n'ont pas pu être réordonnées car certaines
!>                   valeurs propres étaient trop proches pour être séparées (le problème
!>                   est très mal conditionné) ;
!>             = N+2 : après réordonnancement, l'arrondi a modifié les valeurs de certaines
!>                   valeurs propres complexes de sorte que les valeurs propres dominantes dans
!>                   la forme de Schur ne satisfont plus SELECT=.TRUE.  Cela
!>                   peut aussi être causé par un sous-flux dû à la mise à l'échelle.
!>
