Documentation de la fonction/sous-programme

sous-programme dglmts (entier n, entier m, entier p, double précision, dimension( lda, * ) a, double précision, dimension( lda, * ) af, entier lda, double précision, dimension( ldb, * ) b, double précision, dimension( ldb, * ) bf, entier ldb, double précision, dimension( * ) d, double précision, dimension( * ) df, double précision, dimension( * ) x, double précision, dimension( * ) u, double précision, dimension( lwork ) work, entier lwork, double précision, dimension( * ) rwork, double précision result)

DGLMTS

Objectif:

!>
!> DGLMTS teste DGGGLM - un sous-programme pour résoudre le problème
!> du modèle linéaire généralisé.
!>

Paramètres

N 
!>          N est un ENTIER
!>          Le nombre de lignes des matrices A et B.  N >= 0.
!>

M

!>          M est un ENTIER
!>          Le nombre de colonnes de la matrice A.  M >= 0.
!>

P

!>          P est un ENTIER
!>          Le nombre de colonnes de la matrice B.  P >= 0.
!>

A

!>          A est un tableau DOUBLE PRÉCISION, dimension (LDA,M)
!>          La matrice N-par-M A.
!>

AF

!>          AF est un tableau DOUBLE PRÉCISION, dimension (LDA,M)
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale des tableaux A, AF. LDA >= max(M,N).
!>

B

!>          B est un tableau DOUBLE PRÉCISION, dimension (LDB,P)
!>          La matrice N-par-P A.
!>

BF

!>          BF est un tableau DOUBLE PRÉCISION, dimension (LDB,P)
!>

LDB

!>          LDB est un ENTIER
!>          La dimension principale des tableaux B, BF. LDB >= max(P,N).
!>

D

!>          D est un tableau DOUBLE PRÉCISION, dimension( N )
!>          En entrée, le membre de gauche du GLM.
!>

DF

!>          DF est un tableau DOUBLE PRÉCISION, dimension( N )
!>

X

!>          X est un tableau DOUBLE PRÉCISION, dimension( M )
!>          vecteur solution X dans le problème GLM.
!>

U

!>          U est un tableau DOUBLE PRÉCISION, dimension( P )
!>          vecteur solution U dans le problème GLM.
!>

WORK

!>          WORK est un tableau DOUBLE PRÉCISION, dimension (LWORK)
!>

LWORK

!>          LWORK est un ENTIER
!>          La dimension du tableau WORK.
!>

RWORK

!>          RWORK est un tableau DOUBLE PRÉCISION, dimension (M)
!>

RESULT

!>          RESULT est un DOUBLE PRÉCISION
!>          Le ratio de test :
!>                           norme( d - A*x - B*u )
!>            RESULT = -----------------------------------------
!>                     (norme(A)+norme(B))*(norme(x)+norme(u))*EPS
!>
