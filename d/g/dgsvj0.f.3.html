subroutine dgsvj0 (character*1 jobv, integer m, integer n, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( n ) d, double precision, dimension( n ) sva, integer mv, double precision, dimension( ldv, * ) v, integer ldv, double precision eps, double precision sfmin, double precision tol, integer nsweep, double precision, dimension( lwork ) work, integer lwork, integer info)

DGSVJ0 pré-processeur pour la routine dgesvj.

But :

!>
!> DGSVJ0 est appelé depuis DGESVJ en tant que pré-processeur et c'est son
!> but principal. Il applique les rotations de Jacobi de la même manière
!> que DGESVJ, mais il ne vérifie pas la convergence (critère d'arrêt).
!> Quelques paramètres d'ajustement (marqués par [TP]) sont disponibles
!> pour l'implémenteur.
!>

Paramètres

JOBV 
!>          JOBV est CHARACTER*1
!>          Spécifie si la sortie de cette procédure est utilisée
!>          pour calculer la matrice V :
!>          = 'V' : le produit des rotations de Jacobi est accumulé
!>                  en multipliant à droite le tableau V de taille N par N.
!>                  (Voir la description de V.)
!>          = 'A' : le produit des rotations de Jacobi est accumulé
!>                  en multipliant à droite le tableau V de taille MV par N.
!>                  (Voir les descriptions de MV et V.)
!>          = 'N' : les rotations de Jacobi ne sont pas accumulées.
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice d'entrée A.  M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice d'entrée A.
!>          M >= N >= 0.
!>

A

!>          A est un tableau DOUBLE PRECISION, dimension (LDA,N)
!>          À l'entrée, la matrice A de taille M par N, telle que A*diag(D)
!>          représente la matrice d'entrée.
!>          À la sortie,
!>          A_onexit * D_onexit représente la matrice d'entrée A*diag(D)
!>          post-multipliée par une séquence de rotations de Jacobi, où le
!>          seuil de rotation et le nombre total de balayages sont donnés
!>          respectivement dans TOL et NSWEEP.
!>          (Voir les descriptions de D, TOL et NSWEEP.)
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,M).
!>

D

!>          D est un tableau DOUBLE PRECISION, dimension (N)
!>          Le tableau D accumule les facteurs d'échelle provenant des
!>          rotations de Jacobi à échelle rapide.
!>          À l'entrée, A*diag(D) représente la matrice d'entrée.
!>          À la sortie, A_onexit*diag(D_onexit) représente la matrice
!>          d'entrée post-multipliée par une séquence de rotations de Jacobi,
!>          où le seuil de rotation et le nombre total de balayages sont
!>          donnés respectivement dans TOL et NSWEEP.
!>          (Voir les descriptions de A, TOL et NSWEEP.)
!>

SVA

!>          SVA est un tableau DOUBLE PRECISION, dimension (N)
!>          À l'entrée, SVA contient les normes euclidiennes des colonnes
!>          de la matrice A*diag(D).
!>          À la sortie, SVA contient les normes euclidiennes des colonnes
!>          de la matrice onexit*diag(D_onexit).
!>

MV

!>          MV est INTEGER
!>          Si JOBV = 'A', alors MV lignes de V sont post-multipliées par
!>                           une séquence de rotations de Jacobi.
!>          Si JOBV = 'N',   alors MV n'est pas référencé.
!>

V

!>          V est un tableau DOUBLE PRECISION, dimension (LDV,N)
!>          Si JOBV = 'V', alors N lignes de V sont post-multipliées par
!>                           une séquence de rotations de Jacobi.
!>          Si JOBV = 'A', alors MV lignes de V sont post-multipliées par
!>                           une séquence de rotations de Jacobi.
!>          Si JOBV = 'N',   alors V n'est pas référencé.
!>

LDV

!>          LDV est INTEGER
!>          La dimension principale du tableau V,  LDV >= 1.
!>          Si JOBV = 'V', LDV >= N.
!>          Si JOBV = 'A', LDV >= MV.
!>

EPS

!>          EPS est DOUBLE PRECISION
!>          EPS = DLAMCH('Epsilon')
!>

SFMIN

!>          SFMIN est DOUBLE PRECISION
!>          SFMIN = DLAMCH('Safe Minimum')
!>

TOL

!>          TOL est DOUBLE PRECISION
!>          TOL est le seuil pour les rotations de Jacobi. Pour une paire
!>          de colonnes pivot A(:,p), A(:,q), la rotation de Jacobi est
!>          appliquée uniquement si DABS(COS(angle(A(:,p),A(:,q)))) > TOL.
!>

NSWEEP

!>          NSWEEP est INTEGER
!>          NSWEEP est le nombre de balayages de rotations de Jacobi à
!>          effectuer.
!>

WORK

!>          WORK est un tableau DOUBLE PRECISION, dimension (LWORK)
!>

LWORK

!>          LWORK est INTEGER
!>          LWORK est la dimension de WORK. LWORK >= M.
!>

INFO

!>          INFO est INTEGER
!>          = 0 :  sortie réussie.
!>          < 0 :  si INFO = -i, alors le i-ème argument avait une valeur
!>                 illégale
!>

Détails supplémentaires :

DGSVJ0 est utilisé uniquement pour permettre à DGESVJ d'appeler une version simplifiée d'elle-même pour travailler sur une sous-matrice de la matrice originale.
