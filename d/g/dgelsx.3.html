Documentation de la fonction/sous-routine

subroutine dgelsx (integer m, integer n, integer nrhs, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( ldb, * ) b, integer ldb, integer, dimension( * ) jpvt, double precision rcond, integer rank, double precision, dimension( * ) work, integer info)

DGELSX résout des systèmes surdéterminés ou sousdéterminés pour les matrices GE

Objectif :

!>
!> Cette routine est obsolète et a été remplacée par la routine DGELSY.
!>
!> DGELSX calcule la solution de norme minimale pour un problème de moindres carrés
!> linéaires réels :
!>     minimiser || A * X - B ||
!> en utilisant une factorisation orthogonale complète de A. A est une matrice
!> M par N qui peut être de rang déficient.
!>
!> Plusieurs vecteurs second membre b et vecteurs solution x peuvent être
!> traités en un seul appel ; ils sont stockés sous forme de colonnes des
!> matrices B (M par NRHS) et X (N par NRHS).
!>
!> La routine calcule d'abord une factorisation QR avec pivotement de colonnes :
!>     A * P = Q * [ R11 R12 ]
!>                 [  0  R22 ]
!> avec R11 défini comme la plus grande sous-matrice principale dont le
!> numéro de condition estimé est inférieur à 1/RCOND. L'ordre de R11, RANK,
!> est le rang effectif de A.
!>
!> Ensuite, R22 est considéré comme négligeable, et R12 est annihilé
!> par des transformations orthogonales par la droite, arrivant à la
!> factorisation orthogonale complète :
!>    A * P = Q * [ T11 0 ] * Z
!>                [  0  0 ]
!> La solution de norme minimale est alors
!>    X = P * Z**T [ inv(T11)*Q1**T*B ]
!>                 [        0         ]
!> où Q1 est constitué des RANK premières colonnes de Q.
!>

Paramètres

M 
!>          M est INTEGER
!>          Le nombre de lignes de la matrice A. M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice A. N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de seconds membres, c'est-à-dire le nombre
!>          de colonnes des matrices B et X. NRHS >= 0.
!>

A

!>          A est un tableau DOUBLE PRECISION, de dimension (LDA,N)
!>          À l'entrée, la matrice A de dimensions M x N.
!>          À la sortie, A a été écrasé par les détails de sa
!>          factorisation orthogonale complète.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,M).
!>

B

!>          B est un tableau DOUBLE PRECISION, de dimension (LDB,NRHS)
!>          À l'entrée, la matrice B de dimensions M x NRHS du second membre.
!>          À la sortie, la matrice solution X de dimensions N x NRHS.
!>          Si m >= n et RANK = n, la somme des carrés des résidus pour
!>          la solution dans la i-ème colonne est donnée par la somme
!>          des carrés des éléments N+1:M de cette colonne.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B. LDB >= max(1,M,N).
!>

JPVT

!>          JPVT est un tableau INTEGER, de dimension (N)
!>          À l'entrée, si JPVT(i) .ne. 0, la i-ème colonne de A est une
!>          colonne initiale, sinon c'est une colonne libre. Avant
!>          la factorisation QR de A, toutes les colonnes initiales sont
!>          permutées vers les positions principales ; seules les colonnes
!>          libres restantes sont déplacées à la suite du pivotement de colonnes
!>          pendant la factorisation.
!>          À la sortie, si JPVT(i) = k, alors la i-ème colonne de A*P
!>          était la k-ème colonne de A.
!>

RCOND

!>          RCOND est DOUBLE PRECISION
!>          RCOND est utilisé pour déterminer le rang effectif de A, qui
!>          est défini comme l'ordre de la plus grande sous-matrice triangulaire
!>          principale R11 dans la factorisation QR avec pivotement de A,
!>          dont le numéro de condition estimé est < 1/RCOND.
!>

RANK

!>          RANK est INTEGER
!>          Le rang effectif de A, c'est-à-dire l'ordre de la sous-matrice
!>          R11. C'est le même que l'ordre de la sous-matrice T11
!>          dans la factorisation orthogonale complète de A.
!>

WORK

!>          WORK est un tableau DOUBLE PRECISION, de dimension
!>                      (max( min(M,N)+3*N, 2*min(M,N)+NRHS )),
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>
