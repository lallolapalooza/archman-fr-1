NOM

dgn_comp - Compilateur de donjon NetHack

SYNTAXE

dgn_comp [ fichier ]

Si aucun argument n'est fourni, il lit l'entrée standard.

DESCRIPTION

Dgn_comp est un compilateur de donjon pour NetHack version 3.2 et supérieure. Il prend un fichier de description comme argument et produit un "script" de donjon à charger par NetHack au moment de l'exécution.

Le but de cet outil est de fournir aux administrateurs et aux développeurs de NetHack un moyen pratique de créer un donjon personnalisé pour le jeu, sans avoir à recompiler le monde entier.

GRAMMAIRE

DUNGEON: nom marqueur_os ( base , aléatoire ) [ %âge ]

où nom est le nom du donjon, marqueur_os est une lettre pour marquer les fichiers d'os, ( base , aléatoire ) est le nombre de niveaux, et %âge est sa chance de génération (si absent, chance de 100%).

DESCRIPTION: tag

où tag est actuellement l'un de HELLISH, MAZELIKE, ou ROGUELIKE.

ALIGNEMENT | ALIGNEMENT_NIVEAU: [ loyal | neutre | chaotique | non-aligné ]

donne l'alignement du donjon/niveau (par défaut : non-aligné).

ENTREE: niveau

le point d'entrée du donjon. La connexion du donjon s'attache à ce niveau du donjon donné. Si la valeur de niveau est négative, le niveau d'entrée est calculé à partir du bas du donjon, -1 étant le dernier niveau. Si cette ligne n'est pas présente dans une description de donjon, le niveau d'entrée est par défaut 1.

FICHIER_PROTO: nom

le nom prototypique des fichiers de niveau de donjon dans ce donjon. Par exemple, le nom FICHIER_PROTO du donjon Tour de Vlad est tower.

NIVEAU: nom marqueur_os @ ( base , aléatoire ) [ %âge ]

où nom est le nom du niveau, marqueur_os est une lettre pour marquer les fichiers d'os, ( base , aléatoire ) est la localisation et %âge est le pourcentage de génération, comme ci-dessus.

NIVEAU_ALEATOIRE: nom marqueur_os @ ( base , aléatoire ) [ %âge ] niveaux_aleatoires

où nom est le nom du niveau, marqueur_os est une lettre pour marquer les fichiers d'os, ( base , aléatoire ) est la localisation, %âge est le pourcentage de génération, comme ci-dessus, et niveaux_aleatoires est le nombre de niveaux similaires disponibles à choisir.

NIVEAU_CHAINE: nom marqueur_os nom_prec + ( base , aléatoire ) [ %âge ]

où nom est le nom du niveau, marqueur_os est une lettre pour marquer les fichiers d'os, nom_prec est le nom d'un niveau défini précédemment, ( base , aléatoire ) est le décalage par rapport au niveau à partir duquel la chaîne est faite, et %âge est le pourcentage de génération.

NIVEAU_CHAINE_ALEATOIRE: nom marqueur_os nom_prec + ( base , aléatoire ) [ %âge ] niveaux_aleatoires

où nom est le nom du niveau, marqueur_os est une lettre pour marquer les fichiers d'os, nom_prec est le nom d'un niveau défini précédemment, ( base , aléatoire ) est le décalage par rapport au niveau à partir duquel la chaîne est faite, %âge est le pourcentage de génération, et niveaux_aleatoires est le nombre de niveaux similaires disponibles à choisir.

DESCRIPTION_NIVEAU: type

où type est le type de niveau (voir DESCRIPTION, ci-dessus). Le type est utilisé pour remplacer toute valeur prédéfinie utilisée pour décrire l'ensemble du donjon, pour ce niveau uniquement.

BRANCHEMENT: nom @ ( base , aléatoire ) [ escalier | pas_haut | pas_bas | portail ] [ haut | bas ]

où nom est le nom du donjon vers lequel le branchement s'effectue, et ( base , aléatoire ) est la localisation du branchement. Les deux derniers arguments optionnels sont le type de branchement et la direction du branchement. Le type d'un branchement peut être une connexion d'escalier bidirectionnelle, une connexion d'escalier unidirectionnelle, ou un portail magique. Un escalier unidirectionnel est décrit par les types pas_haut et pas_bas qui spécifient quelle direction d'escalier est manquante. Le type de branchement par défaut est escalier. La direction d'un escalier peut être soit haut, soit bas ; la direction n'est pas applicable aux portails. La direction par défaut est bas.

BRANCHEMENT_CHAINE: nom nom_prec + ( base , aléatoire ) [ escalier | pas_haut | pas_bas | portail ] [ haut | bas ]

où nom est le nom du donjon vers lequel le branchement s'effectue, nom_prec est le nom d'un niveau défini précédemment et ( base , aléatoire ) est le décalage par rapport au niveau à partir duquel la chaîne est faite. Le type de branchement et la direction optionnels sont les mêmes que décrits ci-dessus.

RÈGLES GÉNÉRALES

Chaque donjon doit avoir un marqueur_os unique, et chaque niveau spécial doit avoir un marqueur_os unique au sein de son donjon (les lettres peuvent être réutilisées dans différents donjons). Si le marqueur_os a la valeur spéciale "none", aucun fichier d'os ne sera créé pour ce niveau ou ce donjon.

La valeur base peut être dans la plage de 1 à MAXLEVEL (tel que défini dans global.h ).

La valeur aléatoire peut être dans la plage de -1 à MAXLEVEL.

Si aléatoire est -1, il sera remplacé par la valeur (nombre_niveaux_donjon(donjon) - base) pendant le processus de chargement (c'est-à-dire, d'ici à la fin du donjon).

Si aléatoire est 0, le niveau est situé absolument à base.

Les branchements n'ont pas de probabilité. Les donjons en ont. Si un donjon échoue à être généré lors du chargement, tous ses niveaux et branchements sont ignorés.

Aucun niveau ou branchement ne peut être chaîné à partir d'un niveau avec une probabilité de génération en pourcentage. Ceci afin d'éviter les non-résolutions pendant le chargement. De plus, aucun branchement ne peut être fait à partir d'un donjon avec une probabilité de génération en pourcentage pour la même raison.

En règle générale, en utilisant le compilateur de donjon :

Si un donjon a un nom de fichier_proto associé (par ex. tower), ce fichier sera utilisé.

Si un niveau spécial est présent, il remplacera la règle ci-dessus et le fichier approprié sera chargé.

Si ni l'un ni l'autre des cas ci-dessus ne sont présents, le générateur standard prendra le relais et créera un niveau "normal".

Un alignement de niveau, s'il est présent, remplacera l'alignement du donjon dans lequel il existe.

EXEMPLE

Voici la syntaxe actuelle du "langage" du compilateur de donjon :

#
#	Le fichier de description du donjon pour le NetHack original standard
#	de la version 3.0.
#
DUNGEON:	"Les Donjons de la Mort" "D" (25, 5)
NIVEAU:		"rogue" "none" @ (15, 4)
NIVEAU:		"oracle" "none" @ (5, 7)
NIVEAU:		"bigroom" "B" @ (12, 3) 15
NIVEAU:		"medusa" "none" @ (20, 5)
NIVEAU_CHAINE:	"castle" "medusa" + (1, 4)
BRANCHEMENT_CHAINE:	"Hell" "castle" + (0, 0) pas_bas
BRANCHEMENT:		"Le Plan Astral" @ (1, 0) pas_bas haut
DUNGEON:	"Hell" "H" (25, 5)
DESCRIPTION:	mazelike
DESCRIPTION:	hellish
BRANCHEMENT:	"La Tour de Vlad" @ (13, 5) haut
NIVEAU:		"wizard" "none" @ (15, 10)
NIVEAU:		"fakewiz" "A" @ (5, 5)
NIVEAU:		"fakewiz" "B" @ (10, 5)
NIVEAU:		"fakewiz" "C" @ (15, 5)
NIVEAU:		"fakewiz" "D" @ (20, 5)
NIVEAU:		"fakewiz" "E" @ (25, 5)
DUNGEON:	"La Tour de Vlad" "T" (3, 0)
FICHIER_PROTO:	"tower"
DESCRIPTION:	mazelike
ENTREE:		-1
DUNGEON:	"Le Plan Astral" "A" (1, 0)
DESCRIPTION:	mazelike
FICHIER_PROTO:	"endgame"

NOTES:
Les lignes commençant par '#' sont considérées comme des commentaires.
Un niveau spécial doit être explicitement aligné. L'alignement du donjon dans lequel il se trouve ne s'applique qu'aux niveaux non spéciaux de ce donjon.
