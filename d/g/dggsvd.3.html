DGGSVD calcule la décomposition en valeurs singulières (SVD) pour d'AUTRES matrices

But :

!>
!> Cette routine est obsolète et a été remplacée par la routine DGGSVD3.
!>
!> DGGSVD calcule la décomposition en valeurs singulières généralisée (GSVD)
!> d'une matrice réelle A de dimension M par N et d'une matrice réelle B de dimension P par N :
!>
!>       U**T*A*Q = D1*( 0 R ),    V**T*B*Q = D2*( 0 R )
!>
!> où U, V et Q sont des matrices orthogonales.
!> Soit K+L = le rang numérique effectif de la matrice (A**T,B**T)**T,
!> alors R est une matrice triangulaire supérieure non singulière de dimension K+L par K+L, D1 et
!> D2 sont des matrices de dimension M par (K+L) et P par (K+L) respectivement et de la
!> structure suivante :
!>
!> Si M-K-L >= 0,
!>
!>                     K  L
!>        D1 =     K ( I  0 )
!>                 L ( 0  C )
!>             M-K-L ( 0  0 )
!>
!>                   K  L
!>        D2 =   L ( 0  S )
!>             P-L ( 0  0 )
!>
!>                 N-K-L  K    L
!>   ( 0 R ) = K (  0   R11  R12 )
!>             L (  0    0   R22 )
!>
!> où
!>
!>   C = diag( ALPHA(K+1), ... , ALPHA(K+L) ),
!>   S = diag( BETA(K+1),  ... , BETA(K+L) ),
!>   C**2 + S**2 = I.
!>
!>   R est stocké dans A(1:K+L,N-K-L+1:N) à la sortie.
!>
!> Si M-K-L < 0,
!>
!>                   K M-K K+L-M
!>        D1 =   K ( I  0    0   )
!>             M-K ( 0  C    0   )
!>
!>                     K M-K K+L-M
!>        D2 =   M-K ( 0  S    0  )
!>             K+L-M ( 0  0    I  )
!>               P-L ( 0  0    0  )
!>
!>                    N-K-L  K   M-K  K+L-M
!>   ( 0 R ) =     K ( 0    R11  R12  R13  )
!>               M-K ( 0     0   R22  R23  )
!>             K+L-M ( 0     0    0   R33  )
!>
!> où
!>
!>   C = diag( ALPHA(K+1), ... , ALPHA(M) ),
!>   S = diag( BETA(K+1),  ... , BETA(M) ),
!>   C**2 + S**2 = I.
!>
!>   (R11 R12 R13 ) est stocké dans A(1:M, N-K-L+1:N), et R33 est stocké
!>   ( 0  R22 R23 )
!>   dans B(M-K+1:L,N+M-K-L+1:N) à la sortie.
!>
!> La routine calcule C, S, R, et éventuellement les matrices de transformation
!> orthogonales U, V et Q.
!>
!> En particulier, si B est une matrice non singulière de dimension N par N, alors la GSVD de
!> A et B donne implicitement la SVD de A*inv(B) :
!>                      A*inv(B) = U*(D1*inv(D2))*V**T.
!> Si ( A**T,B**T)**T a des colonnes orthonormales, alors la GSVD de A et B est
!> aussi égale à la décomposition CS de A et B. De plus, la GSVD
!> peut être utilisée pour dériver la solution du problème de valeurs propres :
!>                      A**T*A x = lambda* B**T*B x.
!> Dans certaines littératures, la GSVD de A et B est présentée sous la forme
!>                  U**T*A*X = ( 0 D1 ),   V**T*B*X = ( 0 D2 )
!> où U et V sont orthogonales et X est non singulière, D1 et D2 sont
!> « diagonales ». La première forme de GSVD peut être convertie en la seconde
!> forme en prenant la matrice non singulière X comme
!>
!>                      X = Q*( I   0    )
!>                            ( 0 inv(R) ).
!>

Paramètres

JOBU 
!>          JOBU est CHARACTER*1
!>          = 'U' : la matrice orthogonale U est calculée ;
!>          = 'N' : U n'est pas calculée.
!>

JOBV

!>          JOBV est CHARACTER*1
!>          = 'V' : la matrice orthogonale V est calculée ;
!>          = 'N' : V n'est pas calculée.
!>

JOBQ

!>          JOBQ est CHARACTER*1
!>          = 'Q' : la matrice orthogonale Q est calculée ;
!>          = 'N' : Q n'est pas calculée.
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes des matrices A et B.  N >= 0.
!>

P

!>          P est INTEGER
!>          Le nombre de lignes de la matrice B.  P >= 0.
!>

K

!>          K est INTEGER
!>

L

!>          L est INTEGER
!>
!>          À la sortie, K et L spécifient la dimension des sous-blocs
!>          décrits dans la section But.
!>          K + L = rang numérique effectif de (A**T,B**T)**T.
!>

A

!>          A est un tableau DOUBLE PRECISION, dimension (LDA,N)
!>          À l'entrée, la matrice A de dimension M par N.
!>          À la sortie, A contient la matrice triangulaire R, ou une partie de R.
!>          Voir la section But pour plus de détails.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,M).
!>

B

!>          B est un tableau DOUBLE PRECISION, dimension (LDB,N)
!>          À l'entrée, la matrice B de dimension P par N.
!>          À la sortie, B contient la matrice triangulaire R si M-K-L < 0.
!>          Voir la section But pour plus de détails.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B. LDB >= max(1,P).
!>

ALPHA

!>          ALPHA est un tableau DOUBLE PRECISION, dimension (N)
!>

BETA

!>          BETA est un tableau DOUBLE PRECISION, dimension (N)
!>
!>          À la sortie, ALPHA et BETA contiennent les paires de valeurs
!>          singulières généralisées de A et B ;
!>            ALPHA(1:K) = 1,
!>            BETA(1:K)  = 0,
!>          et si M-K-L >= 0,
!>            ALPHA(K+1:K+L) = C,
!>            BETA(K+1:K+L)  = S,
!>          ou si M-K-L < 0,
!>            ALPHA(K+1:M)=C, ALPHA(M+1:K+L)=0
!>            BETA(K+1:M) =S, BETA(M+1:K+L) =1
!>          et
!>            ALPHA(K+L+1:N) = 0
!>            BETA(K+L+1:N)  = 0
!>

U

!>          U est un tableau DOUBLE PRECISION, dimension (LDU,M)
!>          Si JOBU = 'U', U contient la matrice orthogonale U de dimension M par M.
!>          Si JOBU = 'N', U n'est pas référencée.
!>

LDU

!>          LDU est INTEGER
!>          La dimension principale du tableau U. LDU >= max(1,M) si
!>          JOBU = 'U' ; LDU >= 1 sinon.
!>

V

!>          V est un tableau DOUBLE PRECISION, dimension (LDV,P)
!>          Si JOBV = 'V', V contient la matrice orthogonale V de dimension P par P.
!>          Si JOBV = 'N', V n'est pas référencée.
!>

LDV

!>          LDV est INTEGER
!>          La dimension principale du tableau V. LDV >= max(1,P) si
!>          JOBV = 'V' ; LDV >= 1 sinon.
!>

Q

!>          Q est un tableau DOUBLE PRECISION, dimension (LDQ,N)
!>          Si JOBQ = 'Q', Q contient la matrice orthogonale Q de dimension N par N.
!>          Si JOBQ = 'N', Q n'est pas référencée.
!>

LDQ

!>          LDQ est un ENTIER
!>          La dimension principale du tableau Q. LDQ >= max(1,N) si
!>          JOBQ = 'Q' ; LDQ >= 1 sinon.
!>

WORK

!>          WORK est un tableau DOUBLE PRECISION,
!>                      de dimension (max(3*N,M,P)+N)
!>

IWORK

!>          IWORK est un tableau ENTIER, de dimension (N)
!>          À la sortie, IWORK stocke les informations de tri. Plus
!>          précisément, la boucle suivante trie ALPHA
!>             pour I = K+1, min(M,K+L)
!>                 échanger ALPHA(I) et ALPHA(IWORK(I))
!>             finpour
!>          de sorte que ALPHA(1) >= ALPHA(2) >= ... >= ALPHA(N).
!>

INFO

!>          INFO est un ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.
!>          > 0 : si INFO = 1, la procédure de type Jacobi n'a pas réussi à
!>                converger. Pour plus de détails, voir la sous-routine DTGSJA.
!>

Paramètres internes :

!>  TOLA    DOUBLE PRECISION
!>  TOLB    DOUBLE PRECISION
!>          TOLA et TOLB sont les seuils pour déterminer le rang effectif
!>          de (A',B')**T. Généralement, ils sont définis comme suit :
!>                   TOLA = MAX(M,N)*norm(A)*MAZHEPS,
!>                   TOLB = MAX(P,N)*norm(B)*MAZHEPS.
!>          La taille de TOLA et TOLB peut affecter la taille des erreurs arrières
!>          de la décomposition.
!>
