sous-programme dget38 (double precision, dimension( 3 ) rmax, integer, dimension( 3 ) lmax, integer, dimension( 3 ) ninfo, integer knt, integer nin)

DGET38

Objectif :

!>
!> DGET38 teste DTRSEN, une routine pour estimer les nombres de condition d'un
!> cluster de valeurs propres et/ou de son sous-espace invariant à droite associé
!>
!> Les matrices de test sont lues à partir d'un fichier avec le numéro logique NIN.
!>

Paramètres

RMAX 
!>          RMAX est un tableau DOUBLE PRECISION, dimension (3)
!>          Valeurs des plus grands ratios de test.
!>          RMAX(1) = plus grands résidus de DHST01 ou comparaison
!>                    entre différents appels à DTRSEN
!>          RMAX(2) = plus grande erreur dans le conditionnement réciproque des nombres
!>                    en tenant compte de leur conditionnement
!>          RMAX(3) = plus grande erreur dans le conditionnement réciproque des nombres
!>                    sans tenir compte de leur conditionnement (peut être plus grand que RMAX(2))
!>

LMAX

!>          LMAX est un tableau INTEGER, dimension (3)
!>          LMAX(i) est le numéro de l'exemple où le plus grand ratio de test
!>          RMAX(i) est atteint. Aussi :
!>          Si DGEHRD renvoie INFO non nul pour l'exemple i, LMAX(1)=i
!>          Si DHSEQR renvoie INFO non nul pour l'exemple i, LMAX(2)=i
!>          Si DTRSEN renvoie INFO non nul pour l'exemple i, LMAX(3)=i
!>

NINFO

!>          NINFO est un tableau INTEGER, dimension (3)
!>          NINFO(1) = Nombre de fois où DGEHRD a renvoyé INFO non nul
!>          NINFO(2) = Nombre de fois où DHSEQR a renvoyé INFO non nul
!>          NINFO(3) = Nombre de fois où DTRSEN a renvoyé INFO non nul
!>

KNT

!>          KNT est un INTEGER
!>          Nombre total d'exemples testés.
!>

NIN

!>          NIN est un INTEGER
!>          Numéro logique d'entrée.
!>
