Documentation de la fonction/sous-programme

sous-programme dgeesx (caractère jobvs, caractère sort, externe select, caractère sense, entier n, double précision, dimension( lda, * ) a, entier lda, entier sdim, double précision, dimension( * ) wr, double précision, dimension( * ) wi, double précision, dimension( ldvs, * ) vs, entier ldvs, double précision rconde, double précision rcondv, double précision, dimension( * ) work, entier lwork, entier, dimension( * ) iwork, entier liwork, logique, dimension( * ) bwork, entier info)

DGEESX calcule les valeurs propres, la forme de Schur et, éventuellement, la matrice des vecteurs de Schur pour les matrices GE

Objectif :

!>
!> DGEESX calcule pour une matrice réelle N-par-N non symétrique A, les
!> valeurs propres, la forme de Schur réelle T, et, éventuellement, la matrice
!> des vecteurs de Schur Z. Cela donne la factorisation de Schur A = Z*T*(Z**T).
!>
!> Éventuellement, il ordonne également les valeurs propres sur la diagonale de
!> la forme de Schur réelle de sorte que les valeurs propres sélectionnées soient
!> en haut à gauche ;
!> calcule un nombre de condition réciproque pour la moyenne des
!> valeurs propres sélectionnées (RCONDE) ; et calcule un nombre de condition réciproque
!> pour le sous-espace invariant à droite correspondant aux
!> valeurs propres sélectionnées (RCONDV). Les colonnes de tête de Z forment une
!> base orthonormée pour ce sous-espace invariant.
!>
!> Pour plus d'explication sur les nombres de condition réciproques RCONDE
!> et RCONDV, voir la section 4.10 du LAPACK Users' Guide (où
!> ces quantités sont appelées s et sep respectivement).
!>
!> Une matrice réelle est en forme de Schur réelle si elle est supérieure quasi-triangulaire
!> avec des blocs de 1x1 et 2x2. Les blocs de 2x2 seront standardisés sous la forme
!>           [  a  b  ]
!>           [  c  a  ]
!>
!> où b*c < 0. Les valeurs propres d'un tel bloc sont a +- sqrt(bc).
!>

Paramètres

JOBVS 
!>          JOBVS est CARACTERE*1
!>          = 'N' : les vecteurs de Schur ne sont pas calculés ;
!>          = 'V' : les vecteurs de Schur sont calculés.
!>

SORT

!>          SORT est CARACTERE*1
!>          Spécifie si les valeurs propres doivent être ordonnées ou non sur la
!>          diagonale de la forme de Schur.
!>          = 'N' : les valeurs propres ne sont pas ordonnées ;
!>          = 'S' : les valeurs propres sont ordonnées (voir SELECT).
!>

SELECT

!>          SELECT est une FONCTION LOGIQUE de deux arguments DOUBLE PRÉCISION
!>          SELECT doit être déclarée EXTERNE dans le sous-programme appelant.
!>          Si SORT = 'S', SELECT est utilisé pour sélectionner les valeurs propres à trier
!>          en haut à gauche de la forme de Schur.
!>          Si SORT = 'N', SELECT n'est pas référencé.
!>          Une valeur propre WR(j)+sqrt(-1)*WI(j) est sélectionnée si
!>          SELECT(WR(j),WI(j)) est vrai ; c'est-à-dire si l'une
!>          d'une paire de valeurs propres conjuguées complexes est sélectionnée, alors les deux
!>          le sont. Notez qu'une valeur propre complexe sélectionnée peut ne plus
!>          satisfaire SELECT(WR(j),WI(j)) = .VRAI. après le tri, puisque
!>          le tri peut modifier la valeur des valeurs propres complexes
!>          (surtout si la valeur propre est mal conditionnée) ; dans ce
!>          cas, INFO peut être défini à N+3 (voir INFO ci-dessous).
!>

SENSE

!>          SENSE est CARACTERE*1
!>          Détermine quels nombres de condition réciproques sont calculés.
!>          = 'N' : aucun n'est calculé ;
!>          = 'E' : calculé pour la moyenne des valeurs propres sélectionnées uniquement ;
!>          = 'V' : calculé pour le sous-espace invariant à droite sélectionné uniquement ;
!>          = 'B' : calculé pour les deux.
!>          Si SENSE = 'E', 'V' ou 'B', SORT doit être égal à 'S'.
!>

N

!>          N est ENTIER
!>          L'ordre de la matrice A. N >= 0.
!>

A

!>          A est un tableau DOUBLE PRÉCISION, dimension (LDA, N)
!>          À l'entrée, la matrice A N-par-N.
!>          À la sortie, A est écrasé par sa forme de Schur réelle T.
!>

LDA

!>          LDA est ENTIER
!>          La dimension de tête du tableau A. LDA >= max(1,N).
!>

SDIM

!>          SDIM est ENTIER
!>          Si SORT = 'N', SDIM = 0.
!>          Si SORT = 'S', SDIM = nombre de valeurs propres (après tri)
!>                         pour lesquelles SELECT est vrai. (Les paires conjuguées complexes
!>                         pour lesquelles SELECT est vrai pour l'une ou l'autre des valeurs propres
!>                         comptent pour 2.)
!>

WR

!>          WR est un tableau DOUBLE PRÉCISION, dimension (N)
!>

WI

!>          WI est un tableau DOUBLE PRÉCISION, dimension (N)
!>          WR et WI contiennent les parties réelle et imaginaire, respectivement,
!>          des valeurs propres calculées, dans le même ordre qu'elles
!>          apparaissent sur la diagonale de la forme de Schur de sortie T. Les paires
!>          conjuguées complexes de valeurs propres apparaissent consécutivement, la
!>          valeur propre ayant la partie imaginaire positive en premier.
!>

VS

!>          VS est un tableau DOUBLE PRÉCISION, dimension (LDVS,N)
!>          Si JOBVS = 'V', VS contient la matrice orthogonale Z des vecteurs de Schur.
!>          Si JOBVS = 'N', VS n'est pas référencé.
!>

LDVS

!>          LDVS est ENTIER
!>          La dimension de tête du tableau VS. LDVS >= 1, et si
!>          JOBVS = 'V', LDVS >= N.
!>

RCONDE

!>          RCONDE est DOUBLE PRÉCISION
!>          Si SENSE = 'E' ou 'B', RCONDE contient le nombre de condition réciproque
!>          pour la moyenne des valeurs propres sélectionnées.
!>          Non référencé si SENSE = 'N' ou 'V'.
!>

RCONDV

!>          RCONDV est DOUBLE PRÉCISION
!>          Si SENSE = 'V' ou 'B', RCONDV contient le nombre de condition réciproque
!>          pour le sous-espace invariant à droite sélectionné.
!>          Non référencé si SENSE = 'N' ou 'E'.
!>

WORK

!>          WORK est un tableau DOUBLE PRÉCISION, dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) renvoie le LWORK optimal.
!>

LWORK

!>          LWORK est ENTIER
!>          La dimension du tableau WORK. LWORK >= max(1,3*N).
!>          Aussi, si SENSE = 'E' ou 'V' ou 'B',
!>          LWORK >= N+2*SDIM*(N-SDIM), où SDIM est le nombre de
!>          valeurs propres sélectionnées calculées par cette routine. Notez que
!>          N+2*SDIM*(N-SDIM) <= N+N*N/2. Notez également qu'une erreur n'est
!>          retournée que si LWORK < max(1,3*N), mais si SENSE = 'E' ou 'V' ou
!>          'B', cela peut ne pas être suffisant.
!>          Pour de bonnes performances, LWORK doit généralement être plus grand.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule uniquement les bornes supérieures des tailles optimales des
!>          tableaux WORK et IWORK, renvoie ces valeurs comme premières
!>          entrées des tableaux WORK et IWORK, et aucun message d'erreur
!>          lié à LWORK ou LIWORK n'est émis par XERBLA.
!>

IWORK

!>          IWORK est un tableau ENTIER, dimension (MAX(1,LIWORK))
!>          À la sortie, si INFO = 0, IWORK(1) renvoie le LIWORK optimal.
!>

LIWORK

!>          LIWORK est ENTIER
!>          La dimension du tableau IWORK.
!>          LIWORK >= N.
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule uniquement les bornes supérieures des tailles optimales des
!>          tableaux WORK et IWORK, renvoie ces valeurs comme premières
!>          entrées des tableaux WORK et IWORK, et aucun message d'erreur
!>          lié à LWORK ou LIWORK n'est émis par XERBLA.
!>

BWORK

!>          BWORK est un tableau LOGIQUE, dimension (MAX(1,N))
!>          Ce tableau est utilisé comme espace de travail interne.
!>

INFO

!>          INFO est ENTIER
!>          = 0 : exécution réussie.
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.
!>          > 0 : une erreur de convergence interne s'est produite. Le sous-programme
!>                n'a pas réussi à calculer toutes les valeurs propres.
!>                Plus précisément, si INFO = k > 0, alors k valeurs propres n'ont pas
!>                pu être calculées.
!>          = N+1 : Le tri des valeurs propres n'a pas pu être effectué. Les valeurs propres
!>                  ne sont pas dans l'ordre attendu.
!>          = N+2 : Le calcul du nombre de condition réciproque n'a pas pu être effectué.
!>          = N+3 : Le tri des valeurs propres n'a pas pu être effectué car au moins une
!>                  valeur propre sélectionnée ne satisfait plus la condition SELECT après
!>                  le tri.
!>
gt;= 1 ; si SENSE = 'V' ou 'B', LIWORK >= SDIM*(N-SDIM). !> Notez que SDIM*(N-SDIM) <= N*N/4. Notez également qu'une erreur n'est !> renvoyée que si LIWORK < 1, mais si SENSE = 'V' ou 'B' cela !> peut ne pas être suffisant. !> !> Si LIWORK = -1, une interrogation d'espace de travail est supposée ; la !> routine ne calcule que des bornes supérieures sur les tailles optimales !> des tableaux WORK et IWORK, renvoie ces valeurs comme les premières !> entrées des tableaux WORK et IWORK, et aucun message d'erreur !> lié à LWORK ou LIWORK n'est émis par XERBLA. !>

BWORK

!>          BWORK est un tableau LOGICAL, de dimension (N)
!>          Non référencé si SORT = 'N'.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.
!>          > 0 : si INFO = i, et i est
!>             <= N : l'algorithme QR n'a pas réussi à calculer toutes les
!>                   valeurs propres ; les éléments 1:ILO-1 et i+1:N de WR et WI
!>                   contiennent les valeurs propres qui ont convergé ; si
!>                   JOBVS = 'V', VS contient la transformation qui
!>                   réduit A à sa forme de Schur partiellement convergée.
!>             = N+1 : les valeurs propres n'ont pas pu être réordonnées car certaines
!>                   valeurs propres étaient trop proches pour être séparées (le problème
!>                   est très mal conditionné) ;
!>             = N+2 : après réordonnancement, l'arrondi a modifié les valeurs de certaines
!>                   valeurs propres complexes de sorte que les valeurs propres dominantes dans
!>                   la forme de Schur ne satisfont plus SELECT=.TRUE.. Cela
!>                   peut aussi être causé par un dépassement de capacité dû à la mise à l'échelle.
!>
