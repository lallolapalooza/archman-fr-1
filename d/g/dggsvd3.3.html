DGGSVD3 calcule la décomposition en valeurs singulières (SVD) pour les matrices OTHER

But :

!>
!> DGGSVD3 calcule la décomposition généralisée en valeurs singulières (GSVD)
!> d'une matrice réelle A de dimensions M par N et d'une matrice réelle B de
!> dimensions P par N :
!>
!>       U**T*A*Q = D1*( 0 R ),    V**T*B*Q = D2*( 0 R )
!>
!> où U, V et Q sont des matrices orthogonales.
!> Soit K+L = le rang numérique effectif de la matrice (A**T,B**T)**T,
!> alors R est une matrice triangulaire supérieure non singulière de
!> dimensions K+L par K+L, D1 et D2 sont des matrices de dimensions
!> M par (K+L) et P par (K+L) respectivement, de structures suivantes :
!>
!> Si M-K-L >= 0,
!>
!>                     K  L
!>        D1 =     K ( I  0 )
!>                 L ( 0  C )
!>             M-K-L ( 0  0 )
!>
!>                   K  L
!>        D2 =   L ( 0  S )
!>             P-L ( 0  0 )
!>
!>                 N-K-L  K    L
!>   ( 0 R ) = K (  0   R11  R12 )
!>             L (  0    0   R22 )
!>
!> où
!>
!>   C = diag( ALPHA(K+1), ... , ALPHA(K+L) ),
!>   S = diag( BETA(K+1),  ... , BETA(K+L) ),
!>   C**2 + S**2 = I.
!>
!>   R est stocké dans A(1:K+L,N-K-L+1:N) à la sortie.
!>
!> Si M-K-L < 0,
!>
!>                   K M-K K+L-M
!>        D1 =   K ( I  0    0   )
!>             M-K ( 0  C    0   )
!>
!>                     K M-K K+L-M
!>        D2 =   M-K ( 0  S    0  )
!>             K+L-M ( 0  0    I  )
!>               P-L ( 0  0    0  )
!>
!>                    N-K-L  K   M-K  K+L-M
!>   ( 0 R ) =     K ( 0    R11  R12  R13  )
!>               M-K ( 0     0   R22  R23  )
!>             K+L-M ( 0     0    0   R33  )
!>
!> où
!>
!>   C = diag( ALPHA(K+1), ... , ALPHA(M) ),
!>   S = diag( BETA(K+1),  ... , BETA(M) ),
!>   C**2 + S**2 = I.
!>
!>   (R11 R12 R13 ) est stocké dans A(1:M, N-K-L+1:N), et R33 est stocké
!>   ( 0  R22 R23 )
!>   dans B(M-K+1:L,N+M-K-L+1:N) à la sortie.
!>
!> La routine calcule C, S, R, et optionnellement les matrices de
!> transformation orthogonales U, V et Q.
!>
!> En particulier, si B est une matrice non singulière de dimensions N par N,
!> alors la GSVD de A et B donne implicitement la SVD de A*inv(B) :
!>                      A*inv(B) = U*(D1*inv(D2))*V**T.
!> Si ( A**T,B**T)**T a des colonnes orthonormales, alors la GSVD de A et B
!> est aussi égale à la décomposition CS de A et B. De plus, la GSVD
!> peut être utilisée pour dériver la solution du problème de valeurs
!> propres :
!>                      A**T*A x = lambda* B**T*B x.
!> Dans certaines littératures, la GSVD de A et B est présentée sous la forme
!>                  U**T*A*X = ( 0 D1 ),   V**T*B*X = ( 0 D2 )
!> où U et V sont orthogonales et X est non singulière, D1 et D2 sont
!> « diagonales ». La première forme de GSVD peut être convertie en la
!> seconde forme en prenant la matrice non singulière X comme
!>
!>                      X = Q*( I   0    )
!>                            ( 0 inv(R) ).
!>

Description


La routine DGGSVD3 calcule la décomposition SVD généralisée de deux
    matrices rectangulaires A et B de la forme :


A = U * diag(S) * V**T
B = V * diag(T) * W**T



où S et T sont des matrices diagonales réelles non négatives.


La décomposition SVD généralisée est définie par les matrices unitaires
    Q et Z de telle sorte que :


Q**T * A * Z = S
Q**T * B * Z = T



Les matrices S et T sont diagonales par blocs.


Les matrices S et T ont les formes suivantes :


      S = ( diag(Sigma)   0  )
          (      0        0  )

      T = ( diag(Theta)   0  )
          (      0        0  )



où Sigma et Theta sont des matrices diagonales réelles non négatives.


La matrice Sigma et Theta sont de la forme :


      Sigma = diag(s_1, ..., s_k, 0, ..., 0)
      Theta = diag(t_1, ..., t_k, 0, ..., 0)



La relation entre s_i et t_i est la suivante :


s_i**2 + t_i**2 = 1.0 (pour i = 1, ..., K)


Dans ce cas, K est le rang effectif de la paire (A, B).


Les matrices Q et Z sont des matrices unitaires.






Arguments




COMPQ


CHARACTER*1. Indique quelles matrices unitaires Q doivent être calculées.


Si COMPQ = 'Q', alors les M colonnes de Q sont calculées.


Si COMPQ = 'N', alors aucune matrice Q n'est calculée.


COMPZ


CHARACTER*1. Indique quelles matrices unitaires Z doivent être calculées.


Si COMPZ = 'Z', alors les P colonnes de Z sont calculées.


Si COMPZ = 'N', alors aucune matrice Z n'est calculée.


M


INTEGER. Le nombre de lignes de la matrice A.


N


INTEGER. Le nombre de colonnes des matrices A et B.


P


INTEGER. Le nombre de lignes de la matrice B.


A


DOUBLE PRECISION array, dimension (LDA, K), où K=max(M,N).


Sur l'entrée, la matrice A est de taille M x N.


Sur la sortie, si COMPQ = 'Q', alors A contient les U.


LDA


INTEGER.


La dimension de la première dimension de A.


B


DOUBLE PRECISION array, dimension (LDB, K), où K=max(P,N).


Sur l'entrée, la matrice B est de taille P x N.


Sur la sortie, si COMPZ = 'Z', alors B contient les W.


LDB


INTEGER.


La dimension de la première dimension de B.


TOL


DOUBLE PRECISION.


Le seuil pour déterminer le rang effectif des matrices.


TRUNC


INTEGER.


Le nombre de valeurs singulières non nulles.


Q


DOUBLE PRECISION array, dimension (LDQ, M).


Si COMPQ = 'Q', alors Q est une matrice unitaire M x M.


LDQ


INTEGER.


La dimension de la première dimension de Q.


LDQ >= max(1,M) si COMPQ = 'Q' ; LDQ >= 1 sinon.


Z


DOUBLE PRECISION array, dimension (LDZ, P).


Si COMPZ = 'Z', alors Z est une matrice unitaire P x P.


LDZ


INTEGER.


La dimension de la première dimension de Z.


LDZ >= max(1,P) si COMPZ = 'Z' ; LDZ >= 1 sinon.


WORK


DOUBLE PRECISION array, dimension (MAX(1,LWORK)).


Sur la sortie, si INFO = 0, WORK(1) contient la taille LWORK optimale.


LWORK


INTEGER.


La dimension du tableau WORK.


LWORK >= 1.


Si LWORK = -1, une requête d'espace de travail est supposée ; la routine
    calcule seulement la taille optimale du tableau WORK, renvoie cette valeur
    comme première entrée du tableau WORK, et aucun message d'erreur lié à
    LWORK n'est émis par XERBLA.


IWORK


INTEGER array, dimension (N).


Sur la sortie, IWORK stocke les informations de tri. Plus
    précisément, la boucle suivante trie ALPHA
    for I = K+1, min(M,K+L)
    swap ALPHA(I) and ALPHA(IWORK(I))
    endfor
    telle que ALPHA(1) >= ALPHA(2) >= ... >= ALPHA(N).


INFO


INTEGER.


= 0: sortie réussie.


< 0: si INFO = -i, le i-ème argument avait une valeur illégale.


> 0: si INFO = 1, la procédure de type Jacobi a échoué à
    converger. Pour plus de détails, voir la sous-routine DTGSJA.








Paramètres internes




 TOLA    DOUBLE PRECISION
 TOLB    DOUBLE PRECISION
         TOLA et TOLB sont les seuils pour déterminer le rang effectif
         de (A**T,B**T)**T. Généralement, ils sont définis à
                  TOLA = MAX(M,N)*norm(A)*MACHEPS,
                  TOLB = MAX(P,N)*norm(B)*MACHEPS.
         La taille de TOLA et TOLB peut affecter la taille des erreurs arrière
         de la décomposition.
