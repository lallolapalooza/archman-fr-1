Documentation de la fonction/sous-programme

subroutine dgemqrt (character side, character trans, integer m, integer n, integer k, integer nb, double precision, dimension( ldv, * ) v, integer ldv, double precision, dimension( ldt, * ) t, integer ldt, double precision, dimension( ldc, * ) c, integer ldc, double precision, dimension( * ) work, integer info)

DGEMQRT

But :

!>
!> DGEMQRT écrase la matrice réelle M par N de C avec
!>
!>                 SIDE = 'L'     SIDE = 'R'
!> TRANS = 'N':      Q C            C Q
!> TRANS = 'T':   Q**T C            C Q**T
!>
!> où Q est une matrice réelle orthogonale définie comme le produit de K
!> réflecteurs élémentaires :
!>
!>       Q = H(1) H(2) . . . H(K) = I - V T V**T
!>
!> généré en utilisant la représentation WY compacte telle que retournée par DGEQRT.
!>
!> Q est d'ordre M si SIDE = 'L' et d'ordre N si SIDE = 'R'.
!>

Paramètres

SIDE 
!>          SIDE est CHARACTER*1
!>          = 'L' : appliquer Q ou Q**T à gauche ;
!>          = 'R' : appliquer Q ou Q**T à droite.
!>

TRANS

!>          TRANS est CHARACTER*1
!>          = 'N' : Pas de transposée, appliquer Q ;
!>          = 'C' : Transposée, appliquer Q**T.
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice C. M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice C. N >= 0.
!>

K

!>          K est INTEGER
!>          Le nombre de réflecteurs élémentaires dont le produit définit
!>          la matrice Q.
!>          Si SIDE = 'L', M >= K >= 0 ;
!>          si SIDE = 'R', N >= K >= 0.
!>

NB

!>          NB est INTEGER
!>          La taille de bloc utilisée pour le stockage de T. K >= NB >= 1.
!>          Cela doit être la même valeur de NB utilisée pour générer T
!>          dans DGEQRT.
!>

V

!>          V est un tableau DOUBLE PRECISION, dimension (LDV,K)
!>          La i-ème colonne doit contenir le vecteur qui définit le
!>          réflecteur élémentaire H(i), pour i = 1,2,...,k, tel que retourné par
!>          DGEQRT dans les K premières colonnes de son argument tableau A.
!>

LDV

!>          LDV est INTEGER
!>          La dimension principale du tableau V.
!>          Si SIDE = 'L', LDA >= max(1,M) ;
!>          si SIDE = 'R', LDA >= max(1,N).
!>

T

!>          T est un tableau DOUBLE PRECISION, dimension (LDT,K)
!>          Les facteurs triangulaires supérieurs des réflecteurs de bloc
!>          tels que retournés par DGEQRT, stockés comme une matrice NB par N.
!>

LDT

!>          LDT est INTEGER
!>          La dimension principale du tableau T. LDT >= NB.
!>

C

!>          C est un tableau DOUBLE PRECISION, dimension (LDC,N)
!>          À l'entrée, la matrice M par N C.
!>          À la sortie, C est écrasé par Q C, Q**T C, C Q**T ou C Q.
!>

LDC

!>          LDC est INTEGER
!>          La dimension principale du tableau C. LDC >= max(1,M).
!>

WORK

!>          WORK est un tableau DOUBLE PRECISION. La dimension de
!>          WORK est N*NB si SIDE = 'L', ou M*NB si SIDE = 'R'.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>
