sous-routine dgelsd (integer m, integer n, integer nrhs, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( ldb, * ) b, integer ldb, double precision, dimension( * ) s, double precision rcond, integer rank, double precision, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, integer

DGELSD calcule la solution de norme minimale d'un problème de moindres carrés linéaire pour les matrices

GE

But

: 
!>
!> DGELSD calcule la solution de norme minimale d'un problème réel
!> de moindres carrés linéaire :
!>     minimiser 2-norme(| b - A*x |)
!> en utilisant la décomposition en valeurs singulières (SVD) de A. A est
!> une matrice M par N qui peut être de rang déficient.
!>
!> Plusieurs vecteurs second membres b et vecteurs solutions x peuvent
!> être traités dans un seul appel ; ils sont stockés en tant que colonnes
!> de la matrice second membre B de dimensions M par NRHS et de la matrice
!> solution X de dimensions N par NRHS.
!>
!> Le problème est résolu en trois étapes :
!> (1) Réduire la matrice des coefficients A à une forme bidiagonale avec
!>     des transformations de Householder, réduisant le problème original
!>     en un (BLS)
!> (2) Résoudre le BLS en utilisant une approche de type « diviser pour
!>     régner ».
!> (3) Appliquer rétroactivement toutes les transformations de Householder
!>     pour résoudre le problème original de moindres carrés.
!>
!> Le rang effectif de A est déterminé en traitant comme nulles les
!> valeurs singulières qui sont inférieures à RCOND fois la plus grande
!> valeur singulière.
!>
!
>

Paramètre

s
M 
!>          M est INTEGER
!>          Le nombre de lignes de A. M >= 0.
!
>

N 
!>          N est INTEGER
!>          Le nombre de colonnes de A. N >= 0.
!
>

NRH

S 
!>          NRHS est INTEGER
!>          Le nombre de second membres, c'est-à-dire le nombre de colonnes
!>          des matrices B et X. NRHS >= 0.
!
>

A 
!>          A est un tableau DOUBLE PRECISION, dimension (LDA,N)
!>          À l'entrée, la matrice A de dimensions M par N.
!>          À la sortie, A a été détruite.
!
>

LD

A 
!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,M).
!
>

B 
!>          B est un tableau DOUBLE PRECISION, dimension (LDB,NRHS)
!>          À l'entrée, la matrice second membre B de dimensions M par NRHS.
!>          À la sortie, B est écrasée par la matrice solution X de
!>          dimensions N par NRHS.  Si m >= n et RANK = n, la somme des
!>          carrés des résidus pour la solution dans la i-ième colonne est donnée
!>          par la somme des carrés des éléments n+1:m dans cette colonne.
!
>

LD

B 
!>          LDB est INTEGER
!>          La dimension principale du tableau B. LDB >= max(1,max(M,N)).
!
>

S 
!>          S est un tableau DOUBLE PRECISION, dimension (min(M,N))
!>          Les valeurs singulières de A en ordre décroissant.
!>          Le nombre de condition de A dans la 2-norme = S(1)/S(min(m,n)).
!
>

RCON

D 
!>          RCOND est DOUBLE PRECISION
!>          RCOND est utilisé pour déterminer le rang effectif de A.
!>          Les valeurs singulières S(i) <= RCOND*S(1) sont traitées comme nulles.
!>          Si RCOND < 0, la précision machine est utilisée à la place.
!
>

RAN

K 
!>          RANK est INTEGER
!>          Le rang effectif de A, c'est-à-dire le nombre de valeurs singulières
!>          qui sont supérieures à RCOND*S(1).
!
>

WOR

K 
!>          WORK est un tableau DOUBLE PRECISION, dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) renvoie le LWORK optimal.
!
>

LWOR

K 
!>          LWORK est INTEGER
!>          La dimension du tableau WORK. LWORK doit être au moins 1.
!>          La quantité exacte minimale d'espace de travail nécessaire dépend de M,
!>          N et NRHS. Tant que LWORK est au moins
!>              12*N + 2*N*SMLSIZ + 8*N*NLVL + N*NRHS + (SMLSIZ+1)**2,
!>          si M est supérieur ou égal à N, ou
!>              12*M + 2*M*SMLSIZ + 8*M*NLVL + M*NRHS + (SMLSIZ+1)**2,
!>          si M est inférieur à N, le code s'exécutera correctement.
!>          SMLSIZ est renvoyé par ILAENV et est égal à la taille maximale
!>          des sous-problèmes au bas de l'arbre de calcul (généralement environ 25), et
!>             NLVL = MAX( 0, INT( LOG_2( MIN( M,N )/(SMLSIZ+1) ) ) + 1 )
!>          Pour de bonnes performances, LWORK devrait généralement être plus grand.
!>
!>          Si LWORK = -1, une interrogation d'espace de travail est supposée ; la routine
!>          calcule uniquement la taille optimale du tableau WORK, renvoie
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          lié à LWORK n'est émis par XERBLA.
!
>

IWOR

K 
!>          IWORK est un tableau INTEGER, dimension (MAX(1,LIWORK))
!>          LIWORK >= max(1, 3 * MINMN * NLVL + 11 * MINMN),
!>          où MINMN = MIN( M,N ).
!>          À la sortie, si INFO = 0, IWORK(1) renvoie le LIWORK minimal.
!
>

INF

O 
!>          INFO est INTEGER
!>          = 0:  sortie réussie
!>          < 0:  si INFO = -i, le i-ième argument avait une valeur illégale.
!>          > 0:  l'algorithme de calcul de la SVD n'a pas convergé ;
!>                si INFO = i, i éléments hors diagonale d'une forme
!>                bidiagonale intermédiaire n'ont pas convergé vers zéro.
!
>
