!> !> DGGEV calcule pour une paire de matrices réelles non symétriques N×N (A,B) !> les valeurs propres généralisées, et optionnellement, les vecteurs !> propres généralisés gauche et/ou droit. !> !> Une valeur propre généralisée pour une paire de matrices (A,B) est un scalaire !> lambda ou un rapport alpha/beta = lambda, tel que A - lambda*B est !> singulière. Elle est généralement représentée sous la forme de la paire (alpha,beta), car !> il existe une interprétation raisonnable pour beta=0, et même pour les deux !> valant zéro. !> !> Le vecteur propre droit v(j) correspondant à la valeur propre lambda(j) !> de (A,B) satisfait !> !> A * v(j) = lambda(j) * B * v(j). !> !> Le vecteur propre gauche u(j) correspondant à la valeur propre lambda(j) !> de (A,B) satisfait !> !>

u(j)**H * A = lambda(j) * u(j)**H * B . !> !> où u(j)**H est le conjugué-transposé de u(j). !> !>

dggev(3)

                
NOM

                
dggev - Résout le problème généralisé de valeurs propres pour deux matrices réelles doubles.

                

                    
SYNTAXE

                    
CALL DGGEV( JOBVL, JOBVR, N, A, LDA, B, LDB, ALPHAR, ALPHAI, BETA, VL, LDVL, VR, LDVR, WORK, LWORK, INFO )

                    

                        Le sous-programme DGGEV est utilisé pour résoudre le problème généralisé de valeurs propres pour deux matrices réelles doubles A et B. Il calcule les valeurs propres généralisées (ALPHAR(i) + i*ALPHAI(i)) / BETA(i) et les vecteurs propres gauches et/ou droits correspondants.
                    

                

                

                    
Documentation des fonctions/sous-routines

                    

                        Le calcul des valeurs propres généralisées pour A et B implique de trouver des scalaires w et des vecteurs non nuls v tels que :
                    

                    
A * v = w * B * v

                    

                        ou de manière équivalente :
                    

                    
(A - w * B) * v = 0

                    

                        ou encore :
                    

                    
alpha * B * v = beta * A * v

                    

                        où alpha et beta sont des scalaires tels que alpha/beta = w.
                    

                    

                        Les paramètres de la sous-routine DGGEV sont les suivants :
                    

                    
    
                        
  • JOBVL : Caractère. Indique si les vecteurs propres gauches sont calculés. ('N' pour non, 'V' pour oui).
    • 
                        
  • JOBVR : Caractère. Indique si les vecteurs propres droits sont calculés. ('N' pour non, 'V' pour oui).
    • 
                        
  • N : Entier. La taille de la matrice.
    • 
                        
  • A : Tableau double précision de taille LDA x N. La matrice d'entrée.
    • 
                        
  • LDA : Entier. La première dimension de A.
    • 
                        
  • B : Tableau double précision de taille LDB x N. La matrice d'entrée.
    • 
                        
  • LDB : Entier. La première dimension de B.
    • 
                        
  • ALPHAR : Tableau double précision de taille N. La partie réelle des scalaires alpha.
    • 
                        
  • ALPHAI : Tableau double précision de taille N. La partie imaginaire des scalaires alpha.
    • 
                        
  • BETA : Tableau double précision de taille N. Les scalaires beta.
    • 
                        
  • VL : Tableau double précision de taille LDVL x N. Les vecteurs propres gauches calculés.
    • 
                        
  • LDVL : Entier. La première dimension de VL.
    • 
                        
  • VR : Tableau double précision de taille LDVR x N. Les vecteurs propres droits calculés.
    • 
                        
  • LDVR : Entier. La première dimension de VR.
    • 
                        
  • WORK : Tableau double précision de taille LWORK. Un espace de travail.
    • 
                        
  • LWORK : Entier. La taille de WORK.
    • 
                        
  • INFO : Entier. Indicateur d'erreur. INFO < 0 indique une erreur dans les paramètres d'entrée. INFO > 0 indique qu'un algorithme de convergence a échoué.
    • 
                    

                    

                        Les valeurs propres généralisées sont données par (ALPHAR(i) + i*ALPHAI(i)) / BETA(i). Si BETA(i) est zéro, alors la valeur propre est infinie. Si ALPHAI(i) est zéro et ALPHAR(i) est non nul, la valeur propre est réelle. Sinon, elle est complexe.
