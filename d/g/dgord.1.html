dgord(1) Manuel de l'utilisateur PT-Scotch dgord(1)

NOM

dgord - calculer des ordonnancements de matrices creuses de graphes en parallèle

SYNTAXE

dgord [options] [gfile] [ofile] [lfile]

DESCRIPTION

Le programme dgord calcule, de manière parallèle, un ordonnancement d'un graphe source Scotch représentant le motif d'une matrice creuse symétrique.

Le fichier de graphe source gfile est soit un fichier de graphe centralisé, soit un ensemble de fichiers représentant des fragments d'un graphe distribué. L'ordonnancement résultant est stocké dans le fichier ofile. Les informations de journalisation éventuelles (telles que celles produites par l'option -v) sont envoyées au fichier lfile. Lorsque les noms de fichiers ne sont pas spécifiés, les données sont lues depuis l'entrée standard et écrites sur la sortie standard. Les flux standards peuvent également être explicitement représentés par un tiret '-'.

Lorsque les bibliothèques appropriées ont été incluses lors de la compilation, dgord peut gérer directement les graphes compressés, tant en entrée qu'en sortie. Un flux est traité comme compressé dès lors que son nom est suffixé d'une extension de fichier compressé, telle que dans 'brol.grf.bz2' ou '-.gz'. Les formats de compression pris en charge sont le format bzip2 ('.bz2'), le format gzip ('.gz') et le format lzma ('.lzma').

dgord s'appuie sur des implémentations de l'interface MPI pour répartir le travail entre les éléments de traitement. Il n'est donc pas susceptible d'être exécuté directement, mais plutôt via une commande de lancement telle que mpirun.

OPTIONS

-c?opt
Choisir la stratégie d'ordonnancement par défaut selon une ou plusieurs options parmi :
b
appliquer l'équilibrage de charge autant que possible.
q
privilégier la qualité sur la vitesse (par défaut).
s
privilégier la vitesse sur la qualité.
t
appliquer la sécurité.
x
appliquer la scalabilité.
-h
afficher une aide.
-m?mfile
enregistrer les données de mappage des blocs de colonnes dans le fichier mfile. Les données de mappage spécifient, pour chaque sommet, l'indice du bloc de colonnes auquel ce sommet appartient.
-o?strat
utiliser la stratégie d'ordonnancement de graphe parallèle strat (voir le manuel de l'utilisateur PT-Scotch pour plus d'informations).
-r?pnum
définir le processus racine pour les fichiers centralisés (par défaut est 0).
-t?tfile
enregistrer les données de l'arbre de partitionnement dans le fichier tfile. Les données de l'arbre de partitionnement spécifient, pour chaque sommet, l'indice du premier sommet du bloc parent du bloc auquel le sommet appartient. Combinées aux données de mappage fournies dans le fichier mfile, elles permettent de reconstruire l'arbre des séparateurs du processus de dissection imbriquée.
-V
afficher la version du programme et le copyright.
-v?verb
définir le mode verbeux à verb. C'est un ensemble d'un ou plusieurs caractères qui peuvent être :
s
informations sur la stratégie.
t
informations de chronométrage.

EXEMPLES

Exécuter dgord sur 5 éléments de traitement pour réordonnancer le graphe de matrice brol.grf et enregistrer l'ordonnancement résultant dans le fichier brol.ord, en utilisant la stratégie d'ordonnancement de graphe séquentiel par défaut :

    $ mpirun -np 5 dgord brol.grf brol.ord
Exécuter dgord sur 5 éléments de traitement pour réordonnancer la matrice distribuée stockée dans les fichiers de fragments de graphe brol5-0.dgr à brol5-4.dgr, et enregistrer l'ordonnancement résultant dans le fichier brol.ord (voir dgscat(1) pour une explication des séquences '%p' et '%r' dans les noms des fragments de graphe distribué). 
    $ mpirun -np 5 dgord brol%p-%r.dgr brol.ord
