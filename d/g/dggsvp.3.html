But

: 
!>
!> Cette routine est obsolète et a été remplacée par la routine DGGSVP3.
!>
!> DGGSVP calcule les matrices orthogonales U, V et Q telles que
!>
!>                    N-K-L  K    L
!>  U**T*A*Q =     K ( 0    A12  A13 )  si M-K-L >= 0;
!>                 L ( 0     0   A23 )
!>             M-K-L ( 0     0    0  )
!>
!>                  N-K-L  K    L
!>         =     K ( 0    A12  A13 )  si M-K-L < 0;
!>             M-K ( 0     0   A23 )
!>
!>                  N-K-L  K    L
!>  V**T*B*Q =   L ( 0     0   B13 )
!>             P-L ( 0     0    0  )
!>
!> où la matrice A12 de taille K par K et la matrice B13 de taille L par L
!> sont triangulaires supérieures non singulières ; A23 est triangulaire
!> supérieure de taille L par L si M-K-L >= 0, sinon A23 est trapézoïdale
!> supérieure de taille (M-K) par L. K+L = le rang numérique effectif de la
!> matrice (A**T,B**T)**T de taille (M+P) par N.
!>
!> Cette décomposition est l'étape de prétraitement pour le calcul de la
!> Décomposition en Valeurs Singulières Généralisée (GSVD), voir la
!> sous-routine DGGSVD.
!
>

!
>

TOL

B 
!>          TOLB est DOUBLE PRECISION
!>
!>          TOLA et TOLB sont les seuils utilisés pour déterminer le rang
!>          numérique effectif de la matrice B et d'un sous-bloc de A.
!>          Généralement, ils sont définis à
!>             TOLA = MAX(M,N)*norm(A)*MACHEPS,
!>             TOLB = MAX(P,N)*norm(B)*MACHEPS.
!>          La taille de TOLA et TOLB peut affecter la taille des erreurs
!>          arrière de la décomposition.

U
