DGBRFSX

Objectif :

!>
!>    DGBRFSX améliore la solution calculée d'un système d'équations linéaires
!>    et fournit des bornes d'erreur et des estimations d'erreur arrière
!>    pour la solution. En plus de la borne d'erreur normée, le code
!>    fournit une borne d'erreur composante maximale si possible. Voir
!>    les commentaires pour ERR_BNDS_NORM et ERR_BNDS_COMP pour les détails des
!>    bornes d'erreur.
!>
!>    Le système d'équations linéaires original peut avoir été équilibré
!>    avant d'appeler cette routine, comme décrit par les arguments EQUED, R
!>    et C ci-dessous. Dans ce cas, la solution et les bornes d'erreur retournées
!>    sont pour le système original non équilibré.
!> 
!>     Certains paramètres optionnels sont regroupés dans le tableau PARAMS. Ces
!>     paramètres déterminent comment le raffinement est effectué, mais souvent
!>     les valeurs par défaut sont acceptables. Si les valeurs par défaut sont acceptables, les utilisateurs
!>     peuvent passer NPARAMS = 0, ce qui empêche le code source d'accéder
!>     à l'argument PARAMS.
!>

Paramètres

TRANS 
!>          TRANS est CHARACTER*1
!>     Spécifie la forme du système d'équations :
!>       = 'N':  A * X = B     (Pas de transposée)
!>       = 'T':  A**T * X = B  (Transposée)
!>       = 'C':  A**H * X = B  (Conjuguée transposée = Transposée)
!>

EQUED

!>          EQUED est CHARACTER*1
!>     Spécifie la forme d'équilibration qui a été effectuée sur A
!>     avant d'appeler cette routine. Ceci est nécessaire pour calculer
!>     la solution et les bornes d'erreur correctement.
!>       = 'N':  Aucune équilibration
!>       = 'R':  Équilibrage des lignes, c'est-à-dire que A a été pré-multiplié par
!>               diag(R).
!>       = 'C':  Équilibrage des colonnes, c'est-à-dire que A a été post-multiplié
!>               par diag(C).
!>       = 'B':  Équilibrage des lignes et des colonnes, c'est-à-dire que A a été
!>               remplacé par diag(R) * A * diag(C).
!>               Le membre de droite B a été modifié en conséquence.
!>

N

!>          N est INTEGER
!>     L'ordre de la matrice A. N >= 0.
!>

KL

!>          KL est INTEGER
!>     Le nombre de sous-diagonales dans la bande de A. KL >= 0.
!>

KU

!>          KU est INTEGER
!>     Le nombre de super-diagonales dans la bande de A. KU >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>     Le nombre de membres de droite, c'est-à-dire le nombre de colonnes
!>     des matrices B et X. NRHS >= 0.
!>

AB

!>          AB est un tableau DOUBLE PRECISION, de dimension (LDAB,N)
!>     La matrice de bande originale A, stockée dans les lignes 1 à KL+KU+1.
!>     La j-ème colonne de A est stockée dans la j-ème colonne du
!>     tableau AB comme suit :
!>     AB(ku+1+i-j,j) = A(i,j) pour max(1,j-ku) <= i <= min(n,j+kl).
!>

LDAB

!>          LDAB est INTEGER
!>     La dimension principale du tableau AB. LDAB >= KL+KU+1.
!>

AFB

!>          AFB est un tableau DOUBLE PRECISION, de dimension (LDAFB,N)
!>     Détails de la factorisation LU de la matrice de bande A, comme
!>     calculé par DGBTRF. U est stocké comme une matrice triangulaire supérieure de bande
!>     avec KL+KU super-diagonales dans les lignes 1 à KL+KU+1, et
!>     les multiplicateurs utilisés lors de la factorisation sont stockés dans
!>     les lignes KL+KU+2 à 2*KL+KU+1.
!>

LDAFB

!>          LDAFB est INTEGER
!>     La dimension principale du tableau AFB. LDAFB >= 2*KL*KU+1.
!>

IPIV

!>          IPIV est un tableau INTEGER, de dimension (N)
!>     Les indices de pivot de DGETRF ; pour 1 <= i <= N, la ligne i de la
!>     matrice a été échangée avec la ligne IPIV(i).
!>

R

!>          R est un tableau DOUBLE PRECISION, de dimension (N)
!>     Les facteurs d'échelle des lignes de A. Si EQUED = 'R' ou 'B', A est
!>     multiplié à gauche par diag(R) ; si EQUED = 'N' ou 'C', R
!>     n'est pas accédé. R est un argument d'entrée si FACT = 'F' ;
!>     sinon, R est un argument de sortie. Si FACT = 'F' et
!>     EQUED = 'R' ou 'B', chaque élément de R doit être positif.
!>     Si R est en sortie, chaque élément de R est une puissance de la base.
!>     Si R est en entrée, chaque élément de R doit être une puissance de la base
!>     pour assurer une solution et des estimations d'erreur fiables. La mise à l'échelle par
!>     des puissances de la base ne cause pas d'erreurs d'arrondi sauf si le
!>     résultat sousflue ou déborde. Les erreurs d'arrondi lors de la mise à l'échelle
!>     conduisent à un raffinement avec une matrice non équivalente à la
!>     matrice d'entrée, produisant des estimations d'erreur qui peuvent ne pas être
!>     fiables.
!>

C

!>          C est un tableau DOUBLE PRECISION, de dimension (N)
!>     Les facteurs d'échelle des colonnes de A. Si EQUED = 'C' ou 'B', A est
!>     multiplié à droite par diag(C) ; si EQUED = 'N' ou 'R', C
!>     n'est pas accédé. C est un argument d'entrée si FACT = 'F' ;
!>     sinon, C est un argument de sortie. Si FACT = 'F' et
!>     EQUED = 'C' ou 'B', chaque élément de C doit être positif.
!>     Si C est en sortie, chaque élément de C est une puissance de la base.
!>     Si C est en entrée, chaque élément de C doit être une puissance de la base
!>     pour assurer une solution et des estimations d'erreur fiables. La mise à l'échelle par
!>     des puissances de la base ne cause pas d'erreurs d'arrondi sauf si le
!>     résultat sousflue ou déborde. Les erreurs d'arrondi lors de la mise à l'échelle
!>     conduisent à un raffinement avec une matrice non équivalente à la
!>     matrice d'entrée, produisant des estimations d'erreur qui peuvent ne pas être
!>     fiables.
!>

B

!>          B est un tableau DOUBLE PRECISION, de dimension (LDB,NRHS)
!>     La matrice du membre de droite B.
!>

LDB

!>          LDB est INTEGER
!>     La dimension principale du tableau B. LDB >= max(1,N).
!>

X

!>          X est un tableau DOUBLE PRECISION, de dimension (LDX,NRHS)
!>     À l'entrée, la matrice solution X, telle que calculée par DGETRS.
!>     À la sortie, la matrice solution améliorée X.
!>

LDX

!>          LDX est INTEGER
!>     La dimension principale
