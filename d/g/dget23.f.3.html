!>
!>    DGET23 vérifie le pilote de problème de valeurs propres non symétrique SGEEVX.
!>    Si COMP = .FALSE., les 8 premiers des tests suivants seront
!>    effectués sur la matrice d'entrée A, et également le test 9 si LWORK est
!>    suffisamment grand.
!>    Si COMP est .TRUE., les 11 tests seront effectués.
!>
!>    (1)     | A * VR - VR * W | / ( n |A| ulp )
!>
!>      Ici VR est la matrice des vecteurs propres droits unitaires.
!>      W est une matrice diagonale par blocs, avec un bloc 1x1 pour chaque
!>      valeur propre réelle et un bloc 2x2 pour chaque paire conjuguée
!>      complexe. Si les valeurs propres j et j+1 forment une paire conjuguée
!>      complexe, de sorte que WR(j) = WR(j+1) = wr et WI(j) = - WI(j+1) = wi, alors le
!>      bloc 2 x 2 correspondant à la paire sera :
!>
!>              (  wr  wi  )
!>              ( -wi  wr  )
!>
!>      Un tel bloc multipliant une matrice n x 2 ( ur ui ) à droite
!>      revient au même que de multiplier ur + i*ui par wr + i*wi.
!>
!>    (2)     | A**H * VL - VL * W**H | / ( n |A| ulp )
!>
!>      Ici VL est la matrice des vecteurs propres gauches unitaires, A**H est la
!>      transposée conjuguée de A, et W est comme ci-dessus.
!>
!>    (3)     | |VR(i)| - 1 | / ulp et plus grand composant réel
!>
!>      VR(i) désigne la i-ième colonne de VR.
!>
!>    (4)     | |VL(i)| - 1 | / ulp et plus grand composant réel
!>
!>      VL(i) désigne la i-ième colonne de VL.
!>
!>    (5)     0 si W(full) = W(partial), 1/ulp sinon
!>
!>      W(full) désigne les valeurs propres calculées lorsque VR, VL, RCONDV
!>      et RCONDE sont également calculés, et W(partial) désigne les
!>      valeurs propres calculées lorsque seulement certains de VR, VL, RCONDV et
!>      RCONDE sont calculés.
!>
!>    (6)     0 si VR(full) = VR(partial), 1/ulp sinon
!>
!>      VR(full) désigne les vecteurs propres droits calculés lorsque VL, RCONDV
!>      et RCONDE sont calculés, et VR(partial) désigne le résultat
!>      lorsque seulement certains de VL et RCONDV sont calculés.
!>
!>    (7)     0 si VL(full) = VL(partial), 1/ulp sinon
!>
!>      VL(full) désigne les vecteurs propres gauches calculés lorsque VR, RCONDV
!>      et RCONDE sont calculés, et VL(partial) désigne le résultat
!>      lorsque seulement certains de VR et RCONDV sont calculés.
!>
!>    (8)     0 si SCALE, ILO, IHI, ABNRM (full) =
!>                 SCALE, ILO, IHI, ABNRM (partial)
!>            1/ulp sinon
!>
!>      SCALE, ILO, IHI et ABNRM décrivent comment la matrice est équilibrée.
!>      (full) est lorsque VR, VL, RCONDE et RCONDV sont également calculés, et
!>      (partial) est lorsque certains ne sont pas calculés.
!>
!>    (9)     0 si RCONDV(full) = RCONDV(partial), 1/ulp sinon
!>
!>      RCONDV(full) désigne les nombres de condition réciproques des
!>      vecteurs propres droits calculés lorsque VR, VL et RCONDE sont également
!>      calculés. RCONDV(partial) désigne les nombres de condition
!>      réciproques lorsque seulement certains de VR, VL et RCONDE sont calculés.
!>
!>   (10)     |RCONDV - RCDVIN| / cond(RCONDV)
!>
!>      RCONDV est le nombre de condition réciproque du vecteur propre droit
!>      calculé par DGEEVX et RCDVIN (la valeur vraie précalculée)
!>      est fourni en entrée. cond(RCONDV) est le nombre de condition de
!>      RCONDV, et prend en compte les erreurs dans le calcul de RCONDV, de sorte
!>      que la quantité résultante devrait être O(ULP). cond(RCONDV) est
!>      essentiellement donné par norm(A)/RCONDE.
!>
!>   (11)     |RCONDE - RCDEIN| / cond(RCONDE)
!>
!>      RCONDE est le nombre de condition réciproque de la valeur propre
!>      calculé par DGEEVX et RCDEIN (la valeur vraie précalculée)
!>      est fourni en entrée. cond(RCONDE) est le nombre de condition
!>      de RCONDE, et prend en compte les erreurs dans le calcul de RCONDE,
!>      de sorte que la quantité résultante devrait être O(ULP). cond(RCONDE)
!>      est essentiellement donné par norm(A)/RCONDV.
!
>

Paramètre

s
COMP 
!>          COMP est de type LOGICAL
!>          COMP décrit quels tests d'entrée effectuer :
!>            = .FALSE. si les nombres de condition calculés ne doivent pas
!>                      être testés par rapport à RCDVIN et RCDEIN
!>            = .TRUE.  s'ils doivent être comparés
!
>

BALAN

C 
!>          BALANC est de type CHARACTER
!>          Décrit l'option d'équilibrage à tester.
!>            = 'N' pour aucune permutation ni mise à l'échelle diagonale
!>            = 'P' pour permutation mais pas de mise à l'échelle diagonale
!>            = 'S' pour pas de permutation mais mise à l'échelle diagonale
!>            = 'B' pour permutation et mise à l'échelle diagonale
!
>

JTYP

E 
!>          JTYPE est de type INTEGER
!>          Type de la matrice d'entrée. Utilisé pour étiqueter la sortie en cas d'erreur.
!
>

THRES

H 
!>          THRESH est de type DOUBLE PRECISION
!>          Un test sera considéré comme réussi si la valeur, calculée comme
!>          décrit ci-dessus, dépasse THRESH. Notez que l'erreur
!>          est mise à l'échelle pour être O(1), donc THRESH devrait être un multiple raisonnablement
!>          petit de 1, par ex. 10 ou 100. En particulier,
!>          il ne devrait pas dépendre de la précision (simple vs. double)
!>          ni de la taille de la matrice. Il doit être au moins zéro.
!
>

ISEE

D 
!>          ISEED est un tableau de type INTEGER, dimension (4)
!>          Si COMP = .FALSE., la graine du générateur de nombres aléatoires
!>          utilisée pour produire la matrice.
!>          Si COMP = .TRUE., ISEED(1) = le numéro de l'exemple.
!>          U

Documentation de la fonction/sous-routine


Cette routine est un prototype de test pour la sous-routine
    LAPACK DGEEVX.


Arguments:



    
CHARACTER * 1FUNITS

    
Indique le type d'unités de sortie : 'U' pour des unités ASCII, 'A' pour
        des unités ASCII, 'L' pour des unités logiques.

    
INTEGERNOUNIT

    
Numéro d'unité FORTRAN pour l'impression des messages d'erreur (par
        exemple, si une routine retourne INFO différent de 0).

    
INTEGERN

    
La dimension de A. N doit être au moins 0.

    
DOUBLE PRECISIONA(LDA,N)

    
Contient la matrice dont les valeurs propres doivent être calculées.

    
INTEGERLDA

    
La dimension principale de A et H. LDA doit être au moins 1 et au moins N.

    
DOUBLE PRECISIONH(LDA,N)

    
Une autre copie de la matrice de test A, modifiée par DGEEVX.

    
DOUBLE PRECISIONWR(N)

    

    
DOUBLE PRECISIONWI(N)

    
Les parties réelle et imaginaire des valeurs propres de A. À la sortie,
        WR + WI*i sont les valeurs propres de la matrice dans A.

    
DOUBLE PRECISIONWR1(N)

    

    
DOUBLE PRECISIONWI1(N)

    
Similaires à WR, WI, ces tableaux contiennent les valeurs propres de A,
        mais celles calculées lorsque DGEEVX ne calcule qu'une décomposition
        propre partielle, c'est-à-dire pas les valeurs propres et les vecteurs
        propres gauches et droits.

    
DOUBLE PRECISIONVL(LDVL,N)

    
VL contient les vecteurs propres gauches calculés.

    
INTEGERLDVL

    
La dimension principale de VL. Doit être au moins max(1,N).

    
DOUBLE PRECISIONVR(LDVR,N)

    
VR contient les vecteurs propres droits calculés.

    
INTEGERLDVR

    
La dimension principale de VR. Doit être au moins max(1,N).

    
DOUBLE PRECISIONLRE(LDLRE,N)

    
LRE contient les vecteurs propres droits ou gauches calculés.

    
INTEGERLDLRE

    
La dimension principale de LRE. Doit être au moins max(1,N).

    
DOUBLE PRECISIONRCONDV(N)

    
RCONDV contient les nombres de condition réciproques calculés pour les
        vecteurs propres.

    
DOUBLE PRECISIONRCNDV1(N)

    
RCNDV1 contient d'autres nombres de condition réciproques calculés pour
        les vecteurs propres.

    
DOUBLE PRECISIONRCDVIN(N)

    
Lorsque COMP = .TRUE., RCDVIN contient les nombres de condition
        réciproques précalculés pour les vecteurs propres à comparer avec RCONDV.

    
DOUBLE PRECISIONRCONDE(N)

    
RCONDE contient les nombres de condition réciproques calculés pour les
        valeurs propres.

    
DOUBLE PRECISIONRCNDE1(N)

    
RCNDE1 contient d'autres nombres de condition réciproques calculés pour
        les valeurs propres.

    
DOUBLE PRECISIONRCDEIN(N)

    
Lorsque COMP = .TRUE., RCDEIN contient les nombres de condition
        réciproques précalculés pour les valeurs propres à comparer avec RCONDE.

    
DOUBLE PRECISIONSCALE(N)

    
Contient des informations décrivant l'équilibrage de la matrice.

    
DOUBLE PRECISIONSCALE1(N)

    
Contient des informations décrivant l'équilibrage de la matrice.

    
DOUBLE PRECISIONRESULT(11)

    
Les valeurs calculées par les 11 tests décrits ci-dessus. Les valeurs sont
        actuellement limitées à 1/ulp, pour éviter le débordement.

    
DOUBLE PRECISIONWORK(LWORK)

    

    
INTEGERLWORK

    
Le nombre d'entrées dans WORK. Il doit être au moins 3*N, et 6*N+N**2 si
        les tests 9, 10 ou 11 doivent être effectués.

    
INTEGERIWORK(2*N)

    

    
INTEGERINFO

    
Si 0, sortie réussie. Si <0, le paramètre d'entrée -INFO avait une
        valeur incorrecte. Si >0, DGEEVX a retourné un code d'erreur, dont la
        valeur absolue est retournée.
