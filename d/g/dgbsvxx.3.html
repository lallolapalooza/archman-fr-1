sous-routine dgbsvxx (character fact, character trans, integer n, integer kl, integer ku, integer nrhs, double precision, dimension( ldab, * ) ab, integer ldab, double precision, dimension( ldafb, * ) afb, integer ldafb, integer, dimension( * ) ipiv, character equed, double precision, dimension( * ) r, double precision, dimension( * ) c, double precision, dimension( ldb, * ) b, integer ldb, double precision, dimension( ldx , * ) x, integer ldx, double precision rcond, double precision rpvgrw, double precision, dimension( * ) berr, integer n_err_bnds, double precision, dimension( nrhs, * ) err_bnds_norm, double precision, dimension( nrhs, * ) err_bnds_comp, integer nparams, double precision, dimension( * ) params, double precision, dimension( * ) work, integer, dimension( * ) iwork, integer info)

DGBSVXX calcule la solution du système d'équations linéaires A * X = B pour les matrices GB

Objectif :

!>
!>    DGBSVXX utilise la factorisation LU pour calculer la solution d'un
!>    système d'équations linéaires en double précision A * X = B, où A est une
!>    matrice N par N et X et B sont des matrices N par NRHS.
!>
!>    Si demandé, des bornes d'erreur normées et des bornes d'erreur par composante maximale
!>    sont retournées. DGBSVXX retournera une solution avec une petite erreur garantie
!>    (O(eps) où eps est la précision de la machine de travail) sauf si la matrice est très mal conditionnée,
!>    auquel cas un avertissement est retourné. Les nombres de condition pertinents sont également
!>    calculés et retournés.
!>
!>    DGBSVXX accepte des factorisations et des facteurs d'équilibrage fournis par l'utilisateur ;
!>    voir les définitions des options FACT et EQUED.
!>    La résolution avec raffinement et l'utilisation d'une factorisation d'un appel précédent DGBSVXX produiront également une solution avec des erreurs O(eps) ou des avertissements, mais nous ne pouvons pas faire cette affirmation pour des factorisations et des facteurs d'équilibrage fournis par l'utilisateur en général s'ils diffèrent de ce que DGBSVXX produirait lui-même.
!>

Description :

!>
!>    Les étapes suivantes sont effectuées :
!>
!>    1. Si FACT = 'E', des facteurs d'échelle en double précision sont calculés pour équilibrer
!>    le système :
!>
!>      TRANS = 'N':  diag(R)*A*diag(C)     *inv(diag(C))*X = diag(R)*B
!>      TRANS = 'T': (diag(R)*A*diag(C))**T *inv(diag(R))*X = diag(C)*B
!>      TRANS = 'C': (diag(R)*A*diag(C))**H *inv(diag(R))*X = diag(C)*B
!>
!>    Que le système soit équilibré ou non dépend de la mise à l'échelle de la matrice A,
!>    mais si l'équilibrage est utilisé, A est écrasé par diag(R)*A*diag(C) et B par diag(R)*B (si TRANS='N')
!>    ou diag(C)*B (si TRANS = 'T' ou 'C').
!>
!>    2. Si FACT = 'N' ou 'E', la décomposition LU est utilisée pour factoriser
!>    la matrice A (après équilibrage si FACT = 'E') comme suit :
!>
!>      A = P * L * U,
!>
!>    où P est une matrice de permutation, L est une matrice triangulaire inférieure unitaire,
!>    et U est triangulaire supérieure.
!>
!>    3. Si un U(i,i)=0, de sorte que U soit exactement singulier, alors la
!>    routine retourne avec INFO = i. Sinon, la forme factorisée de A
!>    est utilisée pour estimer le nombre de condition de la matrice A (voir
!>    l'argument RCOND). Si la réciproque du nombre de condition est inférieure à la
!>    précision de la machine, la routine continue pour résoudre X
!>    et calculer les bornes d'erreur comme décrit ci-dessous.
!>
!>    4. Le système d'équations est résolu pour X en utilisant la forme factorisée de A.
!>
!>    5. Par défaut (sauf si PARAMS(LA_LINRX_ITREF_I) est mis à zéro),
!>    la routine utilise le raffinement itératif pour tenter d'obtenir une petite erreur
!>    et des bornes d'erreur. Le raffinement calcule le résidu à
!>    au moins deux fois la précision de travail.
!>
!>    6. Si l'équilibrage a été utilisé, la matrice X est prémultipliée par
!>    diag(C) (si TRANS = 'N') ou diag(R) (si TRANS = 'T' ou 'C') de sorte qu'elle
!>    résolve le système original avant l'équilibrage.
!> 
!>     Certains paramètres optionnels sont regroupés dans le tableau PARAMS. Ces
!>     paramètres déterminent comment le raffinement est effectué, mais souvent les
!>     valeurs par défaut sont acceptables. Si les valeurs par défaut sont acceptables, les utilisateurs
!>     peuvent passer NPARAMS = 0, ce qui empêche le code source d'accéder
!>     à l'argument PARAMS.
!>

Paramètres :

FACT 
!>          FACT est CHARACTER*1
!>     Spécifie si la forme factorisée de la matrice A est
!>     fournie à l'entrée, et si ce n'est pas le cas, si la matrice A doit être
!>     équilibrée avant d'être factorisée.
!>       = 'F' : À l'entrée, AF et IPIV contiennent la forme factorisée de A.
!>               Si EQUED n'est pas 'N', la matrice A a été
!>               équilibrée avec les facteurs d'échelle donnés par R et C.
!>               A, AF et IPIV ne sont pas modifiés.
!>       = 'N' : La matrice A sera copiée dans AF et factorisée.
!>       = 'E' : La matrice A sera équilibrée si nécessaire, puis
!>               copiée dans AF et factorisée.
!>

TRANS

!>          TRANS est CHARACTER*1
!>     Spécifie la forme du système d'équations :
!>       = 'N' :  A * X = B     (Pas de transpose)
!>       = 'T' :  A**T * X = B  (Transpose)
!>       = 'C' :  A**H * X = B  (Conjugué Transposé = Transposé)
!>

N

!>          N est INTEGER
!>     Le nombre d'équations linéaires, c'est-à-dire l'ordre de
!>     la matrice A.  N >= 0.
!>

KL

!>          KL est INTEGER
!>     Le nombre de sous-diagonales dans la bande de A.  KL >= 0.
!>

KU

!>          KU est INTEGER
!>     Le nombre de super-diagonales dans la bande de A.  KU >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>     Le nombre de membres de droite, c'est-à-dire le nombre de colonnes
!>     des matrices B et X.  NRHS >= 0.
!>

AB

!>          AB est un tableau DOUBLE PRECISION, de dimension (LDAB,N)
!>     À l'entrée, la matrice A en stockage bande, dans les lignes 1 à KL+KU+1.
!>     La j-ème colonne de A est stockée dans la j-ème colonne du
!>     tableau AB comme suit :
!>     AB(KU+1+i-j,j) = A(i,j) pour max(1,j-KU)<=i<=min(N,j+kl)
!>
!>     Si FACT = 'F' et EQUED n'est pas 'N', alors AB doit avoir été
!>     équilibré par les facteurs d'échelle dans R et/ou C.  AB n'est pas
!>     modifié si FACT = 'F' ou 'N', ou si FACT = 'E' et
!>     EQUED = 'N' à la sortie.
!>
!>     À la sortie, si EQUED .ne. 'N', A est mis à l'échelle comme suit :
!>     EQUED = 'R':  A := diag(R) * A
!>     EQUED = 'C':  A := A * diag(C)
!>     EQUED = 'B':  A := diag(R) * A * diag(C).
!>

LDAB

!>          LDAB est INTEGER
!>     La dimension principale du tableau AB.  LDAB >= KL+KU+1.
!>

AFB

!>

U est stockée comme une !> matrice bande triangulaire supérieure avec KL+KU surdiagonales !> dans les lignes 1 à KL+KU+1, et les multiplicateurs utilisés !> pendant la factorisation sont stockés dans les lignes !> KL+KU+2 à 2*KL+KU+1. Si EQUED .ne. 'N', alors AFB est !> la forme factorisée de la matrice équilibrée A. !> !> Si FACT = 'N', alors AF est un argument de sortie et à la sortie !> renvoie les facteurs L et U de la factorisation A = P*L*U !> de la matrice originale A. !> !> Si FACT = 'E', alors AF est un argument de sortie et à la sortie !> renvoie les facteurs L et U de la factorisation A = P*L*U !> de la matrice équilibrée A (voir la description de A pour !> la forme de la matrice équilibrée). !>

LDAFB

!>          LDAFB est INTEGER
!>     La dimension principale du tableau AFB.  LDAFB >= 2*KL+KU+1.
!>

IPIV

!>          IPIV est un tableau INTEGER, dimension (N)
!>     Si FACT = 'F', alors IPIV est un argument d'entrée et à l'entrée
!>     contient les indices de pivot de la factorisation A = P*L*U
!>     telle que calculée par DGETRF ; la ligne i de la matrice a été
!>     interchangée avec la ligne IPIV(i).
!>
!>     Si FACT = 'N', alors IPIV est un argument de sortie et à la sortie
!>     contient les indices de pivot de la factorisation A = P*L*U
!>     de la matrice originale A.
!>
!>     Si FACT = 'E', alors IPIV est un argument de sortie et à la sortie
!>     contient les indices de pivot de la factorisation A = P*L*U
!>     de la matrice équilibrée A.
!>

EQUED

!>          EQUED est CHARACTER*1
!>     Spécifie la forme d'équilibrage qui a été effectuée.
!>       = 'N' :  Pas d'équilibrage (toujours vrai si FACT = 'N').
!>       = 'R' :  Équilibrage par ligne, c.-à-d. A a été multipliée
!>                à gauche par diag(R).
!>       = 'C' :  Équilibrage par colonne, c.-à-d. A a été multipliée
!>                à droite par diag(C).
!>       = 'B' :  Équilibrage par ligne et par colonne, c.-à-d. A a été
!>                remplacée par diag(R) * A * diag(C).
!>     EQUED est un argument d'entrée si FACT = 'F' ; sinon, c'est un
!>     argument de sortie.
!>

R

!>          R est un tableau DOUBLE PRECISION, dimension (N)
!>     Les facteurs d'échelle de ligne pour A.  Si EQUED = 'R' ou 'B', A est
!>     multipliée à gauche par diag(R) ; si EQUED = 'N' ou 'C', R
!>     n'est pas accédé.  R est un argument d'entrée si FACT = 'F' ;
!>     sinon, R est un argument de sortie.  Si FACT = 'F' et
!>     EQUED = 'R' ou 'B', chaque élément de R doit être positif.
!>     Si R est en sortie, chaque élément de R est une puissance de la base.
!>     Si R est en entrée, chaque élément de R devrait être une puissance de la base
!>     pour garantir une solution et des estimations d'erreur fiables. La mise à l'échelle par
!>     puissances de la base ne provoque pas d'erreurs d'arrondi sauf si le
!>     résultat déborde ou est sous le seuil. Les erreurs d'arrondi pendant la mise à l'échelle
!>     conduisent à un raffinement avec une matrice qui n'est pas équivalente à la
!>     matrice d'entrée, produisant des estimations d'erreur qui peuvent ne pas être
!>     fiables.
!>

C

!>          C est un tableau DOUBLE PRECISION, dimension (N)
!>     Les facteurs d'échelle de colonne pour A.  Si EQUED = 'C' ou 'B', A est
!>     multipliée à droite par diag(C) ; si EQUED = 'N' ou 'R', C
!>     n'est pas accédé.  C est un argument d'entrée si FACT = 'F' ;
!>     sinon, C est un argument de sortie.  Si FACT = 'F' et
!>     EQUED = 'C' ou 'B', chaque élément de C doit être positif.
!>     Si C est en sortie, chaque élément de C est une puissance de la base.
!>     Si C est en entrée, chaque élément de C devrait être une puissance de la base
!>     pour garantir une solution et des estimations d'erreur fiables. La mise à l'échelle par
!>     puissances de la base ne provoque pas d'erreurs d'arrondi sauf si le
!>     résultat déborde ou est sous le seuil. Les erreurs d'arrondi pendant la mise à l'échelle
!>     conduisent à un raffinement avec une matrice qui n'est pas équivalente à la
!>     matrice d'entrée, produisant des estimations d'erreur qui peuvent ne pas être
!>     fiables.
!>

B

!>          B est un tableau DOUBLE PRECISION, dimension (LDB,NRHS)
!>     À l'entrée, la matrice second membre B de dimension N par NRHS.
!>     À la sortie,
!>     si EQUED = 'N', B n'est pas modifiée ;
!>     si TRANS = 'N' et EQUED = 'R' ou 'B', B est écrasée par
!>        diag(R)*B ;
!>     si TRANS = 'T' ou 'C' et EQUED = 'C' ou 'B', B est
!>        écrasée par diag(C)*B.
!>

LDB

!>          LDB est INTEGER
!>     La dimension principale du tableau B.  LDB >= max(1,N).
!>

X

!>          X est un tableau DOUBLE PRECISION, dimension (LDX,NRHS)
!>     Si INFO = 0, la matrice solution X de dimension N par NRHS du système
!>     d'équations original.  Notez que A et B sont modifiées à la sortie
!>     si EQUED .ne. 'N', et la solution du système équilibré est
!>     inv(diag(C))*X si TRANS = 'N' et EQUED = 'C' ou 'B', ou
!>     inv(diag(R))*X si TRANS = 'T' ou 'C' et EQUED = 'R' ou 'B'.
!>

LDX

!>          LDX est INTEGER
!>     La dimension principale du tableau X.  LDX >= max(1,N).
!>

RCOND

!>          RCOND est DOUBLE PRECISION
!>     Nombre de condition réciproque mis à l'échelle.  Ceci est une estimation du
!>     nombre de condition réciproque de Skeel de la matrice A après
!>     équilibrage (si effectué).  Si ceci est inférieur à la précision
!>     machine (en particulier, s'il est zéro), la matrice est singulière
!>     à la précision de travail.  Notez que l'erreur peut encore être petite même
!>     si ce nombre est très petit et que la matrice semble mal
!>     conditionnée.
!>

RPVGRW

!>          RPVGRW est DOUBLE PRECISION
!>     Croissance réciproque du pivot.  À la sortie, ceci contient le facteur
!>     de croissance réciproque du pivot norm(A)/norm(U). La
!>     norme est utilisée.  Si ceci est beaucoup inférieur à 1, alors la stabilité de
!>     la factorisation LU de la matrice (équilibrée) A pourrait être mauvaise.
!>     Cela signifie également que la solution X, les nombres de condition estimés
!>     et les bornes d'erreur pourraient ne pas être fiables. Si la factorisation échoue avec
!>     0<INFO<=N, alors ceci contient le facteur de croissance réciproque du pivot
!>     pour les INFO premières colonnes de A.  Dans DGESVX, cette quantité est
!>     renvoyée dans WORK(1).
!>

BERR

!>          BERR est un tableau DOUBLE PRECISION, dimension (NRHS)
!>     Erreur arrière relative composante par composante.  Ceci est
!>     l'erreur arrière relative composante par composante de chaque vecteur solution X(j)
!>     (c.-à-d. le plus petit changement relatif dans n'importe quel élément de A ou B qui
!>     rend X(j) une solution exacte).
!>

N_ERR_BNDS

!>          N_ERR_BNDS est INTEGER
!>     Nombre de bornes d'erreur à renvoyer pour chaque second membre
!>     et chaque type (au sens de la norme ou composante par composante).  Voir ERR_BNDS_NORM et
!>     ERR_BNDS_COMP ci-dessous.
!>

ERR_BNDS_NORM

!>          ERR_BNDS_NORM est un tableau DOUBLE PRECISION, dimension (NRHS, N_ERR_BNDS)
!>     Pour chaque second membre, ce tableau contient des informations sur
!>     diverses bornes d'erreur et nombres de condition correspondant à
!>     l'erreur relative au sens de la norme, qui est définie comme suit :
!>
!>     Erreur relative au sens de la norme dans le ième vecteur solution :
!>             max_j (abs(XTRUE(j,i) - X(j,i)))
!>            ------------------------------
!>                  max_j abs(X(j,i))
!>
!>     Le tableau est indexé par le type d'information d'erreur tel que décrit
!>     ci-dessous. Il y a actuellement jusqu'à trois informations
!>     renvoyées.
!>
!>     Le premier indice dans ERR_BNDS_NORM(i,:) correspond au ième
!>     second membre.
!>
!>     Le second indice dans ERR_BNDS_NORM(:,err) contient les trois
!>     champs suivants :
!>     err = 1  booléen. Faire confiance à la réponse si le
!>              nombre de condition réciproque est inférieur au seuil
!>              sqrt(n) * dlamch('Epsilon').
!>
!>     err = 2  borne d'erreur : L'erreur avant estimée,
!>              presque certainement dans un facteur de 10 de l'erreur réelle
!>              tant que l'entrée suivante est supérieure au seuil
!>              sqrt(n) * dlamch('Epsilon'). Cette borne d'erreur ne devrait
!>              être fiable que si le booléen précédent est vrai.
!>
!>     err = 3  Nombre de condition réciproque : Nombre de condition
!>              réciproque estimé au sens de la norme.  Comparé au seuil
!>              sqrt(n) * dlamch('Epsilon') pour déterminer si l'estimation
!>              d'erreur est . Ces nombres de condition
!>              réciproques sont 1 / (norm(Z^{-1},inf) * norm(Z,inf)) pour une
!>              matrice Z mise à l'échelle de manière appropriée.
!>              Soit Z = S*A, où S met chaque ligne à l'échelle par une puissance de la
!>              base de sorte que toutes les sommes absolues de lignes de Z soient approximativement 1.
!>
!>     Voir Lapack Working Note 165 pour plus de détails et des
!>     avertissements supplémentaires.
!>

ERR_BNDS_COMP

!>          ERR_BNDS_COMP est un tableau DOUBLE PRECISION, dimension (NRHS, N_ERR_BNDS)
!>     Pour chaque second membre, ce tableau contient des informations sur
!>     diverses bornes d'erreur et nombres de condition correspondant à
!>     l'erreur relative composante par composante, qui est définie comme suit :
!>
!>     Erreur relative composante par composante dans le ième vecteur solution :
!>                    abs(XTRUE(j,i) - X(j,i))
!>             max_j ----------------------
!>                         abs(X(j,i))
!>
!>     Le tableau est indexé par le second membre i (dont dépend
!>     l'erreur relative composante par composante), et le type d'information
!>     d'erreur tel que décrit ci-dessous. Il y a actuellement jusqu'à trois
!>     informations renvoyées pour chaque second membre. Si
!>     la précision composante par composante n'est pas demandée (PARAMS(3) = 0.0), alors
!>     ERR_BNDS_COMP n'est pas accédé.  Si N_ERR_BNDS < 3, alors au plus
!>     les premières entrées (:,N_ERR_BNDS) sont renvoyées.
!>
!>     Le premier indice dans ERR_BNDS_COMP(i,:) correspond au ième
!>     second membre.
!>
!>     Le second indice dans ERR_BNDS_COMP(:,err) contient les trois
!>     champs suivants :
!>     err = 1  booléen. Faire confiance à la réponse si le
!>              nombre de condition réciproque est inférieur au seuil
!>              sqrt(n) * dlamch('Epsilon').
!>
!>     err = 2  borne d'erreur : L'erreur avant estimée,
!>              presque certainement dans un facteur de 10 de l'erreur réelle
!>              tant que l'entrée suivante est supérieure au seuil
!>              sqrt(n) * dlamch('Epsilon'). Cette borne d'erreur ne devrait
!>              être fiable que si le booléen précédent est vrai.
!>
!>     err = 3  Nombre de condition réciproque : Nombre de condition
!>              réciproque estimé composante par composante.  Comparé au seuil
!>              sqrt(n) * dlamch('Epsilon') pour déterminer si l'estimation
!>              d'erreur est . Ces nombres de condition
!>              réciproques sont 1 / (norm(Z^{-1},inf) * norm(Z,inf)) pour une
!>              matrice Z mise à l'échelle de manière appropriée.
!>              Soit Z = S*(A*diag(x)), où x est la solution pour le
!>              second membre courant et S met chaque ligne de
!>              A*diag(x) à l'échelle par une puissance de la base de sorte que toutes les sommes absolues de lignesms de Z sont approximativement égaux à 1.
!>
!>     Voir la Note de Travail LAPACK 165 pour plus de détails et des
!>     avertissements supplémentaires.
!
>

NPARAM

S 
!>          NPARAMS est INTEGER
!>     Spécifie le nombre de paramètres définis dans PARAMS. Si <= 0, le

PARAM

S 
!>          PARAMS est un tableau DOUBLE PRECISION, dimension (NPARAMS)
!>     Spécifie les paramètres de l'algorithme. Si une entrée est < 0.0, alors
!>     cette entrée sera remplie avec la valeur par défaut utilisée pour ce
!>     paramètre. Seules les positions jusqu'à NPARAMS sont accédées ; les valeurs
!>     par défaut sont utilisées pour les paramètres de numéro supérieur.
!>
!>       PARAMS(LA_LINRX_ITREF_I = 1) : Indique s'il faut effectuer le

!>         Par défaut : 1.0 (tenter la convergence composante par composante)
!

INF

O 
!>          INFO est INTEGER
!>       = 0 :  Sortie réussie. La solution à chaque second membre est
