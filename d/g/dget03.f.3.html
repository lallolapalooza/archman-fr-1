Documentation de la fonction/sous-routine

sous-routine dget03 (integer n, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( ldainv, * ) ainv, integer ldainv, double precision, dimension( ldwork, * ) work, integer ldwork, double precision, dimension( * ) rwork, double precision rcond, double precision resid)

DGET03

But:

!>
!> DGET03 calcule le résidu pour une matrice générale multipliée par son inverse :
!>    norm( I - AINV*A ) / ( N * norm(A) * norm(AINV) * EPS ),
!> où EPS est l'epsilon machine.
!>

Paramètres

N 
!>          N est un entier (INTEGER)
!>          Le nombre de lignes et de colonnes de la matrice A.  N >= 0.
!>

A

!>          A est un tableau de double précision (DOUBLE PRECISION), dimension (LDA,N)
!>          La matrice originale A de taille N x N.
!>

LDA

!>          LDA est un entier (INTEGER)
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

AINV

!>          AINV est un tableau de double précision (DOUBLE PRECISION), dimension (LDAINV,N)
!>          L'inverse de la matrice A.
!>

LDAINV

!>          LDAINV est un entier (INTEGER)
!>          La dimension principale du tableau AINV.  LDAINV >= max(1,N).
!>

WORK

!>          WORK est un tableau de double précision (DOUBLE PRECISION), dimension (LDWORK,N)
!>

LDWORK

!>          LDWORK est un entier (INTEGER)
!>          La dimension principale du tableau WORK.  LDWORK >= max(1,N).
!>

RWORK

!>          RWORK est un tableau de double précision (DOUBLE PRECISION), dimension (N)
!>

RCOND

!>          RCOND est un double précision (DOUBLE PRECISION)
!>          L'inverse du nombre de condition de A, calculé comme
!>          ( 1/norm(A) ) / norm(AINV).
!>

RESID

!>          RESID est un double précision (DOUBLE PRECISION)
!>          norm(I - AINV*A) / ( N * norm(A) * norm(AINV) * EPS )
!>
