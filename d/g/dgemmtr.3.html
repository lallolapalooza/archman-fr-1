DGEMMTR

Documentation de la fonction/sous-routine

sous-routine dgemmtr (caractère uplo, caractère transa, caractère transb, entier n, entier k, double précision alpha, double précision, dimension(lda,*) a, entier lda, double précision, dimension(ldb,*) b, entier ldb, double précision beta, double précision, dimension(ldc,*) c, entier ldc)

DGEMMTR

Objectif:

!>
!> DGEMMTR  effectue l'une des opérations matricielles
!>
!>    C := alpha*op( A )*op( B ) + beta*C,
!>
!> où  op( X ) est l'une des opérations :
!>
!>    op( X ) = X   ou   op( X ) = X**T,
!>
!> alpha et beta sont des scalaires, et A, B et C sont des matrices, avec
!> op( A ) une matrice n par k, op( B ) une matrice k par n et C une matrice
!> n par n.
!> De plus, la routine n'accède et ne met à jour que la partie triangulaire
!> supérieure ou inférieure de la matrice résultat C. Ce comportement peut
!> être utilisé si la matrice C résultante est connue pour être symétrique.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>           À l'entrée, UPLO spécifie si la partie triangulaire inférieure ou
!>           supérieure de C est accédée et mise à jour.
!>
!>              UPLO = 'L' ou 'l', la partie triangulaire inférieure de C est utilisée.
!>
!>              UPLO = 'U' ou 'u', la partie triangulaire supérieure de C est utilisée.
!>

TRANSA

!>          TRANSA est CHARACTER*1
!>           À l'entrée, TRANSA spécifie la forme de op( A ) à utiliser dans
!>           la multiplication matricielle comme suit :
!>
!>              TRANSA = 'N' ou 'n',  op( A ) = A.
!>
!>              TRANSA = 'T' ou 't',  op( A ) = A**T.
!>
!>              TRANSA = 'C' ou 'c',  op( A ) = A**T.
!>

TRANSB

!>          TRANSB est CHARACTER*1
!>           À l'entrée, TRANSB spécifie la forme de op( B ) à utiliser dans
!>           la multiplication matricielle comme suit :
!>
!>              TRANSB = 'N' ou 'n',  op( B ) = B.
!>
!>              TRANSB = 'T' ou 't',  op( B ) = B**T.
!>
!>              TRANSB = 'C' ou 'c',  op( B ) = B**T.
!>

N

!>          N est INTEGER
!>           À l'entrée, N spécifie le nombre de lignes et de colonnes de
!>           la matrice C, le nombre de colonnes de op(B) et le nombre
!>           de lignes de op(A). N doit être supérieur ou égal à zéro.
!>

K

!>          K est INTEGER
!>           À l'entrée, K spécifie le nombre de colonnes de la matrice
!>           op( A ) et le nombre de lignes de la matrice op( B ). K doit
!>           être supérieur ou égal à zéro.
!>

ALPHA

!>          ALPHA est DOUBLE PRECISION.
!>           À l'entrée, ALPHA spécifie le scalaire alpha.
!>

A

!>          A est un tableau DOUBLE PRECISION, de dimension ( LDA, ka ), où ka est
!>           k  lorsque  TRANSA = 'N' ou 'n',  et est  n  sinon.
!>           Avant l'entrée avec  TRANSA = 'N' ou 'n',  la partie principale n par k
!>           du tableau  A  doit contenir la matrice  A,  sinon
!>           la partie principale  k par m  du tableau  A  doit contenir  la
!>           matrice A.
!>

LDA

!>          LDA est INTEGER
!>           À l'entrée, LDA spécifie la première dimension de A telle que déclarée
!>           dans le programme appelant (sous-programme). Lorsque  TRANSA = 'N' ou 'n' alors
!>           LDA doit être au moins  max( 1, n ), sinon  LDA doit être au
!>           moins  max( 1, k ).
!>

B

!>          B est un tableau DOUBLE PRECISION, de dimension ( LDB, kb ), où kb est
!>           n  lorsque  TRANSB = 'N' ou 'n',  et est  k  sinon.
!>           Avant l'entrée avec  TRANSB = 'N' ou 'n',  la partie principale k par n
!>           du tableau  B  doit contenir la matrice  B,  sinon
!>           la partie principale  n par k  du tableau  B  doit contenir  la
!>           matrice B.
!>

LDB

!>          LDB est INTEGER
!>           À l'entrée, LDB spécifie la première dimension de B telle que déclarée
!>           dans le programme appelant (sous-programme). Lorsque  TRANSB = 'N' ou 'n' alors
!>           LDB doit être au moins  max( 1, k ), sinon  LDB doit être au
!>           moins  max( 1, n ).
!>

BETA

!>          BETA est DOUBLE PRECISION.
!>           À l'entrée, BETA spécifie le scalaire beta. Lorsque BETA est
!>           fourni comme zéro, C n'a pas besoin d'être défini à l'entrée.
!>

C

!>          C est un tableau DOUBLE PRECISION, de dimension ( LDC, N )
!>           Avant l'entrée, la partie principale n par n du tableau C doit
!>           contenir la matrice C, sauf lorsque beta est zéro, auquel cas
!>           C n'a pas besoin d'être défini à l'entrée.
!>           À la sortie, la partie triangulaire supérieure ou inférieure de la matrice
!>           C est écrasée par la matrice n par n
!>           ( alpha*op( A )*op( B ) + beta*C ).
!>

LDC

!>          LDC est INTEGER
!>           À l'entrée, LDC spécifie la première dimension de C telle que déclarée
!>           dans le programme appelant (sous-programme). LDC doit être au
!>           moins  max( 1, n ).
!>
