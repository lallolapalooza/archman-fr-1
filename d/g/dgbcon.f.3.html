sous-routine dgbcon (caractere norme, entier n, entier kl, entier ku, double precision, dimension( ldab, * ) ab, entier ldab, entier, dimension( * ) ipiv, double precision norme_a, double precision rcond, double precision, dimension( * ) travail, entier, dimension( * ) iwork, entier info)

DGBCON

Objectif :

!>
!> DGBCON estime l'inverse du nombre de condition d'une matrice bande générale
!> réelle A, dans la norme 1 ou la norme l'infini, en utilisant la factorisation
!> LU calculée par DGBTRF.
!>
!> Une estimation de norm(inv(A)) est obtenue, et l'inverse du nombre de
!> condition est calculé comme suit :
!>    RCOND = 1 / ( norm(A) * norm(inv(A)) ).
!>

Paramètres

NORME 
!>          NORME est de type CHARACTER*1
!>          Spécifie si le nombre de condition en norme 1 ou en norme
!>          l'infini est requis :
!>          = '1' ou 'O' :  norme 1 ;
!>          = 'I'        :  norme l'infini.
!>

N

!>          N est un ENTIER
!>          L'ordre de la matrice A.  N >= 0.
!>

KL

!>          KL est un ENTIER
!>          Le nombre de sous-diagonales dans la bande de A.  KL >= 0.
!>

KU

!>          KU est un ENTIER
!>          Le nombre de super-diagonales dans la bande de A.  KU >= 0.
!>

AB

!>          AB est un tableau de type DOUBLE PRECISION, de dimension (LDAB,N)
!>          Détails de la factorisation LU de la matrice bande A, tels que
!>          calculés par DGBTRF. U est stocké comme une matrice bande
!>          triangulaire supérieure avec KL+KU super-diagonales dans les
!>          lignes 1 à KL+KU+1, et les multiplicateurs utilisés pendant
!>          la factorisation sont stockés dans les lignes KL+KU+2 à 2*KL+KU+1.
!>

LDAB

!>          LDAB est un ENTIER
!>          La dimension principale du tableau AB.  LDAB >= 2*KL+KU+1.
!>

IPIV

!>          IPIV est un tableau de type ENTIER, de dimension (N)
!>          Les indices de pivot ; pour 1 <= i <= N, la ligne i de la matrice a
!>          été échangée avec la ligne IPIV(i).
!>

ANORM

!>          ANORM est de type DOUBLE PRECISION
!>          Si NORME = '1' ou 'O', la norme 1 de la matrice originale A.
!>          Si NORME = 'I', la norme l'infini de la matrice originale A.
!>

RCOND

!>          RCOND est de type DOUBLE PRECISION
!>          L'inverse du nombre de condition de la matrice A,
!>          calculé comme RCOND = 1/(norme(A) * norme(inv(A))).
!>

WORK

!>          WORK est un tableau de type DOUBLE PRECISION, de dimension (3*N)
!>

IWORK

!>          IWORK est un tableau de type ENTIER, de dimension (N)
!>

INFO

!>          INFO est un ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument était invalide
!>
