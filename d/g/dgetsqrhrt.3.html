sous-routine dgetsqrhrt (integer m, integer n, integer mb1, integer nb1, integer nb2, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( ldt, * ) t, integer ldt, double precision, dimension( * ) work, integer lwork, integer info)

DGETSQRHRT

Objectif :

!>
!> DGETSQRHRT calcule une factorisation QR bloquée par colonnes de taille NB2
!> d'une matrice réelle M par N, A, avec M >= N,
!>
!>    A = Q * R.
!>
!> La routine utilise en interne une factorisation TSQR bloquée par colonnes de taille NB1
!> et bloquée par lignes de taille MB1, et effectue la reconstruction des vecteurs
!> de Householder à partir de la sortie TSQR. La routine convertit également le facteur
!> R_tsqr de la sortie de factorisation TSQR en facteur R qui correspond à la
!> factorisation QR de Householder,
!>
!>    A = Q_tsqr * R_tsqr = Q * R.
!>
!> Les facteurs de sortie Q et R sont stockés dans le même format que dans DGEQRT
!> (Q est en représentation WY compacte et bloquée). Voir la documentation
!> de DGEQRT pour plus de détails sur le format.
!>

Paramètres :

M 
!>          M est un INTEGER
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

N

!>          N est un INTEGER
!>          Le nombre de colonnes de la matrice A. M >= N >= 0.
!>

MB1

!>          MB1 est un INTEGER
!>          La taille du bloc de lignes à utiliser dans la TSQR bloquée.
!>          MB1 > N.
!>

NB1

!>          NB1 est un INTEGER
!>          La taille du bloc de colonnes à utiliser dans la TSQR bloquée.
!>          N >= NB1 >= 1.
!>

NB2

!>          NB2 est un INTEGER
!>          La taille du bloc à utiliser dans la QR bloquée en sortie.
!>          NB2 >= 1.
!>

A

!>          A est un tableau de DOUBLE PRECISION, de dimension (LDA,N)
!>
!>          En entrée : la matrice A de taille M par N.
!>
!>          En sortie :
!>           a) les éléments sur et au-dessus de la diagonale
!>              du tableau contiennent la matrice triangulaire supérieure
!>              N par N, R, correspondant à la QR de Householder ;
!>           b) les éléments en dessous de la diagonale représentent Q par
!>              les colonnes de V bloquées (représentation WY compacte).
!>

LDA

!>          LDA est un INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,M).
!>

T

!>          T est un tableau de DOUBLE PRECISION, de dimension (LDT,N))
!>          Les réflecteurs de blocs triangulaires supérieurs stockés sous forme compacte
!>          comme une séquence de blocs triangulaires supérieurs.
!>

LDT

!>          LDT est un INTEGER
!>          La dimension principale du tableau T.  LDT >= NB2.
!>

WORK

!>          (espace de travail) tableau de DOUBLE PRECISION, de dimension (MAX(1,LWORK))
!>          En sortie, si INFO = 0, WORK(1) contient la valeur LWORK optimale.
!>

LWORK

!>          LWORK est un INTEGER
!>          La dimension du tableau WORK.
!>          Si MIN(M,N) = 0, LWORK >= 1, sinon
!>          LWORK >= MAX( 1, LWT + LW1, MAX( LWT+N*N+LW2, LWT+N*N+N ) ),
!>          où
!>             NB_BLOCS_LIGNES_TOTAUX = CEIL((M-N)/(MB1-N)),
!>             NB1LOCAL = MIN(NB1,N).
!>             LWT = NB_BLOCS_LIGNES_TOTAUX * N * NB1LOCAL,
!>             LW1 = NB1LOCAL * N,
!>             LW2 = NB1LOCAL * MAX( NB1LOCAL, ( N - NB1LOCAL ) ).
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée.
!>          La routine calcule uniquement la taille optimale du tableau WORK,
!>          renvoie cette valeur comme première entrée du tableau WORK, et aucun
!>          message d'erreur lié à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est un INTEGER
!>          = 0 : succès
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>
