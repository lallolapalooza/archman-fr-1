sous-programme dgesc2 (n, a, lda, rhs, ipiv, jpiv, scale)
DGESC2 résout un système d'équations linéaires à l'aide de la factorisation LU avec pivotement complet calculé par sgetc2.

Documentation de la fonction/du sous-programme

sous-programme dgesc2 (entier n, double précision, dimension( lda, * ) a, entier lda, double précision, dimension( * ) rhs, entier, dimension( * ) ipiv, entier, dimension( * ) jpiv, double précision scale)

DGESC2 résout un système d'équations linéaires à l'aide de la factorisation LU avec pivotement complet calculé par sgetc2.

Objectif :

!>
!> DGESC2 résout un système d'équations linéaires
!>
!>           A * X = scale* RHS
!>
!> avec une matrice générale A de taille N-par-N à l'aide de la factorisation LU
!> avec pivotement complet calculé par DGETC2.
!>

Paramètres

N 
!>          N est un ENTIER
!>          L'ordre de la matrice A.
!>

A

!>          A est un tableau DOUBLE PRÉCISION, dimension (LDA,N)
!>          En entrée, la partie LU de la factorisation de la matrice
!>          A de taille n-par-n calculée par DGETC2 :  A = P * L * U * Q
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale du tableau A.  LDA >= max(1, N).
!>

RHS

!>          RHS est un tableau DOUBLE PRÉCISION, dimension (N).
!>          En entrée, le vecteur du second membre b.
!>          En sortie, le vecteur solution X.
!>

IPIV

!>          IPIV est un tableau ENTIER, dimension (N).
!>          Les indices de pivot ; pour 1 <= i <= N, la ligne i de la
!>          matrice a été échangée avec la ligne IPIV(i).
!>

JPIV

!>          JPIV est un tableau ENTIER, dimension (N).
!>          Les indices de pivot ; pour 1 <= j <= N, la colonne j de la
!>          matrice a été échangée avec la colonne JPIV(j).
!>

SCALE

!>          SCALE est DOUBLE PRÉCISION
!>          En sortie, SCALE contient le facteur d'échelle. SCALE est choisi
!>          tel que 0 <= SCALE <= 1 pour éviter le débordement dans la solution.
!>
