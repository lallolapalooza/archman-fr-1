DGESVDQ calcule la décomposition en valeurs singulières (SVD) avec une méthode de SVD QR préconditionnée par QR pour les matrices

GE

But

: 
!>
!> DGESVDQ calcule la décomposition en valeurs singulières (SVD) d'une matrice
!> réelle A de dimensions M par N, où M >= N. La SVD de A est écrite comme
!>                                    [++]   [xx]   [x0]   [xx]
!>              A = U * SIGMA * V^*,  [++] = [xx] * [ox] * [xx]
!>                                    [++]   [xx]
!> où SIGMA est une matrice diagonale de dimensions N par N, U est une matrice
!> orthonormale de dimensions M par N, et V est une matrice orthogonale de
!> dimensions N par N. Les éléments diagonaux de SIGMA sont les valeurs
!> singulières de A. Les colonnes de U et de V sont respectivement les vecteurs
!> singuliers gauche et droit de A.
!
>

Paramètre

s
JOBA 
!>  JOBA est CHARACTER*1
!>  Spécifie le niveau de précision de la SVD calculée
!>  = 'A' La précision demandée correspond à avoir une erreur arrière
!>        bornée par || delta A ||_F <= f(m,n) * EPS * || A ||_F,
!>        où EPS = DLAMCH('Epsilon'). Cela autorise DGESVDQ à
!>        tronquer le facteur triangulaire calculé dans une factorisation
!>        QR révélatrice de rang chaque fois que la partie tronquée est
!>        inférieure au seuil de l'ordre de EPS * ||A||_F. Ceci est un
!>        niveau de troncature agressif.
!>  = 'M' De même qu'avec 'A', mais la troncature est plus douce : elle
!>        n'est autorisée que lorsqu'il y a une chute sur la diagonale du
!>        facteur triangulaire dans la factorisation QR. Ceci est un
!>        niveau de troncature moyen.
!>  = 'H' Haute précision demandée. Aucune détermination du rang numérique
!>        basée sur la factorisation QR révélatrice de rang n'est tentée.
!>  = 'E' Identique à 'H', et en plus le nombre de condition de A mis à
!>        l'échelle par colonnes est estimé et renvoyé dans RWORK(1).
!>        N^(-1/4)*RWORK(1) <= ||pinv(A_scaled)||_2 <= N^(1/4)*RWORK(1)
!
>

JOB

P 
!>  JOBP est CHARACTER*1
!>  = 'P' Les lignes de A sont ordonnées par ordre décroissant par rapport à
!>        ||A(i,:)||_\infty. Cela améliore la précision numérique au prix
!>        de déplacements de données supplémentaires. Recommandé pour la
!>        robustesse numérique.
!>  = 'N' Pas de pivotement sur les lignes.
!
>

JOB

R 
!>          JOBR est CHARACTER*1
!>          = 'T' Après la factorisation QR pivotée initiale, DGESVD est appliquée à
!>          la transposée R**T du facteur triangulaire R calculé. Cela implique
!>          des déplacements de données supplémentaires (transpositions de matrices).
!>          Utile pour les expériences, la recherche et le développement.
!>          = 'N' Le facteur triangulaire R est donné en entrée à DGESVD. Cela peut être
!>          préféré car cela implique moins de déplacements de données.
!
>

JOB

U 
!>          JOBU est CHARACTER*1
!>          = 'A' Les M vecteurs singuliers gauches sont calculés et renvoyés dans la
!>          matrice U. Voir la description de U.
!>          = 'S' ou 'U' N = min(M,N) vecteurs singuliers gauches sont calculés et
!>          renvoyés dans la matrice U. Voir la description de U.
!>          = 'R' Le rang numérique NUMRANK est déterminé et seuls NUMRANK vecteurs
!>          singuliers gauches sont calculés et renvoyés dans la matrice U.
!>          = 'F' Les N vecteurs singuliers gauches sont renvoyés sous forme factorisée
!>          comme le produit du facteur Q de la factorisation QR initiale et des
!>          N vecteurs singuliers gauches de (R**T , 0)**T. Si le pivotement sur les
!>          lignes est utilisé, alors les informations nécessaires sur le pivotement
!>          des lignes sont stockées dans IWORK(N+1:N+M-1).
!>          = 'N' Les vecteurs singuliers gauches ne sont pas calculés.
!
>

JOB

V 
!>          JOBV est CHARACTER*1
!>          = 'A', 'V' Les N vecteurs singuliers droits sont calculés et renvoyés dans
!>          la matrice V.
!>          = 'R' Le rang numérique NUMRANK est déterminé et seuls NUMRANK vecteurs
!>          singuliers droits sont calculés et renvoyés dans la matrice V. Cette option
!>          n'est autorisée que si JOBU = 'R' ou JOBU = 'N' ; sinon elle est illégale.
!>          = 'N' Les vecteurs singuliers droits ne sont pas calculés.
!
>

M 
!>          M est INTEGER
!>          Le nombre de lignes de la matrice d'entrée A.  M >= 0.
!
>

N 
!>          N est INTEGER
!>          Le nombre de colonnes de la matrice d'entrée A.  M >= N >= 0.
!
>

A 
!>          A est un tableau DOUBLE PRECISION de dimensions LDA x N
!>          À l'entrée, la matrice d'entrée A.
!>          À la sortie, si JOBU .NE. 'N' ou JOBV .NE. 'N', le triangle inférieur de A
!>          contient les vecteurs de Householder tels que stockés par DGEQP3. Si JOBU = 'F',
!>          ces vecteurs de Householder, combinés avec WORK(1:N), peuvent être utilisés
!>          pour restaurer les facteurs Q de la factorisation QR pivotée initiale de A.
!>          Voir la description de U.
!
>

LD

A 
!>          LDA est INTEGER.
!>          La dimension principale du tableau A.  LDA >= max(1,M).
!
>

S 
!>          S est un tableau DOUBLE PRECISION de dimension N.
!>          Les valeurs singulières de A, ordonnées de sorte que S(i) >= S(i+1).
!
>

U 
!>          U est un tableau DOUBLE PRECISION, dimension
!>          LDU x M si JOBU = 'A' ; voir la description de LDU. Dans ce cas,
!>          à la sortie, U contient les M vecteurs singuliers gauches.
!>          LDU x N si JOBU = 'S', 'U', 'R' ; voir la description de LDU. Dans ce
!>          cas, U contient les N premiers ou les NUMRANK premiers vecteurs singuliers
!>          gauches.
!>          LDU x N si JOBU = 'F' ; voir la description de LDU. Dans ce cas U
!>          contient une matrice orthogonale N x N qui peut être utilisée pour former
!>          les vecteurs singuliers gauches.
!>          Si JOBU = 'N', U n'est pas référencé.
!
>

LD

U 
!>          LDU est INTEGER.
!>          La dimension principale du tableau U.
!>          Si JOBU = 'A', 'S', 'U', 'R',  LDU >= max(1,M).
!>          Si JOBU = 'F',                 LDU >= max(1,N).
!>          Sinon,                        LDU >= 1.
!
>

V 
!>          V est un tableau DOUBLE PRECISION, dimension
!>          LDV x N si JOBV = 'A', 'V', 'R' ou si JOBA = 'E' .
!>          Si JOBV = 'A', ou 'V',  V contient la matrice orthogonale N par N V**T;
!>          Si JOBV = 'R', V contient les NUMRANK premières lignes de V**T (les vecteurs
!>          singuliers droits, stockés par ligne, des NUMRANK plus grandes valeurs
!>          singulières).
!>          Si JOBV = 'N' et JOBA = 'E', V est utilisé comme espace de travail.
!>          Si JOBV = 'N', et JOBA.NE.'E', V n'est pas référencé.
!
>

LD

V 
!>          LDV est INTEGER
!>          La dimension principale du tableau V.
!>          Si JOBV = 'A', 'V', 'R',  ou JOBA = 'E', LDV >= max(1,N).
!>          Sinon,                               LDV >= 1.

NAME


dgesvdq - computes the singular value decomposition (SVD) of a real
    general m-by-n matrix A, which is a slight modification of the LAPACK
    routine dgesvd.






SYNOPSIS


 SUBROUTINE DGESVDQ( JOBA, JOBV, JOBR, JOBP, M, N, A, LDA, S, U, LDU, V, LDV,
                     IWORK, LIWORK, RWORK, LRWORK, WORK, LWORK, INFO )

 CHARACTER          JOBA, JOBP, JOBR, JOBV
 INTEGER            INFO, LDA, LDU, LDV, LIWORK, LWORK, LRWORK, M, N
 REAL               A( LDA, * ), S( * ), U( LDU, * ), V( LDV, * ), WORK( * )
 INTEGER            IWORK( * )
 REAL               RWORK( * )







Function/Subroutine Documentation


DGESVDQ computes the singular value decomposition (SVD) of a
    real general m-by-n matrix A, which is a slight modification of the LAPACK
    routine dgesvd. The decomposition is given by


 A = U * S * V^T



where S is an m-by-n diagonal matrix of the singular values of A
    with nonnegative real numbers on the diagonal. U is an m-by-m orthogonal
    matrix, and V is an n-by-n orthogonal matrix.


The routine computes the SVD using a QR factorization that reveals
    the rank of the matrix A.


Input Parameters:




JOBA


CHARACTER*1. Specifies the computation of the condition number for the SVD.
    

    
'E'

    
The condition number is computed.
    
'N'

    
The condition number is not computed.

    

    
Constraint: JOBA = 'E' or 'N'.




JOBV


CHARACTER*1. Specifies the computation of the left singular vectors.
    

    
'A'

    
All m columns of U are returned.

    
'S'

    
The first min(M,N) columns of U are returned.

    
'U'

    
The first min(M,N) columns of U are returned if M>=N, otherwise only
        first N columns of U are returned.

    
'R'

    
The first min(M,N) columns of U are returned if M>=N, otherwise only
        first N columns of U are returned.

    
'N'

    
No columns of U are returned. The space U is not used.

    

    
Constraint: JOBV = 'A', 'S', 'U', 'R', or 'N'.




JOBR


CHARACTER*1. Specifies the computation of the SVD.
    

    
'N'

    
The singular values of A are computed. The singular vectors of A are
        computed using the QR decomposition.

    
'T'

    
The singular values of A are computed. The singular vectors of A are
        computed using the Q-less QR decomposition.

    

    
Constraint: JOBR = 'N' or 'T'.




JOBP


CHARACTER*1. Specifies whether pivoting is used in the QR factorization.
    

    
'N'

    
No pivoting is used.

    
'P'

    
Pivoting is used.

    

    
Constraint: JOBP = 'N' or 'P'.




M


INTEGER. The number of rows of A.


N


INTEGER. The number of columns of A.


A


REAL array, dimension (LDA, N). On entry, the m-by-n matrix A.


LDA


INTEGER. The leading dimension of the array A.


S


REAL array, dimension (min(M,N)).
    On exit, S contains the singular values, sorted in descending order.


U


REAL array, dimension (LDU, K).
    K is the number of columns of U to be computed.
    On exit, if JOBV = 'A', U contains the m x m matrix U.
    If JOBV = 'S', U contains the first min(M,N) columns of U.
    If JOBV = 'U' or 'R', U contains the first min(M,N) columns of U
    if M>=N, otherwise U contains the first N columns of U.


LDU


INTEGER. The leading dimension of the array U.


V


REAL array, dimension (LDV, K).
    K is the number of columns of V to be computed.
    On exit, V contains the n x n matrix V.


LDV


INTEGER. The leading dimension of the array V.


LIWORK


INTEGER. The dimension of the array IWORK.


LRWORK


INTEGER. The dimension of the array RWORK.


LWORK


INTEGER. The dimension of the array WORK.




Output Parameters:




IWORK


INTEGER array, dimension (max(1, LIWORK)).
    On exit, IWORK(1:N) contains column pivoting permutation of the
    rank revealing QR factorization.
    If JOBP = 'P', IWORK(N+1:N+M-1) contains the indices of the sequence
    of row swaps used in row pivoting. These can be used to restore the
    left singular vectors in the case JOBU = 'F'.
    If LIWORK, LWORK, or LRWORK = -1, then on exit, if INFO = 0,
    IWORK(1) returns the minimal LIWORK.



RWORK


REAL array, dimension (max(1, LRWORK)).
    On exit,
    1. If JOBA = 'E', RWORK(1) contains an estimate of the condition
    number of column scaled A. If A = C * D where D is diagonal and C
    has unit columns in the Euclidean norm, then, assuming full column rank,
    N^(-1/4) * RWORK(1) <= ||pinv(C)||_2 <= N^(1/4) * RWORK(1).
    Otherwise, RWORK(1) = -1.
    2. RWORK(2) contains the number of singular values computed as
    exact zeros in DGESVD applied to the upper triangular or trapezoidal
    R (from the initial QR factorization). In case of early exit (no call to
    DGESVD, such as in the case of zero matrix) RWORK(2) = -1.
    If LIWORK, LWORK, or LRWORK = -1, then on exit, if INFO = 0,
    RWORK(1) returns the minimal LRWORK.



WORK


REAL array, dimension (max(2, LWORK)), used as a workspace.
    On exit, if, on entry, LWORK.NE.-1, WORK(1:N) contains parameters
    needed to recover the Q factor from the QR factorization computed by
    DGEQP3.
    If LIWORK, LWORK, or LRWORK = -1, then on exit, if INFO = 0,
    WORK(1) returns the optimal LWORK, and
    WORK(2) returns the minimal LWORK.



INFO


INTEGER.
    = 0:  successful exit.
    < 0:  if INFO = -i, the i-th argument had an illegal value.
    > 0:  if DBDSQR did not converge, INFO specifies how many superdiagonals
    of an intermediate bidiagonal form B (computed in DGESVD) did not
    converge to zero.





Constraints and Dimensions:




LIWORK


INTEGER. The dimension of the array IWORK.
    LIWORK >= N + M - 1,     if JOBP = 'P' and JOBA .NE. 'E';
    LIWORK >= N              if JOBP = 'N' and JOBA .NE. 'E';
    LIWORK >= N + M - 1 + N, if JOBP = 'P' and JOBA = 'E';
    LIWORK >= N + N          if JOBP = 'N' and JOBA = 'E'.
    If LIWORK = -1, then a workspace query is assumed; the routine
    only calculates and returns the optimal and minimal sizes
    for the WORK, IWORK, and RWORK arrays, and no error
    message related to LWORK is issued by XERBLA.



LWORK


INTEGER. The dimension of the array WORK. It is determined as follows:
    Let  LWQP3 = 3*N+1,  LWCON = 3*N, and let
    LWORQ = { MAX( N, 1 ),  if JOBU = 'R', 'S', or 'U'
            { MAX( M, 1 ),  if JOBU = 'A'
    LWSVD = MAX( 5*N, 1 )
    LWLQF = MAX( N/2, 1 ), LWSVD2 = MAX( 5*(N/2), 1 ), LWORLQ = MAX( N, 1 ),
    LWQRF = MAX( N/2, 1 ), LWORQ2 = MAX( N, 1 )
    Then the minimal value of LWORK is:
    = MAX( N + LWQP3, LWSVD )        if only the singular values are needed;
    = MAX( N + LWQP3, LWCON, LWSVD ) if only the singular values are needed,
                               and a scaled condition estimate requested;
    = N + MAX( LWQP3, LWSVD, LWORQ ) if the singular values and the left
                               singular vectors are requested;
    = N + MAX( LWQP3, LWCON, LWSVD, LWORQ ) if the singular values and the left
                               singular vectors are requested, and also
                               a scaled condition estimate requested;
    = N + MAX( LWQP3, LWSVD )        if the singular values and the right
                               singular vectors are requested;
    = N + MAX( LWQP3, LWCON, LWSVD ) if the singular values and the right
                               singular vectors are requested, and also
                               a scaled condition etimate requested;
    = N + MAX( LWQP3, LWSVD, LWORQ ) if the full SVD is requested with JOBV = 'R';
                               independent of JOBR;
    = N + MAX( LWQP3, LWCON, LWSVD, LWORQ ) if the full SVD is requested,
                               JOBV = 'R' and, also a scaled condition
                               estimate requested; independent of JOBR;
    = MAX( N + MAX( LWQP3, LWSVD, LWORQ ),
           N + MAX( LWQP3, N/2+LWLQF, N/2+LWSVD2, N/2+LWORLQ, LWORQ ) ) if the
                             full SVD is requested with JOBV = 'A' or 'V', and
                             JOBR ='N'
    = MAX( N + MAX( LWQP3, LWCON, LWSVD, LWORQ ),
           N + MAX( LWQP3, LWCON, N/2+LWLQF, N/2+LWSVD2, N/2+LWORLQ, LWORQ ) )
                             if the full SVD is requested with JOBV = 'A' or 'V', and
                             JOBR ='N', and also a scaled condition number estimate
                             requested.
    = MAX( N + MAX( LWQP3, LWSVD, LWORQ ),
           N + MAX( LWQP3, N/2+LWQRF, N/2+LWSVD2, N/2+LWORQ2, LWORQ ) ) if the
                             full SVD is requested with JOBV = 'A', 'V', and JOBR ='T'
    = MAX( N + MAX( LWQP3, LWCON, LWSVD, LWORQ ),
           N + MAX( LWQP3, LWCON, N/2+LWQRF, N/2+LWSVD2, N/2+LWORQ2, LWORQ ) )
                             if the full SVD is requested with JOBV = 'A' or 'V', and
                             JOBR ='T', and also a scaled condition number estimate
                             requested.
    Finally, LWORK must be at least two: LWORK = MAX( 2, LWORK ).
    If LWORK = -1, then a workspace query is assumed; the routine
    only calculates and returns the optimal and minimal sizes
    for the WORK, IWORK, and RWORK arrays, and no error
    message related to LWORK is issued by XERBLA.



LRWORK


INTEGER.
    The dimension of the array RWORK.
    If JOBP ='P', then LRWORK >= MAX(2, M).
    Otherwise, LRWORK >= 2
    If LRWORK = -1, then a workspace query is assumed; the routine
    only calculates and returns the optimal and minimal sizes
    for the WORK, IWORK, and RWORK arrays, and no error
    message related to LWORK is issued by XERBLA.





Further Details:




1. The data movement (matrix transpose) is coded using simple nested
DO-loops because BLAS and LAPACK do not provide corresponding subroutines.
Those DO-loops are easily identified in this source code - by the CONTINUE
statements labeled with 11**. In an optimized version of this code, the
nested DO loops should be replaced with calls to an optimized subroutine.
2. This code scales A by 1/SQRT(M) if the largest ABS(A(i,j)) could cause
column norm overflow. This is the minial precaution and it is left to the
SVD routine (CGESVD) to do its own preemptive scaling if potential over-
or underflows are detected. To avoid repeated scanning of the array A,
an optimal implementation would do all necessary scaling before calling
CGESVD and the scaling in CGESVD can be switched off.
3. Other comments related to code optimization are given in comments in the
code, enclosed in [[double brackets]].
