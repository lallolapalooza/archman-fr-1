Documentation de la fonction/sous-routine

sous-routine dgemlqt (caractère side, caractère trans, entier m, entier n, entier k, entier mb, double précision, dimension( ldv, * ) v, entier ldv, double précision, dimension( ldt, * ) t, entier ldt, double précision, dimension( ldc, * ) c, entier ldc, double précision, dimension( * ) work, entier info)

DGEMLQT

But :

!>
!> DGEMLQT écrase la matrice générale réelle M par N, C, avec
!>
!>                 SIDE = 'L'     SIDE = 'R'
!> TRANS = 'N':      Q C            C Q
!> TRANS = 'T':   Q**T C            C Q**T
!>
!> où Q est une matrice orthogonale réelle définie comme le produit de K
!> réflecteurs élémentaires :
!>
!>       Q = H(1) H(2) . . . H(K) = I - V T V**T
!>
!> générée en utilisant la représentation WY compacte telle que retournée par DGELQT.
!>
!> Q est d'ordre M si SIDE = 'L' et d'ordre N si SIDE = 'R'.
!>

Paramètres

SIDE 
!>          SIDE est CHARACTER*1
!>          = 'L' : appliquer Q ou Q**T depuis la gauche ;
!>          = 'R' : appliquer Q ou Q**T depuis la droite.
!>

TRANS

!>          TRANS est CHARACTER*1
!>          = 'N' : Pas de transposée, appliquer Q ;
!>          = 'C' : Transposée, appliquer Q**T.
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice C. M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice C. N >= 0.
!>

K

!>          K est INTEGER
!>          Le nombre de réflecteurs élémentaires dont le produit définit
!>          la matrice Q.
!>          Si SIDE = 'L', M >= K >= 0 ;
!>          si SIDE = 'R', N >= K >= 0.
!>

MB

!>          MB est INTEGER
!>          La taille du bloc utilisée pour le stockage de T. K >= MB >= 1.
!>          Doit être la même valeur de MB utilisée pour générer T
!>          dans DGELQT.
!>

V

!>          V est un tableau de DOUBLE PRECISION, dimension
!>                               (LDV,M) si SIDE = 'L',
!>                               (LDV,N) si SIDE = 'R'
!>          La i-ème ligne doit contenir le vecteur qui définit le
!>          réflecteur élémentaire H(i), pour i = 1,2,...,k, tel que retourné par
!>          DGELQT dans les K premières lignes de son argument de tableau A.
!>

LDV

!>          LDV est INTEGER
!>          La dimension principale du tableau V. LDV >= max(1,K).
!>

T

!>          T est un tableau de DOUBLE PRECISION, dimension (LDT,K)
!>          Les facteurs triangulaires supérieurs des réflecteurs de bloc
!>          tels que retournés par DGELQT, stockés sous forme de matrice MB par K.
!>

LDT

!>          LDT est INTEGER
!>          La dimension principale du tableau T. LDT >= MB.
!>

C

!>          C est un tableau de DOUBLE PRECISION, dimension (LDC,N)
!>          À l'entrée, la matrice C de taille M par N.
!>          À la sortie, C est écrasée par Q C, Q**T C, C Q**T ou C Q.
!>

LDC

!>          LDC est INTEGER
!>          La dimension principale du tableau C. LDC >= max(1,M).
!>

WORK

!>          WORK est un tableau de DOUBLE PRECISION. La dimension de
!>          WORK est N*MB si SIDE = 'L', ou M*MB si SIDE = 'R'.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>
