Documentation de la fonction/sous-programme

sous-programme dgbsvxx (fact caractère, trans caractère, n entier, kl entier, ku entier, nrhs entier, double précision, dimension( ldab, * ) ab, entier ldab, double précision, dimension( ldafb, * ) afb, entier ldafb, entier, dimension( * ) ipiv, equed caractère, double précision, dimension( * ) r, double précision, dimension( * ) c, double précision, dimension( ldb, * ) b, entier ldb, double précision, dimension( ldx , * ) x, entier ldx, double précision rcond, double précision rpvgrw, double précision, dimension( * ) berr, entier n_err_bnds, double précision, dimension( nrhs, * ) err_bnds_norm, double précision, dimension( nrhs, * ) err_bnds_comp, entier nparams, double précision, dimension( * ) params, double précision, dimension( * ) work, entier, dimension( * ) iwork, entier info)

DGBSVXX calcule la solution du système d'équations linéaires A * X = B pour les matrices GB

Objectif :

!>
!>    DGBSVXX utilise la factorisation LU pour calculer la solution d'un
!>    système d'équations linéaires double précision  A * X = B,  où A est une
!>    matrice N-par-N et X et B sont des matrices N-par-NRHS.
!>
!>    Si demandé, des bornes d'erreur normées et des bornes d'erreur composantes
!>    maximales sont retournées. DGBSVXX retournera une solution avec une
!>    minuscule erreur garantie (O(eps) où eps est la précision de calcul
!>    de la machine) sauf si la matrice est très mal conditionnée, auquel
!>    cas un avertissement est retourné. Les nombres de conditionnement pertinents
!>    sont également calculés et retournés.
!>
!>    DGBSVXX accepte des factorisations et des facteurs d'équilibrage fournis par
!>    l'utilisateur ; voir les définitions des options FACT et EQUED.
!>    Résoudre avec raffinement et utiliser une factorisation provenant d'un appel
!>    précédent à DGBSVXX produira également une solution avec des erreurs O(eps)
!>    ou des avertissements, mais nous ne pouvons pas affirmer cela pour des
!>    factorisations et des facteurs d'équilibrage généralement fournis par
!>    l'utilisateur s'ils diffèrent de ce que DGBSVXX produirait lui-même.
!>

Description :

!>
!>    Les étapes suivantes sont effectuées :
!>
!>    1. Si FACT = 'E', des facteurs d'échelle double précision sont calculés pour
!>    équilibrer le système :
!>
!>      TRANS = 'N':  diag(R)*A*diag(C)     *inv(diag(C))*X = diag(R)*B
!>      TRANS = 'T': (diag(R)*A*diag(C))**T *inv(diag(R))*X = diag(C)*B
!>      TRANS = 'C': (diag(R)*A*diag(C))**H *inv(diag(R))*X = diag(C)*B
!>
!>    Que le système soit équilibré ou non dépend de la mise à l'échelle
!>    de la matrice A, mais si l'équilibrage est utilisé, A est
!>    écrasé par diag(R)*A*diag(C) et B par diag(R)*B (si TRANS='N')
!>    ou diag(C)*B (si TRANS = 'T' ou 'C').
!>
!>    2. Si FACT = 'N' ou 'E', la décomposition LU est utilisée pour factoriser
!>    la matrice A (après équilibrage si FACT = 'E') comme suit :
!>
!>      A = P * L * U,
!>
!>    où P est une matrice de permutation, L est une matrice triangulaire inférieure
!>    unitaire, et U est triangulaire supérieure.
!>
!>    3. Si un U(i,i)=0, de sorte que U est exactement singulière, alors la
!>    routine retourne avec INFO = i. Sinon, la forme factorisée de A
!>    est utilisée pour estimer le nombre de conditionnement de la matrice A (voir
!>    l'argument RCOND). Si l'inverse du nombre de conditionnement est inférieur
!>    à la précision de la machine, la routine continue quand même à résoudre
!>    pour X et calculer les bornes d'erreur comme décrit ci-dessous.
!>
!>    4. Le système d'équations est résolu pour X en utilisant la forme factorisée
!>    de A.
!>
!>    5. Par défaut (sauf si PARAMS(LA_LINRX_ITREF_I) est mis à zéro),
!>    la routine utilisera le raffinement itératif pour essayer d'obtenir une
!>    petite erreur et de petites bornes d'erreur. Le raffinement calcule le résidu
!>    à au moins deux fois la précision de travail.
!>
!>    6. Si l'équilibrage a été utilisé, la matrice X est prémultipliée par
!>    diag(C) (si TRANS = 'N') ou diag(R) (si TRANS = 'T' ou 'C') de sorte
!>    qu'elle résolve le système original avant équilibrage.
!> 
!>     Certains paramètres optionnels sont regroupés dans le tableau PARAMS. Ces
!>     paramètres déterminent comment le raffinement est effectué, mais souvent les
!>     valeurs par défaut sont acceptables. Si les valeurs par défaut sont acceptables,
!>     les utilisateurs peuvent passer NPARAMS = 0, ce qui empêche le code source
!>     d'accéder à l'argument PARAMS.
!>

Paramètres

FACT 
!>          FACT est CHARACTER*1
!>     Spécifie si la forme factorisée de la matrice A est fournie en entrée,
!>     et sinon, si la matrice A doit être équilibrée avant d'être factorisée.
!>       = 'F':  En entrée, AF et IPIV contiennent la forme factorisée de A.
!>               Si EQUED n'est pas 'N', la matrice A a été
!>               équilibrée avec les facteurs d'échelle donnés par R et C.
!>               A, AF et IPIV ne sont pas modifiés.
!>       = 'N':  La matrice A sera copiée dans AF et factorisée.
!>       = 'E':  La matrice A sera équilibrée si nécessaire, puis
!>               copiée dans AF et factorisée.
!>

TRANS

!>          TRANS est CHARACTER*1
!>     Spécifie la forme du système d'équations :
!>       = 'N':  A * X = B     (Pas de transpose)
!>       = 'T':  A**T * X = B  (Transposée)
!>       = 'C':  A**H * X = B  (Conjuguée Transposée = Transposée)
!>

N

!>          N est INTEGER
!>     Le nombre d'équations linéaires, c'est-à-dire l'ordre de la
!>     matrice A.  N >= 0.
!>

KL

!>          KL est INTEGER
!>     Le nombre de sous-diagonales dans la bande de A.  KL >= 0.
!>

KU

!>          KU est INTEGER
!>     Le nombre de super-diagonales dans la bande de A.  KU >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>     Le nombre de côtés droits, c'est-à-dire le nombre de colonnes
!>     des matrices B et X.  NRHS >= 0.
!>

AB

!>          AB est un tableau DOUBLE PRECISION, de dimension (LDAB,N)
!>     En entrée, la matrice A en stockage bande, sur les lignes 1 à KL+KU+1.
!>     La j-ième colonne de A est stockée dans la j-ième colonne du
!>     tableau AB comme suit :
!>     AB(KU+1+i-j,j) = A(i,j) pour max(1,j-KU) <= i <= min(N,j+kl)
!>
!>     Si FACT = 'F' et EQUED n'est pas 'N', alors AB doit avoir été
!>     équilibré par les facteurs d'échelle dans R et/ou C.  AB n'est pas
!>     modifié si FACT = 'F' ou 'N', ou si FACT = 'E' et
!>     EQUED = 'N' à la sortie.
!>
!>     En sortie, si EQUED .ne. 'N', A est mis à l'échelle comme suit :
!>     EQUED = 'R':  A := diag(R) * A
!>     EQUED = 'C':  A := A * diag(C)
!>     EQUED = 'B':  A := diag(R) * A * diag(C).
!>

LDAB

!>          LDAB est INTEGER
!>     La dimension de tête du tableau AB.  LDAB >= KL+KU+1.
!>

AFB

!>          AFB est un tableau DOUBLE PRECISION, de dimension (LDAFB,N)
!>     Si FACT = 'F', en entrée, AFB contient la factorisation LU de A
!>     (ou de A * diag(C) si EQUED = 'C' ou 'B') calculée par un appel précédent
!>     à DGBSVXX.
!>
!>     Si FACT = 'N' ou 'E', AFB est une copie de la matrice mise à l'échelle A.
!>
!>     En sortie, si FACT = 'N' ou 'E', AFB contient la factorisation LU de la
!>     matrice mise à l'échelle A. Les sous-matrices triangulaires inférieures et
!>     supérieures unitaires qui définissent L et U sont stockées dans les
!>     colonnes 1 à N de AFB. Les éléments de U au-dessus de la première
!>     super-diagonale sont stockés dans les lignes 1 à KU de AFB. Les éléments
!>     de L au-dessous de la première sous-diagonale sont stockés dans les
!>     lignes KU+2 à KU+KL+1 de AFB.
!>

LDAFB

!>          LDAFB est INTEGER
!>     La dimension de tête du tableau AFB. LDAFB >= KL+KU+1.
!>

IPIV

!>          IPIV est un tableau INTEGER, de dimension (N)
!>     Si FACT = 'F', IPIV contient les informations d'échange de lignes de
!>     la factorisation LU de la matrice mise à l'échelle A.
!>
!>     Si FACT = 'N' ou 'E', IPIV contient les informations d'échange de lignes
!>     de la factorisation LU de la matrice mise à l'échelle A.
!>
!>     Si FACT = 'F', IPIV n'est pas modifié.
!>

EQUED

!>          EQUED est CHARACTER*1
!>     Indique l'équilibrage effectué, le cas échéant, sur la matrice A.
!>     = 'N': Aucune mise à l'échelle n'a été effectuée.
!>     = 'R': Les lignes ont été mises à l'échelle, c'est-à-dire que A a été remplacé par diag(R)*A.
!>     = 'C': Les colonnes ont été mises à l'échelle, c'est-à-dire que A a été remplacé par A*diag(C).
!>     = 'B': Les lignes et les colonnes ont été mises à l'échelle, c'est-à-dire que A a été remplacé par diag(R)*A*diag(C).
!>     Ceci est seulement utilisé lorsque FACT = 'F'.
!>

R

!>          R est un tableau DOUBLE PRECISION, de dimension (N)
!>     Si EQUED = 'R' ou 'B', R contient les facteurs qui mettent à l'échelle les lignes de A.
!>

C

!>          C est un tableau DOUBLE PRECISION, de dimension (N)
!>     Si EQUED = 'C' ou 'B', C contient les facteurs qui mettent à l'échelle les colonnes de A.
!>

B

!>          B est un tableau DOUBLE PRECISION, de dimension (LDB,NRHS)
!>     Sur l'entrée, le second membre de l'équation, de dimension N x NRHS.
!>
!>     Si FACT = 'E' et EQUED est 'R' ou 'B', alors B est écrasé par diag(R)*B.
!>
!>     En sortie, B est écrasé par la solution X de l'équation A*X=B.
!>

LDB

!>          LDB est INTEGER
!>     La dimension de tête du tableau B. LDB >= max(1,N).
!>

X

!>          X est un tableau DOUBLE PRECISION, de dimension (LDX,NRHS)
!>     En sortie, la solution du système A*X=B.
!>

LDX

!>          LDX est INTEGER
!>     La dimension de tête du tableau X. LDX >= max(1,N).
!>

RCOND

!>          RCOND est DOUBLE PRECISION
!>     En sortie, une estimation de la précision de l'inverse de A. RCOND est
!>     la réciproque du nombre de conditionnement de A. Les valeurs
!>     en coma flottante de conditionnement sont calculées sur la base de la norme 1.
!>     RCOND est donc une borne inférieure de la précision de l'inverse.
!>

RPVGRW

!>          RPVGRW est DOUBLE PRECISION
!>     En sortie, une estimation de la valeur du plus grand des coefficients
!>     absolus dans les vecteurs calculés par la méthode de Lanczos pour estimer le
!>     nombre de conditionnement.
!>

BERR

!>          BERR est un tableau DOUBLE PRECISION, de dimension (NRHS)
!>     En sortie, BERR(j) contient une estimation de l'erreur relative sur la
!>     solution x(j) du système A*x = b.  BERR(j) est une borne supérieure de
!>     l'erreur relative sur x(j).
!>

N_ERR_BNDS

!>          N_ERR_BNDS est INTEGER
!>     Le nombre de bornes d'erreur calculées.  N_ERR_BNDS = 2.
!>

ERR_BNDS_NORM

!>          ERR_BNDS_NORM est un tableau DOUBLE PRECISION, de dimension (NRHS, N_ERR_BNDS)
!>     Sur la sortie, des bornes d'erreur sont calculées pour les solutions X(*,j).
!>     Les bornes sont de la forme norm(X - X_true) / norm(X) et sont calculées
!>     par rapport à la norme spécifiée par PARAMS(LA_LINRX_NORM_I).
!>
!>     ERR_BNDS_NORM(j,1) : borne d'erreur normée au niveau de la solution.
!>     ERR_BNDS_NORM(j,2) : borne d'erreur normée au niveau de la machine.
!>

ERR_BNDS_COMP

!>          ERR_BNDS_COMP est un tableau DOUBLE PRECISION, de dimension (NRHS, N)
!>     Sur la sortie, des bornes d'erreur sont calculées pour les solutions X(*,j).
!>     Les bornes sont de la forme abs(X(k,j) - X_true(k,j)) / abs(X(k,j)) et sont calculées
!>     par rapport à la norme spécifiée par PARAMS(LA_LINRX_NORM_I).
!>
!>     ERR_BNDS_COMP(j,k) : borne d'erreur composante maximale pour X(k,j).
!>

NPARAMS

!>          NPARAMS est INTEGER
!>     Le nombre de paramètres supplémentaires fournis dans PARAMS. Si NPARAMS = 0,
!>     alors les paramètres par défaut sont utilisés.
!>

PARAMS

!>          PARAMS est un tableau DOUBLE PRECISION, de dimension (NPARAMS)
!>     Tableau de paramètres optionnels. Actuellement, seuls les paramètres
!>     suivants sont pris en charge :
!>
!>     PARAMS(LA_LINRX_ITREF_I) : contrôle le nombre d'itérations de raffinement.
!>                                La valeur par défaut est 2. Si elle est réglée sur
!>                                0, le raffinement est désactivé.
!>     PARAMS(LA_LINRX_NORM_I)  : spécifie la norme à utiliser pour le calcul
!>                                des bornes d'erreur. Les valeurs possibles sont
!>                                1, 2 et 'inf'. La valeur par défaut est 1.
!>

WORK

!>          WORK est un tableau DOUBLE PRECISION, de dimension (MAX(1,LWORK)).
!>     En sortie, WORK(1) contient le nombre minimal de lignes requises dans WORK
!>     pour le raffinement itératif.
!>

LWORK

!>          LWORK est INTEGER
!>     La dimension du tableau WORK. LWORK doit être au moins
!>     max( N*max(KL,KU)+max(KL,KU)+1, 2*N + N*NB ), où NB est le bloc
!>     de taille utilisé par le sous-programme de décomposition LU.
!>     Si LWORK = -1, alors LWORK est calculé et la valeur minimale est retournée
!>     dans WORK(1).
!>

IWORK

!>          IWORK est un tableau INTEGER, de dimension (MAX(1,LIWORK)).
!>     Sur la sortie, IWORK(1) contient le nombre minimal de lignes requises dans IWORK
!>     pour le raffinement itératif.
!>

LIWORK

!>          LIWORK est INTEGER
!>     La dimension du tableau IWORK. LIWORK doit être au moins N.
!>     Si LIWORK = -1, alors LIWORK est calculé et la valeur minimale est retournée
!>     dans IWORK(1).
!>

INFO

!>          INFO est INTEGER
!>     INFO = 0:  Tri est terminé avec succès.
!>     INFO < 0: Si INFO = -i, le i-ème argument avait une valeur illégale.
!>     INFO > 0: Si INFO = i, et 1 <= i <= N, alors U(i,i) est zéro. La matrice est
!>             singulière et la factorisation a été arrêtée. La solution ne peut
!>             pas être calculée.
!>     INFO = N + 1: La matrice est singulière et le raffinement itératif a échoué.
!>     INFO = N + 2: La matrice est très mal conditionnée. Une solution a été calculée,
!>                 mais elle ne peut pas être garantie précise.
!>

LDAFB

!>          LDAFB est INTEGER
!>     La dimension principale du tableau AFB. LDAFB >= 2*KL+KU+1.
!>

IPIV

!>          IPIV est un tableau INTEGER, dimensionné (N)
!>     Si FACT = 'F', alors IPIV est un argument d'entrée et à l'entrée
!>     contient les indices de pivot de la factorisation A = P*L*U
!>     telle que calculée par DGETRF; la ligne i de la matrice a été échangée
!>     avec la ligne IPIV(i).
!>
!>     Si FACT = 'N', alors IPIV est un argument de sortie et à la sortie
!>     contient les indices de pivot de la factorisation A = P*L*U
!>     de la matrice originale A.
!>
!>     Si FACT = 'E', alors IPIV est un argument de sortie et à la sortie
!>     contient les indices de pivot de la factorisation A = P*L*U
!>     de la matrice équilibrée A.
!>

EQUED

!>          EQUED est CHARACTER*1
!>     Spécifie la forme d'équilibration qui a été effectuée.
!>       = 'N':  Aucune équilibration (toujours vrai si FACT = 'N').
!>       = 'R':  Équilibrage des lignes, c'est-à-dire que A a été pré-multiplié par
!>               diag(R).
!>       = 'C':  Équilibrage des colonnes, c'est-à-dire que A a été post-multiplié
!>               par diag(C).
!>       = 'B':  Équilibrage des lignes et des colonnes, c'est-à-dire que A a été
!>               remplacé par diag(R) * A * diag(C).
!>     EQUED est un argument d'entrée si FACT = 'F'; sinon, c'est un
!>     argument de sortie.
!>

R

!>          R est un tableau DOUBLE PRECISION, dimensionné (N)
!>     Les facteurs d'échelle des lignes de A. Si EQUED = 'R' ou 'B', A est
!>     multiplié à gauche par diag(R); si EQUED = 'N' ou 'C', R
!>     n'est pas accédé. R est un argument d'entrée si FACT = 'F';
!>     sinon, R est un argument de sortie. Si FACT = 'F' et
!>     EQUED = 'R' ou 'B', chaque élément de R doit être positif.
!>     Si R est en sortie, chaque élément de R est une puissance de la base.
!>     Si R est en entrée, chaque élément de R devrait être une puissance de la base
!>     pour garantir une solution et des estimations d'erreur fiables. La mise à l'échelle par
!>     des puissances de la base ne provoque pas d'erreurs d'arrondi à moins que le
!>     résultat ne sous-dépasse ou ne dépasse. Les erreurs d'arrondi pendant la mise à l'échelle
!>     conduisent à un raffinement avec une matrice qui n'est pas équivalente à la
!>     matrice d'entrée, produisant des estimations d'erreur qui peuvent ne pas être
!>     fiables.
!>

C

!>          C est un tableau DOUBLE PRECISION, dimensionné (N)
!>     Les facteurs d'échelle des colonnes de A. Si EQUED = 'C' ou 'B', A est
!>     multiplié à droite par diag(C); si EQUED = 'N' ou 'R', C
!>     n'est pas accédé. C est un argument d'entrée si FACT = 'F';
!>     sinon, C est un argument de sortie. Si FACT = 'F' et
!>     EQUED = 'C' ou 'B', chaque élément de C doit être positif.
!>     Si C est en sortie, chaque élément de C est une puissance de la base.
!>     Si C est en entrée, chaque élément de C devrait être une puissance de la base
!>     pour garantir une solution et des estimations d'erreur fiables. La mise à l'échelle par
!>     des puissances de la base ne provoque pas d'erreurs d'arrondi à moins que le
!>     résultat ne sous-dépasse ou ne dépasse. Les erreurs d'arrondi pendant la mise à l'échelle
!>     conduisent à un raffinement avec une matrice qui n'est pas équivalente à la
!>     matrice d'entrée, produisant des estimations d'erreur qui peuvent ne pas être
!>     fiables.
!>

B

!>          B est un tableau DOUBLE PRECISION, dimensionné (LDB,NRHS)
!>     À l'entrée, la matrice B du second membre, de taille N x NRHS.
!>     À la sortie,
!>     si EQUED = 'N', B n'est pas modifiée;
!>     si TRANS = 'N' et EQUED = 'R' ou 'B', B est écrasée par
!>        diag(R)*B;
!>     si TRANS = 'T' ou 'C' et EQUED = 'C' ou 'B', B est
!>        écrasée par diag(C)*B.
!>

LDB

!>          LDB est INTEGER
!>     La dimension principale du tableau B. LDB >= max(1,N).
!>

X

!>          X est un tableau DOUBLE PRECISION, dimensionné (LDX,NRHS)
!>     Si INFO = 0, la matrice X de la solution, de taille N x NRHS, du système d'équations original.
!>     Notez que A et B sont modifiées à la sortie
!>     si EQUED .ne. 'N', et la solution du système équilibré est
!>     inv(diag(C))*X si TRANS = 'N' et EQUED = 'C' ou 'B', ou
!>     inv(diag(R))*X si TRANS = 'T' ou 'C' et EQUED = 'R' ou 'B'.
!>

LDX

!>          LDX est INTEGER
!>     La dimension principale du tableau X. LDX >= max(1,N).
!>

RCOND

!>          RCOND est DOUBLE PRECISION
!>     Conditionnement réciproque mis à l'échelle. Ceci est une estimation du
!>     conditionnement réciproque de Skeel de la matrice A après
!>     équilibration (si effectuée). S'il est inférieur à la précision de la machine
!>     (en particulier, s'il est nul), la matrice est singulière
!>     à la précision de travail. Notez que l'erreur peut toujours être petite même
!>     si ce nombre est très petit et que la matrice semble mal conditionnée.
!>

RPVGRW

!>          RPVGRW est DOUBLE PRECISION
!>     Croissance pivot réciproque. À la sortie, ceci contient le facteur de croissance pivot
!>     réciproque norm(A)/norm(U). La norme est utilisée. S'il est beaucoup inférieur à 1, alors la stabilité de
!>     la factorisation LU de la matrice (équilibrée) A pourrait être médiocre.
!>     Cela signifie également que la solution X, les conditionnements estimés et
!>     les bornes d'erreur pourraient ne pas être fiables. Si la factorisation échoue avec
!>     0<INFO<=N, alors ceci contient le facteur de croissance pivot réciproque
!>     pour les INFO premières colonnes de A. Dans DGESVX, cette quantité est
!>     renvoyée dans WORK(1).
!>

BERR

!>          BERR est un tableau DOUBLE PRECISION, dimensionné (NRHS)
!>     Erreur relative par composante de la rétroaction. Ceci est le
!>     l'erreur relative par composante de chaque vecteur solution X(j)
!>     (c'est-à-dire le plus petit changement relatif dans un élément de A ou B qui
!>     fait de X(j) une solution exacte).
!>

!>          N_ERR_BNDS est INTEGER
!>     Nombre de bornes d'erreur à renvoyer pour chaque second membre
!>     et chaque type (global ou par composante). Voir ERR_BNDS_NORM et
!>     ERR_BNDS_COMP ci-dessous.
!>

ERR_BNDS_NORM

!>          ERR_BNDS_NORM est un tableau DOUBLE PRECISION, dimensionné (NRHS, N_ERR_BNDS)
!>     Pour chaque second membre, ce tableau contient des informations sur
!>     diverses bornes d'erreur et conditionnements correspondant à l'erreur relative globale,
!>     qui est définie comme suit :
!>
!>     Erreur relative globale dans le i-ème vecteur solution :
!>             max_j (abs(XTRUE(j,i) - X(j,i)))
!>            ------------------------------
!>                  max_j abs(X(j,i))
!>
!>     Le tableau est indexé par le type d'information d'erreur tel que décrit
!>     ci-dessous. Il y a actuellement jusqu'à trois informations
!>     renvoyées.
!>
!>     Le premier indice dans ERR_BNDS_NORM(i,:) correspond au i-ème
!>     second membre.
!>
!>     Le second indice dans ERR_BNDS_NORM(:,err) contient les trois
!>     champs suivants :
!>     err = 1  booléen. Faites confiance à la réponse si le
!>              conditionnement réciproque est inférieur au seuil
!>              sqrt(n) * dlamch('Epsilon').
!>
!>     err = 2  borne d'erreur : L'erreur avant estimée,
!>              presque certainement dans un facteur 10 de l'erreur vraie
!>              tant que la prochaine entrée est supérieure au seuil
!>              sqrt(n) * dlamch('Epsilon'). Cette borne d'erreur ne devrait
!>              être fiable que si le booléen précédent est vrai.
!>
!>     err = 3  Conditionnement réciproque : Conditionnement réciproque globale estimé.
!>              Comparé au seuil
!>              sqrt(n) * dlamch('Epsilon') pour déterminer si l'estimation
!>              d'erreur est . Ces conditionnements réciproques
!>              sont 1 / (norm(Z^{-1},inf) * norm(Z,inf)) pour une matrice Z
!>              appropriément mise à l'échelle.
!>              Soit Z = S*A, où S met à l'échelle chaque ligne par une puissance de la
!>              base de sorte que toutes les sommes de lignes absolues de Z soient approximativement 1.
!>
!>     Voir Lapack Working Note 165 pour plus de détails et des précautions supplémentaires.
!>

ERR_BNDS_COMP

!>          ERR_BNDS_COMP est un tableau DOUBLE PRECISION, dimensionné (NRHS, N_ERR_BNDS)
!>     Pour chaque second membre, ce tableau contient des informations sur
!>     diverses bornes d'erreur et conditionnements correspondant à l'erreur relative par composante,
!>     qui est définie comme suit :
!>
!>     Erreur relative par composante dans le i-ème vecteur solution :
!>                    abs(XTRUE(j,i) - X(j,i))
!>             max_j ----------------------
!>                         abs(X(j,i))
!>
!>     Le tableau est indexé par le i-ème second membre (sur lequel l'erreur relative par composante dépend),
!>     et le type d'information d'erreur tel que décrit ci-dessous. Il y a actuellement jusqu'à trois
!>     informations renvoyées pour chaque second membre. Si
!>     la précision par composante n'est pas demandée (PARAMS(3) = 0.0), alors
!>     ERR_BNDS_COMP n'est pas accédé. Si N_ERR_BNDS < 3, alors au plus
!>     les premières entrées (:,N_ERR_BNDS) sont renvoyées.
!>
!>     Le premier indice dans ERR_BNDS_COMP(i,:) correspond au i-ème
!>     second membre.
!>
!>     Le second indice dans ERR_BNDS_COMP(:,err) contient les trois
!>     champs suivants :
!>     err = 1  booléen. Faites confiance à la réponse si le
!>              conditionnement réciproque est inférieur au seuil
!>              sqrt(n) * dlamch('Epsilon').
!>
!>     err = 2  borne d'erreur : L'erreur avant estimée,
!>              presque certainement dans un facteur 10 de l'erreur vraie
!>              tant que la prochaine entrée est supérieure au seuil
!>              sqrt(n) * dlamch('Epsilon'). Cette borne d'erreur ne devrait
!>              être fiable que si le booléen précédent est vrai.
!>
!>     err = 3  Conditionnement réciproque : Conditionnement réciproque par composante estimé.
!>              Comparé au seuil
!>              sqrt(n) * dlamch('Epsilon') pour déterminer si l'estimation
!>              d'erreur est . Ces conditionnements réciproques
!>              sont 1 / (norm(Z^{-1},inf) * norm(Z,inf)) pour une matrice Z
!>              appropriément mise à l'échelle.
!>              Soit Z = S*(A*diag(x)), où x est la solution pour
!>              le second membre courant et S met à l'échelle chaque ligne de
!>              A*diag(x) par une puissance de la base de sorte que toutes les lignes absolues
les sommes de Z sont approximativement égales à 1. !> !> Voir Lapack Working Note 165 pour plus de détails et des !> avertissements supplémentaires. !>

!>          INFO est INTEGER
!>       = 0 :  Sortie réussie. La solution pour chaque second membre est
