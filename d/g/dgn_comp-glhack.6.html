NOM

dgn_comp - Compilateur de donjons pour NetHack

SYNTAXE

dgn_comp [ fichier ]

Si aucun argument n'est donné, il lit l'entrée standard.

DESCRIPTION

Dgn_comp est un compilateur de donjons pour NetHack version 3.2 et supérieures. Il prend un fichier de description comme argument et produit un "script" de donjon qui doit être chargé par NetHack au moment de l'exécution.

Le but de cet outil est de fournir aux administrateurs et aux implémenteurs de NetHack un moyen pratique de créer un donjon personnalisé pour le jeu, sans avoir à recompiler le monde entier.

GRAMMAIRE

DUNGEON: nom marqueur_ossements ( base , rand ) [ %age ]

où nom est le nom du donjon, marqueur_ossements est une lettre pour marquer les fichiers d'ossements, ( base , rand ) est le nombre de niveaux, et %age est sa probabilité d'être généré (si absent, probabilité de 100%).

DESCRIPTION: tag

où tag est actuellement l'un de HELLISH, MAZELIKE, ou ROGUELIKE.

ALIGNEMENT | LEVALIGN: [ loyal | neutre | chaotique | non-aligné ]

donne l'alignement du donjon/niveau (par défaut : non-aligné).

ENTREE: niveau

le point d'entrée du donjon. La connexion du donjon s'attache à ce niveau du donjon donné. Si la valeur de niveau est négative, le niveau d'entrée est calculé à partir du bas du donjon, -1 étant le dernier niveau. Si cette ligne n'est pas présente dans une description de donjon, le niveau d'entrée par défaut est 1.

PROTOFILE: nom

le nom prototypique des fichiers de niveaux de donjon dans ce donjon. Par exemple, le nom PROTOFILE pour le donjon La Tour de Vlad est tour.

NIVEAU: nom marqueur_ossements @ ( base , rand ) [ %age ]

où nom est le nom du niveau, marqueur_ossements est une lettre pour marquer les fichiers d'ossements, ( base , rand ) est la position et %age est le pourcentage de génération, comme ci-dessus.

NIVEAUALEATOIRE: nom marqueur_ossements @ ( base , rand ) [ %age ] niveauxaleatoires

où nom est le nom du niveau, marqueur_ossements est une lettre pour marquer les fichiers d'ossements, ( base , rand ) est la position, %age est le pourcentage de génération, comme ci-dessus, et niveauxaleatoires est le nombre de niveaux similaires disponibles pour le choix.

NIVEAUCONNECTE: nom marqueur_ossements nom_prec + ( base , rand ) [ %age ]

où nom est le nom du niveau, marqueur_ossements est une lettre pour marquer les fichiers d'ossements, nom_prec est le nom d'un niveau défini précédemment, ( base , rand ) est le décalage par rapport au niveau d'où il est connecté, et %age est le pourcentage de génération.

NIVEAUALEATOIRECONNECTE: nom marqueur_ossements nom_prec + ( base , rand ) [ %age ] niveauxaleatoires

où nom est le nom du niveau, marqueur_ossements est une lettre pour marquer les fichiers d'ossements, nom_prec est le nom d'un niveau défini précédemment, ( base , rand ) est le décalage par rapport au niveau d'où il est connecté, %age est le pourcentage de génération, et niveauxaleatoires est le nombre de niveaux similaires disponibles pour le choix.

DESCLEVEL: type

où type est le type de niveau (voir DESCRIPTION, ci-dessus). Le type est utilisé pour remplacer toute valeur prédéfinie utilisée pour décrire l'ensemble du donjon, pour ce niveau uniquement.

BRANCHEMENT: nom @ ( base , rand ) [ escalier | pas_haut | pas_bas | portail ] [ haut | bas ]

où nom est le nom du donjon vers lequel le branchement se fait, et ( base , rand ) est la position du branchement. Les deux derniers arguments optionnels sont le type de branchement et la direction du branchement. Le type d'un branchement peut être une connexion d'escalier bidirectionnelle, une connexion d'escalier unidirectionnelle, ou un portail magique. Un escalier unidirectionnel est décrit par les types pas_haut et pas_bas qui spécifient la direction de l'escalier manquante. Le type de branchement par défaut est escalier. La direction pour un escalier peut être soit haut, soit bas ; la direction n'est pas applicable aux portails. La direction par défaut est bas.

BRANCHEMENTCONNECTE: nom nom_prec + ( base , rand ) [ escalier | pas_haut | pas_bas | portail ] [ haut | bas ]

où nom est le nom du donjon vers lequel le branchement se fait, nom_prec est le nom d'un niveau défini précédemment, et ( base , rand ) est le décalage par rapport au niveau d'où il est connecté. Le type et la direction optionnels du branchement sont les mêmes que ceux décrits ci-dessus.

RÈGLES GÉNÉRALES

Chaque donjon doit avoir un marqueur_ossements unique, et chaque niveau spécial doit avoir un marqueur_ossements unique au sein de son donjon (les lettres peuvent être réutilisées dans différents donjons). Si le marqueur_ossements a la valeur spéciale "aucun", aucun fichier d'ossements ne sera créé pour ce niveau ou ce donjon.

La valeur base peut être comprise entre 1 et MAXLEVEL (tel que défini dans global.h ).

La valeur rand peut être comprise entre -1 et MAXLEVEL.

Si rand est -1, il sera remplacé par la valeur (nombre_niveaux_donjon(donjon) - base) pendant le processus de chargement (c'est-à-dire d'ici jusqu'à la fin du donjon).

Si rand est 0, le niveau est situé absolument à base.

Les branchements n'ont pas de probabilité. Les donjons en ont. Si un donjon n'est pas généré pendant le chargement, tous ses niveaux et branchements sont ignorés.

Aucun niveau ou branchement ne peut être connecté à partir d'un niveau avec une probabilité de génération en pourcentage. Ceci afin d'éviter une non-résolution pendant le chargement. De plus, aucun branchement ne peut être effectué à partir d'un donjon avec une probabilité de génération en pourcentage pour la même raison.

En règle générale, en utilisant le compilateur de donjons :

Si un donjon a un nom de protofile associé (par ex. tour), ce fichier sera utilisé.

Si un niveau spécial est présent, il remplacera la règle ci-dessus et le fichier approprié sera chargé.

Si aucun des éléments ci-dessus n'est présent, le générateur standard prendra le relais et créera un niveau "normal".

Un alignement de niveau, s'il est présent, remplacera l'alignement du donjon dans lequel il se trouve.

EXEMPLE

Voici la syntaxe actuelle du "langage" du compilateur de donjons :

#
#	Le fichier de description du donjon pour le NetHack original
#	standard de 3.0.
#
DUNGEON:	"The Dungeons of Doom" "D" (25, 5)
NIVEAU:		"rogue" "aucun" @ (15, 4)
NIVEAU:		"oracle" "aucun" @ (5, 7)
NIVEAU:		"bigroom" "B" @ (12, 3) 15
NIVEAU:		"medusa" "aucun" @ (20, 5)
NIVEAUCONNECTE:	"castle" "medusa" + (1, 4)
BRANCHEMENTCONNECTE:	"Hell" "castle" + (0, 0) pas_bas
BRANCHEMENT:		"The Astral Plane" @ (1, 0) pas_bas haut
DUNGEON:	"Hell" "H" (25, 5)
DESCRIPTION:	mazelike
DESCRIPTION:	hellish
BRANCHEMENT:		"Vlad's Tower" @ (13, 5) haut
NIVEAU:		"wizard" "aucun" @ (15, 10)
NIVEAU:		"fakewiz" "A" @ (5, 5)
NIVEAU:		"fakewiz" "B" @ (10, 5)
NIVEAU:		"fakewiz" "C" @ (15, 5)
NIVEAU:		"fakewiz" "D" @ (20, 5)
NIVEAU:		"fakewiz" "E" @ (25, 5)
DUNGEON:	"Vlad's Tower" "T" (3, 0)
PROTOFILE:	"tower"
DESCRIPTION:	mazelike
ENTREE:		-1
DUNGEON:	"The Astral Plane" "A" (1, 0)
DESCRIPTION:	mazelike
PROTOFILE:	"endgame"

NOTES:
Les lignes commençant par '#' sont considérées comme des commentaires.
Un niveau spécial doit être explicitement aligné. L'alignement du donjon dans lequel il se trouve ne s'applique qu'aux niveaux non spéciaux dans ce donjon.
