Documentation de la fonction/sous-programme

sous-programme dgelst (caractère trans, entier m, entier n, entier nrhs, double précision, dimension( lda, * ) a, entier lda, double précision, dimension( ldb, * ) b, entier ldb, double précision, dimension( * ) work, entier lwork, entier info)

DGELST résout des systèmes linéaires réels surdéterminés ou sous-déterminés pour des matrices GE en utilisant la factorisation QR ou LQ avec représentation WY compacte de Q.

Objectif:

!>
!> DGELST résout des systèmes linéaires réels surdéterminés ou sous-déterminés
!> impliquant une matrice A de taille M par N, ou sa transposée, en utilisant une
!> factorisation QR ou LQ de A avec une représentation WY compacte de Q.
!>
!> On suppose que A a un rang complet, et seule une protection rudimentaire
!> contre les matrices de rang déficient est fournie. Ce sous-programme ne détecte
!> que la déficience de rang exacte, où un élément diagonal du facteur triangulaire
!> de A est exactement zéro.
!>
!> Il est possible que l'un (ou plusieurs) des éléments diagonaux du facteur
!> triangulaire de A soient des nombres anormalement petits sans que ce sous-programme
!> ne signale d'erreur. Les solutions calculées pour de telles matrices presque de rang
!> déficient peuvent être moins précises en raison d'une perte de précision numérique.
!>
!> Les options suivantes sont proposées :
!>
!> 1. Si TRANS = 'N' et m >= n : trouver la solution des moindres carrés d'un
!>    système surdéterminé, c'est-à-dire résoudre le problème des moindres carrés
!>                 minimiser || B - A*X ||.
!>
!> 2. Si TRANS = 'N' et m < n : trouver la solution de norme minimale d'un
!>    système sous-déterminé A * X = B.
!>
!> 3. Si TRANS = 'T' et m >= n : trouver la solution de norme minimale d'un
!>    système sous-déterminé A**T * X = B.
!>
!> 4. Si TRANS = 'T' et m < n : trouver la solution des moindres carrés d'un
!>    système surdéterminé, c'est-à-dire résoudre le problème des moindres carrés
!>                 minimiser || B - A**T * X ||.
!>
!> Plusieurs vecteurs second membre b et vecteurs solution x peuvent être
!> gérés en un seul appel ; ils sont stockés comme colonnes de la matrice B
!> second membre de taille M par NRHS et de la matrice solution X de taille N par NRHS.
!>

Paramètres

TRANS 
!>          TRANS est CHARACTER*1
!>          = 'N' : le système linéaire implique A ;
!>          = 'T' : le système linéaire implique A**T.
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de seconds membres, c'est-à-dire le nombre de
!>          colonnes des matrices B et X. NRHS >=0.
!>

A

!>          A est un tableau DOUBLE PRECISION, de dimension (LDA,N)
!>          À l'entrée, la matrice A de taille M par N.
!>          À la sortie,
!>            si M >= N, A est écrasée par les détails de sa factorisation QR
!>                       renvoyés par DGEQRT ;
!>            si M <  N, A est écrasée par les détails de sa factorisation LQ
!>                       renvoyés par DGELQT.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,M).
!>

B

!>          B est un tableau DOUBLE PRECISION, de dimension (LDB,NRHS)
!>          À l'entrée, la matrice B des vecteurs seconds membres, stockés
!>          par colonne ; B est de taille M par NRHS si TRANS = 'N', ou N par NRHS
!>          si TRANS = 'T'.
!>          À la sortie, si INFO = 0, B est écrasée par les vecteurs solution,
!>          stockés par colonne :
!>          si TRANS = 'N' et m >= n, les lignes 1 à n de B contiennent les vecteurs
!>          solution des moindres carrés ; la somme des carrés des résidus pour
!>          la solution dans chaque colonne est donnée par la somme des carrés des
!>          éléments N+1 à M dans cette colonne ;
!>          si TRANS = 'N' et m < n, les lignes 1 à N de B contiennent les vecteurs
!>          solution de norme minimale ;
!>          si TRANS = 'T' et m >= n, les lignes 1 à M de B contiennent les vecteurs
!>          solution de norme minimale ;
!>          si TRANS = 'T' et m < n, les lignes 1 à M de B contiennent les vecteurs
!>          solution des moindres carrés ; la somme des carrés des résidus pour
!>          la solution dans chaque colonne est donnée par la somme des carrés des
!>          éléments M+1 à N dans cette colonne.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B. LDB >= MAX(1,M,N).
!>

WORK

!>          WORK est un tableau DOUBLE PRECISION, de dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) renvoie la valeur optimale de LWORK.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK.
!>          LWORK >= max( 1, MN + max( MN, NRHS ) ).
!>          Pour des performances optimales,
!>          LWORK >= max( 1, (MN + max( MN, NRHS ))*NB ).
!>          où MN = min(M,N) et NB est la taille de bloc optimale.
!>
!>          Si LWORK = -1, alors une requête de capacité de stockage est supposée ; la routine
!>          calcule seulement la taille optimale du tableau WORK, renvoie
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          relatif à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : si INFO =  i, le i-ème élément diagonal du
!>                facteur triangulaire de A est exactement zéro, donc A n'a pas
!>                de rang complet ; la solution des moindres carrés n'a pas pu
!>                être calculée.
!>
