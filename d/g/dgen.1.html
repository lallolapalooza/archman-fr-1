DGEN(1) Manuel des commandes générales DGEN(1)

NOM

dgen — Émulateur Sega Genesis/Mega Drive

SYNTAXE

dgen [-Pfhmv] [-R (J|U|E)] [-H HZ] [-D NOMDEMO] [-d NOMDEMO] [-n USEC] [-p CODE,CODE...] [-r FICHIERRC] [-X COEFFX] [-Y COEFFY] [-S COEFF] [-g (0|1)] [-G XxY] [-s EMPLACEMENT] [nomrom [...]]

DESCRIPTION

L'image ROM du fichier nomrom est exécutée, émulée sur une Sega Genesis ou Mega Drive fonctionnant en mode NTSC 60Hz (sauf si l'option -P est spécifiée, auquel cas le mode PAL 50Hz est utilisé). nomrom doit être au format binaire brut ou SMD, et peut être compressé avec gzip(1), zip(1), ou bzip2(1).

Lorsque nomrom n'est pas spécifié, DGen démarre sans ROM. Elle peut être chargée plus tard depuis l'invite de commande. Lorsque plus d'un nomrom est spécifié, ils sont exécutés séquentiellement.

Les options sont les suivantes :

-H HZ
Utilise un taux de rafraîchissement personnalisé, peut être utilisé pour accélérer ou ralentir l'émulation.
-P
Émule le mode PAL 50Hz (utilisé dans les modèles européens de la Mega Drive).
-R (J|U|E)
Région de l'émulateur. Sans cette option, DGen utilise la première région mentionnée dans l'en-tête de la ROM. Elle doit être combinée avec -P pour le mode PAL. Voir ci-dessous.
(aucun)
Autodétection (NTSC, 60Hz)
-P
Autodétection (PAL, 50Hz)
-R J
Japon (NTSC, 60Hz)
-R J -P
Japon (PAL, 50Hz)
-R E
Europe (NTSC, 60Hz, la musique jouera certainement trop vite)
-R E -P
Europe (PAL, 50Hz)
-R U
Amérique (NTSC, 60Hz)
-R U -P
Identique à -R E -P
-f
Exécute en plein écran, si possible.
-h
Affiche un bref résumé de toutes les options.
-m
MinGW uniquement. Cette option empêche DGen de se détacher de sa console de contrôle.
-v
Affiche le numéro de version et quitte.
-D NOMDEMO
Relit une démo enregistrée avec l'option -d.
-d NOMDEMO
Enregistre une démo du programme en cours d'exécution, qui pourra être relue plus tard avec l'option -D.
-n USEC
Attend un nombre de microsecondes après chaque image, pour laisser du temps à d'autres processus.
-p CODE,CODE...
Modifie l'image ROM en mémoire, en utilisant des codes de style Game Genie ou Hex. Les codes Game Genie sont de la forme ABCD-EFGH et les codes Hex sont de la forme 123456:ABCD. Pour spécifier plus d'un code, séparez-les par des virgules (n'utilisez pas d'espaces).
-r FICHIERRC
Analyse un autre fichier rc après $HOME/.dgen/dgenrc. Les valeurs du fichier spécifié remplacent celles des fichiers précédents.
-X COEFFX
Met à l'échelle la fenêtre COEFFX fois dans la direction X. COEFFX doit être un entier positif.
-Y COEFFY
Met à l'échelle la fenêtre COEFFY fois dans la direction Y. COEFFY doit être un entier positif.
-S COEFF
Met à l'échelle la fenêtre COEFF fois dans les deux directions. COEFF doit être un entier positif.
-g (0|1)
Active/désactive OpenGL (si compilé).
-G XxY
Taille de fenêtre désirée (par exemple 640x480, 800x600, etc.)
-s EMPLACEMENT
Charge l'état sauvegardé de l'emplacement donné au démarrage (0-9)

INVITE INTERACTIVE

Une invite interactive minimaliste inspirée de vi(1) peut être utilisée pour effectuer diverses opérations décrites ci-dessous. Elle est déclenchée en appuyant sur deux-points (:), la touche par défaut. L'édition de ligne de commande, l'historique et la complétion sont pris en charge.

Commandes

{quitter, sortir, q}
Quitte, ou charge le prochain nomrom de la ligne de commande, s'il y en a un.
{charger, ouvrir, brancher, o} nomfichier
Charge un ROM nomfichier donné.
{décharger, fermer, débrancher}
Décharge le ROM actuel.
config_charger nomfichier
Charge la configuration depuis le fichier nomfichier.
config_sauver nomfichier
Sauvegarde la configuration actuelle dans le fichier nomfichier.
reset
Réinitialisation Genesis.
{ctv_push, ctv_pop, ctv_none}
Gère la pile des filtres Crap TV (si compilé).
calibrer nombre
Calibration interactive du gamepad spécifié (1 ou 2). Si nombre n'est pas spécifié, utilise 1 par défaut.
unbind liaison [...]
Supprime les liaisons spécifiées (variables préfixées par "bind_"). Voir dgenrc(5) pour plus d'informations à leur sujet.
vgmdump demarrer nomfichier
 
vgmdump arreter
Gère le vidage/journalisation VGM. Si le deuxième argument est demarrer, le vidage VGM sera démarré au chemin spécifié par le troisième argument. Si le deuxième argument est arreter, le vidage VGM sera arrêté et le vidage finalisé.

Variables

Toutes les variables de configuration de dgenrc(5) peuvent être affichées et modifiées interactivement, avec effet immédiat.

{int_nom, bool_nom, cle_nom, joy_nom, ...} {valeur}

Ce site n'est en aucun cas associé à Arch Linux ni affilié à ce projet. Le contenu est uniquement une traduction des pages de manuel d'Arch publiées sur man.archlinux.org.
