sous-routine dgeevx (character balanc, character jobvl, character jobvr, character sense, integer n, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( * ) wr, double precision, dimension( * ) wi, double precision, dimension( ldvl, * ) vl, integer ldvl, double precision, dimension( ldvr, * ) vr, integer ldvr, integer ilo, integer ihi, double precision, dimension( * ) scale, double precision abnrm, double precision, dimension( * ) rconde, double precision, dimension( * ) rcondv, double precision, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, integer

DGEEVX calcule les valeurs propres et, de manière facultative, les vecteurs propres gauche et/ou droit pour les matrices

GE

But

: 
!>
!> DGEEVX calcule pour une matrice réelle non symétrique A de dimension N par N, les
!> valeurs propres et, de manière facultative, les vecteurs propres gauche et/ou droit.
!>
!> De manière facultative, il calcule également une transformation d'équilibrage pour améliorer
!> le conditionnement des valeurs propres et des vecteurs propres (ILO, IHI,
!> SCALE, et ABNRM), les nombres de conditionnement réciproques pour les valeurs propres
!> (RCONDE), et les nombres de conditionnement réciproques pour les vecteurs propres
!> droit (RCONDV).
!>
!> Le vecteur propre droit v(j) de A satisfait
!>                  A * v(j) = lambda(j) * v(j)
!> où lambda(j) est sa valeur propre.
!> Le vecteur propre gauche u(j) de A satisfait
!>               u(j)**H * A = lambda(j) * u(j)**H
!> où u(j)**H désigne la transposée conjuguée de u(j).
!>
!> Les vecteurs propres calculés sont normalisés pour avoir une norme euclidienne
!> égale à 1 et la plus grande composante réelle.
!>
!> Équilibrer une matrice signifie permuter ses lignes et ses colonnes pour la rendre
!> plus proche d'une matrice triangulaire supérieure, et appliquer une transformation de similitude diagonale
!> D * A * D**(-1), où D est une matrice diagonale, pour
!> rendre ses lignes et ses colonnes plus proches en norme et les nombres de conditionnement
!> de ses valeurs propres et de ses vecteurs propres plus petits. Les nombres de conditionnement
!> réciproques calculés correspondent à la matrice équilibrée.
!> Permuter les lignes et les colonnes ne changera pas les nombres de conditionnement
!> (en arithmétique exacte) mais la mise à l'échelle diagonale les changera. Pour une explication
!> plus détaillée de l'équilibrage, voir la section 4.10.2 du Guide de l'utilisateur
!> de LAPACK.
!
>

Paramètre

s
BALANC 
!>          BALANC est de type CHARACTER*1
!>          Indique comment la matrice d'entrée doit être mise à l'échelle diagonalement
!>          et/ou permutée pour améliorer le conditionnement de ses
!>          valeurs propres.
!>          = 'N' : Ne pas mettre à l'échelle diagonalement ni permuter ;
!>          = 'P' : Effectuer des permutations pour rendre la matrice plus proche
!>                 d'une matrice triangulaire supérieure. Ne pas mettre à l'échelle diagonalement ;
!>          = 'S' : Mettre la matrice à l'échelle diagonalement, c'est-à-dire remplacer A par
!>                 D*A*D**(-1), où D est une matrice diagonale choisie
!>                 pour rendre les lignes et les colonnes de A plus égales en
!>                 norme. Ne pas permuter ;
!>          = 'B' : Mettre A à l'échelle diagonalement et la permuter.
!>
!>          Les nombres de conditionnement réciproques calculés le seront pour la matrice
!>          après équilibrage et/ou permutation. La permutation ne change pas
!>          les nombres de conditionnement (en arithmétique exacte), mais l'équilibrage les change.
!
>

JOBV

L 
!>          JOBVL est de type CHARACTER*1
!>          = 'N' : les vecteurs propres gauche de A ne sont pas calculés ;
!>          = 'V' : les vecteurs propres gauche de A sont calculés.
!>          Si SENSE = 'E' ou 'B', JOBVL doit être égal à 'V'.
!
>

JOBV

R 
!>          JOBVR est de type CHARACTER*1
!>          = 'N' : les vecteurs propres droit de A ne sont pas calculés ;
!>          = 'V' : les vecteurs propres droit de A sont calculés.
!>          Si SENSE = 'E' ou 'B', JOBVR doit être égal à 'V'.
!
>

SENS

E 
!>          SENSE est de type CHARACTER*1
!>          Détermine quels nombres de conditionnement réciproques sont calculés.
!>          = 'N' : aucun n'est calculé ;
!>          = 'E' : calculés pour les valeurs propres uniquement ;
!>          = 'V' : calculés pour les vecteurs propres droit uniquement ;
!>          = 'B' : calculés pour les valeurs propres et les vecteurs propres droit.
!>
!>          Si SENSE = 'E' ou 'B', les vecteurs propres gauche et droit
!>          doivent également être calculés (JOBVL = 'V' et JOBVR = 'V').
!
>

N 
!>          N est de type INTEGER
!>          L'ordre de la matrice A. N >= 0.
!
>

A 
!>          A est un tableau de type DOUBLE PRECISION, dimension (LDA,N)
!>          À l'entrée, la matrice A de dimension N par N.
!>          À la sortie, A a été écrasée. Si JOBVL = 'V' ou
!>          JOBVR = 'V', A contient la forme de Schur réelle de la version équilibrée
!>          de la matrice d'entrée A.
!
>

LD

A 
!>          LDA est de type INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,N).
!
>

W

R 
!>          WR est un tableau de type DOUBLE PRECISION, dimension (N)
!
>

W

I 
!>          WI est un tableau de type DOUBLE PRECISION, dimension (N)
!>          WR et WI contiennent respectivement les parties réelle et imaginaire
!>          des valeurs propres calculées. Les paires conjuguées complexes
!>          de valeurs propres apparaîtront consécutivement
!>          avec la valeur propre ayant la partie imaginaire positive
!>          en premier.
!
>

V

L 
!>          VL est un tableau de type DOUBLE PRECISION, dimension (LDVL,N)
!>          Si JOBVL = 'V', les vecteurs propres gauche u(j) sont stockés l'un
!>          après l'autre dans les colonnes de VL, dans le même ordre
!>          que leurs valeurs propres.
!>          Si JOBVL = 'N', VL n'est pas référencé.
!>          Si la j-ième valeur propre est réelle, alors u(j) = VL(:,j),
!>          la j-ième colonne de VL.
!>          Si les j-ième et (j+1)-ème valeurs propres forment une paire conjuguée
!>          complexe, alors u(j) = VL(:,j) + i*VL(:,j+1) et
!>          u(j+1) = VL(:,j) - i*VL(:,j+1).
!
>

LDV

L 
!>          LDVL est de type INTEGER
!>          La dimension principale du tableau VL. LDVL >= 1 ; si
!>          JOBVL = 'V', LDVL >= N.
!
>

V

R 
!>          VR est un tableau de type DOUBLE PRECISION, dimension (LDVR,N)
!>          Si JOBVR = 'V', les vecteurs propres droit v(j) sont stockés l'un
!>          après l'autre dans les colonnes de VR, dans le même ordre
!>          que leurs valeurs propres.
!>          Si JOBVR = 'N', VR n'est pas référencé.
!>          Si la j-ième valeur propre est réelle, alors v(j) = VR(:,j),
!>          la j-ième colonne de VR.
!>          Si les j-ième et (j+1)-ème valeurs propres forment une paire conjuguée
!>          complexe, alors v(j) = VR(:,j) + i*VR(:,j+1) et
!>          v(j+1) = VR(:,j) - i*VR(:,j+1).
!
>

LDV

R 
!>          LDVR est de type INTEGER
!>          La dimension principale du tableau VR. LDVR >= 1, et si
!>          JOBVR = 'V', LDVR >= N.
!
>

IL

O 
!>          ILO est de type INTEGER
!
>

IH

I 
!>          IHI est de type INTEGER
!>          ILO et IHI sont des valeurs entières déterminées lorsque A a été
!>          équilibrée. L'A(i,j) équilibrée = 0 si I > J et
!>          J = 1,...,ILO-1 ou I = IHI+1,...,N.
!
>

SCAL

E 
!>          SCALE est de type DOUBLE PRECISION tableau, dimension (N)
!>          Détails des permutations et des facteurs d'échelle appliqués
!>          lors de l'équilibrage de A. Si P(j) est l'indice de la ligne et de la colonne
!>          interchangées avec la ligne et la colonne j, et D(j) est le facteur
!>          d'échelle appliqué à la ligne et à la colonne j, alors
!>          SCALE(J) = P(J),    pour J = 1,...,ILO-1
!>                   = D(J),    pour J = ILO,...,IHI
!>                   = P(J)     pour J = IHI+1,...,N.
!>          L'ordre dans lequel les interchanges sont effectués est de N à IHI+1,
!>          puis de 1 à ILO-1.
!
>

ABNR

M 
!>          ABNRM est de type DOUBLE PRECISION
!>          La norme 1 de la matrice équilibrée (le maximum
!>          de la somme des valeurs absolues des éléments de n'importe quelle colonne).
!
>

RCOND

E 
!>          RCONDE est un tableau de type DOUBLE PRECISION, dimension (N)
!>          RCONDE(j) est le nombre de condition réciproque du j-ième
!>          valeur propre.
!
>

RCOND

V 
!>          RCONDV est un tableau de type DOUBLE PRECISION, dimension (N)
!>          RCONDV(j) est le nombre de condition réciproque du j-ième
!>          vecteur propre droit.
!
>

WOR

K 
!>          WORK est un tableau de type DOUBLE PRECISION, dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) renvoie la valeur optimale de LWORK.
!
>

LWOR

K 
!>          LWORK est de type INTEGER
!>          La dimension du tableau WORK. Si SENSE = 'N' ou 'E',
!>          LWORK >= max(1,2*N), et si JOBVL = 'V' ou JOBVR = 'V',
!>          LWORK >= 3*N. Si SENSE = 'V' ou 'B', LWORK >= N*(N+6).
!>          Pour de bonnes performances, LWORK doit généralement être plus grand.
!>
!>          Si LWORK = -1, alors une interrogation de l'espace de travail est supposée ; la routine
!>          calcule uniquement la taille optimale du tableau WORK, renvoie
!>          cette valeur comme première entrée du tableau WORK, et aucun message
!>          d'erreur lié à LWORK n'est émis par XERBLA.
!
>

IWOR

K 
!>          IWORK est un tableau de type INTEGER, dimension (2*N-2)
!>          Si SENSE = 'N' ou 'E', non référencé.
!
>

INF

O 
!>          INFO est de type INTEGER
!>          = 0:  sortie réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale.
!>          > 0:  si INFO = i, l'algorithme QR n'a pas réussi à calculer toutes les
!>                valeurs propres, et aucun vecteur propre ni nombre de condition
!>                n'a été calculé ; les éléments 1:ILO-1 et i+1:N de WR
!>                et WI contiennent les valeurs propres qui ont convergé.
!
>
