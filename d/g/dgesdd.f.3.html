Documentation de la fonction/sous-routine

sous-routine dgesdd (character jobz, integer m, integer n, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( * ) s, double precision, dimension( ldu, * ) u, integer ldu, double precision, dimension( ldvt, * ) vt, integer ldvt, double precision, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, integer info)

DGESDD

Purpose:

!>
!> DGESDD calcule la décomposition en valeurs singulières (SVD) d'une matrice réelle
!> M par N, A, en calculant éventuellement les vecteurs singuliers gauche et droit.
!> Si les vecteurs singuliers sont désirés, elle utilise un algorithme de
!> « diviser pour régner ».
!>
!> La SVD est écrite
!>
!>      A = U * SIGMA * transpose(V)
!>
!> où SIGMA est une matrice M par N nulle à l'exception de ses
!> min(m,n) éléments diagonaux, U est une matrice orthogonale M par M, et
!> V est une matrice orthogonale N par N. Les éléments diagonaux de SIGMA
!> sont les valeurs singulières de A ; elles sont réelles et non négatives, et
!> sont retournées en ordre décroissant. Les min(m,n) premières colonnes de
!> U et V sont les vecteurs singuliers gauche et droit de A.
!>
!> Notez que la routine retourne VT = V**T, et non V.
!>
!>

Paramètres

JOBZ 
!>          JOBZ est CHARACTER*1
!>          Spécifie les options pour le calcul de tout ou partie de la matrice U :
!>          = 'A':  toutes les M colonnes de U et toutes les N lignes de V**T sont
!>                  retournées dans les tableaux U et VT ;
!>          = 'S':  les min(M,N) premières colonnes de U et les min(M,N) premières
!>                  lignes de V**T sont retournées dans les tableaux U
!>                  et VT ;
!>          = 'O':  Si M >= N, les N premières colonnes de U sont écrasées
!>                  sur le tableau A et toutes les lignes de V**T sont retournées
!>                  dans le tableau VT ;
!>                  sinon, toutes les colonnes de U sont retournées dans
!>                  le tableau U et les M premières lignes de V**T sont écrasées
!>                  dans le tableau A ;
!>          = 'N':  aucune colonne de U ou ligne de V**T n'est calculée.
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice d'entrée A. M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice d'entrée A. N >= 0.
!>

A

!>          A est un tableau DOUBLE PRECISION, de dimension (LDA,N)
!>          À l'entrée, la matrice M par N, A.
!>          À la sortie,
!>          si JOBZ = 'O', A est écrasée avec les N premières colonnes
!>                          de U (les vecteurs singuliers gauches, stockés
!>                          par colonnes) si M >= N ;
!>                          A est écrasée avec les M premières lignes
!>                          de V**T (les vecteurs singuliers droits, stockés
!>                          par lignes) sinon.
!>          si JOBZ .ne. 'O', le contenu de A est détruit.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,M).
!>

S

!>          S est un tableau DOUBLE PRECISION, de dimension (min(M,N))
!>          Les valeurs singulières de A, triées de telle sorte que S(i) >= S(i+1).
!>

U

!>          U est un tableau DOUBLE PRECISION, de dimension (LDU,UCOL)
!>          UCOL = M si JOBZ = 'A' ou JOBZ = 'O' et M < N ;
!>          UCOL = min(M,N) si JOBZ = 'S'.
!>          Si JOBZ = 'A' ou JOBZ = 'O' et M < N, U contient la matrice orthogonale M par M, U ;
!>          si JOBZ = 'S', U contient les min(M,N) premières colonnes de U
!>          (les vecteurs singuliers gauches, stockés par colonnes) ;
!>          si JOBZ = 'O' et M >= N, ou JOBZ = 'N', U n'est pas référencé.
!>

LDU

!>          LDU est INTEGER
!>          La dimension principale du tableau U. LDU >= 1 ; si
!>          JOBZ = 'S' ou 'A' ou JOBZ = 'O' et M < N, LDU >= M.
!>

VT

!>          VT est un tableau DOUBLE PRECISION, de dimension (LDVT,N)
!>          Si JOBZ = 'A' ou JOBZ = 'O' et M >= N, VT contient la
!>          matrice orthogonale N par N, V**T ;
!>          si JOBZ = 'S', VT contient les min(M,N) premières lignes de
!>          V**T (les vecteurs singuliers droits, stockés par lignes) ;
!>          si JOBZ = 'O' et M < N, ou JOBZ = 'N', VT n'est pas référencé.
!>

LDVT

!>          LDVT est INTEGER
!>          La dimension principale du tableau VT. LDVT >= 1 ;
!>          si JOBZ = 'A' ou JOBZ = 'O' et M >= N, LDVT >= N ;
!>          si JOBZ = 'S', LDVT >= min(M,N).
!>

WORK

!>          WORK est un tableau DOUBLE PRECISION, de dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) contient le LWORK optimal ;
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK. LWORK >= 1.
!>          Si LWORK = -1, une requête d'espace de travail est supposée. L'espace optimal
!>          pour le tableau WORK est calculé et stocké dans WORK(1),
!>          et aucun autre travail que la vérification des arguments n'est effectué.
!>
!>          Soit mx = max(M,N) et mn = min(M,N).
!>          Si JOBZ = 'N', LWORK >= 3*mn + max( mx, 7*mn ).
!>          Si JOBZ = 'O', LWORK >= 3*mn + max( mx, 5*mn*mn + 4*mn ).
!>          Si JOBZ = 'S', LWORK >= 4*mn*mn + 7*mn.
!>          Si JOBZ = 'A', LWORK >= 4*mn*mn + 6*mn + mx.
!>          Ce ne sont pas des minimums stricts dans tous les cas ; voir les commentaires dans le code.
!>          Pour de bonnes performances, LWORK devrait généralement être plus grand ;
!>          une requête est recommandée.
!>

IWORK

!>          IWORK est un tableau INTEGER, de dimension (8*min(M,N))
!>

INFO

!>          INFO est INTEGER
!>          <  0:  si INFO = -i, le i-ème argument avait une valeur illégale.
!>          = -4: si A contenait une entrée NAN.
!>          >  0:  DBDSDC n'a pas convergé, le processus de mise à jour a échoué.
!>          =  0:  fin réussie.
!>
