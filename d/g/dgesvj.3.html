sous-routine dgesvj (character*1 joba, character*1 jobu, character*1 jobv, integer m, integer n, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( n ) sva, integer mv, double precision, dimension( ldv, * ) v, integer ldv, double precision, dimension( lwork ) work, integer lwork, integer

info)

DGESV

J

But

: 
!>
!> DGESVJ calcule la décomposition en valeurs singulières (SVD) d'une matrice
!> réelle A de dimensions M par N, où M >= N. La SVD de A est écrite comme
!>                                    [++]   [xx]   [x0]   [xx]
!>              A = U * SIGMA * V^t,  [++] = [xx] * [ox] * [xx]
!>                                    [++]   [xx]
!> où SIGMA est une matrice diagonale de dimensions N par N, U est une matrice
!> orthonormale de dimensions M par N, et V est une matrice orthogonale de
!> dimensions N par N. Les éléments diagonaux de SIGMA sont les valeurs
!> singulières de A. Les colonnes de U et de V sont respectivement les vecteurs
!> singuliers gauche et droit de A.
!> DGESVJ peut parfois calculer des valeurs singulières très petites et leurs
!> vecteurs singuliers avec beaucoup plus de précision que d'autres routines de
!> SVD, voir ci-dessous sous Détails supplémentaires.
!
>

Paramètre

s
JOBA 
!>          JOBA est de type CHARACTER*1
!>          Spécifie la structure de A.
!>          = 'L' : la matrice d'entrée A est triangulaire inférieure ;
!>          = 'U' : la matrice d'entrée A est triangulaire supérieure ;
!>          = 'G' : la matrice d'entrée A est une matrice générale de
!>                  dimensions M par N, M >= N.
!
>

JOB

U 
!>          JOBU est de type CHARACTER*1
!>          Spécifie s'il faut calculer les vecteurs singuliers gauches
!>          (les colonnes de U) :
!>          = 'U' : les vecteurs singuliers gauches correspondant aux valeurs
!>                  singulières non nulles sont calculés et retournés dans les
!>                  colonnes de tête de A. Voir plus de détails dans la
!>                  description de A.
!>                  Le seuil d'orthogonalité numérique par défaut est défini à
!>                  environ TOL=CTOL*EPS, CTOL=DSQRT(M), EPS=DLAMCH('E').
!>          = 'C' : analogue à JOBU='U', sauf que l'utilisateur peut contrôler
!>                  le niveau d'orthogonalité numérique des vecteurs singuliers
!>                  gauches calculés. TOL peut être défini à TOL = CTOL*EPS,
!>                  où CTOL est donné en entrée dans le tableau WORK.
!>                  Aucune valeur de CTOL inférieure à ONE n'est autorisée.
!>                  Une valeur de CTOL supérieure à 1 / EPS est sans
!>                  signification. L'option 'C' peut être utilisée si
!>                  M*EPS est un niveau d'orthogonalité satisfaisant pour les
!>                  vecteurs singuliers gauches calculés, de sorte que CTOL=M
!>                  pourrait économiser quelques balayages de rotations de
!>                  Jacobi.
!>                  Voir les descriptions de A et WORK(1).
!>          = 'N' : la matrice U n'est pas calculée. Cependant, voir la
!>                  description de A.
!
>

JOB

V 
!>          JOBV est de type CHARACTER*1
!>          Spécifie s'il faut calculer les vecteurs singuliers droits, c'est-
!>          à-dire la matrice V :
!>          = 'V' :  la matrice V est calculée et retournée dans le tableau V
!>          = 'A' :  les rotations de Jacobi sont appliquées au tableau V de
!>                   dimensions MV par N. En d'autres termes, la matrice des
!>                   vecteurs singuliers droits V n'est pas calculée
!>                   explicitement, elle est plutôt appliquée à une matrice de
!>                   dimensions MV par N initialement stockée dans les MV
!>                   premières lignes de V.
!>          = 'N' :  la matrice V n'est pas calculée et le tableau V n'est pas
!>                   référencé
!
>

M 
!>          M est de type INTEGER
!>          Le nombre de lignes de la matrice d'entrée A. 1/DLAMCH('E') > M >= 0.
!
>

N 
!>          N est de type INTEGER
!>          Le nombre de colonnes de la matrice d'entrée A.
!>          M >= N >= 0.
!
>

A 
!>          A est un tableau de type DOUBLE PRECISION, dimension (LDA,N)
!>          À l'entrée, la matrice A de dimensions M par N.
!>          À la sortie :
!>          Si JOBU = 'U' .OR. JOBU = 'C' :
!>                 Si INFO = 0 :
!>                 RANKA colonnes orthonormales de U sont retournées dans les
!>                 RANKA colonnes de tête du tableau A. Ici RANKA <= N
!>                 est le nombre de valeurs singulières de A calculées qui sont
!>                 au-dessus du seuil de débordement inférieur DLAMCH('S'). Les
!>                 vecteurs singuliers correspondant aux valeurs singulières
!>                 sous le seuil ou nulles ne sont pas calculés. La valeur de
!>                 RANKA est retournée dans le tableau WORK sous la forme
!>                 RANKA=NINT(WORK(2)). Voir aussi les descriptions de SVA et
!>                 WORK. Les colonnes calculées de U sont numériquement
!>                 orthogonales entre elles jusqu'à environ
!>                 TOL=DSQRT(M)*EPS (par défaut) ; ou TOL=CTOL*EPS
!>                 (JOBU = 'C'), voir la description de JOBU.
!>                 Si INFO > 0 :
!>                 la procédure DGESVJ n'a pas convergé dans le nombre donné
!>                 d'itérations (balayages). Dans ce cas, les colonnes
!>                 calculées de U peuvent ne pas être orthogonales jusqu'à
!>                 TOL. La sortie U (stockée dans A), SIGMA (donnée par les
!>                 valeurs singulières calculées dans SVA(1:N)) et V est
!>                 toujours une décomposition de la matrice d'entrée A dans le
!>                 sens où le résidu
!>                 ||A-SCALE*U*SIGMA*V^T||_2 / ||A||_2 est petit.
!>
!>          Si JOBU = 'N' :
!>                 Si INFO = 0 :
!>                 Notez que les vecteurs singuliers gauches sont 'gratuits'
!>                 dans l'algorithme de SVD de Jacobi unilatéral. Cependant,
!>                 si seules les valeurs singulières sont nécessaires, le
!>                 niveau d'orthogonalité numérique de U n'est pas un problème
!>                 et les itérations s'arrêtent lorsque les colonnes de la
!>                 matrice itérée sont numériquement orthogonales jusqu'à
!>                 environ M*EPS. Ainsi, à la sortie, A contient les colonnes
!>                 de U mises à l'échelle avec les valeurs singulières
!>                 correspondantes.
!>                 Si INFO > 0 :
!>                 la procédure DGESVJ n'a pas convergé dans le nombre donné
!>                 d'itérations (balayages).
!
>

LD

A 
!>          LDA est de type INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,M).
!
>

SV

A 
!>          SVA est un tableau de type DOUBLE PRECISION, dimension (N)
!>          À la sortie :
!>          Si INFO = 0 :
!>          selon la valeur SCALE = WORK(1), nous avons :
!>                 Si SCALE = ONE :
!>                 SVA(1:N) contient les valeurs singulières calculées de A.
!>                 Pendant le calcul, SVA contient les normes euclidiennes des
!>                 colonnes des matrices itérées dans le tableau A.
!>                 Si SCALE .NE. ONE :
!>                 Les valeurs singulières de A sont SCALE*SVA(1:N), et cette
!>                 représentation factorisée est due au fait que certaines des
!>                 valeurs singulières de A pourraient déborder ou être trop
!>                 petites.
!>          Si INFO > 0 :
!>          la procédure DGESVJ n'a pas convergé dans le nombre donné
!>          d'itérations (balayages) et SCALE*SVA(1:N) peut ne pas être
!>          précis.
!
>

M

V 
!>          MV est de type INTEGER
!>          Si JOBV = 'A', alors le produit des rotations de Jacobi dans
!>          DGESVJ est appliqué aux MV premières lignes de V. Voir la
!>          description de JOBV.
!
>

V 
!>          V est un tableau de type DOUBLE PRECISION, dimension (LDV,N)
!>          Si JOBV = 'V', alors V contient à la sortie la matrice de
!>                         dimensions N par N des vecteurs singuliers droits ;
!>          Si JOBV = 'A', alors V contient le produit de la matrice des
!>                         vecteurs singuliers droits calculée et de la matrice
!>                         initiale dans le tableau V.
!>          Si JOBV = 'N', alors V n'est pas référencé.
!
>

LD

V 
!>          LDV est de type INTEGER
!>          La dimension principale du tableau V, LDV >= 1.
!>          Si JOBV = 'V', alors LDV >= max(1,N).
!>          Si JOBV = 'A', alors LDV >= max(1,MV) .
!
>

WOR

K 
!>          WORK est un tableau DOUBLE PRECISION, dimension (MAX(1,LWORK))
!>          À l'entrée :
!>          Si JOBU = 'C' :
!>          WORK(1) = CTOL, où CTOL définit le seuil de convergence.
!>                    Le processus s'arrête si toutes les colonnes de A sont mutuellement
!>                    orthogonales jusqu'à CTOL*EPS, EPS=DLAMCH('E').
!>                    Il est requis que CTOL >= ONE, c'est-à-dire qu'il n'est pas
!>                    autorisé de forcer la routine à obtenir l'orthogonalité
!>                    en dessous de EPS.
!>          À la sortie :
!>          WORK(1) = SCALE est le facteur d'échelle tel que SCALE*SVA(1:N)
!>                    sont les valeurs singulières calculées de A.
!>                    (Voir la description de SVA().)
!>          WORK(2) = NINT(WORK(2)) est le nombre de valeurs singulières
!>                    non nulles calculées.
!>          WORK(3) = NINT(WORK(3)) est le nombre de valeurs singulières
!>                    calculées qui sont plus grandes que le seuil de débordement
!>                    inférieur.
!>          WORK(4) = NINT(WORK(4)) est le nombre de balayages de rotations
!>                    de Jacobi nécessaires pour la convergence numérique.
!>          WORK(5) = max_{i.NE.j} |COS(A(:,i),A(:,j))| dans le dernier balayage.
!>                    C'est une information utile dans les cas où DGESVJ n'a
!>                    pas convergé, car elle peut être utilisée pour estimer si
!>                    la sortie est encore utile et pour une analyse a posteriori.
!>          WORK(6) = la plus grande valeur absolue de tous les sinus des
!>                    angles de rotation de Jacobi dans le dernier balayage. Elle peut être
!>                    utile pour une analyse a posteriori.
!
>

LWOR

K 
!>          LWORK est INTEGER
!>          La longueur du tableau WORK.
!>          LWORK >= 1, si MIN(M,N) = 0, et LWORK >= MAX(6,M+N), sinon.
!>
!>          Si à l'entrée LWORK = -1, alors une interrogation de l'espace de travail est supposée et
!>          aucune n'est effectuée ; WORK(1) est défini à la longueur minimale (et optimale)
!>          de WORK.
!
>

INF

O 
!>          INFO est INTEGER
!>          = 0:  sortie réussie.
!>          < 0:  si INFO = -i, alors le i-ème argument avait une valeur illégale
!>          > 0:  DGESVJ n'a pas convergé dans le nombre maximal autorisé (30)
!>                de balayages. La sortie peut encore être utile. Voir la
!>                description de WORK.
!
>

Détails supplémentaires

: 
!>
!>  La matrice orthogonale N par N V est obtenue comme un produit de rotations
!>  planes de Jacobi. Les rotations sont implémentées comme des rotations
!>  mises à l'échelle rapides de Anda et Park [1]. Dans le cas de débordement
!>  inférieur de l'angle de Jacobi, une transformation de Jacobi modifiée de
!>  Drmac [4] est utilisée. La stratégie de pivotement utilise des
!>  échanges de colonnes de de Rijk [2]. La précision relative des valeurs
!>  singulières calculées et la précision des vecteurs singuliers calculés (en
!>  métrique angulaire) est telle que garantie par la théorie de Demmel et
!>  Veselic [3]. Le nombre de condition qui détermine la précision dans le cas
!>  de rang complet est essentiellement min_{D=diag} kappa(A*D), où kappa(.) est
!>  le nombre de condition spectral. Les meilleures performances de cette
!>  procédure SVD de Jacobi sont obtenues si elle est utilisée dans une version
!>  accélérée de Drmac et Veselic [5,6], et c'est la routine noyau de la
!>  bibliothèque SIGMA [7]. Certains paramètres d'ajustement (marqués avec [TP])
!>  sont disponibles pour l'implémenteur.
!>  La plage de calcul pour les valeurs singulières non nulles est l'intervalle
!>  de nombres machine ( UNDERFLOW , OVERFLOW ). Dans les cas extrêmes, même
!>  les valeurs singulières dénormalisées peuvent être calculées avec la perte
!>  correspondante de chiffres significatifs.
!
>
