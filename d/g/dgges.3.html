sous-routine dgges (character jobvsl, character jobvsr, character sort, external selctg, integer n, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( ldb, * ) b, integer ldb, integer sdim, double precision, dimension( * ) alphar, double precision, dimension( * ) alphai, double precision, dimension( * ) beta, double precision, dimension( ldvsl, * ) vsl, integer ldvsl, double precision, dimension( ldvsr, * ) vsr, integer ldvsr, double precision, dimension( * ) work, integer lwork, logical, dimension( * ) bwork, integer info)

DGGES calcule les valeurs propres, la forme de Schur, et, optionnellement, la matrice des vecteurs de Schur pour les matrices GE

Objectif :

!>
!> DGGES calcule pour une paire de matrices réelles non symétriques (A,B) de taille N-par-N,
!> les valeurs propres généralisées, la forme de Schur généralisée réelle (S,T),
!> et optionnellement, les matrices gauche et/ou droite des vecteurs de Schur (VSL et
!> VSR). Ceci donne la factorisation de Schur généralisée
!>
!>          (A,B) = ( (VSL)*S*(VSR)**T, (VSL)*T*(VSR)**T )
!>
!> Optionnellement, elle ordonne également les valeurs propres de sorte qu'un cluster sélectionné
!> de valeurs propres apparaisse dans les blocs diagonaux principaux de la matrice quasi-triangulaire
!> supérieure S et de la matrice triangulaire supérieure T. Les colonnes principales de VSL et
!> VSR forment alors une base orthonormée pour les sous-espaces gauche et droits correspondants
!> (sous-espaces défléchissants).
!>
!> (Si seules les valeurs propres généralisées sont nécessaires, utilisez le pilote
!> DGGEV à la place, ce qui est plus rapide.)
!>
!> Une valeur propre généralisée pour une paire de matrices (A,B) est un scalaire w
!> ou un ratio alpha/beta = w, tel que A - w*B est singulière. Elle est
!> généralement représentée par la paire (alpha,beta), car il existe une
!> interprétation raisonnable pour beta=0 ou pour les deux étant zéro.
!>
!> Une paire de matrices (S,T) est en forme de Schur généralisée réelle si T est
!> triangulaire supérieure avec une diagonale non négative et S est en bloc triangulaire
!> supérieure avec des blocs de 1x1 et 2x2. Les blocs de 1x1 correspondent
!> à des valeurs propres généralisées réelles, tandis que les blocs de 2x2 de S seront
!>
!>         [  a  b  ]
!>         [  c  d  ]
!>
!> en rendant les éléments correspondants de T de la forme :
!>         [  alpha  beta  ]
!>         [  0      alpha ]
!>
!> et la paire de blocs de 2x2 correspondants dans S et T aura une paire complexe conjuguée
!> de valeurs propres généralisées.
!>
!>

Paramètres

JOBVSL 
!>          JOBVSL est CHARACTER*1
!>          = 'N' : ne pas calculer les vecteurs de Schur gauches ;
!>          = 'V' : calculer les vecteurs de Schur gauches.
!>

JOBVSR

!>          JOBVSR est CHARACTER*1
!>          = 'N' : ne pas calculer les vecteurs de Schur droits ;
!>          = 'V' : calculer les vecteurs de Schur droits.
!>

SORT

!>          SORT est CHARACTER*1
!>          Spécifie si les valeurs propres doivent être ordonnées sur la
!>          diagonale de la forme de Schur généralisée.
!>          = 'N' : les valeurs propres ne sont pas ordonnées ;
!>          = 'S' : les valeurs propres sont ordonnées (voir SELCTG) ;
!>

SELCTG

!>          SELCTG est une FONCTION LOGIQUE de trois arguments DOUBLE PRECISION
!>          SELCTG doit être déclarée EXTERNE dans la sous-routine appelante.
!>          Si SORT = 'N', SELCTG n'est pas référencée.
!>          Si SORT = 'S', SELCTG est utilisée pour sélectionner les valeurs propres à trier
!>          en haut à gauche de la forme de Schur.
!>          Une valeur propre (ALPHAR(j)+ALPHAI(j))/BETA(j) est sélectionnée si
!>          SELCTG(ALPHAR(j),ALPHAI(j),BETA(j)) est vraie ; c'est-à-dire si l'une
!>          d'une paire complexe conjuguée de valeurs propres est sélectionnée,
!>          alors les deux valeurs propres complexes sont sélectionnées.
!>
!>          Notez que dans le cas mal conditionné, une valeur propre complexe sélectionnée
!>          peut ne plus satisfaire SELCTG(ALPHAR(j),ALPHAI(j),
!>          BETA(j)) = .TRUE. après ordonnancement. INFO doit être mis à N+2
!>          dans ce cas.
!>

N

!>          N est INTEGER
!>          L'ordre des matrices A, B, VSL et VSR. N >= 0.
!>

A

!>          A est un tableau DOUBLE PRECISION, dimension (LDA, N)
!>          En entrée, le premier de la paire de matrices.
!>          En sortie, A a été écrasé par sa forme de Schur généralisée
!>          S.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale de A. LDA >= max(1,N).
!>

B

!>          B est un tableau DOUBLE PRECISION, dimension (LDB, N)
!>          En entrée, le second de la paire de matrices.
!>          En sortie, B a été écrasé par sa forme de Schur généralisée
!>          T.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale de B. LDB >= max(1,N).
!>

SDIM

!>          SDIM est INTEGER
!>          Si SORT = 'N', SDIM = 0.
!>          Si SORT = 'S', SDIM = nombre de valeurs propres (après tri)
!>          pour lesquelles SELCTG est vraie. (Les paires complexes conjuguées pour lesquelles
!>          SELCTG est vraie pour l'une ou l'autre des valeurs propres comptent pour 2.)
!>

ALPHAR

!>          ALPHAR est un tableau DOUBLE PRECISION, dimension (N)
!>

ALPHAI

!>          ALPHAI est un tableau DOUBLE PRECISION, dimension (N)
!>

BETA

!>          BETA est un tableau DOUBLE PRECISION, dimension (N)
!>          En sortie, (ALPHAR(j) + ALPHAI(j)*i)/BETA(j), j=1,...,N, seront
!>          les valeurs propres généralisées. ALPHAR(j) + ALPHAI(j)*i,
!>          et BETA(j), j=1,...,N sont les diagonales de la forme de Schur complexe
!>          (S,T) qui résulterait si les blocs diagonaux 2x2 de
!>          la forme de Schur réelle de (A,B) étaient réduits davantage
!>          en triangulaire à l'aide de transformations unitaires complexes 2x2.
!>          Si ALPHAI(j) est zéro, alors la j-ème valeur propre est réelle ; si
!>          positive, alors la j-ème et la (j+1)-ème valeurs propres sont une paire
!>          complexe conjuguée, avec ALPHAI(j+1) négative.
!>
!>          Note : les quotients ALPHAR(j)/BETA(j) et ALPHAI(j)/BETA(j)
!>          peuvent facilement déborder ou sous-déborder, et BETA(j) peut même être zéro.
!>          Par conséquent, l'utilisateur doit éviter de calculer naïvement le ratio.
!>          Cependant, ALPHAR et ALPHAI seront toujours inférieurs à et
!>          généralement comparables à la norme(A) en magnitude, et BETA toujours
!>          inférieur à et généralement comparable à la norme(B).
!>

VSL

!>          VSL est un tableau DOUBLE PRECISION, dimension (LDVSL,N)
!>          Si JOBVSL = 'V', VSL contiendra les vecteurs de Schur gauches.
!>          Non référencé si JOBVSL = 'N'.
!>

LDVSL

!>          LDVSL est INTEGER
!>          La dimension principale de la matrice VSL. LDVSL >=1, et
!>          si JOBVSL = 'V', LDVSL >= N.
!>

VSR

!>          VSR est un tableau DOUBLE PRECISION, dimension (LDVSR,N)
!>          Si JOBVSR = 'V', VSR contiendra les vecteurs de Schur droits.
!>          Non référencé si JOBVSR = 'N'.
!>

LDVSR

!>          LDVSR est INTEGER
!>          La dimension principale de la matrice VSR. LDVSR >= 1, et
!>          si JOBVSR = 'V', LDVSR >= N.
!>

TRAVAI

L 
!>          WORK est un tableau DOUBLE PRECISION, dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) renvoie le LWORK optimal.
!
>

LWOR

K 
!>          LWORK est INTEGER
!>          La dimension du tableau WORK.
!>          Si N = 0, LWORK >= 1, sinon LWORK >= MAX(8*N,6*N+16).
!>          Pour de bonnes performances, LWORK doit généralement être plus grand.
!>
!>          Si LWORK = -1, une interrogation d'espace de travail est supposée ; la routine
!>          calcule uniquement la taille optimale du tableau WORK, renvoie
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          lié à LWORK n'est émis par XERBLA.
!
>

BWOR

K 
!>          BWORK est un tableau LOGICAL, dimension (N)
!>          Non référencé si SORT = 'N'.
!
>

INF

O 
!>          INFO est INTEGER
!>          = 0:  sortie réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale.
!>          = 1,...,N:
!>                L'itération QZ a échoué. (A,B) ne sont pas en forme
!>                de Schur, mais ALPHAR(j), ALPHAI(j) et BETA(j) devraient
!>                être corrects pour j=INFO+1,...,N.
!>          > N:  =N+1: autre échec que l'itération QZ dans DHGEQZ.
!>                =N+2: après réordonnancement, l'arrondi a modifié les valeurs
!>                      de certains valeurs propres complexes de sorte que les valeurs
!>                      propres dominantes dans la forme de Schur généralisée ne
!>                      satisfassent plus SELCTG=.TRUE. Cela pourrait aussi
!>                      être dû à la mise à l'échelle.
!>                =N+3: le réordonnancement a échoué dans DTGSEN.
!
>
