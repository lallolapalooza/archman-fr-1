sous-routine dget33 (double precision rmax, integer lmax, integer ninfo, integer knt)

DGET33

Objectif :

!>
!> DGET33 teste DLANV2, une routine pour mettre des blocs de 2 par 2
!> sous forme standard. En d'autres termes, elle calcule une rotation
!> de deux par deux [[C,S] 
[-S,C]] où dans
!>
!>    [ C S ][T(1,1) T(1,2)][ C -S ] = [ T11 T12 ]
!>    [-S C ][T(2,1) T(2,2)][ S  C ]   [ T21 T22 ]
!>
!> soit
!>    1) T21=0 (valeurs propres réelles), soit
!>    2) T11=T22 et T21*T12<0 (valeurs propres complexes conjuguées).
!> Nous vérifions également que le résidu est faible.
!>

Paramètres

RMAX 
!>          RMAX est DOUBLE PRECISION
!>          Valeur du rapport de test le plus élevé.
!>

LMAX

!>          LMAX est INTEGER
!>          Numéro de l'exemple où le rapport de test le plus élevé est atteint.
!>

NINFO

!>          NINFO est INTEGER
!>          Nombre d'exemples renvoyés avec INFO .NE. 0.
!>

KNT

!>          KNT est INTEGER
!>          Nombre total d'exemples testés.
!>
