sous-programme dget31 (double precision rmax, integer lmax, integer, dimension( 2 ) ninfo, integer knt)

DGET31

Objectif :

!>
!> DGET31 teste DLALN2, une routine pour résoudre
!>
!>    (ca A - w D)X = sB
!>
!> où A est une matrice NA par NA (NA=1 ou 2 seulement), w est une constante réelle (NW=1) ou
!> complexe (NW=2), ca est une constante réelle, D est une matrice diagonale réelle NA par NA, et B est une matrice NA par NW (quand NW=2 la deuxième
!> colonne de B contient la partie imaginaire de la solution). Le code
!> retourne X et s, où s est un facteur d'échelle, inférieur ou égal à 1,
!> choisi pour éviter le dépassement de capacité dans X.
!>
!> Si des valeurs singulières de ca A-w D sont inférieures à un autre paramètre d'entrée
!> SMIN, elles sont perturbées jusqu'à SMIN.
!>
!> La condition de test est que le résidu mis à l'échelle
!>
!>     norm( (ca A-w D)*X - s*B ) /
!>           ( max( ulp*norm(ca A-w D), SMIN )*norm(X) )
!>
!> soit de l'ordre de 1. Ici, ulp est la précision machine.
!> De plus, il est vérifié que SCALE est inférieur ou égal à 1, et que
!> XNORM = norme infinie(X).
!>

Paramètres

RMAX 
!>          RMAX est DOUBLE PRECISION
!>          Valeur du plus grand rapport de test.
!>

LMAX

!>          LMAX est INTEGER
!>          Numéro de l'exemple où le plus grand rapport de test a été atteint.
!>

NINFO

!>          NINFO est un tableau INTEGER, de dimension (2)
!>          NINFO(1) = nombre d'exemples avec INFO inférieur à 0
!>          NINFO(2) = nombre d'exemples avec INFO supérieur à 0
!>

KNT

!>          KNT est INTEGER
!>          Nombre total d'exemples testés.
!>
