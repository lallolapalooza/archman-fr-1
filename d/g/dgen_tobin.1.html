NOM

dgen_tobin — Convertit une image au format SMD Genesis/Mega Drive en format brut (BIN)

SYNTAXE

dgen_tobin FROMSMD TOBIN

DESCRIPTION

L'image ROM FROMSMD est convertie en une image brute, telle que vue par la console Genesis/Mega Drive elle-même. L'image brute est écrite dans TOBIN. Si compilé avec le support de libarchive et si FROMSMD est compressé dans un format connu, il sera également décompressé de manière transparente.

VOIR AUSSI

dgen(1), libarchive(3)
