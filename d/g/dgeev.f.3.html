DGEEV calcule les valeurs propres et, en option, les vecteurs propres gauche et/ou droit des matrices GE

But :

!>
!> DGEEV calcule pour une matrice réelle non symétrique A de taille N par N,
!> les valeurs propres et, en option, les vecteurs propres gauche et/ou droit.
!>
!> Le vecteur propre droit v(j) de A satisfait
!>                  A * v(j) = lambda(j) * v(j)
!> où lambda(j) est sa valeur propre.
!> Le vecteur propre gauche u(j) de A satisfait
!>               u(j)**H * A = lambda(j) * u(j)**H
!> où u(j)**H désigne le conjugué-transposé de u(j).
!>
!> Les vecteurs propres calculés sont normalisés pour avoir une norme
!> euclidienne égale à 1 et la plus grande composante réelle.
!>

Paramètres

JOBVL 
!>          JOBVL est CHARACTER*1
!>          = 'N' : les vecteurs propres gauche de A ne sont pas calculés ;
!>          = 'V' : les vecteurs propres gauche de A sont calculés.
!>

JOBVR

!>          JOBVR est CHARACTER*1
!>          = 'N' : les vecteurs propres droit de A ne sont pas calculés ;
!>          = 'V' : les vecteurs propres droit de A sont calculés.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A. N >= 0.
!>

A

!>          A est un tableau DOUBLE PRECISION, dimension (LDA,N)
!>          À l'entrée, la matrice A de taille N par N.
!>          À la sortie, A a été écrasée.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,N).
!>

WR

!>          WR est un tableau DOUBLE PRECISION, dimension (N)
!>

WI

!>          WI est un tableau DOUBLE PRECISION, dimension (N)
!>          WR et WI contiennent respectivement les parties réelle et
!>          imaginaire des valeurs propres calculées. Les paires de
!>          valeurs propres conjuguées complexes apparaissent
!>          consécutivement, la valeur propre ayant la partie
!>          imaginaire positive en premier.
!>

VL

!>          VL est un tableau DOUBLE PRECISION, dimension (LDVL,N)
!>          Si JOBVL = 'V', les vecteurs propres gauche u(j) sont stockés
!>          les uns après les autres dans les colonnes de VL, dans le même
!>          ordre que leurs valeurs propres.
!>          Si JOBVL = 'N', VL n'est pas référencé.
!>          Si la j-ième valeur propre est réelle, alors u(j) = VL(:,j),
!>          la j-ième colonne de VL.
!>          Si les j-ième et (j+1)-ème valeurs propres forment une paire
!>          conjuguée complexe, alors u(j) = VL(:,j) + i*VL(:,j+1) et
!>          u(j+1) = VL(:,j) - i*VL(:,j+1).
!>

LDVL

!>          LDVL est INTEGER
!>          La dimension principale du tableau VL. LDVL >= 1 ; si
!>          JOBVL = 'V', LDVL >= N.
!>

VR

!>          VR est un tableau DOUBLE PRECISION, dimension (LDVR,N)
!>          Si JOBVR = 'V', les vecteurs propres droit v(j) sont stockés
!>          les uns après les autres dans les colonnes de VR, dans le même
!>          ordre que leurs valeurs propres.
!>          Si JOBVR = 'N', VR n'est pas référencé.
!>          Si la j-ième valeur propre est réelle, alors v(j) = VR(:,j),
!>          la j-ième colonne de VR.
!>          Si les j-ième et (j+1)-ème valeurs propres forment une paire
!>          conjuguée complexe, alors v(j) = VR(:,j) + i*VR(:,j+1) et
!>          v(j+1) = VR(:,j) - i*VR(:,j+1).
!>

LDVR

!>          LDVR est INTEGER
!>          La dimension principale du tableau VR. LDVR >= 1 ; si
!>          JOBVR = 'V', LDVR >= N.
!>

WORK

!>          WORK est un tableau DOUBLE PRECISION, dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) renvoie le LWORK optimal.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK. LWORK >= max(1,3*N), et
!>          si JOBVL = 'V' ou JOBVR = 'V', LWORK >= 4*N. Pour de bonnes
!>          performances, LWORK doit généralement être plus grand.
!>
!>          Si LWORK = -1, une interrogation de l'espace de travail est
!>          supposée ; la routine calcule uniquement la taille optimale
!>          du tableau WORK, renvoie cette valeur comme première entrée
!>          du tableau WORK, et aucun message d'erreur lié à LWORK n'est
!>          émis par XERBLA.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.
!>          > 0 : si INFO = i, l'algorithme QR a échoué à calculer toutes les
!>                valeurs propres, et aucun vecteur propre n'a été calculé ;
!>                les éléments i+1:N de WR et WI contiennent les valeurs
!>                propres qui ont convergé.
!>
