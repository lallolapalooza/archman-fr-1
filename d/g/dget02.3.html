sous-programme dget02 (caractère trans, entier m, entier n, entier nrhs, double précision, dimension( lda, * ) a, entier lda, double précision, dimension( ldx, * ) x, entier ldx, double précision, dimension( ldb, * ) b, entier ldb, double précision, dimension( * ) rwork, double précision resid)

DGET02

But:

!>
!> DGET02 calcule le résidu pour une solution d'un système d'équations linéaires
!> op(A)*X = B:
!>    RESID = norm(B - op(A)*X) / ( norm(op(A)) * norm(X) * EPS ),
!> où op(A) = A ou A**T, selon TRANS, et EPS est l'epsilon machine.
!> La norme utilisée est la 1-norme.
!>

Paramètres

TRANS 
!>          TRANS est CHARACTER*1
!>          Spécifie la forme du système d'équations:
!>          = 'N':  A    * X = B  (Pas de transposée)
!>          = 'T':  A**T * X = B  (Transposée)
!>          = 'C':  A**H * X = B  (Conjuguée transposée = Transposée)
!>

M

!>          M est un ENTIER
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

N

!>          N est un ENTIER
!>          Le nombre de colonnes de la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est un ENTIER
!>          Le nombre de colonnes de B, la matrice des seconds membres.
!>          NRHS >= 0.
!>

A

!>          A est un tableau DOUBLE PRÉCISION, dimension (LDA,N)
!>          La matrice originale A de dimension M x N.
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale du tableau A.  LDA >= max(1,M).
!>

X

!>          X est un tableau DOUBLE PRÉCISION, dimension (LDX,NRHS)
!>          Les vecteurs solution calculés pour le système d'équations linéaires.
!>

LDX

!>          LDX est un ENTIER
!>          La dimension principale du tableau X.  Si TRANS = 'N',
!>          LDX >= max(1,N); si TRANS = 'T' ou 'C', LDX >= max(1,M).
!>

B

!>          B est un tableau DOUBLE PRÉCISION, dimension (LDB,NRHS)
!>          À l'entrée, les vecteurs seconds membres du système d'équations linéaires.
!>          À la sortie, B est écrasé par la différence B - op(A)*X.
!>

LDB

!>          LDB est un ENTIER
!>          La dimension principale du tableau B.  Si TRANS = 'N',
!>          LDB >= max(1,M); si TRANS = 'T' ou 'C', LDB >= max(1,N).
!>

RWORK

!>          RWORK est un tableau DOUBLE PRÉCISION, dimension (M)
!>

RESID

!>          RESID est un DOUBLE PRÉCISION
!>          Le maximum sur le nombre de seconds membres de
!>          norm(B - op(A)*X) / ( norm(op(A)) * norm(X) * EPS ).
!>
