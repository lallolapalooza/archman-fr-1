subroutine dgeqp3rk (integer m, integer n, integer nrhs, integer kmax, double precision abstol, double precision reltol, double precision, dimension( lda, * ) a, integer lda, integer k, double precision maxc2nrmk, double precision relmaxc2nrmk, integer, dimension( * ) jpiv, double precision, dimension( * ) tau, double precision, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, integer info)

DGEQP3RK calcule une factorisation QR de Householder tronquée avec pivotement de colonnes d'une matrice réelle m-par-n A en utilisant les BLAS de niveau 3 et remplace une matrice réelle m-par-nrhs B par Q**T * B.

But :

!>
!> DGEQP3RK effectue deux tâches simultanément :
!>
!> Tâche 1 : La routine calcule une factorisation QR de Householder tronquée (rang K) ou de rang complet
!> avec pivotement de colonnes d'une matrice réelle
!> M-par-N A en utilisant les BLAS de niveau 3. K est le nombre de colonnes
!> qui ont été factorisées, c'est-à-dire le rang de la factorisation du
!> facteur R, K <= min(M,N).
!>
!>  A * P(K) = Q(K) * R(K)  =
!>
!>        = Q(K) * ( R11(K) R12(K) ) = Q(K) * (   R(K)_approx    )
!>                 ( 0      R22(K) )          ( 0  R(K)_residual ),
!>
!> où :
!>
!>  P(K)            est une matrice de permutation N-par-N ;
!>  Q(K)            est une matrice orthogonale M-par-M ;
!>  R(K)_approx   = ( R11(K), R12(K) ) est une approximation de rang K du
!>                    facteur R de rang complet avec R11(K) triangulaire supérieur
!>                    de taille K-par-K et R12(K) rectangulaire de taille K-par-N. Les entrées diagonales
!>                    de R11(K) apparaissent en ordre décroissant
!>                    de valeur absolue, et les valeurs absolues de toutes
!>                    celles-ci dépassent la norme 2 maximale de colonne de R22(K)
!>                    à l'erreur d'arrondi près.
!>  R(K)_residual = R22(K) est le résidu d'une approximation de rang K
!>                    du facteur R de rang complet. C'est une
!>                    matrice rectangulaire de taille (M-K)-par-(N-K) ;
!>  0               est une matrice nulle de taille (M-K)-par-K.
!>
!> Tâche 2 : En même temps, la routine remplace une matrice réelle M-par-NRHS
!> B par  Q(K)**T * B  en utilisant les BLAS de niveau 3.
!>
!> =====================================================================
!>
!> Les matrices A et B sont stockées en entrée dans le tableau A comme
!> les blocs gauche et droit A(1:M,1:N) et A(1:M, N+1:N+NRHS)
!> respectivement.
!>
!>                                  N     NRHS
!>             array_A   =   M  [ mat_A, mat_B ]
!>
!> Les critères de troncature (c'est-à-dire quand arrêter la factorisation)
!> peuvent être l'un des suivants :
!>
!>   1) Le paramètre d'entrée KMAX, le nombre maximal de colonnes
!>      KMAX à factoriser, c'est-à-dire que le rang de la factorisation est limité
!>      à KMAX. Si KMAX >= min(M,N), le critère n'est pas utilisé.
!>
!>   2) Le paramètre d'entrée ABSTOL, la tolérance absolue pour
!>      la norme 2 maximale de colonne de la matrice résiduelle R22(K). Cela
!>      signifie que la factorisation s'arrête si cette norme est inférieure ou
!>      égale à ABSTOL. Si ABSTOL < 0.0, le critère n'est pas utilisé.
!>
!>   3) Le paramètre d'entrée RELTOL, la tolérance pour la norme 2
!>      maximale de colonne de la matrice résiduelle R22(K) divisée
!>      par la norme 2 maximale de colonne de la matrice originale A, qui
!>      est égale à abs(R(1,1)). Cela signifie que la factorisation s'arrête
!>      lorsque le rapport de la norme 2 maximale de colonne de R22(K) à
!>      la norme 2 maximale de colonne de A est inférieur ou égal à RELTOL.
!>      Si RELTOL < 0.0, le critère n'est pas utilisé.
!>
!>   4) Dans le cas où les deux critères d'arrêt ABSTOL ou RELTOL ne sont pas utilisés,
!>      et lorsque la matrice résiduelle R22(K) est une matrice nulle à un certain
!>      étape de factorisation K. ( Ce critère d'arrêt est implicite. )
!>
!>  L'algorithme s'arrête lorsque l'une de ces conditions est d'abord
!>  satisfaite, sinon toute la matrice A est factorisée.
!>
!>  Pour factoriser toute la matrice A, utilisez les valeurs
!>  KMAX >= min(M,N), ABSTOL < 0.0 et RELTOL < 0.0.
!>
!>  La routine renvoie :
!>     a) Q(K), R(K)_approx = ( R11(K), R12(K) ),
!>        R(K)_residual = R22(K), P(K), c'est-à-dire les matrices résultantes
!>        de la factorisation ; P(K) est représentée par JPIV,
!>        ( si K = min(M,N), R(K)_approx est le facteur R complet,
!>        et il n'y a pas de matrice résiduelle R(K)_residual) ;
!>     b) K, le nombre de colonnes qui ont été factorisées,
!>        c'est-à-dire le rang de la factorisation ;
!>     c) MAXC2NRMK, la norme 2 maximale de colonne de la matrice
!>        résiduelle R(K)_residual = R22(K),
!>        ( si K = min(M,N), MAXC2NRMK = 0.0 ) ;
!>     d) RELMAXC2NRMK égale MAXC2NRMK divisé par MAXC2NRM, la norme 2
!>        maximale de colonne de la matrice originale A, qui est égale
!>        à abs(R(1,1)), ( si K = min(M,N), RELMAXC2NRMK = 0.0 ) ;
!>     e) Q(K)**T * B, la matrice B avec la transformation
!>        orthogonale Q(K)**T appliquée à gauche.
!>
!> La matrice de permutation N-par-N P(K) est stockée sous une forme compacte dans
!> le tableau entier JPIV. Pour 1 <= j <= N, la colonne j
!> de la matrice A a été interchangée avec la colonne JPIV(j).
!>
!> La matrice orthogonale M-par-M Q est représentée comme un produit
!> de réflecteurs de Householder élémentaires
!>
!>     Q(K) = H(1) *  H(2) * . . . * H(K),
!>
!> où K est le nombre de colonnes qui ont été factorisées.
!>
!> Chaque H(j) a la forme
!>
!>     H(j) = I - tau * v * v**T,
!>
!> où 1 <= j <= K et
!>   I    est une matrice identité M-par-M,
!>   tau  est un scalaire réel,
!>   v    est un vecteur réel avec v(1:j-1) = 0 et v(j) = 1.
!>
!> v(j+1:M) est stocké à la sortie dans A(j+1:M,j) et tau dans TAU(j).
!>
!> Voir la section Détails supplémentaires pour plus d'informations.
!>

Paramètres

M 
!>          M est INTEGER
!>          Le nombre de lignes de la matrice A. M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice A. N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de seconds membres, c'est-à-dire le nombre de
!>          colonnes de la matrice B. NRHS >= 0.
!>

KMAX

!>          KMAX est INTEGER
!>
!>          Le premier critère d'arrêt de la factorisation. KMAX >= 0.
!>
!>          Le nombre maximal de colonnes de la matrice A à factoriser,
!>          c'est-à-dire le rang maximal de la factorisation.
!>
!>          a) Si KMAX >= min(M,N), alors ce critère d'arrêt
!>                n'est pas utilisé, la routine factorise les colonnes
!>                en fonction de ABSTOL et RELTOL.
!>
!>          b) Si KMAX = 0, alors ce critère d'arrêt est
!>                satisfait à l'entrée et la routine se termine immédiatement.
!>                Cela signifie que la factorisation n'est pas effectuée,
!>                les matrices A et B ne sont pas modifiées, et
!>                la matrice A est elle-même le résidu.
!>

ABSTOL

!>          ABSTOL est DOUBLE PRECISION
!>
!>          Le deuxième critère d'arrêt de la factorisation, ne peut pas être NaN.
!>
!>          La tolérance absolue (seuil d'arrêt) pour
!>          la norme 2 maximale de colonne de la matrice résiduelle R22(K).
!>          L'algorithme converge (arrête la factorisation) lorsque
!>          la norme 2 maximale de colonne de la matrice résiduelle R22(K)
!>          est inférieure ou égale à ABSTOL. Soit SAFMIN = DLAMCH('S').
!>
!>          a) Si ABSTOL est NaN, alors aucun calcul n'est effectué
!>                et un message d'erreur ( INFO = -5 ) est émis
!>             par XERBLA.
!>
!>          b) Si ABSTOL < 0.0, alors ce critère d'arrêt n'est pas
!>                utilisé, la routine factorise les colonnes en fonction
!>                de KMAX et RELTOL.
!>                Ceci inclut le cas ABSTOL = -Inf.
!>
!>          c) Si 0.0 <= ABSTOL < 2*SAFMIN, alors 2*SAFMIN
!>                est utilisé. Ceci inclut le cas ABSTOL = -0.0.
!>
!>          d) Si 2*SAFMIN <= ABSTOL alors la valeur d'entrée
!>                de ABSTOL est utilisée.
!>
!>          Soit MAXC2NRM la norme euclidienne maximale des colonnes de
!>          la matrice originale A entière.
!>          Si ABSTOL choisi ci-dessus est >= MAXC2NRM, alors ce
!>          critère d'arrêt est satisfait à l'entrée et la routine sort
!>          immédiatement après le calcul de MAXC2NRM. La routine
!>          retourne MAXC2NRM dans MAXC2NORMK,
!>          et 1.0 dans RELMAXC2NORMK.
!>          Ceci inclut le cas ABSTOL = +Inf. Cela signifie que la
!>          factorisation n'est pas effectuée, les matrices A et B ne sont pas
!>          modifiées, et la matrice A est elle-même le résidu.
!>

RELTOL

!>          RELTOL est de type DOUBLE PRECISION
!>
!>          Le troisième critère d'arrêt de factorisation, ne peut pas être NaN.
!>
!>          La tolérance (seuil d'arrêt) pour le rapport
!>          abs(R(K+1,K+1))/abs(R(1,1)) de la norme euclidienne maximale des colonnes de
!>          la matrice résiduelle R22(K) à la norme euclidienne maximale des colonnes de
!>          la matrice originale A. L'algorithme converge (arrête la
!>          factorisation), lorsque abs(R(K+1,K+1))/abs(R(1,1)) A est inférieur
!>          ou égal à RELTOL. Soit EPS = DLAMCH('E').
!>
!>          a) Si RELTOL est NaN, alors aucun calcul n'est effectué
!>                et un message d'erreur ( INFO = -6 ) est émis
!>                par XERBLA.
!>
!>          b) Si RELTOL < 0.0, alors ce critère d'arrêt n'est pas
!>                utilisé, la routine factorise les colonnes en fonction
!>                de KMAX et ABSTOL.
!>                Ceci inclut le cas RELTOL = -Inf.
!>
!>          c) Si 0.0 <= RELTOL < EPS, alors RELTOL = EPS est utilisé.
!>                Ceci inclut le cas RELTOL = -0.0.
!>
!>          d) Si EPS <= RELTOL alors la valeur d'entrée de RELTOL
!>                est utilisée.
!>
!>          Soit MAXC2NRM la norme euclidienne maximale des colonnes de
!>          la matrice originale A entière.
!>          Si RELTOL choisi ci-dessus est >= 1.0, alors ce critère
!>          d'arrêt est satisfait à l'entrée et la routine sort
!>          immédiatement après le calcul de MAXC2NRM.
!>          La routine retourne MAXC2NRM dans MAXC2NORMK,
!>          et 1.0 dans RELMAXC2NORMK.
!>          Ceci inclut le cas RELTOL = +Inf. Cela signifie que la
!>          factorisation n'est pas effectuée, les matrices A et B ne sont pas
!>          modifiées, et la matrice A est elle-même le résidu.
!>
!>          NOTE : Nous recommandons que RELTOL satisfasse
!>                min( max(M,N)*EPS, sqrt(EPS) ) <= RELTOL
!>

A

!>          A est un tableau de type DOUBLE PRECISION, de dimension (LDA,N+NRHS)
!>
!>          À l'entrée :
!>
!>          a) Le sous-tableau A(1:M,1:N) contient la matrice A de taille M x N.
!>          b) Le sous-tableau A(1:M,N+1:N+NRHS) contient la matrice B de taille M x NRHS.
!>
!>                                  N     NRHS
!>              tableau_A   =   M  [ mat_A, mat_B ]
!>
!>          À la sortie :
!>
!>          a) Le sous-tableau A(1:M,1:N) contient des parties des facteurs
!>             de la matrice A :
!>
!>            1) Si K = 0, A(1:M,1:N) contient la matrice originale A.
!>            2) Si K > 0, A(1:M,1:N) contient des parties des
!>               facteurs :
!>
!>              1. Les éléments en dessous de la diagonale du sous-tableau
!>                 A(1:M,1:K) ensemble avec TAU(1:K) représentent la
!>                 matrice orthogonale Q(K) comme un produit de K
!>                 réflecteurs élémentaires de Householder.
!>
!>              2. Les éléments sur et au-dessus de la diagonale du
!>                 sous-tableau A(1:K,1:N) contiennent la matrice
!>                 de forme trapézoïdale supérieure K x N
!>                 R(K)_approx = ( R11(K), R12(K) ).
!>                 NOTE : Si K=min(M,N), c'est-à-dire factorisation de rang plein,
!>                       alors R_approx(K) est le facteur R complet qui
!>                       est de forme trapézoïdale supérieure. Si, en plus, M>=N,
!>                       alors R est de forme triangulaire supérieure.
!>
!>              3. Le sous-tableau A(K+1:M,K+1:N) contient la matrice
!>                 rectangulaire (M-K) x (N-K) R(K)_residual = R22(K).
!>
!>          b) Si NRHS > 0, le sous-tableau A(1:M,N+1:N+NRHS) contient
!>             le produit Q(K)**T * B de taille M x NRHS.
!>

LDA

!>          LDA est un entier.
!>          La dimension de tête du tableau A. LDA >= max(1,M).
!>          Ceci est la dimension de tête pour les deux matrices, A et B.
!>

K

!>          K est un entier.
!>          Rang de factorisation de la matrice A, c'est-à-dire le rang
!>          du facteur R, qui est le même que le nombre de lignes non nulles
!>          du facteur R. 0 <= K <= min(M,KMAX,N).
!>
!>          K représente également le nombre de vecteurs de Householder non nuls.
!>
!>          NOTE : Si K = 0, a) les tableaux A et B ne sont pas modifiés ;
!>                          b) le tableau TAU(1:min(M,N)) est mis à zéro,
!>                             si la matrice A ne contient pas de NaN,
!>                             sinon les éléments TAU(1:min(M,N))
!>                             ne sont pas définis ;
!>                          c) les éléments du tableau JPIV sont définis
!>                             comme suit : pour j = 1:N, JPIV(j) = j.
!>

MAXC2NRMK

!>          MAXC2NRMK est de type DOUBLE PRECISION.
!>          La norme euclidienne maximale des colonnes de la matrice résiduelle R22(K),
!>          lorsque la factorisation s'est arrêtée au rang K. MAXC2NRMK >= 0.
!>
!>          a) Si K = 0, c'est-à-dire que la factorisation n'a pas été effectuée,
!>             la matrice A n'a pas été modifiée et est elle-même une matrice résiduelle,
!>             alors MAXC2NRMK est égale à la norme euclidienne maximale des colonnes
!>             de la matrice originale A.
!>
!>          b) Si 0 < K < min(M,N), alors MAXC2NRMK est retourné.
!>
!>          c) Si K = min(M,N), c'est-à-dire que toute la matrice A a été
!>             factorisée et qu'il n'y a pas de matrice résiduelle,
!>             alors MAXC2NRMK = 0.0.
!>
!>          NOTE : MAXC2NRMK à l'étape de factorisation K serait égal à
!>                R(K+1,K+1) à la prochaine étape de factorisation K+1.
!>

RELMAXC2NRMK

!>          RELMAXC2NRMK est de type DOUBLE PRECISION.
!>          Le rapport MAXC2NRMK / MAXC2NRM de la norme euclidienne maximale des colonnes
!>          de la matrice résiduelle R22(K) (lorsque la factorisation
!>          s'est arrêtée au rang K) à la norme euclidienne maximale des colonnes de
!>          la matrice originale A entière. RELMAXC2NRMK >= 0.
!>
!>          a) Si K = 0, c'est-à-dire que la factorisation n'a pas été effectuée,
!>             la matrice A n'a pas été modifiée et est elle-même une matrice résiduelle,
!>             alors RELMAXC2NRMK = 1.0.
!>
!>          b) Si 0 < K < min(M,N), alors
!>                RELMAXC2NRMK = MAXC2NRMK / MAXC2NRM est retourné.
!>
!>          c) Si K = min(M,N), c'est-à-dire que toute la matrice A a été
!>             factorisée et qu'il n'y a pas de matrice résiduelle,
!>             alors RELMAXC2NRMK = 0.0.
!>
!>         NOTE : RELMAXC2NRMK à l'étape de factorisation K serait égal à
!>               abs(R(K+1,K+1))/abs(R(1,1)) à la prochaine étape de factorisation
!>               K+1.
!>

JPIV

!>          JPIV est un tableau de type INTEGER, de dimension (N).
!>          Indices de pivot des colonnes. Pour 1 <= j <= N, la colonne j
!>          de la matrice A a été échangée avec la colonne JPIV(j).
!>
!>          Les éléments du tableau JPIV(1:N) sont toujours définis
!>          par la routine, par exemple, même lorsque aucune colonne
!>          n'a été factorisée, c'est-à-dire quand K = 0, les éléments sont
!>          définis comme JPIV(j) = j pour j = 1:N.
!>

TAU

!>          TAU est un tableau de type DOUBLE PRECISION, de dimension (min(M,N)).
!>          Les facteurs scalaires des réflecteurs élémentaires.
!>
!>          Si 0 < K <= min(M,N), seuls les éléments TAU(1:K) du
!>          tableau TAU sont modifiés par la factorisation.
!>          Après le calcul de la factorisation, si aucun NaN n'a été trouvé
!>          pendant la factorisation, les éléments restants
!>          TAU(K+1:min(M,N)) sont mis à zéro, sinon les
!>          éléments TAU(K+1:min(M,N)) ne sont pas définis et sont donc
!>          indéfinis.
!>          ( Si K = 0, tous les éléments de TAU sont mis à zéro, si
!>          la matrice A ne contient pas de NaN. )
!>

WORK

!>          WORK est un tableau de type DOUBLE PRECISION, de dimension (MAX(1,LWORK)).
!>          À la sortie, si INFO = 0, WORK(1) retourne la valeur optimale de LWORK.
!>

LWORK

!>          LWORK est un entier.
!>          La dimension du tableau WORK.
!>          LWORK >= 1, si MIN(M,N) = 0, et
!>          LWORK >= (3*N+NRHS-1), sinon.
!>          Pour des performances optimales LWORK >= (2*N + NB*( N+NRHS+1 )),
!>          où NB est la taille de bloc optimale pour DGEQP3RK retournée
!>          par ILAENV. Taille de bloc minimale MINNB=2.
!>
!>          NOTE : La décision de savoir s'il faut utiliser le code BLAS 2
!>          non bloqué ou le code BLAS 3 bloqué est basée non seulement sur la dimension

!>          par ILAENV. (Pour N inférieur à NX, le code non bloqué doit être
!>          utilisé.)
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ;
!>          la routine calcule uniquement la taille optimale du tableau WORK,
!>          la retourne comme première entrée du tableau WORK, et aucun message
!>          d'erreur lié à LWORK n'est émis par XERBLA.
!>

IWORK

!>          IWORK est un tableau de type INTEGER, de dimension (N-1).
!>          Est un tableau de travail. ( IWORK est utilisé pour stocker les indices
!>          des colonnes pour la sous-mise à jour de norme
!>          dans la matrice résiduelle lors de l'étape bloquée de la sous-routine auxiliaire DLAQP3RK ).
!>

NAME

                    
dgeqp3rk — a rank-revealing QR factorization of a real
                        double-precision M-by-N matrix A, with column pivoting.

                

                

                    
SYNOPSIS

                    
SUBROUTINE DGEQP3RK(
   M, N, A, LDA, JPVT, TAU, WORK, LWORK, INFO )


INTEGER M, N, LDA, LWORK, INFO


DOUBLE PRECISION A( LDA, * ), TAU( * ), WORK( * )


INTEGER JPVT( * )





                

                

                    
Function/Subroutine Documentation

                    

                        
!>
!> Routine dgeqp3rk computes the QR factorization of a real
!> double-precision M-by-N matrix A, with column pivoting, which
!> produces an upper triangular matrix R such that
!>
!>    A*P = Q*R
!>
!> where P is an n-by-n orthogonal matrix, and Q is an m-by-m
!> orthogonal matrix. The matrix R is upper triangular.
!>
!> The routine is designed for rank-revealing QR factorization,
!> meaning that the diagonal entries of R will reveal the rank of
!> the matrix A. The rank is exposed by the magnitude of the
!> diagonal entries. Small diagonal entries indicate that the
!> corresponding columns are linearly dependent on the preceding
!> columns.
!>
!> Argument Details:
!>
!> M: The number of rows of the matrix A. M >= 0.
!>
!> N: The number of columns of the matrix A. N >= 0.
!>
!> A: On entry, the M-by-N matrix to be factorized.
!>    On exit, the upper triangular matrix R and the elements of
!>    the upper triangular factor of Q.
!>
!> LDA: The leading dimension of the array A. LDA >= max(1, M).
!>

!>     If JPVT(j) = k, then the k-th column of the initial matrix A
!>     is placed in the j-th column of the factorized matrix.
!>     If JPVT(j) = 0, then the routine selects a column for the j-th

!>     On exit, JPVT describes the permutation. JPVT(j) = k means
!>     that the k-th column of the original matrix A is the j-th

!> Notes on Rank Revealing:
!> The routine aims to produce a rank-revealing QR factorization.
!> If the rank of A is K, then the first K diagonal entries of R
!> should be significantly larger than the remaining N-K diagonal entries.
!> This allows for the determination of the rank of the matrix.

!> Handling of Infinity and NaN:

Further Details:

                    

                        
!> DGEQP3RK is based on the same BLAS3 Householder QR factorization
!> algorithm with column pivoting as in DGEQP3 routine which uses
!> DLARFG routine to generate Householder reflectors
!> for QR factorization.
!>
!> We can also write:
!>
!>   A = A_approx(K) + A_residual(K)
!>
!> The low rank approximation matrix A(K)_approx from
!> the truncated QR factorization of rank K of the matrix A is:
!>
!>   A(K)_approx = Q(K) * ( R(K)_approx ) * P(K)**T
!>                        (     0     0 )
!>
!>               = Q(K) * ( R11(K) R12(K) ) * P(K)**T
!>                        (      0      0 )
!>
!> The residual A_residual(K) of the matrix A is:
!>
!>   A_residual(K) = Q(K) * ( 0              0 ) * P(K)**T =
!>                          ( 0  R(K)_residual )
!>
!>                 = Q(K) * ( 0        0 ) * P(K)**T
!>                          ( 0   R22(K) )
!>
!> The truncated (rank K) factorization guarantees that
!> the maximum column 2-norm of A_residual(K) is less than
!> or equal to MAXC2NRMK up to roundoff error.
!>
!> NOTE: An approximation of the null vectors
!>       of A can be easily computed from R11(K)
!>       and R12(K):
!>
!>       Null( A(K) )_approx = P * ( inv(R11(K)) * R12(K) )
!>                                 (         -I           )
!>
!>
