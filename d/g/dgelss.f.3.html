sous-routine dgelss (m, n, nrhs, a, lda, b, ldb, s, rcond, rank, work, lwork, info)
DGELSS résout des systèmes surdéterminés ou sousdéterminés pour les matrices GE

Documentation de la fonction/sous-routine

sous-routine dgelss (integer m, integer n, integer nrhs, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( ldb, * ) b, integer ldb, double precision, dimension( * ) s, double precision rcond, integer rank, double precision, dimension( * ) work, integer lwork, integer info)

DGELSS résout des systèmes surdéterminés ou sousdéterminés pour les matrices GE

Objectif:

!>
!> DGELSS calcule la solution de norme minimale d'un problème linéaire par
!> moindres carrés réel:
!>
!> Minimiser la norme 2 de | b - A*x |.
!>
!> en utilisant la décomposition en valeurs singulières (SVD) de A. A est une
!> matrice M par N qui peut être de rang déficient.
!>
!> Plusieurs vecteurs second membre b et vecteurs solution x peuvent être
!> gérés en un seul appel; ils sont stockés comme les colonnes de la matrice
!> du second membre B de taille M par NRHS et de la matrice solution X de
!> taille N par NRHS.
!>
!> Le rang effectif de A est déterminé en considérant comme nuls les
!> valeurs singulières inférieures à RCOND fois la plus grande valeur
!> singulière.
!>

Paramètres

M 
!>          M est un entier
!>          Le nombre de lignes de la matrice A. M >= 0.
!>

N

!>          N est un entier
!>          Le nombre de colonnes de la matrice A. N >= 0.
!>

NRHS

!>          NRHS est un entier
!>          Le nombre de seconds membres, c'est-à-dire le nombre de colonnes
!>          des matrices B et X. NRHS >= 0.
!>

A

!>          A est un tableau de DOUBLE PRECISION, dimension (LDA,N)
!>          En entrée, la matrice A de taille M par N.
!>          En sortie, les min(m,n) premières lignes de A sont écrasées par
!>          ses vecteurs singuliers droits, stockés ligne par ligne.
!>

LDA

!>          LDA est un entier
!>          La dimension principale du tableau A. LDA >= max(1,M).
!>

B

!>          B est un tableau de DOUBLE PRECISION, dimension (LDB,NRHS)
!>          En entrée, la matrice du second membre B de taille M par NRHS.
!>          En sortie, B est écrasée par la matrice solution X de taille
!>          N par NRHS. Si m >= n et RANK = n, la somme des carrés des
!>          résidus pour la solution dans la i-ème colonne est donnée par
!>          la somme des carrés des éléments n+1:m de cette colonne.
!>

LDB

!>          LDB est un entier
!>          La dimension principale du tableau B. LDB >= max(1,max(M,N)).
!>

S

!>          S est un tableau de DOUBLE PRECISION, dimension (min(M,N))
!>          Les valeurs singulières de A en ordre décroissant.
!>          Le nombre de conditionnement de A dans la norme 2 = S(1)/S(min(m,n)).
!>

RCOND

!>          RCOND est un DOUBLE PRECISION
!>          RCOND est utilisé pour déterminer le rang effectif de A.
!>          Les valeurs singulières S(i) <= RCOND*S(1) sont traitées comme nulles.
!>          Si RCOND < 0, la précision machine est utilisée à la place.
!>

RANK

!>          RANK est un entier
!>          Le rang effectif de A, c'est-à-dire le nombre de valeurs singulières
!>          supérieures à RCOND*S(1).
!>

WORK

!>          WORK est un tableau de DOUBLE PRECISION, dimension (MAX(1,LWORK))
!>          En sortie, si INFO = 0, WORK(1) retourne la valeur optimale de LWORK.
!>

LWORK

!>          LWORK est un entier
!>          La dimension du tableau WORK. LWORK >= 1, et aussi:
!>          LWORK >= 3*min(M,N) + max( 2*min(M,N), max(M,N), NRHS )
!>          Pour de bonnes performances, LWORK devrait généralement être plus
!>          grand.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée;
!>          la routine calcule seulement la taille optimale du tableau WORK,
!>          retourne cette valeur comme première entrée du tableau WORK, et
!>          aucun message d'erreur lié à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est un entier
!>          = 0:  exécution réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale.
!>          > 0:  l'algorithme de calcul de la SVD n'a pas convergé;
!>                si INFO = i, i éléments hors diagonale d'une forme
!>                bidiagonale intermédiaire n'ont pas convergé vers zéro.
!>
