Documentation de la fonction/sous-routine

sous-routine dgerfsx (caractère trans, caractère equed, entier n, entier nrhs, double précision, dimension( lda, * ) a, entier lda, double précision, dimension( ldaf, * ) af, entier ldaf, entier, dimension( * ) ipiv, double précision, dimension( * ) r, double précision, dimension( * ) c, double précision, dimension( ldb, * ) b, entier ldb, double précision, dimension( ldx , * ) x, entier ldx, double précision rcond, double précision, dimension( * ) berr, entier n_err_bnds, double précision, dimension( nrhs, * ) err_bnds_norm, double précision, dimension( nrhs, * ) err_bnds_comp, entier nparams, double précision, dimension( * ) params, double précision, dimension( * ) work, entier, dimension( * ) iwork, entier info)

DGERFSX

Objectif:

!>
!>    DGERFSX améliore la solution calculée d'un système d'équations linéaires
!>    et fournit des bornes d'erreur et des estimations d'erreur rétrogrades
!>    pour la solution. En plus de la borne d'erreur normée, le code
!>    fournit une borne d'erreur composante par composante maximale si possible. Voir
!>    les commentaires pour ERR_BNDS_NORM et ERR_BNDS_COMP pour les détails des
!>    bornes d'erreur.
!>
!>    Le système d'équations linéaires d'origine peut avoir été équilibré
!>    avant d'appeler cette routine, comme décrit par les arguments EQUED, R
!>    et C ci-dessous. Dans ce cas, la solution et les bornes d'erreur retournées
!>    sont pour le système original non équilibré.
!> 
!>     Certains paramètres optionnels sont regroupés dans le tableau PARAMS. Ceux-ci
!>     les réglages déterminent comment le raffinement est effectué, mais souvent les
!>     les valeurs par défaut sont acceptables. Si les valeurs par défaut sont acceptables, les utilisateurs
!>     peuvent passer NPARAMS = 0 ce qui empêche le code source d'accéder
!>     l'argument PARAMS.
!>

Paramètres

TRANS 
!>          TRANS est CHARACTER*1
!>     Spécifie la forme du système d'équations :
!>       = 'N':  A * X = B     (Pas de transposée)
!>       = 'T':  A**T * X = B  (Transposée)
!>       = 'C':  A**H * X = B  (Transposée conjuguée = Transposée)
!>

EQUED

!>          EQUED est CHARACTER*1
!>     Spécifie la forme d'équilibrage qui a été effectuée sur A
!>     avant d'appeler cette routine. Ceci est nécessaire pour calculer
!>     correctement la solution et les bornes d'erreur.
!>       = 'N':  Pas d'équilibrage
!>       = 'R':  Équilibrage des lignes, c'est-à-dire que A a été multiplié
!>               par diag(R).
!>       = 'C':  Équilibrage des colonnes, c'est-à-dire que A a été post-multiplié
!>               par diag(C).
!>       = 'B':  Équilibrage des lignes et des colonnes, c'est-à-dire que A a été
!>               remplacé par diag(R) * A * diag(C).
!>               Le membre de droite B a été modifié en conséquence.
!>

N

!>          N est INTEGER
!>     L'ordre de la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>     Le nombre de membres de droite, c'est-à-dire le nombre de colonnes
!>     des matrices B et X.  NRHS >= 0.
!>

A

!>          A est un tableau de DOUBLE PRÉCISION, dimension (LDA,N)
!>     La matrice originale A de taille N x N.
!>

LDA

!>          LDA est INTEGER
!>     La dimension principale du tableau A.  LDA >= max(1,N).
!>

AF

!>          AF est un tableau de DOUBLE PRÉCISION, dimension (LDAF,N)
!>     Les facteurs L et U de la factorisation A = P*L*U
!>     tels que calculés par DGETRF.
!>

LDAF

!>          LDAF est INTEGER
!>     La dimension principale du tableau AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV est un tableau de type INTEGER, dimension (N)
!>     Les indices de pivot de DGETRF ; pour 1<=i<=N, la ligne i de la
!>     matrice a été échangée avec la ligne IPIV(i).
!>

R

!>          R est un tableau de DOUBLE PRÉCISION, dimension (N)
!>     Les facteurs d'échelle des lignes de A.  Si EQUED = 'R' ou 'B', A est
!>     multiplié à gauche par diag(R) ; si EQUED = 'N' ou 'C', R
!>     n'est pas accédé.
!>     Si R est accédé, chaque élément de R doit être une puissance de la base
!>     pour garantir une solution et des estimations d'erreur fiables. La mise à l'échelle par
!>     des puissances de la base ne provoque pas d'erreurs d'arrondi sauf si le
!>     résultat sous-dépasse ou dépasse. Les erreurs d'arrondi pendant la mise à l'échelle
!>     conduisent à un raffinement avec une matrice qui n'est pas équivalente à la
!>     matrice d'entrée, produisant des estimations d'erreur qui peuvent ne pas être
!>     fiables.
!>

C

!>          C est un tableau de DOUBLE PRÉCISION, dimension (N)
!>     Les facteurs d'échelle des colonnes de A.  Si EQUED = 'C' ou 'B', A est
!>     multiplié à droite par diag(C) ; si EQUED = 'N' ou 'R', C
!>     n'est pas accédé.
!>     Si C est accédé, chaque élément de C doit être une puissance de la base
!>     pour garantir une solution et des estimations d'erreur fiables. La mise à l'échelle par
!>     des puissances de la base ne provoque pas d'erreurs d'arrondi sauf si le
!>     résultat sous-dépasse ou dépasse. Les erreurs d'arrondi pendant la mise à l'échelle
!>     conduisent à un raffinement avec une matrice qui n'est pas équivalente à la
!>     matrice d'entrée, produisant des estimations d'erreur qui peuvent ne pas être
!>     fiables.
!>

B

!>          B est un tableau de DOUBLE PRÉCISION, dimension (LDB,NRHS)
!>     La matrice du membre de droite B.
!>

LDB

!>          LDB est INTEGER
!>     La dimension principale du tableau B.  LDB >= max(1,N).
!>

X

!>          X est un tableau de DOUBLE PRÉCISION, dimension (LDX,NRHS)
!>     En entrée, la matrice solution X, telle que calculée par DGETRS.
!>     En sortie, la matrice solution améliorée X.
!>

LDX

!>          LDX est INTEGER
!>     La dimension principale du tableau X.  LDX >= max(1,N).
!>

RCOND

!>          RCOND est DOUBLE PRÉCISION
!>     Conditionnement inverse mis à l'échelle. C'est une estimation de
!>     l'inverse du nombre de conditionnement de Skeel de la matrice A après
!>     équilibrage (si effectué). S'il est inférieur à la précision de la machine
!>     (en particulier, s'il est zéro), la matrice est singulière
!>     à la précision de travail. Notez que l'erreur peut toujours être faible même
!>     si ce nombre est très petit et que la matrice semble mal
!>     conditionnée.
!>

BERR

!>          BERR est un tableau de DOUBLE PRÉCISION, dimension (NRHS)
!>     Erreur rétrograde relative composante par composante. C'est l'
!>     erreur rétrograde relative composante par composante de chaque vecteur solution X(j)
!>     (c'est-à-dire la plus petite modification relative dans un élément de A ou B qui
!>     rend X(j) une solution exacte).
!>

N_ERR_BNDS

!>          N_ERR_BNDS est INTEGER
!>     Nombre de bornes d'erreur à retourner pour chaque membre de droite
!>     et chaque type (normé ou composante par composante). Voir ERR_BNDS_NORM et
!>     ERR_BNDS_COMP ci-dessous.
!>

ERR_BNDS_NORM

!>          ERR_BNDS_NOR

ERR_BNDS_COM

P 
!>          ERR_BNDS_COMP est un tableau DOUBLE PRECISION, dimension (NRHS, N_ERR_BNDS)
!>     Pour chaque membre de droite, ce tableau contient des informations sur
!>     diverses bornes d'erreur et nombres de conditionnement correspondant à
!>     l'erreur relative composante par composante, qui est définie comme suit :
!>
!>     Erreur relative composante par composante dans le i-ème vecteur solution :
!>                    abs(XTRUE(j,i) - X(j,i))
!>             max_j ----------------------
!>                         abs(X(j,i))
!>
!>     Le tableau est indexé par le membre de droite i (dont dépend
!>     l'erreur relative composante par composante), et le type d'information
!>     d'erreur comme décrit ci-dessous. Il y a actuellement jusqu'à trois
!>     informations retournées pour chaque membre de droite. Si la
!>     précision composante par composante n'est pas demandée (PARAMS(3) = 0.0), alors
!>     ERR_BNDS_COMP n'est pas accédé. Si N_ERR_BNDS < 3, alors au plus
!>     les premières entrées (:,N_ERR_BNDS) sont retournées.
!>
!>     Le premier indice dans ERR_BNDS_COMP(i,:) correspond au i-ème
!>     membre de droite.
!>
!>     Le deuxième indice dans ERR_BNDS_COMP(:,err) contient les trois
!>     champs suivants :
!>     err = 1  booléen. Faire confiance à la réponse si le
!>              nombre de conditionnement réciproque est inférieur au seuil
!>              sqrt(n) * dlamch('Epsilon').
!>
!>     err = 2  borne d'erreur : L'erreur avant estimée, qui est
!>              presque certainement dans un facteur de 10 de l'erreur réelle
!>              tant que l'entrée suivante est supérieure au seuil
!>              sqrt(n) * dlamch('Epsilon'). Cette borne d'erreur ne doit
!>              être utilisée que si le booléen précédent est vrai.
!>
!>     err = 3  Nombre de conditionnement réciproque : Nombre de
!>              conditionnement réciproque composante par composante estimé. Comparé au seuil
!>              sqrt(n) * dlamch('Epsilon') pour déterminer si l'estimation
!>              d'erreur est . Ces nombres de conditionnement
!>              réciproques sont 1 / (norm(Z^{-1},inf) * norm(Z,inf)) pour
!>              une matrice Z correctement mise à l'échelle.
!>              Soit Z = S*(A*diag(x)), où x est la solution pour le
!>              membre de droite courant et S met chaque ligne de
!>              A*diag(x) à l'échelle par une puissance de la base de sorte
!>              que toutes les sommes absolues de lignes de Z soient
!>              approximativement égales à 1.
!>
!>     Voir la Note de Travail LAPACK 165 pour plus de détails et de
!>     précautions supplémentaires.
!
>

PARAM

S 
!>          PARAMS est un tableau DOUBLE PRECISION, dimension (NPARAMS)
!>     Spécifie les paramètres de l'algorithme. Si une entrée est < 0.0, alors
!>     cette entrée sera remplie avec la valeur par défaut utilisée pour ce
!>     paramètre. Seules les positions jusqu'à NPARAMS sont accédées ; les valeurs par défaut
!>     sont utilisées pour les paramètres de numérotation supérieure.
!>
!>       PARAMS(LA_LINRX_ITREF_I = 1) : Effectuer ou non le raffinement
!>            itératif.
!>         Valeur par défaut : 1.0D+0
!>            = 0.0 : Aucun raffinement n'est effectué, et aucune borne d'erreur n'est
!>                    calculée.
!>            = 1.0 : Utiliser l'algorithme de raffinement en double précision,
!>                    éventuellement avec des calculs single-double si
!>                    l'environnement de compilation ne supporte pas DOUBLE
!>                    PRECISION.
!>              (les autres valeurs sont réservées pour une utilisation future)
!>
!>       PARAMS(LA_LINRX_ITHRESH_I = 2) : Nombre maximal de calculs de résidu
!>            autorisés pour le raffinement.
!>         Valeur par défaut : 10
!>         Agressif : Définir à 100 pour permettre la convergence en utilisant des
!>                     factorisations approchées ou des factorisations autres que LU. Si la
!>                     factorisation utilise une technique autre que
!>                     l'élimination de Gaussienne, les garanties dans
!>                     err_bnds_norm et err_bnds_comp peuvent ne plus être
!>                     dignes de confiance.
!>
!>       PARAMS(LA_LINRX_CWISE_I = 3 : Drapeau déterminant si le code
!>            tentera de trouver une solution avec une petite erreur relative
!>            composante par composante dans l'algorithme en double précision. Positif
!>            est vrai, 0.0 est faux.
!>         Valeur par défaut : 1.0 (tenter la convergence composante par composante)
!

O 
!>          INFO est INTEGER
!>       = 0 : Sortie réussie. La solution à chaque membre de droite est
!>         garantie.
!>       < 0 : Si INFO = -i, le i-ème argument avait une valeur illégale
!>       > 0 et <= N : U(INFO,INFO) est exactement zéro. La factorisation

!>         ERR_BNDS_NORM(:,1) et ERR_BNDS_COMP(:,1). Pour obtenir des informations
!>         sur tous les membres de droite, vérifier ERR_BNDS_NORM ou
