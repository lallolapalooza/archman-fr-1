sous-routine dgsvj1 (jobv, m, n, n1, a, lda, d, sva, mv, v, ldv, eps, sfmin, tol, nsweep, work, lwork, info)
DGSVJ1 pré-processeur de la sous-routine dgesvj, applique des rotations de Jacobi ciblant seulement des pivots particuliers.

Documentation de la fonction/sous-routine

sous-routine dgsvj1 (character*1 jobv, integer m, integer n, integer n1, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( n ) d, double precision, dimension( n ) sva, integer mv, double precision, dimension( ldv, * ) v, integer ldv, double precision eps, double precision sfmin, double precision tol, integer nsweep, double precision, dimension( lwork ) work, integer lwork, integer info)

DGSVJ1 est appelée depuis DGESVJ comme pré-processeur et c'est son but principal. Elle applique des rotations de Jacobi de la même manière que DGESVJ, mais elle ne cible que des pivots particuliers et ne vérifie pas la convergence (critère d'arrêt). Quelques paramètres d'ajustement (marqués par [TP]) sont disponibles pour l'implémenteur.

Objectif :

!>
!> DGSVJ1 est appelée depuis DGESVJ comme pré-processeur et c'est son but
!> principal. Elle applique des rotations de Jacobi de la même manière que
!> DGESVJ, mais elle ne cible que des pivots particuliers et ne vérifie pas
!> la convergence (critère d'arrêt). Quelques paramètres d'ajustement (marqués
!> par [TP]) sont disponibles pour l'implémenteur.
!>
!> Autres détails
!> ~~~~~~~~~~~~~~~
!> DGSVJ1 applique quelques passes de rotations de Jacobi dans l'espace des
!> colonnes de la matrice d'entrée M-par-N A. Les paires de pivots sont prises
!> dans le bloc hors-diagonale (1,2) de la matrice de Gram correspondante N-par-N
!> A^T * A. Les entrées de bloc (tuiles) du bloc hors-diagonale (1,2) sont
!> marquées par les [x] dans le schéma suivant :
!>
!>    | *  *  * [x] [x] [x]|
!>    | *  *  * [x] [x] [x]|    Rotation cyclique des lignes dans les blocs [x]
!>    | *  *  * [x] [x] [x]|    de taille nblr-par-nblc.
!>    |[x] [x] [x] *  *  * |    Pivots cycliques par ligne à l'intérieur de
!>    |[x] [x] [x] *  *  * |    chaque bloc [x].
!>    |[x] [x] [x] *  *  * |
!>
!> En termes de colonnes de A, les N1 premières colonnes sont tournées 'contre'
!> les N-N1 colonnes restantes, essayant d'augmenter l'angle entre les
!> sous-espaces correspondants. Le bloc hors-diagonale est de taille N1-par-(N-N1)
!> et il est tuilé en utilisant des tuiles quadratiques de côté KBL. Ici, KBL est
!> un paramètre d'ajustement. Le nombre de passes est donné dans NSWEEP et le
!> seuil d'orthogonalité est donné dans TOL.
!>

Paramètres

JOBV 
!>          JOBV est CHARACTER*1
!>          Spécifie si la sortie de cette procédure est utilisée
!>          pour calculer la matrice V :
!>          = 'V' : le produit des rotations de Jacobi est accumulé
!>                 en post-multipliant le tableau N-par-N V.
!>                (Voir la description de V.)
!>          = 'A' : le produit des rotations de Jacobi est accumulé
!>                 en post-multipliant le tableau MV-par-N V.
!>                (Voir les descriptions de MV et V.)
!>          = 'N' : les rotations de Jacobi ne sont pas accumulées.
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice d'entrée A.  M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice d'entrée A.
!>          M >= N >= 0.
!>

N1

!>          N1 est INTEGER
!>          N1 spécifie la partition du bloc 2x2, les N1 premières colonnes sont
!>          tournées 'contre' les N-N1 colonnes restantes de A.
!>

A

!>          A est un tableau de DOUBLE PRECISION, dimension (LDA,N)
!>          À l'entrée, la matrice M-par-N A, telle que A*diag(D) représente
!>          la matrice d'entrée.
!>          À la sortie,
!>          A_à_la_sortie * D_à_la_sortie représente la matrice d'entrée A*diag(D)
!>          post-multipliée par une séquence de rotations de Jacobi, où le
!>          seuil de rotation et le nombre total de passes sont donnés dans
!>          TOL et NSWEEP, respectivement.
!>          (Voir les descriptions de N1, D, TOL et NSWEEP.)
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,M).
!>

D

!>          D est un tableau de DOUBLE PRECISION, dimension (N)
!>          Le tableau D accumule les facteurs d'échelle des rotations de Jacobi
!>          rapides et mises à l'échelle.
!>          À l'entrée, A*diag(D) représente la matrice d'entrée.
!>          À la sortie, A_à_la_sortie*diag(D_à_la_sortie) représente la matrice
!>          d'entrée post-multipliée par une séquence de rotations de Jacobi,
!>          où le seuil de rotation et le nombre total de passes sont donnés dans
!>          TOL et NSWEEP, respectivement.
!>          (Voir les descriptions de N1, A, TOL et NSWEEP.)
!>

SVA

!>          SVA est un tableau de DOUBLE PRECISION, dimension (N)
!>          À l'entrée, SVA contient les normes euclidiennes des colonnes de
!>          la matrice A*diag(D).
!>          À la sortie, SVA contient les normes euclidiennes des colonnes de
!>          la matrice à la sortie*diag(D_à_la_sortie).
!>

MV

!>          MV est INTEGER
!>          Si JOBV = 'A', alors MV lignes de V sont post-multipliées par une
!>                         séquence de rotations de Jacobi.
!>          Si JOBV = 'N', alors MV n'est pas référencé.
!>

V

!>          V est un tableau de DOUBLE PRECISION, dimension (LDV,N)
!>          Si JOBV = 'V', alors N lignes de V sont post-multipliées par une
!>                         séquence de rotations de Jacobi.
!>          Si JOBV = 'A', alors MV lignes de V sont post-multipliées par une
!>                         séquence de rotations de Jacobi.
!>          Si JOBV = 'N', alors V n'est pas référencé.
!>

LDV

!>          LDV est INTEGER
!>          La dimension principale du tableau V,  LDV >= 1.
!>          Si JOBV = 'V', LDV >= N.
!>          Si JOBV = 'A', LDV >= MV.
!>

EPS

!>          EPS est DOUBLE PRECISION
!>          EPS = DLAMCH('Epsilon')
!>

SFMIN

!>          SFMIN est DOUBLE PRECISION
!>          SFMIN = DLAMCH('Safe Minimum')
!>

TOL

!>          TOL est DOUBLE PRECISION
!>          TOL est le seuil pour les rotations de Jacobi. Pour une paire
!>          A(:,p), A(:,q) de colonnes de pivot, la rotation de Jacobi est
!>          appliquée seulement si DABS(COS(angle(A(:,p),A(:,q)))) > TOL.
!>

NSWEEP

!>          NSWEEP est INTEGER
!>          NSWEEP est le nombre de passes de rotations de Jacobi à effectuer.
!>

WORK

!>          WORK est un tableau de DOUBLE PRECISION, dimension (LWORK)
!>

LWORK

!>          LWORK est INTEGER
!>          LWORK est la dimension de WORK. LWORK >= M.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie.
!>          < 0 : si INFO = -i, alors le i-ème argument avait une valeur illégale.
!>
