sous-programme dgerfs (caractère trans, entier n, entier nrhs, double précision, dimension( lda, * ) a, entier lda, double précision, dimension( ldaf, * ) af, entier ldaf, entier, dimension( * ) ipiv, double précision, dimension( ldb, * ) b, entier ldb, double précision, dimension( ldx, * ) x, entier ldx, double précision, dimension( * ) ferr, double précision, dimension( * ) berr, double précision, dimension( * ) work, entier, dimension( * ) iwork, entier info)

DGERFS

But :

!>
!> DGERFS améliore la solution calculée d'un système d'équations linéaires
!> et fournit des bornes d'erreur et des estimations d'erreur arrière pour
!> la solution.
!>

Paramètres

TRANS 
!>          TRANS est CHARACTER*1
!>          Spécifie la forme du système d'équations :
!>          = 'N' :  A * X = B     (Pas de transposée)
!>          = 'T' :  A**T * X = B  (Transposée)
!>          = 'C' :  A**H * X = B  (Conjuguée transposée = Transposée)
!>

N

!>          N est INTEGER
!>          Ordre de la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Nombre de seconds membres, c'est-à-dire le nombre de colonnes
!>          des matrices B et X.  NRHS >= 0.
!>

A

!>          A est un tableau DOUBLE PRECISION, dimension (LDA,N)
!>          La matrice originale A de taille N*N.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

AF

!>          AF est un tableau DOUBLE PRECISION, dimension (LDAF,N)
!>          Les facteurs L et U de la factorisation A = P*L*U
!>          tels que calculés par DGETRF.
!>

LDAF

!>          LDAF est INTEGER
!>          La dimension principale du tableau AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV est un tableau INTEGER, dimension (N)
!>          Les indices de pivot de DGETRF ; pour 1<=i<=N, la ligne i de la
!>          matrice a été échangée avec la ligne IPIV(i).
!>

B

!>          B est un tableau DOUBLE PRECISION, dimension (LDB,NRHS)
!>          La matrice second membre B.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

X

!>          X est un tableau DOUBLE PRECISION, dimension (LDX,NRHS)
!>          À l'entrée, la matrice solution X, telle que calculée par DGETRS.
!>          À la sortie, la matrice solution améliorée X.
!>

LDX

!>          LDX est INTEGER
!>          La dimension principale du tableau X.  LDX >= max(1,N).
!>

FERR

!>          FERR est un tableau DOUBLE PRECISION, dimension (NRHS)
!>          La borne d'erreur avant estimée pour chaque vecteur solution
!>          X(j) (la j-ième colonne de la matrice solution X).
!>          Si XTRUE est la vraie solution correspondant à X(j), FERR(j)
!>          est une borne supérieure estimée pour la magnitude du plus grand
!>          élément de (X(j) - XTRUE) divisé par la magnitude du plus grand
!>          élément de X(j).  L'estimation est aussi fiable que
!>          l'estimation de RCOND, et est presque toujours une légère
!>          surestimation de l'erreur réelle.
!>

BERR

!>          BERR est un tableau DOUBLE PRECISION, dimension (NRHS)
!>          L'erreur arrière relative composante par composante de chaque vecteur
!>          solution X(j) (c'est-à-dire le plus petit changement relatif dans
!>          n'importe quel élément de A ou B qui fait de X(j) une solution exacte).
!>

WORK

!>          WORK est un tableau DOUBLE PRECISION, dimension (3*N)
!>

IWORK

!>          IWORK est un tableau INTEGER, dimension (N)
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>

Paramètres internes :

!>  ITMAX est le nombre maximum d'étapes de raffinement itératif.
!>
