double précision fonction dget06 (double précision rcond, double précision rcondc)

DGET06

Objectif :

!>
!> DGET06 calcule un rapport de test pour comparer deux valeurs de RCOND.
!>

Paramètres

RCOND 
!>          RCOND est de type DOUBLE PRECISION
!>          L'estimation de l'inverse du nombre de condition de A,
!>          calculée par DGECON.
!>

RCONDC

!>          RCONDC est de type DOUBLE PRECISION
!>          L'inverse du nombre de condition de A, calculé comme
!>          ( 1/norm(A) ) / norm(inv(A)).
!>
