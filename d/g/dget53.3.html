sous-routine dget53 (double précision, dimension( lda, * ) a, integer lda, double précision, dimension( ldb, * ) b, integer ldb, double précision scale, double précision wr, double précision wi, double précision result, integer info)

DGET53

Objectif :

!>
!> DGET53  vérifie les valeurs propres généralisées calculées par DLAG2.
!>
!> Le test de base pour une valeur propre est :
!>
!>                              | det( s A - w B ) |
!>     RESULTAT =  ---------------------------------------------------
!>               ulp max( s norm(A), |w| norm(B) )*norm( s A - w B )
!>
!> Deux  sont effectués :
!>
!> (1)  ulp*max( s*norm(A), |w|*norm(B) )  doit être au moins
!>      safe_minimum.  Ceci assure que le test effectué n'est pas
!>      essentiellement  det(0*A + 0*B)=0.
!>
!> (2)  s*norm(A) + |w|*norm(B) doit être inférieur à 1/safe_minimum.
!>      Ceci assure que  s*A - w*B  ne débordera pas.
!>
!> Si ces tests ne sont pas réussis, alors  s  et  w  sont mis à l'échelle et
!> testés quand même, si cela est possible.
!>

Paramètres

A 
!>          A est un tableau DOUBLE PRECISION, dimension (LDA, 2)
!>          La matrice 2x2 A.
!>

LDA

!>          LDA est un entier
!>          La dimension principale de A. Elle doit être au moins 2.
!>

B

!>          B est un tableau DOUBLE PRECISION, dimension (LDB, N)
!>          La matrice triangulaire supérieure 2x2 B.
!>

LDB

!>          LDB est un entier
!>          La dimension principale de B. Elle doit être au moins 2.
!>

SCALE

!>          SCALE est DOUBLE PRECISION
!>          Le  s dans la formule  s A - w B .  Il est
!>          supposé être non négatif.
!>

WR

!>          WR est DOUBLE PRECISION
!>          La partie réelle de la valeur propre  w  dans la formule
!>          s A - w B .
!>

WI

!>          WI est DOUBLE PRECISION
!>          La partie imaginaire de la valeur propre  w  dans la formule
!>          s A - w B .
!>

RESULT

!>          RESULT est DOUBLE PRECISION
!>          Si INFO est 2 ou moins, la valeur calculée par le test
!>             décrit ci-dessus.
!>          Si INFO=3, ceci sera juste 1/ulp.
!>

INFO

!>          INFO est un entier
!>          =0 : Les données d'entrée réussissent les .
!>          =1 : s*norm(A) + |w|*norm(B) > 1/safe_minimum.
!>          =2 : ulp*max( s*norm(A), |w|*norm(B) ) < safe_minimum
!>          =3 : Idem que INFO=2, mais  s  et  w  n'ont pas pu être mis à l'échelle
!>               pour calculer le test.
!>
