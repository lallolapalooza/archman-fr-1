Documentation de la fonction/sous-programme

sous-routine dget51 (entier itype, entier n, double précision, dimension( lda, * ) a, entier lda, double précision, dimension( ldb, * ) b, entier ldb, double précision, dimension( ldu, * ) u, entier ldu, double précision, dimension( ldv, * ) v, entier ldv, double précision, dimension( * ) work, double précision result)

DGET51

Objectif :

!>
!>      DGET51  vérifie généralement une décomposition de la forme
!>
!>              A = U B V'
!>
!>      où ' signifie transposée et U et V sont orthogonales.
!>
!>      Spécifiquement, si ITYPE=1
!>
!>              RESULT = | A - U B V' | / ( |A| n ulp )
!>
!>      Si ITYPE=2, alors :
!>
!>              RESULT = | A - B | / ( |A| n ulp )
!>
!>      Si ITYPE=3, alors :
!>
!>              RESULT = | I - UU' | / ( n ulp )
!>

Paramètres

ITYPE 
!>          ITYPE est un ENTIER
!>          Spécifie le type de tests à effectuer.
!>          =1: RESULT = | A - U B V' | / ( |A| n ulp )
!>          =2: RESULT = | A - B | / ( |A| n ulp )
!>          =3: RESULT = | I - UU' | / ( n ulp )
!>

N

!>          N est un ENTIER
!>          La taille de la matrice. Si elle est nulle, DGET51 ne fait rien.
!>          Il doit être supérieur ou égal à zéro.
!>

A

!>          A est un tableau DOUBLE PRÉCISION, dimension (LDA, N)
!>          La matrice originale (non factorisée).
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale de A. Elle doit être supérieure ou égale à 1
!>          et supérieure ou égale à N.
!>

B

!>          B est un tableau DOUBLE PRÉCISION, dimension (LDB, N)
!>          La matrice factorisée.
!>

LDB

!>          LDB est un ENTIER
!>          La dimension principale de B. Elle doit être supérieure ou égale à 1
!>          et supérieure ou égale à N.
!>

U

!>          U est un tableau DOUBLE PRÉCISION, dimension (LDU, N)
!>          La matrice orthogonale du côté gauche dans la
!>          décomposition.
!>          Non référencée si ITYPE=2
!>

LDU

!>          LDU est un ENTIER
!>          La dimension principale de U. LDU doit être supérieur ou égal à N et
!>          supérieur ou égal à 1.
!>

V

!>          V est un tableau DOUBLE PRÉCISION, dimension (LDV, N)
!>          La matrice orthogonale du côté gauche dans la
!>          décomposition.
!>          Non référencée si ITYPE=2
!>

LDV

!>          LDV est un ENTIER
!>          La dimension principale de V. LDV doit être supérieur ou égal à N et
!>          supérieur ou égal à 1.
!>

WORK

!>          WORK est un tableau DOUBLE PRÉCISION, dimension (2*N**2)
!>

RESULT

!>          RESULT est un DOUBLE PRÉCISION
!>          Les valeurs calculées par le test spécifié par ITYPE. La
!>          valeur est actuellement limitée à 1/ulp, pour éviter le débordement.
!>          Les erreurs sont signalées par RESULT=10/ulp.
!>
