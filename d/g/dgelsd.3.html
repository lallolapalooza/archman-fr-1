Documentation de la fonction/sous-routine

sous-routine dgelsd (integer m, integer n, integer nrhs, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( ldb, * ) b, integer ldb, double precision, dimension( * ) s, double precision rcond, integer rank, double precision, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, integer info)

DGELSD calcule la solution de norme minimale pour un problème de moindres carrés linéaires pour les matrices GE

Objectif :

!>
!> DGELSD calcule la solution de norme minimale d'un problème linéaire réel
!> de moindres carrés :
!>     minimiser la norme 2 de | b - A*x |
!> en utilisant la décomposition en valeurs singulières (SVD) de A. A est une
!> matrice M par N qui peut être de rang défectueux.
!>
!> Plusieurs vecteurs second membre b et vecteurs solution x peuvent être
!> gérés en un seul appel ; ils sont stockés comme colonnes de la matrice
!> second membre B de taille M par NRHS et de la matrice solution X de taille
!> N par NRHS.
!>
!> Le problème est résolu en trois étapes :
!> (1) Réduire la matrice de coefficients A à une forme bidiagonale avec
!>     des transformations de Householder, réduisant le problème original
!>     à un (BLS)
!> (2) Résoudre le BLS en utilisant une approche de type "diviser pour régner".
!> (3) Appliquer toutes les transformations de Householder en retour pour résoudre
!>     le problème original de moindres carrés.
!>
!> Le rang effectif de A est déterminé en traitant comme nulles les valeurs
!> singulières inférieures à RCOND multiplié par la plus grande valeur
!> singulière.
!>
!>

Paramètres

M 
!>          M est INTEGER
!>          Le nombre de lignes de A. M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de A. N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de seconds membres, c'est-à-dire le nombre de colonnes
!>          des matrices B et X. NRHS >= 0.
!>

A

!>          A est un tableau DOUBLE PRECISION, dimension (LDA,N)
!>          À l'entrée, la matrice A de taille M par N.
!>          À la sortie, A est détruite.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,M).
!>

B

!>          B est un tableau DOUBLE PRECISION, dimension (LDB,NRHS)
!>          À l'entrée, la matrice second membre B de taille M par NRHS.
!>          À la sortie, B est écrasée par la matrice solution X de taille
!>          N par NRHS. Si m >= n et RANK = n, la somme des carrés des résidus
!>          pour la solution dans la i-ème colonne est donnée par la somme des
!>          carrés des éléments n+1:m de cette colonne.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B. LDB >= max(1,max(M,N)).
!>

S

!>          S est un tableau DOUBLE PRECISION, dimension (min(M,N))
!>          Les valeurs singulières de A en ordre décroissant.
!>          Le nombre de conditionnement de A dans la norme 2 = S(1)/S(min(m,n)).
!>

RCOND

!>          RCOND est DOUBLE PRECISION
!>          RCOND est utilisé pour déterminer le rang effectif de A.
!>          Les valeurs singulières S(i) <= RCOND*S(1) sont traitées comme nulles.
!>          Si RCOND < 0, la précision machine est utilisée à la place.
!>

RANK

!>          RANK est INTEGER
!>          Le rang effectif de A, c'est-à-dire le nombre de valeurs singulières
!>          supérieures à RCOND*S(1).
!>

WORK

!>          WORK est un tableau DOUBLE PRECISION, dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) contient la taille optimale de LWORK.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK. LWORK doit être au moins 1.
!>          La quantité exacte de mémoire de travail nécessaire dépend de M,
!>          N et NRHS. Tant que LWORK est au moins
!>              12*N + 2*N*SMLSIZ + 8*N*NLVL + N*NRHS + (SMLSIZ+1)**2,
!>          si M est supérieur ou égal à N, ou
!>              12*M + 2*M*SMLSIZ + 8*M*NLVL + M*NRHS + (SMLSIZ+1)**2,
!>          si M est inférieur à N, le code s'exécutera correctement.
!>          SMLSIZ est renvoyé par ILAENV et est égal à la taille maximale
!>          des sous-problèmes au bas de l'arbre de calcul (généralement environ 25),
!>          et
!>             NLVL = MAX( 0, INT( LOG_2( MIN( M,N )/(SMLSIZ+1) ) ) + 1 )
!>          Pour de bonnes performances, LWORK devrait généralement être plus grand.
!>
!>          Si LWORK = -1, alors une requête de mémoire de travail est supposée ; la routine
!>          calcule uniquement la taille optimale du tableau WORK, renvoie
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          relatif à LWORK n'est émis par XERBLA.
!>

IWORK

!>          IWORK est un tableau INTEGER, dimension (MAX(1,LIWORK))
!>          LIWORK >= max(1, 3 * MINMN * NLVL + 11 * MINMN),
!>          où MINMN = MIN( M,N ).
!>          À la sortie, si INFO = 0, IWORK(1) contient la taille minimale de LIWORK.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.
!>          > 0 : l'algorithme de calcul de la SVD n'a pas convergé ;
!>                si INFO = i, i éléments hors diagonale d'une forme bidiagonale intermédiaire
!>                n'ont pas convergé vers zéro.
!>
