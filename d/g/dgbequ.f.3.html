Documentation de la fonction/sous-programme

sous-programme dgbequ (integer m, integer n, integer kl, integer ku, double precision, dimension( ldab, * ) ab, integer ldab, double precision, dimension( * ) r, double precision, dimension( * ) c, double precision rowcnd, double precision colcnd, double precision amax, integer info)

DGBEQU

Objectif :

!>
!> DGBEQU calcule les facteurs d'échelle des lignes et des colonnes destinés à équilibrer
!> une matrice bande M par N, A, et à réduire son nombre de conditionnement. R
!> renvoie les facteurs d'échelle des lignes et C ceux des colonnes, choisis pour
!> essayer de rendre la valeur absolue du plus grand élément de chaque ligne et
!> colonne de la matrice B, avec des éléments B(i,j)=R(i)*A(i,j)*C(j), égale à 1.
!>
!> R(i) et C(j) sont limités entre SMLNUM = plus petit nombre sûr
!> et BIGNUM = plus grand nombre sûr. L'utilisation de ces facteurs d'échelle ne
!> garantit pas de réduire le nombre de conditionnement de A, mais fonctionne bien en pratique.
!>

Paramètres

M 
!>          M est un entier (INTEGER)
!>          Le nombre de lignes de la matrice A. M >= 0.
!>

N

!>          N est un entier (INTEGER)
!>          Le nombre de colonnes de la matrice A. N >= 0.
!>

KL

!>          KL est un entier (INTEGER)
!>          Le nombre de sous-diagonales dans la bande de A. KL >= 0.
!>

KU

!>          KU est un entier (INTEGER)
!>          Le nombre de super-diagonales dans la bande de A. KU >= 0.
!>

AB

!>          AB est un tableau de type DOUBLE PRECISION, de dimension (LDAB,N)
!>          La matrice bande A, stockée dans les lignes 1 à KL+KU+1. La j-ème
!>          colonne de A est stockée dans la j-ème colonne du tableau AB comme suit :
!>          AB(ku+1+i-j,j) = A(i,j) pour max(1,j-ku) <= i <= min(m,j+kl).
!>

LDAB

!>          LDAB est un entier (INTEGER)
!>          La dimension principale du tableau AB. LDAB >= KL+KU+1.
!>

R

!>          R est un tableau de type DOUBLE PRECISION, de dimension (M)
!>          Si INFO = 0, ou INFO > M, R contient les facteurs d'échelle des lignes
!>          pour A.
!>

C

!>          C est un tableau de type DOUBLE PRECISION, de dimension (N)
!>          Si INFO = 0, C contient les facteurs d'échelle des colonnes pour A.
!>

ROWCND

!>          ROWCND est un nombre en DOUBLE PRECISION
!>          Si INFO = 0 ou INFO > M, ROWCND contient le rapport du plus petit R(i)
!>          au plus grand R(i). Si ROWCND >= 0.1 et AMAX n'est ni trop grand ni
!>          trop petit, il n'est pas utile de mettre à l'échelle par R.
!>

COLCND

!>          COLCND est un nombre en DOUBLE PRECISION
!>          Si INFO = 0, COLCND contient le rapport du plus petit C(i) au plus grand C(i).
!>          Si COLCND >= 0.1, il n'est pas utile de mettre à l'échelle par C.
!>

AMAX

!>          AMAX est un nombre en DOUBLE PRECISION
!>          Valeur absolue du plus grand élément de la matrice. Si AMAX est très
!>          proche du débordement ou très proche de la sous-estimation, la matrice
!>          devrait être mise à l'échelle.
!>

INFO

!>          INFO est un entier (INTEGER)
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : si INFO = i, et i est
!>                <= M : la i-ème ligne de A est exactement zéro
!>                >  M : la (i-M)-ème colonne de A est exactement zéro
!>
