Documentation de la fonction/sous-programme

sous-programme dgeequ (entier m, entier n, double précision, dimension( lda, * ) a, entier lda, double précision, dimension( * ) r, double précision, dimension( * ) c, double précision rowcnd, double précision colcnd, double précision amax, entier info)

DGEEQU

But :

!>
!> DGEEQU calcule les échelles de lignes et de colonnes destinées à équilibrer une
!> matrice A de taille M par N et à réduire son nombre de conditionnement. R renvoie les facteurs d'échelle de ligne
!> et C les facteurs d'échelle de colonne, choisis pour tenter de faire
!> que l'élément de plus grande valeur absolue dans chaque ligne et colonne de la matrice B, avec
!> éléments B(i,j)=R(i)*A(i,j)*C(j), ait une valeur absolue de 1.
!>
!> R(i) et C(j) sont restreints entre SMLNUM = le plus petit nombre sûr
!> et BIGNUM = le plus grand nombre sûr. L'utilisation de ces facteurs d'échelle n'est pas garantie
!> de réduire le nombre de conditionnement de A, mais
!> fonctionne bien en pratique.
!>

Paramètres

M 
!>          M est un ENTIER
!>          Le nombre de lignes de la matrice A. M >= 0.
!>

N

!>          N est un ENTIER
!>          Le nombre de colonnes de la matrice A. N >= 0.
!>

A

!>          A est un tableau de DOUBLE PRÉCISION, dimension (LDA,N)
!>          La matrice M par N dont les facteurs d'équilibrage doivent être
!>          calculés.
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale du tableau A. LDA >= max(1,M).
!>

R

!>          R est un tableau de DOUBLE PRÉCISION, dimension (M)
!>          Si INFO = 0 ou INFO > M, R contient les facteurs d'échelle de ligne
!>          pour A.
!>

C

!>          C est un tableau de DOUBLE PRÉCISION, dimension (N)
!>          Si INFO = 0, C contient les facteurs d'échelle de colonne pour A.
!>

ROWCND

!>          ROWCND est de type DOUBLE PRÉCISION
!>          Si INFO = 0 ou INFO > M, ROWCND contient le rapport entre le
!>          plus petit R(i) et le plus grand R(i). Si ROWCND >= 0.1 et
!>          AMAX n'est ni trop grand ni trop petit, il n'est pas utile
!>          de mettre à l'échelle par R.
!>

COLCND

!>          COLCND est de type DOUBLE PRÉCISION
!>          Si INFO = 0, COLCND contient le rapport entre le plus petit
!>          C(i) et le plus grand C(i). Si COLCND >= 0.1, il n'est pas
!>          utile de mettre à l'échelle par C.
!>

AMAX

!>          AMAX est de type DOUBLE PRÉCISION
!>          La valeur absolue de l'élément de matrice le plus grand. Si AMAX est très
!>          proche du débordement ou de la sous-dépassement, la matrice
!>          doit être mise à l'échelle.
!>

INFO

!>          INFO est un ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : si INFO = i, et i est
!>                <= M : la i-ème ligne de A est exactement zéro
!>                >  M : la (i-M)-ème colonne de A est exactement zéro
!>
