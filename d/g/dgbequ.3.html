Documentation de fonction/sous routine

subroutine dgbequ (integer m, integer n, integer kl, integer ku, double precision, dimension( ldab, * ) ab, integer ldab, double precision, dimension( * ) r, double precision, dimension( * ) c, double precision rowcnd, double precision colcnd, double precision amax, integer info)

DGBEQU

Objectif :

!>
!> DGBEQU calcule les échelles de lignes et de colonnes destinées à équilibrer une
!> matrice bande M par N, A, et à réduire son nombre de conditionnement. R renvoie les
!> facteurs d'échelle de ligne et C les facteurs d'échelle de colonne, choisis pour essayer de
!> faire en sorte que l'élément de plus grande valeur absolue dans chaque ligne et colonne de la matrice B,
!> avec les éléments B(i,j)=R(i)*A(i,j)*C(j), ait une valeur absolue de 1.
!>
!> R(i) et C(j) sont restreints à être entre SMLNUM = plus petit nombre sûr
!> et BIGNUM = plus grand nombre sûr. L'utilisation de ces facteurs d'échelle ne garantit pas
!> la réduction du nombre de conditionnement de A, mais fonctionne bien en pratique.
!>

Paramètres

M 
!>          M est un INTEGER
!>          Le nombre de lignes de la matrice A. M >= 0.
!>

N

!>          N est un INTEGER
!>          Le nombre de colonnes de la matrice A. N >= 0.
!>

KL

!>          KL est un INTEGER
!>          Le nombre de sous-diagonales dans la bande de A. KL >= 0.
!>

KU

!>          KU est un INTEGER
!>          Le nombre de super-diagonales dans la bande de A. KU >= 0.
!>

AB

!>          AB est un tableau DOUBLE PRECISION, de dimension (LDAB,N)
!>          La matrice bande A, stockée dans les lignes 1 à KL+KU+1. La j-ième
!>          colonne de A est stockée dans la j-ième colonne du tableau AB comme suit :
!>          AB(ku+1+i-j,j) = A(i,j) pour max(1,j-ku)<=i<=min(m,j+kl).
!>

LDAB

!>          LDAB est un INTEGER
!>          La dimension principale du tableau AB. LDAB >= KL+KU+1.
!>

R

!>          R est un tableau DOUBLE PRECISION, de dimension (M)
!>          Si INFO = 0, ou INFO > M, R contient les facteurs d'échelle de ligne
!>          pour A.
!>

C

!>          C est un tableau DOUBLE PRECISION, de dimension (N)
!>          Si INFO = 0, C contient les facteurs d'échelle de colonne pour A.
!>

ROWCND

!>          ROWCND est un DOUBLE PRECISION
!>          Si INFO = 0 ou INFO > M, ROWCND contient le rapport entre le plus petit
!>          R(i) et le plus grand R(i). Si ROWCND >= 0.1 et
!>          AMAX n'est ni trop grand ni trop petit, il ne vaut pas la peine
!>          de mettre à l'échelle avec R.
!>

COLCND

!>          COLCND est un DOUBLE PRECISION
!>          Si INFO = 0, COLCND contient le rapport entre le plus petit
!>          C(i) et le plus grand C(i). Si COLCND >= 0.1, il ne vaut pas la peine
!>          de mettre à l'échelle avec C.
!>

AMAX

!>          AMAX est un DOUBLE PRECISION
!>          Valeur absolue de l'élément de matrice le plus grand. Si AMAX est très
!>          proche du dépassement ou très proche de la sous-évaluation, la matrice
!>          devrait être mise à l'échelle.
!>

INFO

!>          INFO est un INTEGER
!>          = 0 : succès de l'exécution
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : si INFO = i, et i est
!>                <= M : la i-ème ligne de A est exactement nulle
!>                >  M : la (i-M)-ème colonne de A est exactement nulle
!>
