Documentation de la fonction/de la sous-routine

sous-routine dgesdd (character jobz, integer m, integer n, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( * ) s, double precision, dimension( ldu, * ) u, integer ldu, double precision, dimension( ldvt, * ) vt, integer ldvt, double precision, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, integer info)

DGESDD

But :

!>
!> DGESDD calcule la décomposition en valeurs singulières (SVD) d'une
!> matrice réelle A de dimensions M par N, calculant éventuellement les
!> vecteurs singuliers gauche et droit. Si des vecteurs singuliers sont
!> souhaités, un algorithme de type diviser pour mieux régner est utilisé.
!>
!> La SVD est écrite
!>
!>      A = U * SIGMA * transpose(V)
!>
!> où SIGMA est une matrice de dimensions M par N qui est nulle sauf
!> pour ses min(m,n) éléments diagonaux, U est une matrice orthogonale
!> de dimensions M par M, et V est une matrice orthogonale de dimensions
!> N par N. Les éléments diagonaux de SIGMA sont les valeurs singulières
!> de A ; elles sont réelles et non négatives, et sont renvoyées par
!> ordre décroissant. Les premières min(m,n) colonnes de U et V sont
!> les vecteurs singuliers gauche et droit de A.
!>
!> Notez que la routine renvoie VT = V**T, et non V.
!>
!>

Paramètres

JOBZ 
!>          JOBZ est CHARACTER*1
!>          Spécifie les options pour le calcul de toute ou partie de la matrice U :
!>          = 'A' :  toutes les M colonnes de U et toutes les N lignes de V**T sont
!>                  renvoyées dans les tableaux U et VT ;
!>          = 'S' :  les premières min(M,N) colonnes de U et les premières
!>                  min(M,N) lignes de V**T sont renvoyées dans les tableaux U
!>                  et VT ;
!>          = 'O' :  Si M >= N, les N premières colonnes de U écrasent
!>                  le tableau A et toutes les lignes de V**T sont renvoyées dans
!>                  le tableau VT ;
!>                  sinon, toutes les colonnes de U sont renvoyées dans le
!>                  tableau U et les M premières lignes de V**T écrasent
!>                  le tableau A ;
!>          = 'N' :  aucune colonne de U ni ligne de V**T n'est calculée.
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice d'entrée A. M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice d'entrée A. N >= 0.
!>

A

!>          A est un tableau DOUBLE PRECISION, dimension (LDA,N)
!>          À l'entrée, la matrice A de dimensions M par N.
!>          À la sortie,
!>          si JOBZ = 'O',  A est écrasée par les N premières colonnes
!>                          de U (les vecteurs singuliers gauche, stockés
!>                          par colonnes) si M >= N ;
!>                          A est écrasée par les M premières lignes
!>                          de V**T (les vecteurs singuliers droit, stockés
!>                          par lignes) sinon.
!>          si JOBZ .ne. 'O', le contenu de A est détruit.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,M).
!>

S

!>          S est un tableau DOUBLE PRECISION, dimension (min(M,N))
!>          Les valeurs singulières de A, triées de sorte que S(i) >= S(i+1).
!>

U

!>          U est un tableau DOUBLE PRECISION, dimension (LDU,UCOL)
!>          UCOL = M si JOBZ = 'A' ou JOBZ = 'O' et M < N ;
!>          UCOL = min(M,N) si JOBZ = 'S'.
!>          Si JOBZ = 'A' ou JOBZ = 'O' et M < N, U contient la matrice
!>          orthogonale U de dimensions M par M ;
!>          si JOBZ = 'S', U contient les premières min(M,N) colonnes de U
!>          (les vecteurs singuliers gauche, stockés par colonnes) ;
!>          si JOBZ = 'O' et M >= N, ou JOBZ = 'N', U n'est pas référencée.
!>

LDU

!>          LDU est INTEGER
!>          La dimension principale du tableau U. LDU >= 1 ; si
!>          JOBZ = 'S' ou 'A' ou JOBZ = 'O' et M < N, LDU >= M.
!>

VT

!>          VT est un tableau DOUBLE PRECISION, dimension (LDVT,N)
!>          Si JOBZ = 'A' ou JOBZ = 'O' et M >= N, VT contient la
!>          matrice orthogonale V**T de dimensions N par N ;
!>          si JOBZ = 'S', VT contient les premières min(M,N) lignes de
!>          V**T (les vecteurs singuliers droit, stockés par lignes) ;
!>          si JOBZ = 'O' et M < N, ou JOBZ = 'N', VT n'est pas référencée.
!>

LDVT

!>          LDVT est INTEGER
!>          La dimension principale du tableau VT. LDVT >= 1 ;
!>          si JOBZ = 'A' ou JOBZ = 'O' et M >= N, LDVT >= N ;
!>          si JOBZ = 'S', LDVT >= min(M,N).
!>

WORK

!>          WORK est un tableau DOUBLE PRECISION, dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) renvoie la valeur optimale de LWORK ;
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK. LWORK >= 1.
!>          Si LWORK = -1, une interrogation de l'espace de travail est supposée.
!>          La taille optimale du tableau WORK est calculée et stockée dans WORK(1),
!>          et aucun autre travail n'est effectué en dehors de la vérification des
!>          arguments.
!>
!>          Soit mx = max(M,N) et mn = min(M,N).
!>          Si JOBZ = 'N', LWORK >= 3*mn + max( mx, 7*mn ).
!>          Si JOBZ = 'O', LWORK >= 3*mn + max( mx, 5*mn*mn + 4*mn ).
!>          Si JOBZ = 'S', LWORK >= 4*mn*mn + 7*mn.
!>          Si JOBZ = 'A', LWORK >= 4*mn*mn + 6*mn + mx.
!>          Ce ne sont pas des minima stricts dans tous les cas ; voir les commentaires
!>          dans le code.
!>          Pour de bonnes performances, LWORK devrait généralement être plus grand ;
!>          une interrogation est recommandée.
!>

IWORK

!>          IWORK est un tableau INTEGER, dimension (8*min(M,N))
!>

INFO

!>          INFO est INTEGER
!>          <  0 :  si INFO = -i, le i-ème argument avait une valeur illégale.
!>          = -4 :  si A contenait une entrée NAN.
!>          >  0 :  DBDSDC n'a pas convergé, le processus de mise à jour a échoué.
!>          =  0 :  sortie réussie.
!>
