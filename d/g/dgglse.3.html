Documentation de la fonction/sous-routine

subroutine dgglse (integer m, integer n, integer p, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( ldb, * ) b, integer ldb, double precision, dimension( * ) c, double precision, dimension( * ) d, double precision, dimension( * ) x, double precision, dimension( * ) work, integer lwork, integer info)

DGGLSE résout des systèmes surdéterminés ou sousdéterminés pour les matrices OTHER

But :

!>
!> DGGLSE résout le problème des moindres carrés avec contraintes
!> d'égalité linéaires (LSE) :
!>
!>         minimiser || c - A*x ||_2   sous la contrainte   B*x = d
!>
!> où A est une matrice M×N, B est une matrice P×N, c est un vecteur
!> M donné, et d est un vecteur P donné. On suppose que
!> P <= N <= M+P, et
!>
!>          rang(B) = P et  rang( (A) ) = N.
!>                            ( (B) )
!>
!> Ces conditions garantissent que le problème LSE a une solution
!> unique, qui est obtenue à l'aide d'une factorisation RQ
!> généralisée des matrices (B, A) donnée par
!>
!>    B = (0 R)*Q,   A = Z*T*Q.
!>
!> Les appelants de cette sous-routine doivent noter que les
!> vérifications de singularité/défaut de rang implémentées dans
!> cette sous-routine sont rudimentaires. La sous-routine DTRTRS
!> appelée par cette sous-routine ne signale un échec dû à la
!> singularité que si le problème est exactement singulier.
!>
!> Il est concevable qu'un (ou plusieurs) des facteurs impliqués
!> dans la factorisation RQ généralisée de la paire (B, A) soit
!> proche de la singularité de manière subnormale sans que cette
!> sous-routine ne signale d'erreur. Les solutions calculées pour
!> de tels problèmes presque de défaut de rang peuvent être moins
!> précises en raison d'une perte de précision numérique.
!> 
!>

Paramètres

M 
!>          M est INTEGER
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes des matrices A et B. N >= 0.
!>

P

!>          P est INTEGER
!>          Le nombre de lignes de la matrice B. 0 <= P <= N <= M+P.
!>

A

!>          A est un tableau DOUBLE PRECISION, dimension (LDA,N)
!>          À l'entrée, la matrice A de taille M×N.
!>          À la sortie, les éléments sur et au-dessus de la diagonale
!>          du tableau contiennent la matrice trapézoïdale supérieure T
!>          de taille min(M,N)×N.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,M).
!>

B

!>          B est un tableau DOUBLE PRECISION, dimension (LDB,N)
!>          À l'entrée, la matrice B de taille P×N.
!>          À la sortie, le triangle supérieur du sous-tableau
!>          B(1:P,N-P+1:N) contient la matrice triangulaire supérieure R
!>          de taille P×P.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B. LDB >= max(1,P).
!>

C

!>          C est un tableau DOUBLE PRECISION, dimension (M)
!>          À l'entrée, C contient le vecteur du second membre pour la
!>          partie moindres carrés du problème LSE.
!>          À la sortie, la somme des carrés des résidus pour la
!>          solution est donnée par la somme des carrés des éléments
!>          N-P+1 à M du vecteur C.
!>

D

!>          D est un tableau DOUBLE PRECISION, dimension (P)
!>          À l'entrée, D contient le vecteur du second membre pour
!>          l'équation contrainte.
!>          À la sortie, D est détruit.
!>

X

!>          X est un tableau DOUBLE PRECISION, dimension (N)
!>          À la sortie, X est la solution du problème LSE.
!>

WORK

!>          WORK est un tableau DOUBLE PRECISION, dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) renvoie le LWORK optimal.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK. LWORK >= max(1,M+N+P).
!>          Pour des performances optimales, LWORK >= P+min(M,N)+max(M,N)*NB,
!>          où NB est une borne supérieure pour les tailles de blocs
!>          optimales de DGEQRF, SGERQF, DORMQR et SORMRQ.
!>
!>          Si LWORK = -1, une interrogation d'espace de travail est
!>          supposée ; la routine calcule uniquement la taille
!>          optimale du tableau WORK, renvoie cette valeur comme
!>          première entrée du tableau WORK, et aucun message d'erreur
!>          lié à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est INTEGER
!>          = 0 :  sortie réussie.
!>          < 0 :  si INFO = -i, le i-ème argument avait une valeur
!>                illégale.
!>          = 1 :  le facteur triangulaire supérieur R associé à B dans
!>                la factorisation RQ généralisée de la paire (B, A) est
!>                exactement singulier, de sorte que rang(B) < P ; la
!>                solution des moindres carrés n'a pas pu être calculée.
!>          = 2 :  la partie (N-P) × (N-P) du facteur trapézoïdal
!>                supérieur T associé à A dans la factorisation RQ
!>                généralisée de la paire (B, A) est exactement
!>                singulière, de sorte que rang( (A) ) < N ; la
!>                    ( (B) )
!>                solution des moindres carrés n'a pas pu être calculée.
!>
