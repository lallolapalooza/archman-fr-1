Documentation de la fonction/sous-programme

subroutine dgemqr (character side, character trans, integer m, integer n, integer k, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( * ) t, integer tsize, double precision, dimension( ldc, * ) c, integer ldc, double precision, dimension( * ) work, integer lwork, integer info)

DGEMQR

But :

!>
!> DGEMQR écrase la matrice réelle M par N, C, avec
!>
!>                      SIDE = 'L'     SIDE = 'R'
!>      TRANS = 'N':      Q * C          C * Q
!>      TRANS = 'T':      Q**T * C       C * Q**T
!>
!> où Q est une matrice orthogonale réelle définie comme le produit
!> de réflecteurs élémentaires calculés par la factorisation QR en blocs
!> maigre (DGEQR)
!>
!>

Paramètres

SIDE 
!>          SIDE est CHARACTER*1
!>          = 'L' : appliquer Q ou Q**T à gauche ;
!>          = 'R' : appliquer Q ou Q**T à droite.
!>

TRANS

!>          TRANS est CHARACTER*1
!>          = 'N' : Pas de transposée, appliquer Q ;
!>          = 'T' : Transposée, appliquer Q**T.
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice A. M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice C. N >= 0.
!>

K

!>          K est INTEGER
!>          Le nombre de réflecteurs élémentaires dont le produit définit
!>          la matrice Q.
!>          Si SIDE = 'L', M >= K >= 0 ;
!>          si SIDE = 'R', N >= K >= 0.
!>

A

!>          A est un tableau DOUBLE PRECISION, de dimension (LDA,K)
!>          Partie de la structure de données représentant Q telle que retournée par DGEQR.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.
!>          Si SIDE = 'L', LDA >= max(1,M) ;
!>          si SIDE = 'R', LDA >= max(1,N).
!>

T

!>          T est un tableau DOUBLE PRECISION, de dimension (MAX(5,TSIZE)).
!>          Partie de la structure de données représentant Q telle que retournée par DGEQR.
!>

TSIZE

!>          TSIZE est INTEGER
!>          La dimension du tableau T. TSIZE >= 5.
!>

C

!>          C est un tableau DOUBLE PRECISION, de dimension (LDC,N)
!>          À l'entrée, la matrice M par N, C.
!>          À la sortie, C est écrasée par Q*C ou Q**T*C ou C*Q**T ou C*Q.
!>

LDC

!>          LDC est INTEGER
!>          La dimension principale du tableau C. LDC >= max(1,M).
!>

WORK

!>          (espace de travail) Tableau DOUBLE PRECISION, de dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) contient le LWORK minimal.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK. LWORK >= 1.
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée. La routine
!>          calcule seulement la taille du tableau WORK, retourne cette
!>          valeur dans WORK(1), et aucun message d'erreur concernant WORK
!>          n'est émis par XERBLA.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>
