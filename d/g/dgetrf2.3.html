sous-programme récursif dgetrf2 (integer m, integer n, double precision, dimension( lda, * ) a, integer lda, integer, dimension( * ) ipiv, integer info)

DGETRF2

Objectif:

!>
!> DGETRF2 calcule une factorisation LU d'une matrice M-par-N générale A
!> en utilisant le pivotement partiel avec échanges de lignes.
!>
!> La factorisation a la forme
!>    A = P * L * U
!> où P est une matrice de permutation, L est triangulaire inférieure avec des éléments diagonaux unitaires
!> (trapézoïdale inférieure si m > n), et U est triangulaire supérieure
!> (trapézoïdale supérieure si m < n).
!>
!> C'est la version récursive de l'algorithme. Elle divise
!> la matrice en quatre sous-matrices :
!>
!>        [  A11 | A12  ]  où A11 est n1 par n1 et A22 est n2 par n2
!>    A = [ -----|----- ]  avec n1 = min(m,n)/2
!>        [  A21 | A22  ]       n2 = n-n1
!>
!>                                       [ A11 ]
!> Le sous-programme s'appelle lui-même pour factoriser [ --- ],
!>                                       [ A12 ]
!>                 [ A12 ]
!> effectue les échanges sur [ --- ], résout A12, met à jour A22,
!>                 [ A22 ]
!>
!> puis s'appelle lui-même pour factoriser A22 et effectuer les échanges sur A21.
!>
!>

Paramètres

M 
!>          M est INTEGER
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice A.  N >= 0.
!>

A

!>          A est un tableau DOUBLE PRECISION, dimension (LDA,N)
!>          À l'entrée, la matrice M-par-N à factoriser.
!>          À la sortie, les facteurs L et U de la factorisation
!>          A = P*L*U ; les éléments diagonaux unitaires de L ne sont pas stockés.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,M).
!>

IPIV

!>          IPIV est un tableau INTEGER, dimension (min(M,N))
!>          Les indices de pivot ; pour 1 <= i <= min(M,N), la ligne i de la
!>          matrice a été échangée avec la ligne IPIV(i).
!>

INFO

!>          INFO est INTEGER
!>          = 0:  sortie réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0:  si INFO = i, U(i,i) est exactement zéro. La factorisation
!>                a été complétée, mais le facteur U est exactement
!>                singulier, et une division par zéro se produira si il est utilisé
!>                pour résoudre un système d'équations.
!>
