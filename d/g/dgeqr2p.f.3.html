subroutine dgeqr2p (integer m, integer n, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( * ) tau, double precision, dimension( * ) work, integer info)

DGEQR2P calcule la factorisation QR d'une matrice rectangulaire générale avec des éléments diagonaux non négatifs en utilisant un algorithme non bloqué.

Objectif:

!>
!> DGEQR2P calcule une factorisation QR d'une matrice réelle m-par-n A:
!>
!>    A = Q * ( R ),
!>            ( 0 )
!>
!> où :
!>
!>    Q est une matrice orthogonale m-par-m ;
!>    R est une matrice triangulaire supérieure n-par-n avec des entrées diagonales non négatives ;
!>    0 est une matrice nulle (m-n)-par-n, si m > n.
!>
!>

Paramètres

M 
!>          M est INTEGER
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice A.  N >= 0.
!>

A

!>          A est un tableau DOUBLE PRECISION, dimension (LDA,N)
!>          En entrée, la matrice A m par n.
!>          En sortie, les éléments sur et au-dessus de la diagonale du tableau
!>          contiennent la matrice trapézoïdale supérieure R min(m,n) par n (R est
!>          triangulaire supérieure si m >= n). Les entrées diagonales de R sont
!>          non négatives ; les éléments sous la diagonale,
!>          avec le tableau TAU, représentent la matrice orthogonale Q comme un
!>          produit de réflecteurs élémentaires (voir Détails supplémentaires).
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,M).
!>

TAU

!>          TAU est un tableau DOUBLE PRECISION, dimension (min(M,N))
!>          Les facteurs scalaires des réflecteurs élémentaires (voir Détails
!>          supplémentaires).
!>

WORK

!>          WORK est un tableau DOUBLE PRECISION, dimension (N)
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>

Auteur

Univ. du Tennessee

Univ. de Californie Berkeley

Univ. du Colorado Denver

NAG Ltd.

Détails supplémentaires:

!>
!>  La matrice Q est représentée comme un produit de réflecteurs élémentaires
!>
!>     Q = H(1) H(2) . . . H(k), où k = min(m,n).
!>
!>  Chaque H(i) a la forme
!>
!>     H(i) = I - tau * v * v**T
!>
!>  où tau est un scalaire réel, et v est un vecteur réel avec
!>  v(1:i-1) = 0 et v(i) = 1 ; v(i+1:m) est stocké en sortie dans A(i+1:m,i),
!>  et tau dans TAU(i).
!>
!> Voir la note de travail Lapack 203 pour les détails.
!>

Définition à la ligne 133 du fichier dgeqr2p.f.
