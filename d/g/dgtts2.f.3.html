sous-routine dgtts2 (integer itrans, integer n, integer nrhs, double precision, dimension( * ) dl, double precision, dimension( * ) d, double precision, dimension( * ) du, double precision, dimension( * ) du2, integer, dimension( * ) ipiv, double precision, dimension( ldb, * ) b, integer ldb)

DGTTS2 résout un système d'équations linéaires avec une matrice tridiagonale en utilisant la factorisation LU calculée par sgttrf.

Objectif :

!>
!> DGTTS2 résout l'un des systèmes d'équations
!>    A*X = B  ou  A**T*X = B,
!> avec une matrice tridiagonale A en utilisant la factorisation LU calculée
!> par DGTTRF.
!>

Paramètres

ITRANS 
!>          ITRANS est un entier (INTEGER)
!>          Spécifie la forme du système d'équations.
!>          = 0 :  A * X = B  (Pas de transposée)
!>          = 1 :  A**T* X = B  (Transposée)
!>          = 2 :  A**T* X = B  (Transposée conjuguée = Transposée)
!>

N

!>          N est un entier (INTEGER)
!>          L'ordre de la matrice A.
!>

NRHS

!>          NRHS est un entier (INTEGER)
!>          Le nombre de membres de droite, c'est-à-dire le nombre de colonnes
!>          de la matrice B.  NRHS >= 0.
!>

DL

!>          DL est un tableau de double précision (DOUBLE PRECISION array),
!>          de dimension (N-1)
!>          Les (n-1) multiplicateurs qui définissent la matrice L de la
!>          factorisation LU de A.
!>

D

!>          D est un tableau de double précision (DOUBLE PRECISION array),
!>          de dimension (N)
!>          Les n éléments diagonaux de la matrice triangulaire supérieure U issue
!>          de la factorisation LU de A.
!>

DU

!>          DU est un tableau de double précision (DOUBLE PRECISION array),
!>          de dimension (N-1)
!>          Les (n-1) éléments de la première super-diagonale de U.
!>

DU2

!>          DU2 est un tableau de double précision (DOUBLE PRECISION array),
!>          de dimension (N-2)
!>          Les (n-2) éléments de la deuxième super-diagonale de U.
!>

IPIV

!>          IPIV est un tableau d'entiers (INTEGER array), de dimension (N)
!>          Les indices de pivot ; pour 1 <= i <= n, la ligne i de la matrice a
!>          été échangée avec la ligne IPIV(i).  IPIV(i) sera toujours égal à
!>          i ou i+1 ; IPIV(i) = i indique qu'un échange de ligne n'était pas
!>          nécessaire.
!>

B

!>          B est un tableau de double précision (DOUBLE PRECISION array),
!>          de dimension (LDB,NRHS)
!>          À l'entrée, la matrice des vecteurs membres de droite B.
!>          À la sortie, B est écrasée par les vecteurs solutions X.
!>

LDB

!>          LDB est un entier (INTEGER)
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>
