sous-routine dgtrfs (character trans, integer n, integer nrhs, double precision, dimension( * ) dl, double precision, dimension( * ) d, double precision, dimension( * ) du, double precision, dimension( * ) dlf, double precision, dimension( * ) df, double precision, dimension( * ) duf, double precision, dimension( * ) du2, integer, dimension( * ) ipiv, double precision, dimension( ldb, * ) b, integer ldb, double precision, dimension( ldx, * ) x, integer ldx, double precision, dimension( * ) ferr, double precision, dimension( * ) berr, double precision, dimension( * ) work, integer, dimension( * ) iwork, integer

DGTRF

S

But

: 
!>
!> DGTRFS améliore la solution calculée d'un système d'équations
!> linéaires lorsque la matrice des coefficients est tridiagonale, et
!> fournit des bornes d'erreur et des estimations d'erreur arrière
!> pour la solution.
!
>

Paramètre

s
TRANS 
!>          TRANS est CHARACTER*1
!>          Spécifie la forme du système d'équations :
!>          = 'N':  A * X = B     (Sans transposition)
!>          = 'T':  A**T * X = B  (Transposition)
!>          = 'C':  A**H * X = B  (Transposition conjuguée = Transposition)
!
>

N 
!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!
>

NRH

S 
!>          NRHS est INTEGER
!>          Le nombre de seconds membres, c'est-à-dire le nombre de
!>          colonnes de la matrice B.  NRHS >= 0.
!
>

D

L 
!>          DL est un tableau DOUBLE PRECISION, dimension (N-1)
!>          Les (n-1) éléments sous-diagonaux de A.
!
>

D 
!>          D est un tableau DOUBLE PRECISION, dimension (N)
!>          Les éléments diagonaux de A.
!
>

D

U 
!>          DU est un tableau DOUBLE PRECISION, dimension (N-1)
!>          Les (n-1) éléments super-diagonaux de A.
!
>

DL

F 
!>          DLF est un tableau DOUBLE PRECISION, dimension (N-1)
!>          Les (n-1) multiplicateurs qui définissent la matrice L à
!>          partir de la factorisation LU de A telle que calculée par
!>          DGTTRF.
!
>

D

F 
!>          DF est un tableau DOUBLE PRECISION, dimension (N)
!>          Les n éléments diagonaux de la matrice triangulaire
!>          supérieure U issue de la factorisation LU de A.
!
>

DU

F 
!>          DUF est un tableau DOUBLE PRECISION, dimension (N-1)
!>          Les (n-1) éléments de la première super-diagonale de U.
!
>

DU

2 
!>          DU2 est un tableau DOUBLE PRECISION, dimension (N-2)
!>          Les (n-2) éléments de la deuxième super-diagonale de U.
!
>

IPI

V 
!>          IPIV est un tableau INTEGER, dimension (N)
!>          Les indices de pivot ; pour 1 <= i <= n, la ligne i de la
!>          matrice a été interchangée avec la ligne IPIV(i).  IPIV(i)
!>          sera toujours soit i soit i+1 ; IPIV(i) = i indique qu'un
!>          échange de lignes n'a pas été requis.
!
>

B 
!>          B est un tableau DOUBLE PRECISION, dimension (LDB,NRHS)
!>          La matrice du second membre B.
!
>

LD

B 
!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!
>

X 
!>          X est un tableau DOUBLE PRECISION, dimension (LDX,NRHS)
!>          À l'entrée, la matrice solution X, telle que calculée par
!>          DGTTRS.
!>          À la sortie, la matrice solution améliorée X.
!
>

LD

X 
!>          LDX est INTEGER
!>          La dimension principale du tableau X.  LDX >= max(1,N).
!
>

FER

R 
!>          FERR est un tableau DOUBLE PRECISION, dimension (NRHS)
!>          La borne d'erreur avant estimée pour chaque vecteur
!>          solution X(j) (la j-ième colonne de la matrice solution X).
!>          Si XTRUE est la solution réelle correspondant à X(j),
!>          FERR(j) est une borne supérieure estimée pour la grandeur
!>          du plus grand élément dans (X(j) - XTRUE) divisée par la
!>          grandeur du plus grand élément dans X(j).  L'estimation est
!>          aussi fiable que celle pour RCOND, et est presque toujours
!>          une légère surestimation de l'erreur réelle.
!
>

BER

R 
!>          BERR est un tableau DOUBLE PRECISION, dimension (NRHS)
!>          L'erreur arrière relative composante par composante de
!>          chaque vecteur solution X(j) (c'est-à-dire le plus petit
!>          changement relatif dans n'importe quel élément de A ou B
!>          qui rend X(j) une solution exacte).
!
>

WOR

K 
!>          WORK est un tableau DOUBLE PRECISION, dimension (3*N)
!
>

IWOR

K 
!>          IWORK est un tableau INTEGER, dimension (N)
!
>

INF

O 
!>          INFO est INTEGER
!>          = 0:  sortie réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur
!>          illégale
!
>

Paramètres internes

: 
!>  ITMAX est le nombre maximal d'étapes de raffinement itératif.
!
>
