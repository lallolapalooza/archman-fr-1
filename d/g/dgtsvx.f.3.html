sous-routine dgtsvx (caractère fact, caractère trans, entier n, entier nrhs, double précision, dimension( * ) dl, double précision, dimension( * ) d, double précision, dimension( * ) du, double précision, dimension( * ) dlf, double précision, dimension( * ) df, double précision, dimension( * ) duf, double précision, dimension( * ) du2, entier, dimension( * ) ipiv, double précision, dimension( ldb, * ) b, entier ldb, double précision, dimension( ldx, * ) x, entier ldx, double précision rcond, double précision, dimension( * ) ferr, double précision, dimension( * ) berr, double précision, dimension( * ) work, entier, dimension( * ) iwork, entier info)

DGTSVX calcule la solution du système d'équations linéaires A * X = B pour les matrices GT

Objectif :

!>
!> DGTSVX utilise la factorisation LU pour calculer la solution d'un système
!> linéaire réel A * X = B ou A**T * X = B, où A est une matrice tridiagonale
!> d'ordre N et X et B sont des matrices de taille N par NRHS.
!>
!> Les bornes d'erreur sur la solution et une estimation de la condition sont
!> également fournies.
!>

Description :

!>
!> Les étapes suivantes sont effectuées :
!>
!> 1. Si FACT = 'N', la décomposition LU est utilisée pour factoriser la matrice A
!>    en A = L * U, où L est un produit de matrices de permutation et
!>    bidiagonales inférieures unitaires et U est triangulaire supérieure avec
!>    des éléments non nuls uniquement dans la diagonale principale et les deux
!>    superdiagonales.
!>
!> 2. Si certains U(i,i)=0, rendant U singulière, la routine retourne avec
!>    INFO = i. Sinon, la forme factorisée de A est utilisée pour estimer le
!>    nombre de condition de la matrice A. Si l'inverse du nombre de condition
!>    est inférieur à la précision machine, INFO = N+1 est retourné comme un
!>    avertissement, mais la routine continue pour résoudre X et calculer les
!>    bornes d'erreur comme décrit ci-dessous.
!>
!> 3. Le système d'équations est résolu pour X en utilisant la forme factorisée
!>    de A.
!>
!> 4. Un raffinement itératif est appliqué pour améliorer la solution matricielle
!>    calculée et obtenir des bornes d'erreur et des estimations d'erreur arrière
!>    pour celle-ci.
!>

Paramètres

FACT 
!>          FACT est CHARACTER*1
!>          Spécifie si la forme factorisée de A a été fournie en entrée ou non.
!>          = 'F' : DLF, DF, DUF, DU2, et IPIV contiennent la forme factorisée
!>                  de A; DL, D, DU, DLF, DF, DUF, DU2 et IPIV ne seront pas
!>                  modifiés.
!>          = 'N' : La matrice sera copiée dans DLF, DF, et DUF et factorisée.
!>

TRANS

!>          TRANS est CHARACTER*1
!>          Spécifie la forme du système d'équations :
!>          = 'N' : A * X = B     (Pas de transposée)
!>          = 'T' : A**T * X = B  (Transposée)
!>          = 'C' : A**H * X = B  (Conjuguée transposée = Transposée)
!>

N

!>          N est un ENTIER
!>          L'ordre de la matrice A. N >= 0.
!>

NRHS

!>          NRHS est un ENTIER
!>          Le nombre de membres de droite, c'est-à-dire le nombre de colonnes
!>          de la matrice B. NRHS >= 0.
!>

DL

!>          DL est un tableau de DOUBLE PRÉCISION, dimension (N-1)
!>          Les éléments sous-diagonaux (n-1) de A.
!>

D

!>          D est un tableau de DOUBLE PRÉCISION, dimension (N)
!>          Les éléments diagonaux n de A.
!>

DU

!>          DU est un tableau de DOUBLE PRÉCISION, dimension (N-1)
!>          Les éléments superdiagonaux (n-1) de A.
!>

DLF

!>          DLF est un tableau de DOUBLE PRÉCISION, dimension (N-1)
!>          Si FACT = 'F', alors DLF est un argument d'entrée et contient en
!>          entrée les multiplicateurs (n-1) qui définissent la matrice L de
!>          la factorisation LU de A calculée par DGTTRF.
!>
!>          Si FACT = 'N', alors DLF est un argument de sortie et contient en
!>          sortie les multiplicateurs (n-1) qui définissent la matrice L de
!>          la factorisation LU de A.
!>

DF

!>          DF est un tableau de DOUBLE PRÉCISION, dimension (N)
!>          Si FACT = 'F', alors DF est un argument d'entrée et contient en
!>          entrée les éléments diagonaux n de la matrice triangulaire
!>          supérieure U de la factorisation LU de A.
!>
!>          Si FACT = 'N', alors DF est un argument de sortie et contient en
!>          sortie les éléments diagonaux n de la matrice triangulaire
!>          supérieure U de la factorisation LU de A.
!>

DUF

!>          DUF est un tableau de DOUBLE PRÉCISION, dimension (N-1)
!>          Si FACT = 'F', alors DUF est un argument d'entrée et contient en
!>          entrée les éléments (n-1) de la première superdiagonale de U.
!>
!>          Si FACT = 'N', alors DUF est un argument de sortie et contient en
!>          sortie les éléments (n-1) de la première superdiagonale de U.
!>

DU2

!>          DU2 est un tableau de DOUBLE PRÉCISION, dimension (N-2)
!>          Si FACT = 'F', alors DU2 est un argument d'entrée et contient en
!>          entrée les éléments (n-2) de la deuxième superdiagonale de U.
!>
!>          Si FACT = 'N', alors DU2 est un argument de sortie et contient en
!>          sortie les éléments (n-2) de la deuxième superdiagonale de U.
!>

IPIV

!>          IPIV est un tableau d'ENTIER, dimension (N)
!>          Si FACT = 'F', alors IPIV est un argument d'entrée et contient les
!>          indices de pivot de la factorisation LU de A calculée par DGTTRF.
!>
!>          Si FACT = 'N', alors IPIV est un argument de sortie et contient les
!>          indices de pivot de la factorisation LU de A ; la ligne i de la
!>          matrice a été échangée avec la ligne IPIV(i).
!>          IPIV(i) sera toujours i ou i+1 ; IPIV(i) = i indique qu'un échange
!>          de ligne n'était pas requis.
!>

B

!>          B est un tableau de DOUBLE PRÉCISION, dimension (LDB,NRHS)
!>          La matrice B des membres de droite de taille N par NRHS.
!>

LDB

!>          LDB est un ENTIER
!>          La dimension principale du tableau B. LDB >= max(1,N).
!>

X

!>          X est un tableau de DOUBLE PRÉCISION, dimension (LDX,NRHS)
!>          Si INFO = 0 ou INFO = N+1, la matrice solution X de taille N par NRHS.
!>

LDX

!>          LDX est un ENTIER
!>          La dimension principale du tableau X. LDX >= max(1,N).
!>

RCOND

!>          RCOND est un DOUBLE PRÉCISION
!>          L'estimation de l'inverse du nombre de condition de la matrice
!>          A. Si RCOND est inférieur à la précision machine (en
!>          particulier, si RCOND = 0), la matrice est singulière à la précision
!>          de travail. Cette condition est indiquée par un code de retour de
!>          INFO > 0.
!>

FERR

!>          FERR est un tableau de DOUBLE PRÉCISION, dimension (NRHS)
!>          Les bornes d'erreur avant estimées pour chaque vecteur colonne de X,
!>          c'est-à-dire les bornes d'erreur pour la solution X de A*X = B.
!>          L'estimation de l'erreur avant est calculée par :
!>              norm(u - x) / norm(x) = FERR(j)
!>          où u est le vecteur solution exact et x est le vecteur calculé.
!>

BERR

!>          BERR est un tableau de DOUBLE PRÉCISION, dimension (NRHS)
!>          Les estimations d'erreur arrière pour chaque vecteur colonne de X.
!>          BERR(j) est une mesure de l'erreur arrière pour la j-ième colonne
!>          de la solution, sur une échelle relative. Les erreurs arrière sont
!>          définies comme un petit entier d tel que :
!>              A * (X + delta_X) = B + delta_B, ||delta_B|| / ||B|| <= d
!>          BERR est calculé de telle manière que, si d est une petite valeur,
!>          la composante j de la matrice B est suffisamment proche de la
!>          composante j de la matrice exacte.
!>

WORK

!>          WORK est un tableau de DOUBLE PRÉCISION, dimension (LWORK)
!>          -- LWORK: LWORK est un ENTIER et la dimension de WORK.
!>          LWORK >= max(1, N) pour le calcul de X.
!>          LWORK >= max(1, 2*N) pour le calcul des bornes d'erreur.
!>          Si FACT = 'N', LWORK >= max(1, 2*N) est nécessaire.
!>

IWORK

!>          IWORK est un tableau d'ENTIER, dimension (N)
!>          Un tableau de travail pour les indices de pivot.
!>

INFO

!>          INFO est un ENTIER
!>          = 0 : Exécution réussie.
!>          < 0 : Si INFO = -i, le i-ème argument était hors spécifications.
!>          > 0 : Si INFO = i et i <= N, alors U(i,i) est nul. Le système a une
!>                solution unique; la factorisation est complétée mais ne peut
!>                pas être utilisée pour résoudre A*X = B.
!>                Si INFO = N+1, U est non singulière, mais RCOND est
!>                inférieure à la précision machine.
!>
FERR est un tableau DOUBLE PRECISION, dimension (NRHS) !> La borne d'erreur avant estimée pour chaque vecteur solution !> X(j) (la j-ième colonne de la matrice solution X). !> Si XTRUE est la solution réelle correspondant à X(j), FERR(j) !> est une borne supérieure estimée pour la magnitude du plus grand !> élément dans (X(j) - XTRUE) divisée par la magnitude !> du plus grand élément dans X(j). L'estimation est aussi fiable !> que l'estimation pour RCOND, et est presque toujours une légère !> surestimation de l'erreur réelle. !>

BER

R 
!>          BERR est un tableau DOUBLE PRECISION, dimension (NRHS)
!>          L'erreur arrière relative composante par composante de chaque vecteur
!>          solution X(j) (c'est-à-dire le plus petit changement relatif dans
!>          n'importe quel élément de A ou B qui rend X(j) une solution exacte).
!
>

WOR

K 
!>          WORK est un tableau DOUBLE PRECISION, dimension (3*N)
!
>

IWOR

K 
!>          IWORK est un tableau INTEGER, dimension (N)
!
>

INF

O 
!>          INFO est INTEGER
!>          = 0:  sortie réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0:  si INFO = i, et i est
!>                <= N:  U(i,i) est exactement zéro.  La factorisation
!>                       n'a pas été complétée sauf si i = N, mais le
!>                       facteur U est exactement singulier, donc la solution
!>                       et les bornes d'erreur n'ont pas pu être calculées.
!>                       RCOND = 0 est retourné.
!>                = N+1: U est non singulier, mais RCOND est inférieur à la précision
!>                       machine, ce qui signifie que la matrice est singulière
!>                       à la précision de travail.  Néanmoins, la
!>                       solution et les bornes d'erreur sont calculées car
!>                       il existe un certain nombre de situations où la
!>                       solution calculée peut être plus précise que la
!>                       valeur de RCOND ne le suggérerait.
!>
