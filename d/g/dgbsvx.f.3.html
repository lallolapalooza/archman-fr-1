sous-routine dgbsvx (character fact, character trans, integer n, integer kl, integer ku, integer nrhs, double precision, dimension( ldab, * ) ab, integer ldab, double precision, dimension( ldafb, * ) afb, integer ldafb, integer, dimension( * ) ipiv, character equed, double precision, dimension( * ) r, double precision, dimension( * ) c, double precision, dimension( ldb, * ) b, integer ldb, double precision, dimension( ldx, * ) x, integer ldx, double precision rcond, double precision, dimension( * ) ferr, double precision, dimension( * ) berr, double precision, dimension( * ) work, integer, dimension( * ) iwork, integer

info)

DGBSVX calcule la solution du système d'équations linéaires A * X = B pour les matrices

GB

But

: 
!>
!> DGBSVX utilise la factorisation LU pour calculer la solution d'un système
!> réel d'équations linéaires A * X = B, A**T * X = B, ou A**H * X = B,
!> où A est une matrice bande d'ordre N avec KL sous-diagonales et KU
!> sur-diagonales, et X et B sont des matrices de dimensions N par NRHS.
!>
!> Des bornes d'erreur sur la solution et une estimation de condition sont
!> également fournies.
!
>

Description

: 
!>
!> Les étapes suivantes sont effectuées par cette sous-routine :
!>
!> 1. Si FACT = 'E', des facteurs d'échelle réels sont calculés pour
!>    équilibrer le système :
!>       TRANS = 'N':  diag(R)*A*diag(C)     *inv(diag(C))*X = diag(R)*B
!>       TRANS = 'T': (diag(R)*A*diag(C))**T *inv(diag(R))*X = diag(C)*B
!>       TRANS = 'C': (diag(R)*A*diag(C))**H *inv(diag(R))*X = diag(C)*B
!>    Que le système soit équilibré ou non dépend de la mise à l'échelle
!>    de la matrice A, mais si l'équilibrage est utilisé, A est
!>    écrasée par diag(R)*A*diag(C) et B par diag(R)*B (si TRANS='N')
!>    ou diag(C)*B (si TRANS = 'T' ou 'C').
!>
!> 2. Si FACT = 'N' ou 'E', la décomposition LU est utilisée pour factoriser
!>    la matrice A (après équilibrage si FACT = 'E') comme
!>       A = L * U,
!>    où L est un produit de matrices de permutation et triangulaires
!>    inférieures unitaires avec KL sous-diagonales, et U est triangulaire
!>    supérieure avec KL+KU sur-diagonales.
!>
!> 3. Si certains U(i,i)=0, de sorte que U est exactement singulière, la
!>    routine retourne avec INFO = i. Sinon, la forme factorisée de A est
!>    utilisée pour estimer le conditionnement de la matrice A. Si le
!>    réciproque du conditionnement est inférieur à la précision machine,
!>    INFO = N+1 est retourné comme avertissement, mais la routine continue
!>    quand même à résoudre X et à calculer les bornes d'erreur comme
!>    décrit ci-dessous.
!>
!> 4. Le système d'équations est résolu pour X en utilisant la forme
!>    factorisée de A.
!>
!> 5. Un raffinement itératif est appliqué pour améliorer la matrice
!>    solution calculée et calculer les bornes d'erreur et les estimations
!>    d'erreur arrière pour celle-ci.
!>
!> 6. Si l'équilibrage a été utilisé, la matrice X est multipliée à gauche
!>    par diag(C) (si TRANS = 'N') ou diag(R) (si TRANS = 'T' ou 'C') de
!>    sorte qu'elle résolve le système original avant équilibrage.
!
>

Paramètre

s
FACT 
!>          FACT est CHARACTER*1
!>          Spécifie si la forme factorisée de la matrice A est
!>          fournée à l'entrée, et si ce n'est pas le cas, si la matrice A
!>          doit être équilibrée avant d'être factorisée.
!>          = 'F':  À l'entrée, AFB et IPIV contiennent la forme factorisée
!>                  de A. Si EQUED n'est pas 'N', la matrice A a été
!>                  équilibrée avec les facteurs d'échelle donnés par R et C.
!>                  AB, AFB et IPIV ne sont pas modifiés.
!>          = 'N':  La matrice A sera copiée dans AFB et factorisée.
!>          = 'E':  La matrice A sera équilibrée si nécessaire, puis
!>                  copiée dans AFB et factorisée.
!
>

TRAN

S 
!>          TRANS est CHARACTER*1
!>          Spécifie la forme du système d'équations.
!>          = 'N':  A * X = B     (Pas de transposition)
!>          = 'T':  A**T * X = B  (Transposition)
!>          = 'C':  A**H * X = B  (Transposition)
!
>

N 
!>          N est INTEGER
!>          Le nombre d'équations linéaires, c'est-à-dire l'ordre de la
!>          matrice A. N >= 0.
!
>

K

L 
!>          KL est INTEGER
!>          Le nombre de sous-diagonales dans la bande de A. KL >= 0.
!
>

K

U 
!>          KU est INTEGER
!>          Le nombre de sur-diagonales dans la bande de A. KU >= 0.
!
>

NRH

S 
!>          NRHS est INTEGER
!>          Le nombre de seconds membres, c'est-à-dire le nombre de colonnes
!>          des matrices B et X. NRHS >= 0.
!
>

A

B 
!>          AB est un tableau DOUBLE PRECISION, dimension (LDAB,N)
!>          À l'entrée, la matrice A en stockage bande, dans les lignes 1 à
!>          KL+KU+1. La j-ième colonne de A est stockée dans la j-ième
!>          colonne du tableau AB comme suit :
!>          AB(KU+1+i-j,j) = A(i,j) pour max(1,j-KU)<=i<=min(N,j+kl)
!>
!>          Si FACT = 'F' et EQUED n'est pas 'N', alors A doit avoir été
!>          équilibrée par les facteurs d'échelle dans R et/ou C. AB n'est
!>          pas modifié si FACT = 'F' ou 'N', ou si FACT = 'E' et
!>          EQUED = 'N' à la sortie.
!>
!>          À la sortie, si EQUED .ne. 'N', A est mise à l'échelle comme
!>          suit :
!>          EQUED = 'R':  A := diag(R) * A
!>          EQUED = 'C':  A := A * diag(C)
!>          EQUED = 'B':  A := diag(R) * A * diag(C).
!
>

LDA

B 
!>          LDAB est INTEGER
!>          La dimension principale du tableau AB. LDAB >= KL+KU+1.
!
>

AF

B 
!>          AFB est un tableau DOUBLE PRECISION, dimension (LDAFB,N)
!>          Si FACT = 'F', alors AFB est un argument d'entrée et à l'entrée
!>          contient les détails de la factorisation LU de la matrice bande
!>          A, telle que calculée par DGBTRF. U est stockée comme une matrice
!>          bande triangulaire supérieure avec KL+KU sur-diagonales dans les
!>          lignes 1 à KL+KU+1, et les multiplicateurs utilisés pendant la
!>          factorisation sont stockés dans les lignes KL+KU+2 à
!>          2*KL+KU+1. Si EQUED .ne. 'N', alors AFB est la forme
!>          factorisée de la matrice équilibrée A.
!>
!>          Si FACT = 'N', alors AFB est un argument de sortie et à la
!>          sortie retourne les détails de la factorisation LU de A.
!>
!>          Si FACT = 'E', alors AFB est un argument de sortie et à la
!>          sortie retourne les détails de la factorisation LU de la matrice
!>          équilibrée A (voir la description de AB pour la forme de la
!>          matrice équilibrée).
!
>

LDAF

B 
!>          LDAFB est INTEGER
!>          La dimension principale du tableau AFB. LDAFB >= 2*KL+KU+1.
!
>

IPI

V 
!>          IPIV est un tableau INTEGER, dimension (N)
!>          Si FACT = 'F', alors IPIV est un argument d'entrée et à l'entrée
!>          contient les indices de pivot de la factorisation A = L*U
!>          telle que calculée par DGBTRF ; la ligne i de la matrice a été
!>          échangée avec la ligne IPIV(i).
!>
!>          Si FACT = 'N', alors IPIV est un argument de sortie et à la
!>          sortie contients les indices de pivot de la factorisation A = L*U
!>          de la matrice originale A.
!>
!>          Si FACT = 'E', IPIV est un argument de sortie et à l'exécution
!>          contient les indices de pivot de la factorisation A = L*U
!>          de la matrice équilibrée A.
!
>

EQUE

D 
!>          EQUED est de type CHARACTER*1
!>          Spécifie la forme d'équilibrage qui a été effectuée.
!>          = 'N':  Pas d'équilibrage (toujours vrai si FACT = 'N').
!>          = 'R':  Équilibrage par les lignes, c'est-à-dire que A a été
!>                  prémultipliée par diag(R).
!>          = 'C':  Équilibrage par les colonnes, c'est-à-dire que A a été
!>                  postmultipliée par diag(C).
!>          = 'B':  Équilibrage par les lignes et les colonnes, c'est-à-dire
!>                  que A a été remplacée par diag(R) * A * diag(C).
!>          EQUED est un argument d'entrée si FACT = 'F'; sinon, c'est un
!>          argument de sortie.
!
>

R 
!>          R est un tableau de type DOUBLE PRECISION, dimension (N)
!>          Les facteurs d'échelle par ligne de A. Si EQUED = 'R' ou 'B', A est
!>          multipliée à gauche par diag(R); si EQUED = 'N' ou 'C', R
!>          n'est pas accédé. R est un argument d'entrée si FACT = 'F';
!>          sinon, R est un argument de sortie. Si FACT = 'F' et
!>          EQUED = 'R' ou 'B', chaque élément de R doit être positif.
!
>

C 
!>          C est un tableau de type DOUBLE PRECISION, dimension (N)
!>          Les facteurs d'échelle par colonne de A. Si EQUED = 'C' ou 'B', A est
!>          multipliée à droite par diag(C); si EQUED = 'N' ou 'R', C
!>          n'est pas accédé. C est un argument d'entrée si FACT = 'F';
!>          sinon, C est un argument de sortie. Si FACT = 'F' et
!>          EQUED = 'C' ou 'B', chaque élément de C doit être positif.
!
>

B 
!>          B est un tableau de type DOUBLE PRECISION, dimension (LDB,NRHS)
!>          À l'entrée, la matrice second membre B.
!>          À la sortie,
!>          si EQUED = 'N', B n'est pas modifiée;
!>          si TRANS = 'N' et EQUED = 'R' ou 'B', B est écrasée par
!>          diag(R)*B;
!>          si TRANS = 'T' ou 'C' et EQUED = 'C' ou 'B', B est
!>          écrasée par diag(C)*B.
!
>

LD

B 
!>          LDB est de type INTEGER
!>          La dimension principale du tableau B. LDB >= max(1,N).
!
>

X 
!>          X est un tableau de type DOUBLE PRECISION, dimension (LDX,NRHS)
!>          Si INFO = 0 ou INFO = N+1, la matrice solution X de dimension
!>          N par NRHS du système d'équations original. Notez que A et B sont
!>          modifiées à la sortie si EQUED .ne. 'N', et que la solution du
!>          système équilibré est inv(diag(C))*X si TRANS = 'N' et
!>          EQUED = 'C' ou 'B', ou inv(diag(R))*X si TRANS = 'T' ou 'C'
!>          et EQUED = 'R' ou 'B'.
!
>

LD

X 
!>          LDX est de type INTEGER
!>          La dimension principale du tableau X. LDX >= max(1,N).
!
>

RCON

D 
!>          RCOND est de type DOUBLE PRECISION
!>          L'estimation du nombre de condition réciproque de la matrice
!>          A après équilibrage (si effectué). Si RCOND est inférieur à la
!>          précision machine (en particulier, si RCOND = 0), la matrice
!>          est singulière à la précision de travail. Cette condition est
!>          indiquée par un code de retour INFO > 0.
!
>

FER

R 
!>          FERR est un tableau de type DOUBLE PRECISION, dimension (NRHS)
!>          La borne d'erreur avant estimée pour chaque vecteur solution
!>          X(j) (la j-ième colonne de la matrice solution X).
!>          Si XTRUE est la solution exacte correspondant à X(j), FERR(j)
!>          est une borne supérieure estimée pour la magnitude du plus grand
!>          élément de (X(j) - XTRUE) divisée par la magnitude du
!>          plus grand élément de X(j). L'estimation est aussi fiable que
!>          celle pour RCOND, et est presque toujours une légère
!>          surestimation de l'erreur réelle.
!
>

BER

R 
!>          BERR est un tableau de type DOUBLE PRECISION, dimension (NRHS)
!>          L'erreur arrière relative composante par composante de chaque
!>          vecteur solution X(j) (c'est-à-dire le plus petit changement
!>          relatif dans n'importe quel élément de A ou B qui rend X(j) une
!>          solution exacte).
!
>

WOR

K 
!>          WORK est un tableau de type DOUBLE PRECISION, dimension (MAX(1,3*N))
!>          À la sortie, WORK(1) contient le facteur de croissance réciproque
!>          du pivot norm(A)/norm(U). La norme
!>          est utilisée. Si WORK(1) est beaucoup plus petit que 1, la stabilité
!>          de la factorisation LU de la matrice (équilibrée) A
!>          pourrait être mauvaise. Cela signifie également que la solution X,
!>          l'estimateur de condition RCOND et la borne d'erreur avant FERR
!>          pourraient être peu fiables. Si la factorisation échoue avec
!>          0<INFO<=N, alors WORK(1) contient le facteur de croissance réciproque
!>          du pivot pour les INFO premières colonnes de A.
!
>

IWOR

K 
!>          IWORK est un tableau de type INTEGER, dimension (N)
!
>

INF

O 
!>          INFO est de type INTEGER
!>          = 0:  sortie réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0:  si INFO = i, et i est
!>                <= N:  U(i,i) est exactement nul. La factorisation
!>                       a été complétée, mais le facteur U est exactement
!>                       singulier, donc la solution et les bornes d'erreur
!>                       n'ont pas pu être calculées. RCOND = 0 est retourné.
!>                = N+1: U est non singulier, mais RCOND est inférieur à la
!>                       précision machine, ce qui signifie que la matrice est
!>                       singulière à la précision de travail. Néanmoins, la
!>                       solution et les bornes d'erreur sont calculées car
!>                       il existe un certain nombre de situations où la
!>                       solution calculée peut être plus précise que la
!>                       valeur de RCOND ne le suggérerait.
!
>
