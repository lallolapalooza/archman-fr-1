sous-routine dgtsv (n, nrhs, dl, d, du, b, ldb, info)

DGTSV calcule la solution du système d'équations linéaires A * X = B pour les matrices GT

Documentation de la fonction/sous-routine

sous-routine dgtsv (integer n, integer nrhs, double precision, dimension( * ) dl, double precision, dimension( * ) d, double precision, dimension( * ) du, double precision, dimension( ldb, * ) b, integer ldb, integer info)

DGTSV calcule la solution du système d'équations linéaires A * X = B pour les matrices GT

But :

!>
!> DGTSV  résout l'équation
!>
!>    A*X = B,
!>
!> où A est une matrice tridiagonale n par n, par élimination de Gauss avec
!> pivot partiel.
!>
!> Notez que l'équation  A**T*X = B  peut être résolue en intervertissant l'ordre
!> des arguments DU et DL.
!>

Paramètres

N 
!>          N est un entier
!>          L'ordre de la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est un entier
!>          Le nombre de membres de droite, c'est-à-dire le nombre de colonnes
!>          de la matrice B.  NRHS >= 0.
!>

DL

!>          DL est un tableau de DOUBLE PRECISION, de dimension (N-1)
!>          En entrée, DL doit contenir les éléments (n-1) sous-diagonaux de
!>          A.
!>
!>          En sortie, DL est écrasé par les éléments (n-2) de la
!>          seconde supra-diagonale de la matrice triangulaire supérieure U de
!>          la factorisation LU de A, dans DL(1), ..., DL(n-2).
!>

D

!>          D est un tableau de DOUBLE PRECISION, de dimension (N)
!>          En entrée, D doit contenir les éléments diagonaux de A.
!>
!>          En sortie, D est écrasé par les n éléments diagonaux de U.
!>

DU

!>          DU est un tableau de DOUBLE PRECISION, de dimension (N-1)
!>          En entrée, DU doit contenir les éléments (n-1) super-diagonaux
!>          de A.
!>
!>          En sortie, DU est écrasé par les éléments (n-1) de la première
!>          super-diagonale de U.
!>

B

!>          B est un tableau de DOUBLE PRECISION, de dimension (LDB,NRHS)
!>          En entrée, la matrice N par NRHS des membres de droite B.
!>          En sortie, si INFO = 0, la matrice solution X de N par NRHS.
!>

LDB

!>          LDB est un entier
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

INFO

!>          INFO est un entier
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : si INFO = i, U(i,i) est exactement zéro, et la solution
!>               n'a pas été calculée. La factorisation n'a pas été
!>               terminée à moins que i = N.
!>
