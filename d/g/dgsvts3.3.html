DGSVTS3

But :

!>
!> DGSVTS3 teste DGGSVD3, qui calcule la GSVD d'une matrice A de taille M par N
!> et d'une matrice B de taille P par N :
!>              U'*A*Q = D1*R et V'*B*Q = D2*R.
!>

Paramètres

M 
!>          M est INTEGER
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

P

!>          P est INTEGER
!>          Le nombre de lignes de la matrice B.  P >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes des matrices A et B.  N >= 0.
!>

A

!>          A est un tableau DOUBLE PRECISION, dimension (LDA,M)
!>          La matrice A de taille M par N.
!>

AF

!>          AF est un tableau DOUBLE PRECISION, dimension (LDA,N)
!>          Détails de la GSVD de A et B, tels que retournés par DGGSVD3,
!>          voir DGGSVD3 pour plus de détails.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale des tableaux A et AF.
!>          LDA >= max( 1,M ).
!>

B

!>          B est un tableau DOUBLE PRECISION, dimension (LDB,P)
!>          À l'entrée, la matrice B de taille P par N.
!>

BF

!>          BF est un tableau DOUBLE PRECISION, dimension (LDB,N)
!>          Détails de la GSVD de A et B, tels que retournés par DGGSVD3,
!>          voir DGGSVD3 pour plus de détails.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale des tableaux B et BF.
!>          LDB >= max(1,P).
!>

U

!>          U est un tableau DOUBLE PRECISION, dimension(LDU,M)
!>          La matrice orthogonale U de taille M par M.
!>

LDU

!>          LDU est INTEGER
!>          La dimension principale du tableau U. LDU >= max(1,M).
!>

V

!>          V est un tableau DOUBLE PRECISION, dimension(LDV,M)
!>          La matrice orthogonale V de taille P par P.
!>

LDV

!>          LDV est INTEGER
!>          La dimension principale du tableau V. LDV >= max(1,P).
!>

Q

!>          Q est un tableau DOUBLE PRECISION, dimension(LDQ,N)
!>          La matrice orthogonale Q de taille N par N.
!>

LDQ

!>          LDQ est INTEGER
!>          La dimension principale du tableau Q. LDQ >= max(1,N).
!>

ALPHA

!>          ALPHA est un tableau DOUBLE PRECISION, dimension (N)
!>

BETA

!>          BETA est un tableau DOUBLE PRECISION, dimension (N)
!>
!>          Les paires de valeurs singulières généralisées de A et B, les
!>          matrices « diagonales » D1 et D2 sont construites à partir de
!>          ALPHA et BETA, voir la sous-routine DGGSVD3 pour les détails.
!>

R

!>          R est un tableau DOUBLE PRECISION, dimension(LDQ,N)
!>          La matrice triangulaire supérieure R.
!>

LDR

!>          LDR est INTEGER
!>          La dimension principale du tableau R. LDR >= max(1,N).
!>

IWORK

!>          IWORK est un tableau INTEGER, dimension (N)
!>

WORK

!>          WORK est un tableau DOUBLE PRECISION, dimension (LWORK)
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK,
!>          LWORK >= max(M,P,N)*max(M,P,N).
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, dimension (max(M,P,N))
!>

RESULT

!>          RESULT est un tableau DOUBLE PRECISION, dimension (6)
!>          Les rapports de test :
!>          RESULT(1) = norm( U'*A*Q - D1*R ) / ( MAX(M,N)*norm(A)*ULP)
!>          RESULT(2) = norm( V'*B*Q - D2*R ) / ( MAX(P,N)*norm(B)*ULP)
!>          RESULT(3) = norm( I - U'*U ) / ( M*ULP )
!>          RESULT(4) = norm( I - V'*V ) / ( P*ULP )
!>          RESULT(5) = norm( I - Q'*Q ) / ( N*ULP )
!>          RESULT(6) = 0        si ALPHA est en ordre décroissant ;
!>                    = ULPINV   sinon.
!>
