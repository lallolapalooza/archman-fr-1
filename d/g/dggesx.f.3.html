subroutine dggesx (character jobvsl, character jobvsr, character sort, external selctg, character sense, integer n, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( ldb, * ) b, integer ldb, integer sdim, double precision, dimension( * ) alphar, double precision, dimension( * ) alphai, double precision, dimension( * ) beta, double precision, dimension( ldvsl, * ) vsl, integer ldvsl, double precision, dimension( ldvsr, * ) vsr, integer ldvsr, double precision, dimension( 2 ) rconde, double precision, dimension( 2 ) rcondv, double precision, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, integer liwork, logical, dimension( * ) bwork, integer info)

DGGESX calcule les valeurs propres, la forme de Schur et, éventuellement, la matrice des vecteurs de Schur pour les matrices GE

But :

!>
!> DGGESX calcule pour une paire de matrices réelles non symétriques
!> N par N (A,B), les valeurs propres généralisées, la forme de Schur
!> réelle (S,T) et, éventuellement, les matrices gauche et/ou droite
!> des vecteurs de Schur (VSL et VSR). Cela donne la factorisation de
!> Schur généralisée
!>
!>      (A,B) = ( (VSL) S (VSR)**T, (VSL) T (VSR)**T )
!>
!> Éventuellement, elle ordonne aussi les valeurs propres de sorte
!> qu'un cluster sélectionné de valeurs propres apparaisse dans les
!> blocs diagonaux supérieurs de la matrice quasi-triangulaire
!> supérieure S et de la matrice triangulaire supérieure T ; calcule
!> un nombre de condition réciproque pour la moyenne des valeurs
!> propres sélectionnées (RCONDE) ; et calcule un nombre de condition
!> réciproque pour les sous-espaces défléchis droit et gauche
!> correspondant aux valeurs propres sélectionnées (RCONDV). Les
!> colonnes de tête de VSL et VSR forment alors une base
!> orthonormale pour les espaces propres gauche et droit
!> correspondants (sous-espaces défléchis).
!>
!> Une valeur propre généralisée pour une paire de matrices (A,B)
!> est un scalaire w ou un rapport alpha/beta = w, tel que A - w*B
!> soit singulière. Elle est généralement représentée sous la forme
!> de la paire (alpha,beta), car il existe une interprétation
!> raisonnable pour beta=0 ou lorsque les deux sont nuls.
!>
!> Une paire de matrices (S,T) est en forme de Schur réelle
!> généralisée si T est triangulaire supérieure avec une diagonale
!> non négative et si S est triangulaire supérieure par blocs avec
!> des blocs 1 par 1 et 2 par 2. Les blocs 1 par 1 correspondent aux
!> valeurs propres généralisées réelles, tandis que les blocs 2 par 2
!> de S seront en rendant les éléments correspondants de T de la
!> forme :
!>         [  a  0  ]
!>         [  0  b  ]
!>
!> et la paire de blocs 2 par 2 correspondants dans S et T aura une
!> paire conjuguée complexe de valeurs propres généralisées.
!>
!>

Paramètres

JOBVSL 
!>          JOBVSL est de type CHARACTER*1
!>          = 'N' : ne pas calculer les vecteurs de Schur gauches ;
!>          = 'V' : calculer les vecteurs de Schur gauches.
!>

JOBVSR

!>          JOBVSR est de type CHARACTER*1
!>          = 'N' : ne pas calculer les vecteurs de Schur droits ;
!>          = 'V' : calculer les vecteurs de Schur droits.
!>

SORT

!>          SORT est de type CHARACTER*1
!>          Spécifie s'il faut ou non ordonner les valeurs propres sur
!>          la diagonale de la forme de Schur généralisée.
!>          = 'N' : les valeurs propres ne sont pas ordonnées ;
!>          = 'S' : les valeurs propres sont ordonnées (voir SELCTG).
!>

SELCTG

!>          SELCTG est une FONCTION LOGIQUE de trois arguments DOUBLE PRECISION
!>          SELCTG doit être déclarée EXTERNAL dans la sous-routine appelante.
!>          Si SORT = 'N', SELCTG n'est pas référencée.
!>          Si SORT = 'S', SELCTG est utilisée pour sélectionner les valeurs
!>          propres à trier en haut à gauche de la forme de Schur.
!>          Une valeur propre (ALPHAR(j)+ALPHAI(j))/BETA(j) est sélectionnée si
!>          SELCTG(ALPHAR(j),ALPHAI(j),BETA(j)) est vraie ; c'est-à-dire si l'une
!>          des deux valeurs propres d'une paire conjuguée complexe est
!>          sélectionnée, alors les deux valeurs propres complexes sont
!>          sélectionnées.
!>          Notez qu'une valeur propre complexe sélectionnée peut ne plus
!>          satisfaire SELCTG(ALPHAR(j),ALPHAI(j),BETA(j)) = .TRUE. après
!>          le tri, car le tri peut changer la valeur des valeurs propres
!>          complexes (surtout si la valeur propre est mal conditionnée) ; dans
!>          ce cas, INFO est défini à N+3.
!>

SENSE

!>          SENSE est de type CHARACTER*1
!>          Détermine quels nombres de condition réciproques sont calculés.
!>          = 'N' : aucun n'est calculé ;
!>          = 'E' : calculé uniquement pour la moyenne des valeurs propres
!>          sélectionnées ;
!>          = 'V' : calculé uniquement pour les sous-espaces défléchis
!>          sélectionnés ;
!>          = 'B' : calculé pour les deux.
!>          Si SENSE = 'E', 'V' ou 'B', SORT doit être égal à 'S'.
!>

N

!>          N est de type INTEGER
!>          L'ordre des matrices A, B, VSL et VSR. N >= 0.
!>

A

!>          A est un tableau de type DOUBLE PRECISION, dimension (LDA, N)
!>          À l'entrée, la première des deux matrices.
!>          À la sortie, A a été écrasée par sa forme de Schur
!>          généralisée S.
!>

LDA

!>          LDA est de type INTEGER
!>          La dimension principale de A. LDA >= max(1,N).
!>

B

!>          B est un tableau de type DOUBLE PRECISION, dimension (LDB, N)
!>          À l'entrée, la seconde des deux matrices.
!>          À la sortie, B a été écrasée par sa forme de Schur
!>          généralisée T.
!>

LDB

!>          LDB est de type INTEGER
!>          La dimension principale de B. LDB >= max(1,N).
!>

SDIM

!>          SDIM est de type INTEGER
!>          Si SORT = 'N', SDIM = 0.
!>          Si SORT = 'S', SDIM = le nombre de valeurs propres (après
!>          tri) pour lesquelles SELCTG est vraie. (Les paires conjuguées
!>          complexes pour lesquelles SELCTG est vraie pour l'une ou
!>          l'autre valeur propre comptent pour 2.)
!>

ALPHAR

!>          ALPHAR est un tableau de type DOUBLE PRECISION, dimension (N)
!>

ALPHAI

!>          ALPHAI est un tableau de type DOUBLE PRECISION, dimension (N)
!>

BETA

!>          BETA est un tableau de type DOUBLE PRECISION, dimension (N)
!>          À la sortie, (ALPHAR(j) + ALPHAI(j)*i)/BETA(j), j=1,...,N, sera
!>          les valeurs propres généralisées. ALPHAR(j) + ALPHAI(j)*i
!>          et BETA(j), j=1,...,N sont les diagonales de la forme de Schur
!>          complexe (S,T) qui résulterait si les blocs diagonaux 2 par 2
!>          de la forme de Schur réelle de (A,B) étaient encore réduits
!>          à une forme triangulaire en utilisant des transformations
!>          unitaires complexes 2 par 2.
!>          Si ALPHAI(j) est nul, alors la j-ième valeur propre est réelle ; si
!>          positive, alors les valeurs propres j-ième et (j+1)-ième sont une
!>          paire conjuguée complexe, avec ALPHAI(j+1) négative.
!>
!>          Note : les quotients ALPHAR(j)/BETA(j) et ALPHAI(j)/BETA(j)
!>          peuvent facilement déborder ou être trop petits, et BETA(j) peut
!>          même être nul.us, l'utilisateur doit éviter de calculer naïvement le rapport.
!>          Cependant, ALPHAR et ALPHAI seront toujours inférieurs et
!>          généralement comparables à norm(A) en magnitude, et BETA toujours
!>          inférieur et généralement comparable à norm(B).
!>

VSL

!>          VSL est un tableau DOUBLE PRECISION, de dimension (LDVSL,N)
!>          Si JOBVSL = 'V', VSL contiendra les vecteurs de Schur gauches.
!>          Non référencé si JOBVSL = 'N'.
!>

LDVSL

!>          LDVSL est un entier
!>          La dimension principale de la matrice VSL. LDVSL >=1, et
!>          si JOBVSL = 'V', LDVSL >= N.
!>

VSR

!>          VSR est un tableau DOUBLE PRECISION, de dimension (LDVSR,N)
!>          Si JOBVSR = 'V', VSR contiendra les vecteurs de Schur droits.
!>          Non référencé si JOBVSR = 'N'.
!>

LDVSR

!>          LDVSR est un entier
!>          La dimension principale de la matrice VSR. LDVSR >= 1, et
!>          si JOBVSR = 'V', LDVSR >= N.
!>

RCONDE

!>          RCONDE est un tableau DOUBLE PRECISION, de dimension ( 2 )
!>          Si SENSE = 'E' ou 'B', RCONDE(1) et RCONDE(2) contiennent les
!>          nombres conditionnels réciproques pour la moyenne des valeurs propres sélectionnées.
!>          Non référencé si SENSE = 'N' ou 'V'.
!>

RCONDV

!>          RCONDV est un tableau DOUBLE PRECISION, de dimension ( 2 )
!>          Si SENSE = 'V' ou 'B', RCONDV(1) et RCONDV(2) contiennent les
!>          nombres conditionnels réciproques pour les sous-espaces défléchissants sélectionnés.
!>          Non référencé si SENSE = 'N' ou 'E'.
!>

WORK

!>          WORK est un tableau DOUBLE PRECISION, de dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) contient le LWORK optimal.
!>

LWORK

!>          LWORK est un entier
!>          La dimension du tableau WORK.
!>          Si N = 0, LWORK >= 1, sinon si SENSE = 'E', 'V', ou 'B',
!>          LWORK >= max( 8*N, 6*N+16, 2*SDIM*(N-SDIM) ), sinon
!>          LWORK >= max( 8*N, 6*N+16 ).
!>          Notez que 2*SDIM*(N-SDIM) <= N*N/2.
!>          Notez également qu'une erreur n'est renvoyée que si
!>          LWORK < max( 8*N, 6*N+16), mais si SENSE = 'E' ou 'V' ou 'B'
!>          ceci peut ne pas être suffisant.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule seulement la borne de la taille optimale du tableau WORK
!>          et la taille minimale du tableau IWORK, renvoie ces
!>          valeurs comme premières entrées des tableaux WORK et IWORK, et
!>          aucun message d'erreur lié à LWORK ou LIWORK n'est émis par
!>          XERBLA.
!>

IWORK

!>          IWORK est un tableau INTEGER, de dimension (MAX(1,LIWORK))
!>          À la sortie, si INFO = 0, IWORK(1) contient le LIWORK minimum.
!>

LIWORK

!>          LIWORK est un entier
!>          La dimension du tableau IWORK.
!>          Si SENSE = 'N' ou N = 0, LIWORK >= 1, sinon
!>          LIWORK >= N+6.
!>
!>          Si LIWORK = -1, alors une requête d'espace de travail est supposée ; la
!>          routine calcule seulement la borne de la taille optimale du
!>          tableau WORK et la taille minimale du tableau IWORK, renvoie
!>          ces valeurs comme premières entrées des tableaux WORK et IWORK, et
!>          aucun message d'erreur lié à LWORK ou LIWORK n'est émis par
!>          XERBLA.
!>

BWORK

!>          BWORK est un tableau LOGICAL, de dimension (N)
!>          Non référencé si SORT = 'N'.
!>

INFO

!>          INFO est un entier
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.
!>          = 1,...,N :
!>                L'itération QZ a échoué. (A,B) ne sont pas sous forme de Schur,
!>                mais ALPHAR(j), ALPHAI(j), et BETA(j) devraient
!>                être corrects pour j=INFO+1,...,N.
!>          > N : =N+1 : échec de l'itération QZ autre que DHGEQZ
!>                =N+2 : après réorganisation, l'erreur d'arrondi a changé les valeurs de
!>                      certaines valeurs propres complexes de sorte que les valeurs propres principales
!>                      dans la forme de Schur généralisée ne satisfont plus SELCTG=.TRUE. Ceci pourrait également
!>                      être causé par la mise à l'échelle.
!>                =N+3 : réorganisation échouée dans DTGSEN.
!>
