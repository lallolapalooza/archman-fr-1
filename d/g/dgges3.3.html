sous-routine dgges3 (character jobvsl, character jobvsr, character sort, external selctg, integer n, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( ldb, * ) b, integer ldb, integer sdim, double precision, dimension( * ) alphar, double precision, dimension( * ) alphai, double precision, dimension( * ) beta, double precision, dimension( ldvsl, * ) vsl, integer ldvsl, double precision, dimension( ldvsr, * ) vsr, integer ldvsr, double precision, dimension( * ) work, integer lwork, logical, dimension( * ) bwork, integer

DGGES3 calcule les valeurs propres, la forme de Schur et, éventuellement, la matrice des vecteurs de Schur pour les matrices GE (algorithme par

blocs)

But

: 
!>
!> DGGES3 calcule pour une paire de matrices réelles non symétriques N par N (A,B),
!> les valeurs propres généralisées, la forme de Schur réelle généralisée (S,T),
!> éventuellement, les matrices gauche et/ou droite des vecteurs de Schur (VSL et
!> VSR). Cela donne la factorisation de Schur généralisée
!>
!>          (A,B) = ( (VSL)*S*(VSR)**T, (VSL)*T*(VSR)**T )
!>
!> Éventuellement, il ordonne aussi les valeurs propres de sorte qu'un
!> cluster sélectionné de valeurs propres apparaisse dans les blocs
!> diagonaux de tête de la matrice quasi-triangulaire supérieure S et de
!> la matrice triangulaire supérieure T. Les colonnes de tête de VSL et
!> VSR forment alors une base orthonormale pour les sous-espaces propres
!> gauche et droit correspondants (sous-espaces déflationnaires).
!>
!> (Si seules les valeurs propres généralisées sont nécessaires, utilisez
!> plutôt le pilote DGGEV, qui est plus rapide.)
!>
!> Une valeur propre généralisée pour une paire de matrices (A,B) est un
!> scalaire w ou un rapport alpha/beta = w, tel que A - w*B est singulier.
!> Elle est généralement représentée par la paire (alpha,beta), car il
!> existe une interprétation raisonnable pour beta=0 ou les deux nuls.
!>
!> Une paire de matrices (S,T) est en forme de Schur réelle généralisée
!> si T est triangulaire supérieure avec diagonale non négative et S est
!> triangulaire supérieure par blocs avec des blocs 1 par 1 et 2 par 2.
!> Les blocs 1 par 1 correspondent aux valeurs propres généralisées
!> réelles, tandis que les blocs 2 par 2 de S seront en faisant que les éléments correspondants de T aient la
!> forme :
!>         [  a  0  ]
!>         [  0  b  ]
!>
!> et la paire de blocs 2 par 2 correspondants dans S et T aura une paire
!> conjuguée complexe de valeurs propres généralisées.
!>
!
>

Paramètre

s
JOBVSL 
!>          JOBVSL est CHARACTER*1
!>          = 'N' : ne pas calculer les vecteurs de Schur gauches ;
!>          = 'V' : calculer les vecteurs de Schur gauches.
!
>

JOBVS

R 
!>          JOBVSR est CHARACTER*1
!>          = 'N' : ne pas calculer les vecteurs de Schur droits ;
!>          = 'V' : calculer les vecteurs de Schur droits.
!
>

SOR

T 
!>          SORT est CHARACTER*1
!>          Indique s'il faut ou non ordonner les valeurs propres sur la
!>          diagonale de la forme de Schur généralisée.
!>          = 'N' : les valeurs propres ne sont pas ordonnées ;
!>          = 'S' : les valeurs propres sont ordonnées (voir SELCTG) ;
!
>

SELCT

G 
!>          SELCTG est une FONCTION LOGIQUE de trois arguments DOUBLE PRECISION
!>          SELCTG doit être déclarée EXTERNAL dans la sous-routine appelante.
!>          Si SORT = 'N', SELCTG n'est pas référencée.
!>          Si SORT = 'S', SELCTG est utilisée pour sélectionner les valeurs
!>          propres à trier en haut à gauche de la forme de Schur.
!>          Une valeur propre (ALPHAR(j)+ALPHAI(j))/BETA(j) est sélectionnée si
!>          SELCTG(ALPHAR(j),ALPHAI(j),BETA(j)) est vraie ; c'est-à-dire si l'une
!>          des deux valeurs propres d'une paire conjuguée complexe est
!>          sélectionnée, alors les deux valeurs propres complexes sont
!>          sélectionnées.
!>
!>          Notez que dans le cas mal conditionné, une valeur propre
!>          complexe sélectionnée peut ne plus satisfaire
!>          SELCTG(ALPHAR(j),ALPHAI(j), BETA(j)) = .TRUE. après le tri.
!>          INFO doit être défini à N+2 dans ce cas.
!
>

N 
!>          N est INTEGER
!>          L'ordre des matrices A, B, VSL et VSR. N >= 0.
!
>

A 
!>          A est un tableau DOUBLE PRECISION, dimension (LDA, N)
!>          À l'entrée, la première de la paire de matrices.
!>          À la sortie, A a été écrasée par sa forme de Schur
!>          généralisée S.
!
>

LD

A 
!>          LDA est INTEGER
!>          La dimension principale de A. LDA >= max(1,N).
!
>

B 
!>          B est un tableau DOUBLE PRECISION, dimension (LDB, N)
!>          À l'entrée, la seconde de la paire de matrices.
!>          À la sortie, B a été écrasée par sa forme de Schur
!>          généralisée T.
!
>

LD

B 
!>          LDB est INTEGER
!>          La dimension principale de B. LDB >= max(1,N).
!
>

SDI

M 
!>          SDIM est INTEGER
!>          Si SORT = 'N', SDIM = 0.
!>          Si SORT = 'S', SDIM = nombre de valeurs propres (après tri)
!>          pour lesquelles SELCTG est vraie. (Les paires conjuguées
!>          complexes pour lesquelles SELCTG est vraie pour l'une des
!>          valeurs propres comptent pour 2.)
!
>

ALPHA

R 
!>          ALPHAR est un tableau DOUBLE PRECISION, dimension (N)
!
>

ALPHA

I 
!>          ALPHAI est un tableau DOUBLE PRECISION, dimension (N)
!
>

BET

A 
!>          BETA est un tableau DOUBLE PRECISION, dimension (N)
!>          À la sortie, (ALPHAR(j) + ALPHAI(j)*i)/BETA(j), j=1,...,N, sera
!>          les valeurs propres généralisées. ALPHAR(j) + ALPHAI(j)*i,
!>          et BETA(j),j=1,...,N sont les diagonales de la forme de Schur
!>          complexe (S,T) qui résulterait si les blocs diagonaux 2 par 2
!>          de la forme de Schur réelle de (A,B) étaient encore réduits
!>          en forme triangulaire à l'aide de transformations unitaires
!>          complexes 2 par 2.
!>          Si ALPHAI(j) est nulle, alors la j-ième valeur propre est
!>          réelle ; si positive, alors les valeurs propres j-ième et
!>          (j+1)-ième forment une paire conjuguée complexe, avec
!>          ALPHAI(j+1) négative.
!>
!>          Note : les quotients ALPHAR(j)/BETA(j) et ALPHAI(j)/BETA(j)
!>          peuvent facilement déborder par le haut ou par le bas, et
!>          BETA(j) peut même être nulle. Ainsi, l'utilisateur doit
!>          éviter de calculer naïvement le rapport. Cependant, ALPHAR et
!>          ALPHAI seront toujours inférieures et généralement
!>          comparables en magnitude à norm(A), et BETA toujours
!>          inférieure et généralement comparable à norm(B).
!
>

VS

L 
!>          VSL est un tableau DOUBLE PRECISION, dimension (LDVSL,N)
!>          Si JOBVSL = 'V', VSL contiendra les vecteurs de Schur gauches.
!>          Non référencée si JOBVSL = 'N'.
!
>

LDVS

L 
!>          LDVSL est INTEGER
!>          La dimension principale de la matrice VSL. LDVSL >=1, et
!>          si JOBVSL = 'V', LDVSL >= N.
!
>

VS

R 
!>          VSR est un tableau DOUBLE PRECISION, dimension (LDVSR,N)
!>          Si JOBVSR = 'V', VSR contiendra les vecteurs de Schur droits.
!>          Non référencée si JOBVSR = 'N'.
!
>

LDVS

R 
!>          LDVSR est INTEGER
!>          La dimension principale de la matrice VSR. LDVSR >= 1, et          si JOBVSR = 'V', LDVSR >= N.
!
>

WOR

K 
!>          WORK est un tableau DOUBLE PRECISION, dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) renvoie la valeur optimale de LWORK.
!
>

LWOR

K 
!>          LWORK est un INTEGER
!>          La dimension du tableau WORK.
!>          Si N = 0, LWORK >= 1, sinon LWORK >= 6*N+16.
!>          Pour de bonnes performances, LWORK doit généralement être plus grand.
!>
!>          Si LWORK = -1, une interrogation de l'espace de travail est supposée ; la routine
!>          calcule uniquement la taille optimale du tableau WORK, renvoie
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          lié à LWORK n'est émis par XERBLA.
!
>

BWOR

K 
!>          BWORK est un tableau LOGICAL, dimension (N)
!>          Non référencé si SORT = 'N'.
!
>

INF

O 
!>          INFO est un INTEGER
!>          = 0:  sortie réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale.
!>          = 1,...,N:
!>                L'itération QZ a échoué. (A,B) ne sont pas en forme
!>                de Schur, mais ALPHAR(j), ALPHAI(j) et BETA(j) devraient
!>                être corrects pour j=INFO+1,...,N.
!>          > N:  =N+1: autre échec que l'itération QZ dans DLAQZ0.
!>                =N+2: après réordonnancement, l'arrondi a modifié les valeurs
!>                      de certains valeurs propres complexes de sorte que les valeurs
!>                      propres dominantes dans la forme de Schur généralisée ne
!>                      satisfassent plus SELCTG=.TRUE. Cela pourrait aussi
!>                      être dû à la mise à l'échelle.
!>                =N+3: le réordonnancement a échoué dans DTGSEN.
!
>
