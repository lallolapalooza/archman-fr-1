Documentation de la fonction/sous-routine

sous-routine dgetc2 (integer n, double precision, dimension( lda, * ) a, integer lda, integer, dimension( * ) ipiv, integer, dimension( * ) jpiv, integer info)

DGETC2 calcule la factorisation LU avec pivotement complet de la matrice générale n-par-n.

Objectif :

!>
!> DGETC2 calcule une factorisation LU avec pivotement complet de la
!> matrice A n-par-n. La factorisation a la forme A = P * L * U * Q,
!> où P et Q sont des matrices de permutation, L est triangulaire inférieure
!> avec des éléments diagonaux unitaires et U est triangulaire supérieure.
!>
!> Ceci est l'algorithme BLAS de niveau 2.
!>

Paramètres

N 
!>          N est un ENTIER
!>          L'ordre de la matrice A. N >= 0.
!>

A

!>          A est un tableau en DOUBLE PRÉCISION, de dimension (LDA, N)
!>          À l'entrée, la matrice A n-par-n à factoriser.
!>          À la sortie, les facteurs L et U de la factorisation
!>          A = P*L*U*Q ; les éléments diagonaux unitaires de L ne sont pas stockés.
!>          Si U(k, k) semble être inférieur à SMIN, U(k, k) reçoit
!>          la valeur de SMIN, c'est-à-dire qu'il donne un système perturbé non singulier.
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

IPIV

!>          IPIV est un tableau d'ENTIERS, de dimension(N).
!>          Les indices de pivot ; pour 1 <= i <= N, la ligne i de la
!>          matrice a été échangée avec la ligne IPIV(i).
!>

JPIV

!>          JPIV est un tableau d'ENTIERS, de dimension(N).
!>          Les indices de pivot ; pour 1 <= j <= N, la colonne j de la
!>          matrice a été échangée avec la colonne JPIV(j).
!>

INFO

!>          INFO est un ENTIER
!>           = 0 : succès de l'exécution
!>           > 0 : si INFO = k, U(k, k) est susceptible de provoquer un dépassement
!>                si nous essayons de résoudre pour x dans Ax = b. Donc U est
!>                perturbée pour éviter le dépassement.
!>
