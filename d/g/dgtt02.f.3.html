Documentation de la fonction/sous-routine

sous-routine dgtt02 (character trans, integer n, integer nrhs, double precision, dimension( * ) dl, double precision, dimension( * ) d, double precision, dimension( * ) du, double precision, dimension( ldx, * ) x, integer ldx, double precision, dimension( ldb, * ) b, integer ldb, double precision resid)

DGTT02

But :

!>
!> DGTT02 calcule le résidu de la solution d'un système d'équations tridiagonal :
!>    RESID = norm(B - op(A)*X) / (norm(op(A)) * norm(X) * EPS),
!> où EPS est l'epsilon machine.
!> La norme utilisée est la 1-norme.
!>

Paramètres

TRANS 
!>          TRANS est CHARACTER
!>          Spécifie la forme du résidu.
!>          = 'N' :  B - A    * X  (Pas de transposée)
!>          = 'T' :  B - A**T * X  (Transposée)
!>          = 'C' :  B - A**H * X  (Conjuguée transposée = Transposée)
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de membres de droite, c'est-à-dire le nombre de colonnes
!>          des matrices B et X.  NRHS >= 0.
!>

DL

!>          DL est un tableau de type DOUBLE PRECISION, dimension (N-1)
!>          Les éléments sous-diagonaux (n-1) de A.
!>

D

!>          D est un tableau de type DOUBLE PRECISION, dimension (N)
!>          Les éléments diagonaux de A.
!>

DU

!>          DU est un tableau de type DOUBLE PRECISION, dimension (N-1)
!>          Les éléments super-diagonaux (n-1) de A.
!>

X

!>          X est un tableau de type DOUBLE PRECISION, dimension (LDX,NRHS)
!>          Les vecteurs solutions calculés X.
!>

LDX

!>          LDX est INTEGER
!>          La dimension principale du tableau X.  LDX >= max(1,N).
!>

B

!>          B est un tableau de type DOUBLE PRECISION, dimension (LDB,NRHS)
!>          À l'entrée, les vecteurs membres de droite pour le système d'équations
!>          linéaires.
!>          À la sortie, B est écrasé par la différence B - op(A)*X.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

RESID

!>          RESID est DOUBLE PRECISION
!>          norm(B - op(A)*X) / (norm(op(A)) * norm(X) * EPS)
!>
