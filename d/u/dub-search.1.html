NOM

dub-search - Rechercher les paquets disponibles.

SYNTAXE

dub search <nom-du-paquet> OPTIONS...

DESCRIPTION

Recherche dans tous les fournisseurs spécifiés des paquets correspondants.

OPTIONS

OPTIONS COMMUNES

Voir dub(1)

STATUT DE SORTIE

0
DUB a réussi
1
Erreurs d'utilisation, options de ligne de commande inconnues
2
Paquet introuvable, échec du chargement du paquet, erreur diverse

FICHIERS

dub.sdl, dub.json
