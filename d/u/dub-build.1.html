Paquet: dub

DUB-BUILD(1) The D Language Foundation DUB-BUILD(1)

NOM

dub-build - Construit un paquet (utilise le paquet principal dans le répertoire de travail courant par défaut)

SYNTAXE

dub build [<paquet>[@<spécification-version>]] OPTIONS...

DESCRIPTION

Construit un paquet (utilise le paquet principal dans le répertoire de travail courant par défaut)

OPTIONS

--temp-build

Construit le projet dans le dossier temporaire si possible.

--rdmd

Utilise rdmd au lieu d'invoquer directement le compilateur

-f, --force

Force une recompilation même si la cible est à jour

-y, --yes

Réponse automatique aux invites. Suppose « oui » comme réponse à toutes les invites interactives.

-n, --non-interactive

Ne pas entrer en mode interactif.

-d, --deep

Construit toutes les dépendances, même lorsque la cible principale est une bibliothèque statique.

-b, --build=VALEUR

Spécifie le type de construction à effectuer. Notez que la définition de la variable d'environnement DFLAGS remplacera le type de construction par des indicateurs personnalisés. Noms possibles :
debug, plain, release, release-debug, release-nobounds, unittest, profile, profile-gc, docs, ddox, cov, cov-ctfe, unittest-cov, unittest-cov-ctfe, syntax et types personnalisés

-c, --config=VALEUR

Construit la configuration spécifiée. Les configurations peuvent être définies dans dub.json

--override-config=VALEUR

Utilise la configuration spécifiée pour une certaine dépendance. Peut être spécifié plusieurs fois. Format : --override-config=<dépendance>/<config>

--compiler=VALEUR

Spécifie le binaire du compilateur à utiliser (peut être un chemin). Des préfixes et suffixes arbitraires aux identificateurs ci-dessous sont reconnus (par exemple, ldc2 ou dmd-2.063) et mis en correspondance avec le bon type de compilateur :
dmd, gdc, ldc, gdmd, ldmd

-a, --arch=VALEUR

Force une architecture différente (par exemple, x86 ou x86_64)

-d, --debug=VALEUR

Définit l'identificateur de version `debug` spécifié lors de la construction - peut être utilisé plusieurs fois

--d-version=VALEUR

Définit l'identificateur de `version` spécifié lors de la construction - peut être utilisé plusieurs fois. À utiliser avec parcimonie, avec un grand pouvoir vient une grande responsabilité ! Pour les versions couramment utilisées ou combinées et les versions que les dépendants devraient pouvoir utiliser, créez des configurations dans votre paquet.

--nodeps

Ne résout pas les dépendances manquantes avant de construire

--build-mode=VALEUR

Spécifie la manière dont le compilateur et l'éditeur de liens sont invoqués. Valeurs valides :
separate (par défaut), allAtOnce, singleFile

--single

Traite le nom du paquet comme un nom de fichier. Le fichier doit contenir un commentaire de recette de paquet.

--force-remove

Option obsolète qui ne fait rien.

--filter-versions

[Expérimental] Filtre les identificateurs de version et les identificateurs de version de débogage pour améliorer l'efficacité du cache de construction.

--combined

Essaie de construire l'ensemble du projet en une seule exécution du compilateur.

--print-builds

Affiche la liste des types de construction disponibles

--print-configs

Affiche la liste des configurations disponibles

--print-platform

Affiche les identificateurs de la plateforme de construction actuelle tels qu'utilisés pour les champs de construction dans dub.json

--parallel

Exécute plusieurs instances de compilateur en parallèle, si possible.

OPTIONS COMMUNES

Voir dub(1)

STATUT DE SORTIE

0
DUB a réussi
1
erreurs d'utilisation, options de ligne de commande inconnues
2
paquet non trouvé, échec du chargement du paquet, erreur diverse
