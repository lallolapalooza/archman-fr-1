DUNE-INSTALL(1) Manuel de Dune DUNE-INSTALL(1)

NOM

dune-install - Installe les paquets définis dans l'espace de travail.

SYNOPSIS

Les répertoires d'installation utilisés sont définis par priorité :

- répertoires définis sur la ligne de commande de dune install, ou variables d'environnement correspondantes

- répertoires définis dans le binaire dune. Ils sont configurés avant la compilation de dune avec ./configure

- déduits de la variable d'environnement OPAM_SWITCH_PREFIX si présente

OPTIONS

--action-stderr-on-success=VAL
Identique à --action-stdout-on-success mais pour la sortie d'erreur standard au lieu de la sortie standard. Un bon défaut pour les grands mono-dépôts est --action-stdout-on-success=swallow --action-stderr-on-success=must-be-empty. Cela garantit qu'une compilation réussie a une sortie "propre" et vide.
--action-stdout-on-success=VAL
Spécifie comment traiter la sortie standard des actions lorsqu'elles réussissent. Les valeurs possibles sont : print pour simplement l'afficher dans la sortie de Dune, swallow pour l'ignorer complètement et must-be-empty pour imposer que l'action n'ait rien imprimé. Avec must-be-empty, Dune considérera que l'action a échoué si elle a imprimé quelque chose sur sa sortie standard. La valeur par défaut est print.
--bindir=PATH
Remplace manuellement le répertoire d'installation des binaires publics. Seuls les chemins absolus sont acceptés.
--build-info
Affiche les informations de compilation.
--context=CONTEXT
Sélectionne le contexte à partir duquel installer. Par défaut, installe les fichiers de tous les contextes définis.
--create-install-files
N'installe pas directement, mais crée les fichiers d'installation dans le répertoire racine et crée les fichiers substitués si nécessaire dans destdir (_destdir par défaut).
--datadir=PATH
Remplace manuellement le répertoire d'installation des fichiers de la section share. Seuls les chemins absolus sont acceptés.
--destdir=PATH (absent DESTDIR env)
Ce répertoire est préfixé à tous les chemins installés.
--display-separate-messages
Sépare les messages d'erreur par une ligne vide.
--docdir=PATH
Remplace manuellement le répertoire d'installation des fichiers de documentation. Seuls les chemins absolus sont acceptés.
--dry-run
Affiche uniquement les opérations sur les fichiers qui seraient effectuées.
--error-reporting=VAL (absent=deterministic)
Contrôle quand les erreurs de compilation sont signalées. early signale les erreurs dès qu'elles sont découvertes. deterministic signale les erreurs à la fin de la compilation dans un ordre déterministe. twice signale chaque erreur deux fois : une fois dès qu'elle est découverte, puis à nouveau à la fin de la compilation, dans un ordre déterministe.
--etcdir=PATH
Remplace manuellement le répertoire d'installation des fichiers de configuration. Seuls les chemins absolus sont acceptés.
-f, --force
Force la ré-exécution des actions associées aux alias même si leurs dépendances n'ont pas changé.
--file-watcher=VAL (absent=automatic)
Mécanisme de détection des changements dans la source. Automatic pour faire exécuter à dune un programme externe pour détecter les changements. Manual pour notifier à dune que les fichiers ont été modifiés manuellement.
--libdir=PATH
Répertoire où les fichiers de bibliothèque sont copiés, relatif à prefix ou absolu. Si --prefix est spécifié, la valeur par défaut est $prefix/lib. Seuls les chemins absolus sont acceptés.
--libexecdir=PATH
Remplace manuellement le répertoire d'installation des fichiers de bibliothèque exécutables. Seuls les chemins absolus sont acceptés.
--mandir=PATH
Remplace manuellement le répertoire d'installation des pages de manuel. Seuls les chemins absolus sont acceptés.
--passive-watch-mode
Similaire à [--watch], mais ne lance une compilation que lorsqu'il est instruit de le faire par un RPC externe.
--prefix=PREFIX (absent DUNE_INSTALL_PREFIX env)
Répertoire où les fichiers sont copiés. Par exemple, les binaires sont copiés dans $prefix/bin, les fichiers de bibliothèque dans $prefix/lib, etc...
--relocatable
Rend les binaires relocalisables (le répertoire d'installation peut être déplacé). Le répertoire d'installation doit être spécifié avec --prefix
--sandbox=VAL (absent DUNE_SANDBOX env)
Définit le mode de bac à sable. Certaines actions nécessitent un certain mode de bac à sable, elles ignoreront donc ce paramètre. Les valeurs autorisées sont : none, symlink, copy, hardlink.
--sbindir=PATH
Remplace manuellement le répertoire d'installation des fichiers de la section sbin. Seuls les chemins absolus sont acceptés.
--sections=VAL
sections qui doivent être installées
--stop-on-first-error
Arrête la compilation dès qu'une erreur est rencontrée.
-w, --watch
Au lieu de terminer la compilation après son achèvement, attend continuellement les changements de fichiers.
--wait-for-filesystem-clock
Dune calcule des empreintes des contenus de fichiers pour une meilleure incrémentalité. Ces empreintes sont elles-mêmes mises en cache. Dans certains cas, Dune doit supprimer certaines entrées du cache d'empreintes pour que les choses soient fiables. Cette option fait attendre Dune que l'horloge du système de fichiers avance afin qu'il n'ait pas besoin de supprimer quoi que ce soit. Vous ne devriez probablement pas vous soucier de cette option ; elle est principalement utile aux développeurs de Dune pour rendre les tests du cache d'empreintes de Dune plus reproductibles.

OPTIONS COMMUNES

Ces options sont communes à toutes les commandes.

--always-show-command-line
Affiche toujours les lignes de commande complètes des programmes exécutés par dune.
--auto-promote
Promeut automatiquement les fichiers. C'est similaire à exécuter dune promote après la compilation.
--build-dir=FILE (absent DUNE_BUILD_DIR env)
Répertoire de compilation spécifié. _build si non spécifié
--cache=VAL (absent DUNE_CACHE env)
Active ou désactive le cache Dune (l'un de disabled, enabled-except-user-rules ou enabled). La valeur par défaut est `enabled-except-user-rules'.
--cache-check-probability=VAL (absent DUNE_CACHE_CHECK_PROBABILITY env)
Vérifie la reproductibilité de la compilation en ré-exécutant des règles choisies aléatoirement et en comparant leurs résultats avec ceux stockés dans le cache Dune. Note : en augmentant la probabilité de telles vérifications, vous ralentissez la compilation. La probabilité par défaut est zéro, c'est-à-dire qu'aucune règle n'est vérifiée.
--cache-storage-mode=VAL (absent DUNE_CACHE_STORAGE_MODE env)
Mode de stockage du cache Dune (l'un de auto, hardlink ou copy). La valeur par défaut est `hardlink'.
--config-file=FILE
Charge ce fichier de configuration au lieu de celui par défaut.
--debug-artifact-substitution
Affiche des informations de débogage sur la substitution d'artefacts
--debug-backtraces
Affiche toujours les backtraces d'exceptions.
--debug-cache=VAL
Affiche des messages de débogage sur les manques de cache pour les couches de cache données. La valeur est une liste de noms de couches de cache séparés par des virgules. Toutes les couches de cache disponibles : shared,workspace-local,fs.
--debug-dependency-path
En cas d'erreur, affiche le chemin de dépendance des cibles sur la ligne de commande vers la règle qui a échoué.
--debug-digests
Explique pourquoi Dune décide de recalculer l'empreinte de certains fichiers
--debug-load-dir
Affiche des informations de débogage sur le chargement des répertoires
--debug-package-logs (absent DUNE_DEBUG_PACKAGE_LOGS env)
Affiche toujours les journaux standard lors de la compilation des paquets
--default-target=TARGET (absent=@@default)
Définit la cible par défaut utilisée quand aucune n'est spécifiée pour dune build.
--diff-command=VAL (absent DUNE_DIFF_COMMAND env)
Commande shell à utiliser pour comparer les fichiers. Utilisez - pour désactiver l'affichage du diff.
--disable-promotion (absent DUNE_DISABLE_PROMOTION env)
Désactive toutes les règles de promotion
--display=MODE
Contrôle le mode d'affichage de Dune. Voir dune-config(5) pour plus de détails. Les valeurs valides pour cette option sont progress, verbose, short, quiet ou tui.
--dump-gc-stats=FILE
Vide les statistiques du ramasse-miettes dans un fichier après la fin de la compilation.
--dump-memo-graph=FILE
Vide le graphe de dépendances dans un fichier après la fin de la compilation.
--dump-memo-graph-format=FORMAT (absent=gexf)
Définit le format de fichier utilisé par dune(1) — Arch Linux

NAME

dune — a build system

SYNOPSIS

dune [options] [targets]

OPTIONS

See COMMON OPTIONS below.

The following options are available for the build subcommand:

--build-only-packages=PACKAGES
Only build the specified packages. This option is not compatible with building installed programs.
--build-stdin=FILE
Build the targets listed in FILE.
--no-maint-lib
Do not build maintenance libraries. This is useful when you want to build multiple packages and only want to build the runtime parts of the libraries. Note that this implies --no-check.
--only-optional-deps
Build only optional dependencies.
--only-package=PACKAGE
Only build the specified package. This option is not compatible with building installed programs.
--only-deps
Build only dependencies.
--only-targets
Build only the specified targets, not their dependencies.
--prefer-native
Prefer native compilation to bytecode.
--prefer-bytecode
Prefer bytecode compilation to native.
--use-std-exe
Use standard executables, i.e. those installed in the system.
--use-installed-fallback
Use installed programs as a fallback. This is useful when you are building a project that depends on another project that is not yet installed. In this case, dune will try to use the installed version of the other project instead of building it from source.
--check
Check that the build is reproducible. This option is enabled by default.
--no-check
Do not check that the build is reproducible. This option is useful when you are building a project that you know is not reproducible, for example, because it uses external tools that are not sandboxed.
--force-reinstall
Force reinstall of packages.
--force-rebuild
Force rebuild of packages.
--ignore-client-libraries
Ignore client libraries. This is useful when you are building a project that has a complex dependency graph, and you want to avoid building libraries that are not strictly necessary.
--no-install-promoted-rules
Do not install promoted rules.
--dump-invariant-cache
Dump the invariant cache.
--dump-memo-graph
Dump the memo graph.
--dump-memo-graph-with-timing
Re-run each cached node in the Memo graph after building and include the run duration in the output of --dump-memo-graph. Since all nodes contain a cached value, each measurement will only account for a single node.
--help[=FMT] (default=auto)
Show this help in format FMT. The value FMT must be one of auto, pager, groff or plain. With auto, the format is pager or plain whenever the TERM env var is dumb or undefined.
--ignore-lock-dir
Ignore dune.lock/ directory.
--ignore-promoted-rules
Ignore rules with (mode promote), except ones with (only ...). The variable %{ignoring_promoted_rules} in dune files reflects whether this option was passed or not.
--instrument-with=BACKENDS (absent DUNE_INSTRUMENT_WITH env)
Enable instrumentation by BACKENDS. BACKENDS is a comma-separated list of library names, each one of which must declare an instrumentation backend.
-j JOBS
Run no more than JOBS commands simultaneously.
--no-buffer
Do not buffer the output of commands executed by dune. By default dune buffers the output of subcommands, in order to prevent interleaving when multiple commands are executed in parallel. However, this can be an issue when debugging long running tests. With --no-buffer, commands have direct access to the terminal. Note that as a result their output won't be captured in the log file. You should use this option in conjunction with -j 1, to avoid interleaving. Additionally you should use --verbose as well, to make sure that commands are printed before they are being executed.
--no-config
Do not load the configuration file
--no-print-directory
Suppress "Entering directory" messages.
--only-packages=PACKAGES
Ignore stanzas referring to a package that is not in PACKAGES. PACKAGES is a comma-separated list of package names. Note that this has the same effect as deleting the relevant stanzas from dune files. It is mostly meant for releases. During development, it is likely that what you want instead is to build a particular <package>.install target.
-p PACKAGES, --for-release-of-packages=PACKAGES (required)
Shorthand for --release --only-packages PACKAGE. You must use this option in your <package>.opam files, in order to build only what's necessary when your project contains multiple packages as well as getting reproducible builds.
--print-metrics
Print out various performance metrics after every build.
--profile=VAL (absent DUNE_PROFILE env)
Select the build profile, for instance dev or release. The default is dev.
--promote-install-files[=VAL] (default=true)
Promote any generated <package>.install files to the source tree.
--release
Put dune into a reproducible release mode. Shorthand for --root . --ignore-promoted-rules --no-config --profile release --always-show-command-line --promote-install-files --require-dune-project-file --default-target @install. You should use this option for release builds. For instance, you must use this option in your <package>.opam files. Except if you already use -p, as -p implies this option.
--require-dune-project-file[=VAL] (default=true)
Fail if a dune-project file is missing.
--root=DIR
Use this directory as workspace root instead of guessing it. Note that this option doesn't change the interpretation of targets given on the command line. It is only intended for scripts.
--store-orig-source-dir (absent DUNE_STORE_ORIG_SOURCE_DIR env)
Store original source location in dune-package metadata.
--terminal-persistence=MODE
Change how the log of build results are displayed to the console between rebuilds while in --watch mode. Supported modes: preserve, clear-on-rebuild, clear-on-rebuild-and-flush-history.
--trace-extended
Output extended trace data (requires trace-file).
--trace-file=FILE
Output trace data in catapult format (compatible with chrome://tracing).
--verbose
Same as --display verbose
--version
Show version information.
--watch-exclusions=REGEX
Adds a POSIX regular expression that will exclude matching directories from `dune build --watch`. The option --watch-exclusions can be repeated to add multiple exclusions. Semicolons can be also used as a separator. If no exclusions are provided, then a standard set of exclusions is used; however, if one or more --watch-exclusions are used, none of the standard exclusions are used. The standard exclusions are: ^_opam /_opam ^_esy /_esy ^\.#.* /\.#.* ~$ ^#[^#]*#$ /#[^#]*#$ ^4913$ /4913$ /.git /.hg :/windows
--workspace=FILE (absent DUNE_WORKSPACE env)
Use this specific workspace file instead of looking it up.
-x VAL
Cross-compile using this toolchain.

MORE HELP

Use `dune COMMAND --help' for help on a single command.

EXIT STATUS

dune install exits with:

0
on success.
1
if an error happened.
130
if it was interrupted by a signal.

ENVIRONMENT

These environment variables affect the execution of install:

DESTDIR
See option --destdir.
DUNE_BUILD_DIR
Specified build directory. _build if unspecified
DUNE_CACHE
Enable or disable Dune cache (one of disabled, enabled-except-user-rules or enabled). Default is `enabled-except-user-rules'.
DUNE_CACHE_CHECK_PROBABILITY
Check build reproducibility by re-executing randomly chosen rules and comparing their results with those stored in Dune cache. Note: by increasing the probability of such checks you slow down the build. The default probability is zero, i.e. no rules are checked.
DUNE_CACHE_STORAGE_MODE
Dune cache storage mode (one of auto, hardlink or copy). Default is `hardlink'.
DUNE_DEBUG_PACKAGE_LOGS
Always print the standard logs when building packages
DUNE_DIFF_COMMAND
Shell command to use to diff files. Use - to disable printing the diff.
DUNE_DISABLE_PROMOTION
Disable all promotion rules
DUNE_INSTALL_PREFIX
See option --prefix.
DUNE_INSTRUMENT_WITH
Enable instrumentation by BACKENDS. BACKENDS is a comma-separated list of library names, each one of which must declare an instrumentation backend.
DUNE_PROFILE
Build profile. dev if unspecified or release if -p is set.
DUNE_SANDBOX
Sandboxing mode to use by default. (see --sandbox)
DUNE_STORE_ORIG_SOURCE_DIR
Store original source location in dune-package metadata.
DUNE_WORKSPACE
Use this specific workspace file instead of looking it up.
