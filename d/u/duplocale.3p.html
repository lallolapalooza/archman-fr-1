DUPLOCALE(3P) Manuel du programmeur POSIX DUPLOCALE(3P)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour connaître les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

duplocale — dupliquer un objet locale

SYNTAXE

#include <locale.h>
locale_t duplocale(locale_t locobj);

DESCRIPTION

La fonction duplocale() crée une copie dupliquée de l'objet locale référencé par l'argument locobj.

Si l'argument locobj est LC_GLOBAL_LOCALE, duplocale() crée un nouvel objet locale contenant une copie de la locale globale déterminée par la fonction setlocale().

Le comportement est indéfini si l'argument locobj n'est pas un identifiant d'objet locale valide.

VALEUR DE RETOUR

En cas de succès, la fonction duplocale() retourne un identifiant pour un nouvel objet locale. Sinon, duplocale() retourne (locale_t)0 et définit errno pour indiquer l'erreur.

ERREURS

La fonction duplocale() échouera si :

ENOMEM
Il n'y a pas assez de mémoire disponible pour créer l'objet locale ou charger les données de la locale.

Les sections suivantes sont informatives.

EXEMPLES

Construction d'une version modifiée d'un objet locale existant

L'exemple suivant montre un fragment de code pour créer une version légèrement modifiée d'un objet locale existant. La fonction prend un objet locale et un nom de locale, et elle remplace les données de la catégorie LC_TIME dans l'objet locale par celles de la locale nommée.

#include <locale.h>
...
locale_t
with_changed_lc_time (locale_t obj, const char *name)
{
    locale_t retval = duplocale (obj);
    if (retval != (locale_t) 0)
    {
        locale_t changed = newlocale (LC_TIME_MASK, name, retval);
        if (changed == (locale_t) 0)
            /* Une erreur s'est produite. Libérez toutes les ressources allouées. */
            freelocale (retval);
        retval = changed;
    }
    return retval;
}

UTILISATION APPLICATIVE

L'utilisation de la fonction duplocale() est recommandée pour les situations où un objet locale est utilisé à plusieurs endroits, et il est possible que la durée de vie de l'objet locale se termine avant que toutes les utilisations ne soient terminées. Une autre raison de dupliquer un objet locale est si une forme légèrement modifiée est nécessaire. Ceci peut être réalisé par un appel à newlocale() après l'appel à duplocale().

Comme pour la fonction newlocale(), les identifiants des objets locales créés par la fonction duplocale() doivent être libérés par un appel correspondant à freelocale().

La fonction duplocale() peut également être utilisée en conjonction avec uselocale((locale_t)0). Ceci retourne la locale en vigueur pour le thread appelant, mais peut avoir la valeur LC_GLOBAL_LOCALE. Passer LC_GLOBAL_LOCALE à des fonctions telles que isalnum_l() entraîne un comportement indéfini, mais les applications peuvent la convertir en un objet locale utilisable en utilisant duplocale().
