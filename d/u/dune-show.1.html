NOM

dune-show - Groupe de commandes pour afficher des informations sur l'espace de travail

SYNOPSIS

dune show COMMANDE …

COMMANDES

aliases [OPTION]… [DIR]…
Affiche les alias dans un répertoire donné. Fonctionne de manière similaire à ls.
contexts [OPTION]…
Liste les contextes de build disponibles dans l'espace de travail.
depexts [OPTION]…
Affiche la liste de tous les depexts disponibles.
env [OPTION]… [PATH]
Affiche l'environnement d'un répertoire.
external-lib-deps [OPTION]…
Affiche les bibliothèques externes nécessaires pour construire le projet. C'est un ensemble approximatif de bibliothèques.
installed-libraries [OPTION]…
Affiche les bibliothèques installées sur le système.
location [OPTION]… PROG
Affiche le chemin vers l'exécutable en utilisant la même logique de résolution que [dune exec].
opam-files [OPTION]…
Affiche des informations sur les fichiers opam qui ont été découverts.
package-entries [OPTION]…
Affiche des informations sur les entrées par paquet.
pkg COMMANDE …
Sous-commandes liés à la gestion des paquets.
pp [OPTION]… FICHIER
Construit un FICHIER donné et affiche la sortie prétraitée.
rules [OPTION]… [CIBLE]…
Affiche les règles.
targets [OPTION]… [DIR]…
Affiche les cibles dans un répertoire donné. Fonctionne de manière similaire à ls.
workspace [OPTION]… [DIRS]…
Affiche une description de la structure de l'espace de travail. Si des répertoires DIRS sont fournis, alors seuls ces répertoires de l'espace de travail sont considérés.

OPTIONS COMMUNES

--help[=FMT] (défaut=auto)
Affiche cette aide au format FMT. La valeur FMT doit être l'un des choix suivants : auto, pager, groff ou plain. Avec auto, le format est pager ou plain lorsque la variable d'environnement TERM est dumb ou non définie.
--version
Affiche les informations de version.

STATUT DE SORTIE

dune show se termine avec :

0
en cas de succès.
1
si une erreur s'est produite.
130
s'il a été interrompu par un signal.
