NOM

dune-top - Affiche une liste de directives de toplevel pour inclure des répertoires et charger des fichiers cma.

SYNOPSIS

dune top [OPTION]… [DIR]

DESCRIPTION

Affiche une liste de directives de toplevel pour inclure des répertoires et charger des fichiers cma.

La sortie de dune top doit être évaluée dans un toplevel pour rendre une bibliothèque disponible.

OPTIONS

--action-stderr-on-success=VAL
Identique à --action-stdout-on-success mais pour la sortie d'erreur standard au lieu de la sortie standard. Un bon défaut pour les grands mono-repertoires est --action-stdout-on-success=swallow --action-stderr-on-success=must-be-empty. Cela garantit qu'une compilation réussie a une sortie vide « propre ».
--action-stdout-on-success=VAL
Spécifie comment traiter la sortie standard des actions lorsqu'elles réussissent. Les valeurs possibles sont : print pour simplement l'afficher dans la sortie de Dune, swallow pour l'ignorer complètement et must-be-empty pour imposer que l'action n'ait rien imprimé. Avec must-be-empty, Dune considérera que l'action a échoué si elle a imprimé quelque chose sur sa sortie standard. La valeur par défaut est print.
--build-info
Affiche les informations de compilation.
--context=CONTEXT (absent=default)
Sélectionne le contexte dans lequel compiler/exécuter utop.
--display-separate-messages
Sépare les messages d'erreur par une ligne vide.
--error-reporting=VAL (absent=deterministic)
Contrôle quand les erreurs de compilation sont signalées. early signale les erreurs dès qu'elles sont découvertes. deterministic signale les erreurs à la fin de la compilation dans un ordre déterministe. twice signale chaque erreur deux fois : une fois dès qu'elle est découverte, puis à nouveau à la fin de la compilation, dans un ordre déterministe.
-f, --force
Force la réexécution des actions associées aux alias même si leurs dépendances n'ont pas changé.
--file-watcher=VAL (absent=automatic)
Mécanisme pour détecter les changements dans les sources. Automatic pour faire exécuter par dune un programme externe pour détecter les changements. Manual pour notifier manuellement dune que des fichiers ont changé.
--passive-watch-mode
Similaire à [--watch], mais ne lance une compilation que lorsqu'il est instruit de le faire par un RPC externe.
--sandbox=VAL (absent DUNE_SANDBOX env)
Définit le mode de bac à sable. Certaines actions nécessitent un certain mode de bac à sable, elles ignoreront donc ce réglage. Les valeurs autorisées sont : none, symlink, copy, hardlink.
--stop-on-first-error
Arrête la compilation dès qu'une erreur est rencontrée.
-w, --watch
Au lieu de terminer la compilation une fois terminée, attend continuellement les changements de fichiers.
--wait-for-filesystem-clock
Dune calcule des empreintes du contenu des fichiers pour une meilleure incrémentalité. Ces empreintes sont elles-mêmes mises en cache. Dans certains cas, Dune doit supprimer certaines entrées du cache d'empreintes pour que les choses soient fiables. Cette option fait attendre à Dune l'avance de l'horloge du système de fichiers afin qu'il n'ait pas besoin de supprimer quoi que ce soit. Vous ne devriez probablement pas vous soucier de cette option ; elle est surtout utile aux développeurs de Dune pour rendre les tests du cache d'empreintes plus reproductibles.

OPTIONS COMMUNES

Ces options sont communes à toutes les commandes.

--always-show-command-line
Affiche toujours les lignes de commande complètes des programmes exécutés par dune.
--auto-promote
Promeut automatiquement les fichiers. Cela revient à exécuter dune promote après la compilation.
--build-dir=FILE (absent DUNE_BUILD_DIR env)
Répertoire de compilation spécifié. _build si non spécifié
--cache=VAL (absent DUNE_CACHE env)
Active ou désactive le cache de Dune (l'un de disabled, enabled-except-user-rules ou enabled). La valeur par défaut est `enabled-except-user-rules'.
--cache-check-probability=VAL (absent DUNE_CACHE_CHECK_PROBABILITY env)
Vérifie la reproductibilité de la compilation en réexécutant des règles choisies aléatoirement et en comparant leurs résultats avec ceux stockés dans le cache de Dune. Note : en augmentant la probabilité de telles vérifications, vous ralentissez la compilation. La probabilité par défaut est zéro, c'est-à-dire qu'aucune règle n'est vérifiée.
--cache-storage-mode=VAL (absent DUNE_CACHE_STORAGE_MODE env)
Mode de stockage du cache de Dune (l'un de auto, hardlink ou copy). La valeur par défaut est `hardlink'.
--config-file=FILE
Charge ce fichier de configuration au lieu de celui par défaut.
--debug-artifact-substitution
Affiche des informations de débogage sur la substitution d'artefacts
--debug-backtraces
Affiche toujours les backtraces d'exceptions.
--debug-cache=VAL
Affiche des messages de débogage sur les ratés de cache pour les couches de cache données. La valeur est une liste de noms de couches de cache séparés par des virgules. Toutes les couches de cache disponibles : shared,workspace-local,fs.
--debug-dependency-path
En cas d'erreur, affiche le chemin de dépendance depuis les cibles sur la ligne de commande jusqu'à la règle qui a échoué.
--debug-digests
Explique pourquoi Dune décide de recalculer l'empreinte de certains fichiers
--debug-load-dir
Affiche des informations de débogage sur le chargement des répertoires
--debug-package-logs (absent DUNE_DEBUG_PACKAGE_LOGS env)
Affiche toujours les journaux standard lors de la compilation des paquets
--default-target=TARGET (absent=@@default)
Définit la cible par défaut utilisée lorsqu'aucune n'est spécifiée pour dune build.
--diff-command=VAL (absent DUNE_DIFF_COMMAND env)
Commande shell à utiliser pour comparer des fichiers. Utilisez - pour désactiver l'affichage du diff.
--disable-promotion (absent DUNE_DISABLE_PROMOTION env)
Désactive toutes les règles de promotion
--display=MODE
Contrôle le mode d'affichage de Dune. Voir dune-config(5) pour plus de détails. Les valeurs valides pour cette option sont : progress, verbose, short, quiet ou tui.
--dump-gc-stats=FILE
Vide les statistiques du ramasse-miettes dans un fichier une fois la compilation terminée.
--dump-memo-graph=FILE
Vide le graphe de dépendances dans un fichier une fois la compilation terminée.
--dump-memo-graph-format=FORMAT (absent=gexf)
Définit le format de fichier utilisé par --dump-memo-graph
--dump-memo-graph-with-timing
Réexécute chaque nœud mis en cache dans le graphe Memo après la compilation et inclut la durée d'exécution dans la sortie de --dump-memo-graph. Comme tous les nœuds contiennent une valeur mise en cache, chaque mesure ne comptera que pour un seul nœud.
--help[=FMT] (par défaut=auto)
Affiche cette aide au format FMT. La valeur FMT doit être l'une de auto, pager, groff ou plain. Avec auto, le format est pager ou plain lorsque la variable d'environnement TERM est dumb ou indéfinie.
--ignore-lock-dir
Ignore le répertoire dune.lock/.
--ignore-promoted-rules
Ignore les règles avec (mode promote), sauf celles avec (only ...). La variable %{ignoring_promoted_rules} dans les fichiers dune reflète si cette option a été passée ou non.
--instrument-with=BACKENDS (absent DUNE_INSTRUMENT_WITH env)
Active l'instrumentation par BACKENDS. BACKENDS est une liste de noms de bibliothèques séparés par des virgules, chacun devant déclarer un backend d'instrumentation.
-j JOBS
N'exécute pas plus de JOBS commandes simultanément.
--no-buffer
Ne met pas en tampon la sortie des commandes exécutées par dune. Par défaut, dune met en tampon la sortie des sous-commandes afin d'éviter l'entrelacement lorsque plusieurs commandes sont exécutées en parallèle. Cependant, cela peut poser problème lors du débogage de tests longs. Avec --no-buffer, les commandes ont un accès direct au terminal. Notez qu'en conséquence, leur sortie ne sera pas capturée dans le fichier journal. Vous devriez utiliser cette option en conjonction avec -j 1pour éviter l'entrelacement. De plus, vous devriez utiliser --verbose également, pour vous assurer que les commandes sont imprimées avant d'être exécutées.
--no-config
Ne charge pas le fichier de configuration
--no-print-directory
Supprime les messages « Entering directory ».
