NOM

dump.exfat - Afficher les informations sur disque du système de fichiers exfat

SYNTAXE

dump.exfat [ -d chemin-fichier ] [ -s chemin-repertoire ] [ -r ] périphérique
dump.exfat -V

DESCRIPTION

dump.exfat Affiche les informations sur disque à partir du périphérique donné, formaté avec un système de fichiers exFAT.

Note : Pour afficher les informations des entrées de répertoire, l'absence de "double-lien" n'indique pas que le cluster n'est pas alloué en double si le balayage n'a pas commencé à partir du répertoire racine avec l'option récursive.

OPTIONS

-V
Affiche le numéro de version et quitte.
-d, --dentry-set=chemin
Affiche les informations des entrées de répertoire à partir d'un chemin donné qui existe dans le périphérique donné.
-s, --scan-dir=chemin-repertoire
Balaye et affiche les informations des entrées de répertoire à partir d'un chemin donné qui existe dans le périphérique donné.
-r, --recursive
Balaye et affiche les informations des entrées de répertoire à partir d'un chemin donné de manière récursive qui existe dans le périphérique donné. Ne fonctionne qu'avec l'option -s.
-c, --cluster-chain
Affiche la chaîne de clusters lors de l'affichage des informations des entrées de répertoire. Ne fonctionne qu'avec les options -d/-s.
