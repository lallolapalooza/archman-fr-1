NOM

dub-lint - Exécute les tests de lint du paquet sélectionné

SYNTAXE

dub lint [<paquet>[@<spécification-version>]] OPTIONS... [-- <arguments-application...>]

DESCRIPTION

Compile le paquet et exécute les tests de lint D-Scanner.

OPTIONS

--syntax-check

Lexicalise et analyse les fichiers source, affiche le numéro de ligne et de colonne de toute erreur de syntaxe sur la sortie standard.

--style-check

Lexicalise et analyse les fichiers source, affiche le numéro de ligne et de colonne de toute défaillance de vérification d'analyse statique sur la sortie standard.

--error-format=VALEUR

Formate les erreurs produites par les vérificateurs de style/syntaxe.

--report

Génère un rapport d'analyse statique au format JSON.

--report-format=VALEUR

Spécifie le format du rapport généré.

--report-file=VALEUR

Écrit le rapport dans un fichier.

--import-paths=VALEUR

Chemins d'importation

--dscanner-config=VALEUR

Utilise le fichier de configuration d-scanner donné.

-b, --build=VALEUR

Spécifie le type de compilation à effectuer. Notez que la définition de la variable d'environnement DFLAGS remplacera le type de compilation par des indicateurs personnalisés. Noms possibles :
debug, plain, release, release-debug, release-nobounds, unittest, profile, profile-gc, docs, ddox, cov, cov-ctfe, unittest-cov, unittest-cov-ctfe, syntax et types personnalisés

-c, --config=VALEUR

Compile la configuration spécifiée. Les configurations peuvent être définies dans dub.json

--override-config=VALEUR

Utilise la configuration spécifiée pour une dépendance donnée. Peut être spécifié plusieurs fois. Format : --override-config=<dépendance>/<configuration>

--compiler=VALEUR

Spécifie le binaire du compilateur à utiliser (peut être un chemin). Les préfixes et suffixes arbitraires des identificateurs ci-dessous sont reconnus (par exemple, ldc2 ou dmd-2.063) et correspondent au bon type de compilateur :
dmd, gdc, ldc, gdmd, ldmd

-a, --arch=VALEUR

Force une architecture différente (par exemple, x86 ou x86_64)

-d, --debug=VALEUR

Définit l'identificateur de version `debug` spécifié lors de la compilation - peut être utilisé plusieurs fois

--d-version=VALEUR

Définit l'identificateur `version` spécifié lors de la compilation - peut être utilisé plusieurs fois. À utiliser avec parcimonie, car un grand pouvoir implique de grandes responsabilités ! Pour les versions couramment utilisées ou combinées et les versions que les dépendants devraient pouvoir utiliser, créez des configurations dans votre paquet.

--nodeps

Ne résout pas les dépendances manquantes avant la compilation

--build-mode=VALEUR

Spécifie la manière dont le compilateur et l'éditeur de liens sont invoqués. Valeurs valides :
separate (par défaut), allAtOnce, singleFile

--single

Traite le nom du paquet comme un nom de fichier. Le fichier doit contenir un commentaire de recette de paquet.

--force-remove

Option obsolète qui ne fait rien.

--filter-versions

[Expérimental] Filtre les identificateurs de version et les identificateurs de version de débogage pour améliorer l'efficacité du cache de compilation.

OPTIONS COMMUNES

Voir dub(1)

STATUT DE SORTIE

0
DUB a réussi
1
erreurs d'utilisation, indicateurs de ligne de commande inconnus
2
paquet introuvable, échec du chargement du paquet, erreur diverse
