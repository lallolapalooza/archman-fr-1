DUMP.EROFS(1) Manuel des commandes générales DUMP.EROFS(1)

NOM

dump.erofs - récupérer les entrées de répertoire et de fichier, afficher les informations spécifiques d'un fichier ou les statistiques globales du disque à partir d'une image formatée EROFS.

SYNOPSIS

dump.erofs [OPTIONS] IMAGE

DESCRIPTION

dump.erofs est utilisé pour récupérer les métadonnées et les données d'erofs de IMAGE et démontrer
1) les statistiques globales du disque,
2) les informations du superbloc,
3) les informations de fichier du NID d'inode donné,
4) les informations d'extension de fichier du NID d'inode donné,
5) le contenu du fichier pour le NID d'inode donné.

OPTIONS

--device=chemin
Spécifier un périphérique supplémentaire à utiliser ensemble. Vous pouvez donner plusieurs options --device dans le bon ordre.
--ls
Lister le contenu du répertoire. NID ou chemin requis.
--cat
Écrire le contenu du fichier sur la sortie standard. NID ou chemin requis.
--nid=NID
Spécifier un NID d'inode afin d'afficher ses informations de fichier.
--path=chemin
Spécifier un chemin d'inode afin d'afficher ses informations de fichier.
-e
Afficher les informations d'extension de fichier. NID ou chemin requis.
-V, --version
Afficher le numéro de version et quitter.
-h, --help
Afficher la chaîne d'aide et quitter.
-s
Afficher les informations du superbloc. C'est l'option par défaut si aucune option n'est spécifiée.
-S
Afficher les statistiques de l'image, y compris la distribution des types/tailles de fichiers, le nombre de fichiers (dé)compressés, le taux de compression, etc.
