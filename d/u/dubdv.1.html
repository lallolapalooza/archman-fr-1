dubdv(1) Manuel des commandes générales dubdv(1)

NOM

dubdv - insérer de l'audio dans un flux vidéo numérique

SYNTAXE

dubdv [ options ] fichier_entrée_audio [ nom_fichier ou - pour stdin ]

DESCRIPTION

dubdv lit l'audio depuis un fichier WAV ou le périphérique DSP OSS et écrase l'audio existant dans un fichier ou un flux DV brut.

--version
affiche le numéro de version de dubdv.
-v, --verbose
affiche les statistiques de l'encodeur / informations d'état.
-a, --audio-input=nom_filtre
Choisit le filtre d'entrée audio : [aucun, >wav<, dsp] WAV est le format par défaut pour audio_input.
-o, --output=nom_filtre
Choisit le filtre de sortie : [>raw<]
-t, --truncate
tronque la sortie à la fin de l'entrée DV.
-r, --repeat=compteur
répète la première image vidéo compteur fois. Cette option ne dub pas l'audio dans l'image répétée.

Options d'aide

-?, --help
Affiche le message d'aide.
--usage
Affiche un bref message d'utilisation.

VOIR AUSSI

playdv(1),dvconnect(1),encodedv(1).

DISPONIBILITÉ

Voir http://libdv.sourceforge.net/ pour la dernière version.
