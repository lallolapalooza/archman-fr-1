dummyhttp(1) Manuel des commandes générales dummyhttp(1)

NOM

dummyhttp - Serveur HTTP super simple qui répond avec un corps fixe et un code de réponse fixe

SYNOPIS

dummyhttp [-q|--quiet] [-v|--verbose]... [-p|--port] [-H|--headers] [-c|--code] [-b|--body] [-i|--interface] [-d|--delay] [--print-completions] [--print-manpage] [--tls-cert] [--tls-key] [-h|--help] [-V|--version]

DESCRIPTION

Serveur HTTP super simple qui répond avec un corps fixe et un code de réponse fixe

OPTIONS

-q, --quiet
Être silencieux (ne rien enregistrer)
-v, --verbose
Être verbeux (enregistrer les données des requêtes entrantes et sortantes). Si donné deux fois, il enregistrera également les données du corps.
-p, --port <PORT> [défaut : 8080]
Port sur lequel écouter
-H, --headers <HEADERS>
En-têtes à envoyer (format : clé:valeur)
-c, --code <CODE> [défaut : 200]
Code de statut HTTP à envoyer
-b, --body <BODY> [défaut : dummyhttp]
Corps HTTP à envoyer

Supporte le templating basé sur Tera (https://tera.netlify.app/docs/) avec quelques fonctions supplémentaires par rapport aux fonctions intégrées par défaut :

uuid() - génère un UUID aléatoire lorem(words) - génère `words` mots de lorem ipsum

Exemple : dummyhttp -b "Bonjour {{ uuid() }}, nous sommes le {{ now() | date(format="%Y") }} {{ lorem(words=5)}}"

-i, --interface <INTERFACE> [défaut : 0.0.0.0]
Interface à lier
-d, --delay <DELAY> [défaut : 0]
Délai en millisecondes avant l'envoi de la réponse en millisecondes
--print-completions <shell>
Générer un fichier de complétion pour un shell

[valeurs possibles : bash, elvish, fish, powershell, zsh]

--print-manpage
Générer la page de manuel
--tls-cert <TLS_CERT>
Certificat TLS à utiliser
--tls-key <TLS_KEY>
Clé privée TLS à utiliser
-h, --help
Afficher l'aide (voir un résumé avec '-h')
-V, --version
Afficher la version

VERSION

v1.1.2
