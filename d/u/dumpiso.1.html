NOM

dumpiso - vidange les paquets isochrones IEEE 1394

SYNTAXE

dumpiso [ options ] [ FICHIER ]

DESCRIPTION

dumpiso écoute sur une plage de canaux sélectionnée et vide tous les paquets reçus dans le fichier FICHIER ou, s'il n'est pas donné, sur la sortie standard. Pendant la vidange, le nombre actuel de paquets reçus est écrit sur la sortie d'erreur et mis à jour à chaque paquet.

Il utilise un format de fichier simple pour les vidanges, décrit dans isodump(5). Les paquets vidangés peuvent être renvoyés avec sendiso(1).

OPTIONS

-c, --channels=CANAUX
Définit les canaux sur lesquels écouter. CANAUX peut être soit un nombre unique, auquel cas il s'agit du seul canal sur lequel écouter, soit une plage de canaux sous la forme X-Y. Les numéros de canal peuvent aller de 0 à 63. Vous pouvez donner cette option plusieurs fois, les nouveaux canaux sont ajoutés à la liste des canaux déjà définis. Par défaut, tous les canaux.
-p, --port=PORT
Choisit le port PORT pour la réception. Un port est une carte ou une puce 1394 et représente un bus connecté, donc ce n'est pertinent que si vous en avez plusieurs. Par défaut, 0.
-h, --help
Affiche le texte d'aide et quitte.

BOGUES

Aucun connu.

VOIR AUSSI

sendiso(1), isodump(5)
