NOM

dub-list - Imprime une liste de tous les paquets locaux ou de paquets sélectionnés dont dub a connaissance

SYNOPSIS

dub list [<paquet>[@<spécification-version>]] OPTIONS...

DESCRIPTION

Imprime une liste de tous les paquets locaux ou de paquets sélectionnés. Cela inclut tous les paquets mis en cache (au niveau utilisateur ou système), tous les paquets dans les chemins de recherche de paquets ("dub add-path") et tous les paquets enregistrés manuellement ("dub add-local"). Si un paquet (et éventuellement une spécification de version) est spécifié, seuls les paquets correspondants sont affichés.

OPTIONS

OPTIONS COMMUNES

Voir dub(1)

STATUT DE SORTIE

0
DUB a réussi
1
erreurs d'utilisation, drapeaux de ligne de commande inconnus
2
paquet non trouvé, échec du chargement du paquet, erreur diverse
