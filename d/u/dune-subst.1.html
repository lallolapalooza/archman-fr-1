NOM

dune subst - Substitue les filigranes dans les fichiers sources.

SYNTAXE

dune subst [--build-info] [OPTION]…

DESCRIPTION

Substitue les chaînes %%ID%% dans les fichiers sources, de manière similaire à ce que fait topkg dans la configuration par défaut.

Cette commande est destinée à être appelée uniquement lorsqu'un utilisateur épingle un paquet à sa version de développement. Elle remplace notamment les chaînes %%VERSION%% par la version obtenue à partir du vcs. Actuellement, seul git est pris en charge et la version est obtenue à partir de la sortie de :

  $ git describe --always --dirty --abbrev=7

dune subst substitue les variables que topkg substitue avec la configuration par défaut :

- %%NAME%%, le nom du projet (depuis le fichier dune-project)

- %%VERSION%%, la sortie de git describe --always --dirty --abbrev=7

- %%VERSION_NUM%%, identique à %%VERSION%% mais avec un éventuel 'v' ou 'V' préfixe supprimé

- %%VCS_COMMIT_ID%%, le hash du commit du vcs

- %%PKG_MAINTAINER%%, le contenu du champ maintainer: du fichier opam

- %%PKG_AUTHORS%%, le contenu du champ authors: du fichier opam

- %%PKG_HOMEPAGE%%, le contenu du champ homepage: du fichier opam

- %%PKG_ISSUES%%, le contenu du champ issues: du fichier opam

- %%PKG_DOC%%, le contenu du champ doc: du fichier opam

- %%PKG_LICENSE%%, le contenu du champ license: du fichier opam

- %%PKG_REPO%%, le contenu du champ repo: du fichier opam

Pour appeler dune subst lorsque votre paquet est épinglé, ajoutez cette ligne au champ build: de votre fichier opam :

  [dune "subst"] {pinned}

Notez que cette commande est destinée à être appelée uniquement depuis les fichiers opam et se comporte un peu différemment des autres commandes dune. En particulier, elle n'essaie pas de détecter la racine et doit être appelée depuis la racine du projet.

OPTIONS

--build-info
Afficher les informations de construction.

OPTIONS COMMUNES

Ces options sont communes à toutes les commandes.

--debug-backtraces
Toujours imprimer les traces d'exception.
--help[=FMT] (défaut=auto)
Afficher cette aide dans le format FMT. La valeur FMT doit être l'un des choix : auto, pager, groff ou plain. Avec auto, le format est pager ou plain chaque fois que la variable d'environnement TERM est dumb ou indéfinie.
--version
Afficher les informations de version.

PLUS D'AIDE

Utilisez `dune COMMANDE --help' pour obtenir de l'aide sur une commande spécifique.

STATUT DE SORTIE

dune subst se termine avec :

0
en cas de succès.
1
si une erreur s'est produite.
130
si elle a été interrompue par un signal.

BOGUES

Consultez les rapports de bogues sur https://github.com/ocaml/dune/issues
