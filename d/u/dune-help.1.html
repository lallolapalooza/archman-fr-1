NOM

dune-help - Aide supplémentaire pour Dune.

SYNTAXE

dune help [--build-info] [--man-format=FMT] [OPTION]… [SUJET]

DESCRIPTION

dune help SUJET fournit une aide supplémentaire sur le sujet donné. Les sujets suivants sont disponibles :

config
dune-config

OPTIONS

--build-info
Afficher les informations de construction.
--man-format=FMT (absent=pager)
Afficher la sortie dans le format FMT. La valeur FMT doit être l'une des suivantes : auto, pager, groff ou plain. Avec auto, le format est pager ou plain chaque fois que la variable d'environnement TERM est dumb ou indéfinie.

OPTIONS COMMUNES

--help[=FMT] (défaut=auto)
Afficher cette aide dans le format FMT. La valeur FMT doit être l'une des suivantes : auto, pager, groff ou plain. Avec auto, le format est pager ou plain chaque fois que la variable d'environnement TERM est dumb ou indéfinie.
--version
Afficher les informations de version.

STATUT DE SORTIE

dune help se termine avec :

0
en cas de succès.
1
en cas d'erreur.
130
si interrompu par un signal.

ENVIRONNEMENT

Ces variables d'environnement affectent l'exécution de help :

CLICOLOR
Si différent de 0, les couleurs ANSI sont supportées et doivent être utilisées lorsque le programme n'est pas pipé. Si égal à 0, n'émettez pas de codes d'échappement de couleur ANSI.
CLICOLOR_FORCE
Si différent de 0, les couleurs ANSI doivent être activées quoi qu'il arrive.
DUNE_CACHE_ROOT
Si défini, détermine l'emplacement du cache partagé global de la machine.

BOGUES

Vérifiez les rapports de bogues sur https://github.com/ocaml/dune/issues
