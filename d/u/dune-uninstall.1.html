NOM

dune-uninstall - Désinstalle les paquets définis dans l'espace de travail.

SYNOPSIS

Les répertoires d'installation utilisés sont définis par priorité :

- répertoires définis sur la ligne de commande de dune install, ou variables d'environnement correspondantes

- répertoires définis dans le binaire dune. Ils sont configurés avant la compilation de dune avec ./configure

- déduits de la variable d'environnement OPAM_SWITCH_PREFIX si présente

OPTIONS

--action-stderr-on-success=VAL
Identique à --action-stdout-on-success mais pour la sortie standard d'erreur au lieu de la sortie standard. Une bonne valeur par défaut pour les grands mono-répertoires est --action-stdout-on-success=swallow --action-stderr-on-success=must-be-empty. Cela garantit qu'une construction réussie a une sortie vide et « propre ».
--action-stdout-on-success=VAL
Spécifie comment gérer la sortie standard des actions lorsqu'elles réussissent. Les valeurs possibles sont : print pour simplement l'imprimer dans la sortie de Dune, swallow pour l'ignorer complètement et must-be-empty pour imposer que l'action n'ait rien imprimé. Avec must-be-empty, Dune considérera que l'action a échoué si elle a imprimé quelque chose sur sa sortie standard. La valeur par défaut est print.
--bindir=CHEMIN
Remplace manuellement le répertoire pour installer les binaires publics. Seul le chemin absolu est accepté.
--build-info
Affiche les informations de construction.
--context=CONTEXTE
Sélectionne le contexte à installer. Par défaut, installe les fichiers de tous les contextes définis.
--create-install-files
N'installe pas directement, mais crée des fichiers d'installation dans le répertoire racine et crée des fichiers substitués si nécessaire dans destdir (_destdir par défaut).
--datadir=CHEMIN
Remplace manuellement le répertoire pour installer les fichiers de la section share. Seul le chemin absolu est accepté.
--destdir=CHEMIN (absent DESTDIR env)
Ce répertoire est ajouté devant tous les chemins installés.
--display-separate-messages
Sépare les messages d'erreur par une ligne vide.
--docdir=CHEMIN
Remplace manuellement le répertoire pour installer les fichiers de documentation. Seul le chemin absolu est accepté.
--dry-run
Affiche uniquement les opérations sur les fichiers qui seraient effectuées.
--error-reporting=VAL (absent=deterministic)
Contrôle quand les erreurs de construction sont signalées. early signale les erreurs dès qu'elles sont découvertes. deterministic signale les erreurs à la fin de la construction dans un ordre déterministe. twice signale chaque erreur deux fois : une fois dès que l'erreur est découverte et ensuite à la fin de la construction, dans un ordre déterministe.
--etcdir=CHEMIN
Remplace manuellement le répertoire pour installer les fichiers de configuration. Seul le chemin absolu est accepté.
-f, --force
Force la ré-exécution des actions associées aux alias même si leurs dépendances n'ont pas changé.
--file-watcher=VAL (absent=automatic)
Mécanisme pour détecter les changements dans la source. Automatic pour que dune exécute un programme externe pour détecter les changements. Manual pour notifier dune que les fichiers ont été modifiés manuellement.
--libdir=CHEMIN
Répertoire où les fichiers de bibliothèque sont copiés, relatif à prefix ou absolu. Si --prefix est spécifié, la valeur par défaut est $prefix/lib. Seul le chemin absolu est accepté.
--libexecdir=CHEMIN
Remplace manuellement le répertoire pour installer les fichiers de bibliothèque exécutables. Seul le chemin absolu est accepté.
--mandir=CHEMIN
Remplace manuellement le répertoire pour installer les pages de manuel. Seul le chemin absolu est accepté.
--passive-watch-mode
Similaire à [--watch], mais ne démarre une construction que lorsqu'elle est instruite extérieurement par une RPC.
--prefix=PREFIX (absent DUNE_INSTALL_PREFIX env)
Répertoire où les fichiers sont copiés. Par exemple, les binaires sont copiés dans $prefix/bin, les fichiers de bibliothèque dans $prefix/lib, etc...
--relocatable
Rend les binaires déplaçables (le répertoire d'installation peut être déplacé). Le répertoire d'installation doit être spécifié avec --prefix
--sandbox=VAL (absent DUNE_SANDBOX env)
Définit le mode sandbox. Certaines actions nécessitent un certain mode sandbox, elles ignoreront donc ce réglage. Les valeurs autorisées sont : none, symlink, copy, hardlink.
--sbindir=CHEMIN
Remplace manuellement le répertoire pour installer les fichiers de la section sbin. Seul le chemin absolu est accepté.
--sections=VAL
Sections qui devraient être installées
--stop-on-first-error
Arrête la construction dès qu'une erreur est rencontrée.
-w, --watch
Au lieu de terminer la construction après son achèvement, attend en continu les changements de fichiers.
--wait-for-filesystem-clock
Dune digère le contenu des fichiers pour une meilleure incrémentalité. Ces digests sont eux-mêmes mis en cache. Dans certains cas, Dune doit supprimer certaines entrées du cache des digests pour que les choses soient fiables. Cette option fait attendre Dune que l'horloge du système de fichiers avance afin qu'elle n'ait pas besoin de supprimer quoi que ce soit. Vous ne devriez probablement pas vous soucier de cette option ; elle est principalement utile aux développeurs de Dune pour rendre les tests de Dune sur le cache des digests plus reproductibles.

OPTIONS COMMUNES

Ces options sont communes à toutes les commandes.

--always-show-command-line
Affiche toujours les lignes de commande complètes des programmes exécutés par dune.
--auto-promote
Promeut automatiquement les fichiers. Ceci est similaire à l'exécution de dune promote après la construction.
--build-dir=FICHIER (absent DUNE_BUILD_DIR env)
Répertoire de construction spécifié. _build si non spécifié
--cache=VAL (absent DUNE_CACHE env)
Active ou désactive le cache Dune (l'un des choix : disabled, enabled-except-user-rules ou enabled). La valeur par défaut est `enabled-except-user-rules'.
--cache-check-probability=VAL (absent DUNE_CACHE_CHECK_PROBABILITY env)
Vérifie la reproductibilité de la construction en ré-exécutant des règles choisies aléatoirement et en comparant leurs résultats avec ceux stockés dans le cache Dune. Note : augmenter la probabilité de telles vérifications ralentit la construction. La probabilité par défaut est zéro, c'est-à-dire qu'aucune règle n'est vérifiée.
--cache-storage-mode=VAL (absent DUNE_CACHE_STORAGE_MODE env)
Mode de stockage du cache Dune (l'un des choix : auto, hardlink ou copy). La valeur par défaut est `hardlink'.
--config-file=FICHIER
Charge ce fichier de configuration au lieu de celui par défaut.
--debug-artifact-substitution
Affiche des informations de débogage sur la substitution d'artefacts
--debug-backtraces
Affiche toujours les traces d'exception.
--debug-cache=VAL
Affiche les messages de débogage en cas de miss du cache pour les couches de cache données. La valeur est une liste de noms de couches de cache séparés par des virgules. Toutes les couches de cache disponibles : shared,workspace-local,fs.
--debug-dependency-path
En cas d'erreur, affiche le chemin de dépendance depuis les cibles sur la ligne de commande jusqu'à la règle qui a échoué.
--debug-digests
Explique pourquoi Dune décide de redigérer certains fichiers
--debug-load-dir
Affiche des informations de débogage sur le chargement des répertoires
--debug-package-logs (absent DUNE_DEBUG_PACKAGE_LOGS env)
Affiche toujours les logs standards lors de la construction de paquets
--default-target=CIBLE (absent=@@default)
Définit la cible par défaut utilisée lorsqu'aucune n'est spécifiée pour dune build.
--diff-command=VAL (absent DUNE_DIFF_COMMAND env)
Commande shell à utiliser pour différer les fichiers. Utilisez - pour désactiver l'affichage du diff.
--disable-promotion (absent DUNE_DISABLE_PROMOTION env)
Désactive toutes les règles de promotion
--display=MODE
Contrôle le mode d'affichage de Dune. Voir dune-config(5) pour plus de détails. Les valeurs valides pour cette option sont progress, verbose, short, quiet ou tui.
--dump-gc-stats=FICHIER
Déverse les statistiques du ramasse-miettes dans un fichier après la fin de la construction.
--dump-memo-graph=FICHIER
Déverse le graphe de dépendances dans un fichier après la fin de la construction.
--dump-memo-graph-format=FORMAT (absent=gexf)
Définit le format du fichier

Ce site n'est en aucun cas associé à Arch Linux ni affilié à ce projet. Le contenu est uniquement une traduction des pages de manuel d'Arch publiées sur man.archlinux.org.

utilisé par --dump-memo-graph
--dump-memo-graph-with-timing
Réexécute chaque nœud mis en cache dans le graphe Memo après la construction et inclut la durée d'exécution dans la sortie de --dump-memo-graph. Comme tous les nœuds contiennent une valeur en cache, chaque mesure ne prendra en compte qu'un seul nœud.
--help[=FMT] (par défaut=auto)
Affiche cette aide au format FMT. La valeur FMT doit être l'une des suivantes : auto, pager, groff ou plain. Avec auto, le format est pager ou plain lorsque la variable d' env ironnement TERM vaut `dumb` ou est indéfinie.
--ignore-lock-dir
Ignore le répertoire dune.lock/.
--ignore-promoted-rules
Ignore les règles avec (mode promote), sauf celles avec (only ...). La variable %{ignoring_promoted_rules} dans les fichiers dune reflète si cette option a été passée ou non.
--instrument-with=BACKENDS (absent DUNE_INSTRUMENT_WITH env)
Active l'instrumentation par BACKENDS. BACKENDS est une liste de noms de bibliothèques séparés par des virgules, chacun devant déclarer un backend d'instrumentation.
-j JOBS
N'exécute pas plus de JOBS commandes simultanément.
--no-buffer
Ne met pas en mémoire tampon la sortie des commandes exécutées par dune. Par défaut, dune met en mémoire tampon la sortie des sous-commandes afin d'éviter l'entrelacement lorsque plusieurs commandes sont exécutées en parallèle. Cependant, cela peut poser problème lors du débogage de tests longs. Avec --no-buffer, les commandes ont un accès direct au terminal. Notez qu'en conséquence, leur sortie ne sera pas capturée dans le fichier de log. Vous devriez utiliser cette option en conjonction avec -j 1, pour éviter l'entrelacement. De plus, vous devriez utiliser --verbose également, pour vous assurer que les commandes sont imprimées avant d'être exécutées.
--no-config
Ne charge pas le fichier de configuration
--no-print-directory
Supprime les messages « Entering directory ».
--only-packages=PACKAGES
Ignore les stanzas faisant référence à un paquet qui n'est pas dans PACKAGES. PACKAGES est une liste de noms de paquets séparés par des virgules. Notez que cela a le même effet que de supprimer les stanzas pertinents des fichiers dune. C'est principalement destiné aux releases. Pendant le développement, il est probable que ce que vous voulez à la place est de construire une cible <package>.install particulière.
-p PACKAGES, --for-release-of-packages=PACKAGES (requis)
Raccourci pour --release --only-packages PACKAGE. Vous devez utiliser cette option dans vos fichiers <package>.opam , afin de ne construire que ce qui est nécessaire lorsque votre projet contient plusieurs paquets ainsi que pour obtenir des builds reproductibles.
--print-metrics
Imprime diverses métriques de performance après chaque build.
--profile=VAL (absent DUNE_PROFILE env)
Sélectionne le profil de build, par exemple dev ou release. Le par défaut est dev.
--promote-install-files[=VAL] (par défaut=true)
Promouvoir tous les fichiers <package>.install générés vers l'arbre source.
--release
Met dune en mode release reproductible. Raccourci pour --root . --ignore-promoted-rules --no-config --profile release --always-show-command-line --promote-install-files --require-dune-project-file --default-target @install. Vous devriez utiliser cette option pour les builds de release. Par exemple, vous devez utiliser cette option dans vos fichiers <package>.opam . Sauf si vous utilisez déjà -p, car -p implique cette option.
--require-dune-project-file[=VAL] (par défaut=true)
Échoue si un fichier dune-project est manquant.
--root=DIR
Utilise ce répertoire comme racine de l'espace de travail au lieu de le deviner. Notez que cette option ne change pas l'interprétation des cibles données sur la ligne de commande. Elle n'est destinée qu'aux scripts.
--store-orig-source-dir (absent DUNE_STORE_ORIG_SOURCE_DIR env)
Stocke l'emplacement source d'origine dans les métadonnées dune-package.
--terminal-persistence=MODE
Change la manière dont le journal des résultats de build est affiché sur la console entre les reconstructions en mode --watch . Modes pris en charge : preserve, clear-on-rebuild, clear-on-rebuild-and-flush-history.
--trace-extended
Sort des données de trace étendues (nécessite trace-file).
--trace-file=FILE
Sort des données de trace au format catapult (compatible avec chrome://tracing).
--verbose
Identique à --display verbose
--version
Affiche les informations de version.
--watch-exclusions=REGEX
Ajoute une expression rationnelle POSIX qui exclura les répertoires correspondants de `dune build --watch`. L'option --watch-exclusions peut être répétée pour ajouter plusieurs exclusions. Les points-virgules peuvent également être utilisés comme séparateur. Si aucune exclusion n'est fournie, un ensemble standard d'exclusions est utilisé ; cependant, si une ou plusieurs --watch-exclusions sont utilisées, aucune des exclusions standard n'est utilisée. Les exclusions standard sont : ^_opam /_opam ^_esy /_esy ^\.#.* /\.#.* ~$ ^#[^#]*#$ /#[^#]*#$ ^4913$ /4913$ /.git /.hg :/windows
--workspace=FILE (absent DUNE_WORKSPACE env)
Utilise ce fichier d'espace de travail spécifique au lieu de le rechercher.
-x VAL
Compilation croisée en utilisant cette chaîne d'outils.

PLUS D'AIDE

Utilisez `dune COMMAND --help' pour obtenir de l'aide sur une seule commande.

STATUT DE SORTIE

dune uninstall se termine avec :

0
en cas de succès.
1
si une erreur s'est produite.
130
s'il a été interrompu par un signal.

ENVIRONNEMENT

Ces variables d'environnement affectent l'exécution de uninstall:

DESTDIR
Voir l'option --destdir.
DUNE_BUILD_DIR
Répertoire de build spécifié. _build si non spécifié
DUNE_CACHE
Active ou désactive le cache Dune (l'un de disabled, enabled-except-user-rules ou enabled). Par défaut est `enabled-except-user-rules'.
DUNE_CACHE_CHECK_PROBABILITY
Vérifie la reproductibilité du build en réexécutant des règles choisies aléatoirement et en comparant leurs résultats avec ceux stockés dans le cache Dune. Note : en augmentant la probabilité de telles vérifications, vous ralentissez le build. La probabilité par défaut est zéro, c'est-à-dire qu'aucune règle n'est vérifiée.
DUNE_CACHE_STORAGE_MODE
Mode de stockage du cache Dune (l'un de auto, hardlink ou copy). Par défaut est `hardlink'.
DUNE_DEBUG_PACKAGE_LOGS
Affiche toujours les logs standard lors de la construction de paquets
DUNE_DIFF_COMMAND
Commande shell à utiliser pour comparer des fichiers. Utilisez - pour désactiver l'affichage de la diff.
DUNE_DISABLE_PROMOTION
Désactive toutes les règles de promotion
DUNE_INSTALL_PREFIX
Voir l'option --prefix.
DUNE_INSTRUMENT_WITH
Active l'instrumentation par BACKENDS. BACKENDS est une liste de noms de bibliothèques séparés par des virgules, chacun devant déclarer un backend d'instrumentation.
DUNE_PROFILE
Profil de build. dev si non spécifié ou release si -p est défini.
DUNE_SANDBOX
Mode de sandboxing à utiliser par défaut. (voir --sandbox)
DUNE_STORE_ORIG_SOURCE_DIR
Stocke l'emplacement source d'origine dans les métadonnées dune-package.
DUNE_WORKSPACE
Utilise ce fichier d'espace de travail spécifique au lieu de le rechercher.
