Dust(1) Manuel des commandes générales Dust(1)

NOM

Dust - Comme du mais plus intuitif

SYNOPIS

dust [-d|--depth] [-T|--threads] [--config] [-n|--number-of-lines] [-p|--full-paths] [-X|--ignore-directory] [-I|--ignore-all-in-file] [-L|--dereference-links] [-x|--limit-filesystem] [-s|--apparent-size] [-r|--reverse] [-c|--no-colors] [-C|--force-colors] [-b|--no-percent-bars] [-B|--bars-on-right] [-z|--min-size] [-R|--screen-reader] [--skip-total] [-f|--filecount] [-i|--ignore-hidden] [-v|--invert-filter] [-e|--filter] [-t|--file-types] [-w|--terminal-width] [-P|--no-progress] [--print-errors] [-D|--only-dir] [-F|--only-file] [-o|--output-format] [-S|--stack-size] [-j|--output-json] [-M|--mtime] [-A|--atime] [-y|--ctime] [--files0-from] [--collapse] [-m|--filetime] [-h|--help] [-V|--version] [CHEMIN]

DESCRIPTION

Comme du mais plus intuitif

OPTIONS

-d, --depth=PROFONDEUR
Profondeur à afficher
-T, --threads=THREADS
Nombre de threads à utiliser
--config=FICHIER
Spécifier un fichier de configuration à utiliser
-n, --number-of-lines=NOMBRE
Nombre de lignes de sortie à afficher. (Par défaut : hauteur_terminal - 10)
-p, --full-paths
Les sous-répertoires n'auront pas leur chemin raccourci
-X, --ignore-directory=CHEMIN
Exclure tout fichier ou répertoire ayant ce chemin
-I, --ignore-all-in-file=FICHIER
Exclure tout fichier ou répertoire dont une expression régulière correspond à ceux listés dans ce fichier. Les entrées du fichier seront ajoutées aux expressions régulières d'ignorance fournies par --invert_filter
-L, --dereference-links
Déréférencer les liens symboliques - Traiter les liens symboliques comme des répertoires et y entrer
-x, --limit-filesystem
Ne compter que les fichiers et répertoires sur le même système de fichiers que le répertoire fourni
-s, --apparent-size
Utiliser la taille du fichier au lieu des blocs
-r, --reverse
Afficher l'arbre à l'envers (le plus grand en haut)
-c, --no-colors
Aucune couleur ne sera imprimée (Utile pour des commandes comme : watch)
-C, --force-colors
Forcer l'impression des couleurs
-b, --no-percent-bars
Aucune barre de progression ou pourcentage ne sera affiché
-B, --bars-on-right
Les barres de progression sont déplacées sur le côté droit de l'écran
-z, --min-size=TAILLE_MIN
Taille minimale du fichier à inclure dans la sortie
-R, --screen-reader
Pour les lecteurs d'écran. Supprime les barres. Ajoute une nouvelle colonne : niveau de profondeur (Peut-être utiliser -p aussi pour le chemin complet)
--skip-total
Aucune ligne de total ne sera affichée
-f, --filecount
La 'taille' du répertoire est le nombre de fichiers enfants au lieu de la taille disque
-i, --ignore-hidden
N'affiche pas les fichiers cachés
-v, --invert-filter=REGEX
Exclure les chemins de fichiers correspondant à cette expression régulière. Pour ignorer les fichiers png, tapez : -v "\.png$"
-e, --filter=REGEX
Inclure uniquement les chemins de fichiers correspondant à cette expression régulière. Pour les fichiers png, tapez : -e "\.png$"
-t, --file-types
afficher seulement ces types de fichiers
-w, --terminal-width=LARGEUR
Spécifier la largeur de la sortie en remplaçant la détection automatique de la largeur du terminal
-P, --no-progress
Désactiver l'indicateur de progression
--print-errors
Afficher les chemins avec des erreurs
-D, --only-dir
Seuls les répertoires seront affichés
-F, --only-file
Seuls les fichiers seront affichés. (Trouve vos plus gros fichiers)
-o, --output-format=FORMAT
Change la taille d'affichage de la sortie. `si` affichera les tailles par puissances de 1000. `b`, `k`, `m`, `g`, `t`, `kb`, `mb`, `gb`, `tb` afficheront l'arbre entier dans cette taille

Valeurs possibles :

  • si : préfixe SI (puissances de 1000)
  • b : octet (B)
  • k : kibioctet (KiB)
  • m : mébioctet (MiB)
  • g : gibioctet (GiB)
  • t : tébioctet (TiB)
  • kb : kilooctet (kB)
  • mb : mégaoctet (MB)
  • gb : gigaoctet (GB)
  • tb : téraoctet (TB)
-S, --stack-size=TAILLE_PILE
Spécifier la mémoire à utiliser comme taille de pile - à utiliser si vous voyez : 'fatal runtime error: stack overflow' (mémoire faible par défaut = 1048576, mémoire élevée = 1073741824)
-j, --output-json
Sortir l'arborescence des répertoires au format JSON dans le répertoire courant
-M, --mtime=MTIME
+/-n correspond aux fichiers modifiés il y a plus/moins de n jours, et n correspond aux fichiers modifiés il y a exactement n jours. Les jours sont arrondis à l'inférieur. C'est-à-dire : +n => (‐∞, actuel‐(n+1)), n => [actuel‐(n+1), actuel‐n), et -n => [actuel‐n, +∞)
-A, --atime=ATIME
Identique à -mtime, mais basé sur le temps d'accès au fichier
-y, --ctime=CTIME
Identique à -mtime, mais basé sur le temps de changement du fichier
--files0-from=FICHIERS0_DE
Exécuter dust sur des noms de fichiers séparés par NUL spécifiés dans le fichier ; si l'argument est -, lire les noms depuis l'entrée standard
--collapse=COLLAPSE
Garder ces répertoires effondrés
-m, --filetime=TEMPS_FICHIER
La 'taille' du répertoire est le temps de fichier maximum des fichiers enfants au lieu de la taille disque. Tandis que a/c/m pour le dernier temps d'accès/changement/modification

Valeurs possibles :

  • a : dernier temps d'accès
  • c : dernier temps de changement
  • m : dernier temps de modification
-h, --help
Afficher l'aide (voir un résumé avec '-h')
-V, --version
Afficher la version
[CHEMIN]
Fichiers ou répertoires d'entrée
