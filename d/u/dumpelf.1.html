NOM

dumpelf - affiche la structure interne d'ELF

SYNTAXE

dumpelf [options] ELF

DESCRIPTION

dumpelf est un utilitaire en espace utilisateur pour afficher toutes les structures internes ELF dans les structures C équivalentes à des fins de débogage ou de référence.

OPTIONS

-h, --help

Affiche l'utilisation condensée et quitte

-V, --version

Affiche la version et quitte

-v, --verbose

Soyez verbeux (peut être utilisé plus d'une fois)

PAGE D'ACCUEIL

https://wiki.gentoo.org/wiki/Hardened/PaX_Utilities
