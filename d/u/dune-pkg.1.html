NOM

dune-pkg - Gestion de paquets expérimentale

SYNTAXE

dune pkg COMMANDE …

DESCRIPTION

Commandes de gestion de paquets OCaml

COMMANDES

enabled [OPTION]…
Vérifie si le projet indique que les fonctionnalités de gestion de paquets de dune doivent être activées. Se termine avec 0 si la gestion de paquets est activée et 1 sinon.
lock [OPTION]… [LOCKDIRS]…
Crée un fichier de verrouillage
outdated [OPTION]… [LOCKDIRS]…
Vérifie les paquets obsolètes
print-solver-env [OPTION]… [LOCKDIRS]…
Affiche une description de l'environnement qui serait utilisé pour résoudre les dépendances, puis se termine sans tenter de résoudre les dépendances ou de générer le fichier de verrouillage. Destiné à être utilisé pour déboguer les situations où aucune solution ne peut être trouvée aux dépendances d'un projet.
validate-lockdir [OPTION]… [LOCKDIRS]…
Valide qu'un répertoire de verrouillage contient une solution pour les paquets locaux

OPTIONS COMMUNES

Ces options sont communes à toutes les commandes.

--help[=FMT] (défaut=auto)
Affiche cette aide au format FMT. La valeur FMT doit être l'une des valeurs suivantes : auto, pager, groff ou plain. Avec auto, le format est pager ou plain chaque fois que la variable d'environnement TERM est dumb ou indéfinie.
--version
Affiche les informations de version.

PLUS D'AIDE

Utilisez `dune COMMANDE --help' pour obtenir de l'aide sur une commande unique.

STATUT DE SORTIE

dune pkg se termine avec :

0
en cas de succès.
1
si une erreur s'est produite.
130
s'il a été interrompu par un signal.

BOGUES

Consultez les rapports de bogues sur https://github.com/ocaml/dune/issues
