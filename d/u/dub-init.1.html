NOM

dub-init - Initialise un squelette de paquet vide

SYNTAXE

dub init [<répertoire> [<dépendance>...]] OPTIONS... [-- <arguments d'application...>]

DESCRIPTION

Initialise un paquet vide du type spécifié dans le répertoire donné.

Par défaut, le répertoire de travail actuel est utilisé.

Des modèles personnalisés peuvent être définis par des paquets en fournissant un sous-paquet appelé « init-exec ». Aucun fichier source par défaut n'est ajouté dans ce cas.

Le sous-paquet « init-exec » est compilé et exécuté à l'intérieur du dossier de destination après la création du répertoire de projet de base.

Les arguments libres « dub init -t custom -- arguments libres » sont transmis au sous-paquet « init-exec » en tant qu'arguments de l'application.

OPTIONS

-t, --type=VALEUR

Définit le type de projet à générer. Types disponibles :

minimal - projet simple « hello world » (par défaut) vibe.d - serveur HTTP minimal basé sur vibe.d deimos - squelette pour liaisons d'en-têtes C custom - projet personnalisé fourni par un paquet dub

-f, --format=VALEUR

Définit le format à utiliser pour le fichier de description du paquet. Valeurs possibles :
json (par défaut), sdl

-n, --non-interactive

Ne pas entrer en mode interactif.

OPTIONS COMMUNES

Voir dub(1)

STATUT DE RÉSULTAT

0
DUB a réussi
1
erreurs d'utilisation, drapeaux de ligne de commande inconnus
2
paquet non trouvé, échec du chargement du paquet, erreur diverse
