NOM

dune-upgrade - Mettre à jour des projets à travers les versions majeures de Dune.

SYNOPSIS

dune upgrade [OPTION]…

DESCRIPTION

dune upgrade met à jour tous les projets de l'espace de travail vers la dernière version majeure de Dune

OPTIONS

--action-stderr-on-success=VAL
Identique à --action-stdout-on-success mais pour la sortie d'erreur standard au lieu de la sortie standard. Un bon choix par défaut pour les grands mono-repertoires est --action-stdout-on-success=swallow --action-stderr-on-success=must-be-empty. Cela garantit qu'une compilation réussie a une sortie vide « propre ».
--action-stdout-on-success=VAL
Spécifie comment gérer la sortie standard des actions lorsqu'elles réussissent. Les valeurs possibles sont : print pour simplement l'afficher dans la sortie de Dune, swallow pour l'ignorer complètement, et must-be-empty pour imposer que l'action n'ait rien imprimé. Avec must-be-empty, Dune considérera que l'action a échoué si elle a imprimé quelque chose sur sa sortie standard. La valeur par défaut est print.
--build-info
Afficher les informations de compilation.
--display-separate-messages
Séparer les messages d'erreur par une ligne vide.
--error-reporting=VAL (absent=deterministic)
Contrôle quand les erreurs de compilation sont signalées. early signale les erreurs dès qu'elles sont découvertes. deterministic signale les erreurs à la fin de la compilation dans un ordre déterministe. twice signale chaque erreur deux fois : une fois dès qu'elle est découverte, puis à nouveau à la fin de la compilation, dans un ordre déterministe.
-f, --force
Forcer la ré-exécution des actions associées aux alias même si leurs dépendances n'ont pas changé.
--file-watcher=VAL (absent=automatic)
Mécanisme de détection des changements dans les sources. Automatic pour faire exécuter à dune un programme externe pour détecter les changements. Manual pour notifier manuellement à dune que des fichiers ont changé.
--passive-watch-mode
Similaire à [--watch], mais ne lance une compilation que lorsqu'il est demandé de l'extérieur par un RPC.
--sandbox=VAL (absent DUNE_SANDBOX env)
Définir le mode de bac à sable. Certaines actions nécessitent un certain mode de bac à sable, elles ignoreront donc ce paramètre. Les valeurs autorisées sont : none, symlink, copy, hardlink.
--stop-on-first-error
Arrêter la compilation dès qu'une erreur est rencontrée.
-w, --watch
Au lieu de terminer la compilation après son achèvement, attendre continuellement les changements de fichiers.
--wait-for-filesystem-clock
Dune calcule des empreintes des contenus de fichiers pour une meilleure incrémentalité. Ces empreintes sont elles-mêmes mises en cache. Dans certains cas, Dune doit supprimer certaines entrées du cache d'empreintes pour que les choses soient fiables. Cette option fait attendre à Dune que l'horloge du système de fichiers avance afin qu'il n'ait pas besoin de supprimer quoi que ce soit. Vous ne devriez probablement pas vous soucier de cette option ; elle est principalement utile aux développeurs de Dune pour rendre les tests du cache d'empreintes de Dune plus reproductibles.

OPTIONS COMMUNES

Ces options sont communes à toutes les commandes.

--always-show-command-line
Toujours afficher les lignes de commande complètes des programmes exécutés par dune.
--auto-promote
Promouvoir automatiquement les fichiers. Cela revient à exécuter dune promote après la compilation.
--build-dir=FILE (absent DUNE_BUILD_DIR env)
Répertoire de compilation spécifié. _build si non spécifié
--cache=VAL (absent DUNE_CACHE env)
Activer ou désactiver le cache Dune (l'une de disabled, enabled-except-user-rules ou enabled). La valeur par défaut est `enabled-except-user-rules'.
--cache-check-probability=VAL (absent DUNE_CACHE_CHECK_PROBABILITY env)
Vérifier la reproductibilité de la compilation en ré-exécutant des règles choisies aléatoirement et en comparant leurs résultats avec ceux stockés dans le cache Dune. Remarque : en augmentant la probabilité de telles vérifications, vous ralentissez la compilation. La probabilité par défaut est zéro, c'est-à-dire qu'aucune règle n'est vérifiée.
--cache-storage-mode=VAL (absent DUNE_CACHE_STORAGE_MODE env)
Mode de stockage du cache Dune (l'un de auto, hardlink ou copy). La valeur par défaut est `hardlink'.
--config-file=FILE
Charger ce fichier de configuration au lieu de celui par défaut.
--debug-artifact-substitution
Afficher des informations de débogage sur la substitution d'artefacts
--debug-backtraces
Toujours afficher les backtraces d'exceptions.
--debug-cache=VAL
Afficher des messages de débogage sur les manques de cache pour les couches de cache données. La valeur est une liste de noms de couches de cache séparés par des virgules. Toutes les couches de cache disponibles : shared,workspace-local,fs.
--debug-dependency-path
En cas d'erreur, afficher le chemin de dépendance depuis les cibles sur la ligne de commande jusqu'à la règle qui a échoué.
--debug-digests
Expliquer pourquoi Dune décide de recalculer l'empreinte de certains fichiers
--debug-load-dir
Afficher des informations de débogage sur le chargement des répertoires
--debug-package-logs (absent DUNE_DEBUG_PACKAGE_LOGS env)
Toujours afficher les journaux standard lors de la compilation des paquets
--default-target=TARGET (absent=@@default)
Définir la cible par défaut utilisée lorsqu'aucune n'est spécifiée pour dune build.
--diff-command=VAL (absent DUNE_DIFF_COMMAND env)
Commande shell à utiliser pour comparer des fichiers. Utilisez - pour désactiver l'affichage de la différence.
--disable-promotion (absent DUNE_DISABLE_PROMOTION env)
Désactiver toutes les règles de promotion
--display=MODE
Contrôler le mode d'affichage de Dune. Voir dune-config(5) pour plus de détails. Les valeurs valides pour cette option sont progress, verbose, short, quiet ou tui.
--dump-gc-stats=FILE
Écrire les statistiques du ramasse-miettes dans un fichier après la fin de la compilation.
--dump-memo-graph=FILE
Écrire le graphe de dépendances dans un fichier après la fin de la compilation.
--dump-memo-graph-format=FORMAT (absent=gexf)
Définir le format de fichier utilisé par --dump-memo-graph
--dump-memo-graph-with-timing
Ré-exécuter chaque nœud mis en cache dans le graphe Memo après la compilation et inclure la durée d'exécution dans la sortie de --dump-memo-graph. Comme tous les nœuds contiennent une valeur en cache, chaque mesure ne comptera que pour un seul nœud.
--help[=FMT] (par défaut=auto)
Afficher cette aide au format FMT. La valeur FMT doit être l'une de auto, pager, groff ou plain. Avec auto, le format est pager ou plain lorsque la variable d'environnement TERM est dumb ou indéfinie.
--ignore-lock-dir
Ignorer le répertoire dune.lock/.
--ignore-promoted-rules
Ignorer les règles avec (mode promote), sauf celles avec (only ...). La variable %{ignoring_promoted_rules} dans les fichiers dune reflète si cette option a été passée ou non.
--instrument-with=BACKENDS (absent DUNE_INSTRUMENT_WITH env)
Activer l'instrumentation par BACKENDS. BACKENDS est une liste de noms de bibliothèques séparés par des virgules, chacun devant déclarer un backend d'instrumentation.
-j JOBS
Exécuter pas plus de JOBS commandes simultanément.
--no-buffer
Ne pas mettre en tampon la sortie des commandes exécutées par dune. Par défaut, dune met en tampon la sortie des sous-commandes afin d'éviter l'entrelacement lorsque plusieurs commandes sont exécutées en parallèle. Cependant, cela peut poser problème lors du débogage de tests longs. Avec --no-buffer, les commandes ont un accès direct au terminal. Notez qu'en conséquence, leur sortie ne sera pas capturée dans le fichier journal. Vous devriez utiliser cette option en conjonction avec -j 1, pour éviter l'entrelacement. De plus, vous devriez utiliser --verbose également, pour vous assurer que les commandes sont imprimées avant d'être exécutées.
--no-config
Ne pas charger le fichier de configuration
--no-print-directory
Supprimer les messages « Entering directory ».
--only-packages=PACKAGES
Ignorer les stanzas faisant référence à un paquet qui n'est pas dans PACKAGES. PACKAGES est une liste de noms de paquets séparés par des virgules. Notez que cela a le même effet que de supprimer les stanzas pertinentsdune-upgrade -- Copier les fichiers d’installation des packages dans le système de fichiers local. SYNOPSIS dune upgrade [TARGET]... DESCRIPTION Cette commande est principalement destinée à la mise à jour des fichiers d’installation des packages. Elle copie les fichiers installés depuis les builds de dune (qui sont toujours dans le répertoire _build) vers le système de fichiers local. Il est principalement destiné aux releases. Pendant le développement, il est probable que ce que vous voulez à la place est de construire une cible <package>.install particulière. OPTIONS Les options suivantes sont disponibles pour contrôler la manière dont dune génère et promeut les fichiers d’installation. Common Options: - `build` est l’alias de `dune build` utilisé pour construire le projet. Il est recommandé de construire votre projet avec `dune build`. - --as-native Construire le projet en utilisant des binaires natifs. - --clear-source-and-build-dir Efface le répertoire source et le répertoire de build avant de commencer la construction. Ceci est utile pour garantir un build propre et reproductible. - --config-flags=FLAGS Passe FLAGS au système de configuration. - --create-install-dirs Crée les répertoires d’installation nécessaires pour les packages. - -d DIR, --build-dir=DIR Utilise DIR comme répertoire de build. Par défaut, il s’agit de _build. - --debug-allocations Active le traçage des allocations mémoire. - --debug-backtraces Active les backtraces pour tous les événements. - --debug-dependency-graphs Imprime les graphes de dépendances dans le répertoire de build. - --debug-ml-backtraces Imprime les backtraces OCaml pour tous les événements. - --debug-runtime-config Affiche la configuration d’exécution de Dune. - --delete-old-install-files Supprime les anciens fichiers d’installation avant d’en créer de nouveaux. - --display=VAL Contrôle l’affichage de la sortie de Dune. Les modes disponibles sont: auto, silent, readable, short, verbose, very-verbose. Par défaut, il s’agit de auto. - --dry-run Ne fait rien, se contente d’imprimer les actions qui seraient exécutées. - --dump-ast-all Décharge la représentation AST de tous les modules. - --dump-binary-asts Décharge les ASTs binaires des modules. - --dump-dot Décharge le graphe des dépendances au format DOT. - --external-filter=REGEX N’exécute pas les règles externes correspondant à REGEX. - --file-syntax-error=FILE Affiche la ligne où se trouve l’erreur, si elle est dans FILE. - --finalize-file=FILE Écrit le fichier de finalisation dans FILE. - --flush-history Efface l’historique des reconstructions. - --force-install-all Force l’installation de tous les packages, même s’ils n’ont pas changé. - --for-release Met dune en mode release reproductible. Raccourci pour --root . --ignore-promoted-rules --no-config --profile release --always-show-command-line --promote-install-files --require-dune-project-file --default-target @install. Vous devriez utiliser cette option pour les builds de release. Par exemple, vous devez utiliser cette option dans vos fichiers <package>.opam. Sauf si vous utilisez déjà -p, car -p implique cette option. - --for-release-of-packages=PACKAGES, -p PACKAGES (obligatoire) Raccourci pour --release --only-packages PACKAGE. Vous devez utiliser cette option dans vos fichiers <package>.opam, afin de construire uniquement ce qui est nécessaire lorsque votre projet contient plusieurs packages ainsi que pour obtenir des builds reproductibles. - --ignore-promoted-rules Ignore les règles promues. - --instrument-with=BACKENDS Active l’instrumentation par BACKENDS. BACKENDS est une liste de noms de bibliothèques séparés par des virgules, chacune d’elles devant déclarer un backend d’instrumentation. - --kind=VAL Sélectionne le type de build. Les valeurs possibles sont ocaml, native, native-readonly. - --log-level=VAL Définit le niveau de journalisation. - --no-archive-source Ne pas inclure les sources dans les archives générées. - --no-build Ne pas exécuter de build. - --no-config Ne pas utiliser de fichier de configuration. - --no-check Ne pas vérifier la correction des builds. - --no-parallel Désactive le parallélisme. - --no-print-directory Ne pas imprimer le répertoire de build courant. - --no-promote Désactive la promotion des fichiers générés. - --no-satisfy-dependencies Ne pas satisfaire les dépendances. - --no-tests Ne pas exécuter les tests. - --only-packages=PACKAGES Construit uniquement les packages spécifiés. - --only-effects Construit uniquement les effets. - --output-dependencies-to=FILE Écrit les dépendances dans le fichier spécifié. - --promote-install-files[=VAL] (par défaut=true) Promeut les fichiers <package>.install générés dans l’arbre source. - --profile=VAL (absent DUNE_PROFILE env) Sélectionne le profil de build, par exemple dev ou release. Le profil par défaut est dev. - --require-dune-project-file[=VAL] (par défaut=true) Échoue si un fichier dune-project est manquant. - --restore-project Restaure le projet à son état précédent. - --run-tests Exécute les tests après la construction. - --sandbox=MODE Définit le mode de sandboxing. Les modes possibles sont skip, build, run, native. - --store-orig-source-dir (absent DUNE_STORE_ORIG_SOURCE_DIR env) Stocke l’emplacement source d’origine dans les métadonnées de dune-package. - --strict-dependencies Verifie la stricte dépendance entre les cibles. - --stop-on-test-failure Arrête l’exécution des tests en cas d’échec. - --trace-extended Produit des données de trace étendues (nécessite trace-file). - --trace-file=FILE Produit des données de trace au format catapult (compatible avec chrome://tracing). - --verbose Identique à --display verbose - --version Affiche les informations de version. - --watch Exécute dune en mode surveillance, redéclanchant les builds en cas de changement de fichiers. - --watch-exclusions=REGEX Ajoute une expression régulière POSIX qui exclura les répertoires correspondants de `dune build --watch`. L’option --watch-exclusions peut être répétée pour ajouter plusieurs exclusions. Les points-virgules peuvent également être utilisés comme séparateur. Si aucune exclusion n’est fournie, un ensemble standard d’exclusions est utilisé ; cependant, si une ou plusieurs options --watch-exclusions sont utilisées, aucune des exclusions standard n’est utilisée. Les exclusions standard sont : `^_opam /_opam ^_esy /_esy ^\.#.* /.#.* ~$ ^#[^#]*#$ /#[^#]*#$ ^4913$ /4913$ /.git /.hg :/windows` - --workspace=FILE (absent DUNE_WORKSPACE env) Utilise ce fichier workspace spécifique au lieu de le rechercher. - -x VAL Compile de manière croisée en utilisant cette toolchain. MORE HELP Utilisez `dune COMMAND --help' pour obtenir de l'aide sur une seule commande. EXIT STATUS dune upgrade se termine avec : 0 En cas de succès. 1 Si une erreur s’est produite. 130 Si elle a été interrompue par un signal. ENVIRONMENT Les variables d’environnement suivantes affectent l’exécution de upgrade : DUNE_BUILD_DIR Répertoire de build spécifié. _build si non spécifié DUNE_CACHE Active ou désactive le cache Dune (l’un des disabled, enabled-except-user-rules ou enabled). Par défaut, `enabled-except-user-rules'. DUNE_CACHE_CHECK_PROBABILITY Vérifie la reproductibilité des builds en réexécutant des règles choisies aléatoirement et en comparant leurs résultats avec ceux stockés dans le cache Dune. Remarque : en augmentant la probabilité de telles vérifications, vous ralentissez le build. La probabilité par défaut est zéro, c’est-à-dire qu’aucune règle n’est vérifiée. DUNE_CACHE_STORAGE_MODE Mode de stockage du cache Dune (l’un de auto, hardlink ou copy). Par défaut, `hardlink'. DUNE_DEBUG_PACKAGE_LOGS Imprime toujours les logs standard lors de la construction des packages DUNE_DIFF_COMMAND Commande shell à utiliser pour comparer les fichiers. Utilisez - pour désactiver l’impression de la différence. DUNE_DISABLE_PROMOTION Désactive toutes les règles de promotion DUNE_INSTRUMENT_WITH Active l’instrumentation par BACKENDS. BACKENDS est une liste de noms de bibliothèques séparés par des virgules, chacune d’elles devant déclarer un backend d’instrumentation. DUNE_PROFILE Profil de build. dev si non spécifié ou release si -p est défini. DUNE_SANDBOX Mode de sandboxing à utiliser par défaut. (voir --sandbox) DUNE_STORE_ORIG_SOURCE_DIR Stocke l’emplacement source d’origine dans les métadonnées de dune-package. DUNE_WORKSPACE Utilise ce fichier workspace spécifique au lieu de le rechercher. BUGS Vérifiez les rapports de bugs sur https://github.com/ocaml/dune/issues SEE ALSO dune(1)
