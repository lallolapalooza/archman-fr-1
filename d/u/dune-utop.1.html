NOM

dune-utop - Charger une bibliothèque dans utop.

SYNTAXE

dune utop [OPTION]… [REP] [ARGUMENTS]…

DESCRIPTION

dune utop REP construit et exécute l'interpréteur utop avec les bibliothèques définies dans REP.

OPTIONS

--action-stderr-on-success=VALEUR
Identique à --action-stdout-on-success mais pour la sortie d'erreur standard au lieu de la sortie standard. Une bonne valeur par défaut pour les grands mono-dépôts est --action-stdout-on-success=swallow --action-stderr-on-success=must-be-empty. Cela garantit qu'une construction réussie a une sortie vide et "propre".
--action-stdout-on-success=VALEUR
Spécifie comment traiter la sortie standard des actions lorsqu'elles réussissent. Les valeurs possibles sont : print pour simplement l'afficher dans la sortie de Dune, swallow pour l'ignorer complètement et must-be-empty pour s'assurer que l'action n'a rien affiché. Avec must-be-empty, Dune considérera que l'action a échoué si elle a imprimé quelque chose dans sa sortie standard. La valeur par défaut est print.
--build-info
Afficher les informations de construction.
--context=CONTEXTE (absent=default)
Sélectionne le contexte dans lequel construire/exécuter utop.
--display-separate-messages
Sépare les messages d'erreur par une ligne vide.
--error-reporting=VALEUR (absent=deterministic)
Contrôle quand les erreurs de construction sont signalées. early signale les erreurs dès qu'elles sont découvertes. deterministic signale les erreurs à la fin de la construction dans un ordre déterministe. twice signale chaque erreur deux fois : une fois dès qu'elle est découverte, puis à nouveau à la fin de la construction, dans un ordre déterministe.
-f, --force
Force la réexécution des actions associées aux alias, même si leurs dépendances n'ont pas changé.
--file-watcher=VALEUR (absent=automatic)
Mécanisme pour détecter les changements dans la source. automatic pour faire exécuter un programme externe par dune afin de détecter les changements. manual pour notifier manuellement dune que les fichiers ont changé.
--passive-watch-mode
Similaire à [--watch], mais ne démarre une construction que lorsqu'elle est instruite extérieurement par une RPC.
--sandbox=VALEUR (absent DUNE_SANDBOX env)
Définit le mode de sandboxing. Certaines actions nécessitent un mode de sandboxing particulier, elles ignoreront donc ce réglage. Les valeurs autorisées sont : none, symlink, copy, hardlink.
--stop-on-first-error
Arrête la construction dès qu'une erreur est rencontrée.
-w, --watch
Au lieu de terminer la construction après achèvement, attend en continu les changements de fichiers.
--wait-for-filesystem-clock
Dune hache le contenu des fichiers pour une meilleure incrémentalité. Ces hachages sont eux-mêmes mis en cache. Dans certains cas, Dune doit supprimer certaines entrées de cache de hachage pour que les choses soient fiables. Cette option permet à Dune d'attendre que l'horloge du système de fichiers avance afin de ne pas avoir à supprimer quoi que ce soit. Vous ne devriez probablement pas vous soucier de cette option ; elle est principalement utile aux développeurs de Dune pour rendre les tests de Dune du cache de hachage plus reproductibles.

OPTIONS COMMUNES

Ces options sont communes à toutes les commandes.

--always-show-command-line
Afficher toujours les lignes de commande complètes des programmes exécutés par dune.
--auto-promote
Promeut automatiquement les fichiers. C'est similaire à l'exécution de dune promote après la construction.
--build-dir=FICHIER (absent DUNE_BUILD_DIR env)
Répertoire de construction spécifié. _build s'il n'est pas spécifié.
--cache=VALEUR (absent DUNE_CACHE env)
Active ou désactive le cache de Dune (l'une des valeurs : disabled, enabled-except-user-rules ou enabled). Par défaut, c'est `enabled-except-user-rules'.
--cache-check-probability=VALEUR (absent DUNE_CACHE_CHECK_PROBABILITY env)
Vérifie la reproductibilité de la construction en réexécutant des règles choisies aléatoirement et en comparant leurs résultats avec ceux stockés dans le cache de Dune. Note : augmenter la probabilité de telles vérifications ralentit la construction. La probabilité par défaut est zéro, c'est-à-dire qu'aucune règle n'est vérifiée.
--cache-storage-mode=VALEUR (absent DUNE_CACHE_STORAGE_MODE env)
Mode de stockage du cache de Dune (l'une des valeurs : auto, hardlink ou copy). Par défaut, c'est `hardlink'.
--config-file=FICHIER
Charge ce fichier de configuration au lieu de celui par défaut.
--debug-artifact-substitution
Affiche des informations de débogage sur la substitution d'artefacts.
--debug-backtraces
Affiche toujours les traces d'exception.
--debug-cache=VALEUR
Affiche les messages de débogage en cas de misses de cache pour les couches de cache données. La valeur est une liste de noms de couches de cache séparés par des virgules. Toutes les couches de cache disponibles : shared,workspace-local,fs.
--debug-dependency-path
En cas d'erreur, affiche le chemin des dépendances depuis les cibles sur la ligne de commande jusqu'à la règle qui a échoué.
--debug-digests
Explique pourquoi Dune décide de re-hacher certains fichiers.
--debug-load-dir
Affiche des informations de débogage sur le chargement des répertoires.
--debug-package-logs (absent DUNE_DEBUG_PACKAGE_LOGS env)
Affiche toujours les journaux standard lors de la construction des paquets.
--default-target=CIBLE (absent=@@default)
Définit la cible par défaut utilisée lorsqu'aucune cible n'est spécifiée pour dune build.
--diff-command=VALEUR (absent DUNE_DIFF_COMMAND env)
Commande shell à utiliser pour comparer les fichiers. Utiliser - pour désactiver l'affichage de la différence.
--disable-promotion (absent DUNE_DISABLE_PROMOTION env)
Désactive toutes les règles de promotion.
--display=MODE
Contrôle le mode d'affichage de Dune. Voir dune-config(5) pour plus de détails. Les valeurs valides pour cette option sont progress, verbose, short, quiet ou tui.
--dump-gc-stats=FICHIER
Sauvegarde les statistiques du garbage collector dans un fichier après l'achèvement de la construction.
--dump-memo-graph=FICHIER
Sauvegarde le graphe de dépendances dans un fichier après l'achèvement de la construction.
--dump-memo-graph-format=FORMAT (absent=gexf)
Définit le format de fichier utilisé par --dump-memo-graph
--dump-memo-graph-with-timing
Réexécute chaque nœud mis en cache dans le graphe Memo après la construction et inclut la durée d'exécution dans la sortie de --dump-memo-graph. Comme tous les nœuds contiennent une valeur mise en cache, chaque mesure ne représentera qu'un seul nœud.
--help[=FORMAT] (défaut=auto)
Affiche cette aide au format FORMAT. La valeur FORMAT doit être l'une des suivantes : auto, pager, groff ou plain. Avec auto, le format est pager ou plain lorsque la variable d'environnement TERM est dumb ou non définie.
--ignore-lock-dir
Ignore le répertoire dune.lock/.
--ignore-promoted-rules
Ignore les règles avec (mode promote), sauf celles avec (only ...). La variable %{ignoring_promoted_rules} dans les fichiers dune reflète si cette option a été passée ou non.
--instrument-with=BACKENDS (absent DUNE_INSTRUMENT_WITH env)
Active l'instrumentation par BACKENDS. BACKENDS est une liste de noms de bibliothèques séparés par des virgules, chacun d'eux devant déclarer un backend d'instrumentation.
-j JOBS
Exécute au maximum JOBS commandes simultanément.
--no-buffer
Ne pas mettre en mémoire tampon la sortie des commandes exécutées par dune. Par défaut, dune met en mémoire tampon la sortie des sous-commandes afin d'éviter les entrelacements lorsque plusieurs commandes sont exécutées en parallèle. Cependant, cela peut poser problème lors du débogage de tests longs. Avec --no-buffer, les commandes ont un accès direct au terminal. Notez qu'en conséquence, leur sortie ne sera pas capturée dans le fichier journal. Vous devriez utiliser cette option conjointement avec -j 1, pour éviter les entrelacements. De plus, vous devriez également utiliser --verbose, pour vous assurer que les commandes sont imprimées avant d'être exécutées.
--no-config
Ne pas charger le fichier de configuration.
--no-print-directory
Supprime les messages "Entering directory".
--only-packages=PAQUETS
Ignore les stanzas faisant référence à un paquet qui n'est pas dans PAQUETS. PAQUETS est une liste séparée par des virgules
ed list of package names. Note that this has the same effect as deleting the relevant stanzas from dune files. It is mostly meant for releases. During development, it is likely that what you want instead is to build a particular <package>.install target.
-p PACKAGES, --for-release-of-packages=PACKAGES (required)
Raccourci pour --release --only-packages PACKAGE. Vous devez utiliser cette option dans vos fichiers <package>.opam afin de ne construire que ce qui est nécessaire lorsque votre projet contient plusieurs paquets et également pour obtenir des builds reproductibles.
--print-metrics
Affiche diverses métriques de performance après chaque build.
--profile=VAL (absent DUNE_PROFILE env)
Sélectionne le profil de build, par exemple dev ou release. La valeur par défaut est dev.
--promote-install-files[=VAL] (défaut=true)
Promeut tous les fichiers <package>.install générés dans l'arborescence source.
--release
Met dune en mode release reproductible. Raccourci pour --root . --ignore-promoted-rules --no-config --profile release --always-show-command-line --promote-install-files --require-dune-project-file --default-target @install. Vous devriez utiliser cette option pour les builds de release. Par exemple, vous devez utiliser cette option dans vos fichiers <package>.opam. Sauf si vous utilisez déjà -p, car -p implique cette option.
--require-dune-project-file[=VAL] (défaut=true)
Échoue si un fichier dune-project est manquant.
--root=DIR
Utilise ce répertoire comme racine de l'espace de travail au lieu de le deviner. Notez que cette option ne change pas l'interprétation des cibles données sur la ligne de commande. Elle est principalement destinée aux scripts.
--store-orig-source-dir (absent DUNE_STORE_ORIG_SOURCE_DIR env)
Stocke l'emplacement source d'origine dans les métadonnées dune-package.
--terminal-persistence=MODE
Change la façon dont le journal des résultats de build est affiché sur la console entre les re-builds en mode --watch. Modes supportés : preserve, clear-on-rebuild, clear-on-rebuild-and-flush-history.
--trace-extended
Produit des données de trace étendues (nécessite trace-file).
--trace-file=FILE
Produit des données de trace au format catapult (compatible avec chrome://tracing).
--verbose
Identique à --display verbose
--version
Affiche les informations de version.
--watch-exclusions=REGEX
Ajoute une expression régulière POSIX qui exclura les répertoires correspondants de `dune build --watch`. L'option --watch-exclusions peut être répétée pour ajouter plusieurs exclusions. Des points-virgules peuvent également être utilisés comme séparateur. Si aucune exclusion n'est fournie, un ensemble standard d'exclusions est utilisé ; cependant, si une ou plusieurs options --watch-exclusions sont utilisées, aucune des exclusions standard n'est utilisée. Les exclusions standard sont : ^_opam /_opam ^_esy /_esy ^\.#.* /\.#.* ~$ ^#[^#]*#$ /#[^#]*#$ ^4913$ /4913$ /.git /.hg :/windows
--workspace=FILE (absent DUNE_WORKSPACE env)
Utilise ce fichier d'espace de travail spécifique au lieu de le rechercher.
-x VAL
Compilation croisée en utilisant cette chaîne d'outils.

PLUS D'AIDE

Utilisez `dune COMMAND --help' pour obtenir de l'aide sur une seule commande.

STATUT DE SORTIE

dune utop se termine avec :

0
en cas de succès.
1
si une erreur s'est produite.
130
s'il a été interrompu par un signal.

ENVIRONNEMENT

Ces variables d'environnement affectent l'exécution de utop :

DUNE_BUILD_DIR
Répertoire de build spécifié. _build si non spécifié.
DUNE_CACHE
Active ou désactive le cache Dune (l'un des choix : disabled, enabled-except-user-rules ou enabled). La valeur par défaut est `enabled-except-user-rules'.
DUNE_CACHE_CHECK_PROBABILITY
Vérifie la reproductibilité du build en ré-exécutant des règles choisies aléatoirement et en comparant leurs résultats avec ceux stockés dans le cache Dune. Note : en augmentant la probabilité de ces vérifications, vous ralentissez le build. La probabilité par défaut est zéro, c'est-à-dire qu'aucune règle n'est vérifiée.
DUNE_CACHE_STORAGE_MODE
Mode de stockage du cache Dune (l'un des choix : auto, hardlink ou copy). La valeur par défaut est `hardlink'.
DUNE_DEBUG_PACKAGE_LOGS
Affiche toujours les logs standards lors de la construction des paquets.
DUNE_DIFF_COMMAND
Commande shell à utiliser pour comparer les fichiers. Utilisez - pour désactiver l'affichage du diff.
DUNE_DISABLE_PROMOTION
Désactive toutes les règles de promotion.
DUNE_INSTRUMENT_WITH
Active l'instrumentation par BACKENDS. BACKENDS est une liste de noms de bibliothèques séparés par des virgules, dont chacun doit déclarer un backend d'instrumentation.
DUNE_PROFILE
Profil de build. dev si non spécifié ou release si -p est défini.
DUNE_SANDBOX
Mode de sandboxing à utiliser par défaut. (voir --sandbox)
DUNE_STORE_ORIG_SOURCE_DIR
Stocke l'emplacement source d'origine dans les métadonnées dune-package.
DUNE_WORKSPACE
Utilise ce fichier d'espace de travail spécifique au lieu de le rechercher.
