NOM

dune rules - Afficher les règles.

SYNOPSIS

dune rules [OPTION]… [CIBLE]…

DESCRIPTION

Affiche les règles Dune pour les cibles données. Si aucune cible n'est fournie, affiche toutes les règles.

Par défaut, la sortie est une liste d'expressions S, une expression S par règle. Chaque expression S est de la forme :

  ((deps    (<dépendances>))
   (targets (<cibles>))
   (context <nom-contexte>)
   (action  <action>))

<nom-contexte> est le contexte dans lequel l'action est exécutée. Il est omis si l'action est indépendante du contexte.

<action> est l'action suivant la même syntaxe que les actions utilisateur, comme décrit dans le manuel.

OPTIONS

--action-stderr-on-success=VAL
Identique à --action-stdout-on-success mais pour la sortie d'erreur standard au lieu de la sortie standard. Une bonne valeur par défaut pour les grands monorepôts est --action-stdout-on-success=swallow --action-stderr-on-success=must-be-empty. Cela garantit qu'une construction réussie a une sortie vide et "propre".
--action-stdout-on-success=VAL
Spécifie comment traiter la sortie standard des actions lorsqu'elles réussissent. Les valeurs possibles sont : print pour simplement l'afficher dans la sortie de Dune, swallow pour l'ignorer complètement et must-be-empty pour s'assurer que l'action n'a rien affiché. Avec must-be-empty, Dune considérera que l'action a échoué si elle a affiché quelque chose dans sa sortie standard. La valeur par défaut est print.
--build-info
Afficher les informations de construction.
--display-separate-messages
Séparer les messages d'erreur par une ligne vide.
--error-reporting=VAL (absent=deterministic)
Contrôle quand les erreurs de construction sont rapportées. early rapporte les erreurs dès qu'elles sont découvertes. deterministic rapporte les erreurs à la fin de la construction dans un ordre déterministe. twice rapporte chaque erreur deux fois : une fois dès que l'erreur est découverte et ensuite à la fin de la construction, dans un ordre déterministe.
-f, --force
Forcer la ré-exécution des actions associées aux alias, même si leurs dépendances n'ont pas changé.
--file-watcher=VAL (absent=automatic)
Mécanisme pour détecter les changements dans la source. automatic pour faire exécuter un programme externe par dune pour détecter les changements. manual pour notifier à dune que des fichiers ont changé manuellement.
-m, --makefile
Sortir les règles en syntaxe Makefile.
-o FICHIER
Sortie vers un fichier au lieu de la sortie standard.
--passive-watch-mode
Similaire à [--watch], mais ne démarre une construction que lorsqu'elle est instruite extérieurement par une RPC.
-r, --recursive
Afficher toutes les règles nécessaires pour construire les dépendances transitives des cibles données.
--sandbox=VAL (absent DUNE_SANDBOX env)
Définir le mode sandbox. Certaines actions nécessitent un certain mode sandbox, elles ignoreront donc ce réglage. Les valeurs autorisées sont : none, symlink, copy, hardlink.
--stop-on-first-error
Arrêter la construction dès qu'une erreur est rencontrée.
-w, --watch
Au lieu de terminer la construction après son achèvement, attendre en permanence les changements de fichiers.
--wait-for-filesystem-clock
Dune utilise des hachages de contenu de fichiers pour une meilleure incrémentation. Ces hachages sont eux-mêmes mis en cache. Dans certains cas, Dune doit supprimer certaines entrées du cache de hachage pour que les choses soient fiables. Cette option fait attendre Dune que l'horloge du système de fichiers avance afin qu'elle n'ait pas besoin de supprimer quoi que ce soit. Vous ne devriez probablement pas vous soucier de cette option ; elle est principalement utile aux développeurs de Dune pour rendre les tests de Dune du cache de hachage plus reproductibles.

OPTIONS COMMUNES

Ces options sont communes à toutes les commandes.

--always-show-command-line
Toujours afficher les lignes de commande complètes des programmes exécutés par dune.
--auto-promote
Promouvoir automatiquement les fichiers. C'est similaire à exécuter dune promote après la construction.
--build-dir=FICHIER (absent DUNE_BUILD_DIR env)
Répertoire de construction spécifié. _build si non spécifié
--cache=VAL (absent DUNE_CACHE env)
Activer ou désactiver le cache Dune (l'une des valeurs : disabled, enabled-except-user-rules ou enabled). La valeur par défaut est `enabled-except-user-rules'.
--cache-check-probability=VAL (absent DUNE_CACHE_CHECK_PROBABILITY env)
Vérifier la reproductibilité des constructions en réexécutant des règles choisies aléatoirement et en comparant leurs résultats avec ceux stockés dans le cache Dune. Remarque : augmenter la probabilité de telles vérifications ralentit la construction. La probabilité par défaut est zéro, c'est-à-dire qu'aucune règle n'est vérifiée.
--cache-storage-mode=VAL (absent DUNE_CACHE_STORAGE_MODE env)
Mode de stockage du cache Dune (l'une des valeurs : auto, hardlink ou copy). La valeur par défaut est `hardlink'.
--config-file=FICHIER
Charger ce fichier de configuration au lieu de celui par défaut.
--debug-artifact-substitution
Afficher les informations de débogage sur la substitution d'artefacts
--debug-backtraces
Toujours afficher les traces d'exception.
--debug-cache=VAL
Afficher les messages de débogage lors des échecs de cache pour les couches de cache données. La valeur est une liste séparée par des virgules de noms de couches de cache. Toutes les couches de cache disponibles : shared,workspace-local,fs.
--debug-dependency-path
En cas d'erreur, afficher le chemin de dépendance depuis les cibles de la ligne de commande jusqu'à la règle qui a échoué.
--debug-digests
Expliquer pourquoi Dune décide de rehacher certains fichiers
--debug-load-dir
Afficher les informations de débogage sur le chargement des répertoires
--debug-package-logs (absent DUNE_DEBUG_PACKAGE_LOGS env)
Toujours afficher les logs standards lors de la construction de paquets
--default-target=CIBLE (absent=@@default)
Définir la cible par défaut utilisée lorsqu'aucune n'est spécifiée pour dune build.
--diff-command=VAL (absent DUNE_DIFF_COMMAND env)
Commande shell à utiliser pour comparer les fichiers. Utiliser - pour désactiver l'affichage de la différence.
--disable-promotion (absent DUNE_DISABLE_PROMOTION env)
Désactiver toutes les règles de promotion
--display=MODE
Contrôler le mode d'affichage de Dune. Voir dune-config(5) pour plus de détails. Les valeurs valides pour cette option sont progress, verbose, short, quiet ou tui.
--dump-gc-stats=FICHIER
Exporter les statistiques du garbage collector vers un fichier après la fin de la construction.
--dump-memo-graph=FICHIER
Exporter le graphe de dépendances vers un fichier après la fin de la construction.
--dump-memo-graph-format=FORMAT (absent=gexf)
Définir le format de fichier utilisé par --dump-memo-graph
--dump-memo-graph-with-timing
Réexécuter chaque nœud mis en cache dans le graphe Memo après la construction et inclure la durée d'exécution dans la sortie de --dump-memo-graph. Comme tous les nœuds contiennent une valeur mise en cache, chaque mesure ne représentera qu'un seul nœud.
--help[=FMT] (défaut=auto)
Afficher cette aide au format FMT. La valeur FMT doit être l'une des suivantes : auto, pager, groff ou plain. Avec auto, le format est pager ou plain lorsque la variable d'environnement TERM est dumb ou non définie.
--ignore-lock-dir
Ignorer le répertoire dune.lock/
--ignore-promoted-rules
Ignorer les règles avec (mode promote), sauf celles avec (only ...). La variable %{ignoring_promoted_rules} dans les fichiers dune reflète si cette option a été passée ou non.
--instrument-with=BACKENDS (absent DUNE_INSTRUMENT_WITH env)
Activer l'instrumentation par BACKENDS. BACKENDS est une liste de noms de bibliothèques séparés par des virgules, chacune d'elles devant déclarer un backend d'instrumentation.
-j JOBS
Exécuter au maximum JOBS commandes simultanément.
--no-buffer
Ne pas mettre en mémoire tampon la sortie des commandes exécutées par dune. Par défaut, dune met en mémoire tampon la sortie des sous-commandes, afin d'éviter les entrelacements lorsque plusieurs commandes sont exécutées en parallèle. Cependant, cela peut poser problème lors du débogage de longues

--promote-install-files[=VAL] (défaut=true)
Promouvoir tous les fichiers <package>.install générés vers l'arborescence source.
--release
Met dune en mode release reproductible. Raccourci pour --root . --ignore-promoted-rules --no-config --profile release --always-show-command-line --promote-install-files --require-dune-project-file --default-target @install. Vous devriez utiliser cette option pour les builds de release. Par exemple, vous devez utiliser cette option dans vos fichiers <package>.opam . Sauf si vous utilisez déjà -p, car -p implique cette option.
--require-dune-project-file[=VAL] (défaut=true)
Échoue si un fichier dune-project est manquant.
--root=DIR
Utiliser ce répertoire comme racine de l'espace de travail au lieu de le deviner. Notez que cette option ne change pas l'interprétation des cibles données sur la ligne de commande. Elle n'est destinée qu'aux scripts.
--store-orig-source-dir (absent DUNE_STORE_ORIG_SOURCE_DIR env)
Stocker l'emplacement source original dans les métadonnées dune-package.
--terminal-persistence=MODE
Change la façon dont le journal des résultats de build est affiché sur la console entre les rebuilds en mode --watch . Modes supportés : preserve, clear-on-rebuild, clear-on-rebuild-and-flush-history.
--trace-extended

--verbose

--version
Affiche les informations de version.
--watch-exclusions=REGEX

-x VAL

PLUS D'AIDE

Utilisez `dune COMMAND --help' pour obtenir de l'aide sur une seule commande.

CODES DE SORTIE

dune rules se termine avec :

0
en cas de succès.
1
si une erreur s'est produite.
130
s'il a été interrompu par un signal.

ENVIRONNEMENT

Ces variables d'environnement affectent l'exécution de rules:

DUNE_BUILD_DIR
Répertoire de build spécifié. _build si non spécifié
DUNE_CACHE
Active ou désactive le cache Dune (l'un de disabled, enabled-except-user-rules ou enabled). La valeur par défaut est `enabled-except-user-rules'.
DUNE_CACHE_CHECK_PROBABILITY
Vérifie la reproductibilité du build en ré-exécutant des règles choisies aléatoirement et en comparant leurs résultats avec ceux stockés dans le cache Dune. Note : en augmentant la probabilité de telles vérifications, vous ralentissez le build. La probabilité par défaut est zéro, c'est-à-dire qu'aucune règle n'est vérifiée.
DUNE_CACHE_STORAGE_MODE
Mode de stockage du cache Dune (l'un de auto, hardlink ou copy). La valeur par défaut est `hardlink'.
DUNE_DEBUG_PACKAGE_LOGS
Affiche toujours les journaux standard lors de la construction des paquets
DUNE_DIFF_COMMAND
Commande shell à utiliser pour comparer des fichiers. Utilisez - pour désactiver l'affichage de la différence.
DUNE_DISABLE_PROMOTION
Désactive toutes les règles de promotion
DUNE_INSTRUMENT_WITH
Active l'instrumentation par BACKENDS. BACKENDS est une liste de noms de bibliothèques séparés par des virgules, chacun devant déclarer un backend d'instrumentation.
DUNE_PROFILE
Profil de build. dev si non spécifié ou release si -p est défini.
DUNE_SANDBOX
Mode de bac à sable à utiliser par défaut. (voir --sandbox)
DUNE_STORE_ORIG_SOURCE_DIR
Stocker l'emplacement source original dans les métadonnées dune-package.
DUNE_WORKSPACE
Utiliser ce fichier d'espace de travail spécifique au lieu de le rechercher.
