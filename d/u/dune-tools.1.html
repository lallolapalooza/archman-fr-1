NOM

dune-tools - Groupe de commandes pour les outils encapsulés.

SYNTAXE

dune tools COMMANDE …

COMMANDES

exec COMMANDE …
Groupe de commandes pour exécuter des outils encapsulés.
install COMMANDE …
Groupe de commandes pour installer des outils encapsulés.
which COMMANDE …
Groupe de commandes pour afficher le chemin vers les outils encapsulés.

OPTIONS COMMUNES

--help[=FMT] (par défaut=auto)
Afficher cette aide au format FMT. La valeur FMT doit être l'une de auto, pager, groff ou plain. Avec auto, le format est pager ou plain lorsque la variable d'environnement TERM est dumb ou indéfinie.
--version
Afficher les informations de version.

STATUT DE SORTIE

dune tools se termine avec :

0
en cas de succès.
1
en cas d'erreur.
130
s'il a été interrompu par un signal.
