NOM

dune-ocaml - Groupe de commandes lié à OCaml.

SYNTAXE

dune ocaml COMMANDE …

COMMANDES

doc [OPTION]…
Construit et affiche la documentation d'un projet OCaml
dump-dot-merlin [OPTION]… [CHEMIN]
Affiche la configuration de Merlin
merlin COMMANDE …
Groupe de commandes lié à merlin
ocaml-merlin [OPTION]…
Démarre un serveur de configuration merlin.
top [OPTION]… [REP]
Affiche une liste de directives de toplevel pour inclure des répertoires et charger des fichiers cma.
top-module [OPTION]… MODULE
Affiche une liste de directives de toplevel pour charger un module dans le toplevel.
utop [OPTION]… [REP] [ARGS]…
Charge une bibliothèque dans utop.

OPTIONS COMMUNES

--help[=FMT] (par défaut=auto)
Affiche cette aide au format FMT. La valeur FMT doit être l'un des choix auto, pager, groff ou plain. Avec auto, le format est pager ou plain lorsque la variable d'environnement TERM est dumb ou non définie.
--version
Affiche les informations de version.

STATUT DE SORTIE

dune ocaml se termine avec :

0
en cas de succès.
1
si une erreur s'est produite.
130
s'il a été interrompu par un signal.
