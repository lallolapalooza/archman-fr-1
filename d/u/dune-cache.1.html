NOM

dune-cache - Gérer le cache partagé des artefacts de build de Dune.

SYNOPIS

dune cache COMMANDE …

DESCRIPTION

Dune peut partager les artefacts de build entre différents espaces de travail. Nous ne prenons actuellement en charge que quelques sous-commandes ; cependant, nous prévoyons de proposer davantage de fonctionnalités bientôt.

COMMANDES

clear [OPTION]…
Vider le cache de Dune.
size [--machine-readable] [OPTION]…
Interroger la taille du cache de Dune.
trim [--size=OCTETS] [--trimmed-size=OCTETS] [OPTION]…
Réduire la taille du cache de Dune.

OPTIONS COMMUNES

--help[=FMT] (défaut=auto)
Afficher cette aide au format FMT. La valeur FMT doit être l'une des suivantes : auto, pager, groff ou plain. Avec auto, le format est pager ou plain lorsque la variable d'environnement TERM est dumb ou non définie.
--version
Afficher les informations de version.

STATUT DE SORTIE

dune cache se termine avec :

0
en cas de succès.
1
si une erreur s'est produite.
130
s'il a été interrompu par un signal.
