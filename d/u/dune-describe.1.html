NOM

dune-describe - Décrire l'espace de travail.

SYNOPSIS

dune describe [COMMANDE] …

DESCRIPTION

Décrire ce qui se trouve dans l'espace de travail courant sous une forme lisible par l'humain ou par la machine. Par défaut, cette commande produit une description lisible par l'humain de l'espace de travail courant. Cette sortie est destinée à l'humain et n'est pas adaptée au traitement par une machine. En particulier, elle n'est pas versionnée. Si vous souhaitez interpréter la sortie de cette commande depuis un programme, vous devez utiliser l'option --format pour spécifier un format lisible par la machine ainsi que l'option --lang pour obtenir une sortie stable.

COMMANDES

aliases [OPTION]… [DIR]…
Afficher les alias dans un répertoire donné. Fonctionne de manière similaire à ls.
contexts [OPTION]…
Lister les contextes de construction disponibles dans l'espace de travail.
depexts [OPTION]…
Afficher la liste de tous les depexts disponibles
env [OPTION]… [PATH]
Afficher l'environnement d'un répertoire.
external-lib-deps [OPTION]…
Afficher les bibliothèques externes nécessaires pour construire le projet. C'est un ensemble approximatif de bibliothèques.
installed-libraries [OPTION]…
Afficher les bibliothèques installées sur le système.
location [OPTION]… PROG
Afficher le chemin vers l'exécutable en utilisant la même logique de résolution que [dune exec].
opam-files [OPTION]…
Afficher des informations sur les fichiers opam qui ont été découverts.
package-entries [OPTION]…
afficher des informations sur les entrées par paquet.
pkg COMMANDE …
Sous-commandes liées à la gestion des paquets
pp [OPTION]… FILE
Construire un FILE donné et afficher la sortie prétraitée.
rules [OPTION]… [TARGET]…
Vider les règles.
targets [OPTION]… [DIR]…
Afficher les cibles dans un répertoire donné. Fonctionne de manière similaire à ls.
workspace [OPTION]… [DIRS]…
Afficher une description de la structure de l'espace de travail. Si des répertoires DIRS sont fournis, alors seuls ces répertoires de l'espace de travail sont considérés.

ARGUMENTS

afficher une description de la structure de l'espace de travail. Si des répertoires DIRS sont fournis, alors seuls ces répertoires de l'espace de travail sont considérés.

OPTIONS

--action-stderr-on-success=VAL
Identique à --action-stdout-on-success mais pour la sortie d'erreur standard au lieu de la sortie standard. Un bon défaut pour les grands mono-repertoires est --action-stdout-on-success=swallow --action-stderr-on-success=must-be-empty. Cela garantit qu'une construction réussie a une sortie vide "propre".
--action-stdout-on-success=VAL
Spécifier comment traiter la sortie standard des actions lorsqu'elles réussissent. Les valeurs possibles sont : print pour simplement l'imprimer dans la sortie de Dune, swallow pour l'ignorer complètement et must-be-empty pour imposer que l'action n'ait rien imprimé. Avec must-be-empty, Dune considérera que l'action a échoué si elle a imprimé quelque chose sur sa sortie standard. La valeur par défaut est print.
--build-info
Afficher les informations de construction.
--context=CONTEXT (absent=default)
Contexte de construction à utiliser.
--display-separate-messages
Séparer les messages d'erreur par une ligne vide.
--error-reporting=VAL (absent=deterministic)
Contrôle quand les erreurs de construction sont rapportées. early rapporte les erreurs dès qu'elles sont découvertes. deterministic rapporte les erreurs à la fin de la construction dans un ordre déterministe. twice rapporte chaque erreur deux fois : une fois dès que l'erreur est découverte, puis à nouveau à la fin de la construction, dans un ordre déterministe.
-f, --force
Forcer la ré-exécution des actions associées aux alias même si leurs dépendances n'ont pas changé.
--file-watcher=VAL (absent=automatic)
Mécanisme pour détecter les changements dans la source. Automatic pour faire exécuter à dune un programme externe pour détecter les changements. Manual pour notifier dune que les fichiers ont changé manuellement.
--format=FORMAT (absent=sexp)
FORMAT doit être soit sexp soit csexp
--lang=VERSION (absent=0.1)
Se comporter de la même manière que cette version de Dune.
--passive-watch-mode
Similaire à [--watch], mais ne démarrer une construction que lorsqu'instructé de l'extérieur par un RPC.
--sandbox=VAL (absent DUNE_SANDBOX env)
Définir le mode de bac à sable. Certaines actions nécessitent un certain mode de bac à sable, elles ignoreront donc ce paramètre. Les valeurs autorisées sont : none, symlink, copy, hardlink.
--sanitize-for-tests
Assainir les chemins absolus dans les éléments de l'espace de travail, et les UID associés, afin que la sortie soit reproductible.
--stop-on-first-error
Arrêter la construction dès qu'une erreur est rencontrée.
-w, --watch
Au lieu de terminer la construction après son achèvement, attendre continuellement les changements de fichiers.
--wait-for-filesystem-clock
Dune calcule des empreintes du contenu des fichiers pour une meilleure incrémentalité. Ces empreintes sont elles-mêmes mises en cache. Dans certains cas, Dune doit supprimer certaines entrées du cache d'empreintes pour que les choses soient fiables. Cette option fait attendre à Dune l'avancement de l'horloge du système de fichiers afin qu'il n'ait pas à supprimer quoi que ce soit. Vous ne devriez probablement pas vous soucier de cette option ; elle est principalement utile aux développeurs de Dune pour rendre les tests de Dune sur le cache d'empreintes plus reproductibles.
--with-deps
Si les dépendances entre modules doivent être imprimées.
--with-pps
Si les dépendances vers les ppx-rewriters (qui sont appelés à la compilation) doivent être prises en compte.
