DUMP.F2FS(8) Manuel du gestionnaire système DUMP.F2FS(8)

NOM

dump.f2fs - récupérer les entrées de répertoire et de fichier d'une image formatée F2FS

SYNTAXE

dump.f2fs [ -i numéro d'inode ] [ -I numéro d'inode ] [ -n plage NAT ] [ -M carte de blocs ] [ -s plage SIT ] [ -a plage SSA ] [ -b adresse de bloc ] [ -d niveau de débogage ] périphérique

DESCRIPTION

dump.f2fs est utilisé pour récupérer les métadonnées f2fs (généralement dans une partition de disque). périphérique est le fichier spécial correspondant au périphérique (par exemple, /dev/sdXX).

Actuellement, il peut récupérer 1) un fichier étant donné son numéro d'inode, 2) les entrées NAT dans un fichier, 3) les entrées SIT dans un fichier, 4) les entrées SSA dans un fichier, 5) des informations inverses depuis l'adresse de bloc donnée.

Le code de sortie renvoyé par dump.f2fs est 0 en cas de succès et -1 en cas d'échec.

OPTIONS

-i numéro d'inode
Spécifie un numéro d'inode à extraire.
-I numéro d'inode
Spécifie un numéro d'inode et analyse tout le disque pour extraire, y compris le bloc d'inode historique
-n plage NAT
Spécifie une plage présentée par des nids pour extraire les entrées NAT.
-M carte de blocs
Affiche toutes les adresses de blocs allouées étant donné le numéro d'inode.
-s plage SIT
Spécifie une plage présentée par des numéros de segment pour extraire les entrées SIT.
-a plage SSA
Spécifie une plage présentée par des numéros de segment pour extraire les entrées SSA.
-b adresse de bloc
Spécifie une adresse de bloc pour récupérer ses informations métadonnées.
-d niveau de débogage
Spécifie le niveau des options de débogage. Le numéro par défaut est 0, qui affiche des messages de débogage de base.
