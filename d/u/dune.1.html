EXEMPLE

S
1.
Initialise un nouveau projet nommé `foo':
      dune init project foo
2.
Compile toutes les cibles dans l'arborescence source actuelle :
      dune build
3.
Exécute l'exécutable nommé `bar':
      dune exec bar
4.
Exécute tous les tests dans l'arborescence source actuelle :
      dune runtest
5.
Installe tous les composants définis dans le projet :
      dune install
6.
Supprime tous les artefacts de construction :
      dune clean
