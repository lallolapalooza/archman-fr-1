NOM

dune-config - configuration du système de construction dune

SYNTAXE

~/.config/dune/config

DESCRIPTION

À moins que --no-config ou -p ne soit passé, Dune lira un fichier de configuration depuis le répertoire personnel de l'utilisateur. Ce fichier est utilisé pour contrôler divers aspects du comportement de Dune.

Le fichier de configuration est normalement ~/.config/dune/config sur les systèmes Unix et Local Settings/dune/config dans le répertoire personnel de l'utilisateur sous Windows. Cependant, il est possible de spécifier un fichier de configuration alternatif avec l'option --config-file.

La première ligne du fichier doit être de la forme (lang dune X.Y) où X.Y est la version du langage dune utilisée dans le fichier.

Le reste du fichier doit être écrit en syntaxe S-expression et être composé d'une liste de strophes. Les sections suivantes décrivent les strophes disponibles.

MISE EN CACHE

Syntaxe : (cache ENABLED)


Cette strophe détermine si la mise en cache de construction de dune est activée. Voir https://dune.readthedocs.io/en/stable/caching.html pour plus de détails. Les valeurs valides pour ENABLED sont enabled ou disabled.

MODES D'AFFICHAGE

Syntaxe : (display MODE)

Cette strophe contrôle la manière dont Dune rapporte ce qu'il fait à l'utilisateur. Ce paramètre peut également être défini depuis la ligne de commande via --display MODE. Les modes d'affichage suivants sont disponibles :

progress
C'est le défaut, Dune affiche et met à jour une ligne de statut à mesure que les objectifs de construction sont achevés.
quiet
N'afficher que les erreurs.
short
Imprimer une ligne par commande exécutée, avec le nom du binaire à gauche et la raison de son exécution à droite.
verbose
Imprimer les lignes de commande complètes des programmes exécutés par Dune, avec quelques couleurs pour aider à différencier les programmes.

Notez que lorsque le mode d'affichage sélectionné est progress et que la sortie n'est pas un terminal, le mode quiet est sélectionné à la place. Cette règle ne s'applique pas lors de l'exécution de Dune dans Emacs. Dune détecte s'il est exécuté depuis Emacs ou non en examinant la variable d'environnement INSIDE_EMACS qui est définie par Emacs. Si vous souhaitez le même comportement avec un autre éditeur, vous pouvez définir cette variable. Si votre éditeur définit déjà une autre variable, veuillez ouvrir un ticket sur le projet GitHub ocaml/dune afin que nous puissions y ajouter le support.

JOBS

Syntaxe : (jobs NUMBER)

Définit le nombre maximum de tâches que Dune peut exécuter en parallèle. Ceci peut également être défini depuis la ligne de commande via -j NUMBER.

La valeur par défaut pour ce paramètre est le nombre de processeurs.

SANDBOXING

Syntaxe : (sandboxing_preference MODE ...)

Contrôle l'ordre de préférence des modes de sandboxing utilisés par dune. Dune utilisera le premier élément de cette liste qui est autorisé par la spécification des dépendances d'action, ou utilisera la valeur par défaut codée en dur. Voir man dune-build pour la description des modes individuels.

BUGS

Vérifiez les rapports de bugs sur https://github.com/ocaml/dune/issues
