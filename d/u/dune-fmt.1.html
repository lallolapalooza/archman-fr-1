NOM

dune-fmt - Formater le code source.

SYNOPSIS

dune fmt [OPTION]…

DESCRIPTION

dune fmt exécute le formateur sur le code source. Le formateur est sélectionné automatiquement. ocamlformat est utilisé pour formater le code source OCaml (fichiers *.ml et *.mli) et refmt est utilisé pour formater le code source Reason (fichiers *.re et *.rei).

OPTIONS

--action-stderr-on-success=VAL
Identique à --action-stdout-on-success mais pour la sortie d'erreur standard au lieu de la sortie standard. Un bon défaut pour les grands mono-dépôts est --action-stdout-on-success=swallow --action-stderr-on-success=must-be-empty. Cela garantit qu'une compilation réussie a une sortie "propre" et vide.
--action-stdout-on-success=VAL
Spécifie comment traiter la sortie standard des actions lorsqu'elles réussissent. Les valeurs possibles sont : print pour simplement l'afficher dans la sortie de Dune, swallow pour l'ignorer complètement, et must-be-empty pour imposer que l'action n'ait rien imprimé. Avec must-be-empty, Dune considérera que l'action a échoué si elle a imprimé quelque chose sur sa sortie standard. La valeur par défaut est print.
--build-info
Afficher les informations de compilation.
--display-separate-messages
Séparer les messages d'erreur par une ligne vide.
--error-reporting=VAL (absent=deterministic)
Contrôle quand les erreurs de compilation sont signalées. early signale les erreurs dès qu'elles sont découvertes. deterministic signale les erreurs à la fin de la compilation dans un ordre déterministe. twice signale chaque erreur deux fois : une fois dès qu'elle est découverte, puis à nouveau à la fin de la compilation, dans un ordre déterministe.
-f, --force
Forcer la ré-exécution des actions associées aux alias même si leurs dépendances n'ont pas changé.
--file-watcher=VAL (absent=automatic)
Mécanisme pour détecter les changements dans la source. Automatic pour faire exécuter à dune un programme externe pour détecter les changements. Manual pour notifier dune que des fichiers ont changé manuellement.
--passive-watch-mode
Similaire à [--watch], mais ne lance une compilation que lorsqu'il est instructé de le faire par un RPC externe.
--preview
Simplement imprimer les changements qui seraient faits sans les appliquer réellement. Cela prend le dessus sur la promotion automatique car cette option est supposée activée pour cette commande.
--sandbox=VAL (absent DUNE_SANDBOX env)
Définir le mode de bac à sable. Certaines actions nécessitent un certain mode de bac à sable, elles ignoreront donc ce paramètre. Les valeurs autorisées sont : none, symlink, copy, hardlink.
--stop-on-first-error
Arrêter la compilation dès qu'une erreur est rencontrée.
-w, --watch
Au lieu de terminer la compilation après son achèvement, attendre continuellement les changements de fichiers.
--wait-for-filesystem-clock
Dune calcule des empreintes du contenu des fichiers pour une meilleure incrémentalité. Ces empreintes sont elles-mêmes mises en cache. Dans certains cas, Dune doit supprimer certaines entrées du cache d'empreintes pour que les choses soient fiables. Cette option fait attendre Dune que l'horloge du système de fichiers avance afin qu'il n'ait pas besoin de supprimer quoi que ce soit. Vous ne devriez probablement pas vous soucier de cette option ; elle est principalement utile aux développeurs de Dune pour rendre les tests de Dune du cache d'empreintes plus reproductibles.

OPTIONS COMMUNES

Ces options sont communes à toutes les commandes.

--always-show-command-line
Toujours afficher les lignes de commande complètes des programmes exécutés par dune.
--auto-promote
Promouvoir automatiquement les fichiers. Cela revient à exécuter dune promote après la compilation.
--build-dir=FILE (absent DUNE_BUILD_DIR env)
Répertoire de compilation spécifié. _build si non spécifié
--cache=VAL (absent DUNE_CACHE env)
Activer ou désactiver le cache Dune (l'un de disabled, enabled-except-user-rules ou enabled). La valeur par défaut est `enabled-except-user-rules'.
--cache-check-probability=VAL (absent DUNE_CACHE_CHECK_PROBABILITY env)
Vérifier la reproductibilité de la compilation en ré-exécutant des règles choisies aléatoirement et en comparant leurs résultats avec ceux stockés dans le cache Dune. Note : en augmentant la probabilité de telles vérifications, vous ralentissez la compilation. La probabilité par défaut est zéro, c'est-à-dire qu'aucune règle n'est vérifiée.
--cache-storage-mode=VAL (absent DUNE_CACHE_STORAGE_MODE env)
Mode de stockage du cache Dune (l'un de auto, hardlink ou copy). La valeur par défaut est `hardlink'.
--config-file=FILE
Charger ce fichier de configuration au lieu du fichier par défaut.
--debug-artifact-substitution
Afficher des informations de débogage sur la substitution d'artefacts
--debug-backtraces
Toujours afficher les backtraces des exceptions.
--debug-cache=VAL
Afficher des messages de débogage sur les manques de cache pour les couches de cache données. La valeur est une liste de noms de couches de cache séparés par des virgules. Toutes les couches de cache disponibles : shared,workspace-local,fs.
--debug-dependency-path
En cas d'erreur, afficher le chemin de dépendance depuis les cibles sur la ligne de commande jusqu'à la règle qui a échoué.
--debug-digests
Expliquer pourquoi Dune décide de recalculer l'empreinte de certains fichiers
--debug-load-dir
Afficher des informations de débogage sur le chargement des répertoires
--debug-package-logs (absent DUNE_DEBUG_PACKAGE_LOGS env)
Toujours afficher les journaux standard lors de la compilation des paquets
--default-target=TARGET (absent=@@default)
Définir la cible par défaut qui est utilisée lorsqu'aucune n'est spécifiée pour dune build.
--diff-command=VAL (absent DUNE_DIFF_COMMAND env)
Commande shell à utiliser pour comparer les fichiers. Utilisez - pour désactiver l'affichage du diff.
--disable-promotion (absent DUNE_DISABLE_PROMOTION env)
Désactiver toutes les règles de promotion
--display=MODE
Contrôler le mode d'affichage de Dune. Voir dune-config(5) pour plus de détails. Les valeurs valides pour cette option sont progress, verbose, short, quiet ou tui.
--dump-gc-stats=FILE
Écrire les statistiques du ramasse-miettes dans un fichier après que la compilation est terminée.
--dump-memo-graph=FILE
Écrire le graphe de dépendances dans un fichier après que la compilation est terminée.
--dump-memo-graph-format=FORMAT (absent=gexf)
Définir le format de fichier utilisé par --dump-memo-graph
--dump-memo-graph-with-timing
Ré-exécuter chaque nœud mis en cache dans le graphe Memo après la compilation et inclure la durée d'exécution dans la sortie de --dump-memo-graph. Comme tous les nœuds contiennent une valeur en cache, chaque mesure ne comptera que pour un seul nœud.
--help[=FMT] (par défaut=auto)
Afficher cette aide au format FMT. La valeur FMT doit être l'une de auto, pager, groff ou plain. Avec auto, le format est pager ou plain lorsque la variable d'environnement TERM est dumb ou indéfinie.
--ignore-lock-dir
Ignorer le répertoire dune.lock/.
--ignore-promoted-rules
Ignorer les règles avec (mode promote), sauf celles avec (only ...). La variable %{ignoring_promoted_rules} dans les fichiers dune reflète si cette option a été passée ou non.
--instrument-with=BACKENDS (absent DUNE_INSTRUMENT_WITH env)
Activer l'instrumentation par BACKENDS. BACKENDS est une liste de noms de bibliothèques séparés par des virgules, chacun devant déclarer un backend d'instrumentation.
-j JOBS
Exécuter pas plus de JOBS commandes simultanément.
--no-buffer
Ne pas mettre en tampon la sortie des commandes exécutées par dune. Par défaut, dune met en tampon la sortie des sous-commandes, afin d'éviter l'entrelacement lorsque plusieurs commandes sont exécutées en parallèle. Cependant, cela peut poser problème lors du débogage de tests de longue durée. Avec --no-buffer, les commandes ont un accès direct au terminal. Notez qu'en conséquence leur sortie ne sera pas capturée dans le fichier journal. Vous devriez utiliser cette option en conjonction avec -j 1, pour éviter l'entrelacement. De plus, vous devriez utiliser --verbose également, pour vous assurer que les commandes sont imprimées avant d'être exécutées.
--no-config
Ne pas charger le fichier de configuration
--no-print-directory
Supprimer Messages « Entering directory ».
--only-packages=PACKAGES
Ignore les stanzas faisant référence à un paquet qui n'est pas dans PACKAGES. PACKAGES est une liste de noms de paquets séparés par des virgules. Notez que cela a le même effet que de supprimer les stanzas pertinentes des fichiers dune. C'est principalement destiné aux releases. Pendant le développement, il est probable que ce que vous voulez à la place est de construire une cible <package>.install particulière.
-p PACKAGES, --for-release-of-packages=PACKAGES (requis)
Raccourci pour --release --only-packages PACKAGE. Vous devez utiliser cette option dans vos fichiers <package>.opam , afin de ne construire que ce qui est nécessaire lorsque votre projet contient plusieurs paquets ainsi que pour obtenir des builds reproductibles.
--print-metrics
Affiche diverses métriques de performance après chaque build.
--profile=VAL (absent DUNE_PROFILE env)
Sélectionne le profil de build, par exemple dev ou release. La valeur par défaut est dev.
--promote-install-files[=VAL] (par défaut=true)
Promouvoir tous les fichiers <package>.install générés vers l'arborescence source.
--release
Met dune en mode release reproductible. Raccourci pour --root . --ignore-promoted-rules --no-config --profile release --always-show-command-line --promote-install-files --require-dune-project-file --default-target @install. Vous devriez utiliser cette option pour les builds de release. Par exemple, vous devez utiliser cette option dans vos fichiers <package>.opam . Sauf si vous utilisez déjà -p, car -p implique cette option.
--require-dune-project-file[=VAL] (par défaut=true)
Échoue si un fichier dune-project est manquant.
--root=DIR
Utiliser ce répertoire comme racine de l'espace de travail au lieu de le deviner. Notez que cette option ne change pas l'interprétation des cibles données sur la ligne de commande. Elle n'est destinée qu'aux scripts.
--store-orig-source-dir (absent DUNE_STORE_ORIG_SOURCE_DIR env)
Stocker l'emplacement source d'origine dans les métadonnées dune-package.
--terminal-persistence=MODE
Change la façon dont le journal des résultats de build est affiché sur la console entre les rebuilds en mode --watch . Modes pris en charge : preserve, clear-on-rebuild, clear-on-rebuild-and-flush-history.
--trace-extended
Produit des données de trace étendues (nécessite trace-file).
--trace-file=FILE
Produit des données de trace au format catapult (compatible avec chrome://tracing).
--verbose
Identique à --display verbose
--version
Affiche les informations de version.
--watch-exclusions=REGEX
Ajoute une expression rationnelle POSIX qui exclura les répertoires correspondants de `dune build --watch`. L'option --watch-exclusions peut être répétée pour ajouter plusieurs exclusions. Les points-virgules peuvent aussi être utilisés comme séparateur. Si aucune exclusion n'est fournie, un ensemble standard d'exclusions est utilisé ; cependant, si une ou plusieurs --watch-exclusions sont utilisées, aucune des exclusions standard n'est utilisée. Les exclusions standard sont : ^_opam /_opam ^_esy /_esy ^\.#.* /\.#.* ~$ ^#[^#]*#$ /#[^#]*#$ ^4913$ /4913$ /.git /.hg :/windows
--workspace=FILE (absent DUNE_WORKSPACE env)
Utiliser ce fichier d'espace de travail spécifique au lieu de le rechercher.
-x VAL
Compilation croisée en utilisant cette chaîne d'outils.

PLUS D'AIDE

Utilisez `dune COMMAND --help' pour obtenir de l'aide sur une seule commande.

STATUT DE SORTIE

dune fmt se termine avec :

0
en cas de succès.
1
si une erreur s'est produite.
130
s'il a été interrompu par un signal.

ENVIRONNEMENT

Ces variables d'environnement affectent l'exécution de fmt:

CLICOLOR
Si différent de 0, les couleurs ANSI sont prises en charge et devraient être utilisées lorsque le programme n'est pas dans un pipe. Si égal à 0, ne pas produire de codes d'échappement de couleur ANSI
CLICOLOR_FORCE
Si différent de 0, les couleurs ANSI devraient être activées quoi qu'il arrive.
DUNE_BUILD_DIR
Répertoire de build spécifié. _build si non spécifié
DUNE_CACHE
Activer ou désactiver le cache Dune (un parmi disabled, enabled-except-user-rules ou enabled). Par défaut est `enabled-except-user-rules'.
DUNE_CACHE_CHECK_PROBABILITY
Vérifier la reproductibilité du build en ré-exécutant des règles choisies aléatoirement et en comparant leurs résultats avec ceux stockés dans le cache Dune. Note : en augmentant la probabilité de telles vérifications, vous ralentissez le build. La probabilité par défaut est zéro, c'est-à-dire qu'aucune règle n'est vérifiée.
DUNE_CACHE_ROOT
Si défini, détermine l'emplacement du cache partagé global de la machine.
DUNE_CACHE_STORAGE_MODE
Mode de stockage du cache Dune (un parmi auto, hardlink ou copy). Par défaut est `hardlink'.
DUNE_DEBUG_PACKAGE_LOGS
Toujours afficher les journaux standard lors de la construction des paquets
DUNE_DIFF_COMMAND
Commande shell à utiliser pour comparer des fichiers. Utilisez - pour désactiver l'affichage de la différence.
DUNE_DISABLE_PROMOTION
Désactiver toutes les règles de promotion
DUNE_INSTRUMENT_WITH
Activer l'instrumentation par BACKENDS. BACKENDS est une liste de noms de bibliothèques séparés par des virgules, chacun devant déclarer un backend d'instrumentation.
DUNE_PROFILE
Profil de build. dev si non spécifié ou release si -p est défini.
DUNE_SANDBOX
Mode de bac à sable à utiliser par défaut. (voir --sandbox)
DUNE_STORE_ORIG_SOURCE_DIR
Stocker l'emplacement source d'origine dans les métadonnées dune-package.
DUNE_WORKSPACE
Utiliser ce fichier d'espace de travail spécifique au lieu de le rechercher.
