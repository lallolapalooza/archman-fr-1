DESCRIPTIO

N

Dunst est un démon de notifications hautement configurable et

léger.

Démarrage automatique de

dunst

Sur la plupart des installations, dunst devrait pouvoir être démarré automatiquement par D-Bus lorsqu'une notification e

st envoyée. Ceci n'est pas recommandé lorsque plusieurs démons de notifications sont installés, car D-Bus ne saura pas l
equel démarrer. D'autres moyens de démarrer dunst automatiquement incluent le démarrage de dunst avec la fonctionnalité
de démarrage automatique de votre environnement de bureau ou gestionnaire de fenêtres, ou via le service systemd fourni.

CONFIGURATIO

N

Un fichier de configuration par défaut est inclus (généralement /etc/dunst/dunstrc) et sert de fichier de configuration de moindre importance. Note : c'était auparavant /usr/share/dunst/dunstrc. Vous pouvez modifier ce fichier pour changer les valeurs par défaut au niveau du système ou le copier dans un emplacement plus important pour remplacer ses paramètres. Voir la section FICHIERS pour plus de détails sur les endroits où dunst recherche ses fichiers de configuration et la manière dont les paramètres sont

appliqués.

Voir dunst(5) pour tous les paramètres

possibles.

INDICES

NOTIFY-SEND

Dunst est capable d'obtenir différentes couleurs pour un message via notify-send. Pour ce faire, vous devez ajouter un indice via l'option -h. La valeur de progression peut également être définie avec un

indice.

Voir dunst(5) pour la liste des indices

acceptés.

Quelques exemples

:

notify-send -h string:bgcolor:#4444ff -h string:fgcolor:#ff4444 -h string:frcolor:#44ff44

DIVER

S

Dunst peut être mis en pause via la commande `dunstctl set-paused true`. Pour reprendre dunst, utilisez `dunstctl set-paused false`. Une autre manière est d'envoyer SIGUSR1 et SIGUSR2 pour mettre en pause et reprendre respectivement. L'utilisation de dunstctl pour la pause est recommandée par rapport à l'utilisation des signaux, car la signification des signaux n'est pas stable et pourrait changer à

l'avenir.

Lorsqu'il est en pause, dunst n'affichera aucune notification, mais conservera toutes les notifications dans une file d'at

tente. Cela peut par exemple être placé autour d'un verrouilleur d'écran (i3lock, slock) pour empêcher le clignotement des
notifications à travers le verrouillage, et pour lire toutes les notifications manquées après être revenu à l'ordinateur.

Dunst recherchera dans ces répertoires les chemins de fichiers relatifs suivants

dunst/dunst
rc
C'est la configuration de base et en tant que telle la moins importante dans un répertoire de base
particulier.
dunst/dunstrc.d/*.
conf
Ce sont des « drop-ins » (attention au suffixe « .d » du répertoire). Ils sont plus importants que le dunstrc de base du répertoire parent, car ils sont considérés comme de petits extraits pour remplacer des paramètres. Le dernier en ordre lexicographique est le plus important, vous pouvez donc facilement changer l'ordre en les renommant. Une approche courante pour nommer les drop-ins est de les préfixer avec des chiffres, c'est-à-dire : 
00-least-important.conf
01-foo.conf
20-bar.conf
99-most-important.
conf
