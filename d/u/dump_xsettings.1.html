DUMP_XSETTINGS(1) Manuel des commandes générales DUMP_XSETTINGS(1)

NOM

dump_xsettings - imprime les paramètres des applications X11 à partir d'un fournisseur XSETTINGS

SYNTAXE

dump_xsettings [options]

DESCRIPTION

La spécification XSETTINGS fournit une méthode pour notifier les applications X11 des changements dans les paramètres du système. dump_xsettings imprime les paramètres actuels d'un écran X en utilisant le format de fichier de configuration de xsettingsd(1).

OPTIONS

-h, --help
Affiche un message d'aide et quitte.
-s, --screen=ECRAN
Utilise l'écran X numéroté ECRAN (par défaut 0).
