DUMPIMAGE(1) Manuel des commandes générales DUMPIMAGE(1)

NOM

dumpimage - extraire des données des images U-Boot

SYNTAXE

dumpimage [-T type] -l image
dumpimage [-T type] [-p position] -o fichier_sortie image
dumpimage -h
dumpimage -V

DESCRIPTION

dumpimage liste et extrait des données des images U-Boot. Si -l est spécifié, dumpimage liste les composants dans image. Sinon, dumpimage extrait le composant à la position spécifiée vers fichier_sortie.

OPTIONS

-h
Affiche les informations d'utilisation et quitte.
-l
Affiche les informations d'en-tête pour image, y compris une liste des composants.
-o fichier_sortie
Le fichier dans lequel écrire le composant extrait.
-p position
Spécifie la position du composant à extraire. Il doit s'agir d'un index numérique, commençant à 0. Si non spécifiée, la position par défaut est 0.
-T type
Spécifie le type de l'image. Si non spécifié, le type de l'image sera automatiquement détecté. Une liste des types d'images pris en charge peut être affichée en exécutant mkimage -T list.
-V
Affiche les informations de version et quitte.

BOGUES

Veuillez signaler les bogues sur le suivi des bogues de U-Boot.

EXEMPLES

Créer une image multi-fichiers puis extraire une partie de cette image

$ 
mkimage -A x86 -O linux -T multi -n x86 \
-d vmlinuz:initrd.img:System.map multi.img
Image Name:   x86
Created:      Thu Jul 25 10:29:13 2013
Image Type:   Intel x86 Linux Multi-File Image (gzip compressed)
Data Size:    13722956 Bytes = 13401.32 kB = 13.09 MB
Load Address: 00000000
Entry Point:  00000000
Contents:
   Image 0: 4040128 Bytes = 3945.44 kB = 3.85 MB
   Image 1: 7991719 Bytes = 7804.41 kB = 7.62 MB
   Image 2: 1691092 Bytes = 1651.46 kB = 1.61 MB
$ 
dumpimage -p 2 -o System.map multi.img
