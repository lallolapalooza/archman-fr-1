duplocale(3) Manuel des fonctions de bibliothèque duplocale(3)

NOM

duplocale - dupliquer un objet locale

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <locale.h>
locale_t duplocale(locale_t locobj);
Exigences pour le macro de test de fonctionnalité glibc (voir feature_test_macros(7)):

duplocale():

    Depuis glibc 2.10 :
        _XOPEN_SOURCE >= 700
    Avant glibc 2.10 :
        _GNU_SOURCE

DESCRIPTION

La fonction duplocale() crée une copie de l'objet locale référencé par locobj.

Si locobj est LC_GLOBAL_LOCALE, duplocale() crée un objet locale contenant une copie de la locale globale déterminée par setlocale(3).

VALEUR DE RETOUR

En cas de succès, duplocale() renvoie un descripteur pour le nouvel objet locale. En cas d'erreur, elle renvoie (locale_t) 0 et définit la variable errno pour indiquer l'erreur.

ERREURS

ENOMEM
Mémoire insuffisante pour créer l'objet locale dupliqué.

NORMES

POSIX.1-2008.

HISTORIQUE

glibc 2.3.

NOTES

La duplication d'une locale peut servir aux objectifs suivants :

•
Pour créer une copie d'un objet locale dans lequel une ou plusieurs catégories doivent être modifiées (en utilisant newlocale(3)).
•
Pour obtenir un descripteur de la locale actuelle qui peut être utilisé dans d'autres fonctions qui emploient un descripteur de locale, telles que toupper_l(3). Ceci est fait en appliquant duplocale() à la valeur renvoyée par l'appel suivant :

loc = uselocale((locale_t) 0);

Cette technique est nécessaire, car l'appel ci-dessus à uselocale(3) peut renvoyer la valeur LC_GLOBAL_LOCALE, ce qui entraîne un comportement indéfini si elle est passée à des fonctions telles que toupper_l(3). Appeler duplocale() peut être utilisé pour s'assurer que la valeur LC_GLOBAL_LOCALE est convertie en un objet locale utilisable. Voir EXEMPLES, ci-dessous.

Chaque objet locale créé par duplocale() doit être désalloué à l'aide de freelocale(3).

EXEMPLES

Le programme ci-dessous utilise uselocale(3) et duplocale() pour obtenir un descripteur de la locale actuelle qui est ensuite passé à toupper_l(3). Le programme prend un argument de ligne de commande, une chaîne de caractères qui est convertie en majuscules et affichée sur la sortie standard. Un exemple de son utilisation est le suivant :


$ ./a.out abc;
ABC

Source du programme

#define _XOPEN_SOURCE 700
#include <ctype.h>
#include <err.h>
#include <locale.h>
#include <stdio.h>
#include <stdlib.h>
int
main(int argc, char *argv[])
{
    locale_t loc, nloc;
    if (argc != 2) {
        fprintf(stderr, "Usage: %s string\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    /* Cette séquence est nécessaire, car uselocale() peut renvoyer
       la valeur LC_GLOBAL_LOCALE, qui ne peut pas être passée comme
       argument à toupper_l().  */
    loc = uselocale((locale_t) 0);
    if (loc == (locale_t) 0)
        err(EXIT_FAILURE, "uselocale");
    nloc = duplocale(loc);
    if (nloc == (locale_t) 0)
        err(EXIT_FAILURE, "duplocale");
    for (char *p = argv[1]; *p; p++)
        putchar(toupper_l(*p, nloc));
    printf("\n");
    freelocale(nloc);
    exit(EXIT_SUCCESS);
}
