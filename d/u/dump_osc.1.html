NOM

dump_osc - Affiche les messages OSC entrants

SYNTAXE

dump_osc port

DESCRIPTION

dump_osc affiche tous les messages OSC reçus sur le port (numéro de port UDP, ou toute autre chaîne d'adresse prise en charge par liblo).
