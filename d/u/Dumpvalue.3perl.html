Dumpvalue(3perl) Guide de référence des programmeurs Perl Dumpvalue(3perl)

NOM

Dumpvalue - fournit une impression d'écran des données Perl.

SYNTAXE

use Dumpvalue;
my $dumper = Dumpvalue->new;
$dumper->set(globPrint => 1);
$dumper->dumpValue(\*::);
$dumper->dumpvars('main');
my $dump = $dumper->stringify($some_value);

DESCRIPTION

Création

Un nouveau dump est créé par un appel

$d = Dumpvalue->new(option1 => valeur1, option2 => valeur2)

Options reconnues :

"arrayDepth", "hashDepth"
Imprimer uniquement les N premiers éléments des tableaux et des hachages. Si faux, imprime tous les éléments.
"compactDump", "veryCompact"
Modifier le style des dump de tableaux et de hachages. Si vrai, un tableau court peut être imprimé sur une seule ligne.
"globPrint"
Indique s'il faut imprimer le contenu des globs.
"dumpDBFiles"
Dump les tableaux contenant le contenu des fichiers débogués.
"dumpPackages"
Dump les tables de symboles des paquets.
"dumpReused"
Dump le contenu des adresses « réutilisées ».
"tick", "quoteHighBit", "printUndef"
Modifier le style des dump de chaînes. La valeur par défaut de "tick" est "auto", on peut activer soit le dump entre guillemets doubles, soit entre apostrophes en le définissant à """ ou "'". Par défaut, les caractères avec le bit de poids fort activé sont imprimés *tels quels*. Si "quoteHighBit" est défini, ils seront mis entre guillemets.
"usageOnly"
Dump rudimentaire d'utilisation mémoire par paquet. Si défini, "dumpvars" calcule la taille totale des chaînes dans les variables du paquet.
unctrl
Modifie le style d'impression des chaînes. Les valeurs possibles sont "unctrl" et "quote".
subdump
Indique s'il faut essayer de trouver le nom de la sous-routine à partir de la référence.
bareStringify
Indique s'il faut écrire la forme non surchargée des objets avec surcharge de stringify.
quoteHighBit
Indique s'il faut imprimer les caractères avec le bit de poids fort activé en binaire ou *tels quels*.
stopDbSignal
Indique s'il faut abandonner l'impression si le signal du débogueur est activé.

Plus tard dans la vie de l'objet, les méthodes peuvent être interrogées avec la méthode get() et la méthode set() (qui acceptent plusieurs arguments).

Méthodes

dumpValue
$dumper->dumpValue($valeur);
$dumper->dumpValue([$valeur1, $valeur2]);

Imprime un dump sur le fichier actuellement sélectionné.

dumpValues
$dumper->dumpValues($valeur1, $valeur2);

Identique à "$dumper->dumpValue([$valeur1, $valeur2]);".

stringify
my $dump = $dumper->stringify($valeur [,$noticks] );

Retourne le dump d'un seul scalaire sans l'imprimer. Si le second argument est vrai, la valeur de retour ne contient pas de guillemets englobants. Ne gère pas les structures de données.

dumpvars
$dumper->dumpvars('mon_paquet');
$dumper->dumpvars('mon_paquet', 'foo', '~bar$', '!......');

Les arguments optionnels sont considérés comme des chaînes littérales sauf s'ils commencent par "~" ou "!", auquel cas ils sont interprétés comme des expressions régulières (possiblement niées).

Le second exemple imprime les entrées avec le nom "foo", ainsi que les entrées dont le nom se termine par "bar", ou est plus court que 5 caractères.

set_quote
$d->set_quote('"');

Définit les options "tick" et "unctrl" à des valeurs appropriées pour l'impression avec le caractère de guillemet donné. Les valeurs possibles sont "auto", "'" et """.

set_unctrl
$d->set_unctrl('unctrl');

Définit l'option "unctrl" en vérifiant les arguments invalides. Les valeurs possibles sont "unctrl" et "quote".

compactDump
$d->compactDump(1);

Définit l'option "compactDump". Si la valeur est 1, elle est définie à un grand nombre raisonnable.

veryCompact
$d->veryCompact(1);

Définit les options "compactDump" et "veryCompact" simultanément.

set
$d->set(option1 => valeur1, option2 => valeur2);
get
@valeurs = $d->get('option1', 'option2');
