NOM

dumpexfat - décharger le système de fichiers exFAT

SYNTAXE

dumpexfat [ -s ] [ -u ] [ -f fichier ] [ -V ] périphérique

DESCRIPTION

dumpexfat décharge les détails du système de fichiers exFAT, y compris les informations de bas niveau. Toutes les tailles sont en octets.

OPTIONS

Options de ligne de commande disponibles :

-s
Décharger uniquement les informations du super bloc. Peut être utile pour les systèmes de fichiers fortement corrompus.
-u
Décharger les plages de secteurs utilisés en commençant par 0 et séparées par des espaces. Peut être utile pour les outils de sauvegarde.
-f fichier
Afficher une liste des fragments qui composent le fichier donné. Chaque fragment est affiché sur sa propre ligne, sous forme de décalage de début (en octets) dans le système de fichiers, et de longueur (en octets).
-V
Afficher la version et le copyright.

CODES DE RETOUR

Zéro est retourné en cas de succès. Tout autre code signifie une erreur.
