NOM

dumpseg - afficher les informations de segment de NILFS2

SYNTAXE

dumpseg [-hV]

dumpseg [périphérique] numéro-de-segment ...

DESCRIPTION

Le programme dumpseg est un outil d'analyse des journaux sur disque d'un système de fichiers NILFS2 trouvé dans périphérique. Il affiche la configuration de chaque journal stocké dans les segments spécifiés par un ou plusieurs numéros-de-segment. Le terme segment désigne ici un bloc contigu de blocs disque constituant une unité d'allocation de l'espace disque de NILFS2. Lorsque périphérique est omis, il essaie de trouver un système de fichiers NILFS2 actif à partir de /proc/mounts.

dumpseg est un outil de débogage plutôt qu'un outil d'administration. Pour lister un résumé des segments, lssu(1) est disponible à la place.

OPTIONS

-h, --help
Afficher le message d'aide et quitter.
-V, --version
Afficher la version et quitter.

DESCRIPTION DES CHAMPS

dumpseg affiche la configuration de chaque journal avec les champs suivants, où chaque champ est imprimé dans le style «nom-du-champ = valeur».

date de création
Date et heure de création du journal.
nfinfo
Nombre de résumés d'informations de fichier.
finfo
Résumé des informations de fichier. Ces informations commencent par les champs suivants :
ino
Numéro d'inode du fichier.
cno
Numéro du point de contrôle auquel appartiennent les blocs inclus dans le fichier. Pour les écritures normales, c'est le dernier numéro de point de contrôle. Pour les écritures impliquées dans le nettoyage de la mémoire (garbage collection), cela indique un numéro de point de contrôle précédent.
nblocks
Nombre de blocs du fichier écrits dans le journal. Ce nombre est la somme du nombre de blocs de données et de blocs de nœuds B-tree. Le contenu de ces blocs est écrit séquentiellement dans la partie payload du journal. Seuls les blocs modifiés ou nouvellement créés sont écrits dans chaque journal.
ndatblk
Nombre de blocs de données du fichier écrits dans le journal.
Ensuite, pour chaque bloc de mise à jour du fichier, les informations suivantes suivront ces en-têtes.
vblocknr
Numéro de bloc virtuel. Non affiché pour les blocs de données du fichier de traduction d'adresses disque (fichier DAT).
blkoff
Numéro de décalage de bloc. Non affiché pour les blocs de nœuds B-tree, sauf pour le fichier DAT.
level
Niveau du bloc de nœud B-tree. Affiché uniquement pour le fichier DAT.
blocknr
Adresse du bloc sur le périphérique. Ce n'est pas un champ réel dans le résumé, mais il est calculé à partir de l'adresse disque de chaque journal.
