NOM

dub-generate - Génère les fichiers de projet en utilisant le générateur spécifié

SYNOPSIS

dub generate <générateur> [<paquet>[@<spécification-version>]] OPTIONS...

DESCRIPTION

Génère les fichiers de projet en utilisant l'un des générateurs supportés :

visuald - Fichiers de projet VisualD

sublimetext - Fichier de projet SublimeText

cmake - Scripts de construction CMake

build - Construit le paquet directement

Un nom de paquet optionnel peut être donné pour générer un paquet différent de celui de la racine/CWD.

OPTIONS

-b, --build=VALEUR

Spécifie le type de construction à effectuer. Notez que la définition de la variable d'environnement DFLAGS remplacera le type de construction par des drapeaux personnalisés. Noms possibles :
debug, plain, release, release-debug, release-nobounds, unittest, profile, profile-gc, docs, ddox, cov, cov-ctfe, unittest-cov, unittest-cov-ctfe, syntax et types personnalisés

-c, --config=VALEUR

Construit la configuration spécifiée. Les configurations peuvent être définies dans dub.json

--override-config=VALEUR

Utilise la configuration spécifiée pour une dépendance donnée. Peut être spécifié plusieurs fois. Format : --override-config=<dépendance>/<config>

--compiler=VALEUR

Spécifie le binaire du compilateur à utiliser (peut être un chemin). Des préfixes et suffixes arbitraires aux identifiants ci-dessous sont reconnus (par exemple, ldc2 ou dmd-2.063) et correspondent au type de compilateur approprié :
dmd, gdc, ldc, gdmd, ldmd

-a, --arch=VALEUR

Force une architecture différente (par exemple, x86 ou x86_64)

-d, --debug=VALEUR

Définit l'identifiant de version `debug` spécifié lors de la construction - peut être utilisé plusieurs fois

--d-version=VALEUR

Définit l'identifiant `version` spécifié lors de la construction - peut être utilisé plusieurs fois. À utiliser avec parcimonie, un grand pouvoir implique de grandes responsabilités ! Pour les versions couramment utilisées ou combinées et les versions que les dépendants doivent pouvoir utiliser, créez des configurations dans votre paquet.

--nodeps

Ne résout pas les dépendances manquantes avant la construction

--build-mode=VALEUR

Spécifie la manière dont le compilateur et l'éditeur de liens sont invoqués. Valeurs valides :
separate (par défaut), allAtOnce, singleFile

--single

Traite le nom du paquet comme un nom de fichier. Le fichier doit contenir un commentaire de recette de paquet.

--force-remove

Option obsolète qui ne fait rien.

--filter-versions

[Expérimental] Filtre les identifiants de version et les identifiants de version de débogage pour améliorer l'efficacité du cache de construction.

--combined

Essaie de construire l'ensemble du projet en une seule compilation.

--print-builds

Affiche la liste des types de construction disponibles

--print-configs

Affiche la liste des configurations disponibles

--print-platform

Affiche les identifiants de la plateforme de construction actuelle tels qu'utilisés pour les champs de construction dans dub.json

--parallel

Exécute plusieurs instances du compilateur en parallèle, si possible.

OPTIONS COMMUNES

Voir dub(1)

STATUT DE SORTIE

0
DUB a réussi
1
erreurs d'utilisation, drapeaux de ligne de commande inconnus
2
paquet non trouvé, échec du chargement du paquet, erreur diverse
