NOM

dumpe2fs - exporter les informations du système de fichiers ext2/ext3/ext4

SYNTAXE

dumpe2fs [ -bfghixV ] [ -o superbloc=superbloc ] [ -o taille_bloc=taille_bloc ] périphérique

DESCRIPTION

dumpe2fs affiche le superbloc et les informations des groupes de blocs du système de fichiers présent sur périphérique.

Le spécificateur périphérique peut être un nom de fichier (par ex. /dev/sda1), ou un spécificateur LABEL ou UUID : "LABEL=label-volume" ou "UUID=uuid". (par ex. LABEL=home ou UUID=e40486c6-84d5-4f2f-b99c-032281799c9d).

Note : Lors de l'utilisation avec un système de fichiers monté, les informations affichées peuvent être obsolètes ou incohérentes.

OPTIONS

-b
affiche les blocs réservés comme défectueux dans le système de fichiers.
-o superbloc=superbloc
utilise le bloc superbloc lors de l'examen du système de fichiers. Cette option n'est généralement pas nécessaire, sauf pour un expert en systèmes de fichiers qui examine les restes d'un système de fichiers très gravement corrompu.
-o taille_bloc=taille_bloc
utilise des blocs de taille_bloc octets lors de l'examen du système de fichiers. Cette option n'est généralement pas nécessaire, sauf pour un expert en systèmes de fichiers qui examine les restes d'un système de fichiers très gravement corrompu.
-f
force dumpe2fs à afficher un système de fichiers même s'il possède des indicateurs de fonctionnalités que dumpe2fs pourrait ne pas comprendre (et qui peuvent rendre suspecte une partie de l'affichage de dumpe2fs).
-g
affiche les informations des descripteurs de groupe dans un format lisible par machine, séparé par des deux-points. Les champs affichés sont le numéro du groupe ; le numéro du premier bloc du groupe ; l'emplacement du superbloc (ou -1 s'il n'est pas présent) ; la plage de blocs utilisée par les descripteurs de groupe (ou -1 s'il n'est pas présent) ; l'emplacement du bitmap de blocs ; l'emplacement du bitmap d'inodes ; et la plage de blocs utilisée par la table d'inodes.
-h
affiche uniquement les informations du superbloc et aucun détail sur les descripteurs de groupe.
-i
affiche les données du système de fichiers à partir d'un fichier image créé par e2image, en utilisant périphérique comme chemin d'accès au fichier image.
-m
Si la fonctionnalité mmp est activée sur le système de fichiers, vérifie si périphérique est utilisé par un autre nœud, voir e2mmpstatus(8) pour plus de détails. Si elle est utilisée avec l'option -i, seules les informations du bloc MMP sont affichées.
-x
affiche les numéros de blocs des informations détaillées du groupe au format hexadécimal
-V
affiche le numéro de version de dumpe2fs et quitte.

CODE DE SORTIE

dumpe2fs se termine avec un code de retour de 0 si l'opération s'est terminée sans erreur. Il se terminera avec un code de retour non nul en cas d'erreurs, telles que des problèmes de lecture d'un superbloc valide, des sommes de contrôle incorrectes, ou si le périphérique est utilisé par un autre nœud et que -m est spécifié.

BOGUES

Vous devrez peut-être connaître la structure physique du système de fichiers pour comprendre la sortie.
