NOM

dune-rpc - Mécanisme RPC de Dune. Expérimental.

SYNTAXE

dune rpc COMMANDE …

DESCRIPTION

Ceci est expérimental. Ne pas utiliser.

COMMANDES

build [OPTION]… [CIBLE]…
Construit une cible donnée (nécessite que dune soit en cours d'exécution en mode de surveillance passive).
ping [OPTION]…
Envoie un ping au serveur de build en cours d'exécution dans le répertoire courant.
status [OPTION]…
Affiche les connexions actives.

OPTIONS COMMUNES

Ces options sont communes à toutes les commandes.

--help[=FMT] (par défaut=auto)
Affiche cette aide dans le format FMT. La valeur FMT doit être l'une des suivantes : auto, pager, groff ou plain. Avec auto, le format est pager ou plain lorsque la variable d'environnement TERM est dumb ou non définie.
--version
Affiche les informations sur la version.

AIDE SUPPLÉMENTAIRE

Utilisez `dune COMMANDE --help' pour obtenir de l'aide sur une commande individuelle.

STATUT DE SORTIE

dune rpc se termine avec :

0
en cas de succès.
1
si une erreur s'est produite.
130
s'il a été interrompu par un signal.

BOGUES

Vérifiez les rapports de bogues sur https://github.com/ocaml/dune/issues
