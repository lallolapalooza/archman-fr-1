DDRGEV3

But :

!>
!> DDRGEV3 vérifie la routine pilote du problème de valeurs propres généralisées non symétriques DGGEV3.
!>
!> DGGEV3 calcule pour une paire de matrices non symétriques n par n (A,B) les
!> valeurs propres généralisées et, en option, les vecteurs propres
!> gauche et droit.
!>
!> Une valeur propre généralisée pour une paire de matrices (A,B) est un scalaire w
!> ou un rapport  alpha/beta = w, tel que A - w*B soit singulière.  Elle est
!> généralement représentée sous la forme de la paire (alpha,beta), car il existe une interprétation raisonnable
!> pour beta=0, et même pour les deux étant nuls.
!>
!> Un vecteur propre généralisé droit correspondant à une valeur
!> propre généralisée  w  pour une paire de matrices (A,B) est un vecteur r  tel que
!> (A - wB) * r = 0.  Un vecteur propre généralisé gauche est un vecteur l tel
!> que l**H * (A - wB) = 0, où l**H est le conjugué-transposé de l.
!>
!> Lorsque DDRGEV3 est appelé, un nombre de matrices  () et un
!> nombre de matrices  sont spécifiés.  Pour chaque taille ()
!> et chaque type de matrice, une paire de matrices (A, B) sera générée
!> et utilisée pour les tests.  Pour chaque paire de matrices, les tests suivants
!> seront effectués et comparés au seuil THRESH.
!>
!> Résultats de DGGEV3 :
!>
!> (1)  max sur toutes les paires valeur propre/vecteur gauche (alpha/beta,l) de
!>
!>      | VL**H * (beta A - alpha B) |/( ulp max(|beta A|, |alpha B|) )
!>
!>      où VL**H est le conjugué-transposé de VL.
!>
!> (2)  | |VL(i)| - 1 | / ulp et si la plus grande composante est réelle
!>
!>      VL(i) désigne la i-ème colonne de VL.
!>
!> (3)  max sur toutes les paires valeur propre/vecteur gauche (alpha/beta,r) de
!>
!>      | (beta A - alpha B) * VR | / ( ulp max(|beta A|, |alpha B|) )
!>
!> (4)  | |VR(i)| - 1 | / ulp et si la plus grande composante est réelle
!>
!>      VR(i) désigne la i-ème colonne de VR.
!>
!> (5)  W(full) = W(partial)
!>      W(full) désigne les valeurs propres calculées lorsque l et r
!>      sont également calculés, et W(partial) désigne les valeurs propres
!>      calculées lorsque seul W, seul W et r, ou seul W et l sont
!>      calculés.
!>
!> (6)  VL(full) = VL(partial)
!>      VL(full) désigne les vecteurs propres gauche calculés lorsque l
!>      et r sont calculés, et VL(partial) désigne le résultat
!>      lorsque seul l est calculé.
!>
!> (7)  VR(full) = VR(partial)
!>      VR(full) désigne les vecteurs propres droit calculés lorsque l
!>      et r sont également calculés, et VR(partial) désigne le résultat
!>      lorsque seul l est calculé.
!>
!>
!> Matrices de test
!> ---- --------
!>
!> Les tailles des matrices de test sont spécifiées par un tableau
!> NN(1:NSIZES) ; la valeur de chaque élément NN(j) spécifie une taille.
!> Les  sont spécifiées par un tableau logique DOTYPE( 1:NTYPES ) ; si
!> DOTYPE(j) est .TRUE., alors le type de matrice  sera généré.
!> Actuellement, la liste des types possibles est :
!>
!> (1)  ( 0, 0 )         (une paire de matrices nulles)
!>
!> (2)  ( I, 0 )         (une matrice identité et une matrice nulle)
!>
!> (3)  ( 0, I )         (une matrice identité et une matrice nulle)
!>
!> (4)  ( I, I )         (une paire de matrices identité)
!>
!>         t   t
!> (5)  ( J , J  )       (une paire de blocs de Jordan transposés)
!>
!>                                     t                ( I   0  )
!> (6)  ( X, Y )         où  X = ( J   0  )  et Y = (      t )
!>                                  ( 0   I  )          ( 0   J  )
!>                       et I est une identité k x k et J un bloc de Jordan (k+1)x(k+1)
!>                       ; k=(N-1)/2
!>
!> (7)  ( D, I )         où D est diag( 0, 1,..., N-1 ) (une matrice
!>                       diagonale avec ces éléments diagonaux.)
!> (8)  ( I, D )
!>
!> (9)  ( big*D, small*I ) où  est proche du débordement et small=1/big
!>
!> (10) ( small*D, big*I )
!>
!> (11) ( big*I, small*D )
!>
!> (12) ( small*I, big*D )
!>
!> (13) ( big*D, big*I )
!>
!> (14) ( small*D, small*I )
!>
!> (15) ( D1, D2 )        où D1 est diag( 0, 0, 1, ..., N-3, 0 ) et
!>                        D2 est diag( 0, N-3, N-4,..., 1, 0, 0 )
!>           t   t
!> (16) Q ( J , J ) Z     où Q et Z sont des matrices orthogonales aléatoires.
!>
!> (17) Q ( T1, T2 ) Z    où T1 et T2 sont des matrices triangulaires supérieures
!>                        avec des éléments O(1) aléatoires au-dessus de la diagonale
!>                        et des éléments diagonaux diag(T1) =
!>                        ( 0, 0, 1, ..., N-3, 0 ) et diag(T2) =
!>                        ( 0, N-3, N-4,..., 1, 0, 0 )
!>
!> (18) Q ( T1, T2 ) Z    diag(T1) = ( 0, 0, 1, 1, s, ..., s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1,..., 1, 0 )
!>                        s = précision machine.
!>
!> (19) Q ( T1, T2 ) Z    diag(T1)=( 0,0,1,1, 1-d, ..., 1-(N-5)*d=s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0 )
!>
!>                                                        N-5
!> (20) Q ( T1, T2 ) Z    diag(T1)=( 0, 0, 1, 1, a, ..., a   =s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0, 0 )
!>
!> (21) Q ( T1, T2 ) Z    diag(T1)=( 0, 0, 1, r1, r2, ..., r(N-4), 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0, 0 )
!>                        où r1,..., r(N-4) sont aléatoires.
!>
!> (22) Q ( big*T1, small*T2 ) Z    diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (23) Q ( small*T1, big*T2 ) Z    diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (24) Q ( small*T1, small*T2 ) Z  diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (25) Q ( big*T1, big*T2 ) Z      diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (26) Q ( T1, T2 ) Z     où T1 et T2 sont des matrices triangulaires supérieures
!>                         aléatoires.
!>
!>

Paramètres

NSIZES 
!>          NSIZES est un entier
!>          Le nombre de tailles de matrices à utiliser. Si c'est zéro,
!>          DDRGEV3 ne fait rien.  NSIZES >= 0.
!>

NN

!>          NN est un tableau d'entiers, de dimension (NSIZES)
!>          Un tableau contenant les tailles à utiliser pour les matrices.
!>          Les valeurs zéro seront ignorées.  NN >= 0.
!>

NTYPES

!>          NTYPES est un entier
!>          Le nombre d'éléments dans DOTYPE.   Si c'est zéro, DDRGEV3
!>          ne fait rien.  Il doit être supérieur ou égal à zéro.  Si c'est MAXTYP+1
!>          et NSIZES est 1, alors un type supplémentaire, MAXTYP+1 est
!>          défini, qui consiste à utiliser la matrice présente dans A.  Ceci
!>          n'est utile que si DOTYPE(1:MAXTYP) est .FALSE. et
!>          DOTYPE(MAXTYP+1) est .TRUE. .
!>

DOTYPE

!>          DOTYPE est un tableau logique, de dimension (NTYPES)
!>          Si DOTYPE(j) est .TRUE., alors pour chaque taille dans NN, une
!>          matrice de cette taille et de type j sera générée.
!>          Si NTYPES est plus petit que le nombre maximum de types
!>          définis (PARAMETER MAXTYP), alors les types NTYPES+1 jusqu'à
!>          MAXTYP ne seront pas générés. Si NTYPES est plus grand
!>          que MAXTYP, DOTYPE(MAXTYP+1) à DOTYPE(NTYPES)
!>          seront ignorés.
!>

ISEED

!>          ISEED est un tableau d'entiers, de dimension (4)
!>          À l'entrée, ISEED spécifie la graine du générateur de nombres
!>          aléatoires. Les éléments du tableau doivent être compris entre 0 et 4095;
!>          sinon, ils seront réduits modulo 4096. De plus, ISEED(4) doit
!>          être impair.  Le générateur de nombres aléatoires utilise une séquence
!>          congruentielle linéaire limitée à de petits entiers, et devrait
!>          produire des nombres aléatoires indépendants de la machine. Les
!>          valeurs de ISEED sont modifiées à la sortie, et peuvent être utilisées dans
!>          l'appel suivant à DDRGEV3 pour continuer la même séquence de nombres
!>          aléatoires.
!>

THRESH

!>          THRESH est un nombre réel double précision
!>          Un test sera considéré comme réussi si le rapport d'erreur, calculé
!>          comme décrit ci-dessus, dépasse THRESH.  Notez que l'erreur est
!>          normalisée pour être d'ordre O(1), donc THRESH devrait être un multiple raisonnablement petit
!>          de 1, par exemple, 10 ou 100.  En particulier, il ne doit pas dépendre de la précision (simple ou double) ou de la taille
!>          de la matrice.  Il doit être supérieur ou égal à zéro.
!>

NOUNIT

!>          NOUNIT est un entier
!>          Le numéro d'unité FORTRAN pour l'impression des messages d'erreur
!>          (par exemple, si une routine renvoie IERR différent de 0.)
!>

A

!>          A est un tableau de nombres réels double précision,
!>                                       de dimension(LDA, max(NN))
!>          Utilisé pour contenir la matrice A d'origine. Utilisé en entrée seulement
!>          si NTYPES=MAXTYP+1, DOTYPE(1:MAXTYP)=.FALSE., et
!>          DOTYPE(MAXTYP+1)=.TRUE.
!>

LDA

!>          LDA est un entier
!>          La dimension principale de A, B, S, et T.
!>          Elle doit être au moins 1 et au moins max( NN ).
!>

B

!>          B est un tableau de nombres réels double précision,
!>                                       de dimension(LDA, max(NN))
!>          Utilisé pour contenir la matrice B d'origine. Utilisé en entrée seulement
!>          si NTYPES=MAXTYP+1, DOTYPE(1:MAXTYP)=.FALSE., et
!>          DOTYPE(MAXTYP+1)=.TRUE.
!>

S

!>          S est un tableau de nombres réels double précision,
!>                                 de dimension (LDA, max(NN))
!>          La matrice de forme de Schur calculée à partir de A par DGGEV3.  À la sortie, S
!>          contient la matrice de forme de Schur correspondant à la matrice
!>          dans A.
!>

T

!>          T est un tableau de nombres réels double précision,
!>                                 de dimension (LDA, max(NN))
!>          La matrice triangulaire supérieure calculée à partir de B par DGGEV3.
!>

Q

!>          Q est un tableau de nombres réels double précision,
!>                                 de dimension (LDQ, max(NN))
!>          La matrice des vecteurs propres (gauches) calculée par DGGEV3.
!>

LDQ

!>          LDQ est un entier
!>          La dimension principale de Q et Z. Elle doit
!>          être au moins 1 et au moins max( NN ).
!>

Z

!>          Z est un tableau de nombres réels double précision, de dimension( LDQ, max(NN) )
!>          La matrice orthogonale (droite) calculée par DGGEV3.
!>

QE

!>          QE est un tableau de nombres réels double précision, de dimension( LDQ, max(NN) )
!>          QE contient les vecteurs propres droits ou gauches calculés.
!>

LDQE

!>          LDQE est un entier
!>          La dimension principale de QE. LDQE >= max(1,max(NN)).
!>

ALPHAR

!>          ALPHAR est un tableau de nombres réels double précision, de dimension (max(NN))
!>

ALPHAI

!>          ALPHAI est un tableau de nombres réels double précision, de dimension (max(NN))
!>

BETA

!>          BETA est un tableau de nombres réels double précision, de dimension (max(NN))
!>
!>          Les valeurs propres généralisées de (A,B) calculées par DGGEV3.
!>          ( ALPHAR(k)+ALPHAI(k)*i ) / BETA(k) est la k-ième
!>          valeur propre généralisée de A et B.
!>

ALPHR1

!>          ALPHR1 est un tableau de nombres réels double précision, de dimension (max(NN))
!>

ALPHI1

!>          ALPHI1 est un tableau de nombres réels double précision, de dimension (max(NN))
!>

BETA1

!>          BETA1 est un tableau de nombres réels double précision, de dimension (max(NN))
!>
!>          Comme ALPHAR, ALPHAI, BETA, ces tableaux contiennent les
!>          valeurs propres de A et B, mais celles calculées lorsque DGGEV3 ne
!>          calcule qu'une décomposition propre partielle, c'est-à-dire pas les
!>          valeurs propres ni les vecteurs propres gauches et droits.
!>

WORK

!>          WORK est un tableau de nombres réels double précision, de dimension (LWORK)
!>

LWORK

!>          LWORK est un entier
!>          Le nombre d'éléments dans WORK.  LWORK >= MAX( 8*N, N*(N+1) ).
!>

RESULT

!>          RESULT est un tableau de nombres réels double précision, de dimension (2)
!>          Les valeurs calculées par les tests décrits ci-dessus.
!>          Les valeurs sont actuellement limitées à 1/ulp, pour éviter le débordement.
!>

INFO

!>          INFO est un entier
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.
!>          > 0 : une routine a renvoyé un code d'erreur. INFO est la valeur
!>                absolue de la valeur INFO retournée.
!>
