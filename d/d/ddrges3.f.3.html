sous-routine ddrges3 (integer nsizes, integer, dimension( * ) nn, integer ntypes, logical, dimension( * ) dotype, integer, dimension( 4 ) iseed, double precision thresh, integer nounit, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( lda, * ) b, double precision, dimension( lda, * ) s, double precision, dimension( lda, * ) t, double precision, dimension( ldq, * ) q, integer ldq, double precision, dimension( ldq, * ) z, double precision, dimension( * ) alphar, double precision, dimension( * ) alphai, double precision, dimension( * ) beta, double precision, dimension( * ) work, integer lwork, double precision, dimension( 13 ) result, logical, dimension( * ) bwork, integer info)

DDRGES3

Objectif :

!>
!> DDRGES3 teste le pilote du problème de valeurs propres généralisées non symétriques (forme de Schur)
!> DGGES3.
!>
!> DGGES3 factorise A et B en Q S Z' et Q T Z', où ' signifie transposée, T est triangulaire supérieure, S est en forme de Schur généralisée
!> (triangulaire par blocs, avec des blocs 1x1 et 2x2 sur la diagonale,
!> les blocs 2x2 correspondant à des paires de valeurs propres généralisées conjuguées complexes),
!> et Q et Z sont orthogonales. Il calcule également les valeurs propres généralisées (alpha(j),beta(j)), j=1,...,n,
!> Ainsi, w(j) = alpha(j)/beta(j) est une racine de l'équation caractéristique
!>                 det( A - w(j) B ) = 0
!> Optionnellement, il réordonne également les valeurs propres de manière à ce qu'un amas sélectionné
!> de valeurs propres apparaisse dans le bloc diagonal principal des formes de Schur.
!>
!> Lorsque DDRGES3 est appelé, un certain nombre de matrices () et un
!> nombre de matrices () sont spécifiés. Pour chaque taille ()
!> et chaque TYPE de matrice, une paire de matrices (A, B) sera générée
!> et utilisée pour les tests. Pour chaque paire de matrices, les 13 tests suivants
!> seront effectués et comparés au seuil THRESH, à l'exception des tests (5), (11) et (13).
!>
!>
!> (1)   | A - Q S Z' | / ( |A| n ulp ) (pas de tri des valeurs propres)
!>
!>
!> (2)   | B - Q T Z' | / ( |B| n ulp ) (pas de tri des valeurs propres)
!>
!>
!> (3)   | I - QQ' | / ( n ulp ) (pas de tri des valeurs propres)
!>
!>
!> (4)   | I - ZZ' | / ( n ulp ) (pas de tri des valeurs propres)
!>
!> (5)   si A est en forme de Schur (c'est-à-dire forme quasi-triangulaire)
!>       (pas de tri des valeurs propres)
!>
!> (6)   si les valeurs propres = blocs diagonaux de la forme de Schur (S, T),
!>       c'est-à-dire tester le maximum sur j de D(j) où :
!>
!>       si alpha(j) est réel :
!>                     |alpha(j) - S(j,j)|        |beta(j) - T(j,j)|
!>           D(j) = ------------------------ + -----------------------
!>                  max(|alpha(j)|,|S(j,j)|)   max(|beta(j)|,|T(j,j)|)
!>
!>       si alpha(j) est complexe :
!>                                 | det( s S - w T ) |
!>           D(j) = ---------------------------------------------------
!>                  ulp max( s norm(S), |w| norm(T) )*norm( s S - w T )
!>
!>       et S et T sont ici les blocs diagonaux 2x2 de S et T
!>       correspondant aux j-ième et (j+1)-ième valeurs propres.
!>       (pas de tri des valeurs propres)
!>
!> (7)   | (A,B) - Q (S,T) Z' | / ( | (A,B) | n ulp )
!>            (avec tri des valeurs propres).
!>
!> (8)   | I - QQ' | / ( n ulp ) (avec tri des valeurs propres).
!>
!> (9)   | I - ZZ' | / ( n ulp ) (avec tri des valeurs propres).
!>
!> (10)  si A est en forme de Schur (c'est-à-dire forme quasi-triangulaire)
!>       (avec tri des valeurs propres).
!>
!> (11)  si les valeurs propres = blocs diagonaux de la forme de Schur (S, T),
!>       c'est-à-dire tester le maximum sur j de D(j) où :
!>
!>       si alpha(j) est réel :
!>                     |alpha(j) - S(j,j)|        |beta(j) - T(j,j)|
!>           D(j) = ------------------------ + -----------------------
!>                  max(|alpha(j)|,|S(j,j)|)   max(|beta(j)|,|T(j,j)|)
!>
!>       si alpha(j) est complexe :
!>                                 | det( s S - w T ) |
!>           D(j) = ---------------------------------------------------
!>                  ulp max( s norm(S), |w| norm(T) )*norm( s S - w T )
!>
!>       et S et T sont ici les blocs diagonaux 2x2 de S et T
!>       correspondant aux j-ième et (j+1)-ième valeurs propres.
!>       (avec tri des valeurs propres).
!>
!> (12)  si le tri a fonctionné et SDIM est le nombre de valeurs propres
!>       qui ont été SÉLECTIONNÉES.
!>
!> Matrices de Test
!> ==============
!>
!> Les tailles des matrices de test sont spécifiées par un tableau
!> NN(1:NSIZES) ; la valeur de chaque élément NN(j) spécifie une taille.
!> Les  sont spécifiés par un tableau logique DOTYPE( 1:NTYPES ) ; si
!> DOTYPE(j) est .VRAI., alors le type de matrice  sera généré.
!> Actuellement, la liste des types possibles est :
!>
!> (1)  ( 0, 0 )         (une paire de matrices nulles)
!>
!> (2)  ( I, 0 )         (une matrice identité et une matrice nulle)
!>
!> (3)  ( 0, I )         (une matrice nulle et une matrice identité)
!>
!> (4)  ( I, I )         (une paire de matrices identité)
!>
!>         t   t
!> (5)  ( J , J  )       (une paire de blocs de Jordan transposés)
!>
!>                                     t                ( I   0  )
!> (6)  ( X, Y )         où  X = ( J   0  )  et Y = (      t )
!>                                  ( 0   I  )          ( 0   J  )
!>                       et I est une identité k x k et J un bloc de Jordan (k+1)x(k+1)
!>                       ; k=(N-1)/2
!>
!> (7)  ( D, I )         où D est diag( 0, 1,..., N-1 ) (une matrice diagonale
!>                       avec ces entrées diagonales.)
!> (8)  ( I, D )
!>
!> (9)  ( big*D, small*I ) où  est proche du dépassement de capacité et small=1/big
!>
!> (10) ( small*D, big*I )
!>
!> (11) ( big*I, small*D )
!>
!> (12) ( small*I, big*D )
!>
!> (13) ( big*D, big*I )
!>
!> (14) ( small*D, small*I )
!>
!> (15) ( D1, D2 )        où D1 est diag( 0, 0, 1, ..., N-3, 0 ) et
!>                        D2 est diag( 0, N-3, N-4,..., 1, 0, 0 )
!>           t   t
!> (16) Q ( J , J ) Z     où Q et Z sont des matrices orthogonales aléatoires.
!>
!> (17) Q ( T1, T2 ) Z    où T1 et T2 sont des matrices triangulaires supérieures
!>                        avec des entrées aléatoires d'ordre O(1) au-dessus de la diagonale
!>                        et des entrées diagonales diag(T1) =
!>                        ( 0, 0, 1, ..., N-3, 0 ) et diag(T2) =
!>                        ( 0, N-3, N-4,..., 1, 0, 0 )
!>
!> (18) Q ( T1, T2 ) Z    diag(T1) = ( 0, 0, 1, 1, s, ..., s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1,..., 1, 0 )
!>                        s = précision machine.
!>
!> (19) Q ( T1, T2 ) Z    diag(T1)=( 0, 0, 1, 1, 1-d, ..., 1-(N-5)*d=s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0 )
!>
!>                                                        N-5
!> (20) Q ( T1, T2 ) Z    diag(T1)=( 0, 0, 1, 1, a, ..., a   =s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0, 0 )
!>
!> (21) Q ( T1, T2 ) Z    diag(T1)=( 0, 0, 1, r1, r2, ..., r(N-4), 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0, 0 )
!>                        où r1,..., r(N-4) sont aléatoires.
!>
!> (22) Q ( big*T1, small*T2 ) Z    diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>
diag(T2) = ( 0, 1, ..., 1, 0, 0 ) !> !> (23) Q ( small*T1, big*T2 ) Z diag(T1) = ( 0, 0, 1, ..., N-3, 0 ) !> diag(T2) = ( 0, 1, ..., 1, 0, 0 ) !> !> (24) Q ( small*T1, small*T2 ) Z diag(T1) = ( 0, 0, 1, ..., N-3, 0 ) !> diag(T2) = ( 0, 1, ..., 1, 0, 0 ) !> !> (25) Q ( big*T1, big*T2 ) Z diag(T1) = ( 0, 0, 1, ..., N-3, 0 ) !> diag(T2) = ( 0, 1, ..., 1, 0, 0 ) !> !> (26) Q ( T1, T2 ) Z où T1 et T2 sont des matrices triangulaires !> supérieures aléatoires. !> !>

Paramètre

s
NSIZES 
!>          NSIZES est INTEGER
!>          Le nombre de tailles de matrices à utiliser. S'il vaut zéro,
!>          DDRGES3 ne fait rien. NSIZES >= 0.
!
>

N

N 
!>          NN est un tableau INTEGER, dimension (NSIZES)
!>          Un tableau contenant les tailles à utiliser pour les matrices.
!>          Les valeurs nulles seront ignorées. NN >= 0.
!
>

NTYPE

S 
!>          NTYPES est INTEGER
!>          Le nombre d'éléments dans DOTYPE. S'il vaut zéro, DDRGES3
!>          ne fait rien. Il doit être au moins zéro. S'il vaut MAXTYP+1
!>          et que NSIZES vaut 1, alors un type supplémentaire, MAXTYP+1, est
!>          défini, qui consiste à utiliser quelle que soit la matrice présente dans A en entrée.
!>          Cela n'est utile que si DOTYPE(1:MAXTYP) vaut .FALSE. et
!>          DOTYPE(MAXTYP+1) vaut .TRUE. .
!
>

DOTYP

E 
!>          DOTYPE est un tableau LOGICAL, dimension (NTYPES)
!>          Si DOTYPE(j) vaut .TRUE., alors pour chaque taille dans NN, une
!>          matrice de cette taille et de type j sera générée.
!>          Si NTYPES est inférieur au nombre maximal de types
!>          défini (PARAMETER MAXTYP), les types NTYPES+1 à
!>          MAXTYP ne seront pas générés. Si NTYPES est supérieur
!>          à MAXTYP, DOTYPE(MAXTYP+1) à DOTYPE(NTYPES)
!>          seront ignorés.
!
>

ISEE

D 
!>          ISEED est un tableau INTEGER, dimension (4)
!>          À l'entrée, ISEED spécifie la graine du générateur de nombres
!>          aléatoires. Les éléments du tableau doivent être compris entre 0 et 4095 ;
!>          sinon, ils seront réduits modulo 4096. De plus, ISEED(4) doit
!>          être impair. Le générateur de nombres aléatoires utilise une suite
!>          linéaire congruentielle limitée à de petits entiers, et doit donc
!>          produire des nombres aléatoires indépendants de la machine. Les
!>          valeurs de ISEED sont modifiées à la sortie, et peuvent être utilisées dans le
!>          prochain appel à DDRGES3 pour continuer la même suite de nombres
!>          aléatoires.
!
>

THRES

H 
!>          THRESH est DOUBLE PRECISION
!>          Un test sera considéré comme réussi si la valeur , calculée comme
!>          décrit ci-dessus, dépasse THRESH. Notez que l'erreur est
!>          mise à l'échelle pour être O(1), donc THRESH devrait être un multiple raisonnablement petit
!>          de 1, p. ex., 10 ou 100. En particulier, elle ne devrait
!>          pas dépendre de la précision (simple vs. double) ni de la taille
!>          de la matrice. THRESH >= 0.
!
>

NOUNI

T 
!>          NOUNIT est INTEGER
!>          Le numéro d'unité FORTRAN pour imprimer les messages d'erreur
!>          (p. ex., si une routine retourne IINFO différent de 0).
!
>

A 
!>          A est un tableau DOUBLE PRECISION,
!>                                       dimension(LDA, max(NN))
!>          Utilisé pour stocker la matrice A d'origine. Utilisé uniquement en entrée
!>          si NTYPES=MAXTYP+1, DOTYPE(1:MAXTYP)=.FALSE., et
!>          DOTYPE(MAXTYP+1)=.TRUE.
!
>

LD

A 
!>          LDA est INTEGER
!>          La dimension principale de A, B, S et T.
!>          Elle doit être au moins 1 et au moins max( NN ).
!
>

B 
!>          B est un tableau DOUBLE PRECISION,
!>                                       dimension(LDA, max(NN))
!>          Utilisé pour stocker la matrice B d'origine. Utilisé uniquement en entrée
!>          si NTYPES=MAXTYP+1, DOTYPE(1:MAXTYP)=.FALSE., et
!>          DOTYPE(MAXTYP+1)=.TRUE.
!
>

S 
!>          S est un tableau DOUBLE PRECISION, dimension (LDA, max(NN))
!>          La matrice de forme de Schur calculée à partir de A par DGGES3. À la sortie, S
!>          contient la matrice de forme de Schur correspondant à la matrice
!>          dans A.
!
>

T 
!>          T est un tableau DOUBLE PRECISION, dimension (LDA, max(NN))
!>          La matrice triangulaire supérieure calculée à partir de B par DGGES3.
!
>

Q 
!>          Q est un tableau DOUBLE PRECISION, dimension (LDQ, max(NN))
!>          La matrice orthogonale (gauche) calculée par DGGES3.
!
>

LD

Q 
!>          LDQ est INTEGER
!>          La dimension principale de Q et Z. Elle doit
!>          être au moins 1 et au moins max( NN ).
!
>

Z 
!>          Z est un tableau DOUBLE PRECISION, dimension( LDQ, max(NN) )
!>          La matrice orthogonale (droite) calculée par DGGES3.
!
>

ALPHA

R 
!>          ALPHAR est un tableau DOUBLE PRECISION, dimension (max(NN))
!
>

ALPHA

I 
!>          ALPHAI est un tableau DOUBLE PRECISION, dimension (max(NN))
!
>

BET

A 
!>          BETA est un tableau DOUBLE PRECISION, dimension (max(NN))
!>
!>          Les valeurs propres généralisées de (A,B) calculées par DGGES3.
!>          ( ALPHAR(k)+ALPHAI(k)*i ) / BETA(k) est la k-ième
!>          valeur propre généralisée de A et B.
!
>

WOR

K 
!>          WORK est un tableau DOUBLE PRECISION, dimension (LWORK)
!
>

LWOR

K 
!>          LWORK est INTEGER
!>          La dimension du tableau WORK.
!>          LWORK >= MAX( 10*(N+1), 3*N*N ), où N est la plus grande
!>          dimension de matrice.
!
>

RESUL

T 
!>          RESULT est un tableau DOUBLE PRECISION, dimension (15)
!>          Les valeurs calculées par les tests décrits ci-dessus.
!>          Les valeurs sont actuellement limitées à 1/ulp, pour éviter le débordement.
!
>

BWOR

K 
!>          BWORK est un tableau LOGICAL, dimension (N)
!
>

INF

O 
!>          INFO est INTEGER
!>          = 0 :  sortie réussie
!>          < 0 :  si INFO = -i, le i-ème argument avait une valeur illégale.
!>          > 0 :  Une routine a retourné un code d'erreur. INFO est la
!>                valeur absolue de la valeur INFO retournée.
!
>
