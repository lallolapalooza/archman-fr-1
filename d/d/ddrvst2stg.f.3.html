sous-routine ddrvst2stg (integer nsizes, integer, dimension( * ) nn, integer ntypes, logical, dimension( * ) dotype, integer, dimension( 4 ) iseed, double precision thresh, integer nounit, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( * ) d1, double precision, dimension( * ) d2, double precision, dimension( * ) d3, double precision, dimension( * ) d4, double precision, dimension( * ) eveigs, double precision, dimension( * ) wa1, double precision, dimension( * ) wa2, double precision, dimension( * ) wa3, double precision, dimension( ldu, * ) u, integer ldu, double precision, dimension( ldu, * ) v, double precision, dimension( * ) tau, double precision, dimension( ldu, * ) z, double precision, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, integer liwork, double precision, dimension( * ) result, integer info)

DDRVST2STG

Purpose:

!>
!>      DDRVST2STG  vérifie les pilotes de problème de valeurs propres symétriques.
!>
!>              DSTEV calcule toutes les valeurs propres et, éventuellement,
!>              les vecteurs propres d'une matrice tridiagonale symétrique réelle.
!>
!>              DSTEVX calcule des valeurs propres sélectionnées et, éventuellement,
!>              les vecteurs propres d'une matrice tridiagonale symétrique réelle.
!>
!>              DSTEVR calcule des valeurs propres sélectionnées et, éventuellement,
!>              les vecteurs propres d'une matrice tridiagonale symétrique réelle
!>              en utilisant la Représentation Relativement Robuste lorsque cela est possible.
!>
!>              DSYEV calcule toutes les valeurs propres et, éventuellement,
!>              les vecteurs propres d'une matrice symétrique réelle.
!>
!>              DSYEVX calcule des valeurs propres sélectionnées et, éventuellement,
!>              les vecteurs propres d'une matrice symétrique réelle.
!>
!>              DSYEVR calcule des valeurs propres sélectionnées et, éventuellement,
!>              les vecteurs propres d'une matrice symétrique réelle
!>              en utilisant la Représentation Relativement Robuste lorsque cela est possible.
!>
!>              DSPEV calcule toutes les valeurs propres et, éventuellement,
!>              les vecteurs propres d'une matrice symétrique réelle en stockage
!>              condensé.
!>
!>              DSPEVX calcule des valeurs propres sélectionnées et, éventuellement,
!>              les vecteurs propres d'une matrice symétrique réelle en stockage
!>              condensé.
!>
!>              DSBEV calcule toutes les valeurs propres et, éventuellement,
!>              les vecteurs propres d'une matrice bande symétrique réelle.
!>
!>              DSBEVX calcule des valeurs propres sélectionnées et, éventuellement,
!>              les vecteurs propres d'une matrice bande symétrique réelle.
!>
!>              DSYEVD calcule toutes les valeurs propres et, éventuellement,
!>              les vecteurs propres d'une matrice symétrique réelle en utilisant
!>              un algorithme diviser pour régner.
!>
!>              DSPEVD calcule toutes les valeurs propres et, éventuellement,
!>              les vecteurs propres d'une matrice symétrique réelle en stockage
!>              condensé, en utilisant un algorithme diviser pour régner.
!>
!>              DSBEVD calcule toutes les valeurs propres et, éventuellement,
!>              les vecteurs propres d'une matrice bande symétrique réelle,
!>              en utilisant un algorithme diviser pour régner.
!>
!>      Lorsque DDRVST2STG est appelée, un nombre de tailles de matrices () et un
!>      nombre de types de matrices sont spécifiés. Pour chaque taille ()
!>      et chaque type de matrice, une matrice sera générée et utilisée
!>      pour tester les pilotes appropriés. Pour chaque matrice et chaque
!>      routine pilote appelée, les tests suivants seront effectués :
!>
!>      (1)     | A - Z D Z' | / ( |A| n ulp )
!>
!>      (2)     | I - Z Z' | / ( n ulp )
!>
!>      (3)     | D1 - D2 | / ( |D1| ulp )
!>
!>      où Z est la matrice des vecteurs propres retournée lorsque l'option
!>      vecteur propre est donnée et D1 et D2 sont les valeurs propres
!>      retournées avec et sans l'option vecteur propre.
!>
!>      Les  sont spécifiées par un tableau NN(1:NSIZES) ; la valeur de
!>      chaque élément NN(j) spécifie une taille.
!>      Les  sont spécifiées par un tableau logique DOTYPE( 1:NTYPES ) ;
!>      si DOTYPE(j) est .VRAI., alors le type de matrice  sera généré.
!>      Actuellement, la liste des types possibles est :
!>
!>      (1)  La matrice nulle.
!>      (2)  La matrice identité.
!>
!>      (3)  Une matrice diagonale avec des valeurs propres régulièrement espacées
!>           1, ..., ULP  et des signes aléatoires.
!>           (ULP = (premier nombre supérieur à 1) - 1 )
!>      (4)  Une matrice diagonale avec des valeurs propres espacées géométriquement
!>           1, ..., ULP  et des signes aléatoires.
!>      (5)  Une matrice diagonale avec  valeurs propres
!>           1, ULP, ..., ULP et des signes aléatoires.
!>
!>      (6)  Identique à (4), mais multiplié par SQRT( seuil de dépassement )
!>      (7)  Identique à (4), mais multiplié par SQRT( seuil de sous-dépassement )
!>
!>      (8)  Une matrice de la forme  U' D U, où U est orthogonale et
!>           D a des entrées régulièrement espacées 1, ..., ULP avec des signes aléatoires
!>           sur la diagonale.
!>
!>      (9)  Une matrice de la forme  U' D U, où U est orthogonale et
!>           D a des entrées espacées géométriquement 1, ..., ULP avec des signes aléatoires
!>           sur la diagonale.
!>
!>      (10) Une matrice de la forme  U' D U, où U est orthogonale et
!>           D a des entrées  1, ULP,..., ULP avec des signes aléatoires
!>           sur la diagonale.
!>
!>      (11) Identique à (8), mais multiplié par SQRT( seuil de dépassement )
!>      (12) Identique à (8), mais multiplié par SQRT( seuil de sous-dépassement )
!>
!>      (13) Matrice symétrique avec des entrées aléatoires choisies entre (-1,1).
!>      (14) Identique à (13), mais multiplié par SQRT( seuil de dépassement )
!>      (15) Identique à (13), mais multiplié par SQRT( seuil de sous-dépassement )
!>      (16) Matrice bande avec une demi-bande choisie aléatoirement entre
!>           0 et N-1, avec des valeurs propres régulièrement espacées 1, ..., ULP
!>           avec des signes aléatoires.
!>      (17) Identique à (16), mais multiplié par SQRT( seuil de dépassement )
!>      (18) Identique à (16), mais multiplié par SQRT( seuil de sous-dépassement )
!> 
!>  NSIZES  INTEGER
!>          Le nombre de tailles de matrices à utiliser. S'il est zéro,
!>          DDRVST2STG ne fait rien. Il doit être supérieur ou égal à zéro.
!>          Non modifié.
!>
!>  NN      Tableau INTEGER, dimension (NSIZES)
!>          Un tableau contenant les tailles à utiliser pour les matrices.
!>          Les valeurs nulles seront ignorées. Les valeurs doivent être supérieures ou égales
!>          à zéro.
!>          Non modifié.
!>
!>  NTYPES  INTEGER
!>          Le nombre d'éléments dans DOTYPE. S'il est zéro, DDRVST2STG
!>          ne fait rien. Il doit être supérieur ou égal à zéro. S'il est MAXTYP+1
!>          et NSIZES est 1, alors un type supplémentaire, MAXTYP+1 est
!>          défini, qui consiste à utiliser quelle que soit la matrice dans A. Ceci
!>          n'est utile que si DOTYPE(1:MAXTYP) est .FAUX. et
!>          DOTYPE(MAXTYP+1) est .VRAI. .
!>          Non modifié.
!>
!>  DOTYPE  LOGICAL
tableau, dimension (NTYPES) !> Si DOTYPE(j) est .TRUE., alors pour chaque taille dans NN, une !> matrice de cette taille et de type j sera générée. !> Si NTYPES est plus petit que le nombre maximal de types !> défini (PARAMÈTRE MAXTYP), les types NTYPES+1 à !> MAXTYP ne seront pas générés. Si NTYPES est plus grand !> que MAXTYP, DOTYPE(MAXTYP+1) à DOTYPE(NTYPES) !> seront ignorés. !> Non modifié. !> !> ISEED tableau INTEGER, dimension (4) !> À l'entrée, ISEED spécifie la graine du générateur de !> nombres aléatoires. Les éléments du tableau doivent être compris entre 0 et 4095 ; !> sinon ils seront réduits modulo 4096. De plus, ISEED(4) doit !> être impair. Le générateur de nombres aléatoires utilise une séquence !> linéaire congruentielle limitée à de petits entiers, et doit donc !> produire des nombres aléatoires indépendants de la machine.
