NOM

ddrescue - outil de récupération de données

SYNTAXE

ddrescue [options] fichier_entree fichier_sortie [fichier_carte]

DESCRIPTION

GNU ddrescue est un outil de récupération de données. Il copie des données d'un fichier ou d'un périphérique bloc (disque dur, cdrom, etc.) vers un autre, en essayant de récupérer d'abord les bonnes parties en cas d'erreurs de lecture.

Utilisez toujours un fichier carte, sauf si vous savez que vous n'en aurez pas besoin. Sans fichier carte, ddrescue ne peut pas reprendre une récupération, seulement la réinitialiser. Faites attention à ne pas spécifier par erreur un ancien fichier carte d'une récupération sans rapport.

NOTE : Dans les versions de ddrescue antérieures à 1.20, le fichier carte s'appelait 'logfile'. Le format est le même ; seul le nom a changé.

Si vous redémarrez, vérifiez les noms des périphériques avant de relancer ddrescue. N'utilisez pas les options '-F' ou '-G' sans avoir lu le manuel au préalable.

OPTIONS

-h, --help
afficher cette aide et quitter
-V, --version
afficher les informations de version et quitter
-a, --min-read-rate=<octets>
taux de lecture minimum des zones bonnes en octets/s
-A, --try-again
marquer les secteurs non coupés, non raclés comme non tentés
-b, --sector-size=<octets>
taille de secteur du périphérique d'entrée [défaut 512]
-B, --binary-prefixes
afficher les multiplicateurs binaires dans les nombres [SI]
-c, --cluster-size=<secteurs>
secteurs à copier à la fois [128]
-C, --complete-only
ne pas lire de nouvelles données au-delà des limites du fichier carte
-d, --idirect
utiliser l'accès direct au disque pour le fichier d'entrée
-D, --odirect
utiliser l'accès direct au disque pour le fichier de sortie
-e, --max-bad-areas=[+]<n>
nombre maximum de zones mauvaises [nouvelles] autorisées
-E, --max-error-rate=<octets>
taux maximum d'erreurs de lecture par seconde autorisé
-f, --force
écraser le périphérique de sortie ou la partition
-F, --fill-mode=<types>
remplir les blocs des types donnés avec des données (?*/-+l)
-G, --generate-mode
générer un fichier carte approximatif à partir d'une copie partielle
-H, --test-mode=<fichier>
définir la carte des blocs bons/mauvais à partir du fichier carte donné
-i, --input-position=<octets>
position de départ du domaine dans le fichier d'entrée [0]
-I, --check-input-size
comparer la taille du fichier d'entrée avec la taille dans le fichier carte
-J, --check-on-error
re-lire le dernier secteur bon après chaque erreur
-K, --skip-size=[<i>][,<max>]
taille initiale, maximale à sauter en cas d'erreur de lecture
-L, --loose-domain
accepter un fichier carte de domaine non ordonné avec des lacunes
-m, --domain-mapfile=<fichier>
restreindre le domaine aux blocs terminés dans <fichier>
-M, --retrim
marquer tous les blocs échoués comme non coupés
-n, --no-scrape
sauter la phase de raclage
-N, --no-trim
sauter la phase de découpe
-o, --output-position=<octets>
position de départ dans le fichier de sortie [ipos]
-O, --reopen-on-error
rouvrir le fichier d'entrée après chaque erreur de lecture
-p, --preallocate
préallouer de l'espace sur le disque pour le fichier de sortie
-P, --data-preview[=<lignes>]
afficher quelques lignes des dernières données lues [3]
-q, --quiet
supprimer tous les messages
-r, --retry-passes=<n>
quitter après <n> passes de nouvelle tentative (-1=infini) [0]
-R, --reverse
inverser la direction de toutes les passes
-s, --size=<octets>
taille maximale des données d'entrée à copier
-S, --sparse
utiliser des écritures creuses pour le fichier de sortie
-t, --truncate
tronquer le fichier de sortie à une taille nulle
-T, --timeout=<intervalle>
temps maximum depuis la dernière lecture réussie
-u, --unidirectional
exécuter toutes les passes dans la même direction
-v, --verbose
être verbeux (un 2ème -v donne plus d'informations)
-w, --ignore-write-errors
faire ignorer les erreurs d'écriture au mode de remplissage
-W, --compare-before-write
omettre les écritures superflues en mode de récupération
-x, --extend-outfile=<octets>
étendre la taille du fichier de sortie pour qu'elle soit au moins aussi longue
-X, --max-read-errors=<n>
nombre maximum d'erreurs de lecture autorisées
-y, --synchronous
utiliser des écritures synchrones pour le fichier de sortie
-Z, --max-read-rate=<octets>
taux de lecture maximum en octets/s
--ask
demander confirmation avant de commencer la copie
--bad-sector-data=<fichier>
traiter les secteurs contenant des données de <fichier> comme des erreurs de lecture
--command-mode
exécuter des commandes depuis l'entrée standard
--continue-on-errno=<n>[,<n>]
traiter le code errno <n> comme non fatal
--cpass=<plage>
sélectionner quelle(s) passe(s) de copie exécuter
--delay-slow=<intervalle>
délai initial avant de vérifier les lectures lentes [30]
--log-events=<fichier>
enregistrer les événements significatifs dans <fichier>
--log-rates=<fichier>
enregistrer les taux et les tailles d'erreur dans <fichier>
--log-reads=<fichier>
enregistrer toutes les opérations de lecture dans <fichier>
--mapfile-interval=[i][,i]
sauvegarder/synchroniser le fichier carte à l'intervalle donné [auto]
--max-slow-reads=<n>
nombre maximum de lectures lentes autorisées
--pause-on-error=<intervalle>
temps d'attente après chaque erreur de lecture [0]
--pause-on-pass=<intervalle>
temps d'attente entre les passes [0]
--reset-slow
réinitialiser les lectures lentes si le taux augmente au-dessus du minimum
--same-file
autoriser le fichier d'entrée et le fichier de sortie à être le même fichier
