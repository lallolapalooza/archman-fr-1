Documentation de la fonction/sous-routine

sous-routine ddrvsy_rk (logique, dimension( * ) dotype, entier nn, entier, dimension( * ) nval, entier nrhs, double précision thresh, logique tsterr, entier nmax, double précision, dimension( * ) a, double précision, dimension( * ) afac, double précision, dimension( * ) e, double précision, dimension( * ) ainv, double précision, dimension( * ) b, double précision, dimension( * ) x, double précision, dimension( * ) xact, double précision, dimension( * ) work, double précision, dimension( * ) rwork, entier, dimension( * ) iwork, entier nout)

DDRVSY_RK

Objectif :

!> DDRVSY_RK teste les routines de pilotage DSYSV_RK.
!>

Paramètres

DOTYPE 
!>          DOTYPE est un tableau LOGIQUE, de dimension (NTYPES)
!>          Les types de matrices à utiliser pour les tests. Les matrices de type j
!>          (pour 1 <= j <= NTYPES) sont utilisées pour les tests si DOTYPE(j) =
!>          .VRAI.; si DOTYPE(j) = .FAUX., alors le type j n'est pas utilisé.
!>

NN

!>          NN est un ENTIER
!>          Le nombre de valeurs de N contenues dans le vecteur NVAL.
!>

NVAL

!>          NVAL est un tableau d'ENTIERS, de dimension (NN)
!>          Les valeurs de la dimension de la matrice N.
!>

NRHS

!>          NRHS est un ENTIER
!>          Le nombre de vecteurs de second membre à générer pour
!>          chaque système linéaire.
!>

THRESH

!>          THRESH est une DOUBLE PRÉCISION
!>          La valeur seuil pour les ratios de test. Un résultat est
!>          inclus dans le fichier de sortie si RESULTAT >= THRESH. Pour avoir
!>          tous les ratios de test imprimés, utilisez THRESH = 0.
!>

TSTERR

!>          TSTERR est un LOGIQUE
!>          Indicateur qui détermine si les sorties d'erreur doivent être testées.
!>

NMAX

!>          NMAX est un ENTIER
!>          La valeur maximale autorisée pour N, utilisée pour dimensionner les
!>          tableaux de travail.
!>

A

!>          A est un tableau de DOUBLE PRÉCISION, de dimension (NMAX*NMAX)
!>

AFAC

!>          AFAC est un tableau de DOUBLE PRÉCISION, de dimension (NMAX*NMAX)
!>

E

!>          E est un tableau de DOUBLE PRÉCISION, de dimension (NMAX)
!>

AINV

!>          AINV est un tableau de DOUBLE PRÉCISION, de dimension (NMAX*NMAX)
!>

B

!>          B est un tableau de DOUBLE PRÉCISION, de dimension (NMAX*NRHS)
!>

X

!>          X est un tableau de DOUBLE PRÉCISION, de dimension (NMAX*NRHS)
!>

XACT

!>          XACT est un tableau de DOUBLE PRÉCISION, de dimension (NMAX*NRHS)
!>

WORK

!>          WORK est un tableau de DOUBLE PRÉCISION, de dimension (NMAX*max(2,NRHS))
!>

RWORK

!>          RWORK est un tableau de DOUBLE PRÉCISION, de dimension (NMAX+2*NRHS)
!>

IWORK

!>          IWORK est un tableau d'ENTIERS, de dimension (2*NMAX)
!>

NOUT

!>          NOUT est un ENTIER
!>          Le numéro de l'unité de sortie.
!>
