!>
!> DDRVRFP teste les routines RFP de LAPACK :
!>     DPFTRF, DPFTRS et DPFTRI.
!>
!> Cette routine de test suit les mêmes tests que DDRVPO (test du solveur
!> Symmetric Positive Definite en format complet).
!>
!> Les tests sont effectués en format complet ; les conversions aller-retour
!> du format complet vers le format RFP sont effectuées à l'aide des routines
!> DTRTTF et DTFTTR.
!>
!> Tout d'abord, une matrice A spécifique de taille N est créée. Il existe
!> neuf types de matrices possibles.
!>  1. Diagonale                        6. Aléatoire, CNDNUM = sqrt(0.1/EPS)
!>  2. Aléatoire, CNDNUM = 2            7. Aléatoire, CNDNUM = 0.1/EPS
!> *3. Première ligne et colonne nulles 8. Mise à l'échelle proche du sous-dépassement
!> *4. Dernière ligne et colonne nulles  9. Mise à l'échelle proche du débordement
!> *5. Ligne et colonne médianes nulles
!> (* - teste les sorties d'erreur de DPFTRF, aucun rapport de test n'est calculé)
!> Une solution XACT de taille N-par-NRHS est créée ainsi que le second membre
!> associé B. Ensuite, DPFTRF est appelé pour calculer L (ou U), le facteur
!> de Cholesky de A. Puis L (ou U) est utilisé pour résoudre le système
!> linéaire d'équations AX = B. Cela donne X. Ensuite, L (ou U) est utilisé
!> pour calculer l'inverse de A, AINV. Les quatre tests suivants sont alors
!> effectués :
!> (1) norm( L*L' - A ) / ( N * norm(A) * EPS ) ou
!>     norm( U'*U - A ) / ( N * norm(A) * EPS ),
!> (2) norm(B - A*X) / ( norm(A) * norm(X) * EPS ),
!> (3) norm( I - A*AINV ) / ( N * norm(A) * norm(AINV) * EPS ),
!> (4) ( norm(X-XACT) * RCOND ) / ( norm(XACT) * EPS ),
!> où EPS est la précision machine, RCOND le conditionnement de A, et
!> norm( . ) la 1-norme pour (1,2,3) et l'inf-norme pour (4).
!> Des erreurs surviennent lorsque le paramètre INFO n'est pas celui attendu.
!> Des échecs surviennent lorsque un rapport de test est supérieur à THRES.
!>

Paramètres

NOUT 
!>          NOUT est INTEGER
!>                Le numéro d'unité pour la sortie.
!>

NN

!>          NN est INTEGER
!>                Le nombre de valeurs de N contenues dans le vecteur NVAL.
!>

NVAL

!>          NVAL est un tableau INTEGER, dimension (NN)
!>                Les valeurs de la dimension de matrice N.
!>

NNS

!>          NNS est INTEGER
!>                Le nombre de valeurs de NRHS contenues dans le vecteur NSVAL.
!>

NSVAL

!>          NSVAL est un tableau INTEGER, dimension (NNS)
!>                Les valeurs du nombre de secondes membres NRHS.
!>

NNT

!>          NNT est INTEGER
!>                Le nombre de valeurs de TYPE DE MATRICE contenues dans le vecteur NTVAL.
!>

NTVAL

!>          NTVAL est un tableau INTEGER, dimension (NNT)
!>                Les valeurs du type de matrice (entre 0 et 9 pour les matrices PO/PP/PF).
!>

THRESH

!>          THRESH est DOUBLE PRECISION
!>                La valeur de seuil pour les rapports de test. Un résultat est
!>                inclus dans le fichier de sortie si RESULT >= THRESH. Pour que
