DDGR(1) Commandes utilisateur DDGR(1)

NOM

ddgr - DuckDuckGo depuis le terminal

SYNTAXE

ddgr [OPTIONS] [MOT-CLÉ [MOT-CLÉ ...]]

DESCRIPTION

ddgr est un outil en ligne de commande pour rechercher sur DuckDuckGo (version HTML). ddgr affiche le titre, l'URL et le contexte textuel de chaque résultat. Les résultats sont récupérés par pages. Des raccourcis clavier sont disponibles pour la navigation entre les pages. Les résultats sont indexés et une URL de résultat peut être ouverte dans un navigateur en utilisant son numéro d'index. Il n'y a pas de fichier de configuration car les alias servent le même objectif pour cet utilitaire. Prend en charge les recherches séquentielles dans une seule instance.

Fonctionnalités


* Rapide et propre ; couleurs personnalisées
* Conçu pour une lisibilité maximale avec un espace minimum
* Réponses instantanées (supporté par la version HTML de DDG)
* Nombre personnalisé de résultats par page
* Navigation, intégration navigateur
* Scripts de complétion de recherche et d'options (Bash, Fish, Zsh)
* Bangs DuckDuckGo (avec complétion)
* Ouvre le premier résultat dans le navigateur (Je me sens "Ducky")
* REPL pour des recherches continues
* Mots-clés (par exemple, `filetype:mime`, `site:monsite.com`)
* Limite la recherche par temps, spécifie la région, désactive la recherche sécurisée
* Support proxy HTTPS, désactive optionnellement l'User Agent
* Ne pas suivre activé par défaut
* Supporte un script gestionnaire d'URL personnalisé ou un utilitaire en ligne de commande
* Entièrement documenté, page de manuel avec exemples
* Dépendances minimales

OPTIONS

-h, --help
Affiche le texte d'aide et quitte.
-n, --num=N
Affiche N résultats par page (par défaut 10). N doit être compris entre 0 et 25. N=0 désactive la pagination fixe et affiche le nombre réel de résultats récupérés par page.
-r, --reg=REG
Recherche spécifique à la région, par exemple 'us-en' pour les États-Unis (par défaut) ; visitez https://duckduckgo.com/params.
-C, --nocolor
Désactive la sortie couleur.
--colors=COULEURS
Définit les couleurs de sortie. Voir la section COULEURS ci-dessous pour plus de détails.
-j, --ducky
Ouvre le premier résultat dans un navigateur web ; implique --noprompt. Je me sens Ducky ?
-t, --time=SPAN
Limite la recherche dans le temps [j=jour passé, s=semaine passée, m=mois passé, a=année passée] (par défaut=tous les temps).
-w, --site=SITE
Recherche sur un site en utilisant DuckDuckGo.
-x, --expand
Développe les URL au lieu de n'afficher que le nom de domaine (par défaut).
-p, --proxy=URI
Fait transiter le trafic par un proxy HTTP. URI est de la forme [http[s]://][utilisateur:mdp@]hôte[:port]. Le serveur proxy doit supporter le tunneling HTTP CONNECT et ne doit pas bloquer le port 443 pour les hôtes DuckDuckGo pertinents. Si un proxy n'est pas explicitement donné, la variable d'environnement https_proxy ou HTTPS_PROXY (si disponible) est utilisée à la place.
--unsafe
Désactive la recherche sécurisée.
--noua
Désactive l'agent utilisateur. Les résultats sont récupérés plus rapidement.
--json
Sortie au format JSON ; implique --noprompt.
--gb, --gui-browser
Ouvre un bang directement dans un navigateur graphique.
--np, --noprompt
Effectue la recherche et quitte ; n'interroge pas pour d'autres interactions.
--rev, --reverse
Liste les entrées dans l'ordre inversé.
--url-handler=UTIL
Script personnalisé ou utilitaire en ligne de commande pour ouvrir les URL avec.
--show-browser-logs
Ne supprime pas la sortie du navigateur lors de l'ouverture d'un résultat dans le navigateur ; c'est-à-dire, connecte stdout et stderr du navigateur à stdout et stderr de ddgr au lieu de /dev/null. Par défaut, la sortie du navigateur est supprimée (en raison de certains navigateurs graphiques qui émettent des messages à la console) à moins que la variable d'environnement BROWSER ne soit un navigateur textuel connu : elinks, links, lynx, w3m ou www-browser.
-v, --version
Affiche le numéro de version et quitte.
-d, --debug
Active le débogage.

TOUCHES OMNIPROMMPT

n, p, f
Récupère l'ensemble suivant, précédent ou le premier ensemble de résultats de recherche.
index
Ouvre le résultat correspondant à l'index dans le navigateur.
o [index|plage|tous ...]
Ouvre dans le navigateur les index de résultats séparés par des espaces, les plages numériques ou tous les index, si 'tous' est spécifié.
O [index|plage|tous ...]
Fonctionne de manière similaire à la touche 'o', mais essaie d'ignorer les navigateurs textuels (même si BROWSER est défini) et d'ouvrir les liens dans un navigateur graphique.
d mots-clés
Lance une nouvelle recherche DuckDuckGo pour mots-clés avec les options d'origine. Cette touche doit être utilisée pour rechercher les touches omniprompt (y compris elle-même) et les index.
x
Active/désactive l'expansion de l'URL.
c index
Copie l'URL dans le presse-papiers.
q, ^D, double Entrée
Quitte ddgr.
?
Affiche l'aide omniprompt.
*
Toute autre chaîne initie une nouvelle recherche avec les options d'origine.
