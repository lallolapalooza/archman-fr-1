Documentation de la fonction/sous-routine

sous-routine ddrvgb (logical, dimension( * ) dotype, integer nn, integer, dimension( * ) nval, integer nrhs, double precision thresh, logical tsterr, double precision, dimension( * ) a, integer la, double precision, dimension( * ) afb, integer lafb, double precision, dimension( * ) asav, double precision, dimension( * ) b, double precision, dimension( * ) bsav, double precision, dimension( * ) x, double precision, dimension( * ) xact, double precision, dimension( * ) s, double precision, dimension( * ) work, double precision, dimension( * ) rwork, integer, dimension( * ) iwork, integer nout)

DDRVGBX

Objectif :

!>
!> DDRVGB teste les routines pilotes DGBSV, -SVX et -SVXX.
!>
!> Notez que ce fichier n'est utilisé que lorsque les XBLAS sont disponibles,
!> sinon ddrvgb.f définit cette sous-routine.
!>

Paramètres

DOTYPE 
!>          DOTYPE est un tableau LOGICAL, dimension (NTYPES)
!>          Les types de matrices à utiliser pour les tests. Les matrices de type j
!>          (pour 1 <= j <= NTYPES) sont utilisées pour les tests si DOTYPE(j) =
!>          .VRAI.; si DOTYPE(j) = .FAUX., alors le type j n'est pas utilisé.
!>

NN

!>          NN est un entier
!>          Le nombre de valeurs de N contenues dans le vecteur NVAL.
!>

NVAL

!>          NVAL est un tableau d'entiers, dimension (NN)
!>          Les valeurs de la dimension de colonne de matrice N.
!>

NRHS

!>          NRHS est un entier
!>          Le nombre de vecteurs de second membre à générer pour
!>          chaque système linéaire.
!>

THRESH

!>          THRESH est un double précision
!>          La valeur seuil pour les ratios de test. Un résultat est
!>          inclus dans le fichier de sortie si RESULT >= THRESH. Pour que
!>          chaque ratio de test soit imprimé, utilisez THRESH = 0.
!>

TSTERR

!>          TSTERR est un LOGICAL
!>          Indicateur qui spécifie si les sorties d'erreur doivent être testées.
!>

A

!>          A est un tableau DOUBLE PRECISION, dimension (LA)
!>

LA

!>          LA est un entier
!>          La longueur du tableau A. LA >= (2*NMAX-1)*NMAX
!>          où NMAX est la plus grande entrée dans NVAL.
!>

AFB

!>          AFB est un tableau DOUBLE PRECISION, dimension (LAFB)
!>

LAFB

!>          LAFB est un entier
!>          La longueur du tableau AFB. LAFB >= (3*NMAX-2)*NMAX
!>          où NMAX est la plus grande entrée dans NVAL.
!>

ASAV

!>          ASAV est un tableau DOUBLE PRECISION, dimension (LA)
!>

B

!>          B est un tableau DOUBLE PRECISION, dimension (NMAX*NRHS)
!>

BSAV

!>          BSAV est un tableau DOUBLE PRECISION, dimension (NMAX*NRHS)
!>

X

!>          X est un tableau DOUBLE PRECISION, dimension (NMAX*NRHS)
!>

XACT

!>          XACT est un tableau DOUBLE PRECISION, dimension (NMAX*NRHS)
!>

S

!>          S est un tableau DOUBLE PRECISION, dimension (2*NMAX)
!>

WORK

!>          WORK est un tableau DOUBLE PRECISION, dimension
!>                      (NMAX*max(3,NRHS,NMAX))
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, dimension
!>                      (max(2*NMAX,NMAX+2*NRHS))
!>

IWORK

!>          IWORK est un tableau INTEGER, dimension (2*NMAX)
!>

NOUT

!>          NOUT est un entier
!>          Le numéro d'unité pour la sortie.
!>
