NOM

ddns-confgen - outil de génération de clés ddns

SYNTAXE

ddns-confgen [-a algorithme] [-h] [-k nomclé] [-q] [-s nom] [-z zone]

DESCRIPTION

ddns-confgen est un utilitaire qui génère des clés pour être utilisées dans la signature TSIG. Les clés résultantes peuvent être utilisées, par exemple, pour sécuriser les mises à jour DNS dynamiques vers une zone, ou pour le canal de commande rndc <#std-iscman-rndc>.

Le nom de la clé peut être spécifié à l'aide du paramètre -k et vaut par défaut ddns-key. La clé générée est accompagnée de texte de configuration et d'instructions qui peuvent être utilisées avec nsupdate <#std-iscman-nsupdate> et named <#std-iscman-named> lors de la configuration du DNS dynamique, y compris une instruction update-policy d'exemple. (Cette utilisation est similaire à la commande rndc-confgen <#std-iscman-rndc-confgen> pour la configuration de la sécurité du canal de commande.)

Notez que named <#std-iscman-named> lui-même peut configurer une clé DDNS locale à utiliser avec nsupdate -l <#cmdoption-nsupdate-l> ; il le fait lorsqu'une zone est configurée avec update-policy local;. ddns-confgen n'est nécessaire que lorsqu'une configuration plus élaborée est requise : par exemple, si nsupdate <#std-iscman-nsupdate> doit être utilisé à partir d'un système distant.

OPTIONS

-a algorithme
Cette option spécifie l'algorithme à utiliser pour la clé TSIG. Les choix disponibles sont : hmac-md5, hmac-sha1, hmac-sha224, hmac-sha256, hmac-sha384, et hmac-sha512. La valeur par défaut est hmac-sha256. Les options ne sont pas sensibles à la casse, et le préfixe "hmac-" peut être omis.
-h
Cette option affiche un bref résumé des options et des arguments.
-k nomclé
Cette option spécifie le nom de la clé d'authentification DDNS. La valeur par défaut est ddns-key lorsque les options -s ou -z ne sont pas spécifiées ; sinon, la valeur par défaut est ddns-key comme étiquette séparée suivie de l'argument de l'option, par exemple, ddns-key.example.com. Le nom de la clé doit avoir le format d'un nom de domaine valide, composé de lettres, de chiffres, de traits d'union et de points.
-q
Cette option active le mode silencieux, qui n'affiche que la clé, sans texte explicatif ni exemples d'utilisation. Ceci est essentiellement identique à tsig-keygen <#std-iscman-tsig-keygen>.
-s nom
Cette option génère un exemple de configuration pour permettre les mises à jour dynamiques d'un seul nom d'hôte. Le texte d'exemple named.conf <#std-iscman-named.conf> montre comment définir une politique de mise à jour pour le nom spécifié en utilisant le type de nom "name". Le nom de clé par défaut est ddns-key.nom. Notez que le type de nom "self" ne peut pas être utilisé, car le nom à mettre à jour peut différer du nom de la clé. Cette option ne peut pas être utilisée avec l'option -z.
-z zone
Cette option génère un exemple de configuration pour permettre les mises à jour dynamiques d'une zone. Le texte d'exemple named.conf <#std-iscman-named.conf> montre comment définir une politique de mise à jour pour la zone spécifiée en utilisant le type de nom "zonesub", permettant les mises à jour de tous les noms de sous-domaines dans cette zone. Cette option ne peut pas être utilisée avec l'option -s.
