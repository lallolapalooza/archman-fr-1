!>
!> DDRVBD vérifie les pilotes de décomposition en valeurs singulières (SVD)
!> DGESVD, DGESDD, DGESVDQ, DGESVJ, DGEJSV, et DGESVDX.
!>
!> DGESVD et DGESDD factorisent tous deux A = U diag(S) VT, où U et VT sont
!> orthogonaux et diag(S) est diagonale avec les éléments du tableau S
!> sur sa diagonale. Les éléments de S sont les valeurs singulières,
!> non négatives et stockées en ordre décroissant. U et VT peuvent être
!> éventuellement non calculés, écrasés sur A, ou calculés partiellement.
!>
!> A est de dimension M par N. Soit MNMIN = min( M, N ). S a la dimension MNMIN.
!> U peut être M par M ou M par MNMIN. VT peut être N par N ou MNMIN par N.
!>
!> Lorsque DDRVBD est appelé, un nombre de tailles de matrices (M et N)
!> et un nombre de types de matrices sont spécifiés. Pour chaque taille (M,N)
!> et chaque type de matrix, et pour l'espace de travail minimal ainsi que
!> l'espace de travail suffisant pour permettre le blocage, une matrice M x N
!> sera générée et utilisée pour tester les routines SVD. Pour chaque matrice, A sera
!> factorisé comme A = U diag(S) VT et les 12 tests suivants calculés :
!>
!> Test pour DGESVD :
!>
!> (1)    | A - U diag(S) VT | / ( |A| max(M,N) ulp )
!>
!> (2)    | I - U'U | / ( M ulp )
!>
!> (3)    | I - VT VT' | / ( N ulp )
!>
!> (4)    S contient MNMIN valeurs non négatives en ordre décroissant.
!>        (Retourne 0 si vrai, 1/ULP si faux.)
!>
!> (5)    | U - Upartial | / ( M ulp ) où Upartial est un U
!>        calculé partiellement.
!>
!> (6)    | VT - VTpartial | / ( N ulp ) où VTpartial est un VT
!>        calculé partiellement.
!>
!> (7)    | S - Spartial | / ( MNMIN ulp |S| ) où Spartial est le
!>        vecteur de valeurs singulières du SVD partiel
!>
!> Test pour DGESDD :
!>
!> (8)    | A - U diag(S) VT | / ( |A| max(M,N) ulp )
!>
!> (9)    | I - U'U | / ( M ulp )
!>
!> (10)   | I - VT VT' | / ( N ulp )
!>
!> (11)   S contient MNMIN valeurs non négatives en ordre décroissant.
!>        (Retourne 0 si vrai, 1/ULP si faux.)
!>
!> (12)   | U - Upartial | / ( M ulp ) où Upartial est un U
!>        calculé partiellement.
!>
!> (13)   | VT - VTpartial | / ( N ulp ) où VTpartial est un VT
!>        calculé partiellement.
!>
!> (14)   | S - Spartial | / ( MNMIN ulp |S| ) où Spartial est le
!>        vecteur de valeurs singulières du SVD partiel
!>
!> Test pour DGESVDQ :
!>
!> (36)   | A - U diag(S) VT | / ( |A| max(M,N) ulp )
!>
!> (37)   | I - U'U | / ( M ulp )
!>
!> (38)   | I - VT VT' | / ( N ulp )
!>
!> (39)   S contient MNMIN valeurs non négatives en ordre décroissant.
!>        (Retourne 0 si vrai, 1/ULP si faux.)
!>
!> Test pour DGESVJ :
!>
!> (15)   | A - U diag(S) VT | / ( |A| max(M,N) ulp )
!>
!> (16)   | I - U'U | / ( M ulp )
!>
!> (17)   | I - VT VT' | / ( N ulp )
!>
!> (18)   S contient MNMIN valeurs non négatives en ordre décroissant.
!>        (Retourne 0 si vrai, 1/ULP si faux.)
!>
!> Test pour DGEJSV :
!>
!> (19)   | A - U diag(S) VT | / ( |A| max(M,N) ulp )
!>
!> (20)   | I - U'U | / ( M ulp )
!>
!> (21)   | I - VT VT' | / ( N ulp )
!>
!> (22)   S contient MNMIN valeurs non négatives en ordre décroissant.
!>        (Retourne 0 si vrai, 1/ULP si faux.)
!>
!> Test pour DGESVDX( 'V', 'V', 'A' )/DGESVDX( 'N', 'N', 'A' )
!>
!> (23)   | A - U diag(S) VT | / ( |A| max(M,N) ulp )
!>
!> (24)   | I - U'U | / ( M ulp )
!>
!> (25)   | I - VT VT' | / ( N ulp )
!>
!> (26)   S contient MNMIN valeurs non négatives en ordre décroissant.
!>        (Retourne 0 si vrai, 1/ULP si faux.)
!>
!> (27)   | U - Upartial | / ( M ulp ) où Upartial est un U
!>        calculé partiellement.
!>
!> (28)   | VT - VTpartial | / ( N ulp ) où VTpartial est un VT
!>        calculé partiellement.
!>
!> (29)   | S - Spartial | / ( MNMIN ulp |S| ) où Spartial est le
!>        vecteur de valeurs singulières du SVD partiel
!>
!> Test pour DGESVDX( 'V', 'V', 'I' )
!>
!> (30)   | U' A VT''' - diag(S) | / ( |A| max(M,N) ulp )
!>
!> (31)   | I - U'U | / ( M ulp )
!>
!> (32)   | I - VT VT' | / ( N ulp )
!>
!> Test pour DGESVDX( 'V', 'V', 'V' )
!>
!> (33)   | U' A VT''' - diag(S) | / ( |A| max(M,N) ulp )
!>
!> (34)   | I - U'U | / ( M ulp )
!>
!> (35)   | I - VT VT' | / ( N ulp )
!>
!> Les tailles sont spécifiées par les tableaux MM(1:NSIZES) et
!> NN(1:NSIZES) ; la valeur de chaque paire d'éléments (MM(j),NN(j))
!> spécifie une taille. Les types sont spécifiés par un tableau logique
!> DOTYPE( 1:NTYPES ) ; si DOTYPE(j) est .TRUE., alors le type de matrice j
!> sera généré.
!> Actuellement, la liste des types possibles est :
!>
!> (1)  La matrice nulle.
!> (2)  La matrice identité.
!> (3)  Une matrice de la forme U D V, où U et V sont orthogonaux et
!>      D a des éléments régulièrement espacés 1, ..., ULP avec des signes
!>      aléatoires sur la diagonale.
!> (4)  Identique à (3), mais multipliée par le seuil de débordement inférieur / ULP.
!> (5)  Identique à (3), mais multipliée par le seuil de débordement supérieur * ULP.
!
>

s
NSIZES 
!>          NSIZES est INTEGER
!>          Le nombre de tailles de matrices (M,N) contenues dans les vecteurs
!>          MM et NN.
!
>

M

!>          NN est un tableau INTEGER, dimension (NSIZES)

NTYPE

S 
!>          NTYPES est INTEGER
!>          Le nombre d'éléments dans DOTYPE. S'il est zéro, DDRVBD
!>          ne fait rien. Il doit être au moins zéro. S'il vaut MAXTYP+1
!>          et que NSIZES vaut 1, alors un type supplémentaire, MAXTYP+1, est
!>          défini, qui consiste à utiliser quelles que soient les matrices présentes dans A et B.
!>          Cela n'est utile que si DOTYPE(1:MAXTYP) est .FALSE. et
!>          DOTYPE(MAXTYP+1) est .TRUE. .
!
>

DOTYP

E 
!>          DOTYPE est un tableau LOGICAL, dimension (NTYPES)
!>          Si DOTYPE(j) est .TRUE., alors pour chaque taille (m,n), une matrice
!>          de type j sera générée. Si NTYPES est inférieur au
!>          nombre maximal de types définis (PARAMETER MAXTYP), alors
!>          les types NTYPES+1 à MAXTYP ne seront pas générés. Si
!>          NTYPES est supérieur à MAXTYP, DOTYPE(MAXTYP+1) à
!>          DOTYPE(NTYPES) seront ignorés.
!> re>

ISEE
D

!>          ISEED est un tableau INTEGER de dimension (4)
!>          À l'entrée, la graine du générateur de nombres aléatoires. Les éléments
!>          du tableau doivent être compris entre 0 et 4095 ; sinon, ils seront
!>          réduits modulo 4096. De plus, ISEED(4) doit être impair.
!>          À la sortie, ISEED est modifié et peut être utilisé dans l'appel suivant à
!>          DDRVBD pour continuer la même séquence de nombres aléatoires.
!
>

THRES
H

!>          THRESH est de type DOUBLE PRECISION
!>          La valeur de seuil pour les rapports de test. Un résultat est
!>          inclus dans le fichier de sortie si RESULT >= THRESH. Les rapports
!>          de test sont mis à l'échelle pour être O(1), donc THRESH doit être un petit
!>          multiple de 1, p. ex., 10 ou 100. Pour que chaque rapport de test
!>          soit imprimé, utilisez THRESH = 0.
!
>

!>          Si 0, alors tout s'est déroulé correctement.
!>           -1: NSIZES < 0
