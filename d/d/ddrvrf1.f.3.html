DDRVRF1

Objectif :

!>
!> DDRVRF1 teste les routines RFP de LAPACK :
!>     DLANSF
!>

Paramètres

NOUT 
!>          NOUT est un ENTIER
!>                Le numéro de l'unité pour la sortie.
!>

NN

!>          NN est un ENTIER
!>                Le nombre de valeurs de N contenues dans le vecteur NVAL.
!>

NVAL

!>          NVAL est un tableau d'ENTIERS, de dimension (NN)
!>                Les valeurs de la dimension de la matrice N.
!>

THRESH

!>          THRESH est une DOUBLE PRÉCISION
!>                La valeur seuil pour les rapports de test. Un résultat est
!>                inclus dans le fichier de sortie si RESULTAT >= THRESH. Pour
!>                imprimer chaque rapport de test, utiliser THRESH = 0.
!>

A

!>          A est un tableau de DOUBLE PRÉCISION, de dimension (LDA,NMAX)
!>

LDA

!>          LDA est un ENTIER
!>                La dimension principale du tableau A. LDA >= max(1,NMAX).
!>

ARF

!>          ARF est un tableau de DOUBLE PRÉCISION, de dimension ((NMAX*(NMAX+1))/2).
!>

WORK

!>          WORK est un tableau de DOUBLE PRÉCISION, de dimension ( NMAX )
!>
