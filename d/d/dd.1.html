DD(1) Commandes utilisateur DD(1)

NOM

dd - convertir et copier un fichier

SYNTAXE

dd [OPÉRANDE]...
dd OPTION

DESCRIPTION

Copie un fichier, en convertissant et formatant selon les opérandes.

bs=OCTETS
lit et écrit jusqu'à OCTETS octets à la fois (par défaut : 512) ; remplace ibs et obs
cbs=OCTETS
convertit OCTETS octets à la fois
conv=CONVS
convertit le fichier selon la liste de symboles séparés par des virgules
count=N
copie seulement N blocs d'entrée
ibs=OCTETS
lit jusqu'à OCTETS octets à la fois (par défaut : 512)
if=FICHIER
lit depuis FICHIER au lieu de l'entrée standard
iflag=FLAGS
lit selon la liste de symboles séparés par des virgules
obs=OCTETS
écrit OCTETS octets à la fois (par défaut : 512)
of=FICHIER
écrit vers FICHIER au lieu de la sortie standard
oflag=FLAGS
écrit selon la liste de symboles séparés par des virgules
seek=N
(ou oseek=N) saute N blocs de sortie de taille obs
skip=N
(ou iseek=N) saute N blocs d'entrée de taille ibs
status=NIVEAU
Le NIVEAU d'information à imprimer sur la sortie d'erreur standard ; 'none' supprime tout sauf les messages d'erreur, 'noxfer' supprime les statistiques de transfert finales, 'progress' affiche des statistiques de transfert périodiques

N et OCTETS peuvent être suivis des suffixes multiplicatifs suivants : c=1, w=2, b=512, kB=1000, K=1024, MB=1000*1000, M=1024*1024, xM=M, GB=1000*1000*1000, G=1024*1024*1024, et ainsi de suite pour T, P, E, Z, Y, R, Q. Les préfixes binaires peuvent également être utilisés : KiB=K, MiB=M, et ainsi de suite. Si N se termine par 'B', il compte les octets et non les blocs.

Chaque symbole CONV peut être :

ascii
de EBCDIC vers ASCII
ebcdic
d'ASCII vers EBCDIC
ibm
d'ASCII vers EBCDIC alternatif
block
rembourre les enregistrements terminés par une nouvelle ligne avec des espaces jusqu'à la taille cbs
unblock
remplace les espaces de fin dans les enregistrements de taille cbs par une nouvelle ligne
lcase
convertit les majuscules en minuscules
ucase
convertit les minuscules en majuscules
sparse
tente de sauter plutôt que d'écrire des blocs de sortie entièrement NUL
swab
échange chaque paire d'octets d'entrée
sync
rembourre chaque bloc d'entrée avec des NUL jusqu'à la taille ibs ; lorsqu'il est utilisé avec block ou unblock, rembourre avec des espaces plutôt que des NUL
excl
échoue si le fichier de sortie existe déjà
nocreat
ne crée pas le fichier de sortie
notrunc
ne tronque pas le fichier de sortie
noerror
continue après les erreurs de lecture
fdatasync
écrit physiquement les données du fichier de sortie avant de terminer
fsync
de même, mais écrit aussi les métadonnées

Chaque symbole FLAG peut être :

append
mode ajout (n'a de sens qu'en sortie ; conv=notrunc suggéré)
direct
utilise les E/S directes pour les données
directory
échoue sauf si c'est un répertoire
dsync
utilise les E/S synchronisées pour les données
sync
de même, mais aussi pour les métadonnées
fullblock
accumule des blocs complets d'entrée (iflag seulement)
nonblock
utilise les E/S non bloquantes
noatime
ne met pas à jour l'heure d'accès
nocache
Demande de vider le cache. Voir aussi oflag=sync
noctty
n'assigne pas de terminal de contrôle à partir du fichier
nofollow
ne suit pas les liens symboliques

L'envoi d'un signal USR1 à un processus 'dd' en cours d'exécution le fait imprimer les statistiques d'E/S sur la sortie d'erreur standard, puis reprendre la copie.

Les options sont :

--help
affiche cette aide et quitte
--version
affiche les informations de version et quitte

DD(1)

coreutils — Copier et convertir les fichiers

NOM

dd — Copier et convertir les fichiers

SYNTAXE

dd [OPTION]...

DESCRIPTION

Copier un fichier et le convertir par la même occasion.

Lit depuis le fichier d'entrée IF= (par défaut, stdin), ou depuis le périphérique si non spécifié, et écrit vers le fichier de sortie OF= (par défaut, stdout), ou vers le périphérique si non spécifié.

SIZE peut être suivi d'un des suffixes multiplicatifs suivants : kB 1000, K 1024, MB 1000*1000, M 1024*1024, GB 1000*1000*1000, G 1024*1024*1024, et ainsi de suite pour T, P, E, Z, Y.

Options :

bs=SIZE
lit et écrit par blocs de SIZE octets.
count=N
copie seulement N blocs d'entrée.
skip=N
saute N blocs d'entrée.
seek=N
saute N blocs de sortie.
conv=conversion[,conversion]...
convertit les données par les méthodes suivantes :
ascii : convertit les caractères EBCDIC en ASCII.
ebcdic : convertit les caractères ASCII en EBCDIC.
ibm-overline : convertit les caractères ASCII en EBCDIC, en utilisant le jeu de caractères EBCDIC qui utilise des caractères de contrôle appropriés au lieu de caractères de contrôle dans le code de déplacement.
block : remplit les lignes trop courtes à BLOCKSIZE (voir plus bas).
unblock : supprime les caractères d'espacement de fin de ligne.
lcase : convertit les lettres majuscules en minuscules.
ucase : convertit les lettres minuscules en majuscules.
strip_trailing_crt : supprime les caractères de tabulation de fin de ligne.
sponse : remplace les espaces par des caractères de tabulation.
tabs : remplace les caractères de tabulation par des espaces.
sparse : réduit les fichiers en apparaissant comme des trous de zéros non alloués ; ne s'applique qu'aux fichiers de sortie qui sont des périphériques de stockage.
noerror : ne pas s'arrêter en cas d'erreur de lecture ; le faire si un périphérique est utilisé.
notrunc : ne pas tronquer le fichier de sortie.
fdatasync : vide physiquement le fichier de sortie sur le disque, en ne demandant au système d'exploitation que de transférer les données au pilote du périphérique.
fsync : vide physiquement le fichier de sortie sur le disque, en demandant au système d'exploitation de transférer les données et les métadonnées du fichier sur le disque.
--help
afficher l'aide et quitter.
--version
afficher les informations de version et quitter.

Les options if=IF, of=OF, blocks=SIZE, input_block_size=SIZE, et output_block_size=SIZE sont obsolètes, utilisez iflag et oflag à la place.
