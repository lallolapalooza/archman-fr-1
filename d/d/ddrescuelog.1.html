NOM

ddrescuelog - outil pour les fichiers de mappage de ddrescue

SYNTAXE

ddrescuelog [options] fichier_map

DESCRIPTION

GNU ddrescuelog est un outil qui manipule les fichiers de mappage de ddrescue, affiche le contenu des fichiers de mappage, convertit les fichiers de mappage vers/depuis d'autres formats, compare les fichiers de mappage, teste le statut de récupération, et peut supprimer un fichier de mappage si la récupération est terminée. Les opérations de ddrescuelog peuvent être restreintes à une ou plusieurs parties du fichier de mappage si les options de paramétrage de domaine sont utilisées.

Utilisez un trait d'union '-' comme fichier de mappage pour lire le fichier de mappage depuis l'entrée standard (également dans les options prenant un argument de fichier de mappage) ou pour écrire le fichier de mappage créé par '--create-mapfile' vers la sortie standard.

NOTE : Dans les versions de ddrescue antérieures à 1.20, le fichier de mappage s'appelait 'logfile'. Le format est le même ; seul le nom a changé.

OPTIONS

-h, --help
afficher cette aide et quitter
-V, --version
afficher les informations de version et quitter
-a, --change-types=<ot>,<nt>
changer les types de blocs du fichier de mappage
-A, --annotate-mapfile
ajouter des commentaires avec des positions/tailles lisibles par l'homme
-b, --block-size=<octets>
taille de bloc (secteur) en octets [défaut 512]
-B, --binary-prefixes
afficher les multiplicateurs binaires dans les nombres [SI]
-c, --create-mapfile[=<tt>]
créer un fichier de mappage à partir d'une liste de blocs [+-]
-C, --complete-mapfile[=<t>]
compléter le fichier de mappage en ajoutant des blocs de type t [?]
-d, --delete-if-done
supprimer le fichier de mappage si la récupération est terminée
-D, --done-status
retourner 0 si la récupération est terminée
-f, --force
écraser les fichiers de sortie existants
-F, --format=<nom>
format pour -c et -l (list, bitmap-[bl]e)
-i, --input-position=<octets>
position de départ du domaine de récupération [0]
-l, --list-blocks=<types>
afficher les numéros de bloc des types donnés (?*/-+)
-L, --loose-domain
accepter un fichier de mappage de domaine non ordonné avec des lacunes
-m, --domain-mapfile=<fichier>
restreindre le domaine aux blocs terminés dans <fichier>
-n, --invert-mapfile
inverser les types de blocs (terminé <--> autres)
-o, --output-position=<octets>
position de départ dans le fichier de sortie [ipos]
-p, --compare-mapfile=<fichier>
comparer les types de blocs dans le domaine des deux fichiers
-P, --compare-as-domain=<fichier>
comme -p mais compare uniquement les blocs terminés
-q, --quiet
supprimer tous les messages
-s, --size=<octets>
taille maximale du domaine de récupération à traiter
-t, --show-status
afficher un résumé du contenu du fichier de mappage
-v, --verbose
être verbeux (une deuxième fois -v donne plus d'informations)
-x, --xor-mapfile=<fichier>
XOR les blocs terminés dans <fichier> avec le fichier de mappage
-y, --and-mapfile=<fichier>
ET les blocs terminés dans <fichier> avec le fichier de mappage
-z, --or-mapfile=<fichier>
OU les blocs terminés dans <fichier> avec le fichier de mappage
--shift
décaler toutes les positions des blocs par (opos - ipos)

Les nombres peuvent être en décimal, hexadécimal ou octal, et peuvent être suivis d'un multiplicateur : s = secteurs, k = 1000, Ki = 1024, M = 10^6, Mi = 2^20, etc...

Statut de sortie : 0 pour une sortie normale, 1 pour des problèmes environnementaux (fichier non trouvé, options de ligne de commande invalides, erreurs d'E/S, etc.), 2 pour indiquer un fichier d'entrée corrompu ou invalide, 3 pour une erreur de cohérence interne (par exemple, un bug) qui a provoqué une panique de ddrescuelog.
