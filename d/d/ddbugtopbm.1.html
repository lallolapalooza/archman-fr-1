NOM

ddbugtopbm - convertir des croquis Diddle ou DiddleBug en fichiers PBM

SYNTAXE

ddbugtopbm

EXEMPLES

ddbugtopbm </chemin/vers/le/répertoire/de/sauvegarde/palm/DiddleBugDB.pdb
ddbugtopbm </chemin/vers/le/répertoire/de/sauvegarde/palm/DiddleDB.pdb
ddbugtopbm </chemin/vers/le/répertoire/de/sauvegarde/palm/DiddleIDB.pdb

DESCRIPTION

Ce programme fait partie de Netpbm(1)

ddbugtopbm convertit tous les croquis présents dans une base de données utilisée par les programmes PalmOS Diddle ou DiddleBug en fichiers PBM nommés de manière appropriée. La copie de sauvegarde de la base de données de DiddleBug que vous devriez utiliser comme entrée pour ce programme s'appelle généralement DiddleBugDB.pdb. Ou si vous utilisez le Diddle original, il possède deux bases de données distinctes : DiddleDB.pdb, contenant des croquis "brouillons" sans nom, et DiddleIDB.pdb, contenant les croquis sauvegardés (et nommés) qui sont listés par son option 'index'. Vous pouvez fournir l'un de ces trois fichiers à ce programme en entrée standard.

UTILISATION DU PROGRAMME

Je recommande de ne *pas* exécuter ddbugtopbm depuis votre répertoire de sauvegarde Palm, c'est-à-dire ne l'exécutez pas depuis le répertoire où la DB se trouverait normalement. Au lieu de cela, exécutez-le depuis un autre répertoire (peut-être pourriez-vous créer un répertoire uniquement pour contenir les fichiers PBM, pour simplifier les choses) et utilisez un chemin absolu ou relatif vers la DB.

Les noms de fichiers utilisés pour les PBM de sortie sont basés sur les noms donnés à chaque croquis ; si vous avez un croquis sans nom, il reçoit un nom du genre sketch-0123.pbm.

Bien que les croquis nommés écrasent tout fichier PBM existant portant le même nom, les croquis sans nom ne le font pas ; ils essaieront simplement d'utiliser un autre nom de fichier. (Je pense que c'est probablement la bonne approche, car vous ne pouvez pas vraiment distinguer les croquis sans nom.)

LIMITATIONS

Le lecteur de base de données DiddleBug est seulement connu pour fonctionner avec les DB de la version 2.50 de DiddleBug. Mais il devrait probablement fonctionner sur des versions ultérieures, et je pense qu'il fonctionnera également sur des DB de la version 2.15.

Il pourrait échouer si on lui fournit une base de données vide, et ne fait pas beaucoup de vérifications (voire aucune) sur l'entrée.
