NOM

dkimsign - Script pour signer des messages DKIM depuis stdin

VERSION

0.7.0

DESCRIPTION

dkimsign est un filtre qui lit un message RFC822 depuis l'entrée standard, et écrit le même message sur la sortie standard avec une ligne DKIM-Signature ajoutée en préfixe.

USAGE

utilisation : dkimsign.py [-h] [--hcanon {simple,relaxed}]
[--bcanon {simple,relaxed}]
[--signalg {rsa-sha256,ed25519-sha256,rsa-sha1}]
[--identity IDENTITÉ]
sélecteur domaine fichier-clé-privée

arguments positionnels obligatoires :
sélecteur
domaine
fichier-clé-privée

arguments optionnels :
-h, --help afficher ce message d'aide et quitter
--hcanon {simple,relaxed}
Algorithme de canonicalisation des en-têtes : par défaut=relaxed
--bcanon {simple,relaxed}
Algorithme de canonicalisation du corps : par défaut=simple
--signalg {rsa-sha256,ed25519-sha256,rsa-sha1}
Algorithme de signature : par défaut=rsa-sha256
--identity IDENTITÉ Valeur optionnelle pour le tag i=.
