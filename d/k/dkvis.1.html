NOM

dkvis - visualisation de l'activité et des performances des E/S disque

SYNTAXE

dkvis [-brVw] [-m maxrate] [-X ndisk] [-Y nctl] [options pmview] [diskid ...]

DESCRIPTION

dkvis affiche un graphique en barres tridimensionnel de l'activité disque. Chaque ligne de barres sur le plan de base représente un contrôleur de disque (ou adaptateur hôte, ou bus), et les barres dans une ligne correspondent aux disques attachés au contrôleur.

L'étiquette à gauche de chaque ligne identifie la partie commune du nom du disque pour tous les disques de cette ligne, par exemple dks3 pour tous les disques SCSI IRIX attachés au contrôleur numéro 3.

La hauteur des barres est proportionnelle à l'activité.

L'utilisateur peut spécifier une liste de disques sous forme d'arguments diskid en utilisant le schéma de nommage de disque rapporté par

$ pminfo -f disk.dev.total

par exemple hda ou dks0d4 ou sda ou scsi/host1/bus0/target4/lun0/disc ou 20000080e5114459/lun3/c2p1 selon le type de disques. Alternativement, si l'argument diskid contient l'un des caractères ^ ou . ou [ alors diskid sera traité comme une expression régulière dans le style de egrep(1) et l'ensemble correspondant de noms de disques sera utilisé à la place de diskid.

Si un ou plusieurs arguments diskid sont spécifiés, seuls les disques de cette liste sont affichés dans la vue. Les disques sont regroupés dans la scène par contrôleur comme dans la scène par défaut lorsque tous les disques sont présents.

dkvis génère un fichier de configuration pmview(1), et transmet la plupart des options de ligne de commande à pmview(1). Par conséquent, les options de ligne de commande -A, -a, -C, -h, -n, -O, -p, -S, -t, -T, -Z et -z, ainsi que l'interface utilisateur sont décrites dans la page de manuel pmview(1).

OPTIONS DE LIGNE DE COMMANDE

Les options spécifiques à dkvis sont :

-b
Rapporte l'activité comme débit de données en Kbytes par seconde plutôt que l'opération d'E/S par seconde (IOPS) par défaut.
-m
Utilise maxrate comme activité maximale à partir de laquelle les pourcentages d'utilisation sont calculés. Ceci spécifie effectivement la hauteur à laquelle les barres seront coupées. Si -b est spécifié, la valeur maximale par défaut est de 2048 Kbytes par seconde, sinon la valeur maximale par défaut est de 150 IOPS.
-r
Affiche l'activité de lecture. Par défaut, affiche l'activité totale (lecture et écriture).
-V
Mode verbeux - affiche le fichier de configuration pmview(1) généré.
-w
Affiche l'activité d'écriture. Par défaut, affiche l'activité totale (lecture et écriture).
-X
La disposition par défaut tente d'afficher jusqu'à 12 disques sur le même contrôleur dans une seule ligne. Lorsque plus de 12 disques sont associés à un contrôleur, des lignes supplémentaires sont créées dans une tentative d'obtenir une empreinte au sol pour la scène qui soit aussi proche que possible d'un carré.

L'option -X peut être utilisée pour remplacer l'algorithme de disposition par défaut et forcer une scène dans laquelle chaque ligne ne contient pas plus de ndisk disques.

-Y
La disposition par défaut tente d'afficher les disques pour jusqu'à 16 lignes de contrôleur dans un seul bloc. Lorsque plus de 16 lignes de contrôleur sont présentes, des blocs supplémentaires sont créés dans une tentative d'obtenir une empreinte au sol pour la scène qui soit aussi proche que possible d'un carré.

L'option -Y peut être utilisée pour remplacer l'algorithme de disposition par défaut et forcer une scène dans laquelle les blocs sont attribués de telle sorte que chacun ne contienne pas plus de nctl lignes de contrôleur.

Pour des raisons de compatibilité ascendante, -R est un synonyme obsolète de -Y .

Un seul type d'activité peut être affiché par invocation de dkvis, donc -r et -w sont mutuellement exclusifs.

INITIALISATION

Le comportement de pmchart(1) lorsqu'il est lancé depuis dkvis dépend du nombre de disques par ligne. S'il y a plus de 6 contrôleurs, un graphique distinct sera généré pour chaque colonne de disques. En d'autres termes, le premier disque de chaque contrôleur dans un graphique, le deuxième disque dans le graphique suivant, et ainsi de suite. Sinon, un graphique distinct sera généré pour chaque contrôleur de disque.

FICHIERS

$PCP_VAR_DIR/config/pmlogger/config.dkvis
Un fichier de configuration pmlogger(1) pour les métriques dkvis.
$PCP_SHARE_DIR/lib/pmview-args
Procédures shell pour l'analyse des options de ligne de commande de pmview(1).

ENVIRONNEMENT PCP

Les variables d'environnement avec le préfixe PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Sur chaque installation, le fichier /etc/pcp.conf contient les valeurs locales pour ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(4).
