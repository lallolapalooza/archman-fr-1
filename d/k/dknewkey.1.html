NOM

dknewkey - Génère de nouvelles paires de clés publiques/privées DKIM

VERSION

0.8.0

DESCRIPTION

dknewykey génère de nouvelles clés DKIM.

Pour les clés RSA, la taille par défaut est de 2048 bits. Ceci est contrôlé par la variable BITS_REQUIRED. Les clés ed25519 n'ont pas de taille variable.

Pour les clés RSA, il utilise openssl pour la génération. Par défaut, il suppose qu'il se trouve à /usr/bin/openssl. Ceci est contrôlé par la variable OPENSSL_BINARY. Pour les clés ed25519, PyNaCl (python-nacl sur Debian et dérivés) est utilisé. Pour les clés RSA, k=sha256 est maintenant inclus dans l'enregistrement DNS public pour empêcher une utilisation involontaire avec l'algorithme de hachage sha1 désormais obsolète (Voir RFC 8301).

UTILISATION

dknewkey.py [-h] [--ktype {rsa,ed25519}] nom_cle

arguments positionnels obligatoires :
nom_cle

arguments optionnels :
-h, --help afficher ce message d'aide et quitter
--ktype {rsa,ed25519}
Type de clé DKIM : Par défaut est rsa

NOTE : Selon le paquetage et la distribution, le chemin d'accès exact et le nom de l'exécutable peuvent varier.
