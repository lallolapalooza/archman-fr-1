sous-routine dlacn2 (n, v, x, isgn, est, kase, isave)
DLACN2 estime la 1-norme d'une matrice carrée, utilisant la communication inverse pour évaluer les produits matrice-vecteur.

Documentation de la fonction/sous-routine

sous-routine dlacn2 (integer n, double precision, dimension( * ) v, double precision, dimension( * ) x, integer, dimension( * ) isgn, double precision est, integer kase, integer, dimension( 3 ) isave)

DLACN2 estime la 1-norme d'une matrice carrée réelle, utilisant la communication inverse pour évaluer les produits matrice-vecteur.

But :

!>
!> DLACN2 estime la 1-norme d'une matrice carrée réelle A.
!> La communication inverse est utilisée pour évaluer les produits matrice-vecteur.
!>

Paramètres

N 
!>          N est un ENTIER
!>         L'ordre de la matrice.  N >= 1.
!>

V

!>          V est un tableau DOUBLE PRECISION, dimension (N)
!>         Lors du retour final, V = A*W,  où  EST = norm(V)/norm(W)
!>         (W n'est pas retourné).
!>

X

!>          X est un tableau DOUBLE PRECISION, dimension (N)
!>         Lors d'un retour intermédiaire, X doit être écrasé par
!>               A * X,   si KASE=1,
!>               A**T * X,  si KASE=2,
!>         et DLACN2 doit être rappelée avec tous les autres paramètres
!>         inchangés.
!>

ISGN

!>          ISGN est un tableau ENTIER, dimension (N)
!>

EST

!>          EST est DOUBLE PRECISION
!>         À l'entrée avec KASE = 1 ou 2 et ISAVE(1) = 3, EST doit être
!>         inchangé par rapport à l'appel précédent de DLACN2.
!>         À la sortie, EST est une estimation (une borne inférieure) de norm(A).
!>

KASE

!>          KASE est ENTIER
!>         Lors de l'appel initial de DLACN2, KASE doit être 0.
!>         Lors d'un retour intermédiaire, KASE sera 1 ou 2, indiquant
!>         si X doit être écrasé par A * X  ou A**T * X.
!>         Lors du retour final de DLACN2, KASE sera à nouveau 0.
!>

ISAVE

!>          ISAVE est un tableau ENTIER, dimension (3)
!>         ISAVE est utilisé pour sauvegarder des variables entre les appels
!>         à DLACN2.
!>
