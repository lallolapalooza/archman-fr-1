Documentation de la fonction/sous-routine

sous-routine dlarscl2 (entier m, entier n, double précision, dimension( * ) d, double précision, dimension( ldx, * ) x, entier ldx)

DLARSCL2 effectue une mise à l'échelle diagonale réciproque d'une matrice.

But :

!>
!> DLARSCL2 effectue une mise à l'échelle diagonale réciproque d'une matrice :
!>   x <-- inv(D) * x
!> où la matrice diagonale D est stockée comme un vecteur.
!>
!> Sera éventuellement remplacée par BLAS_dge_diag_scale dans la nouvelle
!> norme BLAS.
!>

Paramètres

M 
!>          M est ENTIER
!>     Le nombre de lignes de D et X. M >= 0.
!>

N

!>          N est ENTIER
!>     Le nombre de colonnes de X. N >= 0.
!>

D

!>          D est un tableau DOUBLE PRÉCISION, dimension (M)
!>     Matrice diagonale D, stockée comme un vecteur de longueur M.
!>

X

!>          X est un tableau DOUBLE PRÉCISION, dimension (LDX,N)
!>     À l'entrée, la matrice X à mettre à l'échelle par D.
!>     À la sortie, la matrice mise à l'échelle.
!>

LDX

!>          LDX est ENTIER
!>     La dimension principale de la matrice X. LDX >= M.
!>
