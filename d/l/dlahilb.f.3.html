Documentation de la fonction/sous-programme

sous-programme dlahilb (integer n, integer nrhs, double precision, dimension(lda, n) a, integer lda, double precision, dimension(ldx, nrhs) x, integer ldx, double precision, dimension(ldb, nrhs) b, integer ldb, double precision, dimension(n) work, integer info)

DLAHILB

But:

!>
!> DLAHILB génère une matrice de Hilbert N x N mise à l'échelle dans A, ainsi que
!> NRHS membres de droite en B et solutions en X tels que A*X=B.
!>
!> La matrice de Hilbert est mise à l'échelle par M = PPCM(1, 2, ..., 2*N-1) de sorte que toutes
!> les entrées soient des entiers. Les membres de droite sont les NRHS premières colonnes de
!> M * la matrice identité, et les solutions sont les
!> NRHS premières colonnes de la matrice de Hilbert inverse.
!>
!> Le nombre de condition de la matrice de Hilbert croît exponentiellement avec
!> sa taille, approximativement comme O(e ** (3.5*N)). De plus, les matrices de Hilbert inverses
!> au-delà d'une dimension relativement petite ne peuvent pas être
!> générées exactement sans précision supplémentaire. La précision est épuisée
!> lorsque la plus grande entrée de la matrice de Hilbert inverse est supérieure à
!> 2 élevé à la puissance du nombre de bits dans la fraction du type de données
!> utilisé plus un, qui est 24 pour la précision simple.
!>
!> En précision simple, la solution générée est exacte pour N <= 6 et a
!> une petite erreur composante pour 7 <= N <= 11.
!>

Paramètres

N 
!>          N est INTEGER
!>          La dimension de la matrice A.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre demandé de membres de droite.
!>

A

!>          A est un tableau DOUBLE PRECISION, dimension (LDA, N)
!>          La matrice de Hilbert mise à l'échelle générée.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= N.
!>

X

!>          X est un tableau DOUBLE PRECISION, dimension (LDX, NRHS)
!>          Les solutions exactes générées. Actuellement, les NRHS premières
!>          colonnes de la matrice de Hilbert inverse.
!>

LDX

!>          LDX est INTEGER
!>          La dimension principale du tableau X. LDX >= N.
!>

B

!>          B est un tableau DOUBLE PRECISION, dimension (LDB, NRHS)
!>          Les membres de droite générés. Actuellement, les NRHS premières
!>          colonnes de PPCM(1, 2, ..., 2*N-1) * la matrice identité.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B. LDB >= N.
!>

WORK

!>          WORK est un tableau DOUBLE PRECISION, dimension (N)
!>

INFO

!>          INFO est INTEGER
!>          = 0: sortie réussie
!>          = 1: N est trop grand; les données sont toujours générées mais peuvent ne pas
!>               être exactes.
!>          < 0: si INFO = -i, le i-ème argument avait une valeur illégale
!>
