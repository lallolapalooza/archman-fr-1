Documentation de la fonction/sous-routine

integer function dlaneg (integer n, double precision, dimension( * ) d, double precision, dimension( * ) lld, double precision sigma, double precision pivmin, integer r)

DLANEG calcule le compte de Sturm.

Objectif :

!>
!> DLANEG calcule le compte de Sturm, le nombre de pivots négatifs
!> rencontrés lors de la factorisation de T - sigma I = L D L^T.
!> Cette implémentation travaille directement sur les facteurs sans former
!> la matrice tridiagonale T. Le compte de Sturm est aussi le nombre
!> d'éléments propres de T inférieurs à sigma.
!>
!> Cette routine est appelée par DLARRB.
!>
!> La routine actuelle n'utilise pas le paramètre PIVMIN mais requiert plutôt
!> la propagation IEEE-754 des infinis et des NaN. Cette routine n'a pas
!> non plus de restrictions de plage d'entrée, mais requiert la gestion
!> par défaut des exceptions de manière à ce que x/0 produise Inf lorsque x est
!> non nul, et Inf/Inf produise NaN. Pour plus d'informations, voir :
!>
!>   Marques, Riedy, et Voemel, SIAM Journal on
!>   Scientific Computing, v28, n5, 2006. DOI 10.1137/050641624
!>   (Version rapport technique dans LAWN 172 avec le même titre.)
!>

Paramètres

N 
!>          N est INTEGER
!>          L'ordre de la matrice.
!>

D

!>          D est un tableau DOUBLE PRECISION, dimension (N)
!>          Les N éléments diagonaux de la matrice diagonale D.
!>

LLD

!>          LLD est un tableau DOUBLE PRECISION, dimension (N-1)
!>          Les (N-1) éléments L(i)*L(i)*D(i).
!>

SIGMA

!>          SIGMA est DOUBLE PRECISION
!>          Quantité de décalage dans T - sigma I = L D L^T.
!>

PIVMIN

!>          PIVMIN est DOUBLE PRECISION
!>          Le pivot minimum dans la séquence de Sturm. Peut être utilisé
!>          lorsque des pivots nuls sont rencontrés sur des architectures non-IEEE-754.
!>

R

!>          R est INTEGER
!>          L'indice de torsion pour la factorisation tordue qui est utilisée
!>          pour le calcul du nombre de pivots négatifs.
!>
