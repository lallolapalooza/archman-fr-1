Documentation de la fonction/sous-programme

sous-programme dlaed5 (integer i, double precision, dimension( 2 ) d, double precision, dimension( 2 ) z, double precision, dimension( 2 ) delta, double precision rho, double precision dlam)

DLAED5 utilisé par DSTEDC. Résout l'équation séculaire 2x2.

Objectif :

!>
!> Ce sous-programme calcule la I-ème valeur propre d'une modification
!> de rang un d'une matrice diagonale 2x2
!>
!>            diag( D )  +  RHO * Z * transpose(Z) .
!>
!> Les éléments diagonaux dans le tableau D sont supposés satisfaire
!>
!>            D(i) < D(j)  pour  i < j .
!>
!> Nous supposons également RHO > 0 et que la norme euclidienne du vecteur
!> Z est unitaire.
!>

Paramètres

I 
!>          I est un entier (INTEGER)
!>         L'indice de la valeur propre à calculer.  I = 1 ou I = 2.
!>

D

!>          D est un tableau de double précision (DOUBLE PRECISION), dimension (2)
!>         Les valeurs propres originales.  Nous supposons D(1) < D(2).
!>

Z

!>          Z est un tableau de double précision (DOUBLE PRECISION), dimension (2)
!>         Les composantes du vecteur de mise à jour.
!>

DELTA

!>          DELTA est un tableau de double précision (DOUBLE PRECISION), dimension (2)
!>         Le vecteur DELTA contient les informations nécessaires
!>         pour construire les vecteurs propres.
!>

RHO

!>          RHO est un double précision (DOUBLE PRECISION)
!>         Le scalaire dans la formule de mise à jour symétrique.
!>

DLAM

!>          DLAM est un double précision (DOUBLE PRECISION)
!>         La valeur calculée lambda_I, la I-ème valeur propre mise à jour.
!>
