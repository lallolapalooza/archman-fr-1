sous-routine dlaqr2 (logical wantt, logical wantz, integer n, integer ktop, integer kbot, integer nw, double precision, dimension( ldh, * ) h, integer ldh, integer iloz, integer ihiz, double precision, dimension( ldz, * ) z, integer ldz, integer ns, integer nd, double precision, dimension( * ) sr, double precision, dimension( * ) si, double precision, dimension( ldv, * ) v, integer ldv, integer nh, double precision, dimension( ldt, * ) t, integer ldt, integer nv, double precision, dimension( ldwv, * ) wv, integer ldwv, double precision, dimension( * ) work, integer lwork)

DLAQR2 effectue la transformation de similarité orthogonale d'une matrice de Hessenberg pour détecter et déflater les valeurs propres entièrement convergées d'une sous-matrice principale traînante (déflation précoce agressive).

But :

!>
!>    DLAQR2 est identique à DLAQR3 sauf qu'il évite
!>    la récursion en appelant DLAHQR au lieu de DLAQR4.
!>
!>    Déflation précoce agressive :
!>
!>    Cette sous-routine accepte en entrée une matrice de Hessenberg
!>    supérieure H et effectue une transformation de similarité
!>    orthogonale conçue pour détecter et déflater les valeurs propres
!>    entièrement convergées d'une sous-matrice principale traînante.
!>    En sortie, H a été écrasée par une nouvelle matrice de
!>    Hessenberg qui est une perturbation d'une transformation de
!>    similarité orthogonale de H. On espère que la version finale
!>    de H a de nombreuses entrées sous-diagonales nulles.
!>

Paramètres

WANTT 
!>          WANTT est de type LOGIQUEL
!>          Si .TRUE., alors la matrice de Hessenberg H est
!>          entièrement mise à jour de sorte que le facteur de
!>          Schur quasi-triangulaire puisse être calculé (en
!>          coopération avec la sous-routine appelante).
!>          Si .FALSE., alors seule la partie de H nécessaire est
!>          mise à jour pour préserver les valeurs propres.
!>

WANTZ

!>          WANTZ est de type LOGIQUEL
!>          Si .TRUE., alors la matrice orthogonale Z est mise à
!>          jour de sorte que le facteur de Schur orthogonal puisse
!>          être calculé (en coopération avec la sous-routine
!>          appelante).
!>          Si .FALSE., alors Z n'est pas référencée.
!>

N

!>          N est de type ENTIER
!>          L'ordre de la matrice H et (si WANTZ est .TRUE.) l'ordre
!>          de la matrice orthogonale Z.
!>

KTOP

!>          KTOP est de type ENTIER
!>          On suppose que soit KTOP = 1, soit H(KTOP,KTOP-1)=0.
!>          KBOT et KTOP déterminent ensemble un bloc isolé le long
!>          de la diagonale de la matrice de Hessenberg.
!>

KBOT

!>          KBOT est de type ENTIER
!>          On suppose sans vérification que soit KBOT = N, soit
!>          H(KBOT+1,KBOT)=0. KBOT et KTOP déterminent ensemble un
!>          bloc isolé le long de la diagonale de la matrice de
!>          Hessenberg.
!>

NW

!>          NW est de type ENTIER
!>          Taille de la fenêtre de déflation. 1 <= NW <= (KBOT-KTOP+1).
!>

H

!>          H est un tableau de type DOUBLE PRÉCISION, dimension (LDH,N)
!>          En entrée, la section initiale N par N de H stocke la
!>          matrice de Hessenberg subissant la déflation précoce
!>          agressive.
!>          En sortie, H a été transformée par une transformation de
!>          similarité orthogonale, perturbée, puis ramenée à la
!>          forme de Hessenberg qui (on l'espère) a certaines
!>          entrées sous-diagonales nulles.
!>

LDH

!>          LDH est de type ENTIER
!>          Dimension principale de H telle que déclarée dans la
!>          sous-routine appelante. N <= LDH
!>

ILOZ

!>          ILOZ est de type ENTIER
!>

IHIZ

!>          IHIZ est de type ENTIER
!>          Spécifient les lignes de Z auxquelles les transformations
!>          doivent être appliquées si WANTZ est .TRUE..
!>          1 <= ILOZ <= IHIZ <= N.
!>

Z

!>          Z est un tableau de type DOUBLE PRÉCISION, dimension (LDZ,N)
!>          Si WANTZ est .TRUE., alors en sortie, la transformation
!>          de similarité orthogonale mentionnée ci-dessus a été
!>          accumulée dans Z(ILOZ:IHIZ,ILOZ:IHIZ) par la droite.
!>          Si WANTZ est .FALSE., alors Z n'est pas référencée.
!>

LDZ

!>          LDZ est de type ENTIER
!>          La dimension principale de Z telle que déclarée dans la
!>          sous-routine appelante. 1 <= LDZ.
!>

NS

!>          NS est de type ENTIER
!>          Le nombre de valeurs propres non convergées (c.-à-d.
!>          approximatives) retournées dans SR et SI qui peuvent être
!>          utilisées comme décalages par la sous-routine appelante.
!>

ND

!>          ND est de type ENTIER
!>          Le nombre de valeurs propres convergées découvertes par
!>          cette sous-routine.
!>

SR

!>          SR est un tableau de type DOUBLE PRÉCISION, dimension (KBOT)
!>

SI

!>          SI est un tableau de type DOUBLE PRÉCISION, dimension (KBOT)
!>          En sortie, les parties réelle et imaginaire des valeurs
!>          propres approximatives pouvant servir de décalages sont
!>          stockées respectivement dans SR(KBOT-ND-NS+1) à
!>          SR(KBOT-ND) et SI(KBOT-ND-NS+1) à SI(KBOT-ND).
!>          Les parties réelle et imaginaire des valeurs propres
!>          convergées sont stockées respectivement dans
!>          SR(KBOT-ND+1) à SR(KBOT) et SI(KBOT-ND+1) à SI(KBOT).
!>

V

!>          V est un tableau de type DOUBLE PRÉCISION, dimension (LDV,NW)
!>          Un tableau de travail NW par NW.
!>

LDV

!>          LDV est de type ENTIER
!>          La dimension principale de V telle que déclarée dans la
!>          sous-routine appelante. NW <= LDV
!>

NH

!>          NH est de type ENTIER
!>          Le nombre de colonnes de T. NH >= NW.
!>

T

!>          T est un tableau de type DOUBLE PRÉCISION, dimension (LDT,NW)
!>

LDT

!>          LDT est de type ENTIER
!>          La dimension principale de T telle que déclarée dans la
!>          sous-routine appelante. NW <= LDT
!>

NV

!>          NV est de type ENTIER
!>          Le nombre de lignes du tableau de travail WV disponibles
!>          pour l'espace de travail. NV >= NW.
!>

WV

!>          WV est un tableau de type DOUBLE PRÉCISION, dimension (LDWV,NW)
!>

LDWV

!>          LDWV est de type ENTIER
!>          La dimension principale de W telle que déclarée dans la
!>          sous-routine appelante. NW <= LDV
!>

WORK

!>          WORK est un tableau de type DOUBLE PRÉCISION, dimension (LWORK)
!>          À la sortie, WORK(1) est défini à une estimation de la
!>          valeur optimale de LWORK pour les valeurs données de N,
!>          NW, KTOP et KBOT.
!>

LWORK

!>          LWORK est de type ENTIER
!>          La dimension du tableau de travail WORK. LWORK = 2*NW
!>          est suffisant, mais une plus grande efficacité peut
!>          résulter de valeurses de LWORK.
!>
!>          Si LWORK = -1, une interrogation d'espace de travail est supposée ; DLAQR2
!>          estime uniquement la taille optimale de l'espace de travail pour les valeurs
!>          données de N, NW, KTOP et KBOT. L'estimation est renvoyée
!>          dans WORK(1). Aucun message d'erreur lié à LWORK n'est émis
!>          par XERBLA. Ni H ni Z ne sont accédés.
!>
