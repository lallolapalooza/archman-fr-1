sous-programme dlaed4 (entier n, entier i, double précision, dimension( * ) d, double précision, dimension( * ) z, double précision, dimension( * ) delta, double précision rho, double précision dlam, entier info)

DLAED4 utilisé par DSTEDC. Trouve une racine unique de l'équation séculaire.

Objectif :

!>
!> Ce sous-programme calcule la I-ième valeur propre mise à jour d'une
!> modification de rang un d'une matrice diagonale dont les éléments sont
!> donnés dans le tableau d, et tel que
!>
!>            D(i) < D(j)  pour  i < j
!>
!> et que RHO > 0. Ceci est organisé par la routine appelante, et ne constitue
!> aucune perte de généralité. Le système modifié de rang un est donc
!>
!>            diag( D )  +  RHO * Z * Z_transpose.
!>
!> où nous supposons que la norme euclidienne de Z est 1.
!>
!> La méthode consiste à approximer les fonctions rationnelles dans l'équation
!> séculaire par des fonctions rationnelles interpolatrices plus simples.
!>

Paramètres

N 
!>          N est ENTIER
!>         La longueur de tous les tableaux.
!>

I

!>          I est ENTIER
!>         L'indice de la valeur propre à calculer.  1 <= I <= N.
!>

D

!>          D est un tableau DOUBLE PRÉCISION, dimension (N)
!>         Les valeurs propres d'origine. On suppose qu'elles sont en
!>         ordre, D(I) < D(J)  pour I < J.
!>

Z

!>          Z est un tableau DOUBLE PRÉCISION, dimension (N)
!>         Les composantes du vecteur de mise à jour.
!>

DELTA

!>          DELTA est un tableau DOUBLE PRÉCISION, dimension (N)
!>         Si N > 2, DELTA contient (D(j) - lambda_I) dans sa j-ème
!>         composante.  Si N = 1, alors DELTA(1) = 1. Si N = 2, voir DLAED5
!>         pour les détails. Le vecteur DELTA contient les informations nécessaires
!>         pour construire les vecteurs propres par DLAED3 et DLAED9.
!>

RHO

!>          RHO est DOUBLE PRÉCISION
!>         Le scalaire dans la formule de mise à jour symétrique.
!>

DLAM

!>          DLAM est DOUBLE PRÉCISION
!>         Le lambda_I calculé, la I-ième valeur propre mise à jour.
!>

INFO

!>          INFO est ENTIER
!>         = 0 : sortie réussie
!>         > 0 : si INFO = 1, le processus de mise à jour a échoué.
!>

Paramètres internes :

!>  La variable logique ORGATI (origin-at-i?) est utilisée pour distinguer
!>  si D(i) ou D(i+1) est traité comme origine.
!>
!>            ORGATI = .vrai.    origine à i
!>            ORGATI = .faux.   origine à i+1
!>
!>   La variable logique SWTCH3 (switch-for-3-poles?) sert à noter
!>   si nous travaillons avec TROIS pôles !
!>
!>   MAXIT est le nombre maximum d'itérations autorisées pour chaque
!>   valeur propre.
!>
