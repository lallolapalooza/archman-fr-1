double precision function dlatm2 (integer m, integer n, integer i, integer j, integer kl, integer ku, integer idist, integer, dimension( 4 ) iseed, double precision, dimension( * ) d, integer igrade, double precision, dimension( * ) dl, double precision, dimension( * ) dr, integer ipvtng, integer, dimension( * ) iwork, double precision sparse)

DLATM2

Objectif :

!>
!>    DLATM2 retourne l'entrée (I,J) d'une matrice aléatoire de dimension
!>    (M, N) décrite par les autres paramètres. Elle est appelée par la
!>    routine DLATMR afin de construire des matrices de test aléatoires. Aucune vérification
!>    d'erreurs sur les paramètres n'est effectuée, car cette routine est appelée dans
!>    une boucle serrée par DLATMR qui a déjà vérifié les paramètres.
!>
!>    L'utilisation de DLATM2 diffère de SLATM3 dans l'ordre dans lequel le générateur
!>    de nombres aléatoires est appelé pour remplir les entrées de la matrice aléatoire.
!>    Avec DLATM2, le générateur est appelé pour remplir la matrice pivotée
!>    colonne par colonne. Avec DLATM3, le générateur est appelé pour remplir la
!>    matrice colonne par colonne, après quoi elle est pivotée. Ainsi, DLATM3 peut
!>    être utilisé pour construire des matrices aléatoires qui diffèrent uniquement par leur
!>    ordre de lignes et/ou de colonnes. DLATM2 est utilisé pour construire des matrices bande
!>    tout en évitant d'appeler le générateur de nombres aléatoires pour les entrées en dehors
!>    de la bande (et donc en générant des nombres aléatoires
!>
!>    La matrice dont l'entrée (I,J) est retournée est construite comme
!>    suit (cette routine ne calcule qu'une seule entrée) :
!>
!>      Si I est hors de (1..M) ou J est hors de (1..N), retourner zéro
!>         (cela est pratique pour générer des matrices au format bande).
!>
!>      Générer une matrice A avec des entrées aléatoires de distribution IDIST.
!>
!>      Définir la diagonale à D.
!>
!>      Graduer la matrice, si désiré, à gauche (par DL) et/ou
!>         à droite (par DR ou DL) comme spécifié par IGRADE.
!>
!>      Permuter, si désiré, les lignes et/ou colonnes comme spécifié par
!>         IPVTNG et IWORK.
!>
!>      Mettre la matrice en bande pour avoir une bande inférieure KL et une bande supérieure
!>         KU.
!>
!>      Définir les entrées aléatoires à zéro comme spécifié par SPARSE.
!>

Paramètres

M 
!>          M est INTEGER
!>           Nombre de lignes de la matrice. Non modifié.
!>

N

!>          N est INTEGER
!>           Nombre de colonnes de la matrice. Non modifié.
!>

I

!>          I est INTEGER
!>           Ligne de l'entrée à retourner. Non modifiée.
!>

J

!>          J est INTEGER
!>           Colonne de l'entrée à retourner. Non modifiée.
!>

KL

!>          KL est INTEGER
!>           Bande inférieure. Non modifié.
!>

KU

!>          KU est INTEGER
!>           Bande supérieure. Non modifié.
!>

IDIST

!>          IDIST est INTEGER
!>           En entrée, IDIST spécifie le type de distribution à utiliser
!>           pour générer une matrice aléatoire.
!>           1 => UNIFORME( 0, 1 )
!>           2 => UNIFORME( -1, 1 )
!>           3 => NORMALE( 0, 1 )
!>           Non modifié.
!>

ISEED

!>          ISEED est un tableau INTEGER de dimension ( 4 )
!>           Graine pour le générateur de nombres aléatoires.
!>           Modifié en sortie.
!>

D

!>          D est un tableau DOUBLE PRECISION de dimension ( MIN( I , J ) )
!>           Entrées diagonales de la matrice. Non modifié.
!>

IGRADE

!>          IGRADE est INTEGER
!>           Spécifie la gradation de la matrice comme suit :
!>           0  => pas de gradation
!>           1  => matrice pré-multipliée par diag( DL )
!>           2  => matrice post-multipliée par diag( DR )
!>           3  => matrice pré-multipliée par diag( DL ) et
!>                         post-multipliée par diag( DR )
!>           4  => matrice pré-multipliée par diag( DL ) et
!>                         post-multipliée par inv( diag( DL ) )
!>           5  => matrice pré-multipliée par diag( DL ) et
!>                         post-multipliée par diag( DL )
!>           Non modifié.
!>

DL

!>          DL est un tableau DOUBLE PRECISION ( I ou J, selon le cas )
!>           Facteurs d'échelle gauche pour la gradation de la matrice. Non modifié.
!>

DR

!>          DR est un tableau DOUBLE PRECISION ( I ou J, selon le cas )
!>           Facteurs d'échelle droite pour la gradation de la matrice. Non modifié.
!>

IPVTNG

!>          IPVTNG est INTEGER
!>           En entrée, spécifie les permutations de pivotement comme suit :
!>           0 => aucune.
!>           1 => pivotement de lignes.
!>           2 => pivotement de colonnes.
!>           3 => pivotement complet, c'est-à-dire des deux côtés.
!>           Non modifié.
!>

IWORK

!>          IWORK est un tableau INTEGER ( I ou J, selon le cas )
!>           Ce tableau spécifie la permutation utilisée. La
!>           ligne (ou colonne) à la position K était initialement à la
!>           position IWORK( K ).
!>           Ceci diffère de IWORK pour DLATM3. Non modifié.
!>

SPARSE

!>          SPARSE est DOUBLE PRECISION entre 0. et 1.
!>           En entrée, spécifie la sparsité de la matrice
!>           si une matrice creuse doit être générée.
!>           SPARSE doit être compris entre 0 et 1.
!>           Un nombre aléatoire uniforme ( 0, 1 ) x est généré et
!>           comparé à SPARSE ; si x est plus grand, l'entrée de la matrice
!>           n'est pas modifiée et si x est plus petit, l'entrée est mise
!>           à zéro. Ainsi, en moyenne, une fraction SPARSE des
!>           entrées sera mise à zéro.
!>           Non modifié.
!>
