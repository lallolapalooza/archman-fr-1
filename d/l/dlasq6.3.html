subroutine dlasq6 (i0, n0, z, pp, dmin, dmin1, dmin2, dn, dnm1, dnm2)
DLASQ6 calcule une transformation dqd en forme ping-pong. Utilisé par sbdsqr et sstegr.

Documentation de la fonction/sous-programme

sous-routine dlasq6 (integer i0, integer n0, double precision, dimension( * ) z, integer pp, double precision dmin, double precision dmin1, double precision dmin2, double precision dn, double precision dnm1, double precision dnm2)

DLASQ6 calcule une transformation dqd (décalage égal à zéro) en forme ping-pong, avec protection contre le sous-dépassement et le dépassement de capacité.

Objectif:

!>
!> DLASQ6 calcule une transformation dqd (décalage égal à zéro) en
!> forme ping-pong, avec protection contre le sous-dépassement et le dépassement
!> de capacité.
!>

Paramètres

I0 
!>          I0 est un entier
!>        Premier indice.
!>

N0

!>          N0 est un entier
!>        Dernier indice.
!>

Z

!>          Z est un tableau de double précision, dimension ( 4*N )
!>        Z contient le tableau qd. EMIN est stocké dans Z(4*N0) pour éviter
!>        un argument supplémentaire.
!>

PP

!>          PP est un entier
!>        PP=0 pour ping, PP=1 pour pong.
!>

DMIN

!>          DMIN est double précision
!>        Valeur minimale de d.
!>

DMIN1

!>          DMIN1 est double précision
!>        Valeur minimale de d, excluant D( N0 ).
!>

DMIN2

!>          DMIN2 est double précision
!>        Valeur minimale de d, excluant D( N0 ) et D( N0-1 ).
!>

DN

!>          DN est double précision
!>        d(N0), la dernière valeur de d.
!>

DNM1

!>          DNM1 est double précision
!>        d(N0-1).
!>

DNM2

!>          DNM2 est double précision
!>        d(N0-2).
!>
