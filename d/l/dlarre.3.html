sous-routine dlarre (character range, integer n, double precision vl, double precision vu, integer il, integer iu, double precision, dimension( * ) d, double precision, dimension( * ) e, double precision, dimension( * ) e2, double precision rtol1, double precision rtol2, double precision spltol, integer nsplit, integer, dimension( * ) isplit, integer m, double precision, dimension( * ) w, double precision, dimension( * ) werr, double precision, dimension( * ) wgap, integer, dimension( * ) iblock, integer, dimension( * ) indexw, double precision, dimension( * ) gers, double precision pivmin, double precision, dimension( * ) work, integer, dimension( * ) iwork, integer info)

DLARRE étant donné la matrice tridiagonale T, met à zéro les éléments hors diagonale petits et, pour chaque bloc non réduit Ti, trouve les représentations de base et les valeurs propres.

But :

!>
!> Pour trouver les valeurs propres désirées d'une matrice
!> tridiagonale réelle symétrique T donnée, DLARRE met à zéro
!> les éléments hors diagonale  et, pour chaque bloc non réduit
!> T_i, il trouve
!> (a) un décalage approprié à une extrémité du spectre du bloc,
!> (b) la représentation de base, T_i - sigma_i I = L_i D_i L_i^T, et
!> (c) les valeurs propres de chaque L_i D_i L_i^T.
!> Les représentations et les valeurs propres trouvées sont ensuite
!> utilisées par DSTEMR pour calculer les vecteurs propres de T.
!> La précision varie selon que la bissection est utilisée pour
!> trouver quelques valeurs propres ou l'algorithme dqds (sous-routine
!> DLASQ2) pour calculer toutes les valeurs propres puis en écarter
!> les indésirables.
!> En bonus, DLARRE sort également les n intervalles de
!> Gerschgorin pour les matrices L_i D_i L_i^T.
!>

Paramètres

RANGE 
!>          RANGE est CHARACTER*1
!>          = 'A' : () toutes les valeurs propres seront trouvées.
!>          = 'V' : () toutes les valeurs propres dans l'intervalle
!>                           semi-ouvert (VL, VU] seront trouvées.
!>          = 'I' : () les valeurs propres de la IL-ième à la IU-ième
!>                           (de la matrice entière) seront trouvées.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice. N > 0.
!>

VL

!>          VL est DOUBLE PRECISION
!>          Si RANGE='V', la borne inférieure des valeurs propres.
!>          Les valeurs propres inférieures ou égales à VL, ou
!>          supérieures à VU, ne seront pas retournées. VL < VU.
!>          Si RANGE='I' ou ='A', DLARRE calcule des bornes sur la
!>          partie désirée du spectre.
!>

VU

!>          VU est DOUBLE PRECISION
!>          Si RANGE='V', la borne supérieure des valeurs propres.
!>          Les valeurs propres inférieures ou égales à VL, ou
!>          supérieures à VU, ne seront pas retournées. VL < VU.
!>          Si RANGE='I' ou ='A', DLARRE calcule des bornes sur la
!>          partie désirée du spectre.
!>

IL

!>          IL est INTEGER
!>          Si RANGE='I', l'indice de la
!>          plus petite valeur propre à retourner.
!>          1 <= IL <= IU <= N.
!>

IU

!>          IU est INTEGER
!>          Si RANGE='I', l'indice de la
!>          plus grande valeur propre à retourner.
!>          1 <= IL <= IU <= N.
!>

D

!>          D est un tableau DOUBLE PRECISION, dimension (N)
!>          À l'entrée, les N éléments diagonaux de la matrice
!>          tridiagonale T.
!>          À la sortie, les N éléments diagonaux des matrices
!>          diagonales D_i.
!>

E

!>          E est un tableau DOUBLE PRECISION, dimension (N)
!>          À l'entrée, les premières (N-1) entrées contiennent les
!>          éléments sous-diagonaux de la matrice tridiagonale T ;
!>          E(N) n'a pas besoin d'être défini.
!>          À la sortie, E contient les éléments sous-diagonaux des
!>          matrices bidiagonales unitaires L_i. Les entrées
!>          E( ISPLIT( I ) ), 1 <= I <= NSPLIT, contiennent les points
!>          de base sigma_i en sortie.
!>

E2

!>          E2 est un tableau DOUBLE PRECISION, dimension (N)
!>          À l'entrée, les premières (N-1) entrées contiennent les
!>          CARRÉS des éléments sous-diagonaux de la matrice
!>          tridiagonale T ; E2(N) n'a pas besoin d'être défini.
!>          À la sortie, les entrées E2( ISPLIT( I ) ),
!>          1 <= I <= NSPLIT, ont été mises à zéro
!>

RTOL1

!>          RTOL1 est DOUBLE PRECISION
!>

RTOL2

!>          RTOL2 est DOUBLE PRECISION
!>           Paramètres pour la bissection.
!>           Un intervalle [LEFT,RIGHT] a convergé si
!>           RIGHT-LEFT < MAX( RTOL1*GAP, RTOL2*MAX(|LEFT|,|RIGHT|) )
!>

SPLTOL

!>          SPLTOL est DOUBLE PRECISION
!>          Le seuil pour la division en blocs.
!>

NSPLIT

!>          NSPLIT est INTEGER
!>          Le nombre de blocs en lesquels T se divise. 1 <= NSPLIT <= N.
!>

ISPLIT

!>          ISPLIT est un tableau INTEGER, dimension (N)
!>          Les points de division, auxquels T se sépare en blocs.
!>          Le premier bloc est constitué des lignes/colonnes 1 à
!>          ISPLIT(1), le deuxième des lignes/colonnes ISPLIT(1)+1 à
!>          ISPLIT(2), etc., et le NSPLIT-ième est constitué des
!>          lignes/colonnes ISPLIT(NSPLIT-1)+1 à ISPLIT(NSPLIT)=N.
!>

M

!>          M est INTEGER
!>          Le nombre total de valeurs propres (de tous les
!>          L_i D_i L_i^T) trouvées.
!>

W

!>          W est un tableau DOUBLE PRECISION, dimension (N)
!>          Les M premiers éléments contiennent les valeurs propres.
!>          Les valeurs propres de chacun des blocs, L_i D_i L_i^T,
!>          sont triées en ordre croissant (DLARRE peut utiliser les
!>          N-M éléments restants comme espace de travail).
!>

WERR

!>          WERR est un tableau DOUBLE PRECISION, dimension (N)
!>          La borne d'erreur sur la valeur propre correspondante dans W.
!>

WGAP

!>          WGAP est un tableau DOUBLE PRECISION, dimension (N)
!>          La séparation par rapport à la valeur propre voisine de
!>          droite dans W. L'écart n'est considéré qu'entre les valeurs
!>          propres du même bloc, car chaque bloc a son propre arbre de
!>          représentation.
!>          Exception : à l'extrémité droite d'un bloc, nous stockons
!>          l'écart gauche
!>

IBLOCK

!>          IBLOCK est un tableau INTEGER, dimension (N)
!>          Les indices des blocs (sous-matrices) associés aux valeurs
!>          propres correspondantes dans W ; IBLOCK(i)=1 si la valeur
!>          propre W(i) appartient au premier bloc en partant du haut,
!>          =2 si W(i) appartient au deuxième bloc, etc.
!>

INDEXW

!>          INDEXW est un tableau INTEGER, dimension (N)
!>          Les indices des valeurs propres au sein de chaque bloc
!>          (sous-matrice) ; par exemple, INDEXW(i)= 10 et IBLOCK(i)=2 implique que
!>          la i-ème valeur propre W(i) est la 10-ème valeur propre dans le bloc 2
!>

GERS

!>          GERS est un tableau DOUBLE PRECISION, de dimension (2*N)
!>          Les N intervalles de Gerschgorin (le i-ème intervalle de
!>          Gerschgorin est (GERS(2*i-1), GERS(2*i)).
!>

PIVMIN

!>          PIVMIN est DOUBLE PRECISION
!>          Le pivot minimum dans la suite de Sturm pour T.
!>

WORK

!>          WORK est un tableau DOUBLE PRECISION, de dimension (6*N)
!>          Espace de travail.
!>

IWORK

!>          IWORK est un tableau INTEGER, de dimension (5*N)
!>          Espace de travail.
!>

INFO

!>          INFO est INTEGER
!>          = 0:  sortie réussie
!>          > 0:  Un problème est survenu dans DLARRE.
!>          < 0:  Une des sous-routines appelées a signalé un problème interne.
!>                Nécessite l'inspection du paramètre correspondant IINFO
!>                pour plus d'informations.
!>
!>          =-1:  Problème dans DLARRD.
!>          = 2:  Aucune représentation de base n'a pu être trouvée en MAXTRY itérations.
!>                Augmenter MAXTRY et recompiler pourrait être un remède.
!>          =-3:  Problème dans DLARRB lors du calcul de la représentation
!>                de racine affinée pour DLASQ2.
!>          =-4:  Problème dans DLARRB lors de la bissection sur la
!>                partie souhaitée du spectre.
!>          =-5:  Problème dans DLASQ2.
!>          =-6:  Problème dans DLASQ2.
!>
