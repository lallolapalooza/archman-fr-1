NOM

dlopen-notes.py

SYNTAXE

dlopen-notes.py [-r] [-s] [-f [FONCTIONNALITÉ1,FONCTIONNALITÉ2]] [-h] nom_fichier [nom_fichier ...]

DESCRIPTION

Lit les notes .note.dlopen des fichiers ELF et rapporte leur contenu.

Les binaires ELF stockent les dépendances au moment de l'édition des liens dans leurs en-têtes, lesquelles peuvent être analysées par divers outils. Il n'existe pas de métadonnées lisibles par machine concernant les dépendances chargées au moment de la compilation via dlopen(3) disponibles par défaut. La spécification des métadonnées ELF pour dlopen vise à combler cette lacune en définissant un format commun. Voir https://systemd.io/ELF_DLOPEN_METADATA/.

Cet outil permet d'analyser une telle note et d'afficher le résultat dans divers formats.

nom_fichier
Fichier bibliothèque à partir duquel extraire les notes

OPTIONS

-r, --brut
Affiche le JSON original extrait des fichiers d'entrée
-s, --sonames
Liste tous les sonames et leurs priorités, un soname par ligne
-f [FONCTIONNALITÉ1,FONCTIONNALITÉ2], --fonctionnalités [FONCTIONNALITÉ1,FONCTIONNALITÉ2]
Décrit les fonctionnalités, peut être spécifié plusieurs fois

COMMENTAIRES

Si aucune option n'est spécifiée, --brut est la valeur par défaut.
