Documentation de la fonction/sous-routine

subroutine dlaqz2 (logical, intent(in) ilq, logical, intent(in) ilz, integer, intent(in) k, integer, intent(in) istartm, integer, intent(in) istopm, integer, intent(in) ihi, double precision, dimension( lda, * ) a, integer, intent(in) lda, double precision, dimension( ldb, * ) b, integer, intent(in) ldb, integer, intent(in) nq, integer, intent(in) qstart, double precision, dimension( ldq, * ) q, integer, intent(in) ldq, integer, intent(in) nz, integer, intent(in) zstart, double precision, dimension( ldz, * ) z, integer, intent(in) ldz)

DLAQZ2

Objectif :

!>
!>      DLAQZ2 fait glisser une protubérance de décalage 2x2 d'une position vers le bas dans un pinceau de matrices
!>

Paramètres

ILQ 
!>          ILQ est LOGICAL
!>              Détermine si la matrice Q doit être mise à jour ou non
!>

ILZ

!>          ILZ est LOGICAL
!>              Détermine si la matrice Z doit être mise à jour ou non
!>

K

!>          K est INTEGER
!>              Indice indiquant la position de la protubérance.
!>              À l'entrée, la protubérance est située dans
!>              (A(k+1:k+2,k:k+1),B(k+1:k+2,k:k+1)).
!>              À la sortie, la protubérance est située dans
!>              (A(k+2:k+3,k+1:k+2),B(k+2:k+3,k+1:k+2)).
!>

ISTARTM

!>          ISTARTM est INTEGER
!>

ISTOPM

!>          ISTOPM est INTEGER
!>              Les mises à jour de (A,B) sont limitées à
!>              (istartm:k+3,k:istopm). On suppose
!>              sans vérification que istartm <= k+1 et
!>              k+2 <= istopm
!>

IHI

!>          IHI est INTEGER
!>

A

!>          A est un tableau DOUBLE PRECISION, dimension (LDA,N)
!>

LDA

!>          LDA est INTEGER
!>              La dimension principale de A telle que déclarée dans
!>              la procédure appelante.
!>

B

!>          B est un tableau DOUBLE PRECISION, dimension (LDB,N)
!>

LDB

!>          LDB est INTEGER
!>              La dimension principale de B telle que déclarée dans
!>              la procédure appelante.
!>

NQ

!>          NQ est INTEGER
!>              L'ordre de la matrice Q
!>

QSTART

!>          QSTART est INTEGER
!>              Indice de départ de la matrice Q. Les rotations sont appliquées
!>              aux colonnes k+2-qStart:k+4-qStart de Q.
!>

Q

!>          Q est un tableau DOUBLE PRECISION, dimension (LDQ,NQ)
!>

LDQ

!>          LDQ est INTEGER
!>              La dimension principale de Q telle que déclarée dans
!>              la procédure appelante.
!>

NZ

!>          NZ est INTEGER
!>              L'ordre de la matrice Z
!>

ZSTART

!>          ZSTART est INTEGER
!>              Indice de départ de la matrice Z. Les rotations sont appliquées
!>              aux colonnes k+1-qStart:k+3-qStart de Z.
!>

Z

!>          Z est un tableau DOUBLE PRECISION, dimension (LDZ,NZ)
!>

LDZ

!>          LDZ est INTEGER
!>              La dimension principale de Q telle que déclarée dans
!>              la procédure appelante.
!>
