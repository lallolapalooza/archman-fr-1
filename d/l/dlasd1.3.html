DLASD1 calcule la SVD d'une matrice bidiagonale supérieure B de la taille spécifiée. Utilisé par

sbdsdc.

But

: 
!>
!> DLASD1 calcule la SVD d'une matrice bidiagonale supérieure B de
!> dimension N par M, où N = NL + NR + 1 et M = N + SQRE. DLASD1 est
!> appelé depuis DLASD0.
!>
!> Une sous-routine connexe, DLASD7, traite le cas où les valeurs
!> singulières (et les vecteurs singuliers sous forme factorisée) sont
!> souhaitées.
!>
!> DLASD1 calcule la SVD comme suit :
!>
!>               ( D1(in)    0    0       0 )
!>   B = U(in) * (   Z1**T   a   Z2**T    b ) * VT(in)
!>               (   0       0   D2(in)   0 )
!>
!>     = U(out) * ( D(out) 0) * VT(out)
!>
!> où Z**T = (Z1**T a Z2**T b) = u**T VT**T, et u est un vecteur de
!> dimension M avec ALPHA et BETA aux entrées NL+1 et NL+2 et des zéros
!> ailleurs ; et l'entrée b est vide si SQRE = 0.
!>
!> Les vecteurs singuliers gauches de la matrice originale sont stockés
!> dans U, et la transposée des vecteurs singuliers droits est stockée
!> dans VT, et les valeurs singulières sont dans D. L'algorithme se
!> compose de trois étapes :
!>
!>    La première étape consiste à déflater la taille du problème
!>    lorsqu'il y a des valeurs singulières multiples ou lorsqu'il y a
!>    des zéros dans le vecteur Z. Pour chaque occurrence de ce type,
!>    la dimension du problème de l'équation séculaire est réduite
!>    d'une unité. Cette étape est réalisée par la routine DLASD2.
!>
!>    La deuxième étape consiste à calculer les valeurs singulières
!>    mises à jour. Cela se fait en trouvant les racines carrées des
!>    racines de l'équation séculaire via la routine DLASD4 (appelée
!>    par DLASD3). Cette routine calcule également les vecteurs
!>    singuliers du problème courant.
!>
!>    L'étape finale consiste à calculer les vecteurs singuliers mis à
!>    jour directement en utilisant les valeurs singulières mises à
!>    jour. Les vecteurs singuliers du problème courant sont multipliés
!>    avec les vecteurs singuliers de l'ensemble du problème.
!
>

Paramètre

s
NL 
!>          NL est INTEGER
!>         La dimension des lignes du bloc supérieur. NL >= 1.
!
>

N

R 
!>          NR est INTEGER
!>         La dimension des lignes du bloc inférieur. NR >= 1.
!
>

SQR

E 
!>          SQRE est INTEGER
!>         = 0 : le bloc inférieur est une matrice carrée NR par NR.
!>         = 1 : le bloc inférieur est une matrice rectangulaire NR par (NR+1).
!>
!>         La matrice bidiagonale a une dimension de lignes N = NL + NR + 1,
!>         et une dimension de colonnes M = N + SQRE.
!
>

D 
!>          D est un tableau DOUBLE PRECISION,
!>                        dimension (N = NL+NR+1).
!>         À l'entrée, D(1:NL,1:NL) contient les valeurs singulières du
!>         bloc supérieur ; et D(NL+2:N) contient les valeurs
!>         singulières du bloc inférieur. À la sortie, D(1:N) contient
!>         les valeurs singulières de la matrice modifiée.
!
>

ALPH

A 
!>          ALPHA est DOUBLE PRECISION
!>         Contient l'élément diagonal associé à la ligne ajoutée.
!
>

BET

A 
!>          BETA est DOUBLE PRECISION
!>         Contient l'élément hors-diagonal associé à la ligne ajoutée.
!
>

U 
!>          U est un tableau DOUBLE PRECISION, dimension(LDU,N)
!>         À l'entrée, U(1:NL, 1:NL) contient les vecteurs singuliers
!>         gauches du bloc supérieur ; U(NL+2:N, NL+2:N) contient les
!>         vecteurs singuliers gauches du bloc inférieur. À la sortie,
!>         U contient les vecteurs singuliers gauches de la matrice
!>         bidiagonale.
!
>

LD

U 
!>          LDU est INTEGER
!>         La dimension principale du tableau U. LDU >= max( 1, N ).
!
>

V

T 
!>          VT est un tableau DOUBLE PRECISION, dimension(LDVT,M)
!>         où M = N + SQRE.
!>         À l'entrée, VT(1:NL+1, 1:NL+1)**T contient les vecteurs
!>         singuliers droits du bloc supérieur ; VT(NL+2:M, NL+2:M)**T
!>         contient les vecteurs singuliers droits du bloc inférieur. À
!>         la sortie, VT**T contient les vecteurs singuliers droits de
!>         la matrice bidiagonale.
!
>

LDV

T 
!>          LDVT est INTEGER
!>         La dimension principale du tableau VT. LDVT >= max( 1, M ).
!
>

IDX

Q 
!>          IDXQ est un tableau INTEGER, dimension(N)
!>         Cela contient la permutation qui réintégrera le sous-problème
!>         juste résolu dans l'ordre trié, c'est-à-dire que
!>         D( IDXQ( I = 1, N ) ) sera en ordre croissant.
!
>

IWOR

K 
!>          IWORK est un tableau INTEGER, dimension( 4 * N )
!
>

WOR

K 
!>          WORK est un tableau DOUBLE PRECISION, dimension( 3*M**2 + 2*M )
!
>

INF

O 
!>          INFO est INTEGER
!>          = 0 :  sortie réussie.
!>          < 0 :  si INFO = -i, le i-ème argument avait une valeur illégale.
!>          > 0 :  si INFO = 1, une valeur singulière n'a pas convergé
!
>
