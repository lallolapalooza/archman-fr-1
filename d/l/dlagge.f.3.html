Documentation de la fonction/sous-programme

sous-programme dlagge (integer m, integer n, integer kl, integer ku, double precision, dimension( * ) d, double precision, dimension( lda, * ) a, integer lda, integer, dimension( 4 ) iseed, double precision, dimension( * ) work, integer info)

DLAGGE

But :

!>
!> DLAGGE génère une matrice réelle générale m par n, A, en pré- et post-
!> multipliant une matrice diagonale réelle D par des matrices orthogonales
!> aléatoires : A = U*D*V. Les bandes inférieure et supérieure peuvent ensuite
!> être réduites à kl et ku par des transformations orthogonales supplémentaires.
!>

Paramètres

M 
!>          M est un entier
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

N

!>          N est un entier
!>          Le nombre de colonnes de la matrice A.  N >= 0.
!>

KL

!>          KL est un entier
!>          Le nombre de sous-diagonales non nulles dans la bande de A.
!>          0 <= KL <= M-1.
!>

KU

!>          KU est un entier
!>          Le nombre de super-diagonales non nulles dans la bande de A.
!>          0 <= KU <= N-1.
!>

D

!>          D est un tableau de double précision, dimension (min(M,N))
!>          Les éléments diagonaux de la matrice diagonale D.
!>

A

!>          A est un tableau de double précision, dimension (LDA,N)
!>          La matrice générée m par n, A.
!>

LDA

!>          LDA est un entier
!>          La dimension principale du tableau A.  LDA >= M.
!>

ISEED

!>          ISEED est un tableau d'entiers, dimension (4)
!>          En entrée, la graine du générateur de nombres aléatoires ; les
!>          éléments d'ISEED doivent être compris entre 0 et 4095, et
!>          ISEED(4) doit être impair.
!>          En sortie, la graine est mise à jour.
!>

WORK

!>          WORK est un tableau de double précision, dimension (M+N)
!>

INFO

!>          INFO est un entier
!>          = 0 : succès de l'exécution
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>
