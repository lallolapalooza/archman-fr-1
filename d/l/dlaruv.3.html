Documentation de la fonction/sous-routine

sous-routine dlaruv (entier, dimension( 4 ) iseed, entier n, double précision, dimension( n ) x)

DLARUV renvoie un vecteur de n nombres réels aléatoires issus d'une distribution uniforme.

Objectif :

!>
!> DLARUV renvoie un vecteur de n nombres réels aléatoires issus d'une
!> distribution uniforme (0,1) (n <= 128).
!>
!> Ceci est une routine auxiliaire appelée par DLARNV et ZLARNV.
!>

Paramètres

ISEED 
!>          ISEED est un tableau d'ENTIERS, de dimension (4)
!>          En entrée, la graine du générateur de nombres aléatoires ; les éléments
!>          du tableau doivent être compris entre 0 et 4095, et ISEED(4) doit
!>          être impair.
!>          En sortie, la graine est mise à jour.
!>

N

!>          N est un ENTIER
!>          Le nombre de nombres aléatoires à générer. N <= 128.
!>

X

!>          X est un tableau de DOUBLE PRÉCISION, de dimension (N)
!>          Les nombres aléatoires générés.
!>

Auteur

Univ. du Tennessee

Univ. de Californie Berkeley

Univ. du Colorado Denver

NAG Ltd.

Détails supplémentaires :

!>
!>  Cette routine utilise une méthode congruente multiplicative avec un module
!>  de 2**48 et un multiplicateur de 33952834046453 (voir G.S.Fishman,
!>  'Multiplicative congruential random number generators with modulus
!>  2**b: an exhaustive analysis for b = 32 and a partial analysis for
!>  b = 48', Math. Comp. 189, pp 331-344, 1990).
!>
!>  Les entiers de 48 bits sont stockés dans 4 éléments de tableau d'entiers
!>  avec 12 bits par élément. La routine est donc portable sur des machines
!>  ayant des entiers de 32 bits ou plus.
!>

Définition à la ligne 94 du fichier dlaruv.f.
