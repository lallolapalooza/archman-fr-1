sous-routine dlasv2 (f, g, h, ssmin, ssmax, snr, csr, snl, csl)
DLASV2 calcule la décomposition en valeurs singulières d'une matrice triangulaire 2x2.

Documentation de la Fonction/Sous-routine

sous-routine dlasv2 (double précision f, double précision g, double précision h, double précision ssmin, double précision ssmax, double précision snr, double précision csr, double précision snl, double précision csl)

DLASV2 calcule la décomposition en valeurs singulières d'une matrice triangulaire 2x2.

Objectif :

!>
!> DLASV2 calcule la décomposition en valeurs singulières d'une matrice
!> triangulaire 2x2
!>    [  F   G  ]
!>    [  0   H  ].
!> Au retour, abs(SSMAX) est la plus grande valeur singulière, abs(SSMIN) est la
!> plus petite valeur singulière, et (CSL,SNL) et (CSR,SNR) sont les vecteurs singuliers
!> gauche et droit pour abs(SSMAX), donnant la décomposition
!>
!>    [ CSL  SNL ] [  F   G  ] [ CSR -SNR ]  =  [ SSMAX   0   ]
!>    [-SNL  CSL ] [  0   H  ] [ SNR  CSR ]     [  0    SSMIN ].
!>

Paramètres

F 
!>          F est DOUBLE PRECISION
!>          L'élément (1,1) de la matrice 2x2.
!>

G

!>          G est DOUBLE PRECISION
!>          L'élément (1,2) de la matrice 2x2.
!>

H

!>          H est DOUBLE PRECISION
!>          L'élément (2,2) de la matrice 2x2.
!>

SSMIN

!>          SSMIN est DOUBLE PRECISION
!>          abs(SSMIN) est la plus petite valeur singulière.
!>

SSMAX

!>          SSMAX est DOUBLE PRECISION
!>          abs(SSMAX) est la plus grande valeur singulière.
!>

SNL

!>          SNL est DOUBLE PRECISION
!>

CSL

!>          CSL est DOUBLE PRECISION
!>          Le vecteur (CSL, SNL) est un vecteur singulier gauche unitaire pour la
!>          valeur singulière abs(SSMAX).
!>

SNR

!>          SNR est DOUBLE PRECISION
!>

CSR

!>          CSR est DOUBLE PRECISION
!>          Le vecteur (CSR, SNR) est un vecteur singulier droit unitaire pour la
!>          valeur singulière abs(SSMAX).
!>

Détails supplémentaires :

!>
!>  N'importe quel paramètre d'entrée peut être aliasé avec n'importe quel paramètre de sortie.
!>
!>  En excluant les dépassements/sous-dépassements et en supposant une garde de chiffre dans la soustraction, toutes
!>  les quantités de sortie sont correctes à quelques unités près dans la dernière
!>  position (ulps).
!>
!>  En arithmétique IEEE, le code fonctionne correctement si un élément de la matrice est
!>  infini.
!>
!>  Le dépassement ne se produira pas à moins que la plus grande valeur singulière elle-même
!>  ne dépasse ou soit à quelques ulps du dépassement.
!>
!>  Le sous-dépassement est inoffensif si le sous-dépassement est graduel. Sinon, les résultats
!>  peuvent correspondre à une matrice modifiée par des perturbations de taille proche
!>  du seuil de sous-dépassement.
!>

Définition à la ligne 135 du fichier dlasv2.f.
