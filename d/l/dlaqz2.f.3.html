Documentation de la fonction/sous-routine

sous-routine  dlaqz2 (logique, intent(in) ilq, logique, intent(in) ilz, entier, intent(in) k, entier, intent(in) istartm, entier, intent(in) istopm, entier, intent(in) ihi, double precision, dimension( lda, * ) a, entier, intent(in) lda, double precision, dimension( ldb, * ) b, entier, intent(in) ldb, entier, intent(in) nq, entier, intent(in) qstart, double precision, dimension( ldq, * ) q, entier, intent(in) ldq, entier, intent(in) nz, entier, intent(in) zstart, double precision, dimension( ldz, * ) z, entier, intent(in) ldz)

DLAQZ2

Objectif :

!>
!>      DLAQZ2 fait chasser un renflement de décalage 2x2 dans un crayon de matrices
!>      vers le bas d'une position
!>

Paramètres

ILQ 
!>          ILQ est LOGIQUE
!>              Détermine si la matrice Q doit être mise à jour ou non
!>

ILZ

!>          ILZ est LOGIQUE
!>              Détermine si la matrice Z doit être mise à jour ou non
!>

K

!>          K est ENTIER
!>              Indice indiquant la position du renflement.
!>              À l'entrée, le renflement est situé dans
!>              (A(k+1:k+2,k:k+1),B(k+1:k+2,k:k+1)).
!>              À la sortie, le renflement est situé dans
!>              (A(k+2:k+3,k+1:k+2),B(k+2:k+3,k+1:k+2)).
!>

ISTARTM

!>          ISTARTM est ENTIER
!>

ISTOPM

!>          ISTOPM est ENTIER
!>              Les mises à jour de (A,B) sont restreintes à
!>              (istartm:k+3,k:istopm). Il est supposé
!>              sans vérification que istartm <= k+1 et
!>              k+2 <= istopm
!>

IHI

!>          IHI est ENTIER
!>

A

!>          A est un tableau DOUBLE PRECISION, dimension (LDA,N)
!>

LDA

!>          LDA est ENTIER
!>              La dimension principale de A telle que déclarée dans
!>              la procédure appelante.
!>

B

!>          B est un tableau DOUBLE PRECISION, dimension (LDB,N)
!>

LDB

!>          LDB est ENTIER
!>              La dimension principale de B telle que déclarée dans
!>              la procédure appelante.
!>

NQ

!>          NQ est ENTIER
!>              L'ordre de la matrice Q
!>

QSTART

!>          QSTART est ENTIER
!>              Indice de début de la matrice Q. Les rotations sont appliquées
!>              aux colonnes k+2-qstart:k+4-qstart de Q.
!>

Q

!>          Q est un tableau DOUBLE PRECISION, dimension (LDQ,NQ)
!>

LDQ

!>          LDQ est ENTIER
!>              La dimension principale de Q telle que déclarée dans
!>              la procédure appelante.
!>

NZ

!>          NZ est ENTIER
!>              L'ordre de la matrice Z
!>

ZSTART

!>          ZSTART est ENTIER
!>              Indice de début de la matrice Z. Les rotations sont appliquées
!>              aux colonnes k+1-qstart:k+3-qstart de Z.
!>

Z

!>          Z est un tableau DOUBLE PRECISION, dimension (LDZ,NZ)
!>

LDZ

!>          LDZ est ENTIER
!>              La dimension principale de Q telle que déclarée dans
!>              la procédure appelante.
!>
