Documentation de la fonction/sous-routine

double precision function dla_syrpvgrw (character*1 uplo, integer n, integer info, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( ldaf, * ) af, integer ldaf, integer, dimension( * ) ipiv, double precision, dimension( * ) work)

DLA_SYRPVGRW calcule le facteur de croissance réciproque des pivots norm(A)/norm(U) pour une matrice indéfinie symétrique.

Objectif

!>
!>
!> DLA_SYRPVGRW calcule le facteur de croissance réciproque des pivots
!> norm(A)/norm(U). La norme est utilisée. Si cela
!> est beaucoup moins que 1, la stabilité de la factorisation LU de la
!> matrice (équilibrée) A pourrait être mauvaise. Cela signifie également que
!> la solution X, les estimations des nombres de condition et les bornes d'erreur pourraient
!> être peu fiables.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>       = 'U':  Le triangle supérieur de A est stocké ;
!>       = 'L':  Le triangle inférieur de A est stocké.
!>

N

!>          N est INTEGER
!>     Le nombre d'équations linéaires, c'est-à-dire l'ordre de la
!>     matrice A.  N >= 0.
!>

INFO

!>          INFO est INTEGER
!>     La valeur de INFO retournée par DSYTRF, c'est-à-dire que le pivot dans
!>     la colonne INFO est exactement 0.
!>

A

!>          A est un tableau DOUBLE PRECISION, de dimension (LDA,N)
!>     En entrée, la matrice A de taille N x N.
!>

LDA

!>          LDA est INTEGER
!>     La dimension principale du tableau A.  LDA >= max(1,N).
!>

AF

!>          AF est un tableau DOUBLE PRECISION, de dimension (LDAF,N)
!>     La matrice diagonale par blocs D et les multiplicateurs utilisés pour
!>     obtenir le facteur U ou L calculés par DSYTRF.
!>

LDAF

!>          LDAF est INTEGER
!>     La dimension principale du tableau AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV est un tableau INTEGER, de dimension (N)
!>     Détails des échanges et de la structure de blocs de D
!>     tels que déterminés par DSYTRF.
!>

WORK

!>          WORK est un tableau DOUBLE PRECISION, de dimension (2*N)
!>
