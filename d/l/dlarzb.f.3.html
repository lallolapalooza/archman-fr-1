sous-routine dlarzb (side, trans, direct, storev, m, n, k, l, v, ldv, t, ldt, c, ldc, work, ldwork)
DLARZB applique un réflecteur de bloc ou sa transposée à une matrice générale.

Documentation de la fonction/sous-routine

sous-routine dlarzb (caractère side, caractère trans, caractère direct, caractère storev, entier m, entier n, entier k, entier l, double précision, dimension( ldv, * ) v, entier ldv, double précision, dimension( ldt, * ) t, entier ldt, double précision, dimension( ldc, * ) c, entier ldc, double précision, dimension( ldwork, * ) work, entier ldwork)

DLARZB applique un réflecteur de bloc réel H ou sa transposée H**T à une matrice générale réelle distribuée C de dimensions M-par-N, à partir de la gauche ou de la droite.

Objectif :

!>
!> DLARZB applique un réflecteur de bloc réel H ou sa transposée H**T
!> à une matrice générale réelle distribuée C de dimensions M-par-N
!> à partir de la gauche ou de la droite.
!>
!> Actuellement, seuls STOREV = 'R' et DIRECT = 'B' sont pris en charge.
!>

Paramètres

SIDE 
!>          SIDE est un CARACTÈRE*1
!>          = 'L' : appliquer H ou H**T à gauche
!>          = 'R' : appliquer H ou H**T à droite
!>

TRANS

!>          TRANS est un CARACTÈRE*1
!>          = 'N' : appliquer H (Pas de transposée)
!>          = 'C' : appliquer H**T (Transposée)
!>

DIRECT

!>          DIRECT est un CARACTÈRE*1
!>          Indique comment H est formé à partir d'un produit de réflecteurs
!>          élémentaires
!>          = 'F' : H = H(1) H(2) . . . H(k) (Avant, pas encore pris en charge)
!>          = 'B' : H = H(k) . . . H(2) H(1) (Arrière)
!>

STOREV

!>          STOREV est un CARACTÈRE*1
!>          Indique comment les vecteurs qui définissent les réflecteurs
!>          élémentaires sont stockés :
!>          = 'C' : par colonne (pas encore pris en charge)
!>          = 'R' : par ligne
!>

M

!>          M est un ENTIER
!>          Le nombre de lignes de la matrice C.
!>

N

!>          N est un ENTIER
!>          Le nombre de colonnes de la matrice C.
!>

K

!>          K est un ENTIER
!>          L'ordre de la matrice T (= le nombre de réflecteurs
!>          élémentaires dont le produit définit le réflecteur de bloc).
!>

L

!>          L est un ENTIER
!>          Le nombre de colonnes de la matrice V contenant la partie
!>          significative des réflecteurs de Householder.
!>          Si SIDE = 'L', M >= L >= 0, si SIDE = 'R', N >= L >= 0.
!>

V

!>          V est un tableau de DOUBLE PRÉCISION, de dimension (LDV,NV).
!>          Si STOREV = 'C', NV = K ; si STOREV = 'R', NV = L.
!>

LDV

!>          LDV est un ENTIER
!>          La dimension principale du tableau V.
!>          Si STOREV = 'C', LDV >= L ; si STOREV = 'R', LDV >= K.
!>

T

!>          T est un tableau de DOUBLE PRÉCISION, de dimension (LDT,K)
!>          La matrice triangulaire K-par-K T dans la représentation du
!>          réflecteur de bloc.
!>

LDT

!>          LDT est un ENTIER
!>          La dimension principale du tableau T. LDT >= K.
!>

C

!>          C est un tableau de DOUBLE PRÉCISION, de dimension (LDC,N)
!>          À l'entrée, la matrice C de dimensions M-par-N.
!>          À la sortie, C est écrasée par H*C ou H**T*C ou C*H ou C*H**T.
!>

LDC

!>          LDC est un ENTIER
!>          La dimension principale du tableau C. LDC >= max(1,M).
!>

WORK

!>          WORK est un tableau de DOUBLE PRÉCISION, de dimension (LDWORK,K)
!>

LDWORK

!>          LDWORK est un ENTIER
!>          La dimension principale du tableau WORK.
!>          Si SIDE = 'L', LDWORK >= max(1,N) ;
!>          si SIDE = 'R', LDWORK >= max(1,M).
!>
