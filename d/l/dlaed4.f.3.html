sous-programme dlaed4 (integer n, integer i, double precision, dimension( * ) d, double precision, dimension( * ) z, double precision, dimension( * ) delta, double precision rho, double precision dlam, integer info)

DLAED4 utilisé par DSTEDC. Trouve une seule racine de l'équation séculaire.

Objectif :

!>
!> Ce sous-programme calcule la I-ème valeur propre mise à jour d'une modification
!> de rang un d'une matrice diagonale dont les éléments sont donnés dans le tableau d,
!> et telle que
!>
!>            D(i) < D(j)  pour  i < j
!>
!> et que RHO > 0. Ceci est organisé par la routine appelante, et il n'y a pas de
!> perte de généralité. Le système modifié de rang un est donc
!>
!>            diag( D )  +  RHO * Z * Z_transpose.
!>
!> où nous supposons que la norme euclidienne de Z est 1.
!>
!> La méthode consiste à approximer les fonctions rationnelles de l'équation
!> séculaire par des fonctions rationnelles interpolantes plus simples.
!>

Paramètres

N 
!>          N est un entier (INTEGER)
!>         La longueur de tous les tableaux.
!>

I

!>          I est un entier (INTEGER)
!>         L'indice de la valeur propre à calculer.  1 <= I <= N.
!>

D

!>          D est un tableau de double précision (DOUBLE PRECISION) de dimension (N)
!>         Les valeurs propres originales. On suppose qu'elles sont ordonnées,
!>         D(I) < D(J)  pour I < J.
!>

Z

!>          Z est un tableau de double précision (DOUBLE PRECISION) de dimension (N)
!>         Les composantes du vecteur de mise à jour.
!>

DELTA

!>          DELTA est un tableau de double précision (DOUBLE PRECISION) de dimension (N)
!>         Si N > 2, DELTA contient (D(j) - lambda_I) dans sa j-ème
!>         composante.  Si N = 1, alors DELTA(1) = 1. Si N = 2, voir DLAED5
!>         pour les détails. Le vecteur DELTA contient les informations nécessaires
!>         pour construire les vecteurs propres par DLAED3 et DLAED9.
!>

RHO

!>          RHO est un double précision (DOUBLE PRECISION)
!>         Le scalaire dans la formule de mise à jour symétrique.
!>

DLAM

!>          DLAM est un double précision (DOUBLE PRECISION)
!>         Le lambda_I calculé, la I-ème valeur propre mise à jour.
!>

INFO

!>          INFO est un entier (INTEGER)
!>         = 0 : sortie réussie
!>         > 0 : si INFO = 1, le processus de mise à jour a échoué.
!>

Paramètres internes :

!>  La variable logique ORGATI (origine à i ?) est utilisée pour distinguer
!>  si D(i) ou D(i+1) est traité comme l'origine.
!>
!>            ORGATI = .true.    origine à i
!>            ORGATI = .false.   origine à i+1
!>
!>   La variable logique SWTCH3 (commutation pour 3 pôles ?) sert à noter
!>   si nous travaillons avec TROIS pôles !
!>
!>   MAXIT est le nombre maximum d'itérations autorisées pour chaque
!>   valeur propre.
!>
