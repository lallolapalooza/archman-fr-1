Documentation de la fonction/sous-routine

sous-routine dlag2 (double precision, dimension( lda, * ) a, integer lda, double precision, dimension( ldb, * ) b, integer ldb, double precision safmin, double precision scale1, double precision scale2, double precision wr1, double precision wr2, double precision wi)

DLAG2 calcule les valeurs propres d'un problème de valeurs propres généralisé 2x2, avec mise à l'échelle si nécessaire pour éviter les dépassements/sous-dépassements de capacité.

Objectif :

!>
!> DLAG2 calcule les valeurs propres d'un problème de valeurs propres généralisé 2 x 2
!> A - w B, avec mise à l'échelle si nécessaire pour éviter les dépassements/sous-dépassements de capacité.
!>
!> Le facteur de mise à l'échelle  résulte en une équation de valeur propre modifiée
!>
!>     s A - w B
!>
!> où  s  est un facteur de mise à l'échelle non négatif choisi de telle sorte que  w,  w B,
!> et  s A  ne débordent pas et, si possible, ne sous-débordent pas non plus.
!>

Paramètres

A 
!>          A est un tableau DOUBLE PRECISION, dimension (LDA, 2)
!>          En entrée, la matrice A 2x2. On suppose que sa norme 1 est
!>          inférieure à 1/SAFMIN. Les entrées inférieures à
!>          sqrt(SAFMIN)*norm(A) sont susceptibles d'être traitées comme zéro.
!>

LDA

!>          LDA est un INTEGER
!>          La dimension principale du tableau A. LDA >= 2.
!>

B

!>          B est un tableau DOUBLE PRECISION, dimension (LDB, 2)
!>          En entrée, la matrice triangulaire supérieure B 2x2. On
!>          suppose que la norme 1 de B est inférieure à 1/SAFMIN. Les
!>          diagonales doivent être au moins sqrt(SAFMIN) fois le plus grand
!>          élément de B (en valeur absolue) ; si une diagonale est plus petite
!>          que cela, alors +/- sqrt(SAFMIN) sera utilisé à la place de
!>          cette diagonale.
!>

LDB

!>          LDB est un INTEGER
!>          La dimension principale du tableau B. LDB >= 2.
!>

SAFMIN

!>          SAFMIN est DOUBLE PRECISION
!>          Le plus petit nombre positif tel que 1/SAFMIN ne déborde pas.
!>          (Cela devrait toujours être DLAMCH('S') -- c'est un
!>          argument pour éviter d'appeler DLAMCH fréquemment.)
!>

SCALE1

!>          SCALE1 est DOUBLE PRECISION
!>          Un facteur de mise à l'échelle utilisé pour éviter les dépassements/sous-dépassements de capacité dans
!>          l'équation de valeur propre qui définit la première valeur propre. Si
!>          les valeurs propres sont complexes, alors les valeurs propres sont
!>          ( WR1  +/-  WI i ) / SCALE1  (qui peuvent se trouver en dehors de
!>          la plage d'exposants de la machine), SCALE1=SCALE2, et SCALE1
!>          sera toujours positif. Si les valeurs propres sont réelles, alors
!>          la première valeur propre (réelle) est  WR1 / SCALE1 , mais cela peut
!>          déborder ou sous-déborder, et en fait, SCALE1 peut être zéro ou
!>          inférieur au seuil de sous-dépassement si la valeur propre exacte
!>          est suffisamment grande.
!>

SCALE2

!>          SCALE2 est DOUBLE PRECISION
!>          Un facteur de mise à l'échelle utilisé pour éviter les dépassements/sous-dépassements de capacité dans
!>          l'équation de valeur propre qui définit la deuxième valeur propre. Si
!>          les valeurs propres sont complexes, alors SCALE2=SCALE1. Si les
!>          valeurs propres sont réelles, alors la deuxième valeur propre (réelle) est
!>          WR2 / SCALE2 , mais cela peut déborder ou sous-déborder, et en fait,
!>          SCALE2 peut être zéro ou inférieur au seuil de sous-dépassement si la
!>          valeur propre exacte est suffisamment grande.
!>

WR1

!>          WR1 est DOUBLE PRECISION
!>          Si la valeur propre est réelle, alors WR1 est SCALE1 multiplié par la
!>          valeur propre la plus proche de l'élément (2,2) de A B**(-1). Si la
!>          valeur propre est complexe, alors WR1=WR2 est SCALE1 multiplié par la partie réelle
!>          des valeurs propres.
!>

WR2

!>          WR2 est DOUBLE PRECISION
!>          Si la valeur propre est réelle, alors WR2 est SCALE2 multiplié par l'autre
!>          valeur propre. Si la valeur propre est complexe, alors
!>          WR1=WR2 est SCALE1 multiplié par la partie réelle des valeurs propres.
!>

WI

!>          WI est DOUBLE PRECISION
!>          Si la valeur propre est réelle, alors WI est zéro. Si la
!>          valeur propre est complexe, alors WI est SCALE1 multiplié par la partie imaginaire
!>          des valeurs propres. WI sera toujours non négatif.
!>
