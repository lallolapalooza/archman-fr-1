sous-programme dlarrk (n, iw, gl, gu, d, e2, pivmin, reltol, w, werr, info)
DLARRK calcule une valeur propre d'une matrice tridiagonale symétrique T avec une précision appropriée.

Documentation de la fonction/sous-programme

sous-programme dlarrk (integer n, integer iw, double precision gl, double precision gu, double precision, dimension( * ) d, double precision, dimension( * ) e2, double precision pivmin, double precision reltol, double precision w, double precision werr, integer info)

DLARRK calcule une valeur propre d'une matrice tridiagonale symétrique T avec une précision appropriée.

Objectif :

!>
!> DLARRK calcule une valeur propre d'une matrice tridiagonale
!> symétrique T avec une précision appropriée. Il s'agit d'un code auxiliaire à appeler depuis DSTEMR.
!>
!> Pour éviter le débordement, la matrice doit être mise à l'échelle de sorte que sa
!> plus grande valeur élémentaire ne dépasse pas overflow**(1/2) * underflow**(1/4) en valeur absolue, et pour une précision maximale, elle ne doit pas être beaucoup plus petite que cela.
!>
!> Voir W. Kahan , Report CS41, Computer Science Dept., Stanford
!> University, July 21, 1966.
!>

Paramètres

N 
!>          N est INTEGER
!>          L'ordre de la matrice tridiagonale T.  N >= 0.
!>

IW

!>          IW est INTEGER
!>          L'indice de la valeur propre à retourner.
!>

GL

!>          GL est DOUBLE PRECISION
!>

GU

!>          GU est DOUBLE PRECISION
!>          Une borne inférieure et une borne supérieure sur la valeur propre.
!>

D

!>          D est un tableau DOUBLE PRECISION, de dimension (N)
!>          Les n éléments diagonaux de la matrice tridiagonale T.
!>

E2

!>          E2 est un tableau DOUBLE PRECISION, de dimension (N-1)
!>          Les (n-1) éléments hors diagonale au carré de la matrice tridiagonale T.
!>

PIVMIN

!>          PIVMIN est DOUBLE PRECISION
!>          Le pivot minimum autorisé dans la séquence de Sturm pour T.
!>

RELTOL

!>          RELTOL est DOUBLE PRECISION
!>          La largeur relative minimale d'un intervalle. Lorsqu'un intervalle
!>          est plus étroit que RELTOL multiplié par le plus grand (en
!>          valeur absolue) des points terminaux, alors il est considéré comme
!>          suffisamment petit, c'est-à-dire convergé. Note : cela devrait
!>          toujours être au moins epsilon machine*radix.
!>

W

!>          W est DOUBLE PRECISION
!>

WERR

!>          WERR est DOUBLE PRECISION
!>          La borne d'erreur sur l'approximation de la valeur propre correspondante
!>          dans W.
!>

INFO

!>          INFO est INTEGER
!>          = 0 :       Valeur propre convergée
!>          = -1 :      Valeur propre NON convergée
!>

Paramètres internes :

!>  FUDGE   DOUBLE PRECISION, par défaut = 2
!>          A  pour élargir les intervalles de Gershgorin.
!>
