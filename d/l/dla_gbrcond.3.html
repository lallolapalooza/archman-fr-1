double precision function dla_gbrcond (character trans, integer n, integer kl, integer ku, double precision, dimension( ldab, * ) ab, integer ldab, double precision, dimension( ldafb, * ) afb, integer ldafb, integer, dimension( * ) ipiv, integer cmode, double precision, dimension( * ) c, integer info, double precision, dimension( * ) work, integer, dimension( * ) iwork)

DLA_GBRCOND estime le nombre de conditionnement de Skeel pour une matrice bande générale.

Objectif :

!>
!>    DLA_GBRCOND Estime le nombre de conditionnement de Skeel de  op(A) * op2(C)
!>    où op2 est déterminé par CMODE comme suit
!>    CMODE =  1    op2(C) = C
!>    CMODE =  0    op2(C) = I
!>    CMODE = -1    op2(C) = inv(C)
!>    Le nombre de conditionnement de Skeel  cond(A) = norminf( |inv(A)||A| )
!>    est calculé en calculant des facteurs de mise à l'échelle R tels que
!>    diag(R)*A*op2(C) est équilibré en ligne et en calculant le nombre de
!>    conditionnement standard en norme infinie.
!>

Paramètres

TRANS 
!>          TRANS est CHARACTER*1
!>     Spécifie la forme du système d'équations :
!>       = 'N':  A * X = B     (Pas de transposée)
!>       = 'T':  A**T * X = B  (Transposée)
!>       = 'C':  A**H * X = B  (Transposée conjuguée = Transposée)
!>

N

!>          N est INTEGER
!>     Le nombre d'équations linéaires, c'est-à-dire l'ordre de
!>     la matrice A.  N >= 0.
!>

KL

!>          KL est INTEGER
!>     Le nombre de sous-diagonales dans la bande de A.  KL >= 0.
!>

KU

!>          KU est INTEGER
!>     Le nombre de super-diagonales dans la bande de A.  KU >= 0.
!>

AB

!>          AB est un tableau DOUBLE PRECISION, de dimension (LDAB,N)
!>     En entrée, la matrice A en stockage bande, dans les lignes 1 à KL+KU+1.
!>     La j-ième colonne de A est stockée dans la j-ième colonne du
!>     tableau AB comme suit :
!>     AB(KU+1+i-j,j) = A(i,j) pour max(1,j-KU)<=i<=min(N,j+kl)
!>

LDAB

!>          LDAB est INTEGER
!>     La dimension principale du tableau AB.  LDAB >= KL+KU+1.
!>

AFB

!>          AFB est un tableau DOUBLE PRECISION, de dimension (LDAFB,N)
!>     Détails de la factorisation LU de la matrice bande A, tels que
!>     calculés par DGBTRF.  U est stockée comme une matrice triangulaire
!>     supérieure bande avec KL+KU super-diagonales dans les lignes 1 à KL+KU+1,
!>     et les multiplicateurs utilisés lors de la factorisation sont stockés
!>     dans les lignes KL+KU+2 à 2*KL+KU+1.
!>

LDAFB

!>          LDAFB est INTEGER
!>     La dimension principale du tableau AFB.  LDAFB >= 2*KL+KU+1.
!>

IPIV

!>          IPIV est un tableau INTEGER, de dimension (N)
!>     Les indices de pivot de la factorisation A = P*L*U
!>     tels que calculés par DGBTRF ; la ligne i de la matrice a été échangée
!>     avec la ligne IPIV(i).
!>

CMODE

!>          CMODE est INTEGER
!>     Détermine op2(C) dans la formule op(A) * op2(C) comme suit :
!>     CMODE =  1    op2(C) = C
!>     CMODE =  0    op2(C) = I
!>     CMODE = -1    op2(C) = inv(C)
!>

C

!>          C est un tableau DOUBLE PRECISION, de dimension (N)
!>     Le vecteur C dans la formule op(A) * op2(C).
!>

INFO

!>          INFO est INTEGER
!>       = 0:  Sortie réussie.
!>     i > 0:  Le i-ème argument est invalide.
!>

WORK

!>          WORK est un tableau DOUBLE PRECISION, de dimension (5*N).
!>     Espace de travail.
!>

IWORK

!>          IWORK est un tableau INTEGER, de dimension (N).
!>     Espace de travail.
!>
