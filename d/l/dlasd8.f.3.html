sous-routine dlasd8 (entier icompq, entier k, double précision, dimension( * ) d, double précision, dimension( * ) z, double précision, dimension( * ) vf, double précision, dimension( * ) vl, double précision, dimension( * ) difl, double précision, dimension( lddifr, * ) difr, entier lddifr, double précision, dimension( * ) dsigma, double précision, dimension( * ) work, entier info)

DLASD8 trouve les racines carrées des racines de l'équation séculaire, et stocke, pour chaque élément de D, la distance à ses deux pôles les plus proches. Utilisé par sbdsdc.

Objectif :

!>
!> DLASD8 trouve les racines carrées des racines de l'équation séculaire,
!> comme défini par les valeurs dans DSIGMA et Z. Elle fait les appels appropriés
!> à DLASD4, et stocke, pour chaque élément de D, la distance
!> à ses deux pôles les plus proches (éléments de DSIGMA). Elle met également à jour
!> les tableaux VF et VL, les première et dernière composantes de tous les
!> vecteurs singuliers droits de la matrice bidiagonale d'origine.
!>
!> DLASD8 est appelée depuis DLASD6.
!>

Paramètres

ICOMPQ 
!>          ICOMPQ est un ENTIER
!>          Spécifie si les vecteurs singuliers doivent être calculés sous
!>          forme factorisée dans la routine appelante :
!>          = 0 : Calculer uniquement les valeurs singulières.
!>          = 1 : Calculer également les vecteurs singuliers sous forme factorisée.
!>

K

!>          K est un ENTIER
!>          Le nombre de termes dans la fonction rationnelle à résoudre
!>          par DLASD4. K >= 1.
!>

D

!>          D est un tableau de DOUBLE PRÉCISION, dimension ( K )
!>          En sortie, D contient les valeurs singulières mises à jour.
!>

Z

!>          Z est un tableau de DOUBLE PRÉCISION, dimension ( K )
!>          En entrée, les K premiers éléments de ce tableau contiennent les
!>          composantes du vecteur ligne de mise à jour ajusté par déflation.
!>          En sortie, Z est mis à jour.
!>

VF

!>          VF est un tableau de DOUBLE PRÉCISION, dimension ( K )
!>          En entrée, VF contient des informations transmises via DBEDE8.
!>          En sortie, VF contient les K premières composantes des K premières
!>          composantes de tous les vecteurs singuliers droits de la matrice bidiagonale.
!>

VL

!>          VL est un tableau de DOUBLE PRÉCISION, dimension ( K )
!>          En entrée, VL contient des informations transmises via DBEDE8.
!>          En sortie, VL contient les K premières composantes des K dernières
!>          composantes de tous les vecteurs singuliers droits de la matrice bidiagonale.
!>

DIFL

!>          DIFL est un tableau de DOUBLE PRÉCISION, dimension ( K )
!>          En sortie, DIFL(I) = D(I) - DSIGMA(I).
!>

DIFR

!>          DIFR est un tableau de DOUBLE PRÉCISION,
!>                   dimension ( LDDIFR, 2 ) si ICOMPQ = 1 et
!>                   dimension ( K ) si ICOMPQ = 0.
!>          En sortie, DIFR(I,1) = D(I) - DSIGMA(I+1), DIFR(K,1) n'est pas
!>          défini et ne sera pas référencé.
!>
!>          Si ICOMPQ = 1, DIFR(1:K,2) est un tableau contenant les
!>          facteurs de normalisation pour la matrice des vecteurs singuliers droits.
!>

LDDIFR

!>          LDDIFR est un ENTIER
!>          La dimension principale de DIFR, doit être au moins K.
!>

DSIGMA

!>          DSIGMA est un tableau de DOUBLE PRÉCISION, dimension ( K )
!>          En entrée, les K premiers éléments de ce tableau contiennent les anciennes
!>          racines du problème de mise à jour déflaté. Ce sont les pôles
!>          de l'équation séculaire.
!>

WORK

!>          WORK est un tableau de DOUBLE PRÉCISION, dimension (3*K)
!>

INFO

!>          INFO est un ENTIER
!>          = 0 : sortie réussie.
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.
!>          > 0 : si INFO = 1, une valeur singulière n'a pas convergé
!>
