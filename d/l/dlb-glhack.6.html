DLB(6) Manuel des jeux DLB(6)

NOM

dlb - Bibliothèque de données NetHack

SYNTAXE

dlb { xct } [ vfIC ] arguments... [ fichiers... ]

DESCRIPTION

Dlb est un outil d'archivage de fichiers dans l'esprit (et la tradition) de tar pour NetHack version 3.1 et supérieure. Il est utilisé pour maintenir les fichiers d'archives à partir desquels NetHack lit les niveaux spéciaux et d'autres informations en lecture seule. Notez que, comme tar, la commande et les spécificateurs d'options sont spécifiés sous forme d'une chaîne continue et sont suivis des arguments requis dans le même ordre que les spécificateurs d'options.

Cette fonctionnalité est facultative et peut être exclue lors de la configuration de NetHack.

COMMANDES

La commande x demande à dlb d'extraire le contenu de l'archive dans le répertoire courant.

La commande c demande à dlb de créer une nouvelle archive à partir des fichiers du répertoire courant.

La commande t liste les fichiers dans l'archive.

OPTIONS ET ARGUMENTS

v sortie détaillée

f archive spécifie l'archive. Par défaut si f n'est pas spécifié, c'est LIBFILE (habituellement le fichier nhdat dans l'aire de jeu).

I lfile spécifie le fichier contenant la liste des fichiers à inclure ou à extraire de l'archive si aucun fichier n'est listé sur la ligne de commande. Par défaut pour la création d'archive si aucun fichier n'est listé, c'est LIBLISTFILE.

C dir changer de répertoire. Change de répertoire avant d'essayer de lire n'importe quel fichier (y compris l'archive et lfile).

EXEMPLES

Créer l'archive par défaut à partir de la liste de fichiers par défaut :
dlb c

Lister le contenu de l'archive 'foo' :
dlb tf foo

AUTEUR

Kenneth Lorber

VOIR AUSSI

nethack(6), tar(1)

BOGUES

N'est pas une bonne émulation de tar ; - ne signifie pas stdin ou stdout. Devrait inclure une installation de compression facultative. Tous les fichiers en lecture seule pour NetHack ne peuvent pas être lus à partir d'une archive ; examiner le code source est la seule façon de savoir quels fichiers peuvent l'être.
