Documentation de la fonction/sous-routine

sous-routine dlanv2 (double precision a, double precision b, double precision c, double precision d, double precision rt1r, double precision rt1i, double precision rt2r, double precision rt2i, double precision cs, double precision sn)

DLANV2 calcule la factorisation de Schur d'une matrice réelle 2x2 non symétrique en forme standard.

Objectif :

!>
!> DLANV2 calcule la factorisation de Schur d'une matrice réelle 2x2 non symétrique
!> en forme standard :
!>
!>      [ A  B ] = [ CS -SN ] [ AA  BB ] [ CS  SN ]
!>      [ C  D ]   [ SN  CS ] [ CC  DD ] [-SN  CS ]
!>
!> où soit
!> 1) CC = 0 donc AA et DD sont les valeurs propres réelles de la matrice, soit
!> 2) AA = DD et BB*CC < 0, donc AA + ou - sqrt(BB*CC) sont les valeurs propres complexes
!> conjuguées.
!>

Paramètres

A 
!>          A est DOUBLE PRECISION
!>

B

!>          B est DOUBLE PRECISION
!>

C

!>          C est DOUBLE PRECISION
!>

D

!>          D est DOUBLE PRECISION
!>          En entrée, les éléments de la matrice d'entrée.
!>          En sortie, ils sont écrasés par les éléments de la forme
!>          de Schur standardisée.
!>

RT1R

!>          RT1R est DOUBLE PRECISION
!>

RT1I

!>          RT1I est DOUBLE PRECISION
!>

RT2R

!>          RT2R est DOUBLE PRECISION
!>

RT2I

!>          RT2I est DOUBLE PRECISION
!>          Les parties réelles et imaginaires des valeurs propres. Si les
!>          valeurs propres sont une paire complexe conjuguée, RT1I > 0.
!>

CS

!>          CS est DOUBLE PRECISION
!>

SN

!>          SN est DOUBLE PRECISION
!>          Paramètres de la matrice de rotation.
!>

!>  abs(RT1R) >= abs(RT2R).
!>
