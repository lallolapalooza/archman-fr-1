Documentation de la fonction/sous-routine

sous-routine dlasd0 (entier n, entier sqre, double précision, dimension( * ) d, double précision, dimension( * ) e, double précision, dimension( ldu, * ) u, entier ldu, double précision, dimension( ldvt, * ) vt, entier ldvt, entier smlsiz, entier, dimension( * ) iwork, double précision, dimension( * ) work, entier info)

DLASD0 calcule les valeurs singulières d'une matrice réelle supérieure bidiagonale n-par-m B de diagonale D et hors-diagonale E. Utilisé par sbdsdc.

Objectif :

!>
!> En utilisant une approche diviser pour régner, DLASD0 calcule la
!> décomposition en valeurs singulières (SVD) d'une matrice B réelle supérieure bidiagonale N-par-M
!> avec diagonale D et hors-diagonale E, où M = N + SQRE.
!> L'algorithme calcule des matrices orthogonales U et VT telles que
!> B = U * S * VT. Les valeurs singulières S sont écrasées sur D.
!>
!> Une sous-routine associée, DLASDA, calcule uniquement les valeurs singulières,
!> et éventuellement, les vecteurs singuliers sous forme compacte.
!>

Paramètres

N 
!>          N est ENTIER
!>         À l'entrée, la dimension de ligne de la matrice bidiagonale supérieure.
!>         C'est aussi la dimension du tableau de diagonale principale D.
!>

SQRE

!>          SQRE est ENTIER
!>         Spécifie la dimension de colonne de la matrice bidiagonale.
!>         = 0 : La matrice bidiagonale a la dimension de colonne M = N ;
!>         = 1 : La matrice bidiagonale a la dimension de colonne M = N+1 ;
!>

D

!>          D est un tableau DOUBLE PRÉCISION, dimension (N)
!>         À l'entrée, D contient la diagonale principale de la matrice
!>         bidiagonale.
!>         À la sortie, si INFO = 0, D contient ses valeurs singulières.
!>

E

!>          E est un tableau DOUBLE PRÉCISION, dimension (M-1)
!>         Contient les entrées sous-diagonales de la matrice bidiagonale.
!>         À la sortie, E a été détruit.
!>

U

!>          U est un tableau DOUBLE PRÉCISION, dimension (LDU, N)
!>         À la sortie, U contient les vecteurs singuliers gauches,
!>          si U est passé comme identité (N, N).
!>

LDU

!>          LDU est ENTIER
!>         À l'entrée, dimension de conduite de U.
!>

VT

!>          VT est un tableau DOUBLE PRÉCISION, dimension (LDVT, M)
!>         À la sortie, VT**T contient les vecteurs singuliers droits,
!>          si VT est passé comme identité (M, M).
!>

LDVT

!>          LDVT est ENTIER
!>         À l'entrée, dimension de conduite de VT.
!>

SMLSIZ

!>          SMLSIZ est ENTIER
!>         À l'entrée, taille maximale des sous-problèmes au
!>         bas de l'arbre de calcul.
!>

IWORK

!>          IWORK est un tableau ENTIER, dimension (8*N)
!>

WORK

!>          WORK est un tableau DOUBLE PRÉCISION, dimension (3*M**2+2*M)
!>

INFO

!>          INFO est ENTIER
!>          = 0 : sortie réussie.
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.
!>          > 0 : si INFO = 1, une valeur singulière n'a pas convergé
!>
