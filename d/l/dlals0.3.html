DLALS0 applique les facteurs de multiplication inverses pour résoudre le problème des moindres carrés en utilisant l'approche SVD par diviser pour régner. Utilisé par sgelsd.

Objectif :

!>
!> DLALS0 applique les facteurs de multiplication inverses de la matrice
!> singulière gauche ou droite d'une matrice diagonale complétée par une ligne
!> à la matrice second membre B lors de la résolution du problème des moindres
!> carrés à l'aide de l'approche SVD par diviser pour régner.
!>
!> Pour la matrice singulière gauche, trois types de matrices orthogonales sont
!> impliquées :
!>
!> (1L) Rotations de Givens : le nombre de ces rotations est GIVPTR ; les
!>      paires de colonnes/lignes sur lesquelles elles ont été appliquées sont
!>      stockées dans GIVCOL ; et les valeurs C et S de ces rotations sont
!>      stockées dans GIVNUM.
!>
!> (2L) Permutation. La (NL+1)-ième ligne de B est à déplacer vers la première
!>      ligne, et pour J=2:N, la J-ième ligne de B est déplacée vers la
!>      J-ième ligne, où J est l'indice de PERM.
!>
!> (3L) La matrice singulière gauche de la matrice restante.
!>
!> Pour la matrice singulière droite, quatre types de matrices orthogonales sont
!> impliquées :
!>
!> (1R) La matrice singulière droite de la matrice restante.
!>
!> (2R) Si SQRE = 1, une rotation de Givens supplémentaire pour générer l'espace
!>      nul droit.
!>
!> (3R) La transformation inverse de (2L).
!>
!> (4R) La transformation inverse de (1L).
!>

Paramètres

ICOMPQ 
!>          ICOMPQ est INTEGER
!>         Spécifie si les vecteurs singuliers doivent être calculés sous
!>         forme factorisée :
!>         = 0 : Matrice singulière gauche.
!>         = 1 : Matrice singulière droite.
!>

NL

!>          NL est INTEGER
!>         La dimension de ligne du bloc supérieur. NL >= 1.
!>

NR

!>          NR est INTEGER
!>         La dimension de ligne du bloc inférieur. NR >= 1.
!>

SQRE

!>          SQRE est INTEGER
!>         = 0 : le bloc inférieur est une matrice carrée de taille NRxNR.
!>         = 1 : le bloc inférieur est une matrice rectangulaire de taille NRx(NR+1).
!>
!>         La matrice bidiagonale a une dimension de ligne N = NL + NR + 1,
!>         et une dimension de colonne M = N + SQRE.
!>

NRHS

!>          NRHS est INTEGER
!>         Le nombre de colonnes de B et BX. NRHS doit être au moins 1.
!>

B

!>          B est un tableau DOUBLE PRECISION, de dimension ( LDB, NRHS )
!>         En entrée, B contient les seconds membres du problème des moindres
!>         carrés dans les lignes 1 à M. En sortie, B contient la solution X
!>         dans les lignes 1 à N.
!>

LDB

!>          LDB est INTEGER
!>         La dimension principale de B. LDB doit être au moins
!>         max(1,MAX( M, N ) ).
!>

BX

!>          BX est un tableau DOUBLE PRECISION, de dimension ( LDBX, NRHS )
!>

LDBX

!>          LDBX est INTEGER
!>         La dimension principale de BX.
!>

PERM

!>          PERM est un tableau INTEGER, de dimension ( N )
!>         Les permutations (issues de la déflation et du tri) appliquées
!>         aux deux blocs.
!>

GIVPTR

!>          GIVPTR est INTEGER
!>         Le nombre de rotations de Givens qui ont eu lieu dans ce
!>         sous-problème.
!>

GIVCOL

!>          GIVCOL est un tableau INTEGER, de dimension ( LDGCOL, 2 )
!>         Chaque paire de nombres indique une paire de lignes/colonnes
!>         impliquée dans une rotation de Givens.
!>

LDGCOL

!>          LDGCOL est INTEGER
!>         La dimension principale de GIVCOL, doit être au moins N.
!>

GIVNUM

!>          GIVNUM est un tableau DOUBLE PRECISION, de dimension ( LDGNUM, 2 )
!>         Chaque nombre indique la valeur C ou S utilisée dans la rotation
!>         de Givens correspondante.
!>

LDGNUM

!>          LDGNUM est INTEGER
!>         La dimension principale des tableaux DIFR, POLES et
!>         GIVNUM, doit être au moins K.
!>

POLES

!>          POLES est un tableau DOUBLE PRECISION, de dimension ( LDGNUM, 2 )
!>         En entrée, POLES(1:K, 1) contient les nouvelles valeurs singulières
!>         obtenues en résolvant l'équation séculaire, et
!>         POLES(1:K, 2) est un tableau contenant les pôles de
!>         l'équation séculaire.
!>

DIFL

!>          DIFL est un tableau DOUBLE PRECISION, de dimension ( K ).
!>         En entrée, DIFL(I) est la distance entre la I-ème valeur singulière
!>         mise à jour (non déflatée) et l'ancienne I-ème valeur singulière
!>         (non déflatée).
!>

DIFR

!>          DIFR est un tableau DOUBLE PRECISION, de dimension ( LDGNUM, 2 ).
!>         En entrée, DIFR(I, 1) contient les distances entre la I-ème valeur
!>         singulière mise à jour (non déflatée) et la (I+1)-ième ancienne
!>         valeur singulière (non déflatée). Et DIFR(I, 2) est le
!>         facteur de normalisation pour le I-ème vecteur singulier droit.
!>

Z

!>          Z est un tableau DOUBLE PRECISION, de dimension ( K )
!>         Contient les composantes du vecteur ligne de mise à jour ajusté par
!>         déflation.
!>

K

!>          K est INTEGER
!>         Contient la dimension de la matrice non déflatée,
!>         C'est l'ordre de l'équation séculaire associée. 1 <= K <=N.
!>

C

!>          C est DOUBLE PRECISION
!>         C contient des données incorrectes si SQRE = 0 et la valeur C d'une
!>         rotation de Givens liée à l'espace nul droit si SQRE = 1.
!>

S

!>          S est DOUBLE PRECISION
!>         S contient des données incorrectes si SQRE = 0 et la valeur S d'une
!>         rotation de Givens liée à l'espace nul droit si SQRE = 1.
!>

WORK

!>          WORK est un tableau DOUBLE PRECISION, de dimension ( K )
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie.
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.
!>
