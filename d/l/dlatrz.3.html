Documentation de la fonction/sous-programme

sous-programme dlatrz (integer m, integer n, integer l, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( * ) tau, double precision, dimension( * ) work)

DLATRZ factorise une matrice trapézoïdale supérieure par des transformations orthogonales.

Objectif :

!>
!> DLATRZ factorise la matrice trapézoïdale supérieure réelle M par (M+L)
!> [ A1 A2 ] = [ A(1:M,1:M) A(1:M,N-L+1:N) ] en ( R  0 ) * Z, par des
!> transformations orthogonales.  Z est une matrice orthogonale de (M+L)x(M+L)
!> et R et A1 sont des matrices triangulaires supérieures de MxM.
!>

Paramètres

M 
!>          M est un ENTIER
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

N

!>          N est un ENTIER
!>          Le nombre de colonnes de la matrice A.  N >= 0.
!>

L

!>          L est un ENTIER
!>          Le nombre de colonnes de la matrice A contenant la partie
!>          significative des vecteurs de Householder. N-M >= L >= 0.
!>

A

!>          A est un tableau DOUBLE PRECISION, de dimension (LDA,N)
!>          À l'entrée, la partie trapézoïdale supérieure principale MxN de
!>          du tableau A doit contenir la matrice à factoriser.
!>          À la sortie, la partie triangulaire supérieure principale MxM de A
!>          contient la matrice triangulaire supérieure R, et les éléments N-L+1 à
!>          N des M premières lignes de A, avec le tableau TAU, représentent la
!>          matrice orthogonale Z comme un produit de M transformées élémentaires.
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale du tableau A.  LDA >= max(1,M).
!>

TAU

!>          TAU est un tableau DOUBLE PRECISION, de dimension (M)
!>          Les facteurs scalaires des transformées élémentaires.
!>

WORK

!>          WORK est un tableau DOUBLE PRECISION, de dimension (M)
!>

Détails supplémentaires :

!>
!> La factorisation est obtenue par la méthode de Householder. La k-ième
!> matrice de transformation, Z( k ), qui est utilisée pour introduire des zéros dans
!> la ( m - k + 1 )-ième ligne de A, est donnée sous la forme
!>
!>    Z( k ) = ( I     0   ),
!>             ( 0  T( k ) )
!>
!> où
!>
!>    T( k ) = I - tau*u( k )*u( k )**T,   u( k ) = (   1    ),
!>                                                (   0    )
!>                                                ( z( k ) )
!>
!> tau est un scalaire et z( k ) est un vecteur de l et sont
!> choisis pour annuler les éléments de la k-ième ligne de A2.
!>
!> Le scalaire tau est retourné dans le k-ième élément de TAU et le vecteur
!> u( k ) dans la k-ième ligne de A2, de sorte que les éléments de z( k ) sont
!> dans  a( k, l + 1 ), ..., a( k, n ). Les éléments de R sont retournés dans
!> la partie triangulaire supérieure de A1.
!>
!> Z est donné par
!>
!>    Z =  Z( 1 ) * Z( 2 ) * ... * Z( m ).
!>
