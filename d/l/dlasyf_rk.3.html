sous-routine dlasyf_rk (uplo, n, nb, kb, a, lda, e, ipiv, w, ldw, info)
DLASYF_RK calcule une factorisation partielle d'une matrice symétrique indéfinie réelle en utilisant la méthode de pivotement diagonal Bunch-Kaufman bornée (rook).

sous-routine dlasyf_rk (character uplo, integer n, integer nb, integer kb, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( * ) e, integer, dimension( * ) ipiv, double precision, dimension( ldw, * ) w, integer ldw, integer

DLASYF_RK calcule une factorisation partielle d'une matrice symétrique indéfinie réelle en utilisant la méthode de pivotement diagonal Bunch-Kaufman bornée (rook)

.

But

: 
!> DLASYF_RK calcule une factorisation partielle d'une matrice
!> symétrique réelle A en utilisant la méthode de pivotement diagonal
!> Bunch-Kaufman bornée (rook). La factorisation partielle a la forme :
!>
!> A  =  ( I  U12 ) ( A11  0  ) (  I       0    )  si UPLO = 'U', ou :
!>       ( 0  U22 ) (  0   D  ) ( U12**T U22**T )
!>
!> A  =  ( L11  0 ) (  D   0  ) ( L11**T L21**T )  si UPLO = 'L',
!>       ( L21  I ) (  0  A22 ) (  0       I    )
!>
!> où l'ordre de D est au plus NB. L'ordre réel est renvoyé dans
!> l'argument KB, et vaut soit NB ou NB-1, ou N si N <= NB.
!>
!> DLASYF_RK est une routine auxiliaire appelée par DSYTRF_RK. Elle utilise
!> un code par blocs (appelant les BLAS de niveau 3) pour mettre à jour la
!> sous-matrice A11 (si UPLO = 'U') ou A22 (si UPLO = 'L').
!
>

Paramètre

s
UPLO 
!>          UPLO est CHARACTER*1
!>          Indique si la partie triangulaire supérieure ou inférieure de la
!>          matrice symétrique A est stockée :
!>          = 'U' :  Triangulaire supérieure
!>          = 'L' :  Triangulaire inférieure
!
>

N 
!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!
>

N

B 
!>          NB est INTEGER
!>          Le nombre maximal de colonnes de la matrice A qui doivent être
!>          factorisées.  NB devrait être au moins 2 pour permettre des
!>          blocs pivots de taille 2 par 2.
!
>

K

B 
!>          KB est INTEGER
!>          Le nombre de colonnes de A qui ont été effectivement factorisées.
!>          KB vaut soit NB-1 ou NB, ou N si N <= NB.
!
>

A 
!>          A est un tableau DOUBLE PRECISION, dimension (LDA,N)
!>          À l'entrée, la matrice symétrique A.
!>            Si UPLO = 'U' : la partie triangulaire supérieure N par N
!>            de A contient la partie triangulaire supérieure de la matrice A,
!>            et la partie strictement triangulaire inférieure de A n'est pas
!>            référencée.
!>
!>            Si UPLO = 'L' : la partie triangulaire inférieure N par N
!>            de A contient la partie triangulaire inférieure de la matrice A,
!>            et la partie strictement triangulaire supérieure de A n'est pas
!>            référencée.
!>
!>          À la sortie, contient :
!>            a) UNIQUEMENT les éléments diagonaux de la matrice diagonale par
!>               blocs symétrique D sur la diagonale de A, c.-à-d. D(k,k) = A(k,k) ;
!>               (les éléments superdiagonaux (ou sous-diagonaux) de D
!>                sont stockés à la sortie dans le tableau E), et
!>            b) Si UPLO = 'U' : le facteur U dans la partie superdiagonale de A.
!>               Si UPLO = 'L' : le facteur L dans la partie sous-diagonale de A.
!
>

LD

A 
!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!
>

E 
!>          E est un tableau DOUBLE PRECISION, dimension (N)
!>          À la sortie, contient les éléments superdiagonaux (ou sous-diagonaux)
!>          de la matrice diagonale par blocs symétrique D
!>          avec des blocs diagonaux de taille 1 par 1 ou 2 par 2, où
!>          Si UPLO = 'U' : E(i) = D(i-1,i), i=2:N, E(1) est mis à 0 ;
!>          Si UPLO = 'L' : E(i) = D(i+1,i), i=1:N-1, E(N) est mis à 0.
!>
!>          NOTE : Pour un bloc diagonal D(k) de taille 1 par 1, où
!>          1 <= k <= N, l'élément E(k) est mis à 0 dans les deux cas
!>          UPLO = 'U' et UPLO = 'L'.
!
>

IPI

V 
!>          IPIV est un tableau INTEGER, dimension (N)
!>          IPIV décrit la matrice de permutation P dans la factorisation
!>          de la matrice A comme suit. La valeur absolue de IPIV(k)
!>          représente l'indice de la ligne et de la colonne qui ont été
!>          interchangées avec la k-ième ligne et colonne. La valeur de UPLO
!>          décrit l'ordre dans lequel les interchanges ont été appliqués.
!>          De plus, le signe de IPIV représente la structure par blocs de
!>          la matrice diagonale par blocs symétrique D avec des blocs
!>          diagonaux de taille 1 par 1 ou 2 par 2 qui correspondent à 1 ou 2
!>          interchanges à chaque étape de factorisation.
!>
!>          Si UPLO = 'U',
!>          ( dans l'ordre de factorisation, k décroît de N à 1 ) :
!>            a) Une entrée unique positive IPIV(k) > 0 signifie :
!>               D(k,k) est un bloc diagonal de taille 1 par 1.
!>               Si IPIV(k) != k, les lignes et colonnes k et IPIV(k) ont été
!>               interchangées dans la sous-matrice A(1:N,N-KB+1:N) ;
!>               Si IPIV(k) = k, aucun interchange n'a eu lieu.
!>
!>
!>            b) Une paire d'entrées négatives consécutives
!>               IPIV(k) < 0 et IPIV(k-1) < 0 signifie :
!>               D(k-1:k,k-1:k) est un bloc diagonal de taille 2 par 2.
!>               (NOTE : les entrées négatives dans IPIV apparaissent UNIQUEMENT par paires).
!>               1) Si -IPIV(k) != k, les lignes et colonnes
!>                  k et -IPIV(k) ont été interchangées
!>                  dans la matrice A(1:N,N-KB+1:N).
!>                  Si -IPIV(k) = k, aucun interchange n'a eu lieu.
!>               2) Si -IPIV(k-1) != k-1, les lignes et colonnes
!>                  k-1 et -IPIV(k-1) ont été interchangées
!>                  dans la sous-matrice A(1:N,N-KB+1:N).
!>                  Si -IPIV(k-1) = k-1, aucun interchange n'a eu lieu.
!>
!>            c) Dans les deux cas a) et b), ABS( IPIV(k) ) <= k est toujours vrai.
!>
!>            d) NOTE : Toute entrée IPIV(k) est toujours NON NULLE à la sortie.
!>
!>          Si UPLO = 'L',
!>          ( dans l'ordre de factorisation, k croît de 1 à N ) :
!>            a) Une entrée unique positive IPIV(k) > 0 signifie :
!>               D(k,k) est un bloc diagonal de taille 1 par 1.
!>               Si IPIV(k) != k, les lignes et colonnes k et IPIV(k) ont été
!>               interchangées dans la sous-matrice A(1:N,1:KB).
!>               Si IPIV(k) = k, aucun interchange n'a eu lieu.
!>
!>            b) Une paire d'entrées négatives consécutives
!>               IPIV(k) < 0 et IPIV(k+1) < 0 signifie :
!>               D(k:k+1,k:k+1) est un bloc diagonal de taille 2 par 2.
!>               (NOTE : les entrées négatives dans IPIV apparaissent UNIQUEMENT par paires).
!>               1) Si -IPIV(k) != k, les lignes et colonnes
!>                  k et -IPIV(k) ont été interchangées
!>                  dans la sous-matrice A(1:N,1:KB).
!>                  Si -IPIV(k) = k, aucun interchange n'a eu lieu.
!>               2) Si -IPIV(k+1) != k+1, les lignes et colonnes
!>                  k-1 et -IPIV(k-1) ont été interchangées
!>                  dans la sous-matrice A(1:N,1:KB).
!>                  Si -IPIV(k+1) = k+1, aucun interchange n'a eu lieu.
!>
!>            c) Dans les deux cas a) et b), ABS( IPIV(k) ) >= k est toujours vrai.
!>
!>            d) NOTE : Toute entrée IPIV(k) est toujours NON NULLE à la sortie.
!
>

W 
!>          W est un tableau DOUBLE PRECISION, dimension (LDW,NB)
!
>

LD

W 
!>          LDW est INTEGER
!>          La dimension principale du tableau W.  LDW >= max(1,N).
!
>

INF

O 
!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>
!>          < 0 : Si INFO = -k, le k-ième argument avait une valeur illégale
!>
!>          > 0 : Si INFO = k, la matrice A est singulière, car :
!>                 Si UPLO = 'U' : la colonne k dans la partie
!>                 triangulaire supérieure de A contient uniquement des zéros.
!>                 Si UPLO = 'L' : la colonne k dans la partie
!>                 triangulaire inférieure de A contient uniquement des zéros.
!>
!>               Par conséquent D(k,k) est exactement nul, et les éléments
!>               superdiagonaux de la colonnemn k de U (ou les éléments sous-diagonaux de
!>               la colonne k de L ) sont tous nuls. La factorisation a
!>               été achevée, mais la matrice diagonale par blocs D est
!>               exactement singulière, et une division par zéro se produira si
!>               elle est utilisée pour résoudre un système d'équations.
!>
!>               NOTE : INFO ne stocke que la première occurrence
!>               d'une singularité, toute occurrence ultérieure de singularité
!>               n'est pas stockée dans INFO même si la factorisation
!>               se termine toujours.
!
>
