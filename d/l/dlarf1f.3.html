Documentation de fonction/sous-routine

sous-routine dlarf1f (caractère side, entier m, entier n, double précision, dimension( * ) v, entier incv, double précision tau, double précision, dimension( ldc, * ) c, entier ldc, double précision, dimension( * ) work)

DLARF1F applique un réflecteur élémentaire réel H à une matrice réelle m par n

Objectif :

!>
!> DLARF1F applique un réflecteur élémentaire réel H à une matrice réelle m par n
!> C, soit à gauche, soit à droite. H est représenté sous la forme
!>
!>       H = I - tau * v * v**T
!>
!> où tau est un scalaire réel et v est un vecteur réel.
!>
!> Si tau = 0, alors H est considérée comme la matrice unité.
!>

Paramètres

SIDE 
!>          SIDE est CHARACTER*1
!>          = 'L' : former H * C
!>          = 'R' : former C * H
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice C.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice C.
!>

V

!>          V est un tableau DOUBLE PRECISION, dimension
!>                     (1 + (M-1)*abs(INCV)) si SIDE = 'L'
!>                  ou (1 + (N-1)*abs(INCV)) si SIDE = 'R'
!>          Le vecteur v dans la représentation de H. V n'est pas utilisé si
!>          TAU = 0. V(1) n'est pas référencé ni modifié.
!>

INCV

!>          INCV est INTEGER
!>          L'incrément entre les éléments de v. INCV <> 0.
!>

TAU

!>          TAU est DOUBLE PRECISION
!>          La valeur tau dans la représentation de H.
!>

C

!>          C est un tableau DOUBLE PRECISION, dimension (LDC,N)
!>          À l'entrée, la matrice m par n C.
!>          À la sortie, C est écrasé par la matrice H * C si SIDE = 'L',
!>          ou C * H si SIDE = 'R'.
!>

LDC

!>          LDC est INTEGER
!>          La dimension principale du tableau C. LDC >= max(1,M).
!>

WORK

!>          WORK est un tableau DOUBLE PRECISION, dimension
!>                         (N) si SIDE = 'L'
!>                      ou (M) si SIDE = 'R'
!>
