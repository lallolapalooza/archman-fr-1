sous-routine dlarrj (integer n, double precision, dimension( * ) d, double precision, dimension( * ) e2, integer ifirst, integer ilast, double precision rtol, integer offset, double precision, dimension( * ) w, double precision, dimension( * ) werr, double precision, dimension( * ) work, integer, dimension( * ) iwork, double precision pivmin, double precision spdiam, integer info)

DLARRJ effectue le raffinement des estimations initiales des valeurs propres de la matrice T.

But :

!>
!> Étant donné les approximations initiales des valeurs propres de T, DLARRJ
!> effectue une dichotomie pour raffiner les valeurs propres de T,
!> W( IFIRST-OFFSET ) à travers W( ILAST-OFFSET ), avec plus de précision. Les
!> estimations initiales de ces valeurs propres sont entrées dans W, l'estimation
!> correspondante de l'erreur dans ces estimations dans WERR. Pendant la dichotomie,
!> les intervalles [gauche, droite] sont maintenus en stockant leurs points médians
!> et leurs demi-largeurs dans les tableaux W et WERR respectivement.
!>

Paramètres

N 
!>          N est un entier (INTEGER)
!>          L'ordre de la matrice.
!>

D

!>          D est un tableau de double précision (DOUBLE PRECISION), dimension (N)
!>          Les N éléments diagonaux de T.
!>

E2

!>          E2 est un tableau de double précision (DOUBLE PRECISION), dimension (N-1)
!>          Les carrés des (N-1) éléments sous-diagonaux de T.
!>

IFIRST

!>          IFIRST est un entier (INTEGER)
!>          L'indice de la première valeur propre à calculer.
!>

ILAST

!>          ILAST est un entier (INTEGER)
!>          L'indice de la dernière valeur propre à calculer.
!>

RTOL

!>          RTOL est une double précision (DOUBLE PRECISION)
!>          Tolérance pour la convergence des intervalles de dichotomie.
!>          Un intervalle [GAUCHE, DROITE] est considéré comme convergé si
!>          DROITE-GAUCHE < RTOL*MAX(|GAUCHE|,|DROITE|).
!>

OFFSET

!>          OFFSET est un entier (INTEGER)
!>          Décalage pour les tableaux W et WERR, c'est-à-dire que les éléments
!>          IFIRST-OFFSET à ILAST-OFFSET de ces tableaux doivent être utilisés.
!>

W

!>          W est un tableau de double précision (DOUBLE PRECISION), dimension (N)
!>          En entrée, W( IFIRST-OFFSET ) à W( ILAST-OFFSET ) sont
!>          des estimations des valeurs propres de L D L^T indexées de IFIRST à
!>          ILAST.
!>          En sortie, ces estimations sont raffinées.
!>

WERR

!>          WERR est un tableau de double précision (DOUBLE PRECISION), dimension (N)
!>          En entrée, WERR( IFIRST-OFFSET ) à WERR( ILAST-OFFSET ) sont
!>          les erreurs dans les estimations des éléments correspondants dans W.
!>          En sortie, ces erreurs sont raffinées.
!>

WORK

!>          WORK est un tableau de double précision (DOUBLE PRECISION), dimension (2*N)
!>          Espace de travail.
!>

IWORK

!>          IWORK est un tableau d'entiers (INTEGER), dimension (2*N)
!>          Espace de travail.
!>

PIVMIN

!>          PIVMIN est une double précision (DOUBLE PRECISION)
!>          Le pivot minimum dans la suite de Sturm de T.
!>

SPDIAM

!>          SPDIAM est une double précision (DOUBLE PRECISION)
!>          Le diamètre spectral de T.
!>

INFO

!>          INFO est un entier (INTEGER)
!>          Indicateur d'erreur.
!>
