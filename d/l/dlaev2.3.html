subroutine dlaev2 (double precision a, double precision b, double precision c, double precision rt1, double precision rt2, double precision cs1, double precision sn1)

DLAEV2 calcule les valeurs propres et les vecteurs propres d'une matrice symétrique 2x2.

But :

!>
!> DLAEV2 calcule la décomposition en valeurs propres d'une matrice symétrique 2x2
!>    [  A   B  ]
!>    [  B   C  ].
!> Au retour, RT1 est la valeur propre de plus grande valeur absolue, RT2 est la
!> valeur propre de plus petite valeur absolue, et (CS1,SN1) est le vecteur propre
!> à droite unitaire pour RT1, donnant la décomposition
!>
!>    [ CS1  SN1 ] [  A   B  ] [ CS1 -SN1 ]  =  [ RT1  0  ]
!>    [-SN1  CS1 ] [  B   C  ] [ SN1  CS1 ]     [  0  RT2 ].
!>

Paramètres

A 
!>          A est DOUBLE PRECISION
!>          L'élément (1,1) de la matrice 2x2.
!>

B

!>          B est DOUBLE PRECISION
!>          L'élément (1,2) et le conjugué de l'élément (2,1) de
!>          la matrice 2x2.
!>

C

!>          C est DOUBLE PRECISION
!>          L'élément (2,2) de la matrice 2x2.
!>

RT1

!>          RT1 est DOUBLE PRECISION
!>          La valeur propre de plus grande valeur absolue.
!>

RT2

!>          RT2 est DOUBLE PRECISION
!>          La valeur propre de plus petite valeur absolue.
!>

CS1

!>          CS1 est DOUBLE PRECISION
!>

SN1

!>          SN1 est DOUBLE PRECISION
!>          Le vecteur (CS1, SN1) est un vecteur propre à droite unitaire pour RT1.
!>

Auteur

Univ. du Tennessee

Univ. de Californie à Berkeley

Univ. du Colorado à Denver

NAG Ltd.

Détails supplémentaires :

!>
!>  RT1 est précise à quelques ulps près, sous réserve de dépassement de capacité
!>  ou de sous-dépassement.
!>
!>  RT2 peut être imprécise s'il y a une annulation massive dans le
!>  déterminant A*C-B*B ; une arithmétique de plus haute précision ou correctement arrondie ou
!>  correctement tronquée serait nécessaire pour calculer RT2
!>  avec précision dans tous les cas.
!>
!>  CS1 et SN1 sont précis à quelques ulps près, sous réserve de dépassement de capacité
!>  ou de sous-dépassement.
!>
!>  Un dépassement de capacité n'est possible que si RT1 est à un facteur 5 du dépassement.
!>  Un sous-dépassement n'est pas nuisible si les données d'entrée sont 0 ou dépassent
!>     seuil_de_sous-dépassement / macheps.
!>

Définition à la ligne 119 du fichier dlaev2.f.
