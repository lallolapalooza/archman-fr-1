Documentation de la fonction/sous-programme

sous-programme dlsets (entier m, entier p, entier n, double précision, dimension( lda, * ) a, double précision, dimension( lda, * ) af, entier lda, double précision, dimension( ldb, * ) b, double précision, dimension( ldb, * ) bf, entier ldb, double précision, dimension( * ) c, double précision, dimension( * ) cf, double précision, dimension( * ) d, double précision, dimension( * ) df, double précision, dimension( * ) x, double précision, dimension( lwork ) work, entier lwork, double précision, dimension( * ) rwork, double précision, dimension( 2 ) result)

DLSETS

Objectif :

!>
!> DLSETS teste DGGLSE - un sous-programme pour résoudre le problème du moindre carré linéaire avec contraintes d'égalité (LSE).
!>

Paramètres

M 
!>          M est un ENTIER
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

P

!>          P est un ENTIER
!>          Le nombre de lignes de la matrice B.  P >= 0.
!>

N

!>          N est un ENTIER
!>          Le nombre de colonnes des matrices A et B.  N >= 0.
!>

A

!>          A est un tableau de DOUBLE PRÉCISION, dimension (LDA,N)
!>          La matrice M par N, A.
!>

AF

!>          AF est un tableau de DOUBLE PRÉCISION, dimension (LDA,N)
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale des tableaux A, AF, Q et R.
!>          LDA >= max(M,N).
!>

B

!>          B est un tableau de DOUBLE PRÉCISION, dimension (LDB,N)
!>          La matrice P par N, A.
!>

BF

!>          BF est un tableau de DOUBLE PRÉCISION, dimension (LDB,N)
!>

LDB

!>          LDB est un ENTIER
!>          La dimension principale des tableaux B, BF, V et S.
!>          LDB >= max(P,N).
!>

C

!>          C est un tableau de DOUBLE PRÉCISION, dimension( M )
!>          Le vecteur C dans le problème LSE.
!>

CF

!>          CF est un tableau de DOUBLE PRÉCISION, dimension( M )
!>

D

!>          D est un tableau de DOUBLE PRÉCISION, dimension( P )
!>          Le vecteur D dans le problème LSE.
!>

DF

!>          DF est un tableau de DOUBLE PRÉCISION, dimension( P )
!>

X

!>          X est un tableau de DOUBLE PRÉCISION, dimension( N )
!>          Vecteur solution X dans le problème LSE.
!>

WORK

!>          WORK est un tableau de DOUBLE PRÉCISION, dimension (LWORK)
!>

LWORK

!>          LWORK est un ENTIER
!>          La dimension du tableau WORK.
!>

RWORK

!>          RWORK est un tableau de DOUBLE PRÉCISION, dimension (M)
!>

RESULT

!>          RESULT est un tableau de DOUBLE PRÉCISION, dimension (2)
!>          Les rapports de test :
!>            RESULT(1) = norm( A*x - c )/ norm(A)*norm(X)*EPS
!>            RESULT(2) = norm( B*x - d )/ norm(B)*norm(X)*EPS
!>
