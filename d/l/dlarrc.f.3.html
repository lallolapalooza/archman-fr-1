DLARRC calcule le nombre de valeurs propres de la matrice tridiagonale symétrique.

Documentation de la fonction/sous-routine

sous-routine dlarrc (character jobt, integer n, double precision vl, double precision vu, double precision, dimension( * ) d, double precision, dimension( * ) e, double precision pivmin, integer eigcnt, integer lcnt, integer rcnt, integer info)

DLARRC calcule le nombre de valeurs propres de la matrice symétrique tridiagonale.

Objectif :

!>
!> Trouver le nombre de valeurs propres de la matrice tridiagonale symétrique T
!> qui sont dans l'intervalle (VL,VU] si JOBT = 'T', et de L D L^T
!> si JOBT = 'L'.
!>

Paramètres

JOBT 
!>          JOBT est CHARACTER*1
!>          = 'T' : Calculer le dénombrement de Sturm pour la matrice T.
!>          = 'L' : Calculer le dénombrement de Sturm pour la matrice L D L^T.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice. N > 0.
!>

VL

!>          VL est DOUBLE PRECISION
!>          La borne inférieure pour les valeurs propres.
!>

VU

!>          VU est DOUBLE PRECISION
!>          La borne supérieure pour les valeurs propres.
!>

D

!>          D est tableau DOUBLE PRECISION, dimension (N)
!>          JOBT = 'T' : Les N éléments diagonaux de la matrice tridiagonale T.
!>          JOBT = 'L' : Les N éléments diagonaux de la matrice diagonale D.
!>

E

!>          E est tableau DOUBLE PRECISION, dimension (N)
!>          JOBT = 'T' : Les N-1 éléments hors diagonaux de la matrice T.
!>          JOBT = 'L' : Les N-1 éléments hors diagonaux de la matrice L.
!>

PIVMIN

!>          PIVMIN est DOUBLE PRECISION
!>          Le pivot minimum dans la séquence de Sturm pour T.
!>

EIGCNT

!>          EIGCNT est INTEGER
!>          Le nombre de valeurs propres de la matrice tridiagonale symétrique T
!>          qui sont dans l'intervalle (VL,VU]
!>

LCNT

!>          LCNT est INTEGER
!>

RCNT

!>          RCNT est INTEGER
!>          Les dénombrements gauche et droit de l'intervalle.
!>

INFO

!>          INFO est INTEGER
!>
