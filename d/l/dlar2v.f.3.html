Documentation Fonction/Sous-programme

sous-programme dlar2v (integer n, double precision, dimension( * ) x, double precision, dimension( * ) y, double precision, dimension( * ) z, integer incx, double precision, dimension( * ) c, double precision, dimension( * ) s, integer incc)

DLAR2V applique un vecteur de rotations planes avec des cosinus réels et des sinus réels des deux côtés à une séquence de matrices symétriques/hermitiennes de taille 2x2.

Objectif :

!>
!> DLAR2V applique un vecteur de rotations planes réelles des deux côtés
!> à une séquence de matrices réelles symétriques 2x2, définies par les éléments
!> des vecteurs x, y et z. Pour i = 1,2,...,n
!>
!>    ( x(i)  z(i) ) := (  c(i)  s(i) ) ( x(i)  z(i) ) ( c(i) -s(i) )
!>    ( z(i)  y(i) )    ( -s(i)  c(i) ) ( z(i)  y(i) ) ( s(i)  c(i) )
!>

Paramètres

N 
!>          N est INTEGER
!>          Le nombre de rotations planes à appliquer.
!>

X

!>          X est un tableau DOUBLE PRECISION,
!>                         dimension (1+(N-1)*INCX)
!>          Le vecteur x.
!>

Y

!>          Y est un tableau DOUBLE PRECISION,
!>                         dimension (1+(N-1)*INCX)
!>          Le vecteur y.
!>

Z

!>          Z est un tableau DOUBLE PRECISION,
!>                         dimension (1+(N-1)*INCX)
!>          Le vecteur z.
!>

INCX

!>          INCX est INTEGER
!>          L'incrément entre les éléments de X, Y et Z. INCX > 0.
!>

C

!>          C est un tableau DOUBLE PRECISION, dimension (1+(N-1)*INCC)
!>          Les cosinus des rotations planes.
!>

S

!>          S est un tableau DOUBLE PRECISION, dimension (1+(N-1)*INCC)
!>          Les sinus des rotations planes.
!>

INCC

!>          INCC est INTEGER
!>          L'incrément entre les éléments de C et S. INCC > 0.
!>
