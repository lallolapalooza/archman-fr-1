subroutine dlar1v (integer n, integer b1, integer bn, double precision lambda, double precision, dimension( * ) d, double precision, dimension( * ) l, double precision, dimension( * ) ld, double precision, dimension( * ) lld, double precision pivmin, double precision gaptol, double precision, dimension( * ) z, logical wantnc, integer negcnt, double precision ztz, double precision mingma, integer r, integer, dimension( * ) isuppz, double precision nrminv, double precision resid, double precision rqcorr, double precision, dimension( * ) work)

DLAR1V calcule la r-ième colonne (mise à l'échelle) de l'inverse de la sous-matrice située dans les lignes b1 à bn de la matrice tridiagonale LDLT - λI.

But :

!>
!> DLAR1V calcule la r-ième colonne (mise à l'échelle) de l'inverse de
!> la sous-matrice située dans les lignes B1 à BN de la matrice tridiagonale
!> L D L**T - sigma I. Lorsque sigma est proche d'une valeur propre, le
!> vecteur calculé est un vecteur propre précis. Généralement, r correspond
!> à l'indice où le vecteur propre est le plus grand en valeur absolue.
!> Les étapes suivantes accomplissent ce calcul :
!> (a) Transformation qd stationnaire, L D L**T - sigma I = L(+) D(+) L(+)**T,
!> (b) Transformation qd progressive, L D L**T - sigma I = U(-) D(-) U(-)**T,
!> (c) Calcul des éléments diagonaux de l'inverse de
!>     L D L**T - sigma I en combinant les transformations ci-dessus, et en choisissant
!>     r comme l'indice où la diagonale de l'inverse est (l'une des plus)
!>     grandes en valeur absolue.
!> (d) Calcul de la r-ième colonne (mise à l'échelle) de l'inverse en utilisant la
!>     factorisation tordue obtenue en combinant la partie supérieure de la
!>     transformation stationnaire et la partie inférieure de la transformation progressive.
!>

Paramètres

N 
!>          N est INTEGER
!>           L'ordre de la matrice L D L**T.
!>

B1

!>          B1 est INTEGER
!>           Premier indice de la sous-matrice de L D L**T.
!>

BN

!>          BN est INTEGER
!>           Dernier indice de la sous-matrice de L D L**T.
!>

LAMBDA

!>          LAMBDA est DOUBLE PRECISION
!>           Le décalage. Afin de calculer un vecteur propre précis,
!>           LAMBDA devrait être une bonne approximation d'une valeur propre
!>           de L D L**T.
!>

L

!>          L est un tableau DOUBLE PRECISION, dimension (N-1)
!>           Les (n-1) éléments sous-diagonaux de la matrice bidiagonale unitaire
!>           L, dans les éléments 1 à N-1.
!>

D

!>          D est un tableau DOUBLE PRECISION, dimension (N)
!>           Les n éléments diagonaux de la matrice diagonale D.
!>

LD

!>          LD est un tableau DOUBLE PRECISION, dimension (N-1)
!>           Les n-1 éléments L(i)*D(i).
!>

LLD

!>          LLD est un tableau DOUBLE PRECISION, dimension (N-1)
!>           Les n-1 éléments L(i)*L(i)*D(i).
!>

PIVMIN

!>          PIVMIN est DOUBLE PRECISION
!>           Le pivot minimum dans la séquence de Sturm.
!>

GAPTOL

!>          GAPTOL est DOUBLE PRECISION
!>           Tolérance qui indique quand les entrées du vecteur propre sont négligeables
!>           par rapport à leur contribution au résidu.
!>

Z

!>          Z est un tableau DOUBLE PRECISION, dimension (N)
!>           En entrée, toutes les entrées de Z doivent être mises à 0.
!>           En sortie, Z contient la r-ième colonne (mise à l'échelle) de
!>           l'inverse. La mise à l'échelle est telle que Z(R) vaut 1.
!>

WANTNC

!>          WANTNC est LOGICAL
!>           Indique si NEGCNT doit être calculé.
!>

NEGCNT

!>          NEGCNT est INTEGER
!>           Si WANTNC est .TRUE. alors NEGCNT = le nombre de pivots < pivmin
!>           dans la factorisation de matrice L D L**T, et NEGCNT = -1 sinon.
!>

ZTZ

!>          ZTZ est DOUBLE PRECISION
!>           Le carré de la 2-norme de Z.
!>

MINGMA

!>          MINGMA est DOUBLE PRECISION
!>           L'inverse de l'élément diagonal le plus grand (en valeur absolue)
!>           de l'inverse de L D L**T - sigma I.
!>

R

!>          R est INTEGER
!>           L'indice de torsion pour la factorisation tordue utilisée pour
!>           calculer Z.
!>           En entrée, 0 <= R <= N. Si R est entré comme 0, R est défini à
!>           l'indice où (L D L**T - sigma I)^{-1} est le plus grand
!>           en valeur absolue. Si 1 <= R <= N, R est inchangé.
!>           En sortie, R contient l'indice de torsion utilisé pour calculer Z.
!>           Idéalement, R désigne la position de l'entrée maximale dans le
!>           vecteur propre.
!>

ISUPPZ

!>          ISUPPZ est un tableau INTEGER, dimension (2)
!>           Le support du vecteur dans Z, c'est-à-dire que le vecteur Z est
!>           non nul uniquement dans les éléments ISUPPZ(1) à ISUPPZ( 2 ).
!>

NRMINV

!>          NRMINV est DOUBLE PRECISION
!>           NRMINV = 1/SQRT( ZTZ )
!>

RESID

!>          RESID est DOUBLE PRECISION
!>           Le résidu du vecteur FP.
!>           RESID = ABS( MINGMA )/SQRT( ZTZ )
!>

RQCORR

!>          RQCORR est DOUBLE PRECISION
!>           La correction du quotient de Rayleigh pour LAMBDA.
!>           RQCORR = MINGMA*TMP
!>

WORK

!>          WORK est un tableau DOUBLE PRECISION, dimension (4*N)
!>
