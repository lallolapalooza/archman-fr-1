Paramètres

ILSCHUR 
!>          ILSCHUR est de type LOGICAL
!>              Détermine s'il faut ou non mettre à jour la forme de Schur complète
!>

ILQ

!>          ILQ est de type LOGICAL
!>              Détermine s'il faut ou non mettre à jour la matrice Q
!>

ILZ

!>          ILZ est de type LOGICAL
!>              Détermine s'il faut ou non mettre à jour la matrice Z
!>

N

!>          N est de type INTEGER
!>          L'ordre des matrices A, B, Q et Z.  N >= 0.
!>

ILO

!>          ILO est de type INTEGER
!>

IHI

!>          IHI est de type INTEGER
!>

NSHIFTS

!>          NSHIFTS est de type INTEGER
!>          Le nombre de décalages souhaité à utiliser
!>

NBLOCK_DESIRED

!>          NBLOCK_DESIRED est de type INTEGER
!>          La taille souhaitée des fenêtres de calcul
!>

SR

!>          SR est un tableau de type DOUBLE PRECISION. SR contient
!>          les parties réelles des décalages à utiliser.
!>

SI

!>          SI est un tableau de type DOUBLE PRECISION. SI contient
!>          les parties imaginaires des décalages à utiliser.
!>

SS

!>          SS est un tableau de type DOUBLE PRECISION. SS contient
!>          l'échelle des décalages à utiliser.
!>

A

!>          A est un tableau de type DOUBLE PRECISION, dimension (LDA, N)
!>

LDA

!>          LDA est de type INTEGER
!>          La dimension principale du tableau A.  LDA >= max( 1, N ).
!>

B

!>          B est un tableau de type DOUBLE PRECISION, dimension (LDB, N)
!>

LDB

!>          LDB est de type INTEGER
!>          La dimension principale du tableau B.  LDB >= max( 1, N ).
!>

Q

!>          Q est un tableau de type DOUBLE PRECISION, dimension (LDQ, N)
!>

LDQ

!>          LDQ est de type INTEGER
!>

Z

!>          Z est un tableau de type DOUBLE PRECISION, dimension (LDZ, N)
!>

LDZ

!>          LDZ est de type INTEGER
!>

QC

!>          QC est un tableau de type DOUBLE PRECISION, dimension (LDQC, NBLOCK_DESIRED)
!>

LDQC

!>          LDQC est de type INTEGER
!>

ZC

!>          ZC est un tableau de type DOUBLE PRECISION, dimension (LDZC, NBLOCK_DESIRED)
!>

LDZC

!>          LDZ est de type INTEGER
!>

WORK

!>          WORK est un tableau de type DOUBLE PRECISION, dimension (MAX(1,LWORK))
!>          À la sortie, si INFO >= 0, WORK(1) renvoie le LWORK optimal.
!>

LWORK

!>          LWORK est de type INTEGER
!>          La dimension du tableau WORK.  LWORK >= max(1,N).
!>
!>          Si LWORK = -1, une interrogation sur l'espace de travail est supposée ; la routine
!>          calcule uniquement la taille optimale du tableau WORK, renvoie
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          lié à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est de type INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>
